# Voxel and Grid Representations

Also called: Explicit Grid Representations, Voxel Grids, Feature Volumes

## Overview
Voxel and Grid Representations store scene information (density, color, SDF, or latent features) in explicit, discrete 3D structures, such as regular grids, octrees, or sparse volumes, rather than relying solely on coordinate-based neural networks [S1][S2, S3, unofficial]. This approach solves the computational bottleneck of evaluating large MLPs for every ray sample by replacing them with fast, differentiable interpolation operations (e.g., trilinear or bilinear) on pre-allocated memory [S1][S2, S3, unofficial]. Unlike coordinate-based methods, grid representations allow for aggressive empty space skipping, early ray termination, and efficient caching of learned features, significantly accelerating both training and inference [S3, unofficial]. They differ from sibling [Triplane and Planar Representations](18410-triplane-and-planar-representations.md) by using 3D volumetric storage rather than 2D planar projections, offering better handling of complex 3D geometry at the cost of higher memory usage for dense grids [S1][S2, unofficial].

## Shared principles
All voxel and grid representations share the following mechanism:
1.  **Discretization:** The 3D scene space is divided into a set of voxels organized in a hierarchy (e.g., coarse-to-fine levels, octrees) or a regular tensor $\mathbb{R}^{H \times W \times D}$ [S1][S2, S3, unofficial].
2.  **Feature Storage:** Each voxel (or node in an octree) stores learnable parameters. These may include:
    *   Volume density $\sigma$ [S1][S2, S3, unofficial].
    *   Latent feature vectors $f$ or $e$ used to decode color or SDF [S1][S2, S3, unofficial].
    *   Binary values $\{-1, +1\}$ for compressed storage [S2, unofficial].
3.  **Differentiable Query:** For a query point $\mathbf{x}$, values are retrieved via interpolation. Standard trilinear interpolation is used for 3D grids:
    $$ f(\mathbf{x}) = \text{interp}(\mathbf{x}, \mathbf{V}) $$
    where $\mathbf{V}$ is the feature grid [S1][S2, S3, unofficial]. This operation is differentiable, allowing gradients to flow back to the grid values during optimization [S1][S2, S3, unofficial].
4.  **Decoding:** Interpolated features are passed to a small decoder network (typically an MLP) $S_\Theta$ to predict final outputs like color $\mathbf{c}$ or SDF $s$:
    $$ \mathbf{c}(\mathbf{x}) = S_\Theta(\text{interp}(\mathbf{x}, \mathbf{V}_a)) $$
    [S1][S2, S3, unofficial].

## Subtopics

### [Binary Radiance Fields](13622-binary-radiance-fields.md)
A storage-efficient representation that constrains grid parameters to binary values $\{-1, +1\}$ using a straight-through estimator, combined with a 2D-3D hybrid multi-resolution architecture to mitigate hash collisions.

### [Adaptive Differentiable Grids for Cryo-ET](17614-adaptive-differentiable-grids-for-cryo-et.md)
An adaptive octree structure for cryo-ET where each node stores a learnable 3D density grid, optimized with differentiable trilinear interpolation and regularization to handle low-SNR data.

### [Vox-Surf](18110-vox-surf.md)
A voxel-based neural implicit surface representation storing trainable embeddings at voxel corners, using a sparse hierarchical octree to restrict learning to occupied space and enable efficient surface reconstruction.

### [Depth-Guided Robust and Fast Point Cloud Fusion NeRF](18135-depth-guided-robust-and-fast-point-cloud-fusion-nerf.md)
A framework for sparse RGB-D inputs that uses a standard 3D grid for geometry and appearance, refining depth inaccuracies by fusing point clouds from multiple views.

### [Sparse Feature Volume](18180-sparse-feature-volume.md)
A 3D scene representation encoding geometry and appearance into a sparse grid of learnable latent vectors, decoded into continuous SDF and radiance fields, offering higher resolution efficiency than dense grids.

### [PAC-NeRF](18672-pac-nerf.md)
A geometry-agnostic system identification method using a hybrid Eulerian-Lagrangian representation, where an Eulerian voxel grid stores NeRF fields and Lagrangian particles advect them via a differentiable Material Point Method (MPM).

### [Spatially Encoded Radiance Fields](21788-spatially-encoded-radiance-fields.md)
A method that simplifies the implicit radiance function by spatially decomposing it into smaller functions stored in a 3D voxel grid, reducing MLP complexity and accelerating optimization.

### Uncertain Surface Distillation
- **Definition:** A strategy to distill knowledge of previously learned 3D scenes by querying density on a subdivided occupancy grid [S1].
- **Step:** Divide each occupancy grid cell into a 5x5x5 subgrid. Query the density of each subgrid point. Consider a volume cell as a surface for distillation if any subgrid point has density above threshold $\tau$ [S1].
- **Parameter:** USD occupancy grid resolution: 50x50x50. Subgrid division per cell: 5x5x5. Density threshold $\tau$: 3 [S1].

### Occupancy-Aware NeRF
- **Definition:** A NeRF variant that jointly learns volumetric density ($\sigma$), RGB color ($c$), and a binary occupancy value ($o$) for a 3D point $x$ and viewing direction $d$, enabling O(1) collision queries via a cached 3D array [S2, unofficial].
- **Step:** At inference, the occupancy grid is cached as a regular 3D array at resolution $\Delta$ to enable O(1) collision queries [S2, unofficial].
- **Formula:** $f_\theta(x, d) = (\sigma, c, o)$, where $\sigma$ is volumetric density, $c \in \mathbb{R}^3$ is RGB color, and $o \in \{0, 1\}$ is binary occupancy [S2, unofficial]. $L = L_{rgb} + \lambda_d L_{depth} + \lambda_o \text{BCE}(\hat{o}, o^*)$, where $L_{rgb}$ is photometric loss, $L_{depth}$ is depth supervision, $o^*$ is derived from depth observations via volumetric carving, and BCE is binary cross-entropy [S2, unofficial]. $\gamma(x) = \prod_{l=1}^{L} h_l(\lfloor x \cdot s_l \rfloor)$, where $h_l$ are learned hash tables at $L$ resolution levels, $s_l$ are per-level scales, and $\prod$ denotes concatenation [S2, unofficial].
- **Layout:** Network architecture: A shared hash-grid backbone (from Instant-NGP [4]) feeds into a separate two-layer MLP head with sigmoid activation for the occupancy branch [S2, unofficial].

### Neural Sparse Voxel Fields
- **Definition:** A method that builds and dynamically updates an octree structure while the MLP is optimized to allow aggressive empty space skipping and early ray termination [S3, unofficial].
- **Step:** Build and dynamically update an octree structure during MLP optimization. Perform aggressive empty space skipping. Perform early ray termination when the transmittance along the ray approaches zero [S3, unofficial].

### PlenOctrees
- **Definition:** A method querying the MLP to produce a sparse voxel octree of volume density and spherical harmonic coefficients, finetuned using a rendering loss [S3, unofficial].
- **Step:** Query the MLP to produce a sparse voxel octree of volume density and spherical harmonic coefficients. Finetune this octree representation using a rendering loss to improve output image quality [S3, unofficial].

## Background
Voxel and grid representations originated as a means to accelerate the rendering of neural radiance fields (NeRFs), which are traditionally slow due to the repeated evaluation of large MLPs [S3, unofficial]. Early works like Neural Sparse Voxel Fields (NSVF) introduced dynamic octree structures to skip empty space [S3, unofficial]. Subsequent methods such as PlenOctrees and KiloNeRF explored caching MLP outputs into sparse grids or dense grids of small MLPs to enable real-time rendering [S3, unofficial]. The introduction of hash-based grid encodings (e.g., Instant-NGP) further optimized memory and computation by using sparse hash tables to store features at multiple resolutions [S2, S3, unofficial]. More recent developments include binary quantization (BiRF) for memory efficiency [S2, unofficial], adaptive octrees for specific domains like cryo-ET [S1], and hybrid Eulerian-Lagrangian approaches for dynamic physics-based scenes [S1]. These methods are widely used in robotics navigation [S2, unofficial], continual learning [S1], and high-fidelity 3D reconstruction [S1][S3, unofficial].
