# Iterative Optimization with Learnable Parameters for Diffusion-Guided Radiance Fields

Also called: Iterative Optimization with Learnable Parameters

## Overview
This method addresses quality impairments in 3D generation caused by the discrepancy between the diffusion prior and the training process of the diffusion model [S1][S2, unofficial]. It sets itself apart from standard diffusion-guided approaches by introducing an iterative optimization loop that jointly updates the 3D model and specific learnable parameters within the diffusion guidance mechanism, rather than treating the diffusion model as a static prior [S1][S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A frozen pre-trained diffusion model (e.g., Stable Diffusion), a 3D radiance field representation (e.g., 3D Gaussian Splatting or NeRF), and a text prompt.
- Output: An optimized 3D radiance field.

**Data Structures:**
- **Learnable Unconditional Embedding ($e_{uncond}$):** A vector parameter replacing or augmenting the standard unconditional embedding in the classifier-free guidance formula.
- **Network Parameters ($\theta_{net}$):** Additional parameters added to the diffusion network, such as Low-Rank Adaptation (LoRA) weights [S1][S2, unofficial].
- **3D Model Parameters ($\theta_{3D}$):** The parameters defining the radiance field (e.g., Gaussian centers, covariances, colors) [S1][S2, unofficial].

**Numbered Steps:**
1. **Initialization:** Initialize the 3D model parameters $\theta_{3D}$, the learnable unconditional embedding $e_{uncond}$, and the additional network parameters $\theta_{net}$ (e.g., LoRA matrices) [S1][S2, unofficial].
2. **Sampling:** Render an image from the current 3D model $\theta_{3D}$ from a random viewpoint [S1][S2, unofficial].
3. **Diffusion Guidance:** Pass the rendered image and the text prompt into the frozen diffusion model. Compute the noise prediction using classifier-free guidance, but substitute the standard unconditional embedding with the learnable $e_{uncond}$ and apply the updated network parameters $\theta_{net}$ [S1][S2, unofficial].
4. **Loss Calculation:** Calculate the Score Distillation Sampling (SDS) or similar loss based on the difference between the predicted noise and the actual noise added to the image [S1][S2, unofficial].
5. **Optimization:** Perform gradient descent to update $\theta_{3D}$, $e_{uncond}$, and $\theta_{net}$ simultaneously [S1][S2, unofficial].
6. **Iteration:** Repeat steps 2-5 until convergence [S1][S2, unofficial].

**Formulas:**
The classifier-free guidance formula is modified to include the learnable parameters. Let $\epsilon_\theta$ be the noise prediction network. The guidance signal typically involves:
$$ \epsilon_{pred} = \epsilon_\theta(z_t, c, t) + w \cdot (\epsilon_\theta(z_t, c, t) - \epsilon_\theta(z_t, u, t)) $$
Where:
- $z_t$ is the noisy latent/image at timestep $t$.
- $c$ is the conditional text embedding.
- $u$ is replaced by the learnable unconditional embedding $e_{uncond}$ [S1][S2, unofficial].
- The network $\epsilon_\theta$ includes the additional parameters $\theta_{net}$ (e.g., LoRA) [S1][S2, unofficial].
- $w$ is the guidance scale.

**Parameters:**

**Pseudocode:**
```python
# Initialize parameters
theta_3D = initialize_3d_model()
e_uncond = initialize_embedding()
theta_net = initialize_lora_parameters()

for iteration in range(num_iterations):
    # 1. Render image from 3D model
    image = render(theta_3D, viewpoint)
    
    # 2. Encode image to latent space (if using latent diffusion)
    z_t = encode(image)
    
    # 3. Add noise for diffusion step
    noise = sample_noise()
    z_noisy = add_noise(z_t, noise, timestep)
    
    # 4. Predict noise using diffusion model with learnable parameters
    # The unconditional embedding is replaced by e_uncond
    # The network uses theta_net (e.g., LoRA)
    epsilon_cond = diffusion_model.predict_noise(z_noisy, text_prompt, timestep, unconditional_embedding=e_uncond, network_params=theta_net)
    
    # 5. Compute SDS Loss
    # Standard SDS formula using epsilon_cond
    loss = compute_sds_loss(epsilon_cond, noise, timestep)
    
    # 6. Backpropagate and update all learnable parameters
    loss.backward()
    optimizer.step(theta_3D, e_uncond, theta_net)
    optimizer.zero_grad()
```

## Background
The method was proposed by Yang et al. [S1][S2, unofficial]. It is part of the broader effort to improve 3D generation quality by aligning the diffusion prior with the 3D model training process [S1][S2, unofficial]. It is applicable to various 3D representations, including 3D Gaussian Splatting (3DGS) and NeRF-based methods [S1][S2, unofficial].
