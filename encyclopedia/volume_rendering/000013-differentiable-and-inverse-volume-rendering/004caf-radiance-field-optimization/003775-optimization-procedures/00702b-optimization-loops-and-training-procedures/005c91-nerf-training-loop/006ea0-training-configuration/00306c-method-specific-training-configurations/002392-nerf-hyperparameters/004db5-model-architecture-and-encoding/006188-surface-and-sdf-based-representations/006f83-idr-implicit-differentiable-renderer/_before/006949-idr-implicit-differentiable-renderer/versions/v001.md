# IDR (Implicit Differentiable Renderer)
Also called: Implicit Differentifferentiable Renderer

## Overview
IDR is a method for learning a neural Signed Distance Function (SDF) and camera parameters simultaneously from uncalibrated images [S2]. It disentangles geometry and appearance by combining a DVR-like implicit surface MLP with a NeRF-like view-dependent branch [S1, unofficial]. Unlike standard NeRF which models volume density, IDR represents geometry as the zero-level set of an MLP and uses a neural renderer to approximate light reflection [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of uncalibrated images (RGB), their approximate camera intrinsics, and initial camera extrinsics.
*   **Outputs:** A trained neural SDF $\phi(\mathbf{x})$, a neural renderer predicting color $\mathbf{c}$, and optimized camera poses.

**Data Structures:**
1.  **SDF Network:** An MLP mapping $\mathbf{x} \in \mathbb{R}^3 \to \mathbb{R}$ (SDF value).
2.  **Color Network:** An MLP mapping encoded features to $\mathbf{c} \in \mathbb{R}^3$.
3.  **Camera Parameters:** Extrinsic matrix $[R|t]$ and intrinsic matrix $K$, treated as trainable variables.

**Method Steps:**
1.  **Ray Casting:** For each pixel, compute the ray $r(\lambda) = o + \lambda d$ using current camera parameters [S1, unofficial].
2.  **SDF Sampling:** Sample points $\mathbf{x}$ along the ray. Query the SDF network to get $\phi(\mathbf{x})$ [S2].
3.  **Surface Intersection:** Identify the zero-crossing of $\phi(\mathbf{x})$ to approximate the surface location. [Note: Specific root-finding or sampling density around the zero-level set is not detailed in the provided sources, but the geometry is defined by $\phi(\mathbf{x})=0$] [S2].
4.  **Feature Extraction:**
    *   Compute the surface normal $\mathbf{n} = \nabla \phi(\mathbf{x}) / \|\nabla \phi(\mathbf{x})\|$ via automatic differentiation of the SDF network [S1, unofficial].
    *   Apply positional encoding $\gamma$ to the position $\mathbf{x}$ and view direction $\mathbf{d}$ [S1, unofficial].
5.  **Color Prediction:** Concatenate the encoded position, view direction $\mathbf{d}$, and normal $\mathbf{n}$. Pass this through the color network to predict RGB color $\mathbf{c}$ [S1, unofficial]. The inclusion of $\mathbf{n}$ helps disentangle geometry from appearance [S1, unofficial].
6.  **Rendering:** Integrate the color along the ray. [Note: The specific integration scheme (e.g., volume rendering approximation or surface shading) is not explicitly defined in the provided text, but it is described as a "neural renderer that approximates the light reflected from surfaces toward the camera" [S2]].
7.  **Optimization:** Minimize the photometric loss between rendered images and input images. Jointly optimize the network weights and the camera extrinsics $[R|t]$ to recover from miscalibration [S1, unofficial][S2].

## Operating characteristics
*   **Strengths:** Disentangles geometry and appearance effectively by using surface normals as input to the color branch [S1, unofficial]. Recovers from small camera miscalibration errors by jointly optimizing poses [S1, unofficial].
*   **Limitations:** Relies on a neural renderer that implicitly models lighting, which may limit explicit material control [S2].
*   **Performance:** Not given in the sources.

## Background
IDR was introduced by Yariv et al. [YKM* 20] as one of the first geometric Implicit Neural Representations (INR) approaches to learn a neural SDF directly from images [S2]. It builds on the concept of differentiable rendering to optimize the SDF and camera parameters simultaneously [S2]. It is cited as influencing many other works in surface representation [S2].
