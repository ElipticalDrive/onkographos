# NeuTex Initialization Training Procedure

Also called: Initialization stage, Pre-training loss

## Overview
The NeuTex Initialization Training Procedure is a pre-training stage that initializes the inverse texture mapping network $F_{uv}^{-1}$ and the texture mapping network $F_{uv}$ using a downsampled point cloud and uniformly sampled UV coordinates on a unit sphere [S1]. It differs from standard volume rendering initialization by explicitly optimizing bi-directional UV-to-3D and 3D-to-UV consistency via Chamfer distance and cycle losses before entering the main optimization loop [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Downsampled ground-truth point cloud $P_{gt}$ from COLMAP (2,000–3,000 points) [S1]. Uniformly sampled UV coordinates $P$ on the unit sphere (2,500 points) [S1]. Ground-truth images and camera parameters required for the main pipeline losses [S1].
*   **Outputs:** Initialized weights for $F_{uv}^{-1}$ and $F_{uv}$ [S1]. Total initialization loss $L_{\text{init}}$ for gradient backpropagation [S1].

**Data Structures:**
*   **Point Cloud $P_{gt}$:** A set of 3D points $\{(x_i, y_i, z_i)\}$ downsampled to 2,000–3,000 points [S1].
*   **UV Sample Set $P$:** A set of 2,500 points uniformly distributed on the unit sphere, representing texture-space coordinates [S1].
*   **Network Architecture:** The networks accept inputs $x$ (3D coordinates), $u$ (texture-space points on the unit sphere), and $d$ (3D unit viewing direction), and output $\sigma$ (predicted volumetric density) and $c$ (predicted radiance) [S1]. $F_{uv}^{-1}$ maps UV inputs to 3D coordinates, while $F_{uv}$ maps 3D coordinates and viewing directions to UV coordinates [S1].

**Numbered Steps:**
1.  Downsample the COLMAP point cloud to 2,000–3,000 points and denote it as $P_{gt}$ [S1].
2.  Uniformly sample 2,500 points on the unit sphere to represent UV coordinates and denote them as $P$ [S1].
3.  Pass $P$ through $F_{uv}^{-1}$ to generate a 3D point cloud, then compute the Chamfer distance between this output and $P_{gt}$ [S1].
4.  Pass the generated 3D points through $F_{uv}$ to reconstruct UV coordinates, then compute the $L_2$ distance between the reconstructed coordinates and the original $P$ [S1].
5.  Apply the rendering loss $L_{\text{render}}$ and mask loss $L_{\text{mask}}$ as defined in the main pipeline [S1].
6.  Combine all components into the total initialization loss $L_{\text{init}}$ [S1].
7.  Perform gradient descent to minimize $L_{\text{init}}$ and update the weights of both networks [S1].

**Formulas:**
The total initialization loss is defined as [S1]:
$$L_{\text{init}} = L_{\text{chamfer}} + aL_{\text{cycle2}} + bL_{\text{render}} + cL_{\text{mask}}$$
Where:
*   $L_{\text{chamfer}}$ is the Chamfer distance between the network-generated point cloud and the ground truth:
    $$L_{\text{chamfer}} = \text{Chamfer}(F_{uv}^{-1}(P), P_{gt})$$
    Here, $F_{uv}^{-1}(P)$ is the point cloud generated by mapping UV coordinates $P$ to 3D space using the inverse network, and $P_{gt}$ is the downsampled ground-truth point cloud [S1].
*   $L_{\text{cycle2}}$ is the inverse cycle consistency loss (2D-to-3D-to-2D):
    $$L_{\text{cycle2}} = \|F_{uv}(F_{uv}^{-1}(P)) - P\|_2^2$$
    Here, $F_{uv}$ is the texture mapping network, $F_{uv}^{-1}$ is the inverse mapping network, and $P$ is the set of original UV coordinates [S1].
*   $L_{\text{render}}$ and $L_{\text{mask}}$ are the rendering and mask losses from the main pipeline [S1].

**Parameters:**
*   $a = 100$: Weight for the inverse cycle loss $L_{\text{cycle2}}$ [S1].
*   $b = 1$: Weight for the rendering loss $L_{\text{render}}$ [S1].
*   $c = 1$: Weight for the mask loss $L_{\text{mask}}$ [S1].
*   Point cloud downsampling target: 2,000–3,000 points [S1].
*   UV sampling count: 2,500 points [S1].

**Pseudocode:**
```python
import math

class Vector3:
    def __init__(self, x, y, z):
        self.x, self.y, self.z = x, y, z
    def __sub__(self, other):
        return Vector3(self.x - other.x, self.y - other.y, self.z - other.z)
    def dot(self, other):
        return self.x * other.x + self.y * other.y + self.z * other.z
    def norm_sq(self):
        return self.dot(self)

INFINITY = float('inf')

def neuTexInitializationTrainingStep(
    P_gt: list,  # Downsampled COLMAP point cloud (2000-3000 points)
    P_uv: list,  # Uniformly sampled UV coordinates on unit sphere (2500 points)
    F_uv_inv,    # Inverse texture mapping network (UV -> 3D)
    F_uv,        # Texture mapping network (3D -> UV)
    a: float = 100.0,
    b: float = 1.0,
    c: float = 1.0
) -> tuple:
    # Step 1: Generate 3D points from UV coordinates using inverse network
    generated_points_3d = []
    for uv in P_uv:
        point_3d = F_uv_inv.forward(uv)
        generated_points_3d.append(point_3d)

    # Step 2: Compute Chamfer Loss
    chamfer_loss = compute_chamfer_distance(generated_points_3d, P_gt)

    # Step 3: Compute Inverse Cycle Loss (2D-to-3D-to-2D)
    reconstructed_uv = []
    for point_3d in generated_points_3d:
        # [G] The source formula L_cycle2 does not specify a viewing direction d.
        # A fixed direction is used here as a standard implementation detail.
        view_dir = Vector3(0.0, 0.0, 1.0)
        uv_recon = F_uv.forward(point_3d, view_dir)
        reconstructed_uv.append(uv_recon)

    cycle_loss = 0.0
    for uv_orig, uv_recon in zip(P_uv, reconstructed_uv):
        diff = uv_orig - uv_recon
        cycle_loss += diff.norm_sq()
    cycle_loss /= len(P_uv)

    # Step 4: Compute Rendering and Mask Losses
    # Sources do not provide the implementation for rendering and mask losses from Sec 4.1 [S1].
    rendering_loss = 0.0
    mask_loss = 0.0

    # Step 5: Combine Losses
    total_loss = chamfer_loss + a * cycle_loss + b * rendering_loss + c * mask_loss

    metrics = {
        "chamfer": chamfer_loss,
        "cycle2": cycle_loss,
        "render": rendering_loss,
        "mask": mask_loss
    }

    return total_loss, metrics

def compute_chamfer_distance(points_a: list, points_b: list) -> float:
    dist_a_to_b = 0.0
    dist_b_to_a = 0.0

    for p_a in points_a:
        min_dist = INFINITY
        for p_b in points_b:
            d = (p_a - p_b).norm_sq()
            if d < min_dist:
                min_dist = d
        dist_a_to_b += math.sqrt(min_dist)

    for p_b in points_b:
        min_dist = INFINITY
        for p_a in points_a:
            d = (p_b - p_a).norm_sq()
            if d < min_dist:
                min_dist = d
        dist_b_to_a += math.sqrt(min_dist)

    return (dist_a_to_b + dist_b_to_a) / (len(points_a) + len(points_b))
```

## Background
The NeuTex Initialization Training Procedure was introduced in the paper "NeuTex: Neural Texture Mapping for Volumetric Neural Rendering" [S1]. The paper was presented at CVPR 2021 [S1]. The method initializes the inverse and forward texture mapping networks to stabilize training within the NeuTex framework [S1]. The paper reports quantitative comparisons on DTU scenes (55, 83, 114, 118, 122) against SRN, DeepVoxels, COLMAP, and NeRF using PSNR and SSIM metrics [S1].
