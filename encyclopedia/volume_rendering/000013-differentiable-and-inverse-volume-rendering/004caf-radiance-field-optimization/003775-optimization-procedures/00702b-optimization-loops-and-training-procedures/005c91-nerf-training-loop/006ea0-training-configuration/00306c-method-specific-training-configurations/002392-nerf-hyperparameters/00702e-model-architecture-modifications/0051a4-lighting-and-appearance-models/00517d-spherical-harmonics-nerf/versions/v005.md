# Spherical Harmonics NeRF

Also called: NeRF with Spherical Harmonics, SH-NeRF

## Overview
Spherical Harmonics NeRF replaces the view-dependent color prediction of a standard NeRF with an explicit 2nd-order Spherical Harmonics (SH) illumination model, enabling explicit relighting by varying learnable SH coefficients [S1]. Unlike standard NeRFs where view dependence is implicit in the neural network's output, this method separates the scene's intrinsic albedo and geometry from the lighting conditions, allowing for direct control over illumination [S1].

## How it works
The method modifies the standard volume rendering pipeline by decoupling the estimation of surface albedo and normals from the shading calculation. Instead of predicting final color directly, the network predicts accumulated albedo and normals, which are then shaded using a fixed SH basis and learnable lighting coefficients [S1].

### Inputs and Outputs
*   **Inputs:**
    *   Ray parameters: $\{\mathbf{x}_i\}_{i=1}^{N_{\mathrm{depth}}}$, the 3D coordinates of $N_{\mathrm{depth}}$ samples along the ray.
    *   Per-image learnable SH coefficients: $\mathbf{L} \in \mathbb{R}^{9 \times 3}$.
*   **Outputs:**
    *   Rendered color: $\mathbf{C} \in \mathbb{R}^3$.

### Data Structures
*   **SH Coefficients ($\mathbf{L}$):** A matrix of size $9 \times 3$. The 9 rows correspond to the 2nd-order SH basis functions (0th and 1st orders, plus 2nd order components), and the 3 columns correspond to the RGB color channels. This matrix is learnable and specific to each image (or light source configuration) [S1].
*   **SH Basis Vector ($\mathbf{b}(\mathbf{n})$):** A fixed vector of size $9 \times 1$, computed from the surface normal $\mathbf{n}$ using standard 2nd-order SH basis functions [S1].
*   **Accumulated Albedo ($\mathbf{A}$):** A vector in $\mathbb{R}^3$, accumulated similarly to standard NeRF color but derived from an albedo MLP [S1].
*   **Surface Normal ($\mathbf{N}$):** A unit vector in $\mathbb{R}^3$, derived from the gradient of the density field [S1].

### Steps
1.  **Compute Unnormalized Normal ($\mathbf{\hat{N}}$):**
    For each ray, iterate through all $N_{\mathrm{depth}}$ samples. For each sample $i$ at position $\mathbf{x}_i$:
    *   Compute the gradient of the density $\sigma(\mathbf{x}_i)$ with respect to the spatial coordinates $\mathbf{x}_i$.
    *   Compute the transmittance $T(t_i)$ and opacity $\alpha(\sigma(\mathbf{x}_i)\delta_i)$, where $\delta_i$ is the distance between samples.
    *   Accumulate the weighted gradient:
        $$
        \mathbf{\hat{N}}\left(\{\mathbf{x}_i\}_{i=1}^{N_{\mathrm{depth}}}\right) = \sum_{i=1}^{N_{\mathrm{depth}}} \left( \frac{\partial}{\partial \mathbf{x}_i} \sigma(\mathbf{x}_i) \right) \odot T(t_i) \alpha(\sigma(\mathbf{x}_i)\delta_i)
        $$
        where $\odot$ denotes elementwise multiplication [S1].

2.  **Normalize Normal ($\mathbf{N}$):**
    Normalize the unnormalized vector $\mathbf{\hat{N}}$ to obtain the unit surface normal $\mathbf{N}$:
    $$
    \mathbf{N}\left(\{\mathbf{x}_i\}_{i=1}^{N_{\mathrm{depth}}}\right) = \frac{\mathbf{\hat{N}}\left(\{\mathbf{x}_i\}_{i=1}^{N_{\mathrm{depth}}}\right)}{\left\| \mathbf{\hat{N}}\left(\{\mathbf{x}_i\}_{i=1}^{N_{\mathrm{depth}}}\right) \right\|^2}
    $$
    Note: The source uses the squared norm in the denominator for normalization [S1].

3.  **Compute SH Basis ($\mathbf{b}$):**
    Evaluate the 2nd-order Spherical Harmonics basis functions at the computed normal $\mathbf{N}$ to produce $\mathbf{b}(\mathbf{N}) \in \mathbb{R}^9$ [S1].

4.  **Accumulate Albedo ($\mathbf{A}$):**
    Compute the accumulated albedo $\mathbf{A} \in \mathbb{R}^3$ by integrating the output of an albedo MLP along the ray, using the same transmittance and opacity weights as standard volume rendering [S1].

5.  **Render Color ($\mathbf{C}$):**
    Combine the accumulated albedo, the SH coefficients, and the SH basis to compute the final color:
    $$
    \mathbf{C}\left(\{\mathbf{x}_i\}_{i=1}^{N_{\mathrm{depth}}}, \mathbf{L}\right) = \mathbf{A}\left(\{\mathbf{x}_i\}_{i=1}^{N_{\mathrm{depth}}}\right) \odot \mathbf{L} \mathbf{b}\left(\mathbf{N}\left(\{\mathbf{x}_i\}_{i=1}^{N_{\mathrm{depth}}}\right)\right)
    $$
    Here, $\mathbf{L} \mathbf{b}(\mathbf{N})$ results in a 3D vector (RGB), which is elementwise multiplied with $\mathbf{A}$ [S1].

### Pseudocode
```python
def render_sh_nerf(ray_samples, density_mlp, albedo_mlp, L_matrix):
    """
    Renders a single ray using Spherical Harmonics NeRF.
    
    Args:
        ray_samples: List of 3D points [x, y, z] along the ray, length N_depth.
        density_mlp: Function returning density sigma for a given point.
        albedo_mlp: Function returning albedo color for a given point.
        L_matrix: Learnable SH coefficients, shape (9, 3).
        
    Returns:
        C: Rendered color, shape (3,).
    """
    N_depth = len(ray_samples)
    accumulated_albedo = np.zeros(3)
    unnormalized_normal = np.zeros(3)
    
    # Precompute transmittance and opacity weights
    # Note: Standard NeRF transmittance T(t_i) = exp(-sum_{j=0}^{i-1} sigma_j * delta_j)
    # This requires access to sigma values of previous samples.
    # Assuming standard volume rendering accumulation logic is available.
    
    for i in range(N_depth):
        x_i = ray_samples[i]
        
        # 1. Get density and its gradient
        sigma_i = density_mlp(x_i)
        # Gradient of density w.r.t spatial coordinates
        grad_sigma = compute_gradient_density(density_mlp, x_i)
        
        # 2. Compute weights for accumulation
        # delta_i is distance to next sample (or half distance if at end)
        delta_i = compute_delta(ray_samples, i)
        alpha_i = 1.0 - np.exp(-sigma_i * delta_i)
        
        # Transmittance T(t_i) is product of (1 - alpha_j) for j < i
        # This is typically computed in a forward pass or maintained in a loop
        T_i = compute_transmittance(ray_samples, i, density_mlp)
        
        weight = T_i * alpha_i
        
        # 3. Accumulate Albedo
        albedo_i = albedo_mlp(x_i)
        accumulated_albedo += weight * albedo_i
        
        # 4. Accumulate Unnormalized Normal
        # Weighted gradient of density
        unnormalized_normal += weight * grad_sigma
        
    # 5. Normalize Normal
    # Source formula: N = N_hat / ||N_hat||^2
    norm_sq = np.dot(unnormalized_normal, unnormalized_normal)
    if norm_sq == 0:
        normal = np.array([0.0, 0.0, 1.0]) # Default normal if no density gradient
    else:
        normal = unnormalized_normal / norm_sq
        
    # 6. Compute SH Basis
    sh_basis = compute_sh_basis_2nd_order(normal) # Returns vector of size 9
    
    # 7. Compute Lighting Term
    # L is (9, 3), sh_basis is (9,)
    # Result is (3,)
    lighting = np.dot(L_matrix.T, sh_basis) # Equivalent to L @ sh_basis if shapes align correctly for matrix mult
    
    # 8. Final Color
    C = accumulated_albedo * lighting
    
    return C
```

### Parameters
*   **Order of SH:** 2nd-order, resulting in 9 basis functions [S1].
*   **SH Coefficients ($\mathbf{L}$):** Per-image learnable parameters, size $9 \times 3$ [S1].

### Edge Cases and Pitfalls
*   **Shadow Generation:** The basic SH-NeRF model lacks direct shadow generation, which is a significant limitation for outdoor scenes where shadows are crucial for realism and relighting [S1]. Extensions using a dedicated shadow control network $S$ are proposed to address this [S1].
*   **Normal Estimation:** The normal is derived from the density gradient. If the density field is noisy or poorly trained, the normals may be inaccurate, leading to incorrect shading [S1]. The accumulation of albedo and normals aids convergence and reduces noise [S1].
*   **Normalization:** The source specifies normalization by the squared norm $\|\mathbf{\hat{N}}\|^2$. This is unusual compared to standard unit normalization ($\|\mathbf{\hat{N}}\|$). Implementers must follow the source formula exactly [S1].

## Operating characteristics
*   **Relighting Capability:** The primary advantage is the ability to relight scenes by simply changing the learnable coefficients $\mathbf{L}$, without retraining the neural network [S1].
*   **Lighting Model:** It accounts for Lambertian effects but does not model complex view-dependent reflections or shadows natively [S1].
*   **Performance:** The shading calculation is performed once per ray (screen space), rather than per sample, which is more efficient than per-sample shading [S1].
*   **Limitations:** Not suitable for scenes requiring accurate shadow modeling without additional shadow networks [S1].

## Background
*   **Origin:** The method was introduced in "NeRF for Outdoor Scene Relighting" by V. Rudnev et al. [S1].
*   **Motivation:** Standard NeRF representations lack semantic meaning of scene intrinsics and do not allow direct control over lighting [S1]. This method introduces an explicit SH illumination model to enable relighting [S1].
*   **Development:** The approach builds on the standard NeRF volume rendering pipeline but modifies the output layer to separate albedo and lighting [S1]. A shadow generation network was later introduced as an extension to handle outdoor scenes [S1].
