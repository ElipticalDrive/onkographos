# Dynamic Appearance Particle Neural Radiance Field

Also called: Dynamic Appearance Particle NeRF, Lagrangian dynamic model in NeRF

## Overview
Dynamic Appearance Particle Neural Radiance Field (DAP-NeRF) is a method for novel view synthesis from monocular video that models scene dynamics using a Lagrangian particle-based representation [S1]. It solves the problem of reconstructing dynamic scenes without prior geometric knowledge or multi-view stereo data, which are requirements for related methods like ParticleNeRF [S1]. Unlike ParticleNeRF, which encodes the entire scene with particles and requires 20 camera views per frame, DAP-NeRF applies appearance particles only to dynamic elements while maintaining a static grid-based field for the background, enabling efficient linear interpolation and handling single-camera input [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Monocular video data (one camera view per time frame $t$).
*   **Output:** Rendered pixel color $C(\mathbf{r}, t)$ for a given ray $\mathbf{r}$ and time $t$.

**Data Structures:**
The method uses two distinct feature fields superimposed to form the total radiance field $V(\mathbf{x}, t)$:
1.  **Static Field $V_s(\mathbf{x})$:** A time-independent grid-based model (canonical feature field) [S1].
2.  **Dynamic Field $V_{td}(\mathbf{x})$:** A particle-based representation where dynamics are encoded in individual particle models [S1].

**Notation:**
*   $\mathbf{x} \in \mathbb{R}^3$: Spatial position.
*   $\mathbf{d} \in \mathbb{R}^3$: Viewing direction.
*   $t \in \mathbb{R}$: Time parameter.
*   $V(\mathbf{x}, t)$: Total feature field.
*   $V_s(\mathbf{x})$: Static component.
*   $V_{td}(\mathbf{x})$: Dynamic component.
*   $w_t(\mathbf{x})$: Weight function.
*   $\delta(\cdot)$: Dirac delta function.
*   $W(\cdot)$: Finite support kernel.

**Formulas:**
The total field is a superposition of static and dynamic components [S1]:
$$ V(\mathbf{x}, t) = (1 - w_t(\mathbf{x}))V_s(\mathbf{x}) + w_t(\mathbf{x})V_{td}(\mathbf{x}) $$
where $w_t(\mathbf{x})$ takes the value 1 if the dynamic field is effective at $(\mathbf{x}, t)$ and 0 otherwise [S1]. The support of the dynamic field is implied by the particle representation [S1].

The dynamic field $V_{td}$ is formulated as a convolution with a Dirac function to integrate over finite volumes [S1]:
$$ V_{td}(\mathbf{x}) = (V_{td} * \delta)(\mathbf{x}) = \int V_{td}(\mathbf{x}')\delta(\mathbf{x} - \mathbf{x}')d\nu(\mathbf{x}') $$
where $\delta(\mathbf{r}) = 0$ for $\mathbf{r} \neq 0$ and $\int \delta(\mathbf{r})d\nu = 1$ [S1].

To quantize the field, the Dirac function $\delta$ is replaced by a kernel $W$ with finite support [S1]:
$$ W(\mathbf{x}) = 0 \quad \text{when } \|\mathbf{x}\| \text{ exceeds a small radius} $$
$$ \int W(\mathbf{x})d\nu(\mathbf{x}) = 1 $$

Rendering computes the pixel color $C(\mathbf{r}, t)$ by casting a ray $\mathbf{r}(s) = \mathbf{o} + s\mathbf{d}$ from camera center $\mathbf{o}$ [S1]:
$$ C(\mathbf{r}, t) = \int_{s_n}^{s_f} T(s)\sigma(\mathbf{r}(s), t)c(\mathbf{r}(s), \mathbf{d}, t)ds $$
where $s_n, s_f$ are near and far bounds, $T(s) = \exp\left(-\int_{s_n}^s \sigma(\mathbf{r}(s'), t)ds'\right)$ is accumulated transmittance, $\sigma$ is volume density, and $c$ is emitted radiance [S1].

**Steps:**
1.  **Initialize Fields:** Construct the static grid-based field $V_s(\mathbf{x})$ and initialize the particle-based dynamic field $V_{td}(\mathbf{x})$ [S1].
2.  **Define Kernel:** Replace the Dirac delta $\delta$ with a finite-support kernel $W$ for quantization [S1].
3.  **Compute Superposition:** For a query point $\mathbf{x}$ and time $t$, calculate the weight $w_t(\mathbf{x})$ based on particle effectiveness [S1]. Compute $V(\mathbf{x}, t)$ using the superposition formula [S1].
4.  **Render:** Cast rays from the camera. For each ray, sample points, query $V(\mathbf{x}, t)$, decode density $\sigma$ and color $c$, and integrate using volume rendering [S1].

**Pseudocode:**
```python
def render_ray(ray_origin, ray_direction, time_t, static_grid, particles, kernel_width):
    """
    Renders a single pixel for a given ray and time using DAP-NeRF.
    
    Args:
        ray_origin: 3D vector, camera center o.
        ray_direction: 3D vector, viewing direction d.
        time_t: float, current time t.
        static_grid: Grid structure for V_s(x).
        particles: List of dynamic particles, each with position, velocity, and appearance features.
        kernel_width: float, radius for kernel W.
        
    Returns:
        color: 3D vector, rendered pixel color C(r, t).
    """
    # Standard volume rendering setup
    num_samples = 128
    near_bound = 0.0
    far_bound = 10.0
    step_size = (far_bound - near_bound) / num_samples
    
    accumulated_transmittance = 1.0
    accumulated_color = [0.0, 0.0, 0.0]
    
    for s in range(num_samples):
        # Sample point along ray
        distance = near_bound + s * step_size
        point_x = ray_origin + distance * ray_direction
        
        # 1. Query Static Field
        # V_s(x) is retrieved from the grid via linear interpolation
        v_s = static_grid.query(point_x)
        
        # 2. Query Dynamic Field
        # V_td(x) is computed by aggregating contributions from nearby particles
        # using the finite support kernel W
        v_td = [0.0, 0.0, 0.0]
        weight_active = 0.0
        
        for particle in particles:
            # Calculate distance from particle to query point
            dist = norm(particle.position - point_x)
            
            # Check if particle is within kernel support
            if dist <= kernel_width:
                # Compute kernel weight W(dist)
                # W(x) = 0 when ||x|| exceeds radius, integral is 1
                # Implementation depends on specific kernel shape (e.g., Gaussian, Box)
                kernel_val = compute_kernel(dist, kernel_width)
                
                # Get particle appearance features
                p_features = particle.get_features(time_t)
                
                # Accumulate dynamic field contribution
                v_td += p_features * kernel_val
                weight_active += kernel_val
        
        # Normalize dynamic field if needed, or use raw aggregation
        # Note: The source defines V_td as convolution, implying aggregation
        # The weight w_t(x) is 1 if dynamic field is effective, 0 otherwise.
        # Effectiveness is implied by particle representation.
        # If weight_active > 0, dynamic field is effective.
        w_t = 1.0 if weight_active > 1e-6 else 0.0
        
        # 3. Superposition
        # V(x, t) = (1 - w_t(x)) * V_s(x) + w_t(x) * V_td(x)
        v_total = (1.0 - w_t) * v_s + w_t * v_td
        
        # 4. Decode Density and Color
        # MLPs or decoders map v_total to sigma and c
        sigma = decode_density(v_total)
        color = decode_color(v_total)
        
        # 5. Volume Rendering Integration
        # T(s) = exp(-int sigma ds)
        # Contribution = T(s) * (1 - exp(-sigma * step_size)) * color
        alpha = 1.0 - exp(-sigma * step_size)
        contribution = accumulated_transmittance * alpha * color
        
        accumulated_color += contribution
        accumulated_transmittance *= (1.0 - alpha)
        
        if accumulated_transmittance < 1e-4:
            break
            
    return accumulated_color
```

**Parameters:**
*   **Kernel Width:** Radius for $W(\mathbf{x})$. Not given in the sources.
*   **Weight $w_t(\mathbf{x})$:** Binary (0 or 1). 1 if dynamic field is effective at $(\mathbf{x}, t)$, 0 otherwise [S1].

**Edge Cases and Pitfalls:**
*   **Precision:** The transition between static and dynamic fields relies on $w_t(\mathbf{x})$. Discontinuities may occur if the particle support boundaries are sharp.
*   **Boundaries:** The kernel $W$ must integrate to 1. Improper normalization leads to incorrect radiance values [S1].
*   **Degenerate Input:** The method is designed for monocular video. Multi-view data is not required but may not be utilized optimally if the architecture assumes single-view dynamics [S1].
