# CodeNeRF

Also called: Disentangled Neural Radiance Fields for Object Categories

## Overview
CodeNeRF is an implicit 3D neural representation that learns the variation of object shapes and textures across a semantic category, enabling the synthesis of novel views of unseen objects from a single unposed input image [S1]. Unlike standard NeRF which is scene-specific, CodeNeRF disentangles shape and texture by learning separate latent embeddings, allowing for joint optimization of camera viewpoint and latent codes at test time [S1]. It differs from sibling methods like [DoF-NeRF](9432-dof-nerf.md) and [NeRF-VPT](11770-nerf-vpt.md) by explicitly decoupling the geometry and appearance priors into distinct embedding spaces, whereas [Signed Distance Function (SDF) Representations](12495-signed-distance-function-sdf-representations.md) rely on distance fields rather than volumetric density [S1].

## How it works
**Inputs and Outputs:**
*   **Training Input:** A set of $N$ images $\mathcal{V} = \{I_i, K_i, T_i\}_{i=1}^N$ depicting $M$ objects with known camera poses (intrinsic $K_i$ and extrinsic $T_i$).
*   **Inference Input:** A single unposed reference image $I_{test}$ of an unseen object.
*   **Outputs:** Rendered novel views, estimated camera pose (inference), and disentangled shape/texture codes.

**Data Structures:**
1.  **Network Weights $\Theta$:** Parameters for two MLPs, $\text{F}^s_{\Theta_s}$ and $\text{F}^t_{\Theta_t}$.
2.  **Latent Embeddings:**
    *   Shape code $\mathbf{z_s} \in \mathbb{R}^{d_s}$
    *   Texture code $\mathbf{z_t} \in \mathbb{R}^{d_t}$
    *   During training, a set $\{\mathbf{z_s}_j, \mathbf{z_t}_j\}_{j=1}^M$ is optimized for each object.
3.  **Camera Parameters:** Azimuth $\phi$, elevation $\theta$, and distance $\rho$.

**Positional Encoding:**
Positional encoding $\gamma(\cdot)$ is applied to 3D coordinates $\mathbf{x}$ and viewing directions $\mathbf{d}$ [S1].
*   Frequencies for $\mathbf{x}$: 10.
*   Frequencies for $\mathbf{d}$: 4 [S1].

**Network Architecture:**
The model uses an auto-decoder architecture with decoupled embedding spaces [S1].
1.  **Shape Network $\text{F}^s_{\Theta_s}$:** Maps $(\gamma_{\mathbf{x}}(\mathbf{x}), \mathbf{z_s})$ to volume density $\sigma$ and an intermediate feature vector $\mathbf{v} \in \mathbb{R}^{256}$ [S1].
    $$ \text{F}^s_{\Theta_s} : (\gamma_{\mathbf{x}}(\mathbf{x}), \mathbf{z_s}) \xrightarrow{} (\sigma, \mathbf{v}) $$
2.  **Texture Network $\text{F}^t_{\Theta_t}$:** Maps $(\mathbf{v}, \gamma_{\mathbf{d}}(\mathbf{d}), \mathbf{z_t})$ to RGB color $\mathbf{c}$ [S1].
    $$ \text{F}^t_{\Theta_t} : (\mathbf{v}, \gamma_{\mathbf{d}}(\mathbf{d}), \mathbf{z_t}) \xrightarrow{} (\mathbf{c}) $$
3.  **Combined Field:** $\text{F}_\Theta = \text{F}^t_{\Theta_t} \circ \text{F}^s_{\Theta_s}$ [S1].

**Volume Rendering:**
For a camera ray $\mathbf{r}(t) = \mathbf{c} + t\mathbf{d}$, $N$ uniform samples are taken from near to far bounds [S1]. The estimated pixel color $\hat{C}(\mathbf{r})$ is:
$$ \hat{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i $$
where $\delta_i = t_{i+1} - t_i$ and $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ [S1].

**Training Procedure:**
1.  Sample a batch of 4094 rays per image using intrinsic and extrinsic parameters [S1].
2.  Sample 64 points along each ray [S1].
3.  Feed points to $\text{F}_\Theta$ with current $\mathbf{z_s}$ and $\mathbf{z_t}$ estimates to obtain $\sigma$ and $\mathbf{c}$ [S1].
4.  Compute loss $\mathcal{L}$:
    $$ \mathcal{L}(\Theta, \{\mathbf{z_s}^i, \mathbf{z_t}^i\}^M) = \sum_{\mathbf{r} \in \mathcal{R}} ||\hat{C}(\mathbf{r}) - C(\mathbf{r})||_2^2 + \frac{1}{\nu^2} \sum_{i=1}^M (||\mathbf{z_s}^i||_2^2 + ||\mathbf{z_t}^i||_2^2) $$
    where the first term is photometric L2 loss and the second is $L_2$ regularization on latent vectors [S1].
5.  Optimize $\Theta$, $\{\mathbf{z_s}^i\}$, and $\{\mathbf{z_t}^i\}$ using AdamW [S1].

**Inference Procedure:**
Given a single unposed image $I_{test}$:
1.  Initialize $\mathbf{z_s}$ and $\mathbf{z_t}$ with the mean vector of trained embeddings [S1].
2.  Initialize camera parameters $(\phi, \theta, \rho)$ with random or coarse estimates [S1].
3.  Fix network weights $\Theta$ [S1].
4.  Minimize photometric loss jointly with respect to $\mathbf{z_s}, \mathbf{z_t}$ and camera parameters $(\phi, \theta, \rho)$ [S1]:
    $$ \min_{\mathbf{z_s}, \mathbf{z_t}, \phi, \theta, \rho} \mathcal{L}(\mathbf{z_s}, \mathbf{z_t}, \phi, \theta, \rho) + \frac{1}{\nu^2} (||\mathbf{z_s}||_2^2 + ||\mathbf{z_t}||_2^2) $$
5.  Run optimization for 299 iterations [S1].

class PositionalEncoding(nn.Module):
    def __init__(self, num_freq):
        super().__init__()
        self.num_freq = num_freq
        
    def forward(self, x):
        # x: (..., 3)
        # Freqs: 2^0, 2^1, ..., 2^(num_freq-1)
        freqs = 2.0 ** torch.linspace(0, self.num_freq - 1, self.num_freq).to(x.device)
        # x_scales = x.unsqueeze(-1) * freqs.unsqueeze(0) # (..., 3, num_freq)
        # sin and cos
        # concat sin and cos
        # Standard NeRF PE
        x_expanded = x.unsqueeze(-1) * freqs.unsqueeze(0) # (..., 3, num_freq)
        x_sin = torch.sin(x_expanded)
        x_cos = torch.cos(x_expanded)
        out = torch.cat([x_sin, x_cos], dim=-1) # (..., 3, 2*num_freq)
        out = out.reshape(*x.shape[:-1], -1) # (..., 6*num_freq)
        return out

def get_rays_from_pose(phi, theta, rho, batch_size):
    """
    Simplified ray generation from spherical coordinates.
    """
    # [G] This is a placeholder for the specific camera projection used in CodeNeRF.
    # The paper uses intrinsic/extrinsic matrices.
    # Here we assume a simple look-at at origin.
    d = torch.stack([
        torch.sin(theta) * torch.cos(phi),
        torch.sin(theta) * torch.sin(phi),
        torch.cos(theta)
    ], dim=-1)
    o = -rho * d
    # Expand to batch
    d = d.unsqueeze(0).expand(batch_size, -1)
    o = o.unsqueeze(0).expand(batch_size, -1)
    return o, d

## Operating characteristics
*   **Time Complexity:** Training requires joint optimization of network weights and latent codes for all objects in the batch. Inference requires iterative optimization (299 iterations) per unseen object [S1].
*   **Memory Complexity:** Stores network weights $\Theta$ and $M$ pairs of latent vectors $\{\mathbf{z_s}, \mathbf{z_t}\}$ [S1].
*   **Performance:** On the ShapeNet-SRN benchmark, CodeNeRF achieves competitive PSNR and SSIM scores for novel view synthesis and few-shot reconstruction compared to methods like SRN and PixelNeRF [S1].
*   **Camera Pose Estimation:** The method converges to the correct camera pose in 85% of cases, even when initializations have rotation errors averaging 80 degrees [S1].
*   **Strengths:** Disentangles shape and texture, allowing independent editing; works with unposed input images; generalizes across object categories [S1].
*   **Limitations:** Requires iterative optimization at inference time; sensitive to initialization if disentanglement is not properly enforced (e.g., M1/M2 variants fail) [S1].

## Background
CodeNeRF was introduced in 2021 by [S1]. It builds on the original NeRF [S1] and SRN [S1] architectures. It addresses the limitation of NeRF being scene-specific by learning a prior over object categories. It is distinct from DeepSDF [S1] by not requiring 3D supervision and from SRN [S1] by decoupling shape and texture embeddings.
