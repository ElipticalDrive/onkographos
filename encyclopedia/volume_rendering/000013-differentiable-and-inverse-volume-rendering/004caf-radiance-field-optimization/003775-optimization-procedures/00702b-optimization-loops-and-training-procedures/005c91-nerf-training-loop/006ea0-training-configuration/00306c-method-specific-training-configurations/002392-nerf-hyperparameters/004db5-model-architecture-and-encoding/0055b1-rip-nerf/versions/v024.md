# Rip-NeRF

Also called: Rip-NeRF25k

## Overview
Rip-NeRF is a radiance field method that renders high-fidelity anti-aliased images by combining cone casting with an anisotropic 3D Gaussian characterization [S1]. It utilizes Platonic Solid Projection and Ripmap Encoding to enable efficient anisotropic area-sampling of 3D space, distinguishing itself from sibling methods like Zip-NeRF by replacing inefficient multi-sampling with compact, learnable feature grids [S1].

## How it works
**Inputs:** A set of calibrated multi-view 2D images.
**Outputs:** Rendered pixel colors $\hat{C}(\mathbf{r})$ for viewing rays $\mathbf{r}$.

**Data Structures:**
1.  **Ripmap Encoding:** A hierarchical feature grid. The base level $R_{0,0}$ is a learnable tensor of shape $H \times W \times C$. Higher levels are derived from the base level using averaging operations, ensuring consistency and compactness [S1].
    *   Base level dimensions: $H=512, W=512, C=16$ [S1].
2.  **Platonic Solid:** A geometric proxy for area sampling. The default is an icosahedron with 10 unparalleled faces [S1].
3.  **Occupancy Grid:** A binary grid used to skip samples in empty space, implemented via the NerfAcc library [S1].
4.  **Gaussian Parameters:** Each conical frustum is characterized by a mean $\boldsymbol{\mu}$ and covariance $\boldsymbol{\Sigma}$ [S1].

**Numbered Steps:**

1.  **Cone Casting and Frustum Division:** For each pixel, cast a cone and divide it into multiple conical frustums [S1]. This avoids discrete point-based sampling of continuous signals [S1].
2.  **Gaussian Characterization:** Characterize each conical frustum as an anisotropic 3D Gaussian parameterized by mean $\boldsymbol{\mu}$ and covariance $\boldsymbol{\Sigma}$ [S1].
3.  **Platonic Solid Projection:** Project the 3D Gaussian onto the $n$ faces $\{P_i | i = 1, \dots, n\}$ of the Platonic solid to form 2D Gaussians [S1].
    *   For each face $P_i$, compute the projected mean $\boldsymbol{\mu}_{proj}^i$ and covariance $\boldsymbol{\Sigma}_{proj}^i$ using a projection matrix $M_i \in \mathbb{R}^{3 \times 2}$ that maps the 3D world coordinate system to the 2D coordinate system of plane $P_i$ [S1].
4.  **Ripmap Querying:** Query a feature vector $\mathbf{f}_i$ from the Ripmap Encoding of each plane $P_i$ [S1].
    *   The position $(p_x, p_y)$ and level $(l_x, l_y)$ for interpolation are determined by $\boldsymbol{\mu}_{proj}^i$ and $\boldsymbol{\Sigma}_{proj}^i$ respectively [S1].
    *   Perform tetra-linear interpolation on the Ripmap Encoding to obtain $\mathbf{f}_i$ [S1].
    *   The interpolation uses a hyper-parameter $w=2.0$ to adjust the probability mass coverage of the Gaussian footprint [S1].
5.  **Feature Aggregation:** Concatenate all feature vectors $\{\mathbf{f}_i | i = 1, \dots, n\}$ from the Platonic solid faces and the encoded view direction $\mathbf{d}$ to form the final feature vector $\mathbf{f}$ [S1].
6.  **MLP Decoding:** Pass the aggregated feature vector $\mathbf{f}$ through a tiny MLP $F_\theta$ to estimate color $\mathbf{c}$ and density $\sigma$ for the frustum [S1].
7.  **Volume Rendering:** Render the pixel color using the standard volume rendering equation:
    $$ \hat{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i $$
    where $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$, $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$, and $\delta_i$ is the distance between samples [S1].
8.  **Optimization:** Optimize the system end-to-end using a photometric loss between rendered and observed images [S1].
    *   **Area Loss:** Scale the photometric loss for each pixel by the area of its footprint on the image plane, denoted as $L_{area}$ [S1]. This makes the loss area-aware [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class RipNeRF:
    def __init__(self, num_faces=10, ripmap_h=512, ripmap_w=512, ripmap_c=16, w=2.0):
        """
        Initialize Rip-NeRF.
        :param num_faces: Number of faces on the Platonic solid (default 10 for icosahedron).
        :param ripmap_h, ripmap_w, ripmap_c: Dimensions of the base Ripmap level.
        :param w: Hyper-parameter for Gaussian footprint coverage.
        """
        self.num_faces = num_faces
        self.w = w
        
        # Base level Ripmap Encoding is learnable; higher levels are derived
        self.base_ripmag = nn.Parameter(torch.randn(1, ripmap_c, ripmap_h, ripmap_w))
        
        # Tiny MLP for color and density prediction
        # Input dim: num_faces * ripmap_c + view_dir_dim
        # Output dim: 4 (3 for color, 1 for density)
        self.mlp = nn.Sequential(
            nn.Linear(num_faces * ripmap_c + 3, 64),
            nn.ReLU(),
            nn.Linear(64, 4)
        )
        
        # Projection matrices for Platonic solid faces (pre-computed or learned)
        # M_i maps 3D world to 2D plane i
        self.projection_matrices = self._init_projection_matrices()

    def _init_projection_matrices(self):
        # Placeholder for actual icosahedron face projection matrices
        # Returns list of tensors M_i of shape (3, 2)
        return [torch.eye(3, 2) for _ in range(self.num_faces)]

    def _get_ripmag_level(self, level_idx):
        """
        Derive Ripmap levels from the base level using averaging.
        Eq. 1 from [S1]:
        R_{i,j} = Avg2x1(R_{i, j-1}) if j != 0
        R_{i,j} = Avg1x2(R_{i-1, j}) if i != 0 & j == 0
        R_{i,j} = 0 otherwise
        """
        if level_idx == 0:
            return self.base_ripmag
        
        # Simplified derivation: In practice, this is done via CUDA kernels
        # or pre-computed downsampling. Here we simulate the hierarchy.
        # Note: The source states only base level is learnable.
        # We assume a simple average pooling for demonstration of the structure.
        current = self.base_ripmag
        for _ in range(level_idx):
            # Average pooling to reduce resolution
            current = F.avg_pool2d(current.squeeze(0), kernel_size=2, stride=2).unsqueeze(0)
        return current

    def query_ripmag(self, position, level, ripmap_level_tensor):
        """
        Tetra-linear interpolation on Ripmap Encoding.
        :param position: (px, py) in 2D plane coordinates.
        :param level: (lx, ly) determining the resolution/level.
        :param ripmap_level_tensor: The feature grid for the specific level.
        :return: Feature vector f_i.
        """
        # Normalize position to [-1, 1] for grid_sample
        # This is a simplified representation of the interpolation logic
        # The exact mapping from Gaussian stats to (px, py, lx, ly) is defined in Eq 2/3 of [S1]
        
        # Assuming position is normalized and level determines the grid size
        # In implementation, this uses custom CUDA kernels [S1]
        
        # Placeholder for actual interpolation logic
        # grid_sample expects normalized coordinates [-1, 1]
        pos_grid = position.unsqueeze(0).unsqueeze(0).unsqueeze(0) # (1, 1, 1, 2)
        
        # Sample from the ripmap level tensor
        # Note: Standard grid_sample is bilinear. Tetra-linear implies interpolation 
        # across levels as well, but since we select a specific level tensor here,
        # we perform bilinear interpolation on that level.
        features = F.grid_sample(ripmag_level_tensor, pos_grid, mode='bilinear', align_corners=True)
        return features.squeeze()

    def forward(self, rays, gaussian_params):
        """
        Forward pass for a batch of rays.
        :param rays: Ray origins and directions.
        :param gaussian_params: Mean (mu) and Covariance (Sigma) for each frustum.
        :return: Rendered colors.
        """
        # 1. Cast cone and divide into frustums (handled by caller or ray sampler)
        # 2. Characterize frustums as 3D Gaussians (mu, Sigma)
        
        all_features = []
        
        # 3. Project 3D Gaussian to 2D Gaussians on Platonic Solid faces
        for i in range(self.num_faces):
            M_i = self.projection_matrices[i]
            
            # Project mean and covariance
            # mu_proj = M_i^T * mu (simplified, actual projection involves Jacobian for Sigma)
            # Sigma_proj = M_i^T * Sigma * M_i
            mu_proj = torch.matmul(M_i.T, gaussian_params['mu'])
            Sigma_proj = torch.matmul(torch.matmul(M_i.T, gaussian_params['Sigma']), M_i)
            
            # 4. Determine position and level for Ripmap query
            # Position (px, py) from mu_proj
            # Level (lx, ly) from Sigma_proj and hyper-parameter w
            # Eq 3 in [S1] uses w=2.0 to adjust probability mass coverage
            px, py = mu_proj[0], mu_proj[1]
            lx, ly = self._compute_level_from_covariance(Sigma_proj, self.w)
            
            # Get the specific Ripmap level tensor
            ripmap_level = self._get_ripmag_level((lx, ly))
            
            # Query feature vector f_i
            f_i = self.query_ripmag(torch.tensor([px, py]), (lx, ly), ripmap_level)
            all_features.append(f_i)
            
        # 5. Aggregate features
        # Concatenate f_i from all faces and encoded view direction d
        view_dir_encoded = self._encode_view_direction(rays['direction'])
        final_feature = torch.cat(all_features + [view_dir_encoded], dim=-1)
        
        # 6. MLP Decoding
        output = self.mlp(final_feature)
        color = output[..., :3]
        density = output[..., 3:]
        
        # 7. Volume Rendering
        # This is typically handled by a differentiable renderer (e.g., NerfAcc)
        # which accumulates color and alpha along the ray
        return color, density

    def _compute_level_from_covariance(self, sigma_proj, w):
        """
        Compute interpolation levels (lx, ly) from projected covariance.
        Uses hyper-parameter w to adjust probability mass coverage.
        """
        # Simplified logic: levels are derived from the scale of the covariance
        # In practice, this maps the Gaussian extent to the Ripmap resolution hierarchy
        # lx = floor(log2(scale_x / w))
        # ly = floor(log2(scale_y / w))
        # This is a placeholder for the exact formula in Eq 3 of [S1]
        scale_x = torch.sqrt(sigma_proj[0, 0])
        scale_y = torch.sqrt(sigma_proj[1, 1])
        lx = int(torch.clamp(torch.log2(scale_x / self.w), min=0))
        ly = int(torch.clamp(torch.log2(scale_y / self.w), min=0))
        return (lx, ly)

    def _encode_view_direction(self, direction):
        # Placeholder for view direction encoding (e.g., positional encoding)
        return direction

    def compute_loss(self, rendered_color, target_color, footprint_area):
        """
        Compute area-aware photometric loss.
        L_area = sum( footprint_area * (rendered_color - target_color)^2 )
        """
        mse = (rendered_color - target_color) ** 2
        loss = torch.sum(mse * footprint_area)
        return loss
```

**Parameters:**
*   **Ripmap Base Level:** $H=512, W=512, C=16$ [S1].
*   **Platonic Solid:** Icosahedron (10 faces) [S1].
*   **Hyper-parameter $w$:** 2.0 [S1].
*   **Optimizer:** AdamW [S1].
*   **Iterations:** 120k (standard Rip-NeRF) or 25k (Rip-NeRF25k variant) [S1].
*   **Weight Decay:** $1 \times 10^{-5}$ [S1].
*   **Initial Learning Rate:** $2 \times 10^{-3}$, modulated by MultiStepLR [S1].
*   **Ripmap Learning Rate:** Scaled up by 10.0 times relative to the base learning rate [S1].

**Edge Cases and Pitfalls:**
*   **Empty Space:** Use a binary occupancy grid (via NerfAcc) to skip samples in empty areas, improving efficiency [S1].
*   **Precision:** The Ripmap levels are derived from the base level via averaging, ensuring consistency but potentially limiting high-frequency detail if the base level is too coarse [S1].
*   **Footprint Coverage:** The hyper-parameter $w$ controls how much of the Gaussian's probability mass is covered by the sampling area. Incorrect tuning may lead to aliasing or blurring [S1].

## Operating characteristics
*   **Training Time:** 2.6 hours on NVIDIA A100-SXM4-80GB GPU for 120k iterations [S1]. The Rip-NeRF25k variant trains in 32 minutes (11.76% of Zip-NeRF's time) [S1].
*   **Model Size:** 160 MB [S1].
*   **GPU Memory:** 20 GB during training [S1].
*   **Rendering Speed:** 3 FPS [S1].
*   **Comparison:** Outperforms Zip-NeRF in training time (2.6h vs 4.5h), model size (160MB vs 592MB), and rendering speed (3 FPS vs 0.25 FPS) [S1]. Zip-NeRF has slightly better SSIM [S1].
*   **Strengths:** Efficient anisotropic area-sampling; compact representation; high-fidelity anti-aliasing [S1].
*   **Limitations:** Requires calibrated multi-view images; performance on unbounded scenes may be inferior to methods like Zip-NeRF designed for them [S1].

## Background
Rip-NeRF was introduced in 2024 by authors including Barron et al. and Hu et al., building upon prior work in Mip-NeRF, Tri-MipRF, and Zip-NeRF [S1]. It addresses the limitations of discrete point-based sampling and inefficient multi-sampling in hybrid radiance field representations by introducing Ripmap-Encoded Platonic Solids for area sampling [S1].
