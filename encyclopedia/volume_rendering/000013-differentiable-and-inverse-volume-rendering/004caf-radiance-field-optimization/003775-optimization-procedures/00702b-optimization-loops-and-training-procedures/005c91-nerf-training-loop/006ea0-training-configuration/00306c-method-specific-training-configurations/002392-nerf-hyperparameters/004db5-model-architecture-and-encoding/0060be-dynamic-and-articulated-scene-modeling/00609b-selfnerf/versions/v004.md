# SelfNeRF


## Overview
SelfNeRF is a novel view synthesis method for human performance that trains from scratch using monocular self-rotating video inputs, achieving high-fidelity results in approximately twenty minutes [S1, unofficial]. It distinguishes itself from sibling methods like [MoCo-NeRF](16197-moco-nerf.md) and [A-NeRF](18108-a-nerf.md) by eliminating the need for multi-view inputs or explicit skeletal priors, instead relying on a surface-relative hash encoding to aggregate inter-frame information and accelerate training [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A monocular self-rotating video of a human performer consisting of $N_t$ frames [S1, unofficial].
*   **Output:** A trained neural radiance field model capable of rendering novel views of the performer [S1, unofficial].

**Data Structures:**
*   **Surface Shape $\{T_t\}$:** A set of point clouds representing the human surface for each frame $t \in \{0, \dots, N_t - 1\}$, recovered using external reconstruction methods such as VideoAvatar or SelfRecon [S1, unofficial].
*   **Body Mask $\{M_t\}$:** Binary masks for each frame $t$, identifying the human region [S1, unofficial].
*   **Hash Grid:** A multi-resolution hash encoding structure storing high-dimensional feature vectors [S1, unofficial].
*   **MLP $F_\omega$:** A neural network with weights $\omega$ that maps encoded features to density $\sigma$ and color $c$ [S1, unofficial].

**Numbered Steps:**
1.  **Preprocessing:** For the input video, recover the surface shape $T_t$ and body mask $M_t$ for each frame $t$ using existing reconstruction algorithms [S1, unofficial].
2.  **Surface-Relative Representation:** For a query point $\mathbf{x}$ at frame $t$, find the $K$-nearest neighbor points on the current frame's point cloud $T_t$ and calculate their signed distances [S1, unofficial]. Map these neighbors and their signed distances to the corresponding points and signed distances in the canonical space (Frame 0) [S1, unofficial].
3.  **Encoding:** Encode the resulting surface-relative representation using multi-resolution hash encoding to produce a high-dimensional feature vector [S1, unofficial].
4.  **Radiance Prediction:** Feed the encoded feature vector into the MLP $F_\omega$ to regress the density $\sigma$ and color $c$ [S1, unofficial].
5.  **Rendering:** Render the image using volume rendering to calculate the pixel color $C(\mathbf{r})$ for each ray $\mathbf{r}$ [S1, unofficial].
6.  **Optimization:** Train the model by minimizing photometric loss and geometric guidance loss [S1, unofficial].

**Formulas:**
The volume rendering equation for a ray $\mathbf{r}$ is [S1, unofficial]:
$$
C(\mathbf{r}) = \sum_{i=1}^{N} \alpha(\mathbf{x}_i) \left( \prod_{j<i} (1 - \alpha(\mathbf{x}_j)) \right) c(\mathbf{x}_i, \mathbf{v})
$$
where:
*   $\alpha(\mathbf{x}_i) = 1 - \exp(-\sigma(\mathbf{x}_i) \delta_i)$ is the transmittance-derived opacity [S1, unofficial].
*   $\mathbf{x}_i = \mathbf{o} + t_i \mathbf{v}$ are the sample points on the ray [S1, unofficial].
*   $\delta_i = u_{i+1} - u_i$ is the distance between adjacent sample points [S1, unofficial].
*   $c(\mathbf{x}_i, \mathbf{v})$ is the color predicted by $F_\omega$ [S1, unofficial].

**Parameters:**
*   $N_t$: Total number of frames in the input monocular video [S1, unofficial].
*   $K$: Number of nearest neighbors used to calculate the surface-relative representation [S1, unofficial].

**Pseudocode:**
```python
def selfnerf_render(ray_o, ray_d, frame_idx, surface_clouds, hash_grid, mlp_weights, K, num_samples, t_min, t_max):
    # 1. Sample points along the ray
    t_vals = [t_min + i * (t_max - t_min) / num_samples for i in range(num_samples + 1)]
    x_samples = [(ray_o[0] + t * ray_d[0], ray_o[1] + t * ray_d[1], ray_o[2] + t * ray_d[2]) for t in t_vals[:-1]]
    deltas = [t_vals[i+1] - t_vals[i] for i in range(num_samples)]

    # 2. Compute surface-relative representation and features
    features = []
    for x in x_samples:
        current_cloud = surface_clouds[frame_idx]
        # Find K nearest neighbors and signed distances
        dists = [(x[0]-p[0])**2 + (x[1]-p[1])**2 + (x[2]-p[2])**2 for p in current_cloud]
        sorted_indices = sorted(range(len(dists)), key=lambda i: dists[i])[:K]
        k_neighbors = [current_cloud[i] for i in sorted_indices]
        k_dists = [dists[i]**0.5 for i in sorted_indices]

        # Map to canonical space (Frame 0)
        canonical_neighbors = surface_clouds[0]
        canonical_dists = k_dists

        # Hash encode
        feature = []
        for level in range(num_hash_levels):
            grid = hash_grid[level]
            idx = hash_function(canonical_neighbors, canonical_dists, level)
            feature.extend(grid[idx])
        features.append(feature)

    # 3. Predict density and color
    sigma = []
    color = []
    for f in features:
        s, c = mlp_forward(f, ray_d, mlp_weights)
        sigma.append(s)
        color.append(c)

    # 4. Volume rendering
    alpha = [1.0 - (2.718281828 ** (-sigma[i] * deltas[i])) for i in range(num_samples)]
    transmittance = [1.0]
    for i in range(num_samples - 1):
        transmittance.append(transmittance[-1] * (1.0 - alpha[i]))

    final_color = [0.0, 0.0, 0.0]
    for i in range(num_samples):
        weight = alpha[i] * transmittance[i]
        for c in range(3):
            final_color[c] += weight * color[i][c]
    return final_color

def hash_function(points, distances, level):
    # Standard hash encoding index computation [G]
    return hash((points, distances, level)) % (2**level)

def mlp_forward(feature, view_dir, weights):
    # Standard MLP forward pass [G]
    hidden = [sum(f * w for f, w in zip(feature, weights['w1'])) + weights['b1']]
    sigma = max(0.0, hidden[0]) # Density must be non-negative
    color = [sum(f * w for f, w in zip(hidden, weights['w2'][c])) + weights['b2'][c] for c in range(3)]
    return sigma, color
```

## Operating characteristics
*   **Training Time:** Approximately 20 minutes for convergence [S1, unofficial].
*   **Input Requirements:** Monocular self-rotating video; no multi-view setup required [S1, unofficial].
*   **Strengths:** Fast training speed due to hash encoding; ability to train from scratch with minimal input [S1, unofficial].
*   **Limitations:** Relies on recovering surface shape using external reconstruction methods such as VideoAvatar or SelfRecon [S1, unofficial].
*   **When to use:** When only monocular video is available and rapid training is desired [S1, unofficial].

## Background
SelfNeRF was proposed by Bo Peng, Jun Hu, Jingtao Zhou, and Juyong Zhang from the University of Science and Technology of China [S1, unofficial]. It was published on arXiv in October 2022 [S1, unofficial]. The method addresses the challenge of high-fidelity novel view synthesis for human performance using only monocular inputs, a common scenario in practical applications like sports broadcasts and VR/AR [S1, unofficial].
