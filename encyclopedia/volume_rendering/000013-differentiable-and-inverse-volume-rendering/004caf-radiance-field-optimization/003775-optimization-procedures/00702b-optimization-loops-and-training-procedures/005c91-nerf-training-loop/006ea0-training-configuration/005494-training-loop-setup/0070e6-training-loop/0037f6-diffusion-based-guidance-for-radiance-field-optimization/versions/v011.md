# Diffusion-Based Guidance for Radiance Field Optimization

Also called: Score Distillation Sampling, Stable Diffusion Training Guidance

## Overview
Diffusion-Based Guidance for Radiance Field Optimization, commonly known as Score Distillation Sampling (SDS), computes a gradient signal from a frozen 2D diffusion model to optimize a 3D radiance field representation [S1, unofficial]. It solves the problem of generating 3D geometry and texture from 2D text or image priors by backpropagating the difference between the diffusion model's predicted noise and the actual noise added to a rendered view [S1, unofficial]. Unlike methods that rely on explicit 3D supervision or CLIP-based image-text alignment, SDS leverages the rich generative prior of diffusion models to guide the optimization loop, setting it apart from siblings like [VCCNF Training Loop](4736-vccnf-training-loop.md) which may use different consistency constraints, and [MVDream Multi-View Diffusion Guidance](6345-mvdream-multi-view-diffusion-guidance.md) which extends this guidance to multiple views simultaneously.

## How it works
**Inputs and Outputs**
- **Input:** A rendered image (or latent representation) from the radiance field, a text prompt, and optionally a mask or reference view.
- **Output:** A gradient update for the radiance field parameters (e.g., NeRF MLP weights, Gaussian splat attributes).

**Data Structures**
- **Latents:** If operating in latent space, the input is encoded into a latent tensor of shape `[B, 4, 64, 64]` using a Variational Autoencoder (VAE) [S1, unofficial].
- **Timesteps:** Integer or float values $t$ representing the diffusion step, typically sampled from a range $[t_{min}, t_{max}]$ [S1, unofficial].
- **Embeddings:** Text embeddings (positive and negative) and optionally directional embeddings based on camera azimuth [S1, unofficial].

**Parameters**
- **`guidance_scale`:** Classifier-free guidance scale multiplier. Default value in code is 100 [S1, unofficial].
- **`t_range`:** List `[0.02, 0.98]` used to compute `min_step` and `max_step` as fractions of `num_train_timesteps` [S1, unofficial].
- **`step_ratio`:** Float controlling timestep selection. `1.0` maps to `min_step` (early diffusion), `0.0` maps to `max_step` (late diffusion) [S1, unofficial].

**Algorithm Steps**
1.  **Preprocessing:** Convert the input predicted RGB image `pred_rgb` to the target data type. If `as_latent` is false, interpolate the image to 512x512 and encode it via the VAE to obtain `latents` of shape `[B, 4, 64, 64]`. If `as_latent` is true, interpolate to 64x64 and scale by `2 * x - 1` [S1, unofficial].
2.  **Weighting:** Compute the weighting factor $w = (1 - \alpha_t)$, where $\alpha_t$ is the noise schedule coefficient at timestep $t$. Reshape $w$ to `[batch_size, 1, 1, 1]` [S1, unofficial].
3.  **Noise Addition:** Sample random noise `noise` from a standard normal distribution with the same shape as `latents`. Add this noise to the latents using the diffusion scheduler: `latents_noisy = scheduler.add_noise(latents, noise, t)` [S1, unofficial].
4.  **Classifier-Free Guidance (CFG) Preparation:** Duplicate the noisy latents and timesteps to prepare for conditional and unconditional predictions. `latent_model_input = torch.cat([latents_noisy] * 2)` and `tt = torch.cat([t] * 2)` [S1, unofficial].
5.  **Embedding Preparation:** Concatenate positive and negative text embeddings. If directional information (azimuth angles `hors`) is provided, select directional embeddings: `front` for $|h| < 60^\circ$, `side` for $60^\circ \le |h| < 120^\circ$, and `back` otherwise. Concatenate these with the negative embeddings [S1, unofficial].
6.  **Diffusion Prediction:** Pass the inputs to the UNet: `noise_pred = unet(latent_model_input, tt, encoder_hidden_states=embeddings).sample` [S1, unofficial].
7.  **Guidance Application:** Split `noise_pred` into `noise_pred_cond` and `noise_pred_uncond`. Compute the guided prediction: `noise_pred = noise_pred_uncond + guidance_scale * (noise_pred_cond - noise_pred_uncond)` [S1, unofficial].
8.  **Gradient Computation:** Calculate the gradient as `grad = w * (noise_pred - noise)`. Apply `torch.nan_to_num(grad)` to handle numerical instabilities that may produce NaN values [S1, unofficial].
9.  **Target Calculation:** Compute the target latent: `target = (latents - grad).detach()` [S1, unofficial].
10. **Loss Calculation:** Compute the Mean Squared Error (MSE) loss between the original latents and the target: `loss = 0.5 * F.mse_loss(latents.float(), target, reduction='sum') / latents.shape[0]` [S1, unofficial].

**Pseudocode**
```python
def compute_sds_loss(latents, t, unet, scheduler, text_embeddings, guidance_scale=100):
    """
    Computes the Score Distillation Sampling loss.
    
    Args:
        latents: Tensor of shape [B, 4, 64, 64], the encoded image latents.
        t: Integer or float, the current diffusion timestep.
        unet: The frozen UNet model.
        scheduler: The diffusion scheduler.
        text_embeddings: Tuple of (positive_embeddings, negative_embeddings).
        guidance_scale: Float, CFG scale.
        
    Returns:
        loss: Scalar tensor, the computed SDS loss.
    """
    # Step 2: Compute weighting factor
    # Assuming alpha_t is available from the scheduler or noise schedule
    alpha_t = scheduler.alphas_cumprod[t] if hasattr(scheduler, 'alphas_cumprod') else 1.0 - scheduler.alphas[t]
    w = (1 - alpha_t).view(latents.shape[0], 1, 1, 1)
    
    # Step 3: Sample noise and add to latents
    noise = torch.randn_like(latents)
    latents_noisy = scheduler.add_noise(latents, noise, t)
    
    # Step 4: Duplicate for CFG
    latent_model_input = torch.cat([latents_noisy] * 2)
    tt = torch.cat([t] * 2)
    
    # Step 5: Prepare embeddings
    pos_emb, neg_emb = text_embeddings
    # Concatenate positive and negative embeddings for the batch
    # Note: In practice, pos_emb is repeated for the first half, neg_emb for the second
    # The UNet expects embeddings of shape [2*B, seq_len, dim]
    embeddings = torch.cat([pos_emb, neg_emb], dim=0)
    
    # Step 6: Pass to UNet
    noise_pred = unet(latent_model_input, tt, encoder_hidden_states=embeddings).sample
    
    # Step 7: Apply CFG
    noise_pred_cond, noise_pred_uncond = noise_pred.chunk(2)
    noise_pred = noise_pred_uncond + guidance_scale * (noise_pred_cond - noise_pred_uncond)
    
    # Step 8: Compute gradient
    grad = w * (noise_pred - noise)
    grad = torch.nan_to_num(grad)
    
    # Step 9: Compute target
    target = (latents - grad).detach()
    
    # Step 10: Compute loss
    loss = 0.5 * F.mse_loss(latents.float(), target, reduction='sum') / latents.shape[0]
    
    return loss
```

**Edge Cases and Pitfalls**
- **NaN Values:** Gradient computation can produce NaN values due to numerical instability in the diffusion process or high guidance scaling. The code explicitly clamps NaNs to 0 using `torch.nan_to_num(grad)` [S1, unofficial].
- **Timestep Selection:** Choosing inappropriate timesteps can lead to poor generation quality. Early timesteps (high noise) capture global structure, while late timesteps (low noise) capture details [S6].

## Subtopics

### [Inpainting SDS Loss](11185-inpainting-sds-loss.md)
Inpainting SDS Loss is a training objective for Neural Radiance Fields (NeRFs) that uses a pre-trained 2D diffusion inpainting model to generate 3D content that harmonizes with an existing scene. It solves the problem of incomplete or misaligned object generation common in vanilla SDS, where generated parts (e.g., a cat's head) fail to composite properly with the background. Unlike vanilla SDS, which optimizes based on global noise prediction, this method conditions the diffusion model on a masked image and mask derived from a 3D bounding box, ensuring complete geometry and proper pose relative to the scene context.

### SKED
SKED is a method for editing a Neural Radiance Field (NeRF) scene using guidance from 2D sketches provided from multiple views, in addition to an input text prompt [S1, unofficial][S2]. It addresses the problem of localized 3D editing, specifically object insertion and replacement, by ensuring that edits are confined to sketched regions while preserving the unedited parts of the original scene [S1, unofficial][S2]. It is distinguished from sibling methods like [Inpainting SDS Loss](11185-inpainting-sds-loss.md) by its explicit use of multi-view 2D sketches as spatial priors to define the edit region, rather than relying solely on text prompts or single-view masks [S1, unofficial][S2].

### [Synthetic Training with EG3D Supervision](13312-synthetic-training-with-eg3d-supervision.md)
This method trains an image-to-triplane encoder to reconstruct a 3D radiance field representation from a single input image by leveraging synthetic data generated by a frozen, pretrained EG3D generator. It solves the problem of generalizing single-image portrait synthesis by ensuring the encoder produces triplanes that are consistent not only with the input reference view but also with novel multiview renderings, thereby enforcing geometric and photometric coherence. It differs from standard supervised training by using a frozen generative model as a ground-truth oracle and alternating between reference-view and multiview supervision to prevent overfitting to the specific distribution of the input image.

### [Mask+SDS with Background Prompt](14382-mask-sds-with-background-prompt.md)
Mask+SDS with Background Prompt is a differentiable volume rendering optimization method that uses a frozen Stable Diffusion model to edit specific regions of a scene while explicitly guiding the generation of surrounding content. It solves the problem of "black holes" (unsupervised, often black or undefined regions) that occur when masking out parts of a NeRF for editing, by appending a background description to the diffusion model's text prompt. It sets itself apart from standard Mask+SDS by providing explicit semantic guidance for the occluded areas, and from Mask+SDS+CLIP by relying on the diffusion model's generative prior for the background rather than a separate CLIP-based texture fill.

### [Diffusion-Based 3D Inpainting](14834-diffusion-based-3d-inpainting.md)
Diffusion-Based 3D Inpainting is a method that utilizes a self-trained 2D inpainting diffusion model to reconstruct missing or masked regions in a 3D scene represented by a radiance field. It solves the problem of 3D scene completion or object removal by combining explicit reconstruction constraints for visible areas with implicit diffusion priors for occluded areas. It is distinguished from sibling methods like [Inpainting SDS Loss](11185-inpainting-sds-loss.md) by its specific reliance on a *self-trained* 2D inpainting model rather than a generic pre-trained one, and from [SKED](12268-sked.md) by its focus on distilling 2D inpainting results into a single 3D scene via iterative refinement.

### [Reference-guided Controllable Inpainting of Neural Radiance Fields](15289-reference-guided-controllable-inpainting-of-neural-radiance-.md)
This method performs 3D inpainting of Neural Radiance Fields (NeRFs) by substituting a single reference view with a diffusion-generated target view, then optimizing the NeRF to match the new view while maintaining consistency with the remaining input views. It solves the problem of inserting or modifying objects in a 3D scene without requiring multi-view supervision for the target content. It differs from [Inpainting SDS Loss](11185-inpainting-sds-loss.md) by using a deterministic 2D inpainting prior (Stable Diffusion) followed by a bilateral solver for residual smoothing, rather than relying solely on gradient-based SDS guidance during optimization.

### [Diffusion Model Preprocessing & Training Setup](15506-diffusion-model-preprocessing-training-setup.md)
This method defines the data preprocessing pipeline and training configuration for a fine-tuned Stable Diffusion 1.5 model used as a prior in Street View Synthesis with Gaussian Splatting (SGD). It addresses the challenge of adapting a 2D diffusion model to guide 3D radiance field optimization by ensuring input images maintain aspect ratio integrity and by establishing a robust reference image selection strategy. It sets apart from generic diffusion setups by specifically handling the extreme aspect ratio distortion of KITTI-360 data and enforcing a "perspective gap" via random cropping of reference images during training to prevent overfitting to exact training views.

### Iterative Optimization with Learnable Parameters for Diffusion-Guided Radiance Fields
A method addressing quality impairment caused by differences between the diffusion prior and the training process of the diffusion model [S2]. It performs iterative optimization of the 3D model and the diffusion prior. A learnable unconditional embedding is introduced in the classifier-free guidance formula, and additional parameters, such as LoRA parameters, are added to the network [S2].

### Interval Score Matching
A modification to SDS loss that replaces DDPM with DDIM inversion and introduces supervisions from interval steps to avoid high error in one-step reconstruction [S2].

### Context-Translation Training with Segmentation Masking
Passes a segmentation mask to the training process where pixels excluded in the stylization process are masked out. The loss is calculated only on the pixels outside the mask to avoid changing the appearance of masked pixels. It employs a background loss $L_{BG}$ as an additional regularization loss within the stylization process, defined as the L1 distance between the ground truth pixels of the background in the rendered image and the pixels in the background of the GT image, to prevent the model from introducing unwanted style artifacts in the background [S3].

### Style Adaptation via Diffusion Guidance
Uses a reference image as a condition alongside the text prompt to guide generation [S4].

### Blending Refinement Model
A model employing two Instruct-Pix2Pix processes as learned regularization to improve quality by purifying noisy mixup images and aligning them with detailed characteristics, using averaged latent codes for stability [S5]. First pass: Use the mixup image as input and the original image as a condition to purify the noisy mixup image by preserving structural integrity. Second pass: Use the resulting image from the first pass as input and the mixup image as the condition to align with the mixup image’s detailed characteristics. Introduce $n_r$ noised latent codes and update them independently. Compute the average of the latent codes and decode it back into the image. Parameters: $n_r=5$, input timestep $t=0.6$, 3 diffusion steps [S5].

### Masked-NeRF + DreamFusion
A baseline method that uses per-scene text prompts to guide the generation of masked regions using score distillation sampling (SDS) loss [S6]. It gradually and uniformly decreases the maximum noise steps $t_{max}$ during fitting, until it equals the minimum noise steps $t_{min}$ at the last iteration [S6].

## Operating characteristics
- **Time Complexity:** The method requires multiple forward passes through the diffusion UNet per optimization step (one for conditional, one for unconditional, or batched). The complexity is dominated by the UNet inference, which is $O(N_{params} \cdot H \cdot W)$ where $N_{params}$ is the number of parameters in the UNet, and $H, W$ are the latent dimensions [S1, unofficial].
- **Memory Complexity:** Requires storing the UNet weights, the VAE encoder/decoder weights, and the intermediate activations for the backward pass. The latent space reduces memory usage compared to pixel-space diffusion [S1, unofficial].
- **Measured Performance:** Performance depends heavily on the `guidance_scale` and timestep selection. High guidance scales (e.g., 100) can lead to over-saturation or artifacts if not balanced with proper timestep scheduling [S1, unofficial].
- **Scaling:** Scales with the resolution of the rendered image (or latent size). Latent-space diffusion allows for efficient optimization at high effective resolutions (e.g., 512x512) without the memory cost of pixel-space diffusion [S1, unofficial].
- **Strengths:** Leverages powerful 2D diffusion priors for high-quality texture and geometry generation. Flexible with various conditioning inputs (text, masks, sketches) [S1, unofficial][S2, S3, S4].
- **Limitations:** Can suffer from "Janus" problems (multi-headed objects) or floaters if not properly regularized. Computationally expensive due to the need for multiple UNet passes and gradient computation through the diffusion process [S2, S6].
- **When to use:** When generating 3D content from 2D text or image prompts is required, and high-fidelity texture is a priority.
- **When not to use:** When real-time performance is critical, or when explicit 3D supervision is available and sufficient.

## Background
Originated from the DreamFusion paper by Poole et al. (2022), which introduced Score Distillation Sampling (SDS) as a method to optimize 3D representations using pre-trained 2D diffusion models [S1, unofficial][S6]. The method was developed to address the lack of 3D data for training generative models by leveraging the vast amount of 2D data used to train models like Stable Diffusion. It has since become a foundational technique in text-to-3D generation and has been extended in numerous ways, including multi-view guidance, inpainting, and style transfer [S1, unofficial][S2, S3, S4, S5, S6].
