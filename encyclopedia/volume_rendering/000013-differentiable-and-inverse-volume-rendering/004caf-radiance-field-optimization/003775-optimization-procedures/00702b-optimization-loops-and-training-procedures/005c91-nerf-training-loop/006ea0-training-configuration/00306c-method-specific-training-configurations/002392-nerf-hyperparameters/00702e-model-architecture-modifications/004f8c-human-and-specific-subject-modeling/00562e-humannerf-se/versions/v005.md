# HumanNeRF-SE

Also called: HumanNeRF with Sparse Encoding

## Overview
HumanNeRF-SE is a method for synthesizing novel pose images of humans from monocular video inputs by combining explicit SMPL shape priors with an implicit NeRF representation [S1]. It solves the problem of overfitting and high computational complexity inherent in previous NeRF-based human avatars, which typically require large numbers of optimizable parameters and multi-camera data [S1]. Unlike sibling methods such as [HumanNeRF](13842-humannerf.md) and [Unified Volumetric Avatar (UVA)](13784-unified-volumetric-avatar-uva.md) that rely on frame-level features or learned blend weights prone to overfitting, HumanNeRF-SE uses frozen SMPL blending weights for rigid deformation and point-level spatial features for non-rigid refinement, ensuring pose generalization without pose leakage [S1].

## How it works
**Inputs:** Monocular video frames $\{I_n\}$, corresponding SMPL mesh vertices $v$ and pose parameters $J$ for each frame.
**Outputs:** Rendered images $\tilde{C}(r)$ for arbitrary viewpoints and poses.

**Data Structures:**
*   **Voxel Volume $V$:** A sparse 3D grid. Each voxel containing SMPL vertices stores a tuple $(n_v, w_1, \dots, w_{24})$, where $n_v$ is the vertex count (occupancy) and $w_j$ are the 24 Linear Blending Skinning (LBS) weights from SMPL. Empty voxels store $(0, 0, \dots, 0)$ [S1].
*   **Spatial-Aware Features $F_s$:** The result of convolving $V$, used to query point-level features [S1].

**Parameters:**
*   $v_s$: Voxel size used to scale the SMPL bounding box [S1].
*   $\lambda$: Weight for the MSE loss term [S1].
*   $N_s$: Number of samples per ray [S1].

**Algorithm Steps:**

1.  **Voxelization:**
    Calculate the bounding box $[min, max]$ of the SMPL vertices $v$. Scale the bounding box to voxel size $v_s$. Find the least common multiple of the axes dimensions and 32. Scale vertices $v$ by subtracting $min$ and dividing by $v_s$. Construct the voxel volume $V$ using sparse convolution $Sp$:
    $$ V = Sp(v, v_s, W) $$
    [S1]

2.  **Conv-Filter (Feature Extraction & Filtering):**
    Initialize a convolution kernel to one. Perform channel-by-channel convolution on $V$ to obtain spatially-aware features $F_s$. For a voxel at index $(h, w, d)$ with kernel size $k$:
    $$ F_{s,i} = \sum_{m=h-k}^{h} \sum_{n=w-k}^{w} \sum_{t=d-k}^{d} \nu_{m,n,t,i} \cdot \vartheta_{m,n,t,i} $$
    where $\nu$ is the voxel value and $\vartheta$ is the kernel weight [S1].
    Query the occupancy of $F_s(x)$ for each sampling point $x$:
    $$
    \begin{cases}
    x_o \text{ filtered out}, \sigma(x_o) = 0 & \text{if } F_s(x) = 0 \\
    x_r \text{ remains} & \text{if } F_s(x) > 0
    \end{cases}
    $$
    $x_o$ are irrelevant points; $x_r$ are human-related points [S1].

3.  **Point Canonicalization:**
    *   **Rigid Deformation ($D$):** Query the nearest neighbor SMPL weights $W_{smpl} = K(x_r, v)$. Compute the rigid deformation $x^{rcnl}$ using the frozen SMPL weights $w_j$, joint rotations $R_j$, and translations $T_j$ relative to the T-pose:
        $$ x^{rcnl} = \sum_{j \in J} w_j ((x_r \cdot R_j) + T_j) $$
        [S1]
    *   **Non-Rigid Refinement ($P$):** Refine the coarse coordinates using a network $P$ conditioned on the spatial-aware features $F_s$ and the remaining points $x_r$:
        $$ x^{cnl} = x^{rcnl} + P(F_s, x_r) $$
        [S1]

4.  **Appearance Net:**
    Encode $x^{cnl}$ using positional encoding (as in standard NeRF). Pass through an MLP $M_\sigma$ to output color $c$ and density $\sigma$:
    $$ c, \sigma = M_\sigma(x^{cnl}) $$
    [S1]

5.  **Rendering:**
    Render the image using differentiable volume rendering. For a ray $r$ with $N_s$ samples:
    $$ \alpha_i = 1 - \exp(-\sigma(x_i) \Delta t_i) $$
    $$ \tilde{C}_t(r) = \sum_{k=1}^{N_s} \alpha_k c(x_k) \prod_{j=1}^{k-1} (1 - \alpha_j) $$
    [S1]

**Pseudocode:**

```python
def human_neRF_SE(video_frames, smpl_vertices, smpl_weights, pose_params, voxel_size):
    """
    video_frames: List of images
    smpl_vertices: List of vertex arrays for each frame
    smpl_weights: SMPL LBS weights (24 channels)
    pose_params: Pose parameters (J) for each frame
    voxel_size: Scaling factor for voxelization
    """
    
    # 1. Voxelization
    # Calculate bounding box of SMPL vertices
    min_coord = min(smpl_vertices)
    max_coord = max(smpl_vertices)
    
    # Scale vertices to voxel grid
    scaled_vertices = (smpl_vertices - min_coord) / voxel_size
    
    # Construct sparse voxel volume V
    # V contains occupancy count and 24 LBS weights per voxel
    V = sparse_convolution(scaled_vertices, smpl_weights, voxel_size)
    
    # 2. Conv-Filter
    # Initialize kernel to ones
    kernel = initialize_ones_kernel()
    
    # Channel-by-channel convolution to get spatial features Fs
    Fs = channel_by_channel_conv(V, kernel)
    
    # 3. Point Canonicalization
    # Sample points x in the volume
    sampling_points = sample_points_in_volume(V)
    
    # Filter points based on Fs occupancy
    human_points = []
    for x in sampling_points:
        if query_occupancy(Fs, x) > 0:
            human_points.append(x)
        else:
            # Force density to 0 for filtered points
            set_density(x, 0)
            
    # Rigid Deformation using frozen SMPL weights
    canonical_coords_rigid = []
    for x in human_points:
        # Query nearest SMPL weights
        w_smpl = query_nearest_weights(x, smpl_vertices, smpl_weights)
        
        # Compute rigid transform relative to T-pose
        x_rcnl = sum(w_j * (x * R_j + T_j) for w_j, R_j, T_j in zip(w_smpl, pose_params.R, pose_params.T))
        canonical_coords_rigid.append(x_rcnl)
        
    # Non-Rigid Refinement
    canonical_coords_final = []
    for i, x in enumerate(human_points):
        # Get spatial feature for this point
        fs_feature = query_feature(Fs, x)
        
        # Refine coordinate using point-level network P
        x_cnl = canonical_coords_rigid[i] + P(fs_feature, x)
        canonical_coords_final.append(x_cnl)
        
    # 4. Appearance Net
    colors = []
    densities = []
    for x_cnl in canonical_coords_final:
        # Positional Encoding
        pe_x = positional_encoding(x_cnl)
        # MLP to get color and density
        c, sigma = MLP_sigma(pe_x)
        colors.append(c)
        densities.append(sigma)
        
    # 5. Rendering
    # Render rays using volume rendering equation
    rendered_images = []
    for frame_idx, ray in enumerate(get_rays(video_frames[frame_idx])):
        samples = sample_along_ray(ray, num_samples=Ns)
        # Filter samples based on canonicalization results
        # (Assuming samples are mapped to canonical space and filtered above)
        alpha = 1 - exp(-densities * delta_t)
        color = sum(alpha_k * colors_k * product(1 - alpha_j) for k, j in indices)
        rendered_images.append(color)
        
    return rendered_images
```

## Operating characteristics
*   **Complexity:** Reduces required sampling points from ~300K to less than 100K [S1]. Uses less than 1% of learnable parameters compared to previous methods [S1].
*   **Performance:** Reduces training time by 95% (to 1/20 of previous methods) [S1]. Increases rendering speed by 15 times without using existing acceleration modules [S1].
*   **Metrics (ZJU-MOCAP few-shot):** PSNR=31.09, SSIM=0.974, LPIPS=24.085 [S1].
*   **Strengths:** Avoids overfitting by using frozen SMPL weights; generalizes to novel poses; works with monocular input; reduces computational load significantly [S1].
*   **Limitations:** Relies on the accuracy of SMPL fitting; if the SMPL fit is poor, the rigid deformation may be inaccurate [S1]. The Conv-Filter may fail to learn the correct alpha map if skin weight distribution causes color diffusion into surrounding space [S1].

## Background
HumanNeRF-SE was introduced in 2024 by Miles et al. [S1]. It addresses the limitations of prior NeRF-based human avatars that required multi-camera data or suffered from pose leakage and overfitting when using limited monocular inputs [S1]. The method builds on [HumanNeRF](13842-humannerf.md) but replaces frame-level features with point-level features and learned weights with frozen SMPL priors [S1].
