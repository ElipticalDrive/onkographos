# Dynamic Appearance Particle Neural Radiance Field
Also called: Dynamic Appearance Particle NeRF, Lagrangian dynamic model in NeRF

## Overview
Dynamic Appearance Particle Neural Radiance Field is a method for novel view synthesis from monocular video that models scene dynamics using a particle motion network and appearance particles [S1]. It solves the problem of rendering dynamic scenes without prior geometric knowledge or multi-view data by separating the scene into a static grid-based field and a dynamic particle-based field [S1]. Unlike ParticleNeRF, which encodes the entire scene with particles and requires multiple views per frame, this method applies appearance particles only to dynamic elements and uses a grid-based field with linear interpolation for efficient querying, enabling it to handle monocular video data [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Monocular video data (one camera view per time frame) [S1].
*   **Output:** Rendered pixel color $C(r, t)$ for a given ray $r$ and time $t$ [S1].

**Data Structures:**
1.  **Static Field ($V_s$):** A time-independent grid-based model (e.g., hash grid or dense grid) storing features for static scene components [S1].
2.  **Dynamic Field ($V_{td}$):** An ensemble of particles representing dynamic elements. Each particle has a position and associated appearance features [S1].
3.  **Particle Motion Network:** A neural network that predicts particle motion/velocity over time [S1].

**Formulas:**
The rendered color $C(r, t)$ at time $t$ is computed by volume rendering along a ray $r(s) = o + sd$ from near bound $s_n$ to far bound $s_f$ [S1]:
$$
C(r, t) = \int_{s_n}^{s_f} T(s, t)\sigma(r(s), t)c(r(s), \mathbf{d}, t)ds
$$
where $T(s, t)$ is the accumulated transmittance:
$$
T(s, t) = \exp\left(-\int_{s_n}^{s} \sigma(r(s'), t)ds'\right)
$$
The total feature field $V(x, t)$ is a superposition of static and dynamic components [S1]:
$$
V(x, t) = (1 - w_t(x))V_s(x) + w_t(x)V_{td}(x)
$$
where:
*   $V_s(x)$ is the static field component [S1].
*   $V_{td}(x)$ is the dynamic field component [S1].
*   $w_t(x)$ is a weight taking value 1 if the dynamic field is effective at $(x, t)$ and 0 otherwise [S1]. The support of the dynamic field is implied by the particle representation [S1].

The dynamic field $V_{td}$ is formulated as a convolution with a Dirac function to integrate over finite volumes [S1]:
$$
V_{td}(x) = (V_{td} * \delta)(x) = \int V_{td}(x')\delta(x - x')d\nu(x')
$$
where $\delta(\cdot)$ is the Dirac function [S1]. To quantize the field, the Dirac function is replaced with a kernel $W$ with finite support [S1]:
$$
W(x) = 0 \text{ when } \|x\| \text{ exceeds a small radius, and } \int W(x)d\nu(x) = 1
$$

**Notation Convention:**
Time $t$ is denoted in subscripts on the right-hand side of the superposition equation (e.g., $V_{td}$) to clarify that the dynamic component consists of an ensemble of particles, where the time argument is fixed for the instantaneous status construction [S1].

**Steps:**
1.  **Ray Casting:** For a target time $t$, cast a ray $r(s) = o + sd$ from the camera center $o$ to the pixel [S1].
2.  **Field Evaluation:** For each sample point $x$ along the ray:
    a. Query the static field $V_s(x)$ using grid-based interpolation [S1].
    b. Determine if the point is covered by dynamic particles. If yes, query the dynamic field $V_{td}(x)$ using the particle kernel $W$ [S1].
    c. Compute the combined field $V(x, t)$ using the superposition formula [S1].
3.  **Density and Color Prediction:** Use the combined field $V(x, t)$ to predict volume density $\sigma$ and color $c$ [S1].
4.  **Rendering:** Integrate the density and color along the ray to compute the final pixel color $C(r, t)$ [S1].

**Pseudocode:**
```python
def render_dynamic_appearance_particle_nerf(ray_o, ray_d, time_t, static_grid, particles, motion_net, kernel_width):
    """
    Renders a pixel for a given ray and time using Dynamic Appearance Particle NeRF.
    
    Args:
        ray_o: Ray origin (3D vector)
        ray_d: Ray direction (3D vector)
        time_t: Current time step
        static_grid: Grid-based static field model
        particles: List of dynamic particles, each with position and features
        motion_net: Neural network for particle motion
        kernel_width: Radius for the finite support kernel W
        
    Returns:
        pixel_color: Rendered color for the ray
    """
    # 1. Sample points along the ray
    num_samples = 128
    t_vals = linspace(ray_near, ray_far, num_samples)
    points = ray_o + outer(t_vals, ray_d)  # Shape: (num_samples, 3)
    
    # 2. Initialize accumulators
    accumulated_transmittance = 1.0
    accumulated_color = zeros(3)
    
    # 3. Iterate over samples
    for i in range(num_samples):
        x = points[i]
        
        # Query static field
        v_s = static_grid.query(x)
        
        # Query dynamic field
        # Determine if dynamic field is effective at (x, t)
        # This involves checking proximity to particles and their motion state
        is_dynamic_effective = False
        v_td = zeros_like(v_s)
        
        # Find nearby particles (e.g., using spatial hashing or KD-tree)
        nearby_particles = find_nearby_particles(particles, x, kernel_width)
        
        for particle in nearby_particles:
            # Predict particle position at time_t using motion_net
            # Note: motion_net takes particle's base position and time_t
            particle_pos = motion_net.predict(particle.base_pos, time_t)
            
            # Compute distance from sample point to particle position
            dist = norm(x - particle_pos)
            
            # Apply kernel W (finite support)
            if dist <= kernel_width:
                weight = kernel_W(dist, kernel_width)
                v_td += weight * particle.features
                is_dynamic_effective = True
        
        # Superposition
        w_t = 1.0 if is_dynamic_effective else 0.0
        v_combined = (1 - w_t) * v_s + w_t * v_td
        
        # Predict density and color from combined field
        sigma, color = predict_density_color(v_combined)
        
        # Volume rendering step
        alpha = 1 - exp(-sigma * (t_vals[i+1] - t_vals[i])) if i < num_samples - 1 else 1 - exp(-sigma * (ray_far - t_vals[i]))
        transmittance_term = accumulated_transmittance * alpha
        accumulated_color += transmittance_term * color
        accumulated_transmittance *= (1 - alpha)
        
        # Early termination if transmittance is very low
        if accumulated_transmittance < 0.001:
            break
            
    return accumulated_color

def kernel_W(dist, radius):
    """
    Finite support kernel W.
    W(x) = 0 when ||x|| exceeds radius.
    Integral of W over volume is 1.
    Implementation detail: Normalization factor depends on kernel shape (e.g., Gaussian, box).
    """
    if dist > radius:
        return 0.0
    # Placeholder for specific kernel shape normalization

    # For a Gaussian: exp(-dist^2 / (2 * sigma^2)) / (2 * pi * sigma^2)
    # The source does not specify the exact kernel shape, only that it has finite support and integrates to 1.
    return 1.0  # [G] Placeholder; actual implementation requires specific kernel definition
```

**Edge Cases and Pitfalls:**
*   **Particle Motion Prediction:** Errors in the motion network can lead to ghosting or artifacts in dynamic regions [S1].
*   **Kernel Support:** The choice of kernel width affects the smoothness of the dynamic field and computational cost [S1].
*   **Static/Dynamic Boundary:** The weight $w_t(x)$ must accurately distinguish between static and dynamic regions to avoid blending artifacts [S1].

## Operating characteristics
*   **Time Complexity:** Depends on the number of samples per ray and the number of nearby particles queried for each sample. Grid-based static field query is $O(1)$ with hashing. Particle query requires spatial indexing (e.g., KD-tree, grid) for efficiency [S1].
*   **Memory Complexity:** Proportional to the size of the static grid and the number of dynamic particles [S1].
*   **Measured Performance:** Not given in the sources.
*   **Strengths:** Handles monocular video data; no prior geometric knowledge required; efficient querying via grid-based static field and particle-based dynamic field [S1].
*   **Limitations:** Performance may degrade with highly complex dynamic scenes or large numbers of particles; requires training the motion network [S1].
*   **When to use:** When only monocular video data is available and the scene contains dynamic elements [S1].
*   **When not to use:** When multi-view data is available and ParticleNeRF might be more suitable for capturing fine details across views [S1].
