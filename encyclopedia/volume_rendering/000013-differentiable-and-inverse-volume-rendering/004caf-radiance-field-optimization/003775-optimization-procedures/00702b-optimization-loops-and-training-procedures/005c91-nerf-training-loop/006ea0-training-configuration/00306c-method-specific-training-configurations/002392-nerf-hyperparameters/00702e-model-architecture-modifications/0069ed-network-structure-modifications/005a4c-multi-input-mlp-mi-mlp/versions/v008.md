# Multi-input MLP (mi-MLP)
Also called: mi-MLP, per-layer inputs incorporation

## Overview
The multi-input MLP (mi-MLP) is a network architecture modification for Neural Radiance Fields (NeRF) that incorporates the raw input embeddings (3D location and viewing direction) into every layer of the network to prevent overfitting in few-shot view synthesis without reducing model capacity [S1]. Unlike the standard NeRF architecture which relies on a single shared MLP to implicitly map inputs to outputs through deep layers, mi-MLP ensures each layer is explicitly aware of the input embeddings, creating shorter paths between inputs and outputs [S1]. This structural change alleviates overfitting by balancing gradient amplitudes across layers, allowing the model to synthesize high-frequency details with fewer effective parameters [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 5D coordinate vector $\mathbf{x} = [\mathbf{p}, \mathbf{d}]$, where $\mathbf{p} \in \mathbb{R}^3$ is the 3D spatial position and $\mathbf{d} \in \mathbb{R}^3$ is the viewing direction.
*   **Output:** Volume density $\sigma \in \mathbb{R}$ and view-dependent color $\mathbf{c} \in \mathbb{R}^3$.

**Data Structures:**
The network consists of $L_{layers}$ linear layers (excluding the final output layer). Each layer $i$ (for $i > 1$) maintains:
*   Weight matrix $\mathbf{W}_i \in \mathbb{R}^{d_{out} \times (d_{in} + d_{enc})}$, where $d_{in}$ is the hidden dimension of the previous layer and $d_{enc}$ is the dimension of the positional encoding.
*   Bias vector $\mathbf{b}_i \in \mathbb{R}^{d_{out}}$.
*   Activation function $\epsilon$ (default: ReLU).

**Positional Encoding:**
The input $\mathbf{x}$ is transformed into an encoded embedding $\gamma_L(\mathbf{x})$ using a sinusoidal positional encoding scheme [S1]:
$$
\gamma_L(\mathbf{x}) = (\sin(2^0 \mathbf{x}), \cos(2^0 \mathbf{x}), \dots, \sin(2^{L-1} \mathbf{x}), \cos(2^{L-1} \mathbf{x}))
$$
where $L$ is a hyperparameter controlling the number of frequency bands [S1]. The dimension of $\gamma_L(\mathbf{x})$ is $2 \cdot L \cdot 5$ (since $\mathbf{x}$ is 5D).

**Algorithm:**
The forward pass computes the feature $f_i$ for each layer $i$ as follows:

1.  **Encode Input:** Compute $\mathbf{e} = \gamma_L(\mathbf{x})$.
2.  **First Layer:** Compute $f_1 = \epsilon(\mathbf{W}_1 [\mathbf{e}]^T + \mathbf{b}_1)$. Note: The first layer takes only the encoded input.
3.  **Subsequent Layers ($i = 2$ to $L_{layers}-1$):**
    Concatenate the encoded input $\mathbf{e}$ with the output of the previous layer $f_{i-1}$.
    $$
    f_i = \epsilon(\mathbf{W}_i [\mathbf{e}, f_{i-1}]^T + \mathbf{b}_i)
    $$
    Here, $[\mathbf{e}, f_{i-1}]$ denotes the concatenation of the encoded input and the previous layer's output.
4.  **Output Layer:** The final layer $L_{layers}$ takes the output of the previous layer $f_{L_{layers}-1}$ and the encoded input $\mathbf{e}$ to predict density and color.
    $$
    [\sigma, \mathbf{c}] = \mathbf{W}_{out} [\mathbf{e}, f_{L_{layers}-1}]^T + \mathbf{b}_{out}
    $$
    (Note: The source [S1] describes the general layer formula $f_i = \phi_i(f_{i-1}, \gamma_L(\mathbf{x}))$. The output layer follows the same pattern but produces the scalar $\sigma$ and vector $\mathbf{c}$.)

**Weight Initialization:**
The weights are initialized using the default PyTorch initialization [S1]. This initialization satisfies the condition $\|\mathbf{w}_i^{j1}\|_1 \in (0, 1]$ for the weight components associated with the previous layer's output, which is critical for the gradient behavior described below [S1].

**Gradient Behavior and Pitfalls:**
In vanilla NeRF, gradient amplitudes are similar across all layers during early training [S1]. In mi-MLP, the explicit connection of inputs to every layer ensures that deeper layers (closer to the output) receive larger gradient updates while shallower layers receive extremely small ones [S1]. This is mathematically derived from the ratio of gradient norms:
$$
\| \frac{\partial \mathcal{L}}{\partial \mathbf{w}_i} \|_1 / \| \frac{\partial \mathcal{L}}{\partial \mathbf{w}_{i-1}} \|_1 = \frac{1}{d_2} \sum_{j=1}^{d_2} \frac{\|\gamma_L(\mathbf{x})\|_1 + \|\phi_{i-1}(\gamma_L(\mathbf{x}))\|_1}{\|\sum \mathbf{w}_i^{j1}\|_1 \cdot \{\|\gamma_L(\mathbf{x})\|_1 + \|\phi_{i-2}(\gamma_L(\mathbf{x}))\|_1\}}
$$
where $\mathcal{L}$ is the loss, $d_2$ is the output dimension of the layer, and $\phi_i^j$ is the $j$-th element of $f_i$ [S1].
*   **Pitfall:** If the weight initialization does not satisfy $\|\mathbf{w}_i^{j1}\|_1 \in (0, 1]$, the gradient scaling property may not hold, potentially leading to training instability or failure to alleviate overfitting [S1].
*   **Pitfall:** The positional encoding frequency $L$ must be chosen carefully; too low loses high-frequency details, too high may introduce noise [S1].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import math

class PositionalEncoding(nn.Module):
    def __init__(self, num_freqs):
        super().__init__()
        self.num_freqs = num_freqs

    def forward(self, x):
        # x shape: (..., 5)
        # Output shape: (..., 2 * num_freqs * 5)
        freq_bands = 2.0 ** torch.arange(self.num_freqs, device=x.device).float()
        # Expand dimensions for broadcasting
        # x: (..., 5) -> (..., 1, 5)
        # freq_bands: (num_freqs,) -> (num_freqs, 1)
        # result: (..., num_freqs, 5)
        scaled_x = x.unsqueeze(-2) * freq_bands.unsqueeze(-1)
        # Sine and Cosine
        sin_vals = torch.sin(scaled_x)
        cos_vals = torch.cos(scaled_x)
        # Concatenate along the last dimension
        encoded = torch.cat([sin_vals, cos_vals], dim=-1)
        return encoded

class MultiInputMLP(nn.Module):
    def __init__(self, hidden_dim, num_layers, num_freqs):
        super().__init__()
        self.num_layers = num_layers
        self.hidden_dim = hidden_dim
        self.enc_dim = 2 * num_freqs * 5  # 5D input (3 pos + 2 dir)
        
        # Positional encoding module
        self.pe = PositionalEncoding(num_freqs)
        
        # Layers
        # Layer 1 takes only encoded input
        self.layers = nn.ModuleList()
        
        # First layer: input is encoded input (enc_dim)
        self.layers.append(nn.Linear(self.enc_dim, hidden_dim))
        
        # Intermediate layers: input is encoded input + previous output (enc_dim + hidden_dim)
        for _ in range(num_layers - 2):
            self.layers.append(nn.Linear(self.enc_dim + hidden_dim, hidden_dim))
            
        # Output layer: input is encoded input + previous output
        # Outputs sigma (1) and color (3)
        self.output_layer = nn.Linear(self.enc_dim + hidden_dim, 4) # 1 for sigma, 3 for color
        
        # Initialize weights using PyTorch default (Kaiming uniform/normal)
        self._init_weights()

    def _init_weights(self):
        # PyTorch default initialization is used.
        # The source [S1] states this meets the requirement ||w_i^j1||_1 in (0, 1].
        # No manual initialization needed if relying on PyTorch defaults.
        pass

    def forward(self, x):
        """
        x: (..., 5) tensor containing [x, y, z, dx, dy]
        Returns: sigma (..., 1), color (..., 3)
        """
        # 1. Encode input
        e = self.pe(x)  # (..., enc_dim)
        
        # 2. First layer
        h = self.layers[0](e)
        h = torch.relu(h)
        
        # 3. Intermediate layers
        for i in range(1, self.num_layers - 1):
            # Concatenate encoded input with previous hidden state
            input_concat = torch.cat([e, h], dim=-1)
            h = self.layers[i](input_concat)
            h = torch.relu(h)
            
        # 4. Output layer
        input_concat = torch.cat([e, h], dim=-1)
        out = self.output_layer(input_concat)
        
        sigma = out[..., :1]
        color = out[..., 1:]
        
        return sigma, color
```

## Subtopics

### Separate Density and Color Modeling
A companion technique often used with mi-MLP where density and color are predicted by separate MLPs or branches, allowing different positional encoding frequencies for geometry and appearance [S1].

## Operating characteristics
*   **Time Complexity:** Similar to standard NeRF per forward pass, but slightly higher due to the concatenation of encoded inputs at every layer. The number of parameters is comparable to the baseline if the hidden dimension is kept constant, as the input dimension to each layer increases by $d_{enc}$ [S1].
*   **Memory Complexity:** Slightly higher memory usage during training due to the larger input dimension to each linear layer, but no significant change in inference memory compared to standard NeRF [S1].
*   **Performance:** The method boosts PSNR from 14.73 to 24.23 on few-shot view synthesis benchmarks compared to the baseline [S1]. It achieves state-of-the-art results on a wide range of benchmarks [S1].
*   **Strengths:** Prevents overfitting in few-shot scenarios without reducing model capacity; plug-and-play solution; maintains high-frequency detail synthesis [S1].
*   **Limitations:** Requires careful selection of positional encoding frequencies; relies on specific weight initialization properties for optimal gradient behavior [S1].
*   **When to use:** Few-shot view synthesis where standard NeRF overfits; when model capacity needs to be preserved but overfitting is a concern [S1].
*   **When not to use:** When training on large datasets with many views, where standard NeRF may not overfit and the added complexity is unnecessary [S1].

## Background
The multi-input MLP (mi-MLP) was proposed in the paper "Is Vanilla MLP in Neural Radiance Field Enough for Few-Shot View Synthesis?" [S1]. The authors observed that trivially reducing model parameters alleviates overfitting but harms detail synthesis. They introduced mi-MLP as an orthogonal method from the perspective of network structure, incorporating inputs into each layer to prevent overfitting without harming detailed synthesis [S1]. The method was shown to significantly improve PSNR on few-shot view synthesis tasks [S1].
