# Position Encoding

Also called: Frequency Position Encoding, Sine/Cosine Encoding

## Overview
Position Encoding (PE) is a feature mapping technique that transforms low-frequency coordinate representations into high-frequency information using sine and cosine functions, thereby increasing dimensionality to help deep networks approximate high-frequency functions and prevent the loss of high-frequency spatial information [S1]. It sets itself apart from its siblings by serving as the foundational explicit encoding scheme for NeRF, whereas alternatives like Frequency-Modulated Position Encoding or Random Offset Annealed Fourier Encoding introduce stochasticity, modulation, or local affine transformations to address specific limitations such as spectral bias or domain shift [S1].

## How it works
**Inputs and Outputs:**
The method takes a query point coordinate vector $\mathbf{x} \in \mathbb{R}^3$ (position) and a camera viewing direction vector $\mathbf{d} \in \mathbb{R}^3$ as input [S1]. It outputs a high-dimensional encoded vector resulting from the application of the encoding function $\gamma(\cdot)$ to $\mathbf{x}$ and $\mathbf{d}$, which is then concatenated and passed to a fully-connected MLP [S1].

**Data Structures:**
The encoding relies on an encoding level parameter $L$, representing the number of frequency bands [S1]. In the standard NeRF configuration, $L=10$ for position $\mathbf{x}$ and $L=4$ for direction $\mathbf{d}$ [S1].

**Formulas:**
The encoding function $\gamma: \mathbb{R} \to \mathbb{R}^{2L}$ is defined as [S1]:
$$
\gamma(p) = (\sin(2^0 \pi p), \cos(2^0 \pi p), \dots, \sin(2^{L-1} \pi p), \cos(2^{L-1} \pi p))
$$
The final encoded feature vector is computed by applying $\gamma$ separately to each of the three components of $\mathbf{x}$ and $\mathbf{d}$, and then feeding the result into a regular MLP $F_{\Theta'}$ [S1]:
$$
F_\Theta = F_{\Theta'} \circ \gamma
$$
where $\circ$ denotes the composition of the mapping $\gamma$ with the MLP $F_{\Theta'}$ [S1]. The MLP architecture typically consists of two branches: a density branch that processes the encoded position features to predict volume density $\sigma$, and a color branch that processes the encoded direction features concatenated with intermediate features from the density branch to predict RGB color $\mathbf{c}$ [S1].

**Parameters:**
*   $L_x = 10$: Encoding levels for position [S1].
*   $L_d = 4$: Encoding levels for direction [S1].

**Numbered Steps:**
1.  Compute the frequency scaling factors $2^l \pi$ for $l = 0, \dots, L-1$.
2.  For each coordinate component $p \in \{x_1, x_2, x_3, d_1, d_2, d_3\}$, evaluate $\sin(2^l \pi p)$ and $\cos(2^l \pi p)$ for all $l$.
3.  Concatenate the resulting $2L$ values for each component to form the encoded vectors for position and direction.
4.  Concatenate the position and direction encoded vectors and pass them to the MLP branches (density for position, color for direction) [S1].

**Pseudocode:**
```python
import math

def position_encoding(p, L):
    """
    Applies the standard NeRF position encoding to a scalar or vector p.
    
    Args:
        p (float or list of floats): Input coordinate(s).
        L (int): Number of frequency bands.
        
    Returns:
        list: Encoded vector of size 2 * L * len(p).
    """
    encoded = []
    if isinstance(p, (int, float)):
        p = [p]
    
    for coord in p:
        for l in range(L):
            freq = (2 ** l) * math.pi
            encoded.append(math.sin(freq * coord))
            encoded.append(math.cos(freq * coord))
    return encoded

def nerf_encode(x, d, L_x=10, L_d=4):
    """
    Encodes position x and direction d for NeRF.
    
    Args:
        x (list of 3 floats): 3D position coordinates.
        d (list of 3 floats): 3D viewing direction vector.
        L_x (int): Encoding levels for position.
        L_d (int): Encoding levels for direction.
        
    Returns:
        list: Concatenated encoded vector for x and d.
    """
    enc_x = position_encoding(x, L_x)
    enc_d = position_encoding(d, L_d)
    return enc_x + enc_d
```

**Edge Cases and Pitfalls:**
*   **Spectral Bias:** Deep networks tend to focus on learning low-frequency functions while losing high-frequency information; PE explicitly injects high frequencies to mitigate this [S1].
*   **Precision:** High-frequency components $2^{L-1}$ can cause numerical instability or overflow if input coordinates are not normalized, requiring careful scaling or clamping [G].
*   **Degenerate Input:** Zero or near-zero direction vectors should be normalized before encoding to avoid undefined behavior in downstream ray sampling [G].

## Subtopics

### [Positional Encoding Unit (PEU)](21626-positional-encoding-unit-peu.md)
A specialized hardware accelerator designed to compute feature mapping functions for neural radiance fields by performing inner product operations with vector sizes $R=3$ and $R=6$. It differs from software-based implementations by offloading the matrix multiplication and trigonometric evaluation to dedicated logic, supporting isotropic and anisotropic random Fourier features. ## Operating characteristics
*   **Time Complexity:** The encoding step is $O(L \cdot D)$, where $L$ is the number of frequency bands and $D$ is the dimensionality of the input (3 for position, 3 for direction) [G]. This is negligible compared to the MLP evaluation.
*   **Memory Complexity:** The memory footprint for the encoding parameters is minimal, as the frequencies are fixed constants. The output vector size is $2 \cdot L \cdot D$, which for standard NeRF ($L_x=10, L_d=4, D=3$) results in a vector of size 72 [G].
*   **Strengths:** Simple to implement, fully differentiable, and effective at mitigating spectral bias in MLPs by expanding the frequency spectrum [S1].
*   **Limitations:** Fixed frequency bands may not be optimal for all scenes; high frequencies can be difficult to optimize without careful initialization or optimization strategies [S1].
*   **When to Use:** Standard NeRF training and rendering where high-frequency spatial details must be preserved [S1].
*   **When Not to Use:** Not given in the sources.

## Background
NeRF employs PE as a specialized mapping technique to transform low-frequency coordinate representations into high-frequency information, addressing the tendency of deep networks to learn low-frequency functions and lose high-frequency spatial information [S1]. The technique maps coordinates to a higher-dimensional space using multi-period sine and cosine functions with exponentially increasing frequencies [S1].
