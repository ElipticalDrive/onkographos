# NeRF-GT Baseline Training Setup

Also called: NeRF-GT

## Overview
The NeRF-GT baseline establishes a standard training configuration for Neural Radiance Fields (NeRF) to serve as a reproducible reference point for comparison in radiance field optimization [S2, S2, unofficial]. It defines specific hyperparameters for sampling, batching, and iteration counts to ensure convergence on standard test scenes [S2, S2, unofficial]. Unlike variants that optimize for high dynamic range or generalization, this setup focuses on the canonical volume rendering pipeline with fixed resolution and sample counts [S1][S2, S2, unofficial].

## How it works
The method implements the standard NeRF training loop with specific hyperparameter constraints derived from the original implementation's recommended configuration [S2, S2, unofficial].

**Inputs and Outputs**
*   **Input:** A set of calibrated training images with known camera poses.
*   **Output:** A trained neural radiance field model (MLP and positional encoding parameters).

**Data Structures**
*   **Ray Batch:** A collection of 2,048 rays [S2, S2, unofficial].
*   **Sampling Points:**
    *   Coarse phase: 64 samples per ray [S2, S2, unofficial].
    *   Fine phase: 128 samples per ray [S2, S2, unofficial].
*   **Resolution:** 800 × 600 pixels [S2, S2, unofficial].

**Steps**
1.  **Initialization:** Initialize the NeRF model parameters.
2.  **Ray Sampling:** For each training iteration, randomly sample 2,048 rays from the training views [S2, S2, unofficial].
3.  **Coarse Volume Rendering:**
    *   Sample 64 points along each ray [S2, S2, unofficial].
    *   Query the NeRF for volume density ($\sigma$) and view-dependent color ($c$) at each point.
    *   Compute the coarse color $C_c$ using standard volume rendering integration [S2, S2, unofficial].
4.  **Fine Volume Rendering:**
    *   Sample 128 points along each ray, typically using importance sampling based on the coarse density [S2, S2, unofficial].
    *   Query the NeRF for $\sigma$ and $c$ at these fine points.
    *   Compute the fine color $C_f$ [S2, S2, unofficial].
5.  **Loss Computation:** Compare the rendered fine color $C_f$ against the ground truth pixel color $C_{gt}$ using a loss function (typically Mean Squared Error) [S2, S2, unofficial].
6.  **Optimization:** Update model parameters using gradient descent [S2, S2, unofficial].
7.  **Termination:** Repeat steps 2–6 for 200,000 solver steps [S2, S2, unofficial].

**Parameters**
*   **Batch Size:** 2,048 rays [S2, S2, unofficial].
*   **Coarse Samples:** 64 [S2, S2, unofficial].
*   **Fine Samples:** 128 [S2, S2, unofficial].
*   **Max Iterations:** 200,000 [S2, S2, unofficial].
*   **Resolution:** 800 × 600 [S2, S2, unofficial].

**Edge Cases and Pitfalls**
*   **Convergence:** The method relies on stopping after a fixed number of iterations (200,000) rather than a validation metric, which may lead to overfitting or underfitting depending on scene complexity [S2, S2, unofficial].
*   **Performance:** The fixed batch size and sample counts result in significant training time per iteration [S2, S2, unofficial].

## Subtopics

### NeRF Baseline
The NeRF Baseline refers to the standard configuration described above, serving as the primary reference for evaluating other methods [S2, S2, unofficial]. It is chosen when a direct comparison to the original NeRF implementation is required [S2, S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Training time is approximately 0.40 seconds per iteration [S2, S2, unofficial].
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Rendering time is approximately 32 seconds per frame [S2, S2, unofficial].
*   **Strengths:** Provides a consistent, reproducible baseline for comparing novel radiance field methods [S2, S2, unofficial].
*   **Limitations:** High iteration count (200,000) and per-iteration cost (0.40s) make training computationally expensive compared to some meta-learning approaches [S2, S2, unofficial].
*   **When to use:** When establishing a standard for comparison in radiance field research [S2, S2, unofficial].
*   **When not to use:** When real-time rendering or rapid convergence is required [S2, S2, unofficial].

## Background
The NeRF-GT baseline is based on the original NeRF paper [S2, S2, unofficial]. The specific hyperparameters (64/128 samples, 2048 batch size, 200,000 iterations) were derived from the `config_fern.txt` configuration provided by the original authors [S2, S2, unofficial]. The performance metrics (0.40s/iteration, 32s/frame) were measured in a study evaluating fast training methods for Neural Lumigraph Representations [S2, S2, unofficial].
