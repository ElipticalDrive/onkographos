# HumanNeRF-SE


## Overview
HumanNeRF-SE synthesizes novel pose images of humans from monocular video inputs by combining explicit SMPL shape priors with an implicit NeRF representation [S1]. It avoids the overfitting and high computational complexity of previous methods by using frozen SMPL blending weights for rigid deformation and a sparse voxel volume to filter irrelevant sampling points [S1]. Unlike siblings [HumanNeRF](13842-humannerf.md) and [Unified Volumetric Avatar (UVA)](13784-unified-volumetric-avatar-uva.md) which often rely on learnable weight volumes or frame-level features, HumanNeRF-SE uses only point-level spatial-aware features to ensure pose generalization [S1].

## How it works
**Inputs:** Monocular video frames $\{I_n\}$, corresponding SMPL mesh vertices $v$ and pose parameters $J$ for each frame.
**Outputs:** Synthesized images $C(r)$ for arbitrary viewpoints and poses.

**Data Structures:**
*   **Voxel Volume $V$:** A sparse 3D grid. Each voxel containing SMPL vertices stores a tuple $(n_v, w_1, \dots, w_{24})$, where $n_v$ is the count of vertices in the voxel and $w_j$ are the Linear Blending Skinning (LBS) weights from SMPL [S1]. Empty voxels store $(0, 0, \dots, 0)$ [S1].
*   **Spatial-Aware Features $F_s$:** The result of convolving $V$, containing features for each voxel [S1].

**Algorithm Steps:**

1.  **Voxelization:**
    Calculate the bounding box of SMPL vertices $v$ (min/max coordinates). Scale the bounding box to a target voxel size $v_s$. Find the least common multiple of the axes dimensions and 32 to prepare for sparse convolution [S1]. Scale each vertex $v$ by subtracting the minimum coordinate and dividing by $v_s$. Construct the voxel volume $V$ using sparse convolution $Sp$:
    $$ V = Sp(v, v_s, W) $$
    [S1]

2.  **Conv-Filter (Feature Extraction and Point Filtering):**
    Initialize a convolution kernel to one. Perform channel-by-channel convolution on $V$ to obtain spatially-aware features $F_s$. For a voxel at position $(h, w, d)$, the $i$-th channel of $F_s$ is computed as [S1]:
    $$ F_{s,i} = \sum_{m=h-k}^{h'} \sum_{n=w-k}^{w'} \sum_{t=d-k}^{d'} \nu_{m,n,t,i} \cdot \vartheta_{m,n,t,i}' $$
    where $\nu$ is the voxel value, $\vartheta$ is the kernel weight, and $k$ is the kernel size [S1].
    Query the occupancy of $F_s(x)$ for each sampling point $x$. If $F_s(x) = 0$, the point is irrelevant ($x_o$) and its density is forced to 0. If $F_s(x) > 0$, the point is human-related ($x_r$) and remains [S1]:
    $$
    \begin{cases}
    x_o \text{ filtered out}, d(x_o) = 0 & \text{if } F_s(x) = 0 \\
    x_r \text{ remain} & \text{if } F_s(x) > 0
    \end{cases}
    $$
    [S1]

3.  **Point Canonicalization (Rigid Deformation):**
    Query the nearest neighbor SMPL weights $W_{smpl}$ for the remaining points $x_r$ using a function $K(x, v)$ [S1]. Compute the rigid deformation $x_{rcnl}$ using the frozen SMPL blending weights $w_j$ and the current pose joints $J$ relative to the T-pose joints (rotation $R_j$, translation $T_j$) [S1]:
    $$ x_{rcnl} = \sum_{j \in J} w_j ((x_r \cdot R_j) + T_j) $$
    [S1]

4.  **Point Canonicalization (Non-Rigid Refinement):**
    Refine the coarse coordinates $x_{rcnl}$ using a network $P$ conditioned on the point-level spatial-aware features $F_s$ and the points $x_r$ [S1]. This accounts for non-rigid clothing deformation which rigid LBS ignores [S1]:
    $$ x_{cnl} = x_{rcnl} + P(F_s, x_r) $$
    [S1]

5.  **Appearance Net and Rendering:**
    Encode the canonical coordinates $x_{cnl}$ using positional encoding (same as standard NeRF) [S1]. Pass through an MLP $M_\sigma$ to output color $c$ and density $\sigma$ [S1]:
    $$ c, \sigma = M_\sigma(x_{cnl}) $$
    [S1]
    Render the image using volume rendering. For a ray $r$ with $N_s$ samples $x_i$:
    $$ \alpha_i = 1 - \exp(-\sigma(x_i) \cdot \Delta t_i) $$
    $$ \tilde{C}_t(r) = \sum_{k=1}^{N_s} \alpha_k c(x_k) \prod_{j=1}^{k-1} (1 - \alpha_j) $$
    [S1]

**Pseudocode:**

```python
def human_nerf_se_train(video_frames, smpl_vertices, smpl_poses, voxel_size):
    # 1. Voxelization
    # Calculate bounding box of smpl_vertices
    min_coord = min(smpl_vertices, axis=0)
    max_coord = max(smpl_vertices, axis=0)
    # Scale vertices to voxel grid
    scaled_vertices = (smpl_vertices - min_coord) / voxel_size
    # Construct sparse voxel volume V with occupancy and LBS weights
    # V contains (n_v, w1...w24) for occupied voxels, (0...0) for empty
    V = sparse_convolution(scaled_vertices, smpl_lbs_weights, voxel_size)
    
    # 2. Conv-Filter
    # Initialize kernel to ones
    kernel = initialize_ones_kernel()
    # Channel-by-channel convolution to get spatial features Fs
    Fs = channel_by_channel_conv(V, kernel)
    
    # 3. Point Canonicalization
    # Sample points x in the volume
    sampling_points = sample_points_in_volume(V)
    
    # Filter points based on Fs occupancy
    human_related_points = []
    for x in sampling_points:
        if Fs.query(x) > 0:
            human_related_points.append(x)
        else:
            # Force density to 0 for filtered points
            set_density_to_zero(x)
            
    # Rigid Deformation using frozen SMPL weights
    canonical_points_rigid = []
    for x in human_related_points:
        # Query nearest SMPL weights
        weights = query_nearest_smpl_weights(x, smpl_vertices)
        # Compute rigid transform based on current pose J
        # J contains rotations R_j and translations T_j relative to T-pose
        x_rcnl = sum(weights[j] * (x * R_j + T_j) for j in joints)
        canonical_points_rigid.append((x, x_rcnl))
        
    # Non-Rigid Refinement
    canonical_points_final = []
    for x, x_rcnl in canonical_points_rigid:
        # Get spatial features for x
        features = Fs.query(x)
        # Refine using point-level network P
        x_cnl = x_rcnl + P_refine(features, x)
        canonical_points_final.append((x, x_cnl))
        
    # 4. Appearance Net
    # Encode canonical coordinates
    encoded_points = positional_encoding(canonical_points_final)
    # Predict color and density
    colors, densities = mlp_appearance(encoded_points)
    
    # 5. Rendering and Loss
    # Render image from rays
    rendered_image = volume_render(rays, colors, densities)
    
    # Compute Loss
    # L = L_LPIPS + lambda * L_MSE
    # L_MSE = mean((rendered_image - ground_truth)^2)
    # L_LPIPS = l_pips(foreground_mask(rendered_image), foreground_mask(ground_truth))
    loss = compute_loss(rendered_image, video_frames)
    
    return loss
```

**Parameters:**
*   $v_s$: Voxel size used to scale the bounding box of the SMPL model [S1].
*   $\lambda$: Weight for the MSE loss term in the total loss function [S1].
*   SMPL Blending Weights: Frozen from the pre-trained SMPL model; not fine-tuned [S1].

**Edge Cases and Pitfalls:**
*   **Overfitting:** Learning blending weights from scratch or fine-tuning SMPL weights leads to overfitting on limited input data, causing artifacts in novel poses [S1]. HumanNeRF-SE avoids this by using frozen SMPL weights [S1].
*   **Irrelevant Points:** Simply using nearest SMPL vertex blending weights fills the sampling space with incorrect colors because training deforms irrelevant sampling points onto the human body [S1]. The Conv-Filter step is critical to remove these points [S1].
*   **Non-Rigid Deformation:** Direct nearest weight rigid deformation ignores non-rigid clothing deformation [S1]. The point-level refinement $P(F_s, x_r)$ is required to solve this [S1].
*   **Pose Leakage:** In datasets like ZJU-MOCAP, action repetition can cause pose leakage. Mitigated by using few-shot training (30 frames) and in-the-wild diverse action videos for evaluation [S1].
*   **Alpha Map Errors:** If points are not filtered, learning the correct alpha map is difficult due to color diffusion into surrounding space, increasing computational complexity and training time [S1].

## Operating characteristics
*   **Complexity:** Reduces required sampling points from ~300K to less than 100K [S1]. Uses less than 1% of learnable parameters compared to previous methods [S1].
*   **Performance:** Reduces training time by 95% (or to 1/20 of previous methods) [S1]. Increases rendering speed by 15 times without using existing acceleration modules [S1].
*   **Metrics (ZJU-MOCAP few-shot):** PSNR=31.09, SSIM=0.974, LPIPS=24.085 [S1].
*   **Comparison:** Outperforms HumanNeRF (PSNR=30.10, SSIM=0.9677, LPIPS=33.056) and MonoHuman (PSNR=30.11, SSIM=0.9684, LPIPS=32.084) [S1].
*   **Strengths:** Generalizes to diverse poses with few-shot input; avoids overfitting; efficient computation [S1].
*   **Limitations:** Relies on the accuracy of the SMPL model and its pre-trained weights; performance may degrade if the input human significantly deviates from the SMPL shape prior [S1].

## Background
HumanNeRF-SE was introduced in 2024 by Miles et al. [S1]. It addresses the limitations of previous NeRF-based human avatars that require large numbers of optimizable parameters and multi-camera data [S1]. The method builds on the insight that explicit shape priors (SMPL) can reduce sampling complexity and that frozen blending weights prevent overfitting [S1]. It is designed for monocular input scenarios where multi-camera data is unavailable [S1].
