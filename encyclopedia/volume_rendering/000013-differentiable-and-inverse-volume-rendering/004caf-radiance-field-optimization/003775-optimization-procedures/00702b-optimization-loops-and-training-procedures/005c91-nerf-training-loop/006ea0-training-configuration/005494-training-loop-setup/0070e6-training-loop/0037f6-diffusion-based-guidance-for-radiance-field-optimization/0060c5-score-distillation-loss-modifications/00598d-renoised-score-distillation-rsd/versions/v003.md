# Renoised Score Distillation (RSD)


## Overview
Renoised Score Distillation (RSD) is a score-distillation objective designed for 2D image resolution and super-resolution, specifically within the context of refining latent vectors during the upscaling stage of iterative 3D synchronization [S1]. It combines features from ancestral sampling and Score Distillation Sampling (SDS) to generate sharp, high-resolution images that remain consistent with low-resolution (LR) conditioning [S1]. Unlike standard SDS, which optimizes in the $z_0$ space and often produces limited details, or ancestral sampling, which can generate details structurally inconsistent with the LR input, RSD guides the optimization towards intermediate denoised latents $z_{t-1}$ over a linearly decreasing time schedule [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A base latent $z_0$ (encoded from a 4× interpolated low-resolution image), text prompt embeddings $y_{text}$, noise level conditioning $y_{noise\_level}$, LR image conditioning $I_{lr}$, minimum timestep $t_{min}$, maximum timestep $t_{max}$, and the number of super-resolution iterations $max\_sr\_iter$ [S1].
*   **Outputs:** Refined latent residuals $h_\theta$ [S1].

**Data Structures:**
*   $h_\theta$: Learnable latent residuals, initialized to zero with the same shape as $z_0$ [S1].
*   $z'_0$: Refined latent, defined as $z_0 + h_\theta$ [S1].
*   $z'_t, z'_{t-1}$: Noised latents at timesteps $t$ and $t-1$ derived from $z'_0$ [S1].
*   $\hat{\epsilon}_\phi$: Predicted noise residual from the UNet backbone of the diffusion model (parameterized by $\phi$) [S1].
*   $\hat{z}_{t-1}$: Predicted denoised latent at timestep $t-1$ [S1].

**Parameters:**
*   **Scheduler:** DDPM scheduler [S1].
*   **Time Schedule:** Linearly decreasing from $t_{max}$ to $t_{min}$ over the course of optimization [S1].
*   **Patch Sampling:** Uniform random crops of $128 \times 128$ resolution in latent space (corresponding to $512 \times 512$ image patches) are used for optimization [S1].
*   **Text Prompt:** Fixed prompt format: `"<subject>, high resolution, 4K, photo"` [S1].
*   **Learning Rate:** Constant $1 \times 10^{-2}$ [S1].

**Formulas:**
The forward noising process (Eq. 1 in [S1]) is:
$$ z'_t = \sqrt{\bar{\alpha}_t} z'_0 + \sqrt{1 - \bar{\alpha}_t} \epsilon $$
where $\epsilon \sim \mathcal{N}(0, I)$ [S1].

The predicted denoised latent $\hat{z}_{t-1}$ is constructed using the DDPM reverse process (Eq. 3 in [S1]):
$$ \hat{z}_{t-1} = \sqrt{\frac{1}{\bar{\alpha}_t}} \left( z'_t - \sqrt{1 - \bar{\alpha}_t} \hat{\epsilon}_\phi(z'_t, y, t) \right) + \sigma_t \epsilon $$
where $\sigma_t$ is the standard deviation of Gaussian noise samples [S1].

The RSD loss (Eq. 7 in [S1]) is the L1 error between the current noised latent at $t-1$ and the predicted denoised latent:
$$ L_{RSD} = \| z'_{t-1} - \hat{z}_{t-1} \| $$
Gradients are backpropagated through $z'_{t-1}$ towards $h_\theta$ [S1].

**Numbered Steps:**
1.  Initialize learnable latent residuals $h_\theta = 0$ with the same shape as $z_0$ [S1].
2.  Loop for $sr\_iter$ from $0$ to $max\_sr\_iter$:
    a. Sample noise $\epsilon \sim \mathcal{N}(0, I)$ [S1].
    b. Construct conditioning $y = y_{text} + y_{noise\_level} + I_{lr}$ [S1].
    c. Calculate current timestep $t$ using a linearly decreasing schedule:
       $$ t = t_{max} - (t_{max} - t_{min}) \frac{sr\_iter}{max\_sr\_iter} $$
       [S1].
    d. Calculate refined latent $z'_0 = \sqrt{z_0 + h_\theta}$ [S1].
    e. Calculate noised latents $z'_t$ and $z'_{t-1}$ using the forward process:
       $$ z'_t = \sqrt{\bar{\alpha}_t} z'_0 + \sqrt{1 - \bar{\alpha}_t} \epsilon $$
       $$ z'_{t-1} = \sqrt{\bar{\alpha}_{t-1}} z'_0 + \sqrt{1 - \bar{\alpha}_{t-1}} \epsilon $$
       [S1].
    f. Pass $z'_t$ and conditioning $y$ to the UNet backbone $\phi$ to predict noise residual $\hat{\epsilon}_\phi(z'_t, y, t)$ [S1].
    g. Construct predicted denoised latent $\hat{z}_{t-1}$ using the DDPM reverse process equation [S1].
    h. Compute the loss $\| z'_{t-1} - \hat{z}_{t-1} \|$ and take a gradient descent step on $\nabla_\theta \| z'_{t-1} - \hat{z}_{t-1} \|$ [S1].
3.  Return refined latent residuals $h_\theta$ [S1].

**Pseudocode:**
```python
def RSD(z0, y_text, y_noise_level, I_lr, t_min, t_max, max_sr_iter):
    """
    Implements Renoised Score Distillation (RSD) for latent refinement.
    
    Args:
        z0: Base latent encoded from 4x interpolated LR image.
        y_text: Text prompt embeddings.
        y_noise_level: Noise level conditioning.
        I_lr: Low-resolution image conditioning.
        t_min: Minimum timestep.
        t_max: Maximum timestep.
        max_sr_iter: Number of super-resolution iterations.
        
    Returns:
        h_theta: Refined latent residuals.
    """
    # Initialize learnable latent residuals to zero
    h_theta = torch.zeros_like(z0)
    
    for sr_iter in range(max_sr_iter):
        # Sample noise
        epsilon = torch.randn_like(z0)
        
        # Construct conditioning
        y = y_text + y_noise_level + I_lr
        
        # Calculate timestep t using linearly decreasing schedule
        t = t_max - (t_max - t_min) * (sr_iter / max_sr_iter)
        
        # Calculate refined latent z0'
        # Note: Source uses sqrt(z0 + h_theta), which implies element-wise sqrt of the sum.
        # However, standard latent addition is z0 + h_theta. 
        # The source text says "z0' = sqrt(z0 + h_theta)" in the step list, 
        # but Eq 8 says "z0' = z0 + h_theta". 
        # Given Eq 8 is explicit and Eq 1 uses z0', we follow Eq 8 for z0' definition.
        # The "sqrt" in the step list likely refers to the noising formula components or is a typo for the noising step.
        # We follow Eq 8: z0' = z0 + h_theta.
        z0_prime = z0 + h_theta
        
        # Calculate noised latents zt' and zt-1' using forward process (Eq 1)
        # alpha_bar_t is precomputed for timestep t
        zt_prime = torch.sqrt(alpha_bar_t) * z0_prime + torch.sqrt(1 - alpha_bar_t) * epsilon
        zt_minus_1_prime = torch.sqrt(alpha_bar_t_minus_1) * z0_prime + torch.sqrt(1 - alpha_bar_t_minus_1) * epsilon
        
        # Predict noise residual using UNet
        epsilon_phi = UNet(z=zt_prime, y=y, t=t)
        
        # Construct predicted denoised latent zt-1 (Eq 3)
        # sigma_t is the standard deviation of Gaussian noise samples for timestep t
        zt_minus_1_hat = (1 / torch.sqrt(alpha_bar_t)) * (zt_prime - torch.sqrt(1 - alpha_bar_t) * epsilon_phi) + sigma_t * epsilon
        
        # Compute loss and backpropagate
        # Loss is L1 error between zt-1' and zt-1_hat
        loss = torch.norm(zt_minus_1_prime - zt_minus_1_hat, p=1)
        
        # Take gradient descent step on h_theta
        # Gradients flow through zt_minus_1_prime (which depends on z0_prime -> h_theta)
        # and zt_minus_1_hat (which depends on epsilon_phi -> zt_prime -> z0_prime -> h_theta)
        loss.backward()
        
        # Update h_theta
        # Note: In a real implementation, an optimizer step would be called here.
        # The source says "Take gradient descent step", implying an optimizer update.
        # We assume a standard optimizer step is performed.
        optimizer.step()
        optimizer.zero_grad()
        
    return h_theta
```

**Edge Cases and Pitfalls:**
*   **Inconsistency:** Default ancestral sampling can generate details structurally inconsistent with the conditioned LR image, aggravating multi-view inconsistency [S1]. RSD mitigates this by enforcing LR consistency [S1].
*   **Detail Limitation:** SDS produces LR-consistent features but with limited details [S1]. RSD addresses this by incorporating ancestral sampling elements [S1].
*   **Implementation Note:** In practice, $\hat{z}_{t-1}$ can be obtained directly from $\hat{\epsilon}_\phi(z_t, y, t)$ using the DDPM denoising equation instead of re-noising $\hat{z}_0$ [S1].

## Operating characteristics
*   **Time Complexity:** The optimization time is longer than standard NeRF training due to the RSD optimization steps, but faster than DreamFusion-SDS because I3DS segregates upscaling and synchronization stages [S1].
*   **Memory Complexity:** Uses patch sampling ($128 \times 128$ latent space crops) to optimize memory usage and speed compared to full image optimization [S1].
*   **Performance:** RSD produces sharper details compared to SDS while maintaining LR-consistent features compared to ancestral sampling [S1].
*   **Strengths:** Generates sharp, high-resolution images consistent with low-resolution conditioning; alleviates the need for high-resolution reference images [S1].
*   **Limitations:** Requires multiple stages (upscaling and synchronization) and more optimization time than basic NeRF training [S1].

## Background
Renoised Score Distillation (RSD) was introduced in the paper "DiSR-NeRF: Diffusion-Guided View-Consistent Super-Resolution NeRF" [S1]. It was developed to address the limitations of existing super-resolution methods for NeRFs, specifically the trade-off between detail sharpness and multi-view consistency. The method is a core component of the Iterative 3D Diffusion Super-Resolution (I3DS) framework, which alternates between upscaling low-resolution rendered images with diffusion models and updating the underlying 3D representation with standard NeRF training [S1].
