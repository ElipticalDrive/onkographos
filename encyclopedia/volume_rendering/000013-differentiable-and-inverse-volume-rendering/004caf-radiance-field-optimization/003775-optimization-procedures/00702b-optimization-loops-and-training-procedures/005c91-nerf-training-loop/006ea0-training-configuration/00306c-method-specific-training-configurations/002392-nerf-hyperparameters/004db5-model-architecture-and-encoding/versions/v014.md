# Model Architecture and Encoding


## Overview
This family defines the neural network topologies, feature encoding schemes, and data structures used to represent the radiance field $\Phi(\mathbf{x}, \mathbf{d}) = (\sigma, \mathbf{c})$. It addresses the trade-off between representational capacity, training convergence speed, and memory efficiency. It distinguishes itself from sibling methods like [NeRF Initialization Strategies](8674-nerf-initialization-strategies.md) by focusing on the structural definition of the model (MLPs, grids, tensors) rather than the parameter initialization values, and from [Model Architecture Modifications](11313-model-architecture-modifications.md) by encompassing the core encoding mechanisms (positional, hash, triplane) that define the base representation.

## Shared principles
All methods in this family map a 3D spatial coordinate $\mathbf{x} \in \mathbb{R}^3$ and a viewing direction $\mathbf{d} \in S^2$ to a volume density $\sigma \in \mathbb{R}_{\ge 0}$ and an RGB color vector $\mathbf{c} \in [0, 1]^3$. The mapping is typically decomposed into two networks: a density network $f_\sigma(\mathbf{x})$ and a color network $f_\mathbf{c}(\mathbf{x}, \mathbf{d})$. The density network outputs raw density, which is often activated via Softplus or Exponential to ensure positivity. The color network takes features derived from $\mathbf{x}$ and the direction $\mathbf{d}$ to predict color. The core architectural choice lies in how $\mathbf{x}$ and $\mathbf{d}$ are encoded and how the feature space is structured (e.g., dense MLP weights, sparse hash grids, or low-rank tensors).

## Subtopics

### [Depth-Guided NeRF Training Configuration](11916-depth-guided-nerf-training-configuration.md)
This configuration modifies the standard NeRF MLP architecture by adding dropout layers to the density network and introducing a learnable depth scale parameter [11916-depth-guided-nerf-training-configuration.md]. It is distinguished from sibling methods by its explicit integration of depth supervision losses (using Earth Mover’s Distance or L1/L2) rather than semantic or generative constraints, and it maintains a continuous density representation unlike [Binary Radiance Fields](13622-binary-radiance-fields.md).

### [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md)
This configuration freezes the density parameters of the NeRF MLP and optimizes only the color/feature networks to enforce stylistic trajectories defined by CLIP embeddings [12073-clipnerf-training-configuration.md]. It distinguishes itself from standard reconstruction by using directional CLIP loss (absolute or relative) and patch-based rendering to manage memory, rather than optimizing for photometric accuracy of the original scene geometry.

### [Binary Radiance Fields](13622-binary-radiance-fields.md)
Binary Radiance Fields (BiRF) constrains all feature grid parameters in a multi-resolution 2D-3D hybrid hash encoding to binary values $\{-1, +1\}$ [13622-binary-radiance-fields.md]. It differs from real-valued grid methods by using a Straight-Through Estimator (STE) for gradients during training, achieving compact storage (<0.5 MB for small variants) while maintaining reconstruction quality via a specific sparsity loss (Cauchy loss) and hybrid grid structure (3D voxels + 2D planes).

### [Mip-NeRF 360 MLP Architecture](14098-mip-nerf-360-mlp-architecture.md)
The Mip-NeRF 360 architecture replaces standard positional encoding with **integrated positional encoding** to analytically integrate the encoding function over conical frustums, solving aliasing and high-frequency detail loss [14098-mip-nerf-360-mlp-architecture.md]. It is distinguished by its use of integrated encoding for density inputs, optional Integrated Directional Encoding (IDE) for view-dependent effects, and a specific skip-connection topology (e.g., skip connections every 4 layers) and biasing strategies (e.g., density bias of -1.0).

### SUDS
SUDS factorizes the scene into three separate multi-resolution hash table structures: static, dynamic, and far-field [14964-suds.md]. It enables 4D radiance field representation for large-scale dynamic scenes using only unlabeled inputs. It differs from sibling methods by using spatial partitioning and explicit shadow modeling to disentangle static background from dynamic foreground without manual annotation, and by using video IDs as auxiliary inputs to hash functions to index separate interpolating functions per video.

### CCNeRF
CCNeRF models the radiance field entirely through tensor rank decomposition (Tucker or CP), avoiding neural networks for the final rendering step [15008-ccnerf.md]. Unlike NeRF variants that rely on a shared MLP renderer, CCNeRF uses factor matrices/vectors and a weight matrix to compute rendering via algebraic operations. It allows arbitrary composition of objects and dynamic level-of-detail adjustment via rank truncation without retraining.

### [Rip-NeRF](15532-rip-nerf.md)
Rip-NeRF combines cone casting with anisotropic 3D Gaussian characterization to render high-fidelity, anti-aliased images [15532-rip-nerf.md]. It differs from sibling methods like Zip-NeRF by using Ripmap-Encoded Platonic Solids (e.g., icosahedron) for efficient anisotropic area-sampling. It projects 3D Gaussians onto the faces of a Platonic solid, queries features from a hierarchical Ripmap grid via tetra-linear interpolation, and aggregates them through a tiny MLP.

### [UE4-NeRF](15539-ue4-nerf.md)
UE4-NeRF partitions the environment into sub-NeRFs represented as textured polygonal meshes (regular octahedra) deployed in Unreal Engine 4 [15539-ue4-nerf.md]. It solves real-time rendering limitations by integrating a learned neural shader (HLSL fragment shader) into the rasterization pipeline. It uses a grid-based initialization ($128^3$) and multi-resolution hash encoding for training, optimizing vertex positions continuously, and achieves real-time 4K performance by using LOD meshes for different observation heights.

### [Generative Occupancy Fields (GOF)](15773-generative-occupancy-fields-gof.md)
GOF combines radiance fields with occupancy representations to learn compact object surfaces without impeding training convergence [15773-generative-occupancy-fields-gof.md]. It solves the problem of diffused surfaces in standard generative radiance fields by predicting alpha values $\alpha$ directly (reinterpreted as occupancy) and using root-finding (secant method) to locate the surface. It transitions from cumulative volume rendering to surface-point rendering, using a shrinking sampling region during training.

### [Panoptic Radiance Field](15849-panoptic-radiance-field.md)
Panoptic Radiance Field lifts noisy 2D panoptic segmentation masks into a consistent 3D representation of color, density, semantics, and instances [15849-panoptic-radiance-field.md]. It differs from sibling methods by requiring no manual ground truth (such as coarse meshes), relying instead on pre-trained 2D segmentation networks. It uses a TensoRF-like representation for density/color and separate small MLPs for semantic and instance fields, with gradient blocking to prevent noisy labels from corrupting geometry.

#### Triplane NeRF with Diffusion Prior
- **Definition:** A framework using a triplane NeRF representation where scene codes are optimized jointly with a diffusion prior to handle sparse-view data and ensure end-to-end coherence [S1].
- **Parameters:** Uses v-parameterization $\hat{v}_\phi(x(t), t)$ such that $\hat{x} = \alpha(t)x(t) - \sigma(t)\hat{v}$. Uses SNR-based weighting $w(t) = (\alpha(t)/\sigma(t))^2\omega$ in the diffusion loss [S1].
- **Layout:** Scene code $x_i \in \mathbb{R}^{3 \times 6 \times 128 \times 128}$. Denoising network is a U-Net with 122M parameters, taking noisy/denoised triplane features with stacked channels [S1].

#### EG3D Triplane Representation
- **Steps:** Renders feature image $I_f \in \mathbb{R}^{32 \times 128 \times 128}$ and raw RGB image $I_{128} \in \mathbb{R}^{3 \times 128 \times 128}$ via volume rendering. Extracts dense depth map $I_D \in \mathbb{R}^{128 \times 128}$. Feeds $I_f$ and $I_{128}$ into a 2D super-resolution network to yield $I_{512} \in \mathbb{R}^{3 \times 512 \times 512}$ [S2].
- **Formula:** $\text{SuperRes}(I_f, I_{128}) = I_{512}$ [S2].
- **Parameters:** Input and output resolution 512x512 [S2].
- **Layout:** Triplane representation $T \in \mathbb{R}^{256 \times 256 \times 96}$, corresponding to 3 axis-aligned planes (xy, xz, yz), each with 32 channels and resolution 256x256 [S2].
- **Number:** Rendering speed 42 fps on RTX 3090 [S2].

#### NeRF-W Hyperparameter Configuration
- **Parameters:** Base MLP: 8 layers of 512 hidden units. Static and Transient/Uncertainty MLPs: 4 layers of 128 hidden units each. Positional encoding frequencies: 15 for position, 4 for viewing direction. Sampling points: 512 per ray per model (coarse and fine) during training (1024 total), doubled to 2048 during evaluation. Appearance embedding dimension $n(a) = 48$. Transient object embedding dimension $n(\tau) = 16$. L1 regularizer multiplier $\lambda_u = 0.01$. Minimum importance threshold $\beta_{min} = 0.03$. Optimizer: Adam, batch size 2048, initial learning rate 0.001, decaying ten-fold every 150,000 iterations, over 300,000 iterations total [S3].
- **Number:** Hyperparameters were optimized for the Brandenburg Gate scene of the Phototourism dataset and reused for remaining scenes [S3].

#### Explicit Mesh Reconstruction from Neural Fields
- **Definition:** An algorithm to extract an explicit 3D mesh representation from the implicit neural radiance field learned by CodeNeRF, allowing for 3D reconstruction from a single input image [S4].
- **Steps:** Feed the center coordinates of a $256^3$ voxel grid to the CodeNeRF MLP to obtain volume density values $\sigma$. Apply the Marching Cubes algorithm to the volume density values $\sigma$ to find mesh vertices. Cast rays along the vertex normals of the generated mesh to associate colors to the vertices [S4].

#### Efficient EndoNeRF scene representation
- **Definition:** A voxel-grids-based scene representation that replaces coordinate-based MLPs with explicit density and feature volume grids to accelerate optimization, combined with a canonical field and time-dependent deformation field for dynamic surgical scenes [S5].
- **Steps:** The dynamic scene at time $t$ is modeled by warping a canonical radiance field (represented by $\mathbf{V}_\sigma$ and $\mathbf{V}_a$) with a time-dependent deformation field. The deformation field is modeled using decomposed 4D motion fields and a 3-layer MLP that maps a spatial-temporal coordinate $(\mathbf{x}, t)$ to a deformation offset $\Delta \mathbf{x}$ [S5].

#### NeRF-Liif
- **Definition:** A baseline method that super-resolves LR images using a pretrained LIIF (Local Implicit Image Function) model, which requires LR-HR pairs for training and introduces external data priors [S6].
- **Parameters:** Training data requirement: LR-HR pairs [S6].
- **Pitfall:** On synthetic Blender dataset, LIIF may produce false predictions due to domain mismatch with its external training set. On real-world LLFF dataset, LIIF tends to be oversmooth and may predict false color or geometry [S6].
- **Number:** Blender ×2 (100x100): PSNR 27.07, SSIM 0.919, LPIPS 0.067. Blender ×4 (100x100): PSNR 25.36, SSIM 0.885, LPIPS 0.125. Blender ×2 (200x200): PSNR 28.81, SSIM 0.934, LPIPS 0.058. Blender ×4 (200x200): PSNR 27.34, SSIM 0.912, LPIPS 0.096. LLFF ×2: PSNR 26.81, SSIM 0.823, LPIPS 0.145. LLFF ×4: PSNR 24.76, SSIM 0.723, LPIPS 0.292 [S6].

#### UniSurf
- **Definition:** A method unifying volume rendering (radiance fields) and surface rendering (implicit surfaces) to achieve high-quality geometry and sharp textures without mask supervision [S7, unofficial].
- **Steps:** Uses an occupancy field where the occupancy at the $i^{th}$ sample corresponds to an indicator of surface presence. Uses volume rendering in the early stage for optimization without mask supervision. Uses surface rendering in the later stage to extract level-set surfaces [S7, unofficial].
- **Comparison:** Unlike pure surface rendering which requires mask supervision and has blurry texture mapping, this method provides high-quality novel views and sharp textures/colors without mask supervision [S7, unofficial].

## Background
The foundational NeRF architecture [Parent] introduced the use of fully connected MLPs with positional encoding for density and color prediction. Subsequent developments focused on efficiency (hash encoding, triplanes), robustness (integrated encoding, binary constraints), and new representations (occupancy, panoptic fields). The field has evolved from dense MLPs to sparse grid-based structures and tensor decompositions to enable real-time rendering and large-scale scene representation.
