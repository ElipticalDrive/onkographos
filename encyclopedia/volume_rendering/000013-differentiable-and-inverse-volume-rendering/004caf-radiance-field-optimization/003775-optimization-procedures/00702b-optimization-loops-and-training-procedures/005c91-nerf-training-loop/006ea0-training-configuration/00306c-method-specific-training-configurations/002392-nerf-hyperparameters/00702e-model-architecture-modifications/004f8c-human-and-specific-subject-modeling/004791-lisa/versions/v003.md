# LISA

Also called: LISA (April 2022)

## Overview
LISA is a part-based implicit neural representation method specifically designed for modeling human hands [S1, S2]. It addresses the complexity of hand geometry by approximating the hand as a collection of rigid parts, leveraging the MANO model for structural priors [S1, S2]. Unlike general body avatars, LISA distinguishes itself by using Signed Distance Fields (SDFs) for shape description and implicitly encoding MANO shape parameters via skeletal posture, while simultaneously learning a color field for realistic appearance [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D query points $\mathbf{x}$, skeletal posture parameters (derived from MANO), and potentially viewing direction for color prediction.
*   **Outputs:** Signed Distance Field (SDF) value for geometry, color $\mathbf{c}$, and hand part decomposition [S1, S2].

**Data Structures:**
*   **MANO Model:** Used as a structural prior. Shape parameters are not explicit inputs but are implicitly described by the skeletal posture [S2].
*   **MLPs:** Multi-Layer Perceptrons used to map query points and posture features to SDF and color values [S1].

**Steps:**
1.  **Part Approximation:** The human hand is approximated as a collection of rigid parts [S1].
2.  **Implicit Shape Encoding:** The shape parameters of the MANO model are implicitly described using the current skeletal posture [S2].
3.  **Geometry Prediction:** Query points $\mathbf{x}$ are input into MLPs. The network predicts the Signed Distance Field (SDF) value, representing the distance from the query point to the hand surface [S1, S2].
4.  **Color Prediction:** Alongside the SDF, the MLPs predict the view-dependent color $\mathbf{c}$ for the query point to achieve realistic appearance [S2].
5.  **Decomposition:** The final prediction includes the decomposition of the hand into its constituent parts [S2].
6.  **Physical Constraints:** To avoid penetration between the decoded hand and interacting objects, physical constraints are introduced into the optimization [S2].

**Formulas:**
*   Let $F_{\Theta}(\mathbf{x}, \text{posture})$ be the network function.
*   Output: $(\text{SDF}, \mathbf{c}) = F_{\Theta}(\mathbf{x}, \text{posture})$ [S1, S2].
*   The SDF represents the distance from $\mathbf{x}$ to the hand surface [S2].

**Parameters:**
*   Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Penetration:** Without physical constraints, the decoded hand may penetrate interacting objects [S2].
*   **Part Boundaries:** As a part-based method, handling boundaries between rigid parts requires careful SDF blending or decomposition logic [S1, S2].

## Background
LISA was introduced in April 2022 [S1]. It emerged in the context of research targeting human avatar modeling, specifically focusing on the challenges of hand animation and novel pose synthesis [S1]. It builds upon the MANO model, which is a popular parametric hand model [S2]. The method is part of the broader trend of using implicit neural representations (like SDFs) for detailed geometry recovery in 3D vision [S1, S2].
