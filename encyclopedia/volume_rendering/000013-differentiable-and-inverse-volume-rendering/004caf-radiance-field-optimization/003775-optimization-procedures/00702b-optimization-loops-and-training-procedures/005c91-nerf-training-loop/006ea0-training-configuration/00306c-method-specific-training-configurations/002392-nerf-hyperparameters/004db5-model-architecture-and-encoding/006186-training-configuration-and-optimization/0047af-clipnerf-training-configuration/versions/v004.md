# CLIPNeRF Training Configuration

Also called: Absolute Directional CLIP Loss, CLIPNeRF Hyperparameters, CLIPNeRF Implementation, Directional CLIP Loss, Relative Directional CLIP Loss, StyleGAN-NADA CLIP Loss

## Overview
CLIPNeRF training configuration defines the optimization procedure for text-guided stylization of Neural Radiance Fields (NeRFs) by minimizing the negative cosine similarity between rendered image features and text prompt embeddings in the CLIP embedding space [S1, S2]. It distinguishes itself from standard NeRF reconstruction by freezing density-related parameters and utilizing a patch-based rendering strategy to manage memory constraints while enforcing stylistic directionality via directional CLIP losses [S1, S2].

## How it works

**Inputs and Outputs**
*   **Inputs:** A pre-trained NeRF model (architecture defined in [Model Architecture and Encoding](13550-model-architecture-and-encoding.md)), a source image $\mathbf{I}_{src}$, a target text prompt $\mathbf{t}_{tgt}$, and optionally a source text prompt $\mathbf{t}_{src}$ for relative loss.
*   **Outputs:** A stylized NeRF model where the radiance field reflects the style described by $\mathbf{t}_{tgt}$.

**Data Structures**
*   **CLIP Encoder:** Uses CLIP ViT-B/32 [S1]. The text encoder $\mathcal{E}_t$ and image encoder $\mathcal{E}_i$ produce normalized feature vectors $\hat{\mathbf{e}}_t$ and $\hat{\mathbf{e}}_i$.
*   **Patch Buffer:** Stores rendered patches of size $128 \times 128$ pixels [S1].

**Parameters**
*   **Iterations:** 500 [S1].
*   **Optimizer:** Adam with learning rate $\eta = 0.0001$ [S1].
*   **Patch Size:** $128 \times 128$ pixels [S1].
*   **Ray Sampling Stride:** 5 within the patch, resulting in a receptive field of $640 \times 640$ on the original image scale [S1].
*   **Importance Sampling Points:** 16 per ray during patch rendering [S1].
*   **Fine MLP Samples:** 80 total (64 coarse + 16 fine) [S1].
*   **Freezing:** Sub-parameters related to density are frozen; only radiance/feature parameters are optimized [S1].

**Loss Functions**
Two variants of directional CLIP loss are used, both measuring cosine similarity $\langle \cdot, \cdot \rangle$ between normalized vectors:

1.  **Absolute Directional CLIP Loss:** Measures similarity between the rendered image $\mathbf{I}_{tgt}$ and the target text prompt $\mathbf{t}_{tgt}$ [S2]:
    $$
    \mathcal{L}_{dir} = 1 - \langle \hat{\mathcal{E}}_i(\mathbf{I}_{tgt}), \hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) \rangle
    $$
    This guides the NeRF rendering with a global direction of the target text [S2].

2.  **Relative Directional CLIP Loss:** Transfers style from a source image $\mathbf{I}_{src}$ to the target domain guided by the trajectory between source text $\mathbf{t}_{src}$ and target text $\mathbf{t}_{tgt}$ [S2]:
    $$
    \mathcal{L}_{dir} = 1 - \langle \hat{\mathcal{E}}_i(\mathbf{I}_{tgt}) - \hat{\mathcal{E}}_i(\mathbf{I}_{src}), \hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) - \hat{\mathcal{E}}_t(\mathbf{t}_{src}) \rangle
    $$
    This enforces the correct stylization trajectory while ignoring magnitude differences [S2].

**Algorithm Steps**
1.  **Initialize:** Load pre-trained NeRF and CLIP ViT-B/32 model [S1]. Freeze density network parameters [S1].
2.  **Sample View:** Randomly sample a camera pose from the training dataset [S1].
3.  **Render Patch:**
    a.  Cast rays through a $128 \times 128$ grid.
    b.  Sample rays with stride 5 to cover a $640 \times 640$ receptive field [S1].
    c.  Perform volume rendering using 16 importance sampling points per ray and 80 total samples for the fine MLP (64 coarse + 16 fine) [S1].
    d.  Output rendered patch $\mathbf{I}_{patch}$ [S1].
4.  **Encode:** Pass $\mathbf{I}_{patch}$ through $\mathcal{E}_i$ and text prompt(s) through $\mathcal{E}_t$ to get normalized embeddings [S2].
5.  **Compute Loss:** Calculate $\mathcal{L}_{dir}$ using either absolute or relative formulation [S2].
6.  **Optimize:** Update NeRF radiance/feature parameters using Adam ($\eta=0.0001$) to minimize $\mathcal{L}_{dir}$ [S1].
7.  **Repeat:** Iterate for 500 steps [S1].

**Pseudocode**
```python
def train_clipnerf(nerf_model, clip_model, text_prompt_tgt, text_prompt_src=None, 
                   num_iterations=500, lr=0.0001, patch_size=128, stride=5, 
                   samples_per_ray=16, fine_samples=80):
    """
    Train NeRF for text-guided stylization using CLIP loss.
    """
    optimizer = Adam(nerf_model.parameters(), lr=lr)
    # Freeze density parameters as per [S1]
    freeze_density_params(nerf_model) 
    
    for step in range(num_iterations):
        # 1. Sample random view
        camera_pose = sample_random_pose()
        
        # 2. Render patch with reduced sampling for memory efficiency [S1]
        # Rays are sampled with stride to cover larger receptive field
        rays = generate_rays(camera_pose, patch_size, stride)
        rendered_patch = nerf_model.render(rays, 
                                           num_samples=samples_per_ray, 
                                           fine_samples=fine_samples)
        
        # 3. Encode inputs
        img_embed = clip_model.encode_image(rendered_patch)
        img_embed = normalize(img_embed)
        
        tgt_embed = clip_model.encode_text(text_prompt_tgt)
        tgt_embed = normalize(tgt_embed)
        
        if text_prompt_src is not None:
            src_embed = clip_model.encode_text(text_prompt_src)
            src_embed = normalize(src_embed)
            # Relative Directional Loss [S2]
            loss = 1.0 - cosine_similarity(img_embed - src_embed, tgt_embed - src_embed)
        else:
            # Absolute Directional Loss [S2]
            loss = 1.0 - cosine_similarity(img_embed, tgt_embed)
            
        # 4. Optimize
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
    return nerf_model
```

**Edge Cases and Pitfalls**
*   **Memory Constraints:** Naive differentiable rendering of high-resolution images is intractable due to memory limits [S1]. The patch-based approach with reduced sampling (16 points) is required [S1].
*   **Mode Collapse:** Absolute directional CLIP loss can cause mode collapse of the generator and hurt generation diversity [S2].
*   **Insufficient Magnitude:** Directional loss alone struggles to reach sufficient stylization magnitude, resulting in weak style transfer, as it ignores vector distances [S2].

## Operating characteristics

**Time and Memory Complexity**
*   **Memory:** Reduced by rendering small patches ($128 \times 128$) instead of full images and reducing importance sampling points to 16 [S1].
*   **Time:** Limited to 500 iterations [S1]. The use of InstantNGP-style hash grids (implied by context of [S1] referencing ngp_pl) provides fast encoding, but CLIP encoding adds overhead per step [S1].

**Strengths and Limitations**
*   **Strengths:** Enables text-driven stylization of 3D scenes without requiring 3D annotations [S2]. Efficient rendering via patches allows optimization on standard hardware [S1].
*   **Limitations:** Absolute loss leads to mode collapse and low diversity [S2]. Directional loss may result in insufficient stylization magnitude [S2]. The method relies on the quality of the CLIP model and the text prompts [S2].

**When to Use**
*   Use for text-guided artistic stylization of NeRFs where global style transfer is desired [S2].
*   Use relative loss when a source image and corresponding text are available to guide the trajectory [S2].

**When Not to Use**
*   Avoid absolute directional loss if generation diversity is critical [S2].
*   Avoid if high-fidelity magnitude preservation is required without additional contrastive mechanisms [S2].

## Background

**Origin**
The method originates from "NeRF-Art: Text-Driven Neural Radiance Fields Stylization" [S2] and "Decomposing NeRF for Editing Via Feature Field Distillation" [S1]. The directional CLIP loss was first designed in StyleCLIP [Patashnik et al. 2021] for face editing and extended to generative NeRF editing in CLIP-NeRF [Wang et al. 2021a] [S2]. StyleGAN-NADA [Gal et al. 2021] highlighted the mode collapse issue with absolute directional loss [S2].

**History and Development**
Initial attempts to apply StyleGAN-NADA's directional CLIP loss directly to NeRFs revealed issues with mode collapse and insufficient magnitude [S2]. The NeRF-Art paper introduced relative directional loss and global-local contrastive learning to address these issues [S2]. The implementation details in [S1] highlight the practical necessity of patch-based rendering for memory efficiency.

**Usage**
Used for text-driven 3D scene stylization and editing [S2].
