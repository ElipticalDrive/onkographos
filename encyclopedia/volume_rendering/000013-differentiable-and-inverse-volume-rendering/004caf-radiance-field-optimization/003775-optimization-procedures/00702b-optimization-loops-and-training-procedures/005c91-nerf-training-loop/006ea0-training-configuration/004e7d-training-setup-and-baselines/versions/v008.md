# Training Setup and Baselines


## Overview
This family defines the specific hyperparameters, data pipelines, and baseline configurations required to train neural radiance field models and related 3D generative architectures. It addresses the problem of stabilizing optimization and establishing performance benchmarks by configuring inputs (such as HDR vs. LDR data), network architectures (e.g., StyleGAN2 backbones, feature-volume hybrids), and optimization routines (e.g., meta-learning, GAN adversarial losses). It differs from general optimization loops by focusing on the static configuration and baseline references rather than the dynamic scheduling or sampling strategies.

## Shared principles
The articles in this family share the following mechanisms and terms:
- **Baseline Establishment:** Several entries define "baseline" configurations (NeRF-GT, NLR) that serve as upper-bound references or standard comparisons for novel methods [S1, unofficial].
- **Input/Output Contracts:** Each configuration specifies strict input types (e.g., HDR views, real image batches, meta-parameters) and outputs (e.g., trained models, rendered images) [S1, unofficial][S2].
- **Optimization Objectives:** The training objectives vary by architecture but generally involve minimizing a loss function between rendered outputs and ground truth, whether through photometric MSE, GAN adversarial losses, or meta-learning inner/outer loops [S1, unofficial][S2].
- **Hyperparameter Sensitivity:** All entries highlight critical hyperparameters (learning rates, batch sizes, regularization strengths) that significantly impact convergence and visual quality [S1, unofficial][S2].

## Subtopics

### [NeRF-GT Baseline Training Setup](11349-nerf-gt-baseline-training-setup.md)
A baseline that establishes an upper-bound reference for neural radiance field quality by training directly on High Dynamic Range (HDR) ground truth views [11349-nerf-gt-baseline-training-setup]. It differs from standard NeRF implementations by utilizing HDR inputs and applying tone-mapping to both predictions and ground truth for loss computation, addressing the limitations of training on Low Dynamic Range (LDR) data [11349-nerf-gt-baseline-training-setup]. This setup serves as a performance ceiling against which methods like HDR-NeRF are evaluated [11349-nerf-gt-baseline-training-setup].

### [StyleGAN2 Training Configuration](12972-stylegan2-training-configuration.md)
This configuration defines the training recipe for 3D-aware image synthesis models (such as VoxGRAF) that utilize the StyleGAN2 architecture as a backbone for the generator and discriminator [12972-stylegan2-training-configuration]. It solves the problem of stable training for high-resolution generative models by combining equalized learning rates, minibatch statistics, and specific regularization techniques [12972-stylegan2-training-configuration]. It sets itself apart from standard NeRF training loops by employing a GAN-based adversarial objective rather than pure photometric reconstruction, and differs from the original StyleGAN2 paper by disabling path regularization and style-mixing to reduce computational cost and memory usage [12972-stylegan2-training-configuration].

### [NeRF Training Setup](13271-nerf-training-setup.md)
This article defines the training configuration for NeRF-based models using the Nerfstudio library, specifically leveraging NerfAcc and Instant-NGP for fast convergence on static scenes [13271-nerf-training-setup]. It also details the specific architectural and optimization setup of Control-NeRF, which replaces standard positional encoding of 3D positions with sampled feature vectors [13271-nerf-training-setup]. The method solves the problem of efficient and editable scene representation by optimizing a coarse and fine network pair to render images from multi-view inputs [13271-nerf-training-setup]. It differs from standard NeRF by using pre-computed feature volumes and omitting positional encoding on those features, and differs from generic NeRF-GT baselines by utilizing specific acceleration libraries (NerfAcc/Instant-NGP) and feature-based inputs [13271-nerf-training-setup].

### [NLR Baseline](15254-nlr-baseline.md)
NLR [15254-nlr-baseline, unofficial] is a neural rendering method that represents light fields using a compact set of neural networks to predict radiance and density, serving as a baseline for meta-learning approaches in novel view synthesis [15254-nlr-baseline, unofficial]. It differs from standard NeRF [15254-nlr-baseline, unofficial] by optimizing a representation that is specialized to specific scenes via meta-learning initialization, rather than learning a single global field from scratch [15254-nlr-baseline, unofficial].

### NeuralVDB Hyperparameter Configuration
- **Step:** Batch sampling strategy: Either draw $2^{16}$ random samples per epoch, or resample a subset of input voxels at fixed intervals and draw $2^{12}$ batches per epoch. Resampling subset size = resampling intervals (100 or 500) × batch size. Use resampling when fine details with thin structures are critical [S1, unofficial].
- **Parameter:** Subdomain size: Must be a multiple of 512. Too large wastes compute on empty subdomains; too small increases dispatch overhead and causes dominant overlapping halo regions leading to redundant computation [S1, unofficial]. Network width: Level-1 networks use half the width of level-0 networks. Default starting point: level-0 width 128, depth 3. Use 4 layers for volumes requiring more detail capture [S1, unofficial]. Optimizer: Adam optimizer. Default learning rate: 0.001. Decay: 0.975 every 100 epochs (no resampling) or 0.75 every 1,000 epochs (with resampling). Max epochs: 2,500 for non-resampled; more for resampled cases [S1, unofficial].
- **Comparison:** Dense grid training produces the highest noise. Block grid (dense leaf nodes without active masks) reduces noise but still shows visible fog artifacts. Sparse VDB with active voxel masks yields the best visual quality and low noise reconstruction [S1, unofficial].

### Neural Codebook Training Configuration
- **Step:** Multiply learning rate by 0.3 for every 5,000 iterations [S2]. Cast the trained Neural Codebook (NCB) to float16 after training [S2].
- **Parameter:** Optimizer: Adam with $\beta_1 = 0.9$ and $\beta_2 = 0.999$ [S2]. Weight decay: $1e-5$ [S2]. Initial learning rate: $5e-3$ [S2]. Total training iterations: 20,000 [S2]. Batch size: 100,000 voxels [S2].

## Background
The concept of training baselines in neural rendering originated with the initial NeRF paper, which established standard photometric loss minimization on LDR data [11349-nerf-gt-baseline-training-setup, 13271-nerf-training-setup, 15254-nlr-baseline, unofficial]. The introduction of HDR training baselines (NeRF-GT) addressed dynamic range limitations [11349-nerf-gt-baseline-training-setup]. Concurrently, the integration of GAN-based training configurations (StyleGAN2) adapted generative adversarial networks to 3D volume synthesis [12972-stylegan2-training-configuration]. Meta-learning baselines (NLR) were developed to enable rapid scene specialization [15254-nlr-baseline, unofficial]. More recently, sparse volume representations (NeuralVDB) and compact representations (Neural Codebook) introduced specific hyperparameter configurations to handle sparsity and memory efficiency [S1, unofficial][S2].
