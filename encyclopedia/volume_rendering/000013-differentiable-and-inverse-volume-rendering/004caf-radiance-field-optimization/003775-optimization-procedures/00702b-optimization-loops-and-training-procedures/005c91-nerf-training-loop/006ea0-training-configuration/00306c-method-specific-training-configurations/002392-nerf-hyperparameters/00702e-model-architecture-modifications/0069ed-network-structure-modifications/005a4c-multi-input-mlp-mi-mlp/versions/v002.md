# Multi-input MLP (mi-MLP)
Also called: per-layer inputs incorporation

## Overview
The multi-input MLP (mi-MLP) is a network architecture modification for Neural Radiance Fields (NeRF) designed to alleviate overfitting in few-shot view synthesis without sacrificing the capacity to synthesize high-frequency details [S1]. Unlike vanilla NeRF, which processes inputs through a sequential chain of layers, mi-MLP incorporates the positional encodings of the 3D location and viewing direction into every layer of the network [S1]. This structure creates shorter paths between inputs and outputs, allowing the model to learn flexible mappings that prevent overfitting while maintaining the original model capacity [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 5D coordinate vector $\mathbf{x}$, composed of the 3D spatial location $\mathbf{p} \in \mathbb{R}^3$ and the 2D viewing direction $\mathbf{d} \in \mathbb{R}^2$.
*   **Output:** Volume density $\sigma$ and view-dependent color $\mathbf{c}$ for the given ray point.

**Data Structures:**
The network consists of $L_{layers}$ hidden layers. Each layer $i$ (where $i > 1$) maintains:
*   Weight matrix components $\mathbf{w}_i^{j0} \in \mathbb{R}^{1 \times d_1}$ and $\mathbf{w}_i^{j1} \in \mathbb{R}^{1 \times d_2}$ for each output neuron $j$.
*   Bias vector $\mathbf{b}_i \in \mathbb{R}^{d_2 \times 1}$.
*   Activation function $\epsilon$ (default: ReLU).
*   $d_1$ is the dimension of the positional encoding $\gamma_L(\mathbf{x})$.
*   $d_2$ is the hidden dimension (output dimension) of the layer.

**Positional Encoding:**
The input $\mathbf{x}$ is mapped to a higher-dimensional embedding $\gamma_L(\mathbf{x})$ using sinusoidal positional encoding [S1]:
$$ \gamma_L(\mathbf{x}) = (\sin(2^0 \mathbf{x}), \cos(2^0 \mathbf{x}), \dots, \sin(2^{L-1} \mathbf{x}), \cos(2^{L-1} \mathbf{x})) $$
where $L$ is a hyperparameter controlling the number of frequency bands [S1]. The dimension $d_1 = 2 \times L \times 5$ (since $\mathbf{x}$ is 5D).

**Algorithm Steps:**
1.  **Encode Input:** Compute $\gamma_L(\mathbf{x})$ for the input 5D coordinate $\mathbf{x}$ [S1].
2.  **Initialize First Layer:** Compute the output of the first hidden layer $f_1$ [S1]:
    $$ f_1 = \phi_1(\gamma_L(\mathbf{x})) $$
    where $\phi_1$ is the first layer function [S1].
3.  **Iterate Through Hidden Layers:** For each subsequent layer $i$ from 2 to $L_{layers}-1$:
    *   Compute the output feature $f_i$ by combining the previous layer's output $f_{i-1}$ and the encoded input $\gamma_L(\mathbf{x})$ [S1]:
        $$ f_i = \phi_i(f_{i-1}, \gamma_L(\mathbf{x})) $$
    *   The computation for the $j$-th neuron in layer $i$ is defined as [S1]:
        $$ \phi_i^j(\gamma_L(\mathbf{x})) = \epsilon\left( \mathbf{w}_i^{j0}[\gamma_L(\mathbf{x})] + \mathbf{w}_i^{j1}[f_{i-1}] + \mathbf{b}_i \right) $$
        where $\epsilon$ is the activation function (default ReLU) [S1].
4.  **Output Prediction:** The final layer produces the volume density $\sigma$ and color $\mathbf{c}$ from the last hidden feature $f_{L_{layers}-1}$ and the encoded input $\gamma_L(\mathbf{x})$ [S1].

**Parameters:**
*   **Frequency Bands ($L$):** Hyperparameter in positional encoding. Not given in the sources for specific values, but defined as controlling frequencies [S1].
*   **Weight Initialization:** Default PyTorch initialization is used. The sources state that this initialization satisfies the condition $\|\mathbf{w}_i^{j1}\|_1 \in (0, 1]$ [S1].
*   **Activation Function:** ReLU is the default [S1].

**Edge Cases and Pitfalls:**
*   **Gradient Amplitude:** During early training, vanilla MLPs result in similar gradient amplitudes for all layers. mi-MLP ensures that deeper layers (close to outputs) are updated with large gradients while shallower layers receive extremely small gradients [S1]. This behavior is theoretically supported by the ratio of gradient amplitudes between adjacent layers [S1]:
    $$ \left\| \frac{\partial \mathcal{L}}{\partial \mathbf{w}_i} \right\|_1 / \left\| \frac{\partial \mathcal{L}}{\partial \mathbf{w}_{i-1}} \right\|_1 = \frac{1}{d_2} \sum_{j=1}^{d_2} \frac{\|\gamma_L(\mathbf{x})\|_1 + \|f_{i-1}\|_1}{\|\sum \mathbf{w}_i^{j1}\|_1 \cdot \{\|\gamma_L(\mathbf{x})\|_1 + \|f_{i-2}\|_1\}} $$
    where $\mathcal{L}$ is the loss function [S1].
*   **Overfitting:** The primary problem solved is overfitting in few-shot view synthesis. Trivially reducing parameters alleviates overfitting but loses detail; mi-MLP prevents overfitting without harming detailed synthesis [S1].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import math

def positional_encoding(x, L):
    """
    Computes the positional encoding for input x.
    x: Tensor of shape (..., 5) representing 3D location and 2D viewing direction.
    L: Integer, number of frequency bands.
    Returns: Tensor of shape (..., 2 * 5 * L)
    """
    # x shape: (..., 5)
    # frequencies: 2^0, 2^1, ..., 2^(L-1)
    frequencies = torch.pow(2.0, torch.arange(L, device=x.device).float())
    # Expand dimensions for broadcasting
    # x: (..., 5) -> (..., 1, 5)
    # frequencies: (L,) -> (L, 1, 1)
    # scaled_x: (..., L, 5)
    scaled_x = x.unsqueeze(-2) * frequencies.unsqueeze(-1)
    
    # Compute sin and cos
    # scaled_x: (..., L, 5)
    sin_vals = torch.sin(scaled_x) # (..., L, 5)
    cos_vals = torch.cos(scaled_x) # (..., L, 5)
    
    # Concatenate along the last dimension
    # sin_vals: (..., L, 5) -> (..., L*5)
    # cos_vals: (..., L, 5) -> (..., L*5)
    # Result: (..., 2 * L * 5)
    pe = torch.cat([sin_vals, cos_vals], dim=-1)
    return pe

class MiMLPLayer(nn.Module):
    def __init__(self, d_in, d_out):
        super(MiMLPLayer, self).__init__()
        self.d_in = d_in
        self.d_out = d_out
        # w_i^j0: (d_out, d_in)
        # w_i^j1: (d_out, d_in) -- Note: In the formula, w_i^j1 connects to f_{i-1} which has dim d_in (if d_in=d_out)
        # The source defines w_i^j1 as R^{1 x d_2} where d_2 is output dim of previous layer.
        # Assuming hidden dim is constant d_h.
        # w_i^0 connects to gamma_L(x) (dim d_gamma)
        # w_i^1 connects to f_{i-1} (dim d_h)
        self.weight_input = nn.Parameter(torch.empty(d_out, d_in)) # w_i^j0
        self.weight_hidden = nn.Parameter(torch.empty(d_out, d_in)) # w_i^j1
        self.bias = nn.Parameter(torch.zeros(d_out))
        
        # Initialize weights using default PyTorch initialization (Kaiming Uniform/Normal)
        # The source states default PyTorch init satisfies ||w_i^j1||_1 in (0, 1]
        nn.init.kaiming_uniform_(self.weight_input, a=math.sqrt(5))
        nn.init.kaiming_uniform_(self.weight_hidden, a=math.sqrt(5))
        nn.init.zeros_(self.bias)

    def forward(self, f_prev, gamma_x):
        """
        f_prev: Tensor of shape (..., d_in) representing f_{i-1}
        gamma_x: Tensor of shape (..., d_gamma) representing gamma_L(x)
        Returns: Tensor of shape (..., d_out) representing f_i
        """
        # phi_i^j = epsilon( w_i^0 * gamma_x + w_i^1 * f_{i-1} + b_i )
        # Matrix multiplication:
        # w_i^0 @ gamma_x.T -> (d_out, d_gamma) @ (d_gamma, ...) -> (d_out, ...)
        # w_i^1 @ f_prev.T -> (d_out, d_in) @ (d_in, ...) -> (d_out, ...)
        
        # Using linear layers for clarity, but implementing manually to match formula structure
        # term1 = gamma_x @ self.weight_input.T -> (..., d_out)
        term1 = torch.matmul(gamma_x, self.weight_input.T)
        # term2 = f_prev @ self.weight_hidden.T -> (..., d_out)
        term2 = torch.matmul(f_prev, self.weight_hidden.T)
        
        out = term1 + term2 + self.bias
        return torch.relu(out)

class MiMLP(nn.Module):
    def __init__(self, d_gamma, d_h, num_layers, d_out_density=1, d_out_color=3):
        """
        d_gamma: Dimension of positional encoding (2 * 5 * L)
        d_h: Hidden dimension
        num_layers: Number of hidden layers
        """
        super(MiMLP, self).__init__()
        self.num_layers = num_layers
        
        # Layer 1: Input is gamma_x
        self.layer1 = MiMLPLayer(d_gamma, d_h)
        
        # Layers 2 to num_layers-1: Input is gamma_x and f_{i-1}
        self.layers = nn.ModuleList([
            MiMLPLayer(d_h, d_h) for _ in range(num_layers - 2)
        ])
        
        # Output layers
        # Density head
        self.density_head = MiMLPLayer(d_h, d_out_density)
        # Color head
        self.color_head = MiMLPLayer(d_h, d_out_color)

    def forward(self, x, L):
        """
        x: Tensor of shape (..., 5)
        L: Integer, number of frequency bands
        """
        gamma_x = positional_encoding(x, L)
        
        # Layer 1
        f = self.layer1(gamma_x, gamma_x)
        
        # Layers 2 to num_layers-1
        for layer in self.layers:
            f = layer(f, gamma_x)
            
        # Output heads
        # Note: The source implies the final prediction also uses gamma_x
        # sigma = phi_density(f, gamma_x)
        # c = phi_color(f, gamma_x)
        
        # Assuming the output layers also follow the mi-MLP structure
        # However, standard NeRF output layers are often simple linear.
        # The source says "incorporates inputs... into each layer".
        # If the output layers are considered part of the "MLP" structure described:
        
        # Let's assume the final prediction layers also take gamma_x
        # But typically, the last layer outputs the scalar/vector.
        # The source formula f_i = phi_i(f_{i-1}, gamma_x) applies to hidden layers.
        # For the final output, we can treat the density/color heads as layers that take f and gamma_x.
        
        sigma = self.density_head(f, gamma_x)
        color = self.color_head(f, gamma_x)
        
        return sigma, color
```

## Subtopics

### Separate Modeling of Colors and Volume Density
A complementary technique often used with mi-MLP where density and color are predicted by separate networks or branches to allow different positional encoding frequencies, reducing artifacts [S1].

### Few-Shot View Synthesis
The primary application domain for mi-MLP, where the method's ability to prevent overfitting with limited training views is most critical [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources. The architecture maintains the same model capacity (number of parameters) as the vanilla MLP if layer dimensions are kept constant, but adds weight matrices for the direct connections from $\gamma_L(\mathbf{x})$ to each layer [S1].
*   **Measured Performance:** On the baseline NeRF, mi-MLP boosted the PSNR from 14.73 to 24.23 in few-shot view synthesis experiments [S1].
*   **Strengths:**
    *   Prevents overfitting in few-shot scenarios without reducing model capacity [S1].
    *   Enables shorter paths between inputs and outputs [S1].
    *   Plug-and-play solution that keeps inputs and outputs unchanged [S1].
    *   Achieves state-of-the-art results on a wide range of benchmarks [S1].
*   **Limitations:**
    *   Still contains noticeable artifacts if not combined with separate modeling of colors and density [S1].
*   **When to use:** When performing few-shot view synthesis with NeRF and observing overfitting, but wanting to retain high-frequency detail synthesis capabilities [S1].
*   **When not to use:** When computational resources are extremely constrained and parameter reduction is preferred over capacity preservation, or when sufficient training data is available to prevent overfitting in vanilla MLPs [S1].

## Background
The multi-input MLP (mi-MLP) was proposed in the paper "Is Vanilla MLP in Neural Radiance Field Enough for Few-Shot View Synthesis?" published in CVPR 2024 [S1]. It addresses the observation that trivially reducing model parameters alleviates overfitting but harms detail synthesis. The method provides an orthogonal approach by modifying the network structure to incorporate inputs into each layer, revealing insights about gradient amplitudes and path lengths in neural radiance fields [S1].
