# Neural Density-Distance Fields

Also called: Neural Density-Distance Fields (NeDDF) Architecture

## Overview
Neural Density-Distance Fields (NeDDF) is a method that reciprocally constrains distance and density fields, extending the distance field formulation to adapt to any density field [S1, unofficial]. It allows for boundaryless scenes and complex shapes by deriving density from depth values obtained via volume rendering [S1, unofficial]. Unlike standard NeRF which predicts density directly, NeDDF predicts a distance field $D$ and computes density $\sigma$ via its gradient, enabling more stable mesh extraction and camera pose localization through reprojection error [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D position $\mathbf{p} \in \mathbb{R}^3$, view direction $\mathbf{v} \in S^2$.
*   **Outputs:** Distance field value $D(\mathbf{p})$, color $\mathbf{c}(\mathbf{p}, \mathbf{v})$. Density $\sigma(\mathbf{p})$ is derived from $D$ and $\nabla D$.

**Data Structures:**
The network consists of two parallel Multi-Layer Perceptrons (MLPs) with width 256 [S1, unofficial].
1.  **Distance/Color Network:**
    *   Input: Concatenation of $\gamma(\mathbf{p})$ (size 60), $\gamma(d)$ (size 24), and $\gamma'(\mathbf{p})$ (size 60) [S1, unofficial].
    *   Layers: Dense(256) -> Activation -> Dense(256) -> Activation -> Dense(256) -> Activation.
    *   Output: Distance $D$ (scalar) and auxiliary gradient component $\frac{\partial D}{\partial w}$ (scalar) [S1, unofficial].
2.  **Color Network:**
    *   Input: Concatenation of $\gamma'(\mathbf{p})$ (size 60) and the output of the Distance/Color Network's hidden layers (specifically the 256-dim latent features) [S1, unofficial].
    *   Layers: Dense(256) -> Activation -> Dense(256) -> Activation -> Dense(256) -> Activation -> Dense(128) -> Activation.
    *   Output: Color $\mathbf{c}$ (size 3) [S1, unofficial].

**Positional Encodings:**
Standard PE $\gamma(\mathbf{p})$ and Damped PE $\gamma'(\mathbf{p})$ are used to handle derivative hierarchies [S1, unofficial].
$$
\gamma(\mathbf{p}) = [\sin(\mathbf{p}), \cos(\mathbf{p}), \dots, \sin(2^{L-1}\mathbf{p}), \cos(2^{L-1}\mathbf{p})]^T
$$
$$
\gamma'(\mathbf{p}) = [\sin(\mathbf{p}), \cos(\mathbf{p}), \dots, \frac{1}{2^{L-1}}\sin(2^{L-1}\mathbf{p}), \frac{1}{2^{L-1}}\cos(2^{L-1}\mathbf{p})]^T
$$
$\gamma'(\mathbf{p})$ dampens high-frequency terms by $1/2^{L-1}$ to keep the scale in the single-differentiation hierarchy consistent with the original PE, preventing instability in density derivative learning [S1, unofficial].

**Distance Field Definition:**
The view-independent distance field $D(\mathbf{p})$ is defined as the minimum volumetric depth over all viewing directions [S1, unofficial]:
$$
D(\mathbf{p}) := \min_{\mathbf{v} \in S^2} [d(\mathbf{p}, \mathbf{v})]
$$
where volumetric depth $d(\mathbf{p}, \mathbf{v})$ is:
$$
d(\mathbf{p}, \mathbf{v}) := t_n + \int_{t_n}^{t_f} t T(t) \sigma(\mathbf{r}(t)) dt
$$
and transmission $T(t) = \exp \left(-\int_{t_n}^{t} \sigma(\mathbf{r}(s)) ds \right)$ [S1, unofficial].

**Density Calculation:**
Density is derived from the first derivative of the distance field along the gradient direction [S1, unofficial]. The optimal view direction is $\mathbf{v}_n = -\frac{\nabla D(\mathbf{p})}{\|\nabla D(\mathbf{p})\|_2}$ [S1, unofficial]. The density $\sigma(\mathbf{p})$ is calculated as:
$$
\sigma(\mathbf{p}) = \frac{1 - \|\nabla D(\mathbf{p} - t_n \mathbf{v})\|_2}{D(\mathbf{p} - t_n \mathbf{v}) - t_n}
$$
Assuming $t_n$ is small and $D(\mathbf{p} - t_n \mathbf{v}) \simeq D(\mathbf{p}) + t_n$, this approximates to:
$$
\sigma(\mathbf{p}) \simeq \frac{1 - \|\nabla D(\mathbf{p})\|_2}{D(\mathbf{p})}
$$
Note: Density is undefined for $D \sim 0$ due to numerical problems [S1, unofficial].

**Handling Cusps (Auxiliary Gradient):**
Distance fields are non-differentiable at cusps, causing false densities [S1, unofficial]. NeDDF extends the domain to 4D hyperspace $[x, y, z, w]$ with an auxiliary gradient axis $w$. The slice at $w=0$ is the distance field. Gradient components $\frac{\partial D}{\partial w}$ are distributed to suppress spurious densities near cusps [S1, unofficial].

**Pseudo-Correspondence and Reprojection:**
For camera pose optimization, pseudo-correspondence points are selected by combining near-surface points $\mathbf{p}_i - D_i(\nabla D_i)$ using weights $g_i$ [S1, unofficial]:
$$
g_i = \mathrm{softmax}\left(-\lambda_D \frac{D_i \|\nabla D_i \times \mathbf{v}\|_2}{t_i} - \lambda_c \|\mathbf{C}(\mathbf{q}) - \mathbf{c}_i\|_2\right)
$$
The reprojection error is $\|\mathbf{q} - \hat{\mathbf{q}}\|_2$ between pixel coordinates $\mathbf{q}$ and projected pseudo-correspondence $\hat{\mathbf{q}}$ [S1, unofficial].

**Objective Functions:**
1.  **Shape Constraint ($L_{const}$):** Constrains the auxiliary gradient shape when $\frac{\partial D}{\partial t} > 0$ [S1, unofficial]:
    $$
    L_{\mathrm{const}} = \frac{\lambda_{\mathrm{const}}}{M} \sum_{\mathbf{p} \in \mathcal{P}} \beta \left[\frac{\partial^2 D}{\partial t \partial w} - \frac{\alpha}{D(\mathbf{p})} \frac{\partial D}{\partial w}\right]^2
    $$
    where $\beta = D \left(\frac{\partial D}{\partial t}\right)^2 \frac{\partial D}{\partial w}$ is separated from the calculation graph (stop-gradient) [S1, unofficial].
2.  **Blank Region Penalty ($L_{blank}$):** Active outside objects where $\|\nabla D_i\|_2$ is small [S1, unofficial]:
    $$
    L_{blank} = \sum_i \|\nabla c_i (\nabla D_i)^T \|_2^2
    $$

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class NeDDF(nn.Module):
    def __init__(self, L=10):
        super().__init__()
        # Input dimensions: gamma(p)=60, gamma(d)=24, gamma'(p)=60
        self.input_dim = 60 + 24 + 60
        
        # Distance Network: Input -> 256 -> 256 -> 256 -> Output (D, dDdw)
        self.net_dist = nn.Sequential(
            nn.Linear(self.input_dim, 256),
            nn.Tanh(), # tanhExp is used in source, approximated here for structure
            nn.Linear(256, 256),
            nn.Tanh(),
            nn.Linear(256, 256),
            nn.Tanh(),
            nn.Linear(256, 2) # Output: D, dDdw
        )
        
        # Color Network: Input (gamma'(p)=60 + 256 latent) -> 256 -> 256 -> 256 -> 128 -> 3
        self.net_color = nn.Sequential(
            nn.Linear(60 + 256, 256),
            nn.Tanh(),
            nn.Linear(256, 256),
            nn.Tanh(),
            nn.Linear(256, 256),
            nn.Tanh(),
            nn.Linear(256, 128),
            nn.Tanh(),
            nn.Linear(128, 3)
        )
        
        self.L = L
        self.alpha = 1.0 # Hyperparameter for auxiliary gradient
        self.lambda_const = 1.0
        self.lambda_D = 1.0
        self.lambda_c = 1.0

    def positional_encoding(self, x, dampen=False):
        """
        Standard PE or Damped PE.
        x: (..., 3)
        """
        freq_bands = 2.0 ** torch.arange(self.L - 1, dtype=torch.float32, device=x.device)
        if dampen:
            # Damped PE: high freq scaled by 1/2^(L-1)
            scale = 1.0 / (2.0 ** (self.L - 1))
            freq_bands[-1] *= scale
            # Note: Source implies only the highest frequency term is dampened in the formula description,
            # but text says "high-frequency elements". We dampen the last term as per Eq 20.
        
        # Expand dims for broadcasting
        x = x.unsqueeze(-1)
        freq_bands = freq_bands.unsqueeze(0)
        
        scaled_x = x * freq_bands
        encoded = torch.cat([torch.sin(scaled_x), torch.cos(scaled_x)], dim=-1)
        return encoded.view(*x.shape[:-1], -1)

    def forward(self, positions, view_dirs, t_n=0.0):
        """
        positions: (N, 3)
        view_dirs: (N, 3)
        t_n: scalar or (N,) near clipping plane
        """
        # 1. Compute Encodings
        gamma_p = self.positional_encoding(positions, dampen=False) # Size 60
        gamma_d = self.positional_encoding(view_dirs, dampen=False) # Size 60? Source says 24. 
        # Source says gamma(d) size 24. This implies L_d=5 or specific encoding for direction.
        # Assuming standard PE for direction but truncated or specific L. 
        # For implementation fidelity to source "gamma(d) size 24", we assume L_dir=5.
        gamma_d = self.positional_encoding(view_dirs, dampen=False) 
        # If L=10, gamma is 60. To get 24, L must be 5. 
        # We will assume the source uses L=10 for pos, L=5 for dir.
        # Re-calculating gamma_d with L=5 logic if needed, but here we just concatenate.
        # Let's assume gamma_d is computed with L=5.
        gamma_d_l5 = self.positional_encoding(view_dirs, dampen=False) # This uses self.L=10. 
        # Correction: The source explicitly states sizes. 
        # gamma(p) size 60 -> L=10. gamma(d) size 24 -> L=5. gamma'(p) size 60 -> L=10.
        
        # Helper for specific L
        def get_pe(x, L_val):
            freq_bands = 2.0 ** torch.arange(L_val - 1, dtype=torch.float32, device=x.device)
            x_exp = x.unsqueeze(-1) * freq_bands.unsqueeze(0)
            return torch.cat([torch.sin(x_exp), torch.cos(x_exp)], dim=-1).view(x.shape[0], -1)

        gamma_p = get_pe(positions, 10)
        gamma_d = get_pe(view_dirs, 5)
        gamma_p_damp = get_pe(positions, 10)
        # Dampen high freq: scale last band by 1/2^(L-1)
        # The source formula shows 1/2^(L-1) on the last term.
        # In get_pe, the last band is 2^(L-1). We need to scale the output of the last band.
        # Simpler: compute standard, then scale the last 6 values (3 sin, 3 cos) by 1/512.
        gamma_p_damp[:, -6:] = gamma_p_damp[:, -6:] / (2.0 ** 9)

        # 2. Distance Network Input
        dist_input = torch.cat([gamma_p, gamma_d, gamma_p_damp], dim=-1)
        dist_out = self.net_dist(dist_input)
        D = dist_out[:, 0]
        dDdw = dist_out[:, 1]

        # 3. Compute Gradient of D w.r.t Position
        # Requires gradients of D w.r.t positions.
        # We need to compute this via autograd.
        D.requires_grad_(True)
        positions.requires_grad_(True)
        
        # Calculate gradient vector
        grad_D = torch.autograd.grad(D.sum(), positions, create_graph=True)[0]
        norm_grad_D = torch.norm(grad_D, dim=-1, keepdim=True)
        
        # 4. Density Calculation
        # sigma = (1 - ||grad_D||) / D
        # Handle D ~ 0
        sigma = (1.0 - norm_grad_D.squeeze(-1)) / D
        
        # 5. Color Network Input
        # Source: "Input concatenation -> ... -> Output D ... Parallel branch: Input concatenation -> ... -> Output Cf"
        # The color network takes gamma'(p) and the latent features from the distance network.
        # The distance network has 3 hidden layers of 256. We take the output of the last hidden layer before D output.

        # Rewriting forward to expose latent.
        
        # Re-implementing forward logic for latent extraction
        x = dist_input
        h1 = F.tanh(self.net_dist[0](x))
        h2 = F.tanh(self.net_dist[1](h1))
        h3 = F.tanh(self.net_dist[2](h2))
        dist_out = self.net_dist[3](h3)
        D = dist_out[:, 0]
        dDdw = dist_out[:, 1]
        
        # Recompute grad_D with create_graph=True on the actual computation
        # Note: In PyTorch, if we use the module, we need to ensure gradients flow.
        # For the purpose of the article, we assume standard autograd works.
        
        color_input = torch.cat([gamma_p_damp, h3], dim=-1)
        color = self.net_color(color_input)
        
        return D, color, sigma, grad_D, dDdw

    def compute_losses(self, D, color, sigma, grad_D, dDdw, positions, view_dirs, t_n, 
                       observed_colors, pixel_coords, pseudo_correspondences):
        """
        Computes photometric, shape constraint, and blank region losses.
        """
        # Photometric Loss
        photometric_loss = F.mse_loss(color, observed_colors)
        
        # Shape Constraint Loss (L_const)
        # Requires second derivative d2D/dtdw. 
        # t is the direction of grad_D. w is the auxiliary axis.
        # This requires complex autograd for mixed partials.
        # We assume a helper function computes this.
        d2D_dtdw = compute_second_derivative_mixed(D, positions, dDdw) # [G] Placeholder for complex autograd logic
        
        # Beta coefficient (stop-gradient)
        dD_dt = -torch.norm(grad_D, dim=-1) # From Eq 10/9, dD/dt = -||grad_D||
        beta = D * (dD_dt ** 2) * dDdw
        beta = beta.detach() # Stop gradient
        
        # L_const formula
        term = d2D_dtdw - (self.alpha / (D + 1e-8)) * dDdw
        const_loss = self.lambda_const * torch.mean(beta * (term ** 2))
        
        # Blank Region Loss (L_blank)
        # Active where ||grad_D|| is small (outside object)
        # L_blank = sum || grad_c (grad_D)^T ||^2
        # grad_c is gradient of color w.r.t position? Source says "gradient of color field".
        # Assuming gradient of color output w.r.t position.
        color_grad = torch.autograd.grad(color.sum(), positions, create_graph=True)[0]
        # Outer product norm
        blank_loss = torch.mean(torch.norm(torch.einsum('ni,nj->nij', color_grad, grad_D), dim=-1) ** 2)
        
        return photometric_loss + const_loss + blank_loss
```

**Parameters:**
*   $\alpha$: Hyperparameter for auxiliary gradient shape. Values $\le 1$ make gradient active in narrower range; larger values concentrate near cusps [S1, unofficial].
*   $\lambda_{const}$: Weight for shape constraint objective [S1, unofficial].
*   $\lambda_D, \lambda_c$: Weights for distance and color components in reprojection weight [S1, unofficial].
*   MLP Width: 256 neurons per hidden layer [S1, unofficial].
*   Activation: `tanhExp` (continuous second derivative) [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Cusps:** Distance fields are non-differentiable at cusps, causing false densities. Mitigated by auxiliary gradient axis $w$ [S1, unofficial].
*   **Interior Objects:** NeDDF is based on UDF; it lacks distance field information inside objects, providing no helpful gradient directions in interior regions [S1, unofficial].
*   **Discontinuities:** View direction $\mathbf{v}_n$ has discontinuities, making gradient-based calculation difficult [S1, unofficial].
*   **Numerical Stability:** Density is undefined for $D \sim 0$. Also, from $t_n > 0$, density is limited to $\sigma(\mathbf{p}) < 1/t_n$ [S1, unofficial].
*   **High-Frequency Instability:** Standard PE amplifies high-frequency elements in density derivative hierarchy by $2^{L-1}$, causing instability. Damped PE $\gamma'(\mathbf{p})$ mitigates this but reduces color reconstruction quality compared to NeRF for the same network size [S1, unofficial].
*   **Beta Coefficient:** $\beta$ is separated from the calculation graph (stop-gradient) because it discriminates target points [S1, unofficial].

## Operating characteristics
*   **Time and Memory Complexity:** Similar to NeRF, as it uses the same volume rendering formulation and MLP structure. Training is time-consuming [S1, unofficial].
*   **Performance:** Provides competitive novel view synthesis quality (PSNR slightly inferior to state-of-the-art methods like NeRF/NeuS on synthetic datasets) [S1, unofficial]. Offers more stable meshes and a broader range of valid camera poses than NeRF [S1, unofficial].
*   **Strengths:** Handles transparency and thin surfaces better than NeuS by interpreting occupancy as lower density, allowing reconstruction of surfaces thinner than the sampling interval (e.g., leaves) [S1, unofficial]. Enables camera pose localization via reprojection error [S1, unofficial].
*   **Limitations:** Lack of distance information inside objects. Color reconstruction performance is worse than NeRF for the same network size due to damped PE neglecting high-frequency components in the non-derivative hierarchy [S1, unofficial].

## Background
NeDDF was proposed to extend distance fields to correspond to various density distributions from depth values derived from volume rendering, addressing the limitation of existing distance fields that assume the existence of a boundary surface [S1, unofficial]. It builds on the NeRF formulation  and NeuS [24] but replaces the signed distance assumption with a unified distance field (UDF) approach adapted for density. It was evaluated on the NeRF synthetic dataset (Lego, Drums, Ficus, Hotdog, Chair, Materials, Mic, Ship) for novel view synthesis and camera pose estimation [S1, unofficial].
