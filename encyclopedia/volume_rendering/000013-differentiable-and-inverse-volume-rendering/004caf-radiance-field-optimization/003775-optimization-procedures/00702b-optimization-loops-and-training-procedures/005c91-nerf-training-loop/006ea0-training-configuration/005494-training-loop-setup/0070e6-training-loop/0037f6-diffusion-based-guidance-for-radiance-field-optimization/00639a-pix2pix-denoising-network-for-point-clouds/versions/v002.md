# Pix2Pix Denoising Network for Point Clouds

Also called: DSS-based denoising, DSS-based point cloud denoising, Differentiable Surface Splatting denoising

## Overview
A generative adversarial network (GAN) based method to denoise point cloud renderings by mapping noisy splat images to clean splat images, followed by a 3D update via Differentiable Surface Splatting (DSS) [S1]. It solves the ill-posed problem of point cloud denoising where handcrafted priors struggle to recover both smooth and sharp features simultaneously [S1]. Unlike optimization-based methods that rely on local geometric priors, this approach leverages a learned image-to-image translation network to hallucinate plausible high-frequency details, which are then transferred to 3D geometry through simultaneous multi-view optimization [S1].

## How it works

### Inputs and Outputs
*   **Input:** A noisy point cloud $P_{\text{noisy}}$ with associated normals $N_{\text{noisy}}$ [S1].
*   **Output:** A denoised point cloud $P_{\text{clean}}$ with associated normals $N_{\text{clean}}$ [S1].

### Data Structures
*   **Point Cloud:** A set of points $P = \{p_i\}$ where each $p_i \in \mathbb{R}^3$ and a normal $n_i \in \mathbb{R}^3$ [S1].
*   **Image:** A 2D tensor $I \in \mathbb{R}^{H \times W \times C}$ representing the rendered splat image [G].
*   **Generator ($G$):** A ResNet-based architecture mapping noisy images to clean images [S1].
*   **Discriminator ($D$):** A convolutional network classifying images as real or generated [S1].

### Numbered Steps

1.  **Data Preparation:**
    *   Sample 20,000 points per model from the Sketchfab dataset using Poisson-disk sampling to create reference point clouds [S1].
    *   Create noisy input points by adding white Gaussian noise to the reference points [S1].
    *   Compute PCA normals for both reference and input points [S1].
    *   Render training pairs (noisy and clean images) using DSS from various viewpoints and distances. Use point light and diffuse shading only [S1].

2.  **Network Training (Offline):**
    *   Train two separate Pix2Pix models targeting specific noise levels: 1.0% and 0.3% [S1].
    *   The generator uses a ResNet architecture with 2-stride convolution and 2-stride up-convolution for encoder/decoder, with 9 residual blocks in-between [S1].
    *   The discriminator uses convolutional layers with channel counts $C64-C128-C256-C512-C1$ [S1].
    *   Apply pixel-wise normalization in the generator to deal with checkerboard artifacts [S1].
    *   Add a convolutional layer after each deconvolutional layer in the discriminator to deal with checkerboard artifacts [S1].
    *   Remove the tanh activation in the final layer of the generator to obtain unbounded pixel values [S1].
    *   Optimize using Least Squares GAN (LSGAN) loss [S1].
    *   Use ADAM optimizer with $lr = 0.0002$, $\beta_1 = 0.5$, $\beta_2 = 0.999$ [S1].
    *   Initialize weights using Xavier initialization [S1].

3.  **Inference and 3D Update:**
    *   Render images of the noisy point cloud from multiple views [S1].
    *   Pass the noisy images through the trained Pix2Pix network to reconstruct geometric structure (clean splat images) [S1].
    *   Update the point cloud using DSS with the denoised images as reference [S1].
    *   The simultaneous multi-view optimization in DSS resolves cross-view inconsistencies, transferring plausible 2D details to 3D without visible artifacts [S1].

### Formulas

**Generator Architecture:**
The generator $G$ consists of an encoder, 9 residual blocks, and a decoder.
$$ G = D_{\text{decoder}} \circ \text{ResNet}_{9} \circ E_{\text{encoder}} $$
Where $E_{\text{encoder}}$ uses 2-stride convolutions and $D_{\text{decoder}}$ uses 2-stride up-convolutions [S1].

**Discriminator Architecture:**
The discriminator $D$ consists of a sequence of convolutional layers:
$$ D = \text{Conv}_{C1} \circ \text{Conv}_{C512} \circ \text{Conv}_{C256} \circ \text{Conv}_{C128} \circ \text{Conv}_{C64} $$
Where $C_k$ denotes a convolutional layer with $k$ output channels [S1].

**Loss Function:**
Least Squares GAN (LSGAN) loss is used [S1].
$$ \mathcal{L}_{\text{GAN}} = \mathbb{E}_{y \sim p_{\text{data}}}[(D(y) - 1)^2] + \mathbb{E}_{x \sim p_g}[(D(G(x)) - 0)^2] $$
*(Standard LSGAN formulation provided for implementation completeness [G].)*

**Optimizer:**
ADAM update rule:
$$ \theta_{t+1} = \theta_t - \frac{\eta \hat{m}_t}{\sqrt{\hat{v}_t} + \epsilon} $$
With $\eta = 0.0002$, $\beta_1 = 0.5$, $\beta_2 = 0.999$ [S1]. *(Standard ADAM formulation provided for implementation completeness [G].)*

### Parameters
*   **Noise Levels:** Two models trained for 1.0% and 0.3% noise [S1].
*   **Generator:** ResNet with 9 residual blocks, 2-stride conv/up-conv [S1].
*   **Discriminator:** Channels $[64, 128, 256, 512, 1]$ [S1].
*   **Optimizer:** ADAM ($lr=0.0002, \beta_1=0.5, \beta_2=0.999$) [S1].
*   **Initialization:** Xavier [S1].
*   **Hardware:** NVIDIA 1080Ti GPU [S1].
*   **Lighting:** Point light and diffuse shading only [S1].

### Edge Cases and Pitfalls
*   **Checkerboard Artifacts:** Mitigated by pixel-wise normalization in the generator and adding a convolutional layer after each deconvolutional layer in the discriminator [S1].
*   **Unbounded Values:** The tanh activation is removed from the generator's final layer to allow unbounded pixel values [S1].
*   **View Inconsistency:** The Pix2Pix model is not trained with view-consistency constraints. Small inconsistencies may appear in high-frequency detail regions across views, but DSS resolves these during the 3D update phase [S1].
*   **Lighting Complexity:** Glossy/specular effects are avoided because they pose unnecessary difficulties for the network to infer local geometric structure [S1].

### Pseudocode

```python
import torch
import torch.nn as nn
import torch.optim as optim

class ResNetGenerator(nn.Module):
    def __init__(self, input_nc=3, output_nc=3, ngf=64, n_residual=9):
        super(ResNetGenerator, self).__init__()
        # Encoder: 2-stride convolutions
        self.encoder = nn.Sequential(
            nn.Conv2d(input_nc, ngf, kernel_size=4, stride=2, padding=1),
            nn.InstanceNorm2d(ngf), # Pixel-wise normalization
            nn.LeakyReLU(0.2, inplace=True)
        )
        # Bottleneck: 9 residual blocks
        self.bottleneck = nn.Sequential()
        for i in range(n_residual):
            self.bottleneck.add_module(f'res{i}', ResidualBlock(ngf))
        
        # Decoder: 2-stride up-convolutions (no tanh for unbounded values)
        self.decoder = nn.Sequential(
            nn.ConvTranspose2d(ngf, output_nc, kernel_size=4, stride=2, padding=1)
        )

    def forward(self, x):
        x = self.encoder(x)
        x = self.bottleneck(x)
        x = self.decoder(x)
        return x

class ResidualBlock(nn.Module):
    def __init__(self, channels):
        super(ResidualBlock, self).__init__()
        self.conv1 = nn.Conv2d(channels, channels, kernel_size=3, padding=1)
        self.norm1 = nn.InstanceNorm2d(channels)
        self.conv2 = nn.Conv2d(channels, channels, kernel_size=3, padding=1)
        self.norm2 = nn.InstanceNorm2d(channels)
        
    def forward(self, x):
        identity = x
        out = self.conv1(x)
        out = self.norm1(out)
        out = nn.ReLU(inplace=True)(out)
        out = self.conv2(out)
        out = self.norm2(out)
        out += identity
        return out

class Discriminator(nn.Module):
    def __init__(self, input_nc=3, ndf=64):
        super(Discriminator, self).__init__()
        # C64-C128-C256-C512-C1 architecture
        self.model = nn.Sequential(
            nn.Conv2d(input_nc, ndf, kernel_size=4, stride=2, padding=1),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Conv2d(ndf, ndf*2, kernel_size=4, stride=2, padding=1),
            nn.InstanceNorm2d(ndf*2),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Conv2d(ndf*2, ndf*4, kernel_size=4, stride=2, padding=1),
            nn.InstanceNorm2d(ndf*4),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Conv2d(ndf*4, ndf*8, kernel_size=4, stride=2, padding=1),
            nn.InstanceNorm2d(ndf*8),
            nn.LeakyReLU(0.2, inplace=True),
            nn.Conv2d(ndf*8, 1, kernel_size=4, stride=1, padding=1)
        )

    def forward(self, x):
        return self.model(x)

def render_dss(point_cloud, view_matrix):
    """
    Renders a point cloud to a 2D splat image using Differentiable Surface Splatting.
    point_cloud: Tensor of shape (N, 3) for positions and (N, 3) for normals.
    view_matrix: Camera view-projection matrix.
    Returns: Rendered image tensor of shape (H, W, 3).
    """
    # Standard DSS rasterization: project points, sort by depth, splat to pixels

def dss_optimize(point_cloud, target_images, view_matrices, optimizer, steps=100):
    """
    Updates point cloud positions to minimize rendering error against target images.
    point_cloud: Tensor of shape (N, 3).
    target_images: Tensor of shape (V, H, W, 3).
    view_matrices: List of V view matrices.
    optimizer: Optimizer for point positions.
    steps: Number of optimization iterations.
    """
    for _ in range(steps):
        optimizer.zero_grad()
        rendered_images = []
        for view in view_matrices:
            img = render_dss(point_cloud, view)
            rendered_images.append(img)
        rendered_images = torch.stack(rendered_images)
        loss = nn.MSELoss()(rendered_images, target_images)
        loss.backward()
        optimizer.step()
    return point_cloud

def train_pix2pix(noisy_images, clean_images, generator, discriminator, optimizer_G, optimizer_D, epochs=2):
    # LSGAN Loss (MSE)
    criterion = nn.MSELoss()
    
    for epoch in range(epochs):
        # Train Discriminator
        optimizer_D.zero_grad()
        # Real images
        output_real = discriminator(clean_images)
        label_real = torch.ones_like(output_real)
        loss_real = criterion(output_real, label_real)
        
        # Generated images
        with torch.no_grad():
            fake_images = generator(noisy_images)
        output_fake = discriminator(fake_images.detach())
        label_fake = torch.zeros_like(output_fake)
        loss_fake = criterion(output_fake, label_fake)
        
        loss_D = (loss_real + loss_fake) / 2
        loss_D.backward()
        optimizer_D.step()
        
        # Train Generator
        optimizer_G.zero_grad()
        output_fake = discriminator(fake_images)
        label_fake = torch.ones_like(output_fake)
        loss_G = criterion(output_fake, label_fake)
        loss_G.backward()
        optimizer_G.step()

def denoise_point_cloud(noisy_point_cloud, views, generator, steps=100):
    """
    1. Render noisy images from multiple views.
    2. Denoise images using Pix2Pix.
    3. Update point cloud using DSS with denoised images as reference.
    """
    # Step 1: Render noisy images
    noisy_images = []
    for view in views:
        img = render_dss(noisy_point_cloud, view)
        noisy_images.append(img)
    noisy_images = torch.stack(noisy_images)
    
    # Step 2: Denoise images
    clean_images = generator(noisy_images)
    
    # Step 3: Update point cloud using DSS
    optimizer = optim.Adam([noisy_point_cloud], lr=0.001)
    denoised_point_cloud = dss_optimize(noisy_point_cloud, clean_images, views, optimizer, steps)
    
    return denoised_point_cloud
```

## Operating characteristics
*   **Measured Performance:** On 1% noisy, 20K point input: Pix2Pix-DSS outperforms WLOP, EAR, RIMLS, GPF, and PointCleanNet quantitatively and qualitatively [S1]. On 0.3% noisy, 100K point input: Pix2Pix-DSS reconstructs clean surfaces with abundant hallucinated details, outperforming PointCleanNet which deteriorates due to generalizability issues [S1].
*   **Strengths:** Can hallucinate plausible high-frequency details that optimization-based methods miss [S1]. Less sensitive to point sampling characteristics compared to direct learning-based methods [S1]. Simultaneous multi-view optimization in DSS resolves cross-view inconsistencies [S1].
*   **Limitations:** Not trained with view-consistency constraints, potentially causing small inconsistencies in high-frequency detail regions across views [S1]. Limited to the noise levels it was trained on (1.0% and 0.3%) [S1].
*   **Time Complexity:** Training requires approximately two days on an NVIDIA 1080Ti GPU [S1].
