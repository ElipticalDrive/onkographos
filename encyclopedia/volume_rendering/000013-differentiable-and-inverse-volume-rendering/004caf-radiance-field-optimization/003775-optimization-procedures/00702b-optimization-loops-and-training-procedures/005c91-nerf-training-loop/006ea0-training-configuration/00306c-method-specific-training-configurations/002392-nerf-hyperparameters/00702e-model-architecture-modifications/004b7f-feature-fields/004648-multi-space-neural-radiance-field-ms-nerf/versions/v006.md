# Multi-Space Neural Radiance Field (MS-NeRF)

Also called: MS-Mip-NeRF 360, MS-NeRFB, Multi-space NeRF

## Overview
MS-NeRF addresses the failure of standard single-space NeRF methods to render reflective and refractive objects, which typically result in blurry or distorted images due to violated multi-view consistency in Euclidean space [S1]. It differs from its siblings by representing the scene as a group of feature fields in parallel sub-spaces rather than a single radiance field, allowing virtual images to be placed in sub-spaces visible only from specific viewpoints [S1]. This approach serves as a general enhancement module for existing NeRF backbones (MLP-based or grid-based) with minimal computational overhead [S1].

## How it works
MS-NeRF replaces the standard output layer of a backbone NeRF network with a multi-space module that outputs multiple densities and feature vectors per ray sample, corresponding to different sub-spaces [S1].

**Inputs and Outputs:**
*   **Input:** Ray $r$, backbone network parameters, hyperparameters $K$ (number of sub-spaces) and $d$ (feature dimension).
*   **Output:** Final rendered color $\hat{C}(r)$.

**Data Structures:**
*   **Sub-spaces:** $K$ parallel feature fields.
*   **Per-sample data:** For each sample $i$ along a ray and each sub-space $k$:
    *   Density $\sigma_{ik}$ (scalar).
    *   Feature vector $f_{ik}$ (dimension $d$).
*   **Aggregated Feature Map:** $F^k$ for each sub-space $k$, computed by integrating samples along the ray.
*   **MLPs:**
    *   Decoder MLP ($\Theta_D$): Takes $F^k$, outputs RGB color $C^k$.
    *   Gate MLP ($\Theta_G$): Takes $F^k$, outputs visibility weight $w_k$.

**Numbered Steps:**

1.  **Ray Casting and Multi-Space Sampling:**
    For a given ray $r$, sample $N$ points along the ray. For each sample point $i$ and each sub-space $k \in \{1, \dots, K\}$, query the backbone network to obtain the density $\sigma_{ik}$ and the feature vector $f_{ik}$ of dimension $d$ [S1].

2.  **Feature Integration per Sub-space:**
    Compute the aggregated feature map $F^k$ for each sub-space $k$ by integrating the features along the ray, weighted by the transmittance and density of that specific sub-space [S1]:
    $$
    \hat{F}^k(r) = \sum_{i=1}^{N} T_i^k (1 - \exp(-\sigma_{ik} \delta_i)) f_{ik}
    $$
    where:
    *   $\delta_i$ is the distance between sample $i$ and $i+1$.
    *   $T_i^k = \exp\left(-\sum_{j=1}^{i-1} \sigma_{jk} \delta_j\right)$ is the accumulated transmittance for sub-space $k$ up to sample $i$.
    *   $f_{ik}$ is the feature vector at sample $i$ in sub-space $k$.
    *   $T_1^k = 1$ [S1].

3.  **Multi-Head Output Generation:**
    Pass the aggregated feature maps $\{F^k\}_{k=1}^K$ through two separate Multi-Layer Perceptrons (MLPs) [S1]:
    *   **Decoder MLP ($\Theta_D$):** Maps $F^k$ to an RGB color vector $C^k$:
        $$
        \Theta_D\{F^k\} \rightarrow \{C^k\}
        $$
    *   **Gate MLP ($\Theta_G$):** Maps $F^k$ to a scalar visibility weight $w_k$:
        $$
        \Theta_G\{F^k\} \rightarrow \{w_k\}
        $$
    Both MLPs have one hidden layer [S1].

4.  **Softmax Weighting and Final Rendering:**
    Apply the softmax function to the visibility weights $\{w_k\}$ to determine the contribution of each sub-space to the final color [S1]:
    $$
    \hat{C}(r) = \sum_{k=1}^{K} \left( \frac{\exp(w_k)}{\sum_{i=1}^{K} \exp(w_i)} \right) C^k
    $$
    This equation combines the colors $C^k$ from all sub-spaces, weighted by their relative visibility [S1].

**Parameters:**
*   $K$: Total number of sub-spaces. Typical values are not explicitly fixed in the text but are described as hyperparameters [S1].
*   $d$: Feature dimension of the neural feature field. Described as a hyperparameter [S1].

**Pitfalls and Edge Cases:**
*   **Complex Scenes:** More complex reflective and refractive scenes may require a larger number of sub-spaces ($K$) to be accurately modeled [S2].
*   **No Additional Loss:** The method requires no additional loss terms compared to vanilla NeRF; the multi-space module is integrated into the standard rendering pipeline [S1].
*   **Virtual Images:** Unlike vanilla NeRF which treats virtual images as textures on reflective surfaces (leading to blur), MS-NeRF places virtual images in specific sub-spaces visible only from certain views, overcoming multi-view consistency violations [S1].

**Pseudocode:**

```python
def ms_nerf_render(ray, backbone_mlp, decoder_mlp, gate_mlp, K, d, num_samples):
    """
    Renders a single ray using the MS-NeRF multi-space module.
    
    Args:
        ray: Ray origin and direction.
        backbone_mlp: The pre-trained backbone NeRF network.
        decoder_mlp: The Decoder MLP (Theta_D) with one hidden layer.
        gate_mlp: The Gate MLP (Theta_G) with one hidden layer.
        K: Number of sub-spaces.
        d: Feature dimension.
        num_samples: Number of samples along the ray.
        
    Returns:
        final_color: Rendered RGB color.
    """
    # Step 1: Sample points and query multi-space features
    # Initialize arrays for densities and features for all sub-spaces
    # Shape: (num_samples, K) for densities, (num_samples, K, d) for features
    densities = torch.zeros(num_samples, K)
    features = torch.zeros(num_samples, K, d)
    
    for i in range(num_samples):
        point = ray.sample_point(i)
        for k in range(K):
            # Query backbone for sub-space k
            # Note: In practice, backbone might be shared or have sub-space specific heads
            # The source implies the backbone outputs K densities and features
            densities[i, k], features[i, k] = backbone_mlp(point, sub_space_index=k)
            
    # Step 2: Integrate features per sub-space
    # Initialize aggregated features for each sub-space
    aggregated_features = torch.zeros(K, d)
    
    for k in range(K):
        transmittance = 1.0
        accumulated_feature = torch.zeros(d)
        
        for i in range(num_samples):
            sigma = densities[i, k]
            delta = ray.sample_distance(i) # Distance between sample i and i+1
            f = features[i, k]
            
            # Contribution: T_i * (1 - exp(-sigma * delta)) * f
            alpha = 1.0 - torch.exp(-sigma * delta)
            contribution = transmittance * alpha * f
            accumulated_feature += contribution
            
            # Update transmittance for next sample
            transmittance *= torch.exp(-sigma * delta)
            
        aggregated_features[k] = accumulated_feature
        
    # Step 3: Generate colors and weights via MLPs
    colors = torch.zeros(K, 3)
    weights_raw = torch.zeros(K)
    
    for k in range(K):
        # Decoder MLP: F^k -> C^k
        colors[k] = decoder_mlp(aggregated_features[k])
        # Gate MLP: F^k -> w_k
        weights_raw[k] = gate_mlp(aggregated_features[k])
        
    # Step 4: Softmax weighting and final color
    # Apply softmax to weights
    softmax_weights = torch.softmax(weights_raw, dim=0)
    
    # Weighted sum of colors
    final_color = torch.sum(softmax_weights.unsqueeze(1) * colors, dim=0)
    
    return final_color
```

## Subtopics

### Grid-based Multi-Space NeRF
Adapts the multi-space module to grid-based NeRF methods (e.g., TensoRF, iNGP) for accelerated training and inference [S1].

### MLP-based Multi-Space NeRF
Applies the module to MLP-based methods (e.g., NeRF, Mip-NeRF, Mip-NeRF 360) [S1].

## Operating characteristics
*   **Computational Overhead:** The method introduces only small computational overheads for training and inference compared to single-space NeRF methods [S1].
*   **Performance:**
    *   On Mip-NeRF 360, it improves PSNR by 4.15 dB on reflective regions with 0.5% extra parameters, without degrading quality on other regions [S1].
    *   On TensoRF, it improves PSNR by 2.71 dB on reflective regions with 0.046% extra parameters, without degrading quality on other regions [S1].
*   **Strengths:** Automatically handles mirror-like objects in 360-degree rendering without manual labeling of reflective surfaces [S1]. Significantly outperforms single-space NeRF in scenes with complex reflections and refractions [S1, S2].
*   **Limitations:** May require more sub-spaces ($K$) for highly complex reflective and refractive scenes [S2].
*   **Usage:** Used as an enhancement module for MLP-based and grid-based NeRF methods, and integrated with reconstruction methods like NeuS [S1].

## Background
MS-NeRF was proposed to address the limitations of existing NeRF methods in handling reflective objects, which often result in blurry or distorted rendering [S1]. The method was introduced by Z.X. Yin, P.Y. Jiao, M.M. Cheng, B. Ren, and J. Qiu [S1]. A preliminary version appeared at CVPR, with the full version published in IEEE Transactions on Pattern Analysis and Machine Intelligence in 2025 [S1]. The authors also constructed a novel dataset with 33 synthetic and 7 real captured scenes with complex reflection and refraction to benchmark the method [S1].
