# Panoptic Radiance Field

Also called: Panoptic Lifting

## Overview
Panoptic Lifting learns a panoptic 3D volumetric representation from posed RGB images and machine-generated 2D panoptic segmentation masks, lifting noisy 2D labels into a consistent 3D representation comprising color, density, semantics, and instances [S1]. It differs from siblings like [Panoptic NeRF](11916-panoptic-nerf.md) and [DM-NeRF](11916-dm-nerf.md) by requiring only machine-generated 2D labels rather than manual ground truth or coarse meshes, and by explicitly modeling instance consistency via surrogate identifiers and linear assignment [S1].

## How it works
**Inputs:** Posed RGB images $\{I\}$ and corresponding machine-generated 2D panoptic segmentation masks. Each training ray $r$ has an associated RGB color $\hat{\mathbf{c}}_r \in \mathbb{R}^3$, semantic class $\hat{k}_r \in K$, and 2D instance ID $\hat{h}_r \in H_I$ (defined only for thing classes $\hat{k}_r \in K_T$) [S1].

**Outputs:** A panoptic radiance field $\Phi(\mathbf{x}, \mathbf{d})$ that assigns to each 3D point $\mathbf{x} \in \mathbb{R}^3$ and viewing direction $\mathbf{d} \in S^2$:
1.  Density $\sigma \in \mathbb{R}_{\ge 0}$.
2.  Semantic class distribution $\kappa$ over classes $K$.
3.  Distribution $\pi$ over surrogate identifiers $J$.
4.  RGB color $\mathbf{c} \in \mathbb{R}^3$ [S1].

**Data Structures:**
*   **Panoptic Radiance Field $\Phi$:** Composed of a TensoRF representation for density and color, and two separate small MLPs for semantics and instances [S1].
*   **Classes $K$:** Partitioned into thing classes $K_T$ and stuff classes $K_S$ [S1].
*   **Surrogate Identifiers $J$:** A fixed number of class-agnostic, 3D-consistent identifiers held by the instance MLP [S1].
*   **3D Instances $H_{3D}$:** Defined as $H_{3D} := K_T \times J$ [S1].

**Rendering Equation:**
For a vector field $f$ along ray $r$ given density $\sigma$:
$$ R[f |r, \sigma] := \int_0^\infty \alpha_t (r)\sigma(r_t)f (r_t, \mathbf{d}_{r_t})dt $$
where $\alpha_t (r) := \exp \left(-\int_0^t \sigma(r_s)ds\right)$ is the transmittance probability at $t$ [S1].

**Training Steps:**
1.  **Preprocessing (Test-Time Augmentation):** Apply augmentations (horizontal flip, scale, brightness, contrast) to input images. Fuse resulting segmentations via segment clustering to obtain a semantic class distribution $\hat{\kappa}_r$ and confidence estimate $w_r$ for each pixel/ray [S1].
2.  **Linear Assignment:** Solve a linear assignment problem to map noisy 2D instance IDs $\hat{h}_r$ to 3D surrogate identifiers $j \in J$. The cost is based on the model's current predictions and the 2D masks, enabling consistent lifting of 2D instances to 3D [S1].
3.  **Forward Pass:** Query $\Phi(\mathbf{x}, \mathbf{d})$ for sampled rays. Render color $\mathbf{c}_r$, semantic distribution $\kappa_r$, and instance distribution $\pi_r$ using the rendering equation [S1].
4.  **Loss Computation:** Compute the total loss $L_{tot}$ [S1]:
    $$ L_{tot}(R) := \lambda_{ins} L_{ins}(R_I) + \lambda_{con} L_{con}(R_I) + \lambda_{RGB} L_{RGB}(R_S) + \lambda_{sem} L_{sem}(R_S) $$
    where $R_S$ are rays randomly sampled across the scene and $R_I$ are rays sampled from a single image [S1].
    *   **Semantic Loss ($L_{sem}$):** Cross-entropy between rendered distribution $\kappa_r$ and 2D label distribution $\hat{\kappa}_r$, weighted by confidence $w_r$ [S1]:
        $$ L_{sem}(R) := -\frac{1}{|R|} \sum_{r \in R} w_r \sum_{k \in K} \hat{\kappa}_r(k) \log \kappa_r(k) $$
    *   **Instance Loss ($L_{ins}$):** Log-loss of the co-occurrence of mapped 2D instances and rendered surrogate identifiers [S1].
    *   **Segment Consistency Loss ($L_{con}$):** Guides semantic supervision to avoid fragmenting objects due to label inconsistencies [S1].
    *   **Photometric Loss ($L_{RGB}$):** L2 loss on rendered color [S1].
5.  **Optimization:** Update parameters using Adam [S1].

**Edge Cases and Pitfalls:**
*   **Logits vs. Probabilities:** Rendering class logits instead of probabilities can introduce semantic inconsistencies because unbounded logits can generate significant signals in low-density areas, violating geometric constraints. The method resolves this by rendering bounded probability distributions (using Softmax) [S1].
*   **Geometry Degradation:** Supervision from noisy 2D labels can influence geometry, causing "cloudy" geometry to satisfy conflicting labels. This is avoided by stopping gradients from the semantic and instance branches back to the density (geometry) parameters [S1].
*   **Label Noise:** Machine-generated labels are noisy and inconsistent across views. Test-time augmentations and confidence weighting are critical to mitigate this [S1].

## Operating characteristics
*   **Time Complexity:** Training is lengthy, requiring ~450k iterations (~10 hours) on a single NVIDIA A6000 [S1].
*   **Memory Complexity:** Uses TensoRF for density/color and small MLPs for semantics/instances, which is more memory-efficient than dense MLPs for all fields [S1].
*   **Performance:** Improves scene-level Panoptic Quality (PQ) by 8.4% on Hypersim, 13.8% on Replica, and 10.6% on ScanNet over state-of-the-art methods [S1]. Maintains comparable PSNR for novel view synthesis [S1].
*   **Strengths:** Robust to noise in machine-generated labels; does not require manual ground truth or 3D bounding boxes; enables scene editing (deletion, duplication, manipulation) [S1].
*   **Limitations:** Limited to classes supported by the pre-trained 2D segmentation model (e.g., Mask2Former); runs offline due to pre-processing (pose estimation, 2D segmentation) and optimization time [S1].

## Background
Panoptic Lifting was introduced in 2023 by the authors of "Panoptic Lifting for 3D Scene Understanding with Neural Fields" [S1]. It addresses the limitations of prior panoptic NeRF methods (like Panoptic NeRF and DM-NeRF) which required manual ground truth or coarse meshes, by lifting machine-generated 2D panoptic labels into a consistent 3D representation [S1]. It builds on [TensoRF](13550-model-architecture-and-encoding.md) for efficient density and color representation [S1].
