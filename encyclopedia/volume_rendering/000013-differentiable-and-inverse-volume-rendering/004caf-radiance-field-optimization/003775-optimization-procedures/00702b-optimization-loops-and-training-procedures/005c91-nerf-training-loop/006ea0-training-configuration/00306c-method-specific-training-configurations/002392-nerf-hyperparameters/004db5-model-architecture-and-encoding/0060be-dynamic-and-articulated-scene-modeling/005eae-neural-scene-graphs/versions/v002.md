# Neural Scene Graphs

Also called: NSG

## Overview
Neural Scene Graphs (NSG) is a method for decomposing dynamic, multi-object scenes into a learned hierarchical scene graph with decoupled object transformations and scene representations, enabling novel view synthesis and rendering of unseen object arrangements [S1]. Unlike existing neural rendering methods that encode the entire scene into a single, static network, NSG uses a hierarchical scene-graph model with object-level implicit representations, allowing for the modeling of dynamic scenes with varying object poses and compositions [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of video frames and corresponding tracking data (labels for object instances, classes, and poses) [S1].
*   **Outputs:** A learned scene graph $S$ comprising a background node, a camera node, and dynamic object nodes, along with optimized parameters for rendering [S1].

**Data Structures:**
The scene is defined as a directed acyclic graph $S$:
$$ S = \langle W, C, F, L, E \rangle \quad (1) $$
*   $W$: Root node representing the global world space [S1].
*   $C$: Camera node [S1].
*   $F$: Set of representation models (neural radiance fields) [S1].
*   $L$: Latent descriptors for objects [S1].
*   $E$: Set of edges representing affine transformations or property assignments [S1].

Edges $E$ are defined as:
$$ E = \{ e_{u,v} \in \{ \mathbf{0}, M_{uv} \} \} \quad (2) $$
where $M_v = \begin{bmatrix} R & t \\ 0 & 1 \end{bmatrix}$, with $R \in \mathbb{R}^{3 \times 3}$ and $t \in \mathbb{R}^3$ [S1].

**Representation Models:**
*   **Background Node ($F_{\theta_{bckg}}$):** Approximates static parts of the scene. It maps a point $x$ and viewing direction $d$ to color $c$ and density $\sigma$: $F_{\theta_{bckg}} : (x, d) \rightarrow (c, \sigma)$ [S1]. It lives on sparse planes rather than a volume [S1]. It uses Fourier encodings for high-frequency learning [S1].
*   **Object Nodes ($F_{\theta_o}$):** Represent dynamic objects as augmented implicit neural radiance fields, following Mildenhall et al. [22] [S1]. Instances of the same class share a volumetric representation model $F$ [S1].

**Algorithm Steps:**
1.  **Graph Construction:** Initialize the scene graph $S$ with a root node $W$, a camera node $C$, and dynamic nodes for each object instance [S1].
2.  **Edge Assignment (Transformations):** For all edges originating from the root node $W$, assign transformations $T^W_v$ between the global world space and the local object or camera space [S1].
3.  **Scaling Assignment:** To represent different scales of the same object type, compute the non-uniform scaling matrix $S_o$. Assign this scaling at edge $e_{o,f}$ between the object node and its shared representation model $F$ [S1].
4.  **Latent Code Optimization:** Optimize latent descriptors $l_o$ for each object to enable generalization across a class of objects [S1].
5.  **Rendering/Querying:** To retrieve an object’s local transformation and position $p_o = [x, z, y]_o$:
    *   Traverse from the root node $W$.
    *   Apply transformations along the path until the desired object node $F_{\theta_o}$ is reached [S1].
    *   This ends in the frame of reference defined by the accumulated transformations (Eq. 8 in source) [S1].
6.  **Differentiable Rendering:** Use differentiable ray casting/marching through the scene volume to infer features for sampling points along a ray, optimizing the graph parameters via gradient descent [S1].

**Parameters:**
*   **Fourier Encodings:** Used for the background node MLP [S1].
*   **Sparse Planes:** Used for background representation instead of a dense volume [S1].
*   **Shared Volumetric Representation:** Used for object instances of the same class [S1].

**Edge Cases and Pitfalls:**
*   **Dynamic Scenes:** The method specifically addresses scenes where static assumptions fail, requiring tracking data for training [S1].
*   **Unseen Arrangements:** The method must handle rendering of unseen sets of objects at unseen poses, which requires robust decomposition of the graph [S1].

## Operating characteristics
*   **Complexity:** Not given in the sources.
*   **Performance:** Validated on simulated and experimental data, rendering novel unseen views and dynamic scene arrangements [S1].
*   **Strengths:** Allows for 3D object detection using inverse rendering; facilitates continuous view interpolation; handles dynamic, multi-object scenes [S1].
*   **Limitations:** Relies on labeled and generated tracking data for training [S1].

## Background
*   **Origin:** Proposed by Niemeyer et al. in "Neural Scene Graphs for Dynamic Scenes" (CVPR 2021) [S1].
*   **Development:** Builds upon implicit neural representations for static scenes (NeRF) [S1]. It extends differentiable rendering to dynamic scenes by introducing a hierarchical scene-graph model [S1].
*   **Usage:** Used for novel view synthesis of dynamic scenes, 3D object detection, and modeling scenes with unseen object arrangements [S1].
