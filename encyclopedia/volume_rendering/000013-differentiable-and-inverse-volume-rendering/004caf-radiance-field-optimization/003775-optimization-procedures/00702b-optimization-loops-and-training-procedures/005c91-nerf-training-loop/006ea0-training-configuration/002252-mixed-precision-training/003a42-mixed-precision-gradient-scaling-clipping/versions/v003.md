# Mixed Precision & Gradient Scaling/Clipping

Also called: Adaptive Gradient Clipping, GradScaler Optimization Step

## Overview
This method combines automatic mixed precision (AMP) gradient scaling with L2 norm clipping to stabilize optimization in differentiable volume rendering [S1, unofficial]. Scaling the loss before backpropagation and clipping gradients prevents silent failures from NaN/Inf values and mitigates texture contamination from high-variance Monte Carlo estimates [S1, unofficial][S2].

## How it works
**Inputs:**
- `loss`: The scalar loss tensor.
- `optimizer`: The optimization instance.
- `grad_scaler`: The AMP gradient scaler instance.
- `max_norm`: Maximum L2 norm for gradient clipping (from optimizer config).

**Outputs:**
- Optimizer step executed or skipped.

**Data Structures:**
- `grad_scaler`: Manages the scaling factor `scale`.
- `optimizer`: Contains parameter groups with gradients.

**Steps:**
1. **Scale Loss:** Multiply the loss by the scaler's current factor [S1, unofficial].
   $$ loss_{scaled} = loss \times scale $$
2. **Backward Pass:** Compute gradients for all parameters [S1, unofficial].
   $$ loss_{scaled}.backward() $$
3. **Unscale Gradients:** Retrieve the unscaled gradients from the parameters before clipping [S1, unofficial].
   $$ grad\_scaler.unscale\_(optimizer) $$
4. **Clip Gradients:** If `max_norm` is not `None`, clip the global L2 norm of all gradients [S1, unofficial].
   $$ \text{clip\_grad\_norm\_}(parameters, max\_norm=max\_norm) $$
   If `max_norm` is `None`, this step is skipped [S1, unofficial].
5. **Check Finiteness:** Verify that at least one parameter group has non-`None` gradients and that all gradients are finite; skip the step if not [S1, unofficial].
6. **Step Optimizer:** Update the parameters if the check passes [S1, unofficial].
7. **Update Scaler:** Adjust the scaler's internal state based on finiteness history [G].

**Pseudocode:**
```python
def optimizer_scaler_step(optimizer, grad_scaler, loss, max_norm=None):
    # 1. Scale loss
    scaled_loss = loss * grad_scaler.scale

    # 2. Backward pass
    scaled_loss.backward()

    # 3. Unscale gradients
    grad_scaler.unscale_(optimizer)

    # 4. Clip gradients if max_norm is specified
    if max_norm is not None:
        total_norm_sq = 0.0
        for group in optimizer.param_groups:
            for p in group['params']:
                if p.grad is not None:
                    for g in p.grad.flatten():
                        total_norm_sq += g * g
        total_norm = total_norm_sq ** 0.5
        clip_coef = max_norm / (total_norm + 1e-6)
        if clip_coef < 1.0:
            for group in optimizer.param_groups:
                for p in group['params']:
                    if p.grad is not None:
                        for i in range(p.grad.numel()):
                            p.grad.flatten()[i] *= clip_coef

    # 5. Check finiteness and non-None gradients
    has_valid_grads = False
    all_finite = True
    for group in optimizer.param_groups:
        for p in group['params']:
            if p.grad is not None:
                has_valid_grads = True
                for g in p.grad.flatten():
                    if g != g or abs(g) == float('inf'):
                        all_finite = False
                        break
            if not all_finite:
                break

    # 6. Step optimizer if valid
    if has_valid_grads and all_finite:
        optimizer.step()

    # 7. Update scaler
    grad_scaler.update()
```

**Parameters:**
- `max_norm`: Maximum L2 norm for gradient clipping. If `None`, clipping is skipped [S1, unofficial]. Typical values are not given in the sources [G].

**Edge Cases:**
- **NaN/Inf Gradients:** If gradients contain NaN or Inf, the optimizer step is skipped to prevent silent corruption [S1, unofficial].
- **No Gradients:** If no parameter groups have non-`None` gradients, the step is skipped [S1, unofficial].

## Subtopics

### Gradient Clamping
A regularization technique that clamps gradients to the range $[-10^{-8}, 10^{-8}]$ before Adam rescaling [S2]. It prevents extremely high-valued outliers caused by improbable light paths in path-traced samples from contaminating optimized textures [S2]. This applies a hard bound to individual gradient values rather than the global L2 norm [S2].

## Background
Originated in the context of differentiable volume rendering and neural radiance fields (NeRFs) [S1, unofficial]. The gradient clamping technique was introduced to handle noisy stochastic gradient descent and Monte Carlo estimation noise in path-traced samples [S2]. The integration with AMP and gradient scaling follows standard deep learning optimization practices adapted for volume rendering [S1, unofficial].
