# CLIPNeRF Training Configuration

Also called: Absolute Directional CLIP Loss, CLIPNeRF Hyperparameters, CLIPNeRF Implementation, Directional CLIP Loss, Relative Directional CLIP Loss, StyleGAN-NADA CLIP Loss

## Overview
CLIPNeRF training configuration defines the optimization procedure for text-guided stylization of Neural Radiance Fields (NeRFs) by minimizing the negative cosine similarity between rendered images and text prompts in the CLIP embedding space [S1, S2]. It distinguishes itself from standard NeRF reconstruction by freezing density-related parameters and using a directional loss to enforce a specific stylization trajectory, addressing the intractability of high-resolution differentiable rendering through patch-based sampling [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A pre-trained NeRF model (MLP parameters), a source image $I_{src}$ (optional, for relative loss), a target text prompt $t_{tgt}$, and a source text prompt $t_{src}$ (optional, for relative loss).
*   **Outputs:** Updated NeRF MLP parameters that stylize the rendered views according to $t_{tgt}$.

**Data Structures:**
*   **NeRF Model:** Multi-layer Perceptron (MLP) mapping 3D coordinates and viewing directions to color and density. Parameters are split into density-related and appearance-related sub-parameters.
*   **CLIP Encoder:** ViT-B/32 architecture, fixed during training.
*   **Patch Data:** A $128 \times 128$ pixel patch sampled from the rendered view.

**Numbered Steps:**
1.  **Initialization:** Load the pre-trained NeRF model. Freeze all sub-parameters related to density. Initialize the appearance parameters for optimization.
2.  **Sampling:** Randomly sample a camera pose from the training dataset.
3.  **Patch Rendering:**
    *   Define a $128 \times 128$ pixel patch within the view.
    *   Sample rays for this patch with a stride interval of 5. This results in a receptive field of $640 \times 640$ in the original image space [S1].
    *   For each ray, perform volume rendering using importance sampling.
    *   Limit the number of importance sampling points to 16 per ray to manage memory [S1].
    *   The fine MLP uses a total of 80 samples (64 coarse + 16 fine) [S1].
    *   Apply bilinear interpolation to resize the rendered patch if necessary before feeding to CLIP [S1].
4.  **Embedding:**
    *   Encode the rendered patch $I_{tgt}$ using the CLIP image encoder $\mathcal{E}_i$ to get $\hat{e}_i = \mathcal{E}_i(I_{tgt})$ [S2].
    *   Encode the target text prompt $t_{tgt}$ using the CLIP text encoder $\mathcal{E}_t$ to get $\hat{e}_t = \mathcal{E}_t(t_{tgt})$ [S2].
    *   (Optional) If using relative loss, encode source image $I_{src}$ and source text $t_{src}$ to get $\mathcal{E}_i(I_{src})$ and $\mathcal{E}_t(t_{src})$ [S2].
5.  **Loss Calculation:**
    *   **Absolute Directional CLIP Loss:** Measures the cosine similarity between the normalized embedded vectors [S2].
        $$ \mathcal{L}_{dir} = \sum_{I_{tgt}} \left( 1 - \langle \hat{e}_i(I_{tgt}), \hat{e}_t(t_{tgt}) \rangle \right) $$
        where $\langle \cdot, \cdot \rangle$ denotes the cosine similarity (dot product of normalized vectors) [S2].
    *   **Relative Directional CLIP Loss:** Transfers style from source to target by measuring the trajectory in CLIP space [S2].
        $$ \mathcal{L}_{dir} = \sum_{I_{tgt}} \left( 1 - \langle \hat{e}_i(I_{tgt}) - \hat{e}_i(I_{src}), \hat{e}_t(t_{tgt}) - \hat{e}_t(t_{src}) \rangle \right) $$
        [S2].
6.  **Optimization:** Minimize the negative cosine similarity (equivalent to minimizing $\mathcal{L}_{dir}$) using the Adam optimizer [S1].

**Parameters:**
*   **Iterations:** 500 [S1].
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** 0.0001 [S1].
*   **Text Encoder:** CLIP ViT-B/32 [S1].
*   **Patch Size:** $128 \times 128$ [S1].
*   **Ray Sampling Stride:** 5 (within the patch) [S1].
*   **Importance Sampling Points:** 16 per ray [S1].
*   **Fine MLP Samples:** 80 total (64 coarse + 16 fine) [S1].

**Pitfalls:**
*   **Memory Constraints:** Naive differentiable rendering of high-resolution images is intractable due to memory constraints, necessitating the patch-based approach [S1].
*   **Mode Collapse:** The absolute directional CLIP loss can cause mode collapse of the generator and hurt generation diversity [S2].
*   **Insufficient Magnitude:** The directional loss only measures direction, ignoring magnitude, which can result in weak or insufficient style transfer [S2].

**Pseudocode:**
```python
# Configuration
iterations = 500
learning_rate = 0.0001
patch_size = 128
ray_stride = 5
importance_samples = 16
fine_samples = 80 # 64 coarse + 16 fine

# Initialize NeRF and freeze density parameters
nerf_model = load_nerf()
freeze_density_params(nerf_model)
optimizer = Adam(nerf_model.appearance_params, lr=learning_rate)

# Load CLIP model
clip_model = load_clip_vit_b_32()

for i in range(iterations):
    # 1. Sample random pose
    pose = sample_random_pose(training_dataset)
    
    # 2. Render patch
    # Calculate ray origins and directions for the patch with stride
    rays = generate_rays(pose, patch_size, stride=ray_stride)
    
    # Render using volume rendering with limited samples
    rendered_patch = render_nerf_patch(
        nerf_model, 
        rays, 
        importance_samples=importance_samples,
        fine_samples=fine_samples
    )
    
    # Resize if necessary (bilinear interpolation)
    rendered_patch = resize(rendered_patch, target_size=(224, 224)) # CLIP input size
    
    # 3. Encode
    # Target text prompt
    target_text = "stylized_prompt"
    img_emb = clip_model.encode_image(rendered_patch)
    text_emb = clip_model.encode_text(target_text)
    
    # Normalize embeddings
    img_emb = normalize(img_emb)
    text_emb = normalize(text_emb)
    
    # 4. Compute Loss (Absolute Directional)
    # Cosine similarity is dot product of normalized vectors
    similarity = dot_product(img_emb, text_emb)
    loss = 1.0 - similarity
    loss = loss.sum()
    
    # 5. Optimize
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

## Operating characteristics
*   **Time Complexity:** Dependent on the number of iterations (500) and the cost of rendering patches. The patch-based approach reduces memory usage but requires multiple forward passes for different patches.
*   **Memory Complexity:** Significantly reduced compared to full-resolution rendering by using $128 \times 128$ patches and limiting importance sampling points to 16 [S1].
*   **Strengths:** Enables text-guided stylization of NeRFs; efficient memory usage via patch rendering; leverages powerful CLIP embeddings for semantic guidance [S1, S2].
*   **Limitations:** Prone to mode collapse with absolute loss; may produce weak stylization due to lack of magnitude control; limited to 500 iterations which may not be sufficient for complex scenes [S1, S2].
*   **When to use:** When text-guided stylization of a NeRF is required and computational resources are limited [S1, S2].
*   **When not to use:** When high-fidelity magnitude control is critical or when generation diversity is a primary concern (use relative loss or other methods) [S2].

## Background
The CLIPNeRF training configuration originates from the work on text-driven NeRF stylization. The absolute directional CLIP loss was first designed in StyleCLIP for face image editing and extended to generative NeRF editing in CLIP-NeRF [S2]. The relative directional loss was proposed in StyleGAN-NADA to address mode collapse and is adapted for NeRF stylization in NeRF-Art [S2]. The specific implementation details (patch size, stride, iterations) are derived from the implementation of Decomposing NeRF for Editing Via Feature Field Distillation [S1].
