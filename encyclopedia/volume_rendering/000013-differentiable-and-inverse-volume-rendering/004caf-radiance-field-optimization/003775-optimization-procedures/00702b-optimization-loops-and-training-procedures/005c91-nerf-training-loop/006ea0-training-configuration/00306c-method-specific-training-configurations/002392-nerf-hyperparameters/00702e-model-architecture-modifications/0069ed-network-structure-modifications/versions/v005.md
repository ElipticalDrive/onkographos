# Network Structure Modifications

## Overview
This family encompasses modifications to the neural network architectures used in Neural Radiance Fields (NeRF) to map spatial coordinates and viewing directions to radiance field properties. While the baseline NeRF employs two standard Multi-Layer Perceptrons (MLPs), these modifications alter input dimensions, output channels, network depth, or the number of parallel networks to address specific challenges such as dynamic scenes, transparency, mobile efficiency, or semantic consistency. They set themselves apart from the baseline by introducing specialized components like blend weight fields, residual networks, or multi-input multi-output (MIMO) structures, optimizing for trade-offs between training speed, inference latency, and reconstruction fidelity.

## Shared principles
The core task of a NeRF network architecture is to learn a continuous volumetric scene representation $F_\Theta: (\mathbf{x}, \mathbf{d}) \rightarrow (\sigma, \mathbf{c})$, where $\mathbf{x} \in \mathbb{R}^3$ is the spatial position, $\mathbf{d} \in \mathbb{R}^3$ is the viewing direction, $\sigma$ is the volume density, and $\mathbf{c} \in \mathbb{R}^3$ is the view-dependent color [G]. The rendering process integrates these outputs along rays using standard volume rendering equations [G].

### Standard NeRF Architecture
The baseline architecture [S1, unofficial] employs two MLPs:
1.  **Position MLP ($\Phi_{pos}$)**: Takes $\mathbf{x}$ and positional encoding $\gamma(\mathbf{x})$ to produce a feature vector $\mathbf{h}$ [G].
2.  **Shading MLP ($\Phi_{shade}$)**: Takes $\mathbf{h}$ and directional encoding $\gamma(\mathbf{d})$ to predict $\sigma$ and $\mathbf{c}$ [G].

### [Multi-input MLP (mi-MLP)](16599-multi-input-mlp-mi-mlp.md)
Incorporates the raw input embeddings (3D location and viewing direction) into every layer of the MLP, rather than only at the input stage. It solves the overfitting problem in few-shot view synthesis by creating shorter paths between inputs and outputs, allowing the model to synthesize high-quality details with fewer parameters while maintaining the capacity of the original architecture. Unlike vanilla NeRF, which relies on deep implicit mappings, mi-MLP ensures each layer is explicitly aware of the input embeddings, alleviating overfitting without harming detailed synthesis.

### NeRF Model Architecture
The neural network architecture for NeRF, consisting of dense layers with ReLU activations, potentially using view directions as input [S1, unofficial].
*   `D`: The depth of the network (number of hidden layers). Default is 8 [S1, unofficial].
*   `input_ch_views`: The number of input channels for view directions. Default is 3 [S1, unofficial].
*   `output_ch`: The number of output channels. Default is 4 (RGB + density) [S1, unofficial].
*   `use_viewdirs`: Boolean flag to determine if view directions are used as input to the network [S1, unofficial].

## Background
The baseline NeRF architecture was introduced by Mildenhall et al. in 2020 [S1, unofficial]. The specific hyperparameters for the network depth and width are defined in the original implementation's command-line arguments [S1, unofficial].
