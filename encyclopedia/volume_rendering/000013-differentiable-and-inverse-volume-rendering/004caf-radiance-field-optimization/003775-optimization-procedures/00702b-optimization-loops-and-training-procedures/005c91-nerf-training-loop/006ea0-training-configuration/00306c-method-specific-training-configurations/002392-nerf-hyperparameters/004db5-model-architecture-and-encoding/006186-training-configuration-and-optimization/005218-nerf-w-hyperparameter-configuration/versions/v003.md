# NeRF-W Hyperparameter Configuration
Also called: NeRF-W Training Parameters

## Overview
NeRF-W (NeRF in the Wild) extends standard NeRF to handle unconstrained photo collections by explicitly modeling transient objects (e.g., pedestrians, vehicles) and appearance variations. It solves the problem of dynamic elements corrupting static geometry reconstruction by using a dual-MLP architecture: one for static scene structure and one for transient/view-dependent effects [S1]. It differs from standard NeRF by introducing a transient head and appearance embeddings, and from variants like Depth-Guided NeRF by relying on photometric consistency and transient modeling rather than explicit depth supervision for structure [S1, S2].

## How it works
**Inputs and Outputs**
- **Inputs:** A set of uncalibrated or SfM-calibrated images $I_i$ with known camera poses, and optionally semantic masks for background/sky [S2].
- **Outputs:** A static radiance field (density $\sigma$ and color $c$) and a transient field (transient color $c_\tau$ and uncertainty/importance) [S1].

**Data Structures**
The model consists of three Multi-Layer Perceptrons (MLPs):
1.  **Base MLP:** 8 layers, 512 hidden units. Inputs: positional encoding of 3D point $x$ (15 frequencies) and viewing direction $\omega$ (4 frequencies). Outputs: density $\sigma$ and intermediate features for color.
2.  **Static MLP:** 4 layers, 128 hidden units. Takes features from Base MLP and appearance embedding $a$. Outputs static color $c$.
3.  **Transient/Uncertainty MLP:** 4 layers, 128 hidden units. Takes features from Base MLP and transient embedding $\tau$. Outputs transient color $c_\tau$ and uncertainty/importance score [S1].

**Positional Encoding**
- Position $x$: 15 frequencies [S1].
- Viewing direction $\omega$: 4 frequencies [S1].

**Sampling**
- **Training:** 512 points per ray per model (coarse and fine), totaling 1024 points per ray [S1].
- **Evaluation:** 2048 points per ray [S1].

**Appearance and Transient Embeddings**
- Appearance embedding dimension $n(a) = 48$ [S1].
- Transient object embedding dimension $n(\tau) = 16$ [S1].

**Loss Function**
The primary loss is the L1 loss on rendered color (following NeuS convention mentioned in [S2], though [S1] cites L1 regularizer multiplier $\lambda_u$ for transient uncertainty):
$$ L_{rgb} = \| C - C_{gt} \|_1 $$
Additionally, an L1 regularizer is applied to the transient uncertainty output with multiplier $\lambda_u = 0.01$ [S1]. A minimum importance threshold $\beta_{min} = 0.03$ is used to filter transient contributions [S1].

**Optimization**
- **Optimizer:** Adam [S1].
- **Batch Size:** 2048 rays [S1].
- **Iterations:** 300,000 total [S1].
- **Learning Rate:** Initial $\eta = 0.001$, decaying ten-fold every 150,000 iterations [S1].

**Pseudocode**
```python
# Initialization
base_mlp = MLP(layers=8, hidden=512)
static_mlp = MLP(layers=4, hidden=128)
transient_mlp = MLP(layers=4, hidden=128)
appearance_embeddings = Embedding(num_images, 48)
transient_embeddings = Embedding(num_images, 16)
optimizer = Adam(params=[base_mlp, static_mlp, transient_mlp, appearance_embeddings, transient_embeddings], lr=0.001)

# Training Loop
for step in range(300000):
    # Learning rate decay
    if step % 150000 == 0 and step > 0:
        optimizer.lr /= 10.0

    # Sample batch of rays
    rays = sample_rays(batch_size=2048)
    
    # Sample points along rays (512 coarse + 512 fine = 1024 total)
    points = sample_points_along_rays(rays, num_samples=1024)
    
    # Encode positions and directions
    pos_enc = positional_encoding(points.xyz, freqs=15)
    dir_enc = positional_encoding(rays.directions, freqs=4)
    
    # Forward pass through Base MLP
    base_output = base_mlp(concat(pos_enc, dir_enc))
    sigma = base_output.sigma
    features = base_output.features
    
    # Get embeddings for each ray's image index
    img_indices = rays.image_indices
    app_embs = appearance_embeddings(img_indices)
    trans_embs = transient_embeddings(img_indices)
    
    # Static and Transient heads
    static_color = static_mlp(concat(features, app_embs))
    transient_color, uncertainty = transient_mlp(concat(features, trans_embs))
    
    # Volume rendering (alpha compositing)
    # C_static = sum(T_i * sigma_i * c_static_i * delta_i)
    # C_transient = sum(T_i * sigma_i * c_transient_i * delta_i)
    # C_rendered = C_static + C_transient * uncertainty
    # Note: Specific compositing formula for transient dominance mitigation is not fully detailed in [S1],
    # but [S2] notes that transient head can dominate if not handled.
    # [S1] uses L1 regularizer on uncertainty with lambda_u = 0.01.
    
    rendered_color = volume_render(points, sigma, static_color, transient_color, uncertainty)
    
    # Loss computation
    gt_color = rays.gt_colors
    loss_rgb = L1(rendered_color, gt_color)
    loss_transient_reg = L1(uncertainty, 0) * 0.01 # lambda_u = 0.01
    
    # Importance thresholding (beta_min = 0.03)
    # Rays with transient importance < 0.03 may be treated differently or filtered
    # Implementation detail: [S1] mentions beta_min but does not specify exact masking logic in the provided text.
    
    loss = loss_rgb + loss_transient_reg
    
    # Backpropagation
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
```

## Subtopics

### Transient Object Handling via Segmentation Masks
A method to handle dynamic objects in Internet photo collections by using segmentation masks to exclude rays belonging to dynamic objects during training, avoiding the issue where a transient NeRF head dominates rendered color [S2]. Directly using the NeRF-W transient head causes the transient NeRF to dominate rendered color because it converges faster than the geometry MLP, leading scene structures to be modeled as view-dependent transient effects rather than geometry [S2]. This variant uses semantic masks to label background rays (mostly sky) as free space and excludes transient object rays [S2].

## Operating characteristics
- **Time Complexity:** Training requires 300,000 iterations with a batch size of 2048 rays [S1]. The dual-MLP structure (Base + Static + Transient) increases computational cost compared to single-MLP NeRF.
- **Memory Complexity:** Requires storing appearance embeddings (48 dims) and transient embeddings (16 dims) per image, plus the weights of three MLPs (Base: $8 \times 512$, Static: $4 \times 128$, Transient: $4 \times 128$) [S1].
- **Performance:** Hyperparameters were optimized for the Brandenburg Gate scene of the Phototourism dataset and reused for remaining scenes, suggesting good generalization within the dataset family [S1].
- **Strengths:** Effectively handles unconstrained photo collections with transient objects and appearance variations [S1].
- **Limitations:** The transient head can dominate rendering if not properly regularized or masked [S2]. Performance evaluation on in-the-wild collections is challenging due to the lack of ground truth [S1].

## Background
NeRF-W was introduced by Mildenhall et al. in 2021 [S1]. It was designed to address the limitations of NeRF when applied to unconstrained photo collections, where dynamic objects and lighting changes are prevalent. The method builds on the NeRF training loop and architecture but introduces specific components for transient modeling and appearance variation [S1]. It is part of the broader effort to extend neural radiance fields to real-world, uncontrolled environments [S1].
