# Gaussian and Primitive-Based Representations

Also called: Explicit Primitive Representations, Differentiable Primitives, Neural Point Clouds

## Overview
Gaussian and Primitive-Based Representations replace the continuous, coordinate-based implicit function of standard NeRF with explicit geometric structures—such as Gaussian blobs, discrete points, or quadric primitives—to improve rendering speed, editability, and high-frequency detail reconstruction [S1]. Unlike implicit MLPs that suffer from spectral bias and require ray-marching through empty space, these methods leverage explicit spatial locality or differentiable set operations to define scene geometry and appearance [S1].

## Shared principles
The family shares the substitution of the global continuous field $F_\Theta(\mathbf{x}, \mathbf{d})$ with an explicit set of primitives $\mathcal{P}$. The rendering process integrates contributions from these primitives along rays, but the density and color are derived from local interactions rather than a global query.

1.  **Explicit Parameterization:** The scene is defined by a discrete set of parameters $\mathbf{P}$ (e.g., means, covariances, positions, coefficients) rather than neural network weights alone.
2.  **Local Aggregation or Differentiable Operations:**
    *   **Point/Gaussian Methods:** Features at a query point $\mathbf{x}$ are aggregated from neighbors $\mathcal{N}(\mathbf{x})$ using weights $w_i$ (e.g., inverse distance) or projected via rasterization [S1].
    *   **Primitive Assembly:** Occupancy is computed via differentiable set operations (intersection/union) on primitive distances [S1].
3.  **Differentiable Rendering:** The final pixel color is computed via alpha compositing or volume rendering, where opacity $\alpha$ is derived from the primitive properties (e.g., Gaussian variance, point confidence, or signed distance) [S1].

## Subtopics

### [Differentiable Primitive Assembly](13657-differentiable-primitive-assembly.md)
Differentiable Primitive Assembly (DPA) models 3D shapes as an explicit assembly of learnable quadric primitives, utilizing differentiable set operations (intersection and union) to construct the scene geometry [13657-differentiable-primitive-assembly]. Unlike implicit neural representations that query a continuous field, DPA defines the scene via a discrete set of primitives $\mathcal{P}$ and a selection matrix $\mathbf{T}$ that groups them into convexes, enabling end-to-end optimization of both geometry and appearance from image-space losses alone [13657-differentiable-primitive-assembly]. It is chosen when explicit, editable convex geometry is required.

### [Viewing Direction Gaussian Splatting](14273-viewing-direction-gaussian-splatting.md)
Viewing Direction Gaussian Splatting (VDGS) is a hybrid neural rendering method that combines the explicit geometric representation of 3D Gaussian Splatting with the view-dependent appearance modeling of Neural Radiance Fields (NeRF) [14273-viewing-direction-gaussian-splatting]. It solves the limitation of classical Gaussian Splatting, where color and opacity are static per primitive, by introducing a neural network that modulates opacity (and optionally color) based on the viewing direction [14273-viewing-direction-gaussian-splatting]. This allows VDGS to accurately model view-dependent phenomena such as glass reflections, transparency, and specular highlights without the computational overhead of full NeRF ray-marching [14273-viewing-direction-gaussian-splatting]. It is chosen for real-time rendering of scenes with strong specularities.

### [Point-NeRF Representation](15538-point-nerf-representation.md)
Point-NeRF represents a continuous volumetric radiance field using a discrete neural point cloud, avoiding ray sampling in empty space by leveraging classical point clouds to approximate scene geometry [15538-point-nerf-representation]. It differs from global MLP-based NeRFs by regressing density and radiance from local neighborhood features rather than querying a single global network, and from Gaussian Splatting by using point-based aggregation with inverse distance weighting rather than explicit Gaussian projection [15538-point-nerf-representation]. It is chosen for memory-efficient representation of complex surfaces.

### [Frequency-Modulated Point Cloud Rendering](15903-frequency-modulated-point-cloud-rendering.md)
Frequency-Modulated Point Cloud Rendering is a real-time rendering pipeline that represents scenes as explicit point clouds and uses an Adaptive Frequency Net (AFNet) to modulate implicit radiance signals with local texture frequency encoding [15903-frequency-modulated-point-cloud-rendering]. It solves the problem of high-frequency detail reconstruction in point-based rendering, where standard MLPs suffer from spectral bias towards low-frequency signals [15903-frequency-modulated-point-cloud-rendering]. Unlike sibling methods that use fixed activation functions or global frequency encoding, AFNet predicts local frequency and phase parameters for each point via a hypernetwork, allowing the network to adaptively handle varying texture complexities (high frequency for textured regions, low for smooth regions) [15903-frequency-modulated-point-cloud-rendering]. This approach enables high-fidelity local detail reconstruction, real-time rendering speeds, and user-friendly object-level editing [15903-frequency-modulated-point-cloud-rendering].

#### GARF
**Definition:** GARF uses Gaussian activations as an effective alternative to positional encoding in NeRF, in conjunction with bundle adjustment for pose estimation [S1].
**Steps:** It replaces standard positional encoding with Gaussian activations and performs bundle adjustment to jointly refine camera poses and scene representation [S1].
**Performance:** It successfully recovers scene representations from unknown camera poses, even in challenging scenes with low-textured regions, making it suitable for real-world applications [S1].

## Background
The shift from implicit to explicit representations in radiance fields emerged to address the computational bottlenecks of ray-marching and the spectral bias of MLPs. Early works like Point-NeRF [15538-point-nerf-representation] introduced neural point clouds to replace global MLPs, while Gaussian Splatting variants [14273-viewing-direction-gaussian-splatting] leveraged differentiable rasterization for real-time performance. Differentiable Primitive Assembly [13657-differentiable-primitive-assembly] further explored explicit geometry via quadrics. Frequency-modulated approaches [15903-frequency-modulated-point-cloud-rendering] addressed high-frequency detail loss. GARF [S1] explored Gaussian activations for pose estimation. These methods are widely used in real-time rendering, SLAM, and editable 3D scene reconstruction.
