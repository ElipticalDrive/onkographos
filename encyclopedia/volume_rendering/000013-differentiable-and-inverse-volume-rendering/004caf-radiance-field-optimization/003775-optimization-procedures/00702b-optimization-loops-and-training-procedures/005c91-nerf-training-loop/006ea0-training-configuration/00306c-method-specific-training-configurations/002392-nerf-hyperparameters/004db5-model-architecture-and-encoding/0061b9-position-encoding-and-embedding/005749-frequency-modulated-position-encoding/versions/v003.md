# Frequency-Modulated Position Encoding

Also called: FM-NeRF Encoding, Frequency-Modulated Point Cloud Rendering with Easy Editing

## Overview
Frequency-Modulated Position Encoding (FMPE) is a coordinate encoding scheme used in point-based radiance field optimization to map 3D spatial coordinates and viewing directions to feature vectors. It solves the problem of representing high-frequency geometric details in sparse point clouds by narrowing the frequency interval of the basis functions compared to standard NeRF [S1]. Unlike standard positional encoding which uses integer powers of 2 ($2^0, 2^1, \dots$), FMPE uses fractional powers ($2^0, 2^{0.5}, \dots$) to provide finer-grained basis function support, allowing the network to capture sharper edges and details with fewer parameters [S1]. It is distinct from [Mip-NeRF 360 MLP Architecture](14098-mip-nerf-360-mlp-architecture.md) which uses integrated positional encoding for anti-aliasing, and from [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md) which relies on semantic features rather than frequency modulation for representation [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D point coordinate $\mathbf{p} \in \mathbb{R}^3$ or a viewing direction $\mathbf{d} \in S^2$.
*   **Output:** A high-dimensional feature vector $\gamma(\mathbf{p})$ or $\gamma(\mathbf{d})$ passed to the network backbone (AFNet).

**Data Structures:**
The encoding is a fixed-length vector constructed by concatenating sine and cosine terms. The dimensionality is $2 \times L$, where $L$ is the number of frequency bands.
*   For spatial coordinates: $L=10$, resulting in a 20-dimensional vector.
*   For view directions: $L=2$, resulting in a 4-dimensional vector.
*   The total input dimension to the AFNet MLP is 120 (derived from the specific implementation details in [S1], likely combining spatial and directional encodings with other features, though the text explicitly states "input feature dimension: 120" for the AFNet).

**Formulas:**
The frequency-modulated encoding function $\gamma(\mathbf{p})$ is defined as [S1]:

$$
\gamma (\mathbf {p}) = \left (\sin \left (2^0 \pi \mathbf {p}\right ), \cos \left (2^0 \pi \mathbf {p}\right ), \sin \left (2^{0.5} \pi \mathbf {p}\right ), \cos \left (2^{0.5} \pi \mathbf {p}\right ), \dots , \sin \left (2^{L-1} \pi \mathbf {p}\right ), \cos \left (2^{L-1} \pi \mathbf {p}\right ) \right )
$$

Where:
*   $\mathbf{p}$ is the input coordinate or direction.
*   $L$ is the number of frequency bands.
*   The exponents of 2 are spaced by 0.5 (i.e., $0, 0.5, 1.0, \dots, L-1$). Note: The source formula shows the last term as $2^{L-1}$, implying the sequence of exponents is $0, 0.5, \dots, L-1$. For $L=10$, the exponents are $0, 0.5, 1.0, 1.5, 2.0, 2.5, 3.0, 3.5, 4.0, 4.5$.

**Parameters:**
*   $L_{\text{spatial}} = 10$ [S1].
*   $L_{\text{direction}} = 2$ [S1].
*   Learning rate for MLP weights: $5 \times 10^{-4}$ [S1].
*   Learning rate for opacity parameters $\alpha$: $0.01$ [S1].
*   $\lambda_{\text{sparse}} = 5 \times 10^{-4}$ [S1].

**Pseudocode:**
The following Python-like pseudocode implements the encoding function. It assumes standard math operations.

```python
import math
import numpy as np

def frequency_modulated_encoding(p, L):
    """
    Computes the frequency-modulated position encoding for input p.
    
    Args:
        p (np.ndarray): Input coordinate or direction vector of shape (D,) or (N, D).
        L (int): Number of frequency bands.
        
    Returns:
        np.ndarray: Encoded vector of shape (2*L*D,) or (N, 2*L*D).
    """
    # p can be a single point (1D) or batch (2D)
    # We need to handle broadcasting correctly.
    # If p is (D,), reshape to (1, D) for calculation, then flatten result.
    
    original_shape = p.shape
    if p.ndim == 1:
        p = p.reshape(1, -1)
    
    # p shape: (N, D)
    N, D = p.shape
    
    # Generate frequency bands: 0, 0.5, 1.0, ..., L-1
    # The source formula implies exponents are 0, 0.5, ..., L-1.
    # Number of bands is L.
    bands = np.arange(L) * 0.5  # Shape (L,)
    
    # Reshape for broadcasting: bands (L,) -> (1, 1, L)
    # p (N, D) -> (N, D, 1)
    # Resulting freqs (N, D, L)
    freqs = p[:, :, np.newaxis] * bands[np.newaxis, np.newaxis, :] * 2 * np.pi
    
    # Compute sin and cos
    # sin_vals shape: (N, D, L)
    sin_vals = np.sin(freqs)
    cos_vals = np.cos(freqs)
    
    # Concatenate along the last axis
    # Result shape: (N, D, 2*L)
    encoded = np.concatenate([sin_vals, cos_vals], axis=-1)
    
    # Flatten the last two dimensions (D and 2*L) into one feature dimension
    # Result shape: (N, D * 2 * L)
    encoded = encoded.reshape(N, -1)
    
    if original_shape.ndim == 1:
        return encoded[0]
    return encoded

# d_view = np.array([dx, dy, dz])

```

**Training Loop and Preprocessing Steps:**
1.  **Preprocessing:** Perform 4-20 loops of point cloud denoising and completion. For every denoising step, train for 300 epochs [S1].
2.  **Initialization:** Use initial point clouds generated by MVSNet [S1].
3.  **Optimization:**
    *   Minimize the loss function $\mathcal{L} = \mathcal{L}_{\text{RGB}} + \lambda_{\text{sparse}} \mathcal{L}_{\text{sparse}}$ [S1].
    *   $\mathcal{L}_{\text{RGB}} = ||\hat{C} - C_{gt}||_2^2$ [S1].
    *   $\mathcal{L}_{\text{sparse}} = \frac{1}{N} \sum_{i=1}^N [\log(\alpha_i) + \log(1-\alpha_i)]$ [S1].
    *   For scenes without background, add transparency loss (L2 distance of predicted vs ground truth transparency) [S1].
4.  **Refinement:** When training converges, remove low-opacity points [S1].
5.  **Data Augmentation:** Conduct random scaling and cropping during training. Random scaling is critical for U-Net training [S1].

**Edge Cases and Pitfalls:**
*   **Bleeding Problem:** If the rasterization radius (used to expand points to disks) is too small, points from occluded surfaces and background can be seen through the front surface [S1].
*   **Edge Expansion:** If the rasterization radius is too large, it leads to inaccurate depth estimation and object edges expand [S1].
*   **Radius Selection:** The radius should cover gaps between points but be as small as possible. It depends on point cloud density and can be adjusted by observing the depth map obtained by rasterization [S1].

## Subtopics

### AFNet MLP
The network backbone that takes the encoded features. It has 5 layers, input dimension 120, hidden dimensions [256, 256, 256, 128], and output dimension 11 (3-channel raw image + 8-channel feature map) [S1].

### U-Net Decoder
Used for decoding features, employing gated convolution blocks, nearest neighbor interpolation for upsampling, and average pooling for downsampling [S1].

### Point Cloud Editing
Involves storing the object to be edited as a mask (using PCL library for selection) and shrinking masks determined by index buffers to avoid edge artifacts caused by point expansion [S1].

## Operating characteristics
*   **Training Time:** Approximately 10 minutes for realistic rendering, and about 10 hours to almost converge. One epoch consumes ~12.8 seconds on the NeRF-Synthetic dataset [S1].
*   **Performance:** Achieves higher PSNR/SSIM on NeRF-Synthetic and Tanks and Temples datasets compared to NeRF, CCNeRF, NPBG, NPBG++, and Huang et al. Comparable or better results on ScanNet and DTU datasets [S1].
*   **Resolution:**
    *   NeRF-Synthetic: Training 800x800 (scaling [0.5, 1.5]), Test 800x800 [S1].
    *   Tanks and Temples: Training 640x640, Test 1920x1056 [S1].
    *   ScanNet: Training 800x800, Test 1200x1600 [S1].
    *   DTU: Training 720x720, Test 960x1200 [S1].
*   **Strengths:** Fast convergence to realistic rendering; effective handling of sparse point clouds via frequency modulation; easy editing capabilities [S1].
*   **Limitations:** Requires careful tuning of rasterization radius to avoid bleeding or edge expansion; dependent on initial point cloud quality from MVSNet [S1].

## Background
Frequency-Modulated Position Encoding was introduced in the paper "Frequency-Modulated Point Cloud Rendering with Easy Editing" [S1]. It builds upon the positional encoding form of NeRF [S1] but modifies the frequency intervals to provide finer-grained basis function support. The method is designed for point-based radiance field optimization, aiming to improve rendering quality and editing capabilities for 3D scenes represented by point clouds. It is particularly effective for scenes with sparse geometry where standard NeRF might struggle with high-frequency details.
