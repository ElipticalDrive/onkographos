# Gear-NeRF

Also called: Gear-NeRF: Free-Viewpoint Rendering and Tracking with Motion-aware Spatio-Temporal Sampling

## Overview
Gear-NeRF is a method for free-viewpoint rendering and tracking of dynamic scenes that leverages semantic information from image segmentation models to stratify the scene into motion-based 'gears', allowing for region-specific spatio-temporal sampling resolution [S1]. It addresses the inefficiency of uniform sampling in dynamic scenes by assigning higher-resolution feature volumes to regions with larger motion scales [S1]. Unlike sibling methods that use a single unified 4D volume or explicit time-parameterized MLPs, Gear-NeRF maintains a series of parallel 4D feature volumes, one for each gear level, enabling adaptive resource allocation based on local motion intensity [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $W$ input videos $\mathcal{V} = \{V_1, V_2, \dots, V_W\}$ of a dynamic scene with calibrated camera poses [S1].
*   **Output:** Rendered images for novel views and time steps, and semantic embeddings for object tracking [S1].

**Data Structures:**
The representation consists of $N_{gear}$ parallel 4D feature volumes, where each volume corresponds to a specific gear level $G \in \{1, \dots, N_{gear}\}$ [S1].
*   **Feature Volumes:** Each gear $G$ has its own set of 2D feature grids for spatio-temporal embeddings.
*   **Shared Components:** Planar spatial embeddings $h_j$ and linear transforms $B_j$ are shared across all gears [S1].
*   **Gear-Specific Components:** Each gear $G$ has its own spatio-temporal embeddings $k^G_j$ [S1].
*   **Dimensionality:** Embeddings are in $M$-dimensional space [S1].

**Parameters:**
*   $N_{gear}$: The total number of gear levels used to stratify the scene representation based on motion scales [S1].
*   $M$: The dimensionality of the feature vectors [S1].
*   Typical values: Not given in the sources.

**Algorithm Steps:**

1.  **Semantic Embedding Optimization:** Optimize a 4D semantic embedding based on powerful image segmentation models (specifically SAM) to profile the scene into semantic regions [S1]. This embedding guides the stratification of the scene [S1].

2.  **Gear Determination:** For any space-time coordinate $(\mathbf{x}, t)$, compute the gear level $g(\mathbf{x}, t)$ using a planar-factorized 4D feature volume [S1]. The formula is:
    $$ g(\mathbf{x}, t) = \mathbf{1}^\top (h'_1(x, y) \bowtie k'_1(z, t) + h'_2(x, z) \bowtie k'_2(y, t) + h'_3(y, z) \bowtie k'_3(x, t)) $$
    where $h'_j$ and $k'_j$ are functions evaluated by bilinear interpolation on regularly spaced 2D feature grids, $\bowtie$ denotes element-wise product, and $\mathbf{1}$ is a vector of ones [S1]. *Note: The source text cuts off the arguments for $k'_1$, but implies a similar structure to the feature vector calculation.* Regions with larger motion scales are assigned higher gear levels through this scheme [S1].

3.  **Feature Vector Computation:** For a specific gear level $G$ and coordinate $(\mathbf{x}, t)$, compute the feature vector $\mathbf{f}^G(\mathbf{x}, t)$ by summing three terms, each involving an element-wise product of 2D plane embeddings and a linear transform [S1]:
    $$ \mathbf{f}^G(\mathbf{x}, t) = B_1 (h_1(x, y) \bowtie k^G_1(z, t)) + B_2 (h_2(x, z) \bowtie k^G_2(y, t)) + B_3 (h_3(y, z) \bowtie k^G_3(x, t)) $$
    where:
    *   $h_j(\cdot, \cdot)$ are spatial planar embeddings shared by all gears [S1].
    *   $k^G_j(\cdot, \cdot)$ are gear-specific spatio-temporal embeddings [S1].
    *   $B_j$ are linear transforms mapping the products to feature vectors [S1].
    *   $\bowtie$ denotes element-wise product [S1].

4.  **Radiance Field Prediction:** Pass the feature vector $\mathbf{f}^G(\mathbf{x}, t)$ through a tiny MLP to predict volume density $\sigma$ and view-dependent emitted color $\mathbf{c}$, given the viewing direction $\mathbf{d}$ [S1].

5.  **Spatio-Temporal Sampling:** Perform spatio-temporal sampling for ray integration. Regions assigned to higher gear levels (larger motion scales) are sampled at higher resolution to improve dynamic novel view synthesis [S1].

6.  **Rendering:** Integrate $\sigma$ and $\mathbf{c}$ along rays using standard volume rendering equations [G].

**Pseudocode:**

def gear_nerf_forward(xyz, time, direction, gear_level, params):
    """
    Computes the radiance field output for a specific gear level.
    
    Args:
        xyz: Spatial coordinates (x, y, z)
        time: Temporal coordinate t
        direction: Viewing direction d
        gear_level: Integer G indicating the gear level
        params: Object containing shared and gear-specific parameters
        
    Returns:
        sigma: Volume density
        color: View-dependent color
    """
    # 1. Compute Feature Vector for Gear G
    # Shared spatial embeddings
    h1_xy = bilinear_interp(params.h1, xyz[:, 0], xyz[:, 1])
    h2_xz = bilinear_interp(params.h2, xyz[:, 0], xyz[:, 2])
    h3_yz = bilinear_interp(params.h3, xyz[:, 1], xyz[:, 2])
    
    # Gear-specific spatio-temporal embeddings
    k1_zt = bilinear_interp(params.k_gear_specific[gear_level][0], xyz[:, 2], time)
    k2_yt = bilinear_interp(params.k_gear_specific[gear_level][1], xyz[:, 1], time)
    k3_xt = bilinear_interp(params.k_gear_specific[gear_level][2], xyz[:, 0], time)
    
    # Element-wise products
    prod1 = h1_xy * k1_zt
    prod2 = h2_xz * k2_yt
    prod3 = h3_yz * k3_xt
    
    # Linear transforms and summation
    f_vec = params.B1 @ prod1 + params.B2 @ prod2 + params.B3 @ prod3
    
    # 2. Predict Density and Color
    # Tiny MLP takes feature vector and viewing direction
    sigma, color = tiny_mlp(f_vec, direction)
    
    return sigma, color

**Edge Cases and Pitfalls:**
*   **Precision:** Bilinear interpolation on 2D grids requires careful handling of boundary conditions [S1].
*   **Degenerate Input:** The method relies on calibrated camera poses; uncalibrated inputs are not supported [S1].
*   **Motion Scale Ambiguity:** The exact mapping from the gear score $g(\mathbf{x}, t)$ to the discrete gear level $G$ is not fully specified in the provided text, only that higher motion scales lead to higher gears [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Scales with $N_{gear}$ due to the storage of separate feature volumes for each gear level [S1].
*   **Measured Performance:** Achieves state-of-the-art rendering and tracking performance on multiple challenging datasets [S1].
*   **Scaling:** Higher gear levels allow for higher-resolution sampling in dynamic regions, improving quality at the cost of increased computation in those regions [S1].
*   **Strengths:** Motion-aware sampling improves photo-realistic dynamic novel view synthesis; enables free-viewpoint tracking almost for free [S1].
*   **Limitations:** Requires semantic segmentation models (SAM) for initialization; complexity increases with the number of gear levels [S1].
*   **When to use:** Dynamic scenes with varying motion scales where uniform sampling is inefficient.
*   **When not to use:** Static scenes or scenes with uniform motion where a single resolution suffices.

## Background
Gear-NeRF was introduced in 2024 by the authors of "Gear-NeRF: Free-Viewpoint Rendering and Tracking with Motion-aware Spatio-Temporal Sampling" [S1]. It builds on the NeRF architecture [Parent](3065-nerf-hyperparameters.md) and extends it to dynamic scenes by incorporating semantic information from segmentation models [S1]. The method is designed to address the resource inefficiency of dynamic NeRFs by stratifying the scene representation based on motion scales [S1].
