# ViT-NeRF

Also called: Global-Local Feature NeRF, Hybrid ViT-CNN NeRF, Vision Transformer for NeRF (ViT-NeRF)

## Overview
ViT-NeRF is a view synthesis method that combines a Vision Transformer (ViT) to encode global shape information and a 2D CNN to extract local appearance features, conditioning volume rendering on hybrid per-pixel features [S1]. It addresses the limitation of using only global features, which compromises rendering quality for views close to the input view, by fusing them with local CNN features [S1]. Unlike CodeNeRF and DISN, it does not require a canonical coordinate system to utilize global features [S1].

## How it works
**Inputs and Outputs:**
*   Input: A single input image $I_s \in \mathbb{R}^{H \times W \times 3}$ [S1].
*   Output: A rendered 2D image $\hat{C}(\mathbf{r})$ for a target viewpoint [S1].

**Data Structures:**
*   **Image Tokens:** The input image is reshaped into a sequence of flattened 2D patches $P \in \mathbb{R}^{N \times P^2 \times 3}$, where $N = \frac{HW}{P^2}$ is the number of patches and $P$ is the patch size [S1].
*   **Global Feature Maps:** A set of multi-level feature maps $W^0_G, ..., W^J_G$, where each $W^j_G \in \mathbb{R}^{H_j \times W_j \times D_j}$ [S1].
*   **Local Feature Map:** A single feature map $W_L \in \mathbb{R}^{\frac{H}{2} \times \frac{W}{2} \times D_L}$ [S1].
*   **Hybrid Feature Map:** The fused feature map $W$ [S1].

**Numbered Steps:**

1.  **Global Feature Extraction:**
    a.  The input image $I_s$ is divided into patches. Each patch is flattened and linearly projected to an image token $P_l$ [S1].
    b.  A Transformer Encoder takes the image tokens and learnable positional embeddings $\epsilon$ as input to extract global information as a set of latent features $f$ [S1].
    c.  The class token is dropped from the latent features. The operation is defined as $O: \mathbb{R}^{(N+1) \times D} \rightarrow \mathbb{R}^{N \times D}$ [S1].
    d.  The remaining features are unflattened: $U: \mathbb{R}^{N \times D} \rightarrow \mathbb{R}^{\frac{H}{P} \times \frac{W}{P} \times D}$ [S1].
    e.  Multi-level feature maps are generated using convolutional decoders $D$: $W^j_G = (D \circ U \circ O)(f_j)$, where $j \in \{0, 1, ..., J\}$ [S1]. The decoders convolve with a $1 \times 1$ layer, resample with strided or transposed convolution to size $H_j \times W_j$, and convolve with a $3 \times 3$ layer [S1].

2.  **Local Feature Extraction:**
    a.  A 2D CNN module $G_L$ extracts local image features from the input image: $W_L = G_L(I_s)$, where $G_L: \mathbb{R}^{H \times W \times C} \rightarrow \mathbb{R}^{\frac{H}{2} \times \frac{W}{2} \times D_L}$ [S1].
    b.  $G_L$ consists of three ResBlocks [S1].

3.  **Feature Fusion:**
    a.  The global feature maps $W^0_G, ..., W^J_G$ and the local feature map $W_L$ are fused by a convolutional layer $G$ to produce the hybrid feature map $W$:
    $$ W = G(W^0_G, W^1_G, ..., W^J_G; W_L) $$
    [S1]

4.  **Volumetric Rendering:**
    a.  For a target viewpoint, a ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ is sampled, bounded by $t_{near}$ and $t_{far}$ [S1].
    b.  Equally distributed samples are picked along the ray. For a 3D sample location $\mathbf{x}_c$, the corresponding 2D location $\pi(\mathbf{x}_c)$ on the input image plane is computed [S1].
    c.  The per-pixel feature $W(\pi(\mathbf{x}_c))$ is extracted from the hybrid feature map [S1].
    d.  The 3D location $\mathbf{x}_c$ is encoded with positional encoding $\gamma(\mathbf{x}_c)$ using $M=10$ frequency bases:
    $$ \gamma(\mathbf{p}) = (\sin(2^0 \pi \mathbf{p}), \cos(2^0 \pi \mathbf{p}), ..., \sin(2^{M-1} \pi \mathbf{p}), \cos(2^{M-1} \pi \mathbf{p})) $$
    [S1]
    e.  An MLP takes the positional encoding $\gamma(\mathbf{x}_c)$, the viewing direction $\mathbf{d}_c$, and the vision feature $W(\pi(\mathbf{x}_c))$ as input to predict density $\sigma$ and color $\mathbf{c}$:
    $$ (\sigma, \mathbf{c}) = \text{MLP}(\gamma(\mathbf{x}_c); \mathbf{d}_c; W(\pi(\mathbf{x}_c))) $$
    [S1]
    f.  The target view is rendered via volume rendering:
    $$ \hat{C}(\mathbf{r}) = \int_{t_n}^{t_f} T(t)\sigma(t)\mathbf{c}(t) dt $$
    where $T(t) = \exp(-\int_{t_n}^t \sigma(\mathbf{r}(s)) ds)$ is the accumulated transmittance [S1]. The integral is approximated with quadrature [S1].

**Parameters:**
*   Number of frequency bases $M$: 10 [S1].
*   Learning rate: $10^{-4}$ for the NeRF MLP, $10^{-5}$ for the ViT and CNN modules [S1].
*   Batch size: 8 instances, with 512 rays per instance [S1].
*   Training iterations: Converges at 500K iterations [S1].
*   Warm-up schedule: Linear warm-up from 0 learning rate for the first 10k steps [S1].
*   ViT initialization: Initialized from pretrained weights of reference [55] and fine-tuned [S1].

**Pitfalls:**
*   Using only global ViT features compromises rendering quality for views close to the input view (inconsistent color/appearance) [S1].
*   The class token in ViT has no physical meaning when unflattened into spatial feature maps and must be dropped before decoding [S1].

## Operating characteristics
*   **Time and Memory Complexity:** Volume-based methods are more computationally-intensive and require more memory when increasing the grid size [S1].
*   **Measured Performance:** Evaluated on ShapeNet Chairs and Cars datasets. On Chairs, it achieves PSNR 24.48, SSIM 0.93, LPIPS 0.077. On Cars, it achieves PSNR 22.88, SSIM 0.91, LPIPS 0.084 [S1].
*   **Strengths:** Produces sharper edges and clearer structures, avoiding blurriness on invisible parts like chair legs, compared to SRN and PixelNeRF [S1]. Combines the advantage of 2D-based methods (local features) and 1D-based methods (global information) [S1].
*   **Limitations:** Computationally intensive compared to 2D methods [S1].
*   **When to use:** When high-resolution image features and global receptive fields are needed for view synthesis, especially for unseen regions [S1].

## Background
ViT-NeRF was introduced in "Vision Transformer for NeRF-Based View Synthesis from a Single Input Image" [S1]. It builds on the success of Vision Transformers in learning long-range dependencies between features [S1].
