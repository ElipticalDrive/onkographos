# Sharp-NeRF

Also called: Grid-based Fast Deblurring Neural Radiance Fields using Sharpness Prior

## Overview
Sharp-NeRF is a grid-based NeRF framework designed to render clean, sharp images from input blurry images by modeling spatially varying blur using discrete learnable kernels and a sharpness prior [S1]. Unlike MLP-based deblurring methods such as Deblur-NeRF and DP-NeRF which suffer from long training times, Sharp-NeRF accelerates training to approximately half an hour by replacing neural kernel generators with a decomposed-grid representation and a fixed set of discrete kernels indexed by a quantized sharpness map [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of blurry training images (and their camera poses). A precomputed per-pixel sharpness level map $L$ for each view.
*   **Outputs:** A sharp novel view image $I_c$ (during inference) or a blurred image patch $I_b$ (during training for loss computation).

**Data Structures:**
1.  **Grid Representation:** A decomposed-grid neural field architecture [S1] storing color and density. This replaces the standard MLPs.
2.  **Discrete Blur Kernels ($B$):** A set of $N_k$ learnable 2D convolution kernels. These are not generated by a network but are direct parameters [S1].
3.  **Sharpness Level Map ($L$):** A 2D map where each pixel value is an integer index into $B$, derived from a precomputed defocus map [S1].

**Preprocessing:**
1.  Compute a defocus map (sharpness level) for each training view using a sharpness measure operator [S1].
2.  Quantize the defocus map into $N_k$ discrete values to create the sharpness level map $L$ [S1]. This step is performed once before training [S1].

**Training Procedure:**
1.  **Patch Sampling:** Instead of sampling single rays, sample ray patches with stride 1. Each patch has size $K \times K$ [S1].
2.  **Backbone Rendering:** Render a sharp image patch $I_c'$ from the ray patch inputs using the grid-based backbone neural fields [S1].
3.  **Kernel Indexing:** For each pixel in the patch, use the corresponding value in the preprocessed sharpness level map $L$ to index into the set of learned discrete blur kernels $B$. This yields per-pixel weights $w_x$ (the kernel associated with that sharpness level) [S1].
4.  **Blurring Synthesis:** Perform a weighted sum of the rendered sharp patch $I_c'$ and the indexed blur kernels to produce the final blurred image patch $I_b$. The operation is effectively a convolution of $I_c'$ with the spatially varying kernels defined by $L$ [S1].
5.  **Loss:** Compare $I_b$ with the ground-truth blurry input image to optimize the grid parameters and the discrete kernels $B$ [S1].

**Inference:**
At inference time, the blur kernel module is bypassed. The grid-based backbone renders the sharp image $I_c$ directly, which is used as the final output [S1].

**Edge Cases and Pitfalls:**
*   **Memory:** Retaining blur kernels for every individual pixel is impractical for high-resolution and multi-view images. Sharp-NeRF handles this by quantizing sharpness levels into a few discrete kernels ($N_k$) [S1].
*   **Training Time:** Rendering multiple neighboring pixels (5 or 6) to render one pixel increases training time proportionally. Sharp-NeRF handles this by rendering a patch and applying convolution over the patch, which is more efficient than per-pixel ray sampling for blur synthesis [S1].

## Operating characteristics
*   **Training Time:** Approximately half an hour, significantly faster than MLP-based methods like Deblur-NeRF and DP-NeRF [S1].
*   **Memory:** Lower memory footprint than MLP-based approaches due to the grid representation and discrete kernels [S1].
*   **Performance:** Renders sharp novel views with vivid colors and fine details, performing on par with slower methods on benchmarks consisting of blurry images [S1].
*   **Strengths:** Fast training, handles spatially varying blur (defocus), avoids bias from neural network kernel generators [S1].
*   **Limitations:** Relies on a precomputed sharpness map; assumes the blur is primarily defocus-related [S1].

## Background
Sharp-NeRF was proposed to address the high computational cost of MLP-based NeRF deblurring methods [S1]. It builds on grid-based neural field architectures [S1] and discrete learnable kernels to model spatially varying blur without the overhead of neural kernel generators [S1]. It is compared against Deblur-NeRF, DP-NeRF, DoF-NeRF, and PDRF [S1].
