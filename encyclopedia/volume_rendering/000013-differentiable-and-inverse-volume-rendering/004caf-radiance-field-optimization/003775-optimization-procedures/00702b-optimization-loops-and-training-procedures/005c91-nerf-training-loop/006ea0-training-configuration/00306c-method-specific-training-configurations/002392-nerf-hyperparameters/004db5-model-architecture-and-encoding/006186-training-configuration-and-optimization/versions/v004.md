# Training Configuration and Optimization

Also called: NeRF Training Hyperparameters, Optimization Settings

## Overview
This family defines the hyperparameters, loss functions, and optimization schedules required to train Neural Radiance Field (NeRF) models. It addresses the problem of converging the implicit representation to match observed images by configuring the optimizer, learning rate schedules, and specific loss weights. It differs from [Model Architecture and Encoding](13550-model-architecture-and-encoding.md) by focusing on the training dynamics and parameter updates rather than the network topology or feature representation.

## Shared principles
The training process generally involves minimizing a photometric loss between rendered pixels and ground-truth images using gradient-based optimization. Common elements include the use of the Adam optimizer, stratified or importance sampling for ray points, and learning rate decay schedules. Specific configurations vary based on the scene constraints (e.g., static vs. dynamic, presence of depth priors, or semantic guidance).

## Subtopics

### [Depth-Guided NeRF Training Configuration](11916-depth-guided-nerf-training-configuration.md)
Uses ground-truth depth maps to constrain the density field. It adds a depth loss term and a learnable depth scale parameter. Choose this when depth supervision is available to improve geometric accuracy.

### [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md)
Optimizes for text-guided stylization using CLIP embeddings. It freezes density parameters and updates only color parameters to match semantic directions. Choose this for style transfer or text-driven editing.

### [NeRF-W Hyperparameter Configuration](14635-nerf-w-hyperparameter-configuration.md)
Handles unconstrained internet photos with transient objects (people, cars). It uses a separate "Transient" head and semantic masks to exclude dynamic rays from the static geometry optimization. Choose this for "in-the-wild" datasets with moving elements.

## Background
The baseline training configuration originates from the original NeRF paper , establishing the standard MLP architecture, positional encoding, and Adam optimizer settings. Subsequent works like NeRF-W  and CLIPNeRF  adapted these configurations to handle specific challenges such as transient artifacts and semantic guidance, respectively.
