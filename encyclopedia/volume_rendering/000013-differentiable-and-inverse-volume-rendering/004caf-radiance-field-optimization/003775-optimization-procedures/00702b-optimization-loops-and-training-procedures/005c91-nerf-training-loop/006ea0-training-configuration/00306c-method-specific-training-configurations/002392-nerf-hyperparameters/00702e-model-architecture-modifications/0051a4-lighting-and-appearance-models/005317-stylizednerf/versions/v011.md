# StylizedNeRF

Also called: Stylized Neural Radiance Fields

## Overview
StylizedNeRF is a method for applying artistic styles to 3D scenes represented by Neural Radiance Fields (NeRF) while maintaining geometric consistency across different viewing angles [S1]. It solves the problem of view-dependent style inconsistency, where naive 2D style transfer applied to individual views results in flickering or conflicting textures when the camera moves [S1]. It differs from its siblings by employing a mutual learning strategy that jointly optimizes the 3D stylized NeRF and a 2D stylization network, using learnable latent codes to resolve ambiguities in the 2D stylized results [S1]. Unlike [Non-Photorealistic Style Editing](16597-non-photorealistic-style-editing.md) which assigns different styles to different regions, StylizedNeRF typically applies a single global style to the entire scene [S1].

## How it works
StylizedNeRF extends the standard NeRF architecture by integrating a stylization mechanism that ensures 3D consistency. The method relies on a mutual learning framework where the 3D radiance field and a 2D stylization network are optimized simultaneously.

**Inputs and Outputs:**
*   **Inputs:** A set of input images $I_{in}$ representing the original scene, and a target style image $I_{style}$.
*   **Outputs:** A stylized NeRF model $F_{stylized}$ that renders view-consistent stylized images for novel viewpoints.

**Data Structures:**
The method utilizes the standard NeRF data structures:
*   **NeRF Model ($F_\Theta$):** A multi-layer perceptron (MLP) parameterized by $\Theta$. It takes a 3D position $\mathbf{x}$ and a viewing direction $\mathbf{d}$ as input.
    *   Input: $\mathbf{x} \in \mathbb{R}^3$, $\mathbf{d} \in \mathbb{R}^3$.
    *   Output: Volume density $\sigma \in \mathbb{R}$ and view-dependent color $\mathbf{c} \in \mathbb{R}^3$.
*   **2D Stylization Network ($G_\phi$):** A network (e.g., a hypernetwork or style transfer network) parameterized by $\phi$ that maps content features to stylized features.
*   **Learnable Latent Codes ($\mathbf{z}$):** A set of latent vectors used to handle ambiguities in the 2D stylization process, ensuring that the stylized output remains consistent with the 3D geometry.

**Algorithm Steps:**
1.  **Ray Sampling:** For each camera pose, sample points $\mathbf{x}_i$ along the ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$. Compute the viewing direction $\mathbf{d}$ for each point.
2.  **Feature Extraction:** Query the NeRF MLP to obtain the raw feature vector $\mathbf{h}$ and density $\sigma$ for each point. The color $\mathbf{c}$ is initially predicted based on $\mathbf{h}$ and $\mathbf{d}$.
3.  **Stylization via Mutual Learning:**
    *   The method employs a mutual learning strategy. The 3D NeRF and the 2D stylization network are trained together.
    *   The 2D stylization network takes the rendered content image (or intermediate features) and the target style image as input.
    *   Learnable latent codes $\mathbf{z}$ are introduced to guide the stylization process. These codes help resolve ambiguities where a single 2D stylized result might not uniquely correspond to the 3D structure.
4.  **Loss Computation:**
    *   **Content Loss:** Ensures the stylized image retains the structural content of the original view.
    *   **Style Loss:** Ensures the stylized image matches the statistical properties of the target style image.
    *   **Geometry Consistency Loss:** Regularizes the NeRF to ensure that the stylized appearance is consistent across different views. This is achieved by ensuring that the stylized features derived from different viewpoints of the same 3D point are consistent.
5.  **Optimization:**
    *   Update the NeRF parameters $\Theta$ and the stylization network parameters $\phi$ using gradient descent.
    *   The learnable latent codes $\mathbf{z}$ are also optimized to minimize the combined loss.
6.  **Rendering:** To render a novel view, query the stylized NeRF. The output color $\mathbf{c}_{stylized}$ is obtained by integrating the stylized density and color along the ray using the standard volume rendering equation:
    $$
    \mathbf{C}(\mathbf{r}) = \sum_{i=1}^N T_i \alpha_i \mathbf{c}_i, \quad T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right), \quad \alpha_i = 1 - \exp(-\sigma_i \delta_i)
    $$
    where $\mathbf{c}_i$ is the stylized color at point $i$, $\sigma_i$ is the density, and $\delta_i$ is the distance between samples.

**Parameters:**
*   **Learning Rate:** Not given in the sources.
*   **Number of Samples per Ray:** Not given in the sources.
*   **Latent Code Dimension:** Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Geometric Inconsistency:** If the mutual learning is not balanced, the stylization may distort the geometry. The use of learnable latent codes helps mitigate this by providing additional degrees of freedom to align 2D style with 3D structure [S1].
*   **Style Bleeding:** In complex scenes, style from one region might bleed into another. StylizedNeRF addresses this by focusing on global style transfer, but local variations may require additional constraints not detailed in the primary description [S1].

## Subtopics

### Phong Reflection Color Modeling
Phong Reflection Color Modeling is a variant that enhances the appearance of the stylized NeRF by explicitly modeling surface properties. It uses MLPs that take integrated average features as input to predict tint, roughness, modeled normal vector, and diffuse/specular colors [S2]. The modeled normal vectors are trained with regularization losses from RefNeRF and are optimized towards estimated normal vectors via an additional regularization loss weighted by point confidence [S2]. This redundant modeling drives the confidence of outlier points with abnormal normals to zero, while estimated normal vectors provide extra shape information for point features [S2].

## Operating characteristics
*   **Time Complexity:** Training time is increased due to the mutual learning strategy and the optimization of latent codes. The exact computational overhead is not specified, but it involves simultaneous optimization of the NeRF and the stylization network [S1].
*   **Memory Complexity:** Memory usage is higher than standard NeRF due to the storage of latent codes and the additional network parameters for stylization [S1].
*   **Strengths:** Ensures view-consistent stylization; handles ambiguities in 2D style transfer via latent codes [S1].
*   **Limitations:** Requires careful balancing of the mutual learning process; may not support region-specific style assignment as effectively as other methods like [Non-Photorealistic Style Editing](16597-non-photorealistic-style-editing.md) [S1].
*   **When to use:** When a global artistic style needs to be applied to a 3D scene with high geometric consistency.
*   **When not to use:** When region-specific style control is required or when computational resources are severely limited.

## Background
StylizedNeRF was introduced as part of the broader effort to extend NeRF capabilities to artistic and non-photorealistic rendering. It builds on the standard NeRF architecture and incorporates techniques from 2D style transfer. The method is cited in surveys on 3D editing based on NeRF and 3D Gaussian Splatting [S1]. It is distinct from other stylization methods like [StyleRF](16573-stylerf-volvis.md) and [ARF](14882-stylizednerf.md) by its specific use of mutual learning and latent codes for consistency [S1].
