# Interval Score Matching

Also called: LucidDreamer (ISM)

## Overview
Interval Score Matching (ISM) is a modification to Score Distillation Sampling (SDS) that replaces the standard Denoising Diffusion Probabilistic Model (DDPM) forward process with Denoising Diffusion Implicit Model (DDIM) inversion [S1][S2, unofficial]. It introduces supervision from multiple interval steps within the diffusion process to mitigate the high reconstruction error associated with single-step noise prediction [S1][S2, unofficial].

## How it works
Inputs: A text prompt $y$, a radiance field parameterized by $\Theta$, and a DDIM inversion schedule.
Outputs: Gradient $\nabla_\Theta L$ for optimizing $\Theta$.

Data Structures:
- $x_0$: The rendered image from the current radiance field $\Theta$.
- $x_t$: The noisy image at step $t$.
- $\hat{\epsilon}_t$: The noise predicted by the frozen diffusion model at step $t$.
- $t_{start}, t_{end}$: The range of interval steps used for supervision.

Steps:
1. Render image $x_0$ from $\Theta$ at the current camera viewpoint.
2. Apply DDIM inversion to $x_0$ to generate a sequence of noisy images $\{x_t\}$ for $t \in [t_{start}, t_{end}]$. This replaces the standard DDPM forward noising process [S1][S2, unofficial].
3. For each interval step $t$ in the range:
   a. Pass $x_t$ and text embedding $y$ to the frozen diffusion model to predict noise $\hat{\epsilon}_t$.
   b. Compute the loss contribution for this step: $L_t = ||\hat{\epsilon}_t - \epsilon_t||^2_2$, where $\epsilon_t$ is the actual noise added during inversion.
4. Aggregate the loss from all interval steps: $L = \sum_{t=t_{start}}^{t_{end}} L_t$.
5. Compute the gradient $\nabla_\Theta L$ by backpropagating through the diffusion model predictions and the rendering process [S1][S2, unofficial].

Parameters:
- The specific values for $t_{start}$ and $t_{end}$ are not given in the sources.
- The weighting function $\omega(t)$ is not explicitly defined for ISM in the sources, though it is part of the general SDS framework [Parent].

Edge cases and pitfalls:
- The sources do not specify how the DDIM inversion schedule is initialized or handled for degenerate inputs.

## Operating characteristics
Time and memory complexity: Not given in the sources.
Measured performance: Not given in the sources.
Strengths and limitations: ISM avoids the large error in one-step reconstruction inherent in standard SDS [S1][S2, unofficial].
When to use it: When using DDIM inversion for 3D generation from text prompts [S1][S2, unofficial].

## Background
Origin: Proposed by LucidDreamer [S1][S2, unofficial].
History: It is an improvement to SDS loss that addresses the discrepancy between the diffusion prior and the training process of the diffusion model [S1][S2, unofficial].
Usage: Used to optimize 3D assets represented as NeRF, 3DGS, or DMTet [S1][S2, unofficial].
