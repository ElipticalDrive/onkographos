# CLIPNeRF Training Configuration

Also called: Absolute Directional CLIP Loss, CLIPNeRF Hyperparameters, CLIPNeRF Implementation, Directional CLIP Loss, Relative Directional CLIP Loss, StyleGAN-NADA CLIP Loss

## Overview
CLIPNeRF is a text-driven stylization method for Neural Radiance Fields (NeRF) that optimizes the radiance field to match a target text prompt in the CLIP embedding space [S2]. It distinguishes itself from standard NeRF training by replacing or augmenting the photometric reconstruction loss with a directional CLIP loss, which enforces semantic alignment between rendered views and text embeddings [S2]. Unlike methods that rely solely on pixel-wise reconstruction, CLIPNeRF focuses on the trajectory of stylization in the embedding space, though it faces challenges regarding mode collapse and insufficient stylization magnitude [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A pre-trained NeRF model (density and color networks), a source image $\mathbf{I}_{src}$ (optional, for relative loss), a target text prompt $\mathbf{t}_{tgt}$, and a source text prompt $\mathbf{t}_{src}$ (optional).
*   **Outputs:** A stylized NeRF model where rendered views align with $\mathbf{t}_{tgt}$.

**Data Structures:**
*   **CLIP Encoder:** Uses the ViT-B/32 architecture [S1]. It maps images to $\mathbb{R}^{512}$ vectors and text to $\mathbb{R}^{512}$ vectors.
*   **NeRF Model:** Follows the standard MLP decoding structure described in [Model Architecture and Encoding](13550-model-architecture-and-encoding.md).
*   **Patch Buffer:** Stores rendered patches of size $128 \times 128$ [S1].

**Parameters:**
*   **Iterations:** 500 [S1].
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** $0.0001$ [S1].
*   **Patch Size:** $128 \times 128$ pixels [S1].
*   **Ray Sampling Stride:** 5 within the patch, resulting in a receptive field of $640 \times 640$ on the original image scale [S1].
*   **Importance Sampling Points:** 16 per ray during patch rendering [S1].
*   **Fine MLP Samples:** 80 total (64 coarse + 16 fine) [S1].
*   **Density Freeze:** Sub-parameters related to density are frozen during optimization [S1].

**Loss Functions:**
Two variants of the directional CLIP loss are used [S2]:

1.  **Absolute Directional CLIP Loss:** Measures the cosine similarity between the rendered image $\mathbf{I}_{tgt}$ and the target text prompt $\mathbf{t}_{tgt}$ [S2].
    $$
    \mathcal{L}_{dir}^{abs} = \sum_{r} \left( 1 - \langle \hat{\mathcal{E}}_i(\mathbf{I}_{tgt}), \hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) \rangle \right)
    $$
    Where $\hat{\mathcal{E}}_i$ and $\hat{\mathcal{E}}_t$ are the normalized CLIP image and text embeddings, respectively, and $\langle \cdot, \cdot \rangle$ denotes the dot product [S2].

2.  **Relative Directional CLIP Loss:** Transfers style from a source domain to a target domain using a pair of text prompts $(\mathbf{t}_{src}, \mathbf{t}_{tgt})$ [S2].
    $$
    \mathcal{L}_{dir}^{rel} = \sum_{r} \left( 1 - \langle \hat{\mathcal{E}}_i(\mathbf{I}_{tgt}) - \hat{\mathcal{E}}_i(\mathbf{I}_{src}), \hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) - \hat{\mathcal{E}}_t(\mathbf{t}_{src}) \rangle \right)
    $$
    Where $\mathbf{I}_{src}$ is the source image rendered from the original NeRF [S2].

**Algorithm:**
1.  Initialize the NeRF model with pre-trained weights [S1].
2.  Freeze density network parameters [S1].
3.  For iteration $k = 1$ to $500$:
    a. Randomly sample a camera pose from the training dataset [S1].
    b. Render a $128 \times 128$ patch using importance sampling with 16 points per ray and a ray stride of 5 [S1].
    c. Resize the rendered patch via bilinear interpolation to match CLIP's input requirements [S1].
    d. Compute the CLIP embeddings for the rendered patch and the text prompt(s) [S1, S2].
    e. Calculate the directional CLIP loss ($\mathcal{L}_{dir}$) [S2].
    f. Compute gradients of $\mathcal{L}_{dir}$ with respect to the color network parameters [S1].
    g. Update color network parameters using Adam with learning rate $0.0001$ [S1].

**Edge Cases and Pitfalls:**
*   **Memory Constraints:** Naive differentiable rendering of high-resolution images is intractable due to memory limits [S1]. The patch-based approach mitigates this [S1].
*   **Mode Collapse:** The absolute directional CLIP loss can cause mode collapse of the generator and reduce generation diversity [S2].
*   **Insufficient Magnitude:** Directional loss only enforces trajectory (direction) but ignores magnitude (distance) in the embedding space, potentially resulting in weak style transfer [S2].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of iterations (500) and the number of rays sampled per patch. The patch-based rendering reduces per-step cost compared to full-image rendering [S1].
*   **Memory Complexity:** Reduced by rendering only $128 \times 128$ patches instead of full-resolution images [S1].
*   **Strengths:** Enables text-driven stylization of 3D scenes without requiring 3D annotations [S2].
*   **Limitations:** May suffer from uneven stylization across the scene (e.g., excess on some parts, insufficiency on others) because CLIP focuses on distinguishable regions [S2]. The absolute loss variant risks mode collapse [S2].

## Background
CLIPNeRF was introduced by Wang et al. in 2021 [S2]. It extends the StyleCLIP framework for image editing [Patashnik et al. 2021] and StyleGAN-NADA [Gal et al. 2021] to the domain of Neural Radiance Fields. The method leverages the semantic alignment capabilities of the CLIP model to guide the optimization of the radiance field [S2].
