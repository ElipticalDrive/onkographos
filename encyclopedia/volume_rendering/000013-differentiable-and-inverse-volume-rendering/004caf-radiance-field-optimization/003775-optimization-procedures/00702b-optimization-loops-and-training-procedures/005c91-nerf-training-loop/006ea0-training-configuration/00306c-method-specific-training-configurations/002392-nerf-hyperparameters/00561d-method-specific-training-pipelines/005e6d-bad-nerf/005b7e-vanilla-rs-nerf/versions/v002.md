# Vanilla RS-NeRF

Also called: RS-NeRF (basic model)

## Overview
Vanilla RS-NeRF is a framework that reconstructs a Neural Radiance Field (NeRF) from rolling shutter (RS) images by explicitly modeling the camera's motion trajectory during exposure and jointly optimizing NeRF parameters and camera extrinsics for each image row [S1]. It differs from standard NeRF training by replacing the single static camera pose per image with a row-wise continuous pose trajectory to handle RS distortions [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** A set of $K$ rolling shutter images $\mathbf{I}^R \in \mathbb{R}^{H \times W \times 3}$, where $H$ is the image height and $W$ is the width [S1].
*   **Outputs:** Optimized NeRF parameters $\theta_n$ and optimized camera pose parameters $\theta_p$ defining the trajectory for each RS image [S1].

**Data Structures**
*   **Camera Pose ($\mathbf{T}$):** Represented as elements of the Lie algebra of SE(3) for interpolation [S1]. The pose for row $i$ is denoted $\mathbf{T}_i$ [S1].
*   **Ray ($\hat{\mathbf{r}}$):** Defined by origin and direction, parameterized by learnable pose parameters $\theta_p$ and pixel coordinates $(u, v)$ [S1].
*   **NeRF Network ($\mathbf{C}$):** A multi-layer perceptron that takes a 3D point and viewing direction to predict color and density [G].

**Numbered Steps**
1.  **Initialize Poses:** For each of the $K$ RS images, define two learnable camera poses: $\mathbf{T}_0$ for the first row (top) and $\mathbf{T}_{H-1}$ for the last row (bottom) [S1].
2.  **Interpolate Trajectory:** For any intermediate row index $i \in [0, H-1]$, compute the pose $\mathbf{T}_i$ by linearly interpolating between $\mathbf{T}_0$ and $\mathbf{T}_{H-1}$ in the Lie algebra of SE(3) [S1].
3.  **Sample Rays:** For each iteration, select $M$ rows per image and $N$ points per row, yielding $K \times M \times N$ distinct camera rays [S1].
4.  **Compute Ray Parameters:** For each sampled pixel $(u, v)$ on row $i$, determine the camera ray $\hat{\mathbf{r}}(\theta_p; u, v)$ using the interpolated pose $\mathbf{T}_i$ derived from $\theta_p$ [S1].
5.  **Render and Loss:** Render the predicted RGB $\hat{\mathbf{C}}$ for the ray and compute the photometric loss against the ground truth row $[\mathbf{I}^R]_i$ [S1].
6.  **Optimize:** Update $\theta_n$ and $\theta_p$ to minimize the loss [S1].

**Formulas**
The image formation process assumes an infinitesimal exposure time for each row. The relationship between the RS image and a virtual global shutter image is defined as [S1]:
$$
[\mathbf{I}^R(\mathbf{x})]_i = [\mathbf{I}^G_i(\mathbf{x})]_i
$$
where $[\mathbf{I}(\mathbf{x})]_i$ extracts the $i$-th row from image $\mathbf{I}$, $\mathbf{I}^R$ is the rolling shutter image, and $\mathbf{I}^G_i$ is the virtual global shutter image captured at the same pose as the $i$-th row of $\mathbf{I}^R$ [S1].

The camera motion trajectory for row $i$ is computed via linear interpolation in the Lie algebra of SE(3) [S1]:
$$
\mathbf{T}_i = \mathbf{T}_0 \cdot (1 - \rho) + \mathbf{T}_{H-1} \cdot \rho
$$
where $\rho = \frac{i}{H-1}$ is the interpolation coefficient based on the row index $i$ [S1].

The optimization objective is the photometric loss [S1]:
$$
\mathcal{L} = ||\mathbf{C}(\mathbf{r}(u,v)) - \hat{\mathbf{C}}(\theta_n; \hat{\mathbf{r}}(\theta_p; (u,v)))||_2
$$
where $\theta_n$ are NeRF parameters, $\theta_p$ are learnable pose parameters, $\hat{\mathbf{C}}$ is the predicted RGB value, and $\mathbf{C}$ is the ground truth RGB value for the pixel at $(u, v)$ [S1].

**Parameters**
*   **Exposure Time:** Assumed infinitesimal for each row [S1].
*   **Sampling:** $M$ rows per image and $N$ points per row are selected per iteration [S1].

**Edge Cases and Pitfalls**
*   **Lie Algebra Interpolation:** The interpolation must occur in the Lie algebra of SE(3), not in Euclidean space, to ensure valid rigid body transformations [S1].
*   **Readout Direction:** The model assumes a top-to-bottom readout direction [S1].

**Pseudocode**
```python
import numpy as np
from scipy.spatial.transform import Rotation

def vanilla_rs_nerf_forward(K_images, H, W, M_rows, N_points, nerf_model, pose_params):
    """
    K_images: List of K rolling shutter images.
    H: Image height.
    W: Image width.
    M_rows: Number of rows to sample per image.
    N_points: Number of points to sample per row.
    nerf_model: The NeRF MLP function C.
    pose_params: Learnable parameters theta_p containing T_0 and T_{H-1} for each image.
    """
    total_loss = 0.0
    for image_idx in range(K_images):
        T_0 = pose_params[image_idx].T_0
        T_H_minus_1 = pose_params[image_idx].T_H_minus_1
        sampled_rows = np.random.choice(H, M_rows, replace=False)
        for row_idx in sampled_rows:
            rho = row_idx / (H - 1)
            T_i = interpolate_se3(T_0, T_H_minus_1, rho)
            sampled_cols = np.random.choice(W, N_points, replace=False)
            for col_idx in sampled_cols:
                ray = compute_ray(T_i, col_idx, row_idx, W, H)
                predicted_color = nerf_model(ray)
                ground_truth_color = K_images[image_idx][row_idx, col_idx]
                loss = np.mean((predicted_color - ground_truth_color) ** 2)
                total_loss += loss
    return total_loss / (K_images * M_rows * N_points)

def interpolate_se3(T_0, T_end, rho):
    """
    Linear interpolation in the Lie algebra of SE(3).
    Returns the interpolated pose T_i.
    """
    rot_0 = Rotation.from_matrix(T_0[:3, :3])
    rot_end = Rotation.from_matrix(T_end[:3, :3])
    trans_0 = T_0[:3, 3]
    trans_end = T_end[:3, 3]
    rot_interp = rot_0 * rot_end ** rho
    trans_interp = trans_0 * (1 - rho) + trans_end * rho
    T_i = np.eye(4)
    T_i[:3, :3] = rot_interp.as_matrix()
    T_i[:3, 3] = trans_interp
    return T_i

def compute_ray(T, u, v, W, H):
    """
    Computes camera ray origin and direction from pose T and pixel coordinates (u, v).
    """
    fx, fy = W / 2, H / 2
    cx, cy = W / 2, H / 2
    ray_dir = np.array([(u - cx) / fx, (v - cy) / fy, 1.0])
    ray_dir = T[:3, :3].T @ ray_dir
    ray_origin = -T[:3, :3].T @ T[:3, 3]
    return ray_origin, ray_dir

def l2_loss(pred, gt):
    """
    Computes L2 loss between predicted and ground truth RGB values.
    """
    return np.mean((pred - gt) ** 2)
```

## Operating characteristics
*   **Complexity:** Optimizes $2K$ boundary poses per image, with intermediate poses computed via interpolation [S1]. Ray sampling complexity scales with $K \times M \times N$ per iteration [S1].
*   **Strengths:** Explicitly handles rolling shutter distortions by modeling continuous camera motion during exposure [S1].
*   **Limitations:** Not given in the sources.
*   **When to use:** When input images are captured with a rolling shutter sensor and exhibit RS distortions [S1].

## Background
RS-NeRF was introduced to address the limitations of standard NeRFs when applied to images captured with rolling shutter cameras, which capture each row at distinct timestamps [S1]. The method builds upon the physical model of RS image formation and integrates it into the differentiable rendering pipeline [S1].
