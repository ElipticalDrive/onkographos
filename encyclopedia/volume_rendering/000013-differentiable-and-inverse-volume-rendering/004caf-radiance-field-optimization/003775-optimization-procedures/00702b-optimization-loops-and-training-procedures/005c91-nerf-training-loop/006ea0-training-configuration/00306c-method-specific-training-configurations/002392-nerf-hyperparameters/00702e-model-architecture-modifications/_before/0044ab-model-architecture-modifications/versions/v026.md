# Model Architecture Modifications

Also called: NeRF Architecture Variants, Implicit Representation Modifications

## Overview
Model Architecture Modifications extend the standard Neural Radiance Field (NeRF) framework by altering the underlying neural network structure, input conditioning, or geometric representation to address specific limitations such as sparse views, dynamic scenes, lighting variations, or computational efficiency. Unlike standard NeRF, which uses a static Multi-Layer Perceptron (MLP) to map 3D coordinates and view directions to density and color, these methods introduce auxiliary networks, discrete representations, or conditional latent codes. This family sets itself apart from [Optimization Procedures](14565-optimization-and-training-procedures.md) by focusing on the structural definition of the radiance field rather than the algorithmic steps used to train it.

## Shared principles
The standard NeRF architecture [Parent](3065-nerf-hyperparameters.md) consists of two Multi-Layer Perceptrons (MLPs): a coarse network and a fine network. The coarse network takes positional encoded position $\gamma(\mathbf{x})$ and outputs a latent feature vector $\mathbf{h}$ and volume density $\sigma$. The fine network takes $\mathbf{h}$, positional encoded position $\gamma(\mathbf{x})$, and positional encoded view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$ [14428-sparse-view-and-few-shot-optimization.md].

$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$

Modifications generally fall into three categories [14428-sparse-view-and-few-shot-optimization.md]:
1.  **Input Expansion:** Adding new conditioning vectors (e.g., appearance embeddings $\mathbf{z}_i$, fluid volume $v$, or previous stage RGB) to the input concatenation [14428-sparse-view-and-few-shot-optimization.md].
2.  **Output Expansion:** Adding auxiliary heads to predict values other than $\sigma$ and $\mathbf{c}$, such as semantic labels $y_{aux}$, object codes $o$, or area encoding probabilities $p$. These are rendered using the same transmittance weights $T_i$ and opacity $\alpha_i$ as color:
    $$
    \hat{Y}(r) = \sum_{i=1}^{N} T_i \alpha_i y_{aux}(x_i)
    $$
    [14428-sparse-view-and-few-shot-optimization.md].
3.  **Representation Substitution:** Replacing the continuous MLP function with discrete structures (voxel grids, hash tables) or different implicit surfaces (SDFs) [14428-sparse-view-and-few-shot-optimization.md].

## Subtopics

### [DoF-NeRF](9432-dof-nerf.md)
DoF-NeRF extends the standard NeRF architecture to simulate depth-of-field (DoF) effects by explicitly modeling the aperture and focus distance. It differs from siblings like [NeRF-VPT](11770-nerf-vpt.md) by incorporating optical physics (Circle of Confusion) rather than iterative visual prompts. Choose this method when training on shallow DoF inputs to recover an all-in-focus 3D scene.

### [NeRF-VPT](11770-nerf-vpt.md)
NeRF-VPT is a cascading view prompt tuning paradigm that uses RGB information from preceding rendering iterations as visual prompts for subsequent stages. It differs from [DoF-NeRF](9432-dof-nerf.md) by relying on internal network outputs as priors rather than optical models. Choose this method for sparse-view synthesis to progressively enhance image quality.

### [Activation Feature Density Approximation](12492-activation-feature-density-approximation.md)
This method estimates volumetric density $\hat{d}$ directly from intermediate activation features $\mathbf{f}_\ell$ of a coordinate-based MLP, replacing expensive coarse network evaluations. It differs from [SDF-based Neural Fields](12947-sdf-based-neural-fields.md) by retaining the standard density-based rendering formulation. Choose this method to accelerate training by approximating density from latent features.

### [Signed Distance Function (SDF) Representations](12495-signed-distance-function-sdf-representations.md)
SDF representations replace the standard NeRF density field $\sigma(\mathbf{x})$ with a continuous scalar field $s(\mathbf{x})$ representing the distance to the nearest surface. This addresses geometric inaccuracy and surface holes typical of density-based NeRFs. Choose this method when explicit, smooth surface reconstruction is required.

### [Volume-Augmented NeRF](12973-volume-augmented-nerf.md)
Volume-Augmented NeRF binds an explicit fluid volume value $v_i$ to each sample point to handle dynamic scenes, specifically fluid dynamics. Unlike static NeRF, it learns density and color based on the spatial distribution provided by a differentiable fluid simulator. Choose this method for rendering dynamic fluid scenes.

### [Neural-PIL Decomposition Architecture](12975-neural-pil-decomposition-architecture.md)
This architecture separates the estimation of scene geometry, material properties, and illumination into distinct networks. Unlike standard NeRF, it predicts density, a BRDF embedding, and an illumination embedding, using a learned pre-integrated lighting network. Choose this method when input images are captured under varying illumination and explicit reflectance decomposition is required.

### [MINE](13661-mine.md)
MINE models the frustum of the source camera using a continuous depth Multiplane Image (MPI) representation, conditioned on input images via a fully-convolutional decoder. Unlike pixelNeRF and GRF, which model the entire 3D space per ray, MINE reconstructs the frustum per plane, allowing rendering of any target view via homography warping. Choose this method for efficient novel view synthesis from a single source image.

### [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md)
These representations replace the continuous MLP function of standard NeRF with discrete, spatially structured data structures (dense voxels, sparse grids, hash tables, or triplanes). This enables memory-efficient training and real-time differentiable volume rendering. Choose this method for scalability to large scenes and faster inference.

### [Aleth-NeRF](13764-aleth-nerf.md)
Aleth-NeRF trains on under- and over-exposed images to render normal-light novel views by introducing a 'Concealing Field' assumption. It differs from standard NeRF by modeling illumination adaptive volume rendering through local and global concealing fields. Choose this method to synthesize normal-light views from low-light or over-exposed inputs without paired training data.

### [Transformer and Vision Model Integration](13911-transformer-and-vision-model-integration.md)
This family integrates Vision Transformers (ViT) and general Transformer architectures into Neural Radiance Fields to leverage global semantic understanding. It solves the limitations of standard MLP-based NeRFs, which lack explicit global scene modeling. Choose this method for generalizable NeRFs that do not require per-scene tuning.

### [Human and Specific Subject Modeling](13997-human-and-specific-subject-modeling.md)
This family adapts the standard NeRF architecture to model dynamic human subjects, enabling novel view synthesis and novel pose rendering. Unlike static scene modeling, these methods explicitly integrate parametric human priors (such as SMPL) or structured latent codes anchored to deformable meshes. Choose this method for animatable human avatars.

### [OPONeRF](14014-oponerf.md)
OPONeRF personalizes the parameters of the plenoptic mapping function for each sampled 3D point to handle test-time scene changes. Unlike vanilla NeRFs where network parameters are shared and fixed, OPONeRF dynamically conditions the network weights $\Theta$ on the point's representation $\mathbf{x}$ and the overall scene representation $\mathbf{F}$. Choose this method for robustness against perturbations such as motion or illumination changes.

### [Mixer-NeRF](14073-mixer-nerf.md)
Mixer-NeRF addresses the loss of local information and blurry details in standard NeRFs by introducing a hybrid spatial feature learning module (MLCA) and a squeeze-and-excitation (SE) network module. It sets itself apart by explicitly mixing spatial and channel features via fully connected layers before the main MLP inference. Choose this method to recover high-frequency details.

### [Sparse View and Few-Shot Optimization](14428-sparse-view-and-few-shot-optimization.md)
This family addresses severe overfitting, geometry breakdown, and artifact generation that occur when training NeRF with a drastically reduced number of input viewpoints. Unlike standard NeRF methods that rely on dense sampling, these techniques mitigate ambiguity through in-situ regularization, deformable sampling strategies, or pseudo-observation densification. Choose this method for sparse-view reconstruction.

### [Mixture-of-Experts and Modular Architectures](14429-mixture-of-experts-and-modular-architectures.md)
This family encompasses architectures that replace or augment the single continuous function of standard NeRF with multiple specialized networks (experts) or parallel processing streams. It solves the limitations of conventional Implicit Neural Representations (INRs), which struggle with complex features using a single network. Choose this method to improve compression, training speed, or representation capacity.

### [Uncertainty and Reliability](14487-uncertainty-and-reliability.md)
Uncertainty and Reliability methods extend standard NeRF architectures to quantify prediction confidence, addressing artifacts, redundancy, and geometry collapse in sparse or unstructured data. Unlike deterministic NeRF variants, these methods model the scene as a probabilistic entity. Choose this method for robust filtering and conformal prediction.

### [Object Decomposition and Composition](14518-object-decomposition-and-composition.md)
Object Decomposition and Composition methods extend standard NeRF architectures to separate a scene into distinct object instances and a background. Unlike sibling methods that may rely on explicit point clouds, these approaches integrate decomposition into the differentiable rendering pipeline. Choose this method for individual object manipulation and amodal segmentation.

### [Lighting and Appearance Models](14522-lighting-and-appearance-models.md)
Lighting and Appearance Models modify the standard NeRF architecture to explicitly represent illumination and material properties, enabling relighting. Unlike standard NeRF, which learns view-dependent color implicitly, these models separate albedo from illumination. Choose this method for handling varying lighting conditions and relighting.

### [Optimization and Training Procedures](14565-optimization-and-training-procedures.md)
This family covers the algorithmic procedures for optimizing Neural Radiance Fields, ranging from standard training loops to specialized acceleration and editing techniques. Unlike standard gradient descent, methods in this family often employ structural modifications to the optimization scope. Choose this method for efficient minimization of photometric loss.

### [Image Enhancement and Restoration Methods](14566-image-enhancement-and-restoration-methods.md)
Image Enhancement and Restoration Methods address the degradation of input imagery—such as blur, transient occlusions, or low resolution—by integrating restoration mechanisms directly into the NeRF optimization loop. Unlike standard NeRF, these methods either model the degradation process or separate static scene geometry from transient artifacts. Choose this method for rendering clean novel views from degraded inputs.

### [Modular, Hierarchical, and Latent Architectures](14567-modular-hierarchical-and-latent-architectures.md)
This family extends standard NeRF architectures to handle non-rigid deformation with topological changes and hierarchical scene structures. [HyperNeRF](13906-hypernerf.md) models non-rigidly deforming scenes by lifting the canonical 3D space into a higher-dimensional ambient space. [Strata-NeRF](14015-strata-nerf.md) models stratified scenes by replacing continuous positional encoding inputs with discrete latent codes. Choose this method for complex dynamic or hierarchical scenes.

### [MuRF (Multi-Baseline Radiance Fields)](15007-murf-multi-baseline-radiance-fields.md)
MuRF is a feed-forward method for sparse view synthesis that solves the problem of rendering novel views under varying camera baseline settings. It differs from prior radiance field methods by constructing a **target view frustum volume** aligned with the target camera rather than a reference input view. Choose this method for large baseline novel view synthesis.

### [Gaussian and Primitive-Based Representations](15011-gaussian-and-primitive-based-representations.md)
This family replaces the continuous Multi-Layer Perceptron (MLP) radiance field with discrete geometric primitives or explicit Gaussian distributions. It differs from sibling methods like [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md) by using analytic primitives rather than voxel grids. Choose this method for improved rendering efficiency and geometric fidelity.

### [Decentralized Federated NeRF](15032-decentralized-federated-nerf.md)
Decentralized Federated NeRF (DecentNeRF) is a framework for learning global 3D scene representations from crowd-sourced images by distributing training computation to users. It solves the problem of achieving photorealistic 3D reconstruction while preventing the server from reconstructing transient personal content. Choose this method for privacy-preserving crowd-sourced reconstruction.

### [Neural Proxy](15220-neural-proxy.md)
Neural Proxy represents photo-realistic targets as animatable proxies, enabling the synthesis of unseen animations without temporal learning. It combines neural volume rendering with neural texture by injecting an animatable mesh proxy into the scene. Choose this method for animatable neural rendering.

### [ViSNeRF](15255-visnerf.md)
ViSNeRF is a hybrid neural radiance field method designed for the efficient synthesis of visualizations from dynamic volumetric scenes with arbitrary adjustable parameters. It solves the scalability problem of representing high-dimensional $(3+K)$-D radiance fields by combining explicit feature grids with implicit MLP decoders. Choose this method for dynamic volumetric visualization.

### [EBAD-NeRF](15441-ebad-nerf.md)
EBAD-NeRF is a method for reconstructing sharp 3D radiance fields from motion-blurred images by jointly optimizing learnable camera poses and NeRF parameters using hybrid event-RGB data. It distinguishes itself by modeling complex camera motion trajectories with multiple learnable poses. Choose this method for deblurring motion-blurred scenes.

### [Point-NeRF Representation](15538-point-nerf-representation.md)
Point-NeRF replaces the continuous Multi-Layer Perceptron (MLP) function used in standard NeRF with a discrete neural point cloud. This approach avoids ray sampling in empty space by leveraging classical point clouds. Choose this method for faster optimization and higher-quality rendering than standard NeRF.

### [NeurMiPs](15543-neurmips.md)
NeurMiPs represents a 3D scene as a mixture of $K$ learnable rectangular planar surfaces, where each surface acts as an independent "expert". It alleviates the frontal-parallel limitation of traditional Multi-Plane Imagery (MPI). Choose this method for high-efficiency rendering with superior extrapolation capabilities.

### [CodeNeRF](15544-codenerf.md)
CodeNeRF is an implicit 3D neural representation that learns the variation of object shapes and textures across a semantic category. Unlike standard NeRF, it disentangles shape and texture by learning separate latent embeddings. Choose this method for one-shot reconstruction and explicit editing of unseen objects.

### [Dynamic Scene and Temporal Modeling](15546-dynamic-scene-and-temporal-modeling.md)
Dynamic Scene and Temporal Modeling extends static Neural Radiance Fields (NeRF) to reconstruct and render scenes that change over time. Unlike static NeRF variants, these methods explicitly model the 4D space-time volume. Choose this method for temporal consistency in dynamic environments.

### [NeRF-Casting](15547-nerf-casting.md)
NeRF-Casting synthesizes photorealistic specular appearance and reflections in real-world scenes by integrating ray tracing into the NeRF rendering pipeline. It solves the problem of view-dependent appearance modeling by casting reflection rays from points along camera rays. Choose this method for realistic reflections without large MLPs.

### [RoseNeRF](15548-rosenerf.md)
RoseNeRF is a method for high-fidelity novel view synthesis of real refractive objects that simplifies complex ray interactions inside transparent media to a single refraction event. It models refraction by predicting a single refracted ray using a 4D light field representation. Choose this method for rendering transparent objects.

### [Semantic and Feature Field Extensions](15556-semantic-and-feature-field-extensions.md)
Semantic and Feature Field Extensions generalize the Neural Radiance Field (NeRF) formulation to predict arbitrary per-point feature signals $\mathbf{f}$ in addition to color $\mathbf{c}$ and density $\sigma$. This enables the lifting of 2D observations into a consistent 3D representation. Choose this method for semantic segmentation and feature lifting.

### [Neural Density-Distance Fields](15665-neural-density-distance-fields.md)
Neural Density-Distance Fields (NeDDF) reciprocally constrains distance and density fields, extending the distance field formulation to adapt to any density field. It allows for boundaryless scenes and complex shapes by deriving density from depth values. Choose this method for stable mesh extraction and camera pose localization.

### [LAENeRF](15738-laenerf.md)
LAENeRF is a unified framework for the photorealistic and non-photorealistic local appearance editing of pre-trained Neural Radiance Fields (NeRFs). It solves the problem of recoloring or stylizing arbitrary 3D regions while minimizing background artifacts. Choose this method for interactive 3D editing.

### [ExtremeNeRF](15739-extremenerf.md)
ExtremeNeRF is a few-shot view synthesis framework designed to generate novel views from sparse multi-view images captured under unconstrained, varying illumination. It achieves robustness by enforcing multi-view albedo consistency through a two-stage intrinsic decomposition pipeline. Choose this method for illumination-robust few-shot synthesis.

### [Frequency-Modulated Point Cloud Rendering](15903-frequency-modulated-point-cloud-rendering.md)
Frequency-Modulated Point Cloud Rendering (also known as AFNet or FreqPCR) is a real-time rendering pipeline that replaces the standard continuous MLP radiance field with a point cloud representation modulated by an Adaptive Frequency Net (AFNet). It solves the problem of high-frequency detail reconstruction and slow rendering speeds. Choose this method for real-time high-fidelity rendering.

### [Conditional and Latent Representations](15989-conditional-and-latent-representations.md)
Conditional and Latent Representations extend standard NeRF architectures to model entire object classes or multiple 3D instances using a single neural network. By conditioning the radiance field on per-instance latent codes, this approach enables efficient representation of varying geometry and texture. Choose this method for generalizable NeRFs across multiple instances.

### [ActiveNeRF Model Architecture](16203-activenerf-model-architecture.md)
ActiveNeRF modifies the standard NeRF architecture to output prediction variance alongside density and color, enabling uncertainty-aware view synthesis. Unlike sibling architectures, it introduces an auxiliary output head for variance estimation. Choose this method for active sampling strategies.

### NeRF-VAE
- **Definition:** A generative NeRF model that generalizes to out-of-distribution scenes and removes the need to train on each scene from scratch [S1].
- **Steps:** The NeRF renderer is conditioned on a latent code. This latent code is trained using Iterative Amortized Inference and a ResNet encoder. An attention-based scene function is introduced instead of the typical MLP [S1].
- **Comparison:** Outperforms baseline NeRF with a low number of scene views (5-20), but is outperformed by baseline NeRF when a large number of views are available (100+) due to lower scene expressivity [S1].

### PIE-NeRF
- **Definition:** A pipeline integrating physics-based elastodynamic simulation with a neural radiance field representation, using a meshless discretisation based on quadratic generalized moving least squares on top of the density field of a NeRF [S1].
- **Steps:** Enables large deformations and nonlinear hyperelastic material simulation directly on the implicit representation and supports interactive manipulation of real-world captured scenes with complex geometries [S1].

### DäRF Implementation Details
- **Parameters:** NeRF Backbone: K-planes [36]. MDE Model: DPT-hybrid [38]. Optimizer: Adam [21]. NeRF Learning Rate: 1e-2. MDE Learning Rate: 1e-5. LR Schedule: Cosine warmup [S2, unofficial].

### NeRF Model Architecture
- **Definition:** The neural network architecture for NeRF, consisting of dense layers with ReLU activations, potentially using view directions as input [S3, unofficial].
- **Parameters:** `D`: The depth of the network (number of hidden layers). Default is 8. `input_ch_views`: The number of input channels for view directions. Default is 3. `output_ch`: The number of output channels. Default is 4 (RGB + density). `use_viewdirs`: Boolean flag to determine if view directions are used as input to the network [S3, unofficial].

### S3-NeRF
- **Definition:** A method using shadow and shading cues to infer scene geometry and enable single-image NeRF training [S1].
- **Steps:** Employ a UNISURF-based occupancy field 3D representation instead of density. Use a modified physics-based rendering equation. Use occupancy-based shadow calculation [S1].

### NeuralEditor
- **Definition:** A method employing a point cloud-guided NeRF model for shape manipulation, leveraging K-D trees and deterministic integration strategy for accurate point cloud-based rendering, with Phong reflection modeling to enhance color fidelity and geometric detail [S4].
- **Steps:** 1. Employ point cloud-guided NeRF model. 2. Leverage K-D trees. 3. Use deterministic integration strategy. 4. Achieve accurate point cloud-based rendering. 5. Apply Phong reflection modeling [S4].

### [Network Architectures](15530-network-architectures.md)
- **Parameters:** MLPs A and F use the MLP designed in NeRF, with hidden layer sizes increased from 256 to 384. MLPs A and F are not used during inference, allowing more time on training. Small MLP H is the same as the small MLP used in SNeRG, with two hidden layers, each consisting 16 neurons.

### NeRF-Swin
- **Definition:** A baseline method that performs super-resolution on an LR NeRF using released SwinIR models under the 'Real-World Image Super-Resolution' setting, trained on more than 10k LR-HR pairs [S6].
- **Parameters:** Training set size: More than 10k LR-HR pairs [S6].
- **Pitfalls:** On synthetic Blender dataset, SwinIR may produce false predictions due to domain mismatch. On real-world LLFF dataset, SwinIR tends to be oversmooth and may predict false color or geometry [S6].
- **Metrics:** Blender ×2 (100x100): PSNR 26.34, SSIM 0.913, LPIPS 0.075. Blender ×4 (100x100): PSNR 24.85, SSIM 0.881, LPIPS 0.108. Blender ×2 (200x200): PSNR 28.03, SSIM 0.926, LPIPS 0.058. Blender ×4 (200x200): PSNR 26.78, SSIM 0.906, LPIPS 0.086. LLFF ×2: PSNR 25.18, SSIM 0.793, LPIPS 0.147. LLFF ×4: PSNR 23.26, SSIM 0.685, LPIPS 0.247 [S6].

## Background
The original NeRF implementation by Mildenhall et al. [1] employed hierarchical rendering with two networks (coarse and fine) to improve computational efficiency. Subsequent works have focused on accelerating training and inference, often by modifying the architecture to include discrete representations, conditional inputs, or auxiliary tasks. The field has evolved from static, dense-view reconstruction to dynamic, sparse-view, and generalizable representations, driven by the need for efficiency and robustness in real-world applications.
