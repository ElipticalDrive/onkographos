# ProbeSDF

Also called: Light Field Probes For Neural Surface Reconstruction

## Overview
ProbeSDF is a neural surface reconstruction method that decouples spatial and angular light field components using two volumetric grids of different resolutions to achieve real-time rendering and accelerated training [S1]. It addresses the computational bottleneck of standard SDF-based neural fields by replacing the core appearance MLP with a lightweight model that uses spherical harmonic light field probes for angular variation and planar factorized features for spatial texture [S1]. Unlike Plenoxels or 3D Gaussian Splatting which require significantly more parameters per voxel (27 and 48 respectively), ProbeSDF uses as few as four parameters per voxel while maintaining high expressiveness [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Multi-view images, camera poses, and an initial sparse voxel grid structure [S1].
*   **Outputs:** A signed distance function (SDF) field, spatial feature grid, angular feature grid (probes), and optionally per-camera bias vectors [S1]. The final output is rendered images via standard SDF-based volume rendering [G].

**Data Structures:**
1.  **SDF Grid:** Implicit representation of 3D shape storing SDF values and derived surface normals $\mathbf{n}$ [S1].
2.  **Spatial Feature Grid ($F_s$):** High-resolution grid using planar factorization [S1]. Each $16^3$ tile contains three orthogonal planes of resolution $16 \times 16$, where each plane stores $n_s$ coefficients per element, yielding $3 \times 16 \times 16 \times n_s$ spatial coefficients per tile [S1].
3.  **Angular Feature Grid ($F_a$):** Coarser grid storing light field probes as spherical harmonic coefficients [S1]. Probes are stored at the corners of the spatial tiles [S1]. Probes at shared corners of adjacent tiles are duplicated in memory but maintain shared values to benefit from hardware-accelerated interpolation [S1]. Each probe stores $l^2 \times n_a$ coefficients, where $l$ is the spherical harmonic order and $n_a$ is the number of angular features per coefficient [S1].
4.  **MLP:** A small neural network with 2 hidden layers, 32 neurons per layer, ReLU activations, and a sigmoid activation for the final output layer [S1].

**Parameters:**
*   $n_s$: Number of spatial coefficients per probe dimension. Typical value: 4 or 8 [S1].
*   $n_a$: Number of angular features. Typical value: 4 or 8 [S1].
*   $l$: Spherical harmonic order. Up to 16 coefficients ($l=4$). Typical value: 4 [S1].
*   Per-camera bias vectors: Optional MLP bias vectors trained per camera to handle inconsistent shadows or large exposure changes (used for DTU and BMVS) [S1].
*   Grid resolutions: DTU ($1000^3$), BMVS ($666^3$), MVMannequins ($2500 \times 1250 \times 2500$, 2mm/voxel), ActorsHQ ($3000 \times 4000 \times 3000$, 0.6mm/voxel) [S1].

**Method Steps:**

1.  **Ray Marching and SDF Evaluation:**
    For a given camera ray, sample points $\mathbf{x}$ along the ray. Query the SDF grid to get $s(\mathbf{x})$. Compute the surface normal $\mathbf{n} = \nabla s(\mathbf{x}) / \|\nabla s(\mathbf{x})\|$ [Parent]. Convert the SDF value to volume density $\sigma(\mathbf{x})$ using a differentiable mapping that concentrates density near the zero-level set [G].

2.  **Spatial Feature Extraction ($F_s$):**
    For point $\mathbf{x}$, identify the containing $16^3$ tile. Retrieve the three orthogonal planes ($F_x, F_y, F_z$) for that tile. Compute the spatial feature vector via planar factorization (outer product):
    $$F_s = F_x \otimes F_y \otimes F_z$$
    This reduces dimensionality by storing three orthogonal planes per tile instead of a dense 3D grid [S1].

3.  **Angular Feature Extraction ($F_a$):**
    Compute the reflected vector $\mathbf{r}$ based on the view direction $\mathbf{v}$ and surface normal $\mathbf{n}$ (typically $\mathbf{r} = 2(\mathbf{n} \cdot \mathbf{v})\mathbf{n} - \mathbf{v}$) [S1]. Retrieve the 8 corner probes of the containing tile in the angular grid. Tri-linearly interpolate the spherical harmonic coefficients from these 8 corners to obtain the angular feature vector $F_a(\mathbf{x}, \mathbf{r})$ [S1].

4.  **Incidence Angle Embedding:**
    Compute the power terms of the cosine angle between the view direction and the surface normal to account for grazing angle reflectivity (Fresnel approximation):
    $$\text{incidence} = [(1 - \mathbf{n} \cdot \mathbf{v})^0, (1 - \mathbf{n} \cdot \mathbf{v})^1, \dots, (1 - \mathbf{n} \cdot \mathbf{v})^5]$$
    The term $(1 - \mathbf{n} \cdot \mathbf{v})$ approximates $\cos \theta$ where $\theta$ is the angle of incidence [S1].

5.  **Radiance Decoding:**
    Concatenate $F_s$, $F_a$, and the incidence angle embeddings. Pass them through the tiny MLP to predict the outgoing radiance $C$:
    $$C = MLP(F_s(\mathbf{x}), F_a(\mathbf{x}, \mathbf{r}), (1 - \mathbf{n} \cdot \mathbf{v})^0, \dots, (1 - \mathbf{n} \cdot \mathbf{v})^5, \dots)$$
    The MLP acts as a minimal BRDF decoder [S1].

6.  **Volume Rendering:**
    Composite the predicted radiance $C$ along the ray using standard SDF-based volume rendering [G].

7.  **Optimization:**
    Optimize the SDF grid values, spatial features, angular probe coefficients, and optionally per-camera bias vectors using gradient descent to minimize the difference between rendered and input images [S1].

**Pseudocode:**

```python
import numpy as np

def relu(x):
    return np.maximum(0, x)

def sigmoid(x):
    return 1.0 / (1.0 + np.exp(-x))

def sdf_to_density(s, scale=10.0):
    """Standard differentiable SDF-to-density conversion [G]."""
    return scale * np.exp(-scale * np.abs(s))

def compute_normal(sdf_grid, x, eps=1e-4):
    """Finite difference gradient of SDF [G]."""
    dx = np.array([eps, 0, 0])
    grad = np.array([
        sdf_grid.query(x + dx) - sdf_grid.query(x - dx),
        sdf_grid.query(x + dx * [0, 1, 0]) - sdf_grid.query(x - dx * [0, 1, 0]),
        sdf_grid.query(x + dx * [0, 0, 1]) - sdf_grid.query(x - dx * [0, 0, 1])
    ]) / (2 * eps)
    return grad / np.linalg.norm(grad)

def get_tile_id(x, tile_size):
    """Return integer tile ID containing point x [G]."""
    return tuple(int(coord // tile_size) for coord in x)

def get_local_coords(x, tile_size):
    """Return normalized coordinates [0, 1) within the tile [G]."""
    tile_id = get_tile_id(x, tile_size)
    tile_origin = np.array(tile_id) * tile_size
    return (x - tile_origin) / tile_size

def interpolate_3d(plane, local_coords):
    """Trilinear interpolation on a 16x16 plane [G]."""
    # local_coords is (3,), but plane is 2D. We project to the dominant axis or use 2D bilinear.
    # For planar factorization, we typically interpolate on the 2D plane.
    # Simplified: assume interpolation on the first two dimensions.
    u, v = local_coords[0], local_coords[1]
    u_idx = u * 15
    v_idx = v * 15
    u0, v0 = int(np.floor(u_idx)), int(np.floor(v_idx))
    u1, v1 = min(u0 + 1, 15), min(v0 + 1, 15)
    du, dv = u_idx - u0, v_idx - v0
    val = (1-du)*(1-dv)*plane[u0, v0] + du*(1-dv)*plane[u1, v0] + (1-du)*dv*plane[u0, v1] + du*dv*plane[u1, v1]
    return val

def get_tile_corners(tile_id):
    """Return 8 corner IDs of a tile [G]."""
    x, y, z = tile_id
    return [
        (x, y, z), (x+1, y, z), (x, y+1, z), (x+1, y+1, z),
        (x, y, z+1), (x+1, y, z+1), (x, y+1, z+1), (x+1, y+1, z+1)
    ]

def probe_sdf_render(ray_origin, ray_direction, sdf_grid, spatial_grid, angular_grid, 
                     tile_size=16, ns=4, na=4, l=4, mlp_weights=None):
    """
    Renders a single ray using ProbeSDF appearance model.
    """
    num_samples = 256
    dt = 0.01
    color = np.zeros(3)
    alpha_accum = 0.0
    
    for t in range(num_samples):
        x = ray_origin + t * ray_direction * dt
        s_val = sdf_grid.query(x)
        if s_val > 0.5: continue # Outside object
        n = compute_normal(sdf_grid, x)
        sigma = sdf_to_density(s_val)
        
        # Spatial Features
        tile_id = get_tile_id(x, tile_size)
        planes = spatial_grid[tile_id] # Shape (3, 16, 16, ns)
        local = get_local_coords(x, tile_size)
        F_x = interpolate_3d(planes[0], local)
        F_y = interpolate_3d(planes[1], local)
        F_z = interpolate_3d(planes[2], local)
        F_s = np.outer(np.outer(F_x, F_y), F_z).flatten()
        
        # Angular Features
        v = ray_direction
        r = 2 * np.dot(n, v) * n - v
        corner_ids = get_tile_corners(tile_id)
        corner_coeffs = [angular_grid[cid].flatten() for cid in corner_ids]
        
        # Trilinear interpolation weights for corners
        u, w, z = local
        weights = [
            (1-u)*(1-w)*(1-z), u*(1-w)*(1-z), (1-u)*w*(1-z), u*w*(1-z),
            (1-u)*(1-w)*z, u*(1-w)*z, (1-u)*w*z, u*w*z
        ]
        F_a = np.zeros(len(corner_coeffs[0]))
        for i, c in enumerate(corner_coeffs):
            F_a += weights[i] * c
            
        # Incidence Angle Embedding
        cos_theta = np.dot(n, v)
        incidence = np.array([(1 - cos_theta)**i for i in range(6)])
        
        # MLP Decoding
        input_vec = np.concatenate([F_s, F_a, incidence])
        h1 = relu(np.dot(input_vec, mlp_weights['W1']) + mlp_weights['b1'])
        h2 = relu(np.dot(h1, mlp_weights['W2']) + mlp_weights['b2'])
        C = sigmoid(np.dot(h2, mlp_weights['W3']) + mlp_weights['b3'])
        
        # Volume Rendering
        alpha = 1.0 - np.exp(-sigma * dt)
        weight = alpha * (1.0 - alpha_accum)
        color += weight * C
        alpha_accum += weight
        if alpha_accum > 0.99: break
            
    return color
```

## Operating characteristics
*   **Time Complexity:** Training converges in minutes (e.g., ~1 min for MVMannequins, ~150-160s for DTU, ~110-120s for BMVS, ~4 min for ActorsHQ) compared to hours for baselines like Voxurf or NeuS2 [S1]. Rendering achieves 200-300 Hz on DTU and 300-400 Hz on MVMannequins on an RTX A6000 GPU [S1].
*   **Memory Complexity:** Highly memory efficient. Probes require 1/6th of the memory taken by spatial features when $l=4$ and $n_s=n_a$ [S1]. Model sizes are small (e.g., 30MB for MVMannequins, 56-88MB for DTU, 57-232MB for ActorsHQ) [S1]. VRAM usage is low (e.g., 5GB for MVMannequins) [S1].
*   **Performance:**
    *   **MVMannequins:** PSNR 36.81-36.90, Chamfer 1.03-1.04mm [S1].
    *   **ActorsHQ:** PSNR 37.48 (r/1), 36.62 (r/4) [S1].
    *   **DTU:** PSNR 37.03-37.74, Chamfer 0.68-0.71mm [S1].
    *   **BlendedMVS:** PSNR 35.19-35.89, Chamfer 2.22-2.37mm [S1].
*   **Strengths:** Real-time rendering, fast training, low memory footprint, high PSNR and geometric accuracy on generic objects and humans with mild specularities [S1].
*   **Limitations:**
    *   Lighting encoded locally degrades extrapolation capabilities, causing shadow artifacts when looking from above or below on datasets with limited camera overlap along latitude (e.g., ActorsHQ legs) [S1].
    *   Local minima due to shape-radiance ambiguities because light transport is not explicitly simulated [S1].
    *   Relighting and material editing are not supported [S1].
    *   Targets objects with mild specularities; cone tracing methods are better for strong reflections but require >10 GPU-hours [S1].

## Background
ProbeSDF was introduced in the paper "ProbeSDF: Light Field Probes For Neural Surface Reconstruction" [S1]. It builds on the hypothesis that angular components (lighting/environment) are predominantly extrinsic to the surface and locally invariant to parallax, allowing them to be encoded at a lower spatial resolution than intrinsic spatial texture [S1]. The method uses a sparse voxel grid based on Voxurf with targeted modifications to implement probes [S1]. It is evaluated on four representative datasets: MVMannequins, ActorsHQ, DTU, and BlendedMVS [S1].
