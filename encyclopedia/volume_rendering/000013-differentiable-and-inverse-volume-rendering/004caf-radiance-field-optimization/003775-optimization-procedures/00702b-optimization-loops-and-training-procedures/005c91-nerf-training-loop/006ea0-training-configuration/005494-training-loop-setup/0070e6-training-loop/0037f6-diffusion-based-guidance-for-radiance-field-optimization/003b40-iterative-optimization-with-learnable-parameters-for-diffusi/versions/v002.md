# Iterative Optimization with Learnable Parameters for Diffusion-Guided Radiance Fields

Also called: Iterative Optimization with Learnable Parameters

## Overview
This method addresses quality impairments in 3D generation caused by discrepancies between the diffusion prior and the training process of the diffusion model [S1][S2, unofficial]. It sets itself apart from standard diffusion-guided approaches by iteratively optimizing both the 3D model and specific learnable parameters within the diffusion guidance mechanism, rather than treating the diffusion model as a static prior [S1][S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A frozen pre-trained diffusion model, a 3D radiance field representation (e.g., 3D Gaussian Splatting or NeRF), and a text prompt [S1][S2, unofficial].
- Output: An optimized 3D radiance field [S1][S2, unofficial].

**Data Structures:**
- **Learnable Unconditional Embedding ($e_{\text{uncond}}$):** A vector parameter introduced into the classifier-free guidance formula to replace or augment the standard unconditional embedding [S1][S2, unofficial].
- **Network Parameters ($\theta_{\text{net}}$):** Additional parameters added to the diffusion network, such as Low-Rank Adaptation (LoRA) weights [S1][S2, unofficial].
- **3D Model Parameters ($\theta_{\text{3D}}$):** The parameters defining the radiance field representation being optimized [G].

**Numbered Steps:**
1. **Initialization:** Initialize the 3D model parameters $\theta_{\text{3D}}$, the learnable unconditional embedding $e_{\text{uncond}}$, and the additional network parameters $\theta_{\text{net}}$ [G].
2. **Iterative Optimization:** Perform iterative optimization of the 3D model and the diffusion prior [S1][S2, unofficial].
3. **Guidance Modification:** Introduce the two learnable parameters into the classifier-free guidance formula: substitute the unconditional embedding with $e_{\text{uncond}}$ and apply the updated network parameters $\theta_{\text{net}}$ [S1][S2, unofficial].
4. **Update:** Optimize the 3D model parameters, $e_{\text{uncond}}$, and $\theta_{\text{net}}$ jointly based on the diffusion guidance signal [S1][S2, unofficial].

**Formulas:**
The method modifies the standard classifier-free guidance formula to incorporate the learnable parameters. Let $\epsilon_\theta$ denote the noise prediction network. The guidance signal is computed as:
$$ \epsilon_{\text{pred}} = \epsilon_\theta(z_t, c, t) + w \cdot (\epsilon_\theta(z_t, c, t) - \epsilon_\theta(z_t, e_{\text{uncond}}, t)) $$
Where:
- $z_t$ is the noisy latent or image at timestep $t$ [G].
- $c$ is the conditional text embedding [G].
- $e_{\text{uncond}}$ replaces the standard unconditional embedding $u$ in the guidance term [S1][S2, unofficial].
- The network $\epsilon_\theta$ is updated with the additional parameters $\theta_{\text{net}}$ (e.g., LoRA) during optimization [S1][S2, unofficial].
- $w$ is the guidance scale [G].

**Parameters:**

**Pseudocode:**
```python
# Initialize parameters
theta_3D = torch.nn.Parameter(torch.randn(num_gaussians, feature_dim))  # [G] 3D model parameters
e_uncond = torch.nn.Parameter(torch.randn(embed_dim))                  # [G] Learnable unconditional embedding
theta_net = torch.nn.Parameter(torch.randn(net_weight_dim))             # [G] Additional network parameters (e.g., LoRA)

for iteration in range(max_iterations):  # [G] Iterate until convergence
    # 1. Render image from current 3D model at a random viewpoint
    image = render_radiance_field(theta_3D, random_viewpoint())  # [G] Differentiable volume rendering

    # 2. Encode image to latent space
    z_t = vae_encoder(image)  # [G] VAE forward pass

    # 3. Add noise for diffusion step
    noise = torch.randn_like(z_t)
    z_noisy = add_noise_to_latent(z_t, noise, timestep)  # [G] Forward diffusion process

    # 4. Predict noise using diffusion model with learnable parameters
    # Replace standard unconditional embedding with e_uncond
    # Apply updated network parameters theta_net
    epsilon_cond = diffusion_model.predict_noise(z_noisy, text_prompt, timestep, unconditional_embedding=e_uncond, network_params=theta_net)

    # 5. Compute Score Distillation Sampling (SDS) loss
    loss = compute_sds_loss(epsilon_cond, noise, timestep)  # [G] Standard SDS gradient computation

    # 6. Backpropagate and update all learnable parameters
    loss.backward()
    optimizer.step(theta_3D, e_uncond, theta_net)
    optimizer.zero_grad()
```

## Background
The method was proposed by Yang et al. [S1][S2, unofficial]. It is part of the broader effort to improve 3D generation quality by aligning the diffusion prior with the 3D model training process [S1][S2, unofficial]. It is applicable to various 3D representations, including 3D Gaussian Splatting (3DGS) and NeRF-based methods [S1][S2, unofficial].
