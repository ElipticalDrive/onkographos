# Multi-input MLP (mi-MLP)
Also called: mi-MLP, per-layer inputs incorporation

## Overview
The multi-input MLP (mi-MLP) is a network architecture modification for Neural Radiance Fields that incorporates the input embeddings (3D location and viewing direction) into every layer of the MLP to alleviate overfitting in few-shot view synthesis [S1]. Unlike the standard NeRF architecture [20497-network-structure-modifications.md] which passes features through a chain of layers where only the final layer explicitly consumes the directional encoding, mi-MLP ensures each layer is explicitly aware of the input embeddings, creating shorter paths between inputs and outputs [S1]. This allows the model to synthesize high-frequency details with fewer parameters while maintaining model capacity [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 5D coordinate vector $\mathbf{x} \in \mathbb{R}^5$, composed of the 3D spatial position $\mathbf{p} \in \mathbb{R}^3$ and the 2D viewing direction $\mathbf{d} \in \mathbb{R}^2$ (normalized).
*   **Output:** Volume density $\sigma \in \mathbb{R}$ and view-dependent color $\mathbf{c} \in \mathbb{R}^3$.

**Data Structures:**
The network consists of $L_{layers}$ linear layers followed by activation functions.
*   **Layer $i$ ($i=1 \dots L_{layers}$):** Defined by weight matrices $\mathbf{W}_i$ and bias vector $\mathbf{b}_i$.
*   **Input Embedding:** The raw input $\mathbf{x}$ is transformed into an embedding $\gamma_L(\mathbf{x})$ using positional encoding.

**Positional Encoding:**
The input $\mathbf{x}$ is encoded using $\gamma_L(\mathbf{x})$, defined as:
$$ \gamma_L(\mathbf{x}) = (\sin(2^0 \mathbf{x}), \cos(2^0 \mathbf{x}), \dots, \sin(2^{L-1} \mathbf{x}), \cos(2^{L-1} \mathbf{x})) $$
where $L$ is a hyperparameter controlling the number of frequency bands [S1]. The dimension of $\gamma_L(\mathbf{x})$ is $2 \cdot L \cdot 5$ (assuming $\mathbf{x}$ has 5 components). Let $d_1$ be the dimension of $\gamma_L(\mathbf{x})$ [S1].

**Layer Definition:**
Let $\mathbf{f}_i$ be the output feature vector of layer $i$.
For the first layer ($i=1$):
$$ \mathbf{f}_1 = \phi_1(\gamma_L(\mathbf{x})) $$
For subsequent layers ($i > 1$):
$$ \mathbf{f}_i = \phi_i(\mathbf{f}_{i-1}, \gamma_L(\mathbf{x})) $$
where $\phi_i$ is the transformation function of the $i$-th layer [S1].

**Mathematical Formulation:**
Let $\mathbf{f}_i \in \mathbb{R}^{d_2}$ be the output of layer $i$, where $d_2$ is the hidden dimension [S1].
Let $\mathbf{w}_i^j$ be the weight vector for the $j$-th neuron in layer $i$, decomposed into $\mathbf{w}_i^{j0} \in \mathbb{R}^{1 \times d_1}$ (weights for input embedding) and $\mathbf{w}_i^{j1} \in \mathbb{R}^{1 \times d_2}$ (weights for previous layer output) [S1].
The $j$-th element of the output feature $\mathbf{f}_i$, denoted $\phi_i^j$, is computed as:
$$ \phi_i^j(\gamma_L(\mathbf{x})) = \epsilon\left( \mathbf{w}_i^{j0}[\gamma_L(\mathbf{x})] + \mathbf{w}_i^{j1}[\mathbf{f}_{i-1}] + b_i^j \right) $$
where $\epsilon$ is the activation function (default ReLU) [S1].
Note: For $i=1$, $\mathbf{f}_{i-1}$ is treated as zero or the term $\mathbf{w}_i^{j1}[\mathbf{f}_{i-1}]$ is omitted, effectively $\phi_1^j = \epsilon(\mathbf{w}_1^{j0}[\gamma_L(\mathbf{x})] + b_1^j)$ [S1].

**Parameters:**
*   **$L$ (Frequency Bands):** Hyperparameter for positional encoding. Not given in the sources.
*   **Hidden Dimension ($d_2$):** Not given in the sources.
*   **Activation:** ReLU [S1].
*   **Weight Initialization:** Default PyTorch initialization is used. The sources state this initialization satisfies the condition $\|\mathbf{w}_i^{j1}\|_1 \in (0, 1]$ [S1].

**Algorithm Steps:**
1.  **Encode Input:** Compute $\gamma_L(\mathbf{x})$ from the input 5D coordinate $\mathbf{x}$ using the sinusoidal positional encoding formula.
2.  **Initialize First Layer:** Compute $\mathbf{f}_1 = \text{ReLU}(\mathbf{W}_1^{(0)} \gamma_L(\mathbf{x}) + \mathbf{b}_1)$, where $\mathbf{W}_1^{(0)}$ contains weights $\mathbf{w}_1^{j0}$.
3.  **Iterate Layers:** For $i = 2$ to $L_{layers}$:
    a. Concatenate $\gamma_L(\mathbf{x})$ and $\mathbf{f}_{i-1}$.
    b. Compute linear transformation: $\mathbf{z}_i = \mathbf{W}_i^{(0)} \gamma_L(\mathbf{x}) + \mathbf{W}_i^{(1)} \mathbf{f}_{i-1} + \mathbf{b}_i$.
       Here $\mathbf{W}_i^{(0)}$ maps $\gamma_L(\mathbf{x})$ to the hidden dimension, and $\mathbf{W}_i^{(1)}$ maps $\mathbf{f}_{i-1}$ to the hidden dimension.
    c. Apply activation: $\mathbf{f}_i = \text{ReLU}(\mathbf{z}_i)$.
4.  **Output Prediction:**
    a. Compute density: $\sigma = \text{Linear}(\mathbf{f}_{L_{layers}})$ (or a separate head).
    b. Compute color: $\mathbf{c} = \text{Linear}(\mathbf{f}_{L_{layers}})$ (or a separate head).
    *Note: The sources mention modeling colors and volume density separately to reduce artifacts, but the core mi-MLP definition focuses on the per-layer input incorporation [S1].*

**Pseudocode:**
```python
import torch
import torch.nn as nn
import math

class PositionalEncoding(nn.Module):
    def __init__(self, num_frequencies):
        super().__init__()
        self.num_frequencies = num_frequencies

    def forward(self, x):
        # x shape: (..., 5)
        # frequencies: 2^0, ..., 2^(L-1)
        frequencies = torch.tensor([2**i for i in range(self.num_frequencies)], dtype=x.dtype, device=x.device)
        # Expand dimensions for broadcasting
        # x: (..., 5) -> (..., 1, 5)
        # frequencies: (num_frequencies,) -> (num_frequencies, 1, 1)
        scaled_x = x.unsqueeze(-2) * frequencies.unsqueeze(-1)
        # sin and cos
        sin_vals = torch.sin(scaled_x)
        cos_vals = torch.cos(scaled_x)
        # Concatenate along the last dimension
        # Result shape: (..., num_frequencies * 2 * 5)
        return torch.cat([sin_vals, cos_vals], dim=-1)

class MiMLP(nn.Module):
    def __init__(self, num_frequencies, hidden_dim, num_layers):
        super().__init__()
        self.num_frequencies = num_frequencies
        self.hidden_dim = hidden_dim
        self.num_layers = num_layers
        
        # Input dimension after positional encoding
        # 5 input dims * 2 (sin/cos) * num_frequencies
        self.input_dim = 5 * 2 * num_frequencies
        
        self.pos_enc = PositionalEncoding(num_frequencies)
        
        # Layer 1: Takes only encoded input
        self.layer1 = nn.Linear(self.input_dim, hidden_dim)
        
        # Layers 2 to N: Take encoded input AND previous layer output
        # Input to these layers is: hidden_dim (from prev) + input_dim (from pos_enc)
        self.layers = nn.ModuleList([
            nn.Linear(hidden_dim + self.input_dim, hidden_dim) 
            for _ in range(num_layers - 1)
        ])
        
        # Output heads
        self.sigma_head = nn.Linear(hidden_dim, 1)
        self.color_head = nn.Linear(hidden_dim, 3)
        
        # Initialize weights using default PyTorch initialization
        # The sources state default initialization satisfies ||w_j1||_1 in (0, 1]
        
    def forward(self, x):
        # x: (..., 5)
        # 1. Encode input
        gamma_x = self.pos_enc(x)
        
        # 2. First layer
        f_prev = torch.relu(self.layer1(gamma_x))
        
        # 3. Subsequent layers
        for layer in self.layers:
            # Concatenate previous feature and encoded input
            # f_prev: (..., hidden_dim)
            # gamma_x: (..., input_dim)
            combined = torch.cat([f_prev, gamma_x], dim=-1)
            f_prev = torch.relu(layer(combined))
            
        # 4. Output
        sigma = self.sigma_head(f_prev)
        color = self.color_head(f_prev)
        
        return sigma, color
```

**Edge Cases and Pitfalls:**
*   **Gradient Amplitude:** During early training, vanilla MLPs result in similar gradient amplitudes for all layers. mi-MLP ensures deeper layers (close to outputs) are updated with large gradients while shallower layers have extremely small ones [S1]. This is theoretically supported by the ratio of gradient amplitudes:
    $$ \frac{\| \frac{\partial \mathcal{L}}{\partial \mathbf{w}_i} \|_1}{\| \frac{\partial \mathcal{L}}{\partial \mathbf{w}_{i-1}} \|_1} = \frac{1}{d_2} \sum_{j=1}^{d_2} \frac{\|\gamma_L(\mathbf{x})\|_1 + \|\mathbf{f}_{i-1}\|_1}{\|\sum \mathbf{w}_i^{j1}\|_1 \cdot \{\|\gamma_L(\mathbf{x})\|_1 + \|\mathbf{f}_{i-2}\|_1\}} $$
    This ratio is $\ge 1$ with high probability during early training if $\|\mathbf{w}_i^{j1}\|_1 \in (0, 1]$ and $\|\mathbf{f}_{i-1}\|_1 \approx \|\mathbf{w}_i^{j1}\|_1 \cdot \|\mathbf{f}_{i-2}\|_1$ [S1].
*   **Overfitting:** The primary motivation is to prevent overfitting in few-shot view synthesis [S1].
*   **Separate Heads:** While mi-MLP defines the layer structure, the source also proposes modeling colors and volume density separately to reduce artifacts, assuming geometry is smoother than appearance [S1].

## Operating characteristics
*   **Complexity:** The number of parameters is reduced compared to a vanilla MLP of equivalent depth and width because the input embedding is reused across layers, but the weight matrices for the previous layer's output are still required. The computational complexity per layer increases slightly due to the concatenation of the input embedding with the previous layer's output.
*   **Performance:** The method boosts PSNR from 14.73 to 24.23 on the baseline for few-shot view synthesis [S1].
*   **Strengths:** Alleviates overfitting in few-shot scenarios; preserves model capacity for high-frequency details; plug-and-play solution [S1].
*   **Limitations:** May still contain noticeable artifacts without the additional proposal of modeling colors and density separately [S1].

## Background
The mi-MLP was proposed in 2024 by the authors of "Is Vanilla MLP in Neural Radiance Field Enough for Few-Shot View Synthesis?" [S1]. It addresses the overfitting issue in few-shot view synthesis by modifying the network structure to incorporate inputs into each layer.
