## Subtopics

### Adaptive Training Control
A training schedule mechanism that periodically triggers an adaptive control function based on iteration count and training views, while periodically clearing CUDA cache to manage memory [S2, unofficial]. It enables adaptive control when: iteration > control_start_base_interval * num_training_views AND iteration < stop_iteration AND iteration % (control_base_interval * num_training_views) == 0 [S2, unofficial]. If enabled, it calls `self.adaptive_control_function.control()`; otherwise, it skips [S2, unofficial]. Every 1000 iterations, it executes `torch.cuda.empty_cache()` to free unused GPU memory [S2, unofficial].
