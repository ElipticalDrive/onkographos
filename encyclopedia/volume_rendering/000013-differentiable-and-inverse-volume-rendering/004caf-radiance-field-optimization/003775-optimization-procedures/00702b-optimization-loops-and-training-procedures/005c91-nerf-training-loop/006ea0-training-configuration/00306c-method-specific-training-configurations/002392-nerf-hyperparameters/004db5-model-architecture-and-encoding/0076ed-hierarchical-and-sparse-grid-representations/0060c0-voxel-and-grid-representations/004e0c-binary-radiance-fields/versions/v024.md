# Binary Radiance Fields

Also called: BRF

## Overview
Binary Radiance Fields (BiRF) is a storage-efficient radiance field representation that constrains feature grid parameters to binary values (+1 or -1) to achieve compact storage without post-processing compression [S1]. Unlike methods that compress pre-trained models or use real-valued floating-point grids, BiRF performs binarization during training using a straight-through estimator, maintaining reconstruction quality via a 2D-3D hybrid multi-resolution architecture [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D position $\mathbf{x} \in \mathbb{R}^3$, viewing direction $\mathbf{d} \in S^2$.
*   **Output:** Volume density $\sigma \in \mathbb{R}$, color $\mathbf{c} \in \mathbb{R}^3$.

**Data Structures:**
The model consists of four multi-resolution feature grids implemented using hash encoding [S1]:
1.  One 3D voxel grid $\Phi_{\theta_{xyz}}$ with $L$ levels.
2.  Three 2D plane grids $\Phi_{\theta_{xy}}, \Phi_{\theta_{xz}}, \Phi_{\theta_{yz}}$ with $M$ levels each [S1].
*   **Hash Encoding:** All grids use hash encoding [S1].
*   **Resolution Levels:**
    *   3D Grid: $L$ levels, resolutions from 16 to 1024 [S1].
    *   2D Grids: $M$ levels, resolutions from 64 to 512 [S1].
*   **Feature Vectors:**
    *   3D Grid: Maximum $T_{3D}$ feature vectors per level [S1].
    *   2D Grids: Maximum $T_{2D}$ feature vectors per level [S1].
*   **Feature Dimension:** $F$ features per level. Variants use $F \in \{2, 4, 8\}$ [S1].
*   **Parameter Storage:** Parameters are binary ($\pm 1$), stored as 1-bit values [S1].

**Parameters:**
*   $\lambda_{\text{sparsity}}$: Sparsity loss weight. Value: $2.0 \times 10^{-5}$ [S1].
*   Model Sizes:
    *   Small (Ours-S): $\log_2(T_{3D}) = 17$, $\log_2(T_{2D}) = 15$ [S1].
    *   Base (Ours-B): $\log_2(T_{3D}) = 19$, $\log_2(T_{2D}) = 17$ [S1].
*   MLPs: 128-channel hidden layers, ReLU activation [S1].
    *   Density MLP: 1 hidden layer [S1].
    *   Color MLP: 2 hidden layers [S1].
*   Directional Encoding: Spherical harmonics basis functions [S1].
*   Optimizer: Adam, initial learning rate 0.01, decayed by 0.33 at 15K and 18K iterations [S1].
*   Warm-up: First 1K iterations [S1].

**Steps:**

1.  **Binarization:** Transform real-valued grid parameters $\theta$ to binary $\theta'$ using the sign function:
    $$ \theta' = \text{sign}(\theta) = \begin{cases} +1 & \text{if } \theta \ge 0 \\ -1 & \text{otherwise} \end{cases} $$
    Gradients are propagated using the Straight-Through Estimator (STE):
    $$ \frac{\partial L}{\partial \theta} = \frac{\partial L}{\partial \theta'} \cdot \mathbb{I}(|\theta| \le 1) $$
    This constrains values to $\{-1, 1\}$ and prevents scale divergence [S1].

2.  **Feature Extraction (3D):** For input coordinate $\mathbf{x}$, compute features from the 3D grid by tri-linearly interpolating binary parameters across $L$ resolution levels and concatenating them:
    $$ \mathbf{f}_{xyz} = \left\{ \text{interp}(\mathbf{x}, \text{sign}(\Phi^l_{\theta_{xyz}})) \right\}_{l=1}^L $$
    where $\text{interp}$ denotes tri-linear interpolation [S1].

3.  **Feature Extraction (2D):** Project $\mathbf{x}=(x,y,z)$ to 2D coordinates: $\mathbf{x}_{xy}=(x,y)$, $\mathbf{x}_{xz}=(x,z)$, $\mathbf{x}_{yz}=(y,z)$. For each axis, bi-linearly interpolate binary parameters across $M$ resolution levels and concatenate:
    $$ \mathbf{f}_{xy} = \left\{ \text{interp}(\mathbf{x}_{xy}, \text{sign}(\Phi^m_{\theta_{xy}})) \right\}_{m=1}^M $$
    Repeat for $\mathbf{f}_{xz}$ and $\mathbf{f}_{yz}$ [S1].

4.  **Feature Concatenation:** Combine all encoded features:
    $$ \mathbf{f} = \{ \mathbf{f}_{xyz}, \mathbf{f}_{xy}, \mathbf{f}_{xz}, \mathbf{f}_{yz} \} $$
    [S1].

5.  **Positional Encoding:** Apply sinusoidal positional encoding $\gamma(\mathbf{x})$ to the input 3D coordinate [S1].

6.  **Density Prediction:** Feed $\gamma(\mathbf{x})$ and $\mathbf{f}$ into the density MLP:
    $$ (\sigma, \mathbf{e}) = \text{MLP}_{\text{density}}(\gamma(\mathbf{x}), \mathbf{f}) $$
    where $\sigma$ is density and $\mathbf{e}$ is the embedded feature [S1].

7.  **Color Prediction:** Feed $\mathbf{e}$ and directional encoding $\mathbf{d}$ (spherical harmonics) into the color MLP:
    $$ \mathbf{c} = \text{MLP}_{\text{color}}(\mathbf{e}, \mathbf{d}) $$
    [S1].

8.  **Rendering:** Compute pixel color $\hat{C}(\mathbf{r})$ using volumetric rendering:
    $$ \hat{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i $$
    where $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$, $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$, and $\delta_i$ is the distance between samples [S1].

9.  **Loss Calculation:**
    *   Reconstruction Loss: $L_{\text{recon}} = \sum_{\mathbf{r} \in \mathcal{R}} ||\hat{C}(\mathbf{r}) - C(\mathbf{r})||_2^2$ [S1].
    *   Sparsity Loss: $L_{\text{sparsity}} = \sum_{i,k} \log(1 + 2\sigma(\mathbf{r}_i(t_k))^2)$ using Cauchy loss [S1].
    *   Total Loss: $L = L_{\text{recon}} + \lambda_{\text{sparsity}} L_{\text{sparsity}}$ [S1].

## Operating characteristics
*   **Storage:** Extremely compact. Ours-S2 requires < 0.5 MB, outperforming TensoRF-CP (3.7 MB) and Instant-NGP (24.5 MB) on the mic scene [S1].
*   **Performance:** PSNR of 32.03 dB on Synthetic-NeRF, 34.48 dB on Synthetic-NSVF, and 28.20 dB on Tanks and Temples [S1].
*   **Training Time:** Approximately 6, 9, and 14 minutes for Synthetic-NeRF scenes for Ours-B2 to Ours-B8 models on a single NVIDIA RTX A6000 [S1].
*   **Strengths:** Storage efficiency without post-optimization; superior reconstruction quality compared to prior efficient methods with smaller storage [S1].
*   **Limitations:** Hash collisions in 3D grids at higher resolutions (mitigated by 2D grids) [S1]. Gradient vanishing due to sign function (mitigated by STE) [S1].
*   **When to use:** Static scene reconstruction where storage is a bottleneck [S1].
*   **When not to use:** Dynamic scenes or scenarios requiring post-training compression [S1].

## Background
Binary Radiance Fields were proposed by Seungjoo Shin and Jaesik Park from POSTECH and Seoul National University, published in arXiv:2306.07581v2 on December 4, 2023 [S1]. The method builds on Instant-NGP and NerfAcc, optimizing for 20K iterations on an NVIDIA RTX A6000 [S1]. It addresses the storage bottleneck of neural radiance fields by replacing real-valued parameters with binary ones during training [S1].
