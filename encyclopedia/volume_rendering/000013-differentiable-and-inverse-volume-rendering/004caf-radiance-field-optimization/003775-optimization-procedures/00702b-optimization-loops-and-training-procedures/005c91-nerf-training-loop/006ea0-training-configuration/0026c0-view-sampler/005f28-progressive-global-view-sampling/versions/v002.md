# Progressive Global View Sampling

Also called: Moving beta distribution, Probabilistic Gradient Vector Sampling

## Overview
Progressive Global View Sampling (PGVS) is a camera view sampling strategy for 3D object reconstruction that progressively shifts the sampling distribution from in-boundary (IB) concentration to a uniform distribution over training iterations using a Beta distribution [S1, unofficial]. It sets itself apart from static view samplers by dynamically adjusting the probability density of camera angles to prioritize frontal views early in training and back views later, ensuring comprehensive coverage without requiring pre-defined view lists [S1, unofficial]. It builds on [View Sampler](3864-view-sampler.md) and differs from [Diverse View Selection via Overlap and Distance](10788-diverse-view-selection-via-overlap-and-distance.md) and [Sparse View Sampling Strategy](15397-sparse-view-sampling-strategy.md) by using a parametric decay schedule rather than geometric overlap or sparsity metrics.

## How it works
**Inputs and Outputs**
*   **Inputs:** Initial Beta distribution parameters $\alpha_0, \beta_0$; total training iterations $T$; current iteration $t$; range of camera angles $\text{range}(\theta, \phi)$; set of pre-rendered positions $\mathcal{P}$; in-boundary region definition [S1, unofficial].
*   **Outputs:** Sampled camera angles $(\theta, \phi)$; selected camera position from $\mathcal{P}$ or a new random position [S1, unofficial].

**Data Structures**
*   **Beta Distribution Parameters:** Two floating-point values $\alpha(t)$ and $\beta(t)$ representing the shape parameters of the Beta distribution at iteration $t$ [S1, unofficial].
*   **Pre-rendered Positions:** A list or set of 3D coordinates $\mathcal{P} = \{p_1, p_2, ..., p_n\}$ corresponding to previously rendered views [S1, unofficial].

**Formulas**
The decay of the Beta distribution parameters is linear with respect to a normalized time factor $u_0 t$:
$$ \alpha(t) = \alpha_0 + (1 - \alpha_0)u_0 t $$
$$ \beta(t) = \beta_0 + (1 - \beta_0)u_0 t $$
where $t$ is the current iteration step and $u_0$ is a scaling factor [S1, unofficial].

The **uniform point** $t_u$ is defined as the iteration where both $\alpha(t)$ and $\beta(t)$ decay to 1 [S1, unofficial]. Solving the decay formula for $\alpha(t_u) = 1$ yields $t_u = 1 / u_0$ [S1, unofficial]. At this point, the Beta distribution becomes uniform [S1, unofficial].

For iterations $t < t_u$, camera angles $\theta, \phi$ are sampled from the corresponding Probability Density Function (PDF) $f(x; t)$ using inverse transform sampling:
$$ \theta, \phi = \left( \int f(x; t)dx \right)^{-1} (U_{\theta,\phi}(0, 1)) \cdot \text{range}(\theta, \phi) $$
where $U_{\theta,\phi}(0, 1)$ is a uniform random variable in $[0, 1]$ [S1, unofficial].

**Steps**
1.  **Initialize:** Set initial parameters $\alpha_0, \beta_0$ [S1, unofficial].
2.  **Determine Uniform Point:** Calculate $t_u$ where $\alpha(t_u) = 1$ and $\beta(t_u) = 1$ [S1, unofficial].
3.  **Check Iteration:** If current iteration $t \ge t_u$, proceed to Step 5. Otherwise, proceed to Step 4.
4.  **Progressive Sampling:** Calculate current $\alpha(t)$ and $\beta(t)$ using the decay formulas [S1, unofficial]. Sample raw angles from the Beta distribution defined by $\alpha(t)$ and $\beta(t)$ [S1, unofficial]. Map these angles to the desired range $\text{range}(\theta, \phi)$ using the inverse CDF method described in the formula [S1, unofficial]. In the initial phase, this concentrates samples in the frontal part; as $t$ increases, samples shift toward the back part [S1, unofficial].
5.  **Uniform Sampling:** If $t \ge t_u$, sample $\theta, \phi$ uniformly from $\text{range}(\theta, \phi)$ [S1, unofficial].
6.  **Boundary Handling:** Check if the sampled camera position lies within the in-boundary (IB) region [S1, unofficial]. If yes, select the nearest pre-rendered position from $\mathcal{P}$ to avoid unnecessary computational burden [S1, unofficial]. If no, use the newly sampled position [S1, unofficial].

**Pseudocode**
```python
import math
import random

def progressive_global_view_sampling(t, alpha_0, beta_0, u_0, range_theta, range_phi, pre_rendered_positions, is_in_boundary):
    # Calculate current Beta distribution parameters
    alpha_t = alpha_0 + (1 - alpha_0) * u_0 * t
    beta_t = beta_0 + (1 - beta_0) * u_0 * t

    # Uniform point t_u occurs when alpha(t_u) = 1 and beta(t_u) = 1
    # Solving the decay formula gives t_u = 1 / u_0
    if t >= 1.0 / u_0:
        # Uniform sampling after the uniform point
        u_theta = random.uniform(0, 1)
        u_phi = random.uniform(0, 1)
        theta = u_theta * (range_theta[1] - range_theta[0]) + range_theta[0]
        phi = u_phi * (range_phi[1] - range_phi[0]) + range_phi[0]
    else:
        # Progressive sampling before the uniform point
        u_theta = random.uniform(0, 1)
        u_phi = random.uniform(0, 1)
        # Inverse CDF sampling scaled to the desired range
        theta = inverse_beta_cdf(u_theta, alpha_t, beta_t) * (range_theta[1] - range_theta[0]) + range_theta[0]
        phi = inverse_beta_cdf(u_phi, alpha_t, beta_t) * (range_phi[1] - range_phi[0]) + range_phi[0]

    # Convert angles to a 3D direction vector (unit radius)
    sampled_pos = (math.sin(phi) * math.cos(theta), math.sin(phi) * math.sin(theta), math.cos(phi))

    # Boundary handling: if sampled position lies within the in-boundary region,
    # select the nearest pre-rendered position to avoid unnecessary computational burden
    if is_in_boundary(sampled_pos):
        nearest_pos = pre_rendered_positions[0]
        min_dist = float('inf')
        for p in pre_rendered_positions:
            dist = math.sqrt(sum((a - b) ** 2 for a, b in zip(sampled_pos, p)))
            if dist < min_dist:
                min_dist = dist
                nearest_pos = p
        return nearest_pos
    else:
        return sampled_pos
```

**Parameters**
*   $\alpha_0, \beta_0$: Initial shape parameters. Typical values are not explicitly given in the sources [S1, unofficial].
*   $u_0$: Scaling factor for time. Not given in the sources [S1, unofficial].

**Edge Cases and Pitfalls**
*   **Precision:** If $\alpha_0$ or $\beta_0$ are close to 1, the uniform point $t_u$ is reached very early, reducing the benefit of progressive sampling [G].
*   **Degenerate Input:** If $\alpha_0 = 1$ and $\beta_0 = 1$, the distribution is uniform from the start, and no progressive sampling occurs [G].

## Subtopics

### Moving Beta Distribution
A variant where $\alpha$ and $\beta$ gradually swap to each other's initial values, shifting focus from front to back differently than standard PGVS [S1, unofficial].

### Discrete Accumulation Distribution
Used in conjunction with PGVS for optimizing camera placement, though specific details are not provided in the sources [S1, unofficial].

## Operating characteristics
*   **Strengths:** Reduces computational burden by reusing pre-rendered views in the IB region; ensures comprehensive coverage of the object by progressively shifting sampling focus [S1, unofficial].

## Background
PGVS was introduced in the DITTO-NeRF paper, which focuses on diffusion-based iterative text-to-omni-directional 3D model generation [S1, unofficial]. The method addresses the issue of extraneous points and inconsistent reconstruction by optimizing camera placement using a probabilistic gradient vector sampling approach [S1, unofficial].
