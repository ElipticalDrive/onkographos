# SCARF

Also called: Scalable Continual Learning Framework, Scalable Continual Learning Framework for Memory-efficient Multiple Neural Radiance Fields

## Overview
SCARF is a method for memory-efficient continual learning of multiple 3D scenes using a single neural network, addressing catastrophic forgetting when training on a sequence of scenes with access to only one scene at a time and training data accessible only once [S1]. It sets itself apart from siblings like [DoF-NeRF](9432-dof-nerf.md) or [NeRF-VPT](11770-nerf-vpt.md) by factorizing the NeRF MLP weights into scene-specific and cross-scene shared components generated by a hypernetwork, rather than augmenting inputs or modifying topology for single-scene enhancement [S1]. Unlike [MINE](13661-mine.md) or [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md) which focus on spatial efficiency, SCARF focuses on parameter efficiency across scene sequences [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A sequence of scenes $\{S_i\}_{i=1}^N$. For each scene $S_i$, training data consists of rays $\mathbf{r}$ with associated ground truth colors $C(\mathbf{r})$. Position $\mathbf{x}$ and viewing direction $\mathbf{d}$ are encoded using positional encoding.
*   **Outputs:** A unified model $F_\Theta$ capable of rendering any scene $S_i$ given its specific scene identifier (implicitly handled via the generated weights) and ray $\mathbf{r}$. The output is the RGB radiance $\mathbf{c}$ and volume density $\sigma$.

**Data Structures:**
1.  **Cross-Scene Weight Matrix (CSWM):** $C_{Ml} \in \mathbb{R}^{K \times c_{out}}$ for each encoder layer $l \in \{1, \dots, L\}$. Shared across all scenes.
2.  **Cross-Scene Decoder:** $D$. Shared across all scenes.
3.  **Hypernetwork:** $G_l$. Generates scene-specific weight matrices.
4.  **Scene-Specific Weight Matrix (SSWM):** $S_{Ml}^i \in \mathbb{R}^{c_{in} \times K}$ for scene $i$ at layer $l$. Generated by $G_l$.
5.  **Coefficient Matrix:** $C_{li} \in \mathbb{R}^{K \times K}$ for scene $i$ at layer $l$. Learnable per scene.
6.  **Random Noise:** $z_{il} \sim \mathcal{N}(0, 1)$. Input to $G_l$ for scene $i$ at layer $l$.
7.  **Occupancy Grid:** Explicit density grid for each learned scene to guide sampling during distillation.

**Neural Network Structure:**
The NeRF MLP is divided into an encoder and a decoder [S1]:
*   **Encoder:** 8 fully-connected layers (plus an output layer for density/feature), each with 256 channels. Input is 10-degree positional encoding of position $\mathbf{x}$. A skip connection is added at the 5th layer. Output is density $\sigma$ and a 256-dim feature vector.
*   **Decoder:** 128 channels, then 3 channels. Input is 4-degree positional encoding of viewing direction $\mathbf{d}$ concatenated with the encoder's feature vector. Output is RGB radiance $\mathbf{c}$ [S1].

**Weight Factorization:**
For an encoder layer $E_{li}$ (input dim $c_{in}$, output dim $c_{out}$) of scene $i$:
1.  The layer is factorized into a scene-specific matrix $S_{Ml}^i$ and a cross-scene matrix $C_{Ml}$:
    $$ E_{li} = S_{Ml}^i \times C_{Ml} $$
2.  The SSWM is generated by a hypernetwork $G_l$ from random noise $z_{il}$:
    $$ S_{Ml}^i = G_l(z_{il}) $$
3.  A scene-dependent linear transformation is applied to the CSWM using a learnable coefficient matrix $C_{li}$:
    $$ C_{Mli} = C_{li} \times C_{Ml} $$
4.  The final encoder layer weights are:
    $$ E_{li} = G_l(z_{il}) \times C_{Mli} $$
The decoder $D$ is global and shared across all scenes [S1].

**Continual Learning Procedure:**
When the $t$-th scene $S_t$ arrives:
1.  **Initialization:** Initialize model $M_t$ with parameters from $M_{t-1}$: shared CSWM $\{C_{Ml}\}$, shared hypernetwork $\{G_l\}$, and existing coefficient matrices $\{C_{li}\}$ and noises $\{z_{il}\}$ for $i=1 \dots t-1$.
2.  **New Parameters:** Add only new parameters for scene $t$: $L$ layers of random noise $\{z_{tl}\}$ and $L$ layers of coefficient matrices $\{C_{tl}\}$ [S1].
3.  **Uncertain Surface Radiance field Distillation (USD):** To prevent catastrophic forgetting, distill knowledge from $M_{t-1}$ to $M_t$ for all previous scenes $i=1 \dots t-1$.
    *   **Pre-extraction:** Extract an explicit density occupancy grid for each learned scene. Resolution is $50 \times 50 \times 50$. Divide each cell into a $5 \times 5 \times 5$ subgrid. A cell is considered "surface" if any subgrid point has density $\sigma > \tau$ (where $\tau=3$). Only sample radiance field points on these surfaces for distillation to avoid blank regions [S1].
    *   **Loss Functions:**
        *   Density-Radiance Distillation Loss ($L_{ic\sigma}^i$):
            $$ L_{ic\sigma}^i = ||\hat{c}_i^{M_t} - c_i^{M_{t-1}}||^2 + \alpha ||\hat{\sigma}_i^{M_t} - \sigma_i^{M_{t-1}}||^2 $$
            where $\hat{c}_i^{M_t}, \hat{\sigma}_i^{M_t}$ are sampled from $M_t$ in scene $S_i$, and $c_i^{M_{t-1}}, \sigma_i^{M_{t-1}}$ are from $M_{t-1}$ in scene $S_i$. $\alpha$ balances the terms.
        *   Rendered Pixel Distillation Loss ($L_{C(r)}^i$):
            $$ L_{C(r)}^i = ||\hat{C(r)}_i^{M_t} - C(r)_i^{M_{t-1}}||^2 $$
            where $\hat{C(r)}_i^{M_t}$ is the rendered pixel from $M_t$ in scene $S_i$, and $C(r)_i^{M_{t-1}}$ is from $M_{t-1}$ in scene $S_i$.
        *   Uncertain Loss ($L_{dis}^i$):
            $$ L_{dis}^i = \beta_1 \mathbb{I}(\sigma_i > \tau) L_{ic\sigma}^i + \beta_2 L_{C(r)}^i + \log(\beta_1) + \log(\beta_2) $$
            where $\mathbb{I}(\cdot)$ is the indicator function, $\tau$ is the density threshold, and $\beta_1, \beta_2$ are learnable self-balancing parameters [S1].
    *   **Total Loss:**
        $$ L = \sum_{i=1}^{t-1} L_{dis}^i + \gamma L_{C(r)}^t $$
        where $\gamma$ balances distillation for previous scenes and learning for the new scene $S_t$. $L_{C(r)}^t$ is the standard photometric loss for the new scene [S1].

import numpy as np

class SCARF:
    def __init__(self, num_encoder_layers=9, encoder_dim=256, decoder_dims=[128, 3], 
                 latent_dim_K=21, noise_dim_Z=256, density_threshold_tau=3):
        """
        Initialize SCARF model.
        """
        self.L = num_encoder_layers
        self.c_in = encoder_dim
        self.c_out = encoder_dim
        self.K = latent_dim_K
        self.Z = noise_dim_Z
        self.tau = density_threshold_tau
        
        # Shared parameters (Cross-Scene)
        # CSWM: L layers, shape (K, c_out)
        self.C_M = [np.random.randn(self.K, self.c_out) for _ in range(self.L)]
        # Hypernetwork G_l: Simple MLP to generate SSWM from noise
        # Input: Z, Output: c_in * K
        self.G = [self._init_hypernetwork() for _ in range(self.L)]
        # Decoder D
        self.D = self._init_decoder(decoder_dims)
        
        # Scene-specific parameters (initialized when scene arrives)
        self.scene_params = {} # Key: scene_id, Value: {C_li, z_il, occupancy_grid}

    def _init_hypernetwork(self):
        """
        Initialize a simple hypernetwork G_l.
        Input: noise (Z), Output: latent feature (Z), Resized to (c_in, K), 
        then multiplied by C_M to get final weights? 
        Note: Source says G_l outputs latent feature resized to 256x21, 
        then multiplied by C_li, then by C_M.
        Actually, source says: G_l(z_il) generates SSWM S_Mli.
        But then it says: S_Mli = G_l(z_il). And E_li = S_Mli * C_Mli.
        And C_Mli = C_li * C_Ml.
        So G_l outputs S_Mli directly? 
        Source Appendix B: "Input random noise... output a latent feature. 
        After resizing the feature to 256x21, A learnable coefficient matrix 
        is multiplied by the feature. Finally, by multiplying the cross-scene 
        share weight matrix... the parameter of fully-connected layer is generated."
        This implies G_l outputs a latent vector, which is reshaped and transformed.
        Let's follow the formula: E_li = G_l(z_il) * C_Mli.
        And C_Mli = C_li * C_Ml.
        So G_l(z_il) must produce S_Mli (c_in x K).
        """
        # Simplified Hypernetwork: Linear projection from Z to c_in*K
        # In practice, G_l is a small MLP. Here we use a linear layer for simplicity.
        return lambda z: np.dot(z, np.random.randn(self.Z, self.c_in * self.K))

    def _init_decoder(self, dims):
        """Initialize shared decoder."""
        return lambda x: np.dot(x, np.random.randn(dims[0], dims[1]))

    def generate_encoder_weights(self, scene_id, layer_idx):
        """
        Generate encoder weights for a specific scene and layer.
        """
        if scene_id not in self.scene_params:
            raise ValueError("Scene parameters not initialized.")
        
        params = self.scene_params[scene_id]
        z_il = params['z_il'][layer_idx]
        C_li = params['C_li'][layer_idx]
        
        # 1. Generate SSWM from Hypernetwork
        # G_l(z_il) -> S_Mli (c_in x K)
        S_Mli = self.G[layer_idx](z_il).reshape(self.c_in, self.K)
        
        # 2. Transform CSWM with Coefficient Matrix
        # C_Mli = C_li * C_Ml (K x K * K x c_out -> K x c_out)
        C_Ml = self.C_M[layer_idx]
        C_Mli = np.dot(C_li, C_Ml)
        
        # 3. Final Encoder Layer Weights
        # E_li = S_Mli * C_Mli (c_in x K * K x c_out -> c_in x c_out)
        E_li = np.dot(S_Mli, C_Mli)
        
        return E_li

    def forward(self, x_encoded, d_encoded, scene_id):
        """
        Forward pass for a ray.
        x_encoded: (c_in,) positional encoding of position
        d_encoded: (4,) positional encoding of direction
        scene_id: identifier for the scene
        """
        # Encoder
        h = x_encoded
        for l in range(self.L):
            E_li = self.generate_encoder_weights(scene_id, l)
            h = np.dot(h, E_li)
            if l == 4: # Skip connection at 5th layer (index 4)
                h_skip = h
            if l < 7: # First 8 layers are encoder hidden
                h = np.maximum(0, h) # ReLU
            else:
                # Last encoder layer outputs density and feature
                pass
        
        # Output density and feature vector
        # Assuming the last layer of encoder produces sigma and feature
        # The source says: "An additional layer outputs the density sigma and a 256-dimensional feature vector."
        # This implies the 9th layer (index 8) is special.
        # For simplicity, we assume the last encoder output is split.
        sigma = h[0] # Placeholder for density
        feature = h[1:] # 256-dim feature
        
        # Decoder
        # Concatenate feature with d_encoded
        decoder_input = np.concatenate([feature, d_encoded])
        rgb = self.D(decoder_input)
        
        return sigma, rgb

    def train_scene(self, scene_id, rays, gt_colors, optimizer, num_steps):
        """
        Train the model on a new scene or update for continual learning.
        """
        if scene_id not in self.scene_params:
            # Initialize new scene parameters
            self.scene_params[scene_id] = {
                'z_il': [np.random.randn(self.Z) for _ in range(self.L)],
                'C_li': [np.random.randn(self.K, self.K) for _ in range(self.L)],
                'occupancy_grid': None # To be filled by pre-extraction
            }
            
        # Pre-extract occupancy grid for this scene if new
        if self.scene_params[scene_id]['occupancy_grid'] is None:
            self.scene_params[scene_id]['occupancy_grid'] = self._extract_occupancy_grid(scene_id)
            
        for step in range(num_steps):
            # Sample rays
            batch_rays, batch_colors = self._sample_batch(rays, gt_colors)
            
            # Forward pass for new scene
            sigmas, rgbs = [], []
            for ray in batch_rays:
                sigma, rgb = self.forward(ray.x_encoded, ray.d_encoded, scene_id)
                sigmas.append(sigma)
                rgbs.append(rgb)
            
            # Loss for new scene
            loss_new = self._compute_photometric_loss(rgbs, batch_colors)
            
            # Distillation loss for previous scenes
            loss_distill = 0
            for prev_id in self.scene_params.keys():
                if prev_id == scene_id:
                    continue
                # Sample rays from previous scene using its occupancy grid
                prev_rays = self._sample_from_occupancy_grid(prev_id)
                prev_gt = self._get_gt_for_scene(prev_id, prev_rays)
                
                prev_sigmas, prev_rgbs = [], []
                for ray in prev_rays:
                    sigma, rgb = self.forward(ray.x_encoded, ray.d_encoded, prev_id)
                    prev_sigmas.append(sigma)
                    prev_rgbs.append(rgb)
                
                # Compute distillation loss
                # Note: In practice, we need to compare Mt and Mt-1 outputs.
                # Here, we assume we have access to Mt-1 outputs or re-render with old weights.
                # For implementation, we would store Mt-1 weights or re-render.
                # Simplified: Assume we have prev_sigmas_mt1, prev_rgbs_mt1
                # loss_distill += self._compute_distillation_loss(prev_sigmas, prev_rgbs, prev_sigmas_mt1, prev_rgbs_mt1)
                pass
            
            total_loss = loss_distill + loss_new
            optimizer.step(total_loss)

    def _extract_occupancy_grid(self, scene_id):
        """
        Extract explicit density occupancy grid for a scene.
        Resolution 50x50x50. Subgrid 5x5x5.
        """
        # Placeholder for grid extraction logic
        return np.zeros((50, 50, 50))

    def _compute_photometric_loss(self, rgbs, gt_colors):
        return np.mean((np.array(rgbs) - np.array(gt_colors))**2)

    def _compute_distillation_loss(self, sigmas_mt, rgbs_mt, sigmas_mt1, rgbs_mt1, alpha=1.0, beta1=1.0, beta2=1.0):
        # L_ic_sigma
        lic_sigma = np.mean((np.array(rgbs_mt) - np.array(rgbs_mt1))**2) + \
                    alpha * np.mean((np.array(sigmas_mt) - np.array(sigmas_mt1))**2)
        # L_C(r)
        lc_r = np.mean((np.array(rgbs_mt) - np.array(rgbs_mt1))**2) # Simplified, should be rendered pixels

        l_dis = beta1 * indicator * lic_sigma + beta2 * lc_r + np.log(beta1) + np.log(beta2)
        return np.mean(l_dis)

## Operating characteristics
*   **Time Complexity:** Training is approximately 1.2x slower than vanilla NeRF due to the Uncertain Surface Distillation (USD) strategy [S1]. Rendering speed is equivalent to vanilla NeRF because weights are pre-generated [S1].
*   **Memory Complexity:** Parameters depend most on the number of layers $L$ rather than the number of scenes $N$. For $N$ scenes, vanilla NeRF parameters grow linearly with $N$. SCARF achieves a 16.4% compression rate for 8 scenes and 0.03% for 50 scenes compared to vanilla NeRF [S1].
*   **Strengths:** Memory-efficient continual learning across multiple 3D scenes with vast domain gaps. No catastrophic forgetting. Orthogonal to single-scene NeRF extensions [S1].
*   **Limitations:** Requires pre-extraction of occupancy grids. Hyperparameter tuning for $\alpha, \beta_1, \beta_2, \tau, \gamma$ is required. Performance degradation is minor but present (e.g., Lego PSNR dropped by 0.31 in M3) [S1].
*   **When to use:** When learning a sequence of distinct 3D scenes with limited memory and single-pass access to training data.
*   **When not to use:** When only a single scene is needed, or when real-time weight generation during rendering is required (though pre-generation mitigates this) [S1].

## Background
SCARF (Scalable Continual Learning Framework) was proposed by Y. Wang et al. in a preprint submitted in 2024 [S1]. It addresses the problem of catastrophic forgetting in NeRF when training on a sequence of scenes. It builds on HyperNetworks [HDL16] and contrasts with methods like Progressive Volume Distillation (PVD) [FXW*23], MEIL-NeRF [CLBL22], and CL-NeRF [unofficial], which either focus on single scenes with multiple sequences or are multi-stage/overfitting [S1].
