# NeRF with Time Parameter

Also called: NeRF + time, NeRF with Time Parameter Baseline, Time-NeRF

## Overview
This method adapts the standard NeRF architecture [3065-nerf-hyperparameters.md] for dynamic scenes by treating time as an explicit input dimension, creating a 4D radiance field $f(\mathbf{x}, t)$ [14705-nerf-with-time-parameter.md]. Unlike static NeRF, it allows the network to condition density and color on temporal position, though it serves primarily as a baseline that lacks sophisticated dynamic reasoning [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 5D query vector $(\mathbf{x}, \mathbf{d}, t)$, where $\mathbf{x} \in \mathbb{R}^3$ is spatial position, $\mathbf{d} \in \mathbb{R}^3$ is viewing direction, and $t \in \mathbb{R}$ is the time coordinate.
*   **Output:** Density $\sigma$ and view-dependent color $\mathbf{c}$.

**Data Structures:**
The neural network architecture is identical to the standard NeRF MLP [3065-nerf-hyperparameters.md], but the input embedding dimension is increased to accommodate the time component.

**Steps:**
1.  **Positional Encoding of Time:** Apply the standard positional encoding function $\gamma$ to the time scalar $t$.
    $$ \gamma_t(t) = \text{PE}(t) $$
2.  **Positional Encoding of Space:** Apply the standard positional encoding function $\gamma$ to the spatial coordinates $\mathbf{x}$.
    $$ \gamma_x(\mathbf{x}) = \text{PE}(\mathbf{x}) $$
3.  **Concatenation:** Concatenate the time encoding with the spatial encoding to form the combined spatial-temporal input vector.
    $$ \mathbf{v} = [\gamma_x(\mathbf{x}); \gamma_t(t)] $$
4.  **Network Forward Pass:** Feed $\mathbf{v}$ and the direction $\mathbf{d}$ into the NeRF MLP to predict density $\sigma$ and color $\mathbf{c}$.
5.  **Rendering:** Perform volume rendering using the time-conditioned density and color along the ray $r(s)$ for the specific time $t$ of the target image.

**Parameters:**
*   **Training Configuration:** Use the configuration reported for NeRF's real forward-facing experiments [S1].
*   **Time Range:** $t$ is normalized to $[0, 1]$ or mapped to the sequence duration, though exact normalization is not specified in the source [S1].

**Edge Cases and Pitfalls:**
*   **Blurriness:** The method suffers from blurry predictions and lacks detail compared to more advanced dynamic methods [S1].
*   **Dynamic Reasoning:** It fails to reason about scene dynamics explicitly, relying solely on the network's capacity to interpolate temporal changes [S1].
*   **Ghosting:** While improved over vanilla NeRF, it may still exhibit artifacts if the temporal interpolation is insufficient for rapid motion [S1].

## Subtopics

### Temporal Compression of NeRF Models
A compression strategy for sequences of NeRF models that exploits temporal redundancy by treating the first model as a key-frame and compressing only the deltas between successive models [S2].
*   **Definition:** Exploits the insight that neighboring NeRF models share considerable similarities [S2].
*   **Training Strategy:** The first NeRF is initialized and trained from scratch. Subsequent NeRFs are initialized based on the previous frame's trained NeRF to encourage temporal redundancy and save training time [S2].
*   **Compression Step:** Calculate the delta between the current frame's NeRF weights and the previous frame's NeRF weights. Apply exponent-based quantization and Huffman coding to these deltas [S2].
*   **Restoration:** To restore a model, accumulate the decoded deltas to the reference model (the previous frame's model) [S2].

## Operating characteristics
*   **Performance:** Improves quality over vanilla NeRF on dynamic scenes but yields lower metrics (PSNR, SSIM) than methods designed specifically for dynamics like Neural Scene Graphs [S1].
*   **Limitations:** Suffers from blurry predictions and lacks the ability to reason about scene dynamics [S1].
*   **Complexity:** Computational complexity is similar to standard NeRF, as it adds only one input dimension and its positional encoding [S1].

## Background
*   **Origin:** Introduced as a baseline modification to demonstrate the limitations of simple temporal conditioning in implicit representations [S1].
*   **Context:** Standard SRNs and NeRF were designed for static scenes [S1]. Adding a time parameter was an initial attempt to adapt these methods to dynamic environments, such as those found in the KITTI dataset [S1].
*   **Evaluation:** Evaluated on KITTI scenes, showing that while time-aware NeRF recovers some changes, it is insufficient for complex dynamic scenes [S1].
