# Forward Warping for Novel View Synthesis

Also called: Canonical Field Forward Warping, Forward Flow

## Overview
Forward Warping for Novel View Synthesis is a method for rendering dynamic scenes by modeling a static scene at a canonical time step and forward warping the entire canonical field to other time steps [S1]. It addresses the many-to-one and one-to-many mapping difficulties inherent in dynamic scene reconstruction by employing differentiable forward warping with average splatting and an inpaint network [S1]. Unlike backward flow-based methods such as NDVG, this approach leverages the smooth trajectory field generated by forward warping to achieve superior performance, particularly on canonical frames [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   A set of multi-view images of a dynamic scene at various timestamps $t$.
*   Camera poses for each input image.
*   A canonical time $t_{can}$ (first frame for D-NeRF, middle frame for HyperNeRF) [S1].

**Outputs:**
*   A rendered RGB image for a target viewpoint and time $t$.
*   A set of learned voxel grids and neural networks representing the canonical radiance field, deformation trajectories, and appearance.

### Data Structures
The method relies on several voxel grids and neural networks. All voxel grids are 3D structures indexed by voxel coordinates.

1.  **Canonical Radiance Feature Grid ($V_{Rf}$):** Voxel grid containing radiance features. Feature dimension is 12 [S1].
2.  **Canonical Coordinate Grid ($V_{rCan}$):** Voxel grid containing the 3D coordinate of each voxel center [S1].
3.  **Canonical Density Grid ($V_{\sigma}^{Can}$):** Voxel grid containing canonical density values [S1].
4.  **Canonical Color Feature Grid ($V_{cf}^{Can}$):** Voxel grid containing canonical color features. Dimension is 3 or 12 depending on the training stage [S1].
5.  **Canonical Deformation Feature Grid ($V_{Df}^{Can}$):** Voxel grid containing canonical deformation features. Dimension is 0 for D-NeRF, 12 for HyperNeRF [S1].
6.  **Trajectory Grid ($V_{Tt}$):** Voxel grid containing DCT (Discrete Cosine Transform) parameters for each voxel's trajectory. The number of DCT bases is 15 for D-NeRF, 25 for HyperNeRF [S1].
7.  **Deformation Flow Grid ($V_{flow}$):** Voxel grid containing the deformation flow vector of each voxel from the canonical time to time $t$ [S1].
8.  **Warped Radiance Field ($V_{Rt}$):** The radiance field at time $t$ warped from the canonical field [S1].
9.  **Inpainted Radiance Field ($V_{Rt}^{Inp}$):** The radiance field at time $t$ after processing by the inpaint network [S1].
10. **Upsampled Radiance Field ($V_{Rt}^{Up}$):** The upsampled radiance field at time $t$ [S1].

### Neural Networks
Four networks are used:

1.  **Canonical Radiance Network ($F_{\theta_1}$):**
    *   **Structure:** 3-layer MLP, width 128, ReLU activation [S1].
    *   **Input:** Concatenation of radiance feature sampled from $V_{Rf}$ (dim 12) and embedded position (dim 33) [S1].
    *   **Output:** Density (dim 1) and color feature (dim 3 or 12) [S1].

2.  **Canonical Deformation Network ($F_{\theta_2}$):**
    *   **Structure:** 4-layer MLP, width 64 [S1].
    *   **Input:** Concatenation of deformation feature (dim 0 or 12) and embedded position (dim 33) [S1].
    *   **Output:** Trajectory parameters (DCT coefficients) [S1].

3.  **View Dependent Color Network ($F_{\theta_4}$):**
    *   **Structure:** 2-layer MLP, width 64 [S1].
    *   **Input:** Concatenation of embedded view direction (dim 27) and color feature (dim 12) [S1].
    *   **Output:** RGB color (dim 3) [S1].

4.  **Inpaint Network ($F_{\theta_3}$):**
    *   **Structure:** UNet with 4 encode layers and 3 decode layers, plus an upsample layer [S1].
    *   **Encode Layer:** Max pooling layer followed by two convolution layers.
    *   **Decode Layer:** Up-sample interpolation layer followed by two convolution layers.
    *   **Convolution Layer:** Instance norm, followed by convolution and ReLU [S1].
    *   **Input/Output:** Operates on the warped radiance field features to fill holes and refine geometry [S1].

### Positional Encoding
The spatial position $\mathbf{x}$ and view direction $\mathbf{d}$ are embedded using standard NeRF positional encoding. The dimension of the embedded position is 33, and the embedded view direction is 27 [S1].

### Forward Warping Pipeline

#### 1. Canonical Field Estimation
At the canonical time $t_{can}$, the scene is static. The Canonical Radiance Network $F_{\theta_1}$ estimates density $\sigma$ and color features from the canonical radiance features $V_{Rf}$ and voxel coordinates $V_{rCan}$. The Canonical Deformation Network $F_{\theta_2}$ estimates trajectory parameters for each voxel.

#### 2. Deformation Flow Calculation
For a target time $t$, the deformation flow $V_{flow}$ is computed by evaluating the trajectory function (defined by DCT parameters in $V_{Tt}$) at time $t$. This yields a displacement vector for each voxel in the canonical grid, representing the movement from $t_{can}$ to $t$ [S1].

#### 3. Average Splatting (Forward Warping)
The canonical radiance features $V_{Rf}$ are warped to time $t$ using average splatting. For each voxel in the target grid at time $t$, the contribution from canonical voxels is accumulated based on the deformation flow. Average splatting is used instead of softmax splatting because predicted weights for softmax splatting showed no obvious improvement and introduced unnecessary complexity [S1]. This process produces the Warped Radiance Field $V_{Rt}$ [S1].

#### 4. Inpainting
The warped field $V_{Rt}$ often contains holes or artifacts due to occlusions and many-to-one/one-to-many mappings. The Inpaint Network $F_{\theta_3}$ processes $V_{Rt}$ to produce the Inpainted Radiance Field $V_{Rt}^{Inp}$ [S1].

#### 5. Upsampling
An upsample layer refines the inpainted field to produce the final Upsampled Radiance Field $V_{Rt}^{Up}$ [S1].

#### 6. Rendering
To render a ray $\mathbf{r}$ at time $t$:
1.  Sample points along the ray.
2.  Query the Inpainted Radiance Field $V_{Rt}^{Inp}$ or Upsampled Radiance Field $V_{Rt}^{Up}$ for density and color features.
3.  Use $F_{\theta_1}$ to get density $\sigma$ and color features if not directly stored, or use the stored features.
4.  Use $F_{\theta_4}$ to compute the final RGB color $\mathbf{c}$ from the color features and view direction.
5.  Perform volume rendering using the standard accumulation equation:
    $$
    C(\mathbf{r}, t) = \int_{s_n}^{s_f} T(s, t) \sigma(\mathbf{r}(s), t) \mathbf{c}(\mathbf{r}(s), \mathbf{d}, t) ds
    $$
    where $T(s, t) = \exp\left(-\int_{s_n}^{s} \sigma(\mathbf{r}(s'), t) ds'\right)$ [S1].

### Loss Functions
The total loss is a weighted sum of several components:
$$
\mathcal{L} = \mathcal{L}_{photo} + w_1\mathcal{L}_{ptc} + w_2\mathcal{L}_{bg} + w_3\mathcal{L}_{flow} + w_4\mathcal{L}_{vdiff} + w_5\mathcal{L}_{tv}(\mathbf{V}_{\sigma}^{\text{Can}}) + w_6\mathcal{L}_{tv}(\mathbf{V}_{\text{flow}}^t) + w_7\mathcal{L}_{tv}(\mathbf{D})
$$
where $w_1..w_7$ are balancing weights [S1].

1.  **Point-wise Color Loss ($\mathcal{L}_{ptc}$):** Supervises the color of sampled points weighted by their accumulation.
    $$
    \mathcal{L}_{ptc} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Up}}(\mathbf{r}))
    $$
    where
    $$
    \mathcal{L}(\mathbf{C}(\mathbf{r})) = \frac{1}{K} \sum_{k=1}^{K} A_{\text{accum}}(k) \|\mathbf{c}(w_k) - \mathbf{C}_{\text{gt}}(\mathbf{r})\|_2^2
    $$
    and
    $$
    A_{\text{accum}}(k) = T(w_k) \, \sigma(w_k) \delta_k
    $$
    $\mathbf{C}_{\text{Inp}}$ and $\mathbf{C}_{\text{Up}}$ are colors rendered from the inpainted and upsampled fields respectively [S1].

2.  **Background Entropy Loss ($\mathcal{L}_{bg}$):** Encourages densities to concentrate on foreground or background.
    $$
    \mathcal{L}_{bg} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Up}}(\mathbf{r}))
    $$
    where
    $$
    \mathcal{L}(\mathbf{A}(\mathbf{r})) = -\frac{1}{K-1} \sum_{k=1}^{K-1} \left[ A_{\text{accum}}(k)\log(A_{\text{accum}}(k)) + (1-A_{\text{accum}}(k))\log(1-A_{\text{accum}}(k)) \right]
    $$
    [S1].

3.  **Total Variation Losses ($\mathcal{L}_{tv}$):** Applied to canonical density grid $\mathbf{V}_{\sigma}^{\text{Can}}$, flow grid $\mathbf{V}_{\text{flow}}^t$, and deformation features $\mathbf{D}$ to improve visual quality and smoothness [S1].

4.  **Flow Loss ($\mathcal{L}_{flow}$) and View Difference Loss ($\mathcal{L}_{vdiff}$):** Additional regularization terms [S1].

### Training Strategy
The method uses a coarse-to-fine training strategy [S1].

**Coarse Stage:**
*   **Voxel Number:** $6^3$ [S1].
*   **Inpaint Scale:** 1.5 [S1].
*   **Iterations:** 20,000 [S1].
*   **Inpaint Network:** Not used during coarse stage; the purpose is to learn proxy geometry [S1].
*   **Weights:** $w_1=10^{-1}, w_2=10^{-2}, w_3=10^{-5}, w_4=0, w_5=10^{-6}, w_6=10^{-3}, w_7=10^{-1}$ [S1].

**Fine Stage:**
*   **Voxel Number:** $8^3$ for D-NeRF, $7^3$ for HyperNeRF [S1].
*   **Inpaint Scale:** 2.0 [S1].
*   **Iterations:** 100,000 [S1].
*   **Weights:** $w_1=10^{-2}, w_2=10^{-3}, w_3=10^{-5}, w_4=10^{-5}, w_5=10^{-6}, w_6=10^{-3}, w_7=10^{-1}$ [S1].
*   **Progressive Training:** Start with 10 images closest to the canonical step. Add one image with the closest time step every 60 iterations [S1].

**Optimization:**
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** $10^{-1}$ for voxel grids, $10^{-3}$ for networks [S1].

import torch
import torch.nn as nn
import torch.nn.functional as F

# Standard NeRF positional encoding for position and view direction
# Assumes standard implementation with L bands
def positional_encoding(x, L):
    # x: (..., D)
    # Returns: (..., D * 2 * L)
    scales = torch.tensor([2**i for i in range(L)], dtype=x.dtype, device=x.device)
    xb = torch.reshape((x * scales).unsqueeze(-1), (*x.shape[:-1], -1))
    freq_bands = torch.cat([torch.sin(xb), torch.cos(xb)], dim=-1)
    return freq_bands

class CanonicalRadianceMLP(nn.Module):
    def __init__(self):
        super().__init__()
        # 3-layer MLP, width 128, ReLU
        self.fc1 = nn.Linear(12 + 33, 128)
        self.fc2 = nn.Linear(128, 128)
        self.fc3 = nn.Linear(128, 1 + 12) # Density (1) + Color Feature (12)
    
    def forward(self, radiance_feat, pos_embed):
        x = torch.cat([radiance_feat, pos_embed], dim=-1)
        x = F.relu(self.fc1(x))
        x = F.relu(self.fc2(x))
        out = self.fc3(x)
        density = out[..., :1]
        color_feat = out[..., 1:]
        return density, color_feat

class CanonicalDeformationMLP(nn.Module):
    def __init__(self, def_feat_dim, num_dct_bases):
        super().__init__()
        # 4-layer MLP, width 64
        self.fc1 = nn.Linear(def_feat_dim + 33, 64)
        self.fc2 = nn.Linear(64, 64)
        self.fc3 = nn.Linear(64, 64)
        self.fc4 = nn.Linear(64, 64)
        self.fc5 = nn.Linear(64, num_dct_bases) # Output DCT params
        
    def forward(self, def_feat, pos_embed):
        x = torch.cat([def_feat, pos_embed], dim=-1)
        x = F.relu(self.fc1(x))
        x = F.relu(self.fc2(x))
        x = F.relu(self.fc3(x))
        x = F.relu(self.fc4(x))
        dct_params = self.fc5(x)
        return dct_params

class ViewDependentColorMLP(nn.Module):
    def __init__(self):
        super().__init__()
        # 2-layer MLP, width 64
        self.fc1 = nn.Linear(12 + 27, 64)
        self.fc2 = nn.Linear(64, 3) # RGB
        
    def forward(self, color_feat, view_embed):
        x = torch.cat([color_feat, view_embed], dim=-1)
        x = F.relu(self.fc1(x))
        rgb = self.fc2(x)
        return rgb

class InpaintNetwork(nn.Module):
    def __init__(self):
        super().__init__()
        # UNet with 4 encode, 3 decode layers
        # Encode: MaxPool + 2 Conv (InstanceNorm + Conv + ReLU)
        # Decode: UpSample + 2 Conv (InstanceNorm + Conv + ReLU)
        # UpSample layer has same structure as decode layer
        self.encoder1 = nn.Sequential(nn.MaxPool2d(2), ConvBlock(12, 64), ConvBlock(64, 64))
        self.encoder2 = nn.Sequential(nn.MaxPool2d(2), ConvBlock(64, 128), ConvBlock(128, 128))
        self.encoder3 = nn.Sequential(nn.MaxPool2d(2), ConvBlock(128, 256), ConvBlock(256, 256))
        self.encoder4 = nn.Sequential(nn.MaxPool2d(2), ConvBlock(256, 512), ConvBlock(512, 512))
        
        self.decoder1 = nn.Sequential(UpSampleBlock(512, 256), ConvBlock(512, 256), ConvBlock(256, 256))
        self.decoder2 = nn.Sequential(UpSampleBlock(256, 128), ConvBlock(256, 128), ConvBlock(128, 128))
        self.decoder3 = nn.Sequential(UpSampleBlock(128, 64), ConvBlock(128, 64), ConvBlock(64, 64))
        
        self.upsample = nn.Sequential(UpSampleBlock(64, 32), ConvBlock(64, 32), ConvBlock(32, 32))
        self.final_conv = nn.Conv2d(32, 12, 1) # Output feature dim 12

    def forward(self, x):
        # x: (B, 12, H, W)
        e1 = self.encoder1(x)
        e2 = self.encoder2(e1)
        e3 = self.encoder3(e2)
        e4 = self.encoder4(e3)
        
        d1 = self.decoder1(e4, e3)
        d2 = self.decoder2(d1, e2)
        d3 = self.decoder3(d2, e1)
        
        up = self.upsample(d3)
        out = self.final_conv(up)
        return out

class ConvBlock(nn.Module):
    def __init__(self, in_ch, out_ch):
        super().__init__()
        self.conv1 = nn.Conv2d(in_ch, out_ch, 3, padding=1)
        self.norm1 = nn.InstanceNorm2d(out_ch)
        self.conv2 = nn.Conv2d(out_ch, out_ch, 3, padding=1)
        self.norm2 = nn.InstanceNorm2d(out_ch)
        
    def forward(self, x):
        x = F.relu(self.norm1(self.conv1(x)))
        x = F.relu(self.norm2(self.conv2(x)))
        return x

class UpSampleBlock(nn.Module):
    def __init__(self, in_ch, out_ch):
        super().__init__()
        self.up = nn.Upsample(scale_factor=2, mode='bilinear', align_corners=True)
        self.conv1 = nn.Conv2d(in_ch, out_ch, 3, padding=1)
        self.norm1 = nn.InstanceNorm2d(out_ch)
        self.conv2 = nn.Conv2d(out_ch, out_ch, 3, padding=1)
        self.norm2 = nn.InstanceNorm2d(out_ch)
        
    def forward(self, x):
        x = self.up(x)
        x = F.relu(self.norm1(self.conv1(x)))
        x = F.relu(self.norm2(self.conv2(x)))
        return x

def compute_ptc_loss(rendered_color, gt_color, accumulation_weights):
    # L_ptc = mean( accumulation_weights * ||rendered_color - gt_color||^2 )
    loss = torch.mean(accumulation_weights * (rendered_color - gt_color)**2)

    # L_bg = -mean( A*log(A) + (1-A)*log(1-A) )
    # Avoid log(0)
    eps = 1e-7
    A = torch.clamp(accumulation_weights, eps, 1-eps)
    loss = -torch.mean(A * torch.log(A) + (1-A) * torch.log(1-A))

### Edge Cases and Pitfalls
*   **Memory Consumption:** The method is memory-intensive, especially for real scenes, due to the multiple voxel grids and large model size (260M-440M parameters) [S1].
*   **Training Speed:** Training is slow, taking approximately one day per scene on an RTX 3090 [S1].
*   **Coarse Stage Necessity:** Removing the coarse stage causes significant performance drops because the voxel grid covers a larger space without proxy geometry filtering [S1].
*   **Inpaint Network Importance:** The inpaint network is critical; ablation shows significant PSNR drops (e.g., from 27.71 to 27.15 on Hell Warrior) without it [S1].
*   **Canonical Time Selection:** Setting the canonical time to the middle frame can improve performance for datasets like HyperNeRF, as the geometry is closer to other time steps [S1].

## Operating characteristics

*   **Time Complexity:** Training is slow, taking ~1 day per scene [S1]. Rendering is also slow, taking 7s per image for D-NeRF and 15s per image for HyperNeRF [S1].
*   **Memory Complexity:** High memory consumption due to multiple voxel grids and large neural networks (260M-440M parameters) [S1].
*   **Performance:** Achieves SOTA performance on public datasets (D-NeRF, HyperNeRF) and a new Lego Complete Dataset, especially for canonical frames [S1]. Outperforms backward flow-based methods like NDVG [S1].
*   **Strengths:** Handles many-to-one and one-to-many mappings effectively via forward warping and inpainting. Smooth trajectory field allows for better generalization.
*   **Limitations:** High memory usage and slow training/rendering speeds.
*   **When to Use:** When high-quality novel view synthesis for dynamic scenes is required, and computational resources are sufficient. Particularly effective for canonical frames.
*   **When Not to Use:** When real-time rendering or low-memory constraints are critical.

## Background

*   **Origin:** Proposed in "Forward Flow for Novel View Synthesis of Dynamic Scenes" [S1].
*   **History:** The method builds on canonical-based representations for dynamic scenes. It addresses limitations of backward flow methods by using forward warping, which provides a smoother trajectory field [S1].
*   **Usage:** Used for novel view synthesis of dynamic scenes, evaluated on D-NeRF, HyperNeRF, and a custom Lego Complete Dataset [S1].
