# Forward Warping for Novel View Synthesis

Also called: Canonical Field Forward Warping, Forward Flow

## Overview
Forward Warping for Novel View Synthesis is a method for rendering dynamic scenes by modeling a static "canonical" radiance field and differentially warping this field to target time steps [S1]. It solves the many-to-one and one-to-many mapping ambiguities inherent in dynamic scene reconstruction by using average splatting for forward warping and an inpaint network to fill occluded regions [S1]. Unlike backward-flow methods such as NDVG, this approach achieves superior performance, particularly for canonical frames, by explicitly learning a deformation flow from a static reference [S1].

## How it works

### Inputs and Outputs
*   **Inputs:** A set of multi-view images of a dynamic scene at various time steps $t$. Camera poses and intrinsics are required.
*   **Outputs:** A rendered RGB image for any arbitrary view and time step $t$.

### Data Structures
The method relies on several voxel grids and neural networks. All voxel grids are 3D structures indexed by spatial coordinates.

1.  **Canonical Radiance Feature Grid ($V_{Rf}$):** Stores radiance features. Dimension: 12 [S1].
2.  **Canonical Coordinate Grid ($V_{rCan}$):** Stores the 3D coordinate of each voxel center [S1].
3.  **Canonical Density Grid ($V_{\sigma}^{Can}$):** Stores the density ($\sigma$) of each voxel in the canonical space [S1].
4.  **Canonical Color Feature Grid ($V_{cf}^{Can}$):** Stores color features. Dimension: 3 or 12, depending on the training stage [S1].
5.  **Canonical Deformation Feature Grid ($V_{Df}^{Can}$):** Stores deformation features. Dimension: 0 for D-NeRF dataset, 12 for HyperNeRF dataset [S1].
6.  **Trajectory Grid ($V_{T}^{t}$):** Stores the DCT (Discrete Cosine Transform) parameters for the trajectory of each voxel [S1].
7.  **Deformation Flow Grid ($V_{flow}$):** Stores the deformation flow vector for each voxel, representing the displacement from the canonical position to the position at time $t$ [S1].
8.  **Warped Radiance Field ($V_{R}^{t}$):** The radiance field at time $t$, obtained by warping $V_{Rf}$ using the deformation flow [S1].
9.  **Inpainted Radiance Field ($V_{R}^{t \text{ Inp}}$):** The radiance field after applying the inpaint network to $V_{R}^{t}$ [S1].
10. **Upsampled Radiance Field ($V_{R}^{t \text{ Up}}$):** The radiance field after upsampling $V_{R}^{t \text{ Inp}}$ [S1].

### Neural Networks

1.  **Canonical Radiance Network ($F_{\theta_1}$):**
    *   **Structure:** 3-layer MLP, width 128, ReLU activation [S1].
    *   **Input:** Concatenation of radiance feature sampled from $V_{Rf}$ (dim 12) and embedded position (dim 33) [S1].
    *   **Output:** Density (dim 1) and color feature (dim 3 or 12) [S1].

2.  **Canonical Deformation Network ($F_{\theta_2}$):**
    *   **Structure:** 4-layer MLP, width 64 [S1].
    *   **Input:** Concatenation of deformation feature (dim 0 for D-NeRF, 12 for HyperNeRF) and embedded position (dim 33) [S1].
    *   **Output:** Trajectory parameters (DCT coefficients) [S1].

3.  **View Dependent Color Network ($F_{\theta_4}$):**
    *   **Structure:** 2-layer MLP, width 64 [S1].
    *   **Input:** Concatenation of embedded view direction (dim 27) and color feature (dim 12) [S1].
    *   **Output:** RGB color (dim 3) [S1].

4.  **Inpaint Network ($F_{\theta_3}$):**
    *   **Structure:** UNet with 4 encode layers and 3 decode layers, followed by an upsample layer [S1].
    *   **Encode Layer:** Max pooling + two convolution layers.
    *   **Decode Layer:** Up-sample interpolation + two convolution layers.
    *   **Convolution Layer:** Instance norm + Convolution + ReLU [S1].
    *   **Input:** Warped radiance field features [S1].
    *   **Output:** Inpainted radiance field features [S1].

### Algorithm Steps

1.  **Canonical Field Initialization:**
    Initialize voxel grids $V_{Rf}$, $V_{rCan}$, $V_{\sigma}^{Can}$, $V_{cf}^{Can}$, and $V_{Df}^{Can}$ [S1]. The canonical time is set to the first frame for D-NeRF and the middle frame for HyperNeRF [S1].

2.  **Deformation Flow Estimation:**
    For a query point $\mathbf{x}$ in canonical space and time $t$:
    a. Sample deformation feature from $V_{Df}^{Can}$ at $\mathbf{x}$ [S1].
    b. Pass feature and embedded position through $F_{\theta_2}$ to get DCT coefficients [S1].
    c. Compute the trajectory of $\mathbf{x}$ at time $t$ using the DCT basis functions [S1].
    d. Calculate the deformation flow $\mathbf{d} = \mathbf{x}_t - \mathbf{x}$, where $\mathbf{x}_t$ is the position at time $t$ [S1].
    e. Store $\mathbf{d}$ in $V_{flow}$ at $\mathbf{x}$ [S1].

3.  **Forward Warping (Average Splatting):**
    To warp the canonical field to time $t$:
    a. For each voxel $\mathbf{x}$ in the canonical grid, compute its warped position $\mathbf{x}_t = \mathbf{x} + \mathbf{d}(\mathbf{x}, t)$ [S1].
    b. Splat the radiance features from $V_{Rf}$ at $\mathbf{x}$ to the target grid location $\mathbf{x}_t$ [S1].
    c. Use **average splatting**: accumulate features by summing and dividing by the count of contributing voxels, rather than softmax splatting [S1].
    d. The result is the Warped Radiance Field $V_{R}^{t}$ [S1].

4.  **Inpainting:**
    Pass $V_{R}^{t}$ through the Inpaint Network $F_{\theta_3}$ to produce $V_{R}^{t \text{ Inp}}$, filling holes caused by occlusions or non-rigid motion [S1].

5.  **Upsampling:**
    Upsample $V_{R}^{t \text{ Inp}}$ to produce $V_{R}^{t \text{ Up}}$ [S1].

6.  **Volume Rendering:**
    For a ray $\mathbf{r}$:
    a. Sample points $w_k$ along the ray in the canonical space [S1].
    b. Query density $\sigma$ and color feature from $V_{\sigma}^{Can}$ and $V_{cf}^{Can}$ at $w_k$ using $F_{\theta_1}$ [S1].
    c. Compute accumulated opacity $A_{\text{accum}}(k) = T(w_k) \sigma(w_k) \delta_k$, where $T(w_k)$ is the transmittance and $\delta_k$ is the distance between samples [S1].
    d. Render color $\mathbf{C}(\mathbf{r})$ using $F_{\theta_4}$ with the color feature and view direction [S1].
    e. Render colors $\mathbf{C}_{\text{Inp}}(\mathbf{r})$ from $V_{R}^{t \text{ Inp}}$ and $\mathbf{C}_{\text{Up}}(\mathbf{r})$ from $V_{R}^{t \text{ Up}}$ [S1].

7.  **Loss Computation:**
    Compute the total loss $\mathcal{L}$ (see Formulas below) and update parameters using Adam optimizer [S1].

### Formulas

**Point-wise Color Loss ($\mathcal{L}_{ptc}$):**
Supervises the color of sampled points weighted by their accumulation [S1].
$$
\mathcal{L}_{ptc} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Up}}(\mathbf{r}))
$$
where
$$
\mathcal{L}(\mathbf{C}(\mathbf{r})) = \frac{1}{K} \sum_{k=1}^{K} A_{\text{accum}}(k) \|\mathbf{c}(w_k) - \mathbf{C}_{\text{gt}}(\mathbf{r})\|_2^2
$$
and
$$
A_{\text{accum}}(k) = T(w_k) \, \sigma(w_k) \delta_k
$$
$\mathbf{C}_{\text{Inp}}$ and $\mathbf{C}_{\text{Up}}$ are colors from inpainted and upsampled fields, respectively [S1].

**Background Entropy Loss ($\mathcal{L}_{bg}$):**
Encourages densities to concentrate on foreground or background [S1].
$$
\mathcal{L}_{bg} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Up}}(\mathbf{r}))
$$
where
$$
\mathcal{L}(\mathbf{A}(\mathbf{r})) = -\frac{1}{K-1} \sum_{k=1}^{K-1} \left[ A_{\text{accum}}(k)\log(A_{\text{accum}}(k)) + (1-A_{\text{accum}}(k))\log(1-A_{\text{accum}}(k)) \right]
$$
[ S1 ]

**Total Loss:**
$$
\mathcal{L} = \mathcal{L}_{photo} + w_1\mathcal{L}_{ptc} + w_2\mathcal{L}_{bg} + w_3\mathcal{L}_{flow} + w_4\mathcal{L}_{vdiff} + w_5\mathcal{L}_{tv}(\mathbf{V}_{\sigma}^{\text{Can}}) + w_6\mathcal{L}_{tv}(\mathbf{V}_{\text{flow}}^t) + w_7\mathcal{L}_{tv}(\mathbf{D})
$$
$\mathcal{L}_{tv}$ denotes Total Variation loss. $\mathbf{D}$ refers to the deformation feature grid or similar regularized field [S1]. $w_1..w_7$ are balancing weights [S1].

### Parameters

**Coarse Stage:**
*   **Voxel Number:** $6^3$ [S1].
*   **Inpaint Scale:** 1.5 [S1].
*   **Iterations:** 20,000 [S1].
*   **Weights:** $w_1=10^{-1}, w_2=10^{-2}, w_3=10^{-5}, w_4=0, w_5=10^{-6}, w_6=10^{-3}, w_7=10^{-1}$ [S1].
*   **Note:** Inpaint network is **not** used during the coarse stage [S1].

**Fine Stage:**
*   **Voxel Number:** $8^3$ for D-NeRF, $7^3$ for HyperNeRF [S1].
*   **Inpaint Scale:** 2.0 [S1].
*   **Iterations:** 100,000 [S1].
*   **Weights:** $w_1=10^{-2}, w_2=10^{-3}, w_3=10^{-5}, w_4=10^{-5}, w_5=10^{-6}, w_6=10^{-3}, w_7=10^{-1}$ [S1].
*   **Progressive Training:** Start with 10 images closest to the canonical time step. Add one image with the closest time step every 60 iterations [S1].

**General:**
*   **Learning Rate:** $10^{-1}$ for voxel grids, $10^{-3}$ for networks [S1].
*   **Optimizer:** Adam [S1].

### Edge Cases and Pitfalls
*   **Memory Consumption:** High memory usage, especially for real-world scenes [S1].
*   **Training Speed:** Slow training time, approximately one day per scene on an RTX 3090 [S1].
*   **Coarse Stage Necessity:** Removing the coarse stage causes significant performance drops because the voxel grid covers a larger space without proxy geometry filtering [S1].
*   **Inpainting Importance:** Removing the inpaint network significantly reduces performance (e.g., Hell Warrior PSNR drops from 27.71 to 27.15) [S1].
*   **Canonical Time Selection:** Setting the canonical time to the middle frame improves performance for HyperNeRF as the geometry is closer to other time steps [S1].

## Operating characteristics

*   **Time Complexity:** Training is slow, taking ~1 day per scene [S1]. Rendering speed is 7s per image for D-NeRF and 15s per image for HyperNeRF [S1].
*   **Memory Complexity:** High memory consumption due to multiple voxel grids and large model sizes (260M parameters for D-NeRF, 440M for HyperNeRF) [S1].
*   **Strengths:** Achieves SOTA performance on public datasets, particularly for canonical frames. Forward warping design offers advantages over backward flow methods like NDVG [S1].
*   **Limitations:** High memory usage and slow training speed make it less suitable for real-time or resource-constrained applications [S1].
*   **When to Use:** When high-quality novel view synthesis for dynamic scenes is required, especially for canonical views, and computational resources are available.
*   **When Not to Use:** When real-time rendering or fast training is required, or when memory is severely constrained.

## Background

*   **Origin:** Proposed in the paper "Forward Flow for Novel View Synthesis of Dynamic Scenes" [S1].
*   **History:** The method builds on canonical-based representations and differentiable rendering. It addresses limitations of backward-flow methods by explicitly modeling forward deformation from a static canonical field [S1].
*   **Usage:** Applied to dynamic scene novel view synthesis on datasets like D-NeRF and HyperNeRF [S1].
