# Training Setup and Baselines

## Overview
This family defines the hyperparameter configurations, data handling protocols, and baseline architectures used to train neural radiance fields and related volume representations. It establishes the standard reference conditions (such as the NeRF-GT baseline) against which novel view synthesis methods are evaluated, ensuring that performance gains are attributable to the representation or rendering technique rather than training artifacts. It differs from sibling articles like [Learning Rate Scheduling](2701-learning-rate-scheduling.md) by focusing on the structural setup of the training loop, data inputs, and network architecture choices rather than the dynamic adjustment of optimization parameters.

## Shared principles
All methods in this family operate within the differentiable volume rendering pipeline [52-volume-rendering.md]. The core mechanism involves minimizing a photometric loss (typically Mean Squared Error) between rendered pixel colors and ground truth images via stochastic gradient descent. The training loop consists of ray generation, point sampling along rays, neural network queries to predict density and color, and differentiable volume rendering to compute pixel values.

## Subtopics

### [NeRF-GT Baseline Training Setup](11349-nerf-gt-baseline-training-setup.md)
Establishes the standard reference for training Neural Radiance Fields using calibrated LDR or HDR inputs. It differs from variants like DBARF by relying on accurate initial camera poses and standard supervised learning rather than self-supervised pose optimization. It serves as the ground-truth comparison for evaluating novel view synthesis methods. See [NeRF-GT Baseline Training Setup](11349-nerf-gt-baseline-training-setup.md).

### [StyleGAN2 Training Configuration](12972-stylegan2-training-configuration.md)
Adapts the StyleGAN2 training protocol for 3D-aware image synthesis within differentiable volume rendering frameworks like VoxGRAF. It replaces standard GAN regularization with R1 regularization and omits style-mixing to optimize for 3D consistency. It is distinct from NeRF baselines by leveraging StyleGAN2-specific dynamics (equalized learning rates, minibatch std) rather than MLP-based optimization loops. See [StyleGAN2 Training Configuration](12972-stylegan2-training-configuration.md).

### [NeRF Training Setup](13271-nerf-training-setup.md)
Defines the training configuration for NeRFs using feature volumes and accelerators like NerfAcc and Instant-NGP. It solves efficient training on static scenes by replacing standard positional encoding of 3D coordinates with sampled feature vectors from a 3D grid. It differs from standard NeRF by using a 64-dimensional feature vector as the primary spatial input, omitting positional encoding on this vector, and employing a two-stage sampling strategy. See [NeRF Training Setup](13271-nerf-training-setup.md).

### [NLR Baseline](15254-nlr-baseline.md)
Serves as a reference implementation for Neural Lumigraph Representations. It differs from siblings by utilizing a specific neural architecture designed for lumigraph-like representations, distinct from MLP-based NeRF or generative StyleGAN2 approaches. It operates within the standard differentiable volume rendering loop, minimizing photometric loss. See [NLR Baseline](15254-nlr-baseline.md).

### NeuralVDB Hyperparameter Configuration
Configures training for sparse volume representations using hierarchical neural networks. It uses a block grid or sparse VDB voxel representation to reduce noise compared to dense grids. It employs Adam optimizer with specific learning rate decay schedules and subdomain sizes to balance compute efficiency and reconstruction quality.

### Neural Codebook Training Configuration
Trains separate Neural Codebooks (NCB) for each scene to compress radiance fields. It uses Adam optimizer with weight decay and a decaying learning rate. The trained model is cast to float16 for storage and inference.

## Background
The concept of training Neural Radiance Fields (NeRF) was introduced by Mildenhall et al. in 2020 [S2]. The NeRF-GT baseline provides the standard for this method. Subsequent variations like the feature-volume based NeRF setup leverage libraries such as NerfAcc and Instant-NGP for acceleration [S2]. The StyleGAN2 configuration adapts generative adversarial networks for 3D-aware synthesis in volume rendering contexts [S1, unofficial]. NeuralVDB introduces sparse volume representations with hierarchical neural networks to handle high-resolution data efficiently [S1, unofficial]. Neural Codebooks provide a compact real-time radiance field representation [S2].
