# Forward Warping for Novel View Synthesis

Also called: Canonical Field Forward Warping, Forward Flow

## Overview
Forward Warping for Novel View Synthesis is a method for rendering dynamic scenes by modeling a static scene at a canonical time step and forward warping the entire canonical field to other time steps [S1]. It addresses the many-to-one and one-to-many mapping difficulties inherent in dynamic scene reconstruction by using differentiable forward warping with average splatting and an inpaint network [S1]. It sets itself apart from backward flow-based methods like NDVG by achieving superior performance, particularly for canonical frames, despite using similar regularization terms [S1].

## How it works
The method employs a coarse-to-fine training strategy. The core idea is to learn a canonical radiance field and a deformation field, then warp the canonical field to target time steps for rendering [S1].

### Inputs and Outputs
*   **Inputs:** A set of images $\{I_t\}$ captured at different time steps $t$, along with their camera poses.
*   **Outputs:** A rendered image $C(\mathbf{r})$ for a given ray $\mathbf{r}$ at a target time step $t$.

### Data Structures
The method relies on several voxel grids and neural networks [S1].

**Voxel Grids:**
1.  **Canonical Radiance Feature Grid ($VR_f$):** Contains radiance features. Feature dimension is 12.
2.  **Canonical Coordinate Grid ($VR_{Can}$):** Contains the coordinate of each voxel.
3.  **Canonical Density Grid ($V_{\sigma}^{Can}$):** Contains canonical density.
4.  **Canonical Color Feature Grid ($V_{cf}^{Can}$):** Contains canonical color features. Dimension is 3 or 12 depending on the training stage.
5.  **Canonical Deformation Feature Grid ($VD_f^{Can}$):** Contains canonical deformation features. Dimension is 0 for D-NeRF dataset, 12 for HyperNeRF dataset.
6.  **Trajectory Grid ($VT_t$):** Contains DCT parameters of each voxel's trajectory.
7.  **Deformation Flow Grid ($V_{flow}$):** Contains deformation flow of each voxel from canonical to time $t$.
8.  **Warped Radiance Field ($VR_t$):** Radiance field at time $t$ warped from $VR_{Can}$.
9.  **Inpainted Radiance Field ($VR_t^{Inp}$):** Radiance field at time $t$ after inpainting by $F_{\theta3}$.
10. **Upsampled Radiance Field ($VR_t^{Up}$):** Upsampled radiance field at time $t$.

**Neural Networks:**
1.  **Canonical Radiance Network ($F_{\theta1}$):**
    *   Structure: 3-layer MLP, width 128, ReLU activation.
    *   Input: Radiance feature from $VR_f$ (dim 12) and embedded position (dim 33).
    *   Output: Density (dim 1) and color feature (dim 3 or 12).
2.  **Canonical Deformation Network ($F_{\theta2}$):**
    *   Structure: 4-layer MLP, width 64.
    *   Input: Deformation feature and embedded position (dim 33).
    *   Output: Deformation parameters.
3.  **View Dependent Color Network ($F_{\theta4}$):**
    *   Structure: 2-layer MLP, width 64.
    *   Input: Embedded view direction (dim 27) and color feature (dim 12).
    *   Output: RGB color (dim 3).
4.  **Inpaint Network ($F_{\theta3}$):**
    *   Structure: UNet with 4 encode layers and 3 decode layers, plus an upsample layer.
    *   Encode layer: One max pooling layer and two convolution layers.
    *   Decode layer: One up-sample interpolation layer and two convolution layers.
    *   Convolution layers: Instance norm followed by convolution and ReLU.

### Steps

1.  **Canonical Field Initialization (Coarse Stage):**
    *   Initialize voxel grids with expected voxel number $6^3$.
    *   Train $F_{\theta1}$ and $F_{\theta2}$ to learn a proxy geometry.
    *   The inpaint network is **not** used in this stage.
    *   This stage lasts for 20,000 iterations.
    *   The purpose is to learn a bounding box/proxy geometry for the fine stage [S1].

2.  **Fine Stage Training:**
    *   Initialize voxel grids with expected voxel number $8^3$ (D-NeRF) or $7^3$ (HyperNeRF).
    *   Set inpaint network scale factor to 2.0.
    *   Train for 100,000 iterations.
    *   **Progressive Training:** Start with 10 images closest to the canonical time step. Add one image with the closest time step every 60 iterations [S1].

3.  **Forward Warping Pipeline:**
    For a target time step $t$:
    a.  **Deformation Estimation:**
        *   Sample deformation features from $VD_f^{Can}$ and coordinates from $VR_{Can}$.
        *   Pass through $F_{\theta2}$ to get deformation parameters.
        *   Compute the deformation flow $V_{flow}$ from canonical to time $t$ using DCT bases (15 for D-NeRF, 25 for HyperNeRF) [S1].
    b.  **Average Splatting:**
        *   Warp the canonical radiance features from $VR_f$ to time $t$ using the deformation flow.
        *   Use **average splatting** (not softmax splatting) to handle many-to-one and one-to-many mappings [S1].
        *   Result is the Warped Radiance Field $VR_t$.
    c.  **Inpainting:**
        *   Pass $VR_t$ through the Inpaint Network $F_{\theta3}$ to produce $VR_t^{Inp}$.
        *   This step refines the voxel grid and handles occlusions/gaps caused by forward warping [S1].
    d.  **Upsampling:**
        *   Upsample $VR_t^{Inp}$ to produce $VR_t^{Up}$.
        *   This provides a higher-resolution feature field for rendering [S1].

4.  **Volume Rendering:**
    *   For a ray $\mathbf{r}$, sample points $w_k$ along the ray in the warped fields.
    *   Compute density $\sigma(w_k)$ and color feature $c(w_k)$ using $F_{\theta1}$ and $F_{\theta4}$ [S1].
    *   Render color $C(\mathbf{r})$ using standard volume rendering equation [S1].

### Formulas

**Point-wise Color Loss ($\mathcal{L}_{ptc}$):**
Supervises the color of sampled points weighted by their accumulation.
$$
\mathcal{L}_{ptc} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Up}}(\mathbf{r}))
$$
where
$$
\mathcal{L}(\mathbf{C}(\mathbf{r})) = \frac{1}{K} \sum_{k=1}^{K} A_{\text{accum}}(k) \|\mathbf{c}(w_k) - \mathbf{C}_{\text{gt}}(\mathbf{r})\|_2^2
$$
and
$$
A_{\text{accum}}(k) = T(w_k) \, \sigma(w_k) \delta_k
$$
$\mathbf{C}_{\text{Inp}}$ and $\mathbf{C}_{\text{Up}}$ are colors from inpainted and upsampled fields. $T(w_k)$ is transmittance, $\sigma(w_k)$ is density, $\delta_k$ is distance between samples [S1].

**Background Entropy Loss ($\mathcal{L}_{bg}$):**
Encourages densities to concentrate on foreground or background.
$$
\mathcal{L}_{bg} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Up}}(\mathbf{r}))
$$
where
$$
\mathcal{L}(\mathbf{A}(\mathbf{r})) = -\frac{1}{K-1} \sum_{k=1}^{K-1} [ A_{\text{accum}}(k)\log(A_{\text{accum}}(k)) + (1-A_{\text{accum}}(k))\log(1-A_{\text{accum}}(k)) ]
$$
[ S1 ]

**Total Loss:**
$$
\mathcal{L} = \mathcal{L}_{photo} + w_1\mathcal{L}_{ptc} + w_2\mathcal{L}_{bg} + w_3\mathcal{L}_{flow} + w_4\mathcal{L}_{vdiff} + w_5\mathcal{L}_{tv}(\mathbf{V}_{\sigma}^{\text{Can}}) + w_6\mathcal{L}_{tv}(\mathbf{V}_{\text{flow}}^t) + w_7\mathcal{L}_{tv}(\mathbf{D})
$$
where $w_1..w_7$ are balancing weights [S1].

### Parameters

**Coarse Stage:**
*   Voxel Number: $6^3$ [S1]
*   Inpaint Scale: 1.5 [S1]
*   Iterations: 20,000 [S1]
*   Weights: $w_1=10^{-1}, w_2=10^{-2}, w_3=10^{-5}, w_4=0, w_5=10^{-6}, w_6=10^{-3}, w_7=10^{-1}$ [S1]

**Fine Stage:**
*   Voxel Number: $8^3$ (D-NeRF), $7^3$ (HyperNeRF) [S1]
*   Inpaint Scale: 2.0 [S1]
*   Iterations: 100,000 [S1]
*   Weights: $w_1=10^{-2}, w_2=10^{-3}, w_3=10^{-5}, w_4=10^{-5}, w_5=10^{-6}, w_6=10^{-3}, w_7=10^{-1}$ [S1]

**General:**
*   Learning Rate: $10^{-1}$ for voxel grids, $10^{-3}$ for networks [S1]
*   Canonical Time: First frame for D-NeRF, middle frame for HyperNeRF [S1]
*   Optimizer: Adam [S1]

### Edge Cases and Pitfalls
*   **Memory Consumption:** High, especially for real scenes [S1].
*   **Training Speed:** Slow, approximately one day per scene on GeForce RTX 3090 [S1].
*   **Coarse Stage Importance:** Removing the coarse stage causes significant performance drop because the voxel grid covers a bigger space without proxy geometry filtering [S1].
*   **Inpaint Network Importance:** Removing the inpaint network significantly reduces performance (e.g., Hell Warrior PSNR drops from 27.71 to 27.15) [S1].
*   **Splatting Choice:** Softmax splatting with predicted weights showed no obvious improvement and introduced too much complexity compared to average splatting [S1].

## Operating characteristics
*   **Time Complexity:** Training is slow, taking ~1 day per scene on GeForce RTX 3090 [S1].
*   **Memory Complexity:** High, especially for real scenes [S1].
*   **Model Size:** 260M parameters for D-NeRF, 440M for HyperNeRF [S1].
*   **Rendering Speed:** 7s per image for D-NeRF, 15s per image for HyperNeRF [S1].
*   **Strengths:** SOTA performance on public datasets, especially for canonical frames. Clear advantage over backward flow-based methods like NDVG [S1].
*   **Limitations:** High memory consumption, slow training speed [S1].
*   **When to Use:** When high-quality novel view synthesis for dynamic scenes is required, and computational resources are sufficient.
*   **When Not to Use:** When real-time rendering or low memory footprint is critical.

## Background
The method was proposed in "Forward Flow for Novel View Synthesis of Dynamic Scenes" [S1]. It builds on the idea of canonical representations for dynamic scenes, addressing the limitations of backward flow methods by using forward warping. The method was evaluated on D-NeRF and HyperNeRF datasets, as well as a newly built Lego Complete Dataset [S1].
