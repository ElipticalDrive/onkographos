# View-Dependent Appearance and Lighting


## Overview
This configuration defines how a radiance field models the angular dependence of light emission and reflection at each 3D point, enabling the synthesis of glossy, specular, and view-dependent effects that standard Lambertian NeRF cannot represent. It sets apart from sibling methods like [Depth-Guided NeRF Training Configuration](11916-depth-guided-nerf-training-configuration.md) by explicitly parameterizing the appearance function $F_\theta(\mathbf{x}, \mathbf{d})$ to separate or integrate view-dependent components, rather than relying solely on geometric or depth priors.

## Shared principles
The core mechanism involves extending the standard NeRF query function to accept the viewing direction $\mathbf{d}$ as an explicit input alongside the 3D position $\mathbf{x}$. The network outputs not only density $\sigma$ and base color $\mathbf{c}$, but also view-dependent features or explicit reflection components.

1.  **Directional Encoding**: The viewing direction $\mathbf{d}$ is encoded using a positional encoding function $\Gamma(\mathbf{d})$ or an integrated direction encoding scheme to capture high-frequency angular variations [S1].
2.  **View-Dependent Output**: The MLP $F_\theta$ outputs a view-dependent feature vector $\mathbf{f}_{vd}$ or explicit color components (diffuse/specular) conditioned on $\mathbf{d}$ [S1].
3.  **Rendering Integration**: During volume rendering, the view-dependent features are aggregated along the ray. For methods using feature vectors, a decoder MLP maps the accumulated feature $\mathbf{F}_{vd}$ to the final view-dependent color $\mathbf{C}_{vd}$ [S1].

## Subtopics

### [See-NeRF](18115-see-nerf.md)
See-NeRF is a unified sensor-physics grounded framework for sharp High Dynamic Range (HDR) novel view synthesis from single-exposure blurry Low Dynamic Range (LDR) images and corresponding event data [18115-see-nerf.md]. It solves the problem of suboptimal HDR reconstruction and deblurring caused by sensor-physics mismatches in traditional methods, which often ignore the specific imaging characteristics of RGB and event sensors [18115-see-nerf.md]. Unlike sibling methods like EvHDR-NeRF that apply tone mapping directly to 3D points, See-NeRF explicitly models the radiance-to-measurement process for both RGB and event sensors using physically grounded Camera Response Function (CRF) models [18115-see-nerf.md]. It uses standard hierarchical sinusoidal positional encoding $\gamma_M(x) = \{\sin(2^m\pi x), \cos(2^m\pi x)\}_{m=0}^{M}$ [18115-see-nerf.md]. The method employs three separate MLPs for RGB CRF and an MLP for event delay coefficient $\epsilon_i$. It minimizes a combined loss $\mathcal{L} = \lambda \mathcal{L}_{evs} + \mathcal{L}_{ldr}$ where $\lambda=0.005$ [18115-see-nerf.md].

### [REF2-NeRF](18124-ref2-nerf.md)
REF2-NeRF is a NeRF-based modeling method designed for scenes containing transparent objects, specifically glass cases, where it models both refraction and reflection effects [18124-ref2-nerf.md]. It distinguishes itself from standard NeRF and reflection-only methods (e.g., NeRFReN, NeuS-HSR) by simultaneously estimating refraction surfaces and separating direct (view-independent) and reflected (view-dependent) light components using two independent MLPs: a glass network for refraction offsets and a decomposition NeRF for rendering [18124-ref2-nerf.md]. It uses four MLPs: Glass Network ($\Theta_{gl}$), Decomposition NeRF ($\Theta_{nf}$), Decoder MLP ($\Theta_{dc}$), and Gate MLP ($\Theta_{gt}$) [18124-ref2-nerf.md]. The feature vector dimension is $\theta=64$ and regularization weight $\epsilon=10^{-5}$ [18124-ref2-nerf.md]. It samples 128 coarse points and 192 fine points (64 hierarchical + 32 glass + 32 view-independent) [18124-ref2-nerf.md]. The final color is $\mathbf{C}(\mathbf{r}) = \mathbf{C}_{vi}(\mathbf{r}) + \alpha(\mathbf{r}) \mathbf{C}_{vd}(\mathbf{r})$ [18124-ref2-nerf.md].

#### Ref-NeRF
- **Definition**: A method that significantly improves the realism and accuracy of NeRF in rendering complex scenes with glossy surfaces by introducing a new parameterization method and a structured view-dependent appearance representation [S1].
- **Steps**: Improves the ability to interpolate glossy and reflective appearances by using reflection directions about local normals as input instead of view directions [S1]. Introduces an integrated direction encoding technique and decomposes the output radiation into explicit diffuse and specular reflection components [S1].
- **Pitfalls**: Computationally expensive; the integrated orientation encoding for evaluating reflection directions is slower than standard positional encoding [S1].
- **Comparison**: Enables scene editing due to structured output radiation, which is not possible with standard NeRF [S1].

## Background
The concept of view-dependent appearance in neural rendering originated with the foundational NeRF paper, which introduced the directional encoding for specular highlights [G]. Ref-NeRF (2022) significantly advanced this by introducing a structured view-dependent appearance representation and integrated direction encoding to handle glossy surfaces more accurately [S1]. Subsequent works like REF2-NeRF extended this to handle complex refraction and reflection in transparent objects by decoupling view-independent and view-dependent components [18124-ref2-nerf.md]. See-NeRF further extended the paradigm to include event sensors and HDR physics [18115-see-nerf.md]. VDN-NeRF (2023) addressed geometric reconstruction under non-Lambertian surfaces by normalizing viewpoint dependence [S1].
