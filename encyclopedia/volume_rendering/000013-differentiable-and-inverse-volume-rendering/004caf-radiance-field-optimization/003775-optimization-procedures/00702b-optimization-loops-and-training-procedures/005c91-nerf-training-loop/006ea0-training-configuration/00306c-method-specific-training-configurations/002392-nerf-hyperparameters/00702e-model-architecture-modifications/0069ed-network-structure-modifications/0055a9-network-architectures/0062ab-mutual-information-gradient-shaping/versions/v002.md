# Mutual Information Gradient Shaping

Also called: J-NeRF, MI-shaping NeRF, NeRF shaping with mutual information gradients, mutual information shaped NeRF

## Overview
Mutual Information Gradient Shaping (MIGS), implemented as JacobiNeRF, is a training regularization technique that shapes the tangent space of a Neural Radiance Field (NeRF) to encode semantic correlations between scene entities [S1]. Unlike first-order approaches that distill 2D features into 3D radiance channels or treat labels as separate output channels, MIGS aligns the Jacobians of correlated entities to maximize their mutual information under random weight perturbations, enabling efficient sparse label propagation and semantic consensus [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** A standard NeRF model $\Phi$ parameterized by weights $\theta \in \mathbb{R}^D$; a set of labeled source pixels/points $S = \{s_1, \dots, s_K\}$ with semantic labels; unlabeled target pixels/points $T = \{t_1, \dots, t_M\}$; camera parameters for rendering [S1].
*   **Outputs:** A trained NeRF $\Phi$ where the Jacobian of rendered values with respect to weights encodes semantic similarity; propagated semantic labels for target entities [S1].

**Data Structures**
*   **NeRF Weights ($\theta$):** Vector of size $D$ [S1].
*   **Jacobian ($\partial \Phi$):** Gradient vector of size $D$, representing $\frac{\partial I(p)}{\partial \theta}$ for a pixel or 3D point $p$ [S1].
*   **Perturbation ($n$):** Vector of size $D$, sampled from a uniform distribution on the unit sphere $S^{D-1}$ [S1].

**Method Steps**

1.  **Compute Jacobians:** For each labeled source pixel $s_k$ and target pixel $t_i$, compute the Jacobian of the rendered value with respect to the NeRF weights $\theta$ at the current training state [S1]. Let $\partial \Phi^{J,s_k}$ and $\partial \Phi^{J,t_i}$ denote these gradients [S1].

2.  **MI-Shaping Loss Calculation:** Align the Jacobians of correlated entities using contrastive learning [S1]. The Mutual Information (MI) between two entities is approximated by the cosine similarity of their Jacobians [S1].
    *   Define the MI approximation:
        $$ I(I(p_i), I(p_j)) = \log\left(\frac{1}{\sqrt{1 - \cos^2 \alpha}}\right) + \text{const} $$
        where $\alpha$ is the angle between Jacobians $\partial \Phi_i$ and $\partial \Phi_j$, and $MI(p, q) \propto \cos(\partial \Phi_p, \partial \Phi_q)$ [S1].
    *   Construct positive pairs (entities known to be correlated, e.g., same semantic class) and negative pairs (different classes) using general-purpose self-supervised features (e.g., DINO) [S1].
    *   Compute the MI-Shaping Loss ($L_{MIG}$) using an InfoNCE formulation [S1]:
        $$ L_{MIG} = -\log \frac{\exp(\|\cos(\partial \Phi_i, \partial \Phi_{i+})\|/\tau)}{\sum_{j \in \{i^+\} \cup \{i^-\}} \exp(\|\cos(\partial \Phi_i, \partial \Phi_j)\|/\tau)} $$
        where $\tau$ is a temperature parameter, $i+$ denotes positive pairs, and $i-$ denotes negative pairs [S1].

3.  **Gradient Normalization:** Apply a regularization term to compact gradients onto a unit sphere, which improves training efficiency and facilitates label propagation [S1]:
    $$ L_{norm} = \gamma (1.0 - \|\partial \Phi_i\|)^2 $$
    where $\gamma$ is a weighting factor [S1].

4.  **Total Loss:** Combine the standard photometric reconstruction loss ($L_{NeRF}$) with the shaping terms [S1]:
    $$ L_{TM} = L_{NeRF} + \lambda L_{MIG} + \gamma(1.0 - \|\partial \Phi_i\|)^2 $$
    where $\lambda$ controls the strength of the mutual information shaping [S1].

5.  **Label Propagation (Inference/Post-Training):**
    *   For a target pixel $t_i$, select the best source pixel $k^*$ based on Jacobian alignment:
        $$ k^* = \arg\max_k \frac{\|\partial \Phi^{J,s_k} \cdot \partial \Phi^{J,t_i}\|}{\|\partial \Phi^{J,s_k}\| \|\partial \Phi^{J,t_i}\|} $$
        [S1].
    *   Alternatively, propagate labels via perturbation response:
        *   Perturb weights: $\theta' = \theta + \sigma n$, where $n \sim \text{Uniform}(S^{D-1})$ [S1].
        *   Render perturbed image $I_k$ using weights perturbed along the gradient of source pixel $k$ (i.e., $\theta + \sigma \partial \Phi^{J,s_k}$) [S1].
        *   Compute response: $R_k(t_i) = |I_k(t_i) - I(t_i)|$ [S1].
        *   Assign label: $l_{t_i} = \arg\max_k R_k(t_i)$, treating $R_k$ as logits for $K$-way classification [S1].

**Pseudocode**
```python
import torch
import torch.nn.functional as F

def mse_loss(pred, target):
    return torch.mean((pred - target) ** 2)

def compute_jacobian(nerf_model, ray_origins, ray_directions, weights):
    pred_values = nerf_model(ray_origins, ray_directions)
    grad = torch.autograd.grad(pred_values.mean(), weights, create_graph=True)[0]
    return grad

def cosine_similarity(vec1, vec2):
    dot = torch.dot(vec1, vec2)
    norm1 = torch.norm(vec1)
    norm2 = torch.norm(vec2)
    if norm1 == 0 or norm2 == 0:
        return torch.tensor(0.0)
    return dot / (norm1 * norm2)

def train_jacobi_nerf(nerf_model, rays, gt_images, labeled_sources, unlabeled_targets,
                      lambda_mi, gamma_norm, tau, optimizer, num_epochs):
    weights = nerf_model.parameters()
    for epoch in range(num_epochs):
        optimizer.zero_grad()
        pred_images = nerf_model(rays.origins, rays.directions)
        l_nerf = mse_loss(pred_images, gt_images)

        jacobians_s = {}
        for s in labeled_sources:
            jacobians_s[s.id] = compute_jacobian(nerf_model, s.origins, s.directions, weights)

        jacobians_t = {}
        for t in unlabeled_targets:
            jacobians_t[t.id] = compute_jacobian(nerf_model, t.origins, t.directions, weights)

        l_mig = torch.tensor(0.0)
        count = 0
        for t in unlabeled_targets:
            for s_pos in labeled_sources:
                cos_pos = cosine_similarity(jacobians_s[s_pos.id], jacobians_t[t.id])
                exp_pos = torch.exp(torch.abs(cos_pos) / tau)
                sum_exp = exp_pos
                for s_neg in labeled_sources:
                    if s_neg.id != s_pos.id:
                        cos_neg = cosine_similarity(jacobians_s[s_neg.id], jacobians_t[t.id])
                        sum_exp += torch.exp(torch.abs(cos_neg) / tau)
                l_mig -= torch.log(exp_pos / sum_exp)
                count += 1
        if count > 0:
            l_mig /= count

        l_norm = torch.tensor(0.0)
        for t in unlabeled_targets:
            norm_t = torch.norm(jacobians_t[t.id])
            l_norm += (1.0 - norm_t) ** 2
        l_norm /= len(unlabeled_targets)

        total_loss = l_nerf + lambda_mi * l_mig + gamma_norm * l_norm
        total_loss.backward()
        optimizer.step()

def propagate_labels(nerf_model, rays, labeled_sources, target_pixels, sigma):
    propagated_labels = {}
    perturbed_models = {}
    for s in labeled_sources:
        grad_s = compute_jacobian(nerf_model, s.origins, s.directions, nerf_model.parameters())
        perturbed_model = nerf_model.clone()
        with torch.no_grad():
            perturbed_model.parameters().add_(sigma * grad_s)
        perturbed_models[s.id] = perturbed_model

    for t in target_pixels:
        responses = []
        for s in labeled_sources:
            pred_perturbed = perturbed_models[s.id](t.origins, t.directions)
            pred_original = nerf_model(t.origins, t.directions)
            r_k = torch.abs(pred_perturbed - pred_original)
            responses.append(r_k)
        best_idx = torch.argmax(torch.stack(responses))
        best_source = labeled_sources[best_idx]
        propagated_labels[t.id] = best_source.label
    return propagated_labels
```

**Parameters**
*   $\lambda$ (lambda): Weight for $L_{MIG}$. Not given in the sources.
*   $\gamma$ (gamma): Weight for gradient normalization. Not given in the sources.
*   $\tau$ (tau): Temperature parameter for InfoNCE loss. Not given in the sources.
*   $\sigma$: Scale for weight perturbation. Not given in the sources.

**Edge Cases and Pitfalls**
*   **Gradient Normalization:** The term $\gamma(1.0 - \|\partial \Phi_i\|)^2$ improves training efficiency and facilitates label propagation by compacting gradients onto a unit sphere [S1].

## Subtopics

### J-NeRF 2D
Propagates labels in the 2D image domain by computing perturbation differences after volume rendering [S1]. Suitable for pixel-wise semantic segmentation [S1].

### J-NeRF 3D
Propagates labels in 3D space by estimating perturbation differences for 3D points along rays before volume rendering [S1]. Suitable for instance segmentation and 3D entity selection [S1].

## Operating characteristics
*   **Time and Memory Complexity:** Not given in the sources.
*   **Strengths:** Enables efficient label propagation from extremely sparse annotations; encodes semantic consensus in the tangent space rather than output channels; supports view-invariant propagation [S1].
*   **Limitations:** Requires computing second-order Jacobian information, which is more expensive than first-order methods [S1].
*   **When to use:** Sparse label propagation for semantic/instance segmentation; entity selection by clicking a single point; appearance edit propagation [S1].
*   **When not to use:** When computational resources are extremely limited and only photometric reconstruction is needed; when dense annotations are available and first-order methods suffice [S1].

## Background
Mutual Information Gradient Shaping was introduced by Xiaomeng Xu, Yanchao Yang, Kaichun Mo, Boxiao Pan, Li Yi, and Leonidas Guibas in "JacobiNeRF: NeRF Shaping with Mutual Information Gradients" (arXiv:2304.00341v1, April 2023) [S1]. The method addresses the limitation of traditional NeRFs that only capture appearance by explicitly regularizing learning dynamics to align Jacobians of correlated entities, thereby encoding mutual information in the NeRF tangent space [S1]. It is used for sparse label propagation, entity selection, and scene modifications [S1].
