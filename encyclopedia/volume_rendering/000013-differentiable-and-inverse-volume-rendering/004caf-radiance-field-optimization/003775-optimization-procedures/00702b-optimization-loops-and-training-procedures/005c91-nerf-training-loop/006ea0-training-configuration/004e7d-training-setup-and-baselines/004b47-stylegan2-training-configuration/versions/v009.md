# StyleGAN2 Training Configuration

Also called: StyleGAN2 Training Setup

## Overview
This configuration adapts the StyleGAN2 training protocol for 3D-aware image synthesis, specifically within the context of sparse voxel grid-based radiance fields (e.g., VoxGRAF). It solves the problem of stable GAN convergence for 3D generators by leveraging established 2D GAN stabilization techniques. It differs from standard NeRF training setups [NeRF Training Setup](13271-nerf-training-setup.md) by utilizing equalized learning rates, minibatch standard deviation, and R1 regularization, while explicitly excluding path regularization and style-mixing. It serves as a high-fidelity baseline for comparing 3D-aware generative models.

## How it works
**Inputs:** Generator weights, Discriminator weights, minibatch of images, dataset statistics.
**Outputs:** Updated Generator and Discriminator weights.

**Data Structures:**
*   **Generator/Discriminator Parameters:** Standard convolutional and dense layer weights.
*   **EMA State:** Exponential moving average of generator weights.
*   **R1 State:** Accumulator for R1 gradient penalty.

**Steps:**
1.  **Equalized Learning Rates:** Apply equalized learning rates to all trainable parameters in the generator and discriminator. This scales the learning rate for each layer inversely to the number of parameters in that layer, stabilizing training [S1].
2.  **Minibatch Standard Deviation:** Append a minibatch standard deviation layer to the end of the discriminator. This layer computes the standard deviation of features across the minibatch dimension and concatenates it as an additional channel to the feature map, providing global statistical information to the discriminator [S1].
3.  **Exponential Moving Average (EMA):** Maintain an EMA of the generator weights. Update the EMA after each generator update step to stabilize the generator's output during training [S1].
4.  **Mixed Precision:** Use mixed-precision arithmetic (FP16 for activations/weights, FP32 for master weights) for both the generator and discriminator to accelerate training and reduce memory usage [S1].
5.  **R1 Regularization:** Apply R1 gradient penalty regularization to the discriminator. To reduce computational cost, compute the R1 penalty once every 4 minibatches. The regularization strength is set to $\gamma = 1$ [S1].
6.  **Exclusions:** Do not use path regularization or style-mixing, which are present in the original StyleGAN2 but omitted here for efficiency and compatibility with the 3D generation pipeline [S1].

**Parameters:**
*   R1 regularization strength ($\gamma$): 1 [S1].
*   R1 regularization frequency: Every 4 minibatches [S1].
*   Learning rate scaling: Equalized per layer [S1].

**Pitfalls:**
*   **Small Datasets:** For small datasets like AFHQ, direct training may fail. Finetune a generator pretrained on FFHQ with $R_I=128$ and $R_G=32$ (before pruning) [S1].
*   **Precision:** Ensure mixed-precision implementation handles gradient scaling correctly to avoid underflow in the discriminator [S1].

## Subtopics

### Conditional Discriminator with Skip Connections for Progressive Growing
A conditional discriminator variant based on StyleGAN2 designed for progressive growing. It uses conditional input and implements a skip architecture that adds a downsampled version of the input image to the input of each layer, facilitating stable training at increasing resolutions [S1].

## Operating characteristics
*   **Time Complexity:** R1 regularization is applied every 4 minibatches, reducing the computational overhead of the penalty compared to per-step application [S1].
*   **Memory Complexity:** Mixed precision reduces memory usage for both generator and discriminator [S1].
*   **Strengths:** Stable convergence for 3D-aware GANs; efficient training via mixed precision and infrequent R1; effective for high-fidelity synthesis [S1].
*   **Limitations:** Requires careful handling for small datasets; excludes style-mixing which may affect diversity in some contexts [S1].
*   **When to use:** When training 3D-aware generative models using sparse voxel grids or similar architectures that benefit from StyleGAN2's stabilization techniques [S1].
*   **When not to use:** For very small datasets without pretrained initialization; when style-mixing is critical for the specific generative task [S1].

## Background
Originated from the StyleGAN2 framework [22], adapted for 3D-aware image synthesis in VoxGRAF [S1]. The configuration builds on the official PyTorch implementation of StyleGAN2 [S1]. It integrates techniques from [19] (minibatch std dev) and [29] (R1 regularization) to stabilize training for 3D generators [S1].
