# Dynamic Scene and Temporal Modeling

Also called: Dynamic NeRF, 4D NeRF, Time-conditioned NeRF

## Overview
Dynamic Scene and Temporal Modeling adapts static Neural Radiance Fields (NeRF) to represent time-varying geometry and appearance, solving the problem of rendering novel views of scenes that change over time [S1]. Unlike static methods, these approaches extend the input domain of the radiance field to include a temporal coordinate $t$ or model explicit deformation fields [S1]. The family is distinguished from sibling methods like [DoF-NeRF](9432-dof-nerf.md) or [NeRF-VPT](11770-nerf-vpt.md) by its focus on the fundamental representation of dynamics, ranging from simple time-conditioning to complex particle systems and Kalman-filtered deformation fields [S1].

## Shared principles
The core task of a dynamic NeRF network architecture is to learn a continuous volumetric scene representation $F_\Theta: (\mathbf{x}, \mathbf{d}, t) \rightarrow (\sigma, \mathbf{c})$, where $\mathbf{x} \in \mathbb{R}^3$ is the spatial position, $\mathbf{d} \in \mathbb{R}^3$ is the viewing direction, $t \in \mathbb{R}$ is the time parameter, $\sigma$ is the volume density, and $\mathbf{c} \in \mathbb{R}^3$ is the view-dependent color [G]. The rendering process integrates these outputs along rays using standard volume rendering equations [G].

## Subtopics

### [Gear-NeRF](13848-gear-nerf.md)
Gear-NeRF is a dynamic scene representation method that stratifies the volumetric scene into motion-based "gears" using semantic embeddings from image segmentation models, allowing for region-specific spatio-temporal sampling resolution. It solves the inefficiency of uniform high-resolution sampling in dynamic NeRFs by assigning higher gear levels (and thus higher sampling densities) to regions with larger motion scales, while maintaining static or low-motion regions at lower resolutions. Unlike sibling methods that use a single unified 4D volume or explicit deformation fields, Gear-NeRF employs a series of parallel 4D feature volumes, one per gear level, where the gear assignment is determined by a learned semantic embedding.

### [NeRF with Time Parameter](14705-nerf-with-time-parameter.md)
NeRF with Time Parameter is a baseline method for adapting static Neural Radiance Fields (NeRF) to dynamic scenes by explicitly conditioning the radiance field on a temporal coordinate. It solves the problem of representing time-varying geometry and appearance by extending the input domain of the implicit function from $(\mathbf{x}, \mathbf{d})$ to $(\mathbf{x}, \mathbf{d}, t)$. Unlike deformation-based approaches that warp points to a canonical space, this method treats time as a direct conditioning signal. It sets itself apart from siblings like [Gear-NeRF](13848-gear-nerf.md) or [ST-NeRF](18515-st-nerf.md) by its simplicity: it modifies only the input encoding and MLP conditioning, without introducing explicit deformation fields, particle systems, or complex temporal attention mechanisms.

### [Forward Warping for Novel View Synthesis](15541-forward-warping-for-novel-view-synthesis.md)
Forward Warping for Novel View Synthesis is a method for rendering dynamic scenes by modeling a static radiance field at a canonical time step and forward-warping this entire field to other time steps. It addresses the many-to-one and one-to-many mapping difficulties inherent in dynamic scene reconstruction by employing differentiable forward warping with average splatting and an inpaint network. Unlike backward-flow methods such as NDVG, this approach achieves superior performance, particularly for canonical frames, by explicitly warping the canonical representation forward in time.

### [Dynamic Appearance Particle Neural Radiance Field](15550-dynamic-appearance-particle-neural-radiance-field.md)
Dynamic Appearance Particle Neural Radiance Field is a method for modeling dynamic scenes from monocular video data by superimposing a static grid-based radiance field with a particle-based dynamic field. It solves the problem of capturing continuous scene dynamics without requiring prior geometric knowledge or multi-view stereo setups, distinguishing itself from ParticleNeRF by applying particles only to dynamic elements and using efficient linear interpolation instead of radius nearest neighbor searching.

### [KFD-NeRF](15551-kfd-nerf.md)
KFD-NeRF is a dynamic neural radiance field method that models the 4D radiance field as a dynamic system with temporally varying states, estimated using a Kalman filter to combine observations from input data and predictions based on local linear motion equations. It differs from sibling methods like [Gear-NeRF](13848-gear-nerf.md) or [NeRF with Time Parameter](14705-nerf-with-time-parameter.md) by explicitly separating motion estimation into an observation branch (shallow MLP) and a prediction branch (linear motion model), fusing them via a learnable Kalman gain. This approach leverages the inductive smoothness bias of deformation fields over feature interpolation, allowing for faster convergence and higher quality reconstruction of non-rigid motions.

### [SLS4D](16576-sls4d.md)
SLS4D is a method for 4D novel view synthesis that represents dynamic scenes using a sparse, compact, and informative latent feature space, significantly reducing the number of network parameters compared to dense voxel-based or coordinate-based alternatives. It distinguishes itself by abandoning direct coordinate-to-feature mapping in favor of a sparse set of globally learnable latent codes weighted by an attention mechanism, combined with a deformation field conditioned on dense time slots to decouple spatial and temporal dynamics.

### [ST-NeRF](18515-st-nerf.md)
ST-NeRF is a layered neural radiance field representation designed for editable free-viewpoint videos of dynamic scenes. It solves the problem of modeling independently moving and articulated objects by assigning each entity its own continuous function spanning space and time, thereby disentangling position, deformation, and appearance. Unlike monolithic dynamic NeRFs, ST-NeRF enables explicit spatial and temporal editing (e.g., rescaling, shifting, removal) by treating scene entities as separate layers rendered via ray-box intersection.

## Background
The concept of dynamic scene reconstruction using neural radiance fields emerged as an extension of the original static NeRF framework [S1]. Early approaches focused on simple time-conditioning, while subsequent research introduced more complex mechanisms such as deformation fields, particle systems, and semantic stratification to handle non-rigid motions and varying scene dynamics [S1]. The field has seen significant development in handling monocular inputs, multi-view consistency, and real-time rendering capabilities [S1][S2, unofficial].
