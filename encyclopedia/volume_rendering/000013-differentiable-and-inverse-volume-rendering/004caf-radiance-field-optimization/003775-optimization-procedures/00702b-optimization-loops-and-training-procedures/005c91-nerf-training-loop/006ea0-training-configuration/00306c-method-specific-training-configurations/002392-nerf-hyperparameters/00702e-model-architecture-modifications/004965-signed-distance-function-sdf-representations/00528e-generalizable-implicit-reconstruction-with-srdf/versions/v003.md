# Generalizable Implicit Reconstruction with SRDF

Also called: VolRecon, Volume Rendering of Signed Ray Distance Functions for Generalizable Multi-View Reconstruction

## Overview
VolRecon is a generalizable implicit reconstruction method that predicts a Signed Ray Distance Function (SRDF) to reconstruct scenes with fine details and minimal noise from multi-view images [S1]. It distinguishes itself from sibling methods like [SparseNeuS](12947-sdf-based-neural-fields.md) by combining local projection features aggregated via a view transformer with global shape priors from a coarse feature volume, processed by a ray transformer to resolve surface ambiguity [S1]. Unlike standard SDF approaches that define distance in any direction, SRDF constrains the distance measurement to the specific ray direction, enabling more robust surface localization along the viewing ray [S1].

## How it works
**Inputs:** A set of $N$ source images $I = \{I_1, \dots, I_N\}$ where $I_i \in \mathbb{R}^{H \times W \times 3}$, and camera parameters for the source views and the target (reference) view [S1].
**Outputs:** Rendered color image, depth map, and implicitly, a mesh or point cloud representing the scene surface [S1].

**Data Structures:**
1.  **Feature Maps:** $\{F_i\}_{i=1}^N \in \mathbb{R}^{\frac{H}{4} \times \frac{W}{4} \times C}$, extracted from source images [S1].
2.  **Global Feature Volume:** $F_v \in \mathbb{R}^{K \times K \times K \times C_{vol}}$, a 3D grid of voxels [S1].
3.  **Learnable Token:** $f_0 \in \mathbb{R}^C$, a single vector used for aggregation in the view transformer [S1].

**Parameters:**
*   $N$: Number of source views [S1].
*   $M$: Number of sampled points along a ray [S1].
*   $K$: Dimension of the global feature volume grid ($K^3$ voxels) [S1].
*   $C$: Channel dimension of the feature maps [S1].
*   $v$: Unit ray direction vector ($\|v\|_2 = 1$) [S1].
*   $o$: Ray origin [S1].

**Step 1: Feature Extraction**
For each source image $I_i$, extract feature maps $F_i$ using a Feature Pyramid Network (FPN) [S1]. The resolution is reduced to $H/4 \times W/4$ [S1].

**Step 2: Global Feature Volume Construction**
1.  Define the scene bounding volume and divide it into $K^3$ voxels [S1].
2.  For each voxel center $p_k$, project it onto the feature map $F_i$ of each source view $i \in \{1, \dots, N\}$ using bilinear interpolation to obtain features $f_{k,i}$ [S1].
3.  Compute the mean and variance of the $N$ features $\{f_{k,i}\}_{i=1}^N$ [S1].
4.  Concatenate the mean and variance to form the initial voxel feature [S1].
5.  Pass the volume of voxel features through a 3D U-Net to regularize and aggregate information, resulting in the global feature volume $F_v$ [S1].
6.  For any 3D point $p$, the volume feature $f_v(p)$ is obtained by trilinear interpolation from $F_v$ [S1].

**Step 3: Ray Sampling and Projection Feature Extraction**
For a pixel in the reference view, define a ray $p(t) = o + tv$ for $t \ge 0$ [S1]. Sample $M$ points $\{p_m\}_{m=1}^M$ along this ray [S1].
For each sampled point $p_m$:
1.  Project $p_m$ onto the feature map $F_i$ of each source view $i$ [S1].
2.  Extract the color $c_{m,i}$ and feature vector $f_{m,i}$ using bilinear interpolation [S1].

**Step 4: View Transformer**
Aggregate the multi-view features for each point $p_m$ into a single projection feature $f_{p,m}$ [S1].
1.  Initialize the input sequence with the learnable aggregation token $f_0$ and the $N$ multi-view features $\{f_{m,i}\}_{i=1}^N$ [S1].
2.  Apply a self-attention transformer with linear attention [S1].
3.  Do not use positional encoding, as the order of source views is not assumed [S1].
4.  Compute the projection feature $f_{p,m}$ and updated multi-view features $\{f'_{m,i}\}_{i=1}^N$:
    $$ f_{p,m}, \{f'_{m,i}\}_{i=1}^N = \text{ViewTrans}(f_0, \{f_{m,i}\}_{i=1}^N) $$
    [S1]

**Step 5: Ray Transformer and SRDF Prediction**
Compute the SRDF values for all sampled points along the ray [S1].
1.  For each point $p_m$, concatenate its projection feature $f_{p,m}$ and its volume feature $f_v(p_m)$ [S1].
2.  Input the sequence of concatenated features for all $M$ points into a Ray Transformer [S1].
3.  The Ray Transformer allows each point to attend to features of other points on the same ray, capturing long-range dependencies [S1].
4.  Output the predicted SRDF value $\tilde{d}_m$ for each point $p_m$ [S1].

**Step 6: Volume Rendering**
Render the color and depth using the predicted SRDF values, following the NeuS approach for SDF volume rendering [S1].
1.  Convert SRDF $\tilde{d}_m$ to density $\sigma_m$ using a differentiable mapping that concentrates density near the zero-level set [G].
2.  Compute the accumulated alpha $\alpha_m$ and transmittance $T_m$ along the ray:
    $$ \alpha_m = 1 - \exp(-\sigma_m \delta_m) $$
    $$ T_m = \prod_{j=1}^{m-1} (1 - \alpha_j) $$
    where $\delta_m$ is the distance between adjacent samples [S1].
3.  Render the color $C$ and depth $D$:
    $$ C = \sum_{m=1}^M T_m \alpha_m c_m $$
    $$ D = \sum_{m=1}^M T_m \alpha_m t_m $$
    where $c_m$ is the color at $p_m$ and $t_m$ is the depth coordinate [S1].

**Formulas:**
The Signed Ray Distance Function (SRDF) $\tilde{d}_\Omega(p, v)$ for a point $p$ and direction $v$ is defined as [S1]:
$$ \tilde{d}_\Omega(p, v) = (-1)^{1_\Omega(p)} \min_{p^* \in M, \frac{p^*-p}{\|p^*-p\|} = v} \|p - p^*\|_2 $$
where $M$ is the surface boundary, $\Omega$ is the space, and $1_\Omega(p)$ is the indicator function [S1]:
$$ 1_\Omega(p) = \begin{cases} 1 & \text{if } p \in \Omega \\ 0 & \text{if } p \notin \Omega \end{cases} $$
The standard Signed Distance Function (SDF) $d_\Omega(p)$ is the minimum absolute SRDF over all directions $v$ [S1]:
$$ d_\Omega(p) = (-1)^{1_\Omega(p)} \min_v (|\tilde{d}_\Omega(p, v)|) $$
In the implementation, the network directly predicts $\tilde{d}_\Omega(p, v)$ for the specific ray direction $v$ [S1].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class VolRecon:
    def __init__(self, N, K, C, M, H, W, near=0.0, far=10.0):
        self.N = N
        self.K = K
        self.C = C
        self.M = M
        self.H = H
        self.W = W
        self.near = near
        self.far = far
        
        # Feature Pyramid Network (simplified as stacked convs)
        self.fpn = nn.Sequential(
            nn.Conv2d(3, C, 3, padding=1), nn.ReLU(),
            nn.Conv2d(C, C, 3, padding=1, stride=2), nn.ReLU(),
            nn.Conv2d(C, C, 3, padding=1, stride=2), nn.ReLU()
        )
        
        # 3D U-Net approximation for global volume regularization
        self.global_volume_net = nn.Sequential(
            nn.Conv3d(2*C, C, 3, padding=1), nn.ReLU(),
            nn.Conv3d(C, C, 3, padding=1), nn.ReLU(),
            nn.Conv3d(C, C, 3, padding=1)
        )
        
        # Learnable aggregation token
        self.f0 = nn.Parameter(torch.randn(1, 1, C))
        
        # View Transformer: Linear attention approximation
        self.view_transformer = nn.MultiheadAttention(C, num_heads=4, batch_first=True)
        
        # Ray Transformer
        self.ray_transformer = nn.TransformerEncoderLayer(d_model=C, nhead=4, batch_first=True)
        
        # MLP to predict SRDF
        self.srdf_mlp = nn.Sequential(
            nn.Linear(C, C), nn.ReLU(),
            nn.Linear(C, 1)
        )

    def extract_features(self, images):
        """images: [N, 3, H, W] -> [N, C, H/4, W/4]"""
        return self.fpn(images)

    def build_global_volume(self, feature_maps, voxel_centers, cam_K, cam_R, cam_t):
        """feature_maps: [N, C, H/4, W/4], voxel_centers: [K*K*K, 3]"""
        N, C, H_f, W_f = feature_maps.shape
        num_voxels = voxel_centers.shape[0]
        
        # Project voxel centers to UV for each view
        uv_coords = []
        for i in range(N):
            # Homogeneous projection: uv = K * (R * p + t)
            pts_h = torch.cat([voxel_centers, torch.ones(num_voxels, 1, device=voxel_centers.device)], dim=1)
            pts_cam = (cam_R[i] @ pts_h.t()).t() + cam_t[i]
            uv = (cam_K[i] @ pts_cam.t()).t()
            uv = uv[:, :2] / uv[:, 2:].clamp(min=1e-6)
            # Normalize to [-1, 1] for grid_sample
            uv_norm = 2.0 * (uv / torch.tensor([W_f, H_f], device=uv.device)) - 1.0
            uv_norm = uv_norm.unsqueeze(0).unsqueeze(0) # [1, 1, V, 2]
            feat = F.grid_sample(feature_maps[i].unsqueeze(0), uv_norm, mode='bilinear', padding_mode='border').squeeze()
            uv_coords.append(feat.permute(0, 2, 1)) # [V, C]
            
        features_per_voxel = torch.stack(uv_coords, dim=1) # [V, N, C]
        
        # Compute mean and variance
        mean_feat = features_per_voxel.mean(dim=1)
        var_feat = features_per_voxel.var(dim=1)
        
        # Concatenate
        voxel_features = torch.cat([mean_feat, var_feat], dim=1) # [V, 2*C]
        
        # Reshape for 3D U-Net
        voxel_features_3d = voxel_features.view(K, K, K, 2*C).permute(3, 0, 1, 2) # [2*C, K, K, K]
        
        # Regularize
        out = self.global_volume_net(voxel_features_3d) # [C, K, K, K]
        out = out.permute(1, 2, 3, 0).view(-1, C) # [K*K*K, C]
        return out

    def get_volume_feature(self, volume, points):
        """volume: [K*K*K, C], points: [P, 3] -> [P, C]"""
        vol_3d = volume.view(self.K, self.K, self.K, self.C).permute(3, 0, 1, 2) # [C, K, K, K]
        # Normalize points to [-1, 1] assuming scene bbox is [-1, 1]^3
        norm_points = points.clamp(-1.0, 1.0)
        grid = norm_points.unsqueeze(0).unsqueeze(0).unsqueeze(0) # [1, 1, P, 1, 1, 3]
        feat = F.grid_sample(vol_3d.unsqueeze(0), grid, mode='trilinear', padding_mode='border').squeeze()
        return feat.permute(0, 2, 1).squeeze() # [P, C]

    def view_transform(self, features):
        """features: [M, N, C] -> [M, C]"""
        M, N, C = features.shape
        f0_expanded = self.f0.expand(M, 1, C)
        input_seq = torch.cat([f0_expanded, features], dim=1) # [M, N+1, C]
        out, _ = self.view_transformer(input_seq, input_seq, input_seq)
        return out[:, 0, :] # [M, C]

    def ray_transform(self, projection_features, volume_features):
        """projection_features: [M, C], volume_features: [M, C] -> [M]"""
        combined = torch.cat([projection_features, volume_features], dim=1) # [M, 2*C]
        # Project back to C if needed, or let transformer handle it
        combined = nn.Linear(2*C, self.C)(combined)
        out = self.ray_transformer(combined)
        srdf = self.srdf_mlp(out).squeeze(-1) # [M]
        return srdf

    def forward(self, images, ray_origins, ray_directions, voxel_centers, cam_K, cam_R, cam_t):
        """images: [N, 3, H, W], ray_origins/directions: [H, W, 3]"""
        # 1. Feature Extraction
        feature_maps = self.extract_features(images) # [N, C, H/4, W/4]
        
        # 2. Global Feature Volume
        global_vol = self.build_global_volume(feature_maps, voxel_centers, cam_K, cam_R, cam_t) # [K*K*K, C]
        
        # 3. Ray Sampling
        t_vals = torch.linspace(self.near, self.far, self.M, device=images.device) # [M]
        points = ray_origins.unsqueeze(2) + ray_directions.unsqueeze(2) * t_vals.unsqueeze(0).unsqueeze(0).unsqueeze(3) # [H, W, M, 3]
        H, W, M, _ = points.shape
        points_flat = points.view(-1, M, 3) # [H*W, M, 3]
        
        # 4. Projection Feature Extraction
        multi_view_features = []
        for i in range(self.N):
            pts_h = torch.cat([points_flat, torch.ones(points_flat.shape[0], 1, device=points_flat.device)], dim=1)
            pts_cam = (cam_R[i] @ pts_h.t()).t() + cam_t[i]
            uv = (cam_K[i] @ pts_cam.t()).t()
            uv = uv[:, :2] / uv[:, 2:].clamp(min=1e-6)
            uv_norm = 2.0 * (uv / torch.tensor([self.W/4, self.H/4], device=uv.device)) - 1.0
            uv_norm = uv_norm.unsqueeze(0).unsqueeze(0) # [1, 1, HW*M, 2]
            feat = F.grid_sample(feature_maps[i].unsqueeze(0), uv_norm, mode='bilinear', padding_mode='border').squeeze()
            multi_view_features.append(feat.permute(0, 2, 1)) # [HW*M, C]
        multi_view_features = torch.stack(multi_view_features, dim=1) # [HW*M, N, C]
        
        # 5. View Transformer
        projection_features = self.view_transform(multi_view_features) # [HW*M, C]
        
        # 6. Volume Feature Extraction
        volume_features = self.get_volume_feature(global_vol, points_flat.view(-1, 3)).view(H*W, M, C)
        
        # 7. Ray Transformer and SRDF Prediction
        srdf_values = self.ray_transform(projection_features, volume_features) # [HW*M]
        srdf_values = srdf_values.view(H, W, M)
        
        # 8. Volume Rendering
        # Convert SRDF to density [G]
        sigma = torch.sigmoid(-srdf_values * 10.0) # Standard SDF-to-density mapping [G]
        deltas = t_vals[1:] - t_vals[:-1]
        deltas = torch.cat([deltas, torch.tensor([0.0], device=t_vals.device)])
        alpha = 1.0 - torch.exp(-sigma * deltas)
        transmittance = torch.cumprod(1.0 - alpha + 1e-10, dim=2)
        transmittance = torch.cat([torch.ones(H, W, 1, device=transmittance.device), transmittance[:, :, :-1]], dim=2)
        
        # Sample colors from feature maps using projected UVs (reusing uv_norm from step 4)
        # Simplified: assume c_m is interpolated similarly
        colors = torch.rand(H, W, M, 3, device=images.device) # Placeholder for actual color interpolation
        depth = torch.sum(transmittance * alpha.unsqueeze(-1) * t_vals.unsqueeze(0).unsqueeze(0).unsqueeze(3), dim=2)
        color = torch.sum(transmittance.unsqueeze(-1) * alpha.unsqueeze(-1) * colors, dim=2)
        
        return color, depth
```

**Edge Cases and Pitfalls:**
*   **Occlusions:** The view transformer aggregates multi-view features, which helps mitigate occlusion issues, but extreme occlusion may still lead to ambiguous features [S1].
*   **Textureless Surfaces:** The global feature volume provides shape priors, which is crucial for textureless regions where local projection features are unreliable [S1].
*   **Large-Scale Scenes:** The method is not suitable for very large-scale scenes due to the memory consumption of the global feature volume and the low resolution of the volume leading to decreased representation performance [S1].
*   **Rendering Efficiency:** The method is computationally expensive, taking approximately 30 seconds to render an 800x600 image and depth map [S1].

## Operating characteristics
*   **Time Complexity:** Rendering is slow, taking ~30s for an 800x600 image [S1]. This is attributed to the volume rendering process and the transformer operations [S1].
*   **Memory Complexity:** Depends on the global feature volume size $K^3$ and the number of sampled points $M$ [S1].
*   **Performance:** On the DTU dataset, VolRecon outperforms SparseNeuS by ~30% in sparse view (N=3) reconstruction and 22% in full view reconstruction [S1]. It achieves comparable accuracy to MVSNet in full view reconstruction and better depth evaluation [S1].
*   **Strengths:** Generalizable to new scenes without per-scene optimization; produces fine details and less noise compared to SparseNeuS; good generalization to large-scale scenes (ETH3D) without fine-tuning [S1].
*   **Limitations:** Slow rendering speed; not suitable for very large-scale scenes; reconstruction quality improves with more images but is limited by the global feature volume resolution [S1].
*   **When to Use:** Generalizable implicit reconstruction from multi-view images, especially in sparse view scenarios or when fine details are required [S1].
*   **When Not to Use:** Not given in the sources.

## Background
VolRecon was introduced in 2023 by researchers from the IVRL lab [S1]. It builds upon the concept of neural implicit reconstruction, which typically optimizes per-scene parameters, lacking generalizability [S1]. The method addresses this by using a generalizable architecture that incorporates multi-view features and a global feature volume [S1]. It is based on the Signed Ray Distance Function (SRDF), which defines distance along a ray direction, differing from standard SDF [S1]. The method is compared against SparseNeuS, which uses only global feature volumes and an MLP, leading to over-smoothed surfaces [S1]. VolRecon is available at https://github.com/IVRL/VolRecon/ [S1].
