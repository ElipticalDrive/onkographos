# Dynamic Semantic Human NeRF

Also called: H-NeRF (dynamic)

## Overview
Dynamic Semantic Human NeRF extends the radiance field framework to model dynamic human motion by learning a consistent continuous function $G_\omega$ for geometry and appearance variations across frames [S1, unofficial]. It solves the problem of reconstructing temporally coherent 3D humans from video sequences by warping observations into a canonical reference frame using the imGHUM prior [S1, unofficial]. It sets itself apart from static human NeRF variants by conditioning the neural fields on semantic latent codes (shape $\beta$, pose $\theta$, and root transformation $T$), enabling generalization to novel poses and shapes through interpolation [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A sequence of images $I_t$ with known camera poses, and corresponding human parameters from imGHUM fitting: shape code $\beta$, pose code $\theta$, and root transformation $T$.
*   **Outputs:** A canonical radiance field $F_\omega$ and a residual Signed Distance Field (SDF) function $\Delta H_\omega$ that can render novel views of the human in novel poses.

**Data Structures:**
*   **Canonical Point Descriptor:** A 4D vector $(s, d) \in \mathbb{R}^4$, where $s$ is the semantic label and $d$ is the signed distance to the body surface [S1, unofficial].
*   **Bounding Box $\mathcal{B}$:** A 3D axis-aligned bounding box enclosing the human subject. Points outside $\mathcal{B}$ are treated as static background [S1, unofficial].

**Method Steps:**

1.  **Canonical Mapping via imGHUM:**
    For a spatial point $\mathbf{x}$ in a specific frame with parameters $(\beta, \theta, T)$, compute its canonical descriptor $(s, d)$ using the mapping function $H_\omega$:
    $$ (s, d) = H_\omega(T^{-1}\mathbf{x}, \beta, \theta) $$
    Here, $T^{-1}\mathbf{x}$ transforms the point into the local coordinate system of the human instance [S1, unofficial]. The function $H_\omega$ is implemented by the pre-trained imGHUM network [S1, unofficial]. Two points $\mathbf{x}$ and $\mathbf{x}'$ from different frames are considered in correspondence if their descriptors are identical: $(s, d | \beta, \theta, T) = (s', d' | \beta', \theta', T')$ [S1, unofficial].

2.  **Neural Field Definition:**
    Define the canonical NeRF function $F_\omega$ and the residual SDF function $\Delta H_\omega$:
    *   $F_\omega: (s, d) \rightarrow (\mathbf{c}, \sigma)$, where $\mathbf{c} \in \mathbb{R}^3$ is color and $\sigma \in \mathbb{R}$ is volume density [S1, unofficial].
    *   $\Delta H_\omega: (s, d) \rightarrow \Delta d$, where $\Delta d$ is the residual signed distance [S1, unofficial].

3.  **Conditioning for Dynamics:**
    *   **Pose Conditioning:** Condition both $F_\omega$ (for $\sigma$ and $\mathbf{c}$) and $\Delta H_\omega$ on the body pose code $\theta$. This captures fine-grained geometric deformations (e.g., clothing) and appearance changes (e.g., self-shadows) [S1, unofficial].
    *   **Root Transformation Conditioning:** Condition the color output $\mathbf{c}$ of $F_\omega$ on the root transformation $T$. This accounts for illumination effects due to the person's position/rotation relative to the scene, without affecting geometry [S1, unofficial].
    *   The final color prediction is $\mathbf{c} = F_\omega(s, d, \theta, T)$ [S1, unofficial].

4.  **Warping Strategy:**
    Apply the imGHUM warping function $H_\omega$ only to spatial points $\mathbf{x}$ inside the bounding box $\mathcal{B}$ [S1, unofficial]. Points outside $\mathcal{B}$ are rendered using a static background representation, as the background is invariant to human motion [S1, unofficial]. This reduces computation time and memory usage [S1, unofficial].

5.  **Regularization:**
    Apply a regularization term $\mathcal{L}_{reg}$ to the residual distance $\Delta d$ to enforce $\Delta d \le 0$. This ensures that the imGHUM surface remains within the learned geometry, allowing $\Delta d$ to model only personalized geometric details on top of the skin surface [S1, unofficial].

6.  **Inference and Generalization:**
    *   To render a novel pose or shape, assign new latent codes $(\beta', \theta')$ and compute the canonical descriptor $(s, d)$ using these new codes [S1, unofficial].
    *   Add Gaussian noise to the input codes $(\theta, T)$ during training to prevent overfitting to specific pose-dependent deformations and appearance effects [S1, unofficial].
    *   If training with sparse views, apply the same Gaussian noise technique to the viewing direction $\mathbf{v}$ conditioning [S1, unofficial].

        """
        Maps spatial point x to canonical descriptor (s, d) using imGHUM.
        x: (N, 3) spatial points in world coordinates
        beta: (N, 10) shape code
        theta: (N, 72) pose code (SMPL pose)
        T: (N, 4, 4) root transformation matrix
        """
        # Transform to local human coordinate system
        x_local = torch.matmul(T.inverse(), torch.cat([x, torch.ones_like(x[:, :1])], dim=1).unsqueeze(-1)).squeeze(-1)[:, :3]
        
        # imGHUM provides semantic label s and signed distance d
        # H_omega(T^-1 x, beta, theta) -> (s, d)
        s, d = self.imghum(x_local, beta, theta)
        return s, d

    def forward(self, x, beta, theta, T, view_dir=None):
        """
        Forward pass for a batch of points.
        x: (N, 3) spatial points
        beta: (N, 10) shape code
        theta: (N, 72) pose code
        T: (N, 4, 4) root transformation
        view_dir: (N, 3) viewing direction (optional, for sparse view noise)
        """
        # Determine if points are inside bounding box B
        inside_box = is_inside_bounding_box(x, B)
        
        # Initialize outputs
        sigma = torch.zeros_like(x[:, :1])
        color = torch.zeros_like(x[:, :3])
        residual_d = torch.zeros_like(x[:, :1])
        
        # Process points inside the bounding box (human)
        if torch.any(inside_box):
            x_human = x[inside_box]
            beta_human = beta[inside_box]
            theta_human = theta[inside_box]
            T_human = T[inside_box]
            
            # Add noise for generalization if in training mode
            if self.training:
                theta_noisy = theta_human + torch.randn_like(theta_human) * 0.01
                T_noisy = T_human + torch.randn_like(T_human) * 0.01
                if view_dir is not None:
                    view_dir_noisy = view_dir[inside_box] + torch.randn_like(view_dir[inside_box]) * 0.01
                else:
                    view_dir_noisy = None
            else:
                theta_noisy = theta_human
                T_noisy = T_human
                view_dir_noisy = view_dir[inside_box] if view_dir is not None else None

            # Get canonical descriptors
            s, d = self.get_canonical_descriptor(x_human, beta_human, theta_noisy, T_noisy)
            
            # Predict residual SDF
            # Delta H_omega(s, d) -> Delta d
            residual_d_human = self.residual_sdf(torch.cat([s, d], dim=1))
            
            # Regularization: Delta d <= 0
            # L_reg = max(0, residual_d_human) # Applied in loss function
            
            # Predict NeRF outputs
            # F_omega(s, d, theta, T) -> (c, sigma)
            # Note: Color is conditioned on T, Geometry (sigma) on theta
            neRF_input = torch.cat([s, d], dim=1)
            # Concatenate conditioning codes
            f_input = torch.cat([neRF_input, theta_noisy, T_noisy[:, :3, 3]], dim=1) # T[:, :3, 3] is translation
            
            # If view direction is available, concatenate it
            if view_dir_noisy is not None:
                f_input = torch.cat([f_input, view_dir_noisy], dim=1)
                
            raw_output = self.neural_field(f_input)
            sigma_human = raw_output[..., 0:1]
            color_human = raw_output[..., 1:4]
            
            # Scatter back to full batch
            sigma[inside_box] = sigma_human
            color[inside_box] = color_human
            residual_d[inside_box] = residual_d_human
            
        # Points outside box are background (static)
        # Not given in the sources. Assume static background rendering or zero density.
        
        return sigma, color, residual_d

## Operating characteristics
*   **Time Complexity:** Reduced compared to full-volume warping because imGHUM warping is applied only to points inside the bounding box $\mathcal{B}$ [S1, unofficial].
*   **Memory Complexity:** Lowered by restricting warping to the bounding box $\mathcal{B}$ [S1, unofficial].
*   **Strengths:** Generalizes to novel poses and shapes via interpolation of latent codes; handles dynamic motion and appearance changes (lighting, shadows); leverages strong geometric priors from imGHUM [S1, unofficial].
*   **Limitations:** Relies on the accuracy of imGHUM fitting; errors in fitting can propagate to the NeRF [S1, unofficial]. Performance depends on the quality of the bounding box definition [S1, unofficial].
*   **When to use:** When reconstructing dynamic humans from video where novel pose/shape synthesis is required.
*   **When not to use:** For static scenes or when high-precision background reconstruction is needed without a separate background model.

## Background
Dynamic Semantic Human NeRF (H-NeRF) was introduced by [S1, unofficial]. It builds on the concept of warping observations into a canonical frame, extending prior work [36, 38] by using the imGHUM prior for semantic and geometric conditioning [S1, unofficial]. The method addresses the limitations of static NeRFs in capturing temporal dynamics and fine-grained appearance variations in human subjects [S1, unofficial].
