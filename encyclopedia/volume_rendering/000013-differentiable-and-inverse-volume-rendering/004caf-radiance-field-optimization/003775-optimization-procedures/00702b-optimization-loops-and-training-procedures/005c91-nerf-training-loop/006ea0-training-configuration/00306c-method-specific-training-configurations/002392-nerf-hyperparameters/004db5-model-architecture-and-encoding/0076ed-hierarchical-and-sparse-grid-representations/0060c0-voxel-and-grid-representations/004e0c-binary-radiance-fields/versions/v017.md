# Binary Radiance Fields

Also called: BRF

## Overview
Binary Radiance Fields (BiRF) is a storage-efficient radiance field representation that constrains feature grid parameters to binary values (+1 or -1) to achieve compact storage without post-processing compression [S1]. Unlike methods that compress pre-trained models, BiRF performs binarization during training, allowing it to outperform state-of-the-art efficient radiance field models in reconstruction quality while using significantly less memory (e.g., < 0.5 MB for Synthetic-NeRF scenes) [S1]. It distinguishes itself from siblings like [Instant-NGP](13550-model-architecture-and-encoding.md) by replacing real-valued hash grid features with binary features and employing a 2D-3D hybrid grid structure to mitigate hash collisions inherent in high-resolution 3D grids [S1].

## How it works
BiRF maps a 3D coordinate $\mathbf{x} \in \mathbb{R}^3$ and viewing direction $\mathbf{d} \in S^2$ to volume density $\sigma \in \mathbb{R}_{\ge 0}$ and RGB color $\mathbf{c} \in [0, 1]^3$. The method relies on a multi-resolution 2D-3D hybrid feature grid where all parameters are binary, and two shallow MLPs for density and color prediction.

### Inputs and Outputs
*   **Inputs:** 3D coordinate $\mathbf{x}$, viewing direction $\mathbf{d}$, training images (for loss calculation).
*   **Outputs:** Density $\sigma$, color $\mathbf{c}$, embedding feature $\mathbf{e}$.

### Data Structures
The core data structure is a set of feature grids implemented using hash encoding [S1]. All grid parameters are binary, stored as 1-bit values [S1].

1.  **3D Voxel Grid ($\Phi_{\theta_{xyz}}$):**
    *   Contains $L$ resolution levels.
    *   Resolutions range from 16 to 1024 [S1].
    *   Maximum number of feature vectors per level: $T_{3D}$ [S1].
    *   Parameters: $\theta_{xyz} \in \{-1, 1\}$ [S1].
2.  **2D Plane Grids ($\Phi_{\theta_{xy}}, \Phi_{\theta_{xz}}, \Phi_{\theta_{yz}}$):**
    *   Three orthogonal planes corresponding to the XY, XZ, and YZ axes [S1].
    *   Contains $M$ resolution levels.
    *   Resolutions range from 64 to 512 [S1].
    *   Maximum number of feature vectors per level: $T_{2D}$ [S1].
    *   Parameters: $\theta_{xy}, \theta_{xz}, \theta_{yz} \in \{-1, 1\}$ [S1].
3.  **MLPs:**
    *   **Density MLP:** 1 hidden layer, 128 channels, ReLU activation [S1].
    *   **Color MLP:** 2 hidden layers, 128 channels, ReLU activation [S1].
    *   Input feature dimension per level is $F \in \{2, 4, 8\}$ [S1].

### Parameters
*   $L$: Number of 3D grid levels (Not given in the sources, implied by resolutions 16-1024).
*   $M$: Number of 2D grid levels (Not given in the sources, implied by resolutions 64-512).
*   $T_{3D}$: Max feature vectors per 3D level.
    *   Small model (Ours-S): $\log_2(T_{3D}) = 17$ [S1].
    *   Base model (Ours-B): $\log_2(T_{3D}) = 19$ [S1].
*   $T_{2D}$: Max feature vectors per 2D level.
    *   Small model (Ours-S): $\log_2(T_{2D}) = 15$ [S1].
    *   Base model (Ours-B): $\log_2(T_{2D}) = 17$ [S1].
*   $F$: Feature dimension per level [S1].
*   $\lambda_{\text{sparsity}}$: Sparsity loss weight. Value: $2.0 \times 10^{-5}$ [S1].
*   Optimizer: Adam, initial learning rate 0.01, decayed by 0.33 at 15K and 18K iterations [S1].
*   Warm-up: 1K iterations [S1].

### Algorithm Steps

1.  **Binarization (Training Only):**
    Real-valued grid parameters $\theta$ are constrained to binary values $\theta'$ using the sign function [S1]:
    $$
    \theta' = \text{sign}(\theta) = \begin{cases} +1 & \text{if } \theta \ge 0 \\ -1 & \text{otherwise} \end{cases}
    $$
    Gradients are propagated using the Straight-Through Estimator (STE) [S1]:
    $$
    \frac{\partial L}{\partial \theta} = \frac{\partial L}{\partial \theta'} \cdot \mathbb{I}(|\theta| \le 1)
    $$
    This stops gradient propagation when $|\theta| > 1$, preventing scale divergence and constraining values to $\{-1, 1\}$ [S1].

2.  **Feature Encoding:**
    For an input 3D coordinate $\mathbf{x} = (x, y, z)$:
    *   **3D Features ($f_{xyz}$):** Compute features by tri-linearly interpolating binary parameters across $L$ levels and concatenating [S1]:
        $$
        f_{xyz} = \left\{ \text{interp}(\mathbf{x}, \text{sign}(\Phi^l_{\theta_{xyz}})) \right\}_{l=1}^L
        $$
    *   **2D Features ($f_{xy}, f_{xz}, f_{yz}$):** Project $\mathbf{x}$ to 2D coordinates: $\mathbf{x}_{xy}=(x,y)$, $\mathbf{x}_{xz}=(x,z)$, $\mathbf{x}_{yz}=(y,z)$ [S1]. Bi-linearly interpolate binary parameters across $M$ levels for each plane and concatenate [S1]:
        $$
        f_{xy} = \left\{ \text{interp}(\mathbf{x}_{xy}, \text{sign}(\Phi^m_{\theta_{xy}})) \right\}_{m=1}^M
        $$
        Repeat for $f_{xz}$ and $f_{yz}$ [S1].
    *   **Concatenation:** Combine all features:
        $$
        f = \{ f_{xyz}, f_{xy}, f_{xz}, f_{yz} \}
        $$

3.  **Positional Encoding:**
    Apply sinusoidal positional encoding $\gamma(\mathbf{x})$ to the input coordinate $\mathbf{x}$ [S1].

4.  **Density Prediction:**
    Feed $\gamma(\mathbf{x})$ and $f$ into the density MLP to obtain density $\sigma$ and embedding feature $\mathbf{e}$ [S1]:
    $$
    (\sigma, \mathbf{e}) = \text{MLP}_{\text{density}}(\gamma(\mathbf{x}), f)
    $$

5.  **Color Prediction:**
    Encode viewing direction $\mathbf{d}$ using spherical harmonics [S1]. Feed $\mathbf{e}$ and $\mathbf{d}$ into the color MLP to obtain color $\mathbf{c}$ [S1]:
    $$
    \mathbf{c} = \text{MLP}_{\text{color}}(\mathbf{e}, \mathbf{d})
    $$

6.  **Loss Calculation:**
    *   **Reconstruction Loss ($L_{\text{recon}}$):** Mean squared error between rendered color $\hat{C}(\mathbf{r})$ and ground truth $C(\mathbf{r})$ for sampled rays $\mathbf{r}$ [S1]:
        $$
        L_{\text{recon}} = \sum_{\mathbf{r} \in \mathcal{R}} ||\hat{C}(\mathbf{r}) - C(\mathbf{r})||_2^2
        $$
    *   **Sparsity Loss ($L_{\text{sparsity}}$):** Cauchy loss to encourage sparse density, accelerating rendering by allowing empty space skipping via occupancy grid [S1]:
        $$
        L_{\text{sparsity}} = \sum_{i,k} \log(1 + 2\sigma(\mathbf{r}_i(t_k))^2)
        $$
    *   **Total Loss:**
        $$
        L = L_{\text{recon}} + \lambda_{\text{sparsity}} L_{\text{sparsity}}
        $$

### Edge Cases and Pitfalls
*   **Hash Collisions:** 3D grids suffer from hash collisions at higher resolutions, limiting performance [S1]. BiRF mitigates this by supplementing the 3D grid with 2D grids, which reinforce features with fewer parameters and alleviate collision impact [S1].
*   **Gradient Vanishing:** The derivative of the sign function is zero almost everywhere [S1]. This is solved by the Straight-Through Estimator (STE), which passes gradients through the threshold function during training [S1].
*   **Scale Divergence:** Large values of real-valued parameters $\theta$ can cause divergence [S1]. STE stops propagating gradients when $|\theta| > 1$, constraining the value to $\{-1, 1\}$ [S1].

## Operating characteristics
*   **Storage Efficiency:** BiRF achieves dramatic storage reduction. The small model (Ours-S2) requires < 0.5 MB, outperforming TensoRF-CP (3.7 MB) and Instant-NGP (24.5 MB) on the mic scene [S1]. The total storage capacity of MLPs varies from 0.06 to 0.11 MB depending on feature dimension $F$ [S1].
*   **Performance:** On Synthetic-NeRF scenes, BiRF achieves a PSNR of 32.03 dB [S1]. On Synthetic-NSVF, 34.48 dB [S1]. On Tanks and Temples, 28.20 dB [S1].
*   **Training Time:** Approximately 6, 9, and 14 minutes for Synthetic-NeRF scenes for Ours-B2 to Ours-B8 models, respectively, on a single NVIDIA RTX A6000 GPU [S1].
*   **Strengths:** Extremely compact storage; no post-optimization required; superior reconstruction quality compared to prior efficient methods with comparable training time [S1].
*   **Limitations:** Performance is bounded by the binary representation capacity; may struggle with very high-frequency details compared to full-precision models if grid resolution is limited [S1].
*   **When to use:** Static scene reconstruction where storage size is a critical constraint and high precision is not required [S1].
*   **When not to use:** Dynamic scenes or scenarios requiring extremely high-fidelity reconstruction where storage is not a bottleneck [S1].

## Background
Binary Radiance Fields were proposed by Seungjoo Shin and Jaesik Park from POSTECH and Seoul National University, respectively [S1]. The paper was published on arXiv in June 2023 (v2 in December 2023) [S1]. The method builds on the Instant-NGP architecture [S1] and uses the occupancy grid implementation from NerfAcc [S1]. It addresses the storage bottleneck of neural radiance fields by introducing binary feature encoding, contrasting with post-processing compression methods like PlenOctrees and Re:NeRF which require additional optimization steps [S1].
