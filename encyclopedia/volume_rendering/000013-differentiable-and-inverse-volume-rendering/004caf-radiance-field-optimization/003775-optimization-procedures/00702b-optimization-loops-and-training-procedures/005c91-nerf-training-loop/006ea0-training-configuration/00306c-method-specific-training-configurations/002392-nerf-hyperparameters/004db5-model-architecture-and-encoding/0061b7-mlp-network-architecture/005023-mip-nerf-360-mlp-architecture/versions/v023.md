# Mip-NeRF 360 MLP Architecture

Also called: Integrated Positional Encoding MLP, PosEnc MLP

## Overview
The Mip-NeRF 360 MLP architecture is a specific neural network configuration for differentiable volume rendering that replaces standard positional encoding with **Integrated Positional Encoding (IPE)** to handle aliasing and frequency ambiguity [S1, unofficial]. It consists of two coupled Multi-Layer Perceptrons (MLPs): a density network that processes 3D positions using IPE, and a color network that processes the resulting bottleneck features along with view-dependent directions [S1, unofficial]. It is distinguished from standard NeRF by its explicit modeling of the ray segment's mean and covariance during encoding, and from hash-based methods by its reliance on dense linear layers with specific skip connections and bias parameters [S1, unofficial].

## How it works
The method maps a 3D position $\mathbf{x}$ and viewing direction $\mathbf{d}$ to density $\sigma$ and color $\mathbf{c}$ [S1, unofficial]. It operates in two stages: density prediction using integrated positional encoding, and color prediction using directional encoding.

### Inputs and Outputs
**Inputs:**
*   **Ray Segment Statistics:** Mean position $\boldsymbol{\mu} \in \mathbb{R}^3$ and $3 \times 3$ covariance matrix $\boldsymbol{\Sigma} \in \mathbb{R}^{3 \times 3}$ representing the Gaussian approximation of the ray segment [S1, unofficial].
*   **View/Reflection Direction:** $\mathbf{d} \in S^2$ [S1, unofficial].
*   **Optional Inputs:** Surface normals $\mathbf{n}$ (if predicted or provided), roughness $\alpha$ (if predicted), and GLO vectors for global lighting [S1, unofficial].

**Outputs:**
*   **Density:** $\sigma \in \mathbb{R}$ [S1, unofficial].
*   **Color:** $\mathbf{c} \in \mathbb{R}^3$ [S1, unofficial].
*   **Normals:** $\mathbf{n} \in \mathbb{R}^3$ (optional, computed from density gradient) [S1, unofficial].
*   **Roughness:** $\alpha \in \mathbb{R}$ (optional) [S1, unofficial].

### Data Structures and Parameters
The architecture is defined by a configuration object containing the following fields [S1, unofficial]:

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `net_depth` | int | 8 | Depth of the density MLP. |
| `net_width` | int | 256 | Width of the density MLP. |
| `bottleneck_width` | int | 256 | Width of the feature vector connecting density and color networks. |
| `net_depth_viewdirs` | int | 1 | Depth of the color MLP. |
| `net_width_viewdirs` | int | 128 | Width of the color MLP. |
| `min_deg_point` | int | 0 | Minimum degree of positional encoding for points. |
| `max_deg_point` | int | 12 | Maximum degree of positional encoding for points. |
| `skip_layer` | int | 4 | Frequency of skip connections in the density MLP. |
| `skip_layer_dir` | int | 4 | Frequency of skip connections in the color MLP. |
| `deg_view` | int | 4 | Degree of spherical harmonic encoding for directions. |
| `density_bias` | float | -1.0 | Bias added to raw density before activation. |
| `density_noise` | float | 0.0 | Standard deviation of noise added to raw density. |
| `rgb_bias` | float | 0.0 | Bias added to raw color before activation. |
| `rgb_padding` | float | 0.001 | Padding applied to RGB output range. |
| `use_reflections` | bool | False | Use reflection directions instead of view directions. |
| `use_directional_enc` | bool | False | Use Integrated Directional Encoding (IDE). |
| `basis_shape` | str | 'icosahedron' | Basis shape for IPE ('octahedron' or 'icosahedron'). |
| `basis_subdivisions` | int | 2 | Tessellation count for the basis shape. |
| `enable_pred_normals` | bool | False | Enable explicit normal prediction. |
| `disable_density_normals` | bool | True | Disable gradient-based normal computation from density. |
| `use_diffuse_color` | bool | False | Predict diffuse and specular colors separately. |
| `use_specular_tint` | bool | False | Predict a tint vector for specular color. |
| `use_n_dot_v` | bool | False | Feed $\mathbf{n} \cdot \mathbf{d}$ to the color network. |
| `bottleneck_noise` | float | 0.0 | Noise added to the bottleneck vector. |
| `warp_fn` | callable | None | Function to linearize means/covs. |

### Algorithm Steps

1.  **Setup and Basis Precomputation:**
    Generate the transpose of the basis matrix for integrated positional encoding using the specified `basis_shape` and `basis_subdivisions`. Store as $B^T$ [S1, unofficial].
    $$ B^T = \text{generate\_basis}(\text{basis\_shape}, \text{basis\_subdivisions})^T $$

2.  **Directional Encoding Function Selection:**
    If `use_directional_enc` is True, generate an Integrated Directional Encoding (IDE) function using `deg_view`. Otherwise, define a standard positional encoding function for directions with `min_deg=0`, `max_deg=deg_view`, and `append_identity=True` [S1, unofficial].

3.  **Linearization (Optional):**
    If `warp_fn` is provided, linearize the input means $\boldsymbol{\mu}$ and covariances $\boldsymbol{\Sigma}$ using `track_linearize` [S1, unofficial].

4.  **Lift and Diagonalize:**
    Lift the means and covariances into the basis space and diagonalize the covariance to obtain lifted means $\boldsymbol{\mu}'$ and lifted variances $\boldsymbol{\sigma}'^2$ [S1, unofficial].
    $$ \boldsymbol{\mu}', \boldsymbol{\sigma}'^2 = \text{lift\_and\_diagonalize}(\boldsymbol{\mu}, \boldsymbol{\Sigma}, B^T) $$

5.  **Integrated Positional Encoding (IPE):**
    Compute the integrated positional encoding input $x$ by integrating the sinusoidal features over the Gaussian distribution defined by $\boldsymbol{\mu}'$ and $\boldsymbol{\sigma}'^2$, using `min_deg_point` and `max_deg_point` [S1, unofficial].
    $$ x = \text{integrated\_pos\_enc}(\boldsymbol{\mu}', \boldsymbol{\sigma}'^2, \text{min\_deg\_point}, \text{max\_deg\_point}) $$

6.  **Density Network Forward Pass:**
    Initialize $h = x$. Iterate $i$ from 0 to `net_depth` - 1:
    *   Apply dense layer: $h = \text{Activation}(W_i h + b_i)$, where width is `net_width` and activation is `net_activation` [S1, unofficial].
    *   **Skip Connection:** If $i > 0$ and $i \pmod{\text{skip\_layer}} == 0$, concatenate the original input $x$ to $h$: $h = \text{concat}(h, x)$ [S1, unofficial].
    
    Compute raw density:
    $$ \sigma_{\text{raw}} = \text{Dense}_{\text{out}}(h)[0] $$
    where $\text{Dense}_{\text{out}}$ has width 1 [S1, unofficial].

7.  **Density Noise and Activation:**
    If `density_noise` > 0, add Gaussian noise: $\sigma_{\text{raw}} \leftarrow \sigma_{\text{raw}} + \mathcal{N}(0, \text{density\_noise})$ [S1, unofficial].
    Apply density activation (typically softplus or similar) with bias:
    $$ \sigma = \text{density\_activation}(\sigma_{\text{raw}} + \text{density\_bias}) $$

8.  **Normal Computation (Gradient-Based):**
    If `disable_density_normals` is False, compute normals from the gradient of the raw density with respect to the input position $\boldsymbol{\mu}$ [S1, unofficial].
    *   Flatten $\boldsymbol{\mu}$ and $\boldsymbol{\Sigma}$ for batched gradient computation.
    *   Compute $\nabla_{\boldsymbol{\mu}} \sigma_{\text{raw}}$ using automatic differentiation [S1, unofficial].
    *   Normalize: $\mathbf{n} = -\frac{\nabla_{\boldsymbol{\mu}} \sigma_{\text{raw}}}{\|\nabla_{\boldsymbol{\mu}} \sigma_{\text{raw}}\|_2}$ [S1, unofficial].
    *   *Note:* Normals are computed from raw density for numerical stability [S1, unofficial].

9.  **Color Network Input Preparation:**
    *   Broadcast the bottleneck features (output of density network before final layer, or a separate bottleneck vector) to match the expected shape.
    *   Compute directional encoding $e_d$ using the function selected in Step 2 on the view/reflection direction $\mathbf{d}$ [S1, unofficial].
    *   If `use_n_dot_v` is True, compute $n\_dot\_v = \mathbf{n} \cdot \mathbf{d}$ and append to features [S1, unofficial].
    *   If `glo_vec` is provided, broadcast and append it [S1, unofficial].
    *   Concatenate all feature components along the last axis to form input $x_c$ for the color network [S1, unofficial].

10. **Color Network Forward Pass:**
    Initialize $h_c = x_c$. Iterate $i$ from 0 to `net_depth_viewdirs` - 1:
    *   Apply dense layer: $h_c = \text{Activation}(W_{c,i} h_c + b_{c,i})$, width `net_width_viewdirs` [S1, unofficial].
    *   **Skip Connection:** If $i > 0$ and $i \pmod{\text{skip\_layer\_dir}} == 0$, concatenate $x_c$ to $h_c$ [S1, unofficial].

11. **RGB Output and Tone Mapping:**
    Compute raw RGB:
    $$ \mathbf{c}_{\text{raw}} = \text{Dense}_{\text{rgb}}(h_c) $$
    Apply premultiplier, bias, and activation:
    $$ \mathbf{c}_{\text{pre}} = \text{rgb\_activation}(\text{rgb\_premultiplier} \cdot \mathbf{c}_{\text{raw}} + \text{rgb\_bias}) $$
    
    If `use_diffuse_color` is True:
    *   Compute diffuse component: $\mathbf{c}_{\text{diffuse}} = \sigma(\mathbf{c}_{\text{raw, diffuse}} - \ln(3))$ [S1, unofficial].
    *   Compute specular component: If `use_specular_tint`, $\mathbf{c}_{\text{spec}} = \text{tint} \cdot \mathbf{c}_{\text{pre}}$; else $\mathbf{c}_{\text{spec}} = 0.5 \cdot \mathbf{c}_{\text{pre}}$ [S1, unofficial].
    *   Combine and tone map: $\mathbf{c} = \text{clip}(\text{linear\_to\_srgb}(\mathbf{c}_{\text{spec}} + \mathbf{c}_{\text{diffuse}}), 0, 1)$ [S1, unofficial].
    
    If `use_diffuse_color` is False, $\mathbf{c} = \mathbf{c}_{\text{pre}}$ [S1, unofficial].

12. **RGB Padding:**
    Apply final padding to ensure output range is $[-\text{rgb\_padding}, 1 + \text{rgb\_padding}]$:
    $$ \mathbf{c}_{\text{final}} = \mathbf{c} \cdot (1 + 2 \cdot \text{rgb\_padding}) - \text{rgb\_padding} $$

### Pseudocode

import jax.numpy as jnp
import jax
from jax import random

def mipnerf360_mlp_forward(
    means,           # (..., 3) Mean positions
    covs,            # (..., 3, 3) Covariance matrices
    viewdirs,        # (..., 3) View directions
    config,          # Configuration object
    rng,             # Random key
    params           # Network parameters
):
    """
    Forward pass for Mip-NeRF 360 MLP.
    Returns: density, color, normals (optional)
    """
    
    # 1. Setup Basis
    # Precomputed in init, accessed here
    pos_basis_t = config.pos_basis_t 
    
    # 2. Directional Encoding Function
    if config.use_directional_enc:
        dir_enc_fn = config.ide_fn
    else:
        def dir_enc_fn(d):
            return pos_enc(d, min_deg=0, max_deg=config.deg_view, append_identity=True)

    # 3. Linearization (Optional)
    if config.warp_fn is not None:
        means, covs = track_linearize(config.warp_fn, means, covs)

    # 4. Lift and Diagonalize
    lifted_means, lifted_vars = lift_and_diagonalize(means, covs, pos_basis_t)

    # 5. Integrated Positional Encoding
    x = integrated_pos_enc(lifted_means, lifted_vars, 
                           config.min_deg_point, config.max_deg_point)

    # 6. Density Network
    h = x
    for i in range(config.net_depth):
        h = dense_layer(h, params['density_weights'][i], params['density_biases'][i])
        h = activation(h) # e.g., ReLU
        if i > 0 and i % config.skip_layer == 0:
            h = jnp.concatenate([h, x], axis=-1)
            # Note: width increases after skip connection in original impl, 
            # handled by weight matrix dimensions in params.

    raw_density = dense_layer(h, params['density_out_weight'], params['density_out_bias'])[..., 0]
    
    # 7. Density Noise and Activation
    if config.density_noise > 0:
        noise = random.normal(rng, raw_density.shape)
        raw_density += config.density_noise * noise
    
    density = density_activation(raw_density + config.density_bias)

    # 8. Normal Computation (if enabled)
    normals = None
    if not config.disable_density_normals:
        # Compute gradient of raw_density w.r.t means
        # Using jax.vmap for batched gradients
        def predict_density_single(m):
            # Re-run IPE for single point to get scalar raw_density
            # This is computationally expensive; usually optimized in practice
            # Here we assume a helper exists or use jax.value_and_grad on the batch
            pass 
        
        # Simplified: assume raw_grad_density is computed via vmap of value_and_grad
        raw_grad_density = compute_density_gradient(means, covs, params, config)
        normals = -l2_normalize(raw_grad_density)

    # 9. Color Network Input
    # Bottleneck is typically the output of the last density layer before the final density head,
    # or a separate projected vector. Assuming 'bottleneck' is extracted from 'h' before final layer.
    bottleneck = h # In many implementations, this is the output of the last hidden layer
    
    # Broadcast bottleneck if necessary
    dir_enc = dir_enc_fn(viewdirs)
    
    # Append directional encoding
    # Ensure shapes match: bottleneck (..., W), dir_enc (..., D)
    dir_enc_expanded = jnp.broadcast_to(
        dir_enc[..., None, :], 
        bottleneck.shape[:-1] + (dir_enc.shape[-1],)
    )
    
    x_c = [bottleneck, dir_enc_expanded]
    
    if config.use_n_dot_v and normals is not None:
        n_dot_v = jnp.sum(normals * viewdirs[..., None, :], axis=-1, keepdims=True)
        x_c.append(n_dot_v)
        
    if config.glo_vec is not None:
        glo_expanded = jnp.broadcast_to(
            config.glo_vec[..., None, :],
            bottleneck.shape[:-1] + (config.glo_vec.shape[-1],)
        )
        x_c.append(glo_expanded)
        
    x_c = jnp.concatenate(x_c, axis=-1)

    # 10. Color Network
    h_c = x_c
    for i in range(config.net_depth_viewdirs):
        h_c = dense_layer(h_c, params['color_weights'][i], params['color_biases'][i])
        h_c = activation(h_c)
        if i > 0 and i % config.skip_layer_dir == 0:
            h_c = jnp.concatenate([h_c, x_c], axis=-1)

    # 11. RGB Output
    raw_rgb = dense_layer(h_c, params['color_out_weight'], params['color_out_bias'])
    
    if config.use_diffuse_color:
        # Separate diffuse and specular heads would be needed here
        # Simplified assumption: raw_rgb contains both or is split
        diffuse_linear = sigmoid(raw_rgb[..., 0:3] - jnp.log(3.0)) # Example split
        if config.use_specular_tint:
            specular_linear = config.tint * raw_rgb[..., 0:3]
        else:
            specular_linear = 0.5 * raw_rgb[..., 0:3]
        rgb = clip(linear_to_srgb(specular_linear + diffuse_linear), 0.0, 1.0)
    else:
        rgb = rgb_activation(config.rgb_premultiplier * raw_rgb + config.rgb_bias)

    # 12. RGB Padding
    rgb_final = rgb * (1 + 2 * config.rgb_padding) - config.rgb_padding
    
    return density, rgb_final, normals

### Edge Cases and Pitfalls
*   **Reflections Require Normals:** If `use_reflections` is True, normals must be available (either predicted or computed via density gradient). If `enable_pred_normals` is False and `disable_density_normals` is True, a `ValueError` is raised [S1, unofficial].
*   **Reflection Direction Flip:** View directions point from camera to point. Reflection functions typically assume directions pointing toward the camera. Therefore, view directions must be flipped (`-viewdirs`) before computing reflections [S1, unofficial].
*   **Normal Stability:** Normals are computed from the gradient of the *raw* (pre-activation) density, not the activated density, to avoid numerical instability caused by steep or flat activation gradients [S1, unofficial].
*   **Skip Connection Widths:** The width of the hidden layers increases when skip connections are concatenated. The weight matrices for subsequent layers must account for this increased input dimension [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The density network has $O(\text{net\_depth} \cdot \text{net\_width}^2)$ operations per sample. The color network has $O(\text{net\_depth\_viewdirs} \cdot \text{net\_width\_viewdirs}^2)$. The IPE computation adds $O(\text{max\_deg\_point} \cdot \text{basis\_size})$ per sample.
*   **Memory Complexity:** The model stores weights for two MLPs. The basis matrix $B^T$ is precomputed and stored.
*   **Strengths:** Integrated positional encoding reduces aliasing artifacts and improves reconstruction of high-frequency details compared to standard positional encoding [S1, unofficial]. The specific bias and padding parameters help stabilize training and ensure valid color ranges.
*   **Limitations:** The MLP architecture is computationally heavier than hash-based or grid-based methods (e.g., Instant NGP) for equivalent resolution. The use of covariance matrices for IPE adds computational overhead during the lifting and diagonalization steps [S1, unofficial].
*   **When to Use:** Suitable for high-quality novel view synthesis where aliasing is a concern and computational resources allow for dense MLP evaluation. Not ideal for real-time applications requiring very high resolution.

## Background
The Mip-NeRF 360 MLP architecture originates from the "Mip-NeRF 360" paper by Barron et al. (2022), which extended the original Mip-NeRF approach to unbounded scenes [S1, unofficial]. It was implemented in the `google-research/multinerf` repository [S1, unofficial]. The architecture integrates the concept of integrated positional encoding to handle the frequency ambiguity of rays, a key innovation over the original NeRF MLP [S1, unofficial].
