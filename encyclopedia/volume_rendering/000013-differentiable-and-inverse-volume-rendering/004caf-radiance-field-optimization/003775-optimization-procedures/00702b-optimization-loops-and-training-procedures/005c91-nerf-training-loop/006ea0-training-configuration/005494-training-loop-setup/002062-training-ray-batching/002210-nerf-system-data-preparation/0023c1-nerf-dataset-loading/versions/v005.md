# NeRF Dataset Loading

Also called: Blender Dataset Loader, Blender Dataset Loading, NeRF Synthetic Data Loading, NeRF Synthetic Dataset Loading, NeRF/Blender Transform Reader, NeRFDatasetLoader

## Overview
Loads the NeRF-Synthetic (Blender) dataset by parsing JSON metadata for camera poses and images, handling coordinate system conversions, half-resolution resizing, and alpha compositing to return normalized RGBA images and camera parameters [S1, S4, unofficial]. It differs from [LLFF Dataset Loading](2818-llff-dataset-loading.md) by assuming known, precise camera poses from synthetic renders rather than estimating them from sparse, unstructured real-world photos [S1, S4, unofficial].

## How it works
**Inputs:**
- `dataset_path`: Path to the root directory of the dataset [S3, S4, unofficial].
- `mode`: String indicating 'train', 'test', or 'val' [S3, unofficial]. Determines which JSON file to load (`transforms_train.json`, `transforms_test.json`, or `transforms_val.json`) [S3, unofficial].
- `half_res`: Boolean flag to resize images to half resolution. Default: `True` [S1, unofficial].
- `white_background`: Boolean flag to composite transparent images over a white background instead of black. Default: `False` [S2, unofficial].
- `extension`: Image file extension. Default: `".png"` [S2, unofficial].

**Outputs:**
- `images`: Tensor of shape `[N, H, W, 4]` containing float32 RGBA values in `[0, 1]` [S1, unofficial].
- `poses`: Tensor of shape `[N, 4, 4]` containing camera-to-world matrices [S1, unofficial].
- `focal`: Float value for the focal length [S1, unofficial].
- `near`: Float value for the near plane bound. Fixed at `2.0` for Blender data [S1, unofficial].
- `far`: Float value for the far plane bound. Fixed at `6.0` for Blender data [S1, unofficial].

**Data Structures:**
- JSON Metadata: Contains a `camera_angle_x` field and a `frames` array [S2, S4, unofficial]. Each frame object contains `file_path` and `transform_matrix` (a 4x4 matrix) [S2, S4, unofficial].

**Steps:**
1. **Load Metadata**: Construct the path to `transforms_{split}.json` using `dataset_path` and `mode` [S3, S4, unofficial]. Load the JSON file into a dictionary `data` [S3, S4, unofficial].
2. **Extract FOV**: Read `camera_angle_x` from `data` [S2, unofficial].
3. **Initialize Containers**: Prepare lists or tensors for images and poses [S3, unofficial].
4. **Iterate Frames**: For each frame in `data['frames']`:
   a. **Load Image**: Construct the image path by joining the frame's `file_path` with the `extension` (default `.png`) [S2, S3, unofficial]. Load the image using a library like `cv2` or `PIL` [S3, S4, unofficial].
   b. **Normalize Pixels**: Convert image data to `float32` and normalize pixel values to `[0, 1]` by dividing by `255.0` [S2, S4, unofficial].
   c. **Handle Alpha**: If the image has an alpha channel (RGBA):
      i. Extract RGB and Alpha channels.
      ii. Determine background color: `bg = [1, 1, 1]` if `white_background` is `True`, else `bg = [0, 0, 0]` [S2, S4, unofficial].
      iii. Composite: `rgb_composited = rgb * alpha + bg * (1 - alpha)` [S2, S4, unofficial].
      iv. Result is an RGB image in `[0, 1]` [S2, unofficial].
   d. **Resize (Optional)**: If `half_res` is `True` (or `config.factor == 2` in some implementations):
      i. Resize the image to half its width and height [S1, S4, unofficial].
      ii. Use `cv2.INTER_AREA` or `cv2.INTER_LANCZOS4` interpolation [S1, S4, unofficial].
      iii. Halve the focal length calculated in step 5 [S1, unofficial].
   e. **Compute Focal Length**: Calculate focal length `f` using the formula:
      $$f = \frac{0.5 \times \text{width}}{\tan(0.5 \times \text{camera\_angle\_x})}$$
      [S1, S3, S4, unofficial].
   f. **Convert Poses**:
      i. Parse `transform_matrix` from the frame data [S5, unofficial]. This is a camera-to-world (c2w) matrix in OpenGL/Blender coordinates (Y up, Z back) [S2, unofficial].
      ii. Convert to COLMAP coordinates (Y down, Z forward) by negating the Y and Z columns of the rotation part:
          $$c2w_{new}[:3, 1:3] = -c2w_{old}[:3, 1:3]$$
          [S2, unofficial].
      iii. Store the converted `c2w` matrix [S4, unofficial].
5. **Finalize**: Stack images into `[N, H, W, 4]` (or `[N, H, W, 3]` if alpha was composited and stored as RGB) [S1, unofficial]. Stack poses into `[N, 4, 4]` [S1, unofficial]. Return `images`, `poses`, `focal`, `near=2.0`, `far=6.0` [S1, unofficial].

**Pseudocode:**
```python
import json
import os
import numpy as np
import cv2
import math

def load_nerf_synthetic_dataset(dataset_path, mode, half_res=True, white_background=False):
    """
    Loads NeRF-Synthetic (Blender) dataset.
    
    Args:
        dataset_path (str): Path to the dataset root.
        mode (str): 'train', 'test', or 'val'.
        half_res (bool): If True, resize images to half resolution.
        white_background (bool): If True, composite alpha over white background.
        
    Returns:
        images (np.ndarray): Shape [N, H, W, 4], float32, [0, 1].
        poses (np.ndarray): Shape [N, 4, 4], float32, camera-to-world matrices.
        focal (float): Focal length.
        near (float): Near plane bound (2.0).
        far (float): Far plane bound (6.0).
    """
    # 1. Load Metadata
    if mode == "test":
        file_name = "transforms_test.json"
    elif mode == "train":
        file_name = "transforms_train.json"
    elif mode == "val":
        file_name = "transforms_val.json"
    else:
        raise ValueError(f"Unknown mode: {mode}")
        
    transforms_path = os.path.join(dataset_path, file_name)
    with open(transforms_path, 'r') as f:
        data = json.load(f)
        
    # 2. Extract FOV
    camera_angle_x = data['camera_angle_x']
    
    # 3. Initialize Containers
    images = []
    poses = []
    
    # 4. Iterate Frames
    for frame in data['frames']:
        # 4a. Load Image
        file_path = frame['file_path']
        if not file_path.endswith('.png'):
            file_path += '.png'
        img_path = os.path.join(dataset_path, file_path)
        
        img_bgr = cv2.imread(img_path, cv2.IMREAD_UNCHANGED)
        if img_bgr is None:
            raise FileNotFoundError(f"Could not load image: {img_path}")
            
        img_rgb = cv2.cvtColor(img_bgr, cv2.COLOR_BGR2RGB)
        
        # 4b. Normalize Pixels
        img_float = img_rgb.astype(np.float32) / 255.0
        
        # 4c. Handle Alpha
        if img_float.shape[2] == 4:
            rgb = img_float[:, :, :3]
            alpha = img_float[:, :, 3:4]
            bg_color = np.array([1.0, 1.0, 1.0]) if white_background else np.array([0.0, 0.0, 0.0])
            rgb_composited = rgb * alpha + bg_color * (1.0 - alpha)
            img_float = np.concatenate([rgb_composited, alpha], axis=2)
        else:
            img_float = np.concatenate([img_float, np.ones_like(img_float[:, :, :1])], axis=2)
            
        # 4d. Resize (Optional)
        h, w = img_float.shape[:2]
        
        if half_res:
            new_w, new_h = w // 2, h // 2
            img_float = cv2.resize(img_float, (new_w, new_h), interpolation=cv2.INTER_AREA)
            h, w = new_h, new_w
            
        images.append(img_float)
        
        # 4f. Convert Poses
        c2w_opengl = np.array(frame['transform_matrix'], dtype=np.float32)
        c2w_colmap = c2w_opengl.copy()
        c2w_colmap[:3, 1:3] *= -1
        poses.append(c2w_colmap)
        
    # 5. Finalize
    images = np.stack(images, axis=0)
    poses = np.stack(poses, axis=0)
    
    # Calculate focal length based on final image width
    focal = 0.5 * w / math.tan(0.5 * camera_angle_x)
    
    near = 2.0
    far = 6.0
    
    return images, poses, focal, near, far
```

**Edge Cases and Pitfalls:**
- **Coordinate Systems**: Blender uses a right-handed coordinate system with Y up and Z back, while COLMAP and many rendering engines use Y down and Z forward [S2, unofficial]. Failure to negate the Y and Z columns of the camera-to-world matrix results in inverted camera orientations [S2, unofficial].
- **Alpha Compositing**: NeRF-Synthetic images often have transparent backgrounds [S2, unofficial]. The background color (black or white) must be chosen consistently with the training setup [S2, unofficial].
- **Resolution**: The `half_res` flag is critical for memory management [S1, unofficial]. If `half_res=True`, the focal length must be halved to maintain the correct field of view [S1, unofficial].
- **File Extensions**: Ensure the correct extension (`.png`) is appended to the `file_path` from the JSON [S2, unofficial].

## Background
The NeRF-Synthetic dataset is loaded by this method [S1, unofficial]. It consists of 8 scenes rendered using Blender, with known camera poses and high-quality images [S1, unofficial]. The dataset loader described here is a standard implementation found in many NeRF codebases (e.g., [S1, S3, S4, unofficial]) to facilitate training on this benchmark.
