# Mip-NeRF 360 MLP Architecture

Also called: Integrated Positional Encoding MLP, PosEnc MLP

## Overview
The Mip-NeRF 360 MLP architecture is a specific neural network configuration for radiance field optimization that replaces standard positional encoding with **integrated positional encoding** to handle aliasing and frequency ambiguity along rays [S1, unofficial]. It consists of two distinct Multi-Layer Perceptrons (MLPs): a density network that processes 3D positions and a color network that processes viewing directions, connected by a bottleneck vector [S1, unofficial]. This architecture is designed to be robust to the "Mip-NeRF" effect where a single ray samples a volume with significant spatial extent, ensuring that high-frequency details are not aliased during rendering [S1, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   $\mathbf{x} \in \mathbb{R}^3$: 3D position.
*   $\mathbf{d} \in S^2$: Viewing direction (or reflection direction $\mathbf{r}$ if reflections are enabled).
*   $\boldsymbol{\mu} \in \mathbb{R}^3$: Mean of the Gaussian distribution along the ray segment.
*   $\boldsymbol{\Sigma} \in \mathbb{R}^{3 \times 3}$: Covariance matrix of the Gaussian distribution along the ray segment.
*   $\mathbf{n} \in \mathbb{R}^3$: Surface normal (optional, required if `use_reflections` is True).

**Outputs:**
*   $\sigma \in \mathbb{R}$: Volume density.
*   $\mathbf{c} \in \mathbb{R}^3$: Color (RGB).
*   $\mathbf{n}_{pred} \in \mathbb{R}^3$: Predicted normal (optional).
*   $\rho \in \mathbb{R}$: Predicted roughness (optional).

### Data Structures
The architecture is defined by a configuration object containing the following fields:
*   `net_depth`: Integer, depth of density MLP. Default: 8.
*   `net_width`: Integer, width of density MLP. Default: 256.
*   `bottleneck_width`: Integer, width of the bottleneck vector. Default: 256.
*   `net_depth_viewdirs`: Integer, depth of color MLP. Default: 1.
*   `net_width_viewdirs`: Integer, width of color MLP. Default: 128.
*   `min_deg_point`: Integer, minimum degree of positional encoding for points. Default: 0.
*   `max_deg_point`: Integer, maximum degree of positional encoding for points. Default: 12.
*   `skip_layer`: Integer, frequency of skip connections in density MLP. Default: 4.
*   `skip_layer_dir`: Integer, frequency of skip connections in color MLP. Default: 4.
*   `deg_view`: Integer, degree of directional encoding. Default: 4.
*   `density_bias`: Float, bias added to raw density. Default: -1.0.
*   `density_noise`: Float, standard deviation of density noise. Default: 0.0.
*   `rgb_bias`: Float, bias added to raw color. Default: 0.0.
*   `rgb_padding`: Float, padding for RGB output range. Default: 0.001.
*   `use_reflections`: Boolean, enable reflection directions. Default: False.
*   `use_directional_enc`: Boolean, use Integrated Directional Encoding (IDE). Default: False.
*   `basis_shape`: String, 'icosahedron' or 'octahedron'. Default: 'icosahedron'.
*   `basis_subdivisions`: Integer, tessellation count for basis. Default: 2.
*   `enable_pred_normals`: Boolean, enable normal prediction via gradient. Default: False.
*   `disable_density_normals`: Boolean, disable density gradient normals. Default: False.
*   `use_diffuse_color`: Boolean, split diffuse/specular. Default: False.
*   `use_specular_tint`: Boolean, predict specular tint. Default: False.
*   `use_n_dot_v`: Boolean, include $\mathbf{n} \cdot \mathbf{v}$ in color input. Default: False.
*   `bottleneck_noise`: Float, standard deviation of bottleneck noise. Default: 0.0.
*   `warp_fn`: Callable, warping function for linearization (optional).

def lift_and_diagonalize(mu, Sigma, pos_basis_t):
    """
    Lifts mean and covariance into the basis space and diagonalizes.
    lifted_mu = B^T mu
    lifted_vars = diag(B^T Sigma B)
    """
    lifted_mu = jnp.dot(pos_basis_t, mu) # (..., num_bases)
    # Sigma is (..., 3, 3), pos_basis_t is (num_bases, 3)
    # Result is (..., num_bases, num_bases)
    lifted_Sigma = jnp.einsum('...ij,kj->...ki', Sigma, pos_basis_t)
    lifted_Sigma = jnp.einsum('...ij,kj->...ki', lifted_Sigma, pos_basis_t) # Simplified
    # Actually: lifted_Sigma = B^T Sigma B
    # Diagonalize: take diagonal
    lifted_vars = jnp.einsum('...ij,ij->...i', lifted_Sigma, jnp.eye(3)) # Approximation
    # Correct: lifted_vars = diag(B^T Sigma B)
    # B^T is (K, 3), Sigma is (3, 3) -> (K, 3)
    # (K, 3) @ (3, 3) @ (3, K)^T -> (K, K)
    # We only need diagonal
    lifted_vars = jnp.sum(lifted_Sigma * jnp.eye(lifted_Sigma.shape[-1])[None, None, :, :], axis=-1)
    return lifted_mu, lifted_vars

def integrated_pos_enc(mu, var, min_deg, max_deg):
    """
    Computes integrated positional encoding for a Gaussian.
    Input: mu (..., D), var (..., D)
    Output: PE (..., D * 2 * max_deg)
    """
    # Standard PE: [sin(2^k pi mu), cos(2^k pi mu)]
    # Integrated PE: [sin(2^k pi mu) * exp(-2 (2^k pi)^2 var), ...]
    # This accounts for the variance of the sampling distribution
    freq_bands = 2.0 ** jnp.arange(min_deg, max_deg)
    pe = []
    for k in freq_bands:
        freq = k * jnp.pi
        # Mean component
        sin_mu = jnp.sin(freq * mu)
        cos_mu = jnp.cos(freq * mu)
        # Variance component (attenuation)
        var_atten = jnp.exp(-0.5 * freq**2 * var)
        
        pe.append(sin_mu * var_atten)
        pe.append(cos_mu * var_atten)
        
    return jnp.concatenate(pe, axis=-1)

### Parameters and Typical Values
*   **Network Depth:** The density network typically has 8 layers (`net_depth=8`), while the color network has 1 layer (`net_depth_viewdirs=1`) [S1, unofficial].
*   **Network Width:** Density network width is 256 (`net_width=256`), color network width is 128 (`net_width_viewdirs=128`), and the bottleneck width is 256 (`bottleneck_width=256`) [S1, unofficial].
*   **Positional Encoding:** Minimum degree 0, maximum degree 12 (`min_deg_point=0`, `max_deg_point=12`) [S1, unofficial].
*   **Directional Encoding:** Degree 4 (`deg_view=4`) [S1, unofficial].
*   **Skip Connections:** Applied every 4 layers in both networks (`skip_layer=4`, `skip_layer_dir=4`) [S1, unofficial].
*   **Density Bias:** -1.0 (`density_bias=-1.0`) [S1, unofficial].
*   **RGB Padding:** 0.001 (`rgb_padding=0.001`) [S1, unofficial].

### Edge Cases and Pitfalls
*   **Reflections Require Normals:** If `use_reflections` is True, normals must be computed. This requires either `enable_pred_normals` to be True or `disable_density_normals` to be False. If neither is set, a `ValueError` is raised [S1, unofficial].
*   **Reflection Direction Flip:** When computing reflection directions, view directions are flipped (`-viewdirs`) before reflection because they point from the camera to the point, whereas the reflection utility assumes they point toward the camera [S1, unofficial].
*   **Normal Stability:** Normals are computed from the gradient of the **raw** (pre-activation) density, not the post-activation density. This is numerically more stable, especially when the activation function has a steep or flat gradient [S1, unofficial].
*   **Basis Shape:** The basis shape for integrated positional encoding can be 'icosahedron' or 'octahedron'. The default is 'icosahedron' with 2 subdivisions [S1, unofficial].

## Operating characteristics

### Time and Memory Complexity
*   **Time Complexity:** The complexity is dominated by the MLP forward passes. The density network has $L_d$ layers of width $W_d$, and the color network has $L_c$ layers of width $W_c$. The integrated positional encoding adds a factor of $O(D \cdot \log(\text{max\_deg}))$ per point, where $D$ is the dimensionality (3). The overall complexity per ray sample is $O(L_d W_d^2 + L_c W_c^2)$.
*   **Memory Complexity:** The memory usage is proportional to the number of parameters in the MLPs. For the default configuration, the total parameters are approximately $3 \times 256 + 256 \times 256 + 256 \times 128 + 128 \times 3 \approx 100,000$ parameters, which is very small. The memory for the basis matrix is negligible.

### Measured Performance
*   The Mip-NeRF 360 architecture is designed for outdoor scenes with large depth ranges and high frequencies. It significantly reduces aliasing artifacts compared to standard NeRF [S1, unofficial].
*   Performance is measured in terms of PSNR and SSIM on the Blender and Tanks & Temples datasets, as well as the new Mip-NeRF 360 dataset [S1, unofficial].

### Strengths and Limitations
*   **Strengths:** Robust to aliasing, handles large depth ranges well, computationally efficient due to small MLP size.
*   **Limitations:** The MLP architecture may struggle with very high-frequency details compared to hash-based or grid-based methods (e.g., Instant NGP). The integrated positional encoding requires careful tuning of the basis shape and subdivisions.

### When to Use
*   Use this architecture when rendering outdoor scenes or scenes with large depth variations where aliasing is a concern.
*   Use when computational resources are limited and a small model size is preferred.

### When Not to Use
*   Do not use if the scene requires extremely high-frequency details that the MLP cannot capture.
*   Do not use if real-time rendering is required and the overhead of integrated positional encoding is too high (though the MLP itself is fast).

## Background

### Origin
The Mip-NeRF 360 MLP architecture was introduced in the paper "Mip-NeRF 360: Unbounded Anti-Aliased Neural Radiance Fields" by T. Müller et al. (2022) [S1, unofficial]. It builds upon the original Mip-NeRF work by extending the integrated positional encoding to handle unbounded scenes and 360-degree views.

### History and Development
The architecture was developed to address the limitations of the original NeRF, which suffered from aliasing and poor performance on unbounded scenes. The key innovation is the use of integrated positional encoding, which accounts for the spatial extent of the sampling distribution along the ray.

### Usage
The architecture is widely used in research and applications requiring high-quality rendering of large-scale scenes, such as urban environments and natural landscapes. It is implemented in the `multinerf` library from Google Research [S1, unofficial].
