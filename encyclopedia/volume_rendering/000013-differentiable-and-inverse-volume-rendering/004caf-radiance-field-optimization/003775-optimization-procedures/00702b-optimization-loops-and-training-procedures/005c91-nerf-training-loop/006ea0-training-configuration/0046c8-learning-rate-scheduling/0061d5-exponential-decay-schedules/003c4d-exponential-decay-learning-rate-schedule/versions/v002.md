# Exponential Decay Learning Rate Schedule

Also called: Adam with Exponential Decay, Exponential Decay Schedule, ExponentialSchedule, Instant NGP LR Schedule, LambdaLR Exponential Decay, Training Optimizer and Schedule

## Overview
An exponentially decaying schedule that transitions from an initial value to a final value using a base raised to a normalized step exponent [S1, unofficial]. It is used in NeRF training to reduce the learning rate after an initial period of iterations [S3].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Current training step ($step$), initial learning rate ($lr$), decay factor ($\gamma$), decay interval ($step\_size$), and start step ($start\_step$) [G].
*   **Output:** The current learning rate value ($lr_{current}$) [G].

**Data Structures:**
No complex data structures are required. The state is maintained implicitly by the training loop's step counter [G].

**Parameters:**
*   $lr$: Initial learning rate. Typical values vary by parameter group. For Instant NGP-style training: positions $10^{-4}$, features $5 \times 10^{-3}$, MLP weights $5 \times 10^{-5}$ [S3].
*   $\gamma$: Decay factor. Typical value: $0.33$ [S3].
*   $step\_size$: Number of steps between each decay. Typical value: $10,000$ [S3].
*   $start\_step$: The step at which decay begins. Typical value: $20,000$ [S3].

**Steps:**
1. If $step < start\_step$, return $lr$ [S3].
2. Calculate the number of decay intervals elapsed: $n = \lfloor step / step\_size \rfloor$ [S1, unofficial][S2, unofficial].
3. Compute the decayed learning rate: $lr_{current} = lr \times \gamma^n$ [S2, unofficial].
4. Return $lr_{current}$.

**Pseudocode:**
```python
def get_exponential_decay_lr(step, lr, gamma, step_size, start_step):
    if step < start_step:
        return lr
    n = step // step_size
    return lr * (gamma ** n)
```

**Edge Cases and Pitfalls:**
*   **Redundant Checks:** In some implementations (e.g., Nerfies), the condition `step >= self.num_steps` may be checked twice, causing redundant execution paths [S1, unofficial].
*   **Precision:** For very large $n$, $\gamma^n$ may underflow to zero, effectively freezing the learning rate [G].
*   **Zero Division:** Not applicable as no division by zero occurs in the standard formula, but ensure `step_size` is non-zero [G].

## Subtopics

### Step Decay Learning Rate Schedule
A step-wise decay schedule that reduces a value by a fixed factor at regular intervals until a maximum number of decays is reached [S1, unofficial]. It explicitly bounds the decay by `max_decays`, ensuring the learning rate does not vanish indefinitely [S1, unofficial]. Choose this when a hard lower bound on the learning rate is desired or when training duration is fixed [S1, unofficial].
*   **Definition:** Reduces learning rate by `decay_factor` every `decay_interval` steps, up to `max_decays` [S1, unofficial].
*   **Formula:** $lr = lr_{init} \times decay\_factor^{\min(\lfloor step / decay\_interval \rfloor, max\_decays)}$ [S1, unofficial].
*   **Parameters:** `decay_interval`, `decay_factor`, `max_decays`, `final_value` (defaults to $lr_{init} \times decay\_factor^{max\_decays}$) [S1, unofficial].
*   **Pseudocode:**
    ```python
    def get_step_decay_lr(step, lr_init, decay_interval, decay_factor, max_decays, final_value=None):
        phase = step // decay_interval
        if phase >= max_decays:
            return final_value if final_value is not None else lr_init * (decay_factor ** max_decays)
        return lr_init * (decay_factor ** phase)
    ```

## Operating characteristics
*   **Time Complexity:** $O(1)$ per step [G].
*   **Memory Complexity:** $O(1)$ [G].
*   **Performance:** Applied after 20,000 iterations with a factor of 0.33 every 10,000 steps in Instant NGP-style training [S3].
*   **Strengths:** Simple to implement, computationally cheap [G].
*   **Limitations:** Requires careful tuning of `start_step`, `decay_interval`, and `decay_factor` [G].
*   **When to Use:** When training neural radiance fields with Adam optimizer and separate parameter groups [S3].
*   **When Not to Use:** When a smooth, continuous decay is preferred over step-wise changes (consider [Linear Learning Rate Schedule](11850-linear-learning-rate-schedule.md) or [Annealing Schedules](11839-annealing-schedules.md)) [G].

## Background
The exponential decay schedule is a common technique in optimization [G]. In NeRF training, it was adopted from Instant NGP to manage learning rates of different parameter groups separately [S3]. The specific parameters (start at 20,000 steps, factor 0.33 every 10,000 steps) are cited from Instant NGP [S3]. Implementation details and potential pitfalls are documented in the Nerfies repository [S1, unofficial].
