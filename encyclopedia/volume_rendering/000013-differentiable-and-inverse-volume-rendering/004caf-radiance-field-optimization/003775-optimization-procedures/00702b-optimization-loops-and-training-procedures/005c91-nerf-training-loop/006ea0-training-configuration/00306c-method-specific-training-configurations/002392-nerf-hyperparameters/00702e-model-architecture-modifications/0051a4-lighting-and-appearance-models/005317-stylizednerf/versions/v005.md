# StylizedNeRF

Also called: StyleNeRF

## Overview
StylizedNeRF (also known as StyleNeRF) is a method for high-resolution 3D-aware image synthesis that integrates a style-based generator into the Neural Radiance Field (NeRF) framework [S2, unofficial]. It solves the problem of generating consistent, high-fidelity 3D objects with specific artistic styles by combining a NeRF++ backbone with StyleGAN2-style synthesis networks [S2, unofficial]. It differs from its siblings, such as [Spherical Harmonics NeRF](14480-spherical-harmonics-nerf.md) which focuses on lighting decomposition, and [Non-Photorealistic Style Editing](16597-non-photorealistic-style-editing.md) which focuses on post-hoc style transfer, by natively synthesizing the stylized appearance during the 3D reconstruction process using mutual learning between the 3D field and a 2D stylization network [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Latent codes sampled from a standard Gaussian distribution; camera parameters (position, orientation, intrinsics).
*   **Outputs:** RGB images of the synthesized 3D object from arbitrary viewpoints.

**Data Structures:**
The architecture consists of three main components:
1.  **Mapping Network:** Processes input latent codes.
2.  **Synthesis Network:** A NeRF++ variant that renders the scene.
    *   **Foreground NeRF:** Encoded within a unit sphere.
    *   **Background NeRF:** Uses inverted sphere parameterization for unbounded backgrounds.
    *   **Style-Conditioned Blocks:** Interleaved within the density and color prediction MLPs.
3.  **Discriminator:** Standard StyleGAN2 discriminator for adversarial training.

**Numbered Steps:**
1.  **Latent Code Generation:** Sample a latent vector $z$ from a standard Gaussian distribution $\mathcal{N}(0, I)$.
2.  **Mapping:** Pass $z$ through the Mapping Network to produce a style vector $w$. This vector is broadcast to all style-conditioned blocks in the synthesis network [S2, unofficial].
3.  **Ray Sampling:** For a given camera ray, sample points $\mathbf{x}_i$ along the ray.
4.  **Density Prediction:**
    *   The foreground MLP predicts density $\sigma_f$ for points inside the unit sphere.
    *   The background MLP predicts density $\sigma_b$ for points outside. The background MLP has fewer parameters than the foreground MLP [S2, unofficial].
    *   Total density $\sigma(\mathbf{x})$ is determined by the spatial location relative to the sphere boundary.
5.  **Color Prediction with Style Modulation:**
    *   A shared MLP predicts base color features.
    *   Each **Style-Conditioned Block** applies the style vector $w$ to the features.
    *   The block consists of an affine transformation layer and a $1 \times 1$ Convolution layer (Conv) [S2, unofficial].
    *   The Conv weights $W$ are modulated by the affine-transformed style $s$ and demodulated for computation:
        $$ W' = \frac{s \cdot W}{\sqrt{\sum W^2 + \epsilon}} $$
    *   Leaky ReLU is used as the activation function [S2, unofficial].
6.  **Volume Rendering:** Render the final color $\hat{C}(r)$ using standard volumetric rendering with transmittance $T_i$ and opacity $\alpha_i$:
    $$ \hat{C}(r) = \sum_{i=1}^{N} T_i \alpha_i C_i $$
7.  **Mutual Learning Optimization:**
    *   Optimize the Stylized NeRF and a 2D stylization network simultaneously [S1].
    *   Use learnable latent codes to handle ambiguities in 2D stylized results, ensuring 3D geometry consistency [S1].
    *   Apply a NeRF path regularization loss to enforce 3D consistency [S2, unofficial].
    *   Use a non-saturating GAN objective with R1 regularization [S2, unofficial].

**Parameters:**
*   **Input Resolution:** Fixed at $32^2$ for all experiments [S2, unofficial].
*   **Batch Size:** 64 images per batch [S2, unofficial].
*   **Training Steps:** $T_1 = 500k$, $T_2 = 5000k$, $T_3 = 25000k$ images (used for progressive training/stages) [S2, unofficial].
*   **Target Resolution:** Evaluated at $256^2$ [S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Small Datasets:** Training on small datasets (e.g., CelebFaces) is unstable; fine-tuning from a pretrained model (e.g., FFHQ) is required [S2, unofficial].
*   **3D Consistency:** Without proper regularization, the model may produce 3D inconsistent artifacts where shape and appearance change constantly as the camera moves [S2, unofficial].

## Subtopics

### StyleNeRF Architecture
This variant refers to the specific architectural configuration described in [S2, unofficial]. It uses a NeRF++ backbone (foreground unit sphere + background inverted sphere) combined with StyleGAN2-style style-conditioned blocks. It differs from standard NeRF by introducing low-dimensional appearance codes and style-based MLPs, setting it apart from siblings like StylizedNeRF which may use different stylization mechanisms [14882-stylizednerf.md].

## Operating characteristics
*   **Time and Memory Complexity:** The method uses a NeRF++ backbone which is more complex than standard NeRF due to the separate background and foreground networks. The integration of StyleGAN2-style synthesis networks increases memory usage compared to baseline NeRF.
*   **Measured Performance:** On datasets like FFHQ, AFHQ, and CompCars, StyleNeRF achieves high quality and 3D consistency at $256^2$ resolution, outperforming baselines like HoloGAN, GARF, and $\pi$-GAN which fail to learn geometry correctly [S2, unofficial].
*   **Strengths:** High-resolution synthesis, 3D consistency, ability to handle unbounded backgrounds.
*   **Limitations:** Requires large datasets or fine-tuning from pretrained models for stability; computationally expensive due to GAN training and NeRF++ structure.
*   **When to use:** When high-resolution, 3D-consistent, stylized image synthesis is required.
*   **When not to use:** When working with very small datasets without pretrained weights, or when computational resources are limited.

## Background
StylizedNeRF (StyleNeRF) was introduced in the paper "StyleNeRF: A Style-based 3D-Aware Generator for High-resolution Image Synthesis" [S2, unofficial]. It builds on the NeRF++ architecture [S2, unofficial] and StyleGAN2 [S2, unofficial] to address the limitations of previous 3D-aware generative models that suffered from 3D inconsistency or low resolution. The method was developed to enable high-fidelity 3D object synthesis with style control.
