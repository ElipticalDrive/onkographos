# Residual-NeRF

Also called: Residual-NeRF-S (ablation variant)

## Overview
Residual-NeRF is a method for improving depth perception and training speed for transparent objects in mostly static scenes by leveraging a static scene prior [S1]. It solves the ambiguity faced by standard NeRFs when reconstructing transparent objects, which often suffer from inaccurate depth estimation due to multiple surfaces radiating light along a ray [S1]. Unlike methods that require pre-defined areas or fusion techniques (e.g., Block-NeRF, NeRFusion), Residual-NeRF learns to mix a background NeRF and a residual NeRF at every point in space using a learned Mixnet [S1].

## How it works
Residual-NeRF decomposes the scene representation into a static background component and a dynamic residual component caused by transparent objects. It employs three Multi-Layer Perceptrons (MLPs): a Background MLP ($\Phi_{bg}$), a Residual MLP ($\Phi_{res}$), and a Mixing MLP ($\Phi_{mix}$) [S1].

### Inputs and Outputs
*   **Inputs:**
    *   Background images ($I_{bg}$): Images of the scene without transparent objects.
    *   Residual images ($I_{res}$): Images of the scene with transparent objects present.
    *   Ray parameters: Position $(x, y, z)$ and view direction $(\theta, \phi)$ for $\Phi_{bg}$ and $\Phi_{res}$; Position $(x, y, z)$ for $\Phi_{mix}$ [S1].
    *   Encoding: Location-dependent multi-resolution hash encoding is used for all inputs [S1].
*   **Outputs:**
    *   Rendered color $\hat{C}(r)$ for a ray $r$.
    *   Inferred depth $\hat{D}(r)$ [S1].

### Data Structures
The method maintains three distinct neural network models:
1.  **$\Phi_{bg}$ (Background NeRF):** Takes encoded position and view direction. Outputs pre-activation color $c'_{bg}$ and density $\sigma_{bg}$ [S1].
2.  **$\Phi_{res}$ (Residual NeRF):** Takes encoded position and view direction. Outputs pre-activation color $c'_{res}$ and density $\sigma_{res}$ [S1].
3.  **$\Phi_{mix}$ (Mixnet):** Takes encoded position. Outputs a scalar mixing weight $\beta$ [S1].

### Training Procedure
The training occurs in two distinct phases [S1]:

1.  **Background Learning:** Train $\Phi_{bg}$ on $I_{bg}$ to infer $\sigma_{bg}$ and $c'_{bg}$. This establishes a prior for the static scene [S1].
2.  **Residual and Mixnet Learning:** Train $\Phi_{res}$ and $\Phi_{mix}$ on $I_{res}$. During this phase, $\Phi_{bg}$ is frozen and not updated [S1].

### Rendering and Depth Estimation
For a given ray $r$, the final color is computed by integrating along the ray. The density and color at each sample point $i$ are blended using the mixing weight $\beta_i$ inferred by $\Phi_{mix}$ [S1].

The mixing weight is defined as:
$$ \beta = S(\Phi_{mix}(h(x, y, z))) $$
where $S(x) = \frac{1}{1 + e^{-x}}$ is the sigmoid function, and $h(x, y, z)$ is the multi-resolution hash encoded position [S1].

The combined pre-activation color $c'_{bg+res}$ is a sigmoid-weighted sum of the background and residual pre-activation colors:
$$ c'_{bg+res} = S((1 - \beta)c'_{bg} + \beta c'_{res}) $$
The final color $c_{bg+res}$ is obtained by applying the sigmoid activation to $c'_{bg+res}$ [S1].

The rendered color $\hat{C}(r)$ is calculated using the volumetric rendering equation:
$$ \hat{C}(r) = \sum_{i=1}^{N} T_i (1 - \exp(-((1 - \beta)\sigma_{bg} + \beta\sigma_{res})_i \delta_i)) (c_{bg+res})_i $$
where:
*   $T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)$ is the accumulated transmittance.
*   $\delta_i = t_{i+1} - t_i$ is the segment length between samples.
*   $\sigma_{bg}$ and $\sigma_{res}$ are the densities from the background and residual networks, respectively.
*   $(c_{bg+res})_i$ is the final color after sigmoid activation [S1].

**Depth Estimation:**
Standard depth estimation using the expected distance is inaccurate for transparent objects due to multiple surfaces [S1]. Instead, Residual-NeRF finds the point closest to the camera where the density exceeds a threshold $m$:
$$ \hat{D}(r) = t_k \quad \text{where} \quad k = \min \{ i \mid \sigma_i \ge m \} $$
The parameter $m$ is a tunable depth estimation threshold [S1].

### Pseudocode

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class ResidualNeRF:
    def __init__(self, encoding_config, m_threshold=3.0):
        """
        Initialize Residual-NeRF components.
        
        Args:
            encoding_config: Configuration for multi-resolution hash grid.
            m_threshold: Density threshold for depth estimation (default 3.0 for Blender scenes).
        """
        # Initialize Multi-Resolution Hash Grid for encoding positions
        self.hash_grid = MultiResolutionHashGrid(encoding_config)
        
        # Initialize MLPs
        # Phi_bg: Background NeRF
        self.phi_bg = BackgroundMLP(encoding_dim=self.hash_grid.get_dim())
        # Phi_res: Residual NeRF
        self.phi_res = ResidualMLP(encoding_dim=self.hash_grid.get_dim())
        # Phi_mix: Mixnet
        self.phi_mix = MixnetMLP(encoding_dim=self.hash_grid.get_dim())
        
        self.m = m_threshold

    def forward_background(self, x, y, z, theta, phi):
        """
        Forward pass for Background NeRF.
        
        Args:
            x, y, z: Coordinates.
            theta, phi: View direction angles.
            
        Returns:
            c_prime_bg: Pre-activation color.
            sigma_bg: Density.
        """
        # Encode position
        h = self.hash_grid.encode(x, y, z)
        # Combine with view direction if required by MLP architecture
        # Note: Source implies view direction is input to Phi_bg
        input_vec = torch.cat([h, theta, phi], dim=-1)
        
        c_prime_bg, sigma_bg = self.phi_bg(input_vec)
        return c_prime_bg, sigma_bg

    def forward_residual(self, x, y, z, theta, phi):
        """
        Forward pass for Residual NeRF.
        
        Args:
            x, y, z: Coordinates.
            theta, phi: View direction angles.
            
        Returns:
            c_prime_res: Pre-activation color.
            sigma_res: Density.
        """
        h = self.hash_grid.encode(x, y, z)
        input_vec = torch.cat([h, theta, phi], dim=-1)
        
        c_prime_res, sigma_res = self.phi_res(input_vec)
        return c_prime_res, sigma_res

    def forward_mixnet(self, x, y, z):
        """
        Forward pass for Mixnet.
        
        Args:
            x, y, z: Coordinates.
            
        Returns:
            beta: Mixing weight in [0, 1].
        """
        h = self.hash_grid.encode(x, y, z)
        beta = torch.sigmoid(self.phi_mix(h))
        return beta

    def render_ray(self, ray_origin, ray_direction, t_near, t_far, num_samples):
        """
        Render a single ray using the combined Background and Residual NeRFs.
        
        Args:
            ray_origin: (3,) tensor.
            ray_direction: (3,) tensor.
            t_near: Float. Near plane distance.
            t_far: Float. Far plane distance.
            num_samples: Int. Number of samples along the ray.
            
        Returns:
            color: (3,) tensor. Rendered color.
            depth: Float. Estimated depth.
        """
        # Sample points along the ray
        t_vals = torch.linspace(t_near, t_far, num_samples)
        points = ray_origin.unsqueeze(0) + t_vals.unsqueeze(1) * ray_direction.unsqueeze(0)
        x, y, z = points[:, :, 0], points[:, :, 1], points[:, :, 2]
        
        # Compute view direction (constant for all samples on the ray)
        theta, phi = get_spherical_coords(ray_direction)
        
        # Get Background outputs (Frozen during Residual training)
        c_prime_bg, sigma_bg = self.forward_background(x, y, z, theta, phi)
        
        # Get Residual outputs
        c_prime_res, sigma_res = self.forward_residual(x, y, z, theta, phi)
        
        # Get Mixing weights
        beta = self.forward_mixnet(x, y, z)
        
        # Compute combined density
        # sigma_combined = (1 - beta) * sigma_bg + beta * sigma_res
        sigma_combined = (1 - beta) * sigma_bg + beta * sigma_res
        
        # Compute combined pre-activation color
        # c_prime_combined = (1 - beta) * c_prime_bg + beta * c_prime_res
        c_prime_combined = (1 - beta) * c_prime_bg + beta * c_prime_res
        
        # Apply sigmoid to get final color
        c_combined = torch.sigmoid(c_prime_combined)
        
        # Compute segment lengths
        delta = t_vals[1:] - t_vals[:-1]
        delta = torch.cat([delta, torch.tensor([1e-10], device=points.device)]) # Handle last segment
        
        # Compute transmittance
        # T_i = exp(-sum_{j=1}^{i-1} sigma_j * delta_j)
        alpha = 1.0 - torch.exp(-sigma_combined * delta)
        transmittance = torch.cumprod(1.0 - alpha, dim=0)
        transmittance = torch.cat([torch.ones_like(transmittance[0:1]), transmittance[:-1]], dim=0)
        
        # Render color
        # C(r) = sum_{i=1}^{N} T_i * (1 - exp(-sigma_i * delta_i)) * c_i
        # Note: (1 - exp(-sigma * delta)) is equivalent to alpha if sigma is constant over delta
        # Using the explicit formula from source:
        weights = transmittance * (1.0 - torch.exp(-sigma_combined * delta))
        color = torch.sum(weights.unsqueeze(-1) * c_combined, dim=0)
        
        # Estimate depth
        # Find closest point where sigma >= m
        # Note: This requires checking sigma_combined against m
        # In practice, this is often done during sampling or post-processing
        # Here we approximate by finding the first index where sigma_combined >= m
        mask = sigma_combined >= self.m
        if torch.any(mask):
            depth_idx = torch.argmax(mask.float())
            depth = t_vals[depth_idx]
        else:
            depth = t_far # Fallback if no point exceeds threshold
            
        return color, depth

    def train_step(self, images_bg, images_res, poses_bg, poses_res):
        """
        Perform a training step.
        
        Args:
            images_bg: Tensor of background images.
            images_res: Tensor of residual images.
            poses_bg: Camera poses for background images.
            poses_res: Camera poses for residual images.
        """
        # Phase 1: Train Background NeRF (if not already trained)
        # This is typically done in a separate loop before Phase 2
        # loss_bg = compute_loss(render_ray(poses_bg), images_bg)
        # optimizer_bg.step()
        
        # Phase 2: Train Residual NeRF and Mixnet
        # Background NeRF is frozen
        self.phi_bg.eval()
        
        # Sample rays from images_res
        rays = sample_rays(poses_res, images_res.shape)
        
        # Render rays
        colors, _ = self.render_ray_batch(rays)
        
        # Compute loss against images_res
        loss = F.mse_loss(colors, images_res)
        
        # Backpropagate through phi_res and phi_mix only
        loss.backward()
        optimizer_res_mix.step()
```

### Parameters
*   **$m$**: A tunable parameter for depth estimation threshold. It defines the minimum density $\sigma_i \ge m$ for the closest point to the camera. Typical value: 3.0 for Blender scenes; tuned per real environment [S1].
*   **$\beta$**: The mixing weight inferred by the Mixnet, constrained to $[0, 1]$ via sigmoid activation [S1].

### Pitfalls and Edge Cases
*   **Depth Inaccuracy:** Standard depth estimation (expected distance) is inaccurate for transparent objects because multiple surfaces radiate light along the ray [S1].
*   **Holes and Hallucinations:** Perceived holes in depth maps can lead to robot collisions, while hallucinating non-existent surfaces may lead to no available grasp location [S1].
*   **Mixnet Necessity:** Without the Mixnet (using simple addition, referred to as Residual-NeRF-S), the residual NeRF must deduce the background NeRF's predictions in previously empty regions. This leads to unpredictable behavior, significant noise in view reconstruction, and noisy depth maps [S1].
*   **Freezing Background:** The background NeRF must not be updated during the training of the residual NeRF and Mixnet to preserve the static scene prior [S1].

## Operating characteristics
*   **Time Complexity:** Training speed is improved compared to training a single NeRF on the full scene with transparent objects, as the background is learned separately and the residual network only needs to learn the changes [S1].
*   **Memory Complexity:** Requires storing parameters for three MLPs ($\Phi_{bg}$, $\Phi_{res}$, $\Phi_{mix}$) and the multi-resolution hash grid [S1].
*   **Performance:** On synthetic data, Residual-NeRF achieves 46.1% lower RMSE and 29.5% lower MAE compared to baselines (NeRF, Dex-NeRF) [S1].
    *   RMSE on 'Bowl' scene: NeRF 0.1900, Dex-NeRF 0.1065, Residual-NeRF 0.0699 [S1].
    *   MAE on 'Bowl' scene: NeRF 0.1453, Dex-NeRF 0.0195, Residual-NeRF 0.0140 [S1].
*   **Strengths:** Improves depth perception for transparent objects; reduces ambiguity by leveraging static scene priors; speeds up training; leads to more robust grasp planning with fewer holes and less noise in depth maps [S1].
*   **Limitations:** Requires images of the scene without the transparent objects for background training; assumes the background is static and opaque [S1].
*   **When to use:** Depth perception and grasp planning for transparent objects in robotics, specifically compatible with grasp planners like Dex-Net [S1].
*   **When not to use:** Scenes where the background is not static or cannot be captured without the object [S1].

## Background
Residual-NeRF was proposed to address the challenges of depth perception for transparent objects in robotics, where common depth sensors struggle [S1]. The method builds on the observation that robot work areas (e.g., kitchens) are often mostly static and opaque, allowing a background NeRF to serve as a strong prior [S1]. It was implemented using Torch-NGP (PyTorch version of InstantNGP) with multi-resolution hash grid, running on RTX 4090 and AMD Ryzen Threadripper PRO 5965WX [S1]. The method was evaluated on synthetic Blender scenes and real-world scenes, demonstrating improvements over NeRF and Dex-NeRF [S1].
