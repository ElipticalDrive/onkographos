# Spherical Harmonics Regularization

Also called: SH coefficient masking, SH curriculum training, SH degree regularization

## Overview
Spherical Harmonics Regularization is a training strategy that restricts the maximum degree of Spherical Harmonics (SH) during the early stages of optimization to prevent high-frequency overfitting and stabilize geometry reconstruction [S1, S2]. It differs from general density-based floaters removal by directly controlling the frequency bandwidth of the view-dependent radiance representation, ensuring that low-frequency diffuse properties are learned before high-frequency specular details [S1, S2].

## How it works
**Inputs:**
*   Training epochs counter $t$.
*   Total early-stage epochs $T_{early}$ (typically 5) [S1].
*   Maximum SH degree $D_{max}$ (typically 3 or 4 for Plenoxels) [S1, S2].
*   Current SH degree limit $D_{curr}$ [S2].

**Outputs:**
*   Active SH degree mask or limit $D_{curr}$ for the current optimization step [S1, S2].

**Data Structures:**
*   SH Coefficients: Stored per voxel. For degree $l$, there are $2l+1$ coefficients. Total coefficients for degree $L$ is $(L+1)^2$ [S1].

**Steps:**
1.  **Initialize:** Set initial maximum SH degree $D_{curr} = 0$ or a low value (e.g., degree 0 or 1) at the start of training [S2].
2.  **Curriculum Schedule:** During the early training phase ($t < T_{early}$), gradually increase the allowable SH degree [S1, S2].
    *   *Method A (HDR-Plenoxels):* Apply SH masking to coefficients of degrees 2 and 3. Decrease the masking rate by 1/5 per epoch for the first 5 epochs [S1]. After 5 epochs, update all SH degrees with full rate (no masking) [S1].
    *   *Method B (F2Plenoxels):* Gradually increase the allowable SH degree as training progresses, following a curriculum schedule [S2].
3.  **Apply Mask:** During rendering or gradient computation, zero out or ignore gradients for SH coefficients with degree $l > D_{curr}$ [S1, S2].
4.  **Update Limit:** Increment $D_{curr}$ according to the schedule [S1, S2].
5.  **Full Resolution:** After $T_{early}$ epochs, enable all SH degrees up to $D_{max}$ [S1].

**Pseudocode:**
```python
def get_sh_degree_limit(epoch, total_epochs=5, max_degree=3):
    """
    Returns the maximum SH degree allowed for optimization at the given epoch.
    Implements the curriculum schedule from HDR-Plenoxels and F2Plenoxels.
    """
    if epoch < total_epochs:
        # Gradually increase degree or reduce masking
        # HDR-Plenoxels: Masking decreases by 1/5 per epoch.
        # This implies full access is granted progressively.
        # A simple interpretation: allow degree 0 initially, then 1, then 2, etc.
        # Or: allow all coefficients but scale their learning rate/gradient.
        # Based on "decrease the rate of SH masking by 1/5", 
        # we can interpret this as allowing higher degrees stepwise.
        
        # Let's assume a step-wise unlock for clarity, consistent with "curriculum"
        # Epoch 0: Degree 0
        # Epoch 1: Degree 1
        # Epoch 2: Degree 2
        # Epoch 3: Degree 3 (if max_degree >= 3)
        # Epoch 4: Degree 3 (full)
        
        # More precise mapping from "decrease masking rate by 1/5":
        # If masking rate is 1.0 at start, it becomes 0.8, 0.6, 0.4, 0.2, 0.0
        # This likely refers to the *proportion* of high-frequency coefficients 
        # that are masked or penalized.
        
        # F2Plenoxels explicitly states "gradually increase the allowable SH degree".
        # We implement a linear increase in allowed degree.
        
        progress = epoch / total_epochs
        allowed_degree = int(progress * max_degree)
        return allowed_degree
    else:
        return max_degree

def apply_sh_masking(sh_coefficients, current_max_degree):
    """
    Zeros out SH coefficients with degree > current_max_degree.
    """
    masked_coefficients = sh_coefficients.copy()
    for l in range(current_max_degree + 1, len(sh_coefficients)):
        # Zero out coefficients for degree l
        # Assuming coefficients are stored in order of increasing l
        # Number of coefficients for degree l is 2*l + 1
        start_idx = sum(2*k + 1 for k in range(l))
        end_idx = start_idx + (2*l + 1)
        masked_coefficients[start_idx:end_idx] = 0
    return masked_coefficients
```

**Parameters:**
*   $T_{early}$: Number of early epochs for curriculum. Typical value: 5 [S1].
*   $D_{max}$: Maximum SH degree. Typical value: 3 or 4 for Plenoxels [S1, S2].

**Edge Cases:**
*   **Harsh Input Conditions:** The method is specifically designed to stabilize optimization when input data is noisy or sparse [S1].
*   **High-Frequency Reflectance:** Glossy materials, which exhibit drastic reflectance changes with subtle view direction changes, are prone to overfitting if high-frequency SH are enabled too early [S1].

## Operating characteristics
*   **Time Complexity:** Negligible overhead. The masking operation is a simple index check or zeroing of coefficients, which is faster than computing high-frequency SH basis functions [S2].
*   **Memory Complexity:** No additional memory required. The SH coefficients are stored regardless; the regularization only affects which coefficients are updated [S1, S2].
*   **Performance:** Improves coarse geometry accuracy and reduces floaters with negligible computational cost [S2]. Stabilizes optimization in harsh input conditions [S1].
*   **Strengths:** Prevents high-frequency overfitting early in training, leading to better geometry [S2]. Simple to implement [S1, S2].
*   **Limitations:** Requires tuning of the curriculum schedule ($T_{early}$) [S1]. May slow down convergence if the schedule is too conservative [G].

## Background
*   **Origin:** Introduced in HDR-Plenoxels [S1] and F2Plenoxels [S2].
*   **History:** Inspired by frequency regularization techniques in FreeNeRF (positional encoding) and FourieRF (Fourier coefficients) [S2]. Applied directly to SH coefficients in voxel grid representations [S2].
*   **Usage:** Used in few-shot view synthesis and high-dynamic-range radiance field optimization [S1, S2].
