# S-NeRF Training Configuration

Also called: S-NeRF Optimization Setup

## Overview
S-NeRF training configuration defines the specific hyperparameters, network architectures, and confidence-based loss weighting required to train neural radiance fields on dynamic street scenes using LiDAR and RGB data. It distinguishes itself from standard NeRF variants by decoupling the training of foreground moving vehicles from the static background, and by integrating geometry and projection confidence maps derived from multi-view LiDAR reprojection to suppress depth outliers [S1, unofficial].

## How it works
The method splits training into two independent phases: foreground vehicle reconstruction and background street scene reconstruction. Each phase uses distinct MLP architectures, sampling strategies, and loss weights.

### Inputs and Outputs
**Inputs:**
*   Sparse LiDAR point clouds from consecutive frames ($t-1, t, t+1$).
*   RGB images from corresponding camera poses.
*   Camera intrinsics and extrinsics.

**Outputs:**
*   Trained density and color MLPs for foreground and background.
*   Confidence maps for pose weighting.

### Data Structures
The network consists of two separate MLPs for the background and one for the foreground.

**Background Density MLP:**
*   Layers: 8
*   Hidden units per layer: 1024
*   Activation: ReLU (implied by standard MLP structure in this context, though not explicitly named, standard practice for mip-NeRF family [S1, unofficial]).

**Background Color MLP:**
*   Layers: 3
*   Hidden units per layer: 128
*   Input: Concatenated density features and viewing direction.

**Foreground Vehicle MLP:**
*   Layers: 4
*   Hidden units per layer: 256
*   Input: Position and viewing direction.

### Numbered Steps

1.  **Scene Parameterization:**
    Define the scene radius $r = 3$ for the background scene parameterization function [S1, unofficial].

2.  **Confidence Map Computation (Background):**
    *   Project 3D LiDAR points from time $t-1$ and $t+1$ to time $t$ using the displacement $\Delta P$ between frames [S1, unofficial].
    *   Perform consistency checks using optical flow and depth projection to identify and remove moving object outliers [S1, unofficial].
    *   Compute individual confidence components:
        *   Geometry confidence: Depth and Flow consistency.
        *   Projection confidence: RGB, SSIM, and VGG feature consistency [S1, unofficial].
    *   Combine components via learnable aggregation to produce final confidence maps.
    *   Apply a confidence threshold $\tau = 20\%$ for confidence measurement in background scenes [S1, unofficial].

3.  **Foreground Sampling:**
    Sample $N_f = 64$ points along each ray for foreground vehicle rendering [S1, unofficial].

4.  **Background Sampling:**
    Sample $N_b = 128$ points along each ray for background rendering using a log-scale distribution [S1, unofficial].

5.  **Foreground Training Loop:**
    *   Initialize Adam optimizer with learning rate $\eta_f = 5 \times 10^{-4}$ [S1, unofficial].
    *   Set batch size $B_f = 1024$ [S1, unofficial].
    *   Iterate for $I_f = 30,000$ iterations [S1, unofficial].
    *   Compute loss using weights $\lambda_1 = 1$ (depth) and $\lambda_2 = 0.15$ (smoothness) [S1, unofficial].

6.  **Background Training Loop:**
    *   Initialize Adam optimizer with initial learning rate $\eta_{b,0} = 5 \times 10^{-4}$ [S1, unofficial].
    *   Set batch size $B_b = 2048$ [S1, unofficial].
    *   Apply warm-up phase for $W = 2500$ iterations [S1, unofficial].
    *   Apply log-linear decay schedule reducing learning rate from $5 \times 10^{-4}$ to $5 \times 10^{-6}$ over $I_b = 100,000$ iterations [S1, unofficial].
    *   Compute loss using weights $\lambda_1 = 0.2$ (depth) and $\lambda_2 = 0.01$ (smoothness) [S1, unofficial].

### Pseudocode

```python
def train_snerf_foreground(vehicle_data, iterations=30000, lr=5e-4, batch_size=1024):
    """
    Trains the foreground vehicle MLP.
    """
    model = MLP(layers=4, hidden_units=256)
    optimizer = Adam(model.parameters(), lr=lr)
    
    for i in range(iterations):
        batch = sample_batch(vehicle_data, batch_size)
        rays = batch.rays
        gt_color = batch.gt_color
        gt_depth = batch.gt_depth
        
        # Sample 64 points per ray
        points = sample_rays(rays, num_samples=64)
        
        # Forward pass
        density, color = model(points, rays.directions)
        
        # Render
        rendered_color = volume_render(color, density, rays)
        rendered_depth = volume_render_depth(density, points, rays)
        
        # Loss calculation
        # lambda1 = 1, lambda2 = 0.15
        loss = 1.0 * l1_loss(rendered_color, gt_color) + \
               0.15 * smoothness_loss(rendered_depth)
        
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

def train_snerf_background(scene_data, iterations=100000, warmup=2500, 
                           lr_start=5e-4, lr_end=5e-6, batch_size=2048):
    """
    Trains the background street scene MLP with confidence weighting.
    """
    density_model = MLP(layers=8, hidden_units=1024)
    color_model = MLP(layers=3, hidden_units=128)
    optimizer = Adam(list(density_model.parameters()) + list(color_model.parameters()), lr=lr_start)
    
    # Precompute confidence maps
    confidence_maps = compute_confidence_maps(scene_data.lidar_points, 
                                              scene_data.images, 
                                              threshold=0.2)
    
    for i in range(iterations):
        # Learning rate schedule: log-linear decay with warmup
        if i < warmup:
            lr = lr_start * (i / warmup)
        else:
            # Log-linear decay from lr_start to lr_end
            progress = (i - warmup) / (iterations - warmup)
            lr = lr_start * (lr_end / lr_start) ** progress
            
        optimizer.param_groups[0]['lr'] = lr
        
        batch = sample_batch(scene_data, batch_size)
        rays = batch.rays
        gt_color = batch.gt_color
        gt_depth = batch.gt_depth
        
        # Sample 128 points per ray in log scale
        points = sample_rays_log(rays, num_samples=128)
        
        # Forward pass
        density, features = density_model(points)
        color = color_model(features, rays.directions)
        
        # Render
        rendered_color = volume_render(color, density, rays)
        rendered_depth = volume_render_depth(density, points, rays)
        
        # Get confidence weight for this batch
        # Confidence maps are projected to ray space
        conf_weight = project_confidence(confidence_maps, rays)
        
        # Loss calculation
        # lambda1 = 0.2, lambda2 = 0.01
        # Apply confidence weighting to depth loss
        depth_loss = l1_loss(rendered_depth, gt_depth)
        depth_loss = depth_loss * conf_weight # [G] Assuming element-wise multiplication with confidence
        
        loss = 0.2 * depth_loss + \
               0.01 * smoothness_loss(rendered_depth)
        
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
```

### Parameters and Typical Values

| Parameter | Foreground (Vehicle) | Background (Street) |
| :--- | :--- | :--- |
| **Iterations** | 30,000 | 100,000 |
| **Learning Rate** | $5 \times 10^{-4}$ (constant) | $5 \times 10^{-4}$ to $5 \times 10^{-6}$ (log-linear decay) |
| **Warm-up** | None specified | 2,500 iterations |
| **Batch Size** | 1,024 | 2,048 |
| **Samples/Ray** | 64 (linear) | 128 (log scale) |
| **Depth Loss Weight ($\lambda_1$)** | 1.0 | 0.2 |
| **Smoothness Loss Weight ($\lambda_2$)** | 0.15 | 0.01 |
| **Scene Radius ($r$)** | Not specified | 3 |
| **Confidence Threshold ($\tau$)** | Not specified | 20% |

### Edge Cases and Pitfalls
*   **Moving Objects:** Moving objects (e.g., other vehicles, pedestrians) must be removed via instance segmentation and optical flow before training the background model to prevent ghosting [S1, unofficial].
*   **Pose Outliers:** Without confidence updating, shape-radiance ambiguity can cause outlier poses to exhibit higher rendering quality (PSNR) than inlier poses, leading to incorrect ray sampling [S1, unofficial]. The confidence map computation mitigates this.
*   **Hardware Scaling:** Training time scales with scene complexity. Background scenes with ~250 images (1280×1920) require two RTX 3090 GPUs and ~17 hours, while foreground vehicles require one RTX 3090 and ~2 hours [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Training takes approximately 2 hours per foreground vehicle on a single RTX 3090 GPU and ~17 hours per background scene (250 images, 1280×1920) on two RTX 3090 GPUs [S1, unofficial].
*   **Memory Complexity:** The total number of learnable parameters is 8.76M, which is comparable to other state-of-the-art methods (8.7–9.9M) [S1, unofficial].
*   **Performance:** On the Waymo dataset, S-NeRF achieves a PSNR of 23.60 and SSIM of 0.743, outperforming Mip-NeRF 360 (PSNR 22.10, SSIM 0.724) and Urban-NeRF (PSNR 17.80, SSIM 0.494) [S1, unofficial].
*   **Strengths:** Robust to LiDAR outliers via confidence maps; handles dynamic scenes by separating foreground and background.
*   **Limitations:** Requires LiDAR data for confidence computation; training time is longer than methods that skip coarse rendering supervision (e.g., Mip-NeRF 360 is faster as it does not require coarse rendering for supervision) [S1, unofficial].

## Background
S-NeRF was introduced in the paper "S-NeRF: Neural Radiance Fields for Street Views" published at ICLR 2023 [S1, unofficial]. It was developed to address the challenges of reconstructing large-scale dynamic street scenes using sparse LiDAR and RGB data, building upon the mip-NeRF optimization framework [S1, unofficial].
