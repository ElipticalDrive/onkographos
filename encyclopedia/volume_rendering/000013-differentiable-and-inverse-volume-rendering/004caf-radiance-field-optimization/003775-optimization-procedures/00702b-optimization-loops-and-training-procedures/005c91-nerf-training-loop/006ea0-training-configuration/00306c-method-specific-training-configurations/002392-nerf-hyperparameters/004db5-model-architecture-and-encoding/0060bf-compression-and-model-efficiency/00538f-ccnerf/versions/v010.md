# CCNeRF

Also called: Compressible-Composable NeRF, Rank-residual Decomposition NeRF

## Overview
CCNeRF is a neural field representation that enables efficient compression and composition of 3D scenes by learning a hybrid tensor rank decomposition of the scene without using neural networks for rendering [S1]. Unlike NeRF variants that rely on a shared MLP renderer (e.g., NSVF) or hybrid tensor-MLP approaches (e.g., TensoRF), CCNeRF models the radiance field *only* with tensor rank decomposition, preserving low-rank approximation properties to allow dynamic model size adjustment via rank truncation and arbitrary composition via rank concatenation [S1].

## How it works
**Inputs:**
*   3D spatial coordinate $\mathbf{x} = (x, y, z)$.
*   Viewing direction $\mathbf{d} = (\theta, \phi)$ (spherical coordinates).
*   Target rank $R$ (for compression) or set of rank components (for composition).

**Outputs:**
*   Volume density $\sigma \in \mathbb{R}$.
*   Color $\mathbf{c} \in \mathbb{R}^3$.

**Data Structures:**
The model consists of two main parts:
1.  **Rank Weights Matrix ($W$):** A matrix storing weights for different feature channels. If the total rank is $R_{total}$ and the feature dimension is $F$, $W \in \mathbb{R}^{R_{total} \times F}$.
2.  **Rank Components ($\mathcal{U}$):** A set of decomposed rank components. Each component is either:
    *   **Vector-based (CP):** Factor matrices $U^x \in \mathbb{R}^{H \times R_{vec}}, U^y \in \mathbb{R}^{W \times R_{vec}}, U^z \in \mathbb{R}^{D \times R_{vec}}$.
    *   **Matrix-based (Triple Plane):** Factor matrices $U^{xy} \in \mathbb{R}^{H \times W \times R_{mat}}, U^{xz} \in \mathbb{R}^{H \times D \times R_{mat}}, U^{yz} \in \mathbb{R}^{W \times D \times R_{mat}}$.
    *   The total rank $R_{total} = R_{vec} + R_{mat}$. The ratio of vector- to matrix-based components is controllable [S1].

**Querying a 3D Coordinate:**
To query density $\sigma$ and color $\mathbf{c}$ at $\mathbf{x}$ and $\mathbf{d}$:
1.  **Project Coordinate:** Project $\mathbf{x}$ onto the decomposed vectors or matrices.
    *   For vector-based components: Compute dot products $\mathbf{u}^x_i = U^x_i \cdot \mathbf{x}$, $\mathbf{u}^y_i = U^y_i \cdot \mathbf{x}$, $\mathbf{u}^z_i = U^z_i \cdot \mathbf{x}$.
    *   For matrix-based components: Interpolate values from the planes $U^{xy}, U^{xz}, U^{yz}$ at coordinates $(x,y), (x,z), (y,z)$ respectively.
2.  **Weighted Interpolation:** Combine the projected values using the rank weights $W$. The specific combination depends on the decomposition type (CP or Triple Plane), but generally involves summing the weighted contributions of all rank components [S1].
3.  **Output Generation:** The aggregated feature vector is passed through a simple linear layer (or directly used, depending on implementation details not fully specified in the abstract, but implied to be non-MLP) to produce $\sigma$ and $\mathbf{c}$. Note: The paper emphasizes *no neural networks* for rendering, implying the final mapping from aggregated features to $\sigma, \mathbf{c}$ is likely a simple linear transformation or direct readout, distinct from the MLPs in standard NeRF [S1].

**Volume Rendering:**
The final pixel color is computed by integrating along a ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$:
$$ \hat{C}(r) = \sum_{i=1}^N T_i \alpha_i c_i $$
where:
*   $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ is the opacity.
*   $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$ is the transmittance.
*   $\delta_i = t_{i+1} - t_i$ is the distance between sample points.
*   $\sigma_i$ and $c_i$ are the density and color queried at sample point $i$ [S1].

**Compression (Rank Truncation):**
1.  **Rank-Residual Learning:** During training, a rank-residual learning strategy is employed to encourage lower ranks to preserve more important information of the whole scene [S1].
2.  **Sort-and-Truncate:** An empirical sort-and-truncate strategy is used to achieve near-optimal low-rank approximation at any targeted rank. Components are sorted by importance (derived from weights $W$ or singular values if HOSVD is used) and truncated [S1].
3.  **Dynamic Adjustment:** The number of components kept determines the model size and detail level. Lower ranks preserve primary information [S1].

**Composition:**
1.  **Concatenation:** Different models are composed by concatenating their rank components along the rank dimension. If Model A has ranks $R_A$ and Model B has ranks $R_B$, the composed model has ranks $R_A + R_B$ [S1].
2.  **Transformation:** A transformation matrix is recorded for each object to control its position and orientation in the scene. This matrix is applied to the 3D coordinates before querying the rank components [S1].

**Parameters:**
*   $R_{vec}$: Number of vector-based (CP) ranks. Typical values not given in sources.
*   $R_{mat}$: Number of matrix-based (Triple Plane) ranks. Typical values not given in sources.

**Edge Cases and Pitfalls:**
*   **Truncated HOSVD:** Standard truncated Higher-Order SVD (HOSVD) does not hold the optimal property of truncated SVD, but yields a quasi-optimal solution sufficient for practical use [S1].
*   **Rank Ratio:** The ratio of vector- to matrix-based components is controllable and affects the trade-off between model size and performance [S1].
*   **Composition Growth:** Composing many objects can lead to large model size, mitigated by compressing unimportant objects [S1].

## Operating characteristics
*   **Time Complexity:** Querying is $O(R_{total} \cdot F)$, where $R_{total}$ is the total rank and $F$ is the feature dimension. This is generally faster than MLP-based rendering as it avoids multiple layers of non-linear activations [S1].
*   **Memory Complexity:** Memory usage is proportional to $R_{total} \cdot (H \cdot W + H \cdot D + W \cdot D + F)$. Compression reduces this by reducing $R_{total}$ [S1].
*   **Performance:** Achieves comparable rendering quality to state-of-the-art methods while enabling extra capabilities of compression and composition [S1].
*   **Strengths:**
    *   No neural networks for rendering, allowing arbitrary composition without retraining [S1].
    *   Dynamic model size adjustment via rank truncation without retraining [S1].
    *   Near-optimal compression [S1].
*   **Limitations:**
    *   Quasi-optimal compression due to HOSVD limitations [S1].
    *   Composition can lead to large model sizes if not compressed [S1].
*   **When to use:** When compression and composition of 3D scenes are required, and computational efficiency during rendering is a priority.
*   **When not to use:** When maximum possible rendering quality is required and compression is not a concern, or when the scene has very high-frequency details that are not well-captured by low-rank approximations.

## Background
CCNeRF was introduced by Jiaxiang Tang, Xiaokang Chen, Jingbo Wang, and Gang Zeng from Peking University and Chinese University of Hong Kong in 2022 [S1]. It addresses the difficulty in manipulating NeRF models, such as compression and composition, which are typically restricted by shared renderer networks or suffer from large model sizes [S1]. The method is motivated by the low-rank approximation property of the SVD algorithm and proposes a rank-residual learning strategy [S1].
