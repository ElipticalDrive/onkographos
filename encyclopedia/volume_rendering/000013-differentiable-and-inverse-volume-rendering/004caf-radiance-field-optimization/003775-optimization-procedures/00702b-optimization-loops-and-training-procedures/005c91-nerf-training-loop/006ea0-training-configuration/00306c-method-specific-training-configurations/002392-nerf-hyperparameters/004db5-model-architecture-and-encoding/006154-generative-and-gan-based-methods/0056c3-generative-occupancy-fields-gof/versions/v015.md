# Generative Occupancy Fields (GOF)


## Overview
Generative Occupancy Fields (GOF) is a 3D-aware image synthesis method that combines radiance fields with occupancy representations to learn compact object surfaces without impeding training convergence [S1, unofficial]. It solves the problem of diffused surfaces in generative radiance fields (like GRAFs) and the sparse gradient convergence issues in direct occupancy networks by transitioning from cumulative volume rendering to surface-point rendering [S1, unofficial]. Unlike its siblings that predict volume density $\sigma$ and suffer from shape-color ambiguity or require complex hierarchical sampling, GOF predicts alpha values $\alpha$ directly, reinterpreting them as occupancy to locate surfaces via root-finding [S1, unofficial].

## How it works
GOF builds on [Model Architecture and Encoding](13550-model-architecture-and-encoding.md) by modifying the output interpretation and sampling strategy. While the parent defines the general mapping of $(\mathbf{x}, \mathbf{d})$ to $(\sigma, \mathbf{c})$, GOF modifies the decoder to predict $\alpha_\theta(\mathbf{x}, z)$ directly, where $z$ is a latent code.

### Inputs and Outputs
*   **Inputs:**
    *   Latent code $z \sim p_z$ (typically truncated normal).
    *   Camera pose $\xi$ (origin $o$, direction $d$).
    *   Training step $n$ (for shrinking schedule).
*   **Outputs:**
    *   Rendered image color $\tilde{C}(r, z)$.
    *   Surface point $x_s$ (during training/inference root-finding).

### Data Structures
*   **Generator $G_\theta$:** A neural network (FiLMed-SIREN backbone) taking $(\mathbf{x}, z)$ and outputting $\alpha_\theta(\mathbf{x}, z) \in [0, 1]$ and color $c_\theta(\mathbf{x}, d, z) \in \mathbb{R}^3$.
*   **Discriminator $D_\phi$:** Standard GAN discriminator taking images.
*   **Parameters:**
    *   $N$: Number of rendering samples. Typical value: 12 [S1, unofficial].
    *   $M$: Number of root-finding bins. Typical value: 12 [S1, unofficial].
    *   $m_s$: Secant iterations. Typical value: 3 [S1, unofficial].
    *   $\tau$: Threshold for root-finding. Typical value: 0.5 [S1, unofficial].
    *   $\Delta_{init}$: Initial sampling interval, $(t_f - t_n)/2$.
    *   $\Delta_{min}$: Minimal sampling interval (pre-defined).
    *   $\gamma$: Shrinking rate.

### Formulas
1.  **Alpha Prediction:**
    $$ \alpha_\theta(x_i, z) = 1 - \exp(-\sigma_\theta(x_i, z)\delta_i) $$
    This ensures $\alpha \in [0, 1]$, resembling occupancy values [S1, unofficial].

2.  **Rendering (Alpha Composition):**
    $$ \tilde{C}(r, z) = \sum_{i=1}^{N} \alpha_\theta(x_i, z) \left( \prod_{j<i} (1 - \alpha_\theta(x_j, z)) \right) c_\theta(x_i, d, z) $$
    Where $T_i = \prod_{j<i} (1 - \alpha_\theta(x_j, z))$ is the transmittance [S1, unofficial].

3.  **Surface Location (Root-Finding):**
    Sample $M$ points $x_k$ in $[t_n, t_f]$. Find bin $k_S$:
    $$ k_S = \arg\min_k (\alpha_\theta(x_k, z) < \tau \le \alpha_\theta(x_{k+1}, z)) $$
    Apply secant method $m_s$ times within $[x_{k_S}, x_{k_S+1}]$ to find precise surface $x_s$ [S1, unofficial].

4.  **Shrinking Sampling Region:**
    At step $n$, compute interval $\Delta_n$:
    $$ \Delta_n = \max(\Delta_{init} \exp(-\gamma n), \Delta_{min}) $$
    Sample $N$ points uniformly in $[t_s - \Delta_n, t_s + \Delta_n]$ [S1, unofficial].

5.  **Loss Functions:**
    *   **GAN Loss:**
        $$ L_{origin}(\theta_D, \theta_G) = \mathbb{E}_{z, \xi} f(D_{\theta_D}(G_{\theta_G}(z, \xi))) + \mathbb{E}_{I \sim p_D} f(-D_{\theta_D}(I)) + \lambda ||\nabla_{D_{\theta_D}}(I)||_2^2 $$
        where $f(u) = -\log(1 + \exp(-u))$ [S1, unofficial].
    *   **Opacity Regularization:**
        $$ L_{opacity} = \frac{1}{N} \sum_{i=1}^{N} \log(\alpha_\theta(x_i, z)) + \log(1 - \alpha_\theta(x_i, z)) $$
        Reduces entropy of alpha values [S1, unofficial].
    *   **Normal Regularization:**
        $$ L_{normal} = \sum_{x_s \in S} ||n_\theta(x_s, z) - n_\theta(x_s + \epsilon, z)||_2 $$
        Encourages surface smoothness [S1, unofficial].
    *   **Total Loss:**
        $$ L(\theta, \phi) = L_{origin} + \lambda_{normal} L_{normal} + \lambda_{opacity} L_{opacity} $$

    """
    Renders an image using GOF.
    If step_n is provided, performs training step (includes loss calc).
    If step_n is None, performs inference.
    """
    # 1. Surface Location via Root-Finding
    # Sample M points in the full volume [t_near, t_far]
    t_bins = np.linspace(t_near, t_far, M + 1)
    x_bins = camera_origin + t_bins[:, np.newaxis] * camera_direction
    
    # Query alpha values (no gradients needed for root-finding)
    alpha_bins = generator.predict_alpha(x_bins, latent_z)
    
    # Find bin where alpha crosses threshold tau
    # alpha < tau (free) to alpha >= tau (occupied)
    crossing_indices = np.where((alpha_bins[:-1] < tau) & (alpha_bins[1:] >= tau))[0]
    
    if len(crossing_indices) == 0:
        # Fallback: if no crossing, use midpoint or handle edge case
        # [G] In practice, ensure alpha is monotonic or handle noise
        k_s = len(alpha_bins) // 2
    else:
        k_s = crossing_indices[0]
        
    x_start = x_bins[k_s]
    x_end = x_bins[k_s + 1]
    
    # Secant method refinement
    t_s = (t_bins[k_s] + t_bins[k_s+1]) / 2.0
    for _ in range(ms):
        # Evaluate alpha at current t_s and previous t_s (or boundary)
        # [G] Standard secant method requires two points.

        t_s = secant_solve(generator, latent_z, camera_origin, camera_direction,

    x_surface = camera_origin + t_s * camera_direction
    
    # 2. Determine Sampling Region
    if step_n is not None:
        # Training: Shrinking region
        if delta_init is None:
            delta_init = (t_far - t_near) / 2.0
        delta_n = max(delta_init * math.exp(-gamma * step_n), delta_min)
        t_start = t_s - delta_n
        t_end = t_s + delta_n
        
        # Clamp to volume bounds
        t_start = max(t_start, t_near)
        t_end = min(t_end, t_far)
        
        # Sample N points in [t_start, t_end]
        t_render = np.linspace(t_start, t_end, N + 1)[:-1] # N points
        # Uniform sampling within the interval
        t_render = t_start + (t_end - t_start) * np.random.rand(N)
        # Sort for correct transmittance calculation
        t_render.sort()
    else:
        # Inference: Can use minimal region or single point
        # Option A: Minimal region cumulative
        delta_n = delta_min
        t_start = t_s - delta_n
        t_end = t_s + delta_n
        t_render = np.linspace(t_start, t_end, N + 1)[:-1]
        t_render.sort()
        
        # Option B: Single surface point (faster)
        # t_render = [t_s]
        # N = 1
        
    x_render = camera_origin + t_render[:, np.newaxis] * camera_direction
    
    # 3. Render
    alpha_render = generator.predict_alpha(x_render, latent_z)
    color_render = generator.predict_color(x_render, camera_direction, latent_z)
    
    # Alpha composition
    # T_i = product(1 - alpha_j) for j < i
    # C = sum(alpha_i * T_i * c_i)
    transmittance = np.ones(N + 1)
    for i in range(N - 1, -1, -1):
        transmittance[i] = transmittance[i+1] * (1 - alpha_render[i])
        
    weights = alpha_render * transmittance[:-1]
    image_color = np.sum(weights[:, np.newaxis] * color_render, axis=0)
    
    return image_color, x_surface

### Edge Cases and Pitfalls
*   **Shape-Color Ambiguity:** Direct training of generative radiance fields fails to maintain surface compactness because small perturbations on surfaces still lead to realistic RGB images, fooling the discriminator [S1, unofficial]. GOF mitigates this by shrinking the sampling region.
*   **Gradient Sparsity:** Directly applying occupancy representations causes severe convergence problems due to sparse gradients on surfaces [S1, unofficial]. GOF avoids this by starting with cumulative rendering (dense gradients) and transitioning to surface rendering.
*   **Density Thresholding:** Predicted densities in generative radiance fields range from 0 to 50, making thresholding difficult [S1, unofficial]. GOF uses alpha values (0-1) for robust root-finding.
*   **Inference Speed:** Standard rendering requires $M + m_s + N$ queries. Single-point surface rendering requires $M + m_s + 1$ queries [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Rendering requires $M + m_s + N$ neural network queries per pixel for standard mode, or $M + m_s + 1$ for surface-only mode. Baselines (e.g., pi-GAN) require $2N$ queries due to hierarchical sampling [S1, unofficial].
*   **Memory Complexity:** Depends on the generator size (SIREN) and discriminator. No large voxel grids or hash tables are stored, unlike grid-based methods.
*   **Strengths:** Produces compact and smooth surfaces (low MAD) compared to pi-GAN. Comparable depth accuracy (SIDE) to strong baselines. Efficient inference with single-point rendering.
*   **Limitations:** Struggles with non-solid objects (e.g., furry cats become over-smooth) [S1, unofficial]. Requires careful tuning of shrinking schedule parameters ($\gamma, \Delta_{min}$).
*   **When to use:** 3D-aware image synthesis for solid objects (faces, animals) where surface compactness is critical.
*   **When not to use:** Scenes with transparent objects, complex internal structures, or highly detailed textures that require volumetric depth.

## Background
GOF was proposed by Xudong Xu, Xingang Pan, Dahua Lin, and Bo Dai in 2021 [S1, unofficial]. It addresses limitations in prior generative radiance fields like GRAFs and pi-GAN, which produce diffused surfaces, and occupancy networks, which suffer from convergence issues in generative settings. The method leverages the similarity between alpha values in volume rendering and occupancy values in implicit surface representations. It is evaluated on CelebA, BFM, and Cats datasets [S1, unofficial].
