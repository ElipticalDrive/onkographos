# MZEN (Multi-zoom Enhanced NeRF)

Also called: Multi-zoom Enhanced NeRF

## Overview
MZEN is a framework for 3-D reconstruction from images with unknown camera poses where the optical zoom level varies significantly across views [S1]. It solves the problem of geometric inconsistency in pose-free NeRFs when magnification changes, which typically couples translation, scale, and focal length in an unidentifiable way [S1]. Unlike [Mip-NeRF 360 MLP Architecture](14098-mip-nerf-360-mlp-architecture.md) or [CamP](14098-mip-nerf-360-mlp-architecture.md) which rely on high-resolution image pyramids or external pose initialization, MZEN keeps every frame at native resolution and explicitly models optical zoom as a learnable intrinsic parameter [S1].

## How it works
MZEN represents the radiance field using a standard NeRF MLP and introduces a zoom-aware camera model optimized through a three-phase training schedule [S1].

**Inputs and Outputs**
*   **Inputs:** A set of $N$ images $\mathcal{I} = \{I_k\}_{k=1}^N$. The set is partitioned into $N_{out}$ zoomed-out images (indices $i=1 \dots N_{out}$) and $N_{in}$ zoomed-in images (indices $j=N_{out}+1 \dots N$) [S1]. Each image has a rough initial estimate of its zoom parameter $\xi_k$ (e.g., from a dial reading or apparent size comparison) [S1].
*   **Outputs:** NeRF network parameters $\Theta$, camera poses $\Pi = \{R_k, t_k\}_{k=1}^N$, and zoom parameters $\{\xi_k\}_{k=1}^N$ [S1].

**Data Structures**
*   **Camera Pose $\Pi_k$:** A tuple $(R_k, t_k, f, c, \xi_k)$ where $R_k \in SO(3)$ is rotation, $t_k \in \mathbb{R}^3$ is translation, $f=(f_x, f_y)$ is the shared base focal length, $c=(c_x, c_y)$ is the principal point, and $\xi_k \ge 1$ is the zoom parameter [S1].
*   **Effective Intrinsic Matrix:** $K_{eff}^k = \text{diag}(\xi_k f_x, \xi_k f_y, 1)$ [S1].
*   **NeRF Parameters $\Theta$:** Weights of the MLP representing the radiance field [S1].

**Numbered Steps**

1.  **Phase A: Global Pose Bootstrap**
    *   Initialize zoom parameters for the $N_{out}$ most zoomed-out images: $\xi_i = 1$ for $i=1 \dots N_{out}$ [S1].
    *   Randomly initialize NeRF parameters $\Theta^{(A)}$, rotations $R_i$, translations $t_i$, and focal lengths $f^{(A)}$ [S1].
    *   Withhold all zoomed-in images ($j > N_{out}$) from training [S1].
    *   Optimize $\Theta^{(A)}$, $R_i$, $t_i$, and $f^{(A)}$ by minimizing the coarse loss $L_{coarse}$ over the $N_{out}$ images [S1].
    *   The coarse loss is defined as:
        $$ L_{coarse} = \sum_{i=1}^{N_{out}} \| F_{\Theta^{(A)}}(\Theta^{(A)}, \Pi_i) - I_i \|_2^2 $$
        where $\Pi_i = (R_i, t_i, f, c, \xi_i)$ and $F_{\Theta}$ is the differentiable volume renderer [S1].
    *   Output: Coarse NeRF parameters $\Theta^{(A)}$ and globally consistent poses for zoomed-out views [S1].

2.  **Cross-Zoom Pose Registration (Initialization for Phase B)**
    *   For each zoomed-in image $I_j$ ($j > N_{out}$):
        *   Find the best matching zoomed-out image $g^*(j)$ from the set of $N_{out}$ images [S1].
        *   Extract the central $1/\xi_j$ crop from the zoomed-out image $I_{g^*(j)}$ [S1].
        *   Bilinearly resize the crop to the native resolution of $I_j$ to create a surrogate view $\tilde{I}_{g^*(j) \to j}$ [S1].
        *   Select $g^*(j)$ that minimizes the RGB mean-squared error between $I_j$ and $\tilde{I}_{g^*(j) \to j}$ [S1].
    *   **Pose Priming:** Initialize the pose $\Pi_j$ for each zoomed-in image $j$ by copying the rotation $R_{g^*(j)}$, translation $t_{g^*(j)}$, and focal length $f$ from the matched zoomed-out image $g^*(j)$ [S1]. The zoom parameter $\xi_j$ is initialized from the rough estimate [S1].

3.  **Phase B: Zoom-in Pose Registration**
    *   Freeze NeRF parameters at $\Theta^{(A)}$ [S1].
    *   For each zoomed-in image $j$, optimize only the rotation $R_j$, translation $t_j$, and zoom parameter $\xi_j$ [S1].
    *   Intrinsics $f$ and $c$ remain fixed from the surrogate initialization [S1].
    *   Minimize the pose loss $L_{pose}$:
        $$ L_{pose} = \sum_{j=N_{out}+1}^{N} \| F_{\Theta^{(A)}}(\Theta^{(A)}, \Pi_j) - I_j \|_2^2 $$
        where $\Pi_j = (R_j, t_j, f, c, \xi_j)$ [S1].
    *   Output: Provisional full pose set $\Pi^{(B)} = \{\Pi_i^{(A)}\}_{i=1}^{N_{out}} \cup \{\Pi_j^{(B)}\}_{j=N_{out}+1}^{N}$ [S1].

4.  **Phase C: Joint Refinement**
    *   Initialize NeRF parameters $\Theta^{(C)} = \Theta^{(A)}$ [S1].
    *   Unfreeze all NeRF parameters and all camera pose parameters (including all $\xi_k$) [S1].
    *   Optimize jointly over all $N$ images by minimizing the fine loss $L_{fine}$:
        $$ L_{fine} = \sum_{k=1}^{N} \| F_{\Theta^{(C)}}(\Theta^{(C)}, \Pi_k) - I_k \|_2^2 $$
    *   Output: Final NeRF parameters and pixel-accurate poses [S1].

**Pseudocode**

```python
def mzen_training(images, initial_zoom_estimates, N_out):
    """
    images: list of N images, each a 2D array of shape (H, W, 3)
    initial_zoom_estimates: list of N floats
    N_out: int, number of zoomed-out images
    """
    N = len(images)
    
    # Phase A: Global Pose Bootstrap
    zoom_params = [1.0] * N_out + initial_zoom_estimates[N_out:]
    theta_A = random_init_nerf()
    poses_A = random_init_poses(N_out)
    focal_length = random_init_focal_length()
    principal_point = [0.0, 0.0]
    lr = 0.01  # [G] Learning rate
    
    # Minimize L_coarse over N_out images
    for _ in range(Phase_A_iterations):
        loss = 0.0
        for i in range(N_out):
            pi_i = (poses_A[i].R, poses_A[i].t, focal_length, principal_point, zoom_params[i])
            rendered_i = volume_renderer(theta_A, pi_i, images[i].shape)
            loss += l2_norm(rendered_i - images[i])
        theta_A, poses_A, focal_length = update_parameters(theta_A, poses_A, focal_length, loss)
        
    theta_star = theta_A
    
    # Cross-Zoom Pose Registration
    poses_B = list(poses_A)
    zoom_params_B = list(zoom_params)
    
    for j in range(N_out, N):
        best_match_idx = argmin([l2_norm(images[j] - bilinear_resize(extract_center_crop(images[g], 1.0/initial_zoom_estimates[j]), images[j].shape)) for g in range(N_out)])
        matched_pose = poses_A[best_match_idx]
        poses_B.append(matched_pose)
        zoom_params_B.append(initial_zoom_estimates[j])
        
    # Phase B: Zoom-in Pose Registration
    for _ in range(Phase_B_iterations):
        loss = 0.0
        for j in range(N_out, N):
            pi_j = (poses_B[j].R, poses_B[j].t, focal_length, principal_point, zoom_params_B[j])
            rendered_j = volume_renderer(theta_star, pi_j, images[j].shape)
            loss += l2_norm(rendered_j - images[j])
        poses_B, zoom_params_B = update_parameters(poses_B, zoom_params_B, loss, freeze_nerf=True)
        
    # Phase C: Joint Refinement
    theta_C = theta_star
    poses_final = poses_B
    zoom_final = zoom_params_B
    
    for _ in range(Phase_C_iterations):
        loss = 0.0
        for k in range(N):
            pi_k = (poses_final[k].R, poses_final[k].t, focal_length, principal_point, zoom_final[k])
            rendered_k = volume_renderer(theta_C, pi_k, images[k].shape)
            loss += l2_norm(rendered_k - images[k])
        theta_C, poses_final, zoom_final = update_parameters(theta_C, poses_final, zoom_final, loss, freeze_nerf=False)
        
    return theta_C, poses_final, zoom_final

def random_init_nerf():
    """[G] Initialize MLP weights with small random values."""
    return np.random.randn(1000)

def random_init_poses(n):
    """[G] Initialize poses with identity rotation and zero translation."""
    return [(np.eye(3), np.zeros(3)) for _ in range(n)]

def random_init_focal_length():
    """[G] Initialize base focal length."""
    return np.array([1.0, 1.0])

def volume_renderer(theta, pose, img_shape):
    """[G] Standard differentiable volume rendering forward pass."""
    return np.zeros(img_shape)

def extract_center_crop(image, scale):
    h, w = image.shape[:2]
    ch, cw = int(h * scale), int(w * scale)
    y0, x0 = (h - ch) // 2, (w - cw) // 2
    return image[y0:y0+ch, x0:x0+cw]

def bilinear_resize(crop, target_shape):
    """[G] Standard bilinear interpolation resize."""
    return np.zeros(target_shape)

def l2_norm(a, b):
    return np.sum((a - b) ** 2)

def argmin(values):
    return int(np.argmin(values))

def update_parameters(*params, loss, freeze_nerf=False):
    """[G] Standard gradient descent update step."""
    updated = []
    for p in params:
        grad = compute_gradient(loss, p)
        if freeze_nerf and p is theta_A:
            updated.append(p)
        else:
            updated.append(p - lr * grad)
    return tuple(updated) if len(updated) > 1 else updated[0]

def compute_gradient(loss, param):
    """[G] Standard automatic differentiation or finite difference gradient."""
    return np.zeros_like(param)
```

**Parameters**
*   **Zoom parameter $\xi_k$:** Learnable intrinsic parameter. $\xi_k=1$ for zoomed-out, $\xi_k > 1$ for zoomed-in [S1].
*   **Step size $\eta$:** Must satisfy $\eta \in (0, 1/L]$ where $L$ is the Lipschitz constant of the gradients [S1].
*   **PL constant $\mu$:** Positive constant defining the local Polyak-Łojasiewicz condition [S1].

**Edge Cases and Pitfalls**
*   Simultaneous optimization of NeRF parameters and camera poses across all zoom levels is unstable; the three-phase schedule is required [S1].
*   Standard NeRF formulations assume fixed or small zoom-level perturbations; significant magnification changes break these assumptions, coupling translation, scale, and focal length [S1].
*   Pose priming converges faster than random initialization because the initial error is $O(\delta^2)$ (crop misregistration) compared to $O(\sigma_{rand}^2)$ (random noise), where $\delta \ll \sigma_{rand}$ [S1].

## Operating characteristics
*   **Time Complexity:** The method requires three sequential optimization phases. Phase A scales with $N_{out}$, Phase B with $N_{in}$, and Phase C with $N$. Theoretical analysis shows linear convergence rate $e^{(t+1)} \leq (1 - \eta\mu) e^{(t)}$ for Phase B under the PL condition [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Does not require high-resolution images or external pose initialization (unlike [Mip-NeRF 360 MLP Architecture](14098-mip-nerf-360-mlp-architecture.md) or [CamP](14098-mip-nerf-360-mlp-architecture.md)). Handles non-overlapping zoomed-in and zoomed-out views via cross-zoom registration [S1].
*   **Limitations:** Requires a rough initial estimate of zoom parameters (e.g., from dial readings) [S1]. Performance degrades if Phase B (cross-zoom matching) is skipped or if wide-field views are absent [S1].
*   **When to use:** Industrial imaging systems (microscopes, SEMs) where exact calibration is unavailable and stage movement is minimal [S1].

## Background
MZEN was introduced to address the failure of classical Structure-from-Motion (SfM) and standard pose-free NeRFs in industrial imaging contexts where optical zoom changes significantly [S1]. It explicitly models optical magnification as a learnable intrinsic parameter and uses cross-zoom pose registration to align views [S1]. The method is designed for scenarios where the specimen stage moves only microns, making traditional pose estimation unreliable [S1].
