# Dynamic Appearance Particle Neural Radiance Field

Also called: Dynamic Appearance Particle NeRF, Lagrangian dynamic model in NeRF

## Overview
Dynamic Appearance Particle NeRF is a method for modeling dynamic scenes from monocular video data by combining a static grid-based radiance field with a particle-based dynamic component [S1]. It solves the problem of reconstructing time-varying scenes without requiring multi-view stereo data or prior geometric knowledge of dynamic objects [S1]. Unlike ParticleNeRF, which encodes the entire scene with particles and requires multiple views per frame, this method applies appearance particles only to dynamic elements and uses a grid-based field for efficient querying, enabling reconstruction from single-camera inputs [S1].

## How it works
The method models the dynamic radiance field $V(x, t)$ as a superposition of a static component $V_s(x)$ and a dynamic component $V_{td}(x)$ [S1]. The rendering process follows the standard volume rendering integral, but the field values are determined by the particle-based dynamic model [S1].

### Inputs and Outputs
*   **Inputs:** Monocular video data (sequence of images at times $t$); camera poses for each frame.
*   **Outputs:** Rendered pixel colors $C(r, t)$ for arbitrary rays $r$ and times $t$ [S1].

### Data Structures
1.  **Static Field ($V_s$):** A time-independent grid-based model (e.g., canonical feature field) [S1].
2.  **Dynamic Field ($V_{td}$):** An ensemble of particles. Each particle has a position, appearance features, and a motion state [S1].
3.  **Particle Motion Network:** A neural network that predicts particle motion [S1].
4.  **Appearance Network:** A network (e.g., MLP) that maps particle features to radiance [S1].

### Formulas
The rendered color $C(r, t)$ for a ray $r(s) = o + sd$ at time $t$ is computed by integrating along the ray from near bound $s_n$ to far bound $s_f$ [S1]:

$$
C(r, t) = \int_{s_n}^{s_f} T(s) \sigma(r(s), t) c(r(s), d, t) ds
$$

where $T(s) = \exp\left(-\int_{s_n}^{s} \sigma(r(s'), t) ds'\right)$ is the accumulated transmittance, $\sigma$ is volume density, and $c$ is emitted radiance [S1].

The total field $V(x, t)$ is a superposition of static and dynamic components [S1]:

$$
V(x, t) = (1 - w_t(x))V_s(x) + w_t(x)V_{td}(x)
$$

where $V_s(x)$ is the static field, $V_{td}(x)$ is the dynamic field, and $w_t(x)$ is a weight that is 1 if the dynamic field is effective at $(x, t)$ and 0 otherwise [S1]. The support of the dynamic field is implied by the particle representation [S1].

The dynamic field $V_{td}$ is formulated as a convolution with a Dirac function to integrate over finite volumes [S1]:

$$
V_{td}(x) = (V_{td} * \delta)(x) = \int V_{td}(x') \delta(x - x') d\nu(x')
$$

where $\delta(\cdot)$ is the Dirac function [S1]. For implementation, the Dirac function is replaced by a kernel $W$ with finite support [S1]:

$$
W(x) = 0 \text{ when } \|x\| \text{ exceeds a small radius, and } \int W(x) d\nu(x) = 1
$$

This kernel approximation leads to a quantization of the field [S1].

### Steps
1.  **Initialize:** Set up the static grid-based field $V_s(x)$ and initialize the particle ensemble for the dynamic field $V_{td}(x)$ [S1].
2.  **Ray Casting:** For each pixel at time $t$, cast a ray $r(s) = o + sd$ from the camera center [S1].
3.  **Field Evaluation:** For each sample point $x$ along the ray:
    a. Query the static field $V_s(x)$ [S1].
    b. Determine the dynamic field contribution $V_{td}(x)$ using the particle kernel $W$ [S1].
    c. Compute the weighted superposition $V(x, t)$ using $w_t(x)$ [S1].
4.  **Rendering:** Integrate the transmittance and radiance along the ray to compute $C(r, t)$ [S1].
5.  **Optimization:** Update the static field parameters, particle positions, features, and motion network parameters to minimize the difference between rendered and ground truth images [S1].

### Parameters
*   $w_t(x)$: Weight for dynamic field effectiveness. Takes value 1 if dynamic field is effective at $(x, t)$, 0 otherwise [S1].
*   Kernel radius: Small radius for kernel $W$ [S1].

### Edge Cases and Pitfalls
*   **Particle Density:** If particles are too sparse, the dynamic field may not capture fine details [S1].
*   **Kernel Support:** The kernel radius must be chosen to balance smoothness and detail [S1].
*   **Monocular Ambiguity:** Without multi-view constraints, disambiguating dynamic from static elements can be challenging [S1].

## Operating characteristics
*   **Time Complexity:** Depends on the number of particles and samples per ray. Linear interpolation in the grid-based field is efficient [S1].
*   **Memory Complexity:** Proportional to the number of particles and the size of the static grid [S1].
*   **Strengths:** Handles monocular video data; does not require prior geometric knowledge; efficient querying via grid interpolation [S1].
*   **Limitations:** May struggle with highly complex dynamic scenes if particle count is insufficient; monocular ambiguity [S1].
*   **When to use:** When only monocular video data is available and dynamic scene reconstruction is needed [S1].
*   **When not to use:** When multi-view data is available and higher accuracy is required (e.g., ParticleNeRF might be more suitable for multi-view) [S1].

## Background
The method was proposed in "Dynamic Appearance Particle Neural Radiance Field" [S1]. It builds on the concept of Lagrangian dynamic models in NeRF [S1]. It differs from ParticleNeRF, which encodes the entire scene with particles and requires 20 camera views per time frame [S1]. This method is not tightly coupled to a specific architecture and can be integrated into frameworks like InstantNGP [S1].
