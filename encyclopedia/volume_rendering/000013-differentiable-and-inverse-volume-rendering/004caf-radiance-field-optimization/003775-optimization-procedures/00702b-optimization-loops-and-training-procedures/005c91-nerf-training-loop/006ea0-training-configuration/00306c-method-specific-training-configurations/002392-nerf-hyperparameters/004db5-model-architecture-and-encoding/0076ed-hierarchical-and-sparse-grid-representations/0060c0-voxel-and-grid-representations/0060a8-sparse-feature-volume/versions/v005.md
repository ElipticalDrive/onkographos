# Sparse Feature Volume

Also called: NISR, Neural Implicit Scene Representation

## Overview
The Sparse Feature Volume is a 3D scene representation that encodes geometry and appearance into a sparse grid of learnable latent vectors, where each voxel stores features decoded into a continuous Signed Distance Function (SDF) and radiance field [S1, unofficial]. It differs from dense voxel grids by storing data only in occupied regions, offering higher resolution efficiency and better detail expression for surface reconstruction compared to continuous occupancy fields [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Multi-view images (or a monocular stream), camera poses, and a discretized 3D bounding box [S1, unofficial].
*   **Outputs:** A sparse feature volume $F_\theta$ (and radiance volume $F_\omega$) containing latent vectors per voxel, and a differentiable query function that returns SDF values $s$ and color values $c$ for any 3D point $x$ [S1, unofficial].

**Data Structures:**
The scene space is divided into a set of sparse voxels organized in a coarse-to-fine hierarchy [S1, unofficial].
*   **Levels:** Three levels are defined: coarse ($c$), middle ($m$), and fine ($f$) [S1, unofficial].
*   **Voxel Content:** Each voxel $v$ at level $l$ contains a feature latent vector $F_{\theta}^l$, while the radiance field uses a separate volume $F_\omega$ [S1, unofficial].
*   **Layout:** The structure is sparse, allocating voxels only where scene content exists, unlike dense $\mathbb{R}^{I \times J \times K}$ grids [S1, unofficial].

**Numbered Steps:**
1.  **Space Discretization:** Divide the 3D space into sparse voxels [S1, unofficial].
2.  **Feature Extraction:** Encode input multi-view images using a 2D CNN-based image encoder [S1, unofficial].
3.  **Spatial-Aware Fusion:** Fuse features from multiple views using a transformer module to build expressive latent vectors $F_\theta^l$ [S1, unofficial]. This replaces the channel-wise average fusion used in prior works [S1, unofficial].
4.  **Temporal Integration:** Merge the newly fused features with previous feature latent vectors using a GRU module, followed by a sparse 3D CNN, to form global feature latent vectors $F_\theta^l$ [S1, unofficial].
5.  **Volume Rendering Optimization:** Render images by accumulating opacity $\alpha_i$ and color $c_i$ along rays [S1, unofficial]. The SDF provides geometric regularization via normal maps $\hat{N}(r)$ [S1, unofficial].
6.  **Mesh Extraction:** Extract the surface mesh using Marching Cubes on the SDF field at arbitrary resolution [S1, unofficial].

**Formulas:**
*   **Query Interpolation:** $f(x) = \text{interp}(F_\theta^l, x)$, where $\text{interp}$ denotes trilinear interpolation in the sparse feature volume $F_\theta^l$ [S1, unofficial].
*   **SDF Decoder:** $s = f_\theta(x, \text{interp}(F_\theta^f, x))$, where $s$ is the signed distance, $f_\theta$ is an MLP-based decoder, $x \in \mathbb{R}^3$ is the query point, and $F_\theta^f$ is the fine-level feature volume [S1, unofficial].
*   **Radiance Decoder:** $c = f_\omega(x, \text{interp}(F_\omega, x))$, where $c$ is the color value, $f_\omega$ is an MLP-based radiance decoder, and $F_\omega$ is the radiance field latent vector [S1, unofficial].
*   **Volume Rendering Accumulation:** $\hat{C}(r) = \sum_{i=1}^N T_i \alpha_i c_i$ and $\hat{N}(r) = \sum_{i=1}^N T_i \alpha_i n_i$, where $T_i$ is the transmittance, $\alpha_i$ is the discrete opacity, $c_i$ is the color, $n_i$ is the normal measurement, and $N$ is the number of sampling points along ray $r$ [S1, unofficial].

**Parameters:**
*   **Levels:** $l \in \{c, m, f\}$ representing coarse, middle, and fine resolutions [S1, unofficial].
*   **Decoder Architectures:** MLPs $f_\theta$ and $f_\omega$ [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Interpolation Boundaries:** Trilinear interpolation assumes the query point lies within a valid voxel; points outside the sparse grid require boundary handling [G].
*   **Sparse Allocation:** Incorrect voxel culling or grid coordinate normalization will break the interpolation and decoding pipeline [G].

**Pseudocode:**
```python
import math

def trilinear_interp(v000, v100, v010, v110, v001, v101, v011, v111, fx, fy, fz):
    """Standard trilinear interpolation for 8 corner values using fractional coordinates."""
    lerp = lambda a, b, t: a * (1.0 - t) + b * t
    c00 = lerp(v000, v100, fx)
    c10 = lerp(v010, v110, fx)
    c01 = lerp(v001, v101, fx)
    c11 = lerp(v011, v111, fx)
    c0 = lerp(c00, c10, fy)
    c1 = lerp(c01, c11, fy)
    return lerp(c0, c1, fz)

def query_sparse_feature_volume(x, voxel_corners, decoder_sdf, decoder_radiance):
    """
    Query the sparse feature volume for SDF and color at point x.
    Args:
        x: Query point (x, y, z) in grid coordinates.
        voxel_corners: List of 8 latent vectors at the voxel corners.
        decoder_sdf: MLP function for SDF prediction.
        decoder_radiance: MLP function for color prediction.
    Returns:
        s: Signed distance value.
        c: Color value.
    """
    fx, fy, fz = x[0] - math.floor(x[0]), x[1] - math.floor(x[1]), x[2] - math.floor(x[2])
    f_geom = trilinear_interp(*voxel_corners, fx, fy, fz)
    s = decoder_sdf(x, f_geom)
    f_rad = trilinear_interp(*voxel_corners, fx, fy, fz)
    c = decoder_radiance(x, f_rad)
    return s, c

def construct_sparse_feature_volume(image_features, camera_poses, levels):
    """
    Construct the sparse feature volume from multi-view inputs following the 5-step pipeline.
    """
    sparse_grids = {l: {} for l in levels}
    fused_features = {}
    
    # Step 1 & 2: Space discretization and 2D CNN encoding (implementation details not provided in sources)
    # Step 3: Spatial-aware feature fusion using a transformer module
    # Step 4: Temporal integration using GRU and sparse 3D CNN
    # Note: The exact mathematical formulation for the transformer fusion, GRU merge, 
    # and sparse 3D CNN operations is not provided in the sources.
    for l in levels:
        fused_features[l] = {k: sum(v * w for v, w in zip(image_features, camera_poses)) for k, v in sparse_grids[l].items()}
        prev = sparse_grids[l].get('prev_features', None)
        gru_out = fused_features[l] if prev is None else (fused_features[l] + prev) / 2
        sparse_grids[l]['prev_features'] = gru_out
        
    return sparse_grids
```

## Operating characteristics
*   **Efficiency:** The sparse structure allows for higher resolution and more efficient geometry learning compared to dense grids, as computation is restricted to occupied voxels [S1, unofficial].
*   **Geometry Quality:** The use of continuous SDFs provides stronger detail expression and allows for gradient-domain supervision, leading to higher-fidelity surface reconstruction than occupancy fields [S1, unofficial].
*   **Online Capability:** The integration of GRU and sparse 3D CNN enables efficient online reconstruction from monocular or multi-view streams [S1, unofficial].
*   **Limitations:** Requires careful management of sparse voxel allocation and may be more complex to implement than dense grid methods due to the need for sparse data structures and transformer-based fusion [S1, unofficial].
*   **When to Use:** Suitable for online monocular/multi-view reconstruction where high-fidelity surface extraction and memory efficiency are prioritized over dense volumetric density estimation [S1, unofficial].

## Background
The Sparse Feature Volume, also known as Neural Implicit Scene Representation (NISR), was introduced in *MonoNeuralFusion: Online Monocular Neural 3D Reconstruction with Geometric Priors* [S1, unofficial]. It builds upon the sparse feature volume data structure from NeuralRecon but enhances it with spatial-aware feature fusion using transformers and SDF-based decoding for improved geometry representation [S1, unofficial].
