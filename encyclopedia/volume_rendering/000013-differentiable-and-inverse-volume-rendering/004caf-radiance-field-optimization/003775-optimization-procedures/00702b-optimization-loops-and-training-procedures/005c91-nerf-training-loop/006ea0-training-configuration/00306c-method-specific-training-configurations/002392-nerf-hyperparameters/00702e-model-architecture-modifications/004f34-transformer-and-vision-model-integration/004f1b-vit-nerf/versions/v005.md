# ViT-NeRF

Also called: Global-Local Feature NeRF, Hybrid ViT-CNN NeRF, Vision Transformer for NeRF (ViT-NeRF)

## Overview
ViT-NeRF is a view synthesis method that combines a Vision Transformer (ViT) to encode global shape information and a 2D CNN to extract local appearance features, conditioning volume rendering on hybrid per-pixel features [S1]. Unlike sibling methods that rely solely on local features (e.g., PixelNeRF) or global features without local refinement (e.g., CodeNeRF), ViT-NeRF produces sharper edges and clearer structures in unseen regions while maintaining color consistency in visible regions [S1]. It builds on the [Transformer and Vision Model Integration](13911-transformer-and-vision-model-integration.md) principles by replacing standard positional encoding with features extracted from a hybrid vision backbone.

## How it works
**Inputs:** A single input image $I_s \in \mathbb{R}^{H \times W \times 3}$, where $H$ and $W$ are height and width.
**Outputs:** A rendered 2D image $\hat{C}(\mathbf{r})$ for a target viewpoint defined by ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$.

**Data Structures:**
1.  **Image Tokens:** Sequence of flattened 2D patches $P \in \mathbb{R}^{N \times P^2 \times 3}$, where $N = \frac{HW}{P^2}$ is the number of patches and $P$ is the patch size.
2.  **Global Feature Maps:** A set of multi-level feature maps $W^0_G, \dots, W^J_G$, where $W^j_G \in \mathbb{R}^{H_j \times W_j \times D_j}$.
3.  **Local Feature Map:** $W_L \in \mathbb{R}^{\frac{H}{2} \times \frac{W}{2} \times D_L}$.
4.  **Hybrid Feature Map:** $W \in \mathbb{R}^{H \times W \times D}$, fused from global and local features.
5.  **NeRF MLP:** A multi-layer perceptron mapping encoded coordinates and features to density $\sigma$ and color $\mathbf{c}$.

**Numbered Steps:**

1.  **Global Feature Extraction (ViT):**
    *   Reshape $I_s$ into patches and linearly project to image tokens.
    *   Add learnable positional embeddings $\epsilon$.
    *   Process through Transformer Encoder layers to extract latent features $f$.
    *   Drop the class token (which has no physical meaning when unflattened) [S1].
    *   Unflatten the remaining tokens into feature patches $P_f$.
    *   Decode into multi-level global feature maps $W^j_G$ using convolutional decoders $D$:
        $$W^j_G = (D \circ U \circ O)(f_j), \quad j \in \{0, \dots, J\}$$
        where $O$ drops the class token, $U$ unflattens, and $D$ involves $1\times1$ convolution, strided/transposed convolution for resizing, and $3\times3$ convolution [S1].

2.  **Local Feature Extraction (CNN):**
    *   Pass $I_s$ through a 2D CNN module $G_L$ consisting of three ResBlocks to extract local features:
        $$W_L = G_L(I_s)$$
        This step addresses the inconsistency in color/appearance for views close to the input view when using only global ViT features [S1].

3.  **Feature Fusion:**
    *   Fuse global maps $W^0_G, \dots, W^J_G$ and local map $W_L$ using a convolutional layer $G$ to produce the hybrid feature map $W$:
        $$W = G(W^0_G, W^1_G, \dots, W^J_G; W_L)$$

4.  **Volumetric Rendering:**
    *   For a target ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ bounded by $t_{near}$ and $t_{far}$, sample points $\mathbf{x}_c$ along the ray.
    *   Project $\mathbf{x}_c$ to 2D coordinates $\pi(\mathbf{x}_c)$ on the input image plane.
    *   Sample the hybrid feature $W(\pi(\mathbf{x}_c))$ from the feature map $W$.
    *   Encode the 3D location $\mathbf{x}_c$ using positional encoding $\gamma(\mathbf{x}_c)$ with $M=10$ frequency bases:
        $$\gamma(\mathbf{p}) = (\sin(2^0 \pi \mathbf{p}), \cos(2^0 \pi \mathbf{p}), \dots, \sin(2^{M-1} \pi \mathbf{p}), \cos(2^{M-1} \pi \mathbf{p}))$$
    *   Input $\gamma(\mathbf{x}_c)$, viewing direction $\mathbf{d}_c$, and feature $W(\pi(\mathbf{x}_c))$ into the NeRF MLP to predict density $\sigma$ and color $\mathbf{c}$:
        $$(\sigma, \mathbf{c}) = \text{MLP}(\gamma(\mathbf{x}_c); \mathbf{d}_c; W(\pi(\mathbf{x}_c)))$$
    *   Render the image via volume rendering integral approximation:
        $$\hat{C}(\mathbf{r}) = \int_{t_n}^{t_f} T(t) \sigma(t) \mathbf{c}(t) dt, \quad T(t) = \exp\left(-\int_{t_n}^{t} \sigma(\mathbf{r}(s)) ds\right)$$

**Parameters:**
*   **Frequency bases ($M$):** 10 [S1].
*   **Learning Rate:** $10^{-4}$ for the NeRF MLP; $10^{-5}$ for ViT and CNN modules [S1].
*   **Batch Size:** 8 instances, with 512 rays per instance [S1].
*   **ViT Initialization:** Pretrained weights from reference [55] (DINO), fine-tuned during training [S1].
*   **CNN Architecture:** $G_L$ consists of three ResBlocks [S1].

**Pitfalls:**
*   Using only global ViT features compromises rendering quality for views close to the input view (inconsistent color/appearance) [S1].
*   The class token in ViT must be dropped before decoding into spatial feature maps as it has no physical meaning in that context [S1].

## Operating characteristics
*   **Performance:** Outperforms SRN and PixelNeRF in producing sharper edges and clearer structures, particularly on invisible parts like chair legs [S1]. Performs favorably against CodeNeRF and DISN without requiring a canonical coordinate system [S1].
*   **Hardware:** Trained on 16 NVIDIA A100 GPUs [S1].
*   **Convergence:** Converges at 500K iterations [S1].
*   **Training Stability:** Uses a linear warm-up schedule for the first 10k steps [S1].
*   **Limitations:** Volume-based methods are computationally intensive and require more memory when increasing grid size [S1].

## Background
ViT-NeRF was introduced in "Vision Transformer for NeRF-Based View Synthesis from a Single Input Image" [S1]. It addresses the limitations of previous methods by combining the long-range dependency modeling of Vision Transformers with the local appearance fidelity of CNNs. Unlike CodeNeRF and DISN, it does not require a canonical coordinate system to utilize global features [S1].
