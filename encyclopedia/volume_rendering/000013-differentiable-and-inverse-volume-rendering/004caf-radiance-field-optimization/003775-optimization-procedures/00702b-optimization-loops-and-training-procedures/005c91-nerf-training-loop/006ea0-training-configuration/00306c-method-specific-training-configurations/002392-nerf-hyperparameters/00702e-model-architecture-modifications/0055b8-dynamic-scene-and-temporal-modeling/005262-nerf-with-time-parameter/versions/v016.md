# NeRF with Time Parameter

Also called: NeRF + time, NeRF with Time Parameter Baseline, Time-NeRF

## Overview
This method adapts the static Neural Radiance Field (NeRF) architecture for dynamic scenes by introducing a temporal dimension to the input space [S1]. It solves the problem of representing time-varying geometry and appearance by allowing the network to condition its density and color predictions on a specific timestamp [S1]. Unlike advanced dynamic NeRF variants that model explicit motion fields or scene graphs, this approach relies solely on the network's capacity to interpolate or extrapolate scene states through the time parameter, serving as a baseline for temporal modeling [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A 3D spatial coordinate $\mathbf{x} \in \mathbb{R}^3$, a viewing direction $\mathbf{d} \in \mathbb{R}^3$, and a scalar time parameter $t \in \mathbb{R}$ [S1].
*   **Outputs:** Volume density $\sigma \in \mathbb{R}$ and view-dependent color $\mathbf{c} \in \mathbb{R}^3$ [S1].

**Data Structures:**
The neural network is a Multi-Layer Perceptron (MLP). The input layer accepts the concatenated positional encodings of spatial coordinates and time. The architecture follows the standard NeRF configuration used for real forward-facing experiments [S1].

**Steps:**
1.  **Positional Encoding of Time:** Apply the same positional encoding function $\gamma_t$ used for spatial coordinates to the time parameter $t$ [S1].
2.  **Concatenation:** Concatenate the encoded time $\gamma_t(t)$ with the encoded spatial position $\gamma_x(\mathbf{x})$ to form the combined input vector $\mathbf{z} = [\gamma_x(\mathbf{x}); \gamma_t(t)]$ [S1].
3.  **Network Forward Pass:** Feed $\mathbf{z}$ and the viewing direction $\mathbf{d}$ into the NeRF MLP to predict density $\sigma$ and color $\mathbf{c}$ [S1].
4.  **Volume Rendering:** Render the image using the standard volume rendering integral, summing contributions from sampled points along rays parameterized by time $t$ [G].

**Pseudocode:**
```python
def nerf_with_time_forward(x, d, t, network):
    """
    x: (3,) spatial coordinates
    d: (3,) viewing direction
    t: (1,) scalar time parameter
    network: The NeRF MLP model
    """
    # 1. Positional encoding of time
    # Assuming gamma_t is the same positional encoding function as gamma_x
    t_encoded = gamma_t(t)
    
    # 2. Concatenate with spatial encoding
    # gamma_x(x) is assumed to be pre-computed or computed similarly
    x_encoded = gamma_x(x)
    z = concatenate([x_encoded, t_encoded])
    
    # 3. Forward pass through the network
    # The network takes the concatenated encoding and direction
    sigma, color = network(z, d)
    
    return sigma, color
```

**Parameters:**
*   **Training Configuration:** The configuration reported for NeRF's real forward-facing experiments is used [S1]. Specific hyperparameters (learning rate, layer sizes) are not detailed in the sources beyond this reference [S1].

**Edge Cases and Pitfalls:**
*   **Blurriness:** The method suffers from blurry predictions and lacks detail compared to more complex dynamic scene representations [S1].
*   **Lack of Dynamics Reasoning:** The model cannot explicitly reason about scene dynamics; it treats time as an additional input dimension without enforcing temporal consistency or motion constraints [S1].
*   **Ghosting:** While improved over vanilla NeRF, it may still exhibit artifacts if the temporal interpolation is insufficient for rapid scene changes [S1].

## Subtopics

### Temporal Compression of NeRF Models
A compression strategy for sequences of NeRF models that exploits temporal redundancy by treating the first model as a key-frame and compressing only the deltas between successive models [S2].
*   **Definition:** The system design stems from the insight that neighboring NeRF models share considerable similarities [S2].
*   **Training Strategy:** Each NeRF is initialized based on the previous frame’s NeRF, except for the first frame’s NeRF, which is trained from the beginning as the starting point [S2]. This encourages temporal redundancy and saves training time [S2].
*   **Compression Step:** For a sequence of trained NeRF models, the first model is regarded as a “key-frame” or “I-frame” [S2]. The deltas between the current frame's NeRF weights and the previous frame's NeRF weights are calculated [S2].
*   **Encoding:** Exponent-based quantization and Huffman coding are applied to the deltas [S2].
*   **Decoding:** To restore a model, the decoded deltas are accumulated to the reference model (the previous frame's model) [S2].

## Operating characteristics
*   **Quality:** Adding a time parameter improves quality over vanilla NeRF but still lacks detail and suffers from blurry predictions [S1].
*   **Limitations:** It fails to reason about scene dynamics, leading to inferior performance on complex dynamic scenes compared to methods that explicitly model motion or scene graphs [S1].
*   **Performance:** Quantitative results on KITTI data show that while PSNR and SSIM improve over vanilla NeRF, they remain lower than advanced methods like Neural Scene Graphs [S1]. Specifically, on KITTI, NeRF + time achieves a PSNR of 24.18 and SSIM of 0.677, compared to 23.34 and 0.662 for vanilla NeRF, but significantly lower than the proposed graph method's 26.66 and 0.806 [S1].
*   **Use Case:** Suitable as a baseline for temporal NeRF research or for scenes with slow, smooth temporal variations where explicit motion modeling is not required [S1].

## Background
*   **Origin:** Introduced in "Neural Scene Graphs for Dynamic Scenes" by Yuang Shi et al. (CVPR 2021) [S1].
*   **Context:** SRNs and NeRF were originally designed for static scenes [S1]. This method represents the simplest adaptation to dynamic scenes by augmenting the input space [S1].
*   **Development:** It serves as a comparative baseline to demonstrate the necessity of more complex temporal modeling techniques, such as neural scene graphs, which can explicitly handle scene dynamics and novel scene compositions [S1].
