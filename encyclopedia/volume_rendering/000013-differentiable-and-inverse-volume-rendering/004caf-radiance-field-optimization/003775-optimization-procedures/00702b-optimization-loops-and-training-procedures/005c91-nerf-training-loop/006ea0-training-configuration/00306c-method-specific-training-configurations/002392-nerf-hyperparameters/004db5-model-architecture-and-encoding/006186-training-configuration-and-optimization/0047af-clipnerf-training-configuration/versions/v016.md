# CLIPNeRF Training Configuration

Also called: Absolute Directional CLIP Loss, CLIPNeRF Hyperparameters, CLIPNeRF Implementation, Directional CLIP Loss, Relative Directional CLIP Loss, StyleGAN-NADA CLIP Loss

## Overview
CLIPNeRF training configuration defines the optimization procedure for text-guided stylization of Neural Radiance Fields (NeRFs) by minimizing the negative cosine similarity between rendered images and text embeddings in the CLIP space [S1, S2]. It distinguishes itself from standard NeRF reconstruction by freezing density parameters and utilizing a directional loss that enforces semantic alignment rather than photometric fidelity [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A pre-trained NeRF model (density and color networks), a source image $\mathbf{I}_{src}$ (optional, for relative loss), a target text prompt $\mathbf{t}_{tgt}$, and a source text prompt $\mathbf{t}_{src}$ (optional, for relative loss).
*   **Output:** Updated NeRF parameters (specifically color/feature fields) that produce stylized renderings aligned with $\mathbf{t}_{tgt}$.

**Data Structures:**
*   **CLIP Model:** Uses CLIP ViT-B/32 [S1]. The image encoder $\mathcal{E}_i$ and text encoder $\mathcal{E}_t$ produce normalized embedding vectors $\hat{\mathbf{e}}_i$ and $\hat{\mathbf{e}}_t$ [S2].
*   **Rendering Patch:** To manage memory, rendering is performed on a $128 \times 128$ pixel patch [S1].
*   **Ray Sampling:** Rays for the patch are sampled with a stride of 5, covering a $640 \times 640$ receptive field of the original image [S1].
*   **Sampling Points:** Importance sampling uses 16 points per ray [S1]. The fine MLP uses 64 coarse samples + 16 fine samples = 80 total samples [S1].

**Loss Functions:**
Two variants of the directional CLIP loss are defined [S2]:

1.  **Absolute Directional CLIP Loss:** Measures cosine similarity between the rendered image $\mathbf{I}_{tgt}$ and the target text prompt $\mathbf{t}_{tgt}$ [S2].
    $$
    \mathcal{L}_{dir}^{abs} = 1 - \langle \hat{\mathcal{E}}_i(\mathbf{I}_{tgt}), \hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) \rangle
    $$
    This guides the NeRF with a global direction but ignores magnitude [S2].

2.  **Relative Directional CLIP Loss:** Transfers style from a source domain to a target domain using a pair of text prompts $(\mathbf{t}_{src}, \mathbf{t}_{tgt})$ [S2].
    $$
    \mathcal{L}_{dir}^{rel} = 1 - \langle \hat{\mathcal{E}}_i(\mathbf{I}_{tgt}) - \hat{\mathcal{E}}_i(\mathbf{I}_{src}), \hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) - \hat{\mathcal{E}}_t(\mathbf{t}_{src}) \rangle
    $$
    This enforces the correct stylization trajectory relative to the source [S2].

**Optimization Procedure:**
1.  **Freeze Density:** Freeze sub-parameters related to density $\sigma$ to prevent structural changes [S1].
2.  **Sample View:** Randomly sample a pose from the training dataset [S1].
3.  **Render Patch:** Render a $128 \times 128$ patch using the configured ray stride and sampling points [S1].
4.  **Resize:** Apply bilinear interpolation to resize the patch if necessary for the CLIP input size [S1].
5.  **Compute Loss:** Calculate $\mathcal{L}_{dir}$ using the CLIP embeddings [S1, S2].
6.  **Update:** Minimize the loss using the Adam optimizer [S1].

```python
    # 3. Render patch
    # Ray stride 5, patch size 128x128
    patch_image = nerf_model.render_patch(pose, patch_size=128, ray_stride=5)
    
    # 4. Resize for CLIP
    # [G] CLIP ViT-B/32 expects 224x224 input
    resized_patch = F.interpolate(patch_image, size=224, mode='bilinear', align_corners=False)
    
    # 5. Compute CLIP embeddings
    image_emb = clip_model.encode_image(resized_patch)
    text_emb = clip_model.encode_text(text_prompt)
    
    # Normalize embeddings
    image_emb = F.normalize(image_emb, dim=-1)
    text_emb = F.normalize(text_emb, dim=-1)
    
    # 6. Compute Absolute Directional Loss
    # L_dir = 1 - <e_i, e_t>
    similarity = torch.cosine_similarity(image_emb, text_emb, dim=-1)
    loss = 1.0 - similarity.mean()
    
    # 7. Backpropagate
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    
    return loss.item()
```

**Parameters:**
*   **Iterations:** 500 [S1].
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** 0.0001 [S1].
*   **Text Encoder:** CLIP ViT-B/32 [S1].
*   **Patch Size:** $128 \times 128$ [S1].
*   **Ray Stride:** 5 [S1].
*   **Importance Sampling Points:** 16 [S1].
*   **Fine MLP Samples:** 80 total (64 coarse + 16 fine) [S1].

**Edge Cases and Pitfalls:**
*   **Memory Constraints:** Naive differentiable rendering of high-resolution images is intractable due to memory constraints [S1]. The patch-based approach is required [S1].
*   **Mode Collapse:** The absolute directional CLIP loss can cause mode collapse of the generator and hurt generation diversity [S2].
*   **Insufficient Magnitude:** The directional loss measures similarity but ignores magnitude, potentially resulting in weak or insufficient style transfer [S2].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of iterations (500) and the number of rays in the patch. The patch-based rendering reduces memory complexity significantly compared to full-image rendering [S1].
*   **Memory Complexity:** Reduced by rendering only $128 \times 128$ patches and using fewer sampling points (16) [S1].
*   **Strengths:** Enables text-guided stylization of 3D scenes without requiring 3D annotations [S2].
*   **Limitations:** May suffer from mode collapse (absolute loss) or insufficient stylization magnitude (directional loss) [S2].
*   **When to use:** When text-guided stylization of NeRFs is required and computational resources are limited [S1, S2].
*   **When not to use:** When high-fidelity photometric reconstruction is the primary goal, or when diverse stylization outputs are critical without careful tuning [S2].

## Background
The CLIPNeRF training configuration originates from the work on text-driven NeRF stylization [S1, S2]. The directional CLIP loss was first designed in StyleCLIP for face image editing and extended to generative NeRF editing in CLIP-NeRF [S2]. It was further analyzed in StyleGAN-NADA, which highlighted the issues of mode collapse and magnitude loss [S2]. NeRF-Art proposed the relative directional loss to address these issues by using source and target text prompts [S2]. The specific implementation details (patch rendering, freezing density) were detailed in the context of feature field distillation [S1].
