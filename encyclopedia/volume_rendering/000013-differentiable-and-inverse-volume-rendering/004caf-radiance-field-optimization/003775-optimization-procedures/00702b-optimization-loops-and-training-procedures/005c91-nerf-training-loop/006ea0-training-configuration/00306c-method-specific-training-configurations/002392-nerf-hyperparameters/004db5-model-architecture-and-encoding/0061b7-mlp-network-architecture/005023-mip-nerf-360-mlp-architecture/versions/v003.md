# Mip-NeRF 360 MLP Architecture

Also called: Integrated Positional Encoding MLP, PosEnc MLP

## Overview
This architecture defines the multi-layer perceptron (MLP) used in the Mip-NeRF 360 implementation to predict volume density and view-dependent color from 3D coordinates and viewing directions. It distinguishes itself from standard NeRF by employing **integrated positional encoding** [S1, unofficial], which analytically integrates the positional encoding function over Gaussian distributions (defined by mean and covariance) to handle aliasing and frequency-aware rendering. It also supports optional **Integrated Directional Encoding (IDE)** for view-dependent effects and advanced shading features like specular tinting and diffuse/specular splitting [S1, unofficial].

## How it works
The architecture consists of two main components: a density network and a color network, separated by a bottleneck layer. The density network processes spatial information using integrated positional encoding, while the color network processes directional information.

### Inputs and Outputs
**Inputs:**
*   $\mathbf{x} \in \mathbb{R}^3$: 3D position.
*   $\mathbf{\Sigma} \in \mathbb{R}^{3 \times 3}$: Covariance matrix of the Gaussian distribution at $\mathbf{x}$ (used for integrated encoding).
*   $\mathbf{d} \in \mathbb{R}^3$: Viewing direction (or reflection direction).
*   $\mathbf{n} \in \mathbb{R}^3$: Surface normal (optional, for view-dependent features).

**Outputs:**
*   $\sigma \in \mathbb{R}$: Raw volume density.
*   $\mathbf{c} \in \mathbb{R}^3$: Final RGB color.
*   $\mathbf{n}_{pred} \in \mathbb{R}^3$: Predicted surface normal (optional).

### Data Structures and Parameters
The architecture is configured via a set of hyperparameters [S1, unofficial]:

| Parameter | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `net_depth` | int | 8 | Depth of the density MLP. |
| `net_width` | int | 256 | Width of the density MLP layers. |
| `bottleneck_width` | int | 256 | Width of the feature vector connecting density and color networks. |
| `net_depth_viewdirs` | int | 1 | Depth of the color MLP. |
| `net_width_viewdirs` | int | 128 | Width of the color MLP layers. |
| `min_deg_point` | int | 0 | Minimum degree for positional encoding of points. |
| `max_deg_point` | int | 12 | Maximum degree for positional encoding of points. |
| `skip_layer` | int | 4 | Frequency of skip connections in the density MLP. |
| `skip_layer_dir` | int | 4 | Frequency of skip connections in the color MLP. |
| `deg_view` | int | 4 | Degree of encoding for view directions. |
| `density_bias` | float | -1.0 | Bias added to raw density before activation. |
| `density_noise` | float | 0.0 | Standard deviation of noise added to raw density. |
| `rgb_bias` | float | 0.0 | Bias added to raw color before activation. |
| `rgb_padding` | float | 0.001 | Padding applied to RGB output range. |
| `use_reflections` | bool | False | Use reflection directions instead of view directions. |
| `use_directional_enc` | bool | False | Use Integrated Directional Encoding (IDE). |
| `use_diffuse_color` | bool | False | Predict diffuse and specular colors separately. |
| `use_specular_tint` | bool | False | Predict a tint vector for specular color. |
| `use_n_dot_v` | bool | False | Feed $\mathbf{n} \cdot \mathbf{d}$ to the color network. |
| `basis_shape` | str | 'icosahedron' | Basis shape for integrated encoding ('octahedron' or 'icosahedron'). |
| `basis_subdivisions` | int | 2 | Tessellation count for the basis shape. |

### Detailed Steps

1.  **Setup**:
    *   If `use_reflections` is True, verify that normals are enabled (`enable_pred_normals` is True or `disable_density_normals` is False). If not, raise `ValueError` [S1, unofficial].
    *   Precompute the transpose of the basis matrix using `geopoly.generate_basis(basis_shape, basis_subdivisions)` and store as `self.pos_basis_t` [S1, unofficial].
    *   If `use_directional_enc` is True, generate the Integrated Directional Encoding (IDE) function using `ref_utils.generate_ide_fn(deg_view)`. Otherwise, define `dir_enc_fn` to use standard positional encoding with `min_deg=0`, `max_deg=deg_view`, and `append_identity=True` [S1, unofficial].

2.  **Density Prediction**:
    *   If `warp_fn` is not None, linearize means and covs using `coord.track_linearize(warp_fn, means, covs)` [S1, unofficial].
    *   Lift and diagonalize means and covs using `coord.lift_and_diagonalize(means, covs, pos_basis_t)` to get `lifted_means` and `lifted_vars` [S1, unofficial].
    *   Compute integrated positional encoding using `coord.integrated_pos_enc(lifted_means, lifted_vars, min_deg_point, max_deg_point)` to get input $x$ [S1, unofficial].
    *   Iterate $i$ from 0 to `net_depth`-1. Apply a dense layer with width `net_width` and activation `net_activation` (typically Tanh). If $i > 0$ and $i \% \text{skip\_layer} == 0$, concatenate $x$ with the original integrated positional encoding inputs along the last axis [S1, unofficial].
    *   Output raw density using a dense layer with width 1: `raw_density = dense_layer(1)(x)[..., 0]` [S1, unofficial].
    *   If `density_key` is not None and `density_noise` > 0, add noise: `raw_density += density_noise * random.normal(density_key, raw_density.shape)` [S1, unofficial].

3.  **Normal Computation**:
    *   If `disable_density_normals` is False, flatten means and covs. Use `jax.vmap(jax.value_and_grad(predict_density, has_aux=True))` to compute `raw_density` and `raw_grad_density` simultaneously [S1, unofficial].
    *   Compute normals as negative normalized `raw_grad_density`: `normals = -ref_utils.l2_normalize(raw_grad_density)` [S1, unofficial].

4.  **Density Activation**:
    *   Compute final density = `density_activation(raw_density + density_bias)` [S1, unofficial].

5.  **Directional Encoding**:
    *   Broadcast `dir_enc` to match bottleneck shape dimensions: `dir_enc = jnp.broadcast_to(dir_enc[..., None, :], bottleneck.shape[:-1] + (dir_enc.shape[-1],))` [S1, unofficial].

6.  **Color Network Input**:
    *   Append `dir_enc` to bottleneck list $x$.
    *   If `use_n_dot_v` is True, compute `dotprod = jnp.sum(normals_to_use * viewdirs[..., None, :], axis=-1, keepdims=True)` and append to $x$ [S1, unofficial].
    *   If `glo_vec` is not None, broadcast `glo_vec` to match bottleneck shape and append to $x$ [S1, unofficial].
    *   Concatenate all elements in $x$ along the last axis [S1, unofficial].

7.  **Color Network**:
    *   Iterate $i$ from 0 to `net_depth_viewdirs`-1. Apply a dense layer with width `net_width_viewdirs` and activation `net_activation`. If $i > 0$ and $i \% \text{skip\_layer\_dir} == 0$, concatenate $x$ with original inputs along the last axis [S1, unofficial].

8.  **RGB Output**:
    *   Compute `rgb = rgb_activation(rgb_premultiplier * dense_layer(num_rgb_channels)(x) + rgb_bias)` [S1, unofficial].

9.  **Specular/Diffuse Split**:
    *   If `use_diffuse_color` is True, compute `diffuse_linear = nn.sigmoid(raw_rgb_diffuse - jnp.log(3.0))`.
    *   If `use_specular_tint` is True, `specular_linear = tint * rgb`. Else, `specular_linear = 0.5 * rgb`.
    *   Combine and tone map: `rgb = jnp.clip(image.linear_to_srgb(specular_linear + diffuse_linear), 0.0, 1.0)` [S1, unofficial].

10. **RGB Padding**:
    *   Apply padding to rgb: `rgb = rgb * (1 + 2 * rgb_padding) - rgb_padding` [S1, unofficial].

### Edge Cases and Pitfalls
*   **Reflections require normals**: If `use_reflections` is True, normals must be computed (either via `enable_pred_normals` or by not disabling density normals), otherwise a `ValueError` is raised [S1, unofficial].
*   **Reflection direction flip**: When computing reflection directions, viewdirs are flipped (`-viewdirs`) before reflection because they point from camera to point, whereas `ref_utils.reflect` assumes they point toward the camera [S1, unofficial].
*   **Normal stability**: Normals are computed from the gradient of raw (pre-activation) density because it is numerically more stable than post-activation density when the activation function has a steep or flat gradient [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: The complexity is dominated by the MLP forward passes. The density network has depth `net_depth` and width `net_width`, while the color network has depth `net_depth_viewdirs` and width `net_width_viewdirs`. The integrated positional encoding adds a constant overhead per sample based on `max_deg_point` and `basis_subdivisions`.
*   **Memory Complexity**: The model stores weights for the density and color networks. The size is proportional to `net_depth * net_width^2` and `net_depth_viewdirs * net_width_viewdirs^2`.
*   **Strengths**: Integrated positional encoding reduces aliasing and improves rendering quality for out-of-focus regions. The modular design allows for easy extension with features like specular tinting and diffuse/specular splitting.
*   **Limitations**: The use of integrated positional encoding requires computing the basis matrix and lifting/diagonalizing covariances, which can be computationally expensive compared to standard positional encoding. The reliance on JAX-specific operations (e.g., `jax.vmap`, `jax.value_and_grad`) makes porting to other frameworks non-trivial.
*   **When to use**: Use this architecture when implementing Mip-NeRF 360 or when high-quality, alias-free rendering is required, especially for scenes with large depth of field or out-of-focus effects.
*   **When not to use**: Avoid if computational resources are extremely limited and aliasing is not a primary concern, or if the implementation environment does not support JAX or similar automatic differentiation frameworks efficiently.
