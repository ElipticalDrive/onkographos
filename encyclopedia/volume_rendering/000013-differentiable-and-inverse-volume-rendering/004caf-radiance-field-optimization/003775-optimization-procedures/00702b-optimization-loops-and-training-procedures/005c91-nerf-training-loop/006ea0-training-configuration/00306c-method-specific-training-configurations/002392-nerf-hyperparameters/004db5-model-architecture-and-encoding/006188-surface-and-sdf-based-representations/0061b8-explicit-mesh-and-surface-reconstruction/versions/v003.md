# Explicit Mesh and Surface Reconstruction
## Overview
This family extracts explicit polygonal meshes or duplex surface structures from implicit neural radiance fields (NeRFs) or signed distance fields (SDFs) [G]. It solves the high computational cost and lack of explicit geometric topology in volumetric NeRFs by replacing dense ray sampling with surface intersections or deformable anchor grids [G]. It differs from sibling methods like [I2-SDF](18170-i2-sdf.md) and [SDF-based Volume Rendering with Laplacian CDF](18174-sdf-based-volume-rendering-with-laplacian-cdf.md) by prioritizing explicit mesh extraction or duplex surface approximation for real-time rendering, rather than optimizing a continuous SDF field for volume rendering integration [G]. Subsequent developments like [Neural Deformable Anchor (NeuDA)](18140-neural-deformable-anchor-neuda.md) and [Neural Duplex Radiance Fields (NDRF)](18147-neural-duplex-radiance-fields-ndrf.md) extended these principles to address specific limitations in spatial encoding efficiency and rendering speed, respectively [G].

### [Neural Deformable Anchor (NeuDA)](18140-neural-deformable-anchor-neuda.md)
NeuDA is a neural implicit representation for high-fidelity surface reconstruction that replaces learnable feature vectors at voxel vertices with optimized 3D positions (anchors) to adaptively encode local geometry [18140-neural-deformable-anchor-neuda.md]. It solves the limitation of standard voxel grids where uniformly distributed features fail to capture small structures with complicated topologies [18140-neural-deformable-anchor-neuda.md]. Unlike Instant-NGP which uses multi-resolution hash encoding and may suffer from hash collision, NeuDA uses hierarchical voxel grids with deformable anchors [18140-neural-deformable-anchor-neuda.md].

Inputs are camera parameters (origin $\mathbf{o}$, direction $\mathbf{d}$) and a hierarchical voxel grid structure $G$ [18140-neural-deformable-anchor-neuda.md]. The output is the rendered color $\hat{C}$ [18140-neural-deformable-anchor-neuda.md]. The grid consists of deformable anchors $\{ \mathbf{p}_v, \Delta \mathbf{p}_v \mid v \in G \}$, where $\mathbf{p}_v$ is the base position and $\Delta \mathbf{p}_v$ is a learnable offset, initially uniformly distributed at voxel vertices [18140-neural-deformable-anchor-neuda.md]. A 4-layer MLP $F$ takes geometric features to output SDF $f(\mathbf{x})$ and a 256-dimensional geometric feature vector $\mathbf{z}(\mathbf{x})$ [18140-neural-deformable-anchor-neuda.md]. A 4-layer MLP $M$ takes view direction $\mathbf{d}$, normal $\mathbf{n}$, and $\hat{\mathbf{z}}$ to output color $\mathbf{c} \in \mathbb{R}^3$ [18140-neural-deformable-anchor-neuda.md].

Frequency encoding uses Hierarchical Positional Encoding (HPE): $\gamma(\mathbf{p}_l) = (\sin(2^l \pi \mathbf{p}_l), \cos(2^l \pi \mathbf{p}_l))$, returning a 6-dimensional embedding per anchor [18140-neural-deformable-anchor-neuda.md]. Feature interpolation for a sample point $\mathbf{p}$ sums the encoded deformable positions of 8 adjacent anchors: $\phi(\mathbf{p}, \psi(G)) = \sum_{v \in \mathcal{V}} w(\mathbf{p}_v) \cdot \gamma(\mathbf{p}_v + \Delta \mathbf{p}_v)$ [18140-neural-deformable-anchor-neuda.md]. Weights are normalized cosine similarities: $\hat{w}(\mathbf{p}_n) = \frac{\mathbf{p} \cdot \mathbf{p}_n}{\|\mathbf{p}\| \|\mathbf{p}_n\|}$ [18140-neural-deformable-anchor-neuda.md].

Opacity $\alpha_i$ is derived from consecutive SDF values $f(\mathbf{p}(t_i))$ and $f(\mathbf{p}(t_{i+1}))$ using a trainable parameter $s$: $\alpha_i = \max\left( \frac{\Phi_s(f(\mathbf{p}(t_i))) - \Phi_s(f(\mathbf{p}(t_{i+1})))}{\Phi_s(f(\mathbf{p}(t_i)))}, 0 \right)$, where $\Phi_s(x) = (1 + e^{-sx})^{-1}$ [18140-neural-deformable-anchor-neuda.md]. As optimization converges, $1/s$ approaches zero [18140-neural-deformable-anchor-neuda.md]. Rendering accumulates color: $\hat{C} = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i$, with $T_i = \prod_{j=1}^{i-1}(1-\alpha_j)$ [18140-neural-deformable-anchor-neuda.md]. Edge cases include avoiding hash collisions via hierarchical grids and managing numerical stability for $s$ [18140-neural-deformable-anchor-neuda.md].

```python
import math
import numpy as np

def hierarchical_positional_encoding(p_l, level):
    freq = 2**level * math.pi
    return np.concatenate([np.sin(freq * p_l), np.cos(freq * p_l)])

def compute_anchor_weights(p, anchor_positions):
    p_norm = np.linalg.norm(p)
    if p_norm == 0:
        return np.ones(8) / 8.0
    raw_weights = np.zeros(8)
    for i in range(8):
        p_n = anchor_positions[i]
        p_n_norm = np.linalg.norm(p_n)
        raw_weights[i] = np.dot(p, p_n) / (p_norm * p_n_norm) if p_n_norm > 0 else 0
    sum_weights = np.sum(raw_weights)
    return raw_weights / sum_weights if sum_weights > 0 else np.ones(8) / 8.0

def get_feature_at_point(p, grid_level, grid_size, anchor_params):
    x = p * grid_size
    min_idx = np.floor(x).astype(int)
    corners = []
    for i in range(2):
        for j in range(2):
            for k in range(2):
                corners.append(np.array([min_idx[0] + i, min_idx[1] + j, min_idx[2] + k]))
    corners = np.array(corners)
    # Grid-to-anchor index mapping is implementation-specific [G]
    anchor_positions = np.array([anchor_params['positions'][get_vertex_index(c, grid_size)] for c in corners])
    anchor_offsets = np.array([anchor_params['offsets'][get_vertex_index(c, grid_size)] for c in corners])
    weights = compute_anchor_weights(p, anchor_positions)
    feature = np.zeros(6)
    for i in range(8):
        deformable_pos = anchor_positions[i] + anchor_offsets[i]
        feature += weights[i] * hierarchical_positional_encoding(deformable_pos, grid_level)
    return feature

def get_vertex_index(corner, grid_size):
    return corner[0] * grid_size * grid_size + corner[1] * grid_size + corner[2]

def render_ray(ray_origin, ray_direction, grid_levels, grid_sizes, anchor_params_list, sdf_net, color_net, num_samples):
    t_near, t_far = 0.0, 10.0  # [G] Not given in sources
    t_values = np.linspace(t_near, t_far, num_samples)
    sample_points = ray_origin + ray_direction * t_values[:, np.newaxis]
    accumulated_transmittance = 1.0
    accumulated_color = np.zeros(3)
    s_param = 100.0  # [G] Trainable parameter, initialized heuristically
    for i in range(num_samples):
        p = sample_points[i]
        all_features = [get_feature_at_point(p, level, grid_sizes[level_idx], anchor_params_list[level_idx]) for level_idx, level in enumerate(grid_levels)]
        geometric_input = np.concatenate(all_features)
        sdf_val, z_vec = sdf_net(geometric_input)
        phi_current = 1.0 / (1.0 + math.exp(-s_param * sdf_val))
        if i < num_samples - 1:
            p_next = sample_points[i+1]
            next_features = [get_feature_at_point(p_next, level, grid_sizes[level_idx], anchor_params_list[level_idx]) for level_idx, level in enumerate(grid_levels)]
            next_sdf_val, _ = sdf_net(np.concatenate(next_features))
            phi_next = 1.0 / (1.0 + math.exp(-s_param * next_sdf_val))
        else:
            phi_next = 0.0
        alpha = max((phi_current - phi_next) / phi_current, 0.0)
        if alpha > 0:
            normal = np.array([0.0, 1.0, 0.0])  # [G] Normal computed via SDF gradient
            color = color_net(ray_direction, normal, z_vec)
            accumulated_color += accumulated_transmittance * alpha * color
            accumulated_transmittance *= (1.0 - alpha)
        if accumulated_transmittance < 1e-4:
            break
    accumulated_color += accumulated_transmittance * np.array([0.0, 0.0, 0.0])  # [G] Background color
    return accumulated_color
```

### [Neural Duplex Radiance Fields (NDRF)](18147-neural-duplex-radiance-fields-ndrf.md)
NDRF distills a pretrained NeRF into a mesh-based representation for real-time view synthesis [18147-neural-duplex-radiance-fields-ndrf.md]. It solves the high computational cost of standard NeRF rendering by replacing dense volumetric sampling with a "duplex" interval defined by two ray-surface intersections on a proxy mesh [18147-neural-duplex-radiance-fields-ndrf.md]. Unlike standard NeRF which uses a deep MLP for every sample, NDRF uses a shallow convolutional network (CNN) to aggregate local geometric and appearance information from these two points, achieving approximately 10,000 times faster run-time performance while maintaining high-quality appearance [18147-neural-duplex-radiance-fields-ndrf.md].

Inputs are a pretrained NeRF, training images with camera poses, and a target ray $r(\lambda) = o + \lambda d$ [18147-neural-duplex-radiance-fields-ndrf.md]. The output is rendered RGB color $\mathbf{c} \in \mathbb{R}^3$ [18147-neural-duplex-radiance-fields-ndrf.md]. A duplex mesh is extracted from the pretrained NeRF's density field using Marching Cubes, consisting of inner and outer surfaces bracketing the true geometry [18147-neural-duplex-radiance-fields-ndrf.md]. Each vertex stores a learned radiance feature vector [18147-neural-duplex-radiance-fields-ndrf.md].

Steps: 1) Extract geometry proxy via Marching Cubes [18147-neural-duplex-radiance-fields-ndrf.md]. 2) Find two intersection points $p_{in}$ and $p_{out}$ where the ray intersects the inner and outer mesh layers [18147-neural-duplex-radiance-fields-ndrf.md]. 3) Retrieve radiance features $\mathbf{f}_{in}$ and $\mathbf{f}_{out}$ at intersections via barycentric interpolation on mesh triangles: $\mathbf{f} = u \mathbf{f}_0 + v \mathbf{f}_1 + w \mathbf{f}_2$ [18147-neural-duplex-radiance-fields-ndrf.md]. 4) Predict color $\mathbf{c}$ using a shallow CNN aggregating $\mathbf{f}_{in}$, $\mathbf{f}_{out}$, and the local screen-space pixel neighborhood [18147-neural-duplex-radiance-fields-ndrf.md]. 5) Optimize via multi-view distillation by comparing $\mathbf{c}$ to ground-truth pixels [18147-neural-duplex-radiance-fields-ndrf.md].

Parameters reduce sampled 3D locations per ray from hundreds to two [18147-neural-duplex-radiance-fields-ndrf.md]. Direct training from scratch causes artifacts, mitigated by initializing from a pretrained NeRF [18147-neural-duplex-radiance-fields-ndrf.md]. The duplex interval covers the reliable density field interval, mitigating geometry inaccuracies from single-surface extraction [18147-neural-duplex-radiance-fields-ndrf.md].

```python
def ray_mesh_intersect(origin, direction, vertices, faces):
    closest_t = float('inf')
    closest_point = None
    for i in range(0, len(faces), 3):
        v0, v1, v2 = vertices[faces[i]], vertices[faces[i+1]], vertices[faces[i+2]]
        edge1 = [v1[j]-v0[j] for j in range(3)]
        edge2 = [v2[j]-v0[j] for j in range(3)]
        h = [direction[1]*edge2[2]-direction[2]*edge2[1], direction[2]*edge2[0]-direction[0]*edge2[2], direction[0]*edge2[1]-direction[1]*edge2[0]]
        a = sum(e*d for e,d in zip(edge1, h))
        if -1e-6 < a < 1e-6: continue
        f = 1.0 / a
        s = [origin[j]-v0[j] for j in range(3)]
        u = f * sum(s[j]*h[j] for j in range(3))
        if u < 0.0 or u > 1.0: continue
        q = [s[1]*edge1[2]-s[2]*edge1[1], s[2]*edge1[0]-s[0]*edge1[2], s[0]*edge1[1]-s[1]*edge1[0]]
        v = f * sum(direction[j]*q[j] for j in range(3))
        if v < 0.0 or u + v > 1.0: continue
        t = f * sum(edge2[j]*q[j] for j in range(3))
        if t > 1e-6 and t < closest_t:
            closest_t = t
            closest_point = [origin[j] + t*direction[j] for j in range(3)]
    return closest_t, closest_point

def get_barycentric_coords(v0, v1, v2, p):
    v0v1 = [v1[j]-v0[j] for j in range(3)]
    v0v2 = [v2[j]-v0[j] for j in range(3)]
    v0p = [p[j]-v0[j] for j in range(3)]
    d00 = sum(a*b for a,b in zip(v0v1, v0v1))
    d01 = sum(a*b for a,b in zip(v0v1, v0v2))
    d11 = sum(a*b for a,b in zip(v0v2, v0v2))
    d20 = sum(a*b for a,b in zip(v0p, v0v1))
    d21 = sum(a*b for a,b in zip(v0p, v0v2))
    denom = d00 * d11 - d01 * d01
    v = (d11 * d20 - d01 * d21) / denom
    w = (d00 * d21 - d01 * d20) / denom
    u = 1.0 - v - w
    return [u, v, w]

def interpolate_features(vertex_feats, bary):
    return [sum(bary[k]*vertex_feats[k][j] for k in range(3)) for j in range(len(vertex_feats[0]))]

def shallow_cnn_forward(f_in, f_out, screen_patch):
    # Exact CNN architecture not specified in sources [G]. Using a linear projection as a representative implementation.
    combined = [f_in[j] + f_out[j] + screen_patch[j] for j in range(len(f_in))]
    weights = [[0.5, -0.2, 0.1], [0.1, 0.5, -0.1], [-0.1, 0.1, 0.5]]
    bias = [0.0, 0.0, 0.0]
    out = [sum(w*c for w,c in zip(row, combined)) + b for row, b in zip(weights, bias)]
    return [max(0.0, x) for x in out]

def render_ndrf(ray_origin, ray_direction, mesh_data, screen_patch):
    t_in, p_in = ray_mesh_intersect(ray_origin, ray_direction, mesh_data['inner_v'], mesh_data['inner_f'])
    t_out, p_out = ray_mesh_intersect(ray_origin, ray_direction, mesh_data['outer_v'], mesh_data['outer_f'])
    if t_in is None or t_out is None:
        return [0.0, 0.0, 0.0]
    # Triangle lookup for intersection points is implementation-specific [G]
    tri_in_idx = mesh_data['inner_tri_idx'][tuple(p_in)]
    tri_out_idx = mesh_data['outer_tri_idx'][tuple(p_out)]
    v0, v1, v2 = [mesh_data['inner_v'][mesh_data['inner_f'][tri_in_idx+k]] for k in range(3)]
    v0_out, v1_out, v2_out = [mesh_data['outer_v'][mesh_data['outer_f'][tri_out_idx+k]] for k in range(3)]
    bary_in = get_barycentric_coords(v0, v1, v2, p_in)
    bary_out = get_barycentric_coords(v0_out, v1_out, v2_out, p_out)
    f_in = interpolate_features([mesh_data['inner_feats'][mesh_data['inner_f'][tri_in_idx+k]] for k in range(3)], bary_in)
    f_out = interpolate_features([mesh_data['outer_feats'][mesh_data['outer_f'][tri_out_idx+k]] for k in range(3)], bary_out)
    return shallow_cnn_forward(f_in, f_out, screen_patch)

def train_ndrf(pretrained_nerf, training_data, epochs=1000, lr=1e-3):
    mesh_data = extract_mesh_from_nerf(pretrained_nerf)  # Not given in sources
    mesh_data['inner_feats'] = [[0.0]*64 for _ in range(len(mesh_data['inner_v']))]
    mesh_data['outer_feats'] = [[0.0]*64 for _ in range(len(mesh_data['outer_v']))]
    for epoch in range(epochs):

            rays = generate_rays(img.shape, cam_pose)  # Not given in sources
```

### Explicit Mesh Reconstruction from Neural Fields
An algorithm to extract an explicit 3D mesh representation from the implicit neural radiance field learned by CodeNeRF, allowing for 3D reconstruction from a single input image [S1]. The process feeds the center coordinates of a $256^3$ voxel grid to the CodeNeRF MLP to obtain volume density values $\sigma$ [S1]. Marching cubes is then applied to the volume density values $\sigma$ to find mesh vertices [S1]. Finally, rays are cast along the vertex normals of the generated mesh to associate colors to the vertices [S1].

## Background
The concept of extracting explicit meshes from neural fields was introduced by CodeNeRF (2021), which disentangles shape and appearance to allow 3D reconstruction from a single image [S1]. The method leverages texture priors learned by CodeNeRF to complete object shape and texture information not present in the input image [S1]. Subsequent developments like [Neural Deformable Anchor (NeuDA)](18140-neural-deformable-anchor-neuda.md) and [Neural Duplex Radiance Fields (NDRF)](18147-neural-duplex-radiance-fields-ndrf.md) extended these principles to address specific limitations in spatial encoding efficiency and rendering speed, respectively [G].
