# Unified Volumetric Avatar (UVA)


## Overview
Unified Volumetric Avatar (UVA) is a neural radiance field representation for dynamic human avatars that enables local and independent editing of both geometry and texture while supporting novel view synthesis and pose rendering [S1, unofficial]. It distinguishes itself from methods relying on pre-defined UV mapping or two-stage distillation by anchoring structured latent codes to a deformable canonical mesh, allowing direct manipulation of 3D space without 3D-to-2D projection ambiguities [S1, unofficial].

## How it works
**Inputs:**
*   Target observation point $\mathbf{x}_t$ (sampled from a ray in the current pose) [S1, unofficial].
*   Current pose parameters $\theta_t$ (defining the skeleton and mesh deformation) [S1, unofficial].
*   Canonical mesh $\mathcal{M}$ (T-pose reference with $N$ anchor nodes) [S1, unofficial].
*   Top-K parameter for nearest-neighbor search [S1, unofficial].

**Outputs:**
*   Final pixel color $\mathbf{c}(\mathbf{r})$ for the ray $\mathbf{r}$ [S1, unofficial].

**Data Structures:**
1.  **Canonical Mesh $\mathcal{M}$:** A deformable mesh in canonical space with $N$ anchor nodes, storing vertex positions, UV coordinates, and pre-computed LBS weights [S1, unofficial].
2.  **Latent Codes:** Two sets of learnable vectors anchored to the mesh nodes: $\mathbf{l}_{geo} \in \mathbb{R}^{N \times d_{geo}}$ for geometry and $\mathbf{l}_{rgb} \in \mathbb{R}^{N \times d_{rgb}}$ for appearance [S1, unofficial].
3.  **Neural Deformation Field:** An MLP $\phi_{def}$ that predicts non-rigid displacement [S1, unofficial].
4.  **Radiance MLP:** An MLP $\phi_{rad}$ that predicts volume density $\sigma$ and base color $\mathbf{c}_0$ [S1, unofficial].
5.  **Shading MLP:** An MLP $\phi_{shade}$ that predicts a pose-dependent shading factor $s$ [S1, unofficial].

**Steps:**
1.  **Compute LBS Weights:** For $\mathbf{x}_t$, find the Top-K nearest neighbors on the current posed mesh. Interpolate the Linear Blending Skinning (LBS) weights $\mathbf{w}_b$ from the neighbors' weights [S1, unofficial].
2.  **Transform to Canonical Space:** Invert the LBS transformation using $\mathbf{w}_b$ and $\theta_t$ to get an initial canonical position, then combine it with the neural deformation field to obtain $\mathbf{x}_c$ [S1, unofficial].
3.  **Interpolate Latent Codes:** In canonical space, find the Top-K nearest neighbors of $\mathbf{x}_c$ on $\mathcal{M}$. Interpolate $\mathbf{l}_{geo}$ and $\mathbf{l}_{rgb}$ from the anchored nodes using nearest-neighbor interpolation [S1, unofficial].
4.  **Compute Signed Height Indicator:** Calculate $\tilde{\mathbf{h}}$ for $\mathbf{x}_c$, comprising UV coordinates $(u, v)$ and point-to-surface distance $\bar{d}$ relative to the canonical mesh [S1, unofficial].
5.  **Predict Density and Base Color:** Pass the interpolated latent codes and $\tilde{\mathbf{h}}$ through the radiance MLP [S1, unofficial].
6.  **Modulate Color:** Predict a pose-dependent shading factor $s$ using the shading MLP and $\theta_t$. Modulate the base color [S1, unofficial].
7.  **Volume Rendering:** Integrate the modulated colors and densities along the ray $\mathbf{r}$ using standard volume rendering to produce $\mathbf{c}(\mathbf{r})$ [S1, unofficial].

**Formulas:**
*   LBS Inversion & Deformation: $\mathbf{x}_c = \text{LBS}^{-1}(\mathbf{x}_t, \mathbf{w}_b, \theta_t) + \phi_{def}(\mathbf{x}_c)$ [S1, unofficial].
*   Signed Height Indicator: $\tilde{\mathbf{h}} = [u, v, \bar{d}]$ [S1, unofficial].
*   Radiance Prediction: $[\sigma, \mathbf{c}_0] = \phi_{rad}(\mathbf{l}_{geo}, \mathbf{l}_{rgb}, \tilde{\mathbf{h}})$ [S1, unofficial].
*   Color Modulation: $\mathbf{c}_{mod} = \mathbf{c}_0 \otimes s$ [S1, unofficial].

**Parameters:**
*   **Top-K:** The number of nearest neighbors used for interpolating LBS weights and latent codes. Typical values are not given in the sources. [S1, unofficial]

**Edge Cases and Pitfalls:**
*   **Spatial Ambiguity:** Using discrete latent codes defined on mesh nodes diffused via nearest-neighbor interpolation leads to spatial query indistinguishability (blocky artifacts or discontinuities). This is mitigated by the signed height indicator $\tilde{\mathbf{h}}$ [S1, unofficial].
*   **UV Mapping Limitations:** Unlike methods using pre-defined UV mapping, UVA avoids the difficulty of local texture editing because it operates in 3D canonical space with mesh-anchored codes [S1, unofficial].

**Pseudocode:**
```python
def render_uva(ray, pose_params, mesh, l_geo, l_rgb, top_k):
    # 1. Sample target point in current pose
    x_t = sample_point_on_ray(ray, pose_params)
    
    # 2. Compute LBS weights from Top-K neighbors on posed mesh
    posed_neighbors = find_top_k_neighbors(x_t, mesh.posed_vertices, top_k)
    w_b = interpolate_weights(posed_neighbors.weights, posed_neighbors.distances)
    
    # 3. Transform to canonical space: invert LBS + neural deformation
    x_c = invert_lbs(x_t, w_b, pose_params)
    x_c = x_c + neural_deformation_field(x_c)
    
    # 4. Interpolate latent codes from Top-K neighbors on canonical mesh
    c_neighbors = find_top_k_neighbors(x_c, mesh.canonical_vertices, top_k)
    l_geo_interp = interpolate_latents(c_neighbors.l_geo, c_neighbors.distances)
    l_rgb_interp = interpolate_latents(c_neighbors.l_rgb, c_neighbors.distances)
    
    # 5. Compute signed height indicator [u, v, d_bar]
    h_tilde = compute_signed_height(x_c, mesh)
    
    # 6. Predict density and base color
    sigma, c_0 = radiance_mlp(l_geo_interp, l_rgb_interp, h_tilde)
    
    # 7. Predict shading factor and modulate
    s = shading_mlp(pose_params)
    c_mod = c_0 * s
    
    # 8. Volume render along ray
    c_r = volume_render(ray, sigma, c_mod)
    return c_r
# Note: Helper functions (find_top_k_neighbors, interpolate_weights, etc.)
```

## Operating characteristics
*   **Editing Capability:** Enables local and independent editing of geometry and texture, which is not possible with standard NeRF or UV-mapped methods [S1, unofficial].
*   **Training:** End-to-end trainable from scratch, jointly optimizing the skinning field and radiance field, unlike two-stage distilling methods that require manual parameter tuning [S1, unofficial].
*   **Performance:** Achieves competitive results in novel view synthesis and novel pose rendering on human avatars [S1, unofficial].

## Background
Unified Volumetric Avatar (UVA) was proposed to address the challenges of editing dynamic human avatars. Previous methods either lacked editing capabilities or relied on static meshes and two-stage processes [S1, unofficial]. UVA introduces a mesh-guided canonical radiance field with structured latent codes and a signed height indicator to enable all-in-one solutions for view synthesis, pose rendering, and local editing [S1, unofficial].
