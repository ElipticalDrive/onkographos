# HumanNeRF-SE


## Overview
HumanNeRF-SE synthesizes novel pose images of humans from monocular video inputs by combining explicit SMPL shape priors with an implicit NeRF representation [S1]. It differs from sibling methods like [HumanNeRF](13842-humannerf.md) and [MonoHuman](13842-humannerf.md) by using frozen SMPL blending weights for rigid deformation and point-level spatial features for non-rigid refinement, thereby avoiding the pose leakage and overfitting associated with frame-level features or learned weight volumes [S1].

## How it works
**Inputs:** Monocular video frames $\{I_n\}$, corresponding SMPL mesh vertices $v$ and pose parameters $J$ for each frame.
**Outputs:** Rendered images $\tilde{C}(r)$ for arbitrary viewpoints and poses.

**Data Structures:**
*   **Voxel Volume $V$:** A sparse 3D grid. Each voxel containing SMPL vertices stores a tuple $(n_v, w_1, \dots, w_{24})$, where $n_v$ is the vertex count (occupancy) and $w_j$ are the 24 Linear Blending Skinning (LBS) weights from SMPL. Empty voxels store $(0, 0, \dots, 0)$ [S1].
*   **Spatial-Aware Features $F_s$:** Output of channel-by-channel convolution on $V$.
*   **Sampling Points:** Divided into human-related points $x_r$ (where $F_s(x) > 0$) and filtered points $x_o$ (where $F_s(x) = 0$) [S1].

**Steps:**

1.  **Voxelization:**
    Calculate the bounding box of SMPL vertices $v$ (min/max coordinates). Scale the bounding box to a target voxel size $v_s$. Find the least common multiple of the axes dimensions and 32. Scale vertices down by $v_s$ after subtracting the minimum. Construct $V$ using Sparse Convolution $Sp$:
    $$ V = Sp(v, v_s, W) $$
    [S1]

2.  **Conv-Filter:**
    Initialize a convolution kernel to one. Perform channel-by-channel convolution on $V$ to obtain spatially-aware features $F_s$. For a voxel at $(h, w, d)$ with value $\nu_{m,n,t,i}$ and kernel weight $\vartheta_{m,n,t,i}'$:
    $$ F_{s,i} = \sum_{m=h}^{h'} \sum_{n=w}^{w'} \sum_{t=d}^{d'} \nu_{m,n,t,i} \cdot \vartheta_{m,n,t,i}' $$
    where $h' = h-k$, etc. [S1].
    Query $F_s(x)$ for each sampling point $x$. If $F_s(x) = 0$, the point is filtered out ($x_o$) and its density is forced to 0. If $F_s(x) > 0$, the point is kept ($x_r$) [S1].

3.  **Point Canonicalization (Rigid Deformation):**
    Query the nearest neighbor SMPL weights $W_{smpl} = K(x, v)$ for each $x_r \in x_r$. Compute the rigid deformation $x^{rcnl}$ using the frozen SMPL blending weights $w_j$ and the current pose joints $J$ relative to the T-pose joints (rotation $R_j$, translation $T_j$):
    $$ x^{rcnl} = \sum_{j \in J} w_j ((x_r \cdot R_j) + T_j) $$
    [S1]

4.  **Point Canonicalization (Non-Rigid Refinement):**
    Refine the coarse coordinates using a network $P$ conditioned on the spatial-aware features $F_s$ and the points $x_r$:
    $$ x^{cnl} = x^{rcnl} + P(F_s, x_r) $$
    [S1]

5.  **Appearance Net:**
    Encode $x^{cnl}$ using positional encoding (as in standard NeRF). Pass through an MLP $M_\sigma$ to output color $c$ and density $\sigma$:
    $$ c, \sigma = M_\sigma(x^{cnl}) $$
    [S1]

6.  **Rendering:**
    Render the image using volume rendering. For a ray $r$ with $N_s$ samples:
    $$ \alpha_i = 1 - \exp(-\sigma(x_i) \Delta t_i) $$
    $$ \tilde{C}_t(r) = \sum_{k=1}^{N_s} \alpha_k c(x_k) \prod_{j=1}^{k-1} (1 - \alpha_j) $$
    [S1]

**Pseudocode:**

```python
def human_nerf_se_train(video_frames, smpl_vertices, smpl_poses, voxel_size_vs):
    # 1. Voxelization
    # Calculate bounding box of smpl_vertices
    min_coord = min(smpl_vertices, axis=0)
    max_coord = max(smpl_vertices, axis=0)
    # Scale vertices to voxel grid
    scaled_vertices = (smpl_vertices - min_coord) / voxel_size_vs
    # Construct sparse voxel volume V with occupancy and SMPL weights
    # V contains (n_v, w1...w24) for voxels with vertices, else zeros
    V = sparse_convolution(scaled_vertices, smpl_weights)
    
    # 2. Conv-Filter
    # Initialize kernel to ones
    kernel = ones(kernel_size)
    # Channel-by-channel convolution
    Fs = channel_by_channel_conv(V, kernel)
    
    # 3. Sampling and Filtering
    # Generate sampling points x along rays
    all_points = sample_rays(video_frames)
    
    # Query spatial features
    features = query_volume(Fs, all_points)
    
    # Filter points
    human_points = all_points[features > 0]
    filtered_points = all_points[features == 0]
    
    # 4. Canonicalization
    # Rigid deformation using frozen SMPL weights
    # K(x, v) queries nearest SMPL weights for point x
    smpl_weights_x = nearest_neighbor_weights(human_points, smpl_vertices)
    
    # Compute rigid transform based on current pose J
    # R_j, T_j are rotation/translation of joint j relative to T-pose
    rigid_coords = sum(
        smpl_weights_x[:, j] * (human_points * R_j + T_j) 
        for j in range(num_joints)
    )
    
    # Non-rigid refinement
    # P is a network taking Fs and human_points
    refined_coords = rigid_coords + point_refinement_network(Fs, human_points)
    
    # 5. Appearance
    # Positional encoding
    encoded_coords = positional_encoding(refined_coords)
    # MLP for color and density
    colors, densities = appearance_mlp(encoded_coords)
    
    # 6. Rendering
    # Set density of filtered points to 0
    densities[filtered_points] = 0
    
    # Volume rendering
    alphas = 1 - exp(-densities * step_sizes)
    rendered_colors = volume_render(alphas, colors)
    
    return rendered_colors

def loss_function(rendered_image, ground_truth_image, densities):
    # Foreground mask from density
    foreground_mask = densities > threshold
    
    # MSE loss on foreground
    mse_loss = mean_squared_error(rendered_image[foreground_mask], ground_truth_image[foreground_mask])
    
    # LPIPS loss on foreground
    lpips_loss = l_pips(rendered_image[foreground_mask], ground_truth_image[foreground_mask])
    
    # Total loss
    total_loss = lpips_loss + lambda_param * mse_loss
    return total_loss
```

**Parameters:**
*   $v_s$: Voxel size for scaling the SMPL bounding box [S1].
*   $\lambda$: Weight for the MSE loss term in the total loss function [S1].
*   SMPL blending weights: Frozen, not fine-tuned [S1].

**Edge Cases and Pitfalls:**
*   **Overfitting:** Using learned or fine-tuned SMPL weights causes overfitting to limited input data, leading to artifacts in novel poses [S1].
*   **Irrelevant Points:** Simply using nearest SMPL weights deforms irrelevant sampling points onto the human body, causing incorrect colors. The Conv-Filter is required to remove these [S1].
*   **Non-Rigid Deformation:** Direct nearest weight rigid deformation ignores non-rigid clothing deformation. The point-level refinement $P$ is necessary to handle this [S1].
*   **Pose Leakage:** In datasets like ZJU-MOCAP, action repetition can cause pose leakage. Mitigated by using few-shot training (30 frames) and diverse in-the-wild videos for evaluation [S1].

## Operating characteristics
*   **Complexity:** Reduces required sampling points from ~300K to <100K [S1]. Uses <1% of learnable parameters compared to previous methods [S1].
*   **Performance:** Reduces training time by 95% (1/20 of previous methods) [S1]. Increases rendering speed by 15x without acceleration modules [S1].
*   **Metrics (ZJU-MOCAP Few-shot):** PSNR=31.09, SSIM=0.974, LPIPS=24.085 (vs HumanNeRF: 30.10, 0.9677, 33.056) [S1].
*   **Strengths:** Generalizes to diverse poses with few-shot input; avoids overfitting; efficient computation [S1].
*   **Limitations:** Relies on SMPL accuracy; performance may degrade if SMPL fit is poor [S1].

## Background
HumanNeRF-SE was introduced in 2024 by Miles et al. [S1]. It addresses the limitations of prior NeRF-based human avatars that required large numbers of optimizable parameters and multi-camera data [S1]. It builds on [HumanNeRF](13842-humannerf.md) but replaces neural blend weights with frozen SMPL weights and frame-level features with point-level spatial features [S1].
