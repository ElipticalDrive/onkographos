# Gear-NeRF

Also called: Gear-NeRF: Free-Viewpoint Rendering and Tracking with Motion-aware Spatio-Temporal Sampling

## Overview
Gear-NeRF is a framework for free-viewpoint rendering and tracking of dynamic scenes that leverages semantic information from image segmentation models to stratify the scene into motion-based 'gears', allowing for region-specific spatio-temporal sampling resolution [S1]. It differs from standard dynamic NeRFs by replacing the unified 4D volume with a series of 4D feature volumes, one per gear level, where higher gears correspond to regions with larger motion scales and thus receive higher-resolution sampling [S1]. This approach improves photo-realistic dynamic novel view synthesis and enables free-viewpoint object tracking as a by-product [S1].

## How it works
**Inputs:** A set of $W$ input videos $V = \{V_1, V_2, \dots, V_W\}$ of a dynamic scene with calibrated camera poses [S1].

**Outputs:** Rendered images for novel viewpoints and time steps; tracked object trajectories [S1].

**Data Structures:**
The representation consists of a series of 4D feature volumes, where each volume corresponds to a specific gear level $G$ [S1].
1.  **Shared Spatial Features:** Functions $h_j(\cdot, \cdot)$ mapping 2D coordinate tuples to features. These are shared across all gears.
2.  **Gear-Specific Temporal/Spatial Embeddings:** For each gear $G$, functions $k^G_j(\cdot, \cdot)$ mapping 2D coordinate tuples to $M$-dimensional feature vectors. Each gear has its own set of these embeddings [S1].
3.  **Linear Transforms:** Functions $B_j(\cdot)$ mapping the element-wise products to feature vectors. These are shared across all gears [S1].
4.  **Gear Level Map:** A planar-factorized 4D feature volume used to compute the gear level $g(x,t)$ at any spatio-temporal coordinate [S1].

**Parameters:**
*   $N_{gear}$: The total number of gear levels used to stratify the scene representation based on motion scales [S1].
*   $M$: The dimensionality of the feature space for the gear-specific embeddings [S1].

**Method Steps:**

1.  **Semantic Embedding Optimization:** Optimize for a 4D semantic embedding based on powerful image segmentation models (specifically SAM) to profile the scene into semantic regions [S1]. This embedding is used to determine motion scales.

2.  **Gear Assignment:** Determine the gear level $g(x,t)$ for any space-time coordinate $(x,t)$. This is computed from a planar-factorized 4D feature volume. The source provides the start of the formula but cuts off:
    $$
    g(x, t) = \mathbf{1}^\top (h'_1 (x, y) \bowtie k'_1 (z, t) + \dots)
    $$
    [S1]. Regions with larger motion scales are assigned higher gear levels through this gear determination scheme [S1].

3.  **Feature Vector Computation:** For a specific gear $G$ and coordinate $(x,t)$, compute the feature vector $f^G(x,t)$ by summing three terms. Each term involves an element-wise product of 2D plane embeddings and a linear transform [S1]:
    $$
    f^G(x, t) = B_1 (h_1 (x, y) \bowtie k^G_1 (z, t)) + B_2 (h_2 (x, z) \bowtie k^G_2 (y, t)) + B_3 (h_3 (y, z) \bowtie k^G_3 (x, t))
    $$
    where:
    *   $\bowtie$ denotes element-wise product [S1].
    *   $h_i(\cdot, \cdot)$ are functions evaluated by bilinear interpolation on regularly spaced 2D feature grids embedding coordinate tuples to features [S1].
    *   $k^G_i(\cdot, \cdot)$ are functions evaluated by bilinear interpolation on regularly spaced 2D feature grids for gear $G$, embedding coordinate tuples to features of dimension $M$ [S1].
    *   $B_i(\cdot)$ denotes a linear transform mapping products to feature vectors [S1].
    *   The vector-valued functions $h_j(\cdot, \cdot)$ and linear transforms $B_j(\cdot)$ are shared by all gears [S1].
    *   Each gear has its own spatio-temporal embedding $k^G_j(\cdot, \cdot)$ [S1].

4.  **NeRF Output Prediction:** Pass the feature vector $f^G(x,t)$ through a tiny MLP to map it to the volume density $\sigma$ and the view-dependent emitted color $\mathbf{c}$, given the viewing direction $\mathbf{d}$ [S1].

5.  **Spatio-Temporal Sampling:** Perform spatio-temporal sampling for ray marching. Regions with larger motion scales (higher gears) are assigned higher-resolution spatio-temporal sampling [S1]. This is done to improve dynamic novel view synthesis [S1].

6.  **Rendering:** Render the image using standard volume rendering integration over the sampled points, using the computed $\sigma$ and $\mathbf{c}$ [S1].

7.  **Tracking (Optional):** Use the 4D semantic embedding to enable free-viewpoint tracking of target objects given simple user prompts like clicks [S1].

def bilinear_interpolate(grid, u, v, resolution):
    """
    Bilinear interpolation on a 2D grid.
    
    Args:
        grid: 2D array of shape (resolution, resolution, D)
        u, v: 1D arrays of shape (N,) coordinates in [0, 1]
        resolution: int
        
    Returns:
        interpolated: 1D array of shape (N, D)
    """
    # Scale coordinates to grid indices
    u_idx = u * (resolution - 1)
    v_idx = v * (resolution - 1)
    
    # Get floor and ceil indices
    u0 = np.floor(u_idx).astype(int)
    v0 = np.floor(v_idx).astype(int)
    u1 = np.minimum(u0 + 1, resolution - 1)
    v1 = np.minimum(v0 + 1, resolution - 1)
    
    # Interpolate weights
    w_u = u_idx - u0
    w_v = v_idx - v0
    
    # Get values at corners
    # grid is (res, res, D)
    # We need to interpolate for each dimension D
    # This is a simplified version; actual implementation would handle D correctly
    
    # Interpolate along u
    val_u0 = grid[v0, u0, :] # (N, D)
    val_u1 = grid[v0, u1, :] # (N, D)
    val_u = val_u0 * (1 - w_u)[:, None] + val_u1 * w_u[:, None]
    
    val_u0 = grid[v1, u0, :] # (N, D)
    val_u1 = grid[v1, u1, :] # (N, D)
    val_u1_interp = val_u0 * (1 - w_u)[:, None] + val_u1 * w_u[:, None]
    
    # Interpolate along v
    result = val_u * (1 - w_v)[:, None] + val_u1_interp * w_v[:, None]
    
    return result

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

**Edge Cases and Pitfalls:**
*   **Gear Assignment Boundary:** The source does not specify how the gear level $g(x,t)$ is discretized or handled at boundaries between gears. [G] In practice, this might involve soft assignment or hard thresholding based on motion scale.
*   **Semantic Embedding Quality:** The method relies on the quality of the 4D semantic embedding from SAM. Poor segmentation or tracking in the input videos may lead to incorrect gear assignments. [S1]
*   **Motion Scale Estimation:** The gear determination scheme is based on motion scales. Accurate estimation of motion scale is crucial for proper stratification. [S1]

## Operating characteristics
*   **Time Complexity:** Not given in the sources. However, the use of multiple gear levels and higher-resolution sampling for dynamic regions suggests increased computational cost compared to static NeRFs, but potentially lower than uniform high-resolution dynamic NeRFs.
*   **Memory Complexity:** Not given in the sources. The method uses a series of 4D feature volumes, one per gear level. This may increase memory usage compared to a single 4D volume, but the stratification allows for lower resolution in static regions.
*   **Measured Performance:** The method achieves state-of-the-art rendering and tracking performance on multiple challenging datasets [S1].
*   **Strengths:**
    *   Improved dynamic novel view synthesis through motion-aware sampling [S1].
    *   Enables free-viewpoint object tracking as a by-product [S1].
    *   Efficient resource allocation by assigning higher resolution to dynamic regions [S1].
*   **Limitations:**
    *   Relies on external semantic segmentation models (SAM) [S1].
    *   Requires calibrated camera poses for input videos [S1].
*   **When to use:** When rendering dynamic scenes with varying motion scales and when free-viewpoint tracking is desired. [S1]
*   **When not to use:** For static scenes or scenes with uniform motion where the overhead of gear stratification is not justified. [S1]

## Background
Gear-NeRF was introduced in 2024 by the authors of "Gear-NeRF: Free-Viewpoint Rendering and Tracking with Motion-aware Spatio-Temporal Sampling" [S1]. It builds on the standard NeRF architecture and dynamic NeRF modifications, specifically addressing the need for efficient representation of dynamic scenes with varying motion scales [S1]. The method leverages semantic information from image segmentation models to stratify the scene into motion-based 'gears' [S1].
