# Transformer and Vision Model Integration

Also called: Vision Transformer Integration in NeRF, ViT-NeRF Family

## Overview
This family of methods integrates Vision Transformers (ViT) and other vision backbones into Neural Radiance Fields (NeRF) to replace or augment standard positional encoding and local feature extraction. The core problem solved is the limitation of standard NeRF architectures, which rely on local MLPs that struggle to model long-range dependencies, global scene structure, and semantic consistency, particularly in novel view synthesis from sparse or single inputs [S1]. Unlike sibling methods that modify the MLP structure directly (e.g., [Mixer-NeRF](14073-mixer-nerf.md)) or use explicit geometric priors (e.g., [Signed Distance Function (SDF) Representations](12495-signed-distance-function-sdf-representations.md)), this approach leverages the global receptive field and semantic understanding of pre-trained vision models to condition the radiance field [S1].

## Shared principles
The shared mechanism involves extracting features from a 2D image using a vision backbone (typically a ViT or CNN) and using these features to condition the prediction of density $\sigma$ and color $\mathbf{c}$ for 3D points sampled along rays.

1.  **Feature Extraction:** An input image $I$ is processed by a backbone network to produce feature maps or tokens.
    *   For ViTs, the image is split into patches, linearly projected, and processed through self-attention layers to capture global context [S1].
    *   For CNNs, hierarchical feature maps are extracted to capture local details [S1].
2.  **Feature Conditioning:** For a 3D point $\mathbf{x}$ sampled along a ray, the corresponding 2D location $\pi(\mathbf{x})$ on the input image plane is computed. The feature vector $\mathbf{f}$ at $\pi(\mathbf{x})$ is interpolated from the extracted feature maps.
3.  **Radiance Field Prediction:** The NeRF MLP takes the positional encoding of $\mathbf{x}$, the viewing direction $\mathbf{d}$, and the vision feature $\mathbf{f}$ as input:
    $$ (\sigma, \mathbf{c}) = \text{MLP}(\gamma(\mathbf{x}), \mathbf{d}, \mathbf{f}) $$
    This replaces the standard NeRF input which typically only uses $\gamma(\mathbf{x})$ and $\mathbf{d}$ [G].
4.  **Generalization:** By using features from pre-trained models, these methods often enable generalization to unseen scenes or sparse views without per-scene optimization, or improve quality in single-view reconstruction by leveraging semantic priors [S1].

## Subtopics

### [ViT-NeRF](13878-vit-nerf.md)
**Definition:** A method that combines a Vision Transformer (ViT) for global shape information and a 2D CNN for local appearance features, conditioning volume rendering on hybrid per-pixel features.
**Distinction:** Unlike [PixelNeRF](13878-vit-nerf.md) which relies solely on local features or [CodeNeRF](15544-codenerf.md) which uses global features without local refinement, ViT-NeRF produces sharper edges and clearer structures in unseen regions while maintaining color consistency in visible regions.
**When to choose:** Use when high-fidelity reconstruction from a single or few views is required, and the scene benefits from both global structural understanding and local texture detail.
**Link:** [ViT-NeRF](13878-vit-nerf.md)

### [VisionNeRF](13885-visionnerf.md)
**Definition:** A method that infers a 3D representation from a single unposed input image by combining global ViT features and local CNN features, rendered via a NeRF-based MLP.
**Distinction:** Unlike [ViT-NeRF](13878-vit-nerf.md) which focuses on multi-view consistency, VisionNeRF explicitly handles self-occlusion in single-view reconstruction by using self-attention to find long-range dependencies, allowing it to retrieve relevant features from distant parts of the source view for occluded regions. It does not require camera pose information.
**When to choose:** Use for single-view 3D reconstruction where camera poses are unknown or unreliable, and occlusion handling is critical.
**Link:** [VisionNeRF](13885-visionnerf.md)

### [TransNeRF](13907-transnerf.md)
**Definition:** A generalizable neural radiance field method that learns a generic scene representation from a set of source views to synthesize novel views without per-scene optimization.
**Distinction:** Unlike standard NeRF which requires per-scene training, TransNeRF is trained end-to-end on a large dataset and generalizes to unseen scenes directly. It replaces pooling-based multi-view fusion with an encoder-decoder Transformer framework that explores deep relationships among multiple views and enforces local geometry consistency along rays.
**When to choose:** Use for few-shot or zero-shot novel view synthesis on unseen scenes where per-scene optimization is computationally prohibitive.
**Link:** [TransNeRF](13907-transnerf.md)

### [NeRF Analogies](18133-nerf-analogies.md)
**Definition:** A method that transfers visual attributes (appearance) from a source NeRF to a target NeRF by establishing dense semantic correspondences using Vision Transformer (ViT) features.
**Distinction:** Unlike [ViT-NeRF](13878-vit-nerf.md) and [VisionNeRF](13885-visionnerf.md) which focus on single-scene reconstruction, NeRF Analogies focuses on cross-scene attribute transfer via semantic key-component matching, solving appearance transfer without requiring geometric alignment between scenes.
**When to choose:** Use for appearance transfer or style transfer between 3D scenes based on semantic similarity.
**Link:** [NeRF Analogies](18133-nerf-analogies.md)

### Mixture of View Experts (MoE) in GNT
**Definition:** A modification to the GNT view transformer where dense MLP layers are replaced with sparsely activated Mixture-of-Experts (MoE) layers to specialize different components for specific rendering properties (e.g., diffuse vs. specular reflection) [S1].
**Step:** Replace the dense MLP layer in the view transformer with a sparsely activated MoE layer composed of a set of half-sized MLP experts $\{f_e\}_{e=1}^E$ [S1].
**Formula:** The routing weights are computed as $R(x) = \text{softmax}(\text{TopK}(G(x), K))$, where $G$ is the learnable network within the router [S1]. The output is the weighted summation of the selected experts. A diversity regularizer is applied: $L_{div} = \text{CV}(\mathbb{E}_{r \sim R} \mathbb{E}_{x \in r} R(x))$, where $\text{CV}(g) = \text{mean}(g)/\text{var}(g)$ [S1].
**Parameters:** $K=2$ (number of top experts), $E=4$ (total experts), Expert Size is half the dense MLP size, $\lambda_{div} = 1 \times 10^{-3}$ [S1].
**Link:** [GNT](13907-transnerf.md) (Note: GNT is the parent method for TransNeRF/GNT family, linked via TransNeRF context)

## Background
The integration of transformers into NeRF stems from the need to overcome the inductive biases of CNNs and the limited receptive field of standard MLPs in NeRFs. Vision Transformers, pre-trained on large-scale image datasets (e.g., ImageNet, DINO), offer strong semantic and structural priors. Early works like [ViT-NeRF](13878-vit-nerf.md) and [VisionNeRF](13885-visionnerf.md) demonstrated that combining global ViT features with local CNN features improves single-view and few-view synthesis. [TransNeRF](13907-transnerf.md) and [GNT](13907-transnerf.md) extended this to generalizable NeRFs, allowing training on diverse datasets to generalize to unseen scenes. [NeRF Analogies](18133-nerf-analogies.md) explored the semantic capabilities of ViT features for cross-scene tasks. The use of Mixture-of-Experts (MoE) in [GNT-MOVE](13907-transnerf.md) further specialized the transformer for different rendering properties [S1].
