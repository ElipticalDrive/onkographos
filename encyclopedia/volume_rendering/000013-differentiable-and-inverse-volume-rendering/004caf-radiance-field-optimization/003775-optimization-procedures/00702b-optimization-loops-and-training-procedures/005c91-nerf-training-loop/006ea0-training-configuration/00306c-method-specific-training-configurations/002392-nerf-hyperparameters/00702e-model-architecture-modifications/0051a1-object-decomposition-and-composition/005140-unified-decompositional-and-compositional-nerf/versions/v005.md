# Unified Decompositional and Compositional NeRF

Also called: Joint decomposition and composition framework, Two-stage NeRF for joint decomposition and composition, UDC-NeRF, Unifed decompositional and compositional NeRF

## Overview
Unified Decompositional and Compositional NeRF (UDC-NeRF) is a two-stage framework that jointly learns disentangled object-level representations and a global scene representation to enable both novel view synthesis and semantic scene editing [S1]. Unlike sibling methods that treat decomposition and composition as separate or loosely coupled tasks, UDC-NeRF unites them in a single pipeline where a coarse global field guides sampling for a fine-grained stage that enforces one-hot object activation and residual composition [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** A set of $N$ multi-view posed images $\{x_i \mid i \in [1, N]\}$ and their corresponding instance semantic masks $\{s_{ij} \mid i \in [1, N], j \in [1, K+1]\}$ for a static scene [S1]. $K$ is the number of object instances; the background is treated as instance index 1 [S1].
*   **Outputs:** A composited radiance field $(c_{comp}, \sigma_{comp})$ for novel view synthesis, and individual object/background radiance fields $(c^k_{object}, \sigma^k_{object})$ for editing [S1].

**Data Structures**
*   **Shared Backbone:** A 4-layer Multi-Layer Perceptron (MLP) [S1].
    *   Input: 3D point coordinate $p=(x,y,z)$ and view direction $d$.
    *   Output: Generic implicit scene feature vector $f$ with dimension 256 [S1].
*   **Guidance Head:** Several MLPs following the backbone [S1].
    *   Output: Global RGB color $c_{guidance}$ and volume density $\sigma_{guidance}$ [S1].
*   **Object/Background Heads:** Two separate 3-layer MLPs (color and density prediction layers) [S1].
    *   Input: Generic feature $f$ concatenated with learnable object codes (vectors representing specific objects or background) [S1].
    *   Output: RGB color $c^i_{object}$ and volume density $\sigma^i_{object}$ for instance $i$ [S1].
*   **Learnable Codes:** A set of vectors, one for each of the $K$ objects and the background [S1].
*   **Positional Encoding:** 10 levels for coordinates, 4 levels for ray directions [S1].

**Algorithm Steps**
The method operates in two stages: Coarse Stage and Fine Stage.

1.  **Coarse Stage (Global Guidance):**
    *   Sample points along camera rays.
    *   Pass points and directions through the Shared Backbone to get $f$.
    *   Pass $f$ through the Guidance Head to predict global color $c_{guidance}$ and density $\sigma_{guidance}$ [S1].
    *   Use the distribution of $\sigma_{guidance}$ to guide point sampling for the Fine Stage (coarse-to-fine sampling) [S1].

2.  **Fine Stage (Decomposition):**
    *   Sample points along rays using the guidance from Stage 1 [S1].
    *   Pass points and directions through the Shared Backbone to get generic feature $f$ [S1].
    *   For each instance $i \in [1, K+1]$:
        *   Concatenate $f$ with the learnable code for instance $i$.
        *   Pass to the corresponding Head (Background Head for $i=1$, Object Head for $i>1$) to predict $c^i_{object}$ and $\sigma^i_{object}$ [S1].
    *   **3D One-Hot Density Regularization:**
        *   Determine if foreground objects dominate at a point by checking if any object density exceeds 1:
            $$ M_c = [\arg\max([\sigma^1_{object}, \sigma^2_{object}, ..., \sigma^{K+1}_{object}]) > 1] $$
            where $M_c$ is a binary mask [S1].
        *   Apply regularization to the background branch (index 1) at these points to suppress its density:
            $$ L_{one-hot} = M_c \|\sigma^1_{object} - \sigma_0\|^2_2 $$
            Set $\sigma_0 = -0.01$ [S1]. Note: ReLU is applied to $\sigma$ during rendering to ensure positivity, so negative raw predictions do not contribute to rendering [S1].

3.  **Fine Stage (Composition):**
    *   **One-Hot Activation:**
        *   Compute soft probability $p_i$ for the $i$-th object using Gumbel-Softmax on densities:
            $$ p_i = \frac{\exp((\sigma^i_{object} + g_i)/\tau)}{\sum_j \exp((\sigma^j_{object} + g_j)/\tau)} $$
            where $g_i \sim \text{Gumbel}(0,1)$ and temperature $\tau = 0.1$ [S1].
        *   Compute one-hot composition weights $M_{obj}$ using stop-gradient ($f_{sp}$) and one-hot function ($f_h$):
            $$ M_{obj} = f_h(\arg\max[g_i + \log \sigma^i_{object}]) - f_{sp}(P) + P $$
            where $P$ is the tensor of soft probabilities $p_i$ [S1].
        *   Composite the radiance fields:
            $$ (c_{comp}, \sigma_{comp}) = \sum_{i=1}^{K+1} M_{obj}^i \cdot (c^i_{object}, \sigma^i_{object}) $$
            [S1].
    *   **Residual Composition:**
        *   Combine the composited field $(c_{comp}, \sigma_{comp})$ with the coarse stage residual $(c_{guidance}, \sigma_{guidance})$ using point-wise average pooling:
            $$ c_{final} = \text{AvgPool}(c_{comp}, c_{guidance}) $$
            $$ \sigma_{final} = \text{AvgPool}(\sigma_{comp}, \sigma_{guidance}) $$
            [S1].
    *   **Rendering:**
        *   Render final color $\hat{C}(r)$ and opacity $\hat{O}(r)$ using standard volume rendering equations with $\sigma_{final}$ and $c_{final}$ [S1].

**Loss Functions**
The total loss is:
$$ L_{overall} = L_{comp} + \lambda_1 L_{object} + \lambda_2 L_{color pseudo} + \lambda_3 L_{one-hot} $$
where $\lambda_1, \lambda_2, \lambda_3$ are balancing weights [S1].

1.  **Object Loss ($L_{object}$):** Enforces color and opacity consistency using semantic masks $M_o(r)^k$ (foreground) and $M_b(r)^1$ (background) [S1].
    *   Render intermediate local object color and opacity:
        $$ \hat{C}^k_{object}(r) = \sum_{i=1}^N T^k_i (1 - \exp(-\sigma^k_{object} \delta_i)) c^k_{object} $$
        $$ \hat{O}^k_{object}(r) = \sum_{i=1}^N T^k_i (1 - \exp(-\sigma^k_{object} \delta_i)) $$
        $$ T^k_i = \exp(-\sum_{j=1}^{i-1} \sigma^k_{object} \delta_j) $$
        where $N$ is the number of sampled points and $\delta_i$ is the distance between adjacent points [S1].
    *   Calculate loss:
        $$ L_{object} = \sum_{k=1}^{K+1} M_o(r)^k \|\hat{C}^k_{object}(r) - C(r)\|^2_2 + \lambda_b M_b(r)^1 \|\hat{O}^1_{object}(r) - M_o(r)^1\|^2_2 $$
        [S1].

2.  **In-Painting Pseudo Supervision ($L_{color pseudo}$):** Handles occluded background regions using a pre-trained Lama inpainting model to generate pseudo-color $C^1_{pseudo}(r)$ for uncertain background regions [S1].
    *   Calculate loss:
        $$ L_{color pseudo} = M^1_b(r) \|\hat{C}^1_{object}(r) - C^1_{pseudo}(r)\|^2_2 $$
        where $M^1_b(r)$ is a 2D spatial weight map with value 0.05 for uncertain background regions [S1].

3.  **One-Hot Regularization ($L_{one-hot}$):** Defined in Step 2 above [S1].

4.  **Composition Loss ($L_{comp}$):** Standard color loss on the final rendered pixels $\hat{C}(r)$ against ground truth $C(r)$ [S1].

**Pseudocode**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class UDCNeRF:
    def __init__(self, num_objects, hidden_dim=256, num_coarse_samples=64, num_fine_samples=48):
        """
        num_objects: K, number of foreground objects.
        Background is index 1, objects are 2..K+1.
        """
        self.K = num_objects
        self.num_instances = num_objects + 1  # 1 background + K objects
        
        # Positional Encoding (simplified placeholder for standard NeRF PE)
        self.pos_enc = PositionalEncoding(freq_bands=10, include_input=True)
        
        # Shared Backbone: 4-layer MLP
        self.backbone = nn.Sequential(
            nn.Linear(self.pos_enc.output_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU()
        )
        
        # Guidance Head: Predicts global scene for coarse sampling
        self.guidance_head = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 4) # 3 for color, 1 for density
        )
        
        # Learnable Object Codes
        self.object_codes = nn.Parameter(torch.randn(self.num_instances, hidden_dim))
        
        # Heads: Separate Background Head and Object Head
        # Background Head (Index 1)
        self.bg_head = nn.Sequential(
            nn.Linear(hidden_dim * 2, hidden_dim), # Concat feature + code
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 4) # 3 for color, 1 for density
        )
        
        # Object Heads (Indices 2..K+1) - Shared weights for simplicity or separate
        # The paper says "separate background head and object head", implying one head for all objects
        self.obj_head = nn.Sequential(
            nn.Linear(hidden_dim * 2, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 4)
        )
        
        # Hyperparameters
        self.sigma_0 = -0.01
        self.tau = 0.1
        self.lambda_1 = 1.0
        self.lambda_2 = 1.0
        self.lambda_3 = 1.0
        self.lambda_b = 1.0
        
    def forward(self, rays_o, rays_d, masks, gt_colors, pseudo_colors=None):
        """
        rays_o: (N_rays, 3) origin
        rays_d: (N_rays, 3) direction
        masks: (N_rays, num_instances) semantic masks (0 or 1)
        gt_colors: (N_rays, 3) ground truth colors
        pseudo_colors: (N_rays, 3) inpainted background colors (optional)
        """
        # 1. Coarse Stage
        # Sample coarse points
        coarse_points, coarse_alphas = self.sample_coarse(rays_o, rays_d)
        coarse_features = self.get_features(coarse_points, rays_d)
        coarse_preds = self.guidance_head(coarse_features)
        coarse_c, coarse_sigma = coarse_preds[:, :3], coarse_preds[:, 3:]
        
        # 2. Fine Stage Sampling guided by coarse density
        fine_points, fine_alphas = self.sample_fine(rays_o, rays_d, coarse_sigma)
        fine_features = self.get_features(fine_points, rays_d)
        
        # 3. Fine Stage Decomposition
        # Get codes for all instances
        codes = self.object_codes.unsqueeze(0).expand(fine_points.size(0), -1, -1) # (N_rays, K+1, D)
        
        # Concatenate features and codes
        # fine_features: (N_rays, D) -> expand to (N_rays, K+1, D)
        fine_features_exp = fine_features.unsqueeze(1).expand(-1, self.num_instances, -1)
        inputs = torch.cat([fine_features_exp, codes], dim=-1) # (N_rays, K+1, 2D)
        
        # Predict for all instances
        # Use separate heads: Index 0 is background, 1..K are objects
        preds = torch.zeros(fine_points.size(0), self.num_instances, 4, device=fine_points.device)
        
        # Background Head (Index 0)
        preds[:, 0, :] = self.bg_head(inputs[:, 0, :])
        
        # Object Heads (Indices 1..K)
        preds[:, 1:, :] = self.obj_head(inputs[:, 1:, :])
        
        c_fine = preds[:, :, :3] # (N_rays, K+1, 3)
        sigma_fine = preds[:, :, 3] # (N_rays, K+1)
        
        # Apply ReLU to sigma for rendering positivity
        sigma_fine_relu = F.relu(sigma_fine)
        
        # 4. Loss Calculation
        
        # A. One-Hot Density Regularization
        # M_c = [argmax(sigma_fine) > 1]
        max_sigma, _ = torch.max(sigma_fine, dim=1)
        M_c = (max_sigma > 1.0).float()
        
        # L_one_hot = M_c * ||sigma_bg - sigma_0||^2
        sigma_bg = sigma_fine[:, 0]
        L_one_hot = torch.mean(M_c * (sigma_bg - self.sigma_0)**2)
        
        # B. Intermediate Local Rendering for Object Loss
        # Render each object branch separately
        # Note: Standard NeRF rendering requires transmittance calculation
        # We approximate N and delta for the loss calculation based on fine samples
        # Assuming uniform spacing for simplicity in this pseudocode block
        # In practice, delta_i is computed from point positions
        N_samples = fine_points.size(0) // rays_o.size(0)
        delta = torch.ones_like(fine_alphas) # Placeholder for actual delta calculation
        
        # Render opacity and color for each object k
        # T_i = exp(-sum_{j<i} sigma_j * delta_j)
        # This is complex to vectorize fully without a dedicated renderer function, 
        # so we outline the logic.
        
        # For each object k:
        # 1. Calculate transmittance T^k
        # 2. Calculate C^k and O^k
        # 3. Apply mask M_o(r)^k and M_b(r)^1
        # 4. Compute L_object
        
        # C. In-Painting Pseudo Supervision (Background)
        # Render background branch specifically for pseudo loss
        # Render background color C^1_object
        # L_color_pseudo = M_b^1(r) * ||C^1_object - C_pseudo||^2
        # M_b^1(r) is 0.05 in uncertain regions, 0 otherwise.
        # Uncertain regions are those covered by foreground in all views (handled by mask logic)
        L_color_pseudo = 0.0
        if pseudo_colors is not None:
            # Render background branch
            # ... (rendering logic for background only) ...
            # C_bg_rendered = ...
            # M_b_mask = ... (from semantic masks, background region)
            # L_color_pseudo = torch.mean(M_b_mask * 0.05 * (C_bg_rendered - pseudo_colors)**2)
            pass

        # D. Composition and Final Rendering
        # Gumbel-Softmax for activation weights
        g = torch.distributions.gumbel.Gumbel(0, 1)
        g_samples = g.sample((rays_o.size(0), self.num_instances)).to(fine_points.device)
        
        # Soft probability p_i
        # p_i = exp((sigma_i + g_i)/tau) / sum(exp((sigma_j + g_j)/tau))
        logits = (sigma_fine + g_samples) / self.tau
        P = F.softmax(logits, dim=1) # (N_rays, K+1)
        
        # One-hot weights M_obj
        # M_obj = fh(argmax[g_i + log(sigma_i)]) - f_sp(P) + P
        # argmax on g_i + log(sigma_i)
        # Note: sigma_i can be 0, log(0) is -inf. Handle carefully.
        log_sigma = torch.log(sigma_fine_relu + 1e-6)
        argmax_indices = torch.argmax(g_samples + log_sigma, dim=1, keepdim=True)
        
        # One-hot function fh
        M_one_hot = F.one_hot(argmax_indices.squeeze(-1), num_classes=self.num_instances).float()
        
        # Stop gradient on P
        P_no_grad = P.detach()
        
        M_obj = M_one_hot - P_no_grad + P
        
        # Composite radiance
        # c_comp = sum(M_obj_i * c_i)
        c_comp = torch.sum(M_obj.unsqueeze(-1) * c_fine_relu, dim=1) # (N_rays, 3)
        sigma_comp = torch.sum(M_obj * sigma_fine_relu, dim=1) # (N_rays)
        
        # Residual Composition with Guidance
        # c_final = AvgPool(c_comp, c_guidance)
        # sigma_final = AvgPool(sigma_comp, sigma_guidance)
        # Need to sample guidance at fine points or average guidance over the ray
        # Assuming guidance is averaged over the ray for the final pixel
        c_guidance_avg = torch.mean(coarse_c, dim=1)
        sigma_guidance_avg = torch.mean(coarse_sigma, dim=1)
        
        c_final = (c_comp + c_guidance_avg) / 2.0
        sigma_final = (sigma_comp + sigma_guidance_avg) / 2.0
        
        # Final Rendering (using standard volume rendering with final sigma/c)
        # This step is recursive in standard NeRF, but here we use the composed values
        # as the primary signal. The paper says "apply a color loss L_comp for the pixels 
        # rendered from the composited radiance field".
        # We assume the composited (c_comp, sigma_comp) is rendered via standard VR,
        # then averaged with guidance? Or the guidance is a residual added to the final output?
        # "combine the composited radiance fields ... with the predicted residual ... 
        # using point-wise average pooling ... Then we apply a color loss"
        # This implies the final pixel color is the average of the composed object field 
        # and the global guidance field.
        
        # Render final pixel color from c_final, sigma_final
        # Standard VR: C = sum(T_i * (1-exp(-sigma_i*delta_i)) * c_i)
        # Since we already composed c and sigma, we can treat them as a single field
        # or render the composed field. The paper suggests averaging the *fields* before 
        # or after? "combine ... using point-wise average pooling on color and density".
        # This suggests we average the density and color values, then render? 
        # Or render the composed object field, render the guidance field, and average?
        # "Residual Prediction ... produce a final composited scene radiance field ... 
        # apply a color loss L_comp for the pixels rendered from the composited radiance field."
        # It seems the "composited radiance field" IS the final field used for rendering.
        # So we render using c_final and sigma_final.
        
        # For simplicity in pseudocode, we assume the final color is just c_final 
        # if we consider the composition as the final appearance, 
        # but strictly, volume rendering must be applied to sigma_final and c_final.
        # Let's assume standard VR on the final composed values.
        
        # T_final = exp(-sum(sigma_final * delta))
        # C_rendered = sum(T_final * (1-exp(-sigma_final*delta)) * c_final)
        
        # Since we don't have a full VR engine here, we approximate the loss 
        # on the composed values if they are treated as the final pixel color 
        # (which is an approximation if sigma is not 0).
        # However, the paper distinguishes between the "composited radiance field" 
        # and the "final rendered pixels".
        # Let's assume the standard VR is applied to the final (c_final, sigma_final).
        
        # L_comp = ||C_rendered - C_gt||^2
        # For this pseudocode, we will calculate L_comp on the direct composition 
        # if we assume the guidance is a residual correction to the *rendered* image,
        # but the text says "average pooling on color and density" then "rendered from 
        # the composited radiance field". This implies:
        # 1. Compose objects -> (c_obj_comp, sigma_obj_comp)
        # 2. Average with guidance -> (c_final, sigma_final)
        # 3. Render (c_final, sigma_final) -> C_final
        # 4. Loss on C_final.
        
        # We will skip the full VR implementation for brevity and assume 
        # C_final is approximated by c_final for the loss calculation in this context,
        # or that the "average pooling" happens at the pixel level after rendering.
        # Re-reading: "combine the composited radiance fields ... with the predicted residual 
        # radiance field ... using point-wise average pooling on color and density."
        # This happens at the point/sample level. Then "rendered from the composited radiance field".
        # So we render using the averaged sigma and c.
        
        # L_comp = MSE(C_rendered, gt_colors)
        L_comp = torch.mean((c_final - gt_colors)**2) # Approximation
        
        L_object = 0.0 # Placeholder for complex mask-based loss
        L_color_pseudo = 0.0 # Placeholder
        
        L_total = L_comp + self.lambda_1 * L_object + self.lambda_2 * L_color_pseudo + self.lambda_3 * L_one_hot
        
        return c_final, L_total
```

**Parameters**
*   $N$: Number of multi-view images [S1].
*   $K$: Number of object instances [S1].
*   $\tau$: Gumbel-Softmax temperature, set to 0.1 [S1].
*   $\sigma_0$: Regularization target for background density, set to -0.01 [S1].
*   $\lambda_1, \lambda_2, \lambda_3$: Balancing weights for $L_{object}, L_{color pseudo}, L_{one-hot}$ [S1].
*   Positional Encoding: 10 levels for coordinates, 4 levels for directions [S1].

**Edge Cases and Pitfalls**
*   **Occlusion Ambiguity:** Regions occluded by objects in all training views have no pixel-wise supervision, leading to generation ambiguity [S1]. Addressed by 2D in-painting pseudo supervision [S1].
*   **Gradient Backpropagation:** The $\arg\max$ operation for one-hot activation is non-differentiable. Addressed by using Gumbel-Softmax on volume density as a continuous approximation [S1].
*   **In-painting Ambiguity:** 2D in-painting may introduce ambiguity in regions seen in other views. This is suppressed by strong multi-view consistency supervision [S1].
*   **Density Positivity:** Raw density predictions can be negative. ReLU is applied during rendering to ensure positivity, allowing $\sigma_0$ to be negative [S1].

## Operating characteristics
*   **Time Complexity:** Two-stage rendering (coarse + fine) increases per-ray computation compared to single-stage NeRF. The fine stage requires $K+1$ forward passes through the heads per point, plus Gumbel-Softmax computation [S1].
*   **Memory Complexity:** Requires storing $K+1$ sets of object codes and separate MLP heads for objects and background [S1].
*   **Strengths:** Enables joint novel view synthesis and semantic editing (removal, addition, duplication, rotation) in a unified pipeline [S1]. Models interactions between global consistency and local details [S1].
*   **Limitations:** Relies on semantic masks for supervision [S1]. Performance depends on the quality of the pre-trained in-painting model for background regions [S1].
*   **When to use:** When both high-fidelity novel view synthesis and semantic object-level editing are required [S1].
*   **When not to use:** If only novel view synthesis is needed without editing, or if semantic masks are unavailable [S1].

## Background
The method was proposed in "Learning Unified Decompositional and Compositional NeRF for Editable Novel View Synthesis" (2023) [S1]. It addresses the limitation of prior works like ObjectNeRF, which learn separate networks for global scene branch and local object branch without modeling interactions [S1]. UDC-NeRF unites decomposition and composition to model these interactions [S1].
