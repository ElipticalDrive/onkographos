# LISA

Also called: LISA (April 2022)

## Overview
LISA is a part-based implicit neural representation method specifically designed for modeling human hands [S1, S2]. It approximates the complex geometry of hands by decomposing them into a collection of rigid parts, leveraging the MANO (Modeling of the HAND) parametric model [S2]. Unlike monolithic NeRF approaches, LISA distinguishes itself by using Signed Distance Fields (SDFs) for shape description and implicitly encoding MANO shape parameters via skeletal posture, while simultaneously learning a color field for realistic appearance [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D query points $\mathbf{x}$, skeletal posture parameters (derived from MANO), and potentially object interaction constraints.
*   **Outputs:** Signed Distance Field (SDF) values representing geometry (distance to hand and object surfaces), decomposition labels (part identification), and color values [S2].

**Data Structures:**
*   **MANO Model:** Used as a prior for hand topology and rigging. Shape parameters are not stored explicitly but are implicitly described by the current skeletal posture [S2].
*   **MLP Architecture:** Multi-Layer Perceptrons are employed to map input features to geometry and color outputs [S1].

**Steps:**
1.  **Pose-Driven Shape Encoding:** The method takes the skeletal posture of the hand as input. Instead of using explicit shape coefficients, it implicitly describes the MANO shape parameters based on this posture [S2].
2.  **Query Processing:** 3D query points $\mathbf{x}$ are sampled in the vicinity of the hand. These points are fed into the MLPs [S1].
3.  **Geometry Prediction (SDF):** The MLP predicts the SDF value for each query point. This value represents the distance from the point to the hand surface and any interacting objects [S2]. The use of SDF allows for robust surface reconstruction and handling of self-occlusions or part boundaries [S2].
4.  **Part Decomposition:** The model predicts a decomposition label for each query point, identifying which rigid part of the hand (e.g., finger, palm) the point belongs to [S2].
5.  **Color Prediction:** Alongside geometry, the MLP learns a color field to predict the RGB appearance of the query point, ensuring realistic rendering [S2].
6.  **Physical Constraint Enforcement:** To prevent interpenetration between the decoded hand and interacting objects, physical constraints are introduced into the optimization process [S2].

**Formulas:**
*   Let $\mathbf{p}$ be the skeletal posture.
*   Let $\mathbf{x}$ be a 3D query point.
*   The SDF is predicted as $d = \text{MLP}_{geo}(\mathbf{x}, \mathbf{p})$ [S1, S2].
*   The color is predicted as $c = \text{MLP}_{color}(\mathbf{x}, \mathbf{p})$ [S2].
*   The decomposition label is predicted as $l = \text{MLP}_{decomp}(\mathbf{x}, \mathbf{p})$ [S2].

**Parameters:**
*   Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Interpenetration:** Without explicit physical constraints, the hand mesh may penetrate interacting objects. LISA addresses this by incorporating constraints during training [S2].
*   **Part Boundary Artifacts:** Since the hand is modeled as rigid parts, discontinuities may occur at part boundaries if not handled by the SDF blending or decomposition logic.

## Operating characteristics
*   **Time and Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Not given in the sources.
*   **Strengths:** Explicit handling of hand topology via MANO; robust geometry via SDF; realistic appearance via learned color field; ability to handle object interactions via constraints [S2].
*   **Limitations:** Specific to hands; relies on the accuracy of the MANO model and skeletal pose estimation [S1, S2].
*   **When to use:** When high-fidelity hand modeling with object interaction is required.
*   **When not:** For full-body avatars or non-hand objects.

## Background
LISA was introduced in April 2022 [S1]. It emerged as a response to the need for specialized modeling of hands, which are complex due to their many degrees of freedom and frequent interactions with objects [S1, S2]. It builds upon the pioneering research in HyperNeRF and NeRFies, adapting their implicit neural representation techniques to the specific domain of hand avatars [S1]. It is related to other part-based methods like HALO but distinguishes itself by using SDFs and implicit shape encoding [S2].
