# ActiveNeRF Model Architecture

Also called: ActiveNeRF MLP structure, Uncertainty-aware NeRF network

## Overview
ActiveNeRF modifies the standard NeRF architecture [14428-sparse-view-and-few-shot-optimization.md] to output prediction variance alongside density and color, enabling uncertainty-aware view synthesis [S1]. Unlike sibling architectures that primarily focus on input expansion or representation substitution, ActiveNeRF introduces an auxiliary output head for variance estimation to guide active sampling strategies [S1].

## How it works
**Inputs and Outputs:**
The network takes positional encoded 3D coordinates $\gamma(\mathbf{x})$ and viewing directions $\gamma(\mathbf{d})$ as inputs. It outputs volume density $\sigma$, RGB color $\mathbf{c}$, and prediction variance $\beta^2$ [S1].

**Data Structures:**
The model consists of two Multi-Layer Perceptrons (MLPs): a coarse network and a fine network, following the standard NeRF configuration [S1]. The specific architectural modifications apply to both networks.

**Network Layout:**
1.  **Positional Encoding:** Inputs are encoded using $\gamma(\mathbf{x})$ for 3D coordinates and $\gamma(\mathbf{d})$ for viewing directions [S1].
2.  **Feature Extraction:** The encoded coordinates $\gamma(\mathbf{x})$ are passed through an 8-layer fully connected (FC) MLP. A residual connection is applied to the 4th layer [S1].
3.  **Density Prediction:** A single FC layer outputs the volume density $\sigma$ [S1].
4.  **Variance Prediction:** A separate FC layer with a softplus activation function outputs the prediction variance $\beta^2$ [S1].
5.  **Color Prediction:** The latent feature vector from the feature extraction MLP is concatenated with the encoded viewing directions $\gamma(\mathbf{d})$. This concatenated vector is passed through a final FC layer to predict the RGB color $\mathbf{c}$ [S1].

**Formulas:**
Positional encoding for a scalar $p$ with $L$ bands [S1]:
$$
\gamma(p) = (\sin(2^0\pi p), \cos(2^0\pi p), \dots, \sin(2^{L-1}\pi p), \cos(2^{L-1}\pi p))
$$

**Parameters:**
*   $L=10$: Number of frequency bands for 3D coordinates [S1].
*   $L=4$: Number of frequency bands for viewing directions [S1].

## Background
ActiveNeRF was introduced to address the problem of active view selection by incorporating uncertainty estimation into the radiance field representation [S1]. The architecture builds upon the original NeRF [20] (cited in [S1]), which uses positional encoding and MLPs for density and color prediction [S1]. The key innovation is the addition of the variance prediction head, allowing the model to estimate where its predictions are uncertain, thereby guiding the selection of new viewpoints for training [S1].
