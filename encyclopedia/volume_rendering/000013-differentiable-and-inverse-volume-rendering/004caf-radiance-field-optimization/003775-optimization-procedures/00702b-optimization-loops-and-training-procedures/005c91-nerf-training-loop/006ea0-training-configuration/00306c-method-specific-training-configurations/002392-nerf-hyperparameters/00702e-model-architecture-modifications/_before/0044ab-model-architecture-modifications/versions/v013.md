# Model Architecture Modifications

Also called: NeRF Architecture Variants, NeRF Structural Changes

## Overview
Model Architecture Modifications extend the standard Neural Radiance Field (NeRF) framework by altering the underlying neural network structure, the implicit representation of the scene, or the input/output interfaces to address specific limitations such as dynamic scenes, sparse views, hardware constraints, or semantic understanding. While the standard NeRF [S6] uses two Multi-Layer Perceptrons (MLPs) to map 3D coordinates and viewing directions to density and color, this family encompasses methods that substitute these MLPs with discrete grids [13738-voxel-and-sparse-grid-representations], replace density with Signed Distance Functions (SDFs) [12495-signed-distance-function-sdf-representations], or augment the network with auxiliary heads for semantics [13619-said-nerf] and features [12995-feature-fields]. These modifications enable capabilities ranging from real-time rendering on edge devices [12401-mixrt] to robust reconstruction from under-exposed images [13764-aleth-nerf] and dynamic human avatars [13784-unified-volumetric-avatar-uva].

## Shared principles
The standard NeRF architecture [S6] serves as the baseline for most modifications. It consists of two MLPs: a coarse network and a fine network.
1.  **Coarse Network:** Takes positional encoded position $\gamma(\mathbf{x})$ and outputs a latent feature vector $\mathbf{h}$ and volume density $\sigma$.
2.  **Fine Network:** Takes $\mathbf{h}$, positional encoded position $\gamma(\mathbf{x})$, and positional encoded view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$.

The positional encoding function $\gamma(\mathbf{x}, d_1, d_2)$ is defined as:
$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$

Modifications generally fall into three categories:
1.  **Input Expansion:** Adding new conditioning vectors (e.g., appearance embeddings $\mathbf{z}_i$, fluid volume $v$, or previous stage RGB) to the input concatenation.
2.  **Output Expansion:** Adding auxiliary heads to predict values other than $\sigma$ and $\mathbf{c}$, such as semantic labels $y_{aux}$, object codes $o$, or area encoding probabilities $p$. These are rendered using the same transmittance weights $T_i$ and opacity $\alpha_i$ as color:
    $$
    \hat{Y}(r) = \sum_{i=1}^{N} T_i \alpha_i y_{aux}(x_i)
    $$
3.  **Representation Substitution:** Replacing the continuous MLP function with discrete structures (voxel grids, hash tables) or different implicit surfaces (SDFs).

## Subtopics

### [DoF-NeRF](9432-dof-nerf.md)
DoF-NeRF extends the standard NeRF to simulate depth-of-field effects by modeling the Circle of Confusion (CoC). It introduces two learnable scalar parameters per training view: the aperture parameter $K$ and the focus distance $F$. These are jointly optimized with the NeRF network parameters. The CoC diameter is defined as $\delta(h_t) = K \times | \frac{1}{F} - \frac{1}{h_t} |$. It is chosen when the input images have shallow depth-of-field and the goal is to recover an all-in-focus 3D representation.

### [NeRF-VPT](11770-nerf-vpt.md)
NeRF-VPT is a cascading view prompt tuning paradigm that uses RGB information from preceding rendering iterations as visual prompts for subsequent stages. It solves the problem of limited scene understanding in sparse-view settings by iteratively refining the network's output. Unlike methods relying on external networks, it uses only the network's internal output as prior knowledge. It is chosen when high-quality novel view synthesis is required from limited input views without pre-training.

### [MixRT](12401-mixrt.md)
MixRT is a hybrid neural representation for real-time NeRF rendering on edge devices. It combines a low-quality triangle mesh for coarse geometry, a view-dependent displacement map for surface calibration, and a compressed NeRF model (Instant-NGP format) for density and color. It offloads ray intersection to rasterizers and surface refinement to texture mapping units. It is chosen when real-time performance (>30 FPS) and low storage (<80% of SOTA) are critical constraints.

### [Activation Feature Density Approximation](12492-activation-feature-density-approximation.md)
This method estimates volumetric density $\hat{d}$ directly from intermediate activation features $\mathbf{f}_\ell$ of a coordinate-based MLP, replacing expensive coarse network evaluations. It differs from SDF-based methods by retaining the standard density-based rendering formulation. It is chosen when inference speed is prioritized over the precision of the coarse pass.

### [Signed Distance Function (SDF) Representations](12495-signed-distance-function-sdf-representations.md)
SDF Representations replace volumetric density prediction with a continuous scalar field representing the distance to the nearest surface. The surface is defined as the zero-level set $\{\mathbf{x} \mid s(\mathbf{x}) = 0\}$. This approach addresses geometric inaccuracy and surface holes typical of density-based NeRFs. It is chosen when explicit, sharp surface reconstruction is required.

### [Volume-Augmented NeRF](12973-volume-augmented-nerf.md)
Volume-Augmented NeRF is designed for dynamic fluid scenes. It binds an explicit fluid volume value $v_i$ to each sample point, allowing the renderer to learn density and color based on the spatial distribution from a differentiable fluid simulator. It serves as the rendering component in a joint differentiable framework. It is chosen for simulating and rendering fluid dynamics.

### [Neural-PIL Decomposition Architecture](12975-neural-pil-decomposition-architecture.md)
This architecture separates scene geometry, material properties, and illumination into distinct networks. It predicts density, a BRDF embedding, and an illumination embedding, using a learned pre-integrated lighting network. It is chosen when input images are captured under varying illumination and explicit reflectance decomposition is required.

### [Feature Fields](12995-feature-fields.md)
Feature Fields generalize NeRF by predicting arbitrary per-point feature signals $\mathbf{f}$ in addition to color $\mathbf{c}$ and density $\sigma$. This allows the radiance field to encode semantic labels, object codes, or latent embeddings. It is chosen when 3D-aware semantic understanding or object segmentation is needed.

### [SAID-NeRF](13619-said-nerf.md)
SAID-NeRF exploits instance masks from Visual Foundation Models (VFMs) to enhance surface estimation of transparent objects. It decomposes appearance into diffuse and specular components and uses semantic segmentation to enforce higher surface densities. It builds on Instant-NGP and Semantic and Feature Branches. It is chosen for robotic grasping applications requiring sharp depth estimates of transparent objects.

### [MINE](13661-mine.md)
MINE models the frustum of the source camera using a continuous depth Multiplane Image (MPI) representation, conditioned on input images via a fully-convolutional decoder. It reconstructs the frustum per plane, allowing rendering of any target view via homography warping after a single encoder pass. It is significantly more efficient than ray-based methods for rendering multiple novel views.

### [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md)
This family replaces the continuous MLP with discrete structures like 3D voxel grids, hash tables, or triplanes. This enables real-time differentiable volume rendering by computing color and density via interpolation. It is chosen when inference latency must be reduced compared to heavy feed-forward MLP computation.

### [Aleth-NeRF](13764-aleth-nerf.md)
Aleth-NeRF trains on under- and over-exposed images to render normal-light novel views by introducing a 'Concealing Field' assumption. It models illumination adaptive volume rendering through local and global concealing fields. Unlike RAW-NeRF, it operates on standard 8-bit LDR images. It is chosen for low-light or over-exposed input scenarios without paired training data.

### [Unified Volumetric Avatar (UVA)](13784-unified-volumetric-avatar-uva.md)
UVA represents dynamic human avatars with local and independent editing of geometry and texture. It anchors structured latent codes to a deformable mesh in canonical space, unlike pre-defined UV mapping methods. It is end-to-end trainable and jointly optimized with the skinning field. It is chosen for dynamic avatar synthesis with editable textures.

### [Gear-NeRF](13848-gear-nerf.md)
Gear-NeRF leverages semantic information to stratify dynamic scenes into motion-based 'gears', allowing region-specific spatio-temporal sampling resolution. It uses a series of 4D feature volumes, one per gear level. It is chosen for efficient free-viewpoint rendering and tracking of dynamic scenes with varying motion scales.

### [Transformer and Vision Model Integration](13911-transformer-and-vision-model-integration.md)
This family integrates Vision Transformers (ViT) into NeRFs to leverage global semantic understanding. It solves the limitations of standard MLP-based NeRFs regarding global scene modeling and single-image inputs. It is chosen when generalization across scenes or handling occlusions via attention is required.

### [Human and Specific Subject Modeling](13997-human-and-specific-subject-modeling.md)
Not given in the sources.

### [OPONeRF](14014-oponerf.md)
OPONeRF personalizes the parameters of the plenoptic mapping function for each sampled 3D point. It dynamically conditions network weights $\Theta$ on the point's representation $\mathbf{x}$ and the scene representation $\mathbf{F}$. This handles test-time scene changes and perturbations. It is chosen for robustness against motion, illumination changes, or contamination.

### [Mixer-NeRF](14073-mixer-nerf.md)
Mixer-NeRF addresses the loss of local information and blurry details in standard NeRFs by introducing a hybrid spatial feature learning module (MLCA) and a squeeze-and-excitation (SE) network module. It explicitly mixes spatial and channel features via fully connected layers before the main MLP inference. It is chosen when high-frequency detail preservation is critical.

### [SCALAR-NeRF](14267-scalar-nerf.md)
SCALAR-NeRF is a coarse-to-fine framework for scalable large-scale neural scene reconstruction. It decomposes scenes into spatial blocks, training a coarse global model first, followed by local block models that share the global decoder. It fuses local outputs using a reference image from the global model. It is chosen for large-scale reconstruction on a single GPU.

### [Sparse View and Few-Shot Optimization](14428-sparse-view-and-few-shot-optimization.md)
This family addresses overfitting and artifact generation when training with drastically reduced viewpoints ($|S| < 20$). It mitigates ambiguity through in-situ regularization, deformable sampling, or pseudo-observation densification. It is chosen when input data is extremely sparse.

### [Mixture-of-Experts and Modular Architectures](14429-mixture-of-experts-and-modular-architectures.md)
This family replaces the single continuous function of NeRF with multiple specialized networks (experts) or parallel streams. It solves the limitations of conventional INRs struggling with complex features. It is chosen when representation capacity or compression is limited by a single network.

### [Uncertainty and Reliability](14487-uncertainty-and-reliability.md)
Uncertainty and Reliability methods extend NeRF architectures to quantify prediction confidence. They model the scene as a probabilistic entity, providing pixel-level reliability metrics for color and depth. It is chosen for robust filtering and conformal prediction in sparse or unstructured data.

### [Object Decomposition and Composition](14518-object-decomposition-and-composition.md)
These methods explicitly separate a scene into distinct semantic or geometric object instances. They introduce auxiliary outputs (object codes, separate heads) to decompose the volume. It is chosen for instance-level editing, manipulation, and amodal segmentation.

### [Lighting and Appearance Models](14522-lighting-and-appearance-models.md)
Lighting and Appearance Models modify NeRF to explicitly represent illumination and material properties. They decouple geometry, albedo, and illumination using explicit mathematical bases or neural modules. It is chosen for semantic lighting control, relighting, and stylization.

### [Optimization and Training Procedures](14565-optimization-and-training-procedures.md)
This family covers algorithmic procedures for optimizing NeRFs, including structural modifications to the optimization scope. It addresses efficiently minimizing photometric loss while managing computational constraints. It is chosen when standard gradient descent is insufficient or too slow.

### [Image Enhancement and Restoration Methods](14566-image-enhancement-and-restoration-methods.md)
These methods address input imagery degradation (blur, occlusions, low resolution) by integrating restoration mechanisms into the NeRF loop. They differ by focusing on specific degradation types, often using 2D priors. It is chosen when input images are not sharp or clean.

### [Modular, Hierarchical, and Latent Architectures](14567-modular-hierarchical-and-latent-architectures.md)
This family extends NeRFs to handle non-rigid deformation with topological changes (HyperNeRF) and hierarchical scene structures (Strata-NeRF). It is chosen for complex dynamic scenes or scenes with distinct interior/exterior levels.

### [MuRF (Multi-Baseline Radiance Fields)](15007-murf-multi-baseline-radiance-fields.md)
MuRF is a feed-forward method for sparse view synthesis under varying camera baselines. It constructs a target view frustum volume aligned with the target camera and uses a 3D context-aware convolutional decoder. It is chosen when input and target views have small overlap (large baselines).

### [Gaussian and Primitive-Based Representations](15011-gaussian-and-primitive-based-representations.md)
This family replaces the continuous MLP with discrete geometric primitives or explicit Gaussian distributions. It differs from voxel grids by using analytic primitives and from SDFs by relying on alpha-blended primitives. It is chosen for improved rendering efficiency and geometric fidelity.

### [Decentralized Federated NeRF](15032-decentralized-federated-nerf.md)
DecentNeRF learns global 3D scene representations from crowd-sourced images by distributing training to users and aggregating only global models. It decomposes the scene into global and personal radiance fields per user. It is chosen for privacy-preserving, large-scale 3D reconstruction.

### [Tile and Slide Framework](15219-tile-and-slide-framework.md)
The Tile and Slide Framework (Snake-NeRF) scales NeRFs to large-scale Earth observation scenes by dividing the region into non-overlapping 3D tiles. It operates on a single GPU using a 2x2 sliding window. It is chosen for out-of-core training of massive scenes.

### [Neural Proxy](15220-neural-proxy.md)
Neural Proxy represents photo-realistic targets as animatable proxies, combining neural volume rendering with neural texture. It injects an animatable mesh proxy into the scene. It is chosen for synthesizing unseen animations without temporal learning.

### [ViSNeRF](15255-visnerf.md)
ViSNeRF is a hybrid method for synthesizing visualizations from dynamic volumetric scenes with adjustable parameters. It combines explicit feature grids with implicit MLP decoders and generalized tensor factorization. It is chosen for scalable representation of high-dimensional $(3+K)$-D radiance fields.

### NeRF-VAE
- **Definition:** A generative NeRF model that generalizes to out-of-distribution scenes and removes the need to train on each scene from scratch [S1].
- **Steps:** The NeRF renderer is conditioned on a latent code trained using Iterative Amortized Inference and a ResNet encoder. An attention-based scene function is introduced instead of the typical MLP [S1].
- **Comparison:** Outperforms baseline NeRF with a low number of scene views (5-20), but is outperformed by baseline NeRF when a large number of views are available (100+) due to lower scene expressivity [S1].

### PIE-NeRF
- **Definition:** A pipeline integrating physics-based elastodynamic simulation with a neural radiance field representation, using a meshless discretisation based on quadratic generalized moving least squares on top of the density field of a NeRF [S1].
- **Steps:** Enables large deformations and nonlinear hyperelastic material simulation directly on the implicit representation and supports interactive manipulation of real-world captured scenes with complex geometries [S1].

### DäRF Implementation Details
- **Parameters:** NeRF Backbone: K-planes [S2, unofficial]. MDE Model: DPT-hybrid [S2, unofficial]. Optimizer: Adam [S2, unofficial]. NeRF Learning Rate: 1e-2 [S2, unofficial]. MDE Learning Rate: 1e-5 [S2, unofficial]. LR Schedule: Cosine warmup [S2, unofficial].

### NeRF Model Architecture
- **Definition:** The neural network architecture for NeRF, consisting of dense layers with ReLU activations, potentially using view directions as input [S3, unofficial].
- **Parameters:** `D`: The depth of the network (number of hidden layers). Default is 8 [S3, unofficial]. `input_ch_views`: The number of input channels for view directions. Default is 3 [S3, unofficial]. `output_ch`: The number of output channels. Default is 4 (RGB + density) [S3, unofficial]. `use_viewdirs`: Boolean flag to determine if view directions are used as input to the network [S3, unofficial].

### S3-NeRF
- **Definition:** A method using shadow and shading cues to infer scene geometry and enable single-image NeRF training [S1].
- **Steps:** Employ a UNISURF-based occupancy field 3D representation instead of density. Use a modified physics-based rendering equation. Use occupancy-based shadow calculation [S1].

### NeRF with Time Parameter
- **Steps:** Add a time parameter to the model inputs to adapt NeRF for dynamic scenes. Positionally encode the time parameter and concatenate it with the positional encoding of spatial coordinates $\gamma_x(\mathbf{x})$ [S4].
- **Parameters:** Train using the configuration reported for NeRF's real forward-facing experiments [S4].
- **Comparison:** Adding a time parameter improves quality over vanilla NeRF but still lacks detail, suffers from blurry predictions, and fails to reason about scene dynamics [S4].

### NeRF-Editing
- **Definition:** The first mesh-based shape deformation method, leveraging explicit representations for scene geometry edits and implicit representations for realistic rendering effects [S5].
- **Steps:** 1. Extract explicit triangular mesh from NeRF. 2. Enable intuitive user-driven deformations through classic ARAP deformation method. 3. Generate tetrahedral mesh around triangular mesh to propagate deformations spatially. 4. Employ tetrahedral vertex interpolation to transform discrete deformations into continuous field. 5. Ensure rays passing through mesh bend according to user adjustments [S5].

### NeuralEditor
- **Definition:** A method employing a point cloud-guided NeRF model for shape manipulation, leveraging K-D trees and deterministic integration strategy for accurate point cloud-based rendering, with Phong reflection modeling to enhance color fidelity and geometric detail [S5].
- **Steps:** 1. Employ point cloud-guided NeRF model. 2. Leverage K-D trees. 3. Use deterministic integration strategy. 4. Achieve accurate point cloud-based rendering. 5. Apply Phong reflection modeling [S5].

### Shared G-MLP
- **Definition:** A shared geometry MLP that enables the constraint of multi-view consistency to be propagated from the NeRF branch to the detection branch [S6].
- **Number:** Without the shared G-MLP, performance drops from 50.1 to 48.1 mAP@.25, as the influence of multi-view consistency is only propagated into the image backbone [S6].

## Background
The standard NeRF architecture was introduced by Mildenhall et al. [S6], utilizing hierarchical rendering with coarse and fine networks to improve computational efficiency. Subsequent works have focused on improving geometry [S1], training speed [S1], and generalization. NeRF-VAE [S1] introduced generative capabilities with latent codes. S3-NeRF [S1] used shadow cues for single-image training. PIE-NeRF [S1] integrated physics-based simulation. DäRF [S2, unofficial] boosted radiance fields from sparse inputs with monocular depth adaptation. NeRF-Editing [S5] and NeuralEditor [S5] introduced mesh and point cloud-based deformation. The addition of time parameters [S4] attempted to handle dynamic scenes. Shared G-MLP [S6] was used in NeRF-Det for multi-view 3D object detection.
