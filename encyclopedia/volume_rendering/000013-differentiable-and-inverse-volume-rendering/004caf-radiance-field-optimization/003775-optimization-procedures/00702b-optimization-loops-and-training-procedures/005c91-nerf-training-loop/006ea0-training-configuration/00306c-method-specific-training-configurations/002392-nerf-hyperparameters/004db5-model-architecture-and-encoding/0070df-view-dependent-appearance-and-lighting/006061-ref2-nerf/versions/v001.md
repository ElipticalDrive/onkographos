# REF2-NeRF
Also called: Reflection and Refraction aware Neural Radiance Field

## Overview
REF2-NeRF is a NeRF-based modeling method designed for scenes containing transparent objects, specifically glass cases, where it models both refraction and reflection effects [S1]. It distinguishes itself from standard NeRF and reflection-only methods (e.g., NeRFReN, NeuS-HSR) by simultaneously estimating refraction surfaces and separating direct (view-independent) and reflected (view-dependent) light components using two independent MLPs: a glass network for refraction offsets and a decomposition NeRF for rendering [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** A set of $n$ images $\{I_k\}$ taken from different viewpoints, with predetermined camera poses (often acquired via robotic arm) [S1].
*   **Outputs:** Rendered pixel color $C(\mathbf{r})$ for a ray $\mathbf{r}$, along with intermediate fields for glass density, offsets, view-independent color/density, and view-dependent features [S1].

**Data Structures and Network Layout**
The method employs four Multi-Layer Perceptrons (MLPs):
1.  **Glass Network ($\Theta_{gl}$):**
    *   Input: Positional encoded position $\Gamma(\mathbf{x})$ and view direction $\Gamma(\mathbf{d})$ [S1].
    *   Output: Glass density $\sigma_{gl} \in \mathbb{R}$ and offset vector $\Delta \mathbf{x} \in \mathbb{R}^3$ [S1].
    *   Architecture: Input layer $[6 \times 256]$, Output layer $[2 \times 24]$ (implied by Fig 3 structure description, though exact hidden layers not fully detailed in text, standard NeRF-like structure assumed for MLPs) [S1].
2.  **Decomposition NeRF ($\Theta_{nf}$):**
    *   Input: Positional encoded adjusted position $\Gamma(\mathbf{x}')$ and view direction $\Gamma(\mathbf{d})$ [S1].
    *   Output: View-independent density $\sigma_{vi} \in \mathbb{R}$, view-independent color $\mathbf{c}_{vi} \in \mathbb{R}^3$, view-dependent density $\sigma_{vd} \in \mathbb{R}$, and view-dependent feature vector $\mathbf{f}_{vd} \in \mathbb{R}^\theta$ [S1].
    *   Architecture: View-independent branch takes only $\Gamma(\mathbf{x}')$; View-dependent branch takes $\Gamma(\mathbf{x}')$ and $\Gamma(\mathbf{d})$ [S1].
3.  **Decoder MLP ($\Theta_{dc}$):**
    *   Input: Rendered feature vector $\mathbf{F}_{vd}(\mathbf{r})$ [S1].
    *   Output: Reflection color $\mathbf{C}_{vd}(\mathbf{r}) \in \mathbb{R}^3$ [S1].
4.  **Gate MLP ($\Theta_{gt}$):**
    *   Input: Rendered feature vector $\mathbf{F}_{vd}(\mathbf{r})$ [S1].
    *   Output: Blending parameter $\alpha(\mathbf{r}) \in [0, 1]$ [S1].

**Parameters**
*   Feature vector dimension $\theta = 64$ [S1].
*   Regularization weight $\epsilon = 10^{-5}$ [S1].
*   Sampling points: Coarse 128, Fine hierarchical 64, Glass density 32, View-independent density 32. Total fine model points: 192 [S1].

**Numbered Steps**

1.  **Sampling:** For a ray $\mathbf{r}$, sample $N$ points $\mathbf{x}_i$ along the ray. The method uses a coarse-to-fine strategy. Initial coarse sampling uses 128 points at uniform intervals. Fine sampling adds 64 points hierarchically based on coarse density, plus 32 points sampled using glass density $\sigma_{gl}$ and 32 points using view-independent density $\sigma_{vi}$ [S1].

2.  **Glass Network Forward Pass:** For each sampled point $\mathbf{x}_i$ and view direction $\mathbf{d}_i$, compute glass density $\sigma_{gl,i}$ and offset $\Delta \mathbf{x}_i$ using $\Theta_{gl}$:
    $$ \sigma_{gl,i}, \Delta \mathbf{x}_i = F_{\Theta_{gl}}(\Gamma(\mathbf{x}_i), \Gamma(\mathbf{d}_i)) $$
    [S1]

3.  **Refraction Weight Calculation:** Calculate the weight $w_i$ for each sampling point $i$ using glass density $\sigma_{gl,i}$ and distance $\delta_{gl,i}$ between adjacent points. Compute transmittance $T_i$:
    $$ w_i = T_i (1 - \exp(-\sigma_{gl,i} \delta_{gl,i})) $$
    $$ T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_{gl,j} \delta_{gl,j}\right) $$
    [S1]

4.  **Position Adjustment:** Calculate the adjusted position $\mathbf{x}'_i$ by cumulatively adding the weighted offset vectors along the ray:
    $$ \mathbf{x}'_i = \mathbf{x}_i + \sum_{k=1}^{i} w_k \Delta \mathbf{x}_k $$
    [S1] (Note: Source text says "adding the weighted offset cumulatively... $x' = x + w\Delta x$" in Fig 5 caption, but Eq 3-4 context implies cumulative sum for the shift. The text states "amount of ray shifting... by adding the weighted offset cumulatively". We implement the cumulative sum.)

5.  **View-Independent Rendering:** Perform volume rendering on the adjusted positions $\mathbf{x}'$ using view-independent density $\sigma_{vi}$ and color $\mathbf{c}_{vi}$ from $\Theta_{nf}$. Note that $\sigma_{vi}$ and $\mathbf{c}_{vi}$ depend only on $\mathbf{x}'$ (view-independent):
    $$ \mathbf{C}_{vi}(\mathbf{r}) = \sum_{i=1}^{N} T_{vi,i} (1 - \exp(-\sigma_{vi,i} \delta_{vi,i})) \mathbf{c}_{vi,i} $$
    where $T_{vi,i}$ is calculated similarly to $T_i$ using $\sigma_{vi}$ [S1].

6.  **View-Dependent Feature Rendering:** Perform volume rendering on adjusted positions $\mathbf{x}'$ and view directions $\mathbf{d}$ using view-dependent density $\sigma_{vd}$ and feature vector $\mathbf{f}_{vd}$ from $\Theta_{nf}$:
    $$ \mathbf{F}_{vd}(\mathbf{r}) = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_{vd,i} \delta_{vd,i})) \mathbf{f}_{vd,i} $$
    [S1] (Note: Uses $T_i$ from glass transmittance or standard NeRF transmittance? Source Eq 8 uses $T_i$. Given the context of "view-dependent components... separated using feature field", and Eq 8 explicitly uses $T_i$ (defined in Eq 4 for glass), we use the glass transmittance $T_i$ for the view-dependent accumulation as well, or potentially standard NeRF transmittance. However, Eq 8 in source explicitly references $T_i$ which was defined in Eq 4 as glass transmittance. We follow the source notation strictly.)

7.  **View-Dependent Color and Blending:** Decode the rendered feature vector $\mathbf{F}_{vd}$ into reflection color $\mathbf{C}_{vd}$ and determine blending parameter $\alpha$:
    $$ \mathbf{C}_{vd}(\mathbf{r}) = F_{\Theta_{dc}}(\mathbf{F}_{vd}(\mathbf{r})) $$
    $$ \alpha(\mathbf{r}) = F_{\Theta_{gt}}(\mathbf{F}_{vd}(\mathbf{r})) $$
    [S1]

8.  **Final Image Composition:** Combine view-independent and view-dependent components:
    $$ \mathbf{C}(\mathbf{r}) = \mathbf{C}_{vi}(\mathbf{r}) + \alpha(\mathbf{r}) \mathbf{C}_{vd}(\mathbf{r}) $$
    [S1]

**Loss Function**
The total loss $\mathcal{L}$ is the sum of rendering loss and offset regularization:
$$ \mathcal{L} = \mathcal{L}_{render} + \epsilon \mathcal{L}_{offset} $$
$$ \mathcal{L}_{render} = \sum_{\mathbf{r} \in R} \|\bar{\mathbf{C}}(\mathbf{r}) - \mathbf{C}(\mathbf{r})\|^2 $$
$$ \mathcal{L}_{offset} = \sum_{\mathbf{x}, \mathbf{d}} \|\Delta \mathbf{x}\|^2 $$
where $\bar{\mathbf{C}}(\mathbf{r})$ is the input image color, $R$ is the batch of sampled rays, and $\epsilon = 10^{-5}$ [S1].

```python
import torch
import torch.nn as nn
import math

def positional_encoding(x, min_deg, max_deg):
    """Standard NeRF positional encoding."""
    scales = torch.tensor([2**i for i in range(min_deg, max_deg)])
    xb = torch.reshape((x * scales)[:, None, :], (x.shape[0], -1))
    freq_b = torch.cat([torch.sin(xb), torch.cos(xb)], dim=1)
    return torch.cat([x, freq_b], dim=1)

class GlassNetwork(nn.Module):
    def __init__(self):
        super().__init__()
        # Input: pos_enc (6*256? No, standard is 6*256 for 256 dim? 
        # Source Fig 3 says [6*256] input layer. This likely means input dim is 6*256? 
        # Or 6 bands * 256? Standard NeRF uses 10 bands -> 60 dim. 
        # Source text: "Input [Gamma(x), Gamma(d)]". Fig 3: "MLP [6*256]". 
        # This notation is ambiguous. Usually [L1, L2]. 
        # Let's assume standard NeRF encoding for implementation clarity, 
        # but note the source specifies specific architecture dimensions if available.
        # Source says: "Glass network... Input [Gamma(x), Gamma(d)]... Output sigma, delta x"
        # We will use a standard MLP structure for the example, assuming inputs are encoded.
        self.mlp = nn.Sequential(
            nn.Linear(60, 256), # Assuming 10 bands * 2 (sin/cos) + 3 = 23? 
            # Source Fig 3: "2*[2*24]" for Gamma. This implies 2 bands, 24 dim? 
            # Let's stick to the functional description.
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, 4) # 1 for sigma, 3 for delta x
        )

    def forward(self, x_enc, d_enc):
        x = torch.cat([x_enc, d_enc], dim=-1)
        out = self.mlp(x)
        sigma_gl = out[..., :1]
        delta_x = out[..., 1:]
        return sigma_gl, delta_x

class DecompNeRF(nn.Module):
    def __init__(self):
        super().__init__()
        # View-independent branch
        self.vi_mlp = nn.Sequential(
            nn.Linear(60, 256),
            nn.ReLU(),
            nn.Linear(256, 128),
            nn.ReLU(),
            nn.Linear(128, 4) # 1 for sigma_vi, 3 for c_vi
        )
        # View-dependent branch
        self.vd_mlp = nn.Sequential(
            nn.Linear(60 + 60, 256), # x' and d
            nn.ReLU(),
            nn.Linear(256, 128),
            nn.ReLU(),
            nn.Linear(128, 65) # 1 for sigma_vd, 64 for f_vd
        )

    def forward(self, x_prime_enc, d_enc):
        # VI
        vi_out = self.vi_mlp(x_prime_enc)
        sigma_vi = vi_out[..., :1]
        c_vi = vi_out[..., 1:]
        
        # VD
        vd_in = torch.cat([x_prime_enc, d_enc], dim=-1)
        vd_out = self.vd_mlp(vd_in)
        sigma_vd = vd_out[..., :1]
        f_vd = vd_out[..., 1:]
        
        return sigma_vi, c_vi, sigma_vd, f_vd

class DecoderMLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.mlp = nn.Sequential(
            nn.Linear(64, 128),
            nn.ReLU(),
            nn.Linear(128, 3)
        )
    def forward(self, f_vd):
        return self.mlp(f_vd)

class GateMLP(nn.Module):
    def __init__(self):
        super().__init__()
        self.mlp = nn.Sequential(
            nn.Linear(64, 128),
            nn.ReLU(),
            nn.Linear(128, 1),
            nn.Sigmoid()
        )
    def forward(self, f_vd):
        return self.mlp(f_vd)

def volume_render(sigma, color, transmittance_prev):
    """
    sigma: (N, 1)
    color: (N, 3)
    transmittance_prev: (N,)
    delta: (N,)
    """
    alpha = 1.0 - torch.exp(-sigma.squeeze(-1))
    T = transmittance_prev * (1.0 - alpha)
    weights = alpha * transmittance_prev
    color_out = torch.sum(weights.unsqueeze(-1) * color, dim=0)
    return color_out, T

def render_ray(x, d, glass_net, decomp_net, decoder_net, gate_net, 
               num_coarse=128, num_fine=192):
    """
    x: (N_rays, 3)
    d: (N_rays, 3)
    """
    # 1. Coarse Sampling
    t_coarse = torch.linspace(0, 1, num_coarse).unsqueeze(0).expand_as(x)
    # Assuming ray origin and direction are handled externally or passed
    # Here we assume x is the sampled position along the ray segment [0,1]
    
    # 2. Glass Network
    x_enc = positional_encoding(x, 0, 10) # Placeholder for exact encoding
    d_enc = positional_encoding(d, 0, 10)
    sigma_gl, delta_x = glass_net(x_enc, d_enc)
    
    # 3. Refraction Weight and Position Adjustment
    # Calculate distances between points
    delta_x_dist = torch.diff(x, dim=0, prepend=torch.zeros_like(x[:1]))
    # Note: In practice, delta is along the ray. 
    # T_i calculation
    sigma_gl_cum = torch.cumsum(sigma_gl * delta_x_dist.abs().sum(dim=-1, keepdim=True), dim=0)
    T_gl = torch.exp(-sigma_gl_cum)
    # Shift to align with points
    T_gl = torch.cat([torch.ones_like(T_gl[:1]), T_gl[:-1]], dim=0)
    
    weights_gl = T_gl * (1.0 - torch.exp(-sigma_gl * delta_x_dist.abs().sum(dim=-1, keepdim=True)))
    
    # Cumulative offset
    # delta_x is (N, 3). weights_gl is (N, 1).
    # We need to sum weighted deltas.
    weighted_delta = weights_gl * delta_x
    cumulative_offset = torch.cumsum(weighted_delta, dim=0)
    
    x_prime = x + cumulative_offset
    
    # 4. Fine Sampling (Simplified: using adjusted positions for fine pass)
    # In real implementation, hierarchical sampling would re-sample based on densities.
    # Here we assume x_prime represents the fine sampled points or we re-sample.
    # Source says "Total points for fine model: 192".
    # We will use x_prime as the input to DecompNeRF.
    
    x_prime_enc = positional_encoding(x_prime, 0, 10)
    sigma_vi, c_vi, sigma_vd, f_vd = decomp_net(x_prime_enc, d_enc)
    
    # 5. View-Independent Rendering
    # T_vi calculation similar to glass but using sigma_vi
    delta_vi_dist = torch.diff(x_prime, dim=0, prepend=torch.zeros_like(x_prime[:1]))
    sigma_vi_cum = torch.cumsum(sigma_vi * delta_vi_dist.abs().sum(dim=-1, keepdim=True), dim=0)
    T_vi = torch.exp(-sigma_vi_cum)
    T_vi = torch.cat([torch.ones_like(T_vi[:1]), T_vi[:-1]], dim=0)
    
    alpha_vi = 1.0 - torch.exp(-sigma_vi.squeeze(-1))
    weights_vi = alpha_vi * T_vi
    C_vi = torch.sum(weights_vi.unsqueeze(-1) * c_vi, dim=0)
    
    # 6. View-Dependent Feature Rendering
    # Using T_gl (glass transmittance) as per Eq 8 in source
    alpha_vd = 1.0 - torch.exp(-sigma_vd.squeeze(-1))
    weights_vd = alpha_vd * T_gl.squeeze(-1)
    F_vd = torch.sum(weights_vd.unsqueeze(-1) * f_vd, dim=0)
    
    # 7. Decode and Gate
    C_vd = decoder_net(F_vd)
    alpha_blend = gate_net(F_vd)
    
    # 8. Final Composition
    C = C_vi + alpha_blend * C_vd
    
    return C

```

## Operating characteristics
*   **Time Complexity:** Training requires 200,000 iterations. On an Nvidia RTX 4080, it takes approximately 10 hours per scene [S1].
*   **Memory Complexity:** Depends on the number of sampled points (192 for fine model) and MLP sizes. The method uses two main MLPs and two smaller decoders/gates [S1].
*   **Strengths:** Handles both refraction and reflection in scenes with multiple transparent objects (e.g., glass cases) more accurately than methods assuming straight rays or only handling reflections [S1]. Separates direct and reflected light components [S1].
*   **Limitations:** Requires predetermined camera poses, which are difficult to acquire in scenes with glass objects (necessitating robotic arms) [S1]. More complex than standard NeRF due to multiple networks and sampling strategies [S1].
*   **When to use:** Scenes containing glass objects or multiple transparent surfaces where both refraction and reflection are significant [S1].
*   **When not to use:** Scenes without transparent objects, or where camera poses cannot be accurately predetermined [S1].

## Background
REF2-NeRF was proposed to address the challenge of modeling scenes with multiple glass objects, such as objects in a glass showcase, where existing NeRF-based methods struggled with multiple reflection and refraction effects [S1]. It builds on LB-NeRF, which simplified refraction as an offset, by introducing view-independent density and view-dependent offset fields to estimate refraction surfaces and offsets simultaneously [S1]. It also differs from MS-NeRF, which used multiple explicit spaces for mirrors, by using a single view-dependent feature field to handle reciprocal reflections from multiple glass plates [S1]. The method was implemented based on NeRFPytorch and evaluated on simulation datasets generated using Blender [S1].
