# Generative Occupancy Fields (GOF)


## Overview
Generative Occupancy Fields (GOF) is a 3D-aware image synthesis method that combines generative radiance fields with occupancy representations to learn compact object surfaces without impeding training convergence [S1, unofficial]. It solves the problem of diffused surfaces in methods like GRAFs and the sparse gradient convergence issues in direct occupancy networks by transitioning from cumulative volume rendering to surface-point rendering [S1, unofficial]. Unlike its sibling [Lifting 2D GAN to 3D Radiance Field](18126-lifting-2d-gan-to-3d-radiance-field.md) which may predict diffused surfaces, GOF concentrates rendering weights closely around object surfaces, resulting in compact and smooth geometry [S1, unofficial].

## How it works
GOF predicts alpha values (interpreted as occupancy) instead of volume densities to resolve shape-color ambiguity and enable surface-aware image synthesis [S1, unofficial]. The method locates the surface via root-finding on these alpha values and gradually shrinks the sampling region during training to enforce compactness [S1, unofficial].

### Inputs and Outputs
- **Inputs**: Latent code $z \sim \mathcal{N}(0, I)$, camera pose $\xi$ (origin $o$, direction $d$).
- **Outputs**: Rendered image color $C(r)$ for rays $r(t) = o + td$.

### Data Structures
- **Generator $g_\theta$**: A neural network (e.g., FiLMed-SIREN backbone) that takes position $x$ and latent code $z$ as input and outputs alpha value $\alpha_\theta(x, z) \in [0, 1]$ and color $c_\theta(x, d, z) \in \mathbb{R}^3$ [S1, unofficial].
- **Discriminator $D_{\theta_D}$**: A neural network that classifies images as real or fake [S1, unofficial].

### Parameters
- $N$: Number of rendering samples per ray. Typical value: 12 [S1, unofficial].
- $M$: Number of root-finding bins. Typical value: 12 [S1, unofficial].
- $m_s$: Number of secant iterations for surface refinement. Typical value: 3 [S1, unofficial].
- $\tau$: Threshold for root-finding. Typical value: 0.5 [S1, unofficial].
- $\Delta_{init}$: Initial sampling interval half-width. Set to $(t_f - t_n)/2$ [S1, unofficial].
- $\Delta_{min}$: Minimal sampling interval half-width. Not given in the sources.
- $\gamma$: Decay rate for shrinking interval. Not given in the sources.
- $\lambda_{normal}$: Weight for normal regularization. Not given in the sources.
- $\lambda_{opacity}$: Weight for opacity regularization. Not given in the sources.

### Steps

1. **Surface Location via Root-Finding**:
   - Sample $M$ evenly-spaced points $x_k$ partitioning the volume $[t_n, t_f]$ along the ray [S1, unofficial].
   - Query the generator for alpha values $\alpha_\theta(x_k, z)$ for all $k=1 \dots M$ [S1, unofficial].
   - Find the bin $k_S$ where the alpha value crosses the threshold $\tau$:
     $$ k_S = \arg\min_k (\alpha_\theta(x_k, z) < \tau \le \alpha_\theta(x_{k+1}, z)) $$
     [S1, unofficial]
   - Apply the secant method iteratively $m_s$ times within the bin $[x_{k_S}, x_{k_S+1}]$ to find the precise surface point $x_s$ and its distance $t_s$ [S1, unofficial].
   - Note: The $M$ points are used only for root-finding and do not require gradient computation [S1, unofficial].

2. **Shrinking Sampling Region**:
   - Initialize sampling interval $\Delta_{init} = (t_f - t_n)/2$ [S1, unofficial].
   - At training step $n$, compute the current interval half-width:
     $$ \Delta_n = \max(\Delta_{init} \exp(-\gamma n), \Delta_{min}) $$
     [S1, unofficial]
   - Sample $N$ points uniformly in the region $[t_s - \Delta_n, t_s + \Delta_n]$ using:
     $$ t_i \sim U\left[t_s - \Delta_n + \frac{2i-2}{N}\Delta_n, t_s - \Delta_n + \frac{2i}{N}\Delta_n\right] $$
     for $i=1 \dots N$ [S1, unofficial].
   - If the region exceeds $[t_n, t_f]$, shift it back to fit within bounds [S1, unofficial].

3. **Rendering**:
   - Compute the integrated color $\tilde{C}(r, z)$ using alpha composition:
     $$ \tilde{C}(r, z) = \sum_{i=1}^{N} \alpha_\theta(x_i, z) \left( \prod_{j<i} (1 - \alpha_\theta(x_j, z)) \right) c_\theta(x_i, d, z) $$
     [S1, unofficial]
   - Here, $\alpha_\theta(x_i, z)$ is the predicted alpha (occupancy) and $c_\theta(x_i, d, z)$ is the predicted color [S1, unofficial].

4. **Inference**:
   - Fetch truncated latent code $\hat{z}$ [S1, unofficial].
   - Locate surface $x_s$ using steps 1-2 with $\Delta_{min}$ [S1, unofficial].
   - Render using either:
     - Cumulative rendering with $N$ points in $[t_s - \Delta_{min}, t_s + \Delta_{min}]$ [S1, unofficial].
     - Single-point surface rendering with $N=1$ at $x_s$ for speed [S1, unofficial].

### Pseudocode

```python
import math
import random

def query_generator(theta, x, z):
    """Returns alpha in [0,1] and color in R^3 from generator g_theta."""
    alpha = theta(x, z)
    color = theta.color(x, z)
    return alpha, color

def secant_method(f, a, b, iterations):
    """Finds root of f(t) = 0 in [a, b] using secant method."""
    t_prev, t_curr = a, b
    f_prev, f_curr = f(t_prev), f(t_curr)
    for _ in range(iterations):
        if abs(f_curr - f_prev) < 1e-8:
            break
        t_next = t_curr - f_curr * (t_curr - t_prev) / (f_curr - f_prev)
        t_prev, t_curr = t_curr, t_next
        f_prev, f_curr = f_curr, f(t_curr)
    return t_curr

def compute_gan_loss(gen_logit, real_logit, lambda_grad=10.0):
    """Computes non-saturating GAN loss with gradient penalty.
    f(u) = -log(1 + exp(-u))
    Gradient penalty ||grad_D(I)||^2 is computed via automatic differentiation in practice."""
    def f(u):
        return -math.log(1 + math.exp(-u))
    return f(gen_logit) + f(-real_logit) + lambda_grad * 10.0

def compute_normal_loss(theta, x_s, z, eps=0.01):
    """Computes normal regularization loss: sum ||n(x_s) - n(x_s + eps*d)||^2.
    Normal n is typically the normalized gradient of alpha w.r.t position."""
    n_s = theta.gradient_alpha(x_s, z)
    n_s_eps = theta.gradient_alpha(x_s + eps * theta.direction, z)
    return sum((n_s[i] - n_s_eps[i])**2 for i in range(3))

def compute_opacity_loss(alphas):
    """Computes opacity regularization loss: 1/N sum (log(alpha) + log(1-alpha))."""
    return sum(math.log(a) + math.log(1 - a) for a in alphas) / len(alphas)

def render_gof(theta, z, camera_pose, tau=0.5, M=12, ms=3, N=12, delta_min=0.01, gamma=0.0, step=0):
    o, d = camera_pose
    tn, tf = 0.1, 10.0

    # 1. Surface Location via Root-Finding
    t_bins = [tn + i * (tf - tn) / M for i in range(M + 1)]
    alphas = [query_generator(theta, o + t * d, z)[0] for t in t_bins]

    k_S = -1
    for k in range(M):
        if alphas[k] < tau <= alphas[k+1]:
            k_S = k
            break

    if k_S == -1:
        t_s = (tn + tf) / 2
    else:
        def alpha_func(t):
            return query_generator(theta, o + t * d, z)[0]
        t_s = secant_method(alpha_func, t_bins[k_S], t_bins[k_S+1], ms)

    # 2. Shrinking Sampling Region
    delta_init = (tf - tn) / 2
    delta_n = max(delta_init * math.exp(-gamma * step), delta_min)

    t_start = t_s - delta_n
    t_end = t_s + delta_n
    t_start = max(tn, t_start)
    t_end = min(tf, t_end)
    if t_end <= t_start:
        t_end = t_start + delta_min

    # Sample N points uniformly in [t_s - delta_n, t_s + delta_n]
    t_samples = []
    for i in range(1, N + 1):
        lower = t_s - delta_n + (2 * i - 2) / N * delta_n
        upper = t_s - delta_n + (2 * i) / N * delta_n
        t_samples.append(random.uniform(lower, upper))

    # 3. Rendering
    color = [0.0, 0.0, 0.0]
    T = 1.0
    for t in t_samples:
        x = o + t * d
        alpha, c = query_generator(theta, x, z)
        contribution = [T * alpha * c[j] for j in range(3)]
        color = [color[j] + contribution[j] for j in range(3)]
        T *= (1 - alpha)
        if T < 1e-4:
            break
    return color

def compute_loss(theta, phi, z, camera_pose, real_image, tau=0.5, M=12, ms=3, N=12, delta_min=0.01, gamma=0.0, step=0):
    o, d = camera_pose
    tn, tf = 0.1, 10.0

    # Render generated image
    gen_image = render_gof(theta, z, camera_pose, tau, M, ms, N, delta_min, gamma, step)

    # GAN Loss
    gen_logit = phi(gen_image)
    real_logit = phi(real_image)
    gan_loss = compute_gan_loss(gen_logit, real_logit)

    # Locate surface for regularization
    t_bins = [tn + i * (tf - tn) / M for i in range(M + 1)]
    alphas = [query_generator(theta, o + t * d, z)[0] for t in t_bins]
    k_S = -1
    for k in range(M):
        if alphas[k] < tau <= alphas[k+1]:
            k_S = k
            break

    normal_loss = 0.0
    opacity_loss = 0.0
    if k_S != -1:
        def alpha_func(t):
            return query_generator(theta, o + t * d, z)[0]
        t_s = secant_method(alpha_func, t_bins[k_S], t_bins[k_S+1], ms)
        x_s = o + t_s * d
        normal_loss = compute_normal_loss(theta, x_s, z)

        delta_init = (tf - tn) / 2
        delta_n = max(delta_init * math.exp(-gamma * step), delta_min)
        t_start = max(tn, t_s - delta_n)
        t_end = min(tf, t_s + delta_n)
        t_samples = []
        for i in range(1, N + 1):
            lower = t_s - delta_n + (2 * i - 2) / N * delta_n
            upper = t_s - delta_n + (2 * i) / N * delta_n
            t_samples.append(random.uniform(lower, upper))
        render_alphas = [query_generator(theta, o + t * d, z)[0] for t in t_samples]
        opacity_loss = compute_opacity_loss(render_alphas)

    return gan_loss + 1.0 * normal_loss + 1.0 * opacity_loss
```

### Edge Cases and Pitfalls
- **Shape-Color Ambiguity**: Direct training of generative radiance fields fails to maintain surface compactness because small perturbations on surfaces still lead to realistic RGB images, fooling the discriminator [S1, unofficial]. GOF mitigates this by reinterpreting alpha as occupancy and using root-finding [S1, unofficial].
- **Convergence Issues**: Directly applying occupancy representations to generative models causes severe convergence problems due to sparse gradients located only on object surfaces [S1, unofficial]. GOF avoids this by starting with cumulative rendering (radiance field) and gradually shrinking the sampling region [S1, unofficial].
- **Density Thresholding**: Predicted densities in generative radiance fields range from 0 to 50, making it hard to determine an effective threshold for surface location [S1, unofficial]. GOF uses alpha values which are naturally bounded in $[0, 1]$ [S1, unofficial].
- **Surface Not Found**: If the root-finding bin is not found (e.g., all alphas < $\tau$ or all > $\tau$), the surface location step fails. The pseudocode includes a fallback to the midpoint [G].
- **Inference Speed**: GOF requires $M + m_s + N$ queries for standard rendering, or $M + m_s + 1$ for single-point surface rendering [S1, unofficial]. Baselines require $2N$ queries [S1, unofficial].

## Operating characteristics
- **Time Complexity**: GOF requires $M + m_s + N$ queries for standard rendering, or $M + m_s + 1$ for single-point surface rendering [S1, unofficial]. Baselines require $2N$ queries [S1, unofficial].
- **Memory Complexity**: Not given in the sources.
- **Performance**: GOF significantly outperforms baseline methods on the MAD (Mean Angle Deviation) metric, which focuses on surface compactness, and is comparable on SIDE (Scale-invariant Depth Error) [S1, unofficial].
- **Strengths**: Compact and smooth surfaces; efficient rendering with single-point surface query; resolves shape-color ambiguity.
- **Limitations**: May over-smooth furry or complex textures when using single-point rendering; suitable for solid objects with a single surface [S1, unofficial].
- **When to use**: 3D-aware image synthesis where compact surface representation is desired, especially for solid objects like faces or animals [S1, unofficial].
- **When not to use**: Scenes with complex, multi-layered, or translucent objects where a single surface is insufficient [S1, unofficial].

## Background
GOF was proposed by Xudong Xu, Xingang Pan, Dahua Lin, and Bo Dai from CUHK - SenseTime Joint Lab, The Chinese University of Hong Kong, Max Planck Institute for Informatics, and Nanyang Technological University [S1, unofficial]. It was published on arXiv on November 1, 2021 [S1, unofficial]. The method builds on the principles of generative radiance fields and occupancy networks, aiming to combine their respective strengths [S1, unofficial]. It is used on datasets such as CelebA, BFM, and Cats for 3D-aware image synthesis [S1, unofficial].
