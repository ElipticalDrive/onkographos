# Forward Warping for Novel View Synthesis

Also called: Canonical Field Forward Warping, Forward Flow

## Overview
Forward Warping for Novel View Synthesis is a method for rendering dynamic scenes by modeling a static scene at a canonical time step and forward warping the entire canonical radiance field to other time steps [S1]. It addresses the many-to-one and one-to-many mapping difficulties inherent in dynamic scene reconstruction by employing differentiable forward warping with average splatting and an inpaint network [S1]. Unlike backward flow-based methods such as NDVG, this approach leverages a canonical representation that simplifies the learning of trajectories and geometry, achieving state-of-the-art performance on public datasets, particularly for canonical frames [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   A set of multi-view images of a dynamic scene at various time steps $t$.
*   Camera poses for each input image.
*   A canonical time step $t_{can}$ (first frame for D-NeRF, middle frame for HyperNeRF) [S1].

**Outputs:**
*   A rendered RGB image for a novel view at a target time step $t$ and camera pose.
*   A learned canonical radiance field and deformation fields.

### Data Structures
The method relies on several voxel grids and neural networks. All voxel grids are 3D structures indexed by spatial coordinates.

1.  **Canonical Radiance Feature Grid ($VRf$):** Voxel grid containing radiance features. Feature dimension is 12 [S1].
2.  **Canonical Coordinate Grid ($VrCan$):** Voxel grid containing the spatial coordinate of each voxel [S1].
3.  **Canonical Density Grid ($V\sigma_{Can}$):** Voxel grid containing canonical density values [S1].
4.  **Canonical Color Feature Grid ($Vcf_{Can}$):** Voxel grid containing canonical color features. Dimension is 3 or 12 depending on the training stage [S1].
5.  **Canonical Deformation Feature Grid ($VDf_{Can}$):** Voxel grid containing canonical deformation features. Dimension is 0 for D-NeRF, 12 for HyperNeRF [S1].
6.  **Trajectory Grid ($VT_t$):** Voxel grid containing DCT (Discrete Cosine Transform) parameters for each voxel's trajectory [S1].
7.  **Deformation Flow Grid ($Vflow$):** Voxel grid containing the deformation flow of each voxel from the canonical position to time $t$ [S1].
8.  **Warped Radiance Field ($VR_t$):** The radiance field at time $t$ warped from the canonical field [S1].
9.  **Inpainted Radiance Field ($VR_t^{Inp}$):** The radiance field at time $t$ after processing by the inpaint network [S1].
10. **Upsampled Radiance Field ($VR_t^{Up}$):** The upsampled radiance field at time $t$ [S1].

### Neural Networks
Four networks define the model parameters:

1.  **Canonical Radiance Network ($F_{\theta_1}$):**
    *   **Structure:** 3-layer MLP, width 128, ReLU activation [S1].
    *   **Input:** Radiance feature sampled from $VRf$ (dim 12) and embedded position (dim 33) [S1].
    *   **Output:** Density (dim 1) and color feature (dim 3 or 12) [S1].

2.  **Canonical Deformation Network ($F_{\theta_2}$):**
    *   **Structure:** 4-layer MLP, width 64 [S1].
    *   **Input:** Deformation feature (dim 0 for D-NeRF, 12 for HyperNeRF) and embedded position (dim 33) [S1].
    *   **Output:** Trajectory parameters (DCT coefficients) [S1].
    *   **Note:** Number of DCT bases is 15 for D-NeRF, 25 for HyperNeRF [S1].

3.  **View Dependent Color Network ($F_{\theta_4}$):**
    *   **Structure:** 2-layer MLP, width 64 [S1].
    *   **Input:** Embedded view direction (dim 27) and color feature (dim 12) [S1].
    *   **Output:** RGB color (dim 3) [S1].

4.  **Inpaint Network ($F_{\theta_3}$):**
    *   **Structure:** UNet with 4 encode layers and 3 decode layers, plus an upsample layer [S1].
    *   **Encode Layer:** One max pooling layer, two convolution layers (Instance Norm + Conv + ReLU) [S1].
    *   **Decode Layer:** One up-sample interpolation layer, two convolution layers (Instance Norm + Conv + ReLU) [S1].
    *   **Upsample Layer:** Same structure as a decode layer [S1].
    *   **Input/Output:** Operates on the warped radiance field features to fill holes and refine details [S1].

### Algorithm Steps

#### 1. Canonical Field Initialization
The canonical field is initialized using a coarse-to-fine strategy.
*   **Coarse Stage:**
    *   Voxel grid resolution: $6^3$ [S1].
    *   Inpaint scale: 1.5 [S1].
    *   Iterations: 20,000 [S1].
    *   Purpose: Learn proxy geometry to calculate the bounding box for the fine stage. The inpaint network is **not** used during this stage [S1].
*   **Fine Stage:**
    *   Voxel grid resolution: $8^3$ for D-NeRF, $7^3$ for HyperNeRF [S1].
    *   Inpaint scale: 2.0 [S1].
    *   Iterations: 100,000 [S1].
    *   Progressive Training: Start with 10 images closest to the canonical step. Add one image with the closest time step every 60 iterations [S1].

#### 2. Forward Warping Pipeline
For a target time $t$ and a ray $\mathbf{r}$:

1.  **Sample Canonical Points:** Sample points $\mathbf{x}_{can}$ along the ray in the canonical space.
2.  **Query Canonical Features:**
    *   Query $VRf$, $V\sigma_{Can}$, $Vcf_{Can}$, and $VDf_{Can}$ at $\mathbf{x}_{can}$ using trilinear interpolation.
    *   Compute density $\sigma_{can}$ and color feature $\mathbf{c}_{can}$ using $F_{\theta_1}$ [S1].
3.  **Compute Deformation:**
    *   Query $VDf_{Can}$ and $VT_t$ at $\mathbf{x}_{can}$.
    *   Use $F_{\theta_2}$ to predict trajectory parameters.
    *   Compute the deformation flow $\mathbf{v}_{flow}$ from canonical to time $t$ [S1].
    *   Compute the warped position $\mathbf{x}_t = \mathbf{x}_{can} + \mathbf{v}_{flow}$ [S1].
4.  **Average Splatting:**
    *   Instead of softmax splatting, use average splatting to map the canonical features to the warped positions $\mathbf{x}_t$ [S1].
    *   This produces the **Warped Radiance Field** $VR_t$. Average splatting is chosen because softmax splatting with predicted weights showed no obvious improvement and introduced unnecessary complexity [S1].
5.  **Inpainting:**
    *   Pass $VR_t$ through the Inpaint Network $F_{\theta_3}$ to produce the **Inpainted Radiance Field** $VR_t^{Inp}$ [S1].
    *   This step addresses holes and artifacts caused by the forward warping (many-to-one/one-to-many mappings) [S1].
6.  **Upsampling:**
    *   Upsample $VR_t^{Inp}$ to produce the **Upsampled Radiance Field** $VR_t^{Up}$ [S1].
7.  **Rendering:**
    *   Render color from $VR_t^{Inp}$ and $VR_t^{Up}$ using standard volume rendering [S1].
    *   Let $\mathbf{C}_{Inp}(\mathbf{r})$ and $\mathbf{C}_{Up}(\mathbf{r})$ be the rendered colors [S1].

#### 3. Loss Functions
The total loss $\mathcal{L}$ is a weighted sum of several components:

$$ \mathcal{L} = \mathcal{L}_{photo} + w_1\mathcal{L}_{ptc} + w_2\mathcal{L}_{bg} + w_3\mathcal{L}_{flow} + w_4\mathcal{L}_{vdiff} + w_5\mathcal{L}_{tv}(\mathbf{V}_{\sigma}^{\text{Can}}) + w_6\mathcal{L}_{tv}(\mathbf{V}_{\text{flow}}^t) + w_7\mathcal{L}_{tv}(\mathbf{D}) $$

*   **Point-wise Color Loss ($\mathcal{L}_{ptc}$):** Supervises the color of sampled points weighted by their accumulation.
    $$ \mathcal{L}_{ptc} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Up}}(\mathbf{r})) $$
    $$ \mathcal{L}(\mathbf{C}(\mathbf{r})) = \frac{1}{K} \sum_{k=1}^{K} A_{\text{accum}}(k) \|\mathbf{c}(w_k) - \mathbf{C}_{\text{gt}}(\mathbf{r})\|_2^2 $$
    $$ A_{\text{accum}}(k) = T(w_k) \, \sigma(w_k) \delta_k $$
    Where $T(w_k)$ is the transmittance, $\sigma(w_k)$ is the density, and $\delta_k$ is the distance between samples [S1].

*   **Background Entropy Loss ($\mathcal{L}_{bg}$):** Encourages densities to concentrate on foreground or background.
    $$ \mathcal{L}_{bg} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Up}}(\mathbf{r})) $$
    $$ \mathcal{L}(\mathbf{A}(\mathbf{r})) = -\frac{1}{K-1} \sum_{k=1}^{K-1} [ A_{\text{accum}}(k)\log(A_{\text{accum}}(k)) + (1-A_{\text{accum}}(k))\log(1-A_{\text{accum}}(k)) ] $$
    [S1]

*   **Total Variation Losses ($\mathcal{L}_{tv}$):** Applied to canonical density, flow, and deformation fields to improve visual quality [S1].

*   **Other Losses:** $\mathcal{L}_{flow}$ and $\mathcal{L}_{vdiff}$ are used in the fine stage [S1].

#### 4. Hyperparameters
*   **Learning Rate:** $1e-1$ for voxel grids, $1e-3$ for networks [S1].
*   **Optimizer:** Adam [S1].
*   **Weights (Coarse Stage):** $w_1=1e-1, w_2=1e-2, w_3=1e-5, w_4=0., w_5=1e-6, w_6=1e-3, w_7=1e-1$ [S1].
*   **Weights (Fine Stage):** $w_1=1e-2, w_2=1e-3, w_3=1e-5, w_4=1e-5, w_5=1e-6, w_6=1e-3, w_7=1e-1$ [S1].

### Edge Cases and Pitfalls
*   **Memory Consumption:** The method is memory-intensive, especially for real scenes [S1].
*   **Training Speed:** Training is slow, taking approximately one day per scene on a GeForce RTX 3090 [S1].
*   **Coarse Stage Importance:** Removing the coarse stage causes significant performance drops because the voxel grid covers a larger space without proxy geometry filtering [S1].
*   **Inpaint Network Necessity:** The inpaint network is critical; ablation shows significant performance reduction without it (e.g., Hell Warrior PSNR drops from 27.71 to 27.15) [S1].
*   **Canonical Time Selection:** Setting the canonical time to the middle frame (for HyperNeRF) improves performance compared to the first frame, as the geometry is closer to other time steps [S1].

## Operating characteristics

### Time and Memory Complexity
*   **Memory:** High memory consumption, particularly for real-world scenes [S1].
*   **Training Time:** Approximately one day per scene on a GeForce RTX 3090 GPU [S1].
*   **Rendering Speed:** 7 seconds per image for D-NeRF dataset, 15 seconds per image for HyperNeRF dataset [S1].

### Measured Performance
*   **Model Size:** 260M parameters for D-NeRF, 440M for HyperNeRF [S1].
*   **Quality:** Achieves state-of-the-art performance on public datasets, especially for canonical frames [S1].
*   **Comparison:** Outperforms backward flow-based methods like NDVG despite using similar regularization terms [S1].

### Strengths and Limitations
*   **Strengths:**
    *   Effective handling of many-to-one and one-to-many mappings via forward warping and inpainting [S1].
    *   High quality on canonical frames [S1].
    *   Simple splatting mechanism (average splatting) is sufficient and less complex than softmax splatting [S1].
*   **Limitations:**
    *   High memory usage [S1].
    *   Slow training speed [S1].
    *   Rendering speed is slower compared to some other NeRF variants [S1].

### When to Use
*   Use when high-quality novel view synthesis for dynamic scenes is required, particularly for canonical frames.
*   Suitable when computational resources (memory and time) are available for training.
*   Prefer over backward flow methods if the forward warping design aligns better with the scene dynamics.

### When Not to Use
*   Avoid if real-time rendering is required.
*   Avoid if memory constraints are tight.
*   Avoid if training time is a critical bottleneck.

## Background

### Origin
Forward Warping for Novel View Synthesis was proposed in the paper "Forward Flow for Novel View Synthesis of Dynamic Scenes" [S1]. The method builds on the concept of canonical representations for dynamic scenes, similar to D-NeRF and HyperNeRF, but introduces a forward warping pipeline with average splatting and an inpaint network to handle the complexities of dynamic geometry [S1].

### History and Development
The method was developed to address the limitations of existing dynamic NeRF approaches, particularly those relying on backward flow or explicit deformation fields that struggle with occlusions and complex motions [S1]. By forward warping a static canonical field, the method simplifies the learning process and improves rendering quality [S1].

### Applications
*   Novel view synthesis for dynamic scenes.
*   Animation and video editing.
*   Virtual reality and augmented reality applications involving dynamic content.
