# Neural Deformable Anchor (NeuDA)


## Overview
NeuDA is a neural implicit representation for high-fidelity surface reconstruction that replaces learnable feature vectors at voxel vertices with optimized 3D positions (anchors) to adaptively encode local geometry [S1]. It solves the limitation of standard voxel grids where uniformly distributed features fail to capture small structures with complicated topologies [S1]. Unlike Instant-NGP which uses multi-resolution hash encoding and may suffer from hash collision, NeuDA uses hierarchical voxel grids with deformable anchors [S1].

## How it works
**Inputs and Outputs**
*   **Input:** Camera parameters (origin $\mathbf{o}$, direction $\mathbf{d}$), hierarchical voxel grid structure $G$.
*   **Output:** Rendered color $\hat{C}$ for the pixel.

**Data Structures**
*   **Hierarchical Anchor Grid ($G$):** A set of levels. At each level $l$, the grid consists of vertices.
*   **Deformable Anchor ($\psi(G)$):** A set of parameters $\{ \mathbf{p}_v, \Delta \mathbf{p}_v \mid v \in G \}$, where $\mathbf{p}_v$ is the base 3D position of the anchor and $\Delta \mathbf{p}_v$ is the learnable offset [S1]. Initially, anchors are uniformly distributed at voxel vertices [S1].
*   **SDF Network ($F$):** A 4-layer Multi-Layer Perceptron (MLP) taking geometric features as input and outputting the SDF value $f(\mathbf{x})$ and geometric feature vector $\mathbf{z}(\mathbf{x}) \in \mathbb{R}^{256}$ [S1].
*   **Color Network ($M$):** A 4-layer MLP taking view direction $\mathbf{d}$, normal $\mathbf{n}$, and geometric feature $\hat{\mathbf{z}}$ as input, outputting color $\mathbf{c} \in \mathbb{R}^3$ [S1].

**Frequency Encoding**
NeuDA employs a Hierarchical Positional Encoding (HPE) policy. For a coordinate $\mathbf{p}_l$ at level $l$, the encoding function $\gamma$ is defined as [S1]:
$$
\gamma(\mathbf{p}_l) = (\sin(2^l \pi \mathbf{p}_l), \cos(2^l \pi \mathbf{p}_l))
$$
The function $\gamma$ is applied to the three coordinate values in $\mathbf{p}_l$ individually, returning a 6-dimensional embedding per anchor [S1].

**Interpolation of Features**
To compute the input feature $\phi(\mathbf{p}, \psi(G))$ for a sample point $\mathbf{p}$, the method interpolates the frequency encoding of the eight adjacent anchors [S1]:
$$
\phi(\mathbf{p}, \psi(G)) = \sum_{v \in \mathcal{V}} w(\mathbf{p}_v) \cdot \gamma(\mathbf{p}_v + \Delta \mathbf{p}_v)
$$
where $\mathcal{V}$ is the set of 8 voxel vertices surrounding the sample point [S1].

**Weight Calculation**
The weight $w(\mathbf{p}_n)$ measures the contribution of different anchors using cosine similarity [S1]:
$$
w(\mathbf{p}_n) = \frac{\hat{w}(\mathbf{p}_n)}{\sum_n \hat{w}(\mathbf{p}_n)}, \quad \hat{w}(\mathbf{p}_n) = \frac{\mathbf{p} \cdot \mathbf{p}_n}{\|\mathbf{p}\| \|\mathbf{p}_n\|}
$$
where $\mathbf{p}_n$ is the position of the $n$-th anchor [S1].

**SDF and Opacity**
The SDF network $F$ predicts the signed distance $f(\mathbf{p}(t))$ at sample point $\mathbf{p}(t)$ along the ray [S1]. Opacity $\alpha_i$ is derived from the SDF values at consecutive sample points $t_i$ and $t_{i+1}$ using a trainable parameter $s$ [S1]:
$$
\alpha_i = \max\left( \frac{\Phi_s(f(\mathbf{p}(t_i))) - \Phi_s(f(\mathbf{p}(t_{i+1})))}{\Phi_s(f(\mathbf{p}(t_i)))}, 0 \right)
$$
where $\Phi_s(x)$ is defined as [S1]:
$$
\Phi_s(x) = (1 + e^{-sx})^{-1}
$$
As optimization converges, $1/s$ approaches zero [S1].

**Rendering**
The rendered color $\hat{C}$ is accumulated along the ray with $N$ discrete sampled points [S1]:
$$
\hat{C} = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i
$$
where $T_i = \prod_{j=1}^{i-1}(1-\alpha_j)$ is the accumulated transmittance and $\mathbf{c}_i$ is the color predicted by network $M$ [S1].

import math
import numpy as np

def hierarchical_positional_encoding(p_l, level):
    """
    Applies frequency encoding to coordinate p_l at a specific grid level.
    p_l: numpy array of shape (3,)
    level: int, the grid level index
    Returns: numpy array of shape (6,)
    """
    freq = 2**level * math.pi
    sin_vals = np.sin(freq * p_l)
    cos_vals = np.cos(freq * p_l)
    return np.concatenate([sin_vals, cos_vals])

def compute_anchor_weights(p, anchor_positions):
    """
    Computes normalized cosine similarity weights for 8 anchors.
    p: numpy array of shape (3,), the sample point
    anchor_positions: numpy array of shape (8, 3), positions of the 8 anchors
    Returns: numpy array of shape (8,), normalized weights
    """
    # Calculate raw weights (cosine similarity numerator)
    # Note: The source defines w(p_n) based on p and p_n. 
    # Assuming p is the sample point and p_n is the anchor position.
    # The source formula: w_hat = (p . p_n) / (||p|| ||p_n||)
    
    p_norm = np.linalg.norm(p)
    if p_norm == 0:
        return np.ones(8) / 8.0
        
    raw_weights = np.zeros(8)
    for i in range(8):
        p_n = anchor_positions[i]
        p_n_norm = np.linalg.norm(p_n)
        if p_n_norm == 0:
            raw_weights[i] = 0
        else:
            raw_weights[i] = np.dot(p, p_n) / (p_norm * p_n_norm)
            
    # Normalize
    sum_weights = np.sum(raw_weights)
    if sum_weights == 0:
        return np.ones(8) / 8.0
    return raw_weights / sum_weights

**Edge Cases and Pitfalls**
*   **Hash Collision:** Unlike Instant-NGP, NeuDA avoids hash collision by using hierarchical voxel grids [S1].
*   **Uniform Distribution Failure:** Standard voxel grids store uniformly distributed features which may fail to capture small structures with complicated topologies; NeuDA solves this by optimizing anchor positions [S1].
*   **Precision:** The parameter $s$ in the opacity function is trainable, and $1/s$ approaches zero as optimization converges, which may require careful initialization or gradient scaling to avoid numerical instability [S1].

## Operating characteristics
*   **Complexity:** Time and memory complexity are not explicitly given in the sources. However, it uses a 4-layer MLP for the SDF network, which is shallower than NeuS's 8-layer MLP, suggesting potentially lower computational cost per query [S1].
*   **Performance:** Experiments on DTU and BlendedMVS show NeuDA is superior in recovering high-quality geometry with fine-grained details compared to baselines and SOTA methods [S1].
*   **Strengths:** Improves flexibility of voxel grid representation; spatial context in 3D space is better exploited; anchors adaptively move from corners to vicinity of abrupt geometry-changing areas [S1].
*   **Limitations:** Not given in the sources.

## Background
NeuDA was introduced by Bowen Cai, Jinchi Huang, Rongfei Jia, Chengfei Lv, and Huan Fu from Alibaba Group. It was published on arXiv on March 26, 2023 (arXiv:2303.02375v2) [S1]. The method builds on the principles of differentiable volume rendering and SDF-based surface reconstruction, specifically addressing the limitations of previous works like IDR and NeuS which overlook spatial context in 3D space when predicting and rendering the surface [S1].
