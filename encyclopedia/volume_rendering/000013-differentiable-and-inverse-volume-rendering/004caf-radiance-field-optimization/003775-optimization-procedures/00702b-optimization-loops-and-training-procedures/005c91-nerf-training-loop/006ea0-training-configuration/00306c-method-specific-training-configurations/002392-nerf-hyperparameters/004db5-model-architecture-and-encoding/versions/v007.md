# Model Architecture and Encoding

Also called: NeRF MLP Configuration, Radiance Field Network Structure, Feature Encoding Schemes

## Overview
Model Architecture and Encoding defines the neural network topology and input feature transformation strategies used to map 3D spatial coordinates and viewing directions to volume density and color. It solves the problem of representing continuous 3D radiance fields with finite parameters, balancing reconstruction fidelity, training stability, and computational efficiency. It differs from sibling methods like [NeRF Initialization Strategies](8674-nerf-initialization-strategies.md) (which focus on parameter starting values) and [Model Architecture Modifications](11313-model-architecture-modifications.md) (which focus on high-level structural changes like multi-branching) by specifying the exact layer dimensions, activation functions, skip connections, and encoding functions (e.g., positional encoding, hash grids) that constitute the core decoder.

## Shared principles
The standard NeRF architecture [S1, S2, S3] consists of two Multi-Layer Perceptrons (MLPs): a density network and a color network, separated by a bottleneck feature vector.

**Input Encoding:**
Spatial coordinates $\mathbf{x} \in \mathbb{R}^3$ and viewing directions $\mathbf{d} \in \mathbb{R}^3$ are transformed into higher-dimensional representations before entering the MLPs.
*   **Positional Encoding (PE):** The standard approach uses sinusoidal functions [S1, S3]. For a coordinate $x$, the encoding $\gamma(x)$ is a vector of sines and cosines at frequencies $2^l \pi$:
    $$ \gamma(x) = [\sin(2^0 \pi x), \cos(2^0 \pi x), \dots, \sin(2^{L-1} \pi x), \cos(2^{L-1} \pi x)] $$
    where $L$ is the number of frequencies.
*   **Directional Encoding:** Viewing directions are typically encoded using Spherical Harmonics (SH) [S1, S2, S4] or lower-degree positional encoding [S3].

**Network Topology:**
*   **Density Network:** Takes the encoded spatial coordinates $\gamma(\mathbf{x})$ and outputs a raw density value $\sigma_{\text{raw}}$. It typically consists of $D$ hidden layers of width $W$.
*   **Bottleneck:** The output of the density network (excluding the final density layer) serves as a feature vector $\mathbf{e}$ passed to the color network.
*   **Color Network:** Takes the feature vector $\mathbf{e}$ and the encoded viewing direction $\gamma(\mathbf{d})$ (or SH coefficients) to predict the color $\mathbf{c}$.

**Skip Connections:**
To preserve low-frequency information and aid gradient flow, skip connections are added from the input $\mathbf{x}$ to intermediate layers of the density network [S1, S3]. Specifically, at layer $i$ where $i \pmod{\text{skip\_layer}} == 0$, the input $\mathbf{x}$ is concatenated with the hidden state.

**Activations and Biases:**
*   Hidden layers use ReLU activation [S1, S3].
*   The density network applies a bias term to the raw density before the final activation (often ReLU or Softplus) to prevent density from collapsing to zero [S1].
*   The color network may apply padding to the output range (e.g., $[0, 1]$) to ensure valid RGB values [S1].

**Alternative Encodings:**
While the MLP is standard, the encoding mechanism varies significantly across variants:
*   **Hash Encoding:** Uses multi-resolution hash tables to store features, replacing the dense positional encoding input with sparse lookups [S1, S4, S5].
*   **Triplane Representation:** Projects 3D coordinates onto three 2D planes ($xy, xz, yz$) and aggregates features, often used in generative models [S2].
*   **Integrated Positional Encoding (IPE):** Integrates the positional encoding function over the volume of a conical frustum to handle aliasing, replacing point-wise PE [S1].

## Subtopics

### [Depth-Guided NeRF Training Configuration](11916-depth-guided-nerf-training-configuration.md)
This configuration modifies the standard NeRF architecture by adding dropout regularization to the feature encoding network and integrating a weighted depth consistency loss [11916-depth-guided-nerf-training-configuration.md]. It differs from standard NeRF by explicitly supervising geometry via depth priors, distinguishing it from [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md) which uses semantic constraints, or [Binary Radiance Fields](13622-binary-radiance-fields.md) which constrain parameters to binary values. It uses a dropout probability of 0.1 after each of the first eight fully connected ReLU layers of the density network [11916-depth-guided-nerf-training-configuration.md].

### [CLIPNeRF Training Configuration](12073-clipnerf-training-configuration.md)
CLIPNeRF is a text-driven stylization method that optimizes the radiance field to match a target text prompt in the CLIP embedding space. It distinguishes itself from standard NeRF training by replacing or augmenting the photometric reconstruction loss with a directional CLIP loss, which enforces semantic alignment between rendered views and text embeddings. Unlike methods that rely solely on pixel-wise reconstruction, CLIPNeRF focuses on the trajectory of stylization in the embedding space, though it faces challenges regarding mode collapse and insufficient stylization magnitude. It freezes the density network parameters and optimizes only the color network [12073-clipnerf-training-configuration.md].

### [Binary Radiance Fields](13622-binary-radiance-fields.md)
Binary Radiance Fields (BiRF) is a storage-efficient radiance field representation that constrains feature encoding parameters in multi-resolution grids to binary values $\{-1, +1\}$, reducing storage overhead to approximately 0.5 MB for standard scenes. Unlike post-processing compression methods such as PlenOctrees or Re:NeRF, which require additional optimization steps and are bounded by pre-trained model performance, BiRF performs binarization during training, achieving superior reconstruction quality with significantly smaller storage footprints than state-of-the-art efficient models like Instant-NGP or TensoRF. It uses a 3D voxel grid and three 2D plane grids with linear interpolation, and applies the Straight-Through Estimator (STE) for gradient propagation through the sign function [13622-binary-radiance-fields.md].

### [Mip-NeRF 360 MLP Architecture](14098-mip-nerf-360-mlp-architecture.md)
The Mip-NeRF 360 MLP architecture is a specific configuration of the radiance field model that replaces standard positional encoding with **Integrated Positional Encoding (IPE)** to handle aliasing and frequency mismatch during volume rendering. It solves the problem where high-frequency scene details are undersampled by the camera rays, causing flickering and artifacts in the rendered output. Unlike the original NeRF architecture which uses deterministic sinusoidal encoding, this method integrates the encoding function over the conical frustum of each ray segment, effectively low-pass filtering the input features. It is distinguished by its support for advanced material properties such as specular tinting, roughness prediction, and reflection directions, making it suitable for complex, unbounded 360-degree scenes.

### SUDS
SUDS is a 4D radiance field representation designed for large-scale dynamic urban scenes that factorizes the scene into three separate hash table data structures to efficiently encode static, dynamic, and far-field radiance fields [S1]. It solves the problem of scaling neural reconstruction to city-level footprints with tens of thousands of objects and ego-motion by using unlabeled target signals (RGB, sparse LiDAR, 2D descriptors, 2D optical flow) for supervision, avoiding the need for 3D bounding boxes or panoptic labels [S1]. Unlike sibling methods that rely on per-object NeRFs or supervised annotations, SUDS uses a multi-branch hash encoding to disentangle static background, dynamic objects, and lighting variations across multiple videos [S1].

### CCNeRF
CCNeRF is a neural field representation that enables efficient compression and composition of 3D scenes by modeling the radiance field as a hybrid tensor rank decomposition without using neural networks for rendering [S1]. Unlike NeRF variants that rely on a shared MLP renderer (e.g., [NSVF](11916-depth-guided-nerf-training-configuration.md) or [TensoRF](13550-model-architecture-and-encoding.md)), CCNeRF allows arbitrary composition of different models by concatenating rank components and dynamic adjustment of model size via rank truncation, achieving near-optimal low-rank approximation without retraining [S1]. It avoids MLPs in the rendering path to preserve low-rank approximation properties [15008-ccnerf.md].

### [Rip-NeRF](15532-rip-nerf.md)
Rip-NeRF is a radiance field method that renders high-fidelity, anti-aliased images by combining cone casting with an anisotropic 3D Gaussian characterization and a novel "Ripmap Encoding" based on Platonic Solid Projection. It solves the aliasing artifacts inherent in point-based sampling by treating conical frustums as 2D Gaussians projected onto the faces of a Platonic solid, allowing for efficient area-sampling. Unlike Zip-NeRF, which uses a multi-sampling mechanism that is effective but computationally inefficient and memory-heavy, Rip-NeRF achieves comparable or superior quality with significantly faster training, smaller model size, and higher rendering speed.

### [UE4-NeRF](15539-ue4-nerf.md)
UE4-NeRF is a neural rendering system designed for the real-time interactive rendering of large-scale 3D scenes by partitioning the environment into sub-NeRFs represented by textured polygonal meshes. Unlike standard differentiable volume rendering which renders rays directly, UE4-NeRF extracts a mesh representation from the neural field and integrates it into the Unreal Engine 4 (UE4) rasterization pipeline. It sets itself apart from sibling methods like [Mobile-NeRF](13622-mobile-nerf.md) and [Mega-NeRF](14098-mega-nerf.md) by utilizing regular octahedra for mesh initialization to handle tilted surfaces and multi-resolution hash encoding for training acceleration, achieving real-time frame rates at 4K resolution.

### [Generative Occupancy Fields (GOF)](15773-generative-occupancy-fields-gof.md)
Generative Occupancy Fields (GOF) is a 3D-aware image synthesis method that learns compact object surfaces by transitioning from cumulative volume rendering to surface-point rendering. It solves the shape-color ambiguity and diffused surface artifacts inherent in standard generative radiance fields (like pi-GAN) and the sparse gradient convergence issues of direct occupancy networks by reinterpreting alpha values as occupancy probabilities and using root-finding to locate surfaces. Unlike its siblings which often rely on density thresholding or complex hierarchical sampling, GOF explicitly predicts alpha values to enable a deterministic surface location mechanism that shrinks the sampling region during training.

### Triplane NeRF with Diffusion Prior
- [S1] The framework uses a triplane NeRF representation where scene codes are optimized jointly with a diffusion prior to handle sparse-view data and ensure end-to-end coherence.
- [S1] Prediction Format: v-parameterization v̂ϕ(x(t), t) from [43], such that x̂ = α(t)x(t) − σ(t)v̂.
- [S1] Weighting Function w(t): Uses SNR-based weighting w(t) = (α(t)/σ(t))^2ω from Eq. (5), instead of LSGM mechanisms.
- [S1] Scene code xi: Shape ℝ^(3×6×128×128), representing a triplane NeRF representation.
- [S1] Denoising Network Input/Output: Noisy and denoised triplane features, with channels of all three planes stacked together.
- [S1] Denoising Network Architecture: U-Net with 122M parameters.

### EG3D Triplane Representation
- [S2] Render feature image I_f in R^{32x128x128} and raw RGB image I_128 in R^{3x128x128} by accumulating points along rays and performing volume rendering.
- [S2] Extract dense depth map I_D in R^{128x128} from the volume rendering.
- [S2] Feed I_f and I_128 into a 2D super-resolution network to yield final output I_512 in R^{3x512x512}.
- [S2] SuperRes(I_f, I_128) = I_512
- [S2] Image resolution: 512x512 for input images and final output.
- [S2] Triplane representation T is a tensor in R^{256x256x96}, corresponding to 3 axis-aligned planes (xy, xz, yz), each with 32 channels and resolution 256x256.
- [S2] Rendering speed: 42 fps on RTX 3090.

### NeRF-W Hyperparameter Configuration
- [S3] Base MLP: 8 layers of 512 hidden units.
- [S3] Static and Transient/Uncertainty MLPs: 4 layers of 128 hidden units each.
- [S3] Positional encoding frequencies: 15 for position, 4 for viewing direction.
- [S3] Sampling points: 512 per ray per model (coarse and fine) during training (1024 total), doubled to 2048 during evaluation.
- [S3] Appearance embedding dimension $n(a) = 48$.
- [S3] Transient object embedding dimension $n(\tau) = 16$.
- [S3] L1 regularizer multiplier $\lambda_u = 0.01$.
- [S3] Minimum importance threshold $\beta_{min} = 0.03$.
- [S3] Optimizer: Adam, batch size 2048, initial learning rate 0.001, decaying ten-fold every 150,000 iterations, over 300,000 iterations total.
- [S3] Hyperparameters were optimized for the Brandenburg Gate scene of the Phototourism dataset and reused for remaining scenes.

### Explicit Mesh Reconstruction from Neural Fields
- [S4] An algorithm to extract an explicit 3D mesh representation from the implicit neural radiance field learned by CodeNeRF, allowing for 3D reconstruction from a single input image.
- [S4] Feed the center coordinates of a 256^3 voxel grid to the CodeNeRF MLP to obtain volume density values σ.
- [S4] Apply the Marching Cubes algorithm to the volume density values σ to find mesh vertices.
- [S4] Cast rays along the vertex normals of the generated mesh to associate colors to the vertices.

### Efficient EndoNeRF scene representation
- [S5] A voxel-grids-based scene representation that replaces coordinate-based MLPs with explicit density and feature volume grids to accelerate optimization, combined with a canonical field and time-dependent deformation field for dynamic surgical scenes.
- [S5] The dynamic scene at time $t$ is modeled by warping a canonical radiance field (represented by $\mathbf{V}_\sigma$ and $\mathbf{V}_a$) with a time-dependent deformation field.
- [S5] The deformation field is modeled using decomposed 4D motion fields and a 3-layer MLP that maps a spatial-temporal coordinate to a deformation offset.

### NeRF-Liif
- [S6] A baseline method that super-resolves LR images using a pretrained LIIF (Local Implicit Image Function) model, which requires LR-HR pairs for training and introduces external data priors.
- [S6] Training data requirement: LR-HR pairs.
- [S6] On synthetic Blender dataset, LIIF may produce false predictions due to domain mismatch with its external training set.
- [S6] On real-world LLFF dataset, LIIF tends to be oversmooth and may predict false color or geometry.
- [S6] Blender ×2 (100x100): PSNR 27.07, SSIM 0.919, LPIPS 0.067.
- [S6] Blender ×4 (100x100): PSNR 25.36, SSIM 0.885, LPIPS 0.125.
- [S6] Blender ×2 (200x200): PSNR 28.81, SSIM 0.934, LPIPS 0.058.
- [S6] Blender ×4 (200x200): PSNR 27.34, SSIM 0.912, LPIPS 0.096.
- [S6] LLFF ×2: PSNR 26.81, SSIM 0.823, LPIPS 0.145.
- [S6] LLFF ×4: PSNR 24.76, SSIM 0.723, LPIPS 0.292.

### UniSurf
- [S7, unofficial] A method unifying volume rendering (radiance fields) and surface rendering (implicit surfaces) to achieve high-quality geometry and sharp textures without mask supervision.
- [S7, unofficial] Uses an occupancy field where the occupancy at the $i^{th}$ sample corresponds to an indicator of surface presence.
- [S7, unofficial] Uses volume rendering in the early stage for optimization without mask supervision.
- [S7, unofficial] Uses surface rendering in the later stage to extract level-set surfaces.
- [S7, unofficial] Unlike pure surface rendering which requires mask supervision and has blurry texture mapping, this method provides high-quality novel views and sharp textures/colors without mask supervision.

## Background
The standard NeRF architecture was introduced by Mildenhall et al. in 2020 [S1, S2, S3]. It established the use of a coordinate-based MLP with positional encoding to represent continuous 3D scenes. Subsequent works have modified this architecture to address specific challenges: NeRF-W [S3] introduced appearance embeddings for unconstrained photo collections; Mip-NeRF [S1] introduced integrated positional encoding for anti-aliasing; Instant-NGP [S1, S4] introduced hash encoding for real-time training; and generative models like EG3D [S2] and Diffusion NeRF [S1] introduced triplane representations and diffusion priors. The architecture has evolved from simple MLPs to complex hybrid systems involving hash grids, tensor decompositions, and explicit mesh extraction.
