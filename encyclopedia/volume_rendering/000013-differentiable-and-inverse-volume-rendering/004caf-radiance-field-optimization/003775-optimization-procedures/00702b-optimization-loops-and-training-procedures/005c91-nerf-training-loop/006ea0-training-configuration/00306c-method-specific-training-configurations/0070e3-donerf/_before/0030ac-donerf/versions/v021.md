# DONeRF

Also called: Depth Oracle Neural Radiance Fields, DONeRF Training Configuration, DONeRF training setup, Depth Oracle Network, DoNeRF

## Overview
DONeRF is a training configuration for neural radiance fields that replaces the standard coarse-to-fine raymarching with a dual-network architecture: a **depth oracle network** and a **shading network** [S3]. It solves the prohibitive computational cost of NeRF by using the oracle to predict a small set of optimal sample locations along each ray, allowing the shading network to render high-quality images with only 2–16 samples per ray instead of hundreds [S3]. It sets itself apart from standard NeRF by explicitly decoupling geometry estimation (oracle) from appearance modeling (shading) and by employing a classification-based depth prediction strategy rather than direct regression [S1][S3].

## How it works
**Inputs and Outputs:**
*   **Input:** RGBD images (color and depth) sampled from a **view cell** [S3]. A view cell is a bounding box with a primary orientation and maximum viewing angle, capturing rays within specific rotation limits [S3].
*   **Output:** Rendered RGB color $\mathbf{c}$ and accumulated opacity for each pixel [S3].

**Data Structures:**
1.  **Depth Oracle Network:**
    *   **Architecture:** 8-layer MLP, 256 hidden units per layer, ReLU activation [S1][S3].
    *   **Input:** Concatenated position $\mathbf{x} \in \mathbb{R}^3$ and view direction $\mathbf{d} \in S^2$ [S1].
    *   **Encoding:** No positional encoding is applied to inputs [S1].
    *   **Output:** Discretized depth classification logits [S3].
2.  **Shading Network:**
    *   **Architecture:** 8-layer MLP, 256 hidden units per layer, ReLU activation [S1][S3].
    *   **Input:** Position $\mathbf{x}$ and view direction $\mathbf{d}$ [S1].
    *   **Encoding:** Positional encoding $\gamma(\mathbf{x})$ (63-dim) and $\gamma(\mathbf{d})$ (27-dim) [S1].
    *   **Processing:** $\gamma(\mathbf{x})$ is fed into the first layer; $\gamma(\mathbf{d})$ is concatenated to the feature vector before the last layer [S1].
    *   **Output:** RGB color $\mathbf{c} \in \mathbb{R}^3$ and volume density $\sigma \in \mathbb{R}^+$ [S1].

**Numbered Steps:**
1.  **Ray Unification:** Rays are transformed into a unified space relative to the view cell's primary orientation [S3].
2.  **Depth Classification (Oracle):** The depth oracle network takes the unified ray parameters and predicts a classification over discretized depth bins. This replaces direct depth regression [S3].
3.  **Sample Selection:** Based on the oracle's classification, $N_s$ samples are selected along the ray [S1]. The number of selected samples is denoted as $N_s$ (e.g., DONeRF-16 uses $N_s=16$) [S1].
4.  **Space Warping:** The selected sample positions are transformed (warped) towards the view cell and logarithmically scaled to handle large depth ranges and focus on foreground frequencies [S3].
5.  **Shading and Accumulation:** The shading network evaluates the warped samples to produce density $\sigma_i$ and color $\mathbf{c}_i$. The final color is accumulated using the standard volume rendering integral [S3].

**Formulas:**
*   **Opacity Loss ($\text{loss}_O$):** Prevents dark pixel artifacts by forcing accumulated opacity to be at least 1 [S3].
    $$
    \text{loss}_O = \begin{cases} 
    0, & \text{if } \sum_{i=1}^{X} \delta_i \geq 1 \\
    \left( \left( \sum_{i=1}^{X} \delta_i \right) - 1 \right)^2, & \text{otherwise}
    \end{cases}
    $$
    Where $X$ is the number of samples per ray and $\delta_i$ is the opacity contribution of sample $i$ [S3].
*   **Total Loss:**
    $$
    \text{loss} = \alpha \cdot \text{loss}_{\text{MSE}} + \beta \cdot \text{loss}_O
    $$
    Where $\text{loss}_{\text{MSE}}$ is the Mean Squared Error between rendered and ground truth RGB, $\alpha = 1.0$, and $\beta = 10.0$ [S3].
*   **Effective Run Count (# Run):**
    $$
    \# \text{Run} = 1 + \frac{N_s}{N_p}
    $$
    Where $N_s$ is the number of samples selected by the oracle and $N_p$ is the number of grouped samples (in standard DONeRF, $N_p=1$) [S1].

**Parameters:**
*   **Network Depth:** 8 hidden layers for both networks [S3].
*   **Hidden Units:** 256 per layer [S3].
*   **Samples per Ray ($N$):** Typically 2, 4, 8, or 16 [S3].
*   **Training Iterations:** 300,000 iterations for the oracle, followed by 300,000 iterations for the shading network [S3].
*   **Optimizer:** Adam, learning rate 0.0005, batch size 4096 samples per iteration [S3].
*   **Loss Weights:** $\alpha = 1.0$ (MSE), $\beta = 10.0$ (Opacity) [S3].
*   **Oracle Configuration:** K-5, Z-5, I-128 (parameters for the depth classification bins) [S3].

**Edge Cases and Pitfalls:**
*   **Dark Pixel Artifacts:** Low sample counts can cause rays to fail to accumulate to opacity 1, resulting in dark backgrounds. This is mitigated by the opacity loss term [S3].
*   **Non-End-to-End Training:** The architecture is not end-to-end trainable; the oracle must be trained first, then the shading network [S2][S3].
*   **No Ground Truth Depth:** If GT depth is unavailable, a dense NeRF (12 layers, 512 units, 128 samples/ray) is trained first to extract depth maps, which are then used to train the DONeRF oracle [S3]. This may result in high-frequency noise in background regions [S2].
*   **Reflective/Transparent Surfaces:** Single depth estimates are insufficient for mirrors or refractive surfaces, leading to artifacts [S3].

**Pseudocode:**
```python
# DONeRF Training Loop
# Assumes pre-defined OracleNet and ShadingNet classes
# Assumes dataset provides RGBD images within a ViewCell

def train_donerf(dataset, oracle_iterations=300000, shading_iterations=300000):
    # 1. Initialize Networks
    oracle_net = DepthOracleNetwork(layers=8, units=256, use_positional_encoding=False)
    shading_net = ShadingNetwork(layers=8, units=256, use_positional_encoding=True)
    
    # 2. Train Depth Oracle
    oracle_optimizer = Adam(oracle_net.parameters(), lr=0.0005)
    for i in range(oracle_iterations):
        batch = dataset.get_batch(batch_size=4096)
        rays = batch.rays # (x, d) in unified space
        gt_depth = batch.depth
        
        # Oracle predicts classification logits for discretized depth bins
        oracle_logits = oracle_net(rays)
        
        # BCE Loss for classification
        loss_oracle = BCELoss(oracle_logits, gt_depth_discretized)
        
        oracle_optimizer.zero_grad()
        loss_oracle.backward()
        oracle_optimizer.step()

    # 3. Train Shading Network
    shading_optimizer = Adam(shading_net.parameters(), lr=0.0005)
    alpha = 1.0
    beta = 10.0
    
    for i in range(shading_iterations):
        batch = dataset.get_batch(batch_size=4096)
        rays = batch.rays
        gt_rgb = batch.rgb
        
        # Step 1: Oracle predicts sample locations
        # Oracle returns indices or positions for Ns samples
        selected_samples = oracle_net.select_samples(rays, Ns=4) # Example Ns=4
        
        # Step 2: Warp samples to view cell space
        warped_samples = warp_samples(selected_samples, rays)
        
        # Step 3: Shading network evaluates samples
        # ShadingNet takes warped positions and original directions
        densities, colors = shading_net(warped_samples, rays.directions)
        
        # Step 4: Volume Rendering
        # Compute opacity and transmittance for each sample
        deltas = compute_sample_distances(warped_samples)
        alphas = 1.0 - torch.exp(-densities * deltas)
        transmittances = compute_transmittance(alphas)
        
        # Accumulate color
        rendered_rgb = accumulate_color(transmittances, alphas, colors)
        
        # Compute Losses
        loss_mse = MSELoss(rendered_rgb, gt_rgb)
        
        # Opacity Loss: Force sum of opacities >= 1
        sum_opacities = torch.sum(alphas)
        opacity_loss = torch.where(
            sum_opacities >= 1.0,
            torch.tensor(0.0),
            (sum_opacities - 1.0)**2
        )
        
        total_loss = alpha * loss_mse + beta * opacity_loss
        
        shading_optimizer.zero_grad()
        total_loss.backward()
        shading_optimizer.step()

    return oracle_net, shading_net
```

## Operating characteristics
*   **Time Complexity:** Inference cost is approximately 4.35 MFLOP per pixel [S3].
*   **Memory Complexity:** Compact; requires only the storage for two MLPs (approx. 4 MB), no additional acceleration structures or caching [S3].
*   **Performance:** Renders at 22 ms per frame on a single GPU at 400x400 pixels [S3]. On NVIDIA RTX 3090 at 800x800 with 2 samples/ray, total time is 51.3 ms (~20 fps) [S3].
*   **Quality:** Achieves an average PSNR of 31.14 dB, compared to NeRF's 30.52 dB [S3].
*   **Speedup:** Up to 48x faster than NeRF when conditioning on ground truth depth [S3].
*   **Strengths:** Real-time rendering capability, high quality with very few samples (2-4), compact memory footprint [S3].
*   **Limitations:** Not end-to-end trainable; struggles with reflective/transparent surfaces; requires high-quality depth supervision or a pre-trained NeRF for initialization [S2][S3].

## Background
DONeRF was introduced by Nagel et al. to bring compact neural representations closer to practical real-time rendering applications like games and VR [S3]. It addresses the prohibitive computational cost of NeRF, which requires dozens of petaFLOPS, by replacing the MLP-based raymarching with a local sampling strategy guided by a depth oracle [S3]. The method was developed at Graz University of Technology and Facebook Reality Labs [S3].
