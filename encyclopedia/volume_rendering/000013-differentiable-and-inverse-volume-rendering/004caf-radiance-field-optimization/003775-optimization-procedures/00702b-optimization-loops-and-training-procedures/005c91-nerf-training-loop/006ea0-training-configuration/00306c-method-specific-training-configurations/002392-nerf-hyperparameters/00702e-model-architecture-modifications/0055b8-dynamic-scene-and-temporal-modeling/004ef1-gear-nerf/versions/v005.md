# Gear-NeRF

Also called: Gear-NeRF: Free-Viewpoint Rendering and Tracking with Motion-aware Spatio-Temporal Sampling

## Overview
Gear-NeRF is a dynamic scene representation method that stratifies a 4D scene into multiple "gear" levels based on semantic motion scales, allowing for region-specific spatio-temporal sampling resolution [S1]. It solves the inefficiency of uniform sampling in dynamic NeRFs by assigning higher-resolution feature volumes to regions with larger motion, thereby improving dynamic novel view synthesis quality while enabling free-viewpoint object tracking [S1]. Unlike [NeRF with Time Parameter](14705-nerf-with-time-parameter.md) which treats time as a continuous input to a single network, Gear-NeRF uses discrete gear levels to allocate computational resources proportional to motion intensity.

## How it works
**Inputs:** A set of $W$ input videos $V = \{V_1, V_2, \dots, V_W\}$ of a dynamic scene with calibrated camera poses.
**Outputs:** A radiance field representation capable of rendering novel views and tracking objects.

**Data Structures:**
The representation consists of $N_{gear}$ 4D feature volumes, where each volume corresponds to a specific gear level $G \in \{1, \dots, N_{gear}\}$ [S1].
1.  **Spatial Feature Grids ($h_j$):** Shared across all gears. These are 2D planes embedding coordinate tuples $(x,y), (x,z), (y,z)$ to features of dimension $M$.
2.  **Gear-Specific Temporal/Spatial Embeddings ($k^G_j$):** Unique to each gear $G$. These are 2D planes embedding coordinate tuples $(z,t), (y,t), (x,t)$ to features of dimension $M$.
3.  **Linear Transforms ($B_j$):** Shared linear layers mapping the element-wise products to the final feature vector dimension.
4.  **Gear Assignment Volume ($g$):** A scalar field determining the gear level for any coordinate.

**Numbered Steps:**

1.  **Semantic Embedding and Gear Determination:**
    The method optimizes for a 4D semantic embedding derived from powerful image segmentation models (specifically SAM) to profile the scene into semantic regions [S1]. The gear level $g(\mathbf{x}, t)$ at any space-time coordinate $(\mathbf{x}, t)$ is computed using a planar-factorized 4D feature volume. The source provides the start of this formula but cuts off:
    $$
    g(\mathbf{x}, t) = \mathbf{1}^\top (h'_1(x, y) \bowtie k'_1(z, \dots
    $$
    *Note: The exact completion of the gear assignment formula is not provided in the sources.* The resulting $g(\mathbf{x}, t)$ determines the gear level $G$ for that coordinate. Regions with larger motion scales are assigned higher gear levels through a gear determination scheme [S1].

2.  **Feature Vector Computation:**
    For a specific gear level $G$ and space-time coordinate $(\mathbf{x}, t)$, the feature vector $\mathbf{f}^G(\mathbf{x}, t)$ is computed by summing three terms. Each term involves an element-wise product of a shared spatial embedding and a gear-specific embedding, followed by a linear transform [S1]:
    $$
    \mathbf{f}^G(\mathbf{x}, t) = B_1 (h_1(x, y) \bowtie k^G_1(z, t)) + B_2 (h_2(x, z) \bowtie k^G_2(y, t)) + B_3 (h_3(y, z) \bowtie k^G_3(x, t))
    $$
    Where:
    *   $h_j(\cdot, \cdot)$ are functions evaluated by bilinear interpolation on regularly spaced 2D feature grids.
    *   $k^G_j(\cdot, \cdot)$ are functions evaluated by bilinear interpolation on regularly spaced 2D feature grids specific to gear $G$.
    *   $\bowtie$ denotes element-wise product.
    *   $B_j$ denotes a linear transform mapping the products to feature vectors.
    *   The vector-valued functions $h_j(\cdot, \cdot)$ and linear transforms $B_j(\cdot)$ are shared by all gears.
    *   Each gear has its own spatio-temporal embedding $k^G_j(\cdot, \cdot)$ in $M$-dimensional space [S1].

3.  **Radiance Field Prediction:**
    A tiny MLP maps the feature vector $\mathbf{f}^G(\mathbf{x}, t)$ to the volume density $\sigma$ and the view-dependent emitted color $\mathbf{c}$, given the viewing direction $\mathbf{d}$ [S1].

4.  **Spatio-Temporal Sampling:**
    Higher gear levels receive higher-resolution spatio-temporal sampling to improve dynamic novel view synthesis [S1]. This means rays passing through regions assigned to higher gears are sampled more densely.

**Parameters:**
*   $N_{gear}$: The total number of gear levels used to stratify the scene representation based on motion scales [S1].
*   $M$: The dimension of the feature space for the embeddings [S1].

**Edge Cases and Pitfalls:**
*   **Gear Assignment Ambiguity:** The exact formula for $g(\mathbf{x}, t)$ is truncated in the source. Implementers must infer the structure from the pattern of $\mathbf{f}^G$ or consult the full paper [S1].
*   **Semantic Dependency:** The method relies on semantic information from image segmentation models (SAM) [S1]. Errors in segmentation may propagate to incorrect gear assignments.

## Operating characteristics
*   **Time Complexity:** Not given in the sources. However, the method implies variable cost per ray depending on the gear level assigned to the sampled points, with higher gears requiring more samples.
*   **Memory Complexity:** Not given in the sources. The memory usage scales with $N_{gear}$ times the size of the feature grids, as each gear has its own set of temporal embeddings $k^G_j$.
*   **Strengths:** Improves photo-realistic dynamic novel view synthesis by allocating resources to dynamic regions; enables free-viewpoint tracking of objects of interest almost for free [S1].
*   **Limitations:** Requires calibrated camera poses and input videos; relies on external semantic segmentation models [S1].
*   **When to use:** When rendering dynamic scenes with varying motion scales and when free-viewpoint tracking is desired.
*   **When not to use:** For static scenes or scenes with uniform motion where the overhead of managing multiple gear levels is unjustified.

## Background
Gear-NeRF was introduced in 2024 by the authors of "Gear-NeRF: Free-Viewpoint Rendering and Tracking with Motion-aware Spatio-Temporal Sampling" [S1]. It addresses the issue that dynamic regions inherently require more resources per unit volume than static regions due to their time-evolving nature [S1]. The method builds on the standard NeRF architecture but replaces the unified 4D volume with a series of feature volumes stratified by motion scale [S1].
