# Triplane and Planar Representations

Also called: Triplanar Representation, Planar Grids

## Overview
Triplane and Planar Representations encode 3D scenes using a fixed set of three orthogonal 2D feature grids ($xy, xz, yz$) to enable efficient neural volumetric rendering [S2]. This approach distinguishes itself from standard 3D voxel grids by significantly reducing memory footprint through the use of 2D convolutions, and from MLP-only representations by explicitly storing spatial features, although it introduces an axis-aligned bias that can complicate the handling of complex structures [S1].

## Shared principles
The family shares a common data structure and query mechanism.

**Data Structure**
The scene is represented by a tensor $\mathbf{T}$ (or $S$) with shape $\mathbb{R}^{3 \times C \times D \times D}$ [S1, S2].
*   **Dimensions:** The first dimension (size 3) indexes the three orthogonal canonical planes: $xy$, $xz$, and $yz$ [S1, S2].
*   **Channels ($C$):** The feature dimension per grid cell [S1, S2].
*   **Resolution ($D \times D$):** The spatial resolution of each 2D plane [S1, S2].

**Feature Aggregation (Query)**
To query a point $\mathbf{x} \in \mathbb{R}^3$, features are gathered by projecting $\mathbf{x}$ onto each canonical plane and bilinearly interpolating the nearby features [S1, S2]. Let $\mathbf{f}_{xy}, \mathbf{f}_{xz}, \mathbf{f}_{yz}$ be the features gathered from the respective planes. These are combined using an aggregation operator $\Phi$ and passed to a lightweight MLP to predict radiance field properties [S2]:

$$
(\mathbf{f}, c, \sigma) = \text{MLP}(\Phi(\mathbf{f}_{xy}, \mathbf{f}_{xz}, \mathbf{f}_{yz}))
$$

The output values, including color, are independent of viewing direction and depend only on $\mathbf{x}$ [S2].

**Rendering**
Points are sampled along rays, and their features are aggregated to render images via volume rendering [S1, S2].

## Subtopics

### [EG3D Triplane Representation](13901-eg3d-triplane-representation.md)
The EG3D Triplane Representation is a 3D scene encoding method that stores features in three orthogonal 2D grids to enable efficient neural volumetric rendering. It distinguishes itself from standard 3D voxel grids by reducing memory footprint through 2D convolution and from MLP-only representations by explicitly storing spatial features, though it introduces axis-aligned bias that can complicate handling of complex structures.

*   **When to choose:** Use when generating high-fidelity 3D assets from noise vectors where memory efficiency and 2D generative priors are prioritized over explicit multi-view conditioning.
*   **Link:** [EG3D Triplane Representation](13901-eg3d-triplane-representation.md)

### [Image-Conditional Triplanar Representation](18169-image-conditional-triplanar-representation.md)
Image-Conditional Triplanar Representation is a 3D scene representation that constructs a fixed set of three axis-aligned 2D feature grids from input images, enabling efficient neural rendering without the cubic complexity of voxel-based methods. It differs from standard triplane approaches by explicitly conditioning the feature grid construction on camera poses and intrinsic parameters via a back-projected 3D feature volume, allowing the representation to capture appearance details directly from the input view rather than relying solely on a generic latent code.

*   **When to choose:** Use when reconstructing 3D scenes from single or few input images where explicit conditioning on camera parameters is required to resolve depth ambiguity and missing features.
*   **Link:** [Image-Conditional Triplanar Representation](18169-image-conditional-triplanar-representation.md)

### Triplane NeRF with Diffusion Prior
This variant uses a triplane NeRF representation where scene codes are optimized jointly with a diffusion prior to handle sparse-view data and ensure end-to-end coherence [S1].

*   **Definition:** The framework optimizes scene codes $\{x_i\}$, prior parameters $\phi$, and decoder parameters $\psi$ in a single training stage by minimizing the rendering loss $L_{rend}$ and a diffusion prior term in the form of NLL, approximated as $L_{diff}$ [S1]. The total loss is $L = \lambda_{rend} L_{rend}(\{x_i\}, \psi) + \lambda_{diff} L_{diff}(\{x_i\}, \phi)$ [S1].
*   **Parameters:**
    *   **Prediction Format:** Uses v-parameterization $\hat{v}_\phi(x^{(t)}, t)$ from [43], such that $\hat{x} = \alpha(t)x^{(t)} - \sigma(t)\hat{v}$ [S1].
    *   **Weighting Function:** Uses SNR-based weighting $w(t) = (\alpha(t)/\sigma(t))^2\omega$ from Eq. (5), instead of LSGM mechanisms, which are found unstable with NeRF auto-decoders [S1].
*   **Layout:**
    *   **Scene Code $x_i$:** Shape $\mathbb{R}^{3 \times 6 \times 128 \times 128}$, representing a triplane NeRF representation [S1].
    *   **Denoising Network:** A U-Net with 122M parameters takes noisy and denoised triplane features as input/output, with channels of all three planes stacked together [S1].
*   **Link:** [EG3D Triplane Representation](13901-eg3d-triplane-representation.md) (Note: No dedicated article exists; details are cited from [S1]).

### DoublePlane
DoublePlane is a variant of planar representations designed for dynamic scenes, optimizing for both spatial and temporal efficiency.

*   **Performance:** On the D-NeRF dataset, DoublePlane achieves PSNR 30.370, SSIM 0.961, LPIPS 0.054, and a Training Time of 8m 04s [S2].
*   **Link:** [EG3D Triplane Representation](13901-eg3d-triplane-representation.md) (Note: No dedicated article exists; details are cited from [S2]).

## Background
Triplane representations were introduced to address the high memory cost of 3D voxel grids and the lack of explicit spatial structure in MLP-only NeRFs. The EG3D Triplane Representation [S2] leverages the success of 2D generative models (GANs) by representing 3D shapes as three 2D planes, allowing the use of efficient 2D convolutions. The Image-Conditional Triplanar Representation [S1] extends this by incorporating explicit camera conditioning to enable single-view reconstruction. The integration of diffusion priors [S1] further allows for robust generation and reconstruction from sparse views by regularizing the triplane codes.
