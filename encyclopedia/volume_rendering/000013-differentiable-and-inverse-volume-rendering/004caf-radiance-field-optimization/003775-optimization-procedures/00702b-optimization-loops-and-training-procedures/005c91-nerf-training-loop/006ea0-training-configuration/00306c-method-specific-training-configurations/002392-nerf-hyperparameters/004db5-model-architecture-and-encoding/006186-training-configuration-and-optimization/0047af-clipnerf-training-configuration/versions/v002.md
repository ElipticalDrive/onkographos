# CLIPNeRF Training Configuration

Also called: Absolute Directional CLIP Loss, CLIPNeRF Hyperparameters, CLIPNeRF Implementation, Directional CLIP Loss, Relative Directional CLIP Loss, StyleGAN-NADA CLIP Loss

## Overview
CLIPNeRF is a text-guided stylization method that optimizes a Neural Radiance Field (NeRF) to match the semantic direction of a target text prompt in CLIP embedding space [S2]. It distinguishes itself from standard NeRF training by freezing density parameters and minimizing the negative cosine similarity between rendered image patches and text embeddings, using a relative directional loss to prevent mode collapse [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Source NeRF model (pre-trained on images), target text prompt $\mathbf{t}_{tgt}$, optional source text prompt $\mathbf{t}_{src}$, training dataset poses.
*   **Outputs:** Stylized NeRF model.

**Data Structures:**
*   **CLIP Encoder:** Uses CLIP ViT-B/32 [S1].
*   **NeRF Representation:** Standard MLP predicting density $\sigma$ and color $\mathbf{c}$ [S2].
*   **Patch Rendering Buffer:** Stores rendered RGB values for a $128 \times 128$ patch [S1].

**Parameters:**
*   **Iterations:** 500 [S1].
*   **Optimizer:** Adam, learning rate $1 \times 10^{-4}$ [S1].
*   **Patch Size:** $128 \times 128$ pixels [S1].
*   **Ray Sampling Stride:** 5 within the patch, resulting in a $640 \times 640$ receptive field on the original image [S1].
*   **Importance Sampling Points:** 16 per ray during patch rendering [S1].
*   **Fine MLP Samples:** 80 total (64 coarse + 16 fine) [S1].

**Method Steps:**
1.  **Freeze Density:** Freeze all NeRF parameters related to density $\sigma$ to preserve geometry [S1].
2.  **Sample Pose:** Randomly sample a camera pose from the training dataset [S1].
3.  **Render Patch:** Render a $128 \times 128$ image patch using the sampled pose. Rays are sampled with a stride of 5 to cover a wider area [S1].
    *   *Note:* Naive differentiable rendering of high-resolution images is intractable due to memory constraints [S1].
4.  **Compute Embeddings:**
    *   Encode the rendered patch $\mathbf{I}_{tgt}$ using the CLIP image encoder $\mathcal{E}_i$ [S2].
    *   Encode the target text prompt $\mathbf{t}_{tgt}$ using the CLIP text encoder $\mathcal{E}_t$ [S2].
    *   (Optional) Encode the source text prompt $\mathbf{t}_{src}$ using $\mathcal{E}_t$ [S2].
5.  **Compute Loss:** Calculate the directional CLIP loss.
    *   **Absolute Directional Loss:** Measures cosine similarity between the rendered image and target text [S2]:
        $$ \mathcal{L}_{dir} = 1 - \langle \hat{\mathcal{E}}_i(\mathbf{I}_{tgt}), \hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) \rangle $$
        where $\hat{\mathcal{E}}$ denotes normalized embeddings [S2].
    *   **Relative Directional Loss:** Transfers style from source to target by measuring the trajectory in CLIP space [S2]:
        $$ \mathcal{L}_{dir} = 1 - \langle \hat{\mathcal{E}}_i(\mathbf{I}_{tgt}) - \hat{\mathcal{E}}_i(\mathbf{I}_{src}), \hat{\mathcal{E}}_t(\mathbf{t}_{tgt}) - \hat{\mathcal{E}}_t(\mathbf{t}_{src}) \rangle $$
        where $\mathbf{I}_{src}$ is the rendered source image [S2].
6.  **Optimize:** Minimize $\mathcal{L}_{dir}$ using Adam [S1].

**Pitfalls:**
*   **Mode Collapse:** Absolute directional CLIP loss can cause mode collapse and reduce generation diversity [S2].
*   **Weak Stylization:** The loss measures directional similarity but ignores magnitude, potentially leading to insufficient style transfer [S2].
*   **Memory Constraints:** High-resolution differentiable rendering is intractable; patch-based rendering is required [S1].

## Operating characteristics
*   **Memory:** Reduced by rendering small patches ($128 \times 128$) instead of full images [S1].
*   **Speed:** Limited to 500 iterations in reported experiments [S1].
*   **Strengths:** Enables text-driven stylization of 3D scenes [S2].
*   **Limitations:** May struggle with uniform stylization across the whole scene (e.g., excess on some parts, insufficiency on others) [S2].

## Background
CLIPNeRF was introduced by Wang et al. in 2021, extending StyleCLIP [Patashnik et al. 2021] and StyleGAN-NADA [Gal et al. 2021] to 3D NeRFs [S2]. It uses the absolute directional CLIP loss initially designed for face editing [S2]. Later work (NeRF-Art) proposed relative directional loss to address mode collapse and magnitude issues [S2].
