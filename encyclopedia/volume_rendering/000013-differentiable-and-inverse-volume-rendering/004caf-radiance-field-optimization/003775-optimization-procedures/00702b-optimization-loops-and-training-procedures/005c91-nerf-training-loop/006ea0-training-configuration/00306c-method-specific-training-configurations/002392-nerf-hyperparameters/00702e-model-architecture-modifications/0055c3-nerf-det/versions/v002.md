# NeRF-Det

Also called: NeRF-then-Det

## Overview
NeRF-Det is a method for indoor 3D object detection using posed RGB images that explicitly models scene geometry as an opacity field by jointly training a NeRF branch with a 3D detection pipeline [S1]. It improves upon standard volume-based detectors by integrating multi-view geometry constraints from the NeRF branch into 3D detection through a shared geometry MLP [S1]. Unlike "NeRF-then-Det" approaches like NeRF-RPN, which suffer from high latency due to per-scene optimization, NeRF-Det is a joint "NeRF-and-Det" paradigm that generalizes to unseen scenes without per-scene training, achieving state-of-the-art accuracy with significantly lower inference latency [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $T$ posed RGB images $I_i \in \mathbb{R}^{H_i \times W_i \times 3}$ with corresponding intrinsic matrix $K \in \mathbb{R}^{3 \times 3}$ and extrinsic matrix $R_i \in \mathbb{R}^{3 \times 4}$ for $i=1, \dots, T$ [S1].
*   **Output:** 3D bounding boxes for detected objects [S1].

**Data Structures:**
1.  **2D Feature Map ($F_i$):** High-resolution features extracted from each image $I_i$ using a Feature Pyramid Network (FPN). $F_i \in \mathbb{R}^{C \times H/4 \times W/4}$ [S1].
2.  **3D Voxel Grid:** A 3D grid of $N_x \times N_y \times N_z$ voxels. The coordinate system has the z-axis as height, and x/y as horizontal dimensions [S1].
3.  **Volume Features ($V_i(p)$):** For each voxel center $p = (x, y, z)^T$, a feature vector assigned from the 2D image features [S1].
4.  **Aggregated Volume Features ($V_{avg}(p)$):** The multi-view aggregated feature for voxel $p$ [S1].
5.  **Density Field ($\sigma(p)$):** Predicted by the shared G-MLP [S1].
6.  **Opacity Field ($\alpha(p)$):** Derived from $\sigma(p)$ [S1].

**Numbered Steps:**

1.  **2D Feature Extraction:** Pass each input image $I_i$ through a 2D image backbone (FPN) to extract high-resolution features $F_i \in \mathbb{R}^{C \times H/4 \times W/4}$ [S1].

2.  **3D-to-2D Projection:** For each voxel center $p = (x, y, z)^T$ in the 3D grid, project it into view $i$ to obtain 2D pixel coordinates. Compute the projected coordinates $(u'_i, v'_i, d_i)^T$ using the scaled intrinsic matrix $K'$ (which accounts for feature map downsampling) and the extrinsic matrix $R_i$:
    $$
    \begin{pmatrix} u'_i, v'_i, d_i \end{pmatrix}^T = K' \times R_i \times \begin{pmatrix} \mathbf{p}, 1 \end{pmatrix}^T
    $$
    The pixel coordinates are $(u_i, v_i) = (u'_i/d_i, v'_i/d_i)$ [S1].

3.  **Feature Assignment:** Assign 3D features $V_i(p)$ by nearest neighbor interpolation of $F_i$ at location $(u_i, v_i)$:
    $$
    V_i(p) = \text{interpolate}((u_i, v_i), F_i)
    $$
    If $p$ is projected outside the image boundary or behind the image plane ($d_i \le 0$), discard the feature and set $V_i(p) = 0$ [S1].

4.  **Multi-view Aggregation:** Aggregate features from all $M_p$ effective 2D projections (where $M_p$ is the number of views where $V_i(p) \neq 0$) by averaging:
    $$
    V_{avg}(p) = \sum_{i=1}^{M_p} \frac{V_i(p)}{M_p}
    $$
    [S1].

5.  **Geometry Prediction (Shared G-MLP):** Feed the voxel coordinates $p$ into a shared geometry MLP (G-MLP) to predict the volume density $\sigma(p)$. The activation function for $\sigma(p)$ is ReLU [S1].

6.  **Opacity Calculation:** Transform the density field $\sigma(p)$ into an opacity field $\alpha(p)$. The specific formula for $\alpha$ is not explicitly defined in the source text beyond "transform the density field into an opacity field," but standard NeRF conventions imply $\alpha = 1 - \exp(-\sigma \delta)$ or similar, though the text simply states multiplication with volume features [S1]. *Note: The source text does not provide the explicit mathematical formula for $\alpha$ from $\sigma$, only that it is transformed.* [G: Assuming standard volume rendering opacity $\alpha = 1 - e^{-\sigma \Delta}$ where $\Delta$ is voxel size, or simply $\alpha = \sigma$ if normalized, but the text says "transform". We stick to the text: "transform the density field into an opacity field $\alpha$".]

7.  **Geometry-Aware Volume Features:** Multiply the opacity field $\alpha(p)$ with the aggregated volume features $V_{avg}(p)$ to reduce the weights of empty space:
    $$
    V_{geo}(p) = \alpha(p) \cdot V_{avg}(p)
    $$
    [S1].

8.  **3D Detection:** Feed the geometry-aware volume features $V_{geo}(p)$ to a detection head for 3D bounding box regression [S1].

9.  **Inference:** During inference, the NeRF branch (G-MLP and associated rendering logic) is removed to minimize overhead. Only the detection head operating on $V_{geo}$ (or potentially just $V_{avg}$ if $\alpha$ is not needed, but the text says "remove the NeRF branch") is used. The text states: "during inference, the NeRF branch is removed, which minimizes the additional overhead to the original detector" [S1].

    Shared Geometry MLP
    Input: p (Nx, Ny, Nz, 3)

    """

**Parameters:**
*   **Activation for density $\sigma(p)$:** ReLU [S1].
*   **Activation for color $c(p, d)$:** Sigmoid [S1]. (Note: Color is used for NeRF branch, not detection branch directly, but part of the joint training).
*   **Interpolation:** Nearest neighbor [S1].

**Edge Cases and Pitfalls:**
*   **Boundary/Depth:** For voxels projected outside the image boundary or behind the image plane ($d_i \le 0$), the feature is discarded and set to 0 [S1].
*   **Depth Estimation Errors:** Using predicted depth maps from external methods like NeuralRecon significantly degrades detection performance (by 2.3 mAP@.50 compared to plain ImVoxelNet), demonstrating that depth estimation errors propagate inaccuracy [S1].
*   **NeRF Branch Impact:** The detection branch negatively impacts the NeRF branch's novel view synthesis quality because it is prone to erasing low-level details required for NeRF rendering. Disabling the detection branch brings a 0.43dB improvement in PSNR [S1].

## Subtopics

### Shared G-MLP
A shared geometry MLP that enables the constraint of multi-view consistency to be propagated from the NeRF branch to the detection branch [S1]. Without the shared G-MLP, performance drops from 50.1 to 48.1 mAP@.25, as the influence of multi-view consistency is only propagated into the image backbone [S1].

## Operating characteristics
*   **Time Complexity:** The method avoids per-scene optimization, allowing it to generalize to unseen scenes. Inference latency is 0.554s on one V100 for NeRF-Det-R50, compared to ~846.8s for NeRF-RPN (a NeRF-then-Det method) [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:**
    *   Improves state-of-the-art by 3.9 mAP on ScanNet and 3.1 mAP on ARKITScenes benchmarks [S1].
    *   On ScanNet, NeRF-Det-R50 achieves 35.13 AP50 with 0.554s latency on one V100 [S1].
    *   Achieves an average PSNR of 20+ for novel view synthesis and an RMSE of 0.756 for depth estimation on 312 scenes in the validation set, without per-scene training [S1].
*   **Scaling:** The method is designed to be generalizable to large-scale datasets (e.g., ScanNet) without the heavy overhead of per-scene NeRF optimization [S1].
*   **Strengths:** Joint training allows geometry-aware volumetric representations; significantly faster than NeRF-then-Det methods; improves detection accuracy by explicitly modeling geometry [S1].
*   **Limitations:** The detection branch can degrade the NeRF branch's novel view synthesis quality by erasing low-level details [S1].
*   **When to use:** Indoor 3D object detection with posed RGB images where generalization to new scenes is required without per-scene optimization [S1].
*   **When not to use:** When high-fidelity novel view synthesis is the primary goal, as the detection branch negatively impacts it [S1].

## Background
NeRF-Det was introduced by Chenfeng et al. from Meta in 2023 [S1]. It addresses the limitations of existing indoor 3D detection methods that struggle to model scene geometry and the high latency of per-scene NeRF optimization. The method builds on the standard NeRF architecture and 3D detection pipelines like ImVoxelNet [S1].
