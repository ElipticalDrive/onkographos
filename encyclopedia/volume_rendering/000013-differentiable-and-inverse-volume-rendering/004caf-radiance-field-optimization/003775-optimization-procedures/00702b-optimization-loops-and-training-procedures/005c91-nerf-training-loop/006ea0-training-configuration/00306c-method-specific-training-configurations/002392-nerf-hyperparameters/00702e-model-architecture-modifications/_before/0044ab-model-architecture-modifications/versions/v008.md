# Model Architecture Modifications

Also called: NeRF Architecture Variants, Neural Radiance Field Structural Changes

## Overview
Model Architecture Modifications alter the fundamental structure of the Neural Radiance Field (NeRF) representation—specifically the input conditioning, output heads, or underlying geometric primitives—to address limitations in standard NeRF, such as static scene assumptions, limited expressivity, or computational inefficiency. Unlike [NeRF Hyperparameters](3065-nerf-hyperparameters.md), which tune training dynamics without changing the model's topology, these modifications redefine the function $F_\Theta$ that maps spatial coordinates and viewing directions to radiance properties. They set themselves apart from [Optimization Procedures](14565-optimization-and-training-procedures.md) by introducing new learnable parameters or data structures (e.g., grids, experts, latent codes) rather than just changing loss functions or learning rates.

## Shared principles
The standard NeRF architecture [S6] consists of two Multi-Layer Perceptrons (MLPs): a coarse network and a fine network. The coarse network takes positional encoded position $\gamma(\mathbf{x})$ and outputs a latent feature vector $\mathbf{h}$ and volume density $\sigma$. The fine network takes $\mathbf{h}$, positional encoded position $\gamma(\mathbf{x})$, and positional encoded view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$.

$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$

Modifications generally fall into three categories:
1.  **Input Expansion:** Adding new conditioning vectors (e.g., appearance embeddings $\mathbf{z}_i$, fluid volume $v$, or previous stage RGB) to the input concatenation.
2.  **Output Expansion:** Adding auxiliary heads to predict values other than $\sigma$ and $\mathbf{c}$, such as semantic labels $y_{aux}$, object codes $o$, or area encoding probabilities $p$. These are rendered using the same transmittance weights $T_i$ and opacity $\alpha_i$ as color:
    $$
    \hat{Y}(r) = \sum_{i=1}^{N} T_i \alpha_i y_{aux}(x_i)
    $$
3.  **Representation Substitution:** Replacing the continuous MLP function with discrete structures (voxel grids, hash tables) or different implicit surfaces (SDFs).

## Subtopics

### [DoF-NeRF](9432-dof-nerf.md)
Extends NeRF to simulate depth-of-field (DoF) effects by optimizing aperture $K$ and focus distance $F$ parameters per view, enabling all-in-focus reconstruction from shallow DoF inputs. Choose when inputs are blurred by lens optics and a sharp 3D representation is required.

### [NeRF-VPT](11770-nerf-vpt.md)
Uses a cascading view prompt tuning paradigm where RGB images from previous rendering stages serve as visual prompts for subsequent networks, enhancing image quality in sparse-view settings without external networks. Choose when iterative refinement of scene understanding is needed.

### [MixRT](12401-mixrt.md)
A hybrid representation combining a low-quality mesh, a view-dependent displacement map, and a compressed NeRF (Instant-NGP) to enable real-time rendering on edge devices by offloading tasks to standard graphics hardware. Choose when real-time performance on constrained hardware is critical.

### [Activation Feature Density Approximation](12492-activation-feature-density-approximation.md)
Estimates volumetric density directly from intermediate MLP activation features, replacing expensive coarse network evaluations with lightweight statistical computations. Choose when inference speed is prioritized over the fidelity of the coarse sampling stage.

### [Signed Distance Function (SDF) Representations](12495-signed-distance-function-sdf-representations.md)
Replaces volumetric density with a continuous scalar field representing distance to the nearest surface, providing explicit geometry via a zero-level set. Choose when sharp surface reconstruction and integration with PBR models are required.

### [Volume-Augmented NeRF](12973-volume-augmented-nerf.md)
Binds an explicit fluid volume value $v_i$ to each sample point, allowing density and color to change over time due to fluid flow, serving as the rendering component for differentiable fluid simulators. Choose for dynamic fluid scenes.

### [Neural-PIL Decomposition Architecture](12975-neural-pil-decomposition-architecture.md)
Separates geometry, material properties (BRDF), and illumination into distinct networks, using a learned pre-integrated lighting network to handle varying lighting conditions. Choose when explicit reflectance decomposition and varying illumination are present.

### [Feature Fields](12995-feature-fields.md)
Generalizes NeRF to predict arbitrary per-point feature signals $\mathbf{f}$ (e.g., semantic labels, physical properties) in addition to color and density, lifting 2D observations into consistent 3D representations. Choose when encoding semantic or functional information into the 3D scene is required.

### [SAID-NeRF](13619-said-nerf.md)
Exploits instance masks from Visual Foundation Models to enhance surface estimation of transparent objects by decomposing appearance into diffuse/specular components and enforcing higher surface densities. Choose for transparent object reconstruction and robotic grasping.

### [MINE](13661-mine.md)
Models the source camera frustum using a continuous depth Multiplane Image (MPI) representation, allowing novel view synthesis via homography warping after a single encoder pass. Choose for efficient multi-view synthesis where target views are known.

### [Voxel and Sparse Grid Representations](13738-voxel-and-sparse-grid-representations.md)
Replaces the continuous MLP with discrete structures (voxel grids, hash tables, triplanes) to store density and appearance features, enabling real-time rendering via interpolation. Choose for real-time differentiable volume rendering.

### [Aleth-NeRF](13764-aleth-nerf.md)
Trains on under- and over-exposed images to render normal-light views by introducing local and global concealing fields that model illumination adaptive volume rendering. Choose when working with low-light or over-exposed LDR inputs without paired HDR data.

### [Unified Volumetric Avatar (UVA)](13784-unified-volumetric-avatar-uva.md)
Represents dynamic human avatars by anchoring structured latent codes to a deformable mesh in canonical space, enabling local editing of geometry and texture. Choose for dynamic human avatars requiring independent geometry/texture editing.

### [Gear-NeRF](13848-gear-nerf.md)
Stratifies dynamic scenes into motion-based 'gears' using semantic information, assigning higher resolution to regions with larger motion scales. Choose for efficient free-viewpoint rendering of dynamic scenes with varying motion complexity.

### [Transformer and Vision Model Integration](13911-transformer-and-vision-model-integration.md)
Integrates Vision Transformers (ViT) to leverage global semantic understanding and long-range dependencies, solving limitations of MLP-based NeRFs in single-image inputs or occlusions. Choose when global scene modeling or generalization across scenes is needed.

### [Human and Specific Subject Modeling](13997-human-and-specific-subject-modeling.md)
*Not given in the sources.*

### [OPONeRF](14014-oponerf.md)
Personalizes plenoptic mapping function parameters for each sampled 3D point by dynamically conditioning network weights on point and scene representations, handling test-time scene changes. Choose when robustness against perturbations and local variations is required.

### [Mixer-NeRF](14073-mixer-nerf.md)
Addresses loss of local information and blurry details by introducing a hybrid spatial feature learning module (MLCA) and a squeeze-and-excitation (SE) network module before the main MLP inference. Choose when high-frequency detail preservation is critical.

### [SCALAR-NeRF](14267-scalar-nerf.md)
Decomposes large-scale scenes into spatial blocks with a coarse global model and local block models sharing a global decoder, fusing outputs using a reference image to avoid "foggy" artifacts. Choose for scalable large-scale neural scene reconstruction on single GPUs.

### [Sparse View and Few-Shot Optimization](14428-sparse-view-and-few-shot-optimization.md)
Mitigates overfitting and geometry breakdown in sparse-view settings through in-situ regularization, deformable sampling, or pseudo-observation densification. Choose when training with drastically reduced input viewpoints ($|S| < 20$).

### [Mixture-of-Experts and Modular Architectures](14429-mixture-of-experts-and-modular-architectures.md)
Replaces the single continuous function with multiple specialized networks (experts) or parallel streams to improve compression, training speed, or representation capacity. Choose when complex features require partitioned neural modules.

### [Uncertainty and Reliability](14487-uncertainty-and-reliability.md)
Extends NeRF to quantify prediction confidence by modeling the scene as a probabilistic entity, providing pixel-level reliability metrics for color and depth. Choose when robust filtering and conformal prediction are needed for sparse or unstructured data.

### [Object Decomposition and Composition](14518-object-decomposition-and-composition.md)
Explicitly separates a scene into distinct semantic or geometric object instances, enabling instance-level editing and amodal segmentation. Choose when structural decomposition for editing is the primary goal.

### [Lighting and Appearance Models](14522-lighting-and-appearance-models.md)
Decouples scene geometry from illumination variations and transient artifacts using learned appearance embeddings or explicit pre-integrated lighting queries. Choose when rendering failure due to lighting changes or shadows is a concern.

### [Optimization and Training Procedures](14565-optimization-and-training-procedures.md)
Covers algorithmic procedures for optimizing NeRFs, including structural modifications to optimization scope like skipping expensive evaluations or restricting updates. Choose when efficient minimization of photometric loss under computational constraints is needed.

### [Image Enhancement and Restoration Methods](14566-image-enhancement-and-restoration-methods.md)
Integrates restoration mechanisms (e.g., blur kernels, inpainting) into the NeRF loop to address input degradation like blur or transient occlusions. Choose when input imagery is degraded and 3D consistency is required.

### [Modular, Hierarchical, and Latent Architectures](14567-modular-hierarchical-and-latent-architectures.md)
Handles non-rigid deformation with topological changes (HyperNeRF) or hierarchical scene structures (Strata-NeRF) using higher-dimensional spaces or discrete latent codes. Choose for non-rigidly deforming or stratified scenes.

### [NeRF-W](14630-nerf-w.md)
Handles unconstrained "in-the-wild" photo collections by disentangling shared static geometry from image-dependent transient elements and photometric variations. Choose for real-world image collections with lighting changes and moving objects.

### [Generalizable Implicit Reconstruction with SRDF](14760-generalizable-implicit-reconstruction-with-srdf.md)
Reconstructs scenes with fine details using a Signed Ray Distance Function (SRDF) and ray transformer to aggregate features, addressing over-smoothing in global feature volumes. Choose for generalizable implicit reconstruction with fine details.

### [MuRF (Multi-Baseline Radiance Fields)](15007-murf-multi-baseline-radiance-fields.md)
Constructs a target view frustum volume aligned with the target camera and uses a 3D context-aware convolutional decoder to handle varying camera baselines. Choose for sparse view synthesis under varying camera baseline settings.

### [Gaussian and Primitive-Based Representations](15011-gaussian-and-primitive-based-representations.md)
Replaces the continuous MLP with discrete geometric primitives or explicit Gaussian distributions to improve rendering efficiency and geometric fidelity. Choose when analytic primitives offer better efficiency than voxel grids.

### [Decentralized Federated NeRF](15032-decentralized-federated-nerf.md)
Distributes training computation to users and aggregates only global radiance field models using Secure Multi-Party Computation (SMPC) to prevent personal data leakage. Choose for crowd-sourced 3D reconstruction with privacy constraints.

#### NeRF-VAE
- **Definition:** A generative NeRF model that generalizes to out-of-distribution scenes and removes the need to train on each scene from scratch [S1].
- **Steps:** The NeRF renderer is conditioned on a latent code trained using Iterative Amortized Inference and a ResNet encoder. An attention-based scene function is introduced instead of the typical MLP [S1].
- **Comparison:** Outperforms baseline NeRF with a low number of scene views (5-20), but is outperformed by baseline NeRF when a large number of views are available (100+) due to lower scene expressivity [S1].

#### PIE-NeRF
- **Definition:** A pipeline integrating physics-based elastodynamic simulation with a neural radiance field representation, using a meshless discretisation based on quadratic generalized moving least squares on top of the density field of a NeRF [S1].
- **Steps:** Enables large deformations and nonlinear hyperelastic material simulation directly on the implicit representation and supports interactive manipulation of real-world captured scenes with complex geometries [S1].

#### DäRF Implementation Details
- **Parameters:** NeRF Backbone: K-planes [36]. MDE Model: DPT-hybrid [38]. Optimizer: Adam [21]. NeRF Learning Rate: 1e-2. MDE Learning Rate: 1e-5. LR Schedule: Cosine warmup [S2, unofficial].

#### NeRF Model Architecture
- **Definition:** The neural network architecture for NeRF, consisting of dense layers with ReLU activations, potentially using view directions as input [S3, unofficial].
- **Parameters:** `D`: The depth of the network (number of hidden layers). Default is 8. `input_ch_views`: The number of input channels for view directions. Default is 3. `output_ch`: The number of output channels. Default is 4 (RGB + density). `use_viewdirs`: Boolean flag to determine if view directions are used as input to the network [S3, unofficial].

#### S3-NeRF
- **Definition:** A method using shadow and shading cues to infer scene geometry and enable single-image NeRF training [S1].
- **Steps:** Employ a UNISURF-based occupancy field 3D representation instead of density. Use a modified physics-based rendering equation. Use occupancy-based shadow calculation [S1].

#### KiloNeRF-style Grid Distillation
- **Definition:** Distills a large teacher NeRF into a spatially partitioned grid of tiny MLPs to enable fast, adaptive evaluation by mapping 3D positions to local student networks [S4, unofficial].
- **Steps:** Initialize a dictionary mapping 3D grid cell indices (i,j,k) to TinyMLP instances. For each training iteration, sample a random ray and generate num_samples stratified samples along it. Compute the grid cell index for each sample by normalizing its position within the bounding box and scaling by grid resolution. Accumulate L2 loss between student and teacher outputs across all samples. Update all grid MLPs using the accumulated loss and the configured learning rate [S4, unofficial].
- **Parameters:** grid_resolution: 3D tuple defining the number of cells per axis, e.g., (16,16,16). num_distill_iterations: Number of distillation optimization steps, e.g., 1000. num_samples: Number of stratified samples per ray, e.g., 384. learning_rate: Optimization step size for grid MLP updates, e.g., 1e-3. bmin, bmax: Axis-aligned bounding box defining the scene bounds, e.g., [0,0,0] and [1,1,1] [S4, unofficial].

#### NeRF with Time Parameter
- **Steps:** Add a time parameter to the model inputs to adapt NeRF for dynamic scenes. Positionally encode the time parameter and concatenate it with the positional encoding of spatial coordinates $\gamma_x(\mathbf{x})$ [S5].
- **Parameters:** Train using the configuration reported for NeRF's real forward-facing experiments [S5].
- **Comparison:** Adding a time parameter improves quality over vanilla NeRF but still lacks detail, suffers from blurry predictions, and fails to reason about scene dynamics [S5].

#### StylizedNeRF
- **Steps:** Utilizes a mutual learning strategy to optimize both the stylized NeRF and the 2D stylization network. Handles ambiguities of the 2D stylized results via learnable latent codes, ensuring consistency in geometry [S6].

#### NeRF-Editing
- **Definition:** The first mesh-based shape deformation method, leveraging explicit representations for scene geometry edits and implicit representations for realistic rendering effects [S6].
- **Steps:** 1. Extract explicit triangular mesh from NeRF. 2. Enable intuitive user-driven deformations through classic ARAP deformation method. 3. Generate tetrahedral mesh around triangular mesh to propagate deformations spatially. 4. Employ tetrahedral vertex interpolation to transform discrete deformations into continuous field. 5. Ensure rays passing through mesh bend according to user adjustments [S6].

#### NeuralEditor
- **Definition:** A method employing a point cloud-guided NeRF model for shape manipulation, leveraging K-D trees and deterministic integration strategy for accurate point cloud-based rendering, with Phong reflection modeling to enhance color fidelity and geometric detail [S6].
- **Steps:** 1. Employ point cloud-guided NeRF model. 2. Leverage K-D trees. 3. Use deterministic integration strategy. 4. Achieve accurate point cloud-based rendering. 5. Apply Phong reflection modeling [S6].

#### Shared G-MLP
- **Definition:** A shared geometry MLP that enables the constraint of multi-view consistency to be propagated from the NeRF branch to the detection branch [S7].
- **Number:** Without the shared G-MLP, performance drops from 50.1 to 48.1 mAP@.25, as the influence of multi-view consistency is only propagated into the image backbone [S7].
