# SLS4D

Also called: Sparse Latent Space for 4D Novel View Synthesis

## Overview
SLS4D is a method for 4D novel view synthesis that represents dynamic scenes using a sparse, compact, and informative latent feature space, significantly reducing the number of network parameters compared to previous state-of-the-art methods [S1]. It distinguishes itself from siblings like [Gear-NeRF](13848-gear-nerf.md) and [TiNeuVox](18515-st-nerf.md) by abandoning dense voxel grids or direct coordinate-based feature lookups in favor of a finite set of globally learnable latent codes interpolated via attention, thereby decoupling spatial and temporal dynamics more efficiently [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of input images with known camera poses and timestamps $t$.
*   **Outputs:** Volume density $\sigma$ and view-dependent color $\mathbf{c}$ for a ray $\mathbf{r}(s) = \mathbf{o} + s\mathbf{d}$ at time $t$, computed via the standard volume rendering integral [G].

**Data Structures:**
1.  **Time Slot Features ($\mathbf{T}$):** A dense learnable tensor of shape $(T, D_t)$, where $T$ is the number of time slots and $D_t$ is the temporal feature dimension.
2.  **Spatial Latent Codes ($\mathbf{L}$):** A sparse set of globally learnable latent codes of shape $(B, D_s)$, where $B$ is the number of latent features and $D_s$ is the spatial feature dimension.
3.  **Deformation Field ($\mathcal{M}_d$):** A 7-layer Multi-Layer Perceptron (MLP).
4.  **Interpolator Decoder ($\mathcal{M}_i$):** A network using GeGLU (bilinear Gated Linear Unit) activation.

**Parameters:**
*   $B = 512$: Number of latent features.
*   $T = 512$: Number of time slots.
*   These values are chosen because the total time of scenes in datasets like HyperNeRF is significantly longer than in D-NeRF [S1].

**Numbered Steps:**

1.  **Temporal Encoding:** For a query time $t$, retrieve or interpolate the corresponding time slot feature $\mathbf{t}_{feat}$ from the dense learnable time slot features $\mathbf{T}$. This ensures smooth transitions between timestamps [S1].
2.  **Deformation Field Prediction:** To handle dynamic motion, the method decouples time and space. The deformation field $\mathcal{M}_d$ takes the 4D coordinate $(x, y, z, t)$ as input. However, to leverage the time slots, the input is effectively processed such that the deformation predicts a 3D displacement $(\Delta x, \Delta y, \Delta z)$. The output is the deformed position $\mathbf{p}' = (x + \Delta x, y + \Delta y, z + \Delta z)$ [S1].
    *   *Note:* The deformation field is fitted with linear MLPs. The time slots ensure the smoothness of dense temporal information in the deformation field [S1].
3.  **Spatial Feature Interpolation (Attention):**
    *   The deformed position $\mathbf{p}'$ is used to query the sparse spatial latent space.
    *   A query feature $\mathbf{q}$ is derived from $\mathbf{p}'$ (and potentially the time slot feature, though the text emphasizes the spatial position's query feature) [S1].
    *   The weights $\alpha_i$ for each latent code $\mathbf{l}_i \in \mathbf{L}$ are determined by the attention mechanism:
        $$ \alpha_i = \text{softmax}\left(\frac{\mathbf{q} \cdot \mathbf{k}_i}{\sqrt{d}}\right) $$
        where $\mathbf{k}_i$ is the key value associated with the $i$-th latent code, and $d$ is the dimensionality [S1].
    *   The aggregated spatial feature $\mathbf{f}_{spatial}$ is the weighted sum of the latent codes:
        $$ \mathbf{f}_{spatial} = \sum_{i=1}^{B} \alpha_i \mathbf{l}_i $$
    *   This approach abandons direct coordinate relationships, relying instead on relative relationships in the latent feature space, which is more compact and informative [S1].
4.  **Radiance Field Prediction:** The aggregated spatial feature $\mathbf{f}_{spatial}$ and the time slot feature $\mathbf{t}_{feat}$ are concatenated and passed through the Interpolator Decoder $\mathcal{M}_i$.
    *   The decoder uses GeGLU activation: $\text{GeGLU}(\mathbf{x}) = \mathbf{x}_1 \otimes \text{Gelu}(\mathbf{x}_2)$, where $\mathbf{x}$ is split into two halves [S1].
    *   The output is the volume density $\sigma$ and view-dependent color $\mathbf{c}$ [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SLS4D:
    def __init__(self, B=512, T=512, dim_latent=256, dim_time=256):
        """
        Initialize SLS4D model.
        B: Number of spatial latent codes.
        T: Number of time slots.
        dim_latent: Dimension of spatial latent codes.
        dim_time: Dimension of time slot features.
        """
        self.B = B
        self.T = T
        
        # Data Structures
        # Dense learnable time slot features
        self.time_slots = nn.Parameter(torch.randn(T, dim_time))
        
        # Sparse spatial latent codes
        self.latent_codes = nn.Parameter(torch.randn(B, dim_latent))
        
        # Deformation Field: 7-layer MLP
        # Input: 4D coord (x,y,z,t) -> Output: 3D displacement (dx,dy,dz)
        self.deformation_mlp = self._build_mlp(4, 256, 3, layers=7)
        
        # Interpolator Decoder: Uses GeGLU
        # Input: Concat(Spatial Feature, Time Feature) -> Output: (sigma, color)
        self.decoder = self._build_decoder(dim_latent + dim_time)
        
        # Loss function for temporal smoothness
        self.tv_loss_fn = self._total_variance_loss

    def _build_mlp(self, input_dim, hidden_dim, output_dim, layers=7):
        """Builds a linear multi-layer perceptron."""
        layers_list = []
        current_dim = input_dim
        for _ in range(layers - 1):
            layers_list.append(nn.Linear(current_dim, hidden_dim))
            layers_list.append(nn.ReLU())
            current_dim = hidden_dim
        layers_list.append(nn.Linear(current_dim, output_dim))
        return nn.Sequential(*layers_list)

    def _build_decoder(self, input_dim):
        """Builds the interpolator decoder with GeGLU."""
        # GeGLU is a bilinear GLU. We assume a simple MLP structure with GeGLU activations.
        # The exact architecture isn't fully specified beyond "GeGLU instead of GeLU or MLP".
        # We implement a standard MLP with GeGLU activations.
        hidden_dim = 256
        layers_list = []
        layers_list.append(nn.Linear(input_dim, hidden_dim))
        layers_list.append(nn.GeGLU()) # Using PyTorch's GeGLU or custom implementation
        layers_list.append(nn.Linear(hidden_dim, hidden_dim))
        layers_list.append(nn.GeGLU())
        layers_list.append(nn.Linear(hidden_dim, 4)) # sigma (1) + color (3)
        return nn.Sequential(*layers_list)

    def _total_variance_loss(self, tensor):
        """Computes Total Variance loss for temporal smoothness."""
        # TV loss encourages smoothness in the time slot features
        return torch.mean(torch.abs(tensor[1:] - tensor[:-1]))

    def forward(self, xyz, t, rays_d=None):
        """
        Forward pass.
        xyz: (N, 3) 3D coordinates
        t: (N,) timestamps
        """
        # Step 1: Temporal Encoding
        # Normalize t to index range [0, T-1]
        # Assuming t is normalized to [0, 1] or similar, we map it to indices.
        # For simplicity, assume t is already scaled to [0, T-1] or we interpolate.
        # The paper mentions "dense learnable time slot features".
        # We interpolate between time slots based on t.
        t_float = t * (self.T - 1)
        t_low = t_float.floor().long()
        t_high = t_float.ceil().long()
        t_low = torch.clamp(t_low, 0, self.T - 1)
        t_high = torch.clamp(t_high, 0, self.T - 1)
        t_frac = t_float - t_low.float()
        
        t_feat_low = self.time_slots[t_low]
        t_feat_high = self.time_slots[t_high]
        t_feat = t_feat_low + t_frac.unsqueeze(1) * (t_feat_high - t_feat_low)
        
        # Step 2: Deformation Field
        # Input to deformation MLP: (x, y, z, t_index_or_feature)
        # The paper says input is 4D coordinate (x,y,z,t).
        # We use the raw t or a normalized version.
        xyz_t = torch.cat([xyz, t.unsqueeze(1)], dim=1) # (N, 4)
        displacement = self.deformation_mlp(xyz_t) # (N, 3)
        xyz_deformed = xyz + displacement
        
        # Step 3: Spatial Feature Interpolation
        # Query feature from deformed position
        # The paper says "query feature of the 3D position".
        # We can use the deformed coordinates directly or pass them through a small network.
        # Assuming direct use for query generation or simple embedding.
        # Let's assume the query is derived from xyz_deformed.
        # To match the attention mechanism description:
        # q = f(xyz_deformed). If f is identity, q = xyz_deformed.
        # However, dimensions must match. Latent codes are dim_latent.
        # We project xyz_deformed to dim_latent.
        query_proj = nn.Linear(3, self.latent_codes.shape[1])(xyz_deformed)
        q = query_proj # (N, dim_latent)
        
        # Keys are the latent codes themselves
        k = self.latent_codes # (B, dim_latent)
        
        # Attention weights
        # alpha_i = softmax(q . k_i / sqrt(d))
        scores = torch.matmul(q, k.t()) / (self.latent_codes.shape[1] ** 0.5) # (N, B)
        alpha = F.softmax(scores, dim=1) # (N, B)
        
        # Aggregated spatial feature
        f_spatial = torch.matmul(alpha, self.latent_codes) # (N, dim_latent)
        
        # Step 4: Radiance Field Prediction
        # Concatenate spatial feature and time feature
        input_decoder = torch.cat([f_spatial, t_feat], dim=1)
        output = self.decoder(input_decoder) # (N, 4)
        
        sigma = output[:, 0:1]
        color = output[:, 1:4]
        
        return sigma, color

    def compute_loss(self, sigma_pred, color_pred, sigma_gt, color_gt, time_slots):
        """Compute training loss."""
        # Reconstruction loss
        color_loss = F.mse_loss(color_pred, color_gt)
        # Density loss (optional, depending on ground truth)
        # sigma_loss = F.mse_loss(sigma_pred, sigma_gt)
        
        # Temporal smoothness loss (TV Loss on time slots)
        tv_loss = self.tv_loss_fn(time_slots)
        
        total_loss = color_loss + 0.1 * tv_loss # Weight for TV loss not specified, assumed small
        return total_loss

    def train_step(self, optimizer, xyz, t, color_gt):
        optimizer.zero_grad()
        sigma, color = self.forward(xyz, t)
        loss = self.compute_loss(sigma, color, None, color_gt, self.time_slots)
        loss.backward()
        optimizer.step()
        return loss.item()
```

**Edge Cases and Pitfalls:**
*   **Long-Duration Inputs:** Excessively long-duration inputs may struggle to fit data adequately with a small number of parameters ($B=512, T=512$) [S1]. A growing NeRF strategy (adaptively splitting spatial dimensions) is suggested as a solution [S1].
*   **Absence of Deformation Fields:** Without deformation fields (SLS4Dnd), the absence of decoupling between time and space poses challenges in extracting information for reconstruction, leading to quality decline [S1].
*   **Removing Time Slots:** Removing time slots (SLS4Dnf) results in degradation of rendering quality because they ensure smooth transitions in deformation fields [S1].
*   **Decoder Choice:** Using only GeLU (SLS4Dge) or a plain MLP (SLS4Dml) as the interpolator decoder results in inferior performance compared to GeGLU, which offers higher fitting capacity for complex nonlinear relationships [S1].
*   **Learning Rate:** Cosine decay alone is unstable; exponential decay alone may get stuck in local optima. The method uses a combined cosine*exp decay function [S1].

## Operating characteristics
*   **Time Complexity:** Training time is approximately 3 hours to achieve results similar to V4D (which takes 7 hours) on an Nvidia 4090, with a total of 6 hours to reach final results [S1].
*   **Memory Complexity:** The method uses approximately 6% of the parameters of the previous SOTA work V4D. On the D-NeRF dataset, SLS4D has ~0.25M parameters compared to V4D's ~0.1M (Note: The text says 6% of V4D, but V4D is 0.1M and SLS4D is 0.25M, which is 2.5x. *   **Performance:** On the D-NeRF dataset, SLS4D achieves PSNR 34.84, SSIM 0.981, and LPIPS 0.025 [S1].
*   **Strengths:** Significant reduction in network parameters; superior rendering quality; efficient training time; effective handling of global dynamics via sparse latent space.
*   **Limitations:** Struggles with excessively long-duration scenes due to parameter constraints; requires careful tuning of learning rate decay (cosine*exp) to avoid instability or local optima [S1].

## Background
SLS4D was introduced in the paper "SLS4D: Sparse Latent Space for 4D Novel View Synthesis" [S1]. It builds upon the principles of dynamic NeRFs, specifically addressing the limitations of dense voxel grids and direct coordinate-based feature lookups by introducing a sparse latent space representation. The method was developed to reduce the computational and memory burden of dynamic 3D representation while maintaining high-quality novel view synthesis. It is particularly relevant for AR/VR applications and cultural heritage protection [S1].
