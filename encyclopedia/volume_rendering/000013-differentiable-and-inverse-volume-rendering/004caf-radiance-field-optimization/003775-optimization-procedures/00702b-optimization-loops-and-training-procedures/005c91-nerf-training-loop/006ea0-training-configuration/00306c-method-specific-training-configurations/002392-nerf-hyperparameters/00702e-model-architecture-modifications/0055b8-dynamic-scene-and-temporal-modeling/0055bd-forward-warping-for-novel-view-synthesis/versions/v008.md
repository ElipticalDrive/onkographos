# Forward Warping for Novel View Synthesis

Also called: Canonical Field Forward Warping, Forward Flow

## Overview
Forward Warping for Novel View Synthesis is a method for rendering dynamic scenes by modeling a static "canonical" radiance field and differentially warping it to target time steps [S1]. It solves the many-to-one and one-to-many mapping ambiguities inherent in dynamic scene reconstruction by using average splatting and an inpaint network to handle occlusions and voids created during warping [S1]. Unlike backward-flow methods such as NDVG, this approach explicitly constructs a deformation flow from the canonical space to the target time, achieving state-of-the-art performance on canonical frames and generalizing well to unseen times [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   A set of multi-view images $\{I_t\}$ captured at various time steps $t$.
*   Camera poses $\{P_t\}$ for each time step.
*   A canonical time step $t_{can}$ (first frame for D-NeRF, middle frame for HyperNeRF) [S1].

**Outputs:**
*   Rendered RGB images for arbitrary novel views and arbitrary time steps.
*   Learned canonical radiance field, deformation fields, and trajectory parameters [S1].

### Data Structures
The method relies on several voxel grids and neural networks. All voxel grids are 3D structures indexed by spatial coordinates.

1.  **Canonical Radiance Feature Grid ($VR_f$):** Stores the latent radiance features for each voxel.
    *   Dimension: 12 [S1].
2.  **Canonical Coordinate Grid ($VR_{Can}$):** Stores the 3D spatial coordinates of each voxel center.
    *   Dimension: 3 [S1].
3.  **Canonical Density Grid ($V_{\sigma}^{Can}$):** Stores the volume density $\sigma$ for each voxel.
    *   Dimension: 1 [S1].
4.  **Canonical Color Feature Grid ($V_{cf}^{Can}$):** Stores color features used by the view-dependent network.
    *   Dimension: 3 or 12, depending on the training stage [S1].
5.  **Canonical Deformation Feature Grid ($VD_f^{Can}$):** Stores features used to predict deformation.
    *   Dimension: 0 for D-NeRF dataset, 12 for HyperNeRF dataset [S1].
6.  **Trajectory Grid ($VT_t$):** Stores Discrete Cosine Transform (DCT) parameters defining the trajectory of each voxel over time.
    *   Number of DCT bases: 15 for D-NeRF, 25 for HyperNeRF [S1].
7.  **Deformation Flow Grid ($V_{flow}$):** Stores the deformation flow vector $\mathbf{d}$ for each voxel, representing the displacement from the canonical position to the position at time $t$.
    *   Dimension: 3 [S1].
8.  **Warped Radiance Field ($VR_t$):** The radiance field at time $t$, obtained by warping $VR_f$ using $V_{flow}$.
9.  **Inpainted Radiance Field ($VR_t^{Inp}$):** The field after applying the inpaint network to $VR_t$ to fill holes.
10. **Upsampled Radiance Field ($VR_t^{Up}$):** The field after upsampling $VR_t^{Inp}$.

### Neural Networks
Four networks are used:

1.  **Canonical Radiance Network ($F_{\theta_1}$):**
    *   **Input:** Concatenation of radiance feature sampled from $VR_f$ (dim 12) and embedded position $\gamma(\mathbf{x})$ (dim 33).
    *   **Output:** Density $\sigma$ (dim 1) and color feature $\mathbf{c}_{feat}$ (dim 3 or 12) [S1].
    *   **Structure:** 3-layer MLP, width 128, ReLU activation [S1].
2.  **Canonical Deformation Network ($F_{\theta_2}$):**
    *   **Input:** Concatenation of deformation feature sampled from $VD_f^{Can}$ (dim 0 or 12) and embedded position $\gamma(\mathbf{x})$ (dim 33).
    *   **Output:** DCT coefficients for the trajectory [S1].
    *   **Structure:** 4-layer MLP, width 64 [S1].
3.  **View Dependent Color Network ($F_{\theta_4}$):**
    *   **Input:** Concatenation of embedded view direction $\gamma(\mathbf{d})$ (dim 27) and color feature $\mathbf{c}_{feat}$ (dim 12).
    *   **Output:** RGB color $\mathbf{c}$ (dim 3) [S1].
    *   **Structure:** 2-layer MLP, width 64 [S1].
4.  **Inpaint Network ($F_{\theta_3}$):**
    *   **Input:** Warped radiance field $VR_t$.
    *   **Output:** Inpainted radiance field $VR_t^{Inp}$ [S1].
    *   **Structure:** UNet with 4 encode layers and 3 decode layers, plus an upsample layer. Each encode layer has one max pooling layer and two convolution layers (Instance Norm + Conv + ReLU). Each decode layer has one up-sample interpolation layer and two convolution layers (Instance Norm + Conv + ReLU) [S1].

### Positional Encoding
The positional encoding $\gamma(\mathbf{x}, d_1, d_2)$ is defined as:
$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$
For this method:
*   Position embedding dimension is 33.
*   View direction embedding dimension is 27 [S1].

### Training Strategy: Coarse-to-Fine
The training is divided into a coarse stage and a fine stage.

**Coarse Stage:**
*   **Goal:** Learn proxy geometry to calculate the bounding box for the fine stage.
*   **Voxel Grid Resolution:** $6^3$ [S1].
*   **Inpaint Network:** Not used [S1].
*   **Iterations:** 20,000 [S1].
*   **Loss Weights:** $w_1=10^{-1}, w_2=10^{-2}, w_3=10^{-5}, w_4=0, w_5=10^{-6}, w_6=10^{-3}, w_7=10^{-1}$ [S1].

**Fine Stage:**
*   **Goal:** High-fidelity rendering.
*   **Voxel Grid Resolution:** $8^3$ for D-NeRF, $7^3$ for HyperNeRF [S1].
*   **Inpaint Network Scale:** 2.0 [S1].
*   **Iterations:** 100,000 [S1].
*   **Loss Weights:** $w_1=10^{-2}, w_2=10^{-3}, w_3=10^{-5}, w_4=10^{-5}, w_5=10^{-6}, w_6=10^{-3}, w_7=10^{-1}$ [S1].
*   **Progressive Training:** Start with 10 images closest to the canonical time step. Add one image with the closest time step every 60 iterations [S1].

### Algorithm Steps

1.  **Initialization:**
    *   Initialize voxel grids $VR_f, VR_{Can}, V_{\sigma}^{Can}, V_{cf}^{Can}, VD_f^{Can}, VT_t, V_{flow}$ [S1].
    *   Initialize networks $F_{\theta_1}, F_{\theta_2}, F_{\theta_4}, F_{\theta_3}$ [S1].
    *   Set canonical time $t_{can}$ (first frame for D-NeRF, middle for HyperNeRF) [S1].

2.  **Canonical Field Estimation:**
    *   For a sampled point $\mathbf{x}$ in canonical space:
        *   Sample radiance feature $\mathbf{h} = VR_f(\mathbf{x})$ [S1].
        *   Compute $\mathbf{h}_{out} = F_{\theta_1}(\text{concat}(\mathbf{h}, \gamma(\mathbf{x})))$ [S1].
        *   Extract density $\sigma = \mathbf{h}_{out}[0]$ and color feature $\mathbf{c}_{feat} = \mathbf{h}_{out}[1:]$ [S1].
        *   Store $\sigma$ in $V_{\sigma}^{Can}(\mathbf{x})$ and $\mathbf{c}_{feat}$ in $V_{cf}^{Can}(\mathbf{x})$ [S1].

3.  **Deformation and Trajectory Prediction:**
    *   For each voxel in $VD_f^{Can}$:
        *   Sample deformation feature $\mathbf{d}_{feat} = VD_f^{Can}(\mathbf{x})$ [S1].
        *   Compute DCT coefficients $\mathbf{w} = F_{\theta_2}(\text{concat}(\mathbf{d}_{feat}, \gamma(\mathbf{x})))$ [S1].
        *   Store $\mathbf{w}$ in $VT_t(\mathbf{x})$ [S1].
    *   To compute deformation flow $V_{flow}$ at time $t$ for a point $\mathbf{x}$:
        *   Retrieve DCT coefficients $\mathbf{w}$ from $VT_t(\mathbf{x})$ [S1].
        *   Compute trajectory $\mathbf{x}(t)$ using DCT basis functions and $\mathbf{w}$ [S1].
        *   Compute flow $\mathbf{d} = \mathbf{x}(t) - \mathbf{x}$ [S1].
        *   Store $\mathbf{d}$ in $V_{flow}(\mathbf{x})$ [S1].

4.  **Forward Warping (Average Splatting):**
    *   For a target time $t$:
        *   Initialize empty grid $VR_t$ [S1].
        *   For each voxel $\mathbf{x}$ in canonical space:
            *   Retrieve feature $\mathbf{h} = VR_f(\mathbf{x})$ [S1].
            *   Compute flow $\mathbf{d} = V_{flow}(\mathbf{x})$ [S1].
            *   Compute target position $\mathbf{x}' = \mathbf{x} + \mathbf{d}$ [S1].
            *   Splat $\mathbf{h}$ to $\mathbf{x}'$ in $VR_t$ using average splatting [S1].
            *   *Note:* Average splatting is used instead of softmax splatting to avoid complexity and because the UNet refines the grid sufficiently [S1].

5.  **Inpainting:**
    *   Input $VR_t$ to $F_{\theta_3}$ to produce $VR_t^{Inp}$ [S1].
    *   Upsample $VR_t^{Inp}$ to produce $VR_t^{Up}$ [S1].

6.  **Rendering:**
    *   For each ray $\mathbf{r}$:
        *   Sample points $w_k$ along $\mathbf{r}$ in the warped space [S1].
        *   For each point $w_k$:
            *   Retrieve density $\sigma(w_k)$ from $V_{\sigma}^{Can}$ (warped) [S1].
            *   Retrieve color feature $\mathbf{c}_{feat}(w_k)$ from $VR_t^{Up}$ or $VR_t^{Inp}$ [S1].
            *   Compute color $\mathbf{c}(w_k) = F_{\theta_4}(\text{concat}(\gamma(\mathbf{d}_r), \mathbf{c}_{feat}(w_k)))$ [S1].
        *   Compute transmittance $T(w_k)$ and opacity $\alpha_k$ [S1].
        *   Compute accumulated weight $A_{accum}(k) = T(w_k) \sigma(w_k) \delta_k$ [S1].
        *   Render color $\mathbf{C}(\mathbf{r}) = \sum A_{accum}(k) \mathbf{c}(w_k)$ [S1].

### Loss Functions

1.  **Point-wise Color Loss ($\mathcal{L}_{ptc}$):**
    Supervises the color of sampled points weighted by their accumulation.
    $$
    \mathcal{L}_{ptc} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{C}_{\text{Up}}(\mathbf{r}))
    $$
    Where:
    $$
    \mathcal{L}(\mathbf{C}(\mathbf{r})) = \frac{1}{K} \sum_{k=1}^{K} A_{\text{accum}}(k) \|\mathbf{c}(w_k) - \mathbf{C}_{\text{gt}}(\mathbf{r})\|_2^2
    $$
    $$
    A_{\text{accum}}(k) = T(w_k) \, \sigma(w_k) \delta_k
    $$
    $\mathbf{C}_{\text{Inp}}$ and $\mathbf{C}_{\text{Up}}$ are colors rendered from the inpainted and upsampled fields respectively [S1].

2.  **Background Entropy Loss ($\mathcal{L}_{bg}$):**
    Encourages densities to concentrate on foreground or background.
    $$
    \mathcal{L}_{bg} = \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Inp}}(\mathbf{r})) + \frac{1}{|\mathcal{R}|} \sum_{r \in \mathcal{R}} \mathcal{L}(\mathbf{A}_{\text{Up}}(\mathbf{r}))
    $$
    Where:
    $$
    \mathcal{L}(\mathbf{A}(\mathbf{r})) = -\frac{1}{K-1} \sum_{k=1}^{K-1} [ A_{\text{accum}}(k)\log(A_{\text{accum}}(k)) + (1-A_{\text{accum}}(k))\log(1-A_{\text{accum}}(k)) ]
    $$
    [S1].

3.  **Total Loss:**
    $$
    \mathcal{L} = \mathcal{L}_{photo} + w_1\mathcal{L}_{ptc} + w_2\mathcal{L}_{bg} + w_3\mathcal{L}_{flow} + w_4\mathcal{L}_{vdiff} + w_5\mathcal{L}_{tv}(\mathbf{V}_{\sigma}^{\text{Can}}) + w_6\mathcal{L}_{tv}(\mathbf{V}_{\text{flow}}^t) + w_7\mathcal{L}_{tv}(\mathbf{D})
    $$
    $\mathcal{L}_{photo}$ is the standard photometric loss. $\mathcal{L}_{flow}$ and $\mathcal{L}_{vdiff}$ are flow and velocity difference losses (not detailed in the provided notes, but present in the formula). $\mathcal{L}_{tv}$ is Total Variation loss [S1].

### Parameters and Settings

*   **Learning Rate:** $10^{-1}$ for voxel grids, $10^{-3}$ for networks [S1].
*   **Optimizer:** Adam [S1].
*   **Canonical Time:** First frame for D-NeRF, middle frame for HyperNeRF [S1].
*   **Coarse Stage Voxel Number:** $6^3$ [S1].
*   **Coarse Stage Inpaint Scale:** 1.5 [S1].
*   **Coarse Stage Iterations:** 20,000 [S1].
*   **Fine Stage Voxel Number:** $8^3$ for D-NeRF, $7^3$ for HyperNeRF [S1].
*   **Fine Stage Inpaint Scale:** 2.0 [S1].
*   **Fine Stage Iterations:** 100,000 [S1].

### Edge Cases and Pitfalls

*   **Memory Consumption:** High, especially for real scenes [S1].
*   **Training Speed:** Slow, approximately one day per scene on a GeForce RTX 3090 [S1].
*   **Coarse Stage Importance:** Removing the coarse stage causes significant performance drops because the voxel grid covers a larger space without proxy geometry filtering [S1].
*   **Inpaint Network Importance:** Removing the inpaint network significantly reduces performance (e.g., Hell Warrior PSNR drops from 27.71 to 27.15) [S1].
*   **Canonical Time Selection:** Setting the canonical time to the middle frame improves performance for HyperNeRF as the geometry is closer to other time steps [S1].

## Operating characteristics

*   **Time Complexity:** Training is slow, taking approximately one day per scene on a GeForce RTX 3090 [S1].
*   **Memory Complexity:** High memory consumption, particularly for real-world scenes [S1].
*   **Model Size:** 260M parameters for D-NeRF, 440M for HyperNeRF [S1].
*   **Rendering Speed:** 7 seconds per image for D-NeRF, 15 seconds per image for HyperNeRF [S1].
*   **Strengths:** State-of-the-art performance on public datasets, especially for canonical frames. Clear advantage over backward-flow methods like NDVG [S1].
*   **Limitations:** High memory usage and slow training speed [S1].
*   **When to Use:** When high-quality novel view synthesis for dynamic scenes is required, particularly for canonical frames, and computational resources are sufficient for long training times [S1].
*   **When Not to Use:** When real-time rendering or low-latency training is required, or when memory is constrained [S1].

## Background

Forward Warping for Novel View Synthesis was proposed in the paper "Forward Flow for Novel View Synthesis of Dynamic Scenes" [S1]. It builds upon the canonical field representation introduced in D-NeRF and HyperNeRF [S1]. The method addresses the limitations of backward-flow methods by explicitly warping the canonical field forward in time, using average splatting and an inpaint network to handle occlusions and voids [S1]. It has been evaluated on the D-NeRF and HyperNeRF datasets, as well as a newly built Lego Complete Dataset [S1].
