# Neural Multi-View Image Reconstruction with Hash Encoding

Also called: Ours (multi-view)

## Overview
This method performs neural multi-view image reconstruction and novel view synthesis by combining a hash-encoded geometry representation with a separate light field network, utilizing signed distance functions (SDF) for explicit surface constraints [S1]. It distinguishes itself from sibling methods like [Voxel-based Radiance Fields](11470-voxel-based-radiance-fields.md) and [Lightning NeRF](14134-lightning-nerf.md) by replacing dense voxel grids with a sparse, multi-resolution hash table, which significantly reduces memory usage and training time while preserving high-frequency geometric details in textureless areas [S1]. Unlike [NeRF](11469-nerf.md) which suffers from noisy geometry due to a lack of direct surface constraints, this approach uses SDF thresholding to extract clean meshes and synthesizes views via volume or surface rendering [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of multi-view images with known camera parameters (view direction $\mathbf{v}$).
*   **Outputs:** A reconstructed 3D geometry (mesh) and novel view images.

**Data Structures:**
1.  **Hash Encoding Table:** A multi-resolution hash table with $L=16$ layers [S1]. Each layer maps hashed spatial coordinates to a feature vector of dimension $D=2$ [S1]. The hash function maps input coordinates to indices in the table, allowing for sparse storage of features [S1].
2.  **Geometry Network:** A Multi-Layer Perceptron (MLP) with 6 hidden layers [S1].
3.  **Light Field Network:** A Multi-Layer Perceptron (MLP) with 4 hidden layers, each containing 256 units [S1].

**Parameters:**
*   Fourier positional encoding dimension: 6 [S1].
*   Hash encoding layers: 16 [S1].
*   Hash encoding feature dimension: 2 per grid feature in each layer [S1].
*   Loss weights: $\alpha = 0.1$, $\beta = 0.1$, $\gamma = 5 \times 10^{-4}$ [S1].
*   Marching Cubes resolution: $512^3$ [S1].
*   Training hardware: GeForce RTX 3090 GPU [S1].

**Algorithm Steps:**

1.  **Initialization:** Initialize the hash table and the weights of the Geometry and Light Field MLPs. The geometry network initialization follows the strategy from [S1] (referenced as Ref. [12] in the source), which modifies the initialization used in NeuS [S1].

2.  **Ray Sampling:** For each training ray, sample points using a hierarchical sampling strategy [S1]. This involves sampling points near the expected surface based on the current SDF estimate, similar to the approach in NeuS [S1].

3.  **Invalid Point Elimination:** Calculate the mean of the SDF values of the sampled points on each ray. Use this mean as a threshold to eliminate invalid sampled points that are far from the surface [S1].

4.  **Feature Retrieval (Hash Encoding):** For each valid sample point $\mathbf{x}$:
    *   Apply Fourier positional encoding to $\mathbf{x}$ with dimension 6 [S1].
    *   Compute the hash encoding $\text{enc}(\theta_h, \mathbf{x})$ by querying the multi-resolution hash table [S1]. This involves hashing $\mathbf{x}$ at each of the 16 resolutions and interpolating the features (dimension 2) from the hash table [S1].

5.  **Geometry Network Forward Pass:**
    *   Input to the Geometry MLP: Concatenation of the Fourier-encoded position and the hash-encoded features [S1].
    *   The Geometry MLP consists of 6 layers [S1].
    *   Output: The SDF value $s$ and a geometry feature vector $\mathbf{f}_g$ [S1]. The SDF $s$ represents the signed distance to the surface.

6.  **Light Field Network Forward Pass:**
    *   Compute the surface normal $\mathbf{n}$ by taking the gradient of the SDF with respect to $\mathbf{x}$: $\mathbf{n} = \nabla s / \|\nabla s\|$ [S1].
    *   Input to the Light Field MLP: Concatenation of:
        *   Fourier positional encoding of the view direction $\mathbf{v}$ (dimension 6) [S1].
        *   Fourier positional encoding of the normal $\mathbf{n}$ (dimension 6) [S1].
        *   The geometry feature vector $\mathbf{f}_g$ from the Geometry Network [S1].
    *   The Light Field MLP consists of 4 hidden layers with 256 units each [S1].
    *   Output: The color $\mathbf{c}$ of the sample point [S1].

7.  **Volume Rendering:**
    *   Convert SDF values to opacity $\alpha_k$ and density $\sigma_k$ using the standard differentiable volume rendering formulation [S1]. Note: The source states the rendering pipeline remains the standard equation $\hat{C}(r) = \sum w_k \mathbf{c}_k$ with $\alpha_k = 1 - e^{-\sigma_k \delta_k}$ [S1], but explicitly uses SDF thresholding for geometry extraction. The specific conversion from SDF to $\sigma$ is not detailed in the provided text, but the method relies on the SDF for surface definition [S1].
    *   Render the image pixel color by compositing the colors and opacities of the sampled points along the ray [S1].

8.  **Loss Calculation:**
    *   Compute the loss using the weights $\alpha=0.1$, $\beta=0.1$, and $\gamma=5 \times 10^{-4}$ as defined in Eq. (8) of the source [S1]. The source does not explicitly define Eq. (8), but typically in such SDF-based methods, this includes photometric loss, SDF regularization, and consistency losses [S1].

9.  **Optimization:**
    *   Update the hash table features and MLP weights using gradient descent [S1].

10. **Geometry Extraction (Post-Training):**
    *   Extract the final mesh using the Marching Cubes algorithm on the learned SDF field at a resolution of $512^3$ [S1].

11. **Novel View Synthesis:**
    *   Synthesize novel view images by performing volume or surface rendering of the reconstructed geometry using the given novel view parameters [S1].

## Operating characteristics
*   **Time Complexity:** Training time is significantly faster than baselines. On the DTU dataset, the method takes 1.8 hours compared to 5.2 hours for IDR and 7.2 hours for NeuS [S1].
*   **Memory Complexity:** Memory usage is 5 GB, compared to 6.5 GB for IDR and 7 GB for NeuS [S1]. The hash encoding allows for sparse representation, reducing memory footprint.
*   **Performance:** Achieves a mean Chamfer-L2 distance of $0.72 \times 10^{-6}$ and a mean PSNR of 30.85 dB on multi-view reconstruction, outperforming IDR (CD: 0.90, PSNR: 23.20) and NeuS (CD: 0.77, PSNR: 29.66) [S1].
*   **Strengths:** Reconstructs more geometric detail than baselines, particularly in textureless areas where NeuS, IDR, VolSDF, and UNISURF perform poorly [S1]. Provides better high-frequency detail than NeRF, which suffers from rough geometry and noise [S1].
*   **Limitations:** The method relies on the quality of the hash encoding and the SDF thresholding. The specific hash function and interpolation details are not provided, which may affect implementation reproducibility [S1].

## Background
The method was proposed in "Multi-scale hash encoding based neural geometry representation" [S1]. It builds upon the principles of neural implicit representations, specifically leveraging the efficiency of hash encoding introduced in [S1] (referenced as the source of the hash encoding technique). The approach adapts the neural point cloud reconstruction framework to multi-view image reconstruction, using SDFs for explicit surface representation and hash encoding for efficient feature storage [S1].
