# Multi-input MLP (mi-MLP)
Also called: mi-MLP, per-layer inputs incorporation

## Overview
The multi-input MLP (mi-MLP) is a network architecture modification for Neural Radiance Fields that incorporates 3D location and viewing direction inputs into every layer of the MLP, rather than only at the input layer. It solves the overfitting problem in few-shot view synthesis by ensuring each layer is explicitly aware of input embeddings, which creates shorter paths between inputs and outputs. Unlike vanilla NeRF, which uses all layers to learn mappings implicitly, mi-MLP allows flexible connections that alleviate overfitting without reducing model capacity or harming high-frequency detail synthesis [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 5D coordinate vector $\mathbf{x}$, comprising the 3D spatial location and the 2D viewing direction.
*   **Output:** For the density network, the volume density $\sigma$. For the color network, the view-dependent color $\mathbf{c}$.

**Data Structures:**
The network consists of $L$ layers. Each layer $i$ (where $i > 1$) maintains standard MLP weights and biases but receives an additional input stream.
*   **Weights:** For layer $i$, the weight matrix $\mathbf{W}_i$ is split into two components: $\mathbf{W}_i^{j0}$ connecting the positional encoding to the $j$-th output neuron, and $\mathbf{W}_i^{j1}$ connecting the previous layer's output to the $j$-th output neuron.
*   **Biases:** A bias vector $\mathbf{b}_i \in \mathbb{R}^{d_2 \times 1}$ for layer $i$, where $d_2$ is the output dimension of the layer.
*   **Positional Encoding:** The input $\mathbf{x}$ is transformed via $\gamma_L(\mathbf{x})$.

**Positional Encoding:**
The positional encoding $\gamma_L(\mathbf{x})$ expands the input $\mathbf{x}$ into a higher-dimensional space to capture high-frequency details. It is defined as [S1]:

$$
\gamma_L(\mathbf{x}) = (\sin(2^0 \mathbf{x}), \cos(2^0 \mathbf{x}), \dots, \sin(2^{L-1} \mathbf{x}), \cos(2^{L-1} \mathbf{x}))
$$

where $L$ is a hyperparameter controlling the number of frequency bands. Note: In the source notation, $L$ is used for both the number of frequency bands and the number of layers in some contexts, but Eq. 2 specifically defines the encoding frequencies up to $2^{L-1}$. To avoid ambiguity with layer index $i$, let $K$ be the number of frequency bands in the encoding if distinct from layer count. However, the source uses $L$ for the encoding exponent limit. We retain the source's notation $\gamma_L(\mathbf{x})$ [S1].

**Numbered Steps:**
1.  **Encode Input:** Compute the positional encoding $\gamma_L(\mathbf{x})$ for the input 5D coordinate $\mathbf{x}$.
2.  **First Layer:** Compute the output of the first layer $f_1$ by applying the layer function $\phi_1$ to the encoded input:
    $$
    f_1 = \phi_1(\gamma_L(\mathbf{x}))
    $$
3.  **Subsequent Layers:** For each subsequent layer $i$ (from $2$ to $N$, where $N$ is the total number of layers):
    *   Retrieve the previous layer's output $f_{i-1}$.
    *   Compute the current layer's output $f_i$ by applying the layer function $\phi_i$ to both the previous output and the encoded input:
        $$
        f_i = \phi_i(f_{i-1}, \gamma_L(\mathbf{x}))
        $$
4.  **Final Output:** The final layer produces the density $\sigma$ or color $\mathbf{c}$ based on the network branch.

**Formulas:**
The computation for the $j$-th element of the output feature vector $f_i$ at layer $i$ is given by [S1]:

$$
\phi_i^j(\gamma_L(\mathbf{x})) = \epsilon\left\{ \mathbf{w}_i^j \begin{bmatrix} \gamma_L(\mathbf{x}) \\ \phi_{i-1}(\gamma_L(\mathbf{x})) \end{bmatrix}^T + \mathbf{b}_i \right\}
$$

Expanding the weight vector $\mathbf{w}_i^j = (\mathbf{w}_i^{j0}, \mathbf{w}_i^{j1})^T$, where $\mathbf{w}_i^{j0} \in \mathbb{R}^{1 \times d_1}$ and $\mathbf{w}_i^{j1} \in \mathbb{R}^{1 \times d_2}$:

$$
\phi_i^j(\gamma_L(\mathbf{x})) = \epsilon\left\{ \mathbf{w}_i^{j0}[\gamma_L(\mathbf{x})] + \mathbf{w}_i^{j1}[\phi_{i-1}(\gamma_L(\mathbf{x}))] + \mathbf{b}_i \right\}
$$

Where:
*   $\epsilon$ is the activation function (default ReLU) [S1].
*   $\mathbf{b}_i \in \mathbb{R}^{d_2 \times 1}$ is the bias vector [S1].
*   $d_1$ is the dimension of $\gamma_L(\mathbf{x})$ and $d_2$ is the dimension of $f_{i-1}$ and $f_i$ [S1].

**Parameters:**
*   **Frequency Bands ($L$ in $\gamma_L$):** Hyperparameter controlling the highest frequency in positional encoding. Not given in the sources.
*   **Weight Initialization:** Default PyTorch initialization is used. The source notes that this initialization satisfies the condition $\|\mathbf{w}_i^{j1}\|_1 \in (0, 1]$ [S1].

**Pitfalls and Edge Cases:**
*   **Gradient Amplitude:** During early training, vanilla MLPs result in similar gradient amplitudes for all layers. mi-MLP ensures that deeper layers (close to outputs) are updated with large gradients while shallower layers receive extremely small ones. This behavior is inherent to the architecture and helps prevent overfitting [S1].
*   **Dimension Mismatch:** The input $\gamma_L(\mathbf{x})$ must be concatenated with $f_{i-1}$ before applying weights. The dimensions $d_1$ and $d_2$ must be consistent across layers if the hidden size is constant.

**Pseudocode:**

```python
import torch
import torch.nn as nn
import math

def positional_encoding(x, num_bands):
    """
    Computes the positional encoding gamma_L(x).
    x: Tensor of shape (..., 5) representing 3D location and 2D view direction.
    num_bands: Integer L, the number of frequency bands.
    Returns: Tensor of shape (..., 2 * 5 * num_bands)
    """
    # x shape: (batch, 5)
    # We need to apply sin(2^k * pi * x) and cos(2^k * pi * x) for k in 0..L-1
    # Note: The source formula is sin(2^0 x)... which implies the argument is just 2^k * x.
    # Standard NeRF uses 2^d * pi * x. The source Eq 2 is:
    # gamma_L(x) = (sin(2^0 x), cos(2^0 x), ..., sin(2^{L-1} x), cos(2^{L-1} x))
    # It does not explicitly include pi in the source text for Eq 2, but standard practice often does.
    # We follow the source text literally: sin(2^k * x).
    
    frequencies = 2.0 ** torch.arange(num_bands, device=x.device).float()
    # frequencies shape: (num_bands,)
    
    # Expand x to (..., 1, 5) and frequencies to (1, num_bands, 1)
    # x: (batch, 5) -> (batch, 1, 5)
    # freq: (num_bands,) -> (1, num_bands, 1)
    
    scaled_x = x.unsqueeze(1) * frequencies.unsqueeze(0) # (batch, num_bands, 5)
    
    # Compute sin and cos
    sin_vals = torch.sin(scaled_x) # (batch, num_bands, 5)
    cos_vals = torch.cos(scaled_x) # (batch, num_bands, 5)
    
    # Interleave sin and cos: sin(2^0), cos(2^0), sin(2^1), cos(2^1)...
    # Stack along the last dimension
    encoded = torch.stack([sin_vals, cos_vals], dim=2) # (batch, num_bands, 2, 5)
    encoded = encoded.permute(0, 2, 1, 3) # (batch, 2, num_bands, 5)
    encoded = encoded.reshape(x.shape[0], -1) # (batch, 2 * num_bands * 5)
    
    return encoded

class MiMLPLayer(nn.Module):
    def __init__(self, input_dim, output_dim):
        super(MiMLPLayer, self).__init__()
        self.input_dim = input_dim
        self.output_dim = output_dim
        
        # Weights for input encoding (gamma_L(x))
        # w_i^{j0} in R^{1 x d1}
        self.weight_input = nn.Parameter(torch.randn(1, input_dim))
        
        # Weights for previous layer output (f_{i-1})
        # w_i^{j1} in R^{1 x d2}
        self.weight_prev = nn.Parameter(torch.randn(1, output_dim))
        
        # Bias
        self.bias = nn.Parameter(torch.zeros(output_dim))
        
        # Activation
        self.activation = nn.ReLU()

    def forward(self, prev_output, encoded_input):
        """
        prev_output: Tensor of shape (batch, output_dim) or (batch, 1) for first layer
        encoded_input: Tensor of shape (batch, input_dim)
        """
        # If prev_output is from the very first layer, it might be just the encoded input
        # But the structure is f_i = phi_i(f_{i-1}, gamma_L(x))
        
        # Compute linear combination
        # w_i^{j0} * gamma_L(x)
        term_input = torch.matmul(encoded_input, self.weight_input.T) # (batch, 1)
        
        # w_i^{j1} * f_{i-1}
        term_prev = torch.matmul(prev_output, self.weight_prev.T) # (batch, 1)
        
        # Sum and add bias
        out = term_input + term_prev + self.bias # (batch, 1)
        
        # Apply activation
        out = self.activation(out)
        
        return out

class MiMLP(nn.Module):
    def __init__(self, num_layers, hidden_dim, num_freq_bands):
        super(MiMLP, self).__init__()
        self.num_layers = num_layers
        self.hidden_dim = hidden_dim
        self.num_freq_bands = num_freq_bands
        
        # The input to the first layer is gamma_L(x)
        # The input to subsequent layers is (f_{i-1}, gamma_L(x))
        
        # Layer 1: Input is gamma_L(x)
        # Input dim for layer 1 is the dim of gamma_L(x)
        self.input_dim = 5 * 2 * num_freq_bands # 5 coords * 2 (sin/cos) * L bands
        
        # We need to define layers 1 to N
        # Layer 1 takes gamma_L(x) and outputs f_1
        # Layer i takes (f_{i-1}, gamma_L(x)) and outputs f_i
        
        # To implement this cleanly with the specific weight splitting:
        # We will create a list of MiMLPLayer modules.
        # However, MiMLPLayer above assumes a single output dim. 
        # If hidden_dim > 1, we need to handle vector outputs.
        # The source formula expands to element-wise j.
        # For implementation, we can use standard Linear layers but inject gamma_L(x) into every layer.
        
        # Let's rewrite the forward pass to be explicit about the architecture described.
        
        self.layers = nn.ModuleList()
        
        # Layer 1: phi_1(gamma_L(x))
        # This is a standard linear layer from input_dim to hidden_dim
        self.layers.append(nn.Linear(self.input_dim, hidden_dim))
        
        # Layers 2 to N: phi_i(f_{i-1}, gamma_L(x))
        # Each layer takes f_{i-1} (hidden_dim) and gamma_L(x) (input_dim)
        # And outputs f_i (hidden_dim)
        for _ in range(num_layers - 1):
            self.layers.append(nn.Linear(hidden_dim + self.input_dim, hidden_dim))
            
        self.activation = nn.ReLU()

    def forward(self, x):
        """
        x: Tensor of shape (batch, 5)
        """
        # 1. Encode input
        gamma_x = positional_encoding(x, self.num_freq_bands)
        
        # 2. First layer
        f_prev = self.layers[0](gamma_x)
        f_prev = self.activation(f_prev)
        
        # 3. Subsequent layers
        for i in range(1, self.num_layers):
            # Concatenate previous output and encoded input
            # f_{i-1} is f_prev
            # gamma_L(x) is gamma_x
            combined_input = torch.cat([f_prev, gamma_x], dim=-1)
            
            f_curr = self.layers[i](combined_input)
            f_curr = self.activation(f_curr)
            
            f_prev = f_curr
            
        return f_prev

# Note: The source distinguishes between modeling color and density separately.
# This MiMLP class represents the core "per-layer inputs incorporation" mechanism.
# In practice, two such networks (or one with two heads) are used.
```

## Subtopics

### Separate Color and Density Modeling
A companion technique to mi-MLP that models volume density and colors using separate networks to reduce artifacts, allowing different positional encoding frequencies for geometry and appearance [S1].

### Regularization Terms
The source mentions proposing two regularization terms to further reduce artifacts when using mi-MLP, but does not detail them in the provided text [S1].

## Operating characteristics
*   **Time Complexity:** The forward pass requires computing the positional encoding once per ray/sample, but concatenating it with the hidden state at every layer. This increases the input dimension for layers $2$ to $N$ from $d_{hidden}$ to $d_{hidden} + d_{input}$. This results in slightly higher computational cost per layer compared to vanilla NeRF, but the source claims it allows synthesis with fewer parameters overall while preserving capacity [S1].
*   **Memory Complexity:** Slightly higher memory usage for weights due to the expanded input connections in layers $2$ to $N$.
*   **Performance:** The source reports that mi-MLP boosts the PSNR of the baseline from 14.73 to 24.23 on few-shot view synthesis benchmarks [S1].
*   **Strengths:** Alleviates overfitting in few-shot scenarios; preserves high-frequency detail synthesis; plug-and-play with existing NeRF pipelines [S1].
*   **Limitations:** Requires careful initialization to maintain gradient flow properties (though default PyTorch init works) [S1].

## Background
The mi-MLP was proposed in the paper "Is Vanilla MLP in Neural Radiance Field Enough for Few-Shot View Synthesis?" published in CVPR 2024 [S1]. It addresses the observation that trivially reducing model parameters alleviates overfitting but harms detail synthesis. The method was introduced to provide an orthogonal solution from the perspective of network structure, incorporating inputs into each layer to create shorter paths between inputs and outputs [S1].
