# NeRF with Time Parameter

Also called: NeRF + time, NeRF with Time Parameter Baseline, Time-NeRF

## Overview
This method adapts the standard NeRF architecture [Parent](3065-nerf-hyperparameters.md) for dynamic scenes by introducing a temporal dimension to the input space [S1]. It solves the problem of static scene representation in video sequences by allowing the neural radiance field to vary over time. Unlike sibling methods that may use complex graph structures or explicit warping, this approach relies solely on expanding the MLP input vector [S1]. While it improves reconstruction quality over vanilla NeRF, it remains a baseline that lacks detailed dynamic reasoning and suffers from blurry predictions [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Spatial coordinates $\mathbf{x} \in \mathbb{R}^3$, view direction $\mathbf{d} \in \mathbb{R}^3$, and time parameter $t \in \mathbb{R}$.
*   **Outputs:** Volume density $\sigma$ and color $\mathbf{c}$, conditioned on $t$.

**Data Structures:**
The model consists of two Multi-Layer Perceptrons (MLPs): a coarse network and a fine network, following the standard NeRF architecture [Parent](3065-nerf-hyperparameters.md).
*   **Coarse Network:** Takes positional encoded position $\gamma(\mathbf{x}, t)$ and outputs a latent feature vector $\mathbf{h}$ and volume density $\sigma$.
*   **Fine Network:** Takes $\mathbf{h}$, positional encoded position $\gamma(\mathbf{x}, t)$, and positional encoded view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$.

**Positional Encoding:**
The time parameter $t$ is positionally encoded using the same scheme as spatial coordinates [S1]. The combined positional encoding for position and time is:
$$
\gamma(\mathbf{x}, t) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x}), t, \sin(2^{d_1}\pi t), \cos(2^{d_1}\pi t), \dots, \sin(2^{d_2-1}\pi t), \cos(2^{d_2-1}\pi t)]
$$
This vector is concatenated with the view direction encoding for the fine network input.

**Training Configuration:**
The model is trained using the configuration reported for NeRF's real forward-facing experiments [S1]. This includes the standard loss functions and sampling strategies defined in the parent article [Parent](3065-nerf-hyperparameters.md).

**Pseudocode:**
```python
def positional_encode(x, t, num_freqs):
    """
    Computes positional encoding for spatial coordinates x and time t.
    x: numpy array of shape (3,)
    t: float
    num_freqs: int, number of frequency bands
    Returns: concatenated encoding vector
    """
    # Encode spatial coordinates
    x_enc = []
    for i in range(num_freqs):
        freq = 2**i
        x_enc.append(np.sin(freq * np.pi * x))
        x_enc.append(np.cos(freq * np.pi * x))
    
    # Encode time parameter
    t_enc = []
    for i in range(num_freqs):
        freq = 2**i
        t_enc.append(np.sin(freq * np.pi * t))
        t_enc.append(np.cos(freq * np.pi * t))
        
    # Concatenate x and t encodings
    # Note: The base x is also included in the standard NeRF encoding
    # Assuming standard NeRF encoding includes x itself at the start
    full_x_enc = np.concatenate([x, x_enc])
    full_t_enc = np.concatenate([t_enc])
    
    return np.concatenate([full_x_enc, full_t_enc])

def nerf_forward_coarse(x, t, coarse_mlp):
    """
    Forward pass through the coarse MLP.
    x: spatial coordinates (3,)
    t: time parameter (float)
    coarse_mlp: the coarse network function
    Returns: latent vector h, density sigma
    """
    x_t_enc = positional_encode(x, t, num_freqs=coarse_mlp.num_freqs)
    h, sigma = coarse_mlp(x_t_enc)
    return h, sigma

def nerf_forward_fine(h, x, t, d, fine_mlp):
    """
    Forward pass through the fine MLP.
    h: latent vector from coarse network
    x: spatial coordinates (3,)
    t: time parameter (float)
    d: view direction (3,)
    fine_mlp: the fine network function
    Returns: color c
    """
    x_t_enc = positional_encode(x, t, num_freqs=fine_mlp.num_freqs)
    d_enc = positional_encode(d, 0.0, num_freqs=fine_mlp.num_freqs) # Time not used for direction
    input_vec = np.concatenate([h, x_t_enc, d_enc])
    c = fine_mlp(input_vec)
    return c
```

## Subtopics

### Temporal Compression of NeRF Models
A compression strategy for sequences of NeRF models that exploits temporal redundancy by treating the first model as a key-frame and compressing only the deltas between successive models [S2]. It initializes the NeRF for the first frame from scratch [S2]. For subsequent frames, it initializes the new NeRF based on the previous frame's trained NeRF to encourage temporal redundancy and save training time [S2]. It calculates the delta between the current frame's NeRF weights and the previous frame's NeRF weights [S2]. It applies exponent-based quantization and Huffman coding to the deltas [S2]. To restore a model, it accumulates the decoded deltas to the reference model (the previous frame's model) [S2].

## Operating characteristics
**Time and Memory Complexity:**
The complexity is identical to the standard NeRF architecture [Parent](3065-nerf-hyperparameters.md), as the time parameter is simply an additional input dimension. The number of parameters in the MLPs remains unchanged.

**Measured Performance:**
On KITTI dataset scenes, NeRF + time achieves a PSNR of 24.18, SSIM of 0.677, and LPIPS of 0.425 [S1]. This is an improvement over vanilla NeRF (PSNR 23.34, SSIM 0.662, LPIPS 0.415) but significantly worse than the proposed Neural Scene Graphs method (PSNR 26.66, SSIM 0.806, LPIPS 0.186) [S1].

**Strengths and Limitations:**
*   **Strengths:** Simple to implement; improves quality over static NeRF for dynamic scenes [S1].
*   **Limitations:** Lacks detail; suffers from blurry, uncertain predictions; fails to reason about scene dynamics; significant ghosting remains compared to more advanced methods [S1].

**When to Use:**
Use as a baseline for dynamic scene reconstruction when computational resources are limited or as a starting point for more complex dynamic NeRF variants.

## Background
This method was introduced in "Neural Scene Graphs for Dynamic Scenes" by Yuang Shi et al. (CVPR 2021) [S1]. It represents the simplest extension of NeRF to dynamic scenes by adding a time input, serving as a comparison point for more sophisticated dynamic scene representations [S1].
