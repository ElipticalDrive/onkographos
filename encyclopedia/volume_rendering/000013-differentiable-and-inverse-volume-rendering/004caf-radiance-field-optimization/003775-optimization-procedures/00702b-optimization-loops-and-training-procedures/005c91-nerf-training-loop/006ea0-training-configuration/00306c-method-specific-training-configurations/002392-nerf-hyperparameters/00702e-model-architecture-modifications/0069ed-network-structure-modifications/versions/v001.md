# Network Structure Modifications


## Overview
Network structure modifications alter the standard NeRF architecture to address hardware constraints, training speed, and semantic representation capabilities [S1, unofficial]. These variants trade parameter efficiency and inference latency for specific rendering capabilities, distinguishing themselves from the baseline two-MLP design [Parent](11313-model-architecture-modifications.md) [G].

## Shared principles
The core task of a NeRF network architecture is to learn a continuous volumetric scene representation $F_\Theta: (\mathbf{x}, \mathbf{d}) \rightarrow (\sigma, \mathbf{c})$, where $\mathbf{x} \in \mathbb{R}^3$ is the spatial position, $\mathbf{d} \in \mathbb{R}^3$ is the viewing direction, $\sigma$ is the volume density, and $\mathbf{c} \in \mathbb{R}^3$ is the view-dependent color. The rendering process integrates these outputs along rays using standard volume rendering equations.

### Standard NeRF Architecture
The baseline architecture [S1, unofficial] employs two MLPs:
1.  **Position MLP ($\Phi_{pos}$)**: Takes $\mathbf{x}$ and positional encoding $\gamma(\mathbf{x})$ to produce a feature vector $\mathbf{h}$.
2.  **Shading MLP ($\Phi_{shade}$)**: Takes $\mathbf{h}$ and directional encoding $\gamma(\mathbf{d})$ to predict $\sigma$ and $\mathbf{c}$.

Prevents overfitting in few-shot view synthesis by incorporating positional encoding into every layer, creating shorter paths between inputs and outputs.

### NeRF Model Architecture
#### definition
The neural network architecture for NeRF, consisting of dense layers with ReLU activations, potentially using view directions as input [S1, unofficial].

#### parameter
- `D`: The depth of the network (number of hidden layers). Default is 8 [S1, unofficial].
- `input_ch_views`: The number of input channels for view directions. Default is 3 [S1, unofficial].
- `output_ch`: The number of output channels. Default is 4 (RGB + density) [S1, unofficial].
- `use_viewdirs`: Boolean flag to determine if view directions are used as input to the network [S1, unofficial].

## Background
The standard NeRF architecture was introduced by Mildenhall et al. in 2020 [S1, unofficial]. The multi-input MLP (mi-MLP) was proposed to address overfitting in few-shot scenarios [S1, unofficial]. Texture-based variants like MobileNeRF were developed to enable mobile deployment [S1, unofficial]. Pyramid NeRF introduced progressive segmentation for efficient training . Residual-NeRF-S modified the combination of background and residual outputs . OccNet explored positional encoding alternatives .
