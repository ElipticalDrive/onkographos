# Multi-scale Joint Training Parameters

Also called: Multi-scale joint training loss weights

## Overview
Multi-scale joint training parameters are hyperparameters used to balance the contributions of reconstruction and uncertainty losses across multiple stages of a dynamically growing neural radiance field. This method addresses the problem of stable optimization in recursive NeRF architectures by ensuring that errors in coarser stages do not dominate the gradient updates for finer details. It sets apart from standard single-scale training by explicitly weighting the loss at each depth level of the network hierarchy, preventing the "forgetting" of coarse geometry as the network grows.

## How it works
The method operates within a multi-stage training framework where the network grows iteratively. At each stage $i$, the total loss is a weighted sum of the Mean Squared Error (MSE) and an uncertainty-based loss.

**Inputs and Outputs:**
*   **Input:** The current stage index $i$, the predicted color/opacity at stage $i$, and the ground truth image.
*   **Output:** The scalar loss value $\mathcal{L}^i$ for stage $i$, and the total loss $\mathcal{L}$ for backpropagation.

**Data Structures:**
*   $\mathcal{L}_{MSE}^i$: Scalar MSE loss for stage $i$.
*   $\mathcal{L}_{unct}^i$: Scalar uncertainty loss for stage $i$.
*   $\beta_1$: Weight for the MSE term.
*   $\beta_2$: Weight for the uncertainty term.

**Parameters:**
*   $\beta_1 = 1.0$
*   $\beta_2 = 0.1$
*   $D$: The current number of stages in the network.

**Formulas:**
The loss for a single stage $i$ is defined as:
$$
\mathcal{L}^i = \beta_1 \mathcal{L}_{MSE}^i + \beta_2 \mathcal{L}_{unct}^i
$$
The total loss for the multi-scale joint training is the sum over all $D$ stages:
$$
\mathcal{L} = \sum_{i=1}^D \mathcal{L}^i = \sum_{i=1}^D \left( \beta_1 \mathcal{L}_{MSE}^i + \beta_2 \mathcal{L}_{unct}^i \right)
$$
where $\mathcal{L}_{MSE}^i$ is the pixel-wise MSE between the rendered and ground truth images at stage $i$, and $\mathcal{L}_{unct}^i$ is the uncertainty loss derived from the network's predictive uncertainty at stage $i$.

**Steps:**
1.  Initialize $\beta_1 = 1.0$ and $\beta_2 = 0.1$.
2.  For each training iteration:
    a. Perform forward pass through all active stages $1 \dots D$.
    b. For each stage $i$:
       i. Compute $\mathcal{L}_{MSE}^i$ between rendered output and ground truth.
       ii. Compute $\mathcal{L}_{unct}^i$ based on the uncertainty estimate of the stage.
       iii. Compute $\mathcal{L}^i = \beta_1 \mathcal{L}_{MSE}^i + \beta_2 \mathcal{L}_{unct}^i$.
    c. Compute total loss $\mathcal{L} = \sum_{i=1}^D \mathcal{L}^i$.
    d. Backpropagate $\mathcal{L}$ to update network parameters.

**Pseudocode:**
```python
def compute_multi_scale_loss(rendered_images, ground_truth_images, uncertainties, num_stages):
    beta1 = 1.0
    beta2 = 0.1
    total_loss = 0.0
    
    for i in range(num_stages):
        # Compute MSE loss for stage i
        mse_loss = mean_squared_error(rendered_images[i], ground_truth_images[i])
        
        # Compute uncertainty loss for stage i
        # Note: Specific formulation of L_unct is not detailed in source, 
        # assumed to be a function of uncertainties[i]
        unct_loss = compute_uncertainty_loss(uncertainties[i])
        
        # Weighted sum for stage i
        stage_loss = beta1 * mse_loss + beta2 * unct_loss
        total_loss += stage_loss
        
    return total_loss
```

**Edge Cases and Pitfalls:**
*   **Precision:** Ensure $\mathcal{L}_{unct}^i$ is normalized similarly to $\mathcal{L}_{MSE}^i$ before weighting, as uncertainty values may have different scales.
*   **Boundary:** If $D=1$, the method reduces to single-scale training with fixed weights.

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of stages $D$, as each stage's loss is computed and summed.
*   **Memory Complexity:** Requires storing intermediate outputs and uncertainties for all $D$ stages during the forward pass.
*   **Strengths:** Stabilizes training in dynamically growing networks by preventing fine-scale details from being overwhelmed by coarse-scale errors.
*   **Limitations:** Requires careful tuning of $\beta_1$ and $\beta_2$ if the scale of uncertainty loss changes significantly across stages.
*   **When to use:** When using recursive or dynamically growing NeRF architectures that involve multiple stages of refinement.

## Background
The method originates from Recursive-NeRF, an efficient and dynamically growing NeRF approach. It was introduced to handle the challenges of training networks that grow in depth and capacity over time, ensuring that the loss function appropriately accounts for the contributions of each stage to the final rendering quality.
