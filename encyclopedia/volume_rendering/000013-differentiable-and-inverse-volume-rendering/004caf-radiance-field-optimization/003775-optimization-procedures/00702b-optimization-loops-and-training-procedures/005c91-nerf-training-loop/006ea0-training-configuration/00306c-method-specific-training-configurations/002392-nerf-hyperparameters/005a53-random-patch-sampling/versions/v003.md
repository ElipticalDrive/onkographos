# Random Patch Sampling

Also called: RP+RRot+Hflip, Rand-Patch, Random Patch Sampling with Augmentations

## Overview
Random patch sampling is a training strategy for Neural Radiance Field (NeRF) models, specifically those employing Super-Resolution (SR) modules or handling defocus blur, where image patches are extracted from random positions in the ray space rather than a fixed grid [S1, S2]. It addresses the overfitting of CNN-based SR modules on small NeRF datasets by ensuring convolutional kernels see diverse patterns, and models defocus blur interference by sampling neighboring rays within a patch [S1, S2]. Unlike grid-based patch sampling, it avoids cutting ray space strictly, allowing kernels to capture variations between grid boundaries [S1]. In deblurring contexts, it also reduces training time by allowing neighboring pixels to share ray computations [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Training views containing low-resolution (LR) ray space patches $R_{LR}$ and high-resolution (HR) counterparts $R_{HR}$, a patch size $P'$, and optional augmentation parameters (rotation angle, flip probability) [S1].
*   **Outputs:** Transformed patches $R_{LR}^{P'}$ and $R_{HR}^{P'}$ integrated into the training loop [S1].

**Data Structures:**
*   **Ray Space:** Represented as 2D image grids corresponding to camera views [S1, S2].
*   **Patch:** A sub-region of the ray space defined by width and height $P'$ [S2].

**Steps:**
1.  **Random Region Selection:** Randomly sample a region in the ray space defined by a top-left coordinate and dimensions $P' \times P'$ [S1, S2]. In deblurring contexts, the patch size $P'$ determines the number of "interesting" pixels, and the total rendered pixels include neighboring rays for blur convolution: $(P' + K + 1)^2$, where $K$ is the blur kernel size [S2].
2.  **Transformation (Augmentation):** Apply a transformation $\mathcal{A}$ to the selected LR and HR patches to yield transformed patches [S1]:
    $$ R_{LR}^{P'} = \mathcal{A}(R_{LR}^{P}) $$
    $$ R_{HR}^{P'} = \mathcal{A}(R_{HR}^{P}) $$
    The transformation $\mathcal{A}$ applies random rotation and horizontal flip [S1].
3.  **Training Integration:** Integrate the transformed patches into the pipeline's loss function to compute gradients [S1].
4.  **Iteration:** Repeat steps 1–3 for a fixed number of iterations or epochs [S1]. The patch size and number of training iterations are fixed to ensure the total number of patches seen by the model is identical to grid-based baselines [S1].

**Parameters:**
*   **Patch Size ($P'$):** The width and height of the region to compute intensity. In experiments, $P' = 22$ [S2].
*   **Blur Kernel Size ($K$):** Size of the blur kernel ($K \times K$). In experiments, $K = 11$ [S2].
*   **Rotation Angle:** Maximum rotation angle. Set to $10^\circ$ for synthetic datasets and $5^\circ$ for LLFF [S1].
*   **Horizontal Flip Probability:** Set to 10% for synthetic datasets. Omitted for LLFF as it is inappropriate for forward-facing scenes [S1].

**Pseudocode:**
```python
import math
import random

def rotate_patch(patch, angle_deg):
    """Rotate a 2D patch by angle_deg degrees."""
    angle_rad = math.radians(angle_deg)
    cos_a, sin_a = math.cos(angle_rad), math.sin(angle_rad)
    h, w = len(patch), len(patch[0])
    rotated = [[0.0] * w for _ in range(h)]
    cx, cy = w / 2.0, h / 2.0
    for y in range(h):
        for x in range(w):
            dx, dy = x - cx, y - cy
            new_x = int(dx * cos_a - dy * sin_a + cx)
            new_y = int(dx * sin_a + dy * cos_a + cy)
            new_x = max(0, min(w - 1, new_x))
            new_y = max(0, min(h - 1, new_y))
            rotated[new_y][new_x] = patch[y][x]
    return rotated

def flip_horizontal_patch(patch):
    """Flip a 2D patch horizontally."""
    return [row[::-1] for row in patch]

def compute_mse_loss(pred, target):
    """Compute Mean Squared Error loss."""
    h, w = len(pred), len(pred[0])
    return sum((pred[y][x] - target[y][x]) ** 2 for y in range(h) for x in range(w)) / (h * w)

def random_patch_sampling_training(nerf_params, sr_params, dataset, patch_size, num_epochs, augmentation_config):
    """
    Trains a NeRF+SR pipeline using random patch sampling.
    """
    lr = 0.01
    for epoch in range(num_epochs):
        for view in dataset:
            h, w = len(view.lr_image), len(view.lr_image[0])
            # 1. Randomly sample a region in the ray space
            y_start = random.randint(0, h - patch_size)
            x_start = random.randint(0, w - patch_size)
            
            # Extract LR and HR patches
            lr_patch = [row[x_start:x_start+patch_size] for row in view.lr_image[y_start:y_start+patch_size]]
            hr_patch = [row[x_start:x_start+patch_size] for row in view.hr_image[y_start:y_start+patch_size]]
            
            # 2. Apply transformation A (Augmentation)
            angle = random.uniform(-augmentation_config['max_rotation'], augmentation_config['max_rotation'])
            lr_patch = rotate_patch(lr_patch, angle)
            hr_patch = rotate_patch(hr_patch, angle)
            
            if random.random() < augmentation_config['flip_prob']:
                lr_patch = flip_horizontal_patch(lr_patch)
                hr_patch = flip_horizontal_patch(hr_patch)
            
            # 3. Forward Pass
            rendered_lr_patch = nerf_forward(lr_patch)  # Not given in the sources.
            sr_output = sr_forward(rendered_lr_patch)   # Not given in the sources.
            
            # 4. Compute Loss and Backpropagate
            loss = compute_mse_loss(sr_output, hr_patch)
            # Simulate gradient computation and optimizer step
            grad = [[sr_output[y][x] for x in range(len(sr_output[0]))] for y in range(len(sr_output))]
            for p in nerf_params:
                p -= lr * grad
            for p in sr_params:
                p -= lr * grad
```

**Edge Cases and Pitfalls:**
*   **Boundary Conditions:** Random sampling near image edges requires coordinate clamping to avoid out-of-bounds errors [G].
*   **Forward-Facing Scenes:** Horizontal flips must be omitted for forward-facing datasets (e.g., LLFF) as they create geometrically invalid views [S1].
*   **Training Stability:** Grid-based sampling requires randomizing the order of patches to ensure stability; random patch sampling inherently provides this diversity [S1].

## Subtopics

### Finetuning Pretrained SR Model with Random Patch Sampling
A training strategy where a pretrained Super-Resolution model (e.g., EDSR) is finetuned on the NeRF dataset using random patch sampling [S1]. It offers the best trade-off between training time and PSNR, achieving 31.64 PSNR (2×) and 32.53 PSNR (4×) on NeRF-Synthetic with training times of 51 minutes (2×) and 19 minutes (4×) [S1]. It outperforms bilinear interpolation and pretrained EDSR without finetuning, while being faster than distillation methods [S1]. Training duration is fixed at 150 epochs [S1].

## Operating characteristics
*   **Time Complexity:** Reduces training time compared to rendering all rays. In deblurring, it reduces the number of required neighboring rays per ray from $K^2$ to $\frac{K^2}{(P' + K + 1)^2 / P'^2}$ [S2].
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** Improves PSNR by up to 0.89 dB for 2× upscaling and 1.44 dB for 4× upscaling compared to grid-based sampling [S1]. On NeRF-Synthetic SR-2×, it yields 32.53 dB versus 31.84 dB for grid-based sampling [S1]. On NeRF-Synthetic SR-4×, it yields 35.39 dB versus 34.34 dB [S1]. On LLFF SR-4×, it yields 30.47 dB versus 29.28 dB [S1].
*   **Strengths:** Lightweight augmentation that improves generalization by exposing convolutional kernels to diverse patterns and reduces training overhead compared to distillation [S1].
*   **Limitations:** Adding rotation and horizontal flip augmentations causes marginal PSNR degradation compared to random patch sampling alone [S1]. It shows a slight PSNR decrease (0.16 dB) at 2× on LLFF [S1].

## Background
Originated in the context of efficient NeRF training, specifically for Super-Resolution pipelines (FastSR-NeRF) and deblurring (Sharp-NeRF) [S1, S2]. Proposed to mitigate the overfitting issues of CNN-based SR modules on small NeRF datasets and to model defocus blur interference [S1, S2]. The technique was introduced in 2024 [S1, S2].
