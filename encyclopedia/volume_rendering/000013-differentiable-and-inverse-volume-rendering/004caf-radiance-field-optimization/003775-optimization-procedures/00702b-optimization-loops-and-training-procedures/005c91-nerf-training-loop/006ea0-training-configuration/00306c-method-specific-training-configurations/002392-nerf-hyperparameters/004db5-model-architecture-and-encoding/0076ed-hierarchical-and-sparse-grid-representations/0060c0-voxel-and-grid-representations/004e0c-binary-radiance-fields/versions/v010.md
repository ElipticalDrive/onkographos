# Binary Radiance Fields

Also called: BRF

## Overview
Binary Radiance Fields (BiRF) is a storage-efficient radiance field representation that constrains feature grid parameters to binary values (+1 or -1) to drastically reduce memory overhead while maintaining high reconstruction quality [S1]. Unlike post-processing compression methods such as PlenOctrees or Re:NeRF, which require additional optimization steps and are bounded by pre-trained model performance, BiRF performs binarization during training using a 2D-3D hybrid multi-resolution architecture [S1]. This approach allows for compact storage (e.g., < 0.5 MB for Synthetic-NeRF scenes) without sacrificing the fidelity of the radiance field [S1].

## How it works
**Inputs:**
*   3D spatial coordinate $\mathbf{x} \in \mathbb{R}^3$.
*   Viewing direction $\mathbf{d} \in \mathbb{R}^3$ (encoded via spherical harmonics).

**Outputs:**
*   Volume density $\sigma \in \mathbb{R}$.
*   RGB color $\mathbf{c} \in [0, 1]^3$.

**Data Structures:**
The feature grid consists of a 3D voxel grid $\Phi_{\theta_{xyz}}$ and three orthogonal 2D plane grids $\Phi_{\theta_{xy}}$, $\Phi_{\theta_{xz}}$, $\Phi_{\theta_{yz}}$. All grids use hash encoding [S1].
*   **3D Grid:** $L$ levels with resolutions ranging from 16 to 1024. Each level holds up to $T_{3D}$ feature vectors.
*   **2D Grids:** $M$ levels with resolutions ranging from 64 to 512. Each level holds up to $T_{2D}$ feature vectors.
*   **Feature Dimension:** $F$ per level. Model variants scale by $F \in \{2, 4, 8\}$ [S1].
*   **Parameter Storage:** Parameters are constrained to $\{-1, +1\}$, allowing storage in 1-bit per parameter [S1].

**Parameters:**
*   $\lambda_{\text{sparsity}}$: Hyper-parameter for sparsity loss. Value: $2.0 \times 10^{-5}$ [S1].
*   $T_{3D}$: Max feature vectors per 3D level. Small model (Ours-S): $\log_2(T_{3D}) = 17$. Base model (Ours-B): $\log_2(T_{3D}) = 19$ [S1].
*   $T_{2D}$: Max feature vectors per 2D level. Small model (Ours-S): $\log_2(T_{2D}) = 15$. Base model (Ours-B): $\log_2(T_{2D}) = 17$ [S1].
*   MLP Hidden Layers: Density MLP has 1 hidden layer (128 channels); Color MLP has 2 hidden layers (128 channels) [S1].

**Pitfalls and Edge Cases:**
*   **Gradient Vanishing:** The derivative of the sign function is zero almost everywhere. This is mitigated by the Straight-Through Estimator (STE), which passes gradients through the threshold function during training [S1].
*   **Scale Divergence:** Large values of real-valued parameters $\theta$ can cause divergence. The STE implementation stops propagating gradients when $|\theta| > 1$, constraining the value to $\{-1, 1\}$ [S1].
*   **Hash Collisions:** 3D grids suffer from hash collisions at higher resolutions. The 2D grids supplement the 3D grid to alleviate collision impact and reinforce features with fewer parameters [S1].

**Algorithm:**

1.  **Binarization:** Transform real-valued grid parameters $\theta$ to binary $\theta'$ using the sign function:
    $$ \theta' = \text{sign}(\theta) = \begin{cases} +1 & \text{if } \theta \ge 0 \\ -1 & \text{otherwise} \end{cases} $$
    During backpropagation, use the Straight-Through Estimator (STE):
    $$ \frac{\partial L}{\partial \theta} = \begin{cases} \frac{\partial L}{\partial \theta'} & \text{if } |\theta| \le 1 \\ 0 & \text{otherwise} \end{cases} $$
    [S1]

2.  **Feature Encoding:**
    *   **3D Encoding:** For input coordinate $\mathbf{x}$, compute features from the 3D grid by linearly interpolating the binary parameters across $L$ resolution levels and concatenating them:
        $$ \mathbf{f}_{xyz} = \left\{ \text{interp}(\mathbf{x}, \text{sign}(\Phi^l_{\theta_{xyz}})) \right\}_{l=1}^L $$
        where $\text{interp}$ denotes tri-linear interpolation [S1].
    *   **2D Encoding:** Project $\mathbf{x}=(x,y,z)$ to 2D coordinates: $\mathbf{x}_{xy}=(x,y)$, $\mathbf{x}_{xz}=(x,z)$, $\mathbf{x}_{yz}=(y,z)$. For each axis, interpolate binary parameters across $M$ resolution levels and concatenate:
        $$ \mathbf{f}_{xy} = \left\{ \text{interp}(\mathbf{x}_{xy}, \text{sign}(\Phi^m_{\theta_{xy}})) \right\}_{m=1}^M $$
        Repeat for $\mathbf{f}_{xz}$ and $\mathbf{f}_{yz}$ using bi-linear interpolation [S1].
    *   **Concatenation:** Combine all encoded features:
        $$ \mathbf{f} = \{ \mathbf{f}_{xyz}, \mathbf{f}_{xy}, \mathbf{f}_{xz}, \mathbf{f}_{yz} \} $$
        [S1]

3.  **Density Prediction:**
    *   Apply positional encoding $\gamma(\mathbf{x})$ to the input 3D coordinate (as defined in [Parent](13550-model-architecture-and-encoding.md)).
    *   Feed the concatenated features $\mathbf{f}$ and positional encoded coordinates $\gamma(\mathbf{x})$ into a shallow density MLP:
        $$ (\sigma, \mathbf{e}) = \text{MLP}_{\text{density}}(\gamma(\mathbf{x}), \mathbf{f}) $$
        where $\sigma$ is density and $\mathbf{e}$ is the embedded feature vector [S1].

4.  **Color Prediction:**
    *   Encode the viewing direction $\mathbf{d}$ using spherical harmonics basis functions [S1].
    *   Feed the embedded feature $\mathbf{e}$ and directional encoding into a shallow color MLP:
        $$ \mathbf{c} = \text{MLP}_{\text{color}}(\mathbf{e}, \mathbf{d}) $$
        [S1]

5.  **Loss Calculation:**
    *   **Reconstruction Loss:** Standard $L_2$ loss between rendered color $\hat{C}(\mathbf{r})$ and ground truth $C(\mathbf{r})$:
        $$ L_{\text{recon}} = \sum_{\mathbf{r} \in \mathcal{R}} ||\hat{C}(\mathbf{r}) - C(\mathbf{r})||_2^2 $$
        [S1]
    *   **Sparsity Loss:** Regularize sparsity using Cauchy loss to accelerate rendering by encouraging empty space:
        $$ L_{\text{sparsity}} = \sum_{i,k} \log(1 + 2\sigma(\mathbf{r}_i(t_k))^2) $$
        [S1]
    *   **Total Loss:**
        $$ L = L_{\text{recon}} + \lambda_{\text{sparsity}} L_{\text{sparsity}} $$
        [S1]

## Operating characteristics
*   **Storage Efficiency:** BiRF achieves significant storage reduction. For example, the Ours-S2 variant requires less than 0.5 MB of storage for Synthetic-NeRF scenes, outperforming baselines like TensoRF-CP (3.7 MB) and Instant-NGP (24.5 MB) on the mic scene while maintaining comparable or better PSNR [S1].
*   **Performance:** On Synthetic-NeRF scenes, BiRF achieves a PSNR of 32.03 dB; on Synthetic-NSVF, 34.48 dB; and on Tanks and Temples, 28.20 dB [S1].
*   **Training Time:** Training takes approximately 6, 9, and 14 minutes for Ours-B2 to Ours-B8 models on Synthetic-NeRF scenes using a single NVIDIA RTX A6000 GPU [S1].
*   **Strengths:** Compact storage without post-optimization; superior reconstruction performance compared to prior efficient methods; efficient ray sampling via occupancy grid [S1].
*   **Limitations:** Hash collisions in 3D grids at high resolutions (mitigated by 2D grids); requires careful handling of gradient flow during binarization [S1].
*   **When to use:** When storage footprint is a critical constraint and real-time or efficient training is desired without sacrificing reconstruction quality [S1].
*   **When not to use:** When extremely high-frequency details require real-valued precision that binary encoding might lose, or when post-processing compression is acceptable and pre-trained models are available [S1].

## Background
Binary Radiance Fields were proposed by Seungjoo Shin and Jaesik Park from POSTECH and Seoul National University, respectively, in a paper published on arXiv in June 2023 (v2 in December 2023) [S1]. The work addresses the storage bottleneck of neural radiance fields by introducing binary feature encoding. It builds on the multi-resolution hash encoding architecture of Instant-NGP and utilizes the occupancy grid from NerfAcc for efficient ray sampling [S1]. The method was implemented and tested on NVIDIA RTX A6000 GPUs [S1].
