# Depth-Guided NeRF Training Configuration

Also called: Depth-Guided NeRF Training

## Overview
This configuration defines the hyperparameters, architectural modifications, and optimization settings required to train a Neural Radiance Field (NeRF) model using depth priors. It addresses the problem of geometry regularization and convergence stability by integrating explicit depth supervision into the standard differentiable volume rendering pipeline. It distinguishes itself from sibling methods by relying on a specific dropout-based regularization strategy and a fixed, empirically derived depth loss weight ($\lambda$) rather than adaptive uncertainty weighting or complex multi-scale encodings.

## How it works
The method modifies the standard NeRF training loop by injecting architectural regularization and a weighted depth reconstruction loss.

**Inputs and Outputs**
*   **Inputs:** Camera poses $\mathbf{P}$, image observations $\mathbf{I}$, and ground truth depth maps $\mathbf{D}_{gt}$.
*   **Outputs:** Optimized network parameters $\theta$ for the radiance field.

**Data Structures**
The network architecture builds on the original NeRF [S1]. The specific modification is the insertion of dropout layers.
*   **Structure:** A Multi-Layer Perceptron (MLP) taking positional encoding inputs.
*   **Modification:** Dropout layers with probability $p=0.1$ are added after each of the first eight fully connected ReLU-activated layers.

**Parameters**
*   **Depth Loss Weight ($\lambda$):** $0.007$ for all scenes except scene 710, where $\lambda = 0.02$ [S1].
*   **Uncertainty Weight ($\gamma$):** $1$ [S1].
*   **Optimizer:** Adam [S1].
*   **Learning Rate (Base):** $5 \times 10^{-4}$ [S1].
*   **Learning Rate Schedule:** Reduced to $5 \times 10^{-5}$ after 80% of total steps [S1].
*   **Weight Decay:** $1 \times 10^{-6}$ [S1].
*   **Total Training Steps:** $500,000$ [S1].
*   **Depth Scale Learning Rate:** $1 \times 10^{-7}$ [S1].
*   **Depth Threshold ($\tau$):** Used to evaluate depth uncertainty. Calculated as $\tau = (\text{max\_depth} - \text{min\_depth}) \cdot 0.0001$ [S1]. For ScanNet, $\text{max\_depth} = 10$ and $\text{min\_depth} = 0.001$ [S1].

**Numbered Steps**
1.  **Initialize:** Load the NeRF architecture. Insert dropout layers ($p=0.1$) after the first 8 FC ReLU layers. Initialize Adam optimizer with base LR $5 \times 10^{-4}$ and weight decay $1 \times 10^{-6}$.
2.  **Sample Rays:** For each training iteration, sample rays through the scene.
3.  **Render:** Compute volume rendering to predict color $\hat{\mathbf{c}}$ and depth $\hat{d}$ for each pixel.
4.  **Compute Color Loss:** Calculate the photometric loss between rendered color $\hat{\mathbf{c}}$ and ground truth color $\mathbf{c}$.
5.  **Compute Depth Loss:** Calculate the depth loss between rendered depth $\hat{d}$ and ground truth depth $d_{gt}$. The specific metric is not explicitly defined as L1 or L2 in the configuration notes, but evaluation metrics include RMSE and Log-RMSE [S1]. The loss is weighted by $\lambda$.
6.  **Compute Uncertainty Loss (Optional):** If using the uncertainty weight $\gamma$, incorporate the uncertainty term evaluated against threshold $\tau$ [S1].
7.  **Backpropagate:** Compute gradients and update weights using Adam.
8.  **Schedule Update:** If the current step exceeds 80% of 500,000, reduce the learning rate to $5 \times 10^{-5}$.
9.  **Repeat:** Continue until 500,000 steps are completed.

**Pseudocode**
```python
def train_depth_guided_nerf(scene_data, total_steps=500000):
    # 1. Initialize Model with Dropout
    model = NeRF()
    # Add dropout p=0.1 after first 8 FC ReLU layers
    for i, layer in enumerate(model.layers[:8]):
        if isinstance(layer, FullyConnectedReLU):
            layer.add_dropout(p=0.1)
            
    # 2. Initialize Optimizer
    optimizer = Adam(model.parameters(), lr=5e-4, weight_decay=1e-6)
    
    # 3. Scene Specific Parameters
    if scene_id == 710:
        lambda_depth = 0.02
    else:
        lambda_depth = 0.007
        
    gamma_uncertainty = 1.0
    lr_depth_scale = 1e-7
    
    # 4. Training Loop
    for step in range(total_steps):
        # Sample rays and get ground truth color/depth
        rays, gt_color, gt_depth = sample_batch(scene_data)
        
        # Render
        pred_color, pred_depth = model(rays)
        
        # Compute Losses
        loss_color = mse_loss(pred_color, gt_color)
        loss_depth = depth_loss(pred_depth, gt_depth) # Metric unspecified in config notes
        loss_uncertainty = uncertainty_loss(pred_depth, gt_depth, gamma=gamma_uncertainty, tau=tau)
        
        # Combine Losses
        total_loss = loss_color + (lambda_depth * loss_depth) + (gamma_uncertainty * loss_uncertainty)
        
        # Backpropagate
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()
        
        # Learning Rate Schedule
        if step > 0.8 * total_steps:
            set_lr(optimizer, 5e-5)
            
    return model
```

**Edge Cases and Pitfalls**
*   **Scene 710:** Requires a distinct depth loss weight ($\lambda=0.02$) compared to other scenes ($\lambda=0.007$) [S1].
*   **Depth Threshold:** The threshold $\tau$ for uncertainty evaluation is scene-dependent, derived from the min/max depth range of the specific dataset (e.g., ScanNet) [S1].
*   **Overfitting:** The dropout regularization is critical for preventing overfitting, particularly in sparse view scenarios [S1].

## Subtopics

### DS-NeRF Depth Loss Integration
This variant involves integrating the depth loss implementation from the official DS-NeRF codebase into the training pipeline. Due to missing configuration files for the DTU dataset in the official release, results for DTU with fixed ground-truth poses are taken directly from the publication. For the LLFF dataset, the original publication results used a different train/test split; therefore, re-training is performed on the standard train/test splits using the released configuration files [S2].

## Operating characteristics
*   **Time Complexity:** Determined by the 500,000 training steps and the MLP forward/backward passes. The dropout layers add negligible overhead.
*   **Memory Complexity:** Standard NeRF memory footprint plus minimal overhead for dropout masks.
*   **Strengths:** Provides stable geometry regularization through explicit depth supervision and dropout-based regularization.
*   **Limitations:** The depth loss weight is fixed per scene (with one exception), lacking adaptive mechanisms. The specific depth loss function (L1 vs L2) is not explicitly defined in the configuration notes, only evaluation metrics are provided [S1].
*   **When to use:** When training NeRFs with available depth priors and requiring robust regularization against overfitting in sparse view settings.

## Background
This configuration originates from the work on Depth-Guided NeRF Training via Earth Mover’s Distance [S1]. It builds upon the original NeRF architecture [S1] and incorporates techniques from DS-NeRF [S2] for depth loss integration. The method is designed to improve the geometric accuracy of radiance fields by leveraging depth information during the optimization process.
