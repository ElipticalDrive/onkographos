# Depth-Guided NeRF Training Configuration

Also called: Depth-Guided NeRF Training

## Overview
This configuration defines the hyperparameters and architectural modifications for training a Neural Radiance Field (NeRF) model using depth priors to regularize the optimization process [S1]. It addresses the ambiguity in inverse volume rendering by incorporating explicit depth supervision, which stabilizes training and improves geometric accuracy [S1]. It differs from standard NeRF training by introducing specific dropout layers, a dedicated depth loss term with scene-dependent weighting, and a separate learning rate for depth scale parameters [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Camera poses, image pixels, and ground truth depth maps (where available).
*   **Outputs:** Trained NeRF model parameters (MLP weights, encoding tables) and associated depth scale parameters.

**Data Structures:**
The model builds upon the original NeRF architecture [S1]. The specific modification is the addition of dropout layers within the positional encoding network [S1].
*   **Dropout Layers:** Placed after each of the first eight fully connected ReLU-activated layers that encode the positional encoding [S1].
*   **Dropout Probability:** $p = 0.1$ [S1].

**Parameters:**
*   **Optimizer:** Adam [S1].
*   **Initial Learning Rate ($\eta$):** $5 \times 10^{-4}$ [S1].
*   **Learning Rate Schedule:** The learning rate is reduced to $5 \times 10^{-5}$ after 80% of the total training steps [S1].
*   **Weight Decay ($\lambda_w$):** $1 \times 10^{-6}$ [S1].
*   **Total Training Steps:** 500,000 [S1].
*   **Depth Scale Learning Rate ($\eta_d$):** $1 \times 10^{-7}$ [S1].
*   **Depth Loss Weight ($\lambda$):**
    *   $\lambda = 0.007$ for all scenes except scene 710 [S1].
    *   $\lambda = 0.02$ for scene 710 [S1].
*   **Uncertainty Weight ($\gamma$):** $1$ [S1].
*   **Depth Threshold ($\tau$):** Used to evaluate depth map uncertainty. Calculated as:
    $$ \tau = (\text{max\_depth} - \text{min\_depth}) \cdot 0.0001 $$
    For ScanNet, $\text{max\_depth} = 10$ and $\text{min\_depth} = 0.001$ [S1].

**Algorithm:**
1.  Initialize the NeRF model based on the original architecture [S1].
2.  Insert dropout layers with probability $0.1$ after the first eight fully connected ReLU layers of the positional encoding network [S1].
3.  Initialize Adam optimizer with learning rate $\eta = 5 \times 10^{-4}$ and weight decay $\lambda_w = 1 \times 10^{-6}$ [S1].
4.  Initialize depth scale parameters with learning rate $\eta_d = 1 \times 10^{-7}$ [S1].
5.  For each training step $t$ from 1 to 500,000:
    a. Sample rays and render color and depth [S1].
    b. Compute photometric loss [S1].
    c. Compute depth loss using the weight $\lambda$ (0.007 or 0.02 depending on scene) [S1].
    d. Compute uncertainty-weighted depth loss using $\gamma = 1$ [S1].
    e. Update model weights using Adam [S1].
    f. Update depth scale parameters using Adam with $\eta_d$ [S1].
    g. If $t > 0.8 \times 500,000$, set $\eta = 5 \times 10^{-5}$ [S1].

**Edge Cases and Pitfalls:**
*   **Scene 710:** Requires a higher depth loss weight ($\lambda = 0.02$) compared to other scenes ($\lambda = 0.007$) [S1].
*   **Depth Threshold:** The threshold $\tau$ must be calculated per scene based on its specific depth range to properly evaluate uncertainty [S1].

## Subtopics

### DS-NeRF Depth Loss Integration
Integrates the depth loss implementation from the official DS-NeRF code base into the training pipeline [S2]. Due to missing configuration files in the official DS-NeRF release, DTU results from the original publication could not be reproduced; therefore, results are reported from the publication for DTU [S2]. For LLFF, the original publication used a different train/test split, so re-training is performed on the standard splits using the released configuration files [S2].

## Operating characteristics
**Time and Memory Complexity:**
Not given in the sources.

**Measured Performance:**
Not given in the sources.

**Strengths and Limitations:**
*   **Strengths:** Incorporates explicit depth supervision to resolve geometric ambiguity [S1]. Dropout regularization helps prevent overfitting [S1].
*   **Limitations:** Requires ground truth depth maps for training [S1]. Performance may vary significantly across scenes, requiring per-scene tuning of the depth loss weight (e.g., scene 710) [S1]. Reproducing results from other works (like DS-NeRF) can be difficult due to missing configuration files or undocumented architectural tricks [S2].

**When to Use:**
Use when depth priors are available and geometric accuracy is critical [S1].

**When Not to Use:**
Not suitable for sparse pose scenarios without depth supervision unless adapted (see [SPARF](12073-sparf-training-configuration.md) or similar sparse methods).

## Background
This configuration was introduced in the context of Depth-Guided NeRF Training via Earth Mover’s Distance [S1]. It builds on the original NeRF architecture [S1]. The approach is part of a broader effort to improve NeRF geometry by leveraging depth information [S1]. Variants of depth loss integration, such as those from DS-NeRF, have been explored in subsequent works like SPARF [S2].
