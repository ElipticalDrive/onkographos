# IE-NeRF

Also called: IE-NeRF Pipeline, Image-dependent NeRF with transient mask inpainting, Inpainting Enhanced NeRF

## Overview
IE-NeRF is a Neural Radiance Field (NeRF) variant designed for novel view synthesis in uncontrolled, "in-the-wild" environments containing transient occlusions (e.g., pedestrians, vehicles) [S1]. It solves the problem of static scene reconstruction in the presence of dynamic elements by separating static scene rendering from transient occlusions using an image-dependent 2D transient mask and a pre-trained inpainting module [S1]. Unlike sibling methods such as [DeblurNeRF](11964-deblurnerf.md) which address motion blur, or [Sharp-NeRF](14270-sharp-nerf.md) which focuses on sharpness, IE-NeRF specifically targets transient object removal [S1]. It differs from [NeRF-W](11313-model-architecture-modifications.md) by using a single MLP to predict both static properties and a 2D transient mask, rather than a 3D transient field or dual NeRF pipelines [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of uncontrolled images $\{I_i\}$ with corresponding camera poses.
*   **Outputs:** A static radiance field capable of rendering novel views of the static scene, free from transient occlusions.

**Data Structures and Layout:**
The model consists of three main modules [S1]:
1.  **CNN Encoder ($E_E$):** Encodes input image $I_i$ into a feature latent vector $\ell_i \in \mathbb{R}^k$.
2.  **NeRF MLPs:**
    *   **MLP$_{\theta_1}$:** 8 fully connected layers, 256 hidden units. Input: Positional encoded position $\gamma_x(r(t))$. Output: Density $\sigma(t)$ and intermediate feature $z_i(t)$.
    *   **MLP$_{\theta_2}$:** Takes $\gamma_d(d)$, $z_i(t)$, and original position $(x,y,z)$. Output: Image-dependent radiance $c_i(t)$ and transient mask embedding $\ell_t$.
    *   **Transient Mask Head:** A fully connected layer with 128 channels and Sigmoid activation. Input: $\ell_t$ and 2D pixel location $l_{ij}$. Output: Transient mask probability $M_{ij} \in [0, 1]$.
    *   **Static Color Head:** A fully connected layer with 128 channels and Sigmoid activation. Input: Output from MLP$_{\theta_2}$. Output: Static RGB color $c_s$.
3.  **Inpainting Module ($G_\Delta$):** Uses the LaMa model [S1].
    *   **Architecture:** ResNet-like with 3 downsampling blocks, 12 residual blocks using Fast Fourier Convolution (FFC), and 3 upsampling blocks.
    *   **Input:** Four-channel tensor $x' = \text{stack}(x \odot m, m)$, where $x$ is the masked image and $m$ is the binary mask.
    *   **Output:** Restored static image $\hat{I}_r$ and repaired depth map $\hat{D}_r$.

**Numbered Steps:**

1.  **Image Encoding:** Encode each input image $I_i$ into a feature latent vector $\ell_i$ using the CNN encoder $E_E$ [S1].
2.  **Ray Sampling:** For each pixel, sample points $t_k$ along the camera ray $r(t) = o + td$ using mip-NeRF cone casting with Integrated Positional Encoding (IPE) [S1].
3.  **Static Property Prediction:** Process the sample location $r(t)$ through MLP$_{\theta_1}$ with positional encoding $\gamma_x$ to output density $\sigma(t)$ and intermediate feature $z_i(t)$ [S1]:
    $$ [\sigma(t), z_i(t)] = \text{MLP}_{\theta_1}[\gamma_x(r(t))] $$
    where $\theta = [\theta_1, \theta_2]$ are learnable weights [S1].
4.  **Radiance and Mask Embedding:** Feed the viewing direction $d$ (with encoding $\gamma_d$), intermediate feature $z_i(t)$, and original position into MLP$_{\theta_2}$ to predict image-dependent radiance $c_i(t)$ and transient mask embedding $\ell_t$ [S1]:
    $$ c_i(t) = \text{MLP}_{\theta_2}[\gamma_d(d), z_i(t)] $$
    [S1].
5.  **Transient Mask Generation:** Generate a 2D pixel-wise transient mask probability $M_{ij}$ by mapping the 2D pixel location $l_{ij}$ and transient embedding $\ell_t$ through linear layers $E_\phi$ [S1]:
    $$ M_{ij} = E_\phi(l_{ij}, \ell_t) $$
    [S1]. The mask is thresholded to create a binary mask for inpainting [S1].
6.  **Volumetric Rendering:** Compute the approximated pixel color $\hat{C}_i(r)$ using the static density $\sigma(t)$ and image-dependent radiance $c_i(t)$ [S1]:
    $$ \hat{C}_i(r) = \sum_{k=1}^{K} T(t_k) \cdot \alpha(\sigma(t_k)\delta_k) \cdot c_i(t_k) $$
    where $T(t_k) = \exp\left(-\sum_{k'=1}^{k-1} \sigma(t_{k'}) \cdot \delta_{k'}\right)$ is the accumulated transmittance [S1].
7.  **Inpainting:** Feed the original image $I_i$ and the thresholded transient mask $M_{ij}$ into the LaMa inpainting network $G_\Delta$ to produce the restored static image $\hat{I}_r$ and repaired depth map $\hat{D}_r$ [S1].
8.  **Depth Rendering and Inpainting:** Render depth maps $\hat{D}_s$ from the static NeRF. Inpaint them using LaMa guided by the transient mask to produce restored depth maps $\hat{D}_r$ for geometry supervision [S1].
9.  **Optimization:** Optimize the model by minimizing the total loss $L$ [S1]:
    $$ L = \alpha \sum_{ij} L_s + \beta \sum_{ij} L_t + \gamma \sum_i L_{\text{LPIPS}} + \rho \sum_i L_{\text{depth}} $$
    [S1].

**Formulas:**
*   **Static Photometric Loss ($L_s$):** Supervises rendered static image $\hat{C}_s$ against ground truth $C$ outside the mask and repaired image inside [S1].
*   **Transient Loss ($L_t$):** Balances occlusion and reconstruction errors [S1]:
    $$ L_t = \sum_{ij} (1 - M_{ij}) \| C(r_{ij}) - \hat{C}_s(r_{ij}) \|^2 + \lambda M_{ij} \| C_s(r_{ij}) - \hat{C}_s(r_{ij}) \|^2 $$
    where $\lambda$ balances static/transient components [S1].
*   **Depth Loss ($L_{\text{depth}}$):** $\ell_2$ distance between rendered static depth $\hat{D}_s$ and inpainted depth $\hat{D}_r$ [S1]:
    $$ L_{\text{depth}} = \frac{1}{|R|} \sum_{r \in R} \| \hat{D}_s(r) - \hat{D}_r(r) \|^2 $$
    [S1].
*   **Frequency Regularization:** Uses a linearly increasing frequency mask $\omega$ on positional encoding $\gamma_L$ [S1]:
    $$ \gamma'_L(t, T; x) = \gamma_L(x) \odot \omega(t, T, L) $$
    where $\omega^i(t, T, L)$ is defined based on iteration $t$, max iteration $T$, max frequency $L$, and transient mask factor $r$ (ratio of transient pixels) [S1]:
    $$ \omega^i(t, T, L) = \begin{cases} r & \text{if } i \le \lfloor \frac{t \cdot L}{T} \rfloor \\ \frac{t \cdot L}{T} - \lfloor \frac{t \cdot L}{T} \rfloor & \text{if } \lfloor \frac{t \cdot L}{T} \rfloor < i \le \lfloor \frac{t \cdot L}{T} \rfloor + 6 \\ 0 & \text{if } i > \lfloor \frac{t \cdot L}{T} \rfloor + 6 \end{cases} $$
    [S1].

**Parameters:**
*   $\alpha, \beta, \gamma, \rho$: Weights for static loss, transient loss, perceptual loss (LPIPS), and depth loss [S1].
*   $\lambda$: Parameter adjusting the balance between transient and static components in $L_t$ [S1].
*   $L$: Hyperparameter determining the maximum encoded frequency in the positional encoding [S1].
*   $r$: Transient mask factor, ratio of transient pixels to total image area [S1].
*   Typical values: Not given in the sources.

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class IENeRF:
    def __init__(self, num_layers=8, hidden_dim=256, color_dim=128, max_freq=10):
        # CNN Encoder for image features
        self.encoder = CNN_Encoder()
        
        # MLP for density and intermediate features
        self.mlp_density = MLP_Density(num_layers, hidden_dim)
        
        # MLP for radiance and transient embedding
        self.mlp_radiance = MLP_Radiance(hidden_dim, color_dim)
        
        # Transient mask head
        self.mask_head = nn.Linear(color_dim, 1) # Simplified linear layer for mask
        
        # Static color head
        self.color_head = nn.Linear(color_dim, 3) # RGB output
        
        # LaMa Inpainting Module (Pre-trained)
        self.inpainting_module = LaMa_Inpainting()
        
        self.max_freq = max_freq
        self.lambda_transient = 1.0 # Placeholder for lambda
        self.alpha = 1.0
        self.beta = 1.0
        self.gamma = 1.0
        self.rho = 1.0

    def forward(self, images, rays, t, T, iteration):
        """
        images: List of input images I_i
        rays: Camera rays (origin o, direction d)
        t: Sample points along rays
        T: Max iteration for frequency regularization
        iteration: Current training iteration
        """
        batch_size = len(images)
        losses = []
        
        for i in range(batch_size):
            I_i = images[i]
            
            # Step 1: Encode image to latent vector
            l_i = self.encoder(I_i)
            
            # Step 2: Get ray direction and position
            o, d = rays[i]
            # Apply Integrated Positional Encoding (IPE) with frequency regularization
            pos_enc = get_ippe_with_freq_reg(t, self.max_freq, iteration, T, l_i)
            
            # Step 3: Predict density and intermediate feature
            sigma, z_i = self.mlp_density(pos_enc)
            
            # Step 4: Predict radiance and transient embedding
            dir_enc = get_direction_encoding(d)
            c_i, l_t = self.mlp_radiance(dir_enc, z_i, l_i)
            
            # Step 5: Generate Transient Mask
            # Map 2D pixel location and transient embedding to mask probability
            # Note: In implementation, l_ij is derived from pixel coordinates of the ray
            mask_prob = torch.sigmoid(self.mask_head(l_t))
            
            # Step 6: Volumetric Rendering for Static Scene
            # Compute transmittance and alpha
            alpha = 1.0 - torch.exp(-sigma * (t[1:] - t[:-1])) # Simplified delta
            T_trans = torch.cumprod(torch.cat([torch.ones_like(alpha[:1]), 1.0 - alpha + 1e-10], dim=0)[:-1], dim=0)
            
            # Render static color
            C_static = torch.sum(T_trans * alpha * c_i, dim=-1)
            
            # Step 7: Inpainting
            # Create masked image
            # Threshold mask to binary for inpainting input
            mask_binary = (mask_prob > 0.5).float()
            masked_image = I_i * (1 - mask_binary)
            
            # Prepare input for LaMa: stack(masked_image, mask_binary)
            inpaint_input = torch.cat([masked_image, mask_binary], dim=1)
            
            # Restore static image and depth
            I_restored, D_restored = self.inpainting_module(inpaint_input)
            
            # Render static depth (simplified)
            D_static = render_depth(t, sigma)
            
            # Step 8: Compute Losses
            # Static Photometric Loss (outside mask)
            L_s = torch.mean((C_static - I_i) ** 2 * (1 - mask_prob))
            
            # Transient Loss
            # Term 1: Occlusion error (outside mask)
            # Term 2: Reconstruction error (inside mask, using lambda)
            L_t = torch.mean((1 - mask_prob) * (C_static - I_i)**2) + \
                  self.lambda_transient * torch.mean(mask_prob * (C_static - I_restored)**2)
            
            # Perceptual Loss (LPIPS) inside mask
            L_lpips = compute_lpips(C_static, I_restored) * mask_prob.mean()
            
            # Depth Loss
            L_depth = torch.mean((D_static - D_restored)**2)
            
            total_loss = self.alpha * L_s + self.beta * L_t + self.gamma * L_lpips + self.rho * L_depth
            losses.append(total_loss)
            
        return torch.mean(torch.stack(losses))

def get_ippe_with_freq_reg(t, max_freq, iteration, T, l_i):
    # Standard IPE for mip-NeRF
    pos_enc = integrated_positional_encoding(t)
    
    # Frequency Regularization Mask
    r = get_transient_mask_factor() # Ratio of transient pixels
    omega = torch.zeros_like(pos_enc)
    
    for i in range(pos_enc.shape[-1]):
        threshold_low = int(iteration * max_freq / T)
        threshold_high = threshold_low + 6
        
        if i <= threshold_low:
            omega[..., i] = r
        elif threshold_low < i <= threshold_high:
            omega[..., i] = (iteration * max_freq / T) - threshold_low
        else:
            omega[..., i] = 0
            
    return pos_enc * omega

class CNN_Encoder(nn.Module):
    def __init__(self):
        super().__init__()
        # Placeholder for CNN architecture
        self.conv = nn.Conv2d(3, 256, kernel_size=3, padding=1)
        
    def forward(self, x):
        return F.relu(self.conv(x))

class MLP_Density(nn.Module):
    def __init__(self, num_layers, hidden_dim):
        super().__init__()
        layers = []
        for _ in range(num_layers):
            layers.append(nn.Linear(hidden_dim, hidden_dim))
            layers.append(nn.ReLU())
        self.mlp = nn.Sequential(*layers)
        
    def forward(self, x):
        out = self.mlp(x)
        sigma = torch.sigmoid(out[..., :1]) # Density
        z = out[..., 1:] # Intermediate feature
        return sigma, z

class MLP_Radiance(nn.Module):
    def __init__(self, hidden_dim, color_dim):
        super().__init__()
        self.fc1 = nn.Linear(hidden_dim + 3 + 27, color_dim) # z, pos, dir
        self.fc_mask = nn.Linear(color_dim, 1)
        self.fc_color = nn.Linear(color_dim, 3)
        
    def forward(self, dir_enc, z, l_i):
        # Concatenate features
        x = torch.cat([z, l_i, dir_enc], dim=-1)
        h = torch.relu(self.fc1(x))
        l_t = self.fc_mask(h)
        c = torch.sigmoid(self.fc_color(h))
        return c, l_t
```

**Edge Cases and Pitfalls:**
*   **Small Datasets/Sparse Inputs:** The method struggles when the transient mask lacks sufficient information to infer the inpainting process [S1].
*   **Blurry Results:** Inpainting modules may produce blurry results and inconsistencies across views [S1]. Mitigated by using LPIPS loss inside the mask and depth supervision [S1].
*   **High-Frequency Instability:** High-frequency signals cause instability in transient separation [S1]. Mitigated by starting training without positional encoding and incrementally boosting frequency (RegFre-IPE) [S1].

## Operating characteristics
*   **Time and Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Evaluated on the Phototourism dataset (Brandenburg Gate, Sacre Coeur, Trevi Fountain, Taj Mahal) using 2x downsampled images [S1].
    *   **Brandenburg Gate:** PSNR 25.33, SSIM 0.898, LPIPS 0.158 [S1]. Outperforms NeRF (18.90/0.816/0.232), NeRF-W (24.17/0.891/0.167), and Ha-NeRF (24.04/0.877/0.139) [S1].
    *   **Ablation on Training Strategy (Brandenburg Gate):** RegFre-IPE (25.33/0.898/0.158) > IPE (23.58/0.864/0.191) > WT-IPE (19.86/0.723/0.289) [S1].
    *   **Ablation on Mask Generation:** IE-NeRF(Ours) (25.33/0.898/0.158) > IE-NeRF(SM) (24.65/0.879/0.187) > IE-NeRF(IM) (22.27/0.802/0.191) [S1].
*   **Scaling:** Not given in the sources.
*   **Strengths:** Effective at separating static and transient components in uncontrolled environments without requiring 3D transient fields or semantic priors [S1].
*   **Limitations:** Struggles with small datasets and sparse inputs; may overlook shadows or images on walls if relying on semantic masks (though IE-NeRF(Ours) avoids this) [S1].

## Background
IE-NeRF was proposed by Wang et al. from Sun Yat-sen University and Pengcheng Laboratory [S1]. It was published in *Neurocomputing* in 2024 (arXiv:2407.10695v2, Dec 8, 2024) [S1]. The method builds on [Model Architecture Modifications](11313-model-architecture-modifications.md) [G]. It addresses limitations of NeRF-W and Ha-NeRF by using a single-stage inpainting-enhanced pipeline rather than dual NeRFs or semantic segmentation priors [S1].
