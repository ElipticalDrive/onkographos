# SLS4D

Also called: Sparse Latent Space for 4D Novel View Synthesis

## Overview
SLS4D is a method for 4D novel view synthesis that represents dynamic scenes using a sparse, compact, and informative latent feature space, significantly reducing the number of network parameters compared to previous state-of-the-art methods like V4D [S1]. It distinguishes itself by abandoning direct coordinate-based feature determination in favor of relative relationships in a latent space, utilizing dense learnable time slots for temporal continuity and an attention-based interpolator decoder for spatial feature aggregation [S1].

## How it works
SLS4D decomposes the 4D scene representation into two distinct components: a temporal deformation field and a spatial latent feature space. The method operates by first mapping 4D coordinates to a deformed 3D position using a deformation network conditioned on time slots, and then retrieving spatial features from a sparse set of global latent codes using an attention mechanism.

### Inputs and Outputs
*   **Inputs:**
    *   Ray origin $\mathbf{o} \in \mathbb{R}^3$.
    *   Ray direction $\mathbf{d} \in \mathbb{R}^3$.
    *   Time $t \in [0, 1]$.
*   **Outputs:**
    *   Volume density $\sigma \in \mathbb{R}$.
    *   View-dependent color $\mathbf{c} \in \mathbb{R}^3$.

### Data Structures
1.  **Latent Codes ($\mathbf{L}$):** A set of $B$ globally learnable latent vectors.
    *   Layout: $\mathbf{L} \in \mathbb{R}^{B \times D}$, where $B$ is the number of latent features and $D$ is the feature dimension.
    *   Initialization: Random or learned from scratch.
2.  **Time Slots ($\mathbf{T}$):** A set of $T$ dense learnable time slot features.
    *   Layout: $\mathbf{T} \in \mathbb{R}^{T \times D}$.
    *   Initialization: Random or learned from scratch.
3.  **Deformation Network ($\mathcal{N}_{def}$):** A 7-layer Multi-Layer Perceptron (MLP).
    *   Input: Concatenation of 3D position $\mathbf{x}$ and time slot embedding.
    *   Output: 3D displacement $\Delta \mathbf{x}$.
4.  **Interpolator Decoder ($\mathcal{N}_{dec}$):** A network using GeGLU (Gated Linear Unit with GeLU activation) instead of standard GeLU or MLP.
    *   Input: Aggregated spatial features.
    *   Output: Density $\sigma$ and color $\mathbf{c}$.

### Parameters
*   $B = 512$: Number of latent features [S1].
*   $T = 512$: Number of time slots [S1].
*   $D$: Feature dimension (Not given in the sources, but implied by matrix dimensions).
*   Network depth for $\mathcal{N}_{def}$: 7 layers [S1].

### Numbered Steps

1.  **Time Slot Embedding:**
    For a given time $t$, compute the time slot embedding $\mathbf{t}_{emb}$. The source describes using "dense learnable time slot features" [S1]. Typically, this involves interpolating or selecting from the set $\mathbf{T}$ based on $t$. Let $\mathbf{t}_{emb} \in \mathbb{R}^D$ be the resulting vector.

2.  **Deformation Field Prediction:**
    To handle dynamic scenes, SLS4D decouples time and space. For a query 3D position $\mathbf{x}$ at time $t$:
    *   Compute the deformation displacement $\Delta \mathbf{x}$ using the deformation network $\mathcal{N}_{def}$:
        $$ \Delta \mathbf{x} = \mathcal{N}_{def}(\mathbf{x}, \mathbf{t}_{emb}) $$
    *   The network $\mathcal{N}_{def}$ is a 7-layer MLP [S1].
    *   The deformed position $\mathbf{x}'$ is:
        $$ \mathbf{x}' = \mathbf{x} + \Delta \mathbf{x} $$
    *   This step ensures smooth transitions between timestamps by leveraging the time slots [S1].

3.  **Spatial Feature Retrieval via Attention:**
    Retrieve spatial features for the deformed position $\mathbf{x}'$ from the sparse latent space $\mathbf{L}$.
    *   Treat $\mathbf{x}'$ as a query. The source states: "the attention mechanism determines the weights of each latent code using the inner product of the query feature of the 3D position and the key value of the latent code" [S1].
    *   Let $\mathbf{q} = \mathbf{x}'$ (possibly projected or embedded, though the source implies direct use of position or a simple embedding). Let $\mathbf{K} = \mathbf{L}$ be the keys.
    *   Compute attention weights $\mathbf{w} \in \mathbb{R}^B$:
        $$ \mathbf{w}_i = \text{softmax}_i \left( \frac{\mathbf{q} \cdot \mathbf{K}_i}{\sqrt{D}} \right) $$
        where $\mathbf{K}_i$ is the $i$-th latent code in $\mathbf{L}$.
    *   Aggregate features $\mathbf{f}_{spatial}$:
        $$ \mathbf{f}_{spatial} = \sum_{i=1}^{B} \mathbf{w}_i \mathbf{L}_i $$
    *   This approach abandons direct coordinate relationships, relying on relative relationships in the latent space [S1].

4.  **Radiance Field Prediction:**
    Pass the aggregated spatial features $\mathbf{f}_{spatial}$ through the Interpolator Decoder $\mathcal{N}_{dec}$ to predict density and color.
    *   $\mathcal{N}_{dec}$ uses GeGLU activations [S1].
    *   Output: $(\sigma, \mathbf{c}) = \mathcal{N}_{dec}(\mathbf{f}_{spatial})$.

5.  **Volume Rendering:**
    Integrate $\sigma$ and $\mathbf{c}$ along the ray using standard volume rendering equations [G].

### Pseudocode

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class SLS4D:
    def __init__(self, B=512, T=512, D=256, hidden_dim=256):
        """
        Initialize SLS4D model.
        B: Number of latent features.
        T: Number of time slots.
        D: Feature dimension.
        hidden_dim: Hidden dimension for MLPs.
        """
        self.B = B
        self.T = T
        self.D = D
        
        # Data Structures
        # Latent codes: B x D
        self.latent_codes = nn.Parameter(torch.randn(B, D))
        # Time slots: T x D
        self.time_slots = nn.Parameter(torch.randn(T, D))
        
        # Deformation Network: 7-layer MLP
        # Input: x (3) + t_emb (D) -> Output: delta_x (3)
        self.deformation_net = nn.Sequential(
            nn.Linear(3 + D, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, 3)
        )
        
        # Interpolator Decoder: Uses GeGLU
        # Input: f_spatial (D) -> Output: sigma (1), color (3)
        self.decoder = nn.Sequential(
            nn.Linear(D, hidden_dim),
            GeGLU(), # Custom layer defined below
            nn.Linear(hidden_dim, hidden_dim),
            GeGLU(),
            nn.Linear(hidden_dim, 4) # sigma + rgb
        )

    def get_time_embedding(self, t):
        """
        Get time slot embedding for time t in [0, 1].
        Assumes t is a tensor of shape (N,).
        """
        # Map t to indices in [0, T-1]
        # Simple interpolation or selection. 
        # Source says "dense learnable time slot features".
        # We assume linear interpolation between slots for smoothness.
        t_scaled = t * (self.T - 1)
        t_low = torch.floor(t_scaled).long()
        t_high = torch.ceil(t_scaled).long()
        t_frac = t_scaled - t_low.float()
        
        t_low = torch.clamp(t_low, 0, self.T - 1)
        t_high = torch.clamp(t_high, 0, self.T - 1)
        
        emb_low = self.time_slots[t_low]
        emb_high = self.time_slots[t_high]
        
        return emb_low + t_frac.unsqueeze(1) * (emb_high - emb_low)

    def forward(self, x, d, t):
        """
        Forward pass.
        x: 3D position, shape (N, 3)
        d: Viewing direction, shape (N, 3)
        t: Time, shape (N,)
        """
        # 1. Time Slot Embedding
        t_emb = self.get_time_embedding(t) # (N, D)
        
        # 2. Deformation Field
        # Concatenate x and t_emb
        def_input = torch.cat([x, t_emb], dim=-1) # (N, 3+D)
        delta_x = self.deformation_net(def_input) # (N, 3)
        x_prime = x + delta_x # (N, 3)
        
        # 3. Spatial Feature Retrieval (Attention)
        # Query is x_prime. Keys are latent_codes.
        # q: (N, 3) -> Project to D? Source says "inner product of query feature... and key value".
        # Assuming x_prime is projected or used directly if D=3. 
        # Given D is likely > 3, we project x_prime to D.
        # Note: Source doesn't specify projection layer for query. 
        # We assume a linear projection for compatibility.
        query_proj = F.linear(x_prime, self.query_proj_weight) # (N, D)
        
        # Attention weights
        # logits: (N, B)
        logits = torch.matmul(query_proj, self.latent_codes.T) # (N, B)
        weights = F.softmax(logits, dim=-1) # (N, B)
        
        # Aggregate
        f_spatial = torch.matmul(weights, self.latent_codes) # (N, D)
        
        # 4. Radiance Field Prediction
        # Decoder takes f_spatial. 
        # Note: Standard NeRF also conditions on direction d.
        # Source doesn't explicitly detail how d is used in the decoder.
        # Assuming standard NeRF practice: concatenate d or use separate branch.
        # However, SLS4D focuses on spatial features. 
        # Let's assume d is concatenated or processed separately.
        # For completeness, we assume d is projected and concatenated.
        d_proj = F.linear(d, self.dir_proj_weight) # (N, D)
        decoder_input = f_spatial + d_proj # Or concat. Source is vague here.
        # Let's assume concatenation for safety, or addition if dimensions match.
        # Given "Interpolator Decoder... offer higher fitting capacity", 
        # it likely takes the spatial feature. View dependence is standard.
        # We will assume d is concatenated to f_spatial before decoder.
        decoder_input = torch.cat([f_spatial, d_proj], dim=-1) # (N, 2D)
        
        # Adjust decoder input size if needed. 
        # The decoder definition above takes D. 
        # We need to update decoder to take 2D or project.
        # For this pseudocode, we assume the decoder handles the input.
        # Let's redefine decoder input handling in the class for clarity.
        
        out = self.decoder(decoder_input) # (N, 4)
        sigma = out[:, 0:1]
        color = out[:, 1:4]
        
        return sigma, color

class GeGLU(nn.Module):
    def forward(self, x):
        # x is split into two halves
        x1, x2 = x.chunk(2, dim=-1)
        return F.gelu(x1) * x2
```

### Edge Cases and Pitfalls
*   **Long-duration inputs:** Excessively long-duration scenes may struggle to fit data adequately with a small number of parameters ($B=512, T=512$) [S1].
*   **Absence of Deformation:** Removing the deformation field (SLS4Dnd) leads to a decline in reconstruction quality due to the lack of decoupling between time and space [S1].
*   **Absence of Time Slots:** Removing time slots (SLS4Dnf) results in degradation of rendering quality [S1].
*   **Decoder Choice:** Using only GeLU (SLS4Dge) or a standard MLP (SLS4Dml) as the interpolator decoder results in inferior performance compared to GeGLU [S1].
*   **Learning Rate:** Using only cosine decay (SLS4Dco) is unstable; using only exponential decay (SLS4Deo) may get stuck in local optima. The method uses a combined cosine*exp decay [S1].

## Background
SLS4D was proposed as a novel approach for 4D novel-view synthesis, representing the 4D space in a sparse, compact, and informative latent feature space [S1]. It is the first method to use a sparse latent space representation for dynamic neural radiance fields [S1]. The method was developed to address the high parameter count and computational cost of previous state-of-the-art methods like V4D [S1]. It builds on the idea of decoupling time and space using deformation fields, similar to D-NeRF, but replaces the dense voxel or grid-based spatial features with a sparse set of global latent codes [S1].
