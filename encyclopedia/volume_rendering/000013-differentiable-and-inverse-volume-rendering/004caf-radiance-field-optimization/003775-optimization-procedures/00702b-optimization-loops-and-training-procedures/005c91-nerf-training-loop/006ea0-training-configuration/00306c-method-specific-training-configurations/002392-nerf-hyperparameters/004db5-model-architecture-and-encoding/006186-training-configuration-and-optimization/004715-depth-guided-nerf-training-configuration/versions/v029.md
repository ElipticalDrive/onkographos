# Depth-Guided NeRF Training Configuration

Also called: Depth-Guided NeRF Training

## Overview
A training configuration for Neural Radiance Fields (NeRF) that incorporates depth priors to regularize the optimization process, addressing the ambiguity of scale and geometry in sparse-view or uncalibrated settings [S1]. It distinguishes itself from standard NeRF training by explicitly integrating a depth loss term and modifying the MLP architecture with dropout to prevent overfitting to noisy depth estimates [S1].

## How it works
The method modifies the standard NeRF optimization loop by adding architectural regularization and a weighted depth supervision term to the loss function.

**Inputs and Outputs**
*   **Inputs:** Camera poses, images, and ground-truth depth maps (or depth estimates from a separate module).
*   **Outputs:** Trained NeRF model parameters (MLP weights, embedding tables) and rendered images/depths.

**Data Structures**
The network architecture builds upon the original NeRF MLP [S1].
*   **MLP Layers:** Fully connected layers with ReLU activation.
*   **Dropout:** Applied after the first eight fully connected layers.
*   **Depth Scale:** A learnable parameter or scaling factor for depth predictions, optimized with a distinct learning rate [S1].

**Parameters**
*   **Depth loss weight ($\lambda$):** 0.007 for most scenes; 0.02 for scene 710 [S1].
*   **Uncertainty weight ($\gamma$):** 1 [S1].
*   **Optimizer:** Adam [S1].
*   **Learning Rate (Base):** $5 \times 10^{-4}$ [S1].
*   **Learning Rate Schedule:** Reduced to $5 \times 10^{-5}$ after 80% of total steps [S1].
*   **Weight Decay:** $1 \times 10^{-6}$ [S1].
*   **Total Training Steps:** 500,000 [S1].
*   **Depth Scale Learning Rate:** $1 \times 10^{-7}$ [S1].
*   **Depth Threshold ($\tau$):** Used to evaluate depth uncertainty. Calculated as $\tau = (\text{max\_depth} - \text{min\_depth}) \cdot 0.0001$ [S1].
    *   For ScanNet: $\text{max\_depth} = 10$, $\text{min\_depth} = 0.001$ [S1].

**Numbered Steps**
1.  **Initialize** the NeRF MLP with positional encoding.
2.  **Apply Dropout:** Insert dropout layers with probability $p=0.1$ after each of the first eight fully connected ReLU-activated layers [S1].
3.  **Sample Rays:** For each training image, sample points along rays.
4.  **Render:** Compute color and depth for each ray using the current network state.
5.  **Compute Color Loss:** Calculate the photometric reconstruction loss (e.g., MSE) between rendered and ground-truth colors.
6.  **Compute Depth Loss:** Calculate the discrepancy between rendered/estimated depth and ground-truth depth, scaled by $\lambda$ [S1].
7.  **Compute Uncertainty:** Evaluate depth map uncertainty using the threshold $\tau$ defined in [S1].
8.  **Aggregate Loss:** Combine losses using weights $\lambda$ and $\gamma$ [S1].
9.  **Update:** Perform gradient descent using Adam with the specified learning rates and weight decay [S1].
10. **Schedule:** Reduce the base learning rate to $5 \times 10^{-5}$ after 80% of the 500,000 steps [S1].

**Pseudocode**
```python
# Configuration constants
DROPOUT_PROB = 0.1
NUM_DROPOUT_LAYERS = 8
LAMBDA_DEPTH = 0.007  # 0.02 for scene 710
GAMMA_UNCERTAINTY = 1
INITIAL_LR = 5e-4
FINAL_LR = 5e-5
LR_SCHEDULE_STEP = 0.8
WEIGHT_DECAY = 1e-6
TOTAL_STEPS = 500000
DEPTH_SCALE_LR = 1e-7

def compute_threshold(max_depth, min_depth):
    """Compute uncertainty threshold tau."""
    return (max_depth - min_depth) * 0.0001

def train_depth_guided_nerf(model, data_loader, optimizer, depth_scale_param):
    """
    Training loop for Depth-Guided NeRF.
    """
    model.apply_dropout_after_first_n_layers(n=NUM_DROPOUT_LAYERS, prob=DROPOUT_PROB)
    
    for step, batch in enumerate(data_loader):
        images, poses, gt_depths = batch
        
        # Forward pass
        rendered_colors, rendered_depths = model(poses)
        
        # Compute Color Loss (e.g., MSE)
        color_loss = mean_squared_error(rendered_colors, images)
        
        # Compute Depth Loss
        # Note: Specific depth loss formula (e.g., L1, L2, EMD) is not detailed in [S1]
        # beyond the weight lambda. Assuming standard L2 or similar based on context.
        depth_loss = mean_squared_error(rendered_depths, gt_depths)
        
        # Compute Uncertainty (if applicable)
        # Threshold calculation for ScanNet as example
        max_d = 10.0
        min_d = 0.001
        tau = compute_threshold(max_d, min_d)
        uncertainty = evaluate_depth_uncertainty(rendered_depths, tau)
        
        # Aggregate Loss
        # Formula structure inferred from weights lambda and gamma
        total_loss = color_loss + (LAMBDA_DEPTH * depth_loss) + (GAMMA_UNCERTAINTY * uncertainty)
        
        # Backward pass
        optimizer.zero_grad()
        total_loss.backward()
        
        # Update parameters
        optimizer.step()
        
        # Learning rate schedule
        if step > TOTAL_STEPS * LR_SCHEDULE_STEP:
            set_learning_rate(optimizer, FINAL_LR)
            set_learning_rate(depth_scale_param, DEPTH_SCALE_LR)
        else:
            set_learning_rate(optimizer, INITIAL_LR)
            set_learning_rate(depth_scale_param, DEPTH_SCALE_LR)
```

## Subtopics

### DS-NeRF Depth Loss Integration
Integrates the depth loss implementation from the official DS-NeRF code base into the training pipeline [S2]. Due to missing configuration files for DTU in the official release, results were reproduced using released configs for LLFF on specific train/test splits, as original LLFF results used a different split [S2].

## Operating characteristics
*   **Complexity:** Standard NeRF complexity, with additional overhead for depth map computation and loss calculation.
*   **Performance:** Improves geometric accuracy and scale consistency in scenes with available depth priors [S1].
*   **Limitations:** Sensitive to the quality of ground-truth depth; requires careful tuning of $\lambda$ (e.g., 0.02 for scene 710 vs 0.007 for others) [S1]. Overfitting can occur if architectural regularization (dropout) is not applied [S1].

## Background
Originated from the work on Depth-Guided NeRF Training via Earth Mover’s Distance [S1]. The approach builds on the original NeRF architecture [S1] and incorporates techniques from DS-NeRF for depth loss integration [S2]. It is used in scenarios where depth information is available to regularize the inverse volume rendering problem.
