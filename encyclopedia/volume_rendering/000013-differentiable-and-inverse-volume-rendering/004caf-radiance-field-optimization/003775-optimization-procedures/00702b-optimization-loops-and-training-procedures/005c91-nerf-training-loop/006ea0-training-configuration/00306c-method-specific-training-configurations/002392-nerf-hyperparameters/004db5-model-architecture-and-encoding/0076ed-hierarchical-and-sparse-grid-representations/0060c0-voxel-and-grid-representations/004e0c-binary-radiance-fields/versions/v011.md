# Binary Radiance Fields

Also called: BRF

## Overview
Binary Radiance Fields (BiRF) is a storage-efficient radiance field representation that constrains feature grid parameters to binary values (+1 or -1) to achieve compact storage [S1]. Unlike post-processing compression methods such as PlenOctrees or Re:NeRF, which require additional optimization steps and are bounded by pre-trained model performance, BiRF performs binarization during training without post-optimization [S1]. It utilizes a 2D-3D hybrid multi-resolution architecture to maintain reconstruction quality while significantly reducing storage overhead compared to real-valued floating-point grids [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D spatial coordinate $\mathbf{x} \in \mathbb{R}^3$, viewing direction $\mathbf{d} \in \mathbb{R}^3$.
*   **Outputs:** Volume density $\sigma \in \mathbb{R}$, RGB color $\mathbf{c} \in [0, 1]^3$.

**Data Structures:**
The radiance field consists of a multi-resolution 2D-3D hybrid feature grid implemented using hash encoding [S1].
1.  **3D Voxel Grid ($\Phi_{\theta_{xyz}}$):** Contains $L$ levels with resolutions ranging from 16 to 1024. Each level holds up to $T_{3D}$ feature vectors.
2.  **2D Plane Grids ($\Phi_{\theta_{xy}}, \Phi_{\theta_{xz}}, \Phi_{\theta_{yz}}$):** Three orthogonal planes. Each contains $M$ levels with resolutions ranging from 64 to 512. Each level holds up to $T_{2D}$ feature vectors.
3.  **Feature Vectors:** Each entry in the grids is a vector of dimension $F$. The parameters $\theta$ are constrained to $\{-1, +1\}$ [S1].

**Parameters:**
*   $L$: Number of 3D grid levels.
*   $M$: Number of 2D grid levels.
*   $T_{3D}$: Max feature vectors per 3D level. Small model (Ours-S): $\log_2(T_{3D}) = 17$. Base model (Ours-B): $\log_2(T_{3D}) = 19$ [S1].
*   $T_{2D}$: Max feature vectors per 2D level. Small model (Ours-S): $\log_2(T_{2D}) = 15$. Base model (Ours-B): $\log_2(T_{2D}) = 17$ [S1].
*   $F$: Feature dimension per level. Variants use $F \in \{2, 4, 8\}$ [S1].
*   $\lambda_{\text{sparsity}}$: Sparsity loss weight. Value: $2.0 \times 10^{-5}$ [S1].
*   MLPs: Shallow networks with 128-channel hidden layers and ReLU activation. Density MLP has 1 hidden layer; Color MLP has 2 hidden layers [S1].

**Algorithm:**

1.  **Binarization:**
    Real-valued grid parameters $\theta$ are transformed to binary $\theta'$ using the sign function:
    $$ \theta' = \text{sign}(\theta) = \begin{cases} +1 & \text{if } \theta \ge 0 \\ -1 & \text{otherwise} \end{cases} $$
    During training, gradients are propagated using the Straight-Through Estimator (STE). The gradient is passed if $|\theta| \le 1$, otherwise it is zeroed to prevent scale divergence [S1].

2.  **Feature Encoding:**
    For an input coordinate $\mathbf{x} = (x, y, z)$:
    *   **3D Features ($f_{xyz}$):** Tri-linearly interpolate binary parameters from the 3D grid across $L$ levels and concatenate:
        $$ f_{xyz} = \{ \text{interp}(\mathbf{x}, \text{sign}(\Phi^l_{\theta_{xyz}})) \}_{l=1}^L $$
    *   **2D Features ($f_{xy}, f_{xz}, f_{yz}$):** Project $\mathbf{x}$ to 2D coordinates ($\mathbf{x}_{xy}=(x,y)$, etc.). Bi-linearly interpolate binary parameters from the respective 2D grids across $M$ levels and concatenate:
        $$ f_{xy} = \{ \text{interp}(\mathbf{x}_{xy}, \text{sign}(\Phi^m_{\theta_{xy}})) \}_{m=1}^M $$
        Repeat for $f_{xz}$ and $f_{yz}$ [S1].
    *   **Concatenation:** Combine all features:
        $$ \mathbf{f} = \{ f_{xyz}, f_{xy}, f_{xz}, f_{yz} \} $$

3.  **Positional Encoding:**
    Apply sinusoidal positional encoding $\gamma(\mathbf{x})$ to the input coordinate $\mathbf{x}$ [S1].

4.  **Density Prediction:**
    Feed $\gamma(\mathbf{x})$ and $\mathbf{f}$ into the density MLP:
    $$ (\sigma, \mathbf{e}) = \text{MLP}_{\text{density}}(\gamma(\mathbf{x}), \mathbf{f}) $$
    where $\sigma$ is density and $\mathbf{e}$ is the embedded feature vector [S1].

5.  **Color Prediction:**
    Feed $\mathbf{e}$ and directional encoding $\mathbf{d}$ (using spherical harmonics) into the color MLP:
    $$ \mathbf{c} = \text{MLP}_{\text{color}}(\mathbf{e}, \mathbf{d}) $$

6.  **Loss Calculation:**
    *   **Reconstruction Loss:** $L_{\text{recon}} = \sum_{\mathbf{r} \in \mathcal{R}} ||\hat{C}(\mathbf{r}) - C(\mathbf{r})||_2^2$ [S1].
    *   **Sparsity Loss:** $L_{\text{sparsity}} = \sum_{i,k} \log(1 + 2\sigma(\mathbf{r}_i(t_k))^2)$ [S1].
    *   **Total Loss:** $L = L_{\text{recon}} + \lambda_{\text{sparsity}} L_{\text{sparsity}}$ [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import math

class BinaryRadianceField:
    def __init__(self, L=4, M=4, T_3D=131072, T_2D=32768, F=2):
        """
        Initialize BiRF.
        L: Number of 3D grid levels.
        M: Number of 2D grid levels.
        T_3D: Max feature vectors per 3D level.
        T_2D: Max feature vectors per 2D level.
        F: Feature dimension per level.
        """
        self.L = L
        self.M = M
        self.F = F
        
        # Initialize hash grids with real-valued parameters
        # In practice, these are managed by a hash map implementation like Instant-NGP
        # Here we simulate the structure for clarity
        self.grid_3d = [nn.Embedding(T_3D, F) for _ in range(L)]
        self.grid_xy = [nn.Embedding(T_2D, F) for _ in range(M)]
        self.grid_xz = [nn.Embedding(T_2D, F) for _ in range(M)]
        self.grid_yz = [nn.Embedding(T_2D, F) for _ in range(M)]
        
        # Initialize MLPs
        # Density MLP: Input dim = pos_enc_dim + L*F + 3*M*F, Output = 1 + F
        # Color MLP: Input dim = F + dir_enc_dim, Output = 3
        self.density_mlp = nn.Sequential(
            nn.Linear(64 + L*F + 3*M*F, 128),
            nn.ReLU(),
            nn.Linear(128, 1 + F) # sigma, e
        )
        self.color_mlp = nn.Sequential(
            nn.Linear(F + 27, 128), # e + SH(3)
            nn.ReLU(),
            nn.Linear(128, 128),
            nn.ReLU(),
            nn.Linear(128, 3)
        )
        
    def binarize(self, grid_params):
        """
        Apply binarization with Straight-Through Estimator.
        """
        # Forward pass: sign function
        binary_params = torch.sign(grid_params)
        
        # Backward pass: STE
        # Gradient is passed if |param| <= 1, else 0
        # Note: In PyTorch, this requires a custom autograd function or hook.
        # Here we assume a helper function `ste_sign` exists.
        return ste_sign(grid_params)

    def get_features_3d(self, x, grid_levels):
        """
        Tri-linear interpolation of 3D grid features.
        x: (N, 3) coordinates.
        """
        features = []
        for l in range(self.L):
            # Hash x to get indices, lookup embeddings, interpolate
            # Simplified: assume hash_grid_lookup returns interpolated features
            feats = hash_grid_lookup(self.grid_3d[l], x)
            feats = self.binarize(feats)
            features.append(feats)
        return torch.cat(features, dim=-1)

    def get_features_2d(self, x, grid_levels):
        """
        Bi-linear interpolation of 2D grid features.
        """
        features = []
        # Project to xy, xz, yz
        x_xy = x[:, :2]
        x_xz = x[:, [0, 2]]
        x_yz = x[:, [1, 2]]
        
        for m in range(self.M):
            feats_xy = hash_grid_lookup(self.grid_xy[m], x_xy)
            feats_xz = hash_grid_lookup(self.grid_xz[m], x_xz)
            feats_yz = hash_grid_lookup(self.grid_yz[m], x_yz)
            
            feats_xy = self.binarize(feats_xy)
            feats_xz = self.binarize(feats_xz)
            feats_yz = self.binarize(feats_yz)
            
            features.append(torch.cat([feats_xy, feats_xz, feats_yz], dim=-1))
        return torch.cat(features, dim=-1)

    def forward(self, x, d):
        """
        Forward pass.
        x: (N, 3) coordinates.
        d: (N, 3) viewing directions.
        """
        # Positional encoding
        gamma_x = positional_encoding(x)
        
        # Feature encoding
        f_xyz = self.get_features_3d(x, self.L)
        f_2d = self.get_features_2d(x, self.M)
        f = torch.cat([f_xyz, f_2d], dim=-1)
        
        # Density prediction
        density_out = self.density_mlp(torch.cat([gamma_x, f], dim=-1))
        sigma = density_out[:, :1]
        e = density_out[:, 1:]
        
        # Color prediction
        gamma_d = directional_encoding(d) # Spherical harmonics
        c = self.color_mlp(torch.cat([e, gamma_d], dim=-1))
        c = torch.sigmoid(c) # Bound to [0, 1]
        
        return sigma, c

    def loss(self, sigma, c, target_sigma, target_c):
        """
        Calculate total loss.
        """
        L_recon = torch.mean((c - target_c) ** 2)
        L_sparsity = torch.mean(torch.log(1 + 2 * sigma ** 2))
        lambda_sparsity = 2.0e-5
        return L_recon + lambda_sparsity * L_sparsity
```

## Operating characteristics
*   **Storage:** Extremely compact. The small model (Ours-S2) requires less than 0.5 MB of storage [S1]. This outperforms baselines like TensoRF-CP (3.7 MB) and Instant-NGP (24.5 MB) on the mic scene [S1].
*   **Performance:** Achieves PSNR of 32.03 dB on Synthetic-NeRF, 34.48 dB on Synthetic-NSVF, and 28.20 dB on Tanks and Temples [S1].
*   **Training Time:** Approximately 6, 9, and 14 minutes for Synthetic-NeRF scenes for Ours-B2 to Ours-B8 models on a single NVIDIA RTX A6000 [S1].
*   **Strengths:** Significant reduction in storage overhead compared to real-valued grids; no post-optimization required; superior reconstruction quality compared to prior efficient methods with smaller storage [S1].
*   **Limitations:** Hash collisions in 3D grids at higher resolutions are mitigated by 2D grids but remain a factor; gradient vanishing is handled by STE but requires careful scale management [S1].

## Background
Binary Radiance Fields were proposed by Seungjoo Shin and Jaesik Park from POSTECH and Seoul National University, published in arXiv:2306.07581v2 on December 4, 2023 [S1]. The method builds on the Instant-NGP architecture [20] and uses the occupancy grid from NerfAcc [42] for efficient ray sampling [S1]. It addresses the storage bottleneck of neural radiance fields by introducing binary feature encoding [S1].
