# KFD-NeRF

Also called: Kalman Filter Guided Deformation Field NeRF, Kalman Filter Guided Dynamic NeRF

## Overview
KFD-NeRF is a dynamic neural radiance field method that models the 4D radiance field as a dynamic system with temporally varying states, estimated using a Kalman filter to combine observations from input data and predictions based on local linear motion equations [S1]. It differs from sibling methods like [Gear-NeRF](13848-gear-nerf.md) and [NeRF with Time Parameter](14705-nerf-with-time-parameter.md) by explicitly separating motion estimation into an observer branch (direct observation via a shallow MLP) and a predictor branch (history-based prediction), fusing them via a learnable Kalman gain [S1]. Unlike [Forward Warping for Novel View Synthesis](15541-forward-warping-for-novel-view-synthesis.md) which may rely on feature interpolation, KFD-NeRF uses deformation fields warped to a canonical space represented by tri-planes, leveraging the inductive smoothness bias of MLPs for deformation while using voxel-based tri-planes for efficient spatial encoding [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of images with known camera poses and timestamps $t_i$. 3D points $\mathbf{x}$ in real space.
*   **Outputs:** Deformation fields $\Delta \mathbf{x}$ mapping real-space points to a time-independent canonical space, and radiance values (color and density) in the canonical space.

**Data Structures:**
1.  **Tri-Plane Representation:** Three mutually orthogonal 2D planes encoding the canonical space. Features from these planes are concatenated with raw coordinate inputs to handle coordinate shift errors [S1].
2.  **Observer MLP:** A two-layer shallow MLP. Inputs: 3D coordinates $\mathbf{x}$ and timestamp $t_i$. Outputs: Mean observation $\mathbf{y}_{t_i}$ and noise-related terms $\varepsilon_{t_i}$ [S1].
3.  **Kalman Gain Network:** A linear layer. Inputs: Noise terms $\varepsilon_{t_i}, \varepsilon_{t_{i-1}}$ and timestamps $t_i, t_{i-1}$. Output: Kalman gain $K_{t_i}$ [S1].

**Numbered Steps:**

1.  **Initialization:** For the first two frames ($t_0, t_1$), initialize deformation estimates. For subsequent frames, use previous estimates.
2.  **Prediction Branch:**
    *   Retrieve deformation estimates from the two previous frames: $\Delta \mathbf{x}_{t_{i-1}}$ and $\Delta \mathbf{x}_{t_{i-2}}$ [S1].
    *   Calculate the approximate velocity $\mathbf{v}_{t_i}$ using the local linear motion model:
        $$ \mathbf{v}_{t_i} = (\Delta \mathbf{x}_{t_{i-1}} - \Delta \mathbf{x}_{t_{i-2}}) / \Delta t_i $$
        where $\Delta t_i = t_i - t_{i-1}$ [S1].
    *   Compute the predicted deformation state $\hat{\mathbf{d}}_{t_i}^{-}$:
        $$ \hat{\mathbf{d}}_{t_i}^{-} = \Delta \mathbf{x}_{t_{i-1}} + \Delta t_i \cdot \mathbf{v}_{t_i} $$
        Simplifying, this is equivalent to:
        $$ \hat{\mathbf{d}}_{t_i}^{-} = 2\Delta \mathbf{x}_{t_{i-1}} - \Delta \mathbf{x}_{t_{i-2}} $$
        [S1].
3.  **Observation Branch:**
    *   Query the Observer MLP with the current 3D point $\mathbf{x}$ and timestamp $t_i$.
    *   Obtain the mean observation $\mathbf{y}_{t_i}$ and noise-related terms $\varepsilon_{t_i}$ [S1].
4.  **Kalman Gain Calculation:**
    *   Compute the Kalman gain $K_{t_i}$ using the linear layer $f$:
        $$ K_{t_i} = f(\varepsilon_{t_i}, \varepsilon_{t_{i-1}}, t_i, t_{i-1}) $$
        [S1].
5.  **Deformation Estimation (Update):**
    *   Combine the prediction and observation using the Kalman gain to produce the final deformation estimation $\hat{\mathbf{d}}_{t_i}$:
        $$ \hat{\mathbf{d}}_{t_i} = \hat{\mathbf{d}}_{t_i}^{-} + K_{t_i} (\mathbf{y}_{t_i} - \hat{\mathbf{d}}_{t_i}^{-}) $$
        [S1].
6.  **Warping:**
    *   Warp all points in real space to the time-independent canonical space using the estimated deformation $\hat{\mathbf{d}}_{t_i}$ [S1].
7.  **Radiance Field Query:**
    *   Query the radiance field (density and color) in the canonical space using the warped points [S1].
8.  **Volume Rendering:**
    *   Render the image using the standard volume rendering equation adapted for time [Parent](15546-dynamic-scene-and-temporal-modeling.md).

**Pseudocode:**

```python
def kfd_nerf_deformation_step(observer_mlp, kalman_gain_net, x, t_i, t_prev, t_prev_prev, 
                              dx_prev, dx_prev_prev, eps_prev, t_prev_val):
    """
    Computes the deformation for point x at time t_i using Kalman Filter logic.
    
    Args:
        observer_mlp: Two-layer MLP taking (x, t) -> (y, eps)
        kalman_gain_net: Linear layer taking (eps_curr, eps_prev, t_curr, t_prev) -> K
        x: 3D point coordinates
        t_i: Current timestamp
        t_prev: Previous timestamp
        t_prev_prev: Timestamp before previous
        dx_prev: Deformation estimate at t_prev
        dx_prev_prev: Deformation estimate at t_prev_prev
        eps_prev: Noise terms from previous frame observer
        t_prev_val: Timestamp value for previous frame (used in gain net if needed)
        
    Returns:
        dx_hat: Final deformation estimate
    """
    # 1. Prediction Branch
    # Calculate velocity based on local linear motion
    dt_i = t_i - t_prev
    v_t_i = (dx_prev - dx_prev_prev) / dt_i
    
    # Predicted deformation state
    dx_pred = dx_prev + dt_i * v_t_i
    # Equivalent to: dx_pred = 2 * dx_prev - dx_prev_prev
    
    # 2. Observation Branch
    # Query observer MLP for current frame
    y_t_i, eps_t_i = observer_mlp(x, t_i)
    
    # 3. Kalman Gain Calculation
    # Note: The source specifies inputs to the linear layer f are eps_t_i, eps_prev, t_i, t_prev
    # We assume t_prev_val is passed as the timestamp for the previous frame
    K_t_i = kalman_gain_net(eps_t_i, eps_prev, t_i, t_prev_val)
    
    # 4. Update Step
    # Final deformation estimation
    dx_hat = dx_pred + K_t_i * (y_t_i - dx_pred)
    
    return dx_hat, eps_t_i

def train_kfd_nerf(images, poses, timestamps, observer_mlp, radiance_field, 
                   kalman_gain_net, canonical_space_triplanes, optimizer):
    """
    Training loop for KFD-NeRF.
    """
    # Initialize deformation estimates for first two frames
    # In practice, these are learned parameters or outputs of the observer
    dx_prev_prev = None
    dx_prev = None
    eps_prev = None
    t_prev_val = None
    
    # Training strategy: Gradually release training images in chronological order
    sorted_indices = sort_timestamps(timestamps)
    
    for step in range(num_steps):
        # Select batch of rays/images based on chronological release strategy
        batch = get_chronological_batch(images, poses, timestamps, step)
        
        total_loss = 0.0
        dx_prev_prev_store = []
        dx_prev_store = []
        eps_prev_store = []
        
        for ray in batch:
            x_real = ray.origin + ray.direction * t # Sample point in real space
            t_i = ray.timestamp
            
            # Determine previous states
            # If first frame, handle initialization appropriately [G]
            if dx_prev is None:
                # Initialize with observer output or zero [G]
                y_init, eps_init = observer_mlp(x_real, t_i)
                dx_prev = y_init
                dx_prev_prev = y_init # Dummy for first step
                eps_prev = eps_init
                t_prev_val = t_i
                continue
                
            # Compute deformation
            dx_hat, eps_curr = kfd_nerf_deformation_step(
                observer_mlp, kalman_gain_net, 
                x_real, t_i, t_prev, t_prev_prev,
                dx_prev, dx_prev_prev, eps_prev, t_prev_val
            )
            
            # Warp to canonical space
            x_canonical = x_real - dx_hat
            
            # Query radiance field in canonical space
            density, color = radiance_field.query(x_canonical)
            
            # Render pixel value
            rendered_color = volume_render(density, color, ray)
            
            # Calculate losses
            # 1. Image Loss (e.g., MSE)
            loss_image = mse(rendered_color, ray.gt_color)
            
            # 2. Kalman Loss: Minimize error between observation and estimated deformation
            # L_kf = 1/N * sum || y_ti - dx_hat ||^2
            loss_kf = mse(dx_hat, dx_prev) # Note: Source defines L_kf as ||y_ti - dx_hat||^2. 
                                            # In the update step, dx_hat is a combination. 
                                            # The source Eq 13 uses y_ti - dx_hat. 
                                            # Here dx_hat is the final estimate. 
                                            # We use the observer's y_ti as the target for the loss term.
            loss_kf = mse(dx_hat, observer_mlp(x_real, t_i)[0])
            
            # 3. Canonical Observation Loss (Soft regularization for t=0)
            # L_co = 1/N * sum 1(t) * dx
            # Only applies if t_i is the canonical frame (t=0)
            loss_co = 0.0
            if is_canonical_frame(t_i):
                loss_co = mean(dx_hat)
                
            # 4. Total Variation Loss on Tri-Planes
            # L_tv applied to canonical space points
            loss_tv = compute_total_variation_loss(canonical_space_triplanes, x_canonical)
            
            # 5. Proposal Loss (from Mip-NeRF 360 distillation) [S1]
            loss_prop = compute_proposal_loss(radiance_field, ray)
            
            # Total Loss
            lambda_tv = 1e-4
            loss = loss_image + loss_kf + loss_co + loss_prop + lambda_tv * loss_tv
            
            total_loss += loss
            
            # Store states for next frame prediction
            dx_prev_prev_store.append(dx_prev)
            dx_prev_store.append(dx_hat)
            eps_prev_store.append(eps_curr)
            
        # Backpropagate and update
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()
        
        # Update previous states for next iteration
        # In a real implementation, these would be stored in a buffer or memory bank
        # for the next timestamp's prediction
        dx_prev_prev = dx_prev
        dx_prev = dx_hat # Or the last computed dx_hat
        eps_prev = eps_curr
        t_prev_val = t_i
```

**Parameters:**
*   **Total Variation Weight ($\lambda_{tv}$):** $1 \times 10^{-4}$ [S1].
*   **Observer MLP Depth:** 2 layers [S1].
*   **Spatial Representation:** Tri-plane (three mutually orthogonal 2D planes) [S1].

**Edge Cases and Pitfalls:**
*   **Initial Frames:** For the first two frames, velocity cannot be calculated. The method relies on the observer branch primarily in early training stages, with predictions influencing convergence for frames with substantial motion [S1]. Implementation requires initialization of $\Delta \mathbf{x}_{t_{-1}}$ and $\Delta \mathbf{x}_{t_{-2}}$ [G].
*   **Coordinate Shift Errors:** Tri-plane representation introduces errors due to finite resolution. Concatenating raw coordinates with encoded features mitigates this [S1].
*   **Training Order:** Images must be released in chronological order to ensure previous frames offer ample priors for current frame learning [S1].

## Operating characteristics
*   **Time Complexity:** Training time is comparable to other dynamic NeRF methods. On synthetic data, it takes approximately 30 minutes (KFD-NeRF-S) to 3 hours (KFD-NeRF-L) [S1].
*   **Memory Complexity:** Uses tri-plane representation, which significantly reduces memory consumption compared to MLP-based spatial representations (e.g., D-NeRF) [S1]. Parameter size is 175 MB for the large variant [S1].
*   **Performance:**
    *   **Synthetic Data:** PSNR 35.73 dB, SSIM 0.984, LPIPS 0.045, Average 0.0131 [S1].
    *   **Real Data:** PSNR 28.75 dB, SSIM 0.891, LPIPS 0.115, Average 0.0389 [S1].
*   **Strengths:**
    *   Accurate deformation estimation by combining observations and predictions [S1].
    *   Faster convergence due to tri-plane representation and shallow observer MLP [S1].
    *   Smooth deformation fields due to inductive bias of MLPs and Kalman filtering [S1].
*   **Limitations:**
    *   Relies on local linear motion assumption, which may not capture complex non-linear motions perfectly [S1].
    *   Performance depends on the quality of the tri-plane representation and the observer MLP [S1].
*   **When to Use:** Suitable for dynamic scene reconstruction where motion is relatively smooth and can be approximated locally linearly, and where efficient training and memory usage are priorities.
*   **When Not to Use:** For scenes with highly non-linear, abrupt, or chaotic motion where local linear approximation fails, or when extremely high-frequency detail is required in the deformation field itself (though tri-planes help with spatial detail, the deformation model is smooth) [S1].

## Background
KFD-NeRF was introduced by Li, Niu, Zhong, Nobuhara, Nishino, and Zheng in 2024 [S1]. It builds upon the concept of modeling 4D radiance fields as dynamic systems, drawing inspiration from control theory and Kalman filtering [S1]. Previous methods like D-NeRF used MLP-based deformation fields, while others like DyNeRF used time-conditioned feature interpolation. KFD-NeRF addresses the limitations of these by using a Kalman filter to guide the deformation field, combining a shallow MLP observer with a physics-based predictor [S1]. It also adopts the tri-plane representation from TiNeuVox to improve efficiency and convergence [S1].
