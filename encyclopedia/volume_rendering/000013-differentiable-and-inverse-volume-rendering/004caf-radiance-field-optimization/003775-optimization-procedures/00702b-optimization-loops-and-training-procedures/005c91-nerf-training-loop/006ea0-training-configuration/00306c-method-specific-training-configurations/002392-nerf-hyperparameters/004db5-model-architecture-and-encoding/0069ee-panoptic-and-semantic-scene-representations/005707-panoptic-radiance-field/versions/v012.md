# Panoptic Radiance Field

Also called: Panoptic Lifting

## Overview
Panoptic Lifting learns a panoptic 3D volumetric representation from posed RGB images and machine-generated 2D panoptic segmentation masks, lifting noisy 2D labels into a consistent 3D representation comprising color, density, semantics, and instances [S1]. Unlike [Panoptic NeRF](11916-panoptic-nerf.md) and [DM-NeRF](11916-dm-nerf.md) which require manual ground truth or coarse meshes, this method requires only machine-generated 2D masks inferred from a pre-trained network [S1]. It sets itself apart by explicitly modeling class-agnostic surrogate identifiers and using linear assignment to resolve instance inconsistencies across views, enabling robust handling of noisy in-the-wild data [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** Posed RGB images $\{I\}$ and corresponding machine-generated 2D panoptic segmentation masks. Each training ray $r$ has an associated RGB color $\hat{c}_r \in \mathbb{R}^3$, semantic class $\hat{k}_r \in K$, and 2D instance ID $\hat{h}_r \in H_I$ (defined only for thing classes $\hat{k}_r \in K_T$) [S1].
*   **Outputs:** A panoptic radiance field $\Phi(\mathbf{x}, \mathbf{d})$ that renders RGB color $c$, density $\sigma$, semantic class distribution $\kappa$, and instance distribution $\pi$ for any ray [S1]. From this, novel view images and 3D-consistent panoptic masks are generated [S1].

**Data Structures**
The field $\Phi(\mathbf{x}, \mathbf{d})$ assigns to each 3D point $\mathbf{x} \in \mathbb{R}^3$ and viewing direction $\mathbf{d} \in S^2$:
1.  **Density:** $\sigma \in \mathbb{R}_{\ge 0}$ [S1].
2.  **Semantic Distribution:** $\kappa$ over the set of semantic classes $K$ [S1].
3.  **Instance Distribution:** $\pi$ over a fixed set of surrogate identifiers $J$ [S1].
4.  **Color:** $c \in \mathbb{R}^3$ [S1].

The architecture leverages **TensoRF** [S1] for color and density. Two small Multi-Layer Perceptrons (MLPs) are used for the semantic field ($\kappa$) and the instance field ($\pi$) [S1]. The set of all possible 3D instances is $H_{3D} := K_T \times J$ [S1].

**Rendering Equation**
Given density $\sigma$, any vector field $f$ along ray $r$ is rendered as [S1]:
$$ R[f | r, \sigma] := \int_0^\infty \alpha_t(r) \sigma(r_t) f(r_t, d_{r_t}) dt $$
where $\alpha_t(r) := \exp \left(-\int_0^t \sigma(r_s) ds\right)$ is the transmittance probability at $t$ [S1].

**Training Procedure**
1.  **Preprocessing:** Use a pre-trained 2D panoptic segmentation model (e.g., Mask2Former with Swin-L backbone) to generate initial labels [S1]. Apply test-time augmentations (horizontal flip, scale, brightness, contrast) to input images and fuse resulting segmentations via segment clustering to obtain a refined semantic class distribution $\hat{\kappa}_r$ and a confidence estimate $w_r$ for each pixel/ray $r$ [S1].
2.  **Linear Assignment:** For instance supervision, solve a linear assignment problem to map noisy 2D instance IDs $\hat{h}_r$ to 3D surrogate identifiers $j \in J$. The cost is based on the model’s current predictions and the machine-generated masks, ensuring consistent lifting of 2D instances to 3D [S1]. Let $\Pi^*_R$ be the injective mapping assigning each ray $r$ to its most compatible 3D surrogate identifier [S1].
3.  **Loss Computation:** Compute the total loss $L_{tot}(R)$ over a batch of rays $R = R_S \cup R_I$, where $R_S$ are rays randomly sampled across the scene and $R_I$ are rays sampled from a single image [S1]:
    $$ L_{tot}(R) := \lambda_{ins} L_{ins}(R_I) + \lambda_{con} L_{con}(R_I) + \lambda_{RGB} L_{RGB}(R_S) + \lambda_{sem} L_{sem}(R_S) $$
    *   **Semantic Loss ($L_{sem}$):** Cross-entropy between rendered distribution $\kappa_r$ and 2D label distribution $\hat{\kappa}_r$, weighted by confidence $w_r$ [S1]:
        $$ L_{sem}(R) := -\frac{1}{|R|} \sum_{r \in R} w_r \sum_{k \in K} \hat{\kappa}_r(k) \log \kappa_r(k) $$
    *   **Instance Loss ($L_{ins}$):** Minimizes the log-loss of the co-occurrence of the mapped 2D instance and the rendered surrogate identifier distribution [S1].
    *   **Segment Consistency Loss ($L_{con}$):** Guides semantic supervision to avoid optima that fragment objects in the presence of label inconsistencies [S1].
    *   **Photometric Loss ($L_{RGB}$):** L2 loss on rendered color [S1].
4.  **Gradient Blocking:** Stop gradients from the semantic and instance branches back to the density field to prevent noisy labels from corrupting geometry (cloudy geometry) [S1].
5.  **Bounded Segmentation Fields:** Render bounded probability distributions for semantics and instances rather than unbounded logits to prevent significant signals in low-density areas [S1].
6.  **Optimization:** Update parameters using Adam [S1].

**Pseudocode**
```python
# Panoptic Lifting Training Step
def train_step(rays, images, poses, precomputed_2d_labels):
    """
    rays: List of Ray objects, each with origin p0, direction dr, 
          and associated 2D labels (rgb_color, semantic_dist, confidence, instance_id).
    images: Tensor of RGB images.
    poses: Camera poses.
    precomputed_2d_labels: Dict mapping ray index to (semantic_dist, confidence, instance_id).
    """
    # 1. Forward Pass through Panoptic Radiance Field
    # Phi(x, d) returns sigma, kappa, pi, color
    sigma, kappa, pi, color = panoptic_radiance_field(rays)
    
    # 2. Volumetric Rendering
    # Render RGB, Semantic Distribution, and Instance Distribution
    rendered_rgb = volumetric_render_color(rays, sigma, color)
    rendered_kappa = volumetric_render_field(rays, sigma, kappa)
    rendered_pi = volumetric_render_field(rays, sigma, pi)
    
    # 3. Compute Losses
    loss_rgb = 0
    loss_sem = 0
    loss_ins = 0
    loss_con = 0
    
    for i, ray in enumerate(rays):
        # Get 2D ground truth and confidence from precomputed labels
        gt_kappa, w_r, gt_instance_id = precomputed_2d_labels[i]
        
        # Photometric Loss (on scene-sampled rays)
        if ray.is_scene_sampled:
            loss_rgb += mse(rendered_rgb[i], images[ray.image_idx][ray.pixel])
            
        # Semantic Loss (on single-image sampled rays)
        if ray.is_single_image_sampled:
            # Bounded probability distribution is used for kappa
            # Cross-entropy weighted by confidence
            loss_sem += -w_r * sum(gt_kappa[k] * log(rendered_kappa[i][k]) for k in K)
            
        # Instance Loss (on single-image sampled rays)
        if ray.is_single_image_sampled and gt_instance_id is not None:
            # Map 2D instance to 3D surrogate ID via linear assignment
            # This mapping depends on current model predictions
            surrogate_id = linear_assignment(gt_instance_id, rendered_pi[i])
            
            # Instance loss minimizes log-loss of co-occurrence
            # Assuming NCE-like loss or cross-entropy between mapped ID and rendered pi
            loss_ins += instance_loss(rendered_pi[i], surrogate_id)
            
            # Segment consistency loss (simplified)
            # Encourages consistency of semantic and instance predictions
            loss_con += segment_consistency_loss(rendered_kappa[i], rendered_pi[i])

    # 4. Aggregate Losses
    # Lambda values: lambda_con=1.35, lambda_ins=1, lambda_sem=1, lambda_RGB=1
    total_loss = (1.0 * loss_rgb + 
                  1.0 * loss_sem + 
                  1.0 * loss_ins + 
                  1.35 * loss_con)
    
    # 5. Backpropagation with Gradient Blocking
    # Stop gradients from semantic/instance branches to density
    # This is implemented by detaching sigma from the computation graph
    # of the semantic and instance losses, or by zeroing gradients
    # for density parameters from those specific loss terms.
    
    optimizer.zero_grad()
    total_loss.backward()
    optimizer.step()
    
    return total_loss

def volumetric_render_field(rays, sigma, field):
    """
    Renders a field (kappa or pi) along rays using the density sigma.
    Returns the weighted average of the field values along the ray.
    """
    # Discretize ray into samples
    samples = sample_along_ray(rays)
    # Query field and sigma at samples
    field_vals = field(samples)
    sigma_vals = sigma(samples)
    
    # Compute transmittance and weights
    # alpha_t(r) = exp(-int_0^t sigma(r_s) ds)
    # weight_t = alpha_t * sigma_t
    weights = compute_transmittance_weights(sigma_vals)
    
    # Rendered field is sum of weight * field_val
    rendered = sum(weights * field_vals)
    return rendered
```

**Parameters**
*   **Optimizer:** Adam [S1].
*   **Learning Rates:** $5 \times 10^{-4}$ for MLPs, $1 \times 10^{-2}$ for TensoRF lines and planes [S1].
*   **Loss Weights:** $\lambda_{con} = 1.35$, $\lambda_{ins} = 1$, $\lambda_{sem} = 1$, $\lambda_{RGB} = 1$ [S1].
*   **Training Duration:** 450k iterations (~10 hours) on 1 NVIDIA A6000 [S1].
*   **Classes:** $K$ is partitioned into thing classes $K_T$ and stuff classes $K_S$ [S1].
*   **Surrogate Identifiers:** $J$ is a fixed number held by the instance field MLP [S1].

**Edge Cases and Pitfalls**
*   **Logits vs. Probabilities:** Rendering class logits instead of probabilities can introduce semantic inconsistencies across viewpoints because unbounded logits can generate significant signals in low-density areas, violating geometric constraints. This is resolved by rendering bounded probability distributions [S1].
*   **Geometry Corruption:** Supervision from noisy 2D labels can influence geometry, causing cloudy geometry to satisfy conflicting labels. This is avoided by stopping gradients from segmentation branches back to densities [S1].
*   **Label Noise:** 2D machine-generated labels are noisy and inconsistent across views. Test-time augmentations and confidence weighting are required to handle this [S1].
*   **Offline Processing:** The method runs offline due to lengthy pre-processing for pose estimation, 2D segmentation inference, and neural field optimization [S1].

## Operating characteristics
*   **Time and Memory Complexity:** Training takes ~10 hours on an NVIDIA A6000 for 450k iterations [S1]. Memory usage depends on the TensoRF grid size and MLP dimensions, which are not explicitly detailed in the sources [S1].
*   **Measured Performance:** Improves scene-level Panoptic Quality (PQ_scene) by 8.4% on Hypersim, 13.8% on Replica, and 10.6% on ScanNet over state-of-the-art methods [S1]. Maintains comparable PSNR for novel view synthesis [S1].
*   **Strengths:** Robust to inherent noise in machine-generated labels; enables in-the-wild scene processing without manual ground truth; supports scene editing (deletion, duplication, manipulation) [S1].
*   **Limitations:** Limited to classes supported by the pre-trained 2D segmentation model; offline processing; requires posed images [S1].
*   **When to use:** When 3D panoptic segmentation is needed from in-the-wild images without manual 3D annotations, and novel view synthesis is also required.
*   **When not to use:** When real-time processing is required, or when the scene contains classes outside the pre-trained 2D model's vocabulary.

## Background
Panoptic Lifting was introduced in the paper "Panoptic Lifting for 3D Scene Understanding with Neural Fields" (CVPR 2023) [S1]. It addresses the limitation of previous methods like Panoptic NeRF and DM-NeRF, which required manual ground truth (coarse meshes or per-image 2D panoptic segmentations) [S1]. The method builds on the TensoRF architecture for efficient radiance field representation [S1]. It is used on Hypersim, Replica, and ScanNet datasets [S1].
