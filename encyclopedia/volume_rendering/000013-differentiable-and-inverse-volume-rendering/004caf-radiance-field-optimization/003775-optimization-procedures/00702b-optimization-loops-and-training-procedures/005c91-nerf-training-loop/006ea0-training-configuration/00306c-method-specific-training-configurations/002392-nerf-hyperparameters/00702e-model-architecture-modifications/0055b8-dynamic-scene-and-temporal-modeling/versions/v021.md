# Dynamic Scene and Temporal Modeling

Also called: Dynamic NeRF, 4D NeRF, Temporal NeRF

## Overview
Dynamic Scene and Temporal Modeling extends the static Neural Radiance Field (NeRF) assumption to handle time-varying geometry and appearance, solving the problem of reconstructing and rendering scenes that change over time [S1]. Unlike static NeRF variants which assume a frozen scene, this family introduces temporal dimensions into the input space, deformation fields, or particle systems to model motion and appearance changes [S1]. It sets itself apart from sibling methods like [DoF-NeRF](9432-dof-nerf.md) (which focuses on depth-of-field) or [Lighting and Appearance Models](14522-lighting-and-appearance-models.md) (which focus on static lighting) by explicitly encoding time as a variable or modeling temporal dynamics through deformation and warping mechanisms.

## Shared principles
The core principle shared by all methods in this family is the augmentation of the spatial representation $(x, y, z)$ with a temporal component $t$, or the use of a canonical space that is warped to time $t$ to handle non-rigid motion [S1].

1.  **Temporal Input:** The input to the radiance field network is extended from $(\mathbf{x}, \mathbf{d})$ to $(\mathbf{x}, \mathbf{d}, t)$ or a canonical coordinate $\mathbf{x}'$ derived from $\mathbf{x}$ and $t$ [S1].
2.  **Canonical Space:** Many methods (e.g., [Forward Warping for Novel View Synthesis](15541-forward-warping-for-novel-view-synthesis.md), [KFD-NeRF](15551-kfd-nerf.md)) map dynamic points to a time-independent canonical space using a deformation field $\mathbf{d}(\mathbf{x}, t)$, where $\mathbf{x}_t = \mathbf{x} + \mathbf{d}(\mathbf{x}, t)$ [S1].
3.  **Temporal Interpolation/Extrapolation:** Methods must handle arbitrary time queries. This is achieved via positional encoding of time [S1], dense time slots [S1], or explicit motion prediction (Kalman filter) [S1].
4.  **Rendering:** The volume rendering equation remains standard, but density $\sigma$ and color $\mathbf{c}$ are functions of time:
    $$ C(\mathbf{r}, t) = \int_{s_n}^{s_f} T(s, t) \sigma(\mathbf{r}(s), t) c(\mathbf{r}(s), \mathbf{d}, t) ds $$
    where $T(s, t) = \exp \left( -\int_{s_n}^{s} \sigma(\mathbf{r}(s'), t) ds' \right)$ [S1].

## Subtopics

### [Gear-NeRF](13848-gear-nerf.md)
A framework for free-viewpoint rendering and tracking of dynamic scenes that leverages semantic information from image segmentation models to stratify the scene into motion-based 'gears', allowing for region-specific spatio-temporal sampling resolution. It solves the inefficiency of uniform 4D volume representations by assigning higher sampling resolution to regions with larger motion scales, thereby improving photo-realistic dynamic novel view synthesis while enabling free-viewpoint object tracking. Unlike [NeRF with Time Parameter](14705-nerf-with-time-parameter.md) which typically uses a unified representation, Gear-NeRF uses a series of 4D feature volumes, one per gear level.

### [NeRF with Time Parameter](14705-nerf-with-time-parameter.md)
This method adapts the static Neural Radiance Field (NeRF) architecture for dynamic scenes by introducing a temporal dimension to the input space. It solves the problem of reconstructing time-varying geometry and appearance, which standard NeRF cannot handle due to its static assumption. Unlike sibling methods that model explicit motion fields or use complex graph structures, this approach simply augments the input vector with time, serving as a baseline for temporal NeRFs. It sets itself apart by its minimal architectural change, though it is noted to lack detail and suffer from blurry predictions compared to more advanced dynamic scene methods.

### [Forward Warping for Novel View Synthesis](15541-forward-warping-for-novel-view-synthesis.md)
Forward Warping for Novel View Synthesis is a method for rendering dynamic scenes by modeling a static "canonical" radiance field and differentially warping this field to target time steps. It solves the many-to-one and one-to-many mapping ambiguities inherent in dynamic scene reconstruction by using average splatting for forward warping and an inpaint network to fill occluded regions. Unlike backward-flow methods such as NDVG, this approach achieves superior performance, particularly for canonical frames, by explicitly learning a deformation flow from a static reference.

### [Dynamic Appearance Particle Neural Radiance Field](15550-dynamic-appearance-particle-neural-radiance-field.md)
Dynamic Appearance Particle Neural Radiance Field is a method for novel view synthesis in dynamic scenes using monocular video input. It solves the problem of modeling temporal dynamics without requiring multi-view data or prior geometric knowledge of moving objects. It differs from ParticleNeRF by applying particle-based representation only to dynamic elements while keeping a static grid for the background, and by supporting single-camera input rather than requiring multiple views per frame.

### [KFD-NeRF](15551-kfd-nerf.md)
KFD-NeRF is a dynamic neural radiance field method that models the 4D radiance field as a dynamic system with temporally varying states, estimated using a Kalman filter to combine observations from input data and predictions based on local linear motion equations. It differs from sibling methods like [Gear-NeRF](13848-gear-nerf.md) and [NeRF with Time Parameter](14705-nerf-with-time-parameter.md) by explicitly treating motion estimation as a state estimation problem, using a Kalman gain to weight a shallow MLP-based observer against a physics-based predictor, rather than relying solely on time-conditioned feature interpolation or complex deformation networks.

### [SLS4D](16576-sls4d.md)
SLS4D is a method for 4D novel view synthesis that represents dynamic scenes using a sparse, compact, and informative latent feature space, significantly reducing the number of network parameters compared to dense voxel-based or hierarchical grid approaches. It distinguishes itself from siblings like [Gear-NeRF](13848-gear-nerf.md) and [KFD-NeRF](15551-kfd-nerf.md) by abandoning direct coordinate-to-feature mapping in favor of a sparse set of globally learnable latent codes interpolated via attention, while explicitly decoupling temporal dynamics through dense time slots and deformation fields.

#### ER-NeRF
- **Definition:** A Conditional NeRF framework for effective, high-accuracy dynamic portrait creation, producing dynamic portrait videos synchronized with audio [S1].
- **Steps:** Utilizes spatial regions’ distinct contributions to steer dynamic head modeling; develops a concise and articulate Tri-Plane Hash Representation; introduces rapid and straightforward Adaptive Pose Encoding to enhance the separation of the head and torso [S1].
- **Pitfalls:** Additional fine-tuning might be necessary to sustain superior rendering outcomes for poses that exceed the scope of the training dataset [S1].
- **Performance:** Attains instantaneous rendering and rapid convergence using a compact model size [S1].

#### NeRF-MS
- **Definition:** A method that diminishes vagueness in visual alterations by implementing a ternary loss to standardize the spread of visual codes across each image [S1].
- **Steps:** Suggests a temporary decomposition unit to more effectively distinguish still scenes from dynamic objects [S1].
- **Pitfalls:** Might encounter difficulties in managing significant sequence discrepancies, like severe alterations in the visual aspect of scenes caused by the activation of lights [S1].
- **Performance:** Trials using both real-life outdoor and artificial datasets reveal that NeRF-MS attains cutting-edge results in multi-sequence scenarios, markedly enhancing rendering efficiency through the reconstruction of 3D-consistent visuals and minimizing ghost effects [S1].

## Background
The concept of dynamic NeRFs emerged as an extension of the original static NeRF [G]. Early approaches focused on simple time-parameterization, while later works introduced deformation fields, particle systems, and semantic stratification to handle complex non-rigid motions [S1]. The field has seen significant development in handling monocular inputs, semantic guidance, and efficient sparse representations [S1].
