# NeRF-W Hyperparameter Configuration
Also called: NeRF-W Training Parameters

## Overview
NeRF-W (NeRF in the Wild) hyperparameter configuration defines the specific training settings for optimizing unconstrained photo collections, addressing the challenge of transient objects (moving people, vehicles) that violate the static scene assumption of standard NeRF [S1]. It distinguishes itself from static NeRF variants by employing a dual-MLP architecture (static and transient heads) and specific regularization to prevent transient components from dominating geometry [S1, S2]. Unlike Depth-Guided NeRF, it relies on photometric consistency and appearance embeddings rather than depth priors, and unlike CLIPNeRF, it does not use semantic segmentation for guidance but rather handles transients via explicit modeling or mask-based exclusion in variants [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of uncalibrated or SfM-calibrated images $I_i$ with known poses $P_i$. Optional: Segmentation masks for dynamic objects (in variant).
*   **Output:** A radiance field model defined by two MLPs (Static and Transient/Uncertainty) and embedding vectors, capable of rendering novel views.

**Data Structures:**
1.  **Base MLP (Static):** 8 layers, 512 hidden units each.
2.  **Static/Transient MLPs:** 4 layers, 128 hidden units each.
3.  **Positional Encoding:**
    *   Position $\mathbf{x}$: 15 frequencies.
    *   Viewing direction $\mathbf{d}$: 4 frequencies.
4.  **Embeddings:**
    *   Appearance embedding $\mathbf{a}_i$: Dimension $n(a) = 48$ per image.
    *   Transient object embedding $\mathbf{\tau}_i$: Dimension $n(\tau) = 16$ per image.
5.  **Sampling:**
    *   Training: 512 points per ray per model (coarse + fine) = 1024 total points per ray.
    *   Evaluation: 2048 points per ray.

**Parameters:**
*   Optimizer: Adam.
*   Batch size: 2048.
*   Initial learning rate: $0.001$.
*   Learning rate decay: Ten-fold reduction every 150,000 iterations.
*   Total iterations: 300,000.
*   L1 regularizer multiplier: $\lambda_u = 0.01$.
*   Minimum importance threshold: $\beta_{min} = 0.03$.

**Algorithm:**
The training minimizes a photometric loss between rendered pixels and ground-truth images. The model uses stratified sampling for coarse and fine stages.

1.  **Initialize** the Base MLP, Static MLP, and Transient/Uncertainty MLP with random weights. Initialize appearance embeddings $\mathbf{a}_i$ and transient embeddings $\mathbf{\tau}_i$ for each image $i$.
2.  **For** each iteration $t$ from 1 to 300,000:
    3.  **Sample** a batch of 2048 rays from the training images.
    4.  **For** each ray in the batch:
        5.  **Sample** 512 points along the ray for the coarse model using stratified sampling.
        6.  **Encode** position $\mathbf{x}$ and direction $\mathbf{d}$ using positional encodings (15 and 4 frequencies respectively).
        7.  **Compute** coarse density $\sigma_c$ and color $C_c$ using the Base MLP and Static MLP.
        8.  **Sample** 512 points along the ray for the fine model, potentially using importance sampling based on coarse density.
        9.  **Compute** fine density $\sigma_f$ and color $C_f$ using the Base MLP, Static MLP, and Transient/Uncertainty MLP.
        10. **Composite** the final color $C$ using volume rendering integration over the fine samples:
            $$ C = \sum_{i=1}^{N} T_i \alpha_i c_i $$
            where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$, $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$, and $c_i$ is the color contribution.
        11. **Calculate** the photometric loss $L_{color}$ between $C$ and the ground-truth pixel color.
        12. **Apply** L1 regularization on the transient components with multiplier $\lambda_u = 0.01$ to encourage sparsity in transient modeling [S1].
        13. **Update** model weights and embeddings using Adam optimizer with learning rate $\eta_t$, where $\eta_t = 0.001 \times 0.1^{\lfloor t/150000 \rfloor}$.
    14. **If** $t > 150,000$, reduce learning rate by factor of 10.
15. **End For**

**Edge Cases and Pitfalls:**
*   **Transient Dominance:** If the transient head is not regularized or constrained, it may converge faster than the geometry MLP, causing scene structures to be modeled as view-dependent transient effects rather than static geometry [S2].
*   **Evaluation Sampling:** Doubling the number of samples to 2048 during evaluation is critical for high-quality rendering [S1].

## Subtopics

### Transient Object Handling via Segmentation Masks
A variant method to handle dynamic objects in Internet photo collections by using segmentation masks to exclude rays belonging to dynamic objects during training [S2]. This approach avoids the issue where a transient NeRF head dominates rendered color, which occurs because the transient NeRF converges faster than the geometry MLP $d$, leading scene structures to be modeled as view-dependent transient effects [S2]. Instead of relying on the NeRF-W transient head, this method removes dynamic rays from the loss calculation [S2].

## Operating characteristics
*   **Time Complexity:** Training requires 300,000 iterations with a batch size of 2048. The use of two MLP stages (coarse and fine) doubles the sampling cost per ray compared to a single-stage model, but importance sampling mitigates this.
*   **Memory Complexity:** The model stores two MLPs (Base, Static, Transient) and per-image embeddings. The appearance embedding dimension is 48, and transient embedding is 16. For $N$ images, memory scales with $N \times (48 + 16)$.
*   **Performance:** Optimized for the Brandenburg Gate scene of the Phototourism dataset and reused for remaining scenes [S1].
*   **Strengths:** Handles unconstrained photo collections with transient objects effectively when combined with appropriate regularization or masking [S1, S2].
*   **Limitations:** Requires careful tuning of the transient head to prevent it from dominating geometry [S2]. Performance on textureless sky regions may suffer without additional background handling (e.g., semantic masks for free space) [S2].

## Background
NeRF-W was introduced by Mildenhall et al. in 2021 as an extension of NeRF to handle unconstrained photo collections [S1]. The hyperparameter configuration was determined via grid search on the Brandenburg Gate scene of the Phototourism dataset and applied to other scenes in the dataset [S1]. The work addresses the challenge of view synthesis in the wild, where static scene assumptions are violated by transient objects [S1]. Subsequent works like Neural 3D Reconstruction in the Wild have explored alternative handling of transients, such as using segmentation masks to avoid the dominance of the transient head [S2].
