# Dynamic Scene and Temporal Modeling

Also called: Dynamic NeRF, 4D Radiance Fields, Temporal NeRF

## Overview
Dynamic Scene and Temporal Modeling extends static Neural Radiance Fields (NeRF) to handle scenes where geometry and appearance change over time, solving the problem of rendering temporal variations that vanilla NeRF cannot represent, which typically results in ghosting or blurring [14705-nerf-with-time-parameter.md]. Unlike static methods, these approaches model the 4D radiance field $\mathbb{R}^3 \times \mathbb{R}$, enabling novel view synthesis at arbitrary times $t$ [15550-dynamic-appearance-particle-neural-radiance-field.md]. This family is distinguished from its siblings by the specific mechanism used to encode temporal dynamics: direct time-conditioning [14705-nerf-with-time-parameter.md], canonical space warping [15541-forward-warping-for-novel-view-synthesis.md], stratified multi-resolution sampling [13848-gear-nerf.md], particle-based decomposition [15550-dynamic-appearance-particle-neural-radiance-field.md], or Kalman-filtered state estimation [15551-kfd-nerf.md].

## Shared principles
All methods in this family share the fundamental volume rendering equation, adapted to include time $t$ as an explicit input or state variable [14705-nerf-with-time-parameter.md]. The rendered color $C(r, t)$ for a ray $r$ at time $t$ is computed via the volume rendering integral:

$$
C(r, t) = \int_{s_n}^{s_f} T(s, t)\sigma(\mathbf{r}(s), t)c(\mathbf{r}(s), \mathbf{d}, t)ds
$$

where the accumulated transmittance $T(s, t)$ is:

$$
T(s, t) = \exp\left(-\int_{s_n}^{s} \sigma(\mathbf{r}(s'), t)ds'\right)
$$

[15550-dynamic-appearance-particle-neural-radiance-field.md].

The core challenge is representing the 4D function $(\mathbf{x}, \mathbf{d}, t) \mapsto (\sigma, \mathbf{c})$. All methods modify the standard NeRF architecture [Parent](3065-nerf-hyperparameters.md) by expanding the input domain or representation structure to account for $t$. Common strategies include:
1.  **Direct Conditioning:** Concatenating a positional encoding of time $\gamma(t)$ with spatial coordinates $\gamma(\mathbf{x})$ as input to the MLP [14705-nerf-with-time-parameter.md].
2.  **Canonical Warping:** Mapping dynamic points $\mathbf{x}$ at time $t$ to a static canonical space $\mathbf{x}_{can}$ via a deformation field $\Delta \mathbf{x}$, then querying a static radiance field [15541-forward-warping-for-novel-view-synthesis.md][15551-kfd-nerf.md].
3.  **Hybrid Representations:** Combining grid-based static fields with particle-based or stratified dynamic fields [13848-gear-nerf.md][15550-dynamic-appearance-particle-neural-radiance-field.md].

## Subtopics

### [Gear-NeRF](13848-gear-nerf.md)
Stratifies the 4D radiance field into multiple "gear" levels based on local motion scales, using semantic embeddings to assign higher-resolution feature volumes to dynamic regions. Choose this when region-specific spatio-temporal resolution is needed for efficient dynamic novel view synthesis and object tracking.

### [NeRF with Time Parameter](14705-nerf-with-time-parameter.md)
Adapts the static NeRF architecture by explicitly incorporating time as an input dimension $(\mathbf{x}, \mathbf{d}, t)$. Choose this for simple dynamic scenes where direct time-conditioning suffices, though it may suffer from blurriness compared to warping methods.

### [Forward Warping for Novel View Synthesis](15541-forward-warping-for-novel-view-synthesis.md)
Models a static "canonical" radiance field and forward-warps it to target time steps using a learned deformation flow and average splatting. Choose this for handling complex dynamic topologies and occlusions, as it explicitly constructs the target view by displacing canonical voxels.

### [Dynamic Appearance Particle Neural Radiance Field](15550-dynamic-appearance-particle-neural-radiance-field.md)
Decomposes the radiance field into static grid-based components and dynamic particle-based components. Choose this for monocular video data where multi-view consistency is not available, as it applies appearance particles only to dynamic elements.

### [KFD-NeRF](15551-kfd-nerf.md)
Models the 4D radiance field as a dynamic system with temporally varying states, estimated using a Kalman filter to combine observations from input data and predictions based on local linear motion equations. Choose this when explicit state estimation and physics-based motion prediction are required to handle rapid or complex motion.

## Background
The standard NeRF architecture [Parent](3065-nerf-hyperparameters.md) serves as the baseline for most modifications. It consists of two Multi-Layer Perceptrons (MLPs): a coarse network and a fine network. The coarse network takes positional encoded position $\gamma(\mathbf{x})$ and outputs a latent feature vector $\mathbf{h}$ and volume density $\sigma$. The fine network takes $\mathbf{h}$, positional encoded position $\gamma(\mathbf{x})$, and positional encoded view direction $\gamma(\mathbf{d})$ to output color $\mathbf{c}$ [14428-sparse-view-and-few-shot-optimization.md].

$$
\gamma(\mathbf{x}, d_1, d_2) = [\mathbf{x}, \sin(2^{d_1}\pi\mathbf{x}), \cos(2^{d_1}\pi\mathbf{x}), \dots, \sin(2^{d_2-1}\pi\mathbf{x}), \cos(2^{d_2-1}\pi\mathbf{x})]
$$

Modifications generally fall into three categories [14428-sparse-view-and-few-shot-optimization.md]:
1.  **Input Expansion:** Adding new conditioning vectors (e.g., appearance embeddings $\mathbf{z}_i$, fluid volume $v$, or previous stage RGB) to the input concatenation [14428-sparse-view-and-few-shot-optimization.md].
2.  **Output Expansion:** Adding auxiliary heads to predict values other than $\sigma$ and $\mathbf{c}$, such as semantic labels $y_{aux}$, object codes $o$, or area encoding probabilities $p$. These are rendered using the same transmittance weights $T_i$ and opacity $\alpha_i$ as color:
    $$
    \hat{Y}(r) = \sum_{i=1}^{N} T_i \alpha_i y_{aux}(x_i)
    $$
3.  **Representation Substitution:** Replacing the continuous MLP function with discrete structures (voxel grids, hash tables) or different implicit surfaces (SDFs).

Dynamic scene modeling emerged as a necessary extension to handle real-world video data, moving beyond the static assumption of the original NeRF [14705-nerf-with-time-parameter.md]. Early approaches focused on direct time conditioning, while later methods introduced canonical space warping and particle-based representations to better handle occlusions and complex motion [15541-forward-warping-for-novel-view-synthesis.md][15550-dynamic-appearance-particle-neural-radiance-field.md].
