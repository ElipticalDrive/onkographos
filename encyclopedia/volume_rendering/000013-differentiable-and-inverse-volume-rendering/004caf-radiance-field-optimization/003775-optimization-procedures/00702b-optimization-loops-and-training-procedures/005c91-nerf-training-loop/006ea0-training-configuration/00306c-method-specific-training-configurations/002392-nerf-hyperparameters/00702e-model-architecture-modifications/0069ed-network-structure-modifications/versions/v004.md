# Network Structure Modifications


## Overview
Network structure modifications alter the baseline Multi-Layer Perceptron (MLP) architecture of Neural Radiance Fields to address specific challenges such as few-shot overfitting, mobile inference constraints, or dynamic scene representation [S1, unofficial]. Unlike the standard two-MLP design, these variants modify layer connectivity, dimensionality, or activation strategies to improve generalization or efficiency [S1, unofficial].

## Shared principles
The baseline NeRF architecture [S1, unofficial] employs two MLPs:
1.  **Position MLP ($\Phi_{pos}$)**: Takes the spatial position $\mathbf{x}$ and its positional encoding $\gamma(\mathbf{x})$ to produce a feature vector $\mathbf{h}$ [G].
2.  **Shading MLP ($\Phi_{shade}$)**: Takes the feature vector $\mathbf{h}$ and the viewing direction $\mathbf{d}$ (encoded as $\gamma(\mathbf{d})$) to predict the volume density $\sigma$ and the RGB color $\mathbf{c}$ [G].

## Subtopics

### [Network Architectures](15530-network-architectures.md)
Modifies the standard MLP structure to handle dynamic scenes, noise, or efficiency constraints. Includes MobileNeRF variants (A, F, H) which adjust hidden layer sizes (e.g., 384 for A/F, 16 for H) to balance training time and inference speed.

### [Multi-input MLP (mi-MLP)](16599-multi-input-mlp-mi-mlp.md)
Incorporates raw input embeddings into every layer to prevent overfitting in few-shot view synthesis. Creates explicit connections between inputs and hidden layers, allowing high-frequency detail synthesis with fewer effective parameters.

### NeRF Model Architecture
The default neural network architecture for NeRF, consisting of dense layers with ReLU activations [S1, unofficial].
*   **Definition**: Dense layers with ReLU activations, potentially using view directions as input [S1, unofficial].
*   **Parameters**:
    *   `D`: Depth of the network (number of hidden layers). Default is 8 [S1, unofficial].
    *   `input_ch_views`: Number of input channels for view directions. Default is 3 [S1, unofficial].
    *   `output_ch`: Number of output channels. Default is 4 (RGB + density) [S1, unofficial].
    *   `use_viewdirs`: Boolean flag to determine if view directions are used as input [S1, unofficial].

## Background
The standard NeRF architecture was introduced in the original NeRF paper [S1, unofficial]. Subsequent modifications, such as MobileNeRF and mi-MLP, were developed to address specific limitations regarding inference speed and few-shot generalization [S1, unofficial].
