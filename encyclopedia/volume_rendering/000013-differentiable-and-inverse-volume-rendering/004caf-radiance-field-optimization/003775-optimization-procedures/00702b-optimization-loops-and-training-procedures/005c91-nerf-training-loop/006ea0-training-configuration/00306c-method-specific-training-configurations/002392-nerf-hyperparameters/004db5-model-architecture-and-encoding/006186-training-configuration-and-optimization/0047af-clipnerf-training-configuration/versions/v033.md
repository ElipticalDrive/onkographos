# CLIPNeRF Training Configuration

Also called: Absolute Directional CLIP Loss, CLIPNeRF Hyperparameters, CLIPNeRF Implementation, Directional CLIP Loss, Relative Directional CLIP Loss, StyleGAN-NADA CLIP Loss

## Overview
CLIPNeRF training configuration defines the optimization procedure for text-guided stylization of Neural Radiance Fields (NeRFs) by integrating a directional CLIP loss into the standard volume rendering loop [S2]. It differs from standard NeRF optimization by freezing density-related parameters and minimizing the negative cosine similarity between rendered image embeddings and target text prompt embeddings, thereby enforcing a specific stylization trajectory in the CLIP embedding space [S1, S2].

## How it works
**Inputs and Outputs**
*   **Inputs:** A pre-trained NeRF model (MLP predicting density $\sigma$ and color $c$), a source image $I_{src}$, a target text prompt $t_{tgt}$, and optionally a source text prompt $t_{src}$ for relative loss.
*   **Outputs:** A stylized NeRF model with updated color/feature parameters.

**Data Structures**
*   **NeRF MLP:** Standard multi-layer perceptron. Parameters are split into density-related and color/feature-related sub-parameters [S1].
*   **CLIP Encoder:** ViT-B/32 architecture, used to embed images and text into a shared vector space [S1].
*   **Patch Data:** A $128 \times 128$ pixel patch of the rendered view, sampled with a ray stride of 5, resulting in a $640 \times 640$ effective receptive field [S1].

**Numbered Steps**
1.  **Initialization:** Load the pre-trained NeRF and freeze all sub-parameters related to density $\sigma$ [S1]. Initialize the optimizer (Adam) with a learning rate $\eta = 0.0001$ [S1].
2.  **Ray Sampling:** For each training step, sample a batch of rays. To manage memory, render a patch of size $128 \times 128$. Rays within this patch are sampled with a stride interval of 5 [S1].
3.  **Volume Rendering:** Render the patch using importance sampling. The number of importance sampling points is reduced to 16 for memory efficiency. The fine MLP uses a total of 80 samples (64 coarse + 16 fine) [S1].
4.  **Embedding:** Pass the rendered patch $I_{tgt}$ through the CLIP image encoder $\mathcal{E}_i$ to obtain the image embedding $\mathcal{E}_i(I_{tgt})$. Encode the target text prompt $t_{tgt}$ using the CLIP text encoder $\mathcal{E}_t$ to obtain $\mathcal{E}_t(t_{tgt})$ [S2].
5.  **Loss Computation:** Compute the directional CLIP loss. Two variants are defined:
    *   **Absolute Directional CLIP Loss:** Measures the cosine similarity between the rendered image and the target text [S2]:
        $$ \mathcal{L}_{dir} = 1 - \langle \hat{\mathcal{E}}_i(I_{tgt}), \hat{\mathcal{E}}_t(t_{tgt}) \rangle $$
        where $\hat{\mathcal{E}}$ denotes normalized embeddings [S2].
    *   **Relative Directional CLIP Loss:** Transfers style from a source image $I_{src}$ guided by the trajectory between source text $t_{src}$ and target text $t_{tgt}$ [S2]:
        $$ \mathcal{L}_{dir} = 1 - \langle \hat{\mathcal{E}}_i(I_{tgt}) - \hat{\mathcal{E}}_i(I_{src}), \hat{\mathcal{E}}_t(t_{tgt}) - \hat{\mathcal{E}}_t(t_{src}) \rangle $$
        [S2].
6.  **Optimization:** Minimize the negative cosine similarity (equivalent to maximizing similarity) using the Adam optimizer [S1]. The optimization runs for 500 iterations [S1].
7.  **Update:** Backpropagate gradients to update only the color/feature parameters of the NeRF [S1].

**Parameters**
*   **Iterations:** 500 [S1].
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** 0.0001 [S1].
*   **Patch Size:** $128 \times 128$ [S1].
*   **Ray Stride:** 5 (Receptive field $640 \times 640$) [S1].
*   **Importance Sampling Points:** 16 [S1].
*   **Fine MLP Samples:** 80 total (64 coarse + 16 fine) [S1].
*   **Text Encoder:** CLIP ViT-B/32 [S1].

**Edge Cases and Pitfalls**
*   **Memory Constraints:** Naive differentiable rendering of high-resolution images is intractable due to memory constraints [S1]. The patch-based approach is required [S1].
*   **Mode Collapse:** The absolute directional CLIP loss can cause mode-collapse of the generator and hurt generation diversity [S2].
*   **Insufficient Magnitude:** The directional CLIP loss measures only directional similarity between normalized vectors, ignoring magnitude. This can result in weak or insufficient style transfer [S2].
*   **Non-uniform Stylization:** Global contrastive loss may lead to excess stylization in some regions and insufficiency in others (e.g., faces vs. eyes) because CLIP focuses on distinguishable features [S2].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Reduced via patch-based rendering ($128 \times 128$) and reduced importance sampling (16 points) to fit within memory constraints [S1].
*   **Strengths:** Enables text-driven stylization of NeRFs without requiring 3D ground truth [S2]. The relative loss improves diversity compared to absolute loss [S2].
*   **Limitations:** Struggles with stylization magnitude [S2]. Prone to mode collapse with absolute loss [S2]. Non-uniform stylization across the scene [S2].
*   **When to use:** When text-guided stylization of a NeRF is required and computational resources are limited [S1, S2].
*   **When not to use:** When uniform stylization magnitude is critical or when high-resolution full-image differentiable rendering is feasible and desired [S1, S2].

## Background
CLIPNeRF was introduced by Wang et al. in 2021 as a method for text-driven NeRF stylization [S2]. It builds upon StyleCLIP [Patashnik et al. 2021] and StyleGAN-NADA [Gal et al. 2021], adapting the directional CLIP loss from 2D image editing to 3D radiance fields [S2]. The configuration described in [S1] is derived from the implementation details provided in "Decomposing NeRF for Editing Via Feature Field Distillation," which cites the original CLIPNeRF work [S1].
