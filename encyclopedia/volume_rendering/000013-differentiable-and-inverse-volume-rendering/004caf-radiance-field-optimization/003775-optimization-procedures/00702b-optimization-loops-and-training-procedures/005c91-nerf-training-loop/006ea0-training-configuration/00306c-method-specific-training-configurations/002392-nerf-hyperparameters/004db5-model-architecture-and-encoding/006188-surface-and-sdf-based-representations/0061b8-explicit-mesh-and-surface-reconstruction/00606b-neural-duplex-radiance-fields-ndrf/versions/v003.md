# Neural Duplex Radiance Fields (NDRF)


## Overview
Neural Duplex Radiance Fields (NDRF) is a method for distilling a pretrained Neural Radiance Field (NeRF) into a mesh-based representation that enables real-time view synthesis [S1]. It solves the high computational cost of standard NeRF rendering by replacing dense volumetric sampling with a "duplex" interval defined by two ray-surface intersections on a proxy mesh [S1]. Unlike standard NeRF which uses a deep MLP for every sample, NDRF uses a shallow convolutional network (CNN) to aggregate local geometric and appearance information from these two points, achieving approximately 10,000 times faster run-time performance while maintaining high-quality appearance [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A pretrained NeRF model (MLP parameters), a set of training images with known camera poses, and a target camera ray $r(\lambda) = o + \lambda d$ where $o \in \mathbb{R}^3$ is the origin and $d \in \mathbb{R}^3$ is the direction [S1].
*   **Output:** A rendered RGB color $\mathbf{c} \in \mathbb{R}^3$ for the pixel corresponding to the ray [S1].

**Data Structures:**
1.  **Duplex Mesh:** A two-layer mesh extracted from the pretrained NeRF's density field [S1]. It consists of an inner surface and an outer surface that bracket the true underlying geometry [S1]. This defines the reliable interval of the density field [S1].
2.  **Radiance Features:** For each vertex on the duplex mesh, a feature vector is stored [S1]. These features are learned during optimization [S1].
3.  **Shallow CNN:** A convolutional network that takes the radiance features from the two intersection points and the local pixel neighborhood as input to predict the final color [S1].

**Steps:**

1.  **Geometry Proxy Extraction:**
    Extract a geometry proxy (mesh) from the pretrained NeRF model using marching cubes [S1]. The mesh has two layers: an inner layer and an outer layer [S1].

2.  **Ray-Surface Intersection:**
    For each target camera ray with origin $o$ and direction $d$, find the two intersection points where the ray intersects the two layers of the duplex mesh [S1]. Let these points be $p_{in}$ (inner intersection) and $p_{out}$ (outer intersection) [S1].

3.  **Feature Retrieval via Barycentric Interpolation:**
    Derive radiance features at the intersection points $p_{in}$ and $p_{out}$ using barycentric interpolation on the mesh triangles [S1]. Let $\mathbf{f}_{in}$ and $\mathbf{f}_{out}$ be the interpolated feature vectors [S1]. The interpolation follows $\mathbf{f} = u \mathbf{f}_0 + v \mathbf{f}_1 + w \mathbf{f}_2$, where $u,v,w$ are the barycentric coordinates of the intersection point on the triangle, and $\mathbf{f}_0, \mathbf{f}_1, \mathbf{f}_2$ are the vertex features [S1].

4.  **Color Prediction via Shallow CNN:**
    Use a shallow convolutional network to aggregate the local geometric and appearance information from $\mathbf{f}_{in}$ and $\mathbf{f}_{out}$, along with the local neighborhood of pixels in the screen space, to produce the view-dependent color $\mathbf{c}$ [S1]. This replaces the deep MLP used in standard NeRF [S1].

5.  **Optimization:**
    Optimize the representation by comparing the output color $\mathbf{c}$ directly with the pixels of rendered or ground-truth views [S1]. This is done using a multi-view distillation optimization strategy [S1].

**Pseudocode:**

```python
def ray_mesh_intersect(origin, direction, vertices, faces):
    """Returns closest positive t and intersection point using Möller–Trumbore."""
    closest_t = float('inf')
    closest_point = None
    for i in range(0, len(faces), 3):
        v0, v1, v2 = vertices[faces[i]], vertices[faces[i+1]], vertices[faces[i+2]]
        edge1 = [v1[j]-v0[j] for j in range(3)]
        edge2 = [v2[j]-v0[j] for j in range(3)]
        h = [direction[1]*edge2[2]-direction[2]*edge2[1],
             direction[2]*edge2[0]-direction[0]*edge2[2],
             direction[0]*edge2[1]-direction[1]*edge2[0]]
        a = sum(e*d for e,d in zip(edge1, h))
        if -1e-6 < a < 1e-6: continue
        f = 1.0 / a
        s = [origin[j]-v0[j] for j in range(3)]
        u = f * sum(s[j]*h[j] for j in range(3))
        if u < 0.0 or u > 1.0: continue
        q = [s[1]*edge1[2]-s[2]*edge1[1],
             s[2]*edge1[0]-s[0]*edge1[2],
             s[0]*edge1[1]-s[1]*edge1[0]]
        v = f * sum(direction[j]*q[j] for j in range(3))
        if v < 0.0 or u + v > 1.0: continue
        t = f * sum(edge2[j]*q[j] for j in range(3))
        if t > 1e-6 and t < closest_t:
            closest_t = t
            closest_point = [origin[j] + t*direction[j] for j in range(3)]
    return closest_t, closest_point

def get_barycentric_coords(v0, v1, v2, p):
    """Computes barycentric coordinates (u,v,w) for point p on triangle v0,v1,v2."""
    v0v1 = [v1[j]-v0[j] for j in range(3)]
    v0v2 = [v2[j]-v0[j] for j in range(3)]
    v0p = [p[j]-v0[j] for j in range(3)]
    d00 = sum(a*b for a,b in zip(v0v1, v0v1))
    d01 = sum(a*b for a,b in zip(v0v1, v0v2))
    d11 = sum(a*b for a,b in zip(v0v2, v0v2))
    d20 = sum(a*b for a,b in zip(v0p, v0v1))
    d21 = sum(a*b for a,b in zip(v0p, v0v2))
    denom = d00 * d11 - d01 * d01
    v = (d11 * d20 - d01 * d21) / denom
    w = (d00 * d21 - d01 * d20) / denom
    u = 1.0 - v - w
    return [u, v, w]

def interpolate_features(vertex_feats, bary):
    """Linear interpolation of feature vectors using barycentric coordinates."""
    return [sum(bary[k]*vertex_feats[k][j] for k in range(3)) for j in range(len(vertex_feats[0]))]

def shallow_cnn_forward(f_in, f_out, screen_patch):
    """Aggregates local geometry and appearance via a shallow CNN."""
    combined = f_in + f_out + screen_patch
    # Standard shallow CNN: linear projection + activation
    weights = [[0.5, -0.2, 0.1], [0.1, 0.5, -0.1], [-0.1, 0.1, 0.5]]
    bias = [0.0, 0.0, 0.0]
    out = [sum(w*c for w,c in zip(row, combined)) + b for row, b in zip(weights, bias)]
    return [max(0.0, x) for x in out] # ReLU activation

def render_ndrf(ray_origin, ray_direction, mesh_data, screen_patch):
    """Renders a single pixel using the NDRF method."""
    t_in, p_in = ray_mesh_intersect(ray_origin, ray_direction, mesh_data['inner_v'], mesh_data['inner_f'])
    t_out, p_out = ray_mesh_intersect(ray_origin, ray_direction, mesh_data['outer_v'], mesh_data['outer_f'])
    if t_in is None or t_out is None:
        return [0.0, 0.0, 0.0]
    # Assume triangle indices for p_in and p_out are pre-computed or found via spatial hash
    tri_in_idx = mesh_data['inner_tri_idx'][tuple(p_in)]
    tri_out_idx = mesh_data['outer_tri_idx'][tuple(p_out)]
    v0, v1, v2 = [mesh_data['inner_v'][mesh_data['inner_f'][tri_in_idx+k]] for k in range(3)]
    v0_out, v1_out, v2_out = [mesh_data['outer_v'][mesh_data['outer_f'][tri_out_idx+k]] for k in range(3)]
    bary_in = get_barycentric_coords(v0, v1, v2, p_in)
    bary_out = get_barycentric_coords(v0_out, v1_out, v2_out, p_out)
    f_in = interpolate_features([mesh_data['inner_feats'][mesh_data['inner_f'][tri_in_idx+k]] for k in range(3)], bary_in)
    f_out = interpolate_features([mesh_data['outer_feats'][mesh_data['outer_f'][tri_out_idx+k]] for k in range(3)], bary_out)
    return shallow_cnn_forward(f_in, f_out, screen_patch)

def train_ndrf(pretrained_nerf, training_data, epochs=1000, lr=1e-3):
    """Distills a pretrained NeRF into NDRF representation."""
    mesh_data = extract_mesh_from_nerf(pretrained_nerf) # Not given in sources
    mesh_data['inner_feats'] = [[0.0]*64 for _ in range(len(mesh_data['inner_v']))]
    mesh_data['outer_feats'] = [[0.0]*64 for _ in range(len(mesh_data['outer_v']))]
    for epoch in range(epochs):
        for img, cam_pose in training_data:
            rays = generate_rays(img.shape, cam_pose) # Not given in sources
```

**Parameters:**
*   **Number of sampled 3D locations per ray:** Reduced from hundreds (in NeRF) to two (in NDRF) [S1].
*   **Mesh Extraction:** Marching cubes [S1].

**Edge Cases and Pitfalls:**
*   **Direct Training Artifacts:** Directly training the neural duplex radiance field from scratch leads to noticeable artifacts [S1]. This is mitigated by using a multi-view distillation optimization strategy, where the NDRF is initialized from a pretrained NeRF [S1].
*   **Geometry Inaccuracies:** The extracted mesh may not faithfully represent the true underlying geometry and can contain artifacts due to inaccuracies in the density field around surfaces [S1]. The duplex interval (two layers) helps cover the reliable interval of the density field, mitigating this issue compared to a single surface [S1].

## Operating characteristics
*   **Performance:** NDRF improves run-time performance by approximately 10,000 times compared to the original NeRF [S1]. While standard NeRF requires about 30 seconds to render a single 800x800 image, NDRF enables real-time view synthesis [S1].
*   **Memory:** The method stores radiance features on a mesh, which is generally more memory-efficient than storing a large MLP and dense sampling volumes, though exact memory figures are not provided in the sources [S1].
*   **Strengths:**
    *   Real-time rendering capability [S1].
    *   Post-processing step for any existing NeRFs; does not require complex multi-stage optimization or retraining from scratch [S1].
    *   High-quality appearance by leveraging local geometric relationships via CNNs [S1].
*   **Limitations:**
    *   Relies on the quality of the initial NeRF model for distillation [S1].
    *   Mesh extraction via marching cubes may introduce geometric inaccuracies, though the duplex structure mitigates this [S1].
*   **When to use:** When real-time view synthesis is required and a pretrained NeRF model is available [S1].
*   **When not to use:** When high-fidelity geometry is required without the approximation of a mesh proxy, or when no pretrained NeRF is available (as training from scratch causes artifacts) [S1].

## Background
NDRF was proposed in the paper "Learning Neural Duplex Radiance Fields for Real-Time View Synthesis" [S1]. The work addresses the inescapable problem of high computational cost in NeRF and its extensions, which prevents their use for real-time applications [S1]. It builds on the concept of distilling NeRFs into mesh-based representations, similar to concurrent works like MobileNeRF, but distinguishes itself by serving as a post-processing step that avoids complex multi-stage optimization [S1]. The method leverages the massively parallel graphics rendering pipeline by using screen-space convolutions instead of MLPs [S1].
