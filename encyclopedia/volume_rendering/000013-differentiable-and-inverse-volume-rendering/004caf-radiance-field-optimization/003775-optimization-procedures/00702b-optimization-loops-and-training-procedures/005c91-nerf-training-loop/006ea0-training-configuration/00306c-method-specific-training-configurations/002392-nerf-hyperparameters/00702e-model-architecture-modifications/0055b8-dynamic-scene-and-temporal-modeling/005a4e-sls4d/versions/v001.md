# SLS4D

Also called: Sparse Latent Space for 4D Novel View Synthesis

## Overview
SLS4D is a method for 4D novel view synthesis that represents dynamic scenes using a sparse, compact, and informative latent feature space, significantly reducing the number of network parameters compared to dense voxel-based or fully implicit alternatives [S1]. It distinguishes itself by abandoning direct coordinate-to-feature mapping in favor of relative relationships within a latent space, utilizing dense learnable time slots for temporal continuity and an attention-based interpolator decoder for spatial feature aggregation [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of images capturing a dynamic scene over time, along with their corresponding camera poses and timestamps.
*   **Output:** A radiance field model capable of rendering novel views at arbitrary spatial coordinates $(x, y, z)$ and time $t$.

**Data Structures:**
1.  **Latent Codes ($\mathcal{L}$):** A finite set of globally learnable spatial latent codes.
    *   Size: $B$ codes.
    *   Dimension: $D_L$ (Not given in the sources).
    *   Layout: A tensor of shape $(B, D_L)$.
2.  **Time Slots ($\mathcal{T}$):** Dense learnable features representing temporal states.
    *   Size: $T$ slots.
    *   Dimension: $D_T$ (Not given in the sources).
    *   Layout: A tensor of shape $(T, D_T)$.
3.  **Deformation Field ($\Phi$):** A 7-layer Multi-Layer Perceptron (MLP).
    *   Input: Concatenation of 3D spatial coordinate $(x, y, z)$ and a specific time slot feature from $\mathcal{T}$.
    *   Output: 3D displacement vector $(\Delta x, \Delta y, \Delta z)$.
4.  **Interpolator Decoder:** A network module using GeGLU (bilinear Gated Linear Unit) activation.
    *   Input: Aggregated spatial features.
    *   Output: Density $\sigma$ and view-dependent color $\mathbf{c}$.

**Parameters:**
*   $B = 512$: Number of latent features [S1].
*   $T = 512$: Number of time slots [S1].
*   Typical values are based on the HyperNeRF dataset duration; for D-NeRF, smaller values may be used, but the source specifies 512 for the reported experiments [S1].

**Algorithm Steps:**

1.  **Temporal Encoding:**
    For a query time $t$, identify the corresponding time slot index or interpolate between time slots in $\mathcal{T}$ to obtain the time feature $\mathbf{t}_{feat} \in \mathbb{R}^{D_T}$. The source notes that time slots ensure smoothness of dense temporal information [S1].

2.  **Deformation Field Prediction:**
    Compute the deformation displacement for a 3D position $\mathbf{p} = (x, y, z)$ at time $t$:
    $$ \Delta \mathbf{p} = \Phi(\mathbf{p}, \mathbf{t}_{feat}) $$
    where $\Phi$ is the 7-layer MLP. The deformed position is:
    $$ \mathbf{p}' = \mathbf{p} + \Delta \mathbf{p} $$
    This step decouples time and space, allowing the spatial latent space to represent the scene in a canonical, undeformed state [S1].

3.  **Spatial Feature Aggregation via Attention:**
    Retrieve the spatial features for $\mathbf{p}'$ from the sparse latent space $\mathcal{L}$. This is done using an attention mechanism:
    *   Compute a query feature $\mathbf{q}$ from the position $\mathbf{p}'$ (implementation detail: "query feature of the 3D position" [S1]).
    *   Compute attention weights $\alpha_i$ for each latent code $\mathbf{l}_i \in \mathcal{L}$ using the inner product of the query $\mathbf{q}$ and the key value $\mathbf{k}_i$ of the latent code:
        $$ \alpha_i = \text{softmax}\left(\frac{\mathbf{q} \cdot \mathbf{k}_i}{\sqrt{d}}\right) $$
        where $d$ is the dimensionality of the key/query vectors [S1].
    *   Aggregate the latent codes:
        $$ \mathbf{f}_{spatial} = \sum_{i=1}^{B} \alpha_i \mathbf{l}_i $$
    This approach abandons direct coordinate relationships, relying instead on relative relationships in the latent feature space [S1].

4.  **Radiance Field Decoding:**
    Pass the aggregated spatial feature $\mathbf{f}_{spatial}$ through the Interpolator Decoder to predict density $\sigma$ and color $\mathbf{c}$:
    $$ \sigma, \mathbf{c} = \text{Decoder}(\mathbf{f}_{spatial}) $$
    The decoder uses GeGLU activations, which offer higher fitting capacity than standard GeLU or MLPs for modeling complex nonlinear relationships [S1].

5.  **Rendering:**
    Perform volume rendering along the ray using the predicted $\sigma$ and $\mathbf{c}$ values [S1].

**Loss Functions:**
*   **Reconstruction Loss:** Standard photometric loss between rendered and ground truth images [S1].
*   **Total Variance (TV) Loss:** Applied to the deformation field to supervise temporal smoothness. This ensures smooth transitions between deformation fields for adjacent timestamps [S1].

**Edge Cases and Pitfalls:**
*   **Excessively Long Durations:** If the input scene duration is very long, the fixed number of parameters ($B, T$) may struggle to fit the data adequately [S1].
*   **Absence of Deformation Fields:** Removing the deformation field (SLS4Dnd) leads to challenges in extracting information for reconstruction due to the lack of decoupling between time and space [S1].
*   **Removing Time Slots:** Removing time slots (SLS4Dnf) results in degradation of rendering quality because smoothness of dense temporal information is lost [S1].
*   **Decoder Choice:** Using only GeLU (SLS4Dge) or a standard MLP (SLS4Dml) as the interpolator decoder results in inferior performance compared to GeGLU [S1].
*   **Learning Rate Stability:** Using only cosine decay (SLS4Dco) is unstable; using only exponential decay (SLS4Deo) may get stuck in local optima. The method uses a combined cosine*exp decay [S1].

## Background
SLS4D was introduced as a novel approach for 4D novel-view synthesis, representing the first method to use a sparse latent space representation for dynamic neural radiance fields [S1]. It builds upon the D-NeRF framework by introducing a sparse spatial latent space and dense temporal time slots [S1]. The method was developed to address the high parameter count and computational cost of previous state-of-the-art methods like V4D and TiNeuVox [S1].
