# Depth Alignment for Monocular Cues
Also called: Least-squares Depth Alignment, Scale and Shift Alignment

## Overview
Depth Alignment for Monocular Cues solves the scale and shift ambiguity inherent in monocular depth estimation (MDE) by linearly aligning relative MDE outputs with rendered depth values during NeRF training. It differs from sibling methods like [NerfingMVS](9518-nerfingmvs.md) which use multi-view stereo consistency, by relying solely on a single-view depth prior per image and optimizing alignment parameters per mini-batch to enforce geometric consistency [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Rendered depth map $\bar{D}$ from the NeRF, monocular depth estimate $D^*$ from a frozen pre-trained network (e.g., Omnidata), and a set of sampled pixel indices $P$ for the current mini-batch.
*   **Outputs:** Alignment parameters (scale $w$, shift $q$) and the aligned depth loss contribution to the total objective.

**Data Structures:**
*   $D^*$: 2D tensor of shape $(H, W)$, values in $[0, 1]$ (normalized MDE output).
*   $\bar{D}$: 2D tensor of shape $(H, W)$, rendered depth values.
*   $P$: List of $(u, v)$ pixel coordinates sampled from the image.

**Steps:**
1.  **Sample Pixels:** Select $N$ pixels from the image to compute alignment statistics. Let the sampled values be $D^*_p$ and $\bar{D}_p$ for $p \in P$.
2.  **Stop-Gradient:** Apply stop-gradient to $D^*$ to prevent gradients from flowing into the frozen MDE network: $D^*_{sg} = \text{sg}(D^*)$.
3.  **Least-Squares Optimization:** Solve for scale $w$ and shift $q$ that minimize the squared error between the aligned MDE depth and rendered depth:
    $$ \min_{w, q} \sum_{p \in P} \| (w \cdot D^*_{sg}(p) + q) - \bar{D}(p) \|^2 $$
    The closed-form solution for $w$ and $q$ is derived from the covariance and mean of the sampled depths [S1, S2].
4.  **Apply Alignment:** Compute the aligned MDE depth: $\tilde{D}(p) = w \cdot D^*(p) + q$.
5.  **Compute Loss:** Calculate the depth consistency loss $L_{depth}$ using the aligned depth $\tilde{D}$ and rendered depth $\bar{D}$.

**Formulas:**
Let $\mu_{MDE} = \frac{1}{N} \sum_{p \in P} D^*_{sg}(p)$ and $\mu_{R} = \frac{1}{N} \sum_{p \in P} \bar{D}(p)$.
Let $\sigma_{MDE, R} = \frac{1}{N} \sum_{p \in P} (D^*_{sg}(p) - \mu_{MDE})(\bar{D}(p) - \mu_{R})$.
Let $\sigma^2_{MDE} = \frac{1}{N} \sum_{p \in P} (D^*_{sg}(p) - \mu_{MDE})^2$.

$$ w = \frac{\sigma_{MDE, R}}{\sigma^2_{MDE} + \epsilon} $$
$$ q = \mu_{R} - w \cdot \mu_{MDE} $$

Where $\epsilon$ is a small constant (e.g., $10^{-8}$) to prevent division by zero [G].

**Parameters:**
*   $N$: Number of sampled pixels. Typical value: Not given in the sources.
*   $\epsilon$: Regularization constant. Typical value: $10^{-8}$ [G].

**Edge Cases and Pitfalls:**
*   **Zero Variance:** If $\sigma^2_{MDE} \approx 0$ (e.g., flat regions), $w$ becomes unstable. Add $\epsilon$ to the denominator.
*   **Outliers:** MDE errors can be large. Using robust loss functions (e.g., Huber) instead of squared error can mitigate this, though the source specifies least-squares [S1].
*   **Scale Ambiguity:** Without alignment, the NeRF may converge to an arbitrary scale. This method ensures the scale matches the MDE prior relative to the rendered depth.

**Pseudocode:**
```python
def depth_alignment(D_mde, D_rendered, num_samples=1024):
    """
    Align monocular depth with rendered depth using least-squares.
    
    Args:
        D_mde: Tensor (H, W), monocular depth estimate [0, 1].
        D_rendered: Tensor (H, W), rendered depth from NeRF.
        num_samples: Number of pixels to sample for alignment.
        
    Returns:
        w: Scale parameter.
        q: Shift parameter.
    """
    # Sample random pixel indices
    H, W = D_mde.shape
    indices = torch.randint(0, H * W, (num_samples,))
    u = indices // W
    v = indices % W
    
    # Extract sampled values
    # Note: In practice, gather from tensors
    d_mde_sampled = D_mde[u, v]
    d_rendered_sampled = D_rendered[u, v]
    
    # Stop gradient on MDE depth
    d_mde_sampled = d_mde_sampled.detach()
    
    # Compute means
    mu_mde = torch.mean(d_mde_sampled)
    mu_rendered = torch.mean(d_rendered_sampled)
    
    # Compute covariance and variance
    cov = torch.mean((d_mde_sampled - mu_mde) * (d_rendered_sampled - mu_rendered))
    var_mde = torch.mean((d_mde_sampled - mu_mde) ** 2)
    
    # Compute scale and shift
    epsilon = 1e-8
    w = cov / (var_mde + epsilon)
    q = mu_rendered - w * mu_mde
    
    return w, q
```

## Subtopics

### Depth Normalization for Scale/Shift Invariance
A preprocessing step to normalize monocular depth estimates because monocular depth is not scale- and shift-invariant, allowing for meaningful comparison with rendered depth. It computes the mean depth $t(D)$ and mean absolute deviation $s(D)$ over $N$ sampled pixels, then normalizes the depth image $D^* = \frac{D - t(D)}{s(D)}$ [S2]. This is used in [Incremental Joint Learning of Depth, Pose, and Implicit Scene Representation on Monocular Camera in Large-Scale Scenes](https://doi.org/10.1109/tase.2025.3617654) to define the normalized depth loss $\mathcal{L}_d = \| \hat{\mathbf{D}}^* - \mathbf{D}^* \|$ [S2].

## Operating characteristics
*   **Time Complexity:** $O(N)$ per mini-batch for sampling and computing statistics, where $N$ is the number of sampled pixels. Negligible compared to NeRF forward pass.
*   **Memory Complexity:** $O(N)$ to store sampled depth values.
*   **Strengths:** Simple to implement; effectively resolves scale ambiguity; works with any pre-trained MDE model.
*   **Limitations:** Relies on the quality of the MDE prior; sensitive to outliers in MDE; assumes linear relationship between MDE and rendered depth.
*   **When to Use:** When training NeRFs from monocular images with a reliable MDE prior (e.g., Omnidata) and no sparse point cloud or multi-view stereo data is available.
*   **When Not to Use:** When high-precision absolute scale is required and MDE is known to be inaccurate; when multi-view consistency is available and preferred.

## Background
Originated in methods like MonoSDF and Neuralangelo for inferring signed distance functions from monocular images. It addresses the challenge of using monocular depth priors in volume rendering by aligning them with the rendered depth to enforce geometric consistency [S1, S2]. The method is widely used in recent monocular NeRF and SDF reconstruction pipelines.
