# PixelSplat Training and Depth Regularization

Also called: Depth Regularization for 3DGS, PixelSplat Training

## Overview
PixelSplat Training and Depth Regularization is a training procedure for generalizable 3D Gaussian Splatting that combines photometric reconstruction with geometric regularization [S1]. It differs from its siblings by explicitly placing multiple Gaussians per ray to enable multi-depth gradients and applying a discrete depth regularization term based on second-order derivatives [S1].

## How it works
**Inputs:** Scenes with reference views and camera poses [S1].
**Outputs:** Trained 3D Gaussians and rendered RGB/depth maps for target views [S1].
**Data Structures:**
- **Gaussian:** Defined by mean position $\mu \in \mathbb{R}^3$, covariance matrix $\Sigma \in \mathbb{R}^{3 \times 3}$ (or rotation/scale parameters), color $c \in \mathbb{R}^3$, and opacity $\alpha \in [0, 1]$ [G].
- **Ray Probability Distribution:** A distribution $P(z)$ along the viewing ray, from which Gaussian centers are sampled [S1].
**Parameters:**
- Total training steps: 300,000 [S1].
- Batch size: 7 scenes per batch [S1].
- Gaussians per ray: 3 [S1].
- Alpha scaling factor: $1/3$ [S1].
- MSE loss phase: Steps 0–150,000 [S1].
- LPIPS loss phase: Steps 150,000–300,000, weight 0.05 [S1].
- Depth regularization phase: 50,000 steps [S1].
- VRAM requirement: ~80 GB on a single GPU [S1].
**Steps:**
1. **Initialization:** Initialize Gaussians for each scene [G].
2. **Forward Pass (Rendering):** For each scene in the batch, render 4 target views [S1]. For each pixel in the target view, cast a ray and sample 3 Gaussian positions independently from the ray's probability distribution $P(z)$ [S1]. For each sampled Gaussian $i$, set its opacity $\alpha_i = \phi_z / 3$, where $\phi_z$ is the base opacity contribution, ensuring the total opacity of the 3 Gaussians along the ray sums to roughly 1 [S1]. Render the RGB image and depth map $D$ using standard volume rendering accumulation [S1].
3. **Photometric Loss Calculation (Steps 0–150,000):** Compute the MSE loss for the rendered images [S1].
4. **Photometric Loss Calculation (Steps 150,000–300,000):** Compute the combined loss: $L_{photo} = L_{MSE} + 0.05 \cdot L_{LPIPS}$, where $L_{LPIPS}$ is the Learned Perceptual Image Patch Similarity loss [S1].
5. **Depth Regularization (Fine-tuning, Steps 0–50,000 of phase 2):** Generate a depth map $D$ for each rendered view [S1]. Compute horizontal and vertical second-order differences of the depth map: $D_x^{\Delta}[\mathbf{u}] = D[\mathbf{u}_{x-1}, \mathbf{u}_y] - 2D[\mathbf{u}_x, \mathbf{u}_y] + D[\mathbf{u}_{x+1}, \mathbf{u}_y]$ and $D_y^{\Delta}[\mathbf{u}] = D[\mathbf{u}_x, \mathbf{u}_{y-1}] - 2D[\mathbf{u}_x, \mathbf{u}_y] + D[\mathbf{u}_x, \mathbf{u}_{y+1}]$, where $\mathbf{u} = (u_x, u_y)$ are pixel coordinates [S1]. Compute the depth regularization loss $L_{reg\_depth}$ based on these differences and optimize the Gaussian parameters to minimize it [S1].

    optimizer = Adam(model_params, lr=lr)

    for step in range(num_steps):
        batch_scenes = sample_batch(scenes, batch_size)
        optimizer.zero_grad()
        total_loss = 0.0

        for scene in batch_scenes:
            rendered_images = []
            rendered_depths = []

            for target_idx in target_view_indices:
                rays = cast_rays(scene, target_idx)
                gaussian_params = sample_gaussians_per_ray(rays, num_samples=3)
                gaussian_params.alpha /= 3.0
                rgb, depth = volume_render(gaussian_params, rays)
                rendered_images.append(rgb)
                rendered_depths.append(depth)

            gt_images = get_ground_truth(scene, target_view_indices)

            if step < 150000:
                loss = compute_mse(rendered_images, gt_images)
            else:
                loss = compute_mse(rendered_images, gt_images) + 0.05 * compute_lpips(rendered_images, gt_images)

            total_loss += loss

        total_loss.backward()
        optimizer.step()

    for step in range(reg_steps):
        batch_scenes = sample_batch(scenes, batch_size)
        optimizer.zero_grad()
        total_reg_loss = 0.0

        for scene in batch_scenes:
            reg_loss = 0.0
            for target_idx in target_view_indices:
                rays = cast_rays(scene, target_idx)
                gaussian_params = sample_gaussians_per_ray(rays, num_samples=3)
                gaussian_params.alpha /= 3.0
                rgb, depth = volume_render(gaussian_params, rays)

                dx = depth[:-2, :, :] - 2.0 * depth[1:-1, :, :] + depth[2:, :, :]
                dy = depth[:, :-2, :] - 2.0 * depth[:, 1:-1, :] + depth[:, 2:, :]
                depth_reg = compute_depth_regularization(dx, dy)
                reg_loss += depth_reg

            total_reg_loss += reg_loss

        total_reg_loss.backward()
        optimizer.step()

## Subtopics

### SparSplat Training Objective
SparSplat Training Objective is a variant that uses end-to-end training with multi-view RGB and ground truth depth supervision, freezing deep feature networks for efficiency [S2, unofficial]. It employs a multi-stage coarse-to-fine optimization with a composite loss function: $L_k = L_{mse} + \lambda_s L_{ssim} + \lambda_p L_{perc} + \lambda_\alpha L_d + \lambda_\beta L_n + \lambda_\gamma L_{depth}$ [S2, unofficial]. Here, $L_d = \sum_{i,j} \omega_i \omega_j |z_i - z_j|$ is the depth distortion loss concentrating weights along rays, and $L_n = \sum_i \omega_i (1 - n_i^T N)$ is the normal consistency loss aligning splat normals with rendered depth normals [S2, unofficial]. This approach differs from PixelSplat by using 2D Gaussian Splatting and explicit normal/depth distortion terms rather than second-order depth derivatives [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Training requires 300,000 steps for the main phase and 50,000 for depth regularization [S1].
- **Memory Complexity:** Requires approximately 80 GB of VRAM on a single GPU for a batch size of 7 [S1].
- **Strengths:** Allows gradients for multiple depths per ray, improving reconstruction in complex scenes [S1].
- **Limitations:** High VRAM requirement limits batch size and resolution [S1].

## Background
The method builds on 3D Gaussian Splatting and generalizable reconstruction techniques [S1]. The depth regularization technique is designed to enhance the geometric quality of the reconstructed point clouds [S1]. SparSplat uses 2D Gaussian Splatting with explicit normal/depth distortion terms [S2, unofficial].
