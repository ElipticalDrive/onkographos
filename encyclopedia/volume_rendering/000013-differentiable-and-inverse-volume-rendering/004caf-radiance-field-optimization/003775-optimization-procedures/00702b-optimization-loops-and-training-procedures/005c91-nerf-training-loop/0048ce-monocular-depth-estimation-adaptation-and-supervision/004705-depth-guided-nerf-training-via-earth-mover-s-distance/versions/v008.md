# Depth-Guided NeRF Training via Earth Mover’s Distance

Also called: Depth-guided NeRF via Earth Mover’s Distance, EM D-Guided Sampling, EMD-Guided Depth Supervision for NeRF, EMD-NeRF, EMD-based objective

## Overview
This method improves the geometric accuracy of Neural Radiance Fields (NeRFs) trained on sparse views by supervising the distribution of ray termination distances using Earth Mover’s Distance (EMD) rather than enforcing direct depth matching [S1]. Unlike sibling methods such as [DäRF](12331-d-rf.md) which minimize the norm between rendered and prior depth, or [SCADE](9518-nerfingmvs.md) which relies on multiple ambiguous hypotheses, this approach uses a single off-the-shelf diffusion-based depth prior and its intrinsic uncertainty map to selectively guide the NeRF’s geometry without propagating prior inaccuracies [S1]. It builds on [Monocular Depth Estimation Adaptation and Supervision](12353-monocular-depth-estimation-adaptation-and-supervision.md) by replacing standard L2 depth consistency losses with a distributional EMD loss weighted by uncertainty [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   A set of $N$ input RGB images $\{I_i\}_{i=1}^N$ (typically $N < 20$) and their corresponding SfM camera poses [S1].
*   A pre-trained monocular depth estimation (MDE) network, specifically DiffDP [S1].
*   A NeRF model $F_\Theta$ initialized with random weights [S1].

**Outputs:**
*   A trained NeRF model $F_\Theta$ capable of rendering novel views with accurate geometry [S1].
*   Rendered RGB images and depth maps for novel viewpoints [S1].

### Data Structures
*   **NeRF Model ($F_\Theta$):** A multilayer perceptron (MLP) taking 5D input $(x, y, z, \theta, \phi)$ representing camera position and viewing direction, outputting color $c$ and volume density $\sigma$ [S1].
*   **Depth Prior ($z_0$):** A relative depth map generated by DiffDP for each input image [S1].
*   **Uncertainty Map ($u$):** A pixel-wise uncertainty map derived from the DiffDP denoising process, normalized to $[0, 1]$ [S1].
*   **Ray Samples:** For each ray, a set of termination distances $y = \{y_1, \dots, y_N\}$ sampled from the NeRF's predicted distribution [S1].

### Numbered Steps

1.  **Depth Prior and Uncertainty Extraction:**
    For each input image $I$, run the DiffDP network to generate the depth prior $z_0$ and the uncertainty map $u$ [S1]. DiffDP formulates denoising as $p_\theta(z_{0:T}|I)$ [S1]. The uncertainty is derived by comparing estimates at consecutive denoising steps $t$ and $t-1$ [S1]. Let $c(z_{0:T})$ be the count of steps where the change exceeds a threshold $\tau$:
    $$ c(z_{0:T}) = \frac{1}{T} \sum_{t=T,\dots,1} \mathbb{I}(|z_t - z_{t-1}| \ge \tau) $$
    The final uncertainty $u(z_{0:T}|I)$ combines this temporal uncertainty with spatial consistency using a mirrored image $M(I)$:
    $$ U(z_{0:T}|I) = \frac{c(z_{0:T}|I) + M(c(z_{0:T}|M(I)))}{2} $$
    $$ u(z_{0:T}|I) = U(z_{0:T}|I) \cdot \| (z_0|I) - M(z_0|M(I)) \|_1 $$
    [S1]

2.  **NeRF Forward Pass and Weight Calculation:**
    Cast rays through the camera. For each sample $i$ along a ray at distance $d_i$, query $F_\Theta$ to get density $\sigma_i$ [S1]. Calculate the transmittance $T_i$ and the weight $w_i$ representing the probability that the ray terminates at sample $i$:
    $$ T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right) $$
    $$ w_i = T_i (1 - \exp(-\sigma_i \delta_i)) $$
    where $\delta_i$ is the distance between adjacent samples [S1].

3.  **Probability Density Construction:**
    Normalize the weights $w_i$ to form a piece-wise constant probability density function (PDF):
    $$ \hat{w}_i = \frac{w_i}{\sum_{j=1}^{N} w_j} $$
    Construct the Cumulative Distribution Function (CDF) from $\hat{w}_i$ [S1].

4.  **EMD-Guided Sampling:**
    Sample new ray termination distances $y = \{y_1, \dots, y_N\}$ from the constructed CDF using inverse transform sampling [S1]. These samples represent the NeRF's learned distribution of surface locations [S1].

5.  **Loss Calculation:**
    *   **Photometric Loss:** Compute the L2 loss between the rendered color $\hat{C}(r)$ and the observed color $C(r)$:
        $$ L_{photo} = ||\hat{C}(r) - C(r)||_2^2 $$
        [S1]
    *   **EMD Depth Loss:** Compute the Earth Mover’s Distance between the sampled NeRF distances $y$ and the depth prior $z_0$ [S1]. Since EMD is non-differentiable, approximate it using Sinkhorn Divergence during training:
        $$ L_{EMD} = EMD(y, z_0) $$
        [S1]
    *   **Total Loss:** Combine the losses weighted by the uncertainty map $u$, a balancing weight $\lambda$, and a focal-like exponent $\gamma$:
        $$ L = (1 + u)^\gamma L_{photo} + \lambda (1 - u)^\gamma L_{EMD} $$
        Note: Unlike Focal Loss which increases weight for uncertain examples, this method *decreases* the weight of the depth loss for uncertain pixels ($1-u$), relying more on photometric supervision when depth is unreliable [S1].

6.  **Optimization:**
    Update NeRF parameters $\Theta$ using gradient descent [S1]. Initialize the scale of the depth priors to 1 and learn the scale with a small learning rate [S1].

### Pseudocode

```python
import torch

def compute_uncertainty(depth_estimates, threshold_tau=0.1):
    """
    Computes uncertainty map u from DiffDP denoising process.
    depth_estimates: tensor of shape (T, H, W) containing z_t for t=0..T-1
    """
    diffs = torch.abs(depth_estimates[1:] - depth_estimates[:-1])
    c_temporal = (diffs >= threshold_tau).float().mean(dim=0)
    mirrored_depth = torch.flip(depth_estimates, dims=[1])
    mirrored_diffs = torch.abs(mirrored_depth[1:] - mirrored_depth[:-1])
    c_mirrored = (mirrored_diffs >= threshold_tau).float().mean(dim=0)
    c_mirrored = torch.flip(c_mirrored, dims=[0])
    U = (c_temporal + c_mirrored) / 2.0
    z0 = depth_estimates[0]
    z0_mirrored = torch.flip(z0, dims=[0])
    spatial_diff = torch.abs(z0 - z0_mirrored)
    u = U * spatial_diff.mean(dim=0, keepdim=True)
    return u

def nerf_forward(ray_origins, ray_directions, sigma_fn, near, far, num_samples):
    """
    Standard NeRF forward pass returning weights, samples, and colors.
    sigma_fn: callable returning (rgb, sigma) for points and directions
    """
    t_vals = torch.linspace(0., 1., num_samples, device=ray_origins.device)
    z_vals = near * (1. - t_vals) + far * t_vals
    pts = ray_origins.unsqueeze(1) + ray_directions.unsqueeze(1) * z_vals.unsqueeze(2)
    pts_flat = pts.reshape(-1, 3)
    dirs = ray_directions.unsqueeze(1).expand(pts.shape).reshape(-1, 3)
    rgb, sigma = sigma_fn(pts_flat, dirs)
    sigma = sigma.reshape(pts.shape[:-1])
    deltas = z_vals[1:] - z_vals[:-1]
    deltas = torch.cat([deltas, torch.tensor([1e10], device=deltas.device)], dim=-1)
    alpha = 1.0 - torch.exp(-sigma * deltas)
    transmittance = torch.cumprod(torch.cat([torch.ones_like(alpha[..., :1]), 1.0 - alpha + 1e-10], dim=-1), dim=-1)
    weights = alpha * transmittance[..., :-1]
    rgb_final = (weights.unsqueeze(-1) * rgb).sum(dim=-2)
    return weights, z_vals, rgb_final

def sinkhorn_divergence(p, q, epsilon=0.01, num_iter=10):
    """
    Approximates EMD using Sinkhorn Divergence.
    p, q: 1D tensors representing sampled distributions.
    """
    cost_matrix = torch.cdist(p.unsqueeze(1), q.unsqueeze(1)).squeeze()
    K = torch.exp(-cost_matrix / epsilon)
    u = torch.ones_like(p)
    v = torch.ones_like(q)
    for _ in range(num_iter):
        u = 1.0 / (K @ v)
        v = 1.0 / (K.T @ u)
    return (u.unsqueeze(1) * K * v).sum()

def train_step(nerf_sigma_fn, diff_dp_depths, images, poses, uncertainty_maps, lambda_bal, gamma, near, far, coarse_samples, fine_samples):
    """
    Single training step implementing the EMD-guided NeRF method.
    """
    # [G] Standard ray sampling from camera poses and image dimensions
    # rays_o, rays_d = sample_rays_from_poses(poses, images.shape)
    rays_o, rays_d = torch.randn(1024, 3), torch.randn(1024, 3)

    # 2. NeRF Forward (Coarse)
    weights, z_vals, rgb_coarse = nerf_forward(rays_o, rays_d, nerf_sigma_fn, near, far, coarse_samples)

    # 3. Construct CDF and Sample for EMD
    pdf = weights / weights.sum(dim=-1, keepdim=True)
    cdf = torch.cumsum(pdf, dim=-1)
    u_rand = torch.rand_like(cdf)
    indices = torch.searchsorted(cdf, u_rand)
    y_dist = torch.gather(z_vals, 1, indices)

    # [G] Standard photometric loss computation
    # target_rgb = get_target_color(rays_o, rays_d, images)
    target_rgb = torch.randn_like(rgb_coarse)

    l_photo = torch.mean((rgb_coarse - target_rgb) ** 2)

    # Depth prior z0 needs alignment. Assume scaled_z0 is provided or aligned.
    # scaled_z0 = align_depth_prior(z_vals, diff_dp_depths)
    scaled_z0 = torch.randn_like(y_dist)

    l_emd = sinkhorn_divergence(y_dist, scaled_z0)

    # 5. Weight by Uncertainty
    # u_expanded = uncertainty_maps.gather(1, ray_indices).unsqueeze(-1)
    u_expanded = torch.randn(1024, 1)

    l_total = (1 + u_expanded)**gamma * l_photo + lambda_bal * (1 - u_expanded)**gamma * l_emd

    return l_total, rgb_coarse
```

### Parameters
*   **N:** Number of input images, typically $N < 20$ [S1].
*   **Rays per batch:** 1024 [S1].
*   **Ray termination distances (Coarse):** 64 [S1].
*   **Ray termination distances (Fine):** 128 [S1].
*   **Additional samples for EMD:** 128 [S1].
*   **Dropout probability:** 0.1 [S1].
*   **Weight decay:** $10^{-6}$ [S1].
*   **$\lambda$:** Balancing weight between photometric and EMD losses [S1].
*   **$\gamma$:** Exponent controlling the impact of uncertainty $u$ [S1].
*   **Depth Prior Scale:** Initialized to 1, learned with a small learning rate [S1].

### Edge Cases and Pitfalls
*   **Photometric-Geometric Mismatch:** High photometric quality (PSNR/SSIM) does not guarantee correct geometry. Models may render plausible textures while misinterpreting structure (e.g., misinterpreting a cabinet as a patterned carpet) [S1].
*   **Uncertainty Handling:** Unlike Focal Loss which emphasizes hard/uncertain examples, this method *downweights* uncertain pixels in the depth loss to prevent the NeRF from learning incorrect geometry from unreliable priors [S1].
*   **Prior Noise:** Using multiple depth hypotheses (as in SCADE) can introduce noise and training instability. This method uses a single prior to avoid this [S1].
*   **Diffusion Uncertainty:** The uncertainty measure is specific to diffusion-based models like DiffDP. It may not be directly applicable to other MDE architectures without modification [S1].

## Operating characteristics

### Time and Memory Complexity
*   **Time:** The method adds overhead for the uncertainty calculation (mirrored image inference) and the EMD approximation (Sinkhorn Divergence) [S1].
*   **Memory:** Requires storing the depth prior and uncertainty map for each input image [S1].

### Measured Performance
*   **ScanNet+:** Reduces baseline RMSE by at least 56% while maintaining comparable photometric results (PSNR/SSIM) [S1].
*   **Prior Reduction:** With DiffDP prior, the EMD objective reduces the initial prior RMSE by 31.4% [S1]. With DepthAnything prior, it reduces it by 18.8% [S1].
*   **Uncertainty Impact:** For pixels with uncertainty $> 0.8$, incorporating $u$ improves RMSE by 5.1% [S1]. For pixels with uncertainty $< 0.1$, it helps by only 1.9% [S1].

### Strengths and Limitations
*   **Strengths:** Robust to noisy depth priors; does not enforce incorrect geometry; leverages intrinsic uncertainty from diffusion models; drop-in replacement for existing depth-supervised NeRFs [S1].
*   **Limitations:** Uncertainty measure is tied to diffusion-based priors (DiffDP); hyperparameters for uncertainty construction can be sensitive; EMD approximation adds computational cost [S1].

### When to Use
*   Use for sparse-view NeRF reconstruction (e.g., $N < 20$) where geometric accuracy is critical [S1].
*   Use when off-the-shelf diffusion-based depth priors (like DiffDP) are available [S1].
*   Use when standard L2 depth supervision leads to geometric inaccuracies due to prior errors [S1].

### When Not to Use
*   Do not use if only non-diffusion MDE networks are available, as the specific uncertainty measure relies on the denoising process [S1].
*   Do not use if computational resources are extremely limited, due to the overhead of Sinkhorn Divergence and mirrored image inference [S1].

## Background

### Origin
The method was introduced by A. Rau et al. in the paper "Depth-Guided NeRF Training via Earth Mover’s Distance" [S1]. It addresses the issue of NeRFs learning incorrect geometry despite good photometric reconstruction, particularly in sparse-view settings with untextured regions [S1].

### History and Development
Previous methods like DäRF supervised NeRF-rendered depth directly using L2 loss, which forced the NeRF to approximate potentially inaccurate priors [S1]. SCADE used multiple depth hypotheses but suffered from instability and noise [S1]. This method leverages the uncertainty inherent in diffusion-based depth estimation (DiffDP) to guide the *distribution* of ray termination distances using EMD, providing a more robust supervision signal [S1].

### Usage
It is used as a drop-in replacement for existing depth-supervised NeRFs, particularly on challenging indoor scenes like ScanNet and ScanNet+ [S1].
