# Progressive View Synthesis Training

Also called: PERF training loop, collaborative RGBD inpainting and progressive inpainting-and-erasing

## Overview
Progressive View Synthesis Training (PERF) is a training strategy for Panoramic Neural Radiance Fields (NeRF) that synthesizes novel views from a single input panorama by iteratively generating synthetic reference views to resolve occluded regions [S1]. Unlike standard NeRF training which optimizes on a fixed dataset, PERF progressively expands the training set by sampling new camera poses and filling their missing content via inpainting, thereby improving geometry and semantic coherence in areas not visible in the original input [S1]. It distinguishes itself from sibling methods like [Dynamic Growth Parameters](2968-dynamic-growth-parameters.md) by specifically targeting panoramic distortion and semantic consistency through a collaborative RGBD inpainting and erasing mechanism, rather than purely geometric uncertainty metrics.

## How it works
**Inputs and Outputs:**
- **Input:** A single input RGB-D panorama (color and depth maps).
- **Output:** A trained NeRF model capable of synthesizing novel panoramic views with coherent geometry and semantics in occluded regions.

**Data Structures:**
- **NeRF Representation:** Instant-NGP [S1] is used. The hash table size is $2^{19}$ with 16 levels of feature vectors, each of channel size 2 [S1].
- **Training State:** The set of reference views $\mathcal{V}$, initially containing only the input panorama. The set of learned parameters $\Phi$.

**Parameters:**
- Initial training iterations: 10,000 [S1].
- Number of progressively sampled new positions: 32 [S1].
- Training iterations per new view: 2,000 [S1].
- Supervision iterations using only the new view: 100 [S1].
- Supervision iterations using all views: 1,900 [S1].
- Initial learning rate: $10^{-3}$ [S1].
- Decayed learning rate: $10^{-4}$ [S1].
- Number of rays sampled per iteration: 2,048 [S1].
- Distortion loss weight ($\lambda_{dist}$): 1 [S1].
- Inpainting model: Pre-trained Stable Diffusion 2 [S1].

**Steps:**

1.  **Initial Training:** Train the NeRF model using only the single input panorama for 10,000 iterations [S1].
2.  **Progressive View Sampling:** Sample 32 new camera positions. These positions are distributed with gradually increased distance from the original reference panorama view position [S1].
3.  **Iterative View Addition:** For each newly sampled position $v_{new}$:
    a.  **Collaborative RGBD Inpainting:** Generate color and depth data for the new view. Since inpainting models (Stable Diffusion 2) are trained on perspective FOV and distort panoramas, masked regions in the panorama are projected to perspective views, inpainted, and then projected back to the panorama [S1].
    b.  **Progressive Inpainting-and-Erasing:** Apply this strategy to avoid geometry conflicts and redundant geometry that arise from different views [S1].
    c.  **Add to Dataset:** Add the inpainted view to the set of reference views $\mathcal{V}$ [S1].
    d.  **Supervised Training:** Continue NeRF training for 2,000 iterations [S1]:
        i.  For the first 100 iterations, use only the new reference view $v_{new}$ for supervision [S1].
        ii. For the remaining 1,900 iterations, supervise NeRF with all reference views in $\mathcal{V}$ [S1].
4.  **Optimization:** Use the Adam optimizer [S1]. For each learning stage (each new view), the learning rate starts at $10^{-3}$ and decays to $10^{-4}$ using cosine annealing [S1].
5.  **Ray Sampling:** At each iteration, randomly sample 2,048 rays. These rays are supervised using ground-truth or inpainted colors and depth values [S1].
6.  **Regularization:** Apply distortion loss with weight $\lambda_{dist} = 1$ to encourage volume densities to converge to valid surfaces, preventing "foggy effects" or "floating" densities [S1].

**Edge Cases and Pitfalls:**
- **Panoramic Distortion:** Inpainting models trained on perspective FOV cannot be directly applied to panoramas due to distortion. The method must project masked regions to perspective views, inpaint, and project back [S1].
- **Foggy Effects/Floating Densities:** NeRF can produce invalid surfaces. This is mitigated by using distortion loss with weight 1 [S1].
- **Geometry Conflicts:** Without inpainting-and-erasing, geometry conflicts arise from different views, leading to wrong redundant geometry and degraded RGB quality [S1].

## Operating characteristics
- **Time Complexity:** Training a scene takes approximately 2 hours on a single Nvidia V100 GPU with 32G memory [S1].
- **Memory Complexity:** Uses Instant-NGP hash table of size $2^{19}$ with 16 levels of feature vectors of channel size 2 [S1].
- **Performance:** On the Replica dataset, PERF achieves a PSNR of 23.49, SSIM of 0.838, and LPIPS of 0.244, outperforming DS-NeRF, DietNeRF, SinNeRF, 360FusionNeRF, and Omni-NeRF [S1]. It shows significant improvement on masked PSNR (12.63 vs. 11.73 for DS-NeRF), demonstrating better inpainting of occluded regions [S1].
- **Strengths:** Better semantic coherence in occluded regions compared to semantic regularization methods like DietNeRF and SinNeRF [S1]. Avoids the foggy artifacts of DS-NeRF [S1].
- **Limitations:** Relies on a pre-trained inpainting model (Stable Diffusion 2), which may introduce artifacts if the inpainting fails [S1]. Computationally intensive due to the iterative inpainting and training steps [S1].
- **When to use:** Single panorama novel view synthesis, 3D virtual tours, VR games/conferences, filmmaking, text-to-3D, and 3D scene stylization [S1].
- **When not to use:** When high-quality ground truth depth is not available for the initial panorama, as the method relies on RGB-D input [S1]. When computational resources are limited, as it requires significant GPU memory and time [S1].
