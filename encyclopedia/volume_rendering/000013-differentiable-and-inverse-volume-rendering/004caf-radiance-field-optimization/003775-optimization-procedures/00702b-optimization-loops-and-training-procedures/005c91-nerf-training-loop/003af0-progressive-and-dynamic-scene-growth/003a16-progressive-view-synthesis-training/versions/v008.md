# Progressive View Synthesis Training

Also called: PERF training loop, collaborative RGBD inpainting and progressive inpainting-and-erasing

## Overview
Progressive View Synthesis Training (PERF) is a training strategy for Panoramic Neural Radiance Fields (NeRF) that synthesizes novel views from a single input panorama by progressively adding reference views to improve geometry and semantic coherence in occluded regions [S1]. Unlike methods that rely on semantic regularization via CLIP or DINO features on perspective patches, PERF uses collaborative RGBD inpainting and an inpainting-and-erasing strategy to generate high-quality pseudo-ground truth for unseen areas, avoiding the "foggy effects" and redundant geometry common in other few-shot NeRF approaches [S1].

## How it works
**Inputs:** A single input RGB-D panorama.
**Outputs:** A trained NeRF model capable of synthesizing novel panoramic views.

**Data Structures:**
*   **NeRF Representation:** Instant-NGP [S1].
    *   Hash table size: $2^{19}$ [S1].
    *   Levels: 16 [S1].
    *   Feature vector channel size: 2 [S1].
*   **Inpainting Model:** Pre-trained Stable Diffusion 2 [S1].
*   **Optimizer:** Adam [S1].

**Parameters:**
*   Initial training iterations: 10,000 [S1].
*   Number of progressively sampled new positions: 32 [S1].
*   Training iterations per new view: 2,000 [S1].
*   Supervision iterations using only the new view: 100 [S1].
*   Supervision iterations using all views: 1,900 [S1].
*   Initial learning rate: $10^{-3}$ [S1].
*   Decayed learning rate: $10^{-4}$ [S1].
*   Number of rays sampled per iteration: 2,048 [S1].
*   Distortion loss weight ($\lambda_{dist}$): 1 [S1].

**Steps:**

1.  **Initial Training:** Train the NeRF model using only the single input panorama for 10,000 iterations [S1].
2.  **Progressive View Sampling:** Sample 32 new camera positions with gradually increased distance from the original reference panorama view position [S1].
3.  **Iterative View Addition:** For each newly added reference view:
    a.  **Collaborative RGBD Inpainting:** Generate color and depth values for the occluded regions of the new view.
        *   *Pitfall Handling:* Since inpainting models (Stable Diffusion 2) are trained on perspective FOV images, direct application to panoramas causes distortion [S1].
        *   *Procedure:* Project masked regions of the panorama to perspective views, perform inpainting, and project the inpainted regions back to the panorama [S1].
    b.  **Progressive Inpainting-and-Erasing:** Apply this strategy to avoid geometry conflicts from different views, which otherwise lead to wrong redundant geometry and degraded RGB quality [S1].
    c.  **NeRF Optimization:** Continue NeRF training for 2,000 iterations [S1].
        *   *Phase 1 (Iterations 1–100):* Supervise NeRF using only the new reference view [S1].
        *   *Phase 2 (Iterations 101–2000):* Supervise NeRF using all reference views (original + newly added) [S1].
        *   *Learning Rate Schedule:* For each learning stage of a newly sampled view, set the initial learning rate to $10^{-3}$ and decay to $10^{-4}$ using cosine annealing [S1].
        *   *Ray Sampling:* Randomly sample 2,048 rays per iteration using ground-truth or inpainted colors and depth values [S1].
        *   *Loss Function:* Include distortion loss with weight $\lambda_{dist} = 1$ to encourage volume densities to converge to a valid surface instead of producing "foggy effects" or "floating" densities [S1].

**Pseudocode:**

```python
def progressive_view_synthesis_training(input_panorama_rgb, input_panorama_depth):
    """
    Trains a Panoramic NeRF from a single input panorama using the PERF method.
    
    Args:
        input_panorama_rgb: RGB data of the single input panorama.
        input_panorama_depth: Depth data of the single input panorama.
        
    Returns:
        trained_nerf: The optimized NeRF model.
    """
    # Initialize Instant-NGP NeRF with hash table size 2^19, 16 levels, channel size 2
    nerf = InstantNGPNeRF(hash_table_size=2**19, levels=16, channel_size=2)
    
    # Initialize Adam optimizer
    optimizer = Adam(nerf.parameters(), lr=1e-3)
    
    # Initialize Stable Diffusion 2 for inpainting
    inpainting_model = StableDiffusion2()
    
    # List of reference views, starting with the single input
    reference_views = [input_panorama_rgb, input_panorama_depth]
    
    # Step 1: Initial Training
    for iteration in range(10000):
        rays = sample_rays(2048, reference_views[0], reference_views[1])
        rendered_color, rendered_depth, weights = nerf.forward(rays)
        gt_color, gt_depth = get_ground_truth(rays, reference_views)
        
        loss = compute_loss(rendered_color, gt_color, rendered_depth, gt_depth)
        # Add distortion loss with weight 1
        loss += 1.0 * compute_distortion_loss(weights, rays)
        
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
    # Step 2: Progressive View Sampling
    # Sample 32 new positions with gradually increased distance from original view
    new_positions = sample_positions(count=32, base_position=reference_views[0].camera_position, distance_increment="gradual")
    
    for pos in new_positions:
        # Generate new view using inpainting
        # Project masked regions to perspective, inpaint, project back
        new_rgb, new_depth = collaborative_rgbd_inpainting(
            nerf, pos, inpainting_model, reference_views
        )
        
        # Add new view to reference views
        reference_views.append((new_rgb, new_depth))
        
        # Step 3: NeRF Optimization for new view
        # Reset learning rate schedule for this stage
        current_lr = 1e-3
        optimizer.param_groups[0]['lr'] = current_lr
        
        for iteration in range(2000):
            # Cosine annealing decay from 1e-3 to 1e-4 over 2000 iterations
            current_lr = cosine_annealing(1e-3, 1e-4, iteration, 2000)
            optimizer.param_groups[0]['lr'] = current_lr
            
            rays = sample_rays(2048, reference_views)
            
            # Determine supervision source
            if iteration < 100:
                # Only use the new reference view for supervision
                gt_color, gt_depth = get_ground_truth(rays, reference_views[-1])
            else:
                # Supervise with all reference views
                gt_color, gt_depth = get_ground_truth(rays, reference_views)
                
            rendered_color, rendered_depth, weights = nerf.forward(rays)
            
            loss = compute_loss(rendered_color, gt_color, rendered_depth, gt_depth)
            # Add distortion loss with weight 1
            loss += 1.0 * compute_distortion_loss(weights, rays)
            
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            
    return nerf
```

## Operating characteristics
*   **Time Complexity:** Training a scene takes approximately 2 hours on a single Nvidia V100 GPU with 32G memory [S1].
*   **Memory Complexity:** Uses Instant-NGP hash table of size $2^{19}$ with 16 levels of feature vectors of channel size 2 [S1].
*   **Performance:** On the Replica dataset, PERF achieves the best performance in PSNR (23.49), SSIM (0.838), and LPIPS (0.244) compared to DS-NeRF, DietNeRF, SinNeRF, 360FusionNeRF, and Omni-NeRF [S1]. It shows significant improvement in masked PSNR (12.63), demonstrating effective inpainting of invisible regions [S1].
*   **User Preference:** In a user study with 29 users, ~81% preferred PERF results over DS-NeRF, SinNeRF, and DietNeRF [S1].
*   **Strengths:**
    *   Better semantic coherence in occluded regions compared to semantic regularization methods (DietNeRF, SinNeRF) [S1].
    *   Avoids "foggy effects" and "floating" densities through distortion loss and inpainting-and-erasing [S1].
    *   Outperforms Omni-NeRF, which suffers from blurred results due to lack of geometric regularization [S1].
*   **Limitations:**
    *   Relies on pre-trained inpainting models (Stable Diffusion 2), which may introduce artifacts if the inpainting is inaccurate [S1].
    *   Requires careful handling of panoramic distortion when using perspective-trained inpainting models [S1].
    *   Without inpainting-and-erasing, geometry conflicts arise from different views, leading to wrong redundant geometry and degraded RGB quality [S1].
*   **When to Use:** Single panorama novel view synthesis, 3D virtual tours, VR games/conferences, filmmaking, text-to-3D, and 3D scene stylization [S1].
*   **When Not to Use:** When high-quality multi-view input is available, as the method is designed for single-panorama scenarios [S1].

## Background
*   **Origin:** PERF was introduced in the paper "PERF: Panoramic Neural Radiance Field From a Single Panorama" [S1].
*   **History:** The method addresses the limitations of existing NeRF techniques in handling single-panorama inputs, where occluded regions are difficult to synthesize. It builds on Instant-NGP for efficient representation and integrates Stable Diffusion for semantic inpainting [S1].
*   **Usage:** Used for single panorama novel view synthesis and extended to applications like text-to-3D and 3D scene stylization [S1].
