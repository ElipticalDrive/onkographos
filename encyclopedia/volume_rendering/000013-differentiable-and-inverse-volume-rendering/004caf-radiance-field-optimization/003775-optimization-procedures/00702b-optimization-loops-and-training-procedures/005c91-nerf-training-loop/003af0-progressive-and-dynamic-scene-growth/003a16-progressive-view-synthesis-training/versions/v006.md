# Progressive View Synthesis Training

Also called: PERF training loop, collaborative RGBD inpainting and progressive inpainting-and-erasing

## Overview
Progressive View Synthesis Training (PERF) is a training strategy for Panoramic Neural Radiance Fields (NeRF) that addresses the challenge of synthesizing high-quality novel views from a single input panorama, specifically targeting occluded regions where geometric and semantic information is missing [S1]. Unlike methods that rely solely on semantic regularization or pseudo-ground truth generation, PERF iteratively expands the training set by progressively sampling new camera positions and filling missing data via collaborative RGBD inpainting, thereby improving geometry and semantic coherence in unseen areas [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A single input RGB-D panorama.
*   **Output:** A trained NeRF model capable of synthesizing novel views from arbitrary panoramic poses.

**Data Structures:**
*   **NeRF Representation:** Instant-NGP [S1].
    *   **Hash Table:** Size $2^{19}$ [S1].
    *   **Levels:** 16 levels of feature vectors [S1].
    *   **Channel Size:** 2 per feature vector [S1].
*   **Ray Sampling:** 2048 rays sampled per iteration [S1].
*   **Supervision Data:** Ground-truth or inpainted colors and depth values [S1].

**Algorithm Steps:**

1.  **Initial Training:** Train the NeRF model using only the single input panorama for 10,000 iterations [S1].
2.  **Progressive View Sampling:** Sample 32 new camera positions. These positions are distributed with gradually increased distance from the original reference panorama view position [S1].
3.  **Iterative Expansion Loop:** For each of the 32 newly sampled positions, perform the following sub-steps:
    a.  **Collaborative RGBD Inpainting:**
        *   Identify masked regions in the target view corresponding to occlusions or unobserved areas.
        *   **Projection:** Project the masked regions from the panoramic coordinate system to perspective views to avoid distortion artifacts inherent in applying perspective-trained inpainting models directly to panoramas [S1].
        *   **Inpainting:** Apply a pre-trained Stable Diffusion 2 model to inpaint the perspective views [S1].
        *   **Back-Projection:** Project the inpainted regions back to the panoramic coordinate system [S1].
    b.  **Progressive Inpainting-and-Erasing:** This strategy prevents geometry conflicts arising from different views, which otherwise lead to wrong redundant geometry and degraded RGB quality [S1]. (Specific algorithmic details of the erasing mechanism are not provided in the source text, but it is applied after inpainting [S1]).
    c.  **NeRF Re-optimization:** Continue training the NeRF for 2,000 iterations using the Adam optimizer [S1].
        *   **Learning Rate Schedule:** For each learning stage (new view), the learning rate starts at $10^{-3}$ and decays to $10^{-4}$ using cosine annealing [S1].
        *   **Supervision Strategy:**
            *   First 100 iterations: Supervise using *only* the new reference view [S1].
            *   Remaining 1,900 iterations: Supervise using *all* accumulated reference views (original + previously added) [S1].
        *   **Ray Sampling:** Randomly sample 2048 rays per iteration. Use ground-truth or inpainted colors and depth values for supervision [S1].
4.  **Regularization:** Apply distortion loss with weight $\lambda_{dist} = 1$ throughout training to encourage volume densities to converge to a valid surface, preventing "foggy effects" or "floating" densities [S1].

def train_nef(nerf_model, optimizer, views, num_iterations):
    """
    Standard NeRF training loop [S1].
    """
    for iteration in range(num_iterations):
        # Randomly sample 2048 rays [S1]
        rays = sample_rays(views, num_rays=NUM_RAYS_PER_ITERATION)
        
        # Render colors and depths
        rendered_colors, rendered_depths = render_rays(nerf_model, rays)
        
        # Get ground truth or inpainted colors/depths for these rays
        gt_colors, gt_depths = get_supervision_data(rays, views)
        
        # Compute loss
        color_loss = compute_color_loss(rendered_colors, gt_colors)
        depth_loss = compute_depth_loss(rendered_depths, gt_depths)
        
        # Distortion loss to prevent foggy effects [S1]
        distortion_loss = compute_distortion_loss(nerf_model, rays)
        
        total_loss = color_loss + depth_loss + LAMBDA_DIST * distortion_loss
        
        # Backpropagate
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()
        
        # Update learning rate (cosine annealing) [S1]
        update_lr_schedule(optimizer, INITIAL_LR, FINAL_LR, iteration, num_iterations)

def train_nef_with_single_view(nerf_model, optimizer, new_view, num_iterations):
    """
    Supervise NeRF with only the new reference view for the first 100 iterations [S1].
    """
    train_nef(nerf_model, optimizer, [new_view], num_iterations)

def train_nef_with_all_views(nerf_model, optimizer, all_views, num_iterations):
    """
    Supervise NeRF with all accumulated reference views for the remaining 1900 iterations [S1].
    """
    train_nef(nerf_model, optimizer, all_views, num_iterations)

**Parameters:**
*   **Initial Training Iterations:** 10,000 [S1].
*   **Number of New Views:** 32 [S1].
*   **Iterations per New View:** 2,000 [S1].
*   **Supervision Split:** 100 iterations on new view only, 1,900 iterations on all views [S1].
*   **Learning Rate:** Initial $10^{-3}$, decaying to $10^{-4}$ via cosine annealing per new view stage [S1].
*   **Rays per Iteration:** 2,048 [S1].
*   **Distortion Loss Weight ($\lambda_{dist}$):** 1 [S1].
*   **Inpainting Model:** Pre-trained Stable Diffusion 2 [S1].
*   **Framework:** NeRFAcc implementing Instant-NGP [S1].

**Edge Cases and Pitfalls:**
*   **Panoramic Distortion:** Inpainting models trained on perspective FOV cannot be directly applied to panoramas due to distortion. The method mitigates this by projecting masked regions to perspective views, inpainting, and projecting back [S1].
*   **Foggy Effects/Floating Densities:** NeRF may produce invalid surfaces or foggy artifacts in occluded regions. This is mitigated by using distortion loss with weight 1 to encourage convergence to valid surfaces [S1].
*   **Geometry Conflicts:** Without the inpainting-and-erasing strategy, geometry conflicts from different views lead to redundant geometry and degraded RGB quality [S1].

## Operating characteristics
*   **Time Complexity:** Training a scene takes approximately 2 hours on a single Nvidia V100 GPU with 32G memory [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** On the Replica dataset, PERF achieves the best performance among compared methods (DS-NeRF, DietNeRF, SinNeRF, 360FusionNeRF, Omni-NeRF) across PSNR, SSIM, and LPIPS metrics [S1]. Specifically, it shows significant improvement in masked PSNR, indicating better inpainting of invisible regions [S1].
*   **User Preference:** In a user study with 29 users, ~81% preferred PERF results over DS-NeRF, SinNeRF, and DietNeRF [S1].
*   **Strengths:** Better semantic coherence in occluded regions compared to semantic regularization methods (DietNeRF, SinNeRF) and better geometric quality compared to pseudo-ground truth methods (Omni-NeRF) [S1].
*   **Limitations:** Relies on the quality of the pre-trained inpainting model (Stable Diffusion 2) and the projection strategy [S1].

## Background
*   **Origin:** Proposed in "PERF: Panoramic Neural Radiance Field From a Single Panorama" [S1].
*   **History:** The method addresses limitations of existing few-shot NeRF techniques and single panorama view synthesis works, which often fail to synthesize occluded regions well or suffer from semantic incoherence [S1].
*   **Usage:** Designed for single panorama novel view synthesis, with extensions to 3D virtual tours, VR games/conferences, filmmaking, text-to-3D, and 3D scene stylization [S1].
