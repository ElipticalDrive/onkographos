# Global-Local Contrastive Learning

Also called: Global-Local Contrastive Loss Strategy, Glocal Contrastive Loss

## Overview
Global-Local Contrastive Learning is a regularization strategy for text-driven NeRF stylization that controls stylization strength by combining global and local contrastive terms in CLIP space [S1]. It ensures uniform stylization across the entire scene, overcoming the directional-only limitation of standard CLIP losses and the non-uniformity of global-only approaches [S1]. It builds on [CLIP Direction Consistency](12264-clip-direction-consistency.md) by adding magnitude control and local balance [S1].

## How it works
**Inputs:** Rendered image $I_{tgt}$, target text prompt $t_{tgt}$, set of negative text prompts $\mathcal{T}_{neg}$, patch size $p$ [S1].
**Outputs:** Scalar loss value $\mathcal{L}_{glocal}$ [S1].

**Data Structures:**
- $E_{img}(\cdot)$: CLIP image encoder [S1].
- $E_{text}(\cdot)$: CLIP text encoder [S1].
- $\mathcal{P}$: Set of non-overlapping patches extracted from $I_{tgt}$, each of size $p \times p$ [S1].

**Steps:**
1. **Global Contrastive Loss ($\mathcal{L}_{gc}$):**
   - Compute global image embedding: $v = E_{img}(I_{tgt})$ [S1].
   - Compute target text embedding: $v^+ = E_{text}(t_{tgt})$ [S1].
   - Sample $N$ negative text prompts from $\mathcal{T}_{neg}$ and compute their embeddings: $v^-_i = E_{text}(t^-_i)$ for $i=1 \dots N$ [S1].
   - Calculate $\mathcal{L}_{gc}$ using the InfoNCE-like formula:
     $$ \mathcal{L}_{gc} = -\log \frac{\exp(v \cdot v^+ / \tau)}{\exp(v \cdot v^+ / \tau) + \sum_{i=1}^{N} \exp(v \cdot v^-_i / \tau)} $$
     where $\cdot$ denotes dot product and $\tau$ is the temperature parameter [S1].
2. **Local Contrastive Loss ($\mathcal{L}_{lc}$):**
   - Extract patches $\{P_j\}$ from $I_{tgt}$ using patch size $p$ [S1].
   - For each patch $P_j$:
     - Compute patch embedding: $v_j = E_{img}(P_j)$ [S1].
     - Compute target text embedding: $v^+ = E_{text}(t_{tgt})$ [S1].
     - Use the same negative text embeddings $v^-_i$ as in the global loss [S1].
     - Compute local loss for patch $j$:
       $$ \mathcal{L}_{lc}^{(j)} = -\log \frac{\exp(v_j \cdot v^+ / \tau)}{\exp(v_j \cdot v^+ / \tau) + \sum_{i=1}^{N} \exp(v_j \cdot v^-_i / \tau)} $$
       [S1].
   - Aggregate local loss: $\mathcal{L}_{lc} = \frac{1}{|\mathcal{P}|} \sum_{j} \mathcal{L}_{lc}^{(j)}$ [S1].
3. **Combine:**
   - Total loss: $\mathcal{L}_{glocal} = \mathcal{L}_{gc} + \lambda \mathcal{L}_{lc}$, where $\lambda$ is a weighting factor [S1].

**Parameters:**
- Temperature $\tau = 0.07$ [S1].
- Patch size $p = \frac{1}{10} \times \text{original image dimension}$ (both width and height) [S1].
- Number of negative samples $N \approx 200$ (collected from external sources like Pinterest) [S1].

**Edge Cases and Pitfalls:**
- **Global-only failure:** Using only $\mathcal{L}_{gc}$ leads to excessive stylization on parts with distinguishable features and insufficient stylization elsewhere, as CLIP focuses on local distinct features [S1].
- **Local-only failure:** Using only $\mathcal{L}_{lc}$ may produce hallucinated attributes (e.g., extra eyes or ears) because local patches lack sufficient semantic context [S1].

## Subtopics

### [View-invariant Contrastive Loss](17051-view-invariant-contrastive-loss.md)
Regularizes latent codes for 3D content invariance across viewpoints, building on this method by targeting latent representation stability rather than just stylization uniformity.

## Operating characteristics
- **Time Complexity:** $O(N \cdot |\mathcal{P}|)$ per iteration, where $N$ is the number of negative samples and $|\mathcal{P}|$ is the number of patches [G]. High due to multiple forward passes through CLIP encoders [S1].
- **Memory Complexity:** Stores embeddings for $N$ negatives and all patches [G].
- **Strengths:** Ensures uniform stylization magnitude and distribution across the scene [S1].
- **Limitations:** Computationally expensive due to multiple CLIP evaluations [S1].
- **When to use:** Text-driven NeRF stylization requiring uniform style application [S1].
- **When not to use:** Not given in the sources.

## Background
Originated in "NeRF-Art: Text-Driven Neural Radiance Fields Stylization" (2023) [S1]. Developed to address limitations of directional CLIP losses in preserving stylization strength and uniformity [S1]. Inspired by PatchNCE loss [Park et al. 2020] for local attention [S1].
