# CLIP Distillation for Semantic NeRFs
Also called: Kobayashi et al. (CLIP Distillation)

## Overview
A method that distills knowledge from an off-the-shelf 2D feature extractor (CLIP-based) into 3D feature fields, optimized in conjunction with in-scene radiance fields to produce a NeRF model with semantic understanding [S1]. It sets itself apart from standard photometric NeRFs by enabling zero-shot segmentation from an open set of text labels or queries, and from direct supervision methods by using image features as a teacher signal rather than ground-truth labels [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Input images with known camera poses, an off-the-shelf CLIP-based 2D feature extractor, and a set of text queries or labels for segmentation [S1].
*   **Outputs:** A NeRF model that outputs color and semantic feature vectors for any 3D point and viewing direction [S1].

**Data Structures:**
*   **3D Feature Field:** A continuous function mapping 3D coordinates and viewing directions to semantic feature vectors [S1]. The specific network architecture and feature dimensionality are not given in the sources [S1].
*   **Teacher Features:** 2D semantic features extracted from input images using the CLIP-based feature extractor [S1].

**Steps:**
1.  **Initialize Fields:** Initialize the standard radiance field and the 3D feature field [S1].
2.  **Render Features:** For each training view, sample points along camera rays and query the 3D feature field to obtain per-point semantic features [S1].
3.  **Aggregate Features:** Aggregate the per-point features along each ray using standard volume rendering to produce a rendered 2D feature map [G].
4.  **Extract Teacher Features:** Extract corresponding 2D features from the input images using the off-the-shelf CLIP-based feature extractor [S1].
5.  **Compute Distillation Loss:** Calculate the distillation loss between the rendered 3D features and the extracted 2D teacher features [S1]. The exact loss function formulation is not given in the sources [S1].
6.  **Optimize:** Update the radiance field and feature field parameters jointly to minimize the distillation loss alongside standard photometric losses [S1].
7.  **Inference:** Render semantic feature maps for novel views and perform zero-shot segmentation by comparing the rendered features to text embeddings from the CLIP text encoder [S1].

**Formulas:** Not given in the sources [S1].

**Parameters:**
*   Learning rate: Not given in the sources [S1].
*   Feature dimension: Not given in the sources [S1].

**Edge Cases and Pitfalls:**
*   **Teacher Signal Source:** The method relies on features extracted from input training images as the teacher signal [S1]. The source does not specify a fallback mechanism if novel views are unavailable during training [S1].
*   **Precision:** Not given in the sources [S1].

## Subtopics

### [2D Semantic Distillation Loss](15121-2d-semantic-distillation-loss.md)
The 2D Semantic Distillation Loss is a regularization term used in semantic-aware NeRF training to enhance the discrimination and semantic consistency of rendered features. It addresses the problem of weak semantic understanding in standard radiance fields by distilling knowledge from an off-the-shelf 2D feature extractor (specifically CLIP-based features from novel views) into the 3D feature field. It sets itself apart from standard color losses by operating in the semantic feature space rather than RGB space, and from direct supervision by using novel-view features as a teacher signal rather than ground-truth labels. It builds on [CLIP Distillation for Semantic NeRFs](11968-clip-distillation-for-semantic-nerfs.md).

## Background
Originated by Kobayashi et al. in May 2022 [S1]. The work demonstrated that distilling CLIP-based features into 3D fields allows for semantic segmentation synthesis, instance segmentation synthesis, and scene editing [S1]. It is part of the broader effort to add semantic capabilities to NeRFs, following related works like SS-NeRF (June 2022) which employed separate encoding and decoding MLPs for semantics [S1].
