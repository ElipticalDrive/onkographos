# RegNeRF

Also called: Regularized NeRF

## Overview
RegNeRF synthesizes novel views from sparse input images by applying depth smoothness and color priors to constrain unobserved regions of the scene [S1]. It employs generative priors via Normalizing Flows and geometric smoothness constraints without requiring pretraining on the target dataset [S1].

## How it works
RegNeRF operates within the differentiable volume rendering framework [S1, 8582-regnerf.md]. It uses Mip-NeRF as the backbone neural radiance field [S1]. The method introduces three key components: sampled space annealing, depth smoothness regularization, and color regularization via Normalizing Flows [S1].

### Inputs and Outputs
*   **Inputs:** A sparse set of $N$ input images with known camera poses [S1].
*   **Outputs:** A trained NeRF model (density $\sigma$ and color $\mathbf{c}$ fields) capable of rendering novel views [S1].

### Data Structures
*   **Patches:** The method operates on image patches of size $S_{patch} \times S_{patch}$ rather than single pixels or full images [S1]. A patch $P_{\mathbf{r}}$ is centered at pixel $\mathbf{r}$ [S1].
*   **Normalizing Flow Model:** A learned bijection $\phi$ mapping patches to $\mathbb{R}^d$ where $d = S_{patch} \cdot S_{patch} \cdot 3$, trained on a large unposed dataset (e.g., JFT-300M) [S1].

### Algorithm Steps

1.  **Sampled Space Annealing:**
    At the start of training, to prevent divergent NeRF modes with high density at the ray origin, the range of sample points along each ray is limited to a small volume defined by the bounding box of all input images. This volume is gradually extended to cover the full scene as training progresses [S1].

2.  **Random View Sampling:**
    For each training step, randomly sample unobserved viewpoints (camera poses) that are not in the input set [S1]. Render patches from these viewpoints using the current NeRF model [S1].

3.  **Depth Smoothness Loss ($\mathcal{L}_{ds}$):**
    Compute the expected depth $\hat{D}(\mathbf{r})$ for rays passing through the rendered patches [S1]. The smoothness loss encourages the world geometry to be piecewise smooth by penalizing depth differences between adjacent pixels in the patch [S1]:
    $$ \mathcal{L}_{ds} = \sum_{\mathbf{r}} \sum_{i=0}^{S_{patch}-2} \sum_{j=0}^{S_{patch}-2} \left( (d(\mathbf{r}_{i,j}) - d(\mathbf{r}_{i+1,j}))^2 + (d(\mathbf{r}_{i,j}) - d(\mathbf{r}_{i,j+1}))^2 \right) $$
    where $d(\mathbf{r}_{i,j})$ is the expected depth of the ray through pixel $(i,j)$ of a patch of size $S_{patch}$ from a randomly sampled unobserved viewpoint [S1].

4.  **Color Regularization Loss ($\mathcal{L}_{NLL}$):**
    Estimate the likelihood of the rendered color patches using a Normalizing Flow model [S1]. The flow model $\phi$ maps the predicted RGB patch $P_{\mathbf{r}}$ (centered at $\mathbf{r}$) to a latent space where the distribution is assumed to be Gaussian $p_z$ [S1]. The loss is the negative log-likelihood:
    $$ \mathcal{L}_{NLL} = - \sum_{\mathbf{r}} \log p_z(\phi(P_{\mathbf{r}})) $$
    where $p_z$ is a Gaussian distribution [S1].

5.  **Optimization:**
    Minimize the total loss combining $\mathcal{L}_{ds}$ and $\mathcal{L}_{NLL}$ with respect to the NeRF parameters using gradient descent [S1].

### Pseudocode

```python
def train_regnerf(input_images, input_poses, flow_model, num_epochs):
    # Backbone NeRF (Mip-NeRF variant) [S1]
    nerf = NeRF()
    optimizer = Optimizer(nerf.parameters())  # [G] standard gradient descent optimizer

    # Annealing bounds [S1]
    min_volume = compute_bounding_box(input_poses)
    max_volume = compute_scene_extent(input_poses)

    for epoch in range(num_epochs):
        # 1. Sampled space annealing: gradually expand sample range [S1]
        progress = epoch / num_epochs
        current_min = lerp(min_volume, max_volume, progress)
        current_max = max_volume

        for batch in input_images:
            optimizer.zero_grad()

            # 2. Render input views for reconstruction
            colors_input = render(nerf, batch.poses, current_min, current_max)
            loss_recon = mean_squared_error(colors_input, batch.images)

            # 3. Sample random unobserved viewpoints [S1]
            random_poses = sample_random_poses(num_views=1)

            # 4. Render patches from unobserved views [S1]
            colors_random = render(nerf, random_poses, current_min, current_max)
            depths_random = render_depth(nerf, random_poses, current_min, current_max)

            # Extract patches of size S_patch x S_patch [S1]
            patches_color = extract_patches(colors_random, S_patch)
            patches_depth = extract_patches(depths_random, S_patch)

            # 5. Depth smoothness loss [S1]
            loss_ds = 0.0
            for d_patch in patches_depth:
                diff_x = d_patch[:, 1:, :] - d_patch[:, :-1, :]
                diff_y = d_patch[:, :, 1:] - d_patch[:, :, :-1]
                loss_ds += mean_squared_error(diff_x, 0.0) + mean_squared_error(diff_y, 0.0)

            # 6. Color regularization loss [S1]
            loss_nll = 0.0
            for c_patch in patches_color:
                latent = flow_model.encode(c_patch)
                loss_nll += negative_log_likelihood_gaussian(latent)

            # 7. Total loss and update
            total_loss = loss_recon + lambda_ds * loss_ds + lambda_nll * loss_nll
            total_loss.backward()
            optimizer.step()

# Helper definitions
def compute_bounding_box(poses): return min(poses.origin)
def compute_scene_extent(poses): return max(poses.origin)
def lerp(a, b, t): return a + (b - a) * t
def render(nerf, poses, min_t, max_t): return [nerf.sample(p, min_t, max_t) for p in poses]
def render_depth(nerf, poses, min_t, max_t): return [nerf.expected_depth(p, min_t, max_t) for p in poses]
def extract_patches(tensor, size): return tensor.unfold(1, size, 1).unfold(2, size, 1).permute(0, 2, 3, 1, 4).reshape(-1, size, size, 3)
def mean_squared_error(pred, target): return torch.mean((pred - target) ** 2)
def negative_log_likelihood_gaussian(latent): return 0.5 * torch.sum(latent ** 2) + 0.5 * latent.shape[0] * math.log(2 * math.pi)
def sample_random_poses(num_views): return generate_random_cameras(num_views)
```

### Parameters
*   $S_{patch}$: Patch size. Not given in the sources.
*   $\lambda_{ds}$: Weight for depth smoothness loss. Not given in the sources.
*   $\lambda_{NLL}$: Weight for color regularization loss. Not given in the sources.
*   Backbone: Mip-NeRF [S1].

### Edge Cases and Pitfalls
*   **Divergent Modes:** Without sampled space annealing, the NeRF may converge to modes with high density at the ray origin, failing to reconstruct the scene geometry [S1].
*   **Sparse Views:** The method is specifically designed for sparse input views; performance on dense views may be suboptimal compared to standard NeRF due to the overhead of regularization [S1].
*   **Flow Model Training:** The color regularization relies on a Normalizing Flow model trained on a varied unposed dataset [S1]. If the flow model is not well-calibrated for the domain, the regularization may introduce artifacts [S1].

## Subtopics

### DiffNeRF
DiffNeRF is a regularization framework for Neural Radiance Fields (NeRF) that uses differential geometry to improve robustness when training with sparse or inconsistent data [S1]. It addresses MLP overfitting and unrealistic interpolation in few-shot scenarios by modifying the NeRF to represent continuous, infinitely differentiable functions [S1].

### SS-NeRF
SS-NeRF employs an encoding function and two position decoding functions (one direction-dependent, one direction-independent) represented by MLPs to produce various scene properties [S1]. It trains the network to produce color, semantic labels, surface normal, shading, keypoints, and edges [S1]. It uses a combination of losses: MSE for color and surface normals; MAE for shading, keypoints and edges; and cross-entropy for semantic labels [S1].

## Operating characteristics
*   **Time Complexity:** Training time is increased due to the additional loss computations (depth smoothness and flow likelihood) and the need to render from random unobserved viewpoints at each step [S1].
*   **Memory Complexity:** Requires storing the NeRF model and the Normalizing Flow model parameters [S1].
*   **Performance:** RegNeRF outperforms models such as PixelNeRF, SRF, and MVSNeRF under sparse view conditions on DTU and LLFF datasets [S1]. It achieves comparable performance to models that require pretraining on DTU and fine-tuning per scene, without needing such pretraining [S1].
*   **Strengths:** Does not require pretraining on the target dataset; effective for sparse view synthesis; improves geometric smoothness and color consistency in unobserved regions [S1].
*   **Limitations:** Relies on the quality of the Normalizing Flow model trained on external unposed data [S1].

## Background
RegNeRF was proposed in December 2021 [S1]. It aimed to solve the problem of NeRF training with sparse input views by employing additional depth and color regularization, without requiring pretraining [S1]. It was tested on DTU and LLFF datasets [S1]. The method builds on the Mip-NeRF backbone [48] [S1].
