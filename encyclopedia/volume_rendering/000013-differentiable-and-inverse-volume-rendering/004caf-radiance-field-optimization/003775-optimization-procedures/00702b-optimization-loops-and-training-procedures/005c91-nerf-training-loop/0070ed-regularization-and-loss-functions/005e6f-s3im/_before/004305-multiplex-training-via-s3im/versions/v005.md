# Multiplex Training via S3IM

Also called: S3IM Training, Stochastic Structural SIMilarity Training

## Overview
Multiplex Training via S3IM is a training paradigm that combines a conventional pixel-wise loss (e.g., L1 or MSE) with a Stochastic Structural SIMilarity (S3IM) loss to improve neural field reconstruction quality, particularly for complex details and sparse inputs [S1]. It sets itself apart from standard SSIM optimization by using stochastic patch generation to capture non-local structural information from distant pixels across different images, whereas standard SSIM via local patches only captures structural information from nearby pixels within a single image [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A dataset of rays $\mathcal{D}$, a neural field model with parameters $\Theta$ (density $\sigma$ and color $\mathbf{c}$), hyperparameters $M$ (number of stochastic patches), $K$ (kernel size), $s$ (stride), and $\lambda$ (loss weight).
*   **Outputs:** Updated model parameters $\Theta$.

**Data Structures:**
*   $\mathcal{R}$: A minibatch of rays sampled from $\mathcal{D}$.
*   $\mathcal{C}$: Ground-truth pixel colors corresponding to $\mathcal{R}$.
*   $\hat{\mathcal{C}}$: Rendered pixel colors corresponding to $\mathcal{R}$.
*   $\Patch^{(m)}(\cdot)$: A function that generates the $m$-th stochastic patch from a set of pixels.

**Numbered Steps:**
1.  Sample a data minibatch of rays $\mathcal{R}$ from the dataset $\mathcal{D}$.
2.  Obtain the ground-truth pixels $\mathcal{C} = \{ \mathbf{C}(\mathbf{r}) | \mathbf{r} \in \mathcal{R} \}$.
3.  Compute the rendered pixels $\hat{\mathcal{C}} = \{ \hat{\mathbf{C}}(\mathbf{r}) | \mathbf{r} \in \mathcal{R} \}$ using the current model parameters $\Theta$.
4.  Initialize the total loss $L_M(\Theta) = 0$.
5.  Loop $m$ from 1 to $M$:
    a. Initialize the stochastic patch generation function $\Patch^{(m)}$.
    b. Transform rendered pixels into the rendered stochastic patch $\hat{\mathcal{P}}^{(m)} = \Patch^{(m)}(\hat{\mathcal{C}})$.
    c. Transform ground-truth pixels into the ground-truth stochastic patch $\mathcal{P}^{(m)} = \Patch^{(m)}(\mathcal{C})$.
    d. Compute the SSIM between $\hat{\mathcal{P}}^{(m)}$ and $\mathcal{P}^{(m)}$ using kernel size $K \times K$ and stride $s$.
6.  Calculate the average S3IM score: $\SSSIM(\hat{\mathcal{C}}, \mathcal{C}) = \frac{1}{M} \sum_{m=1}^{M} \SSIM(\hat{\mathcal{P}}^{(m)}, \mathcal{P}^{(m)})$.
7.  Calculate the S3IM loss: $L_{\SSSIM}(\Theta) = 1 - \SSSIM(\hat{\mathcal{C}}, \mathcal{C})$.
8.  Calculate the conventional color loss $L_{\mathrm{color}}(\Theta)$. For general neural fields, this is typically the L1 loss: $L_{\mathrm{color}} = \frac{1}{\|\mathcal{R}\|} \sum_{\mathbf{r} \in \mathcal{R}} \| \hat{\mathbf{C}}(\mathbf{r}) - \mathbf{C}(\mathbf{r}) \|_{1}$ [S1].
9.  Calculate the total multiplex loss: $L_M(\Theta) = L_{\mathrm{color}}(\Theta) + \lambda L_{\SSSIM}(\Theta)$.
10. Compute the gradient $\nabla L_M(\Theta)$.
11. Update model parameters $\Theta$ using an SGD-like algorithm $A$.

**Formulas:**
The S3IM loss is defined as [S1]:
$$ L_{\SSSIM}(\Theta, \mathcal{R}) = 1 - \SSSIM(\hat{\mathcal{R}}, \mathcal{R}) = 1 - \frac{1}{M} \sum_{m=1}^{M} \SSIM(\Patch^{(m)}(\hat{\mathcal{C}}), \Patch^{(m)}(\mathcal{C})) $$
where $\SSSIM$ is the average SSIM over $M$ stochastic patches, $\hat{\mathcal{C}}$ are rendered pixels, $\mathcal{C}$ are ground-truth pixels, and $\Patch^{(m)}$ generates the $m$-th stochastic patch.

For neural surface representations like NeuS, the color loss is replaced by the multiplex color loss [S1]:
$$ L_{\mathrm{M},\mathrm{color}} = L_{\mathrm{color}} + \lambda L_{\SSSIM} $$
where the base color loss uses the L1 form:
$$ L_{\mathrm{color}} = \frac{1}{\|\mathcal{R}\|} \sum_{\mathbf{r} \in \mathcal{R}} \| \hat{\mathbf{C}}(\mathbf{r}) - \mathbf{C}(\mathbf{r}) \|_{1} $$

**Parameters:**
*   $M$: The number of stochastic patches. Default value is 10 to reduce stochasticity, but $M=1$ produces nearly the same good results. Approaching $+\infty$ eliminates stochasticity [S1].
*   $K$: Kernel size for SSIM calculation. Default setting is $K=4$ [S1].
*   $s$: Stride size for SSIM calculation. Default setting is $s=K$ (i.e., stride equals kernel size) [S1].
*   $\lambda$: The weight for the S3IM loss term. Requires fine-tuning in practice [S1].

**Pitfalls:**
*   Directly optimizing standard SSIM may not work well. Using an additional local-patch dataloader for standard SSIM increases coding and computational costs and hurts NeRF performance [S1].
*   S3IM lies in $[-1, 1]$ and is positively correlated with image quality, so the loss is defined as $1 - \SSSIM$ to ensure minimization [S1].

    # 3. Compute conventional color loss (L1)
    # L_color = mean(|rendered_colors - ground_truth_colors|)
    color_loss = torch.mean(torch.abs(rendered_colors - ground_truth_colors))
    
    # 4. Compute S3IM loss
    ssim_sum = 0.0
    for m in range(M):
        # Initialize stochastic patch generation
        # This function randomly selects patches or transforms pixels to create stochastic patches
        # The exact implementation of P^(m) is not specified beyond "stochastic patch generation"
        # We assume it returns patches of size KxK with stride s
        rendered_patches = generate_stochastic_patches(rendered_colors, K, s, seed=m)
        gt_patches = generate_stochastic_patches(ground_truth_colors, K, s, seed=m)
        
        # Compute SSIM for this batch of patches
        # SSIM function typically computes structural similarity index
        # We assume ssim_function returns the mean SSIM over the patches
        current_ssim = ssim_function(rendered_patches, gt_patches, K, s)
        ssim_sum += current_ssim
        
    # Average S3IM score
    s3im_score = ssim_sum / M
    
    # S3IM loss
    s3im_loss = 1.0 - s3im_score

    optimizer.zero_grad()
    total_loss.backward()
    optimizer.step()
    
    return model

## Subtopics

### S3IM (Stochastic Structural SIMilarity)
The core loss component that uses stochastic patching to capture non-local structural information. It differs from standard SSIM by avoiding local-patch dataloaders and capturing cross-image structural dependencies.(10895-s3im-stochastic-structural-similarity.md)

## Operating characteristics
*   **Time and Memory Complexity**: The extra computational cost is limited because S3IM requires only one backpropagation per iteration, similar to standard training [S1]. The complexity scales linearly with $M$, the number of stochastic patches.
*   **Measured Performance**:
    *   On the Replica Dataset with DVGO: Mean PSNR improved from 17.07 to 33.50, SSIM from 0.696 to 0.955, and LPIPS from 0.510 to 0.0637 [S1].
    *   On the Replica Dataset with TensoRF: Mean PSNR improved from 14.30 to 39.05, SSIM from 0.574 to 0.971, and LPIPS from 0.689 to 0.0454 [S1].
    *   On the T&T Dataset with DVGO: Mean PSNR improved from 22.42 to 23.20, SSIM from 0.776 to 0.809, and LPIPS from 0.236 to 0.176 [S1].
    *   With only 20% of training images (Sparse Truck scene): PSNR improved by up to 4.32 compared to standard training [S1].
    *   On dynamic scene 'Lego' with D-NeRF: PSNR improved from 21.29 to 23.36, SSIM from 0.821 to 0.900, and LPIPS from 0.0634 to 0.0482 [S1].
*   **Scaling**: Improvements are more significant with sparser inputs (e.g., 20% of training images) [S1].
*   **Strengths**: Improves RGB image quality metrics and geometric quality metrics (e.g., Chamfer Distance) significantly. It is robust to image corruption and noise [S1].
*   **Limitations**: Requires fine-tuning of the hyperparameter $\lambda$ [S1].
*   **When to use**: When training neural fields (NeRF, DVGO, TensoRF, D-NeRF, NeuS) with sparse inputs or noisy/corrupted images, or when standard pixel-wise losses fail to capture complex structural details [S1].

## Background
Multiplex Training via S3IM was introduced in the paper "S3IM: Stochastic Structural SIMilarity and Its Unreasonable Effectiveness for Neural Fields" [S1]. It is model-agnostic and orthogonal to existing point-wise training paradigms and NeRF variants [S1]. It has been applied to NeRF, DVGO, TensoRF, D-NeRF, and NeuS [S1].
