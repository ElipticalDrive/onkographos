# Robust Depth Loss

Also called: Huber-like depth loss, robust geometry loss

## Overview
Robust Depth Loss is a regularization term designed to supervise Neural Radiance Field (NeRF) optimization using dense but potentially inaccurate pseudo-depth maps [S1]. It addresses the degradation of extrapolation performance caused by geometry errors in pseudo-labels by being less sensitive to outliers than standard L2 loss [S1]. Unlike strict geometric constraints, it encourages rays to terminate near the pseudo-depth while retaining freedom for inaccurate geometry by allowing gradients to vanish for large errors [S1]. It differs from [Geometric Baseline Regularization](7475-geometric-baseline-regularization.md) by specifically targeting the robustness of depth supervision against noise and outliers rather than enforcing smoothness or baseline consistency.

## How it works
**Inputs and Outputs**
*   **Input:** The expected depth value along the camera axis of a ray $\mathbf{r}$, denoted $\hat{D}(\mathbf{r})$, and the ground truth or scaffold depth value $D(\mathbf{r})$ [S1].
*   **Output:** A scalar loss value $\mathcal{L}_{\text{robust}}(\mathbf{r})$ [S1].

**Data Structures**
No specific data structures are required beyond scalar values for depth and the threshold parameter.

**Parameters**
*   $\beta$: A constant threshold controlling the transition between quadratic and logarithmic behavior. Set to $0.1$ in experiments [S1].

**Formula**
The loss is defined as a piecewise function based on the absolute depth difference $\Delta D(\mathbf{r})$:

$$ \Delta D(\mathbf{r}) = | \hat{D}(\mathbf{r}) - D(\mathbf{r}) | $$

$$ \mathcal {L}_{\text {robust}}(\mathbf {r}) = \begin {cases} 0.5\Delta {D}(\mathbf {r})^{2}, &\text {if } \Delta {D}(\mathbf {r}) < \beta \\ \beta ^ {2} \left(0.5 + \log \left(\frac {\Delta {D}(\mathbf {r})}{\beta }\right)\right), &\text {otherwise } \end {cases} $$

**Steps**
1.  Compute the absolute difference between the predicted/expected depth $\hat{D}(\mathbf{r})$ and the reference depth $D(\mathbf{r})$ to obtain $\Delta D(\mathbf{r})$ [S1].
2.  Compare $\Delta D(\mathbf{r})$ with the threshold $\beta$ [S1].
3.  If $\Delta D(\mathbf{r}) < \beta$, compute the loss as half the square of the difference: $0.5 \cdot \Delta D(\mathbf{r})^2$ [S1].
4.  If $\Delta D(\mathbf{r}) \ge \beta$, compute the loss as $\beta^2 (0.5 + \log(\Delta D(\mathbf{r}) / \beta))$ [S1].

**Pseudocode**
```python
def robust_depth_loss(expected_depth, reference_depth, beta=0.1):
    """
    Computes the robust depth loss for a single ray.
    
    Args:
        expected_depth (float): The depth expectation along the camera axis, D_hat(r).
        reference_depth (float): The reference depth value, D(r).
        beta (float): The threshold constant, default 0.1.
        
    Returns:
        float: The computed loss value.
    """
    # Compute absolute depth difference
    delta_d = abs(expected_depth - reference_depth)
    
    if delta_d < beta:
        # Quadratic region for small errors
        loss = 0.5 * (delta_d ** 2)
    else:
        # Logarithmic region for large errors (outliers)
        # Note: log is natural logarithm
        loss = (beta ** 2) * (0.5 + math.log(delta_d / beta))
        
    return loss
```

**Edge Cases and Pitfalls**
*   **Precision:** When $\Delta D(\mathbf{r})$ is very large, the logarithmic term grows slowly, preventing the loss from dominating the gradient update, which is the intended behavior for robustness [S1].
*   **Boundaries:** The function is continuous at $\Delta D(\mathbf{r}) = \beta$. At this point, both branches yield $0.5 \beta^2$ [S1].
*   **Degenerate Input:** If $\Delta D(\mathbf{r}) = 0$, the loss is 0, providing no gradient, which allows the network freedom when the prediction is perfect [S1].

## Subtopics

### Depth Noise Robustness and Supervision
This variant, associated with S-NeRF, focuses on the robustness of depth supervision against noise in pseudo-depth maps [S2, unofficial]. It employs a confidence strategy to locate and measure depth outliers, thereby avoiding their negative influence during training [S2, unofficial]. To evaluate this, random Gaussian noise is added to original depth map inputs, with outlier rates computed using a threshold of 1 compared to original inputs [S2, unofficial]. The method remains robust to light noise and shows only slight PSNR/SSIM drops (0.05–0.5%) under strong noise [S2, unofficial]. Using only sparse depth improves PSNR by 5% over RGB-only baselines but performs 2% worse in PSNR and 8% worse in LPIPS compared to dense depth with confidence [S2, unofficial]. The method does not rely on the quality of specific depth completion networks (e.g., NLSPN), as replacing it with traditional methods like Ku et al. (2018) yields similar rendering quality (24.41 vs 24.40 PSNR) [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per ray, as it involves basic arithmetic operations and a logarithm.
*   **Memory Complexity:** $O(1)$, requiring no additional storage beyond the depth values.
*   **Strengths:** It effectively handles inaccurate pseudo-depth maps by reducing the gradient magnitude for large errors, preventing geometry errors from degrading extrapolation performance [S1]. It allows the NeRF to terminate rays near pseudo-depth while maintaining freedom for inaccurate geometry [S1].
*   **Limitations:** It requires a threshold parameter $\beta$ (typically 0.1) which may need tuning for different scales of depth data [S1]. It is specifically designed for scenarios with dense but noisy depth priors [S1].
*   **When to use:** Use when training NeRFs with dense pseudo-depth maps that contain outliers or significant noise, particularly when extrapolation performance is a concern [S1].
*   **When not to use:** Avoid if high-precision, clean depth maps are available, as standard L2 loss may provide tighter geometric constraints.

## Background
Robust Depth Loss was proposed in the context of NeRFVS (Neural Radiance Fields for Free View Synthesis via Geometry Scaffolds) to optimize NeRF with dense but inaccurate depth maps [S1]. The method was inspired by previous works combining NeRF and geometry, aiming to mitigate the degradation of extrapolation performance caused by geometry errors in scaffolds [S1]. It was introduced in 2023 [S1].
