# Single-view NeRF Training with Depth Map

Also called: Depth-guided Single-view NeRF, Single-view NeRF with Depth Initialization

## Overview
This method initializes the geometry of visible regions in a single-view NeRF using a 360-degree depth estimation pipeline, addressing the under-constrained optimization problem inherent to single-view reconstruction [S1]. It sets itself apart from sibling methods by explicitly fusing perspective depth maps into a canonical panorama depth map via deformable alignment before NeRF training, rather than relying solely on RGB consistency or post-hoc inpainting [S1].

## How it works
**Inputs:** A single input RGB panorama $I_{\text{rgb}}$ [S1].
**Outputs:** A trained NeRF model $f_{\text{nerf}}$ representing the visible regions of the scene [S1].

**Data Structures:**
*   **Perspective Images:** A set $\{\bar{I}_{\text{rgb}}^k\}_{k=1}^K$ of $K$ perspective projections of the input panorama [S1].
*   **Perspective Depth Maps:** A set $\{\bar{I}_d^k\}_{k=1}^K$ where each $\bar{I}_d^k$ contains depth values estimated for $\bar{I}_{\text{rgb}}^k$ [S1].
*   **Canonical Panorama Depth Map:** A learnable depth map $I_d$ representing the aligned depth of the full panorama [S1].
*   **Alignment Parameters:**
    *   Scale factor $w_k$ for each perspective view $k$ [S1].
    *   Local bias field $\{b_{k,i,j}\}$ for each pixel $(i,j)$ in perspective view $k$ [S1].

**Numbered Steps:**

1.  **Perspective Projection:** Project the single input panorama $I_{\text{rgb}}$ into $K$ perspective images $\{\bar{I}_{\text{rgb}}^k\}_{k=1}^K$ using different viewing directions [S1]. The number of views is set to $K=20$ [S1]. This is necessary because existing monocular depth estimators are trained on limited field-of-view images and do not handle 360-degree panoramas directly [S1].
2.  **Depth Estimation:** Use a monocular depth estimation model to estimate depth values for each perspective image $\bar{I}_{\text{rgb}}^k$, obtaining the set of depth maps $\{\bar{I}_d^k\}_{k=1}^K$ [S1]. Note that due to scale ambiguity in single-view depth estimation, estimated depth values in overlapped regions may differ significantly [S1].
3.  **Deformable Alignment:** Perform deformable alignment to jointly align the perspective depth maps $\{\bar{I}_d^k\}$ to a canonical learnable panorama depth map $I_d$ [S1]. This is achieved by optimizing the alignment objective to determine the scale $w_k$ and local bias $b_{k,i,j}$ for each view [S1].
4.  **NeRF Training:** Train the single-view NeRF using the RGB panorama $I_{\text{rgb}}$ and the aligned depth map $I_d$ [S1]. The NeRF is optimized by minimizing the combined color and depth reconstruction loss $L_{\text{nerf}}'$ [S1].

**Formulas:**

**Depth Alignment Objective:**
The alignment is performed by optimizing the following equation [S1]:

$$
\sum_{k,i,j} \left\| \bar{v}_{i,j}^k w_k + b_{k,i,j} - v_{M(i,j)} \right\| + L_s(b_{i,j+1}, b_{i,j}) + L_s(b_{i+1,j}, b_{i,j})
$$

Where:
*   $k$ indexes the perspective view ($1 \dots K$) [S1].
*   $i, j$ are pixel coordinates in the perspective depth map [S1].
*   $\bar{v}_{i,j}^k$ is the pixel value of the perspective depth map $\bar{I}_d^k$ at $(i,j)$ [S1].
*   $w_k$ is the learnable scale value for view $k$ [S1].
*   $b_{k,i,j}$ is the learnable local bias value for pixel $(i,j)$ in view $k$ [S1].
*   $v_{M(i,j)}$ is the pixel value of the canonical panorama depth map $I_d$ at the coordinate mapped from $(i,j)$ [S1].
*   $M$ is a projective operation mapping perspective image coordinates to panorama image coordinates [S1].
*   $L_s$ is the smooth L1 loss [S1].
*   The terms $L_s(b_{i,j+1}, b_{i,j})$ and $L_s(b_{i+1,j}, b_{i,j})$ constitute a total variation term [S1].

**NeRF Training Loss:**
The NeRF is trained by minimizing [S1]:

$$
L_{\text{nerf}}' = \sum_{r \in R} \left( \|\hat{C}(r) - C(r)\|^2 + \|\hat{D}(r) - \bar{D}(r)\|^2 \right)
$$

Where:
*   $R$ is the set of rays sampled from the panorama [S1].
*   $\hat{C}(r)$ is the expected pixel color rendered by the NeRF for ray $r$ [S1].
*   $C(r)$ is the ground-truth pixel color from the input panorama [S1].
*   $\hat{D}(r)$ is the expected depth value rendered by the NeRF for ray $r$ [S1].
*   $\bar{D}(r)$ is the corresponding depth pixel value computed by the depth estimator (derived from $I_d$) for ray $r$ [S1].

**Parameters:**
*   $K$: Number of perspective projections. Set to 20 [S1].

**Edge Cases and Pitfalls:**
*   **Scale Ambiguity:** Single-view depth estimation suffers from scale ambiguity, leading to large discrepancies in overlapped regions between perspective depth maps [S1]. The deformable alignment step is critical to resolve this [S1].
*   **Limited Field of View:** Standard monocular depth estimators are not trained on 360-degree panoramas [S1]. Direct application fails, necessitating the projection into perspective views [S1].
*   **Visible Regions Only:** Since only a single panorama is available, the trained NeRF $f_{\text{nerf}}$ only accurately represents visible regions [S1]. Invisible regions require separate completion methods (e.g., inpainting) [S1].

## Operating characteristics
*   **Time Complexity:** The method involves two main optimization phases: deformable alignment of $K$ depth maps and NeRF training [S1]. The alignment complexity depends on the number of pixels and views ($O(K \cdot H \cdot W)$ per iteration), while NeRF training complexity is standard for volume rendering ($O(N_{rays} \cdot N_{samples})$ per iteration) [S1].
*   **Memory Complexity:** Requires storing $K$ perspective depth maps, the canonical panorama depth map, and the NeRF weights [S1]. The alignment parameters (scales and biases) add $O(K \cdot H \cdot W)$ memory overhead [S1].
*   **Measured Performance:** Not given in the sources.
*   **Strengths:** Provides accurate geometry reconstruction for visible regions in single-view scenarios by leveraging explicit depth supervision, addressing the under-constrained nature of single-view NeRF [S1].
*   **Limitations:** The NeRF is only valid for visible regions; invisible regions are not reconstructed by this specific step and require additional inpainting [S1]. Performance depends on the accuracy of the monocular depth estimator [S1].
*   **When to Use:** When only a single panoramic image is available and accurate geometry of visible regions is required [S1].
*   **When Not to Use:** When multiple views are available (multi-view NeRF is more robust) or when the full 360-degree geometry (including occluded regions) is needed without additional inpainting steps [S1].

## Background
This method is part of the PERF (Panoramic Neural Radiance Field From a Single Panorama) framework [S1]. It was introduced to address the lack of geometry consistency in single-view panoramic NeRF methods, which often rely on inpainting or perceptual losses without explicit geometric constraints [S1]. The approach builds on 360MonoDepth for depth estimation and integrates it into the NeRF training loop via deformable alignment [S1].
