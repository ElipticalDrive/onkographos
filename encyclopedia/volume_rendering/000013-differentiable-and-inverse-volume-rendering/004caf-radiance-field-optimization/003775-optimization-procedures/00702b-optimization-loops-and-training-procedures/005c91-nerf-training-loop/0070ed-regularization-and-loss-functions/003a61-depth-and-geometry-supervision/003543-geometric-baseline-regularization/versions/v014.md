# Geometric Baseline Regularization

Also called: Geometric Baseline, Geometric Loss

## Overview
Geometric Baseline Regularization is a composite loss function designed to prevent degenerate solutions, such as image copying and floaters, during the optimization of Neural Radiance Fields (NeRFs), particularly in few-view settings [S1]. It serves as a strong baseline by combining photometric reconstruction with geometric priors that enforce foreground completeness, frustum consistency, and compact depth distributions [S1]. Unlike methods that rely on external depth supervision or structural consistency constraints, this approach relies solely on internal geometric plausibility derived from the ray termination weights and view frustums [S1, 8687-depth-supervised-nerf.md].

## How it works
The method defines a total geometric loss $\mathcal{L}_{\text{geom}}$ that augments the standard photometric loss with three specific regularization terms [S1].

**Inputs and Outputs:**
*   **Inputs:**
    *   $\mathcal{I}$: Set of training images.
    *   $\sigma, \mathbf{c}$: Density and color field parameters.
    *   $N$: Number of sampling points per ray.
    *   $t_i, t_{i+1}$: Start and end depths of the $i$-th interval along a ray $\mathbf{r}$.
    *   $w_i$: Weight (contribution) of the $i$-th sample to the final color.
    *   $n_i$: Number of training view frustums containing the point at $t_i$.
    *   $\lambda_{\text{fg}}, \lambda_{\text{fr}}, \lambda_{\text{dist}}$: Loss coefficients.
*   **Outputs:**
    *   $\mathcal{L}_{\text{geom}}$: Scalar loss value for backpropagation.

**Data Structures:**
*   Ray sampling intervals are defined by depths $t_i$.
*   Weights $w_i$ are computed via standard volume rendering accumulation: $w_i = \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j)$, where $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ [S1, 8582-regnerf.md].

**Formulas:**
The total loss is defined as [S1]:
$$ \mathcal{L}_{\text{geom}} = \mathcal{L}_{\text{photo}} + \lambda_{\text{fg}} \mathcal{L}_{\text{fg}} + \lambda_{\text{fr}} \mathcal{L}_{\text{fr}} + \lambda_{\text{dist}} \mathcal{L}_{\text{dist}} $$

1.  **Photometric Loss ($\mathcal{L}_{\text{photo}}$):** L2 difference between input images $I_i$ and rendered colors $\mathbf{C}_i$ [S1]:
    $$ \mathcal{L}_{\text{photo}}(\sigma , \mathbf{c}) = \sum_{i=1}^{\mathcal{I}} ||I_i - \mathbf{C}_i||_2 $$

2.  **Foreground Completeness Loss ($\mathcal{L}_{\text{fg}}$):** Encourages the sum of weights along a ray to equal 1, ensuring rays are fully absorbed by scene geometry [S1]:
    $$ \mathcal{L}_{\text{fg}} = \left( 1 - \sum_{i=1}^N w_i \right)^2 $$

3.  **Frustum Consistency Loss ($\mathcal{L}_{\text{fr}}$):** Penalizes density placed in only one view frustum to prevent image copying. It sums weights $w_i$ where the point is contained in fewer than two training view frustums ($n_i \le 1$) [S1]:
    $$ \mathcal{L}_{\text{fr}} = \sum_i w_i \mathbf{1}(n_i \le 1) $$
    Here, $\mathbf{1}(\cdot)$ is the indicator function.

4.  **Distribution Regularization Loss ($\mathcal{L}_{\text{dist}}$):** Encourages compact distribution of weights (single dominant depth) rather than spread-out density. It uses the expected depth $D(\mathbf{r})$ for normalization [S1]:
    $$ \mathcal{L}_{\text{dist}} = \frac{1}{D(\mathbf{r})} \left( \sum_{i,j} w_i w_k \left| \frac{t_i + t_{i+1}}{2} - \frac{t_j + t_{j+1}}{2} \right| + \frac{1}{3} \sum_{i=1}^N w_i^2 (t_{i+1} - t_i) \right) $$
    Note: The source text contains a typo in the first summation index ($w_k$ instead of $w_j$). Based on the context of pairwise distance between intervals $i$ and $j$, the term is interpreted as $w_i w_j$ [S1]. The expected depth $D(\mathbf{r})$ is defined as [S1]:
    $$ \mathbf{D}(\mathbf{r}) = \frac{\sum_{i=1}^N w_i t_i}{\sum_{i=1}^N w_i} $$

**Parameters:**
*   $\lambda_{\text{fg}}, \lambda_{\text{fr}}$: Fixed coefficients (values not explicitly given in sources, assumed to be 1 or standard defaults if not specified, but source says "coefficients controlling contributions" without specific values for these two) [S1].
*   $\lambda_{\text{dist}}$: Scheduled coefficient. Starts at 0 for the first 2500 steps. Linearly increases to $1 \times 10^{-4}$ at 8000 steps for the DTU dataset, and to $1.5 \times 10^{-5}$ at 8000 steps for the LLFF dataset [S1].

**Pseudocode:**
```python
def geometric_baseline_loss(rendered_colors, input_images, weights, depths, frustum_counts, step, dataset):
    """
    Computes the Geometric Baseline Loss.
    
    Args:
        rendered_colors: List of rendered color tensors for each training view.
        input_images: List of input image tensors for each training view.
        weights: Tensor of shape (num_rays, N) containing sample weights w_i.
        depths: Tensor of shape (num_rays, N+1) containing interval boundaries t_i.
        frustum_counts: Tensor of shape (num_rays, N) containing n_i (view frustum overlap).
        step: Current training step integer.
        dataset: String, 'DTU' or 'LLFF'.
        
    Returns:
        total_loss: Scalar tensor.
    """
    # 1. Photometric Loss (L2)
    # Sum over all training views
    photo_loss = 0.0
    for C_rendered, C_input in zip(rendered_colors, input_images):
        photo_loss += torch.sum((C_rendered - C_input) ** 2)
        
    # 2. Foreground Completeness Loss
    # Sum of weights along each ray
    sum_weights = torch.sum(weights, dim=1) # Shape: (num_rays,)
    # L_fg = (1 - sum(w_i))^2
    fg_loss = torch.mean((1.0 - sum_weights) ** 2)
    
    # 3. Frustum Consistency Loss
    # Indicator: 1 if n_i <= 1, else 0
    mask_single_view = (frustum_counts <= 1).float()
    # L_fr = sum(w_i * 1(n_i <= 1))
    fr_loss = torch.sum(weights * mask_single_view)
    
    # 4. Distribution Regularization Loss
    # Compute expected depth D(r) for each ray
    # D(r) = sum(w_i * t_i) / sum(w_i)
    # Note: depths has shape (N+1). We need midpoints or use t_i.
    # The formula uses (t_i + t_{i+1})/2. Let's compute midpoints.
    midpoints = (depths[:, :-1] + depths[:, 1:]) / 2.0 # Shape: (num_rays, N)
    
    # Term 1: Pairwise distance between midpoints weighted by w_i * w_j
    # sum_{i,j} w_i w_j |mid_i - mid_j|
    # This can be computed efficiently or via loop. For clarity:
    # Expand dimensions for broadcasting
    w_i = weights.unsqueeze(2) # (num_rays, N, 1)
    w_j = weights.unsqueeze(1) # (num_rays, 1, N)
    mid_i = midpoints.unsqueeze(2) # (num_rays, N, 1)
    mid_j = midpoints.unsqueeze(1) # (num_rays, 1, N)
    
    pairwise_dist = torch.abs(mid_i - mid_j) # (num_rays, N, N)
    term1 = torch.sum(w_i * w_j * pairwise_dist)
    
    # Term 2: (1/3) * sum_i w_i^2 * (t_{i+1} - t_i)
    # delta_t = t_{i+1} - t_i
    delta_t = depths[:, 1:] - depths[:, :-1] # Shape: (num_rays, N)
    term2 = (1.0 / 3.0) * torch.sum(weights ** 2 * delta_t)
    
    # Normalize by expected depth
    # Avoid division by zero
    epsilon = 1e-8
    expected_depth = torch.sum(weights * midpoints, dim=1) / (torch.sum(weights, dim=1) + epsilon)
    expected_depth = torch.clamp(expected_depth, min=epsilon)
    
    dist_loss = (term1 + term2) / torch.sum(expected_depth)
    
    # 5. Schedule lambda_dist
    lambda_dist = 0.0
    if step > 2500:
        # Linear increase from 0 to max_val at step 8000
        progress = (step - 2500) / (8000 - 2500)
        progress = min(progress, 1.0)
        if dataset == 'DTU':
            max_lambda = 1e-4
        elif dataset == 'LLFF':
            max_lambda = 1.5e-5
        else:
            max_lambda = 1e-4 # Default fallback
        lambda_dist = progress * max_lambda
        
    # 6. Combine
    # Note: Source does not specify lambda_fg and lambda_fr values. 
    # Assuming 1.0 as standard baseline unless specified otherwise [G].
    lambda_fg = 1.0
    lambda_fr = 1.0
    
    total_loss = photo_loss + lambda_fg * fg_loss + lambda_fr * fr_loss + lambda_dist * dist_loss
    
    return total_loss
```

**Edge Cases and Pitfalls:**
*   **Division by Zero:** The expected depth $D(\mathbf{r})$ in $\mathcal{L}_{\text{dist}}$ can be zero if no weights are accumulated. A small epsilon must be added to the denominator [G].
*   **Few-View Collapse:** Without $\mathcal{L}_{\text{fr}}$, NeRFs may collapse to copying training images. This loss specifically targets points covered by only one view frustum [S1].
*   **Index Typo:** The source formula for $\mathcal{L}_{\text{dist}}$ uses $w_k$ in the pairwise sum. This is interpreted as $w_j$ to match the summation index $j$ [S1].

## Operating characteristics
*   **Time Complexity:** The photometric and foreground losses are linear in the number of rays and samples. The frustum loss is linear. The distribution loss involves a pairwise summation over samples ($O(N^2)$ per ray), which can be computationally expensive for large $N$. Optimizations using vectorized operations or approximations are recommended [S1].
*   **Memory Complexity:** Requires storing weights, depths, and frustum counts for all rays. The pairwise distance calculation in $\mathcal{L}_{\text{dist}}$ requires $O(N^2)$ memory per ray if computed naively, or $O(N)$ with optimized broadcasting [S1].
*   **Strengths:** Effective at preventing degenerate solutions (image copying) in few-view scenarios without requiring external depth maps or point clouds [S1].
*   **Limitations:** The $O(N^2)$ term in $\mathcal{L}_{\text{dist}}$ increases training time. The effectiveness depends on correct scheduling of $\lambda_{\text{dist}}$ [S1].
*   **When to use:** When training NeRFs with few input views and no external geometric supervision (depth/points) is available [S1].

## Background
Geometric Baseline Regularization was introduced in the context of regularizing NeRFs with Denoising Diffusion Models (DiffusioNeRF) [S1]. It serves as a strong baseline for NeRF optimization, combining photometric and geometric losses to prevent degenerate solutions in few-view settings [S1]. The method is based on the principle that real scenes should have compact depth distributions, rays should be fully absorbed, and density should not be confined to a single view frustum [S1].
