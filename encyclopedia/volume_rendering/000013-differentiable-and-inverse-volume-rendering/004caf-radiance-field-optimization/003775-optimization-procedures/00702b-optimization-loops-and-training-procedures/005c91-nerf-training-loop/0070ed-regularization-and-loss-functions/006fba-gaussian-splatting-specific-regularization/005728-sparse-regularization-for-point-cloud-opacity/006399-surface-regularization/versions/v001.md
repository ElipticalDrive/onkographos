# Surface Regularization

Also called: Point Cloud Surface Regularization, Repulsion and Projection Regularization

## Overview
Surface Regularization is a geometric constraint strategy applied during the optimization of point-based radiance fields to prevent the point cloud from collapsing into local minima and to enforce manifold structure [S1]. It addresses the lack of inherent connectivity in point clouds by combining a repulsion term, which encourages uniform point distribution on local tangent planes, and a projection term, which forces points to lie on those planes [S1]. Unlike mesh-based regularization, it operates directly on unstructured points using weighted Principal Component Analysis (PCA) to estimate local geometry [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of points $P = \{p_i\}$ with associated normals $N = \{n_i\}$, a neighborhood radius $D$, and an occlusion counter $O = \{o_k\}$ for each point.
*   **Outputs:** Gradient updates for point positions $p_i$ and normals $n_i$ derived from the regularization losses $L_r$ and $L_p$.

**Data Structures:**
*   **Point:** 3D position vector $p_i \in \mathbb{R}^3$.
*   **Normal:** 3D unit vector $n_i \in \mathbb{R}^3$.
*   **Occlusion Counter:** Integer $o_k \ge 0$.

**Algorithm:**
The method computes two loss terms based on local surface estimation via weighted PCA.

1.  **Compute Weights:** For a target point $p_i$ and each neighbor $p_k$ within distance $D$ (i.e., $\|p_i - p_k\| \le D$), compute three weights:
    *   **Spatial Weight ($\psi_{ik}$):** Penalizes distance.
        $$ \psi_{ik} = \exp \left( - \frac{\|p_i - p_k\|^2}{D^2} \right) $$
    *   **Normal Similarity Weight ($\theta_{ik}$):** Penalizes normal divergence.
        $$ \theta_{ik} = \exp \left( - \frac{(1 - n_k^\top n_i)^2}{\max(10^{-5}, 1 - \cos(\Theta))} \right) $$
        *Note: The denominator uses a constant $10^{-5}$ or a threshold $\cos(\Theta)$ to prevent division by zero when normals are identical. The source formula explicitly writes $\max(10^{-5}, 1 - \cos(\Theta))$ [S1].*
    *   **Visibility Weight ($\phi_{ik}$):** Penalizes occluded points, treating them as potential outliers.
        $$ \phi_{ik} = \frac{1}{o_k + 1} $$
    *   **Combined Weight ($w_{ik}$):**
        $$ w_{ik} = \frac{\psi_{ik} \theta_{ik} \phi_{ik}}{\sum_{k \in \mathcal{N}_i} \psi_{ik} \theta_{ik} \phi_{ik}} $$
        where $\mathcal{N}_i$ is the set of neighbors of $p_i$.

2.  **Estimate Local Tangent Plane:**
    *   Compute weighted covariance matrix or perform Singular Value Decomposition (SVD) on the weighted vectors $w_{ik}(p_i - p_k)$ to find the principal components.
    *   Let $V$ be the matrix of eigenvectors (principal components) sorted by eigenvalue magnitude.
    *   $\tilde{V}$ contains the first 2 principal components (spanning the tangent plane).
    *   $V_n$ is the 3rd principal component (the surface normal).

3.  **Compute Repulsion Loss ($L_r$):**
    *   Calculate projected point-to-point distances on the tangent plane:
        $$ d_{ik}^r = \tilde{V}^\top (p_i - p_k) $$
        *Note: The source defines $d_{ik} = \tilde{V}^\top (p_i - p_k)$ and squares it in the loss. This represents the distance in the 2D tangent space.*
    *   The loss encourages points to spread out uniformly:
        $$ L_r = \frac{1}{N} \sum_{i} \sum_{k \in \mathcal{N}_i} \frac{\psi_{ik}}{N} \left( \|d_{ik}^r\|^2 + 10^{-4} \right) $$
        *Correction/Clarification:* The source formula is $L_r = \frac{1}{N} \sum_{i} \sum_{K} \frac{\psi_{ik} d_{ik}^2}{N} + 10^{-4}$. The $10^{-4}$ is likely a smoothing term added to the squared distance or the loss itself to prevent singularities. Given the structure $\frac{\psi_{ik} d_{ik}^2}{N} + 10^{-4}$, it is applied per term or globally. The text says "minimize it together with...". We interpret the $10^{-4}$ as a small constant added to the squared distance to ensure differentiability and stability [S1].

4.  **Compute Projection Loss ($L_p$):**
    *   Calculate point-to-plane distances (distance to the tangent plane):
        $$ d_{ik}^p = V_n^\top (p_i - p_k) $$
        *Note: This is the scalar projection of the vector $(p_i - p_k)$ onto the normal $V_n$.*
    *   The loss forces points to lie on the surface:
        $$ L_p = \frac{1}{N} \sum_{i} \sum_{k \in \mathcal{N}_i} w_{ik} (d_{ik}^p)^2 $$

5.  **Total Objective:**
    The total loss for optimization is:
    $$ L = \sum_{v=0}^{V} L(I_v, I_v^*) + \gamma_p L_p + \gamma_r L_r $$
    where $L(I_v, I_v^*)$ is the image reconstruction loss for view $v$, $\gamma_p = 0.02$, and $\gamma_r = 0.05$ [S1].

**Pseudocode:**

```python
import numpy as np

def compute_surface_regularization_gradients(points, normals, occlusion_counts, 
                                            neighbors, D, gamma_p=0.02, gamma_r=0.05):
    """
    Computes gradients for point positions based on Surface Regularization.
    
    Args:
        points: Array of shape (N, 3) containing point positions p_i.
        normals: Array of shape (N, 3) containing point normals n_i.
        occlusion_counts: Array of shape (N,) containing occlusion counters o_k.
        neighbors: List of lists, where neighbors[i] contains indices of neighbors k for point i.
        D: Neighborhood radius.
        
    Returns:
        grad_points: Array of shape (N, 3) containing gradients for point positions.
    """
    N = points.shape[0]
    grad_points = np.zeros_like(points)
    
    # Precompute visibility weights
    # phi_ik = 1 / (o_k + 1)
    visibility_weights = 1.0 / (occlusion_counts + 1.0)
    
    for i in range(N):
        p_i = points[i]
        n_i = normals[i]
        neighbor_indices = neighbors[i]
        
        if len(neighbor_indices) == 0:
            continue
            
        p_k = points[neighbor_indices]
        n_k = normals[neighbor_indices]
        
        # 1. Compute Spatial Weight psi_ik
        dist_sq = np.sum((p_i - p_k) ** 2, axis=1)
        psi = np.exp(-dist_sq / (D ** 2))
        
        # 2. Compute Normal Weight theta_ik
        # dot products between n_i and n_k
        dot_products = np.sum(n_i * n_k, axis=1)
        # 1 - cos(theta) = 1 - dot_product
        one_minus_cos = 1.0 - dot_products
        # Denominator max(1e-5, 1 - cos(theta))
        denom = np.maximum(1e-5, one_minus_cos)
        # Numerator (1 - n_k^T n_i)^2
        numerator = (1.0 - dot_products) ** 2
        theta = np.exp(-numerator / denom)
        
        # 3. Compute Visibility Weight phi_ik
        # Use occlusion counts of neighbors k
        phi = visibility_weights[neighbor_indices]
        
        # 4. Compute Combined Weight w_ik
        raw_weights = psi * theta * phi
        sum_weights = np.sum(raw_weights)
        if sum_weights == 0:
            w = np.zeros_like(raw_weights)
        else:
            w = raw_weights / sum_weights
            
        # 5. Compute Weighted Vectors for PCA
        # v_vectors = w_ik * (p_i - p_k)
        diff_vectors = p_i - p_k
        weighted_vectors = w[:, np.newaxis] * diff_vectors
        
        # 6. Perform PCA (SVD) on weighted vectors
        # We want the covariance matrix or directly SVD of the weighted data matrix
        # Centered weighted vectors are already used in the formula derivation 
        # but here we compute SVD of the matrix of weighted vectors to get principal components.
        # Note: The source says "SVD from weighted vectors w_ik(p_i - sum w_ik p_k)".
        # This implies centering. Let's compute the weighted centroid.
        weighted_centroid = np.sum(weighted_vectors, axis=0) # Sum of w*(p_i - p_k)
        # Actually, the formula for the plane is derived from the weighted covariance.
        # Let's construct the matrix M where rows are sqrt(w_ik) * (p_i - p_k)
        # Or simply use the weighted covariance matrix.
        
        # Weighted Covariance Matrix C = sum( w_k * (p_k - mean) * (p_k - mean)^T )
        # But the source uses vectors w_ik * (p_i - p_k). 
        # Let's stick to the SVD of the matrix of weighted differences.
        # Matrix A of shape (K, 3) where row k is sqrt(w_k) * (p_i - p_k)
        sqrt_w = np.sqrt(w)
        A = (sqrt_w[:, np.newaxis] * diff_vectors)
        
        # SVD
        U, S, Vt = np.linalg.svd(A, full_matrices=False)
        
        # Vt rows are the principal components.
        # V_n is the last component (normal), V_tilde is the first two (tangent).
        V_n = Vt[-1, :] # Shape (3,)
        V_tilde = Vt[:2, :] # Shape (2, 3)
        
        # 7. Compute Projection Loss Gradient
        # d_ik^p = V_n^T (p_i - p_k)
        d_proj = V_n @ diff_vectors.T # Shape (K,)
        # L_p = 1/N sum_i sum_k w_ik (d_ik^p)^2
        # Gradient w.r.t p_i involves chain rule.
        # d(L_p)/d(p_i) = sum_k w_ik * 2 * d_ik^p * d(d_ik^p)/d(p_i)
        # d_ik^p = V_n . (p_i - p_k)
        # d(d_ik^p)/d(p_i) = V_n
        # However, V_n depends on p_i. The source notes "gradients on point positions p mainly stems from the visibility term" 
        # and implies alternating updates. For the purpose of implementing the regularization term itself, 
        # we often treat the geometry (V_n) as fixed for the gradient step or compute full derivatives.
        # The source does not provide the explicit gradient formula, only the loss.
        # We will compute the gradient assuming V_n is fixed for this step (common in such regularizers) 
        # or note that full differentiation is complex. 
        # Given the instruction "complete enough to implement", we provide the gradient assuming fixed local frame.
        
        grad_proj = 2.0 * d_proj * V_n # Shape (K, 3)
        # Weighted sum
        grad_proj_sum = np.sum(w[:, np.newaxis] * grad_proj, axis=0)
        
        # 8. Compute Repulsion Loss Gradient
        # d_ik^r = V_tilde^T (p_i - p_k) -> Shape (2,)
        d_rep = V_tilde @ diff_vectors.T # Shape (2, K)
        # L_r = 1/N sum_i sum_k (psi_ik / N) * (||d_ik^r||^2 + 1e-4)
        # Gradient w.r.t p_i:
        # d(||d_ik^r||^2)/d(p_i) = 2 * V_tilde^T * d_ik^r
        # d_ik^r is a vector in tangent space.
        
        # Calculate squared norms
        d_rep_sq = np.sum(d_rep ** 2, axis=0) # Shape (K,)
        
        # Gradient of squared distance in tangent space back to 3D
        # grad_rep_3d = V_tilde^T * (2 * d_rep)
        grad_rep_3d = V_tilde.T @ (2.0 * d_rep) # Shape (3, K)
        
        # Weight by psi_ik / N
        # Note: The source has psi_ik / N in the sum.
        weights_rep = psi / N
        grad_rep_sum = np.sum(weights_rep[:, np.newaxis] * grad_rep_3d, axis=1) # Shape (3,)
        
        # 9. Combine Gradients
        # L = ImageLoss + gamma_p * L_p + gamma_r * L_r
        # grad_points[i] += gamma_p * grad_proj_sum + gamma_r * grad_rep_sum
        
        grad_points[i] += gamma_p * grad_proj_sum + gamma_r * grad_rep_sum

    return grad_points
```

**Parameters:**
*   $\gamma_p = 0.02$: Weight for the projection loss [S1].
*   $\gamma_r = 0.05$: Weight for the repulsion loss [S1].
*   $D$: Neighborhood radius. Not given in the sources.
*   $\Theta$: Threshold for normal similarity. The source uses $\max(10^{-5}, 1 - \cos(\Theta))$. It is unclear if $\Theta$ is a variable or a constant threshold. The formula suggests a constant floor of $10^{-5}$ [S1].

**Edge Cases and Pitfalls:**
*   **Occlusion Counters:** Points with high occlusion counts receive low visibility weights, reducing their influence on the local plane estimation. This prevents outliers inside the model from distorting the surface [S1].
*   **Normal Similarity:** The term $\max(10^{-5}, 1 - \cos(\Theta))$ prevents division by zero when normals are parallel. If normals are identical, the weight $\theta_{ik}$ becomes $\exp(0) = 1$ [S1].
*   **Alternating Updates:** Normals and points are updated alternately because the gradient for positions depends on normals and vice versa. The source suggests optimizing normals for $T_n$ steps, then points for $T_p$ steps [S1].

## Operating characteristics
*   **Time Complexity:** The method requires computing weights and PCA for each point's neighborhood. If $K$ is the average number of neighbors, the complexity per point is $O(K \log K)$ or $O(K)$ depending on the PCA implementation (SVD is typically $O(K \cdot 3^2)$). Total complexity is $O(N \cdot K)$.
*   **Memory Complexity:** $O(N \cdot K)$ to store neighbor weights and intermediate vectors.
*   **Strengths:** Effectively prevents point clustering in local minima (Fig. 8) and enforces clean manifold surfaces (Fig. 9) [S1]. It is robust to noise due to the weighted PCA and visibility filtering.
*   **Limitations:** Requires maintaining and updating normals for each point, which adds computational overhead compared to position-only optimization. The method is sensitive to the choice of neighborhood radius $D$ (Not given in the sources).
*   **When to Use:** Use when optimizing point-based radiance fields or implicit surfaces where geometric smoothness and uniformity are required, and mesh structures are not available.

## Background
Surface Regularization was introduced by Wang Yifan, Serena Felice, Shihao Wu, Cengiz Öztireli, and Olga Sorkine-Hornung in their paper "Differentiable Surface Splatting for Point-based Geometry Processing" (2020) [S1]. It is inspired by earlier works on point cloud denoising and surface reconstruction by Huang et al. (2009) and Öztireli et al. (2009) [S1]. The method is used in differentiable rendering pipelines that optimize point clouds to match target images, ensuring that the resulting geometry is well-structured and manifold-like.
