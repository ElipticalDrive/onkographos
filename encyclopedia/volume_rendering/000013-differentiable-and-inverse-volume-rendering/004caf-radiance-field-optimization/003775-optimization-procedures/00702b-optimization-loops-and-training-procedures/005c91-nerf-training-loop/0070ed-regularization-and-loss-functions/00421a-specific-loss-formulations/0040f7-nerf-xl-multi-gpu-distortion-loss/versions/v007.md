# NeRF-XL Multi-GPU Distortion Loss


## Overview
The NeRF-XL Multi-GPU Distortion Loss computes the distortion loss for a ray distributed across $N$ GPUs by aggregating local transmittance, auxiliary, and loss terms into a single global value [S1]. It builds on [Specific Loss Formulations](10636-specific-loss-formulations.md) [G].

## How it works
### Inputs and Outputs
*   **Inputs**:
    *   Local segment data on GPU $k$: Transmittance $T_{k \to k+1}$, Color $C_{k \to k+1}$, Auxiliary variable $A_{k \to k+1}$, Distortion auxiliary $D_{k \to k+1}$, Local loss $L_{k \to k+1}$ [S1].
    *   Ray segment assignment list $I = \{i_1, i_2, \dots, i_N\}$, where $i_s$ is the ID of the GPU responsible for the $s$-th segment of the ray [S1].
    *   $N$: Total number of segments in the ray [S1].
*   **Outputs**:
    *   Global distortion loss $L_{1 \to N+1}$ [S1].

### Data Structures
The algorithm maintains global accumulators for each ray being processed:
*   $T_{1 \to i}$: Global transmittance up to the current segment [S1].
*   $A_{1 \to i}$: Global accumulated auxiliary variable [S1].
*   $D_{1 \to i}$: Global accumulated distortion auxiliary variable [S1].
*   $L_{1 \to N+1}$: Global accumulated distortion loss [S1].

### Formulas
The method computes the global distortion loss using the following recurrence relations [S1]:
1.  Initialize $T_{1 \to 1} = 1$, $A_{1 \to 1} = 0$, $D_{1 \to 1} = 0$, and $L_{1 \to N+1} = 0$ [S1].
2.  For each segment $s$ from $1$ to $N$:
    *   Let $i = I[s]$ be the GPU ID for the current segment [S1].
    *   If $i \neq k$, gather $T_{i \to i+1}$, $C_{i \to i+1}$ from GPU $i$ with gradients disabled, and gather $A_{i \to i+1}$, $D_{i \to i+1}$, $L_{i \to i+1}$ using a distributed communication primitive [S1].
    *   Compute the intermediate cross-term $S_{1 \to i} = D_{k \to k+1} \times A_{1 \to i} - A_{k \to k+1} \times D_{1 \to i}$ [S1].
    *   Update global loss: $L_{1 \to N+1} \leftarrow L_{1 \to N+1} + T_{1 \to i} \times L_{i \to i+1} + T_{1 \to i} \times S_{1 \to i}$ [S1].
    *   Update global auxiliary $A$: $A_{1 \to i} \leftarrow A_{1 \to i} + T_{1 \to i} \times A_{i \to i+1}$ [S1].
    *   Update global distortion $D$: $D_{1 \to i} \leftarrow D_{1 \to i} + T_{1 \to i} \times D_{i \to i+1}$ [S1].
    *   Update global transmittance: $T_{1 \to i} \leftarrow T_{1 \to i} \times T_{i \to i+1}$ [S1].

### Pseudocode
The following pseudocode implements Algorithm 2 from [S1] for the $k$-th GPU. It defines the communication primitives explicitly as distributed calls that fetch tensors without gradients [S1].

```python
def compute_distortion_loss(k, local_T, local_A, local_D, local_L, ray_segments):
    """
    Compute global distortion loss for a ray distributed across multiple GPUs.
    
    Args:
        k: ID of the current GPU.
        local_T: Transmittance of the segment on this GPU (T_{k->k+1}).
        local_A: Auxiliary A of the segment on this GPU (A_{k->k+1}).
        local_D: Distortion auxiliary D of the segment on this GPU (D_{k->k+1}).
        local_L: Local loss of the segment on this GPU (L_{k->k+1}).
        ray_segments: List of GPU IDs [i_1, i_2, ..., i_N] for each segment of the ray.
        
    Returns:
        global_loss: The aggregated distortion loss L_{1->N+1}.
    """
    # Initialize global accumulators [S1]
    global_T = 1.0
    global_A = 0.0
    global_D = 0.0
    global_L = 0.0
    
    N = len(ray_segments)
    
    for s in range(N):
        i = ray_segments[s]
        
        # Fetch segment data from GPU i [S1]
        if i != k:
            # Distributed communication to fetch T_{i->i+1}, C_{i->i+1} from GPU i without gradients [G]
            T_i, C_i = ... # Framework-specific distributed call
            # Distributed communication to fetch A_{i->i+1}, D_{i->i+1}, L_{i->i+1} from GPU i without gradients [G]
            A_i, D_i, L_i = ... # Framework-specific distributed call
        else:
            # Use local data [S1]
            T_i, C_i = local_T, None
            A_i, D_i, L_i = local_A, local_D, local_L
            
        # Compute cross-term S_{1->i} = D_{k->k+1} * A_{1->i} - A_{k->k+1} * D_{1->i} [S1]
        S = D_i * global_A - A_i * global_D
        
        # Update global loss [S1]
        global_L += global_T * L_i + global_T * S
        
        # Update global auxiliary A [S1]
        global_A += global_T * A_i
        
        # Update global auxiliary D [S1]
        global_D += global_T * D_i
        
        # Update global transmittance [S1]
        global_T *= T_i
        
    return global_L
```

## Background
The method was introduced in "NeRF-XL: Scaling NeRFs with Multiple GPUs" [S1]. The paper addresses the challenge of training NeRFs on large-scale captures with billions of pixels by distributing computation across multiple GPUs [S1]. The distortion loss is computed as part of the multi-GPU volume rendering and optimization procedures [S1].
