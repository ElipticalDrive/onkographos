# Sparse Regularization for Point Cloud Opacity
Also called: Denoising and Completion, Point Cloud Geometry Optimization, Sparse Opacity Optimization
## Overview
Sparse regularization for point cloud opacity is an optimization strategy applied during the training of point-based radiance fields to manage point density and geometry [S1]. It operates through an alternating loop of denoising and completion stages [S1]. Unlike sibling methods that focus on smoothness, it explicitly manages opacity parameters via a sparsity-inducing loss function and iteratively adds points to fill rendering gaps [S1].
## How it works
**Inputs and Outputs:**
*   **Input:** A set of 3D points $P = \{p_i\}$, each with an associated optimizable opacity parameter $\alpha_i$, and a set of training views with ground truth images [S1].
*   **Output:** An optimized point cloud with refined geometry and opacity values, where low-opacity points are removed based on a threshold $\mu$ [S1].

**Data Structures:**
*   **Point Cloud:** A list of points $p_i$. Each point has an opacity parameter $\alpha_i$ [S1].
*   **Depth Buffer:** For each pixel, a buffer storing the depths of $k$ points along the ray, explicitly not restricted to the single nearest point [S1].
*   **Rectified Coordinates:** Computed from the depth buffer values using a transformation defined in the source (Eqn. 1 in [S1]), which maps points to a deformed space suitable for radiance mapping [S1].

**Parameters:**
*   $k$: Number of points maintained in the depth buffer per pixel [S1].
*   $\mu$: Threshold used to remove low-opacity points after training convergence [S1].
*   Typical values for $k$ and $\mu$ are not given in the sources [S1].

**Steps:**
The method operates in an alternating loop of Denoising and Completion until convergence [S1].

1.  **Denoising:**
    1.  **Rasterization:** For each training view, rasterize the point cloud. Maintain a depth buffer of $k$ points for each pixel [S1].
    2.  **Coordinate Transformation:** Compute rectified coordinates for the points in the depth buffer using the depth values and the transformation equation (Eqn. 1 in [S1]) [S1].
    3.  **Radiance Mapping:** Feed the rectified coordinates and the ray directions into a Multi-Layer Perceptron (MLP) to estimate colors [S1].
    4.  **Volume Rendering:** Assign an optimizable opacity parameter $\alpha_i$ to each point $p_i$. Compute the pixel RGB values using the volume rendering equation [S1].
    5.  **Loss Computation:** Compute the sparse regularization loss $\mathcal{L}_{\text{sparse}}$ [S1]:
        $$ \mathcal{L}_{\text{sparse}} = \frac{1}{N} \sum_{i=1}^N [\log(\alpha_i) + \log(1 - \alpha_i)] $$
        where $N$ is the number of points and $\alpha_i$ is the opacity parameter [S1].
    6.  **Optimization:** Optimize the point positions and opacity parameters $\alpha_i$ using the computed loss [S1].

2.  **Completion:**
    1.  **Masking:** Rasterize the current point cloud to get a mask. Identify pixels where the ground truth image indicates an occupied surface, but the rasterization buffer is empty (i.e., no points were rendered) [S1].
    2.  **Point Addition:** For each such pixel, add a set of new points with opacity parameters along the pixel ray [S1].
    3.  **Depth Range Determination:** Determine the depth range for the added points by referring to the depth range of adjacent pixel buffers [S1].
    4.  **Note:** The completion step may introduce noise, which is expected to be removed in the subsequent denoising stage [S1].

3.  **Convergence Check:**
    *   Repeat the Denoising and Completion steps alternatively until convergence [S1].
    *   After convergence, remove all points with opacity $\alpha_i < \mu$ [S1].

import numpy as np

def sparse_regularization_optimization(points, training_views, threshold_mu, k):
    """
    Optimizes point cloud geometry and opacity using sparse regularization.
    
    Args:
        points: List of dicts with 'pos' (3D array) and 'alpha' (float).
        training_views: List of dicts with 'camera' (dict with pose) and 'gt_image' (HxWx3 array).
        threshold_mu: Threshold for removing low-opacity points.
        k: Number of points to keep in the depth buffer per pixel.
        
    Returns:
        Optimized list of points.
    """
    converged = False
    while not converged:
        # --- Denoising Step ---
        for view in training_views:
            # 1. Rasterize and maintain depth buffer of k points
            depth_buffer = {}
            for p in points:
                u, v, z = project_point(p['pos'], view['camera'])
                pixel = (int(u), int(v))
                if pixel not in depth_buffer: depth_buffer[pixel] = []
                depth_buffer[pixel].append(z)
                depth_buffer[pixel].sort()
                if len(depth_buffer[pixel]) > k:
                    depth_buffer[pixel] = depth_buffer[pixel][:k]
            
            # 2. Compute rectified coordinates using depth buffer (Eqn 1 in [S1])
            rectified_coords = {pix: apply_rectification_formula(depths, view['camera']) for pix, depths in depth_buffer.items()}
            
            # 3. Estimate colors using MLP
            ray_dirs = {pix: normalize(compute_ray_direction(pix, view['camera'])) for pix in rectified_coords}
            colors = {pix: mlp_forward(rectified_coords[pix], ray_dirs[pix]) for pix in rectified_coords}
            
            # 4. Compute pixel RGB using volume rendering equation
            rendered_images = volume_render_equation(points, colors, view['camera'])
            
            # 5. Compute sparse regularization loss
            loss_sparse = compute_sparse_loss(points)
            
            # 6. Optimize points and opacities
            points = optimize_parameters(points, loss_sparse)
            
        # --- Completion Step ---
        for view in training_views:
            # 1. Rasterize to get mask
            mask = rasterize_occupancy(points, view['camera'])
            gt_image = view['gt_image']
            
            # 2. Identify empty pixels where GT is occupied
            empty_occupied_pixels = []
            for y in range(gt_image.shape[0]):
                for x in range(gt_image.shape[1]):
                    if mask[y, x] == 0 and np.linalg.norm(gt_image[y, x]) > 0.0:
                        empty_occupied_pixels.append((x, y))
            
            # 3. Add points for empty pixels
            for pixel in empty_occupied_pixels:
                # Determine depth range from adjacent pixels
                depth_range = get_adjacent_depth_range(pixel, depth_buffer)
                
                # Add points along the ray within the depth range
                new_points = add_points_along_ray(pixel, view['camera'], depth_range)
                points.extend(new_points)
                
        # Check convergence criteria (e.g., loss change, max iterations)
        if check_convergence(points):
            break
            
    # --- Post-processing ---
    # Remove low-opacity points
    final_points = [p for p in points if p['alpha'] >= threshold_mu]
    return final_points

def compute_sparse_loss(points):
    N = len(points)
    if N == 0: return 0.0
    total = 0.0
    for p in points:
        a = p['alpha']
        a = max(min(a, 1.0 - 1e-6), 1e-6) # [G] Guard against log(0)
        total += math.log(a) + math.log(1 - a)

def rasterize_occupancy(points, camera):
    mask = np.zeros((camera['height'], camera['width']), dtype=bool)
    for p in points:
        u, v, z = project_point(p['pos'], camera)
        if 0 <= u < camera['width'] and 0 <= v < camera['height']:

def get_adjacent_depth_range(pixel, depth_buffer):

    return (min(depths) if depths else 0.0, max(depths) if depths else 1.0)

**Edge Cases and Pitfalls:**
*   **Logarithm Domain:** The loss function involves $\log(\alpha_i)$ and $\log(1 - \alpha_i)$. If $\alpha_i$ is exactly 0 or 1, the log is undefined. A guard clamping $\alpha_i$ to $[\epsilon, 1-\epsilon]$ is necessary [G].
*   **Noise in Completion:** The completion step introduces noise, which must be handled by the subsequent denoising step [S1].
*   **Depth Buffer Size:** The choice of $k$ affects the smoothness of the rendering and the accuracy of the rectified coordinates. Not given in the sources.
*   **Threshold Selection:** The threshold $\mu$ determines the final sparsity. Not given in the sources.

## Subtopics

### [Surface Regularization](18866-surface-regularization.md)
Surface Regularization is a geometric constraint strategy applied during the optimization of point-based radiance fields to prevent the point cloud from collapsing into local minima and to enforce manifold structure. It addresses the lack of inherent connectivity in point clouds by combining a repulsion term, which encourages uniform point distribution on local tangent planes, and a projection term, which forces points to lie on those planes. Unlike mesh-based regularization, it operates directly on unstructured points using weighted Principal Component Analysis (PCA) to estimate local geometry.
