# Confidence-Based Loss Calibration

Also called: ICON

## Overview
Confidence-Based Loss Calibration dynamically weights the optimization of NeRF parameters and camera poses using estimated reliability metrics [S1]. It sets itself apart from static regularization methods by cross-weighting gradients: pose confidence weights NeRF gradients, while ray confidence weights pose gradients [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Current NeRF parameters $\Theta$, current pose estimates $\hat{P}$, input images $I$, momentum factor $\beta$, re-initialization threshold $\lambda$, and window size $K$ [S1].
*   **Outputs:** Calibrated loss values $L_{\text{NeRF}}$, $L_{\text{Pose}}$, and updated parameters $\Theta, \hat{P}$ [S1].

**Data Structures:**
*   **Pose Confidence ($\zeta_P$):** A scalar value per pose, maintained as an exponential moving average [S1].
*   **Ray Confidence ($\zeta_r$):** A scalar value per ray, computed from consistency metrics [S1].

**Steps:**
1.  **Initialize:** Set initial pose confidences $\zeta_{P}^{(0)}$ based on the first batch's mean ray confidence [G].
2.  **Sample Rays:** For each pose $P_i$, sample a set of $B$ rays $\{r_{ji}\}_{j=1}^B$ [S1].
3.  **Compute Ray Confidence ($\zeta_r$):** Calculate a confidence metric $\zeta_{r_{ji}}$ for each ray based on photometric or geometric consistency [S1].
4.  **Update Pose Confidence ($\zeta_P$):** Update the exponential moving average for pose $P_i$:
    $$ \zeta_{P_i}^{(t)} = \beta \zeta_{P_i}^{(t-1)} + (1 - \beta) \frac{1}{B} \sum_{j=1}^B \zeta_{r_{ji}} $$
    The momentum $\beta$ is typically 0.9 [S1].
5.  **Compute Calibrated Losses:**
    *   **NeRF Loss:** Weight the per-ray loss by the *pose* confidence $\zeta_{P_i}$:
        $$ L_{\text{NeRF}}(\Theta|\hat{P}, I) = \frac{\sum_i \sum_j L(r_{ji}) \zeta_{P_i}}{\sum_i \zeta_{P_i}} $$
    *   **Pose Loss:** Weight the per-ray loss by the *ray* confidence $\zeta_{r_{ji}}$: 
        $$ L_{\text{Pose}}(\hat{P}|\Theta, I) = \frac{\sum_i \sum_j L(r_{ji}) \zeta_{r_{ji}}}{\sum_i \sum_j \zeta_{r_{ji}}} $$
    *   **Total Loss:**
        $$ L_{\text{all}}(\Theta, \hat{P}|I) = L_{\text{NeRF}} + L_{\text{Pose}} + L_{\text{conf}} $$
        Where $L_{\text{conf}}$ is an additional confidence regularization term [S1].
6.  **Optimize:** Backpropagate gradients through $L_{\text{all}}$ to update $\Theta$ and $\hat{P}$ [S1].
7.  **Pose Re-initialization (Guard):** If a new pose $P_i$ fails to register (abrupt confidence drop), restart from the previous pose. Failure is declared if:
    $$ \zeta_{P_i} \le \text{mean}(\{\zeta_{P_j}\}_{j=i-K}^{i-1}) - \lambda \cdot \text{std}(\{\zeta_{P_j}\}_{j=i-K}^{i-1}) $$
    Typical values: $\lambda = 2$, $K = 10$ [S1].

**Pseudocode:**
```python
def confidence_calibrated_step(nerf_params, poses, images, beta=0.9, lam=2.0, K=10):
    L_neRF = 0.0
    L_pose = 0.0
    sum_pose_conf = 0.0
    sum_ray_conf = 0.0
    pose_confs = []

    for i, P_i in enumerate(poses):
        rays = [r for r in range(B)]  # B rays sampled per pose
        current_ray_confs = []
        current_ray_losses = []

        for j, r in enumerate(rays):
            loss_r = render_and_compute_loss(nerf_params, P_i, r, images[i])
            conf_r = compute_consistency_confidence(nerf_params, P_i, r, images[i])
            
            current_ray_losses.append(loss_r)
            current_ray_confs.append(conf_r)
            
            # Accumulate for Pose Loss (Eq 6)
            L_pose += loss_r * conf_r
            sum_ray_conf += conf_r

        # Update Pose Confidence (Eq 4)
        mean_ray_conf = sum(current_ray_confs) / len(current_ray_confs)
        prev_conf = pose_confs[i-1] if i > 0 else mean_ray_conf
        new_conf = beta * prev_conf + (1 - beta) * mean_ray_conf
        pose_confs.append(new_conf)
        
        # Accumulate for NeRF Loss (Eq 5)
        for loss_r in current_ray_losses:
            L_neRF += loss_r * new_conf
        sum_pose_conf += new_conf

    # Normalize Losses
    if sum_pose_conf > 0:
        L_neRF /= sum_pose_conf
    if sum_ray_conf > 0:
        L_pose /= sum_ray_conf

    # Pose Re-initialization Guard
    if i >= K:
        window = pose_confs[i-K:i]
        mean_w = sum(window) / len(window)
        std_w = (sum((x - mean_w)**2 for x in window) / len(window)) ** 0.5
        if new_conf < mean_w - lam * std_w:
            poses[i] = poses[i-1]  # Restart from previous pose

    # Confidence regularization term (formula not provided in sources)
    L_conf = 0.0 

    total_loss = L_neRF + L_pose + L_conf
    return total_loss, nerf_params, poses

def render_and_compute_loss(nerf_params, pose, ray, image):
    # Standard differentiable volume rendering and L2/SSIM loss computation [G]
    rendered_color = volume_render(nerf_params, pose, ray)
    return (rendered_color - image[ray]).pow(2).mean()

def compute_consistency_confidence(nerf_params, pose, ray, image):
    # Consistency metric (e.g., photometric or geometric) normalized to [0, 1] [G]
    return 1.0 / (1.0 + abs(volume_render(nerf_params, pose, ray) - image[ray]))
```

## Subtopics

### Learnable Confidence Combination
A variant that computes a robust confidence map by defining learnable weights $\omega_i$ for individual confidence metrics (e.g., RGB, SSIM, VGG, Depth, Flow) and jointly optimizing them during training [S2, unofficial]. The final confidence map is $\hat{C} = \sum_i \omega_i C_i$, subject to $\sum_i \omega_i = 1$ [S2, unofficial]. This allows the model to automatically focus on the most reliable confidence signal for a given scene or region [S2, unofficial].

## Operating characteristics
*   **Complexity:** Adds minimal overhead to the training loop, primarily involving the computation of ray/pose confidence metrics and simple averaging operations [S1].
*   **Strengths:** Prevents error propagation from poorly registered images by re-initializing failed poses [S1].
*   **Limitations:** Requires careful tuning of hyperparameters $\beta$, $\lambda$, and $K$ [S1]. Relies on the quality of the underlying confidence metrics [S1][S2, unofficial].
*   **When to use:** Joint pose and NeRF optimization where initial pose estimates may be noisy or registration fails [S1].

## Background
Introduced in the ICON (Incremental CONfidence) paper [S1], this method draws inspiration from trial-and-error registration mechanisms in incremental SfM [S1].
