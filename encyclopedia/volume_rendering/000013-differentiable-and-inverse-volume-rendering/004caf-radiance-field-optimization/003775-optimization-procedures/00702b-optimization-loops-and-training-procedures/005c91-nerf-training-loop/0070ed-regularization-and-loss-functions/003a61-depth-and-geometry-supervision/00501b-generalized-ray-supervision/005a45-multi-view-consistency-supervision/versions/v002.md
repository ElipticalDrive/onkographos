# Multi-view Consistency Supervision
## Overview
Multi-view Consistency Supervision is a regularization technique for neural radiance fields that enforces semantic and geometric consistency across different viewpoints by generating rays from unseen views and supervising their rendered colors against pseudo-ground truth [S1]. It differs from standard color loss by using uncertainty-weighted pseudo-labels derived from map priors or depth estimates, ensuring that semantic structures (e.g., road lanes) appear consistent regardless of the viewing angle [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of input images $I$, a ground depth map $D_{pgt}$ from map priors, an uncertainty parameter $\epsilon$, and a random perturbation vector norm $\|\delta\| = 0.1$ [S1].
*   **Outputs:** A scalar loss value $L_v$ [S1].

**Data Structures:**
*   $D_{pgt}$: 2D tensor of ground truth depth values [S1].
*   $\Gamma(r_i, D_i)$: Confidence function returning a scalar weight [S1].

**Steps:**
1.  **Ray Origin Perturbation:** For each input ray $r_i = o_i + t \cdot d_i$ from image $I$, perturb the origin $o_i$ by a random 3D vector $\delta$ with norm 0.1 to obtain a new origin $o'_i = o_i + \delta$ [S1].
2.  **Ray Construction:** Retrieve the 3D point $p_i$ corresponding to the ray termination in the global coordinate system using the ground depth $D_{pgt}$ [S1]. Construct a new sampled ray $r'_i$ connecting the perturbed origin $o'_i$ to the point $p_i$:
    $$ r'_i = o'_i + t \cdot \frac{p_i - o'_i}{\|p_i - o'_i\|_2} $$
    [S1]
3.  **Optional Occlusion Filtering:** Optionally filter occluded regions on $D_{pgt}$ using DPT [47] and least squares fitting [48] to ensure $D_{pgt}$ represents visible surfaces [S1].
4.  **Lane Enlargement (Optional):** If the original ray $r_i$ passes near rendered vector lanes, enlarge the supervision area according to the minimal distance to the lane [S1].
5.  **Confidence Weighting:** Compute the confidence $\Gamma(r_i, D_i)$ that the ray $r_i$ terminates on the surface of the ground:
    $$ \Gamma(r_i, D_i) = \exp\left( -\frac{\|D(r_i) - D_{pgt}\|_1}{2\epsilon} \right) $$
    where $\epsilon$ is the uncertainty parameter [S1].
6.  **Loss Calculation:** Compute the multi-view consistency loss $L_v$ by comparing the rendered color $C(r'_i)$ against the pseudo-ground truth color $C_{pgt}(r'_i)$, weighted by the confidence $\Gamma$:
    $$ L_v = \sum_{r \in I_i} \Gamma(r_i, D_{pgt}) \| C(r'_i) - C_{pgt}(r'_i) \|_2^2 $$
    [S1]

**Parameters:**
*   $\delta$: Randomly sampled 3D vector with norm 0.1 [S1].
*   $\epsilon$: Uncertainty parameter (same as used in ground density supervision) [S1].

**Edge Cases and Pitfalls:**
*   Prior online pseudo-labels [7] are insufficient due to imprecise ray termination; this method explicitly uses $D_{pgt}$ to stabilize training [S1].
*   If $D_{pgt}$ contains occluded regions, the supervision may be incorrect unless filtered [S1].

## Subtopics

### Geometry-guided View Sampling
A constraint enforcement mechanism that uses sparse Structure-from-Motion (SfM) points to validate multi-view consistency during training [S2]. It selects context views based on three thresholds: spatial overlap $\tau_s = 0.25$, scale consistency $\tau_r = 1.3$, and a minimum point count $N \ge \tau_n = 5$ across context views [S2]. This ensures that only geometrically valid and sufficiently overlapping views contribute to the multi-view constraints [S2].

## Operating characteristics
*   **Complexity:** Not given in the sources.
*   **Performance:** Improves PSNR and SSIM while reducing LPIPS compared to baseline NeRF [S1].
*   **Strengths:** Enforces semantic consistency (e.g., lanes look like lanes from any view) [S1].
*   **Limitations:** Relies on the quality of $D_{pgt}$ and map priors; requires careful tuning of $\epsilon$ [S1].

## Background
Originated in MapNeRF [S1], which incorporates map priors into neural radiance fields for driving view simulation. The method addresses the limitation of online pseudo-labels [7] by using explicit ground depth and uncertainty weighting to stabilize training [S1].
