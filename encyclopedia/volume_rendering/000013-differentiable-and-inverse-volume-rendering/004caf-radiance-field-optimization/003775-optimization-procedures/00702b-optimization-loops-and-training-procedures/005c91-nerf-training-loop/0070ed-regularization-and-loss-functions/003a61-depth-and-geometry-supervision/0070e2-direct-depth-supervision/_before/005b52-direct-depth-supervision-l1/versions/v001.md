# Direct Depth Supervision (L1)
Also called: Depth Loss, L1 Depth Loss

## Overview
Direct Depth Supervision (L1) is a regularization term applied during the training of radiance fields that minimizes the discrepancy between the depth map rendered by the neural network and a provided ground truth depth prior [S2]. Unlike photometric losses that enforce color consistency, this method explicitly constrains the geometric structure of the scene [S2]. It is distinguished from other depth supervision techniques, such as L2 depth loss or consistency losses, by its use of the mean absolute error metric, which is less sensitive to outliers in depth prediction [S1, unofficial][S2].

## How it works
**Inputs and Outputs**
- **Inputs**:
  - $\lambda$: The predicted depth value for a specific pixel or sample point [S2].
  - $\lambda_{GT}$: The ground truth depth value corresponding to the same pixel or point [S2].
  - $S_1$: The set of pixels containing valid depth information [S1, unofficial].
- **Outputs**:
  - $\mathcal{L}_D$: The scalar depth loss value [S2].

**Data Structures**
- Depth maps are typically stored as 2D arrays of floating-point values, where each element corresponds to the distance from the camera center to the first surface intersection along the viewing ray [S1, unofficial].
- Validity masks are used to exclude background or invalid pixels from the loss calculation [S1, unofficial].

**Steps**
1. Render the depth map from the current NeRF state for the given camera pose.
2. Align the rendered depth map with the ground truth depth map, ensuring pixel-wise correspondence [S1, unofficial].
3. Identify the set of valid pixels $S_1$ where both rendered and ground truth depths are defined and non-zero [S1, unofficial].
4. Compute the absolute difference between the predicted depth $D_{\hat{s}}$ and ground truth depth $D_s$ for each valid pixel $s \in S_1$ [S1, unofficial].
5. Sum the absolute differences and normalize by the number of valid pixels [S1, unofficial].

**Formula**
The loss is defined as the mean L1 norm of the depth error:
$$ \mathcal{L}_D(\lambda) = \| \lambda - \lambda_{GT} \|_1 $$
[S2]

In the context of a full image or batch, this is expanded as:
$$ \mathcal{L}_{depth} = \frac{1}{|S_1|} \sum_{s \in S_1} | D_{\hat{s}} - D_s | $$
[S1, unofficial]

Where:
- $|S_1|$ is the number of pixels with valid depth [S1, unofficial].
- $D_s$ is the ground truth depth for pixel $s$ [S1, unofficial].
- $D_{\hat{s}}$ is the predicted depth for pixel $s$ [S1, unofficial].

**Parameters**
- Weight $w_d$: The coefficient scaling the depth loss in the total training objective. Typical values are not specified in the sources [S2].

**Edge Cases and Pitfalls**
- **Invalid Depth**: Pixels with no ground truth depth (e.g., background) must be excluded from the sum to prevent biasing the gradient [S1, unofficial].
- **Scale Ambiguity**: If the ground truth depth is not metrically accurate or scaled correctly relative to the NeRF's coordinate system, the loss may converge to a geometrically incorrect solution [S2].
- **Precision**: Floating-point precision issues may arise when depth values vary significantly in magnitude across the scene [S1, unofficial].

**Pseudocode**
```python
def compute_l1_depth_loss(rendered_depth, ground_truth_depth, valid_mask):
    """
    Computes the L1 depth loss.
    
    Args:
        rendered_depth: 2D array of predicted depth values.
        ground_truth_depth: 2D array of ground truth depth values.
        valid_mask: 2D boolean array indicating valid depth pixels.
        
    Returns:
        scalar: The mean L1 depth loss.
    """
    # Select valid pixels
    valid_rendered = rendered_depth[valid_mask]
    valid_gt = ground_truth_depth[valid_mask]
    
    # Compute number of valid pixels
    num_valid = valid_mask.sum()
    
    # Handle edge case where no valid pixels exist
    if num_valid == 0:
        return 0.0
        
    # Compute absolute differences
    abs_diffs = abs(valid_rendered - valid_gt)
    
    # Compute mean
    loss = abs_diffs.sum() / num_valid
    
    return loss
```

## Operating characteristics
- **Time Complexity**: $O(N)$, where $N$ is the number of valid pixels, as it requires a single pass over the depth map [S1, unofficial].
- **Memory Complexity**: $O(N)$ to store the depth maps and masks [S1, unofficial].
- **Strengths**: Robust to outliers in depth prediction due to the L1 norm [S2]. Provides direct geometric supervision [S2].
- **Limitations**: May result in less smooth depth maps compared to L2 loss [S2]. Requires accurate ground truth depth data [S2].
- **When to Use**: When metric depth accuracy is critical and ground truth depth is available [S2].
- **When Not to Use**: When ground truth depth is unavailable or noisy [S2].

## Background
The L1 depth loss is a standard component in inverse rendering frameworks that utilize signed distance functions (SDFs) or depth maps [S2]. It was employed in the FIRe framework for fast inverse rendering [S2]. The concept of using L1 norms for depth estimation is well-established in computer vision [S1, unofficial].
