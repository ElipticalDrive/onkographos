# Guided Optimization of NeRF

Also called: Confidence-Based Depth Filtering

## Overview
Guided Optimization of NeRF mitigates shape-radiance ambiguity in indoor scenes by constraining the sampling range of Neural Radiance Fields (NeRF) using adapted monocular depth priors [S1]. Unlike standard NeRF, which samples uniformly between near and far bounds derived from sparse reconstruction, this method calculates adaptive bounds based on multi-view consistency errors of the depth priors, ensuring samples concentrate around plausible geometry even in textureless regions [S1]. It sets itself apart from [Depth and Geometry Supervision](8727-depth-and-geometry-supervision.md) methods that apply explicit geometric losses by instead guiding the *sampling distribution* itself, thereby preventing the network from exploring degenerate geometric solutions that still fit the RGB data [S1].

## How it works
**Inputs:** $N$ input views with RGB images, camera intrinsics $K$, relative poses $T^{i \to j}$, and a pre-computed set of adapted monocular depth priors $\{D^i\}_{i=1}^N$ for each view [S1].
**Outputs:** A trained NeRF model $F_\theta: (\mathbf{x}, \mathbf{d}) \to (\mathbf{c}, \sigma)$ and a refined depth map [S1].

**Data Structures:**
*   **Adapted Depth Priors:** A set of depth maps $D^i$ for each view $i$.
*   **Error Maps:** A set of scalar maps $e_i$ per view, where each pixel value represents the average of the $K$ minimum cross-view reprojection errors [S1].
*   **NeRF Model:** A multi-layer perceptron (MLP) parameterized by $\theta$, taking 3D position $\mathbf{x}$ and viewing direction $\mathbf{d}$ as input, outputting color $\mathbf{c}$ and density $\sigma$ [S1].

**Parameters:**
*   $K=4$: Number of minimum cross-view depth projection errors used to compute the error map [S1].
*   $\alpha_l = 0.05$: Lower bound for the relative sampling range expansion [S1].
*   $\alpha_h = 0.15$: Upper bound for the relative sampling range expansion [S1].
*   $M$: Number of sample points per ray (standard NeRF default, e.g., 64 or 128) [S1].

**Steps:**

1.  **Compute Error Maps:**
    For each view $i$, project its depth map $D^i$ to all other views $j \neq i$ using the camera intrinsics $K$ and relative pose $T^{i \to j}$ to obtain projected depth $D^{i \to j}$ [S1].
    Calculate the relative reprojection error for each pixel. The error map value $e_i$ for a pixel in view $i$ is defined as the average of the $K$ minimum cross-view depth projection errors [S1].

2.  **Calculate Adaptive Sample Ranges:**
    For each ray $\mathbf{r}$ corresponding to a pixel in view $i$, let $D$ be the adapted depth prior value at that pixel, and $e$ be the error map value $e_i$ at that pixel [S1].
    Compute the near bound $t_n$ and far bound $t_f$ using the clamping function:
    $$ t_n = D(1 - \text{clamp}(e, \alpha_l, \alpha_h)) $$
    $$ t_f = D(1 + \text{clamp}(e, \alpha_l, \alpha_h)) $$
    where $\text{clamp}(x, a, b) = \max(a, \min(b, x))$ [S1].
    *Note:* If the error $e$ is small, the range $[t_n, t_f]$ is narrow, concentrating samples near the prior. If $e$ is large, the range expands towards the original NeRF bounds [S1].

3.  **Stratified Sampling:**
    Partition the interval $[t_n, t_f]$ into $M$ bins. For each bin $k \in [1, M]$, sample a point $t_k$ uniformly from the bin interval:
    $$ t_k \sim \mathcal{U} \left[ t_n + \frac{k-1}{M}(t_f - t_n), \,\, t_n + \frac{k}{M}(t_f - t_n) \right] $$
    The 3D position is $\mathbf{x}_k = \mathbf{r}(t_k)$ [S1].

4.  **Volume Rendering:**
    Query the NeRF for density $\sigma_k$ and color $\mathbf{c}_k$ at each sample point $\mathbf{x}_k$ [S1].
    Compute the accumulated transmittance $T_k$:
    $$ T_k = \exp \left( -\sum_{j=1}^{k-1} \sigma_j \delta_j \right) $$
    where $\delta_j = t_{j+1} - t_j$ is the distance between adjacent samples [S1].
    Render the color $\hat{\mathbf{C}}(\mathbf{r})$ and depth $\hat{D}(\mathbf{r})$:
    $$ \hat{\mathbf{C}}(\mathbf{r}) = \sum_{k=1}^{M} T_k (1 - e^{-\sigma_k \delta_k}) \mathbf{c}_k $$
    $$ \hat{D}(\mathbf{r}) = \sum_{k=1}^{M} T_k (1 - e^{-\sigma_k \delta_k}) t_k $$
    [S1]

5.  **Compute Confidence Scores:**
    Calculate the confidence score $S^i_j$ for pixel $j$ in view $i$ based on the $L_1$ difference between the ground truth RGB image $C_{gt}^i(j)$ and the rendered RGB image $C_{render}^i(j)$, normalized by 255:
    $$ S^i_j = 1 - \frac{1}{3} \| C_{gt}^i(j) - C_{render}^i(j) \|_1 $$
    The $L_1$ norm is taken over the 3 color channels [S1].

6.  **Depth Refinement (Post-Processing):**
    Apply plane bilateral filtering to the rendered depth map, weighted by the confidence scores $S^i_j$, to produce the final depth output [S1].

7.  **Optimization Loop:**
    Backpropagate the loss (typically RGB reconstruction loss) through the differentiable volume rendering process to update the network parameters $\theta$ [S1].

## Subtopics

### [ENeRF with Guided Sampling Training](7580-enerf-with-guided-sampling-training.md)
Integrates pixel-region and depth-boundary-guided ray sampling into the Efficient NeRF framework to reduce GPU memory consumption and improve sampling efficiency compared to uniform strategies.

## Operating characteristics
**Time and Memory Complexity:** The method adds overhead for computing multi-view consistency error maps (projection and interpolation) and requires storing adapted depth priors. The sampling step is slightly more complex than uniform sampling due to adaptive bounds, but the number of samples $M$ remains the same. The core volume rendering complexity is unchanged [S1].
**Measured Performance:** On the ScanNet dataset, the method outperforms state-of-the-art depth estimation methods in all metrics, including those trained with ground truth depth supervision (e.g., DeepV2D, DELTAS, Atlas) [S1]. It significantly improves depth estimation quality over original NeRF, particularly in indoor scenes [S1].
**Strengths:** Effectively mitigates shape-radiance ambiguity in poorly textured indoor areas (e.g., walls) where standard NeRF fails [S1]. It allows accurate depth estimation by directly optimizing over RGB images without requiring explicit geometric loss terms during training [S1].
**Limitations:** Relies on the quality of the adapted monocular depth priors. Applying existing correspondence-based neural optimization (like CVD) to these priors can degrade quality due to unreliable flow correspondences in textureless regions [S1].
**When to use:** Indoor multi-view stereo and depth estimation where texture is sparse and shape-radiance ambiguity is high [S1].
**When not to use:** Scenes with rich texture where standard NeRF sampling is sufficient, or when high-quality monocular depth priors are not available [S1].

## Background
The method was proposed in "Depth-Guided Optimization of Neural Radiance Fields for Indoor Multi-View Stereo" [S1]. It addresses the limitation of original NeRF [33], which assumes that correct geometry is favored due to smoother surface light fields, an assumption that fails in poorly textured indoor environments [S1]. The authors observed that NeRF can synthesize high-quality RGB images with incorrect geometry in such areas, leading to depth deviation from ground truth [S1]. The method builds on adapted monocular depth priors (finetuned on the target scene) and guides the NeRF sampling process to avoid degenerate cases [S1].
