# Adaptive View Selection for Inpainting

Also called: 3D Inpainting Component, 3D Inpainting Component with Adaptive View Selection, Adaptive Weight Inpainting, Gradient-Based View Selection

## Overview
This method addresses inconsistency artifacts inherent in applying 2D inpainting priors directly to 3D NeRF representations by introducing a training view selection mechanism based on regional average gradients [S1]. Unlike methods that uniformly blend 2D priors or rely solely on multi-view geometry, this approach adaptively switches between using 2D inpainted appearance priors and multi-view geometric consistency based on local texture richness [S1]. It is chosen when a pre-trained NeRF requires object removal or de-occlusion where maintaining multi-view consistency is critical to prevent flickering or geometric conflicts [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A pre-trained NeRF model $f_\theta$ (typically a coarse and fine MLP pair, denoted $\hat{C}_c$ and $\hat{C}_f$), a set of input views with known camera poses, a binary mask $M$ identifying occluded/removed regions in the input views, and a 2D inpainter (e.g., LaMa) [S1].
*   **Outputs:** Updated NeRF parameters $\theta$ that reconstruct the scene with the occluded region filled in consistently across all views [S1].

**Data Structures:**
*   **Mask $\hat{P}(r)$:** A predicted mask value for ray $r$, indicating the probability that the ray passes through the occluded region [S1].
*   **Sub-regions:** The occluded area in each view is divided into multiple sub-regions (patches) to evaluate local texture gradients individually [S1].
*   **2D Inpainting Prior $C_l(r)$:** The color value of the pixel corresponding to ray $r$ in the image generated by the 2D inpainter for the occluded region [S1].

**Numbered Steps:**
1.  **Initial 2D Inpainting:** Use a pretrained 2D image inpainter (e.g., LaMa) to generate appearance priors $C_l$ for the occluded areas in the input views [S1].
2.  **Mask Generation:** Use an object segmentation network to automatically infer binary masks $M$ for occluded regions across all views [S1].
3.  **Sub-region Division:** Divide the occluded area in each view into multiple sub-regions (patches) [S1].
4.  **Gradient Evaluation:** For each sub-region, calculate the average gradient of the rendered result ($\nabla \hat{g}$) and the average gradient of the 2D inpainting result ($\nabla g$) [S1].
5.  **Adaptive Weight Calculation:** Determine the adaptive weight $\lambda$ for the reconstruction loss based on the gradient comparison [S1]:
    $$
    \lambda = \begin{cases} 
    1 & \text{if } \nabla \hat{g} > \tau \cdot \nabla g \\
    0 & \text{if } \nabla \hat{g} \le \tau \cdot \nabla g 
    \end{cases}
    $$
    Here, $\tau$ is a threshold parameter [S1]. If the rendered texture is richer than the 2D prior (scaled by $\tau$), the method trusts the multi-view geometry ($\lambda=1$); otherwise, it relies on the 2D prior ($\lambda=0$) [S1].
6.  **Loss Computation:** Compute the total reconstruction loss $L$ as a weighted sum of non-occluded loss $L_{NonOcc}$ and occluded loss $L_{Occ}$ [S1]:
    $$
    L = \lambda L_{NonOcc} + (1 - \lambda) L_{Occ}
    $$
7.  **Optimization:** Update the NeRF parameters $\theta$ by minimizing $L$ [S1].

**Formulas:**
*   **Reconstruction Loss for Non-Occluded Areas ($L_{NonOcc}$):**
    $$
    L_{NonOcc} = \sum_{r \in R} (1 - \hat{P}(r)) \left[ ||\hat{C}_c(r) - C(r)||_2^2 + ||\hat{C}_f(r) - C(r)||_2^2 \right]
    $$
    Where $R$ is the set of rays, $\hat{P}(r)$ is the mask value, $\hat{C}_c(r)$ and $\hat{C}_f(r)$ are the coarse and fine predicted colors, and $C(r)$ is the ground truth color [S1].
*   **Reconstruction Loss for Occluded Areas ($L_{Occ}$):**
    $$
    L_{Occ} = \sum_{r \in R} \hat{P}(r) \left[ ||\hat{C}_c(r) - C_l(r)||_2^2 + ||\hat{C}_f(r) - C_l(r)||_2^2 \right]
    $$
    Where $C_l(r)$ is the color from the 2D inpainting prior [S1].
*   **Depth Loss (for segmentation network training):**
    $$
    L_{depth} = \sum_{r \in R} ||\hat{D}(r) - D(r)||_2^2
    $$
    Where $\hat{D}(r)$ is the rendered depth and $D(r)$ is the ground truth depth [S1].

**Parameters:**
*   $\tau$: Threshold for gradient comparison. Not given in the sources.
*   $\lambda_1, \lambda_2, \lambda_3$: Weights for the segmentation network loss components ($L_{region-encoding}, L_{rgb}, L_{depth}$) [S1].

**Pseudocode:**
```python
def compute_adaptive_inpainting_loss(nerf_model, rays, gt_colors, gt_masks, priors_2d, tau):
    """
    Computes the adaptive reconstruction loss for NeRF inpainting.
    
    Args:
        nerf_model: Pre-trained NeRF model with .render_coarse(rays) and .render_fine(rays).
        rays: List of ray objects with .pixel_index (tuple of int).
        gt_colors: Tensor of shape (H, W, 3) containing ground truth colors.
        gt_masks: Tensor of shape (H, W) containing binary occlusion masks (1=occluded).
        priors_2d: Tensor of shape (H, W, 3) containing 2D inpainted priors.
        tau: Threshold for gradient-based view selection.
        
    Returns:
        total_loss: The computed adaptive loss.
    """
    # 1. Render NeRF predictions
    pred_c = nerf_model.render_coarse(rays)
    pred_f = nerf_model.render_fine(rays)
    
    # 2. Extract 2D priors for rays
    priors = torch.stack([priors_2d[r.pixel_index] for r in rays])
    
    # 3. Compute average gradients over the occluded region
    occluded_mask = gt_masks.flatten() == 1
    if occluded_mask.sum() == 0:
        return torch.tensor(0.0)
        
    occluded_pred_c = pred_c[occluded_mask]
    occluded_pred_f = pred_f[occluded_mask]
    occluded_prior = priors[occluded_mask]
    
    # Compute average gradient magnitude for rendered and prior colors
    grad_rendered = compute_average_gradient(occluded_pred_c, occluded_pred_f)
    grad_prior = compute_average_gradient(occluded_prior)
    
    # 4. Determine adaptive weight lambda
    lambda_val = 1.0 if grad_rendered > tau * grad_prior else 0.0
    
    # 5. Compute Non-Occluded Loss (sum over rays)
    non_occ_mask = gt_masks.flatten() == 0
    if non_occ_mask.sum() > 0:
        non_occ_pred_c = pred_c[non_occ_mask]
        non_occ_pred_f = pred_f[non_occ_mask]
        non_occ_gt = torch.stack([gt_colors[r.pixel_index] for r, m in zip(rays, non_occ_mask) if m])
        loss_non_occ = torch.sum((non_occ_pred_c - non_occ_gt)**2 + (non_occ_pred_f - non_occ_gt)**2)
    else:
        loss_non_occ = torch.tensor(0.0)
        
    # 6. Compute Occluded Loss (sum over rays)
    if occluded_mask.sum() > 0:
        loss_occ = torch.sum((occluded_pred_c - occluded_prior)**2 + (occluded_pred_f - occluded_prior)**2)
    else:
        loss_occ = torch.tensor(0.0)
        
    # 7. Combine losses
    total_loss = lambda_val * loss_non_occ + (1 - lambda_val) * loss_occ
    return total_loss

def compute_average_gradient(color_tensor_c, color_tensor_f):
    """
    Computes the mean gradient magnitude across the spatial domain of the occluded region.
    color_tensor_c, color_tensor_f: Tensors of shape (N, 3) for occluded pixels.
    """
    # Flatten to 2D grid approximation for gradient estimation
    # In practice, this operates on the (H, W, 3) tensor before ray sampling
    # Here we approximate using finite differences along the flattened sequence
    # as a placeholder for the spatial patch gradient calculation [G].
    grad_c = torch.abs(color_tensor_c[1:] - color_tensor_c[:-1])
    grad_f = torch.abs(color_tensor_f[1:] - color_tensor_f[:-1])
    return (grad_c.mean() + grad_f.mean()) / 2.0
```

**Edge Cases and Pitfalls:**
*   **Uniform Strategy Misjudgment:** Applying a uniform strategy to the entire occluded area can lead to misjudgment [S1]. The method avoids this by dividing the occluded area into sub-regions and evaluating gradients individually [S1].
*   **2D Inpainter Inconsistency:** Single 2D image inpainting does not consider consistency in the real 3D scene [S1]. The method addresses this by selecting training views based on texture richness to ensure multi-view consistency [S1].
*   **Gradient Calculation:** The gradient $\nabla \hat{g}$ and $\nabla g$ must be calculated as *average* gradients over sub-regions, not per-pixel, to accurately reflect texture richness [S1].

## Subtopics

### Weder et al. Inpainting
Updates the set of images used for optimization iteratively based on confidence scores to maintain consistency during inpainting [S2]. Selectively excludes views using an uncertainty mechanism and a pixelwise loss [S2].

## Operating characteristics
*   **Time Complexity:** Depends on the number of rays, the number of sub-regions, and the cost of the 2D inpainter [G]. The adaptive weight calculation adds a gradient computation step per sub-region [G].
*   **Memory Complexity:** Requires storing the NeRF model, the 2D inpainted images, and the mask predictions [G].
*   **Strengths:** Effectively reduces the disturbing effect of 2D inpainters on 3D editing by leveraging multi-view correlation [S1]. It adapts to local texture richness, providing better detail recovery in complex areas [S1].
*   **Limitations:** Relies on the quality of the 2D inpainter and the accuracy of the segmentation mask [S1]. Performance depends on the availability of multi-view data; if no other views can provide supplementary information, it falls back to the 2D prior [S1].
*   **When to use:** When performing object removal or de-occlusion in NeRFs where multi-view consistency is crucial and the occluded region has varying texture complexity [G].
*   **When not to use:** When the scene has very limited multi-view coverage or when the 2D inpainter produces highly inaccurate priors that cannot be corrected by gradient-based selection [G].

## Background
The method was proposed in the paper "3D Scene De-occlusion in Neural Radiance Fields: A Framework for Obstacle Removal and Realistic Inpainting" [S1]. It addresses the limitations of previous 3D inpainting methods that either ignored multi-view consistency or applied 2D priors uniformly [S1]. The work builds on the NeRF representation [S1] and uses LaMa as the 2D inpainter [S1]. It has been evaluated on datasets like LLFF and SPIn-NeRF [S1].
