# DFF (Decomposing NeRF for Editing Via Feature Field Distillation)

Also called: Feature Field Distillation, LSeg-DFF, DINO-DFF

## Overview
DFF enables 3D semantic segmentation and editable novel-view synthesis by distilling features from a pre-trained 2D teacher network (such as LSeg or DINO) into a neural radiance field [S1]. It solves the problem that standard NeRF feature spaces are entangled with low-level factors like color or spatial adjacency rather than semantic similarity, making naive decomposition unreliable [S1]. Unlike methods that rely on semantic labels during training, DFF achieves this through unsupervised distillation, allowing for zero-shot text-based or image-patch-based editing without retraining the underlying radiance field geometry [S1].

## How it works
**Inputs:**
*   A set of posed training images $I_r$ with camera poses $r$ [S1].
*   A pre-trained NeRF radiance field $f_\theta$ (or a newly trained one) [S1].
*   A 2D teacher network (LSeg or DINO) and its associated query mechanism (text prompt for LSeg, image patch for DINO) [S1].

**Outputs:**
*   A decomposed NeRF representation consisting of a radiance field (density $\sigma$ and color $\mathbf{c}$) and a feature field $\mathbf{f}$ [S1].
*   Semantic segmentation probabilities for any 3D point or 2D pixel [S1].

**Data Structures:**
The implementation uses two primary neural network architectures:

1.  **Radiance Field MLP ($f_\theta$):**
    *   Input: Positional encoded coordinate $\mathbf{x}$ and viewing direction $\mathbf{d}$ [S1].
    *   Structure: 8 hidden ReLU layers with 256 dimensions [S1].
    *   Outputs:
        *   Density $\sigma$: Linear layer (1 output) [S1].
        *   Color $\mathbf{c}$: 3 hidden layers (256 dims) $\to$ Linear layer (3 outputs, RGB) [S1].
        *   Feature $\mathbf{f}$: 3 hidden layers (256 dims) $\to$ Linear layer (output dim depends on teacher, e.g., 256 for DINO, 128 for LSeg) [S1].
    *   *Note:* In the "branch-based" variant, the feature branch shares the first 8 layers with the radiance field [S1]. In the "independent" variant, the feature field is a separate MLP [S1].

2.  **Independent Feature Field MLP (Optional):**
    *   Used to avoid retraining the radiance field [S1].
    *   Structure: 4 hidden layers [S1].
    *   Skip connection: Added at the 3rd layer if positional encoding is used [S1].
    *   Input: Positional encoded coordinate $\mathbf{x}$ (and optionally $\mathbf{d}$) [S1].
    *   Output: Feature vector $\mathbf{f}$ [S1].

**Positional Encoding:**
*   Input coordinate $\mathbf{x}$: Length 10 [S1].
*   Viewing direction $\mathbf{d}$: Length 4 [S1].
*   Skip connections: Applied to the input coordinate [S1].

**Sampling Strategy:**
*   **Coarse MLP:** Stratified sampling with $N_c = 64$ points [S1].
*   **Fine MLP:** Importance sampling with $N_f = 128$ points (total 192 points including coarse) [S1].
*   *Distillation Note:* Feature fields are trained using **coarse sampling** to ensure smoothness [S1]. Rendering for editing uses **fine sampling** [S1].

**Training Phases:**

1.  **Phase 1: Radiance Field Training (Standard NeRF)**
    *   Train the radiance field $f_\theta$ for 200,000 iterations [S1].
    *   Loss: Photometric loss $L_p$ (e.g., $L_1$ or SSIM between rendered and input images) [S1].
    *   Optimizer: Adam, linearly decaying learning rate from $5 \times 10^{-4}$ to $8 \times 10^{-5}$ [S1].
    *   Regularization: Gaussian noise added to density [S1].
    *   Batch size: 1024 rays (Replica) or 2048 rays (others) [S1].
    *   Image resolution: 320×240 (Replica) or 1008×756 (others) [S1].

2.  **Phase 2: Feature Field Distillation (Finetuning)**
    *   Initialize feature branch (either attached to radiance field or independent) [S1].
    *   Remove Gaussian noise from density [S1].
    *   Set learning rate to $1 \times 10^{-4}$ [S1].
    *   Train for 5,000 iterations [S1].
    *   Loss: $L = L_p + \lambda L_f$ [S1].
    *   *Note:* Feature loss converges significantly faster than photometric loss; thus, short training is sufficient [S1]. Excessively increasing $\lambda$ (e.g., $\times 10$) degrades view synthesis without improving segmentation [S1].

**Feature Distillation Loss ($L_f$):**
The feature loss minimizes the distance between the rendered feature $\mathbf{f}_{render}$ and the target teacher feature $\mathbf{f}_{img}$ [S1].

$$
L_f = \sum_{r} \sum_{i \in \text{pixels}} \| \mathbf{f}_{render}(r, i) - \mathbf{f}_{img}(I_r, r, i) \|^2
$$

Where:
*   $\mathbf{f}_{img}(I_r, r, i)$ is the feature map from the teacher network for image $I_r$ at pixel $i$ [S1].
*   Teacher feature maps are resized to the original image size to match the NeRF pixel grid [S1].
*   $\mathbf{f}_{render}$ is obtained by volume rendering the feature field $\mathbf{f}$ along the ray, similar to color rendering:
    $$
    \mathbf{f}_{render} = \sum_{j=1}^{N} T_j (1 - \alpha_j) \mathbf{f}_j
    $$
    where $T_j$ is the accumulated transmittance and $\alpha_j$ is the opacity at sample $j$ [S1].

**Semantic Probability Calculation:**
To perform segmentation or editing, the probability $p$ that a 3D point (or rendered pixel) belongs to a query is computed differently for LSeg and DINO [S1].

1.  **LSeg (Text Query):**
    *   Encode text label $t$ using LSeg text encoder to get $\mathbf{t}_{vec}$ [S1].
    *   Compute cosine similarity between rendered feature $\mathbf{f}_{render}$ and $\mathbf{t}_{vec}$ [S1].
    *   Probability $p$ is derived via softmax over all possible labels (Equation 22 in [S1]) [S1].

2.  **DINO (Image Patch Query):**
    *   Select a query patch from an image [S1].
    *   Compute patch feature $\mathbf{q}$ by averaging DINO features of all pixels in the patch [S1].
    *   Compute cosine similarity between $\mathbf{f}_{render}$ and $\mathbf{q}$ [S1].
    *   **Hard Decomposition:** If similarity $> \tau$ (threshold), $p=1$; else $p=0$ [S1].
    *   *Note:* DINO does not use softmax with negative queries; it uses direct thresholded cosine similarity [S1].

**Edge Cases and Pitfalls:**
*   **Feature Loss Weight:** Excessively increasing the feature loss weight ($\lambda \times 10$) hurts view synthesis quality without improving segmentation [S1].
*   **Sampling Mismatch:** Using fine sampling for training feature fields introduces high-frequency artifacts. Coarse sampling is preferred for smooth decomposition [S1].
*   **Naive NeRF Features:** Using hidden layers of the original NeRF (e.g., the 8th layer) for decomposition is not robust; selections leak to regions with similar color/geometry but different semantics [S1].
*   **Deletion Artifacts:** Deleting foreground objects may leave floating artifacts and blurred volumes in the far distance behind the object [S1].
*   **Training Duration:** Feature loss converges much faster than photometric loss; 5K iterations is sufficient for distillation [S1].

## Operating characteristics
*   **Time Complexity:** Distillation phase is short (5,000 iterations) compared to initial training (200,000 iterations) [S1].
*   **Memory Complexity:** Branch-based DFF adds minimal overhead (3 extra layers). Independent DFF adds a separate small MLP (4 layers) [S1].
*   **Performance:** DFF achieves 3D semantic segmentation performance comparable to or better than supervised sparse 3D convolution models (e.g., MinkowskiNet) [S1].
*   **Strengths:**
    *   Enables zero-shot text-based and image-patch-based editing [S1].
    *   Multi-view consistent results for deletion/extraction, unlike 2D inpainting baselines (LaMa) [S1].
    *   Independent feature field allows adding semantics to existing NeRFs without retraining geometry [S1].
*   **Limitations:**
    *   Struggles with "volume decomposition" smoothness if fine sampling is used for training features [S1].
    *   Deletion can leave artifacts in occluded background regions [S1].
    *   Original NeRF features are not semantically meaningful [S1].

## Background
DFF was introduced in the paper "Decomposing NeRF for Editing Via Feature Field Distillation" [S1]. It addresses the limitations of editable NeRFs, which previously struggled with surface decomposition, volume decomposition, and estimating unobserved parts [S1]. The method leverages pre-trained 2D vision-language models (LSeg) and self-supervised models (DINO) as teachers to distill semantic information into the 3D field, bypassing the need for 3D semantic labels during training [S1].
