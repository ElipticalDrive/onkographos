# Local Editing via SAM and Depth Propagation

Also called: Depth-propagated Mask Editing, SAM-based NeRF Editing

## Overview
A technique to edit specific objects within a NeRF without altering the background, using 2D segmentation masks propagated across views via depth information [S1]. It solves the problem where existing methods induce simultaneous changes in both background and foreground, contradicting user intentions to alter distinct objects [S1]. It sets itself apart by using depth-based reprojection to ensure multi-view consistency of the segmentation mask, allowing exclusive modification of the target instance while leaving the background intact [S1]. Builds on [NeRF Editing Procedure](12491-nerf-editing-procedure.md).

## How it works
**Inputs:** A trained NeRF, depth maps for each view, and a user interaction point on a target object in one or more views [S1].
**Outputs:** A modified NeRF where the target object is edited while the background remains unchanged [S1].
**Data structures:** Not given in the sources.
**Steps:**
1. **Initial Segmentation:** Employ the Segment Anything Model (SAM) to derive masks encompassing all components within each image [S1].
2. **User Selection:** Users pinpoint the target instance with a single point to isolate it [S1].
3. **Key View Selection:** Designate nearly all views as key views to facilitate propagation [S1].
4. **Depth-Based Projection:** Utilize depth information to project the identified mask across different views progressively [S1]. Standard 3D reprojection maps pixels from a source view to a target view using camera intrinsics and extrinsics [G].
5. **Reprojection Check:** Continue the projection process as long as the projected mask sufficiently overlaps with the corresponding mask in the current view [S1].
6. **Mask Integration:** Integrate the wrapped segmentation mask with the segmented masks in the current view [S1]. This results in a multi-view consistent segmentation mask set [S1].
7. **Editing:** Apply the editing operation constrained by the integrated masks to modify only the target object [S1].
**Formulas:** Not given in the sources.
**Parameters:** Overlap threshold for sufficient overlap is not explicitly defined in the sources [S1]. Key view density designates nearly all views as key views, which leads to reduced efficiency [S1].
**Edge Cases and Pitfalls:** Incorrect depth estimation is handled robustly as long as the NeRF is built successfully, demonstrated on glossy surfaces and sparser views [S1]. Existing methods often induce simultaneous changes in both background and foreground, contradicting user intentions to alter distinct objects [S1].

## Subtopics

### MaskEditor
A grid-based 3D editing method using a 3D mask grid trained on 2D masks from SAM [S2]. It introduces a 3D mask grid trained on the 2D masks from SAM to locate the target object accurately [S2]. Instead of utilizing SDS, it employs Variational Score Distillation (VSD) along with composited rendering and a coarse-to-fine editing strategy to improve editing quality [S2].

## Operating characteristics
*   **Efficiency:** Designating nearly all views as key views leads to reduced efficiency [S1].
*   **Robustness:** The method demonstrates robustness to incorrect depth estimation, handling glossy surfaces and sparse input views (e.g., 20% or 50% of views) effectively [S1].
*   **Consistency:** It achieves multi-view consistent segmentation, permitting exclusive modification of the target object without changing the background [S1].

## Background
Originated in ViCA-NeRF (View-Consistency-Aware 3D Editing of Neural Radiance Fields) [S1]. The method addresses the discrepancy in existing methods that fail to isolate foreground edits from background changes [S1]. It builds on the Segment Anything Model (SAM) and leverages depth information for view consistency [S1].
