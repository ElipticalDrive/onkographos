# Reference-guided Controllable Inpainting of NeRFs

Also called: Reference-guided Inpainting

## Overview
A 3D inpainting algorithm that uses a single inpainted reference view to guide the geometry and appearance of a NeRF, avoiding view inconsistencies and generating view-dependent effects [S2]. It differs from multi-view inpainting methods by requiring only one edited image as input, relying on monocular depth estimation for geometry and a bilateral solver for view-dependent consistency, whereas methods like [NeRF-In Inpainting Optimization](12372-nerf-in-inpainting-optimization.md) typically optimize directly against multiple views or text prompts without a specific single-reference guidance mechanism [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** $n$ input images $\{I_i\}_{i=1}^n$, camera transform matrices $\{\Pi_i\}_{i=1}^n$, masks $\{M_i\}_{i=1}^n$ delineating unwanted regions, and a single inpainted reference view $I_r$ where $r \in \{1, ..., N\}$ [S2].
*   **Outputs:** An optimized NeRF $f_\theta$ that represents the scene with the object removed and the reference view's content extended consistently across all views [S2].

**Data Structures:**
*   **NeRF $f_\theta$:** Standard MLP mapping 3D coordinates and viewing directions to density $\sigma$ and color $C$.
*   **Ray Set $R$:** Set of rays generated from camera poses.
*   **Mask $M_i$:** Binary mask for each input image $I_i$.

**Parameters:**
*   $N_{depth}$: Number of iterations for initial unmasked supervision.
*   $N_{bilateral}$: Iteration interval for bilateral solver updates.
*   $N_{do}$: Iteration interval for disocclusion handling.
*   $\gamma_{depth}, \gamma_{rec}, \gamma_{do}$: Loss weights.

**Steps:**

1.  **Initialization:** Initialize NeRF $f_\theta$.
2.  **Stage 1: Unmasked Supervision:** Supervise $f_\theta$ on unmasked pixels for $N_{depth}$ iterations using the standard NeRF reconstruction loss $L_{rec}^{unmasked}$. The masked region remains under-fit to allow altering masked values in later stages [S2].
    $$L_{rec}^{unmasked} = \mathbb{E}_{r \sim R_{unmasked}} \| \hat{C}(r) - C_{GT}(r) \|^2$$
    where $R_{unmasked}$ is the set of rays corresponding to pixels in $\{I_i(1 - M_i)\}_{i=1}^n$ and $C_{GT}(r)$ is the ground truth color [S2].
3.  **Geometry Supervision:** Use monocular depth estimators to back-project the inpainted reference view $I_r$ to 3D positions. Compute a disparity map, align it with the current inpainted NeRF scene, and use it for masked depth supervision via $L_{depth}^{masked}$ [S2].
4.  **View-Dependent Effects (VDEs):** Use a view-substitution technique followed by bilaterally guided inpainting to obtain target colors $I_{br,t}$ for non-reference views. These are used for $L_{rec}^{masked}$ [S2].
5.  **Disocclusion Handling:** For non-reference disoccluded regions not supervised by the single reference view, use image inpainters to guide both geometry and appearance via loss $L_{do}$ [S2].
6.  **Optimization Loop:** Minimize the total loss:
    $$L = L_{rec}^{unmasked} + \gamma_{depth} L_{depth}^{masked} + \gamma_{rec} L_{rec}^{masked} + \gamma_{do} L_{do}$$
    Losses $L_{depth}^{masked}$, $L_{rec}^{masked}$, and $L_{do}$ are computed every $N_{depth}$, $N_{bilateral}$, and $N_{do}$ iterations respectively [S2].

**Pseudocode:**

```python
def reference_guided_inpainting(images, poses, masks, reference_view, num_iterations):
    """
    Perform 3D inpainting of a NeRF using a single reference view.
    
    Args:
        images: List of n input images {I_i}
        poses: List of n camera transform matrices {Pi}
        masks: List of n binary masks {Mi}
        reference_view: The single inpainted reference image Ir
        num_iterations: Total training iterations
        
    Returns:
        Optimized NeRF model f_theta
    """
    # Initialize NeRF
    f_theta = initialize_nerf()
    
    # Precompute ray sets
    unmasked_rays = []
    masked_rays = []
    for i in range(len(images)):
        rays_i = generate_rays(images[i], poses[i])
        for ray in rays_i:
            if masks[i][ray.pixel] == 0:
                unmasked_rays.append(ray)
            else:
                masked_rays.append(ray)
                
    # Stage 1: Unmasked Supervision
    for step in range(num_iterations):
        if step < N_depth:
            # Only supervise unmasked pixels
            loss = 0.0
            for ray in unmasked_rays:
                color_pred = render_ray(f_theta, ray)
                color_gt = get_ground_truth_color(ray, images)
                loss += mse(color_pred, color_gt)
            loss.backward()
            optimizer.step()
            optimizer.zero_grad()
        else:
            # Stage 2: Full Optimization with Reference Guidance
            loss = 0.0
            
            # 1. Unmasked Reconstruction Loss
            for ray in unmasked_rays:
                color_pred = render_ray(f_theta, ray)
                color_gt = get_ground_truth_color(ray, images)
                loss += mse(color_pred, color_gt)
                
            # 2. Geometry Supervision from Reference View
            if step % N_depth == 0:
                # Back-project reference view to 3D using monocular depth
                depth_map = monocular_depth_estimator(reference_view)
                disparity_map = 1.0 / depth_map
                # Align disparity map with NeRF geometry
                # Compute masked depth loss L_depth^masked
                depth_loss = compute_masked_depth_loss(f_theta, reference_view, disparity_map, masked_rays)
                loss += gamma_depth * depth_loss
                
            # 3. View-Dependent Effects via Bilateral Solver
            if step % N_bilateral == 0:
                # Use view-substitution and bilateral solver to get target colors for non-reference views
                target_colors = bilateral_solver(reference_view, f_theta, poses, masks)
                # Compute masked reconstruction loss L_rec^masked
                rec_loss = compute_masked_rec_loss(f_theta, target_colors, masked_rays)
                loss += gamma_rec * rec_loss
                
            # 4. Disocclusion Handling
            if step % N_do == 0:
                # Identify disoccluded regions in non-reference views
                disoccluded_rays = find_disoccluded_rays(f_theta, poses, masks)
                # Use image inpainters to guide geometry and appearance
                do_loss = compute_disocclusion_loss(f_theta, disoccluded_rays, images)
                loss += gamma_do * do_loss
                
            loss.backward()
            optimizer.step()
            optimizer.zero_grad()
            
    return f_theta
```

**Edge Cases and Pitfalls:**
*   **Precision:** Monocular depth estimation errors can propagate into geometry supervision [S2].
*   **Boundaries:** The method assumes the reference view is correctly inpainted; errors in $I_r$ affect the entire 3D result [S2].
*   **Disocclusions:** Regions visible in non-reference views but occluded in the reference view require specific handling via $L_{do}$ [S2].

## Subtopics

### MVInpainter
A multi-view consistent inpainting model designed to bridge 2D and 3D scene editing [S1]. It employs domain adapters and motion modules as video priors to enhance cross-view consistency [S1]. It introduces a Reference Key&Value concatenation technique for appearance consistency while incorporating slot attention to aggregate optical flow features for controlling camera movement without explicit pose conditions [S1].

## Operating characteristics
*   **Time Complexity:** Depends on the number of iterations and the cost of monocular depth estimation and bilateral solver.
*   **Memory Complexity:** Standard NeRF memory plus storage for reference view and intermediate disparity maps.
*   **Strengths:** Avoids view inconsistencies by using a single reference view; generates view-dependent effects; controllable via a single image [S2].
*   **Limitations:** Relies on the quality of the single reference view; may struggle with complex disocclusions [S2].
*   **When to Use:** When a user has a single edited image and wants to propagate it consistently across all views of a NeRF [S2].
*   **When Not to Use:** When multi-view consistency is critical and multiple edited views are available, or when the reference view is unreliable [S1, S2].

## Background
Originated from the work on Reference-guided Controllable Inpainting of Neural Radiance Fields [S2]. It addresses the challenge of 3D scene inpainting by leveraging a single reference view, avoiding the need for multi-view edited inputs [S2].
