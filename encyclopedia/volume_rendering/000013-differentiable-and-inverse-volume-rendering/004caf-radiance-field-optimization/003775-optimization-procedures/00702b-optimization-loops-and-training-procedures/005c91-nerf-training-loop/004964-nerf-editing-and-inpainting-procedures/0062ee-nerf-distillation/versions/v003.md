# NeRF Distillation

Also called: Distilling edit to NeRF, Edit consolidation, Hashgrid export

## Overview
NeRF Distillation is a post-processing optimization procedure that collapses user-defined spatial edits into the canonical representation of a neural radiance field, specifically the Instant-NGP hashgrid format [S1]. Unlike iterative editing methods that maintain a separate deformation field or cage structure, this method re-trains the scene to bake the edits directly into the base hashgrid parameters [S1]. It is distinguished from sibling methods like [Progressive Inpainting-and-Erasing](8658-progressive-inpainting-and-erasing.md) by its focus on consolidating arbitrary geometric or appearance edits into a single, static representation without retaining the edit history [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A pre-trained NeRF representation (typically Instant-NGP hashgrids), a set of user-defined edits (each defining a source cage and a target deformation), and the original training images [S1].
*   **Output:** A single set of optimized NeRF parameters representing the edited scene in canonical space [S1].

**Data Structures:**
*   **Hashgrid:** The standard Instant-NGP multi-resolution hash table storing feature vectors [S1].
*   **Ray Mappings:** A tracking structure storing all unique mappings per ray, where a mapping $s \to s_{i...j}$ denotes a sample $s$ transformed by edit $i$ (and potentially subsequent edits $j$), or the "default mapping" if the sample remains in canonical space [S1].

**Algorithm:**

1.  **Mapping Identification:** For each sample $s$ generated along rays during an initial pass, check if $s$ lies within the source cage of any edit $i$ [S1]. If it does, compute the transformed position $s_i = T_i(s)$, establishing a mapping $s \to s_i$ [S1]. Recursively check if $s_i$ lies within the source cage of another edit $j$; if so, compute $s_{ij} = T_j(s_i)$, creating a recursive mapping $s \to s_{ij}$ [S1]. If $s$ is not transformed, it retains the "default mapping" [S1]. All unique mappings along each traced ray are tracked during training [S1].
2.  **Ray Preparation and Broken Mapping Check:** Re-trace each ray $r$ that has more than one unique mapping, along with copies $r'$, attempting to apply the identified mappings to each sample along $r$ [S1]. Each mapping implies one or more deformations that copy or remap updates normally occurring in canonical space [S1]. A mapping $s \to s_i$ is considered "broken" if $s_i$ lies inside the deformed cage of a later edit $j$ (meaning deforming space according to $j$ overwrites the result of deformation by $i$) [S1]. Broken mappings also occur for initial rays where the default mapping is no longer possible [S1]. The implementation handles this by simply skipping broken mappings [S1].
3.  **Rendering and Loss Computation:** For each valid ray and mapping, query the NeRF at the mapped or canonical sample position to obtain density $\sigma$ and color $\mathbf{c}$ [S1]. Perform volume rendering to compute the pixel color $C$ [S1]. Compute the photometric loss $L_{render}$ against the original input images [S1].
4.  **Gradient Propagation and Clearing:** Adapt color composition and gradient computation [S1]. Shared sample locations (outside cages) only receive gradients from the first ray that references them [S1]. For non-copying edits, contents at the source must be cleared to prevent random density or color in the left-behind empty space [S1]. Samples that end up in the undeformed cage of a non-copying edit during their mapping are part of these clearing rays; they accumulate density and integrate against an empty space target (zero density) [S1].
5.  **Optimization Loop:** Minimize the total loss using gradient descent to update the NeRF parameters $\theta$ [S1]. Repeat until convergence [S1].

**Pseudocode:**

```python
import torch
import math

def nerf_distillation(nerf_model, edits, training_images, optimizer, max_epochs):
    """
    Distills user edits into the NeRF hashgrid by re-training with forward-mapped samples.
    """
    # [G] Standard ray generation from camera poses and pixel coordinates
    def generate_rays(images):
        rays = []
        for img, cam in images:
            for u, v in img.pixel_coords:
                rays.append((cam, u, v))
        return rays

    training_rays = generate_rays(training_images)
    visited_canonical_points = set() # Tracks shared sample locations for gradient sharing

    # Step 1: Identify mappings for a representative set of rays
    ray_mappings = {}
    for ray in training_rays:
        # [G] Sample points along the ray in canonical space
        samples = nerf_model.sample_along_ray(ray)
        mappings = []
        for s in samples:
            current_s = s
            mapping_chain = []
            # Check for recursive mappings
            for edit in edits:
                if edit['cage'].contains(current_s):
                    transformed_s = edit['transform'](current_s)
                    mapping_chain.append((edit['id'], transformed_s))
                    current_s = transformed_s
                else:
                    break
            mappings.append((s, mapping_chain))
        ray_mappings[ray] = mappings

    # Step 2 & 3: Optimization Loop
    for epoch in range(max_epochs):
        visited_canonical_points.clear()
        total_loss = 0.0
        for img, cam in training_images:
            ray = (cam, img.pixel_coords[0, 0]) # Simplified for single pixel per iteration
            mappings = ray_mappings.get(ray, [])
            
            rendered_color = torch.zeros(3)
            alpha = 0.0
            
            for s, mapping_chain in mappings:
                # Check for broken mappings
                is_broken = False
                for edit in edits:
                    if edit['cage'].contains(s):
                        transformed_s = edit['transform'](s)
                        for later_edit in edits:
                            if later_edit['id'] > edit['id'] and later_edit['cage'].contains(transformed_s):
                                is_broken = True
                                break
                    if is_broken: break
                if is_broken:
                    continue

                query_point = s
                for edit_id, transformed_s in mapping_chain:
                    query_point = transformed_s

                sigma, color = nerf_model.query(query_point)
                
                # [G] Standard volume rendering step
                t = ray.sample_distance
                weight = sigma * math.exp(-sigma * t)
                rendered_color += weight * color
                alpha += weight

                # Handle non-copying edit clearing
                if mapping_chain and not edits[mapping_chain[-1][0]]['is_copying']:
                    # Clearing rays accumulate density and integrate against empty space (zero density)
                    clear_loss = torch.sum((sigma - 0.0)**2 + (color - torch.zeros(3))**2)
                    total_loss += clear_loss

                # Gradient sharing: Shared sample locations only receive gradients from the first ray
                canonical_key = str(s)
                if canonical_key in visited_canonical_points:
                    continue
                visited_canonical_points.add(canonical_key)

            # Photometric loss against original input images
            target_color = img.pixel_value
            photometric_loss = torch.sum((rendered_color - target_color)**2)
            total_loss += photometric_loss

        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()
```

**Edge Cases and Pitfalls:**
*   **Broken Mappings:** If a sample is transformed by edit $i$ into a region that is then transformed by edit $j$, and $j$'s deformation overwrites $i$'s result, the mapping is broken [S1]. The implementation skips these mappings [S1].
*   **Non-Copying Edits:** Failure to clear the source region of a non-copying edit results in random density or color artifacts in the empty space [S1].
*   **Gradient Conflicts:** Shared sample locations outside cages must only receive gradients from one ray to prevent conflicting updates [S1].

## Operating characteristics
*   **Time Complexity:** Requires re-training the entire scene [S1].
*   **Memory Complexity:** No additional memory overhead for deformation fields or cages; the final representation is a standard Instant-NGP hashgrid [S1].
*   **Strengths:** Produces a compact representation suitable for rendering; consolidates all edits into a single static model [S1].
*   **Limitations:** Cannot easily undo edits; requires re-training for any change; broken mappings may lead to loss of content in complex edit sequences [S1].
*   **When to Use:** When a final, optimized, and compact NeRF representation is needed after multiple edits [S1].
*   **When Not to Use:** Not given in the sources.

## Background
NeRF Distillation was introduced in the context of converting between various NeRF representations, specifically targeting the Instant-NGP hashgrid format for its efficiency [S1]. It addresses the need for a clean, consolidated representation after complex editing operations, avoiding the accumulation of deformation fields [S1].
