# NeRF-In

Also called: NeRF Inpainting via MST

## Overview
NeRF-In is a 3D inpainting method that removes undesired objects from a scene by training a Neural Radiance Field (NeRF) to match 2D inpainted images generated by a Masked Scene Transformer (MST) network [S2]. It differs from sibling methods like [Local Editing via SAM and Depth Propagation](13674-local-editing-via-sam-and-depth-propagation.md) by relying on a pre-trained 2D inpainting model to provide both color and depth guidance, rather than propagating edits through geometric constraints alone [S1]. The method solves the problem of 3D object removal by minimizing pixel reconstruction errors against these 2D guides [S2].

## How it works
**Inputs:**
1. A pre-trained NeRF model representing the original scene.
2. A set of input images with known camera poses.
3. A single-view annotation (mask) identifying the object to be removed.

**Outputs:**
1. An updated NeRF model representing the scene with the object removed.
2. Inpainted images and depth maps for the input views.

**Data Structures:**
*   **NeRF Model:** Standard MLP-based representation mapping 3D coordinates and viewing directions to color and density. [G] Standard implementation details (e.g., positional encoding, layer sizes) are assumed from the base NeRF architecture.
*   **Mask:** Binary or soft mask indicating the region of interest.
*   **Guiding Images:** 2D RGB images generated by the MST inpainting network.
*   **Guiding Depth:** 2D depth maps generated by the MST inpainting network.

**Steps:**
1.  **Mask Generation:** Generate an initial mask for the target object using a one-shot segmentation method. Methods include Mask R-CNN [S1], Segment Anything Model (SAM) [S1], or GLIP [S1]. This is done from a single-view annotation.
2.  **2D Inpainting:** Use an inpainting network (specifically the MST network [S2]) to generate a guiding RGB image and a guiding depth image for each input view. The inpainting network takes the original image and the mask as input, producing a completed image and corresponding depth for the masked region [S1].
3.  **Loss Computation:** Compute the pixel reconstruction loss between the rendered output of the NeRF and the guiding images. The loss is defined as:
    $$ L = \sum_{v \in V} \| I_{rendered}^v - I_{guide}^v \|_1 $$
    where $V$ is the set of input views, $I_{rendered}^v$ is the color rendered by the NeRF for view $v$, and $I_{guide}^v$ is the MST-generated guiding image for view $v$ [S2]. [G] The depth guiding loss is also optimized, typically as a similar pixel-wise difference between rendered depth and guiding depth, though the specific weighting is not detailed in the sources [S1].
4.  **Optimization:** Update the NeRF parameters by minimizing the combined color-guiding and depth-guiding losses [S1]. The optimization is performed over the input views.

**Parameters:**
*   **Inpainting Network:** MST [S2].
*   **Loss Function:** Pixel reconstruction loss (L1 or L2) [S2].
*   **Segmentation Method:** One-shot methods (Mask R-CNN, SAM, GLIP) [S1].

**Edge Cases and Pitfalls:**
*   **3D Inconsistency:** The method does not fully resolve 3D inconsistencies inherent in the 2D inpainter's output [S1]. The 2D inpainting may produce results that are inconsistent across different viewpoints, leading to artifacts in the 3D reconstruction.
*   **View Selection:** NeRF-In only minimizes the number of views used for optimization but does not inherently select the most consistent views [S1]. This can lead to suboptimal results if the inpainted regions are unreliable in certain views.
*   **Blurring:** The method may suffer from blurring in the inpainted regions [S1].

## Subtopics

### Local Editing via SAM and Depth Propagation
Uses SAM for segmentation and propagates edits via depth consistency rather than relying on a separate 2D inpainting network for guidance. Choose when geometric consistency is prioritized over texture synthesis fidelity. [Link](13674-local-editing-via-sam-and-depth-propagation.md)

## Operating characteristics
*   **Time Complexity:** Depends on the optimization steps for the NeRF and the inference time of the MST inpainting network. Not given in the sources.
*   **Memory Complexity:** Standard NeRF memory requirements plus storage for guiding images and depth maps. Not given in the sources.
*   **Strengths:** Simple implementation; leverages powerful 2D inpainting models (MST) for high-quality texture synthesis.
*   **Limitations:** Struggles with 3D consistency; relies on the quality of the 2D inpainter; does not actively resolve view-dependent inconsistencies [S1].
*   **When to use:** When high-quality 2D inpainting is available and 3D consistency is secondary or can be tolerated.
*   **When not to use:** When strict 3D consistency is required or when the 2D inpainter produces perceptually inconsistent results across views [S2].

## Background
NeRF-In was introduced as a simple 3D inpainting method that trains a NeRF using pixel reconstruction loss guided by 2D inpainted images generated by an MST inpainting network [S2]. It builds on the premise that 2D inpainting results can be transferred to 3D scenes [S2]. It is often compared to SPIn-NeRF, which improves upon NeRF-In by using perceptual loss and depth supervision [S2]. The method is part of the broader field of NeRF-based 3D editing, which aims to remove or modify objects in 3D scenes while maintaining visual coherence [S1].
