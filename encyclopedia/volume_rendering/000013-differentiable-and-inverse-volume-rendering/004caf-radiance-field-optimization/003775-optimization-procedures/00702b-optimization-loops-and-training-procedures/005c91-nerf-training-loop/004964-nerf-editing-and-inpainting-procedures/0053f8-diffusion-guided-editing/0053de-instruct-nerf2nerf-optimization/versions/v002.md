# Instruct-NeRF2NeRF Optimization

Also called: Instruct-NeRF2NeRF optimization process, NeRF Editing via Diffusion Guidance

## Overview
Instruct-NeRF2NeRF optimization edits an existing 3D scene represented by a Neural Radiance Field (NeRF) by using a text-conditioned image diffusion model as a guidance signal. It solves the problem of applying high-level semantic instructions (e.g., "turn the man into a bear") to a 3D reconstruction without requiring new 3D data. It differs from sibling methods like RePaint-NeRF by using InstructPix2Pix for instruction-based editing rather than mask-based inpainting, and by optimizing the NeRF parameters directly via gradient descent from the 2D diffusion output rather than sampling from a posterior distribution.

## How it works

### Inputs and Outputs
**Inputs:**
1.  **Initial NeRF Model:** A pre-trained NeRF reconstruction of a real scene. The source specifies this is typically obtained using the 'nerfacto' model from NeRFStudio, trained for 30,000 iterations per scene [S1].
2.  **Edit Instruction:** A text string specifying the desired modification.
3.  **Camera Views:** A set of camera poses from which to render views for optimization.
4.  **Guidance Weights:**
    *   $s_I$: Image classifier-free guidance weight. Typical values: 1.3 to 1.75 [S1].
    *   $s_T$: Text classifier-free guidance weight. Typical values: 6.5 to 12.5 [S1].

**Outputs:**
*   **Edited NeRF Model:** A new NeRF representation reflecting the edit.

### Data Structures
The method operates on the parameters of the existing NeRF (e.g., MLP weights, feature grid embeddings). No new complex data structures are introduced; the optimization updates the existing NeRF parameter vector $\theta$. The diffusion model (InstructPix2Pix) is loaded as a static module.

### Steps
1.  **Initialization:** Load the pre-trained NeRF. Re-initialize the optimizers in the NeRF training framework to ensure clean gradient states for the editing phase [S1].
2.  **Iteration Loop:** For each optimization step $k$:
    a.  **Render:** Select a single camera view (or a batch of views) and render an image $I_{render}$ from the current NeRF parameters $\theta_k$.
    b.  **Diffusion Guidance:** Pass $I_{render}$, the edit instruction, and guidance weights $s_I, s_T$ to the InstructPix2Pix model. Generate the edited image $I_{edit}$.
        *   Note: InstructPix2Pix is implemented via the Diffusers library [S1].
    c.  **Loss Calculation:** Compute the difference between the edited image and the rendered image. The loss is typically the Mean Squared Error (MSE) or L2 distance:
        $$ \mathcal{L} = \| I_{edit} - I_{render} \|_2^2 $$
    d.  **Backpropagation:** Backpropagate the gradient of $\mathcal{L}$ through the rendering function to update the NeRF parameters $\theta$.
3.  **Termination:** Stop optimization after a subjective number of iterations.
    *   Small scenes (<100 input images): 3,000–4,000 iterations [S1].
    *   Large scenes (>200–300 input images): 7,000–8,000 iterations [S1].

### Pseudocode

```python
def instruct_nerf2nerf_optimization(nerf_model, edit_instruction, camera_poses, s_I, s_T, max_iterations):
    """
    Optimizes a NeRF model using InstructPix2Pix guidance.
    
    Args:
        nerf_model: Pre-trained NeRF model (e.g., nerfacto from NeRFStudio).
        edit_instruction: String describing the edit.
        camera_poses: List of camera poses for rendering.
        s_I: Image classifier-free guidance weight (1.3 - 1.75).
        s_T: Text classifier-free guidance weight (6.5 - 12.5).
        max_iterations: Maximum number of optimization steps.
        
    Returns:
        Edited NeRF model.
    """
    # Re-initialize optimizers as per source [S1]
    nerf_model.reinitialize_optimizers()
    
    # Load InstructPix2Pix model (via Diffusers library) [S1]
    # This is assumed to be a pre-loaded static module `diffusion_model`
    
    for step in range(max_iterations):
        # 1. Render a single view (or batch) from current NeRF
        # Select a random or sequential camera pose
        pose = camera_poses[step % len(camera_poses)]
        I_render = nerf_model.render(pose)
        
        # 2. Generate edited image using InstructPix2Pix
        # InstructPix2Pix takes the input image, instruction, and guidance weights
        I_edit = diffusion_model.edit(
            image=I_render,
            prompt=edit_instruction,
            guidance_scale_image=s_I,
            guidance_scale_text=s_T
        )
        
        # 3. Compute loss
        # MSE between rendered and edited image
        loss = torch.mean((I_render - I_edit) ** 2)
        
        # 4. Backpropagate to update NeRF parameters
        loss.backward()
        nerf_model.optimizer.step()
        nerf_model.optimizer.zero_grad()
        
        # Optional: Check for termination criteria if dynamic
        # Termination is subjective based on scene size [S1]
        
    return nerf_model
```

### Parameters and Typical Values
*   **$s_I$ (Image Guidance):** 1.3 to 1.75. Specific examples: 1.5 for Tree, Person, Fig 1; 1.3-1.5 for Fig 7 [S1].
*   **$s_T$ (Text Guidance):** 6.5 to 12.5. Specific examples: 10.0 for Tents; 6.5-7.5 for Person, Fig 1, Bear; 7.5-12.5 for Tree; 6.5-8.5 for Fig 7 [S1].
*   **Training Iterations:**
    *   Small scenes (<100 images): 3,000–4,000 [S1].
    *   Large scenes (>200-300 images): 7,000–8,000 [S1].

### Edge Cases and Pitfalls
1.  **Lack of Convergence:** The diffusion model produces temporally varying images during optimization. There is no single convergence point where the NeRF perfectly explains all views. The edit type and strength vary over training, requiring subjective termination [S1].
2.  **Texture Blurriness:** Using Stable Diffusion's autoencoder on input images (or during the process) causes gradual texture blurriness. The autoencoder creates locally similar but non-3D-consistent textures, leading to blurry renders in the final reconstruction [S1].
3.  **Single-View Artifacts:** Because guidance is applied on a single view at a time, artifacts such as "double faces" on added objects may occur [S1].
4.  **View-Dependent Instructions:** Edit instructions may only be relevant to certain camera views. For example, "turn the man into a bear" may not produce an edit in views where the man is not prominent, leading to inconsistent edits across the scene [S1].
5.  **Quality Degradation:** Over much longer optimization runs, visual quality decreases, attributed to the autoencoder effects [S1].

## Operating characteristics

### Time and Memory Complexity
*   **Time:** Each iteration requires one NeRF forward pass (rendering) and one diffusion model forward pass (editing). The diffusion model (InstructPix2Pix) is computationally expensive, making each iteration significantly slower than standard NeRF training. Total time scales linearly with the number of iterations (3,000–8,000) and the complexity of the diffusion model.
*   **Memory:** Requires memory for the NeRF model and the diffusion model (InstructPix2Pix + Stable Diffusion autoencoder) in VRAM simultaneously. No additional large data structures are created.

### Measured Performance
*   Specific quantitative metrics (e.g., PSNR, SSID) are not provided in the notes for the optimization process itself, only qualitative descriptions of artifacts and texture quality [S1].
*   The method is noted to produce "slightly blurrier textures" compared to the original reconstruction [S1].

### Strengths and Limitations
*   **Strengths:** Allows high-level semantic editing of 3D scenes using natural language instructions. Leverages powerful 2D diffusion models.
*   **Limitations:**
    *   Cannot perform large spatial manipulations [S1].
    *   May fail to bind objects referred to in instructions to corresponding scene objects [S1].
    *   Struggles with adding or removing large objects [S1].
    *   Inconsistent edits across views if the instruction is view-dependent [S1].
    *   Texture blurriness due to autoencoder artifacts [S1].
    *   Subjective termination required due to lack of convergence [S1].

### When to Use
*   Use when you have a pre-existing NeRF and want to apply semantic edits via text instructions.
*   Use when 2D diffusion models are preferred over 3D-aware generative models for editing.

### When Not to Use
*   Do not use if 3D consistency of textures is critical and high fidelity is required (due to blurriness).
*   Do not use if the edit involves large spatial changes or object addition/removal (known limitations).
*   Do not use if automatic convergence detection is needed (requires subjective termination).

## Background

### Origin
The method is described in the paper "Instruct-NeRF2NeRF: Editing 3D Scenes with Instructions" by Zhizhuo Zhou and Shubham Tulsiani [S1].

### History and Development
The method builds upon the 'nerfacto' model from NeRFStudio [S1] and InstructPix2Pix [2] (cited in [S1]). It inherits limitations from InstructPix2Pix and DreamFusion (single-view diffusion guidance) [S1].

### Usage
Used for editing 3D scenes represented as NeRFs using natural language instructions.
