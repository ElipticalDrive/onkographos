# NeRF Editing Procedure

Also called: Feature Field Distillation Editing, DFF-based Editing

## Overview
This procedure enables direct 3D editing of a pre-trained NeRF by decoupling semantic or geometric selection from appearance rendering using a Distilled Feature Field (DFF) [S1]. It solves the problem of inconsistent multi-view edits by defining a selection probability $p$ for each 3D point based on external feature queries, allowing for precise operations like deletion, colorization, and geometric transformation that respect the underlying scene structure [S1]. It sets itself apart from standard optimization-based methods (e.g., [RePaint-NeRF](14365-repaint-nerf.md)) by avoiding iterative gradient descent for the edit itself, instead relying on a deterministic query-and-transform pipeline during rendering [S1].

## How it works
**Inputs:**
*   Pre-trained NeRF representation $f_\theta: (\mathbf{x}, \mathbf{d}) \to (\sigma, \mathbf{c})$ [S1].
*   Pre-trained teacher network (e.g., LSeg or DINO) for feature extraction [S1].
*   User-defined editing parameters: selection threshold $\tau$ (user-defined) [S1], colorization function $b(\cdot)$ [S1], geometric transformation $g(\cdot)$ and its inverse $g^{-1}(\cdot)$ [S1].
*   Ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ for each pixel [S1].

**Outputs:**
*   Edited image $I'$ [S1].

**Data Structures:**
*   **DFF:** A field storing feature embeddings or probability scores $p$ for 3D coordinates. In the source, $p$ is calculated by querying the DFF for each point [S1]. The exact internal layout of the DFF is not specified, but it outputs a scalar probability $p \in [0, 1]$ representing the likelihood that coordinate $\mathbf{x}$ matches the editing query [S1].
*   **NeRF:** Representation storing density $\sigma$ and color $\mathbf{c}$, queried via $f_\theta(\mathbf{x}, \mathbf{d})$ [S1].

**Numbered Steps:**
1.  **Ray Sampling:** Sample points $\{\mathbf{x}_i\}$ along the ray $\mathbf{r}$ as in standard volume rendering [S1].
2.  **Feature Query:** For each point $\mathbf{x}_i$, query the DFF to obtain the selection probability $p_i$ [S1].
3.  **Selection Decision:** Determine if $\mathbf{x}_i$ is "selected" by the edit query: if $p_i > \tau$, $\mathbf{x}_i$ is **selected**; otherwise, it is **not selected** [S1]. The source also mentions an alternative mixture approach where results are blended in proportion to $p$, but the primary procedure uses the threshold [S1].
4.  **Transform Application:** For each point $\mathbf{x}_i$, compute the effective density $\sigma'_i$ and color $\mathbf{c}'_i$:
    *   **Case A: Not Selected:** Query the vanilla NeRF: $(\sigma_i, \mathbf{c}_i) = f_\theta(\mathbf{x}_i, \mathbf{d})$ [S1]. Set $\sigma'_i = \sigma_i, \mathbf{c}'_i = \mathbf{c}_i$ [S1].
    *   **Case B: Selected:**
        *   **Deletion:** Set $\sigma'_i = 0$ [S1].
        *   **Color Editing:** Query the vanilla NeRF for $(\sigma_i, \mathbf{c}_i)$. Apply colorization function $b$: $\mathbf{c}'_i = b(\mathbf{c}_i)$ [S1]. Keep $\sigma'_i = \sigma_i$ [S1].
        *   **Translation / Rescaling:**
            1.  Compute deformed coordinate $\mathbf{x}_0 = g^{-1}(\mathbf{x}_i)$ [S1].
            2.  Query the DFF for $\mathbf{x}_0$ to get probability $p_0$ [S1].
            3.  If $\mathbf{x}_0$ is **selected** ($p_0 > \tau$): Query NeRF for $(\sigma_0, \mathbf{c}_0) = f_\theta(\mathbf{x}_0, \mathbf{d})$ [S1]. Set $\sigma'_i = \sigma_0, \mathbf{c}'_i = \mathbf{c}_0$ [S1].
            4.  If $\mathbf{x}_0$ is **not selected**: The source does not explicitly define the fallback for the original point $\mathbf{x}_i$ in this specific branch [S1].
            5.  **Boundary Mixing:** If both $\mathbf{x}_i$ and $\mathbf{x}_0$ are selected and have non-zero density (e.g., at object boundaries during deformation): mix colors $\mathbf{c}_i$ and $\mathbf{c}_0$ in the ratio of their alphas $\alpha_i$ and $\alpha_0$ [S1].
5.  **Volume Rendering:** Perform standard volume rendering using the modified tuples $(\sigma'_i, \mathbf{c}'_i)$ along the ray [S1].

**Formulas:**
*   Selection probability: $p_i = \text{DFF}(\mathbf{x}_i)$ [S1].
*   Selection condition: $\mathbf{x}_i$ is selected if $p_i > \tau$ [S1].
*   Deletion transform: $\sigma'_i = 0$ [S1].
*   Color editing transform: $\mathbf{c}'_i = b(\mathbf{c}_i)$ [S1].
*   Geometric transform: $\mathbf{x}_0 = g^{-1}(\mathbf{x}_i)$ [S1].
*   Boundary color mixing: $\mathbf{c}'_i = \frac{\alpha_i \mathbf{c}_i + \alpha_0 \mathbf{c}_0}{\alpha_i + \alpha_0}$ [G] (Derived from "mix their colors... in the ratio of their alphas").
*   Volume rendering compositing: $C = \sum_i T_i \alpha_i \mathbf{c}'_i$, where $T_i = \prod_{j < i} (1 - \alpha_j)$ and $\alpha_i = 1 - e^{-\sigma'_i \Delta t}$ [G] (Standard volume rendering formula).

**Parameters:**
*   Selection threshold $\tau$: User-defined [S1].
*   Colorization function $b(\cdot)$: User-defined [S1].
*   Geometric transformation $g(\cdot)$: User-defined [S1].
*   Typical values: Not given in the sources.

**Edge cases and pitfalls:**
*   Precision: The threshold $\tau$ requires careful tuning to avoid partial selection artifacts [S1].
*   Boundaries: At deformation boundaries where both $\mathbf{x}_i$ and $\mathbf{x}_0$ are selected, color mixing is applied to prevent visual discontinuities [S1].
*   Degenerate input: If $g^{-1}(\mathbf{x}_i)$ falls outside the training domain, the NeRF query may produce unreliable $\sigma_0, \mathbf{c}_0$ [G].
*   The source does not specify behavior when $\mathbf{x}_0$ is not selected during translation/rescaling [S1].

**Pseudocode:**
```python
import math

def render_edited_ray(ray_o, ray_d, nerf_model, dff_model, transform_g_inv, color_func_b, threshold, is_deletion=False, num_samples=64, near=0.0, far=1.0):
    # 1. Ray Sampling
    t_vals = [near + (far - near) * i / (num_samples - 1) for i in range(num_samples)]
    points = [(ray_o[0] + t * ray_d[0], ray_o[1] + t * ray_d[1], ray_o[2] + t * ray_d[2]) for t in t_vals]
    dist = (far - near) / (num_samples - 1)
    
    densities = []
    colors = []
    
    for x, t in zip(points, t_vals):
        # 2. Feature Query
        p = dff_model(x)
        
        # 3. Selection Decision
        is_sel = p > threshold
        
        if not is_sel:
            # Case A: Not Selected
            sigma, c = nerf_model(x, ray_d)
            densities.append(sigma)
            colors.append(c)
        else:
            # Case B: Selected
            if is_deletion:
                # 4-A: Deletion
                densities.append(0.0)
                colors.append([0.0, 0.0, 0.0])
            else:
                # Query original point for base values
                sigma_orig, c_orig = nerf_model(x, ray_d)
                
                # Check for geometric transformation (Translation/Rescaling)
                x_deformed = transform_g_inv(x)
                p_deformed = dff_model(x_deformed)
                is_deformed_selected = p_deformed > threshold
                
                if is_deformed_selected:
                    # Get values from deformed location
                    sigma_def, c_def = nerf_model(x_deformed, ray_d)
                    
                    # 4'-C: Boundary Mixing
                    alpha_orig = 1.0 - math.exp(-sigma_orig * dist)
                    alpha_def = 1.0 - math.exp(-sigma_def * dist)
                    
                    total_alpha = alpha_orig + alpha_def
                    if total_alpha > 0:
                        w_orig = alpha_orig / total_alpha
                        w_def = alpha_def / total_alpha
                        c_final = [w_orig * c_orig[j] + w_def * c_def[j] for j in range(3)]
                    else:
                        c_final = c_orig
                        
                    densities.append(sigma_def)
                    colors.append(c_final)
                else:
                    # Deformed point not selected. Fallback not specified in sources [S1].
                    if color_func_b is not None:
                        c_final = color_func_b(c_orig)
                    else:
                        c_final = c_orig
                    
                    densities.append(sigma_orig)
                    colors.append(c_final)

    # 5. Volume Rendering
    accumulated_color = [0.0, 0.0, 0.0]
    T = 1.0
    
    for sigma, c in zip(densities, colors):
        alpha = 1.0 - math.exp(-sigma * dist)
        weight = T * alpha
        accumulated_color = [accumulated_color[j] + weight * c[j] for j in range(3)]
        T *= (1.0 - alpha)
        
    return accumulated_color
```

## Subtopics

### [Local Editing via SAM and Depth Propagation](13674-local-editing-via-sam-and-depth-propagation.md)
A technique to edit specific objects within a NeRF without altering the background, using 2D segmentation masks propagated across views via depth information. It sets itself apart by using depth-based reprojection to ensure multi-view consistency of the segmentation mask, allowing exclusive modification of the target instance while leaving the background intact. Choose it when precise object-level editing is required without background alteration.

### ViCA-NeRF Warm-Up
A strategy to efficiently warm up the editing process by blending edits directly before the entire process, accelerating editing while preserving consistency [S2]. It sets itself apart by projecting a single edited view onto all other views using a simple pixel-wise blend formula. Choose it to speed up the initial convergence of view-consistent editing.

### NeRF-RPN Application
An application where scene editing is performed by setting the density inside a proposal bounding box (generated by a Region Proposal Network) to zero when rendering [S3]. It sets itself apart by leveraging 3D object detection proposals for direct density suppression. Choose it for object removal tasks guided by detection frameworks.

### NeRF-In
A simple 3D inpainting method that trains a NeRF using pixel reconstruction loss, guided by 2D inpainted images generated by an MST inpainting network [S4]. It sets itself apart by relying on standard pixel loss rather than DFF-based selection or iterative optimization. Choose it for straightforward inpainting tasks where 2D priors are sufficient.

## Operating characteristics
*   **Time Complexity:** Rendering time is dominated by the additional DFF query per sample point [S1].
*   **Memory Complexity:** Requires storing the DFF in addition to the NeRF [S1]. The size of the DFF is not given in the sources.
*   **Strengths:** Deterministic editing; no iterative optimization required for the edit itself; supports complex transformations (translation, colorization) [S1].
*   **Limitations:** Relies on the quality of the teacher network (LSeg/DINO) for accurate selection; threshold tuning required [S1].
*   **When to use:** When precise, non-iterative editing of specific semantic or geometric regions is required [S1].
*   **When not to use:** When iterative optimization with external diffusion priors is preferred for high-fidelity generation [G].

## Background
The method originates from "Decomposing NeRF for Editing Via Feature Field Distillation" [S1]. It utilizes pre-trained teacher networks like LSeg (ViT-L/16 image encoder, CLIP’s ViT-B/32 text encoder) and DINO to generate feature maps for distillation [S1].
