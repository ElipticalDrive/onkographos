# Reference-guided Controllable Inpainting of NeRFs

Also called: Reference-guided Inpainting

## Overview
Reference-guided Controllable Inpainting of NeRFs is a method for 3D scene inpainting that utilizes a single inpainted reference view to guide the geometry and appearance of a Neural Radiance Field (NeRF), ensuring view consistency and generating view-dependent effects [S2]. It solves the problem of view inconsistencies and lack of view-dependent effects (VDEs) in non-reference views by back-projecting the reference view using monocular depth estimation and employing a bilateral solver to propagate appearance [S2]. Unlike methods that require multi-view inpainted inputs or complex text prompts, this approach allows user control via a single 2D image, avoiding the visual quality deterioration often seen in methods that rely on multiple inconsistent inpainted views [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** $n$ input images $\{I_i\}_{i=1}^n$, camera transform matrices $\{\Pi_i\}_{i=1}^n$, binary masks $\{M_i\}_{i=1}^n$ delineating unwanted regions, and a single inpainted reference view $I_r$ where $r \in \{1, \dots, N\}$ [S2].
*   **Outputs:** An optimized NeRF representation $f_\theta: (\mathbf{x}, \mathbf{d}) \to (\sigma, \mathbf{c})$ that reconstructs the scene with the object removed and the reference content extended consistently [S2].

**Data Structures:**
*   **NeRF Representation:** Standard MLP-based NeRF storing density $\sigma$ and color $\mathbf{c}$ for 3D coordinates $\mathbf{x}$ and viewing directions $\mathbf{d}$ [G].
*   **Ray Set:** Rays $r$ are sampled from input views and partitioned into $R_{unmasked}$ (pixels where $M_i=0$) and $R_{masked}$ (pixels where $M_i=1$) [S2].
*   **Depth Map:** A disparity map $D(r)$ is computed from the monocular depth estimator applied to $I_r$, converted to inverse depth for supervision [S2].

**Parameters:**
*   $N_{depth}$: Number of iterations for initial unmasked supervision [S2].
*   $N_{bilateral}$: Iteration interval for bilateral solver updates [S2].
*   $N_{do}$: Iteration interval for disocclusion handling [S2].
*   $\gamma_{depth}, \gamma_{rec}, \gamma_{do}$: Loss weights (values not given in the sources) [S2].

**Numbered Steps:**

1.  **Initialization:** Initialize NeRF parameters $\theta$ and compute the set of unmasked rays $R_{unmasked}$ corresponding to pixels in $\{I_i(1 - M_i)\}_{i=1}^n$ [S2, G].
2.  **Stage 1: Unmasked Supervision:** Optimize $f_\theta$ on $R_{unmasked}$ for $N_{depth}$ iterations using the standard reconstruction loss $L_{rec}^{unmasked}$ [S2]. The masked region remains under-fit to allow altering masked values in later stages [S2].
    $$
    L_{rec}^{unmasked} = \mathbb{E}_{r \sim R_{unmasked}} \| \hat{C}(r) - C_{GT}(r) \|^2
    $$
    where $\hat{C}(r)$ is the rendered color and $C_{GT}(r)$ is the ground truth color [S2].
3.  **Geometry Supervision via Monocular Depth:** Use a monocular depth estimator to predict depth for the inpainted reference view $I_r$ [S2]. Back-project $I_r$ to 3D positions using the camera matrix $\Pi_r$ and the estimated depth [S2]. Compute a disparity map and align it with the current NeRF scene [S2]. Supervise the masked region's geometry using the depth loss $L_{depth}^{masked}$ [S2].
4.  **View-Dependent Effects (VDEs) via Bilateral Solver:** For non-reference views, use a view-substitution technique followed by bilaterally guided inpainting [S2]. The bilateral solver constructs VDEs in non-reference views from the reference viewpoint, ensuring that the inpainted region appears consistent from any view [S2]. Obtain target colors $I_{br,t}$ for non-reference views [S2]. Compute the reconstruction loss on masked pixels $L_{rec}^{masked}$ using these target colors [S2].
5.  **Disocclusion Handling:** Identify non-reference disoccluded regions (areas visible in other views but not covered by the single reference view) [S2]. Use image inpainters to guide both geometry and appearance for these regions via loss $L_{do}$ [S2].
6.  **Total Loss Optimization:** The total loss is computed as:
    $$
    L = L_{rec}^{unmasked} + \gamma_{depth} L_{depth}^{masked} + \gamma_{rec} L_{rec}^{masked} + \gamma_{do} L_{do}
    $$
    Losses $L_{depth}$, $L_{rec}$, and $L_{do}$ are computed every $N_{depth}$, $N_{bilateral}$, and $N_{do}$ iterations respectively [S2].

**Pseudocode:**

```python
def reference_guided_inpainting(images, cameras, masks, ref_view, depth_estimator, bilateral_solver, image_inpainter, 
                                n_iterations, N_depth, N_bilateral, N_do, gamma_depth, gamma_rec, gamma_do, lr=0.01):
    # Initialize NeRF parameters theta [G]
    theta = init_mlp_nerf()
    
    # Precompute ray sets based on masks [G]
    R_unmasked = []
    R_masked = []
    for i in range(len(images)):
        for ray in generate_rays_from_view(images[i], cameras[i]):
            if masks[i][ray.pixel] == 0:
                R_unmasked.append(ray)
            else:
                R_masked.append(ray)
                
    for step in range(1, n_iterations + 1):
        # Stage 1: Unmasked Supervision (active every iteration)
        rendered_unmasked = render_color(theta, R_unmasked, cameras)
        gt_unmasked = get_ground_truth(R_unmasked, images)
        loss_unmasked = mean_squared_error(rendered_unmasked, gt_unmasked)
        theta = gradient_descent_step(theta, loss_unmasked, lr)
        
        # Geometry Supervision via Monocular Depth
        if step % N_depth == 0:
            ref_depth = depth_estimator(ref_view)
            ref_disparity = compute_disparity_from_depth(ref_depth, cameras[r])
            loss_depth = compute_depth_loss(theta, R_masked, ref_disparity)
            theta = gradient_descent_step(theta, loss_depth, lr)
            
        # View-Dependent Effects via Bilateral Solver
        if step % N_bilateral == 0:
            target_colors = bilateral_solver(ref_view, cameras, theta)
            rendered_masked = render_color(theta, R_masked, cameras)
            loss_rec_masked = mean_squared_error(rendered_masked, target_colors)
            theta = gradient_descent_step(theta, loss_rec_masked, lr)
            
        # Disocclusion Handling
        if step % N_do == 0:
            disoccluded_rays = find_disoccluded_rays(theta, cameras, masks)
            loss_do = compute_disocclusion_loss(theta, disoccluded_rays, image_inpainter)
            theta = gradient_descent_step(theta, loss_do, lr)
            
    return theta

# Helper definitions [G]
def init_mlp_nerf():
    return MLPNeRF()

def generate_rays_from_view(image, camera):
    return [Ray(camera, pixel) for pixel in image.pixels]

def render_color(theta, rays, cameras):
    return [theta(ray.origin, ray.direction) for ray in rays]

def get_ground_truth(rays, images):
    return [ray.pixel.color for ray in rays]

def mean_squared_error(pred, gt):
    return sum((p - g)**2 for p, g in zip(pred, gt)) / len(pred)

def gradient_descent_step(theta, loss, lr):
    return theta - lr * gradient(loss)

def compute_disparity_from_depth(depth, camera):
    return camera.focal_length / depth

def compute_depth_loss(theta, rays, target_disparity):
    return mean_squared_error(render_disparity(theta, rays), target_disparity)

def find_disoccluded_rays(theta, cameras, masks):
    return [ray for i, ray in enumerate(all_rays) if masks[i][ray.pixel] == 1 and not ray.is_covered_by_ref_view]

def compute_disocclusion_loss(theta, rays, inpainter):
    return inpainter_guidance_loss(theta, rays)
```

## Subtopics

### MVInpainter
MVInpainter is a multi-view consistent inpainting model designed to bridge 2D and 3D scene editing [S1]. It employs domain adapters and motion modules as video priors to enhance cross-view consistency [S1]. It introduces a Reference Key&Value concatenation technique for appearance consistency while incorporating slot attention to aggregate optical flow features for controlling camera movement without explicit pose conditions [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources. [G] Iterative optimization dominates runtime, scaling with $N_{depth}$, $N_{bilateral}$, $N_{do}$, and the cost of monocular depth estimation and bilateral solving per iteration.
*   **Memory Complexity:** Not given in the sources. [G] Requires storing NeRF parameters, input images, masks, and intermediate depth maps.
*   **Strengths:** Avoids view inconsistencies by relying on a single reference view; generates view-dependent effects; allows user control via a single image [S2].
*   **Limitations:** Relies on the quality of the single inpainted reference view; may struggle with complex geometry and textures in disoccluded regions [S1, S2].
*   **When to use:** When a user wants to inpaint a NeRF with specific content provided as a single 2D image and requires view-consistent results [S2].

## Background
Reference-guided Controllable Inpainting of NeRFs was introduced in 2023 [S2]. It addresses limitations in existing scene inpainting methods, such as inaccurate removal of large objects and lack of multi-view consistency [S1]. The method builds on the principles of differentiable volume rendering and NeRF optimization [Parent].
