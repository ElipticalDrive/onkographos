# Inpainting and Object Removal


## Overview
This family removes unwanted objects or fills occluded regions in a pre-trained NeRF representation [Parent]. Unlike standard NeRF training which reconstructs the entire scene from input views, these methods optimize the NeRF parameters to erase specific masked regions while maintaining geometric and photometric consistency across all unmasked views [Parent]. They are distinguished from sibling methods by their reliance on external 2D priors (such as inpainted images or diffusion models) to guide the 3D optimization, rather than relying solely on multi-view geometry or semantic segmentation alone [Parent].

## Shared principles
All methods operate on a pre-trained NeRF representation $f_\theta: (\mathbf{x}, \mathbf{d}) \to (\sigma, \mathbf{c})$ as defined in [Parent](12494-nerf-editing-and-inpainting-procedures.md). The core mechanism involves an optimization loop that minimizes a loss function $L$ to update the NeRF parameters $\theta$ [Parent].

The general optimization objective is:
$$
L = L_{render} + \lambda_{guidance} L_{guidance} + \lambda_{reg} L_{reg}
$$
where $L_{render}$ is the standard photometric reconstruction loss on visible pixels, $L_{guidance}$ incorporates external priors (e.g., 2D inpainted images, diffusion model gradients, or semantic features), and $L_{reg}$ prevents artifacts or overfitting [G].

Key shared components include:
1. **Masking/Selection:** A binary or probabilistic mask $M$ or selection field identifies the region of interest (ROI) or occluded areas [Parent].
2. **External Priors:** Methods rely on 2D priors to guide 3D changes, commonly using diffusion guidance (e.g., Score Distillation Sampling from text-to-image models) or semantic/text features (e.g., CLIP or LSeg) to align rendered features with prompts [Parent].
3. **View Consistency Enforcement:** To prevent inconsistencies across views, methods enforce multi-view constraints through implicit geometrical and photometric priors embodied by the neural network, which automatically propagates single-view edits to all views [Parent].

The optimization loop proceeds as follows:
```python
def optimize_nerf_inpainting(nerf_model, rays, masks, guidance_priors, lambda_guidance, lambda_reg, num_steps, lr):
    """
    General optimization loop for NeRF inpainting.
    Args:
        nerf_model: Pre-trained NeRF MLP.
        rays: Batch of camera rays with ground truth colors.
        masks: Binary masks (1 for masked/occluded, 0 for visible).
        guidance_priors: 2D prior colors for masked regions.
        lambda_guidance, lambda_reg: Loss weights.
        num_steps: Optimization iterations.
        lr: Learning rate.
    Returns:
        Updated NeRF model.
    """
    optimizer = torch.optim.Adam(nerf_model.parameters(), lr=lr)
    for step in range(num_steps):
        optimizer.zero_grad()
        # Render current NeRF predictions for the batch
        rendered_colors = nerf_model.render(rays)
        # Photometric loss on visible pixels (mask = 0)
        loss_render = torch.mean((rendered_colors - rays.gt_colors)**2 * (1 - masks))
        # Guidance loss on masked pixels (mask = 1)
        loss_guidance = torch.mean((rendered_colors - guidance_priors)**2 * masks)
        # Regularization loss (e.g., weight decay or density smoothness) [G]
        loss_reg = torch.sum(torch.square(nerf_model.parameters()))
        # Total loss
        loss = loss_render + lambda_guidance * loss_guidance + lambda_reg * loss_reg
        loss.backward()
        optimizer.step()
    return nerf_model
```

## Subtopics

### [NeRF-In Inpainting Optimization](12372-nerf-in-inpainting-optimization.md)
A framework that removes objects using a single user-drawn mask and 2D color/depth guidance. It jointly minimizes color and depth losses to ensure consistency, avoiding the artifacts of using multiple inconsistent 2D priors.

### [Adaptive View Selection for Inpainting](12405-adaptive-view-selection-for-inpainting.md)
Addresses inconsistency by adaptively switching between 2D inpainting priors and multi-view geometry based on local texture gradients. It is chosen when maintaining multi-view consistency is critical to prevent flickering in textured regions.

### [Reference-guided Controllable Inpainting of NeRFs](13952-reference-guided-controllable-inpainting-of-nerfs.md)
Uses a single inpainted reference view to guide geometry and appearance via back-projection and a bilateral solver. It ensures view-dependent effects (VDEs) and avoids the quality deterioration seen in methods requiring multiple inpainted views.

### Interactive Nerflets Editing
Selects individual objects using instance labels and manipulates the nerflet structure directly (e.g., copy-and-paste for duplication, deletion for removal) without additional optimization [S1]. It supports real-time volume-rendered RGB or depth images at up to 320 × 240 resolution while adjusting object bounding boxes [S1]. Performance benchmarks show 31 FPS on 4 A100 GPUs with 64 nerflets, achieving 457 million sample evaluations per second at 192 samples/pixel [S1]. When deleting objects, empty scene regions will not carry any density after deletion, as there is nothing there to evaluate [S1].

## Background
The problem of 3D scene inpainting emerged as NeRFs became popular for novel view synthesis, where removing objects or filling holes required more than just 2D image editing [G]. Early approaches adapted 2D inpainting techniques to 3D by optimizing NeRF parameters [G]. The field has evolved to include diffusion-based guidance and reference-guided consistency [G].
