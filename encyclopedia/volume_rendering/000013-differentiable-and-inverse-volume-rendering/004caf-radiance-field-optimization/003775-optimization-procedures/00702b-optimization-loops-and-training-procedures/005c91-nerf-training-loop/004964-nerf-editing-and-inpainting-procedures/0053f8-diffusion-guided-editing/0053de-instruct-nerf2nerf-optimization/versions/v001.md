# Instruct-NeRF2NeRF Optimization

Also called: Instruct-NeRF2NeRF optimization process, NeRF Editing via Diffusion Guidance

## Overview
Instruct-NeRF2NeRF is a method for editing pre-trained Neural Radiance Fields (NeRFs) using natural language instructions. It solves the problem of modifying 3D scene content (e.g., changing materials, adding objects) without requiring 3D ground truth or multi-view retraining. It differs from sibling methods like [RePaint-NeRF](14365-repaint-nerf.md) by using InstructPix2Pix for instruction-following generation rather than text-to-image diffusion with score distillation, and from [NeRF-In Inpainting Optimization](12372-nerf-in-inpainting-optimization.md) by supporting arbitrary semantic edits rather than just inpainting.

## How it works
**Inputs:**
1.  A pre-trained NeRF model $f_\theta: (\mathbf{x}, \mathbf{d}) \to (\sigma, \mathbf{c})$, typically initialized using the 'nerfacto' model from NeRFStudio trained for 30,000 iterations [S1].
2.  A set of input images $\{I_i\}$ used for the initial reconstruction [S1].
3.  A text instruction $T$ describing the desired edit (e.g., "turn the man into a bear") [S1].
4.  Guidance weights $s_I$ (image classifier-free guidance) and $s_T$ (text classifier-free guidance) [S1].

**Outputs:**
*   An edited NeRF model $f_{\theta'}$ with updated parameters $\theta'$ [S1].

**Data Structures:**
*   **NeRF Parameters $\theta$:** Standard MLP weights and biases for density $\sigma$ and color $\mathbf{c}$. Optimizers are re-initialized before editing begins [S1].
*   **Diffusion Model:** InstructPix2Pix, implemented via the Diffusers library [S1]. It takes an image and text prompt to generate an edited image.

**Numbered Steps:**
1.  **Initialization:** Load the pre-trained NeRF. Re-initialize the optimizers for $\theta$ in the NeRF training framework [S1].
2.  **Iteration Loop:** For each optimization step $k$:
    a.  **Render:** Select a single random view from the current NeRF parameters $\theta_k$. Render the image $I_{render}$ using standard volume rendering [S1].
    b.  **Edit:** Pass $I_{render}$, the text instruction $T$, and guidance weights $s_I, s_T$ to the InstructPix2Pix model. Generate the edited image $I_{edit}$ [S1].
    c.  **Loss Calculation:** Compute the photometric loss between the rendered image and the edited image:
        $$ L_{render} = \| I_{render} - I_{edit} \|_2^2 $$
        [S1]
    d.  **Backpropagation:** Backpropagate the gradient of $L_{render}$ through the rendering process to update the NeRF parameters $\theta$ [S1].
3.  **Termination:** Stop optimization after a subjective number of iterations determined by scene size:
    *   Small scenes (<100 input images): 3,000–4,000 iterations [S1].
    *   Large scenes (>200–300 input images): 7,000–8,000 iterations [S1].

**Parameters:**
*   $s_I$: Image classifier-free guidance weight. Typical values: 1.3 to 1.75 [S1]. Specific examples: 1.5 for Tree, Tents, Person, Fig 1; 1.5 for Bear; 1.3–1.5 for Fig 7 [S1].
*   $s_T$: Text classifier-free guidance weight. Typical values: 6.5 to 12.5 [S1]. Specific examples: 7.5–12.5 for Tree; 10.0 for Tents; 6.5–7.5 for Person, Fig 1, Bear; 6.5–8.5 for Fig 7 [S1].

**Edge Cases and Pitfalls:**
*   **No Convergence Point:** The diffusion model produces temporally varying images during optimization. The edit type and strength change over training, requiring subjective termination rather than a fixed convergence criterion [S1].
*   **Texture Blurriness:** Using Stable Diffusion's autoencoder on input images causes gradual texture blurriness. The autoencoder creates locally similar but non-3D-consistent textures, leading to blurry renders in the final reconstruction [S1].
*   **Single-View Artifacts:** Guidance is applied to a single view at a time, which can cause artifacts like "double faces" on added objects if not consistent across views [S1].
*   **View-Specific Instructions:** Edit instructions may only be relevant to certain camera views. If the subject is not prominent in a view, the edit may be absent or inconsistent in that view [S1].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of optimization iterations. Each iteration requires one NeRF forward pass (rendering) and one InstructPix2Pix forward pass (diffusion).
*   **Memory Complexity:** Dominated by the storage of the NeRF parameters and the diffusion model weights.
*   **Strengths:** Allows for arbitrary semantic edits via natural language without 3D supervision. Simple to implement using existing NeRF and Diffusion libraries.
*   **Limitations:** Lacks a single convergence point; results vary with iteration count. Prone to texture blurriness due to the diffusion autoencoder. Single-view guidance can lead to 3D inconsistencies (e.g., double objects). Cannot perform large spatial manipulations or complex object binding [S1].
*   **When to use:** When editing specific semantic attributes of a scene using text instructions is required, and 3D ground truth is unavailable.
*   **When not to use:** When high-fidelity texture preservation is critical, or when large geometric changes (e.g., moving large objects) are required [S1].

## Background
Instruct-NeRF2NeRF was introduced by [Zhizhuo Zhou and Shubham Tulsiani] in 2022 [S1]. It builds upon the InstructPix2Pix model [S1] and adapts it for 3D NeRF editing. The method leverages the ability of instruction-tuned diffusion models to modify images based on text prompts, extending this capability to the 3D domain through differentiable rendering.
