# RePaint-NeRF

Also called: Iterative DU, Iterative Dataset Update

## Overview
RePaint-NeRF is a framework for editing 3D content in Neural Radiance Fields (NeRF) using text prompts by leveraging a pre-trained diffusion model to guide changes in designated 3D content, ensuring view consistency and scene integrity [S1]. It solves the problem of inconsistent edits that arise when applying 2D image editing models (like InstructPix2Pix) independently to rendered frames [S2]. Unlike [Instruct-NeRF2NeRF Optimization](15089-instruct-nerf2nerf-optimization.md), which relies on a single alternating update scheme without explicit semantic masking for the target object, RePaint-NeRF explicitly extracts a view-consistent semantic mask in a first stage to isolate the target region, then uses a second stage to guide the diffusion model and NeRF optimization specifically within that mask while preserving the background [S1].

## How it works
RePaint-NeRF operates in two distinct stages: Semantic Mask Extraction and Text-to-3D Content Editing. It takes a pre-captured NeRF scene, its source data (images, camera poses, calibration), and a natural-language instruction as input, and produces an edited NeRF and edited input images [S2].

### Inputs and Outputs
*   **Inputs:**
    *   A reconstructed NeRF scene (typically Instant-NGP [S1]).
    *   A set of captured images $I^0_v$ and corresponding camera poses/calibration (from COLMAP) [S1, S2].
    *   A natural-language editing instruction (e.g., "turn him into Albert Einstein") [S2].
    *   A background prompt (BGT) to guide the filling of exposed areas [S1].
*   **Outputs:**
    *   An edited NeRF model.
    *   Edited versions of the input dataset images [S2].

### Data Structures
*   **NeRF Model:** Instant-NGP [Müller et al., 2022], based on a multi-resolution hash grid structure [S1].
*   **Feature Map:** Size $H \times W \times 512$. Interpolated from LSeg [Li et al., 2022] [S1].
*   **Depth Map:** Size $H \times W \times 1$. Normalized to range 0 to 1. Predicted by MiDAS [Ranftl et al., 2022] [S1].
*   **Semantic Mask:** $I_{mask}^{H \times W \times 1}$. Binary mask indicating the target object [S1].

### Stage 1: Semantic Mask Extraction
The goal is to extract a view-consistent semantic mask for the target object.

1.  **Feature and Depth Supervision:**
    *   Extract supervised semantic features from a pre-trained CLIP-based model (LSeg) [S1].
    *   Extract supervised depth information from a robust monocular depth estimation model (MiDAS) [S1].
2.  **Optimization:**
    *   Optimize a feature network $s: x \rightarrow f$ and NeRF parameters simultaneously.
    *   Minimize the first-stage loss:
        $$ L_{\text{first-stage}} = L_{\text{color}} + \lambda_{\text{feature}} L_{\text{feature}} + \lambda_{\text{depth}} L_{\text{depth}} $$
        where:
        *   $L_{\text{color}}$ is the standard NeRF color reconstruction loss.
        *   $L_{\text{feature}} = \sum_{r \in R} (F(r) - \hat{F}(r))^2$, where $F(r)$ is the ground truth feature from LSeg and $\hat{F}(r)$ is the rendered feature [S1].
        *   $L_{\text{depth}} = \sum_{r \in R} (D(r) - \hat{D}(r))^2$, where $D(r)$ is the ground truth depth from MiDAS and $\hat{D}(r)$ is the rendered depth [S1].
    *   **Parameters:** Adam optimizer, learning rate $1e-2$, batch size 4096, 2000 steps [S1].
3.  **Mask Generation:**
    *   Render the feature map $F_I$ from the optimized NeRF.
    *   Compute the mask using a selected patch feature $F_{\text{patch}}$ (mean feature of the target object):
        $$ I_{mask}^{H \times W \times 1} = 1(\text{Sim}(F_{\text{patch}}, F_I) > \alpha) $$
        where $\text{Sim}$ is a similarity function and $\alpha$ is a threshold [S1].
    *   **Note:** Patch features are preferred over text features for higher segmentation accuracy [S1].

### Stage 2: Text-to-3D Content Editing
This stage iteratively updates the dataset images using a diffusion model and re-trains the NeRF.

1.  **Initialization:**
    *   Cache original images $I^0_v$ separately to use as conditioning for the diffusion model [S2].
    *   Train a base NeRF using the mask information (pre-training phase, 3000 steps) [S1].
2.  **Iterative Update Loop:**
    *   The loop alternates between image updates and NeRF updates.
    *   **Image Update (Editing):** For a viewpoint $v$:
        *   Render current NeRF to get $I^i_v$.
        *   Create noisy input $z_t$: A linear combination of $\mathcal{N}(0,1)$ and $z_0 = E(I^i_v)$, following SDEdit [S2]. The noise level $t$ is chosen randomly from $[t_{\min}, t_{\max}]$ [S2].
        *   Edit using InstructPix2Pix:
            $$ I^{i+1}_v \leftarrow U_\theta(I^i_v, t; I^0_v, c_T) $$
            where $U_\theta$ is the DDIM sampling process with $s$ steps (typically 20) [S2].
            *   Conditioning image $c_I = I^0_v$ (original unedited image) [S2].
            *   Text instruction $c_T$ [S2].
        *   Replace the dataset image: $\text{Dataset}[v] = I^{i+1}_v$ [S2].
    *   **NeRF Update:**
        *   Sample random rays from the entire training dataset (including old cached images and newly updated images) [S2].
        *   Compute loss and update NeRF parameters.
        *   **Loss Function:**
            $$ L_{\text{repaint}} = \lambda_{\text{unmask}} L_{\text{unmask}} + \lambda_{\text{clip}} L_{\text{clip}} $$
            where:
            *   $L_{\text{unmask}} = \sum_{r \in R} (C(r)_{\text{unmask}} - \hat{C}(r)_{\text{unmask}})^2$ [S1].
                *   $C(r)_{\text{unmask}} = C(r) \times 1(I_{mask} < 0.5)$ [S1].
                *   $\hat{C}(r)_{\text{unmask}} = \hat{C}(r) \times 1(I_{mask} < 0.5)$ [S1].
                *   This loss constrains the unmasked region to prevent unwanted diffusion changes [S1].
            *   $L_{\text{clip}} = -\text{Sim}(Z_I, Z_{\text{BGT}})$ [S1].
                *   $Z_I$ is the latent feature of the rendered image $I$.
                *   $Z_{\text{BGT}}$ is the latent feature of the background prompt encoded by CLIP [S1].
                *   This guides the filling of "black holes" (previously covered areas exposed by smaller generated objects) [S1].
    *   **Parameters:**
        *   Adan optimizer, learning rate $1e-3$ decaying to $1e-4$, batch size 1 [S1].
        *   Update counts: $d=1$ (image updates), $n=10$ (NeRF updates) per iteration [S2].
        *   Max iterations: 30k [S2].
        *   Generation steps: 10,000 steps after pre-training [S1].

```python
# Stage 1: Semantic Mask Extraction
def stage_1_semantic_mask_extraction(nerf, images, poses, lseg_features, midas_depths):
    # Initialize feature network and NeRF parameters
    # Optimize to minimize L_first_stage = L_color + lambda_feature * L_feature + lambda_depth * L_depth
    # L_feature = sum((F(r) - F_hat(r))^2)
    # L_depth = sum((D(r) - D_hat(r))^2)
    # Optimizer: Adam, lr=1e-2, batch_size=4096, steps=2000
    
    # Render feature map F_I
    F_I = render_feature_map(nerf, images, poses)
    
    # Get patch feature F_patch from user selection or text
    F_patch = get_patch_feature(images, poses, selection)
    
    # Compute mask
    alpha = 0.5 # Threshold
    I_mask = 1(similarity(F_patch, F_I) > alpha)
    return I_mask

# Stage 2: Text-to-3D Content Editing
def stage_2_text_to_3d_editing(nerf, images, poses, text_instruction, background_prompt, mask):
    # Cache original images
    I_0 = images.copy()
    
    # Pre-train NeRF on base data with mask info (3000 steps)
    train_nerf_base(nerf, images, poses, mask, steps=3000)
    
    # Iterative Loop
    for iteration in range(30000):
        # Image Updates
        for viewpoint v in random_order(poses):
            # Render current NeRF
            I_i_v = render_nerf(nerf, v)
            
            # Create noisy input z_t (SDEdit)
            t = random.uniform(t_min=0.02, t_max=0.98)
            z_t = add_noise(I_i_v, t)
            
            # Edit using InstructPix2Pix (DDIM sampling, s=20 steps)
            # Conditioning: cI = I_0[v], cT = text_instruction
            I_i_plus_1_v = instruct_pix2pix_edit(z_t, cI=I_0[v], cT=text_instruction, steps=20)
            
            # Update dataset
            images[v] = I_i_plus_1_v
        
        # NeRF Updates
        for step in range(n=10):
            # Sample random rays from entire dataset
            rays = sample_rays(images, poses)
            
            # Compute Loss
            # L_repaint = lambda_unmask * L_unmask + lambda_clip * L_clip
            # L_unmask = sum((C(r)_unmask - C_hat(r)_unmask)^2)
            # C(r)_unmask = C(r) * 1(mask < 0.5)
            # L_clip = -similarity(Z_I, Z_BGT)
            # Z_I = clip_feature(rendered_image)
            # Z_BGT = clip_feature(background_prompt)
            loss = compute_repaint_loss(rays, nerf, mask, background_prompt, lambda_unmask=100, lambda_clip=1.0)
            
            # Update NeRF
            # Optimizer: Adan, lr=1e-3->1e-4, batch_size=1
            nerf.update(loss)
```

### Parameters
*   **Noise Range:** $[t_{\min}, t_{\max}] = [0.02, 0.98]$ [S2].
*   **Denoising Steps:** 20 [S2].
*   **Classifier-free Guidance:** $s_I = 1.5$ (image), $s_T = 7.5$ (text) [S2].
*   **$\lambda_{\text{unmask}}$:** 100. Controls constraint strength on the unmasked part. Too large values restrict generative ability [S1].
*   **$\lambda_{\text{clip}}$:** Weight for CLIP loss. Balances change of target object and background filling [S1].
*   **$\lambda_{\text{feature}}, \lambda_{\text{depth}}$:** Weights for Stage 1. Values not explicitly given in text [S1].

### Edge Cases and Pitfalls
*   **Black Holes:** If the newly generated object is smaller than the original, previously covered areas become "black holes" (unknown content). Mitigated by adding a background prompt (BGT) and CLIP loss [S1].
*   **Inconsistency:** At early iterations, edited images may be inconsistent across viewpoints. The iterative process allows them to converge on a globally consistent depiction [S2].
*   **Depth Noise:** Noise in depth estimation causes imprecise semantic mask segmentation. Mitigated by coarse depth supervision from MiDAS [S1].
*   **Drift:** Recurrent synthesis can cause drift. Prevented because the diffusion model is conditioned on the un-edited images ($I^0_v$) [S2].

## Subtopics

### Unmasked Region Weighting
A scalar weight $\lambda_{\text{unmask}}$ applied to the loss function to constrain the unmasked region and prevent unwanted diffusion model changes [S1]. When $\lambda_{\text{unmask}} = 0$, no constraints are applied to the background. Typical value is 100; too large values severely restrict the diffusion model's generative ability and slow generation speed [S1].

### Mask+SDS
A variant using Score Distillation Sampling (SDS) instead of CLIP loss for the masked region. Produces significantly better texture and shape than Mask+CLIP because SDS provides stronger gradient guidance for the diffusion model [S1].

### View-consistent Editing (VcEDIT)
A method enhancing editing consistency using cross-attention and editing consistency modules [S3]. Uses a cross-attention consistency module (CCM) to harmonize cross-attention maps across all views and an editing consistency module (ECM) to calibrate inconsistent outputs by fine-tuning a source-cloned 3D Gaussian Splatting (3DGS) model [S3]. Integrates an iterative pattern of editing rendered images and updating the 3DGS, using InfEdit for rapid processing [S3].

## Operating characteristics
*   **Time Complexity:** The process is time-consuming. Editing a car color may take 5 minutes, while changing a car to a chocolate candy car may take over 40 minutes [S1].
*   **Memory Complexity:** Space-consuming due to the need to render whole views and store feature maps. Uses Instant-NGP to accelerate training and rendering [S1].
*   **Hardware:** Tested on a single NVIDIA RTX 3090 GPU [S1]. Instruct-NeRF2NeRF (sibling) takes roughly an hour on a single NVIDIA Titan RTX (15GB memory) for 30k iterations [S2].
*   **Scaling:** Resolution-dependent. LLFF resized to 504x378, Blender to 400x400 to save GPU memory [S1].
*   **Strengths:** View consistency, scene integrity, ability to edit complex scenes with text prompts, alleviates black holes [S1].
*   **Limitations:** Time-consuming, space-consuming, restricted view angles can cause artifacts (e.g., daisy composed of previous orchids) [S1].

## Background
RePaint-NeRF was proposed in 2023 at the Thirty-Second International Joint Conference on Artificial Intelligence (IJCAI-23) [S1]. It builds on DreamFusion [Poole et al., 2022] for 3D generation and DFF [Kobayashi et al., 2022] for semantic feature extraction. It leverages Stable Diffusion [Rombach et al., 2022] for guidance and CLIP [Radford et al., 2021] for semantic features and background filling. The method addresses the limitations of previous approaches that could not extend editing to invisible content or maintain view consistency in complex scenes [S1].
