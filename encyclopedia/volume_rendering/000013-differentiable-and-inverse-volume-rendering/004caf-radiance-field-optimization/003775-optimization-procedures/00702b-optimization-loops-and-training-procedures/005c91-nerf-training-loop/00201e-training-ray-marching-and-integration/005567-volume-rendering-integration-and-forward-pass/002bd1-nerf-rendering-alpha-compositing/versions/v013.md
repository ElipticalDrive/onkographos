# NeRF Rendering (Alpha Compositing)

Also called: NeRF Integration, NeRF Rendering Equation, Alpha Compositing in NeRF, Neural Radiance Field Volume Rendering

## Overview
NeRF Rendering (Alpha Compositing) is the differentiable volume rendering technique used to synthesize novel views from a Neural Radiance Field (NeRF) by integrating sampled density and color along camera rays [S1, S12]. It solves the problem of mapping a continuous 5D implicit function (mapping spatial position and view direction to density and radiance) into a discrete 2D image by numerically approximating the volume rendering integral [S11, S12]. Unlike standard ray tracing which uses deterministic paths, NeRF leverages a probabilistic function to determine the expected value of color along the ray, handling view-dependent effects (non-Lambertian materials) where color changes based on viewpoint [S12]. It sets itself apart from its sibling [NeRF-style Volume Rendering Integrator](5964-nerf-style-volume-rendering-integrator.md) by explicitly defining the standard alpha compositing formulation with stratified sampling and the specific handling of the white background term, which is foundational to the original NeRF implementation [S1, S8].

## How it works
**Inputs:**
*   Camera ray $r(t) = o + td$, defined by origin $o$ and direction $d$ [S1, S12].
*   Integration bounds $t_n$ (near, camera center) and $t_f$ (far, scene boundary) [S1, S11].
*   Number of samples $N$ (typically 64 for both coarse and fine networks) [S10].
*   NeRF model $F_\Theta$ (MLP) taking 5D input $(x, d)$ and outputting $(\sigma, c)$ [S11, S16].

**Outputs:**
*   Rendered RGB color $\hat{C}(r)$ [S1][S6, unofficial].
*   Expected depth $\hat{D}(r)$ [S1][S6, unofficial].
*   (Optional) Accumulated opacity $\alpha_{total} = \sum w_i$ [S8].

**Data Structures:**
*   **Samples:** Array of $N$ depth values $t_i$ along the ray.
*   **Predictions:** Tensor of shape $(N, 4)$ containing RGB color $c_i$ and density $\sigma_i$ for each sample.
*   **Deltas:** Array of distances $\delta_i = t_{i+1} - t_i$ between adjacent samples, with $\delta_N$ set to a large value (e.g., $10^{10}$) to handle the end of the ray [S6, unofficial][S8].

**Steps:**

1.  **Sampling:** Discretize the ray interval $[t_n, t_f]$ into $N$ equally spaced bins. Draw one sample $t_i$ uniformly at random from within each bin $[t_n + \frac{i-1}{N}(t_f - t_n), t_n + \frac{i}{N}(t_f - t_n)]$ [S1, S11, S12]. This is known as non-deterministic stratified sampling [S1].
2.  **Querying:** For each sample point $x_i = o + t_i d$, query the NeRF model with $(x_i, d)$ to obtain volume density $\sigma_i$ and color $c_i$ [S1, S11]. Apply activation functions: $\sigma_i = \text{ReLU}(\sigma_i)$ and $c_i = \text{Sigmoid}(c_i)$ to ensure non-negative density and valid color range [S8].
3.  **Delta Calculation:** Compute the distance between adjacent samples: $\delta_i = t_{i+1} - t_i$ for $i=1 \dots N-1$. Append a large value (e.g., $10^{10}$) for the last segment $\delta_N$ to ensure the ray exits the scene [S6, unofficial][S8]. If the ray direction is not normalized, multiply deltas by $\|d\|$ to convert to real-world distance [S6, unofficial].
4.  **Alpha Compositing:** Compute the opacity $\alpha_i$ for each sample using the volume density and delta:
    $$ \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
    [S1, S8].
5.  **Transmittance:** Compute the accumulated transmittance $T_i$, representing the probability that the ray reaches sample $i$ without being intercepted:
    $$ T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right) = \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    [S1, S4, S8]. To prevent numerical instability (NaNs) when $\sigma_i \delta_i$ is large or small, add a small epsilon ($\epsilon = 10^{-10}$) to the term $(1 - \alpha_i)$ before the cumulative product, and use `exclusive=True` for the cumulative product so $T_1 = 1.0$ [S8].
6.  **Weighting:** Calculate the weight $w_i$ for each sample:
    $$ w_i = \alpha_i T_i $$
    [S1, S8].
7.  **Compositing:** Compute the final RGB color by summing the weighted colors:
    $$ \hat{C}(r) = \sum_{i=1}^{N} w_i c_i $$
    [S1, S8].
8.  **Depth Estimation:** Compute the expected depth by summing the weighted sample depths:
    $$ \hat{D}(r) = \sum_{i=1}^{N} w_i t_i $$
    [S1, S8].
9.  **Background Handling:** If a white background is assumed, add the contribution of rays that exit the scene without being fully absorbed:
    $$ \hat{C}_{final}(r) = \hat{C}(r) + (1 - \sum_{i=1}^{N} w_i) \cdot c_{bg} $$
    where $c_{bg} = (1, 1, 1)$ [S6, unofficial][S8].

**Pseudocode:**

```python
import torch
import math

def nerf_render(rays, t_vals, model, N_samples, white_background=True, epsilon=1e-10):
    """
    Render a batch of rays using NeRF alpha compositing.
    
    Args:
        rays: Tensor of shape (B, H, W, 3) representing ray origins o.
        t_vals: Tensor of shape (B, H, W, N_samples) representing sample depths t_i.
        model: NeRF MLP function taking (points, directions) -> (sigma, rgb).
        N_samples: Number of samples per ray.
        white_background: Boolean, whether to add white background term.
        epsilon: Small value for numerical stability in transmittance.
        
    Returns:
        rgb: Rendered RGB image (B, H, W, 3).
        depth: Rendered depth map (B, H, W).
    """
    # 1. Get ray directions
    # Assuming rays input contains both origin and direction, or direction is derived.
    # For this pseudocode, assume we have ray_directions of shape (B, H, W, 3)
    # and ray_origins of shape (B, H, W, 3).
    # If rays input is just directions, origins are needed separately.
    # Let's assume standard NeRF setup where we have o and d.
    
    # 2. Query NeRF Model
    # Points x_i = o + t_i * d
    # Expand dimensions for broadcasting
    # o: (B, H, W, 1, 3)
    # d: (B, H, W, 1, 3)
    # t_vals: (B, H, W, N_samples, 1)
    
    # Note: In practice, points are often flattened for batched model evaluation
    # x_flat = o[..., None, :] + t_vals[..., None, :] * d[..., None, :]
    # x_flat shape: (B, H, W, N_samples, 3)
    
    # Flatten for model input
    B, H, W, N = t_vals.shape
    x_flat = rays['origins'].unsqueeze(3) + t_vals.unsqueeze(4) * rays['directions'].unsqueeze(3)
    x_flat = x_flat.reshape(-1, N, 3) # (B*H*W, N, 3)
    
    # Get direction for all samples (same for all samples on a ray)
    d_flat = rays['directions'].unsqueeze(3).expand(-1, -1, -1, N).reshape(-1, N, 3)
    
    # Query model
    # model returns (sigma, rgb)
    # sigma: (B*H*W, N, 1)
    # rgb: (B*H*W, N, 3)
    sigma_raw, rgb_raw = model(x_flat, d_flat)
    
    # 3. Apply Activations
    sigma = torch.relu(sigma_raw) # Ensure non-negative density
    rgb = torch.sigmoid(rgb_raw)  # Ensure color in [0, 1]
    
    # 4. Compute Deltas
    # delta_i = t_{i+1} - t_i
    deltas = t_vals[:, :, :, 1:] - t_vals[:, :, :, :-1] # (B, H, W, N-1)
    
    # Append large delta for the last segment
    # delta_inf shape: (B, H, W, 1)
    delta_inf = torch.full_like(deltas[:, :, :, :1], 1e10)
    deltas = torch.cat([deltas, delta_inf], dim=-1) # (B, H, W, N)
    
    # Normalize deltas by ray direction norm if not unit length
    # deltas = deltas * torch.norm(rays['directions'], dim=-1, keepdim=True)
    
    # 5. Compute Alpha
    # alpha_i = 1 - exp(-sigma_i * delta_i)
    alpha = 1.0 - torch.exp(-sigma.squeeze(-1) * deltas) # (B, H, W, N)
    
    # 6. Compute Transmittance
    # T_i = prod_{j=1}^{i-1} (1 - alpha_j)
    # Use exclusive cumprod for T_1 = 1.0
    # Add epsilon for stability
    transmittance = torch.cumprod(1.0 - alpha + epsilon, dim=-1, exclusive=True) # (B, H, W, N)
    
    # 7. Compute Weights
    # w_i = alpha_i * T_i
    weights = alpha * transmittance # (B, H, W, N)
    
    # 8. Compositing
    # RGB = sum(w_i * c_i)
    rgb_final = torch.sum(weights.unsqueeze(-1) * rgb, dim=-2) # (B, H, W, 3)
    
    # Depth = sum(w_i * t_i)
    depth_final = torch.sum(weights * t_vals, dim=-1) # (B, H, W)
    
    # 9. Background Handling
    if white_background:
        # Sum of weights is the total opacity
        weights_sum = torch.sum(weights, dim=-1, keepdim=True) # (B, H, W, 1)
        # Add (1 - opacity) * white_background
        rgb_final = rgb_final + (1.0 - weights_sum) * 1.0
        
    return rgb_final, depth_final
```

## Subtopics

### [Depth-Guided Sampling](7490-depth-guided-sampling.md)
Depth-Guided Sampling is a ray sampling strategy for neural radiance fields that focuses scene sampling on estimated surface regions using depth priors from input views to increase sample density in relevant areas, thereby improving synthesis quality and allowing a reduction in the number of samples per ray. It sets itself apart from uniform or hierarchical stratified sampling by explicitly leveraging predicted depth maps (and their uncertainties) to bias the placement of query points toward likely object surfaces, reducing redundant sampling in free space or occluded regions.

### [Rendered Depth-Guided Warping](8893-rendered-depth-guided-warping.md)
Rendered Depth-Guided Warping is a consistency regularization technique used during NeRF training to enforce geometric coherence between observed and unobserved viewpoints without the computational cost of full-resolution rendering. It generates a warped image from a source view using a low-resolution rendered depth map from a target view, enabling the computation of a consistency loss that encourages globally consistent geometry and appearance. Unlike [Depth-Guided Sampling](7490-depth-guided-sampling.md) which uses depth to guide ray sampling, this method uses rendered depth to warp existing image data for loss calculation.

### [Depth-Prior Guided Stratified Sampling](11292-depth-prior-guided-stratified-sampling.md)
Depth-Prior Guided Stratified Sampling replaces uniform depth sampling in volume rendering by using predicted depth priors and associated confidence bounds to focus sampling on likely object surfaces.

### [Neus SDF Volume Rendering](12443-neus-sdf-volume-rendering.md)
Neus SDF Volume Rendering is a technique that renders 3D scenes represented as Signed Distance Functions (SDF) or Signed Ray Distance Functions (SRDF) by accumulating color and depth along rays using alpha compositing. It solves the problem of precisely extracting geometric surfaces from implicit representations by replacing the standard NeRF density field with an SDF-based weighting scheme. It differs from standard NeRF rendering by using a trainable S-density function to concentrate weight at the zero-level set of the SDF, ensuring the surface contributes most to the image, and adapts this theory to SRDF by treating surface normals as irrelevant to the value distribution.

### [Progressive Blur Estimation](14151-progressive-blur-estimation.md)
Progressive Blur Estimation (PBE) is a two-stage implicit function module that estimates defocus and motion blur by predicting multiple ray origins, directions, and blending weights for each pixel. It solves the problem of rendering blurry observations from a radiance field by modeling blur as a distribution of rays rather than a single ray. It sets itself apart from single-stage blur models by using a coarse stage to predict initial kernel locations and a refinement stage that incorporates ray features for fine-grained blur modeling, which is more accurate and efficient than a single-stage approach with ray features.

### [MipNerfModel](14207-mipnerfmodel.md)
The MipNerfModel is a Neural Radiance Field (NeRF) architecture that approximates integrated positional encoding by treating rays as cones or cylinders rather than infinitesimally thin lines, thereby solving aliasing artifacts caused by high-frequency scene details. It distinguishes itself from standard NeRF implementations by using multi-level sampling (coarse and fine) and integrated positional encoding to model the frequency content of the signal along the ray, which is essential for training on unbounded, outdoor scenes.

### [Event Simulation from NeRF](15450-event-simulation-from-nerf.md)
Event Simulation from NeRF generates virtual event data from a NeRF model to supervise training using real event camera observations. It solves the problem of motion blur in NeRF reconstruction by modeling the temporal integration of light during camera exposure. It differs from sibling methods like [Depth-Guided Sampling](7490-depth-guided-sampling.md) by explicitly simulating asynchronous event streams rather than static depth or color, allowing for event-driven bundle adjustment to refine camera poses and recover sharp geometry.

## Operating characteristics
*   **Time Complexity:** $O(N \cdot P)$ per ray, where $N$ is the number of samples and $P$ is the cost of the MLP query. The total time is proportional to the number of pixels and rays processed in parallel [S1, S12].
*   **Memory Complexity:** $O(N \cdot B)$ for storing intermediate tensors (alpha, transmittance, weights) for a batch of $B$ rays [S8].
*   **Measured Performance:** The original NeRF implementation required extremely high computing power and long training times [S12]. Standard implementations render at roughly 4-35 fps depending on resolution and optimization (e.g., Raymarcher variant achieves 34.9 fps on ShapeNet cars, while standard AVR is slower at 4.2 fps) [S20, unofficial]. Real-time variants like HeadNeRF can achieve >40 fps on NVIDIA 3090 GPUs [S21].
*   **Strengths:** Handles view-dependent effects (non-Lambertian materials) effectively [S12]. Differentiable, allowing end-to-end training from multi-view images [S1, S4]. Can render depth and other auxiliary outputs (instance logits, object codes) alongside color [S1][S5, unofficial][S14].
*   **Limitations:** High computational cost for high-resolution rendering without acceleration structures (like occupancy grids or hash encodings) [S12, S4]. Sensitive to sampling strategy; uniform sampling may waste samples in empty space [S1, S4].
*   **When to Use:** When synthesizing novel views from a set of multi-view images with known camera poses, especially for scenes with complex lighting or view-dependent effects [S12].
*   **When Not to Use:** When real-time performance is critical without hardware acceleration or simplified representations (e.g., use [Raymarcher](15450-event-simulation-from-nerf.md) or explicit representations like Plenoxels) [S20, unofficial][S11].

## Background
NeRF (Neural Radiance Fields) was first presented by Mildenhall et al. in 2020 [S12]. It represents a static scene as a continuous 5D function $F_\Theta: (x, d) \rightarrow (c, \sigma)$, mapping spatial location $x=(x,y,z)$ and viewing direction $d=(\theta, \phi)$ to emitted color $c$ and volume density $\sigma$ [S11, S12]. The method was inspired by classical volume rendering [22] and uses positional encoding to improve fine detail reconstruction [S1, S12]. Significant implementations include Instant NGP by Müller et al. (2022), which introduced multi-resolution hash encoding to significantly reduce processing time [S12]. It is used in cultural heritage for image-based reconstruction of 3D models, particularly for challenging surfaces like metallic, translucent, or transparent objects [S12].
