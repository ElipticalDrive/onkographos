# SqueezeNeRF

Also called: SqueezeNeRF (1K cache)

## Overview
SqueezeNeRF is a memory-efficient neural rendering method that further factorizes the position-dependent Multi-Layer Perceptron (MLP) of FastNeRF into three separate 2D networks operating on coordinate pairs $(x,y)$, $(y,z)$, and $(z,x)$ to reduce cache size complexity from $O(n^3)$ to $O(n^2)$ [S1]. It builds on FastNeRF by replacing the dense 3D position cache with a set of 2D position caches and a 2D direction cache, enabling real-time inference with significantly lower memory overhead than FastNeRF or NeRF-SH while maintaining high rendering speeds [S1].

## How it works
### Inputs and Outputs
**Inputs:**
- Camera viewing direction $(\theta, \phi)$ [S1].
- 3D spatial coordinates $(x, y, z)$ of sample points along a ray [S1].
- Pre-trained cache files containing outputs of the position-conditioned and view-conditioned networks [S1].

**Outputs:**
- Volume density $\sigma$ [S1].
- Radiance map components $(u, v, w)$ [S1].
- Final pixel color $(r, g, b)$ via volume rendering [S1].

### Data Structures and Cache Layout
The method relies on dense caches for the outputs of the neural networks [S1]. The cache layout differs between the default architecture and the alternate architecture [S1].

**Default Architecture Cache:**
- **Position Caches:** Three caches corresponding to networks $F_{pos}^{xy}$, $F_{pos}^{yz}$, and $F_{pos}^{zx}$ [S1]. Each cache stores outputs for $n_p^2$ coordinate pairs [S1].
  - For each pair, the network outputs a scalar $\sigma_0^j$ and three $D$-dimensional vectors $(u_0^j, v_0^j, w_0^j)$, along with scaling weights $W_\sigma^j$ (scalar) and $W_k^j$ ($D$-dimensional vectors for $k \in \{u,v,w\}$) [S1].
  - Storage: $\sigma_0^j$ is stored as a 32-bit float [S1]. $u_0^j, v_0^j, w_0^j$ and weights are stored as 16-bit floats [S1].
  - Total storage per 3D point combination (conceptually $n_p^3$) is $3n_p^2(3D + 1)$ values [S1].
- **Direction Cache:** One cache for $F_{dir}$ storing $\beta$ for $n_d^2$ direction pairs $(\theta, \phi)$ [S1].
  - Storage: $\beta$ is stored as 16-bit floats [S1]. Total storage is $n_d^2(D)$ values [S1].

**Alternate Architecture Cache (SqueezeNeRF alt):**
- **Position Caches:** Same structure as default, but outputs are vectors [S1].
  - $F_{pos}^j$ outputs $\sigma^j \in \mathbb{R}^{D_\sigma}$ and $k^j \in \mathbb{R}^{D_k}$ for $k \in \{u,v,w\}$ [S1].
  - Storage: All values stored as 16-bit floats [S1].
  - Total storage per 3D point combination is $3n_p^2(3D + D_\sigma)$ values [S1].
- **Direction Cache:** Same as default [S1].

**Parameters:**
- $n_p$: Number of bins per position dimension [S1]. Typical values: 512 ('512 cache') or 1024 ('1K cache') [S1].
- $n_d$: Number of bins per direction dimension [S1]. Typical values: 64 (synthetic 360° scenes) or 32 (LLFF dataset) [S1].
- $D$: Dimensionality of radiance map vectors [S1]. Typical value: 8 [S1].
- $D_\sigma, D_k$: Dimensionality of outputs in alternate architecture [S1]. Typical values: $D_\sigma=12, D_k=8$ [S1].
- MLP Hidden Dimensions: Position MLPs have 6 layers with 256 hidden units [S1]. View MLP has 4 layers with 128 hidden units [S1].

### Numbered Steps

1.  **Network Factorization:** Split the position-dependent network $F_{pos}$ from FastNeRF into three separate MLPs: $F_{pos}^{xy}$, $F_{pos}^{yz}$, and $F_{pos}^{zx}$ [S1].
2.  **Network Definition:**
    -   For the **default** configuration, each $F_{pos}^j$ (where $j \in \{(x,y), (y,z), (z,x)\}$) maps 2D coordinates to:
        $$ F_{pos}^j: j \rightarrow \{(\sigma_0^j, W_\sigma^j), (w_j^u, u_0^j, w_j^v, v_0^j, w_j^w, w_0^j)\} $$
        where $\sigma_0^j$ is a scalar and $u_0^j, v_0^j, w_0^j$ are $D$-dimensional vectors [S1].
    -   For the **alternate** configuration, $F_{pos}^j$ maps to $\{\sigma^j, u^j, v^j, w^j\}$ where $\sigma^j \in \mathbb{R}^{D_\sigma}$ and $k^j \in \mathbb{R}^{D_k}$ [S1].
    -   The view-dependent network $F_{dir}$ remains unchanged from FastNeRF, mapping $(\theta, \phi) \rightarrow \beta \in \mathbb{R}^D$ [S1].
3.  **Cache Generation (Training Phase):**
    -   Train the networks using standard NeRF training procedures, including hierarchical sampling and positional encoding [S1].
    -   Discretize the input space into a grid of $n_p \times n_p$ for each position pair and $n_d \times n_d$ for directions [S1].
    -   Compute the network outputs for all grid points and store them in the cache files using the precision specified (32-bit for $\sigma_0$, 16-bit for others) [S1].
4.  **Inference Query (Ray Marching):**
    -   Sample $N=256$ points along the ray [S1].
    -   For each sample point with coordinates $(x,y,z)$ and direction $(\theta, \phi)$:
        a.  **Fetch Position Outputs:** Retrieve $\sigma_0^j, u_0^j, v_0^j, w_0^j$ (or $\sigma^j, k^j$ for alt) from the three position caches using **nearest neighbor interpolation** [S1].
        b.  **Fetch Direction Output:** Retrieve $\beta$ from the direction cache using **bilinear interpolation** [S1].
        c.  **Compute Intermediate Density and Radiance (Default):**
            $$ \sigma^j = \sigma_0^j \cdot W_\sigma^j $$
            $$ k^j = W_k^j \cdot k_0^j \quad \forall k \in \{u, v, w\} $$
            where $\cdot$ denotes pointwise multiplication [S1].
        d.  **Combine Outputs (Default):**
            $$ \sigma = \prod_{j \in \{xy, yz, zx\}} \sigma^j $$
            $$ k = \sum_{j \in \{xy, yz, zx\}} k^j \quad \forall k \in \{u, v, w\} $$
            Thus, $u = \sum u^j, v = \sum v^j, w = \sum w^j$ [S1].
        e.  **Combine Outputs (Alternate):**
            $$ \sigma = W_\sigma [\text{concat}(\{\sigma^j\})] + b_\sigma $$
            $$ k = W_k [\text{concat}(\{k^j\})] + b_k \quad \forall k \in \{u, v, w\} $$
            where $W_\sigma \in \mathbb{R}^{1 \times 3D_\sigma}, b_\sigma \in \mathbb{R}, W_k \in \mathbb{R}^{D \times 3D_k}, b_k \in \mathbb{R}^D$ are learnable parameters stored in the cache [S1].
        f.  **Compute Color:**
            $$ c = (r, g, b) = \sum_{i=1}^D \beta_i (u_i, v_i, w_i) = \beta^T \cdot (u, v, w) $$
            [S1].
        g.  **Volume Rendering:** Compute final pixel color using standard volume rendering integration based on $\sigma$ and $c$ [S1].

def nearest_neighbor_interpolate(cache_grid, coord):
    """
    Nearest neighbor interpolation on a 2D cache grid.
    coord: (u, v) float coordinates in [0, 1].
    """
    idx_u = int(coord[0] * (cache_grid.shape[0] - 1))
    idx_v = int(coord[1] * (cache_grid.shape[1] - 1))
    idx_u = np.clip(idx_u, 0, cache_grid.shape[0] - 1)
    idx_v = np.clip(idx_v, 0, cache_grid.shape[1] - 1)
    return cache_grid[idx_u, idx_v]

def bilinear_interpolate(cache_grid, coord):
    """
    Bilinear interpolation on a 2D cache grid.
    coord: (u, v) float coordinates in [0, 1].
    """
    u, v = coord
    u0, v0 = int(u * (cache_grid.shape[0] - 1)), int(v * (cache_grid.shape[1] - 1))
    u1, v1 = np.clip(u0 + 1, 0, cache_grid.shape[0] - 1), np.clip(v0 + 1, 0, cache_grid.shape[1] - 1)
    du, dv = u * (cache_grid.shape[0] - 1) - u0, v * (cache_grid.shape[1] - 1) - v0
    top = cache_grid[u0, v0] * (1 - du) + cache_grid[u0, v1] * du
    bot = cache_grid[u1, v0] * (1 - du) + cache_grid[u1, v1] * du
    return top * (1 - dv) + bot * dv

def volume_render(t_vals, sigma, color):
    """
    Standard volume rendering integration [G].
    t_vals: (N,) distances along ray.
    sigma: (N,) volume density.
    color: (N, 3) color at samples.
    """
    dt = np.diff(t_vals, prepend=0.0)
    alpha = 1.0 - np.exp(-sigma * dt)
    T = np.exp(-np.cumsum(sigma * dt))
    weights = alpha * T
    return np.sum(weights[:, None] * color, axis=0)

def squeeze_nerf_infer_default(ray_origins, ray_directions, n_samples=256, 
                               pos_caches=None, dir_cache=None, D=8):
    """
    Default SqueezeNeRF inference.
    """
    t_vals = np.linspace(0.0, 1.0, n_samples)
    points = ray_origins[:, None, :] + ray_directions[:, None, :] * t_vals[None, :, None]
    num_rays = points.shape[0]
    
    sigma_total = np.ones(num_rays)
    u_total = np.zeros((num_rays, D))
    v_total = np.zeros((num_rays, D))
    w_total = np.zeros((num_rays, D))
    
    for i in range(n_samples):
        p = points[:, i, :]
        theta = np.arccos(np.clip(p[:, 2] / (np.linalg.norm(p, axis=1) + 1e-8), -1.0, 1.0))
        phi = np.arctan2(p[:, 1], p[:, 0])
        theta_norm = (theta / np.pi) * 0.5
        phi_norm = (phi / (2 * np.pi)) + 0.5
        
        sigma_xy = nearest_neighbor_interpolate(pos_caches['xy']['sigma_0'], (p[:, 0], p[:, 1]))
        u_xy = nearest_neighbor_interpolate(pos_caches['xy']['u_0'], (p[:, 0], p[:, 1]))
        v_xy = nearest_neighbor_interpolate(pos_caches['xy']['v_0'], (p[:, 0], p[:, 1]))
        w_xy = nearest_neighbor_interpolate(pos_caches['xy']['w_0'], (p[:, 0], p[:, 1]))
        w_sigma_xy = nearest_neighbor_interpolate(pos_caches['xy']['w_sigma'], (p[:, 0], p[:, 1]))
        w_u_xy = nearest_neighbor_interpolate(pos_caches['xy']['w_u'], (p[:, 0], p[:, 1]))
        w_v_xy = nearest_neighbor_interpolate(pos_caches['xy']['w_v'], (p[:, 0], p[:, 1]))
        w_w_xy = nearest_neighbor_interpolate(pos_caches['xy']['w_w'], (p[:, 0], p[:, 1]))
        
        sigma_yz = nearest_neighbor_interpolate(pos_caches['yz']['sigma_0'], (p[:, 1], p[:, 2]))
        u_yz = nearest_neighbor_interpolate(pos_caches['yz']['u_0'], (p[:, 1], p[:, 2]))
        v_yz = nearest_neighbor_interpolate(pos_caches['yz']['v_0'], (p[:, 1], p[:, 2]))
        w_yz = nearest_neighbor_interpolate(pos_caches['yz']['w_0'], (p[:, 1], p[:, 2]))
        w_sigma_yz = nearest_neighbor_interpolate(pos_caches['yz']['w_sigma'], (p[:, 1], p[:, 2]))
        w_u_yz = nearest_neighbor_interpolate(pos_caches['yz']['w_u'], (p[:, 1], p[:, 2]))
        w_v_yz = nearest_neighbor_interpolate(pos_caches['yz']['w_v'], (p[:, 1], p[:, 2]))
        w_w_yz = nearest_neighbor_interpolate(pos_caches['yz']['w_w'], (p[:, 1], p[:, 2]))
        
        sigma_zx = nearest_neighbor_interpolate(pos_caches['zx']['sigma_0'], (p[:, 2], p[:, 0]))
        u_zx = nearest_neighbor_interpolate(pos_caches['zx']['u_0'], (p[:, 2], p[:, 0]))
        v_zx = nearest_neighbor_interpolate(pos_caches['zx']['v_0'], (p[:, 2], p[:, 0]))
        w_zx = nearest_neighbor_interpolate(pos_caches['zx']['w_0'], (p[:, 2], p[:, 0]))
        w_sigma_zx = nearest_neighbor_interpolate(pos_caches['zx']['w_sigma'], (p[:, 2], p[:, 0]))
        w_u_zx = nearest_neighbor_interpolate(pos_caches['zx']['w_u'], (p[:, 2], p[:, 0]))
        w_v_zx = nearest_neighbor_interpolate(pos_caches['zx']['w_v'], (p[:, 2], p[:, 0]))
        w_w_zx = nearest_neighbor_interpolate(pos_caches['zx']['w_w'], (p[:, 2], p[:, 0]))
        
        sigma_xy = sigma_xy * w_sigma_xy
        u_xy = u_xy * w_u_xy
        v_xy = v_xy * w_v_xy
        w_xy = w_xy * w_w_xy
        
        sigma_yz = sigma_yz * w_sigma_yz
        u_yz = u_yz * w_u_yz
        v_yz = v_yz * w_v_yz
        w_yz = w_yz * w_w_yz
        
        sigma_zx = sigma_zx * w_sigma_zx
        u_zx = u_zx * w_u_zx
        v_zx = v_zx * w_v_zx
        w_zx = w_zx * w_w_zx
        
        sigma_total *= sigma_xy * sigma_yz * sigma_zx
        u_total += u_xy + u_yz + u_zx
        v_total += v_xy + v_yz + v_zx
        w_total += w_xy + w_yz + w_zx
        
    beta = bilinear_interpolate(dir_cache['beta'], (theta_norm, phi_norm))
    color = beta * np.stack([u_total, v_total, w_total], axis=-1)
    color = np.sum(color, axis=-1)
    return volume_render(t_vals, sigma_total, color)

def squeeze_nerf_infer_alt(ray_origins, ray_directions, n_samples=256, 
                           pos_caches=None, dir_cache=None, D=8, D_sigma=12, D_k=8):
    """
    Alternate SqueezeNeRF inference.
    """
    t_vals = np.linspace(0.0, 1.0, n_samples)
    points = ray_origins[:, None, :] + ray_directions[:, None, :] * t_vals[None, :, None]
    num_rays = points.shape[0]
    
    sigma_total = np.ones(num_rays)
    u_total = np.zeros((num_rays, D_k))
    v_total = np.zeros((num_rays, D_k))
    w_total = np.zeros((num_rays, D_k))
    
    for i in range(n_samples):
        p = points[:, i, :]
        theta = np.arccos(np.clip(p[:, 2] / (np.linalg.norm(p, axis=1) + 1e-8), -1.0, 1.0))
        phi = np.arctan2(p[:, 1], p[:, 0])
        theta_norm = (theta / np.pi) * 0.5
        phi_norm = (phi / (2 * np.pi)) + 0.5
        
        sigma_xy = nearest_neighbor_interpolate(pos_caches['xy']['sigma'], (p[:, 0], p[:, 1]))
        u_xy = nearest_neighbor_interpolate(pos_caches['xy']['u'], (p[:, 0], p[:, 1]))
        v_xy = nearest_neighbor_interpolate(pos_caches['xy']['v'], (p[:, 0], p[:, 1]))
        w_xy = nearest_neighbor_interpolate(pos_caches['xy']['w'], (p[:, 0], p[:, 1]))
        
        sigma_yz = nearest_neighbor_interpolate(pos_caches['yz']['sigma'], (p[:, 1], p[:, 2]))
        u_yz = nearest_neighbor_interpolate(pos_caches['yz']['u'], (p[:, 1], p[:, 2]))
        v_yz = nearest_neighbor_interpolate(pos_caches['yz']['v'], (p[:, 1], p[:, 2]))
        w_yz = nearest_neighbor_interpolate(pos_caches['yz']['w'], (p[:, 1], p[:, 2]))
        
        sigma_zx = nearest_neighbor_interpolate(pos_caches['zx']['sigma'], (p[:, 2], p[:, 0]))
        u_zx = nearest_neighbor_interpolate(pos_caches['zx']['u'], (p[:, 2], p[:, 0]))
        v_zx = nearest_neighbor_interpolate(pos_caches['zx']['v'], (p[:, 2], p[:, 0]))
        w_zx = nearest_neighbor_interpolate(pos_caches['zx']['w'], (p[:, 2], p[:, 0]))
        
        sigma_combined = pos_caches['xy']['W_sigma'] @ np.concatenate([sigma_xy, sigma_yz, sigma_zx], axis=-1) + pos_caches['xy']['b_sigma']
        u_combined = pos_caches['xy']['W_k'] @ np.concatenate([u_xy, u_yz, u_zx], axis=-1) + pos_caches['xy']['b_k']
        v_combined = pos_caches['xy']['W_k'] @ np.concatenate([v_xy, v_yz, v_zx], axis=-1) + pos_caches['xy']['b_k']
        w_combined = pos_caches['xy']['W_k'] @ np.concatenate([w_xy, w_yz, w_zx], axis=-1) + pos_caches['xy']['b_k']
        
        sigma_total *= sigma_combined
        u_total += u_combined
        v_total += v_combined
        w_total += w_combined
        
    beta = bilinear_interpolate(dir_cache['beta'], (theta_norm, phi_norm))
    color = beta * np.stack([u_total, v_total, w_total], axis=-1)
    color = np.sum(color, axis=-1)
    return volume_render(t_vals, sigma_total, color)

### Edge Cases and Pitfalls
-   **Coordinate Pairing:** Splitting coordinates into individual dimensions $(x), (y), (z)$ instead of pairs $(x,y), (y,z), (z,x)$ leads to considerably inferior results [S1].
-   **Interpolation:** Nearest neighbor interpolation is used for position caches, which may introduce artifacts if $n_p$ is too small [S1]. Bilinear interpolation is used for direction caches [S1].
-   **Precision:** Using 16-bit floats for radiance components and 32-bit for density scalars is critical for memory efficiency but may affect precision in extreme cases [S1].
-   **Cache Size vs Quality:** Smaller caches (512 vs 1K) reduce memory but may degrade image quality (PSNR/SSIM) [S1].

## Operating characteristics
-   **Memory Complexity:** $O(n_p^2)$ for position caches and $O(n_d^2)$ for direction cache, compared to $O(n^3)$ for FastNeRF [S1].
-   **Memory Usage:**
    -   SqueezeNeRF (1K cache, $n_p=1024$): ~155 MB [S1].
    -   SqueezeNeRF (512 cache, $n_p=512$): ~39 MB [S1].
    -   SqueezeNeRF (alt) (512 cache): ~58 MB [S1].
    -   Comparison: FastNeRF 1K cache ~54 GB, NeRF 1K cache ~35 TB [S1].
-   **Speed:**
    -   Over 150 FPS on high-end GPUs (e.g., V100, A100) [S1].
    -   Specifics: 168 FPS on V100, 202 FPS on A100 for 512 cache [S1].
    -   Cache generation time: < 9 seconds on V100 [S1].
-   **Quality:**
    -   Slightly inferior to NeRF and some baselines in PSNR/SSIM due to simple combination scheme [S1].
    -   Synthetic 360° (800x800): 29.61 PSNR (1K), 28.12 PSNR (512) [S1].
    -   LLFF (504x378): 21.62 PSNR (1K), 23.87 PSNR (512) [S1].
-   **Strengths:** Extremely low memory footprint, fast cache generation, real-time inference speed [S1].
-   **Limitations:** Lower image quality compared to full NeRF or FastNeRF with sparse caching; simple combination function limits expressiveness [S1].

## Background
SqueezeNeRF was proposed by Wadhwani et al. in 2022 [S1]. It is a further factorization of FastNeRF [S1]. FastNeRF itself was the first NeRF-based model to render at over 200 Hz on GPU [S2]. SqueezeNeRF addresses the substantial memory overhead of FastNeRF by reducing cache size complexity from $O(n^3)$ to $O(n^2)$ [S1]. It is designed for deployment on embedded systems and real-time applications where memory is constrained [S1].
