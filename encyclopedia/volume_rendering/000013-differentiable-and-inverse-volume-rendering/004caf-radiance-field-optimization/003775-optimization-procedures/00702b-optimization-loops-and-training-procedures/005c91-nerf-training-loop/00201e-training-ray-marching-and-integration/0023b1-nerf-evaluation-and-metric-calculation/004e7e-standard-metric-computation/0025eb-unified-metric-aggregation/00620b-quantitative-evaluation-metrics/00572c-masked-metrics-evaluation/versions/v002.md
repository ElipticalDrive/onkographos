# Masked Metrics Evaluation

Also called: Loss-masked Metric Reporting, Masked PSNR/SSIM/LPIPS, Object-crop image quality metrics

## Overview
Masked Metrics Evaluation is a protocol for computing quantitative image quality metrics (PSNR, SSIM, LPIPS, FLIP) restricted to specific regions of interest, typically defined by a ground-truth or loss mask, to isolate visible reconstruction quality from background artifacts [S1, S2, unofficial]. It differs from standard metric computation by decoupling object-level fidelity from scene-level completeness, allowing fair comparison between object-centric and scene-centric renders [S2, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** Rendered image $I_{pred}$, ground truth image $I_{gt}$, binary mask $M$ (where $M_{ij}=1$ for pixels inside the region of interest, $0$ otherwise).
- **Outputs:** Scalar metric values (e.g., PSNR, SSIM) computed over the masked region, often reported alongside full-image metrics.

**Data Structures:**
- **Mask $M$:** Binary tensor of same spatial dimensions as $I_{pred}$ and $I_{gt}$.
- **Metric Functions:** Standard implementations of PSNR, SSIM, LPIPS, or FLIP.

**Steps:**
1. **Full-Image Baseline (Optional):** Compute standard metrics over all pixels $P_{all}$ in $I_{pred}$ and $I_{gt}$ [S1, unofficial].
2. **Mask Application:** Identify valid pixels $P_{mask} = \{(i,j) | M_{ij} = 1\}$ [S1, S2, unofficial].
3. **Restricted Computation:** Compute the chosen metric $Metric(I_{pred}, I_{gt})$ using only pixels in $P_{mask}$ [S1, S2, unofficial].
4. **Reporting:** Report the masked metric value, often in parentheses next to the full-image value [S1, unofficial].

**Formulas:**
For PSNR, the masked mean squared error (MSE) is:
$$ MSE_{mask} = \frac{1}{|P_{mask}|} \sum_{(i,j) \in P_{mask}} (I_{pred}(i,j) - I_{gt}(i,j))^2 $$
$$ PSNR_{mask} = 10 \cdot \log_{10} \left( \frac{MAX_I^2}{MSE_{mask}} \right) $$
where $MAX_I$ is the maximum possible pixel value (e.g., 1.0 or 255) [S3].

**Parameters:**
- **Mask Source:** Can be a loss mask (from training supervision) or a ground-truth object mask [S1, S2, unofficial].
- **Evaluation Views:** For radiance field completion, metrics are averaged across evaluation views (typically 10 randomly chosen views) [S3].

**Edge Cases and Pitfalls:**
- **Empty Mask:** If $|P_{mask}| = 0$, the metric is undefined. Guard against division by zero [G].
- **Boundary Precision:** Mask boundaries may introduce aliasing if not aligned with pixel centers. Ensure mask and image resolutions match exactly [G].
- **Depth Projection:** In masked radiance field completion, the mask is projected into the image plane using depth estimated from the input radiance field $f_{in}$ [S3]. Errors in depth estimation affect the mask validity [S3].

**Pseudocode:**
```python
def compute_masked_psnr(rendered_image, gt_image, mask):
    """
    Compute PSNR restricted to pixels where mask is 1.
    rendered_image: numpy array (H, W, C)
    gt_image: numpy array (H, W, C)
    mask: numpy array (H, W) of 0s and 1s
    """
    # Identify valid pixels
    valid_pixels = mask == 1
    
    if not np.any(valid_pixels):
        return float('nan') # Guard against empty mask
    
    # Extract valid pixels
    pred_valid = rendered_image[valid_pixels]
    gt_valid = gt_image[valid_pixels]
    
    # Compute MSE
    mse = np.mean((pred_valid - gt_valid) ** 2)
    
    # Compute PSNR
    if mse == 0:
        return float('inf')
    
    max_val = 1.0 # Assuming normalized [0,1] images
    psnr = 10 * np.log10((max_val ** 2) / mse)
    
    return psnr

def evaluate_masked_metrics(rendered_images, gt_images, masks, num_views=10):
    """
    Average masked PSNR across evaluation views.
    rendered_images: list of images
    gt_images: list of images
    masks: list of masks
    """
    psnr_values = []
    for i in range(num_views):
        psnr = compute_masked_psnr(rendered_images[i], gt_images[i], masks[i])
        if not np.isnan(psnr):
            psnr_values.append(psnr)
            
    if not psnr_values:
        return float('nan')
        
    return np.mean(psnr_values)
```

## Subtopics

### Masked Peak Signal-to-Noise Ratio (mPSNR) Evaluation
A metric for evaluating masked radiance field completion that computes PSNR only on non-masked pixels projected from depth [S3]. Given a binary mask $m$ of the input radiance field $f_{in}$, the non-masked area is computed by depth-based projection into the image plane using depth estimated from $f_{in}$ [S3]. The mPSNR is then computed by averaging the PSNR on the non-masked pixels for all evaluation views (typically 10 randomly chosen views) [S3]. This variant is specifically designed for scenarios where the mask is derived from the input field's geometry rather than a ground-truth object label [S3].

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of pixels in the mask. Negligible overhead compared to rendering [S1, S2, unofficial].
- **Memory Complexity:** $O(N)$ to store the mask and intermediate valid pixel arrays [G].
- **Strengths:** Isolates object reconstruction quality from background errors; enables fair comparison between object-centric and scene-centric methods [S2, unofficial].
- **Limitations:** Requires a reliable mask; metrics can be misleading if the mask is inaccurate or misaligned [S3].
- **When to Use:** When evaluating object-level fidelity in the presence of background noise or when comparing methods with different scene coverage [S2, unofficial].
- **When Not to Use:** When scene-level completeness is the primary concern; use full-image metrics instead [S2, unofficial].

## Background
The protocol originates from NeRS [38] as "Object-crop image quality" metrics (PSNR, SSIM, LPIPS, FLIP) [S2, unofficial]. It has been adopted in works like Splatt3R [S1, unofficial] and CADSplat [S2, unofficial] to report metrics on loss-masked regions. The mPSNR variant was introduced in DiffRF for masked radiance field completion [S3].
