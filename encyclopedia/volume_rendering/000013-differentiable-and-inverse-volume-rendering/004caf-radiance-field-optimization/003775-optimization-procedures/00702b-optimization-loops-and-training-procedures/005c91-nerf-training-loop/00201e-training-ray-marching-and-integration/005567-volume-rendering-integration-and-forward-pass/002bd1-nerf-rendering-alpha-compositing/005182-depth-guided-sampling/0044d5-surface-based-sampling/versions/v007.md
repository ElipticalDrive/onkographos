# Surface-Based Sampling

Also called: Near-Surface Sampling

## Overview
Surface-Based Sampling is a strategy that restricts 3D sample point generation to a narrow band around the estimated surface of an object, rather than sampling throughout the entire volume or free space [S1]. It solves the problem of quality degradation caused by standard NeRF sampling in irrelevant regions (free space or occluded areas) by concentrating computational resources where the radiance field actually varies [S1].

## How it works
**Inputs:**
*   $d$: The depth value for a pixel/ray, representing the distance from the camera to the surface [S1].
*   $\alpha$: Half of the specified sampling range (bandwidth) [S1].
*   $N$: The number of sample points per ray [S1].
*   Ray origin and direction (implicit in the calculation of sample positions along the ray) [S1].

**Outputs:**
*   A set of $N$ sample locations $\{S_{r,1}, \dots, S_{r,N}\}$ along the ray, clustered around the surface [S1].

**Data Structures:**
*   The method generates a 1D array of $N$ scalar distances from the camera origin [S1]. No complex spatial data structures are required for the sampling step itself, though the source notes mention an offline point cloud generation step for novel view depth estimation [S1].

**Parameters:**
*   $\alpha$: Determines sampling density. Typical values: $1/2$, $1/16$ [S1].
*   $N$: Number of samples. Typical value: $8$ [S1].
*   $\gamma$: A random number for stratified sampling, uniformly distributed in $[0, 2\alpha/N)$ [S1].

**Steps:**
1.  Calculate the starting distance of the sampling range from the camera:
    $$S_{r,0} = d - \alpha$$
    where $S_{r,0}$ is the location of the point nearest to the camera within the sampling range [S1].
2.  Generate $N$ sample points using stratified sampling within the range $[S_{r,0}, S_{r,0} + 2\alpha]$:
    $$S_{r,n} = S_{r,0} + (n - 1) \frac{2\alpha}{N} + \gamma, \quad n = 1, \dots, N$$
    where $\gamma$ is a random number uniformly generated between $0$ and $\frac{2\alpha}{N}$ [S1].
3.  Use the resulting points $\{S_{r,1}, \dots, S_{r,N}\}$ to query the NeRF network for color and density [S1].

**Pseudocode:**
```python
def uniform(a, b):
    """Returns a random float uniformly distributed in [a, b)."""
    # Implementation depends on the language's standard PRNG; 
    # here it represents the standard uniform random generator.
    pass

def surface_based_sampling(depth_d, alpha, N):
    """
    Generates N sample points along a ray, centered around the surface depth.
    
    Args:
        depth_d (float): Depth value from the camera to the surface.
        alpha (float): Half of the specified sampling range.
        N (int): Number of sample points.
        
    Returns:
        list[float]: List of N sample distances from the camera origin.
    """
    # Step 1: Calculate the start of the sampling range
    start_dist = depth_d - alpha
    
    # Step 2: Calculate bin width for stratified sampling
    bin_width = (2.0 * alpha) / N
    
    samples = []
    for n in range(1, N + 1):
        # Generate random offset gamma within [0, bin_width)
        gamma = uniform(0, bin_width)
        
        # S_r,n = S_r,0 + (n - 1) * (2*alpha/N) + gamma
        sample_dist = start_dist + (n - 1) * bin_width + gamma
        samples.append(sample_dist)
        
    return samples
```

**Edge Cases and Pitfalls:**
*   **Depth Accuracy:** If the depth $d$ is poorly estimated, using a small $\alpha$ degrades rendering quality because the sampling band misses the actual surface [S1].
*   **Parameter Selection:** The value of $\alpha$ must be set considering the accuracy of the input depth images [S1]. A larger $\alpha$ provides a wider band, tolerating depth errors but reducing density near the surface [S1].

## Subtopics

### [Adaptive Primary Surface Sampling](16708-adaptive-primary-surface-sampling.md)
Accelerates neural rendering by sampling only on the primary surface using a point cloud distribution, avoiding redundant sampling of multiple surfaces or empty space.

## Operating characteristics
*   The method computes $N$ sample locations per ray using a constant number of arithmetic operations per sample [S1].
*   Restricting sampling to the near-surface area prevents quality degradation caused by sampling in free space or occluded regions, potentially improving rendering accuracy (PSNR) even without a fine sampling process [S1].
*   Strengths include improved rendering performance by focusing on the object surface and allowing denser sampling near the surface with fewer total samples when $\alpha$ is small [S1].
*   Limitations include heavy dependence on the accuracy of the depth images, where poor depth estimation leads to degraded quality especially with small $\alpha$ [S1]. The method requires depth images during training or a mechanism to generate them for novel views, such as point cloud refinement [S1].

## Background
The method was introduced in "Improving Neural Radiance Fields Using Near-Surface Sampling with Point Cloud Generation" [S1]. It addresses the inefficiency of standard NeRF, which samples uniformly or hierarchically across the entire volume, including empty space [S1]. By leveraging depth information (either from training data or estimated for novel views), the method confines the search space to the object's vicinity [S1].
