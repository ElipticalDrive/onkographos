# SeaThru-NeRF

Also called: SeaThru

## Overview
SeaThru-NeRF is a neural radiance field method designed for visualizing and reconstructing scenes within dispersed scattering media, such as fog, haze, and subaquatic environments [S1]. It extends the standard NeRF formulation by treating the scattering medium as a semi-transparent entity with distinct color and density parameters, separate from opaque objects [S2]. This allows the model to distinguish between unblemished and backscattered segments of the scene, enabling the restoration of scene hue and 3D configuration in far-off areas that are typically obscured [S1]. It builds on [HybridNeRF Model Architecture](4842-hybridnerf-model-architecture.md) by incorporating a scattering model into the NeRF rendering formulas [S1].

## How it works
SeaThru-NeRF modifies the standard volume rendering equation to account for the additive density and color contributions of a scattering medium [S2]. It assumes that the total density at any point along a ray is the sum of the object density and the medium density [S2].

**Inputs and Outputs:**
*   **Input:** Camera ray $r$, scene geometry and appearance data (learned via MLPs).
*   **Output:** Rendered color $C(r)$, potentially decomposed into object-only and medium-only components.

**Data Structures:**
The method utilizes the standard NeRF MLP architecture but outputs two sets of parameters for each sampled point $t$ along the ray: object density $\sigma_{obj}(t)$ and object color $c_{obj}(t)$, and medium density $\sigma_{med}(t)$ and medium color $c_{med}(t)$ [S2].

**Rendering Formulas:**
The rendered color $C(r)$ is computed by integrating the accumulated color along the ray segment from $t_n$ to $t_f$ [S2]:

$$
C(r) = \int_{t_n}^{t_f} T(t) \left[ \sigma_{obj}(t)c_{obj}(t) + \sigma_{med}(t)c_{med}(t) \right] dt \quad (8)
$$

where $T(t)$ is the transmittance, representing the probability that light travels from the camera to point $t$ without being absorbed or scattered [S2]:

$$
T(t) = \exp \left( - \int_{t_n}^{t} \left[ \sigma_{obj}(s) + \sigma_{med}(s) \right] ds \right) \quad (9)
$$

Here, $c_{obj}(t)$ and $c_{med}(t)$ are the colors of the object and medium at $t$, respectively [S2].

**Training:**
The model parameters are optimized by minimizing the squared distance between the expected color $\hat{C}(r)$ and the ground truth color $C_{gt}(r)$ [S2].

**Pseudocode:**
The following pseudocode illustrates the rendering step for a single ray. The discrete volume rendering accumulation is a standard implementation [G].

```python
import math

def render_seathru_ray(ray_origin, ray_direction, t_near, t_far, num_samples, 
                       query_object, query_medium):
    """
    Renders a single ray using the SeaThru-NeRF scattering model.
    
    Args:
        ray_origin: list of 3 floats, camera origin.
        ray_direction: list of 3 floats, normalized ray direction.
        t_near: float, near plane distance.
        t_far: float, far plane distance.
        num_samples: int, number of sample points along the ray.
        query_object: function, returns (sigma_obj, c_obj) for a 3D point.
        query_medium: function, returns (sigma_med, c_med) for a 3D point.
        
    Returns:
        color: float, rendered color value.
    """
    # Discretize the ray into uniformly spaced sample points
    t_vals = [t_near + i * (t_far - t_near) / (num_samples - 1) for i in range(num_samples)]
    delta_t = (t_far - t_near) / (num_samples - 1)
    
    accumulated_transmittance = 1.0
    accumulated_color = 0.0
    
    for i in range(num_samples):
        t = t_vals[i]
        point = [ray_origin[j] + t * ray_direction[j] for j in range(3)]
        
        # Query object and medium properties
        sigma_obj, c_obj = query_object(point)
        sigma_med, c_med = query_medium(point)
        
        # Total density at this point
        sigma_total = sigma_obj + sigma_med
        
        # Skip if density is negligible to avoid division by zero
        if sigma_total < 1e-6:
            accumulated_transmittance *= math.exp(-sigma_total * delta_t)
            continue
            
        # Calculate opacity for this segment: alpha = 1 - exp(-sigma * delta_t)
        alpha = 1.0 - math.exp(-sigma_total * delta_t)
        
        # Weight = accumulated_transmittance * alpha
        weight = accumulated_transmittance * alpha
        
        # Compute weighted color contribution: c_total = (sigma_obj*c_obj + sigma_med*c_med) / sigma_total
        c_total = (sigma_obj * c_obj + sigma_med * c_med) / (sigma_total + 1e-6)
        
        accumulated_color += weight * c_total
        
        # Update transmittance for next step: T_{i+1} = T_i * (1 - alpha)
        accumulated_transmittance *= (1.0 - alpha)
        
    return accumulated_color
```

**Edge Cases and Pitfalls:**
*   **Degenerate Input:** If the medium density is zero everywhere, the model reduces to standard NeRF [G]. If object density is zero, it renders only the medium [G].
*   **Precision:** The exponential function in transmittance calculation can lead to underflow for very dense media. Clamping or using log-space arithmetic may be necessary [G].
*   **Boundary Conditions:** The integration limits $t_n$ and $t_f$ must be carefully chosen to include all relevant scattering and object contributions [G].

## Operating characteristics
*   **Time Complexity:** Depends on the number of samples per ray and the depth of the MLPs [G].
*   **Memory Complexity:** Requires storing two sets of density and color parameters per point, effectively doubling the output size of the MLPs compared to standard NeRF [G].
*   **Strengths:** Capable of restoring scene hue and 3D configuration in far-off areas obscured by scattering media [S1]. Can produce lifelike new-view composites while maintaining or eliminating the medium effect [S1].
*   **Limitations:** Performance in highly complex reflective and refractive scenes may require more subspaces, similar to MS-NeRF [S1]. Not given in the sources for specific hardware performance metrics.
*   **When to use:** Underwater, fog, or haze visualization and reconstruction [S1].
*   **When not to use:** Clear air scenes where standard NeRF is sufficient and more efficient [G].

## Background
SeaThru-NeRF was introduced in 2023 [S1]. It is inspired by the SeaThru method [S2]. It extends the capability of NeRFs to handle scattering media such as underwater environments [S2]. The method showcases proficiency in depicting scenes in both simulated and actual settings, resulting in cutting-edge, realistic new-view composites [S1].
