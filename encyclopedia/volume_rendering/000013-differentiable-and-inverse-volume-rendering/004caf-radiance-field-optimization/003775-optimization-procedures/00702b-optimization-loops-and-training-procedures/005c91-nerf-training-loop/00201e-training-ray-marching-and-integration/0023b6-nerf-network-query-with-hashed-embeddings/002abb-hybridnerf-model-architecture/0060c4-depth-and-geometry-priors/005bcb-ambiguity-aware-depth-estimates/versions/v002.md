# Ambiguity-Aware Depth Estimates

Also called: Multimodal Depth Prior, cIMLE-based Depth Estimation

## Overview
Ambiguity-Aware Depth Estimates is a technique for learning a multimodal distribution of depth estimates conditioned on a single input image, using an implicit generative model to capture inherent ambiguities in monocular depth estimation such as non-opaque surfaces and albedo-shading confusion [S1]. Unlike GANs which optimize for similarity to a single ground truth, this method uses conditional Implicit Maximum Likelihood Estimation (cIMLE) to prevent mode collapse by enforcing that all ground truth points are explained by at least one generated sample [S1].

## How it works
**Inputs:** A set of input images $\{I_1, I_2, ..., I_n\}$, each with a corresponding ground truth depth map $D_i$ [S1].
**Outputs:** Network parameters $\phi$ for the conditional distribution $G_\phi(I, z)$ and per-image scale/shift variables [S1].

**Data Structures:**
*   $G_\phi$: Implicit generative network parameterized by $\phi$. Takes image $I$ and latent code $z$ as input [S1].
*   $z$: Latent code sampled from standard normal distribution $\mathcal{N}(0, I)$ [S1].
*   $M$: Number of samples drawn per image [S1].
*   $\delta_i$: Threshold radius for the neighborhood around ground truth depth $D_i$ [S1].
*   $w_i$: Weighting factor for training example $i$ [S1].

**Parameters:**
*   $\phi$: Network parameters for $G_\phi$ [S1].
*   $z \sim \mathcal{N}(0, I)$: Latent codes [S1].
*   $M = 20$: Typical number of samples [S1].
*   $\delta_i$: Dependent on training example $i$ [S1].
*   $w_i = 0$: In the specific implementation cited, weights are zero [S1].
*   Learning Rate: $1e-6$ for $\phi$ and scale/shift variables [S1].

**Steps:**
1.  **Initialization:** Initialize $\phi$ and a 2-dimensional scale/shift variable for each input image. The depth estimates are in relative scale, so these variables directly optimize the scale and shift for each input image [S1].
2.  **Sampling:** For each training image $I_i$, sample $M$ latent codes $z_j \sim \mathcal{N}(0, I)$. Compute $M$ depth estimates $y_{i,j} = G_\phi(I_i, z_j)$ [S1].
3.  **Distance Calculation:** Compute the distance $d(y_{i,j}, D_i)$ between each sampled depth estimate $y_{i,j}$ and the ground truth depth map $D_i$ [S1].
4.  **Loss Computation:** The objective is derived from maximizing the likelihood induced by the model. The kernel function $\Phi'_{\delta}(t)$ is defined as:
    $$
    \Phi'_{\delta}(t) = \begin{cases} 
    1/\delta & \text{for } 0 \le t \le \delta \\
    0 & \text{for } t > \delta 
    \end{cases}
    $$
    The likelihood objective $L_{\{\delta_i\}_i}(\phi)$ is equivalent to minimizing the following sample-based loss function [S1]:
    $$
    \mathcal{L} = \sum_{i=1}^n w_i \min_{j \in [M]} d(y_{i,j}, D_i)
    $$
    In the cited implementation, $w_i = 0$ for all $i$, which implies the explicit weighted loss value vanishes, but the minimization over $j$ remains the core mechanism to ensure at least one sample is close to the ground truth [S1].
5.  **Optimization:** The scale and shift variables are jointly optimized with the NeRF for the first 400,000 iterations with a learning rate of $1e-6$. Then, they are kept frozen for the last 100,000 iterations [S1].

**Pseudocode:**
```python
def train_ambiguity_aware_depth(
    images: List[Image], 
    gt_depths: List[DepthMap], 
    phi: Network, 
    scale_shift_vars: List[Vector2],
    M: int = 20,
    num_iters: int = 500000,
    lr: float = 1e-6
):
    """
    Trains the ambiguity-aware depth prior using cIMLE.
    """
    # Initialize optimizer for phi and scale_shift_vars
    optimizer = Optimizer(params=phi.parameters() + scale_shift_vars, lr=lr)
    
    for iteration in range(num_iters):
        total_loss = 0.0
        
        for i, (I_i, D_i) in enumerate(zip(images, gt_depths)):
            # Apply per-image scale and shift to ground truth depth
            s, sh = scale_shift_vars[i]
            D_i_aligned = [[s * p + sh for p in row] for row in D_i]
            
            # Sample M latent codes from standard normal distribution
            z_samples = [sample_normal() for _ in range(M)]
            
            # Generate M depth estimates
            y_samples = [phi(I_i, z) for z in z_samples]
            
            # Compute distances and find minimum
            distances = [compute_distance(y, D_i_aligned) for y in y_samples]
            min_dist = min(distances)
            
            # Accumulate loss (w_i = 0 per source, loss reduces to sum of min distances)
            total_loss += min_dist
        
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()

def sample_normal():
    # Box-Muller transform for standard normal sampling
    u1, u2 = random(), random()
    return math.sqrt(-2.0 * math.log(u1)) * math.cos(2.0 * math.pi * u2)

def compute_distance(pred: List[List[float]], gt: List[List[float]]) -> float:
    # Mean absolute error over pixels
    total = 0.0
    count = 0
    for p_row, g_row in zip(pred, gt):
        for p, g in zip(p_row, g_row):
            total += abs(p - g)
            count += 1
    return total / max(count, 1)
```

**Edge Cases and Pitfalls:**
*   If $\delta_i$ is too small such that all sampled distances $d(y_{i,j}, D_i) > \delta_i$, the loss becomes constant ($\delta_i - \delta_i = 0$), resulting in no gradients for $\phi$ [S1].
*   The minimum viable $\delta_i$ is $\min_{j} d(y_{i,j}, D_i)$ [S1].

## Operating characteristics
*   **Time Complexity:** Depends on the number of samples $M$ and the cost of the generator $G_\phi$. For each image, $M$ forward passes are required [S1].
*   **Memory Complexity:** Stores the generator parameters $\phi$ and the latent codes during the forward pass [S1].
*   **Strengths:** Captures multimodal depth distributions, handling ambiguities like non-opaque surfaces (e.g., glass) and albedo-shading confusion [S1]. Prevents mode collapse compared to GANs [S1].
*   **Limitations:** Requires ground truth depth maps for training [S1].
*   **When to use:** When monocular depth estimation is inherently ambiguous and a single deterministic estimate is insufficient [S1].

## Background
Ambiguity-Aware Depth Estimates was introduced in the SCADE paper (CVPR 2023) [S1]. It builds on the concept of Implicit Maximum Likelihood Estimation (IMLE) [S1]. The method is used in the HybridNeRF model architecture to provide a multimodal depth prior [S1].
