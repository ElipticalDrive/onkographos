# Space-time Neural Irradiance Fields

Also called: ST-NIF, Space-time Neural Irradiance Fields for Free-Viewpoint Video

## Overview
Space-time Neural Irradiance Fields (ST-NIF) represents a dynamic scene as a 4D implicit function mapping spatiotemporal coordinates $(x,t)$ to color and volume density [S2]. It solves free-viewpoint video synthesis from a single moving camera by regularizing the inherently under-constrained geometry of dynamic scenes [S2]. Unlike static NeRF variants, ST-NIF introduces empty-space and static-scene losses to prevent haze-like artifacts and disocclusion errors, respectively [S2].

## How it works

### Inputs and Outputs
**Inputs:**
*   A stream of $N_f$ RGB-D images $I_t: u \rightarrow (c, d)$ at discrete time steps $t \in \mathcal{T} = \{1, \dots, N_f\}$, where $u=(u,v)$ are 2D pixel coordinates [S2].
*   Camera calibrations $P_t$ for each frame [S2].
*   Near and far clipping planes $s_n$ and $s_f$ [S2].

**Outputs:**
*   A neural network $F$ that approximates the irradiance field: $F: (x,t) \rightarrow (c, \sigma)$, where $c$ is color and $\sigma$ is volume density [S2].
*   Rendered RGB images for novel viewpoints and time steps [S2].

### Data Structures
*   **Neural Network:** An MLP with the same architecture as the original NeRF, except the first 8 layers use 1024 activations instead of 256 [S2].
*   **Positional Encoding:** Applied to spatial coordinates with 4 frequency bands [S2].
*   **Time Normalization:** Time $t$ is normalized to the range $[-1, 1]$ [S2].
*   **Sample Pool:** A set of 3D points $\mathcal{X}$ derived from the union of sampling locations along all rays of all frames, excluding points closer than $\epsilon$ to observed surfaces [S2].

### Parameters
*   **Batch Size:** $N_r = 1024$ rays randomly drawn from an input frame $I_t$ without replacement [S2].
*   **Empty-space margin:** $\epsilon = 0.05 \cdot (s_f - s_n)$ [S2].
*   **Loss Weights:** $\alpha, \beta, \gamma$ for depth, empty-space, and static losses respectively [S2].
*   **Training Iterations:** 800,000 [S2].

### Ray Parameterization
A ray $r$ at time $t$ is determined by a pixel location $u$ and camera calibration $P_t$ [S2]. The ray is parameterized such that the parameter $s$ denotes scene depth, achieved by setting the directional vector $d$ so its projection onto the principal ray has unit norm in camera space [S2].

### Training Steps

1.  **Hierarchical Sampling:** Use hierarchical volume sampling as in the original NeRF to generate coarse and fine samples along each ray [S2].
2.  **Static Scene Sample Pool Construction:**
    *   Take the union of all sampling locations along all rays of all frames to form a sample pool $\mathcal{X}$ [S2].
    *   Exclude all points closer to any observed surfaces than threshold $\epsilon$ [S2].
3.  **Static Loss Sampling:**
    *   Randomly draw a fixed number of sampling locations from $\mathcal{X}$ at each training iteration [S2].
    *   Add small random jitters to each sampling location [S2].
    *   Randomly choose a time $t'$ for each sample location $x$, ensuring $(x, t')$ is not close to any scene surfaces [S2].
4.  **Forward Pass:** Query the network $F$ for color and density at sampled points [S2].
5.  **Volume Rendering:** Compute rendered color $\hat{C}(r,t)$ using numerical quadrature (Eq. 1) [S2].
6.  **Loss Computation:** Calculate $L_{color}$, $L_{depth}$, $L_{empty}$, and $L_{static}$ [S2].
7.  **Optimization:** Minimize total loss $L$ [S2].

### Formulas

**Volume Rendering:**
$$ \hat{C}(r,t) = \int_{s_n}^{s_f} T(s,t) \sigma(r(s),t) c(r(s),d) \, ds $$
$$ T(s,t) = \exp \left( -\int_{s_n}^{s} \sigma(r(p),t) \, dp \right) $$
[S2]

**Color Reconstruction Loss:**
$$ L_{color} = \sum_{(r,t) \in \mathcal{R}} \| \hat{C}(r,t) - C(r,t) \|^2 $$
where $\mathcal{R}$ is a batch of rays associated with time $t$, and $C(r,t)$ is the ground truth color [S2].

**Depth Reconstruction Loss:**
$$ L_{depth} = \sum_{(r,t) \in \mathcal{R}} \left\| \frac{1}{\hat{D}(r,t)} - \frac{1}{D(r,t)} \right\|^2 $$
where $D(r,t)$ is the input depth, and $\hat{D}(r,t)$ is the integrated sample depth:
$$ \hat{D}(r,t) = \int_{s_n}^{s_f} T(s,t) \sigma(r(s),t) s \, ds $$
[S2]

**Empty-Space Loss:**
$$ L_{empty} = \sum_{(r,t) \in \mathcal{R}} \int_{s_n}^{d_t(u) - \epsilon} \sigma(r(s),t) \, ds $$
where $d_t(u)$ is the scene depth for pixel $u$ at time $t$, and $\epsilon = 0.05 \cdot (s_f - s_n)$ [S2].

**Static Scene Loss:**
Measured on the jittered samples from pool $\mathcal{X}$ at random times $t'$ [S2]. The specific formula is not provided in the sources, but it constrains spaces surrounding surface regions to handle disocclusions [S2].

**Total Loss:**
$$ L = L_{color} + \alpha L_{depth} + \beta L_{empty} + \gamma L_{static} $$
[S2]

### Pseudocode

```python
def train_st_nif(frames, cameras, s_n, s_f, alpha=1.0, beta=1.0, gamma=1.0, num_iterations=800000):
    # Initialize MLP F(x, t) -> (c, sigma) with NeRF architecture (1024 units, first 8 layers)
    # Positional encoder with 4 frequency bands applied to x
    # Time t normalized to [-1, 1]
    
    epsilon = 0.05 * (s_f - s_n)
    sample_pool = []
    
    # Precompute static sample pool X
    for t_idx, (color_img, depth_img) in enumerate(frames):
        rays = [ray_from_pixel(u, v, cameras[t_idx]) for u, v in pixel_grid(color_img)]
        for r in rays:
            coarse_pts = uniform_sample(r, s_n, s_f, 64)
            fine_pts = importance_sample(r, coarse_pts, F, 128)
            for x in coarse_pts + fine_pts:
                if distance_to_surface(x, depth_img, cameras[t_idx]) > epsilon:
                    sample_pool.append(x)
    
    for iteration in range(num_iterations):
        l_color = 0.0; l_depth = 0.0; l_empty = 0.0; l_static = 0.0
        
        # 1. Sample Rays for Color/Depth/Empty Losses
        batch_rays = random_sample_rays(frames, cameras, N_r=1024)
        for r, t in batch_rays:
            coarse_pts, fine_pts = hierarchical_volume_sampling(r, s_n, s_f, F)
            c_fine, sigma_fine = query_network(fine_pts, t)
            c_rendered = volume_render(c_fine, sigma_fine, r)
            c_gt = frames[t].color[r.pixel]; d_gt = frames[t].depth[r.pixel]
            
            l_color += squared_l2_norm(c_rendered - c_gt)
            d_pred = compute_expected_depth(sigma_fine, fine_pts, r)
            l_depth += squared_l2_norm(1.0 / d_pred - 1.0 / d_gt)
            l_empty += integrate_density_up_to(sigma_fine, fine_pts, r, d_gt - epsilon)
            
        # 2. Sample for Static Loss
        static_samples = random_sample_from_pool(sample_pool, count=1024)
        for x in static_samples:
            t_prime = random_time_not_near_surface(x, frames, cameras, epsilon)
            sigma_static, _ = query_network(x, t_prime)
            l_static += compute_static_loss(sigma_static, x, t_prime)
            
        loss = l_color + alpha * l_depth + beta * l_empty + gamma * l_static
        optimize(loss)

# Standard helper implementations
def ray_from_pixel(u, v, cam): return Ray(cam.origin, normalize(cam.K @ [u, v, 1] - cam.origin))
def pixel_grid(img): return [(u, v) for u in range(img.width) for v in range(img.height)]
def uniform_sample(r, s_n, s_f, N): return r.o + r.d * linspace(s_n, s_f, N)
def importance_sample(r, coarse, F, N): return hierarchical_sample_coarse_to_fine(r, coarse, F, N)
def distance_to_surface(x, depth_img, cam): return backproject_depth(x, depth_img, cam)
def random_sample_rays(frames, cameras, N_r): return random.sample([(r, t) for t, f in enumerate(frames) for r in rays_from_frame(f, cameras[t])], N_r)
def hierarchical_volume_sampling(r, s_n, s_f, F): return uniform_sample(r, s_n, s_f, 64), importance_sample(r, uniform_sample(r, s_n, s_f, 64), F, 128)
def query_network(pts, t): return F(positional_encode(pts), normalize_time(t))
def volume_render(c, sigma, r): return sum(c_i * T_i * alpha_i for i in range(len(c))) where T_i = exp(-sum(sigma[:i]))
def squared_l2_norm(v): return sum(v_i**2 for v_i in v)
def compute_expected_depth(sigma, pts, r): return sum(sigma_i * s_i for sigma_i, s_i in zip(sigma, pts)) / sum(sigma)
def integrate_density_up_to(sigma, pts, r, limit): return sum(sigma_i for sigma_i, s_i in zip(sigma, pts) if s_i < limit)
def random_time_not_near_surface(x, frames, cameras, epsilon): 
    t = random.choice(range(len(frames)))
    while distance_to_surface(x, frames[t].depth, cameras[t]) <= epsilon: t = random.choice(range(len(frames)))
    return t
def compute_static_loss(sigma, x, t): return sigma # Constrains unconstrained regions; formula not given
def optimize(loss): return sgd_step(loss)
```

### Edge Cases and Pitfalls
*   **Motion-Appearance Ambiguity:** In dynamic scenes, a single video provides only one observation per time step, making geometry estimation severely under-constrained. Incorrect geometry leads to artifacts when deviating from the original camera trajectory [S2].
*   **Haze-like Artifacts:** Predicted depth is a weighted sum of depth values along the ray, leading to haze-like visual artifacts at novel views. Addressed by the empty-space loss [S2].
*   **Disocclusion Artifacts:** Unconstrained spaces hidden from input viewpoints are prone to artifacts when disoccluded due to viewpoint changes. Addressed by the static scene loss [S2].

## Operating characteristics

*   **Time Complexity:** Training takes approximately 48 hours for a network with about 100 video frames [S2].
*   **Memory Complexity:** Not given in the sources. [S2]
*   **Strengths:** Handles dynamic scenes from a single moving camera; produces geometrically correct novel view synthesis when combined with depth and empty-space constraints [S2].
*   **Limitations:** Relies on input depth maps; prone to artifacts in disoccluded regions if static loss is insufficient; computationally expensive training [S2].
*   **When to use:** Free-viewpoint video synthesis from a single moving camera with RGB-D input. [S2]
*   **When not to use:** Static scenes (use standard NeRF); scenes with no depth information; real-time rendering (requires offline training) [S2].
