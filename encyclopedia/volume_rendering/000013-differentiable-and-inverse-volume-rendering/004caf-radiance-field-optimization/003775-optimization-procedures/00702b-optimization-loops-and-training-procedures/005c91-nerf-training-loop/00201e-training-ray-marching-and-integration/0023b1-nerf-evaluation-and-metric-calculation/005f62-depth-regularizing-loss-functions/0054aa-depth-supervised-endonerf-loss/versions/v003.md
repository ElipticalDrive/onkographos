# Depth-Supervised EndoNeRF Loss

Also called: Depth-Supervised Loss, EndoNeRF Loss

## Overview
A training objective that combines photometric color loss with a depth-supervised loss using estimated stereo depth to accelerate convergence and remove the need for a depth refinement module [S1]. It sets itself apart from standard NeRF losses by explicitly constraining the rendered depth to match external stereo-matching estimates, thereby reducing training time compared to methods like STTR that require iterative depth refinement [S1].

## How it works
**Inputs and Outputs**
*   **Inputs**:
    *   $\mathcal{R}$: The set of camera rays $\textbf{r}(z)$ [S1].
    *   $t \in [0,1]$: The time parameter for dynamic scenes [S1].
    *   $\hat{\textbf{C}}(\textbf{r}(z), t)$: The rendered color for ray $\textbf{r}(z)$ at time $t$ [S1].
    *   $\textbf{C}(\textbf{r}(z), t)$: The ground truth pixel color for ray $\textbf{r}(z)$ at time $t$ [S1].
    *   $\hat{\textbf{D}}(\textbf{r}(z), t)$: The rendered depth for ray $\textbf{r}(z)$ at time $t$ [S1].
    *   $\textbf{D}(\textbf{r}(z), t)$: The estimated stereo depth for ray $\textbf{r}(z)$ at time $t$, obtained via stereo-matching feature correspondence of robotic surgery videos using Unimatch [S1].
    *   $\lambda_d$: The weight coefficient for the depth loss term [S1].
*   **Output**:
    *   $\mathcal{L}$: The total loss value [S1].

**Data Structures**
*   **Rays**: Represented as $\textbf{r}(z)$, where $z_j$ is the distance of the $j$-th sample along the ray [S1].
*   **Depth Maps**: $\textbf{D}$ is treated as a dense per-ray value or 2D map derived from Unimatch [S1].

**Steps**
1.  **Estimate Stereo Depth**: Compute the estimated stereo depth $\textbf{D}(\textbf{r}(z),t)$ by performing stereo-matching on feature correspondence of the robotic surgery videos using the Unimatch algorithm [S1].
2.  **Render Color and Depth**: For each ray $\textbf{r}(z) \in \mathcal{R}$ and time $t \in [0,1]$, compute the rendered color $\hat{\textbf{C}}(\textbf{r}(z), t)$ and rendered depth $\hat{\textbf{D}}(\textbf{r}(z), t)$ from the current radiance field representation [S1].
3.  **Compute Photometric Loss**: Calculate the squared L2 norm between the rendered color and the ground truth color: $\left\| \hat{\textbf{C}}(\textbf{r}(z), t) - \textbf{C}(\textbf{r}(z), t) \right\| _2^2$ [S1].
4.  **Compute Depth Loss**: Calculate the Huber loss between the rendered depth and the estimated stereo depth: ${\text {Huber}}\left( \hat{\textbf{D}}(\textbf{r}(z), t), \textbf{D}(\textbf{r}(z), t) \right)$ [S1].
5.  **Aggregate Loss**: Sum the photometric and weighted depth losses over all rays and time steps to obtain $\mathcal{L}$ [S1].

**Formulas**
The total loss function is defined as [S1]:

$$
\mathcal {L}= \sum _{\textbf{r}(z) \in \mathcal {R}, t\in [0,1]} \left\| \hat{\textbf{C}}(\textbf{r}(z), t) - \textbf{C}(\textbf{r}(z), t) \right\| _2^2 + \lambda _d {\text {Huber}}\left( \hat{\textbf{D}}(\textbf{r}(z), t), \textbf{D}(\textbf{r}(z), t) \right)
$$

Where:
*   $\textbf{r}(z)$ is the camera ray [S1].
*   $z_j$ is the distance of the $j$-th sample along the ray [S1].
*   $t \in [0,1]$ is the time [S1].
*   $\hat{\textbf{C}}$ is the rendered color [S1].
*   $\textbf{C}$ is the ground truth pixel color [S1].
*   $\hat{\textbf{D}}$ is the rendered depth [S1].
*   $\textbf{D}$ is the estimated stereo depth from Unimatch [S1].
*   $\lambda_d$ is the weight for the depth loss [S1].

**Parameters**
*   $\lambda_d$: The weight coefficient for the Huber depth loss term. Not given in the sources. [S1]

**Pitfalls**
*   **Outliers**: Huber loss is adopted for the depth term because it is more stable to outliers than L2 loss [S1].
*   **Stereo Quality**: Convergence to the estimated stereo depth requires well-matched stereo correspondence [S1].

**Pseudocode**
```python
def huber_loss(diff, delta=1.0):
    """Standard Huber loss implementation [G]."""
    abs_diff = abs(diff)
    quadratic = min(abs_diff, delta)
    linear = abs_diff - quadratic
    return 0.5 * quadratic ** 2 + delta * linear

def depth_supervised_endonerf_loss(rendered_colors, ground_truth_colors, rendered_depths, stereo_depths, lambda_d, delta=1.0):
    """
    Computes the Depth-Supervised EndoNeRF Loss.
    Inputs are flattened lists of values over all rays and time steps.
    """
    # 1. Photometric Color Loss (L2 norm squared)
    color_loss = sum((c_r - c_g) ** 2 for c_r, c_g in zip(rendered_colors, ground_truth_colors))
    
    # 2. Depth Loss (Huber)
    depth_loss = sum(huber_loss(d_r - d_s, delta) for d_r, d_s in zip(rendered_depths, stereo_depths))
    
    # 3. Total Loss
    total_loss = color_loss + lambda_d * depth_loss
    return total_loss
```

## Background
The method originates from the Efficient EndoNeRF reconstruction and its application for data-driven surgical simulation paper [S1]. It was developed to address the computational overhead of depth refinement in previous EndoNeRF variants [S1]. The approach leverages Unimatch for stereo depth estimation [S1].
