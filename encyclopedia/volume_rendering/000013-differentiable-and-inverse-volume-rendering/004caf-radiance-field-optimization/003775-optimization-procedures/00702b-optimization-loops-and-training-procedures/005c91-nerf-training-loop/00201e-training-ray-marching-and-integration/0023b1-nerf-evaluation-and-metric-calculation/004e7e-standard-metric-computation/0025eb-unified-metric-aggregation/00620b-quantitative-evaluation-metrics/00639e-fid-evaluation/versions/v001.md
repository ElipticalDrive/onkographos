# FID Evaluation

Also called: Frechet Inception Distance

## Overview
FID evaluates the perceptual quality of rendered images by comparing the distribution of deep features from a pretrained network against ground truth images [S1, S2]. It is distinct from pixel-wise metrics like PSNR by measuring statistical distance in feature space, making it sensitive to global coherence and texture realism [S2].

## How it works
**Inputs and Outputs:**
- Input: A set of $N$ generated images $G = \{g_1, ..., g_N\}$ and a set of $M$ ground truth images $R = \{r_1, ..., r_M\}$.
- Output: A scalar FID score. Lower scores indicate better quality.

**Data Structures:**
- Images are assumed to be 3-channel RGB tensors.
- Features are extracted using a pretrained Inception-v3 network (specifically the pool3 layer) [S2].

**Steps:**
1. **Preprocessing:** Resize all images to $128 \times 128$ resolution [S1]. If resizing is required, use antialiased resampling (area interpolation) to prevent artifacts that distort feature distributions [S1].
2. **Feature Extraction:** Pass each image through the pretrained Inception-v3 network to obtain feature vectors. Let $\phi(g_i)$ and $\phi(r_j)$ be the feature vectors for generated and real images, respectively.
3. **Statistics Calculation:** Compute the mean vectors $\mu_g, \mu_r$ and covariance matrices $\Sigma_g, \Sigma_r$ for the feature sets of $G$ and $R$ [S2].
4. **Distance Calculation:** Compute the Frechet distance between the two multivariate Gaussian distributions defined by these statistics [S2].

**Formula:**
$$ \text{FID} = \|\mu_g - \mu_r\|^2 + \text{Tr}(\Sigma_g + \Sigma_r - 2(\Sigma_g \Sigma_r)^{1/2}) $$
Where $\|\cdot\|$ is the Euclidean norm and $\text{Tr}(\cdot)$ is the trace of the matrix [S2].

**Parameters:**
- Resolution: $128 \times 128$ [S1].
- Background: For evaluations involving isolated subjects (e.g., faces), render against an empty background with value 0 (gray) [S1].
- Resampling: Antialiased (area interpolation) [S1].

**Edge Cases and Pitfalls:**
- **Resolution Sensitivity:** FID is highly sensitive to image resolution and resizing methods. Using nearest-neighbor or bilinear interpolation without antialiasing can artificially inflate or deflate scores [S1].
- **Background Consistency:** When comparing methods, ensure background handling is identical. For methods generating isolated objects, an empty (value=0) background is required for fair comparison [S1].
- **Implementation Consistency:** When evaluating baseline methods, modify their public implementations to match these specific preprocessing and background settings rather than using default evaluation pipelines [S1].

## Subtopics

### [Masked Metrics Evaluation](15886-masked-metrics-evaluation.md)
Computes metrics only on masked regions (e.g., face area), ignoring background. Choose when background artifacts should not penalize the score.

## Operating characteristics
- **Time Complexity:** Dominated by the forward pass of the Inception-v3 network for all $N+M$ images.
- **Memory Complexity:** Requires storing feature vectors for all images in memory.
- **Strengths:** Correlates well with human perception of image quality and diversity [S2].
- **Limitations:** Does not measure temporal coherence (use FVD for video) [S2]. Sensitive to preprocessing steps like resizing [S1].

## Background
FID was introduced as a metric for evaluating Generative Adversarial Networks (GANs) [S2]. It has been adopted in radiance field and novel view synthesis literature to assess the perceptual quality of generated views, particularly for dynamic faces and 3D objects [S1, S2].
