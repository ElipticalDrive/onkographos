# NAN (Noise-Aware NeRFs for Burst-Denoising)
Also called: Noise-Aware NeRFs

## Overview
NAN is a NeRF-based burst denoising method that leverages inter-view and spatial information to handle high levels of noise and large camera motion by operating in 3D space rather than the image plane [S1]. It solves the problem of generating a clean version of a target image from a burst of $N$ noisy images, treating the burst as an un-ordered set with potentially large parallax between frames [S1]. Unlike sibling methods that operate in the 2D image plane (e.g., [SeaThru-NeRF](11884-seathru-nerf.md) or [FastSR-NeRF](16574-fastsr-nerf.md) which may rely on optical flow or local kernels), NAN explicitly reasons about the scene's underlying 3D structure, allowing it to cope with significant motion and occlusions under very high noise levels [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N$ noisy images $\{I_n\}_{n=1}^N$ of a scene. The method requires as few as 8 images for inference [S1].
*   **Output:** A single clean target image corresponding to one of the viewpoints in the burst [S1].

**Data Structures:**
The method builds upon the IBRNet architecture [S1]. For each pixel in the target image, a ray $r$ is projected into 3D space. The ray is sampled at $M$ positions indexed by $m = 1, \dots, M$ [S1].
*   **Sample Point Representation:** For each 3D point along the ray, the system accumulates features from all other views that image this point. This involves projecting the 3D point onto the other $N-1$ input images and extracting local image features [S1].
*   **Feature Aggregation:** The features from all viewing directions are aggregated by concatenating mean and variance vectors, which serve as signals for downstream density and color prediction [S1].

**Noise Model:**
The noisy version of a clean linear image $I_n(x)$ at coordinate $x$ follows a Gaussian distribution [S1]:
$$ I_n(x) \sim \mathcal{N}(I_c(x), \sigma_r^2 + \sigma_s^2 I_c(x)) $$
where $I_c(x)$ is the clean intensity, $\sigma_r$ is the signal-independent read-noise parameter, and $\sigma_s$ is the signal-dependent shot-noise parameter [S1].

**Rendering Equation:**
The density $\rho_m$ predicted for the $m$-th sample point determines the probability $w_m$ that an object exists at that location [S1]:
$$ w_m = \frac{1 - e^{-\rho_m}}{e^{\sum_{j=1}^{m-1} \rho_j}} $$
The final color $\hat{C}(r)$ of the predicted target image pixel is the weighted sum of the point colors $c_m$ [S1]:
$$ \hat{C}(r) = \sum_{m=1}^{M} w_m c_m $$

**Training Procedure:**
1.  **Pre-training:** The network builds upon IBRNet, which is pre-trained on different image sets to produce novel views in unseen scenes [S1].
2.  **Novel View Selection:** In training, the novel pose is taken to be one of the available (non-input) viewpoints [S1].
3.  **Loss:** A loss function measures rendering quality by comparing the rendered image to the ground truth clean image [S1].
4.  **Noise Range:** Training extends up to a gain level of 20, with a maximum noise level equivalent to a standard deviation of $\sim 0.4$ for images in $[0,1]$ [S1].

**Inference Steps:**
1.  Select a target view from the burst.
2.  For each pixel in the target image:
    a. Project a ray $r$ into 3D space.
    b. Sample the ray at $M$ positions $m=1 \dots M$ on an inverse-depth scale [S1].
    c. For each sample point, project it onto all other input views to gather local features.
    d. Aggregate features by concatenating mean and variance vectors [S1].
    e. Predict density $\rho_m$ and color $c_m$ for the point [S1].
    f. Compute weights $w_m$ and accumulate color $\hat{C}(r)$ [S1].
3.  The process is repeated in two stages: 'coarse' and 'fine'. In the fine stage, sampling is refined around depth values that most influence the rendering (i.e., at visible surfaces) [S1].

**Pseudocode:**
```python
def nan_burst_denoise(noisy_images, target_view_index, num_samples_coarse, num_samples_fine):
    """
    Performs burst denoising using the NAN method.
    
    Args:
        noisy_images: List of N noisy images.
        target_view_index: Index of the target view to reconstruct.
        num_samples_coarse: M_coarse, number of coarse samples.
        num_samples_fine: M_fine, number of fine samples.
        
    Returns:
        clean_target_image: Reconstructed clean image.
    """
    # 1. Feature Extraction (Pre-Net)
    # Pre-process all input images to extract initial features
    input_features = pre_net(noisy_images)
    
    # 2. Initialize Output Image
    H, W, C = noisy_images[0].shape
    clean_target_image = np.zeros((H, W, C))
    
    # 3. Ray Marching for each pixel
    for y in range(H):
        for x in range(W):
            # Project ray for target pixel (x, y) into 3D space
            ray = project_ray(target_view_index, x, y)
            
            # Stage 1: Coarse Sampling
            # Sample M_coarse points on inverse-depth scale
            coarse_points = sample_inverse_depth(ray, num_samples_coarse)
            
            # Aggregate features for coarse points
            coarse_densities = []
            coarse_colors = []
            for point in coarse_points:
                # Project 3D point to other views
                projected_pixels = []
                for i, img_feat in enumerate(input_features):
                    if i != target_view_index:
                        # Get local features at projected location
                        feat = get_local_features(img_feat, point)
                        projected_pixels.append(feat)
                
                # Concatenate mean and variance of features from other views
                aggregated_feat = aggregate_features(projected_pixels)
                
                # Predict density and color using the main network
                density, color = predict_density_color(aggregated_feat, point)
                coarse_densities.append(density)
                coarse_colors.append(color)
            
            # Stage 2: Fine Sampling
            # Refine sampling around depths that influence rendering (visible surfaces)
            # This typically involves using the coarse depth distribution to guide fine sampling
            fine_points = refine_sampling(coarse_densities, coarse_points, num_samples_fine)
            
            fine_densities = []
            fine_colors = []
            for point in fine_points:
                projected_pixels = []
                for i, img_feat in enumerate(input_features):
                    if i != target_view_index:
                        feat = get_local_features(img_feat, point)
                        projected_pixels.append(feat)
                
                aggregated_feat = aggregate_features(projected_pixels)
                density, color = predict_density_color(aggregated_feat, point)
                fine_densities.append(density)
                fine_colors.append(color)
            
            # Combine coarse and fine samples (implementation detail: usually fine replaces or augments coarse)
            # For simplicity, we assume fine samples are used for final integration or combined
            all_densities = coarse_densities + fine_densities
            all_colors = coarse_colors + fine_colors
            
            # Compute weights and final color
            # w_m = (1 - exp(-rho_m)) / exp(sum_{j=1}^{m-1} rho_j)
            cumulative_density = 0.0
            final_color = np.zeros(C)
            total_weight = 0.0
            
            for density, color in zip(all_densities, all_colors):
                weight = (1.0 - np.exp(-density)) / np.exp(cumulative_density)
                final_color += weight * color
                total_weight += weight
                cumulative_density += density
            
            clean_target_image[y, x] = final_color
            
    return clean_target_image
```

**Edge Cases and Pitfalls:**
*   **High Noise:** The method is designed for noise levels up to $\sigma \approx 0.4$, which is higher than typical burst denoising benchmarks ($\sigma \approx 0.1-0.2$) [S1].
*   **Large Motion:** Unlike methods relying on optical flow (e.g., DeepRep), NAN handles large camera motion and occlusions by working in 3D [S1].
*   **Few Images:** The method works with as few as 8 images, leveraging pre-trained IBRNet priors [S1].

## Operating characteristics
*   **Time Complexity:** The method processes each pixel independently, projecting rays and aggregating features from $N-1$ other views for $M$ sample points. This is computationally intensive compared to 2D methods but scales linearly with the number of samples and views.
*   **Memory Complexity:** Requires storing features for all input images and intermediate aggregation states for each ray sample.
*   **Performance:** Achieves state-of-the-art results in burst denoising, especially under high noise and large motion [S1].
*   **Strengths:** Explicit 3D reasoning handles large parallax and occlusions better than 2D alignment methods. Robust to very high noise levels ($\sigma \approx 0.4$).
*   **Limitations:** Computationally more expensive than 2D CNN-based denoising. Requires a pre-trained model (IBRNet) which may have domain gaps if the scene differs significantly from training data.
*   **When to use:** Low-light imaging with handheld devices where burst capture is possible, and significant camera motion or high noise is expected.
*   **When not to use:** Real-time applications requiring low latency, or scenes with no inter-view overlap.

## Background
NAN was introduced in the paper "NAN: Noise-Aware NeRFs for Burst-Denoising" [S1]. It builds on the IBRNet architecture [S1], which pre-trains on different image sets to produce novel views in unseen scenes. The method addresses the limitations of previous burst denoising methods that operate in the image plane and are prone to errors in high noise or large motion due to reliance on optical flow or local kernels [S1]. It extends the training noise range up to gain level 20, covering noise levels up to $\sigma \approx 0.4$ [S1].
