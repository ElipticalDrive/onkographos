# NeRF-style Volume Rendering Integrator

Also called: NeRF forward raymarching, NeRFIntegrator

## Overview
This method computes the expected color $\hat{C}(r)$ for a ray $r$ by discretizing the medium interaction interval into fixed steps and accumulating emission weighted by transmittance [S1, unofficial]. It differs from its sibling [NeRF Rendering (Alpha Compositing)](5124-nerf-rendering-alpha-compositing.md) by using a fixed-step marching loop with explicit throughput tracking and jittering, rather than bin-based stratified sampling [S1, unofficial]. It is designed for dense grid-based media where direction-dependent emission is not required [S1, unofficial].

## How it works
**Inputs:**
- Ray origin $o$ and direction $d$.
- Medium exit distance $t_f$ (from intersection).
- Density field $\sigma(x)$ and emission field $c(x)$.
- Parameters: `queries_per_ray` ($N$), `density_noise_std`, `jittering_enabled`, `activation`.

**Outputs:**
- Accumulated color $\hat{C}(r)$.

**Data Structures:**
- `throughput`: Scalar float, initialized to 1.0.
- `result`: Vector float (color), initialized to 0.
- `weights_sum`: Scalar float, initialized to 0.
- `step_j`: Integer counter, initialized to 0.
- `t_a`: Scalar float, current position along ray, initialized to 0.
- `active_mask`: Boolean mask for active rays.

**Steps:**
1. **Initialization:** Set `result` = 0, `delta_L` = 0, `throughput` = 1.0, `weights_sum` = 0, `step_j` = 0, `t_a` = 0. Determine primal mode. Intersect ray to find medium exit $t_f$. Update `active_mask` to rays hitting the exit [S1, unofficial].
2. **Step Size Calculation:** Calculate `step_size` using `step_size_for_marching(queries_per_ray, 0, t_f, jittering_enabled)`. Sample `jitter_sample` from sampler [S1, unofficial].
3. **Marching Loop:** While `still_walking` (mask: `step_j < queries_per_ray`):
    a. Calculate $t_b$ using `query_t_for_step(step_j + 1, step_size, jitter_sample, jittering_enabled)`.
    b. Calculate `actual_step` = $t_b - t_a$.
    c. Calculate `alpha_recip`:
       - If `step_j + 1 < queries_per_ray`: $\alpha_{recip} = \exp(-\sigma \cdot \text{actual\_step})$.
       - Else: $\alpha_{recip} = 1.0$.
       - Add $10^{-10}$ to `alpha_recip` for numerical stability [S1, unofficial].
    d. Calculate `weight` = $(1.0 - \alpha_{recip}) \cdot \text{throughput}$.
    e. Update `result`:
       - If primal: `result` += `weight` * emission.
       - Else: `result` -= `weight` * emission.
    f. Increment `step_j`. Update $t_a = t_b$.
    g. Update `throughput` *= `safe_alpha_recip` (where `safe_alpha_recip` is `alpha_recip` with epsilon guard).
    h. Update `weights_sum` += `weight` [S1, unofficial].
4. **Background Contribution:** Calculate `contribution` = $(1 - \text{weights\_sum}) \cdot c_{bg}$. Add to `result` for active pixels [S1, unofficial].

**Pseudocode:**
```python
def nerf_integrator(ray_o, ray_d, t_f, sigma_func, c_func, N=128, jitter=True, eps=1e-10):
    throughput = 1.0
    result = 0.0
    weights_sum = 0.0
    step_j = 0
    t_a = 0.0
    
    # Step size calculation (simplified)
    step_size = t_f / N
    jitter_sample = random.uniform(0, 1) if jitter else 0.0
    
    while step_j < N:
        # Calculate next sample position
        t_b = (step_j + 1) * step_size + (jitter_sample * step_size if jitter else 0.0)
        # Clamp to t_f if necessary, though logic assumes t_f is exit
        if t_b > t_f:
            t_b = t_f
            
        actual_step = t_b - t_a
        
        # Density query
        pos = ray_o + t_a * ray_d # Approximate position for sigma
        sigma = sigma_func(pos)
        
        # Alpha reciprocal calculation
        if step_j + 1 < N:
            alpha_recip = math.exp(-sigma * actual_step)
        else:
            alpha_recip = 1.0
            
        # Numerical stability
        alpha_recip_safe = alpha_recip + eps
        
        # Weight calculation
        weight = (1.0 - alpha_recip_safe) * throughput
        
        # Emission query
        c = c_func(pos)
        
        # Accumulate result (primal mode assumed)
        result += weight * c
        
        # Update state
        step_j += 1
        t_a = t_b
        throughput *= alpha_recip_safe
        weights_sum += weight
        
    # Background contribution
    result += (1.0 - weights_sum) * c_bg
    
    return result
```

**Parameters:**
- `queries_per_ray` ($N$): Number of steps. Default 128 [S1, unofficial].
- `density_noise_std`: Standard deviation for density noise. Default 0 [S1, unofficial].
- `jittering_enabled`: Enable jittering. Default True [S1, unofficial].
- `activation`: Activation for density ('identity', 'relu'). Default 'identity' [S1, unofficial].

**Edge Cases:**
- If `weights_sum` is zero, background emitters may be hidden if `hide_emitters` is True [S1, unofficial].
- Epsilon ($10^{-10}$) is added to `alpha_recip` to prevent NaNs in gradients [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N)$ per ray, where $N$ is `queries_per_ray`.
- **Memory Complexity:** $O(1)$ per ray (excluding density grid storage).
- **Strengths:** Simple implementation, differentiable, suitable for dense grids [S1, unofficial].
- **Limitations:** Fixed step size may undersample complex media; no direction-dependent emission [S1, unofficial].
- **When to use:** When using dense grid representations and direction-independent emission is sufficient [S1, unofficial].

## Background
Originated from NeRF-style volume rendering approaches, adapted for unbiased inverse volume rendering with dense grids [S1, unofficial].
