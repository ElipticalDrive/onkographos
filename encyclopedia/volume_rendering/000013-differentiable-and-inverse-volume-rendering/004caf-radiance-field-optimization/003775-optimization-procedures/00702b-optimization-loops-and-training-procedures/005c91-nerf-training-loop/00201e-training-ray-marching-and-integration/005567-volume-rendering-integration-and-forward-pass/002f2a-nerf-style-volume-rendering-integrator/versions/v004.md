# NeRF-style Volume Rendering Integrator

Also called: NeRF forward raymarching, NeRFIntegrator

## Overview
This method computes the expected color $\hat{C}(r)$ for a ray $r$ by discretizing the medium interaction interval into a fixed number of steps and accumulating emission weighted by opacity [S1, unofficial]. It differs from standard NeRF implementations by using a dense grid for density queries rather than a neural network, and by supporting both primal and adjoint (gradient) modes for inverse rendering [S1, unofficial]. It serves as the forward pass component in differentiable volume rendering pipelines [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Ray $r(t) = o + td$, medium exit distance $t_f$ (from intersection), number of queries per ray $N$ (default 128), jittering flag, density noise standard deviation, activation function type.
*   **Output:** Accumulated color $\hat{C}(r)$ and transmittance/weight sums for gradient computation.

**Data Structures:**
*   **State Variables:** `result` (color accumulator), `throughput` (accumulated transmittance $T$), `weights_sum` (accumulated weight $\sum w_i$), `step_j` (current step index), `t_a` (previous sample position), `t_b` (current sample position).
*   **Mask:** `active_mask` (boolean vector indicating which rays are still valid/inside the medium).

**Parameters:**
*   `queries_per_ray` ($N$): Number of steps. Default: 128 [S1, unofficial].
*   `density_noise_std`: Standard deviation for density noise. Default: 0 [S1, unofficial].
*   `jittering_enabled`: Enable stratified jittering. Default: True [S1, unofficial].
*   `activation`: Density activation ('identity', 'relu'). Default: 'identity' [S1, unofficial].
*   `hide_emitters`: Hide background if weights_sum is zero. Default: False [S1, unofficial].

**Algorithm Steps:**
1.  **Initialization:** Initialize `result` = 0, `throughput` = 1, `weights_sum` = 0, `step_j` = 0, `t_a` = 0. Determine if the current mode is primal or adjoint.
2.  **Ray Intersection:** Intersect the ray with the medium boundary to find the exit distance $t_f$. Update `active_mask` to exclude rays that do not hit the medium.
3.  **Step Size Calculation:** Calculate `step_size` based on $t_f$, $N$, and jittering. If jittering is enabled, draw a random offset `jitter_sample` from the sampler [S1, unofficial].
4.  **Marching Loop:** While `step_j < N` and `active_mask` is true:
    a.  **Sample Position:** Calculate $t_b$ using `query_t_for_step(step_j + 1, step_size, jitter_sample, jittering_enabled)`. Calculate `actual_step` = $t_b - t_a$.
    b.  **Density Query:** Query the density grid at position $r(t_b)$. Apply `activation` and add noise if `density_noise_std > 0`. Let the result be $\sigma$.
    c.  **Alpha/Weight Calculation:**
        *   If `step_j + 1 < N`: Calculate `alpha_recip` = $\exp(-\sigma \cdot \text{actual\_step})$.
        *   Else (last step): `alpha_recip` = 1.0.
        *   Add epsilon ($10^{-10}$) to `alpha_recip` for numerical stability [S1, unofficial].
        *   Calculate `weight` = $(1.0 - \text{alpha\_recip}) \cdot \text{throughput}$.
    d.  **Accumulation:**
        *   If primal mode: `result` += `weight` * emission($r(t_b)$).
        *   If adjoint mode: `result` -= `weight` * emission($r(t_b)$) [S1, unofficial].
    e.  **Update State:**
        *   `step_j` += 1.
        *   `t_a` = $t_b$.
        *   `throughput` *= `alpha_recip`.
        *   `weights_sum` += `weight`.
        *   Update `active_mask`: false if `step_j >= N`.
5.  **Background Contribution:** Calculate background term: `contribution` = $(1 - \text{weights\_sum}) \cdot c_{bg}$ (where $c_{bg}$ is the background color, typically white). Add to `result` for active pixels [S1, unofficial].
6.  **Emitter Hiding:** If `hide_emitters` is true and `weights_sum` is zero, do not add emitter contributions [S1, unofficial].

**Pseudocode:**
```python
def nerf_integrator(ray_o, ray_d, t_f, N=128, jittering=True, density_noise_std=0.0, activation='identity'):
    # Initialize state
    result = 0.0
    throughput = 1.0
    weights_sum = 0.0
    step_j = 0
    t_a = 0.0
    
    # Determine mode (primal/adjoint) - assumed passed or global context
    is_primal = True 
    
    # Calculate step size
    step_size = t_f / N
    jitter_sample = random.uniform(0, 1) if jittering else 0.0
    
    # Pre-calculate jittered step positions if needed, or compute on fly
    # For clarity, we compute t_b iteratively
    
    while step_j < N:
        # Calculate current sample position t_b
        # query_t_for_step implements stratified sampling logic
        t_b = t_a + step_size * (step_j + 1) + (jitter_sample * step_size if jittering else 0)
        # Clamp t_b to t_f if necessary, though loop condition handles N steps
        if t_b > t_f:
            t_b = t_f
            
        actual_step = t_b - t_a
        
        # Query density
        pos = ray_o + ray_d * t_b
        sigma = query_density_grid(pos)
        
        # Apply activation
        if activation == 'relu':
            sigma = max(0.0, sigma)
        elif activation == 'identity':
            pass
            
        # Add noise
        if density_noise_std > 0:
            sigma += random.gauss(0, density_noise_std)
            
        # Calculate alpha_recip and weight
        if step_j + 1 < N:
            alpha_recip = math.exp(-sigma * actual_step)
        else:
            alpha_recip = 1.0
            
        # Numerical stability
        alpha_recip_safe = alpha_recip + 1e-10
        
        weight = (1.0 - alpha_recip_safe) * throughput
        
        # Accumulate result
        emission = query_emission_grid(pos) # Assuming emission query
        if is_primal:
            result += weight * emission
        else:
            result -= weight * emission
            
        # Update state
        step_j += 1
        t_a = t_b
        throughput *= alpha_recip_safe
        weights_sum += weight
        
    # Background contribution
    background_color = [1.0, 1.0, 1.0] # Default white
    background_term = (1.0 - weights_sum) * background_color
    result += background_term
    
    return result
```

## Operating characteristics
*   **Time Complexity:** $O(N)$ per ray, where $N$ is `queries_per_ray`.
*   **Memory Complexity:** $O(1)$ per ray for state variables, plus $O(V)$ for the density grid storage $V$.
*   **Strengths:** Simple, differentiable, supports dense grids for fast lookup.
*   **Limitations:** Fixed number of steps may lead to aliasing or insufficient sampling in complex regions. Dense grids consume significant memory for large scenes.
*   **When to use:** When using dense voxel grids for density representation and needing differentiable rendering.
*   **When not to use:** For sparse scenes where sparse data structures (like Octrees) are more efficient, or when direction-dependent emission is required (this method assumes no direction dependence [S1, unofficial]).

## Background
This integrator is derived from the NeRF framework but adapted for unbiased inverse volume rendering using dense grids [S1, unofficial]. It originates from research into differentiable volume rendering for inverse problems [S1, unofficial].
