# Masked Evaluation

Also called: Depth reprojection masking, Evaluation Visibility Mask Generation

## Overview
Masked Evaluation is a procedure that restricts radiance field evaluation metrics (such as PSNR or SSIM) to pixels visible in at least two training views, preventing metric degradation caused by predicting unseen geometry [S1, S2]. Unlike standard metric computation which evaluates all pixels, this method identifies occluded or single-view-only regions and excludes them, ensuring that errors are not artificially inflated by the radiance field's inability to predict content it has not seen [S2]. It differs from feature-level occlusion handling by operating directly on rendered depth maps to guide visibility determination [S1].

## How it works
**Inputs and Outputs:**
- **Inputs:**
  - Set of training views $V_{train} = \{v_1, \dots, v_N\}$ with known camera poses $P_i$ and intrinsics $K_i$.
  - Dense depth maps $D_i$ predicted by a Dense-NeRF model for each training view $v_i$ [S1, S2].
  - Test view $v_{test}$ with camera pose $P_{test}$ and intrinsics $K_{test}$.
  - Dense depth map $D_{test}$ predicted by the Dense-NeRF model for the test view [S1, S2].
- **Outputs:**
  - Binary visibility mask $M_{test}$ of the same spatial dimensions as $v_{test}$, where $M_{test}(u,v) = 1$ if the pixel is visible in at least two training views, and $0$ otherwise [S1, S2].

**Data Structures:**
- Depth maps are 2D arrays of floating-point values representing distance from the camera center.
- The visibility mask is a 2D boolean or integer array.

**Parameters:**
- **Depth Difference Threshold ($\tau$):** Set to $0.05 \times \max(D_{train})$, where $\max(D_{train})$ is the maximum depth value in the training view's depth map [S1, S2].

**Steps:**
1. Initialize the visibility accumulator $Acc_{test}$ as a zero-filled 2D array with the same dimensions as $D_{test}$ [S1, S2].
2. For each training view $v_i \in V_{train}$:
   a. Warp the training depth map $D_i$ to the test view coordinate system using depth-based reprojection [S1, S2]. This involves projecting each pixel $(u_i, v_i)$ from $D_i$ into 3D space using $P_i, K_i$, and then projecting that 3D point into the test view using $P_{test}, K_{test}$ to obtain coordinates $(u_{test}, v_{test})$ [S1, S2].
   b. Let $D_{warped}(u_{test}, v_{test})$ be the depth value at the projected location in the test view [S1, S2].
   c. Compare $D_{warped}(u_{test}, v_{test})$ with the predicted test depth $D_{test}(u_{test}, v_{test})$ [S1, S2].
   d. If the absolute difference $|D_{warped}(u_{test}, v_{test}) - D_{test}(u_{test}, v_{test})| < \tau$, mark the pixel $(u_{test}, v_{test})$ as visible in training view $v_i$ [S1, S2].
   e. Increment $Acc_{test}(u_{test}, v_{test})$ by 1 for each such valid correspondence [S1, S2].
3. Generate the final mask $M_{test}$ by setting $M_{test}(u,v) = 1$ if $Acc_{test}(u,v) \ge 2$, and $0$ otherwise [S1, S2].

**Pseudocode:**
```python
def generate_masked_evaluation_mask(training_depths, training_poses, training_intrinsics,
                                    test_depth, test_pose, test_intrinsics):
    """
    Generate a binary visibility mask for a test view based on depth consistency
    with at least two training views.
    
    Args:
        training_depths: List of 2D arrays, depth maps for each training view.
        training_poses: List of camera pose matrices for training views.
        training_intrinsics: Camera intrinsic matrices for training views.
        test_depth: 2D array, predicted depth map for the test view.
        test_pose: Camera pose matrix for the test view.
        test_intrinsics: Camera intrinsic matrix for the test view.
        
    Returns:
        mask: 2D boolean array, True if visible in >= 2 training views.
    """
    h, w = test_depth.shape
    # Accumulator for visibility counts
    visibility_count = np.zeros((h, w), dtype=np.int32)
    
    # Threshold: 0.05 * max depth of the training view
    # Note: Sources specify using the max depth of the *training* view.
    # We iterate over training views, so we use the max depth of the current training view.
    
    for i in range(len(training_depths)):
        d_train = training_depths[i]
        pose_train = training_poses[i]
        K_train = training_intrinsics[i]
        K_test = test_intrinsics
        pose_test = test_pose
        
        # Max depth of the current training view
        max_depth_train = np.max(d_train)
        threshold = 0.05 * max_depth_train
        
        # Warp training depth to test view
        # 1. Unproject training depth to 3D points
        # 2. Transform 3D points to test camera coordinates
        # 3. Project to test image coordinates
        # 4. Sample depth at projected coordinates
        
        # Create grid for training view
        u_train, v_train = np.meshgrid(np.arange(w), np.arange(h))
        
        # Unproject to 3D (assuming normalized camera coordinates or similar)
        # This step depends on the specific coordinate system definition.
        # Generally: X = K^{-1} * [u, v, 1]^T * depth
        # Then transform: X_test = R_test * R_train^T * (X_train - t_train) + t_test
        # Or using full pose matrices: X_test = P_test * P_train^{-1} * X_train_homogeneous
        
        # For implementation clarity, we assume a helper function for reprojection
        # that handles the geometry.
        u_test, v_test, valid_mask = warp_depth_to_test_view(
            d_train, pose_train, K_train, pose_test, K_test
        )
        
        # Get warped depth values at projected locations
        # Interpolate from d_train at (u_train, v_train) mapped to (u_test, v_test)
        # Actually, we need the depth value *at* the projected location in the test view
        # which corresponds to the depth value *from* the training view.
        # So, d_warped(u_test, v_test) = d_train(u_train, v_train)
        
        # Collect valid projected pixels
        valid_indices = np.where(valid_mask)
        if len(valid_indices[0]) == 0:
            continue
            
        u_t = u_test[valid_indices]
        v_t = v_test[valid_indices]
        
        # Get the corresponding depth from the training view
        # Since we warped FROM training TO test, the depth value is from training view
        d_warped_values = d_train[valid_indices]
        
        # Get the predicted depth from the test view at the projected locations
        # Clip coordinates to image bounds
        u_t_clipped = np.clip(u_t, 0, w - 1).astype(int)
        v_t_clipped = np.clip(v_t, 0, h - 1).astype(int)
        
        d_test_values = test_depth[v_t_clipped, u_t_clipped]
        
        # Check depth consistency
        depth_diff = np.abs(d_warped_values - d_test_values)
        is_visible = depth_diff < threshold
        
        # Increment visibility count for visible pixels
        visible_u = u_t_clipped[is_visible]
        visible_v = v_t_clipped[is_visible]
        
        # Ensure indices are within bounds for accumulation
        valid_acc_u = np.clip(visible_u, 0, w - 1)
        valid_acc_v = np.clip(visible_v, 0, h - 1)
        
        for u, v in zip(valid_acc_u, valid_acc_v):
            visibility_count[v, u] += 1
            
    # Final mask: visible if count >= 2
    mask = visibility_count >= 2
    return mask
```

**Edge Cases and Pitfalls:**
- **Depth Estimation Accuracy:** Mask accuracy is entirely dependent on the accuracy of the Dense-NeRF depth estimation. Incorrect depths produce incorrect masks [S1, S2].
- **Specular Surfaces:** Using depth-based reprojection is robust to specular objects, whereas color-based reprojection fails on such surfaces [S1, S2].
- **Single-View Objects:** Radiance fields are designed to memorize scenes and cannot predict geometry seen in only one view. Evaluating these regions artificially inflates error metrics [S2].

## Subtopics

### [Masked Evaluation (Depth-based Visibility Mask Generation)](8648-masked-evaluation-depth-based-visibility-mask-generation.md)
Identifies pixels in a reference view that are occluded when viewed from a new camera pose by comparing depth maps. Used to restrict evaluation or inpainting to visible regions.

### [View-Consistency Metric (E_warp)](15720-view-consistency-metric-e-warp.md)
Evaluates geometric and photometric consistency between rendered and warped views, serving as a self-supervised regularizer.

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of training views and the number of pixels in the test view. For each training view, depth warping and comparison are performed.
- **Memory Complexity:** Proportional to the size of the depth maps and the visibility accumulator.
- **Strengths:** Prevents metric degradation from predicting unseen geometry; robust to specular objects when using depth; ensures evaluation focuses on geometrically consistent regions [S2].
- **Limitations:** Relies heavily on the accuracy of the Dense-NeRF depth predictions; does not account for occlusions that are not captured by depth consistency (e.g., if depth estimates are noisy) [S1, S2].
- **When to Use:** When evaluating radiance fields trained on sparse input views where unseen regions are common and should not penalize the model [S1, S2].
- **When Not to Use:** When the goal is to evaluate the model's ability to hallucinate or predict unseen content (though NeRFs are not designed for this) [S2].

## Background
Masked Evaluation was introduced in the context of regularizing sparse input Neural Radiance Fields (NeRFs) to address the issue that radiance fields memorize scenes and cannot predict unseen regions by design [S1, S2]. The method was proposed in "SimpleNeRF" [S1] and "Simple-RF" [S2] to ensure that evaluation metrics reflect the model's ability to reconstruct visible geometry rather than its failure to predict invisible content. It builds on depth-based reprojection techniques similar to those used in [Cho et al. 2017] and [Kanchana et al. 2022] [S1, S2].
