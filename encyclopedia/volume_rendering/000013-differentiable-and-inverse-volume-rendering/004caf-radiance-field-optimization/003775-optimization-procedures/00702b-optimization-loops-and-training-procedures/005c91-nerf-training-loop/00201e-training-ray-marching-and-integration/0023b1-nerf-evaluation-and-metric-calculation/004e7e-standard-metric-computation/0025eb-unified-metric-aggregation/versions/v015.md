# Unified Metric Aggregation

Also called: Evaluation & Metric Computation, Evaluation Reporting, Global and Per-view Metric Aggregation, Frame-Averaged Evaluation Metrics, NVS metric aggregation, test-time metric logging

## Overview
Unified Metric Aggregation computes and averages standard photometric and perceptual metrics (PSNR, SSIM, LPIPS, RMSE, L1) over a set of valid novel view synthesis (NVS) frames, then logs and saves these global and per-view statistics [S1, S2, S3, unofficial]. It differs from [PSNR Evaluation Pipeline](4315-psnr-evaluation-pipeline.md) by supporting a broader suite of metrics (including SSIM and LPIPS) and from [Masked Evaluation](7531-masked-evaluation.md) by typically operating on full-frame RGB comparisons unless a specific validity mask is applied [S1, unofficial]. It serves as the statistical aggregation layer that consumes raw per-view scores generated by metric-specific protocols [S2, unofficial].

## How it works
**Inputs:**
1.  A list of paired rendered images and ground truth (GT) images.
2.  A boolean mask `valid_nvs_frames` indicating which frames are valid for evaluation [S1, unofficial].
3.  Configuration flags for extra metrics (SSIM, LPIPS) and logging backends (e.g., Weights & Biases) [S1, S3, unofficial].

**Outputs:**
1.  Global average metrics (PSNR, SSIM, LPIPS, etc.) [S2, unofficial].
2.  Per-view metric dictionaries mapping image names to individual scores [S2, unofficial].
3.  JSON files containing global and per-view metrics [S2, unofficial].
4.  Optional logs to W&B and saved text/image files [S1, S3, unofficial].

**Data Structures:**
*   `psnr_list`, `rmse_list`, `l1_list`, `ssim_list`, `lpips_list`: Lists of floats storing per-view metric values.
*   `per_view_metrics`: Dictionary mapping `image_name` to a dict of metric values.
*   `global_metrics`: Dictionary mapping metric name to float average.

**Steps:**
1.  **Initialization**: Initialize empty lists for each metric type and an empty dictionary for per-view results [S2, unofficial].
2.  **Iteration**: Iterate over the paired render/GT image paths. If a validity mask is provided, skip frames where the mask is false [S1, unofficial].
3.  **Preprocessing**:
    *   Load the rendered RGB image and GT RGB image.
    *   Normalize pixel values to the range $[0, 1]$ [S2, unofficial].
    *   Convert images to CHW (Channel, Height, Width) tensor format [S2, unofficial].
    *   Verify that rendered and GT images have matching shapes [S2, unofficial].
    *   *Note*: If GT has an alpha channel, composite it with a white background before comparison [Parent].
4.  **Metric Computation**:
    *   Compute MSE: $\text{MSE} = \frac{1}{N} \sum_{i=1}^{N} (R_i - G_i)^2$ [Parent].
    *   Compute PSNR: $\text{PSNR} = -10 \cdot \frac{\log(\text{MSE})}{\log(10)}$ [S3, unofficial]. Handle infinite PSNR (MSE=0) by capping or using epsilon [Parent].
    *   Compute L1: $\text{L1} = \frac{1}{N} \sum_{i=1}^{N} |R_i - G_i|$ [S1, unofficial].
    *   Compute RMSE: $\text{RMSE} = \sqrt{\text{MSE}}$ [S1, unofficial].
    *   If enabled, compute SSIM and LPIPS [S3, unofficial]. LPIPS requires specific input intensity scaling before feature comparison [S1, unofficial].
5.  **Validation**: Check that computed metrics are finite. Discard or flag non-finite values [S2, unofficial].
6.  **Storage**: Append valid metric values to their respective lists. Store per-view results in `per_view_metrics` keyed by image name [S2, unofficial].
7.  **Aggregation**: After the loop, compute the arithmetic mean of each metric list [S2, unofficial].
    $$ \text{Global Metric} = \frac{1}{M} \sum_{j=1}^{M} \text{Metric}_j $$
    where $M$ is the number of valid frames.
8.  **Logging and Saving**:
    *   Save global metrics and per-view dictionaries to JSON files [S2, unofficial].
    *   Print averages: PSNR to 2 decimals, RMSE/L1 to 2 decimals (often scaled by 100 for cm in depth contexts, but here for pixel error), SSIM/LPIPS to 3 decimals [S1, unofficial].
    *   Save metric lists as text files [S1, unofficial].
    *   Log to Weights & Biases if enabled [S1, unofficial].
    *   Optionally plot metrics over time steps [S1, unofficial].

**Pseudocode:**
```python
import numpy as np
import torch
import json

def compute_unified_metrics(rendered_images, gt_images, valid_mask=None, 
                            compute_ssim=False, compute_lpips=False, 
                            wandb_run=None, eval_dir=None):
    """
    Compute and aggregate PSNR, L1, RMSE, SSIM, LPIPS over valid frames.
    
    Args:
        rendered_images: List of tensors (H, W, 3) or (3, H, W) in [0, 1].
        gt_images: List of tensors (H, W, 3) or (3, H, W) in [0, 1].
        valid_mask: Boolean array indicating valid frames. If None, all are valid.
        compute_ssim: Boolean flag for SSIM.
        compute_lpips: Boolean flag for LPIPS.
        wandb_run: W&B run object for logging.
        eval_dir: Directory to save JSON/text outputs.
        
    Returns:
        global_metrics: Dict of metric names to float averages.
        per_view_metrics: Dict of image_name to metric dicts.
    """
    psnr_list = []
    l1_list = []
    rmse_list = []
    ssim_list = []
    lpips_list = []
    per_view_metrics = {}
    
    # Determine valid indices
    if valid_mask is not None:
        indices = [i for i, valid in enumerate(valid_mask) if valid]
    else:
        indices = list(range(len(rendered_images)))
        
    for idx in indices:
        render = rendered_images[idx]
        gt = gt_images[idx]
        image_name = f"frame_{idx}" # Or derived from path
        
        # Ensure CHW format and [0,1] range
        if render.dim() == 3 and render.shape[0] in [1, 3]:
            render = render.permute(1, 2, 0) # HWC
        if gt.dim() == 3 and gt.shape[0] in [1, 3]:
            gt = gt.permute(1, 2, 0) # HWC
            
        # Handle alpha channel in GT if present (composite with white bg)
        if gt.shape[-1] == 4:
            alpha = gt[:, :, 3:4]
            white_bg = torch.ones_like(gt[:, :, :3])
            gt_rgb = gt[:, :, :3] * alpha + white_bg * (1 - alpha)
        else:
            gt_rgb = gt[:, :, :3]
            
        # Compute MSE and PSNR
        mse = torch.mean((render - gt_rgb) ** 2)
        mse_val = mse.item()
        
        # Handle infinite PSNR
        if mse_val == 0:
            psnr_val = 100.0 # Cap at reasonable max or use epsilon
        else:
            psnr_val = -10.0 * np.log10(mse_val)
            
        # Compute L1 and RMSE
        l1_val = torch.mean(torch.abs(render - gt_rgb)).item()
        rmse_val = np.sqrt(mse_val)
        
        psnr_list.append(psnr_val)
        l1_list.append(l1_val)
        rmse_list.append(rmse_val)
        
        # Compute SSIM if requested
        ssim_val = None
        if compute_ssim:
            ssim_val = compute_ssim_metric(render, gt_rgb) # [G] Placeholder for SSIM implementation
            ssim_list.append(ssim_val)
            
        # Compute LPIPS if requested
        lpips_val = None
        if compute_lpips:
            lpips_val = compute_lpips_metric(render, gt_rgb) # [G] Placeholder for LPIPS implementation
            lpips_list.append(lpips_val)
            
        # Validate finiteness
        if not np.isfinite(psnr_val):
            continue
            
        # Store per-view
        view_metrics = {"PSNR": psnr_val, "L1": l1_val, "RMSE": rmse_val}
        if ssim_val is not None:
            view_metrics["SSIM"] = ssim_val
        if lpips_val is not None:
            view_metrics["LPIPS"] = lpips_val
            
        per_view_metrics[image_name] = view_metrics
        
    # Aggregate
    global_metrics = {}
    if psnr_list:
        global_metrics["PSNR"] = np.mean(psnr_list)
    if l1_list:
        global_metrics["L1"] = np.mean(l1_list)
    if rmse_list:
        global_metrics["RMSE"] = np.mean(rmse_list)
    if ssim_list:
        global_metrics["SSIM"] = np.mean(ssim_list)
    if lpips_list:
        global_metrics["LPIPS"] = np.mean(lpips_list)
        
    # Save outputs
    if eval_dir:
        # Save global metrics
        global_json = {"global": global_metrics}
        with open(f"{eval_dir}/global_metrics.json", "w") as f:
            json.dump(global_json, f)
            
        # Save per-view metrics
        per_view_json = {"per_view": per_view_metrics}
        with open(f"{eval_dir}/per_view_metrics.json", "w") as f:
            json.dump(per_view_json, f)
            
        # Save lists as text
        np.savetxt(f"{eval_dir}/psnr_list.txt", psnr_list)
        np.savetxt(f"{eval_dir}/l1_list.txt", l1_list)
        
    # Log to W&B
    if wandb_run and global_metrics:
        wandb_run.log({"Final Stats/PSNR": global_metrics.get("PSNR"),
                       "Final Stats/SSIM": global_metrics.get("SSIM"),
                       "Final Stats/LPIPS": global_metrics.get("LPIPS")})
                       
    return global_metrics, per_view_metrics
```

**Parameters:**
*   `valid_nvs_frames`: Boolean array indicating which frames are valid for evaluation [S1, unofficial].
*   `compute_extra_metrics`: Boolean flag to enable SSIM and LPIPS computation [S3, unofficial].
*   `img_eval_interval`: Step size for evaluating rays/images if processing large datasets incrementally [S3, unofficial].

**Edge Cases and Pitfalls:**
*   **Infinite PSNR**: If MSE is 0, PSNR is infinite. Implementations must cap this value or use a small epsilon to prevent aggregation errors [Parent].
*   **Alpha Channels**: GT images may have alpha channels while NeRFs render RGB. GT must be composited with a white background before comparison [Parent].
*   **Shape Mismatch**: Rendered and GT images must have identical dimensions. Checks should be performed before metric computation [S2, unofficial].
*   **Non-finite Values**: NaN or Inf values in metrics should be filtered out before averaging [S2, unofficial].

## Subtopics

### [LPIPS Evaluation Protocol](4376-lpips-evaluation-protocol.md)
LPIPS is a perceptual similarity metric used in volume rendering evaluation to quantify reconstruction fidelity. It differs from pixel-wise metrics by requiring a specific input intensity scaling step before feature comparison. It is chosen when perceptual quality is more important than pixel-wise accuracy. See [LPIPS Evaluation Protocol](4376-lpips-evaluation-protocol.md).

### [Quantitative Evaluation Metrics](9928-quantitative-evaluation-metrics.md)
Quantitative Evaluation Metrics provide a standardized numerical assessment of rendered image quality and geometric fidelity by comparing synthesized views against ground-truth data. While Unified Metric Aggregation handles the statistical aggregation of these scores, this method defines the specific computations for pixel-wise, perceptual, and distributional comparisons. It distinguishes itself from sibling methods like [LPIPS Evaluation Protocol](4376-lpips-evaluation-protocol.md) by encompassing the full suite of standard photometric metrics (PSNR, SSIM) alongside perceptual ones, rather than focusing exclusively on learned feature distances. See [Quantitative Evaluation Metrics](9928-quantitative-evaluation-metrics.md).

### Evaluation Reporting
This variant extends metric aggregation to include system-level performance metrics. It reports PSNR, SSIM, and LPIPS alongside the size of the resulting model (e.g., splats in MB) and rendering speed on specific hardware platforms (standalone PC, PC-VR, mobile VR) [S4]. It is chosen when evaluating real-time applicability and memory efficiency in addition to visual fidelity.

## Operating characteristics
*   **Time Complexity**: Linear with respect to the number of valid frames $M$ and the number of metrics $K$. $O(M \cdot K \cdot H \cdot W)$ for pixel-wise metrics (PSNR, L1, SSIM). LPIPS adds overhead due to neural network feature extraction.
*   **Memory Complexity**: $O(M \cdot K)$ to store per-view metric lists. JSON output size is $O(M \cdot K)$.
*   **Performance**: Depends heavily on the cost of SSIM and LPIPS. PSNR and L1 are very fast. LPIPS requires loading a pre-trained network (AlexNet or VGG) and can be slow if not batched or cached [S3, unofficial].
*   **Strengths**: Provides a comprehensive view of reconstruction quality across multiple dimensions (photometric, perceptual). Standardized output formats (JSON) facilitate comparison across methods.
*   **Limitations**: Does not evaluate geometric fidelity (e.g., depth error) unless explicitly added. LPIPS is computationally expensive.
*   **When to use**: Standard evaluation of novel view synthesis results.
*   **When not to use**: When only specific metrics (e.g., only PSNR) are required, or when real-time performance metrics are the primary focus (use Evaluation Reporting variant).

## Background
Unified Metric Aggregation is a standard post-processing step in NeRF and Gaussian Splatting evaluation pipelines. It originated from the need to standardize reporting across different NeRF implementations (e.g., [S3, unofficial] TensoRF, [S1, unofficial] SplaTAM). The method aggregates scores computed by specific metric protocols to provide a single summary of model performance. It is widely used in academic papers and open-source repositories for benchmarking 3D reconstruction methods [S1, S2, S3, unofficial][S4].
