# Cage-based Deformation for 3DGS

Also called: GSDeformer Deformation Algorithm

## Overview
Cage-based deformation for 3DGS (GSDeformer) is a real-time method that transfers geometric deformation from a proxy point cloud to a trained 3D Gaussian Splatting (3DGS) scene without retraining [S1, unofficial]. It solves the problem of accurately modeling large bending deformations, which standard mean-only optimization fails to capture, by splitting Gaussians and transforming their covariances [S1, unofficial]. Unlike sibling methods such as [Deformation Network for 4D Gaussian Splatting](16173-deformation-network-for-4d-gaussian-splatting.md) or [VolSegGS](10433-volseggs.md) which optimize existing Gaussians, GSDeformer explicitly subdivides ellipsoids to handle complex curvature [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Source 3DGS scene $S_s$ (set of Gaussians), Source Cage $C_s$, Target Cage $C_d$, Split threshold angle $t$.
*   **Output:** Deformed 3DGS scene $S_d$.

**Data Structures:**
*   **Gaussian:** Defined by mean position $\mu$, covariance matrix $\Sigma$ (or rotation $R$ and scale $S$), opacity $\alpha$, and spherical harmonics coefficients $c_{lm}$.
*   **Cage:** A polygonal mesh defining the deformation space.
*   **Points-represented ellipsoid ($AP$):** A set of points approximating the Gaussian's ellipsoidal shape.

**Steps:**
1.  **Proxy Construction:** For each Gaussian $i$ in the source scene, generate a points-represented ellipsoid set $AP_s$ [S1, unofficial]. The source notes reference Equation (4) for this conversion, but do not provide the explicit formula. [G] Typically, this involves sampling points on the surface of the ellipsoid defined by $\Sigma_i$ and $\mu_i$.
2.  **Cage-based Deformation:** Deform the points $AP_s$ to $AP_d$ using the source cage $C_s$ and target cage $C_d$ [S1, unofficial].
    *   Convert Euclidean points $AP_s$ to cage-based coordinates using $EulerToMVC(AP_s, C_s)$ [S1, unofficial].
    *   Interpolate deformation based on the cage topology (standard cage-based deformation logic).
    *   Convert back to Euclidean coordinates using $MVCToEuler(AP_{mvc}, C_d)$ to get $AP_d$ [S1, unofficial].
3.  **Splitting:** Initialize split sets $AP_{ss} = [AP_s]$ and $AP_{ds} = [AP_d]$. Call the `Split` function with threshold $t$ to handle large deformations [S1, unofficial].
    *   The `Split` function iterates over axes $a \in \{x, y, z\}$ and deformed ellipsoids $d_i \in AP_{ds}$ [S1, unofficial].
    *   For each axis, calculate the angle $\alpha$ formed by the endpoints $l, r$ of the axis and the center $c$ of the ellipsoid ($\alpha = \angle l-c-r$) [S1, unofficial].
    *   If $\alpha < t$, the ellipsoid is too "flat" or bent to be represented by a single Gaussian. It is split into two ellipsoids, $d_l$ and $d_r$ [S1, unofficial].
    *   $d_l$ center is set to $\text{mean}(c, l)$, and the $c-l$ vector becomes its new axis $a$ [S1, unofficial].
    *   $d_r$ center is set to $\text{mean}(c, r)$, and the $c-r$ vector becomes its new axis $a$ [S1, unofficial].
    *   The corresponding source ellipsoids in $AP_{ss}$ are also split to maintain correspondence [S1, unofficial].
4.  **Gaussian Transformation:** For each pair of source ellipsoid $s_i \in AP_{ss}$ and deformed ellipsoid $d_i \in AP_{ds}$:
    *   Compute the affine transform $T$ from $s_i$ to $d_i$ using Equation (6) [S1, unofficial]. [G] This is typically the least-squares affine transform mapping the point set $s_i$ to $d_i$.
    *   Compute translation $t = \text{center}(d_i) - \text{center}(s_i)$ [S1, unofficial].
    *   Transform the original Gaussian $i$ using Equations (7) and (8) [S1, unofficial]. [G] Equation (7) likely updates the mean: $\mu' = T\mu + t$. Equation (8) likely updates the covariance: $\Sigma' = T \Sigma T^T$ (or similar rotation/scaling update).
    *   Append the transformed Gaussian to the result set $S_d$ [S1, unofficial].
    *   **Note:** Spherical harmonics parameters are copied directly without rotation adjustment [S1, unofficial].

**Parameters:**
*   $t$: Split threshold angle. Theoretical analysis suggests $k$ (scaling factor related to splitting) should be $3/1$ or similar, but the threshold $t$ controls when splitting occurs [S1, unofficial]. A large $k$ (e.g., 1.0) causes spikes; a small $k$ (e.g., 0.1) causes fragmentation [S1, unofficial].

**Pitfalls:**
*   **Mean-only deformation:** Optimizing only the position causes significant striping artifacts [S1, unofficial].
*   **No splitting:** Disabling splitting causes spiking artifacts in bent regions because a single Gaussian cannot model the deformation [S1, unofficial].

def gsdeformer_deform(gs_scene, source_cage, target_cage, split_threshold):
    """
    Deforms a 3DGS scene using cage-based deformation.
    
    Args:
        gs_scene: List of Gaussian objects. Each has .mu, .cov, .opacity, .sh.
        source_cage: Cage mesh for source space.
        target_cage: Cage mesh for target space.
        split_threshold: Angle threshold for splitting ellipsoids.
        
    Returns:
        deformed_gs_scene: List of deformed Gaussian objects.
    """
    deformed_gs_scene = []
    
    for gaussian in gs_scene:
        # 1. Convert Gaussian to points-represented ellipsoid
        # Equation (4) from source. [G] Sample points on ellipsoid surface.
        ap_s = points_from_ellipsoid(gaussian.mu, gaussian.cov)
        
        # 2. Deform points using cage-based deformation
        # Convert to cage coordinates
        ap_mvc = euler_to_mvc(ap_s, source_cage)
        # Interpolate deformation (implicit in cage-based def)
        # Convert back to Euclidean
        ap_d = mvc_to_euler(ap_mvc, target_cage)
        
        # 3. Perform splitting
        ap_ss = [ap_s]
        ap_ds = [ap_d]
        ap_ss, ap_ds = split_function(gaussian, ap_ss, ap_ds, split_threshold)
        
        # 4. Transform Gaussians
        for si, di in zip(ap_ss, ap_ds):
            # Compute affine transform T from si to di
            # Equation (6) from source. [G] Compute least-squares affine transform.
            T = compute_affine_transform(si, di)
            
            # Compute translation
            center_si = mean_point(si)
            center_di = mean_point(di)
            t_vec = center_di - center_si
            
            # Transform Gaussian
            # Equations (7) and (8) from source. [G] Update mean and covariance.
            new_mu = T @ gaussian.mu + t_vec
            new_cov = T @ gaussian.cov @ T.T
            
            # Create new Gaussian
            new_gaussian = Gaussian()
            new_gaussian.mu = new_mu
            new_gaussian.cov = new_cov
            new_gaussian.opacity = gaussian.opacity
            # Copy SH without rotation adjustment
            new_gaussian.sh = gaussian.sh 
            
            deformed_gs_scene.append(new_gaussian)
            
    return deformed_gs_scene

def split_function(gaussian, ap_ss, ap_ds, threshold):
    """
    Splits ellipsoids if the bending angle is too large.
    """
    new_ap_ss = []
    new_ap_ds = []
    
    for si, di in zip(ap_ss, ap_ds):
        # Check if splitting is needed
        # [G] The source iterates over axes and checks angle alpha.
        # If alpha < threshold, split.
        # For simplicity, we assume a single split decision per ellipsoid here.
        # In reality, multiple splits might occur.
        
        center_di = mean_point(di)
        # [G] Determine principal axis endpoints l, r from di's covariance
        l, r = get_axis_endpoints(di, gaussian.cov)
        
        # Calculate angle alpha
        alpha = angle_between_vectors(center_di - l, center_di - r)
        
        if alpha < threshold:
            # Split into two
            # Left ellipsoid
            dl = copy_ellipsoid(di)
            dl.center = mean_point([center_di, l])
            # Shift points
            shift_points(dl.points, center_di, dl.center)
            # Update axis
            dl.axis = dl.center - l # c-l is new axis? Source says "make c-l dl's new a axis"
            
            # Right ellipsoid
            dr = copy_ellipsoid(di)
            dr.center = mean_point([center_di, r])
            shift_points(dr.points, center_di, dr.center)
            dr.axis = dr.center - r
            
            # Corresponding source splits
            sl = copy_ellipsoid(si)
            sl.center = mean_point([mean_point(si), l]) # Approximation
            shift_points(sl.points, mean_point(si), sl.center)
            
            sr = copy_ellipsoid(si)
            sr.center = mean_point([mean_point(si), r])
            shift_points(sr.points, mean_point(si), sr.center)
            
            new_ap_ss.extend([sl, sr])
            new_ap_ds.extend([dl, dr])
        else:
            new_ap_ss.append(si)
            new_ap_ds.append(di)
            
    return new_ap_ss, new_ap_ds

def get_axis_endpoints(ellipsoid_points, cov):
    """[G] Get endpoints of the principal axis."""
    eigenvalues, eigenvectors = np.linalg.eigh(cov)
    max_idx = np.argmax(eigenvalues)
    axis_vec = eigenvectors[:, max_idx]
    scale = np.sqrt(eigenvalues[max_idx])
    center = mean_point(ellipsoid_points)
    l = center - scale * axis_vec

## Operating characteristics
*   **Time Complexity:** Real-time performance is achieved through extensive caching. $AP_{mvc}$ and parts of the transform $T$ can be precomputed [S1, unofficial]. The splitting and transformation steps are linear with respect to the number of Gaussians and split ellipsoids.
*   **Memory Complexity:** Requires storing the proxy point sets and split ellipsoids temporarily. No additional training data or architectural changes are needed [S1, unofficial].
*   **Strengths:** Handles large bending deformations accurately via splitting; works on existing trained vanilla 3DGS without retraining; real-time capable.
*   **Limitations:** Copies spherical harmonics without rotation adjustment, potentially causing color inaccuracies under rotation; point-based deformation (if used instead of cage) is better for small deformations like facial expressions [S1, unofficial].
*   **When to use:** When deforming large, complex shapes with significant bending where mean-only optimization fails.
*   **When not to use:** For small, local deformations (e.g., facial expressions) where point-based methods might be more efficient, or when high-fidelity viewpoint-dependent color rotation is critical.

## Background
GSDeformer was introduced by the authors of the paper "GSDeformer: Direct Cage-based Deformation for 3D Gaussian Splatting" [S1, unofficial]. It adapts traditional cage-based deformation techniques to the specific data structure of 3DGS. The method addresses limitations in prior works like ARAP-GS and VRGS, which only optimize existing Gaussians and fail to model bending accurately [S1, unofficial]. The cage-building process is inspired by the 3DGS marching cube method proposed in SuGaR [S1, unofficial].
