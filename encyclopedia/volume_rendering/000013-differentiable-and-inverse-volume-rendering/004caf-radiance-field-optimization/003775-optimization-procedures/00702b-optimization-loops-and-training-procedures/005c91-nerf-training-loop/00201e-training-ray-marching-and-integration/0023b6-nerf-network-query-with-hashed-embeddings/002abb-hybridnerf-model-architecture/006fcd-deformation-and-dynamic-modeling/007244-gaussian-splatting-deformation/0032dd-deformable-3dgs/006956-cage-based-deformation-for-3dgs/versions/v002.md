# Cage-based Deformation for 3DGS

Also called: Deformation Algorithm, GSDeformer Deformation Algorithm

## Overview
Cage-based deformation for 3DGS (GSDeformer) is a real-time method that transfers geometric deformation from a proxy point cloud to a trained 3D Gaussian Splatting (3DGS) scene without retraining [S1, unofficial]. It solves the problem of accurately modeling large bending deformations, which standard mean-only optimization fails to capture, by splitting Gaussians and transforming their covariances [S1, unofficial]. Unlike sibling methods such as [Deformation Network for 4D Gaussian Splatting](16173-deformation-network-for-4d-gaussian-splatting.md) or [VolSegGS](10433-volseggs.md) which only optimize existing Gaussians, GSDeformer explicitly subdivides ellipsoids to handle complex curvature [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Source 3DGS scene $S_s$ (set of Gaussians), Source Cage $C_s$, Target Cage $C_d$, Split threshold angle $t$ [S1, unofficial].
*   **Output:** Deformed 3DGS scene $S_d$ [S1, unofficial].

**Data Structures:**
*   **Gaussian:** Standard 3DGS representation defined by mean position $\mu$, covariance matrix $\Sigma$ (encoding rotation and scale), opacity $\alpha$, and spherical harmonics coefficients $c_{lm}$ [G].
*   **Cage:** A polygonal mesh defining the deformation space [S1, unofficial].
*   **Points-represented ellipsoid ($AP$):** A discrete point set approximating the Gaussian's ellipsoidal shape, used as a proxy for deformation [S1, unofficial].

**Steps:**
1.  **Proxy Construction:** For each Gaussian $i$ in the source scene, generate a points-represented ellipsoid set $AP_s$ using Equation (4) [S1, unofficial]. [G] This typically samples points on the ellipsoid surface defined by $\Sigma_i$ and $\mu_i$.
2.  **Cage-based Deformation:** Deform the points $AP_s$ to $AP_d$ using the source cage $C_s$ and target cage $C_d$ [S1, unofficial].
    *   Convert Euclidean points $AP_s$ to cage-based coordinates using $EulerToMVC(AP_s, C_s)$ [S1, unofficial].
    *   Interpolate deformation based on the cage topology using standard cage-based deformation logic [G].
    *   Convert back to Euclidean coordinates using $MVCToEuler(AP_{mvc}, C_d)$ to obtain $AP_d$ [S1, unofficial].
3.  **Splitting:** Initialize split sets $AP_{ss} = [AP_s]$ and $AP_{ds} = [AP_d]$ [S1, unofficial]. Call the `Split` function with threshold $t$ to handle large deformations [S1, unofficial].
    *   The `Split` function iterates over axes $a \in \{x, y, z\}$ and deformed ellipsoids $d_i \in AP_{ds}$ [S1, unofficial].
    *   For each axis, calculate the angle $\alpha$ formed by the endpoints $l, r$ of the axis and the center $c$ of the ellipsoid ($\alpha = \angle l-c-r$) [S1, unofficial].
    *   If $\alpha < t$, the ellipsoid is too bent to be represented by a single Gaussian and is split into two ellipsoids, $d_l$ and $d_r$ [S1, unofficial].
    *   $d_l$ center is set to $\text{mean}(c, l)$, points are shifted from $c$ to the new center, and the $c-l$ vector becomes its new axis $a$ [S1, unofficial].
    *   $d_r$ center is set to $\text{mean}(c, r)$, points are shifted from $c$ to the new center, and the $c-r$ vector becomes its new axis $a$ [S1, unofficial].
    *   The corresponding source ellipsoids in $AP_{ss}$ are split identically to maintain correspondence [S1, unofficial].
4.  **Gaussian Transformation:** For each pair of source ellipsoid $s_i \in AP_{ss}$ and deformed ellipsoid $d_i \in AP_{ds}$:
    *   Compute the affine transform $T$ from $s_i$ to $d_i$ using Equation (6) [S1, unofficial]. [G] This is the least-squares affine transform mapping the point set $s_i$ to $d_i$.
    *   Compute translation $t_{vec} = \text{center}(d_i) - \text{center}(s_i)$ [S1, unofficial].
    *   Transform the original Gaussian $i$ using Equations (7) and (8) [S1, unofficial]. Equation (7) updates the mean position, and Equation (8) updates the covariance to account for rotation and scaling [S1, unofficial].
    *   Append the transformed Gaussian to the result set $S_d$ [S1, unofficial].
    *   Spherical harmonics parameters are copied directly without rotation adjustment [S1, unofficial].

**Parameters:**
*   $t$: Split threshold angle used to determine when an ellipsoid must be subdivided during deformation [S1, unofficial].
*   $k$: Split scaling factor. Theoretical analysis suggests $k$ should be $3/1$, but empirical testing shows a large $k$ (e.g., $1.0$) creates spikes on intricate surfaces, while a small $k$ (e.g., $0.1$) produces fragmented surfaces [S1, unofficial].

**Pitfalls:**
*   **Mean-only deformation:** Optimizing only the position causes significant striping artifacts [S1, unofficial].
*   **No splitting:** Disabling splitting causes spiking artifacts in bent regions because a single Gaussian cannot model the deformation [S1, unofficial].

import math
import numpy as np

def gsdeformer_deform(gs_scene, source_cage, target_cage, split_threshold):
    """
    Deforms a 3DGS scene using cage-based deformation.
    
    Args:
        gs_scene: List of Gaussian objects. Each has .mu (3,), .cov (3,3), .opacity (float), .sh (array).
        source_cage: Cage mesh for source space.
        target_cage: Cage mesh for target space.
        split_threshold: Angle threshold for splitting ellipsoids.
        
    Returns:
        deformed_gs_scene: List of deformed Gaussian objects.
    """
    deformed_gs_scene = []
    
    for gaussian in gs_scene:
        # 1. Convert Gaussian to points-represented ellipsoid
        ap_s = sample_ellipsoid_points(gaussian.mu, gaussian.cov)
        
        # 2. Deform points using cage-based deformation
        ap_mvc = euler_to_mvc(ap_s, source_cage)
        ap_d = mvc_to_euler(ap_mvc, target_cage)
        
        # 3. Perform splitting
        ap_ss = [ap_s]
        ap_ds = [ap_d]
        ap_ss, ap_ds = split_function(gaussian, ap_ss, ap_ds, split_threshold)
        
        # 4. Transform Gaussians
        for si, di in zip(ap_ss, ap_ds):
            # Compute affine transform T from si to di
            T = compute_affine_transform(si, di)
            
            # Compute translation
            center_si = mean_point(si)
            center_di = mean_point(di)
            t_vec = center_di - center_si
            
            # Transform Gaussian
            new_mu = T @ gaussian.mu + t_vec
            new_cov = T @ gaussian.cov @ T.T
            
            # Create new Gaussian
            new_gaussian = Gaussian()
            new_gaussian.mu = new_mu
            new_gaussian.cov = new_cov
            new_gaussian.opacity = gaussian.opacity
            new_gaussian.sh = gaussian.sh 
            
            deformed_gs_scene.append(new_gaussian)
            
    return deformed_gs_scene

def split_function(gaussian, ap_ss, ap_ds, threshold):
    """
    Splits ellipsoids if the bending angle is too large.
    """
    new_ap_ss = []
    new_ap_ds = []
    
    for axis in ['x', 'y', 'z']:
        for si, di in zip(ap_ss, ap_ds):
            center_di = mean_point(di)
            l, r = get_axis_endpoints(di, gaussian.cov, axis)
            
            # Calculate angle alpha
            v1 = l - center_di
            v2 = r - center_di
            alpha = math.acos(np.clip(np.dot(v1, v2) / (np.linalg.norm(v1) * np.linalg.norm(v2) + 1e-8), -1.0, 1.0))
            
            if alpha < threshold:
                # Split into two
                # Left ellipsoid
                dl = copy_ellipsoid(di)
                dl.center = (center_di + l) / 2.0
                shift_points(dl.points, center_di, dl.center)
                dl.axis = dl.center - l
                
                # Right ellipsoid
                dr = copy_ellipsoid(di)
                dr.center = (center_di + r) / 2.0
                shift_points(dr.points, center_di, dr.center)
                dr.axis = dr.center - r
                
                # Corresponding source splits
                center_si = mean_point(si)
                sl = copy_ellipsoid(si)
                sl.center = (center_si + l) / 2.0
                shift_points(sl.points, center_si, sl.center)
                
                sr = copy_ellipsoid(si)
                sr.center = (center_si + r) / 2.0
                shift_points(sr.points, center_si, sr.center)
                
                new_ap_ss.extend([sl, sr])
                new_ap_ds.extend([dl, dr])
            else:
                new_ap_ss.append(si)
                new_ap_ds.append(di)
                
    return new_ap_ss, new_ap_ds

    return np.array(points)

def compute_affine_transform(source_points, target_points):
    """[G] Compute affine transform T such that T * source_points ≈ target_points."""
    # Least squares solution: T = target_points @ source_points^+
    source_mean = np.mean(source_points, axis=0)
    target_mean = np.mean(target_points, axis=0)
    centered_s = source_points - source_mean
    centered_t = target_points - target_mean
    H = centered_t.T @ centered_s
    U, S, Vt = np.linalg.svd(H)
    T_rot = Vt.T @ U.T
    if np.linalg.det(T_rot) < 0:
        Vt[-1, :] *= -1
        T_rot = Vt.T @ U.T
    T_trans = target_mean - T_rot @ source_mean
    T = np.eye(4)
    T[:3, :3] = T_rot
    T[:3, 3] = T_trans

def mean_point(points):
    return np.mean(points, axis=0)

def get_axis_endpoints(ellipsoid_points, cov, axis):
    """[G] Get endpoints of the principal axis."""
    eigenvalues, eigenvectors = np.linalg.eigh(cov)
    max_idx = np.argmax(eigenvalues)
    axis_vec = eigenvectors[:, max_idx]
    scale = np.sqrt(eigenvalues[max_idx])
    center = mean_point(ellipsoid_points)
    l = center - scale * axis_vec
    r = center + scale * axis_vec
    return l, r

    points += (new_center - old_center)

## Operating characteristics
*   **Time Complexity:** Real-time performance is achieved through extensive caching, where $AP_{mvc}$ and parts of the transform $T$ can be precomputed [S1, unofficial]. The splitting and transformation steps scale linearly with the number of Gaussians and split ellipsoids [G].
*   **Memory Complexity:** Requires storing the proxy point sets and split ellipsoids temporarily, but needs no additional training data or architectural changes [S1, unofficial].
*   **Strengths:** Handles large bending deformations accurately via splitting; works on existing trained vanilla 3DGS without retraining; real-time capable [S1, unofficial].
*   **Limitations:** Copies spherical harmonics without rotation adjustment, potentially causing color inaccuracies under rotation; point-based deformation is better suited for small deformations like facial expressions [S1, unofficial].
*   **When to use:** When deforming large, complex shapes with significant bending where mean-only optimization fails [S1, unofficial].
*   **When not to use:** For small, local deformations (e.g., facial expressions) where point-based methods might be more efficient, or when high-fidelity viewpoint-dependent color rotation is critical [S1, unofficial].

## Background
GSDeformer was introduced by the authors of the paper "GSDeformer: Direct Cage-based Deformation for 3D Gaussian Splatting" [S1, unofficial]. It adapts traditional cage-based deformation techniques to the specific data structure of 3DGS [S1, unofficial]. The method addresses limitations in prior works like ARAP-GS and VRGS, which only optimize existing Gaussians and fail to model bending accurately [S1, unofficial]. The cage-building process is inspired by the 3DGS marching cube method proposed in SuGaR [S1, unofficial].
