# HybridNeRF Model Architecture

Also called: HybridNeRF

## Overview
HybridNeRF is a neural radiance field architecture that combines dense multi-resolution 3D feature grids with multi-resolution triplanes to featurize 3D sample locations [S1]. It solves the problem of balancing rendering quality and computational efficiency in neural rendering by leveraging the geometric priors of 3D grids and the view-dependent flexibility of 2D triplanes [S1]. It sets itself apart from its siblings by summing features across resolution levels rather than concatenating them, and by using a spatially adaptive surfaceness field for density estimation [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D point $\mathbf{x}$ and a viewing direction $\mathbf{d}$.
*   **Outputs:** Color $\mathbf{c}$ and signed distance $f$ (from which density $\sigma$ is derived).

**Data Structures:**
1.  **3D Feature Grids:** Three resolution levels: $128^3$, $256^3$, and $512^3$.
2.  **Triplanes:** Seven resolution levels, ranging from $128^2$ to $8,192^2$.
3.  **Surfaceness Field:** A $512^3$ voxel grid storing $\beta(\mathbf{x})$.
4.  **MLPs:** Separate MLPs for color and signed distance prediction.

**Parameters:**
*   $K=4$: Number of features fetched per level [S1].
*   $\beta(\mathbf{x}) > 0$: Surfaceness parameter, implemented as a spatially adaptive $512^3$ voxel grid queried via nearest-neighbor interpolation [S1].

**Steps:**
1.  **Fetch 3D Features:** For the given 3D point $\mathbf{x}$, fetch $K=4$ features from each of the 3 resolution levels of the 3D feature grids using trilinear interpolation.
2.  **Fetch Triplane Features:** For the given 3D point $\mathbf{x}$, project it onto the 7 triplane levels (resolutions $128^2$ to $8,192^2$) and fetch $K=4$ features from each level using bilinear interpolation.
3.  **Sum Features:** Sum the fetched features across all levels for the 3D grids separately to get $\mathbf{f}_{3D}$. Sum the fetched features across all levels for the triplanes separately to get $\mathbf{f}_{tri}$.
4.  **Concatenate:** Concatenate $\mathbf{f}_{3D}$ and $\mathbf{f}_{tri}$ to form a 16-dimensional input vector ($4K=16$) for the MLPs [S1].
5.  **Encode Direction:** Encode the viewing direction $\mathbf{d}$ using spherical harmonics up to the 4th degree.
6.  **Predict Color and Distance:** Pass the concatenated features and the encoded direction into separate MLPs to predict color $\mathbf{c}$ and signed distance $f$.
7.  **Compute Density:** Compute density $\sigma_{\text{SDF}}(\mathbf{x})$ using the SDF formulation.
8.  **Aliasing Handling:** Handle aliasing as described in VR-NeRF due to the multi-resolution feature grid [S1].

**Formulas:**
The density is computed as [S1]:
$$
\sigma_{\text{SDF}}(\mathbf{x}) := \beta(\mathbf{x})\Psi(f(\mathbf{x})\beta(\mathbf{x}))
$$
where $\Psi$ is the CDF of a standard Laplace distribution:
$$
\Psi(s) = \begin{cases} \frac{1}{2} \exp(-s) & \text{if } s > 0 \\ 1 - \frac{1}{2} \exp(s) & \text{if } s \leq 0. \end{cases}
$$
Here, $s = f(\mathbf{x})\beta(\mathbf{x})$.

## Subtopics

### [Shading Replacement for Relighting](6346-shading-replacement-for-relighting.md)
Shading Replacement for Relighting is a technique for object insertion that avoids inferring scene illumination by replacing the inserted object's shading with shading from existing scene points. It solves the problem of lighting inconsistency when compositing objects into neural radiance field (NeRF) scenes, where naive composition leads to unrealistic results due to varying illumination. It sets itself apart from direct relighting methods by not requiring explicit light source estimation, instead relying on the correlation between surface normals and shading in Lambertian scenes.

### [Hybrid Multi-Space Module](11712-hybrid-multi-space-module.md)
The Hybrid Multi-Space Module extends grid-based NeRF methods (such as iNGP and TensoRF) to handle multiple sub-spaces (e.g., reflections and refractions) by decomposing the multi-space composition information into a small MLP branch, while the main branch models multiple radiance fields using explicit grids. Unlike pure feature-field approaches, this module integrates discrete learnable grids with small MLPs to output densities and colors for each sub-space, enabling efficient rendering of complex light paths in grid-based architectures. It builds on [HybridNeRF Model Architecture](4842-hybridnerf-model-architecture.md).

### [LidaRF Hybrid Representation](12893-lidarf-hybrid-representation.md)
LidaRF is a NeRF variant for street scenes that fuses explicit Lidar point cloud features with an implicit hash-based grid representation to improve geometry and rendering quality under sparse and collinear camera trajectories. It differs from prior Lidar-only NeRF approaches by avoiding low-resolution and incomplete rendering caused by sparse Lidar coverage and limited field of view; instead, it combines explicit Lidar geometry with a high-resolution implicit grid.

### [Pano-NeRF](15013-pano-nerf.md)
Pano-NeRF is a method for geometry recovery and High Dynamic Range (HDR) novel view synthesis from sparse Low Dynamic Range (LDR) panoramic images. It models the scene using irradiance fields, which treat radiance as both a signal conveying lighting information and a light source illuminating other pixels, thereby increasing observation counts for geometry and leveraging irradiance-radiance attenuation for HDR reconstruction. It differs from standard radiance field methods by integrating surface rendering principles into the volume rendering framework to explicitly model inter-reflection and lighting interactions.

### Geometry Composition by Segmented Sampling
Geometry Composition by Segmented Sampling transforms sampling points from scene coordinates to object coordinates using the inserting position (translation and rotation) [S2]. It composites density as the normalized sum of densities of corresponding points from scene and object at the same position, and composites reflectance as a weighted sum of reflectance values, where weights are the densities of the voxel particles [S2]. The final image is rendered following Eqn. 1 using composited density, reflectance, and shading [S2].

### HybridNeRF SDF Density Formulation
The density $\sigma_{\text{SDF}}(\mathbf{x})$ is computed as $\beta(\mathbf{x})\Psi(f(\mathbf{x})\beta(\mathbf{x}))$, where $f(\mathbf{x})$ is the signed distance field output, $\beta(\mathbf{x})$ is the surfaceness parameter, and $\Psi$ is the CDF of a standard Laplace distribution [S1]. The Laplace CDF $\Psi(s)$ is defined piecewise: $\frac{1}{2} \exp(-s)$ if $s > 0$, and $1 - \frac{1}{2} \exp(s)$ if $s \leq 0$. Here $s = f(\mathbf{x})\beta(\mathbf{x})$ [S1]. The surfaceness field $\beta(\mathbf{x})$ is stored in a $512^3$ voxel grid and queried using nearest-neighbor interpolation [S1].

### SeaThru-NeRF
SeaThru-NeRF extends NeRFs to handle underwater scattering media by treating the medium as a semi-transparent entity with separate color and density parameters from opaque objects [S3]. It replaces the traditional single opaque object density $\sigma(t)$ with the sum of the object density $\sigma_{\text{obj}}(t)$ and the medium density $\sigma_{\text{med}}(t)$ [S3].

### Neural Proxy Rendering with Mixed Samplers
Neural Proxy Rendering with Mixed Samplers is a rendering pipeline that mixes a neural proxy sampler $S_p$ for animated objects and a neural scene sampler $S_c$ for static elements, using a neural texture for local surface appearance [S4, unofficial]. It separates the particle set $X$ into proxy set $X_p$ and scene set $X_c$ [S4, unofficial]. For each ray $r$, it finds the convex set $X_r$ bounded by the closest and farthest intersection points with the proxy mesh $M$ [S4, unofficial]. It uses the triangle intersection method $f_\delta$ from [MT97] to get $(\hat{t}, u_\delta, v_\delta) = f_\delta(r, \delta)$ [S4, unofficial]. Unlike NeRF which uses global scene information, neural proxy uses local information (features from neural texture) sampled via Barycentric coordinates [S4, unofficial].

*   **Strengths:** Combines 3D grids and triplanes for efficient featurization; uses spatially adaptive surfaceness for better geometry; handles aliasing via VR-NeRF techniques [S1].
*   **Limitations:** Negatively impacts quality near fine objects (lamp wires) and transparent structures (glass door) [S1].
*   **When to use:** When high-quality neural rendering is needed with efficient memory usage and good geometric priors [S1].
*   **When not to use:** When fine details or transparent structures are critical and the multi-resolution grid causes aliasing artifacts [S1].

## Background
HybridNeRF was introduced in the paper "HybridNeRF: Efficient Neural Rendering via Adaptive Volumetric Surfaces" [S1]. It builds on previous work in neural radiance fields and multi-resolution feature grids. The method uses a proposal network similar to Nerfacto to improve sampling efficiency [S1].
