# Instant-NGP

Also called: Instant Neural Graphics Primitives with a Multiresolution Hash Encoding

## Overview
Instant-NGP is a method for real-time training and rendering of Neural Radiance Fields (NeRFs) that achieves speedups of three orders of magnitude over vanilla NeRF by replacing positional encoding with a multi-resolution hash encoding [S1][S2, unofficial][S4]. It solves the bottleneck of slow neural network queries and inefficient sampling by offloading representational burden to hash-table lookups, using an occupancy grid to skip empty space, and employing a fully-fused small MLP [S4]. Unlike its siblings, it prioritizes training throughput (seconds) and interactive rendering (milliseconds) over the high-quality, slow optimization of original NeRF [S2, unofficial][S3].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D spatial coordinates $\mathbf{x}$, viewing direction $\mathbf{d}$, and camera parameters.
*   **Output:** Volume density $\sigma$ and view-dependent color $\mathbf{c}$.

**Data Structures:**
1.  **Multi-resolution Hash Grids:** A set of $L$ hash tables. Each table $l \in \{0, \dots, L-1\}$ contains $T$ entries. Each entry is a trainable feature vector of dimension $F$ [S2, unofficial][S4].
2.  **Occupancy Grids:** A set of multiscale voxel grids (coarse to fine) storing a single bit per voxel indicating occupancy (empty vs. non-empty) [S4]. These are updated during training based on density predictions [S4].

**Parameters:**
*   $L$: Number of resolution levels [S4].
*   $T$: Number of feature vectors (hash table size) per level [S4].
*   $F$: Dimensionality of feature vectors [S4].
*   Typical values: Training time 5–30 seconds; Rendering time tens of milliseconds at 1920×1080 [S2, unofficial][S3].

**Algorithm Steps:**

1.  **Occupancy Culling:**
    For a ray segment, check the occupancy grids. If the occupancy bit is low (empty), skip sampling in that region. If the accumulated transmittance is low (behind high density), skip sampling [S4]. This increases sampling speed by 10-100x [S4].

2.  **Hash Encoding Query:**
    For each sampled 3D point $\mathbf{x}$:
    a.  **Voxel Identification:** For each resolution level $l$, identify the enclosing voxel in the grid at that resolution [S1][S4].
    b.  **Vertex Hashing:** Map the 8 vertices of the enclosing voxel to hash indices. The hash function uses the input hash table size $(l, b)$ and scaling factors $(1/N_a, 1/N_b)$ [S1].
    c.  **Feature Lookup:** Retrieve the $F$-dimensional feature vectors from the hash table using the computed indices [S1][S4].
    d.  **Trilinear Interpolation:** Interpolate the 8 retrieved feature vectors based on the continuous position of $\mathbf{x}$ within the voxel to obtain the interpolated feature vector $\mathbf{f}_l$ for level $l$ [S1][S4].
    e.  **Concatenation:** Concatenate the interpolated features $\mathbf{f}_l$ from all $L$ levels [S1][S4].
    f.  **Direction Encoding:** Encode the viewing direction $\mathbf{d}$ using spherical harmonics [S4].
    g.  **Joint Vector:** Concatenate the hashed spatial features and the encoded direction into a joint feature vector [S1][S4].

3.  **Neural Network Prediction:**
    Feed the joint feature vector into a small, fully-fused MLP (typically 4 layers with 64 neurons each, or 1-2 layers for the final regression head depending on implementation specifics cited) to predict density $\sigma$ and color $\mathbf{c}$ [S1][S4].

**Pseudocode:**

```python
def query_instant_ngp(x, d, hash_grids, occupancy_grids, L, T, F):
    """
    Query the Instant-NGP encoding and MLP for density and color.
    
    Args:
        x: 3D coordinate (float3)
        d: Viewing direction (float3)
        hash_grids: List of L hash tables, each of size T x F
        occupancy_grids: List of L occupancy grids (bitmasks)
        L: Number of resolution levels
        T: Hash table size
        F: Feature dimension
        
    Returns:
        sigma: Volume density (float)
        color: RGB color (float3)
    """
    
    # 1. Occupancy Culling (Simplified for single point query)
    # In practice, this is done during ray marching to skip segments.
    # For a single point query, we assume the point is valid.
    
    # 2. Hash Encoding
    concatenated_features = []
    
    for l in range(L):
        # a. Identify enclosing voxel at level l
        # Resolution scales with l. Let voxel_size_l be the side length.
        voxel_size_l = get_voxel_size(l, L) 
        voxel_coords = floor(x / voxel_size_l)
        
        # b. Get 8 vertices of the voxel
        vertices = get_voxel_vertices(voxel_coords, voxel_size_l)
        
        # c. Hash vertices and lookup features
        # Hash function: h(v) = hash(v) % T
        # Note: Hash collisions are not explicitly handled; gradients dominate optimization [S4]
        feature_vectors = []
        for v in vertices:
            index = hash_function(v, T)
            feature_vectors.append(hash_grids[l][index])
            
        # d. Trilinear interpolation
        # Compute local coordinates within the voxel
        local_coords = (x - voxel_coords * voxel_size_l) / voxel_size_l
        interpolated_feature = trilinear_interpolate(feature_vectors, local_coords)
        
        concatenated_features.append(interpolated_feature)
        
    # e. Concatenate features from all levels
    spatial_features = concatenate(concatenated_features)
    
    # f. Encode viewing direction using spherical harmonics
    direction_features = encode_spherical_harmonics(d)
    
    # g. Joint feature vector
    joint_vector = concatenate([spatial_features, direction_features])
    
    # 3. MLP Prediction
    # Fully-fused MLP: 4 layers, 64 neurons each [S4]
    # Or shallow MLP (1-2 layers) for final regression [S1]
    # Implementation depends on specific framework (e.g., tinycudann)
    sigma, color = mlp_forward(joint_vector)
    
    return sigma, color

def hash_function(vertex, T):
    # Standard hash function modulo table size
    # Exact hash function details not specified in sources [S1]
    return hash(vertex) % T

def trilinear_interpolate(features, local_coords):
    # features: list of 8 vectors (F-dim)
    # local_coords: (x, y, z) in [0, 1]
    # Perform trilinear interpolation
    x, y, z = local_coords
    # Interpolate along x
    f000 = features[0]
    f100 = features[1]
    f010 = features[2]
    f110 = features[3]
    f001 = features[4]
    f101 = features[5]
    f011 = features[6]
    f111 = features[7]
    
    # Interpolate along x
    f00 = lerp(f000, f100, x)
    f01 = lerp(f010, f110, x)
    f10 = lerp(f001, f101, x)
    f11 = lerp(f011, f111, x)
    
    # Interpolate along y
    f0 = lerp(f00, f01, y)
    f1 = lerp(f10, f11, y)
    
    # Interpolate along z
    result = lerp(f0, f1, z)
    return result

def lerp(a, b, t):
    return a + t * (b - a)
```

**Edge Cases and Pitfalls:**
*   **Hash Collisions:** Not explicitly handled. Multiple vertices may map to the same hash index. The trainable nature of the features allows the most important vertices to dominate optimization via gradients [S4].
*   **Precision:** Trilinear interpolation requires precise local coordinate calculation [S1].
*   **Boundaries:** The method assumes a bounded spatial domain for the hash grids [S1].

## Operating characteristics
*   **Time Complexity:** Training time is reduced to seconds (5–30s for typical scenes) [S2, unofficial][S3]. Rendering time is tens of milliseconds at 1920×1080 [S3].
*   **Memory Complexity:** Determined by $L \times T \times F$. Trade-off between quality, memory, and performance [S4].
*   **Performance:** 1000x speedup over vanilla NeRF [S4]. Occupancy grid sampling increases speed by 10-100x [S4]. Fully-fused MLP is 5-10x faster than TensorFlow implementations [S4].
*   **Strengths:** Real-time training and rendering; efficient memory usage via hash encoding; robust to sparse input via regularization principles inherited from parent methods [S1][S4].
*   **Limitations:** Quality may be lower than high-quality NeRF variants; hash collisions can cause artifacts if $T$ is too small [S4].
*   **When to use:** Real-time applications, interactive editing, rapid prototyping.
*   **When not to use:** High-fidelity offline rendering where training time is not a constraint.

## Background
Instant-NGP was introduced by Müller et al. in 2022 [S2, unofficial]. It builds on the principles of hash-grid anti-aliasing and regularization [Parent]. The method breaks NeRF training into three pillars: improved ray marching with occupancy grids, a fully-fused small MLP, and multi-resolution hash encoding [S4]. It was the first practical NeRF for production, enabling real-time training and rendering [S2, unofficial].
