# NeRFCodec


## Overview
NeRFCodec is an end-to-end compression framework for plane-based hybrid Neural Radiance Fields (NeRF) that integrates non-linear transform, quantization, and entropy coding to achieve memory-efficient scene representation [S1]. It solves the high storage footprint of hybrid NeRF representations by compressing feature planes using a pre-trained 2D neural image codec backbone, adapted with content-specific parameters [S1]. Unlike raw parameter counting or generic image codecs, NeRFCodec exploits inter-channel information in feature planes through a specialized encoder-decoder adaptation, achieving superior rate-distortion performance compared to methods like Masked Wavelet NeRF and VQ-TensoRF [S1]. It enables high-quality novel view synthesis within a strict memory budget of approximately 0.5 MB per scene [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A pre-trained hybrid NeRF model (specifically plane-based variants like TensoRF-VM or HexPlane) for a specific scene, consisting of orthogonal feature planes and a small attribute regression MLP [S1].
*   **Output:** A compressed bitstream containing quantized latent codes, quantized hyperprior latent codes, content-specific decoder head parameters, feature residual vectors, tiny MLP parameters, and metadata [S1].

**Data Structures:**
The framework modifies a pre-trained 2D neural image codec (backbone: Cheng et al., implementation: CompressAI) [S1].
*   **Encoder Head ($E_{\phi1}$):** The first layer of the 2D codec, modified to accept the channel dimension of the NeRF feature planes [S1].
*   **Frozen Decoder Body:** The intermediate layers of the pre-trained 2D decoder remain frozen [S1].
*   **Decoder Head ($D_{\phi2}$):** The last layer of the 2D codec, modified to output the target channel dimension [S1]. This head contains content-specific learnable parameters [S1].
*   **Feature Planes ($x$):** Orthogonal feature planes extracted from the pre-trained hybrid NeRF [S1].
*   **Tiny MLP ($f$):** The small MLP used for attribute regression (color/density) in the renderer [S1].
*   **Bitstream Components:**
    1.  Quantized latent code $\hat{y}$ [S1].
    2.  Quantized hyperprior latent code $\hat{z}$ [S1].
    3.  Feature decoder head parameters $D_{\phi2}$ [S1].
    4.  Feature residual vectors $v_{\Delta x}$ [S1].
    5.  Tiny MLP parameters $f$ [S1].
    6.  Metadata [S1].

**Training Procedure:**
The training occurs in four phases [S1]:
1.  **Pre-training:** Pre-train the hybrid NeRF on the target scene for 100,000 iterations to obtain feature planes $x$ and tiny MLP $f$ [S1].
2.  **Warm-up:** Perform a warm-up of the neural feature codec using only the feature plane reconstruction loss to establish a better starting point [S1].
3.  **Joint Training:** Jointly train the neural feature codec and the neural radiance field for 100,000 iterations [S1]. The loss function $L_{total}$ combines rendering loss and entropy loss [S1]. During this phase, the full encoder and the decoder head are adapted to fit the specific scene, while the remaining parts of the decoder are frozen [S1].
4.  **Quantization-Aware Training (QAT):** Perform QAT on the network parameters to be transmitted (decoder head and MLP in renderer) for 10,000 iterations [S1].

**Pseudocode:**

```python
def train_nerf_codec(scene_data, pre_trained_neurf, pre_trained_2d_codec):
    # 1. Pre-train Hybrid NeRF for 100,000 iterations
    nerf_model = pre_trained_neurf
    optimizer_neurf = Optimizer(nerf_model.parameters())
    for _ in range(100000):
        rays, gt_images = scene_data.sample_batch()
        rendered_images = volume_render(nerf_model, rays)
        loss = mse_loss(rendered_images, gt_images)
        loss.backward()
        optimizer_neurf.step()

    feature_planes = nerf_model.get_feature_planes()
    tiny_mlp = nerf_model.get_mlp()

    # 2. Initialize Neural Feature Codec
    codec = pre_trained_2d_codec
    # Replace encoder and decoder heads to match feature plane channels
    codec.encoder_head = replace_head(codec.encoder_head, target_channels=feature_planes.shape[1])
    codec.decoder_head = replace_head(codec.decoder_head, target_channels=feature_planes.shape[1])
    # Freeze intermediate decoder layers
    for param in codec.decoder_body.parameters():
        param.requires_grad = False

    # 3. Warm-up Phase (iteration count not specified in sources)
    optimizer_codec = Optimizer(codec.parameters())
    warmup_iters = 1000  # [G]
    for _ in range(warmup_iters):
        latent = codec.encode(feature_planes)
        reconstructed_planes = codec.decode(latent)
        rec_loss = mse_loss(reconstructed_planes, feature_planes)
        rec_loss.backward()
        optimizer_codec.step()

    # 4. Joint Training Phase (100,000 iterations)
    optimizer_joint = Optimizer(list(codec.parameters()) + list(tiny_mlp.parameters()))
    for _ in range(100000):
        rays, gt_images = scene_data.sample_batch()
        latent = codec.encode(feature_planes)
        reconstructed_planes = codec.decode(latent)
        rendered_images = volume_render(reconstructed_planes, tiny_mlp, rays)
        rendering_loss = mse_loss(rendered_images, gt_images)
        entropy_loss = compute_entropy_loss(latent, codec.probability_model)
        L_total = rendering_loss + entropy_loss
        L_total.backward()
        optimizer_joint.step()

    # 5. Quantization-Aware Training Phase (10,000 iterations)
    optimizer_qat = Optimizer(list(codec.decoder_head.parameters()) + list(tiny_mlp.parameters()))
    for _ in range(10000):
        rays, gt_images = scene_data.sample_batch()
        latent = codec.encode(feature_planes)
        reconstructed_planes = codec.decode(latent)
        rendered_images = volume_render(reconstructed_planes, tiny_mlp, rays)
        rendering_loss = mse_loss(rendered_images, gt_images)
        entropy_loss = compute_entropy_loss(latent, codec.probability_model)
        L_total = rendering_loss + entropy_loss
        L_total.backward()
        optimizer_qat.step()

    return codec, tiny_mlp

def encode_scene(codec, tiny_mlp, feature_planes):
    bitstreams = []
    # Orthogonal feature planes are fed into the codec one by one
    for plane in feature_planes:
        latent = codec.encode(plane)
        quantized_latent = quantize(latent)
        bitstreams.append(entropy_encode(quantized_latent))
        hyperprior = codec.get_hyperprior(latent)
        quantized_hyperprior = quantize(hyperprior)
        bitstreams.append(entropy_encode(quantized_hyperprior))

    # Compress content-specific parameters
    bitstreams.append(entropy_encode(quantize(codec.decoder_head.parameters())))
    bitstreams.append(entropy_encode(quantize(tiny_mlp.parameters())))
    # Feature residual vectors are also compressed and transmitted
    bitstreams.append(entropy_encode(quantize(feature_planes)))

    return multiplex(bitstreams)

def decode_scene(codec, tiny_mlp, total_bitstream, query_points):
    substreams = demultiplex(total_bitstream)
    idx = 0
    reconstructed_feature_planes = []
    for _ in range(len(feature_planes)):
        quantized_latent = entropy_decode(substreams[idx])
        idx += 1
        quantized_hyperprior = entropy_decode(substreams[idx])
        idx += 1
        codec.decoder_head.set_parameters(entropy_decode(substreams[idx]))
        idx += 1
        reconstructed_plane = codec.decode(quantized_latent)
        reconstructed_feature_planes.append(reconstructed_plane)

    quantized_mlp = entropy_decode(substreams[idx])
    tiny_mlp.set_parameters(quantized_mlp)
    idx += 1

    rendered_image = volume_render(reconstructed_feature_planes, tiny_mlp, query_points)
    return rendered_image

# Helper definitions
def replace_head(layer, target_channels):
    return LinearLayer(layer.in_features, target_channels)

def quantize(tensor):
    return round_to_integers(tensor)

def entropy_encode(tensor):
    return arithmetic_coding_encode(tensor)

def entropy_decode(bitstream):
    return arithmetic_coding_decode(bitstream)

def multiplex(streams):
    return bytes_concat(streams)

def demultiplex(total_stream):
    return bytes_split(total_stream)

def volume_render(feature_planes, mlp, rays):
    return alpha_compositing(feature_planes, mlp, rays)

def mse_loss(pred, target):
    return mean_squared_error(pred, target)

def compute_entropy_loss(latent, prob_model):
    return negative_log_likelihood(latent, prob_model)
```

**Parameters:**
*   **Memory Budget:** 0.5 MB per scene [S1].
*   **Joint Training Iterations:** 100,000 [S1].
*   **Quantization-Aware Training Iterations:** 10,000 [S1].
*   **Pre-training Iterations:** 100,000 [S1].
*   **Implementation Base:** CompressAI library [S1].
*   **Backbone:** Neural image codec proposed by Cheng et al. [S1].

**Edge Cases and Pitfalls:**
*   **Architecture Modification:** Using a pre-trained 2D neural image codec without modifying the encoder/decoder heads (e.g., splitting planes into three channels and normalizing) results in significantly higher bitrate consumption because it fails to fully exploit inter-channel information [S1].
*   **Generalization:** A neural feature codec trained on a small-scale feature dataset (e.g., 8 scenes from NeRF-Synthetic) fails to generalize to unseen objects from other datasets (e.g., NSVF-Synthetic) without test-time optimization, producing unreasonable rendering results [S1].
*   **Training Time:** Training the non-linear transform is time-consuming [S1].
*   **Scene Specificity:** A specialized neural feature codec must be trained for each scene individually [S1].
*   **Feature Reconstruction Loss:** Adding a feature plane reconstruction loss during joint training degrades performance (PSNR 32.81 dB vs 35.08 dB) compared to relying solely on rendering loss [S1].

## Subtopics

### [NeRFCodec Decoder Payload Estimation](17943-nerfcodec-decoder-payload-estimation.md)
This method estimates the compressed bitrate budget for the decoder-side parameters of the NeRFCodec framework, which must be transmitted alongside encoded Neural Radiance Fields. It differs from raw parameter counting by applying per-tensor quantization and entropy estimation to approximate the actual payload size in a streaming application. It serves as a proxy for memory footprint when NeRFCodec is used as a 3D representation for content delivery.

## Operating characteristics
**Time and Memory Complexity:**
*   **Memory:** NeRFCodec achieves a total compressed size of 0.453 MB for the TensoRF-VM variant, compared to an original size of 72.342 MB (compression ratio x159.7) [S1].
    *   Compressed Feature planes: 0.052 MB (Original 69.953 MB, Ratio x1345.3) [S1].
    *   Compressed Decoder head: 0.269 MB (Original 1.761 MB, Ratio x6.5) [S1].
    *   Compressed MLP in renderer: 0.042 MB (Original 0.160 MB, Ratio x3.8) [S1].
    *   Feature vectors: 0.049 MB (Original 0.234 MB, Ratio x4.8) [S1].
    *   Residual vectors: 0.041 MB (Original 0.234 MB, Ratio x5.7) [S1].
*   **Compression Ratio:** The non-linear transform allows for a compression ratio over 1000 times for feature planes [S1].

**Measured Performance:**
*   **NeRF-Synthetic Dataset:**
    *   36.60 dB PSNR at 0.91 MB [S1].
    *   36.21 dB PSNR at 0.46 MB [S1].
*   **Ablation (Chair Scene, NeRF-Synthetic):**
    *   Auto-encoder Size: 0.453 MB, PSNR: 35.08 dB, SSIM: 0.981 [S1].
    *   Auto-decoder Size: 0.461 MB, PSNR: 34.41 dB, SSIM: 0.973 [S1].
    *   Without Entropy Loss: Size 0.701 MB, PSNR 34.98 dB, SSIM 0.980 [S1].
    *   With Feature Reconstruction Loss: Size 0.479 MB, PSNR 32.81 dB, SSIM 0.965 [S1].
    *   Re-using unmodified Image Codec: Size 1.786 MB, PSNR 29.96 dB, SSIM 0.923 [S1].
    *   Re-using Tuned Image Codec: Size 1.150 MB, PSNR 33.25 dB, SSIM 0.961 [S1].

**Strengths and Limitations:**
*   **Strengths:** Superior rate-distortion performance compared to Masked Wavelet NeRF, Binary Radiance Fields, and VQ-TensoRF across three datasets (NeRF-Synthetic, NSVF-Synthetic, Tanks and Temples) [S1]. The use of a non-linear transform instead of a wavelet transform improves upon Masked Wavelet NeRF [S1]. Compatible with different plane-based NeRF approaches (validated on TensoRF-VM and HexPlane) [S1].
*   **Limitations:** Training the non-linear transform is time-consuming [S1]. Requires training a specialized neural feature codec for each scene individually [S1]. Does not generalize well to unseen objects without test-time optimization if trained on limited data [S1].

**When to Use:**
*   Use when high-quality novel view synthesis is required with a strict memory budget (e.g., < 0.5 MB per scene) [S1].
*   Use when compressing plane-based hybrid NeRF representations [S1].

**When Not to Use:**
*   Do not use if real-time training of a generalized codec for unseen objects is required without per-scene adaptation [S1].
*   Do not use if computational resources for the time-consuming non-linear transform training are limited [S1].

## Background
NeRFCodec was proposed by researchers from Zhejiang University, published in CVPR 2024 [S1]. It addresses the significant storage requirements of hybrid NeRF representations, which combine feature grids and small MLPs for high reconstruction quality and fast training [S1]. The method leverages advances in neural compression and neural field representation, specifically reusing pre-trained neural 2D image codecs (such as the one by Cheng et al.) by adapting their encoder and decoder heads to the specific channel dimensions of NeRF feature planes [S1]. It was validated on the NeRF-Synthetic, NSVF-Synthetic, and Tanks and Temples datasets [S1].
