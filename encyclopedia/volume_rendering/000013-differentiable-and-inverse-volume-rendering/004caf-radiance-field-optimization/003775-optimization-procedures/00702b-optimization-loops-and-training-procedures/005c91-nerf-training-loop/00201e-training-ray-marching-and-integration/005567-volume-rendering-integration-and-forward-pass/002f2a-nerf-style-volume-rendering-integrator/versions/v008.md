# NeRF-style Volume Rendering Integrator

Also called: NeRF forward raymarching, NeRFIntegrator

## Overview
This method computes the expected color $\hat{C}(r)$ for a ray $r$ by discretizing the medium interaction interval into fixed steps and accumulating emission weighted by transmittance [S1, unofficial]. It differs from its sibling [NeRF Rendering (Alpha Compositing)](5124-nerf-rendering-alpha-compositing.md) by using a dense grid-based density representation with no direction-dependent emission, and by employing a fixed-step marching loop with optional jittering rather than adaptive sampling or neural network queries [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Ray $r$ (origin, direction), scene geometry (for exit intersection), density grid (scalar field $\sigma$), emission field (vector field $c$), parameters: `queries_per_ray`, `density_noise_std`, `jittering_enabled`, `activation`, `hide_emitters` [S1, unofficial].
*   **Output:** Rendered color $\hat{C}(r)$ and accumulated weights [S1, unofficial].

**Data Structures:**
*   **Density Grid:** Dense 3D grid of scalar values $\sigma$ [S1, unofficial].
*   **Emission Field:** Dense 3D grid of RGB values $c$ [S1, unofficial].
*   **State Variables:** `result` (color accumulator), `throughput` (transmittance $T$), `weights_sum` (accumulated opacity weight), `step_j` (current step index), `t_a` (previous sample position), `t_b` (current sample position) [S1, unofficial].

**Parameters:**
*   `queries_per_ray`: Number of steps for ray marching. Default: 128 [S1, unofficial].
*   `density_noise_std`: Standard deviation for noise added to density. Default: 0 [S1, unofficial].
*   `jittering_enabled`: Boolean flag enabling jittering for step positions. Default: True [S1, unofficial].
*   `activation`: Activation function type for density ('identity', 'relu'). Default: 'identity' [S1, unofficial].
*   `hide_emitters`: Boolean flag to hide background emitters if `weights_sum` is zero. Default: Not given in the sources.

**Steps:**
1.  **Initialization:** Initialize `result` = 0, `throughput` = 1, `weights_sum` = 0, `step_j` = 0, `t_a` = 0 [S1, unofficial].
2.  **Exit Intersection:** Intersect ray with scene geometry to find medium exit distance $t_{exit}$ [S1, unofficial].
3.  **Step Size Calculation:** Calculate `step_size` = $t_{exit} / \text{queries\_per\_ray}$ [S1, unofficial]. Sample `jitter_sample` from a uniform sampler if `jittering_enabled` [S1, unofficial].
4.  **Marching Loop:** While `step_j < queries_per_ray`:
    a.  Calculate `t_b` = `t_a` + `step_size` $\times$ $(1.0 + \text{jitter\_sample})$ [S1, unofficial]. Calculate `actual_step` = `t_b` - `t_a` [S1, unofficial].
    b.  Query density $\sigma$ and emission $c$ at $t_b$ along the ray [G].
    c.  Apply `activation` to $\sigma$ if specified [S1, unofficial].
    d.  Add Gaussian noise with standard deviation `density_noise_std` to $\sigma$ if enabled [S1, unofficial].
    e.  Calculate `alpha_recip`: if `step_j + 1 < queries_per_ray`, `alpha_recip` = $\exp(-\sigma \cdot \text{actual\_step})$; else `alpha_recip` = 1.0 [S1, unofficial].
    f.  **Numerical Stability:** Add $\epsilon = 10^{-10}$ to `alpha_recip` to prevent NaNs during gradient computation [S1, unofficial].
    g.  Calculate `weight` = $(1.0 - \text{alpha\_recip}) \cdot \text{throughput}$ [S1, unofficial].
    h.  **Accumulate Color:** `result` += `weight` $\times$ `emission` [S1, unofficial].
    i.  Increment `step_j`. Update `t_a` = `t_b` [S1, unofficial].
    j.  **Update Throughput:** `throughput` *= `alpha_recip` [S1, unofficial].
    k.  **Update Weights Sum:** `weights_sum` += `weight` [S1, unofficial].
5.  **Background Contribution:** Calculate `contribution` = $(1 - \text{weights\_sum}) \cdot c_{bg}$ [S1, unofficial]. Add to `result` for active pixels. If `hide_emitters` is true and `weights_sum` is zero, do not add background emission [S1, unofficial].

```python
import math
import random

def query_density(ray_origin, ray_direction, t):
    """Standard 3D grid trilinear lookup [G]."""
    return 0.0  # Placeholder for actual grid query

def query_emission(ray_origin, ray_direction, t):
    """Standard 3D grid trilinear lookup [G]."""
    return (1.0, 1.0, 1.0)  # Placeholder for actual grid query

def nerf_integrator(ray_origin, ray_direction, t_exit, queries_per_ray, density_noise_std, jittering_enabled, activation, hide_emitters):
    # Initialization
    result = 0.0
    throughput = 1.0
    weights_sum = 0.0
    step_j = 0
    t_a = 0.0

    # Step size calculation
    step_size = t_exit / queries_per_ray
    jitter_sample = random.uniform(0, 1) if jittering_enabled else 0.0

    while step_j < queries_per_ray:
        # Calculate current sample position
        t_b = t_a + step_size * (1.0 + jitter_sample)
        actual_step = t_b - t_a

        # Query density and emission at t_b along ray
        sigma = query_density(ray_origin, ray_direction, t_b)
        c = query_emission(ray_origin, ray_direction, t_b)

        # Apply activation
        if activation == 'relu':
            sigma = max(0.0, sigma)

        # Add density noise
        if density_noise_std > 0:
            sigma += random.gauss(0, density_noise_std)

        # Calculate alpha_recip (transmittance factor for this step)
        if step_j + 1 < queries_per_ray:
            alpha_recip = math.exp(-sigma * actual_step)
        else:
            alpha_recip = 1.0

        # Numerical stability
        alpha_recip += 1e-10

        # Calculate weight
        weight = (1.0 - alpha_recip) * throughput

        # Accumulate color (primal mode)
        result += weight * c

        # Update throughput and weights_sum
        throughput *= alpha_recip
        weights_sum += weight

        # Update step variables
        step_j += 1
        t_a = t_b

    # Background contribution
    c_bg = (1.0, 1.0, 1.0)
    if not hide_emitters or weights_sum > 0:
        result += (1.0 - weights_sum) * c_bg

    return result
```

**Edge Cases and Pitfalls:**
*   **Precision:** Adding $\epsilon = 10^{-10}$ to `alpha_recip` is critical to prevent NaNs during gradient computation [S1, unofficial].
*   **Boundaries:** Rays missing the scene return 0. Rays hitting the exit are processed up to `queries_per_ray` steps [S1, unofficial].
*   **Degenerate Input:** If `queries_per_ray` is 0, the loop does not execute and only background is returned [G]. If `density_noise_std` is large, noise may dominate the signal [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ per ray, where $N$ is `queries_per_ray` [G]. Total time is $O(N \cdot R)$, where $R$ is the number of rays [G].
*   **Memory Complexity:** $O(V)$ for the density and emission grids, where $V$ is the volume of the grid [G].
*   **Measured Performance:** Not given in the sources [S1, unofficial].
*   **Scaling:** Linear with respect to `queries_per_ray` and number of rays [G].
*   **Strengths:** Simple implementation, deterministic (with fixed jitter), easy to differentiate [G].
*   **Limitations:** Fixed step size may lead to aliasing or inefficiency in sparse regions. No direction-dependent emission [S1, unofficial].
*   **When to Use:** When a dense grid representation is sufficient and direction-dependent effects are not required [G].
*   **When Not to Use:** When adaptive sampling is needed for efficiency or accuracy, or when direction-dependent emission is required [G].

## Background
*   **Origin:** The method is a simplified NeRF-style integrator that accumulates emission along a ray through a medium, backed by a dense grid instead of a neural network, with no direction-dependent emission [S1, unofficial].
*   **History:** The implementation originates from the `unbiased-inverse-volume-rendering` repository [S1, unofficial].
*   **Usage:** The surrounding codebase provides finite-difference gradient computation and loss functions for differentiable optimization tasks [S1, unofficial].
