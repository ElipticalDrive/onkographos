# HybridNeRF Model Architecture

Also called: HybridNeRF

## Overview
HybridNeRF is a neural radiance field architecture that combines dense multi-resolution 3D feature grids with multi-resolution triplanes to featurize 3D sample locations [S1]. It solves the problem of balancing geometric detail and rendering efficiency by using 3D grids for volumetric density and triplanes for color/reflectance, avoiding the high memory cost of pure 3D grids at high resolutions [S1]. It sets itself apart from its siblings by summing features across resolution levels rather than concatenating them, and by using a spatially adaptive surfaceness field for SDF-based density estimation [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D point coordinates $\mathbf{x}$, viewing direction $\mathbf{d}$.
*   **Outputs:** Density $\sigma(\mathbf{x})$, color $\mathbf{c}(\mathbf{x}, \mathbf{d})$, and optionally signed distance $f(\mathbf{x})$.

**Data Structures:**
1.  **3D Feature Grids:** Three resolution levels: $128^3$, $256^3$, and $512^3$. Each cell stores a feature vector.
2.  **Triplanes:** Seven resolution levels, ranging from $128^2$ to $8,192^2$. Each plane stores a feature vector.
3.  **Surfaceness Field:** A $512^3$ voxel grid storing scalar values $\beta(\mathbf{x})$.
4.  **MLPs:** Two small MLPs (one for density/SDF, one for color).

**Parameters:**
*   $K=4$: Number of features fetched per level from both 3D grids and triplanes [S1].
*   Spherical Harmonics: Degree 4 for viewing direction encoding [S1].
*   $\beta(\mathbf{x})$: Surfaceness parameter, initialized globally uniform, later spatially adaptive via the $512^3$ grid [S1].

**Steps:**

1.  **Feature Fetching:**
    For a given 3D point $\mathbf{x}$:
    *   Fetch $K=4$ features from each of the 3 resolution levels of the 3D feature grids using trilinear interpolation.
    *   Fetch $K=4$ features from each of the 7 resolution levels of the triplanes using bilinear interpolation.

2.  **Feature Aggregation:**
    *   Sum the fetched features across the 3 resolution levels of the 3D grids to produce a single summed vector $\mathbf{v}_{3D}$.
    *   Sum the fetched features across the 7 resolution levels of the triplanes to produce a single summed vector $\mathbf{v}_{tri}$.
    *   Concatenate $\mathbf{v}_{3D}$ and $\mathbf{v}_{tri}$ to form the input vector $\mathbf{v}_{in}$ of dimension $4K + 4K = 16$ (assuming feature dimension per fetch is 4, or generally $2 \times K \times \text{feature\_dim}$). *Note: The source states "4K=16-dimensional MLP input", implying the feature dimension per fetch is 4, resulting in $4 \times 4 = 16$ from 3D and $4 \times 4 = 16$ from triplanes? Or does it mean the total input is 16? The text says "concatenate... to obtain a 4K=16-dimensional MLP input". If K=4, 4K=16. This implies the sum of features from 3D grids is concatenated with the sum from triplanes, and the resulting vector has 16 dimensions. This suggests the feature dimension per level is 2, or the "sum" reduces dimensionality? Let's stick to the explicit statement: the concatenated result is 16-dimensional.* [S1].

3.  **Density and SDF Prediction:**
    *   Pass $\mathbf{v}_{in}$ through the density/SDF MLP to obtain the signed distance $f(\mathbf{x})$.
    *   Query the surfaceness field $\beta(\mathbf{x})$ from the $512^3$ grid using nearest-neighbor interpolation.
    *   Compute density $\sigma_{\text{SDF}}(\mathbf{x})$ using the SDF formulation:
        $$ \sigma_{\text{SDF}}(\mathbf{x}) = \beta(\mathbf{x})\Psi(f(\mathbf{x})\beta(\mathbf{x})) $$
        where $\Psi(s)$ is the CDF of a standard Laplace distribution:
        $$ \Psi(s) = \begin{cases} \frac{1}{2} \exp(-s) & \text{if } s > 0 \\ 1 - \frac{1}{2} \exp(s) & \text{if } s \leq 0 \end{cases} $$
        Here $s = f(\mathbf{x})\beta(\mathbf{x})$ [S1].

4.  **Color Prediction:**
    *   Encode the viewing direction $\mathbf{d}$ using spherical harmonics up to the 4th degree.
    *   Concatenate the encoded direction with $\mathbf{v}_{in}$ (or pass $\mathbf{v}_{in}$ and $\mathbf{d}$ through the color MLP as per standard NeRF practice, though the source specifies SH as an "auxiliary input").
    *   Pass through the color MLP to obtain color $\mathbf{c}(\mathbf{x}, \mathbf{d})$ [S1].

5.  **Aliasing Handling:**
    *   Handle aliasing as described in VR-NeRF due to the multi-resolution feature grid [S1].

## Subtopics

### [Shading Replacement for Relighting](6346-shading-replacement-for-relighting.md)
Shading Replacement for Relighting is a technique for object insertion that avoids inferring scene illumination by replacing the inserted object's shading with shading from existing scene points. It solves the problem of lighting inconsistency when compositing objects into neural radiance field (NeRF) scenes, where naive composition leads to unrealistic results due to varying illumination. It sets itself apart from direct relighting methods by not requiring explicit light source estimation, instead relying on the correlation between surface normals and shading in Lambertian scenes. See [Shading Replacement for Relighting](6346-shading-replacement-for-relighting.md).

### [Hybrid Multi-Space Module](11712-hybrid-multi-space-module.md)
The Hybrid Multi-Space Module extends grid-based NeRF methods (such as iNGP and TensoRF) to handle multiple sub-spaces (e.g., reflections and refractions) by decomposing the multi-space composition information into a small MLP branch, while the main branch models multiple radiance fields using explicit grids. Unlike pure feature-field approaches, this module integrates discrete learnable grids with small MLPs to output densities and colors for each sub-space, enabling efficient rendering of complex light paths in grid-based architectures. It builds on [HybridNeRF Model Architecture](4842-hybridnerf-model-architecture.md). See [Hybrid Multi-Space Module](11712-hybrid-multi-space-module.md).

### [LidaRF Hybrid Representation](12893-lidarf-hybrid-representation.md)
LidaRF is a NeRF variant for street scenes that fuses explicit Lidar point cloud features with an implicit hash-based grid representation to improve geometry and rendering quality under sparse and collinear camera trajectories. It differs from prior Lidar-only NeRF approaches by avoiding low-resolution and incomplete rendering caused by sparse Lidar coverage and limited field of view; instead, it combines explicit Lidar geometry with a high-resolution implicit grid. See [LidaRF Hybrid Representation](12893-lidarf-hybrid-representation.md).

### [Pano-NeRF](15013-pano-nerf.md)
Pano-NeRF is a method for geometry recovery and High Dynamic Range (HDR) novel view synthesis from sparse Low Dynamic Range (LDR) panoramic images. It models the scene using irradiance fields, which treat radiance as both a signal conveying lighting information and a light source illuminating other pixels, thereby increasing observation counts for geometry and leveraging irradiance-radiance attenuation for HDR reconstruction. It differs from standard radiance field methods by integrating surface rendering principles into the volume rendering framework to explicitly model inter-reflection and lighting interactions. See [Pano-NeRF](15013-pano-nerf.md).

### [FastSR-NeRF](16574-fastsr-nerf.md)
FastSR-NeRF is a method that improves the rendering efficiency of Neural Radiance Fields (NeRF) on consumer-grade hardware by combining a lightweight NeRF model with a CNN-based super-resolution (SR) module. It solves the problem of high computational cost and long training times associated with high-resolution NeRF rendering by training the NeRF to produce low-resolution (LR) 3D-consistent features and upscaling them to high-resolution (HR) outputs. Unlike prior NeRF+SR methods that rely on complex training procedures, knowledge distillation, or high-resolution reference images, FastSR-NeRF requires no architectural changes to the NeRF backbone and uses a simple end-to-end training pipeline. See [FastSR-NeRF](16574-fastsr-nerf.md).

### [NeRFCodec](16590-nerfcodec.md)
NeRFCodec is an end-to-end compression framework for plane-based hybrid Neural Radiance Fields (NeRF) that integrates non-linear transform, quantization, and entropy coding to achieve memory-efficient scene representation. It solves the high storage requirements of hybrid representations by leveraging a pre-trained 2D neural image codec, adapted with content-specific parameters for each scene, to compress feature planes while maintaining high visual fidelity. Unlike methods that apply generic image codecs directly or use wavelet transforms, NeRFCodec modifies the encoder and decoder heads of the 2D codec to exploit inter-channel information in feature planes, achieving superior rate-distortion performance with a memory budget of approximately 0.5 MB per scene. See [NeRFCodec](16590-nerfcodec.md).

### [Ambiguity-Aware Depth Estimates](16981-ambiguity-aware-depth-estimates.md)
Ambiguity-Aware Depth Estimates is a technique for learning a multimodal distribution of depth estimates conditioned on a single input image, using an implicit generative model to capture inherent ambiguities in monocular depth estimation such as non-opaque surfaces and albedo-shading confusion. Unlike GANs which optimize for similarity to a single ground truth, this method uses conditional Implicit Maximum Likelihood Estimation (cIMLE) to prevent mode collapse by enforcing that all ground truth points are explained by at least one generated sample. See [Ambiguity-Aware Depth Estimates](16981-ambiguity-aware-depth-estimates.md).

### Geometry Composition by Segmented Sampling
Geometry Composition by Segmented Sampling is a method for inserting objects into NeRF scenes by transforming sampling points from scene coordinates to object coordinates using the inserting position (translation and rotation). It composites density as the normalized sum of densities of corresponding points from scene and object at the same position, and reflectance as a weighted sum of reflectance values where weights are the densities of the voxel particles. The final image is rendered using the composited density, reflectance, and shading. See [Geometry Composition by Segmented Sampling](12345-geometry-composition-by-segmented-sampling.md).

### HybridNeRF SDF Density Formulation
The HybridNeRF SDF Density Formulation computes density $\sigma_{\text{SDF}}(\mathbf{x})$ as $\beta(\mathbf{x})\Psi(f(\mathbf{x})\beta(\mathbf{x}))$, where $f(\mathbf{x})$ is the signed distance field output, $\beta(\mathbf{x})$ is the surfaceness parameter, and $\Psi$ is the CDF of a standard Laplace distribution. The surfaceness field $\beta(\mathbf{x})$ is stored in a $512^3$ voxel grid and queried via nearest-neighbor interpolation, allowing it to be spatially adaptive. See [HybridNeRF SDF Density Formulation](12346-hybridnerf-sdf-density-formulation.md).

### SeaThru-NeRF
SeaThru-NeRF extends NeRFs to handle underwater scattering media by treating the medium as a semi-transparent entity with separate color and density parameters from opaque objects. It replaces the traditional single opaque object density with the sum of object density and medium density, allowing for the rendering of scattering media such as underwater environments. See [SeaThru-NeRF](12347-seathru-nerf.md).

### Neural Proxy Rendering with Mixed Samplers
Neural Proxy Rendering with Mixed Samplers is a rendering pipeline that mixes a neural proxy sampler $S_p$ for animated objects and a neural scene sampler $S_c$ for static elements, using a neural texture for local surface appearance. It separates the particle set into proxy and scene sets, using triangle intersection methods to determine the convex set of rays intersecting the proxy mesh, and samples local features via Barycentric coordinates. Unlike NeRF which uses global scene information, neural proxy uses local information. See [Neural Proxy Rendering with Mixed Samplers](12348-neural-proxy-rendering.md).

### Normal Smoothness Constraint
Normal Smoothness Constraint is an adaptive constraint that ensures continuity of estimated surface normals in flat regions while preserving sharp features by weighting the normal difference based on albedo similarity. It samples a perturbed point by adding uniform noise in the normalized 3D space with magnitude 0.01, and computes an edge-aware weight mask $M_i$ from the albedo color difference. The loss is $L_{normalSM} = \frac{1}{N} \sum_{i=1}^{N} M_i \cdot \| N_{pi} - N_{near} \|$. See [Normal Smoothness Constraint](12349-normal-smoothness-constraint.md).

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Uses 3 resolution levels of 3D grids ($128^3, 256^3, 512^3$) and 7 levels of triplanes ($128^2$ to $8,192^2$), plus a $512^3$ surfaceness grid. The exact memory footprint depends on the feature dimension per cell, which is not specified, but the multi-resolution structure is designed for efficiency compared to single high-resolution 3D grids [S1].
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** The multi-resolution feature grid handles aliasing as in VR-NeRF [S1].
*   **Strengths:** Combines the geometric detail of 3D grids with the efficiency of triplanes; uses spatially adaptive surfaceness for better SDF-based density estimation [S1].
*   **Limitations:** Negatively impacts quality near fine objects (lamp wires) and transparent structures (glass door) [S1].
*   **When to use:** When high-quality geometric reconstruction via SDF is needed alongside efficient rendering, and when fine details and transparency are not the primary focus [S1].
*   **When not to use:** When rendering fine, thin structures or highly transparent objects [S1].

## Background
HybridNeRF was introduced in the paper "HybridNeRF: Efficient Neural Rendering via Adaptive Volumetric Surfaces" [S1]. It builds on previous work in multi-resolution feature grids and triplanes, adapting them for SDF-based rendering with adaptive surfaceness [S1].
