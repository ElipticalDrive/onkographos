# Truncated Depth-Based Sampling


## Overview
Truncated Depth-Based Sampling (TDBS) is a ray sampling strategy that utilizes monocular depth priors informed by the truncated normal distribution to optimize ray point sampling, improving convergence speed and accuracy of pose estimation [S1]. It differs from siblings like [NoPe-NeRF](link) by explicitly using the truncated normal distribution for sampling to fully exploit depth priors, whereas NoPe-NeRF considers overall depth distortion and does not fully exploit the potential of monocular depth maps [S1]. It builds on [Depth-Guided Sampling](7490-depth-guided-sampling.md) by replacing uniform or heuristic sampling with a probabilistic model centered on the estimated depth.

## How it works
**Inputs and Outputs:**
*   **Inputs:** A sequence of input images, camera poses (initially unknown or coarse), and a pre-trained monocular depth network (DPT) [S1].
*   **Outputs:** Sampled 3D points along rays, estimated color $c$ and density $\sigma$, rendered RGB and depth images, and optimized radiance field parameters $\theta$ and camera poses $P$ [S1].

**Data Structures:**
*   **Depth Map:** A 2D array of depth values $D(u,v)$ for each pixel $(u,v)$ in the input image, estimated by DPT [S1].
*   **Ray:** Defined as $r(t) = o + td$, where $o$ is the camera origin and $d$ is the viewing direction [S1].
*   **Sampling Points:** A set of $N$ points $\{t_1, t_2, ..., t_N\}$ along the ray, where $N=128$ [S1].

**Parameters:**
*   **Truncation Interval:** $[a, b] = [0.001, 1.0]$ [S1].
*   **Variance:** $\bar{\sigma} = 0.1$ [S1].
*   **Number of Samples:** $N = 128$ [S1].

**Steps:**
1.  **Depth Estimation:** Use a pre-trained monocular depth network (DPT) to estimate a coarse depth map for each input image [S1]. Let $\bar{\mu}$ be the depth value at the current pixel's location in this map [S1].
2.  **Ray Casting:** For each pixel, cast a camera ray $r(t) = o + td$ into the scene [S1].
3.  **Sampling Distribution Definition:** Define the probability density function (PDF) $\psi(\bar{\mu}, \bar{\sigma}, a, b; x)$ of the truncated normal distribution [S1]:
    $$
    \psi(\bar{\mu}, \bar{\sigma}, a, b; x) = 
    \begin{cases} 
    0 & x \le a \\
    \frac{\phi(\bar{\mu}, \bar{\sigma}^2; x)}{\Phi(\bar{\mu}, \bar{\sigma}^2; b) - \Phi(\bar{\mu}, \bar{\sigma}^2; a)} & a < x < b \\
    0 & b \le x
    \end{cases}
    $$
    where $\phi(\cdot)$ and $\Phi(\cdot)$ denote the probability density and distribution function of the normal distribution with mean $\bar{\mu}$ and variance $\bar{\sigma}^2$, respectively [S1].
4.  **Inverse Transform Sampling:** Use inverse distribution sampling to obtain $N$ sampling points along the ray from the truncated normal distribution defined by mean $\bar{\mu}$, variance $\bar{\sigma}$, and interval $[a, b]$ [S1].
5.  **Network Evaluation:** Feed the sampled points into an MLP $F_\theta$ to estimate color $c$ and volume density $\sigma$ [S1].
6.  **Volume Rendering:** Render RGB and depth images by integrating color $c$ and density $\sigma$ via volume rendering [S1]. The color $C(r)$ is computed as:
    $$
    C(r) = \int_{t_n}^{t_f} T(t) \sigma(r(t)) c(r(t), d) dt
    $$
    where $T(t) = \exp\left(-\int_{t_n}^{t} \sigma(r(s)) ds\right)$ is the accumulated transmittance [S1].
7.  **Optimization:** Optimize the radiance field by supervising the rendered depth and RGB against targets [S1].

**Pseudocode:**
```python
import numpy as np
from scipy.stats import norm

def truncated_normal_pdf(x, mu, sigma, a, b):
    """
    Probability density function of the truncated normal distribution.
    """
    # Standardize
    z_a = (a - mu) / sigma
    z_b = (b - mu) / sigma
    
    # CDF difference for normalization
    cdf_diff = norm.cdf(z_b) - norm.cdf(z_a)
    
    # PDF values
    pdf_unnormalized = norm.pdf((x - mu) / sigma) / sigma
    
    # Apply truncation
    pdf = np.where((x > a) & (x < b), pdf_unnormalized / cdf_diff, 0.0)
    return pdf

def inverse_transform_sampling_truncated_normal(mu, sigma, a, b, n_samples):
    """
    Generate samples from a truncated normal distribution using inverse transform sampling.
    """
    # Standardize bounds
    z_a = (a - mu) / sigma
    z_b = (b - mu) / sigma
    
    # CDF values at bounds
    cdf_a = norm.cdf(z_a)
    cdf_b = norm.cdf(z_b)
    
    # Generate uniform random numbers in the truncated CDF range
    u = np.random.uniform(cdf_a, cdf_b, n_samples)
    
    # Inverse CDF (PPF)
    z_samples = norm.ppf(u)
    
    # Transform back to original scale
    t_samples = z_samples * sigma + mu
    
    return t_samples

def tdbs_rendering(ray_origin, ray_direction, depth_prior, n_samples=128, a=0.001, b=1.0, sigma=0.1):
    """
    Perform Truncated Depth-Based Sampling and rendering for a single ray.
    
    Args:
        ray_origin: 3D vector, camera origin o
        ray_direction: 3D vector, viewing direction d
        depth_prior: float, estimated depth value mu_bar from DPT
        n_samples: int, number of sampling points
        a: float, lower bound of truncation
        b: float, upper bound of truncation
        sigma: float, standard deviation of the normal distribution
        
    Returns:
        rendered_color: RGB value
        rendered_depth: Depth value
    """
    # Step 1: Sample points along the ray using truncated normal distribution
    # The depth prior mu_bar is the mean of the distribution
    # We sample t values (distances along the ray)
    t_samples = inverse_transform_sampling_truncated_normal(
        mu=depth_prior, 
        sigma=sigma, 
        a=a, 
        b=b, 
        n_samples=n_samples
    )
    
    # Compute 3D points
    points = ray_origin + t_samples[:, np.newaxis] * ray_direction
    
    # Step 2: Evaluate MLP for color and density
    # F_theta(points, ray_direction) -> (colors, densities)
    # Note: In practice, this involves batching and neural network inference
    colors, densities = evaluate_mlp(points, ray_direction)
    
    # Step 3: Volume Rendering
    # Compute transmittance
    # T(t) = exp(-integral from t_n to t of sigma(s) ds)
    # Discrete approximation
    dt = t_samples[1] - t_samples[0] # Assuming uniform spacing in t for simplicity, or use actual differences
    # More accurately, compute alpha and transmittance step-by-step
    
    alphas = 1.0 - np.exp(-densities * dt)
    transmittances = np.cumprod(1.0 - alphas)
    transmittances = np.insert(transmittances, 0, 1.0) # T(t_0) = 1
    
    # Weighted sum for color
    weights = alphas * transmittances
    rendered_color = np.sum(weights[:, np.newaxis] * colors, axis=0)
    
    # Weighted sum for depth
    rendered_depth = np.sum(weights * t_samples)
    
    return rendered_color, rendered_depth
```

## Subtopics

### [Coarse-to-Fine Training Strategy](10617-coarse-to-fine-training-strategy.md)
A training strategy that progressively improves depth precision to circumvent local minima and refine depth geometry. It sets itself apart from standard single-stage training by decoupling the optimization into distinct phases: an initial phase focused on global convergence using robust priors, followed by a phase focused on local precision or error correction. This approach accelerates convergence and enhances the accuracy of pose estimation and scene reconstruction.

## Operating characteristics
*   **Time Complexity:** Depends on the number of sampling points per ray ($N=128$) and the number of rays. The inverse transform sampling is $O(N)$ per ray. The MLP evaluation is the dominant cost.
*   **Memory Complexity:** Proportional to the number of samples and the size of the MLP.
*   **Performance:** Improves convergence speed and accuracy of pose estimation compared to methods that do not fully exploit depth priors [S1].
*   **Strengths:** Explicitly uses truncated normal distribution to sample near the estimated depth, reducing the search space for the surface [S1].
*   **Limitations:** Relies on the quality of the coarse depth map. Coarse depth maps from pre-trained networks (e.g., DPT) fail to capture fine details and may be inaccurate or incorrect in many details, which can degrade rendering quality if used directly in a full-stage manner [S1].
*   **When to Use:** When monocular depth priors are available and the goal is to improve convergence and pose estimation accuracy in NeRF optimization [S1].
*   **When Not to Use:** When high-fidelity depth details are critical and the monocular depth prior is significantly inaccurate, as this can lead to local minima and degraded quality [S1].

## Background
Truncated Depth-Based Sampling (TDBS) was proposed in the TD-NeRF paper [S1]. It addresses the challenge of jointly optimizing neural radiance fields and camera poses without given camera poses [S1]. The method explicitly utilizes monocular depth priors through three key advancements: 1) TDBS, 2) a coarse-to-fine training strategy, and 3) a robust inter-frame point constraint [S1]. It improves upon previous state-of-the-art methods like NoPe-NeRF by fully exploiting the potential of monocular depth maps [S1].
