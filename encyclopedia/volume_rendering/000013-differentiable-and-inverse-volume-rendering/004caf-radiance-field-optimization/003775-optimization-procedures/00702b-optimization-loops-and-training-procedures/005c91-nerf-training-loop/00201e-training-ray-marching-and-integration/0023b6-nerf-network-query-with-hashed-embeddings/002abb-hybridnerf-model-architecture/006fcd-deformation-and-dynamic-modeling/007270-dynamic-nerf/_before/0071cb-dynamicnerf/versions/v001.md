# DynamicNeRF

Also called: Dynamic NeRF, DynamicNeRF

## Overview
DynamicNeRF is a method for reconstructing dynamic scenes from monocular video by employing two coupled neural radiance fields: a static NeRF for background elements and a time-varying dynamic NeRF for moving objects [S1, unofficial]. It distinguishes itself from single-field dynamic approaches by explicitly separating static and dynamic components, using predicted 3D scene flow vectors to warp radiance fields from adjacent time instances, thereby ensuring temporal consistency [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A sequence of monocular images representing a dynamic scene.
*   **Output:** A composite radiance field capable of rendering novel views at arbitrary timestamps, including volume density, color, and 3D scene flow.

**Data Structures:**
The method utilizes two distinct neural network architectures (MLPs):
1.  **Static NeRF:** Takes 3D spatial coordinates $\mathbf{x}$ as input. Outputs volume density $\sigma$ and color $\mathbf{c}$.
2.  **Dynamic NeRF:** Takes spatiotemporal coordinates $(\mathbf{x}, t)$ as input. Outputs:
    *   Volume density $\sigma(\mathbf{x}, t)$
    *   Color $\mathbf{c}(\mathbf{x}, t)$
    *   Forward 3D scene flow vector $\mathbf{v}_{fwd}(\mathbf{x}, t)$
    *   Backward 3D scene flow vector $\mathbf{v}_{bwd}(\mathbf{x}, t)$

**Algorithm Steps:**
1.  **Initialization:** Initialize the static NeRF to model the background and the dynamic NeRF to model moving foreground elements.
2.  **Spatiotemporal Query:** For a given ray and time $t$, query the dynamic NeRF at position $\mathbf{x}$ to obtain density, color, and flow vectors.
3.  **Flow Prediction:** The dynamic NeRF predicts the forward flow $\mathbf{v}_{fwd}$ (displacement from $t$ to $t+1$) and backward flow $\mathbf{v}_{bwd}$ (displacement from $t$ to $t-1$) [S1, unofficial].
4.  **Warping:** Use the flow vectors to warp the radiance field representation from adjacent time instances. Specifically, the flow vectors describe the displacement of a point in 3D space from one time step to the next [S1, unofficial].
5.  **Integration:** Render the final pixel color by integrating the density and color along the ray, combining contributions from the static NeRF (for static regions) and the warped dynamic NeRF (for dynamic regions) [S1, unofficial].
6.  **Optimization:** Train the networks using photometric loss on the input video frames. The method may employ data-driven priors such as geometric consistency and single-view depth terms to learn correct scene geometry, particularly in dynamic regions [S1, unofficial].

**Formulas:**
Let $\mathbf{x}$ be the 3D position and $t$ be the time.
The dynamic NeRF function $F_{dyn}$ is defined as:
$$ F_{dyn}(\mathbf{x}, t) = (\sigma, \mathbf{c}, \mathbf{v}_{fwd}, \mathbf{v}_{bwd}) $$
The warped position $\mathbf{x}'$ at time $t'$ can be estimated using the flow vector:
$$ \mathbf{x}' = \mathbf{x} + \mathbf{v}(\mathbf{x}, t) \cdot (t' - t) $$
where $\mathbf{v}$ is either $\mathbf{v}_{fwd}$ or $\mathbf{v}_{bwd}$ depending on the direction of warping [S1, unofficial].

**Parameters:**
*   **Time Window:** The method considers adjacent time instances for warping. The specific window size is not given in the sources [G].
*   **Learning Rate:** Not given in the sources [G].

**Edge Cases and Pitfalls:**
*   **Occlusion:** The separation of static and dynamic fields must handle occlusions correctly; moving objects may occlude static backgrounds or vice versa. The sources mention "sharp motion discontinuities" as a challenge [S1, unofficial].
*   **Flow Accuracy:** Incorrect flow prediction leads to temporal artifacts. The method relies on the accuracy of the predicted 3D scene flow vectors [S1, unofficial].
*   **Static/Dynamic Boundary:** Defining the boundary between static and dynamic regions is implicit in the network training but requires sufficient data to distinguish static background from moving foreground [S1, unofficial].

## Subtopics

### DMRF
DMRF establishes a two-way coupling between meshes and NeRF, allowing the updating of radiance and throughput along a cast ray with an arbitrary number of bounces [S1, unofficial]. It addresses the color space discrepancy between path tracing and standard NeRF by training NeRF with high dynamic range (HDR) images, enabling more accurate light transport simulation [S1, unofficial]. It also presents a strategy for estimating light sources and casting shadows on NeRF [S1, unofficial].

### V4D
V4D employs a dual voxel format for density and texture fields, processed by a small MLP [S1, unofficial]. It incorporates a lookup table refinement module for pixel-level enhancements with minimal computational overhead [S1, unofficial]. It also introduces conditional positional encoding to improve performance with negligible computational costs [S1, unofficial].

### MSTH
MSTH represents dynamic scenes as a weighted combination of 3D and 4D hash encodings, with weights determined by a learnable mask guided by uncertainty estimation [S1, unofficial]. This method reduces hash collision rates and enables compact representation, allowing rapid optimization and convergence [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources [G].
*   **Memory Complexity:** Not given in the sources [G].
*   **Measured Performance:** Not given in the sources [G].
*   **Strengths:** Capable of capturing complex dynamic scenes from a single monocular video; separates static and dynamic elements for cleaner reconstruction; uses flow-based warping for temporal consistency [S1, unofficial].
*   **Limitations:** Relies on accurate flow prediction; may struggle with severe occlusions or rapid motion if flow estimation is poor; requires sufficient temporal data for flow estimation [S1, unofficial].
*   **When to use:** When reconstructing dynamic scenes from monocular video is required, and explicit separation of static and dynamic components is beneficial.
*   **When not to use:** When multi-view stereo data is available (other methods may be more robust); when real-time rendering is the primary constraint without specific optimizations (not given in sources) [G].

## Background
DynamicNeRF was introduced in the paper "DynamicNeRF" [3] (cited as [S1, unofficial] in the provided notes). It addresses the limitation of standard NeRF, which assumes static scenes, by extending the radiance field representation to handle time-varying scenes. The method builds on the concept of using scene flow to model temporal dynamics, as seen in related works like NeRFlow [4] [S1, unofficial].
