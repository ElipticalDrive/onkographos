# HybridNeRF Model Architecture

Also called: HybridNeRF

## Overview
HybridNeRF is a neural radiance field architecture that accelerates training and rendering by combining dense multi-resolution 3D feature grids with multi-resolution triplanes [S1]. It solves the bottleneck of querying high-dimensional implicit representations by using explicit grid structures for spatial features while maintaining the flexibility of neural networks for color and geometry prediction [S1]. It sets itself apart from pure grid-based methods like [Instant-NGP](13315-instant-ngp.md) by incorporating triplanes, which provide anisotropic feature resolution, and from pure MLP methods by avoiding the computational cost of evaluating deep networks for every sample point [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D point $\mathbf{x} \in \mathbb{R}^3$ and a viewing direction $\mathbf{d} \in \mathbb{R}^3$.
*   **Outputs:** Color $\mathbf{c} \in \mathbb{R}^3$ and signed distance $f \in \mathbb{R}$ (or density $\sigma$ derived from $f$).

**Data Structures:**
1.  **3D Feature Grids:** Three resolution levels with dimensions $128^3$, $256^3$, and $512^3$. Each cell stores a feature vector of size $K=4$.
2.  **Triplanes:** Seven resolution levels with dimensions $128^2, 256^2, \dots, 8192^2$. Each plane stores a feature vector of size $K=4$.
3.  **Surfaceness Field:** A $512^3$ voxel grid storing scalar values $\beta(\mathbf{x}) > 0$.
4.  **MLPs:** Two small Multi-Layer Perceptrons (one for color, one for signed distance).

**Numbered Steps:**

1.  **Feature Fetching (3D Grids):** For the input point $\mathbf{x}$, query the three 3D feature grids. At each resolution level $l \in \{1, 2, 3\}$, fetch $K=4$ features using trilinear interpolation. Let the fetched features be $\mathbf{g}_l(\mathbf{x})$.
2.  **Feature Fetching (Triplanes):** For the input point $\mathbf{x}$, project it onto the three canonical planes (XY, YZ, XZ) to obtain 2D coordinates. Query the seven triplane levels. At each resolution level $m \in \{1, \dots, 7\}$, fetch $K=4$ features using bilinear interpolation. Let the fetched features be $\mathbf{t}_m(\mathbf{x})$.
3.  **Feature Aggregation:**
    *   Sum the features from the 3D grids: $\mathbf{G}(\mathbf{x}) = \sum_{l=1}^{3} \mathbf{g}_l(\mathbf{x})$.
    *   Sum the features from the triplanes: $\mathbf{T}(\mathbf{x}) = \sum_{m=1}^{7} \mathbf{t}_m(\mathbf{x})$.
    *   Concatenate the summed features: $\mathbf{H}(\mathbf{x}) = [\mathbf{G}(\mathbf{x}); \mathbf{T}(\mathbf{x})]$. The resulting vector $\mathbf{H}(\mathbf{x})$ has dimension $4K + 4K = 16$ (since $K=4$).
4.  **Direction Encoding:** Encode the viewing direction $\mathbf{d}$ using spherical harmonics up to the 4th degree. Let this encoded vector be $\mathbf{e}(\mathbf{d})$.
5.  **Network Query:**
    *   Feed $\mathbf{H}(\mathbf{x})$ into the Signed Distance MLP to obtain the raw signed distance $f(\mathbf{x})$.
    *   Feed $\mathbf{H}(\mathbf{x})$ and $\mathbf{e}(\mathbf{d})$ into the Color MLP to obtain the color $\mathbf{c}(\mathbf{x}, \mathbf{d})$.
6.  **Density Computation:** Compute the density $\sigma_{\text{SDF}}(\mathbf{x})$ using the SDF formulation:
    $$ \sigma_{\text{SDF}}(\mathbf{x}) = \beta(\mathbf{x})\Psi(f(\mathbf{x})\beta(\mathbf{x})) $$
    where $\Psi$ is the CDF of a standard Laplace distribution.
7.  **Surfaceness Query:** Query the surfaceness field $\beta(\mathbf{x})$ from the $512^3$ voxel grid using nearest-neighbor interpolation.

**Formulas:**

The Laplace CDF $\Psi(s)$ is defined as:
$$ \Psi(s) = \begin{cases} \frac{1}{2} \exp(-s) & \text{if } s > 0 \\ 1 - \frac{1}{2} \exp(s) & \text{if } s \leq 0 \end{cases} $$
where $s = f(\mathbf{x})\beta(\mathbf{x})$ [S1].

**Parameters:**
*   $K=4$: Number of features fetched per level [S1].
*   3D Grid Levels: 3 resolutions ($128^3, 256^3, 512^3$) [S1].
*   Triplane Levels: 7 resolutions ($128^2$ to $8192^2$) [S1].
*   Surfaceness Grid Resolution: $512^3$ [S1].
*   Spherical Harmonics Degree: 4 [S1].

**Edge Cases and Pitfalls:**
*   **Aliasing:** Due to the multi-resolution feature grid, aliasing artifacts can occur. This is handled using the technique described in VR-NeRF [S1].
*   **Surfaceness Initialization:** The surfaceness parameter $\beta(\mathbf{x})$ is initially constrained to be globally uniform and allowed to diverge spatially during the fine-tuning stage to prevent degradation of semi-transparent surfaces [S1].

## Subtopics

### [Shading Replacement for Relighting](6346-shading-replacement-for-relighting.md)
Shading Replacement for Relighting is a technique for object insertion that avoids inferring scene illumination by replacing the inserted object's shading with shading from existing scene points. It solves the problem of lighting inconsistency when compositing objects into neural radiance field (NeRF) scenes, where naive composition leads to unrealistic results due to varying illumination. It sets itself apart from direct relighting methods by not requiring explicit light source estimation, instead relying on the correlation between surface normals and shading in Lambertian scenes.

### [Hybrid Multi-Space Module](11712-hybrid-multi-space-module.md)
The Hybrid Multi-Space Module extends grid-based NeRF methods (such as iNGP and TensoRF) to handle multiple sub-spaces (e.g., reflections and refractions) by decomposing the multi-space composition information into a small MLP branch, while the main branch models multiple radiance fields using explicit grids. Unlike pure feature-field approaches, this module integrates discrete learnable grids with small MLPs to output densities and colors for each sub-space, enabling efficient rendering of complex light paths in grid-based architectures. It builds on [HybridNeRF Model Architecture](4842-hybridnerf-model-architecture.md).

### [LidaRF Hybrid Representation](12893-lidarf-hybrid-representation.md)
LidaRF is a NeRF variant for street scenes that fuses explicit Lidar point cloud features with an implicit hash-based grid representation to improve geometry and rendering quality under sparse and collinear camera trajectories. It differs from prior Lidar-only NeRF approaches by avoiding low-resolution and incomplete rendering caused by sparse Lidar coverage and limited field of view; instead, it combines explicit Lidar geometry with a high-resolution implicit grid.

### [Pano-NeRF](15013-pano-nerf.md)
Pano-NeRF is a method for geometry recovery and High Dynamic Range (HDR) novel view synthesis from sparse Low Dynamic Range (LDR) panoramic images. It models the scene using irradiance fields, which treat radiance as both a signal conveying lighting information and a light source illuminating other pixels, thereby increasing observation counts for geometry and leveraging irradiance-radiance attenuation for HDR reconstruction. It differs from standard radiance field methods by integrating surface rendering principles into the volume rendering framework to explicitly model inter-reflection and lighting interactions.

### Geometry Composition by Segmented Sampling
Geometry Composition by Segmented Sampling is a method for compositing inserted objects into a NeRF scene. It transforms sampling points from scene coordinates to object coordinates using the inserting position (translation and rotation) [S2]. The composited density is the normalized sum of densities of corresponding points from the scene and the object at the same position. The reflectance is the weighted sum of reflectance values, where the weights are the densities of the voxel particles [S2]. The final image is rendered using the composited density, reflectance, and shading [S2].

### HybridNeRF SDF Density Formulation
The HybridNeRF SDF Density Formulation computes density from a signed distance field $f(\mathbf{x})$ using a spatially adaptive surfaceness parameter $\beta(\mathbf{x})$. The density is given by $\sigma_{\text{SDF}}(\mathbf{x}) = \beta(\mathbf{x})\Psi(f(\mathbf{x})\beta(\mathbf{x}))$, where $\Psi$ is the CDF of a standard Laplace distribution [S1]. The surfaceness field $\beta(\mathbf{x})$ is stored in a $512^3$ voxel grid and queried via nearest-neighbor interpolation [S1].

### SeaThru-NeRF
SeaThru-NeRF extends NeRFs to handle underwater scattering media by treating the medium as a semi-transparent entity with separate color and density parameters from opaque objects [S3]. It replaces the traditional single opaque object density $\sigma(t)$ with the sum of the object density $\sigma_{obj}(t)$ and the medium density $\sigma_{med}(t)$ [S3].

### Neural Proxy Rendering with Mixed Samplers
Neural Proxy Rendering with Mixed Samplers is a rendering pipeline that mixes a neural proxy sampler $S_p$ for animated objects and a neural scene sampler $S_c$ for static elements, using a neural texture for local surface appearance [S4, unofficial]. It separates the particle set $X$ into a proxy set $X_p$ and a scene set $X_c$. For each ray, it finds the convex set bounded by the closest and farthest intersection points with the proxy mesh using a triangle intersection method [S4, unofficial]. It uses Barycentric coordinates to sample local features from the neural texture, unlike NeRF which uses global scene information [S4, unofficial].

## Operating characteristics
*   **Time Complexity:** The feature fetching from multi-resolution grids and triplanes is $O(1)$ per sample point, significantly faster than evaluating a deep MLP for every coordinate. The MLPs are small, keeping the per-sample computation low.
*   **Memory Complexity:** The memory usage is dominated by the storage of the 3D feature grids and triplanes. The total memory is proportional to the sum of the volumes of the 3D grids and the areas of the triplanes multiplied by the feature dimension $K$.
*   **Performance:** HybridNeRF achieves faster training and rendering times compared to standard NeRF and VolSDF [S1].
*   **Strengths:** High efficiency due to explicit feature storage; good quality due to multi-resolution representation; handles aliasing effectively [S1].
*   **Limitations:** Quality may degrade near fine objects (e.g., lamp wires) and transparent structures (e.g., glass doors) [S1]. The surfaceness field requires careful tuning to avoid degrading semi-transparent surfaces [S1].
*   **When to use:** When fast training and rendering are required for high-quality novel view synthesis, and the scene contains complex geometry that benefits from multi-resolution features.
*   **When not to use:** For scenes with very fine, thin structures or highly transparent materials where the grid resolution may not be sufficient to capture details without aliasing or artifacts.

## Background
HybridNeRF was introduced in the paper "HybridNeRF: Efficient Neural Rendering via Adaptive Volumetric Surfaces" [S1]. It builds upon previous work in neural radiance fields, such as NeRF [S1], VolSDF [S1], and Instant-NGP [S1], by combining the benefits of multi-resolution hash grids and triplanes. The method was developed to address the computational bottlenecks of traditional NeRFs while maintaining high rendering quality.
