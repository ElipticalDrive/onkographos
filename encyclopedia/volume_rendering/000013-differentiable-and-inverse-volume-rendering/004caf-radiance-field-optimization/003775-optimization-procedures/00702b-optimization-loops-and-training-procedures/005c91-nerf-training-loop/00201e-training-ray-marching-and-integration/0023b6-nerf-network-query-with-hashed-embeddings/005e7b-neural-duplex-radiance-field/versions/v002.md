# Neural Duplex Radiance Field

Also called: Duplex Radiance Field

## Overview
The Neural Duplex Radiance Field is a real-time view synthesis method that replaces dense volumetric ray marching with a two-surface proxy representation [S1]. It solves the computational bottleneck of evaluating deep MLPs for every sample point by learning to map the two endpoints of a ray segment (defined by intersections with inner and outer meshes) and the view direction to the final pixel color [S1]. It sets itself apart from its parent [NeRF Network Query with Hashed Embeddings](3107-nerf-network-query-with-hashed-embeddings.md) by abandoning per-point MLP queries in favor of vertex-attached features interpolated via hardware rasterization, and from siblings like [HybridNeRF Model Architecture](4842-hybridnerf-model-architecture.md) by relying on explicit mesh proxies rather than hybrid voxel/grid structures for the primary geometry [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A pretrained NeRF density field (used to generate proxies), camera parameters (view direction $\mathbf{d}$), and two proxy meshes (inner $\mathcal{T}_i$ and outer $\mathcal{T}_o$) [S1].
*   **Output:** Pixel color $\mathbf{c} \in \mathbb{R}^3$ [S1].

**Data Structures:**
1.  **Inner Mesh ($\mathcal{T}_i$):** Extracted from the density field using a threshold of $10^{-4}$ [S1]. Contains vertices $V_i$ and triangles $T_i$ [S1].
2.  **Outer Mesh ($\mathcal{T}_o$):** Extracted from the density field using a threshold of $10^{-2}$ [S1]. Contains vertices $V_o$ and triangles $T_o$ [S1].
3.  **Vertex Features:** Each vertex $v_k$ in both meshes has an associated learnable feature vector $\mathbf{f}_k \in \mathbb{R}^N$ [S1].
    *   $N=20$ for CUDA implementation [S1].
    *   $N=8$ for WebGL implementation [S1].

**Numbered Steps:**
1.  **Mesh Extraction:** Extract $\mathcal{T}_i$ and $\mathcal{T}_o$ from a pretrained NeRF density field using marching cubes at the specified density thresholds [S1].
2.  **Feature Initialization:** Initialize learnable feature vectors $\mathbf{f}_k$ for every vertex $v_k$ in $\mathcal{T}_i$ and $\mathcal{T}_o$ [S1].
3.  **Ray Intersection:** For each pixel, cast a ray with direction $\mathbf{d}$ [S1]. Compute the depth-sorted intersection points $\mathbf{x}_1$ with the outer mesh $\mathcal{T}_o$ and $\mathbf{x}_2$ with the inner mesh $\mathcal{T}_i$ [S1].
4.  **Feature Interpolation:** For each intersection point $\mathbf{x} \in \{\mathbf{x}_1, \mathbf{x}_2\}$, determine the containing triangle and compute barycentric coordinates [S1]. Interpolate the vertex features to obtain $\mathbf{f}(\mathbf{x})$ [S1]. This is performed via hardware rasterization [S1].
5.  **Color Aggregation:** Pass the interpolated features and view direction through a shallow aggregation network $F_\Theta$ to predict the color [S1].

**Formula:**
The rendering equation is defined as:
$$
\mathbf{c} = F_{\Theta}(\mathbf{f}(\mathbf{x}_1), \mathbf{f}(\mathbf{x}_2), \mathbf{d})
$$
where:
*   $\mathbf{x}_1 \in \mathcal{T}_o$ is the intersection with the outer mesh [S1].
*   $\mathbf{x}_2 \in \mathcal{T}_i$ is the intersection with the inner mesh [S1].
*   $\mathbf{d}$ is the view direction vector [S1].
*   $F_{\Theta}$ is a shallow network (3-layer convolutional network in CUDA, simplified in WebGL) [S1].

**Pseudocode:**
```python
def render_ray(ray_origin, ray_direction, inner_mesh, outer_mesh, aggregation_net, N):
    """Renders a single ray using the Neural Duplex Radiance Field."""
    # Step 3: Find depth-sorted intersections with outer and inner meshes
    x1, bary1 = ray_triangle_intersect(ray_origin, ray_direction, outer_mesh)
    x2, bary2 = ray_triangle_intersect(ray_origin, ray_direction, inner_mesh)
    
    # Step 4: Initialize feature vectors
    f1 = [0.0] * N
    f2 = [0.0] * N
    
    # Interpolate features if intersections exist
    if x1 is not None:
        f1 = interpolate_barycentric(outer_mesh.vertices, outer_mesh.features, x1, bary1)
    if x2 is not None:
        f2 = interpolate_barycentric(inner_mesh.vertices, inner_mesh.features, x2, bary2)
        
    # Step 5: Aggregate color using shallow network
    color = aggregation_net(f1, f2, ray_direction)
    return color

def ray_triangle_intersect(origin, direction, mesh):
    """Finds the closest intersection of a ray with any triangle in the mesh [G]."""
    closest_dist = float('inf')
    closest_point = None
    closest_bary = None
    for tri in mesh.triangles:
        v0, v1, v2 = tri.v0, tri.v1, tri.v2
        e1 = [v1[i] - v0[i] for i in range(3)]
        e2 = [v2[i] - v0[i] for i in range(3)]
        normal = [e1[1]*e2[2] - e1[2]*e2[1], e1[2]*e2[0] - e1[0]*e2[2], e1[0]*e2[1] - e1[1]*e2[0]]
        denom = sum(direction[i] * normal[i] for i in range(3))
        if abs(denom) < 1e-8: continue
        t = sum((v0[i] - origin[i]) * normal[i] for i in range(3)) / denom
        if t < 1e-6 or t > closest_dist: continue
        point = [origin[i] + t * direction[i] for i in range(3)]
        v0v1 = [v1[i] - v0[i] for i in range(3)]
        v0v2 = [v2[i] - v0[i] for i in range(3)]
        v0p = [point[i] - v0[i] for i in range(3)]
        d11 = sum(v0v1[i]*v0v1[i] for i in range(3))
        d12 = sum(v0v1[i]*v0v2[i] for i in range(3))
        d22 = sum(v0v2[i]*v0v2[i] for i in range(3))
        d01 = sum(v0p[i]*v0v1[i] for i in range(3))
        d02 = sum(v0p[i]*v0v2[i] for i in range(3))
        inv = 1.0 / (d11 * d22 - d12 * d12)
        u = (d22 * d01 - d12 * d02) * inv
        v = (d11 * d02 - d12 * d01) * inv
        if u >= 0 and v >= 0 and u + v <= 1:
            w = 1.0 - u - v
            closest_dist = t
            closest_point = point
            closest_bary = [w, u, v]
    return closest_point, closest_bary

def interpolate_barycentric(vertices, features, point, barycentric):
    """Interpolates feature vector using barycentric coordinates [G]."""
    v0, v1, v2 = vertices[0], vertices[1], vertices[2]
    f0, f1, f2 = features[0], features[1], features[2]
    w, u, v = barycentric
    return [f0[i]*w + f1[i]*u + f2[i]*v for i in range(len(f0))]
```

**Parameters:**
*   **Feature Dimension ($N$):** 20 (CUDA), 8 (WebGL) [S1].
*   **Inner Mesh Density Threshold:** $10^{-4}$ [S1].
*   **Outer Mesh Density Threshold:** $10^{-2}$ [S1].
*   **Aggregation Network:** 3-layer convolutional network (CUDA); simplified network without final convolution layer (WebGL) [S1].

**Edge Cases and Pitfalls:**
*   **Missing Intersections:** Not all rays hit both proxy surfaces [S1]. The view direction $\mathbf{d}$ is appended to the input of $F_\Theta$ to allow the network to handle cases where one intersection is missing [S1].
*   **Occlusion Artifacts:** Local sampling around a single surface suffers from missing geometry or visible occlusions, leading to hole artifacts [S1]. The duplex field mitigates this by learning to combine locations on two estimated surfaces [S1].
*   **High-Frequency Artifacts:** Training from scratch fails to match the fidelity of original NeRFs [S1]. Multi-view distillation from a pretrained teacher model (e.g., TensoRF) is required to guide optimization [S1].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per ray for feature lookup and aggregation, dominated by rasterization and ray-triangle intersection [S1]. Significantly faster than dense volumetric sampling $O(N)$ where $N$ is the number of samples [S1].
*   **Memory Complexity:** $O(V)$ where $V$ is the number of vertices in the proxy meshes [S1]. Much lower than storing dense voxel grids or large hash tables for every sample point [S1].
*   **Performance:** Evaluated on an NVIDIA RTX 2080 Ti GPU, achieving real-time rendering speeds comparable to efficiency-class methods like KiloNeRF and SNeRG [S1]. WebGL implementation offers cross-platform compatibility with some performance degradation [S1].
*   **Strengths:** Real-time rendering capability, reduced memory footprint compared to dense volumetric methods, handles view-dependent appearance via the aggregation network [S1].
*   **Limitations:** Relies on the quality of the proxy meshes; poor mesh extraction leads to artifacts [S1]. Requires a pretrained teacher model for stable training [S1]. May struggle with complex internal structures not captured by the two surface proxies [S1].
*   **When to use:** Real-time view synthesis where high fidelity is needed but dense volumetric rendering is too slow [S1].
*   **When not to use:** Scenes with highly complex internal geometry that cannot be approximated by two surfaces, or when training from scratch without distillation is required [S1].

## Background
The Neural Duplex Radiance Field was introduced in "Learning Neural Duplex Radiance Fields for Real-Time View Synthesis" (CVPR 2023) [S1]. It addresses the computational cost of densely evaluating deep MLPs in NeRF-based methods [S1]. By leveraging two geometric proxy meshes and hardware rasterization, it enables real-time rendering [S1]. The method builds on the concept of using explicit geometry to guide neural rendering, contrasting with implicit volumetric approaches [S1]. It uses multi-view distillation from a pretrained teacher model (like TensoRF) to overcome the lack of high-frequency details when training from scratch [S1].
