# Warped LPIPS Metric

Also called: E_warp (LPIPS variant), Warped LPIPS Consistency Metric, Warped View Consistency with LPIPS

## Overview
The Warped LPIPS Metric is a no-reference evaluation method used to assess geometric and photometric consistency across viewpoints in novel view synthesis, particularly for stylized or super-resolved NeRFs [S1, S2]. It quantifies consistency by computing the Learned Perceptual Image Patch Similarity (LPIPS) between a target rendered view and a source view warped into the target's coordinate system using estimated depth [S1, S2]. Unlike standard metrics that require ground truth, it measures how well the underlying 3D structure supports consistent appearance from nearby angles [S1]. It distinguishes itself from the base View-Consistency Metric (E_warp) by using LPIPS instead of MSE, making it more sensitive to perceptual artifacts [S1, S2].

## How it works
**Inputs:**
- $I_v$: Rendered image from target viewpoint $v$.
- $I_{v'}$: Rendered image from source viewpoint $v'$ (a nearby viewpoint).
- $D_{v'}$: Predicted depth map corresponding to $I_{v'}$.
- $K_v, K_{v'}$: Intrinsic camera matrices for viewpoints $v$ and $v'$ [G].
- $T_{v \to v'}$: Extrinsic transformation matrix from $v$ to $v'$ [G].
- $M_{v,v'}$: Warping mask indicating valid pixels (occlusion-free regions) [G].

**Outputs:**
- $E_{warp}$: Scalar LPIPS score representing inconsistency; lower values indicate higher consistency [S2].

**Data Structures:**
- Depth map $D_{v'}$: 2D array of floats, shape $(H, W)$, where each element represents the distance from the camera center to the surface along the ray [G].
- Warping mask $M_{v,v'}$: 2D binary array, shape $(H, W)$, where 1 indicates a valid pixel and 0 indicates an occluded or invalid region [G].

**Steps:**

1. **Select Source Viewpoint:**
   Select $v'$ as the 3rd nearest test pose from $v$ [S1]. For short-range consistency, pairs with a gap of 5 indices ($O_i, O_{i+5}$) are used; for long-range, a gap of 15 ($O_i, O_{i+15}$) is used [S2].

2. **Backproject to World Space:**
   Use predicted depths to backproject pixels in $I_{v'}$ to a point cloud in world space [S1].

3. **Reproject and Rasterize:**
   Apply a point cloud rasterizer to render the warped image $W(I_{v'})$ in viewpoint $v$ [S1].

4. **Compute Warping Mask $M_{v,v'}$:**
   Identify pixels in the target view $v$ that correspond to valid, non-occluded regions in $v'$ [G]. The mask ensures LPIPS is only computed on geometrically consistent regions [S2].

5. **Compute LPIPS Score:**
   Calculate the LPIPS score between the masked target image $M_{v,v'} \cdot I_v$ and the warped image $W(I_{v'})$ [S1, S2].
   Formula:
   $$ E_{warp}(I_v, I_{v'}) = \text{LPIPS}(M_{v,v'} \cdot I_v, W(I_{v'})) $$
   Only pixels where $M_{v,v'} = 1$ contribute to the LPIPS calculation [S2].

**Pseudocode:**

```python
import numpy as np

def compute_warped_lpips(I_v, I_v_prime, D_v_prime, K_v, K_v_prime, T_v_to_v_prime, T_v):
    """
    Compute the Warped LPIPS metric between view v and v'.
    
    Args:
        I_v: Target rendered image (H, W, 3)
        I_v_prime: Source rendered image (H, W, 3)
        D_v_prime: Depth map for source view (H, W)
        K_v, K_v_prime: Camera intrinsics
        T_v_to_v_prime: Extrinsics from v to v'
        T_v: Extrinsics for view v
        
    Returns:
        E_warp: Scalar LPIPS score
    """
    H, W = I_v.shape[:2]
    
    # 1. Backproject source pixels to world space
    u, v = np.meshgrid(np.arange(W), np.arange(H))
    fx, fy = K_v_prime[0, 0], K_v_prime[1, 1]
    cx, cy = K_v_prime[0, 2], K_v_prime[1, 2]
    x_cam = (u - cx) / fx
    y_cam = (v - cy) / fy
    Z = D_v_prime
    X = x_cam * Z
    Y = y_cam * Z
    P_v_prime_homo = np.stack([X, Y, Z, np.ones_like(Z)], axis=0)
    T_inv = np.linalg.inv(T_v_to_v_prime)
    P_v_homo = T_inv @ P_v_prime_homo
    X_v = P_v_homo[0] / P_v_homo[2]
    Y_v = P_v_homo[1] / P_v_homo[2]
    Z_v = P_v_homo[2]
    
    # 2. Project to target image coordinates
    fx_v, fy_v = K_v[0, 0], K_v[1, 1]
    cx_v, cy_v = K_v[0, 2], K_v[1, 2]
    u_warped = X_v * fx_v + cx_v
    v_warped = Y_v * fy_v + cy_v
    
    # 3. Create Warped Image W(I_v_prime) via bilinear sampling
    def bilinear_sample(img, coords):
        y, x = coords[:,:,0], coords[:,:,1]
        y0, x0 = np.floor(y).astype(int), np.floor(x).astype(int)
        y1, x1 = np.clip(y0 + 1, 0, H-1), np.clip(x0 + 1, 0, W-1)
        wa = (x1 - x) * (y1 - y)
        wb = (x1 - x) * (y - y0)
        wc = (x - x0) * (y1 - y)
        wd = (x - x0) * (y - y0)
        return wa*img[y0, x0] + wb*img[y0, x1] + wc*img[y1, x0] + wd*img[y1, x1]
    
    coords = np.stack([v_warped, u_warped], axis=-1)
    W_I_v_prime = bilinear_sample(I_v_prime, coords)
    
    # 4. Compute Warping Mask M_v,v'
    valid_bounds = (u_warped >= 0) & (u_warped < W) & (v_warped >= 0) & (v_warped < H)
    valid_depth = Z_v > 0
    M_v_v_prime = (valid_bounds & valid_depth).astype(float)
    
    # 5. Compute LPIPS Score
    I_v_masked = I_v * M_v_v_prime[..., np.newaxis]
    # Compute LPIPS using a standard pretrained perceptual network (e.g., VGG or AlexNet) [S1, S2]
    E_warp = compute_lpips_perceptual_score(I_v_masked, W_I_v_prime)
    return E_warp
```

**Parameters:**
- **View Selection:** $v'$ is the 3rd nearest test pose [S1].
- **Consistency Range:** Short-range uses view pairs with a gap of 5; long-range uses a gap of 15 [S2].
- **LPIPS Model:** Standard LPIPS network (typically VGG or AlexNet based) [S1, S2].

**Edge Cases and Pitfalls:**
- **Occlusions:** The warping mask must correctly identify occluded regions; incorrect masking leads to high LPIPS scores due to comparing background with foreground [S2].
- **Boundary Conditions:** Pixels near image borders may not have valid correspondences, requiring careful handling of the mask [G].

## Subtopics

### Short-Range Consistency
Measures consistency between view pairs with a gap of 5 [S2]. Use when evaluating short-term geometric and photometric stability across closely spaced viewpoints [S2].

### Long-Range Consistency
Measures consistency between view pairs with a gap of 15 [S2]. Use when evaluating long-term structural coherence across widely spaced viewpoints [S2].

## Operating characteristics
- **Time Complexity:** Dominated by backprojection and rasterization steps, which are $O(H \times W)$ per view pair [G]. LPIPS computation is also $O(H \times W)$ but involves neural network inference [G].
- **Memory Complexity:** $O(H \times W)$ for storing depth maps, warped images, and masks [G].
- **Measured Performance:** On the LLFF dataset, scores range from 0.0018 (Trex) to 0.0037 (Orchids) for short-range consistency [S2]. For long-range, scores range from 0.0049 (Fern) to 0.0140 (Trex) [S2].
- **Strengths:** No-reference; perceptually relevant; measures short- and long-term consistency [S1, S2].
- **Limitations:** Requires predicted depth maps; sensitive to depth estimation errors [G].
- **When to Use:** Evaluating novel view synthesis methods where ground truth is unavailable, especially for stylized or super-resolved NeRFs [S1, S2].

## Background
The Warped LPIPS Metric was introduced as a no-reference evaluator for assessing view consistency in NeRF-based super-resolution and stylization tasks [S1, S2]. It builds on the concept of warping views using depth to detect inconsistencies, adapting the LPIPS metric for perceptual quality assessment [S1, S2]. It is used in evaluating methods like DiSR-NeRF [S1] and stylization pipelines [S2].
