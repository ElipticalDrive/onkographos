# NeRFCodec

Also called: Neural Feature Compression for Hybrid NeRF

## Overview
NeRFCodec is an end-to-end compression framework for plane-based hybrid Neural Radiance Fields (NeRF) that integrates non-linear transform, quantization, and entropy coding to achieve memory-efficient scene representation [S1]. It solves the high storage requirements of hybrid representations by leveraging a pre-trained 2D neural image codec, adapted with content-specific parameters for each scene, to compress feature planes while maintaining high visual fidelity [S1]. Unlike methods that apply generic image codecs directly or use wavelet transforms, NeRFCodec modifies the encoder and decoder heads of the 2D codec to exploit inter-channel information in feature planes, achieving superior rate-distortion performance with a memory budget of approximately 0.5 MB per scene [S1].

## How it works
**Inputs:** Pre-trained hybrid NeRF feature planes (orthogonal planes from a representation like TensoRF-VM or HexPlane), a pre-trained 2D neural image codec backbone (e.g., Cheng et al. [10]), and a target memory budget (e.g., 0.5 MB).
**Outputs:** A multiplexed bitstream containing quantized latent codes, quantized hyperprior latent codes, content-specific decoder head parameters, residual vectors, tiny MLP parameters, and metadata.

**Data Structures:**
The final bitstream consists of the following components [S1]:
1.  Quantized latent code $\hat{y}$: The compressed representation of the feature planes.
2.  Quantized hyperprior latent code $\hat{z}$: Side information for the entropy model.
3.  Feature decoder head $D_{\phi_2}$: Content-specific network parameters for the neural feature decoder.
4.  Feature residual vectors $v_{\Delta x}$: Residuals for feature reconstruction.
5.  Tiny MLPs $f$: Small multi-layer perceptrons for attribute regression (color/density).
6.  Metadata: Scene-specific configuration data.

**Algorithm Steps:**

1.  **Pre-training:** Pre-train the hybrid NeRF on a specific scene for 100,000 iterations to obtain the initial feature planes $x$ and tiny MLPs $f$ [S1].
2.  **Codec Initialization:** Take a well-trained 2D neural image codec. Replace its encoder head (first layer) and decoder head (last layer) to adjust to the target channel dimension of the NeRF feature planes [S1].
3.  **Warm-up:** Perform a warm-up phase using only the feature plane reconstruction loss to establish a better starting point for the neural feature codec [S1].
4.  **Joint Training:** Train the full pipeline (neural feature codec and neural radiance field) jointly for 100,000 iterations. The loss function $L_{total}$ combines rendering loss (supervision of image quality) and entropy loss (supervision of bitrate) [S1].
    *   The encoder and the new decoder head are updated.
    *   The remaining parts of the pre-trained decoder are frozen [S1].
    *   Note: A feature reconstruction loss between the reconstructed feature plane and the pre-trained feature plane is *not* used, as it degrades performance [S1].
5.  **Quantization-Aware Training (QAT):** Perform QAT on the network parameters to be transmitted (decoder head and MLP in renderer) for 10,000 iterations to prepare for discrete entropy coding [S1].
6.  **Test-Time Encoding:**
    *   Feed orthogonal feature planes into the codec one by one [S1].
    *   Encode the latent code $\hat{y}$ and hyperprior $\hat{z}$ using the entropy model [S1].
    *   Quantize and entropy-encode the content-specific decoder head parameters $D_{\phi_2}$, residual vectors $v_{\Delta x}$, and tiny MLPs $f$ [S1].
    *   Multiplex all substreams into a total bitstream [S1].
7.  **Test-Time Decoding:**
    *   Demultiplex the total bitstream into substreams [S1].
    *   Independently entropy-decode each substream [S1].
    *   Reassemble the content-specific decoder head and residual vectors to reconstruct the feature planes [S1].
    *   Reconstruct feature planes once; subsequent querying operations for volume rendering are executed on these reconstructed planes [S1].

**Pseudocode:**

```python
def train_nerf_codec(scene_data, pre_trained_2d_codec, num_iterations=100000, qat_iterations=10000):
    """
    Trains the NeRFCodec for a specific scene.
    """
    # Step 1: Pre-train Hybrid NeRF
    nerf_model = HybridNeRF(scene_data)
    nerf_model.train(100000) # Standard NeRF training
    feature_planes, tiny_mlp = nerf_model.get_feature_planes_and_mlp()
    
    # Step 2: Initialize Codec
    # Replace first and last layers of pre_trained_2d_codec to match feature plane channels
    codec = pre_trained_2d_codec
    codec.encoder_head = LinearLayer(in_channels=feature_planes.channels, out_channels=latent_channels)
    codec.decoder_head = LinearLayer(in_channels=latent_channels, out_channels=feature_planes.channels)
    
    # Freeze the middle parts of the decoder (pre-trained weights)
    for param in codec.decoder_middle.parameters():
        param.requires_grad = False
        
    # Step 3: Warm-up
    # Optimize codec encoder/decoder_head with feature reconstruction loss only
    warmup_loss = reconstruction_loss(codec.decode(codec.encode(feature_planes)), feature_planes)
    optimize(warmup_loss, params=[codec.encoder_head, codec.decoder_head])
    
    # Step 4: Joint Training
    # Loss = Rendering Loss + Entropy Loss
    for i in range(num_iterations):
        # Sample rays and render images using current feature planes and tiny_mlp
        rendered_images = render(nerf_model, feature_planes, tiny_mlp)
        rendering_loss = compute_rendering_loss(rendered_images, ground_truth_images)
        
        # Encode feature planes to get latent code y
        y = codec.encode(feature_planes)
        
        # Compute entropy loss based on the probability model of y
        entropy_loss = compute_entropy_loss(y, codec.probability_model)
        
        total_loss = rendering_loss + entropy_loss
        optimize(total_loss, params=[codec.encoder_head, codec.decoder_head, tiny_mlp])
        
    # Step 5: Quantization-Aware Training
    for i in range(qat_iterations):
        # Quantize parameters to be transmitted (decoder_head, tiny_mlp)
        quantized_decoder_head = quantize(codec.decoder_head)
        quantized_mlp = quantize(tiny_mlp)
        
        # Forward pass with quantized parameters
        y = codec.encode(feature_planes)
        reconstructed_planes = codec.decode(y, quantized_decoder_head)
        rendered_images = render(nerf_model, reconstructed_planes, quantized_mlp)
        
        loss = compute_rendering_loss(rendered_images, ground_truth_images)
        optimize(loss, params=[codec.encoder_head, quantized_decoder_head, quantized_mlp])
        
    return codec, tiny_mlp, feature_planes

def encode_scene(codec, feature_planes, tiny_mlp):
    """
    Encodes the scene into a bitstream.
    """
    bitstreams = []
    
    # Encode latent codes for each orthogonal plane
    for plane in feature_planes:
        y = codec.encode(plane)
        z = codec.get_hyperprior(y)
        bitstreams.append(entropy_encode(y))
        bitstreams.append(entropy_encode(z))
        
    # Encode content-specific parameters
    bitstreams.append(entropy_encode(quantize(codec.decoder_head)))
    bitstreams.append(entropy_encode(quantize(tiny_mlp)))
    
    # Multiplex
    total_bitstream = multiplex(bitstreams)
    return total_bitstream

def decode_scene(total_bitstream, codec):
    """
    Decodes the bitstream and reconstructs the NeRF for rendering.
    """
    # Demultiplex
    substreams = demultiplex(total_bitstream)
    
    # Decode latent codes and reconstruct planes
    reconstructed_planes = []
    for substream in substreams:
        y = entropy_decode(substream)
        z = entropy_decode(substream) # Assuming z is separate or interleaved
        plane = codec.decode(y)
        reconstructed_planes.append(plane)
        
    # Decode parameters
    decoder_head = entropy_decode(substream) # Content-specific head
    tiny_mlp = entropy_decode(substream)     # Tiny MLP
    
    # Reassemble
    codec.decoder_head = decoder_head
    nerf_model.tiny_mlp = tiny_mlp
    
    # Return reconstructed planes and model for rendering
    return reconstructed_planes, nerf_model
```

**Parameters:**
*   **Memory Budget:** 0.5 MB per scene [S1].
*   **Joint Training Iterations:** 100,000 [S1].
*   **QAT Iterations:** 10,000 [S1].
*   **Backbone:** Neural image codec by Cheng et al. [10] [S1].
*   **Implementation Base:** CompressAI library [4] [S1].

**Edge Cases and Pitfalls:**
*   **Direct Reuse Failure:** Using a pre-trained 2D neural image codec without architecture modification (splitting planes into three channels, normalizing, and feeding) results in significantly higher bitrate consumption because it does not fully exploit inter-channel information [S1].
*   **Generalization Failure:** A neural feature codec trained on a small-scale feature dataset (e.g., 8 scenes from NeRF-Synthetic) fails to generalize to unseen objects from other datasets (e.g., NSVF-Synthetic) without test-time optimization, producing unreasonable rendering results [S1].
*   **Feature Reconstruction Loss:** Adding a reconstruction loss between the reconstructed feature plane and the pre-trained feature plane degrades performance (lower PSNR/SSIM) and increases size [S1].
*   **Training Time:** Training the non-linear transform is time-consuming [S1].
*   **Scene Specificity:** A specialized neural feature codec must be trained for each scene individually [S1].

## Operating characteristics
*   **Time Complexity:** Training is time-consuming due to the joint optimization of the neural feature codec and the neural radiance field, as well as the non-linear transform training [S1].
*   **Memory Complexity:** The method achieves a memory budget of approximately 0.5 MB per scene [S1].
*   **Measured Performance:**
    *   On NeRF-Synthetic Dataset: 36.60 dB PSNR at 0.91 MB and 36.21 dB PSNR at 0.46 MB [S1].
    *   Compression Ratio: Over 1000 times for feature planes via non-linear transform [S1].
    *   Memory Breakdown (TensoRF-VM variant):
        *   Compressed Feature planes: 0.052 MB (Original 69.953 MB, Ratio x1345.3) [S1].
        *   Compressed Decoder head: 0.269 MB (Original 1.761 MB, Ratio x6.5) [S1].
        *   Compressed MLP in renderer: 0.042 MB (Original 0.160 MB, Ratio x3.8) [S1].
        *   Feature vectors: 0.049 MB (Original 0.234 MB, Ratio x4.8) [S1].
        *   Residual vectors: 0.041 MB (Original 0.234 MB, Ratio x5.7) [S1].
        *   Total Compressed: 0.453 MB (Original 72.342 MB, Ratio x159.7) [S1].
*   **Strengths:** Superior rate-distortion performance compared to Masked Wavelet NeRF, Binary Radiance Fields, and VQ-TensoRF [S1]. The use of a non-linear transform instead of a wavelet transform improves performance [S1]. Decoding incurs only a short waiting time as feature planes are reconstructed once [S1].
*   **Limitations:** Requires training a specialized codec for each scene [S1]. Training is time-consuming [S1].
*   **When to Use:** When high-quality novel view synthesis is required with strict memory constraints (e.g., < 0.5 MB per scene) and per-scene optimization is feasible [S1].
*   **When Not to Use:** When real-time generalization to unseen scenes without per-scene training is required, or when computational resources for joint training are limited [S1].

## Background
NeRFCodec was proposed by researchers from Zhejiang University and published in CVPR 2024 [S1]. It addresses the significant storage requirements of hybrid NeRF representations, which combine feature grids and small MLPs for high reconstruction quality and fast training [S1]. The method is validated on TensoRF-VM and HexPlane as representative implementations of neural fields, and evaluated on NeRF-Synthetic, NSVF-Synthetic, and Tanks and Temples datasets [S1]. It builds on advances in neural compression and neural field representation, specifically reusing pre-trained neural 2D image codecs [S1].
