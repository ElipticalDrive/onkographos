# NeRF with Local Neural Fields (Nerflets)
Also called: Local Radiance Fields

## Overview
Nerflets represent a 3D scene as a structured, irregular collection of local neural radiance fields, where each "nerflet" maintains its own spatial position, orientation, and extent to contribute to density, radiance, and semantic reconstructions within its region of influence [S1]. Unlike global implicit representations that evaluate a single large MLP for every sample, Nerflets evaluate only the small MLPs of nearby nerflets, weighted by their spatial influence, enabling efficient, structure-aware scene decomposition and interactive editing using only 2D supervision [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A set of posed RGB images of a scene. Optionally, 2D semantic segmentation masks for panoptic supervision [S1].
*   **Output:** A rendered RGB image and associated semantic/instance fields for a target camera view; a trained set of Nerflets representing the scene [S1].

**Data Structures**
The scene is represented by a set of $N$ Nerflets. Each Nerflet $i$ stores the following fields:
1.  **Pose Parameters (9 DOF):**
    *   Center position $\mu_i \in \mathbb{R}^3$.
    *   Axis-aligned radii $r_i \in \mathbb{R}^3$ (one per axis).
    *   Rotation angles $\theta_i \in \mathbb{R}^3$ (XYZ rotation) defining the orientation of the local coordinate frame [S1].
2.  **Influence Function Parameters:** Derived from the pose, defining the spatial extent $g_i(x)$ [S1].
3.  **Miniature MLP ($f_i$):** A small neural network that takes a local coordinate as input and outputs density $\sigma$ and color $c$ [S1].
4.  **Semantic Logit Vector ($s_i$):** A fixed-size vector storing semantic class logits directly, rather than being generated by the MLP [S1].
5.  **Instance ID ($I_{nsi}$):** An integer label indicating the real-world object instance to which this Nerflet belongs [S1].

**Algorithm Steps**

1.  **Initialization:** Initialize a set of $N$ Nerflets. The number $N$ is not fixed a priori but is determined by the optimization process (parsimony encourages decomposition) [S1]. Initialize pose parameters, MLP weights, semantic logits, and instance IDs. [G] Instance IDs may be initialized randomly or via a clustering step, but are refined during training.

2.  **Ray Marching and Query:** For a given ray, sample points $x_k$ along the ray. For each sample point $x_k$:
    a. Identify the subset of Nerflets $i$ that are "near" $x_k$. The sources state that only nearby Nerflets are evaluated, but do not specify the exact distance threshold or neighbor search algorithm (e.g., voxel grid, KD-tree) [S1]. [G] In practice, a spatial index structure is required to efficiently find nearby Nerflets.
    b. For each nearby Nerflet $i$, compute the influence weight $w_{k,i}$ based on the distance between $x_k$ and the Nerflet's center $\mu_i$, modulated by the radii and rotation [S1].
    c. Transform $x_k$ into the local coordinate frame of Nerflet $i$ using $\mu_i$, rotation $\theta_i$, and radii $r_i$. Let this local coordinate be $x'_{k,i}$ [S1].
    d. Query the miniature MLP $f_i$ with $x'_{k,i}$ to obtain density $\sigma_{k,i}$ and color $c_{k,i}$ [S1].
    e. Query the semantic logit vector $s_i$ to obtain semantic logits $s_{k,i} = s_i$ (constant for the Nerflet) [S1].

3.  **Aggregation:** Combine the outputs from all contributing Nerflets for sample $x_k$. The sources state that results are averaged, weighting by the influence [S1]. The specific aggregation formula is not explicitly detailed in the provided text, but standard volume rendering principles apply. [G] The effective density $\sigma_k$ and color $c_k$ at sample $x_k$ are typically computed as weighted sums:
    $$ \sigma_k = \sum_{i} w_{k,i} \sigma_{k,i} $$
    $$ c_k = \frac{\sum_{i} w_{k,i} \sigma_{k,i} c_{k,i}}{\sum_{i} w_{k,i} \sigma_{k,i}} $$
    Similarly, semantic logits are aggregated:
    $$ s_k = \sum_{i} w_{k,i} s_i $$
    where $w_{k,i}$ is the influence weight.

4.  **Volume Rendering:** Perform standard density-based volume rendering [S1]. For a ray with samples $k=1 \dots K$, compute the transmittance $T_k$ and the final color $C$ and semantic output $S$:
    $$ T_k = \exp\left(-\sum_{j=1}^{k-1} \sigma_j \delta_j\right) $$
    $$ C = \sum_{k=1}^{K} T_k (1 - \exp(-\sigma_k \delta_k)) c_k $$
    $$ S = \sum_{k=1}^{K} T_k (1 - \exp(-\sigma_k \delta_k)) s_k $$
    where $\delta_k$ is the distance between samples [S1].

5.  **Loss Computation:** Compute the loss between the rendered image/semantics and the ground truth 2D images/segmentations. The loss includes photometric loss and semantic segmentation loss [S1].

6.  **Optimization:** Update all continuous parameters of the Nerflets (pose, MLP weights, semantic logits) jointly using gradient descent. The rendering is fully differentiable with respect to these parameters [S1]. Instance IDs are assigned based on scene structure after training, though they may be optimized jointly during training to improve instance recall [S1].

**Parameters**
*   **Number of Nerflets ($N$):** Not fixed; determined by optimization. Parsimony encourages decomposition [S1].
*   **MLP Size:** "Miniature" or "tiny" MLP. Specific architecture (layers, hidden units) is not given in the sources [S1].
*   **Semantic Logit Vector Size:** Not given in the sources [S1].
*   **Influence Function:** Radial Basis Function (RBF) falling off with distance [S1]. Exact parameters (e.g., variance) are not given in the sources [S1].

**Edge Cases and Pitfalls**
*   **Overlap:** Nerflets may overlap. The weighting scheme handles this, but degenerate overlaps (e.g., identical centers) may require regularization [S1].
*   **Instance Assignment:** Instance labels are assigned based on scene structure after training. Ambiguities in instance boundaries may arise [S1].
*   **Neighbor Search:** Efficiency depends on finding "nearby" Nerflets. Poor spatial indexing can lead to evaluating all Nerflets, negating the efficiency benefit [S1].

## Subtopics

### Panoptic Neural Fields (PNF)
Requires expensive ground truth 3D supervision for detector and tracker and has a fixed 3D scene decomposition. Nerflets require only 2D supervision and support any class with 2D panoptic segmentations [S1]. [PNF](link)

### DM-NeRF
Uses a large MLP to decode spatial positions to object identity vectors, requiring an inverse query algorithm for editing. Nerflets provide explicit structure and can be edited directly as geometric primitives [S1]. [DM-NeRF](link)

## Operating characteristics
*   **Time Complexity:** Rendering is faster than global NeRF because only nearby Nerflets are evaluated per sample, rather than a single large MLP. However, the overhead of neighbor search and multiple MLP queries exists. [S1]
*   **Memory Complexity:** Depends on the number of Nerflets $N$ and the size of each miniature MLP. Generally more compact than a single large MLP for complex scenes due to sparsity [S1].
*   **Measured Performance:** Experiments on indoor and outdoor datasets confirm benefits in parsimony, efficiency, compactness, and scalability [S1].
*   **Strengths:** Efficient, structure-aware, supports 2D supervision, enables interactive editing, provides 3D panoptic decomposition [S1].
*   **Limitations:** Requires neighbor search; instance assignment is post-training; specific hyperparameters (MLP size, RBF parameters) are not detailed [S1].
*   **When to Use:** When 2D supervision is available, and scene structure, panoptic segmentation, and interactive editing are desired. [S1]
*   **When Not to Use:** When 3D ground truth supervision is available and a fixed decomposition is acceptable (PNF might be simpler); when editing requires complex inverse queries (DM-NeRF might be more flexible in some contexts, though Nerflets are explicitly designed for direct editing) [S1].
