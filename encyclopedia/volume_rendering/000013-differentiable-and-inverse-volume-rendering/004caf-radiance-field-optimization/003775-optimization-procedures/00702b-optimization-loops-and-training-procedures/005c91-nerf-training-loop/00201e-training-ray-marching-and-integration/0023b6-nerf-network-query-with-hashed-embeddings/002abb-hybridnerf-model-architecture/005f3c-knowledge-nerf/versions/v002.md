# Knowledge NeRF


## Overview
Knowledge NeRF is a few-shot novel view synthesis method for dynamic articulated objects that reconstructs a current state $S_1$ using sparse inputs (typically 5 images) by leveraging a pretrained NeRF model of a previous state $S_0$ as a knowledge base [S1]. It differs from previous dynamic NeRF methods that learn deformation from monocular videos by considering two frames at a time: a frozen pretrained base and the current state, using a lightweight projection module to map points from the current state to the knowledge base [S1]. This approach achieves clarity comparable to NeRF trained with abundant images, avoiding the limited clarity often suffered by methods relying solely on monocular video deformation [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A pretrained NeRF model representing the knowledge base state $S_0$; 5 input images of the object in a new state $S_1$; 3D positions $X_1$ of points in $S_1$ (derived from the 5 images via standard NeRF ray marching [G]).
*   **Outputs:** Color $(r, g, b)$ and opacity $(\sigma)$ for points in $S_1$, enabling novel view synthesis for the dynamic state [S1].

**Data Structures:**
1.  **Pretrained NeRF ($S_0$):** A frozen neural network taking 3D position $(x_0, y_0, z_0)$ and viewing angles $(\theta_0, \phi_0)$ as input, outputting color and density. This structure is not modified during the training of $S_1$ [S1].
2.  **Projection Module ($F_P$):** A lightweight neural network composed of 4 fully connected layers.
    *   **Input:** 3D position vector $X_1 = (x_1, y_1, z_1)$ from the current state $S_1$.
    *   **Output:** 3D position vector $X_0 = (x_0, y_0, z_0)$ in the knowledge base $S_0$ [S1].

**Numbered Steps:**
1.  **Knowledge Base Construction:** Pretrain a standard NeRF model on a set of images of the articulated object in a specific initial pose $S_0$. This model serves as the frozen knowledge base [S1].
2.  **Data Acquisition:** Capture 5 input images of the object in a new state $S_1$ [S1].
3.  **Projection Module Training:** Train the projection module $F_P$ end-to-end with the frozen NeRF using Mean-Squared Error (MSE) loss to learn the correspondence between points in $S_1$ and $S_0$ [S1]. The module is placed before the frozen NeRF [S1].
4.  **Rendering Query:** For a point $X_1$ in the current state $S_1$:
    a. Query $F_P$ to obtain the corresponding position $X_0$ in $S_0$: $X_0 = F_P(X_1)$ [S1].
    b. Assume viewing angles are approximately equal: $(\theta_1, \phi_1) \approx (\theta_0, \phi_0)$, based on the assumption that most points are not reflective and look the same from all directions [S1].
    c. Query the frozen pretrained NeRF with $(X_0, \theta_0, \phi_0)$ to retrieve color $(r, g, b)$ and opacity $(\sigma)$ [S1].

**Formulas:**
The projection function $F_P$ maps a point $X_1$ in the current state to $X_0$ in the knowledge base [S1]:

$$
X_0 = F_P(X_1) = \begin{cases} 
X_1, & \text{if } X_1 \text{ is in a static part}, \\
T(X_1), & \text{if } X_1 \text{ is in a moving part}.
\end{cases}
$$

Where $T$ represents rotation, translation, scaling, or the introduction of new contents [S1].

**Parameters:**
*   **Input images per state:** 5 [S1].
*   **Viewing angle assumption:** $(\theta_1, \phi_1) \approx (\theta_0, \phi_0)$ [S1].
*   **Projection Module Architecture:** 4 fully connected layers [S1].

**Pitfalls and Edge Cases:**
*   **Air Particles:** Air particles in $S_1$ may not have a correspondence to $S_0$. However, this is handled because their transparency makes them irrelevant to the reconstruction [S1].
*   **New Contents:** The introduction of new parts in $S_1$ that were not present in $S_0$ must be handled by the projection module $T(X_1)$, which implicitly learns these changes [S1].
*   **Viewing Angle Assumption:** The method assumes $(\theta_1, \phi_1) \approx (\theta_0, \phi_0)$ because most points are not reflective and look the same from all directions [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class ProjectionModule(nn.Module):
    """Lightweight projection module F_P with 4 fully connected layers [S1]."""
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(3, 64)
        self.fc2 = nn.Linear(64, 64)
        self.fc3 = nn.Linear(64, 64)
        self.fc4 = nn.Linear(64, 3)

    def forward(self, X1):
        x = F.relu(self.fc1(X1))
        x = F.relu(self.fc2(x))
        x = F.relu(self.fc3(x))
        return self.fc4(x)

class KnowledgeNeRF:
    def __init__(self, pretrained_nerf, projection_module):
        self.pretrained_nerf = pretrained_nerf
        self.pretrained_nerf.eval()
        self.projection_module = projection_module

    def query(self, X1, theta1, phi1):
        """Map X1 to X0 and query frozen NeRF [S1]."""
        X0 = self.projection_module(X1)
        theta0 = theta1
        phi0 = phi1
        with torch.no_grad():
            color, sigma = self.pretrained_nerf(X0, theta0, phi0)
        return color, sigma

    def train_step(self, images_S1, rays_S1, optimizer):
        """Train projection module using 5 images from S1 [S1]."""
        optimizer.zero_grad()
        rendered_images = []
        for ray in rays_S1:
            origin, direction, theta, phi = ray.origin, ray.direction, ray.theta, ray.phi
            t_vals = torch.linspace(ray.t_near, ray.t_far, 64)
            deltas = t_vals[1:] - t_vals[:-1]
            deltas = torch.cat([deltas, torch.tensor([0.0], device=deltas.device)])
            X1 = origin + direction.unsqueeze(0) * t_vals.unsqueeze(1)
            colors, sigmas = self.query(X1, theta, phi)
            # Standard volume rendering integration [G]
            alphas = 1.0 - torch.exp(-sigmas * deltas)
            transmittance = torch.cumprod(torch.cat([torch.ones_like(alphas[:, :1]), 1.0 - alphas + 1e-10], dim=1)[:, :-1], dim=1)
            weights = alphas * transmittance
            rendered_pixel = torch.sum(weights * colors, dim=1)
            rendered_images.append(rendered_pixel)
        rendered_images = torch.stack(rendered_images)
        loss = F.mse_loss(rendered_images, images_S1)
        loss.backward()
        optimizer.step()
        return loss.item()
```

## Operating characteristics
*   **Time Complexity:** Training is efficient as only the lightweight projection module (4 fully connected layers) is trained, while the main NeRF is frozen [S1].
*   **Memory Complexity:** Low memory overhead for the projection module. The frozen NeRF must be stored in memory, but no additional large structures are required [S1].
*   **Measured Performance:** Achieves clarity comparable to NeRF trained with abundant images using only 5 input images per state [S1].
*   **Scaling:** The method scales to dynamic articulated objects by considering two frames at a time (pretrained base + current state) [S1].
*   **Strengths:** Few-shot capability (5 images), high clarity, efficient training (lightweight module), handles rigid motion and new contents [S1].
*   **Limitations:** Assumes viewing angles are approximately equal, which relies on the assumption that most points are not reflective and look the same from all directions [S1]. Requires a pretrained NeRF for the initial state [S1].
*   **When to use:** When reconstructing dynamic articulated objects from sparse views, especially when a pretrained model of the object in a previous state is available [S1].
*   **When not to use:** When no initial state is available to train the knowledge base [S1].

## Background
Knowledge NeRF was proposed by Wang et al. in 2024 [S1]. It addresses the challenge of reconstructing dynamic 3D scenes from sparse views, which is difficult for previous dynamic NeRF methods that learn deformation from monocular videos and suffer from limited clarity [S1]. The method leverages the idea of considering two frames at a time: a pretrained knowledge base and the current state, to achieve high-quality novel view synthesis [S1]. The data and implementation are publicly available at https://github.com/RussRobin/Knowledge_NeRF [S1].
