# Radiance Field Decoding with Hybrid Features

Also called: D(x, fr)

## Overview
This method defines the radiance field decoder $D$ that predicts volume density $\sigma$ and color $c$ for a 3D location $x$ and viewing direction $d$, conditioned on global triplane features $f_{tp}$ and residual local features $f_r$ [S1]. It differs from standard NeRF decoders by replacing raw positional encoding with structured global features (triplanes) and local residuals, enabling effective 360° view synthesis from minimal input views [S1].

## How it works
**Inputs:**
- 3D query point $x = (x, y, z)$.
- Viewing direction $d$.
- Triplane set $S = \{S_{xy}, S_{xz}, S_{yz}\}$, where each $S$ is a 2D feature map.
- Residual local features $f_r$ associated with the query point or neighborhood.

**Outputs:**
- Volume density $\sigma$.
- View-dependent color $c$.

**Data Structures:**
- **Triplanes ($S$):** Three 2D tensors representing orthogonal projections of the scene. Dimensions are not explicitly given in the sources [S1].
- **Residual Features ($f_r$):** Local feature vectors. In the variant [S2], these are enhanced by aggregating image features $g_i$ via an MLP: $r_i = r'_i + \text{MLP}(r'_i, g_i)$ [S2].

**Steps:**
1. **Coordinate System Establishment:** Establish the coordinate system using the view space of the input image to standardize scene scales [S1].
2. **Triplane Sampling:** Orthogonally project point $x$ into each plane in $S$. Perform bilinear sampling to obtain vectors from the $xy$, $xz$, and $yz$ planes:
   $$ f_{tp} = [S_{xy}(i, j), S_{xz}(j, k), S_{yz}(i, k)] $$
   where $(i, j, k)$ are the projected coordinates [S1].
3. **Feature Conditioning:** Concatenate the sampled triplane features $f_{tp}$ with the residual local features $f_r$ and the viewing direction $d$ [S1].
4. **Decoding:** Pass the conditioned features through a modular rendering MLP $D$ to predict $\sigma$ and $c$:
   $$ \sigma, c = D(x, d, f_{tp}, f_r) $$
   [S1].
5. **Near/Far Split (Optional):** If implementing the NeRF++-style split [S1]:
   - Calculate squared distance $r^2 = x^2 + y^2 + z^2$.
   - If $r^2 < 1$, use foreground MLP $D_{fg}$.
   - If $r^2 > 1$, use background MLP $D_{bg}$.
   - A coordinate remapping function $M$ contracts points outside the unit sphere [S1].
6. **Multi-view Integration (Optional):** To integrate multi-view observations, pool features along the view dimension in the rendering MLPs [S1].

## Subtopics

### Hybrid Neural Feature Aggregation
Predicts volume density $\delta_i$ for a query point using $k$ nearby geometric-consistent point descriptors, leveraging the view-independent nature of 3D geometry [S2]. Estimates radiance values $c_i$ through hybrid neural features $r_i$ which contain rich details [S2]. The hybrid feature $r_i$ is enhanced by aggregating image features $g_i$: $r_i = r'_i + \text{MLP}(r'_i, g_i)$ [S2]. Rendering uses standard volume rendering: $c = \sum_{i=1}^M \tau_i(1 - \exp(-\delta_i\Delta_i))c_i$, where $\tau_i = \exp(-\sum_{t=1}^{i-1} \delta_t\Delta_t)$ [S2]. $M$ is the number of query points, $\Delta_i$ is the distance between adjacent points [S2]. Random drop strategies (ray-based and query-point-based) are used to ensure both modalities of features are well-optimized [S2].

## Operating characteristics
- **Time Complexity:** Not given in the sources [S1, S2].
- **Memory Complexity:** Depends on the size of the triplanes and residual features. Not given in the sources [S1, S2].
- **Strengths:** Combines local and global feature representations effectively, resulting in accurate 360° view synthesis from as minimal as a single view of an unbounded scene [S1]. Standardizes scales of scenes from various data sources [S1].
- **Limitations:** Requires careful coordinate system establishment [S1]. Performance on single views may be limited compared to multi-view inputs [S1].
- **When to use:** Sparse view synthesis, especially outdoor scenes or unbounded scenes [S1]. Large-scale scenes with motion blur [S2].
- **When not to use:** Dense view settings where standard NeRF might suffice, or when computational resources for triplane storage are limited.

## Background
Originated in NeO 360 for neural fields in sparse view synthesis of outdoor scenes [S1]. Also used in Hybrid Neural Rendering for large-scale scenes with motion blur [S2]. Builds on NeRF++ [74] for the modular MLP structure [S1].
