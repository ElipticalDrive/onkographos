# Occlusion-Aware Masking

Also called: Depth-based Visibility Mask Generation, Invisible Mask Computation, Invisible Region Detection via Depth Warping

## Overview
Occlusion-Aware Masking generates a consistency mask $M_l$ to ignore regions with geometric inconsistencies (such as artifacts or self-occlusion) during feature-level regularization in NeRF optimization [S1, unofficial]. It sets apart from its siblings by explicitly comparing rendered depth maps between a target view and a warped source view to identify invalid warps, rather than relying solely on pixel-space optical flow consistency [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Rendered depth map of the target (unseen) view $D_j$, rendered depth map of the source (seen) view $D_i$, camera intrinsic matrix $K$, relative rotation $R_{j \to i}$ between views, and a distance threshold $\tau$.
*   **Outputs:** A binary consistency mask $M_l$ aligned with the feature map of layer $l$.

**Data Structures:**
*   $D_j, D_i$: 2D arrays of depth values, same resolution as the image.
*   $M$: Binary mask (0 or 1) of the same resolution as $D_j$.
*   $M_l$: Downsampled mask matching the spatial dimensions of the $l$-th layer feature map.

**Steps:**
1.  **Reprojection:** For each pixel $p_j$ in the target view $j$, compute its corresponding coordinate $p_{j \to i}$ in the source view $i$ using the camera parameters and the depth of the target view:
    $$ p_{j \to i} \sim K R_{j \to i} D_j(p_j) K^{-1} p_j $$
    where $\sim$ indicates approximate equality and the result is a continuous coordinate [S1, unofficial].
2.  **Depth Sampling:** Sample the depth value $D_i(p_{j \to i})$ from the source view's depth map at the reprojected coordinate [S1, unofficial].
3.  **Mask Generation:** Compute the binary mask $M$ for each pixel $p_j$ using the Iverson bracket:
    $$ M(p_j) = [ || D_j(p_j) - D_i(p_{j \to i}) || < \tau ] $$
    If the Euclidean distance between the target depth and the reprojected source depth exceeds $\tau$, the pixel is considered occluded or inconsistent and is masked out (0); otherwise, it is valid (1) [S1, unofficial].
4.  **Downsampling:** Apply nearest-neighbor downsampling to $M$ to produce $M_l$, matching the dimensions of the $l$-th layer feature map outputs [S1, unofficial].

**Pseudocode:**
```python
def generate_occlusion_mask(D_j, D_i, K, R_j_to_i, tau):
    """
    Generate occlusion-aware mask by comparing target depth D_j with 
    reprojected source depth D_i.
    
    Args:
        D_j: 2D array, depth of target view j.
        D_i: 2D array, depth of source view i.
        K: 3x3 camera intrinsic matrix.
        R_j_to_i: 3x3 rotation matrix from j to i.
        tau: float, depth distance threshold.
        
    Returns:
        M: 2D binary array, same shape as D_j.
    """
    H, W = D_j.shape
    M = np.zeros((H, W), dtype=float)
    
    # Precompute inverse intrinsic matrix
    K_inv = np.linalg.inv(K)
    
    # Create grid of pixel coordinates for target view
    # p_j is represented as homogeneous coordinates [x, y, 1]
    y, x = np.meshgrid(np.arange(H), np.arange(W), indexing='ij')
    p_j_homogeneous = np.stack([x, y, np.ones_like(x)], axis=-1).astype(np.float32) # Shape (H, W, 3)
    
    # Reshape for matrix multiplication: (H*W, 3)
    p_j_flat = p_j_homogeneous.reshape(-1, 3)
    
    # Step 1: Reprojection
    # Formula: p_{j->i} ~ K * R_{j->i} * D_j(p_j) * K^{-1} * p_j
    # Note: D_j(p_j) is a scalar depth value for each pixel.
    # We perform element-wise multiplication of depth with the transformed coordinates.
    
    # Transform pixel coordinates to camera frame of j, then to i
    # p_cam_j = K^{-1} * p_j_homogeneous (unproject to normalized camera coords)
    p_cam_j = np.einsum('ij, nj -> ni', K_inv, p_j_flat) # (H*W, 3)
    
    # Scale by depth D_j
    # D_j_flat is (H*W,)
    D_j_flat = D_j.reshape(-1)
    p_cam_j_scaled = p_cam_j * D_j_flat[:, np.newaxis] # (H*W, 3)
    
    # Rotate to source camera frame i
    p_cam_i = np.einsum('ij, nj -> ni', R_j_to_i, p_cam_j_scaled) # (H*W, 3)
    
    # Project back to image plane of i
    p_i_homogeneous = np.einsum('ij, nj -> ni', K, p_cam_i) # (H*W, 3)
    
    # Normalize to get 2D coordinates
    # p_i_2d = p_i_homogeneous[:, :2] / p_i_homogeneous[:, 2]
    # Handle division by zero or near-zero depth
    valid_depth = p_i_homogeneous[:, 2] > 1e-5
    p_i_2d = np.zeros((p_i_homogeneous.shape[0], 2))
    p_i_2d[valid_depth] = p_i_homogeneous[valid_depth, :2] / p_i_homogeneous[valid_depth, 2:3]
    
    # Step 2: Sample depth from D_i at p_i_2d
    # Using bilinear or nearest neighbor sampling. The source mentions "differentiable sampler" for color,
    # but for depth consistency in masking, nearest neighbor is often used for robustness, 
    # or bilinear if differentiable masking is required. The text implies standard sampling.
    # We assume a standard bilinear sampler for D_i.
    D_i_sampled = sample_depth(D_i, p_i_2d) # Helper function to sample 2D array at float coordinates
    
    # Step 3: Mask Generation
    # Calculate Euclidean distance between D_j and sampled D_i
    # Note: D_j_flat is the depth at p_j. D_i_sampled is the depth at reprojected p_j.
    depth_diff = np.abs(D_j_flat - D_i_sampled)
    
    # Apply threshold
    M_flat = (depth_diff < tau).astype(float)
    
    # Reshape back to image
    M = M_flat.reshape(H, W)
    
    return M

def downsample_mask(M, target_shape):
    """
    Nearest-neighbor downsampling of mask M to target_shape.
    """
    # Implementation of nearest-neighbor downsampling
    # Using standard interpolation with mode='nearest'
    return scipy.ndimage.zoom(M, (target_shape[0]/M.shape[0], target_shape[1]/M.shape[1]), order=0)
```

**Parameters:**
*   $\tau$: Threshold for depth difference. If the distance between two rays' rendered depths is greater than $\tau$, the pixel is masked out [S1, unofficial]. Typical values are not specified in the sources.

**Edge Cases and Pitfalls:**
*   **Boundary Conditions:** Pixels reprojected outside the source view bounds must be handled (masked out) [S1, unofficial].
*   **Precision:** The reprojection formula uses approximate equality ($\sim$), implying floating-point precision issues may arise [S1, unofficial].
*   **Degenerate Input:** If $D_j(p_j)$ is zero or invalid, reprojection fails.

## Subtopics

### [Optical Flow Masking](17223-optical-flow-masking.md)
Distinguishes valid/invalid optical flow areas to handle occlusion and lighting errors. It sets itself apart by using pixel-space flow consistency rather than just depth-based visibility.

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of pixels $N$ in the image, as it involves per-pixel reprojection and depth comparison.
*   **Memory Complexity:** $O(N)$ for storing the depth maps and masks.
*   **Strengths:** Effectively filters out regions with geometric inconsistencies, artifacts, and self-occlusion, preventing them from corrupting feature-level regularization [S1, unofficial].
*   **Limitations:** Relies on accurate depth estimation; erroneous geometry in the source or target view can lead to incorrect masking [S1, unofficial].
*   **When to use:** When performing feature-level consistency regularization in NeRF training, especially in few-shot settings where geometric errors are prominent [S1, unofficial].

## Background
Originated in GeCoNeRF (Geometric Consistency NeRF), a method for few-shot Neural Radiance Fields [S1, unofficial]. The technique addresses the issue of imperfect and distorted warping caused by erroneous geometry degrading reconstruction quality [S1, unofficial].
