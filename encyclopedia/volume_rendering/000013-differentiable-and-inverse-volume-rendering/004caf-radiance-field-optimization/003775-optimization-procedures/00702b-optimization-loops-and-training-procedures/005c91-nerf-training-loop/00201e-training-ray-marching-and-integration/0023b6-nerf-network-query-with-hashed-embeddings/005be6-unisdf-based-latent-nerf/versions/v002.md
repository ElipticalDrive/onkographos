# UniSDF-based Latent NeRF

Also called: Latent NeRF Model with UniSDF

## Overview
UniSDF-based Latent NeRF is a geometry estimator and appearance model that utilizes UniSDF, a signed distance function (SDF) based volume rendering approach, to decouple geometry from appearance [S1]. It solves the problem of generating relightable 3D assets by extracting a mesh from the SDF for radiance cue computation via a standard rendering engine, while optimizing a latent NeRF for appearance [S1]. It sets itself apart from sibling methods by explicitly leveraging SDF-based mesh extraction to compute physically-based shading normals and radiance cues, rather than relying solely on differentiable volume rendering for all geometric cues [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Input images, camera poses, and a mask [S1].
*   **Outputs:** A mesh representing the geometry, a latent NeRF model for appearance, and radiance cues (shading normals, depth, etc.) rendered from the mesh [S1].

**Data Structures:**
*   **UniSDF Model:** Parameterized similarly to the original UniSDF for the DTU dataset, with specific modifications to proposal sampling and encoding [S1].
*   **Hash Grid Encoding:** An additional hash grid encoding with 15 scales between a resolution of 32 and 4096, used exclusively for outputting predicted normals [S1].
*   **GLO Embeddings:** Applied via an MLP that predicts element-wise scale and shift values for the 'bottleneck' feature of UniSDF [S1].

**Numbered Steps:**
1.  **Geometry Estimation:** Optimize the UniSDF model on the input images. The number of proposal sampling rounds is reduced from two to one, using 64 proposal samples [S1].
2.  **Normal Prediction:** Use the additional hash grid encoding (15 scales, resolution 32 to 4096) to output predicted normals [S1].
3.  **Loss Computation:** Compute the asymmetric predicted normal loss $L_p$ and the smoothness loss $L_s$ during optimization [S1].
4.  **Mesh Extraction:** Convert the optimized SDF representation to a mesh using marching cubes with a threshold set to zero [S1].
5.  **Radiance Cue Rendering:** Import the extracted mesh into a standard rendering engine (Blender Cycles) with predefined materials based on the GGX material model to render radiance cues [S1].
6.  **Latent NeRF Optimization:** Optimize the latent NeRF model. Incorporate GLO embeddings by using an MLP to predict element-wise scale and shift values applied to the UniSDF 'bottleneck' feature [S1].

**Formulas:**
The asymmetric predicted normal loss $L_p$ is defined as [S1]:
$$ L_p = \sum_i \left( \lambda_1 \omega_i \|\nabla n_i - \nabla n'_i \|_2 + \lambda_2 \nabla \omega_i \| n_i - n'_i \|_2 + \lambda_3 \nabla \omega_i \|\nabla n_i - n'_i \|_2 \right) $$
where:
*   $\omega_i$ is the volume rendering weight of the $i$-th sample [S1].
*   $\nabla$ denotes the stop-gradient operator [S1].
*   $n_i$ is the $i$-th sample's density normal [S1].
*   $n'_i$ is the $i$-th sample's predicted normal [S1].
*   $\lambda_1 = 10^{-3}$, $\lambda_2 = 10^{-3}$, $\lambda_3 = 10^{-2}$ [S1].

The smoothness loss $L_s$ is defined as [S1]:
$$ L_s = \lambda_4 \sum_i \omega_i \| n'(x_i + \epsilon) - n'(x_i) \|_2^2 $$
where:
*   $x_i$ is the 3D position of the $i$-th sample [S1].
*   $\epsilon \sim \mathcal{N}(0, \sigma^2 I)$ is an isotropic Gaussian random variable used to perturb the sample locations [S1].
*   $\lambda_4 = 0.1$ [S1].
*   $\sigma = 0.01$ [S1].

**Parameters:**
*   **Optimizer:** Adam with $\beta_1 = 0.9$, $\beta_2 = 0.99$, and $\epsilon = 1 \times 10^{-15}$ [S1].
*   **Learning Rate:** Decayed logarithmically from $5 \times 10^{-3}$ to $5 \times 10^{-4}$ over 25k training iterations [S1].
*   **Warmup:** Cosine-scheduled warmup in the first 500 steps [S1].
*   **Proposal Samples:** 64 samples, with one round of proposal sampling [S1].
*   **Hash Grid:** 15 scales, resolution range 32 to 4096 [S1].

**Pseudocode:**
```python
import math
import numpy as np

def sample_rays(num_proposal_samples, num_rounds):
    positions = np.random.uniform(-1.0, 1.0, (num_proposal_samples, 3))
    weights = np.ones(num_proposal_samples) / num_proposal_samples
    return positions, weights

def compute_density_normals(density_field):
    return np.zeros_like(density_field)  # Standard gradient computation of density field

def compute_asymmetric_normal_loss(weights, density_normals, predicted_normals, lambda1, lambda2, lambda3):
    def stop_gradient(x): return x
    term1 = lambda1 * weights * np.linalg.norm(stop_gradient(density_normals) - stop_gradient(predicted_normals), axis=1)**2
    term2 = lambda2 * stop_gradient(weights) * np.linalg.norm(density_normals - stop_gradient(predicted_normals), axis=1)**2
    term3 = lambda3 * stop_gradient(weights) * np.linalg.norm(stop_gradient(density_normals) - predicted_normals, axis=1)**2
    return np.sum(term1 + term2 + term3)

def sample_gaussian_noise(positions, sigma):
    return np.random.normal(0, sigma, positions.shape)

def cosine_warmup(step, warmup_steps, initial_lr, final_lr):
    return initial_lr + (final_lr - initial_lr) * (1 + math.cos(math.pi * step / warmup_steps)) / 2

def logarithmic_decay(step, total_steps, start_lr, end_lr):
    return end_lr + (start_lr - end_lr) * (math.log(1 + step) / math.log(1 + total_steps))

class Adam:
    def __init__(self, params, lr, beta1, beta2, eps):
        self.params = params
        self.lr = lr
        self.beta1 = beta1
        self.beta2 = beta2
        self.eps = eps
        self.m = {k: np.zeros_like(v) for k, v in params.items()}
        self.v = {k: np.zeros_like(v) for k, v in params.items()}
        self.t = 0
    def step(self, grads):
        self.t += 1
        for k in self.params:
            self.m[k] = self.beta1 * self.m[k] + (1 - self.beta1) * grads[k]
            self.v[k] = self.beta2 * self.v[k] + (1 - self.beta2) * grads[k]**2
            m_hat = self.m[k] / (1 - self.beta1**self.t)
            v_hat = self.v[k] / (1 - self.beta2**self.t)
            self.params[k] -= self.lr * m_hat / (np.sqrt(v_hat) + self.eps)

class UniSDFModel:
    def __init__(self): self.params = {'weights': np.random.randn(10)}
    def forward(self, positions):
        return np.zeros_like(positions), np.abs(np.sin(positions.sum(axis=1)))

class HashGrid:
    def __init__(self, num_levels, resolution_min, resolution_max): pass
    def forward(self, positions): return np.random.randn(len(positions), 3)

class GLOMLP:
    def __init__(self): pass
    def predict(self, feature): return {'scale': np.ones_like(feature), 'shift': np.zeros_like(feature)}

class LatentNeRF:
    def optimize(self, cues, feature): pass

def marching_cubes(sdf_field, threshold): return "mesh"
def render_with_blender_cycles(mesh, material_model): return "radiance_cues"

# Initialization
model = UniSDFModel()
hash_grid = HashGrid(num_levels=15, resolution_min=32, resolution_max=4096)
optimizer = Adam(params=model.params, lr=5e-3, beta1=0.9, beta2=0.99, eps=1e-15)
warmup_steps = 500
total_steps = 25000

# Training Loop
for step in range(total_steps):
    lr = cosine_warmup(step, warmup_steps, 5e-3, 5e-4) if step < warmup_steps else logarithmic_decay(step - warmup_steps, total_steps - warmup_steps, 5e-3, 5e-4)
    optimizer.lr = lr

    positions, weights = sample_rays(64, 1)
    sdf_values, densities = model.forward(positions)
    predicted_normals = hash_grid.forward(positions)

    density_normals = compute_density_normals(densities)
    loss_p = compute_asymmetric_normal_loss(weights, density_normals, predicted_normals, 1e-3, 1e-3, 1e-2)

    epsilon = sample_gaussian_noise(positions, 0.01)
    perturbed_normals = hash_grid.forward(positions + epsilon)
    loss_s = 0.1 * np.mean(weights * np.linalg.norm(perturbed_normals - predicted_normals, axis=1)**2)

    total_loss = loss_p + loss_s
    grads = {k: np.ones_like(v) for k, v in model.params.items()}
    optimizer.step(grads)

# Post-processing: Mesh Extraction
mesh = marching_cubes(sdf_field=sdf_values, threshold=0.0)

# Radiance Cue Rendering
radiance_cues = render_with_blender_cycles(mesh, 'GGX')

# Latent NeRF Optimization
bottleneck_feature = np.random.randn(10)
scale_shift = GLOMLP().predict(bottleneck_feature)
bottleneck_feature = bottleneck_feature * scale_shift['scale'] + scale_shift['shift']
LatentNeRF().optimize(radiance_cues, bottleneck_feature)
```

## Operating characteristics
*   **Time Complexity:** Not given in the sources [S1].
*   **Memory Complexity:** Not given in the sources [S1].
*   **Measured Performance:** Not given in the sources [S1].
*   **Strengths:** Decouples geometry from appearance, allowing fixed geometry weights and optimized appearance weights [S1]. Enables mesh extraction for radiance cue computation [S1]. Modifications result in better and smoother geometry necessary for relighting objects with specular highlights [S1].
*   **Limitations:** Relies on external rendering engine (Blender Cycles) for radiance cues [S1].
*   **When to use:** When relightable 3D assets with specular highlights are required [S1].
*   **When not to use:** When end-to-end differentiable volume rendering without external tools is required [S1].

## Background
UniSDF-based Latent NeRF is based on the IllumiNeRF paper [S1]. It uses UniSDF as the geometry estimator and Latent NeRF model [S1]. The method was implemented using JAX [S1].
