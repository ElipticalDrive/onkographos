# JacobiNeRF Label Propagation

Also called: Adaptive Gradient Sampling, J-NeRF 2D, J-NeRF 3D

## Overview
JacobiNeRF Label Propagation is a test-time method for transferring semantic or instance segmentation labels from a source view to novel target views in a trained NeRF [S1]. It operates by perturbing the NeRF's network parameters along gradients of mutual information associated with labeled pixels, synthesizing perturbed images, and analyzing the response to assign labels [S1]. Unlike methods that append a semantic branch to the network (e.g., Semantic-NeRF) or rely on feature similarity in a separate latent space (e.g., DINO-NeRF), JacobiNeRF leverages the second-order geometry of the radiance field itself to propagate information through mutual-information-induced synergies [S1]. It distinguishes itself from its siblings by utilizing a "shaping" technique that aligns gradients of correlated entities, allowing value information to propagate via the network's parameter space rather than just the feature space [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A trained JacobiNeRF model $\Phi_J$ with parameters $\theta$; a source view with known labels (sparse: one pixel per class, or dense: all pixels labeled); a target view defined by camera pose $(o_t, v_{pt_t})$; number of classes $K$.
*   **Output:** Predicted semantic/instance labels for pixels in the target view.

**Data Structures:**
*   **JacobiNeRF Model $\Phi_J$:** The radiance field network. The specific internal architecture (hashing, MLPs) is defined in [HybridNeRF Model Architecture](4842-hybridnerf-model-architecture.md).
*   **Gradients $\partial \Phi_{J,s_k}$:** The gradient of the mutual information (or relevant loss) with respect to network parameters $\theta$, computed for a specific labeled pixel $s_k$ in the source view. The norm of these gradients is normalized to be close to 1.0 [S1].
*   **Perturbation Magnitude $\sigma$:** A scalar hyper-parameter controlling the step size of the parameter perturbation.

**Parameters:**
*   $\sigma = 0.1$: Empirically set perturbation magnitude [S1].
*   $K$: Number of semantic/instance classes.
*   $N_{sample} = 20$: Number of gradient combinations sampled per iteration in the dense setting [S1].
*   $N_{select} = 5$: Number of qualified gradient selections required to terminate the adaptive sampling loop [S1].

**Algorithm Steps:**

The method supports two settings: Sparse and Dense.

1.  **Gradient Computation:** For each labeled pixel $s_k$ in the source view (where $k=1 \dots K$), compute the gradient $\partial \Phi_{J,s_k}$ of the mutual information shaping objective with respect to the network parameters $\theta$ [S1]. Normalize $\|\partial \Phi_{J,s_k}\| \approx 1.0$ [S1].

2.  **Perturbation and Synthesis (Core Propagation):**
    For each selected gradient index $k \in \{1, \dots, K\}$:
    a. Generate a perturbed model instance:
       $$ \Phi_J^{(k)} = \Phi_J(\cdot; \theta + \sigma \partial \Phi_{J,s_k}) $$
    b. Synthesize the perturbed image at the target pixel $p_{t_i}$ with origin $o_t$ and direction $v_{pt_t}$:
       $$ I_k(p_{t_i}) = \Phi_J^{(k)}(o_t, v_{pt_t}) $$
       This yields a $K$-dimensional response vector (logits or probabilities) for the target pixel, where the $k$-th component corresponds to the response induced by perturbing along the gradient of the $k$-th class label [S1].

3.  **Label Assignment (Sparse Setting):**
    For each target pixel, assign the label $k$ corresponding to the maximum response in the $K$-dimensional vector:
    $$ \hat{y} = \arg\max_k I_k(p_{t_i}) $$

4.  **Adaptive Gradient Sampling (Dense Setting):**
    In the dense setting, perturbing along all labeled pixels is redundant. An adaptive sampling strategy selects representative gradients [S1].
    a. **Initialization:** Randomly select 20 combinations of labeled pixels. Each combination contains $K$ pixels (one for each class).
    b. **Response Evaluation:** For each combination, perturb the model along the corresponding $K$ gradients and synthesize the response for the *source* view (where the ground truth dense label is known).
    c. **Selection Metric:** Calculate the gain in mean Intersection over Union (mIoU) between the predicted label (derived from the $\arg\max$ of the response) and the ground truth dense label.
    d. **Selection:** Choose the combination of gradients that yields the largest positive gain. Discard the combination if the gain is $\le 0$ [S1].
    e. **Iteration:** Repeat steps (a-d) for subsequent iterations, sampling new combinations.
    f. **Termination:** Stop when 5 qualified selections (combinations) are obtained. This results in a total of $5 \times K$ selected gradients used for the final propagation [S1].

5.  **Aggregation MLP (Dense Setting):**
    To enhance the $\arg\max$ operator, a lightweight decoding MLP is applied [S1].
    a. Input: The $K$-dimensional perturbation response vector for each pixel.
    b. Process: Map the response to $K$-dimensional segmentation logits.
    c. Output: Refined logits used for final label assignment via $\arg\max$ [S1].

**Pseudocode:**

```python
def jacobi_label_propagation(model_phi_j, theta, source_labels, target_view, sigma=0.1, K=10):
    """
    model_phi_j: The JacobiNeRF function Phi_J(theta, ray)
    theta: Current network parameters
    source_labels: List of (pixel_coord, class_id) tuples for the source view
    target_view: Camera pose (origin, direction) for the target view
    sigma: Perturbation magnitude (default 0.1)
    K: Number of classes
    """
    
    # Step 1: Compute gradients for source labels
    # Note: In practice, gradients are computed via backpropagation of the MI-shaping loss
    gradients = {}
    for pixel, class_id in source_labels:
        grad = compute_gradient(model_phi_j, theta, pixel, class_id)
        # Normalize gradient norm to ~1.0
        grad = grad / norm(grad)
        gradients[class_id] = grad

    # Step 2 & 3: Sparse Propagation
    # For each class k, perturb and synthesize
    responses = [] # List of K vectors, one per class
    for k in range(K):
        if k not in gradients:
            continue
        grad_k = gradients[k]
        # Perturbed parameters
        theta_perturbed = theta + sigma * grad_k
        # Synthesize image at target view using perturbed model
        # This returns a tensor of shape (H, W, C) or similar, depending on implementation
        # Here we assume we query specific target pixels
        perturbed_image = model_phi_j(theta_perturbed, target_view)
        responses.append(perturbed_image)
    
    # Stack responses along the class dimension
    # response_map[p, k] is the response for pixel p, class k
    response_map = stack(responses, axis=-1) 
    
    # Assign labels via Argmax
    predicted_labels = argmax(response_map, axis=-1)
    
    return predicted_labels

def jacobi_label_propagation_dense(model_phi_j, theta, source_dense_labels, target_view, sigma=0.1, K=10):
    """
    Dense setting with adaptive sampling and aggregation MLP.
    source_dense_labels: Dense label map (H, W) of the source view.
    """
    
    # Step 4: Adaptive Gradient Sampling
    selected_gradients = []
    qualified_count = 0
    iteration = 0
    
    while qualified_count < 5:
        # Sample 20 combinations of labeled pixels
        # Each combination has K pixels, one for each class
        candidates = []
        for _ in range(20):
            combo = []
            for k in range(K):
                # Find all pixels of class k in source_dense_labels
                class_pixels = get_pixels_with_label(source_dense_labels, k)
                # Randomly select one pixel from this class
                pixel = random.choice(class_pixels)
                combo.append(pixel)
            candidates.append(combo)
        
        best_gain = -1
        best_combo = None
        
        for combo in candidates:
            # Compute gradients for this combination
            combo_grads = []
            for pixel in combo:
                class_id = source_dense_labels[pixel]
                grad = compute_gradient(model_phi_j, theta, pixel, class_id)
                grad = grad / norm(grad)
                combo_grads.append(grad)
            
            # Evaluate response on SOURCE view (known ground truth)
            # Synthesize perturbed images for each gradient
            source_responses = []
            for grad in combo_grads:
                theta_pert = theta + sigma * grad
                # Synthesize on source view camera
                src_img = model_phi_j(theta_pert, source_view_camera)
                source_responses.append(src_img)
            
            # Aggregate responses to get prediction
            # Note: In the paper, this might involve the Aggregation MLP even during selection
            # or a simple aggregation. We assume a standard aggregation for selection metric.
            response_map = stack(source_responses, axis=-1)
            
            # Apply Aggregation MLP if available, else identity
            if aggregation_mlp_exists:
                logits = aggregation_mlp(response_map)
            else:
                logits = response_map
                
            pred_labels = argmax(logits, axis=-1)
            
            # Calculate mIoU gain against ground truth
            gain = calculate_miou_gain(pred_labels, source_dense_labels)
            
            if gain > best_gain:
                best_gain = gain
                best_combo = combo
                best_grads = combo_grads
        
        # Discard if gain <= 0
        if best_gain > 0:
            selected_gradients.extend(best_grads)
            qualified_count += 1
        else:
            # If no positive gain found, break or handle edge case
            break
            
        iteration += 1
        if iteration > 100: # Safety break
            break

    # Step 5: Final Propagation with Selected Gradients
    # Use the selected 5*K gradients to synthesize target view
    final_responses = []
    for grad in selected_gradients:
        theta_pert = theta + sigma * grad
        tgt_img = model_phi_j(theta_pert, target_view)
        final_responses.append(tgt_img)
        
    response_map = stack(final_responses, axis=-1)
    
    # Apply Aggregation MLP for final denoising
    if aggregation_mlp_exists:
        final_logits = aggregation_mlp(response_map)
    else:
        final_logits = response_map
        
    final_labels = argmax(final_logits, axis=-1)
    return final_labels
```

**Edge Cases and Pitfalls:**
*   **Perturbation Magnitude ($\sigma$):** If $\sigma$ is too small, the propagation response is weak and noisy, leading to failure. If $\sigma$ is too large, the first-order Taylor expansion approximation underlying the method becomes invalid, degrading results [S1]. The value $\sigma=0.1$ is recommended [S1].
*   **Gradient Norm:** Gradients must be normalized to have a norm close to 1.0 to ensure the cosine similarity approximation holds [S1].
*   **Dense Sampling Failure:** If the adaptive sampling yields no combinations with positive gain, the process may stall. The implementation should discard such gradients [S1].

## Subtopics

### J-NeRF 2D
An implementation scheme that utilizes the 2D structure of the NeRF (likely treating rays or pixels in a 2D grid manner) for label propagation. It differs from J-NeRF 3D in how it handles the spatial structure during perturbation and aggregation. [Link](4842-hybridnerf-model-architecture.md)

### J-NeRF 3D
An implementation scheme that leverages the 3D structure of the NeRF for label propagation. It differs from J-NeRF 2D by explicitly considering the volumetric nature of the radiance field during the gradient computation and perturbation steps. [Link](4842-hybridnerf-model-architecture.md)

## Operating characteristics
*   **Time Complexity:** The method requires $O(N_{grad} \cdot N_{pixels})$ forward passes, where $N_{grad}$ is the number of selected gradients (e.g., $5K$ in dense setting) and $N_{pixels}$ is the number of target pixels. In the dense adaptive sampling phase, this is multiplied by the number of iterations and candidate combinations (20 per iteration).
*   **Memory Complexity:** Requires storing the perturbed model parameters for each gradient evaluation. Since perturbations are applied to the same base model, memory overhead is proportional to the number of simultaneous perturbations if parallelized, or linear with the number of sequential forward passes.
*   **Performance:** On ScanNet, JacobiNeRF achieves higher mIoU and Total Accuracy compared to S-NeRF and D-NeRF, particularly in far-view scenarios (e.g., 0.47 mIoU vs 0.28 for S-NeRF in far views with 1 source view) [S1].
*   **Strengths:** Does not require retraining the network; leverages mutual information gradients for robust propagation; effective for both sparse and dense label transfer.
*   **Limitations:** Requires computing gradients of the NeRF parameters, which can be computationally expensive; sensitive to the choice of $\sigma$; the adaptive sampling in dense settings adds overhead.

## Background
JacobiNeRF was introduced in the paper "JacobiNeRF: NeRF Shaping with Mutual Information Gradients" [S1]. The method is based on the concept of "NeRF Shaping," where the network parameters are adjusted to align gradients of correlated entities (via mutual information) in the tangent space. This alignment allows the NeRF to propagate value information (such as semantic labels) from selected quantities to other correlated quantities through the network's parameter space. The label propagation technique was developed as a test-time application of this shaping framework, demonstrating its ability to transfer semantic and instance information without modifying the network architecture or retraining.
