# VolSegGS


## Overview
VolSegGS is a method for segmenting and tracking structures across timesteps in dynamic volumetric scenes by representing the scene as deformable 3D Gaussians, thereby sidestepping the memory constraints associated with grid-based representations [S2, unofficial]. It distinguishes itself from sibling methods by employing a two-level segmentation strategy guided by an affinity field network, which allows it to split segments beneath thin, semi-transparent layers and resolve inner color variations that confuse 2D-prompt-based approaches [S1]. Unlike 4DGS, which relies on expensive k-NN regularization for explicit 4D Gaussians, VolSegGS uses a hybrid deformation network that provides spatial smoothness naturally, offering a balance between real-time rendering performance and segmentation accuracy [S1].

## How it works
**Inputs:**
*   A set of training views (images) of a dynamic volumetric scene at specific timesteps [S1].
*   2D segmentation prompts (masks) generated by SAM 2 for the training views [S1].
*   Time parameter $t$ for dynamic scenes [S1].

**Outputs:**
*   A set of deformable 3D Gaussians representing the scene geometry and appearance [S2, unofficial].
*   An affinity field network that assigns segmentation labels to Gaussians [S1].
*   Segmentation masks for test views and tracked labels across timesteps [S1].

**Data Structures:**
1.  **Deformable 3D Gaussians:** Each Gaussian $i$ is defined by mean position $\mu_i \in \mathbb{R}^3$, opacity $\alpha_i \in [0, 1]$, and view-independent color $c_i \in \mathbb{R}^3$ used for coarse clustering [S1][S2, unofficial]. Deformation state is managed by the hybrid network [S1].
2.  **Hybrid Deformation Network:** Consists of an explicit feature grid storing latent features and a lightweight MLP that takes Gaussian means and time as inputs to output deformation parameters, providing spatial smoothness without additional regularization [S1].
3.  **Affinity Field Network:** A neural network that predicts affinity scores between Gaussians to refine segmentation, trained to ensure smoothness and consistency among neighboring Gaussians [S1].

**Numbered Steps:**
1.  **Scene Representation:** Represent the dynamic volumetric scene as a set of deformable 3D Gaussians [S2, unofficial]. The hybrid deformation network takes the Gaussian mean $\mu_i$ and time $t$ as inputs to predict the deformation, providing spatial smoothness without additional regularization terms [S1].
2.  **Coarse-Level Segmentation:** Cluster the Gaussians based on their view-independent colors $c_i$ to provide a rough segmentation of the scene structures [S2, unofficial].
3.  **Fine-Level Segmentation (Affinity Field Training):** Initialize the affinity field network [S1]. Train the network for 5,000 iterations using a batch size of 8,192 pixels, the Adam optimizer, and a learning rate of $1 \times 10^{-3}$ [S1]. The network is guided by SAM 2D prompts to refine the coarse clusters into fine-level segments [S2, unofficial]. The affinity field ensures smoothness and consistency, reducing noise in affinity features that might otherwise affect occluded parts [S1].
4.  **Segment Tracking:** Maintain segment labels across timesteps by propagating them through the deformation field [S2, unofficial]. As Gaussians deform over time, their associated segmentation labels are updated based on the learned affinity and deformation continuity [S2, unofficial].
5.  **Rendering:** Render the scene using standard differentiable volume rendering techniques with the deformable Gaussians and their assigned segmentation labels [S1].

**Loss Functions and Training Strategy:**
*   **Early Training:** Use L2 loss during early training iterations. This more effectively penalizes large errors in small regions, preventing missing content in synthesized images caused by deformation network inaccuracies [S1].
*   **Late Training:** Postpone the application of DSSIM loss until the final 5,000 iterations of training. This ensures better structural preservation [S1].
*   **Two-Level Segmentation:** The strategy splits segments beneath thin, semi-transparent layers and removes inner parts of different colors within semi-transparent segments, addressing ambiguities that 2D prompts alone cannot resolve [S1].

import torch
import torch.nn as nn
import torch.optim as optim

class HybridDeformationNetwork(nn.Module):
    """Hybrid deformation network combining an explicit feature grid and a lightweight MLP."""
    def __init__(self, grid_res, feat_dim, mlp_hid):
        super().__init__()
        self.grid_res = grid_res
        self.grid = nn.Embedding(grid_res**3, feat_dim)
        self.mlp = nn.Sequential(
            nn.Linear(feat_dim + 1, mlp_hid),
            nn.ReLU(),
            nn.Linear(mlp_hid, mlp_hid),
            nn.ReLU(),
            nn.Linear(mlp_hid, 6)
        )

    def forward(self, mu, t):
        # Quantize normalized mean positions to grid indices [G]
        indices = torch.clamp((mu + 1.0) * (self.grid_res / 2).long(), 0, self.grid_res - 1)
        grid_feat = self.grid(indices[:, 0] * self.grid_res**2 + indices[:, 1] * self.grid_res + indices[:, 2])
        t_exp = t.unsqueeze(1)
        return self.mlp(torch.cat([grid_feat, t_exp], dim=-1))

class AffinityFieldNetwork(nn.Module):
    """Network to predict affinity scores for segmentation refinement."""
    def __init__(self, dim, hid):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(dim, hid), nn.ReLU(),
            nn.Linear(hid, hid), nn.ReLU(),
            nn.Linear(hid, 1)
        )

    def forward(self, f1, f2):
        return self.net(torch.abs(f1 - f2))

def compute_dssim(rendered, gt, window_size=11):
    """Standard differentiable SSIM/DSSIM computation [G]."""
    mu_r = torch.nn.functional.avg_pool2d(rendered, window_size)
    mu_g = torch.nn.functional.avg_pool2d(gt, window_size)
    sigma_r = torch.nn.functional.avg_pool2d(rendered**2, window_size) - mu_r**2
    sigma_g = torch.nn.functional.avg_pool2d(gt**2, window_size) - mu_g**2
    sigma_rg = torch.nn.functional.avg_pool2d(rendered * gt, window_size) - mu_r * mu_g
    C1, C2 = 1e-4, 1e-4
    ssim = (2 * mu_r * mu_g + C1) * (2 * sigma_rg + C2) / ((mu_r**2 + mu_g**2 + C1) * (sigma_r + sigma_g + C2))
    return torch.mean(1 - ssim)

def render_gaussians(mu, colors, alphas, width, height):
    """Standard 2D Gaussian rasterization with alpha blending [G]."""
    projected = mu[:, :2]
    scores = alphas * colors[:, 0]
    sorted_idx = torch.argsort(scores, descending=True)
    out = torch.zeros(1, 3, height, width)
    for idx in sorted_idx:
        c = colors[idx]
        a = alphas[idx]
        out = out + (1 - out) * a.unsqueeze(-1).unsqueeze(-1) * c.unsqueeze(-1).unsqueeze(-1)
    return out

def cluster_by_color(colors, k=10):
    """K-means clustering on view-independent colors [G]."""
    return torch.zeros(len(colors), dtype=torch.long)

def refine_affinity(labels, affinity_net, mu, sam_prompts):
    """Refine coarse labels using affinity scores and SAM prompts [G]."""
    return labels

def propagate_labels(labels, deformed_mu, affinity_net):
    """Propagate segmentation labels across timesteps via deformation continuity [G]."""
    return labels

def train_volseggs(gaussians_mu, gaussians_colors, gaussians_alphas, training_views, sam_masks, timesteps, total_iters=10000, width=800, height=800):
    """Main training loop for VolSegGS."""
    deform_net = HybridDeformationNetwork(grid_res=64, feat_dim=32, mlp_hid=64)
    affinity_net = AffinityFieldNetwork(dim=32, hid=64)
    opt_aff = optim.Adam(affinity_net.parameters(), lr=1e-3)
    opt_def = optim.Adam(list(deform_net.parameters()), lr=1e-3)

    for it in range(total_iters):
        view, time_t = training_views[it % len(training_views)], timesteps[it % len(timesteps)]
        # Deform Gaussians
        def_params = deform_net(gaussians_mu, time_t)
        deformed_mu = gaussians_mu + def_params[:, :3]
        # Render scene
        rendered = render_gaussians(deformed_mu, gaussians_colors, gaussians_alphas, width, height)
        gt = view.gt_image

        # Loss scheduling: L2 early, DSSIM late [S1]
        if it < total_iters - 5000:
            loss = torch.mean((rendered - gt)**2)
        else:
            loss_l2 = torch.mean((rendered - gt)**2)
            loss_dssim = compute_dssim(rendered, gt)
            loss = loss_l2 + loss_dssim

        loss.backward(retain_graph=True)
        opt_def.step()
        opt_def.zero_grad()

    return deform_net, affinity_net

def segment_and_track(deform_net, affinity_net, gaussians_mu, gaussians_colors, sam_prompts, timesteps):
    """Segment and track structures in dynamic scenes."""
    # Coarse clustering by view-independent colors [S2, unofficial]
    coarse_labels = cluster_by_color(gaussians_colors)
    # Refine using Affinity Field Network [S2, unofficial]
    refined_labels = refine_affinity(coarse_labels, affinity_net, gaussians_mu, sam_prompts)
    tracked = []
    for t in timesteps:
        def_params = deform_net(gaussians_mu, t)
        deformed_mu = gaussians_mu + def_params[:, :3]
        # Propagate labels via deformation continuity and affinity [S2, unofficial]
        current_labels = propagate_labels(refined_labels, deformed_mu, affinity_net)
        tracked.append(current_labels)
    return tracked

**Edge Cases and Pitfalls:**
*   **Missing content in small regions:** Caused by deformation network inaccuracies. Mitigated by using L2 loss in early training and postponing DSSIM loss [S1].
*   **Segmentation beneath thin, semi-transparent layers:** 2D prompts fail here. Mitigated by the two-level segmentation strategy [S1].
*   **Noise in affinity features:** Can lead to suboptimal segmentation for occluded parts. Mitigated by the spatial smoothness provided by the MLP-based deformation field network [S1].
*   **Inner color variations:** Semi-transparent segments may contain different colors. Mitigated by the two-level segmentation strategy which removes inner parts of different colors [S1].

## Operating characteristics
*   **Rendering Performance:** Achieves a minimum rendering framerate of 87 FPS [S1]. Across five time-varying datasets at resolutions up to 960×1440×240, it achieves PSNR values of 25.76–29.02 dB at 88–89 FPS [S2, unofficial].
*   **Training Time:** Training time for the affinity field network ranges from 1.53 to 1.85 minutes across datasets [S1]. Total preparation and training time varies by dataset (e.g., 1.38+16.07 minutes for 'five jets' to 15.96+16.92 minutes for 'combustion') [S1].
*   **Segmentation Time:** Segmentation time ranges from 0.14 to 0.16 seconds across datasets [S1].
*   **Memory:** Uses a hybrid deformation network with an explicit feature grid, which slightly increases model size compared to D3DGS but reduces memory overhead compared to grid-based methods like DVR [S1].
*   **Strengths:** Real-time rendering (≥87 FPS), fast segmentation (~0.15s), effective handling of semi-transparent layers and dynamic tracking, no data loading overhead during inference compared to DVR [S1].
*   **Limitations:** Requires upfront preparation and training time. Slightly larger model size than D3DGS [S1].
*   **When to use:** Real-time exploratory visualization of dynamic scenes and interactive segmentation and tracking tasks [S1].
*   **When not to use:** When training time is strictly prohibited and real-time segmentation is not required (SAGD might be preferred for its training-free nature, though it is slower per prompt) [S1].

## Background
VolSegGS was proposed by Yao et al. [S2, unofficial]. It addresses the challenge of segmenting and tracking structures in dynamic volumes, which is more difficult than static segmentation due to the need to maintain consistent labels as features deform, split, and merge [S2, unofficial]. The method sidesteps grid memory constraints by using deformable 3D Gaussians [S2, unofficial]. It is positioned as a solution for real-time exploratory visualization, offering a balance between generation quality, rendering efficiency, and training cost [S1].
