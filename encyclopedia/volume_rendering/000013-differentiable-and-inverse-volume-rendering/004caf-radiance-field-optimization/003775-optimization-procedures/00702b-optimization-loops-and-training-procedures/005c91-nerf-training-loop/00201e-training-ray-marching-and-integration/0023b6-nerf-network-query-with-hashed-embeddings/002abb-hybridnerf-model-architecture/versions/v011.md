# HybridNeRF Model Architecture

Also called: Adaptive Volumetric Surfaces, HybridNeRF

## Overview
HybridNeRF is a neural radiance field architecture that combines dense multi-resolution 3D feature grids with multi-resolution triplanes to efficiently featurize 3D sample locations [S1]. It solves the trade-off between the high memory cost of pure 3D grids and the limited geometric expressiveness of pure 2D triplanes by using a hybrid representation [S1]. It sets itself apart from its sibling [MVS Network Query](7517-mvs-network-query.md) by explicitly summing features across resolution levels rather than concatenating them, and from [SqueezeNeRF](8704-squeezenerf.md) by utilizing a spatially adaptive surfaceness field for density estimation [S1].

## How it works
**Inputs:** 3D spatial coordinates $\mathbf{x}$, viewing direction $\mathbf{d}$, and training rays.
**Outputs:** Volume density $\sigma(\mathbf{x})$, color $\mathbf{c}(\mathbf{x}, \mathbf{d})$, and optionally signed distance $f(\mathbf{x})$.

### Data Structures
1.  **3D Feature Grids:** Three resolution levels with dimensions $128^3$, $256^3$, and $512^3$. Each cell stores a feature vector.
2.  **Triplanes:** Seven resolution levels ranging from $128^2$ to $8,192^2$. Each plane stores a feature vector.
3.  **Surfaceness Field:** A $512^3$ voxel grid storing scalar values $\beta(\mathbf{x})$, queried via nearest-neighbor interpolation [S1].
4.  **MLPs:** Two separate MLPs (one for density/SDF, one for color) that process the aggregated features.

### Algorithm Steps
1.  **Feature Fetching:** For a given 3D point $\mathbf{x}$:
    *   Fetch $K=4$ features per level from the 3D feature grids at 3 resolution levels ($128^3, 256^3, 512^3$) via trilinear interpolation [S1].
    *   Fetch $K=4$ features per level from the triplanes at 7 levels (from $128^2$ to $8,192^2$) via bilinear interpolation [S1].
2.  **Feature Aggregation:**
    *   Sum the fetched features across all 3 levels for the 3D grids separately to obtain a summed 3D feature vector $\mathbf{f}_{3D}$ [S1].
    *   Sum the fetched features across all 7 levels for the triplanes separately to obtain a summed triplane feature vector $\mathbf{f}_{tri}$ [S1].
    *   Concatenate $\mathbf{f}_{3D}$ and $\mathbf{f}_{tri}$ to form the input vector $\mathbf{f}_{in}$ for the MLPs. The dimension is $4K + 4K = 16$ (assuming $K=4$ features per level and standard feature dimensions implied by the sum/concat operation described) [S1]. *Note: The source specifies "4K=16-dimensional MLP input", implying the feature dimension per level is 4, or the sum results in a 16-dim vector total. Given $K=4$ features per level, if the feature vector size is $d$, the sum is $3 \times d$ and $7 \times d$. The text "4K=16" suggests the final concatenated dimension is 16. We assume the implementation yields a 16-dimensional vector.* [S1].
3.  **Density/SDF Prediction:**
    *   Pass $\mathbf{f}_{in}$ through the density/SDF MLP to obtain the signed distance $f(\mathbf{x})$ [S1].
    *   Query the surfaceness field $\beta(\mathbf{x})$ from the $512^3$ grid using nearest-neighbor interpolation [S1].
    *   Compute density $\sigma_{\text{SDF}}(\mathbf{x})$ using the SDF formulation (see Formulas).
4.  **Color Prediction:**
    *   Encode the viewing direction $\mathbf{d}$ using spherical harmonics up to the 4th degree [S1].
    *   Concatenate the encoded direction with $\mathbf{f}_{in}$ (or pass through the color MLP which takes direction as auxiliary input) [S1].
    *   Output color $\mathbf{c}(\mathbf{x}, \mathbf{d})$ [S1].
5.  **Rendering:**
    *   Perform volume rendering using the computed density and color along rays [S1].
    *   Handle aliasing using the method from VR-NeRF due to the multi-resolution feature grid [S1].

### Formulas
The density is derived from the signed distance field $f(\mathbf{x})$ and the surfaceness parameter $\beta(\mathbf{x})$:

$$
\sigma_{\text{SDF}}(\mathbf{x}) = \beta(\mathbf{x})\Psi(f(\mathbf{x})\beta(\mathbf{x}))
$$

where $\Psi$ is the cumulative distribution function (CDF) of a standard Laplace distribution:

$$
\Psi(s) = \begin{cases} 
\frac{1}{2} \exp(-s) & \text{if } s > 0 \\ 
1 - \frac{1}{2} \exp(s) & \text{if } s \leq 0. 
\end{cases}
$$

Here, $s = f(\mathbf{x})\beta(\mathbf{x})$ [S1].

### Parameters
*   $K=4$: Number of features fetched per level [S1].
*   3D Grid Levels: 3 levels ($128^3, 256^3, 512^3$) [S1].
*   Triplane Levels: 7 levels ($128^2$ to $8,192^2$) [S1].
*   Surfaceness Grid: $512^3$ voxel grid [S1].
*   Spherical Harmonics: Up to 4th degree [S1].

### Edge Cases and Pitfalls
*   **Aliasing:** The multi-resolution feature grid can cause aliasing artifacts. This is handled using the technique from VR-NeRF [S1].
*   **Surfaceness Tuning:** The surfaceness parameter $\beta(\mathbf{x})$ must be carefully tuned. If too high, it degrades quality near fine objects (e.g., lamp wires) and transparent structures (e.g., glass doors) [S1]. The implementation tracks the Eikonal loss to determine when to stop increasing surfaceness in regions where it becomes too high [S1].
*   **Feature Summation vs Concatenation:** The method explicitly sums features across levels instead of concatenating them, which reduces memory and computational load compared to prior works like [8, 23] cited in [S1].

## Subtopics

### [Shading Replacement for Relighting](6346-shading-replacement-for-relighting.md)
Shading Replacement for Relighting is a technique for object insertion that avoids inferring scene illumination by replacing the inserted object's shading with shading from existing scene points. It solves the problem of lighting inconsistency when compositing objects into neural radiance field (NeRF) scenes, where naive composition leads to unrealistic results due to varying illumination. It sets itself apart from direct relighting methods by not requiring explicit light source estimation, instead relying on the correlation between surface normals and shading in Lambertian scenes.

### [Hybrid Multi-Space Module](11712-hybrid-multi-space-module.md)
The Hybrid Multi-Space Module extends grid-based NeRF methods (such as iNGP and TensoRF) to handle multiple sub-spaces (e.g., reflections and refractions) by decomposing the multi-space composition information into a small MLP branch, while the main branch models multiple radiance fields using explicit grids. Unlike pure feature-field approaches, this module integrates discrete learnable grids with small MLPs to output densities and colors for each sub-space, enabling efficient rendering of complex light paths in grid-based architectures. It builds on [HybridNeRF Model Architecture](4842-hybridnerf-model-architecture.md).

### [LidaRF Hybrid Representation](12893-lidarf-hybrid-representation.md)
LidaRF is a NeRF variant for street scenes that fuses explicit Lidar point cloud features with an implicit hash-based grid representation to improve geometry and rendering quality under sparse and collinear camera trajectories. It differs from prior Lidar-only NeRF approaches by avoiding low-resolution and incomplete rendering caused by sparse Lidar coverage and limited field of view; instead, it combines explicit Lidar geometry with a high-resolution implicit grid.

### [Pano-NeRF](15013-pano-nerf.md)
Pano-NeRF is a method for geometry recovery and High Dynamic Range (HDR) novel view synthesis from sparse Low Dynamic Range (LDR) panoramic images. It models the scene using irradiance fields, which treat radiance as both a signal conveying lighting information and a light source illuminating other pixels, thereby increasing observation counts for geometry and leveraging irradiance-radiance attenuation for HDR reconstruction. It differs from standard radiance field methods by integrating surface rendering principles into the volume rendering framework to explicitly model inter-reflection and lighting interactions.

### [FastSR-NeRF](16574-fastsr-nerf.md)
FastSR-NeRF is a method that improves the rendering efficiency of Neural Radiance Fields (NeRF) on consumer-grade hardware by combining a lightweight NeRF model with a CNN-based super-resolution (SR) module. It solves the problem of high computational cost and long training times associated with high-resolution NeRF rendering by training the NeRF to produce low-resolution (LR) 3D-consistent features and upscaling them to high-resolution (HR) outputs. Unlike prior NeRF+SR methods that rely on complex training procedures, knowledge distillation, or high-resolution reference images, FastSR-NeRF requires no architectural changes to the NeRF backbone and uses a simple end-to-end training pipeline.

### [NeRFCodec](16590-nerfcodec.md)
NeRFCodec is an end-to-end compression framework for plane-based hybrid Neural Radiance Fields (NeRF) that integrates non-linear transform, quantization, and entropy coding to achieve memory-efficient scene representation. It solves the high storage requirements of hybrid representations by leveraging a pre-trained 2D neural image codec, adapted with content-specific parameters for each scene, to compress feature planes while maintaining high visual fidelity. Unlike methods that apply generic image codecs directly or use wavelet transforms, NeRFCodec modifies the encoder and decoder heads of the 2D codec to exploit inter-channel information in feature planes, achieving superior rate-distortion performance with a memory budget of approximately 0.5 MB per scene.

### [Ambiguity-Aware Depth Estimates](16981-ambiguity-aware-depth-estimates.md)
Ambiguity-Aware Depth Estimates is a technique for learning a multimodal distribution of depth estimates conditioned on a single input image, using an implicit generative model to capture inherent ambiguities in monocular depth estimation such as non-opaque surfaces and albedo-shading confusion. Unlike GANs which optimize for similarity to a single ground truth, this method uses conditional Implicit Maximum Likelihood Estimation (cIMLE) to prevent mode collapse by enforcing that all ground truth points are explained by at least one generated sample.

### [Space-time Neural Irradiance Fields](17161-space-time-neural-irradiance-fields.md)
Space-time Neural Irradiance Fields (ST-NIF) is a differentiable volume rendering method that represents a dynamic scene as a 4D implicit function mapping spatiotemporal coordinates $(x,t)$ to color and volume density. It solves the problem of free-viewpoint video synthesis from a single moving camera by regularizing the inherently under-constrained geometry of dynamic scenes. Unlike static NeRF variants, ST-NIF introduces empty-space and static-scene losses to prevent haze-like artifacts and disocclusion errors, respectively.

### Geometry Composition by Segmented Sampling
Geometry Composition by Segmented Sampling is a method for compositing inserted objects into a scene. It transforms sampling points from scene coordinates to object coordinates using the inserting position (translation and rotation) [S2]. The density is composited as a normalized sum of densities of corresponding points from the scene and object at the same position. The reflectance is composited as a weighted sum of reflectance values, where weights are the densities of the voxel particles [S2]. The final image is rendered using the composited density, reflectance, and shading [S2].

### HybridNeRF SDF Density Formulation
The HybridNeRF SDF Density Formulation computes density $\sigma_{\text{SDF}}(\mathbf{x})$ as $\beta(\mathbf{x})\Psi(f(\mathbf{x})\beta(\mathbf{x}))$, where $f(\mathbf{x})$ is the signed distance field output, $\beta(\mathbf{x})$ is the surfaceness parameter, and $\Psi$ is the CDF of a standard Laplace distribution [S1]. The Laplace CDF $\Psi(s)$ is defined piecewise: $\frac{1}{2} \exp(-s)$ if $s > 0$, and $1 - \frac{1}{2} \exp(s)$ if $s \leq 0$. Here $s = f(\mathbf{x})\beta(\mathbf{x})$ [S1]. The surfaceness field $\beta(\mathbf{x})$ is stored in a $512^3$ voxel grid and queried via nearest-neighbor interpolation [S1]. The parameter $\beta(\mathbf{x}) > 0$ determines the surfaceness of point $\mathbf{x}$, controlling how concentrated the density is around the zero-level set of $f$ [S1].

### SeaThru-NeRF
SeaThru-NeRF extends NeRFs to handle underwater scattering media by treating the medium as a semi-transparent entity with separate color and density parameters from opaque objects [S3]. It replaces the traditional single opaque object density $\sigma(t)$ with the sum of the object density $\sigma_{obj}(t)$ and the medium density $\sigma_{med}(t)$ [S3].

### Neural Proxy Rendering with Mixed Samplers
Neural Proxy Rendering with Mixed Samplers is a rendering pipeline that mixes a neural proxy sampler $S_p$ for animated objects and a neural scene sampler $S_c$ for static elements, using a neural texture for local surface appearance [S4, unofficial]. It separates the particle set $X$ into proxy set $X_p$ and scene set $X_c$ [S4, unofficial]. For each ray $r$, it finds the convex set $X_r$ bounded by the closest and farthest intersection points with the proxy mesh $M$ [S4, unofficial]. It uses a triangle intersection method to get Barycentric coordinates and computes the sampled proxy set $X_p$ for a batch of rays [S4, unofficial]. It renders the image ray by ray and trains with a photometric loss [S4, unofficial]. Unlike NeRF which uses global scene information, neural proxy uses local information (features from neural texture) sampled via Barycentric coordinates [S4, unofficial].

### Normal Smoothness Constraint
Normal Smoothness Constraint is an adaptive constraint that ensures continuity of estimated surface normals in flat regions while preserving sharp features by weighting the normal difference based on albedo similarity [S5]. It samples a perturbed point by adding uniform noise in the normalized 3D space with magnitude 0.01 to generate the neighbor point for $N_{near}$ [S5]. It computes an edge-aware weight mask $M_i$ from the albedo color difference $\tau = \| c_i - c_j \|_2$. If $\tau \le \tau_n = 0.15$, set $M_i = 1.0$; otherwise, set $M_i = 0.05$ [S5]. The loss is $L_{normalSM} = \frac{1}{N} \sum_{i=1}^{N} M_i \cdot \| N_{pi} - N_{near} \|$ [S5]. The weight $\gamma_{sm}$ is selected from $\{0.001, 0.005, 0.01\}$ [S5]. Over-smoothing across edges is prevented by weakening the constraint when local albedo differences indicate an edge [S5].

## Operating characteristics
*   **Memory:** Uses dense multi-resolution 3D grids ($128^3$ to $512^3$) and triplanes ($128^2$ to $8,192^2$). The exact memory footprint depends on the feature dimension per cell, but the summation strategy reduces it compared to concatenation [S1].
*   **Speed:** The use of triplanes and summed features aims for efficiency. The proposal network improves sampling efficiency [S1].
*   **Quality:** Handles aliasing via VR-NeRF techniques [S1]. Quality near fine objects and transparent structures can degrade if surfaceness is too high [S1].
*   **Limitations:** The method relies on the assumption that the scene can be well-represented by the hybrid grid/triplane structure. It may struggle with highly dynamic scenes without extensions like Space-time Neural Irradiance Fields [S1].

## Background
HybridNeRF was introduced in the paper "HybridNeRF: Efficient Neural Rendering via Adaptive Volumetric Surfaces" [S1]. It builds on the idea of using multi-resolution grids (like Instant NGP) and triplanes (like MVSNeRF) but combines them in a specific way with adaptive surfaceness for density estimation. The method was presented at CVPR 2024 [S1].
