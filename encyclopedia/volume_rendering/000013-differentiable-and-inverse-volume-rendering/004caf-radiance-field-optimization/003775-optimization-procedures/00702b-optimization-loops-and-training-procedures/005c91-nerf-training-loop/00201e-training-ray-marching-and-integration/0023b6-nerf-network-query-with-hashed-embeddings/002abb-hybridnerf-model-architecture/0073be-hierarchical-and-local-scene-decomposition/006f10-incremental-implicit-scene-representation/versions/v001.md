# Incremental Implicit Scene Representation

Also called: Incremental NeRF, Local Radiance Fields

## Overview
Incremental Implicit Scene Representation is a method for reconstructing large-scale scenes by dynamically allocating multiple local neural radiance fields (LR) as the camera moves, rather than optimizing a single global representation [S1]. It solves the problems of memory constraints and convergence to local minima inherent in global NeRF approaches for long sequences [S1]. It differs from global NeRF by using a sliding window of local fields and Vector-Matrix decomposition, reducing space complexity from cubic $O(n^3)$ to square $O(n)$ [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A sequence of $M$ monocular images $\{I_i\}_{i=1}^M$ and their corresponding estimated depth maps $\{D_i\}_{i=1}^M$. Camera intrinsics are assumed known or calibrated.
*   **Outputs:** A set of $n$ local radiance fields $\{\text{LR}_{\theta_1}^1, \dots, \text{LR}_{\theta_n}^n\}$ and optimized camera poses, capable of rendering novel views $\{\mathbf{c}, \sigma\}$ [S1].

**Data Structures:**
1.  **Local Radiance Field Index ($j$):** Integer tracking the current local field.
2.  **Pose Indices ($p, q$):** Integers defining the sliding window of frames $[p, q]$ optimized for the current local field. $P$ is the total number of frames.
3.  **Camera Poses $\{R, T\}$:** A list of rotation matrices and translation vectors.
4.  **Network Parameters $\theta_j$:** Weights for the $j$-th local radiance field.
5.  **3D Feature Grid $\mathcal{G}$:** Factorized using Vector-Matrix (VM) decomposition. For each local field, the grid is stored as:
    *   Vectors $\mathbf{v}_r^X, \mathbf{v}_r^Y, \mathbf{v}_r^Z$ for axes $X, Y, Z$.
    *   Matrices $\mathbf{M}_r^{YZ}, \mathbf{M}_r^{XZ}, \mathbf{M}_r^{XY}$ for the cross-terms.
    *   $R$ is the number of rank components.
    *   Storage size is proportional to $O(n)$ rather than $O(n^3)$ [S1].

**Algorithm Steps:**
1.  **Initialization:**
    *   Set local field index $j = 1$.
    *   Set pose start index $p = 1$ and current frame index $q = 1$.
    *   Initialize poses $\{R, T\}_{p..q}$ as identity matrices.
    *   Initialize parameters $\theta_j$ for the first local radiance field $\text{LR}_{\theta_1}^1$ [S1].

2.  **Optimization Loop:**
    *   While $q < P$ (total frames):
        *   Initialize iteration counter $m = 0$.
        *   **Local Optimization:** While $m < 100$:
            *   Optimize parameters $\theta_j$ using the current frame $I_q$ and depth $D_q$ [S1].
            *   Increment $m$.
        *   **Sliding Window Expansion:**
            *   While the pose of frame $q$ is within the boundary $\text{Bound}_j$ of the current local field:
                *   Increment $q$.
                *   Append the new pose $\{R, T\}_q$ as a copy of $\{R, T\}_{q-1}$ (initial guess) [S1].
                *   Jointly optimize poses $\{R, T\}_{p..q}$ and local radiance field parameters $\theta_j$ [S1].
        *   **Field Switching:**
            *   If $q < P$:
                *   Increment local field index $j \leftarrow j + 1$.
                *   Initialize new local radiance field $\theta_j$ [S1].
                *   Set the center of the new field $t_j = t_q$ (centered around the last pose) [S1].
                *   Increment start index $p \leftarrow p + n$ (where $n$ is the number of frames skipped, effectively stopping consideration of frames in the previous local field) [S1].
                *   Freeze network parameters and poses of the previous field $\theta_{j-1}$ to decrease memory usage [S1].

3.  **Termination:**
    *   Repeat until all frames are registered ($q = P$) [S1].

**Ray Marching and Integration:**
For rendering, rays $\mathbf{r}$ are generated using the camera intrinsic matrix and pose: $\mathbf{r} = \mathbf{x}_i + t \mathbf{d}_i$, where $\mathbf{x}_i$ is the camera center and $\mathbf{d}_i$ is the direction [S1]. Points $\mathbf{x}_i$ are sampled along the rays. The local radiance field $\mathcal{F}_\Theta$ queries these points: $\mathcal{F}_\Theta: (\mathbf{x}_i, \mathbf{d}_i) \rightarrow (\mathbf{c}_i, \sigma_i)$ [S1]. The final color $\hat{\mathbf{C}}(\mathbf{r})$ is computed via volume rendering:

$$
\hat{\mathbf{C}}(\mathbf{r}) = \sum_{i=1}^N T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i
$$

where $\delta_i$ is the distance between samples, and the transmittance $T_i$ is:

$$
T_i = \exp \left( - \sum_{j=1}^i \sigma_j \delta_j \right)
$$

**Feature Interpolation:**
To query the factorized grid $\mathcal{G}$, tri-linear interpolation is performed directly on the vector/matrix factors rather than recovering eight individual tensor elements. This reduces computation and memory costs [S1]. The grid representation is defined as:

$$
\mathcal{G} = \sum_{r=1}^R \mathbf{v}_r^X \circ \mathbf{M}_r^{YZ} + \mathbf{v}_r^Y \circ \mathbf{M}_r^{XZ} + \mathbf{v}_r^Z \circ \mathbf{M}_r^{XY}
$$

where $\circ$ denotes the outer product or appropriate tensor contraction depending on implementation, and $\mathbf{v}$ are vectors for XYZ axes [S1].

**Pseudocode:**

```python
def incremental_implicit_scene_representation(images, depths, intrinsics, total_frames P):
    # Initialization
    j = 1
    p = 1
    q = 1
    poses = [IdentityPose()] * P # Pre-allocate or append
    poses[0] = IdentityPose()
    local_fields = []
    
    # Initialize first local field
    theta_j = InitializeLR()
    local_fields.append(theta_j)
    
    while q < P:
        # Local optimization for current frame
        for m in range(100):
            theta_j = Optimize(theta_j, images[q], depths[q])
            
        # Expand window while within bounds
        while IsWithinBound(poses[q], local_fields[j-1]):
            q += 1
            if q < P:
                # Append pose as copy of previous
                poses[q] = CopyPose(poses[q-1])
            
            # Joint optimization of poses and field
            poses[p:q+1], theta_j = JointOptimize(
                poses[p:q+1], 
                theta_j, 
                images[p:q+1], 
                depths[p:q+1]
            )
            
        # Switch to new local field if frames remain
        if q < P:
            j += 1
            theta_j = InitializeLR()
            local_fields.append(theta_j)
            
            # Center new field around last pose
            t_j = poses[q].translation
            
            # Skip frames from previous field consideration
            p = p + n # n is a hyperparameter for skip count
            
            # Freeze previous field
            local_fields[j-2] = Freeze(local_fields[j-2])
            
    return local_fields, poses

def query_local_field(theta, point, direction):
    # Query factorized grid
    feature = InterpolateFactorizedGrid(theta.grid, point)
    return theta.network(feature, direction)
```

## Operating characteristics
*   **Complexity:** Space complexity is reduced from cubic $O(n^3)$ to square $O(n)$ due to Vector-Matrix decomposition of the 3D feature grid [S1].
*   **Memory Usage:** Memory usage is decreased by freezing and discoring supervisory frames that are no longer needed once the camera moves beyond the boundary of the current local radiance field [S1].
*   **Performance:** On Tanks and Temples datasets, the method achieves higher PSNR compared to NoPe-NeRF and LocalRF [S1].
*   **Strengths:** Avoids local minima in large-scale scenes; handles long sequences efficiently; reduces memory footprint.
*   **Limitations:** Requires depth estimation (monocular depth network); boundary definition for local fields is critical; freezing parameters may prevent global consistency corrections.

## Background
*   **Origin:** Proposed in 2025 by authors addressing large-scale scene reconstruction from monocular cameras [S1].
*   **Context:** Existing implicit scene representations (like global NeRF) struggle with large-scale scenes due to memory constraints and local minima convergence [S1]. This method builds on the concept of local radiance fields [8] but introduces an incremental framework with joint depth, pose, and scene optimization [S1].
*   **Usage:** Used for novel view synthesis in large-scale environments, such as those found in robotics or autonomous driving scenarios [S1].
