# Sparsesat-NeRF
Also called: SpS-NeRF

## Overview
Sparsesat-NeRF is a neural radiance field optimization method for sparse-view satellite imagery that integrates dense depth supervision derived from Semi-Global Matching (SGM) to resolve reconstruction ambiguities [S1]. Unlike standard NeRF or Sat-NeRF, which rely on hierarchical coarse/fine models with importance sampling, Sparsesat-NeRF employs a single coarse network with a hybrid ray sampling strategy that uses random samples for global structure and guided Gaussian samples around depth priors for local geometry [S1]. It explicitly models input depth uncertainty to weight the depth loss and control the sampling distribution, enabling robust training with as few as two or three input images [S1].

## How it works
### Inputs and Outputs
**Inputs:**
*   $N$ input satellite images with refined RPC camera poses [S1].
*   $N$ low-resolution depth maps (downsampled by factor $2^{-2}$) and corresponding cross-correlation similarity maps generated via SGM [S1].
*   Scene envelope defined by near ($t_n$) and far ($t_f$) planes [S1].

**Outputs:**
*   Optimized neural radiance field parameters (density $\sigma$ and color $c$) [S1].
*   Novel view images and depth maps [S1].

### Data Structures
The method does not define unique persistent data structures beyond standard neural network weights and the pre-computed depth/similarity maps [S1]. The depth map $D_{input}$ and similarity map $corr$ are indexed by pixel coordinates $(u, v)$ [S1].

### Numbered Steps
1. **Pre-processing:** Refine RPC camera poses using bundle adjustment [S1]. For each of the $N$ input images, run an independent SGM algorithm to generate a low-resolution depth map $D_{input}(u,v)$ and a cross-correlation similarity map $corr(u,v)$ [S1]. If SGM depths are unavailable, substitute with a coarse global DEM (e.g., SRTM) and set $corr(u,v)$ to a constant value [S1].
2. **Ray Casting and Sampling:** For each training ray $r$, divide the total samples into two groups of equal cardinality $N_{sample} = 64$ [S1]. Group 1 (Random) samples $N_{sample}$ points uniformly at random within the scene envelope $[t_n, t_f]$ [S1]. Group 2 (Guided) samples $N_{sample}$ points based on a Gaussian distribution centered on a depth prior [S1]. If the pixel has valid input depth during training, draw from $\mathcal{N}(D_{input}(r), \Sigma(r))$ [S1]. If the pixel lacks input depth (occlusion) or during testing, draw from $\mathcal{N}(D(r), S(r))$, where $D(r)$ is the predicted depth and $S(r)$ is the predicted standard deviation [S1].
3. **Network Query:** Query the coarse neural network at each sample point $x_i$ along ray $r$ to obtain density $\sigma_i$ and color $c_i$ [S1].
4. **Volume Rendering:** Compute opacity $\alpha_i$ and transmittance $T_i$ for each sample [S1]:
   $$ \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
   $$ T_i = \prod_{j=1}^{i-1} (1 - \alpha_j) $$
   where $\delta_i = t_{i+1} - t_i$ is the distance between samples [S1]. Render the final color $C(r)$:
   $$ C(r) = \sum_{i=1}^{N} T_i \alpha_i c_i $$
   [S1]
5. **Depth Prediction and Uncertainty Estimation:** Compute the predicted depth $D(r)$ along the ray:
   $$ D(r) = \sum_{i=1}^{N} T_i \alpha_i t_i $$
   [S1] Compute the predicted standard deviation $S(r)$ of the sample distribution:
   $$ S(r)^2 = \sum_{i=1}^{N} T_i \alpha_i (t_i - D(r))^2 $$
   [S1] Compute the input uncertainty $\Sigma(r)$ from the similarity map:
   $$ \Sigma(r) = \gamma \cdot (1 - corr(r)) + m $$
   where $\gamma = 1.0$ and $m = 10^{-4}$ [S1].
6. **Loss Computation:** Compute the mean squared error between rendered color $C(r)$ and ground truth color $\hat{C}(r)$ over all rays $R$ [S1]:
   $$ L_{color}(r) = \| C(r) - \hat{C}(r) \|^2 $$
   $$ L_{color} = \sum_{r \in R} L_{color}(r) $$
   [S1] Define a subregion $R_{sub}$ for each ray where the depth loss is active. The condition for inclusion in $R_{sub}$ is:
   $$ S(r) > \Sigma(r) \quad \text{OR} \quad |D(r) - D_{input}(r)| > \Sigma(r) $$
   [S1] Compute the weighted depth loss over $R_{sub}$:
   $$ L_{depth}(r) = \sum_{r \in R_{sub}} corr(r) (D(r) - D_{input}(r))^2 $$
   [S1] Compute the total loss:
   $$ L = L_{color} + \lambda L_{depth} $$
   where $\lambda = 31$ for urban areas and $\lambda = 50$ for rural areas [S1].
7. **Optimization:** Update network parameters using gradient descent [S1]. Repeat for 30,000 iterations [S1].

### Pseudocode
```python
import torch
import torch.nn as nn

def compute_uncertainty(corr_map, gamma=1.0, m=1e-4):
    """Compute input uncertainty Sigma from cross-correlation similarity."""
    return gamma * (1.0 - corr_map) + m

def generate_rays(image_shape, camera_pose, intrinsics):
    """Standard pinhole camera ray generation [G].
    Returns origins (H, W, 3) and directions (H, W, 3)."""
    h, w = image_shape
    y, x = torch.meshgrid(torch.arange(h), torch.arange(w), indexing='ij')
    # Back-project pixel coordinates to camera space
    fx, fy = intrinsics[0, 0], intrinsics[1, 1]
    cx, cy = intrinsics[0, 2], intrinsics[1, 2]
    z_cam = torch.ones(h, w)
    x_cam = (x - cx) / fx
    y_cam = (y - cy) / fy
    rays_cam = torch.stack([x_cam, y_cam, z_cam], dim=-1)
    # Transform to world space using camera pose
    rays_dir = (camera_pose[:3, :3] @ rays_cam.view(-1, 3).T).T.view(h, w, 3)
    rays_dir = rays_dir / torch.norm(rays_dir, dim=-1, keepdim=True)
    rays_orig = camera_pose[:3, 3].expand(h, w, 3)
    return rays_orig, rays_dir

def volume_render(points, network, t_samples, near_plane, far_plane):
    """Query network and perform volume rendering."""
    sigma, color = network(points)
    # Compute deltas: delta_i = t_{i+1} - t_i
    deltas = torch.cat([t_samples[1:] - t_samples[:-1], torch.tensor([far_plane - t_samples[-1]])])
    # Compute opacity
    alpha = 1.0 - torch.exp(-sigma * deltas)
    # Compute transmittance: T_i = prod_{j=1}^{i-1} (1 - alpha_j)
    transmittance = torch.cumprod(1.0 - alpha, dim=0)
    transmittance = torch.cat([torch.ones_like(transmittance[:1]), transmittance[:-1]])
    # Render color
    weights = transmittance * alpha
    rendered_color = torch.sum(weights.unsqueeze(-1) * color, dim=0)
    # Render depth
    rendered_depth = torch.sum(weights * t_samples, dim=0)
    # Render depth variance S^2
    depth_var = torch.sum(weights * (t_samples - rendered_depth)**2, dim=0)
    return rendered_color, rendered_depth, depth_var

def train_step(images, depth_maps, corr_maps, camera_poses, intrinsics, 
               network, optimizer, near_plane, far_plane, lambda_depth=31):
    """Single training step."""
    optimizer.zero_grad()
    total_color_loss = 0.0
    total_depth_loss = 0.0
    N_random = 64
    N_guided = 64
    
    for image, depth_map, corr_map, cam_pose in zip(images, depth_maps, corr_maps, camera_poses):
        rays_o, rays_d = generate_rays(image.shape[:2], cam_pose, intrinsics)
        sigma_input = compute_uncertainty(corr_map)
        
        # Group 1: Random samples
        t_random = torch.rand(N_random) * (far_plane - near_plane) + near_plane
        points_random = rays_o + t_random.unsqueeze(1) * rays_d
        
        # Group 2: Guided samples
        valid_depth_mask = ~torch.isnan(depth_map)
        guided_points_list = []
        t_guided_list = []
        
        # Pixels with valid input depth
        if valid_depth_mask.any():
            d_input = depth_map[valid_depth_mask]
            s_input = sigma_input[valid_depth_mask]
            z = torch.randn(valid_depth_mask.sum(), N_guided)
            t_guided_valid = d_input.unsqueeze(1) + z * s_input.unsqueeze(1)
            t_guided_valid = torch.clamp(t_guided_valid, min=near_plane, max=far_plane)
            points_valid = rays_o[valid_depth_mask] + t_guided_valid.unsqueeze(2) * rays_d[valid_depth_mask]
            guided_points_list.append(points_valid)
            t_guided_list.append(t_guided_valid)
            
        # Pixels without input depth (occlusions) -> fallback to scene bounds midpoint [G]
        if (~valid_depth_mask).any():
            d_fallback = (near_plane + far_plane) / 2.0
            s_fallback = (far_plane - near_plane) / 4.0
            z = torch.randn((~valid_depth_mask).sum(), N_guided)
            t_guided_invalid = d_fallback + z * s_fallback
            t_guided_invalid = torch.clamp(t_guided_invalid, min=near_plane, max=far_plane)
            points_invalid = rays_o[~valid_depth_mask] + t_guided_invalid.unsqueeze(2) * rays_d[~valid_depth_mask]
            guided_points_list.append(points_invalid)
            t_guided_list.append(t_guided_invalid)
            
        guided_points = torch.cat(guided_points_list, dim=0)
        t_guided = torch.cat(t_guided_list, dim=0)
        
        # Combine and render
        all_points = torch.cat([points_random, guided_points], dim=0)
        all_t = torch.cat([t_random, t_guided], dim=0)
        rendered_color, rendered_depth, depth_var = volume_render(all_points, network, all_t, near_plane, far_plane)
        
        # Color Loss
        color_loss = torch.mean((rendered_color - image)**2)
        
        # Depth Loss over R_sub
        diff = rendered_depth - depth_map
        s_r = torch.sqrt(depth_var + 1e-8)
        sigma_r = sigma_input
        
        # R_sub condition: S(r) > Sigma(r) OR |D(r) - D_input(r)| > Sigma(r)
        mask_sub = (s_r > sigma_r) | (torch.abs(diff) > sigma_r)
        
        # Only compute depth loss where input depth is valid and mask_sub is true
        valid_and_active = valid_depth_mask & mask_sub
        if valid_and_active.any():
            active_diff = diff[valid_and_active]
            active_corr = corr_map[valid_and_active]
            depth_loss_val = torch.sum(active_corr * (active_diff**2))
        else:
            depth_loss_val = torch.tensor(0.0)
            
        total_color_loss += color_loss
        total_depth_loss += depth_loss_val
        
    loss = total_color_loss + lambda_depth * total_depth_loss
    loss.backward()
    optimizer.step()
```

### Parameters
*   **SGM Resolution Scale:** $2^{-2}$ (depth maps downsampled by factor of 4) [S1].
*   **Uncertainty Scaling $\gamma$:** $1.0$ [S1].
*   **Uncertainty Shift $m$:** $10^{-4}$ [S1].
*   **Depth Loss Weight $\lambda$:** $31$ for urban areas, $50$ for rural areas [S1].
*   **Initial Random Samples:** $64$ [S1].
*   **Guided Samples:** $64$ [S1].
*   **Batch Size:** $1024$ [S1].
*   **Training Iterations:** $30,000$ [S1].
*   **Learning Rate:** $10^{-5}$ (inherited from Sat-NeRF backbone) [S1].
*   **Learning Rate Decay:** $0.9$ [S1].

### Edge Cases and Pitfalls
*   **Depth Loss Inactivity:** The depth loss is inactive or clipped outside the subregion $R_{sub}$ defined by $S(r) > \Sigma(r)$ or $|D(r) - D_{input}(r)| > \Sigma(r)$ [S1]. This prevents the optimizer from being biased by inaccurate depth priors in occluded or low-texture regions [S1].
*   **Missing Depth:** If SGM depths are unavailable, the method falls back to a coarse global DEM (e.g., SRTM) with a constant similarity metric [S1].
*   **High-Resolution Depth Bias:** Using high-resolution SGM depths is avoided to prevent biasing the NeRF towards the SGM solution and to mitigate incomplete depth information at challenging surfaces (e.g., low texture) [S1].

## Operating characteristics
*   **Time Complexity:** Training takes approximately 2 hours on an NVIDIA GPU with 40GB RAM for 30,000 iterations [S1].
*   **Memory Complexity:** Uses a single coarse network, reducing memory overhead compared to hierarchical NeRF models that require coarse and fine networks [S1].
*   **Strengths:** Efficiently handles sparse satellite views by leveraging external depth priors [S1]. The guided sampling reduces the number of samples needed to resolve geometry compared to pure random sampling [S1].
*   **Limitations:** Relies on the quality of the input SGM depth maps [S1]. Performance degrades if depth maps are missing or inaccurate [S1]. The method uses only a coarse model, potentially lacking the fine-detail resolution of hierarchical NeRFs [S1].
*   **When to Use:** Suitable for sparse-view satellite imagery reconstruction where dense depth maps can be generated via SGM [S1].
*   **When Not to Use:** Unsuitable for scenarios requiring high-frequency detail resolution that might require a fine model, or where SGM depth generation is not feasible [S1].

## Background
Sparsesat-NeRF was introduced in 2023 by researchers presenting at the ISPRS Geospatial Week [S1]. It builds upon the Sat-NeRF architecture but adapts it for sparse satellite imagery by integrating dense depth supervision [S1]. The method draws inspiration from Roessle et al. (2022) for guided sampling and depth loss formulation [S1]. It is specifically designed to address the challenges of photo-realistic novel view synthesis from very few satellite images (2-3 views) [S1].
