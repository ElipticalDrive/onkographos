# Unified Metric Aggregation

Also called: Evaluation & Metric Computation, Evaluation Reporting, Global and Per-view Metric Aggregation

## Overview
Unified Metric Aggregation computes standard photorealistic metrics—Peak Signal-to-Noise Ratio (PSNR), Structural Similarity Index (SSIM), and Learned Perceptual Image Patch Similarity (LPIPS)—to quantify the fidelity of rendered images against ground truth references [S1, S2, unofficial][S4]. It addresses the problem of evaluating novel-view synthesis quality by balancing pixel-level precision (PSNR), structural integrity (SSIM), and perceptual similarity (LPIPS) [S1, unofficial][S3]. What sets it apart from raw error metrics is the inclusion of perceptual models (LPIPS) and structural models (SSIM) that correlate better with human judgment than simple pixel differences, while remaining computationally efficient enough for per-view evaluation during training loops [S2, unofficial]. It aggregates these per-view scores into global averages and per-view dictionaries for reporting [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Paired lists of rendered and ground truth (GT) images, typically in tensor format (Channel, Height, Width) normalized to $[0, 1]$ [S1, unofficial][S2, unofficial]. Configuration flags for extra metrics (SSIM, LPIPS) [S2, unofficial].
*   **Outputs:** Global metric averages (JSON/text) and per-view metric dictionaries (JSON) [S1, unofficial].

**Data Structures:**
*   **Per-view metrics:** A dictionary mapping image names to metric scores.
    *   Layout: `{"image_name": {"PSNR": float, "SSIM": float, "LPIPS": float}}` [S1, unofficial].
*   **Global metrics:** A dictionary mapping iteration keys to average metric scores.
    *   Layout: `{"ours_{iteration}": {"PSNR": float, "SSIM": float, "LPIPS": float}}` [S1, unofficial].

**Steps:**
1.  Initialize empty lists for per-view metric scores (PSNR, SSIM, LPIPS) [S1, unofficial].
2.  Determine evaluation interval if subsampling is used: `img_eval_interval = 1 if N_vis < 0 else max(test_dataset.all_rays.shape[0] // N_vis, 1)` [S2, unofficial].
3.  Iterate over paired render/GT paths, applying the evaluation interval if applicable [S1, S2, unofficial].
4.  Load RGB images, normalize to $[0, 1]$, and convert to CHW tensor format [S1, unofficial].
5.  Validate that rendered and GT images have matching shapes (H, W, C) [S1, unofficial].
6.  Compute Mean Squared Error (MSE): $\text{MSE} = \frac{1}{N} \sum_{i=1}^{N} (R_i - G_i)^2$, where $R_i$ is the rendered pixel value and $G_i$ is the GT pixel value [S2, unofficial].
7.  Compute PSNR: $\text{PSNR} = -10 \cdot \frac{\log(\text{MSE})}{\log(10)}$ [S2, unofficial].
8.  If `compute_extra_metrics` is true, compute SSIM and LPIPS [S2, unofficial].
    *   SSIM uses structural similarity models [S1, unofficial][S4].
    *   LPIPS requires specific input intensity scaling before feature comparison [S1, unofficial].
9.  Validate finiteness of computed metrics (check for NaN or Inf) [S1, unofficial].
    *   *Edge Case:* Handle zero MSE resulting in infinite PSNR by capping or flagging [S1, unofficial].
10. Store per-view results in the per-view dictionary [S1, unofficial].
11. After the loop, compute the arithmetic mean of each metric list for the global average [S1, unofficial].
12. Write global metrics and per-view JSON to disk [S1, unofficial].
13. (Optional) Save rendered RGB and depth images/videos for qualitative review [S2, unofficial].

**Pseudocode:**
```python
def compute_unified_metrics(rendered_images, gt_images, compute_extra_metrics=False):
    """
    Computes PSNR, SSIM, and LPIPS for paired images and aggregates results.
    rendered_images: List of tensors (C, H, W) in [0, 1].
    gt_images: List of tensors (C, H, W) in [0, 1].
    compute_extra_metrics: Boolean flag for SSIM/LPIPS.
    Returns: global_metrics (dict), per_view_metrics (dict)
    """
    per_view_psnr = []
    per_view_ssim = []
    per_view_lpips = []
    per_view_results = {}
    
    for i, (rendered, gt) in enumerate(zip(rendered_images, gt_images)):
        # 1. Validation
        if rendered.shape != gt.shape:
            raise ValueError(f"Shape mismatch at index {i}: {rendered.shape} vs {gt.shape}")
        
        # 2. MSE and PSNR
        mse = torch.mean((rendered - gt) ** 2)
        # Guard against log(0)
        if mse == 0:
            psnr = float('inf')
        else:
            psnr = -10.0 * torch.log(mse) / torch.log(torch.tensor(10.0))
        
        # 3. Extra Metrics
        ssim_val = None
        lpips_val = None
        
        if compute_extra_metrics:
            # SSIM computation (structural similarity)
            ssim_val = compute_ssim(rendered, gt)
            
            # LPIPS computation (perceptual similarity)
            # Requires specific intensity scaling as per LPIPS protocol
            lpips_val = compute_lpips(rendered, gt)
            
            per_view_ssim.append(ssim_val.item())
            per_view_lpips.append(lpips_val.item())
        
        # 4. Validation and Storage
        if not torch.isfinite(psnr):
            # Handle infinite PSNR (e.g., perfect match)
            psnr = float('inf')
            
        per_view_psnr.append(psnr.item())
        
        image_name = f"view_{i}"
        per_view_results[image_name] = {
            "PSNR": psnr.item(),
            "SSIM": ssim_val.item() if ssim_val is not None else None,
            "LPIPS": lpips_val.item() if lpips_val is not None else None
        }
        
    # 5. Aggregation
    global_psnr = sum(per_view_psnr) / len(per_view_psnr) if per_view_psnr else 0.0
    global_ssim = sum(per_view_ssim) / len(per_view_ssim) if per_view_ssim else None
    global_lpips = sum(per_view_lpips) / len(per_view_lpips) if per_view_lpips else None
    
    global_metrics = {
        "PSNR": global_psnr,
        "SSIM": global_ssim,
        "LPIPS": global_lpips
    }
    
    return global_metrics, per_view_results
```

## Subtopics

### [LPIPS Evaluation Protocol](4376-lpips-evaluation-protocol.md)
LPIPS is a perceptual similarity metric used in volume rendering evaluation to quantify reconstruction fidelity. It differs from pixel-wise metrics by requiring a specific input intensity scaling step before feature comparison. It is chosen when perceptual fidelity is more important than pixel-level accuracy. Link: [LPIPS Evaluation Protocol](4376-lpips-evaluation-protocol.md).

### [Metric Computation (PSNR, SSIM, LPIPS)](9928-metric-computation-psnr-ssim-lpips.md)
This method computes standard photorealistic metrics—Peak Signal-to-Noise Ratio (PSNR), Structural Similarity Index (SSIM), and Learned Perceptual Image Patch Similarity (LPIPS)—to quantify the fidelity of rendered images against ground truth references. It addresses the problem of evaluating novel-view synthesis quality by balancing pixel-level precision (PSNR), structural integrity (SSIM), and perceptual similarity (LPIPS). What sets this apart from raw error metrics is the inclusion of perceptual models (LPIPS) and structural models (SSIM) that correlate better with human judgment than simple pixel differences, while remaining computationally efficient enough for per-view evaluation during training loops. Link: [Metric Computation (PSNR, SSIM, LPIPS)](9928-metric-computation-psnr-ssim-lpips.md).

### Evaluation Reporting
This variant extends standard metric computation to include performance and size metrics for real-time applications. It reports PSNR, SSIM, and LPIPS, but also includes the size of resulting splats in MB and rendering speed on specific hardware platforms (standalone PC, PC-VR, mobile VR) [S3]. It is chosen when evaluating the practical deployability of a method in VR or real-time contexts.

### Quantitative Evaluation Metrics
This variant includes temporal metrics for dynamic scene evaluation. It reports PSNR, SSIM, and LPIPS, but also includes temporal Optical Flow (tOF) and temporal Perceptual Loss (tLP) [S4]. tOF examines errors in motion by comparing optical flow to ground truth, and tLP measures perceptual distance as the change in LPIPS between consecutive frames [S4]. It is chosen when evaluating dynamic scene reconstruction consistency.

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of views $N$ and pixels $P$. PSNR is $O(P)$. SSIM is $O(P \cdot K^2)$ where $K$ is the kernel size. LPIPS is $O(P \cdot C \cdot L)$ where $L$ is the number of layers in the perceptual network [S1, S2, unofficial][S4].
*   **Memory Complexity:** $O(P)$ for storing intermediate tensors per view. Global aggregation is $O(1)$ relative to $N$ if streaming means are used, or $O(N)$ if storing all per-view scores.
*   **Measured Performance:** On KITTI reconstruction, NSG achieved PSNR 26.66, SSIM 0.806, LPIPS 0.186, tOF 0.765×10^6, tLP 0.246×100 [S4]. On KITTI novel composition, PSNR 25.11, SSIM 0.789, LPIPS 0.204 [S4].
*   **Strengths:** Provides a comprehensive view of quality (pixel, structure, perception). Standardized for comparison.
*   **Limitations:** LPIPS is computationally expensive. SSIM and LPIPS may not correlate perfectly with human judgment in all domains. Infinite PSNR can occur with perfect matches.
*   **When to use:** Standard evaluation of novel-view synthesis.
*   **When not to use:** Real-time feedback during training (too slow); use PSNR only for quick checks.

## Background
Originated from the need to standardize evaluation in NeRF and Gaussian Splatting communities. PSNR and SSIM are traditional image quality metrics. LPIPS was introduced to address the limitations of pixel-wise metrics in correlating with human perception [S1, unofficial][S4]. The unified aggregation approach combines these into a single reporting pipeline, often implemented in evaluation scripts for frameworks like TensoRF and Advanced3DGS [S1, S2, unofficial]. It has been extended to include temporal metrics for dynamic scenes (tOF, tLP) [S4] and performance metrics for VR applications [S3].
