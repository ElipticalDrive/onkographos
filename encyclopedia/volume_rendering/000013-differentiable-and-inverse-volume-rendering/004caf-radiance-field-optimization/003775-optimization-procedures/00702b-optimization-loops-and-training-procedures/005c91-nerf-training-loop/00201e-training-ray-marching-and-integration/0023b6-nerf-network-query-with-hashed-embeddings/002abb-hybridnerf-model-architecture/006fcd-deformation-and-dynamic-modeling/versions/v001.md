# Deformation and Dynamic Modeling

Also called: Dynamic NeRF, Space-Time NeRF, Deformation Fields, Canonical Space Deformation

## Overview
Deformation and Dynamic Modeling extends static radiance field representations to handle temporal changes, enabling the reconstruction and rendering of dynamic 3D scenes from video inputs [S1, unofficial][S2, unofficial]. It solves the problem of under-constrained geometry in dynamic scenes by introducing time as an explicit input and using deformation fields, scene flow, or canonical space mappings to align temporal observations [S1, unofficial][S2, unofficial]. Unlike static NeRF variants, these methods explicitly model motion, distinguishing themselves from siblings like [Relighting and Shading](17925-relighting-and-shading.md) which handle lighting changes, or [View Synthesis and Morphing](17926-view-synthesis-and-morphing.md) which may focus on interpolation without explicit physical motion modeling.

## Shared principles
All methods in this family share the core mechanism of canonical space deformation. A static set of 3D primitives (either volumetric samples or Gaussian splats) $\mathcal{G}_{canon}$ is defined in a canonical coordinate system, storing base parameters: mean $\boldsymbol{\mu}_i \in \mathbb{R}^3$, rotation $\mathbf{q}_i \in \mathbb{R}^4$ (unit quaternion), scale $\mathbf{s}_i \in \mathbb{R}^3$, opacity $\sigma_i$, and spherical harmonics coefficients $\mathbf{c}_{SH,i}$ [G]. For a given time $t$, a deformation function $D$ predicts offsets $(\delta\boldsymbol{\mu}, \delta\mathbf{q}, \delta\mathbf{s})$ based on the canonical position and time [G]. The time-varying parameters are computed as:
$$ \boldsymbol{\mu}_i(t) = \boldsymbol{\mu}_i + \delta\boldsymbol{\mu} $$
$$ \mathbf{s}_i(t) = \mathbf{s}_i + \delta\mathbf{s} $$
$$ \mathbf{q}_i(t) = \text{Normalize}(\mathbf{q}_i \otimes \delta\mathbf{q}) $$
where $\otimes$ is quaternion multiplication and normalization prevents drift [G]. The deformation network $D$ typically takes spatial embeddings of canonical positions and temporal embeddings of time $t$ as input [G]. Rendering uses standard differentiable rasterization or volume integration with the updated primitives, camera pose, and time $t$ [G]. Optimization minimizes photometric loss $\mathcal{L} = \mathcal{L}_{rec} + \lambda \mathcal{L}_{reg}$, updating Gaussian parameters and network weights via SGD [G].

## Subtopics

### [Space-time Neural Irradiance Fields](17161-space-time-neural-irradiance-fields.md)
Space-time Neural Irradiance Fields (ST-NIF) represents a dynamic scene as a 4D implicit function mapping spatiotemporal coordinates $(x,t)$ to color and volume density. It solves the problem of free-viewpoint video synthesis from a single moving camera by regularizing the inherently under-constrained geometry of dynamic scenes. Unlike static NeRF variants, ST-NIF introduces empty-space and static-scene losses to prevent haze-like artifacts and disocclusion errors, respectively.

### [Dynamic NeRF](21867-dynamic-nerf.md)
Dynamic NeRF is a variation of NeRF designed to operate on dynamic 3D objects by explicitly considering rigid and non-rigid motion of the target. It constructs a 3D model based on a camera moving around the object, extending the static radiance field representation to handle temporal changes. It sets itself apart from static NeRF by introducing time as an explicit input and using deformation or flow fields to map canonical representations to deformed scenes.

### [Neural Scene Flow Fields (NSFF)](21905-neural-scene-flow-fields-nsff.md)
Neural Scene Flow Fields (NSFF) is a dynamic NeRF method that handles temporal consistency in monocular video by explicitly predicting 3D scene flow and disocclusion weights. It solves the problem of rendering coherent free-viewpoint videos from single-camera input by regularizing the radiance field with optical flow priors, distinguishing itself from methods that simply append time as an input channel.

### [Gaussian Splatting Deformation](22469-gaussian-splatting-deformation.md)
Gaussian Splatting Deformation extends static 3D Gaussian Splatting to dynamic scenes by modeling time-dependent geometric and appearance parameters, solving the problem of reconstructing and rendering moving subjects from multi-view video [G]. It sets itself apart from sibling methods by decomposing the 4D representation into a static canonical set of Gaussians and a deformation function that predicts their state at any time $t$, distinguishing it from [Space-time Neural Irradiance Fields](17161-space-time-neural-irradiance-fields.md) which use neural fields, [Dynamic NeRF](21867-dynamic-nerf.md) which uses volumetric ray marching, and [Neural Scene Flow Fields (NSFF)](21905-neural-scene-flow-fields-nsff.md) which predicts explicit scene flow vectors [G].

#### Unified Static-Dynamic Representation
- [S2, unofficial] A unified representation for static and dynamic scenes where static scenes are treated as a zero-motion special case of the dynamic representation, allowing shared appearance, compression, density-control, and rendering pipelines.

#### Explicit Deformation Field
- [S3, unofficial] Uses a separate deformation field that can map from the deformed space to a canonical space where the NeRF is embedded.
- [S3, unofficial] This can be thought of as space warping or scene flow.
- [S3, unofficial] Shoot straight rays into deformed space.
- [S3, unofficial] Bend them into the canonical scene, usually by regressing per-point offsets for points on the straight ray using a coordinate-based MLP that is conditioned on the deformation.

#### STaR (Scene Decomposition)
- [S4, unofficial] A method that takes multi-view RGB videos as input and decomposes the scene into a static and a dynamic volume.
- [S4, unofficial] Currently only supports one object in motion.

#### NeRF with Deformation Fields
- [S4, unofficial] A method that uses a deformation MLP to model scene flow and integrates it across time to obtain the final deformation.

#### DNRF
- [S4, unofficial] A method focusing on 4D avatars that imposes a strong inductive bias by including a deformable face model into the pipeline.

#### Skeleton-NeRF
- [S5, unofficial] A method for 3D reconstruction and representation of human bodies developed based on traditional human armature animation deformation, trained based on a blending weight field that produces a deformation field.
- [S5, unofficial] For each frame t, extract a query point x in the observation space.
- [S5, unofficial] Infer the blend weight w(x) for point x using a neural blend weight field conditioned by a latent code Ψ_t.
- [S5, unofficial] Process in canonical space: Input appearance code c_t and viewing direction v into the NeRF network.
- [S5, unofficial] NeRF network outputs rendered volume, density, and color.
- [S5, unofficial] Use the neural blend weight field w_canonical(x') network to learn the animation of NeRF in canonical space to gain dynamic rendering.
- [S5, unofficial] x' = Σ_{i=1}^n w_i(x) T_i x, where x' is the transformed point in canonical space, w_i(x) is the blend weight, and T_i represents the viewing direction/transformation.

#### Neural Scene Flow Fields
- [S6, unofficial] A method to model dynamic scenes as time-varying continuous functions of appearance, geometry, and 3D scene motion.

## Background
The concept of dynamic neural radiance fields emerged shortly after the introduction of static NeRF. Early works like Space-Time Neural Irradiance Fields (ST-NIF) [S1, unofficial] and NeRFlow [S4, unofficial] demonstrated that time could be incorporated as an additional input dimension. Subsequent methods such as D-Deformable NeRF (D-NeRF) [S3, unofficial] and Nerfies [S4, unofficial] introduced explicit deformation fields to map between canonical and deformed spaces, improving controllability and handling non-rigid motion. The field has since expanded to include Gaussian Splatting variants [S1, unofficial][S2, unofficial] and specialized applications like avatar reconstruction (DNRF [S4, unofficial], Skeleton-NeRF [S5, unofficial]).
