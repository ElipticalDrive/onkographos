# NeRF-style Volume Rendering Integrator

Also called: NeRF forward raymarching, NeRFIntegrator

## Overview
This method implements a simplified NeRF-style volume rendering integrator that accumulates emission along a ray through a medium, backed by a dense grid instead of a neural network, with no direction-dependent emission [S1, unofficial]. It differs from its sibling [NeRF Rendering (Alpha Compositing)](5124-nerf-rendering-alpha-compositing.md) by explicitly managing ray-marching state (throughput, step indices) and supporting primal/dual mode differentiation for inverse rendering tasks [S1, unofficial].

## How it works
**Inputs:**
- Ray $r(t) = o + td$ with near/far bounds $[t_n, t_f]$.
- Medium exit intersection $t_{exit}$ (from a prior intersection step).
- Grid query function returning density $\sigma$ and emission $L_e$ at 3D coordinates.
- Parameters: `queries_per_ray` ($N$), `density_noise_std`, `jittering_enabled`, `activation`.

**Outputs:**
- Accumulated color $\hat{C}$.
- Optional depth or gradient information depending on primal/dual mode.

**Data Structures:**
- `throughput`: Scalar float, initialized to 1.0. Represents accumulated transmittance $T$.
- `weights_sum`: Scalar float, initialized to 0.0. Represents $\sum w_i$.
- `result`: Vector/Scalar, initialized to 0. Accumulates $\sum w_i L_e$.
- `step_j`: Integer, initialized to 0. Current sample index.
- `t_a`: Float, initialized to 0. Previous sample position.
- `active_mask`: Boolean mask for rays still within the medium.

**Steps:**
1. **Initialization:** Set `result` = 0, `delta_L` = 0, `throughput` = 1. Determine primal mode. Intersect ray to find medium exit $t_{exit}$. Update `active_mask` to rays where $t_{exit}$ is valid.
2. **Step Size Calculation:** Calculate `step_size` using `step_size_for_marching(queries_per_ray, 0, t_{exit}, jittering_enabled)`. Initialize `t_a` = 0, `weights_sum` = 0, `step_j` = 0. Sample `jitter_sample` from sampler.
3. **Marching Loop:** While `still_walking` (mask):
    a. Calculate $t_b$ using `query_t_for_step(step_j + 1, step_size, jitter_sample, jittering_enabled)`.
    b. Calculate `actual_step` = $t_b - t_a$.
    c. Calculate `alpha_recip`:
       - If `step_j + 1 < queries_per_ray`: $\exp(-\sigma \cdot \text{actual\_step})$.
       - Else: 1.0.
       - Add $10^{-10}$ to `alpha_recip` for numerical safety [G].
    d. Calculate `weight` = $(1.0 - \text{alpha\_recip}) \cdot \text{throughput}$.
    e. Update `result`:
       - If primal: `result` += `weight` * $L_e$.
       - Else: `result` -= `weight` * $L_e$ [S1, unofficial].
    f. Increment `step_j`. Update `t_a` = $t_b$.
    g. Update `still_walking` mask: `step_j < queries_per_ray`.
    h. Update `throughput` *= `safe_alpha_recip` (where `safe_alpha_recip` is `alpha_recip` with safety epsilon).
    i. Update `weights_sum` += `weight`.
4. **Background Contribution:** Calculate `contribution` = $(1 - \text{weights\_sum}) \cdot L_e(t_{exit})$. Add to `result` for active pixels [S1, unofficial].

**Pseudocode:**
```python
def nerf_integrator(ray_o, ray_d, queries_per_ray=128, density_noise_std=0.0, 
                    jittering_enabled=True, activation='identity'):
    # 1. Initialization
    result = 0.0
    throughput = 1.0
    weights_sum = 0.0
    step_j = 0
    t_a = 0.0
    
    # Intersect ray to find medium exit
    t_exit = intersect_ray(ray_o, ray_d)
    active_mask = (t_exit > 0)
    
    if not active_mask.any():
        return 0.0, 0.0
        
    # 2. Step Size Calculation
    step_size = step_size_for_marching(queries_per_ray, 0, t_exit, jittering_enabled)
    jitter_sample = sampler.sample()
    
    # 3. Marching Loop
    still_walking = active_mask.clone()
    
    while still_walking.any() and step_j < queries_per_ray:
        # Calculate t_b
        t_b = query_t_for_step(step_j + 1, step_size, jitter_sample, jittering_enabled)
        actual_step = t_b - t_a
        
        # Query density and emission at t_b (simplified)
        pos = ray_o + t_b * ray_d
        sigma = query_density(pos)
        L_e = query_emission(pos)
        
        # Apply activation if needed
        if activation == 'relu':
            sigma = max(0, sigma)
            
        # Add noise if enabled
        if density_noise_std > 0:
            sigma += noise(density_noise_std)
            
        # Calculate alpha_recip
        if step_j + 1 < queries_per_ray:
            alpha_recip = exp(-sigma * actual_step)
        else:
            alpha_recip = 1.0
            
        # Safety epsilon
        alpha_recip += 1e-10
        
        # Calculate weight
        weight = (1.0 - alpha_recip) * throughput
        
        # Update result
        result += weight * L_e
        
        # Update throughput and weights_sum
        throughput *= alpha_recip
        weights_sum += weight
        
        # Update state
        step_j += 1
        t_a = t_b
        
        # Update mask
        still_walking = still_walking & (step_j < queries_per_ray)
        
    # 4. Background Contribution
    # Assuming background emission at exit
    L_bg = query_emission(ray_o + t_exit * ray_d)
    result += (1.0 - weights_sum) * L_bg
    
    return result, weights_sum
```

**Parameters:**
- `queries_per_ray`: Number of steps for ray marching. Default: 128 [S1, unofficial].
- `density_noise_std`: Standard deviation for noise added to density. Default: 0 [S1, unofficial].
- `jittering_enabled`: Boolean flag enabling jittering for step positions. Default: True [S1, unofficial].
- `activation`: Activation function type for density ('identity', 'relu'). Default: 'identity' [S1, unofficial].
- `hide_emitters`: Boolean flag to hide background emitters if weights_sum is zero. Default: Not specified [S1, unofficial].

**Edge Cases:**
- If `t_exit` is invalid, the ray is discarded.
- Numerical stability is maintained by adding $10^{-10}$ to `alpha_recip` [S1, unofficial].
- If `weights_sum` approaches 1, background contribution becomes negligible.

## Operating characteristics
- **Time Complexity:** $O(N)$ per ray, where $N$ is `queries_per_ray`.
- **Memory Complexity:** $O(1)$ per ray (excluding grid storage).
- **Strengths:** Simple implementation, differentiable, suitable for inverse rendering.
- **Limitations:** Dense grid may be memory-intensive for large scenes. No direction-dependent emission.

## Background
Originated from NeRF (Neural Radiance Fields) [S1, unofficial]. Used in unbiased inverse volume rendering frameworks.
