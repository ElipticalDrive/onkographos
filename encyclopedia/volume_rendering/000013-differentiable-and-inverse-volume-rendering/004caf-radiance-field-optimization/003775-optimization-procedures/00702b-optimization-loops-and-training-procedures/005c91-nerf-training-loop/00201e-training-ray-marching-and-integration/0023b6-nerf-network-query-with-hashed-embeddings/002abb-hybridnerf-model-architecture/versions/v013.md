# HybridNeRF Model Architecture

Also called: HybridNeRF

## Overview
HybridNeRF is a neural radiance field architecture that combines 3D feature grids with 2D triplanes to efficiently represent scene geometry and appearance [S1]. It solves the trade-off between the high memory cost of pure 3D voxel representations and the limited geometric expressiveness of pure 2D plane-based methods by using a hybrid query mechanism [S1]. It sets itself apart from its parent method, [NeRF Network Query with Hashed Embeddings](3107-nerf-network-query-with-hashed-embeddings.md), by replacing hash tables with structured multi-resolution 3D grids and triplanes, and from [VoxNeRF](8865-voxnerf.md) by explicitly separating volumetric density prediction (via 3D grids) from surface/geometry prediction (via triplanes and SDFs) [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D point $x \in \mathbb{R}^3$ and a viewing direction $d \in \mathbb{R}^3$.
*   **Output:** Color $c \in \mathbb{R}^3$ and signed distance $f \in \mathbb{R}$ (or density $\sigma$).

**Data Structures:**
1.  **3D Feature Grids:** A set of 3D voxel grids at 3 resolution levels: $128^3$, $256^3$, and $512^3$. Each cell stores a feature vector.
2.  **Triplanes:** A set of 2D feature planes at 7 resolution levels, ranging from $128^2$ to $8,192^2$. These are oriented along the XY, YZ, and XZ axes.
3.  **MLPs:** Two small Multi-Layer Perceptrons (MLPs): one for predicting color and one for predicting signed distance (or density).

**Parameters:**
*   $K=4$: Number of features fetched per level per grid/triplane.
*   $L_{3D}=3$: Number of 3D resolution levels.
*   $L_{2D}=7$: Number of triplane resolution levels.
*   Input dimension to MLP: $4K = 16$.
*   Spherical Harmonics degree: 4.

**Algorithm:**
1.  **Query 3D Grids:** For the input point $x$, sample $K=4$ features from each of the 3 3D resolution levels using trilinear interpolation. Let the features from level $l$ be $g_l(x)$.
2.  **Query Triplanes:** For the input point $x$, project it onto the three canonical planes (XY, YZ, XZ). For each plane, sample $K=4$ features from each of the 7 resolution levels using bilinear interpolation. Let the features from plane $p$ and level $l$ be $t_{p,l}(x)$.
3.  **Aggregate 3D Features:** Sum the features across all 3 levels of the 3D grids:
    $$ F_{3D} = \sum_{l=1}^{3} g_l(x) $$
4.  **Aggregate Triplane Features:** Sum the features across all 7 levels for each of the 3 planes, then sum the results of the three planes (or sum all 21 features directly, as the source states "sum the features across levels... and concatenate the summed features from the 3D grid to those from the 3 triplanes"). The source specifies summing across levels for triplanes separately. Let $T_p = \sum_{l=1}^{7} t_{p,l}(x)$ for each plane $p \in \{XY, YZ, XZ\}$. Then sum the plane features:
    $$ F_{2D} = \sum_{p \in \{XY, YZ, XZ\}} T_p $$
    *Note: The source states "concatenate the summed features from the 3D grid to those from the 3 triplanes". This implies $F_{2D}$ is the concatenation of the three summed plane vectors, or the sum of the three summed plane vectors. Given the input dimension is $4K=16$, and $K=4$, the 3D grid contributes $4$ features (if summed) or $12$ (if concatenated). The text says "fetch K=4 features per level... sum the features across levels... concatenate... to obtain a 4K=16 dimensional MLP input". If 3D grids contribute $K=4$ (summed) and triplanes contribute $3K=12$ (summed per plane then concatenated? or summed all?), the total is 16. So $F_{2D}$ has size $3K=12$. $F_{3D}$ has size $K=4$. Total 16.
5.  **Form MLP Input:** Concatenate $F_{3D}$ and $F_{2D}$:
    $$ V = [F_{3D}; F_{2D}] \in \mathbb{R}^{16} $$
6.  **Encode Direction:** Encode the viewing direction $d$ using spherical harmonics up to the 4th degree. Let this encoding be $SH(d)$.
7.  **Predict Color:** Pass $V$ and $SH(d)$ to the color MLP to predict $c$.
8.  **Predict Distance:** Pass $V$ to the distance MLP to predict signed distance $f$.
9.  **Aliasing:** Handle aliasing using the method from [VR-NeRF](link-to-vrnerf) due to the multi-resolution feature grid [S1].

**Pseudocode:**
```python
import numpy as np

def hybrid_nerf_query(x, d, grids_3d, triplanes_2d, color_mlp, dist_mlp):
    """
    x: (3,) 3D point
    d: (3,) viewing direction
    grids_3d: list of 3 numpy arrays of shape (128,128,128,4), (256,256,256,4), (512,512,512,4)
    triplanes_2d: list of 7 numpy arrays of shape (H,H,4) for each of 3 planes (XY, YZ, XZ)
                  Total 21 arrays.
    color_mlp: function taking (16 + SH_dim) -> (3,)
    dist_mlp: function taking (16,) -> (1,)
    """
    K = 4
    
    # 1. Query 3D Grids
    # Sum features across 3 levels
    F_3D = np.zeros(K)
    for grid in grids_3d:
        # Trilinear interpolation at x
        feat = trilinear_interpolate(grid, x)
        F_3D += feat
        
    # 2. Query Triplanes
    # There are 3 planes (XY, YZ, XZ) and 7 levels each
    # Reshape triplanes_2d to (3 planes, 7 levels, H, H, 4)
    # For simplicity, assume triplanes_2d is a list of 21 arrays ordered by plane then level
    F_2D = np.zeros(3 * K)
    
    plane_idx = 0
    for p in range(3): # XY, YZ, XZ
        plane_sum = np.zeros(K)
        for l in range(7):
            # Get the specific triplane array for this plane and level
            # Assuming triplanes_2d is flattened list [XY_l0, XY_l1, ..., YZ_l0, ...]
            triplane = triplanes_2d[p * 7 + l]
            # Project x to 2D coordinates for this plane
            if p == 0: # XY
                uv = x[:2]
            elif p == 1: # YZ
                uv = x[1:]
            else: # XZ
                uv = np.array([x[0], x[2]])
            
            # Bilinear interpolation at uv
            feat = bilinear_interpolate(triplane, uv)
            plane_sum += feat
        # Concatenate plane sums to F_2D
        F_2D[plane_idx * K : (plane_idx + 1) * K] = plane_sum
        plane_idx += 1
        
    # 3. Concatenate
    V = np.concatenate([F_3D, F_2D]) # Shape (16,)
    
    # 4. Encode Direction
    SH_d = spherical_harmonics_encoding(d, degree=4)
    
    # 5. Predict
    color = color_mlp(np.concatenate([V, SH_d]))
    dist = dist_mlp(V)
    
    return color, dist
```

## Subtopics

### [Shading Replacement for Relighting](6346-shading-replacement-for-relighting.md)
Shading Replacement for Relighting is a technique for object insertion that avoids inferring scene illumination by replacing the inserted object's shading with shading from existing scene points. It solves the problem of lighting inconsistency when compositing objects into neural radiance field (NeRF) scenes, where naive composition leads to unrealistic results due to varying illumination. It sets itself apart from direct relighting methods by not requiring explicit light source estimation, instead relying on the correlation between surface normals and shading in Lambertian scenes.

### [SeaThru-NeRF](11884-seathru-nerf.md)
SeaThru-NeRF is a neural radiance field method designed for visualizing and reconstructing scenes within dispersed scattering media, such as fog, haze, and subaquatic environments. It extends the standard NeRF formulation by treating the scattering medium as a semi-transparent entity with distinct color and density parameters, separate from opaque objects. This allows the model to distinguish between unblemished (directly illuminated) and backscattered segments of the scene, enabling the restoration of scene hue and 3D configuration in far-off areas that are typically obscured. It builds on [HybridNeRF Model Architecture](4842-hybridnerf-model-architecture.md) by incorporating specific scattering physics into the volume rendering integral.

### [Pano-NeRF](15013-pano-nerf.md)
Pano-NeRF is a method for geometry recovery and High Dynamic Range (HDR) novel view synthesis from sparse Low Dynamic Range (LDR) panoramic images. It models the scene using irradiance fields, which treat radiance as both a signal conveying lighting information and a light source illuminating other pixels, thereby increasing observation counts for geometry and leveraging irradiance-radiance attenuation for HDR reconstruction. It differs from standard radiance field methods by integrating surface rendering principles into the volume rendering framework to explicitly model inter-reflection and lighting interactions.

### [FastSR-NeRF](16574-fastsr-nerf.md)
FastSR-NeRF is a method that improves the rendering efficiency of Neural Radiance Fields (NeRF) on consumer-grade hardware by combining a lightweight NeRF model with a CNN-based super-resolution (SR) module. It solves the problem of high computational cost and long training times associated with high-resolution NeRF rendering by training the NeRF to produce low-resolution (LR) 3D-consistent features and upscaling them to high-resolution (HR) outputs. Unlike prior NeRF+SR methods that rely on complex training procedures, knowledge distillation, or high-resolution reference images, FastSR-NeRF requires no architectural changes to the NeRF backbone and uses a simple end-to-end training pipeline.

### [NeRFCodec](16590-nerfcodec.md)
NeRFCodec is an end-to-end compression framework for plane-based hybrid Neural Radiance Fields (NeRF) that integrates non-linear transform, quantization, and entropy coding to achieve memory-efficient scene representation. It solves the high storage requirements of hybrid representations by leveraging a pre-trained 2D neural image codec, adapted with content-specific parameters for each scene, to compress feature planes while maintaining high visual fidelity. Unlike methods that apply generic image codecs directly or use wavelet transforms, NeRFCodec modifies the encoder and decoder heads of the 2D codec to exploit inter-channel information in feature planes, achieving superior rate-distortion performance with a memory budget of approximately 0.5 MB per scene.

### [Ambiguity-Aware Depth Estimates](16981-ambiguity-aware-depth-estimates.md)
Ambiguity-Aware Depth Estimates is a technique for learning a multimodal distribution of depth estimates conditioned on a single input image, using an implicit generative model to capture inherent ambiguities in monocular depth estimation such as non-opaque surfaces and albedo-shading confusion. Unlike GANs which optimize for similarity to a single ground truth, this method uses conditional Implicit Maximum Likelihood Estimation (cIMLE) to prevent mode collapse by enforcing that all ground truth points are explained by at least one generated sample.

### [Space-time Neural Irradiance Fields](17161-space-time-neural-irradiance-fields.md)
Space-time Neural Irradiance Fields (ST-NIF) is a differentiable volume rendering method that represents a dynamic scene as a 4D implicit function mapping spatiotemporal coordinates $(x,t)$ to color and volume density. It solves the problem of free-viewpoint video synthesis from a single moving camera by regularizing the inherently under-constrained geometry of dynamic scenes. Unlike static NeRF variants, ST-NIF introduces empty-space and static-scene losses to prevent haze-like artifacts and disocclusion errors, respectively.

### [NeRF-based View Morphing](17781-nerf-based-view-morphing.md)
NeRF-based View Morphing (VM-NeRF) is a data augmentation technique that synthesizes intermediate training views from sparse input camera pairs using geometric constraints and disparity-based warping. It addresses the challenge of sparse training data in Neural Radiance Fields (NeRF) by generating photometrically consistent intermediate views, thereby improving reconstruction quality compared to semantic-based augmentation methods like DietNeRF.

### Geometry Composition by Segmented Sampling
Geometry Composition by Segmented Sampling is a method for compositing objects into NeRF scenes [S2]. It transforms sampling points from scene coordinates to object coordinates using the inserting position (translation and rotation) [S2]. It composites density via a normalized sum of densities of corresponding points from scene and object at the same position, and composites reflectance via a weighted sum of reflectance values, where weights are the densities of the voxel particles [S2]. It renders the final image following the standard volume rendering equation using the composited density, reflectance, and shading [S2].

### Neural Proxy Rendering with Mixed Samplers
Neural Proxy Rendering with Mixed Samplers is a rendering pipeline that mixes a neural proxy sampler $S_p$ for animated objects and a neural scene sampler $S_c$ for static elements, using a neural texture for local surface appearance [S3, unofficial]. It separates the particle set $X$ into proxy set $X_p$ and scene set $X_c$ [S3, unofficial]. For each ray $r$, it finds the convex set $X_r$ bounded by the closest and farthest intersection points with the proxy mesh $M$ [S3, unofficial]. It uses a triangle intersection method to get distance and Barycentric coordinates, determining the near and far intersection distances $t_n$ and $t_f$ [S3, unofficial]. It computes the full sampled proxy set $X_p$ for a batch of rays and renders the image ray by ray using a photometric loss [S3, unofficial]. Unlike NeRF which uses global scene information, neural proxy uses local information (features from neural texture) sampled via Barycentric coordinates [S3, unofficial]. Offset parameters $\epsilon, \epsilon^-$ are used to adjust the proxy volume [S3, unofficial].

### Normal Smoothness Constraint
Normal Smoothness Constraint is an adaptive constraint that ensures continuity of estimated surface normals in flat regions while preserving sharp features by weighting the normal difference based on albedo similarity [S4]. It samples a perturbed point by adding uniform noise in the normalized 3D space with magnitude 0.01 to generate the neighbor point for $N_{near}$ [S4]. It computes an edge-aware weight mask $M_i$ from the albedo color difference $\tau = \| c_i - c_j \|_2$. If $\tau \le \tau_n = 0.15$, $M_i = 1.0$; otherwise, $M_i = 0.05$ [S4]. The loss is $L_{normalSM} = \frac{1}{N} \sum_{i=1}^{N} M_i \cdot \| N_{pi} - N_{near} \|$ [S4]. The weight $\gamma_{sm}$ is selected from $\{0.001, 0.005, 0.01\}$ [S4]. The mask prevents undesired smoothing across structural breaks like roofs or walls [S4].

### FreeNeRF
FreeNeRF improves NeRF rendering performance with fewer samples through frequency regularization, achieving comparable performance to complex methods with minimal modifications [S5]. It introduces two regularization terms: frequency range regularization and near-camera density field penalties [S5]. It does not require additional pre-training or supervised signals and does not add additional computational cost [S5]. It achieves state-of-the-art performance on Blender, DTU, and LLFF datasets [S5].

### MixNeRF
MixNeRF is a method for creating fresh perspectives from infrequent inputs (sparse view synthesis) by replicating light using a mixing density model to effectively understand the combined RGB color distribution in light samples [S5]. It introduces an additional task estimating light depth, which is linked to the 3D scene’s geometric height, and enhances blending weights using the estimated ray depths [S5]. It surpasses other advanced techniques in training and inference effectiveness across numerous standard benchmark evaluations [S5].

### VM-NeRF
VM-NeRF addresses NeRF overfitting when dealing with limited viewpoints by using a View Morphing method to produce geometrically uniform image transitions [S5]. It eliminates the need for a pre-existing understanding of the scene’s structure by relying on projective geometry basics and seamlessly incorporates the process of generating geometric views into the conventional NeRF training [S5]. It enhances PSNR by 1.8 dB with eight perspectives and 1.0 dB with four perspectives compared to current techniques [S5].

### E2NeRF
E2NeRF learns sharp neural 3D representations from blurred images and event data by combining bio-inspired event camera and standard RGB camera inputs [S5]. It introduces blur rendering loss and event rendering loss to guide the network by modeling the actual blurring process and event generation process, and constructs an event-stream-based camera pose estimation framework [S5]. It effectively learns sharp NeRF from blurred images, especially in complex and low-light scenes [S5].

### LU-NeRF
LU-NeRF jointly estimates camera pose and scene representation by synchronizing locally unlocalized NeRFs [S5]. It employs a local-to-global learning framework, which first optimizes on a subset of local data (mini-scenes), brings the poses of these mini-scenes into a global reference frame through a robust pose synchronization step, and performs fine-grained optimization of the global poses and scenes [S5]. It succeeds even in the absence of a priori knowledge of the pose distribution [S5].

### StructNeRF
StructNeRF is a NeRF technique for indoor settings enhancing new view creation from limited inputs using structural indicators in multi-view inputs [S5]. It integrates structural indicators into self-guided depth estimation by limiting textured area shapes via patch-based multi-view coherent photometric loss, applies planar coherence loss to untextured areas to maintain three-dimensional coherent planes, and implements progressive training to reduce noise from limited depth point cloud in structure-from-motion (SfM) [S5].

### SHERF
SHERF is a generalizable human NeRF model for recovering animatable 3D humans from a single input image, forecasting ongoing varied depth assessments from each perspective [S5]. It uses conditional implicit maximum likelihood estimation (cIMLE) to address intrinsic uncertainty in single-eye depth estimation and presents a spatial sculpting loss technique to merge various theoretical depth maps across perspectives and distill them into a unified geometry aligning with all views [S5].

### CI-NeRF
CI-NeRF utilizes NeRF for volumetric rendering to deduce essential scene characteristics like diffuse albedo, surface normals, shadows, and lighting settings [S5]. It employs a CNN for forecasting interpretable and modifiable lighting parameters from an individual image, allowing physical interpretation of outdoor scene relighting through a unified image inference process [S5].

### IR-NeRF
IR-NeRF is a NeRF training method without camera poses that improves the robustness of pose estimation on real images by introducing implicit pose regularization [S5]. It constructs a scene codebook that implicitly captures the scene-specific camera pose distribution as a priori [S5]. It consistently outperforms GNeRF in terms of image quality metrics (PSNR, SSIM, and LPIPS) [S5].

### SparseNeRF
SparseNeRF addresses the problem of synthesizing new views from finite perspectives by extracting depth priors from pre-trained depth models or rough depth maps captured by consumer-grade depth sensors [S5]. It introduces local depth ordering and spatial continuity constraints to extract robust depth priors from rough depth maps [S5]. A pitfall is that it relies on pre-trained depth models or depth maps captured by consumer-grade sensors, the accuracy and quality of which can be limited by real-world conditions [S5].
