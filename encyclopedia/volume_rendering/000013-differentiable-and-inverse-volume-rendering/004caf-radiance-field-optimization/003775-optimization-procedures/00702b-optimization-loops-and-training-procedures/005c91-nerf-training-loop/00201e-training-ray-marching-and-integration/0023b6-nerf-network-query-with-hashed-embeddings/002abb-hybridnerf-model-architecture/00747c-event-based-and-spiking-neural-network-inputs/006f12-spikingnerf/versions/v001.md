# SpikingNeRF

Also called: SpikingNeRF: Making Bio-inspired Neural Networks See through the Real World

## Overview
SpikingNeRF is a method that aligns the temporal dimension of spiking neural networks (SNNs) with radiance rays to enable spike-based, multiplication-free NeRF rendering, reducing energy consumption for neuromorphic hardware [S1, unofficial]. It differs from standard differentiable rendering by replacing the continuous activation of Multi-Layer Perceptrons (MLPs) with spiking dynamics, where the geometric sequence of points along a ray is mapped to the temporal sequence of input spikes [S1, unofficial]. Unlike Liao et al. (2023), which uses an ANN with a post-processing function B-FIF, SpikingNeRF uses actual SNNs targeting neuromorphic hardware [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Camera poses, intrinsics, and training images.
*   **Output:** Rendered RGB images $\hat{C}(\mathbf{r})$ for given rays $\mathbf{r}$.

**Data Structures:**
1.  **Voxel Grids ($\mathbf{V}_\sigma, \mathbf{V}_f$):** Explicitly stored volumetric parameters.
    *   $\mathbf{V}_\sigma$: Stores density $\sigma$.
    *   $\mathbf{V}_f$: Stores embedded features $\mathbf{e}$.
    *   Layout: 3D grid indexed by spatial coordinates. Values are accessed via trilinear interpolation.
2.  **Spiking MLP (sMLP):** Implicitly yields volumetric color $\mathbf{c}$.
    *   Structure: Standard MLP layers replaced with spiking neuron models.
    *   Input shape: $[\text{batch}, \text{time}, c]$, where `time` corresponds to the sampled point index along the ray.
3.  **Masked Point Set ($A$):** A subset of sampled points retained for rendering based on thresholds.

**Parameters:**
*   $\lambda_1$: Predefined threshold for point weight $w_i$.
*   $\lambda_2$: Predefined threshold for point opacity $\alpha_i$.
*   Typical values: Not given in the sources.

**Steps:**

1.  **Ray Sampling and Masking:**
    For each ray $\mathbf{r}$, sample $K$ points $\mathbf{p}_i$ along the ray. Calculate intermediate weight $w_i$ and opacity $\alpha_i$ using standard volume rendering equations (derived from density $\sigma$).
    Define the active set $A$ for each ray:
    $$ A \triangleq \{i : w_i > \lambda_1, \alpha_i > \lambda_2\} $$
    Points not in $A$ are masked out to reduce computation [S1, unofficial].

2.  **Hybrid Feature Query:**
    For each point $\mathbf{p}_i \in A$:
    *   Query voxel grids to obtain density $\sigma_i$ and embedded feature $\mathbf{e}_i$:
        $$ \sigma_i = \text{act}(\text{interp}(\mathbf{p}_i, \mathbf{V}_\sigma)) $$
        $$ \mathbf{e}_i = \text{interp}(\mathbf{p}_i, \mathbf{V}_f) $$
    *   Here, $\text{interp}$ denotes trilinear interpolation and $\text{act}$ is an activation function (e.g., ReLU or shifted softplus) [S1, unofficial].

3.  **Time-Ray Alignment (TRA):**
    Pack the embedded features $\mathbf{e}_i$ for all active points in a batch.
    *   Original shape: $[\text{ray}, \text{pts}, c]$, where `ray` is the ray index and `pts` is the index of the sampled point along that ray.
    *   Reshape to match SNN temporal input: $[\text{batch}, \text{time}, c]$.
    *   The mapping aligns the geometric consecutiveness of the ray with the temporal continuity of the SNN:
        $$ \text{Input}_{MLP} := [\text{batch}, c] \Rightarrow [\text{ray}, \text{pts}, c] \Rightarrow [\text{batch}, \text{time}, c] := \text{Input}_{s_{MLP}} $$
    *   Each sampled point $\mathbf{p}_i$ is matched to a specific time step $t$ in the sMLP input [S1, unofficial].

4.  **Temporal Condensing-and-Padding (TCP):**
    Due to masking, the number of active points varies per ray, creating irregular tensor lengths.
    *   **Temporal Padding (TP):** Pad shorter ray sequences with zeros to ensure regular tensor shapes for GPU parallel training.
    *   **Temporal Condensing:** Condense the data distribution to form a denser structure, optimizing for hardware-friendly computation on neuromorphic accelerators and GPUs [S1, unofficial].

5.  **Spiking Inference:**
    Pass the aligned input $\text{Input}_{s_{MLP}}$ through the sMLP. The sMLP processes the spike trains addition-only (multiplication-free) to output the color $\mathbf{c}_i$ for each time step [S1, unofficial].

6.  **Volume Rendering Integration:**
    Compute the final color $\hat{C}(\mathbf{r})$ using the accumulated contributions from the active set $A$:
    $$ \hat{C}(\mathbf{r}) \approx \sum_{i \in A} w_i \alpha_i \mathbf{c}_i $$
    where $w_i$ and $\alpha_i$ are the pre-computed weights and opacities [S1, unofficial].

**Pseudocode:**

```python
def spiking_nerf_render(ray, voxel_grid_sigma, voxel_grid_feat, smlp, lambda1, lambda2):
    """
    Renders a single ray using SpikingNeRF.
    
    Args:
        ray: Ray origin and direction.
        voxel_grid_sigma: 3D voxel grid for density.
        voxel_grid_feat: 3D voxel grid for features.
        smlp: Spiking MLP model.
        lambda1: Weight threshold.
        lambda2: Opacity threshold.
        
    Returns:
        color: Rendered RGB color.
    """
    # 1. Sample points along the ray
    # Assume K samples are generated at positions p_0, ..., p_{K-1}
    # and depths t_0, ..., t_{K-1}
    positions = sample_points_along_ray(ray, num_samples=K)
    
    # 2. Query Voxel Grids for Density and Features
    # Interpolate from voxel grids
    densities = interpolate_voxel(positions, voxel_grid_sigma)
    features = interpolate_voxel(positions, voxel_grid_feat)
    
    # Apply activation to density
    densities = activation(densities) # e.g., softplus
    
    # 3. Compute Opacity and Weight for Masking
    # Standard volume rendering accumulation to get alpha and weight
    # This part typically requires forward accumulation
    alphas = compute_opacity(densities)
    weights = compute_weights(alphas)
    
    # 4. Masking
    # Identify active points based on thresholds
    active_indices = []
    for i in range(K):
        if weights[i] > lambda1 and alphas[i] > lambda2:
            active_indices.append(i)
            
    if not active_indices:
        return 0.0 # Or background color
        
    # 5. Extract Active Features
    active_features = features[active_indices]
    
    # 6. Time-Ray Alignment (TRA)
    # Reshape features to [1, len(active_indices), feature_dim]
    # This aligns the spatial sequence to the temporal dimension of SNN
    smlp_input = active_features.reshape(1, len(active_indices), -1)
    
    # 7. Spiking MLP Inference
    # The sMLP processes the input spike train over time steps
    # Output is color for each active point
    colors = smlp(smlp_input) # Shape: [1, len(active_indices), 3]
    colors = colors.squeeze(0) # Shape: [len(active_indices), 3]
    
    # 8. Volume Rendering Integration
    # Retrieve active weights and alphas
    active_weights = weights[active_indices]
    active_alphas = alphas[active_indices]
    
    # Accumulate color
    color = sum(active_weights[i] * active_alphas[i] * colors[i] for i in range(len(active_indices)))
    
    return color
```

**Edge Cases and Pitfalls:**
*   **Irregular Tensor Lengths:** Masking causes different rays to have different numbers of active points. This breaks standard GPU batch processing. TCP (Temporal Condensing-and-Padding) is required to handle this [S1, unofficial].
*   **Precision:** SNNs operate on spike trains. The transition from real-valued inputs to spikes requires careful encoding (TRA) to preserve geometric information without duplication [S1, unofficial].

## Subtopics

### Time-Ray Alignment (TRA)
A method to accommodate SNNs to NeRF rendering by retaining real-valued input data (like direct-encoding) but matching each sample along a ray to a corresponding time step without duplication-based filling [S1, unofficial]. It packs volumetric parameters (e.g., $e, v$) as input data with shape $[\text{ray}, \text{pts}, c]$, where `ray` is the ray index, `pts` is the sampled point index, and `c` is the channel index [S1, unofficial]. The input is reshaped to $[\text{batch}, \text{time}, c]$ for the sMLP [S1, unofficial]. TRA does not require input data pre-processing such as duplication (used in prior arts like Zhou et al. 2022) or Poisson generation (used in Garg et al. 2021) [S1, unofficial].

## Operating characteristics
*   **Energy Efficiency:** SpikingNeRF reduces energy consumption by an average of 70.79% compared to ANN baselines [S1, unofficial].
*   **Performance:** SpikingNeRF-D achieves 72.95% energy reduction with a 0.33 PSNR drop on the Tanks&Temples dataset [S1, unofficial].
*   **Hardware:** Designed for neuromorphic hardware accelerators, benefiting from addition-only, spike-driven computation [S1, unofficial].
*   **Complexity:** The hybrid representation (voxel grids + sMLP) reduces the querying burden on the MLP compared to pure NeRF [S1, unofficial].
*   **Limitations:** Requires handling irregular tensor lengths due to masking, necessitating TCP [S1, unofficial].

## Background
SpikingNeRF was proposed by researchers from the Institute of Automation, Chinese Academy of Sciences, and the University of Chinese Academy of Sciences [S1, unofficial]. It is the first work to accommodate SNNs to reconstruct 3D scenes (real RGB world) using neural radiance fields, making high-quality 3D rendering accessible to neuromorphic hardware [S1, unofficial]. It builds on the concept of hybrid volumetric representations (voxel grids for density/features, MLP for color) and the temporal accumulation process of SNNs inspired by primate fovea imaging [S1, unofficial].
