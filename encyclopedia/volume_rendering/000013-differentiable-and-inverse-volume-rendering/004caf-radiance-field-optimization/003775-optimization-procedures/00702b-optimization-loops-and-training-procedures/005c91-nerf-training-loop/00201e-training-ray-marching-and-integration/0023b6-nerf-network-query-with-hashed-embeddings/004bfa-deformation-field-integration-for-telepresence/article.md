# Deformation Field Integration for Telepresence

Also called: Dynamic Human Volume Rendering

## Overview
This method extends the FastNeRF architecture to support dynamic, expression-driven head avatars for telepresence by integrating a learnable deformation field network ($F_{deform}$) and a non-trainable skeletal deformation field ($F_{bone}$) into the ray marching process [S2, unofficial]. It solves the problem of rendering animatable 3D heads from static multi-view images by warping sample positions based on an expression vector before querying the radiance field [S2, unofficial]. It is distinguished from static NeRF variants by its explicit handling of temporal expression parameters and from other dynamic NeRF methods by its specific integration with the FastNeRF caching infrastructure and grid-based pruning [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A 3D sample position $\mathbf{p}$, an expression vector $\mathbf{e}$, and a viewing direction (implicit in the view-dependent network) [S2, unofficial].
*   **Outputs:** Volume density $\sigma$ and view-dependent color coefficients $(\mathbf{u}, \mathbf{v}, \mathbf{w})$ [S2, unofficial].

**Data Structures:**
1.  **Deformation Network ($F_{deform}$):** A 6-layer Multi-Layer Perceptron (MLP) with 64 units per layer [S2, unofficial]. It takes the encoded position and expression vector as input and outputs a 3D offset vector [S2, unofficial].
2.  **Skeletal Deformation Field ($F_{bone}$):** A non-trainable function that maps $\mathbf{p}$ and $\mathbf{e}$ to a deformed position based on 3D model bones (shoulders and neck) [S2, unofficial].
3.  **Position-Dependent Network ($F_{pos}$):** The FastNeRF position network [S2, unofficial]. It takes the deformed position and outputs $\sigma$ and $(\mathbf{u}, \mathbf{v}, \mathbf{w})$ [S2, unofficial]. It has 384 units per layer during training [S2, unofficial].
4.  **View-Dependent Network:** A 2-layer MLP with 32 units per layer, used for view-dependent color [S2, unofficial].
5.  **Sparse Volume (Pruning Cache):** A sparse 3D grid storing the minimum and maximum density values encountered for each grid cell around the face region [S2, unofficial].

**Numbered Steps:**
1.  **Positional Encoding:** Encode the input sample position $\mathbf{p}$ using the same positional encoding scheme as FastNeRF [S2, unofficial].
2.  **Skeletal Deformation:** Compute the bone-deformed position $\mathbf{p}_{bone} = \mathcal{F}_{bone}(\mathbf{p}, \mathbf{e})$ [S2, unofficial]. This step accounts for large rigid movements of the head and shoulders [S2, unofficial].
3.  **Deformation Field Query:** Compute the offset $\mathbf{o} = \mathcal{F}_{deform}(\mathbf{p}_{bone}, \mathbf{e})$ [S2, unofficial]. The network $F_{deform}$ is a 6-layer MLP with 64 units per layer [S2, unofficial].
4.  **Final Position:** Compute the warped position $\mathbf{p}_{warped} = \mathbf{p}_{bone} + \mathbf{o}$ [S2, unofficial].
5.  **Radiance Field Query:** Query the position-dependent network to get density and color features: $\{\sigma, (\mathbf{u}, \mathbf{v}, \mathbf{w})\} = \mathcal{F}_{pos}(\mathbf{p}_{warped})$ [S2, unofficial].
6.  **View-Dependent Color:** Use $(\mathbf{u}, \mathbf{v}, \mathbf{w})$ and the viewing direction to compute the final RGB color [S2, unofficial].

**Formulas:**
The composition of deformation fields and the position network is defined as [S2, unofficial]:
$$
\{\sigma, (\mathbf{u}, \mathbf{v}, \mathbf{w})\} = \mathcal{F}_{pos}(\mathcal{F}_{deform}(\mathcal{F}_{bone}(\mathbf{p}, \mathbf{e}), \mathbf{e}))
$$
where $\mathbf{e}$ is the expression vector [S2, unofficial].

The deformation network output is an offset applied to the position [S2, unofficial]:
$$
\mathbf{p}_{deform} = \mathcal{F}_{deform}(\mathbf{p}, \mathbf{e})
$$
Note: In the context of the full pipeline, this offset is added to the bone-deformed position [S2, unofficial].

The synthesized pixel color $C_\mathbf{r}$ is computed by marching a ray and accumulating radiance at sampled points between near and far bounds [S1]:
$$
C_\mathbf{r} = \sum_{i=1}^{N} T(p_i) \left[ (1 - e^{-\sigma_{p_i}\delta_{p_i}}) c_{p_i} \right]
$$
where $T(p_i) = e^{-\sum_{k=1}^{i-1} \sigma_{p_k}\delta_{p_k}}$ is the transmittance, $\delta(p_i) = p_{i+1} - p_i$ is the distance between adjacent samples, $c_{p_i}$ is the color at sample $i$, and $N$ is the number of sampled points on the ray [S1].

**Parameters:**
*   **Training Samples:** 64 samples in the coarse stage, 64 additional samples in the fine stage [S2, unofficial].
*   **Test Samples:** 43 samples in the coarse stage [S2, unofficial]. The fine stage is removed [S2, unofficial].
*   **Interpolation:** Additional samples are added by linearly interpolating between samples generated by the deformation network [S2, unofficial]. These interpolated samples are looked up in the FastNeRF cache [S2, unofficial].
*   **Pruning Samples:** 50 randomly chosen samples of $\mathbf{e}$ are used to populate the sparse volume [S2, unofficial].

**Pseudocode:**
> **Unverified code.** The code below did not pass a test run against a reference implementation, or no test fits it, so it may contain errors.

```python
import numpy as np

def query_deformation_field(p, e, F_deform, F_bone, F_pos):
    """Query radiance field with deformation for telepresence."""
    p_bone = F_bone(p, e)
    offset = F_deform(p_bone, e)
    p_warped = p_bone + offset
    sigma, uvw = F_pos(p_warped)
    return sigma, uvw

def compute_pruning_volume(grid_positions, F_deform, F_pos, num_e_samples=50, e_dim=32):
    """Pre-compute min/max density for grid-based pruning at test time."""
    sparse_volume = {}
    for idx, p_grid in enumerate(grid_positions):
        min_sigma = float('inf')
        max_sigma = float('-inf')
        for _ in range(num_e_samples):
            e_random = np.random.uniform(-1.0, 1.0, size=e_dim)
            # Pruning volume computation per evidence does not use F_bone
            offset = F_deform(p_grid, e_random)
            p_warped = p_grid + offset
            sigma, _ = F_pos(p_warped)
            if sigma < min_sigma:
                min_sigma = sigma
            if sigma > max_sigma:
                max_sigma = sigma
        sparse_volume[idx] = (min_sigma, max_sigma)
    return sparse_volume

def prune_and_query(p, e, sparse_volume, F_deform, F_bone, F_pos, cell_size=0.01, saturation_threshold=1e-3):
    """Query with pruning based on sparse volume."""
    idx = tuple(np.floor(p / cell_size).astype(int))
    if idx in sparse_volume:
        min_sigma, max_sigma = sparse_volume[idx]
        if max_sigma == 0:
            return None
        if min_sigma > saturation_threshold:
            return None
    p_bone = F_bone(p, e)
    offset = F_deform(p_bone, e)
    p_warped = p_bone + offset
    sigma, uvw = F_pos(p_warped)
    return sigma, uvw
```

**Edge Cases and Pitfalls:**
*   **Non-Linear Rays:** The deformation network changes sample positions along rays, meaning rays are no longer straight [S2, unofficial]. This prevents the use of hardware-accelerated ray tracing described in the main FastNeRF paper [S2, unofficial].
*   **Identity Constraint:** Without an L2 regularizer constraining $F_{deform}$ to be an identity transform for a neutral expression, training is unstable [S2, unofficial].
*   **Performance Limit:** The approach is limited to rendering 300x300 pixel images with a reduced sample count to maintain 30FPS [S2, unofficial].
*   **Test-Time Optimization:** $F_{bone}$ is removed at test-time to improve performance, relying solely on $F_{deform}$ and caching for dynamic regions [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** The primary bottleneck is the evaluation of $F_{deform}$ for all input samples [S2, unofficial]. The grid-based pruning reduces the runtime of $F_{deform}$ by more than a factor of 2 [S2, unofficial].
*   **Memory Complexity:** Inherits the memory structure of FastNeRF, which is significantly more compact than standard NeRF due to the cache-based approach [S2, unofficial].
*   **Performance:** Renders 300x300 pixel images at 30FPS with 43 coarse samples and no fine stage at test time [S2, unofficial].
*   **Strengths:** Stabilizes training with L2 regularization; handles large movements via $F_{bone}$; efficient test-time rendering via pruning and caching [S2, unofficial].
*   **Limitations:** Cannot use hardware-accelerated ray tracing due to non-linear rays; limited resolution and frame rate compared to static NeRF; requires careful tuning of expression samples for pruning [S1][S2, unofficial].
*   **When to Use:** Telepresence applications requiring real-time, expression-driven head avatars from static multi-view data [S2, unofficial].
*   **When Not to Use:** Scenes requiring hardware-accelerated ray tracing, as the deformation network bends rays and breaks straight-ray assumptions [S2, unofficial]. Scenes with complex non-rigid deformations not captured by the expression vector [S2, unofficial].

## Background
This method was introduced by Garbin et al. in the FastNeRF paper as a proof-of-concept for telepresence scenarios [S2, unofficial]. It builds upon the FastNeRF architecture, which uses a cache-based approach to reduce memory usage [S2, unofficial]. The deformation field approach allows for the animation of 3D heads from static images by learning a mapping from expression parameters to spatial deformations [S2, unofficial].
