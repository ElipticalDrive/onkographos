# Metric Computation (PSNR, SSIM, LPIPS)
Also called: Image quality metrics, Novel-View Rendering Metrics, PSNR, SSIM, LPIPS Computation, Photorealistic Metrics, Rendering Quality Metrics

## Overview
This method computes standard photorealistic metrics—Peak Signal-to-Noise Ratio (PSNR), Structural Similarity Index (SSIM), and Learned Perceptual Image Patch Similarity (LPIPS)—to quantify the fidelity of rendered images against ground truth references [S1, S2, S4]. It addresses the problem of evaluating novel-view synthesis quality by balancing pixel-level precision (PSNR), structural integrity (SSIM), and perceptual similarity (LPIPS) [S1][S3, unofficial]. What sets this apart from raw error metrics is the inclusion of perceptual models (LPIPS) and structural models (SSIM) that correlate better with human judgment than simple pixel differences, while remaining computationally efficient enough for per-view evaluation during training loops [S2, S5].

## How it works
### Inputs and Outputs
**Inputs:**
1.  **Ground Truth Image ($I_{gt}$):** RGB image of shape $[H, W, 3]$ or $[1, 3, H, W]$.
2.  **Predicted Image ($I_{pred}$):** Rendered RGB image of shape $[H, W, 3]$ or $[1, 3, H, W]$.
3.  **Optional Mask ($M$):** Binary mask indicating valid pixels for masked metric computation [S6, unofficial].
4.  **Optional Depth Alignment Scale ($s$):** Scalar for depth evaluation [S2].
5.  **LPIPS Model:** Pre-trained AlexNet feature extractor [S2, S5].

**Outputs:**
1.  **PSNR:** Scalar value in dB.
2.  **SSIM:** Scalar value in $[0, 1]$.
3.  **LPIPS:** Scalar value in $[0, 1]$ (lower is better).
4.  **Optional Masked Metrics:** PSNR and LPIPS restricted to mask $M$ [S6, unofficial].

### Data Structures
*   **Image Tensors:** Float32 tensors. Values must be normalized to $[0, 1]$ for SSIM and LPIPS computation. For PSNR, values are typically in $[0, 1]$ or $[0, 255]$ depending on the MSE calculation, but standard NeRF evaluation assumes $[0, 1]$ with max value 1.0 [S3, unofficial].
*   **LPIPS Feature Map:** Intermediate activations from AlexNet layers (conv1, conv2, conv3, conv4, conv5) [S5].

### Numbered Steps

1.  **Preprocessing:**
    *   If $I_{gt}$ and $I_{pred}$ are in $[H, W, C]$ format, reshape to $[1, C, H, W]$ [S3, unofficial].
    *   Clamp $I_{pred}$ to $[0, 1]$ to handle numerical artifacts from volume rendering [S3, unofficial].
    *   If evaluating depth, align predicted depth $D_{pred}$ with ground truth depth $D_{gt}$ by scaling: $D_{pred}^{aligned} = D_{pred} \times s$, where $s$ is derived from alignment to match the ground-truth depth range [S2].

2.  **PSNR Computation:**
    *   Compute Mean Squared Error (MSE):
        $$ MSE = \frac{1}{N} \sum_{i=1}^{N} (I_{gt, i} - I_{pred, i})^2 $$
        where $N = H \times W \times C$ (or $N$ if masked).
    *   Compute PSNR:
        $$ PSNR = 10 \cdot \log_{10} \left( \frac{MAX_I^2}{MSE} \right) $$
        where $MAX_I = 1.0$ for normalized images [S3, unofficial].

3.  **SSIM Computation:**
    *   Compute SSIM using a sliding window (typically $11 \times 11$) across the image [S1, S2].
    *   For each window, compute local means ($\mu_x, \mu_y$), variances ($\sigma_x^2, \sigma_y^2$), and covariance ($\sigma_{xy}$) [S1].
    *   Apply SSIM formula with constants $C_1 = (0.01 \cdot L)^2$ and $C_2 = (0.03 \cdot L)^2$ where $L=1.0$ for normalized images [S1].
    *   Average SSIM values over all windows to get the final SSIM score [S1].

4.  **LPIPS Computation:**
    *   Pass $I_{gt}$ and $I_{pred}$ through the pre-trained AlexNet network [S2, S5].
    *   Extract feature maps from multiple layers ($l=1..5$) [S5].
    *   For each layer, compute the normalized Euclidean distance between feature vectors:
        $$ d_l = \frac{\sum_{i,j} (f_{gt, l, i,j} - f_{pred, l, i,j})^2}{\sum_{i,j} (f_{gt, l, i,j}^2 + f_{pred, l, i,j}^2)} $$
        (Note: Exact weighting may vary by implementation, but the core is perceptual distance in feature space) [S5].
    *   Aggregate distances across layers, typically weighted by learned parameters [S5].
    *   The final LPIPS score is the sum of these weighted distances [S5].

5.  **Masked Metrics (Optional):**
    *   If a loss mask $M$ is provided, recompute PSNR and LPIPS only for pixels where $M=1$ [S6, unofficial].
    *   Report these values in parentheses alongside global metrics [S6, unofficial].

### Parameters
*   **LPIPS Network:** AlexNet [S2, S5].
*   **LPIPS Weights:** Learned weights from the original LPIPS paper [S5].
*   **SSIM Window Size:** Typically $11 \times 11$ [S1].
*   **Depth Scale ($s$):** Computed via alignment to match ground-truth depth range [S2].

### Edge Cases and Pitfalls
*   **Information Leakage:** In appearance-aware NeRFs, optimizing appearance embeddings on held-out pixels can cause metrics to fail by memorizing the image rather than generalizing [S5]. Use split-image evaluation to prevent this [S5].
*   **Zero/Mean Embeddings:** Setting appearance embeddings to zeros or mean values results in structurally accurate but appearance-mismatched renderings, causing perceptual metrics to fail [S5].
*   **Depth Alignment:** Predicted depth must be scaled to match ground-truth range before computing depth errors [S2].
*   **Clamping:** Predicted RGB values must be clamped to $[0, 1]$ before LPIPS computation [S3, unofficial].

## Subtopics

### Split-image Evaluation Protocol
An evaluation protocol for appearance-aware NeRF models that optimizes the appearance embedding on a subset of pixels to adapt scene appearance without directly optimizing held-out pixels, preventing information leakage while measuring perceptual similarity [S5]. It splits a ground-truth test image into left and right halves, optimizes the appearance embedding using only the left half, renders the right half, and calculates perceptual metrics on the rendered right half against the ground truth right half [S5]. Unlike the NRW baseline which encodes the entirety of a held-out image with an appearance encoder, this scheme isolates geometry from appearance and limits information leakage [S5]. Pitfall: Setting the appearance embedding to zeros or the mean of optimized embeddings results in plausible but structurally accurate renderings that fail to match ground truth appearance, causing perceptual metrics to fail [S5].

### Masked Metrics Evaluation
A metric reporting protocol that computes PSNR, SSIM, and LPIPS on both the full image and the loss-masked region to isolate visible reconstruction quality [S6, unofficial]. It computes standard metrics over all pixels and then recomputes PSNR and LPIPS restricted to pixels inside the loss mask, reporting these values in parentheses [S6, unofficial].

## Operating characteristics
*   **Time Complexity:** PSNR and SSIM are $O(N)$ where $N$ is the number of pixels. LPIPS is $O(N \cdot L)$ where $L$ is the number of layers in the feature extractor (AlexNet has 5 conv layers), dominated by the forward pass through the network [S2, S5].
*   **Memory Complexity:** LPIPS requires storing intermediate feature maps for all layers, which is significant for high-resolution images [S5].
*   **Performance:** PSNR and SSIM are fast and deterministic. LPIPS is slower due to the neural network inference but provides better correlation with human perception [S2, S5].
*   **Strengths:** PSNR is simple and widely used. SSIM captures structural information. LPIPS captures perceptual similarity [S1, S2, S4].
*   **Limitations:** PSNR is sensitive to pixel-level errors and does not correlate well with human perception. SSIM can be sensitive to misalignment. LPIPS is computationally expensive and depends on the pre-trained network [S1, S2, S5].
*   **When to Use:** Use PSNR and SSIM for quick checks and standard comparison. Use LPIPS for perceptual quality assessment, especially in appearance-aware NeRFs [S2, S5].

## Background
PSNR, SSIM, and LPIPS are standard metrics in computer vision and image processing [S1, S2, S4]. They were adopted for NeRF evaluation to provide a multi-faceted view of rendering accuracy, balancing pixel-level precision with structural and perceptual similarity [S1][S3, unofficial]. The use of LPIPS in NeRF evaluation was popularized by works like BARF and NeRF-W [S2, S5]. The split-image evaluation protocol was introduced to address the issue of information leakage in appearance-aware NeRFs [S5].
