# HybridNeRF Model Architecture

Also called: Adaptive Volumetric Surfaces, Hybrid Multi-Resolution Grids

## Overview
HybridNeRF is a neural radiance field architecture that combines explicit multi-resolution 3D feature grids with multi-resolution triplanes to encode scene geometry and appearance, enabling efficient rendering with reduced MLP complexity [S1]. It solves the trade-off between the high memory usage of dense voxel grids and the limited capacity of pure MLP-based NeRFs by using discrete features for spatial locality and triplanes for view-dependent effects [S1]. It sets itself apart from standard hash-grid NeRFs (like [NeRF Network Query with Hashed Embeddings](3107-nerf-network-query-with-hashed-embeddings.md)) by using summed feature aggregation instead of concatenation and by explicitly modeling aliasing via multi-resolution triplanes [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D position $\mathbf{x} \in \mathbb{R}^3$ and a viewing direction $\mathbf{d} \in \mathbb{R}^3$.
*   **Output:** Density $\sigma \in \mathbb{R}$ and color $c \in \mathbb{R}^3$.

**Data Structures:**
1.  **3D Feature Grids:** Three resolution levels: $128^3$, $256^3$, and $512^3$. Each cell stores a feature vector of dimension $K=4$.
2.  **Triplanes:** Seven resolution levels, ranging from $128^2$ to $8,192^2$. Each plane stores a feature vector of dimension $K=4$.
3.  **Surfaceness Field ($\beta$):** A $512^3$ voxel grid storing scalar values for spatially adaptive surfaceness, queried via nearest-neighbor interpolation [S1].
4.  **MLPs:** Separate small MLPs for density ($\mathcal{F}_\sigma$) and color ($\mathcal{F}_c$).

**Numbered Steps:**
1.  **Feature Fetching (3D Grids):** For the input position $\mathbf{x}$, fetch $K=4$ features from each of the 3 resolution levels of the 3D feature grids using trilinear interpolation.
2.  **Feature Fetching (Triplanes):** For the input position $\mathbf{x}$, fetch $K=4$ features from each of the 7 resolution levels of the triplanes using bilinear interpolation.
3.  **Feature Aggregation:** Sum the fetched features across all levels for the 3D grids separately, and sum the fetched features across all levels for the triplanes separately. Do not concatenate features across levels [S1].
4.  **Input Construction:** Concatenate the summed 3D grid features with the summed triplane features to form a single input vector of dimension $4K + 4K = 16$ (since $K=4$) [S1].
5.  **Direction Encoding:** Encode the viewing direction $\mathbf{d}$ using spherical harmonics up to the 4th degree.
6.  **Density Prediction:** Pass the concatenated feature vector through the density MLP $\mathcal{F}_\sigma$ to get an intermediate output. If using the SDF formulation, apply the surfaceness field $\beta(\mathbf{x})$ and the Laplace CDF $\Psi$ (see Formulas). Otherwise, output $\sigma$ directly.
7.  **Color Prediction:** Pass the concatenated feature vector and the spherical harmonic encoded direction $\mathbf{d}$ through the color MLP $\mathcal{F}_c$ to get the color $c$ [S1].

**Formulas:**
The hybrid feature fetching is defined as:
$$ \sigma_{i} = \mathcal{F}_{\sigma} (\mathcal{G}_{\sigma}(\mathbf{x})), \quad c_{i} = \mathcal{F}_{c}(\mathcal{G}_{c}(\mathbf{x}), \mathbf{d}) $$
where $\mathcal{G}_{\sigma}, \mathcal{G}_{c}$ represent the grid-based feature decomposition (summed features from 3D grids and triplanes) [S2].

If using the **SDF Density Formulation** [S1]:
$$ \sigma_{\text{SDF}}(\mathbf{x}) = \beta(\mathbf{x})\Psi(f(\mathbf{x})\beta(\mathbf{x})) $$
where $f(\mathbf{x})$ is the signed distance field output from the network, $\beta(\mathbf{x})$ is the surfaceness parameter from the $512^3$ grid, and $\Psi$ is the CDF of a standard Laplace distribution:
$$ \Psi(s) = \begin{cases} \frac{1}{2} \exp(-s) & \text{if } s > 0 \\ 1 - \frac{1}{2} \exp(s) & \text{if } s \leq 0 \end{cases} $$
Here $s = f(\mathbf{x})\beta(\mathbf{x})$.

**Parameters:**
*   $K=4$: Features fetched per level [S1].
*   3D Grid Levels: 3 ($128^3, 256^3, 512^3$) [S1].
*   Triplane Levels: 7 ($128^2$ to $8,192^2$) [S1].
*   Surfaceness Grid Size: $512^3$ [S1].
*   Spherical Harmonics Degree: Up to 4th degree [S1].

**Edge Cases and Pitfalls:**
*   **Aliasing:** Handled similarly to VR-NeRF due to the multi-resolution feature grid structure [S1].
*   **Surfaceness Tuning:** The surfaceness parameter $\beta(\mathbf{x})$ must be carefully tuned; too high a value degrades quality near fine objects (e.g., lamp wires) and transparent structures (e.g., glass doors) [S1]. It is often initialized as globally uniform and allowed to diverge spatially during fine-tuning [S1].

    if s > 0:

## Subtopics

### [Shading Replacement for Relighting](6346-shading-replacement-for-relighting.md)
Shading Replacement for Relighting is a technique for object insertion that avoids inferring scene illumination by replacing the inserted object's shading with shading from existing scene points. It solves the problem of lighting inconsistency when compositing objects into neural radiance field (NeRF) scenes, where naive composition leads to unrealistic results due to varying illumination. It sets itself apart from direct relighting methods by not requiring explicit light source estimation, instead relying on the correlation between surface normals and shading in Lambertian scenes.

### [Hybrid Multi-Space Module](11712-hybrid-multi-space-module.md)
The Hybrid Multi-Space Module extends grid-based NeRF methods (such as iNGP and TensoRF) to handle multiple sub-spaces (e.g., reflections and refractions) by decomposing the multi-space composition information into a small MLP branch, while the main branch models multiple radiance fields using explicit grids. Unlike pure feature-field approaches, this module integrates discrete learnable grids with small MLPs to output densities and colors for each sub-space, enabling efficient rendering of complex light paths in grid-based architectures. It builds on [HybridNeRF Model Architecture](4842-hybridnerf-model-architecture.md).

### [LidaRF Hybrid Representation](12893-lidarf-hybrid-representation.md)
LidaRF is a NeRF variant for street scenes that fuses explicit Lidar point cloud features with an implicit hash-based grid representation to improve geometry and rendering quality under sparse and collinear camera trajectories. It differs from prior Lidar-only NeRF approaches by avoiding low-resolution and incomplete rendering caused by sparse Lidar coverage and limited field of view; instead, it combines explicit Lidar geometry with a high-resolution implicit grid.

### [Pano-NeRF](15013-pano-nerf.md)
Pano-NeRF is a method for geometry recovery and High Dynamic Range (HDR) novel view synthesis from sparse Low Dynamic Range (LDR) panoramic images. It models the scene using irradiance fields, which treat radiance as both a signal conveying lighting information and a light source illuminating other pixels, thereby increasing observation counts for geometry and leveraging irradiance-radiance attenuation for HDR reconstruction. It differs from standard radiance field methods by integrating surface rendering principles into the volume rendering framework to explicitly model inter-reflection and lighting interactions.

### Geometry Composition by Segmented Sampling
Geometry Composition by Segmented Sampling is a method for compositing objects into NeRF scenes. It transforms sampling points from scene coordinates to object coordinates using the inserting position (translation and rotation) [S3]. It composites density by taking the normalized sum of densities of corresponding points from scene and object at the same position, and composites reflectance via a weighted sum of reflectance values, where weights are the densities of the voxel particles [S3]. The final image is rendered following the standard volume rendering equation using the composited density, reflectance, and shading [S3].

### HybridNeRF SDF Density Formulation
The HybridNeRF SDF Density Formulation computes density $\sigma_{\text{SDF}}(\mathbf{x})$ as $\beta(\mathbf{x})\Psi(f(\mathbf{x})\beta(\mathbf{x}))$, where $f(\mathbf{x})$ is the signed distance field output, $\beta(\mathbf{x})$ is the surfaceness parameter, and $\Psi$ is the CDF of a standard Laplace distribution [S1]. The surfaceness field $\beta(\mathbf{x})$ is stored in a $512^3$ voxel grid and queried via nearest-neighbor interpolation [S1]. The parameter $\beta(\mathbf{x}) > 0$ determines the surfaceness of point $\mathbf{x}$, controlling how concentrated the density is around the zero-level set of $f$ [S1].

### SeaThru-NeRF
SeaThru-NeRF extends NeRFs to handle underwater scattering media by treating the medium as a semi-transparent entity with separate color and density parameters from opaque objects [S4]. It replaces the traditional single opaque object density $\sigma(t)$ with the sum of the object density $\sigma_{obj}(t)$ and the medium density $\sigma_{med}(t)$, allowing the rendering equation to account for scattering in the medium [S4].

### Neural Proxy Rendering with Mixed Samplers
Neural Proxy Rendering with Mixed Samplers is a rendering pipeline that mixes a neural proxy sampler $S_p$ for animated objects and a neural scene sampler $S_c$ for static elements, using a neural texture for local surface appearance [S5, unofficial]. It separates the particle set $X$ into proxy set $X_p$ and scene set $X_c$. For each ray, it finds the convex set bounded by intersection points with the proxy mesh using triangle intersection methods to determine Barycentric coordinates [S5, unofficial]. Unlike NeRF which uses global scene information, neural proxy uses local information (features from neural texture) sampled via Barycentric coordinates [S5, unofficial].

### Normal Smoothness Constraint
Normal Smoothness Constraint is an adaptive constraint that ensures continuity of estimated surface normals in flat regions while preserving sharp features by weighting the normal difference based on albedo similarity [S6]. It samples a perturbed point by adding uniform noise in the normalized 3D space with magnitude 0.01 to generate a neighbor point [S6]. It computes an edge-aware weight mask $M_i$ from the albedo color difference: if the difference is $\le 0.15$, $M_i = 1.0$; otherwise, $M_i = 0.05$ [S6]. This prevents over-smoothing across edges like roofs or walls [S6].

## Operating characteristics
*   **Time Complexity:** Rendering speed is significantly improved compared to vanilla NeRF due to the smaller MLPs required when using explicit features [S2]. On an NVIDIA V100, FastSR-NeRF (using HybridNeRF) achieves 0.309s render time for SR-2× and 0.077s for SR-4×, compared to TensoRF's 1.4s [S2].
*   **Memory Complexity:** The multi-resolution grids ($128^3$ to $512^3$) and triplanes consume memory, but the use of smaller MLPs reduces the overall model size compared to dense MLP-based NeRFs. Model size is reported as 20MB for FastSR-NeRF (2×) and 13MB for (4×) on NeRF-Synthetic, compared to 71.8MB for TensoRF [S2].
*   **Measured Performance:** On NeRF-Synthetic, SR-2× achieves 32.53 PSNR and 0.961 SSIM with 1.5h training time [S2]. SR-4× achieves 30.47 PSNR and 0.944 SSIM with 30m training time [S2].
*   **Scaling:** The method scales well to consumer devices. On an M1 Pro MacBook, SR-2× training takes 22.5h and rendering takes 15.9s, compared to MobileNeRF's >375h training time [S2].
*   **Strengths:** High rendering efficiency, low training time on consumer hardware, model-agnostic SR integration [S2].
*   **Limitations:** Quality drops at high upscaling rates (e.g., 8×) [S2]. Apple MPS support may force CPU execution, slowing down training/rendering [S2].
*   **When to use:** When training on consumer-grade hardware is required, or when fast rendering is prioritized over absolute peak PSNR.
*   **When not to use:** When ultra-high upscaling factors (8×) are needed with high quality, or when GPU acceleration is unavailable and CPU performance is insufficient.

## Background
HybridNeRF was introduced in the paper "HybridNeRF: Efficient Neural Rendering via Adaptive Volumetric Surfaces" [S1]. It builds upon the concept of hybrid representations that combine explicit grids with implicit MLPs, aiming to balance the efficiency of explicit features with the flexibility of implicit networks. The SDF formulation and surfaceness field were introduced to improve surface reconstruction quality [S1]. The FastSR-NeRF pipeline [S2] later demonstrated the effectiveness of combining this architecture with super-resolution for consumer device efficiency.
