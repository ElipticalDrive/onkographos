# NeRF Rendering (Alpha Compositing)

Also called: NeRF Integration, NeRF Rendering Equation, Neural Radiance Fields rendering, Alpha Compositing in NeRF, Standard NeRF

## Overview
NeRF Rendering (Alpha Compositing) is the forward pass method that synthesizes a 2D image pixel color from a 3D implicit scene representation by integrating radiance along camera rays [S1, S2, S3]. It solves the problem of differentiable volume rendering by approximating the continuous volume rendering integral as a discrete weighted sum, where weights are determined by the probability of the ray terminating at each sample point [S1, S2, S3]. It sets itself apart from sibling methods like [NeRF-style Volume Rendering Integrator](5964-nerf-style-volume-rendering-integrator.md) by explicitly defining the standard multi-layer perceptron (MLP) query pipeline, stratified sampling strategy, and the specific alpha-compositing formulation ($\alpha_i = 1 - \exp(-\sigma_i \delta_i)$) that underpins the original NeRF architecture [S1, S2, S13].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of training images with known camera poses (extracted via COLMAP) [S13]; a neural network model $F_\Theta$ (typically an MLP) that maps 5D coordinates $(x, d)$ to volume density $\sigma$ and RGB color $c$ [S1, S12]; ray parameters $r(t) = o + td$ for each pixel, where $o$ is the camera origin and $d$ is the viewing direction [S1, S13].
*   **Outputs:** The rendered RGB color $\hat{C}(r)$ and optionally the expected depth $\hat{D}(r)$ for each ray [S1, S2][S7, unofficial].

**Data Structures:**
*   **Ray Bins:** The integration interval $[t_n, t_f]$ is divided into $N$ equally spaced bins [S2, S12].
*   **Sample Points:** $N$ points $t_i$ are sampled from these bins [S12].
*   **Model Output:** For each sample point $x_i = o + t_i d$, the model outputs a vector containing density $\sigma_i$ and color $c_i = (r_i, g_i, b_i)$ [S1, S12].

**Numbered Steps:**

1.  **Ray Generation:** For each pixel in the target image, generate a camera ray $r(t) = o + td$ using the camera's intrinsic and extrinsic matrices [S1, S4, S13].
2.  **Sampling:** Discretize the ray interval $[t_n, t_f]$ into $N$ evenly-spaced bins [S12]. Use non-deterministic stratified sampling to draw one sample $t_i$ uniformly at random from within each bin $i$:
    $$ t_i \sim U\left[t_n + \frac{i-1}{N}(t_f - t_n), t_n + \frac{i}{N}(t_f - t_n)\right] $$
    [S12, S13].
3.  **Model Query:** For each sample point $x_i = o + t_i d$ and viewing direction $d$, apply positional encoding $\gamma(\cdot)$ and pass through the MLP $F_\Theta$ to predict volume density $\sigma_i$ and color $c_i$ [S1, S12, S17]:
    $$ [\mathbf{c}_i; \sigma_i] = \text{MLP}(\gamma_x(\mathbf{x}_i), \gamma_d(\mathbf{d}); \Theta) $$
    [S17]. Note: Some implementations apply a sigmoid to RGB and ReLU to density [S9].
4.  **Delta Calculation:** Compute the distance $\delta_i$ between adjacent samples:
    $$ \delta_i = t_{i+1} - t_i $$
    [S1, S3]. For the last sample, $\delta_N$ is often set to a large value (e.g., $10^{10}$) to ensure the ray terminates [S7, unofficial][S9].
5.  **Alpha (Opacity) Calculation:** Convert density to opacity $\alpha_i$ using the Beer-Lambert law approximation:
    $$ \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
    [S1, S2, S3].
6.  **Transmittance Calculation:** Compute the accumulated transmittance $T_i$, representing the probability that the ray reaches sample $i$ without being absorbed:
    $$ T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right) $$
    [S1, S2, S3]. In implementation, this is often computed via cumulative product of $(1 - \alpha_j)$ with a small epsilon $\epsilon$ (e.g., $10^{-10}$) added to prevent numerical instability (NaNs) during gradient computation [S7, unofficial][S9]:
    $$ T_i = \prod_{j=1}^{i-1} (1 - \alpha_j + \epsilon) $$
    [S9].
7.  **Weight Calculation:** Compute the weight $w_i$ for each sample:
    $$ w_i = \alpha_i T_i $$
    [S1, S2, S9].
8.  **Color Compositing:** Compute the final rendered color $\hat{C}(r)$ as the weighted sum of colors:
    $$ \hat{C}(r) = \sum_{i=1}^{N} w_i c_i = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) c_i $$
    [S1, S2, S3, S12].
9.  **Background Handling:** If a white background is assumed, add the contribution of rays that pass through the scene without terminating:
    $$ \hat{C}_{final}(r) = \hat{C}(r) + \left(1 - \sum_{i=1}^{N} w_i\right) c_{bg} $$
    where $c_{bg}$ is typically $(1, 1, 1)$ [S7, S8, unofficial].
10. **Depth Estimation (Optional):** Compute the expected depth $\hat{D}(r)$ analogously to color:
    $$ \hat{D}(r) = \sum_{i=1}^{N} w_i t_i $$
    [S2, S15].

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def nerf_render(rays, t_vals, model, white_back=True, noise_std=0.0):
    """
    rays: (B, H, W, 3) ray origins
    t_vals: (N,) sample distances along the ray
    model: callable returning (sigma, rgb) for points and directions
    white_back: bool, whether to add white background
    noise_std: float, std dev for noise added to sigma during training
    """
    # 1. Generate sample points
    # rays_o: (B, H, W, 3), rays_d: (B, H, W, 3)
    rays_o, rays_d = rays[..., :3], rays[..., 3:6]
    
    # 2. Query model
    # pts: (B, H, W, N, 3)
    pts = rays_o.unsqueeze(2) + rays_d.unsqueeze(2) * t_vals.unsqueeze(0).unsqueeze(0).unsqueeze(0)
    
    # Flatten for model input: (B*H*W*N, 3)
    pts_flat = pts.reshape(-1, 3)
    dirs_flat = rays_d.unsqueeze(2).expand(-1, -1, t_vals.shape[0], -1).reshape(-1, 3)
    
    # Query MLP: returns sigma and rgb
    # sigma: (B*H*W*N,), rgb: (B*H*W*N, 3)
    sigma_flat, rgb_flat = model(pts_flat, dirs_flat)
    
    # Reshape back
    sigma = sigma_flat.reshape(rays.shape[0], rays.shape[1], rays.shape[2], t_vals.shape[0])
    rgb = rgb_flat.reshape(rays.shape[0], rays.shape[1], rays.shape[2], t_vals.shape[0], 3)
    
    # 3. Add noise if training
    if noise_std > 0:
        sigma = sigma + torch.randn_like(sigma) * noise_std
        
    # 4. Compute deltas
    # deltas: (B, H, W, N-1)
    deltas = t_vals[1:] - t_vals[:-1]
    # Append infinity for the last segment
    delta_inf = 1e10 * torch.ones_like(deltas[..., :1])
    deltas = torch.cat([deltas, delta_inf], dim=-1)
    
    # Normalize deltas by ray direction norm (if rays are not unit length)
    # Note: In standard NeRF, rays are often normalized, but if not:
    # dir_norm = torch.norm(rays_d, dim=-1, keepdim=True)
    # deltas = deltas * dir_norm
    
    # 5. Compute alpha
    # sigma is clamped to be non-negative (ReLU)
    sigma = F.relu(sigma)
    alpha = 1.0 - torch.exp(-sigma * deltas)
    
    # 6. Compute transmittance
    # T_i = product(1 - alpha_j) for j < i
    # Add epsilon for stability
    eps = 1e-10
    transmittance = torch.cumprod(1.0 - alpha + eps, dim=-1)
    # Shift transmittance: T_0 = 1.0, T_i = prod(1-alpha)_{j=0}^{i-1}
    # cumprod with exclusive=True gives T_1, T_2... so we prepend 1.0
    transmittance = torch.cat([torch.ones_like(transmittance[..., :1]), transmittance[..., :-1]], dim=-1)
    
    # 7. Compute weights
    weights = alpha * transmittance
    
    # 8. Compute RGB
    rgb_final = torch.sum(weights.unsqueeze(-1) * rgb, dim=-2)
    
    # 9. Background
    if white_back:
        weights_sum = torch.sum(weights, dim=-1, keepdim=True)
        rgb_final = rgb_final + (1.0 - weights_sum) * torch.tensor([1.0, 1.0, 1.0])
        
    # 10. Compute Depth (optional)
    depth_final = torch.sum(weights * t_vals, dim=-1)
    
    return rgb_final, depth_final
```

**Parameters:**
*   $N$: Number of samples along the ray. Typical value: 64 for both coarse and fine networks [S11].
*   $t_n, t_f$: Integration bounds. $t_n$ is the near plane (camera center), $t_f$ is the far plane (scene bounding volume) [S2, S12].
*   $\epsilon$: Epsilon for numerical stability. Typical value: $10^{-10}$ [S7, unofficial][S9].
*   $c_{bg}$: Background color. Typically white $(1, 1, 1)$ [S7, unofficial].

**Edge Cases and Pitfalls:**
*   **Numerical Stability:** Without epsilon, $\exp(-\sum \sigma \delta)$ can underflow to 0, causing NaNs in gradients. Epsilon is added to $(1-\alpha)$ before cumulative product [S7, unofficial][S9].
*   **Boundary Conditions:** The last delta $\delta_N$ must be large enough to ensure the ray terminates, effectively setting $T_{N+1} \approx 0$ [S7, unofficial][S9].
*   **Density Positivity:** Density $\sigma$ must be non-negative. ReLU is applied to the model output [S9, S17].
*   **View-Dependent Effects:** NeRF handles view-dependent effects (non-Lambertian materials) by conditioning the color output on the viewing direction $d$ [S13].

## Subtopics

### [Depth-Guided Sampling](7490-depth-guided-sampling.md)
Depth-Guided Sampling is a ray sampling strategy for neural radiance fields that focuses scene sampling on estimated surface regions using depth priors from input views to increase sample density in relevant areas, thereby improving synthesis quality and allowing a reduction in the number of samples per ray. It sets itself apart from uniform or hierarchical stratified sampling by explicitly leveraging predicted depth maps (and their uncertainties) to bias the placement of query points toward likely object surfaces, reducing redundant sampling in free space or occluded regions.

### [Rendered Depth-Guided Warping](8893-rendered-depth-guided-warping.md)
Rendered Depth-Guided Warping is a consistency regularization technique used during NeRF training to enforce geometric coherence between observed and unobserved viewpoints without the computational cost of full-resolution rendering. It generates a warped image from a source view using a low-resolution rendered depth map from a target view, enabling the computation of a consistency loss that encourages globally consistent geometry and appearance. Unlike [Depth-Guided Sampling](7490-depth-guided-sampling.md) which uses depth to guide ray sampling, this method uses rendered depth to warp existing image data for loss calculation.

### [Depth-Prior Guided Stratified Sampling](11292-depth-prior-guided-stratified-sampling.md)
Depth-Prior Guided Stratified Sampling replaces uniform depth sampling in volume rendering by using predicted depth priors and associated confidence bounds to focus sampling on likely object surfaces.

### [Neus SDF Volume Rendering](12443-neus-sdf-volume-rendering.md)
Neus SDF Volume Rendering is a technique that renders 3D scenes represented as Signed Distance Functions (SDF) or Signed Ray Distance Functions (SRDF) by accumulating color and depth along rays using alpha compositing. It solves the problem of precisely extracting geometric surfaces from implicit representations by replacing the standard NeRF density field with an SDF-based weighting scheme. It differs from standard NeRF rendering by using a trainable S-density function to concentrate weight at the zero-level set of the SDF, ensuring the surface contributes most to the image, and adapts this theory to SRDF by treating surface normals as irrelevant to the value distribution.

### [Progressive Blur Estimation](14151-progressive-blur-estimation.md)
Progressive Blur Estimation (PBE) is a two-stage implicit function module that estimates defocus and motion blur by predicting multiple ray origins, directions, and blending weights for each pixel. It solves the problem of rendering blurry observations from a radiance field by modeling blur as a distribution of rays rather than a single ray. It sets itself apart from single-stage blur models by using a coarse stage to predict initial kernel locations and a refinement stage that incorporates ray features for fine-grained blur modeling, which is more accurate and efficient than a single-stage approach with ray features.

### [MipNerfModel](14207-mipnerfmodel.md)
The MipNerfModel is a Neural Radiance Field (NeRF) architecture that approximates integrated positional encoding by treating rays as cones or cylinders rather than infinitesimally thin lines, thereby solving aliasing artifacts caused by high-frequency scene details. It distinguishes itself from standard NeRF implementations by using multi-level sampling (coarse and fine) and integrated positional encoding to model the frequency content of the signal along the ray, which is essential for training on unbounded, outdoor scenes.

### [Event Simulation from NeRF](15450-event-simulation-from-nerf.md)
Event Simulation from NeRF generates virtual event data from a NeRF model to supervise training using real event camera observations. It solves the problem of motion blur in NeRF reconstruction by modeling the temporal integration of light during camera exposure. It differs from sibling methods like [Depth-Guided Sampling](7490-depth-guided-sampling.md) by explicitly simulating asynchronous event streams rather than static depth or color, allowing for event-driven bundle adjustment to refine camera poses and recover sharp geometry.

## Operating characteristics
*   **Time Complexity:** $O(N \cdot P)$, where $N$ is the number of samples per ray and $P$ is the number of rays (pixels) [S1, S12]. The MLP query is the dominant cost.
*   **Memory Complexity:** $O(N \cdot P)$ to store intermediate activations for backpropagation [S1, S12].
*   **Measured Performance:** The original NeRF implementation required extremely high computing power and long training times [S13]. Instant NGP by Müller et al. (2022) introduced multi-resolution hash encoding, significantly reducing processing time [S13].
*   **Strengths:** Handles view-dependent effects (non-Lambertian materials) where color changes based on viewpoint, whereas standard photogrammetry often assumes diffuse reflection [S13]. Capable of synthesizing high-quality, photorealistic novel views with fine details [S13].
*   **Limitations:** Neither a point cloud nor a mesh; it consists of continuous voxels, which affects how the 3D reconstruction is interpreted [S13]. Original NeRF is computationally expensive [S13].
*   **When to Use:** For novel view synthesis from sparse multi-view images, especially for scenes with complex lighting, reflections, or fine details [S13]. Used in Cultural Heritage for image-based reconstruction of 3D models of real, multi-scale objects, especially for metallic, translucent, transparent surfaces, homogeneous textures, occlusions, vegetation, and fine details [S13].
*   **When Not to Use:** When real-time mesh extraction is required without post-processing, or when computational resources are severely limited without acceleration techniques like Instant NGP [S13].

## Background
*   **Origin:** First presented by Mildenhall et al. (2020) [S13].
*   **History:** NeRF represents scenes with an implicit function that maps spatial point $x = (x, y, z)$ and view direction $d = (\theta, \phi)$ into the density $\sigma$ and color $c$ [S3]. The method uses a multi-layer perceptron (MLP) to model geometry and appearance from a sparse set of images [S1].
*   **Development:** Subsequent developments include Instant NGP (Müller et al., 2022) with multi-resolution hash encoding [S13], and various extensions like NeuS for SDF-based rendering [S5].
*   **Usage:** Implemented in platforms like Instant NGP (Müller et al., 2022), Nerfstudio (Tancik et al., 2023), and Luma AI [S13].
