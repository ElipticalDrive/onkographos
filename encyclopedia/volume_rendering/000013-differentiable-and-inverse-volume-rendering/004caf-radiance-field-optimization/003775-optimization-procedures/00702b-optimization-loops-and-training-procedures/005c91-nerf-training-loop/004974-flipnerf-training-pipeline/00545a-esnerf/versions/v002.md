# ESNeRF

Also called: Extremely Sparse Neural Radiance Fields

## Overview
ESNeRF is a sparse neural rendering method designed to address the ill-posed nature of novel view synthesis in extremely sparse-view settings [S1]. It builds on the FreeNeRF backbone but introduces a hybrid loss function incorporating pixel-based, depth-based, and regularization losses to mitigate overfitting and reduce artifacts such as solid floaters [S1]. Unlike standard NeRF training, ESNeRF leverages depth maps generated by a pretrained DPT model for supervision and employs frequency regularization to stabilize high-frequency signal learning [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Sparse set of input images $I$, camera poses, and intrinsics [S1].
*   **Outputs:** Rendered color images $\hat{C}$ and depth maps $\hat{d}$ for novel views [S1].

**Data Structures:**
*   **Ray Set $\mathcal{R}$:** Set of rays sampled for training [S1].
*   **Density $\sigma_K$:** Density values of $K$ points sampled along a ray from near to far [S1].
*   **Mask $m_K$:** Binary mask vector of length $K$ [S1].
*   **Depth Map $d$:** Depth map generated by the pretrained DPT model [S1].
*   **Rendered Depth $\hat{d}$:** Depth estimated by volume rendering [S1].
*   **Frequency Mask $\boldsymbol{\alpha}$:** Vector controlling positional encoding visibility [S1].

**Parameters:**
*   $w_1, w_2, w_3$: Weights for Total Variation, Ranking, and Continuity losses. Not given in the sources [S1].
*   $k$: Tolerance constant for depth ranking penalty. Not given in the sources [S1].
*   $M$: Regularization range index for occlusion penalty. Not given in the sources [S1].
*   $T$: Final iteration for frequency regularization (e.g., 40,000) [S1].
*   $t$: Current iteration for frequency regularization [S1].
*   $L$: Number of bits in the positional encoding frequency table. Not given in the sources [S1].
*   Training Resolution: $1/4$ of the original image resolution [S1].
*   Training Iterations: 5,000 per scene [S1].
*   Batch Size: 1,024 [S1].

**Numbered Steps:**

1.  **Depth Supervision Generation:** Generate ground-truth depth maps $d$ using a pretrained DPT model [S1].
2.  **Frequency Regularization Setup:** Initialize positional encoding. The visible frequency is controlled by a mask $\boldsymbol{\alpha}(t, T, L)$. Start with raw inputs without positional encoding (or low frequency). As training progresses ($t$ increases), the visible frequency increases linearly by 3 bits each step to avoid unstable high-frequency signals early in training [S1].
3.  **Ray Sampling:** Sample rays $r \in \mathcal{R}$ and compute coarse ($\hat{C}_c$) and fine ($\hat{C}_f$) rendered colors and depths ($\hat{d}$) using the current NeRF model [S1].
4.  **Loss Calculation:** Compute the total loss $\mathcal{L}_{total}$ as defined below [S1].
5.  **Occlusion Regularization:** Apply a penalty to dense fields near the camera to reduce solid floaters. The mask $m_k$ is set to 1 for indices up to $M$ and 0 for the rest [S1].
6.  **Optimization:** Update model parameters using the computed loss [S1].
7.  **Upsampling:** After training, upsample the generated target views bilinearly to full resolution [S1].

**Formulas:**

The total loss is a weighted sum of the NeRF reconstruction loss and three regularization terms [S1]:
$$
\mathcal{L}_{total} = \mathcal{L}_{NeRF} + w_1 \mathcal{L}_{TV} + w_2 R_{rank} + w_3 R_{cont}
$$

The NeRF reconstruction loss uses both coarse and fine network outputs [S1]:
$$
\mathcal{L}_{NeRF} = \sum_{r \in \mathcal{R}} \left\| \hat{C}_c(r) - C(r) \right\|^2 + \left\| \hat{C}_f(r) - C(r) \right\|^2
$$
where $C(r)$ is the ground-truth pixel color for ray $r$ [S1].

Total Variation Loss promotes spatial consistency in depth [S1]:
$$
\mathcal{L}_{TV} = \sum_{i,j} \left( |d_{i,j} - d_{i+1,j}|^2 + |d_{i,j} - d_{i,j+1}|^2 \right)
$$
where $d_{i,j}$ is the depth at pixel $(i, j)$ from the DPT model [S1].

Depth-Guided Ranking Regularisation penalizes incorrect depth ordering between random points [S1]:
$$
R_{rank} = \sum_{d_i \leq d_j} \max \left( \hat{d}_i - \hat{d}_j + k, 0 \right)
$$
where $d_i, d_j$ are depths from the DPT model and $\hat{d}_i, \hat{d}_j$ are rendered depths. If $d_i \leq d_j$ but $\hat{d}_i > \hat{d}_j$, a penalty is applied [S1].

Depth-Guided Continuity Regularisation controls frequency visibility [S1]:
$$
\gamma '_L = \gamma _L (x) \odot \boldsymbol {\alpha } (t, T, L)
$$
where the mask $\boldsymbol{\alpha}$ is defined element-wise for bit index $i$ as:
$$
\boldsymbol {\alpha }_i (t, T, L) = \begin{cases} 1 & \text{if}\ i \leq \frac {t \cdot L}{T} + 3 \\ \frac {t \cdot L}{T} & \text{if}\ \frac {t \cdot L}{T} + 3 < i \leq \frac {t \cdot L}{T} + 6 \\ 0 & \text{if}\ i > \frac {t \cdot L}{T} + 6 \end{cases}
$$

Occlusion Regularisation penalizes density near the camera [S1]:
$$
\mathcal{L}_{occ} = \frac{1}{K} \sum_{k=1}^K \sigma_k \cdot m_k
$$
where $\sigma_k$ is the density at the $k$-th sample point (near to far), and $m_k=1$ for $k \leq M$ and $0$ otherwise [S1].

**Pseudocode:**

```python
def train_esnerf(input_images, poses, intrinsics, T=40000, L=10, M=100, k=0.1, w1=1.0, w2=1.0, w3=1.0):
    """Train ESNeRF model."""
    model_params = initialize_free_nerf_params()
    dpt_model = load_pretrained_dpt()
    batch_size = 1024
    training_res = (original_width // 4, original_height // 4)
    optimizer = GradientDescent(model_params, lr=0.0005)

    for t in range(5000):
        alpha_mask = compute_alpha_mask(t, T, L)
        rays = sample_rays(input_images, poses, intrinsics, batch_size, training_res)
        gt_depths = dpt_model(input_images)
        gt_depths = bilinear_resize(gt_depths, training_res)

        coarse_colors, coarse_depths, coarse_densities = nerf_forward(model_params, rays, alpha_mask)
        fine_colors, fine_depths, fine_densities = nerf_forward(model_params, rays, alpha_mask)

        loss_nerf = mean_squared_error(coarse_colors, rays.gt_colors) + mean_squared_error(fine_colors, rays.gt_colors)
        loss_tv = compute_total_variation(gt_depths)
        loss_rank = compute_ranking_loss(gt_depths, coarse_depths, k)
        loss_cont = 0.0
        loss_occ = compute_occlusion_loss(coarse_densities, M)

        total_loss = loss_nerf + w1 * loss_tv + w2 * loss_rank + w3 * loss_cont + loss_occ
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()

    return model_params

def compute_alpha_mask(t, T, L):
    alpha = []
    for i in range(L):
        threshold_low = (t * L) / T + 3
        threshold_high = (t * L) / T + 6
        if i <= threshold_low:
            alpha.append(1.0)
        elif i <= threshold_high:
            alpha.append((t * L) / T)
        else:
            alpha.append(0.0)
    return alpha

def compute_total_variation(depth_map):
    tv = 0.0
    H, W = depth_map.shape
    for i in range(H - 1):
        for j in range(W - 1):
            tv += (depth_map[i+1, j] - depth_map[i, j])**2 + (depth_map[i, j+1] - depth_map[i, j])**2
    return tv

def compute_ranking_loss(gt_depths, rendered_depths, k):
    loss = 0.0
    num_samples = 1000
    for _ in range(num_samples):
        idx_i, idx_j = random_indices(gt_depths.shape)
        d_i = gt_depths[idx_i]
        d_j = gt_depths[idx_j]
        d_hat_i = rendered_depths[idx_i]
        d_hat_j = rendered_depths[idx_j]
        if d_i <= d_j:
            loss += max(d_hat_i - d_hat_j + k, 0)
    return loss / num_samples

def compute_occlusion_loss(densities, M):
    occ_sum = 0.0
    K = densities.shape[1]
    for b in range(densities.shape[0]):
        occ_sum += sum(densities[b, :M])
    return occ_sum / (densities.shape[0] * K)

def sample_rays(images, poses, intrinsics, batch_size, res):
    rays = []
    for _ in range(batch_size):
        u, v = random_pixel_coordinates(res)
        ray = generate_ray_from_pixel(u, v, poses, intrinsics)
        gt_color = bilinear_resize(images, res)[u, v]
        rays.append({'u': u, 'v': v, 'direction': ray.direction, 'origin': ray.origin, 'gt_colors': gt_color})
    return rays

def bilinear_resize(tensor, target_res):
    # Standard bilinear interpolation to target_res
    return interpolate_bilinear(tensor, target_res)

def mean_squared_error(pred, target):
    return sum((p - t)**2 for p, t in zip(pred, target)) / len(pred)

def random_indices(shape):
    h, w = shape
    return (random.randint(0, h-1), random.randint(0, w-1)), (random.randint(0, h-1), random.randint(0, w-1))

def random_pixel_coordinates(res):
    return random.randint(0, res[0]-1), random.randint(0, res[1]-1)

def generate_ray_from_pixel(u, v, poses, intrinsics):
    # Standard pinhole camera ray generation
    return Ray(origin=poses.origin, direction=poses.direction * u, v)

def nerf_forward(params, rays, alpha_mask):
    # Forward pass applying alpha_mask to positional encodings
    colors, depths, densities = [], [], []
    for ray in rays:
        c, d, s = forward_single_ray(params, ray, alpha_mask)
        colors.append(c)
        depths.append(d)
        densities.append(s)
    return colors, depths, densities

def forward_single_ray(params, ray, alpha_mask):
    # Sample points along ray, apply frequency mask to positional encoding, query MLP
    return query_nerf(params, ray, alpha_mask)

def initialize_free_nerf_params():
    return FreeNeRFBackbone()

def load_pretrained_dpt():
    return DPTModel()

def GradientDescent(params, lr):
    return Optimizer(params, lr)
```

**Edge Cases and Pitfalls:**
*   **DPT Inaccuracy:** The DPT-generated depth maps may be inaccurate and lack detail. Using them solely for supervision can deteriorate render quality, necessitating the hybrid loss [S1].
*   **High-Frequency Instability:** Training with full positional encoding from the start can lead to unstable and susceptible high-frequency signals. The frequency regularization is critical to avoid this [S1].
*   **Floaters:** Sparse views often result in solid floaters near the camera. The occlusion regularization is specifically designed to address this [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources [S1].

*   **Measured Performance:** The method was evaluated in the AIM 2024 Sparse Neural Rendering Challenge, Track 1 [S1].
*   **Scaling:** Training is performed at $1/4$ image resolution, followed by bilinear upsampling to full resolution [S1].
*   **Strengths:** Addresses overfitting and ill-posedness in sparse-view settings; reduces solid floaters; stabilizes high-frequency learning [S1].
*   **Limitations:** Relies on the quality of the pretrained DPT model; requires careful tuning of regularization weights (not provided) [S1].

## Background
ESNeRF was proposed by the team "zongqihe" for the AIM 2024 Sparse Neural Rendering Challenge [S1]. It builds on the FreeNeRF backbone and incorporates techniques from [18] (pixel-based losses) and [28] (depth-based losses) [S1]. The method was part of the challenge submissions, with the team participating in Track 1 [S1].
