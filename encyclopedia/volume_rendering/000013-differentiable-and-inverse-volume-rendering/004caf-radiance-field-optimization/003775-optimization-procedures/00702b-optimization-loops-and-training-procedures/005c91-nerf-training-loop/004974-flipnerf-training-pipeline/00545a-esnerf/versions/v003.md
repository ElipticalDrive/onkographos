# ESNeRF

Also called: Extremely Sparse Neural Radiance Fields

## Overview
ESNeRF is a sparse neural rendering method designed to address the ill-posed nature of novel view synthesis in extremely sparse-view settings [S1]. It builds on the FreeNeRF backbone but introduces a hybrid loss function incorporating pixel-based, depth-based, and regularization losses to mitigate overfitting and reduce artifacts such as solid floaters [S1]. Unlike standard NeRF training, ESNeRF leverages depth maps generated by a pretrained DPT model for supervision and employs frequency regularization to stabilize high-frequency signal learning [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Sparse set of input images $I$, camera poses, and intrinsics [S1].
*   **Outputs:** Rendered color images $\hat{C}$ and depth maps $\hat{d}$ for novel views [S1].

**Data Structures:**
*   **Ray Set $\mathcal{R}$:** Set of rays sampled for training [S1].
*   **Density $\sigma_K$:** Density values of $K$ points sampled along a ray from near to far [S1].
*   **Mask $m_K$:** Binary mask vector of length $K$ [S1].
*   **Depth Map $d$:** Depth map generated by the pretrained DPT model [S1].
*   **Rendered Depth $\hat{d}$:** Depth estimated by volume rendering [S1].
*   **Frequency Mask $\boldsymbol{\alpha}$:** Vector controlling positional encoding visibility [S1].

**Parameters:**
*   $w_1, w_2, w_3$: Weights for Total Variation, Ranking, and Continuity losses. Not given in the sources [S1].
*   $k$: Tolerance constant for depth ranking penalty. Not given in the sources [S1].
*   $M$: Regularization range index for occlusion penalty. Not given in the sources [S1].
*   $T$: Final iteration for frequency regularization (e.g., 40,000) [S1].
*   $t$: Current iteration for frequency regularization [S1].
*   $L$: Number of bits in the positional encoding frequency table. Not given in the sources [S1].
*   Training Resolution: $1/4$ of the original image resolution [S1].
*   Training Iterations: 5,000 per scene [S1].
*   Batch Size: 1,024 [S1].

**Numbered Steps:**

1.  **Depth Supervision Generation:** Generate ground-truth depth maps $d$ using a pretrained DPT model [S1].
2.  **Frequency Regularization Setup:** Initialize positional encoding [S1]. The visible frequency is controlled by a mask $\boldsymbol{\alpha}(t, T, L)$ [S1]. Start with raw inputs without positional encoding [S1]. As training progresses ($t$ increases), the visible frequency increases linearly by 3 bits each step to avoid unstable high-frequency signals early in training [S1].
3.  **Ray Sampling:** Sample rays $r \in \mathcal{R}$ and compute coarse ($\hat{C}_c$) and fine ($\hat{C}_f$) rendered colors and depths ($\hat{d}$) using the current NeRF model [S1].
4.  **Loss Calculation:** Compute the total loss $\mathcal{L}_{total}$ as defined below [S1].
5.  **Occlusion Regularization:** Apply a penalty to dense fields near the camera to reduce solid floaters [S1]. The mask $m_k$ is set to 1 for indices up to $M$ and 0 for the rest [S1].
6.  **Optimization:** Update model parameters using the computed loss [S1].
7.  **Upsampling:** After training, upsample the generated target views bilinearly to full resolution [S1].

**Formulas:**

The total loss is a weighted sum of the NeRF reconstruction loss and three regularization terms [S1]:
$$
\mathcal{L}_{total} = \mathcal{L}_{NeRF} + w_1 \mathcal{L}_{TV} + w_2 R_{rank} + w_3 R_{cont}
$$

The NeRF reconstruction loss uses both coarse and fine network outputs [S1]:
$$
\mathcal{L}_{NeRF} = \sum_{r \in \mathcal{R}} \left\| \hat{C}_c(r) - C(r) \right\|^2 + \left\| \hat{C}_f(r) - C(r) \right\|^2
$$
where $C(r)$ is the ground-truth pixel color for ray $r$ [S1].

Total Variation Loss promotes spatial consistency in depth [S1]:
$$
\mathcal{L}_{TV} = \sum_{i,j} \left( |d_{i,j} - d_{i+1,j}|^2 + |d_{i,j} - d_{i,j+1}|^2 \right)
$$
where $d_{i,j}$ is the depth at pixel $(i, j)$ from the DPT model [S1].

Depth-Guided Ranking Regularisation penalizes incorrect depth ordering between random points [S1]:
$$
R_{rank} = \sum_{d_i \leq d_j} \max \left( \hat{d}_i - \hat{d}_j + k, 0 \right)
$$
where $d_i, d_j$ are depths from the DPT model and $\hat{d}_i, \hat{d}_j$ are rendered depths [S1]. If $d_i \leq d_j$ but $\hat{d}_i > \hat{d}_j$, a penalty is applied [S1].

Depth-Guided Continuity Regularisation controls frequency visibility [S1]:
$$
\gamma '_L = \gamma _L (x) \odot \boldsymbol {\alpha } (t, T, L)
$$
where the mask $\boldsymbol{\alpha}$ is defined element-wise for bit index $i$ as:
$$
\boldsymbol {\alpha }_i (t, T, L) = \begin{cases} 1 & \text{if}\ i \leq \frac {t \cdot L}{T} + 3 \\ \frac {t \cdot L}{T} & \text{if}\ \frac {t \cdot L}{T} + 3 < i \leq \frac {t \cdot L}{T} + 6 \\ 0 & \text{if}\ i > \frac {t \cdot L}{T} + 6 \end{cases}
$$

Occlusion Regularisation penalizes density near the camera [S1]:
$$
\mathcal{L}_{occ} = \frac{1}{K} \sum_{k=1}^K \sigma_k \cdot m_k
$$
where $\sigma_k$ is the density at the $k$-th sample point (near to far), and $m_k=1$ for $k \leq M$ and $0$ otherwise [S1].

**Pseudocode:**

```python
def train_esnerf(input_images, poses, intrinsics, T_freq=40000, L_bits=10, M_range=100, k_tol=0.1, w_tv=1.0, w_rank=1.0, w_cont=1.0):
    """Train ESNeRF model."""
    # Initialize FreeNeRF backbone and pretrained DPT model [G]
    model = FreeNeRFBackbone()
    dpt = DPTModel()
    batch_size = 1024
    res = (original_width // 4, original_height // 4)
    optimizer = GradientDescent(model.parameters(), lr=0.0005)

    for t in range(5000):
        alpha_mask = compute_alpha_mask(t, T_freq, L_bits)
        rays = sample_rays(input_images, poses, intrinsics, batch_size, res)
        gt_depths = dpt(input_images)
        gt_depths = bilinear_resize(gt_depths, res)

        coarse_colors, coarse_depths, coarse_densities = nerf_forward(model, rays, alpha_mask)
        fine_colors, fine_depths, fine_densities = nerf_forward(model, rays, alpha_mask)

        loss_nerf = mse(coarse_colors, rays.gt_colors) + mse(fine_colors, rays.gt_colors)
        loss_tv = compute_total_variation(gt_depths)
        loss_rank = compute_ranking_loss(gt_depths, coarse_depths, k_tol)
        loss_cont = 0.0  # Continuity regularization uses alpha_mask [S1]
        loss_occ = compute_occlusion_loss(coarse_densities, M_range)

        total_loss = loss_nerf + w_tv * loss_tv + w_rank * loss_rank + w_cont * loss_cont + loss_occ
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()

    return model

def compute_alpha_mask(t, T, L):
    """Compute frequency visibility mask alpha(t, T, L)."""
    alpha = []
    threshold_low = (t * L) / T + 3
    threshold_high = (t * L) / T + 6
    for i in range(L):
        if i <= threshold_low:
            alpha.append(1.0)
        elif i <= threshold_high:
            alpha.append((t * L) / T)
        else:
            alpha.append(0.0)
    return alpha

def compute_total_variation(depth_map):
    """Compute L_TV = sum_{i,j} (|d_{i,j} - d_{i+1,j}|^2 + |d_{i,j} - d_{i,j+1}|^2)."""
    tv = 0.0
    H, W = depth_map.shape
    for i in range(H - 1):
        for j in range(W - 1):
            tv += (depth_map[i+1, j] - depth_map[i, j])**2 + (depth_map[i, j+1] - depth_map[i, j])**2
    return tv

def compute_ranking_loss(gt_depths, rendered_depths, k):
    """Compute R_rank = sum_{d_i <= d_j} max(d_hat_i - d_hat_j + k, 0)."""
    loss = 0.0
    num_samples = 1000
    H, W = gt_depths.shape
    for _ in range(num_samples):
        idx_i = (random.randint(0, H-1), random.randint(0, W-1))
        idx_j = (random.randint(0, H-1), random.randint(0, W-1))
        d_i = gt_depths[idx_i]
        d_j = gt_depths[idx_j]
        d_hat_i = rendered_depths[idx_i]
        d_hat_j = rendered_depths[idx_j]
        if d_i <= d_j:
            loss += max(d_hat_i - d_hat_j + k, 0)
    return loss / num_samples

def compute_occlusion_loss(densities, M):
    """Compute L_occ = (1/K) sum_{k=1}^K sigma_k * m_k."""
    occ_sum = 0.0
    B, K = densities.shape
    for b in range(B):
        for k in range(K):
            m_k = 1.0 if k < M else 0.0
            occ_sum += densities[b, k] * m_k
    return occ_sum / (B * K)

def sample_rays(images, poses, intrinsics, batch_size, res):
    rays = []
    for _ in range(batch_size):
        u, v = random_pixel_coordinates(res)
        ray = generate_ray_from_pixel(u, v, poses, intrinsics)
        gt_color = bilinear_resize(images, res)[u, v]
        rays.append({'u': u, 'v': v, 'direction': ray.direction, 'origin': ray.origin, 'gt_colors': gt_color})
    return rays

def nerf_forward(model, rays, alpha_mask):
    """Volumetric rendering with frequency mask applied to positional encoding."""
    colors, depths, densities = [], [], []
    for ray in rays:
        z_vals = sample_z_vals(ray.origin, ray.direction)
        pos_enc = apply_frequency_mask(positional_encoding(z_vals), alpha_mask)
        # Query MLP for density and color [G]
        sigma, rgb = query_mlp(model, pos_enc)
        weights = compute_transmittance(sigma)
        c = sum(weights * rgb)
        d = sum(weights * z_vals)
        colors.append(c)
        depths.append(d)
        densities.append(sigma)
    return colors, depths, densities
```

**Edge Cases and Pitfalls:**
*   **DPT Inaccuracy:** The DPT-generated depth maps may be inaccurate and lack detail [S1]. Using them solely for supervision can deteriorate render quality, necessitating the hybrid loss [S1].
*   **High-Frequency Instability:** Training with full positional encoding from the start can lead to unstable and susceptible high-frequency signals [S1]. The frequency regularization is critical to avoid this [S1].
*   **Floaters:** Sparse views often result in solid floaters near the camera [S1]. The occlusion regularization is specifically designed to address this [S1].

## Background
ESNeRF was proposed by the team "zongqihe" for the AIM 2024 Sparse Neural Rendering Challenge [S1]. It builds on the FreeNeRF backbone and incorporates techniques from [18] (pixel-based losses) and [28] (depth-based losses) [S1]. The method was part of the challenge submissions, with the team participating in Track 1 [S1]. The source notes 44K total iterations with frequency regulation ending at 40K iterations, while training is explicitly done at 1/4 image resolution for 5K iterations per scene [S1].
