# 360FusionNeRF


## Overview
360FusionNeRF is a semi-supervised learning framework for synthesizing novel views from a single RGB-D 360° panorama image [S1]. It extends OmniNeRF by introducing geometric supervision via auxiliary depth maps and semantic consistency via CLIP features to guide progressive training and reduce artifacts caused by occlusion in unobserved regions [S1]. Unlike standard NeRF methods that rely solely on photometric reconstruction, 360FusionNeRF explicitly constrains the geometry and semantics of the learned radiance field to ensure plausible completions of missing data [S1].

## How it works
**Inputs and Outputs:**
* **Input:** A single RGB-D 360° panoramic image [S1].
* **Output:** A trained neural radiance field (MLP) capable of rendering novel views from arbitrary camera poses [S1].

**Data Structures:**
The method uses a standard Multi-Layer Perceptron (MLP) architecture identical to OmniNeRF, mapping 3D coordinates and viewing directions to density ($\sigma$) and color ($c$) [S1]. The sampling strategy employs a hierarchical two-stage approach: 1) **Coarse Stage:** Uniformly samples $N_c$ intervals along the ray [S1]. 2) **Refined Stage:** Samples $N_f$ intervals based on the density distribution from the coarse stage [S1].

**Numbered Steps:**
1. **Data Reprojection:** The input 360° panorama is re-projected to generate synthetic views at virtual camera positions, and auxiliary depth maps are extracted for these virtual positions [S1].
2. **Hierarchical Sampling:** For each training ray $r$, the coarse network samples $N_c$ points uniformly along the ray interval [S1]. The refined network samples $N_f$ points adaptively based on the coarse densities using standard importance sampling [G].
3. **Volume Rendering:** Compute the rendered color $\hat{C}(r)$ for both coarse and refined stages using the volume rendering equation [S1].
4. **Loss Computation:** Calculate three loss components: **Color Loss ($L_{Color}$):** Mean Squared Error (MSE) between rendered and ground truth color at known poses [S1]. **Geometric Loss ($L_{Geo}$):** Supervision using the auxiliary depth maps extracted in Step 1 [S1]. **Semantic Consistency Loss ($L_{Sem}$):** Loss derived from CLIP Vision Transformer activations to ensure semantic plausibility in novel views [S1].
5. **Optimization:** Minimize the total loss to update the MLP weights [S1].

**Formulas:**
The rendered color $\hat{C}(r)$ for a ray $r(t) = o + td$ is computed as [S1]:
$$ \hat{C}(r) = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) c_i $$
where:
* $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ is the accumulated transmittance [S1].
* $\delta_i = t_{i+1} - t_i$ is the interval length between adjacent samples [S1].
* $\sigma_i$ is the density and $c_i$ is the color at sample $i$ [S1].

The total optimization objective minimizes the mean squared error between rendered color $\hat{C}(r)$ and ground truth color $C(r)$ over the set of input rays $R_i$ [S1]:
$$ L_{Color} = \sum_{r \in R_i} ||(C(r) - \hat{C}(r))||^2 $$

**Parameters:**
* $N_c$: Number of intervals uniformly sampled along the ray during the coarse stage [S1].
* $N_f$: Number of intervals decided in accordance with densities from the coarse stage during the refined stage [S1].

**Pseudocode:**
```python
def train_360fusionnerf(panorama_rgb, panorama_depth, virtual_cameras, clip_model, N_c, N_f, lr, epochs):
    # Initialize MLP mapping 3D coordinates and viewing directions to density and color
    mlp = MLP()
    optimizer = Adam(mlp.parameters(), lr=lr)

    # 1. Data Reprojection: Extract auxiliary depth maps at virtual poses
    auxiliary_depths = {}
    for cam in virtual_cameras:
        auxiliary_depths[cam.id] = reproject_depthmap(panorama_depth, cam.pose)

    for epoch in range(epochs):
        total_loss = 0.0
        rays = sample_rays_from_panorama(panorama_rgb)

        for ray in rays:
            # 2. Hierarchical Sampling
            # Coarse stage: uniform sampling along ray interval [t_near, t_far]
            t_coarse = linspace(ray.t_near, ray.t_far, N_c)
            delta_t_coarse = t_coarse[1:] - t_coarse[:-1]
            sigma_coarse, color_coarse = mlp.query(t_coarse, ray.direction)

            # Refined stage: sample based on coarse densities
            # Standard importance sampling from NeRF [G]
            weights_coarse = sigma_coarse * exp(-cumsum(sigma_coarse * delta_t_coarse))
            t_refined = sample_pdf(t_coarse, weights_coarse, N_f)
            delta_t_refined = t_refined[1:] - t_refined[:-1]
            sigma_refined, color_refined = mlp.query(t_refined, ray.direction)

            # 3. Volume Rendering
            # Compute transmittance T_i = exp(-sum_{j=1}^{i-1} sigma_j * delta_t_j)
            alpha_refined = 1.0 - exp(-sigma_refined * delta_t_refined)
            T_refined = exp(-cumsum(sigma_refined * delta_t_refined))
            T_refined = concat([1.0, T_refined[:-1]])
            c_refined = sum(T_refined * alpha_refined * color_refined)

            alpha_coarse = 1.0 - exp(-sigma_coarse * delta_t_coarse)
            T_coarse = exp(-cumsum(sigma_coarse * delta_t_coarse))
            T_coarse = concat([1.0, T_coarse[:-1]])
            c_coarse = sum(T_coarse * alpha_coarse * color_coarse)

            # 4. Loss Computation
            gt_color = get_ground_truth_color(ray)
            loss_color = mse(c_refined, gt_color) + mse(c_coarse, gt_color)

            # Geometric loss: penalize deviation from auxiliary depth maps [S1]
            # Exact mathematical formulation not specified in sources [S1]
            loss_geo = geometric_loss(ray, auxiliary_depths)

            # Semantic consistency loss: CLIP feature distance [S1]
            rendered_img = render_image_from_mlp(mlp, ray.camera_pose)
            gt_img = get_ground_truth_image(ray.camera_pose)
            loss_sem = semantic_loss(clip_model, rendered_img, gt_img)

            loss = loss_color + loss_geo + loss_sem
            total_loss += loss

        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()

    return mlp
```

**Edge Cases and Pitfalls:**
* **Occlusion Artifacts:** Without geometric and semantic guidance, the method may produce artifacts in unobserved regions due to overfitting to training views [S1].

## Operating characteristics
* **Time Complexity:** Not given in the sources.
* **Memory Complexity:** Not given in the sources.
* **Performance:** The method produces plausible completions of unobserved regions while preserving scene features, improving perceptual quality compared to OmniNeRF [S1].
* **Strengths:** Reduces artifacts from occlusion; generalizable scene representation from a single image; leverages semantic consistency for realistic content [S1].
* **Limitations:** Relies on the availability of a high-quality RGB-D 360° panorama; requires a pre-trained CLIP model for semantic features [S1].
* **When to use:** When novel views must be synthesized from a single 360° panorama with significant unobserved regions [S1].
* **When not to use:** When multiple views are available (standard NeRF or other multi-view methods may be more appropriate) [G].

## Background
360FusionNeRF was proposed by Shreyas Kulkarni, Peng Yin, and Sebastian Scherer in 2022 [S1]. It is based on the OmniNeRF framework, which estimates neural radiance fields from 360° panoramic images [S1]. The method addresses the challenge of overfitting to training views and artifacts in unobserved regions by introducing semi-supervised guidance [S1]. It was published in IEEE Robotics and Automation Letters (RA-L) [S1].
