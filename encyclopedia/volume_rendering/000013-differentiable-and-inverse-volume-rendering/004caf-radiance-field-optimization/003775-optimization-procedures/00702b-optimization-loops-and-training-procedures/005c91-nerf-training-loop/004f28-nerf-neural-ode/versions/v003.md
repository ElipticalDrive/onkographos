# NeRF-Neural ODE

Also called: NeRFNODE, Neural ODE for NeRF

## Overview
NeRF-Neural ODE replaces the discrete quadrature summation of standard NeRF with a continuous Neural Ordinary Differential Equation (Neural ODE) solver to integrate radiance and transmittance along rays [S1, unofficial]. It treats ray integration as a continuous dynamical system solved via adaptive ODE solvers rather than fixed-step numerical integration [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Ray features tensor of shape $11 \times N$ containing ray origin $o$ (3), ray direction $d$ (3), view directions $v$ (3), near plane $near$ (1), and far plane $far$ (1) [S1, unofficial].
*   **Output:** A `RenderResult` structure containing `rgb` (shape $3 \times N$) and `disparity` [S1, unofficial].

**Data Structures:**
The ODE state vector $x$ has shape $15 \times N$, constructed by augmenting the $11 \times N$ ray features with accumulated color $C$ (3 rows) and accumulated transmittance $T$ (1 row), initialized to zero [S1, unofficial]. Rows 1–3 hold position $p$, rows 4–6 hold direction $d$, rows 7–9 hold view direction $v$, row 10 holds $near$, row 11 holds $far$, rows 12–14 hold $C$, and row 15 holds $T$ [S1, unofficial].

**Neural Network Architecture:**
The model uses a `NeRFNet` wrapped in `NeRFNODE` [S1, unofficial]. Positional encoding for input $x$ and levels $L$ computes $\sin(2^i \pi x)$ and $\cos(2^i \pi x)$ for $i \in 0 \dots L-1$, concatenated along the first dimension [S1, unofficial]. Levels are $L_o=10$ for position and $L_d=4$ for direction [S1, unofficial]. The trunk takes the positional encoding of position (60 dims) and processes it through two parallel paths: one passes the encoding directly, the other passes it through a `Dense(60, 256, relu)` followed by four `Dense(256, 256, relu)` layers [S1, unofficial]. The outputs are concatenated to 316 dims, passed through `Dense(316, 256, relu)`, three `Dense(256, 256, relu)` layers, and a final `Dense(256, 256)` layer [S1, unofficial]. The output splits into density $\sigma$ via `Dense(256, 1, sigmoid)` and features $h$ via identity [S1, unofficial]. The RGB head concatenates the positional encoding of view direction (24 dims) with features $h$ (256 dims) to form 280 dims, followed by `Dense(280, 128, relu)` and `Dense(128, 3, sigmoid)` [S1, unofficial].

**Algorithm Steps:**
1.  **Ray Generation:** Generate rays from camera parameters $H, W, focal, c2w$ [S1, unofficial]. Direction is computed in NDC space if `ndc=true` [S1, unofficial]. Near and far planes are set to 0.0 and 1.0 respectively [S1, unofficial].
2.  **Feature Extraction:** Compute ray features [S1, unofficial]. If `ndc=true`, transform rays to NDC space [S1, unofficial]. Concatenate rays origin, rays direction, view directions, near, and far into an $11 \times N$ tensor [S1, unofficial].
3.  **State Initialization:** Augment the $11 \times N$ ray features with 4 rows of zeros to create the initial state $x_0$ of shape $15 \times N$ [S1, unofficial].
4.  **ODE Definition:** Define the derivative function $f(t, x)$ for $t \in [0, 1]$ [S1, unofficial]. Extract $p, d, v, near, far, C, T$ from $x$ [S1, unofficial]. Compute derivatives: $dp/dt = (far - near) \cdot d$, $dd/dt = 0$, $dv/dt = 0$, $d(near)/dt = 0$, $d(far)/dt = 0$ [S1, unofficial]. Query `NeRFNet` with $p$ and $v$ to get $\sigma$ and $rgb$ [S1, unofficial]. Compute $dC/dt = \exp(-T) \cdot \sigma \cdot rgb$ and $dT/dt = \sigma$ [S1, unofficial]. Return concatenated derivatives [S1, unofficial].
5.  **ODE Solving:** Solve the ODE from $t=0$ to $t=1$ using the `Tsit5()` solver with relative tolerance $10^{-3}$ and absolute tolerance $10^{-3}$ [S1, unofficial].
6.  **Result Extraction:** Extract the final state $x_{end}$ [S1, unofficial]. The RGB values are located at rows 12–14 (0-indexed) of the final state vector [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def positional_encoding(x, L):
    # x: (..., D), returns (..., 2*L*D)
    i = np.arange(L, dtype=x.dtype)
    freq_bands = (2.0 ** i).reshape(-1, 1)
    scaled = x[..., np.newaxis] * freq_bands
    return np.concatenate([np.sin(np.pi * scaled), np.cos(np.pi * scaled)], axis=-1).reshape(*x.shape[:-1], -1)

def linear(x, W, b):
    return x @ W + b

def relu(x):
    return np.maximum(0, x)

def sigmoid(x):
    return 1.0 / (1.0 + np.exp(-x))

class NeRFNet:
    def __init__(self, L_o, L_d):
        self.L_o = L_o
        self.L_d = L_d
        # Trunk weights
        self.W_t1 = np.random.randn(316, 256)
        self.b_t1 = np.zeros(256)
        self.W_t2 = np.random.randn(256, 256)
        self.b_t2 = np.zeros(256)
        self.W_t3 = np.random.randn(256, 256)
        self.b_t3 = np.zeros(256)
        self.W_t4 = np.random.randn(256, 256)
        self.b_t4 = np.zeros(256)
        self.W_sig = np.random.randn(256, 1)
        self.b_sig = np.zeros(1)
        # RGB Head weights
        self.W_h1 = np.random.randn(280, 128)
        self.b_h1 = np.zeros(128)
        self.W_h2 = np.random.randn(128, 3)
        self.b_h2 = np.zeros(3)

    def forward(self, pos, viewdir):
        # pos: (N, 3), viewdir: (N, 3)
        pe_pos = positional_encoding(pos, self.L_o)  # (N, 60)
        # Trunk parallel paths
        path1 = pe_pos
        path2 = relu(linear(pe_pos, self.W_t1, self.b_t1))
        for W, b in [(self.W_t2, self.b_t2), (self.W_t3, self.b_t3), (self.W_t4, self.b_t4)]:
            path2 = relu(linear(path2, W, b))
        trunk_in = np.concatenate([path1, path2], axis=-1)  # (N, 316)

        h = relu(linear(trunk_in, self.W_t1, self.b_t1))
        h = relu(linear(h, self.W_t2, self.b_t2))
        h = relu(linear(h, self.W_t3, self.b_t3))
        h = linear(h, self.W_t4, self.b_t4)  # No activation on last trunk layer

        sigma = sigmoid(linear(h, self.W_sig, self.b_sig))  # (N, 1)
        features = h  # (N, 256)

        # RGB Head
        pe_dir = positional_encoding(viewdir, self.L_d)  # (N, 24)
        head_in = np.concatenate([pe_dir, features], axis=-1)  # (N, 280)
        rgb = sigmoid(linear(relu(linear(head_in, self.W_h1, self.b_h1)), self.W_h2, self.b_h2))  # (N, 3)
        return sigma, rgb

def derivatives(t, state, net):
    # state: (15, N)
    p = state[0:3, :]
    d = state[3:6, :]
    v = state[6:9, :]
    near = state[9, :]
    far = state[10, :]
    C = state[11:14, :]
    T = state[14, :]

    dpdt = (far - near)[:, np.newaxis] * d
    dddt = np.zeros_like(d)
    dvdtdt = np.zeros_like(v)
    dneardt = np.zeros_like(near)
    dfardt = np.zeros_like(far)

    sigma, rgb = net.forward(p.T, v.T)
    sigma = sigma.T  # (N, 1)
    rgb = rgb.T      # (N, 3)

    dCdt = np.exp(-T) * sigma * rgb
    dTdt = sigma.squeeze()

    dxdt = np.concatenate([dpdt, dddt, dvdtdt, dneardt[np.newaxis, :], dfardt[np.newaxis, :], dCdt, dTdt[np.newaxis, :]], axis=0)
    return dxdt

def raw_to_state_space(ray_features):
    # ray_features: (11, N)
    zeros = np.zeros((4, ray_features.shape[1]), dtype=ray_features.dtype)
    return np.concatenate([ray_features, zeros], axis=0)

def render_rays(ray_features, net, t_span=(0.0, 1.0)):
    state = raw_to_state_space(ray_features)
    # Reference implementation uses Tsit5() with reltol=1e-3, abstol=1e-3 [S1, unofficial]
    # Self-contained fixed-step RK4 fallback:
    t, dt = t_span[0], 0.01
    while t < t_span[1] - 1e-6:
        k1 = derivatives(t, state, net)
        k2 = derivatives(t + dt/2, state + dt*k1/2, net)
        k3 = derivatives(t + dt/2, state + dt*k2/2, net)
        k4 = derivatives(t + dt, state + dt*k3, net)
        state += (dt/6) * (k1 + 2*k2 + 2*k3 + k4)
        t += dt
    # Extract RGB (rows 11-13, 0-indexed)
    rgb = state[11:14, :]
    return rgb
```

**Parameters:**
*   **Positional Encoding Levels:** $L_o=10$, $L_d=4$ [S1, unofficial].
*   **Solver:** `Tsit5()` with `reltol=1e-3`, `abstol=1e-3` [S1, unofficial].
*   **Batch Size:** 4096 rays [S1, unofficial].
*   **Optimizer:** ADAM with learning rate $5 \times 10^{-4}$, $\beta_1=0.9$, $\beta_2=0.999$, with exponential decay starting at iteration 250,000 [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **NDC Space:** If `ndc=true`, rays must be transformed to NDC space before feature extraction [S1, unofficial]. The near plane is set to 1.0 in NDC space [S1, unofficial].
*   **Dimension Matching:** The RGB head input dimension is explicitly defined as 280, requiring concatenation of the 24-dim view direction encoding with the 256-dim features [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the number of adaptive steps taken by the Tsit5 solver [S1, unofficial].
*   **Memory Complexity:** Requires storing the $15 \times N$ state vector and neural network parameters [S1, unofficial].
*   **Performance:** Not given in the sources.
*   **Strengths:** Continuous integration along rays [S1, unofficial].
*   **Limitations:** Potential slowness compared to fixed-step marching for simple scenes and reliance on specific ODE solver libraries [S1, unofficial].

## Background
NeRF-Neural ODE is an implementation that attempts to use Neural ODEs instead of quadrature for NeRF [S1, unofficial]. It originates from the `nerf-node` repository [S1, unofficial].
