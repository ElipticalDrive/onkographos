# Training & Optimization Protocol

Also called: Splatfacto Training Protocol

## Overview
This protocol defines the training loop and optimization hyperparameters for decomposed Gaussian splatting methods, specifically targeting distractor-free rendering by separating static scene geometry from dynamic or erroneous "distractor" elements [S1]. It differs from standard Gaussian Splatting by explicitly optimizing distractor point parameters with distinct learning rates and regularization, and by employing specific decay schedulers for the Adam optimizer [S1]. It builds on [Framework and Baseline Implementations](16220-framework-and-baseline-implementations.md).

## How it works
**Inputs:** Training images, initial camera poses, initial static point cloud (from COLMAP), and distractor point initialization.
**Outputs:** Optimized Gaussian parameters (means, covariances/opacities, colors, SH coefficients) for both static and distractor points.

**Data Structures:**
*   **Static Points:** Initialized via COLMAP point cloud. Parameters optimized with Splatfacto defaults.
*   **Distractor Points:** 1000 points initialized per training image.
*   **Optimizer State:** Adam optimizer with Exponential decay scheduler.

**Steps:**
1.  **Initialization:**
    *   Initialize static points using the standard COLMAP point cloud method [S1].
    *   Initialize 1000 distractor points per training image [S1].
    *   Initialize per-image embeddings $e_j \in \mathbb{R}^{d_e}$ with $d_e=32$ and per-Gaussian embeddings $z_i \in \mathbb{R}^{d_z}$ with $d_z=24$ using Fourier frequencies with 4 components (if using appearance modeling) [S1].
2.  **Optimization Loop:**
    *   Optimize all static and distractor point parameters using the Adam optimizer [S1].
    *   **Distractor Learning Rates:**
        *   Quaternions: 0.01 [S1].
        *   Scales: 0.05 [S1].
        *   RGB Colors: 0.025 [S1].
        *   Means and Opacities: Use Splatfacto defaults [S1].
    *   **Static Learning Rates:** Use Splatfacto defaults [S1].
    *   **Regularization:**
        *   Alpha head regularization weight: 0.002 [S1].
        *   SH orders: Head order learning rate 0.002; remaining SH orders learning rate 0.0001 [S1].
        *   Regularization weights: $\lambda_s = 0$, $\lambda_d = 0.01$, $\lambda_{bg} = 0.15$ [S1].
        *   Threshold $T_\epsilon$ for regularization: 0.003 [S1].
    *   **Scheduler:** Apply Exponential decay scheduler with decay rates of 0.0001, 0.0002, and 0.00001 separately [S1].
3.  **Densification Control:**
    *   Densification of distractor Gaussians stops after 15,000 iterations [S1].
4.  **Iteration Count:**
    *   Train for 30,000 iterations on RobustNeRF, On-the-go, and Mip-NeRF-360 datasets [S1].
    *   Train for 200,000 iterations on Photo Tourism datasets [S1].

**Pseudocode:**
```python
# Initialization
static_points = initialize_from_colmap()
distractor_points = initialize_distractors(num_per_image=1000)

# Optimizer Setup
optimizer = Adam(
    params=static_points + distractor_points,
    lr_defaults=splitfacto_defaults,
    distractor_lr_quat=0.01,
    distractor_lr_scale=0.05,
    distractor_lr_rgb=0.025
)
scheduler = ExponentialDecay(decay_rates=[0.0001, 0.0002, 0.00001])

# Regularization Weights
lambda_s = 0.0
lambda_d = 0.01
lambda_bg = 0.15
T_epsilon = 0.003

# Training Loop
max_iterations = 30000 if dataset in [RobustNeRF, OnTheGo, MipNeRF360] else 200000
densification_stop = 15000

for iteration in range(max_iterations):
    # Forward pass and loss computation
    loss = compute_loss(
        rendered_images,
        ground_truth_images,
        lambda_s=lambda_s,
        lambda_d=lambda_d,
        lambda_bg=lambda_bg,
        T_epsilon=T_epsilon
    )
    
    # Backward pass
    optimizer.zero_grad()
    loss.backward()
    
    # Step optimizer
    optimizer.step()
    scheduler.step()
    
    # Densification control
    if iteration < densification_stop:
        densify_distractor_gaussians(distractor_points)
    else:
        stop_densification(distractor_points)
```

## Subtopics

### Perceptual Loss Weighting
Uses a combined photometric and perceptual loss where the weight $\lambda$ for the LPIPS loss $L_{LPIPS}$ is set to 0.05 [S2]. The total loss for rendering $M$ novel views is $L = \sum_{m=1}^M (L_{MSE}(I^{(m)}_{render}, I^{(m)}_{gt}) + \lambda L_{LPIPS}(I^{(m)}_{render}, I^{(m)}_{gt}))$ [S2].

### Symmetric View Mirroring
A data augmentation technique for single-view reconstruction of roughly symmetric objects (e.g., shoes) by mirroring input images to simulate opposite viewpoints [S3, unofficial]. It trains the renderer on the combined original and mirrored dataset to reconstruct the full 3D mesh despite lacking back-side samples [S3, unofficial]. This is a highly ill-posed problem; reconstruction quality for unseen parts remains lower than multi-view training [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** Training duration is dataset-dependent: 30k iterations for standard benchmarks (RobustNeRF, On-the-go, Mip-NeRF-360) and 200k iterations for Photo Tourism [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Explicitly handles distractors, improving rendering fidelity in complex scenes [S1].
*   **Limitations:** Single-view symmetric reconstruction is ill-posed and yields lower quality for unseen parts [S3, unofficial].

## Background
Originated in the context of decomposed Gaussian splatting for distractor-free rendering [S1]. The protocol adapts the Splatfacto baseline [34] to include distractor optimization [S1].
