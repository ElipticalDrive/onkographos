# Training & Optimization Protocol

Also called: Splatfacto Training Protocol

## Overview
This protocol defines the training loop, parameter initialization, and optimization hyperparameters for decomposed Gaussian splatting methods targeting distractor-free rendering [S1]. It distinguishes itself from standard Gaussian Splatting by explicitly modeling distractor elements alongside static scene Gaussians, using specific learning rate schedules and regularization weights [S1].

## How it works
### Inputs and Outputs
**Inputs:** Training images and corresponding camera poses [S1]. Initial static point cloud from COLMAP [S1]. Hyperparameters for optimizer, scheduler, and regularization [S1].

**Outputs:** Optimized parameters for static Gaussians (means, opacities, scales, rotations, spherical harmonics) [S1]. Optimized parameters for distractor Gaussians (means, opacities, scales, rotations, RGB colors) [S1].

### Data Structures
The method maintains two sets of Gaussian primitives:
1. **Static Gaussians:** Initialized from COLMAP point cloud [S1]. Parameters include mean $\mu$, opacity $\alpha$, scale $s$, rotation $q$ (quaternion), and spherical harmonic coefficients $c_{lm}$ [S1].
2. **Distractor Gaussians:** Initialized with 1000 points per training image [S1]. Parameters include mean $\mu$, opacity $\alpha$, scale $s$, rotation $q$, and RGB color $\mathbf{c}$ [S1].

### Steps
1. **Initialization:** Initialize static Gaussians using the standard COLMAP point cloud method [S1]. Initialize 1000 distractor points per training image [S1]. Initialize appearance embeddings if using appearance modeling: per-image embedding $e_j \in \mathbb{R}^{32}$ and per-Gaussian embedding $z_i \in \mathbb{R}^{24}$ with Fourier frequencies [S1].
2. **Forward Pass:** Render images using the current set of static and distractor Gaussians [S1]. Compute photometric and perceptual losses against ground truth [S2].
3. **Loss Computation:** The total loss $L$ for a batch of $M$ novel views is $L = \sum_{m=1}^M \left( L_{MSE}(I_{render}^{(m)}, I_{gt}^{(m)}) + \lambda L_{LPIPS}(I_{render}^{(m)}, I_{gt}^{(m)}) \right)$, where $\lambda = 0.05$ [S2]. Apply regularization terms for distractor Gaussians with weights $\lambda_s = 0$, $\lambda_d = 0.01$, and $\lambda_{bg} = 0.15$ [S1]. The threshold $T_\epsilon$ for regularization is set to $0.003$ [S1].
4. **Backward Pass and Optimization:** Compute gradients with respect to all parameters [S1]. Update parameters using the Adam optimizer [S1]. Apply an Exponential decay scheduler with decay rates of $0.0001$, $0.0002$, and $0.00001$ [S1].
5. **Distractor Densification:** Densify distractor Gaussians for the first 15,000 iterations [S1]. Stop densification after 15,000 iterations [S1].
6. **Training Duration:** Train for 30,000 iterations on RobustNeRF, On-the-go, and Mip-NeRF-360 datasets [S1]. Train for 200,000 iterations on Photo Tourism datasets [S1].

### Pseudocode
```python
# Initialization
static_gaussians = []  # Parameters initialized from COLMAP point cloud [S1]
distractor_gaussians = []  # 1000 points initialized per training image [S1]
appearance_embeddings = {"per_image": 32, "per_gaussian": 24}  # Initialized with Fourier frequencies [S1]

# Hyperparameters
lambda_lpips = 0.05  # Perceptual loss weight [S2]
lambda_d_reg = 0.01  # Distance regularization weight [S1]
lambda_bg_reg = 0.15  # Background regularization weight [S1]
epsilon_threshold = 0.003  # Regularization threshold [S1]
max_densification_iter = 15000  # Densification stops after this [S1]
total_iterations = 30000 if dataset in ["RobustNeRF", "On-the-go", "Mip-NeRF-360"] else 200000  # Training duration [S1]

# Optimizer setup
optimizer = Adam(params=static_gaussians.params + distractor_gaussians.params)  # Adam optimizer [S1]
scheduler = ExponentialDecay(decay_rates=[0.0001, 0.0002, 0.00001])  # Exponential decay scheduler [S1]

for iteration in range(1, total_iterations + 1):
    images, cameras = sample_batch()  # [G] Standard batch sampling

    rendered_images = render(static_gaussians, distractor_gaussians, cameras)  # [G] Standard Gaussian rasterization

    loss_mse = sum((r - g) ** 2 for r, g in zip(rendered_images, images)) / len(images)  # [G] Standard MSE
    loss_lpips = compute_lpips(rendered_images, images)  # [G] Standard LPIPS metric
    loss_perceptual = lambda_lpips * loss_lpips  # [S2]

    # Regularization losses: Formulas for distance and background regularization are not provided in the sources [G]
    reg_dist = lambda_d_reg * compute_distance_regularization(distractor_gaussians)
    reg_bg = lambda_bg_reg * compute_background_regularization(distractor_gaussians)

    total_loss = loss_mse + loss_perceptual + reg_dist + reg_bg  # [S1, S2]

    optimizer.zero_grad()
    total_loss.backward()

    distractor_gaussians.quaternions.lr = 0.01  # [S1]
    distractor_gaussians.scales.lr = 0.05  # [S1]
    distractor_gaussians.rgb.lr = 0.025  # [S1]
    # Means and opacities use Splatfacto defaults [S1]

    optimizer.step()
    scheduler.step()

    if iteration < max_densification_iter:
        densify_distractor_gaussians(distractor_gaussians)  # [G] Standard densification procedure
```

### Parameters
- **Optimizer:** Adam [S1].
- **Learning Rates (Distractors):** Quaternions=0.01, Scales=0.05, RGB=0.025 [S1]. Means and opacities use Splatfacto defaults [S1].
- **Scheduler:** Exponential decay with rates 0.0001, 0.0002, 0.00001 [S1].
- **Regularization Weights:** $\lambda_s=0$, $\lambda_d=0.01$, $\lambda_{bg}=0.15$ [S1].
- **Threshold:** $T_\epsilon=0.003$ [S1].
- **Perceptual Loss Weight:** $\lambda=0.05$ [S2].

### Edge Cases and Pitfalls
- **Distractor Densification:** Must stop after 15,000 iterations to prevent overfitting or instability [S1].
- **Learning Rate Mismatch:** Distractor points require specific learning rates different from static points; using defaults for all may lead to poor convergence [S1].
- **Regularization Threshold:** The threshold $T_\epsilon=0.003$ is critical for controlling the influence of regularization terms [S1].

## Subtopics

### Perceptual Loss Weighting
Uses LPIPS loss with weight $\lambda=0.05$ to improve perceptual quality during optimization [S2].

### Symmetric View Mirroring
A data augmentation technique for single-view reconstruction of roughly symmetric objects (e.g., shoes) by mirroring input images to simulate opposite viewpoints [S3, unofficial]. This allows training on combined original and mirrored datasets to reconstruct full 3D mesh despite lacking back-side samples [S3, unofficial]. Highly ill-posed problem; reconstruction quality for unseen parts remains lower compared to multi-view training [S3, unofficial].

### Long-Sequence Stress Test Protocol
Evaluates method stability and degradation over extended sequence lengths by scaling training iterations and densification/pruning schedules proportionally [S4]. Tested on sequence lengths {300, 600, 900, 1200} frames using the flame_salmon scene from N3DV [S4]. CC-4DGS PSNR degrades from 29.62 dB (300f) to 29.12 dB (1200f, $\Delta = -0.50$ dB), while Swift4D degrades from 29.48 dB to 28.24 dB ($\Delta = -1.25$ dB) [S4]. CC-4DGS retains up to a +0.88 dB advantage at 1200 frames [S4]. This single-scene stress test does not prove general long-duration scalability, but indicates that frequency-based time encoding with depth-3 TimeMLP avoids disproportionate long-sequence failure modes compared to 4D hash-grid baselines [S4].

## Operating characteristics
- **Time Complexity:** Depends on the number of Gaussians and samples per ray [G]. Training duration is 30k iterations for standard datasets and 200k for Photo Tourism [S1].
- **Memory Complexity:** Higher than standard Gaussian Splatting due to the addition of distractor Gaussians and appearance embeddings [S1].
- **Strengths:** Reduces distractor artifacts and improves background reconstruction [S1].
- **Limitations:** Increased training time and memory usage due to distractor optimization and densification [S1]. Single-view reconstruction is ill-posed and less accurate than multi-view [S3, unofficial].
- **When to Use:** When distractor artifacts are prominent [S1].
- **When Not to Use:** Not given in the sources.

## Background
Originated from DeSplat: Decomposed Gaussian Splatting for Distractor-Free Rendering [S1]. The method extends standard Gaussian Splatting by explicitly modeling distractors [S1]. Symmetric View Mirroring was introduced in Pix2Vex for single-view reconstruction [S3, unofficial]. Perceptual loss weighting is adopted from VolSplat [S2]. Long-sequence stress testing evaluates stability over extended durations [S4].
