# Photometric Loss (RawNeRF Variant)

Also called: Color Loss, Gradient-Trick Photometric Loss, Raw-NeRF Loss, RawNeRF Photometric Loss

## Overview
This method is a specialized photometric loss function used to optimize neural radiance fields (NeRFs) and inverse rendering models by enforcing consistency between rendered pixel colors and ground truth images [S1, S2]. It distinguishes itself from standard Mean Squared Error (MSE) losses by applying a "gradient trick" that treats the radiance estimator as a constant during backpropagation, thereby reducing bias in the gradient estimation for Monte Carlo estimators [S3]. This approach is particularly effective when supervising cache-based predictions against physically-based models [S3].

## How it works
### Inputs and Outputs
*   **Inputs:**
    *   $\mathbf{o}$: Ray origin [S3].
    *   $\boldsymbol{\omega}_o$: Ray direction [S3].
    *   $I(\mathbf{o}, \boldsymbol{\omega}_o)$: Ground truth pixel color for the ray [S3].
    *   $\hat{L}_i(\mathbf{o}, \boldsymbol{\omega}_o; \Phi)$: Predicted radiance estimator (Monte Carlo estimate) parameterized by $\Phi$ [S3].
    *   $\hat{L}_i^{\text{cache}}(\mathbf{o}, \boldsymbol{\omega}_o; \Phi)$: Cache estimator used for normalization [S3].
    *   $R$: Set of rays in the training batch [S2].
*   **Outputs:**
    *   $\mathcal{L}_{\text{photometric}}$: The scalar loss value for the batch [S3].

### Data Structures
*   **Ray Batch:** A collection of rays, each defined by origin $\mathbf{o}$ and direction $\boldsymbol{\omega}_o$ [S1, S2].
*   **Ground Truth Image:** A tensor of RGB values corresponding to the camera poses of the rays [S1, S2].
*   **Predicted Radiance:** A tensor of RGB values generated by the forward pass of the radiance estimator [G].
*   **Cache Estimator:** A tensor of RGB values representing the cached radiance estimate, used for variance reduction and normalization [G].

### Steps
1.  Compute the difference between ground truth color $I(\mathbf{o}, \boldsymbol{\omega}_o)$ and the radiance estimator $\hat{L}_i(\mathbf{o}, \boldsymbol{\omega}_o; \Phi)$ [S3].
2.  Apply the `stopgrad` operator to this difference to treat it as a constant in the compute graph [S3].
3.  Multiply the original difference by the stop-graded difference [S3].
4.  Divide by the stop-graded cache estimator $\hat{L}_i^{\text{cache}}(\mathbf{o}, \boldsymbol{\omega}_o; \Phi)$ to normalize [S3].
5.  Use independent secondary samples to estimate the first and second differences in the numerator [S3].

### Formula
The standard photometric loss for NeRFs is defined as the Mean Squared Error (MSE) [S2]:
$$
L_{\text{color}} = \sum_{r \in R} \| \hat{C}(r) - C(r) \|^2
$$
where $R$ is the set of rays in the training batch, $\hat{C}(r)$ is the predicted color, and $C(r)$ is the ground truth color [S2].

The RawNeRF variant applies the gradient trick to minimize the expected squared error while correcting for bias [S3]:
$$
\mathcal{L}_{\text{photometric}} = \frac{2 (I(\mathbf{o}, \boldsymbol{\omega}_o) - \hat{L}_i(\mathbf{o}, \boldsymbol{\omega}_o; \Phi)) \operatorname{stopgrad}(I(\mathbf{o}, \boldsymbol{\omega}_o) - \hat{L}_i(\mathbf{o}, \boldsymbol{\omega}_o; \Phi))}{\operatorname{stopgrad}(\hat{L}_i^{\text{cache}}(\mathbf{o}, \boldsymbol{\omega}_o; \Phi))}
$$
where:
*   $I(\mathbf{o}, \boldsymbol{\omega}_o)$ is the ground truth color [S3].
*   $\hat{L}_i(\mathbf{o}, \boldsymbol{\omega}_o; \Phi)$ is the radiance estimator [S3].
*   $\Phi$ are the model parameters [S3].
*   $\hat{L}_i^{\text{cache}}(\mathbf{o}, \boldsymbol{\omega}_o; \Phi)$ is the cache estimator used for normalization [S3].
*   $\operatorname{stopgrad}(\cdot)$ is an operator that treats its argument as a constant in the compute graph, preventing gradient flow through it [S3].

### Parameters
*   **stopgrad(·):** An operator that freezes the gradient of its argument. It is applied to the cache estimator and the difference term to ensure correct gradient propagation through the Monte Carlo estimator [S3].
*   **Secondary Samples:** Independent samples used to estimate the differences in the numerator. The number of secondary rays (e.g., 64) can impact noise levels and relative PSNR [S3].

### Edge Cases and Pitfalls
*   **Monte Carlo Noise:** The loss is sensitive to noise in the radiance estimator. Rendering the predicted color image multiple times (e.g., 32 times) and averaging the results reduces noise [S3].
*   **Bias:** Using the cache estimator for normalization reduces bias in the gradient estimation. Failure to use `stopgrad` on the cache term may reintroduce bias [S3].
*   **Degenerate Input:** If the cache estimator is zero or near-zero, division by zero may occur. A small epsilon should be added to the denominator [G].

### Pseudocode
> **Unverified code.** The code below did not pass a test run against a reference implementation, or no test fits it, so it may contain errors.

```python
def rawnerf_photometric_loss(ground_truth_color, predicted_radiance, cache_estimator, epsilon=1e-8):
    """
    Computes the RawNeRF variant photometric loss.
    
    Args:
        ground_truth_color: List of RGB tuples for ground truth.
        predicted_radiance: List of RGB tuples for predicted radiance.
        cache_estimator: List of RGB tuples for cache estimates.
        epsilon: Small constant to prevent division by zero [G].
        
    Returns:
        loss: Scalar float representing the mean photometric loss over the batch.
    """
    # Step 1: Compute difference
    diff = [gt - pred for gt, pred in zip(ground_truth_color, predicted_radiance)]
    
    # Step 2: Apply stopgrad to the difference (conceptually detaches from compute graph)
    stopgrad_diff = diff[:] # Copy to break gradient flow
    
    # Step 3: Compute numerator: 2 * diff * stopgrad(diff)
    numerator = [2.0 * d * sg for d, sg in zip(diff, stopgrad_diff)]
    
    # Step 4: Normalize by stopgrad(cache_estimator)
    stopgrad_cache = [c for c in cache_estimator] # Copy to break gradient flow
    denominator = [max(c + epsilon, epsilon) for c in stopgrad_cache] # Prevent division by zero [G]
    
    # Step 5: Compute loss per ray
    loss_per_ray = [n / d for n, d in zip(numerator, denominator)]
    
    # Return mean loss over the batch
    return sum(loss_per_ray) / len(loss_per_ray)
```

## Subtopics

### Standard Photometric Loss
The baseline MSE loss used in NeRFs [S2]. It is simpler but may suffer from bias in Monte Carlo estimators [S3]. Choose this when using deterministic rendering or when bias is not a concern [G]. [Link](7799-photometric-reconstruction-loss.md)

### Depth Supervision
Often combined with photometric loss to improve geometric consistency [S2]. It uses MSE on depth maps [S2]. [Link](7799-photometric-reconstruction-loss.md)

### Neural Radiosity Loss (Static)
A training objective for static scenes using the residual of the rendering equation as the per-point loss, estimated via Monte Carlo integration [S4, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$, where $N$ is the number of rays in the batch [G].
*   **Memory Complexity:** $O(N)$ to store the gradients and intermediate tensors [G].
*   **Measured Performance:** Outperforms TensoIR in albedo metrics and relighting by a large margin, despite potential noise in renderings [S3].
*   **Strengths:** Reduces bias in gradient estimation for inverse rendering; effective for cache-based models [S3].
*   **Limitations:** Sensitive to Monte Carlo noise; requires rendering multiple times and averaging to reduce noise [S3].
*   **When to Use:** When optimizing NeRFs or inverse rendering models with stochastic radiance estimators and cache-based predictions [S3].
*   **When Not to Use:** When deterministic rendering is used and bias is not a concern [G].

## Background
The RawNeRF variant of the photometric loss was introduced to address bias in inverse rendering models that use cache-based predictions [S3]. It builds on the standard NeRF photometric loss [S1] and applies the gradient trick [S3] to ensure correct gradient propagation through Monte Carlo estimators. The method is used in physically-based inverse rendering frameworks to supervise NeRF caches against physically-based models [S3].
