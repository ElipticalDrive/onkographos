# Photometric Loss
Also called: Image reconstruction loss
## Overview
Photometric loss minimizes the difference between rendered pixels and input training images during joint optimization [S1]. It typically combines an $\ell_1$ reconstruction term with a differentiable Structural Similarity (D-SSIM) term to balance pixel-wise accuracy and perceptual structure [S2, S3].

## How it works
**Inputs and Outputs**
*   **Inputs:** Predicted color $\hat{C}(r_i)$ and ground-truth color $C(r_i)$ for sample $i$ along ray $r_i$; hyperparameters $\lambda$ (D-SSIM weight) or $\lambda_1$ (L1 weight), $\lambda_{\text{dist}}$, $\lambda_{\text{normal}}$ [S2, S3].
*   **Outputs:** Scalar loss value $\mathcal{L}_{\text{photo}}$ (and optionally total loss $\mathcal{L}$) [S2, S3].

**Data Structures**
*   Colors are 3-channel vectors (RGB) [S2, S3].
*   D-SSIM is computed over local windows (typically $3\times3$ or $11\times11$ pixels) in the 2D image plane [G].

**Steps**
1.  Compute the $\ell_1$ loss between predicted and ground-truth colors:
    $$ \mathcal{L}_1 = \frac{1}{N} \sum_{i=1}^N \| \hat{C}(r_i) - C(r_i) \|_1 $$
2.  Compute the differentiable SSIM loss $\mathcal{L}_{\text{D-SSIM}}$ between the rendered and ground-truth images. This involves calculating local means, variances, and covariance within a sliding window, using small constants $C_1, C_2$ for numerical stability [G].
3.  Combine them:
    $$ \mathcal{L}_{\text{photo}} = (1-\lambda)\mathcal{L}_1 + \lambda \mathcal{L}_{\text{D-SSIM}} $$
    where $\lambda$ controls the D-SSIM weight [S3]. (Note: [S2] uses $\lambda_1$ for the L1 weight, yielding $L_{img} = \lambda_1 L_1 + (1 - \lambda_1) L_{D-SSIM}$) [S2].
4.  (Optional) If optimizing primitives with depth and normals, add distortion and normal consistency losses to form the total loss:
    $$ \mathcal{L} = \mathcal{L}_{\text{photo}} + \lambda_{\text{dist}}\mathcal{L}_{\text{dist}} + \lambda_{\text{normal}}\mathcal{L}_{\text{normal}} $$
    where $\mathcal{L}_{\text{dist}}$ penalizes spread in rendered depth distributions and $\mathcal{L}_{\text{normal}}$ aligns primitive normals with depth-derived surface normals [S3].

**Parameters**
*   $\lambda$ (or $\lambda_1$): Weight for D-SSIM (or L1). Not given in the sources.
*   $\lambda_{\text{dist}}, \lambda_{\text{normal}}$: Weights for auxiliary losses. Not given in the sources.

**Edge Cases and Pitfalls**
*   **Precision:** D-SSIM requires careful handling of numerical stability in variance calculations (add small epsilon) [G].
*   **Boundaries:** Window-based SSIM requires padding or boundary handling for edge pixels [G].
*   **Degenerate Input:** If ground-truth images are missing or corrupted, $\mathcal{L}_1$ may diverge; clamping or masking is required [G].

**Pseudocode**
```python
import math

def compute_photometric_loss(rendered_image, gt_image, lambda_dssim=0.2):
    """
    Compute photometric loss combining L1 and D-SSIM.
    Args:
        rendered_image: List of lists of lists, shape (H, W, 3), predicted colors.
        gt_image: List of lists of lists, shape (H, W, 3), ground-truth colors.
        lambda_dssim: Weight for D-SSIM term.
    Returns:
        Scalar loss value.
    """
    h, w, c = len(rendered_image), len(rendered_image[0]), len(rendered_image[0][0])
    
    # L1 Loss: mean of L1 norms per pixel
    l1_sum = 0.0
    for i in range(h):
        for j in range(w):
            pixel_l1 = sum(abs(rendered_image[i][j][k] - gt_image[i][j][k]) for k in range(c))
            l1_sum += pixel_l1
    l1_loss = l1_sum / (h * w)
    
    # D-SSIM Loss
    dssim_loss = compute_dssim(rendered_image, gt_image)
    
    # Combined Loss
    photo_loss = (1 - lambda_dssim) * l1_loss + lambda_dssim * dssim_loss
    return photo_loss

def compute_dssim(img1, img2, window_size=11, C1=1e-4, C2=1e-4):
    """Compute differentiable SSIM loss using a Gaussian window."""
    h, w, c = len(img1), len(img1[0]), len(img1[0][0])
    kernel = create_gaussian_kernel(window_size)
    pad = window_size // 2
    
    # Precompute padded images for each channel
    padded1 = [[[0.0] * (w + 2 * pad) for _ in range(h + 2 * pad)] for _ in range(c)]
    padded2 = [[[0.0] * (w + 2 * pad) for _ in range(h + 2 * pad)] for _ in range(c)]
    for ch in range(c):
        for i in range(h):
            for j in range(w):
                padded1[ch][i + pad][j + pad] = img1[i][j][ch]
                padded2[ch][i + pad][j + pad] = img2[i][j][ch]
                
    ssim_sum = 0.0
    valid_pixels = 0
    
    for ch in range(c):
        for i in range(h):
            for j in range(w):
                # Extract local window
                window1 = [padded1[ch][i + pad + di][j + pad + dj] for di in range(window_size) for dj in range(window_size)]
                window2 = [padded2[ch][i + pad + di][j + pad + dj] for di in range(window_size) for dj in range(window_size)]
                
                n = len(window1)
                mu1 = sum(window1) / n
                mu2 = sum(window2) / n
                
                sigma1_sq = sum((x - mu1)**2 for x in window1) / n
                sigma2_sq = sum((x - mu2)**2 for x in window2) / n
                sigma12 = sum((window1[k] - mu1) * (window2[k] - mu2) for k in range(n)) / n
                
                ssim_val = ((2 * mu1 * mu2 + C1) * (2 * sigma12 + C2)) / \
                           ((mu1**2 + mu2**2 + C1) * (sigma1_sq + sigma2_sq + C2))
                ssim_sum += ssim_val
                valid_pixels += 1
                
    return 1.0 - (ssim_sum / valid_pixels)

def create_gaussian_kernel(window_size, sigma=1.5):
    """Create a 1D Gaussian kernel and return outer product."""
    coords = [i - window_size // 2 for i in range(window_size)]
    kernel_1d = [math.exp(-(x**2) / (2 * sigma**2)) for x in coords]
    kernel_2d = [[kernel_1d[i] * kernel_1d[j] for j in range(window_size)] for i in range(window_size)]
    total = sum(sum(row) for row in kernel_2d)
    return [[val / total for val in row] for row in kernel_2d]
```

## Subtopics

### Weighted Photometric Loss
A variant that re-scales the loss with a weight $w_i$ to focus on hard samples for faster convergence [S4]. The weight is calculated as the L2 norm of the color difference divided by the minimum L2 norm across all samples, clamped to $[1, 10]$ [S4]. The loss is defined as $L_p = \frac{1}{N} \sum_{i=1}^N \langle w_i \rangle \| \hat{C}(r_i) - C(r_i) \|_2^2$, where $\langle \cdot \rangle$ denotes the stop-gradient operation [S4]. It is often combined with an L1 regularizer on view-dependent color: $L = L_p + \lambda L_r$ [S4].

## Operating characteristics
*   **Time Complexity:** Linear in the number of pixels and samples per pixel [G]. D-SSIM adds a constant factor related to window size [G].
*   **Memory Complexity:** Linear in image resolution for storing intermediate SSIM maps [G].
*   **Strengths:** Robust to noise; D-SSIM preserves structural details better than pure L1 [G].
*   **Limitations:** Computationally heavier than L1 alone; sensitive to hyperparameter $\lambda$ [G].
*   **When to use:** Standard for novel view synthesis when perceptual quality is prioritized [G].
*   **When not to use:** Real-time applications where speed is critical; scenes with significant lighting changes where photometric consistency is low [G].

## Background
Photometric loss is a standard component in differentiable rendering and neural radiance field (NeRF) optimization [G]. The combination of L1 and D-SSIM was adopted in methods like 2D Gaussian Splatting and Fourier Splatting [S2, S3]. The weighted variant was introduced in Lightning NeRF to address convergence speed in autonomous driving scenes [S4].
