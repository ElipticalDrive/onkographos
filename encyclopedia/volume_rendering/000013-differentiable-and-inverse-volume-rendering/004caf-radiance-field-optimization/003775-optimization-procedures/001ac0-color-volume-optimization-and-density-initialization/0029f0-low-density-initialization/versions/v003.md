# Low-density initialization
Also called: Density Initialization with Bias

## Overview
Low-density initialization is a technique in differentiable volume rendering that initializes the density field with near-zero opacity to prevent early convergence to incorrect local minima [S1]. It achieves this by deriving a scalar bias term that ensures the initial activated alpha value is very close to zero at the start of optimization [S1].

## How it works
**Inputs and Outputs:**
- Input: Voxel size $s$, target initial activated alpha $\alpha_{init}$ [S1].
- Output: A scalar bias term $b$ added to raw density values [S1].

**Data Structures:**
- Raw density volume $V_{density}(c)$: A 3D grid storing raw density values $\hat{\sigma}$ [S1].
- Bias $b$: A single scalar value [S1].

**Steps:**
1. Initialize all raw density values $\hat{\sigma}$ in $V_{density}(c)$ to 0 [S1].
2. Calculate the initial activated density $\sigma_i$ for all segments using the softplus function with bias:
   $$ \sigma_i = \log(1 + \exp(b)) $$
   [S1]
3. Determine the bias $b$ such that the accumulated transmittance decay factor over a distance equal to the voxel size $s$ matches the target $(1 - \alpha_{init})$ [S1]. The relationship is derived from the product of segment transmittances:
   $$ \prod_{i=1}^{N} (1 - \alpha_i) = (1 + \exp(b))^{-s} $$
   where $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ and $\sigma_i = \log(1 + \exp(b))$ [S1].
4. Solve for $b$:
   $$ b = \log \left( (1 - \alpha_{init})^{-1/s} - 1 \right) $$
   [S1]

**Parameters:**
- $\alpha_{init}(c)$: A hyperparameter representing the target activated alpha value; $1 - \alpha_{init}(c)$ serves as the decay factor of accumulated transmittance for a ray tracing forward a distance of the voxel size $s(c)$ [S1].
- $s$: The voxel size (or sum of segment lengths $\delta_i$) [S1].

**Pseudocode:**
```python
import math

def compute_low_density_bias(alpha_init, voxel_size):
    """Computes the bias term for low-density initialization."""
    decay_factor_inv = (1.0 - alpha_init) ** (-1.0 / voxel_size)
    bias = math.log(decay_factor_inv - 1.0)
    return bias

def initialize_density_volume(volume_shape, voxel_size, alpha_init):
    """Initializes a density volume with low density using bias."""
    D, H, W = volume_shape
    density_volume = [[[0.0 for _ in range(W)] for _ in range(H)] for _ in range(D)]
    bias = compute_low_density_bias(alpha_init, voxel_size)
    return density_volume, bias
```

**Edge Cases and Pitfalls:**
- If $\alpha_{init}$ is too close to 1, the term $(1 - \alpha_{init})$ approaches 0, leading to numerical instability in the logarithm [G].
- If $s$ is very small, the exponent $-1/s$ becomes large, potentially causing overflow in $(1 - \alpha_{init})^{-1/s}$ if not handled with care [G].
- The method assumes a uniform voxel size $s$ [G].

## Subtopics

### [Density and Temperature Bias Initialization](4824-density-and-temperature-bias-initialization.md)
Builds on [Low-density initialization](4670-low-density-initialization.md). This method initializes the bias term of the final layer in a neural radiance field network to the midpoint of the log-space bounds for density and temperature. By setting the initial output to the center of the valid range, it ensures that the predicted values start within the valid range. It differs from sibling methods like Alpha Invariance Initialization by explicitly targeting the log-space parameters rather than relying on alpha-invariance constraints. When to choose it: use when log-space parameter bounds are known and a neutral starting point is preferred over a transmittance-derived bias [G].

### [Alpha Invariance Initialization](10064-alpha-invariance-initialization.md)
Alpha Invariance Initialization is a method to initialize the density-predicting network in neural radiance fields such that the average volume transmittance $T'$ is high (e.g., 0.99) regardless of the scene scale $L$. It solves the problem of optimization failure in neural radiance fields when scene scales change, where standard parameterizations either fail to produce sufficient density for small intervals or cause cloudiness for large intervals. It sets itself apart from sibling methods by providing a theoretical foundation for density initialization and activation function selection, rather than just a heuristic initialization step. When to choose it: use when training across varying scene scales or when theoretical transmittance guarantees are required [G].

## Background
Low-density initialization was introduced in the paper "Direct Voxel Grid Optimization: Super-fast Convergence for Radiance Fields Reconstruction" [S1]. It is used as an optimization procedure within color volume optimization pipelines to initialize the density field before final density optimization [S1].
