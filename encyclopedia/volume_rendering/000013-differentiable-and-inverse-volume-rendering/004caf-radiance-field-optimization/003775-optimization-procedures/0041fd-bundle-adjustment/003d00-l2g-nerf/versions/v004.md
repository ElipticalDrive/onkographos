# L2G-NeRF

Also called: Local-to-Global Registration for Bundle-Adjusting Neural Radiance Fields

## Overview
L2G-NeRF is a bundle-adjusting method that jointly optimizes neural 3D representations and camera poses by combining a local photometric alignment objective with a global geometric alignment objective [S1]. It differs from purely parametric methods (like BARF) by using a local-to-global process that is more robust to poor initialization, and from purely non-parametric methods by enforcing global geometric constraints via differentiable solvers [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $M$ images $\{I_i\}_{i=1}^M$, their initial camera poses (typically identity $T_i=I$), and query pixel coordinates $\{x_j\}_{j=1}^N$.
*   **Outputs:** Optimized neural field parameters $\Theta$, optimized camera poses $\{T_i\}_{i=1}^M$, and a warp field $\Phi$ for local transformations.

**Data Structures:**
1.  **Neural Field MLP ($f_R$):**
    *   **3D NeRF:** Input is a 3D coordinate $\mathbb{R}^3$. Output is a 4D vector $[c; \sigma] \in \mathbb{R}^4$ (RGB color $c$ and volume density $\sigma$) [S1].
    *   **2D Image:** Input is a 2D coordinate $\mathbb{R}^2$. Output is a 3D vector (RGB color) [S1].
2.  **Warp Neural Field MLP ($f_W$):**
    *   Input is a 2D coordinate $x \in \mathbb{R}^2$ and a frame-dependent embedding $\ell_i \in \mathbb{R}^d$.
    *   Output is a Lie algebra vector (se(2) or sl(3)) [S1].
3.  **Camera Pose:** $T_i \in SE(3)$, parameterized as $[R|t]$ where $R = \exp(r)$ via exponential map from $\mathfrak{so}(3)$ to $SO(3)$, and $t \in \mathbb{R}^3$ [S1].

**Numbered Steps:**

1.  **Initialization:** Initialize all camera poses to identity $T_i = I \forall i$. Perturb initial poses using right multiplication to alter viewing directions and distances [S1]. Additive noise $r \sim \mathcal{N}(0, n_r I)$ and $t \sim \mathcal{N}(0, n_t I)$ is applied in the Lie algebra and translation space respectively [S1].

2.  **Stage 1: Local Alignment (Non-parametric):**
    *   Predict a local transformation field $T_{ji}$ for each pixel $x_j$ of each camera frame $i$ using the warp neural field:
        $$ T_{ji} = W(x_j; \ell_i, \Phi) = \exp(f_W(x_j; \ell_i, \Phi)) $$
        where $\exp(\cdot)$ maps the Lie algebra output to the Lie group (SE(2) for 2D, SE(3) for 3D) [S1].
    *   Optimize $\Theta$ and $\Phi$ (and embeddings $\ell_i$) by minimizing the local photometric error:
        $$ L_{local} = \sum_{i=1}^M \sum_{j=1}^N \| R(T_{ji} x_j; \Theta) - I_i(x_j) \|^2 $$
    *   For 3D NeRF, the rendering $R(T_{ji} x_j; \Theta)$ is computed via volume rendering. Given ray depth samples $\{z_k\}_{k=1}^K$, the 3D point is $z_k T_{ji} x_j$. The network outputs $y_k = f_R(z_k T_{ji} x_j; \Theta)$. The color is composited as $R(x) = g(y_1, ..., y_K)$ [S1].

3.  **Stage 2: Global Alignment (Parametric):**
    *   Solve for the global frame-wise transformation $T^*_i$ for each frame $i$ by minimizing the alignment error between the local pixel-wise transformations and the global rigid transformation. This is an orthogonal Procrustes problem:
        $$ T^*_i = \arg \min_{T_i} \sum_{j=1}^N \| T_{ji} x_j - T_i x_j \|^2 $$
    *   The closed-form solution for the optimal rigid transformation $T=[R|t]$ is:
        $$ R = V U^T, \quad t = -R\bar{x} + \overline{T x} $$
        where $\bar{x}$ and $\overline{T x}$ are centroids of $\{x_j\}$ and $\{T_{ji} x_j\}$, and $H = \sum_{j=1}^N (x_j - \bar{x})(T_{ji} x_j - T\bar{x})^T = U S V^T$ is the SVD of the covariance matrix $H$ [S1].

4.  **Joint Optimization:**
    *   Minimize the combined relaxed objective function:
        $$ \min_{\{T_{ji}\}, \Theta} \sum_{i=1}^M \sum_{j=1}^N \| R(T_{ji} x_j; \Theta) - I_i(x_j) \|^2 + \lambda \| T_{ji} x_j - T^*_i x_j \|^2 $$
    *   The global alignment term acts as a soft constraint on the local alignment, ensuring geometric consistency [S1].
    *   Gradients flow from the global alignment loss back to the local pose parameters (and thus to $\Phi$ and $\Theta$) via the differentiable Procrustes solver [S1].

5.  **Convergence Schedule:**
    *   Linearly increase noise multipliers $n_r$ and $n_t$ by a common factor $\{n_c\}_{c=2}^9$ starting from base values $n_r=0.01, n_t=0.1$ [S1].

# Helper: Exponential map from Lie algebra to Lie group
def exp_so3(w):
    """
    w: [3] Lie algebra vector (axis-angle)
    Returns: [3,3] Rotation matrix
    """
    theta = torch.norm(w, dim=-1, keepdim=True)
    w_hat = skew_symmetric(w / (theta + 1e-8))
    # Rodrigues' formula
    I = torch.eye(3)
    R = I + torch.sin(theta) * w_hat + (1 - torch.cos(theta)) * torch.bmm(w_hat, w_hat)
    return R.squeeze()

def skew_symmetric(v):
    """
    v: [3]
    Returns: [3,3] skew-symmetric matrix
    """
    return torch.tensor([[0, -v[2], v[1]],
                         [v[2], 0, -v[0]],
                         [-v[1], v[0], 0]], dtype=v.dtype)

# Helper: Orthogonal Procrustes Solver
def solve_procrustes(points_source, points_target):
    """
    points_source: [N, 3] Local transformed points (T_ji * x_j)
    points_target: [N, 3] Original points (x_j)
    Returns: [3,3] R, [3] t
    """
    # Centroids
    mu_s = torch.mean(points_source, dim=0)
    mu_t = torch.mean(points_target, dim=0)
    
    # Centered points
    X = points_source - mu_s
    Y = points_target - mu_t
    
    # Covariance matrix H
    H = torch.matmul(X.t(), Y)
    
    # SVD
    U, S, Vt = torch.linalg.svd(H)
    V = Vt.t()
    
    # Rotation
    R = torch.matmul(V, U.t())
    
    # Check for reflection
    if torch.det(R) < 0:
        V[:, -1] *= -1
        R = torch.matmul(V, U.t())
        
    # Translation
    t = mu_t - torch.matmul(R, mu_s)
    
    return R, t

# Main Optimization Loop

**Parameters:**
*   $\lambda$: Weighting factor for the global constraint. Typical value $1 \times 10^2$ for synthetic/object-centric scenes; floated between $1 \times 10^2$ and $1 \times 10^5$ for forward-facing LLFF scenes [S1].
*   $n_r$: Base rotation noise multiplier. Scene-dependent values range from 0.01 to 0.09 [S1].
*   $n_t$: Base translation noise multiplier. Scene-dependent values range from 0.3 to 0.7 [S1].
*   $K$: Number of points sampled along a ray for discretizing the volume rendering integral [S1].

**Edge Cases and Pitfalls:**
*   **Poor Initialization:** Parametric methods fall into suboptimal solutions if poorly initialized. L2G-NeRF mitigates this with the local-to-global process [S1].
*   **Large Displacements:** Non-parametric methods struggle with large displacements. L2G-NeRF handles this via the global constraint [S1].
*   **Inward-Facing 360° Scenes:** Fails to recover camera poses from identity transformation for inward-facing 360° scenes with large rotation displacements [S1].
*   **High $\lambda$:** Large $\lambda$ ($1 \times 10^5$) improves geometric accuracy but reduces robustness, potentially causing divergence (e.g., on the Flower scene) [S1].

## Operating characteristics
*   **Time Complexity:** Training time on NVIDIA GeForce RTX 2080 Ti is ~4.5 hours for synthetic objects and ~8 hours for real-world scenes. This is comparable to reference NeRF and faster than BARF (~8 and ~10.5 hours respectively) [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Scaling:** The method is agnostic to the type of neural field and works for both 2D images and 3D NeRF [S1].
*   **Strengths:** More robust to poor initialization than parametric methods (BARF). Tolerates larger noise perturbations before divergence ($n_c=8$ vs $n_c=4$ for BARF) [S1].
*   **Limitations:** Cannot recover poses from scratch for inward-facing 360° scenes with large rotations [S1].

## Background

The method combines parametric and non-parametric approaches to overcome the limitations of each when used alone [S1].
