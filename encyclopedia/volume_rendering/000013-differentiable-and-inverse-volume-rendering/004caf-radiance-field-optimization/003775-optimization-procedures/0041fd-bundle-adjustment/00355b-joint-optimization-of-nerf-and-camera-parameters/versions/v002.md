# Joint Optimization of NeRF and Camera Parameters

Also called: Neural Radiance Fields Without Known Camera Parameters

## Overview
This method jointly optimizes a Neural Radiance Field (NeRF) model and camera parameters (poses and focal length) for forward-facing images, eliminating the need for pre-computed camera poses via Structure-from-Motion (SfM) systems like COLMAP [S1, unofficial]. It simplifies classical two-stage Novel View Synthesis (NVS) pipelines by treating camera extrinsics and intrinsics as learnable parameters alongside the neural network weights [S1, unofficial]. Unlike [Bundle Adjustment](8540-bundle-adjustment.md), which typically refines known poses, this approach initializes poses randomly or with coarse estimates and converges them simultaneously with the scene representation [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ training images $\{I_i\}_{i=1}^N$ with pixel coordinates $\{p_{i,m}\}$, where $M$ is the number of pixels per image [S1, unofficial].
*   **Outputs:** Optimized NeRF network parameters $\hat{\Theta}$, camera poses $\{\hat{\phi}_i, \hat{t}_i\}_{i=1}^N$ (rotation and translation), and focal length $\hat{f}$ [S1, unofficial].

**Data Structures:**
*   **Camera Poses:** $\hat{\phi}_i \in \mathbb{R}^3$ (axis-angle representation) and $\hat{t}_i \in \mathbb{R}^3$ for each image $i$ [S1, unofficial].
*   **Focal Length:** $\hat{f} \in \mathbb{R}$, a single scalar value [S1, unofficial].
*   **NeRF Network:** A multi-layer perceptron $F_\Theta$ taking position and view direction as input, outputting color and density [S1, unofficial].

**Parameters:**
*   **NeRF Architecture:** A smaller variant of the original NeRF [S1, unofficial]. Hidden layer dimensions are halved: the first 9 layers have 128 units (original 256), and the final layer has 64 units (original 128) [S1, unofficial]. Positional encoding frequencies and skip connections match the original NeRF implementation [S1, unofficial].
*   **Focal Length Initialization:** Initialized to the input image width $W$ [S1, unofficial].
*   **Scale Factor:** A parameter $s$ (or $\tilde{s}$) used to parameterize focal length, initialized to 1.0 [S1, unofficial].

**Step-by-Step Method:**
1.  **Ray Construction:** For each image $i$ and pixel $m$, construct the ray direction $\hat{d}_{i,m}$ using the current estimated pose $\hat{\phi}_i$, translation $\hat{t}_i$, focal length $\hat{f}$, and pixel coordinates $p_{i,m}$ [S1, unofficial].
2.  **Point Sampling:** Sample points $x_h$ along the ray for heights $h$ ranging from the near plane $h_n$ to the far plane $h_f$ [S1, unofficial].
3.  **NeRF Query:** Query the NeRF network $F_\Theta$ with position $x_h$ and direction $\hat{d}_{i,m}$ to obtain color $c_h$ and density $\sigma_h$ [S1, unofficial].
4.  **Volume Rendering:** Render the pixel value $\hat{I}_{i,m}$ using the collected colors and densities via standard volume rendering integration [S1, unofficial].
5.  **Loss Computation:** Compute the loss $\mathcal{L}$ between the rendered image $\hat{I}_i$ and the ground truth image $I_i$ [S1, unofficial].
6.  **Optimization:** Perform a backward pass and update parameters $[\hat{\phi}_i]$, $[\hat{t}_i]$, $\hat{f}$, and $\hat{\Theta}$ using an optimizer (e.g., Adam) [S1, unofficial].

**Focal Length Parameterization:**
Directly optimizing $f$ in pixel units is numerically difficult due to large magnitudes [S1, unofficial]. Two parameterizations are used:
1.  **1st-order:** $f = s W$, where $s$ is initialized to 1.0 [S1, unofficial].
2.  **2nd-order (Preferred):** $f = \tilde{s}^2 W$, where $\tilde{s}$ is initialized to 1.0. This yields slightly better results (Mean PSNR 22.48 vs 22.26 on LLFF-NeRF) [S1, unofficial].
3.  **Single vs. Dual:** Optimizing a single focal length $f$ yields no performance difference compared to optimizing separate horizontal $f_x$ and vertical $f_y$ focal lengths; $f$ is chosen for simplicity [S1, unofficial].

**Evaluation Alignment:**
To eliminate camera mis-alignment effects during evaluation, optimized parameters are aligned with COLMAP estimates using a Sim(3) transformation via the Umeyama algorithm, followed by gradient-driven camera pose alignment minimizing photometric error on synthesized images while keeping the NeRF model fixed [S1, unofficial].

```python
import torch.nn.functional as F

def construct_ray_direction(poses, translations, focal_length, pixel_coords, image_width, image_height):
    # poses: (N, 3) axis-angle, translations: (N, 3), focal_length: scalar
    # pixel_coords: (M, 2) (u, v)
    # Returns: (N, M, 3) ray directions in world space
    R = axis_angle_to_rotation_matrix(poses)
    R_inv = R.transpose(-2, -1)
    u = pixel_coords[:, 0] - image_width / 2.0
    v = pixel_coords[:, 1] - image_height / 2.0
    ray_cam = torch.stack([u / focal_length, v / focal_length, torch.ones_like(u)], dim=-1)
    ray_world = torch.matmul(R_inv, ray_cam.unsqueeze(-1)).squeeze(-1)
    return ray_world

def sample_points_along_ray(ray_direction, translation, near_plane, far_plane, num_samples):
    # ray_direction: (3,), translation: (3,)
    # Returns: (num_samples, 3) points in world space
    t = torch.linspace(near_plane, far_plane, num_samples)
    points = translation.unsqueeze(0) + t.unsqueeze(1) * ray_direction.unsqueeze(0)
    return points

def render_volume_rendering(colors, densities):
    # colors: (num_samples, 3), densities: (num_samples,)
    # Returns: (3,) rendered color
    delta = 1.0  # [G] Assumes uniform sampling; in practice delta_t = (far-near)/(num_samples-1)
    alpha = 1.0 - torch.exp(-densities * delta)
    transmittance = torch.cumprod(1.0 - alpha + 1e-10, dim=0)
    weights = alpha * transmittance
    rendered_color = torch.sum(weights.unsqueeze(-1) * colors, dim=0)
    return rendered_color

def joint_optimization(images, pixel_coords, image_width, image_height, near_plane, far_plane, num_samples, num_iterations):
    N = images.shape[0]
    M = images.shape[1] * images.shape[2]
    pixel_coords_flat = pixel_coords.view(N, M, 2)

    # Initialize parameters
    poses = nn.Parameter(torch.randn(N, 3))
    translations = nn.Parameter(torch.randn(N, 3))
    s_tilde = nn.Parameter(torch.tensor(1.0))

    # NeRF Network (simplified MLP structure per [S1, unofficial])
    nerf = nn.Sequential(
        nn.Linear(3, 128), nn.ReLU(),
        nn.Linear(128, 128), nn.ReLU(),
        nn.Linear(128, 128), nn.ReLU(),
        nn.Linear(128, 128), nn.ReLU(),
        nn.Linear(128, 128), nn.ReLU(),
        nn.Linear(128, 128), nn.ReLU(),
        nn.Linear(128, 128), nn.ReLU(),
        nn.Linear(128, 128), nn.ReLU(),
        nn.Linear(128, 128), nn.ReLU(),
        nn.Linear(128, 64), nn.ReLU(),
        nn.Linear(64, 4)  # 3 for color, 1 for density
    )

    optimizer = torch.optim.Adam([
        {'params': nerf.parameters()},
        {'params': poses},
        {'params': translations},
        {'params': [s_tilde]}
    ], lr=0.001)

    for step in range(num_iterations):
        optimizer.zero_grad()
        focal_length = s_tilde ** 2 * image_width
        total_loss = 0.0

        for i in range(N):
            ray_dirs = construct_ray_direction(
                poses[i:i+1], translations[i:i+1], focal_length,
                pixel_coords_flat[i], image_width, image_height
            )
            rendered_image = torch.zeros_like(images[i])

            for m in range(M):
                points = sample_points_along_ray(
                    ray_dirs[m], translations[i], near_plane, far_plane, num_samples
                )
                # [G] Standard NeRF uses positional encoding for position and direction
                pos_enc = torch.sin(torch.cat([points, points], dim=-1))
                dir_enc = torch.sin(torch.cat([ray_dirs[m].expand_as(points), ray_dirs[m].expand_as(points)], dim=-1))
                features = nerf(torch.cat([pos_enc, dir_enc], dim=-1))
                colors = features[:, :3]
                densities = features[:, 3:]

                rendered_pixel = render_volume_rendering(colors, densities)
                rendered_image[m] = rendered_pixel

            loss = F.mse_loss(rendered_image, images[i])
            total_loss += loss

        total_loss.backward()
        optimizer.step()

    return nerf, poses, translations, s_tilde
```

## Operating characteristics
*   **Time Complexity:** Training is slower than fixed-camera NeRF due to the additional gradients flowing through camera parameters [S1, unofficial]. A BLEFF scene with 27 training images takes approximately 5.5 hours on a single GPU [S1, unofficial].
*   **Memory Complexity:** Increases slightly due to the storage of learnable pose parameters ($6N$ floats) and the scale factor, but the dominant memory cost remains the NeRF network and intermediate rendering buffers [S1, unofficial].
*   **Strengths:** Eliminates the dependency on SfM pipelines (e.g., COLMAP), which can fail on textureless or repetitive scenes [S1, unofficial]. Simplifies the NVS pipeline to a single end-to-end optimization step [S1, unofficial].
*   **Limitations:** Designed for static scenes and forward-facing images; cannot handle dynamic objects [S1, unofficial]. Convergence may be sensitive to initialization [S1, unofficial]. The method does not inherently handle radiometric calibration or viewpoint selection, which are addressed by sibling methods [1121-best-viewpoint-selection-via-opacity-entropy.md] and [1820-radiometric-self-calibration.md] [S1, unofficial].
*   **When to Use:** When camera poses are unknown, unreliable, or when a simplified pipeline is preferred over a two-stage SfM+NeRF approach [S1, unofficial].
*   **When Not to Use:** For dynamic scenes, or when high-precision metric reconstruction is required without careful evaluation alignment [S1, unofficial].

## Background
The method was introduced in "NeRF--: Neural Radiance Fields Without Known Camera Parameters" [S1, unofficial]. It addresses the limitations of classical two-stage NVS systems that rely on pre-computed camera poses [S1, unofficial]. The authors demonstrated that joint optimization is feasible and effective for forward-facing datasets like LLFF and BLEFF [S1, unofficial]. The approach builds on the differentiable rendering framework of original NeRF but extends the optimization domain to include camera extrinsics and intrinsics [S1, unofficial].
