# High-Frequency Aware Loss

Also called: LHF, Shallow VGG Loss

## Overview
High-Frequency Aware Loss (LHF) is a perceptual regularization term designed to recover high-frequency details in rendered images while avoiding the texture distortion common in deeper perceptual losses [S1]. It sets itself apart from standard VGG-based perceptual losses by restricting feature extraction to the first block of the network, before any max-pooling operations, thereby preserving fine-grained spatial information [S1]. It builds on [Perceptual Loss Training](2000-perceptual-loss-training.md) by specifically targeting the loss of high-frequency content that occurs when using pixel-wise losses on misaligned data [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A rendered patch $R$ and a ground truth patch $G_i$ (aligned to the rendered view) [S1].
*   **Output:** A scalar loss value $L_{HF}$ [S1].

**Data Structures:**
*   $F$: The feature extractor, defined as the first block of a pre-trained VGG-19 model (before max-pooling) [S1].
*   Feature maps: The output of $F$ has dimensions $C \times W \times H$, where $C$ is the number of channels, and $W, H$ are the width and height of the feature map [S1].

**Parameters:**
*   $w$: A weighting scalar for the loss term (used in combination with patch MSE) [S1].
*   $F$: Fixed pre-trained weights from VGG-19 [S1].

**Steps:**
1. Extract features from the rendered patch $R$ using the shallow VGG block: $F_R = F(R)$ [S1].
2. Extract features from the aligned ground truth patch $G_i$: $F_{GT} = F(G_i)$ [S1].
3. Compute the squared Euclidean distance between the feature maps [S1].
4. Normalize by the total number of elements in the feature map ($C \times W \times H$) [S1].

**Formula:**
$$L_{HF}(G_i, R) = \frac{1}{2CW H} \|F(G_i) - F(R)\|_2^2$$ [S1]

Where:
*   $\| \cdot \|_2^2$ denotes the squared L2 norm (sum of squared differences) [S1].
*   $C, W, H$ are the dimensions of the feature maps produced by $F$ [S1].
*   $G_i$ is the ground truth patch after alignment [S1].
*   $R$ is the rendered patch [S1].

**Pseudocode:**
```python
def high_frequency_aware_loss(rendered_patch, ground_truth_patch, vgg_block):
    """
    Computes the High-Frequency Aware Loss.
    
    Args:
        rendered_patch (Tensor): Rendered image patch R.
        ground_truth_patch (Tensor): Aligned ground truth patch G_i.
        vgg_block (Module): The first block of a pre-trained VGG-19 model 
                            (convolutions + ReLUs, no pooling).
                            
    Returns:
        Tensor: Scalar loss value L_HF.
    """
    # Extract features using the shallow VGG block
    features_rendered = vgg_block(rendered_patch)
    features_gt = vgg_block(ground_truth_patch)
    
    # Compute squared L2 difference
    diff = features_rendered - features_gt
    squared_diff = diff ** 2
    
    # Sum over all elements
    sum_squared_diff = sum(squared_diff.flatten())
    
    # Get dimensions C, W, H
    C, W, H = features_rendered.shape[1], features_rendered.shape[2], features_rendered.shape[3]
    
    # Normalize by 2 * C * W * H
    loss = sum_squared_diff / (2 * C * W * H)
    
    return loss
```

**Edge Cases and Pitfalls:**
*   **Misalignment:** The loss assumes $G_i$ is properly aligned with $R$. Misalignment prevents the recovery of high-frequency details, as the features will not match even if the content is correct [S1].
*   **Texture Distortion:** While deeper VGG losses distort textures, this shallow variant preserves them [S1].

## Subtopics

### [VGG Loss for Image Patches](7699-vgg-loss-for-image-patches.md)
A perceptual regularization term that encourages generated image patches to match high-level feature representations of real patches using a pre-trained VGG network. It sets itself apart by operating on specific patch regions rather than the full image, building on High-Frequency Aware Loss [7589-high-frequency-aware-loss.md]. Choose it when patch-level perceptual matching is required for localized alignment refinement.

## Background
The High-Frequency Aware Loss was introduced in the AligNeRF paper [S1]. It was developed to address the limitations of standard perceptual losses, which, while good at capturing high-frequency details, often distort the actual texture of objects [S1]. The authors modified the original perceptual loss proposed by Johnson et al. [12] by using only the output of the first block of VGG-19 before max-pooling [S1]. This approach was integrated into the AligNeRF training pipeline, replacing per-pixel MSE loss with a combination of patch-based MSE and this shallow VGG feature-space loss [S1].
