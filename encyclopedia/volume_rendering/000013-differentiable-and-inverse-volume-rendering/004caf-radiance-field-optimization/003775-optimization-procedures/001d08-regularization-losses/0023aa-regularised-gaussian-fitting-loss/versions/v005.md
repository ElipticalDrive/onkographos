# Regularised Gaussian Fitting Loss

Also called: L1+Regularization Loss for Gaussians, Regularised Loss Function for Gaussian Fitting

## Overview
The Regularised Gaussian Fitting Loss is a composite objective function used to optimize Gaussian splat representations for volume rendering, specifically balancing reconstruction accuracy against geometric priors. It combines an L1 reconstruction loss with regularization terms for splat amplitude and extent [S1, unofficial]. It is distinguished from standard photometric losses by its explicit penalization of the softplus-activated parameters governing the Gaussian covariance diagonal and amplitude, ensuring stable optimization of the splat geometry during early-stopped training [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs:** A set of $K$ Gaussian splats, each defined by parameters including amplitude $a_k$ and a diagonal covariance matrix represented by softplus-activated entries $L_{k,ii}$. A target volume and a predicted volume rendered from the current splat configuration.
*   **Outputs:** A scalar loss value $L$ used for gradient-based optimization.

**Data Structures**
*   **Splat Parameters:** Each splat $k$ has an amplitude $a_k$ and a diagonal covariance matrix. The diagonal entries are stored as softplus-activated parameters $L_{k,ii}$ to ensure positivity, with a floor $\sigma_{\min}$ [S1, unofficial].
*   **Volume Grid:** Target and predicted volumes are sampled at ray positions.

**Formulas**
The total loss is defined as [S1, unofficial]:

$$
L = L_{\text{recon}} + \lambda_a \sum_{k=1}^K |a_k| + \lambda_d \sum_{k=1}^K \sum_{i=1}^D |L_{k,ii} - \sigma_{\min}|
$$

Where:
*   $L_{\text{recon}}$ is the L1 reconstruction loss between the predicted and target volumes.
*   $K$ is the number of splats.
*   $D$ is the dimensionality of the space (typically 3).
*   $a_k$ is the amplitude of splat $k$.
*   $L_{k,ii}$ is the $i$-th diagonal entry of the covariance matrix for splat $k$ (post-softplus).
*   $\sigma_{\min}$ is the minimum floor for the covariance diagonal.
*   $\lambda_a$ and $\lambda_d$ are regularization weights.

**Parameters**
*   $\lambda_a = 0.1 \times \text{lr}$ (Typically $10^{-3}$ if learning rate $\text{lr} = 0.01$) [S1, unofficial].
*   $\lambda_d = 0.01 \times \text{lr}$ (Typically $10^{-4}$ if learning rate $\text{lr} = 0.01$) [S1, unofficial].
*   $\lambda_b = 0$ (Boundary term disabled in standard benchmarks) [S1, unofficial].

**Numbered Steps**
1.  **Render:** Compute the predicted volume $\hat{V}$ from the current Gaussian splats using the standard emission-absorption model.
2.  **Reconstruction Loss:** Calculate $L_{\text{recon}} = \sum |V_{\text{target}} - \hat{V}|$. L1 is preferred over MSE or Poisson deviance for better held-out PSNR [S1, unofficial].
3.  **Amplitude Regularization:** Compute the penalty $\lambda_a \sum_{k=1}^K |a_k|$. This is evaluated before any amplitude clamp $a_{\max}$ is applied [S1, unofficial].
4.  **Extent Regularization:** Compute the penalty $\lambda_d \sum_{k=1}^K \sum_{i=1}^D |L_{k,ii} - \sigma_{\min}|$. This penalizes deviation from the minimum covariance floor. This is evaluated before the amplitude clamp [S1, unofficial].
5.  **Boundary Term (Optional):** If enabled ($\lambda_b > 0$), compute $L_{\text{boundary}} = \sum_{k,i} [ \max(0, r_{k,i} - \mu_{k,i})^2 + \max(0, r_{k,i} - (S_i - 1 - \mu_{k,i}))^2 ]$, where $r_{k,i} = \tau \sqrt{\sum_j L_{k,ij}}$ is the effective radius at truncation threshold $\tau$, $\mu_{k,i}$ is the center, and $S_i$ is the volume extent. Add $\lambda_b L_{\text{boundary}}$ to the total loss.
6.  **Sum:** Combine all terms to form $L$.

**Pseudocode**
```python
def regularised_gaussian_fitting_loss(target_volume, predicted_volume, splats, lambda_a, lambda_d, lambda_b=0, sigma_min=1e-6, tau=3.0):
    """
    Computes the Regularised Gaussian Fitting Loss.
    
    Args:
        target_volume: Tensor of target volume values.
        predicted_volume: Tensor of rendered volume values.
        splats: List/Structure of K splats. Each splat has:
            - amplitude: Tensor of shape (K,)
            - cov_diag: Tensor of shape (K, D) representing L_k,ii (post-softplus)
            - center: Tensor of shape (K, D) representing mu_k
        lambda_a: Weight for amplitude regularization.
        lambda_d: Weight for extent regularization.
        lambda_b: Weight for boundary containment (default 0).
        sigma_min: Minimum floor for covariance diagonal.
        tau: Truncation threshold for effective radius.
        
    Returns:
        Scalar loss value.
    """
    # 1. Reconstruction Loss (L1)
    l_recon = torch.sum(torch.abs(target_volume - predicted_volume))
    
    # Extract splat parameters
    amplitudes = splats.amplitude  # Shape (K,)
    cov_diags = splats.cov_diag    # Shape (K, D)
    centers = splats.center        # Shape (K, D)
    K = amplitudes.shape[0]
    D = cov_diags.shape[1]
    
    # 2. Amplitude Regularization
    # Evaluated before amplitude clamp
    l_amp = torch.sum(torch.abs(amplitudes))
    
    # 3. Extent Regularization
    # Penalize deviation from sigma_min
    l_ext = torch.sum(torch.abs(cov_diags - sigma_min))
    
    # 4. Boundary Term (Optional)
    l_bound = 0.0
    if lambda_b > 0:
        # Effective radius r_k,i = tau * sqrt(sum_j L_k,ij)
        # Note: The source formula uses sum_j L_k,ij inside sqrt. 
        # Assuming L_k,ij refers to the diagonal entries for isotropic or specific dimension calculation.
        # The source says: r_k,i = tau * sqrt(sum_j L_k,ij). 
        # If L_k,ij is the full covariance, this might be trace. 
        # However, the penalty is per dimension i. 
        # Let's follow the source formula strictly: r_k,i depends on sum over j.
        # If L is diagonal, sum_j L_k,ij = L_k,ii.
        
        # Calculate effective radius for each splat and dimension
        # Source: r_k,i = tau * sqrt(sum_j L_k,ij)
        # If L is diagonal, sum_j L_k,ij is just L_k,ii.
        # Let's assume L_k,ij is the diagonal element L_k,ii for dimension i.
        # The source formula: r_k,i = tau * sqrt(sum_j L_k,ij). 
        # If L is diagonal, sum_j L_k,ij = L_k,ii.
        
        # Calculate sum of diagonal entries for each splat (Trace)
        # Actually, the source says "sum_j L_k,ij". If L is diagonal, L_k,ij is 0 for i!=j.
        # So sum_j L_k,ij = L_k,ii.
        
        # Effective radius for each splat k and dimension i
        # r_k,i = tau * sqrt(L_k,ii)
        r_ki = tau * torch.sqrt(cov_diags) # Shape (K, D)
        
        # Volume extent S_i (assuming unit cube or known size)
        # S_i is the volume extent. Assuming S_i = 1 for normalized coordinates [0,1]
        # Or S_i is a parameter. Let's assume S_i is provided or 1.
        S = 1.0 
        
        # Boundary penalty
        # max(0, r_k,i - mu_k,i)^2 + max(0, r_k,i - (S_i - 1 - mu_k,i))^2
        # mu_k,i is center coordinate.
        
        term1 = torch.clamp(r_ki - centers, min=0.0)
        term2 = torch.clamp(r_ki - (S - 1.0 - centers), min=0.0)
        
        l_bound = torch.sum(term1**2 + term2**2)
        
    # Total Loss
    loss = l_recon + lambda_a * l_amp + lambda_d * l_ext + lambda_b * l_bound
    
    return loss
```

**Edge Cases and Pitfalls**
*   **Amplitude Clamp:** The regularization terms are evaluated *before* any amplitude clamp $a_{\max}$ is applied. This ensures the weight does not grow with $K$ as the splat count is swept [S1, unofficial].
*   **Softplus Activation:** The covariance diagonal entries are softplus-activated parameters. The regularization is applied to the post-softplus values $L_{k,ii}$, not the raw parameters [S1, unofficial].
*   **L1 vs MSE:** L1 is chosen over MSE because MSE is not the best training-PSNR loss for these regularised, early-stopped fits [S1, unofficial].

### [Progressive Multi-Pass Fitting](3185-progressive-multi-pass-fitting.md)
A strategy where a nominal splat budget is distributed across sequential passes, fitting residuals left by frozen earlier passes. Evaluated as an alternative to single-pass fitting within this framework.

## Operating characteristics
*   **Time Complexity:** The loss computation is $O(K \cdot D)$ for the regularization terms and $O(N)$ for the reconstruction loss, where $N$ is the number of volume samples. The optimization uses Adam, which has constant memory overhead per parameter [S1, unofficial].
*   **Memory Complexity:** The implementation uses a fixed-pool relocation mechanism, keeping optimizer tensor shapes constant and preserving the benefits of standard vectorized Adam, avoiding $O(kn)$ intermediate state storage associated with reverse-mode AD [S1, unofficial][S5, unofficial].
*   **Performance:** L1 reconstruction loss beats MSE on held-out PSNR for 11 of 17 tested volumes (by +0.20 to +7.78 dB) and never trails by more than 0.28 dB [S1, unofficial].
*   **Strengths:** Stable optimization of splat geometry; better generalization (PSNR) than MSE; efficient memory usage via fixed-pool optimization.
*   **Limitations:** Single-pass fitting generally achieves higher training PSNR than progressive fitting, though progressive fitting may improve SSIM [S1, unofficial].

## Background
The method originates from the Luxar framework for Gaussian splatting in microscopy and scientific data visualization [S1, unofficial]. It was developed to address the need for scalable, interactive web visualization of multidimensional scientific data, requiring robust optimization of Gaussian representations [S1, unofficial].
