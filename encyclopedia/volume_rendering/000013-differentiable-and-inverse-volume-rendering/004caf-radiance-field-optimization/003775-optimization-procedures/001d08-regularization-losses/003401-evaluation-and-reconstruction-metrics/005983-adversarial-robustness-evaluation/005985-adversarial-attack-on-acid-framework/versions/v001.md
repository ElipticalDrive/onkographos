# Adversarial Attack on ACID Framework

Also called: Adversarial attacks to ACID as whole

## Overview
This method computes adversarial perturbations for the entire Adaptive Compressive Iterative Deepening (ACID) reconstruction framework, rather than targeting a single neural network component. It solves the problem of evaluating the robustness of the full iterative reconstruction pipeline by finding input perturbations that maximize the reconstruction error while adhering to a noise budget. It differs from single-network attacks by propagating gradients through the complex, multi-module ACID architecture, which combines deep learning, compressed sensing, and analytic mapping.

## How it works

### Inputs and Outputs
*   **Input:** Original tomographic data $p^{(0)}$, ground truth image $f$, perturbation direction matrix $A$, regularization parameter $\gamma$, maximum outer iterations $K_{AA}$, and maximum inner ACID iterations $K_{ACID}$.
*   **Output:** Optimal adversarial perturbation $e$.

### Data Structures
The ACID system is decomposed into three modules keyed to variables $p$, $u$, and $f$, where $u = \Phi(p)$.
*   **Module $p$:** Input $p_i$, Output $p_o$. Gradient $\frac{dp_o}{dp_i}$.
*   **Module $u$:** Input $u_i$, Output $u_o$. Gradient $\frac{du_o}{du_i}$.
*   **Module $f$:** Input $f_i$, Output $f_o$. Gradient $\frac{df_o}{df_i}$.

### Algorithm Steps
1.  **Initialize:** Set perturbation $e = 0$ (or small random noise). Set iteration counter $k_{AA} = 0$.
2.  **Outer Loop (Gradient Ascent):** While $k_{AA} < K_{AA}$ and noise strength $\|e\|_2$ is within acceptable bounds relative to single-network baselines:
    a.  **Inner Loop (ACID Forward/Backward):**
        i.  Construct perturbed input: $p^{(0)+Ae} = p^{(0)} + Ae$.
        ii. Run ACID feedforward propagation for up to $K_{ACID}$ iterations to compute the reconstructed output $f_e = \hat{f}(p, p^{(0)+Ae})$. Note that $\hat{f}$ is the solution minimizing the ACID objective function.
        iii. Compute the cost function $L_c$ (see Formulas).
        iv. Perform backpropagation through the ACID modules to compute $\frac{dL_{ACID}}{de}$. This involves aggregating gradients from both branches contributing to $f^{(k_{ACID})}$ for $k_{ACID}=1, \dots, K_{ACID}-1$ as depicted in the original backpropagation diagram [S1].
    b.  **Update Perturbation:**
        i.  Compute total gradient: $\frac{dL_c}{de} = \frac{dL_{ACID}}{de} - \gamma e$.
        ii. Update $e$ using gradient ascent: $e \leftarrow e + \alpha \frac{dL_c}{de}$, where $\alpha$ is the step size.
    c.  Increment $k_{AA}$.
3.  **Stop:** Return $e$ when stopping criteria are met.

### Formulas
The objective function for the whole ACID workflow without perturbation is:
$$ D^{(0)}_l(e) = \frac{1}{2}\|\hat{f}(p, p^{(0)}) - l(f)\|_2^2 - \frac{\gamma}{2}\|e\|_2^2 $$
With perturbation $Ae$, the objective becomes:
$$ D^{(0)+Ae}_l(e) = \frac{1}{2}\|\hat{f}(p, p^{(0)}+Ae) - f\|_2^2 - \frac{\gamma}{2}\|e\|_2^2 $$
The cost function $L_c$ used for optimization is defined as:
$$ L_c = \frac{1}{2}\|f_e - f\|_2^2 - \frac{\gamma}{2}\|e\|_2^2 $$
where $f_e = \hat{f}(p, p^{(0)}+Ae)$ is the output with perturbation and $f$ is the output without. The gradient is split as:
$$ \frac{dL_c}{de} = \frac{d(\frac{1}{2}\|f_e - f\|_2^2)}{de} - \gamma e = \frac{dL_{ACID}}{de} - \gamma e $$
Here, $L_{ACID} = \frac{1}{2}\|f_e - f\|_2^2$ [S1].

### Parameters
*   $K_{AA}$: Maximum number of iterations for computing the adversarial attack.
*   $K_{ACID}$: Maximum number of iterations for the ACID feedforward process.
*   $\gamma$: Regularization parameter for the perturbation norm.
*   $\alpha$: Learning rate for gradient ascent (Not given in the sources, standard implementation detail).

### Edge Cases and Pitfalls
*   **Gradient Complexity:** The gradient $\frac{dL_{ACID}}{de}$ is complicated due to the iterative nature of ACID. Direct computation is infeasible; backpropagation through the unrolled iterations is required [S1].
*   **Branching:** The backpropagation must account for two branches contributing to $f^{(k_{ACID})}$ for intermediate iterations [S1].
*   **Stopping Criteria:** The attack stops if the noise strength exceeds that used in attacking the single neural network in terms of L2-norm, or if $K_{AA}$ is reached [S1].

## Subtopics

### Adversarial Robustness Evaluation
*   **What it is:** The broader category of methods used to assess the stability of reconstruction networks against adversarial attacks.
*   **Differentiation:** It focuses on computing BREN (Bias-Relative Error Norm) ratios for different perturbation strengths, providing a metric for robustness rather than just generating the attack.
*   **When to choose:** When the goal is to quantify the robustness of a reconstruction method rather than to find the worst-case perturbation.
*   **Link:** [Adversarial Robustness Evaluation](16421-adversarial-robustness-evaluation.md)

## Operating characteristics

*   **Time Complexity:** The method involves an outer loop of $K_{AA}$ iterations and an inner loop of $K_{ACID}$ iterations. Each inner iteration requires a full forward and backward pass through the ACID framework, which itself is iterative. Thus, the complexity is roughly $O(K_{AA} \cdot K_{ACID} \cdot C_{ACID})$, where $C_{ACID}$ is the cost of one ACID iteration.
*   **Memory Complexity:** Requires storing the state of the ACID iterations for backpropagation, leading to memory usage proportional to $K_{ACID}$ times the size of the intermediate variables.
*   **Strengths:** Evaluates the robustness of the entire ACID pipeline, including the stabilizing effects of compressed sensing and iterative refinement, which single-network attacks miss.
*   **Limitations:** Computationally expensive due to the nested iterative loops. The gradient computation is complex due to the branching structure of ACID.
*   **When to use:** When assessing the security and stability of the ACID framework for tomographic reconstruction.
*   **When not to use:** When computational resources are limited or when only the robustness of the deep learning component is of interest.

## Background

The ACID (Adaptive Compressive Iterative Deepening) framework was proposed to stabilize deep tomographic image reconstruction by combining deep learning with compressed sensing and analytic mapping [S1]. The adversarial attack method described here was introduced in the paper "Stabilizing deep tomographic reconstruction: Part B. Convergence analysis and adversarial attacks" to evaluate the robustness of this framework against adversarial perturbations [S1]. The work highlights that while ACID stabilizes the reconstruction, it is still susceptible to adversarial attacks, albeit potentially requiring different perturbation strategies than single neural networks.
