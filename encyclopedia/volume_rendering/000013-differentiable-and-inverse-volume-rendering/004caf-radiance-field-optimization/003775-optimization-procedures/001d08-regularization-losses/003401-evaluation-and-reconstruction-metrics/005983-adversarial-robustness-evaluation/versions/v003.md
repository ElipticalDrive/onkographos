# Adversarial Robustness Evaluation

Also called: Adversarial Attack Evaluation, BREN Ratio Analysis

## Overview
Adversarial Robustness Evaluation assesses the stability of reconstruction networks when subjected to small, targeted perturbations in the input data [S1]. It quantifies sensitivity by computing the BREN ratio, which measures the relative change in the reconstructed output versus the magnitude of the input perturbation [S1]. Unlike standard accuracy metrics, this method evaluates whether small input errors lead to disproportionately large, artifact-ridden outputs, indicating a lack of robustness [S1].

## How it works
The method evaluates a reconstruction network $\mathcal{R}$ by comparing its output on clean data against its output on perturbed data [S1].

**Inputs and Outputs:**
- Input: Clean measurement data $\mathbf{y}$, perturbation strength $\epsilon$.
- Output: The BREN ratio value.

**Data Structures:**
- $\mathbf{y}$: Vector of raw measurements (e.g., sinogram entries or Fourier samples) [G].
- $\mathbf{e}$: Perturbation vector with bounded norm $\|\mathbf{e}\|_2 \leq \epsilon$ [G].
- $\hat{\mathbf{x}} = \mathcal{R}(\mathbf{y})$: Clean reconstruction [G].
- $\hat{\mathbf{x}}' = \mathcal{R}(\mathbf{y} + \mathbf{e})$: Perturbed reconstruction [G].

**Steps:**
1. **Generate Perturbation:** Compute a perturbation $\mathbf{e}$ with bounded norm $\|\mathbf{e}\|_2 \leq \epsilon$ that maximizes the output difference [G].
2. **Reconstruct:** Compute the clean reconstruction $\hat{\mathbf{x}}$ and the perturbed reconstruction $\hat{\mathbf{x}}'$ [G].
3. **Compute BREN Ratio:** Calculate the ratio of the output change to the input change:
   $$
   \text{BREN} = \frac{\|\hat{\mathbf{x}}' - \hat{\mathbf{x}}\|_2}{\|\mathbf{e}\|_2} = \frac{\|\mathcal{R}(\mathbf{y} + \mathbf{e}) - \mathcal{R}(\mathbf{y})\|_2}{\|\mathbf{e}\|_2}
   $$
   [S1]

**Parameters:**
- $\epsilon$: Maximum perturbation strength. Not given in the sources.

**Edge Cases and Pitfalls:**
- **Artifact Generation:** Small perturbations may corrupt the sparsity of the reconstructed image, leading to artifacts that are not present in the clean reconstruction [S1].
- **Inconsistency:** Perturbed results may become inconsistent with original measurements, violating the constraints used in traditional iterative reconstruction [S1].

**Pseudocode:**
```python
def compute_bren_ratio(reconstruction_network, clean_data, perturbation_strength):
    """
    Computes the BREN ratio for a given reconstruction network and perturbation.
    """
    # Step 1: Generate perturbation
    # The sources do not specify the exact generation method; we use a standard bounded random perturbation [G].
    perturbation = generate_perturbation(clean_data, perturbation_strength)
    
    # Step 2: Create perturbed data
    perturbed_data = [c + p for c, p in zip(clean_data, perturbation)]
    
    # Step 3: Reconstruct both
    clean_reconstruction = reconstruction_network(clean_data)
    perturbed_reconstruction = reconstruction_network(perturbed_data)
    
    # Step 4: Compute L2 norms
    output_diff_norm = l2_norm([p - c for p, c in zip(perturbed_reconstruction, clean_reconstruction)])
    input_diff_norm = l2_norm(perturbation)
    
    # Step 5: Compute ratio
    if input_diff_norm == 0:
        return 0.0 # No perturbation applied
    
    bren_ratio = output_diff_norm / input_diff_norm
    return bren_ratio

def generate_perturbation(data, strength):
    """Generates a perturbation vector with bounded L2 norm."""
    import random
    import math
    # Initialize with random values
    perturbation = [random.gauss(0, 1) for _ in data]
    # Normalize to unit vector
    norm = math.sqrt(sum(x**2 for x in perturbation))
    if norm == 0:
        return [0.0] * len(data)
    perturbation = [x / norm * strength for x in perturbation]
    return perturbation

def l2_norm(vector):
    """Computes the L2 norm of a vector."""
    import math
    return math.sqrt(sum(x**2 for x in vector))
```

## Subtopics

### [Adversarial Attack on ACID Framework](16431-adversarial-attack-on-acid-framework.md)
This method computes a tiny perturbation to the input data of the ACID (Adversarial Compressed Sensing Iterative Deepening) framework that maximizes the difference in the reconstructed image while keeping the perturbation small, thereby assessing the stability of the reconstruction system. It extends the adversarial attack formulation from single neural networks to the entire iterative ACID workflow, which combines deep reconstruction, compressed sensing, and analytic mapping. Unlike attacks on isolated networks, this method accounts for the feedback loops and multi-module structure of ACID by decomposing the system into modules keyed to projection data, neural network output, and image domain. Choose when evaluating iterative frameworks that combine deep reconstruction, compressed sensing, and analytic mapping, as it accounts for feedback loops and multi-module structures.

### [Patch-based Adversarial Attack](21932-patch-based-adversarial-attack.md)
This method evaluates the robustness of neural radiance field reconstruction networks by introducing distortions confined to a region of limited area (a patch) with unbounded intensity values, rather than applying global low-intensity noise. It solves the problem of assessing vulnerability to localized, high-magnitude perturbations that may correspond to physical objects (e.g., stickers) in real-world scenarios. Unlike global perturbation methods, this approach exploits the fact that patches can manipulate distant regions of the rendered output while keeping original output values elsewhere, with position and view angle having little impact on efficacy. Choose when assessing vulnerability to localized, high-magnitude perturbations corresponding to physical objects, as it exploits the ability of patches to manipulate distant rendered regions while preserving local output values.

## Operating characteristics
- **Sensitivity Indicator:** BREN ratios are substantially less than 1 across CT and MRI experiments, indicating the BREN property is satisfied [S1]. The sources do not specify a fixed threshold where a ratio less than 1 guarantees robustness [S1].
- **Comparative Sensitivity:** Networks like AUTOMAP exhibit higher sensitivity (higher BREN ratios) compared to Med-50, Deep MRI, and MRI-VN, meaning small perturbations cause larger changes in the L2-norm of the output [S1].
- **Limitations:** Not given in the sources.

## Background
The BREN ratio was introduced in the context of stabilizing deep tomographic reconstruction [S1]. It was used to analyze the convergence and adversarial robustness of various deep learning-based reconstruction networks (such as AUTOMAP, Med-50, and MRI-VN) in CT and MRI experiments [S1]. The analysis highlighted that while these networks satisfy the BREN property, they remain sensitive to perturbations that corrupt image sparsity [S1].
