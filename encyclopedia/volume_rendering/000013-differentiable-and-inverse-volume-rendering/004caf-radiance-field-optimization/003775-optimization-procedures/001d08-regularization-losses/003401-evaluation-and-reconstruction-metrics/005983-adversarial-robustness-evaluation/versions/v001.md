# Adversarial Robustness Evaluation

Also called: Adversarial Attack Evaluation, BREN Ratio Analysis

## Overview
Adversarial Robustness Evaluation assesses the stability of reconstruction networks (such as those used in tomographic or radiance-field reconstruction) against small, targeted perturbations in input data. It quantifies how sensitive a model is to adversarial attacks by computing the BREN ratio, which measures the consistency between perturbed and unperturbed outputs relative to the perturbation magnitude. It distinguishes itself from standard accuracy metrics by focusing on the structural integrity and sparsity preservation of the reconstruction under malicious noise, rather than just mean error on clean data.

## How it works
The method evaluates robustness by introducing controlled perturbations to input measurements and analyzing the resulting reconstruction artifacts.

**Inputs:**
- Original input measurements $\mathbf{y}$.
- Perturbation magnitude $\epsilon$ (or a set of magnitudes).
- Reconstruction network $f(\cdot)$.
- Ground truth or reference solution $\mathbf{x}^*$ (optional, for L2-norm calculation).

**Outputs:**
- BREN ratio value(s).
- Visual or quantitative assessment of artifacts (e.g., sparsity corruption).

**Data Structures:**
- Perturbed input $\mathbf{y}_{adv} = \mathbf{y} + \delta$, where $\|\delta\| \le \epsilon$.
- Reconstructed image $\hat{\mathbf{x}} = f(\mathbf{y})$.
- Perturbed reconstruction $\hat{\mathbf{x}}_{adv} = f(\mathbf{y}_{adv})$.

**Steps:**
1. **Generate Perturbations:** Create adversarial perturbations $\delta$ for the input measurements. In iterative frameworks like ACID, this involves computing tiny perturbations via gradient ascent to maximize reconstruction error or inconsistency [S1].
2. **Reconstruct:** Pass the perturbed inputs through the reconstruction network to obtain $\hat{\mathbf{x}}_{adv}$.
3. **Compute BREN Ratio:** Calculate the BREN ratio to quantify sensitivity. The ratio is defined such that a value substantially less than 1 indicates robustness (small input changes cause small output changes), while higher values indicate sensitivity [S1].
   $$
   \text{BREN Ratio} = \frac{\|\hat{\mathbf{x}}_{adv} - \hat{\mathbf{x}}\|}{\|\delta\|} \quad \text{(Conceptual scaling, exact formula not fully specified in sources)}
   $$
   *Note: The sources state that BREN ratios are computed and found to be "substantially less than 1" for robust models, implying a normalization against the perturbation strength.*
4. **Analyze Sparsity:** Check if the sparsity of the reconstructed image is corrupted. If the perturbed images contain significant artifacts and the sparsity is lost, the model is considered sensitive [S1].
5. **Compare Models:** Compare BREN ratios across different networks (e.g., AUTOMAP vs. Med-50). Higher BREN ratios indicate greater sensitivity to perturbations [S1].

**Parameters:**
- Perturbation strength $\epsilon$: Varies across experiments.
- Norm used: L2-norm is explicitly mentioned for measuring changes [S1].

**Edge Cases:**
- **Degenerate Perturbations:** If $\delta$ is too large, the reconstruction may fail entirely, making the ratio undefined or meaningless.
- **Sparsity Loss:** If the reconstruction network inherently produces non-sparse outputs, the BREN metric's utility in detecting "corrupted sparsity" is diminished [S1].

## Operating characteristics
- **Time Complexity:** Depends on the reconstruction network's inference time and the number of perturbation iterations. Iterative attacks (like in ACID) require multiple forward passes.
- **Memory Complexity:** Standard for the reconstruction network; no additional large buffers required beyond storing perturbed inputs and outputs.
- **Strengths:** Directly measures vulnerability to adversarial noise; highlights structural failures (sparsity corruption) that standard metrics might miss.
- **Limitations:** Requires access to gradients for iterative attacks; BREN ratio definition is not fully explicit in the provided sources, making exact implementation difficult without inference.
- **When to use:** When evaluating deep learning-based reconstruction models for safety-critical applications (e.g., medical imaging) where adversarial robustness is crucial.
- **When not to use:** For models that are not differentiable or where adversarial threats are not a concern.

## Background
The concept originates from the analysis of deep tomographic reconstruction networks, specifically in the context of stabilizing these networks against adversarial attacks. The BREN ratio was introduced to evaluate the convergence and robustness of reconstruction algorithms like AUTOMAP, Med-50, and MRI-VN [S1]. The work highlights that traditional iterative reconstruction relies on finding feasible solutions within sparse solution spaces, and deep learning models must preserve this property to be robust [S1].
