# Adversarial Attack on ACID Framework

Also called: Adversarial attacks to ACID as whole

## Overview
This method computes adversarial perturbations for the entire Adaptive Compressive Iterative Deep (ACID) reconstruction framework, rather than targeting a single neural network component. It solves the problem of evaluating the robustness of the full iterative reconstruction pipeline by finding input perturbations that maximize the reconstruction error while adhering to a noise budget. It differs from single-network attacks by propagating gradients through the entire ACID loop, including the analytic mapping and compressed sensing modules, thereby assessing the stability of the combined data-driven and physics-based prior.

## How it works
The attack formulates an optimization problem where the goal is to find a perturbation $e$ that increases the loss of the ACID system. The ACID system is decomposed into three modules keyed to variables $p$, $u$, and $f$, where $u = \Phi(p)$ [S1].

### Inputs and Outputs
*   **Inputs**:
    *   $p^{(0)}$: Original tomographic data (initial estimate).
    *   $f$: Ground truth or target output image.
    *   $A$: Measurement matrix/operator (implicit in the data consistency term).
    *   $\gamma$: Regularization weight for the perturbation norm.
    *   $K_{AA}$: Maximum number of iterations for the outer adversarial loop.
    *   $K_{ACID}$: Maximum number of iterations for the inner ACID feedforward/backpropagation loop.
*   **Outputs**:
    *   $e$: The computed adversarial perturbation.
    *   $p^{(0)} + Ae$: The perturbed input data.

### Data Structures
The ACID system is treated as a computational graph with three main branches/modules:
1.  **Module $p$**: Handles the tomographic data domain. Inputs/outputs denoted as $p_i, p_o$. Gradient denoted as $\frac{dp_o}{dp_i}$.
2.  **Module $u$**: Handles the sparse image domain (compressed sensing). Inputs/outputs denoted as $u_i, u_o$. Gradient denoted as $\frac{du_o}{du_i}$.
3.  **Module $f$**: Handles the final image domain. Inputs/outputs denoted as $f_i, f_o$. Gradient denoted as $\frac{df_o}{df_i}$.

The relationship is defined as $u = \Phi(p)$, linking the $p$ and $u$ modules [S1].

### Formulas
The objective function for the unperturbed ACID workflow is:
$$ D^{(0)}_l(e) = \frac{1}{2}\|\hat{f}(p, p^{(0)}) - l(f)\|_2^2 - \frac{\gamma}{2}\|e\|_2^2 $$
where $\hat{f}$ is the solution minimizing the ACID objective function (Equation 1 in [S1]), and $l(f)$ is a label or target function [S1].

With perturbation $e$, the objective becomes:
$$ D^{(0)+Ae}_l(e) = \frac{1}{2}\|\hat{f}(p, p^{(0)}+Ae) - f\|_2^2 - \frac{\gamma}{2}\|e\|_2^2 $$
where $f_e = \hat{f}(p, p^{(0)}+Ae)$ is the output of the ACID system with the perturbation [S1].

The cost function $L_c$ to be maximized via gradient ascent is:
$$ L_c = \frac{1}{2}\|f_e - f\|_2^2 - \frac{\gamma}{2}\|e\|_2^2 $$

The gradient of the cost function with respect to the perturbation $e$ is split into two terms:
$$ \frac{dL_c}{de} = \frac{d(\frac{1}{2}\|f_e - f\|_2^2)}{de} - \gamma e = \frac{dL_{ACID}}{de} - \gamma e $$
where $L_{ACID} = \frac{1}{2}\|f_e - f\|_2^2$ [S1].

### Parameters
*   $\gamma$: Weight for the $L_2$ norm of the perturbation. Value not explicitly given in sources, but standard for adversarial attacks.
*   $K_{AA}$: Maximum iterations for the outer loop. Value not given in sources.
*   $K_{ACID}$: Maximum iterations for the inner ACID loop. Value not given in sources.

### Algorithm Steps
1.  **Initialize**: Set perturbation $e = 0$ (or small random noise). Initialize iteration counter $k_{AA} = 0$.
2.  **Outer Loop**: While $k_{AA} < K_{AA}$ and noise strength $\|e\|_2$ is within acceptable bounds (specifically, not exceeding the strength used for single-network attacks if comparing robustness):
    a. **Inner Loop (ACID Forward/Backward)**:
        i.   Compute $f_e = \text{ACID}(p^{(0)} + Ae)$ by running the ACID feedforward process for up to $K_{ACID}$ iterations. This involves the interaction of modules $p$, $u$, and $f$.
        ii.  Compute the loss $L_{ACID} = \frac{1}{2}\|f_e - f\|_2^2$.
        iii. Perform backpropagation through the ACID modules to compute $\frac{dL_{ACID}}{de}$. This requires computing gradients through all three branches ($p, u, f$) and their interconnections ($u=\Phi(p)$) [S1].
    b. **Gradient Update**:
        i.   Compute total gradient: $\frac{dL_c}{de} = \frac{dL_{ACID}}{de} - \gamma e$.
        ii.  Update perturbation using gradient ascent: $e \leftarrow e + \alpha \frac{dL_c}{de}$, where $\alpha$ is the step size (learning rate) [S1].
    c. Increment $k_{AA}$.
3.  **Output**: Return the final perturbation $e$.

### Edge Cases and Pitfalls
*   **Precision**: The backpropagation through the iterative ACID loop (up to $K_{ACID}$ iterations) can be computationally expensive and may suffer from vanishing or exploding gradients if not carefully implemented.
*   **Boundaries**: The perturbation $e$ is constrained by the $L_2$ norm term in the cost function. The stopping criteria also include a comparison to the noise strength of single-network attacks, which serves as a practical bound for robustness evaluation [S1].
*   **Degenerate Input**: If the ACID framework fails to converge within $K_{ACID}$ iterations, the gradient computation may be invalid.

## Operating characteristics
*   **Time Complexity**: The method involves an outer loop of $K_{AA}$ iterations, each containing an inner loop of up to $K_{ACID}$ ACID iterations. The complexity is $O(K_{AA} \times K_{ACID})$ times the cost of a single ACID forward/backward pass.
*   **Memory Complexity**: Requires storing the state of the ACID framework for backpropagation, which may be significant if $K_{ACID}$ is large.
*   **Strengths**: Provides a comprehensive assessment of the ACID framework's robustness by considering the entire reconstruction pipeline, including the interaction between data-driven priors and physical constraints.
*   **Limitations**: Computationally expensive due to the nested iterative loops. The stopping criteria rely on a comparison to single-network attack strengths, which may not be directly comparable in all scenarios.
*   **When to use**: When evaluating the robustness of the ACID framework against adversarial attacks in tomographic reconstruction.
*   **When not to use**: When computational resources are limited or when only the robustness of a single component (e.g., the deep reconstruction network) is of interest.

## Background
The ACID framework was proposed to stabilize deep tomographic image reconstruction by combining deep learning with compressed sensing and analytic mapping [S1]. The adversarial attack method described here was introduced to evaluate the robustness of this framework. The work is part of a series on stabilizing deep tomographic reconstruction, with this specific method detailed in "Stabilizing deep tomographic reconstruction: Part B. Convergence analysis and adversarial attacks" [S1]. The method uses gradient ascent to find perturbations that maximize the reconstruction error, leveraging the backpropagation algorithm through the ACID modules.
