# Fast Gradient Sign Method (FGSM)
Also called: Goodfellow et al. adversarial attack

## Overview
The Fast Gradient Sign Method (FGSM) is a single-step adversarial attack that generates perturbations by moving the input in the direction of the sign of the gradient of the loss function with respect to the input [S1]. It solves the problem of efficiently creating adversarial examples by approximating the steepest ascent direction using only the sign of the gradient, allowing for rapid attack generation [S1]. Unlike iterative methods, FGSM computes the perturbation in a single pass, prioritizing speed over the precision of the perturbation magnitude [S1].

## How it works
**Inputs and Outputs:**
- Input: Original input tensor $x$, target label $y$ (or true label for untargeted attacks), loss function $J(x, y)$, and perturbation magnitude $\epsilon$.
- Output: Adversarial input $x_{adv}$.

**Data Structures:**
- The input $x$ is treated as a dense tensor of floating-point values.
- The gradient $\nabla_x J(x, y)$ is a tensor of the same shape and precision as $x$.

**Steps:**
1. Compute the loss $J(x, y)$ for the original input $x$ and label $y$.
2. Compute the gradient of the loss with respect to the input: $\nabla_x J(x, y)$.
3. Compute the sign of the gradient: $\text{sign}(\nabla_x J(x, y))$. The sign function returns $1$ if the value is positive, $-1$ if negative, and $0$ if zero.
4. Scale the sign of the gradient by the constant $\epsilon$: $\epsilon \cdot \text{sign}(\nabla_x J(x, y))$.
5. Add the scaled perturbation to the original input: $x_{adv} = x + \epsilon \cdot \text{sign}(\nabla_x J(x, y))$.
6. Clip $x_{adv}$ to the valid input range (e.g., $[0, 1]$ for normalized images) to ensure the result remains a valid input sample [G].

**Formula:**
$$x_{adv} = x + \epsilon \cdot \text{sign}(\nabla_x J(x, y))$$

**Parameters:**
- $\epsilon$ (epsilon): A constant controlling the intensity of the noise. Typical values depend on the input scale; for normalized inputs in $[0, 1]$, values like $0.01$ to $0.03$ are common [S1].

**Edge Cases and Pitfalls:**
- If the gradient is zero, the perturbation is zero, and $x_{adv} = x$.
- Precision issues may arise if $\epsilon$ is very small relative to the input range, potentially resulting in no visible change after clipping.
- The method assumes the loss function is differentiable with respect to the input.

**Pseudocode:**
```python
def fgsm_attack(x, y, loss_fn, epsilon):
    """
    x: Input tensor (requires gradient)
    y: Target label
    loss_fn: Function that computes loss given x and y
    epsilon: Perturbation magnitude
    """
    # Compute loss
    loss = loss_fn(x, y)
    
    # Compute gradient of loss w.r.t input
    loss.backward()
    
    # Get gradient
    grad = x.grad
    
    # Compute sign of gradient
    sign_grad = torch.sign(grad)
    
    # Scale by epsilon
    perturbation = epsilon * sign_grad
    
    # Add perturbation to input
    x_adv = x + perturbation
    
    # Clip to valid range (assuming input was in [0, 1])
    x_adv = torch.clamp(x_adv, 0.0, 1.0)
    
    return x_adv
```

## Subtopics

### Fast Gradient Value Method
An extension of FGSM that uses a scaled version of the gradient's magnitude (value) rather than just the sign [S1]. Proposed by Rozsa et al. [S1]. It retains the single-step nature of FGSM but allows for more nuanced perturbation magnitudes based on gradient strength.

### Iterative FGSM with Momentum
An iterative version of FGSM that incorporates momentum into the gradient update equation to avoid poor local minima and non-convex patterns in the objective function's landscape [S1]. Proposed by Dong et al. [S1]. It improves attack success rates by accumulating gradient information over multiple steps.

## Operating characteristics
Time complexity is $O(1)$ with respect to the number of iterations, as it requires only a single forward and backward pass [S1]. Memory complexity is $O(N)$ where $N$ is the size of the input, for storing the gradient. It is extremely fast compared to iterative methods like PGD [S1]. However, it may produce less effective adversarial examples for robust models because the single-step approximation may not find the optimal perturbation direction [S1]. Strengths include speed and simplicity. Limitations include lower attack success rates against defended models compared to iterative methods [S1]. Use when computational resources are limited or for quick robustness checks. Avoid when high attack success rates are required against robust models.

## Background
Proposed by Goodfellow et al. [S1], FGSM was one of the initial adversarial attacks designed to exploit the high-dimensional nature of neural network inputs [S1]. It demonstrated that small, carefully crafted perturbations could cause drastic deviations in model output [S1]. It has been widely used as a baseline for evaluating adversarial robustness in various domains, including vision and, more recently, neural radiance fields [S1].
