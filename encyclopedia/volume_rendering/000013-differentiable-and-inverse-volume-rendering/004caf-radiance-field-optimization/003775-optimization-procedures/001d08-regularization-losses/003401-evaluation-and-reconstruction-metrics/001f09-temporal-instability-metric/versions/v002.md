# Temporal Instability Metric

Also called: Flicker Metric, TI Metric, Temporal Flicker, Temporal Variation in Reconstruction Error

## Overview
The Temporal Instability (TI) metric quantifies temporal coherence in volume rendering or novel view synthesis by measuring frame-to-frame variations in reconstruction error [S1, unofficial]. It serves as a diagnostic for visual flickering artifacts that static per-frame metrics like RMSE may miss [S1, unofficial]. Lower values indicate smoother temporal consistency [S2].

## How it works
The TI metric evaluates the stability of the reconstruction error across a sequence of frames [S1, unofficial].

### Inputs and Outputs
- **Inputs**:
    - $I(t)$: Reconstructed volume or rendered frames at time $t$.
    - $I^*(t)$: Ground truth volume or frames at time $t$.
    - $\Omega$: Region of interest (ROI) within the volume or image space.
    - $T$: Total number of frames in the sequence.
- **Outputs**:
    - $TI$: A scalar value representing the root mean square of the temporal error changes. Lower values indicate higher temporal stability [S2].

### Data Structures
- **Error Field $E(t)$**: A 3D array (for volumes) or 2D array (for images) of the same spatial dimensions as the input, where each element $E_i(t)$ stores the reconstruction error for froxel/pixel $i$ at frame $t$ [S1, unofficial].
    - Layout: $E \in \mathbb{R}^{H \times W \times D}$ (or $\mathbb{R}^{H \times W}$).
    - Values: Component-wise error (e.g., absolute difference per color channel) [G].

### Steps
1. **Compute Per-Frame Error**: For each frame $t$ in the sequence $[1, T]$, calculate the error field $E(t)$ between the reconstruction $I(t)$ and ground truth $I^*(t)$ [S1, unofficial].
2. **Compute Temporal Error Differences**: For each froxel $i \in \Omega$ and frame $t$, calculate the squared difference between consecutive error values: $(E_i(t) - E_i(t-1))^2$ [S1, unofficial].
3. **Aggregate Over Time**: For each froxel $i$, average the squared temporal differences over the $T$ frames [S1, unofficial].
4. **Aggregate Over Space**: Average the temporal results over all froxels $i$ in the region of interest $\Omega$ [S1, unofficial].
5. **Finalize**: Take the square root of the spatial average to obtain the TI metric. Color channels are averaged at the very end to produce the final scalar value [S1, unofficial].

### Formula
The Temporal Instability metric is defined as [S1, unofficial]:

$$
TI = \sqrt{\frac{1}{|\Omega|} \sum_{i \in \Omega} \frac{1}{T} \sum_t (E_i(t) - E_i(t-1))^2}
$$

Where:
- $|\Omega|$ is the number of froxels in the region of interest.
- $i$ indexes the froxels in $\Omega$.
- $T$ is the total number of frames.
- $E_i(t)$ is the error of froxel $i$ at frame $t$.
- All operations are component-wise, and color channels are averaged at the end [S1, unofficial].

### Parameters
- **Region of Interest ($\Omega$)**: The spatial subset of the volume/image to evaluate. Not given in the sources.
- **Percentile Reporting**: The 95th percentile of the TI signal is sometimes presented instead of the mean to omit large one-frame outliers and align better with visually perceived flicker [S1, unofficial].

### Pseudocode
```python
def compute_temporal_instability(recon_frames, gt_frames, region_of_interest_mask):
    """
    Computes the Temporal Instability (TI) metric.
    
    Args:
        recon_frames: List of reconstructed frames [I(1), ..., I(T)].
        gt_frames: List of ground truth frames [I*(1), ..., I*(T)].
        region_of_interest_mask: List of (h, w) coordinate tuples for spatial region Omega.
        
    Returns:
        ti_value: Scalar TI metric.
        ti_95: 95th percentile of the TI signal.
    """
    T = len(recon_frames)
    if T < 2:
        return 0.0, 0.0

    # Initialize accumulator for squared temporal error differences
    # Shape matches spatial dimensions of frames
    error_diff_sq_sum = [[0.0] * len(recon_frames[0][0]) for _ in range(len(recon_frames[0]))]
    
    # Compute component-wise error differences between consecutive frames
    for t in range(1, T):
        # Compute error field E(t) and E(t-1) component-wise
        err_t = [[abs(recon_frames[t][h][w][c] - gt_frames[t][h][w][c]) for c in range(len(recon_frames[t][0][0]))] for w in range(len(recon_frames[t][0])) for h in range(len(recon_frames[t]))]
        err_prev = [[abs(recon_frames[t-1][h][w][c] - gt_frames[t-1][h][w][c]) for c in range(len(recon_frames[t-1][0][0]))] for w in range(len(recon_frames[t-1][0])) for h in range(len(recon_frames[t-1]))]
        
        for h in range(len(recon_frames[t])):
            for w in range(len(recon_frames[t][0])):
                for c in range(len(recon_frames[t][0][0])):
                    diff = err_t[h][w][c] - err_prev[h][w][c]
                    error_diff_sq_sum[h][w][c] += diff ** 2

    # Average over time T
    avg_sq = [[error_diff_sq_sum[h][w][c] / T for c in range(len(error_diff_sq_sum[0][0]))] for w in range(len(error_diff_sq_sum[0])) for h in range(len(error_diff_sq_sum))]

    # Average over spatial region Omega
    if region_of_interest_mask:
        spatial_vals = [avg_sq[h][w][c] for h, w in region_of_interest_mask for c in range(len(avg_sq[0][0]))]
    else:
        spatial_vals = [avg_sq[h][w][c] for h in range(len(avg_sq)) for w in range(len(avg_sq[0])) for c in range(len(avg_sq[0][0]))]

    # Average color channels at the end
    ti_value = sum(spatial_vals) / len(spatial_vals)

    # 95th percentile of the TI signal
    spatial_vals.sort()
    ti_95 = spatial_vals[int(0.95 * len(spatial_vals))]

    return ti_value ** 0.5, ti_95 ** 0.5
```

### Edge Cases and Pitfalls
- **Ground Truth Changes**: The TI metric does not distinguish between rapid changes in the ground truth and slow responses in the reconstructed signal [S1, unofficial]. A slow-reacting algorithm may produce a high TI spike even if the visual output remains stable [S1, unofficial].
- **Visual Correlation**: High visual flicker implies high TI, but high TI does not necessarily manifest as visual flicker artifacts [S1, unofficial].
- **Outliers**: Large one-frame outliers can skew the mean TI. The 95th percentile of the TI signal is sometimes presented to omit these outliers and align better with visually perceived flicker [S1, unofficial].

## Operating characteristics
- **Complexity**: Not given in the sources.
- **Performance**: On Neural3DVideo (2 input views), the full model achieves a flicker score of 2.916, compared to 5.714 for GS-LRM and 2.746 for 4DGS [S2]. On LongVolumetricVideo (4 input views), the full model achieves 7.782, compared to 8.463 for GS-LRM and 6.528 for 4DGS [S2].
- **Strengths**: Directly measures signal variance in reconstruction error, providing a quantitative link to temporal stability [S1, unofficial].
- **Limitations**: Does not account for perceptual quality or structural similarity [S1, unofficial]. May not correlate perfectly with human perception of flicker due to ground truth dynamics [S1, unofficial].

## Background
The Temporal Instability metric was introduced in the context of volumetric temporal anti-aliasing (TAA) for real-time rendering of participating media [S1, unofficial]. It was designed to complement RMSE by capturing temporal artifacts that static metrics miss [S1, unofficial]. A related "Flicker Metric" was later introduced in the context of novel view streaming for dynamic scene reconstruction, using feature-space variations from a pretrained VGG network [S2].
