# Curvature Loss

Also called: Curvature Regularization, Laplacian Regularization

## Overview
Curvature Loss is a geometric regularization term used in radiance-field optimization to penalize high-frequency variations in the model output, thereby enforcing spatial smoothness and reducing noise in the reconstructed geometry or density field [S1, unofficial]. It sets itself apart from sibling methods like [Normal Smoothness Loss](4190-normal-smoothness-loss.md) by operating on the differential properties of the scalar field itself rather than on discrete normal vectors along viewing rays [S1, unofficial][S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input: The model output field (e.g., density $\sigma$ or Signed Distance Field value $SDF$) at a set of query points.
- Output: A scalar loss value $\mathcal{L}_{curvature}$.

**Data Structures:**
- The model output is typically a tensor of shape $(N, 1)$ or $(N,)$, where $N$ is the number of query points.
- The curvature operator $C$ is a discrete approximation of the Laplacian, often implemented as a convolution kernel or a finite difference matrix.

**Steps:**
1. Retrieve the curvature loss weight $\lambda_{curvature}$ from the configuration [S1, unofficial].
2. Apply the curvature operator $C$ to the model output field $f$ to compute the curvature field $k$:
   $$ k = C(f) $$
   In implementation, this is often done via a discrete Laplacian convolution or finite difference approximation [S1, unofficial].
3. Compute the loss as the mean squared curvature, scaled by the weight:
   $$ \mathcal{L}_{curvature} = \lambda_{curvature} \cdot \frac{1}{N} \sum_{i=1}^{N} k_i^2 $$
   Or simply the sum if normalized internally [S1, unofficial].

**Parameters:**
- $\lambda_{curvature}$: The weight for the curvature loss term. Typical values are small (e.g., $10^{-4}$ to $10^{-2}$) to avoid over-smoothing [S1, unofficial]. Retrieved from `self.config.system.loss.lambda_curvature` [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Boundary Conditions:** The curvature operator may produce artifacts at the boundaries of the query domain if not handled correctly. Padding or masking may be required [G].
- **Precision:** High-frequency noise in the input field can lead to large curvature values, potentially destabilizing training if $\lambda_{curvature}$ is too high [G].

**Pseudocode:**
```python
def curvature_loss(model_output, curvature_operator, lambda_curvature):
    """
    Compute curvature loss for a given model output.
    
    Args:
        model_output: Tensor of shape (N, 1) or (N,) representing the scalar field values.
        curvature_operator: A callable or tensor representing the discrete Laplacian operator.
        lambda_curvature: Scalar weight for the loss term.
        
    Returns:
        Scalar loss value.
    """
    # Apply curvature operator (e.g., discrete Laplacian)
    # Assuming curvature_operator is a convolution kernel or a sparse matrix
    # For a 1D case or if applied per-dimension:
    curvature = curvature_operator(model_output)
    
    # Compute mean squared curvature
    # Note: curvature might be a tensor of the same shape as model_output
    loss = torch.mean(curvature ** 2)
    
    # Scale by weight
    loss = lambda_curvature * loss
    
    return loss
```

## Subtopics

### SDF Edge Regularization Loss
A loss function that penalizes SDF values at edges where the sign changes, encouraging sharp features or correct topology at boundaries [S2, unofficial]. It sets itself apart from standard curvature loss by focusing specifically on the topological correctness of zero-crossings in SDFs rather than general smoothness [S2, unofficial].

**Steps:**
1. Gather SDF values at edge endpoints: `sdf_f1x6x2 = sdf[all_edges.reshape(-1)].reshape(-1, 2)` [S2, unofficial].
2. Create a mask for edges where signs differ: `mask = sign(sdf_f1x6x2[:, 0]) != sign(sdf_f1x6x2[:, 1])` [S2, unofficial].
3. Filter SDF values to only those edges with sign changes: `sdf_f1x6x2 = sdf_f1x6x2[mask]` [S2, unofficial].
4. Compute binary cross-entropy loss between the first endpoint and the boolean second endpoint, and vice versa [S2, unofficial].
5. Return the computed loss [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Linear in the number of query points $N$ for the application of the curvature operator, assuming a fixed-size kernel or sparse matrix.
- **Memory Complexity:** Linear in $N$ to store the curvature field.
- **Strengths:** Effective at reducing high-frequency noise and artifacts in reconstructed fields. Encourages smooth, continuous geometry.
- **Limitations:** Can over-smooth fine details if the weight is too high. Computationally more expensive than simple L2 regularization due to the derivative operation.
- **When to use:** When the reconstructed field exhibits noisy, jagged, or high-frequency artifacts. Useful for SDFs and density fields where smoothness is expected.
- **When not to use:** When preserving sharp features or high-frequency details is critical, or when the input data is already very smooth.

## Background
Curvature Loss is commonly used in differentiable rendering and implicit surface reconstruction, particularly in methods like Instant-NSR-PL [S1, unofficial] and FlexiCubes [S2, unofficial]. It builds on the principle of using differential geometric invariants to regularize the optimization process.
