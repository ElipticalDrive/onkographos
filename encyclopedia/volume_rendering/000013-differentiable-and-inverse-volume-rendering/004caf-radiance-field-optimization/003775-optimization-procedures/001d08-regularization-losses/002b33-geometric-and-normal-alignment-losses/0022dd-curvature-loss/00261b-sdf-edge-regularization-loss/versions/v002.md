# SDF Edge Regularization Loss
## Overview
A loss function that penalizes Signed Distance Function (SDF) values at mesh edges where the sign changes, encouraging sharp features or correct topology at boundaries [S1, unofficial]. It differs from general curvature penalties by focusing specifically on discrete edge connectivity to enforce zero-crossing consistency [S1, unofficial].
## How it works
**Inputs:**
- `sdf`: Tensor of SDF values at vertices. Shape not given in the sources.
- `all_edges`: Tensor of edge indices. Shape not given in the sources.

**Outputs:**
- `loss`: Scalar tensor representing the regularization loss.

**Data Structures:**
- `sdf_edges`: Intermediate tensor storing SDF values at edge endpoints.
- `mask`: Boolean tensor identifying edges with sign changes.

**Steps:**
1. Gather SDF values at edge endpoints: `sdf_edges = sdf[all_edges]`. Reshape to `[E, 2]` (or `[B, E, 2]` for batched).
2. Create a mask for edges where signs differ: `mask = sign(sdf_edges[:, 0]) != sign(sdf_edges[:, 1])`.
3. Filter SDF values to only those edges with sign changes: `sdf_filtered = sdf_edges[mask]`.
4. Compute binary cross-entropy loss between the first endpoint and the boolean second endpoint, and vice versa. Specifically, treat one endpoint's sign as the target and the other's sign as the prediction, or use a hinge-like penalty [G]. The source describes computing BCE between the first endpoint and boolean second endpoint, and vice versa [S1, unofficial].
5. Return the computed loss.

**Pseudocode:**
```python
import torch

def sdf_edge_regularization_loss(sdf, all_edges):
    # 1. Gather SDF values at edge endpoints
    sdf_edges = sdf[all_edges]  # Shape [E, 2] or [B, E, 2]

    # 2. Create mask for edges where signs differ
    signs = torch.sign(sdf_edges)  # Shape [E, 2] or [B, E, 2]
    mask = signs[:, 0] != signs[:, 1]  # Shape [E] or [B, E]

    # 3. Filter SDF values to only those edges with sign changes
    sdf_filtered = sdf_edges[mask]  # Shape [K, 2] where K is number of crossing edges

    if sdf_filtered.numel() == 0:
        return torch.tensor(0.0, device=sdf.device)

    # 4. Compute binary cross-entropy loss between first endpoint and boolean second endpoint, and vice versa
    # Map signs to 0/1 targets
    target_0 = (signs[:, 0] > 0).float()
    target_1 = (signs[:, 1] > 0).float()

    # Apply sigmoid to convert SDF values to probabilities for BCE [G]
    prob_0 = torch.sigmoid(sdf_filtered[:, 0])
    prob_1 = torch.sigmoid(sdf_filtered[:, 1])

    # Compute BCE
    loss_01 = torch.nn.functional.binary_cross_entropy(prob_0, target_1)
    loss_10 = torch.nn.functional.binary_cross_entropy(prob_1, target_0)

    loss = (loss_01 + loss_10) / 2.0
    return loss
```

**Parameters:**
- None explicitly defined in sources.

**Edge Cases:**
- No edges with sign changes: Return 0 loss.
- Precision: SDF values near 0 may cause unstable gradients if not handled.

## Subtopics

### SDF Decision Boundary Regularization
A regularization term to prevent density from growing from background into foreground by enforcing the SDF decision boundary using low-resolution SDF values [S2]. It minimizes the SDF likelihood under a Laplacian distribution using low-resolution probe values [S2].
Formula:
$$ L_{dec} = \sum_{zhw} \exp(-2|S_{zhw}|) $$
where $S_{zhw}$ are SDF values from the low-resolution probe ($192 \times 128 \times 128$), $z$ refers to the sample index, and $h,w$ to pixel [S2].

## Background
Originated in the context of differentiable volume rendering and mesh extraction, specifically associated with the FlexiCubes implementation [S1, unofficial]. It is used to improve the geometric quality of extracted meshes by ensuring consistent SDF signs across edges [S1, unofficial].
