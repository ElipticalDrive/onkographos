# SDF Edge Regularization Loss
## Overview
A loss function that penalizes Signed Distance Function (SDF) values at mesh edges where the sign changes, encouraging sharp features or correct topology at boundaries [S1, unofficial]. It differs from general curvature penalties by focusing specifically on discrete edge connectivity to enforce zero-crossing consistency [S1, unofficial].
## How it works
**Inputs:**
- `sdf`: Tensor of SDF values at vertices. Shape not given in the sources [S1, unofficial].
- `all_edges`: Tensor of edge indices mapping vertices to edges. Shape not given in the sources [S1, unofficial].

**Outputs:**
- `loss`: Scalar tensor representing the regularization loss [S1, unofficial].

**Data Structures:**
- `sdf_edges`: Intermediate tensor storing SDF values at edge endpoints, with shape `[E, 2]` where `E` is the number of edges [S1, unofficial].
- `mask`: Boolean tensor identifying edges with sign changes [S1, unofficial].

**Steps:**
1. Gather SDF values at edge endpoints: `sdf_edges = sdf[all_edges.reshape(-1)].reshape(-1, 2)` [S1, unofficial].
2. Create a mask for edges where signs differ: `mask = torch.sign(sdf_edges[:, 0]) != torch.sign(sdf_edges[:, 1])` [S1, unofficial].
3. Filter SDF values to only those edges with sign changes: `sdf_filtered = sdf_edges[mask]` [S1, unofficial].
4. Compute binary cross-entropy loss between the first endpoint and the boolean second endpoint, and vice versa [S1, unofficial].
5. Return the computed loss [S1, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def sdf_edge_regularization_loss(sdf, all_edges):
    # 1. Gather SDF values at edge endpoints
    sdf_edges = sdf[all_edges.reshape(-1)].reshape(-1, 2)

    # 2. Create mask for edges where signs differ
    mask = torch.sign(sdf_edges[:, 0]) != torch.sign(sdf_edges[:, 1])

    # 3. Filter SDF values to only those edges with sign changes
    sdf_filtered = sdf_edges[mask]

    if sdf_filtered.numel() == 0:
        return torch.tensor(0.0, device=sdf.device)

    # 4. Compute binary cross-entropy loss between first endpoint and boolean second endpoint, and vice versa
    # Targets are boolean flags for the opposite endpoint's sign
    target_0 = (sdf_filtered[:, 1] > 0).float()
    target_1 = (sdf_filtered[:, 0] > 0).float()
    # SDF values are passed directly to BCE; a sigmoid or scaling step is typically applied in practice [G]
    loss_01 = F.binary_cross_entropy(sdf_filtered[:, 0], target_0)
    loss_10 = F.binary_cross_entropy(sdf_filtered[:, 1], target_1)

    return (loss_01 + loss_10) / 2.0
```

**Parameters:**
- None explicitly defined in sources.

**Edge Cases:**
- No edges with sign changes: Return 0 loss [S1, unofficial].
- Precision: SDF values near 0 may cause unstable gradients if not handled [G].

## Subtopics

### SDF Decision Boundary Regularization
A regularization term to prevent density from growing from background into foreground by enforcing the SDF decision boundary using low-resolution SDF values [S2]. It minimizes the SDF likelihood under a Laplacian distribution using low-resolution probe values [S2].
Formula:
$$ L_{dec} = \sum_{zhw} \exp(-2|S_{zhw}|) $$
where $S_{zhw}$ are SDF values from the low-resolution probe ($192 \times 128 \times 128$), $z$ refers to the sample index, and $h,w$ to pixel [S2].
