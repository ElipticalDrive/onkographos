# Stage Control Strategy

Also called: Activation criteria, Explicit Stage-Control Mechanism, Quality-Constrained Stage Control, Stage Control

## Overview
The Stage Control Strategy is a mechanism that activates new Gaussian primitives only in spatial regions where the current reconstruction quality falls below a prescribed fidelity target, avoiding redundancy and promoting compactness [S1, unofficial]. It solves the problem of unnecessary primitive allocation by restricting new Gaussian introduction to under-reconstructed areas, thereby reducing the total number of Gaussians while maintaining controlled distortion levels [S1, unofficial]. It sets itself apart from sibling methods like [Composite Loss](15617-composite-loss.md) by using explicit quality metrics (PSNR and SSIM) to gate primitive activation rather than relying on non-differentiable pseudo-labels or density-based heuristics [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Ground-truth image $I_{gt}$, reconstructed image from the previous stage $I_{i-1}$, candidate Gaussian set predicted by the current stage $\Delta \hat{G}_i$, and fidelity thresholds $\tau_{psnr}$ and $\tau_{ssim}$ [S1, unofficial].
*   **Outputs:** Effective Gaussian subset $\Delta G_i$ to be added to the scene [S1, unofficial].

**Data Structures:**
*   **Quality Maps:** Two 2D maps, $Q_{i-1}^{psnr}$ and $Q_{i-1}^{ssim}$, with dimensions matching the spatial resolution of the image patches [S1, unofficial].
*   **Activation Mask:** A binary 2D map $M_i$ with the same spatial dimensions as the patches, where each element is 0 or 1 [S1, unofficial].
*   **Candidate Gaussians:** A dense set of predicted Gaussian parameters $\Delta \hat{G}_i$, one per spatial token/patch [S1, unofficial].

**Numbered Steps:**
1.  **Compute Quality Maps:** Calculate the PSNR and SSIM between the ground-truth image $I_{gt}$ and the previous stage's reconstruction $I_{i-1}$ for each spatial location $u$ [S1, unofficial].
    $$Q_{i-1}^{psnr} = Q_{psnr}(I_{gt}, I_{i-1})$$
    $$Q_{i-1}^{ssim} = Q_{ssim}(I_{gt}, I_{i-1})$$
    [S1, unofficial]
2.  **Generate Activation Mask:** Create a binary mask $M_i(u)$ for each spatial location $u$ [S1, unofficial]. A location is marked for activation (1) if either the PSNR is below $\tau_{psnr}$ OR the SSIM is below $\tau_{ssim}$ [S1, unofficial]. Otherwise, it is masked out (0) [S1, unofficial].
    $$M_i(u) = \mathbb{I}(Q_{i-1}^{psnr}(u) < \tau_{psnr} \lor Q_{i-1}^{ssim}(u) < \tau_{ssim})$$
    [S1, unofficial]
3.  **Apply Mask to Candidates:** Perform patch-wise masking on the dense candidate Gaussian set $\Delta \hat{G}_i$ using $M_i$ to obtain the effective subset $\Delta G_i$ [S1, unofficial].
    $$\Delta G_i = M_i \odot \Delta \hat{G}_i$$
    where $\odot$ denotes element-wise multiplication or masking, effectively zeroing out or discarding candidates where $M_i(u) = 0$ [S1, unofficial].

**Pseudocode:**
```python
import math

def stage_control_strategy(I_gt, I_prev, candidate_gaussians, tau_psnr, tau_ssim, patch_size):
    """
    Activates new Gaussians only where reconstruction quality is insufficient.
    
    Args:
        I_gt: Ground truth image tensor (H, W, C).
        I_prev: Reconstructed image from previous stage (H, W, C).
        candidate_gaussians: Dense set of predicted Gaussian parameters, 
                             one per spatial token/patch.
        tau_psnr: PSNR threshold (float, e.g., 35.0).
        tau_ssim: SSIM threshold (float, e.g., 0.95).
        patch_size: Spatial dimension of each patch/token.
        
    Returns:
        effective_gaussians: Subset of candidate_gaussians activated by the mask.
    """
    H, W, C = I_gt.shape
    rows = H // patch_size
    cols = W // patch_size
    mask = []
    
    for r in range(rows):
        for c in range(cols):
            y1, y2 = r * patch_size, (r + 1) * patch_size
            x1, x2 = c * patch_size, (c + 1) * patch_size
            p_gt = I_gt[y1:y2, x1:x2, :]
            p_prev = I_prev[y1:y2, x1:x2, :]
            
            # Compute patch-wise PSNR
            mse = sum((p_gt - p_prev) ** 2) / (patch_size * patch_size * C)
            psnr = 10 * math.log10(1.0 / (mse + 1e-8))
            
            # Compute patch-wise SSIM using standard windowed statistics [G]
            mu_x = sum(p_gt) / (patch_size * patch_size * C)
            mu_y = sum(p_prev) / (patch_size * patch_size * C)
            sigma_x_sq = sum((p_gt - mu_x) ** 2) / (patch_size * patch_size * C)
            sigma_y_sq = sum((p_prev - mu_y) ** 2) / (patch_size * patch_size * C)
            sigma_xy = sum((p_gt - mu_x) * (p_prev - mu_y)) / (patch_size * patch_size * C)
            C1, C2 = 1e-4, 1e-4
            ssim = ((2 * mu_x * mu_y + C1) * (2 * sigma_xy + C2)) / \
                   ((mu_x**2 + mu_y**2 + C1) * (sigma_x_sq + sigma_y_sq + C2))
            
            mask.append(psnr < tau_psnr or ssim < tau_ssim)
    
    effective_gaussians = [g for g, m in zip(candidate_gaussians, mask) if m]
    return effective_gaussians
```

**Parameters:**
*   $\tau_{psnr}$: PSNR threshold. Default value: 35 dB [S1, unofficial].
*   $\tau_{ssim}$: SSIM threshold. Default value: 0.95 [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Threshold Sensitivity:** Increasing thresholds imposes a stricter fidelity target, activating more primitives [S1, unofficial]. Decreasing them yields a more compact representation but may degrade quality [S1, unofficial].
*   **No Masking:** If no mask is applied (all Gaussians activated), the method uses the maximum number of primitives (e.g., 58,114 in the cited experiment) [S1, unofficial].
*   **Metric Complementarity:** Using only PSNR or only SSIM provides an incomplete quality criterion [S1, unofficial]. PSNR detects large local reconstruction errors, while SSIM captures structural distortions not fully reflected by pixel-wise error [S1, unofficial]. Combining them covers both pixel-level errors and structural degradation [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The method requires computing PSNR and SSIM maps for the previous stage's reconstruction, which is $O(H \times W)$ per stage, where $H$ and $W$ are image dimensions [G]. The masking operation is also $O(N)$, where $N$ is the number of candidate Gaussians (proportional to $H \times W / ps^2$) [G].
*   **Memory Complexity:** Requires storing two quality maps ($Q_{psnr}$ and $Q_{ssim}$) and the activation mask $M_i$, each of size proportional to the number of spatial tokens [G].
*   **Measured Performance:**
    *   No mask: PSNR 30.89 dB, Utilization 1.00, #Gaussians 58,114 [S1, unofficial].
    *   PSNR target 35 dB only: PSNR 30.60 dB, Utilization 0.69, #Gaussians 40,163 [S1, unofficial].
    *   SSIM target 0.95 only: PSNR 30.29 dB, Utilization 0.75, #Gaussians 43,750 [S1, unofficial].
    *   Joint PSNR 35 dB and SSIM 0.95: PSNR 30.76 dB, Utilization 0.79, #Gaussians 46,001 [S1, unofficial].
    *   Joint PSNR 35 dB and SSIM 0.98: PSNR 30.87 dB, Utilization 0.90, #Gaussians 52,318 [S1, unofficial].
*   **Utilization Ratio:** The proportion of activated Gaussians among all candidate Gaussians, calculated as $4 \times (H/ps) \times (W/ps)$ where $H, W$ are image dimensions and $ps$ is patch size [S1, unofficial].
*   **Strengths:** Reduces unnecessary primitives under a controlled distortion level [S1, unofficial]. Improves over MSE-only and SSIM-only variants by combining complementary quality cues [S1, unofficial].
*   **Limitations:** Requires access to ground-truth images for quality map computation during training (self-supervised context) [S1, unofficial]. Performance is sensitive to threshold selection [S1, unofficial].

## Background
The Stage Control Strategy was proposed in the context of the AIR (Amortized Image Reconstruction Framework) for self-supervised feed-forward 2D Gaussian Splatting [S1, unofficial]. It addresses the drawbacks of scaling pipelines that inject inductive bias and are expensive to train [S1, unofficial]. The method follows a constrained reconstruction objective: using as few Gaussians as possible while satisfying a prescribed fidelity target [S1, unofficial]. It replaces non-differentiable pseudo-labels (like those used in Instant-GI) with an explicit quality-constrained mechanism [S1, unofficial]. The default thresholds of 35 dB PSNR and 0.95 SSIM were chosen to keep utilization at a moderate level while maintaining competitive perceptual quality [S1, unofficial].
