# 2D-GS Loss Configuration

Also called: 2D-GS Training Loss, Distortion Regularization, Uni-Bi Distortion Loss

## Overview
The 2D-GS Loss Configuration is a differentiable regularization method applied to volume rendering weights to reduce distortion artifacts [S1, unofficial]. It sets itself apart from its sibling [Distortion Loss](2755-distortion-loss.md) by decomposing the penalty into two distinct components: a uniform term that penalizes weight magnitude, and a bi-directional term that penalizes the variance of depth distribution along rays [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs**: `w` (alpha weights, shape $N_{samples}$), `s` (normalized depth parameters, shape $N_{samples}$), `ray_id` (ray identifiers, shape $N_{samples}$), and `n_max` (maximum samples per ray) [S1, unofficial].
*   **Outputs**: Scalar `loss` and gradients for `w`; gradients for `s`, `n_max`, and `ray_id` are `None` [S1, unofficial].

**Data Structures**
The method maintains prefix and suffix sums for weights and weighted distances, grouped by `ray_id`: `w_prefix`, `w_total`, `ws_prefix`, `ws_total`, `w_suffix`, and `ws_suffix` [S1, unofficial].

**Pseudocode**
```python
def forward(w, s, ray_id, n_max):
    n_rays = ray_id.max() + 1
    interval = 1.0 / n_max
    # Compute prefix sums grouped by ray_id
    w_prefix = torch.zeros_like(w)
    w_total = torch.zeros(n_rays)
    ws_prefix = torch.zeros_like(w)
    ws_total = torch.zeros(n_rays)
    for i in range(len(w)):
        rid = ray_id[i]
        w_prefix[i] = w_total[rid] + w[i]
        ws_prefix[i] = ws_total[rid] + w[i] * s[i]
        w_total[rid] = w_prefix[i]
        ws_total[rid] = ws_prefix[i]
    loss_uni = (1.0 / 3.0) * interval * w * w
    loss_bi = 2.0 * w * (s * w_prefix - ws_prefix)
    loss = (loss_uni + loss_bi) / n_rays
    save(w, s, w_prefix, w_total, ws_prefix, ws_total, ray_id, interval)
    return loss

def backward(grad_back, saved_tensors):
    w, s, w_prefix, w_total, ws_prefix, ws_total, ray_id, interval = saved_tensors
    w_suffix = w_total[ray_id] - (w_prefix + w)
    ws_suffix = ws_total[ray_id] - (ws_prefix + w * s)
    grad_uni = (1.0 / 3.0) * interval * 2.0 * w
    grad_bi = 2.0 * (s * (w_prefix - w_suffix) + (ws_suffix - ws_prefix))
    grad_w = grad_back * (grad_bi + grad_uni)
    return grad_w, None, None, None
```

**Formulas**
*   Uniform loss: $loss_{uni} = \frac{1}{3} \cdot \text{interval} \cdot w^2$ [S1, unofficial].
*   Bi-directional loss: $loss_{bi} = 2 \cdot w \cdot (s \cdot w_{prefix} - ws_{prefix})$ [S1, unofficial].
*   Total loss: $loss = \frac{loss_{uni} + loss_{bi}}{n_{rays}}$ [S1, unofficial].
*   Uniform gradient: $grad_{uni} = \frac{1}{3} \cdot \text{interval} \cdot 2 \cdot w$ [S1, unofficial].
*   Bi-directional gradient: $grad_{bi} = 2 \cdot (s \cdot (w_{prefix} - w_{suffix}) + (ws_{suffix} - ws_{prefix}))$ [S1, unofficial].
*   Final gradient: $\frac{\partial loss}{\partial w} = grad_{back} \cdot (grad_{bi} + grad_{uni})$ [S1, unofficial].
*   Suffix sums: $w_{suffix} = w_{total}[\text{ray\_id}] - (w_{prefix} + w)$ and $ws_{suffix} = ws_{total}[\text{ray\_id}] - (ws_{prefix} + w \cdot s)$ [S1, unofficial].

**Parameters**
*   `w`: Alpha weights for each sample [S1, unofficial].
*   `s`: Normalized depth parameter for each sample [S1, unofficial].
*   `n_max`: Maximum number of samples per ray [S1, unofficial].
*   `ray_id`: Ray identifier for each sample [S1, unofficial].
*   Distortion loss weight: 0.01 [S2].
*   Normal loss weight: 0.05 [S2].
*   Typical values: Not given in the sources.

**Edge Cases and Pitfalls**
*   Division by zero: If `n_max` is 0, the interval calculation fails; ensure `n_max >= 1` [G].
*   Gradient flow: Gradients for `s`, `n_max`, and `ray_id` are explicitly returned as `None` [S1, unofficial].

## Subtopics

### [Composite Loss](15617-composite-loss.md)
A distortion metric that combines L1, L2, MS-SSIM, and LPIPS error signals to align rendered images with human perception. It sets itself apart from its sibling [Distortion Loss](11301-distortion-loss.md) by explicitly aggregating four distinct error signals rather than relying on a single structural or pixel-wise distance. Choose it when perceptual alignment is prioritized over structural distortion penalties.

### [Stage Control Strategy](19690-stage-control-strategy.md)
A mechanism that activates new Gaussian primitives only in spatial regions where reconstruction quality falls below a prescribed fidelity target. It sets itself apart from sibling methods like [Composite Loss](15617-composite-loss.md) by using explicit quality metrics (PSNR and SSIM) to gate primitive activation rather than relying on non-differentiable pseudo-labels or density-based heuristics. Choose it when reducing primitive redundancy and maintaining controlled distortion levels is required.
