# Predicted Normal Loss

Also called: Predicted Normal Consistency Loss

## Overview
Predicted Normal Loss is a geometric regularization term used in differentiable volume rendering to enforce surface consistency by aligning explicitly predicted surface normals with normals derived from the underlying density field [S1, unofficial]. It addresses the ambiguity of implicit surfaces in radiance fields by ensuring that the geometry encoded in the density $\sigma$ is consistent with the auxiliary normal predictions, thereby stabilizing optimization and improving surface quality [S2]. It differs from [Normal Ray Alignment Loss](4202-normal-ray-alignment-loss.md) by comparing predicted normals against the density gradient rather than against the ray direction.

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   $\mathbf{n}_k^{\text{pred}}$: The predicted normal vector at sample point $k$, output by the neural network.
    *   $\sigma(\mathbf{x})$: The scalar density field.
    *   $\mathbf{x}_{\text{pos}}_k$: The 3D position of sample point $k$ along the ray.
    *   $w_k$: The accumulated transmittance-weight (render weight) for sample point $k$.
    *   $C_{\text{normals}}$: A scalar hyperparameter controlling the loss magnitude.
*   **Output:**
    *   $\mathcal{L}_{\text{normals}}$: The scalar loss value.

**Data Structures:**
*   The density field $\sigma$ is typically represented as a neural network (e.g., MLP or Hash Grid) or a voxel grid.
*   Predicted normals $\mathbf{n}^{\text{pred}}$ are usually unit vectors ($\|\mathbf{n}\| \approx 1$).

**Steps:**
1.  **Compute Density Gradient:** Calculate the spatial gradient of the density field at the sample position $\mathbf{x}_{\text{pos}}_k$.
    $$ \nabla \sigma(\mathbf{x}_{\text{pos}}_k) = \left[ \frac{\partial \sigma}{\partial x}, \frac{\partial \sigma}{\partial y}, \frac{\partial \sigma}{\partial z} \right] $$
    This is typically computed via automatic differentiation of the density network with respect to the input coordinates $\mathbf{x}_{\text{pos}}_k$ [S2].

2.  **Derive Normal:** Normalize the negative gradient to obtain the derived normal $\mathbf{n}_k^{\text{derived}}$. The negative sign ensures the normal points outward from the surface (assuming density decreases away from the object) [S2].
    $$ \mathbf{n}_k^{\text{derived}} = -\frac{\nabla \sigma(\mathbf{x}_{\text{pos}}_k)}{\| \nabla \sigma(\mathbf{x}_{\text{pos}}_k) \|} $$

3.  **Compute L2 Error:** Calculate the squared Euclidean distance between the predicted normal and the derived normal, weighted by the render weight $w_k$ [S2].
    $$ \text{error}_k = \| \mathbf{n}_k^{\text{pred}} - \mathbf{n}_k^{\text{derived}} \|^2 $$

4.  **Aggregate Loss:** Sum the weighted errors over all samples $k$ along all rays and scale by the hyperparameter $C_{\text{normals}}$ [S2].
    $$ \mathcal{L}_{\text{normals}} = C_{\text{normals}} \sum_{k} w_k \| \mathbf{n}_k^{\text{pred}} - \mathbf{n}_k^{\text{derived}} \|^2 $$

**Pseudocode:**
```python
def predicted_normal_loss(
    predicted_normals: Tensor,  # Shape: [num_samples, 3]
    density_network: Module,    # Network taking positions, returning density
    positions: Tensor,          # Shape: [num_samples, 3]
    render_weights: Tensor,     # Shape: [num_samples]
    c_normals: float            # Hyperparameter
) -> Tensor:
    """
    Computes the Predicted Normal Loss.
    """
    # 1. Compute density gradient via automatic differentiation
    positions.requires_grad_(True)
    density = density_network(positions)  # Shape: [num_samples]
    
    # Gradient of density w.r.t positions
    grad_sigma = torch.autograd.grad(
        outputs=density.sum(),
        inputs=positions,
        create_graph=True,
        retain_graph=True
    )[0]  # Shape: [num_samples, 3]
    
    # 2. Derive normal from negative gradient
    # Add small epsilon to avoid division by zero in flat regions
    grad_norm = torch.norm(grad_sigma, dim=1, keepdim=True) + 1e-8
    derived_normals = -grad_sigma / grad_norm
    
    # 3. Compute L2 distance between predicted and derived normals
    # Ensure predicted normals are normalized if not guaranteed by network
    pred_norm = torch.norm(predicted_normals, dim=1, keepdim=True) + 1e-8
    normalized_predicted = predicted_normals / pred_norm
    
    diff = normalized_predicted - derived_normals
    l2_error = torch.sum(diff * diff, dim=1)  # Shape: [num_samples]
    
    # 4. Weight and aggregate
    weighted_loss = l2_error * render_weights
    total_loss = c_normals * torch.sum(weighted_loss)
    
    return total_loss
```

**Parameters:**
*   `pred_normal_loss_mult` (or $C_{\text{normals}}$): Multiplier for the loss. Typical values vary by dataset. For Open Illumination, $C_{\text{normals}} = 1.0$. For TensoIR-synthetic, it linearly interpolates from 0.0001 to 1.0 between iterations 20,000 and 40,000 [S2].

**Edge Cases and Pitfalls:**
*   **Zero Gradient:** In regions where $\nabla \sigma \approx 0$ (e.g., inside empty space or uniform density), the derived normal is undefined. A small epsilon must be added to the norm denominator to prevent NaN gradients [G].
*   **Normal Orientation:** The negative sign in the derivation assumes the density field represents an object where density is high inside and low outside. If the density representation is inverted, the sign must be adjusted [S2].
*   **Precision:** The gradient computation requires `create_graph=True` in autograd to allow backpropagation through the gradient calculation itself, which increases memory usage [G].

## Subtopics

### Density Gradient Normal Loss
This is the specific implementation of Predicted Normal Loss where the reference normal is strictly derived from the negative density gradient. It is an L2 loss constraining predicted normals to match this geometric prior [S2]. It is chosen when a strong geometric prior from the density field is desired to regularize the predicted normals, particularly in methods like Flash Cache that emit normals from density networks [S2].

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of samples, dominated by the forward pass of the density network and the gradient computation.
*   **Memory Complexity:** Increases memory usage during training because `create_graph=True` is required for the gradient of the density, storing the computational graph for second-order derivatives [G].
*   **Strengths:** Provides strong geometric supervision, helping to resolve the "sliding scale" ambiguity of density fields and producing cleaner surfaces [S2].
*   **Limitations:** Relies on the differentiability and smoothness of the density field. Noisy density gradients can lead to noisy normal supervision [G].
*   **When to use:** When optimizing radiance fields that explicitly predict normals and require geometric consistency [S1, unofficial].

## Background
The concept of supervising predicted normals against density gradients originates from works such as Ref-NeRF and TensoIR, which demonstrated that constraining normals to the density gradient improves surface reconstruction quality [S2]. The specific implementation detailed here, including the weighting scheme and dataset-specific hyperparameters, is documented in the Flash Cache paper [S2]. The broader context of differentiable volume rendering and normal consistency is covered in the parent article [44-radiance-field-optimization.md].
