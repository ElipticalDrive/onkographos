# Anisotropic Total Variation

Also called: Anisotropic Total Variation (ATV) Prior, L1 Total Variation

## Overview
Anisotropic Total Variation (ATV) is a regularization prior used in tomographic reconstruction and radiance field optimization to enforce piecewise constant solutions with axis-aligned edges [S1, S2, unofficial]. It minimizes the sum of absolute differences between a voxel and its immediate neighbors along the three principal axes (x, y, z) [S1, S2, unofficial]. Unlike Isotropic Total Variation, which computes the Euclidean norm of the gradient vector at each voxel, ATV treats each axis independently, making it computationally cheaper and favoring structures aligned with the grid axes [S1, S2, unofficial]. It builds on [Total Variation Regularization](860-total-variation-regularization.md) by using the $L_1$ norm specifically along principal directions rather than a general Huber loss or isotropic magnitude.

## How it works
**Inputs:** A 3D volume grid $\mathbf{x}$ of size $N_x \times N_y \times N_z$, where $n = N_x N_y N_z$ is the total number of voxels.
**Outputs:** The regularized volume $\mathbf{x}$ (after optimization steps) or the gradient vector $\mathbf{z} = D\mathbf{x}$ and divergence $D^T\mathbf{z}$.

**Data Structures:**
The forward difference matrix $D \in \mathbb{R}^{3n \times n}$ is defined implicitly and **not stored** in memory to save space [S1, S2, unofficial].
- Each row of $D$ corresponds to an edge (difference between two voxels).
- For an edge $e$ connecting voxel $i$ to voxel $j$, the entries are:
  $$D_{ev} = \begin{cases} -1 & \text{if } v = i \\ 1 & \text{if } v = j \\ 0 & \text{otherwise} \end{cases}$$
- The matrix has $3n$ rows (edges) and $n$ columns (voxels) [S1, S2, unofficial]. Note: While the definition sums forward differences (3 per voxel), the implementation of $D^T$ considers all 6 neighbors (forward and backward) [S1, unofficial].

**Parameters:**
- $\mu$: Proximal operator step size or regularization weight. Typical values depend on the specific solver (e.g., SART or ADMM) and noise level. Not given in the sources.

**Steps:**

1. **Compute Gradient ($D\mathbf{x}$):**
   For each voxel $v = (i, j, k)$, compute the 6 forward differences (edges) connecting it to its neighbors. The vector $\mathbf{z}_v$ for voxel $v$ contains:
   $$ \mathbf{z}_v = \begin{bmatrix} x_{i+1,j,k} - x_{i,j,k} \\ x_{i,j+1,k} - x_{i,j,k} \\ x_{i,j,k+1} - x_{i,j,k} \\ x_{i,j,k} - x_{i-1,j,k} \\ x_{i,j,k} - x_{i,j-1,k} \\ x_{i,j,k} - x_{i,j,k-1} \end{bmatrix} $$
   Boundary handling: Voxels at the boundary are assumed to be replicated. Thus, if a neighbor is out of bounds, the difference is zero (i.e., $x_{boundary} = x_{neighbor}$) [S1, S2, unofficial].

2. **Compute Divergence ($D^T\mathbf{z}$):**
   For a specific vertex $v = (i, j, k)$, sum the difference values $\mathbf{z}_e$ from all incident edges $e$, weighted by $D_{ev}$.
   $$ (D^T\mathbf{z})_v = \sum_{e \ni v} D_{ev} z_e $$
   Expanding this for voxel $(i, j, k)$:
   $$ (D^T\mathbf{z})_{i,j,k} = 6x_{i,j,k} - x_{i-1,j,k} - x_{i+1,j,k} - x_{i,j-1,k} - x_{i,j+1,k} - x_{i,j,k-1} - x_{i,j,k+1} $$
   This operation is equivalent to the discrete Laplace operator $D^T D$ applied to $\mathbf{x}$ [S1, S2, unofficial].

3. **Proximal Operator (for optimization):**
   In proximal algorithms (e.g., SART), the ATV prior $h(\mathbf{x}) = \|\mathbf{D}\mathbf{x}\|_1$ requires the proximal operator of its convex conjugate $g^*$. The proximal operator for the $L_1$ norm's conjugate is the projection onto the unit $L_\infty$ ball, computed component-wise as clipping [S1, S2, unofficial]:
   $$ \text{prox}_{\mu g^*}(\mathbf{q}) = \Pi_{B_\infty}(\mathbf{q}) $$
   Component-wise definition for a value $u$:
   $$ \text{clip}(u) = \begin{cases} 1 & \text{if } u > 1 \\ u & \text{if } |u| \leq 1 \\ -1 & \text{if } u < -1 \end{cases} $$
   If the proximal operator is applied directly to the gradient (as in some soft-thresholding formulations), it uses the soft-thresholding function:
   $$ \text{prox}_{\rho_1}(\mathbf{u}) = \text{sign}(\mathbf{u}) \times \max(0, |\mathbf{u}| - \rho_1) $$
   where $\rho_1$ is the regularization parameter [S3].

**Pseudocode:**

```python
import numpy as np

def compute_atv_gradient(volume):
    """
    Computes the 6-component difference vector for each voxel.
    volume: np.ndarray of shape (Nx, Ny, Nz)
    returns: np.ndarray of shape (Nx, Ny, Nz, 6)
    """
    # Initialize output array for 6 differences:
    # 0: +x, 1: +y, 2: +z, 3: -x, 4: -y, 5: -z
    diffs = np.zeros((*volume.shape, 6))
    
    # Forward differences (+x, +y, +z)
    # x+1 - x
    diffs[:-1, :, :, 0] = volume[1:, :, :] - volume[:-1, :, :]
    # y+1 - y
    diffs[:, :-1, :, 1] = volume[:, 1:, :] - volume[:, :-1, :]
    # z+1 - z
    diffs[:, :, :-1, 2] = volume[:, :, 1:] - volume[:, :, :-1]
    
    # Backward differences (-x, -y, -z)
    # x - x-1
    diffs[1:, :, :, 3] = volume[1:, :, :] - volume[:-1, :, :]
    # y - y-1
    diffs[:, 1:, :, 4] = volume[:, 1:, :] - volume[:, :-1, :]
    # z - z-1
    diffs[:, :, 1:, 5] = volume[:, :, 1:] - volume[:, :, :-1]
    
    # Boundary handling: The slices above naturally handle internal voxels.
    # Voxels at the boundary (e.g., index 0 in x) do not have a +x neighbor in the slice.
    # The difference is implicitly 0 because the slice assignment only covers valid indices.
    # To be explicit about "replicated" boundary condition for the full 6-neighbor view:
    # If a neighbor is out of bounds, diff = 0. The slicing approach above leaves 
    # the boundary entries in 'diffs' as 0.0 (from initialization), which matches 
    # the replicated boundary assumption (x_i - x_i = 0).
    
    return diffs

def compute_atv_divergence(diffs):
    """
    Computes D^T z for each voxel.
    diffs: np.ndarray of shape (Nx, Ny, Nz, 6)
    returns: np.ndarray of shape (Nx, Ny, Nz)
    """
    # (D^T z)_v = sum(D_ev * z_e)
    # For voxel v, the edges are:
    # 0 (+x): D = -1 (v is source)
    # 1 (+y): D = -1 (v is source)
    # 2 (+z): D = -1 (v is source)
    # 3 (-x): D = +1 (v is target)
    # 4 (-y): D = +1 (v is target)
    # 5 (-z): D = +1 (v is target)
    
    # Sum of backward diffs (positive contribution)
    sum_backward = diffs[:, :, :, 3] + diffs[:, :, :, 4] + diffs[:, :, :, 5]
    
    # Sum of forward diffs (negative contribution)
    sum_forward = diffs[:, :, :, 0] + diffs[:, :, :, 1] + diffs[:, :, :, 2]
    
    # Result is sum_backward - sum_forward
    # Note: This is equivalent to 6*x - sum(neighbors) if we expand the diffs
    # But here we operate on the pre-computed diffs.
    return sum_backward - sum_forward

def prox_atv_conjugate(q, mu=1.0):
    """
    Proximal operator of the convex conjugate of the L1 norm (Projection onto L_inf ball).
    q: np.ndarray (gradient or dual variable)
    mu: step size (usually 1 for the projection definition provided)
    returns: clipped q
    """
    # Clip to [-mu, mu]
    # The formula in sources uses mu=1 for the projection definition.
    # If mu is a step size in an algorithm, it scales the input/output.
    # Standard prox_mu g*(q) = q - mu * prox_{g/mu}(q/mu)
    # For L1, prox_{g/mu}(u) = soft_threshold(u, 1/mu)
    # However, source [S1, S2, unofficial] explicitly defines prox_{mu g*} as projection onto B_infty.
    # Let's stick to the explicit clipping formula given:
    # 1 if u > 1, u if |u|<=1, -1 if u < -1.
    # This corresponds to mu=1. If mu != 1, the scaling applies.
    
    # Generalized clipping for arbitrary mu:
    # prox_{mu ||.||_1*}(q) = clip(q / mu) * mu ? 
    # Source [S1, unofficial] says: prox_{mu g*}(u) = u - mu * prox_{1/mu g}(u/mu)
    # prox_{lambda ||.||_1}(v) = sign(v) * max(0, |v| - lambda)
    # So prox_{1/mu g}(u/mu) = sign(u/mu) * max(0, |u/mu| - 1/mu)
    # = (1/mu) * sign(u) * max(0, |u| - 1)
    # Then u - mu * (1/mu) * sign(u) * max(0, |u| - 1)
    # = u - sign(u) * max(0, |u| - 1)
    # = clip(u, -1, 1)
    
    # So the projection is independent of mu in the final clipped value range [-1, 1]?
    # Yes, the projection onto the unit ball is independent of mu scaling in the dual.
    
    return np.clip(q, -1.0, 1.0)

def prox_atv_gradient(u, rho1):
    """
    Soft thresholding proximal operator for the L1 norm on the gradient itself.
    Used in [S3].
    u: np.ndarray (volume gradient)
    rho1: regularization parameter
    """
    return np.sign(u) * np.maximum(0, np.abs(u) - rho1)
```

## Subtopics

### [Sum of Absolute Differences (SAD)](3279-sum-of-absolute-differences-sad.md)
Sum of Absolute Differences (SAD) extends ATV by considering a larger local neighborhood. While ATV sums absolute differences along only the three principal axes, SAD sums the absolute differences between a voxel and all voxels in its immediate 3x3 spatial neighborhood (excluding the voxel itself), thereby enforcing smoothness across more edges per voxel. It has been shown to produce excellent results in stochastic tomography reconstruction.

### [Multi-dimensional Total Variation Loss](12833-multi-dimensional-total-variation-loss.md)
Multi-dimensional Total Variation (TV) Loss computes the total variation regularization on multi-dimensional tensors by summing absolute differences along all spatial and channel dimensions. It serves as a smoothness prior for feature fields, encouraging piecewise constant solutions while preserving sharp boundaries. It extends the standard 3D TV prior by generalizing the difference operation to arbitrary tensor shapes, including batch and channel dimensions.

### Anisotropic Total Variation Proximal Operator
A regularizer based on the $\ell_1$ norm of the image gradient, assuming images are sparse in the gradient domain. The proximal operator is the soft thresholding function applied to each element of the volume gradient [S3].
Formula: $\text{prox}_{\rho_1} G_{ATV} (u_{ni}) = \text{sign}(u_{ni}) \times \max(0, |u_{ni}| - \rho_1)$, where $u_{ni}$ is the $i$th component of the volume gradient $u = Kv$ at voxel $n$ [S3].
Parameter: $\rho_1$ is the regularization parameter that controls how fast the volume gradient shrinks [S3].
Layout: $K \in \mathbb{R}^{3N \times N}$ is the forward difference matrix that produces the discrete volume gradient [S3].

## Operating characteristics
**Time Complexity:** Computing the gradient $D\mathbf{x}$ and divergence $D^T\mathbf{z}$ is $O(n)$, where $n$ is the number of voxels, as each voxel interacts with a constant number of neighbors (6). The proximal operator is also $O(n)$.
**Memory Complexity:** $O(n)$ for storing the volume. The matrix $D$ is not stored, saving significant memory compared to explicit sparse matrix storage [S1, S2, unofficial].
**Performance:** ATV is computationally efficient due to the simple $L_1$ norm and axis-aligned differences. It is faster than Isotropic TV (ITV), which requires square root computations per voxel [S1, S2, unofficial].
**Strengths:** Promotes piecewise constant solutions with sharp, axis-aligned edges. Computationally cheap.
**Limitations:** Can produce "staircasing" artifacts (piecewise constant regions) and may not preserve diagonal features as well as isotropic variants. Sensitive to the choice of regularization parameter $\rho_1$ or $\mu$ [S3].
**When to use:** When the target volume has strong axis-aligned structures and computational efficiency is critical.
**When not to use:** When isotropic smoothness is required or diagonal features are important.

## Background
Anisotropic Total Variation was introduced as a regularization prior for tomographic reconstruction, specifically within the context of proximal algorithms like SART (Simultaneous Algebraic Reconstruction Technique) [S1, S2, unofficial]. It is based on the idea that images are sparse in the gradient domain [S3]. The formulation $h(\mathbf{x}) = \|\mathbf{D}\mathbf{x}\|_1$ leverages the convex conjugate's proximal operator, which is the projection onto the unit $L_\infty$ ball [S1, S2, unofficial]. It is widely used in industrial computed tomography and electron microscopy tomography reconstruction [S1, unofficial][S3].
