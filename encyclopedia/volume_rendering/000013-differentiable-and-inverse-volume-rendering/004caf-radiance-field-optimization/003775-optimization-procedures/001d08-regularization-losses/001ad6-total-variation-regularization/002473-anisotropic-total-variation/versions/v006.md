# Anisotropic Total Variation

Also called: Anisotropic Total Variation (ATV) Prior, L1 Total Variation

## Overview
Anisotropic Total Variation (ATV) is a regularization prior used in tomographic reconstruction and radiance field optimization to enforce piecewise constant solutions with axis-aligned edges [S1, S2, unofficial]. It is defined as the sum of absolute differences between each voxel and its immediate neighbors along the three principal axes (x, y, z) [S1, S2, unofficial]. Unlike Isotropic Total Variation (ITV), which computes the Euclidean norm of the gradient vector at each voxel, ATV treats each axis independently, making it computationally simpler and favoring structures aligned with the grid axes [S1, S2, unofficial]. It builds on [Total Variation Regularization](860-total-variation-regularization.md) by restricting the neighborhood to the three forward (or six bidirectional) principal directions and using the $L_1$ norm.

## How it works
**Inputs and Outputs:**
- Input: A 3D volume grid $\mathbf{x}$ of size $N_x \times N_y \times N_z$, where $n = N_x N_y N_z$ is the total number of voxels.
- Output: The regularization energy value $h(\mathbf{x})$ and, in optimization contexts, the gradient or proximal operator updates.

**Data Structures:**
- The forward difference matrix $D \in \mathbb{R}^{3n \times n}$ is defined implicitly. It is not stored in memory to save space [S1, S2, unofficial].
- Each row of $D$ corresponds to an edge connecting two voxels. For an edge $e$ connecting voxel $i$ to voxel $j$, the entries are:
  $$ D_{ev} = \begin{cases} -1 & \text{if } v = i \\ 1 & \text{if } v = j \\ 0 & \text{otherwise} \end{cases} $$
- The matrix has $3n$ rows (edges) and $n$ columns (voxels) [S1, S2, unofficial].

**Formulas:**
The ATV energy function is defined as [S1, S2, unofficial]:
$$ h(\mathbf{x}) = \sum_{i,j,k} \left( |x_{i+1,j,k} - x_{i,j,k}| + |x_{i,j+1,k} - x_{i,j,k}| + |x_{i,j,k+1} - x_{i,j,k}| \right) $$
This can be written compactly as $h(\mathbf{x}) = \| D \mathbf{x} \|_1$, where $\| \cdot \|_1$ is the $L_1$ norm [S1, S2, unofficial].

**Proximal Operators:**
In proximal optimization algorithms (e.g., SART, ADMM), two proximal operators are commonly used [S1, S2, unofficial]:

1.  **Proximal operator of the convex conjugate ($\text{prox}_{\mu g^*}$):**
    This is used to enforce the constraint on the dual variable. It is the projection onto the unit $L_\infty$ ball $B_\infty$ [S1, S2, unofficial]:
    $$ \text{prox}_{\mu g^*}(\mathbf{q}) = \Pi_{B_\infty}(\mathbf{q}) $$
    Component-wise, for each element $q$ in $\mathbf{q}$:
    $$ \text{prox}_{\mu g^*}(q) = \begin{cases} 1 & \text{if } q > 1 \\ q & \text{if } |q| \leq 1 \\ -1 & \text{if } q < -1 \end{cases} $$
    This operation is equivalent to clipping values to the range $[-1, 1]$ [S1, S2, unofficial].

2.  **Proximal operator of the prior ($\text{prox}_{\rho_1 G_{ATV}}$):**
    Some implementations use the soft-thresholding operator directly on the gradient [S3]. For a gradient component $u_{ni}$ at voxel $n$:
    $$ \text{prox}_{\rho_1 G_{ATV}}(u_{ni}) = \text{sign}(u_{ni}) \times \max(0, |u_{ni}| - \rho_1) $$
    where $\rho_1$ is a regularization parameter controlling the shrinkage rate [S3].

**Steps for Gradient and Divergence Computation:**
Since $D$ is not stored, operations $D\mathbf{x}$ (gradient) and $D^T\mathbf{z}$ (divergence) are computed on-the-fly [S1, S2, unofficial].

1.  **Compute Gradient ($\mathbf{z} = D\mathbf{x}$):**
    For each voxel $v = (i, j, k)$, compute the 6 forward differences (considering both forward and backward neighbors for the divergence step, though the definition uses forward differences, the implementation often aggregates 6 edges per voxel for the divergence calculation) [S1, unofficial]:
    $$ \mathbf{z}_v = \begin{bmatrix} x_{i+1,j,k} - x_{i,j,k} \\ x_{i,j+1,k} - x_{i,j,k} \\ x_{i,j,k+1} - x_{i,j,k} \\ x_{i,j,k} - x_{i-1,j,k} \\ x_{i,j,k} - x_{i,j-1,k} \\ x_{i,j,k} - x_{i,j,k-1} \end{bmatrix} $$
    Boundary handling: Voxels at the boundary are assumed to be replicated, meaning missing neighbors are treated as equal to the boundary voxel, resulting in a difference of zero [S1, unofficial].

2.  **Compute Divergence ($D^T \mathbf{z}$):**
    For a voxel $v = (i, j, k)$, sum the difference values $\mathbf{z}_e$ from all incident edges $e$, weighted by $D_{ev}$:
    $$ (D^T \mathbf{z})_v = \sum_{e \in \text{incident}(v)} D_{ev} z_e $$
    Explicitly, for voxel $(i, j, k)$:
    $$ (D^T \mathbf{z})_{i,j,k} = 6x_{i,j,k} - \sum_{\text{neighbors } u} x_u $$
    where the sum is over the 6 immediate neighbors (right, bottom, back, left, top, front) [S1, unofficial]. Note that $D^T D$ corresponds to the Laplace operator [S2, unofficial].

**Pseudocode:**
```python
def compute_atv_energy(volume):
    """
    Computes the Anisotropic Total Variation energy of a 3D volume.
    volume: numpy array of shape (Nx, Ny, Nz)
    Returns: float, the ATV energy
    """
    energy = 0.0
    # Forward differences along x, y, z axes
    # Using slicing to compute differences efficiently
    # x-axis: (i+1, j, k) - (i, j, k)
    diff_x = volume[1:, :, :] - volume[:-1, :, :]
    # y-axis: (i, j+1, k) - (i, j, k)
    diff_y = volume[:, 1:, :] - volume[:, :-1, :]
    # z-axis: (i, j, k+1) - (i, j, k)
    diff_z = volume[:, :, 1:] - volume[:, :, :-1]
    
    # Sum of absolute differences
    energy = np.sum(np.abs(diff_x)) + np.sum(np.abs(diff_y)) + np.sum(np.abs(diff_z))
    return energy

def compute_gradient(volume):
    """
    Computes the 6-component gradient vector for each voxel.
    Returns: numpy array of shape (Nx, Ny, Nz, 6)
    """
    Nx, Ny, Nz = volume.shape
    grad = np.zeros((Nx, Ny, Nz, 6))
    
    # Forward differences
    grad[:-1, :, :, 0] = volume[1:, :, :] - volume[:-1, :, :] # Right
    grad[:, :-1, :, 1] = volume[:, 1:, :] - volume[:, :-1, :] # Bottom
    grad[:, :, :-1, 2] = volume[:, :, 1:] - volume[:, :, :-1] # Back
    
    # Backward differences (for divergence consistency)
    grad[1:, :, :, 3] = volume[:-1, :, :] - volume[1:, :, :] # Left
    grad[:, 1:, :, 4] = volume[:, :-1, :] - volume[:, 1:, :] # Top
    grad[:, :, 1:, 5] = volume[:, :, :-1] - volume[:, :, 1:] # Front
    
    # Boundary handling: differences involving out-of-bounds are 0
    # The slicing above naturally handles this if we assume replication
    # For explicit replication:
    # grad[-1, :, :, 0] = 0
    # grad[:, -1, :, 1] = 0
    # grad[:, :, -1, 2] = 0
    # grad[0, :, :, 3] = 0
    # grad[:, 0, :, 4] = 0
    # grad[:, :, 0, 5] = 0
    
    return grad

def compute_divergence(grad):
    """
    Computes the divergence D^T z from the 6-component gradient.
    grad: numpy array of shape (Nx, Ny, Nz, 6)
    Returns: numpy array of shape (Nx, Ny, Nz)
    """
    Nx, Ny, Nz = grad.shape[:3]
    div = np.zeros((Nx, Ny, Nz))
    
    # Sum of forward differences (indices 0, 1, 2) with coefficient -1
    # Sum of backward differences (indices 3, 4, 5) with coefficient +1
    # (D^T z)_v = sum_e D_ev z_e
    # For edge v->neighbor, D_ev = -1, z_e = x_neighbor - x_v
    # For edge neighbor->v, D_ev = 1, z_e = x_v - x_neighbor
    
    # Contribution from forward edges (v to neighbor)
    # D_ev = -1, so we subtract the forward differences
    div += -grad[:-1, :, :, 0] # - (x_{i+1} - x_i)
    div += -grad[:, :-1, :, 1] # - (x_{j+1} - x_j)
    div += -grad[:, :, :-1, 2] # - (x_{k+1} - x_k)
    
    # Contribution from backward edges (neighbor to v)
    # D_ev = 1, so we add the backward differences
    div += grad[1:, :, :, 3]   # + (x_i - x_{i-1})
    div += grad[:, 1:, :, 4]   # + (x_j - x_{j-1})
    div += grad[:, :, 1:, 5]   # + (x_k - x_{k-1})
    
    return div

def prox_l_inf(q, mu=1.0):
    """
    Proximal operator of the convex conjugate of L1 norm (Projection onto L_inf ball).
    q: numpy array
    mu: scalar, regularization parameter (usually 1 for the projection itself)
    Returns: clipped array
    """
    # The formula is component-wise clipping to [-1, 1]
    # Note: The mu scaling is handled in the algorithm loop, 
    # the core projection is to [-1, 1]
    return np.clip(q, -1.0, 1.0)

def prox_soft_threshold(u, rho1):
    """
    Proximal operator of the L1 norm (Soft thresholding).
    u: numpy array (gradient components)
    rho1: scalar, regularization parameter
    Returns: shrunk array
    """
    return np.sign(u) * np.maximum(0, np.abs(u) - rho1)
```

**Parameters:**
- $\rho_1$: Regularization parameter controlling the shrinkage rate in the soft-thresholding proximal operator [S3]. Typical values depend on the noise level and desired smoothness; not given in the sources.
- $\mu$: Step size or scaling factor in the proximal operator of the convex conjugate [S1, S2, unofficial].

**Edge Cases and Pitfalls:**
- **Boundary Handling:** Voxels at the boundary are assumed to be replicated, resulting in a difference of zero for missing neighbors [S1, unofficial]. This must be explicitly handled in implementation.
- **Memory:** The matrix $D$ is not stored explicitly to save memory; operations are computed on-the-fly [S1, S2, unofficial].
- **Precision:** The $L_1$ norm is non-differentiable at zero, which is handled by the subgradient/proximal operator framework [S1, unofficial][S3].

## Subtopics

### [Sum of Absolute Differences (SAD)](3279-sum-of-absolute-differences-sad.md)
Sum of Absolute Differences (SAD) is a regularization prior that extends Anisotropic Total Variation (ATV) by considering a larger local neighborhood. While ATV sums absolute differences along only the three principal axes, SAD sums the absolute differences between a voxel and all voxels in its immediate 3x3 spatial neighborhood (excluding the voxel itself), thereby enforcing smoothness across more edges per voxel. It has been shown to produce excellent results in stochastic tomography reconstruction. See [Sum of Absolute Differences (SAD)](3279-sum-of-absolute-differences-sad.md).

### [Multi-dimensional Total Variation Loss](12833-multi-dimensional-total-variation-loss.md)
Multi-dimensional Total Variation (TV) Loss computes the total variation regularization on multi-dimensional tensors by summing absolute differences along all spatial and channel dimensions. It serves as a smoothness prior for feature fields, encouraging piecewise constant solutions while preserving sharp boundaries. It extends the standard 3D TV prior by generalizing the difference operation to arbitrary tensor shapes, including batch and channel dimensions. See [Multi-dimensional Total Variation Loss](12833-multi-dimensional-total-variation-loss.md).

### Anisotropic Total Variation Proximal Operator
A regularizer based on the $\ell_1$ norm of the image gradient, assuming images are sparse in the gradient domain. The proximal operator is the soft thresholding function applied to each element of the volume gradient [S3]. The formula is $\text{prox}_{\rho_1 G_{ATV}}(u_{ni}) = \text{sign}(u_{ni}) \times \max(0, |u_{ni}| - \rho_1)$, where $u_{ni}$ is the $i$-th component of the volume gradient $u = Kv$ at voxel $n$ and $\rho_1$ is a regularization parameter that controls how fast the volume gradient shrinks [S3]. The matrix $K \in \mathbb{R}^{3N \times N}$ is the forward difference matrix that produces the discrete volume gradient [S3].

## Operating characteristics
- **Time Complexity:** Computing the energy and gradient is $O(n)$, where $n$ is the number of voxels, as it involves a constant number of operations per voxel [S1, S2, unofficial]. The proximal operator is also $O(n)$ [S1, S2, unofficial][S3].
- **Memory Complexity:** $O(n)$ for storing the volume and gradients. The difference matrix $D$ is not stored, saving significant memory compared to explicit matrix storage [S1, S2, unofficial].
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales linearly with the number of voxels [S1, S2, unofficial].
- **Strengths:** Computationally efficient due to the simple $L_1$ norm and axis-aligned differences; promotes piecewise constant solutions with sharp, axis-aligned edges; easy to implement with on-the-fly gradient/divergence computation [S1, S2, unofficial].
- **Limitations:** May introduce staircasing artifacts (piecewise constant bias) compared to isotropic TV or higher-order regularizers; less rotationally invariant than ITV [S1, S2, unofficial].
- **When to use:** When computational efficiency is critical, or when the underlying structures are expected to be aligned with the grid axes [S1, S2, unofficial].
- **When not to use:** When rotational invariance is important or when staircasing artifacts are undesirable [S1, S2, unofficial].

## Background
Anisotropic Total Variation (ATV) is a regularization prior used in tomographic reconstruction and image processing. It was introduced as a better prior than simple $L_2$ regularization for promoting piecewise constant solutions [S1, unofficial]. The concept is rooted in the Total Variation regularization framework, which assumes that images are sparse in the gradient domain [S3]. The proximal operator for the convex conjugate of the ATV prior is the projection onto the unit $L_\infty$ ball, which is a key component in proximal algorithms like SART for tomographic reconstruction [S1, S2, unofficial]. It has been used in various tomographic reconstruction contexts, including industrial computed tomography and electron microscopy [S1, S2, unofficial][S3].
