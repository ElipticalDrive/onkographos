# Anisotropic Total Variation

Also called: Anisotropic Total Variation (ATV) Prior, L1 Total Variation

## Overview
Anisotropic Total Variation (ATV) is a regularization prior used in tomographic reconstruction and inverse volume rendering to enforce piecewise constant solutions with axis-aligned edges [S1, S2, unofficial]. It computes the sum of absolute differences between each voxel and its immediate neighbors along the three principal axes (x, y, z) [S1, S2, unofficial]. Unlike Isotropic Total Variation (ITV), which computes the Euclidean norm of the gradient vector at each voxel, ATV treats each axis independently [S1, S2, unofficial].

## How it works
**Inputs and Outputs:** Not given in the sources.

**Data Structures:** The forward difference matrix $\mathbf{D} \in \mathbb{R}^{3n \times n}$ (where $n = N_x N_y N_z$) is not stored explicitly to save memory [S1, S2, unofficial]. Operations involving $\mathbf{D}$ (gradient) and $\mathbf{D}^T$ (divergence) are computed on-the-fly [S1, S2, unofficial]. The product $\mathbf{D}^T \mathbf{D}$ corresponds to the Laplace operator [S2, unofficial].

**Formulas:** The ATV energy function is defined as [S1, S2, unofficial]:
$$h(\mathbf{x}) = \sum_{i,j,k} \left( |x_{i+1,j,k} - x_{i,j,k}| + |x_{i,j+1,k} - x_{i,j,k}| + |x_{i,j,k+1} - x_{i,j,k}| \right)$$
This can be represented as $h(\mathbf{x}) = \|\mathbf{D}\mathbf{x}\|_1$, where $\mathbf{D}$ is the forward difference matrix [S1, S2, unofficial]. For an edge $e$ connecting voxel $i$ to voxel $j$, the matrix entries are $D_{ev} = -1$ if $v=i$, $D_{ev} = 1$ if $v=j$, and $0$ otherwise [S1, S2, unofficial].

The proximal operator for the convex conjugate of the $L_1$ norm, used in dual updates of proximal algorithms, is the projection onto the unit $L_\infty$ ball [S1, S2, unofficial]:
$$\text{prox}_{\mu \tilde{g}^*}(\mathbf{q}) = \Pi_{B_\infty}(\mathbf{q})$$
Component-wise, this is a clipping function [S1, S2, unofficial]:
$$\text{prox}_{\mu \tilde{g}^*}(q)_v = \begin{cases} 1 & \text{if } q_v > 1 \\ q_v & \text{if } |q_v| \leq 1 \\ -1 & \text{if } q_v < -1 \end{cases}$$

**Steps:**
1. **Compute Gradient ($z = \mathbf{D}\mathbf{x}$):** For each voxel $v=(i,j,k)$, compute the 6 differences connecting it to its neighbors [S1, unofficial]. The source describes $z_v$ as a vector of 6 differences [S1, unofficial]:
   $$z_v = \begin{bmatrix} x_{i+1,j,k} - x_{i,j,k} \\ x_{i,j+1,k} - x_{i,j,k} \\ x_{i,j,k+1} - x_{i,j,k} \\ x_{i,j,k} - x_{i-1,j,k} \\ x_{i,j,k} - x_{i,j-1,k} \\ x_{i,j,k} - x_{i,j,k-1} \end{bmatrix}$$
2. **Compute Divergence ($\mathbf{D}^T z$):** For a specific vertex $v$, sum the difference values $z_e$ from all incident edges $e$, weighted by $D_{ev}$ ($\pm 1$) [S1, unofficial]. This results in [S1, unofficial]:
   $$(D^T z)_v = 6x_{i,j,k} - x_{i-1,j,k} - x_{i,j-1,k} - x_{i,j,k-1} - x_{i+1,j,k} - x_{i,j+1,k} - x_{i,j,k+1}$$
3. **Apply Proximal Operator:** If the optimization algorithm requires the proximal step for the prior (e.g., in a primal-dual scheme), apply the clipping function component-wise to the dual variable $\mathbf{q}$ [S1, S2, unofficial].

**Pseudocode:**
```python
def compute_atv_divergence(volume, shape):
    """
    Computes the divergence D^T z for ATV regularization on-the-fly.
    volume: 3D array-like of shape (Nx, Ny, Nz)
    shape: tuple (Nx, Ny, Nz)
    """
    Nx, Ny, Nz = shape
    divergence = [[[0.0 for _ in range(Nz)] for _ in range(Ny)] for _ in range(Nx)]

    # Helper to get neighbor with edge replication boundary condition [S1, S2, unofficial]
    def get_neighbor(i, j, k):
        ni = max(0, min(Nx - 1, i))
        nj = max(0, min(Ny - 1, j))
        nk = max(0, min(Nz - 1, k))
        return volume[ni][nj][nk]

    for i in range(Nx):
        for j in range(Ny):
            for k in range(Nz):
                sum_neighbors = 0.0
                sum_neighbors += get_neighbor(i + 1, j, k)
                sum_neighbors += get_neighbor(i - 1, j, k)
                sum_neighbors += get_neighbor(i, j + 1, k)
                sum_neighbors += get_neighbor(i, j - 1, k)
                sum_neighbors += get_neighbor(i, j, k + 1)
                sum_neighbors += get_neighbor(i, j, k - 1)
                divergence[i][j][k] = 6.0 * volume[i][j][k] - sum_neighbors

    return divergence

def prox_atv_clipping(q):
    """
    Proximal operator for the convex conjugate of ATV prior (projection onto L_infinity ball).
    q: input tensor (3D array-like)
    """
    result = [[[0.0 for _ in range(len(q[0][0]))] for _ in range(len(q[0]))] for _ in range(len(q))]
    for i in range(len(q)):
        for j in range(len(q[0])):
            for k in range(len(q[0][0])):
                val = q[i][j][k]
                if val > 1.0:
                    result[i][j][k] = 1.0
                elif val < -1.0:
                    result[i][j][k] = -1.0
                else:
                    result[i][j][k] = val
    return result
```

**Parameters:**
- $\mu$: Step size in proximal algorithms. Not given in the sources.
- Boundary Condition: Replication (Neumann-like) is specified, resulting in a difference of zero for missing neighbors [S1, S2, unofficial].

**Edge Cases and Pitfalls:**
- **Boundary Handling:** Voxels at the boundary are assumed to be replicated, resulting in a difference of zero for missing neighbors [S1, S2, unofficial].
- **Memory:** The matrix $\mathbf{D}$ is large ($3n \times n$) and must not be stored explicitly [S1, S2, unofficial].

## Operating characteristics
- **Time Complexity:** Computing the gradient and divergence is $O(n)$ where $n$ is the number of voxels, as it involves a constant number of operations per voxel [S1, S2, unofficial].
- **Memory Complexity:** $O(n)$ for storing the volume. The difference matrix $\mathbf{D}$ is not stored, saving significant memory compared to explicit matrix methods [S1, S2, unofficial].
- **Strengths:** Computationally efficient due to separable axis-wise differences; promotes piecewise constant solutions; simple proximal operator (clipping) [S1, S2, unofficial].
- **When to use:** When computational efficiency is critical and the scene has axis-aligned structures; in stochastic tomography reconstruction [S2, unofficial].

## Background
Anisotropic Total Variation was introduced as a regularization prior in the context of industrial computed tomography and proximal algorithms for tomography reconstruction [S1, S2, unofficial]. It is widely used in inverse volume rendering and radiance field optimization to prevent artifacts such as holes or floaters [S1, S2, unofficial]. The method leverages the sparsity-promoting nature of the $L_1$ norm [S1, S2, unofficial].
