# Anisotropic Total Variation Proximal Operator

Also called: ATV Proximal Operator, ROF model proximal operator

## Overview
The Anisotropic Total Variation (ATV) Proximal Operator computes the proximal mapping for the ATV regularizer, which is defined as the $\ell_1$ norm of the discrete volume gradient [S1]. It applies the soft-thresholding function element-wise to the volume gradient components, distinguishing it from [Sum of Absolute Differences (SAD)](3279-sum-of-absolute-differences-sad.md) and [Multi-dimensional Total Variation Loss](12833-multi-dimensional-total-variation-loss.md) by operating on individual gradient directions rather than the gradient vector magnitude [S1].

## How it works
The operator computes the proximal mapping of the ATV regularizer. It assumes that images with excessive noise have high total variation and are sparse in the gradient domain [S1].

**Inputs and Outputs:**
1. **Input:** A volume gradient tensor $\mathbf{u}$ of shape $(N, 3)$, where $N$ is the number of voxels and the last dimension corresponds to the $x, y, z$ components [S1].
2. **Input:** A scalar regularization parameter $\rho_1 \ge 0$ [S1].
3. **Output:** A denoised gradient tensor $\mathbf{u}'$ of shape $(N, 3)$, where each component has been soft-thresholded [S1].

**Data Structures:**
The forward difference matrix $K \in \mathbb{R}^{3N \times N}$ is used to compute the initial gradient from a volume $\mathbf{v}$ such that $\mathbf{u} = K\mathbf{v}$ [S1]. The proximal operator itself operates directly on the pre-computed gradient components $u_{ni}$ [S1].

**Formula:**
The proximal operator is defined as the soft-thresholding function applied element-wise to the volume gradient components [S1]:

$$
\text{prox}_{\rho_1 G_{ATV}}(u_{ni}) = \text{sign}(u_{ni}) \times \max(0, |u_{ni}| - \rho_1)
$$

Where:
* $u_{ni}$ is the $i$-th component ($i \in \{0, 1, 2\}$) of the volume gradient at voxel $n$ [S1].
* $\rho_1$ is the regularization parameter that controls how fast the volume gradient shrinks [S1].
* $\text{sign}(x)$ returns $1$ if $x > 0$, $-1$ if $x < 0$, and $0$ if $x = 0$ [G].

**Parameters:**
* $\rho_1$: Regularization parameter. Higher values result in stronger shrinkage of small gradient components, promoting sparser gradients [S1].

**Pseudocode:**
The following Python-like pseudocode implements the element-wise soft-thresholding. It assumes `gradient` is a list of lists of shape `(N, 3)` and `rho1` is a scalar.

```python
def anisotropic_tv_proximal_operator(gradient, rho1):
    # gradient: list of lists of shape (N, 3)
    # rho1: scalar regularization parameter
    result = []
    for n in range(len(gradient)):
        row = []
        for i in range(3):
            u = gradient[n][i]
            abs_u = abs(u)
            thresholded = abs_u - rho1 if abs_u > rho1 else 0.0
            sign_u = 1.0 if u > 0.0 else (-1.0 if u < 0.0 else 0.0)
            row.append(sign_u * thresholded)
        result.append(row)
    return result
```

**Edge Cases and Pitfalls:**
* **Zero Gradient:** If $u_{ni} = 0$, the output is $0$ [G]. The soft-thresholding function is continuous but not differentiable at $u_{ni} = \pm \rho_1$ [G].
* **Precision:** When $|u_{ni}|$ is very close to $\rho_1$, floating-point precision errors may cause oscillations if the operator is called repeatedly in an iterative solver without momentum or step-size adjustments [G].
* **Anisotropy:** ATV sums absolute differences along the three principal axes independently, which means it does not enforce rotational symmetry [S1].

## Subtopics

### TV Minimization via Proximal Gradient (L1 Update)
This variant implements the ATV proximal operator within a proximal gradient descent framework for TV minimization [S2, unofficial]. It maintains a residual `vol_tv` from previous iterations to update the current estimate [S2, unofficial]. The algorithm initializes `ii = 0` and `stop_count = 0`, then loops while `ii < 6` and `stop_count < 3` [S2, unofficial]. Inside the loop, it computes a new volume estimate `vol[:] = vol_t - la * data.divergence(final_vol_tv)`, clips `vol` to bounds if they exist, and updates the TV residual `vol_tv[:] = final_vol_tv - 1/(8*la) * data.gradient(vol)` [S2, unofficial]. It computes the norm of the TV residual components, clamps values below 1 to 1, takes the square root, and normalizes `vol_tv` by this norm to avoid division by zero [S2, unofficial]. It updates momentum using `tau_ = tau; tau = (1 + numpy.sqrt(1 + 4*tau_**2)) / 2`, then updates `final_vol_tv = vol_tv + (tau_ - 1) / (tau) * (vol_tv - vol_tv_old)` [S2, unofficial]. Convergence is checked via `re = numpy.linalg.norm(vol - vol_old) / numpy.linalg.norm(vol)`; if `re < 1e-3`, `stop_count` increments, otherwise it resets to 0 [S2, unofficial]. The step size parameter `la` is calculated as `lamb / L`, where `L` is the Lipschitz constant of the data fidelity term [S2, unofficial].

## Operating characteristics
* **Time Complexity:** $O(N)$, where $N$ is the number of voxels, as it performs element-wise operations on the gradient tensor [G].
* **Memory Complexity:** $O(N)$ to store the gradient tensor and the output [G].
* **Strengths:** Computationally efficient; promotes piecewise constant solutions; effective at removing noise while preserving sharp edges in the principal directions [G].
* **Limitations:** Can produce "staircasing" artifacts (piecewise constant regions) in smooth gradients; the anisotropic nature sums absolute differences along principal axes independently, which may lead to directional bias in reconstructed structures [S1].
* **When to use:** When computational efficiency is critical and the volume exhibits strong edges aligned with the grid axes [G].
* **When not to use:** When rotational invariance is required (use Isotropic TV instead) or when smooth gradients are expected without staircasing artifacts [G].

## Background
The Anisotropic Total Variation regularizer was conceived based on the idea that images with excessive noise have high total variation and are sparse in the gradient domain [S1]. The proximal operator for the $\ell_1$ norm, which forms the basis of ATV, is the soft-thresholding function [S1]. This approach is widely used in tomographic reconstruction and inverse problems to denoise data [S1]. The proximal gradient implementation with momentum is found in open-source tomography libraries like flexTOMO [S2, unofficial].
