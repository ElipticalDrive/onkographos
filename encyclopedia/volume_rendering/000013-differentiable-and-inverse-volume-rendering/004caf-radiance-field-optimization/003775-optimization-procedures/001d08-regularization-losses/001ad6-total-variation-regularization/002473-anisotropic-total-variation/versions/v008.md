# Anisotropic Total Variation

Also called: Anisotropic Total Variation (ATV) Prior, L1 Total Variation

## Overview
Anisotropic Total Variation (ATV) is a regularization prior used in tomographic reconstruction and radiance field optimization to enforce piecewise constant solutions with axis-aligned edges [S1, S2, unofficial]. It is defined as the sum of absolute differences along the three principal axes (forward differences in x, y, z) [S1, S2, unofficial]. Unlike Isotropic Total Variation, which computes the Euclidean norm of the gradient vector at each voxel, ATV treats each axis independently, making it computationally cheaper and favoring structures aligned with the grid axes [S1, S2, unofficial]. It builds on [Total Variation Regularization](860-total-variation-regularization.md) by using the $L_1$ norm specifically along principal directions rather than a general Huber loss or isotropic magnitude [S1, S2, unofficial].

## How it works
**Inputs:** A 3D volume grid $\mathbf{x}$ of size $N_x \times N_y \times N_z$, where $n = N_x N_y N_z$ is the total number of voxels [S1, S2, unofficial].
**Outputs:** The regularized volume $\mathbf{x}$ (after optimization steps) or the gradient vector $\mathbf{z} = D\mathbf{x}$ and divergence $D^T\mathbf{z}$ [S1, S2, unofficial].

**Data Structures:**
The forward difference matrix $D \in \mathbb{R}^{3n \times n}$ is defined implicitly and **not stored** in memory to save space [S1, S2, unofficial].
- Each row of $D$ corresponds to an edge (difference between two voxels) [S1, unofficial].
- For an edge $e$ connecting voxel $i$ to voxel $j$, the entries are:
  $$D_{ev} = \begin{cases} -1 & \text{if } v = i \\ 1 & \text{if } v = j \\ 0 & \text{otherwise} \end{cases}$$
- The matrix has $3n$ rows (edges) and $n$ columns (voxels) [S1, S2, unofficial]. Note: While the mathematical definition sums forward differences (3 per voxel), the implementation of $D^T$ considers all 6 neighbors (forward and backward) to compute the divergence [S1, unofficial].

**Parameters:**
- $\mu$: Proximal operator step size or regularization weight. Typical values depend on the specific solver (e.g., SART or ADMM) and noise level. Not given in the sources.

**Steps:**

1. **Compute Gradient ($D\mathbf{x}$):**
   For each voxel $v = (i, j, k)$, compute the 3 forward differences connecting it to its neighbors in the positive axes. The vector $\mathbf{z}_v$ for voxel $v$ contains:
   $$ \mathbf{z}_v = \begin{bmatrix} x_{i+1,j,k} - x_{i,j,k} \\ x_{i,j+1,k} - x_{i,j,k} \\ x_{i,j,k+1} - x_{i,j,k} \end{bmatrix} $$
   Boundary handling: Voxels at the boundary are assumed to be replicated. Thus, if a neighbor is out of bounds, the difference is zero (i.e., $x_{boundary} = x_{neighbor}$) [S1, S2, unofficial].

2. **Compute Divergence ($D^T\mathbf{z}$):**
   For a specific vertex $v = (i, j, k)$, sum the difference values $\mathbf{z}_e$ from all incident edges $e$, weighted by $D_{ev}$.
   $$ (D^T\mathbf{z})_v = \sum_{e \ni v} D_{ev} z_e $$
   Expanding this for voxel $(i, j, k)$ considering all 6 neighbors:
   $$ (D^T\mathbf{z})_{i,j,k} = 6x_{i,j,k} - x_{i-1,j,k} - x_{i+1,j,k} - x_{i,j-1,k} - x_{i,j+1,k} - x_{i,j,k-1} - x_{i,j,k+1} $$
   This operation is equivalent to the discrete Laplace operator $D^T D$ applied to $\mathbf{x}$ [S1, S2, unofficial].

3. **Proximal Operator (for optimization):**
   In proximal algorithms (e.g., SART), the ATV prior $h(\mathbf{x}) = \|\mathbf{D}\mathbf{x}\|_1$ requires the proximal operator of its convex conjugate $g^*$. The proximal operator for the $L_1$ norm's conjugate is the projection onto the unit $L_\infty$ ball, computed component-wise as clipping [S1, S2, unofficial]:
   $$ \text{prox}_{\mu g^*}(\mathbf{q}) = \Pi_{B_\infty}(\mathbf{q}) $$
   Component-wise definition for a value $u$:
   $$ \text{clip}(u) = \begin{cases} 1 & \text{if } u > 1 \\ u & \text{if } |u| \leq 1 \\ -1 & \text{if } u < -1 \end{cases} $$
   If the proximal operator is applied directly to the gradient (as in some soft-thresholding formulations), it uses the soft-thresholding function:
   $$ \text{prox}_{\rho}(\mathbf{u}) = \text{sign}(\mathbf{u}) \times \max(0, |\mathbf{u}| - \rho) $$
   where $\rho$ is the regularization parameter [G].

**Pseudocode:**

```python
import numpy as np

def compute_atv_gradient(volume):
    """
    Computes the 3 forward differences for each voxel.
    volume: np.ndarray of shape (Nx, Ny, Nz)
    returns: np.ndarray of shape (Nx, Ny, Nz, 3)
    """
    diffs = np.zeros((*volume.shape, 3))
    diffs[:-1, :, :, 0] = volume[1:, :, :] - volume[:-1, :, :]
    diffs[:, :-1, :, 1] = volume[:, 1:, :] - volume[:, :-1, :]
    diffs[:, :, :-1, 2] = volume[:, :, 1:] - volume[:, :, :-1]
    return diffs

def compute_atv_divergence(volume):
    """
    Computes D^T z for each voxel using the 6-neighbor Laplacian form.
    volume: np.ndarray of shape (Nx, Ny, Nz)
    returns: np.ndarray of shape (Nx, Ny, Nz)
    """
    # Initialize with 6 * volume
    div = 6.0 * volume
    
    # Subtract neighbors
    div[:-1, :, :] -= volume[1:, :, :]
    div[1:, :, :] -= volume[:-1, :, :]
    div[:, :-1, :] -= volume[:, 1:, :]
    div[:, 1:, :] -= volume[:, :-1, :]
    div[:, :, :-1] -= volume[:, :, 1:]
    div[:, :, 1:] -= volume[:, :, :-1]
    return div

def prox_atv_conjugate(q, mu=1.0):
    """
    Proximal operator of the convex conjugate of the L1 norm (Projection onto L_inf ball).
    q: np.ndarray (gradient or dual variable)
    mu: step size
    returns: clipped q
    """
    return np.clip(q, -1.0, 1.0)
```

## Subtopics

### [Sum of Absolute Differences (SAD)](3279-sum-of-absolute-differences-sad.md)
Sum of Absolute Differences (SAD) extends ATV by considering a larger local neighborhood. While ATV sums absolute differences along only the three principal axes, SAD sums the absolute differences between a voxel and all voxels in its immediate 3x3 spatial neighborhood (excluding the voxel itself), thereby enforcing smoothness across more edges per voxel. It has been shown to produce excellent results in stochastic tomography reconstruction.

### [Multi-dimensional Total Variation Loss](12833-multi-dimensional-total-variation-loss.md)
Multi-dimensional Total Variation (TV) Loss computes the total variation regularization on multi-dimensional tensors by summing absolute differences along all spatial and channel dimensions. It serves as a smoothness prior for feature fields, encouraging piecewise constant solutions while preserving sharp boundaries. It extends the standard 3D TV prior by generalizing the difference operation to arbitrary tensor shapes, including batch and channel dimensions.

### [Anisotropic Total Variation Proximal Operator](15332-anisotropic-total-variation-proximal-operator.md)
The Anisotropic Total Variation (ATV) Proximal Operator is a mathematical tool used to enforce sparsity in the gradient domain of a volume during optimization. It serves as the proximal mapping for the ATV regularizer, which penalizes the $\ell_1$ norm of the discrete volume gradient. Unlike isotropic TV, which treats all gradient directions equally, ATV sums the absolute differences along the three principal axes (x, y, z) independently. This operator is distinct from [Sum of Absolute Differences (SAD)](3279-sum-of-absolute-differences-sad.md) and [Multi-dimensional Total Variation Loss](12833-multi-dimensional-total-variation-loss.md) by specifically applying soft-thresholding to the individual gradient components rather than the magnitude of the gradient vector. It is primarily used in differentiable and inverse volume rendering to denoise reconstructed volumes while preserving sharp edges.

## Operating characteristics
**Time Complexity:** Computing the gradient $D\mathbf{x}$ and divergence $D^T\mathbf{z}$ is $O(n)$, where $n$ is the number of voxels, as each voxel interacts with a constant number of neighbors (6) [G]. The proximal operator is also $O(n)$ [G].
**Memory Complexity:** $O(n)$ for storing the volume. The matrix $D$ is not stored, saving significant memory compared to explicit sparse matrix storage [S1, S2, unofficial].
**Performance:** ATV is computationally efficient due to the simple $L_1$ norm and axis-aligned differences. It is faster than Isotropic TV (ITV), which requires square root computations per voxel [S1, S2, unofficial].
**Strengths:** Promotes piecewise constant solutions with sharp, axis-aligned edges [S1, S2, unofficial]. Computationally cheap.
**Limitations:** Can produce "staircasing" artifacts (piecewise constant regions) and may not preserve diagonal features as well as isotropic variants [G]. Sensitive to the choice of regularization parameter $\mu$ [S1, S2, unofficial].
**When to use:** When the target volume has strong axis-aligned structures and computational efficiency is critical [G].
**When not to use:** When isotropic smoothness is required or diagonal features are important [G].

## Background
Anisotropic Total Variation was introduced as a regularization prior for tomographic reconstruction, specifically within the context of proximal algorithms like SART (Simultaneous Algebraic Reconstruction Technique) [S1, S2, unofficial]. The formulation $h(\mathbf{x}) = \|\mathbf{D}\mathbf{x}\|_1$ leverages the convex conjugate's proximal operator, which is the projection onto the unit $L_\infty$ ball [S1, S2, unofficial]. It is used in industrial computed tomography reconstruction [S1, unofficial].
