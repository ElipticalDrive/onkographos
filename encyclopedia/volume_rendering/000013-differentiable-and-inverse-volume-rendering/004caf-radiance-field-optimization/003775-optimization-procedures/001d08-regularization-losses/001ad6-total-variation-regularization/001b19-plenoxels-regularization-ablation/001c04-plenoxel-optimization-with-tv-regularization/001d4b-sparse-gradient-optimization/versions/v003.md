# Sparse Gradient Optimization

Also called: Gradient Sparsity

## Overview
Sparse Gradient Optimization leverages the observation that during the early stages of Plenoxel training, the gradient of the density field is highly sparse, with fewer than 10% of voxels having non-zero gradients [S1]. This method enables efficient training by focusing computational resources only on active voxels, avoiding the overhead of updating the entire voxel grid [S1]. It distinguishes itself from dense gradient-based methods by exploiting this sparsity for significant speedups in optimization [S1].

## How it works
**Inputs and Outputs:**
- Input: A set of training rays, current Plenoxel density values, and gradient information [G].
- Output: Updated Plenoxel density values for active voxels [G].

**Data Structures:**
- **Voxel Grid:** A 3D grid storing density values ($\sigma$) for each voxel [G].
- **Gradient Map:** A structure tracking which voxels have non-zero gradients, implicitly managed by the custom CUDA extension [S1].

**Numbered Steps:**
1. **Ray Casting and Rendering:** For each training ray, compute the accumulated color and transmittance using differentiable volume rendering, implemented via a custom PyTorch CUDA extension for sparse voxel structures [S1].
2. **Gradient Computation:** Compute the gradients of the loss function with respect to the density values of the voxels along the ray [G].
3. **Sparsity Identification:** Identify the subset of voxels with non-zero gradients; within the first 1-2 minutes of optimization (or first 12,800 batches for synthetic scenes), fewer than 10% of voxels have non-zero gradients, with as few as 1% updating per batch in synthetic cases [S1].
4. **Parameter Update:** Update only the density values of the voxels with non-zero gradients using an optimizer, skipping zero-gradient voxels to save computation [S1].

**Formulas:**
The core rendering equation for a ray $\mathbf{r}$ is:
$$ C(\mathbf{r}) = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i $$
where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ is the accumulated transmittance, $\sigma_i$ is the density, $\delta_i$ is the step size, and $\mathbf{c}_i$ is the color at step $i$ [G]. The gradients $\frac{\partial L}{\partial \sigma_i}$ are computed via backpropagation [G]. The implementation leverages gradient sparsity for efficient training by skipping updates for voxels with zero gradients [S1].

**Parameters:**
- **Optimization Steps:** The sparsity effect is most pronounced in the first 1-2 minutes of optimization [S1].
- **Batch Size:** Synthetic scenes may see as few as 1% of voxels updating per batch [S1].

**Edge Cases and Pitfalls:**
- **Precision:** The custom CUDA implementation must handle sparse data structures correctly to avoid missing updates or accessing invalid memory [G].
- **Boundaries:** Voxels at the boundary of the active region may have non-zero gradients due to ray intersections, even if their density is zero, requiring careful handling [G].
- **Degenerate Input:** If the scene is entirely empty or fully opaque, the gradient sparsity may not hold, potentially leading to inefficiencies or incorrect updates [G].

**Pseudocode:**
```python
import math

def sparse_gradient_optimization_step(voxel_grid, rays, optimizer):
    """
    Performs one step of sparse gradient optimization for Plenoxels.
    
    Args:
        voxel_grid: dict mapping (x, y, z) -> [sigma, r, g, b]
        rays: list of dicts with 'origin', 'direction', 'step_size', 'gt_color'
        optimizer: object with 'learning_rate', 'step()', 'zero_grad()'
        
    Returns:
        Updated voxel_grid.
    """
    # 1. Forward pass: Differentiable volume rendering
    rendered_colors = []
    for ray in rays:
        o = ray['origin']
        d = ray['direction']
        dt = ray['step_size']
        T = 1.0
        C = [0.0, 0.0, 0.0]
        for t in range(100):
            pos = [o[i] + d[i] * t * dt for i in range(3)]
            gx, gy, gz = int(pos[0]), int(pos[1]), int(pos[2])
            if (gx, gy, gz) in voxel_grid:
                sigma, color = voxel_grid[(gx, gy, gz)]
                alpha = 1.0 - math.exp(-sigma * dt)
                C = [C[i] + T * alpha * color[i] for i in range(3)]
                T *= (1.0 - alpha)
            if T < 1e-4:
                break
        rendered_colors.append(C)

    # 2. Compute loss (Mean Squared Error)
    loss = 0.0
    for k, ray in enumerate(rays):
        for i in range(3):
            diff = ray['gt_color'][i] - rendered_colors[k][i]
            loss += diff * diff
    loss /= len(rays) * 3

    # 3. Backward pass & Sparse gradient accumulation
    grad_accum = {}
    for k, ray in enumerate(rays):
        o = ray['origin']
        d = ray['direction']
        dt = ray['step_size']
        T = 1.0
        for t in range(100):
            pos = [o[i] + d[i] * t * dt for i in range(3)]
            gx, gy, gz = int(pos[0]), int(pos[1]), int(pos[2])
            if (gx, gy, gz) in voxel_grid:
                sigma, color = voxel_grid[(gx, gy, gz)]
                alpha = 1.0 - math.exp(-sigma * dt)
                # dC/dsigma = T * dt * color * exp(-sigma*dt)
                dCdsigma = [T * dt * color[i] * math.exp(-sigma * dt) for i in range(3)]
                # Accumulate gradient for this voxel from this ray
                if (gx, gy, gz) not in grad_accum:
                    grad_accum[(gx, gy, gz)] = 0.0
                grad_accum[(gx, gy, gz)] += sum(
                    dCdsigma[i] * (rendered_colors[k][i] - ray['gt_color'][i]) * 2.0 / (len(rays) * 3)
                    for i in range(3)
                )
                T *= (1.0 - alpha)
            if T < 1e-4:
                break

    # 4. Sparse parameter update
    for (gx, gy, gz), grad in grad_accum.items():
        if abs(grad) > 1e-6:
            voxel_grid[(gx, gy, gz)][0] -= optimizer.learning_rate * grad

    optimizer.zero_grad()
    return voxel_grid
```

## Subtopics

### Sparsity Loss Gradient
A regularization term added to the density gradient to encourage sparsity, using a Cauchy-like function [S2, unofficial]. The formula for the Cauchy sparsity gradient contribution is `sparsity_loss * (4 * sigma / (1 + 2 * (sigma * sigma)))` [S2, unofficial]. An alternative implementation in Alphs version is commented out: `curr_grad_sigma += sparsity_loss * _EXP(-pcnt) * ray.world_step;` [S2, unofficial]. The parameter `sparsity_loss` is a scalar weight for the sparsity loss term; if 0, the term is skipped [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Significantly reduced compared to dense methods due to sparse gradient updates [S1].
- **Memory Complexity:** Lower memory usage as only active voxels are stored and updated [S1].
- **Measured Performance:** Dramatic speedup in training compared to prior methods, alongside real-time rendering [S1]. Quality results are achieved after the first epoch, less than 1.5 minutes [S1].
- **Scaling:** Not given in the sources.
- **Strengths:** Fast training, efficient memory usage, real-time rendering capability [S1].
- **Limitations:** Requires custom CUDA implementation for optimal performance [S1].
- **When to Use:** Ideal for large-scale scenes where training speed is critical [S1].
- **When Not to Use:** If custom CUDA implementation is not feasible, or for very small scenes where overhead is negligible [G].

## Background
Plenoxels was introduced by [S1] as a method for radiance field representation without neural networks. The observation of gradient sparsity was a key insight that enabled efficient optimization [S1]. The method builds on earlier work in volume rendering and neural radiance fields [G].
