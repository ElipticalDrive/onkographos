# Static-Dynamic Factorization Regularization

Also called: Lslo(r), Static-Dynamic Density Regularization

## Overview
Static-Dynamic Factorization Regularization enforces a physically plausible scene decomposition by encouraging the spatial ratio of static to dynamic density to be binary (0 or 1) [S1]. This ensures that any point in space is occupied by either static or dynamic objects, but not both, preventing visual artifacts from overlapping components [S1]. It is a specific regularization term used within the SUDS framework for large-scale urban dynamic scene reconstruction [S1]. It builds on [Plenoxels regularization ablation](901-plenoxels-regularization-ablation.md) by adding a static-dynamic separation penalty, and differs from [Plenoxel Optimization with TV Regularization](1132-plenoxel-optimization-with-tv-regularization.md) and [Sparsity and Beta Loss Regularization](1392-sparsity-and-beta-loss-regularization.md) by explicitly targeting temporal static-dynamic ratio enforcement rather than spatial smoothness or opacity sparsity [S1].

**Inputs and Outputs:**
*   **Input:** The static density field $s_t(\mathbf{x}, t)$ at time $t$, and the temporal neighborhood $t_0 \in [t-1, t+1]$ [S1].
*   **Output:** A scalar regularization loss value $\mathcal{L}_{slo}(r)$ [S1].

**Data Structures:**
*   $s_t(\mathbf{x}, t)$: The predicted static density at spatial location $\mathbf{x}$ and time $t$ [S1].
*   $t$: The current time step [S1].

**Numbered Steps:**
1.  Identify the temporal neighbors $t_0 \in \{t-1, t, t+1\}$ for the current time step $t$ [S1].
2.  Evaluate the static density $s_{t_0}(\mathbf{x}, t)$ across the spatial domain for each neighbor [S1].
3.  Aggregate the evaluated densities according to the recoverable summation and integral structure to produce $\mathcal{L}_{slo}(r)$ [S1].

## Subtopics

### Static-Dynamic Factorization
This variant estimates a second static volume that is not conditioned on the deformation [S2, unofficial]. It introduces soft regularization losses to constrain static scene content [S2, unofficial]. It is chosen when the scene contains a persistent background that benefits from multi-view consistency across time, and it is trained on observations excluding moving parts using a user-provided binary segmentation mask [S2, unofficial].

## Background
The method is part of the SUDS (Scalable Urban Dynamic Scenes) framework, which evaluates large-scale reconstruction abilities [S1]. It was introduced in the paper "SUDS: Scalable Urban Dynamic Scenes" [S1]. The concept of separating static and dynamic components is also discussed in broader reviews of neural rendering advances, where estimating a second static volume is noted as a common technique for handling static backgrounds [S2, unofficial].
