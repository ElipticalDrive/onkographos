# Forplane Optimization Losses

Also called: Forplane Losses

## Overview
Forplane Optimization Losses are a set of regularization terms designed for differentiable volume rendering in dynamic scenes, specifically within the Forplane framework [S1]. They address the problem of disentangling static and dynamic components in spatiotemporal neural fields by enforcing structural priors on orthogonal 2D planes [S1]. Unlike standard spatial smoothness regularizers, these losses operate on space-time planes to enforce temporal consistency and feature disentanglement, ensuring that dynamic elements do not corrupt the static background representation [S1].

## How it works
The method operates on a representation where the 3D spatiotemporal field is decomposed into a set of 2D orthogonal planes. The optimization minimizes a total loss function composed of a photometric term and several regularization terms [S1].

### Inputs and Outputs
**Inputs:**
*   $\boldsymbol{\theta}$: Parameters of the MLPs (e.g., static and color networks) [S1].
*   $\boldsymbol{\phi}$: Parameters of the plane feature grids (static field $\mathbf{V}_{sd}^s$ and dynamic field $\mathbf{V}_{3d}^d$) [S1].
*   $\lambda_d, \lambda_{tv}, \lambda_{ts}, \lambda_{de}$: Scalar hyperparameters balancing the regularization terms [S1].
*   Ground truth images $I_i$ with corresponding rays $\mathbf{r}$ [S1].

**Outputs:**
*   Gradients $\nabla_{\boldsymbol{\theta}, \boldsymbol{\phi}} \mathcal{L}_{total}$ used to update model parameters [S1].

### Data Structures
The method relies on a collection of 2D planes organized into specific sets [S1]:
*   $\mathbf{V}_{sd}^s = \{G_{XY}, G_{YZ}, G_{XZ}\}$: Static space planes. These store features for the static component of the scene [S1].
*   $\mathbf{V}_{3d}^d = \{G_{XT}, G_{YT}, G_{ZT}\}$: Space-time planes. These store features for the dynamic component, linking spatial coordinates with time $t$ [S1].
*   $\mathbf{V}_{sd}^v$: Refers to the space-time planes used in the Disentanglement Error calculation [S1].

Each plane $G$ is a 2D grid of values. The resolution of these planes is normalized for gradient computation [S1].

### Formulas
The total loss is defined as [S1]:

$$
\mathcal{L}_{total}(\boldsymbol{\theta}, \boldsymbol{\phi}) = \mathcal{L}_{rgb} + \lambda_d \mathcal{L}_D + \lambda_{tv} \mathcal{L}_{TV} + \lambda_{ts} \mathcal{L}_{TS} + \lambda_{de} \mathcal{L}_{DE}
$$

1.  **Photometric Loss ($\mathcal{L}_{rgb}$)**: Measures the difference between rendered and ground truth colors [S1].
    $$
    \mathcal{L}_{rgb}(\boldsymbol{\theta}, \boldsymbol{\phi}) = \sum_i \mathbb{E}_{\mathbf{r} \sim I_i} \left[ \left\| \hat{\boldsymbol{C}}(\mathbf{r}) - \boldsymbol{C}_i^{\text{gt}}(\mathbf{r}) \right\|_2^2 \right]
    $$
    where $\hat{\boldsymbol{C}}(\mathbf{r})$ is the rendered color and $\boldsymbol{C}_i^{\text{gt}}(\mathbf{r})$ is the ground truth color for ray $\mathbf{r}$ in image $I_i$ [S1].

2.  **Total Variation Loss ($\mathcal{L}_{TV}$)**: Enforces spatial smoothness on the static space planes [S1].
    $$
    \mathcal{L}_{TV} = \sum_{G \in \mathbf{V}_{sd}^s} \sum_{g \in G} \|\Delta_h^2(G, g) + \Delta_w^2(G, g)\|
    $$
    where $\Delta_h^2(G, g)$ is the squared difference between the value at grid index $(i,j)$ and $(i+1,j)$ in plane $G$, normalized by the plane resolution [S1]. $\Delta_w^2$ is defined similarly for the width dimension [S1].

3.  **Temporal Smoothness Loss ($\mathcal{L}_{TS}$)**: Enforces smoothness along the time axis for the dynamic space-time planes [S1].
    $$
    \mathcal{L}_{TS} = \sum_{G \in \mathbf{V}_{3d}^d} \sum_{g \in G} \|\Delta_t^2(G, g)\|
    $$
    where $\Delta_t^2(G, g)$ represents the difference along the time axis for grid point $g$ in plane $G$ [S1].

4.  **Disentanglement Error ($\mathcal{L}_{DE}$)**: Encourages the dynamic field features to remain at their initial value of 1, preventing them from encoding static scene information [S1].
    $$
    \mathcal{L}_{DE} = \sum_{G \in \mathbf{V}_{sd}^v} \sum_{g \in G} \|1 - g\|
    $$
    where $\mathbf{V}_{sd}^v$ refers to the space-time planes (specifically those in the dynamic field) [S1].

### Parameters
Typical values for the hyperparameters, as used in the source experiments, are [S1]:
*   $\lambda_d = 1$
*   $\lambda_{tv} = 0.001$
*   $\lambda_{ts} = 0.05$
*   $\lambda_{de} = 0.001$

### Pseudocode
The following pseudocode computes the Forplane optimization losses. It assumes access to the plane grids and the rendered color.

```python
def compute_forplane_losses(
    rendered_colors, 
    ground_truth_colors, 
    static_planes, 
    dynamic_planes, 
    lambda_tv, 
    lambda_ts, 
    lambda_de
):
    """
    Compute the total loss including Forplane regularization terms.
    
    Args:
        rendered_colors: Tensor of shape (N, 3), rendered RGB values for N rays.
        ground_truth_colors: Tensor of shape (N, 3), ground truth RGB values.
        static_planes: List of 2D tensors representing G_XY, G_YZ, G_XZ.
        dynamic_planes: List of 2D tensors representing G_XT, G_YT, G_ZT.
        lambda_tv: Weight for Total Variation loss.
        lambda_ts: Weight for Temporal Smoothness loss.
        lambda_de: Weight for Disentanglement Error loss.
        
    Returns:
        total_loss: Scalar tensor.
    """
    # 1. Photometric Loss (MSE)
    # Note: lambda_d is assumed to be 1.0 based on source [S1]
    l_rgb = torch.mean((rendered_colors - ground_truth_colors) ** 2)
    
    # 2. Total Variation Loss on Static Planes
    l_tv = 0.0
    for plane in static_planes:
        # Compute horizontal difference: (i+1, j) - (i, j)
        # Pad to handle boundary conditions (e.g., zero-padding or replication)
        # Source [S1] specifies normalization by resolution.
        h_diff = plane[1:, :] - plane[:-1, :]
        # Compute vertical difference: (i, j+1) - (i, j)
        v_diff = plane[:, 1:] - plane[:, :-1]
        
        # Normalize by resolution (assuming plane dimensions are H, W)
        # Source [S1] says "normalized by resolution". 
        # We normalize by the number of elements in the difference grid.
        h_norm = h_diff.numel()
        v_norm = v_diff.numel()
        
        l_tv += torch.sum(torch.abs(h_diff)) / h_norm
        l_tv += torch.sum(torch.abs(v_diff)) / v_norm
        
    l_tv *= lambda_tv
    
    # 3. Temporal Smoothness Loss on Dynamic Planes
    l_ts = 0.0
    for plane in dynamic_planes:
        # Compute temporal difference along the time axis.
        # Assuming the last dimension or a specific dimension represents time.
        # Source [S1] defines G_XT, G_YT, G_ZT. 
        # We assume the time dimension is the last one for this implementation.
        t_diff = plane[:, 1:] - plane[:, :-1]
        
        t_norm = t_diff.numel()
        l_ts += torch.sum(torch.abs(t_diff)) / t_norm
        
    l_ts *= lambda_ts
    
    # 4. Disentanglement Error on Dynamic Planes
    # Encourages dynamic plane values to be close to 1.0
    l_de = 0.0
    for plane in dynamic_planes:
        # Source [S1]: sum over g in G of ||1 - g||
        # Assuming L1 norm (absolute difference) based on ||...|| notation in source
        # which is consistent with TV/TS norms used.
        l_de += torch.sum(torch.abs(1.0 - plane))
        
    l_de *= lambda_de
    
    # Total Loss
    total_loss = l_rgb + l_tv + l_ts + l_de
    
    return total_loss
```

### Edge Cases and Pitfalls
*   **Initialization**: The dynamic field $\mathbf{V}_{3d}^d$ must be initialized to 1.0. This ensures that initially, the dynamic field does not influence the features, allowing the static field to model the scene first [S1].
*   **Normalization**: The Total Variation and Temporal Smoothness losses require normalization by the plane resolution to ensure consistent gradient magnitudes across different plane sizes [S1].
*   **Plane Orientation**: The specific orientation of the space-time planes (e.g., $G_{XT}$ vs $G_{TX}$) must be consistent with the interpolation logic used during rendering [S1].

## Operating characteristics
*   **Complexity**: The regularization losses add a computational overhead proportional to the number of planes and their resolution. The TV and TS losses involve simple finite difference operations, which are $O(N)$ with respect to the number of elements in the planes. The DE loss is also $O(N)$.
*   **Memory**: Requires storing the static and dynamic plane grids. The memory footprint is determined by the resolution of these 2D planes.
*   **Strengths**: Effectively disentangles static and dynamic components in neural radiance fields, improving reconstruction quality for dynamic scenes [S1].
*   **Limitations**: Relies on the assumption that static and dynamic components can be separated via orthogonal planes. Performance may degrade if the scene has complex 3D dynamic structures that do not align well with the 2D plane decomposition [S1].
*   **When to use**: Suitable for differentiable volume rendering in dynamic scenes where disentanglement of static and dynamic elements is required [S1].

## Background
The Forplane Optimization Losses were introduced in the paper "Efficient Deformable Tissue Reconstruction via Orthogonal Neural Plane" [S1]. The method is part of the Forplane framework, which uses orthogonal neural planes to represent spatiotemporal fields. The losses are designed to regularize the optimization process, ensuring that the static and dynamic fields capture their respective components without interference [S1].
