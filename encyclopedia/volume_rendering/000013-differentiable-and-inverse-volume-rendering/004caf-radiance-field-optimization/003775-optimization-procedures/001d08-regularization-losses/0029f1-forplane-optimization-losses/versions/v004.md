# Forplane Optimization Losses

Also called: Forplane Losses

## Overview
Forplane Optimization Losses are a set of regularization terms designed to enforce structural priors and disentanglement in dynamic volumetric scene representations, specifically within the context of Neural Radiance Fields (NeRF) and deformable tissue reconstruction. They solve the problem of entangled static and dynamic features in 4D space-time volumes by penalizing spatial irregularities, temporal inconsistencies, and deviations from initial static states. What sets them apart from sibling methods like Total Variation Regularization is their specific application to orthogonal 2D planes (space-space and space-time) within a 3D+time grid, explicitly targeting the disentanglement of static and dynamic components via a dedicated "disentangle loss" [S1].

## How it works
The method operates on a volumetric representation divided into a static field and a dynamic field, each composed of multiple levels of orthogonal 2D planes. The optimization minimizes a total loss function comprising photometric error, depth consistency, and three specific Forplane regularization terms: Total Variation (TV), Temporal Smoothness (TS), and Disentangle (DE) [S1].

### Inputs and Outputs
**Inputs:**
*   $\boldsymbol{\theta}, \boldsymbol{\phi}$: Network parameters (e.g., MLP weights for density/color and deformation fields).
*   $\mathbf{V}_{sd}^s$: Set of space-space planes for the static field, denoted as $\{G_{XY}, G_{YZ}, G_{XZ}\}$ [S1].
*   $\mathbf{V}_{3d}^d$: Set of space-time planes for the dynamic field, denoted as $\{G_{XT}, G_{YT}, G_{ZT}\}$ [S1].
*   $\mathbf{V}_{sd}^v$: Set of space-time planes used for the disentangle loss (context implies these are the dynamic field's space-time planes initialized to 1) [S1].
*   $I_i$: Ground truth images.
*   $\lambda_d, \lambda_{tv}, \lambda_{ts}, \lambda_{de}$: Hyperparameters weighting the respective loss terms.

**Outputs:**
*   $\mathcal{L}_{total}$: The scalar loss value to be minimized.

### Data Structures
The core data structure is the set of 2D planes stored in memory. Each plane $G$ corresponds to a specific coordinate pair (e.g., $X,Y$) and time or static state.
*   **Layout:** A plane $G$ is a 2D grid of values. For a resolution $R \times R$, it contains $R^2$ elements.
*   **Bit Packing:** Not specified in sources. Standard floating-point (FP32) is assumed for differentiable optimization [S1].
*   **Initialization:** The dynamic field planes $\mathbf{V}_{sd}^v$ are initialized to 1. The static field planes are initialized via standard NeRF initialization schemes (not detailed in the specific Forplane notes, but implied by the rendering procedure) [S1].

### Formulas and Definitions
The total loss is defined as [S1]:
$$
\mathcal{L}_{total}(\boldsymbol{\theta}, \boldsymbol{\phi}) = \mathcal{L}_{rgb} + \lambda_d \mathcal{L}_D + \lambda_{tv} \mathcal{L}_{TV} + \lambda_{ts} \mathcal{L}_{TS} + \lambda_{de} \mathcal{L}_{DE}
$$

1.  **Photometric Loss ($\mathcal{L}_{rgb}$):**
    $$
    \mathcal{L}_{rgb}(\boldsymbol{\theta}, \boldsymbol{\phi}) = \sum_i \mathbb{E}_{\mathbf{r} \sim I_i} \left[ \left\| \hat{\boldsymbol{C}}(\mathbf{r}) - \boldsymbol{C}_i^{\text{gt}}(\mathbf{r}) \right\|_2^2 \right]
    $$
    Where $\hat{\boldsymbol{C}}(\mathbf{r})$ is the rendered color and $\boldsymbol{C}_i^{\text{gt}}(\mathbf{r})$ is the ground truth color for ray $\mathbf{r}$ in image $I_i$ [S1].

2.  **Total Variation Loss ($\mathcal{L}_{TV}$):**
    Applied to the static space-space planes $\mathbf{V}_{sd}^s = \{G_{XY}, G_{YZ}, G_{XZ}\}$ [S1]:
    $$
    \mathcal{L}_{TV} = \sum_{G \in \mathbf{V}_{sd}^s} \sum_{g \in G} \|\Delta_h^2(G, g) + \Delta_w^2(G, g)\|
    $$
    Where $\Delta_h^2(G, g)$ is the squared difference between the value at grid index $g$ and its horizontal neighbor, normalized by resolution. $\Delta_w^2$ is the vertical counterpart [S1].

3.  **Temporal Smoothness Loss ($\mathcal{L}_{TS}$):**
    Applied to the dynamic space-time planes $\mathbf{V}_{3d}^d = \{G_{XT}, G_{YT}, G_{ZT}\}$ [S1]:
    $$
    \mathcal{L}_{TS} = \sum_{G \in \mathbf{V}_{3d}^d} \sum_{g \in G} \|\Delta_t^2(G, g)\|
    $$
    Where $\Delta_t^2(G, g)$ represents the squared difference along the time axis for element $g$ in plane $G$ [S1].

4.  **Disentangle Loss ($\mathcal{L}_{DE}$):**
    Applied to the dynamic field's space-time planes $\mathbf{V}_{sd}^v$ (initialized to 1) [S1]:
    $$
    \mathcal{L}_{DE} = \sum_{G \in \mathbf{V}_{sd}^v} \sum_{g \in G} \|1 - g\|
    $$
    This encourages the dynamic features to remain close to their initial value of 1, ensuring that static content is primarily modeled by the static field and dynamic content by the dynamic field [S1].

### Parameters and Typical Values
*   $\lambda_d = 1$
*   $\lambda_{tv} = 0.001$
*   $\lambda_{ts} = 0.05$
*   $\lambda_{de} = 0.001$
These values were used in the experiments described in the source [S1].

### Pseudocode
```python
def compute_forplane_losses(
    static_planes: List[Plane], 
    dynamic_planes: List[Plane], 
    rendered_colors: List[Tensor], 
    gt_colors: List[Tensor],
    lambda_tv: float = 0.001,
    lambda_ts: float = 0.05,
    lambda_de: float = 0.001
) -> Tensor:
    """
    Computes the Forplane optimization losses.
    
    Args:
        static_planes: List of 2D planes for static field (XY, YZ, XZ).
        dynamic_planes: List of 2D planes for dynamic field (XT, YT, ZT).
        rendered_colors: List of rendered color tensors.
        gt_colors: List of ground truth color tensors.
        lambda_tv: Weight for Total Variation loss.
        lambda_ts: Weight for Temporal Smoothness loss.
        lambda_de: Weight for Disentangle loss.
        
    Returns:
        Total loss scalar.
    """
    # 1. Photometric Loss (L_rgb)
    l_rgb = 0.0
    for pred_c, gt_c in zip(rendered_colors, gt_colors):
        l_rgb += torch.mean((pred_c - gt_c) ** 2)
        
    # Note: L_D (Depth Loss) is part of the total loss formula but 
    # its specific definition is not provided in the Forplane notes.
    # It is assumed to be computed from depth outputs D_hat and GT depth.
    # l_d = compute_depth_loss(...) 
    l_d = 0.0 # Placeholder for missing definition in source context
    
    # 2. Total Variation Loss (L_TV) on static space-space planes
    l_tv = 0.0
    for plane in static_planes:
        # Compute horizontal squared differences
        # Shift plane left by 1, subtract from original, square
        h_diff = (plane[:, :-1] - plane[:, 1:]) ** 2
        # Shift plane up by 1, subtract from original, square
        v_diff = (plane[:-1, :] - plane[1:, :]) ** 2
        
        # Normalize by resolution (assuming square resolution R)
        # Source says "normalized by resolution". 
        # Usually this means dividing by R or R^2. 
        # We assume division by number of elements or spatial dimension.
        # Given the formula structure, we sum the differences.
        l_tv += torch.sum(h_diff + v_diff)
        
    # 3. Temporal Smoothness Loss (L_TS) on dynamic space-time planes
    l_ts = 0.0
    for plane in dynamic_planes:
        # Compute squared differences along the time axis (assumed last dim or specific dim)
        # Assuming plane shape is (H, W, T) or similar, but Forplane planes are 2D.
        # In space-time planes (e.g., X-T), one axis is space, one is time.
        # The source defines Delta_t^2 as difference along time axis.
        # If plane is (X, T), we diff along T.
        t_diff = (plane[:, :-1] - plane[:, 1:]) ** 2
        l_ts += torch.sum(t_diff)
        
    # 4. Disentangle Loss (L_DE) on dynamic planes initialized to 1
    l_de = 0.0
    for plane in dynamic_planes:
        # Encourage values to be close to 1
        l_de += torch.sum(torch.abs(1.0 - plane))
        
    # Total Loss
    total_loss = l_rgb + l_d + lambda_tv * l_tv + lambda_ts * l_ts + lambda_de * l_de
    
    return total_loss
```

### Edge Cases and Pitfalls
*   **Initialization Sensitivity:** The Disentangle Loss relies on the dynamic planes being initialized to 1. If initialized differently, the loss will pull them to 1, potentially corrupting the dynamic signal [S1].
*   **Resolution Normalization:** The TV loss mentions normalization by resolution. Failure to normalize correctly can cause the TV term to dominate or vanish as grid resolution changes [S1].
*   **Monocular Inputs:** In endoscopic procedures with monocular cameras, the reliance on stereo depth can limit performance. The Forplane method attempts to mitigate this via regularization, but depth ambiguity remains a challenge [S1].

## Operating characteristics
*   **Time Complexity:** The regularization losses scale linearly with the number of planes and the resolution of each plane ($O(N_{planes} \cdot R^2)$). The photometric loss scales with the number of rays sampled.
*   **Memory Complexity:** Requires storing the 2D planes for both static and dynamic fields. The memory footprint is proportional to the number of levels and planes in the Forplane representation.
*   **Strengths:** Explicitly encourages disentanglement of static and dynamic components, which is crucial for accurate reconstruction of deformable tissues [S1]. The use of orthogonal planes reduces memory compared to full 3D volumes.
*   **Limitations:** Requires careful tuning of hyperparameters ($\lambda$ values). The method is specific to the Forplane architecture and may not transfer directly to other NeRF variants without modification.
*   **When to use:** When reconstructing dynamic scenes with significant static backgrounds, particularly in medical imaging (e.g., endoscopy) where disentanglement is critical [S1].

## Background
Forplane Optimization Losses were introduced in the context of "Efficient Deformable Tissue Reconstruction via Orthogonal Neural Plane" [S1]. The method addresses limitations in previous NeRF-based approaches that struggled with dynamic deformable tissues, particularly in endoscopic procedures where monocular inputs are common [S1]. The approach builds on the idea of representing 4D scenes using orthogonal 2D planes (Forplanes) and introduces specific regularization terms to guide the optimization of these planes.
