# Forplane Optimization Losses

Also called: Forplane Losses

## Overview
Forplane Optimization Losses are a set of regularization terms designed to enforce structural priors on orthogonal neural planes (Forplanes) used in spatiotemporal volume rendering. They address the problem of entangled static and dynamic feature representations by encouraging spatial smoothness, temporal consistency, and feature disentanglement. Unlike sibling methods that primarily focus on photometric accuracy or geometric smoothness in 3D space, Forplane losses operate directly on the 2D orthogonal slices of the 3D/4D feature grid, leveraging the low-rank structure of neural fields to stabilize optimization in dynamic scenes.

## How it works
The method operates on a representation where the scene is modeled using a static field $\mathbf{V}_{sd}^{3d}$ and a dynamic field $\mathbf{V}_{d}^{3d}$, each decomposed into a set of orthogonal 2D planes. The optimization minimizes a total loss function combining photometric error with specific Forplane regularization terms.

### Inputs and Outputs
**Inputs:**
*   $\boldsymbol{\theta}, \boldsymbol{\phi}$: Network parameters (e.g., MLP weights for color/density prediction and plane feature values).
*   $\mathbf{V}_{sd}^{3d}$: Static 3D field composed of orthogonal planes.
*   $\mathbf{V}_{d}^{3d}$: Dynamic 3D field composed of orthogonal planes.
*   $\lambda_d, \lambda_{tv}, \lambda_{ts}, \lambda_{de}$: Scalar hyperparameters balancing the loss terms.
*   $\mathcal{L}_{rgb}$: Photometric reconstruction loss.
*   $\mathcal{L}_D$: Depth reconstruction loss (if applicable).

**Outputs:**
*   $\mathcal{L}_{total}$: The scalar value to be minimized.

### Data Structures
The Forplane representation organizes features into orthogonal 2D grids.
*   **Static Planes ($\mathbf{V}_{sd}^s$):** A set of 2D planes representing spatial dimensions. For a 3D space $(X, Y, Z)$, these are $G_{XY}, G_{YZ}, G_{XZ}$.
*   **Space-Time Planes ($\mathbf{V}_{sd}^v$):** Planes involving time $T$. For 4D space-time $(X, Y, Z, T)$, these include $G_{XT}, G_{YT}, G_{ZT}$ and potentially others depending on the specific decomposition.
*   **Dynamic Planes ($\mathbf{V}_{3d}^d$):** Similar to static planes but associated with the dynamic field.

Each plane $G$ is a 2D array of feature values. The notation $g \in G$ refers to a scalar value at a specific coordinate within the plane.

### Formulas
The total loss is defined as [S1]:
$$
\mathcal{L}_{total}(\boldsymbol{\theta}, \boldsymbol{\phi}) = \mathcal{L}_{rgb} + \lambda_d \mathcal{L}_D + \lambda_{tv} \mathcal{L}_{TV} + \lambda_{ts} \mathcal{L}_{TS} + \lambda_{de} \mathcal{L}_{DE}
$$

1.  **Photometric Loss ($\mathcal{L}_{rgb}$):**
    $$
    \mathcal{L}_{rgb}(\boldsymbol{\theta}, \boldsymbol{\phi}) = \sum_i \mathbb{E}_{\mathbf{r} \sim I_i} \left[ \left\| \hat{\boldsymbol{C}}(\mathbf{r}) - \boldsymbol{C}_i^{\text{gt}}(\mathbf{r}) \right\|_2^2 \right]
    $$
    where $\hat{\boldsymbol{C}}(\mathbf{r})$ is the rendered color for ray $\mathbf{r}$, and $\boldsymbol{C}_i^{\text{gt}}(\mathbf{r})$ is the ground truth color in image $I_i$ [S1].

2.  **Total Variation Loss ($\mathcal{L}_{TV}$):**
    Enforces spatial smoothness on the static field planes [S1]:
    $$
    \mathcal{L}_{TV} = \sum_{G \in \mathbf{V}_{sd}^s} \sum_{g \in G} \|\Delta_h^2(G, g) + \Delta_w^2(G, g)\|
    $$
    where $\mathbf{V}_{sd}^s = \{G_{XY}, G_{YZ}, G_{XZ}\}$ are the static space planes. $\Delta_h^2(G, g)$ and $\Delta_w^2(G, g)$ are the squared differences between the value $g$ and its horizontal and vertical neighbors in plane $G$, normalized by the plane resolution.

3.  **Temporal Smoothness Loss ($\mathcal{L}_{TS}$):**
    Enforces consistency along the time axis for space-time planes [S1]:
    $$
    \mathcal{L}_{TS} = \sum_{G \in \mathbf{V}_{3d}^d} \sum_{g \in G} \|\Delta_t^2(G, g)\|
    $$
    where $\mathbf{V}_{3d}^d = \{G_{XT}, G_{YT}, G_{ZT}\}$ are the space-time planes. $\Delta_t^2(G, g)$ represents the squared difference along the time axis for feature $g$ in plane $G$.

4.  **Disentanglement Loss ($\mathcal{L}_{DE}$):**
    Encourages dynamic field features to remain at their initial value (1) to maximize the use of the static field for static scene components [S1]:
    $$
    \mathcal{L}_{DE} = \sum_{G \in \mathbf{V}_{sd}^v} \sum_{g \in G} \|1 - g\|
    $$
    where $\mathbf{V}_{sd}^v$ refers to the space-time planes in the dynamic field initialization context. The dynamic field $\mathbf{V}_d^{3d}$ is initialized to 1, so this loss penalizes deviation from 1, effectively suppressing dynamic features where they are not needed [S1].

### Parameters
Typical values used in experiments [S1]:
*   $\lambda_d = 1$
*   $\lambda_{tv} = 0.001$
*   $\lambda_{ts} = 0.05$
*   $\lambda_{de} = 0.001$

### Pseudocode
The following pseudocode computes the Forplane regularization losses given the feature planes.

```python
def compute_forplane_losses(static_planes, dynamic_planes, dynamic_init_value=1.0):
    """
    Computes TV, TS, and DE losses for Forplane optimization.
    
    Args:
        static_planes: Dict mapping plane name (e.g., 'XY') to 2D tensor of shape (H, W).
                       Represents V_sd^s.
        dynamic_planes: Dict mapping plane name (e.g., 'XT') to 2D tensor of shape (H, W, T) or similar.
                        Represents V_3d^d. Note: For TS, we assume access to temporal slices.
                        For DE, we assume the planes are initialized to 1.0.
        dynamic_init_value: The initial value of dynamic features (default 1.0).
        
    Returns:
        tv_loss: Scalar, Total Variation loss.
        ts_loss: Scalar, Temporal Smoothness loss.
        de_loss: Scalar, Disentanglement loss.
    """
    tv_loss = 0.0
    ts_loss = 0.0
    de_loss = 0.0
    
    # 1. Total Variation Loss on Static Planes
    # V_sd^s = {G_XY, G_YZ, G_XZ}
    for plane_name, plane_tensor in static_planes.items():
        # plane_tensor is 2D: (H, W)
        # Compute horizontal second-order difference
        # delta_h^2 = (p[i, j+1] - 2*p[i, j] + p[i, j-1])
        # We sum the L2 norm of these differences. 
        # Note: Source uses ||...|| which implies L2 norm of the vector of differences.
        # Assuming standard finite difference for smoothness.
        
        # Horizontal neighbors
        h_diff = plane_tensor[:, 2:] - 2 * plane_tensor[:, 1:-1] + plane_tensor[:, :-2]
        # Vertical neighbors
        v_diff = plane_tensor[2:, :] - 2 * plane_tensor[1:-1, :] + plane_tensor[:-2, :]
        
        # Sum of squared differences (L2 norm squared is often used for gradient stability, 
        # but source says ||...||. We will use L2 norm of the difference tensor).
        # To be precise with source: sum over g of ||delta_h^2 + delta_w^2||
        # This implies element-wise addition of deltas then norm.
        combined_diff = h_diff + v_diff
        tv_loss += torch.norm(combined_diff)
        
    # 2. Temporal Smoothness Loss on Dynamic/Space-Time Planes
    # V_3d^d = {G_XT, G_YT, G_ZT}
    # These planes vary over time. 
    for plane_name, plane_tensor in dynamic_planes.items():
        # plane_tensor shape: (H, W, T) or similar. 
        # Delta_t^2 is difference along time axis.
        # Assuming T is the last dimension.
        if plane_tensor.dim() == 3:
            t_diff = plane_tensor[:, :, 2:] - 2 * plane_tensor[:, :, 1:-1] + plane_tensor[:, :, :-2]
            ts_loss += torch.norm(t_diff)
            
    # 3. Disentanglement Loss
    # Encourages dynamic features to stay at 1.
    # V_sd^v refers to space-time planes in the context of the dynamic field initialization.
    # We apply this to the dynamic planes that have a temporal component.
    for plane_name, plane_tensor in dynamic_planes.items():
        # Difference from initial value 1.0
        diff_from_one = plane_tensor - dynamic_init_value
        de_loss += torch.norm(diff_from_one)
        
    return tv_loss, ts_loss, de_loss
```

### Edge Cases and Pitfalls
*   **Boundary Conditions:** The second-order differences ($\Delta^2$) require interior points. Boundary values in the planes must be handled, either by ignoring them in the sum or using padding. The source does not specify padding, so standard interior summation is assumed [S1].
*   **Initialization:** The Disentanglement Loss relies on the dynamic field being initialized to 1. If initialized differently, the target value in $\mathcal{L}_{DE}$ must change [S1].
*   **Resolution Normalization:** The source mentions $\Delta_h^2$ is "normalized by resolution". This likely means dividing the difference by the spatial extent or pixel size to make the loss scale-invariant. The pseudocode above uses raw differences; implementers should divide by the plane dimensions if strict adherence to the source's normalization is required [S1].

## Operating characteristics
*   **Time Complexity:** The losses are computed in $O(N)$ with respect to the number of elements in the feature planes, as they involve simple element-wise operations and norms.
*   **Memory Complexity:** $O(N)$ to store the feature planes. The loss computation itself is $O(1)$ auxiliary memory.
*   **Strengths:** Effectively disentangles static and dynamic components, leading to cleaner reconstructions in dynamic scenes. The TV and TS terms enforce smoothness, reducing noise and artifacts common in neural field optimization.
*   **Limitations:** Requires careful tuning of hyperparameters ($\lambda_{tv}, \lambda_{ts}, \lambda_{de}$). Over-regularization can lead to oversmoothed features and loss of detail. The method assumes a specific orthogonal plane decomposition structure.
*   **When to use:** When optimizing neural radiance fields or similar representations that use orthogonal planes for spatiotemporal data, especially when static/dynamic separation is desired.
*   **When not to use:** For static scenes where dynamic field regularization is unnecessary, or when computational resources are extremely limited and the overhead of computing multiple loss terms is prohibitive.

## Background
Forplane Optimization Losses were introduced in the context of "Efficient Deformable Tissue Reconstruction via Orthogonal Neural Plane" [S1]. The method leverages the Forplane representation, which decomposes 3D/4D fields into 2D orthogonal planes, to efficiently model dynamic scenes. The specific losses ($\mathcal{L}_{TV}, \mathcal{L}_{TS}, \mathcal{L}_{DE}$) were designed to regularize these planes, ensuring spatial smoothness, temporal consistency, and disentanglement of static and dynamic features. This approach is particularly relevant in medical imaging, such as endoscopic procedures, where monocular inputs are common and stereo depth is limited [S1].
