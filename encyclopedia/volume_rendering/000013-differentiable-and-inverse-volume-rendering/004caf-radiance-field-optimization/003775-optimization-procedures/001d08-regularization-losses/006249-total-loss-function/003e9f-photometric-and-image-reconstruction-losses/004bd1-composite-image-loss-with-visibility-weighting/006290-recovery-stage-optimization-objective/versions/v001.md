# Recovery-stage optimization objective

Also called: Quantization recovery objective, Recovery loss

## Overview
The recovery-stage optimization objective is a composite loss function designed to restore rendering quality and minimize artifacts introduced by feature and attribute quantization in differentiable volume rendering pipelines [S1, unofficial]. It sets itself apart from sibling methods by explicitly combining image-space reconstruction, teacher-student feature distillation, and explicit constraints on geometric offsets and scaling factors, rather than relying solely on perceptual or standard L2 losses [S1, unofficial].

## How it works
### Inputs and outputs
**Inputs:**
*   $I^{Stu}$: The rendered image from the student (quantized) model.
*   $I^{GT}$: Ground truth reference image.
*   $I^{Tea}$: Reference image rendered by the teacher (pre-quantization) model.
*   $\mathbf{f}_i^{Tea}$: Teacher anchor features for anchor $i$.
*   $\widehat{\mathbf{f}}_i^{Stu}$: Recovered student anchor features for anchor $i$.
*   $\tilde{\mathbf{O}}_i, \tilde{\mathbf{S}}_i^{\text{pos}}, \tilde{\mathbf{s}}_i^{\text{anchor}}$: Quantized offsets and scaling factors.
*   $\hat{\mathbf{O}}_i, \hat{\mathbf{s}}_i^{\text{anchor}}$: Adapted (corrected) offsets and scaling factors produced by the Attribute Adapter.
*   $\mathcal{A}_{\text{vis}}$: Set of anchors visible in the current view.
*   $N_a$: Total number of anchors.
*   $K$: Number of stages in the Residual Vector Quantization (RVQ).

**Outputs:**
*   Scalar loss value $\mathcal{L}$ used for gradient backpropagation.

### Data structures
The method operates on the following internal states, which are maintained during the optimization stages:
*   **RVQ Codebooks:** Three codebooks initialized via residual K-means. Each contains 1,024 entries [S1, unofficial].
*   **Context Refiner:** A lightweight Multi-Layer Perceptron (MLP) shared across anchors, used to recover features from quantized states [S1, unofficial].
*   **Attribute Adapter:** A lightweight MLP shared across anchors, used to refine offsets and scaling [S1, unofficial].
*   **Anchor Features:** Vectors of dimension $D_f = 50$ [S1, unofficial].
*   **Local Offsets:** 10 offsets per anchor [S1, unofficial].

### Numbered steps
The optimization proceeds in four distinct stages [S1, unofficial]:

1.  **RVQ Codebook Initialization:** Initialize the three RVQ codebooks using residual K-means. Optimize them to reconstruct teacher anchor features.
2.  **Context Refiner Training:** Train the Context Refiner using quantized anchor features. Sample different RVQ depths during training to allow the refiner to recover features from various reconstruction states.
3.  **Attribute Adapter Optimization:** Freeze the Context Refiner. Optimize the Attribute Adapter to refine the quantized offsets and scaling based on the features recovered by the Context Refiner.
4.  **Joint Fine-tuning:** Fix the nearest-neighbor RVQ indices. Jointly fine-tune the RVQ codebooks, Context Refiner, and Attribute Adapter using the total objective function $\mathcal{L}$ defined below.

After the recovery stage, the RVQ codebooks, Context Refiner, and Attribute Adapter are frozen. Subsequent steps involve fitting a contextual entropy model and performing index search/calibration, which are outside the scope of the optimization objective itself [S1, unofficial].

### Formulas
The total objective $\mathcal{L}$ is a weighted sum of five terms [S1, unofficial]:

$$
\mathcal{L} = \mathcal{L}_{\text{render}} \left( I^{Stu}, I^{GT} \right) + \lambda_f^{\text{train}} \mathcal{L}_f + \mathcal{L}_{Os} + \lambda_{\text{distill}} \mathcal{L}_{\text{render}} \left( I^{Stu}, I^{Tea} \right) + \lambda_A \mathcal{L}_{\text{adapter}}
$$

**1. Rendering Loss ($\mathcal{L}_{\text{render}}$):**
Combines Mean Absolute Error (MAE) and Structural Similarity (SSIM) [S1, unofficial]:

$$
\mathcal{L}_{\text{render}}(I, I^{\text{ref}}) = (1 - \gamma_{\text{SSIM}}) \text{MAE}(I, I^{\text{ref}}) + \gamma_{\text{SSIM}} [1 - \text{SSIM}(I, I^{\text{ref}})]
$$

Where $I^{\text{ref}}$ is either $I^{GT}$ or $I^{Tea}$, and $\gamma_{\text{SSIM}}$ controls the SSIM weight.

**2. Feature Recovery Loss ($\mathcal{L}_f$):**
Average L1 loss between teacher and student anchor features [S1, unofficial]:

$$
\mathcal{L}_f = \frac{1}{N_a} \sum_{i=1}^{N_a} \left\| \mathbf{f}_i^{Tea} - \widehat{\mathbf{f}}_i^{Stu} \right\|_1
$$

**3. Explicit-Attribute Loss ($\mathcal{L}_{Os}$):**
Constrains offsets ($E_i^O$) and scaling ($E_i^s$) errors for visible anchors [S1, unofficial]:

$$
\mathcal{L}_{Os} = \frac{1}{|\mathcal{A}_{\text{vis}}|} \sum_{i \in \mathcal{A}_{\text{vis}}} (\lambda_O E_i^O + \lambda_s E_i^s)
$$

Note: $E_i^O$ and $E_i^s$ are defined in external equations (17 and 18 of the source) evaluated at the current quantized state.

**4. Adapter Loss ($\mathcal{L}_{\text{adapter}}$):**
Penalizes large corrections from the Attribute Adapter, normalizing offset corrections by positional scale and constraining relative anchor scaling changes [S1, unofficial]:

$$
\mathcal{L}_{\text{adapter}} = \frac{1}{|\mathcal{A}_{\text{vis}}|} \sum_{i \in \mathcal{A}_{\text{vis}}} \left[ \frac{1}{3K} \left\| (\hat{\mathbf{O}}_i - \tilde{\mathbf{O}}_i) \otimes (\tilde{\mathbf{S}}_i^{\text{pos}} + \epsilon) \right\|_1 + \frac{1}{6} \left\| (\hat{\mathbf{s}}_i^{\text{anchor}} - \tilde{\mathbf{s}}_i^{\text{anchor}}) \otimes (\tilde{\mathbf{s}}_i^{\text{anchor}} + \epsilon) \right\|_1 \right]
$$

Where $\otimes$ denotes element-wise multiplication, and $\epsilon$ is a small constant for numerical stability.

### Parameters
Typical values from the source experiments [S1, unofficial]:

*   $\gamma_{\text{SSIM}} = 0.2$: Weight for SSIM in rendering loss.
*   $\lambda_f^{\text{train}} = 1/D_f = 0.02$: Weight for feature recovery loss ($D_f=50$).
*   $\lambda_O = 1, \lambda_s = 1$: Weights for offset and scaling errors in $\mathcal{L}_{Os}$.
*   $\lambda_{\text{distill}} = 0.1$: Weight for teacher-student rendering distillation.
*   $\lambda_A = 10^{-3}$: Weight for adapter regularization.
*   $\eta_o = 0.1, \eta_s = 0.05$: Adaptation rates for offset and scaling (used in attribute refinement, context for $\mathcal{L}_{Os}$).

### Edge cases and pitfalls
*   **Visible Anchor Set:** The losses $\mathcal{L}_{Os}$ and $\mathcal{L}_{\text{adapter}}$ are averaged only over $\mathcal{A}_{\text{vis}}$. If no anchors are visible, these terms are undefined or zero; implementation must handle empty sets gracefully [S1, unofficial].
*   **Numerical Stability:** The term $(\tilde{\mathbf{S}}_i^{\text{pos}} + \epsilon)$ and $(\tilde{\mathbf{s}}_i^{\text{anchor}} + \epsilon)$ in $\mathcal{L}_{\text{adapter}}$ requires $\epsilon > 0$ to prevent division by zero or instability if scales are near zero [S1, unofficial].
*   **Fixed Indices:** During joint fine-tuning (Stage 4), RVQ indices are fixed. Gradients do not flow through the discrete index selection, only through the codebook values and adapter/refiner parameters [S1, unofficial].

### Pseudocode

```python
def compute_recovery_loss(
    I_stu, I_gt, I_tea,
    f_tea, f_stu_hat,
    O_tilde, S_pos_tilde, s_anchor_tilde,
    O_hat, s_anchor_hat,
    A_vis, N_a, K,
    gamma_ssim=0.2,
    lambda_f_train=0.02,
    lambda_O=1.0,
    lambda_s=1.0,
    lambda_distill=0.1,
    lambda_A=1e-3,
    epsilon=1e-8
):
    """
    Computes the total recovery-stage optimization objective.
    
    Args:
        I_stu: Rendered student image tensor.
        I_gt: Ground truth image tensor.
        I_tea: Teacher rendered image tensor.
        f_tea: Teacher anchor features [N_a, D_f].
        f_stu_hat: Recovered student anchor features [N_a, D_f].
        O_tilde: Quantized offsets [N_a, 10].
        S_pos_tilde: Quantized positional scaling [N_a].
        s_anchor_tilde: Quantized anchor scaling [N_a].
        O_hat: Adapted offsets [N_a, 10].
        s_anchor_hat: Adapted anchor scaling [N_a].
        A_vis: Set of indices of visible anchors.
        N_a: Total number of anchors.
        K: Number of RVQ stages.
        
    Returns:
        Total loss scalar.
    """
    
    # 1. Rendering Loss against Ground Truth
    # MAE and SSIM are assumed to be available functions
    l_render_gt = (1 - gamma_ssim) * mae(I_stu, I_gt) + gamma_ssim * (1 - ssim(I_stu, I_gt))
    
    # 2. Feature Recovery Loss (L1)
    # Average over all anchors
    feature_diff = torch.abs(f_tea - f_stu_hat)
    l_f = torch.mean(feature_diff)
    
    # 3. Explicit-Attribute Loss
    # Note: E_O and E_S are external errors defined in source Eqs 17/18.
    # Assuming helper functions get_offset_error and get_scaling_error exist.
    # We iterate only over visible anchors.
    if len(A_vis) == 0:
        l_os = torch.tensor(0.0)
    else:
        errors_o = []
        errors_s = []
        for i in A_vis:
            errors_o.append(get_offset_error(O_tilde[i], O_hat[i])) # Placeholder for Eq 17 logic
            errors_s.append(get_scaling_error(S_pos_tilde[i], s_anchor_tilde[i])) # Placeholder for Eq 18 logic
        
        # Average error per visible anchor
        avg_e_o = torch.mean(torch.tensor(errors_o))
        avg_e_s = torch.mean(torch.tensor(errors_s))
        l_os = lambda_O * avg_e_o + lambda_s * avg_e_s

    # 4. Rendering Distillation Loss (Teacher)
    l_render_tea = (1 - gamma_ssim) * mae(I_stu, I_tea) + gamma_ssim * (1 - ssim(I_stu, I_tea))
    
    # 5. Adapter Loss
    if len(A_vis) == 0:
        l_adapter = torch.tensor(0.0)
    else:
        adapter_losses = []
        for i in A_vis:
            # Term 1: Offset correction normalized by positional scale
            # Element-wise multiplication (tensor)
            offset_corr = O_hat[i] - O_tilde[i]
            scale_norm = S_pos_tilde[i] + epsilon
            term1 = torch.norm(offset_corr * scale_norm, p=1) / (3 * K)
            
            # Term 2: Anchor scaling change normalized
            s_corr = s_anchor_hat[i] - s_anchor_tilde[i]
            s_norm = s_anchor_tilde[i] + epsilon
            term2 = torch.norm(s_corr * s_norm, p=1) / 6.0
            
            adapter_losses.append(term1 + term2)
        
        l_adapter = torch.mean(torch.tensor(adapter_losses))

    # Total Loss
    l_total = l_render_gt + lambda_f_train * l_f + l_os + lambda_distill * l_render_tea + lambda_A * l_adapter
    
    return l_total
```

## Operating characteristics
*   **Complexity**: The loss computation involves standard tensor operations (MAE, SSIM, L1 norms) over anchors and pixels. The complexity is linear with respect to the number of visible anchors $|\mathcal{A}_{\text{vis}}|$ and the number of anchors $N_a$ for the feature loss.
*   **Performance**: The method was evaluated on Mip-NeRF 360, Tanks and Temples, and Deep Blending datasets [S1, unofficial].
*   **Hardware**: Implemented in PyTorch, running on a single NVIDIA RTX 4080 GPU [S1, unofficial].
*   **Strengths**: Explicitly addresses quantization errors in both features and geometric attributes (offsets/scaling), preserving high-frequency details better than generic reconstruction losses.
*   **Limitations**: Requires access to a pre-trained teacher model for distillation ($I^{Tea}$) and feature supervision ($\mathbf{f}^{Tea}$). The multi-stage optimization (initialization, refiner training, adapter optimization, joint fine-tuning) increases training time compared to single-stage objectives.

## Background
The recovery-stage optimization objective was introduced in the context of compressing 3D Gaussian Splatting representations using Adaptive Residual Quantization and Error Compensation [S1, unofficial]. It addresses the quality degradation caused by quantizing anchor features, offsets, and scaling factors in neural radiance fields. The method builds on the Composite Image Loss with Visibility Weighting, adding specific terms to recover quantization artifacts [S1, unofficial].
