# Multi-scale Joint Training Loss

Also called: Coarse-Fine Joint Loss, Joint Loss, Multi-scale Joint Loss

## Overview
Multi-scale Joint Training Loss is a composite objective function used in the second round of training for radiance-field optimization, designed to balance low-frequency structural agreement with high-frequency detail fidelity [S2]. It sets itself apart from standard single-scale losses by simultaneously optimizing across multiple network stages or resolution levels, ensuring that global appearance is preserved while local textures are refined [S1, S2].

## How it works
The method aggregates losses from multiple output stages (layers) of a dynamically growing or multi-resolution network. It combines Mean Squared Error (MSE) and uncertainty-based terms across all stages, or balances coarse and fine reconstruction losses using a scalar weight.

**Inputs and Outputs:**
*   **Inputs:** Network parameters $\theta$, query coordinates, ground truth images, and intermediate outputs from $D$ stages.
*   **Outputs:** A scalar total loss value $L_{tot}$ or $\mathcal{L}$ used for backpropagation.

**Data Structures:**
*   **Stages ($D$):** The current number of network layers or resolution levels. In Recursive-NeRF, $D$ corresponds to the number of sub-networks in the growing architecture [S1].
*   **Intermediate Outputs:** Each stage $i$ produces an output image (or feature map) used to compute stage-specific losses $\mathcal{L}_{MSE}^i$ and $\mathcal{L}_{unct}^i$ [S1].

**Formulas:**
Two primary formulations exist in the literature:

1.  **Multi-stage Summation (Recursive-NeRF):**
    $$ \mathcal{L} = \sum_{i=1}^D \left( \beta_1 \mathcal{L}_{MSE}^i + \beta_2 \mathcal{L}_{unct}^i \right) $$
    Where:
    *   $D$ is the current number of stages [S1].
    *   $\mathcal{L}_{MSE}^i$ is the MSE loss for the output image of layer $i$ [S1].
    *   $\mathcal{L}_{unct}^i$ is the uncertainty loss for layer $i$ [S1].
    *   $\beta_1 = 1.0$ and $\beta_2 = 0.1$ are fixed weights [S1].

2.  **Coarse-Fine Balance (Denoise-GS):**
    $$ L(\theta) = \alpha L_{coarse}(\theta) + (1-\alpha) L_{fine}(\theta) $$
    Where:
    *   $\alpha \in [0, 1]$ is a hyperparameter balancing the terms [S2].
    *   $L_{coarse}$ focuses on low-frequency consistency (tone and large-scale structure) [S2].
    *   $L_{fine}$ focuses on high-frequency fidelity (detail sharpness and texture) [S2].

**Numbered Steps:**
1.  **Forward Pass:** Query the network at all active stages $i \in \{1, \dots, D\}$. [S1]
2.  **Compute Stage Losses:** For each stage $i$, calculate $\mathcal{L}_{MSE}^i$ against the ground truth and $\mathcal{L}_{unct}^i$ based on uncertainty estimates [S1]. Alternatively, compute $L_{coarse}$ and $L_{fine}$ using smoothing and detail-consistency terms (robust distance, structural similarity, gradient consistency, chroma consistency) [S2].
3.  **Aggregate:** Sum the weighted losses across all stages using the specified $\beta$ or $\alpha$ weights [S1, S2].
4.  **Backpropagate:** Compute gradients of the total loss with respect to $\theta$ and update parameters [S1, S2].

**Parameters:**
*   $\beta_1 = 1.0, \beta_2 = 0.1$ (Recursive-NeRF) [S1].
*   $\alpha \in [0, 1]$ (Denoise-GS) [S2].

**Edge Cases and Pitfalls:**
*   **Precision:** When summing losses from multiple stages, ensure consistent scaling between $\mathcal{L}_{MSE}$ and $\mathcal{L}_{unct}$ to prevent one term from dominating [S1].
*   **Boundaries:** In dynamic growth strategies, $D$ changes during training; the loss summation must adapt to the current number of active stages [S1].

    """
    Computes the multi-scale joint training loss.
    
    Args:
        network: The radiance field model with multiple stages.
        queries: Ray origins and directions.
        ground_truth: Target RGB images.
        uncertainty_map: Uncertainty estimates from the network.
        stage_weights: Optional tuple (beta1, beta2) for Recursive-NeRF style.
                       If None, assumes Coarse-Fine style.
    
    Returns:
        total_loss: Scalar tensor.
    """
    # Get outputs from all active stages
    # network.forward_all_stages returns a list of rendered images and uncertainties
    stage_outputs = network.forward_all_stages(queries)
    
    total_loss = 0.0
    num_stages = len(stage_outputs)
    
    if stage_weights is not None:
        beta1, beta2 = stage_weights
        # Recursive-NeRF Style: Sum MSE and Uncertainty across stages
        for i in range(num_stages):
            rendered_img, unc = stage_outputs[i]
            
            # MSE Loss
            mse_loss = torch.mean((rendered_img - ground_truth) ** 2)

            total_loss += beta1 * mse_loss + beta2 * unct_loss
    else:
        # Coarse-Fine Style: Balance low and high frequency

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of stages $D$, as each stage's output is rendered and loss-computed [S1].
*   **Memory Complexity:** Requires storing intermediate outputs for all $D$ stages during the forward pass to compute gradients [S1].
*   **Strengths:** Prevents overfitting to high-frequency noise by enforcing low-frequency consistency; improves detail sharpness in sparse-view settings [S2].
*   **Limitations:** Requires careful tuning of weights ($\beta, \alpha$); dynamic growth adds complexity to the training loop [S1, S2].
*   **When to use:** When training radiance fields with dynamic growth (Recursive-NeRF) or when refining denoised inputs for sparse-view reconstruction (Denoise-GS) [S1, S2].

## Background
The concept originates from two distinct lines of work in differentiable volume rendering and Gaussian Splatting. The multi-stage summation formulation was introduced in **Recursive-NeRF** (2022) by [S1], which uses a dynamically growing network where losses are aggregated across all active sub-networks. The coarse-fine balance formulation was introduced in **Denoise-GS** (2026) by [S2], applied to self-supervised denoising for sparse-view 3D Gaussian Splatting to preserve structural consistency while enhancing texture fidelity.
