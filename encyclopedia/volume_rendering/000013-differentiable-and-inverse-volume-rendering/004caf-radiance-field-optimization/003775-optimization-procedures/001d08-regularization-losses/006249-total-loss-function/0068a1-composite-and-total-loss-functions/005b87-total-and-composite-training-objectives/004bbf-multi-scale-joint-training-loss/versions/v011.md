# Multi-scale Joint Training Loss

Also called: Coarse-Fine Joint Loss, Joint Loss, Multi-scale Joint Loss

## Overview
The Multi-scale Joint Training Loss is a composite objective function used in multi-stage or multi-resolution radiance field optimization to balance structural consistency with high-frequency detail fidelity. It addresses the problem of refining coarse reconstructions by ensuring that the optimization process does not sacrifice global appearance (low-frequency agreement) while enhancing local textures and edges (high-frequency fidelity). It differs from single-scale losses by explicitly weighting contributions from different resolution stages or coarse/fine network branches, often employing a dynamic weighting scheme based on the number of active stages.

## How it works
The method operates in two primary formulations found in literature: a coarse-fine balance for refinement stages and a multi-stage summation for dynamically growing networks.

### Inputs and Outputs
*   **Inputs:**
    *   $\theta$: Network parameters.
    *   $I_{coarse}$: Low-resolution or smoothed input/reference image.
    *   $I_{fine}$: High-resolution or current network output.
    *   $I^i_{out}$: Output image from stage $i$.
    *   $D$: Current number of active stages or layers.
*   **Outputs:**
    *   Scalar loss value $L(\theta)$ or $\mathcal{L}$.

### Data Structures
No specific complex data structures are required beyond standard image tensors and scalar weights. The method relies on the hierarchical output of the network architecture (e.g., intermediate layers in a growing NeRF or coarse/fine branches in a denoising pipeline).

### Formulas and Parameters

**1. Coarse-Fine Joint Loss (Refinement Stage)**
Used to balance low-frequency structural consistency and high-frequency detail fidelity [S2].

$$ L(\theta) = \alpha L_{coarse}(\theta) + (1-\alpha) L_{fine}(\theta) $$

*   $\alpha \in [0, 1]$: Weight balancing coarse and fine terms.
*   $L_{coarse}(\theta)$: Low-frequency consistency term. This compares the input and output after smoothing. It focuses on preserving tone and large-scale structure, preventing damage to global appearance during refinement. It typically includes pixel-level robust distance, structural similarity (SSIM), gradient consistency, and chroma consistency terms [S2].
*   $L_{fine}(\theta)$: Detail consistency term. Focuses on high-frequency fidelity.

**2. Multi-Stage Summation Loss (Dynamic Growth)**
Used in dynamically growing networks where queries are processed through multiple outlets [S1].

$$ \mathcal{L} = \sum_{i=1}^D \left( \beta_1 \mathcal{L}_{MSE}^i + \beta_2 \mathcal{L}_{unct}^i \right) $$

*   $D$: Current number of stages (also equal to $D-1$ times of network growth) [S1].
*   $\mathcal{L}_{MSE}^i$: Mean Squared Error loss of the output image of layer $i$.
*   $\mathcal{L}_{unct}^i$: Uncertainty loss of the output image of layer $i$.
*   $\beta_1$: Weight for MSE loss. Typical value: $1.0$ [S1].
*   $\beta_2$: Weight for uncertainty loss. Typical value: $0.1$ [S1].

### Pseudocode

```python
def compute_multi_scale_joint_loss(outputs, targets, uncertainty_maps, config):
    """
    Computes the multi-scale joint training loss.
    
    Args:
        outputs: List of output images [I^1_out, ..., I^D_out] from each stage.
        targets: List of target images corresponding to each stage.
        uncertainty_maps: List of uncertainty maps [U^1, ..., U^D] for each stage.
        config: Dictionary containing hyperparameters.
            - 'method': 'coarse_fine' or 'dynamic_growth'
            - 'alpha': Weight for coarse term (if method is coarse_fine)
            - 'beta1': Weight for MSE term (if method is dynamic_growth)
            - 'beta2': Weight for uncertainty term (if method is dynamic_growth)
            
    Returns:
        scalar_loss: Total loss value.
    """
    if config['method'] == 'coarse_fine':
        # Coarse-Fine Joint Loss [S2]
        # L_coarse: Low-frequency consistency (structure, tone, chroma)
        # L_fine: High-frequency fidelity (edges, textures)
        # Note: Specific sub-terms for L_coarse (SSIM, gradient, etc.) are implementation details
        # of the respective loss functions, assumed to be computed externally.
        
        L_coarse = compute_coarse_consistency_loss(outputs[0], targets[0])
        L_fine = compute_fine_detail_loss(outputs[1], targets[1])
        
        alpha = config['alpha']
        scalar_loss = alpha * L_coarse + (1 - alpha) * L_fine
        
    elif config['method'] == 'dynamic_growth':
        # Multi-Stage Summation Loss [S1]
        D = len(outputs)
        beta1 = config['beta1']
        beta2 = config['beta2']
        
        total_loss = 0.0
        for i in range(D):
            # MSE Loss for stage i
            l_mse = mean_squared_error(outputs[i], targets[i])
            
            # Uncertainty Loss for stage i
            # Typically involves the uncertainty map U^i and the residual
            l_unct = compute_uncertainty_loss(outputs[i], targets[i], uncertainty_maps[i])
            
            total_loss += beta1 * l_mse + beta2 * l_unct
            
        scalar_loss = total_loss
        
    else:
        raise ValueError("Unknown method type")
        
    return scalar_loss
```

### Edge Cases and Pitfalls
*   **Stage Count $D$**: In dynamic growth methods, $D$ changes during training. The loss summation must dynamically adjust to the current number of active stages [S1].
*   **Weight Sensitivity**: The choice of $\alpha$ in coarse-fine loss and $\beta_1, \beta_2$ in multi-stage loss significantly impacts convergence. Incorrect weights may lead to over-smoothing (if coarse weight is too high) or noise amplification (if fine/uncertainty weight is too high) [S1, S2].
*   **Uncertainty Definition**: The exact formulation of $\mathcal{L}_{unct}^i$ is not fully detailed in the sources, but it is tied to the uncertainty of the query outputs [S1]. Implementers must ensure the uncertainty map is properly normalized or calibrated relative to the MSE term.

## Operating characteristics
*   **Time Complexity**: Linear with respect to the number of stages $D$ in the dynamic growth formulation, as it sums losses from all active outlets [S1].
*   **Memory Complexity**: Requires storing intermediate outputs and uncertainty maps for all active stages during the backward pass, increasing memory usage compared to single-stage losses [S1].
*   **Strengths**: Effectively balances global structure and local detail, preventing the "blurring" effect common in single-scale optimizations [S2]. Adapts to network growth dynamically [S1].
*   **Limitations**: Requires careful tuning of multiple hyperparameters ($\alpha, \beta_1, \beta_2$). The uncertainty loss term may be sensitive to the quality of the uncertainty estimation [S1].

## Background
The concept of multi-scale or joint loss functions in radiance field optimization emerged to address the limitations of single-resolution training. The dynamic growth approach with multi-stage loss was introduced in **Recursive-NeRF** [S1], which dynamically grows the network depth based on uncertainty clustering. The coarse-fine joint loss formulation was utilized in **Denoise-GS** [S2] for self-supervised denoising in sparse-view 3D Gaussian Splatting, aiming to refine denoised images while preserving structural consistency.
