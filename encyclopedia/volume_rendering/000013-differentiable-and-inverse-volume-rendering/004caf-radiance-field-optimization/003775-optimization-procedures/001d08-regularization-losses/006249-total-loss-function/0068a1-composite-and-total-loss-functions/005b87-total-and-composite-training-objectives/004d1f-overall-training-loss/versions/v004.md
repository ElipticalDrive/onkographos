# Overall Training Loss

Also called: End-to-End Training Objective, Multi-term Loss Function, PDRF Training Loss

## Overview
The overall training loss combines rendering, masking, and geometry codebook losses for end-to-end training of radiance fields and Gaussian splatting models [S3]. It aggregates photometric reconstruction, geometric consistency, and regularization terms to guide network parameters [S1, S2, S4]. The specific formulation depends on the underlying representation and training protocol [S1, S3, S4][S7, unofficial].

## How it works
### Inputs and Outputs
*   **Inputs:** Rendered images/volumes $\hat{I}$ or $\hat{V}$, ground truth images/volumes $I$ or $V_{gt}$, auxiliary predictions (depth maps $\hat{D}$, normals, masks $M$, point clouds), and model parameters (Gaussian attributes $p, \tilde{o}, \tilde{r}, \tilde{s}, c$, neural field weights, or voxel features) [S1, S2, S3, S4, S6][S7, unofficial].
*   **Outputs:** Scalar loss value $L_{tot}$ used for backpropagation [S1, S2, S3, S4][S7, unofficial].

### Data Structures
*   **Masks:** Tensors $M$ where $M_{ij} = -1$ indicates background/masked-out pixels, and $M_{ij} = 1$ indicates foreground [S6].
*   **Sub-volumes:** During training, sub-volumes $\tilde{V} \in \mathbb{R}^{M/4 \times N/4 \times K/4}$ are randomly sampled from the original volume $V$ to reduce GPU memory usage for gradients [S7, unofficial].

### Formulas and Steps
#### 1. Photometric and Rendering Losses
The primary term measures the difference between rendered and ground truth images [S1, S3, S4][S7, unofficial].
*   **L1 + Perceptual/SSIM:** $\mathcal{L}_{render}(\hat{I}, I) = \mathcal{L}_1(\hat{I}, I) + \lambda \cdot \mathcal{L}_{percept}(\hat{I}, I)$, where $\mathcal{L}_{percept}$ measures distance in VGG feature space [S4].
*   **L1 + D-SSIM:** $\mathcal{L}_{render}(I, I_{gt}) = \lambda_{L1}\mathcal{L}_1(I, I_{gt}) + \lambda_{ssim}\mathcal{L}_{ssim}(I, I_{gt})$ [S7, unofficial].
*   **L1 + SSIM (Weighted Sum):** $L_{ren}$ is the weighted sum of L1 and SSIM loss [S3].
*   **MSE (Volume):** $\mathcal{L}_{volume}(V, V_{gt}) = \sum_{x,y,z} (V(x, y, z) - V_{gt}(x, y, z))^2$ [S7, unofficial].
*   **Photometric (PDRF):** $\mathcal{L}_{photo} = \| \hat{C}^* - \tilde{C} \|_2^2 + \| \hat{C} - \tilde{C} \|_2^2$ for coarse and fine renderers [S1].

#### 2. Geometric and Regularization Losses
*   **Depth Smoothness:** $\mathcal{L}_{smooth}(I, \hat{D}) = |\partial_x \hat{D}| e^{-|\partial_x I|} + |\partial_y \hat{D}| e^{-|\partial_y I|}$, encouraging depth gradients to align with image gradients [S4].
*   **Total Variation (TV):** Applied to explicit feature volumes to enforce smoothness [S1].
*   **Self-Supervised Depth:** $\mathcal{L}_{self-depth}$ [S2].
*   **Gaussian Point Constraint (GPC):** Uses a Gaussian kernel function to measure distance between inter-frame point clouds, reducing sensitivity to depth noise compared to Chamfer distance [S2].
*   **Reprojection Loss:** $\mathcal{L}_{reproj}$ [S2].
*   **Codebook Losses (3DGS):** For rotation $\tilde{r}$ and scale $\tilde{s}$, using stop-gradient ($sg$) and codebook $Z$: $L_r = \sum_{n=1}^N \| sg[\tilde{r}_n - \hat{r}_{n}^{k-1}] - Z^k[i_n^k] \|_2^2$ [S3].

#### 3. Loss Masking
To prevent background pixels from contributing to the loss:
1. Identify pixels where mask $M = -1$ (background) [S6].
2. Multiply loss terms (normals, ambient occlusion, color) by $M$ (or a binary version) so masked pixels contribute 0 [S6].

#### 4. Multi-Stage Training Objectives
*   **Stage 1 (Initial Reconstruction):** $L_{1st} = \sum_{v=1}^V \mathcal{L}_{render}(\hat{I}_v, I_v) + \alpha \cdot \sum_{i=1}^N \mathcal{L}_{smooth}(I_i, \hat{D}_i)$ [S4].
*   **Stage 2 (Recurrent/End-to-End):** Freeze initial model. Train recurrent model with exponentially weighted rendering loss: $L_{2nd} = \sum_{t=0}^{T-1} \gamma^{T-1-t} \sum_{v=1}^V \mathcal{L}_{render}(\hat{I}_v^t, I_v)$ [S4].
*   **Compact 3DGS Total Loss:** $L = L_{ren} + \lambda_m L_m + L_r + L_s$, where $L_m$ is masking loss, $L_r$ is rotation codebook loss, $L_s$ is scale codebook loss [S3].
*   **TD-NeRF Total Loss:** $L = L_{rgb} + \lambda_1 L_{self-depth} + \lambda_2 L_{GPC} + \lambda_3 L_{reproj}$ [S2].
*   **PDRF Total Loss:** $L_{tot} = L_{CRR\_photo} + L_{FVR\_photo} + \lambda(L_{TV\_coar} + L_{TV\_fine})$ [S1].
*   **Semantic Field Training:** Stage I uses $L_{Total} = L_{color} + L_{feat} + L_{dino} + L_{RSR}$ for $T$ iterations. Stage II replaces $L_{RSR}$ with $L_{CSE}$ for cross-view semantic enhancement [S5].

### Parameters and Typical Values
*   $\alpha$ (Depth smoothness weight): 0.01 [S4].
*   $\lambda$ (Perceptual weight): 0.5 [S4].
*   $\lambda_m$ (Masking regularization): Hyperparameter to regularize the number of Gaussians [S3].
*   $\lambda_1, \lambda_2, \lambda_3$ (TD-NeRF weights): 0.04, 1.0, 1.0 [S2].
*   $\gamma$ (Exponential decay for recurrent steps): 0.9 [S4].
*   $\lambda_{L1}, \lambda_{ssim}$: Weights for L1 and SSIM [S7, unofficial].
*   Batch size: 1024 rays [S1].
*   Gamma correction: 2.2 (camera response function) [S1].
*   Sub-volume sampling factor: 1/4 in each dimension [S7, unofficial].
*   Codebook training duration: Last 1K iterations with K-means initialization; $L_r, L_s$ set to zero otherwise [S3].
*   Semantic field iterations $T$: 10,000 [S5].

### Edge Cases and Pitfalls
*   **Background Matching:** Without loss masking, the network must match default ground truth values in empty regions, complicating training [S6].
*   **Memory Constraints:** Rendering with full volume resolution ($256^3$) requires exhaustive GPU memory for gradients [S7, unofficial].
*   **Codebook Training Cost:** R-VQ and codebook learning are computationally heavy [S3].
*   **Chamfer Sensitivity:** Standard Chamfer distance for point cloud constraints is sensitive to depth noise [S2].

## Subtopics

### Loss Masking
A technique to modulate loss terms for normals, ambient occlusion, and colors with the output mask [S6]. Pixels where the mask $M$ is -1 (background) are excluded from the loss calculation [S6]. This simplifies the network's task by preventing it from trying to match default background values in empty regions [S6].

### X-GRM Training Objectives
Specific to X-ray Gaussian Reconstruction Models [S7, unofficial]. Uses volume MSE loss and rendering L1+SSIM loss [S7, unofficial]. To manage GPU memory, sub-volumes of size $M/4 \times N/4 \times K/4$ are randomly sampled from the original volume $V$ during training, while the full volume is used at inference [S7, unofficial].

## Operating characteristics
*   **Complexity:** Training is memory-intensive, particularly for explicit volumes or large Gaussian counts. Sub-volume sampling reduces memory usage by a factor of 64 ($4^3$) [S7, unofficial].
*   **Scalability:** Codebook-based approaches (e.g., Compact 3DGS) reduce parameter count (48 params for SH vs 59) but add complexity to the loss function [S3].
*   **Strengths:** Combines photometric accuracy with geometric priors (depth, smoothness) for robust reconstruction [S1, S2, S4].
*   **Limitations:** Requires careful tuning of multiple hyperparameters ($\lambda$ weights). Some terms (like codebook losses) are computationally expensive and may need to be disabled for most of training [S3].

## Background
The concept of composite training losses in radiance fields evolved from early NeRF works combining L1 and SSIM [S1, S3] to more complex multi-stage and multi-modal objectives.
*   **PDRF:** Introduced progressive deblurring with coarse/fine photometric losses and TV regularization [S1].
*   **TD-NeRF:** Added depth priors and Gaussian point constraints for joint pose and field optimization [S2].
*   **Compact 3DGS:** Adapted 3DGS with codebook regularization for compact representation [S3].
*   **ReSplat:** Introduced two-stage training with recurrent updates and depth smoothness [S4].
*   **X-GRM:** Applied volume and rendering losses to sparse-view X-ray CT reconstruction [S7, unofficial].
*   **Volumetric Isosurface:** Introduced loss masking for deep learning-based super-resolution [S6].
