# DMF Training Losses
Also called: DMF Losses, DMF Regularization Terms

## Overview
DMF Training Losses constitute the optimization objective for training Deep Medial Fields, an implicit neural representation that encodes both signed distance functions (SDF) and local thickness (medial fields) for 3D geometry [S1, unofficial]. The method solves the problem of jointly reconstructing surface geometry and thickness properties from sparse or single-view inputs by combining surface supervision, volume regularization, and gradient consistency constraints. It distinguishes itself from standard SDF optimization by explicitly including a curvature regularizer and a gradient prediction head to accelerate medial sphere tracing, while using specific regularizers to prevent Fourier feature interference with the implicit SDF training [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A ground-truth surface mesh (for sampling) and a neural network $\Phi$ parameterized by weights $\theta$. The network outputs SDF values and, optionally, predicted gradients for acceleration.
*   **Output:** Optimized network parameters $\theta$ that minimize the total loss.

**Data Structures:**
*   **Surface Samples ($x \sim \partial O$):** Points sampled uniformly from the input mesh surface.
*   **Volume Samples ($x \sim \mathbb{R}^d$):** Points sampled in the volume, generated by augmenting surface samples with isotropic Gaussian offsets.
*   **Ground-Truth Normals ($\nabla\Phi_{GT}(x)$):** Triangle normals from the input mesh, used as supervisory signals for surface points.

**Formulas:**
The total loss is a weighted sum of seven components. Let $x$ denote a sample point.

1.  **Surface Reconstruction Loss ($L_{surface}$):**
    $$L_{surface} = \mathbb{E}_{x \sim \partial O} [\Phi(x)^2]$$
    Supervises the SDF to be zero at the ground-truth surface [S1, unofficial].

2.  **Normal Reconstruction Loss ($L_{normal}$):**
    $$L_{normal} = \mathbb{E}_{x \sim \partial O} [(\nabla\Phi(x) - \nabla\Phi_{GT}(x))^2]$$
    Ensures the predicted gradient aligns with the mesh normals [S1, unofficial].

3.  **Eikonal Loss ($L_{Eikonal}$):**
    $$L_{Eikonal} = \mathbb{E}_{x \sim \mathbb{R}^d} [(||\nabla\Phi(x)|| - 1)^2]$$
    Enforces the Eikonal equation $||\nabla\Phi|| = 1$ in the volume [S1, unofficial].

4.  **Min-Surface Regularizer ($L_{minsurface}$):**
    $$L_{minsurface} = \mathbb{E}_{x \sim \mathbb{R}^d} [e^{-100 |\Phi(x)|}]$$
    Prevents Fourier features from interfering with implicit SDF training by penalizing non-zero SDF values in the volume [S1, unofficial].

5.  **Curvature Regularizer ($L_{curvature}$):**
    $$L_{curvature} = \mathbb{E}_{x \sim \mathbb{R}^d} \left[ \frac{\partial}{\partial t} \nabla\Phi(x + t\nabla\Phi(x)) \right]$$
    Regularizes the curvature of the SDF field, scheduled during training [S1, unofficial].

6.  **Gradient Consistency Loss ($L_{gradient}$):**
    $$L_{gradient} = \mathbb{E}_{x \sim \mathbb{R}^d} [||\nabla\Phi(x) - \nabla_{analytic}\Phi(x)||^2]$$
    Constrains a predicted gradient head to match the analytic gradient computed via back-propagation, speeding up medial sphere tracing [S1, unofficial].

**Sampling Strategy:**
1.  **Surface Batches:** Sample points uniformly over the input surface mesh. Use triangle normals to provide $\nabla\Phi_{GT}(x)$.
2.  **Volume Batches:** Augment surface samples with an offset from an isotropic Gaussian distribution where $\sigma$ is equal to half the bounding box diagonal.

**Pseudocode:**
```python
def compute_dmf_loss(network, mesh, batch_size=2**13):
    """
    Computes the DMF training loss for a batch of samples.
    network: Neural network instance with forward() and gradient() methods.
    mesh: Input mesh object providing surface sampling and normals.
    """
    # 1. Sample surface points uniformly from the input mesh
    surface_points = mesh.sample_uniform(batch_size // 2)
    
    # 2. Get ground-truth normals from mesh triangles
    gt_normals = mesh.get_normals(surface_points)
    
    # 3. Augment surface samples with isotropic Gaussian offset for volume
    # sigma = bounding_box_diagonal / 2
    sigma = mesh.bounding_box_diagonal / 2
    noise = torch.randn_like(surface_points) * sigma
    volume_points = surface_points + noise
    
    # Combine for batch processing if needed, or process separately
    all_points = torch.cat([surface_points, volume_points], dim=0)
    
    # 4. Forward pass to get SDF values
    sdf_values = network.forward(all_points)
    
    # 5. Compute gradients via back-propagation (analytic)
    # Note: Requires autograd setup in the calling context
    sdf_values.sum().backward()
    grad_analytic = all_points.grad
    
    # 6. Compute Losses
    
    # Surface Loss: L_surface = E[Phi(x)^2] for x in surface
    surface_sdf = sdf_values[:len(surface_points)]
    l_surface = torch.mean(surface_sdf ** 2)
    
    # Normal Loss: L_normal = E[(grad - grad_GT)^2] for x in surface
    surface_grad = grad_analytic[:len(surface_points)]
    l_normal = torch.mean((surface_grad - gt_normals) ** 2)
    
    # Eikonal Loss: L_Eikonal = E[(||grad|| - 1)^2] for x in volume
    volume_grad = grad_analytic[len(surface_points):]
    l_eikonal = torch.mean((torch.norm(volume_grad, dim=1) - 1) ** 2)
    
    # Min-Surface Regularizer: L_min_surface = E[exp(-100 * |Phi(x)|)] for x in volume
    volume_sdf = sdf_values[len(surface_points):]
    l_min_surface = torch.mean(torch.exp(-100 * torch.abs(volume_sdf)))
    
    # Curvature Regularizer: L_curvature = E[d/dt grad(x + t*grad(x))]
    # Approximated numerically or via higher-order derivatives.
    # Source defines it as the derivative of the gradient along the gradient direction.
    # Implementation detail: Not fully specified in source [G].
    # Placeholder for curvature computation.
    l_curvature = 0.0 
    
    # Gradient Consistency Loss: L_gradient = E[||grad_pred - grad_analytic||^2]
    # Assumes network has a separate head for predicted gradient.
    # If no separate head, this term is 0 or not applicable [G].
    l_gradient = 0.0
    
    # 7. Weighted Sum
    # Weights are empirically determined hyperparameters [S1, unofficial]
    total_loss = (l_surface + l_normal + l_eikonal + 
                  l_min_surface + l_curvature + l_gradient)
    
    return total_loss
```

**Parameters:**
*   **Optimizer:** Adam with default parameters [S1, unofficial].
*   **Batch Size:** $2^{13}$ [S1, unofficial].
*   **Training Iterations:** 500k–900k per run [S1, unofficial].
*   **Training Time:** Average 6 hours per model [S1, unofficial].
*   **Gaussian Offset $\sigma$:** Half the bounding box diagonal [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Fourier Feature Interference:** Without $L_{minsurface}$, Fourier features may interfere with implicit SDF training [S1, unofficial].
*   **Gradient Prediction:** The $L_{gradient}$ term assumes a specific network architecture with a gradient prediction head. If this head is absent, the term is undefined [G].
*   **Curvature Computation:** The exact numerical implementation of the derivative in $L_{curvature}$ is not detailed in the source [G].

## Operating characteristics
*   **Time Complexity:** Training requires 500k–900k iterations, taking approximately 6 hours per model on unspecified hardware [S1, unofficial].
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Improves convergence for sphere tracing, provides efficient ambient occlusion, and enables physics proxies via medial fields [S1, unofficial]. The gradient consistency loss speeds up execution of medial sphere tracing [S1, unofficial].
*   **Limitations:** The method relies on a ground-truth mesh for surface sampling and normal supervision, limiting its use in purely unstructured settings without mesh input [S1, unofficial].
*   **When to use:** When reconstructing geometry with explicit thickness information (medial fields) is required, and a ground-truth mesh is available for supervision.
*   **When not to use:** When only appearance or standard SDF reconstruction is needed without thickness properties, or when no ground-truth mesh is available for surface sampling.

## Background
The DMF Training Losses were introduced in the paper "Deep Medial Fields" [S1, unofficial]. The work expands the capacity of implicit representations by storing medial fields (local thickness) within neural network parameters, enabling O(1) access and efficient computation. It builds on prior work in implicit SDF representations and Eikonal regularization [Gropp et al. 2020, cited in S1, unofficial]. The method is used for applications including improved sphere tracing convergence, ambient occlusion, and physics proxies [S1, unofficial].
