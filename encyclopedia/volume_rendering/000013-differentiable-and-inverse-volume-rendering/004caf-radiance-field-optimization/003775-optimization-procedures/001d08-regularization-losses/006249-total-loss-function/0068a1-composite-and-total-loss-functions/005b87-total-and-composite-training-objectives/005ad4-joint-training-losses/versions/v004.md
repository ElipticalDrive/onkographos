# Joint Training Losses

Also called: Composite Loss with Pose, Skin, and INN Constraints

## Overview
This method defines a composite objective function for the joint optimization of a Template-Free NeRF (TFS-NeRF), an Implicit Neural Network (INN) for spatial transformation, and a skinning weight prediction network. It solves the ambiguity in deforming canonical points to view space by simultaneously enforcing photometric reconstruction, geometric consistency, and physical plausibility of skinning weights. It distinguishes itself from standard NeRF optimization by explicitly constraining the INN and skinning networks through pose, cycle, and skinning-specific losses, rather than relying solely on image reconstruction [S1].

## How it works
The method optimizes three coupled components: the NeRF for volume rendering, the INN for mapping between view and canonical spaces, and a skinning weight predictor. The total loss is the weighted sum of five terms: reconstruction, pose, skinning weight, cycle consistency, and geometric consistency [S1].

**Inputs:**
*   Input images and camera poses.
*   Canonical skeleton joints $J_{p0}$ and posed skeleton joints $J_p$.
*   Points sampled around bones in canonical space $X_{J_{p0}}$ and deformed space $X_{J_p}$ [S1].

**Outputs:**
*   Rendered RGB $\hat{C}(r)$ and density $\alpha$ for rays $r$.
*   Transformed points $x'_c$ and canonical points $x_c$.
*   Predicted skinning weights $\hat{w}$ [S1].

**Data Structures:**
*   $H(\cdot, J_p)$: INN function mapping canonical points to deformed space conditioned by pose $J_p$.
*   $H^{-1}(\cdot, J_{p0})$: INN inverse function mapping view points to canonical space conditioned by canonical pose $J_{p0}$ [S1].
*   $G_{x_c \to w}(J_{p0})$: Skinning weight prediction network outputting weights for canonical joints [S1].

**Formulas:**
1.  **Reconstruction Loss ($L_{rgb}$):** Minimizes the difference between rendered and input RGB.
    $$ L_{rgb} = \sum_{r \in R} ||\hat{C}(r) - C(r)|| $$
    Where $R$ is the set of rays, $\hat{C}(r)$ is the rendered color, and $C(r)$ is the input pixel color [S1].

2.  **Pose Loss ($L_{pose}$):** Ensures the INN correctly transforms deformed points to canonical points.
    $$ L_{pose} = \sum_{p \in P} ||X_{J_{p0}} - G_{v \to c}^{INN}(X_{J_p})|| $$
    Where $P$ is the total number of points sampled around bones, $X_{J_p}$ are points in deformed space, and $G_{v \to c}^{INN}$ is the INN transformation [S1]. Note: The source text labels this $L_{pose}$ but uses $G_{v \to c}^{INN}$ in the formula, while the summary notes label the INN transformation $H$. We treat $G_{v \to c}^{INN}$ as the INN mapping from view/deformed to canonical.

3.  **Skinning Weight Loss ($L_W$):** Constrains predicted skinning weights to be one-hot vectors.
    $$ L_W = ||G_{x_c \to w}(J_{p0}) - \hat{w}||_2^2 $$
    Where $\hat{w}$ is the target one-hot vector (1 for the respective joint, 0 for others) [S1].

4.  **Cycle Consistency Loss ($L_{INN}$):** Ensures invertibility of the INN transformation.
    $$ L_{INN} = ||H(H^{-1}(x_v, J_{p0}), J_p) - x_v||_2^2 $$
    Where $x_v$ is a point in view space, $H^{-1}$ maps view to canonical, and $H$ maps canonical to deformed [S1].

5.  **Consistency Loss ($L_{Consis}$):** Minimizes distance between INN-transformed points and skinning-weight-conditioned points.
    $$ L_{Consis} = ||x'_c - x_c||_2^2 $$
    Where $x'_c$ is the point transformed by INN and $x_c$ is the point conditioned by skinning weights [S1].

**Total Loss:**
$$ L_{tot} = \lambda_{rgb} L_{rgb} + \lambda_{pose} L_{pose} + \lambda_W L_W + \lambda_{INN} L_{INN} + \lambda_{Consis} L_{Consis} $$
Weights $\lambda_k$ are hyperparameters [S1].

**Pseudocode:**
```python
def compute_joint_loss(rendered_rgb, input_rgb, inn_model, skinning_net, 
                       canonical_joints, posed_joints, points_deformed, points_canonical):
    """
    Computes the joint training loss for TFS-NeRF.
    """
    # 1. Reconstruction Loss
    # L_rgb = sum(||C_hat(r) - C(r)||)
    loss_rgb = sum(abs(rendered_rgb - input_rgb))

    # 2. Pose Loss
    # Transform deformed points to canonical using INN
    # G_v->c^INN(X_Jp)
    points_canonical_predicted = inn_model.transform_to_canonical(points_deformed, posed_joints)
    # L_pose = sum(||X_Jp0 - G_v->c^INN(X_Jp)||)
    loss_pose = sum(abs(points_canonical - points_canonical_predicted))

    # 3. Skinning Weight Loss
    # Predict weights for canonical joints
    # G_xc->w(J_p0)
    predicted_weights = skinning_net.predict_weights(canonical_joints)
    # Target is one-hot vector w_hat
    # L_W = ||G_xc->w(J_p0) - w_hat||_2^2
    loss_skinning = sum((predicted_weights - target_one_hot) ** 2)

    # 4. Cycle Consistency Loss
    # Transform view point x_v to canonical, then back to deformed
    # H(H^-1(x_v, J_p0), J_p)
    points_canonical_from_view = inn_model.transform_to_canonical(points_view, canonical_joints)
    points_deformed_from_canonical = inn_model.transform_to_deformed(points_canonical_from_view, posed_joints)
    # L_INN = ||H(H^-1(x_v, J_p0), J_p) - x_v||_2^2
    loss_cycle = sum((points_deformed_from_canonical - points_view) ** 2)

    # 5. Consistency Loss
    # Compare INN-transformed point x'_c and skinning-weight-conditioned point x_c
    # L_Consis = ||x'_c - x_c||_2^2
    # Note: x'_c and x_c definitions in source imply specific conditioning.
    # Assuming x'_c is INN output and x_c is skinning output for same canonical point.
    loss_consistency = sum((points_inn_transformed - points_skinning_conditioned) ** 2)

    # Total Loss
    total_loss = (lambda_rgb * loss_rgb + 
                  lambda_pose * loss_pose + 
                  lambda_W * loss_skinning + 
                  lambda_INN * loss_cycle + 
                  lambda_Consis * loss_consistency)
    
    return total_loss
```

## Operating characteristics
*   **Complexity:** Adds overhead of computing INN transformations and skinning weights for every training step, in addition to standard NeRF ray marching.
*   **Performance:** Requires sufficient supervision on skeleton space to prevent incorrect combinations of canonical points and skinning weights [S1].
*   **Strengths:** Resolves ambiguities in LBS by constraining skinning weights and INN jointly.
*   **Limitations:** Relies on accurate sampling of points around bones; sensitive to weight hyperparameters [S1].

## Background
Originated in TFS-NeRF (Template-Free NeRF for Semantic 3D Reconstruction of Dynamic Scene) [S1]. The method addresses the lack of direct supervision for skinning weight prediction and INN by introducing multiple geometric and consistency constraints [S1].
