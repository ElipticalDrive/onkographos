# ARAH Loss Function

Also called: ARAH Total Loss

## Overview
The ARAH loss function is the composite training objective for the ARAH (Animatable Volume Rendering of Articulated Human SDFs) model, designed to optimize a signed distance function (SDF) and color field for animatable human bodies [S1]. It distinguishes itself from standard NeRF losses by incorporating specific geometric constraints tailored to articulated meshes, including an off-surface point loss and an inside point loss that leverage the canonical SMPL mesh topology [S1]. Unlike general radiance field optimization, it explicitly penalizes SDF values in regions far from the surface and inside the body volume to enforce a valid SDF representation for animation [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   $P$: Set of all pixels sampled from a training image.
*   $I_p \in [0, 1]^3$: Ground-truth RGB value for pixel $p \in P$.
*   $\hat{\mathbf{x}}^{(p)}$: Canonical 3D position corresponding to pixel $p$.
*   $\mathbf{n}^{(p)}$: Surface normal at $\hat{\mathbf{x}}^{(p)}$.
*   $\mathbf{v}^{(p)}$: View direction at $\hat{\mathbf{x}}^{(p)}$.
*   $\mathbf{z}$: Local latent code.
*   $\mathcal{Z}$: Global latent code.
*   $\hat{\mathbf{X}}_{\text{eik}}$: Set of 1024 points sampled uniformly in the range $[-1, 1]^3$ in canonical space.
*   $\hat{\mathbf{X}}_{\text{off}}$: Set of 1024 points in canonical space whose Euclidean distance to the canonical SMPL mesh surface is greater than 20 cm.
*   $\hat{\mathbf{X}}_{\text{in}}$: Set of 1024 points in canonical space that are inside the canonical SMPL mesh and whose distance to the SMPL surface is greater than 1 cm.

**Outputs:**
*   $\mathcal{L}$: Scalar total loss value.

### Data Structures
The method relies on two neural network functions:
1.  $f_{\sigma_f}(\hat{\mathbf{x}})$: Predicts the signed distance value (SDF) at canonical position $\hat{\mathbf{x}}$.
2.  $f_{\sigma_c}(\hat{\mathbf{x}}, \mathbf{n}, \mathbf{v}, \mathbf{z}, \mathcal{Z})$: Predicts the RGB color value given canonical position, normal, view direction, and latent codes.

### Formulas
The total loss is a weighted sum of five terms [S1]:

$$
\mathcal{L} = \lambda_C \cdot \mathcal{L}_C + \lambda_E \cdot \mathcal{L}_E + \lambda_O \cdot \mathcal{L}_O + \lambda_I \cdot \mathcal{L}_I + \lambda_S \cdot \mathcal{L}_S
$$

Where:

1.  **RGB Color Loss ($\mathcal{L}_C$)**: Measures the difference between rendered and ground truth colors [S1].
    $$
    \mathcal{L}_C = \frac{1}{|P|} \sum_{p \in P} \left| f_{\sigma_c}(\hat{\mathbf{x}}^{(p)}, \mathbf{n}^{(p)}, \mathbf{v}^{(p)}, \mathbf{z}, \mathcal{Z}) - I_p \right|
    $$

2.  **Eikonal Regularization ($\mathcal{L}_E$)**: Enforces that the gradient of the SDF has unit norm [S1].
    $$
    \mathcal{L}_E = \frac{1}{|P|} \sum_{\hat{\mathbf{x}} \in \hat{\mathbf{X}}_{\text{eik}}} \left| \| \nabla_{\hat{\mathbf{x}}} f_{\sigma_f}(\hat{\mathbf{x}}) \|_2 - 1 \right|
    $$
    *Note: The source divides by $|P|$ rather than $|\hat{\mathbf{X}}_{\text{eik}}|$ in the summation normalization, which is preserved here as per the source text [S1].*

3.  **Off-surface Point Loss ($\mathcal{L}_O$)**: Penalizes points far from the surface to push SDF values towards positive infinity (outside) [S1].
    $$
    \mathcal{L}_O = \frac{1}{|P|} \sum_{\hat{\mathbf{x}} \in \hat{\mathbf{X}}_{\text{off}}} \exp \left (-1e2 \cdot f_{\sigma_f}(\hat{\mathbf{x}}) \right )
    $$

4.  **Inside Point Loss ($\mathcal{L}_I$)**: Penalizes points inside the mesh to push SDF values towards negative infinity (inside) [S1].
    $$
    \mathcal{L}_I = \frac{1}{|P|} \sum_{\hat{\mathbf{x}} \in \hat{\mathbf{X}}_{\text{in}}} \text{sigmoid} \left ( 5e3 \cdot f_{\sigma_f}(\hat{\mathbf{x}}) \right )
    $$

5.  **Skinning Loss ($\mathcal{L}_S$)**: Defined in the source but the specific formula is not provided in the excerpt [S1].

### Parameters
*   $\lambda_C, \lambda_E, \lambda_O, \lambda_I, \lambda_S$: Weighting coefficients for the respective loss terms. Typical values are not provided in the sources [S1].
*   $1e2$: Constant multiplier in $\mathcal{L}_O$ (100).
*   $5e3$: Constant multiplier in $\mathcal{L}_I$ (5000).

```python
def compute_arah_loss(
    pixels: List[Pixel],
    ground_truth_rgbs: Tensor,
    canonical_positions: Tensor,
    normals: Tensor,
    view_directions: Tensor,
    latent_codes: Tensor,
    global_latent_codes: Tensor,
    sdf_network: Network,
    color_network: Network,
    smpl_mesh: Mesh,
    lambda_c: float,
    lambda_e: float,
    lambda_o: float,
    lambda_i: float,
    lambda_s: float
) -> Tensor:
    """
    Computes the ARAH total loss.
    
    Args:
        pixels: List of pixel indices or objects.
        ground_truth_rgbs: Tensor of shape (N, 3) with values in [0, 1].
        canonical_positions: Tensor of shape (N, 3) for each pixel.
        normals: Tensor of shape (N, 3) for each pixel.
        view_directions: Tensor of shape (N, 3) for each pixel.
        latent_codes: Tensor of shape (N, D) local latents.
        global_latent_codes: Tensor of shape (N, D_g) global latents.
        sdf_network: Network predicting SDF values.
        color_network: Network predicting RGB values.
        smpl_mesh: Canonical SMPL mesh object for distance queries.
        lambda_c, lambda_e, lambda_o, lambda_i, lambda_s: Loss weights.
        
    Returns:
        Total loss scalar.
    """
    N = len(pixels)
    
    # 1. RGB Color Loss
    # Predict colors for all pixels
    # Inputs: canonical position, normal, view dir, latent, global latent
    predicted_rgbs = color_network(
        canonical_positions, 
        normals, 
        view_directions, 
        latent_codes, 
        global_latent_codes
    )
    
    # L_C = mean absolute error
    l_c = torch.mean(torch.abs(predicted_rgbs - ground_truth_rgbs))
    
    # 2. Eikonal Regularization
    # Sample 1024 points in [-1, 1]^3
    num_eik = 1024
    x_eik = torch.rand(num_eik, 3) * 2 - 1  # Uniform in [-1, 1]
    
    # Compute SDF gradient
    x_eik.requires_grad_(True)
    sdf_eik = sdf_network(x_eik)
    grad_eik = torch.autograd.grad(
        sdf_eik, x_eik, grad_outputs=torch.ones_like(sdf_eik), create_graph=True
    )[0]
    
    # L_E = mean(| ||grad|| - 1 |)
    # Note: Source divides by |P| (N), not num_eik
    l_e = torch.mean(torch.abs(torch.norm(grad_eik, dim=1) - 1.0)) / N * N # Simplified: just mean over eik points, then scaled? 
    # Correction based on source formula: sum / |P|. 
    # Since sum is over eik points, and divisor is |P|, we compute mean over eik points and divide by |P|? 
    # No, source: (1/|P|) * sum(...). 
    # Implementation: sum over eik points, then divide by N.
    l_e = torch.sum(torch.abs(torch.norm(grad_eik, dim=1) - 1.0)) / N
    
    # 3. Off-surface Point Loss
    # Sample 1024 points > 20cm from SMPL mesh
    # Note: Exact sampling method for X_off is not detailed, assumed to be provided or sampled via rejection
    num_off = 1024
    x_off = sample_points_far_from_mesh(smpl_mesh, num_off, min_dist=0.20) # 20cm = 0.20m? Source says 20cm. Units in SDF network unknown. Assuming consistent units.
    
    sdf_off = sdf_network(x_off)
    # L_O = (1/|P|) * sum(exp(-100 * sdf))
    l_o = torch.sum(torch.exp(-100.0 * sdf_off)) / N
    
    # 4. Inside Point Loss
    # Sample 1024 points inside mesh, > 1cm from surface
    num_in = 1024
    x_in = sample_points_inside_mesh(smpl_mesh, num_in, min_dist=0.01) # 1cm
    
    sdf_in = sdf_network(x_in)
    # L_I = (1/|P|) * sum(sigmoid(5000 * sdf))
    l_i = torch.sum(torch.sigmoid(5000.0 * sdf_in)) / N
    
    # 5. Skinning Loss
    # Formula not provided in source excerpt
    l_s = 0.0 # Placeholder [G]
    
    # Total Loss
    total_loss = (
        lambda_c * l_c +
        lambda_e * l_e +
        lambda_o * l_o +
        lambda_i * l_i +
        lambda_s * l_s
    )
    
    return total_loss
```

### Edge Cases and Pitfalls
*   **Sampling Constraints**: The sets $\hat{\mathbf{X}}_{\text{off}}$ and $\hat{\mathbf{X}}_{\text{in}}$ require distance queries to the canonical SMPL mesh. If the mesh topology changes or is invalid, these samples cannot be generated [S1].
*   **Normalization**: The source formulas divide the sums for $\mathcal{L}_E, \mathcal{L}_O, \mathcal{L}_I$ by $|P|$ (number of pixels) rather than the number of sampled points (1024). This implies the magnitude of these geometric losses scales with the image resolution, which is non-standard for regularization terms [S1].
*   **Units**: The distance thresholds (20cm, 1cm) and constants (1e2, 5e3) assume a specific unit system for the SDF network. If the canonical space is normalized to $[-1, 1]^3$, these physical distances must be converted to canonical units [S1].

## Subtopics

### Inside Point Loss
A regularization term that penalizes SDF values for points inside the canonical SMPL mesh to ensure they are negative and large in magnitude. It uses a sigmoid function scaled by 5000. It is chosen when a tight, watertight volume is required for the human body [S1].

### Off-surface Point Loss
A regularization term that penalizes SDF values for points far from the surface (outside the mesh) to ensure they are positive and large in magnitude. It uses an exponential decay function scaled by 100. It is chosen to prevent the SDF from being zero or negative far from the surface [S1].

### Eikonal Regularization
A standard SDF regularization term enforcing that the gradient of the SDF has unit norm everywhere. It is sampled in the canonical bounding box $[-1, 1]^3$. It is chosen to ensure the SDF represents a valid distance function [S1].

## Operating characteristics

*   **Time Complexity**: Dominated by the forward passes of the SDF and color networks for all pixels and sampled points. The gradient computation for the Eikonal loss adds a backward pass through the SDF network for the 1024 eikonal points.
*   **Memory Complexity**: Requires storing the SDF and color network parameters, plus intermediate activations for the 1024 eikonal, off-surface, and inside points.
*   **Strengths**: Explicitly handles the geometry of articulated humans using the SMPL mesh, leading to better surface reconstruction and animatability compared to generic NeRF losses.
*   **Limitations**: Relies on the availability of a canonical SMPL mesh and its topology. The specific weighting coefficients ($\lambda$) are not provided, requiring empirical tuning. The normalization by $|P|$ for geometric losses may make them sensitive to image resolution.
*   **When to use**: When training an animatable human model using volume rendering of SDFs where surface accuracy and valid SDF properties are critical.
*   **When not to use**: For static objects without articulated structure, or when computational resources are extremely limited and the overhead of sampling and computing geometric losses is prohibitive.

## Background

The ARAH loss function was introduced in the ARAH (Animatable Volume Rendering of Articulated Human SDFs) paper by Wang et al. (2022) [S1]. It builds upon differentiable volume rendering and signed distance function representations for human avatars. The method integrates concepts from Eikonal regularization [S1] and specific geometric constraints derived from the SMPL human body model. It is used in the context of self-supervised 3D human mesh recovery and animatable avatar creation from images [S1].
