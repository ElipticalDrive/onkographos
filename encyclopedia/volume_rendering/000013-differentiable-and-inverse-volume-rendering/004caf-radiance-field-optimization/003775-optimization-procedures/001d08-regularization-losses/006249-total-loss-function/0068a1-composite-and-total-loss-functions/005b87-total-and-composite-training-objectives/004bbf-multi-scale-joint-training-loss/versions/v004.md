# Multi-scale Joint Training Loss

Also called: Coarse-Fine Joint Loss, Joint Loss, Multi-scale Joint Loss

## Overview
The Multi-scale Joint Training Loss is a composite objective function used in differentiable volume rendering and radiance field optimization to balance low-frequency structural consistency with high-frequency detail fidelity. It addresses the problem of refining neural representations by preventing the loss of global appearance during the enhancement of fine textures. It is distinguished from single-scale losses by explicitly weighting contributions from multiple resolution stages or network depths, ensuring that uncertainty and error are minimized across the entire hierarchy of the model [S1, S2].

## How it works
The method aggregates loss terms from multiple network stages or resolution levels. Two primary formulations exist in the literature, depending on whether the approach involves dynamic network growth or coarse-to-fine refinement.

### Inputs and Outputs
*   **Inputs:**
    *   $\theta$: Network parameters.
    *   $D$: The current number of stages or layers in the network [S1].
    *   $I$: Iteration count (used in dynamic growth contexts) [S1].
    *   $\alpha$: Weighting factor for coarse vs. fine components, where $\alpha \in [0, 1]$ [S2].
    *   $\beta_1, \beta_2$: Weights for MSE and uncertainty components [S1].
*   **Outputs:**
    *   Scalar loss value $L(\theta)$ or $\mathcal{L}$ used for gradient backpropagation.

### Data Structures
No specific complex data structures are required beyond standard tensors for rendered images and ground truth. However, the method requires storing intermediate outputs from all network stages/layers during the forward pass to compute stage-specific losses [S1].

### Formulas and Steps

#### Formulation 1: Dynamic Growth (Recursive-NeRF)
Used when the network grows dynamically. All query coordinates are passed through all outlets (stages) during training.

$$ \mathcal{L} = \sum_{i=1}^D \left( \beta_1 \mathcal{L}_{MSE}^i + \beta_2 \mathcal{L}_{unct}^i \right) $$

Where:
*   $D$ is the current number of stages (also equal to $D-1$ times the network growth) [S1].
*   $\mathcal{L}_{MSE}^i$ is the Mean Squared Error loss of the output image from layer $i$ [S1].
*   $\mathcal{L}_{unct}^i$ is the uncertainty loss of the output image from layer $i$ [S1].
*   $\beta_1 = 1.0$ and $\beta_2 = 0.1$ are typical default weights [S1].

#### Formulation 2: Coarse-Fine Refinement (Denoise-GS)
Used in second-round training to refine denoised images.

$$ L(\theta) = \alpha L_{coarse}(\theta) + (1-\alpha) L_{fine}(\theta) $$

Where:
*   $L_{coarse}(\theta)$: Low-frequency consistency term. Compares input and output after smoothing to preserve tone and large-scale structure [S2].
*   $L_{fine}(\theta)$: Detail consistency term. Composed of:
    *   Pixel-level robust distance (suppresses outlier noise) [S2].
    *   Structural Similarity (SSIM) term (aligns textures and contours) [S2].
    *   Gradient consistency term (matches edge direction and strength) [S2].
    *   Chroma consistency term (reduces color shifts) [S2].
*   $\alpha \in [0, 1]$ balances the two terms [S2].

### Pseudocode
The following Python-like pseudocode implements the aggregation logic for the dynamic growth variant, which is the more explicitly defined multi-scale summation. The coarse-fine variant is a specific case of weighted combination.

```python
def compute_multi_scale_joint_loss(rendered_images, ground_truth_images, uncertainties, beta1=1.0, beta2=0.1):
    """
    Computes the multi-scale joint training loss.
    
    Args:
        rendered_images: List of tensors, one for each stage i=1..D.
        ground_truth_images: List of tensors, one for each stage i=1..D.
        uncertainties: List of tensors, one for each stage i=1..D.
        beta1: Weight for MSE loss.
        beta2: Weight for uncertainty loss.
        
    Returns:
        Total scalar loss.
    """
    total_loss = 0.0
    num_stages = len(rendered_images)
    
    for i in range(num_stages):
        # Compute MSE loss for stage i
        # Assuming standard pixel-wise MSE
        mse_loss = torch.mean((rendered_images[i] - ground_truth_images[i]) ** 2)
        
        # Compute uncertainty loss for stage i
        # Note: Exact definition of L_unct depends on the specific uncertainty model.
        # Commonly involves KL divergence or variance-based terms.
        # If not provided, this step requires implementation of the specific uncertainty metric.
        unct_loss = compute_uncertainty_loss(rendered_images[i], uncertainties[i])
        
        # Aggregate weighted losses for this stage
        stage_loss = beta1 * mse_loss + beta2 * unct_loss
        total_loss += stage_loss
        
    return total_loss
```

### Parameters and Edge Cases
*   **$\beta_1, \beta_2$**: Set to 1.0 and 0.1 respectively in the cited source [S1].
*   **$\alpha$**: Any value in $[0, 1]$ [S2].
*   **Edge Cases**:
    *   **Empty Regions**: Masking is often applied to prevent background pixels from contributing to the gradient, as empty regions lack ground truth [Parent].
    *   **Precision**: High-frequency terms (gradients, SSIM) can be sensitive to numerical precision; robust distance metrics are used to suppress outlier noise [S2].
    *   **Degenerate Input**: If $D=1$, the summation reduces to a single stage loss.

## Operating characteristics
*   **Time Complexity**: $O(D \cdot N)$, where $D$ is the number of stages and $N$ is the number of pixels/queries. All stages must be evaluated during training [S1].
*   **Memory Complexity**: $O(D \cdot N)$ to store intermediate outputs from all stages for backpropagation [S1].
*   **Strengths**: Preserves global structure while enhancing details; robust to noise via uncertainty and robust distance terms [S1, S2].
*   **Limitations**: Increased memory usage due to storing intermediate stage outputs; requires careful tuning of $\alpha, \beta_1, \beta_2$ [S1, S2].
*   **When to Use**: When refining a coarse representation or when using dynamically growing networks where multiple resolutions are available [S1, S2].

## Background
The concept originates from two distinct lines of work in neural rendering. The multi-stage summation formulation was introduced in **Recursive-NeRF** (2022) by [S1], which proposed a dynamically growing network architecture. The coarse-fine joint loss formulation was introduced in **Denoise-GS** (2026) by [S2], focusing on self-supervised denoising for sparse-view 3D Gaussian Splatting. Both methods address the trade-off between structural fidelity and detail reconstruction in inverse volume rendering.
