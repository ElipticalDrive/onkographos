# Multi-scale Joint Training Loss

Also called: Coarse-Fine Joint Loss, Joint Loss, Multi-scale Joint Loss

## Overview
Multi-scale Joint Training Loss is a composite objective function used in differentiable volume rendering to balance low-frequency structural consistency with high-frequency detail fidelity during optimization [S2]. It addresses the problem of refining rendered images by preventing global appearance damage while enhancing texture sharpness [S2]. It differs from single-scale losses by explicitly weighting contributions from multiple network stages or resolution levels [S1], and from simple photometric losses by incorporating uncertainty and multi-scale aggregation [S1].

## How it works
The method aggregates loss terms from multiple output stages or scales. Two distinct formulations exist in the literature for this concept: one based on a coarse-fine balance for refinement [S2], and another based on multi-stage uncertainty-weighted aggregation [S1].

### Inputs and Outputs
*   **Inputs:** Model parameters $\theta$, input images (or reference views), and query coordinates.
*   **Outputs:** A scalar loss value $L(\theta)$ or $\mathcal{L}$ used for gradient backpropagation.

### Data Structures
*   **Stages/Layers:** A set of $D$ output stages or network layers.
*   **Loss Components:** Per-stage Mean Squared Error ($\mathcal{L}_{MSE}$) and uncertainty loss ($\mathcal{L}_{unct}$) [S1].
*   **Weights:** Scalar coefficients $\alpha, \beta_1, \beta_2$ [S1, S2].

### Formulas and Steps

**Formulation 1: Coarse-Fine Balance [S2]**
Used in the second round of training to refine denoised inputs.
$$ L(\theta) = \alpha L_{coarse}(\theta) + (1-\alpha) L_{fine}(\theta) $$
Where:
*   $\alpha \in [0, 1]$ is the balance weight.
*   $L_{coarse}(\theta)$: Low-frequency consistency term. Compares input and output after smoothing to preserve tone and large-scale structure [S2].
*   $L_{fine}(\theta)$: Detail consistency term. Composed of pixel-level robust distance, structural similarity, gradient consistency, and chroma consistency [S2].

**Formulation 2: Multi-Stage Uncertainty Weighted [S1]**
Used in Recursive-NeRF for dynamic growth.
$$ \mathcal{L} = \sum_{i=1}^D \left( \beta_1 \mathcal{L}_{MSE}^i + \beta_2 \mathcal{L}_{unct}^i \right) $$
Where:
*   $D$ is the current number of stages (also equal to $D-1$ times the network growth count) [S1].
*   $\mathcal{L}_{MSE}^i$: MSE loss of the output image of layer $i$ [S1].
*   $\mathcal{L}_{unct}^i$: Uncertainty loss of the output image of layer $i$ [S1].
*   $\beta_1 = 1.0$ and $\beta_2 = 0.1$ are typical weights [S1].
*   All query coordinates are output through all outlets during training [S1].

### Pseudocode
The following pseudocode implements the Multi-Stage Uncertainty Weighted loss [S1], as it provides a complete algorithmic structure. The Coarse-Fine formulation [S2] requires specific definitions of $L_{coarse}$ and $L_{fine}$ components not fully detailed in the source notes.

```python
def multi_scale_joint_loss_stages(predictions, targets, uncertainties, num_stages, beta1=1.0, beta2=0.1):
    """
    Computes the multi-scale joint training loss for Recursive-NeRF.
    
    Args:
        predictions: List of rendered images for each stage i=1..D.
        targets: List of target/reference images for each stage i=1..D.
        uncertainties: List of uncertainty maps for each stage i=1..D.
        num_stages: D, the current number of stages.
        beta1: Weight for MSE loss.
        beta2: Weight for uncertainty loss.
        
    Returns:
        Total scalar loss.
    """
    total_loss = 0.0
    
    for i in range(1, num_stages + 1):
        # Calculate MSE loss for stage i
        # L_MSE^i = mean((predictions[i] - targets[i])^2)
        mse_loss_i = mean_squared_error(predictions[i-1], targets[i-1])
        
        # Calculate uncertainty loss for stage i
        # L_unct^i is derived from the uncertainty map of layer i
        # [G] Standard uncertainty loss often involves log-variance or similar;
        # exact formula for L_unct is not specified in sources, assumed available.
        unct_loss_i = compute_uncertainty_loss(uncertainties[i-1])
        
        # Aggregate weighted losses for this stage
        stage_loss = beta1 * mse_loss_i + beta2 * unct_loss_i
        total_loss += stage_loss
        
    return total_loss

def mean_squared_error(pred, target):
    return mean((pred - target) ** 2)

def compute_uncertainty_loss(uncertainty_map):
    # Placeholder for specific uncertainty loss definition
    # [G] Implementation depends on whether uncertainty is variance or standard deviation
    return mean(uncertainty_map)
```

### Parameters
*   $\alpha$: Balance between coarse and fine terms. Range $[0, 1]$ [S2].
*   $\beta_1$: MSE weight. Typical value $1.0$ [S1].
*   $\beta_2$: Uncertainty weight. Typical value $0.1$ [S1].

### Edge Cases and Pitfalls
*   **Precision:** Summing losses across $D$ stages can lead to gradient magnitude issues if $D$ is large; normalization may be required [S1].
*   **Boundaries:** Query coordinates must be valid for all outlets/stages [S1].
*   **Degenerate Input:** If uncertainty is zero or undefined, the uncertainty loss term may fail [S1].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of stages $D$ [S1].
*   **Memory Complexity:** Requires storing predictions and uncertainties for all $D$ stages simultaneously during the forward pass [S1].
*   **Strengths:** Balances structural integrity with detail recovery [S2]; adapts to dynamic network growth [S1].
*   **Limitations:** Requires careful tuning of $\alpha, \beta_1, \beta_2$ [S1, S2]; increased memory usage with more stages [S1].
*   **When to use:** When refining rendered images or training dynamically growing neural radiance fields [S1, S2].

## Background
The concept originates from two distinct lines of research. The Coarse-Fine Joint Loss was introduced in Denoise-GS for self-supervised denoising in sparse-view 3D Gaussian Splatting [S2]. The Multi-Stage Uncertainty Weighted loss was introduced in Recursive-NeRF for efficient, dynamically growing neural radiance fields [S1].
