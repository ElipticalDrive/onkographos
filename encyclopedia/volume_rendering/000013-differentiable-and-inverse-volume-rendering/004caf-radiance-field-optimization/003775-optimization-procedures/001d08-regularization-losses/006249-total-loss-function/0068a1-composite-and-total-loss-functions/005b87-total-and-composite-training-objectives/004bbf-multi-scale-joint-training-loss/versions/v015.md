# Multi-scale Joint Training Loss

Also called: Coarse-Fine Joint Loss, Joint Loss, Multi-scale Joint Loss

## Overview
Multi-scale joint training loss is a composite objective function used in the refinement stage of radiance field optimization to balance low-frequency structural consistency with high-frequency detail fidelity [S2]. It addresses the problem of noise interference and detail loss during iterative refinement or dynamic network growth by simultaneously optimizing outputs from multiple network stages or scales [S1, S2]. Unlike single-scale losses, it aggregates errors across all active outlets, ensuring that coarse structures are preserved while fine details are sharpened [S2].

## How it works
The method operates in two distinct formulations depending on the specific implementation context: a coarse-fine balance for image refinement [S2] and a multi-stage summation for dynamic network growth [S1].

### Inputs and Outputs
*   **Inputs:** Network parameters $\theta$, input images (or latent representations), and ground truth images. In dynamic growth contexts, query coordinates are passed through all active network outlets [S1].
*   **Outputs:** A scalar loss value $L$ or $\sigma$ used to update $\theta$ via gradient descent.

### Data Structures
No specific complex data structures are required beyond standard tensor representations for images and network weights. The method relies on the output tensors from multiple network layers or stages [S1, S2].

### Formulas and Parameters

**1. Coarse-Fine Joint Loss (Refinement Stage)**
Used to refine denoised or coarse inputs by balancing low-frequency agreement and high-frequency fidelity [S2].

$$ L(\theta) = \alpha L_{coarse}(\theta) + (1-\alpha) L_{fine}(\theta) $$

*   $\alpha \in [0, 1]$: Weight balancing coarse and fine terms.
*   $L_{coarse}(\theta)$: Low-frequency consistency term. Compares input and output after smoothing to preserve tone and large-scale structure [S2].
*   $L_{fine}(\theta)$: Detail consistency term. Composed of:
    *   Pixel-level robust distance (suppresses outlier noise) [S2].
    *   Structural Similarity (SSIM) term (aligns textures/contours) [S2].
    *   Gradient consistency term (matches edge direction/strength) [S2].
    *   Chroma consistency term (reduces color shifts) [S2].

**2. Multi-Stage Joint Loss (Dynamic Growth)**
Used when the network grows dynamically, aggregating losses from all current stages [S1].

$$ \sigma = \sum_{i=1}^D \beta_1 \mathcal{L}_{MSE}^i + \beta_2 \mathcal{L}_{unct}^i $$

*   $D$: Current number of stages (or network depth) [S1].
*   $\mathcal{L}_{MSE}^i$: Mean Squared Error loss of the output image from layer $i$ [S1].
*   $\mathcal{L}_{unct}^i$: Uncertainty loss of the output image from layer $i$ [S1].
*   $\beta_1, \beta_2$: Weights. Typical values: $\beta_1 = 1.0, \beta_2 = 0.1$ [S1].
*   All query coordinates are output through all outlets during training [S1].

### Edge Cases and Pitfalls
*   **Precision:** In dynamic growth, ensuring that query coordinates are correctly routed to all outlets is critical [S1].
*   **Boundaries:** The weight $\alpha$ must be carefully tuned; too high a value may neglect fine details, while too low may lose structural integrity [S2].
*   **Degenerate Input:** If the network has not grown yet ($D=1$), the multi-stage loss reduces to a single-stage loss [S1].

## Subtopics

### Coarse-Fine Refinement
Focuses on balancing low-frequency structure and high-frequency detail in a single-stage refinement context [S2]. Choose when refining denoised inputs.

### Multi-Stage Dynamic Growth
Aggregates losses across multiple network depths during adaptive growth [S1]. Choose when using dynamically growing neural networks.

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of stages $D$ in the multi-stage formulation [S1]. The coarse-fine formulation adds overhead for computing multiple detail terms (SSIM, gradients) [S2].
*   **Memory Complexity:** Requires storing outputs from all active stages in the multi-stage formulation [S1].
*   **Strengths:** Preserves geometric variations while reducing noise [S2]; ensures consistency across scales [S1].
*   **Limitations:** Requires careful tuning of multiple hyperparameters ($\alpha, \beta_1, \beta_2$) [S1, S2].
*   **When to use:** During the second round of training for refinement [S2] or during dynamic network growth phases [S1].

## Background
The concept originates from methods that employ iterative refinement or dynamic network growth for radiance field optimization. The coarse-fine joint loss was introduced in Denoise-GS for self-supervised denoising in sparse-view 3D Gaussian Splatting [S2]. The multi-stage joint loss was proposed in Recursive-NeRF for efficient, dynamically growing neural radiance fields [S1].
