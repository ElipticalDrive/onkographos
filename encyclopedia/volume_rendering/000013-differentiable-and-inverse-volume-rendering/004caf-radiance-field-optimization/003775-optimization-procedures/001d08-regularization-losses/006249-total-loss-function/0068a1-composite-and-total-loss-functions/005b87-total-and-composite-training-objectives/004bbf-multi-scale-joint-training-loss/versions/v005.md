# Multi-scale Joint Training Loss

Also called: Coarse-Fine Joint Loss, Joint Loss, Multi-scale Joint Loss

## Overview
The Multi-scale Joint Training Loss is a composite objective function used in multi-stage or dynamic-growth radiance field optimization to balance low-frequency structural consistency with high-frequency detail fidelity. It addresses the problem of refining coarse representations by ensuring that the optimization process preserves global appearance while enhancing local texture and edge sharpness. It differs from single-scale losses by explicitly weighting contributions from multiple network stages or resolution levels, and from simple photometric losses by incorporating uncertainty or multi-term structural constraints.

## How it works
The method constructs a total loss $L_{tot}$ by aggregating individual loss components from multiple stages or scales. Two primary formulations exist in the literature, depending on whether the architecture uses dynamic stage growth or a coarse-fine refinement pipeline.

### Inputs and Outputs
- **Inputs**: Network parameters $\theta$, input images $I_{in}$, target images $I_{gt}$, stage index $i$, number of stages $D$, and hyperparameters $\alpha, \beta_1, \beta_2$.
- **Outputs**: A scalar loss value $L_{tot}$ for backpropagation.

### Data Structures
No specific complex data structures are required beyond standard image tensors and scalar weights. The method relies on the output images from each stage $i$ of the network.

### Formulas and Steps

#### Formulation 1: Dynamic Stage Growth (Recursive-NeRF)
Used when the network grows dynamically through stages. The loss aggregates MSE and uncertainty losses from all active stages.

$$ \mathcal{L} = \sum_{i=1}^D \left( \beta_1 \mathcal{L}_{MSE}^i + \beta_2 \mathcal{L}_{unct}^i \right) $$

Where:
- $D$ is the current number of stages.
- $\mathcal{L}_{MSE}^i$ is the Mean Squared Error loss between the rendered image and ground truth at stage $i$.
- $\mathcal{L}_{unct}^i$ is the uncertainty loss at stage $i$.
- $\beta_1$ and $\beta_2$ are scalar weights.

**Typical Values**: $\beta_1 = 1.0$, $\beta_2 = 0.1$ [S1].

#### Formulation 2: Coarse-Fine Refinement (Denoise-GS)
Used in a two-round process where a coarse model is refined. The loss balances low-frequency and high-frequency terms.

$$ L(\theta) = \alpha L_{coarse}(\theta) + (1-\alpha) L_{fine}(\theta), \quad \alpha \in [0, 1] $$

Where:
- $L_{coarse}(\theta)$ is the low-frequency consistency term, comparing smoothed versions of input and output to preserve tone and large-scale structure.
- $L_{fine}(\theta)$ is the detail consistency term, comprising:
    - Pixel-level robust distance (suppresses outlier noise).
    - Structural Similarity (SSIM) term (aligns textures/contours).
    - Gradient consistency term (matches edge direction/strength).
    - Chroma consistency term (reduces color shifts).

**Typical Values**: $\alpha$ is a hyperparameter in $[0, 1]$. Specific values for sub-terms in $L_{fine}$ are not explicitly numbered in the source but are described as components of the composite term [S2].

### Pseudocode
```python
def compute_multi_scale_joint_loss(rendered_images, ground_truth_images, uncertainties, stage_count, loss_type="dynamic"):
    """
    Computes the multi-scale joint training loss.
    
    Args:
        rendered_images: List of rendered images for each stage i (0 to D-1).
        ground_truth_images: List of ground truth images for each stage i.
        uncertainties: List of uncertainty maps for each stage i.
        stage_count: Integer D, the number of active stages.
        loss_type: String, either "dynamic" (Recursive-NeRF) or "coarse_fine" (Denoise-GS).
        
    Returns:
        Scalar loss value.
    """
    if loss_type == "dynamic":
        beta1 = 1.0
        beta2 = 0.1
        total_loss = 0.0
        for i in range(stage_count):
            # MSE Loss
            mse_loss = mean_squared_error(rendered_images[i], ground_truth_images[i])
            # Uncertainty Loss (implementation depends on specific uncertainty model)
            unct_loss = compute_uncertainty_loss(rendered_images[i], ground_truth_images[i], uncertainties[i])
            total_loss += beta1 * mse_loss + beta2 * unct_loss
        return total_loss
        
    elif loss_type == "coarse_fine":
        alpha = 0.5 # Placeholder; typically tuned hyperparameter
        # L_coarse: Low-frequency consistency
        # Compare smoothed versions of input and output
        coarse_loss = compute_low_frequency_consistency(rendered_images[0], ground_truth_images[0])
        
        # L_fine: Detail consistency
        # Composed of robust distance, SSIM, gradient, and chroma terms
        fine_loss = compute_detail_consistency(rendered_images[0], ground_truth_images[0])
        
        return alpha * coarse_loss + (1 - alpha) * fine_loss
    else:
        raise ValueError("Unknown loss type")
```

### Edge Cases and Pitfalls
- **Stage Count**: In dynamic growth, $D$ changes during training. The loss summation must adapt to the current number of active stages [S1].
- **Weight Tuning**: The balance between $\beta_1$ and $\beta_2$ (or $\alpha$) is critical. Incorrect weighting can lead to over-smoothing or noise amplification.
- **Uncertainty Calculation**: The definition of $\mathcal{L}_{unct}$ is not fully detailed in the source, requiring implementation of a specific uncertainty model (e.g., pixel-wise variance) [S1].

## Operating characteristics
- **Time Complexity**: Linear with respect to the number of stages $D$ in the dynamic formulation, as it sums losses from each stage. The coarse-fine formulation is constant time relative to stages but involves more complex per-pixel computations for the detail term.
- **Memory Complexity**: Requires storing intermediate rendered images and uncertainties for all active stages if computed simultaneously, or recomputing them if memory is constrained.
- **Strengths**: Improves detail fidelity without sacrificing structural integrity. The dynamic growth version allows efficient resource allocation by focusing computation on uncertain regions.
- **Limitations**: Requires careful tuning of multiple hyperparameters ($\beta_1, \beta_2, \alpha$). The coarse-fine formulation is computationally heavier due to the multi-term detail loss.

## Background
The concept originates from recent advancements in NeRF and Gaussian Splatting optimization. The dynamic stage growth formulation is introduced in Recursive-NeRF [S1], which uses a dynamically growing network structure. The coarse-fine joint loss is proposed in Denoise-GS [S2] for self-supervised denoising in sparse-view 3D Gaussian Splatting. Both methods aim to improve reconstruction quality by explicitly managing multi-scale information during optimization.
