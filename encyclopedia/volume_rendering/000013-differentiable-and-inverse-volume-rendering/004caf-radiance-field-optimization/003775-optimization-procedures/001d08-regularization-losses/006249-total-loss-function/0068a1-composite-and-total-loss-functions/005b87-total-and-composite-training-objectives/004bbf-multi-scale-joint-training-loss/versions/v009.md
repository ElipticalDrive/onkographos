# Multi-scale Joint Training Loss

Also called: Coarse-Fine Joint Loss, Joint Loss, Multi-scale Joint Loss

## Overview
The Multi-scale Joint Training Loss is a composite objective function designed for multi-stage or multi-resolution radiance field optimization, specifically balancing low-frequency structural consistency with high-frequency detail fidelity [S2]. It addresses the problem of refining coarse reconstructions by ensuring that the optimization process preserves global appearance while enhancing local texture and edge sharpness [S2]. Unlike single-scale losses, it explicitly weights contributions from different resolution stages or coarse/fine network outputs to prevent overfitting to noise while maintaining geometric coherence [S1, S2].

## How it works
The method operates in two primary formulations depending on the specific architecture (multi-stage growth vs. coarse-fine refinement). Both formulations adhere to the parent's principle of a weighted sum of component losses [Parent].

### Inputs and Outputs
*   **Inputs**: Ground truth images $I$, rendered images $\hat{I}$ from multiple stages or resolutions, network parameters $\theta$, and hyperparameters $\alpha, \beta_1, \beta_2$.
*   **Outputs**: A scalar total loss value $L_{tot}$ used for backpropagation.

### Data Structures
No specific complex data structures are required beyond standard image tensors and scalar weights. The method relies on the output of intermediate network layers or stages.

### Formulas and Steps

#### Formulation 1: Multi-Stage Growth (Recursive-NeRF)
Used when the network grows dynamically through stages [S1].

1.  **Compute Stage Losses**: For each stage $i$ from $1$ to $D$ (where $D$ is the current number of stages):
    *   Calculate the Mean Squared Error loss $\mathcal{L}_{MSE}^i$ between the rendered image and ground truth.
    *   Calculate the uncertainty loss $\mathcal{L}_{unct}^i$ associated with the output of layer $i$.
2.  **Aggregate Loss**: Compute the total loss using the weighted sum:
    $$ \mathcal{L} = \sum_{i=1}^D \left( \beta_1 \mathcal{L}_{MSE}^i + \beta_2 \mathcal{L}_{unct}^i \right) $$
    *   $\beta_1 = 1.0$
    *   $\beta_2 = 0.1$ [S1]

#### Formulation 2: Coarse-Fine Refinement (Denoise-GS)
Used in a second training round to refine denoised inputs [S2].

1.  **Define Components**:
    *   $L_{coarse}(\theta)$: Low-frequency consistency term. This compares the input and output after smoothing, focusing on tone and large-scale structure to prevent damage to global appearance [S2].
    *   $L_{fine}(\theta)$: Detail consistency term. This consists of:
        *   Pixel-level robust distance (suppresses outlier noise) [S2].
        *   Structural Similarity (SSIM) term (aligns textures and contours) [S2].
        *   Gradient consistency term (matches edge direction and strength) [S2].
        *   Chroma consistency term (reduces color shifts) [S2].
2.  **Compute Joint Loss**:
    $$ L(\theta) = \alpha L_{coarse}(\theta) + (1-\alpha) L_{fine}(\theta) $$
    *   $\alpha \in [0, 1]$ is a hyperparameter balancing coarse and fine contributions [S2].

### Pseudocode
```python
def multi_scale_joint_loss(rendered_images, ground_truth_images, uncertainty_maps, 
                           stages, alpha, beta1=1.0, beta2=0.1, mode='recursive'):
    """
    Computes the multi-scale joint training loss.
    
    Args:
        rendered_images: List of rendered images for each stage/resolution.
        ground_truth_images: List of ground truth images corresponding to stages.
        uncertainty_maps: List of uncertainty maps for each stage (used in recursive mode).
        stages: Integer D, the current number of stages.
        alpha: Float, weight for coarse loss in coarse-fine mode.
        beta1: Float, weight for MSE loss (default 1.0).
        beta2: Float, weight for uncertainty loss (default 0.1).
        mode: String, 'recursive' for multi-stage growth, 'coarse_fine' for refinement.
        
    Returns:
        Scalar total loss.
    """
    total_loss = 0.0
    
    if mode == 'recursive':
        # Formulation 1: Sum over all stages
        for i in range(stages):
            # Compute MSE loss for stage i
            mse_loss = mean_squared_error(rendered_images[i], ground_truth_images[i])
            
            # Compute uncertainty loss for stage i
            # Note: Specific definition of uncertainty loss depends on the network's 
            # uncertainty head, typically involving the variance predicted by the network.
            unct_loss = compute_uncertainty_loss(uncertainty_maps[i])
            
            # Weighted sum for this stage
            stage_loss = beta1 * mse_loss + beta2 * unct_loss
            total_loss += stage_loss
            
    elif mode == 'coarse_fine':
        # Formulation 2: Coarse-Fine balance
        # L_coarse: Low-frequency consistency (e.g., MSE on smoothed images)
        coarse_loss = compute_low_frequency_loss(rendered_images, ground_truth_images)
        
        # L_fine: Detail consistency (SSIM + Gradient + Chroma + Robust Distance)
        fine_loss = compute_detail_consistency_loss(rendered_images, ground_truth_images)
        
        # Weighted combination
        total_loss = alpha * coarse_loss + (1 - alpha) * fine_loss
        
    return total_loss
```

### Parameters and Edge Cases
*   **$\beta_1, \beta_2$**: In Recursive-NeRF, $\beta_1=1.0$ and $\beta_2=0.1$ are fixed [S1].
*   **$\alpha$**: In Denoise-GS, $\alpha$ is a tunable hyperparameter in $[0,1]$ [S2].
*   **Edge Cases**: If $D=1$ (single stage), the recursive loss reduces to a single term. If $\alpha=1$, only coarse loss is considered; if $\alpha=0$, only fine loss is considered.
*   **Pitfalls**: In the recursive formulation, all query coordinates must be output through all outlets during training to ensure consistent loss computation across stages [S1].

## Operating characteristics
*   **Time Complexity**: Linear with respect to the number of stages $D$ in the recursive formulation, as it sums losses from each stage [S1]. The coarse-fine formulation adds overhead for computing structural and gradient terms but is constant with respect to depth [S2].
*   **Memory Complexity**: Requires storing intermediate rendered images and uncertainty maps for all stages if computed simultaneously, or recomputing them if memory is constrained [S1].
*   **Strengths**: Effectively balances global structure preservation with local detail enhancement, reducing noise interference while maintaining sharp textures [S2]. The multi-stage approach allows for efficient dynamic growth of the network [S1].
*   **Limitations**: Requires careful tuning of $\alpha$ and $\beta$ weights. The uncertainty loss component requires a specific network architecture capable of predicting uncertainty [S1].

## Background
The multi-scale joint loss concept appears in two distinct contexts within recent radiance field literature. The recursive formulation was introduced in **Recursive-NeRF** (2022), which proposes a dynamically growing NeRF architecture where losses are aggregated across all active stages to guide the growth process [S1]. The coarse-fine formulation was proposed in **Denoise-GS** (2024), designed for self-supervised denoising in sparse-view 3D Gaussian Splatting, where a second training round refines initial denoised images by balancing low-frequency agreement and high-frequency fidelity [S2].
