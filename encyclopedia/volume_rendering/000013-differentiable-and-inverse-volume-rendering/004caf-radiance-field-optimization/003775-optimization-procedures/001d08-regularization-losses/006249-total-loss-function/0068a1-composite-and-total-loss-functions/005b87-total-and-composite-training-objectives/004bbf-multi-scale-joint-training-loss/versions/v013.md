# Multi-scale Joint Training Loss

Also called: Coarse-Fine Joint Loss, Joint Loss, Multi-scale Joint Loss

## Overview
The Multi-scale Joint Training Loss is a composite objective function used in the second round of training for radiance field optimization, designed to balance low-frequency structural agreement with high-frequency detail fidelity [S2]. It sets itself apart from single-scale losses by explicitly weighting contributions from coarse (low-frequency) and fine (high-frequency) representations, or by aggregating losses across dynamically growing network stages [S1, S2]. It builds on [Total and Composite Training Objectives](16924-total-and-composite-training-objectives.md).

## How it works
**Inputs and Outputs:**
*   **Inputs:** Model parameters $\theta$; ground-truth images; optional depth maps; camera poses. In the multi-stage context, inputs include query coordinates passed through all outlets [S1].
*   **Outputs:** Scalar total loss $L_{tot}$ and its gradients with respect to $\theta$.

**Data Structures:**
*   **Loss Components:** Individual loss terms $\mathcal{L}_k$ (e.g., MSE, uncertainty, structural similarity) computed per stage or per scale [S1, S2].
*   **Weights:** Scalar hyperparameters $\alpha, \beta_1, \beta_2$ balancing the terms [S1, S2].

**Formulas:**
Two primary formulations exist in the literature:

1.  **Coarse-Fine Balance [S2]:**
    $$ L(\theta) = \alpha L_{coarse}(\theta) + (1-\alpha) L_{fine}(\theta) $$
    Where $\alpha \in [0, 1]$ is a hyperparameter. $L_{coarse}$ focuses on low-frequency consistency (tone, large-scale structure), while $L_{fine}$ includes pixel-level robust distance, structural similarity, gradient consistency, and chroma consistency [S2].

2.  **Multi-Stage Aggregation [S1]:**
    $$ \mathcal{L} = \sum_{i=1}^D \beta_1 \mathcal{L}_{MSE}^i + \beta_2 \mathcal{L}_{unct}^i $$
    Where $D$ is the current number of stages (or network growth iterations). $\mathcal{L}_{MSE}^i$ is the Mean Squared Error loss for layer $i$, and $\mathcal{L}_{unct}^i$ is the uncertainty loss for layer $i$. Typical values are $\beta_1 = 1.0$ and $\beta_2 = 0.1$ [S1].

**Numbered Steps:**
1.  **Forward Pass:** Render images from the current model state. In multi-stage models, query coordinates are processed through all active outlets/stages [S1].
2.  **Compute Component Losses:**
    *   Calculate $L_{coarse}$ by comparing smoothed versions of input and output images [S2].
    *   Calculate $L_{fine}$ using robust distance, structural similarity, gradient, and chroma terms [S2].
    *   Alternatively, for each stage $i$, compute $\mathcal{L}_{MSE}^i$ and $\mathcal{L}_{unct}^i$ [S1].
3.  **Aggregate:** Combine losses using the weighted sum formula defined above [S1, S2].
4.  **Backpropagate:** Compute gradients of $L_{tot}$ with respect to $\theta$ and update parameters [S1, S2].

**Parameters:**
*   $\alpha$: Balances coarse vs. fine loss. Range $[0, 1]$ [S2].
*   $\beta_1, \beta_2$: Weights for MSE and uncertainty in multi-stage loss. Typical values: $\beta_1=1.0, \beta_2=0.1$ [S1].

**Edge Cases and Pitfalls:**
*   **Precision:** Robust distance in $L_{fine}$ helps suppress outlier noise [S2].
*   **Boundaries:** Ensure query coordinates are correctly routed to all outlets during training to avoid missing loss contributions [S1].

**Pseudocode:**
```python
def multi_scale_joint_loss(model, inputs, alpha, beta1, beta2, num_stages):
    """
    Computes the multi-scale joint training loss.
    
    Args:
        model: Radiance field model with multiple stages/outputs.
        inputs: Ground truth images, camera poses, query coordinates.
        alpha: Weight for coarse loss (S2).
        beta1: Weight for MSE loss (S1).
        beta2: Weight for uncertainty loss (S1).
        num_stages: Number of active stages D (S1).
        
    Returns:
        total_loss: Scalar loss value.
        gradients: Gradients w.r.t model parameters.
    """
    # Forward pass through all stages
    outputs = []
    for i in range(num_stages):
        # Render image for stage i
        rendered_img = model.forward_stage(i, inputs.query_coords, inputs.camera_poses)
        outputs.append(rendered_img)
        
    total_loss = 0.0
    
    # Check if multi-stage formulation (S1) or coarse-fine formulation (S2) is intended
    # Based on sources, these are distinct implementations. 
    # This pseudocode assumes the multi-stage aggregation (S1) as it is more explicit in structure.
    
    for i in range(num_stages):
        gt_img = inputs.gt_images[i]
        
        # Compute MSE loss for stage i
        mse_loss = mean_squared_error(outputs[i], gt_img)
        
        # Compute uncertainty loss for stage i [S1]
        # Note: Uncertainty loss definition is not fully detailed in sources [G]
        # Assuming a standard uncertainty term based on model confidence
        uncertainty_loss = compute_uncertainty_loss(model, outputs[i], inputs)
        
        # Aggregate with weights
        stage_loss = beta1 * mse_loss + beta2 * uncertainty_loss
        total_loss += stage_loss
        
    # If using Coarse-Fine formulation (S2), replace aggregation with:
    # coarse_loss = compute_coarse_loss(model, inputs)
    # fine_loss = compute_fine_loss(model, inputs)
    # total_loss = alpha * coarse_loss + (1 - alpha) * fine_loss
    
    return total_loss
```

## Operating characteristics
*   **Time Complexity:** Proportional to the number of stages $D$ and the number of pixels/queries. Multi-stage approaches require rendering through all active stages [S1].
*   **Memory Complexity:** Requires storing intermediate outputs for all stages if gradients are computed via backpropagation through all stages [S1].
*   **Strengths:** Preserves structural consistency while enhancing detail sharpness [S2]. Adapts to dynamic network growth [S1].
*   **Limitations:** Requires careful tuning of $\alpha, \beta_1, \beta_2$. Uncertainty loss computation may be non-trivial [S1].
*   **When to use:** When refining initial reconstructions or training dynamically growing networks [S1, S2].
*   **When not to use:** For simple, single-scale NeRF training where a single photometric loss suffices.

## Background
*   **Origin:** The coarse-fine joint loss was introduced in Denoise-GS for self-supervised denoising in sparse-view 3D Gaussian Splatting [S2]. The multi-stage aggregation loss was introduced in Recursive-NeRF for dynamically growing NeRFs [S1].
*   **History:** Developed to address noise interference and detail fidelity in radiance field optimization [S1, S2].
*   **Usage:** Used in denoising pipelines and dynamic network growth strategies [S1, S2].
