# Joint Training Losses

Also called: Composite Loss with Pose, Skin, and INN Constraints

## Overview
This method defines a composite objective function for the joint optimization of a Template-Free NeRF (TFS-NeRF) and an Implicit Neural Network (INN) for dynamic scene reconstruction. It solves the ambiguity in skinning weight prediction and canonical-to-view mapping by combining photometric reconstruction with geometric constraints in the skeleton space. It distinguishes itself from static multi-task learning by explicitly constraining the INN and skinning weight networks through pose, cycle consistency, and skinning weight losses, which are absent in standard NeRF training [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Input pixel RGB values $C(r)$ along rays $r \in R$; posed skeleton configuration $J_p$; canonical skeleton configuration $J_{p0}$; view-space points $x_v$; canonical points $x_c$.
*   **Outputs:** Total loss $L_{tot}$ used for backpropagation to update NeRF densities, INN parameters, and skinning weight network parameters.

**Data Structures:**
*   **Rays:** Set $R$ of camera rays.
*   **Skeletons:** $J_p$ (posed joints), $J_{p0}$ (canonical joints).
*   **Points:** $X_{J_p}$ (points sampled around deformed bones), $X_{J_{p0}}$ (points sampled around canonical bones), $P$ (total number of sampled points).
*   **Networks:**
    *   $G_{x_c \to w}$: Skinning weight prediction network mapping canonical points to weights.
    *   $H$: INN mapping canonical space to view space (or vice versa, see formulas).
    *   $H^{-1}$: Inverse INN mapping.

**Formulas:**
The total loss is the sum of five components [S1]:

1.  **Reconstruction Loss ($L_{rgb}$):**
    $$ L_{rgb} = \sum_{r \in R} ||\hat{C}(r) - C(r)|| $$
    Where $\hat{C}(r)$ is the rendered RGB and $C(r)$ is the input pixel RGB.

2.  **Pose Loss ($L_{pose}$):**
    $$ L_{pose} = \sum_{p \in P} ||X_{J_{p0}} - G_{v \to c}(X_{J_p})|| $$
    Ensures the INN correctly transforms points from the deformed skeleton space to the canonical space. $G_{v \to c}$ denotes the INN transformation.

3.  **Skinning Weight Loss ($L_W$):**
    $$ L_W = ||G_{x_c \to w}(J_{p0}) - \hat{w}||_2^2 $$
    Constrains the predicted skinning weight $\hat{w}$ for canonical joints to be a one-hot vector (1 for the respective joint, 0 for others).

4.  **Cycle Consistency Loss ($L_{INN}$):**
    $$ L_{INN} = ||H(H^{-1}(x_v, J_{p0}), J_p) - x_v||_2^2 $$
    Ensures that transforming a view point $x_v$ to canonical space and back to deformed space (conditioned on $J_p$) recovers the original point.

5.  **Consistency Loss ($L_{Consis}$):**
    $$ L_{Consis} = ||x'_c - x_c||_2^2 $$
    Minimizes the L2 distance between the INN-transformed point $x'_c$ and the skinning-weight-conditioned canonical point $x_c$.

**Pseudocode:**
```python
def compute_joint_training_loss(rendered_rgb, input_rgb, 
                                inn_transform, inn_inverse, 
                                skinning_net, 
                                points_deformed, points_canonical, 
                                posed_joints, canonical_joints,
                                view_points, skinning_conditioned_points):
    """
    Computes the joint training loss for TFS-NeRF.
    
    Args:
        rendered_rgb: Rendered RGB values for rays R.
        input_rgb: Ground truth RGB values for rays R.
        inn_transform: Function H mapping canonical to deformed/view space.
        inn_inverse: Function H^-1 mapping view to canonical space.
        skinning_net: Function G mapping canonical points to skinning weights.
        points_deformed: Set X_Jp of points around deformed bones.
        points_canonical: Set X_Jp0 of points around canonical bones.
        posed_joints: Current posed skeleton J_p.
        canonical_joints: Canonical skeleton J_p0.
        view_points: Points x_v in view space.
        skinning_conditioned_points: Points x_c conditioned by skinning weights.
        
    Returns:
        total_loss: Scalar total loss value.
    """
    
    # 1. Reconstruction Loss
    # L_rgb = sum(||C_hat(r) - C(r)||)
    reconstruction_loss = 0.0
    for r in rays:
        reconstruction_loss += norm(rendered_rgb[r] - input_rgb[r])
        
    # 2. Pose Loss
    # L_pose = sum(||X_Jp0 - G_v->c(X_Jp)||)
    # Note: Source uses G_v->c for INN transformation in pose loss context
    pose_loss = 0.0
    for p in points_deformed:
        # Transform deformed point to canonical space
        canonical_point = inn_inverse(p, canonical_joints)
        pose_loss += norm(points_canonical[p] - canonical_point)
        
    # 3. Skinning Weight Loss
    # L_W = ||G_xc->w(J_p0) - w_hat||_2^2
    # Predict skinning weights for canonical joints
    predicted_weights = skinning_net(canonical_joints)
    # Target is one-hot vector w_hat (defined externally or via label)
    # Assuming w_hat is provided or derived from ground truth joint indices
    skinning_loss = norm_squared(predicted_weights - w_hat)
    
    # 4. Cycle Consistency Loss
    # L_INN = ||H(H^-1(x_v, J_p0), J_p) - x_v||_2^2
    # Transform view point to canonical
    canonical_view_point = inn_inverse(view_points, canonical_joints)
    # Transform canonical point back to deformed space conditioned on posed joints
    deformed_view_point = inn_transform(canonical_view_point, posed_joints)
    cycle_loss = norm_squared(deformed_view_point - view_points)
    
    # 5. Consistency Loss
    # L_Consis = ||x'_c - x_c||_2^2
    # x'_c is INN transformed point, x_c is skinning-weight conditioned point
    consistency_loss = norm_squared(inn_transformed_point - skinning_conditioned_points)
    
    # Total Loss
    # L_tot = L_rgb + L_pose + L_W + L_INN + L_Consis
    # Note: Source does not specify lambda weights for individual terms in the formula block,
    # implying equal weighting or default hyperparameters not detailed in the excerpt.
    total_loss = reconstruction_loss + pose_loss + skinning_loss + cycle_loss + consistency_loss
    
    return total_loss
```

**Edge Cases and Pitfalls:**
*   **Ambiguity:** Without the pose, skinning, and consistency losses, incorrect combinations of canonical points and skinning weights can satisfy the forward Linear Blend Skinning (LBS) equation [S1].
*   **Initialization:** The method relies on a point cloud initialization around the canonical skeleton to accelerate learning via shape loss (mentioned in background but not in the core 5-loss formula block) [S1].

## Subtopics

## Operating characteristics
*   **Complexity:** The method adds significant computational overhead per iteration due to the evaluation of the INN ($H, H^{-1}$) and the skinning weight network for every point in the skeleton vicinity, in addition to the standard NeRF ray marching.
*   **Performance:** The inclusion of these losses accelerates the learning process and stabilizes the optimization of dynamic scenes without templates [S1].
*   **Limitations:** The method requires sampling points around bones ($X_{J_p}, X_{J_{p0}}$), which necessitates access to skeleton information and bone geometry, limiting its applicability to non-rigid scenes with known or estimable skeletons.

## Background
This method originates from the TFS-NeRF (Template-Free NeRF) framework for semantic 3D reconstruction of dynamic scenes [S1]. It addresses the lack of direct supervision for skinning weight prediction and INN by introducing geometric constraints in the skeleton space. The approach builds upon the concept of using cycle consistency for implicit neural representations and extends it with explicit skinning weight regularization [S1].
