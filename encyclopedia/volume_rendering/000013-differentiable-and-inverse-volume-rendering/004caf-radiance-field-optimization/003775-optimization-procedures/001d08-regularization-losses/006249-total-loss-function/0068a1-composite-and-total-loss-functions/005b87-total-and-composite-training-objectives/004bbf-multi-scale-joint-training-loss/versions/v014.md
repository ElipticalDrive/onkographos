# Multi-scale Joint Training Loss

Also called: Coarse-Fine Joint Loss, Joint Loss, Multi-scale Joint Loss

## Overview
Multi-scale Joint Training Loss is a composite objective function used in the second round of training for methods involving dynamic network growth or multi-stage refinement [S1, S2]. It balances low-frequency structural agreement with high-frequency detail fidelity by simultaneously optimizing outputs from multiple network stages or scales [S1, S2]. Unlike single-scale losses, it ensures that coarse approximations do not degrade while fine details are being learned [S2].

## How it works
The method aggregates loss terms from multiple output stages (or coarse/fine branches) into a single scalar objective. The specific formulation depends on the underlying architecture: either a weighted sum of stage-specific losses (Recursive-NeRF) or a weighted combination of coarse and fine consistency terms (Denoise-GS) [S1, S2].

### Inputs and Outputs
*   **Inputs:**
    *   $\theta$: Network parameters.
    *   $D$: Current number of stages or layers [S1].
    *   $\alpha$: Weight balancing coarse and fine components ($\alpha \in [0, 1]$) [S2].
    *   $\beta_1, \beta_2$: Weights for MSE and uncertainty/consistency terms [S1].
    *   Rendered images $I^i$ from each stage $i$ [S1].
    *   Ground truth or reference images $I_{gt}$ [S1, S2].
*   **Outputs:**
    *   Scalar total loss $L_{tot}$ or $\mathcal{L}$ [S1, S2].

### Data Structures
No specific complex data structures are required beyond standard tensors for rendered images and loss buffers. The method iterates over stages $i = 1 \dots D$ [S1].

### Formulas
Two primary formulations exist in the literature:

1.  **Multi-Stage Summation (Recursive-NeRF):**
    $$ \mathcal{L} = \sum_{i=1}^D \left( \beta_1 \mathcal{L}_{MSE}^i + \beta_2 \mathcal{L}_{unct}^i \right) $$
    Where:
    *   $D$ is the current number of stages [S1].
    *   $\mathcal{L}_{MSE}^i$ is the Mean Squared Error loss for the output image of layer $i$ [S1].
    *   $\mathcal{L}_{unct}^i$ is an uncertainty loss for layer $i$ [S1].
    *   $\beta_1 = 1.0$ and $\beta_2 = 0.1$ are typical weights [S1].

2.  **Coarse-Fine Balance (Denoise-GS):**
    $$ L(\theta) = \alpha L_{coarse}(\theta) + (1-\alpha) L_{fine}(\theta) $$
    Where:
    *   $L_{coarse}$ focuses on low-frequency consistency (tone, large-scale structure) [S2].
    *   $L_{fine}$ focuses on high-frequency fidelity (detail sharpness, texture) [S2].
    *   $L_{fine}$ typically comprises pixel-level robust distance, structural similarity (SSIM), gradient consistency, and chroma consistency terms [S2].

### Parameters
*   $\alpha$: Balances coarse vs. fine. Range $[0, 1]$ [S2].
*   $\beta_1, \beta_2$: Balance MSE vs. Uncertainty. Typical values $\beta_1=1.0, \beta_2=0.1$ [S1].

### Edge Cases and Pitfalls
*   **Stage Growth:** In dynamic growth methods, $D$ increases during training. The loss summation must dynamically include new stages [S1].
*   **Query Coordinates:** All query coordinates must be passed through all outlets/stages during training to ensure consistent gradient flow [S1].
*   **Noise Interference:** The coarse term helps preserve essential geometric variations while reducing noise interference [S2].

### Pseudocode
```python
def multi_scale_joint_loss(rendered_images, ground_truth, uncertainty_maps, 
                           num_stages, alpha, beta1, beta2, loss_type):
    """
    Computes the multi-scale joint training loss.
    
    Args:
        rendered_images: List of rendered images [I^1, ..., I^D]
        ground_truth: Ground truth image tensor
        uncertainty_maps: List of uncertainty maps [U^1, ..., U^D]
        num_stages: Current number of stages D
        alpha: Weight for coarse loss (0-1)
        beta1: Weight for MSE term
        beta2: Weight for uncertainty term
        loss_type: 'recursive_nerf' or 'denoise_gs'
        
    Returns:
        Total loss scalar
    """
    total_loss = 0.0
    
    if loss_type == 'recursive_nerf':
        # Sum over all stages
        for i in range(num_stages):
            # MSE Loss for stage i
            mse_loss = mean_squared_error(rendered_images[i], ground_truth)
            
            # Uncertainty Loss for stage i
            # Note: Specific definition of L_unct not fully detailed in source, 
            # assumed to be derived from uncertainty_maps[i]
            unct_loss = compute_uncertainty_loss(uncertainty_maps[i])
            
            total_loss += beta1 * mse_loss + beta2 * unct_loss
            
    elif loss_type == 'denoise_gs':
        # Split rendered images or features into coarse and fine components
        # This depends on the specific network architecture's output structure
        coarse_output = get_coarse_component(rendered_images)
        fine_output = get_fine_component(rendered_images)
        
        # Coarse Loss: Low-frequency consistency
        # Focuses on tone and large-scale structure
        L_coarse = compute_low_frequency_loss(coarse_output, ground_truth)
        
        # Fine Loss: High-frequency fidelity
        # Comprises: robust distance, SSIM, gradient consistency, chroma consistency
        L_fine = compute_high_frequency_loss(fine_output, ground_truth)
        
        total_loss = alpha * L_coarse + (1 - alpha) * L_fine
        
    return total_loss
```

## Operating characteristics
*   **Complexity:** Linear in the number of stages $D$ for the Recursive-NeRF formulation [S1].
*   **Performance:** Improves detail sharpness and texture fidelity while preserving structural consistency [S2].
*   **Strengths:** Prevents damage to global appearance during refinement; suppresses outlier noise influence [S2].
*   **Limitations:** Requires rendering through all stages during training, increasing memory and compute per step [S1].

## Background
*   **Recursive-NeRF:** Introduced by [S1] (2022) as part of a dynamically growing NeRF architecture. The loss balances MSE and uncertainty across growing network stages.
*   **Denoise-GS:** Introduced by [S2] (2026) for self-supervised denoising in sparse-view 3D Gaussian Splatting. The loss balances coarse structural consistency with fine detail fidelity.
