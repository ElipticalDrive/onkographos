# Radiance Field Loss

Also called: Binary occupancy loss, Non-local perturbation loss

## Overview
Radiance Field Loss is a differentiable optimization objective for volume rendering that treats surface candidates as binary existence choices rather than volumetric opacities, minimizing the weighted sum of color losses for the candidate and background surfaces to promote distinct surface geometry [S1]. Unlike standard volumetric alpha-compositing which blends colors and can result in blended, non-binary surfaces, this method blends losses, forcing the optimizer to select the single surface (candidate or background) that minimizes the color difference [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:**
    *   $\mathbf{r}$: A ray defined by origin and direction [S1].
    *   $n$: Total number of rays (pixels across all reference images) [S1].
    *   $m$: Number of surface candidates sampled along a single ray [S1].
    *   $\alpha_{\mathbf{p}_i} \in [0, 1]$: Occupancy parameter for the $i$-th candidate surface $\mathbf{p}_i$ [S1].
    *   $\mathbf{L}_{\mathbf{p}_i}$: Color of the $i$-th candidate surface [S1].
    *   $\mathbf{L}_{\mathbf{b}}$: Color of the background surface (or environment map) [S1].
    *   $L_{\text{target}}$: Target color from the reference image for the corresponding pixel [S1].
    *   $\ell(\cdot, \cdot)$: A color difference metric [S1].
*   **Outputs:**
    *   $\mathcal{L}_{\text{total}}$: The scalar total loss value used for gradient backpropagation [S1].

**Data Structures**
*   **Candidates:** A list or array of $m$ candidate points $\{\mathbf{p}_1, \dots, \mathbf{p}_m\}$ along the ray. Each candidate is associated with an occupancy $\alpha_{\mathbf{p}_i}$ and a color $\mathbf{L}_{\mathbf{p}_i}$ [S1].
*   **Background:** A single color value $\mathbf{L}_{\mathbf{b}}$ associated with the ray [S1].

**Numbered Steps**
1.  **Iterate over Rays:** For each ray $\mathbf{r}_k$ where $k = 1, \dots, n$ [S1].
2.  **Initialize Ray Loss:** Set $\mathcal{L}_{\text{ray}}(\mathbf{r}_k) = 0$ [S1].
3.  **Iterate over Candidates:** For each candidate $i = 1, \dots, m$ along ray $\mathbf{r}_k$ [S1]:
    a. Retrieve occupancy $\alpha_{\mathbf{p}_i}$, candidate color $\mathbf{L}_{\mathbf{p}_i}$, and background color $\mathbf{L}_{\mathbf{b}}$ [S1].
    b. Compute the color difference for the candidate: $C_{\text{cand}} = \ell(\mathbf{L}_{\mathbf{p}_i}, L_{\text{target}})$ [S1].
    c. Compute the color difference for the background: $C_{\text{bg}} = \ell(\mathbf{L}_{\mathbf{b}}, L_{\text{target}})$ [S1].
    d. Compute the candidate loss using the binary occupancy blend:
       $$ \mathcal{L}(\mathbf{p}_i) = \alpha_{\mathbf{p}_i} C_{\text{cand}} + (1 - \alpha_{\mathbf{p}_i}) C_{\text{bg}} $$ [S1].
    e. Add to ray loss: $\mathcal{L}_{\text{ray}}(\mathbf{r}_k) \leftarrow \mathcal{L}_{\text{ray}}(\mathbf{r}_k) + \mathcal{L}(\mathbf{p}_i)$ [S1].
4.  **Accumulate Total Loss:** $\mathcal{L}_{\text{total}} \leftarrow \mathcal{L}_{\text{total}} + \mathcal{L}_{\text{ray}}(\mathbf{r}_k)$ [S1].

**Formulas**
The single-candidate loss is defined as [S1]:
$$ \mathcal{L}(\mathbf{p}) = \alpha_{\mathbf{p}} \ell(\mathbf{L}_{\mathbf{p}}, L_{\text{target}}) + (1 - \alpha_{\mathbf{p}}) \ell(\mathbf{L}_{\mathbf{b}}, L_{\text{target}}) \quad (2) $$
where:
*   $\alpha_{\mathbf{p}} \in [0, 1]$ is the occupancy parameter [S1].
*   $\mathbf{L}_{\mathbf{p}}$ is the candidate color [S1].
*   $\mathbf{L}_{\mathbf{b}}$ is the background color [S1].
*   $L_{\text{target}}$ is the target color [S1].
*   $\ell$ is a color difference metric [S1].

The total ray loss for $m$ candidates is the sum of individual candidate losses [S1]:
$$ \mathcal{L}_{\text{ray}}(\mathbf{r}) = \sum_{i=1}^m \mathcal{L}(\mathbf{p}_i) \quad (3) $$

The total scene loss is the sum of ray losses over all $n$ rays [S1]:
$$ \mathcal{L}_{\text{total}} = \sum_{k=1}^n \mathcal{L}_{\text{ray}}(\mathbf{r}_k) \quad (4) $$

**Parameters**
*   $\alpha_{\mathbf{p}}$: Occupancy parameter, typically output by a neural network or density field. Range $[0, 1]$ [S1].
*   $\ell$: Color metric. Not given in the sources. [G]

**Edge Cases and Pitfalls**
*   **Ambiguity:** If the candidate color $\mathbf{L}_{\mathbf{p}}$ is static and not subject to optimization, ambiguity may persist. In practice, $\mathbf{L}_{\mathbf{p}}$ is optimized, requiring multiple viewpoints to resolve [S1].
*   **Gradient Propagation:** Unlike conventional surface optimization, this loss propagates gradients to the entirety of the observed 3D space because the evaluation of $\ell$ is moved from image space into the scene [S1].
*   **Background Definition:** The term "background" can refer to a surface, an environment map, etc. A concrete definition is provided in later sections of the source, but for this loss computation, it is treated as a fixed color $\mathbf{L}_{\mathbf{b}}$ [S1].

**Pseudocode**
```python
def radiance_field_loss(candidates, background_color, target_color, loss_metric):
    """
    Computes the Radiance Field Loss for a single ray.
    
    Args:
        candidates: List of tuples (alpha_p, L_p) for m candidates.
        background_color: Vector L_b.
        target_color: Vector L_target.
        loss_metric: Function l(L_pred, L_target) returning scalar.
        
    Returns:
        Scalar loss value.
    """
    ray_loss = 0.0
    
    for alpha_p, L_p in candidates:
        # Compute color differences
        loss_cand = loss_metric(L_p, target_color)
        loss_bg = loss_metric(background_color, target_color)
        
        # Blend losses based on occupancy
        candidate_loss = alpha_p * loss_cand + (1.0 - alpha_p) * loss_bg
        
        ray_loss += candidate_loss
        
    return ray_loss

def compute_total_loss(all_rays, background_color, target_colors, loss_metric):
    """
    Computes the total loss over all rays.
    
    Args:
        all_rays: List of lists, where each inner list contains candidates for a ray.
        background_color: Vector L_b (assumed constant for all rays for simplicity).
        target_colors: List of vectors L_target for each ray.
        loss_metric: Function l(L_pred, L_target).
        
    Returns:
        Scalar total loss.
    """
    total_loss = 0.0
    
    for i, ray_candidates in enumerate(all_rays):
        target = target_colors[i]
        ray_loss = radiance_field_loss(ray_candidates, background_color, target, loss_metric)
        total_loss += ray_loss
        
    return total_loss
```

## Background
*   **Origin:** The method was introduced in "Radiance Surfaces: Optimizing Surface Representations with a 5D Radiance Field Loss" [S1].
*   **History:** It addresses the limitation of standard volumetric alpha-compositing, which minimizes $\ell(\alpha_{\mathbf{p}} L_{\mathbf{p}} + (1 - \alpha_{\mathbf{p}}) L_{\mathbf{b}}, L_{\text{target}})$ and fails to promote binary occupancy [S1]. The authors propose interpreting non-local perturbations as binary choices to create a spatio-directional radiance field loss [S1].
*   **Usage:** Used in differentiable volume rendering for surface reconstruction and optimization [S1].
