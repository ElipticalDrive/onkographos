# Loss Function Configuration

Also called: L2 Loss Optimization, Loss Function Simplification, Loss Weighting Scheme, Loss function parameter configuration, Removing Repulsion Loss, Total Training Loss, Training Loss Weights, w/o Lrep

## Overview
Loss Function Configuration defines the specific composition, weighting, and parameterization of the objective function used to optimize radiance fields. It addresses the problem of balancing multiple competing objectives—such as photometric fidelity, structural similarity, geometric consistency, and regularization—to stabilize training and improve reconstruction quality. It differs from sibling methods by focusing on the *selection* and *tuning* of these terms rather than the definition of the individual loss primitives themselves; for example, it may simplify a standard combination of SSIM and L1 losses to a single L2 loss [S4], or remove specific terms like repulsion loss [S3] to prevent artifacts.

## How it works
The configuration process involves selecting a subset of loss terms from a larger family (e.g., [Photometric and Image Reconstruction Losses](9789-photometric-and-image-reconstruction-losses.md), [Total Variation Loss](7047-total-variation-loss.md)) and assigning scalar weights to balance their contributions to the total loss $\mathcal{L}$.

### Inputs and Outputs
*   **Inputs:** List of candidate loss terms (e.g., $\mathcal{L}_{photo}$, $\mathcal{L}_{ptc}$, $\mathcal{L}_{bg}$, $\mathcal{L}_{d\_norm}$, $\mathcal{L}_{d\_tv}$), scene characteristics (static/dynamic, large motion), and optimization stage (coarse/fine).
*   **Outputs:** A configured total loss function $\mathcal{L}$ with specific weight parameters.

### Data Structures
The loss configuration is typically represented as a dictionary or struct mapping loss term identifiers to their scalar weights.
*   `weights`: Dictionary mapping string keys (e.g., `"ptc"`, `"bg"`) to float values.

### Steps
1.  **Select Loss Terms:** Identify the necessary components based on the radiance field variant. For instance, RT-Splatting combines appearance, normal consistency, and transparent mask regularization [S1, unofficial].
2.  **Assign Base Weights:** Initialize weights based on empirical defaults or ablation studies.
3.  **Apply Stage-Specific Scaling:** Adjust weights for coarse vs. fine optimization stages. Coarse stages often prioritize geometric and deformation regularization, while fine stages prioritize photometric accuracy [S2].
4.  **Handle Scene-Specific Variants:** Modify weights for specific scene properties (e.g., large motion scenes require lower deformation norm weights) [S2].
5.  **Exclude Unnecessary Terms:** Remove terms that cause instability or redundancy (e.g., removing repulsion loss [S3] or simplifying to L2 [S4]).

### Formulas
The total loss is generally a weighted sum:
$$ \mathcal{L} = \sum_i w_i \mathcal{L}_i $$

Specific configurations include:

**1. RT-Splatting Configuration [S1, unofficial]:**
$$ \mathcal{L} = \mathcal{L}_{\text {img}} + \lambda _{\text {n}}\mathcal{L}_{\text {n}} + \lambda _{\text {mask}}\mathcal{L}_{\text {mask}} $$
Where:
*   $\mathcal{L}_{\text {img}} = (1 - \lambda )\mathcal{L}_{1} + \lambda \mathcal{L}_{\text {D-SSIM}} + \lambda _{\text {perc}}\mathcal{L}_{\text {perc}}$
*   $\lambda = 0.2$ (D-SSIM weight)
*   $\lambda _{\text {perc}} = 0.01$ (Perceptual loss weight)
*   $\lambda _{\text {n}} = 0.05$ (Normal consistency weight)
*   $\lambda _{\text {mask}} = 0.01$ (Transparent mask regularization weight)

**2. Neural Deformable Voxel Grid Configuration [S2]:**
$$ \mathcal{L} = \mathcal{L}_{photo} + w_{ptc} \cdot \mathcal{L}_{ptc} + w_{bg} \cdot \mathcal{L}_{bg} + w_{d\_norm} \cdot \mathcal{L}_{d\_norm} + w_{d\_tv} \cdot \mathcal{L}_{d\_tv} $$
Where:
*   **Coarse Stage:** $w_{ptc}=0.1$, $w_{bg}=0.01$, $w_{d\_norm}=0.1$, $w_{d\_tv}=1$.
*   **Fine Stage:** $w_{ptc}=0.01$, $w_{bg}=0.001$, $w_{d\_norm}=0.01$, $w_{d\_tv}=1$.
*   **Large Motion Scenes:** For scenes like 'Hell Warrior', $w_{d\_norm}$ is reduced to $0.01$ (coarse) and $0.001$ (fine).

**3. Mip-Splatting Simplification [S4]:**
Standard 3DGS uses SSIM (weight 0.8) and L1 (weight 0.2). Mip-Splatting simplifies this to a single L2 loss for optimization.

**4. Defocus-Engineered Holography [S5]:**
Uses weights $\gamma=40$ and $\beta=20$ to balance in-focus vs. out-of-focus image contributions.

### Pseudocode
```python
def configure_loss(scene_type, stage, loss_terms):
    """
    Configures the loss function weights based on scene and stage.
    """
    weights = {}
    
    # Base weights for Neural Deformable Voxel Grid [S2]
    if stage == "coarse":
        weights["ptc"] = 0.1
        weights["bg"] = 0.01
        weights["d_tv"] = 1.0
        weights["d_norm"] = 0.1
    elif stage == "fine":
        weights["ptc"] = 0.01
        weights["bg"] = 0.001
        weights["d_tv"] = 1.0
        weights["d_norm"] = 0.01
        
    # Adjust for large motion scenes [S2]
    if scene_type == "large_motion":
        if stage == "coarse":
            weights["d_norm"] = 0.01
        elif stage == "fine":
            weights["d_norm"] = 0.001
            
    # RT-Splatting specific terms [S1, unofficial]
    if "rt_splatting" in loss_terms:
        weights["img"] = 1.0
        weights["n"] = 0.05
        weights["mask"] = 0.01
        # Internal img composition
        weights["l1"] = 0.8  # (1 - 0.2)
        weights["d_ssim"] = 0.2
        weights["perc"] = 0.01
        
    return weights
```

### Edge Cases and Pitfalls
*   **Repulsion Loss Removal:** Removing the repulsion loss ($L_{rep}$) during sphere cloud training causes spheres to clump together instead of covering the object, leading to poor reconstructions [S3].
*   **Offset Regularization Strength:** In Palette-based networks, if $\lambda_\delta = 0$, the model over-relies on offsets instead of palette colors, failing to predict correctly. If $\lambda_\delta$ is too large, it over-relies on palette colors, reducing accuracy. A value of 0.1 is typical [S11].
*   **MS-SSIM Usage:** Using MS-SSIM loss instead of MSE loss in defocus-engineered holography resulted in unclear effects and defects in the optimized depth-encoded hologram [S5].
*   **Hybrid Gradient Alignment:** When initial and target shapes are already well-aligned, RGBXY derivatives (used in early stages of hybrid strategies) may lead to inaccurate matching due to approximated optimal transport [S6].

## Subtopics

### [Two-Stage Photometric and Perceptual Training Strategy](9931-two-stage-photometric-and-perceptual-training-strategy.md)
This strategy optimizes feed-forward radiance field networks (specifically SplatVoxel) by decoupling the learning of multi-view consistency from fine-grained voxel attribute refinement. It addresses the instability of jointly training multi-view and voxel transformers by first establishing a robust multi-view backbone before fine-tuning the full system. It differs from standard single-stage optimization by using distinct perceptual weighting factors for the two transformer branches to balance structural consistency and photometric accuracy. [9931-two-stage-photometric-and-perceptual-training-strategy.md]

### [Overall Training Objective](13444-overall-training-objective.md)
The Overall Training Objective defines the composite loss function used to optimize radiance fields, balancing pixel-wise fidelity, structural similarity, perceptual quality, and adversarial constraints. It differs from single-metric approaches by combining multiple perceptual and pixel-wise metrics to supervise optimization, addressing the problem of generating high-fidelity, visually consistent rendered images. It excludes explicit physical priors like visibility or normal consistency unless specified by a variant. [13444-overall-training-objective.md]

### Hybrid Gradients
A strategy combining RGBXY derivatives and standard derivatives to leverage global matching in early stages and precise local alignment in late stages. It uses RGBXY derivatives for the first 75% of optimization iterations and switches to standard derivatives for the last 25%. A pitfall is that when initial and target shapes are already aligned very well, the approximated optimal transport method may lead to inaccurate matching, making RGBXY derivatives less effective. [S6]

### Sky Loss
Computes a sky label as $1.0 - \text{sky}$ (converted to float). For density fields, it computes binary cross entropy between the sum of density weights (clipped to $[10^{-3}, 1-10^{-3}]$) and the sky label, multiplied by 0.01. For occupancy fields, it computes a similar loss (`osky_loss`) with the same weight. [S7, unofficial]

### Color Palette Sparsity Loss
Adopted from PaletteNeRF, this loss measures the sparsity of the learned color palette $\hat{P}$. Formula: $\mathcal{L}_{\text {sp}} = \frac {\sum _{i=1}^{N_{\hat{P}}} \hat{w}_i}{\sum _{i=1}^{N_{\hat{P}}} \hat{w}_i^2} - 1$, where $\hat{w}_i$ is the per-palette weight. [S8]

### Shape Part Addition Loss
A loss function for adding a local part to a shape instance, fitting the network to a composite image of the original and a copied region from another instance. The user selects views, scribbles regions to copy and paste, and the network renders the composite. The loss $L_{add}$ is optimized using Adam with learning rate $10^{-2}$. Regularization weight $\lambda_{reg}$ is 10. [S9]

### Skinning Weights Weak Supervision
Regularization to ensure Gaussian skinning weights generalize by supervising them with SMPL skinning weights based on proximity. Formula: $L_{skn} = \sum_i \text{ReLU}(\|w(g_i) - w(v_i)\|_2^2 - \tau_{skn} \|v_i - p_i\|_2)$, where $w(g_i)$ is Gaussian skinning weight, $w(v_i)$ is SMPL vertex skinning weight, $v_i$ is nearest vertex, $p_i$ is Gaussian canonical position, and $\tau_{skn}$ is a threshold. A pitfall is that the gradient of the distance term $\|v_i - p_i\|_2$ should not be backpropagated. [S10]

### Offset Regularization
Regularization for the offset loss with strength $\lambda_\delta$. Typical value is 0.1. If $\lambda_\delta = 0$, the PCN fails to predict correctly by over-relying on offsets. If $\lambda_\delta$ is too large, it over-relies on palette colors, resulting in less accurate reconstruction. [S11]

### Loss Term Configuration
Specifically regarding entropy loss ($L_{entr}$). Without $L_{entr}$, the separation between static and dynamic radiance becomes ambiguous. $L_{entr}$ encourages static and dynamic radiance separation, improving object renderings and scene decomposition. [S12]

## Operating characteristics
*   **Complexity:** The computational overhead of configuring the loss is negligible compared to the forward/backward passes of the radiance field itself. However, the *choice* of loss terms significantly impacts convergence speed and memory usage (e.g., perceptual losses require feature extraction networks).
*   **Performance:** Simplifying to L2 loss (Mip-Splatting) yields PSNR of 28.57 on Mip-NeRF 360, comparable to L1+SSIM (28.57) and better than SSIM alone (28.34) or L2+SSIM (27.17) [S4].
*   **Strengths:** Proper weighting prevents mode collapse (e.g., sphere clumping) and handles specific artifacts (specular, defocus).
*   **Limitations:** Requires careful tuning per scene type (e.g., large motion vs. static). Incorrect weights can lead to ambiguous decompositions or poor generalization.

## Background
Loss function configuration has evolved alongside radiance field optimization. Early methods like 3DGS used fixed weights for L1 and SSIM [S4]. Subsequent works introduced stage-specific weighting [S2], hybrid gradient strategies [S6], and specialized regularizations for specific tasks like relighting [S1, unofficial], dynamic scenes [S2], and stylization [S8, S11]. The removal of redundant terms (like repulsion loss in sphere-guided methods [S3]) and the introduction of entropy-based separation [S12] reflect ongoing efforts to stabilize and improve the fidelity of differentiable volume rendering.
