# Skinning Weights Weak Supervision

Also called: Weak Supervision for Gaussian Skinning Weights

## Overview
This method regularizes the skinning weights of 3D Gaussians by supervising them with ground-truth skinning weights from the SMPL parametric human model [S1]. It addresses the problem that training on a limited amount of gestures typically yields skinning weights that do not generalize well to novel poses [S1]. Unlike sibling methods that optimize photometric or perceptual image fidelity, this approach focuses specifically on the geometric consistency of deformation weights [G].

## How it works
**Inputs:**
- $G$: Set of $N$ Gaussians.
- $P$: Canonical positions of Gaussians, $p_i \in \mathbb{R}^3$.
- $W_G$: Learned skinning weights for Gaussians, $w(g_i) \in \mathbb{R}^{24}$ [S2].
- $V$: Vertices of the canonical SMPL mesh.
- $W_S$: Ground-truth SMPL skinning weights for vertices, $w(v_i) \in \mathbb{R}^{24}$ [S2].
- $\tau_{skn}$: Threshold parameter [S1].

**Outputs:**
- Scalar loss value $L_{skn}$.

**Data Structures:**
- Skinning weights are vectors of size 24, corresponding to the 24 bones of the SMPL model [G].
- The distance metric is the Euclidean distance in 3D space [G].

**Steps:**
1. For each Gaussian $i$ with canonical position $p_i$:
   a. Find the nearest vertex $v_i$ on the canonical SMPL mesh to $p_i$ [G].
   b. Retrieve the ground-truth skinning weight vector $w(v_i)$ for vertex $v_i$ [S1].
   c. Retrieve the current learned skinning weight vector $w(g_i)$ for Gaussian $i$ [S1].
   d. Compute the Euclidean distance between the Gaussian and the nearest vertex: $d_i = \|v_i - p_i\|_2$ [S1].
   e. Compute the squared L2 distance between the skinning weight vectors: $\Delta w_i = \|w(g_i) - w(v_i)\|_2^2$ [S1].
   f. Compute the loss term for this Gaussian: $l_i = \text{ReLU}(\Delta w_i - \tau_{skn} \cdot d_i)$ [S1].
2. Sum the loss terms over all Gaussians: $L_{skn} = \sum_i l_i$ [S1].

**Formula:**
$$L_{skn} = \sum_i \text{ReLU}(\|w(g_i) - w(v_i)\|_2^2 - \tau_{skn} \|v_i - p_i\|_2)$$ [S1]

Where:
- $w(g_i)$ is the skinning weight vector of Gaussian $i$ [S1].
- $w(v_i)$ is the skinning weight vector of the nearest SMPL vertex $v_i$ [S1].
- $v_i$ is the position of the nearest SMPL vertex to Gaussian $i$ [S1].
- $p_i$ is the canonical position of Gaussian $i$ [S1].
- $\tau_{skn}$ is a threshold parameter controlling the trade-off between weight similarity and spatial proximity [S1].

**Parameters:**
- $\tau_{skn}$: Not given in the sources. [S1]

**Pitfalls:**
- Do not backpropagate the gradient of the distance term $\|v_i - p_i\|_2$ through this loss [S1]. The distance term acts as a static threshold modifier; its gradient must be stopped to prevent instability in the nearest-vertex search or spatial optimization [G].

**Pseudocode:**
```python
def compute_skinning_weak_supervision_loss(gaussians, smpl_mesh, tau_skn):
    """
    Computes the skinning weights weak supervision loss.
    
    Args:
        gaussians: List of tuples (canonical_position, skinning_weights)
        smpl_mesh: Object with method nearest_vertex(position) returning (vertex_position, vertex_skinning_weights)
        tau_skn: Float threshold parameter.
            
    Returns:
        Scalar loss value.
    """
    total_loss = 0.0
    
    for p_i, w_g in gaussians:
        v_i, w_v = smpl_mesh.nearest_vertex(p_i)
        
        # Compute Euclidean distance (gradient stopped for spatial term)
        spatial_dist = sum((v_i[j] - p_i[j])**2 for j in range(3)) ** 0.5
        
        # Compute squared L2 distance between skinning weights
        weight_diff_sq = sum((w_g[k] - w_v[k])**2 for k in range(24))
        
        # Compute loss term: ReLU(weight_diff_sq - tau_skn * spatial_dist)
        loss_term = weight_diff_sq - tau_skn * spatial_dist
        loss_term = loss_term if loss_term > 0 else 0.0
        
        total_loss += loss_term
        
    return total_loss
```

## Subtopics

### Skinning Loss
A variant that regularizes a forward LBS network directly in canonical space [S2]. It samples 1024 points on the canonical SMPL surface and minimizes the L1 distance between the network's output skinning weights and the ground-truth SMPL skinning weights for 24 bones [S2]. The loss is averaged over the sampled points [S2]. Formula: $L_S = \frac{1}{|P|} \sum_{\hat{x} \in \hat{X}_S, w \in W} \sum_{i=1}^{24} | f_{\sigma_\omega}(\hat{x})_i - w_i |$, where $|P|=1024$ [S2].

## Background
Originated in "Human Gaussian Splatting: Real-Time Rendering of Animatable Avatars" (CVPR 2024) [S1]. It was introduced to address the issue that training on a limited amount of gestures leads to skinning weights that do not generalize well [S1]. The method softly supervises Gaussian skinning weights with SMPL skinning weights based on proximity [S1].
