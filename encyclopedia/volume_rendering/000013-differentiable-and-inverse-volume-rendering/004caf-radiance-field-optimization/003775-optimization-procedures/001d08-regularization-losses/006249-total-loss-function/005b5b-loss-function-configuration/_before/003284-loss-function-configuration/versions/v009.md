# Loss Function Configuration

Also called: Loss Weighting Scheme, Loss function parameter configuration, Removing Repulsion Loss, Total Training Loss, Training Loss Weights, w/o Lrep

## Overview
Loss function configuration defines the composite objective, weighting hyperparameters, and optimization schedules used to train differentiable radiance fields. It combines geometric reconstruction fidelity with perceptual and semantic constraints to guide the neural network toward the desired visual output. It differs from simple reconstruction objectives by integrating high-level perceptual metrics (SSIM, LPIPS) and, in stylization variants, contrastive text-image alignment losses.

## How it works
### Inputs and Outputs
**Inputs:**
- Rendered images $\hat{I}$ and ground-truth images $I$.
- Predicted geometric fields (density $\sigma$, occupancy, normals $\mathbf{n}$, depth $d$).
- Optional auxiliary data: sky labels, depth maps with defocus blur, varifocal images.
- Optimization state: current iteration count, stage (coarse/fine).

**Outputs:**
- Scalar total loss value $\mathcal{L}$ and its gradients for backpropagation.

### Data Structures
No specific complex data structures are required beyond standard tensor layouts for images and fields. The configuration is primarily defined by scalar hyperparameters and conditional logic based on iteration counts or scene properties.

### Formulas and Parameters

#### 1. General Composite Loss Structure
The total loss is typically a weighted sum of appearance, geometric consistency, and regularization terms.

$$ \mathcal{L} = \mathcal{L}_{\text{img}} + \lambda_{\text{n}}\mathcal{L}_{\text{n}} + \lambda_{\text{mask}}\mathcal{L}_{\text{mask}} $$

Where:
- $\mathcal{L}_{\text{img}}$: Appearance loss.
- $\mathcal{L}_{\text{n}}$: Normal consistency loss.
- $\mathcal{L}_{\text{mask}}$: Transparent mask regularization loss.
- $\lambda_{\text{n}}$: Normal loss weight.
- $\lambda_{\text{mask}}$: Mask loss weight. [S1, unofficial]

#### 2. Appearance Loss ($\mathcal{L}_{\text{img}}$)
The appearance loss combines pixel-wise fidelity and perceptual similarity.

$$ \mathcal{L}_{\text{img}} = (1 - \lambda)\mathcal{L}_{1} + \lambda \mathcal{L}_{\text{D-SSIM}} + \lambda_{\text{perc}}\mathcal{L}_{\text{perc}} $$

Where:
- $\mathcal{L}_{1}$: L1 loss between rendered and ground-truth images.
- $\mathcal{L}_{\text{D-SSIM}}$: D-SSIM loss.
- $\mathcal{L}_{\text{perc}}$: Perceptual loss (e.g., from EnvGS).
- $\lambda$: D-SSIM weight.
- $\lambda_{\text{perc}}$: Perceptual loss weight. [S1, unofficial]

#### 3. Dynamic/Deformable Loss Structure
For dynamic scenes or deformable voxels, the loss includes photometric, perceptual, background, and deformation regularization terms.

$$ \mathcal{L} = \mathcal{L}_{\text{photo}} + w_{\text{ptc}} \cdot \mathcal{L}_{\text{ptc}} + w_{\text{bg}} \cdot \mathcal{L}_{\text{bg}} + w_{d\_norm} \cdot \mathcal{L}_{d\_norm} + w_{d\_tv} \cdot \mathcal{L}_{d\_tv} $$

Where:
- $\mathcal{L}_{\text{photo}}$: Photometric reconstruction loss.
- $\mathcal{L}_{\text{ptc}}$: Perceptual loss.
- $\mathcal{L}_{\text{bg}}$: Background loss.
- $\mathcal{L}_{d\_norm}$: Deformation norm regularization.
- $\mathcal{L}_{d\_tv}$: Total variation loss on deformation.
- $w_{\text{ptc}}, w_{\text{bg}}, w_{d\_norm}, w_{d\_tv}$: Weights for each term. [S2]

#### 4. Sky Loss
Used to suppress density/occupancy in sky regions.

For density field (NeRF-like):
$$ \mathcal{L}_{\text{sky}} = 0.01 \cdot \text{BCE}\left( \text{clip}\left(\sum_{d=1}^{D} \sigma_d, 10^{-3}, 1-10^{-3}\right), \text{sky\_label} \right) $$

For occupancy field:
$$ \mathcal{L}_{\text{osky}} = 0.01 \cdot \text{BCE}\left( \text{clip}\left(\sum_{d=1}^{D} o_d, 10^{-3}, 1-10^{-3}\right), \text{sky\_label} \right) $$

Where:
- $\text{sky\_label} = 1.0 - \text{float}(\text{batch['sky']})$.
- $\sigma_d, o_d$: Density/occupancy weights along the ray. [S7, unofficial]

#### 5. Color Palette Sparsity Loss
Measures sparsity of learned color palettes.

$$ \mathcal{L}_{\text{sp}} = \frac{\sum_{i=1}^{N_{\hat{P}}} \hat{w}_i}{\sum_{i=1}^{N_{\hat{P}}} \hat{w}_i^2} - 1 $$

Where:
- $\hat{w}_i$: Per-palette weight.
- $N_{\hat{P}}$: Number of palettes. [S8]

#### 6. Shape Part Addition Loss
Used for editing shape instances.

$$ \mathcal{L}_{\text{add}} = \mathcal{L}_{\text{rec}} + \lambda_{\text{reg}} \cdot \mathcal{L}_{\text{reg}} $$

Where:
- $\mathcal{L}_{\text{rec}}$: Reconstruction loss on foreground (pasted region) and background (original region).
- $\mathcal{L}_{\text{reg}}$: Regularization loss (e.g., weight difference from original model).
- $\lambda_{\text{reg}}$: Regularization weight. [S9]

### Parameters and Typical Values

#### RT-Splatting (Reflection-Transmission) [S1, unofficial]
- $\lambda$ (D-SSIM weight): 0.2
- $\lambda_{\text{perc}}$ (Perceptual loss weight): 0.01
- $\lambda_{\text{n}}$ (Normal consistency weight): 0.05
- $\lambda_{\text{mask}}$ (Transparent mask regularization weight): 0.01

#### Neural Deformable Voxel Grid [S2]
**Coarse Stage:**
- $w_{\text{ptc}}$: 0.1
- $w_{\text{bg}}$: 0.01
- $w_{d\_norm}$: 0.1
- $w_{d\_tv}$: 1

**Fine Stage:**
- $w_{\text{ptc}}$: 0.01
- $w_{\text{bg}}$: 0.001
- $w_{d\_norm}$: 0.01
- $w_{d\_tv}$: 1

**Large Motion Scenes ('Hell Warrior', 'Jumping Jacks', 'T-Rex'):**
- $w_{d\_norm}$ (Coarse): 0.01
- $w_{d\_norm}$ (Fine): 0.001

#### SplatVoxel [S6]
- $\lambda$ (LPIPS weight, multi-view transformer): 0.5
- $\lambda$ (LPIPS weight, voxel transformer): 4.0
- Batch size: 128
- Total iterations: 300K (200K Stage 1, 100K Stage 2)

#### Diffraction-engineered Holography [S4]
- Number of varifocal images: 21 (1 pixel larger than max blur circle diameter, e.g., 15px + margin).
- $\gamma$ (focal plane separation): 40
- $\beta$ (in-focus image weight compensation): 20

#### Editing Conditional Radiance Fields [S9]
- $\lambda_{\text{reg}}$ (Shape addition regularization): 10

### Steps and Implementation Logic

1.  **Initialize Weights:** Set hyperparameters based on the specific method variant (e.g., RT-Splatting vs. Deformable Voxels).
2.  **Render:** Compute rendered images $\hat{I}$ and auxiliary fields (normals, depth, occupancy) from the current radiance field parameters.
3.  **Compute Component Losses:**
    - Calculate $\mathcal{L}_{\text{img}}$ (L1, D-SSIM, Perceptual) or $\mathcal{L}_{\text{photo}}$ (MSE).
    - Calculate geometric losses ($\mathcal{L}_{\text{n}}$, $\mathcal{L}_{d\_norm}$, $\mathcal{L}_{d\_tv}$).
    - Calculate regularization losses ($\mathcal{L}_{\text{mask}}$, $\mathcal{L}_{\text{sky}}$, $\mathcal{L}_{\text{sp}}$).
4.  **Apply Weights:** Multiply each component by its configured weight ($\lambda$ or $w$).
5.  **Sum Total Loss:** Aggregate weighted components into $\mathcal{L}$.
6.  **Backpropagate:** Compute gradients and update parameters.

### Edge Cases and Pitfalls

-   **Repulsion Loss Removal:** In sphere-cloud guided training, removing the repulsion loss ($\mathcal{L}_{\text{rep}}$) causes spheres to clump together instead of covering the object, leading to poor reconstructions [S3].
-   **MS-SSIM Defects:** Using MS-SSIM loss instead of MSE/photometric loss in defocus-blur holography optimization can lead to defects in the reconstructed scene [S4].
-   **Hybrid Gradient Alignment:** When initial and target shapes are already well-aligned, RGBXY derivatives (based on optimal transport) may lead to inaccurate matching. A hybrid strategy switching to standard derivatives in the final 25% of iterations mitigates this [S5].
-   **Sky Label Clipping:** Density/occupancy sums for sky loss must be clipped to $[10^{-3}, 1-10^{-3}]$ before applying BCE to avoid gradient instability [S7, unofficial].

## Subtopics

### [Overall Training Objective](13444-overall-training-objective.md)
The Overall Training Objective defines the composite loss function and optimization schedule used to train differentiable radiance fields, specifically in the context of text-driven stylization and multi-baseline reconstruction. It combines geometric reconstruction fidelity with perceptual and semantic constraints to guide the neural network toward the desired visual output. It differs from simple reconstruction objectives by integrating high-level perceptual metrics (SSIM, LPIPS) and, in stylization variants, contrastive text-image alignment losses. [13444-overall-training-objective.md]

### Hybrid Gradients
A strategy combining RGBXY derivatives and standard derivatives to leverage global matching in early stages and precise local alignment in late stages. Use RGBXY derivatives for the first 75% of optimization iterations, then switch to standard derivatives for the last 25%. Pitfall: When initial and target shapes are already aligned very well, the approximated optimal transport method may lead to inaccurate matching, making RGBXY derivatives less effective. [S5]

### Two-Stage Photometric and Perceptual Training Strategy
A two-stage training strategy for the SplatVoxel feed-forward networks using photometric loss. Stage 1: Train the multi-view Transformer backbone for 200K iterations. Stage 2: Jointly fine-tune both the multi-view and voxel Transformers for an additional 100K iterations. Loss function: $\mathcal{L} = \mathcal{L}_{\text{MSE}}(\hat{I}, I) + \lambda \mathcal{L}_{\text{LPIPS}}(\hat{I}, I)$. Parameters: LPIPS weight $\lambda = 0.5$ for multi-view transformer, $\lambda = 4.0$ for voxel transformer. Batch size: 128. Total iterations: 300K. Used on multi-view static scene datasets like DL3DV. [S6]

### Sky Loss
Computes sky label as $1.0 - \text{batch['sky']}$. For density field, computes binary cross entropy between sum of density weights (clipped to $[10^{-3}, 1-10^{-3}]$) and sky label, multiplied by 0.01. For occupancy field, computes binary cross entropy between sum of occupancy weights (clipped to $[10^{-3}, 1-10^{-3}]$) and sky label, multiplied by 0.01. [S7, unofficial]

### Color Palette Sparsity Loss
A loss metric adopted from PaletteNeRF to measure the sparsity of the learned color palette $\hat{P}$. Formula: $\mathcal{L}_{\text{sp}} = \frac{\sum \hat{w}_i}{\sum \hat{w}_i^2} - 1$, where $\hat{w}_i$ is the per-palette weight. [S8]

### Shape Part Addition Loss
Loss function for adding a local part to a shape instance, fitting the network to a composite image of the original and a copied region from another instance. Construct composite image by copying a local region from a new instance to a paste location on the original view. Optimize $\mathcal{L}_{\text{add}} = \mathcal{L}_{\text{rec}} + \lambda_{\text{reg}} \cdot \mathcal{L}_{\text{reg}}$ using Adam optimizer with learning rate $10^{-2}$. Regularization weight $\lambda_{\text{reg}}$ is 10. [S9]

## Operating characteristics
-   **Time Complexity:** Depends on the number of loss components and the complexity of perceptual metrics (e.g., LPIPS requires a VGG network pass). Two-stage strategies (e.g., SplatVoxel) double the training time but improve convergence. [S6]
-   **Memory Complexity:** Low overhead for scalar weights. Perceptual losses (LPIPS, D-SSIM) require storing intermediate feature maps or loading pre-trained networks. [S1, unofficial][S6]
-   **Strengths:** Flexible combination of photometric, geometric, and perceptual cues allows for high-fidelity reconstruction and stylization. Adaptive weighting (e.g., coarse-to-fine) improves stability. [S2, S6]
-   **Limitations:** Sensitive to hyperparameter tuning (e.g., $\lambda_{\text{n}}$, $w_{d\_norm}$). Incorrect weighting can lead to artifacts (e.g., clumping without repulsion loss, defects with MS-SSIM). [S3, S4]
-   **When to Use:** When training differentiable radiance fields requires balancing multiple objectives (appearance, geometry, regularization). Essential for dynamic scenes, stylization, and editing tasks. [S1, unofficial][S6, S9]
-   **When Not to Use:** For simple static scene reconstruction where basic photometric loss suffices, or when computational resources are severely limited and perceptual losses are too expensive. [S4]

## Background
Loss function configuration has evolved alongside differentiable rendering techniques. Early methods relied primarily on photometric (L1/MSE) losses. As radiance fields became more complex (dynamic, stylized, editable), additional constraints were introduced: normal consistency for geometry [S1, unofficial], perceptual losses (LPIPS, SSIM) for visual quality [S1, unofficial][S6], and regularization for sparsity and editing [S8, S9]. The separation of coarse and fine training stages [S2] and hybrid gradient strategies [S5] reflect efforts to stabilize optimization in high-dimensional spaces. Specific applications like holography [S4] and sky suppression [S7, unofficial] introduced specialized loss terms.
