# Efficient O(N) Distortion Loss

Also called: Distortion Regularizer, Linear-time Distortion Loss, MipNeRF360 Distortion Loss, O(N) Distortion Loss

## Overview
The Efficient O(N) Distortion Loss is a regularization term used in differentiable volume rendering to suppress "floaters" (small, disconnected regions of volumetrically dense space) and "background collapse" (distant surfaces incorrectly modeled as semi-transparent clouds close to the camera) [S1]. It minimizes the integral of distances between all pairs of points along the 1D step function parameterized by ray distances and weights [S1]. It sets itself apart from sibling regularizers like Total Variation by directly enforcing compactness along the ray parameterization, and from naive implementations by reducing computational complexity from $O(N^2)$ to $O(N)$, enabling its use with high sample counts (>256 points per ray) without excessive GPU memory consumption [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   $\mathbf{s}$: Array of normalized ray distances for $N$ samples per ray, shape $(N,)$ or $(B, N)$ for batched rays. Values are non-linearly normalized from near-far clipping distances to $[0, 1]$ [S1][S2, unofficial].
    *   $\mathbf{w}$: Array of accumulated weights (opacity contributions) for $N$ samples per ray, shape $(N,)$ or $(B, N)$.
    *   $\lambda$: Scalar hyperparameter balancing the distortion loss against the data reconstruction loss [S1].
*   **Outputs:**
    *   $\mathcal{L}_{\text{dist}}$: Scalar distortion loss value.
    *   $\nabla_{\mathbf{w}} \mathcal{L}_{\text{dist}}$: Gradient of the loss with respect to weights, shape $(N,)$ or $(B, N)$ [S2, unofficial].

**Data Structures:**
*   **Midpoints ($\mathbf{m}$):** Array of length $N$, where $m_i = (s_i + s_{i+1}) / 2$. Note: For the last sample $N-1$, $s_N$ is typically the far clipping plane or handled via boundary conditions. The sources assume $s$ defines intervals $[s_i, s_{i+1})$ [S1][S2, unofficial].
*   **Prefix/Suffix Sums:** Temporary arrays of length $N$ storing cumulative sums of $\mathbf{w}$ and $\mathbf{w} \odot \mathbf{m}$ to enable $O(1)$ lookup during the $O(N)$ computation [S2, unofficial].

**Numbered Steps:**
1.  **Compute Midpoints:** Calculate the midpoint of each interval: $m_i = \frac{s_i + s_{i+1}}{2}$ for $i = 0, \dots, N-1$. Ensure $m_i < m_{i+1}$ [S2, unofficial].
2.  **Compute Second Term:** Calculate the weighted interval size term:
    $$ \mathcal{L}_{\text{dist}}^{\text{2nd}} = \frac{1}{3} \sum_{i=0}^{N-1} w_i^2 (s_{i+1} - s_i) $$
    This term minimizes the weighted size of each individual interval [S1][S2, unofficial].
3.  **Compute Prefix/Suffix Sums for First Term:**
    *   Compute prefix sums of weights: $P_w[k] = \sum_{j=0}^{k-1} w_j$ for $k=1, \dots, N$, with $P_w[0]=0$.
    *   Compute prefix sums of weighted midpoints: $P_{wm}[k] = \sum_{j=0}^{k-1} w_j m_j$ for $k=1, \dots, N$, with $P_{wm}[0]=0$.
    *   Compute suffix sums of weights: $S_w[k] = \sum_{j=k+1}^{N-1} w_j$ for $k=0, \dots, N-2$, with $S_w[N-1]=0$.
    *   Compute suffix sums of weighted midpoints: $S_{wm}[k] = \sum_{j=k+1}^{N-1} w_j m_j$ for $k=0, \dots, N-2$, with $S_{wm}[N-1]=0$.
    These allow direct lookup of inner summations [S2, unofficial].
4.  **Compute First Term (O(N)):**
    The first term of the distortion loss is:
    $$ \mathcal{L}_{\text{dist}}^{\text{1st}} = \sum_{i=0}^{N-1} \sum_{j=0}^{N-1} w_i w_j |m_i - m_j| $$
    By eliminating the diagonal ($i=j$) and exploiting symmetry ($|m_i - m_j| = m_i - m_j$ for $i > j$), this is rewritten as:
    $$ \mathcal{L}_{\text{dist}}^{\text{1st}} = 2 \sum_{i=1}^{N-1} w_i m_i \left( \sum_{j=0}^{i-1} w_j \right) - 2 \sum_{i=1}^{N-1} w_i \left( \sum_{j=0}^{i-1} w_j m_j \right) $$
    Using the prefix sums from Step 3:
    $$ \mathcal{L}_{\text{dist}}^{\text{1st}} = 2 \sum_{i=1}^{N-1} w_i m_i P_w[i] - 2 \sum_{i=1}^{N-1} w_i P_{wm}[i] $$
    This computation is $O(N)$ [S2, unofficial].
5.  **Combine Terms:**
    $$ \mathcal{L}_{\text{dist}} = \mathcal{L}_{\text{dist}}^{\text{1st}} + \mathcal{L}_{\text{dist}}^{\text{2nd}} $$
    [S1][S2, unofficial].
6.  **Compute Gradients (Optional but required for backprop):**
    The gradient with respect to $w_k$ for the first term is:
    $$ \frac{\partial}{\partial w_k} \mathcal{L}_{\text{dist}}^{\text{1st}} = 2m_k P_w[k] - 2 P_{wm}[k] + 2 S_{wm}[k] - 2m_k S_w[k] $$
    The gradient for the second term is:
    $$ \frac{\partial}{\partial w_k} \mathcal{L}_{\text{dist}}^{\text{2nd}} = \frac{2}{3} w_k (s_{k+1} - s_k) $$
    Total gradient: $\frac{\partial \mathcal{L}_{\text{dist}}}{\partial w_k} = \frac{\partial \mathcal{L}_{\text{dist}}^{\text{1st}}}{\partial w_k} + \frac{\partial \mathcal{L}_{\text{dist}}^{\text{2nd}}}{\partial w_k}$ [S2, unofficial].

**Formulas:**
*   **Distortion Loss:**
    $$ \mathcal{L}_{\text{dist}}(\mathbf{s}, \mathbf{w}) = \sum_{i=0}^{N-1} \sum_{j=0}^{N-1} w_i w_j \left| \frac{s_i + s_{i+1}}{2} - \frac{s_j + s_{j+1}}{2} \right| + \frac{1}{3} \sum_{i=0}^{N-1} w_i^2 (s_{i+1} - s_i) $$
    [S1][S2, unofficial].
*   **Normalized Distances:** $s_i$ are non-linearly normalized ray distances mapped to $[0, 1]$ [S1][S2, unofficial].
*   **Hyperparameter:** $\lambda$ balances $\mathcal{L}_{\text{recon}}$ and $\mathcal{L}_{\text{dist}}$. Typical value: 0.01 [S1].

**Pseudocode:**
```python
import torch

def efficient_distortion_loss(s, w, lambda_dist=0.01):
    """
    Computes the O(N) distortion loss and its gradient w.r.t w.
    
    Args:
        s: Tensor of shape (N,) or (B, N), normalized ray distances [0, 1].
        w: Tensor of shape (N,) or (B, N), accumulated weights.
        lambda_dist: Scalar weight for the distortion loss.
        
    Returns:
        loss: Scalar tensor, the total distortion loss.
        grad_w: Tensor of shape (N,) or (B, N), gradient of loss w.r.t w.
    """
    # Ensure s is sorted and has N+1 points to define N intervals
    # s shape: (N+1,) or (B, N+1). If input s is (N,), assume uniform or handle accordingly.
    # Based on sources, s defines intervals [s_i, s_{i+1}). 
    # We assume s has length N+1. If w has length N, s must have length N+1.
    
    # Handle batch dimension
    if s.dim() == 1:
        s = s.unsqueeze(0)
        w = w.unsqueeze(0)
        batched = False
    else:
        batched = True
        
    B, N_plus_1 = s.shape
    N = N_plus_1 - 1
    
    # 1. Compute midpoints m_i = (s_i + s_{i+1}) / 2
    # m shape: (B, N)
    m = (s[:, :N] + s[:, 1:]) / 2.0
    
    # 2. Compute interval lengths
    # lengths shape: (B, N)
    lengths = s[:, 1:] - s[:, :N]
    
    # 3. Compute Second Term: 1/3 * sum(w_i^2 * length_i)
    # term2 shape: (B,)
    term2 = (1.0 / 3.0) * (w * w * lengths).sum(dim=1)
    
    # 4. Compute Prefix and Suffix Sums for First Term
    # prefix_w[k] = sum(w[0]...w[k-1])
    # prefix_wm[k] = sum(w[0]*m[0]...w[k-1]*m[k-1])
    # We need these for indices 1 to N-1 in the summation formula.
    
    # Cumsum along dim=1
    prefix_w = torch.cumsum(w, dim=1) # shape (B, N)
    prefix_wm = torch.cumsum(w * m, dim=1) # shape (B, N)
    
    # Shift prefix sums to align with index i in the formula sum_{j=0}^{i-1}
    # For i=1, we need sum_{j=0}^{0} w_j = w[0]. prefix_w[:, 0] is w[0].
    # The formula uses P_w[i] which is sum_{j=0}^{i-1} w_j.
    # In PyTorch cumsum, prefix_w[:, i] is sum_{j=0}^{i} w_j.
    # So we need prefix_w[:, i-1] for the term sum_{j=0}^{i-1} w_j.
    
    # To avoid index errors, we pad or shift.
    # Let's compute P_w[i] = sum_{j=0}^{i-1} w_j.
    # P_w[0] = 0. P_w[1] = w[0]. P_w[2] = w[0]+w[1].
    # We can create a shifted version.
    
    # Pad with zeros at the beginning
    w_padded = torch.cat([torch.zeros(B, 1, device=w.device), w], dim=1) # (B, N+1)
    wm_padded = torch.cat([torch.zeros(B, 1, device=w.device), w * m], dim=1) # (B, N+1)
    
    P_w = torch.cumsum(w_padded, dim=1)[:, :N] # (B, N), P_w[i] = sum_{j=0}^{i-1} w_j
    P_wm = torch.cumsum(wm_padded, dim=1)[:, :N] # (B, N), P_Wm[i] = sum_{j=0}^{i-1} w_j m_j
    
    # Suffix sums: S_w[k] = sum_{j=k+1}^{N-1} w_j
    # S_w[N-1] = 0.
    # Reverse cumsum
    w_rev = torch.flip(w, dims=[1])
    wm_rev = torch.flip(w * m, dims=[1])
    
    S_w_rev = torch.cumsum(w_rev, dim=1) # (B, N)
    S_wm_rev = torch.cumsum(wm_rev, dim=1) # (B, N)
    
    # Flip back to get suffix sums in original order
    # S_w[k] corresponds to S_w_rev[N-1-k]
    S_w = torch.flip(S_w_rev, dims=[1]) # (B, N)
    S_wm = torch.flip(S_wm_rev, dims=[1]) # (B, N)
    
    # 5. Compute First Term: 2 * sum_{i=1}^{N-1} [ w_i m_i P_w[i] - w_i P_Wm[i] ]
    # Note: The formula sums from i=1 to N-1.
    # We can compute the full sum and subtract i=0 term (which is 0 anyway) or mask.
    # Let's compute for all i and mask out i=0 if necessary, but w[0]*m[0]*P_w[0] is 0.
    
    term1_part1 = 2.0 * (w * m * P_w).sum(dim=1)
    term1_part2 = 2.0 * (w * P_Wm).sum(dim=1)
    
    term1 = term1_part1 - term1_part2
    
    # 6. Total Loss
    loss = term1 + term2
    
    # 7. Gradients w.r.t w
    # dL/dw_k for term2: 2/3 * w_k * length_k
    grad_w_term2 = (2.0 / 3.0) * w * lengths
    
    # dL/dw_k for term1:
    # From source [S2, unofficial]:
    # 2 * m_k * P_w[k] - 2 * P_Wm[k] + 2 * S_Wm[k] - 2 * m_k * S_w[k]
    # Note: P_w[k] in source is sum_{j=0}^{k-1} w_j. This matches our P_w[:, k].
    
    grad_w_term1 = 2.0 * m * P_w - 2.0 * P_Wm + 2.0 * S_Wm - 2.0 * m * S_w
    
    grad_w = grad_w_term1 + grad_w_term2
    
    # Scale by lambda if needed for the final loss value, but gradients should be scaled too
    # Usually lambda is applied to the loss, so gradients are also scaled.
    loss = lambda_dist * loss
    grad_w = lambda_dist * grad_w
    
    if not batched:
        loss = loss.squeeze(0)
        grad_w = grad_w.squeeze(0)
        
    return loss, grad_w
```

**Parameters:**
*   $\lambda$ (or `lambda_distortion`): Weight for the distortion loss. Typical value: 0.01 [S1][S3, unofficial].
*   $N$: Number of sampled points per ray. The efficient implementation supports uneven numbers of sampled points across different rays [S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Unnormalized Distances:** Using unnormalized ray distances $t$ instead of normalized $s$ significantly upweights distant intervals, causing nearby intervals to be effectively ignored [S1].
*   **Memory Usage:** Naive $O(N^2)$ implementations consume excessive GPU memory (>3GB for a batch of 4,096 rays with >256 samples per ray) [S2, unofficial].
*   **Boundary Conditions:** The definition of $s_{N}$ (far clipping) and $s_{0}$ (near clipping) must be consistent with the weight accumulation. The loss assumes intervals $[s_i, s_{i+1})$ [S1][S2, unofficial].

## Subtopics

### Total Variation Regularization
Enforces spatial smoothness of density/color fields. Choose when geometric smoothness is prioritized over ray-wise compactness. [Total Variation Regularization](860-total-variation-regularization.md)

### Output Noise Regularization
Injects noise into density to prevent floaters. Less effective than distortion loss at preventing background collapse. [Output Noise Regularization](928-output-noise-regularization.md)

### Beta Distribution Prior on Exit Opacity
Priors on opacity distributions. Choose when explicit opacity modeling is required. [Beta Distribution Prior on Exit Opacity](2274-beta-distribution-prior-on-exit-opacity.md)

## Operating characteristics
*   **Time Complexity:** $O(N)$ per ray, where $N$ is the number of samples. This is a significant improvement over the naive $O(N^2)$ implementation [S2, unofficial].
*   **Memory Complexity:** $O(N)$ per ray for storing prefix/suffix sums. Avoids the $O(N^2)$ memory footprint of the naive pairwise distance matrix [S2, unofficial].
*   **Measured Performance:** The efficient implementation allows for >256 samples per ray without prohibitive memory usage, improving training speed and rendering quality by suppressing artifacts [S2, unofficial].
*   **Strengths:** Effectively eliminates floaters and background collapse without reducing reconstruction quality, outperforming noise-injection methods [S1]. Enables high-resolution sampling [S2, unofficial].
*   **Limitations:** Requires normalized ray distances. The gradient computation is more complex than simple MSE [S1][S2, unofficial].
*   **When to Use:** When training NeRF-like models with high sample counts per ray and observing floaters or background collapse artifacts.
*   **When Not to Use:** When computational resources are extremely limited and $N$ is very small (where $O(N^2)$ is negligible), or when ray-wise compactness is not a desired property.

## Background
The distortion loss was proposed in MipNeRF 360 [S1]. It was designed to address artifacts common in neural radiance fields, specifically "floaters" and "background collapse" [S1]. The efficient $O(N)$ implementation was later developed and popularized in DirectVoxGO and other subsequent works to handle larger sample counts [S2, unofficial]. It is widely used in modern differentiable volume rendering pipelines [S3, unofficial].
