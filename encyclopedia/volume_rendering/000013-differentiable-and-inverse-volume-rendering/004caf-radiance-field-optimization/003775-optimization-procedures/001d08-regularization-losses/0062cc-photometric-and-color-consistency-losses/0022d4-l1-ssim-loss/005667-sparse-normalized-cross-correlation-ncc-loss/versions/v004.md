# Sparse Normalized Cross-Correlation (NCC) Loss
Also called: Tile-wise Structure-Aware Loss
## Overview
A local structure-aware loss that provides sparse yet effective supervision to preserve fine details and stabilize training by measuring sparse Normalized Cross-Correlation (NCC) [S1, unofficial]. It sets itself apart from dense photometric losses by operating only on per-tile sparsely sampled pixels, prioritizing challenging regions while skipping well-reconstructed ones to avoid redundant gradient computation [S1, unofficial].
## How it works
**Inputs and Outputs:**
- Input: A set of sparsely sampled pixels per tile, driven by multi-view reconstruction errors [S1, unofficial]. Let $P_{tile}$ be the set of pixel coordinates in a tile [G]. For each pixel $p \in P_{tile}$, inputs are the rendered color $C_r(p)$ and the ground truth color $C_g(p)$ [G].
- Output: A scalar loss value $L_{NCC}$ for the tile [G].

**Data Structures:**
- Per-tile error map: Maintained online to prioritize per-iteration rasterization and gradient backpropagation on challenging regions [S1, unofficial].
- Sparse pixel set $P_{tile}$: A subset of pixels within a tile, selected based on the error map [S1, unofficial].

**Steps:**
1. **Sparse Sampling:** Select pixels $P_{tile}$ for each tile based on the online-maintained multi-view error map. Pixels with high reconstruction error are prioritized; well-reconstructed regions are skipped [S1, unofficial].
2. **Compute Local Statistics:** For the set $P_{tile}$, compute the mean and variance of the rendered and ground truth colors [G]. Let $N = |P_{tile}|$ [G].
   - $\mu_r = \frac{1}{N} \sum_{p \in P_{tile}} C_r(p)$ [G]
   - $\mu_g = \frac{1}{N} \sum_{p \in P_{tile}} C_g(p)$ [G]
   - $\sigma_r^2 = \frac{1}{N} \sum_{p \in P_{tile}} (C_r(p) - \mu_r)^2$ [G]
   - $\sigma_g^2 = \frac{1}{N} \sum_{p \in P_{tile}} (C_g(p) - \mu_g)^2$ [G]
3. **Compute Covariance:** Calculate the covariance between rendered and ground truth colors over the sparse set [G].
   - $\sigma_{rg} = \frac{1}{N} \sum_{p \in P_{tile}} (C_r(p) - \mu_r)(C_g(p) - \mu_g)$ [G]
4. **Compute NCC:** Calculate the Normalized Cross-Correlation coefficient $\rho$ [G].
   - $\rho = \frac{\sigma_{rg}}{\sqrt{\sigma_r^2 \sigma_g^2 + \epsilon}}$ [G]
   where $\epsilon$ is a small constant for numerical stability [G].
5. **Compute Loss:** The loss is derived from the NCC score as $L_{NCC} = 1 - \rho$ to minimize dissimilarity [G].

**Parameters:**
- Tile size: Not given in the sources. [G]
- Sparsity ratio: Not given in the sources. [G]
- $\epsilon$: Not given in the sources. [G]

**Edge Cases and Pitfalls:**
- Degenerate tiles: If a tile has no selected pixels or all selected pixels have zero variance, NCC is undefined. Guard against division by zero with $\epsilon$ [G].
- Sparse bias: If sampling is too sparse, the local statistics may not represent the tile's structure accurately [G].

**Pseudocode:**
```python
def sparse_ncc_loss(rendered_colors, ground_truth_colors, epsilon=1e-8):
    # rendered_colors and ground_truth_colors are lists of N RGB vectors
    N = len(rendered_colors)
    if N == 0:
        return 0.0
    channels = len(rendered_colors[0])
    mu_r = [sum(c[i] for c in rendered_colors) / N for i in range(channels)]
    mu_g = [sum(c[i] for c in ground_truth_colors) / N for i in range(channels)]
    var_r = [sum((c[i] - mu_r[i])**2 for c in rendered_colors) / N for i in range(channels)]
    var_g = [sum((c[i] - mu_g[i])**2 for c in ground_truth_colors) / N for i in range(channels)]
    cov_rg = [sum((c[i] - mu_r[i]) * (gt[i] - mu_g[i]) for c, gt in zip(rendered_colors, ground_truth_colors)) / N for i in range(channels)]
    ncc = [cov_rg[i] / ((var_r[i] * var_g[i]) + epsilon)**0.5 for i in range(channels)]
    ncc = [max(-1.0, min(1.0, v)) for v in ncc]
    return 1.0 - sum(ncc) / channels
```
## Subtopics

### [Hybrid Loss Gradient](15696-hybrid-loss-gradient.md)
The Hybrid Loss Gradient is a gradient computation method used in sparse optimization for volume rendering and 3D Gaussian Splatting. It stabilizes training under sparse pixel supervision by combining a pixel-wise Charbonnier $\ell_1$ term with a tile-level sparse Normalized Cross-Correlation (NCC) term. It sets itself apart from dense optimization by maintaining gradient alignment with the full objective through importance sampling, and from pure photometric losses by incorporating structural consistency via NCC. It builds on [Sparse Normalized Cross-Correlation (NCC) Loss](15693-sparse-normalized-cross-correlation-ncc-loss.md).

## Operating characteristics
- **Time Complexity:** Depends on the number of sparse pixels per tile [G].
- **Memory Complexity:** Requires storing per-tile error maps and sparse pixel indices [S1, unofficial].
- **Measured Performance:** TurboGS delivers on par or superior rendering quality within 100 seconds (up to ~10× training speedup over vanilla 3DGS) [S1, unofficial].
- **Strengths:** Preserves fine details, stabilizes training, avoids redundant gradient computation in well-reconstructed regions [S1, unofficial].
- **Limitations:** Performance depends on the quality of the error-driven sampling. If sampling is poor, structural details may be lost [G].
- **When to use:** When training speed is critical and fine detail preservation is important, especially in challenging regions [S1, unofficial].
- **When not to use:** When uniform supervision is required or when the error map is unreliable [G].
