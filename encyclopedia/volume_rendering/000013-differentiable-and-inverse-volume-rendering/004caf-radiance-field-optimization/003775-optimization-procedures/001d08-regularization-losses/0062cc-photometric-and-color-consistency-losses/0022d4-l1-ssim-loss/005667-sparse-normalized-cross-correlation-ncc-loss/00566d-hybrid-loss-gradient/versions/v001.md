# Hybrid Loss Gradient

Also called: Gradient Computation under Sparse Supervision, Sparse Gradient Estimation

## Overview
The Hybrid Loss Gradient is a gradient computation method used in sparse optimization for volume rendering and 3D Gaussian Splatting. It stabilizes training under sparse pixel supervision by combining a pixel-wise Charbonnier $\ell_1$ term with a tile-level sparse Normalized Cross-Correlation (NCC) term. It sets itself apart from dense optimization by maintaining gradient alignment with the full objective through importance sampling, and from pure photometric losses by incorporating structural consistency via NCC. It builds on [Sparse Normalized Cross-Correlation (NCC) Loss](15693-sparse-normalized-cross-correlation-ncc-loss.md).

## How it works
**Inputs:**
- $x$: Predicted pixel value.
- $y$: Ground truth pixel value.
- $\epsilon$: Small constant for numerical stability.
- Tile-level statistics: $\mu_x, \mu_y$ (means) and $\sigma_x^2, \sigma_y^2$ (variances) computed from sampled pixels within a tile.
- Historical gradient magnitudes: $E[|\nabla \ell_1|]$ and $E[|\nabla \ell_{NCC}|]$.
- $\lambda, \tau_{ncc}$: Balancing parameters.

**Outputs:**
- Combined gradient $\frac{\partial L}{\partial x}$.

**Data Structures:**
- Tile statistics are maintained per tile for the current batch of sampled pixels.
- Running averages for gradient magnitudes are maintained per parameter or globally.

**Steps:**

1. **Compute Pixel-wise $\ell_1$ Gradient:**
   Calculate the gradient of the Charbonnier loss:
   $$ \frac{\partial \ell_1}{\partial x} = \frac{x - y}{\sqrt{(x - y)^2 + \epsilon^2}} $$

2. **Compute Tile-level NCC Gradient:**
   Calculate the gradient of the sparse NCC loss. The NCC term measures correlation between prediction and ground truth within a tile. The gradient is:
   $$ \frac{\partial \ell_{NCC}}{\partial x} = - \left( \frac{x - \mu_x}{\sqrt{\sigma_x^2 + \epsilon}} \cdot \frac{y - \mu_y}{\sqrt{\sigma_y^2 + \epsilon}} \right) $$
   Note: The source formula [S1, unofficial] presents this as a product of normalized residuals. The exact derivation assumes a simplified NCC form where the gradient w.r.t $x$ depends on the normalized deviation of $x$ from its tile mean, scaled by the normalized deviation of $y$.

3. **Adaptive Balancing:**
   Compute the balance coefficient $\lambda_{\tau_{ncc}}$ using the ratio of expected gradient magnitudes:
   $$ \lambda_{\tau_{ncc}} = \text{clip}\left( \frac{E[|\nabla \ell_1|]}{E[|\nabla \ell_{NCC}|] + \epsilon}, 0, 1 \right) $$
   This clips the ratio to $[0, 1]$ to prevent dominance by either term.

**Parameters:**
- $\epsilon$: Small constant, value not given in sources.
- $\lambda, \tau_{ncc}$: Balancing parameters, values not given in sources.

**Edge Cases:**
- Division by zero in NCC gradient if $\sigma_x^2 + \epsilon = 0$ or $\sigma_y^2 + \epsilon = 0$. The $\epsilon$ term prevents this.
- If $E[|\nabla \ell_{NCC}|]$ is zero, the clip function handles the division by adding $\epsilon$.

**Pseudocode:**
```python
def compute_hybrid_gradient(x, y, mu_x, mu_y, sigma_x_sq, sigma_y_sq, eps, mean_grad_l1, mean_grad_ncc):
    # Step 1: Pixel-wise L1 gradient
    grad_l1 = (x - y) / sqrt((x - y)**2 + eps**2)
    
    # Step 2: Tile-level NCC gradient
    # Based on Eq 17 in [S1, unofficial]
    norm_x = (x - mu_x) / sqrt(sigma_x_sq + eps)
    norm_y = (y - mu_y) / sqrt(sigma_y_sq + eps)
    grad_ncc = - (norm_x * norm_y)
    
    # Step 3: Adaptive balancing
    # Based on Eq 18 in [S1, unofficial]
    ratio = mean_grad_l1 / (mean_grad_ncc + eps)
    lambda_tau_ncc = max(0.0, min(1.0, ratio))
    
    # Step 4: Combine
    # Based on Eq 18 in [S1, unofficial]
    grad_L = lambda_tau_ncc * grad_l1 - (1 - lambda_tau_ncc) * grad_ncc
    
    return grad_L
```

## Subtopics

### Convergence Stability under Sparse Optimization
A structured sparse optimization scheme ensuring stochastic gradients remain aligned with the dense objective by using importance sampling weights. It combines error-guided hard sampling and age-aware stable sampling to prioritize informative pixels while periodically revisiting under-sampled regions. The gradient estimator is $\hat{g} = \frac{1}{|S|} \sum_{i \in S} w(i) \nabla \ell_i(\theta)$, where $w(i) = 1/p(i)$ for ideal importance sampling, ensuring $E[\hat{g}] \propto \nabla L(\theta)$. It also uses a moment-damped LM update with adaptive diagonal damping through the Adam second moment to improve local conditioning under sparse gradients.

## Operating characteristics
- **Time Complexity:** Reduced compared to dense optimization due to sparse pixel sampling. The sampling rate $r_{tile}$ and view number $K_t$ are scheduled to decrease over time, reducing computation as optimization converges.
- **Memory Complexity:** Lower memory usage due to processing only sampled pixels per tile.
- **Performance:** Accelerates 3D Gaussian Splatting training without noticeable convergence degradation. Tested on NVIDIA RTX 5090 GPU.
- **Strengths:** Stabilizes training under sparse supervision, preserves fine details via NCC, and reduces computational cost.
- **Limitations:** Requires careful tuning of sampling schedules and balancing parameters. Performance may vary with scene complexity and sampling density.
- **When to use:** When training 3D Gaussian Splatting or similar radiance field methods with sparse supervision to save computation while maintaining quality.
- **When not to use:** When dense supervision is available and computational resources are not a constraint, or when the scene has very low texture variation making NCC less effective.

## Background
Originated in the TurboGS paper (2026) by Höllein et al., which accelerates 3D Gaussian Splatting via error-guided sparse pixel sampling and optimization. It addresses the challenge of stable optimization when only a subset of pixels is used for gradient computation.
