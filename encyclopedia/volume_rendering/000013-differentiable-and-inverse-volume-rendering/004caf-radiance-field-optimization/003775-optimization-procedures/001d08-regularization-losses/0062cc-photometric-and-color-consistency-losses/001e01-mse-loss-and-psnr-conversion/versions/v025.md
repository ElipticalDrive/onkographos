# MSE Loss and PSNR Conversion

Also called: Loss Function for Constant Model, MSE Loss, Mean Squared Error, Mean Squared Error Loss

## Overview
MSE Loss and PSNR Conversion computes the Mean Squared Error (MSE) between predicted and target RGB values (or volume intensities) and converts this error into Peak Signal-to-Noise Ratio (PSNR) for logging and evaluation [S2, S4, S9, S10, unofficial]. It serves as the primary photometric fidelity metric for training differentiable volume rendering models, optimizing scene parameters by minimizing pixel-wise intensity differences [S4, S7, unofficial]. Unlike structural metrics such as SSIM, which model human visual perception, MSE focuses strictly on squared intensity error, providing a differentiable, objective measure of reconstruction accuracy [S1, S2, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** Predicted image/volume $\hat{I}$ (or $\hat{C}$), Target image/volume $I$ (or $C$), and optionally a binary mask $M$ indicating valid regions [S2, S9, S10, unofficial].
- **Outputs:** Scalar MSE value, Scalar PSNR value (in dB), and optionally masked statistics [S2, S9, unofficial].

**Data Structures:**
- **Predicted/Target Arrays:** Dense arrays of floating-point values (typically RGB channels or scalar intensity). Shape: $(N, H, W, C)$ for images or $(N, D, H, W)$ for volumes, where $N$ is batch size [S6, S9, unofficial].
- **Mask (Optional):** Boolean array of same spatial dimensions as input, indicating valid voxels/pixels [S9, unofficial].

**Steps:**
1. **Validation:** Ensure inputs are non-empty and have matching dimensions. If using a mask, ensure it is not empty (all False) [S3, S10, unofficial].
2. **Difference Calculation:** Compute element-wise difference: $D = \hat{I} - I$ [S6, unofficial].
3. **Squaring:** Square the difference: $S = D^2$ [S6, unofficial].
4. **Masking (Optional):** If a mask $M$ is provided, apply it to the squared errors. Let $N_{mask}$ be the count of True values in $M$. If $N_{mask} = 0$, raise an error or return infinity [S9, unofficial].
5. **Averaging:** Compute the mean of the squared errors over the valid region (spatial dimensions and batch, or masked voxels).
   - Unmasked: $MSE = \frac{1}{N_{total}} \sum_{i=1}^{N_{total}} S_i$ [S2, S6, unofficial].
   - Masked: $MSE = \frac{1}{N_{mask}} \sum_{i \in M} S_i$ [S9, unofficial].
6. **PSNR Conversion:** Convert MSE to PSNR.
   - If $MSE > 0$: $PSNR = 20 \cdot \log_{10}\left(\frac{1}{\sqrt{MSE}}\right) = -10 \cdot \log_{10}(MSE)$ [S2, S9, unofficial].
   - If $MSE = 0$: $PSNR = \infty$ [S9, unofficial].

**Formulas:**
- **MSE:**
  $$ MSE = \frac{1}{N} \sum_{i=1}^{N} (\hat{x}_i - y_i)^2 $$
  where $\hat{x}_i$ is the predicted value, $y_i$ is the target value, and $N$ is the number of elements (pixels/voxels) [S2, S8, unofficial].
- **PSNR:**
  $$ PSNR = 20 \cdot \log_{10}\left(\frac{1}{\sqrt{MSE}}\right) $$
  derived from the relationship $PSNR = -10 \cdot \log_{10}(MSE)$ [S2, S9, unofficial].

**Parameters:**
- **Mask Threshold (Optional):** For generating masks from volume data, a relative threshold `mask_threshold_rel` (default 0.01) is applied to the maximum volume value to create a boolean mask [S9, unofficial].
- **Clipping Thresholds (Optional):** In Clipped MSE variants, $v_{min}$ and $v_{max}$ define one-sided penalties for under/over-exposed values [S15].

**Pseudocode:**
```python
import math
import numpy as np

def compute_mse_and_psnr(predicted: np.ndarray, target: np.ndarray, mask: np.ndarray = None) -> dict:
    """
    Computes MSE and PSNR between predicted and target arrays.
    
    Args:
        predicted: Array of predicted values (float).
        target: Array of target values (float).
        mask: Optional boolean array indicating valid regions.
        
    Returns:
        Dictionary with 'mse', 'psnr', and optionally 'masked_voxel_count'.
    """
    # 1. Validate inputs
    if predicted.shape != target.shape:
        raise ValueError("Predicted and target must have the same shape.")
    
    if mask is not None and mask.shape != predicted.shape:
        raise ValueError("Mask must have the same shape as input.")

    # 2. Compute squared difference
    squared_diff = (predicted - target) ** 2
    
    # 3. Apply mask if provided
    if mask is not None:
        # Count valid voxels
        valid_count = np.sum(mask)
        if valid_count == 0:
            # Empty mask: return infinity for PSNR, handle MSE appropriately
            return {
                'mse': float('inf'),
                'psnr': float('inf'),
                'masked_voxel_count': 0
            }
        
        # Apply mask to squared differences
        masked_squared_diff = np.where(mask, squared_diff, 0.0)
        mse = np.sum(masked_squared_diff) / valid_count
    else:
        # No mask: average over all elements
        mse = np.mean(squared_diff)
        valid_count = None

    # 4. Compute PSNR
    if mse > 0:
        psnr = 20.0 * math.log10(1.0 / math.sqrt(mse))
    else:
        psnr = float('inf')

    # 5. Return results
    result = {
        'mse': float(mse),
        'psnr': float(psnr)
    }
    
    if mask is not None:
        result['masked_voxel_count'] = int(valid_count)
        
    return result
```

**Edge Cases and Pitfalls:**
- **Zero MSE:** If the prediction perfectly matches the target, MSE is 0. The logarithm in PSNR calculation becomes undefined. Handle by setting PSNR to infinity [S9, unofficial].
- **Empty Mask:** If the boolean mask has no True values, the denominator in masked MSE is zero. Raise an error or return infinity [S9, unofficial].
- **Precision:** Use floating-point arithmetic for MSE calculation to avoid overflow in squared differences for large values [S6, unofficial].
- **Color Space:** MSE should be computed in linear color space, not gamma-compressed space, to ensure perceptual uniformity [S15].

## Subtopics

### [PSNR Metric Calculation](2742-psnr-metric-calculation.md)
PSNR is a standard benchmark metric used to evaluate the quality of reconstructed images or volumes in novel view synthesis and radiance field optimization. It quantifies the photometric fidelity between a rendered prediction and a ground-truth reference by converting the Mean Squared Error (MSE) into a logarithmic decibel (dB) scale. Unlike structural metrics such as SSIM, PSNR focuses strictly on pixel-wise intensity error, making it a fast, objective measure of reconstruction accuracy, though it is known to correlate imperfectly with human perception.

### [SSIM Metric Calculation](3650-ssim-metric-calculation.md)
SSIM is a full-reference quality assessment metric that evaluates the perceptual fidelity of a rendered image by comparing local structural information (luminance, contrast, and geometry) against a ground-truth image. Unlike MSE, which measures pixel-wise error, SSIM models the human visual system's adaptation to structured natural scene information, providing a score correlated with perceived image distortion. It is widely used to evaluate the quality of 3D reconstructions and novel 2D views in differentiable volume rendering.

### [Normal-L2 Score Computation](3842-normal-l2-score-computation.md)
The Normal-L2 score quantifies the geometric fidelity of a reconstructed surface by measuring the angular deviation between predicted surface normals and ground-truth normals. It complements photometric metrics (like MSE) by ensuring that shading cues are consistent, which is critical for perceptual quality. It differs from sibling metrics like PSNR or SSIM, which operate on RGB pixel values, by operating directly on the differential geometry of the rendered or reconstructed surface.

### [Minkowski's Metric](4347-minkowski-s-metric.md)
Minkowski's Metric is a family of mathematical distortion measures that treats an image as a 2D signal to calculate the dissimilarity between a reference image and a test image. It generalizes the Mean Squared Error (MSE) by allowing the order parameter $\gamma$ to vary, enabling different sensitivities to pixel-wise errors. It is distinguished from its sibling MSE Loss by its tunable norm order, which allows it to model error distributions other than the Gaussian assumption inherent in MSE.

### [IoU Loss](7110-iou-loss.md)
IoU Loss is a binary segmentation metric that computes the ratio of overlapping voxels above a threshold to the total union of predicted and target voxels. It is used to optimize occupancy or instance fields in radiance-field training, addressing fragmentation caused by inconsistent 2D masks across views. It differs from its parent, [MSE Loss and PSNR Conversion](1651-mse-loss-and-psnr-conversion.md), by operating on binary occupancy/instance probabilities rather than continuous RGB values, providing structural supervision for geometry or instance segmentation.

### [Perceptually-motivated variance metric](9969-perceptually-motivated-variance-metric.md)
The perceptually-motivated variance metric quantifies the error between an 8-bit ambient occlusion (AO) approximation $T$ and a high-fidelity ray-traced reference $R$. It differs from raw pixel Mean Squared Error (MSE) by operating on log-transformed values and spatial gradients, thereby aligning with human visual sensitivity to radiance and its changes. This metric is specifically designed for evaluating AO approximations where reflected ambient radiance is linear in accessibility.

### [Depth Accuracy Metrics](10453-depth-accuracy-metrics.md)
Depth Accuracy Metrics evaluate the geometric fidelity of predicted depth maps against ground truth data in radiance field optimization pipelines. Unlike photometric losses that assess color consistency, these metrics quantify scale- and translation-invariant errors on valid depth pixels, distinguishing between per-image accuracy and global scene consistency. They are primarily used to benchmark monocular depth estimation modules and depth priors within NeRF-based reconstruction.

### [Discrete Wavelet Transform Loss](11910-discrete-wavelet-transform-loss.md)
The Discrete Wavelet Transform (DWT) Loss is a regularization term for Neural Radiance Fields (NeRF) that minimizes the difference between the frequency representations of rendered and ground-truth images by decomposing them into sub-bands. It addresses high-frequency overfitting in few-shot NeRF training by explicitly prioritizing low-frequency learning during early stages. Unlike its sibling [MSE Loss and PSNR Conversion](1651-mse-loss-and-psnr-conversion.md), which compares pixel-wise values globally, the DW loss operates on local structures using patch-based sampling to supervise low and mid-frequency components.

### [Normalized L1 Loss](15480-normalized-l1-loss.md)
Computes a normalized L1 loss between a reconstructed image and an original image, scaling the loss to the $[0, 1]$ range. It is used in sparse pixel sampling optimization pipelines to provide a scale-invariant error metric for adaptive Gaussian densification and pruning.

### [Masked and Weighted Losses](15713-masked-and-weighted-losses.md)
Masked and Weighted Losses modify standard photometric error metrics (such as MSE or Huber loss) by excluding irrelevant regions from the error calculation or adjusting the contribution of individual pixels based on geometric properties. This solves the problem of optimization bias caused by empty background, invalid rays, or multiscale resolution discrepancies, ensuring the model focuses only on meaningful signal. It sets itself apart from standard MSE by dynamically defining a Region of Interest (ROI) based on active radiance or ray validity, and by weighting losses to account for pixel footprint area.

### [Restricted Mean Error Metric](16552-restricted-mean-error-metric.md)
The Restricted Mean Error Metric is a loss function designed to optimize scattering parameters (specifically phase function weights) in volume rendering by addressing parameter heterogeneity across voxel clusters. Unlike standard Mean Squared Error (MSE) which compares global image averages, this metric computes the squared difference between the average intensities of rendered and reference images restricted to specific spatial clusters, thereby identifying which voxel groups require correction. It is primarily used in the optimization of anisotropic media rendering where global intensity metrics fail to guide local weight adjustments.

### MSE Bias-Variance Decomposition
Treating the TAA algorithm as a biased estimator to analyze correctness using Mean Squared Error (MSE), decomposed into variance and bias squared [S11, unofficial].
$$ MSE[F] = \mathbb{E}[(F - G)^2] = V[F] + \beta[F]^2 $$
where $F$ is the output of the estimator, $G$ is the true value (ground truth), $V[F]$ is the variance of the estimator, and $\beta[F]$ is its bias [S11, unofficial].

### Greedy proposal matching
A fast assignment strategy used during Phase 1 to compute the L2 matching loss between heuristic samples and learnt proposals [S12, unofficial]. For each heuristic sample, find the closest proposal from the learnt proposer set [S12, unofficial]. Optimal matching (Hungarian algorithm) or strict 1-1 greedy matching significantly slows training [S12, unofficial].

### MSLE Loss
Calculates Mean Squared Logarithmic Error between two RGB colors, optionally weighted by luminance [S13, unofficial].
$$ MSLE = \sum_c \left(\log_2\left(\frac{b_c + 1.0}{a_c + 1.0}\right)\right)^2 \cdot w_c $$
where $w_c$ is 1.0 or luminance weight [S13, unofficial].

### RMSE Loss for Constant Model
Calculates the Root Mean Squared Error between predicted and observed intensities for a given sigma and q [S3, unofficial].
1. Validate inputs: intensity not empty, ds > 0. If invalid, return infinity [S3, unofficial].
2. Initialize squared = 0. Loop k from 0 to intensity.size() - 1. Calculate predicted = constant_intensity(intensity.front(), sigma, q, k * ds). Calculate error = predicted - intensity[k]. Add error^2 to squared [S3, unofficial].
3. Return sqrt(squared / intensity.size()) [S3, unofficial].

### Blur Loss
L2 loss between the simulated blurry image and the input blurry image [S14].
$$ L_{blur} = \frac{1}{m} \sum_{x \in X} \| \hat{B}(x) - B(x) \|^2 $$
where $B(x)$ is the input blurry image at pixel $x$ [S14].

### Clipped MSE Loss
A pixel-wise mean squared loss operating in linear color space (no gamma compression) that handles under-exposed and over-exposed values using a one-sided difference based on clipping thresholds [S15].
- $v_{min}$: The lower clipping threshold for under-exposed values. Values below this are penalized only if they are above the threshold (one-sided difference) [S15].
- $v_{max}$: The upper clipping threshold for over-exposed values. Values above this are penalized only if they are below the threshold [S15].

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the number of pixels or voxels, as it requires a single pass to compute differences and averages [S6, S10, unofficial].
- **Memory Complexity:** $O(N)$ for storing intermediate squared differences if not computed in-place, or $O(1)$ if computed incrementally [S6, S10, unofficial].
- **Performance:** Fast and efficient, suitable for real-time logging during training [S2, S9, unofficial].
- **Strengths:** Simple to implement, differentiable, and widely understood as a standard metric [S1, S4, unofficial].
- **Limitations:** Does not account for structural information or human perception, potentially leading to visually suboptimal results despite low MSE [S1, S2, unofficial]. Sensitive to outliers due to squaring [S11, unofficial].
- **When to Use:** As a primary loss function for training when photometric fidelity is the main goal, or as a standard evaluation metric [S4, S7, unofficial].
- **When Not to Use:** When structural similarity or perceptual quality is more important than pixel-wise accuracy [S1, S2, unofficial].

## Background
MSE and PSNR are standard metrics in image and signal processing, widely adopted in differentiable volume rendering for evaluating reconstruction quality [S1, S2, unofficial]. MSE was introduced as a fundamental error metric in early computer vision and graphics literature, while PSNR became a standard benchmark for image compression and reconstruction quality [S1, S2, unofficial]. In the context of Neural Radiance Fields (NeRF) and related methods, MSE is the default loss function for optimizing radiance fields, as demonstrated in the original NeRF paper and subsequent works [S4, S7, unofficial]. PSNR is commonly used in papers to report quantitative results, providing a standardized way to compare different methods [S1, S2, unofficial].
