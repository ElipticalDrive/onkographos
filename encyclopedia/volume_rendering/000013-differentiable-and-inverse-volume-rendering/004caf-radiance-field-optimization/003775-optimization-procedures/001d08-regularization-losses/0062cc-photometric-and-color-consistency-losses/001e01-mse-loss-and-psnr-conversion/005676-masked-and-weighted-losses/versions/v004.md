# Masked and Weighted Losses
## Overview
Masked and Weighted Losses is a family of techniques that modify standard photometric error computation in differentiable volume rendering by applying spatial masks or per-pixel weights to the loss function [S1, S2, S3, S4]. It solves the problem of training instability and evaluation bias caused by invalid background regions, sensor artifacts, multiscale resolution disparities, or structural inconsistencies [S1, S2, S3, S4]. It sets itself apart from its sibling [MSE Loss and PSNR Conversion](1651-mse-loss-and-psnr-conversion.md) by introducing selective suppression or amplification of error terms rather than computing a global average, and from [Masked Volume Metrics](1927-masked-volume-metrics.md) by focusing on training-time gradient correction rather than evaluation-time metric definition [S1, S2, S3, S4, 1927-masked-volume-metrics.md, 4765-training-loss-computation-with-huber-and-masking.md].

## Shared principles
The core mechanism involves computing a base loss $L_{base}$ (typically MSE or Huber) between the rendered prediction $P$ and the ground truth $G$, then applying a mask $M$ or weight $W$ before aggregation [G].

For masking, the loss is computed as:
$$ L = \frac{1}{N_{valid}} \sum_{i} M_i \cdot L_{base}(P_i, G_i) $$
where $M_i \in \{0, 1\}$ is a binary mask indicating whether ray $i$ or froxel $i$ contributes to the loss, and $N_{valid}$ is the count of valid elements (where $M_i=1$) [G].

For weighting, the loss is computed as:
$$ L = \frac{1}{N} \sum_{i} W_i \cdot L_{base}(P_i, G_i) $$
where $W_i$ is a scalar weight for element $i$ [G].

## Subtopics

### [Masked Volume Metrics](1927-masked-volume-metrics.md)
[Masked Volume Metrics](1927-masked-volume-metrics.md) computes evaluation metrics (MSE, PSNR) by excluding empty froxels [1927-masked-volume-metrics.md]. It defines the effective ROI as the union of froxels with non-zero radiance in the rendered scenario and non-zero values in the ground truth [1927-masked-volume-metrics.md]. It is chosen for evaluation to prevent empty background regions from skewing performance scores [1927-masked-volume-metrics.md].

### [Training Loss Computation with Huber and Masking](4765-training-loss-computation-with-huber-and-masking.md)
[Training Loss Computation with Huber and Masking](4765-training-loss-computation-with-huber-and-masking.md) defines the training-time pipeline using Huber loss ($\delta=0.1$) and binary ray validity masks [4765-training-loss-computation-with-huber-and-masking.md]. It differs from Masked Volume Metrics by operating on rays during training rather than froxels during evaluation, and from this family's general definition by specifying the Huber function and JAX-based implementation details [4765-training-loss-computation-with-huber-and-masking.md].

### Area Loss Scaling
**Definition:** Scaling the loss of each pixel by the area of that pixel's footprint in the original image to ensure low-resolution pixels have comparable influence to high-resolution pixels in multiscale datasets [S1].
**Step:** For multiscale datasets, calculate the area scaling factor based on the downsampling factor (e.g., factor of 2 -> area factor 4, factor of 4 -> area factor 16). Multiply the pixel loss by this factor [S1].

### Density-based Loss for Shape Addition
**Definition:** A method for shape addition using a density-based loss which is faster but less effective than composite image reconstruction. The loss encourages predicted densities to match target densities for edited regions and be unchanged for unedited regions [S2].
**Step:** Let $y_f = \{(r, \sigma_f)\}$ be the set of rays and densities in the foreground mask, and $y_b = \{(r, \sigma_b)\}$ be the set of rays and densities in the background mask. $\sigma_f$ are density values of the rays copied from the new object instance, and $\sigma_b$ represent density values of the rays from the original instance. Let $\sigma_r$ be the densities predicted by the model for ray $r$. Densities are normalized to sum to one [S2].
**Formula:**
$$ L_{dens} = \sum_{(r, \sigma_f) \in y_f} (-\sigma_f^T \log \sigma_r) + \sum_{(r, \sigma_b) \in y_b} (-\sigma_b^T \log \sigma_r) $$
[S2]

### Bayer Masking for Loss Supervision
**Step:** Render all three colors for every training ray, then apply a one-hot mask to select the desired output color corresponding to the measured raw pixel for that ray. Apply a second mask to remove a 4 pixel border from all training images to handle saturated pixels often found on the edges of iPhone raw images [S3].
**Pitfall:** Using bilinearly demosaicked raw images for supervision causes distracting color noise artifacts, particularly in extremely high noise areas, due to broken 'hot' pixels being dispersed to neighboring pixels [S3].

### Edge Loss Regularization
**Definition:** A regularization term added to the training loss to enforce edge detail consistency between the current rendering and the target image, alleviating washed-out details caused by noisy 2D-to-3D feature correspondences [S4].
**Formula:**
$$ L_{edge} = \| (I_{Current} * G_{\sigma1}) - (I_{Target} * G_{\sigma2}) \|_1 $$
where $*$ denotes convolution and $G_\sigma$ is a Gaussian kernel with standard deviation $\sigma$ [S4].
**Parameter:** Standard deviation $\sigma_1$ for the current image Gaussian filter is 1.0. Standard deviation $\sigma_2$ for the target image Gaussian filter is 1.6. Weighting factor $\lambda$ for the edge loss is 0 for the first 15% of training, then increased to 50 [S4].

## Background
Area loss scaling was introduced in Mip-NeRF to handle multiscale datasets where low-resolution images have larger pixel footprints [S1]. Density-based losses for shape editing were proposed in Editing Conditional Radiance Fields to facilitate faster object manipulation [S2]. Bayer masking was introduced in RawNeRF to correctly supervise neural radiance fields using raw sensor data, avoiding artifacts from demosaicking [S3]. Edge loss regularization was added in NeRF Analogies to preserve high-frequency details during appearance transfer [S4]. Masked Volume Metrics was developed to exclude empty froxels from evaluation metrics [1927-masked-volume-metrics.md]. Training Loss Computation with Huber and Masking formalized the pipeline for differentiable volume rendering using Huber loss and validity-based masking [4765-training-loss-computation-with-huber-and-masking.md].
