# Mean Square Error (MSE)
Also called: L2 Loss, Squared Error

## Overview
Mean Square Error (MSE) is a photometric consistency loss used in radiance-field optimization to quantify the dissimilarity between a rendered image and a ground-truth reference. It serves as the squared case of Minkowski's Metric, providing a differentiable objective function for gradient-based optimization. Unlike perceptual metrics, MSE operates purely on pixel-wise intensity differences, making it computationally efficient but potentially misaligned with human visual perception [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Two images (or tensors) $x$ and $y$ of size $N$, representing the rendered and reference values respectively.
- Output: A scalar loss value $L_{MSE}$.

**Data Structures:**
- $x, y$: Arrays or tensors of floating-point numbers. No specific bit-packing is required beyond standard floating-point representation.

**Formula:**
The MSE is defined as the mean of the squared differences between corresponding samples:
$$L_{MSE} = \frac{1}{N} \sum_{i=1}^{N} (x_i - y_i)^2$$

Note: The source [S1, unofficial] defines the Minkowski metric $E_\gamma$ for $\gamma=2$ as $\sqrt{MSE}$. However, in the context of optimization losses, the term "Mean Square Error" typically refers to the squared term itself (without the square root) to maintain differentiability and scale properties. The square root is omitted in the loss definition to avoid the singularity of the derivative at zero and to simplify gradient computation.

**Steps:**
1. Compute the difference between each pixel $x_i$ and $y_i$.
2. Square the difference: $(x_i - y_i)^2$.
3. Sum all squared differences.
4. Divide by the total number of samples $N$.

**Parameters:**
- $N$: Total number of pixels or samples.

**Edge Cases and Pitfalls:**
- **Gradient Vanishing:** The derivative of the squared error is linear. For very small errors, gradients are small, potentially slowing convergence.
- **Outliers:** Squaring errors amplifies the impact of outliers (large differences), which can dominate the loss and skew optimization towards minimizing large errors at the expense of overall structure.
- **Dynamic Range:** MSE assumes linear intensity values. Applying it directly to tonemapped or log-space data without appropriate weighting or transformation can lead to suboptimal results [S1, unofficial].

**Pseudocode:**
```python
def mse_loss(x: list[float], y: list[float]) -> float:
    """
    Calculate Mean Square Error between two images/tensors x and y.
    
    Args:
        x: Rendered image values.
        y: Reference image values.
        
    Returns:
        Scalar MSE loss.
    """
    if len(x) != len(y):
        raise ValueError("Images must have the same number of samples")
    
    n = len(x)
    sum_squared_diff = 0.0
    
    for i in range(n):
        diff = x[i] - y[i]
        sum_squared_diff += diff * diff
        
    return sum_squared_diff / n
```

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the number of pixels. Linear scan with constant-time operations per pixel.
- **Memory Complexity:** $O(1)$ auxiliary space if computed in a single pass, or $O(N)$ if storing intermediate differences.
- **Performance:** Computationally inexpensive and highly parallelizable.
- **Strengths:** Simple to implement, differentiable everywhere, widely supported in deep learning frameworks.
- **Limitations:** Poor correlation with human visual perception [S1, unofficial]. Sensitive to outliers. Does not account for structural information.
- **When to Use:** When computational efficiency is critical, or when ground truth is precise and linear. Not ideal for perceptual quality optimization without additional perceptual losses.

## Background
MSE is a fundamental metric in signal processing and image analysis. It is a specific case of Minkowski's Metric where $\gamma=2$ [S1, unofficial]. While widely used in optimization, its limitations regarding human visual system (HVS) perception have been noted, with alternatives like PSNR and Laplacian MSE proposed for specific applications [S1, unofficial].
