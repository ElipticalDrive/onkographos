# MSE Loss and PSNR Conversion

Also called: Loss Function for Constant Model, MSE Loss, Mean Squared Error, Mean Squared Error Loss

## Overview
MSE Loss computes the Mean Squared Error between predicted and target RGB values (or volume intensities), serving as the primary photometric fidelity loss for training differentiable volume rendering models [S2, unofficial][S4, unofficial][S7, unofficial]. PSNR Conversion calculates the Peak Signal-to-Noise Ratio from the MSE to provide a logarithmic, decibel-scale metric for evaluating reconstruction quality, where higher values indicate better fidelity [S2, unofficial][S3, unofficial]. Unlike structural metrics such as SSIM, MSE focuses strictly on pixel-wise intensity accuracy, making it sensitive to large smooth regions while largely ignoring small, high-frequency features like specular highlights [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Predicted image/volume $\hat{I}$ (or $\hat{C}(\mathbf{r})$), Target image/volume $I$ (or $C_{gt}(\mathbf{r})$). Optional: Binary mask $M$ for masked variants [S9, unofficial].
*   **Outputs:** Scalar Loss value $L_{MSE}$; Metric value $PSNR$.

**Data Structures:**
*   **Predicted/Target Arrays:** Tensors or vectors of shape $(N, H, W, C)$ for images or $(N, D, H, W)$ for volumes, containing floating-point intensity values. For RGB, $C=3$. Values are typically normalized to $[0, 1]$ [S4, unofficial].
*   **Mask (Optional):** Boolean array of same spatial dimensions as input, indicating valid voxels/pixels [S9, unofficial].

**Steps:**

1.  **Compute Element-wise Difference:** Calculate the difference between predicted and target values.
    $$ \Delta = \hat{I} - I $$
2.  **Square the Difference:** Compute the squared error for each element.
    $$ E = \Delta^2 = (\hat{I} - I)^2 $$
3.  **Average (MSE Calculation):** Compute the mean of the squared errors over the relevant dimensions (spatial dimensions and batch/channel dimensions as appropriate).
    $$ MSE = \frac{1}{N} \sum_{i=1}^{N} (\hat{I}_i - I_i)^2 $$
    where $N$ is the number of elements (pixels or voxels) included in the average [S2, unofficial][S4, unofficial].
    *   *Masked Variant:* If a mask $M$ is provided, $N$ is the count of elements where $M$ is true, and the sum is restricted to those indices [S9, unofficial].
4.  **PSNR Conversion:** Convert the MSE to PSNR using the logarithmic formula.
    $$ PSNR = -10 \cdot \log_{10}(MSE) $$
    Alternatively, expressed as:
    $$ PSNR = 20 \cdot \log_{10}\left(\frac{1}{\sqrt{MSE}}\right) $$
    [S2, unofficial][S9, unofficial].

**Parameters:**
*   **Mask Threshold (Masked MSE):** A relative threshold `mask_threshold_rel` (default 0.01) applied to the maximum value of the mask volume to create the boolean mask [S9, unofficial].

**Pseudocode:**

import numpy as np

def compute_mse(predicted: np.ndarray, target: np.ndarray, mask: np.ndarray = None) -> float:
    """
    Computes Mean Squared Error between predicted and target arrays.
    
    Args:
        predicted: Array of predicted values (float).
        target: Array of target values (float).
        mask: Optional boolean array indicating valid elements.
        
    Returns:
        float: The MSE value.
    """
    # Validate inputs
    if predicted.shape != target.shape:
        raise ValueError("Predicted and target must have the same shape")
    
    # Compute squared difference
    squared_diff = (predicted - target) ** 2
    
    if mask is not None:
        # Apply mask
        if mask.shape != predicted.shape:
            raise ValueError("Mask must have the same shape as input")
        
        # Check if mask is empty
        if not np.any(mask):
            raise RuntimeError("Mask has no true values (empty region)")
        
        # Calculate masked MSE
        masked_squared_diff = squared_diff[mask]
        mse = np.mean(masked_squared_diff)
    else:
        # Calculate global MSE
        mse = np.mean(squared_diff)
        
    return float(mse)

def mse_to_psnr(mse: float) -> float:
    """
    Converts MSE to PSNR.
    
    Args:
        mse: Mean Squared Error value.

        float: PSNR in decibels. Returns infinity if MSE is 0.
    """
    if mse <= 0:

    # Equivalent to 20 * log10(1 / sqrt(MSE))
    psnr = -10.0 * math.log10(mse)
    return psnr

**Edge Cases and Pitfalls:**
*   **Zero MSE:** If the prediction perfectly matches the target, MSE is 0. The logarithm of 0 is undefined. PSNR is typically set to infinity ($\infty$) in this case [S9, unofficial].
*   **Empty Mask:** If a mask is used and contains no true values, the operation is invalid. A `RuntimeError` should be raised [S9, unofficial].
*   **Color Space:** MSE should be computed in linear color space (without gamma compression) to be physically meaningful, especially for high dynamic range or under/over-exposed scenes [S15].
*   **Gradient Flow:** MSE is differentiable everywhere, allowing standard backpropagation through the rendering equation [44-radiance-field-optimization.md].

## Subtopics

### [PSNR Metric Calculation](2742-psnr-metric-calculation.md)
PSNR is a standard benchmark metric used to evaluate the photometric fidelity of reconstructed images or volumes in novel view synthesis and 3D reconstruction. It quantifies the error between a predicted image and a ground-truth reference by converting the Mean Squared Error (MSE) into a logarithmic decibel (dB) scale, where higher values indicate better quality. Unlike structural metrics such as SSIM, PSNR focuses strictly on pixel-wise intensity accuracy, making it sensitive to large smooth regions while largely ignoring small, high-frequency features like specular highlights.

### [SSIM Metric Calculation](3650-ssim-metric-calculation.md)
SSIM is a full-reference quality assessment metric that evaluates the perceptual fidelity of a rendered image by comparing local structural information (luminance, contrast, and geometry) against a ground-truth image. Unlike MSE, which measures pixel-wise error, SSIM models the human visual system's adaptation to structured natural scene information, providing a score correlated with perceived image distortion. It is widely used to evaluate the quality of 3D reconstructions and novel 2D views in differentiable volume rendering.

### [Normal-L2 Score Computation](3842-normal-l2-score-computation.md)
The Normal-L2 Score computes the mean squared error between predicted surface normals and ground-truth normals to evaluate geometric fidelity in radiance-field optimization. It differs from sibling metrics like [PSNR Metric Calculation](2742-psnr-metric-calculation.md) by focusing on shading-critical surface orientation rather than color intensity, and from [IoU Loss](7110-iou-loss.md) by measuring local geometric accuracy rather than global silhouette alignment.

### [Minkowski's Metric](4347-minkowski-s-metric.md)
Minkowski's Metric is a family of mathematical distortion measures that treats an image as a 2D signal to calculate the dissimilarity between a reference image and a test image. It generalizes the Mean Squared Error (MSE) by allowing the order parameter $\gamma$ to vary, enabling different sensitivities to pixel-wise errors. It is distinguished from its sibling MSE Loss by its tunable norm order, which allows it to model error distributions other than the Gaussian assumption inherent in MSE.

### [IoU Loss](7110-iou-loss.md)
IoU Loss is a binary segmentation metric that computes the ratio of overlapping voxels above a threshold to the total union of predicted and target voxels. It is used to optimize occupancy or instance fields in radiance-field training, addressing fragmentation caused by inconsistent 2D masks across views. It differs from its parent, [MSE Loss and PSNR Conversion](1651-mse-loss-and-psnr-conversion.md), by operating on binary occupancy/instance probabilities rather than continuous RGB values, providing structural supervision for geometry or instance segmentation.

### [Perceptually-motivated variance metric](9969-perceptually-motivated-variance-metric.md)
The perceptually-motivated variance metric quantifies the error between an 8-bit ambient occlusion (AO) approximation $T$ and a high-fidelity ray-traced reference $R$. It differs from raw pixel Mean Squared Error (MSE) by operating on log-transformed values and spatial gradients, thereby aligning with human visual sensitivity to radiance and its changes. This metric is specifically designed for evaluating AO approximations where reflected ambient radiance is linear in accessibility.

### [Depth Accuracy Metrics](10453-depth-accuracy-metrics.md)
Depth Accuracy Metrics evaluate the geometric fidelity of predicted depth maps against ground truth data in radiance field optimization pipelines. They quantify scale- and translation-invariant errors on valid depth pixels. They are used to evaluate depth prior quality and monocular depth estimation outputs in NeRF pipelines.

### [Discrete Wavelet Transform Loss](11910-discrete-wavelet-transform-loss.md)
The Discrete Wavelet Transform (DWT) Loss is a regularization term for Neural Radiance Fields (NeRF) that minimizes the difference between the frequency representations of rendered and ground-truth images by decomposing them into sub-bands. It addresses high-frequency overfitting in few-shot NeRF training by explicitly prioritizing low-frequency learning during early stages. Unlike its sibling [MSE Loss and PSNR Conversion](1651-mse-loss-and-psnr-conversion.md), which compares pixel-wise values globally, the DW loss operates on local structures using patch-based sampling to supervise low and mid-frequency components.

### [Normalized L1 Loss](15480-normalized-l1-loss.md)
Computes a normalized L1 loss between a reconstructed image and an original image, scaling the loss to the $[0, 1]$ range. It is used in sparse pixel sampling optimization pipelines to provide a scale-invariant error metric for adaptive Gaussian densification and pruning.

### [Masked and Weighted Losses](15713-masked-and-weighted-losses.md)
Masked and Weighted Losses modify standard photometric error metrics (such as MSE or Huber loss) by excluding irrelevant regions from the error calculation or adjusting the contribution of individual pixels based on geometric properties. This solves the problem of optimization bias caused by empty background, invalid rays, or multiscale resolution discrepancies, ensuring the model focuses only on meaningful signal. It sets itself apart from standard MSE by dynamically defining a Region of Interest (ROI) based on active radiance or ray validity, and by weighting losses to account for pixel footprint area.

### [Restricted Mean Error Metric](16552-restricted-mean-error-metric.md)
The Restricted Mean Error Metric is a loss function designed to optimize scalar weight factors for pre-computed scattering lobe shapes in volume rendering, specifically addressing parameter heterogeneity across voxel clusters. Unlike standard Mean Squared Error (MSE) which treats all pixels equally or global mean metrics that obscure local errors, this method computes the average intensity only for pixels "directly" visible to specific voxel clusters, allowing the optimizer to identify which clusters cause rendering artifacts (such as seams) and correcting them individually. It is primarily used in the context of optimizing SGGX lobe weights via Stochastic Gradient Descent (SGD).

### MSE Bias-Variance Decomposition
Treating the TAA algorithm as a biased estimator to analyze correctness using Mean Squared Error (MSE), decomposed into variance and bias squared [S11, unofficial]. The formula is $MSE[F] = E[(F - G)^2] = V[F] + \beta[F]^2$, where $F$ is the output of the estimator, $G$ is the true value (ground truth), $V[F]$ is the variance of the estimator, and $\beta[F]$ is its bias [S11, unofficial].

### Greedy proposal matching
A fast assignment strategy used during Phase 1 to compute the L2 matching loss between heuristic samples and learnt proposals [S12, unofficial]. For each heuristic sample, the closest proposal from the learnt proposer set is found [S12, unofficial]. Optimal matching (Hungarian algorithm) or strict 1-1 greedy matching significantly slows training [S12, unofficial].

### MSLE Loss
Calculates Mean Squared Logarithmic Error between two RGB colors, optionally weighted by luminance [S13, unofficial]. The formula is $MSLE = \sum_c (\log_2(\frac{b_c + 1.0}{a_c + 1.0}))^2 \cdot w_c$ where $w_c$ is 1.0 or luminance weight [S13, unofficial].

### RMSE Loss for Constant Model
Calculates the Root Mean Squared Error between predicted and observed intensities for a given sigma and q [S3, unofficial]. Inputs are validated (intensity not empty, ds > 0, sigma >= 0, q >= 0; if invalid, return infinity) [S3, unofficial]. The squared error is accumulated over the intensity samples, and the square root of the mean squared error is returned [S3, unofficial].

### Blur Loss
L2 loss between the simulated blurry image and the input blurry image [S14]. The parameter $B(x)$ is the input blurry image at pixel $x$ [S14].

### Clipped MSE Loss
A pixel-wise mean squared loss operating in linear color space (no gamma compression) that handles under-exposed and over-exposed values using a one-sided difference based on clipping thresholds [S15]. $v_{min}$ is the lower clipping threshold for under-exposed values (penalized only if above threshold), and $v_{max}$ is the upper clipping threshold for over-exposed values (penalized only if below threshold) [S15].

## Operating characteristics
*   **Time Complexity:** $O(N)$, where $N$ is the number of pixels or voxels. The operation is element-wise and parallelizable.
*   **Memory Complexity:** $O(N)$ to store the squared differences or the final MSE/PSNR scalar if computed incrementally.
*   **Performance:** Computationally inexpensive compared to structural metrics like SSIM or LPIPS. It is the standard loss for initial convergence in NeRF and volume rendering training due to its simplicity and differentiability [S4, unofficial][S7, unofficial].
*   **Strengths:** Simple to implement, differentiable, provides a clear global error signal, widely used as a baseline metric [S1, unofficial][S4, unofficial].
*   **Limitations:** Does not correlate well with human perception for high-frequency details or structural fidelity; sensitive to outliers; can lead to blurry results if used alone without perceptual or structural losses [S1, unofficial].
*   **When to Use:** Standard photometric supervision, baseline evaluation, scenarios where color accuracy is paramount and structural details are less critical or handled by other losses.
*   **When Not to Use:** When perceptual quality is the primary goal (use SSIM/LPIPS), or when dealing with significant structural misalignments (use IoU/Depth losses).

## Background
MSE is a fundamental statistical measure of error. In the context of volume rendering and NeRF, it was popularized by the original NeRF paper [S2, unofficial] as the primary loss function for optimizing the radiance field. It has since become the standard photometric loss in various 3D reconstruction and novel view synthesis pipelines [S1, unofficial][S4, unofficial][S7, unofficial]. PSNR is a standard metric in image processing, adapted for 3D reconstruction evaluation to provide a comparable scale across different scenes and resolutions [S1, unofficial][S2, unofficial].
