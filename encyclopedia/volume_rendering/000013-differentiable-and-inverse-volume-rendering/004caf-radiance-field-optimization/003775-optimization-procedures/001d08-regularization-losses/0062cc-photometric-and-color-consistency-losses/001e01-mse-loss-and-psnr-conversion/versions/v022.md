# MSE Loss and PSNR Conversion

Also called: Loss Function for Constant Model, MSE, MSE Loss, Mean Squared Error, Mean Squared Error Loss

## Overview
MSE Loss computes the Mean Squared Error between predicted and target RGB values (or volume intensities) to serve as the primary photometric fidelity metric for training differentiable volume rendering models [S2, S4, S7, unofficial]. It is distinct from structural metrics like SSIM by focusing strictly on pixel-wise intensity error, making it a fast, objective measure of reconstruction accuracy [S1, unofficial]. The method often includes a conversion of the computed MSE into Peak Signal-to-Noise Ratio (PSNR) for logging and benchmarking purposes [S2, S9, unofficial].

## How it works
**Inputs:**
*   `predicted`: Tensor of predicted RGB colors or volume intensities. Shape: `(batch_size, channels, height, width)` for images or `(batch_size, num_voxels)` for volumes.
*   `target`: Tensor of ground-truth RGB colors or volume intensities. Shape matches `predicted`.
*   `mask` (optional): Boolean tensor indicating valid voxels/pixels. If provided, loss is computed only on masked elements [S9, unofficial].

**Outputs:**
*   `mse`: Scalar float representing the Mean Squared Error.
*   `psnr`: Scalar float representing the Peak Signal-to-Noise Ratio (derived from MSE) [S2, unofficial].

**Data Structures:**
*   Standard floating-point tensors (typically `float32`).
*   If masked, a boolean mask tensor of the same spatial dimensions as the input.

**Steps:**
1.  **Validation:** Ensure inputs are not empty and have matching shapes. If using a mask, ensure it contains at least one `True` value; otherwise, raise an error or return infinity [S3, S9, S10, unofficial].
2.  **Difference Calculation:** Compute the element-wise difference between predicted and target values: $diff = predicted - target$ [S6, unofficial].
3.  **Squaring:** Square the difference element-wise: $squared\_diff = diff^2$ [S6, unofficial].
4.  **Masking (Optional):** If a mask is provided, apply it to the squared differences. Let $M$ be the set of indices where the mask is true. The masked squared error is $squared\_diff_{masked} = squared\_diff[M]$ [S9, unofficial].
5.  **Averaging:**
    *   **Unmasked:** Flatten spatial dimensions and compute the mean over the batch dimension. For $N$ total elements (pixels/voxels), $MSE = \frac{1}{N} \sum_{i=1}^{N} (x_i - y_i)^2$ [S2, S6, S8, unofficial].
    *   **Masked:** Compute the mean over the masked elements only. Let $N_{mask}$ be the count of true values in the mask. $MSE_{masked} = \frac{1}{N_{mask}} \sum_{i \in mask} (v_{ref, i} - v_{comp, i})^2$ [S9, unofficial].
6.  **PSNR Conversion:** Calculate PSNR from the MSE. If $MSE > 0$, $PSNR = 20 \cdot \log_{10}\left(\frac{1}{\sqrt{MSE}}\right)$ or equivalently $PSNR = -10 \cdot \log_{10}(MSE)$ [S2, S9, unofficial]. If $MSE = 0$, $PSNR = \infty$ [S9, unofficial].

**Pseudocode:**
```python
import math
import torch

def compute_mse_and_psnr(predicted: torch.Tensor, target: torch.Tensor, mask: torch.Tensor = None) -> dict:
    """
    Computes MSE and PSNR between predicted and target tensors.
    
    Args:
        predicted: Tensor of predicted values (RGB or intensity).
        target: Tensor of ground truth values.
        mask: Optional boolean tensor. If provided, computes masked MSE.
        
    Returns:
        Dictionary with 'mse', 'psnr', and optionally 'masked_voxel_count'.
    """
    # 1. Validation
    if predicted.shape != target.shape:
        raise ValueError("Predicted and target must have the same shape.")
    
    if mask is not None:
        if predicted.shape != mask.shape:
            raise ValueError("Mask must have the same shape as predicted/target.")
        if not mask.any():
            raise RuntimeError("Mask has no true values (empty region).")

    # 2. Difference and Squaring
    diff = predicted - target
    squared_diff = diff ** 2

    # 3. Averaging
    if mask is not None:
        # Apply mask
        masked_squared_diff = squared_diff[mask]
        mse = masked_squared_diff.mean()
        masked_voxel_count = int(mask.sum().item())
    else:
        # Flatten spatial dimensions and average over batch
        # Assuming shape (B, C, H, W) or similar
        mse = squared_diff.mean()
        masked_voxel_count = None

    # 4. PSNR Conversion
    if mse > 0:
        psnr = 20.0 * math.log10(1.0 / math.sqrt(mse))
    else:
        psnr = float('inf')

    result = {
        'mse': mse.item(),
        'psnr': psnr,
    }
    if masked_voxel_count is not None:
        result['masked_voxel_count'] = masked_voxel_count
        
    return result
```

**Parameters:**
*   `batch_size`: Number of random pixels or voxels sampled per iteration [S7, unofficial].
*   `mask_threshold_rel`: Relative threshold applied to the normalized mask volume to create the boolean mask (default 0.01) [S9, unofficial].

**Edge Cases and Pitfalls:**
*   **Division by Zero:** If the mask is empty or all values are identical (MSE=0), PSNR becomes infinity. This must be handled explicitly to avoid numerical issues in logging or comparison [S9, unofficial].
*   **Precision:** Squaring differences can amplify noise. Using `float32` is standard, but `float64` may be needed for high-precision scientific volume rendering [S10, unofficial].
*   **Masking:** If the mask is derived from a thresholded volume, ensure the threshold is appropriate to avoid excluding valid data or including noise [S9, unofficial].

## Subtopics

### [PSNR Metric Calculation](2742-psnr-metric-calculation.md)
Peak Signal-to-Noise Ratio (PSNR) is a standard benchmark metric used to evaluate the quality of reconstructed images or volumes in novel view synthesis and radiance field optimization. It quantifies the photometric fidelity between a rendered prediction and a ground-truth reference by converting the Mean Squared Error (MSE) into a logarithmic decibel (dB) scale. Unlike structural metrics such as SSIM, PSNR focuses strictly on pixel-wise intensity error, making it a fast, objective measure of reconstruction accuracy, though it is known to correlate imperfectly with human perception.

### [SSIM Metric Calculation](3650-ssim-metric-calculation.md)
SSIM is a full-reference quality assessment metric that evaluates the perceptual fidelity of a rendered image by comparing local structural information (luminance, contrast, and geometry) against a ground-truth image. Unlike MSE, which measures pixel-wise error, SSIM models the human visual system's adaptation to structured natural scene information, providing a score correlated with perceived image distortion. It is widely used to evaluate the quality of 3D reconstructions and novel 2D views in differentiable volume rendering.

### [Normal-L2 Score Computation](3842-normal-l2-score-computation.md)
The Normal-L2 score evaluates surface geometry by computing the mean squared L2 distance between predicted surface normals and reference normals from a ground-truth mesh. It is computed only on the intersection of predicted and ground-truth masks, distinguishing it from silhouette metrics like iIoU which evaluate mask alignment separately.

### [Minkowski's Metric](4347-minkowski-s-metric.md)
Minkowski's Metric is a family of mathematical distortion measures that treats an image as a 2D signal to calculate the dissimilarity between a reference image and a test image. It generalizes the Mean Squared Error (MSE) by allowing the order parameter $\gamma$ to vary, enabling different sensitivities to pixel-wise errors. It is distinguished from its sibling MSE Loss by its tunable norm order, which allows it to model error distributions other than the Gaussian assumption inherent in MSE.

### [IoU Loss](7110-iou-loss.md)
IoU Loss is a binary segmentation metric that computes the ratio of overlapping voxels above a threshold to the total union of predicted and target voxels. It is used to optimize occupancy or instance fields in radiance-field training, addressing fragmentation caused by inconsistent 2D masks across views. It differs from its parent, [MSE Loss and PSNR Conversion](1651-mse-loss-and-psnr-conversion.md), by operating on binary occupancy/instance probabilities rather than continuous RGB values, providing structural supervision for geometry or instance segmentation.

### [Perceptually-motivated variance metric](9969-perceptually-motivated-variance-metric.md)
The perceptually-motivated variance metric quantifies the error between an 8-bit ambient occlusion (AO) approximation $T$ and a high-fidelity ray-traced reference $R$. It differs from raw pixel Mean Squared Error (MSE) by operating on log-transformed values and spatial gradients, thereby aligning with human visual sensitivity to radiance and its changes. This metric is specifically designed for evaluating AO approximations where reflected ambient radiance is linear in accessibility.

### [Depth Accuracy Metrics](10453-depth-accuracy-metrics.md)
Depth Accuracy Metrics evaluate the geometric fidelity of predicted depth maps against ground truth data in radiance field optimization pipelines. Unlike photometric losses that assess color consistency, these metrics quantify scale- and translation-invariant errors on valid depth pixels, distinguishing between per-image accuracy and global scene consistency. They are primarily used to benchmark monocular depth estimation modules and depth priors within NeRF-based reconstruction.

### [Discrete Wavelet Transform Loss](11910-discrete-wavelet-transform-loss.md)
The Discrete Wavelet Transform (DWT) Loss is a regularization term for Neural Radiance Fields (NeRF) that minimizes the difference between the frequency representations of rendered and ground-truth images by decomposing them into sub-bands. It addresses high-frequency overfitting in few-shot NeRF training by explicitly prioritizing low-frequency learning during early stages. Unlike its sibling [MSE Loss and PSNR Conversion](1651-mse-loss-and-psnr-conversion.md), which compares pixel-wise values globally, the DW loss operates on local structures using patch-based sampling to supervise low and mid-frequency components.

### [Normalized L1 Loss](15480-normalized-l1-loss.md)
Computes a normalized L1 loss between a reconstructed image and an original image, scaling the loss to the $[0, 1]$ range. It is used in sparse pixel sampling optimization pipelines to provide a scale-invariant error metric for adaptive Gaussian densification and pruning.

#### MSE Bias-Variance Decomposition
Treating the TAA algorithm as a biased estimator to analyze correctness using Mean Squared Error (MSE), decomposed into variance and bias squared [S11, unofficial]. The formula is $MSE[F] = E[(F - G)^2] = V[F] + \beta[F]^2$, where $F$ is the output of the estimator, $G$ is the true value (ground truth), $V[F]$ is the variance of the estimator, and $\beta[F]$ is its bias [S11, unofficial].

#### Greedy proposal matching
A fast assignment strategy used during Phase 1 to compute the L2 matching loss between heuristic samples and learnt proposals [S12, unofficial]. For each heuristic sample, the closest proposal from the learnt proposer set is found. Optimal matching (Hungarian algorithm) or strict 1-1 greedy matching significantly slows training [S12, unofficial].

#### MSLE Loss
Calculates Mean Squared Logarithmic Error between two RGB colors, optionally weighted by luminance [S13, unofficial]. The formula is $MSLE = \sum_c (\log_2(\frac{b_c + 1.0}{a_c + 1.0}))^2 \cdot w_c$ where $w_c$ is 1.0 or luminance weight [S13, unofficial].

#### RMSE Loss for Constant Model
Calculates the Root Mean Squared Error between predicted and observed intensities for a given sigma and q [S3, unofficial]. Inputs are validated (intensity not empty, ds > 0). The squared error is accumulated over the intensity samples, and the square root of the mean squared error is returned [S3, unofficial].

#### Blur Loss
L2 loss between the simulated blurry image and the input blurry image [S14]. The parameter $B(x)$ represents the input blurry image at pixel $x$ [S14].

## Operating characteristics
*   **Time Complexity:** $O(N)$, where $N$ is the number of pixels or voxels compared. The operation is element-wise and highly parallelizable on GPUs [S6, S9, unofficial].
*   **Memory Complexity:** $O(N)$ to store the intermediate squared difference tensor, or $O(1)$ if computed in a streaming fashion [S6, unofficial].
*   **Performance:** MSE is computationally inexpensive and serves as the primary loss function for most NeRF and radiance field optimizations due to its differentiability and simplicity [S4, S7, unofficial].
*   **Strengths:** Simple to implement, differentiable everywhere, and provides a clear gradient signal for pixel-wise errors [S4, unofficial].
*   **Limitations:** Does not account for structural similarity or perceptual quality, often leading to blurry results if used in isolation [S1, S4, unofficial]. Correlates poorly with human perception compared to SSIM or LPIPS [S1, unofficial].
*   **When to Use:** As a baseline loss for photometric consistency, especially when structural details are less critical or when combined with other losses (e.g., SSIM, LPIPS) [S4, unofficial].
*   **When Not to Use:** When perceptual quality is the primary goal and structural artifacts are undesirable [S1, unofficial].

## Background
MSE Loss is a fundamental metric in image and signal processing, widely adopted in differentiable volume rendering as the primary photometric loss function [S1, S4, unofficial]. It was introduced in the context of neural radiance fields (NeRF) by Mildenhall et al. [S2, unofficial] and has since become a standard component in training pipelines [S4, S7, unofficial]. The conversion to PSNR is a standard practice for evaluating reconstruction quality, originating from signal processing literature [S2, S9, unofficial].
