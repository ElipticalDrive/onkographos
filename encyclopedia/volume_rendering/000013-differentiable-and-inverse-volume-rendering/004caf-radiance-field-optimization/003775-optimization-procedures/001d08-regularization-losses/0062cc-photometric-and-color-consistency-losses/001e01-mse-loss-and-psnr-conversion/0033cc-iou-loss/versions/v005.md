# IoU Loss

Also called: Intersection over Union (IoU) Loss

## Overview
IoU Loss is a binary segmentation metric that computes the ratio of overlapping voxels above a threshold to the total union of predicted and target voxels [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Predicted voxel values $\hat{v}$, target voxel values $t_v$, and a threshold $\tau$ [S1, unofficial].
- Output: A scalar loss value $L_{\text{IoU}} = 1 - \text{IoU}$ [G].

**Data Structures:**
- $\hat{v}$ and $t_v$: Scalar fields over the voxel grid [S1, unofficial].
- $\tau$: Scalar threshold for binarization [S1, unofficial].

**Formula:**
The Intersection over Union is defined as [S1, unofficial]:
$$ \text{IoU} = \frac{|\{v \mid \hat{v} > \tau\} \cap \{v \mid t_v > 0\}|}{|\{v \mid \hat{v} > \tau\} \cup \{v \mid t_v > 0\}|} $$

**Parameters:**
- $\tau$: Prediction threshold for binarization. Default value is 0.9 [S1, unofficial].

**Steps:**
1. Binarize predictions: $M_{\text{pred}} = (\hat{v} > \tau)$ [G].
2. Binarize targets: $M_{\text{target}} = (t_v > 0)$ [G].
3. Compute intersection count: $I = \sum (M_{\text{pred}} \land M_{\text{target}})$ [G].
4. Compute union count: $U = \sum (M_{\text{pred}} \lor M_{\text{target}})$ [G].
5. Compute IoU: $\text{IoU} = I / U$ [G].
6. Compute Loss: $L_{\text{IoU}} = 1 - \text{IoU}$ [G].

**Edge Cases and Pitfalls:**
- Division by zero: If both masks are empty ($U=0$), the IoU is undefined. A common guard is to return 0 loss or add a small epsilon to the denominator [G].

**Pseudocode:**
```python
def iou_loss(predicted: Tensor, target: Tensor, threshold: float = 0.9) -> Tensor:
    """
    Computes the IoU loss for binary segmentation.
    
    Args:
        predicted: Tensor of predicted values (probabilities/densities).
        target: Tensor of target values (ground truth).
        threshold: Threshold for binarizing predictions.
        
    Returns:
        Scalar IoU loss.
    """
    # Binarize predictions and targets
    pred_mask = predicted > threshold
    target_mask = target > 0
    
    # Compute intersection and union counts
    intersection = (pred_mask & target_mask).sum()
    union = (pred_mask | target_mask).sum()
    
    # Handle empty case to avoid division by zero
    if union == 0:
        return 0.0
        
    iou = intersection / union
    return 1.0 - iou
```

## Subtopics

### [Instance Segmentation Loss](10594-instance-segmentation-loss.md)
Instance Segmentation Loss trains the instance branch $\Theta_i$ of a radiance field using multi-view consistent 2D instance segmentation maps, while keeping the density $\Theta_\sigma$ and color $\Theta_c$ branches fixed. It distinguishes itself from sibling methods by explicitly optimizing for per-instance class probabilities rather than just binary occupancy or appearance, addressing the fragmentation caused by inconsistent 2D masks across views. [Instance Segmentation Loss](10594-instance-segmentation-loss.md)

### [Bounding Box Regression Loss Selection](13816-bounding-box-regression-loss-selection.md)
Bounding Box Regression Loss Selection determines the objective function used to optimize the geometric parameters (position, size, orientation) of 3D bounding boxes during radiance-field-based object detection. It solves the problem of converging to accurate box coordinates by balancing overlap maximization against center-distance minimization. It differs from its parent, [IoU Loss](7110-iou-loss.md), by incorporating additional geometric penalties (such as center distance) to improve convergence speed and handling oriented (rotated) boxes, which standard axis-aligned IoU does not natively support. [Bounding Box Regression Loss Selection](13816-bounding-box-regression-loss-selection.md)

### Mean Intersection over Union (mIoU)
mIoU is a segmentation evaluation metric computed as the mean of IoU across all classes [S2, unofficial]. It is defined as $mIoU = \frac{1}{N_c} \sum_{c=1}^{N} IoU_c$, where $N_c$ is the number of classes, and $IoU_c = \frac{TP_c}{TP_c + FP_c + FN_c}$ for class $c$, with TP, FP, and FN being true positives, false positives, and false negatives [S2, unofficial].

## Operating characteristics
- Time complexity is $O(N)$, where $N$ is the number of voxels, as it requires a single pass to compute sums [G].
- Memory complexity is $O(N)$ for storing masks if not computed in-place [G].
