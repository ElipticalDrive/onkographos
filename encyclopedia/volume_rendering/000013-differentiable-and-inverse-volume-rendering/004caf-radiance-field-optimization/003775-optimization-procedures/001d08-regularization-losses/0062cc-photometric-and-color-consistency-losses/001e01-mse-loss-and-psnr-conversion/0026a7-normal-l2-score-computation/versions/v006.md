# Normal-L2 Score Computation

Also called: Masked Normal L2, Normal Error Metric

## Overview
The Normal-L2 Score computes the mean squared error between predicted surface normals and ground-truth normals to evaluate geometric fidelity in radiance-field optimization [S1]. It differs from sibling metrics like [PSNR Metric Calculation](2742-psnr-metric-calculation.md) by focusing on shading-critical surface orientation rather than color intensity, and from [IoU Loss](7110-iou-loss.md) by measuring local geometric accuracy rather than global silhouette alignment [G].

## How it works
**Inputs:**
- Predicted surface normals tensor $N_{pred}$ (shape: $H \times W \times 3$) [S1].
- Ground-truth surface normals tensor $N_{gt}$ (shape: $H \times W \times 3$), interpolated from a reference mesh [S1].
- Predicted binary mask $M_{pred}$ (shape: $H \times W$) [S1].
- Ground-truth binary mask $M_{gt}$ (shape: $H \times W$) [S1].

**Outputs:**
- Scalar Normal-L2 Score.

**Data Structures:**
- Masks are boolean or float tensors where $1$ indicates the object silhouette and $0$ indicates background [G].
- Normals are unit vectors [G].

**Steps:**
1. **Mask Intersection:** Compute the intersection mask $M_{int}$ where both predicted and ground-truth masks are active:
   $$ M_{int} = M_{pred} \land M_{gt} $$
   This ensures error is only computed on regions where the object is present in both prediction and ground truth, separating geometric error from segmentation error [S1].

2. **Normal Sampling:** For each pixel $(u, v)$ in the image grid:
   - If $M_{int}[u, v] == 1$, retrieve $N_{pred}[u, v]$ and $N_{gt}[u, v]$ [G].
   - If $M_{int}[u, v] == 0$, discard the pixel [G].

3. **Error Calculation:** Compute the squared L2 distance for each valid pixel:
   $$ E_{uv} = \| N_{pred}[u, v] - N_{gt}[u, v] \|_2^2 $$
   Since normals are unit vectors, this simplifies to:
   $$ E_{uv} = 2 - 2 (N_{pred}[u, v] \cdot N_{gt}[u, v]) $$

4. **Aggregation:** Average the errors over all pixels in $M_{int}$:
   $$ \text{Score} = \frac{1}{|M_{int}|} \sum_{u,v \in M_{int}} E_{uv} $$

**Parameters:**
- Camera positions: 32 evenly distributed fixed positions using a spherical Fibonacci sequence with radius 4 [S1].
- Render resolution: $512 \times 512$ [S1].
- Samples per pixel: 4 [S1].

**Edge Cases:**
- If $|M_{int}| = 0$, the score is undefined or set to infinity, indicating complete silhouette mismatch [G].
- Normals must be normalized before comparison to ensure valid dot products [G].

**Pseudocode:**
```python
def compute_normal_l2_score(N_pred, N_gt, M_pred, M_gt):
    # N_pred, N_gt: list of lists of 3-tuples representing H x W x 3 unit normals
    # M_pred, M_gt: list of lists of booleans representing H x W masks
    H = len(M_pred)
    W = len(M_pred[0])
    valid_count = 0
    total_error = 0.0
    for y in range(H):
        for x in range(W):
            if M_pred[y][x] and M_gt[y][x]:
                # Compute squared L2 distance between unit normals
                # ||a - b||^2 = ||a||^2 + ||b||^2 - 2(a . b) = 2 - 2(a . b)
                dot = (N_pred[y][x][0] * N_gt[y][x][0] +
                       N_pred[y][x][1] * N_gt[y][x][1] +
                       N_pred[y][x][2] * N_gt[y][x][2])
                error = 2.0 - 2.0 * dot
                total_error += error
                valid_count += 1
    if valid_count == 0:
        return float('inf')
    return total_error / valid_count
```

## Subtopics

### [Bounded Relative Error Norm (BREN)](16414-bounded-relative-error-norm-bren.md)
The Bounded Relative Error Norm (BREN) is a theoretical property of a reconstruction neural network $\Phi$ that ensures the ratio of the L2 norm of the reconstruction error to the L2 norm of the ground truth is bounded by a value strictly less than 1.

### [KL Normal Loss](4456-kl-normal-loss.md)
The KL Normal Loss constrains the distribution of an output embedding tensor to match a standard normal distribution by computing the Kullback-Leibler (KL) divergence between the two.

## Operating characteristics
- **Time Complexity:** $O(H \times W)$ per camera view, dominated by mask intersection and element-wise operations [G].
- **Memory Complexity:** $O(H \times W)$ to store intermediate masks and normal tensors [G].
- **Strengths:** Directly correlates with shading quality; sensitive to local geometric errors like bumps or dents [G].
- **Limitations:** Sensitive to normal orientation flips (sign ambiguity) if not handled; requires accurate ground-truth normals from a reference mesh [G].
- **When to use:** When shading fidelity is critical and silhouette alignment is handled separately (e.g., via iIoU) [S1].

## Background
Introduced in [S1] for real-time rendering with implicit 3D shapes [S1]. It is used to evaluate the quality of predicted surface normals against interpolated normals from a reference mesh, ensuring that the rendered geometry produces correct shading [S1].
