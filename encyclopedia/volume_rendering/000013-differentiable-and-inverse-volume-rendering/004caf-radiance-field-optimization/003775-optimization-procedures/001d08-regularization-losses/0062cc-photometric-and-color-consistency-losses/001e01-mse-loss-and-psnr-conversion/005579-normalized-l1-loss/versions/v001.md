# Normalized L1 Loss

Also called: L1 Loss, Sparse Loss Calculation, normalized L1

## Overview
Computes a normalized L1 loss between a reconstructed image and an original image, scaling the loss to the $[0, 1]$ range [S1, unofficial]. It is used in sparse pixel sampling optimization pipelines to provide a scale-invariant error metric for adaptive Gaussian densification and pruning [S2, unofficial].

## How it works
**Inputs:**
- `reconstructed_image`: Tensor of shape $(H, W, 3)$ containing predicted RGB values.
- `original_image`: Tensor of shape $(H, W, 3)$ containing ground truth RGB values.

**Outputs:**
- `l1_loss_norm`: Tensor of shape $(H, W)$ containing the normalized L1 error per pixel.

**Steps:**
1. Compute the absolute difference between the reconstructed and original images:
   $$ \Delta = | \text{reconstructed\_image} - \text{original\_image} | $$
2. Compute the mean absolute error along the channel dimension (dim=0 or dim=2 depending on layout, typically channels last in these implementations):
   $$ \text{l1\_loss} = \text{mean}(\Delta, \text{dim}=\text{channels}) $$
   The result is detached from the computation graph to prevent gradient flow through the normalization step [S1, unofficial].
3. Compute the minimum and maximum values of `l1_loss` across the spatial dimensions (height and width):
   $$ \text{min\_val} = \min(\text{l1\_loss}) $$
   $$ \text{max\_val} = \max(\text{l1\_loss}) $$
4. Normalize the loss using min-max scaling:
   $$ \text{l1\_loss\_norm} = \frac{\text{l1\_loss} - \text{min\_val}}{\text{max\_val} - \text{min\_val}} $$
   If $\text{max\_val} - \text{min\_val} = 0$, the result is undefined or handled as zero [G].

**Pseudocode:**
```python
def normalized_l1_loss(reconstructed_image, original_image):
    """
    Compute normalized L1 loss between reconstructed and original images.
    
    Args:
        reconstructed_image: Tensor of shape (H, W, 3) or (3, H, W).
        original_image: Tensor of shape (H, W, 3) or (3, H, W).
        
    Returns:
        l1_loss_norm: Tensor of shape (H, W) with values in [0, 1].
    """
    # Compute absolute difference
    diff = torch.abs(reconstructed_image - original_image)
    
    # Compute mean L1 loss over channels
    # Assuming channels last (H, W, 3) as per typical PyTorch image tensors in these repos
    l1_loss = torch.mean(diff, dim=-1)
    
    # Detach to stop gradient flow through normalization
    l1_loss = l1_loss.detach()
    
    # Compute min and max over spatial dimensions (H, W)
    min_val = torch.min(l1_loss)
    max_val = torch.max(l1_loss)
    
    # Handle edge case where all values are identical
    if max_val == min_val:
        return torch.zeros_like(l1_loss)
    
    # Normalize
    l1_loss_norm = (l1_loss - min_val) / (max_val - min_val)
    
    return l1_loss_norm
```

**Parameters:**
- None.

**Edge cases and pitfalls:**
- If all pixel errors are identical, the denominator becomes zero. A guard is required [G].
- The normalization is global per image, not per batch or per channel [S1, unofficial].
- Detaching the loss prevents gradients from flowing through the normalization, which is intentional for error map updates but means this loss cannot be used directly for backpropagation of the normalization step [S1, unofficial].

## Subtopics

## Operating characteristics
- **Time Complexity:** $O(H \times W)$ for computing the difference, mean, min, and max.
- **Memory Complexity:** $O(H \times W)$ for storing the intermediate tensors.
- **Strengths:** Scale-invariant; useful for comparing error magnitudes across different scenes or training stages [S1, unofficial].
- **Limitations:** Sensitive to outliers in the min/max calculation; normalization is global, so local variations are compressed if the dynamic range is large [G].
- **When to use:** When a scale-invariant error metric is needed for adaptive sampling or densification criteria [S2, unofficial].
- **When not to use:** When gradients need to flow through the loss value itself for optimization [S1, unofficial].

## Background
Originated in the context of 3D Gaussian Splatting optimization, specifically in implementations like FastGS and TurboGS, where it is used for sparse loss calculation and error-guided pixel sampling [S1, S2, unofficial].
