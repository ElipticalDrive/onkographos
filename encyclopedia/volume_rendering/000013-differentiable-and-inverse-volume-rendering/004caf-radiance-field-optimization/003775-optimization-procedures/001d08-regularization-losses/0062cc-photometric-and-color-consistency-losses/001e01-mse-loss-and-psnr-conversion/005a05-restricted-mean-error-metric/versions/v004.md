# Restricted Mean Error Metric

Also called: Cluster-specific error metric, Error Metric for Optimization, Restricted Mean Error Metric for Weight Optimization, Restricted mean pixel intensity

## Overview
The Restricted Mean Error Metric is a loss function for optimizing scalar weight factors of pre-computed scattering lobe shapes in volume rendering, specifically addressing parameter heterogeneity across voxel clusters [S1]. Unlike global mean metrics that obscure local errors, it computes average intensity only for pixels directly visible to specific voxel clusters, allowing the optimizer to identify and correct artifacts like seams per cluster [S1]. It is used to optimize SGGX lobe weights via Stochastic Gradient Descent (SGD) [S1].

## How it works
**Inputs:**
- $K$: Number of voxel clusters [S1].
- $I^r$: Ground truth reference image for view $r$ [S1].
- $\tilde{I}^r$: Rendered approximate image for view $r$, generated using current weights $w$ [S1].
- $V_k$: Set of pixels in view $r$ that are directly visible to voxels in cluster $k$ [S1].
- $c_r$: Normalization weights for each view $r$ [S1].

**Outputs:**
- $E_{L2}$: The total restricted mean squared error value [S1].
- $\nabla_{w_{k,j}} E_{L2}$: The gradient of the error with respect to weight $w_{k,j}$ (the $j$-th parameter of the $k$-th cluster's lobe shape), required for SGD updates [S1].

**Data Structures:**
- The method assumes a clustering of voxels where each voxel $i$ belongs to a cluster $c(i) \in \{1, \dots, K\}$ [S1].
- Weights $w_{k,j}$ correspond to the parameters defining the shape of each lobe [S1].

**Steps:**

1. **Compute Normalization Weights:** For each view $r$, calculate the normalization factor $c_r$ based on the mean intensity of the ground truth image $I^r$ [S1]. The mean intensity $\text{mean}(I^r)$ is the average intensity of all foreground pixels in $I^r$ [S1].
$$ c_r = \max(\text{mean}(I^r), 0.05)^{-1} $$

2. **Compute Restricted Means:** For each cluster $k$ and each view $r$, compute the restricted mean intensity $\text{mean}_k(I^r)$ and $\text{mean}_k(\tilde{I}^r)$ [S1]. This is the average intensity evaluated only among the pixels in $V_k$ [S1].
$$ \text{mean}_k(I^r) = \frac{1}{|V_k|} \sum_{p \in V_k} I^r(p) $$
$$ \text{mean}_k(\tilde{I}^r) = \frac{1}{|V_k|} \sum_{p \in V_k} \tilde{I}^r(p) $$
*Note: If $V_k$ is empty, the contribution of cluster $k$ to the error for view $r$ is zero [G].*

3. **Calculate Error Metric:** Compute the total error $E_{L2}$ by summing the squared differences of the restricted means, weighted by $c_r$ [S1].
$$ E_{L2}(w_1, \dots, w_K) = \sum_{k=1}^{K} \sum_{r} c_r \left( \text{mean}_k(\tilde{I}^r) - \text{mean}_k(I^r) \right)^2 $$
The goal is to find weights that minimize this metric [S1].
$$ (w_1^*, \dots, w_K^*) = \arg\min_{w_1, \dots, w_K} E_{L2}(w_1, \dots, w_K) $$

4. **Gradient Estimation (for SGD):** To optimize using Stochastic Gradient Descent, compute the partial derivative of $E_{L2}$ with respect to a specific weight $w_{k,j}$ [S1].
$$ \frac{\partial E_{L2}}{\partial w_{k,j}} = 2 \sum_{r} c_r \left( \text{mean}_k(\tilde{I}^r) - \text{mean}_k(I^r) \right) \frac{\partial \text{mean}_k(\tilde{I}^r)}{\partial w_{k,j}} $$
The term $\frac{\partial \text{mean}_k(\tilde{I}^r)}{\partial w_{k,j}}$ represents the sensitivity of the restricted mean of the rendered image to the weight $w_{k,j}$ [S1]. This derivative is estimated via path tracing to obtain an unbiased gradient evaluation [S1].

5. **Weight Update:** Update the weight $w_{k,j}$ using the gradient and a step size $\delta_t$ [S1].
$$ w_{k,j}^{(t+1)} = w_{k,j}^{(t)} - \delta_t \frac{\partial E_{L2}}{\partial w_{k,j}} $$
The step size $\delta_t$ follows a divergent harmonic series to ensure convergence ($\sum \delta_t = \infty$ and $\sum \delta_t^2 < \infty$) [S1].

**Parameters:**
- $c_r$: Normalization factor. Typical implementation uses $\max(\text{mean}(I^r), 0.05)^{-1}$ [S1].
- $\delta_t$: Learning rate. Follows common SGD practices for stochastic optimization [S1].

**Edge Cases and Pitfalls:**
- **Local Minima:** Previous methods using global mean $\text{mean}(\tilde{I}^r)$ only indicated if the whole image was too dark or bright, making it difficult to identify which voxel clusters needed correction [S1]. The restricted mean resolves this by isolating errors to specific clusters [S1].
- **Visibility Boundaries:** If cluster boundaries cut across areas with smoothly varying albedos, visible seams may appear [S1]. The method suggests jittering clusterings by perturbing voxel albedos during K-means clustering to mitigate this [S1].
- **Empty Visibility Sets:** If a cluster is not visible in a particular view, its restricted mean is undefined [G].

## Subtopics

### [Stochastic Gradient Descent for Lobe Weight Optimization](16621-stochastic-gradient-descent-for-lobe-weight-optimization.md)
This method optimizes scalar weight factors for pre-computed SGGX lobe shapes by minimizing the restricted mean squared error between rendered and target images. It differs from direct per-voxel optimization by clustering voxels to share weight factors, which reduces the parameter space and enables efficient optimization. Choose this method when optimizing anisotropic scattering parameters across spatially heterogeneous media.

- **Time Complexity:** Not given in the sources [S1].
- **Memory Complexity:** Not given in the sources [S1].
- **Strengths:** Effectively handles parameter heterogeneity by attributing errors to specific spatial clusters [S1]. It avoids the ambiguity of global mean metrics, leading to more stable convergence in optimizing anisotropic scattering parameters [S1].
- **Limitations:** Requires pre-computed voxel clustering and visibility masks [S1].

## Background
The Restricted Mean Error Metric was introduced in the context of downsampling scattering parameters for rendering anisotropic media [S1]. It addresses limitations in previous work by Zhao et al. (2011) and Khungurn et al. (2015), which used global mean pixel intensity for error metrics [S1]. The global mean approach failed to provide sufficient information for correcting specific voxel clusters, leading to local minima in optimization [S1]. The restricted mean approach was developed to enable efficient optimization of SGGX lobe weights by clustering voxels and sharing weight factors within clusters [S1].
