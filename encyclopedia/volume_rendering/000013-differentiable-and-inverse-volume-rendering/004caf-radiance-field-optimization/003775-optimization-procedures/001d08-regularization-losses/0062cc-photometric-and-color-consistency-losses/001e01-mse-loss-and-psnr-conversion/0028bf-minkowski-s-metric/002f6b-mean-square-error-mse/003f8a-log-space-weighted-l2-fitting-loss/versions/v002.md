# Log-Space Weighted L2 Fitting Loss

Also called: Asymmetric Log-Space L2 Loss

## Overview
A regularization loss function used in radiance-field optimization to fit scattering phase functions, designed to handle asymmetric directional importance [S1, unofficial]. It differs from standard MSE by operating in log-space and applying directional weights to prioritize specific angular regions, such as backward scattering [S1, unofficial].

## How it works
The method computes a weighted L2 loss on the logarithm of predicted and target phase function values, with angular weights that account for spherical integration and backward scattering bias [S1, unofficial].

### Inputs and Outputs
- **Inputs**: Predicted phase function $\phi(\theta)$, target phase function $\phi_{\text{Mie}}(\theta)$, and angle array $\theta$.
- **Outputs**: Scalar loss value $E_{\text{AS}}$.

### Data Structures
- **Values**: Floating-point arrays. Inputs must be strictly positive for the logarithm. [G] If non-positive values are possible, a small epsilon is added before logging, or the loss is masked.

### Formulas and Steps
$$E_{\text{AS}} = \sum_{\theta} |\cos(\theta)| \sin(\theta) \cdot (\log \phi(\theta) - \log \phi_{\text{Mie}}(\theta))^2$$

Where:
- $\phi(\theta)$: Predicted phase function value at angle $\theta$.
- $\phi_{\text{Mie}}(\theta)$: Target Mie scattering phase function value.
- $|\cos(\theta)| \sin(\theta)$: Angular weight. $\sin(\theta)$ accounts for sphere integration, and $|\cos(\theta)|$ increases the influence of backward directions ($\theta \approx \pi$) and forward directions ($\theta \approx 0$) [S1, unofficial].
- The combination of log-space L2 and these weights helps maintain an accurate mean cosine [S1, unofficial].

### Pseudocode
```python
import math

def log_space_weighted_l2_directional(phi_pred, phi_target, angles):
    eps = 1e-8
    loss = 0.0
    for p_pred, p_target, theta in zip(phi_pred, phi_target, angles):
        p_pred = max(p_pred, eps)
        p_target = max(p_target, eps)
        log_diff = math.log(p_pred) - math.log(p_target)
        weight = abs(math.cos(theta)) * math.sin(theta)
        loss += weight * (log_diff ** 2)
    return loss
```

- **$\epsilon$**: Not given in the sources.
- **Loss Weight**: Not given in the sources.

### Edge Cases and Pitfalls
- **Log of Zero/Negative**: Standard L2 on log-transformed values diverges if predictions or targets are $\le 0$. Clamping or adding epsilon is required [G].
- **Precision**: Floating-point underflow in log-space may occur for very small phase values; clamping mitigates this [G].

## Subtopics

### [Gradient-weighted L2 Loss](17259-gradient-weighted-l2-loss.md)
A regularization technique for differentiable volume rendering that stabilizes training on high dynamic range and noisy raw images. It approximates the gradient of a tonemapped loss by weighting the standard L2 residual by the derivative of the tone curve, dynamically suppressing gradients in bright regions and enhancing supervision in dark regions [G]. It sets itself apart from standard MSE by addressing the inadequacy of uniform weighting in scenes with large intensity variations [G].

## Operating characteristics
- **Time Complexity**: $O(N)$ where $N$ is the number of angular samples. Logarithm and weight computation are constant time per sample [G].
- **Memory Complexity**: $O(N)$ to store intermediate residuals and weights [G].
- **Strengths**: Stabilizes fitting in high dynamic range conditions; handles asymmetric directional importance [S1, unofficial].
- **Limitations**: Requires positive inputs for log-space variants; sensitive to $\epsilon$ choice [G].
- **When to Use**: Fitting scattering phase functions with angular bias [S1, unofficial].
- **When Not to Use**: When data contains non-positive values without masking [G].

## Background
The directional log-space L2 loss was introduced in the context of approximating Mie scattering functions for fog and cloud rendering, where maintaining accurate mean cosine and backward scattering influence is critical [S1, unofficial].
