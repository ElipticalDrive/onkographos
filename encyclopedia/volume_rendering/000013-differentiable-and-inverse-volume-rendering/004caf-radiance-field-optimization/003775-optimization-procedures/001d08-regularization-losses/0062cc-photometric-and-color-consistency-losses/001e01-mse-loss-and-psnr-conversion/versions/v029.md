# MSE Loss and PSNR Conversion

Also called: Loss Function for Constant Model, MSE Loss, Mean Squared Error, Mean Squared Error Loss

## Overview
MSE Loss and PSNR Conversion computes the Mean Squared Error (MSE) between predicted and target RGB values (or volumes) and converts this error into Peak Signal-to-Noise Ratio (PSNR) for logging and evaluation [S2, unofficial][S4, unofficial]. It serves as the primary photometric consistency loss for training differentiable volume rendering models by minimizing pixel-wise intensity differences [S4, unofficial][S7, unofficial]. Unlike structural metrics such as SSIM, which measure perceptual similarity, MSE focuses strictly on pixel-wise accuracy, making it sensitive to large smooth regions but largely ignoring high-frequency features like specular highlights [S1, unofficial].

## How it works
**Inputs:**
- Predicted image/volume data ($\hat{I}$ or $\hat{V}$).
- Target/ground-truth image/volume data ($I$ or $V$).
- Optional binary mask ($M$) indicating valid voxels/pixels [S9, unofficial].
- Optional parameters for constant model fitting: density ($\sigma$), step size ($q$), and intensity samples [S3, unofficial].

**Outputs:**
- Scalar loss value (MSE).
- PSNR value (logarithmic scale) [S2, unofficial].
- If masked: masked MSE, masked PSNR, and voxel/pixel count [S9, unofficial].

**Data Structures:**
- Images/Volumes: Tensors or arrays of shape $(B, H, W, C)$ for images or $(D, H, W, C)$ for volumes, where $B$ is batch size, $H, W$ are spatial dimensions, $C$ is channels (typically 3 for RGB), and $D$ is depth [S2, unofficial][S9, unofficial].
- Mask: Boolean tensor of same spatial dimensions as input [S9, unofficial].

**Steps:**

1. **Input Validation:**
   - Ensure inputs are not empty.
   - If using the constant model variant, validate that step size $ds > 0$, density $\sigma \ge 0$, and $q \ge 0$. If invalid, return infinity [S3, unofficial].
   - If using masked MSE, check if input vectors have the same size; if not, raise an error [S10, unofficial].

2. **Compute Squared Differences:**
   - Calculate element-wise difference: $diff = \hat{I} - I$ (or $\hat{V} - V$) [S6, unofficial].
   - Square the difference: $sq\_diff = diff^2$ [S6, unofficial].

3. **Apply Mask (Optional):**
   - If a mask $M$ is provided, create a boolean mask where $M > threshold$ (default threshold relative to max volume is 0.01) [S9, unofficial].
   - If the mask has no true values, raise a `RuntimeError` [S9, unofficial].
   - Apply mask to squared differences: $masked\_sq\_diff = sq\_diff \cdot M$ [S9, unofficial].

4. **Compute MSE:**
   - Flatten spatial dimensions (and batch dimension if aggregating globally) [S6, unofficial].
   - Calculate the mean of squared differences over valid pixels/voxels:
     $$
     MSE = \frac{1}{N} \sum_{i=1}^{N} (\hat{x}_i - y_i)^2
     $$
     where $x$ is predicted, $y$ is target, and $N$ is the number of valid pixels/voxels [S2, unofficial][S8, unofficial].
   - For the constant model variant, sum $0.5 \cdot residual^2$ where residual is the difference between predicted constant intensity and observed intensity [S3, unofficial].

5. **Compute PSNR:**
   - If $MSE > 0$:
     $$
     PSNR = -10 \cdot \log_{10}(MSE)
     $$
     or equivalently:
     $$
     PSNR = 20 \cdot \log_{10}\left(\frac{1}{\sqrt{MSE}}\right)
     $$
     [S2, unofficial][S9, unofficial].
   - If $MSE = 0$, PSNR is infinity [S9, unofficial].

6. **Return Results:**
   - Return dictionary containing `masked_mse`, `masked_psnr`, `masked_voxel_count`, `volume_shape`, `mask_threshold_rel`, and `mask_threshold` if masked [S9, unofficial].
   - Return scalar MSE and PSNR if unmasked [S2, unofficial].

**Pseudocode:**

```python
import math
import numpy as np

def compute_mse_and_psnr(predicted, target, mask=None, mask_threshold_rel=0.01):
    """
    Computes MSE and PSNR between predicted and target images/volumes.
    
    Args:
        predicted: Array of predicted values (float).
        target: Array of target values (float).
        mask: Optional boolean array indicating valid regions.
        mask_threshold_rel: Relative threshold for mask generation if mask is not provided.
        
    Returns:
        mse: Mean Squared Error.
        psnr: Peak Signal-to-Noise Ratio.
        masked_voxel_count: Number of valid voxels/pixels.
    """
    # Step 1: Input Validation
    if predicted.shape != target.shape:
        raise ValueError("Predicted and target must have the same shape.")
    
    # Step 2: Compute Squared Differences
    diff = predicted - target
    sq_diff = diff ** 2
    
    # Step 3: Apply Mask (Optional)
    if mask is None:
        # Create mask based on threshold if not provided
        # Assuming target is the reference for thresholding
        max_val = np.max(target)
        threshold = mask_threshold_rel * max_val
        mask = target > threshold
        
    if not np.any(mask):
        raise RuntimeError("Mask has no true values (empty region).")
        
    masked_sq_diff = sq_diff * mask.astype(float)
    
    # Step 4: Compute MSE
    # Flatten spatial dimensions, keep batch dimension if present
    # For simplicity, assuming single image/volume or batch mean
    valid_values = masked_sq_diff[mask]
    mse = np.mean(valid_values)
    
    # Step 5: Compute PSNR
    if mse > 0:
        psnr = -10.0 * math.log10(mse)
    else:
        psnr = float('inf')
        
    masked_voxel_count = np.sum(mask)
    
    return mse, psnr, masked_voxel_count

def compute_constant_model_mse(intensity, sigma, q, ds):
    """
    Computes MSE for a constant intensity model along a ray.
    
    Args:
        intensity: Array of observed intensity values.
        sigma: Density.
        q: Step size parameter.
        ds: Step size.
        
    Returns:
        loss: MSE loss.
    """
    # Step 1: Input Validation
    if not intensity or ds <= 0 or sigma < 0 or q < 0:
        return float('inf')
        
    loss = 0.0
    # Step 2: Loop over samples
    for k in range(len(intensity)):
        # Predicted intensity for constant model
        # Note: Exact formula for constant_intensity depends on specific implementation
        # Assuming a simplified model where predicted is derived from sigma, q, ds
        predicted = constant_intensity(intensity[0], sigma, q, k * ds)
        residual = predicted - intensity[k]
        loss += 0.5 * (residual ** 2)
        
    return loss

def constant_intensity(ref_intensity, sigma, q, t):
    """
    Placeholder for constant intensity prediction model.
    In a real implementation, this would compute the expected intensity
    based on the physical model (e.g., Beer-Lambert law integration).
    """
    # [G] Generic placeholder: In many NeRF variants, this might be
    # ref_intensity * exp(-sigma * t) or similar, but the exact form
    # is not specified in the sources. We return a dummy value for structure.
    return ref_intensity * math.exp(-sigma * t)
```

**Parameters:**
- `batch_size`: Number of random pixels sampled per iteration [S7, unofficial].
- `lr`: Adam learning rate [S7, unofficial].
- `mask_threshold_rel`: Relative threshold applied to the normalized mask volume to create the boolean mask. Default value is 0.01 [S9, unofficial].
- $v_{min}$: Lower clipping threshold for under-exposed values in Clipped MSE Loss [S15].
- $v_{max}$: Upper clipping threshold for over-exposed values in Clipped MSE Loss [S15].

**Edge Cases and Pitfalls:**
- **Division by Zero:** If $MSE = 0$, PSNR is infinity. This should be handled to avoid numerical issues in logging or gradient computation [S9, unofficial].
- **Empty Mask:** If the boolean mask has no true values, raise a `RuntimeError` [S9, unofficial].
- **Shape Mismatch:** Ensure input vectors have the same size; if not, throw an error [S10, unofficial].
- **Precision:** Use float32 or float64 consistently to avoid precision loss in squared differences [S2, unofficial].

## Subtopics

### [PSNR Metric Calculation](2742-psnr-metric-calculation.md)
PSNR is a standard benchmark metric used to evaluate the photometric fidelity of reconstructed images or volumes in novel view synthesis and 3D reconstruction. It quantifies the error between a predicted image and a ground-truth reference by converting the Mean Squared Error (MSE) into a logarithmic decibel (dB) scale, where higher values indicate better quality. Unlike structural metrics such as SSIM, PSNR focuses strictly on pixel-wise intensity accuracy, making it sensitive to large smooth regions while largely ignoring small, high-frequency features like specular highlights.

### [SSIM Metric Calculation](3650-ssim-metric-calculation.md)
SSIM is a full-reference quality assessment metric that evaluates image fidelity by measuring perceptual similarity through local comparisons of luminance, contrast, and structure. Unlike pixel-wise error metrics such as MSE or PSNR, which often correlate poorly with human perception, SSIM captures structural information changes to approximate perceived distortion. It is widely used as a standard benchmark for image quality in 3D reconstruction and novel view synthesis.

### [Normal-L2 Score Computation](3842-normal-l2-score-computation.md)
The Normal-L2 Score computes the mean squared error between predicted surface normals and ground-truth normals to evaluate geometric fidelity in radiance-field optimization. It differs from sibling metrics like [PSNR Metric Calculation](2742-psnr-metric-calculation.md) by focusing on shading-critical surface orientation rather than color intensity, and from [IoU Loss](7110-iou-loss.md) by measuring local geometric accuracy rather than global silhouette alignment.

### [Minkowski's Metric](4347-minkowski-s-metric.md)
Minkowski's Metric (also known as the Lp norm or Lgamma loss) is a family of photometric consistency losses used in radiance-field optimization to quantify the dissimilarity between a rendered image and a ground-truth reference. It generalizes the Mean Squared Error (MSE) by allowing the exponent $\gamma$ to vary, enabling a trade-off between sensitivity to large errors and robustness to outliers. Unlike MSE, which penalizes large deviations quadratically, Minkowski's Metric with $\gamma < 2$ (e.g., L1) is less sensitive to outliers, while $\gamma > 2$ increases sensitivity to large errors.

### [IoU Loss](7110-iou-loss.md)
IoU Loss is a binary segmentation metric that computes the ratio of overlapping voxels above a threshold to the total union of predicted and target voxels.

### [Perceptually-motivated variance metric](9969-perceptually-motivated-variance-metric.md)
The perceptually-motivated variance metric quantifies the error between an 8-bit ambient occlusion (AO) approximation $T$ and a high-fidelity ray-traced reference $R$. It differs from raw pixel Mean Squared Error (MSE) by operating on log-transformed values and spatial gradients, thereby aligning with human visual sensitivity to radiance and its changes. This metric is specifically designed for evaluating AO approximations where reflected ambient radiance is linear in accessibility.

### [Depth Accuracy Metrics](10453-depth-accuracy-metrics.md)
Depth Accuracy Metrics evaluate the geometric fidelity of predicted depth maps against ground truth data in radiance field optimization pipelines. They quantify scale- and translation-invariant errors on valid depth pixels. They are used to evaluate depth prior quality and monocular depth estimation outputs in NeRF pipelines.

### [Discrete Wavelet Transform Loss](11910-discrete-wavelet-transform-loss.md)
The Discrete Wavelet Transform (DWT) Loss is a regularization term for Neural Radiance Fields (NeRF) that minimizes the difference between the frequency representations of rendered and ground-truth images by decomposing them into sub-bands. It addresses high-frequency overfitting in few-shot NeRF training by explicitly prioritizing low-frequency learning during early stages. Unlike its sibling [MSE Loss and PSNR Conversion](1651-mse-loss-and-psnr-conversion.md), which compares pixel-wise values globally, the DW loss operates on local structures using patch-based sampling to supervise low and mid-frequency components.

### [RMSE Loss for Constant Model](14613-rmse-loss-for-constant-model.md)
Calculates the Root Mean Squared Error (RMSE) between observed intensity values and a predicted constant intensity model parameterized by density ($\sigma$) and step size ($q$). It serves as a photometric consistency loss in differentiable volume rendering, specifically fitting a constant radiance assumption along a ray. Unlike the parent [MSE Loss and PSNR Conversion](1651-mse-loss-and-psnr-conversion.md) which operates on raw RGB predictions, this method explicitly models the physical integration of a constant source over a ray segment.

### [Normalized L1 Loss](15480-normalized-l1-loss.md)
Computes a normalized L1 loss between a reconstructed image and an original image, scaling the loss to the $[0, 1]$ range. It is used in sparse pixel sampling optimization pipelines to provide a scale-invariant error metric for adaptive Gaussian densification and pruning.

### [Masked and Weighted Losses](15713-masked-and-weighted-losses.md)
Masked and Weighted Losses is a family of techniques that modify the standard photometric error computation in differentiable volume rendering by applying spatial masks or per-pixel weights to the loss function. It solves the problem of training instability and evaluation bias caused by invalid background regions, sensor artifacts, multiscale resolution disparities, or structural inconsistencies. It sets itself apart from its sibling [MSE Loss and PSNR Conversion](1651-mse-loss-and-psnr-conversion.md) by introducing selective suppression or amplification of error terms rather than computing a global average, and from [Masked Volume Metrics](1927-masked-volume-metrics.md) by focusing on training-time gradient correction rather than evaluation-time metric definition.

### [Restricted Mean Error Metric](16552-restricted-mean-error-metric.md)
The Restricted Mean Error Metric is a loss function designed to optimize scalar weight factors for pre-computed scattering lobe shapes in volume rendering, specifically addressing parameter heterogeneity across voxel clusters. Unlike standard Mean Squared Error (MSE) which treats all pixels equally or global mean metrics that obscure local errors, this method computes the average intensity only for pixels "directly" visible to specific voxel clusters, allowing the optimizer to identify which clusters cause rendering artifacts (such as seams) and correcting them individually. It is primarily used in the context of optimizing SGGX lobe weights via Stochastic Gradient Descent (SGD).

### MSE Bias-Variance Decomposition
Treating the TAA algorithm as a biased estimator to analyze correctness using Mean Squared Error (MSE), decomposed into variance and bias squared [S11, unofficial]. The formula is $\text{MSE}[F] = \mathbb{E}[(F - G)^2] = V[F] + \beta[F]^2$, where $F$ is the output of the estimator, $G$ is the true value (ground truth), $V[F]$ is the variance of the estimator, and $\beta[F]$ is its bias [S11, unofficial].

### Greedy proposal matching
A fast assignment strategy used during Phase 1 to compute the L2 matching loss between heuristic samples and learnt proposals [S12, unofficial]. For each heuristic sample, find the closest proposal from the learnt proposer set [S12, unofficial]. Optimal matching (Hungarian algorithm) or strict 1-1 greedy matching significantly slows training [S12, unofficial].

### MSLE Loss
Calculates Mean Squared Logarithmic Error between two RGB colors, optionally weighted by luminance [S13, unofficial]. The formula is $MSLE = \sum_c (\log_2(\frac{b_c + 1.0}{a_c + 1.0}))^2 \cdot w_c$ where $w_c$ is 1.0 or luminance weight [S13, unofficial].

### Blur Loss
L2 loss between the simulated blurry image and the input blurry image [S14]. Parameter: $B(x)$: Input blurry image at pixel $x$ [S14].

### Clipped MSE Loss
A pixel-wise mean squared loss operating in linear color space (no gamma compression) that handles under-exposed and over-exposed values using a one-sided difference based on clipping thresholds [S15]. Parameters: $v_{min}$: The lower clipping threshold for under-exposed values. Values below this are penalized only if they are above the threshold (one-sided difference) [S15]. $v_{max}$: The upper clipping threshold for over-exposed values. Values above this are penalized only if they are below the threshold [S15].

### Silhouette Loss
Parameters: $m$: Image mask, values in $\{0, 1\}$ [S16]. $s$: Predicted signed distance [S16]. $\tau$: Truncation distance for the SDF model [S16]. $\sigma$: Predicted ray hit probability from DDF [S16]. $L_\sigma$: DDF silhouette loss from Eq. (8) [S16].

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of pixels or voxels, as it involves a single pass to compute squared differences and mean [S2, unofficial][S6, unofficial].
- **Memory Complexity:** $O(N)$ to store the squared differences and intermediate results [S6, unofficial].
- **Measured Performance:** Used as the primary loss function in many NeRF implementations, providing stable convergence for photometric consistency [S4, unofficial][S7, unofficial].
- **Scaling:** Scales linearly with resolution and batch size [S6, unofficial].
- **Strengths:** Simple to implement, differentiable, and widely understood as a standard metric for image quality [S1, unofficial][S2, unofficial].
- **Limitations:** Does not account for structural similarity or perceptual quality, often correlating poorly with human perception compared to SSIM or LPIPS [S1, unofficial][S7, unofficial]. Sensitive to outliers and high-frequency noise [S1, unofficial].
- **When to use:** When pixel-wise accuracy is the primary goal, or as a baseline loss function for training differentiable volume rendering models [S4, unofficial][S7, unofficial].
- **When not to use:** When perceptual quality or structural fidelity is more important than pixel-wise accuracy, or when dealing with images containing significant high-frequency details or specular highlights [S1, unofficial].

## Background
MSE Loss and PSNR Conversion originated as standard image fidelity scores used to evaluate the quality of 3D reconstructions and novel 2D views [S1, unofficial]. It has been widely adopted in the field of Neural Radiance Fields (NeRF) and differentiable volume rendering as the primary loss function for training [S4, unofficial][S7, unofficial]. The method is often used in conjunction with other metrics like SSIM to provide a more comprehensive evaluation of reconstruction quality [S1, unofficial].
