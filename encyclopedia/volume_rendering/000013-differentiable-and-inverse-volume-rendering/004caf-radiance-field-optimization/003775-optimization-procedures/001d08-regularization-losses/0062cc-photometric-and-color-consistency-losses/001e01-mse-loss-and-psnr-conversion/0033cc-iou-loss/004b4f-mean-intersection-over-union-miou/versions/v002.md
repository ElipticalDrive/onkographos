# Mean Intersection over Union (mIoU)
Also called: Jaccard index, mIoU

## Overview
Mean Intersection over Union (mIoU) is a segmentation evaluation metric that quantifies the overlap between predicted and ground-truth masks by averaging the Intersection over Union (IoU) across all semantic classes [S1, unofficial][S2]. It serves as a standard accuracy measure for semantic segmentation tasks, distinct from pixel accuracy which can be skewed by class imbalance [S2].

## How it works
**Inputs and Outputs:**
- **Input:** Predicted segmentation masks $P = \{p_1, ..., p_N\}$ and ground-truth masks $G = \{g_1, ..., g_N\}$ for $N$ classes [S1, unofficial][S2].
- **Output:** A scalar value $mIoU \in [0, 1]$ representing the mean overlap [S1, unofficial][S2].

**Data Structures:**
- Binary masks for each class $c$, where $1$ indicates the class is present and $0$ otherwise [S2].
- Counters for True Positives ($TP_c$), False Positives ($FP_c$), and False Negatives ($FN_c$) for each class [S1, unofficial].

**Steps:**
1. For each class $c$ from $1$ to $N_c$:
   a. Identify True Positives ($TP_c$): Voxels/pixels where both prediction $p_c$ and ground truth $g_c$ are $1$ [S1, unofficial].
   b. Identify False Positives ($FP_c$): Voxels/pixels where prediction $p_c$ is $1$ but ground truth $g_c$ is $0$ [S1, unofficial].
   c. Identify False Negatives ($FN_c$): Voxels/pixels where prediction $p_c$ is $0$ but ground truth $g_c$ is $1$ [S1, unofficial].
   d. Compute IoU for class $c$:
      $$ IoU_c = \frac{TP_c}{TP_c + FP_c + FN_c} $$
      [S1, unofficial]
   e. Handle the edge case where the denominator is zero (no voxels predicted or present for class $c$). If $TP_c + FP_c + FN_c = 0$, define $IoU_c = 1$ if both masks are empty, else $0$ [G].
2. Compute the mean across all classes:
   $$ mIoU = \frac{1}{N_c} \sum_{c=1}^{N_c} IoU_c $$
   [S1, unofficial]

**Parameters:**
- $N_c$: The total number of semantic classes [S1, unofficial].

**Pseudocode:**
```python
def compute_miou(predictions, ground_truth, num_classes):
    """
    Compute Mean Intersection over Union.
    predictions: List of binary masks for each class, shape (N, H, W) or (N, D, H, W)
    ground_truth: List of binary masks for each class, shape (N, H, W) or (N, D, H, W)
    num_classes: Integer N_c
    """
    miou_sum = 0.0
    for c in range(num_classes):
        p = predictions[c]
        g = ground_truth[c]
        tp = sum(1 for x, y in zip(p, g) if x == 1 and y == 1)
        fp = sum(1 for x, y in zip(p, g) if x == 1 and y == 0)
        fn = sum(1 for x, y in zip(p, g) if x == 0 and y == 1)
        denominator = tp + fp + fn
        if denominator == 0:
            iou_c = 1.0 if (tp == 0 and fp == 0 and fn == 0) else 0.0
        else:
            iou_c = tp / denominator
        miou_sum += iou_c
    return miou_sum / num_classes
```

## Operating characteristics
- **Strengths:** Provides a balanced evaluation of segmentation quality across all classes by averaging per-class IoU [S1, unofficial][S2].
- **Limitations:** Sensitive to class imbalance if not averaged correctly, though mIoU averages per-class so rare classes contribute equally to the mean [S2].
- **Use Cases:** Standard evaluation metric for semantic segmentation tasks [S1, unofficial][S2].

## Background
mIoU is a standard metric in computer vision segmentation tasks [S1, unofficial][S2]. It is also referred to as the Jaccard index [S2]. In 3D scene understanding, it is reported alongside other metrics like LPIPS and Chamfer Distance for comprehensive evaluation [S1, unofficial].
