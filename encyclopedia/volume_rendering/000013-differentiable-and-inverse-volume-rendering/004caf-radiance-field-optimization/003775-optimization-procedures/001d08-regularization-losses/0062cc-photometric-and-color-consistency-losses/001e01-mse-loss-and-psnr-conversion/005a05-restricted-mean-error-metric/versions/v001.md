# Restricted Mean Error Metric

Also called: Cluster-specific error metric, Error Metric for Optimization, Restricted Mean Error Metric for Weight Optimization, Restricted mean pixel intensity

## Overview
The Restricted Mean Error Metric is a loss function designed to optimize scattering parameters (specifically phase function weights) in volume rendering by addressing parameter heterogeneity across voxel clusters. Unlike standard Mean Squared Error (MSE) which compares global image averages, this metric computes the squared difference between the average intensities of rendered and reference images restricted to specific spatial clusters, thereby identifying which voxel groups require correction. It is primarily used in the optimization of anisotropic media rendering where global intensity metrics fail to guide local weight adjustments.

## How it works
The method minimizes the discrepancy between a rendered image $\tilde{I}^r$ and a reference image $I^r$ by enforcing consistency within spatially defined clusters of voxels.

**Inputs and Outputs:**
*   **Inputs:**
    *   $K$: The number of voxel clusters.
    *   $\tilde{I}^r$: The rendered image for view $r$.
    *   $I^r$: The reference (ground truth) image for view $r$.
    *   $w_{k,j}$: The optimization variables, representing the weight of the $j$-th lobe for cluster $k$.
    *   $R$: The set of training views.
*   **Outputs:**
    *   Optimized weights $w_{k,j}^*$ that minimize the error metric.

**Data Structures:**
*   **Cluster Assignment:** Each voxel $i$ is assigned to a cluster $k$ via a mapping $c(i) = k$. This is typically derived via K-means clustering on downsampled voxel parameters, potentially with jittering to avoid seams [S1].
*   **Visibility Mask:** For each cluster $k$ and view $r$, a set of pixels $P_{k,r}$ is defined. These are the pixels to which downsampled voxels from cluster $k$ are "directly" visible [S1].

**Formulas:**
The core metric is the Restricted Mean Error $E_{L2}$, defined as:

$$ E_{L2}(w_1, \dots, w_K) := \sum_{k=1}^{K} \sum_{r \in R} c_r \left( \text{mean}_k(\tilde{I}^r) - \text{mean}_k(I^r) \right)^2 $$

Where:
*   $\text{mean}_k(I^r)$ is the **restricted mean pixel intensity** for cluster $k$ in image $I^r$. It is calculated as the average intensity of pixels in $P_{k,r}$:
    $$ \text{mean}_k(I^r) = \frac{1}{|P_{k,r}|} \sum_{p \in P_{k,r}} I^r(p) $$
*   $c_r$ is a normalization weight for view $r$, defined as:
    $$ c_r = \max(\text{mean}(I^r), 0.05)^{-1} $$
    Here, $\text{mean}(I^r)$ is the global average intensity of all foreground pixels in the reference image $I^r$ [S1].

The optimization goal is to find the weights that minimize this error:
$$ (w_1^*, \dots, w_K^*) = \arg\min_{w_1, \dots, w_K} E_{L2}(w_1, \dots, w_K) $$

**Numbered Steps:**
1.  **Cluster Voxels:** Group voxels into $K$ clusters based on their scattering parameters (e.g., using K-means on downsampled data). Apply jittering to cluster boundaries to reduce visible seams [S1].
2.  **Render Views:** For each training view $r$, render the scene using current weights $w_{k,j}$ to obtain $\tilde{I}^r$.
3.  **Compute Restricted Means:** For each cluster $k$ and view $r$, identify the set of pixels $P_{k,r}$ directly visible to cluster $k$. Compute $\text{mean}_k(\tilde{I}^r)$ and $\text{mean}_k(I^r)$.
4.  **Compute Normalization Weights:** Calculate $c_r$ for each view using the global mean of the reference image $I^r$.
5.  **Calculate Error:** Compute $E_{L2}$ using the summation formula above.
6.  **Optimize Weights:** Use Stochastic Gradient Descent (SGD) to update weights. The gradient for a specific weight $w_{k,j}$ is derived from the chain rule:
    $$ \frac{\partial E_{L2}}{\partial w_{k,j}} = 2 \sum_{r \in R} c_r \left( \text{mean}_k(\tilde{I}^r) - \text{mean}_k(I^r) \right) \frac{\partial \text{mean}_k(\tilde{I}^r)}{\partial w_{k,j}} $$
    Update rule:
    $$ w_{k,j}^{(t+1)} = w_{k,j}^{(t)} - \delta_t \frac{\partial E_{L2}}{\partial w_{k,j}} $$
    where $\delta_t$ is the step size, typically following a divergent harmonic series schedule ($\sum \delta_t = \infty, \sum \delta_t^2 < \infty$) [S1].

**Pseudocode:**

```python
def compute_restricted_mean_error(
    rendered_images: List[Image],
    reference_images: List[Image],
    cluster_pixel_sets: Dict[int, List[Pixel]],
    weights: Dict[int, Dict[int, float]],
    num_clusters: int
) -> float:
    """
    Computes the Restricted Mean Error metric.
    
    Args:
        rendered_images: List of rendered images I_tilde^r.
        reference_images: List of reference images I^r.
        cluster_pixel_sets: Mapping from cluster index k to list of pixel indices P_{k,r} for each view.
                           Note: In practice, this structure depends on the view r.
                           Assumed structure: cluster_pixel_sets[k][r] = [pixel_indices]
        weights: Current scattering weights w_{k,j}.
        num_clusters: Total number of clusters K.
        
    Returns:
        The scalar error value E_L2.
    """
    total_error = 0.0
    
    for r, (I_tilde, I_ref) in enumerate(zip(rendered_images, reference_images)):
        # 1. Compute global mean for normalization factor c_r
        # Assuming I_ref contains only foreground pixels or a mask is applied
        global_mean_ref = mean_intensity(I_ref)
        
        # Normalization factor: c_r = max(mean(I^r), 0.05)^-1
        c_r = 1.0 / max(global_mean_ref, 0.05)
        
        for k in range(num_clusters):
            # 2. Get pixels directly visible to cluster k in view r
            pixels = cluster_pixel_sets[k][r]
            
            if not pixels:
                continue
                
            # 3. Compute restricted means
            # mean_k(I^r) = average intensity of pixels in P_{k,r}
            ref_values = [I_ref[p] for p in pixels]
            rendered_values = [I_tilde[p] for p in pixels]
            
            mean_k_ref = sum(ref_values) / len(ref_values)
            mean_k_rendered = sum(rendered_values) / len(rendered_values)
            
            # 4. Accumulate squared difference weighted by c_r
            diff = mean_k_rendered - mean_k_ref
            total_error += c_r * (diff ** 2)
            
    return total_error

def update_weights_sgd(
    weights: Dict[int, Dict[int, float]],
    gradients: Dict[int, Dict[int, float]],
    step_size: float
):
    """
    Updates weights using SGD.
    
    Args:
        weights: Current weights w_{k,j}.
        gradients: Pre-computed gradients dE_L2/dw_{k,j}.
        step_size: Delta_t.
    """
    for k in weights:
        for j in weights[k]:
            weights[k][j] -= step_size * gradients[k][j]
```

**Edge Cases and Pitfalls:**
*   **Local Minima:** Using the global mean $\text{mean}(\tilde{I}^r)$ instead of the restricted mean makes it difficult to identify which voxel clusters cause errors, leading to optimization getting stuck in local minima [S1].
*   **Parameter Heterogeneity:** The metric is specifically designed to handle cases where a single global weight is insufficient. If clusters are not distinct, the restricted mean may not provide useful gradient signals [S1].
*   **Seams:** If cluster boundaries align with sharp albedo changes, visible seams may appear. Jittering the cluster assignments during K-means helps mitigate this [S1].

## Operating characteristics
*   **Complexity:** The error computation is linear with respect to the number of clusters $K$ and the number of training views $R$, and proportional to the number of pixels in the visibility masks. Gradient computation requires differentiating the rendering process with respect to weights, which depends on the specific renderer's differentiability.
*   **Strengths:** It provides specific feedback for individual voxel clusters, enabling the optimization of anisotropic scattering parameters that vary spatially. It handles parameter heterogeneity better than global MSE.
*   **Limitations:** It requires pre-computed cluster assignments and visibility masks. It is sensitive to the quality of the clustering step.
*   **When to use:** Use when optimizing spatially varying anisotropic scattering parameters in volume rendering, particularly when global intensity metrics fail to guide the optimization.
*   **When not to use:** Do not use for global color correction or when scattering parameters are assumed to be uniform across the entire volume.

## Background
The Restricted Mean Error Metric was introduced in the context of downsampling scattering parameters for rendering anisotropic media. It addresses limitations in previous work (e.g., Zhao et al. 2011; Khungurn et al. 2015) that used global mean intensity, which failed to identify specific voxel clusters needing correction. The method is detailed in the paper "Downsampling scattering parameters for rendering anisotropic media" published in the SIGGRAPH Asia 2016 Proceedings [S1].
