# Noise Floor Estimation via MAD

Also called: MAD-based noise estimation, Noise floor estimation

## Overview
Estimates the noise standard deviation $\sigma$ of a volume to determine the irreducible error floor, which is necessary for calculating the theoretical maximum PSNR [S1, unofficial]. It distinguishes itself from simple global variance by using robust Median Absolute Deviation (MAD) estimators on high-frequency residuals, making it resistant to signal structures that would bias standard deviation calculations [S1, unofficial].

## How it works
**Inputs:** A 3D volume $V$ normalized to $[0, 1]$.
**Outputs:** Noise standard deviation $\sigma$ and Noise Floor PSNR.

**Data Structures:**
*   $V$: Input volume array of shape $(D_x, D_y, D_z)$.
*   $R$: Residual array of the same shape as the Laplacian or Haar response.

**Steps:**

1.  **Compute Laplacian MAD Estimator:**
    *   Compute the $D$-dimensional discrete Laplacian response $L$ for each voxel. For a voxel at $(x,y,z)$, the Laplacian is the sum of differences between the center and its neighbors. The kernel norm is $2D(2D+1)$ where $D=3$ [S1, unofficial].
    *   Calculate the Median Absolute Deviation of the response: $MAD_L = \text{median}(|L - \text{median}(L)|)$.
    *   Estimate $\sigma_L = \frac{MAD_L}{0.6745 \times \sqrt{2D(2D+1)}}$ [S1, unofficial].

2.  **Compute Haar Finite-Difference MAD Estimator:**
    *   Compute diagonal second differences $d$ for each voxel: $d_{y,x} = I_{y,x} - I_{y,x+1} - I_{y+1,x} + I_{y+1,x+1}$ [S1, unofficial].
    *   Calculate the MAD of the differences: $MAD_H = \text{median}(|d - \text{median}(d)|)$.
    *   Estimate $\sigma_H = \frac{MAD_H}{0.6745 \times \sqrt{2}}$ [S1, unofficial].

3.  **Compute Background MAD Estimator (Conditional):**
    *   Identify background voxels as those with intensity below the 10th percentile of the volume's intensity distribution [S1, unofficial].
    *   If sufficient background voxels are present, calculate the standard deviation of these voxels as $\sigma_B$. If not, this estimator is unavailable [S1, unofficial].

4.  **Ensemble Estimate:**
    *   Collect all available estimates ($\sigma_L, \sigma_H, \sigma_B$).
    *   The final noise standard deviation $\sigma$ is the median of the available estimates [S1, unofficial].

5.  **Calculate Noise Floor PSNR:**
    *   Compute PSNR using the formula: $\text{PSNR} = 10 \log_{10}\left(\frac{1}{\sigma^2}\right)$ [S1, unofficial].

**Pitfalls:**
*   **Zero Estimation:** MAD estimators may return exactly zero for some volumes (e.g., Mouse heart nuclei). This indicates the model is signal-limited, not noise-limited, and the estimator bounds nothing [S1, unofficial].
*   **Signal Contamination:** If the volume contains significant high-frequency signal structures, the Laplacian and Haar estimators may overestimate noise. The background estimator helps mitigate this but requires sufficient background presence [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def noise_floor_estimation(volume):
    """
    Estimates noise floor PSNR using MAD-based estimators.
    volume: np.ndarray, shape (Dx, Dy, Dz), normalized to [0, 1]
    """
    sigma_estimates = []
    
    # 1. Laplacian MAD Estimator
    # Compute 3D discrete Laplacian
    # Kernel norm for 3D Laplacian is 2*3*(2*3+1) = 24
    laplacian_kernel = np.zeros((3, 3, 3))
    laplacian_kernel[1, 1, 1] = -26 # Center
    # Neighbors
    for i in [-1, 1]:
        for j in [-1, 1]:
            for k in [-1, 1]:
                if i == 0 and j == 0 and k == 0:
                    continue
                laplacian_kernel[1+i, 1+j, 1+k] = 1
    # Apply convolution (valid padding to match output size)
    from scipy.signal import convolve3d
    laplacian_response = convolve3d(volume, laplacian_kernel, mode='valid')
    mad_l = np.median(np.abs(laplacian_response - np.median(laplacian_response)))
    sigma_l = mad_l / (0.6745 * np.sqrt(24))
    sigma_estimates.append(sigma_l)
    
    # 2. Haar Finite-Difference MAD Estimator
    # Compute diagonal second differences
    # d = I(y,x) - I(y,x+1) - I(y+1,x) + I(y+1,x+1)
    # This is a 2D operation per slice. Assuming volume is (Z, Y, X)
    if volume.shape[1] > 1 and volume.shape[2] > 1:
        # Extract slices
        slices = volume
        # Compute differences
        # d[y, x] = slices[y, x] - slices[y, x+1] - slices[y+1, x] + slices[y+1, x+1]
        d = slices[:-1, :-1] - slices[:-1, 1:] - slices[1:, :-1] + slices[1:, 1:]
        mad_h = np.median(np.abs(d - np.median(d)))
        sigma_h = mad_h / (0.6745 * np.sqrt(2))
        sigma_estimates.append(sigma_h)
        
    # 3. Background MAD Estimator
    # Voxels below 10th percentile
    threshold = np.percentile(volume, 10)
    background_voxels = volume[volume < threshold]
    if len(background_voxels) > 100: # Arbitrary threshold for "enough"
        sigma_b = np.std(background_voxels)
        sigma_estimates.append(sigma_b)
        
    # 4. Ensemble Estimate
    if not sigma_estimates:
        return None, None # No estimators available
        
    sigma = np.median(sigma_estimates)
    
    # 5. Noise Floor PSNR
    # PSNR = 10 * log10(1 / sigma^2)
    if sigma == 0:
        return None, None # Signal-limited, noise floor undefined
    psnr = 10 * np.log10(1 / (sigma ** 2))
    
    return sigma, psnr
```

## Subtopics

### [Noise Floor Estimation via MAD and Adaptive Thresholding](20183-noise-floor-estimation-via-mad-and-adaptive-thresholding.md)
Generates a soft [0,1] mask from a residual field, gated by a robust per-frame noise floor calculated from the median and MAD of valid residuals. It distinguishes itself from basic MAD estimation by introducing adaptive thresholding based on per-pixel noise statistics and spatial support filtering to isolate static background from dynamic foreground or noise. It builds on [Noise Floor Estimation via MAD](3105-noise-floor-estimation-via-mad.md).

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of voxels, as it involves a single pass for median/MAD calculation and a constant-size convolution.
*   **Memory Complexity:** Linear, requiring storage for the residual arrays.
*   **Strengths:** Robust to outliers and signal structures; does not assume Gaussian noise distribution.
*   **Limitations:** May return zero for signal-limited data; requires sufficient background for the background estimator.
*   **When to use:** When estimating the theoretical maximum PSNR for a volume rendering optimization process.
*   **When not to use:** When the volume is purely signal-limited (MAD returns zero) or when noise is non-stationary and requires per-pixel estimation.

## Background
Originated in the context of evaluating Gaussian splatting models for microscopy data, where accurate noise estimation is crucial for comparing against compression baselines like H.265 [S1, unofficial]. The method adapts robust statistical estimators (Laplacian and Haar MAD) from image processing literature (Immerkær, Donoho & Johnstone) to 3D volumes [S1, unofficial].
