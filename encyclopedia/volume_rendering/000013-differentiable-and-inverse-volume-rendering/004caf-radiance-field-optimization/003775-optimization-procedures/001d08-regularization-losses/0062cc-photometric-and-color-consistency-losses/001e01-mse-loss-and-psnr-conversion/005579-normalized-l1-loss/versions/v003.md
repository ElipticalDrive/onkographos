# Normalized L1 Loss

Also called: L1 Loss, Sparse Loss Calculation, normalized L1

## Overview
Computes a normalized L1 loss between a reconstructed image and an original image, scaling the loss to the $[0, 1]$ range [S1, unofficial]. It is used in sparse pixel sampling optimization pipelines to provide an error metric for adaptive Gaussian densification and pruning [S2, unofficial].

## How it works
**Inputs:**
- `reconstructed_image`: Tensor of predicted RGB values [S1, unofficial].
- `original_image`: Tensor of ground truth RGB values [S1, unofficial].

**Outputs:**
- `l1_loss_norm`: Tensor of normalized L1 error per pixel [S1, unofficial].

**Steps:**
1. Compute the absolute difference between the reconstructed and original images: $\Delta = |\text{reconstructed\_image} - \text{original\_image}|$ [S1, unofficial].
2. Compute the mean absolute error along the channel dimension: $\text{l1\_loss} = \text{mean}(\Delta, \text{dim}=0)$ [S1, unofficial]. The result is detached from the computation graph [S1, unofficial].
3. Compute the minimum and maximum values of `l1_loss` across all spatial elements: $\text{min\_val} = \min(\text{l1\_loss})$, $\text{max\_val} = \max(\text{l1\_loss})$ [S1, unofficial].
4. Normalize the loss using min-max scaling: $\text{l1\_loss\_norm} = (\text{l1\_loss} - \text{min\_val}) / (\text{max\_val} - \text{min\_val})$ [S1, unofficial].

**Pseudocode:**
```python
def normalized_l1_loss(reconstructed_image, original_image):
    diff = abs(reconstructed_image - original_image)
    l1_loss = mean(diff, dim=0)
    # Detach from computation graph [S1, unofficial]
    min_val = min(l1_loss)
    max_val = max(l1_loss)
    if max_val == min_val:
        return l1_loss * 0
    l1_loss_norm = (l1_loss - min_val) / (max_val - min_val)
    return l1_loss_norm
```

**Parameters:** Not given in the sources [G].

**Edge cases and pitfalls:** If all pixel errors are identical, the denominator becomes zero and the result is undefined [G]. The normalization is global per image [S1, unofficial].
