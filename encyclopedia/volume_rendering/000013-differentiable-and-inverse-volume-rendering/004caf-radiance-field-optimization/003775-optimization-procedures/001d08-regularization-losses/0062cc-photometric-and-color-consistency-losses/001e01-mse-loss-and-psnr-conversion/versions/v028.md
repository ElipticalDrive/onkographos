# MSE Loss and PSNR Conversion

Also called: Loss Function for Constant Model, MSE Loss, Mean Squared Error, Mean Squared Error Loss

## Overview
MSE Loss and PSNR Conversion computes the Mean Squared Error (MSE) between predicted and target RGB values (or volume intensities) to serve as the primary photometric consistency loss for training differentiable volume rendering models [S2, S4, S7, unofficial]. It simultaneously converts this MSE into Peak Signal-to-Noise Ratio (PSNR) for logging reconstruction quality [S2, unofficial]. Unlike structural metrics such as SSIM, MSE focuses strictly on pixel-wise intensity accuracy, making it sensitive to large smooth regions while largely ignoring small, high-frequency features like specular highlights [S1, unofficial]. It builds on [Photometric and Color Consistency Losses](8132-photometric-and-color-consistency-losses.md) by providing the fundamental differentiable error signal that propagates gradients through the rendering operator [44-radiance-field-optimization.md].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Predicted image/volume data ($\hat{Y}$ or $\hat{v}$), Target image/volume data ($Y$ or $v$), and optionally a binary validity mask ($M$).
*   **Outputs:** Scalar MSE loss value, PSNR value (for logging).

**Data Structures:**
*   **Predicted/Target Data:** Tensors or arrays of shape $(B, H, W, C)$ for images or $(B, D, H, W, C)$ for volumes, where $B$ is batch size, $H, W$ are spatial dimensions, $C$ is channels (typically 3 for RGB), and $D$ is depth. Values are typically in linear color space [S15].
*   **Mask:** Boolean array of same spatial dimensions as input, indicating valid pixels/voxels [S9, unofficial].

**Steps:**
1.  **Input Validation:** Ensure inputs are not empty and have matching shapes [S3, S10, unofficial]. If using a mask, ensure it contains at least one true value [S9, unofficial].
2.  **Compute Difference:** Calculate element-wise difference between predicted and target: $D = \hat{Y} - Y$ [S6, unofficial].
3.  **Square Difference:** Square the difference element-wise: $S = D^2$ [S6, unofficial].
4.  **Masking (Optional):** If a mask $M$ is provided, apply it to the squared errors. Let $N$ be the number of elements where $M$ is true. The masked squared error is computed only over these indices [S9, unofficial].
5.  **Average:** Compute the mean of the squared errors over the valid elements (flattening spatial and channel dimensions) to get MSE [S2, S6, S8, unofficial]:
    $$
    \text{MSE} = \frac{1}{N} \sum_{i=1}^{N} (\hat{y}_i - y_i)^2
    $$
    where $\hat{y}_i$ and $y_i$ are the predicted and target values at index $i$, and $N$ is the count of valid elements [S2, S8, unofficial].
6.  **PSNR Conversion:** Convert MSE to PSNR in decibels (dB) [S2, S9, unofficial]:
    $$
    \text{PSNR} = 20 \cdot \log_{10}\left(\frac{1}{\sqrt{\text{MSE}}}\right) = -10 \cdot \log_{10}(\text{MSE})
    $$
    If $\text{MSE} = 0$, PSNR is defined as $\infty$ [S9, unofficial].

**Parameters:**
*   **mask_threshold_rel:** Relative threshold applied to the normalized mask volume to create the boolean mask. Default value is `0.01` [S9, unofficial].
*   **batch_size:** Number of random pixels sampled per iteration for training [S7, unofficial].

**Edge Cases and Pitfalls:**
*   **Division by Zero/Log of Zero:** If the mask is empty or all errors are zero, PSNR becomes infinite. Implementations should handle this by returning infinity or a large constant [S9, unofficial].
*   **Color Space:** MSE should be computed in linear color space, not gamma-compressed space, to avoid biasing the loss towards darker regions [S15].
*   **Shape Mismatch:** Inputs must have identical shapes; otherwise, an error should be raised [S10, unofficial].

**Pseudocode:**
```python
import math
import numpy as np

def compute_mse_and_psnr(predicted: np.ndarray, target: np.ndarray, mask: np.ndarray = None) -> tuple:
    """
    Computes MSE and PSNR between predicted and target arrays.
    
    Args:
        predicted: Array of predicted values (float).
        target: Array of target values (float).
        mask: Optional boolean array indicating valid elements.
        
    Returns:
        mse: Mean Squared Error (float).
        psnr: Peak Signal-to-Noise Ratio in dB (float or inf).
    """
    # 1. Input Validation
    if predicted.shape != target.shape:
        raise ValueError("Predicted and target must have the same shape.")
    
    if mask is not None and mask.shape != predicted.shape:
        raise ValueError("Mask must have the same shape as input.")
        
    # 2. Compute Difference
    diff = predicted - target
    
    # 3. Square Difference
    sq_error = diff ** 2
    
    # 4. Masking
    if mask is not None:
        # Apply mask
        masked_sq_error = sq_error[mask]
        n_valid = mask.sum()
        
        if n_valid == 0:
            raise RuntimeError("Mask has no true values.")
            
        # 5. Average (Masked)
        mse = float(np.mean(masked_sq_error))
    else:
        # Flatten spatial and channel dimensions
        flat_sq_error = sq_error.flatten()
        n_valid = flat_sq_error.shape[0]
        
        # 5. Average (Unmasked)
        mse = float(np.mean(flat_sq_error))
        
    # 6. PSNR Conversion
    if mse == 0.0:
        psnr = float('inf')
    else:
        psnr = 20.0 * math.log10(1.0 / math.sqrt(mse))
        
    return mse, psnr
```

## Subtopics

### [PSNR Metric Calculation](2742-psnr-metric-calculation.md)
PSNR is a standard benchmark metric used to evaluate the photometric fidelity of reconstructed images or volumes in novel view synthesis and 3D reconstruction. It quantifies the error between a predicted image and a ground-truth reference by converting the Mean Squared Error (MSE) into a logarithmic decibel (dB) scale, where higher values indicate better quality. Unlike structural metrics such as SSIM, PSNR focuses strictly on pixel-wise intensity accuracy, making it sensitive to large smooth regions while largely ignoring small, high-frequency features like specular highlights.

### [SSIM Metric Calculation](3650-ssim-metric-calculation.md)
SSIM is a full-reference quality assessment metric that evaluates image fidelity by measuring perceptual similarity through local comparisons of luminance, contrast, and structure. Unlike pixel-wise error metrics such as MSE or PSNR, which often correlate poorly with human perception, SSIM captures structural information changes to approximate perceived distortion. It is widely used as a standard benchmark for image quality in 3D reconstruction and novel view synthesis.

### [Normal-L2 Score Computation](3842-normal-l2-score-computation.md)
The Normal-L2 Score computes the mean squared error between predicted surface normals and ground-truth normals to evaluate geometric fidelity in radiance-field optimization. It differs from sibling metrics like [PSNR Metric Calculation](2742-psnr-metric-calculation.md) by focusing on shading-critical surface orientation rather than color intensity, and from [IoU Loss](7110-iou-loss.md) by measuring local geometric accuracy rather than global silhouette alignment.

### [Minkowski's Metric](4347-minkowski-s-metric.md)
Minkowski's Metric (also known as the Lp norm or Lgamma loss) is a family of photometric consistency losses used in radiance-field optimization to quantify the dissimilarity between a rendered image and a ground-truth reference. It generalizes the Mean Squared Error (MSE) by allowing the exponent $\gamma$ to vary, enabling a trade-off between sensitivity to large errors and robustness to outliers. Unlike MSE, which penalizes large deviations quadratically, Minkowski's Metric with $\gamma < 2$ (e.g., L1) is less sensitive to outliers, while $\gamma > 2$ increases sensitivity to large errors.

### [IoU Loss](7110-iou-loss.md)
IoU Loss is a binary segmentation metric that computes the ratio of overlapping voxels above a threshold to the total union of predicted and target voxels. It is used to optimize occupancy or instance fields in radiance-field training, addressing fragmentation caused by inconsistent 2D masks across views. It differs from its parent, [MSE Loss and PSNR Conversion](1651-mse-loss-and-psnr-conversion.md), by operating on binary occupancy/instance probabilities rather than continuous RGB values, providing structural supervision for geometry or instance segmentation.

### [Perceptually-motivated variance metric](9969-perceptually-motivated-variance-metric.md)
The perceptually-motivated variance metric quantifies the error between an 8-bit ambient occlusion (AO) approximation $T$ and a high-fidelity ray-traced reference $R$. It differs from raw pixel Mean Squared Error (MSE) by operating on log-transformed values and spatial gradients, thereby aligning with human visual sensitivity to radiance and its changes. This metric is specifically designed for evaluating AO approximations where reflected ambient radiance is linear in accessibility.

### [Depth Accuracy Metrics](10453-depth-accuracy-metrics.md)
Depth Accuracy Metrics evaluate the geometric fidelity of predicted depth maps against ground truth data in radiance field optimization pipelines. They quantify scale- and translation-invariant errors on valid depth pixels. They are used to evaluate depth prior quality and monocular depth estimation outputs in NeRF pipelines.

### [Discrete Wavelet Transform Loss](11910-discrete-wavelet-transform-loss.md)
The Discrete Wavelet Transform (DWT) Loss is a regularization term for Neural Radiance Fields (NeRF) that minimizes the difference between the frequency representations of rendered and ground-truth images by decomposing them into sub-bands. It addresses high-frequency overfitting in few-shot NeRF training by explicitly prioritizing low-frequency learning during early stages. Unlike its sibling [MSE Loss and PSNR Conversion](1651-mse-loss-and-psnr-conversion.md), which compares pixel-wise values globally, the DW loss operates on local structures using patch-based sampling to supervise low and mid-frequency components.

### [RMSE Loss for Constant Model](14613-rmse-loss-for-constant-model.md)
Calculates the Root Mean Squared Error (RMSE) between observed intensity values and a predicted constant intensity model parameterized by density ($\sigma$) and step size ($q$). It serves as a photometric consistency loss in differentiable volume rendering, specifically fitting a constant radiance assumption along a ray. Unlike the parent [MSE Loss and PSNR Conversion](1651-mse-loss-and-psnr-conversion.md) which operates on raw RGB predictions, this method explicitly models the physical integration of a constant source over a ray segment.

### [Normalized L1 Loss](15480-normalized-l1-loss.md)
Computes a normalized L1 loss between a reconstructed image and an original image, scaling the loss to the $[0, 1]$ range. It is used in sparse pixel sampling optimization pipelines to provide a scale-invariant error metric for adaptive Gaussian densification and pruning.

### [Masked and Weighted Losses](15713-masked-and-weighted-losses.md)
Masked and Weighted Losses modify standard photometric error metrics (such as MSE or Huber loss) by excluding irrelevant regions from the error calculation or adjusting the contribution of individual pixels based on geometric properties. This solves the problem of optimization bias caused by empty background, invalid rays, or multiscale resolution discrepancies, ensuring the model focuses only on meaningful signal. It sets itself apart from standard MSE by dynamically defining a Region of Interest (ROI) based on active radiance or ray validity, and by weighting losses to account for pixel footprint area.

### [Restricted Mean Error Metric](16552-restricted-mean-error-metric.md)
The Restricted Mean Error Metric is a loss function designed to optimize scalar weight factors for pre-computed scattering lobe shapes in volume rendering, specifically addressing parameter heterogeneity across voxel clusters. Unlike standard Mean Squared Error (MSE) which treats all pixels equally or global mean metrics that obscure local errors, this method computes the average intensity only for pixels "directly" visible to specific voxel clusters, allowing the optimizer to identify which clusters cause rendering artifacts (such as seams) and correcting them individually. It is primarily used in the context of optimizing SGGX lobe weights via Stochastic Gradient Descent (SGD).

### MSE Bias-Variance Decomposition
Treating the TAA algorithm as a biased estimator to analyze correctness using Mean Squared Error (MSE), decomposed into variance and bias squared [S11, unofficial]. The formula is $\text{MSE}[F] = \mathbb{E}[(F - G)^2] = V[F] + \beta[F]^2$, where $F$ is the output of the estimator, $G$ is the true value (ground truth), $V[F]$ is the variance of the estimator, and $\beta[F]$ is its bias [S11, unofficial].

### Greedy proposal matching
A fast assignment strategy used during Phase 1 to compute the L2 matching loss between heuristic samples and learnt proposals [S12, unofficial]. For each heuristic sample, the closest proposal from the learnt proposer set is found [S12, unofficial]. Optimal matching (Hungarian algorithm) or strict 1-1 greedy matching significantly slows training [S12, unofficial].

### MSLE Loss
Calculates Mean Squared Logarithmic Error between two RGB colors, optionally weighted by luminance [S13, unofficial]. The formula is $\text{MSLE} = \sum_c (\log_2(\frac{b_c + 1.0}{a_c + 1.0}))^2 \cdot w_c$ where $w_c$ is 1.0 or luminance weight [S13, unofficial].

### Blur Loss
L2 loss between the simulated blurry image and the input blurry image [S14]. The parameter $B(x)$ is the input blurry image at pixel $x$ [S14].

### Clipped MSE Loss
A pixel-wise mean squared loss operating in linear color space (no gamma compression) that handles under-exposed and over-exposed values using a one-sided difference based on clipping thresholds [S15]. Parameters are $v_{min}$: The lower clipping threshold for under-exposed values. Values below this are penalized only if they are above the threshold (one-sided difference), and $v_{max}$: The upper clipping threshold for over-exposed values. Values above this are penalized only if they are below the threshold [S15].

### Silhouette Loss
Uses parameters $m$: Image mask, values in $\{0, 1\}$; $s$: Predicted signed distance; $\tau$: Truncation distance for the SDF model; $\sigma$: Predicted ray hit probability from DDF; and $L_\sigma$: DDF silhouette loss from Eq. (8) [S16].

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of pixels/voxels compared, as it involves a single pass to compute differences and averages [S6, S8, unofficial].
*   **Memory Complexity:** $O(N)$ to store the intermediate squared error array, or $O(1)$ if computed incrementally [S6, unofficial].
*   **Measured Performance:** Standard baseline for NeRF and volume rendering training [S2, S4, S7, unofficial].
*   **Scaling:** Scales linearly with resolution and batch size [S6, unofficial].
*   **Strengths:** Simple to implement, differentiable, and provides a clear monotonic error signal [S4, S7, unofficial].
*   **Limitations:** Does not account for structural similarity or perceptual quality, often leading to blurry results compared to SSIM or LPIPS [S1, unofficial][S7, S11, unofficial].
*   **When to use:** As a primary loss for initial training or when pixel-perfect intensity accuracy is required [S4, S7, unofficial].
*   **When not to use:** When perceptual quality is more important than pixel accuracy, or when dealing with high-frequency details where MSE may fail to capture structural fidelity [S1, unofficial][S7, S11, unofficial].

## Background
MSE Loss is a fundamental statistical measure used in signal processing and machine learning for decades. In the context of volume rendering and NeRF, it was popularized by the original NeRF paper [S2, unofficial] and subsequent implementations [S4, unofficial][S7, unofficial] as the primary photometric loss. It is widely used in 3D reconstruction, CBCT reconstruction [S1, unofficial], and novel view synthesis [S1, unofficial][S2, unofficial].
