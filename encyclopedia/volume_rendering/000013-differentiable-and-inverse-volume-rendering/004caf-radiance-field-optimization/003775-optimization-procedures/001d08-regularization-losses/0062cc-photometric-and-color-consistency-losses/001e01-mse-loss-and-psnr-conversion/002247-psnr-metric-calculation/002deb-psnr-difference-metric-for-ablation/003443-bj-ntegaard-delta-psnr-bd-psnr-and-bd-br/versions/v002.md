# Bjøntegaard Delta PSNR (BD-PSNR) and BD-BR

Also called: BD-BR, BD-PSNR, Bjøntegaard Delta

## Overview
BD-PSNR and BD-BR are metrics used to evaluate lossy compression performance by calculating the average difference in quality (BD-PSNR) or bit-rate (BD-BR) between two rate-distortion (RD) curves [S1]. They provide a single scalar value that facilitates the objective comparison of compression techniques, avoiding the impracticality of displaying full RD curves for multiple experiments [S1].

## How it works
**Inputs:** Two sets of rate-distortion points: a reference set $R_{ref} = \{(R_{ref,i}, D_{ref,i})\}$ and a test set $R_{test} = \{(R_{test,j}, D_{test,j})\}$, where $R$ represents the bit-rate (or model size) and $D$ represents the distortion metric (e.g., PSNR in dB) [S1, S2].

**Outputs:**
- BD-PSNR: The average difference in PSNR (dB) between the two curves [S1].
- BD-BR: The average relative difference in bit-rate between the assessed and reference techniques [S1].

**Data Structures:**
- Two lists of tuples: `reference_points` and `test_points`. Each tuple contains `(rate, distortion)` [S1, S2].

**Steps:**
1. **Interpolation:** Fit a continuous rate-distortion curve for both the reference and test sets using piecewise cubic interpolation [S2]. This step transforms discrete experimental points into continuous functions $D_{ref}(R)$ and $D_{test}(R)$ [S2].
2. **Integration:** Calculate the area between the two interpolated curves over the range of rates where both curves are defined [S1]. For BD-PSNR, this area represents the average difference in quality [S1]. For BD-BR, the calculation determines the bit saving at the same quality level [S2].

**Formulas:**
The method computes the average difference by integrating the area between the interpolated curves and normalizing by the rate range [G]. For BD-PSNR, $BD\text{-}PSNR = \frac{1}{R_{max}-R_{min}} \int_{R_{min}}^{R_{max}} (D_{ref}(R) - D_{test}(R)) \, dR$ [G]. For BD-BR, the rate axis is typically transformed logarithmically before interpolation to compute the average relative bit-rate difference [G].

**Parameters:**
- Interpolation method: Piecewise cubic interpolation [S2].

**Edge cases and pitfalls:**
- The method requires overlapping rate ranges for both curves to perform integration [S1].
- Degenerate curves with identical rates or distortions yield zero difference.
- Precision loss may occur if the rate range is extremely large or small [G].

**Pseudocode:**

import math

def calculate_bjontegaard_delta(reference_points, test_points):
    # Sort points by rate
    ref_sorted = sorted(reference_points, key=lambda p: p[0])
    test_sorted = sorted(test_points, key=lambda p: p[0])
    
    # 1. Fit continuous curves using piecewise cubic interpolation [G]
    ref_spline = fit_cubic_spline(ref_sorted)
    test_spline = fit_cubic_spline(test_sorted)
    
    # 2. Determine common rate range for integration
    min_rate = max(p[0] for p in ref_sorted + test_sorted)
    max_rate = min(p[0] for p in ref_sorted + test_sorted)
    
    if min_rate >= max_rate:
        return 0.0, 0.0
        
    # 3. Evaluate curves at N points across the common range
    N = 100
    rates = [min_rate + i * (max_rate - min_rate) / (N - 1) for i in range(N)]
    ref_vals = [ref_spline(r) for r in rates]
    test_vals = [test_spline(r) for r in rates]
    
    # 4. Integrate area between curves using trapezoidal rule [G]
    area = 0.0
    for i in range(N - 1):
        dr = rates[i+1] - rates[i]
        avg_diff = (abs(ref_vals[i] - test_vals[i]) + abs(ref_vals[i+1] - test_vals[i+1])) / 2.0
        area += dr * avg_diff
        
    # 5. Normalize by rate range to obtain average difference [G]
    rate_range = max_rate - min_rate
    bd_psnr = area / rate_range
    
    # BD-BR calculation involves bit saving at the same quality [S2]
    # Standard BD-BR applies logarithmic transformation to rates before interpolation [G]
    bd_br = calculate_bd_br(ref_sorted, test_sorted)
    
    return bd_psnr, bd_br

def fit_cubic_spline(points):
    # Natural cubic spline interpolation [G]
    n = len(points)
    xs = [p[0] for p in points]
    ys = [p[1] for p in points]
    h = [xs[i+1] - xs[i] for i in range(n-1)]
    M = [0.0] * n
    alpha = [0.0] * (n-1)
    for i in range(1, n-1):
        alpha[i] = (3.0/h[i])*(ys[i+1]-ys[i]) - (3.0/h[i-1])*(ys[i]-ys[i-1])
    l = [1.0] * n
    mu = [0.0] * n
    z = [0.0] * n
    for i in range(1, n-1):
        l[i] = 2.0*(xs[i+1]-xs[i-1]) - h[i-1]*mu[i-1]
        mu[i] = h[i]/l[i]
        z[i] = (alpha[i] - h[i-1]*z[i-1])/l[i]
    for j in range(n-2, -1, -1):
        M[j] = z[j] - mu[j]*M[j+1]
    M[n-1] = 0.0
    
    def evaluate(r):
        idx = 0
        for i in range(n-1):
            if xs[i] <= r <= xs[i+1]:

                break
        dx = r - xs[idx]

                (ys[idx+1]*(xs[idx+1]-r) + ys[idx]*(r-xs[idx]))/h[idx] +
                (M[idx]*(xs[idx+1]-r)**3 - M[idx+1]*(r-xs[idx])**3)/(6.0*h[idx]))
    return evaluate

## Subtopics

### Bjøntegaard Delta-Rate (BD-Rate)
A metric for fair comparison of overall rate-distortion performance that calculates bit saving at the same quality level [S2]. It employs piecewise cubic interpolation to fit the continuous RD curve and calculate the bit saving [S2]. It has been applied to compare SPC-NeRF against VQRF on the Synthetic-NeRF dataset, showing 28% bit saving for the base configuration and 32% for the HR configuration [S2].

## Operating characteristics
**Time and memory complexity:** Not given in the sources [S1, S2].
**Measured performance:** Applied to compare SPC-NeRF against VQRF, showing 28% bit saving for the base configuration and 32% bit saving for the HR configuration on the Synthetic-NeRF dataset [S2].
**Strengths and limitations:** Provides a single scalar value for objective comparison, avoiding the impracticality of displaying full RD curves for multiple experiments [S1]. The method relies on accurate interpolation, which may be sensitive to the number of discrete points [S2].
**When to use it:** When comparing lossy compression techniques where a single metric summarizing the rate-distortion performance is needed [S1].
