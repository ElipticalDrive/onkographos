# MSE Loss and PSNR Conversion

Also called: Loss Function for Constant Model, MSE, MSE Loss, Mean Squared Error, Mean Squared Error Loss

## Overview
MSE Loss and PSNR Conversion is the primary photometric loss function for training differentiable volume rendering models, computing the Mean Squared Error (MSE) between predicted and target RGB values and converting this error into Peak Signal-to-Noise Ratio (PSNR) for logging [S2, unofficial][S4, unofficial]. It serves as the baseline for evaluating image fidelity in 3D reconstructions and novel view synthesis, distinguishing itself from structural metrics like SSIM by focusing strictly on pixel-wise intensity error [S1, unofficial][S2, unofficial]. Unlike robust losses such as Huber or L1, standard MSE is sensitive to outliers and saturated pixels, making it most suitable for clean, well-calibrated datasets [S4, unofficial][S7, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** Predicted image tensor $\hat{Y}$ (shape $[B, H, W, C]$ or flattened $[N, C]$) and Ground Truth image tensor $Y$ (same shape and data type, typically float32 normalized to $[0, 1]$ or $[0, 255]$).
- **Outputs:** Scalar MSE loss value and corresponding PSNR value (in dB).

**Data Structures:**
- Tensors for $\hat{Y}$ and $Y$ containing continuous RGB values.
- No auxiliary structures required for the basic calculation.

**Steps:**
1. **Validation:** Ensure input tensors are not empty and have matching shapes [S3, unofficial][S10, unofficial].
2. **Difference Calculation:** Compute the element-wise difference between predicted and target values: $D = \hat{Y} - Y$ [S6, unofficial].
3. **Squaring:** Square the difference element-wise: $S = D^2$ [S6, unofficial].
4. **Averaging:** Compute the mean of the squared differences over the spatial dimensions and batch dimension to obtain MSE [S2, unofficial][S6, unofficial].
   $$
   \text{MSE} = \frac{1}{N} \sum_{i=1}^{N} (\hat{y}_i - y_i)^2
   $$
   where $N$ is the total number of elements (pixels $\times$ channels $\times$ batch size) or just pixels depending on implementation convention [S2, unofficial][S4, unofficial].
5. **PSNR Conversion:** Convert MSE to PSNR using the logarithmic formula [S2, unofficial][S9, unofficial]:
   $$
   \text{PSNR} = -10 \cdot \log_{10}(\text{MSE})
   $$
   Alternatively, if the maximum possible signal value $MAX$ is known (e.g., 1.0 for normalized data), the formula is:
   $$
   \text{PSNR} = 20 \cdot \log_{10}\left(\frac{MAX}{\sqrt{\text{MSE}}}\right)
   $$
   For normalized $[0, 1]$ data, $MAX=1$, reducing to the first formula [S9, unofficial].

**Parameters:**
- **Batch Size:** Number of random pixels or images sampled per iteration [S7, unofficial].
- **Learning Rate:** Adam optimizer learning rate (e.g., $10^{-3}$) [S7, unofficial].

**Pseudocode:**
```python
import math
import torch

def compute_mse_and_psnr(predicted: torch.Tensor, target: torch.Tensor) -> tuple:
    """
    Computes Mean Squared Error and PSNR between predicted and target tensors.
    
    Args:
        predicted: Tensor of shape (..., C) or (B, H, W, C) with predicted RGB values.
        target: Tensor of shape (..., C) or (B, H, W, C) with ground truth RGB values.
        
    Returns:
        mse: Scalar float tensor representing the Mean Squared Error.
        psnr: Scalar float tensor representing the Peak Signal-to-Noise Ratio in dB.
    """
    # 1. Validate inputs
    if predicted.numel() == 0 or target.numel() == 0:
        raise ValueError("Input tensors cannot be empty")
    if predicted.shape != target.shape:
        raise ValueError(f"Shape mismatch: {predicted.shape} vs {target.shape}")
        
    # 2. Compute element-wise difference
    diff = predicted - target
    
    # 3. Square the difference
    squared_diff = diff ** 2
    
    # 4. Compute mean over all dimensions (batch, height, width, channels)
    # Note: Some implementations average only over spatial dims if batch is handled separately.
    # Here we follow the standard definition averaging over all elements for a single scalar loss.
    mse = torch.mean(squared_diff)
    
    # 5. Compute PSNR
    # Handle case where MSE is 0 to avoid log(0)
    if mse == 0:
        psnr = float('inf')
    else:
        # Assuming normalized data [0, 1], MAX = 1
        # PSNR = 10 * log10(1 / MSE) = -10 * log10(MSE)
        psnr = -10.0 * torch.log10(mse)
        
    return mse, psnr

def compute_masked_mse_and_psnr(predicted: torch.Tensor, target: torch.Tensor, mask: torch.Tensor, mask_threshold_rel: float = 0.01) -> dict:
    """
    Computes MSE and PSNR only on voxels/pixels inside a binary mask.
    
    Args:
        predicted: Tensor of predicted values.
        target: Tensor of ground truth values.
        mask: Boolean tensor indicating valid regions.
        mask_threshold_rel: Relative threshold for mask generation if mask is not pre-computed.
        
    Returns:
        Dictionary containing masked_mse, masked_psnr, masked_voxel_count, etc.
    """
    # 1. Create boolean mask if not already boolean (optional step based on source [S9, unofficial])
    # If mask is provided as float, apply threshold
    if mask.dtype != torch.bool:
        max_val = torch.max(mask)
        threshold = mask_threshold_rel * max_val
        mask_bool = mask > threshold
    else:
        mask_bool = mask
        
    # 2. Check for empty mask
    if not mask_bool.any():
        raise RuntimeError("Boolean mask has no true values (empty region)")
        
    # 3. Apply mask to squared errors
    diff = predicted - target
    squared_diff = diff ** 2
    masked_squared_diff = squared_diff * mask_bool.float()
    
    # 4. Compute masked MSE
    masked_mse = masked_squared_diff.sum() / mask_bool.sum()
    
    # 5. Compute masked PSNR
    if masked_mse > 0.0:
        masked_psnr = 20.0 * math.log10(1.0 / math.sqrt(masked_mse.item()))
    else:
        masked_psnr = float('inf')
        
    return {
        'masked_mse': masked_mse.item(),
        'masked_psnr': masked_psnr,
        'masked_voxel_count': mask_bool.sum().item()
    }
```

**Edge Cases and Pitfalls:**
- **Zero MSE:** If the prediction perfectly matches the target, MSE is 0, leading to $\log(0)$ which is undefined. PSNR should be set to infinity or a large constant [S9, unofficial].
- **Outliers:** MSE penalizes large errors quadratically, making it sensitive to noise, saturated pixels, or registration errors [S4, unofficial].
- **Dynamic Range:** The PSNR formula assumes a specific maximum signal value ($MAX$). Using the wrong $MAX$ (e.g., 255 for normalized 0-1 data) scales the PSNR incorrectly [S9, unofficial].

## Subtopics

### [Masked Volume Metrics](1927-masked-volume-metrics.md)
A method to exclude empty froxels from evaluation metrics by including only froxels affected by radiance. It computes MSE and PSNR using only voxels inside a binary mask, calculated by thresholding the mask volume relative to its maximum value.

### [PSNR Metric Calculation](2742-psnr-metric-calculation.md)
Peak Signal-to-Noise Ratio (PSNR) is a standard benchmark metric used to evaluate the photometric quality of reconstructed images or volumes in novel view synthesis and tomographic reconstruction. It quantifies the fidelity of a predicted image $y$ against a ground-truth reference $x$ by converting the Mean Squared Error (MSE) into a logarithmic decibel (dB) scale, where higher values indicate better quality. Unlike structural metrics such as SSIM, PSNR focuses strictly on pixel-wise intensity error, making it sensitive to large smooth regions but less responsive to small, high-frequency features like specular highlights.

### [SSIM Metric Calculation](3650-ssim-metric-calculation.md)
SSIM is a full-reference quality assessment metric that evaluates the perceptual fidelity of a rendered image by comparing local structural information (luminance, contrast, and geometry) against a ground-truth image. Unlike MSE, which measures pixel-wise error, SSIM models the human visual system's adaptation to structured natural scene information, providing a score correlated with perceived image distortion. It is widely used to evaluate the quality of 3D reconstructions and novel 2D views in differentiable volume rendering.

### [Normal-L2 Score Computation](3842-normal-l2-score-computation.md)
The Normal-L2 score evaluates surface geometry by computing the mean squared L2 distance between predicted surface normals and reference normals from a ground-truth mesh. It is computed only on the intersection of predicted and ground-truth masks, distinguishing it from silhouette metrics like iIoU which evaluate mask alignment separately.

### [Minkowski's Metric](4347-minkowski-s-metric.md)
Minkowski's Metric is a family of mathematical distortion measures that treats an image as a 2D signal to calculate the dissimilarity between a reference image and a test image. It generalizes the Mean Squared Error (MSE) by allowing the order parameter $\gamma$ to vary, enabling different sensitivities to pixel-wise errors. It is distinguished from its sibling MSE Loss by its tunable norm order, which allows it to model error distributions other than the Gaussian assumption inherent in MSE.

### [Training Loss Computation with Huber and Masking](4765-training-loss-computation-with-huber-and-masking.md)
This method defines the primary photometric loss function for training differentiable volume rendering models, specifically those utilizing sparse voxel grids or neural radiance fields. It computes the discrepancy between rendered and ground-truth images using a Huber loss on RGB values, masked by ray validity to exclude invalid or background-only rays. It sets itself apart from standard MSE loss by being more robust to outliers (such as saturated pixels or noise) while maintaining differentiability, and explicitly handles the aggregation of valid rays to prevent bias from empty space.

### [IoU Loss](7110-iou-loss.md)
IoU Loss is a binary segmentation metric that computes the ratio of overlapping voxels above a threshold to the total union of predicted and target voxels. It is used to optimize occupancy or instance fields in radiance-field training, addressing fragmentation caused by inconsistent 2D masks across views. It differs from its parent, [MSE Loss and PSNR Conversion](1651-mse-loss-and-psnr-conversion.md), by operating on binary occupancy/instance probabilities rather than continuous RGB values, providing structural supervision for geometry or instance segmentation.

### [Perceptually-motivated variance metric](9969-perceptually-motivated-variance-metric.md)
The perceptually-motivated variance metric quantifies the error between an 8-bit ambient occlusion (AO) approximation $T$ and a high-fidelity ray-traced reference $R$. It differs from raw pixel Mean Squared Error (MSE) by operating on log-transformed values and spatial gradients, thereby aligning with human visual sensitivity to radiance and its changes. This metric is specifically designed for evaluating AO approximations where reflected ambient radiance is linear in accessibility.

### [Depth Accuracy Metrics](10453-depth-accuracy-metrics.md)
Depth Accuracy Metrics evaluate the geometric fidelity of predicted depth maps against ground truth data in radiance field optimization pipelines. Unlike photometric losses that assess color consistency, these metrics quantify scale- and translation-invariant errors on valid depth pixels, distinguishing between per-image accuracy and global scene consistency. They are primarily used to benchmark monocular depth estimation modules and depth priors within NeRF-based reconstruction.

### [Discrete Wavelet Transform Loss](11910-discrete-wavelet-transform-loss.md)
The Discrete Wavelet Transform (DWT) Loss is a regularization term for Neural Radiance Fields (NeRF) that minimizes the difference between the frequency representations of rendered and ground-truth images by decomposing them into sub-bands. It addresses high-frequency overfitting in few-shot NeRF training by explicitly prioritizing low-frequency learning during early stages. Unlike its sibling [MSE Loss and PSNR Conversion](1651-mse-loss-and-psnr-conversion.md), which compares pixel-wise values globally, the DW loss operates on local structures using patch-based sampling to supervise low and mid-frequency components.

### MSE Bias-Variance Decomposition
Treating the TAA algorithm as a biased estimator to analyze correctness using Mean Squared Error (MSE), decomposed into variance and bias squared. The formula is $\text{MSE}[F] = \mathbb{E}[(F - G)^2] = V[F] + \beta[F]^2$, where $F$ is the output of the estimator, $G$ is the true value (ground truth), $V[F]$ is the variance of the estimator, and $\beta[F]$ is its bias [S11, unofficial].

### Area Loss Scaling
Scaling the loss of each pixel by the area of that pixel's footprint in the original image to ensure low-resolution pixels have comparable influence to high-resolution pixels in multiscale datasets. For multiscale datasets, the area scaling factor is calculated based on the downsampling factor (e.g., factor of 2 -> area factor 4) and the pixel loss is multiplied by this factor [S12].

### Greedy proposal matching
A fast assignment strategy used during Phase 1 to compute the L2 matching loss between heuristic samples and learnt proposals. For each heuristic sample, the closest proposal from the learnt proposer set is found. Optimal matching (Hungarian algorithm) or strict 1-1 greedy matching significantly slows training [S13, unofficial].

### MSLE Loss
Calculates Mean Squared Logarithmic Error between two RGB colors, optionally weighted by luminance. The formula is $\text{MSLE} = \sum_c (\log_2(\frac{b_c + 1.0}{a_c + 1.0}))^2 \cdot w_c$ where $w_c$ is 1.0 or luminance weight [S14, unofficial].

### RMSE Loss for Constant Model
Calculates the Root Mean Squared Error between predicted and observed intensities for a given sigma and q. It validates inputs (intensity not empty, ds > 0), initializes a squared accumulator, loops through intensity samples to compute predicted values and residuals, and returns the square root of the mean squared error [S3, unofficial].

### Blur Loss
L2 loss between the simulated blurry image and the input blurry image. It is used in event-driven bundle adjustment for deblurring NeRFs, calculated as $L_{blur} = \frac{1}{m} \sum_{x \in X} \| \hat{B}(x) - B(x) \|_2^2$ [S15].

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of pixels/voxels, as it involves a single pass to compute differences and averages.
- **Memory Complexity:** $O(1)$ auxiliary memory if computed in-place or streaming, or $O(N)$ if storing intermediate difference tensors.
- **Performance:** Extremely fast and differentiable, making it the standard choice for gradient-based optimization in differentiable rendering [S4, unofficial][S7, unofficial].
- **Strengths:** Simple to implement, analytically differentiable, and widely understood metric for convergence monitoring [S2, unofficial][S4, unofficial].
- **Limitations:** Sensitive to outliers and noise; does not account for perceptual quality or structural similarity [S1, unofficial][S2, unofficial].
- **When to Use:** Clean datasets, initial training phases, or when computational efficiency is paramount.
- **When Not to Use:** Noisy datasets, datasets with significant registration errors, or when perceptual quality is the primary goal (use SSIM or LPIPS instead).

## Background
The Mean Squared Error (MSE) is a fundamental statistical measure of the average squared difference between estimated values and the actual value [S1, unofficial]. In the context of volume rendering and NeRFs, it was popularized as the primary loss function by Mildenhall et al. in the original NeRF paper [S2, unofficial][S4, unofficial]. It has since become the standard baseline for evaluating photometric reconstruction quality in 3D vision tasks [S1, unofficial].
