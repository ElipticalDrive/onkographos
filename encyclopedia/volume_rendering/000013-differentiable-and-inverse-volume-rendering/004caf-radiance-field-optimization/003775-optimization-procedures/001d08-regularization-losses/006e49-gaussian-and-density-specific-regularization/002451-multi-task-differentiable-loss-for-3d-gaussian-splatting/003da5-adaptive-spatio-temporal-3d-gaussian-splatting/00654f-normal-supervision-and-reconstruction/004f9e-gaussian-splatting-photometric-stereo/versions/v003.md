# Gaussian Splatting Photometric Stereo

Also called: GS-PS

## Overview
Gaussian Splatting Photometric Stereo (GS-PS) is a calibrated photometric stereo method that represents the scene exclusively using 3D Gaussian primitives to estimate surface normals and albedo [S1][S2, unofficial]. It solves the problem of recovering high-frequency surface geometry from multi-view images under varying lighting by optimizing Gaussian parameters (position, covariance, color, opacity) to minimize a combined photometric and normal alignment loss [S2, unofficial]. Unlike deep neural network methods that predict normals directly from image features, GS-PS optimizes an explicit physical image formation model, making it more explainable and providing geometrically interpretable parameters [S1][S2, unofficial]. It builds on [Normal Supervision and Reconstruction](19339-normal-supervision-and-reconstruction.md) by integrating normal supervision directly into the Gaussian splatting optimization loop.

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ calibrated images of a scene taken under different known light directions $\mathbf{l}_k$. The scene is initialized with a set of 3D Gaussians.
*   **Outputs:** Optimized Gaussian parameters (position $\mathbf{p}_i$, covariance $\Sigma_i$, color $\mathbf{c}_i$, opacity $\alpha_i$, and normal $\mathbf{n}_i$) and the estimated normal map and albedo map.

**Data Structures:**
Each Gaussian $i$ stores:
*   Position $\mathbf{p}_i \in \mathbb{R}^3$.
*   Covariance matrix $\Sigma_i \in \mathbb{R}^{3 \times 3}$ (parameterized as rotation $\mathbf{R}_i$ and scale $\mathbf{s}_i$).
*   Color $\mathbf{c}_i$ (represented via spherical harmonics for view-dependent effects, though photometric stereo typically assumes Lambertian or known lighting).
*   Opacity $\alpha_i \in [0, 1]$.
*   Normal $\mathbf{n}_i \in \mathbb{R}^3$ (unit vector). In standard 3DGS, normals are not explicit; here they are either derived from the covariance orientation or explicitly optimized as a parameter [S1][S2, unofficial].

**Rendering Pipeline:**
1.  **Normal Rendering:** For each pixel $(u,v)$, render the normal map $\hat{\mathbf{n}}_{uv}$ by alpha-blending the normals of contributing Gaussians in depth order [S2, unofficial]:
    $$ \hat{\mathbf{n}}_{uv} = \sum_{i}^{N} \mathbf{n}_{i} \alpha_{i} \prod_{j=1}^{i-1} (1-\alpha_{j}) $$
    where $\mathbf{n}_i$ is the normal of the $i$-th Gaussian, $\alpha_i$ is its opacity, and the product term represents the transparency of preceding Gaussians [S2, unofficial].
2.  **Photometric Rendering:** Render the RGB image $\hat{I}_{uv}$ for a specific light direction $\mathbf{l}_k$. Since standard Gaussian Splatting does not account for lighting, a lighting model is applied. The method analyzes if surfaces are aligned with the light direction to calculate self-occlusion shadows (self-shadowing) [S2, unofficial]. The composite image $c(x, y)$ from multiple inputs can be defined as the maximum of input images:
    $$ c(x, y) = \max\{I_1 (x, y), I_2 (x, y), \dots , I_n (x, y)\} $$
    [S2, unofficial].

**Optimization Steps:**
1.  **Initialization:** Initialize Gaussians in the scene volume.
2.  **Rendering:** For each training iteration:
    *   Render the predicted normal map $\hat{\mathbf{n}}_{uv}$ and RGB image $\hat{I}_{uv}$ for the current camera and light configuration.
    *   Generate a target normal map $\mathbf{n}_{uv}^{target}$ from the gradient of the depth map (or from a monocular estimator if depth is not available, though GS-PS specifically mentions depth gradient [S1]).
3.  **Loss Calculation:**
    *   **Photometric Loss ($L_c$):** Compute the L1 loss between the rendered image $\hat{I}_{uv}$ and the real input image $I_{uv}$ [S1][S2, unofficial]:
        $$ L_c = \| \hat{I}_{uv} - I_{uv} \|_1 $$
    *   **Normal Regularization Loss ($L_n$):** Compute the alignment between the rendered normal $\hat{\mathbf{n}}_{uv}$ and the target normal $\mathbf{n}_{uv}^{target}$. This is typically a cosine distance or similarity loss [S1][S2, unofficial].
    *   **Total Loss:**
        $$ L = L_c + \lambda L_n $$
        where $\lambda$ is the weighting factor for the normal regularization term [S1][S2, unofficial].
4.  **Gradient Descent:** Optimize Gaussian parameters (position, covariance, color, opacity, and normal) using gradient descent [S1][S2, unofficial].
5.  **Adaptive Density Control:** Evolve the number of Gaussians:
    *   **Prune:** Remove Gaussians that are too large or have opacity below a threshold [S1][S2, unofficial].
    *   **Clone/Split:** Clone or split Gaussians in regions requiring more detail [S1][S2, unofficial].

**Parameters:**
*   $\lambda$: Weighting factor for the normal regularization term. Typical values are not explicitly given in the sources, but it balances photometric accuracy against geometric consistency [S1].

**Edge Cases and Pitfalls:**
*   **Cast Shadows:** The current model does not account for cast shadows (ombres portées). This causes high angular estimation errors concentrated in regions where cast shadows are present on many input images [S1][S2, unofficial].
*   **Lambertian Assumption:** The method is tested on Lambertian materials. Non-Lambertian effects may require extensions [S1].

## Subtopics

### Optimization with Stochastic Solids
A variant that optimizes scenes using photometric loss, normal consistency loss, and multi-view regularization [S3, unofficial]. It retains the standard Gaussian Splatting approximation for RGB and normals but computes depth using a stochastic solid method to provide denser supervision for optimization [S3, unofficial]. This setting significantly improves shape reconstruction accuracy [S3, unofficial]. Experiments are evaluated using half-resolution images [S3, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
*   The method leverages the efficient gradient calculation of Gaussian Splatting, allowing for fast optimization via gradient descent [S1][S2, unofficial].
*   Fully volumetric rendering for all modalities (RGB, normals, depth) is computationally expensive [S3, unofficial]. The standard GS-PS approach uses the standard Gaussian Splatting approximation for RGB and normals, which is faster. The stochastic solid variant computes depth differently, potentially adding overhead [S3, unofficial].

**Measured Performance:**
*   On the DiliGenT dataset (Bear, Cat, Pot1 objects with Lambertian materials), GS-PS achieved mean angular errors of:
    *   Cat: 8.13° [S2, unofficial] (Note: [S1] reports 8.26°, [S2, unofficial] reports 8.13°; sources disagree slightly)
    *   Bear: 10.11° [S2, unofficial] (Note: [S1] reports 8.89°, [S2, unofficial] reports 10.11°; sources disagree)
    *   Pot1: 4.12° [S2, unofficial] (Note: [S1] reports 6.41°, [S2, unofficial] reports 4.12°; sources disagree)
*   Comparison with other methods on DiliGenT (Mean Angular Error in degrees):
    *   Baseline [Woodham 1980]: Cat 8.41, Bear 8.39, Pot1 8.89 [S2, unofficial]
    *   DANINet: Cat 4.73, Bear 4.11, Pot1 6.41 [S2, unofficial]
    *   Uni MS-PS: Cat 3.45, Bear 3.14, Pot1 4.12 [S2, unofficial]
    *   GS-PS: Cat 8.13/8.26, Bear 10.11/8.89, Pot1 4.12/6.41 [S1][S2, unofficial]
*   On the DTU dataset, the stochastic solid variant achieves accuracy comparable to GeoSVR with better optimization times than NeRF [S3, unofficial].

**Strengths and Limitations:**
*   **Strengths:** More explainable than deep neural network methods because it optimizes an explicit physical image formation model [S1][S2, unofficial]. More explainable than inverse rendering methods using small networks because the optimized parameters have a geometric interpretation [S1][S2, unofficial]. Efficient gradient calculation [S1].
*   **Limitations:** Does not account for cast shadows, leading to errors in shadowed regions [S1][S2, unofficial]. Performance on DiliGenT is generally lower than specialized deep learning methods like DANINet and Uni MS-PS [S2, unofficial].

**When to Use:**
*   Use when interpretability of the geometric model is important.
*   Use when working with Lambertian surfaces and calibrated lighting.
*   Avoid when cast shadows are prominent and cannot be ignored.

## Background
The method is based on the Gaussian Splatting base method by Kerbl et al. [5] (2023) [S1]. It revisits the problem of calibrated photometric stereo, originally addressed by Woodham [12] (1980) [S1]. The approach was developed to leverage the efficiency and explicit representation of 3D Gaussian Splatting for normal estimation [S1][S2, unofficial].
