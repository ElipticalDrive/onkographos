# Multi-View Constraint

Also called: Patch Matching Regularization

## Overview
Multi-View Constraint is a regularization technique that enforces color consistency between reference and neighborhood views using patch matching and homography warping to improve geometry reconstruction in textureless regions where standard 3D Gaussian Splatting (3DGS) struggles [S1].

## How it works
**Inputs and Outputs**
*   **Inputs**: Reference and neighborhood view images, camera poses (relative rotation $R$ and translation $t$), intrinsic matrix $K$, and the current state of 3D Gaussians (positions, orientations, opacities, colors) [S1].
*   **Outputs**: A scalar loss value $L_{mv}$ added to the total training objective [S1].

**Data Structures**
*   **Rendered Maps**: Depth map $D$ and normal map $N$ for each view, generated by alpha-blending 3D Gaussians [S1].
*   **Homography Matrix $H$**: A $3 \times 3$ matrix mapping pixels from reference to neighborhood view [S1].
*   **Patch $P_i$**: A set of neighboring pixels around a target pixel $p$ [S1].

**Formulas**
1.  **Homography Warping**:
    $$p' = H p$$
    Where $H$ is defined as:
    $$H = K \left( R - \frac{t n^\top}{d} \right) K^{-1}$$
    Here, $R \in \mathbb{R}^{3 \times 3}$ and $t \in \mathbb{R}^{1 \times 3}$ are the relative rotation and translation between the reference and source views, $K \in \mathbb{R}^{3 \times 3}$ is the camera intrinsic matrix, $n \in \mathbb{R}^{1 \times 3}$ is the rendered normal at pixel $p$, and $d$ is the distance from the camera origin to the spatial plane defined by $n$ [S1].

2.  **Multi-View Loss**:
    $$L_{mv} = \sum_{p \in P_i} (1 - \text{NCC}(p, p'))$$
    Where $\text{NCC}(p, p')$ is the Normalized Cross Correlation between the patch at $p$ in the reference view and the patch at $p'$ in the neighborhood view [S1].

3.  **Total Loss Integration**:
    $$L = (1 - \lambda)L_1 + \lambda L_{\text{SSIM}} + L_{mv}$$
    Where $L_1$ and $L_{\text{SSIM}}$ are standard image reconstruction losses from 3DGS [S1].

**Numbered Steps**
1.  **Identify Neighborhood Frames**: For each reference image, identify its neighborhood frames from the subgraphs [S1].
2.  **Render Depth and Normal Maps**: For each image, render depth and normal maps by overlapping the positions and orientations of 3D Gaussians using alpha blending [S1].
3.  **Establish Spatial Plane**: For a pixel $p$ in the reference view, establish a spatial plane defined by the rendered normal $n$ and distance $d$ from the camera origin [S1].
4.  **Compute Homography**: Calculate the homography matrix $H$ using the relative pose $(R, t)$, intrinsics $K$, and the local plane parameters $(d, n)$ [S1].
5.  **Warp Pixel**: Project pixel $p$ to its corresponding pixel $p'$ in the neighborhood view using $p' = H p$ [S1].
6.  **Construct Patch**: Select neighboring pixels around $p$ to form patch $P_i$ [S1].
7.  **Evaluate Consistency**: Compute the Normalized Cross Correlation (NCC) between the patch at $p$ and the warped patch at $p'$ [S1].
8.  **Accumulate Loss**: Sum $(1 - \text{NCC})$ over all pixels in the patch to form $L_{mv}$ [S1].

**Pseudocode**
```python
def compute_multi_view_constraint(reference_image, neighborhood_image, gaussians, K, R, t):
    """
    Computes the Multi-View Constraint loss between a reference and neighborhood view.
    """
    # Render depth and normal maps via alpha blending [G]
    depth_map_ref, normal_map_ref = render_gaussians_alpha_blend(gaussians, reference_image)

    loss_mv = 0.0
    patch_radius = 1  # Not given in the sources [G]

    height, width = reference_image.height, reference_image.width

    # Iterate over pixels in the reference view
    for y in range(height):
        for x in range(width):
            p = (x, y)
            # Get normal and depth at pixel p
            n = normal_map_ref[y][x]  # list of 3 floats
            d = depth_map_ref[y][x]   # float

            # Compute Homography Matrix H: H = K * (R - (t outer n) / d) * K_inv
            t_n_T = outer_product(t, n)  # 3x3 matrix
            H = mat_mul(K, mat_sub(R, mat_scale(t_n_T, 1.0 / d)))
            H = mat_mul(H, mat_inv(K))

            # Warp pixel p to p' using homogeneous coordinates
            p_h = [float(x), float(y), 1.0]
            p_prime_h = mat_vec_mul(H, p_h)
            if abs(p_prime_h[2]) < 1e-6:
                continue  # Skip invalid projections
            p_prime_h = [v / p_prime_h[2] for v in p_prime_h]
            p_prime = (p_prime_h[0], p_prime_h[1])

            # Construct patches around p and p'
            patch_p = get_patch_pixels(reference_image, p, patch_radius)
            patch_p_prime = get_patch_pixels(neighborhood_image, p_prime, patch_radius)

            # Evaluate NCC
            ncc = normalized_cross_correlation(patch_p, patch_p_prime)

            # Accumulate loss
            loss_mv += (1.0 - ncc)

    return loss_mv

def outer_product(a, b):
    return [[a[i] * b[j] for j in range(len(b))] for i in range(len(a))]

def mat_mul(A, B):
    return [[sum(A[i][k] * B[k][j] for k in range(len(B))) for j in range(len(B[0]))] for i in range(len(A))]

def mat_sub(A, B):
    return [[A[i][j] - B[i][j] for j in range(len(A[0]))] for i in range(len(A))]

def mat_scale(A, s):
    return [[A[i][j] * s for j in range(len(A[0]))] for i in range(len(A))]

def mat_inv(M):
    a, b, c = M[0][0], M[0][1], M[0][2]
    d, e, f = M[1][0], M[1][1], M[1][2]
    g, h, i = M[2][0], M[2][1], M[2][2]
    det = a*(e*i - f*h) - b*(d*i - f*g) + c*(d*h - e*g)
    if det == 0:
        return [[0.0]*3 for _ in range(3)]
    inv_det = 1.0 / det
    return [
        [(e*i - f*h)*inv_det, (c*h - b*i)*inv_det, (b*f - c*e)*inv_det],
        [(f*g - d*i)*inv_det, (a*i - c*g)*inv_det, (c*d - a*f)*inv_det],
        [(d*h - e*g)*inv_det, (b*g - a*h)*inv_det, (a*e - b*d)*inv_det]
    ]

def mat_vec_mul(M, v):
    return [sum(M[i][j] * v[j] for j in range(len(v))) for i in range(len(M))]

def get_patch_pixels(image, center, radius):
    patch = []
    cx, cy = center
    for dy in range(-radius, radius + 1):
        for dx in range(-radius, radius + 1):
            x, y = cx + dx, cy + dy
            if 0 <= x < image.width and 0 <= y < image.height:
                color = image.get_color(x, y)
                intensity = 0.299 * color[0] + 0.587 * color[1] + 0.114 * color[2]
                patch.append(intensity)
    return patch

def normalized_cross_correlation(patch1, patch2):
    if len(patch1) == 0 or len(patch2) == 0:
        return 0.0
    n = len(patch1)
    mean1 = sum(patch1) / n
    mean2 = sum(patch2) / n
    diff1 = [v - mean1 for v in patch1]
    diff2 = [v - mean2 for v in patch2]
    numerator = sum(a * b for a, b in zip(diff1, diff2))
    denominator = (sum(a**2 for a in diff1) * sum(b**2 for b in diff2)) ** 0.5
    if denominator == 0:
        return 0.0
    return numerator / denominator
```

**Parameters**
*   **Patch Radius**: Not given in the sources. The method selects several neighboring pixels around each considered pixel [S1].
*   **$\lambda$**: Weight for $L_{\text{SSIM}}$ in the total loss. Not given in the sources [S1].

**Edge Cases and Pitfalls**
*   **Depth/Normal Accuracy**: The homography $H$ depends on the rendered depth $d$ and normal $n$. Inaccurate maps lead to incorrect warping [S1].
*   **Lighting Variations**: Single-pixel optimization is susceptible to lighting variations; the patch-based NCC mitigates this [S1].
*   **Textureless Regions**: Standard 3DGS struggles with geometry in textureless regions, which is the primary motivation for the constraint [S1].

## Subtopics

### [Multi-view Regularization](23237-multi-view-regularization.md)
Penalizes cycle reprojection error to enforce multi-view geometric consistency. Sets itself apart by explicitly computing a forward-backward reprojection cycle error to handle occlusions and unreliable correspondences, rather than relying solely on patch matching and homography warping for color consistency.
