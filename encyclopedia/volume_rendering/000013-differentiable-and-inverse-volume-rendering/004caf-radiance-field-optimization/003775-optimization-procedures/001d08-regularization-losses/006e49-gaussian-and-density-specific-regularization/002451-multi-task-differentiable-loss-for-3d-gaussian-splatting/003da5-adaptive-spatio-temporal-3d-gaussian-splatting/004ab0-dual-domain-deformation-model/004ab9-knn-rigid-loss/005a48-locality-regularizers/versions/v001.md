# Locality Regularizers

Also called: Anchor-based Locality Regularization, Voronoi and Offset Loss

## Overview
Locality Regularizers are a pair of constraints used in resource-linear Gaussian decoding to ensure that the spatial neighborhood of a Gaussian token remains consistent with its parent anchor's local context [S1, unofficial]. They solve the problem of "neighbor drift," where optimized Gaussians move far enough from their initial positions that their true spatial neighbors no longer reside within the parent anchor's computed neighborhood $N_{anc}(n_b)$, thereby breaking the validity of the hierarchical neighbor search [S1, unofficial]. Unlike the parent [KNN Rigid Loss](12815-knn-rigid-loss.md), which enforces smoothness between a point and its K nearest neighbors, Locality Regularizers enforce topological consistency between a Gaussian and its anchor's local cluster structure [S1, unofficial].

## How it works
The method operates on a set of $B$ Gaussian tokens spawned from anchors. For each anchor $n$, the centroid of its initial Gaussians is computed as $\bar{\mu}_n = \frac{1}{k_n} \sum_{b: n_b=n} \mu_b^0$, where $k_n$ is the number of Gaussians spawned by anchor $n$ and $n_b$ is the parent anchor of token $b$ [S1, unofficial]. The regularizers are applied during the refinement stage to constrain the initial centers $\mu_b^0$ and the residual corrections $\Delta \mu_b$ [S1, unofficial].

**Inputs:**
- $B$: Total number of Gaussian tokens.
- $\mu_b^0$: Initial center of token $b$.
- $\Delta \mu_b$: Residual correction predicted by the residual head for token $b$.
- $N_{anc}(n_b)$: Set of neighboring anchor indices to the parent anchor $n_b$.
- $\bar{\mu}_m$: Centroid of anchor $m$.
- $d_{n_b}$: Local anchor spacing for anchor $n_b$.
- $\delta$: Margin parameter.

**Outputs:**
- Scalar loss values $L_{vor}$ and $L_{offset}$.

**Data Structures:**
- The neighbor set $N_{anc}(n_b)$ is determined by a hierarchical neighbor search (e.g., using a spatial index like a KD-tree or grid) over the anchor centroids $\bar{\mu}_n$ [S1, unofficial].
- $d_{n_b}$ is defined as the median distance from $\bar{\mu}_{n_b}$ to its $K_{anc}$ nearest anchors [S1, unofficial].

**Steps:**
1. Compute the centroid $\bar{\mu}_n$ for each anchor $n$ that spawned at least one Gaussian.
2. For each anchor $n_b$, identify its $K_{anc}$ nearest neighbors to compute the local spacing $d_{n_b}$ as the median distance to these neighbors [S1, unofficial].
3. Identify the set of neighboring anchors $N_{anc}(n_b)$ for each parent anchor $n_b$ [S1, unofficial].
4. Compute the Voronoi loss $L_{vor}$ to ensure each Gaussian stays closer to its parent anchor's centroid than to any neighboring anchor's centroid.
5. Compute the Offset loss $L_{offset}$ to limit the magnitude of the residual correction relative to the local anchor scale.

**Formulas:**

The Voronoi loss is defined as [S1, unofficial]:
$$
L_{vor} = \frac{1}{B} \sum_{b=1}^B \sum_{m \in N_{anc}(n_b)} \max\left(0, \|\mu_b^0 - \bar{\mu}_{n_b}\| - \|\mu_b^0 - \bar{\mu}_m\|\right)
$$
where $\mu_b^0$ is the initial center of Gaussian $b$, $\bar{\mu}_{n_b}$ is the centroid of its parent anchor, and $\bar{\mu}_m$ is the centroid of a neighboring anchor $m$ [S1, unofficial].

The Offset loss is defined as [S1, unofficial]:
$$
L_{offset} = \frac{1}{B} \sum_{b=1}^B \max\left(0, \frac{\|\Delta \mu_b\|}{d_{n_b}} - \delta\right)^2
$$
where $\Delta \mu_b$ is the residual correction for Gaussian $b$, $d_{n_b}$ is the local anchor spacing of the parent anchor, and $\delta$ is a margin parameter [S1, unofficial].

**Parameters:**
- $\delta$: Margin limiting Gaussian movement relative to local anchor scale. Typical value is 0.5 [S1, unofficial].
- $K_{anc}$: Number of nearest anchors used to compute local spacing. Not given in the sources.

**Pseudocode:**

```python
def compute_locality_regularizers(
    initial_centers: List[Vector3],  # mu_b^0 for b in 1..B
    residual_corrections: List[Vector3],  # Delta mu_b for b in 1..B
    parent_anchors: List[int],  # n_b for b in 1..B
    anchor_centroids: Dict[int, Vector3],  # mu_bar_n for each anchor n
    neighbor_sets: Dict[int, List[int]],  # N_anc(n_b) for each anchor n_b
    local_spacings: Dict[int, float],  # d_n_b for each anchor n_b
    delta: float = 0.5
) -> Tuple[float, float]:
    """
    Computes Voronoi and Offset losses for locality regularization.
    
    Args:
        initial_centers: List of initial Gaussian centers mu_b^0.
        residual_corrections: List of residual corrections Delta mu_b.
        parent_anchors: List mapping each Gaussian b to its parent anchor n_b.
        anchor_centroids: Dictionary mapping anchor index n to its centroid mu_bar_n.
        neighbor_sets: Dictionary mapping each anchor n_b to a list of neighboring anchor indices m.
        local_spacings: Dictionary mapping each anchor n_b to its local spacing d_n_b.
        delta: Margin parameter for offset loss.
        
    Returns:
        Tuple of (L_vor, L_offset).
    """
    B = len(initial_centers)
    sum_vor = 0.0
    sum_offset = 0.0
    
    for b in range(B):
        mu_b0 = initial_centers[b]
        delta_mu_b = residual_corrections[b]
        n_b = parent_anchors[b]
        
        # Get parent anchor centroid
        mu_bar_nb = anchor_centroids[n_b]
        
        # Voronoi Loss
        # Sum over all neighboring anchors m in N_anc(n_b)
        neighbors = neighbor_sets[n_b]
        for m in neighbors:
            mu_bar_m = anchor_centroids[m]
            dist_to_parent = norm(mu_b0 - mu_bar_nb)
            dist_to_neighbor = norm(mu_b0 - mu_bar_m)
            # max(0, dist_to_parent - dist_to_neighbor)
            term = dist_to_parent - dist_to_neighbor
            if term > 0:
                sum_vor += term
        
        # Offset Loss
        # Limit drift relative to local anchor spacing
        d_nb = local_spacings[n_b]
        # Avoid division by zero if spacing is zero (edge case)
        if d_nb > 1e-8:
            norm_delta_mu = norm(delta_mu_b)
            ratio = norm_delta_mu / d_nb
            margin_term = ratio - delta
            if margin_term > 0:
                sum_offset += margin_term ** 2
    
    L_vor = sum_vor / B
    L_offset = sum_offset / B
    
    return L_vor, L_offset
```

**Edge Cases and Pitfalls:**
- If $d_{n_b}$ is zero or very small, the Offset loss division may become unstable. A small epsilon should be added to the denominator [G].
- The neighbor set $N_{anc}(n_b)$ must be computed consistently with the search used during inference to ensure the regularizer matches the operational context [S1, unofficial].
- If an anchor has no neighbors (isolated), the Voronoi loss sum is empty, contributing 0 to the loss [G].

## Subtopics

### Geometric Anchoring Regularizer
A regularizer that penalizes excessive center displacement in local orthogonal directions while preserving necessary positional adjustments within an allowed subspace, interpreted as MAP estimation with a generalized Gaussian prior [S2, unofficial]. It uses an adaptive strength based on structural confidence: when the neighborhood direction is well-defined, orthogonal displacement is constrained more strongly; when local structure is uncertain, the constraint is weakened to prevent erroneous PCA directions from imposing incorrect restrictions [S2, unofficial]. The loss is defined as $\mathcal{L}_{anchor} = \sum_{i=1}^{K} \hat{C}_i \| (I - P_i)(x_i - x_{0,i}) \|^2$, where $P_i$ is the allowed-direction projection matrix and $\hat{C}_i$ is the structural confidence [S2, unofficial].

## Operating characteristics
- **Time Complexity:** The Voronoi loss requires iterating over all neighbors for each Gaussian, leading to a complexity proportional to $B \times |N_{anc}|$, where $|N_{anc}|$ is the average number of neighboring anchors. The Offset loss is $O(B)$ [S1, unofficial].
- **Memory Complexity:** Requires storing neighbor sets and local spacings for all anchors, which is linear in the number of anchors [S1, unofficial].
- **Strengths:** Ensures that the hierarchical neighbor search remains valid during optimization, preventing topological inconsistencies that could degrade rendering quality [S1, unofficial].
- **Limitations:** Depends on the accuracy of the initial anchor placement and neighbor search; if the initial topology is incorrect, the regularizer may enforce incorrect constraints [S1, unofficial].
- **When to use:** When using resource-linear Gaussian decoding with hierarchical neighbor search to maintain spatial locality [S1, unofficial].
- **When not to use:** When global attention is used instead of local cross-attention, as the locality assumption is not required [S1, unofficial].

## Background
Locality Regularizers were introduced in RLSplat (Resource-Linear Budget Control for Feed-forward 3D Gaussian Splatting) to support resource-linear Gaussian decoding with hierarchical neighbor search [S1, unofficial]. The method was developed to address the scalability issues of global attention in 3D Gaussian Splatting by restricting interactions to local neighborhoods, which requires strict control over Gaussian positions relative to their anchors [S1, unofficial].
