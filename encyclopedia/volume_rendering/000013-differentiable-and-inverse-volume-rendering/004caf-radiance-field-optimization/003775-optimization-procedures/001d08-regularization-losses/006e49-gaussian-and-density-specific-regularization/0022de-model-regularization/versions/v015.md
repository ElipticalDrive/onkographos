# Model Regularization

Also called: Residual Rotation Regularization, Rotation Regularization

## Overview
Model Regularization applies explicit penalty terms to the raw outputs or internal parameters of a neural radiance field or Gaussian splatting decoder to constrain the solution space, prevent overfitting, and ensure physical plausibility [S2, S6]. It solves the problem of unstable or degenerate predictions (e.g., exploding scales, erratic rotations, or complex transfer functions) that standard photometric losses alone may not suppress [S1, unofficial][S2]. Unlike sibling methods that regularize the output image (e.g., [Total Variation](860-total-variation-regularization.md)) or the final rendering noise (e.g., [Output Noise](928-output-noise-regularization.md)), Model Regularization targets the *latent* or *parameter* space of the scene representation itself [S1, unofficial][S6].

## How it works
The method operates by evaluating specific regularization losses on the decoder's raw outputs (residuals, coefficients, or parameters) and adding them to the total training objective.

### Inputs and Outputs
*   **Inputs:** Raw decoder outputs (e.g., residual rotations $\mathbf{r}$, translation residuals $t_{mlp}$, spherical harmonics coefficients $c$, scales $s$, opacity $\sigma$), configuration parameters (caps, weights), and the current batch of rays or points.
*   **Outputs:** A scalar regularization loss value $L_{reg}$ added to the total loss.

### Data Structures
The implementation typically iterates over a dictionary of named regularization losses.
*   `losses_model_reg`: A dictionary mapping loss names (strings) to their computed scalar values (floats).
*   `self.config.system.loss`: A configuration object containing lambda weights for each regularization term, keyed as `lambda_{name}`.

### Steps
1.  **Compute Raw Losses:** Evaluate the specific regularization formulas defined below for the current batch of predictions. Store results in `losses_model_reg`.
2.  **Aggregate:** Iterate over `losses_model_reg`. For each `name, value` pair:
    *   Retrieve the weight $\lambda_{name}$ from `self.config.system.loss[f"lambda_{name}"]`.
    *   Compute the weighted loss: $L_{weighted} = \lambda_{name} \times value$.
    *   Add $L_{weighted}$ to the total model regularization loss.
3.  **Log:** Record the individual and total loss values for monitoring.

### Formulas and Parameters

#### 1. Rotation Regularization (Residual)
Applies a quadratic penalty to raw residual 6D rotations predicted by the decoder to prevent erratic orientation changes [S2].
$$
\mathcal{L}_{\mathrm{rot}} = \frac{1}{N}\sum_{n=1}^{N}\|\mathbf{r}_n\|_2^2
$$
*   $\mathbf{r}_n$: The residual rotation vector for sample $n$.
*   $N$: Total number of samples.

#### 2. SH Soft-Cap Regularization
Softly penalizes spherical harmonics (SH) coefficients whose magnitude exceeds a prescribed cap to avoid unstable appearance [S2].
$$
\mathcal{L}_{\mathrm{SH}} = \mathbb{E}\left [ \left ( \operatorname{softplus}\left (\frac {|c|-c_{\max }}{\tau _{\mathrm{SH}}}\right )\tau _{\mathrm{SH}} \right )^p \right ]
$$
*   $c$: SH coefficient magnitude.
*   $c_{\max}$: Prescribed cap for SH coefficient magnitude.
*   $\tau_{\mathrm{SH}}$: Temperature parameter for the softplus function.
*   $p$: Exponent (typically 2, though not explicitly defined in [S2], standard for L2-like penalties).

#### 3. Scale Regularization
Penalizes scales that exceed a predefined maximum (applied in log-space) [S2].
$$
\mathcal{L}_{\mathrm{scale}} = \frac {1}{N}\sum _{n=1}^{N} \max (\log s_n - \log s_{\max },0)^2
$$
*   $s_n$: Predicted scale.
*   $s_{\max}$: Maximum allowed scale.

#### 4. MLP Output Regularization (Human/Gaussian Splatting)
Controls the norm of translation residuals, pushes rotation residuals to identity, and guides ambient occlusion factors [S6].
$$
\mathcal{L}_{\mathrm{trans}} = \|t_{mlp}\|_2^2
$$
$$
\mathcal{L}_{\mathrm{rot}} = \|q_{mlp} - q_{id}\|_1
$$
$$
\mathcal{L}_s = \|s - 1\|_2^2
$$
*   $t_{mlp}$: Translation residual from MLP.
*   $q_{mlp}$: Predicted rotation quaternion.
*   $q_{id}$: Identity quaternion.
*   $s$: Ambient occlusion factor.

#### 5. Uncertainty Regularization (Zero Regularization)
Encourages predicted uncertainty $\delta_i$ to be close to zero to prevent it from "blowing up" [S3].
$$
\mathcal{L}_0 = \sum_{r \in \mathcal{R}} \sum_{i=1}^N \max(\delta_{c_i}, 0)
$$
*   $\delta_{c_i}$: Predicted uncertainty for query coordinate $c_i$.
*   $\mathcal{R}$: Set of rays.
*   Note: Used in conjunction with an uncertainty loss $\mathcal{L}_{unct} = \alpha_1 \mathcal{L}_{SE} + \alpha_2 \mathcal{L}_0$ with $\alpha_1=1.0, \alpha_2=0.01$ [S3].

#### 6. Volume Regularization (Scaffold-GS)
Regularizes the product of scales to control volume [S4].
$$
\mathcal{L}_{vol} = \sum_{i=1}^N \text{Prod}(s_i)
$$
*   Weighted at 0.01 in Scaffold-GS [S4].

#### 7. Compactness Regularizer
Based on volume and opacity, adopted from 3D-GS-MCMC [S5].
*   Specific formula not given in sources, but applied to Gaussian splatting models to reduce Gaussian count [S5].

### Pseudocode
```python
def compute_model_regularization_loss(model, batch, config):
    """
    Computes model regularization losses for a batch of predictions.
    """
    losses_dict = {}
    
    # 1. Rotation Regularization (Residual)
    # Assumes model outputs residual rotations r_n
    r_n = model.get_residual_rotations(batch)
    if r_n is not None:
        # L_rot = (1/N) * sum(||r_n||_2^2)
        losses_dict['rot'] = torch.mean(torch.norm(r_n, dim=-1)**2)

    # 2. SH Soft-Cap Regularization
    # Assumes model outputs SH coefficients c
    c = model.get_sh_coefficients(batch)
    if c is not None:
        c_max = config.regularization.sh_cap
        tau_sh = config.regularization.sh_temp
        # softplus(x) = log(1 + exp(x))
        # L_SH = E[ (softplus((|c| - c_max) / tau_SH) * tau_SH)^p ]
        # Note: p is assumed to be 2 for L2-like behavior if not specified
        p = 2 
        diff = (torch.abs(c) - c_max) / tau_sh
        soft_val = torch.nn.functional.softplus(diff) * tau_sh
        losses_dict['sh'] = torch.mean(soft_val**p)

    # 3. Scale Regularization
    # Assumes model outputs scales s_n in log-space or raw
    s_n = model.get_scales(batch)
    if s_n is not None:
        s_max = config.regularization.scale_max
        # L_scale = (1/N) * sum(max(log(s_n) - log(s_max), 0)^2)
        log_s = torch.log(s_n)
        log_s_max = torch.log(torch.tensor(s_max))
        diff = torch.clamp(log_s - log_s_max, min=0)
        losses_dict['scale'] = torch.mean(diff**2)

    # 4. MLP Output Regularization (Human/Gaussian)
    t_mlp = model.get_translation_residual(batch)
    if t_mlp is not None:
        losses_dict['trans'] = torch.norm(t_mlp, p=2)**2
        
    q_mlp = model.get_rotation_residual(batch)
    q_id = torch.tensor([1.0, 0.0, 0.0, 0.0]) # Identity quaternion
    if q_mlp is not None:
        # L_rot = ||q_mlp - q_id||_1
        losses_dict['rot_mlp'] = torch.norm(q_mlp - q_id, p=1)
        
    s_ao = model.get_ao_factor(batch)
    if s_ao is not None:
        # L_s = ||s - 1||_2^2
        losses_dict['ao'] = torch.norm(s_ao - 1.0, p=2)**2

    # 5. Uncertainty Regularization
    delta_c = model.get_uncertainty(batch)
    if delta_c is not None:
        # L_0 = sum(max(delta_ci, 0)) over all rays and samples
        losses_dict['uncertainty'] = torch.sum(torch.clamp(delta_c, min=0))

    # 6. Volume Regularization (Scaffold-GS)
    # Prod(s_i) usually implies product of dimensions (sx*sy*sz)
    s_dims = model.get_scale_dimensions(batch)
    if s_dims is not None:
        # Prod(s_i) for each Gaussian
        prod_s = torch.prod(s_dims, dim=-1)
        losses_dict['volume'] = torch.sum(prod_s)

    # 7. Compactness Regularizer
    # Specific implementation details not provided in [S5], 
    # but typically involves opacity and volume terms.
    # Placeholder for implementation specific to 3D-GS-MCMC adaptation.
    # losses_dict['compactness'] = ... 

    return losses_dict

def aggregate_regularization_losses(losses_dict, config):
    """
    Aggregates individual regularization losses using configured lambda weights.
    """
    total_loss = 0.0
    for name, value in losses_dict.items():
        lambda_key = f"lambda_{name}"
        if lambda_key in config.system.loss:
            weight = config.system.loss[lambda_key]
            total_loss += weight * value
        else:
            # [G] Default weight of 0 if not configured
            pass
            
    return total_loss
```

### Edge Cases and Pitfalls
*   **Precision:** Log-space calculations for scale regularization require handling $s_n \le 0$ or $s_n \approx 0$ to avoid `NaN` or `-inf` [S2].
*   **Identity Quaternion:** For rotation regularization, the identity quaternion $q_{id}$ must be correctly defined (usually $[1, 0, 0, 0]$) [S6].
*   **Softplus Stability:** The SH soft-cap regularization uses `softplus`, which is numerically stable, but the temperature $\tau_{SH}$ must be chosen carefully to avoid vanishing or exploding gradients [S2].

## Subtopics

### [L1 Norm Regularization for Transfer Functions](7273-l1-norm-regularization-for-transfer-functions.md)
Applies an L1 penalty to the opacity and color parameters of a transfer function to avoid unnecessary complexity. It is chosen when interpretability of the transfer function is critical, preventing redundant color mappings and multiple opacity peaks.

### [Neural Latent Regularization](10334-neural-latent-regularization.md)
Uses a small auxiliary neural network to reconstruct grid features from canonical coordinates and timestamps, preventing overfitting of the radiance field without affecting inference speed. It is chosen when the grid feature representation itself needs smoothing, distinct from regularizing the transfer function or output colors.

### [L1 Regularization on Residual Grids](11655-l1-regularization-on-residual-grids.md)
Applies L1 regularization to residual grids ($R_t$) during the optimization of dynamic radiance fields to enforce temporal continuity. It is a core component of JointRF, chosen when temporal stability and compression of dynamic scenes are priorities.

### [Component Ablation Diagnostics](14949-component-ablation-diagnostics.md)
A diagnostic procedure, not a training regularizer, used to evaluate the contribution of individual components (like regularization terms) by removing them post-hoc. It is chosen for analysis and debugging rather than active training improvement.

### Zero Regularization Loss
Encourages predicted uncertainty $\delta_i$ to be close to zero to prevent it from blowing up [S3]. Formula: $\mathcal{L}_0 = \sum_{r \in \mathcal{R}} \sum_{i=1}^N \max(\delta_{c_i}, 0)$. Used in Recursive-NeRF [S3].

### Scaffold-GS Volume Regularization
Regularizes the product of Gaussian scales to control volume [S4]. Formula: $\mathcal{L}_{vol} = \sum_{i=1}^N \text{Prod}(s_i)$, weighted at 0.01. Used in Octree-GS [S4].

### Compactness Regularizer
Adds a compactness regularizer based on volume and opacity to the loss function, adopted from 3D-GS-MCMC [S5]. It reduces Gaussian count by 2.5% and raises PSNR by 0.05 dB [S5].

### MLP Output Regularization
Controls the norm of translation residuals, pushes rotation residuals to identity, and guides ambient occlusion factors [S6]. Used in Human Gaussian Splatting [S6].

### SH Soft-Cap Regularization
Softly penalizes spherical harmonics coefficients exceeding a cap to avoid unstable appearance [S2]. Formula: $\mathcal{L}_{\mathrm{SH}} = \mathbb{E}\left [ \left ( \operatorname{softplus}\left (\frac {|c|-c_{\max }}{\tau _{\mathrm{SH}}}\right )\tau _{\mathrm{SH}} \right )^p \right ]$ [S2].

## Operating characteristics
*   **Time Complexity:** Adds negligible overhead to the forward pass, as it operates on already-computed decoder outputs [S2, S6].
*   **Memory Complexity:** No additional memory storage required beyond the decoder outputs [S2].
*   **Strengths:** Prevents specific failure modes (exploding scales, erratic rotations) that photometric loss alone may not address [S2, S6]. Improves generalization and stability [S5].
*   **Limitations:** Requires careful tuning of regularization weights ($\lambda$) and parameters (caps, temperatures) [S2, S3]. Over-regularization can lead to underfitting or loss of detail [S5].
*   **When to Use:** When the model exhibits unstable predictions, overfitting to noise, or physically implausible parameters [S1, unofficial][S2].
*   **When Not to Use:** When the model is already stable and the regularization terms interfere with the learning of fine details [S5].

## Background
Model Regularization techniques have been developed alongside neural radiance fields and 3D Gaussian Splatting to address the ill-posed nature of inverse rendering problems. Key contributions include:
*   **GlobalSplat:** Introduced rotation, scale, and SH soft-cap regularization for efficient feed-forward 3D Gaussian Splatting [S2].
*   **Recursive-NeRF:** Applied uncertainty regularization to prevent uncertainty predictions from blowing up [S3].
*   **Octree-GS:** Used volume regularization for LOD-structured Gaussians [S4].
*   **DART-3DGS:** Adopted compactness regularization from 3D-GS-MCMC to reduce Gaussian count [S5].
*   **Human Gaussian Splatting:** Applied MLP output regularization for animatable avatars [S6].
*   **Instant-NSR-PL:** Provided a framework for aggregating various regularization losses [S1, unofficial].
