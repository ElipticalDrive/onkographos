# Model Regularization

Also called: Residual Rotation Regularization, Rotation Regularization

## Overview
Model Regularization applies penalties to the raw parameters of a neural scene representation (such as residual rotations or spherical harmonics coefficients) to prevent instability and overfitting during optimization [S2]. It distinguishes itself from output-based regularizations (like [Distortion Loss](2755-distortion-loss.md)) by constraining internal latent variables or decoder outputs directly, ensuring predicted geometric or appearance attributes remain within physically plausible or numerically stable bounds [S2].

## How it works
**Inputs and Outputs:**
- **Inputs:** The raw outputs from the neural network's decoder layers, including residual rotation vectors $\mathbf{r}_n$, spherical harmonics coefficients $c$, and scale parameters $s_n$ [S2].
- **Outputs:** A scalar regularization loss value $L_{reg}$ that is weighted by a hyperparameter $\lambda$ and added to the total training objective [S1, unofficial].

**Data Structures:**
- **Residual Rotations ($\mathbf{r}_n$):** A vector of size 6 representing the 6D rotation residual predicted by the decoder [S2].
- **SH Coefficients ($c$):** A vector of spherical harmonics coefficients for each Gaussian or voxel [S2].
- **Scales ($s_n$):** Log-space scale parameters predicted by the decoder [S2].

**Steps:**
1. **Retrieve Decoder Outputs:** Extract the raw parameters from the model's forward pass, typically via a dedicated regularization hook that returns a dictionary of raw parameters [S1, unofficial].
2. **Compute Individual Loss Terms:** Calculate specific regularization losses based on the parameter type using the formulas below [S2].
3. **Aggregate and Weight:** Multiply each loss term by its corresponding weight (lambda) from the configuration dictionary and sum them into the total loss [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def softplus(x):
    return np.logaddexp(0, x)

def compute_model_regularization_loss(raw_params, config):
    # raw_params: dict with keys 'rotations' (N, 6), 'sh_coeffs' (N, C), 'scales' (N,)
    # config: dict with config.system.loss = {name: lambda_val}
    N = raw_params['rotations'].shape[0]
    losses = {}

    # 1. Rotation regularization: quadratic penalty on raw residual 6D rotations [S2]
    losses['rotation'] = np.mean(np.linalg.norm(raw_params['rotations'], axis=1)**2)

    # 2. SH soft-cap regularization: soft penalty for coefficients exceeding cap [S2]
    c = raw_params['sh_coeffs']
    c_max = config.get('c_max')  # [G] Value not given in sources
    tau_SH = config.get('tau_SH')  # [G] Value not given in sources
    p = config.get('p', 2)
    sh_term = softplus((np.abs(c) - c_max) / tau_SH) * tau_SH
    losses['sh_softcap'] = np.mean(sh_term**p)

    # 3. Scale regularization: quadratic penalty for log-scales exceeding max [S2]
    s = raw_params['scales']
    s_max = config.get('s_max')  # [G] Value not given in sources
    losses['scale'] = np.mean(np.maximum(np.log(s) - np.log(s_max), 0)**2)

    # 4. Aggregate and weight per loss name from config [S1, unofficial]
    total_loss = 0.0
    for name, loss_val in losses.items():
        lambda_val = config.system.loss.get(f"lambda_{name}", 0.0)
        weighted = loss_val * lambda_val
        total_loss += weighted
        # Log the loss [S1, unofficial]
        print(f"Logged {name}: {weighted}")

    return total_loss
```

**Formulas:**
- **Rotation Loss ($L_{rot}$):** Applies a quadratic penalty to raw residual 6D rotations $\mathbf{r}_n$ predicted by the decoder [S2].
  $$
  L_{rot} = \frac{1}{N} \sum_{n=1}^{N} \|\mathbf{r}_n\|_2^2
  $$
  where $N$ is the number of samples or Gaussians [S2].

- **SH Soft-Cap Loss ($L_{SH}$):** Softly penalizes spherical harmonics coefficients $c$ whose magnitude exceeds a prescribed cap $c_{max}$ [S2].
  $$
  L_{SH} = \mathbb{E}\left[ \left( \operatorname{softplus}\left( \frac{|c| - c_{max}}{\tau_{SH}} \right) \tau_{SH} \right)^p \right]
  $$
  where $\tau_{SH}$ is the temperature parameter for the softplus function, and $p$ is the power (typically 2) [S2].

- **Scale Regularization ($L_{scale}$):** Penalizes scales $s_n$ that exceed a predefined maximum $s_{max}$ in log-space [S2].
  $$
  L_{scale} = \frac{1}{N} \sum_{n=1}^{N} \max(\log s_n - \log s_{max}, 0)^2
  $$

**Parameters:**
- **$c_{max}$:** Prescribed cap for SH coefficient magnitude. Not given in the sources.
- **$\tau_{SH}$:** Temperature parameter for the softplus function. Not given in the sources.
- **$s_{max}$:** Maximum allowed scale. Not given in the sources.
- **$\lambda_{name}$:** Weight for each regularization term. Configurable per loss name via a dictionary lookup [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Precision:** Scales are predicted in log-space [S2].

## Subtopics

### [L1 Norm Regularization for Transfer Functions](7273-l1-norm-regularization-for-transfer-functions.md)
Applies an L1 penalty to the opacity and color parameters of a transfer function to avoid unnecessary complexity when a simpler transfer function yields a similar result. It addresses convergence to complex transfer functions with multiple opacity peaks and redundant color mappings that are difficult for users to interpret. Choose this when transfer function interpretability is critical.

### [Neural Latent Regularization](10334-neural-latent-regularization.md)
Uses a small auxiliary neural network to reconstruct grid features from canonical coordinates and timestamps, preventing overfitting of the radiance field without affecting inference speed. It distinguishes itself from sibling methods by regularizing the grid feature representation itself rather than the transfer function or output colors. Choose this for dynamic radiance fields where grid consistency is key.

### [L1 Regularization on Residual Grids](11655-l1-regularization-on-residual-grids.md)
Applies L1 regularization to residual grids ($R_t$) during the optimization of dynamic radiance fields to enforce temporal continuity and minimize the magnitude of temporal changes. It is a core component of the JointRF training objective, distinguishing itself from static regularization by explicitly targeting the temporal residual structure to facilitate compression and stability. It builds on [Model Regularization](2912-model-regularization.md). Choose this for dynamic scene reconstruction.

### [Component Ablation Diagnostics](14949-component-ablation-diagnostics.md)
Evaluates the contribution of individual components within a neural scene reconstruction pipeline by systematically removing architectural branches, loss terms, or input signals and comparing performance against a baseline. It is distinguished from sibling methods by its diagnostic nature: rather than actively regularizing the model during training, it isolates marginal utility through parallel or sequential variant training. Choose this for architectural analysis.

### [MLP Output Regularization](16242-mlp-output-regularization.md)
Applies specific loss terms to the outputs of a neural network (typically a scene manipulator or deformation field) to enforce physical plausibility or stability. It solves the problem of unrealistic deformations or artifacts by constraining translation residuals, rotation residuals, and ambient occlusion factors. It differs from general model regularization by targeting the semantic meaning of the output vectors rather than the network weights directly. Choose this for deformation fields or scene manipulators.

### Zero Regularization Loss
Encourages predicted uncertainty $\delta_i$ to be as close to zero as possible to prevent blowing up [S3]. The formula is $\mathcal{L}_0 = \sum_{r \in \mathcal{R}} \sum_{i=1}^N \max(\delta_{c_i}, 0)$ [S3]. It is used in uncertainty-aware NeRFs [S3].

### Scaffold-GS Volume Regularization
Volume regularization loss is defined as $L_{vol} = \sum_{i=1}^N \text{Prod}(s_i)$, weighted at 0.01 [S4]. It is used in Scaffold-GS to control Gaussian volume [S4].

### Compactness Regularizer
A training detail adopted from 3D-GS-MCMC that adds a compactness regularizer based on volume and opacity to the loss function [S5]. Adding the regularizer to the full model raises PSNR by 0.05 dB (to 27.80) and reduces the final Gaussian count by 2.5% (3.23M to 3.15M) [S5]. It improves SSIM by 0.001 but worsens LPIPS by only 0.001 (0.203 to 0.204) [S5].

### SH Soft-Cap Regularization
A regularization term to avoid unstable appearance coefficients by softly penalizing spherical harmonics coefficients whose magnitude exceeds a prescribed cap [S2]. It uses a softplus function with temperature $\tau_{SH}$ and cap $c_{max}$ [S2].

### Triplane Regularization
Regularization applied to triplane features during optimization to simplify the data manifold for the diffusion model, ensuring feature planes do not contain spurious high-frequency information and discouraging outlier values [S6]. It includes total variation (TV) regularization terms to make the distribution of triplane features more similar to the manifold of natural images [S6].

### Anatomy-Aware Regularization
The total loss is $L = L_{photo} + \lambda_1 L_{sparse} + \lambda_2 L_{TV}$ [S7, unofficial]. $L_{photo}$ is MSE($\hat{I}$, $I$), $\lambda_1$ (sparse weight) is $1 \times 10^{-4}$, and $\lambda_2$ (TV weight) is $1 \times 10^{-5}$ [S7, unofficial]. Without a density parameterisation correction ($\Delta=0$), neither regularization term receives a meaningful gradient signal because density is zero [S7, unofficial].

### Regularization Terms
Additional constraints applied during training to improve reconstruction quality and stability [S8]. These include shading the underlying geometry during training, randomly dropping out texture during training, smoothing the normals of the surface, and fitting the model in a coarse-to-fine fashion to capture overall structure first and fine-grained details later [S8].

### Kinematic and Behavioral Regularization
Applies a constant penalty whenever the robot’s yaw angular speed is larger than $\pi$ rad s$^{-1}$ to encourage slow turning [S9]. It applies L2 regularization on joint angles towards a default standing pose [S9]. It applies a walking reward encouraging the average of feet velocities in the robot’s forward direction to be 0.3 m s$^{-1}$ [S9].

- **Limitations:** Requires tuning of caps ($c_{max}$) and weights ($\lambda$) [S2].

## Background
Originated from techniques in 3D Gaussian Splatting and NeRF optimization [S2, S5]. Rotation regularization and SH soft-cap regularization are detailed in GlobalSplat [S2]. Uncertainty regularization ($L_0$) was introduced in Recursive-NeRF [S3]. Compactness regularization was adopted from 3D-GS-MCMC [S5]. Scaffold-GS uses volume regularization [S4]. The general framework of calling `model.regularizations()` is seen in instant-nsr-pl implementations [S1, unofficial].
