# L1 Regularization on Residual Grids

Also called: JointRF Training Objective, Residual Grid L1 Regularization

## Overview
This method applies L1 regularization to residual grids ($R_t$) during the optimization of dynamic radiance fields to enforce temporal continuity and minimize the magnitude of temporal changes [S1]. It is a core component of the JointRF training objective, distinguishing itself from static regularization by explicitly targeting the temporal residual structure to balance reconstruction quality with model compression [S1].

## How it works
The method integrates into a total loss function that combines reconstruction error, estimated bit-rate, and the L1 norm of the residual grid [S1].

**Inputs and Outputs:**
*   **Inputs:** Ground truth color $c(r)$, rendered color $\hat{c}(r)$, residual grid $R_t$, quantized residual grid $\hat{R}_t$, quantized coefficient grid $\hat{C}_t$, and hyperparameters $\lambda_1, \lambda_2$.
*   **Outputs:** Scalar total loss $L_{total}$.

**Data Structures:**
*   $R_t$: The residual grid representing temporal differences.
*   $\hat{R}_t, \hat{C}_t$: Quantized versions of the residual and coefficient grids used for rate estimation [S1].

**Formulas:**
The total loss is defined as [S1]:
$$ L_{total} = L_{mse} + \lambda_1 L_{rate} + \lambda_2 ||R_t||_1 $$

Where:
1.  **Reconstruction Loss ($L_{mse}$):** Measures the difference between ground truth and rendered results [S1]:
    $$ L_{mse} = \sum ||c(r) - \hat{c}(r)||_2 $$
2.  **Rate Loss ($L_{rate}$):** Estimates the bit-rate based on probability mass functions (PMFs) of quantized grids [S1]:
    $$ L_{rate} = -\frac{1}{N} \sum_{\hat{y} \in \hat{R}_t} \log_2(P_1(\hat{y})) - \frac{1}{M} \sum_{\hat{y} \in \hat{C}_t} \log_2(P_2(\hat{y})) $$
    Here, $P_1$ and $P_2$ are the PMFs for $\hat{R}_t$ and $\hat{C}_t$ respectively, and $N, M$ are the number of elements in each grid [S1].
3.  **Residual Regularization ($||R_t||_1$):** The L1 norm of the residual grid $R_t$ [S1].

**Parameters:**
*   $\lambda_1$: Balances rate and distortion. Initialized at $0.000001$ and decrements progressively [S1].
*   $\lambda_2$: Measures the constraint extent on $R_t$. Initialized at $0.000001$ [S1].

**Pseudocode:**
```python
def compute_jointrf_loss(c_gt, c_rendered, R_t, P1, P2, lambda1, lambda2):
    """
    Computes the JointRF total loss.
    
    Args:
        c_gt: Ground truth color tensor.
        c_rendered: Rendered color tensor.
        R_t: Residual grid tensor.
        P1: PMF for quantized residual grid.
        P2: PMF for quantized coefficient grid.
        lambda1: Rate-distortion balance factor.
        lambda2: Residual regularization factor.
        
    Returns:
        Total loss scalar.
    """
    # L_mse: Sum of L2 norms between ground truth and rendered colors
    # Note: Source [S1] uses sum of L2 norms, not squared L2.
    l_mse = sum(norm(c_gt[i] - c_rendered[i]) for i in range(len(c_gt)))
    
    # L_rate: Estimated rate from quantized grids
    # N and M are counts of elements in quantized grids
    # P1 and P2 are probability mass functions
    # Implementation requires quantization step to get y_hat from R_t and C_t
    # Assuming quantized grids R_hat_t and C_hat_t are available:
    # l_rate = - (1/N) * sum(log2(P1[y_hat]) for y_hat in R_hat_t) \
    #          - (1/M) * sum(log2(P2[y_hat]) for y_hat in C_hat_t)
    # [G] Quantization logic is not detailed in [S1], assumed to be handled externally.
    l_rate = compute_rate_loss(R_t, C_t, P1, P2) 
    
    # L_reg: L1 regularization on residual grid
    l_reg = sum(abs(R_t[i]) for i in range(len(R_t)))
    
    l_total = l_mse + lambda1 * l_rate + lambda2 * l_reg
    return l_total
```

**Edge Cases and Pitfalls:**
*   The progressive decrement of $\lambda_1$ requires careful scheduling to avoid premature convergence or instability [S1].
*   Quantization of $R_t$ and $C_t$ is necessary for $L_{rate}$; the specific quantization scheme is not detailed in the source [S1].

## Subtopics

### L1 Time Plane Regularization
A regularizer that encourages time planes to be close to 1 by penalizing the L1 distance from 1 [S2, unofficial]. It identifies spatiotemporal grids based on grid length: if the length is not 3, spatiotemporal grids are indices [2, 4, 5] [S2, unofficial]. For each identified grid, it computes the mean of $|1 - \text{grid}|$ and adds it to the total loss [S2, unofficial]. This method is associated with 4D Gaussian Splatting implementations [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of pixels/views for $L_{mse}$ and the size of the residual grids for $L_{rate}$ and $L_{reg}$ [S1].
*   **Memory Complexity:** Requires storage for $R_t$, $\hat{R}_t$, $\hat{C}_t$, and their PMFs [S1].
*   **Strengths:** Explicitly targets temporal continuity, aiding in compression by minimizing residual magnitude [S1].
*   **Limitations:** Requires quantization for rate estimation, adding complexity [S1].
*   **When to use:** When optimizing dynamic radiance fields with a focus on compression and temporal smoothness [S1].

## Background
This method originates from the JointRF paper, which proposes end-to-end joint optimization for dynamic neural radiance field representation and compression [S1]. It was introduced in 2024 [S1]. The L1 Time Plane Regularization variant is associated with 4D Gaussian Splatting codebases [S2, unofficial].
