# Coherence Metric

Also called: Focus Structure Coherence

## Overview
The Coherence Metric evaluates whether a specific focus structure's shading distribution is preserved in a rendered Direct Volume Rendering Image (DVRI), ensuring a clear and comprehensible presentation without distortion from partial occlusion [S1]. It distinguishes itself from sibling methods like [MSE Loss and PSNR Conversion](1651-mse-loss-and-psnr-conversion.md) by focusing on the structural integrity of a unique, user-defined focus object rather than global pixel-wise error, and from [Visibility-Based Photometric Loss](2917-visibility-based-photometric-loss.md) by explicitly penalizing shading inconsistencies within that structure [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A candidate rendering solution $c$, a defined focus structure $f$ (unique within the candidate), and a visibility threshold $t_{sv}$.
*   **Output:** A coherence score $H(c)$. Lower values indicate higher coherence.

**Data Structures:**
*   `image_f`: Grayscale image representing the exclusive rendering of the focus structure $f$.
*   `image_c`: Grayscale image representing the full candidate rendering $c$.
*   `image_diff`: Image storing the absolute difference between `image_f` and `image_c`.
*   $P$: A set of pixel coordinates $(x, y)$ belonging to the focus structure in the difference image.

**Parameters:**
*   $t_{sv}$: Visibility threshold. If the visibility of $f$ is below this, coherence is considered bad [S1].
*   $K_h$: A large constant used to penalize bad coherence when visibility is insufficient [S1].

**Steps:**
1.  **Visibility Check:** Calculate the visibility $V(f)$ of the focus structure. If $V(f) < t_{sv}$, the structure is not visible enough. Return a bad coherence score:
    $$ H(c) = \left(1 + \frac{t_{sv} - V(f)}{t_{sv}}\right) \cdot K_h $$
    The worse the visibility, the higher the penalty [S1].
2.  **Exclusive Rendering:** If $V(f) \ge t_{sv}$, exclusively render the focus structure $f$ to generate its structure image.
3.  **Grayscale Conversion:** Convert the structure image of $f$ to a grayscale image, denoted as `image_f`. This captures the luminance variation (shading distribution) of the focus structure's projection [S1].
4.  **Candidate Grayscale:** Convert the grayscale image of the full candidate rendering $c$ to `image_c` [S1].
5.  **Difference Calculation:** Compute the difference image `image_diff` where each pixel value is the absolute difference between the corresponding pixels in `image_f` and `image_c`:
    $$ \text{image\_diff}(x, y) = |\text{image\_f}(x, y) - \text{image\_c}(x, y)| $$
6.  **Pixel Set Identification:** Identify the set $P$ of pixels in `image_diff` that belong to the focus structure $f$ [S1].
7.  **Variance Calculation:** Calculate the coherence score $H(c)$ as the statistical variance $\sigma^2$ of the difference values in the set $P$:
    $$ H(c) = \sigma^2(P) $$
    Low variance implies high coherence, meaning the shading distribution of the focus structure is preserved consistently in the candidate rendering [S1].

**Pseudocode:**
```python
def coherence_metric(candidate_rendering, focus_structure, visibility_threshold, large_constant):
    # 1. Check visibility
    visibility = compute_visibility(focus_structure, candidate_rendering)
    
    if visibility < visibility_threshold:
        # Bad coherence due to insufficient visibility
        penalty_factor = 1 + (visibility_threshold - visibility) / visibility_threshold
        return penalty_factor * large_constant
    
    # 2. Render focus structure exclusively
    structure_image = render_exclusively(focus_structure)
    
    # 3. Convert to grayscale
    image_f = to_grayscale(structure_image)
    
    # 4. Get candidate grayscale image
    image_c = to_grayscale(candidate_rendering)
    
    # 5. Compute difference image
    image_diff = new_image_of_same_size()
    for each pixel (x, y) in image_diff:
        image_diff[x, y] = abs(image_f[x, y] - image_c[x, y])
        
    # 6. Identify pixels belonging to focus structure
    P = get_pixels_belonging_to_structure(focus_structure, image_diff)
    
    # 7. Calculate variance of differences in P
    diff_values = [image_diff[p.x, p.y] for p in P]
    coherence_score = statistical_variance(diff_values)
    
    return coherence_score
```

**Edge Cases and Pitfalls:**
*   **Visibility Threshold:** If $V(f)$ is close to $t_{sv}$, small fluctuations in visibility can cause large jumps in the penalty term. The choice of $K_h$ must be significant enough to dominate the optimization landscape when visibility is poor [S1].
*   **Structure Definition:** The set $P$ must accurately correspond to the pixels occupied by the focus structure in the difference image. Misalignment here leads to incorrect variance calculation [S1].

## Subtopics

### [Context Metric](13254-context-metric.md)
Ensures relationships between volume structures remain understandable by maintaining shared context. It is used within the Coherence Metric framework to prevent the generation of DVRIs that lack relational context with previously shown views.

## Operating characteristics
*   **Complexity:** The method requires rendering the focus structure exclusively and the full candidate, plus pixel-wise operations. Complexity depends on the resolution and the number of samples for visibility calculation.
*   **Strengths:** Specifically targets the clarity of individual structures, making it useful for interactive exploration where specific organs or parts need to be highlighted clearly [S1].
*   **Limitations:** It is dependent on the definition of a "focus structure." It does not evaluate the overall quality of the volume rendering, only the coherence of a specific part. It requires a visibility metric to be defined and computed [S1].

## Background
The Coherence Metric was introduced in the context of Visibility-Aware Direct Volume Rendering to help users generate clear and comprehensible volume rendering images. It addresses the problem of inconsistent appearance of structures due to varying degrees of occlusion in different regions [S1].
