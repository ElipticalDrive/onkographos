# Closed-Form Color Estimation (CF) Loss

Also called: Closed-form photometric loss, closed-form color estimation method

## Overview
Closed-Form Color Estimation (CF) Loss is a regularization technique for explicit radiance fields (such as Plenoxels and DVGO) that breaks the entanglement between density and color fields to reduce shape-radiance ambiguity [S1]. Unlike standard photometric losses that supervise the final rendered image directly, CF loss estimates a closed-form color field given the current density field and posed training images, then computes a photometric loss between this estimated color and the ground truth to supervise the density field [S1]. It is distinct from distortion loss in that it is sensitive to specific geometric errors and can distinguish objects from background where distortion loss fails [S1].

## How it works
**Inputs:**
*   Current density field $\mathbf{F}_v^\sigma$ (voxel grid) [S1].
*   Current color field $\mathbf{F}_v^c$ (voxel grid, represented by Spherical Harmonics coefficients) [S1].
*   Set of $K$ source camera poses and intrinsics [S1].
*   Ground truth images [S1].
*   A mini-batch of rays $R_{cf}$ (size $|R_{cf}|$) [S1].

**Outputs:**
*   Scalar loss value $L_{cf}$ [S1].
*   Gradients with respect to the density field parameters [S1].

**Data Structures:**
*   **Voxel Grid:** 3D grid where each voxel $v$ stores density $\sigma_v$ and color coefficients. For Plenoxels, color is stored as $3 \times (2+1)^2 = 27$ Spherical Harmonic (SH) coefficients per voxel (SH degree 2) [S1].
*   **Ray Batch:** A set of $|R_{cf}|$ rays. For Plenoxels, $|R_{cf}|=25$; for DVGO, $|R_{cf}|=10$ [S1].

**Algorithm:**

1.  **Ray Selection:** Select a mini-batch of rays $R_{cf}$ from the training set. A uniform probability distribution $p_d(d) \equiv \frac{1}{4\pi}$ is applied to directions [S1].
2.  **Voxel Identification:** Identify all voxels intersected by the rays in $R_{cf}$. Let $N$ be the number of voxels per ray, and $M = |R_{cf}| \times N$ be the total number of intersected voxels [S1].
3.  **Closed-Form Color Estimation:** For each intersected voxel $v$, estimate its color $\hat{\mathbf{c}}_v$ by solving a linear system that accounts for occlusion and non-uniform view distribution [S1]. The method applies a bias reduction scheme where $\tilde{m} = m$ if $i = \ell$, else $\tilde{m} = i$ [S1].
4.  **Rendering Estimated Color:** Render the scene using the estimated color field $\hat{\mathbf{F}}_v^c$ and the current density field $\mathbf{F}_v^\sigma$ following the volume rendering equation:
    $$
    \hat{C}_{cf}(\mathbf{r}) = \sum_{i=1}^N T_i (1 - \exp(-\sigma_i \delta_i)) \hat{\mathbf{c}}_i
    $$
    where $\hat{\mathbf{c}}_i$ is the estimated color for the $i$-th voxel along ray $\mathbf{r}$ [S1].
5.  **Loss Calculation:** Compute the photometric loss between the ground truth color $C(\mathbf{r})$ and the closed-form estimated color $\hat{C}_{cf}(\mathbf{r})$:
    $$
    L_{cf} = \frac{1}{|R_{cf}|} \sum_{\mathbf{r} \in R_{cf}} ||C(\mathbf{r}) - \hat{C}_{cf}(\mathbf{r})||_2^2
    $$
    [S1].
6.  **Regularization:** Add $\lambda L_{cf}$ to the total training loss, where $\lambda$ is a weight factor [S1].

**Parameters:**
*   $\lambda$ (Weight factor): Plenoxels: DTU=10, NeRF synthetic=0.1, LLFF=0.5 [S1]. DVGO: DTU coarse=1, fine=0.1; NeRF synthetic coarse=2, fine=0.1; LLFF=0.1 [S1].
*   $|R_{cf}|$ (Number of rays): Plenoxels=25, DVGO=10 [S1].
*   $K$ (Number of source cameras): DTU=44 or 58, NeRF synthetic=100, LLFF=17 to 54 [S1].
*   $N$ (Order of voxels per ray): Not given in the sources.
*   $B$ (Batch size): Typical values 10, 25 [S1].

**Pseudocode:**

```python
def compute_cf_loss(density_field, color_field, cameras, gt_images, ray_batch, lambda_weight):
    """
    Computes the Closed-Form Color Estimation Loss.
    """
    # Step 1: Identify voxels intersected by the ray batch
    intersected_voxels = set()
    for ray in ray_batch:
        for voxel in ray.voxels:
            intersected_voxels.add(voxel)
            
    # Step 2: Estimate closed-form color for each intersected voxel
    estimated_colors = {}
    for voxel in intersected_voxels:
        # Gather rays passing through this voxel from all K cameras
        voxel_rays = [r for r in ray_batch if voxel in r.voxels]
        
        # Construct observation vector b and interaction matrix A
        A = []
        b = []
        for r in voxel_rays:
            # Compute transmittance from voxel to camera along the ray
            transmittance = 1.0
            for i, v in enumerate(r.voxels):
                if v == voxel:
                    break
                transmittance *= r.transmittance_factors[i]
            A.append(transmittance)
            b.append(r.gt_color)
            
        # Solve least-squares problem (A^T A) c = A^T b for SH coefficients [G]
        estimated_colors[voxel] = solve_least_squares(A, b)
        
    # Step 3: Render the scene using estimated colors and current density
    estimated_rendered_colors = []
    for ray in ray_batch:
        ray_estimated_colors = []
        for voxel in ray.voxels:
            ray_estimated_colors.append(estimated_colors.get(voxel, [0.0, 0.0, 0.0]))
            
        # Volume render using estimated colors and current density
        rendered_color = volume_render(ray, ray_estimated_colors, density_field)
        estimated_rendered_colors.append(rendered_color)
        
    # Step 4: Compute photometric loss
    gt_colors = [r.gt_color for r in ray_batch]
    loss = 0.0
    for est_c, gt_c in zip(estimated_rendered_colors, gt_colors):
        loss += sum((e - g) ** 2 for e, g in zip(est_c, gt_c))
    loss /= len(ray_batch)
    
    # Step 5: Apply weight
    return lambda_weight * loss

def solve_least_squares(A, b):
    """Solves (A^T A) c = A^T b using standard linear algebra operations [G]."""
    import numpy as np
    A_mat = np.array(A)
    b_vec = np.array(b)
    return np.linalg.lstsq(A_mat, b_vec, rcond=None)[0]

def volume_render(ray, estimated_colors, density_field):
    """Computes rendered color using the volume rendering equation [S1]."""
    rendered = [0.0, 0.0, 0.0]
    T = 1.0
    for i, voxel in enumerate(ray.voxels):
        sigma = density_field[voxel]
        delta = ray.step_sizes[i]
        c = estimated_colors[i]
        alpha = 1.0 - np.exp(-sigma * delta)
        rendered += T * alpha * c
        T *= np.exp(-sigma * delta)
    return rendered
```

**Edge Cases and Pitfalls:**
*   **Highly Reflective Objects:** The closed-form color field has difficulty perfectly recovering highly reflective objects, resulting in less reflective surfaces compared to ground truth [S1].
*   **CUDA Thread Limits:** High computational overhead if excessive threads are used due to hardware limits on maximum CUDA threads, preventing guaranteed parallel execution [S1].
*   **Bias:** Non-uniformly distributed views can cause estimation biases. The source mentions a bias reduction strategy in Appendix A [S1].

## Operating characteristics
**Time and Memory Complexity:**
*   The total number of voxels involved is $M = |R_{cf}| \times N$ [S1].
*   For each voxel, density values along the ray from the voxel to $K$ source cameras need to be calculated [S1].
*   The total computation is of order $K \times |R_{cf}| \times N^2$ without optimization [S1].
*   With CUDA parallelization (one block per voxel, one thread per camera), the theoretical overhead is reduced to order $N$ [S1].
*   Memory usage scales with the ray batch size $|R_{cf}|$ and intersected voxels $M$, avoiding storage of intermediate states for all pixels [G].

**Measured Performance:**
*   **DTU Scan 24:** DVGO PSNR 27.78, IMRC 17.45. DVGO + CF loss PSNR 28.64, IMRC 18.53 [S1].
*   **Mic Scene (NeRF synthetic):** DVGO PSNR 28.41, IMRC 8.09. DVGO + CF loss PSNR 34.01, IMRC 19.83 [S1].
*   **Training Time (Plenoxels, 9 epochs):**
    *   Batch size 10: DTU ~24 min, NeRF synthetic ~20.5 min, LLFF ~29.4 min [S1].
    *   Batch size 25: DTU ~32 min, NeRF synthetic ~25.5 min, LLFF ~34.6 min [S1].
    *   Note: DTU dataset requires longer training time because it is trained for 12 epochs in the source, while NeRF synthetic is trained for 9 epochs [S1].

**Strengths and Limitations:**
*   **Strengths:** Complements distortion loss; more effective at correcting specific geometric errors like floaters; distinguishes objects from background (e.g., wire vs background) where distortion loss fails [S1].
*   **Limitations:** Struggles with highly reflective objects; sensitive to view distribution; computational overhead can be affected by batch size due to hardware limits [S1].

**When to Use:**
*   Use with explicit NeRFs (Plenoxels, DVGO) when shape-radiance ambiguity is a concern [S1].
*   Use when distortion loss alone fails to correct specific geometric errors [S1].
*   Not recommended for scenes with highly reflective objects unless SH degree is increased or other mitigations are applied [S1].

## Background
**Origin:**
*   Proposed in "Reducing Shape-Radiance Ambiguity in Radiance Fields with a Closed-Form Color Estimation Method" [S1].
*   The paper addresses the shape-radiance ambiguity problem in NeRFs, where wrong geometry can be learned and poor novel-views rendered even with simple backgrounds and abundant training images [S1].

**History and Development:**
*   The method was implemented using CUDA kernels for explicit NeRFs [S1].
*   It was tested on DTU, NeRF synthetic, and LLFF datasets [S1].
*   The method uses Spherical Harmonics (SH) degree 2 for color representation in Plenoxels [S1].

**Usage:**
*   Applied to explicit NeRFs: Plenoxels and DVGO [S1].
*   Used in conjunction with distortion loss for best results on DVGO [S1].
