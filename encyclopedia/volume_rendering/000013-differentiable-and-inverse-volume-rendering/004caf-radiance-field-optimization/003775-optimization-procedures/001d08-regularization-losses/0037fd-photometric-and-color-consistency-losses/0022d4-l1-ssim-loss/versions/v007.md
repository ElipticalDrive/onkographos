# L1+SSIM Loss

Also called: 3D Gaussian Splatting Training Loss, SSIM+L1 Loss, Warped Photometric Loss

## Overview
L1+SSIM Loss is a composite photometric objective used to optimize radiance fields and 3D Gaussian splats by minimizing the difference between rendered images and ground-truth reference views [S1, unofficial]. It combines a pixel-wise L1 error term with a Structural Similarity (SSIM) term to preserve local structures and edges while maintaining color accuracy [S2, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** Rendered image $\hat{\mathbf{I}}$, reference image $\mathbf{I}$, SSIM weight $\lambda$ (or $\lambda_s, \alpha$) [S1, unofficial].
- **Outputs:** Scalar loss value $\mathcal{L}$ and gradients with respect to scene parameters (Gaussian attributes, neural network weights, etc.) [S1, unofficial].

**Data Structures:**
- Images $\hat{\mathbf{I}}, \mathbf{I}$ are typically 3D tensors of shape $(H, W, 3)$ representing height, width, and RGB channels [G]. Values are usually normalized to $[0, 1]$ [G].

**Formulas:**
The total loss is a weighted sum of the L1 loss and the SSIM loss [S1, S2, unofficial]:

$$
\mathcal{L} = (1 - \lambda) \mathcal{L}_1(\hat{\mathbf{I}}, \mathbf{I}) + \lambda \mathcal{L}_{\text{SSIM}}(\hat{\mathbf{I}}, \mathbf{I})
$$

Where:
- $\mathcal{L}_1(\hat{\mathbf{I}}, \mathbf{I}) = \frac{1}{HW} \sum_{h,w} \| \hat{\mathbf{I}}_{h,w} - \mathbf{I}_{h,w} \|_1$ is the mean absolute RGB error [S1, unofficial].
- $\mathcal{L}_{\text{SSIM}}(\hat{\mathbf{I}}, \mathbf{I}) = 1 - \text{SSIM}(\hat{\mathbf{I}}, \mathbf{I})$ is the structural similarity loss [S1, S2, unofficial].

In some contexts, such as warped photometric consistency, the loss is applied between a warped image $\mathbf{I}_i'$ and a target image $\mathbf{I}_i$ [S3]:

$$
\mathcal{L}_{\text{photo}} = \frac{1}{|\mathcal{N}_i|} \sum_{j \in \mathcal{N}_i} \left( \alpha \frac{1 - \text{SSIM}(\mathbf{I}_i', \mathbf{I}_i)}{2} + (1 - \alpha) \| \mathbf{I}_i' - \mathbf{I}_i \| \right)
$$

**Parameters:**
- $\lambda$ (or $\lambda_s$): Weight for the SSIM term. The standard value is **0.2** [S1, S2, unofficial].
- $\alpha$: Weight for the SSIM component in warped photometric loss. Typical value not explicitly stated in sources [S3].

**Steps:**
1. **Render:** Compute the rendered image $\hat{\mathbf{I}} = \mathcal{R}(\mathcal{G}; \pi, T)$ using the current scene parameters $\mathcal{G}$, camera pose $\pi$, and preset/transfer function $T$ [S1, unofficial].
2. **Compute L1:** Calculate the mean absolute difference between $\hat{\mathbf{I}}$ and $\mathbf{I}$ [S1, unofficial].
3. **Compute SSIM:** Calculate the Structural Similarity index between $\hat{\mathbf{I}}$ and $\mathbf{I}$ using a sliding window approach (typically $3\times3$ or $11\times11$ windows) [G].
4. **Combine:** Compute the weighted sum $\mathcal{L} = (1 - \lambda) \mathcal{L}_1 + \lambda (1 - \text{SSIM})$ [S1, S2, unofficial].
5. **Backpropagate:** Compute gradients of $\mathcal{L}$ with respect to the scene parameters. Gradients flow through the differentiable renderer $\mathcal{R}$ [S1, unofficial].

**Pseudocode:**
```python
def l1_ssim_loss(rendered, target, ssim_weight=0.2, window_size=11):
    # 1. L1 Loss: Mean absolute difference over all pixels and channels
    l1_loss = sum(abs(rendered[h, w, c] - target[h, w, c]) 
                  for h in range(H) for w in range(W) for c in range(3)) / (H * W * 3)
    
    # 2. SSIM Loss
    ssim_val = compute_ssim(rendered, target, window_size)
    ssim_loss = 1.0 - ssim_val
    
    # 3. Combine Losses
    return (1.0 - ssim_weight) * l1_loss + ssim_weight * ssim_loss

def compute_ssim(img1, img2, window_size=11):
    C1, C2 = 0.01**2, 0.03**2
    H, W, C = img1.shape
    half = window_size // 2
    total_ssim = 0.0
    count = 0
    for c in range(C):
        for h in range(H):
            for w in range(W):
                y1, y2 = max(0, h - half), min(H, h + half + 1)
                x1, x2 = max(0, w - half), min(W, w + half + 1)
                p1 = [img1[r, k, c] for r in range(y1, y2) for k in range(x1, x2)]
                p2 = [img2[r, k, c] for r in range(y1, y2) for k in range(x1, x2)]
                mu_x, mu_y = sum(p1)/len(p1), sum(p2)/len(p2)
                var_x = sum((v - mu_x)**2 for v in p1) / len(p1)
                var_y = sum((v - mu_y)**2 for v in p2) / len(p2)
                cov_xy = sum((v - mu_x)*(u - mu_y) for v, u in zip(p1, p2)) / len(p1)
                num = (2*mu_x*mu_y + C1) * (2*cov_xy + C2)
                den = (mu_x**2 + mu_y**2 + C1) * (var_x + var_y + C2)
                total_ssim += num / den
                count += 1
    return total_ssim / count
```

**Edge Cases and Pitfalls:**
- **Boundaries:** SSIM computation near image boundaries requires padding or window adjustment [G].
- **Degenerate Input:** If the rendered image is constant or the target image has no texture, SSIM may be undefined or unstable [G].

## Subtopics

### Warped Photometric Loss
Uses SSIM+L1 on images warped from neighboring views to enforce multi-view consistency [S3]. It differs from standard L1+SSIM by comparing warped projections rather than direct renders [S3]. Choose when multi-view consistency is more important than single-view accuracy [S3].

### Adaptive Photometric Loss
Dynamically adjusts the loss based on pixel confidence or error magnitude. It differs by thresholding or weighting pixels differently. Choose when dealing with noisy or occluded regions. [Adaptive Photometric Loss](9354-adaptive-photometric-loss-with-thresholding.md)

## Operating characteristics
- **Time Complexity:** $O(HW)$ for L1. SSIM is $O(HW \cdot K^2)$ where $K$ is the window size [G]. Overall complexity is dominated by SSIM computation [G].
- **Memory Complexity:** $O(HW)$ for storing intermediate gradients and images [G].
- **Performance:** SSIM+L1 is widely used in 3D Gaussian Splatting and NeRF optimization. It provides a good balance between sharpness (SSIM) and color fidelity (L1) [S2, unofficial].
- **Strengths:** Robust to outliers (L1), preserves edges and textures (SSIM) [G].
- **Limitations:** SSIM is non-convex and can be sensitive to local structures. Computationally more expensive than MSE or L1 alone [G].
- **When to use:** Standard photometric optimization for radiance fields and Gaussian splats [S1, S2, unofficial].
- **When not to use:** When real-time performance is critical and SSIM is too slow, or when structural similarity is not a desired property (e.g., textureless surfaces) [G].

## Background
The L1+SSIM loss was introduced in the context of 3D Gaussian Splatting and NeRF optimization to improve visual quality over MSE-based losses [S2, unofficial]. It builds on the SSIM metric proposed by Wang et al. (2004) [S1, unofficial].
