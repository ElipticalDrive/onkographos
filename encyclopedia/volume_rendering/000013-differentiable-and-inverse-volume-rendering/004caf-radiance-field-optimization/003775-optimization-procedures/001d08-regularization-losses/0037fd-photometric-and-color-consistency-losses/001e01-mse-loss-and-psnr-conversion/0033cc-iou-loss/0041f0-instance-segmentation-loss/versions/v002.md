# Instance Segmentation Loss

Also called: Instance Field Training, Instance Loss

## Overview
Instance Segmentation Loss trains the instance branch $\Theta_i$ of a radiance field using multi-view consistent 2D instance segmentation maps, while keeping the density $\Theta_\sigma$ and color $\Theta_c$ branches fixed [S1]. It distinguishes itself from sibling methods by explicitly optimizing for per-instance class probabilities rather than just binary occupancy or appearance, addressing the fragmentation caused by inconsistent 2D masks across views [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Pre-trained density network $\Theta_\sigma$ and color network $\Theta_c$ (frozen); instance network $\Theta_i$ (trainable); a set of multi-view 2D instance segmentation maps; camera poses and intrinsics [S1].
*   **Outputs:** Updated instance network parameters $\Theta_i$; rendered instance logits $\hat{I}(r)$, depth $\hat{D}(r)$, and color $\hat{C}(r)$ for rays $r$ [S1].

**Data Structures:**
*   **Instance Branch $\Theta_i$:** A neural network (e.g., MLP with Multi-resolution Hash Encoding for position and Spherical Harmonics for direction) that outputs a vector of instance logits $i(t_k)$ for each sample point $t_k$ along a ray [S1]. The hash grid $H_i$ is distinct from the density hash grid $H_\sigma$ [S1].
*   **Ray Sampling:** For each pixel, a ray $r(t) = o + td$ is generated. $K$ quadrature points $\{t_k\}_{k=1}^K$ are selected within the traceable volume [S1].

**Formulas:**
1.  **Accumulation:** For a ray $r$, the expected instance logits $\hat{I}(r)$, depth $\hat{D}(r)$, and color $\hat{C}(r)$ are accumulated using standard volume rendering integration [S1]:
    $$ \hat{I}(r) = \sum_{k=1}^{K} \hat{T}(t_k) \alpha(\sigma(t_k) \delta_k) i(t_k) $$
    $$ \hat{D}(r) = \sum_{k=1}^{K} \hat{T}(t_k) \alpha(\sigma(t_k) \delta_k) t_k $$
    $$ \hat{C}(r) = \sum_{k=1}^{K} \hat{T}(t_k) \alpha(\sigma(t_k) \delta_k) c(t_k) $$
    Where:
    *   $\delta_k = t_{k+1} - t_k$ is the distance between samples [S1].
    *   $\alpha(x) = 1 - \exp(-x)$ is the transmittance approximation [S1].
    *   $\hat{T}(t_k) = \exp\left(-\sum_{a=1}^{k-1} \sigma(t_a) \delta_a\right)$ is the accumulated transmittance up to sample $k$ [S1].
    *   $i(t_k)$ is the raw instance logit output by $\Theta_i$ at $t_k$ [S1].
    *   $c(t_k)$ is the color output by $\Theta_c$ at $t_k$ [S1].
    *   $\sigma(t_k)$ is the density output by $\Theta_\sigma$ at $t_k$ [S1].

2.  **Probability Prediction:** The volume prediction $\hat{p}_l(r)$ for instance class $l$ is obtained by applying softmax to the accumulated logits $\hat{I}(r)$ [S1]:
    $$ \hat{p}_l(r) = \text{softmax}(\hat{I}(r))_l $$

3.  **Instance Loss ($L_i$):** A multi-class cross-entropy loss comparing ground truth probabilities $p_l(r)$ with predictions $\hat{p}_l(r)$ [S1]:
    $$ L_i = -\frac{1}{|R||L|} \sum_{r \in R} \sum_{l=1}^{L} p_l(r) \log \hat{p}_l(r) $$
    Where $R$ is the set of sampled rays in a batch, $L$ is the number of instance classes, and $p_l(r)$ is the ground truth multi-class instance probability for class $l$ [S1].

4.  **Instance Regularization Loss ($L_r$):** To enforce 3D geometry consistency and smoothness, a regularization term is added based on depth similarity between adjacent pixels $(i,j)$ and $(i,j+1)$ or $(i+1,j)$ [S1]:
    $$ L_r = \frac{1}{|R||L|} \sum_{r_{i,j} \in R} \sum_{l=1}^{L} \left( (\hat{I}_{i,j}^l - \hat{I}_{i,j+1}^l)^2 w_{i,j} + (\hat{I}_{i,j}^l - \hat{I}_{i+1,j}^l)^2 h_{i,j} \right) $$
    Where weights $w_{i,j}$ and $h_{i,j}$ are normalized depth similarities [S1]:
    $$ \delta_w(i,j) = \exp\left(-(\hat{D}(r_{i,j}) - \hat{D}(r_{i,j+1}))^2\right) $$
    $$ w_{i,j} = \frac{\delta_w(i,j)}{\sum_{r'_{i',j'} \in R} \delta_w(i',j')} $$
    (Likewise for $h_{i,j}$ with $\delta_h$) [S1].

5.  **Total Loss:**
    $$ L = L_p + \lambda L_i $$
    Where $L_p$ is the appearance loss (MSE between $\hat{C}(r)$ and ground truth $C(r)$) and $\lambda$ is a hyperparameter [S1].

**Parameters:**
*   $\lambda$: Weight for instance loss. Value: 1.0 [S1].
*   $K$: Number of quadrature points per ray. Not given in the sources.
*   Score Threshold: 0.5 for filtering detections (used in NeRF-RCNN variant) [S1].

**Pitfalls:**
*   **Inconsistency:** 2D segmentation maps from existing models are not 3D geometry-consistent across views, leading to fragmented segmentation if trained directly [S1]. This is mitigated by $L_r$ and 2D mask refinement [S1].
*   **Precision:** The depth similarity weights $\delta_w$ rely on the pre-trained density branch's depth $\hat{D}$. Errors in $\hat{D}$ may propagate to incorrect smoothing weights [S1].

**Pseudocode:**
```python
import math

def compute_instance_loss(rays, gt_instance_probs, model_sigma, model_color, model_instance, lambda_inst=1.0):
    """
    Computes the total loss for Instance Segmentation Loss.
    
    Args:
        rays: List of dicts with keys 'positions' (K,), 'directions' (3,), 
              'gt_color' (3,), 'i' (int), 'j' (int), 'H' (int), 'W' (int).
        gt_instance_probs: List of lists/arrays of shape (num_classes,).
        model_sigma: Frozen density network returning scalar per position.
        model_color: Frozen color network returning vector per position/direction.
        model_instance: Trainable instance network returning vector per position/direction.
        lambda_inst: Hyperparameter lambda.
        
    Returns:
        total_loss: Scalar loss value.
    """
    num_rays = len(rays)
    num_classes = len(gt_instance_probs[0])
    
    rendered_instance_logits = [None] * num_rays
    rendered_depths = [0.0] * num_rays
    loss_p_sum = 0.0
    loss_i_sum = 0.0
    
    for r_idx, ray in enumerate(rays):
        t_k = ray['positions']
        K = len(t_k)
        delta_k = [t_k[k+1] - t_k[k] for k in range(K-1)] + [t_k[-1] - t_k[-2]]
        
        sigma_vals = model_sigma(ray['positions'])
        alpha_vals = [1.0 - math.exp(-s * d) for s, d in zip(sigma_vals, delta_k)]
        
        T_hat = [1.0] * K
        for k in range(1, K):
            T_hat[k] = T_hat[k-1] * (1.0 - alpha_vals[k-1])
            
        c_vals = model_color(ray['positions'], ray['directions'])
        i_vals = model_instance(ray['positions'], ray['directions'])
        
        weights = [T_hat[k] * alpha_vals[k] for k in range(K)]
        
        color = sum(w * c for w, c in zip(weights, c_vals))
        depth = sum(w * t for w, t in zip(weights, t_k))
        inst_logits = [sum(w * i for w, i in zip(weights, i_vals_k)) for i_vals_k in zip(*i_vals)]
        
        rendered_instance_logits[r_idx] = inst_logits
        rendered_depths[r_idx] = depth
        
        gt_color = ray['gt_color']
        loss_p_sum += 0.5 * sum((c - g)**2 for c, g in zip(color, gt_color))
        
        inst_probs = [math.exp(l) for l in inst_logits]
        prob_sum = sum(inst_probs)
        inst_probs = [p / prob_sum for p in inst_probs]
        
        gt_probs = gt_instance_probs[r_idx]
        loss_i_sum += -sum(g * math.log(max(p, 1e-7)) for g, p in zip(gt_probs, inst_probs))
        
    # Regularization Loss
    grid = {}
    for r_idx, ray in enumerate(rays):
        key = (ray['i'], ray['j'])
        grid[key] = (rendered_instance_logits[r_idx], rendered_depths[r_idx])
        
    H, W = rays[0]['H'], rays[0]['W']
    logits_grid = [[grid.get((h, w), ([0.0]*num_classes, 0.0))[0] for w in range(W)] for h in range(H)]
    depth_grid = [[grid.get((h, w), ([0.0]*num_classes, 0.0))[1] for w in range(W)] for h in range(H)]
    
    delta_w_h = [[math.exp(-(depth_grid[h][w] - depth_grid[h][w+1])**2) for w in range(W-1)] for h in range(H)]
    delta_w_v = [[math.exp(-(depth_grid[h][w] - depth_grid[h+1][w])**2) for w in range(W)] for h in range(H-1)]
    
    sum_w_h = sum(sum(row) for row in delta_w_h)
    sum_w_v = sum(sum(row) for row in delta_w_v)
    
    w_h = [[d / sum_w_h for d in row] for row in delta_w_h]
    w_v = [[d / sum_w_v for d in row] for row in delta_w_v]
    
    loss_h = sum(sum((logits_grid[h][w][l] - logits_grid[h][w+1][l])**2 * w_h[h][w] for l in range(num_classes)) for h in range(H) for w in range(W-1))
    loss_v = sum(sum((logits_grid[h][w][l] - logits_grid[h+1][w][l])**2 * w_v[h][w] for l in range(num_classes)) for h in range(H-1) for w in range(W))
    
    loss_r_sum = loss_h + loss_v
    
    loss_i = loss_i_sum / (num_rays * num_classes)
    loss_r = loss_r_sum / (num_rays * num_classes)
    loss_p = loss_p_sum / (2 * num_rays)
    
    return loss_p + lambda_inst * loss_i
```

## Subtopics

### 2D Mask Refinement
Refines preliminary instance segmentation results using CascadePSP to alleviate missing or erroneous masks caused by partial occlusion [S1]. It uses Instance-NeRF rendering results as input to the refinement network instead of Mask2Former output, as Instance-NeRF fuses multi-view information [S1]. Instances in each preliminary mask are split and refined independently, then superimposed to supervise the final instance field training [S1].

## Operating characteristics
*   **Time Complexity:** Training involves two stages: radiance field training (30k iterations) and instance field training (25k + 20k iterations) [S1].
*   **Memory Complexity:** Requires storing instance logits for all sample points along rays. The instance branch uses a separate hash grid $H_i$ [S1].
*   **Performance:** Achieves mIoU of 43.0 and PQ of 32.4 on the 3D-FRONT dataset, outperforming Semantic-NeRF (mIoU 35.0) and DM-NeRF (mIoU 11.3) [S1].
*   **Strengths:** Enables 3D instance segmentation without ground-truth 3D masks at test time; leverages multi-view consistency [S1].
*   **Limitations:** Relies on pre-trained 2D segmentation models that may lack 3D geometry consistency across views [S1].

## Background
Introduced in the Instance Neural Radiance Field paper [S1], extending NeRF-RPN and NeRF-RCNN by introducing an explicit instance branch $\Theta_i$ trained with multi-view consistent 2D instance segmentation maps [S1].
