# MSE Loss and PSNR Conversion

Also called: MSE (Mean Squared Error), MSE Calculation, MSE Loss, Mean Squared Error, Mean Squared Error Loss, img2mse

## Overview
The Mean Squared Error (MSE) loss computes the average of the squared differences between predicted and target RGB values, serving as the primary photometric fidelity metric for training differentiable volume rendering models [S2, S4, unofficial]. It is often accompanied by the Peak Signal-to-Noise Ratio (PSNR), a logarithmic transformation of MSE used for evaluation and logging, where higher values indicate better reconstruction quality [S1, S2, unofficial]. Unlike structural metrics such as SSIM, MSE focuses strictly on pixel-wise intensity differences, making it sensitive to large smooth regions but less responsive to small, high-frequency features [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Predicted RGB tensor $\hat{C}$ (shape: $[B, H, W, 3]$ or flattened $[N, 3]$) and Target RGB tensor $C_{gt}$ (same shape). Optional: Binary mask $M$ for volumetric or masked evaluation.
*   **Outputs:** Scalar loss value (MSE) and optionally the PSNR metric.

**Data Structures:**
*   Tensors are typically stored in contiguous memory layouts (e.g., row-major for images). For batched operations, the first dimension is the batch size $B$.
*   Values are usually 32-bit floating point (`float32`).

**Steps:**

1.  **Compute Element-wise Difference:** Calculate the difference between predicted and target values.
    $$ D = \hat{C} - C_{gt} $$
2.  **Square the Difference:** Square each element of the difference tensor.
    $$ S = D^2 $$
3.  **Aggregate (Standard):** Flatten spatial dimensions and average over all elements (or batch and spatial dimensions).
    $$ MSE = \frac{1}{N} \sum_{i=1}^{N} S_i $$
    where $N$ is the total number of elements (e.g., $B \times H \times W \times 3$) [S3, unofficial].
4.  **Aggregate (Masked):** If a binary mask $M$ is provided (where $M_{ijk} \in \{0, 1\}$), compute the mean only over masked elements.
    $$ MSE_{mask} = \frac{1}{N_{mask}} \sum_{i,j,k} M_{ijk} S_{ijk} $$
    where $N_{mask} = \sum M_{ijk}$ is the count of valid voxels/pixels [S6, unofficial].
5.  **Compute PSNR:** Convert the MSE to PSNR using the logarithmic scale.
    $$ PSNR = -10 \cdot \log_{10}(MSE) $$
    Alternatively, derived from the signal-to-noise ratio of the peak signal (assumed to be 1.0 for normalized [0,1] data):
    $$ PSNR = 20 \cdot \log_{10}\left(\frac{1}{\sqrt{MSE}}\right) $$
    [S1, S6, unofficial].

**Parameters:**
*   **Normalization:** Input RGB values are typically normalized to $[0, 1]$ [S2, unofficial].
*   **Mask Threshold:** In volumetric masked evaluation, a relative threshold (`mask_threshold_rel`, default 0.01) is applied to the maximum mask volume value to generate the boolean mask [S6, unofficial].

**Edge Cases and Pitfalls:**
*   **Division by Zero/Log of Zero:** If $MSE = 0$, $PSNR$ becomes infinity. Implementations should handle this explicitly, often returning `inf` or a large constant [S6, unofficial].
*   **Empty Mask:** If the mask contains no true values ($N_{mask} = 0$), the masked MSE is undefined. This should raise an error or return `NaN` [S6, unofficial].
*   **Dimension Mismatch:** Inputs must have identical shapes. For vector-based volume comparisons, size checks are required [S7, unofficial].

**Pseudocode:**

```python
import math
import numpy as np

def compute_mse(predicted: np.ndarray, target: np.ndarray, mask: np.ndarray = None) -> float:
    """
    Computes Mean Squared Error between predicted and target arrays.
    
    Args:
        predicted: Array of predicted values (e.g., RGB).
        target: Array of ground truth values.
        mask: Optional boolean array of the same shape. If provided, computes masked MSE.
        
    Returns:
        float: The MSE value.
    """
    # 1. Compute difference
    diff = predicted - target
    
    # 2. Square difference
    sq_error = diff ** 2
    
    if mask is not None:
        # 3. Apply mask
        masked_sq_error = sq_error * mask
        
        # 4. Count valid elements
        n_valid = np.sum(mask)
        
        if n_valid == 0:
            raise RuntimeError("Mask has no true values; cannot compute masked MSE.")
            
        # 5. Average over valid elements
        mse = np.sum(masked_sq_error) / n_valid
    else:
        # 3. Flatten and average (standard MSE)
        mse = np.mean(sq_error)
        
    return float(mse)

def mse_to_psnr(mse: float) -> float:
    """
    Converts MSE to PSNR.
    
    Args:
        mse: Mean Squared Error value.
        
    Returns:
        float: PSNR in decibels.
    """
    if mse <= 0:
        # Avoid log(0); return infinity or a large number
        return float('inf')
        
    # Formula: 10 * log10(1 / MSE) or 20 * log10(1 / sqrt(MSE))
    psnr = -10.0 * math.log10(mse)
    return psnr

def compute_psnr(predicted: np.ndarray, target: np.ndarray, mask: np.ndarray = None) -> float:
    """
    Computes PSNR directly from predicted and target arrays.
    """
    mse = compute_mse(predicted, target, mask)
    return mse_to_psnr(mse)
```

## Subtopics

### [PSNR Metric Calculation](2742-psnr-metric-calculation.md)
Peak Signal-to-Noise Ratio (PSNR) is a standard benchmark metric used to evaluate the photometric fidelity of reconstructed or rendered images against ground-truth references in differentiable volume rendering pipelines. It quantifies the mean squared error (MSE) between predicted and target pixel values, converting this error into a logarithmic decibel (dB) scale where higher values indicate better quality. Unlike structural metrics such as SSIM, PSNR focuses strictly on pixel-wise intensity differences, making it sensitive to large smooth regions but less responsive to small, high-frequency features like specular highlights. See [PSNR Metric Calculation](2742-psnr-metric-calculation.md).

### [SSIM Metric Calculation](3650-ssim-metric-calculation.md)
The Structural Similarity Index (SSIM) measures the perceived distortion between a rendered image and a ground truth image by comparing local patterns of pixel intensities, assuming the human visual system is highly adapted to structured natural scene information. It serves as a standard benchmark for image quality in radiance-field optimization, complementing pixel-wise metrics like MSE and PSNR. It provides a value between -1 and 1, where 1 indicates identical images. See [SSIM Metric Calculation](3650-ssim-metric-calculation.md).

### [Normal-L2 Score Computation](3842-normal-l2-score-computation.md)
The Normal-L2 score evaluates surface geometry by computing the mean squared L2 distance between predicted surface normals and reference normals from a ground-truth mesh. It is computed only on the intersection of predicted and ground-truth masks, distinguishing it from silhouette metrics like iIoU which evaluate mask alignment separately. See [Normal-L2 Score Computation](3842-normal-l2-score-computation.md).

### [Minkowski's Metric](4347-minkowski-s-metric.md)
Minkowski's Metric is a full-reference mathematical distance measure that treats images as 2D signals to quantify dissimilarity between a reference image $x$ and a test image $y$. It generalizes the Mean Squared Error (MSE) by allowing the exponent $\gamma$ to vary, thereby controlling the sensitivity to large errors versus small errors. Unlike its sibling [PSNR Metric Calculation](2742-psnr-metric-calculation.md) which is a logarithmic transformation of MSE, or [SSIM Metric Calculation](3650-ssim-metric-calculation.md) which models structural information, Minkowski's Metric operates directly on pixel-wise intensity differences. See [Minkowski's Metric](4347-minkowski-s-metric.md).

### Masked Volume Metrics
A method to exclude empty froxels from evaluation metrics by including only froxels affected by radiance [S8, unofficial]. A froxel is included if any of its RGB channels contain a non-zero value at any point during the test scenario [S8, unofficial]. The Region of Interest (ROI) is computed separately for each tested algorithm; the union of the scenario's ROI and the ground truth's ROI is used to create $ROI_{effective}$, ensuring only relevant froxels are included while excluding completely empty regions [S8, unofficial]. The formula is $ROI_{effective} = ROI_{scenario} \cup ROI_{truth}$ [S8, unofficial].

### MSE Bias-Variance Decomposition
Treating the TAA algorithm as a biased estimator to analyze correctness using Mean Squared Error (MSE), decomposed into variance and bias squared [S8, unofficial]. The formula is $MSE[F] = E[(F - G)^2] = V[F] + \beta[F]^2$, where $F$ is the output of the estimator, $G$ is the true value (ground truth), $V[F]$ is the variance of the estimator, and $\beta[F]$ is its bias [S8, unofficial].

### Training Loss Computation with Huber and Masking
In some pipelines, Huber loss is used instead of MSE for RGB, particularly when blending ground truth RGB with background to match rendering conditions [S9, unofficial]. The per-ray Huber loss is computed with a delta parameter (e.g., 0.1) and masked by ray validity, then averaged over valid rays [S9, unofficial].

### Area Loss Scaling
Scaling the loss of each pixel by the area of that pixel's footprint in the original image to ensure low-resolution pixels have comparable influence to high-resolution pixels in multiscale datasets [S10]. For a downsampling factor of $k$, the area factor is $k^2$ [S10].

### IoU Loss
A binary segmentation loss metric that computes the ratio of overlapping voxels above a threshold to the total union of predicted and target voxels [S11, unofficial]. The formula is $\text{IoU} = \frac{|\{v \mid \hat{v} > \tau\} \cap \{v \mid t_v > 0\}|}{|\{v \mid \hat{v} > \tau\} \cup \{v \mid t_v > 0\}|}$, where $\tau$ is the prediction threshold (default 0.9) [S11, unofficial].

### Greedy proposal matching
A fast assignment strategy used during Phase 1 to compute the L2 matching loss between heuristic samples and learnt proposals [S12, unofficial]. For each heuristic sample, the closest proposal from the learnt proposer set is found [S12, unofficial]. Optimal matching (Hungarian algorithm) or strict 1-1 greedy matching significantly slows training [S12, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
*   **Time:** $O(N)$, where $N$ is the number of pixels or voxels being compared. The operation is element-wise and highly parallelizable on GPUs [S3, unofficial].
*   **Memory:** $O(N)$ to store the difference and squared error tensors, or $O(1)$ if computed incrementally/streaming [S5, unofficial].

**Measured Performance:**
*   MSE is the dominant loss function in NeRF-like architectures due to its simplicity and differentiability [S2, S4, unofficial].
*   Typical PSNR values for NeRF on the Blender dataset range from 28 to 33 dB depending on the variant (e.g., Mip-NeRF achieves ~29.6-33.7 dB on test sets) [S10].

**Strengths and Limitations:**
*   **Strengths:** Simple to implement, differentiable everywhere, standard benchmark for comparison [S2, S4, unofficial].
*   **Limitations:** Does not account for structural similarity or perceptual quality as well as SSIM or LPIPS; sensitive to noise and outliers [S1, unofficial].

**When to Use:**
*   Standard training of radiance fields where pixel-wise accuracy is the primary goal [S4, unofficial].
*   Baseline evaluation of reconstruction quality [S2, unofficial].

**When Not to Use:**
*   When perceptual quality is more important than pixel-wise accuracy (use LPIPS or SSIM) [S1, unofficial].
*   When dealing with significant outliers or noise that should be ignored (use Huber loss or masked MSE) [S9, unofficial].

## Background
The Mean Squared Error (MSE) is a fundamental statistical measure of the average squared difference between estimated values and the actual value [S5, unofficial]. In the context of neural volume rendering, it was popularized by the original NeRF paper and subsequent implementations as the primary photometric loss function [S1, S2, S4, unofficial]. It is widely used in computer vision and image processing for regression tasks and image reconstruction [S7, unofficial].
