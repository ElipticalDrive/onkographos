# IoU Loss
Also called: Intersection over Union (IoU) Loss

## Overview
IoU Loss is a binary segmentation metric used to optimize the occupancy or density fields in differentiable volume rendering by measuring the overlap between predicted and target voxel sets. It differs from pixel-wise photometric losses like [MSE Loss and PSNR Conversion](1651-mse-loss-and-psnr-conversion.md) by operating on binarized volumetric occupancy rather than continuous RGB values, making it robust to intensity ambiguities and suitable for structural consistency [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Predicted occupancy/density field $\hat{v}$ (continuous values per voxel), target occupancy field $t_v$ (binary or continuous ground truth), and a binarization threshold $\tau$.
- Output: A scalar loss value $L_{IoU} = 1 - \text{IoU}$, where $\text{IoU}$ is the Intersection over Union ratio.

**Data Structures:**
- Voxel grids are represented as dense tensors or sparse structures where each element $v$ corresponds to a spatial location.
- $\hat{v}$ contains predicted probabilities or density values.
- $t_v$ contains target values (typically 1 for occupied, 0 for empty).

**Formula:**
The Intersection over Union is calculated as [S1, unofficial]:
$$ \text{IoU} = \frac{|\{v \mid \hat{v} > \tau\} \cap \{v \mid t_v > 0\}|}{|\{v \mid \hat{v} > \tau\} \cup \{v \mid t_v > 0\}|} $$
Where:
- $|\cdot|$ denotes the cardinality (count) of voxels in the set.
- $\{v \mid \hat{v} > \tau\}$ is the set of predicted voxels exceeding the threshold $\tau$.
- $\{v \mid t_v > 0\}$ is the set of target voxels considered occupied.
- The intersection $\cap$ represents voxels correctly predicted as occupied (True Positives).
- The union $\cup$ represents all voxels predicted or targeted as occupied (True Positives + False Positives + False Negatives).

**Parameters:**
- $\tau$: Prediction threshold for binarization. Default value is 0.9 [S1, unofficial].

**Pseudocode:**
```python
def iou_loss(predicted_occupancy, target_occupancy, threshold=0.9):
    """
    Computes the IoU loss for volumetric segmentation.
    
    Args:
        predicted_occupancy: Tensor of predicted occupancy/density values.
        target_occupancy: Tensor of target occupancy values (binary or continuous).
        threshold: Float, threshold for binarizing predictions.
        
    Returns:
        Float, the IoU loss (1 - IoU).
    """
    # Binarize predictions
    pred_binary = (predicted_occupancy > threshold).float()
    
    # Binarize targets (assuming > 0 means occupied)
    target_binary = (target_occupancy > 0).float()
    
    # Compute intersection and union
    intersection = (pred_binary * target_binary).sum()
    union = (pred_binary + target_binary).sum()
    
    # Handle edge case where union is zero (no occupied voxels in either)
    if union == 0:
        return 0.0
        
    iou = intersection / union
    return 1.0 - iou
```

**Edge Cases and Pitfalls:**
- **Division by Zero:** If both predicted and target sets are empty (union is 0), the IoU is undefined. A common convention is to return 0 loss or a specific penalty [G].
- **Threshold Sensitivity:** The choice of $\tau$ significantly impacts the gradient signal. A high threshold (e.g., 0.9) makes the loss sparse and less sensitive to small density changes [S1, unofficial].
- **Non-Differentiability:** The binarization step $(\hat{v} > \tau)$ is non-differentiable. In practice, this is often handled by using straight-through estimators or by optimizing the continuous values with a differentiable approximation (e.g., sigmoid) before applying the threshold for evaluation [G].

## Subtopics

### [Instance Segmentation Loss](10594-instance-segmentation-loss.md)
Trains the instance branch $\Theta_i$ of a radiance field using multi-view consistent 2D instance segmentation maps, while keeping the density $\Theta_\sigma$ and color $\Theta_c$ branches fixed. It distinguishes itself from sibling methods by explicitly optimizing for per-instance class probabilities rather than just binary occupancy or appearance, addressing the fragmentation caused by inconsistent 2D masks across views. It builds on [IoU Loss](7110-iou-loss.md) by providing the probabilistic supervision signal required for differentiable instance field training.

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the number of voxels, as it requires a single pass to compute sums for intersection and union.
- **Memory Complexity:** $O(N)$ to store the binary masks or intermediate tensors.
- **Strengths:** Robust to scale and intensity variations; directly optimizes structural overlap; effective for binary segmentation tasks in volume rendering.
- **Limitations:** Non-differentiable binarization requires special handling for gradient-based optimization; sensitive to threshold selection; less informative for continuous density estimation compared to MSE.
- **When to Use:** When the goal is to optimize the geometric structure or occupancy of a volume rather than photometric appearance.
- **When Not to Use:** When fine-grained intensity accuracy is required or when the ground truth is not binary.

## Background
IoU Loss originated in computer vision for image segmentation tasks and has been adapted for differentiable volume rendering to supervise occupancy fields. In the context of inverse rendering for tomographic volumetric additive manufacturing, it is used to ensure that the reconstructed volume matches the target geometry [S1, unofficial].
