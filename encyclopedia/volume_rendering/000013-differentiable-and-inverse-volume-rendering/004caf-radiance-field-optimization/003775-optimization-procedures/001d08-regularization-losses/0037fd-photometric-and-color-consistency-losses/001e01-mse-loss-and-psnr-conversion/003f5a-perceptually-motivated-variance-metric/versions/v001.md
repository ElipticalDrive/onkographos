# Perceptually-motivated variance metric

Also called: AO estimation error metric, log-mean and log-gradient MSE metric

## Overview
The perceptually-motivated variance metric quantifies the error between an 8-bit ambient occlusion (AO) approximation $T$ and a high-fidelity ray-traced reference $R$ [S1, unofficial]. It differs from raw pixel Mean Squared Error (MSE) by operating on log-transformed values and spatial gradients, thereby aligning with human visual sensitivity to radiance and its changes [S1, unofficial]. This metric is specifically designed for evaluating AO approximations where reflected ambient radiance is linear in accessibility [S1, unofficial].

## How it works
**Inputs and Outputs**
- **Input $T$**: An 8-bit "test" accessibility approximation image, where each pixel value $T_{x,y}$ satisfies $0 < T_{x,y} < 255$ [S1, unofficial].
- **Input $R$**: A ray-traced reference image used as ground truth, typically computed with 5000 samples per pixel to ensure high accuracy [S1, unofficial].
- **Output $E[T]$**: A scalar value representing the total perceptual error [S1, unofficial].

**Data Structures**
- Images are treated as 2D arrays of floating-point values derived from 8-bit integers.
- Gradients are computed as 2D arrays of the same dimensions as the input images.

**Mathematical Definitions**
1.  **Modified Logarithm ($\log^\dagger$)**:
    To handle values near zero and preserve sign, the metric uses a modified logarithm defined as [S1, unofficial]:
    $$ \log^\dagger x = \text{sign}(x) \cdot \log(|x| + 1) $$
    This function avoids the singularity at $x=0$ by adding 1 to the absolute value before taking the natural logarithm [S1, unofficial].

2.  **Mean Squared Error (MSE)**:
    $\text{MSE}[A]$ computes the variance (mean squared deviation from the mean) of the values in array $A$ across all pixels [S1, unofficial].

**Algorithm Steps**
1.  Compute the log-transformed test values: $L_{test} = \log^\dagger T$.
2.  Compute the log-transformed reference values: $L_{ref} = \log^\dagger R$.
3.  Calculate the mean squared error between the log-transformed test and reference images: $\text{MSE}_{mean} = \text{MSE}(L_{test} - L_{ref})$.
4.  Compute the horizontal spatial gradient of $T$, denoted $\frac{\partial T}{\partial x}$, and the vertical spatial gradient of $T$, denoted $\frac{\partial T}{\partial y}$ [S1, unofficial].
5.  Apply $\log^\dagger$ to each gradient component for both test and reference:
    -   $G_{test, x} = \log^\dagger \frac{\partial T}{\partial x}$
    -   $G_{test, y} = \log^\dagger \frac{\partial T}{\partial y}$
    -   $G_{ref, x} = \log^\dagger \frac{\partial R}{\partial x}$
    -   $G_{ref, y} = \log^\dagger \frac{\partial R}{\partial y}$
6.  Calculate the MSE for the horizontal gradients: $\text{MSE}_{x} = \text{MSE}(G_{test, x} - G_{ref, x})$.
7.  Calculate the MSE for the vertical gradients: $\text{MSE}_{y} = \text{MSE}(G_{test, y} - G_{ref, y})$.
8.  Combine the errors using the following formula [S1, unofficial]:
    $$ E[T] = \text{MSE}_{mean} + \frac{1}{2} \left( \text{MSE}_{x} + \text{MSE}_{y} \right) $$

**Pseudocode**
```python
import math

def log_dag(x: float) -> float:
    """
    Modified logarithm that preserves sign and avoids singularity at 0.
    log_dag(x) = sign(x) * log(|x| + 1)
    """
    return math.copysign(1.0, x) * math.log(abs(x) + 1.0)

def mse(values: list[float]) -> float:
    """
    Computes the Mean Squared Error (variance) of a list of values.
    MSE = mean((v - mean(v))^2)
    """
    n = len(values)
    if n == 0:
        return 0.0
    mean_val = sum(values) / n
    squared_diffs = [(v - mean_val) ** 2 for v in values]
    return sum(squared_diffs) / n

def compute_perceptual_error(T: list[list[float]], R: list[list[float]]) -> float:
    """
    Computes the perceptually-motivated variance metric between test image T
    and reference image R.
    
    Args:
        T: 2D list of floats representing the 8-bit test approximation (0 < T < 255).
        R: 2D list of floats representing the ray-traced reference.
        
    Returns:
        The total error E[T].
    """
    height = len(T)
    width = len(T[0])
    
    # Step 1 & 2: Log-transform test and reference
    L_test = [[log_dag(T[i][j]) for j in range(width)] for i in range(height)]
    L_ref = [[log_dag(R[i][j]) for j in range(width)] for i in range(height)]
    
    # Step 3: MSE of log-transformed images
    diff_mean = []
    for i in range(height):
        for j in range(width):
            diff_mean.append(L_test[i][j] - L_ref[i][j])
    mse_mean = mse(diff_mean)
    
    # Helper to compute gradients
    def compute_gradients(img: list[list[float]]) -> tuple[list[list[float]], list[list[float]]]:
        # Compute horizontal and vertical gradients
        # Using simple finite differences: grad_x[i][j] = img[i][j+1] - img[i][j]
        # grad_y[i][j] = img[i+1][j] - img[i][j]
        # Note: Boundary handling is not specified in sources [G]. 
        # Standard practice is to clamp or ignore boundaries. 
        # Here we compute gradients for valid interior pixels to match MSE scope.
        
        grad_x = [[0.0] * width for _ in range(height)]
        grad_y = [[0.0] * width for _ in range(height)]
        
        for i in range(height):
            for j in range(width - 1):
                grad_x[i][j] = img[i][j+1] - img[i][j]
            # Last column gradient undefined in simple forward diff, set to 0 or copy
            grad_x[i][width-1] = img[i][width-2] - img[i][width-1] if width > 1 else 0.0
            
        for i in range(height - 1):
            for j in range(width):
                grad_y[i][j] = img[i+1][j] - img[i][j]
        # Last row gradient undefined, set to 0 or copy
        for j in range(width):
            grad_y[height-1][j] = img[height-2][j] - img[height-1][j] if height > 1 else 0.0
            
        return grad_x, grad_y

    # Step 4: Compute gradients for T and R
    T_grad_x, T_grad_y = compute_gradients(T)
    R_grad_x, R_grad_y = compute_gradients(R)
    
    # Step 5: Log-transform gradients
    T_grad_x_log = [[log_dag(T_grad_x[i][j]) for j in range(width)] for i in range(height)]
    T_grad_y_log = [[log_dag(T_grad_y[i][j]) for j in range(width)] for i in range(height)]
    R_grad_x_log = [[log_dag(R_grad_x[i][j]) for j in range(width)] for i in range(height)]
    R_grad_y_log = [[log_dag(R_grad_y[i][j]) for j in range(width)] for i in range(height)]
    
    # Step 6 & 7: MSE of log-transformed gradients
    diff_x = []
    diff_y = []
    for i in range(height):
        for j in range(width):
            diff_x.append(T_grad_x_log[i][j] - R_grad_x_log[i][j])
            diff_y.append(T_grad_y_log[i][j] - R_grad_y_log[i][j])
            
    mse_x = mse(diff_x)
    mse_y = mse(diff_y)
    
    # Step 8: Combine errors
    error = mse_mean + 0.5 * (mse_x + mse_y)
    
    return error
```

**Parameters**
- **Reference Sampling**: The reference image $R$ should be computed using 5000 samples per pixel to ensure high accuracy [S1, unofficial].

**Edge Cases and Pitfalls**
- **Zero Values**: The logarithmic transformation is undefined at 0. The metric uses $\log^\dagger$, which adds 1 inside the log and preserves the original sign, preventing numerical singularities when $T$ or gradients approach 0 [S1, unofficial].
- **Gradient Boundaries**: The sources do not specify boundary conditions for gradient computation. Implementers must define how to handle pixels at the image edges (e.g., clamping, replication, or exclusion) [G].

## Operating characteristics
- **Time Complexity**: $O(N)$ where $N$ is the number of pixels, as it involves a constant number of passes over the image data (log, gradient, MSE).
- **Memory Complexity**: $O(N)$ to store intermediate gradient and log-transformed images.
- **Strengths**: Aligns with human visual perception by tracking both absolute radiance and spatial changes with decreasing marginal sensitivity [S1, unofficial]. It is particularly appropriate for reflected ambient radiance which is linear in accessibility [S1, unofficial].
- **Limitations**: Computationally more expensive than raw pixel MSE due to gradient calculation and logarithmic transformations. It is specific to AO approximation evaluation and may not generalize to other rendering metrics without modification.
- **When to Use**: When evaluating the perceptual quality of ambient occlusion approximations against a high-quality reference.
- **When Not to Use**: When computational efficiency is paramount and perceptual accuracy is secondary, or when evaluating metrics other than AO.

## Background
The metric was introduced by McGuire in the context of Ambient Occlusion Volumes (AOV) [S1, unofficial]. It was designed to provide a quantitative measure of error that correlates better with human visual perception than standard pixel-wise MSE, specifically for evaluating AO approximation algorithms [S1, unofficial]. The method is detailed in the paper "Ambient Occlusion Volumes" [S1, unofficial].
