# 3D Evaluation Metrics


## Overview
3D Evaluation Metrics quantify the fidelity of reconstructed volumetric data against ground-truth references, addressing the problem of assessing both geometric and photometric accuracy in 3D scenes [S1, unofficial]. Unlike [PSNR Metric Calculation](2742-psnr-metric-calculation.md) which focuses on pixel-level photometric error in 2D projections, this method extends evaluation to full 3D volumes, computing metrics such as PSNR and SSIM across axial, coronal, and sagittal slices [S2, unofficial]. It serves as the foundational evaluation layer for [Mesh Reconstruction Evaluation](2909-mesh-reconstruction-evaluation.md) and [Normal Consistency](3050-normal-consistency.md) by providing the volumetric baseline before surface extraction [S1, unofficial].

## How it works
**Inputs and Outputs**
- **Inputs**: Reconstructed 3D volume $V_{rec}$ and ground-truth 3D volume $V_{gt}$. Both must be normalized to the range $[0, 1]$.
- **Outputs**: Mean PSNR and SSIM values for each viewing direction (axial, coronal, sagittal).

**Data Structures**
- Volumes are represented as 3D arrays (tensors) of floating-point values.
- Dimensions correspond to spatial axes $(x, y, z)$.

**Steps**
1. **Normalization**: Ensure $V_{rec}$ and $V_{gt}$ are scaled to $[0, 1]$. If not, apply linear scaling:
   $$ V_{norm} = \frac{V - V_{min}}{V_{max} - V_{min}} $$
   where $V_{min}$ and $V_{max}$ are the minimum and maximum values in the volume [S1, unofficial].

2. **Slice Extraction**: Iterate over the three orthogonal dimensions to generate 2D slices:
   - **Axial**: Slices along the $z$-axis (fixed $z$, varying $x, y$).
   - **Coronal**: Slices along the $y$-axis (fixed $y$, varying $x, z$).
   - **Sagittal**: Slices along the $x$-axis (fixed $x$, varying $y, z$) [S2, unofficial].

3. **Metric Calculation per Slice**: For each 2D slice pair $(S_{rec}, S_{gt})$:
   - Compute Mean Squared Error (MSE):
     $$ MSE = \frac{1}{N} \sum_{i=1}^{N} (S_{rec}[i] - S_{gt}[i])^2 $$
     where $N$ is the total number of voxels/pixels in the slice, including background [S1, unofficial].
   - Compute PSNR:
     $$ PSNR = 10 \log_{10} \left( \frac{1}{MSE} \right) $$
     This is equivalent to $10 \log_{10}(MAX^2 / MSE)$ with $MAX=1$ [S1, unofficial].
   - Compute SSIM using a Gaussian window of size 11 with standard deviation $\sigma = 1.5$ [S1, unofficial].

4. **Aggregation**: Compute the mean PSNR and SSIM across all slices for each direction [S2, unofficial].

**Parameters**
- **SSIM Window Size**: 11 [S1, unofficial].
- **SSIM Gaussian $\sigma$**: 1.5 [S1, unofficial].
- **Volume Normalization Range**: $[0, 1]$ [S1, unofficial].

**Edge Cases and Pitfalls**
- **Background Inclusion**: MSE must be averaged over *all* voxels, including background, to ensure consistent scoring [S1, unofficial].
- **Normalization**: Failure to normalize to $[0, 1]$ before PSNR calculation invalidates the $MAX=1$ assumption [S1, unofficial].
- **Missing Slices**: If a volume has zero thickness in one dimension, that direction's metrics are undefined [G].

**Pseudocode**
```python
import numpy as np
from skimage.metrics import structural_similarity as ssim

def compute_3d_metrics(volume_rec: np.ndarray, volume_gt: np.ndarray) -> dict:
    """
    Compute PSNR and SSIM for axial, coronal, and sagittal views.
    Assumes volumes are normalized to [0, 1].
    """
    # Ensure float32 for precision
    volume_rec = volume_rec.astype(np.float32)
    volume_gt = volume_gt.astype(np.float32)
    
    results = {}
    
    # Define axes for each view
    # Axial: z-slices (axis 2)
    # Coronal: y-slices (axis 1)
    # Sagittal: x-slices (axis 0)
    views = {
        'axial': 2,
        'coronal': 1,
        'sagittal': 0
    }
    
    for view_name, axis in views.items():
        psnr_scores = []
        ssim_scores = []
        
        # Iterate over slices along the specified axis
        for i in range(volume_rec.shape[axis]):
            # Extract slice
            if axis == 0:
                slice_rec = volume_rec[i, :, :]
                slice_gt = volume_gt[i, :, :]
            elif axis == 1:
                slice_rec = volume_rec[:, i, :]
                slice_gt = volume_gt[:, i, :]
            else: # axis == 2
                slice_rec = volume_rec[:, :, i]
                slice_gt = volume_gt[:, :, i]
            
            # Compute MSE (including background)
            mse = np.mean((slice_rec - slice_gt) ** 2)
            
            # Avoid division by zero
            if mse == 0:
                psnr = float('inf')
            else:
                psnr = 10 * np.log10(1.0 / mse)
            
            psnr_scores.append(psnr)
            
            # Compute SSIM with specified parameters
            # window_size=11, sigma=1.5
            # data_range=1.0 since normalized to [0,1]
            ssim_val = ssim(slice_rec, slice_gt, data_range=1.0, 
                            win_size=11, sigma=1.5)
            ssim_scores.append(ssim_val)
        
        results[view_name] = {
            'mean_psnr': np.mean(psnr_scores),
            'mean_ssim': np.mean(ssim_scores)
        }
        
    return results
```

## Subtopics

### [Mesh Reconstruction Evaluation](2909-mesh-reconstruction-evaluation.md)
Quantifies geometric fidelity of triangular meshes against ground truth, focusing on spatial accuracy rather than photometric error.

### [Normal Consistency](3050-normal-consistency.md)
Measures angular deviation between estimated and ground truth surface normals, evaluating orientation fidelity.

### [Standard Rendering Metrics](3473-standard-rendering-metrics.md)
Provides objective numerical assessment of image fidelity for novel view synthesis, primarily using PSNR as a baseline.

## Operating characteristics
- **Time Complexity**: $O(V)$ where $V$ is the total number of voxels, as each voxel is processed once per view direction (constant factor of 3).
- **Memory Complexity**: $O(V)$ to store the volumes; intermediate slice processing is $O(S)$ where $S$ is slice size.
- **Strengths**: Computationally cheap; provides a standardized baseline for volumetric quality [S1, unofficial].
- **Limitations**: Insensitive to perceptual quality; high PSNR does not guarantee visual fidelity [S6, unofficial].
- **When to Use**: Initial quality assessment of volumetric reconstructions; ablation studies comparing reconstruction methods [S1, unofficial].
- **When Not to Use**: When perceptual quality is the primary concern; when surface geometry is the target metric [S1, unofficial].

## Background
Originated in the context of evaluating 3D Gaussian Splatting for microscopy and scientific data visualization [S1, unofficial]. The method was formalized to provide scalable interactive web visualization of multidimensional scientific data, requiring robust volumetric evaluation metrics [S1, unofficial]. It builds on standard 2D image metrics (PSNR, SSIM) but extends them to 3D volumes by aggregating results across orthogonal slices [S2, unofficial].
