# SSIM Metric Calculation

Also called: Similarité Structurelle, Structural Similarity, Structural Similarity Index, Structural Similarity Index Measure, coefficient de Similarité Structurelle

## Overview

SSIM is a full-reference quality assessment metric that evaluates the perceptual fidelity of a rendered image by comparing local structural information (luminance, contrast, and geometry) against a ground-truth image [S1][S2, unofficial][S4][S6, unofficial]. Unlike MSE, which measures pixel-wise error, SSIM models the human visual system's adaptation to structured natural scene information, providing a score correlated with perceived image distortion [S4][S6, unofficial]. It is widely used to evaluate the quality of 3D reconstructions and novel 2D views in differentiable volume rendering [S3, unofficial][S4].

## How it works

**Inputs and Outputs:**
- Input: Two images (or patches), $I$ (ground truth) and $J$ (prediction/rendered), typically with shape $(C, H, W)$ or $(N, C, H, W)$.
- Output: A scalar SSIM score in the range $[-1, 1]$, where 1 indicates identical images [S7, S10, unofficial].

**Data Structures:**
- **Gaussian Window ($W$):** A 2D tensor of size $K \times K$ (typically $11 \times 11$) containing normalized weights from a circular symmetric Gaussian distribution with standard deviation $\sigma = 1.5$ [S1, S4][S7, S9, unofficial]. The weights sum to 1 [S4].
- **Constants:** $C_1$ and $C_2$ for numerical stability.

**Parameters:**
- **Window Size ($K$):** Typically 11 [S1, S4][S7, S9, unofficial].
- **Sigma ($\sigma$):** 1.5 for the Gaussian kernel [S1, S4][S7, S9, unofficial].
- **Stability Constants:**
  - $K_1 = 0.01$, $K_2 = 0.03$ [S1, S4].
  - $L$ is the dynamic range of pixel values. For normalized RGB values in $[0, 1]$, $L=1$ [S4]. For 8-bit integers, $L=255$ [S1].
  - $C_1 = (K_1 L)^2$ [S1, S4, S5].
  - $C_2 = (K_2 L)^2$ [S1, S4, S5].
  - Note: Some implementations use fixed values $C_1 = 0.01^2$ and $C_2 = 0.03^2$ directly, assuming $L=1$ [S7, S9, unofficial].

**Steps:**

1.  **Initialize Gaussian Window:**
    Create a 2D Gaussian kernel $W$ of size $K \times K$ with $\sigma=1.5$. Normalize $W$ such that $\sum_{i,j} W_{i,j} = 1$ [S1, S4][S9, unofficial].

2.  **Compute Local Means:**
    Compute the local mean for each channel of $I$ and $J$ by convolving with $W$.
    $$ \mu_I = I * W $$
    $$ \mu_J = J * W $$
    Padding must be applied to maintain spatial dimensions (e.g., `padding = K // 2`) [S9, unofficial].

3.  **Compute Local Variances and Covariance:**
    First, compute the squared means and cross-mean:
    $$ \mu_{I}^2 = \mu_I \cdot \mu_I $$
    $$ \mu_{J}^2 = \mu_J \cdot \mu_J $$
    $$ \mu_{IJ} = \mu_I \cdot \mu_J $$
    
    Then, compute the local variances and covariance using the identity $\text{Var}(X) = E[X^2] - (E[X])^2$:
    $$ \sigma_I^2 = (I^2 * W) - \mu_{I}^2 $$
    $$ \sigma_J^2 = (J^2 * W) - \mu_{J}^2 $$
    $$ \sigma_{IJ} = (I \cdot J * W) - \mu_{IJ} $$
    Here, $*$ denotes 2D convolution and $\cdot$ denotes element-wise multiplication [S9, unofficial].

4.  **Calculate Per-Pixel SSIM:**
    Apply the SSIM formula for each pixel location:
    $$ \text{SSIM}(x, y) = \frac{(2\mu_I(x,y)\mu_J(x,y) + C_1)(2\sigma_{IJ}(x,y) + C_2)}{(\mu_I(x,y)^2 + \mu_J(x,y)^2 + C_1)(\sigma_I(x,y)^2 + \sigma_J(x,y)^2 + C_2)} $$
    where $C_1$ and $C_2$ are the stability constants defined above [S1, S4][S7, S9, unofficial].

5.  **Compute Mean SSIM (MSSIM):**
    Average the per-pixel SSIM values over all pixels and channels to obtain the final metric [S4][S9, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn.functional as F

def gaussian_kernel_2d(kernel_size: int, sigma: float) -> torch.Tensor:
    """Create a 2D Gaussian kernel."""
    coords = torch.arange(kernel_size, dtype=torch.float32)
    coords -= (kernel_size - 1) / 2.0
    
    g = coords ** 2
    g = torch.exp(-g / (2 * sigma ** 2))
    g = g / g.sum()
    
    # Outer product to create 2D kernel
    kernel_2d = torch.outer(g, g)
    return kernel_2d

def ssim_metric(I: torch.Tensor, J: torch.Tensor, window_size: int = 11, sigma: float = 1.5, L: float = 1.0) -> torch.Tensor:
    """
    Compute Structural Similarity Index.
    
    Args:
        I: Ground truth image tensor, shape (N, C, H, W) or (C, H, W).
        J: Predicted image tensor, same shape as I.
        window_size: Size of the Gaussian window.
        sigma: Standard deviation for Gaussian window.
        L: Dynamic range of pixel values (1 for [0,1], 255 for uint8).
        
    Returns:
        Scalar SSIM score.
    """
    # Ensure 4D input (N, C, H, W)
    if I.dim() == 3:
        I = I.unsqueeze(0)
        J = J.unsqueeze(0)
        
    N, C, H, W = I.shape
    device = I.device
    
    # 1. Create Gaussian Window
    # Shape: (1, 1, K, K)
    kernel_1d = gaussian_kernel_1d(window_size, sigma)
    kernel_2d = torch.outer(kernel_1d, kernel_1d).unsqueeze(0).unsqueeze(0)
    
    # Repeat for channels if necessary, or use groups in conv
    # Standard implementation often repeats the kernel for each channel or uses groups=C
    kernel = kernel_2d.repeat(C, 1, 1, 1)
    
    # 2. Compute Local Means
    # Convolution with padding to keep size
    mu_I = F.conv2d(I, kernel, padding=window_size // 2, groups=C)
    mu_J = F.conv2d(J, kernel, padding=window_size // 2, groups=C)
    
    # 3. Compute Squared Means and Cross Mean
    mu_I_sq = mu_I ** 2
    mu_J_sq = mu_J ** 2
    mu_IJ = mu_I * mu_J
    
    # 4. Compute Variances and Covariance
    # E[X^2] - (E[X])^2
    sigma_I_sq = F.conv2d(I ** 2, kernel, padding=window_size // 2, groups=C) - mu_I_sq
    sigma_J_sq = F.conv2d(J ** 2, kernel, padding=window_size // 2, groups=C) - mu_J_sq
    sigma_IJ = F.conv2d(I * J, kernel, padding=window_size // 2, groups=C) - mu_IJ
    
    # 5. Define Constants
    C1 = (0.01 * L) ** 2
    C2 = (0.03 * L) ** 2
    
    # 6. Calculate SSIM Map
    num = (2 * mu_I * mu_J + C1) * (2 * sigma_IJ + C2)
    den = (mu_I_sq + mu_J_sq + C1) * (sigma_I_sq + sigma_J_sq + C2)
    
    ssim_map = num / den
    
    # 7. Return Mean SSIM
    # Average over all pixels and channels
    return ssim_map.mean()

def gaussian_kernel_1d(kernel_size: int, sigma: float) -> torch.Tensor:
    """Helper to create 1D Gaussian kernel."""
    coords = torch.arange(kernel_size, dtype=torch.float32)
    coords -= (kernel_size - 1) / 2.0
    g = coords ** 2
    g = torch.exp(-g / (2 * sigma ** 2))
    g = g / g.sum()
    return g
```

**Edge Cases and Pitfalls:**
- **Input Shape:** Input tensors must be 4D with shape $(N, C, H, W)$ for standard convolution-based implementations [S7, S9, unofficial]. Mismatched shapes between render and GT raise errors [S9, unofficial].
- **Numerical Stability:** The constants $C_1$ and $C_2$ prevent division by zero when local variances or means are near zero [S1][S2, unofficial][S5, S8].
- **Boundary Effects:** Convolution padding affects the edges of the image. Consistent padding (e.g., `same` padding) is required to maintain spatial alignment [S9, unofficial].
- **Dynamic Range:** The value of $L$ must match the pixel value range. Using $L=1$ for normalized floats is standard in neural rendering [S4], while $L=255$ is used for 8-bit images [S1].

## Subtopics

### [Accelerated SH and Differentiable Loss Computation](4475-accelerated-sh-and-differentiable-loss-computation.md)
This method optimizes the training loop of 3D Gaussian Splatting (3DGS) by reducing the computational bottleneck of Adam optimizer updates for Spherical Harmonic (SH) coefficients and accelerating differentiable SSIM loss computation. It sets itself apart from standard 3DGS implementations by decoupling SH band updates into separate tensors and fusing loss kernel operations.

### [3D Distance-Aware SSIM](13360-3d-distance-aware-ssim.md)
3D Distance-Aware SSIM is a regularization loss used in differentiable volume rendering (specifically 3D Gaussian Splatting) to mitigate invalid structural similarity penalties between adjacent pixels in 2D image space that originate from different viewpoints. It sets itself apart from standard SSIM by computing the structural similarity metric in 3D world space rather than 2D image space, ensuring that pixels adjacent in the image but distant in 3D space do not force structural similarity.

### SSIM Window Initialization
Creates and caches a 2D Gaussian window for SSIM loss computation to avoid recomputing the kernel in every training step [S11, S11, unofficial]. The window size is typically $11 \times 11$ with a sigma of 1.5 [S11, S11, unofficial].

### GMSD Metric Calculation
GMSD (Gradient Magnitude Similarity Deviation) evaluates the deviation in gradient magnitude between the original and reconstructed images [S12, S12]. It is effective in evaluating the preservation of edges and fine details, particularly in regions with high spatial variability [S12, S12].

### Reverse SSIM (R-SSIM)
A metric proposed to provide a more intuitive representation of image quality differences in AMR data visualization contexts where standard SSIM values are too close to distinguish between error configurations [S13, S13]. It is defined as $R\text{-}SSIM = 1 - SSIM$ [S13, S13]. R-SSIM is more intuitive than SSIM for AMR data because the relative SSIM difference between different error configurations is too small (e.g., 0.999,999,8 for $eb=1E-4$ vs 0.999,60 for $eb=1E-2$), whereas R-SSIM accurately reflects differences across cases [S13, S13].

## Operating characteristics

- **Time Complexity:** $O(K^2 \cdot H \cdot W \cdot C)$ per image, where $K$ is the window size, $H, W$ are image dimensions, and $C$ is the number of channels. The convolution operation dominates the cost [S4][S9, unofficial].
- **Memory Complexity:** $O(H \cdot W \cdot C)$ to store the intermediate mean, variance, and covariance maps [S9, unofficial].
- **Measured Performance:** SSIM values for different reconstruction methods vary significantly. For example, in tomographic reconstruction, Filtered Back Projection (Retroprojection) achieved an SSIM of 0.242, while Fourier Reconstruction achieved 0.600 [S10, S10, unofficial]. In neural rendering benchmarks, SSIM scores often target values above 0.95 for high-quality reconstructions [S7, S7, unofficial].
- **Strengths:** Correlates well with human visual perception [S4][S6, unofficial]. Captures structural information (luminance, contrast, geometry) better than MSE [S2, unofficial][S4].
- **Limitations:** Computationally more expensive than MSE [S6, unofficial]. Sensitive to misalignment and geometric distortions [S10, S10, unofficial]. Standard SSIM can penalize adjacent pixels in 2D space that correspond to distant points in 3D space, which is a limitation in volume rendering [S1, S1].
- **When to Use:** When perceptual quality is more important than pixel-wise accuracy. When evaluating novel view synthesis in 3D reconstruction [S3, unofficial][S4].
- **When Not to Use:** When computational efficiency is critical and MSE is sufficient. When comparing images with significant geometric misalignment that is not perceptually relevant [S10, S10, unofficial].

## Background

SSIM was proposed by Wang et al. in 2004 [S6, S7, unofficial][S8]. It was designed to address the limitations of MSE and PSNR by modeling the human visual system's sensitivity to structural information [S6, unofficial][S8]. The metric assumes that the human visual system is highly adapted to structured natural scene information and measures how this structure changes to approximate perceived distortion [S6, unofficial]. It has become a standard benchmark for image quality in various fields, including tomographic reconstruction [S10, S10, unofficial] and neural rendering [S3, unofficial][S4][S7, unofficial].
