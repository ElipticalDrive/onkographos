# Minkowski's Metric
Also called: Lgamma Loss, Lp Norm Loss

## Overview
Minkowski's Metric is a full-reference mathematical distance measure that treats an image as a 2D signal to calculate the dissimilarity between a reference image $x$ and a test image $y$ [S1, unofficial]. It defines a family of distance metrics parameterized by an exponent $\gamma$ [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Reference image $x$, Test image $y$, Exponent $\gamma \in [1, \infty)$ [G].
- Output: Scalar distance $E_{\gamma}$ [G].

**Data Structures:**
- Images are treated as sets of $N$ samples, where $N$ is the total number of samples in the image [S1, unofficial].
- Samples $x_i, y_i$ are the scalar intensity values at index $i$ [G].

**Formula:**
$$E_{\gamma} = \left( \frac{1}{N} \sum_{i=1}^N |x_i - y_i|^{\gamma} \right)^{\frac{1}{\gamma}}$$

Where:
- $N$: Total number of samples in the image [S1, unofficial].
- $x_i$: Intensity of the $i$-th sample in the reference image [G].
- $y_i$: Intensity of the $i$-th sample in the test image [G].
- $\gamma$: The Minkowski order parameter [S1, unofficial].

**Parameters:**
- $\gamma$: The source specifies the range $\gamma \in [1, \infty)$ [S1, unofficial].

**Pseudocode:**
```python
def minkowski_metric(reference: list[float], test: list[float], gamma: float) -> float:
    """
    Computes the Minkowski distance between two image representations.
    
    Args:
        reference: Flattened list of pixel values for the reference image.
        test: Flattened list of pixel values for the test image.
        gamma: The exponent parameter (>= 1).
        
    Returns:
        The Minkowski distance E_gamma.
    """
    if len(reference) != len(test):
        raise ValueError("Reference and test images must have the same number of samples.")
    if gamma < 1:
        raise ValueError("Gamma must be >= 1.")
        
    n = len(reference)
    sum_diff_gamma = 0.0
    
    for i in range(n):
        diff = reference[i] - test[i]
        sum_diff_gamma += abs(diff) ** gamma
        
    mean_diff_gamma = sum_diff_gamma / n
    distance = mean_diff_gamma ** (1.0 / gamma)
    
    return distance
```

## Subtopics

### Mean Square Error (MSE)
MSE is a specific case of Minkowski's metric where $\gamma=2$, ignoring the square root [S1, unofficial].
**Formula:**
$$E_2 = \left( \frac{1}{N} \sum_{i=1}^N |x_i - y_i|^2 \right)^{\frac{1}{2}} = \sqrt{MSE}$$
Here, $E_2$ represents the metric value for $\gamma=2$, and $MSE$ is the standard Mean Squared Error [S1, unofficial]. The source notes that MSE is the most commonly used mathematical distortion measure, though it correlates poorly with human perception [S1, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
- Time: $O(N)$, where $N$ is the number of samples [G].
- Memory: $O(1)$ auxiliary space if computed in a streaming fashion, or $O(N)$ if storing the full difference tensor [G].

**Strengths and Limitations:**
- Mathematical metrics like Minkowski's are highly objective but correlate very poorly with human perception because they do not account for the Human Visual System's characteristics [S1, unofficial].

## Background
Minkowski's metric is a generalization of the Minkowski distance from mathematics, applied here to image processing as a full-reference metric [S1, unofficial]. The source cites Eskicioglu for a list of other mathematical distortion measures (e.g., PSNR, peak MSE, laplacian MSE) and Girod for demonstrating their poor correlation with human perception [S1, unofficial].
