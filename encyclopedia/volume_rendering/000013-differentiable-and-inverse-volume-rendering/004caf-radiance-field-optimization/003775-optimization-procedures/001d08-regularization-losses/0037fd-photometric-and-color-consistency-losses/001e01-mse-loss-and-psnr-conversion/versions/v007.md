# MSE Loss and PSNR Conversion

Also called: Masked MSE and PSNR Computation, Masked Volume MSE/PSNR Computation, Mean Squared Error (MSE) Calculation, Mean Squared Error Loss, Photometric Loss Computation, img2mse

## Overview
This method computes the Mean Squared Error (MSE) between predicted and target RGB values (or volume voxels) to serve as the primary photometric loss for training neural volume rendering models, and converts this error into Peak Signal-to-Noise Ratio (PSNR) for logging and evaluation [S1, unofficial][S2, unofficial][S3, unofficial]. It differs from structural metrics like SSIM by treating all pixel errors equally without accounting for luminance or contrast correlations [S2, unofficial], and from perceptual losses by operating directly on raw pixel intensities rather than feature spaces [S2000-perceptual-loss-training.md]. It is the standard baseline loss for optimizing radiance fields [S3, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Predicted RGB color tensor $\hat{C}$ (shape $[N, 3]$ or volume equivalent) and Target RGB tensor $C_{gt}$ (shape $[N, 3]$ or volume equivalent). Optional: A binary mask $M$ indicating valid voxels/pixels.
*   **Outputs:** Scalar MSE loss value, PSNR value (for logging), and optionally the count of valid elements.

**Data Structures:**
*   **Tensors:** $\hat{C}$ and $C_{gt}$ are typically floating-point tensors in the range $[0, 1]$ or $[0, 255]$. Consistency in range is critical; if the target is $[0, 255]$ and prediction is $[0, 1]$, the target must be normalized or the prediction scaled before computation [S2, unofficial].
*   **Mask:** A boolean tensor $M$ of the same spatial dimensions as the input, where $M_{i,j} = 1$ if the pixel/voxel is valid, $0$ otherwise.

**Steps:**

1.  **Compute Squared Error:** Calculate the element-wise squared difference between the predicted and target values.
    $$
    E_i = (\hat{C}_i - C_{gt, i})^2
    $$
    where $i$ indexes over all pixels or voxels.

2.  **Apply Mask (Optional):** If a mask $M$ is provided, zero out errors for invalid regions.
    $$
    E'_i = E_i \cdot M_i
    $$
    If no mask is used, $E'_i = E_i$.

3.  **Compute Mean Squared Error (MSE):** Average the squared errors over the valid elements. Let $N$ be the number of valid elements (where $M_i=1$ or all elements if unmasked).
    $$
    MSE = \frac{1}{N} \sum_{i=1}^{N} E'_i
    $$
    [S1, unofficial][S4, unofficial]

4.  **Compute PSNR:** Convert MSE to PSNR. If $MSE > 0$:
    $$
    PSNR = 20 \cdot \log_{10}\left(\frac{1}{\sqrt{MSE}}\right) = -10 \cdot \log_{10}(MSE)
    $$
    [S1, unofficial][S4, unofficial]
    If $MSE = 0$, $PSNR = \infty$. [S4, unofficial]

**Parameters:**
*   **Data Range:** The maximum possible pixel value ($max\_val$). If inputs are normalized to $[0, 1]$, $max\_val = 1$. If inputs are in $[0, 255]$, $max\_val = 255$. The standard formula assumes $max\_val=1$ when using the $-10 \log_{10}(MSE)$ form derived from $20 \log_{10}(max\_val / \sqrt{MSE})$ with normalized inputs. [S1, unofficial][S4, unofficial]
*   **Mask Threshold (for volume masks):** In volume rendering, a relative threshold `mask_threshold_rel` (default 0.01) is often applied to a normalized mask volume to create the boolean mask: $threshold = mask\_threshold\_rel \cdot \max(mask\_volume)$. [S4, unofficial]

**Pseudocode:**

```python
import math
import numpy as np

def compute_mse_and_psnr(predicted: np.ndarray, target: np.ndarray, mask: np.ndarray = None) -> dict:
    """
    Computes MSE and PSNR between predicted and target arrays.
    
    Args:
        predicted: Array of predicted values (e.g., RGB colors).
        target: Array of ground truth values.
        mask: Optional boolean array indicating valid regions.
        
    Returns:
        Dictionary with 'mse', 'psnr', and 'valid_count'.
    """
    # Ensure same shape and dtype
    assert predicted.shape == target.shape, "Predicted and target must have the same shape"
    
    # Compute squared error
    squared_error = (predicted - target) ** 2
    
    if mask is not None:
        # Apply mask
        masked_squared_error = squared_error * mask
        valid_count = int(np.sum(mask))
        
        if valid_count == 0:
            raise RuntimeError("Mask has no true values (empty region).")
            
        mse = float(np.mean(masked_squared_error))
    else:
        # No mask: use all elements
        valid_count = int(np.prod(predicted.shape))
        mse = float(np.mean(squared_error))
        
    # Compute PSNR
    if mse > 0.0:
        psnr = 20.0 * math.log10(1.0 / math.sqrt(mse))
    else:
        psnr = float('inf')
        
    return {
        'mse': mse,
        'psnr': psnr,
        'valid_count': valid_count
    }
```

**Edge Cases and Pitfalls:**
*   **Division by Zero:** If $MSE = 0$, $\log_{10}(0)$ is undefined. The PSNR is set to infinity ($\infty$) to avoid numerical errors. [S4, unofficial]
*   **Empty Mask:** If a mask is provided but contains no `True` values, the method should raise an error or handle it gracefully, as division by zero would occur in the mean calculation. [S4, unofficial]
*   **Data Range Mismatch:** If the target images are in $[0, 255]$ and predictions are in $[0, 1]$, the MSE will be artificially large. Ensure both tensors are in the same range (typically $[0, 1]$) before computation. [S2, unofficial]
*   **Precision:** For very small MSE values, PSNR can become very large. Use float32 or float64 appropriately to avoid overflow in log calculations. [G]

## Subtopics

### [PSNR Metric Calculation](2742-psnr-metric-calculation.md)
Peak Signal-to-Noise Ratio (PSNR) evaluates the quality of reconstructed images in novel view synthesis and volume rendering by comparing rendered output against ground-truth reference images. It quantifies the logarithmic ratio between the maximum possible pixel intensity and the Mean Squared Error (MSE) between the two images, providing a single scalar value where higher indicates better fidelity. Unlike structural metrics such as SSIM, PSNR measures pixel-level photometric error averaged over the entire frame, making it sensitive to large smooth regions but less responsive to small, high-frequency details like specular highlights.

### [SSIM Metric Calculation](3650-ssim-metric-calculation.md)
The Structural Similarity Index (SSIM) measures the perceived distortion between a rendered image and a ground truth image by comparing local patterns of pixel intensities, assuming the human visual system is highly adapted to structured natural scene information. It serves as a standard benchmark for image quality in radiance-field optimization, complementing pixel-wise metrics like MSE and PSNR. Unlike MSE, which treats all errors equally, SSIM accounts for luminance, contrast, and structural correlations, providing a value between -1 and 1 where 1 indicates identical images.

### [Normal-L2 Score Computation](3842-normal-l2-score-computation.md)
The Normal-L2 score evaluates surface geometry by computing the mean squared L2 distance between predicted surface normals and reference normals from a ground-truth mesh. It is computed only on the intersection of predicted and ground-truth masks, distinguishing it from silhouette metrics like iIoU which evaluate mask alignment separately.

### [Minkowski's Metric](4347-minkowski-s-metric.md)
Minkowski's Metric is a full-reference mathematical distance measure that treats images as 2D signals to quantify dissimilarity between a reference image $x$ and a test image $y$. It generalizes the Mean Squared Error (MSE) by allowing the exponent $\gamma$ to vary, thereby controlling the sensitivity to large errors versus small errors. Unlike its sibling [PSNR Metric Calculation](2742-psnr-metric-calculation.md) which is a logarithmic transformation of MSE, or [SSIM Metric Calculation](3650-ssim-metric-calculation.md) which models structural information, Minkowski's Metric operates directly on pixel-wise intensity differences.

### Masked Volume Metrics
A method to exclude empty froxels from evaluation metrics by including only froxels affected by radiance [S6, unofficial]. A froxel is included if any of its RGB channels contain a non-zero value at any point during the test scenario [S6, unofficial]. The Region of Interest (ROI) is computed separately for each tested algorithm, and the union of the scenario's ROI and the ground truth's ROI is used: $ROI_{effective} = ROI_{scenario} \cup ROI_{truth}$ [S6, unofficial]. This ensures that only relevant froxels are included for each output while excluding completely empty regions [S6, unofficial].

### MSE Bias-Variance Decomposition
Treating the TAA algorithm as a biased estimator to analyze correctness using Mean Squared Error (MSE), decomposed into variance and bias squared [S6, unofficial]. The formula is $MSE[F] = E[(F - G)^2] = V[F] + \beta[F]^2$, where $F$ is the output of the estimator, $G$ is the true value (ground truth), $V[F]$ is the variance of the estimator, and $\beta[F]$ is its bias [S6, unofficial].

### Training Loss Computation with Huber and Masking
An extension that uses Huber loss instead of MSE for RGB, masked by ray validity [S7, unofficial]. It renders predicted RGB and depth, blends ground truth RGB with background, and computes per-ray Huber loss with delta=0.1, averaged over valid rays [S7, unofficial].

### Area Loss Scaling
Scaling the loss of each pixel by the area of that pixel's footprint in the original image to ensure low-resolution pixels have comparable influence to high-resolution pixels in multiscale datasets [S8]. For a downsampling factor of $k$, the area factor is $k^2$ [S8].

## Operating characteristics
*   **Time Complexity:** $O(N)$, where $N$ is the number of pixels or voxels. The computation involves a single pass to compute squared differences and a mean reduction.
*   **Memory Complexity:** $O(N)$ to store the squared error tensor, or $O(1)$ if computed incrementally.
*   **Strengths:** Simple to implement, differentiable everywhere, computationally efficient, and widely used as a baseline for comparing other loss functions.
*   **Limitations:** Does not account for structural information or perceptual quality, often leading to blurry results in high-frequency regions compared to perceptual or structural losses. Sensitive to outliers due to the squared term.
*   **When to Use:** As a primary loss for initial training, for datasets with high-quality ground truth, or as a component in a composite loss function.
*   **When Not to Use:** When structural fidelity is more important than pixel-wise accuracy, or when the dataset contains significant noise/outliers that could skew the loss.

## Background
The Mean Squared Error (MSE) loss is a fundamental metric in image processing and computer vision, originating from statistical estimation theory [S1, unofficial]. In the context of neural volume rendering, it was popularized by the NeRF paper [S1, unofficial] as the primary photometric loss for optimizing radiance fields. The conversion to PSNR for evaluation is a standard practice in image quality assessment [S4, unofficial]. Variants like masked MSE for volume rendering have been developed to handle sparse or incomplete data [S4, unofficial].
