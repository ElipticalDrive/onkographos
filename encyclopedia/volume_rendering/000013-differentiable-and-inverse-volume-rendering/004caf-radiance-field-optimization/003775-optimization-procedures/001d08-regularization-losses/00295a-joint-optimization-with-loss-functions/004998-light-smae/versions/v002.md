# Light-SMAE

Also called: Smooth Manifold Auto-Encoder

## Overview
Light-SMAE is a smooth manifold auto-encoder that learns a low-dimensional, differentiable latent representation of high-dynamic-range (HDR) environment maps, serving as a strong regularizer or prior for reflectance decomposition and inverse rendering [S1, unofficial]. It sets itself apart from direct optimization of lighting parameters by constraining the solution space to a smooth manifold learned from data, which enables stable gradient-based optimization of illumination in ill-posed inverse problems [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** An HDR environment map $p$, downscaled to $128 \times 256$ resolution [S1, unofficial].
*   **Output:** A 128-dimensional latent embedding $z_l \in \mathbb{R}^{128}$ (via Encoder) or a reconstructed HDR environment map $\hat{p}_0$ (via Decoder) [S1, unofficial].

**Data Structures:**
The architecture consists of an Encoder $E$, a Decoder $G$, and a Discriminator $D$, all based on Convolutional Neural Networks (CNNs) utilizing CoordConv layers [S1, unofficial].
*   **CoordConv Layer:** A 2D convolution where the input tensor is augmented with coordinate channels (x, y) before convolution [G].
*   **Conv Layer:** Standard 2D convolution [G].
*   **ConvT Layer:** Transposed 2D convolution (upsampling) [G].

**Network Architecture (Light-SMAE):**
The specific layer configurations are defined in the source [S1, unofficial].
*   **Encoder $E$:**
    1.  CoordConv: Kernel $3 \times 3$, Stride 1, 8 features, Activation ELU.
    2.  ConvT: Kernel $1 \times 1$, Stride 1, 64 features, Activation ELU.
    3.  CoordConv: Kernel $3 \times 3$, Stride 1, 8 features, Activation ReLU.
    *   *Padding:* No padding [S1, unofficial].
*   **Decoder $G$:**
    1.  CoordConv: Kernel $3 \times 3$, Stride 1, 8 features, Activation ELU.
    2.  CoordConv: Kernel $4 \times 4$, Stride 2, 21 features, Activation ELU.
    3.  ConvT: Kernel $4 \times 4$, Stride 2, 58 features, Activation ELU.
    4.  Final Output Layer: Conv $1 \times 1$, Stride 1, 3 features (RGB), Activation $\exp(x - 1)$.
    *   *Padding:* Uses 'same' padding [S1, unofficial].
*   **Discriminator $D$:**
    1.  CoordConv: Kernel $3 \times 3$, Stride 1, 8 features, Activation ELU.
    2.  Conv: Kernel $4 \times 4$, Stride 2, 21 features, Activation ELU.
    *   *Padding:* No padding [S1, unofficial].

**Training Procedure:**
The network is trained jointly to minimize a composite loss function [S1, unofficial].
1.  **Data Preprocessing:** Rotate each of the 320 environment maps 10 times. Randomly blend two environment maps during training. Downscale inputs to $128 \times 256$. Transform HDR input $x$ to LDR for encoder: $x_{ldr} = \log(1 + x)$ [S1, unofficial].
2.  **Forward Pass (Encoding):** Pass $x_{ldr}$ through Encoder $E$ to get latent vector $z$ [S1, unofficial].
3.  **Forward Pass (Decoding & Reconstruction):** Pass $z$ through Decoder $G$ to get reconstruction $\hat{p}_{ldr}$. Transform LDR output to HDR: $\hat{p}_{hdr} = \exp(\hat{p}_{ldr} - 1)$ [S1, unofficial].
4.  **Latent Interpolation:** Randomly sample two latent vectors from the mini-batch: $z_a$ and $z_b$. Sample $m$ linearly interpolated embeddings uniformly spaced between $z_a$ and $z_b$: $z_n^0 = (1 - \alpha_n) z_a + \alpha_n z_b$ for $n = 1, \dots, m$. Parameter: $m = 5$ interpolation steps between each of the batch halves [S1, unofficial].
5.  **Forward Pass (Interpolated Reconstruction and Re-encoding):** Pass each $z_n^0$ through Decoder $G$ to obtain $\hat{p}_n^0$. Pass each $\hat{p}_n^0$ (transformed to LDR) through Encoder $E$ to obtain re-estimated latents $\hat{z}_n^0$ [S1, unofficial].
6.  **Loss Calculation:** The total loss $L$ is a weighted sum of four components [S1, unofficial]:
    $$ L = L_r + \lambda_1 L_a + \lambda_2 L_c + \lambda_3 L_s $$
    *   **Reconstruction Loss ($L_r$):** Calculated using the Mean Absolute Log Error (MALE) between the ground truth HDR $x^*$ and the predicted HDR $\hat{x}$ [S1, unofficial]:
        $$ L_r = |\log(1 + x^*) - \log(1 + \hat{x})| $$
    *   **Adversarial Loss ($L_a$):** Standard adversarial loss from LSGAN applied to the discriminator $D$ evaluating the interpolated reconstructions $\hat{p}_n^0$ [S1, unofficial].
    *   **Cyclic Loss ($L_c$):** L2-loss between the interpolated latents $\{z_n^0\}$ and their re-estimated counterparts $\{\hat{z}_n^0\}$ [S1, unofficial]:
        $$ L_c = \sum_{n=1}^m \| z_n^0 - \hat{z}_n^0 \|^2 $$
    *   **Smoothness Loss ($L_s$):** Imposed on the gradient of the decoder $G$ with respect to the interpolating scalar value $\alpha$ [S1, unofficial]:
        $$ L_s = \frac{1}{m} \sum_{n=1}^m \left( \nabla_\alpha G(z_n^0) \right)^2 $$
7.  **Optimization:** Update parameters of $E$, $G$, and $D$ using the Adam optimizer [S1, unofficial].

**Parameters:**
*   **Latent Dimension:** $z_l \in \mathbb{R}^{128}$ [S1, unofficial].
*   **Loss Weights:** $\lambda_1 = 0.01$ (Adversarial), $\lambda_2 = 0.0001$ (Cyclic), $\lambda_3 = 0.05$ (Smoothness) [S1, unofficial].
*   **Optimizer:** Adam, learning rate $5 \times 10^{-4}$ [S1, unofficial].
*   **Batch Size:** 24 [S1, unofficial].
*   **Training Steps:** 4 million steps [S1, unofficial].
*   **Hardware:** Single NVIDIA 1080 TI GPU [S1, unofficial].
*   **Training Time:** Approximately 5 days [S1, unofficial].

**Pseudocode:**
```python
def hdr_to_ldr(x):
    return log(1 + x)

def ldr_to_hdr(x):
    return exp(x - 1)

def compute_smoothness_loss(decoder, z_a, z_b, m):
    loss = 0.0
    for i in range(1, m + 1):
        alpha = i / (m + 1)
        z_interp = z_a + alpha * (z_b - z_a)
        z_interp.requires_grad = True
        recon = decoder(z_interp)
        grad = gradient(recon.sum(), z_interp)
        dz_dalpha = z_b - z_a
        grad_alpha = sum(grad * dz_dalpha)
        loss += grad_alpha ** 2
    return loss / m

def compute_cyclic_loss(encoder, decoder, z_a, z_b, m):
    loss = 0.0
    for i in range(1, m + 1):
        alpha = i / (m + 1)
        z_interp = z_a + alpha * (z_b - z_a)
        ldr_recon = decoder(z_interp)
        hdr_recon = ldr_to_hdr(ldr_recon)
        ldr_recon_enc = hdr_to_ldr(hdr_recon)
        z_re_est = encoder(ldr_recon_enc)
        loss += norm(z_interp - z_re_est) ** 2
    return loss / m

def train_step(encoder, decoder, discriminator, batch, lambda_a, lambda_c, lambda_s, m):
    ldr_input = hdr_to_ldr(batch)
    z = encoder(ldr_input)
    ldr_recon = decoder(z)
    hdr_recon = ldr_to_hdr(ldr_recon)
    
    loss_r = mean(abs(hdr_to_ldr(batch) - hdr_to_ldr(hdr_recon)))
    
    z_a, z_b = z[0], z[1]
    loss_c = compute_cyclic_loss(encoder, decoder, z_a, z_b, m)
    loss_s = compute_smoothness_loss(decoder, z_a, z_b, m)
    
    # Adversarial loss (LSGAN) on interpolated reconstructions [G]
    loss_a = 0.0 
    
    loss = loss_r + lambda_a * loss_a + lambda_c * loss_c + lambda_s * loss_s
    return loss
```

## Operating characteristics
*   **Time Complexity:** Training requires 4 million steps. On a single NVIDIA 1080 TI GPU, this takes approximately 5 days [S1, unofficial].
*   **Memory Complexity:** The latent space is 128-dimensional, which is significantly smaller than the $128 \times 256 \times 3$ input resolution, reducing memory requirements for storing lighting parameters during optimization [S1, unofficial].
*   **Strengths:** Provides a strong prior for ill-posed inverse problems (reflectance decomposition) [S1, unofficial]. The smoothness of the manifold enables stable gradient-based optimization [S1, unofficial]. Handles HDR data effectively via specific HDR/LDR transformations and MALE loss [S1, unofficial].
*   **Limitations:** Requires pre-training on a dataset of high-quality environment maps (320 maps augmented) [S1, unofficial]. The problem of jointly estimating 3D shape, materials, and lighting is highly underconstrained; the SMAE acts as a necessary regularizer but does not solve the ill-posedness alone [S1, unofficial].
*   **When to use:** When optimizing illumination parameters in inverse rendering or reflectance decomposition tasks where direct optimization is unstable or prone to implausible solutions [G].
*   **When not to use:** When no prior distribution of lighting is available or when real-time inference of lighting from a single image without pre-trained priors is required [G].

## Background
Light-SMAE was introduced in the paper "Neural-PIL: Neural Pre-Integrated Lighting for Reflectance Decomposition" [S1, unofficial]. It is based on the concept of Interpolating Auto-Encoders [5] and is designed to learn low-dimensional smooth manifolds for BRDFs and illuminations. The method was developed to address the ill-posedness of jointly estimating 3D shape, materials, and lighting. The Light-SMAE specifically targets environment maps, mapping them to a 128-dimensional latent space, while a companion BRDF-SMAE maps Cook-Torrance BRDF parameters to a 4D latent space [S1, unofficial]. The networks are pre-trained on datasets of real-world BRDFs [10] and environment maps [61], with the Light-SMAE trained on 320 environment maps augmented by rotations and blending [S1, unofficial].
