# Bayesian Posterior Update for Multiple New Data

Also called: ActiveNeRF posterior distribution derivation, Gaussian posterior update for radiance fields

## Overview
This method computes the posterior distribution of a scene point's color given a Gaussian prior and multiple new observed data points, enabling uncertainty-aware view selection in radiance field optimization [S1]. It sets itself apart from sibling methods by explicitly deriving the closed-form posterior parameters for affine-transformed observations, allowing the system to weigh new views against existing priors based on their specific noise and scaling characteristics [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:**
    *   Prior mean $\bar{c}(\text{x})$ and prior variance $\beta_0^2$ for the scene point color $c(\text{x})$.
    *   $N$ new observations (typically $N=2$ in the base derivation, extendable to $N>2$). For each observation $i \in \{1, \dots, N\}$:
        *   Observed color value $C(\text{r}_i)$.
        *   Affine scale parameter $\alpha_i$.
        *   Affine bias parameter $b_i$.
        *   Observation noise variance $\beta_i^2$.
*   **Outputs:**
    *   Posterior mean $\mu_{\text{post}}$.
    *   Posterior variance $\sigma_{\text{post}}^2$.

**Data Structures**
The method operates on scalar values representing the color channel statistics at a specific spatial location $\text{x}$. No complex data structures are required beyond storing the prior parameters and the list of observation parameters.

**Step-by-Step Derivation and Computation**
1.  **Define the Prior:** Assume the prior distribution of the color $c(\text{x})$ given previous data $D_1$ is Gaussian:
    $$ P^{(\text{pri})} = P(c(\text{x})|D_1) \sim \mathcal{N}(\bar{c}(\text{x}), \beta_0^2) $$
    [S1]

2.  **Define the Likelihoods:** For each new observation $i$, assume the likelihood of observing $C(\text{r}_i)$ given the true color $c(\text{x})$ is Gaussian, modeled with an affine transformation:
    $$ p(\text{r}_i|c(\text{x})) \sim \mathcal{N}(\alpha_i c(\text{x}) + b_i, \beta_i^2) $$
    [S1]
    *Note: The source notation $p(\text{r}_i|\text{x})$ implies the dependence on the scene point $\text{x}$ through the color $c(\text{x})$.*

3.  **Compute Posterior Weights:** For the case of two observations ($i=1, 2$), calculate the weights $\gamma_1, \gamma_2, \gamma_3$. These weights determine the contribution of each observation and the prior to the final posterior mean. The common denominator $D$ is:
    $$ D = \alpha_1^2\beta_0^2\beta_2^2 + \alpha_2^2\beta_0^2\beta_1^2 + \beta_1^2\beta_2^2 $$
    [S1]
    The individual weights are:
    $$ \gamma_1 = \frac{\alpha_1^2\beta_0^2\beta_2^2}{D} $$
    $$ \gamma_2 = \frac{\alpha_2^2\beta_0^2\beta_1^2}{D} $$
    $$ \gamma_3 = \frac{\beta_1^2\beta_2^2}{D} $$
    [S1]
    *Note: The source states that derivations for more inputs are similar, involving analogous substitutions for the weights.*

4.  **Calculate Posterior Mean:** The posterior mean is a weighted sum of the inverse-affine-transformed observations and the prior mean:
    $$ \mu_{\text{post}} = \gamma_1 \frac{C(\text{r}_1)-b_1}{\alpha_1} + \gamma_2 \frac{C(\text{r}_2)-b_2}{\alpha_2} + \gamma_3 \bar{c}(\text{x}) $$
    [S1]

5.  **Calculate Posterior Variance:** The posterior variance is determined solely by the prior variance scaled by the weight $\gamma_3$:
    $$ \sigma_{\text{post}}^2 = \gamma_3 \beta_0^2 $$
    [S1]

6.  **Formulate Posterior:** The resulting posterior distribution is:
    $$ P^{(\text{post})} \sim \mathcal{N}\left( \mu_{\text{post}}, \sigma_{\text{post}}^2 \right) $$
    [S1]

**Pseudocode**
```python
def compute_posterior_update(prior_mean, prior_var, observations):
    """
    Computes the posterior mean and variance for a scene point color
    given a Gaussian prior and multiple affine-transformed observations.
    
    Args:
        prior_mean (float): c_bar(x), the prior mean color.
        prior_var (float): beta_0^2, the prior variance.
        observations (list of dicts): Each dict contains:
            - 'C': float, observed color C(r_i)
            - 'alpha': float, affine scale alpha_i
            - 'b': float, affine bias b_i
            - 'var': float, observation noise variance beta_i^2
            
    Returns:
        (float, float): posterior_mean, posterior_var
    """
    n = len(observations)
    
    # Calculate the common denominator D
    # D = sum_{i=1 to n} (alpha_i^2 * beta_0^2 * product_{j!=i} beta_j^2) + product_{i=1 to n} beta_i^2
    # However, the source provides explicit formulas for N=2. 
    # For general N, the weight gamma_3 is product(beta_i^2) / D.
    # The weight gamma_i is (alpha_i^2 * beta_0^2 * product_{j!=i} beta_j^2) / D.
    
    # To implement for general N without hardcoding N=2, we compute D first.
    # Let P_all = product(beta_i^2 for all i)
    # Let term_i = alpha_i^2 * beta_0^2 * (P_all / beta_i^2)
    # D = sum(term_i for all i) + P_all
    
    P_all = 1.0
    for obs in observations:
        P_all *= obs['var']
        
    D = P_all
    for obs in observations:
        # term_i = alpha_i^2 * beta_0^2 * (product of all other betas^2)
        # product of all other betas^2 = P_all / beta_i^2
        term_i = (obs['alpha'] ** 2) * prior_var * (P_all / obs['var'])
        D += term_i
        
    # Compute Posterior Mean
    posterior_mean = 0.0
    
    # Compute weights and accumulate mean
    # gamma_i = term_i / D
    # gamma_3 = P_all / D
    
    # Contribution from observations
    for obs in observations:
        term_i = (obs['alpha'] ** 2) * prior_var * (P_all / obs['var'])
        gamma_i = term_i / D
        # Inverse affine transform: (C - b) / alpha
        inv_obs = (obs['C'] - obs['b']) / obs['alpha']
        posterior_mean += gamma_i * inv_obs
        
    # Contribution from prior
    gamma_3 = P_all / D
    posterior_mean += gamma_3 * prior_mean
    
    # Compute Posterior Variance
    posterior_var = gamma_3 * prior_var
    
    return posterior_mean, posterior_var
```
[G] The pseudocode generalizes the $N=2$ formulas from the source to arbitrary $N$ by identifying the pattern in the denominator $D$ and the weights $\gamma_i$. The source explicitly provides the $N=2$ case [S1].

**Parameters and Edge Cases**
*   **Parameters:** $\alpha_i$ and $b_i$ are affine parameters derived from the rendering process or calibration. $\beta_i^2$ represents the noise variance of the observation. $\beta_0^2$ is the prior uncertainty.
*   **Edge Cases:**
    *   If $\alpha_i = 0$, the inverse affine transform is undefined. This implies the observation provides no information about the color scale, which should be handled by excluding such observations or setting their weight to zero [G].
    *   If $\beta_i^2 = 0$ for any $i$, the denominator $D$ may become zero if all $\beta$ are zero, or the weight $\gamma_i$ may dominate. In practice, $\beta_i^2$ should be strictly positive to avoid division by zero in the weight calculation or numerical instability [G].
    *   If $\beta_0^2 = 0$, the prior is a Dirac delta. The posterior mean becomes a weighted average of observations only, and the posterior variance becomes 0 if any observation has finite variance, or is determined by the relative weights if all are precise [G].

## Operating characteristics
*   **Time Complexity:** $O(N)$ for computing the product of variances and the denominator, where $N$ is the number of new observations. The calculation is closed-form and very fast.
*   **Memory Complexity:** $O(1)$ auxiliary space, as it only requires storing the prior parameters and the current batch of observation parameters.
*   **Strengths:** Provides an exact analytical solution for Gaussian priors and likelihoods. Efficiently combines multiple views with different noise levels and affine distortions.
*   **Limitations:** Assumes Gaussianity and affine linearity. If the noise is non-Gaussian or the relationship is non-linear, the approximation may be poor. The derivation in the source is explicitly for 2 inputs, though stated to be extendable [S1].

## Background
This method originates from the ActiveNeRF paper, which focuses on learning where to see with uncertainty estimation [S1]. It is used in differentiable volume rendering to select informative views by updating the posterior distribution of scene properties (like color) as new data is acquired. The specific derivation for multiple new data points allows the system to jointly consider multiple new observations rather than updating sequentially, which can be more robust in batch processing scenarios.
