# Uncertainty Loss Parameters
Also called: Uncertainty Loss Weights

## Overview
This method defines the scalar hyperparameters used to balance the components of the uncertainty regularization loss in differentiable volume rendering. It addresses the problem of training neural radiance fields to predict reliable uncertainty estimates by penalizing deviations between predicted uncertainty and observed residuals. It is distinct from the sibling [Uniform and Gaussian Noise Models](5127-uniform-and-gaussian-noise-models.md) by focusing on the optimization weights rather than the noise distribution assumption itself, and builds on [Uncertainty Prediction Loss](2961-uncertainty-prediction-loss.md) by providing the specific coefficients for the loss formulation.

## How it works
The method combines a squared error term ($\mathcal{L}_{SE}$) and a zero-penalty term ($\mathcal{L}_0$) into a total uncertainty loss $\mathcal{L}_{unct}$.

**Inputs and Outputs:**
*   **Input:** Predicted uncertainty values $\delta_{c_i}$ for each sample $i$ along rays $\mathcal{R}$; hyperparameters $\alpha_1, \alpha_2$.
*   **Output:** Scalar loss value $\mathcal{L}_{unct}$ used for gradient backpropagation.

**Data Structures:**
*   $\mathcal{R}$: Set of rays.
*   $N$: Number of samples per ray.
*   $\delta_{c_i}$: Predicted uncertainty scalar for sample $i$.

**Formulas:**
The total loss is defined as [S1]:
$$ \mathcal{L}_{unct} = \alpha_1 \mathcal{L}_{SE} + \alpha_2 \mathcal{L}_0 $$

Where:
$$ \mathcal{L}_{SE} = \sum_{r \in \mathcal{R}} \sum_{i=1}^N \delta_{c_i}^2 $$
$$ \mathcal{L}_0 = \sum_{r \in \mathcal{R}} \sum_{i=1}^N \max(\delta_{c_i}, 0) $$

**Parameters:**
*   $\alpha_1$: Weight for the squared error component. Typical value: $1.0$ [S1].
*   $\alpha_2$: Weight for the zero-penalty component. Typical value: $0.01$ [S1].

**Rationale:**
The unbalanced weights are chosen because accurately predicting the expected error $E(r)$ is as difficult as predicting color directly. A shallow network struggles with accurate $E(r)$ prediction. By setting $\alpha_1 \gg \alpha_2$, the network applies larger penalties when uncertainty is lower than the loss (under-confident) and less punishment when uncertainty is higher than the loss (over-confident), encouraging the network to learn uncertainty effectively [S1].

**Pseudocode:**
```python
def compute_uncertainty_loss_params(delta_c, alpha1=1.0, alpha2=0.01):
    """
    Computes the uncertainty loss using parameters alpha1 and alpha2.
    
    Args:
        delta_c: Tensor of predicted uncertainty values, shape (num_rays, num_samples).
        alpha1: Weight for squared error term.
        alpha2: Weight for zero-penalty term.
        
    Returns:
        Scalar loss value.
    """
    # L_SE: Sum of squared uncertainties
    # Note: Source [S1] defines L_SE implicitly via the context of "squared error" 
    # and the formula structure. Standard interpretation of squared error loss 
    # on uncertainty predictions is sum(delta^2).
    l_se = torch.sum(delta_c ** 2)
    
    # L_0: Sum of max(delta, 0)
    # Source [S1] explicitly defines L_0 = sum(max(delta_ci, 0))
    l_0 = torch.sum(torch.maximum(delta_c, torch.zeros_like(delta_c)))
    
    # Total loss
    l_unct = alpha1 * l_se + alpha2 * l_0
    
    return l_unct
```

## Subtopics

### Pixel-Wise Uncertainty with Volumetric Rendering
This variant computes pixel-wise uncertainties by examining diagonal Hessians along the casted ray for volumetric rendering, leveraging the correspondence between parameters and spatial locations in Radiance Field models [S2]. It defines $G_n$ as the submatrix of the Hessian $H''[w^*|D_{train}]$ containing rows and columns corresponding to parameters at location $n$ [S2]. The uncertainty for a ray $r$ is calculated as [S2]:
$$ U(r) = \sum_{n=1}^{N} T_i (1 - \exp(-\sigma_n \delta_n)) \text{tr}(G_n) $$
This computed uncertainty is relative and derived from observed information on model parameters, not involving metric scales [S2]. To estimate absolute uncertainties (e.g., on depth maps), the uncertainty in each term must be denormalized by its depth $d_n$ [S2].

## Operating characteristics
*   **Complexity:** The parameter calculation itself is $O(1)$ per loss evaluation. The cost lies in computing the underlying loss terms ($\mathcal{L}_{SE}$ and $\mathcal{L}_0$), which are linear in the number of samples.
*   **Strengths:** The specific weighting ($\alpha_1=1.0, \alpha_2=0.01$) helps stabilize training for shallow networks by asymmetrically penalizing under- vs. over-confidence [S1].
*   **Limitations:** The parameters are specific to the Recursive-NeRF architecture and loss formulation [S1]. The relative nature of uncertainty in the Hessian-based variant requires careful denormalization for metric tasks [S2].
*   **When to use:** Use these parameters when implementing the Recursive-NeRF uncertainty regularization. Use the Hessian-based variant when active view selection or mapping is required using Fisher Information [S2].

## Background
The parameters $\alpha_1=1.0$ and $\alpha_2=0.01$ were introduced in Recursive-NeRF [S1] to address the difficulty of training neural networks to predict accurate expected error $E(r)$. The Hessian-based pixel-wise uncertainty method was proposed in FisherRF [S2] for active view selection and mapping, utilizing the Fisher Information matrix derived from the radiance field parameters.
