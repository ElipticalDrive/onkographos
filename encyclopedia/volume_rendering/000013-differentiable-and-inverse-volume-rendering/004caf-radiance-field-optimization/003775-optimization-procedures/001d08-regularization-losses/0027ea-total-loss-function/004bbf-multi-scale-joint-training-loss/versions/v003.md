# Multi-scale Joint Training Loss

Also called: Coarse-Fine Joint Loss, Joint Loss, Multi-scale Joint Loss

## Overview
Multi-scale Joint Training Loss is a composite objective function used in the second round of training for radiance-field optimization methods that employ dynamic network growth or multi-stage refinement. It balances low-frequency structural agreement with high-frequency detail fidelity to refine denoised or coarse inputs into high-quality outputs [S2]. It differs from single-scale losses by explicitly weighting contributions from multiple network stages or resolution levels, ensuring that global appearance is preserved while local textures are sharpened [S1, S2].

## How it works
The method operates on outputs from multiple stages or layers of a growing neural network. It combines losses from coarse (low-frequency) and fine (high-frequency) representations, or aggregates losses across all active stages of the network.

**Inputs and Outputs:**
- **Inputs:** Network parameters $\theta$; output images from $D$ stages/layers; hyperparameters $\alpha, \beta_1, \beta_2$.
- **Outputs:** Scalar loss value $L(\theta)$.

**Data Structures:**
- **Stages ($D$):** The current number of active network stages or layers. In dynamic growth methods, $D$ increases as the network expands [S1].
- **Stage Outputs:** For each stage $i \in \{1, \dots, D\}$, the network produces an output image. All query coordinates are passed through all outlets during training [S1].

**Formulas:**
Two primary formulations are cited in the literature, depending on the specific architecture (multi-stage growth vs. coarse-fine refinement):

1.  **Multi-Stage Aggregation (Recursive-NeRF):**
    $$ \mathcal{L} = \sum_{i=1}^D \left( \beta_1 \mathcal{L}_{MSE}^i + \beta_2 \mathcal{L}_{unct}^i \right) $$
    Where:
    - $D$ is the current number of stages [S1].
    - $\mathcal{L}_{MSE}^i$ is the Mean Squared Error loss for the output image of layer $i$ [S1].
    - $\mathcal{L}_{unct}^i$ is the uncertainty loss for the output image of layer $i$ [S1].
    - $\beta_1$ and $\beta_2$ are weighting hyperparameters [S1].

2.  **Coarse-Fine Balance (Denoise-GS):**
    $$ L(\theta) = \alpha L_{coarse}(\theta) + (1-\alpha) L_{fine}(\theta) $$
    Where:
    - $\alpha \in [0, 1]$ is the balance weight [S2].
    - $L_{coarse}(\theta)$ is the low-frequency consistency term, comparing input and output after smoothing to preserve tone and large-scale structure [S2].
    - $L_{fine}(\theta)$ is the detail consistency term, comprising pixel-level robust distance, structural similarity, gradient consistency, and chroma consistency [S2].

**Parameters:**
- $\beta_1 = 1.0$
- $\beta_2 = 0.1$
- $\alpha$: Not specified in sources, but defined as a value in $[0, 1]$ [S2].

**Pseudocode:**
```python
def multi_scale_joint_loss(network_outputs, targets, uncertainty_maps, 
                          num_stages, beta1=1.0, beta2=0.1, alpha=None):
    """
    Computes the multi-scale joint training loss.
    
    Args:
        network_outputs: List of output images for each stage i=1..D.
        targets: Ground truth images corresponding to the outputs.
        uncertainty_maps: Uncertainty maps for each stage.
        num_stages: Current number of stages D.
        beta1: Weight for MSE loss (default 1.0).
        beta2: Weight for uncertainty loss (default 0.1).
        alpha: Balance weight for coarse-fine loss (optional, used if 
               coarse/fine decomposition is applied instead of stage summation).
               
    Returns:
        Scalar loss value.
    """
    total_loss = 0.0
    
    # Method 1: Multi-stage aggregation (Recursive-NeRF style)
    # This is the primary formulation given explicit weights and stage summation.
    for i in range(1, num_stages + 1):
        # Calculate MSE loss for stage i
        # L_MSE^i = mean((network_outputs[i] - targets[i])^2)
        mse_loss_i = mean_squared_error(network_outputs[i], targets[i])
        
        # Calculate uncertainty loss for stage i
        # L_unct^i is defined by the source as uncertainty loss
        # Implementation depends on specific uncertainty model, 
        # but typically involves variance or confidence weighting.
        unct_loss_i = compute_uncertainty_loss(network_outputs[i], uncertainty_maps[i], targets[i])
        
        # Weighted sum for this stage
        stage_loss = beta1 * mse_loss_i + beta2 * unct_loss_i
        total_loss += stage_loss
        
    return total_loss
```

**Edge Cases and Pitfalls:**
- **Precision:** MSE loss is sensitive to outliers; the coarse-fine variant explicitly uses robust distance to suppress outlier noise influence [S2].
- **Boundary Conditions:** In dynamic growth, $D$ changes during training. The loss must be recomputed over the current active stages $1 \dots D$ [S1].
- **Degenerate Input:** If uncertainty maps are not available, the uncertainty loss term cannot be computed. The sources do not specify a fallback for this case [S1].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of stages $D$, as the loss is summed over all active stages [S1].
- **Memory Complexity:** Requires storing output images and uncertainty maps for all $D$ stages simultaneously during the backward pass [S1].
- **Strengths:** Preserves essential geometric variations while reducing noise interference [S2]. Balances global structure (low frequency) with local texture (high frequency) [S2].
- **Limitations:** Requires computing losses for all stages, which can be memory-intensive for large $D$ [S1]. The uncertainty loss term requires a defined uncertainty model [S1].
- **When to use:** When training involves dynamically growing networks or multi-stage refinement where both global structure and local detail are critical [S1, S2].

## Background
The multi-scale joint loss concept appears in two distinct contexts in the provided sources:
1.  **Recursive-NeRF:** Introduced in "Recursive-NeRF: An Efficient and Dynamically Growing NeRF" (2022), it uses a stage-wise summation of MSE and uncertainty losses to train a dynamically growing network [S1].
2.  **Denoise-GS:** Used in "Denoise-GS: Self-Supervised Denoising for Sparse-View 3D Gaussian Splatting" (2026), it employs a coarse-fine balance to refine denoised images, focusing on structural consistency and detail sharpness [S2].
