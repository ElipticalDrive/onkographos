# Overall Training Objective

Also called: Composite Loss

## Overview
The Overall Training Objective defines the composite loss function and optimization schedule used to train differentiable radiance fields, specifically in the context of text-driven stylization and multi-baseline reconstruction. It combines geometric reconstruction fidelity with perceptual and semantic constraints to guide the neural network toward the desired visual output. It differs from simple reconstruction objectives by integrating high-level perceptual metrics (SSIM, LPIPS) and, in stylization variants, contrastive text-image alignment losses.

## How it works
The method operates in two distinct phases: Reconstruction and Stylization (or specific task adaptation). The core mechanism involves minimizing a weighted sum of pixel-space and perceptual losses between rendered images and ground-truth (or target) images.

**Inputs:**
- Rendered image color $C_{rendered}$ from the radiance field.
- Ground-truth image color $C_{gt}$ (or target style image).
- Text embeddings (for stylization variants).

**Data Structures:**
- **Radiance Field Model:** Implicit representation (e.g., VolSDF [S1] or Multi-Baseline decoder [S2]).
- **Optimizer:** Adam optimizer.

**Parameters:**
- **Reconstruction Stage:**
  - Points per ray: 192 [S1].
  - Epochs: 6 [S1].
  - Learning rate: $0.0005$ [S1].
- **Stylization/Adaptation Stage:**
  - Epochs: 4 [S1].
  - Learning rate: $0.001$ [S1].
- **Loss Weights (Stylization):**
  - $\lambda_g = 0.2$ [S1].
  - $\lambda_l = 0.1$ [S1].
  - $\lambda_p = 2.0$ [S1].
  - $\lambda_r = 0.1$ [S1].
- **Negative Samples:** ~200 text descriptions (e.g., "Zombie", "Tolkien elf") collected from Pinterest [S1].

**Steps:**
1. **Ray Sampling:** Sample $N=192$ points along each ray [S1].
2. **Rendering:** Compute color $C_{rendered}$ and density $\sigma$ via volume rendering integration [S1, S2].
3. **Loss Calculation:** Compute the total loss $\mathcal{L}_{total}$ as a weighted sum of components.
   - For general reconstruction (MuRF): $\mathcal{L}_{total} = \mathcal{L}_{L1} + \mathcal{L}_{SSIM} + \mathcal{L}_{LPIPS}$ [S2].
   - For stylization (NeRF-Art): $\mathcal{L}_{total} = \lambda_g \mathcal{L}_g + \lambda_l \mathcal{L}_l + \lambda_p \mathcal{L}_p + \lambda_r \mathcal{L}_r$ [S1]. (Note: Specific definitions of $\mathcal{L}_g, \mathcal{L}_l, \mathcal{L}_p, \mathcal{L}_r$ are not explicitly detailed in the provided text, but $\mathcal{L}_p$ likely refers to perceptual loss given the weight $\lambda_p=2.0$ and context of LPIPS in [S2]).
4. **Optimization:** Update radiance field parameters using Adam optimizer [S1, S2].
5. **Patch-Level Training:** In stylization, use random crops of size $1/10$ of the original input to reduce memory and improve local contrastive learning [S1].

**Pseudocode:**
```python
def train_overall_objective(model, optimizer, dataloader, stage='reconstruction'):
    if stage == 'reconstruction':
        epochs = 6
        lr = 0.0005
        points_per_ray = 192
    elif stage == 'stylization':
        epochs = 4
        lr = 0.001
        points_per_ray = 192 # Assumed same sampling density
    
    optimizer.param_groups[0]['lr'] = lr
    
    for epoch in range(epochs):
        for batch in dataloader:
            # 1. Sample points
            # [G] Standard volume rendering sampling logic
            points = sample_points_along_rays(batch.rays, num_samples=points_per_ray)
            
            # 2. Render
            # [G] Query model for color and density, integrate
            rendered_color = volume_render(points, model)
            
            # 3. Compute Loss
            if stage == 'reconstruction':
                # MuRF style: L1 + SSIM + LPIPS [S2]
                loss_l1 = l1_loss(rendered_color, batch.gt_color)
                loss_ssim = ssim_loss(rendered_color, batch.gt_color)
                loss_lpips = lpips_loss(rendered_color, batch.gt_color)
                total_loss = loss_l1 + loss_ssim + loss_lpips
            else:
                # NeRF-Art style: Weighted composite [S1]
                # [G] Specific sub-losses (g, l, p, r) are not defined in source text
                # Assuming standard perceptual and contrastive components based on weights
                loss_g = compute_geometric_loss(rendered_color, batch.gt_color) # Placeholder for L_g
                loss_l = compute_local_loss(rendered_color, batch.gt_color)     # Placeholder for L_l
                loss_p = compute_perceptual_loss(rendered_color, batch.gt_color) # Placeholder for L_p
                loss_r = compute_regularization_loss(model)                     # Placeholder for L_r
                
                lambda_g = 0.2
                lambda_l = 0.1
                lambda_p = 2.0
                lambda_r = 0.1
                
                total_loss = (lambda_g * loss_g + 
                              lambda_l * loss_l + 
                              lambda_p * loss_p + 
                              lambda_r * loss_r)
            
            # 4. Backpropagate
            optimizer.zero_grad()
            total_loss.backward()
            optimizer.step()
```

## Subtopics

### Composite Training Loss
A variant used in multi-baseline radiance field training (MuRF). It specifically defines the loss as the addition of L1, SSIM, and LPIPS losses between rendered and ground truth image color, applied to random crops of the full image [S2]. It is chosen when high-fidelity reconstruction across varying baselines is required without text-guided stylization.

## Operating characteristics
- **Time Complexity:** Dependent on the number of epochs (6 for reconstruction, 4 for stylization) and points per ray (192) [S1].
- **Memory:** Patch-level training (1/10 resolution crops) significantly reduces memory consumption, allowing high-resolution rendering [S1].
- **Performance:** MuRF achieves competitive PSNR/SSIM on small baselines (DTU) and large baselines (RealEstate10K) compared to specialized methods like ENeRF and AttnRend [S2].
- **Limitations:** Requires manual collection of negative text samples for stylization [S1].

## Background
The Overall Training Objective is central to recent differentiable volume rendering frameworks. The reconstruction parameters (192 points, Adam, LR 0.0005) are based on VolSDF [S1]. The composite loss structure (L1+SSIM+LPIPS) is detailed in MuRF [S2]. The stylization objective incorporates text-driven contrastive learning, drawing from NeRF-Art [S1] and StyleGAN-NADA [S1].
