# Composite Image Loss with Visibility Weighting

Also called: Optimization Loss Function, Visibility-weighted Photometric Loss

## Overview
This method defines the composite image loss $\mathcal{L}_c$ used to supervise the training of radiance field models by combining photometric reconstruction errors with perceptual similarity metrics. It solves the problem of unreliable gradient propagation from background or occluded regions by masking the photometric terms with a visibility map $\mathbf{V}_M$. It sets itself apart from standard photometric losses by explicitly incorporating this visibility weighting for L1 and SSIM terms, while applying the perceptual LPIPS loss to the unmasked rendered image to preserve global structure [S1].

## How it works
The method computes a composite loss $\mathcal{L}_c$ and a total loss $\mathcal{L}$ by combining weighted photometric and perceptual terms with regularization losses.

**Inputs:**
*   $I_r$: Rendered image tensor.
*   $I_{gt}$: Ground-truth reference image tensor.
*   $\mathbf{V}_M$: Visibility map tensor (binary or soft mask indicating reliable pixels).
*   $L_{sc}$: Sampling coordinate regularization loss.
*   $L_{vm}$: Visibility map regularization loss.

**Parameters:**
*   $\lambda_1 = 0.8$: Weight for L1 loss [S1].
*   $\lambda_{SSIM} = 0.2$: Weight for SSIM loss [S1].
*   $\lambda_{LPIPS} = 0.005$: Weight for LPIPS loss [S1].
*   $\lambda_{sc} = 0.001$: Weight for sampling coordinate regularization [S1].
*   $\lambda_{vm} = 0.15$: Weight for visibility map regularization [S1].

**Formulas:**
The composite image loss $\mathcal{L}_c$ is defined as [S1]:
$$
\mathcal{L}_c = \lambda_1 \mathcal{L}_1(\mathbf{V}_M \odot I_r, \mathbf{V}_M \odot I_{gt}) + \lambda_{SSIM} \mathcal{L}_{SSIM}(\mathbf{V}_M \odot I_r, \mathbf{V}_M \odot I_{gt}) + \lambda_{LPIPS} \mathcal{L}_{LPIPS}(I_r, I_{gt})
$$
where $\odot$ denotes the Hadamard (element-wise) product. The L1 and SSIM losses are computed only on pixels where $\mathbf{V}_M$ is active. The LPIPS loss is computed on the full images $I_r$ and $I_{gt}$ [S1].

The total loss $\mathcal{L}$ is defined as [S1]:
$$
\mathcal{L} = \mathcal{L}_c + \lambda_{sc} L_{sc} + \lambda_{vm} L_{vm}
$$

**Pseudocode:**
```python
def compute_composite_image_loss(I_r, I_gt, V_M, L_sc, L_vm):
    # Apply visibility mask to rendered and ground-truth images
    masked_I_r = I_r * V_M
    masked_I_gt = I_gt * V_M
    
    # Compute L1 loss on masked images
    # L1 is typically mean absolute error
    L1_term = torch.mean(torch.abs(masked_I_r - masked_I_gt))
    
    # Compute SSIM loss on masked images
    # SSIM is typically 1 - SSIM_index to convert to a loss
    SSIM_term = 1.0 - compute_ssim(masked_I_r, masked_I_gt)
    
    # Compute LPIPS loss on unmasked images
    # LPIPS requires a pre-trained network (e.g., VGG)
    LPIPS_term = compute_lpips(I_r, I_gt)
    
    # Combine with weights
    lambda_1 = 0.8
    lambda_SSIM = 0.2
    lambda_LPIPS = 0.005
    
    L_c = (lambda_1 * L1_term + 
           lambda_SSIM * SSIM_term + 
           lambda_LPIPS * LPIPS_term)
    
    # Add regularization terms
    lambda_sc = 0.001
    lambda_vm = 0.15
    
    L_total = L_c + (lambda_sc * L_sc) + (lambda_vm * L_vm)
    
    return L_c, L_total
```

**Edge Cases and Pitfalls:**
*   **Visibility Map Definition:** The correctness of the masking depends on the accurate generation of $\mathbf{V}_M$. If $\mathbf{V}_M$ incorrectly masks foreground objects, gradients will not propagate to those regions, hindering reconstruction [S1].
*   **LPIPS Application:** Applying LPIPS to unmasked images ensures that global perceptual structure is preserved even in regions where photometric supervision might be weak or absent due to visibility masking [S1].
*   **Weight Sensitivity:** The weights $\lambda$ are critical. The sources provide specific values ($\lambda_1=0.8, \lambda_{SSIM}=0.2, \lambda_{LPIPS}=0.005, \lambda_{sc}=0.001, \lambda_{vm}=0.15$) which should be used as a baseline [S1].

## Subtopics

### [SRF-Loss](6978-srf-loss.md)
SRF-Loss is the composite objective function used to train SuRFNet for generating high-quality Sparse Radiance Fields (SRFs) from partial or noisy inputs. It addresses the problem of ensuring that generated 3D radiance fields not only match the input density and color statistics but also produce visually accurate renderings from novel views. It sets itself apart from simple pixel-wise reconstruction losses by incorporating a 3D-supervised density/radiance component and an online perceptual loss that explicitly optimizes for rendering quality.

## Operating characteristics
*   **Complexity:** The computational cost is dominated by the rendering process itself and the LPIPS network evaluation. L1 and SSIM are relatively cheap. The visibility masking is an element-wise operation with negligible cost.
*   **Performance:** The method is used in the context of Gaussian Splatting for unconstrained image collections, achieving competitive PSNR, SSIM, and LPIPS scores compared to Ha-NeRF and CR-NeRF [S1].
*   **Strengths:** Explicitly handles background and occlusion via visibility weighting, preventing noise from degrading the model. Combines pixel-wise accuracy (L1) with structural similarity (SSIM) and perceptual quality (LPIPS).
*   **Limitations:** Relies on the availability and accuracy of the visibility map $\mathbf{V}_M$. The LPIPS loss requires a pre-trained network, adding memory and compute overhead.
*   **When to use:** When training radiance fields on unconstrained or noisy image collections where background regions or occlusions are prevalent and need to be masked out during supervision [S1].

## Background
This loss function is introduced in the context of "Gaussian in the Wild: 3D Gaussian Splatting for Unconstrained Image Collections" [S1]. It builds on the shared principles of photometric and image reconstruction losses, specifically incorporating visibility weighting as a key variation [S1]. The method is implemented using PyTorch and trained with the Adam optimizer [S1].
