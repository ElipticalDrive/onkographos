# Composite Image Loss with Visibility Weighting

Also called: Color and Silhouette Loss, L_c + lambda * L_m, Loss Functions, Optimization Loss Function, Visibility-weighted Photometric Loss

## Overview
This method defines the composite objective function used to optimize radiance fields or 3D representations by combining photometric reconstruction errors with visibility-based weighting and silhouette constraints. It solves the problem of ensuring that generated 3D radiance fields not only match input density and color statistics but also produce visually accurate renderings from novel views, particularly in the presence of occlusions or transparent structures [S1, S2]. It sets itself apart from simple pixel-wise reconstruction losses by incorporating a 3D-supervised density/radiance component and an online perceptual loss that explicitly optimizes for rendering quality [S1]. It builds on [Photometric and Image Reconstruction Losses](9789-photometric-and-image-reconstruction-losses.md) by introducing visibility maps to weight the photometric terms and adding specific regularization for sampling coordinates and visibility maps [S2].

## How it works
The method computes a total loss $\mathcal{L}$ composed of a composite image loss $\mathcal{L}_c$ and regularization terms. The composite image loss combines L1, SSIM, and LPIPS metrics, where L1 and SSIM are weighted by a visibility map $V_M$. A separate formulation also includes a silhouette loss $\mathcal{L}_m$ weighted by $\lambda$.

**Inputs and Outputs:**
-   **Inputs:** Rendered image $\mathbf{I}_r$, ground-truth image $\mathbf{I}_{gt}$, visibility map $V_M$ (binary or soft mask indicating visible regions), rendered mask $\alpha_\mathbf{r}$, ground-truth mask $M_\mathbf{r}$, rendered color $C_\mathbf{r}$, ground-truth color $\hat{C}_\mathbf{r}$.
-   **Outputs:** Scalar loss value $\mathcal{L}$.

**Data Structures:**
-   $V_M$: Visibility map, same spatial dimensions as $\mathbf{I}_r$. Elements are 1 for visible pixels, 0 for occluded/background pixels. [S2]
-   $\alpha_\mathbf{r}$: Rendered alpha mask for ray $\mathbf{r}$. [S1]
-   $M_\mathbf{r}$: Ground-truth binary mask for ray $\mathbf{r}$. [S1]

**Formulas:**
1.  **Rendered Mask:** The alpha value for a ray $\mathbf{r}$ is computed as [S1]:
    $$ \alpha(\mathbf{r}) = \sum_{i=1}^{N} T(p_i) (1 - e^{-\sigma_{p_i}\delta_{p_i}}) $$
    where $T(p_i)$ is the transmittance up to point $p_i$, $\sigma_{p_i}$ is the density, and $\delta_{p_i}$ is the distance between samples.

2.  **Composite Image Loss ($\mathcal{L}_c$):** Combines L1, SSIM, and LPIPS losses. L1 and SSIM are applied only to visible regions using the Hadamard product $\odot$ [S2]:
    $$ \mathcal{L}_c = \lambda_1 \mathcal{L}_1(V_M \odot \mathbf{I}_r, V_M \odot \mathbf{I}_{gt}) + \lambda_{SSIM} \mathcal{L}_{SSIM}(V_M \odot \mathbf{I}_r, V_M \odot \mathbf{I}_{gt}) + \lambda_{LPIPS} \mathcal{L}_{LPIPS}(\mathbf{I}_r, \mathbf{I}_{gt}) $$
    where $\mathcal{L}_1$ is the L1 distance, $\mathcal{L}_{SSIM}$ is the Structural Similarity Index, and $\mathcal{L}_{LPIPS}$ is the Learned Perceptual Image Patch Similarity [S2].

    *Alternative Formulation (Color Loss only):* Some implementations use a simpler color loss based on L2 norm [S1]:
    $$ \mathcal{L}_c = \sum_{\mathbf{r} \in \mathcal{R}} ||C_\mathbf{r} - \hat{C}_\mathbf{r}||_2^2 $$

3.  **Silhouette Loss ($\mathcal{L}_m$):** Uses Binary Cross-Entropy (BCE) between the rendered mask and ground-truth mask [S1]:
    $$ \mathcal{L}_m = \sum_{\mathbf{r} \in \mathcal{R}} \text{BCE}(M_\mathbf{r} - \alpha_\mathbf{r}) $$

4.  **Total Loss ($\mathcal{L}$):** Combines the composite image loss with regularization terms for sampling coordinates ($\mathcal{L}_{sc}$) and visibility map ($\mathcal{L}_{vm}$) [S2]:
    $$ \mathcal{L} = \mathcal{L}_c + \lambda_{sc} \mathcal{L}_{sc} + \lambda_{vm} \mathcal{L}_{vm} $$

    *Alternative Formulation:* A simpler total loss combining color and silhouette losses [S1]:
    $$ \mathcal{L} = \mathcal{L}_c + \lambda \mathcal{L}_m $$

**Parameters:**
-   $\lambda_1$: Weight for L1 loss. Value: 0.8 [S2].
-   $\lambda_{SSIM}$: Weight for SSIM loss. Value: 0.2 [S2].
-   $\lambda_{LPIPS}$: Weight for LPIPS loss. Value: 0.005 [S2].
-   $\lambda_{sc}$: Weight for sampling coordinate regularization loss. Value: 0.001 [S2].
-   $\lambda_{vm}$: Weight for visibility map regularization loss. Value: 0.15 [S2].
-   $\lambda$: Weight balancing color and silhouette losses. Value: 0.1 [S1].

**Pseudocode:**
```python
def compute_composite_image_loss(I_r, I_gt, V_M, lambda_1, lambda_ssim, lambda_lpips):
    """
    Computes the composite image loss L_c as defined in [S2].
    I_r: Rendered image tensor (H, W, 3)
    I_gt: Ground truth image tensor (H, W, 3)
    V_M: Visibility map tensor (H, W) or (H, W, 1)
    lambda_1: Weight for L1 loss
    lambda_ssim: Weight for SSIM loss
    lambda_lpips: Weight for LPIPS loss
    """
    # Apply visibility mask to images for L1 and SSIM
    I_r_visible = I_r * V_M
    I_gt_visible = I_gt * V_M
    
    # Calculate L1 loss on visible regions
    l1_loss = torch.mean(torch.abs(I_r_visible - I_gt_visible))
    
    # Calculate SSIM loss on visible regions
    # Note: SSIM implementation details are abstracted; assume a function that returns a scalar
    ssim_loss = 1.0 - ssim_metric(I_r_visible, I_gt_visible)
    
    # Calculate LPIPS loss on full images (not masked in [S2])
    lpips_loss = lpips_metric(I_r, I_gt)
    
    # Combine losses
    L_c = lambda_1 * l1_loss + lambda_ssim * ssim_loss + lambda_lpips * lpips_loss
    
    return L_c

def compute_silhouette_loss(alpha_r, M_r):
    """
    Computes the silhouette loss L_m as defined in [S1].
    alpha_r: Rendered alpha mask tensor
    M_r: Ground truth binary mask tensor
    """
    # Binary Cross Entropy
    bce_loss = torch.nn.functional.binary_cross_entropy(alpha_r, M_r)
    return bce_loss

def compute_total_loss(L_c, L_sc, L_vm, lambda_sc, lambda_vm):
    """
    Computes the total loss L as defined in [S2].
    L_c: Composite image loss
    L_sc: Sampling coordinate regularization loss
    L_vm: Visibility map regularization loss
    lambda_sc: Weight for sampling coordinate regularization
    lambda_vm: Weight for visibility map regularization
    """
    L = L_c + lambda_sc * L_sc + lambda_vm * L_vm
    return L

def compute_total_loss_simple(L_c, L_m, lambda_m):
    """
    Computes the total loss L as defined in [S1].
    L_c: Color loss (L2)
    L_m: Silhouette loss
    lambda_m: Weight for silhouette loss
    """
    L = L_c + lambda_m * L_m
    return L
```

**Edge Cases and Pitfalls:**
-   **Visibility Map Accuracy:** If $V_M$ is inaccurate, the L1 and SSIM terms may be incorrectly weighted, leading to artifacts in occluded regions [S2].
-   **Gradient Flow:** The Hadamard product with $V_M$ must be differentiable. If $V_M$ is binary, gradients may vanish; soft visibility maps are preferred [S2].
-   **LPIPS Normalization:** LPIPS loss is computed on full images, not masked regions, which may cause gradients to propagate to occluded areas if not handled carefully [S2].
-   **Parameter Sensitivity:** The choice of $\lambda$ and other weights significantly impacts convergence. Values provided in [S1] and [S2] are empirically determined and may need adjustment for different datasets [S1, S2].

## Subtopics

### [SRF-Loss](6978-srf-loss.md)
SRF-Loss is the composite objective function used to train SuRFNet for generating high-quality Sparse Radiance Fields (SRFs) from partial or noisy inputs. It addresses the problem of ensuring that generated 3D radiance fields not only match the input density and color statistics but also produce visually accurate renderings from novel views. It sets itself apart from simple pixel-wise reconstruction losses by incorporating a 3D-supervised density/radiance component and an online perceptual loss that explicitly optimizes for rendering quality.

### Single Image 3D Reconstruction Loss
A composite loss function used to optimize geometry, material, and lighting from a single image without supervision [S3, unofficial]. It combines multiple consistency losses: an image loss ($\mathcal{L}_{im}$) computing the L1-distance between rendered and input images, an Intersection-over-Union (IoU) loss ($\mathcal{L}_{msk}$) for silhouettes, a perceptual loss ($\mathcal{L}_{per}$) using pre-trained AlexNet feature maps, and a Laplacian loss ($\mathcal{L}_{lap}$) to penalize changes in relative vertex positions [S3, unofficial]. The total loss is $\mathcal{L}(\vartheta) = \alpha_{im} \mathcal{L}_{im}(\tilde{I}, I) + \alpha_{msk} \mathcal{L}_{msk}(\tilde{V}, V) + \alpha_{per} \mathcal{L}_{per}(I, \tilde{I}) + \alpha_{lap} \mathcal{L}_{lap}(\pi)$ [S3, unofficial]. The weight for image loss $\alpha_{im}$ is set to 20 [S3, unofficial]. The network predicts relative offsets for $|M|=642$ vertices, a 256x256 texture map (diffuse albedo), and lighting parameters (256x256 RGB env map for MC, or K=32 SG coefficients for SG) [S3, unofficial].

## Operating characteristics
-   **Time Complexity:** The computation of L1 and SSIM is linear in the number of pixels. LPIPS involves a forward pass through a pre-trained network (e.g., VGG or AlexNet), which is more expensive but constant per pixel. The visibility weighting adds negligible overhead.
-   **Memory Complexity:** Requires storing the visibility map $V_M$, rendered images, and ground-truth images. The LPIPS loss requires caching features from the pre-trained network, increasing memory usage.
-   **Measured Performance:** In [S2], the method achieved a PSNR of 27.96 on the GS-W dataset, outperforming Ha-NeRF (24.04) and CR-NeRF (26.53). In [S1], the method was used to train HumanNeRF, with training times of about 2 days for the generalizable NeRF module and 30-90 minutes for fine-tuning on 1080x1080 images using a single Nvidia GeForce RTX3090 GPU.
-   **Scaling:** The method scales well with resolution due to the pixel-wise nature of the losses. However, the LPIPS loss may become a bottleneck for very high resolutions due to the memory requirements of the pre-trained network.
-   **Strengths:** Effectively handles occlusions and transparent structures by using visibility maps. Combines multiple metrics (L1, SSIM, LPIPS) to mitigate blurriness and improve perceptual quality.
-   **Limitations:** Requires accurate visibility maps or masks. The choice of hyperparameters is critical and dataset-dependent. The LPIPS loss adds computational overhead.
-   **When to Use:** Suitable for training radiance fields or 3D representations where photometric accuracy and perceptual quality are important, especially in the presence of occlusions.
-   **When Not to Use:** Not suitable for real-time applications due to the computational cost of LPIPS and SSIM. Not ideal if accurate visibility maps are unavailable.

## Background
The method originates from recent advances in differentiable volume rendering and neural radiance fields (NeRF). The use of visibility-weighted photometric losses was introduced to address the ambiguity in rendering occluded regions [S2]. The combination of color and silhouette losses has been used in various 3D reconstruction tasks, including human avatars [S1] and single-image 3D reconstruction [S3, unofficial]. The specific formulation with L1, SSIM, and LPIPS losses weighted by a visibility map was proposed in [S2] for Gaussian Splatting in the wild. The simpler color and silhouette loss formulation was used in [S1] for HumanNeRF. The Single Image 3D Reconstruction Loss variant was proposed in [S3, unofficial] for DIB-R++.
