# Discriminator Loss with Gradient Penalty

Also called: GP Loss, Gradient Penalty Loss, R1 Gradient Penalty, Simple Gradient Penalty (R1)

## Overview
A regularization loss for training the discriminator that enforces Lipschitz continuity by penalizing large gradients of the discriminator output with respect to its input [S1, unofficial]. It distinguishes itself by computing an R1 penalty term exclusively on real data samples [S1, unofficial].

## How it works
The method computes the discriminator loss by combining a non-saturating GAN loss with an R1 gradient penalty term [S1, unofficial].

**Inputs and Outputs:**
- **Inputs:** Real image patches ($I_{real}$), fake image patches ($I_{fake}$), gradient penalty multiplier (`gp_loss_mult`) [S1, unofficial].
- **Outputs:** Total discriminator loss scalar [S1, unofficial].

**Data Structures:**
- Tensors for real and fake images with shape $[B, C, H, W]$ (Batch, Channels, Height, Width) [G].
- Discriminator output logits with shape $[B]$ [G].

**Steps:**
1. Set the real input tensor to require gradients [S1, unofficial].
2. Run the discriminator on real patches to get predictions $pred_{real}$ [S1, unofficial].
3. Run the discriminator on detached fake patches to get predictions $pred_{fake}$ [S1, unofficial].
4. Compute the gradient penalty using the real patches [S1, unofficial]:
   a. Compute the gradients of the sum of predictions with respect to the input [S1, unofficial].
   b. Compute the squared norm of these gradients [S1, unofficial].
   c. Average the squared norms over the batch [S1, unofficial].
   d. Divide by 2 to get the R1 penalty [S1, unofficial].
5. Compute the real and fake GAN losses using the softplus function [S1, unofficial].
6. Sum the real and fake losses to get the total discriminator loss [S1, unofficial].

**Formulas:**
The discriminator loss is defined as:
$$ L_D = L_{real} + L_{fake} + \lambda_{gp} \cdot GP $$

Where:
- $L_{real} = \text{mean}(\text{softplus}(-pred_{real}))$ [S1, unofficial]
- $L_{fake} = \text{mean}(\text{softplus}(pred_{fake}))$ [S1, unofficial]
- $GP = \frac{1}{2} \mathbb{E}_{I \sim p_{data}} [\|\nabla_I D(I)\|^2]$ [S1, unofficial]

In discrete tensor form for a batch:
$$ r1\_penalty = \text{mean}(\sum (\nabla_I D(I))^2, \text{dim}=[1,2,3]) $$ [S1, unofficial]
$$ gradient\_penalty = r1\_penalty / 2 $$ [S1, unofficial]

Here, $\nabla_I D(I)$ is the gradient of the discriminator output $D(I)$ with respect to the input image $I$ [S1, unofficial]. The sum is taken over channel, height, and width dimensions, leaving the batch dimension [S1, unofficial].

**Parameters:**
- `gp_loss_mult` ($\lambda_{gp}$): The multiplier for the gradient penalty term in the discriminator loss [S1, unofficial]. Typical values: Not given in the sources.

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def discriminator_loss_with_gradient_penalty(
    discriminator, 
    real_images, 
    fake_images, 
    gp_loss_mult=10.0
):
    # Step 1: Set the input tensor to require gradients
    real_images.requires_grad_(True)
    
    # Step 2: Run the discriminator on real patches to get predictions
    pred_real = discriminator(real_images)
    
    # Step 3: Run the discriminator on detached fake patches to get predictions
    pred_fake = discriminator(fake_images.detach())
    
    # Step 4: Compute the gradient penalty using the real patches
    # Compute the gradients of the sum of predictions with respect to the input
    gradients = torch.autograd.grad(
        outputs=pred_real.sum(),
        inputs=real_images,
        create_graph=True,
        retain_graph=True,
        only_inputs=True
    )[0]
    
    # Compute the squared norm of these gradients
    # Sum over channel, height, and width dimensions, leaving the batch dimension
    gradients_squared = gradients ** 2
    r1_penalty = torch.mean(torch.sum(gradients_squared, dim=[1, 2, 3]))
    
    # Divide by 2 to get the R1 penalty
    gradient_penalty = r1_penalty / 2.0
    
    # Step 5: Compute the real and fake GAN losses using the softplus function
    loss_d_real = F.softplus(-pred_real).mean()
    loss_d_fake = F.softplus(pred_fake).mean()
    
    # Step 6: Sum the real and fake losses to get the total discriminator loss
    total_loss = loss_d_real + loss_d_fake + gp_loss_mult * gradient_penalty
    
    return total_loss
```

**Edge Cases and Pitfalls:**
- Precision: Computing gradients with `create_graph=True` requires storing the computational graph, increasing memory usage [G].
- Boundaries: Not given in the sources.
- Degenerate Input: If the discriminator output is constant, gradients will be zero, and the penalty will vanish [G].

## Subtopics

### Non-saturating GAN Loss with R1 Regularization
A specific implementation of the discriminator loss with gradient penalty used in $\pi$-GAN [S2]. It defines the loss function as $\mathcal{L}(\theta, \phi) = \mathbf{E}_{\mathbf{z} \sim p_{\theta}, \xi \sim p_{\xi}} [f(D_{\theta D}(G_{\theta G}(\mathbf{z}, \xi)))] + \mathbf{E}_{\mathbf{I} \sim p_{\theta D}} [f(-D_{\theta D}(I)) + \lambda |\nabla D_{\theta D}(I)|^2]$, where $f(u) = -\log(1 + \exp(-u))$ [S2]. The generator minimizes this loss while the discriminator maximizes it [S2]. It uses the Adam optimizer with $\beta_1 = 0, \beta_2 = 0.9$, and initial learning rates of $5 \times 10^{-5}$ for the generator and $4 \times 10^{-4}$ for the discriminator, decayed to $1 \times 10^{-5}$ and $1 \times 10^{-4}$ respectively [S2].
