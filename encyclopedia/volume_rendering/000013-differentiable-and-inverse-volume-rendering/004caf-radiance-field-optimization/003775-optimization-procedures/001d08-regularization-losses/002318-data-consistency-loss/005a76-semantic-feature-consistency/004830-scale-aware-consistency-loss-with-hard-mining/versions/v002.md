# Scale-Aware Consistency Loss with Hard Mining

Also called: Appendix A.1: Re-weighting, Appendix A.1: Resampling, Re-weighting

## Overview
Scale-Aware Consistency Loss with Hard Mining enforces semantic consistency between pixel pairs in radiance field optimization by leveraging shared mask coverage across multiple scales [S1, unofficial]. It differs from standard consistency losses by explicitly gating features based on scale and mining hard positive/negative samples to address class imbalance and ambiguous semantic boundaries [S1, unofficial]. It builds on [Data Consistency Loss](2976-data-consistency-loss.md) [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Rendered semantic features tensor $F_{rendered} \in \mathbb{R}^{C \times H \times W}$, ground truth mask tensor $M_{gt} \in \{0, 1\}^{K \times H \times W}$ (where $K$ is the number of scales), and a list of sampled ray indices $R$ [S1, unofficial].
*   **Output:** A scalar loss value $L_{scale}$ [S1, unofficial].

**Data Structures:**
*   `rendered_features`: Float tensor of shape $(C, H, W)$ [S1, unofficial].
*   `masks`: Float tensor of shape $(K, H, W)$ representing mask coverage at different scales [S1, unofficial].
*   `gt_corrs`: Binary tensor of shape $(N, N)$ indicating ground truth semantic correspondence between $N$ sampled pixels [S1, unofficial].
*   `corr`: Computed cosine similarity tensor of shape $(N, N)$ [S1, unofficial].

**Steps:**

1.  **Feature Normalization and Regularization:** Compute the $L_2$ norm of the rendered features across the channel dimension, averaged over spatial dimensions: $F_{norm} = \frac{1}{HW} \sum_{h,w} \| F_{rendered}[:, h, w] \|_2$ [S1, unofficial]. Compute the norm regularization loss: $L_{norm} = (1 - F_{norm})^2$ [S1, unofficial].
2.  **Scale Interpolation:** Interpolate the rendered features to the resolution of the mask grid using bilinear interpolation: $F_{interp} = \text{Interpolate}(F_{rendered}, \text{size}=M_{gt}.shape[-2:], \text{mode}=\text{'bilinear'})$ [S1, unofficial].
3.  **Scale-Aware Gating:** Apply scale gating to the interpolated features [S1, unofficial]. *Note: The specific gating function is referenced as "Scale-Aware Semantic Feature Gating" but not detailed in the provided source* [G].
4.  **Sampling:** Select features corresponding to the sampled rays: $F_{sampled} = F_{gated}[:, :, R]$ [S1, unofficial]. Normalize the sampled features along the channel dimension: $F_{sam} = \text{Normalize}(F_{sampled}, \text{dim}=-1, p=2)$ [S1, unofficial].
5.  **Similarity Computation:** Compute the cosine similarity matrix between all pairs of sampled rays: $C = F_{sam} \cdot F_{sam}^T$ [S1, unofficial].
6.  **Consistency Classification:** Determine the consistency status of each pixel pair based on mask overlap across all $K$ scales [S1, unofficial]. Let $S_{ij} = \sum_{k=1}^K M_{gt}[k, i] \cdot M_{gt}[k, j]$ be the sum of mask overlaps for pair $(i,j)$ across all scales [S1, unofficial]. Identify pixel pairs with no common masks across all scales ($S_{ij} = 0$) [S1, unofficial]. Identify pixel pairs with common masks in all scales ($S_{ij} = K$) [S1, unofficial]. Identify inconsistent pairs (neither fully positive nor negative) [S1, unofficial].
7.  **Hard Mining and Sampling:** Calculate the number of samples to draw from the inconsistent set: $N_{sample} = \lfloor N_{inconsistent} / 2 \rfloor$ [S1, unofficial]. Randomly select positive samples from the consistent positive set using a threshold based on $N_{sample}$ and uniform random numbers in $[0, 1)$ [S1, unofficial]. Randomly select negative samples from the consistent negative set using the same threshold logic [S1, unofficial]. Add hard positive samples: identify pairs that have common masks ($gt\_corrs_{ij} = 1$) but have low cosine similarity ($C_{ij} < 0.75$) [S1, unofficial]. Add hard negative samples: identify pairs that have no common masks ($gt\_corrs_{ij} = 0$) but have high cosine similarity ($C_{ij} > 0.5$) [S1, unofficial].
8.  **Loss Calculation:** The final loss combines the norm regularization and the consistency loss derived from the mined samples [S1, unofficial]. *Note: The exact aggregation formula for the mined samples is not provided in the source* [G].

**Pseudocode:**

```python
import torch
import torch.nn.functional as F

def scale_aware_consistency_loss(rendered_features, masks, sampled_ray_indices, gt_corrs):
    """
    rendered_features: (C, H, W)
    masks: (K, H, W) - Binary masks for K scales
    sampled_ray_indices: (N,) - Indices into the flattened (H, W) grid
    gt_corrs: (N, N) - Ground truth correspondence matrix for sampled rays
    """
    N = len(sampled_ray_indices)
    
    # 1. Norm Regularization
    feat_norm = torch.norm(rendered_features, dim=0, p=2).mean()
    loss_norm = (1 - feat_norm) ** 2
    
    # 2. Interpolate to mask resolution
    rendered_interp = F.interpolate(
        rendered_features.unsqueeze(0), 
        size=masks.shape[-2:], 
        mode='bilinear', 
        align_corners=False
    ).squeeze(0)
    
    # 3. Scale Gating
    # Note: The source references "Scale-Aware Semantic Feature Gating" but does not provide the implementation.
    feature_with_scale = rendered_interp  # Placeholder for gating logic [G]
    
    # 4. Sample Features
    C, H, W = feature_with_scale.shape
    feature_flat = feature_with_scale.view(C, -1)  # (C, H*W)
    sampled_features = feature_flat[:, sampled_ray_indices]  # (C, N)
    sampled_features = sampled_features.T  # (N, C)
    
    # 5. Normalize
    scale_conditioned_features_sam = F.normalize(sampled_features, dim=-1, p=2)
    
    # 6. Cosine Similarity
    # Source: torch.einsum('nhc,njc->nhj', ...)
    # Fixed to match (N, C) tensor dimensions: nc, mc -> nm
    corr = torch.einsum('nc,mc->nm', scale_conditioned_features_sam, scale_conditioned_features_sam)
    
    # 7. Classify Pairs
    # Flatten masks and sample rays
    masks_flat = masks.view(masks.shape[0], -1)  # (K, H*W)
    sampled_masks = masks_flat[:, sampled_ray_indices]  # (K, N)
    
    # Pairwise mask overlap across scales: (N, K) @ (K, N).T -> (N, N)
    sum_0 = torch.matmul(sampled_masks.T, sampled_masks)
    
    consistent_negative = (sum_0 == 0)
    consistent_positive = (sum_0 == masks.shape[0])  # Fixed from len(gt_corrs) to K
    inconsistent = torch.logical_not(torch.logical_or(consistent_negative, consistent_positive))
    
    # 8. Hard Mining
    inconsistent_num = inconsistent.sum().item()
    sampled_num = inconsistent_num // 2
    
    # Random selection from consistent sets
    rand_num = torch.rand_like(consistent_positive, dtype=torch.float32)
    pos_count = consistent_positive.count_nonzero()
    neg_count = consistent_negative.count_nonzero()
    
    sampled_positive = torch.zeros_like(consistent_positive, dtype=torch.bool)
    sampled_negative = torch.zeros_like(consistent_negative, dtype=torch.bool)
    
    if pos_count > 0:
        sampled_positive = torch.logical_and(consistent_positive, rand_num < sampled_num / pos_count)
    if neg_count > 0:
        sampled_negative = torch.logical_and(consistent_negative, rand_num < sampled_num / neg_count)
        
    # Hard Positives: gt_corrs == 1 AND corr < 0.75
    hard_pos_mask = torch.any(torch.logical_and(corr < 0.75, gt_corrs == 1), dim=0)
    
    # Hard Negatives: gt_corrs == 0 AND corr > 0.5
    hard_neg_mask = torch.any(torch.logical_and(corr > 0.5, gt_corrs == 0), dim=0)
    
    # Note: The source does not specify the final loss aggregation formula for the mined samples.
    # [G] Assuming a standard consistency loss (e.g., MSE or cosine distance) on the selected pairs.
    return loss_norm
```

## Operating characteristics
*   **Time Complexity:** Dominated by the cosine similarity matrix computation $O(N^2 C)$ and the mask overlap computation $O(N^2 K)$, where $N$ is the number of sampled rays, $C$ is the feature dimension, and $K$ is the number of scales [S1, unofficial].
*   **Memory Complexity:** $O(N^2)$ to store the similarity and mask overlap matrices [S1, unofficial].
*   **Strengths:** Explicitly handles scale variations in semantic features [S1, unofficial]. Hard mining focuses optimization on ambiguous or difficult cases, potentially improving convergence in complex scenes [S1, unofficial].
*   **Limitations:** Requires careful tuning of hard mining thresholds (0.75 for positives, 0.5 for negatives) [S1, unofficial]. The $O(N^2)$ memory usage can be prohibitive for large $N$ [S1, unofficial]. The specific gating mechanism is not detailed, making implementation dependent on external modules [S1, unofficial].
*   **When to use:** When semantic consistency is critical and standard consistency losses fail to capture scale-dependent semantic relationships [S1, unofficial].
*   **When not to use:** When computational resources are limited and $N$ is large, or when mask data is not available [S1, unofficial].

## Background
This method is described in the context of "Gaussian Splatting Lightning," an unofficial implementation of 3D Gaussian Splatting [S1, unofficial]. It is presented as an optimization procedure for radiance field optimization, specifically within the domain of differentiable and inverse volume rendering [S1, unofficial]. The technique aims to improve the semantic coherence of the rendered features by leveraging multi-scale mask information [S1, unofficial].
