# Neural Projection with Photometric Consistency

Also called: Point-to-Image Photometric Constraint

## Overview
Neural Projection with Photometric Consistency is a regularization technique for implicit surface reconstruction that enforces geometric accuracy by projecting sampled points onto the learned implicit surface and verifying their appearance consistency across multiple views [S1, unofficial]. It solves the problem of noisy SDF predictions by using multi-view photometric constraints to supervise the position of the projected surface points, indirectly ensuring the accuracy of the SDF values at the original sample locations [S1, unofficial]. Unlike sibling methods that rely on depth maps or optimal transport, this method operates directly on the implicit field's gradient to map points to the surface, making it particularly effective for handling noisy data where explicit depth estimation is unreliable [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of 3D points $P$ sampled in space; a base Signed Distance Function (SDF) network $f$ that outputs scalar SDF values and gradients; a set of $N$ reference and source images $\{I_r, I_{s_1}, ..., I_{s_N}\}$ with known camera poses; a patch size $s$ for image extraction [S1, unofficial].
*   **Outputs:** A photometric consistency loss value $\mathcal{L}_{pc}$ used to update the base SDF network [S1, unofficial].

**Data Structures:**
*   **Point Set $P$:** A list of 3D coordinates $x_P \in \mathbb{R}^3$ [S1, unofficial].
*   **SDF Network $f$:** A neural network taking $x_P$ as input, outputting $f(x_P) \in \mathbb{R}$ and $\nabla f(x_P) \in \mathbb{R}^3$ [S1, unofficial].
*   **Image Patches:** 2D image regions extracted from reference and source views centered at projected coordinates [S1, unofficial].

**Numbered Steps:**
1.  **Gradient Computation:** For each point $x_P \in P$, compute the gradient of the SDF field:
    $$ g(x_P) = \nabla f(x_P) $$
    The gradient direction $g(x_P)$ represents the direction of the fastest increasing SDF value and points outward from the surface [S1, unofficial].
2.  **Neural Projection:** Project the point $x_P$ to its nearest neighbor $t_P$ on the implicit surface $S$ by moving along the gradient direction by a distance equal to the absolute SDF value $|f(x_P)|$ [S1, unofficial]. The projection formula is:
    $$ t_P = x_P - f(x_P) \frac{g(x_P)}{\|g(x_P)\|_2} $$
    This step ensures $t_P$ lies on the zero-level set of the SDF (the implicit surface) [S1, unofficial].
3.  **Patch Extraction:** Identify the reference image $I_r$ corresponding to the depth map that generated the original point $x_P$ [S1, unofficial]. Extract a small image patch $s$ centered at the projected coordinate $t_P$ in the reference image $I_r$ [S1, unofficial]. Similarly, project $t_P$ into each source image $I_{s_i}$ and extract the corresponding patch $I_{s_i}(s)$ [S1, unofficial].
4.  **Photometric Scoring:** Calculate the Normalized Cross-Correlation (NCC) score between the reference patch $I_r(s)$ and each source patch $I_{s_i}(s)$:
    $$ \text{Score}(I_r(s), I_{s_i}(s)) = \frac{\text{Cov}(I_r(s), I_{s_i}(s))}{\sqrt{\text{Var}(I_r(s)) \text{Var}(I_{s_i}(s))}} $$
    where $\text{Cov}$ is the covariance and $\text{Var}$ is the variance of the pixel intensities in the respective patches [S1, unofficial].
5.  **Loss Aggregation:** Compute the photometric consistency loss $\mathcal{L}_{pc}$ by averaging the inconsistency $(1 - \text{Score})$ over all points in $P$ and the top $m$ source images that yield the best scores:
    $$ \mathcal{L}_{pc} = \frac{1}{m D_P} \sum_{x_P \in P} \sum_{i=1}^m (1 - \text{Score}(I_r(s), I_{s_i}(s))) $$
    where $D_P$ is the number of points in set $P$, and $m$ is the number of source images selected [S1, unofficial].

**Parameters:**
*   $m$: Number of source images used for loss calculation. Set to 4 [S1, unofficial].
*   $s$: Size of the image patch. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Gradient Normalization:** If $\|g(x_P)\|_2$ is near zero, the projection becomes unstable. This typically occurs far from the surface or in flat regions [G]. A small epsilon ($\epsilon$) should be added to the denominator to prevent division by zero: $\|g(x_P)\|_2 + \epsilon$ [G].
*   **Network Application:** The loss is applied to the signals from the base SDF network, not the final SDF (which may include a bias network) [S1, unofficial]. This is crucial because the projection requires differentiable gradients of the SDF field, and applying the constraint to the final output could interfere with the bias network's ability to refine details [S1, unofficial].
*   **Occlusion:** The method assumes visibility. If a point is occluded in a source view, the photometric score will be low, potentially penalizing valid geometry [G]. The selection of the "top $m$" scores helps mitigate this by ignoring poorly matching views, which often correspond to occlusions or non-Lambertian regions [S1, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn.functional as F

def neural_projection_photometric_loss(
    points: torch.Tensor, 
    sdf_net: torch.nn.Module, 
    images: torch.Tensor, 
    camera_poses: torch.Tensor, 
    patch_size: int, 
    m: int = 4
) -> torch.Tensor:
    """
    Computes the Neural Projection with Photometric Consistency loss.
    
    Args:
        points: (B, N, 3) Batch of 3D points.
        sdf_net: Base SDF network returning (sdf_values, gradients).
        images: (B, N_cam, H, W, 3) RGB images for all cameras.
        camera_poses: (B, N_cam, 4, 4) Camera-to-World pose matrices.
        patch_size: Size of the square patch for NCC.
        m: Number of best source images to use.
        
    Returns:
        loss: Scalar photometric consistency loss.
    """
    # 1. Compute SDF and Gradient
    # sdf_net returns (B, N, 1) and (B, N, 3)
    sdf_values, gradients = sdf_net(points)
    
    # 2. Project points to surface
    # Normalize gradient with epsilon guard [G]
    grad_norm = torch.norm(gradients, dim=-1, keepdim=True) + 1e-8
    normalized_grad = gradients / grad_norm
    
    # t_P = x_P - f(x_P) * g(x_P) / ||g(x_P)||
    projected_points = points - sdf_values * normalized_grad
    
    # 3. Identify Reference and Source Images
    # The source states the reference image corresponds to the depth map 
    # that generated x_P. We assume reference camera index 0 for this implementation.
    ref_idx = 0
    ref_image = images[:, ref_idx]  # (B, H, W, 3)
    source_indices = [i for i in range(images.shape[1]) if i != ref_idx]
    
    # 4. Project 3D points to 2D image coordinates
    # Convert World-to-Camera using inverse pose, then perspective divide
    # points_h: (B, N, 4)
    points_h = torch.cat([projected_points, torch.ones_like(projected_points[..., :1])], dim=-1)
    
    ref_coords_2d = []
    source_coords_2d = {idx: [] for idx in source_indices}
    
    for b in range(images.shape[0]):
        # Reference view projection
        cam_pose_inv = torch.inverse(camera_poses[b, ref_idx])
        points_cam = torch.matmul(points_h[b], cam_pose_inv.transpose(-1, -2))
        u = points_cam[..., 0] / (points_cam[..., 2] + 1e-8)
        v = points_cam[..., 1] / (points_cam[..., 2] + 1e-8)
        ref_coords_2d.append(torch.stack([u, v], dim=-1))
        
        # Source view projections
        for idx in source_indices:
            cam_pose_inv = torch.inverse(camera_poses[b, idx])
            points_cam = torch.matmul(points_h[b], cam_pose_inv.transpose(-1, -2))
            u = points_cam[..., 0] / (points_cam[..., 2] + 1e-8)
            v = points_cam[..., 1] / (points_cam[..., 2] + 1e-8)
            source_coords_2d[idx].append(torch.stack([u, v], dim=-1))
            
    ref_coords_2d = torch.stack(ref_coords_2d, dim=0) # (B, N, 2)
    source_coords_2d = {idx: torch.stack(source_coords_2d[idx], dim=0) for idx in source_indices}
    
    # 5. Extract patches and compute NCC
    # Convert pixel coordinates to normalized [-1, 1] for grid_sample
    H, W = ref_image.shape[1], ref_image.shape[2]
    norm_scale = torch.tensor([W, H], device=ref_image.device)
    
    ref_norm = 2.0 * ref_coords_2d / norm_scale - 1.0
    ref_norm = ref_norm.unsqueeze(2) # (B, N, 1, 2)
    
    ref_patches = F.grid_sample(
        ref_image.permute(0, 3, 1, 2), # (B, 3, H, W)
        ref_norm,
        mode='bilinear',
        padding_mode='zeros',
        align_corners=False
    ) # (B, 3, N, patch_size, patch_size)
    ref_patches = ref_patches.permute(0, 2, 1, 3, 4) # (B, N, 3, patch_size, patch_size)
    
    scores = []
    for src_idx in source_indices:
        src_image = images[:, src_idx]
        src_norm = 2.0 * source_coords_2d[src_idx] / norm_scale - 1.0
        src_norm = src_norm.unsqueeze(2)
        
        src_patches = F.grid_sample(
            src_image.permute(0, 3, 1, 2),
            src_norm,
            mode='bilinear',
            padding_mode='zeros',
            align_corners=False
        )
        src_patches = src_patches.permute(0, 2, 1, 3, 4)
        
        # Flatten patches for NCC computation
        ref_flat = ref_patches.view(ref_patches.shape[0], ref_patches.shape[1], -1)
        src_flat = src_patches.view(src_patches.shape[0], src_patches.shape[1], -1)
        
        # Compute NCC: Cov / sqrt(Var_ref * Var_src)
        ref_mean = ref_flat.mean(dim=-1, keepdim=True)
        src_mean = src_flat.mean(dim=-1, keepdim=True)
        
        ref_centered = ref_flat - ref_mean
        src_centered = src_flat - src_mean
        
        cov = (ref_centered * src_centered).mean(dim=-1)
        var_ref = (ref_centered ** 2).mean(dim=-1)
        var_src = (src_centered ** 2).mean(dim=-1)
        
        ncc = cov / torch.sqrt(var_ref * var_src + 1e-8)
        scores.append(ncc)
        
    # Stack scores: (B, N, N_sources)
    scores_tensor = torch.stack(scores, dim=-1)
    
    # Select top m scores (highest NCC values)
    top_scores, _ = torch.topk(scores_tensor, m, dim=-1) # (B, N, m)
    
    # Compute loss: 1/(m*D_P) * sum(1 - Score)
    inconsistency = 1.0 - top_scores # (B, N, m)
    loss_per_point = inconsistency.mean(dim=-1) # (B, N)
    loss = loss_per_point.mean() # Scalar
    
    return loss
```

## Subtopics

### Learned Photometric Consistency
A data-driven variant that casts photo-consistency as a classification task to handle noisy real images and non-Lambertian surfaces [S2]. It uses a shared-weight image encoder to extract features from $N$ multi-view RGB images, projects them to multi-scale local features for each 3D point, and combines them via an attention-based encoder into a single multi-view aware feature [S2]. An MLP then outputs a photo-consistency score between 0 and 1 [S2]. Training data is generated by reconstructing surfaces from ground truth point clouds using the Screened Poisson algorithm, rendering depth maps, and sampling positive (on-surface) and negative (off-surface) points with balanced sampling [S2]. To ensure invariance to the number of cameras, camera groups are formed using a soft nearest neighbor approach: a random first camera is selected, its $K'$ nearest neighbors are computed, and $K-1$ cameras are randomly chosen from them, where $K \in [4, 10]$, $K' = \min(2K, 15)$, and total cameras $N \in \{49, 64\}$ [S2].

## Operating characteristics
*   **Time Complexity:** The method requires computing gradients for all sampled points, which is $O(N)$ where $N$ is the number of points [G]. The photometric scoring involves patch extraction and NCC computation for $m$ source images per point, adding a factor of $m$ [G]. Thus, the loss computation is roughly $O(N \cdot m)$ [G].
*   **Memory Complexity:** Requires storing the SDF network parameters, the gradients for all points, and the image patches for all points and source views [G]. This scales linearly with $N$ and $m$ [G].
*   **Strengths:** It provides strong geometric constraints directly on the implicit surface, improving accuracy on noisy data where explicit depth maps are unreliable [S1, unofficial]. It is robust to noise because it relies on the consistency of the implicit field's gradient rather than discrete depth values [S1, unofficial].
*   **Limitations:** It assumes Lambertian surfaces for the standard NCC score, which may fail on highly reflective or non-Lambertian surfaces unless the Learned variant is used [S2]. The projection step requires differentiable SDF gradients [S1, unofficial].
*   **When to Use:** Use when reconstructing surfaces from noisy multi-view data where depth estimation is unreliable, and the scene has sufficient texture for photometric matching [S1, unofficial].
*   **When Not to Use:** Not given in the sources.

## Background
The method was introduced in "Point-NeuS: Point-Guided Neural Implicit Surface Reconstruction by Volume Rendering" [S1, unofficial]. It builds upon the idea of using multi-view stereo (MVS) photometric consistency to regularize neural implicit surfaces [S1, unofficial]. The core insight is that points projected onto the implicit surface should exhibit consistent appearance across multiple views, providing a strong geometric prior [S1, unofficial]. The learned variant was proposed in "Multi-View Reconstruction Using Signed Ray Distance Functions (SRDF)" to address limitations of hand-crafted photometric priors on real-world noisy data [S2].
