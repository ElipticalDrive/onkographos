# Reliable Depth Estimation via Reprojection

Also called: Reprojection-based Depth Reliability Masking, Intensity-based Depth Consistency Check

## Overview
Reliable Depth Estimation via Reprojection identifies trustworthy monocular depth estimates by verifying their geometric consistency across views [S1]. It solves noisy depth supervision in radiance field optimization by distinguishing between reliable and unreliable depth predictions using intensity-based reprojection errors [S1]. It sets itself apart from [Monocular Depth Consistency Loss](4668-monocular-depth-consistency-loss.md) by using explicit geometric reprojection checks rather than direct loss minimization, and from [Depth Supervision Loss (Laug)](8111-depth-supervision-loss-laug.md) by providing reliability masks that enable robust, gradient-stopped supervision [S1].

## How it works
**Inputs and Outputs:**
- Input: Rendered depth maps $z_m$ (main model) and $z_a$ (augmented model), corresponding camera poses, and the nearest training view's image data [S1].
- Output: Binary reliability masks $m_m$ and $m_a$ indicating which pixels have reliable depth estimates [S1].

**Data Structures:**
- Depth maps: 2D arrays of floating-point values representing depth along the viewing ray [S1].
- Image patches: 2D arrays of pixel intensities (RGB or grayscale) from the nearest training view [S1].
- Masks: 2D boolean or binary arrays of the same spatial dimensions as the depth map [S1].

**Steps:**
1. **Reprojection:** For a given pixel $q$ in the current view with predicted depth $z$, unproject $q$ and $z$ to 3D space using the current camera pose. Then, project this 3D point into the nearest training view using that view's camera pose to obtain the reprojected pixel coordinates [S1].
2. **Patch Extraction:** Extract a patch centered at the reprojected coordinates from the nearest training view's image [S1].
3. **Intensity Comparison:** Compute the Mean Squared Error (MSE) of intensities between the reprojected patch and the corresponding patch in the nearest training view. Let $e_m$ be the MSE for the main model's depth $z_m$ and $e_a$ be the MSE for the augmented model's depth $z_a$ [S1].
4. **Thresholding:** Define a threshold $e_\tau$. A depth estimate is considered potentially reliable only if its reprojection MSE is less than $e_\tau$ [S1].
5. **Mask Computation:** Compute the reliability mask $m_a$ for the augmented model as:
   $$
   m_a = \begin{cases} 
   1 & \text{if } (e_a \le e_m) \text{ and } (e_a \le e_\tau) \\
   0 & \text{otherwise}
   \end{cases}
   $$
   Compute the reliability mask $m_m$ for the main model similarly, checking if $e_m \le e_a$ and $e_m \le e_\tau$ [S1].
6. **Supervision Application:** Use these masks to select reliable depths for supervision [S1]. For example, in the [Depth Supervision Loss (Laug)](8111-depth-supervision-loss-laug.md), the loss is computed as:
   $$
   \mathcal{L}_{aug} = \mathbb{1}\{m_a=1\} \odot \| z_m - \nabla(z_a) \|_2 + \mathbb{1}\{m_m=1\} \odot \| \nabla(z_m) - z_a \|_2
   $$
   where $\odot$ is element-wise product, $\mathbb{1}$ is the indicator function, and $\nabla$ is the stop-gradient operator [S1].

**Parameters:**
- $e_\tau$: Reprojection MSE threshold. Not given in the sources.
- Patch size: Not given in the sources.

**Edge Cases and Pitfalls:**
- Specular regions: Intensities may not match between views, leading to masks being zero. This results in fewer pixels being supervised but avoids supervision with incorrect depth estimates [S1].
- Both models incorrect: If both $e_m$ and $e_a$ exceed $e_\tau$, both masks are zero, and no supervision is applied for those pixels [S1].
- Precision: Reprojection accuracy depends on correct camera poses and depth values [G].

**Pseudocode:**
```python
def compute_reprojection_masks(depth_main, depth_aug, current_view_image, camera_pose, nearest_view_image, nearest_view_pose, threshold_e_tau, patch_size):
    """
    Computes binary reliability masks based on reprojection intensity consistency.
    
    Args:
        depth_main: 2D array of depth values for the main model.
        depth_aug: 2D array of depth values for the augmented model.
        current_view_image: 2D array of pixel intensities for the current view.
        camera_pose: 4x4 matrix for the current view.
        nearest_view_image: 2D array of pixel intensities for the nearest training view.
        nearest_view_pose: 4x4 matrix for the nearest training view.
        threshold_e_tau: Float, MSE threshold for reliability.
        patch_size: Int, size of the patch to extract.
        
    Returns:
        mask_main: 2D binary array for the main model.
        mask_aug: 2D binary array for the augmented model.
    """
    height, width = depth_main.shape
    mask_main = [[0] * width for _ in range(height)]
    mask_aug = [[0] * width for _ in range(height)]
    
    for y in range(height):
        for x in range(width):
            z_m = depth_main[y][x]
            z_a = depth_aug[y][x]
            
            if z_m <= 0 or z_a <= 0:
                continue
            
            # Reproject for main model
            proj_m = unproject_and_project(x, y, z_m, camera_pose, nearest_view_pose, width, height)
            if proj_m is None:
                continue
            x_m, y_m = proj_m
            
            # Reproject for augmented model
            proj_a = unproject_and_project(x, y, z_a, camera_pose, nearest_view_pose, width, height)
            if proj_a is None:
                continue
            x_a, y_a = proj_a
            
            # Compute MSE for main model
            mse_m = compute_patch_mse(current_view_image, nearest_view_image, x, y, x_m, y_m, patch_size)
            
            # Compute MSE for augmented model
            mse_a = compute_patch_mse(current_view_image, nearest_view_image, x, y, x_a, y_a, patch_size)
            
            # Compute masks
            if mse_a <= mse_m and mse_a <= threshold_e_tau:
                mask_aug[y][x] = 1
            if mse_m <= mse_a and mse_m <= threshold_e_tau:
                mask_main[y][x] = 1
                
    return mask_main, mask_aug

def unproject_and_project(x, y, z, camera_pose, nearest_view_pose, width, height):
    # Unproject to 3D in camera space
    inv_proj = invert_3x3(camera_pose[:3, :3])
    ndc_x = (2.0 * x / width) - 1.0
    ndc_y = (2.0 * y / height) - 1.0
    ray_dir_cam = multiply_3x3_vector(inv_proj, [ndc_x, ndc_y, 1.0])
    ray_dir_cam = normalize_3(ray_dir_cam)
    point_cam = scale_3(ray_dir_cam, z)
    # Transform to world space
    point_world = transform_point_to_world(point_cam, camera_pose)
    
    # Project to nearest view
    inv_nearest_pose = invert_4x4(nearest_view_pose)
    point_nearest_cam = transform_point_to_camera(point_world, inv_nearest_pose)
    z_cam = point_nearest_cam[2]
    if z_cam <= 0:
        return None
        
    proj_nearest = nearest_view_pose[:3, :3]
    point_ndc = multiply_3x3_vector(proj_nearest, point_nearest_cam)
    ndc_x = point_ndc[0] / z_cam
    ndc_y = point_ndc[1] / z_cam
    x_out = (ndc_x + 1.0) * width / 2.0
    y_out = (ndc_y + 1.0) * height / 2.0
    return (x_out, y_out)

def compute_patch_mse(img1, img2, x1, y1, x2, y2, patch_size):
    half = patch_size // 2
    mse_sum = 0.0
    count = 0
    for dy in range(-half, half + 1):
        for dx in range(-half, half + 1):
            px1, py1 = int(x1) + dx, int(y1) + dy
            px2, py2 = int(x2) + dx, int(y2) + dy
            if 0 <= px1 < img1.shape[1] and 0 <= py1 < img1.shape[0] and \
               0 <= px2 < img2.shape[1] and 0 <= py2 < img2.shape[0]:
                diff = img1[py1][px1] - img2[py2][px2]
                mse_sum += diff * diff
                count += 1
    return mse_sum / count if count > 0 else float('inf')
```

## Subtopics

### [Depth Supervision Loss (Laug)](8111-depth-supervision-loss-laug.md)
Depth Supervision Loss (Laug) enforces geometric consistency by minimizing the discrepancy between rendered depth maps and ground-truth depth estimates during radiance field optimization. It distinguishes itself from sibling methods by combining a dynamic adaptive masking strategy to handle unreliable depth regions with a robust, gradient-stopped reliability weighting mechanism that prevents error propagation from noisy depth priors.

### [Depth Consistency Check / Depth Outlier Removal](9363-depth-consistency-check-depth-outlier-removal.md)
This method filters noisy depth data by unprojecting depth maps to 3D space and reprojecting them into nearby views to verify geometric consistency. It solves the problem of incorrect depth supervision caused by moving objects, ill-posed views, and occlusions in street view scenarios. It sets itself apart from [Depth Supervision Loss (Laug)](8111-depth-supervision-loss-laug.md) by using explicit geometric reprojection checks rather than direct loss minimization, and from [Multi-view Consistency Depth Filtering](12319-multi-view-consistency-depth-filtering.md) by focusing on pairwise reprojection error thresholds rather than complex multi-view voting or probabilistic models.

### [Multi-view Consistency Depth Filtering](12319-multi-view-consistency-depth-filtering.md)
Multi-view Consistency Depth Filtering is a mechanism to verify the accuracy and reliability of monocular depth estimates before distilling them into a radiance field. It generates a binary confidence map by measuring the consistency between scaled monocular depth predictions and rendered NeRF depth across multiple viewpoints, filtering out inaccurate rays. It differs from sibling methods by explicitly leveraging the geometric consistency of the learned NeRF itself as a ground-truth proxy to mask noisy monocular depth, rather than relying solely on static thresholds or external consistency checks.

### Sparse SFM Depth Consistency Loss
Enforces consistency between rendered depth and projected sparse 3D points from Structure-from-Motion (SFM) to handle real-world scenes with noisy poses [S2].
- Obtain sparse 2D key points and corresponding 3D point locations from SFM algorithms like COLMAP [S2].
- Given an image and its camera pose, project visible 3D points into camera space [S2].
- Use the z-value of the projected points as the sparse depth $D_{sfm}$ for the corresponding 2D key points [S2].
- Apply an L2 loss between the rendered depth $D$ and the sparse depth $D_{sfm}$ [S2].

## Operating characteristics
- **Time Complexity:** The method involves unprojecting and projecting pixels, which is $O(N)$ where $N$ is the number of pixels. The patch extraction and MSE computation add a constant factor depending on patch size [G].
- **Memory Complexity:** Requires storing depth maps, image patches, and masks. Memory usage is proportional to the image resolution and patch size [G].
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales linearly with image resolution [G].
- **Strengths:** Robust to noisy depth priors by filtering out unreliable estimates. Simple to implement [S1].
- **Limitations:** Relies on accurate camera poses. May fail in specular or textureless regions where intensity matching is unreliable [S1].
- **When to use:** When optimizing radiance fields with noisy monocular depth estimates and reliable camera poses are available [S1].
- **When not to use:** When camera poses are highly inaccurate or when scenes have significant specularities or textureless regions [S1].

## Background
Introduced in [S1] for regularizing sparse input radiance fields and in [S2] for implicit surface reconstruction with 3D Gaussian Splatting. It is used in scenarios where monocular depth estimates are used as supervision for neural radiance fields or Gaussian splatting, particularly in real-world datasets like DTU and Tanks & Temples [S2].
