# Reliable Depth Estimation via Reprojection
Also called: Reprojection-based Depth Reliability Masking
## Overview
This method selects reliable monocular depth estimates by reprojecting them into a nearest training view and comparing the resulting image intensities against the ground-truth view. It solves the problem of noisy depth supervision in sparse-view radiance field optimization by distinguishing between correct and incorrect depth predictions using a reprojection consistency metric. It sets itself apart from sibling methods by relying on explicit geometric reprojection error thresholds rather than direct loss minimization or static confidence maps [S1].
## How it works
**Inputs and Outputs:**
- Input: A rendered depth map $z_m$ from a main model, an augmented depth map $z_a$ (from a smoothing or Lambertian augmentation), and the corresponding nearest training view image.
- Output: A reliability mask $m_a$ (for the augmented model) and $m_m$ (for the main model), and a supervised depth loss $L_{aug}$.

**Data Structures:**
- Depth maps $z_m, z_a$: 2D arrays of float values representing depth per pixel.
- Training view image: 2D array of RGB intensities.
- Masks $m_m, m_a$: 2D boolean or binary arrays of the same spatial dimensions as the depth maps.

**Parameters:**
- Threshold $e_\tau$: A scalar value defining the maximum allowable Mean Squared Error (MSE) for a depth estimate to be considered reliable. [S1]
- Typical values: Not given in the sources.

**Steps:**
1. **Reprojection:** For each pixel in the current view, unproject the depth value ($z_m$ or $z_a$) to 3D space, then project it into the nearest training view to obtain a reprojected patch.
2. **MSE Calculation:** Compute the Mean Squared Error (MSE) of intensities between the reprojected patch and the corresponding patch in the nearest training view. Let $e_m$ be the MSE for $z_m$ and $e_a$ be the MSE for $z_a$.
3. **Mask Generation:** Compute the reliability mask $m_a$ for the augmented model. The mask is 1 if the augmented model's reprojection error is lower than the main model's AND below the threshold $e_\tau$; otherwise, it is 0.
   $$
   m_a = \begin{cases} 
   1 & \text{if } (e_a \le e_m) \text{ and } (e_a \le e_\tau) \\
   0 & \text{otherwise}
   \end{cases}
   $$
   Compute the reliability mask $m_m$ for the main model similarly, checking if $e_m \le e_a$ and $e_m \le e_\tau$.
4. **Loss Computation:** Compute the depth supervision loss $L_{aug}$ using element-wise multiplication ($\odot$) with the masks and the stop-gradient operator ($\nabla$).
   $$
   L_{aug} = \mathbb{1}\{m_a = 1\} \odot \| z_m - \nabla(z_a) \|_2 + \mathbb{1}\{m_m = 1\} \odot \| \nabla(z_m) - z_a \|_2
   $$
   where $\mathbb{1}$ is the indicator function.
5. **Aggregation:** If multiple augmentations are used (e.g., smoothing and Lambertian), compute separate losses $L_s$ and $L_l$ and sum them for the final depth supervision loss.

**Edge Cases and Pitfalls:**
- Specular regions: Intensities may not match during reprojection, causing masks to be zero. This results in fewer pixels being supervised, but prevents supervision with incorrect depth estimates [S1].
- Both models incorrect: If both $e_m$ and $e_a$ exceed $e_\tau$, no supervision is applied for that pixel.

**Pseudocode:**
```python
def compute_reprojection_mask(z_main, z_aug, nearest_view_img, camera_params, threshold_e_tau):
    """
    Computes reliability masks for main and augmented depth maps based on reprojection error.
    
    Args:
        z_main: 2D array, depth map from main model.
        z_aug: 2D array, depth map from augmented model.
        nearest_view_img: 2D array, RGB intensities of the nearest training view.
        camera_params: Object containing intrinsic and extrinsic matrices for current and nearest views.
        threshold_e_tau: Float, maximum allowed MSE for reliability.
        
    Returns:
        m_main: 2D array, reliability mask for main model.
        m_aug: 2D array, reliability mask for augmented model.
        e_main: 2D array, reprojection MSE for main model.
        e_aug: 2D array, reprojection MSE for augmented model.
    """
    # Step 1: Reproject depths to nearest view
    # Unproject z_main and z_aug to 3D points using current camera params
    points_3d_main = unproject_depth(z_main, camera_params.current)
    points_3d_aug = unproject_depth(z_aug, camera_params.current)
    
    # Project 3D points to nearest view to get reprojected coordinates
    coords_main = project_to_view(points_3d_main, camera_params.nearest)
    coords_aug = project_to_view(points_3d_aug, camera_params.nearest)
    
    # Sample intensities from nearest view at reprojected coordinates
    # Note: Bilinear interpolation is used for sampling
    img_main_reprojected = sample_image(nearest_view_img, coords_main)
    img_aug_reprojected = sample_image(nearest_view_img, coords_aug)
    
    # Step 2: Compute MSE of intensities
    # Compare reprojected patches with the actual nearest view image
    # Assuming nearest_view_img is aligned with the projection coordinates
    e_main = mean_squared_error(img_main_reprojected, nearest_view_img)
    e_aug = mean_squared_error(img_aug_reprojected, nearest_view_img)
    
    # Step 3: Generate masks
    # Mask for augmented model: 1 if e_aug <= e_main AND e_aug <= threshold_e_tau
    m_aug = (e_aug <= e_main) & (e_aug <= threshold_e_tau)
    
    # Mask for main model: 1 if e_main <= e_aug AND e_main <= threshold_e_tau
    m_main = (e_main <= e_aug) & (e_main <= threshold_e_tau)
    
    return m_main, m_aug, e_main, e_aug

def compute_depth_supervision_loss(z_main, z_aug, m_main, m_aug):
    """
    Computes the depth supervision loss using reliability masks and stop-gradient.
    
    Args:
        z_main: 2D array, depth map from main model.
        z_aug: 2D array, depth map from augmented model.
        m_main: 2D array, reliability mask for main model.
        m_aug: 2D array, reliability mask for augmented model.
        
    Returns:
        loss: Float, the computed loss value.
    """
    # Stop-gradient operator prevents gradients from flowing through the reference depth
    z_main_stopped = stop_gradient(z_main)
    z_aug_stopped = stop_gradient(z_aug)
    
    # Compute L2 norms where masks are active
    # Element-wise product with mask selects reliable pixels
    term_aug = m_aug * l2_norm(z_main - z_aug_stopped)
    term_main = m_main * l2_norm(z_main_stopped - z_aug)
    
    # Sum over all pixels (or mean, depending on implementation convention)
    loss = sum(term_aug) + sum(term_main)
    
    return loss
```
## Subtopics

### [Depth Supervision Loss (Laug)](8111-depth-supervision-loss-laug.md)
Depth Supervision Loss (Laug) enforces geometric consistency by minimizing the discrepancy between rendered depth maps and ground-truth depth estimates during radiance field optimization. It distinguishes itself from sibling methods by combining a dynamic adaptive masking strategy to handle unreliable depth regions with a robust, gradient-stopped reliability weighting mechanism that prevents error propagation from noisy depth priors.

### [Depth Consistency Check / Depth Outlier Removal](9363-depth-consistency-check-depth-outlier-removal.md)
This method filters noisy depth data by unprojecting depth maps to 3D space and reprojecting them into nearby views to verify geometric consistency. It solves the problem of incorrect depth supervision caused by moving objects, ill-posed views, and occlusions in street view scenarios. It sets itself apart from [Depth Supervision Loss (Laug)](8111-depth-supervision-loss-laug.md) by using explicit geometric reprojection checks rather than direct loss minimization, and from [Multi-view Consistency Depth Filtering](12319-multi-view-consistency-depth-filtering.md) by focusing on pairwise reprojection error thresholds rather than complex multi-view voting or probabilistic models.

### [Multi-view Consistency Depth Filtering](12319-multi-view-consistency-depth-filtering.md)
Multi-view Consistency Depth Filtering is a mechanism to verify the accuracy and reliability of monocular depth estimates before distilling them into a radiance field. It generates a binary confidence map by measuring the consistency between scaled monocular depth predictions and rendered NeRF depth across multiple viewpoints, filtering out inaccurate rays. It differs from sibling methods by explicitly leveraging the geometric consistency of the learned NeRF itself as a ground-truth proxy to mask noisy monocular depth, rather than relying solely on static thresholds or external consistency checks.

## Operating characteristics
- Time complexity: Proportional to the number of pixels, as reprojection and MSE calculation are performed per pixel.
- Memory complexity: Requires storage for depth maps, reprojected coordinates, and masks.
- Strengths: Effectively filters out incorrect depth estimates in specular or ambiguous regions by relying on geometric consistency [S1].
- Limitations: Relies on the availability of a nearest training view; performance degrades if the nearest view is too distant or has significant viewpoint change [S1].
- When to use: Sparse-view radiance field optimization where monocular depth priors are noisy.
- When not to use: Dense-view scenarios where direct depth supervision is sufficient, or when no training views are available for reprojection.
