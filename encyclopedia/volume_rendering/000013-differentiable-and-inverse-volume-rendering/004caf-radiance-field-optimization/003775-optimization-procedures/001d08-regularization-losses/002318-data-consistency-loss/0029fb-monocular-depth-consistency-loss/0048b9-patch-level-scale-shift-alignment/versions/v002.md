# Patch-level Scale-Shift Alignment

Also called: Patch-level fitting, Patch-level scale-shift adjustment, Patch-wise scale-shift fitting, Patch-wise scale-shift invariant loss

## Overview
Patch-level Scale-Shift Alignment is a regularization technique used in differentiable volume rendering to align predicted monocular depth maps with reference or ground truth depths by optimizing scale and shift parameters locally per image patch rather than globally per image [S1, unofficial]. It solves the problem of local depth misalignment errors that arise when a single global affine transformation fails to account for depth inconsistencies among different objects within a scene [S1, unofficial]. Unlike image-level fitting, which computes a single scale and shift for the entire depth map, this method adapts locally, significantly reducing misalignment errors in rendered depth maps [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs:**
    *   $S$: The set of images in the scene [S1, unofficial].
    *   $D^*_i(p)$: The predicted depth value at pixel $p$ for image $i \in S$ [S1, unofficial].
    *   $\bar{D}_i(p)$: The target depth value at pixel $p$ for image $i \in S$ [S1, unofficial].
    *   $P$: The set of pixels belonging to a specific non-overlapping patch [S1, unofficial].
*   **Outputs:**
    *   $w_i$: The scale parameter for the patch [S1, unofficial].
    *   $q_i$: The shift parameter for the patch [S1, unofficial].
    *   $L$: The total alignment loss [S1, unofficial].

**Data Structures**
*   **Patch Grid:** The depth map is partitioned into non-overlapping square patches [S1, unofficial]. The standard resolution for these patches is $80 \times 80$ pixels [S1, unofficial]. This size balances local adaptability with computational overhead [S1, unofficial].

**Formulas**
The optimization objective for a single patch minimizes the alignment error between the scaled predicted depth and the target depth [S1, unofficial]:
$$ (w_i, q_i) = \arg \min_{w_i, q_i} \sum_{p \in P} \| (w_i D^*_i(p) + q_i) - \bar{D}_i(p) \| $$

The problem is rewritten as a closed-form least-squares solution [S1, unofficial]. Let $h_i = [w_i, q_i]^T$ and $\vec{D}_i(p) = [D^*_i(p), 1]^T$ [S1, unofficial]. The optimal parameters are computed as:
$$ h_{opt} = \left( \sum_{p \in P} \vec{D}_i(p) \vec{D}_i(p)^T \right)^{-1} \left( \sum_{p \in P} \vec{D}_i(p) \bar{D}_i(p) \right) $$

The total loss $L$ over the scene set $S$ sums the residual magnitudes for all patches [S1, unofficial]:
$$ L = \sum_{I_i \in S} \sum_{p \in P} \| (w_i D^*_i(p) + q_i) - \bar{D}_i(p) \| $$

**Numbered Steps**
1.  **Partition:** Divide the input depth map into non-overlapping patches of size $80 \times 80$ pixels [S1, unofficial].
2.  **Vector Construction:** For each pixel $p$ in the current patch, construct the feature vector $\vec{D}_i(p) = [D^*_i(p), 1]^T$ and identify the target depth $\bar{D}_i(p)$ [S1, unofficial].
3.  **Accumulate Matrices:** Compute the sum of outer products $\mathbf{A} = \sum_{p \in P} \vec{D}_i(p) \vec{D}_i(p)^T$ and the sum of cross-terms $\mathbf{b} = \sum_{p \in P} \vec{D}_i(p) \bar{D}_i(p)$ for the current patch [S1, unofficial].
4.  **Solve:** Calculate the optimal scale and shift vector $h_{opt} = [w_i, q_i]^T$ by solving the linear system $\mathbf{A} h_{opt} = \mathbf{b}$ [S1, unofficial].
5.  **Compute Loss:** Calculate the residual error $\| (w_i D^*_i(p) + q_i) - \bar{D}_i(p) \|$ for all pixels in the patch and sum them to contribute to the total loss $L$ [S1, unofficial].
6.  **Iterate:** Repeat steps 2 through 5 for all patches in the image and all images in the batch or scene [S1, unofficial].

**Pseudocode**
```python
import numpy as np

def patch_level_scale_shift_alignment(predicted_depth, target_depth, patch_size=80):
    """
    Computes the patch-level scale-shift alignment loss.
    
    Args:
        predicted_depth (np.ndarray): 2D array of shape (H, W), D*_i(p).
        target_depth (np.ndarray): 2D array of shape (H, W), D_bar_i(p).
        patch_size (int): Size of the square patches (default 80).
        
    Returns:
        float: Total loss L.
        np.ndarray: Array of scale parameters w_i per patch.
        np.ndarray: Array of shift parameters q_i per patch.
    """
    H, W = predicted_depth.shape
    total_loss = 0.0
    scales = []
    shifts = []
    
    for y in range(0, H, patch_size):
        for x in range(0, W, patch_size):
            y_end = min(y + patch_size, H)
            x_end = min(x + patch_size, W)
            
            p_pred = predicted_depth[y:y_end, x:x_end]
            p_target = target_depth[y:y_end, x:x_end]
            
            pred_flat = p_pred.flatten()
            target_flat = p_target.flatten()
            
            D_vec = np.column_stack((pred_flat, np.ones_like(pred_flat)))
            
            A = D_vec.T @ D_vec
            b = D_vec.T @ target_flat
            
            try:
                h_opt = np.linalg.solve(A, b)
            except np.linalg.LinAlgError:
                h_opt = np.array([1.0, 0.0])
                
            w_i, q_i = h_opt
            aligned_pred = w_i * pred_flat + q_i
            
            patch_loss = np.sum(np.abs(aligned_pred - target_flat))
            
            total_loss += patch_loss
            scales.append(w_i)
            shifts.append(q_i)
            
    return total_loss, np.array(scales), np.array(shifts)
```

**Parameters**
*   **Patch Resolution:** $80 \times 80$ pixels [S1, unofficial].

**Edge Cases and Pitfalls**
*   **Singular Matrices:** If a patch contains constant predicted depth, the matrix $\mathbf{A}$ becomes singular [G]. A fallback to identity scaling ($w=1, q=0$) or a pseudo-inverse should be applied [G].
*   **Boundary Conditions:** Patches at image boundaries contain fewer than $80 \times 80$ pixels [G]. The iteration bounds must clamp to the image dimensions to avoid index errors [G].
*   **Depth Inversion:** Monocular depth estimators may output inverse or normalized depth [G]. The predicted and target depths must be converted to the same metric space before alignment [G].

## Subtopics

### Image-Level Fitting
Computes a single scale and shift for the entire depth map [S1, unofficial]. It is simpler to implement but yields higher misalignment errors in scenes with varying depth scales compared to patch-level fitting [S1, unofficial]. Choose it when global depth consistency is sufficient and computational overhead must be minimized [G].

### Reliable Depth Estimation via Reprojection
Uses reprojection consistency rather than direct depth alignment [7293-reliable-depth-estimation-via-reprojection.md]. It enforces geometric consistency across views instead of fitting affine transformations to monocular priors [G].

### Pseudo-depth Supervised Loss
Uses pseudo-depth labels for supervision, potentially without explicit scale-shift alignment [7487-pseudo-depth-supervised-loss.md]. It relies on teacher-student distillation frameworks rather than closed-form parameter optimization [G].

### Self-Supervised Depth Losses
Relies on photometric consistency without explicit depth priors [9374-self-supervised-depth-losses.md]. It optimizes depth by minimizing reconstruction error across views instead of aligning to external monocular estimates [G].

### Depth Prior Loss
General term for losses incorporating depth priors, which may or may not use patch-level alignment [10801-depth-prior-loss.md]. It encompasses various strategies for integrating external depth information into radiance field optimization [G].

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of pixels, as it involves a single pass over pixels to accumulate sums for the least-squares solution [G]. The matrix inversion is $O(1)$ per patch since it operates on a fixed $2 \times 2$ matrix [G].
*   **Memory Complexity:** $O(1)$ auxiliary memory per patch for storing the accumulated sums $\mathbf{A}$ and $\mathbf{b}$ [G].
*   **Strengths:** Significantly reduces misalignment errors compared to image-level fitting, especially in scenes with multiple objects at different depths [S1, unofficial].
*   **Limitations:** Computationally more expensive than image-level fitting due to per-patch optimization [S1, unofficial]. Performance is sensitive to patch size selection; too small leads to noise, too large reduces adaptability [S1, unofficial].
*   **When to Use:** When training NeRFs from sparse inputs with monocular depth priors, particularly when global alignment fails to capture local depth variations [S1, unofficial].
*   **When Not to Use:** When computational resources are extremely limited and global alignment suffices, or when depth maps are already well-aligned globally [G].

## Background
Patch-level Scale-Shift Alignment was introduced in the DaRF (Radiance Fields from Sparse Inputs with Monocular Depth Adaptation) paper [S1, unofficial]. It builds upon the concept of scale-shift invariant loss [39] and least-square alignment [53] used in monocular depth estimation prior distillation [S1, unofficial]. The method was developed to address the limitations of image-level fitting, which computes a single set of scale and shift values for an entire depth map, leading to errors in rendered depth maps due to depth inconsistencies among objects [S1, unofficial]. It is applied in DaRF to refine monocular depth estimation outputs during sparse-view NeRF training [S1, unofficial].
