# Depth-free motion evidence (Epipolar Residual)

Also called: Epipolar Line Distance for Motion Evidence, Epipolar Residual, Epipolar Residual for Depth-Free Motion Evidence

## Overview
A method to detect motion without requiring correct depth, by measuring the distance of measured correspondences to their epipolar lines in the target frame [S1, unofficial]. It measures motion evidence by calculating the distance from each measured correspondence to its epipolar line in pixels, using no correct depth, only camera pose, making it robust against noisy monocular depth that defeats rigid-flow residuals [S1, unofficial]. This approach serves as a geometry confidence metric within the broader framework of [Geometry Confidence Measurement](15151-geometry-confidence-measurement.md), distinguishing true motion from depth estimation errors by leveraging the geometric constraint that static points must lie on their epipolar lines regardless of depth.

## How it works
**Inputs and Outputs**
- **Inputs**:
  - Measured optical flow field $\mathbf{F}$ of shape $(H, W, 2)$, where $H$ and $W$ are height and width.
  - Camera poses for source frame $i$ and target frame $j$: Rotation matrices $R_i, R_j \in \mathbb{R}^{3 \times 3}$ and translation vectors $C_i, C_j \in \mathbb{R}^3$.
  - Camera intrinsics: focal lengths $f_x, f_y$ and principal point $(c_x, c_y)$.
- **Outputs**:
  - A confidence map (or residual map) $D \in \mathbb{R}^{H \times W}$ representing the point-to-line distance in pixels for each pixel.

**Data Structures**
- Pixel coordinate grids $X_s, Y_s \in \mathbb{R}^{H \times W}$ containing the x and y coordinates of each pixel in the source frame.
- Arbitrary depth values $z_l$ (near) and $z_f$ (far) used to construct the epipolar line. Typical values are $z_l = 0.85$ and $z_f = 0.15$ [S1, unofficial].

**Steps**
1. **Construct Source Pixel Grids**: Create grids of pixel coordinates $(x_s, y_s)$ for the source frame $i$ with dimensions $H \times W$.
2. **Define Arbitrary Depths**: Select two arbitrary depth values, $z_l$ and $z_f$, to define the epipolar line. These values do not need to correspond to actual scene depths [S1, unofficial].
3. **Reproject to Target Frame**: For each pixel $(x_s, y_s)$, convert to normalized camera coordinates and then to 3D points at depths $z_l$ and $z_f$ in frame $i$. Transform these 3D points into frame $j$ using the relative pose $(R_j R_i^T, C_j - R_j R_i^T C_i)$. Project these 3D points back to the image plane of frame $j$ using intrinsics to obtain two 2D points: $(u_1, v_1)$ corresponding to $z_l$ and $(u_2, v_2)$ corresponding to $z_f$.
4. **Compute Line Geometry**: Calculate the direction vector $\mathbf{d} = (u_2 - u_1, v_2 - v_1)$ and its norm $\|\mathbf{d}\|$. Identify valid pixels where both projections are finite and $\|\mathbf{d}\| > \epsilon$ (e.g., $\epsilon = 10^{-3}$) to avoid degeneracy at the epipole [S1, unofficial].
5. **Compute Line Normal**: For valid pixels, compute the unit normal vector $\mathbf{n} = (n_x, n_y)$ to the epipolar line. This is typically $(-d_y, d_x) / \|\mathbf{d}\|$ or $(d_y, -d_x) / \|\mathbf{d}\|$ depending on coordinate system orientation.
6. **Determine Correspondence**: Calculate the measured correspondence in frame $j$ by adding the measured flow to the original pixel coordinates: $(x_c, y_c) = (x_s + F_x, y_s + F_y)$.
7. **Compute Point-to-Line Distance**: Calculate the distance from the correspondence $(x_c, y_c)$ to the epipolar line defined by point $(u_1, v_1)$ and normal $\mathbf{n}$. The distance is given by the absolute dot product: $D = |n_x(x_c - u_1) + n_y(y_c - v_1)|$. Reshape the result to image dimensions $H \times W$.

**Pseudocode**
```python
import numpy as np

def compute_epipolar_residual(
    flow: np.ndarray,  # Shape (H, W, 2)
    pose_i: np.ndarray,  # 4x4 transformation matrix from world to frame i
    pose_j: np.ndarray,  # 4x4 transformation matrix from world to frame j
    intrinsics: np.ndarray,  # [fx, fy, cx, cy]
    z_near: float = 0.85,
    z_far: float = 0.15,
    eps: float = 1e-3
) -> np.ndarray:
    """
    Compute depth-free motion evidence using epipolar residuals.
    
    Args:
        flow: Measured optical flow (H, W, 2).
        pose_i: 4x4 pose matrix of source frame.
        pose_j: 4x4 pose matrix of target frame.
        intrinsics: [fx, fy, cx, cy].
        z_near, z_far: Arbitrary depths for epipolar line construction.
        eps: Minimum norm for line direction to avoid degeneracy.
        
    Returns:
        residual: Point-to-line distance map (H, W).
    """
    H, W = flow.shape[:2]
    fx, fy, cx, cy = intrinsics
    
    # 1. Create pixel coordinate grids
    xs, ys = np.meshgrid(np.arange(W), np.arange(H))
    
    # 2. Convert to homogeneous coordinates in camera frame i
    # x_cam = (x - cx) / fx, y_cam = (y - cy) / fy
    x_cam = (xs - cx) / fx
    y_cam = (ys - cy) / fy
    
    # 3. Construct 3D points at two arbitrary depths in frame i
    # Point = [x_cam * z, y_cam * z, z, 1]
    pts_near_i = np.stack([x_cam * z_near, y_cam * z_near, z_near, np.ones_like(xs)], axis=-1)
    pts_far_i = np.stack([x_cam * z_far, y_cam * z_far, z_far, np.ones_like(xs)], axis=-1)
    
    # 4. Transform to world coordinates
    # P_world = pose_i^{-1} @ P_cam (assuming pose_i is world-to-camera)
    # Note: Standard convention varies. If pose_i is T_world_from_cam, then P_cam = pose_i @ P_world.
    # So P_world = inv(pose_i) @ P_cam.
    inv_pose_i = np.linalg.inv(pose_i)
    pts_near_world = (inv_pose_i @ pts_near_i.T).T
    pts_far_world = (inv_pose_i @ pts_far_i.T).T
    
    # 5. Transform to frame j coordinates
    # P_cam_j = pose_j @ P_world
    pts_near_j = (pose_j @ pts_near_world.T).T
    pts_far_j = (pose_j @ pts_far_world.T).T
    
    # 6. Project to image plane j
    # u = x/z * fx + cx, v = y/z * fy + cy
    # Handle division by zero or negative z
    def project(pts):
        z = pts[:, :, 2]
        x = pts[:, :, 0]
        y = pts[:, :, 1]
        # Avoid division by zero
        valid_z = np.abs(z) > eps
        u = np.zeros_like(z)
        v = np.zeros_like(z)
        u[valid_z] = (x[valid_z] / z[valid_z]) * fx + cx
        v[valid_z] = (y[valid_z] / z[valid_z]) * fy + cy
        return u, v, valid_z

    u1, v1, valid1 = project(pts_near_j)
    u2, v2, valid2 = project(pts_far_j)
    
    # 7. Identify valid pixels
    valid = valid1 & valid2
    dx = u2 - u1
    dy = v2 - v1
    norm = np.sqrt(dx**2 + dy**2)
    valid = valid & (norm > eps)
    
    # 8. Compute line normal
    # Normal is perpendicular to direction (dx, dy). n = (-dy, dx) / norm
    nx = np.zeros_like(dx)
    ny = np.zeros_like(dy)
    nx[valid] = -dy[valid] / norm[valid]
    ny[valid] = dx[valid] / norm[valid]
    
    # 9. Compute correspondence in frame j
    # Correspondence = (xs + flow_x, ys + flow_y)
    flow_x = flow[:, :, 0]
    flow_y = flow[:, :, 1]
    xc = xs + flow_x
    yc = ys + flow_y
    
    # 10. Compute point-to-line distance
    # Distance = |n . (P_corr - P_line)|
    # P_line can be (u1, v1)
    dist = np.abs(nx * (xc - u1) + ny * (yc - v1))
    
    # Set invalid pixels to 0 or NaN depending on usage. 
    # For confidence, 0 might mean "on line" (static), but invalid projections are uncertain.
    # Here we keep the calculated distance for valid pixels and 0 for invalid.
    dist[~valid] = 0.0
    
    return dist
```

**Parameters**
- $z_l, z_f$: Arbitrary depths. Values $0.85$ and $0.15$ are used in the source implementation [S1, unofficial].
- $\epsilon$: Threshold for line norm, typically $10^{-3}$ [S1, unofficial].

**Edge Cases and Pitfalls**
- **Epipole Degeneracy**: If the pixel is near the epipole, the direction vector norm approaches zero. The method explicitly checks for $\|\mathbf{d}\| > \epsilon$ to avoid numerical instability [S1, unofficial].
- **Noisy Monocular Depth**: This method survives noisy monocular depth that defeats rigid-flow residuals because it does not rely on correct depth estimates [S1, unofficial].
- **Invalid Projections**: Pixels where reprojected points have invalid or negative depth are masked out [S1, unofficial].

## Operating characteristics
- **Time Complexity**: $O(HW)$ per frame pair, as it involves per-pixel operations.
- **Memory Complexity**: $O(HW)$ for storing coordinate grids and intermediate projections.
- **Strengths**: Robust to inaccurate depth estimates; leverages fundamental epipolar geometry constraints.
- **Limitations**: Requires accurate camera poses and intrinsics; fails if poses are significantly incorrect.
- **When to Use**: When monocular depth estimates are unreliable or noisy, and camera poses are known.
- **When Not to Use**: When camera poses are unknown or highly inaccurate.

## Background
This method is part of the [Geometry Confidence Measurement](15151-geometry-confidence-measurement.md) pipeline, which aims to identify outliers in depth and flow consistency across views. It is implemented in the context of volumetric video processing and 4D Gaussian Splatting optimization, specifically in the `devarshh/volumetric-video-4dgs` repository [S1, unofficial]. The approach exploits the property that static points lie on their epipolar lines regardless of their depth, allowing motion detection without depth priors.
