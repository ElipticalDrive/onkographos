# Reliable Depth Estimation via Reprojection

Also called: Depth Supervision Loss (Laug)

## Overview
This method selects reliable depth estimates for supervising radiance field training by comparing reprojection consistency between a main model and an augmented model against a reference training view. It differs from standard monocular depth consistency by using explicit geometric reprojection error (MSE of intensities) rather than photometric alignment alone, allowing it to filter out incorrect depth predictions in ambiguous regions [S1].

## How it works
**Inputs:**
- Depth maps $z_m$ (main model) and $z_a$ (augmented model) for a target view.
- Reference intensity image $I_{ref}$ from the nearest training view.
- Threshold $e_\tau$ for reliability filtering.

**Outputs:**
- Reliability masks $m_m$ (main) and $m_a$ (augmented).
- Augmentation loss $L_{aug}$.

**Data Structures:**
- Depth maps: 2D arrays of float values, same resolution as $I_{ref}$.
- Masks: 2D binary arrays (0 or 1) of same resolution.

**Steps:**
1. **Reproject and Compute MSE:** For each pixel, reproject the patch around the depth estimate $z_m$ and $z_a$ to the nearest training view. Compute the Mean Squared Error (MSE) of intensities between the reprojected patch and the corresponding patch in $I_{ref}$. Let $e_m$ and $e_a$ be these MSEs [S1].
2. **Compute Augmented Mask ($m_a$):** Determine if the augmented model is more reliable. Set $m_a = 1$ if $e_a \le e_m$ AND $e_a \le e_\tau$. Otherwise, $m_a = 0$ [S1].
3. **Compute Main Mask ($m_m$):** Determine if the main model is more reliable. Set $m_m = 1$ if $e_m \le e_a$ AND $e_m \le e_\tau$. Otherwise, $m_m = 0$ [S1].
4. **Compute Loss:** Calculate the loss using stop-gradient operators to prevent backpropagation through the "teacher" depth estimates [S1].

**Formula:**
$$ L_{aug} = \mathbb{1}\{m_a=1\} \odot \| z_m - \hat{\nabla}(z_a) \|^2 + \mathbb{1}\{m_m=1\} \odot \| \hat{\nabla}(z_m) - z_a \|^2 $$
Where:
- $\odot$ is element-wise product.
- $\mathbb{1}$ is the indicator function.
- $\hat{\nabla}$ is the stop-gradient operator [S1].

**Parameters:**
- $e_\tau$: Threshold for reprojection MSE. Not given in the sources.

**Edge Cases:**
- **Specular Regions:** In specular regions, reprojected intensities may not match, causing both masks to be zero. This results in no supervision for those pixels, which is intended to avoid incorrect depth supervision [S1].
- **Tie-breaking:** If $e_m = e_a$, the condition $e_a \le e_m$ is true, so $m_a$ may be set to 1 if $e_a \le e_\tau$. The source does not specify a strict tie-breaking rule beyond the inequalities [S1].

**Pseudocode:**
```python
def reliable_depth_reprojection_loss(z_m, z_a, I_ref, e_tau):
    """
    z_m: Depth map from main model (H, W)
    z_a: Depth map from augmented model (H, W)
    I_ref: Reference intensity image from nearest training view (H, W, C)
    e_tau: Reliability threshold
    """
    # 1. Reproject patches and compute MSE
    # Note: Exact reprojection geometry (camera intrinsics/extrinsics) is assumed
    # to be handled by a helper function not detailed in the source.
    # We assume 'reproject_patch' returns the MSE intensity difference.
    e_m = compute_reprojection_mse(z_m, I_ref)
    e_a = compute_reprojection_mse(z_a, I_ref)
    
    # 2. Compute masks
    # m_a = 1 if (e_a <= e_m) and (e_a <= e_tau)
    mask_a = ((e_a <= e_m) & (e_a <= e_tau)).astype(float)
    
    # m_m = 1 if (e_m <= e_a) and (e_m <= e_tau)
    mask_m = ((e_m <= e_a) & (e_m <= e_tau)).astype(float)
    
    # 3. Compute loss with stop-gradient
    # Stop-gradient is applied to the "teacher" depth (the one being compared against)
    # In the first term, z_a is the teacher for z_m supervision? 
    # Formula: ||zm - grad_stop(za)||^2. So za is stop-graded.
    # In the second term, ||grad_stop(zm) - za||^2. So zm is stop-graded.
    
    term1 = mask_a * (z_m - stop_gradient(z_a))**2
    term2 = mask_m * (stop_gradient(z_m) - z_a)**2
    
    loss = term1 + term2
    return loss.mean()
```

## Subtopics

### Depth Supervision Loss (Laug)
This is the specific loss function defined by the reprojection reliability method. It combines two directional consistency terms, weighted by reliability masks derived from reprojection MSE. It is used to regularize sparse input radiance fields by providing depth supervision only where the depth estimates are geometrically consistent with a reference view [S1].

## Operating characteristics
- **Time Complexity:** Requires reprojection for both main and augmented models, effectively doubling the reprojection cost compared to single-model consistency.
- **Memory Complexity:** Requires storing depth maps for both models and reference images.
- **Strengths:** Filters out incorrect depth estimates in ambiguous or specular regions by requiring low reprojection error [S1].
- **Limitations:** Relies on the availability of a nearest training view and accurate camera poses for reprojection. Performance depends on the threshold $e_\tau$ [S1].

## Background
Originated in "Simple-RF: Regularizing Sparse Input Radiance Fields with Simpler Solutions" (2024) by the authors of the Simple-RF family (NeRF, TensoRF, ZipNeRF variants). It is part of the augmentation strategy for simple radiance fields to handle sparse input views [S1].
