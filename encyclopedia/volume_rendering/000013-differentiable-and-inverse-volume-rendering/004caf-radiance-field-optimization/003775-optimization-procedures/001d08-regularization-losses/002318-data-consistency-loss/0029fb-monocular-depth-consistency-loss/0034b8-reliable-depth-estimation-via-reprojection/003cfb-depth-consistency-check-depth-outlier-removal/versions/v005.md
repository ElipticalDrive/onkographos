# Depth Consistency Check / Depth Outlier Removal

Also called: Geometric Consistency Masking, Reprojection-based Depth Filtering

## Overview
This method filters noisy depth data by unprojecting depth maps to 3D space and reprojecting them into nearby views to verify geometric consistency [S1]. It sets itself apart from [Depth Supervision Loss (Laug)](8111-depth-supervision-loss-laug.md) by using explicit geometric reprojection checks rather than direct loss minimization, and from [Multi-view Consistency Depth Filtering](12319-multi-view-consistency-depth-filtering.md) by focusing on pairwise reprojection error thresholds rather than complex multi-view voting or probabilistic models [S1, S2].

## How it works
**Inputs:**
- Depth map $D_i$ for frame $i$ [S1].
- Camera projection matrices $\pi_i$ and $\pi_j$ for frames $i$ and $j$ [S1].
- Depth map $D_j$ for frame $j$ [S1].
- Threshold $\sigma$ [S1].

**Outputs:**
- Geometric consistency mask $M_d$ (boolean array same size as $D_i$) [S1].

**Data Structures:**
- $D_i, D_j$: 2D arrays of depth values [S1].
- $\pi_i, \pi_j$: 4×4 camera projection matrices [S1].
- $M_d$: 2D boolean array [S1].
- $\mathbf{u}_i$: 2D array of pixel coordinates $(u, v)$ for frame $i$ [S1].

**Steps:**
1. **Unproject:** Convert the depth map $D_i$ of frame $i$ to 3D points using the inverse projection matrix $\pi_i^{-1}$ [S1].
2. **Reproject:** Project the 3D points into the coordinate system of a nearby view $j$ using $\pi_j$ to obtain the projected pixel coordinates and the projected depth $D_{i \to j}$ [S1].
3. **Compare:** Calculate the absolute difference between the reprojected depth $D_{i \to j}$ and the actual depth $D_j$ at the corresponding pixel location in view $j$ [S1].
4. **Filter:** Apply the consistency check; filter out depths where the error exceeds the threshold $\sigma$ [S1].

**Formulas:**
The primary consistency mask $M_d$ is defined as [S1]:
$$ M_d = |D_{i \to j} - D_j| < \sigma $$
where:
- $D_{i \to j} = D_j(\pi_j \pi_i^{-1}(\mathbf{u}_i))$ is the reprojected depth from frame $i$ to frame $j$ [S1].
- $\mathbf{u}_i$ denotes pixel coordinates of the $i$-th frame [S1].
- $M_d$ represents the geometric consistency mask [S1].

**Parameters:**
- $\sigma = 0.2$ m: Empirical threshold for the absolute error in depth reprojection [S1].

**Edge Cases and Pitfalls:**
- **Occlusions & Dynamic Content:** If a point is occluded in view $j$ or belongs to a dynamic object, the reprojection will land on a different surface or background, causing a large error that the threshold filters out [S1].
- **Interpolation:** When retrieving depth $D_j$ at non-integer projected coordinates, interpolation is required, which introduces small sampling errors [S2].
- **Precision & Floaters:** Floating-point precision in matrix operations can accumulate errors. A 3D statistical filter (e.g., Open3D) with 20 neighbors and a standard deviation ratio of 2.0 is applied to unprojected point clouds to remove clear floaters before reprojection [S1].

**Pseudocode:**
```python
import numpy as np

def depth_consistency_check(D_i, D_j, pi_i, pi_j, sigma=0.2):
    """
    Perform depth consistency check between frame i and frame j.
    Implements the reprojection consistency check from [S1].
    """
    H, W = D_i.shape
    
    # 1. Generate pixel coordinates u_i for frame i
    u, v = np.meshgrid(np.arange(W), np.arange(H))
    coords_i = np.stack([u, v, np.ones_like(u)], axis=-1).astype(np.float32)
    
    # 2. Unproject D_i to 3D using inverse projection matrix pi_i^{-1}
    pi_i_inv = np.linalg.inv(pi_i)
    X_i_hom = (pi_i_inv @ coords_i.reshape(-1, 3).T).T
    X_i = X_i_hom * D_i.reshape(-1, 1)
    
    # 3. Reproject X_i to view j using pi_j
    u_proj_hom = (pi_j @ X_i.T).T
    u_proj = u_proj_hom[:, :2] / u_proj_hom[:, 2:]
    D_reproj = u_proj_hom[:, 2:]
    
    # 4. Sample D_j at projected coordinates (nearest-neighbor sampling)
    u_clamped = np.clip(u_proj[:, 0], 0, W - 1).astype(int)
    v_clamped = np.clip(u_proj[:, 1], 0, H - 1).astype(int)
    D_j_sampled = D_j[v_clamped, u_clamped]
    
    # 5. Calculate absolute error and apply threshold sigma
    abs_error = np.abs(D_reproj - D_j_sampled)
    mask = abs_error < sigma
    
    return mask.reshape(H, W)
```

## Subtopics

### [Probabilistic Depth Testing](11488-probabilistic-depth-testing.md)
Probabilistic Depth Testing determines which input view's reprojection contains the correct geometric information for a novel view pixel by calculating the probability that its depth is closer than all other views' depths. It differs from hard visibility tests by using a mixture model with triangular distributions to perform soft depth resolution, which is necessary because point splatting lacks mesh connectivity and soft rasterization introduces uncertainty from noisy Multi-View Stereo (MVS) data. See [Probabilistic Depth Testing](11488-probabilistic-depth-testing.md).

### [Reprojection Confidence Measurement](15150-reprojection-confidence-measurement.md)
Reprojection Confidence Measurement evaluates the geometric consistency of depth estimates by warping pixels from a source view to a target view and comparing the reconstructed appearance against the actual target image. It distinguishes itself from sibling methods like [Probabilistic Depth Testing](11488-probabilistic-depth-testing.md) by explicitly constructing confidence maps at multiple semantic levels (pixel, patch, and feature) to identify outliers caused by moving objects, ill-posed regions, and occlusions. See [Reprojection Confidence Measurement](15150-reprojection-confidence-measurement.md).

### Geometric Consistency Filtering
Geometric Consistency Filtering measures the consistency of depth estimates among multiple views [S2]. For each pixel $p$ in the reference view with depth $d_0$, it projects to a pixel $p_i$ in the $i$-th source view, retrieves depth $d_i$ with interpolation, and reprojects back to get $d_{reproj}$ at $p_{reproj}$ [S2]. It accepts the estimation as reliable if $|p_{reproj} - p| < \delta$ and $|d_{reproj} - d_0|/d_0 < \varepsilon$ [S2]. It requires consistency in at least $N_{geo}$ source views [S2]. Parameters: $\delta = 1$, $\varepsilon = 0.01$, $N_{geo}$ varies [S2].

### Depth-Based Validity Masking for EM Loss
Depth-Based Validity Masking for EM Loss is a pre-training depth filtering step that identifies valid depth pixels by excluding a fixed invalid value, then computes median and maximum valid depths per camera [S3, unofficial].

### Depth-map Baseline
Depth-map Baseline synthesizes novel views by projecting fused depth information into the target camera without explicit surface reconstruction [S4]. It resolves conflicting samples through depth-consistency and visibility checks, accepting a correspondence if its reprojection displacement is below 2 pixels and its relative depth deviation is below 1% [S4].

### Depth Normal Consistency Masking
Depth Normal Consistency Masking filters out unreliable depth values by masking pixels where the depth surface normal deviates significantly from the camera view direction [S5, unofficial]. It computes the normalized view direction vector, extracts and normalizes the rendered depth normal, calculates the absolute dot product across spatial dimensions, and creates a boolean mask for pixels where the angle exceeds 80.0 degrees, zeroing out those depth values in the TSDF-compatible depth map [S5, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N \cdot V)$, where $N$ is the number of pixels and $V$ is the number of source views checked. Each pixel requires unprojection, reprojection, and sampling [S1, S2].
- **Memory Complexity:** $O(N)$ for storing depth maps and masks. Unprojected 3D points require $O(N)$ additional memory [S1, S2].
- **Measured Performance:** In [S1], the method removes noisy depth data and clear floaters in unprojected point clouds using a 3D statistical filter with 20 neighbors and a standard deviation ratio of 2.0 [S1].
- **Strengths:** Effective at removing outliers caused by MVS noise and geometric inconsistencies [S1]. Simple to implement and understand.
- **Limitations:** Relies on accurate camera calibration. Fails in textureless regions where depth estimation is inherently noisy. The threshold $\sigma$ is empirical and may need tuning for different scenes [S1].
- **When to use:** When using monocular depth estimators or MVS outputs that contain significant noise or outliers [S1].
- **When not to use:** When high precision is required in textureless regions or when computational resources are extremely limited and simple thresholding is insufficient [S1].

## Background
The method originates from the need to clean depth data for volume-based Gaussian Splatting and multi-view reconstruction [S1]. [S1] introduces the basic reprojection consistency check for efficient volume-based Gaussian Splatting in urban view synthesis [S1]. [S2] adapts and expands this concept for generalizable multi-view reconstruction using geometric consistency filtering [S2]. The approach builds on traditional multi-view stereo techniques [S2].
