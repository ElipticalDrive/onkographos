# Geometric Consistency Regularization

Also called: Consistency-aware Fine-tuning Scheme

## Overview
Geometric Consistency Regularization enforces multi-view geometric constraints during radiance-field optimization to resolve ambiguities in sparse-view reconstruction [S1, S2]. It distinguishes itself from sibling losses by filtering correspondences based on geometric agreement, which eliminates distorted geometries and artifacts common in unconstrained optimization [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Input images with known camera poses, a current radiance field or Gaussian splatting model, and candidate correspondences between views [S1, S2, G].
*   **Outputs:** A regularized loss term added to the training objective and refined geometry [G].

**Data Structures:**
*   **Correspondences:** A set of 2D pixel coordinates $(u, v)$ in reference and target views, mapped to 3D points via depth or ray intersection [G].
*   **Threshold:** A scalar parameter $\tau_{ray}$ defining the maximum allowable geometric deviation for a correspondence to be retained [S2].

**Steps:**
1.  Compute the geometric consistency error for each candidate correspondence, typically measured as the reprojection distance or ray-point distance [G].
2.  Filter correspondences by comparing the error against $\tau_{ray}$; correspondences below the threshold are retained for regularization [S2].
3.  Compute the regularization loss only over the set of valid correspondences [S2].
4.  In regions lacking valid correspondences, apply standard photometric supervision to a randomized selection of rays to ensure full image coverage [S2].

**Parameters:**
*   $\tau_{ray}$: Geometry regularization threshold that balances matching accuracy against geometric detail preservation [S2].
    *   LLFF dataset: $\tau_{ray} = 0.15$ [S2].
    *   DTU dataset: $\tau_{ray} = 0.0017$ [S2].
*   $n_t, n_{ref}$: Number of target and reference rays sampled per iteration for photometric backup in unmatched regions [S2].
    *   Typical value: 50 [S2].

**Pseudocode:**
```python
def compute_geometric_consistency_loss(
    reference_view, target_views, model, correspondences, tau_ray, n_backup=50
):
    """
    Computes geometric consistency loss by filtering correspondences and backing up with photometric supervision.
    
    Args:
        reference_view: Reference image and camera pose.
        target_views: List of target images and camera poses.
        model: Current radiance field or Gaussian model.
        correspondences: List of (ref_uv, target_uv) pairs from feature matching.
        tau_ray: Threshold for geometric consistency.
        n_backup: Number of random rays for photometric backup in unmatched regions.
        
    Returns:
        loss: Scalar geometric consistency loss.
    """
    valid_correspondences = []
    
    for ref_uv, target_uv in correspondences:
        # [G] Standard ray casting and depth sampling
        ref_ray = reference_view.camera.unproject(ref_uv)
        ref_depth = model.sample_depth(ref_ray)
        ref_point_3d = ref_ray.origin + ref_depth * ref_ray.direction
        
        # [G] Project to target view and compute reprojection error
        target_uv_proj = target_views.camera.project(ref_point_3d)
        error = np.linalg.norm(np.array(ref_uv) - np.array(target_uv_proj))
        
        # Filter based on threshold
        if error < tau_ray:
            valid_correspondences.append((ref_uv, target_uv))
            
    loss = 0.0
    for ref_uv, target_uv in valid_correspondences:
        ref_rendered = model.render(reference_view.camera, ref_uv)
        target_rendered = model.render(target_views.camera, target_uv)
        loss += np.mean((ref_rendered - target_rendered) ** 2)
        
    # [G] Standard photometric backup for regions without correspondences
    # The sources do not specify the exact sampling algorithm for the backup rays.
    # loss += photometric_backup_loss(model, reference_view, n_backup)
        
    return loss / max(len(valid_correspondences), 1)
```

## Subtopics

### Geometry Regularization Threshold
A threshold parameter $\tau_{ray}$ for the geometry regularization module that filters correspondences based on geometric consistency [S2]. It balances matching accuracy against geometric detail preservation [S2].
*   **Parameter:** LLFF dataset: $\tau_{ray} = 0.15$ [S2]. DTU dataset: $\tau_{ray} = 0.0017$ [S2].
*   **Pitfall:** Higher $\tau_{ray}$ values introduce inaccurate correspondences, while lower values produce less detailed geometry descriptions [S2]. Both extremes negatively impact PSNR [S2].
*   **Performance:** LLFF ablation ($\tau_{ray}$ 0.05 to 0.35, step 0.05): Optimal PSNR 20.33 at 0.15 [S2]. SSIM and LPIPS remain stable [S2]. DTU ablation ($\tau_{ray}$ 0.0005 to 0.002, step ~0.0002): Optimal PSNR 18.71 at 0.0017 [S2].

## Operating characteristics
*   **Time Complexity:** Adds overhead for geometric verification per iteration [S2]. The method requires 44k training iterations on DTU with 3 input views and 70k iterations on LLFF [S2].
*   **Memory Complexity:** Requires storing correspondence lists and intermediate 3D points [G].
*   **Performance:** On the DTU dataset, adding the consistency-aware scheme reduces Chamfer distance from 1.28 (Pixel+Patch blending) to 1.21 [S1].
*   **Strengths:** Produces noticeably cleaner results and eliminates distorted geometries compared to schemes without it [S1]. Per-scene optimization with learned priors converges faster and avoids sub-optimal solutions caused by radiance ambiguity [S1].
*   **Limitations:** Relies heavily on the quality of initial feature matching [S2]. Sparse correspondences may leave regions unsupervised without hybrid photometric backup [S2].

## Background
The method originated in the context of few-shot neural rendering and sparse-view surface reconstruction [S2]. SGCNeRF introduced sparse geometric consistency guidance to leverage sparse geometric constraints [S2]. SparseNeuS applied a consistency-aware fine-tuning scheme to improve generalizable neural surface reconstruction from sparse views [S1].
