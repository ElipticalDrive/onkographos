# Hybrid Explicit-Implicit Representations


## Overview
Hybrid Explicit-Implicit Representations address the trade-off between the memory efficiency of explicit structures and the continuous flexibility of implicit neural decoders in radiance field optimization [S1]. This family balances memory efficiency and rendering speed by leveraging cheap lookups for feature retrieval while maintaining the ability to model complex scene geometry and appearance [S1].

## Shared principles
The core mechanism involves two components: an **Explicit Feature Storage** ($V$) and a **Decoder** ($D$).

1.  **Explicit Feature Storage ($V$):** A data structure holding feature vectors. Common implementations include voxel grids and hash tables [S1]. Not given in the sources for basis vectors.
2.  **Decoder ($D$):** A function that maps the retrieved feature vector $v_p$ to physical properties [S1]. Not given in the sources for specific decoder architectures.

**Algorithm Steps:**
1.  **Initialize Storage:** Construct the explicit feature storage $V$. Not given in the sources for specific initialization procedures.
2.  **Feature Retrieval:** For a query point $p = (x, y, z)$ in 3D space, retrieve the corresponding feature vector $v_p$ from $V$.
    *   If $V$ is a voxel grid, perform tri-linear interpolation of the surrounding voxel features to obtain $v_p$ [G].
    *   If $V$ is a hash table, compute the hash of $p$ and retrieve the associated feature vector [G].
3.  **Decoding:** Pass the feature vector $v_p$ through the decoder $D$ to predict the volume density $\sigma(p)$ and color $c(p, d)$, where $d$ is the viewing direction [S1].
4.  **Rendering:** Use standard volume rendering integration along rays passing through the scene, summing the contributions of $\sigma$ and $c$ weighted by transmittance [G].

**Parameters:**
*   **Storage Type:** Voxel grid or hash table [S1].
*   **Interpolation Method:** Tri-linear interpolation is standard for voxel grids [G].

**Edge Cases and Pitfalls:**
*   **Precision:** Tri-linear interpolation assumes continuous variation between voxels; sharp discontinuities may require higher resolution or specialized handling [S1].
*   **Boundaries:** Points outside the defined storage domain must be handled (e.g., clamping, zero-padding, or out-of-bounds flags) [G].
*   **Degenerate Input:** Empty regions in the scene may result in sparse feature storage, requiring efficient sparse data structures or padding strategies [S1].

Combines a voxel grid and a triangle mesh to achieve real-time view synthesis on mobile devices, converting portions of the volumetric density field into a surface mesh based on rendering quality differences.

### MERF
*   **Definition:** MERF is a volumetric scene representation that achieves real-time rendering of large-scale scenes in a browser by combining a sparse feature grid and high-resolution 2D feature planes, with a lossless baking procedure to convert the optimized parameterization into a fast rendering format [S1]. It uses a unified radiance field representation with two different underlying parameterizations: one for optimization (NGP hash grid) and one for rendering (baked binary occupancy grid and triplanes) [S1].
*   **Steps:** During optimization, MERF uses the NGP hash grid structure to compress the parameterization, allowing for differentiable sparsification and providing an inductive bias that aids convergence [S1]. After optimization, it queries the recovered NGP to explicitly bake out the MERF and create a binary occupancy grid to accelerate rendering [S1].
*   **Performance:** MERF achieves better image quality for the same amount of compression as SNeRG++, matching the output of a SNeRG++ model that is over 17x larger [S1]. Compared to TensoRF, MERF speeds up query time by removing the need for matrix multiplication and halves memory bandwidth consumption [S1].

### NeRF-Editing
*   **Definition:** NeRF-Editing is the first mesh-based shape deformation method, leveraging explicit representations for scene geometry edits and implicit representations for realistic rendering effects [S2].
*   **Steps:** It extracts an explicit triangular mesh from the NeRF, enables intuitive user-driven deformations through the classic ARAP deformation method, generates a tetrahedral mesh around the triangular mesh to propagate deformations spatially, employs tetrahedral vertex interpolation to transform discrete deformations into a continuous field, and ensures rays passing through the mesh bend according to user adjustments [S2].

## Background
Hybrid representations emerged to address the limitations of pure Neural Radiance Fields (NeRF), which are compute-intensive for real-time rendering, and pure explicit methods, which lack the flexibility of continuous representations. The concept of storing features in a structured format (voxel grids, hash tables) and decoding them via lightweight networks was introduced to balance memory efficiency and rendering speed [S1]. Notable implementations include MERF, which introduces a baking procedure to transition from an optimized hash-grid representation to a real-time renderable format [S1].
