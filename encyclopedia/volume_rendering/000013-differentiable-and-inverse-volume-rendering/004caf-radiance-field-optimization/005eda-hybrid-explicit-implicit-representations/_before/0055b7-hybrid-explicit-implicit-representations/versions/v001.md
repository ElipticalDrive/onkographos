# Hybrid Explicit-Implicit Representations

Also called: Hybrid Neural Representations, Explicit-Implicit NeRF

## Overview
Hybrid explicit-implicit representations combine discrete geometric structures (such as triangle meshes or voxel grids) with continuous neural fields (such as MLPs or hash tables) to optimize the trade-off between rendering speed, storage efficiency, and geometric fidelity [S1]. This approach addresses the limitations of pure implicit models, which suffer from slow ray-marching inference, and pure explicit models, which struggle with complex, non-manifold geometry and high storage costs for detailed textures [S1]. By delegating coarse geometry or high-frequency details to explicit structures and using neural fields for residual density, color, or displacement, these methods achieve real-time performance on constrained hardware while maintaining photorealistic quality [S1].

## Shared principles
The core mechanism involves decomposing the scene representation into two complementary components: an **explicit component** and an **implicit component**.

1.  **Explicit Component:** Represents coarse geometry, surface topology, or high-frequency spatial structure using discrete data structures. Common forms include:
    *   Triangle meshes (vertices, faces, texture coordinates).
    *   Voxel grids (sparse or dense 3D arrays).
    *   Tetrahedral meshes (for deformation propagation).
    *   This component is typically rendered using hardware-accelerated rasterization or efficient spatial lookups, bypassing the need for dense ray-marching for all scene elements.

2.  **Implicit Component:** Represents residual details, view-dependent appearance, or volumetric density that the explicit component cannot capture or is too expensive to store explicitly. Common forms include:
    *   Neural Radiance Fields (MLPs).
    *   Hash-based feature grids (e.g., Instant-NGP).
    *   Displacement maps (e.g., spherical harmonics coefficients).
    *   This component is queried at specific points (often derived from the explicit component) to refine the final color and density.

3.  **Integration:** The final pixel color is computed by combining the contributions from both components. This is often achieved through:
    *   **Calibration:** Using the explicit geometry to find a base point, then querying the implicit field for displacement or feature refinement.
    *   **Hybrid Rendering:** Rasterizing the explicit mesh for primary visibility and volume-rendering the implicit voxels/fields for occluded or complex regions.
    *   **Deformation Propagation:** Using explicit meshes to define deformation fields that are interpolated via implicit structures (e.g., tetrahedral interpolation) to update the neural field.

## Subtopics

### [MixRT](12401-mixrt.md)
MixRT is a hybrid representation designed for real-time NeRF rendering on edge devices, decomposing the scene into a low-quality triangle mesh, a view-dependent displacement map, and a compressed NeRF hash table. It differs from siblings by leveraging WebGL hardware parallelism (rasterizers, texture mapping units, SIMD) to maximize throughput, avoiding the storage overhead of high-fidelity meshes and the speed limitations of pure neural models. It is chosen when interactive frame rates (>30 FPS) are required on mobile or edge hardware with limited memory. See [MixRT](12401-mixrt.md).

### [Vosh (VOxel-meSH)](15540-vosh-voxel-mesh.md)
Vosh combines a sparse voxel grid and a textured mesh to achieve real-time view synthesis on mobile devices, converting portions of the volumetric density field into a mesh surface. It differs from siblings like VMesh by using only the implicit volumetric density field rather than Signed Distance Functions (SDFs), thereby avoiding low-quality reconstruction in complex backgrounds and eliminating scene-specific hyper-parameters. It is chosen for mobile deployment where CUDA-based methods (like 3DGS) are unavailable. See [Vosh (VOxel-meSH)](15540-vosh-voxel-mesh.md).

### NeRF-Editing
NeRF-Editing is a method for geometric deformation of NeRF scenes, leveraging explicit representations for scene geometry edits and implicit representations for realistic rendering effects [S1]. It is distinct as the first mesh-based shape deformation method, enabling user-driven edits via ARAP deformation and tetrahedral mesh propagation [S1]. It is chosen when interactive 3D editing of NeRF scenes is required [S1].

## Background
The concept of hybrid representations in NeRF emerged to address the computational bottlenecks of pure neural radiance fields. Early NeRF models relied entirely on MLPs, requiring dense sampling along rays . As demand for real-time rendering grew, researchers began integrating explicit structures. MixRT and Vosh represent recent advancements targeting edge and mobile devices, optimizing hash table configurations and voxel-mesh trade-offs for specific hardware constraints [S1]. NeRF-Editing introduced the paradigm of using explicit meshes to drive deformations in implicit fields, expanding NeRF from static rendering to interactive editing [S1].
