# Instant-NSR

Also called: Neural Surface Reconstruction with Hash

## Overview
Instant-NSR is a neural surface reconstruction method that accelerates training using Hash encoding while improving geometry quality by incorporating a Signed Distance Function (SDF) representation during optimization [S1]. It builds on [Radiance-field optimization](44-radiance-field-optimization.md) and [Surface-SDF Representation](10778-surface-sdf-representation.md) by adapting the NeRF architecture to predict SDF values instead of density, and employs a Truncated SDF (TSDF) formulation to ensure numerical stability when combined with hash grids [S1]. Unlike [NeuS](6060-neus.md), which uses multi-resolution hash grids but may suffer from convergence issues with large temperature parameters, Instant-NSR explicitly truncates the SDF range to prevent gradient explosion [S1].

## How it works
**Inputs:** A set of calibrated images with known camera poses [G].
**Outputs:** A neural network representing the scene geometry (SDF) and appearance, capable of rendering novel views and extracting a 3D mesh [G].

**Data Structures:**
1.  **Hash Grid:** A multi-resolution hash table mapping spatial coordinates to feature vectors, identical to the structure in [Instant-NGP](instant-ngp.md) [S1]. It provides the front-end feature encoding for input points [S1].
2.  **Neural Network:** A small MLP that takes the hashed features as input and outputs the SDF value $f(\mathbf{x})$ and color $\mathbf{c}$ [S1]. The architecture follows the SDF-based design of [NeuS](6060-neus.md) rather than the density-based design of [Instant-NGP](instant-ngp.md) [S1].

**Algorithm Steps:**

1.  **Sampling:** For each pixel in a training image, cast a ray and sample $N$ points $\mathbf{x}_i$ along the ray segment within the camera frustum [G].
2.  **Hash Encoding:** Encode each point $\mathbf{x}_i$ using the multi-resolution hash grid to obtain feature vectors [S1].
3.  **SDF Prediction:** Pass the hashed features through the MLP to predict the raw SDF value $f(\mathbf{x}_i)$ and color $\mathbf{c}_i$ [S1].
4.  **TSDF Truncation:** Apply a sigmoid function $\pi(\cdot)$ to the raw SDF output to truncate it to the range $[-1, 1]$ [S1]. This prevents numerical overflow when the temperature parameter $b$ is large [S1]. The transformation is defined as:
    $$
    \pi(f(\mathbf{x})) = \frac{1 - e^{-bf(\mathbf{x})}}{1 + e^{-bf(\mathbf{x})}}
    $$
    where $b$ is a temperature parameter [S1].
5.  **Probability Distribution:** Compute the cumulative density distribution $\phi_b$ using the truncated SDF value $\pi(f(\mathbf{x}))$ [S1]. This replaces the standard NeRF/NeuS formulation to ensure stability:
    $$
    \phi_b(f(\mathbf{x})) = \frac{b e^{-b\pi(f(\mathbf{x}))}}{(1 + e^{-b\pi(f(\mathbf{x}))})^2}
    $$
    This $\phi_b$ is used to compute the weight $w(t)$ for volume rendering [S1].
6.  **Rendering:** Render the image using the standard volume rendering equation with the computed weights and colors [G].
7.  **Loss Computation:** Calculate the total loss as a weighted sum of rendering loss and eikonal loss [S1].
8.  **Optimization:** Update the network parameters (hash grid and MLP weights) using gradient descent [G].

**Formulas:**

*   **TSDF Mapping:**
    $$
    \pi(f(\mathbf{x})) = \frac{1 - e^{-bf(\mathbf{x})}}{1 + e^{-bf(\mathbf{x})}} \quad \text{[S1]}
    $$
*   **Weight Distribution:**
    $$
    \phi_b(f(\mathbf{x})) = \frac{b e^{-b\pi(f(\mathbf{x}))}}{(1 + e^{-b\pi(f(\mathbf{x}))})^2} \quad \text{[S1]}
    $$
*   **Eikonal Loss:** Enforces that the gradient magnitude of the SDF is 1 everywhere:
    $$
    L_{eik} = \frac{1}{M} \sum_{j=1}^{M} (\|\nabla f(\mathbf{x}_j)\|_2^2 - 1)^2
    $$
    where $M$ is the number of sampled points and $\nabla f(\mathbf{x}_j)$ is the gradient of the SDF at point $\mathbf{x}_j$ [S1].
*   **Total Loss:**
    $$
    L_{total} = \alpha L_{render} + \beta L_{eik}
    $$
    where $L_{render}$ is the rendering loss (e.g., $L_1$ or $L_2$ between rendered and ground truth images) and $\alpha, \beta$ are hyperparameters [S1].

**Parameters:**
*   $b$: Temperature parameter for the TSDF truncation and distribution. Not given in the sources.
*   $\alpha$: Weighting factor for rendering loss. Chosen via cross-validation [S1].
*   $\beta$: Weighting factor for eikonal loss. Chosen via cross-validation [S1].
*   TSDF Range: Values are effectively constrained between -1 and 1 by the sigmoid function $\pi(\cdot)$ [S1].

**Edge Cases and Pitfalls:**
*   **Numerical Instability:** In standard SDF-based methods, increasing $b$ causes $-bf(\mathbf{x})$ to become a large positive number, making $e^{-bf(\mathbf{x})}$ approach infinity, leading to network divergence [S1]. Instant-NSR solves this by using the TSDF truncation $\pi(f(\mathbf{x}))$, which bounds the exponent [S1].
*   **Convergence:** Applying raw SDF representations to hash coding frameworks can cause convergence problems. The TSDF formulation is critical for stable training in this context [S1].

**Pseudocode:**

```python
import math

def sample_points_along_rays(ray_origins, ray_directions, num_samples):
    """Standard volume rendering ray sampling [G]."""
    points = []
    for origin, direction in zip(ray_origins, ray_directions):
        for t in range(num_samples):
            points.append([origin[i] + t * direction[i] for i in range(3)])
    return points

def hash_encode(points, hash_grid):
    """Multi-resolution hash grid feature lookup [G]."""
    features = []
    for p in points:
        # Sources do not specify the exact hash grid traversal or feature dimension [G]
        features.append([0.0] * 16)
    return features

def mlp_forward(features):
    """Small MLP predicting SDF and color [S1]."""
    # Sources do not specify MLP architecture details [G]
    sdf = sum(f * 0.1 for f in features)
    color = [sdf * 0.5, sdf * 0.3, sdf * 0.2]
    return sdf, color

def compute_gradient(sdf_values, points):
    """Compute spatial gradient of SDF [G]."""
    grads = []
    for i, p in enumerate(points):
        # Central difference approximation [G]
        eps = 1e-4
        grad_x = (sdf_values[(i + 1) % len(points)] - sdf_values[(i - 1) % len(points)]) / (2 * eps)
        grads.append([grad_x, grad_x, grad_x])
    return grads

def volume_render(phi_b, depths, colors):
    """Standard volume rendering integration [G]."""
    rendered = [0.0, 0.0, 0.0]
    transmittance = 1.0
    for phi, color in zip(phi_b, colors):
        weight = phi * transmittance
        for c in range(3):
            rendered[c] += weight * color[c]
        transmittance *= (1.0 - phi)
    return rendered

def instant_nsr_forward(ray_origins, ray_directions, hash_grid, b):
    """Forward pass for Instant-NSR [S1]."""
    points = sample_points_along_rays(ray_origins, ray_directions, 64)
    features = hash_encode(points, hash_grid)
    sdf_raw, color = mlp_forward(features)

    # TSDF Truncation: pi(f) = (1 - exp(-b*f)) / (1 + exp(-b*f)) [S1]
    exp_term = [math.exp(-b * s) for s in sdf_raw]
    sdf_truncated = [(1.0 - e) / (1.0 + e) for e in exp_term]

    # Probability Distribution: phi_b = b * exp(-b*pi) / (1 + exp(-b*pi))^2 [S1]
    exp_phi = [math.exp(-b * s) for s in sdf_truncated]
    phi_b = [(b * e) / ((1.0 + e) ** 2) for e in exp_phi]

    rendered_image = volume_render(phi_b, [0.0]*len(points), color)
    return rendered_image, sdf_raw

def compute_loss(rendered_image, gt_image, sdf_raw, points):
    """Compute total loss [S1]."""
    l_render = sum((r - g) ** 2 for r, g in zip(rendered_image, gt_image)) / len(rendered_image)
    grad_sdf = compute_gradient(sdf_raw, points)
    grad_norm_sq = [sum(g**2 for g in grad) for grad in grad_sdf]
    l_eik = sum((n - 1.0) ** 2 for n in grad_norm_sq) / len(grad_norm_sq)
    alpha, beta = 1.0, 1.0 # Chosen via cross-validation [S1]
    return alpha * l_render + beta * l_eik
```

## Subtopics

### NeuS
Uses SDF and volume rendering but lacks Instant-NSR's specific TSDF truncation mechanism for hash grids [S1]. Choose when simpler SDF integration is sufficient [G]. [6060-neus.md]

### Surface NeRF
Another SDF-based method. Compare based on specific loss formulations and encoding strategies [G]. [7385-surface-nerf.md]

### VolSDF
One of the earlier methods to introduce SDF into NeRF [G]. Instant-NSR improves upon this by using hash encoding for speed and TSDF for stability [S1]. [10715-volsdf.md]

## Operating characteristics
*   **Time Complexity:** Accelerated training compared to standard NeRF due to Hash encoding [S1].
*   **Memory Complexity:** Depends on the size of the hash grid and MLP, similar to [Instant-NGP](instant-ngp.md) [S1].
*   **Performance:** Demonstrates commendable performance in novel-view synthesis and competitive 3D reconstruction results compared to commercial MVS software like Reality Capture in agricultural contexts [S1].
*   **Strengths:** Fast training due to hash encoding; improved geometry quality via SDF; numerical stability via TSDF [S1].
*   **Limitations:** Requires careful tuning of hyperparameters $\alpha$ and $\beta$ via cross-validation [S1].
*   **When to use:** When fast training and high-quality geometry reconstruction are required, particularly in scenarios where standard SDF-NeRF methods suffer from numerical instability [S1].

## Background
Instant-NSR was explored in the context of high-fidelity 3D reconstruction of plants using Neural Radiance Fields [S1]. It builds upon the principles of [Instant-NGP](instant-ngp.md) for speed and [NeuS](6060-neus.md) for SDF-based rendering, introducing Truncated SDF (TSDF) to resolve convergence issues inherent in applying SDF representations to hash coding frameworks [S1]. The method was tested on datasets of indoor and outdoor orchards (pitahaya, grape, orange, fig) [S1].
