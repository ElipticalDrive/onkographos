# Surface NeRF

Also called: NeRF surf, Surface rendering via NeRF

## Overview
Surface NeRF converts a pre-trained Neural Radiance Field (NeRF) into a 3D mesh and a surface light field, reducing per-pixel rendering cost by evaluating the NeRF only at the surface isosurface rather than via volumetric raycasting [S1]. It achieves this by extracting an isosurface from the density field and optimizing both the geometry and the network parameters to maintain image quality, reducing per-pixel computational cost from 226 MFLOPS to 1.7 MFLOPS and runtime by more than 100x compared to baseline NeRF [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A pre-trained NeRF model (MLP mapping coordinates to density $\sigma$ and color $\mathbf{c}$) and a set of posed input images.
*   **Output:** An optimized 3D mesh (isosurface) and a finetuned NeRF network that acts as a surface light field.

**Data Structures:**
*   **Density Grid:** A regular 3D grid storing density values $\sigma$. This grid is used to define the isosurface.
*   **NeRF Network:** The original MLP parameters, finetuned during the optimization process.

**Parameters:**
*   **Isosurface Threshold:** 50 [S1].
*   **Optimization Iterations:** 5000 [S1].
*   **Optimizer (NeRF):** Adam [S1].
*   **Optimizer (Density Grid):** Standard Gradient Descent [S1].

**Steps:**
1.  **Density Field Construction:** Evaluate the pre-trained NeRF on a regular 3D grid to construct the input density field [S1].
2.  **Isosurface Extraction:** Extract an isosurface from the density field at the fixed threshold (50) to serve as the initial geometry [S1]. This surface is an accurate but noisy model of the subject shape [S1].
3.  **Initialization:** Since the NeRF was trained under the assumption of volume rendering, it must be finetuned to produce good results when evaluated only at the surface [S1].
4.  **Optimization Loop:** Perform 5000 iterations of alternating optimization [S1]:
    *   **Step A:** Render the isosurface using Rasterize-then-Splat (RtS). The NeRF network produces shaded colors $\mathbf{C}_k$ for the surface points, effectively acting as a surface light field [S1].
    *   **Step B:** Perform one gradient step on the NeRF network while holding the density grid fixed, minimizing the original NeRF L2 loss [S1].
    *   **Step C:** Perform one gradient step on the density grid while holding the NeRF network fixed, using standard gradient descent [S1].

**Pseudocode:**
```python
def surface_nerf_optimization(pretrained_nerf, input_images, grid_resolution, threshold=50, iterations=5000):
    """
    Optimizes a pre-trained NeRF into a surface representation.
    
    Args:
        pretrained_nerf: The initial NeRF MLP model.
        input_images: List of posed input images for loss calculation.
        grid_resolution: Resolution of the regular 3D grid.
        threshold: Isosurface extraction threshold.
        iterations: Number of optimization steps.
        
    Returns:
        optimized_nerf: Finetuned NeRF network.
        density_grid: Optimized density grid values.
    """
    # Step 1: Construct initial density field
    density_grid = evaluate_nerf_on_grid(pretrained_nerf, grid_resolution)
    
    # Step 2: Extract initial isosurface
    # This function extracts vertices and faces from the grid at the given threshold
    initial_surface = extract_isosurface(density_grid, threshold)
    
    # Step 3: Initialize optimizers
    # Adam for the NeRF network parameters
    nerf_optimizer = Adam(pretrained_nerf.parameters())
    # Standard Gradient Descent for the density grid
    # Note: Standard GD is used because Adam is unstable for grid optimization
    # due to the isosurface not constraining all grid values at each iteration [S1]
    grid_optimizer = GradientDescent(density_grid)
    
    for i in range(iterations):
        # Step 4a: Render surface using Rasterize-then-Splat (RtS)
        # The surface is rasterized, and for each pixel, the NeRF is queried
        # at the intersection point to get color C_k
        rendered_images = render_surface_rts(initial_surface, pretrained_nerf, input_images)
        
        # Calculate L2 loss between rendered images and input images
        loss = calculate_l2_loss(rendered_images, input_images)
        
        # Step 4b: Optimize NeRF network (hold grid fixed)
        nerf_optimizer.zero_grad()
        loss.backward()
        nerf_optimizer.step()
        
        # Step 4c: Optimize density grid (hold NeRF fixed)
        # Re-render to get gradients w.r.t. geometry
        # Note: The source implies alternating steps, so we re-evaluate or use
        # the same loss but differentiate w.r.t. grid.
        # In practice, this requires differentiating through the isosurface extraction
        # or using a differentiable surface representation.
        # The source states: "perform one gradient step on the density grid while 
        # holding the NeRF network fixed."
        
        # We need gradients of the loss with respect to the density grid.
        # This typically involves differentiating through the RtS rendering 
        # and the isosurface definition.
        grid_optimizer.zero_grad()
        
        # The loss is still based on the rendered image quality.
        # However, since the NeRF parameters are fixed, the gradient flows
        # through the surface geometry to the density grid.
        # This step assumes a differentiable path from density grid -> surface -> image.
        # If the isosurface extraction is non-differentiable (e.g., Marching Cubes),
        # this step might rely on the "Rasterize-then-splat" method's ability to
        # provide derivatives at occlusion boundaries [S1].
        
        # Compute gradient w.r.t density grid
        # Note: The source does not provide the explicit gradient formula for the grid,
        # but implies it is computed via backpropagation through the rendering process.
        loss.backward() # This computes gradients for all parameters in the computational graph.
                        # Since NeRF is fixed, we only care about grid gradients.
        
        # Update only the grid parameters
        grid_optimizer.step()
        
        # Update the surface geometry based on the new density grid
        # This step is necessary because the surface depends on the grid values.
        # The source mentions "After optimization, the isosurface is refined" [S1].
        # This implies the surface is re-extracted or updated after grid changes.
        initial_surface = extract_isosurface(density_grid, threshold)

    return pretrained_nerf, density_grid

def evaluate_nerf_on_grid(nerf, resolution):
    """
    Evaluates the NeRF on a regular 3D grid.
    """
    grid = np.zeros((resolution, resolution, resolution))
    # Iterate over all grid points
    for x in range(resolution):
        for y in range(resolution):
            for z in range(resolution):
                # Convert grid index to world coordinates
                coord = grid_index_to_world(x, y, z, resolution)
                # Query NeRF for density
                sigma = nerf.query_density(coord)
                grid[x, y, z] = sigma
    return grid

def extract_isosurface(density_grid, threshold):
    """
    Extracts an isosurface from the density grid at the given threshold.
    Uses Marching Cubes or similar algorithm.
    """
    # This is a non-differentiable operation in standard implementations,
    # but the paper claims RtS handles derivatives at occlusion boundaries [S1].
    # For the purpose of this article, we assume a standard extraction.
    vertices, faces = marching_cubes(density_grid, threshold)
    return Surface(vertices, faces)

def render_surface_rts(surface, nerf, images):
    """
    Renders the surface using Rasterize-then-Splat.
    """
    rendered = []
    for img in images:
        # Rasterize the surface to get screen-space coverage
        # Splat the surface points to pixels
        # For each pixel, query the NeRF at the surface intersection
        # to get the color C_k
        color = rasterize_and_splat(surface, nerf, img.camera_params)
        rendered.append(color)
    return rendered
```

**Edge Cases and Pitfalls:**
*   **Optimizer Instability:** Adam is unstable for optimizing the density grid because the isosurface does not constrain all grid values at each iteration [S1]. Standard gradient descent is used instead [S1].
*   **Complex Geometry:** On scenes with extremely complex isosurfaces (e.g., Fern), the quality improvement over the fixed surface baseline is limited [S1]. The method may lose PSNR compared to full volume rendering in such cases [S1].
*   **Discretization:** The method requires a closed-form evaluation function. For surfaces defined via subdivision schemes or Marching Cubes discretization, quality may be affected by the discretization resolution [S1].

## Operating characteristics
*   **Computational Cost:** Reduces per-pixel computational cost from 226 MFLOPS (volume rendering) to 1.7 MFLOPS (SNeRF) [S1]. This is a reduction of more than 100x in runtime compared to baseline NeRF rendering [S1].
*   **Memory:** Not given in the sources.
*   **Quality:** On the Lego dataset, SNeRF achieves a PSNR of 29.61, which is within 0.3 of the baseline NeRF PSNR of 29.91 [S1]. On the Fern dataset, SNeRF achieves a PSNR of 23.52, losing 0.9 PSNR to full volume rendering (24.38) [S1].
*   **Optimization Benefit:** On the Lego dataset, SNeRF improves 2.2 PSNR over the baseline without surface optimization (SNeRF fixed, PSNR 27.44) [S1]. On the Fern dataset, it improves only 0.1 PSNR over the fixed surface baseline (23.41) [S1].
*   **Strengths:** Significant reduction in rendering time; flexible surface representation (can apply to any surface expressible as a non-differentiable sampling and differentiable evaluation function) [S1].
*   **Limitations:** Requires a closed-form evaluation function; quality may degrade on complex scenes with noisy isosurfaces; assumes a single surface at each pixel during splatting [S1].

## Background
Surface NeRF was introduced in the paper "Differentiable Surface Rendering via Non-Differentiable Sampling" [S1]. It builds on the original NeRF method [4972-neural-radiance-fields.md], which produces high-quality view synthesis at the cost of long rendering times [S1]. The method leverages the ability to convert a pre-trained NeRF into a 3D mesh and a surface light field [S1]. It utilizes the Rasterize-then-Splat (RtS) technique, which addresses issues of differentiable surface rendering such as handling varying surface representations and providing derivatives at occlusion boundaries [S1].
