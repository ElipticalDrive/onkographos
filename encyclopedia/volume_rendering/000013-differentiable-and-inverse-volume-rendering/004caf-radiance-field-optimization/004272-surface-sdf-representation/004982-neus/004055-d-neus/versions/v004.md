# D-NeuS

Also called: Details recovering Neural implicit Surface reconstruction

## Overview
D-NeuS is a volume rendering-based neural implicit surface reconstruction method that recovers fine-level geometric details by extending NeuS with two additional loss functions: a geometry bias loss and a multi-view feature consistency loss [S1, unofficial]. It addresses the ambiguity in geometry and appearance representation inherent in volume rendering by ensuring consistency between the rendered surface points (derived from alpha compositing) and the underlying signed distance field (SDF) zero-crossings [S1, unofficial]. Unlike its parent NeuS, which suffers from geometry bias due to the non-linear transformation of SDF to density, D-NeuS explicitly penalizes this bias and enforces feature consistency on surface points rather than all sampled points, distinguishing it from siblings like HAME-NeRF and NeuS2 [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of multi-view images of a static scene [S1, unofficial].
*   **Outputs:** A trained implicit neural network representing the scene geometry (SDF) and appearance (radiance), from which a mesh can be extracted [S1, unofficial].

**Data Structures and Network Layout:**
1.  **Geometry Network ($f$):** An MLP mapping $\mathbb{R}^3 \to \mathbb{R}$ [S1, unofficial].
    *   Architecture: 8 hidden layers, each with 256 units [S1, unofficial].
    *   Skip connections: From input to the output of the 4th hidden layer [S1, unofficial].
    *   Initialization: Weights initialized to approximate the SDF field of a unit sphere [S1, unofficial].
2.  **Radiance Network ($g$ or $c$):** An MLP mapping spatial position, view direction, normal, and feature vector to color $\mathbb{R}^3$ [S1, unofficial].
    *   Architecture: 4 hidden layers, each with 256 units [S1, unofficial].
    *   Inputs: Spatial point $\mathbf{x}$, view direction $\mathbf{v}$, normal $\mathbf{n}$, and feature vector $\mathbf{z}$ [S1, unofficial].
3.  **Position Encoding:**
    *   Spatial coordinates $\mathbf{x}$: 6 frequencies [S1, unofficial].
    *   View direction $\mathbf{v}$: 4 frequencies [S1, unofficial].
4.  **Feature Consistency:**
    *   Feature channels: $N_c = 32$ [S1, unofficial].
    *   Neighboring views: $N_v = 2$ source views compared against each reference view [S1, unofficial].

**Mathematical Formulation:**
The surface $\mathcal{S}$ is defined as the zero-level set of the SDF $f$:
$$ \mathcal{S} = \{ \mathbf{x} \in \mathbb{R}^3 \mid f(\mathbf{x}) = 0 \} \quad (1) $$

A 3D point on a ray from camera center $\mathbf{o}$ with direction $\mathbf{v}$ is:
$$ \mathbf{x}(t) = \mathbf{o} + t\mathbf{v}, \quad t \ge 0 \quad (2) $$

The normal $\mathbf{n}$ is computed via automatic differentiation of the SDF:
$$ \mathbf{n} = \nabla f(\mathbf{x}) $$

The opaque density $\sigma(t)$ is derived from the SDF using a sigmoid function $\Phi_s$:
$$ \sigma(t) = \max \left( -\frac{d\Phi_s}{dt}(f(\mathbf{x}(t))), 0 \right) \quad (5) $$
where $\Phi_s(x) = (1 + e^{-sx})^{-1}$ and $s^{-1}$ is a trainable standard deviation [S1, unofficial].

**Numbered Steps:**

1.  **Sampling:** For each iteration, sample 512 rays. For each ray, generate 64 coarse points, 64 fine points, and 32 additional points outside the unit sphere (following NeRF++ strategy) [S1, unofficial].
2.  **SDF Evaluation:** Query the geometry network $f$ for all sampled points to obtain SDF values $f(\mathbf{x}(t))$ [S1, unofficial].
3.  **Density and Alpha Compositing:** Compute density $\sigma(t)$ using Eq. (5). Perform volume rendering to accumulate color $C_r$ and alpha weights $w(t)$ [S1, unofficial].
4.  **Surface Point Interpolation:** Find the first zero-crossing of the SDF along the ray. Instead of recursive ray tracing, use locally differentiable linear interpolation between adjacent sampled points where the SDF sign changes to estimate the surface point $\mathbf{x}_s$ [S1, unofficial].
5.  **Feature Extraction:** Extract feature vectors $\mathbf{z}$ from the geometry network $f$ at the surface point $\mathbf{x}_s$ [S1, unofficial].
6.  **Loss Calculation:**
    *   **Photometric Loss:** Standard difference between rendered color and ground truth [S1, unofficial].
    *   **Eikonal Loss:** Regularizes the gradient of the SDF to be unit length [S1, unofficial]. Weight $\alpha = 0.1$ [S1, unofficial].
    *   **Geometry Bias Loss:** Generate additional distance maps during rendering [S1, unofficial]. Back-project these distances to 3D points [S1, unofficial]. Penalize the absolute SDF values predicted by $f$ at these points to encourage consistency between the rendered surface and the implicit surface [S1, unofficial]. Weight $\beta$ varies by stage [S1, unofficial].
    *   **Multi-view Feature Consistency Loss:** Compare feature vectors $\mathbf{z}$ of the surface point $\mathbf{x}_s$ from the reference view with those from $N_v=2$ neighboring source views [S1, unofficial]. Use CNNs for robust feature representation [S1, unofficial]. Weight $\gamma$ varies by stage [S1, unofficial].
7.  **Optimization:** Update network weights using the Adam optimizer [S1, unofficial].
8.  **Mesh Extraction:** After training, apply Marching Cubes to the SDF field $f$ in a bounding box of size $512^3$ voxels [S1, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.optim as optim
import math

class GeometryMLP(nn.Module):
    def __init__(self, in_dim=9, hidden_dim=256, num_layers=8):
        super().__init__()
        self.layers = nn.ModuleList([nn.Linear(hidden_dim, hidden_dim) for _ in range(num_layers)])
        self.input_layer = nn.Linear(in_dim, hidden_dim)
        self.skip_layer = nn.Linear(in_dim, hidden_dim)

    def forward(self, x):
        h = self.input_layer(x)
        h_skip = self.skip_layer(x)
        for i, layer in enumerate(self.layers):
            h = torch.relu(layer(h))
            if i == 3:
                h = h + h_skip
        return h

class RadianceMLP(nn.Module):
    def __init__(self, in_dim=256, hidden_dim=256, num_layers=4):
        super().__init__()
        self.layers = nn.ModuleList([nn.Linear(hidden_dim, hidden_dim) for _ in range(num_layers)])
        self.input_layer = nn.Linear(in_dim, hidden_dim)

    def forward(self, z, v, n):
        h = self.input_layer(z)
        for layer in self.layers:
            h = torch.relu(layer(h))
        return h

def sigmoid_density(sdf, s):
    # Derivative of Phi_s(x) = (1 + exp(-sx))^-1 is s*exp(-sx)/(1+exp(-sx))^2
    pdf = s * torch.exp(-s * sdf) / (1 + torch.exp(-s * sdf))**2
    return torch.clamp(pdf, min=0.0)

def find_zero_crossing(t_vals, sdf_vals):
    signs = torch.sign(sdf_vals)
    change = (signs[:-1] * signs[1:]) < 0
    if not torch.any(change):
        return None
    idx = torch.argmax(change)
    t0, t1 = t_vals[idx], t_vals[idx+1]
    s0, s1 = sdf_vals[idx], sdf_vals[idx+1]
    # Linear interpolation for zero crossing
    t_s = t0 - s0 * (t1 - t0) / (s1 - s0)
    return t_s

def sample_points_uniform(t_min, t_max, num_samples):
    return torch.rand(num_samples) * (t_max - t_min) + t_min

def volume_render(rays_o, rays_d, sigma, t_vals, geometry_net, radiance_net):
    # Compute transmittance and weights
    dt = (t_vals[:, 1:] - t_vals[:, :-1]).unsqueeze(-1)
    alpha = 1.0 - torch.exp(-sigma * dt)
    T = torch.cumprod(1.0 - alpha + 1e-10, dim=1)[:, :-1]
    weights = T * alpha
    
    # Evaluate geometry and radiance at all sample points
    x_all = rays_o.unsqueeze(1) + t_vals.unsqueeze(2) * rays_d.unsqueeze(1)
    sdf_all = geometry_net(x_all)
    n_all = torch.autograd.grad(sdf_all.sum(), x_all, create_graph=True)[0]
    z_all = sdf_all # Feature vector z from geometry network
    c_all = radiance_net(z_all, rays_d.unsqueeze(1), n_all)
    
    C_r = torch.sum(weights * c_all, dim=1)
    return C_r, weights, x_all, sdf_all, n_all, z_all

def compute_feature_consistency_loss(z_ref, z_src, Nv=2):
    loss = 0.0
    for i in range(Nv):
        loss += torch.mean((z_ref - z_src[:, i])**2)
    return loss / Nv

def adjust_learning_rate(optimizer, iteration, initial_lr=5e-4, min_lr=2.5e-5, warmup=5000, total_iters=300000):
    if iteration < warmup:
        lr = initial_lr * (iteration / warmup)
    else:
        lr = min_lr + 0.5 * (initial_lr - min_lr) * (1 + math.cos(math.pi * (iteration - warmup) / (total_iters - warmup)))
    for param_group in optimizer.param_groups:
        param_group['lr'] = lr

def train_d_neus(geometry_net, radiance_net, images, num_iters=300000):
    optimizer = optim.Adam(list(geometry_net.parameters()) + list(radiance_net.parameters()), lr=5e-4)
    s = nn.Parameter(torch.tensor(0.3))

    for i in range(num_iters):
        # Stage-based loss weights
        if i < 50000:
            beta, gamma = 0.01, 0.0
        elif i < 150000:
            beta, gamma = 0.1, 0.5
        else:
            beta, gamma = 0.01, 0.05
        alpha = 0.1

        # 1. Sampling
        rays_o, rays_d = torch.randn(512, 3), torch.nn.functional.normalize(torch.randn(512, 3), dim=1)
        t_coarse = sample_points_uniform(0.0, 1.0, 64)
        t_fine = sample_points_uniform(0.0, 1.0, 64)
        t_out = sample_points_uniform(1.0, 2.0, 32) # Outside unit sphere
        t_all = torch.cat([t_coarse, t_fine, t_out], dim=0)

        # 2. SDF Evaluation & 3. Density & Alpha Compositing
        x_all = rays_o.unsqueeze(1) + t_all.unsqueeze(0) * rays_d.unsqueeze(1)
        sdf_vals = geometry_net(x_all)
        sigma = sigmoid_density(sdf_vals, s)
        C_r, weights, x_all, sdf_all, n_all, z_all = volume_render(rays_o, rays_d, sigma, t_all, geometry_net, radiance_net)

        # 4. Surface Point Interpolation
        t_s = find_zero_crossing(t_coarse, sdf_vals[:, :64])
        x_s = rays_o + t_s.unsqueeze(1) * rays_d.unsqueeze(1)
        z_s = geometry_net(x_s)

        # 5. Loss Calculation
        loss_photo = torch.mean((C_r - images)**2)
        
        # Eikonal Loss
        grad_f = torch.autograd.grad(sdf_all.sum(), x_all, create_graph=True)[0]
        loss_eikonal = torch.mean((grad_f.norm(dim=-1) - 1)**2)
        
        # Geometry Bias Loss
        # Back-project distances to 3D points and penalize absolute SDF values
        # Note: Exact back-projection method not detailed in sources [S1, unofficial]
        bias_points = x_all[:, :64, :] # Simplified back-projection to coarse points
        loss_bias = torch.mean(torch.abs(geometry_net(bias_points)))
        
        # Multi-view Feature Consistency Loss
        # Compare features of surface point with neighboring views
        z_src = geometry_net(x_s) # Placeholder for neighboring view features
        loss_feature = compute_feature_consistency_loss(z_s, z_src)

        loss = loss_photo + alpha * loss_eikonal + beta * loss_bias + gamma * loss_feature
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        adjust_learning_rate(optimizer, i)
```

**Edge Cases and Pitfalls:**
*   **Precision:** The linear interpolation for zero-crossing must be locally differentiable to allow backpropagation through the surface point selection [S1, unofficial].
*   **Boundaries:** The inclusion of 32 points outside the unit sphere helps handle boundaries and occlusions [S1, unofficial].
*   **Degenerate Input:** The method assumes a static scene [S1, unofficial].

## Subtopics

### [MS-NeuS](11716-ms-neus.md)
MS-NeuS integrates the Multi-Space (MS) module into the NeuS framework to address multi-view inconsistency, specifically improving novel view synthesis and the reconstruction of mirror surfaces. It distinguishes itself from its parent [D-NeuS](10217-d-neus.md) by focusing on view-dependent appearance consistency via sub-space decomposition rather than explicit geometric bias or feature consistency losses.

## Operating characteristics
*   **Time Complexity:** Training takes approximately 19 hours on a single NVIDIA Titan RTX for 300k iterations [S1, unofficial].
*   **Memory Complexity:** Not given in the sources [S1, unofficial].
*   **Measured Performance:** Rendering an image of resolution $1200 \times 1600$ takes approximately 7 minutes on the described hardware [S1, unofficial]. Mesh extraction takes about 57 seconds [S1, unofficial].
*   **Scaling:** Not given in the sources [S1, unofficial].
*   **Strengths:** Recovers high-accuracy surface geometry, especially fine details and complex scenes. On the DTU dataset, D-NeuS achieves a mean Chamfer distance of 32.22, compared to 31.97 for NeuS, and achieves higher PSNR than state-of-the-art methods when evaluated only on pixels inside object masks [S1, unofficial].
*   **Limitations:** Computationally expensive training and inference (7 mins per image). Relies on multi-view consistency which may struggle with highly reflective or textureless surfaces without additional priors (though MS-NeuS addresses this) [S1, unofficial].
*   **When to use:** When high-fidelity geometric reconstruction is required from multi-view images, particularly for complex scenes with fine details [S1, unofficial].
*   **When not:** When real-time rendering is required or when only a small number of views are available (though it uses neighboring views, sparse views may degrade performance) [S1, unofficial].

## Background
D-NeuS builds upon the NeuS method, which itself was designed to improve geometric reconstruction quality by using a signed distance field (SDF) representation [S1, unofficial]. The key insight of D-NeuS is the analysis of geometry bias arising from the transformation of SDF to density for volume rendering, and the proposal of a novel constraint to regularize this bias [S1, unofficial]. It also incorporates multi-view feature consistency using CNNs, inspired by MVSDF, to recover fine local geometric details [S1, unofficial]. The method was evaluated on the DTU and BlendedMVS datasets [S1, unofficial].
