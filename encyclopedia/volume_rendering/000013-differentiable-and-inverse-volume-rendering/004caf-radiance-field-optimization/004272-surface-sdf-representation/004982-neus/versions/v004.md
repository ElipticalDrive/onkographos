# NeuS

Also called: NeuS, Learning Neural Implicit Surfaces by Volume Rendering for Multi-view Reconstruction

## Overview
NeuS is a neural surface reconstruction method that represents a scene geometry as the zero-level set of a learnable Signed Distance Function (SDF) and trains it using a novel volume rendering scheme [S1, unofficial]. It solves the problem of geometric bias inherent in standard volume rendering when applied to SDFs, where naive density conversions cause the reconstructed surface to deviate from the true SDF zero-level set [S1, unofficial]. Unlike its siblings [Surface NeRF](7385-surface-nerf.md) and [VolSDF](10715-volsdf.md), which also use SDFs, NeuS derives an unbiased weight function for volume rendering that ensures the surface is recovered with first-order accuracy, allowing high-quality mesh extraction without foreground mask supervision [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of posed RGB images $\{I_k\}$ of a 3D object.
*   **Output:** A learned SDF $f(\mathbf{x})$ and color function $c(\mathbf{x}, \mathbf{v})$, from which a triangular mesh is extracted via Marching Cubes [S1, unofficial].

**Data Structures:**
The scene is represented by two Multi-Layer Perceptrons (MLPs) [S1, unofficial]:
1.  **SDF Network ($f$):** Maps spatial position $\mathbf{x} \in \mathbb{R}^3$ to a scalar SDF value $d \in \mathbb{R}$ and a geometry feature vector $\mathbf{g} \in \mathbb{R}^{15}$ [S4].
    *   **Architecture:** 8 hidden layers, hidden size 256.
    *   **Activation:** Softplus with $\beta = 100$ replaces ReLU in all hidden layers [S1, unofficial].
    *   **Skip Connection:** Input is concatenated to the output of the 4th hidden layer [S1, unofficial].
    *   **Input Encoding:** Positional encoding applied to $\mathbf{x}$ with 6 frequencies [S1, unofficial].
2.  **Color Network ($c$):** Maps spatial position $\mathbf{x}$, viewing direction $\mathbf{v}$, normal $\mathbf{n}$, SDF value $d$, and feature $\mathbf{g}$ to RGB color [S1, unofficial].
    *   **Architecture:** 4 hidden layers, hidden size 256.
    *   **Input Encoding:** Positional encoding applied to $\mathbf{v}$ with 4 frequencies [S1, unofficial].
    *   **Normalization:** Weight normalization is used to stabilize training [S1, unofficial].

**Parameters:**
*   $s$: A trainable scalar parameter controlling the sharpness of the S-density distribution. The standard deviation is $1/s$ [S1, unofficial].
*   $\beta_{softplus}$: Softplus activation parameter, fixed at 100 [S1, unofficial].
*   $\beta_{eikonal}$: Weight for the Eikonal loss term [S4].

**Algorithm:**

1.  **Ray Sampling:** For a camera ray $\mathbf{p}(t) = \mathbf{o} + t\mathbf{v}$, sample $n$ points. NeuS uses hierarchical sampling:
    *   Uniformly sample 64 points initially [S1, unofficial].
    *   Perform $k=4$ iterations of importance sampling, adding 16 points per iteration [S1, unofficial].
    *   Total sampled points: 128 [S1, unofficial].
    *   For "w/o mask" settings, sample an additional 32 points outside the bounding sphere to model the background using a NeRF++ approach [S1, unofficial].

2.  **SDF and Gradient Computation:** For each sample point $\mathbf{p}_i$:
    *   Query SDF network to get $d_i = f(\mathbf{p}_i)$ and feature $\mathbf{g}_i$ [S4].
    *   Compute the gradient $\nabla f(\mathbf{p}_i)$ using automatic differentiation [S4].
    *   Compute the normal $\mathbf{n}_i = \nabla f(\mathbf{p}_i) / \|\nabla f(\mathbf{p}_i)\|$ [S1, unofficial].

3.  **Alpha Computation (Unbiased Volume Rendering):**
    NeuS defines an S-density function $\phi_s(x)$ as the derivative of the Sigmoid CDF $\Phi_s(x)$ [S1, unofficial]:
    $$ \phi_s(x) = \frac{s e^{-sx}}{(1 + e^{-sx})^2} $$
    $$ \Phi_s(x) = \frac{1}{1 + e^{-sx}} $$
    
    For a segment between section points $q_i$ and $q_{i+1}$ (where $q_i = \mathbf{o} + t_i \mathbf{v}$), the alpha value $\alpha_i$ is computed as [S1, unofficial]:
    $$ \alpha_i = \max\left( \frac{\Phi_s(f(q_i)) - \Phi_s(f(q_{i+1}))}{\Phi_s(f(q_i))}, 0 \right) $$
    
    *Note: In implementations using learnable variance (e.g., Instant-NSR-PL), $s$ is replaced by $inv\_s = \exp(variance \times 10.0)$, clipped to $[10^{-6}, 10^6]$ to prevent numerical instability [S6, unofficial].*

4.  **Color Computation:**
    The color $c_i$ for the segment is obtained by querying the color network at the midpoint $p_i = \mathbf{o} + \frac{t_i + t_{i+1}}{2} \mathbf{v}$, using inputs $\mathbf{p}_i, \mathbf{v}, \mathbf{n}_i, d_i, \mathbf{g}_i$ [S1, unofficial].

5.  **Volume Rendering:**
    The final pixel color $C(\mathbf{o}, \mathbf{v})$ is computed by standard alpha compositing along the ray [S1, unofficial]:
    $$ C(\mathbf{o}, \mathbf{v}) = \sum_{i=1}^{n} T_i \alpha_i c_i $$
    where $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$ is the transmittance.

6.  **Loss Function:**
    The total loss $\mathcal{L}$ combines color reconstruction and geometric regularization [S4]:
    $$ \mathcal{L} = \mathcal{L}_{\text{color}} + \beta_{\text{eikonal}} \mathcal{L}_{\text{eikonal}} $$
    *   $\mathcal{L}_{\text{color}}$: Huber loss between rendered and ground truth pixels [S4].
    *   $\mathcal{L}_{\text{eikonal}}$: $\frac{1}{n} \sum_{i=1}^n (\|\nabla f(\mathbf{p}_i)\| - 1)^2$, enforcing the Eikonal equation $\|\nabla f\| \approx 1$ [S4].

7.  **Training:**
    *   Optimizer: ADAM [S1, unofficial].
    *   Learning Rate: Linear warmup from 0 to $5 \times 10^{-4}$ over 5,000 iterations, then cosine decay to minimum $2.5 \times 10^{-5}$ [S1, unofficial].
    *   Total Iterations: 300,000 [S1, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class NeuS:
    def __init__(self, num_samples=128, num_importance=4, num_uniform=64):
        self.sdf_net = SDFNetwork() # 8 layers, 256 hidden, Softplus(100)
        self.color_net = ColorNetwork() # 4 layers, 256 hidden
        self.s = nn.Parameter(torch.tensor(32.0)) # Initial sharpness param
        self.num_samples = num_samples
        self.num_importance = num_importance
        self.num_uniform = num_uniform

    def forward(self, rays_o, rays_d, gt_rgb, mask=None):
        # 1. Hierarchical Sampling
        t_vals = torch.linspace(0., 1., steps=self.num_uniform)
        z_vals = 0.1 * t_vals + 0.9 * t_vals ** 2 # Near-far bounds assumed normalized or scaled
        
        # Initial uniform samples
        pts_uniform = rays_o.unsqueeze(-2) + rays_d.unsqueeze(-2) * z_vals.unsqueeze(-1)
        
        # Importance sampling iterations
        pts = pts_uniform
        for i in range(self.num_importance):
            # Compute coarse alpha using current s
            sdf_uniform = self.sdf_net(pts_uniform).squeeze(-1)
            alpha_uniform = self.compute_alpha(sdf_uniform, self.s)
            
            # Compute weights for importance sampling
            weights = alpha_uniform * torch.cumprod(torch.cat([torch.ones_like(alpha_uniform[:, :1]), 1. - alpha_uniform[:, :-1] + 1e-10], dim=-1), dim=-1)
            weights = weights / (weights.sum(dim=-1, keepdim=True) + 1e-10)
            
            # Resample
            z_vals_importance = torch.linspace(0., 1., steps=self.num_samples // (self.num_importance + 1))
            # ... (Resampling logic based on weights) ...
            # For brevity, assuming pts is updated to include importance samples
            pts = torch.cat([pts_uniform, pts_importance], dim=-2)
            pts = pts.sort(dim=-2).values

        # 2. Query SDF and Gradients
        pts_flat = pts.reshape(-1, 3)
        sdf_val = self.sdf_net(pts_flat) # Returns (N, 1)
        sdf = sdf_val.squeeze(-1)
        
        # Compute gradients for normals and Eikonal loss
        grad_outputs = torch.ones_like(sdf)
        grad = torch.autograd.grad(
            outputs=sdf, inputs=pts_flat, grad_outputs=grad_outputs,
            create_graph=True, retain_graph=True, only_inputs=True
        )[0] # (N, 3)
        
        normals = grad / (grad.norm(dim=-1, keepdim=True) + 1e-10)
        
        # Reshape back to ray structure
        sdf = sdf.reshape(pts.shape[:-1])
        normals = normals.reshape(pts.shape[:-2] + (3,))
        
        # 3. Compute Alpha and Color
        # Section points are pts, midpoints are between pts[i] and pts[i+1]
        # Alpha calculation uses section points (S1)
        alpha = self.compute_alpha(sdf, self.s)
        
        # Midpoints for color
        mid_pts = (pts[:, :-1, :] + pts[:, 1:, :]) / 2.0
        mid_pts_flat = mid_pts.reshape(-1, 3)
        
        # Query Color Network
        # Inputs: position, view_dir, normal, sdf_val, feature
        # Note: normals and sdf_val need to be aligned with mid_pts
        # Simplified: assuming normals/sdf are interpolated or queried at midpoints
        # In original NeuS, normal is computed at sample points, used for color
        # Here we approximate by using the normal at the start of the segment or midpoint
        mid_normals = normals[:, :-1, :] 
        mid_sdf = sdf[:, :-1]
        
        # Get features from SDF net (requires re-query or storing)
        # For implementation completeness, assume feature extraction is part of sdf_net forward
        # color_net takes (x, v, n, d, feature)
        # ... query feature ...
        
        rgb = self.color_net(mid_pts_flat, rays_d, mid_normals, mid_sdf, features)
        rgb = rgb.reshape(pts.shape[:-2] + (3,))
        
        # 4. Composite
        # Transmittance T_i = product(1 - alpha_j) for j < i
        T = torch.cumprod(torch.cat([torch.ones_like(alpha[:, :1]), 1. - alpha[:, :-1] + 1e-10], dim=-1), dim=-1)
        weights = alpha * T
        comp_rgb = (weights.unsqueeze(-1) * rgb).sum(dim=-2)
        
        # 5. Loss
        loss_color = F.huber_loss(comp_rgb, gt_rgb)
        
        # Eikonal loss at sample points
        grad_norm = grad.norm(dim=-1)
        loss_eikonal = ((grad_norm - 1.0) ** 2).mean()
        
        total_loss = loss_color + 0.1 * loss_eikonal # Beta_eikonal typical value not specified, using 0.1 as placeholder [G]
        
        return comp_rgb, total_loss

    def compute_alpha(self, sdf, s):
        # Phi_s(x) = 1 / (1 + exp(-s*x))
        # Alpha_i = (Phi(q_i) - Phi(q_{i+1})) / Phi(q_i)
        phi_prev = 1.0 / (1.0 + torch.exp(-s * sdf[:, :-1]))
        phi_next = 1.0 / (1.0 + torch.exp(-s * sdf[:, 1:]))
        
        alpha = (phi_prev - phi_next) / (phi_prev + 1e-10)
        alpha = torch.clamp(alpha, 0.0, 1.0)
        return alpha
```

## Subtopics

### [HAME-NeRF](9325-hame-nerf.md)
HAME-NeRF is a two-stage framework for extracting high-fidelity, textured surface meshes from RGB images by defining volume density as a Secant Hyperbolic Function applied to a Signed Distance Function (SDF). It builds on [NeuS](6060-neus.md) by introducing a spatially-varying sharpness parameter $\beta(\mathbf{x})$ learned via an MLP, which enhances flexibility for complex surfaces compared to methods using fixed $\beta$ values. Unlike [NeuS](6060-neus.md) which focuses on differentiable volume rendering for surface representation, HAME-NeRF explicitly optimizes a mesh through differentiable rendering and iterative refinement, achieving superior geometric accuracy and visual quality on synthetic benchmarks compared to [NeRF2Mesh](52-nerf2mesh.md).

### [D-NeuS](10217-d-neus.md)
D-NeuS is a volume rendering-based neural implicit surface reconstruction method that recovers fine-level geometric details by extending NeuS with two additional loss functions: a geometry bias loss and a multi-view feature consistency loss. It addresses the ambiguity in geometry and appearance representation inherent in volume rendering by ensuring consistency between the rendered surface points (derived from alpha compositing) and the underlying signed distance field (SDF) zero-crossings. Unlike its parent NeuS, which suffers from geometry bias due to the non-linear transformation of SDF to density, D-NeuS explicitly penalizes this bias and enforces feature consistency on surface points rather than all sampled points, distinguishing it from siblings like HAME-NeRF and NeuS2.

### NeuS2
NeuS2 is a fast neural surface reconstruction approach for multi-view RGB input that achieves two orders of magnitude improvement in training speed over NeuS without compromising reconstruction quality, applicable to both static and dynamic scenes [S1, unofficial]. It sets itself apart by parameterizing the neural network-encoded Signed Distance Field (SDF) using multi-resolution hash tables of learnable feature vectors, as introduced in Instant-NGP, and by calculating second-order derivatives using a novel lightweight formula tailored to ReLU-based MLPs to leverage CUDA parallelism and reduce memory footprint [S1, unofficial].

### [HF-NeuS](12039-hf-neus.md)
HF-NeuS is an improvement on NeuS that separates low-frequency details into a base SDF and high-frequency details into a displacement function to increase reconstruction quality. It builds on [NeuS](6060-neus.md) by addressing the smoothness limitations of standard implicit SDF representations, which often fail to capture sharp geometric features.

### SparseNeus
SparseNeus is a method improving NeuS for sparse-view SDF reconstruction using a geometry encoding volume with learnable image features as a hybrid representation method [S3].

## Operating characteristics
*   **Time Complexity:** Training is significantly slower than standard NeRF because SDF queries require more network evaluations per ray (SDF, gradient, feature) [S2]. On a single Nvidia 2080Ti GPU, rendering a 1600x1200 image takes ~320 seconds in default volume rendering settings, or ~60 seconds with sphere tracing acceleration [S1, unofficial].
*   **Memory Complexity:** Requires storing gradients for backpropagation of the Eikonal loss, which involves second-order derivatives if not optimized [S4].
*   **Performance:** On the NeRF Synthetic dataset, NeuS achieved a PSNR of $28.4 \pm 0.8$ dB [S2]. On the DTU dataset, it achieved the most accurate surface reconstruction with a Chamfer distance of $0.62 \pm 0.08$ mm [S2].
*   **Strengths:** Provides high-quality, watertight meshes without requiring foreground masks; robust to complex structures and occlusions; theoretically unbiased surface recovery [S1, unofficial].
*   **Limitations:** Slow training and rendering speeds; sensitive to textureless regions which may fail to reconstruct correctly; random initialization can cause axis-aligned artifacts due to spectral bias of positional encoding [S1, unofficial].
*   **When to use:** When high-fidelity geometric surface reconstruction is required from multi-view images and training time is not the primary constraint.
*   **When not to use:** For real-time rendering or very large-scale scenes where speed is critical; for scenes with large textureless areas.

## Background
NeuS was introduced in 2021 by Yen-Chen Lin et al. in the paper "NeuS: Learning Neural Implicit Surfaces by Volume Rendering for Multi-view Reconstruction" [S1, unofficial]. It was developed to address the limitations of previous implicit surface methods like IDR, which lacked robust optimization in the presence of abrupt depth changes, and standard NeRF, which did not explicitly represent surfaces. NeuS combines the accuracy of neural SDFs with the robustness of volume rendering. It is widely used in 3D computer vision for high-quality surface reconstruction from multi-view images, particularly in datasets like DTU and BlendedMVS [S1, unofficial].
