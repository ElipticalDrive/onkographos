# NeuS

Also called: NeuS, Learning Neural Implicit Surfaces by Volume Rendering for Multi-view Reconstruction

## Overview
NeuS is a neural surface reconstruction method that represents a scene geometry as the zero-level set of a learnable Signed Distance Function (SDF) and trains it using a novel volume rendering scheme to avoid the geometric bias inherent in standard volume rendering applications to SDFs [S1, unofficial][S3]. It differs from its parent [Radiance-field optimization](44-radiance-field-optimization.md) by replacing the density-outputting MLP with an SDF-outputting MLP and deriving a specific S-density probability distribution to compute segment alphas, ensuring unbiased surface reconstruction in the first-order approximation [S1, unofficial][S3]. Unlike [Surface NeRF](7385-surface-nerf.md) which uses occupancy values, NeuS allows natural extraction of the surface as the zero-level set, yielding higher accuracy [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** A set of posed RGB images $\{I_k\}$ of a 3D object.
- **Outputs:** A trained SDF network $f(\mathbf{x})$ and color network $c(\mathbf{x}, \mathbf{v})$, from which a mesh is extracted via Marching Cubes [S1, unofficial][S2].

**Data Structures:**
The scene is represented by two Multi-layer Perceptrons (MLPs) [S1, unofficial]:
1.  **SDF Network ($f$):** Maps spatial position $\mathbf{x} \in \mathbb{R}^3$ to a scalar signed distance $d = f(\mathbf{x})$ and a geometry feature vector $\mathbf{g} \in \mathbb{R}^{15}$ [S4].
    -   Architecture: 8 hidden layers, hidden size 256.
    -   Activation: Softplus with $\beta=100$ (replacing ReLU) [S1, unofficial].
    -   Skip connection: From input to the output of the 4th layer [S1, unofficial].
2.  **Color Network ($c$):** Maps position $\mathbf{x}$, viewing direction $\mathbf{v}$, normal $\mathbf{n}$, and feature $\mathbf{g}$ to RGB color [S1, unofficial].
    -   Architecture: 4 hidden layers, hidden size 256 [S1, unofficial].
    -   Inputs: Spatial location $\mathbf{p}$ (positional encoded), view direction $\mathbf{v}$ (positional encoded), normal $\mathbf{n} = \nabla f(\mathbf{p}) / \|\nabla f(\mathbf{p})\|$, and feature $\mathbf{g}$ from the SDF network [S1, unofficial].
    -   Positional Encoding: 6 frequencies for $\mathbf{p}$, 4 frequencies for $\mathbf{v}$ [S1, unofficial].
    -   Weight normalization is applied to stabilize training [S1, unofficial].

**Parameters:**
-   $s$: A trainable scalar parameter controlling the sharpness of the S-density distribution. The standard deviation of the S-density is $1/s$, which approaches 0 as training converges [S1, unofficial].
-   $\beta$: Weight for the Eikonal loss term [S4].
-   Learning Rate: Warmup from 0 to $5 \times 10^{-4}$ in first 5k iterations, then cosine decay to minimum $2.5 \times 10^{-5}$ [S1, unofficial].

**Algorithm:**

1.  **Ray Sampling:**
    For a ray $p(t) = \mathbf{o} + t\mathbf{v}$ ($t \ge 0$), sample $N=128$ points [S1, unofficial].
    -   Initial uniform sampling of 64 points.
    -   Iterative importance sampling for $k=4$ iterations, adding 16 points per iteration [S1, unofficial].
    -   In the $i$-th importance sampling iteration, coarse probability estimation uses a fixed $s_i = 32 \times 2^i$ [S1, unofficial].
    -   For 'w/o mask' settings, sample extra 32 points outside the bounding sphere to represent the background using a NeRF++-style approach [S1, unofficial].

2.  **SDF and Gradient Computation:**
    For each sample point $\mathbf{p}_i$ on the ray:
    -   Compute SDF value $d_i = f(\mathbf{p}_i)$ [S1, unofficial].
    -   Compute gradient $\nabla f(\mathbf{p}_i)$ and normalize to get normal $\mathbf{n}_i$ [S1, unofficial].

3.  **Alpha Computation (Unbiased Volume Rendering):**
    NeuS defines an S-density function $\phi_s(x)$ as the derivative of the Sigmoid function $\Phi_s(x) = (1 + e^{-sx})^{-1}$ [S1, unofficial]:
    $$ \phi_s(x) = \frac{s e^{-sx}}{(1 + e^{-sx})^2} $$
    The cumulative distribution function is $\Phi_s(x)$ [S1, unofficial].
    
    Let $q_i$ and $q_{i+1}$ be consecutive section points along the ray with SDF values $f(q_i)$ and $f(q_{i+1})$. The alpha value $\alpha_i$ for the segment is computed as [S1, unofficial]:
    $$ \alpha_i = \max\left( \frac{\Phi_s(f(q_i)) - \Phi_s(f(q_{i+1}))}{\Phi_s(f(q_i))}, 0 \right) $$
    
    *Note: Some implementations (e.g., [S6, unofficial]) use a variance parameter $inv_s = \exp(variance \times 10.0)$ clipped to $[10^{-6}, 10^6]$ and apply cosine annealing to the normal alignment for better convergence, computing alpha via CDF differences of estimated previous/next SDFs. The core NeuS formulation [S1, unofficial] uses the fixed trainable $s$.*

4.  **Color Computation:**
    For each segment, compute the color $c_i$ using the color network $c$ at the midpoint $\mathbf{p}_i = \mathbf{o} + \frac{t_i + t_{i+1}}{2}\mathbf{v}$, using the normal $\mathbf{n}_i$ and feature $\mathbf{g}_i$ from the SDF network [S1, unofficial].

5.  **Volume Rendering:**
    Compute the transmittance $T_i$ and accumulated color $C$ for the ray [S1, unofficial]:
    $$ T_0 = 1 $$
    $$ T_{i+1} = T_i (1 - \alpha_i) $$
    $$ C = \sum_i T_i \alpha_i c_i $$

6.  **Loss Calculation:**
    The total loss $\mathcal{L}$ consists of a color loss and an Eikonal regularization term [S1, unofficial][S4]:
    $$ \mathcal{L} = \mathcal{L}_{\text{color}} + \beta \mathcal{L}_{\text{eikonal}} $$
    -   $\mathcal{L}_{\text{color}}$: Huber loss between rendered color $C$ and ground truth pixel color [S4].
    -   $\mathcal{L}_{\text{eikonal}}$: Enforces $\|\nabla f(\mathbf{x})\| \approx 1$ for sampled points [S4].

7.  **Mesh Extraction:**
    Extract the surface mesh by applying the Marching Cubes algorithm to the zero-level set of the trained SDF $f(\mathbf{x}) = 0$ [S2].

**Edge Cases and Pitfalls:**
-   **Geometric Bias:** Naively applying standard volume rendering density to SDF causes inherent geometric errors (bias). NeuS's S-density formulation is free of bias in the first-order approximation [S1, unofficial].
-   **Spectral Bias:** Random initialization can produce axis-aligned artifacts due to positional encoding spectral bias; geometric initialization avoids this [S1, unofficial].
-   **Textureless Regions:** Textureless areas are ambiguous and may fail to reconstruct correctly [S1, unofficial].
-   **Numerical Stability:** The parameter $s$ must be handled carefully; division by $\Phi_s(f(q_i))$ requires guarding against zero, though $\Phi_s$ is strictly positive [S1, unofficial].

## Subtopics

### [HAME-NeRF](9325-hame-nerf.md)
HAME-NeRF is a two-stage framework for extracting high-fidelity, textured surface meshes from RGB images by defining volume density as a Secant Hyperbolic Function applied to a Signed Distance Function (SDF). It builds on [NeuS](6060-neus.md) by introducing a spatially-varying sharpness parameter $\beta(\mathbf{x})$ learned via an MLP, which enhances flexibility for complex surfaces compared to methods using fixed $\beta$ values. Unlike [NeuS](6060-neus.md) which focuses on differentiable volume rendering for surface representation, HAME-NeRF explicitly optimizes a mesh through differentiable rendering and iterative refinement, achieving superior geometric accuracy and visual quality on synthetic benchmarks compared to [NeRF2Mesh](52-nerf2mesh.md).

### [D-NeuS](10217-d-neus.md)
D-NeuS is a volume rendering-based neural implicit surface reconstruction method that recovers fine-level geometric details by extending NeuS with two additional loss functions: a geometry bias loss and a multi-view feature consistency loss. It addresses the ambiguity in geometry and appearance representation inherent in volume rendering by ensuring consistency between the rendered surface points (derived from alpha compositing) and the underlying signed distance field (SDF) zero-crossings. Unlike its parent NeuS, which suffers from geometry bias due to the non-linear transformation of SDF to density, D-NeuS explicitly penalizes this bias and enforces feature consistency on surface points rather than all sampled points, distinguishing it from siblings like HAME-NeRF and NeuS2.

### NeuS2
NeuS2 is a fast neural surface reconstruction approach for multi-view RGB input that achieves two orders of magnitude improvement in training speed over NeuS without compromising reconstruction quality, applicable to both static and dynamic scenes [S1, unofficial]. It sets itself apart by parameterizing the neural network-encoded Signed Distance Field (SDF) using multi-resolution hash tables of learnable feature vectors, as introduced in Instant-NGP, and by calculating second-order derivatives using a novel lightweight formula tailored to ReLU-based MLPs to leverage CUDA parallelism and reduce memory footprint [S1, unofficial].

### [HF-NeuS](12039-hf-neus.md)
HF-NeuS is an improvement on NeuS that separates low-frequency details into a base SDF and high-frequency details into a displacement function to increase reconstruction quality. It builds on [NeuS](6060-neus.md) by addressing the smoothness limitations of standard implicit SDF representations, which often fail to capture sharp geometric features.

### NeuDA
NeuDA is a neural implicit surface reconstruction method that utilizes hierarchical deformable anchors to encode local geometry, building on the NeuS [6060-neus.md] framework. It distinguishes itself by replacing standard positional encoding with Hierarchical Positional Encoding (HPE) and employing a shallower SDF network (4 layers vs. 8 for NeuS) [S1, unofficial]. This design achieves high-fidelity surface reconstruction with lower computational cost and sharper surfaces compared to siblings like [HAME-NeRF](9325-hame-nerf.md), [D-NeuS](10217-d-neus.md), [NeuS2](10220-neus2.md), and [HF-NeuS](12039-hf-neus.md) [S1, unofficial].

### SparseNeus
SparseNeus is a method improving NeuS for sparse-view SDF reconstruction using a geometry encoding volume with learnable image features as a hybrid representation method [S3].

## Operating characteristics
-   **Time Complexity:** Training is slow. On a single Nvidia 2080Ti GPU, training takes ~14-16 hours for 300k iterations [S1, unofficial]. Rendering a 1600x1200 image takes ~320 seconds in default volume rendering settings, or ~60 seconds with sphere tracing acceleration [S1, unofficial].
-   **Memory Complexity:** Requires storing two MLPs (SDF and Color) and their gradients. The SDF network has 8 hidden layers of size 256, and the Color network has 4 hidden layers of size 256 [S1, unofficial].
-   **Performance:** On the NeRF Synthetic dataset, NeuS achieved PSNR = 28.4 +- 0.8 dB [S2]. On the DTU dataset, it achieved the most accurate surface reconstruction with Chamfer distance = 0.62 +- 0.08 mm [S2].
-   **Strengths:** High-quality surface reconstruction, robust optimization with complex structures, unbiased surface extraction, works without foreground masks [S1, unofficial].
-   **Limitations:** Slow training and rendering speed compared to density-based NeRF [S2]. Struggles with textureless regions [S1, unofficial].

## Background
NeuS was introduced in 2021 by Yen-Chen Lin et al. [S1, unofficial]. It builds on [Radiance-field optimization](44-radiance-field-optimization.md) by integrating Signed Distance Functions (SDFs) into the volume rendering framework. The key insight was that standard volume rendering applied to SDF-associated density causes inherent geometric errors (bias), and proposing a new formulation (S-density) free of bias in the first order of approximation [S1, unofficial]. It outperformed concurrent works like UNISURF in accuracy by naturally extracting the surface as the zero-level set of the SDF [S1, unofficial].
