# Canonical Radiance Field with Voxel Grid

Also called: Voxel Grid Based Canonical Field

## Overview
This method replaces the continuous, coordinate-based Multi-Layer Perceptron (MLP) of NeRF with a discrete, learnable voxel grid to represent a static scene in a canonical time frame [S1]. It solves the problem of querying infinite 3D points in canonical space for forward warping, which is impractical with heavy MLPs [S1]. It differs from [Explicit Radiance Fields](806-explicit-radiance-fields.md) by explicitly separating density and color features into distinct grids optimized for canonical static representation, and from [Direct Voxel Grid Optimization](4694-direct-voxel-grid-optimization.md) by serving as a foundational static representation for dynamic scene warping rather than direct view synthesis optimization [S1].

## How it works
**Inputs:**
*   3D coordinates $\mathbf{p}$ of points in the canonical space.
*   A pre-defined voxel grid structure.

**Outputs:**
*   Density $\sigma$ and color feature vector $\mathbf{c}_f$ for each queried point.

**Data Structures:**
The canonical radiance field $\mathbf{R}_{Can}$ is defined as a tuple of two voxel grids:
$$
\mathbf{R}_{Can} = \{ V\sigma_{Can}, Vcf_{Can} \}
$$
1.  $V\sigma_{Can}$: A 3D grid storing scalar density values.
2.  $Vcf_{Can}$: A 3D grid storing color feature vectors.
3.  $\mathbf{p}_{Can}$: The 3D coordinates of the voxel grid points in canonical space, embedded according to the NeRF positional encoding scheme [S1, S26].

**Method Steps:**
1.  **Grid Initialization:** Initialize the learnable voxel grids $V\sigma_{Can}$ and $Vcf_{Can}$ with random or zero values. The grid resolution determines the spatial granularity.
2.  **Coordinate Embedding:** For a query point $\mathbf{p}$, apply positional encoding (as defined in NeRF [S26]) to map the 3D coordinates to a higher-dimensional space.
3.  **Voxel Trilinear Interpolation:** Sample the values from $V\sigma_{Can}$ and $Vcf_{Can}$ at the query location $\mathbf{p}$ using trilinear interpolation. This yields the base density $\sigma_{base}$ and base color features $\mathbf{c}_{f,base}$.
4.  **Radiance Network Evaluation:** Pass the interpolated features through a lightweight MLP network $F_{\theta_1}$ [S1].
    *   Input to $F_{\theta_1}$: The interpolated color features $\mathbf{c}_{f,base}$ (and potentially the density or encoded coordinates, depending on specific implementation details not fully specified in the source, but typically features are decoded to color).
    *   Output: The final color $\mathbf{c}$ and potentially refined density $\sigma$.
    *   *Note:* The source defines the relationship as $\mathbf{R}_{Can} = \RadNet (\mathbf{p}_{Can}, \mathbf{Rf}_{Can})$, implying the network takes the grid features and coordinates to produce the radiance field output [S1].

**Pseudocode:**
```python
def query_canonical_field(p, V_sigma, V_cf, F_theta1, embed_func):
    """
    Query the canonical radiance field for a point p.
    
    Args:
        p: 3D coordinate (x, y, z) in canonical space.
        V_sigma: 3D voxel grid of density values.
        V_cf: 3D voxel grid of color feature vectors.
        F_theta1: Lightweight MLP network.
        embed_func: Positional encoding function (NeRF style).
        
    Returns:
        sigma: Density value.
        c: Color vector.
    """
    # 1. Embed coordinates
    p_embedded = embed_func(p)
    
    # 2. Trilinear interpolation from voxel grids
    # Assuming standard trilinear interpolation function
    sigma_base = trilinear_interpolate(V_sigma, p)
    cf_base = trilinear_interpolate(V_cf, p)
    
    # 3. Pass through lightweight MLP
    # The source indicates F_theta1 models the radiance.
    # Typically, this decodes features to color.
    # Density might be used directly or refined.
    # Based on S1: R_Can = RadNet(p_Can, Rf_Can)
    # We assume the MLP takes the features and possibly coordinates/embeddings.
    
    # Implementation detail: The exact input vector to F_theta1 is not fully
    # specified beyond "lightweight MLP". Standard practice combines features.
    input_to_mlp = concatenate([cf_base, p_embedded]) # [G] Common practice
    
    # 4. Get output from MLP
    # Assuming MLP outputs color c. Density might be sigma_base or output of MLP.
    # S1 says R_Can = {Vsigma, Vcf}, implying the grid stores the raw values
    # and the network refines them.
    output = F_theta1(input_to_mlp)
    
    # Assuming output is color c. Density is often taken from the grid or
    # a separate head. S1 groups them in R_Can.
    # Let's assume the MLP outputs color, and density is interpolated directly
    # or from a separate head. Without explicit formula for sigma output,
    # we use the interpolated sigma.
    sigma = sigma_base
    c = output
    
    return sigma, c
```

**Parameters:**
*   $F_{\theta_1}$: A lightweight MLP network used to model the radiance [S1].
*   Grid Resolution: Not given in the sources.

**Edge Cases:**
*   Points outside the voxel grid bounds: Standard boundary handling (clamp, zero, or error) is required. Not given in the sources.
*   Precision: Trilinear interpolation is differentiable, allowing gradient propagation to the voxel values [S1].

## Subtopics

### [Neural Residual Radiance Fields (ReRF)](12544-neural-residual-radiance-fields-rerf.md)
ReRF extends the canonical field concept to dynamic scenes by modeling residuals between adjacent timestamps, avoiding the fragility of global canonical spaces for large motions.

## Operating characteristics
*   **Memory:** Significantly lower memory usage compared to NeRF's heavy MLP for storing scene representation, as it uses a fixed-size voxel grid [S1].
*   **Speed:** Faster inference than NeRF due to direct voxel lookup and interpolation, avoiding expensive MLP evaluations for every point [S1].
*   **Limitations:** Limited to static scenes in the canonical representation; dynamic aspects require additional warping mechanisms (e.g., Canonical Trajectory Field using DCT) [S1].
*   **Scalability:** Resolution of the voxel grid limits the detail; higher resolution increases memory linearly.

## Background
Originated in the paper "Forward Flow for Novel View Synthesis of Dynamic Scenes" (ICCV 2023) [S1]. It addresses the limitation of NeRF's continuous representation for dynamic scene warping by introducing a discrete, learnable voxel grid for the canonical static scene [S1].
