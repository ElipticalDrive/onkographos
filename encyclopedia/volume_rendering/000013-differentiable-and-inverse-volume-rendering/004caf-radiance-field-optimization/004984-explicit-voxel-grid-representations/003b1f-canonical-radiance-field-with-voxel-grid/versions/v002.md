# Canonical Radiance Field with Voxel Grid

Also called: Voxel Grid Based Canonical Field

## Overview
This method replaces the continuous, coordinate-based Multi-Layer Perceptron (MLP) of NeRF with a discrete, learnable voxel grid to represent a static scene in a canonical time frame [S1]. It solves the problem of querying infinite 3D points in canonical space for forward warping, which is impractical with heavy MLPs [S1]. It differs from [Explicit Radiance Fields](806-explicit-radiance-fields.md) and [Direct Voxel Grid Optimization](4694-direct-voxel-grid-optimization.md) by structuring the canonical static scene as a discrete voxel grid paired with a lightweight MLP, specifically designed to support forward warping to other time steps [S1].

## How it works
**Inputs:**
*   3D coordinates $\mathbf{p}$ of points in the canonical space [S1].
*   Pre-defined voxel grid structure containing learnable parameters [S1].

**Outputs:**
*   Density $\sigma$ and color feature vector $\mathbf{c}_f$ for each queried point [S1].

**Data Structures:**
The canonical radiance field $\mathbf{R}_{\text{Can}}$ is defined as a tuple of two voxel grids:
$$
\mathbf{R}_{\text{Can}} = \{ V\sigma_{\text{Can}}, Vcf_{\text{Can}} \}
$$
1.  $V\sigma_{\text{Can}}$: A 3D grid storing scalar density values [S1].
2.  $Vcf_{\text{Can}}$: A 3D grid storing color feature vectors [S1].
3.  $\mathbf{p}_{\text{Can}}$: The 3D coordinates of the voxel grid points in canonical space, embedded according to the NeRF positional encoding scheme [S1, G].

**Method Steps:**
1.  **Grid Initialization:** Initialize the learnable voxel grids $V\sigma_{\text{Can}}$ and $Vcf_{\text{Can}}$ with learnable parameters (e.g., random or zero initialization) [G].
2.  **Coordinate Embedding:** For a query point $\mathbf{p}$, apply positional encoding to map the 3D coordinates to a higher-dimensional space [G].
3.  **Voxel Trilinear Interpolation:** Sample the values from $V\sigma_{\text{Can}}$ and $Vcf_{\text{Can}}$ at the query location $\mathbf{p}$ using trilinear interpolation to obtain base density $\sigma_{\text{base}}$ and base color features $\mathbf{c}_{f,\text{base}}$ [G].
4.  **Radiance Network Evaluation:** Pass the interpolated features through a lightweight MLP network $F_{\theta_1}$ [S1]. The network takes the embedded coordinates and interpolated color features as input to predict the final color $\mathbf{c}$, while density is typically taken directly from the interpolated grid values [S1, G].

## Subtopics

### [Neural Residual Radiance Fields (ReRF)](12544-neural-residual-radiance-fields-rerf.md)
ReRF extends the canonical field concept to dynamic scenes by modeling residuals between adjacent timestamps, avoiding the fragility of global canonical spaces for large motions. It differs from sibling methods by not relying on a global canonical space, making it robust to large motions or topology changes, and instead exploits feature similarities between adjacent timestamps. Choose this variant when handling dynamic scenes with significant motion or topology changes where global warping fails.

## Operating characteristics
*   **Memory:** Significantly lower memory usage compared to NeRF's heavy MLP for storing scene representation, as it uses a fixed-size voxel grid [S1].
*   **Speed:** Faster inference than NeRF due to direct voxel lookup and interpolation, avoiding expensive MLP evaluations for every point [S1].
*   **Limitations:** Limited to static scenes in the canonical representation; dynamic aspects require additional warping mechanisms (e.g., Canonical Trajectory Field using DCT) [S1].
*   **Scalability:** Resolution of the voxel grid limits the detail; higher resolution increases memory linearly [G].

## Background
Originated in the paper "Forward Flow for Novel View Synthesis of Dynamic Scenes" (ICCV 2023) [S1]. It addresses the limitation of NeRF's continuous representation for dynamic scene warping by introducing a discrete, learnable voxel grid for the canonical static scene [S1].
