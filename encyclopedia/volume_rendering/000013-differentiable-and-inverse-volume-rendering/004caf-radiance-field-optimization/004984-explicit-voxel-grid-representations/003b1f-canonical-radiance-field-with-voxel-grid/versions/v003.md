# Canonical Radiance Field with Voxel Grid

Also called: Voxel Grid Based Canonical Field

## Overview
This method replaces the continuous, coordinate-based Multi-Layer Perceptron (MLP) of NeRF with a discrete, learnable voxel grid to represent a static scene in a canonical time frame [S1]. It solves the problem of querying infinite 3D points in canonical space for forward warping, which is impractical with heavy MLPs [S1]. It differs from [Explicit Radiance Fields](806-explicit-radiance-fields.md) by explicitly separating density and color features into distinct grids optimized for canonical static representation, and from [Direct Voxel Grid Optimization](4694-direct-voxel-grid-optimization.md) by serving as a foundational static representation for dynamic scene warping rather than direct view synthesis optimization [S1].

## How it works
**Inputs:**
*   3D coordinates $\mathbf{p}_{Can}$ of points in the canonical space [S1].
*   A pre-defined voxel grid structure containing $V\sigma_{Can}$ and $Vcf_{Can}$ [S1].

**Outputs:**
*   Density $\sigma$ and color feature vector $\mathbf{c}_f$ for each queried point [S1].

**Data Structures:**
The canonical radiance field $\mathbf{R}_{Can}$ is defined as a tuple of two voxel grids:
$$
\mathbf{R}_{Can} = \{ V\sigma_{Can}, Vcf_{Can} \}
$$
1.  $V\sigma_{Can}$: A 3D grid storing scalar density values [S1].
2.  $Vcf_{Can}$: A 3D grid storing color feature vectors [S1].
3.  $\mathbf{p}_{Can}$: The 3D coordinates of the voxel grid points in canonical space, embedded according to the NeRF positional encoding scheme [S1].

**Method Steps:**
1.  **Coordinate Embedding:** For a query point $\mathbf{p}_{Can}$, apply positional encoding (as defined in NeRF [G]) to map the 3D coordinates to a higher-dimensional space [S1].
2.  **Voxel Trilinear Interpolation:** Sample the values from $V\sigma_{Can}$ and $Vcf_{Can}$ at the query location $\mathbf{p}_{Can}$ using trilinear interpolation [G]. This yields the base density $\sigma_{base}$ and base color features $\mathbf{c}_{f,base}$ [G].
3.  **Radiance Network Evaluation:** Pass the interpolated features through a lightweight MLP network $F_{\theta_1}$ [S1].
    *   Input to $F_{\theta_1}$: The interpolated color features $\mathbf{c}_{f,base}$ [S1].
    *   Output: The final color $\mathbf{c}$ [G].
    *   *Note:* The source defines the relationship as $\mathbf{R}_{Can} = \RadNet (\mathbf{p}_{Can}, \mathbf{Rf}_{Can})$, implying the network takes the grid features and coordinates to produce the radiance field output [S1].

**Pseudocode:**
```python
def trilinear_interpolate(grid, p):
    # Standard 3D trilinear interpolation for grid at normalized coordinate p
    ix, iy, iz = (p * (grid.shape[0]-1, grid.shape[1]-1, grid.shape[2]-1)).astype(int)
    ix, iy, iz = np.clip([ix, iy, iz], 0, [grid.shape[0]-2, grid.shape[1]-2, grid.shape[2]-2])
    fx, fy, fz = p * (grid.shape[0]-1, grid.shape[1]-1, grid.shape[2]-1) - [ix, iy, iz]
    w000 = (1-fx)*(1-fy)*(1-fz)
    w100 = fx*(1-fy)*(1-fz)
    w010 = (1-fx)*fy*(1-fz)
    w110 = fx*fy*(1-fz)
    w001 = (1-fx)*(1-fy)*fz
    w101 = fx*(1-fy)*fz
    w011 = (1-fx)*fy*fz
    w111 = fx*fy*fz
    return (w000*grid[ix,iy,iz] + w100*grid[ix+1,iy,iz] + w010*grid[ix,iy+1,iz] + w110*grid[ix+1,iy+1,iz] +
            w001*grid[ix,iy,iz+1] + w101*grid[ix+1,iy,iz+1] + w011*grid[ix,iy+1,iz+1] + w111*grid[ix+1,iy+1,iz+1])

def positional_encoding(p, min_deg=0, max_deg=10, base=2):
    # Standard NeRF positional encoding [G]
    scales = np.array([base**i for i in range(min_deg, max_deg+1)])
    scaled_p = np.outer(p, scales)
    return np.concatenate([scaled_p, np.pi*scaled_p], axis=-1)

def query_canonical_field(p, V_sigma, V_cf, F_theta1):
    # 1. Coordinate embedding [G]
    p_embedded = positional_encoding(p)

    # 2. Voxel sampling
    sigma_base = trilinear_interpolate(V_sigma, p)
    cf_base = trilinear_interpolate(V_cf, p)

    # 3. Radiance network evaluation [S1]
    # F_theta1 decodes color features to color c
    c = F_theta1(cf_base)

    return sigma_base, c
```

**Parameters:**
*   $F_{\theta_1}$: A lightweight MLP network used to model the radiance [S1].
*   Grid Resolution: Not given in the sources.

**Edge Cases:**
*   Points outside the voxel grid bounds: Standard boundary handling (clamp, zero, or error) is required. Not given in the sources.
*   Precision: Trilinear interpolation is differentiable, allowing gradient propagation to the voxel values [G].

## Subtopics

### [Neural Residual Radiance Fields (ReRF)](12544-neural-residual-radiance-fields-rerf.md)
ReRF extends the canonical field concept to dynamic scenes by modeling residuals between adjacent timestamps, avoiding the fragility of global canonical spaces for large motions.

## Operating characteristics
*   **Memory:** Significantly lower memory usage compared to NeRF's heavy MLP for storing scene representation, as it uses a fixed-size voxel grid [S1].
*   **Speed:** Faster inference than NeRF due to direct voxel lookup and interpolation, avoiding expensive MLP evaluations for every point [S1].
*   **Limitations:** Limited to static scenes in the canonical representation; dynamic aspects require additional warping mechanisms (e.g., Canonical Trajectory Field using DCT) [S1].
*   **Scalability:** Resolution of the voxel grid limits the detail; higher resolution increases memory linearly [G].

## Background
Originated in the paper "Forward Flow for Novel View Synthesis of Dynamic Scenes" (ICCV 2023) [S1]. It addresses the limitation of NeRF's continuous representation for dynamic scene warping by introducing a discrete, learnable voxel grid for the canonical static scene [S1].
