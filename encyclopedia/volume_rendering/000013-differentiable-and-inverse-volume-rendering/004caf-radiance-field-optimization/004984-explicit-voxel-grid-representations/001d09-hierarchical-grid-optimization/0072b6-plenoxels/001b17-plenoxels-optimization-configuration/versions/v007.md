# Plenoxels Optimization Configuration

Also called: Plenoxels optimizer settings, RMSProp vs SGD for Plenoxels

## Overview
Plenoxels Optimization Configuration defines the hyperparameter settings, specifically the choice of gradient-based optimizer and learning rate schedules, required to train the sparse voxel grid representation of Plenoxels [S1]. It solves the problem of efficiently converging voxel opacity ($\sigma$) and spherical harmonic (SH) coefficients from multi-view images without neural networks [S1]. It sets itself apart from its siblings by focusing on the specific numerical stability and convergence properties of optimizing SH coefficients, which are more sensitive to optimizer choice than standard neural network weights [S1].

## How it works
The optimization procedure updates the voxel parameters using gradient descent. The inputs are multi-view images and camera poses; the output is the optimized voxel grid containing opacity values and SH coefficients.

**Data Structures:**
*   **Voxel Grid:** A 3D grid of resolution $N^3$ (typically $256^3$).
*   **Voxel Data:** Each voxel stores:
    *   Opacity $\sigma$: A single scalar value.
    *   SH Coefficients: A vector of coefficients representing view-dependent color. The number of coefficients depends on the degree $L$ of the spherical harmonics. For degree $L$, there are $(L+1)^2$ coefficients per color channel (RGB).

**Parameters:**
*   **Optimizer:** RMSProp is the recommended default. SGD is an alternative but yields lower quality [S1].
*   **Learning Rate (LR):** Base learning rates for $\sigma$ and SH coefficients.
*   **Schedule:**
    *   **Delayed Schedule:** The learning rate for $\sigma$ is delayed (starts later or increases slower) relative to SH coefficients. This yields the best results [S1].
    *   **Constant Schedule:** Constant learning rates for both $\sigma$ and SH.
    *   **Mixed:** Constant for SH, Delayed for $\sigma$.

**Steps:**
1.  **Initialization:** Initialize voxel $\sigma$ and SH coefficients. Common initialization involves setting $\sigma$ to small positive values and SH coefficients to zero or based on average view color [G].
2.  **Sampling:** For each training step, sample rays through the voxel grid.
3.  **Rendering:** Compute the rendered color and opacity for each ray using volume rendering integration with trilinear interpolation for SH coefficients and $\sigma$ [S1].
4.  **Loss Calculation:** Compute the loss between rendered and ground truth images (e.g., L1 or MSE) [G].
5.  **Backpropagation:** Compute gradients for $\sigma$ and SH coefficients.
6.  **Update:** Apply the optimizer update step.
    *   If using RMSProp, maintain a running average of squared gradients for each parameter.
    *   If using SGD, update parameters directly by subtracting the learning rate times the gradient.

**Formulas:**
*   **Volume Rendering:**
    $$ C(r) = \sum_{i=1}^n T_i (1 - \exp(-\sigma_i \delta_i)) c_i $$
    where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$, $\delta_i$ is the segment length, $\sigma_i$ is the opacity, and $c_i$ is the color computed from SH coefficients at direction $\omega$.
*   **RMSProp Update:**
    $$ v_t = \rho v_{t-1} + (1-\rho) g_t^2 $$
    $$ \theta_t = \theta_{t-1} - \frac{\eta}{\sqrt{v_t + \epsilon}} g_t $$
    where $\rho$ is the decay rate (typically 0.99), $\eta$ is the learning rate, $g_t$ is the gradient, and $\epsilon$ is a small constant for numerical stability [G].

**Edge Cases and Pitfalls:**
*   **Optimizer Choice:** Using SGD for both $\sigma$ and SH results in significantly lower PSNR (29.35 vs 30.57) and SSIM (0.932 vs 0.950) [S1].
*   **Learning Rate Schedule:** A constant schedule for both parameters yields lower quality (PSNR 30.13) compared to a delayed schedule for $\sigma$ (PSNR 30.57) [S1].
*   **Precision:** SH coefficients can be sensitive to learning rate variations; RMSProp helps stabilize this [S1].

## Subtopics

### Space Carving and Opaque Voxels Optimization with Spherical Harmonics
A technique composed of two steps: space carving and opaque voxels optimization, used to generate neural radiance fields based on plenoxels [S2, unofficial]. It uses spherical harmonics of degree 9 to render the shading of each voxel [S2, unofficial]. Running the implementation `main_carve_sph.py` takes approximately 4 minutes on a single GPU [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the number of rays sampled and the resolution of the voxel grid. The optimization is generally faster than neural radiance fields due to the lack of MLP evaluation [S1].
*   **Memory Complexity:** Proportional to the number of voxels and the number of SH coefficients per voxel. For a $256^3$ grid with degree 3 SH, this is manageable on modern GPUs [S1].
*   **Measured Performance:** On 8 synthetic NeRF scenes at $256^3$ resolution, RMSProp for both SH and $\sigma$ achieves PSNR 30.57, SSIM 0.950, LPIPS 0.065 [S1]. SGD for both drops to PSNR 29.35, SSIM 0.932, LPIPS 0.087 [S1].
*   **Strengths:** RMSProp provides better convergence for SH coefficients. The method is robust to variations in optimizer and schedule, though RMSProp with delayed schedule is optimal [S1].
*   **Limitations:** SGD is less effective, particularly for SH coefficients [S1].
*   **When to Use:** Use RMSProp with a delayed learning rate schedule for $\sigma$ for best results. Use SGD only if computational resources for RMSProp are constrained, accepting lower quality [S1].

## Background
Plenoxels Optimization Configuration originates from the Plenoxels paper, which introduced a novel approach for fast radiance field reconstruction from sparse views using voxel grids without neural networks [S1]. The specific optimization settings were derived from empirical evaluation on synthetic NeRF scenes [S1]. The method builds on the assumption that voxel opacity and SH coefficients can be optimized directly using gradient-based methods [S1].
