# ERF Optimization with SVO Priors

Also called: ERF, Explicit Radiance Field Optimization, Hierarchical Optimization for Explicit Radiance Field Reconstruction, SVO Reconstruction

## Overview
ERF is an algorithm that reconstructs a scene from scratch using an Explicit Sparse Voxel Octree (SVO) containing opacity and spherical harmonic (SH) radiance fields, optimized via inverse differentiable rendering and adaptive tree subdivision [S1, unofficial]. It differs from implicit methods like NeRF by using a hierarchical grid structure that allows for explicit free-space exploitation and multi-resolution detail, and from other explicit methods by employing specific SVO priors and a tanh-based opacity constraint to stabilize optimization near boundaries [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Multi-view images, their sensor poses and calibrations, and a coarse, conservative Axis-Aligned Bounding Box (AABB) for the scene [S1, unofficial].
*   **Outputs:** A scene model containing an SVO (opacity and SLF fields) within the AABB and an environment map $L_\infty$ for distant regions [S1, unofficial].

**Data Structures:**
*   **SVO Node:** Contains 1 floating-point opacity parameter and multiple RGB SH coefficients ($c_{l,m}$) [S1, unofficial]. Inner nodes store these parameters to support Level-of-Detail (LoD) approximations [S1, unofficial].
*   **Opacity Field ($\sigma$):** A continuous scalar volumetric field $\sigma: \mathbb{R}^3 \mapsto [0, 1]$ stored per tree node, representing surface coverage/absorption probability [S1, unofficial].
*   **Surface Light Field (SLF):** A volumetric vector field storing outgoing radiance, represented by SH coefficients [S1, unofficial].
*   **Loss Cache ($C$):** Tracks loss values for all input pixels to drive importance sampling [S1, unofficial].

**Formulas:**
*   **Opacity Constraint:** Maps unconstrained raw opacity $\widehat{\sigma}(x)$ to $[0, 1]$ using a tanh variant to prevent optimizer oscillation near borders [S1, unofficial]:
    $$f(x) = 0.5 \cdot (\tanh(4x - 2) + 1)$$
*   **Surface Normal Inference:** Derived from the gradient of the raw opacity field [S1, unofficial]:
    $$\mathbf{n}(\mathbf{x}) = -\frac{\nabla \widehat{\sigma}(\mathbf{x})}{\|\nabla \widehat{\sigma}(\mathbf{x})\|_2}$$
*   **SLF Evaluation:** Uses Spherical Harmonics where $c_{l,m}(\mathbf{x})$ are interpolated SH coefficients and $Y_{l,m}$ are basis functions [S1, unofficial]:
    $$\widehat{L}_0(\mathbf{x}, \mathbf{v}) = \sum_{l=0}^{l=b} \sum_{m=-l}^{m=l} c_{l,m}(\mathbf{x}) \cdot Y_{l,m}(\mathbf{v})$$
*   **Total Loss:** Combines pixel photo consistency loss $l_p$ and SVO priors ($l_{3D}, l_{LoD}, l_0$) [S1, unofficial]:
    $$l_{\Theta}(\{\mathbf{p}_i\}, \{n_j\}) = \frac{1}{|\{\mathbf{p}_i\}|} \sum_i [l_p(\mathbf{p}_i)] + \frac{1}{|\{n_j\}|} \cdot [l_{3D}(\{n_j\}) + l_{\text{LoD}}(\{n_j\}) + l_0(\{n_j\})]$$

**Parameters:**
*   **Batch Size:** 4096 pixels and 4096 SVO nodes [S1, unofficial].
*   **SVO Priors:** $l_{3D}$ (local smoothness in 3D space), $l_{LoD}$ (local smoothness along LoD dimension), and $l_0$ (zero opacity/radiance for sparse models) [S1, unofficial].

**Pseudocode:**
```python
# Initialization
SVO = create_dense_grid(AABB) # Random opacity and SLF fields
L_inf = random_env_map_radiance()
C = high_loss_for_all_input_pixels()

# Optimization Loop
for n in range(N):
    # 1. Select pixels based on loss cache
    pixels = importance_sample(C)
    
    # 2. Cast rays
    rays = cast_rays(pixels) # From sensor center x_c,i in direction d_i
    
    # 3. Stratified sampling within SVO
    depths_stratified = stratified_sampling(SVO, rays)
    
    # 4. Randomly select subset of depths uniformly
    depths_subset_1 = select_randomly(depths_stratified)
    
    # 5. Query opacity at selected depths
    opacities = get_opacity(SVO, depths_subset_1)
    
    # 6. Randomly select subset of depths and corresponding opacities
    depths_subset_2, opacities_subset = select_randomly(depths_subset_1, opacities)
    
    # 7. Query SLF at selected depths
    # Note: SLF is evaluated in direction -d_i (outgoing)
    slf_values = get_slf(SVO, rays, depths_subset_2)
    
    # 8. Blend opacity and SLF samples along ray
    pixel_radiance, pixel_opacity = blend(opacities_subset, slf_values)
    
    # 9. Blend with environment map
    pixel_radiance = blend(pixel_radiance, pixel_opacity, L_inf(-rays.direction))
    
    # 10. Map to pixel intensities using sensor response curve
    pixel_intensities = sensor_response(pixel_radiance)
    
    # 11. Compute photo loss
    losses = photo_loss(pixel_intensities, ground_truth_intensities)
    
    # 12. Update loss cache
    C = update_loss_cache(C, losses)
    
    # 13. Update model parameters using gradients
    # Includes SVO priors: l_3D, l_LoD, l_0
    SVO, L_inf = make_step(SVO, L_inf, gradients(losses))

# Post-optimization
merge_leaves(SVO) # Compact free space

# Adaptive Subdivision
if subdivide_leaves(SVO, pixel_footprints):
    reset_optimizer()
    restart_optimization_loop()
```

**Edge Cases and Pitfalls:**
*   **Optimizer Oscillation:** Using ReLU or Softplus for opacity can cause failure or oscillation near zero gradients or borders [S1, unofficial]. The tanh variant is chosen because it is mostly linear but smoothly approaches borders [S1, unofficial].
*   **Physically Implausible Geometry:** Optimizing only photo consistency can lead to solutions with low error but implausible geometry (e.g., untextured surfaces) [S1, unofficial]. SVO priors prevent this and stop parameters from deranging if gradients are missing [S1, unofficial].

## Operating characteristics
*   **Time and Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Not given in the sources.
*   **Strengths:** Explicit representation allows for free-space exploitation and multi-resolution detail; tanh constraint stabilizes optimization; SVO priors prevent convergence to implausible local minima [S1, unofficial].
*   **Limitations:** Requires careful initialization and adaptive subdivision logic; SVO priors add computational overhead [S1, unofficial].
*   **When to use:** When explicit control over geometry and free space is needed, or when implicit methods struggle with untextured surfaces or free space [S1, unofficial].
*   **When not to use:** When implicit methods are sufficient and computational simplicity is preferred [S1, unofficial].

*   **Usage:** Used for 3D scene reconstruction from multi-view images [S1, unofficial].
