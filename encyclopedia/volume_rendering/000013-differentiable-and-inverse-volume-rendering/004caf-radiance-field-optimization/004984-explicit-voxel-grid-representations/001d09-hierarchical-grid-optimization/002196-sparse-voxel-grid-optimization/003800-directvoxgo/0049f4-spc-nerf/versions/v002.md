# SPC-NeRF

Also called: Spatial Predictive Compression for Voxel-Based Radiance Field

## Overview
SPC-NeRF is a Rate-Distortion (RD) optimized predictive coding framework for compressing Explicit Voxel Grid (EVG) represented NeRFs [S1]. It removes spatial redundancy by predicting voxel values from adjacent voxels and jointly optimizes compression ratio and distortion during training [S1]. It builds on the DirectVoxGO pipeline and achieves 32% bit savings compared to VQRF on multiple representative test datasets, with comparable training time [S1].

## How it works
**Inputs:** An uncompressed voxel grid obtained from the DirectVoxGO pipeline [S1].
**Outputs:** A compressed bitstream containing reference indexes, coarse residuals, fine residuals, prune mask, critical mask, non-prune density grid, weights of the shallow MLP, and metadata [S1].

**Data Structures:**
The method operates on an EVG where each voxel stores density and color features [S1]. The compressed bitstream syntax elements are: 1) reference indexes pointing to the chosen adjacent voxel for prediction [S1]; 2) coarse residuals representing quantized differences between actual and predicted values for non-critical voxels [S1]; 3) fine residuals representing quantized differences for critical voxels, reconstructed after post-finetuning [S1]; 4) prune mask indicating pruned versus unpruned voxels [S1]; 5) critical mask indicating critical versus non-critical voxels among unpruned ones [S1]; 6) non-prune density grid containing density values for unpruned voxels [S1]; 7) weights of the shallow MLP containing model parameters [S1]; 8) metadata containing scene-specific information [S1].

**Algorithm Steps:**

1. **Initialization:** Apply the DirectVoxGO pipeline to obtain the initial uncompressed voxel grid [S1].
2. **Pruning and Critical Selection:** Prune approximately 90% of unimportant voxels and mark a small subset of the remaining unpruned voxels as critical [S1].
3. **Reference Graph Construction:** For each unpruned voxel, select one adjacent voxel from seven possible previously encountered neighboring voxels as the prediction value [S1]. Record the index of this reference to construct a reference relation graph [S1].
4. **RD Loss Formulation and Finetuning:** Apply a unique bit estimation method to estimate the bitrate of the residuals [S1]. Formulate a Rate-Distortion loss function combining rendering distortion and estimated bitrate [S1]. Finetune the voxel grid to minimize this loss [S1].
5. **Coarse Residual Generation:** Perform actual quantization and prediction using the reference graph to generate coarse residuals for non-critical voxels [S1].
6. **Post-Finetuning:** Freeze all non-critical voxels [S1]. Perform a second finetuning step to generate fine residuals specifically for reconstructing the critical voxels [S1].
7. **Entropy Coding:** Encode the reference indexes, coarse residuals, and fine residuals using arithmetic coding [S1]. Encode the prune mask, critical mask, non-prune density grid, shallow MLP weights, and metadata using a simple LZ77 codec, as these occupy little storage relative to the residuals [S1].

**Pseudocode:**

```python
def spc_nerf_compress(uncompressed_voxel_grid):
    # Step 1: Pruning and Critical Selection
    # Prune ~90% of unimportant voxels and mark a small part as critical.
    # Not given in the sources how pruning and critical selection are computed.
    prune_mask = compute_pruning_mask(uncompressed_voxel_grid, ratio=0.9)
    critical_mask = compute_critical_mask(unpruned_voxels, prune_mask)

    # Step 2: Reference Graph Construction
    # Select one adjacent voxel from seven possible neighbors as prediction value.
    reference_graph = {}
    for voxel_id in unpruned_voxels:
        neighbors = get_7_adjacent_neighbors(voxel_id)
        # Not given in the sources how the best reference is selected.
        ref_id = select_best_reference(neighbors)
        reference_graph[voxel_id] = ref_id

    # Step 3: RD Loss Formulation and Finetuning
    # Apply unique bit estimation method to form RD loss and finetune voxel grid.
    # Not given in the sources the exact bit estimation method or finetuning procedure.
    voxel_grid = finetune_with_rd_loss(uncompressed_voxel_grid, reference_graph)

    # Step 4: Coarse Residual Generation
    coarse_residuals = {}
    for voxel_id in unpruned_voxels:
        if not critical_mask[voxel_id]:
            ref_id = reference_graph[voxel_id]
            predicted = voxel_grid[ref_id]
            actual = voxel_grid[voxel_id]
            coarse_residuals[voxel_id] = quantize(actual - predicted)

    # Step 5: Post-Finetuning for Critical Voxels
    # Freeze non-critical voxels and finetune to generate fine residuals for critical voxels.
    frozen_grid = voxel_grid.copy()
    for voxel_id in unpruned_voxels:
        if not critical_mask[voxel_id]:
            frozen_grid[voxel_id] = voxel_grid[voxel_id]
    fine_residuals = {}
    for voxel_id in unpruned_voxels:
        if critical_mask[voxel_id]:
            ref_id = reference_graph[voxel_id]
            ref_value = frozen_grid[ref_id] if not critical_mask[ref_id] else voxel_grid[ref_id]
            actual = voxel_grid[voxel_id]
            fine_residuals[voxel_id] = quantize(actual - ref_value)

    # Step 6: Encoding
    bitstream = []
    bitstream.append(encode_arithmetic(reference_graph))
    bitstream.append(encode_arithmetic(coarse_residuals))
    bitstream.append(encode_arithmetic(fine_residuals))
    bitstream.append(encode_lz77(prune_mask))
    bitstream.append(encode_lz77(critical_mask))
    bitstream.append(encode_lz77(get_non_prune_density_grid(uncompressed_voxel_grid, prune_mask)))
    bitstream.append(encode_lz77(get_shallow_mlp_weights(voxel_grid)))
    bitstream.append(encode_lz77(metadata))
    return bitstream

# Standard operations / [G] helpers
def compute_pruning_mask(grid, ratio): return [voxel for voxel in grid if voxel.importance > threshold] # [G]
def compute_critical_mask(unpruned, mask): return [voxel for voxel in unpruned if voxel.criticality > threshold] # [G]
def get_7_adjacent_neighbors(voxel_id): return [grid[voxel_id + offset] for offset in [-1, 0, 1] if valid] # [G]
def select_best_reference(neighbors): return min(neighbors, key=lambda v: abs(v.value - target)) # [G]
def finetune_with_rd_loss(grid, graph): return optimize(grid, loss=distortion + lambda * bitrate) # [G]
def quantize(value): return round(value / scale) # [G]
def encode_arithmetic(data): return arithmetic_encode(data) # [G]
def encode_lz77(data): return lz77_encode(data) # [G]
def get_non_prune_density_grid(grid, mask): return [grid[i].density for i in range(len(grid)) if not mask[i]] # [G]
def get_shallow_mlp_weights(grid): return grid.mlp.parameters() # [G]
```

**Parameters:**
*   **Pruning Ratio:** Approximately 90% of unimportant voxels are pruned [S1].

**Edge Cases and Pitfalls:**
*   **Reference Selection:** The choice of reference from seven neighbors impacts the residual magnitude and thus the bitrate [S1].
*   **Critical Voxels:** The exact definition of critical voxels is not given in the sources [G].
*   **Quantization:** The sources do not specify the bit depth for quantization, which is a potential implementation gap [G].

## Operating characteristics
*   **Compression Performance:** Achieves 32% bit saving compared to VQRF on multiple representative test datasets [S1].
*   **Training Time:** Comparable to the baseline DirectVoxGO pipeline [S1].
*   **Strengths:** Effective removal of spatial redundancy through predictive coding and joint optimization of rate and distortion [S1].
*   **Limitations:** Relies on the initial quality of the uncompressed grid from DirectVoxGO and the two-stage finetuning adds complexity [S1].

## Background
SPC-NeRF was proposed to address the high computational and storage complexity of NeRF models represented by Explicit Voxel Grids [S1]. It builds on the concept of spatial predictive coding, which exploits statistical dependence between spatially adjacent samples, analogous to image compression techniques [S1]. The method was developed to improve coding efficiency by jointly optimizing compression ratio and distortion [S1].
