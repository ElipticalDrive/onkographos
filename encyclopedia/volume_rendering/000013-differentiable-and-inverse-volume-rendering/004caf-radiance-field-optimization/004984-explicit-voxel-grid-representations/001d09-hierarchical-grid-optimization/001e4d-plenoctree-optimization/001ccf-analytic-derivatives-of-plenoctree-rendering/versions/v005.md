# Analytic Derivatives of PlenOctree Rendering
Also called: Gradient Computation for PlenOctree Optimization, NeRF Piecewise Constant Volume Rendering Derivatives

## Overview
This method computes the analytic gradients of the NeRF piecewise constant volume rendering equation with respect to density ($\boldsymbol{\sigma}$) and color ($\mathbf{c}$) parameters, enabling direct optimization of PlenOctrees [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A fixed ray with origin and direction, divided into $N$ consecutive segments with endpoints $\{t_i\}_{i=0}^N$ [S1, unofficial]. Segment lengths are $\delta_i = t_{i+1} - t_i$ [S1, unofficial]. Constant densities $\boldsymbol{\sigma} = (\sigma_0, \dots, \sigma_{N-1})$ and colors $\mathbf{c} = (c_0, \dots, c_N)$, where $c_N$ is the background color [S1, unofficial].
- **Output:** Gradients $\frac{\partial \hat{C}}{\partial \sigma_i}$ and $\frac{\partial \hat{c}_i}$ for each segment $i$ [S1, unofficial].

**Data Structures:**
- **Accumulated Transmittance ($T_i$):** Precomputed for $i=0 \dots N$ [S1, unofficial].
- **Segment Weights ($w_i$):** Precomputed for $i=0 \dots N$ [S1, unofficial].

**Formulas:**
1.  **Accumulated Transmittance:**
    $$T_i(\boldsymbol{\sigma}) := \prod_{j=0}^{i-1} \exp(-\delta_j \sigma_j)$$
    where $T_0 = 1$ [S1, unofficial]. $T_i$ represents the transmittance from $t_0$ to $t_i$ [S1, unofficial].

2.  **Rendered Color:**
    $$\hat{C}(\boldsymbol{\sigma}, \mathbf{c}) = \sum_{i=0}^N w_i(\boldsymbol{\sigma}) c_i$$
    where segment weights are:
    $$w_i(\boldsymbol{\sigma}) = T_i(\boldsymbol{\sigma}) (1 - \exp(-\sigma_i \delta_i)) = T_i(\boldsymbol{\sigma}) - T_{i+1}(\boldsymbol{\sigma}) \quad \text{for } i < N$$
    $$w_N(\boldsymbol{\sigma}) = T_N(\boldsymbol{\sigma})$$
    [S1, unofficial].

3.  **Color Derivative:**
    $$\frac{\partial \hat{C}}{\partial c_i}(\boldsymbol{\sigma}, \mathbf{c}) = w_i(\boldsymbol{\sigma})$$
    [S1, unofficial].

4.  **Density Derivative:**
    The derivative with respect to $\sigma_i$ is:
    $$\frac{\partial \hat{C}}{\partial \sigma_i}(\boldsymbol{\sigma}, \mathbf{c}) = \delta_i \left[ c_i T_{i+1}(\boldsymbol{\sigma}) - \sum_{k=i+1}^N c_k w_k(\boldsymbol{\sigma}) \right]$$
    [S1, unofficial].
    *Derivation Note:* This simplifies from the general form $\frac{\partial \hat{C}}{\partial \sigma_i} = c_N \frac{\partial T_N}{\partial \sigma_i} + \sum_{k=0}^{N-1} c_k \left( \frac{\partial T_k}{\partial \sigma_i} - \frac{\partial T_{k+1}}{\partial \sigma_i} \right)$ using $\frac{\partial T_k}{\partial \sigma_i} = -\delta_i T_k(\boldsymbol{\sigma}) \mathbf{1}_{k>i}$ [S1, unofficial].

**Parameters:**
- Background color $c_N$ is typically a scalar intensity of 1.0 [S1, unofficial].

**Edge Cases and Pitfalls:**
- Numerical stability must be handled for extreme $\sigma_i \delta_i$ values (e.g., using `expm1` for small arguments) [G].
- Degenerate segments with $\delta_i = 0$ should be skipped or merged to avoid division by zero or zero-length transmittance products [G].

**Spherical Harmonics (SH) Handling:**
When colors $\mathbf{c}$ are represented by Spherical Harmonics coefficients, the chain rule is applied [S1, unofficial]. Since SH basis function values are constant across the ray, the derivative with respect to SH coefficients is computed by multiplying the gradient with respect to color $\mathbf{c}$ by the SH basis values [S1, unofficial].

**Pseudocode:**
```python
import math

def compute_gradients(N, deltas, sigmas, colors, background_color):
    """
    Computes gradients for NeRF volume rendering.
    N: Number of segments.
    deltas: Array of length N, segment lengths delta_i.
    sigmas: Array of length N, densities sigma_i.
    colors: Array of length N+1, colors c_0 to c_N (c_N is background).
    background_color: Scalar intensity (typically 1.0) for background light.
    Returns: grad_sigmas (N,), grad_colors (N+1,)
    """
    # 1. Compute Transmittance T_i
    T = [0.0] * (N + 1)
    T[0] = 1.0
    for i in range(1, N + 1):
        T[i] = T[i-1] * math.exp(-deltas[i-1] * sigmas[i-1])

    # 2. Compute Weights w_i
    w = [0.0] * (N + 1)
    for i in range(N):
        w[i] = T[i] - T[i+1]
    w[N] = T[N]

    # 3. Compute Color Gradients
    grad_colors = list(w)

    # 4. Compute Density Gradients in O(N) using a suffix sum
    grad_sigmas = [0.0] * N
    suffix_sum = 0.0
    for i in range(N - 1, -1, -1):
        suffix_sum += colors[i+1] * w[i+1]
        grad_sigmas[i] = deltas[i] * (colors[i] * T[i+1] - suffix_sum)

    return grad_sigmas, grad_colors
```

## Subtopics

### Differentiating Pixel Intensities
This variant extends the derivative computation to the pixel level, modeling pixel intensity $I$ as the inner product between radiance $L$ and a reconstruction kernel $K$ over the pixel footprint $P$ [S2, unofficial]. The differentiated intensity $\hat{I}$ includes a boundary integral term accounting for discontinuities in $L$ along the boundary of the pixel domain $\partial[0,1)^2$, which is necessary when camera parameters depend on scene parameters [S2, unofficial].

## Operating characteristics
- **Time and Memory Complexity:** Not given in the sources.
- **Strengths:** Provides exact gradients for direct PlenOctree optimization [S1, unofficial]. Handles SH colors naturally via the chain rule [S1, unofficial].
- **Limitations:** Assumes piecewise constant density and color within segments [S1, unofficial]. Requires careful handling of numerical stability for very small or large $\sigma_i \delta_i$ values (e.g., using `expm1` for small arguments) [G].
- **When to use:** When optimizing PlenOctree parameters directly using gradient-based methods like SGD [S1, unofficial].
- **When not to use:** Not specified in the sources.

## Background
The method was introduced in the context of PlenOctrees for real-time rendering of Neural Radiance Fields (NeRFs) [S1, unofficial]. It builds on the NeRF volume rendering formulation [S1, unofficial] and provides the necessary gradients for optimizing the octree structure's density and color attributes directly, rather than relying on numerical approximations. The approach is detailed in Appendix B.3 of the PlenOctrees paper [S1, unofficial].
