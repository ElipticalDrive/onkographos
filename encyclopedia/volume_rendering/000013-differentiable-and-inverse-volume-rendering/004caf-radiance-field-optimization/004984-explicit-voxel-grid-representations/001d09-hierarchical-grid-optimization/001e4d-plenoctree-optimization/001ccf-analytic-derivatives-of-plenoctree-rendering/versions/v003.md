# Analytic Derivatives of PlenOctree Rendering
Also called: Gradient Computation for PlenOctree Optimization, NeRF Piecewise Constant Volume Rendering Derivatives

## Overview
This method computes the analytic gradients of the NeRF piecewise constant volume rendering equation with respect to density ($\boldsymbol{\sigma}$) and color ($\mathbf{c}$) parameters, enabling direct optimization of PlenOctrees [S1, unofficial]. It solves the problem of backpropagating the rendering loss through the volumetric integration process without numerical differentiation. It is distinguished from [PlenOctree Conversion](1359-plenoctree-conversion.md) (which focuses on compression and format) and [PlenOctree Fine-tuning](1465-plenoctree-fine-tuning.md) (which describes the high-level training loop) by providing the specific mathematical derivatives required for the optimizer [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** A fixed ray with origin and direction; segment endpoints $\{t_i\}_{i=0}^N$; segment densities $\boldsymbol{\sigma} = (\sigma_0, \dots, \sigma_{N-1})$; segment colors $\mathbf{c} = (c_0, \dots, c_{N-1})$; background color $c_N$; segment lengths $\delta_i = t_{i+1} - t_i$.
- **Outputs:** Gradients $\frac{\partial \hat{C}}{\partial \sigma_i}$ and $\frac{\partial \hat{C}}{\partial c_i}$ for the rendered color $\hat{C}$.

**Data Structures:**
- **Segment Arrays:** Densities $\sigma$ and colors $c$ are stored as arrays of size $N$ (for segments) and $1$ (for background).
- **Transmittance Array:** $T$ is an array of size $N+1$, where $T_i$ represents accumulated transmittance from $t_0$ to $t_i$.

**Definitions:**
1.  **Accumulated Transmittance:**
    $$T_i(\boldsymbol{\sigma}) := \prod_{j=0}^{i-1} \exp(-\delta_j \sigma_j)$$
    where $T_0 = 1$. $T_i$ models absorption from $t_0$ to $t_i$ [S1, unofficial].
2.  **Segment Weights:**
    $$w_i(\boldsymbol{\sigma}) = T_i(\boldsymbol{\sigma}) (1 - \exp(-\sigma_i \delta_i)) = T_i(\boldsymbol{\sigma}) - T_{i+1}(\boldsymbol{\sigma}) \quad \text{for } i < N$$
    $$w_N(\boldsymbol{\sigma}) = T_N(\boldsymbol{\sigma})$$
3.  **Rendered Color:**
    $$\hat{C}(\boldsymbol{\sigma}, \mathbf{c}) = \sum_{i=0}^N w_i(\boldsymbol{\sigma}) c_i$$

**Algorithm Steps:**
1.  **Compute Transmittance:** Calculate $T_i$ for all $i \in [0, N]$.
    $$T_0 = 1$$
    $$T_{i+1} = T_i \cdot \exp(-\sigma_i \delta_i) \quad \text{for } i = 0 \dots N-1$$
2.  **Compute Weights:** Calculate $w_i$ for all $i \in [0, N]$ using the transmittance values.
    $$w_i = T_i - T_{i+1} \quad \text{for } i = 0 \dots N-1$$
    $$w_N = T_N$$
3.  **Compute Color Gradients:**
    $$\frac{\partial \hat{C}}{\partial c_i} = w_i \quad \text{for } i = 0 \dots N$$
4.  **Compute Density Gradients:**
    The derivative with respect to $\sigma_i$ is given by:
    $$\frac{\partial \hat{C}}{\partial \sigma_i} = \delta_i \left[ c_i T_{i+1}(\boldsymbol{\sigma}) - \sum_{k=i+1}^N c_k w_k(\boldsymbol{\sigma}) \right]$$
    
    *Derivation Note:* The general form is $\frac{\partial \hat{C}}{\partial \sigma_i} = c_N \frac{\partial T_N}{\partial \sigma_i} + \sum_{k=0}^{N-1} c_k \left( \frac{\partial T_k}{\partial \sigma_i} - \frac{\partial T_{k+1}}{\partial \sigma_i} \right)$. Since $\frac{\partial T_k}{\partial \sigma_i} = -\delta_i T_k \mathbf{1}_{k>i}$, terms where $k \le i$ vanish. The simplified formula above is derived by grouping terms [S1, unofficial].

**Pseudocode:**
```python
def compute_gradients(sigma, delta, c, c_bg):
    """
    sigma: array of N densities (sigma_0 ... sigma_{N-1})
    delta: array of N segment lengths (delta_0 ... delta_{N-1})
    c: array of N segment colors (c_0 ... c_{N-1})
    c_bg: background color (c_N)
    Returns: grad_sigma (N,), grad_c (N+1,)
    """
    N = len(sigma)
    
    # 1. Compute Transmittance T[0...N]
    T = [0.0] * (N + 1)
    T[0] = 1.0
    for i in range(N):
        T[i+1] = T[i] * math.exp(-sigma[i] * delta[i])
        
    # 2. Compute Weights w[0...N]
    w = [0.0] * (N + 1)
    for i in range(N):
        w[i] = T[i] - T[i+1]
    w[N] = T[N]
    
    # 3. Compute Color Gradients
    grad_c = list(w) # w[0]...w[N-1] for segments, w[N] for background
    
    # 4. Compute Density Gradients
    grad_sigma = [0.0] * N
    for i in range(N):
        # Term 1: c_i * T_{i+1}
        term1 = c[i] * T[i+1]
        
        # Term 2: sum_{k=i+1}^N c_k * w_k
        # Note: c_N is c_bg, w_N is T[N]
        sum_term = 0.0
        for k in range(i+1, N):
            sum_term += c[k] * w[k]
        sum_term += c_bg * w[N]
        
        grad_sigma[i] = delta[i] * (term1 - sum_term)
        
    return grad_sigma, grad_c
```

**Spherical Harmonics (SH):**
If colors are represented by SH coefficients, the chain rule is applied. Since SH basis function values are constant across the ray, the derivative with respect to the SH coefficients is computed by multiplying the color gradient by the SH basis values [S1, unofficial].

**Edge Cases:**
- **Zero Density:** If $\sigma_i = 0$, the term $(1 - \exp(-\sigma_i \delta_i))$ becomes 0, and the weight $w_i$ becomes 0. The gradient formula remains valid as limits are continuous.
- **Background:** $c_N$ is typically treated as a hyperparameter or optimized separately. If optimized, its gradient is $w_N$.

## Subtopics

### Differentiating Pixel Intensities
This variant extends the ray-level derivatives to full image differentiation. Pixel intensity $I$ is modeled as the inner product between radiance $L$ and a reconstruction kernel $K$ over the pixel footprint $P$: $I = \int_{[0,1)^2} L(x(u), \omega(u)) K(u) du$. When $K$ is independent of scene parameters $\pi$ and continuous in $u$, the derivative $\dot{I}$ includes a boundary term accounting for discontinuities in $L$ along the pixel boundary $\partial[0,1)^2$: $\dot{I} = \int_{[0,1)^2} \dot{L}(x(u), \omega(u)) K(u) du + \int_{\partial[0,1)^2} \langle n, \dot{x}(u) \rangle \Delta L(x(u), \omega(u)) K(u) d\ell(u)$, where $n$ is the normal and $\dot{x}$ is the change rate of the boundary curves [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N)$ per ray, where $N$ is the number of segments. The transmittance and weight calculations are linear. The density gradient calculation involves a nested loop if implemented naively ($O(N^2)$), but can be optimized to $O(N)$ by maintaining a running sum of $c_k w_k$ from $N$ down to $0$.
- **Memory Complexity:** $O(N)$ for storing transmittance, weights, and gradients.
- **Strengths:** Provides exact gradients, enabling stable and efficient optimization of PlenOctree parameters using SGD. Avoids the noise and computational cost of numerical differentiation.
- **Limitations:** Assumes piecewise constant density and color within segments. Does not account for pixel footprint effects or camera parameter dependencies in the basic ray formulation (see Subtopics for extensions) [S1, unofficial][S2, unofficial].
- **When to Use:** When optimizing PlenOctree densities and colors directly against a loss function. Not suitable for differentiating camera poses or complex pixel filtering without the extensions in [Differentiating Pixel Intensities](#differentiating-pixel-intensities).

## Background
The method originates from the PlenOctrees paper, which introduced efficient real-time rendering of Neural Radiance Fields by compressing NeRFs into octrees [S1, unofficial]. The analytic derivatives were derived to allow direct optimization of the PlenOctree structure on original training images, improving image quality over the converted model. The derivation builds on the NeRF volume rendering equation [S1, unofficial]. The extension to pixel intensities is part of the broader differential radiative transfer theory, which handles the differentiation of rendered images with respect to scene parameters, including camera motion and pixel filtering [S2, unofficial].
