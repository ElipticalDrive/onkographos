# Analytic Derivatives of PlenOctree Rendering
Also called: Gradient Computation for PlenOctree Optimization, NeRF Piecewise Constant Volume Rendering Derivatives

## Overview
This method computes the analytic gradients of the NeRF piecewise constant volume rendering equation with respect to density ($\boldsymbol{\sigma}$) and color ($\mathbf{c}$) parameters, enabling direct optimization of PlenOctrees [S1, unofficial]. It differs from numerical differentiation by providing exact, efficient gradients required for stochastic gradient descent (SGD) during the fine-tuning phase of PlenOctree optimization [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A fixed ray with origin and direction, divided into $N$ consecutive segments with endpoints $\{t_i\}_{i=0}^N$. Segment lengths are $\delta_i = t_{i+1} - t_i$. Constant densities $\boldsymbol{\sigma} = (\sigma_0, \dots, \sigma_{N-1})$ and colors $\mathbf{c} = (c_0, \dots, c_N)$, where $c_N$ is the background color.
- **Output:** Gradients $\frac{\partial \hat{C}}{\partial \sigma_i}$ and $\frac{\partial \hat{c}_i}$ for each segment $i$.

**Data Structures:**
- **Accumulated Transmittance ($T_i$):** Precomputed for $i=0 \dots N$.
- **Segment Weights ($w_i$):** Precomputed for $i=0 \dots N$.

**Formulas:**
1.  **Accumulated Transmittance:**
    $$T_i(\boldsymbol{\sigma}) := \prod_{j=0}^{i-1} \exp(-\delta_j \sigma_j)$$
    where $T_0 = 1$. $T_i$ represents the transmittance from $t_0$ to $t_i$ [S1, unofficial].

2.  **Rendered Color:**
    $$\hat{C}(\boldsymbol{\sigma}, \mathbf{c}) = \sum_{i=0}^N w_i(\boldsymbol{\sigma}) c_i$$
    where segment weights are:
    $$w_i(\boldsymbol{\sigma}) = T_i(\boldsymbol{\sigma}) (1 - \exp(-\sigma_i \delta_i)) = T_i(\boldsymbol{\sigma}) - T_{i+1}(\boldsymbol{\sigma}) \quad \text{for } i < N$$
    $$w_N(\boldsymbol{\sigma}) = T_N(\boldsymbol{\sigma})$$
    [S1, unofficial].

3.  **Color Derivative:**
    $$\frac{\partial \hat{C}}{\partial c_i}(\boldsymbol{\sigma}, \mathbf{c}) = w_i(\boldsymbol{\sigma})$$
    [S1, unofficial].

4.  **Density Derivative:**
    The derivative with respect to $\sigma_i$ is:
    $$\frac{\partial \hat{C}}{\partial \sigma_i}(\boldsymbol{\sigma}, \mathbf{c}) = \delta_i \left[ c_i T_{i+1}(\boldsymbol{\sigma}) - \sum_{k=i+1}^N c_k w_k(\boldsymbol{\sigma}) \right]$$
    [S1, unofficial].
    *Derivation Note:* This simplifies from the general form $\frac{\partial \hat{C}}{\partial \sigma_i} = c_N \frac{\partial T_N}{\partial \sigma_i} + \sum_{k=0}^{N-1} c_k \left( \frac{\partial T_k}{\partial \sigma_i} - \frac{\partial T_{k+1}}{\partial \sigma_i} \right)$ using $\frac{\partial T_k}{\partial \sigma_i} = -\delta_i T_k(\boldsymbol{\sigma}) \mathbf{1}_{k>i}$ [S1, unofficial].

**Spherical Harmonics (SH) Handling:**
When colors $\mathbf{c}$ are represented by Spherical Harmonics coefficients, the chain rule is applied. Since SH basis function values are constant across the ray, the derivative with respect to SH coefficients is computed by multiplying the gradient with respect to color $\mathbf{c}$ by the SH basis values [S1, unofficial].

**Pseudocode:**
```python
def compute_gradients(N, deltas, sigmas, colors, background_color):
    """
    Computes gradients for NeRF volume rendering.
    N: Number of segments.
    deltas: Array of length N, segment lengths delta_i.
    sigmas: Array of length N, densities sigma_i.
    colors: Array of length N+1, colors c_0 to c_N (c_N is background).
    background_color: Scalar intensity (typically 1.0) for background light.
    Returns: grad_sigmas (N,), grad_colors (N+1,)
    """
    # 1. Compute Transmittance T_i
    # T_i is product from j=0 to i-1 of exp(-delta_j * sigma_j)
    # T_0 = 1
    T = [0.0] * (N + 1)
    T[0] = 1.0
    for i in range(1, N + 1):
        T[i] = T[i-1] * math.exp(-deltas[i-1] * sigmas[i-1])

    # 2. Compute Weights w_i
    # w_i = T_i - T_{i+1} for i < N
    # w_N = T_N
    w = [0.0] * (N + 1)
    for i in range(N):
        w[i] = T[i] - T[i+1]
    w[N] = T[N]

    # 3. Compute Color Gradients
    # dC/dc_i = w_i
    grad_colors = list(w)

    # 4. Compute Density Gradients
    # dC/dsigma_i = delta_i * [ c_i * T_{i+1} - sum_{k=i+1}^N c_k * w_k ]
    grad_sigmas = [0.0] * N
    for i in range(N):
        # Term 1: c_i * T_{i+1}
        term1 = colors[i] * T[i+1]
        
        # Term 2: sum_{k=i+1}^N c_k * w_k
        sum_term = 0.0
        for k in range(i+1, N+1):
            sum_term += colors[k] * w[k]
            
        grad_sigmas[i] = deltas[i] * (term1 - sum_term)

    return grad_sigmas, grad_colors
```

## Subtopics

### Differentiating Pixel Intensities
This variant extends the derivative computation to the pixel level, modeling pixel intensity $I$ as the inner product between radiance $L$ and a reconstruction kernel $K$ over the pixel footprint $P$. The differentiated intensity $\hat{I}$ includes a boundary integral term accounting for discontinuities in $L$ along the boundary of the pixel domain $\partial[0,1)^2$, which is necessary when camera parameters depend on scene parameters [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N)$ per ray for precomputing transmittance and weights, and $O(N)$ for computing gradients. The density derivative summation is $O(N^2)$ if implemented naively, but can be optimized to $O(N)$ by maintaining a running sum of $c_k w_k$ from $N$ down to $0$.
- **Memory Complexity:** $O(N)$ to store $T_i$, $w_i$, and intermediate sums.
- **Strengths:** Provides exact gradients, enabling stable and efficient convergence during PlenOctree fine-tuning. Handles SH colors naturally via the chain rule.
- **Limitations:** Assumes piecewise constant density and color within segments. Requires careful handling of numerical stability for very small or large $\sigma_i \delta_i$ values (e.g., using `expm1` for small arguments) [G].
- **When to use:** When optimizing PlenOctree parameters directly using gradient-based methods like SGD.
- **When not to use:** When using differentiable rendering techniques that require pixel-space derivatives with complex camera models or non-constant kernels [S2, unofficial].

## Background
The method was introduced in the context of PlenOctrees for real-time rendering of Neural Radiance Fields (NeRFs) [S1, unofficial]. It builds on the NeRF volume rendering formulation [S1, unofficial] and provides the necessary gradients for optimizing the octree structure's density and color attributes directly, rather than relying on numerical approximations. The approach is detailed in Appendix B.3 of the PlenOctrees paper [S1, unofficial].
