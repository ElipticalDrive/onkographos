# Fourier PlenOctree


## Overview
Fourier PlenOctree is a 4D scene representation designed for real-time rendering of free-viewpoint videos by compressing time-variant information in the frequency domain [S3]. It extends the static PlenOctree [1366-plenoctree.md] by storing Fourier coefficients for density and spherical harmonic (SH) color coefficients within an octree structure, allowing the reconstruction of dynamic scenes from a unified spatial grid [S3]. Unlike standard PlenOctree where structures vary per frame, Fourier PlenOctree requires a unified octree structure across all timestamps to analyze plenoptic functions at consistent positions [S3].

## How it works
**Inputs and Outputs**
- **Inputs:** A sequence of $T$ PlenOctrees (one per timestamp $t=1 \dots T$) generated from sparse views, or a generalized NeRF model for initialization [S2, S3]. Ground truth images for fine-tuning [S3].
- **Outputs:** A single Fourier PlenOctree containing Fourier coefficients $k_\sigma$ and $k_z$ at each leaf, enabling real-time rendering of dynamic scenes [S3].

**Data Structures**
The Fourier PlenOctree is an octree where each leaf node stores:
1.  $k_\sigma \in \mathbb{R}^{n_1}$: Fourier coefficients for density $\sigma(t)$.
2.  $k_z \in \mathbb{R}^{n_2 \times (l_{max} + 1) \times 3}$: Fourier coefficients for SH color coefficients $z(t)$ [S3].
    -   $n_1$: Number of Fourier coefficients for density.
    -   $n_2$: Number of Fourier coefficients for each SH element.
    -   $l_{max}$: Maximum SH degree. The number of SH coefficients per channel is $(l_{max} + 1)^2$ [S3].
    -   $k_z$ is indexed as $k_{z_{m,l,i}}$, where $m, l$ define the SH basis and $i$ is the Fourier coefficient index [S3].

**Parameters**
-   $l_{max}$: Maximum SH degree. Typical value: 2 (resulting in 9 components) [S3].
-   Grid Size: The spatial resolution of the bounding volume. Typical value: $512^3$ [S3].
-   Transmittance Threshold: Used to filter empty points. Typical value: $10^{-3}$ [S3].

**Steps**

1.  **Unified Octree Construction:**
    Compute the union of octree structures from all frames $t=1 \dots T$. If a leaf in the union is divided relative to a specific frame's tree, copy the pre-existing value from the parent node to the new children leaves to ensure structural uniformity [S3].

2.  **Initialization (Optional/Coarse Stage):**
    If initializing from scratch or sparse views:
    a. Construct a coarse visual hull using Shape-From-Silhouette (SFS) from sparse views [S2].
    b. Densely sample colors and densities inside the hull and store on a coarse PlenOctree [S2].
    c. Sample dense views from the PlenOctree and apply transmissivity thresholding ($T_i > 10^{-3}$) to eliminate empty points [S2, S3].
    d. Generate new leaf densities and SH coefficients for remaining points and update the PlenOctree [S2].
    e. Use a Fourier Transform MLP (Fourier NeRF-SH) to extract initial Fourier coefficients $k_\sigma$ and $k_z$ [S2].

3.  **Fourier Coefficient Extraction (DFT):**
    For each leaf position $(x, y, z)$, compute the Fourier coefficients for density and SH coefficients using the Discrete Fourier Transform (DFT) across the $T$ frames [S3].
    
    For density $\sigma(t)$:
    $$ k_{\sigma, i} = \sum_{t=1}^{T} \sigma(t) \cdot \text{DFT}_i(t) $$
    
    For SH coefficients $z_{m,l}(t)$:
    $$ k_{z_{m,l}, i} = \sum_{t=1}^{T} z_{m,l}(t) \cdot \text{DFT}_i(t) $$
    
    Where the DFT basis function $\text{DFT}_i(t)$ is defined as [S3]:
    $$
    \text{DFT}_i(t) = 
    \begin{cases} 
    \frac{1}{T} \cos\left(\frac{i \pi t}{T}\right) & \text{if } i \text{ is even} \\
    \frac{1}{T} \sin\left(\frac{(i+1) \pi t}{T}\right) & \text{if } i \text{ is odd}
    \end{cases}
    $$

4.  **Rendering (IDFT):**
    To render a frame at timestamp $t$, recover the density and SH coefficients from the stored Fourier coefficients using the Inverse Discrete Fourier Transform (IDFT) [S3].
    
    Recover density $\sigma(t)$:
    $$ \sigma(t; k_\sigma) = \sum_{i=0}^{n_1-1} k_{\sigma, i} \cdot \text{IDFT}_i(t) $$
    
    Recover SH coefficients $z_{m,l}(t)$:
    $$ z_{m,l}(t; k_z) = \sum_{i=0}^{n_2-1} k_{z_{m,l}, i} \cdot \text{IDFT}_i(t) $$
    
    Where the IDFT basis function $\text{IDFT}_i(t)$ is defined as [S3]:
    $$
    \text{IDFT}_i(t) = 
    \begin{cases} 
    \cos\left(\frac{i \pi t}{T}\right) & \text{if } i \text{ is even} \\
    \sin\left(\frac{(i+1) \pi t}{T}\right) & \text{if } i \text{ is odd}
    \end{cases}
    $$

5.  **Fine-tuning (Optional):**
    Optimize the Fourier PlenOctree using ground truth images to improve rendering quality [S3]. This involves updating leaf values using a fusion-based approach where transmittance $T_i$ acts as an update weight [S3].

**Pseudocode**

```python
import numpy as np

def compute_dft_basis(i, t, T):
    if i % 2 == 0:
        return (1.0 / T) * np.cos(i * np.pi * t / T)
    else:
        return (1.0 / T) * np.sin((i + 1) * np.pi * t / T)

def compute_idft_basis(i, t, T):
    if i % 2 == 0:
        return np.cos(i * np.pi * t / T)
    else:
        return np.sin((i + 1) * np.pi * t / T)

def extract_fourier_coefficients(density_seq, sh_seq, T, n1, n2, l_max):
    num_sh = (l_max + 1) ** 2
    k_sigma = np.zeros(n1)
    k_z = np.zeros((n2, num_sh, 3))

    for i in range(n1):
        for t in range(1, T + 1):
            k_sigma[i] += density_seq[t - 1] * compute_dft_basis(i, t, T)

    for i in range(n2):
        for sh_idx in range(num_sh):
            for c in range(3):
                for t in range(1, T + 1):
                    k_z[i, sh_idx, c] += sh_seq[t - 1, sh_idx, c] * compute_dft_basis(i, t, T)
    return k_sigma, k_z

def render_fourier_plenoctree(k_sigma, k_z, t, T, n1, n2, l_max):
    num_sh = (l_max + 1) ** 2
    sigma_t = 0.0
    for i in range(n1):
        sigma_t += k_sigma[i] * compute_idft_basis(i, t, T)

    z_t = np.zeros((num_sh, 3))
    for i in range(n2):
        for sh_idx in range(num_sh):
            for c in range(3):
                z_t[sh_idx, c] += k_z[i, sh_idx, c] * compute_idft_basis(i, t, T)
    return sigma_t, z_t
```

**Edge Cases and Pitfalls**
-   **Structural Unification:** Copying parent values to new leaves during unification ensures consistent geometry across frames but may introduce artifacts if motion is complex [S3].
-   **Frequency Aliasing:** Cutting off high frequencies in DFT compression leads to ghosting artifacts and equally distributed errors across the signal, which persist even after fine-tuning [S1].
-   **Density Saturation:** Large density values saturate in the volume rendering exponential function, allowing for higher reconstruction errors without visual impairment, but standard L2 minimization treats all errors equally [S1].
-   **Negative Densities:** Negative densities cannot be meaningfully interpreted in volume rendering but can represent free space if clipped via ReLU during rendering [S1].

## Operating characteristics
-   **Time Complexity:** Rendering is $O(n_1 + n_2 \cdot (l_{max}+1)^2 \cdot 3)$ per leaf per frame, which is constant and fast, enabling real-time performance [S3]. Generation time is significantly faster than training a dynamic NeRF from scratch (e.g., 2 hours vs 1-2 days) [S2, S3].
-   **Memory Complexity:** Memory usage is proportional to the number of leaves in the unified octree multiplied by the size of the Fourier coefficient arrays ($n_1$ and $n_2$) [S3].
-   **Performance:** Achieves 100 fps at 800x800 resolution on an NVIDIA GeForce RTX 3090, which is 3000 times faster than original NeRF [S2].
-   **Strengths:** Real-time rendering of dynamic scenes; fast generation compared to implicit neural methods; leverages efficient static PlenOctree rendering pipeline [S2, S3].
-   **Limitations:** Requires unified octree structure across all frames, which can be restrictive for highly dynamic scenes with complex topology changes [S3]. Quality depends on the accuracy of the initial PlenOctree generation and the number of Fourier coefficients [S3].

## Background
Fourier PlenOctree was proposed by Wang et al. in February 2022 [S2]. It was designed for human silhouette rendering using Shape-From-Silhouette, drawing inspiration from generalizable image-conditioned NeRFs [S2]. The method extends the PlenOctree [1366-plenoctree.md] concept to 4D dynamic scenes by incorporating frequency domain compression [S3]. It is used for free-viewpoint video generation and real-time novel view synthesis of dynamic scenes [S3].
