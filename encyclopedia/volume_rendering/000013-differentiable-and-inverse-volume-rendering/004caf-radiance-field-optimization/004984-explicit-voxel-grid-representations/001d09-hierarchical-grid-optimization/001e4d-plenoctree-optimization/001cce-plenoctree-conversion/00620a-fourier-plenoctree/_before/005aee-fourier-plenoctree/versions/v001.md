# Fourier PlenOctree

Also called: Fourier PlenOctrees for Dynamic Radiance Field Rendering in Real-time

## Overview
Fourier PlenOctree is a 4D scene representation designed for real-time rendering of free-viewpoint videos by compressing time-variant information in the frequency domain [S2]. It extends the static PlenOctree [1366-plenoctree.md] by storing Fourier coefficients for density and spherical harmonic (SH) color coefficients within an octree structure, allowing the reconstruction of dynamic scenes from a unified spatial grid [S2]. Unlike standard PlenOctree where structures vary per frame, Fourier PlenOctree requires a unified octree structure across all timestamps to analyze plenoptic functions at consistent positions [S2].

## How it works
**Inputs and Outputs**
- **Inputs:** A sequence of $T$ PlenOctrees (one per timestamp $t=1 \dots T$) generated from sparse views, or a generalized NeRF model for initialization. Ground truth images for fine-tuning [S2].
- **Outputs:** A single Fourier PlenOctree containing Fourier coefficients $k_\sigma$ and $k_z$ at each leaf, enabling real-time rendering of dynamic scenes [S2].

**Data Structures**
The Fourier PlenOctree is an octree where each leaf node stores:
1.  $k_\sigma \in \mathbb{R}^{n_1}$: Fourier coefficients for density $\sigma(t)$.
2.  $k_z \in \mathbb{R}^{n_2 \times (l_{max} + 1) \times 3}$: Fourier coefficients for SH color coefficients $z(t)$.
    -   $n_1$: Number of Fourier coefficients for density.
    -   $n_2$: Number of Fourier coefficients for each SH element.
    -   $l_{max}$: Maximum SH degree. The number of SH coefficients per channel is $(l_{max} + 1)^2$. Total SH coefficients for RGB is $(l_{max} + 1)^2 \times 3$ [S2].
    -   $k_z$ is indexed as $k_{z_{m,l,i}}$, where $m, l$ define the SH basis and $i$ is the Fourier coefficient index [S2].

**Parameters**
-   $l_{max}$: Maximum SH degree. Typical value: 2 (resulting in 9 components) [S2].
-   Grid Size: The spatial resolution of the bounding volume. Typical value: $512^3$ [S2].
-   Transmittance Threshold: Used to filter empty points. Typical value: $10^{-3}$ [S2].

**Steps**

1.  **Unified Octree Construction:**
    Compute the union of octree structures from all frames $t=1 \dots T$. If a leaf in the union is divided relative to a specific frame's tree, copy the pre-existing value from the parent node to the new children leaves to ensure structural uniformity [S2].

2.  **Initialization (Optional/Coarse Stage):**
    If initializing from scratch or sparse views:
    a. Construct a coarse visual hull using Shape-From-Silhouette (SFS) from sparse views [S1].
    b. Densely sample colors and densities inside the hull and store on a coarse PlenOctree [S1].
    c. Sample dense views from the PlenOctree and apply transmissivity thresholding ($T_i > 10^{-3}$) to eliminate empty points [S1, S2].
    d. Generate new leaf densities and SH coefficients for remaining points and update the PlenOctree [S1].
    e. Use a Fourier Transform MLP (Fourier NeRF-SH) to extract initial Fourier coefficients $k_\sigma$ and $k_z$ [S1].

3.  **Fourier Coefficient Extraction (DFT):**
    For each leaf position $(x, y, z)$, compute the Fourier coefficients for density and SH coefficients using the Discrete Fourier Transform (DFT) across the $T$ frames [S2].
    
    For density $\sigma(t)$:
    $$ k_{\sigma, i} = \sum_{t=1}^{T} \sigma(t) \cdot \text{DFT}_i(t) $$
    
    For SH coefficients $z_{m,l}(t)$:
    $$ k_{z_{m,l}, i} = \sum_{t=1}^{T} z_{m,l}(t) \cdot \text{DFT}_i(t) $$
    
    Where the DFT basis function $\text{DFT}_i(t)$ is defined as [S2]:
    $$
    \text{DFT}_i(t) = 
    \begin{cases} 
    \frac{1}{T} \cos\left(\frac{i \pi t}{T}\right) & \text{if } i \text{ is even} \\
    \frac{1}{T} \sin\left(\frac{(i+1) \pi t}{T}\right) & \text{if } i \text{ is odd}
    \end{cases}
    $$

4.  **Rendering (IDFT):**
    To render a frame at timestamp $t$, recover the density and SH coefficients from the stored Fourier coefficients using the Inverse Discrete Fourier Transform (IDFT) [S2].
    
    Recover density $\sigma(t)$:
    $$ \sigma(t; k_\sigma) = \sum_{i=0}^{n_1-1} k_{\sigma, i} \cdot \text{IDFT}_i(t) $$
    
    Recover SH coefficients $z_{m,l}(t)$:
    $$ z_{m,l}(t; k_z) = \sum_{i=0}^{n_2-1} k_{z_{m,l}, i} \cdot \text{IDFT}_i(t) $$
    
    Where the IDFT basis function $\text{IDFT}_i(t)$ is defined as [S2]:
    $$
    \text{IDFT}_i(t) = 
    \begin{cases} 
    \cos\left(\frac{i \pi t}{T}\right) & \text{if } i \text{ is even} \\
    \sin\left(\frac{(i+1) \pi t}{T}\right) & \text{if } i \text{ is odd}
    \end{cases}
    $$

5.  **Fine-tuning (Optional):**
    Optimize the Fourier PlenOctree using ground truth images to improve rendering quality [S2]. This involves updating leaf values using a fusion-based approach where transmittance $T_i$ acts as an update weight [S2].

**Pseudocode**

```python
import numpy as np

def compute_dft_basis(i, t, T):
    """
    Computes the DFT basis function value for index i, time t, and total frames T.
    """
    if i % 2 == 0:
        return (1.0 / T) * np.cos((i * np.pi * t) / T)
    else:
        return (1.0 / T) * np.sin(((i + 1) * np.pi * t) / T)

def compute_idft_basis(i, t, T):
    """
    Computes the IDFT basis function value for index i, time t, and total frames T.
    """
    if i % 2 == 0:
        return np.cos((i * np.pi * t) / T)
    else:
        return np.sin(((i + 1) * np.pi * t) / T)

def extract_fourier_coefficients(density_sequence, sh_sequence, T, n1, n2, l_max):
    """
    Extracts Fourier coefficients from time-series density and SH data.
    
    Args:
        density_sequence: Array of shape (T,) containing density sigma(t) for each frame.
        sh_sequence: Array of shape (T, (l_max+1)^2, 3) containing SH coefficients z(t).
        T: Total number of frames.
        n1: Number of Fourier coefficients for density.
        n2: Number of Fourier coefficients for each SH element.
        l_max: Maximum SH degree.
        
    Returns:
        k_sigma: Array of shape (n1,)
        k_z: Array of shape (n2, (l_max+1)^2, 3)
    """
    # Initialize coefficients
    k_sigma = np.zeros(n1)
    # Flatten SH dimensions for easier indexing, then reshape back
    # SH shape: (T, num_sh, 3) where num_sh = (l_max+1)^2
    num_sh = (l_max + 1) ** 2
    k_z_flat = np.zeros((n2, num_sh, 3))
    
    # Compute DFT for density
    for i in range(n1):
        for t in range(1, T + 1): # t is 1-indexed in formula
            k_sigma[i] += density_sequence[t-1] * compute_dft_basis(i, t, T)
            
    # Compute DFT for SH coefficients
    for i in range(n2):
        for m in range(-l_max, l_max + 1):
            for l in range(0, l_max + 1):
                # Map (m, l) to index in num_sh
                # Standard SH indexing: index = l^2 + l + m + l
                # Note: The source uses z_{m,l} where m ranges -l to l.
                # We assume a standard flattening order consistent with the source's (l_max+1)^2 size.
                # A common mapping is: idx = l*(l+1) + (m+l)
                idx = l * (l + 1) + (m + l)
                
                for c in range(3): # RGB channels
                    for t in range(1, T + 1):
                        k_z_flat[i, idx, c] += sh_sequence[t-1, idx, c] * compute_dft_basis(i, t, T)
                        
    k_z = k_z_flat.reshape(n2, (l_max + 1) ** 2, 3)
    return k_sigma, k_z

def render_fourier_plenoctree(k_sigma, k_z, t, T, n1, n2, l_max):
    """
    Renders density and SH coefficients for a specific timestamp t.
    
    Args:
        k_sigma: Array of shape (n1,)
        k_z: Array of shape (n2, (l_max+1)^2, 3)
        t: Target timestamp (1-indexed).
        T: Total number of frames.
        n1: Number of Fourier coefficients for density.
        n2: Number of Fourier coefficients for each SH element.
        l_max: Maximum SH degree.
        
    Returns:
        sigma_t: Density at time t.
        z_t: SH coefficients at time t, shape ((l_max+1)^2, 3).
    """
    num_sh = (l_max + 1) ** 2
    
    # Recover density
    sigma_t = 0.0
    for i in range(n1):
        sigma_t += k_sigma[i] * compute_idft_basis(i, t, T)
        
    # Recover SH coefficients
    z_t = np.zeros((num_sh, 3))
    for i in range(n2):
        for m in range(-l_max, l_max + 1):
            for l in range(0, l_max + 1):
                idx = l * (l + 1) + (m + l)
                for c in range(3):
                    z_t[idx, c] += k_z[i, idx, c] * compute_idft_basis(i, t, T)
                    
    return sigma_t, z_t
```

**Edge Cases and Pitfalls**
-   **Structural Unification:** If octree structures vary significantly across frames, the union operation may create very deep trees or large empty spaces. Copying parent values to new leaves during unification assumes smoothness, which may introduce artifacts if motion is complex [S2].
-   **Frequency Aliasing:** The choice of $n_1$ and $n_2$ must be sufficient to capture the temporal frequency of the scene. Insufficient coefficients lead to reconstruction errors [S2].
-   **Boundary Conditions:** The DFT/IDFT formulas assume periodicity or specific boundary behaviors defined by the cosine/sine basis. Ensure $t$ is handled consistently (1-indexed vs 0-indexed) as per the source formulas [S2].

## Operating characteristics
-   **Time Complexity:** Rendering is $O(n_1 + n_2 \cdot (l_{max}+1)^2 \cdot 3)$ per leaf per frame, which is constant and fast, enabling real-time performance [S2]. Generation time is significantly faster than training a dynamic NeRF from scratch (e.g., 2 hours vs 1-2 days) [S1, S2].
-   **Memory Complexity:** Memory usage is proportional to the number of leaves in the unified octree multiplied by the size of the Fourier coefficient arrays ($n_1$ and $n_2$) [S2].
-   **Performance:** Achieves 100 fps at 800x800 resolution on an NVIDIA GeForce RTX 3090, which is 3000 times faster than original NeRF [S2].
-   **Strengths:** Real-time rendering of dynamic scenes; fast generation compared to implicit neural methods; leverages efficient static PlenOctree rendering pipeline [S2].
-   **Limitations:** Requires unified octree structure across all frames, which can be restrictive for highly dynamic scenes with complex topology changes [S2]. Quality depends on the accuracy of the initial PlenOctree generation and the number of Fourier coefficients [S2].

## Background
Fourier PlenOctree was proposed by Wang et al. in February 2022 [S1]. It was designed for human silhouette rendering using Shape-From-Silhouette, drawing inspiration from generalizable image-conditioned NeRFs [S1]. The method extends the PlenOctree [1366-plenoctree.md] concept to 4D dynamic scenes by incorporating frequency domain compression [S2]. It is used for free-viewpoint video generation and real-time novel view synthesis of dynamic scenes [S2].
