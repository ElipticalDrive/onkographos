# Plenoxel
## Overview
Plenoxel is a volume rendering method that represents a scene as a sparse 3D grid of voxels, calculating color and opacity via trilinear interpolation during ray casting without using neural networks [S2]. It solves the problem of high computational cost in neural radiance fields by relaxing the PlenOctrees assumption of constant opacity and spherical harmonic (SH) coefficients inside each voxel, instead defining a continuous function throughout the volume [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A sparse 3D voxel grid containing learnable parameters; camera poses and viewing directions [S2].
*   **Output:** Rendered HDR color image $\hat{C}(\mathbf{r})$ for given rays $\mathbf{r}$ [S3].

**Data Structures:**
The scene is represented by a voxel grid [S2]. Each vertex of the voxel grid stores a 28-dimensional vector [S3]:
1.  **SH Coefficients:** 27 values, corresponding to 9 coefficients per color channel (R, G, B) for degree-2 spherical harmonics [S3].
2.  **Opacity:** 1 scalar value $\sigma$ [S3].

**Algorithm Steps:**
1.  **Initialization:** Initialize voxel opacities $\sigma$ to 0.1 and color coefficients to grey by adding an offset of 0.5 to the SH coefficients [S3].
2.  **Ray Definition:** For each pixel, define a ray $\mathbf{r} = \mathbf{o} + t\mathbf{d}$, where $\mathbf{o}$ is the camera center and $\mathbf{d}$ is the normalized viewing direction [S3].
3.  **Sampling:** Sample $N$ points along the ray at regular intervals $\delta_i = t_{i+1} - t_i$ [S3].
4.  **Interpolation:** For any 3D point $(x, y, z)$ and normalized viewing angle $(v_x, v_y, v_z)$ within the voxel grid, trilinearly interpolate the color $\mathbf{c}_i$ and opacity $\sigma_i$ from the eight nearby voxel vertices [S1, S3].
5.  **Rendering:** Compute the accumulated transmittance $T_i$ and the final color using the volume rendering integral [S3]:
    $$ \hat{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i \left( 1 - \exp(-\sigma_i \delta_i) \right) \mathbf{c}_i $$
    where the transmittance is defined as:
    $$ T_i = \exp\left( -\sum_{j=1}^{i-1} \sigma_j \delta_j \right) $$
6.  **Optimization:** Directly optimize the voxel opacities and SH coefficients using gradient-based optimizers, without neural network backpropagation through a MLP [S1].

**Pseudocode:**
```python
import math

def render_plenoxel(ray_origin, ray_direction, voxel_grid, num_samples, bounds):
    """
    Renders a single ray using Plenoxel representation.
    
    Args:
        ray_origin: 3D vector (o)
        ray_direction: 3D vector (d), normalized
        voxel_grid: Sparse 3D grid storing 28D vectors per vertex
        num_samples: Integer N
        bounds: Tuple (x_min, x_max, y_min, y_max, z_min, z_max) defining the grid extent
        
    Returns:
        color: 3D vector (RGB)
        alpha: Float (accumulated opacity)
    """
    # 1. Ray-AABB intersection
    t_min, t_max = intersect_aabb(ray_origin, ray_direction, bounds)
    if t_min > t_max:
        return [0.0, 0.0, 0.0], 0.0

    # 2. Sample points at regular intervals
    delta = (t_max - t_min) / num_samples
    t_values = [t_min + i * delta for i in range(num_samples + 1)]

    accumulated_transmittance = 1.0
    final_color = [0.0, 0.0, 0.0]

    for i in range(num_samples):
        t_i = t_values[i]
        point_pos = ray_origin + ray_direction * t_i

        # 3. Trilinear Interpolation
        c_i, sigma_i = trilinear_interpolate(voxel_grid, point_pos, ray_direction)

        # 4. Volume Rendering Step
        weight = 1.0 - math.exp(-sigma_i * delta)
        final_color = [final_color[k] + accumulated_transmittance * weight * c_i[k] for k in range(3)]
        accumulated_transmittance *= math.exp(-sigma_i * delta)

        # Early termination if transmittance is negligible
        if accumulated_transmittance < 1e-5:
            break

    return final_color, 1.0 - accumulated_transmittance

def intersect_aabb(o, d, bounds):
    x_min, x_max, y_min, y_max, z_min, z_max = bounds
    # Handle parallel rays and compute entry/exit distances
    tx1 = (x_min - o[0]) / d[0] if d[0] != 0 else float('-inf')
    tx2 = (x_max - o[0]) / d[0] if d[0] != 0 else float('inf')
    ty1 = (y_min - o[1]) / d[1] if d[1] != 0 else float('-inf')
    ty2 = (y_max - o[1]) / d[1] if d[1] != 0 else float('inf')
    tz1 = (z_min - o[2]) / d[2] if d[2] != 0 else float('-inf')
    tz2 = (z_max - o[2]) / d[2] if d[2] != 0 else float('inf')
    
    t_min = max(min(tx1, tx2), min(ty1, ty2), min(tz1, tz2))
    t_max = min(max(tx1, tx2), max(ty1, ty2), max(tz1, tz2))
    return t_min, t_max

def trilinear_interpolate(grid, pos, dir):
    # Map world position to grid coordinates (assumes unit spacing for simplicity)
    ix, iy, iz = int(math.floor(pos[0])), int(math.floor(pos[1])), int(math.floor(pos[2]))
    fx, fy, fz = pos[0] - ix, pos[1] - iy, pos[2] - iz

    # Boundary check [G]
    if ix < 0 or iy < 0 or iz < 0 or ix >= grid.shape[0]-1 or iy >= grid.shape[1]-1 or iz >= grid.shape[2]-1:
        return [0.0, 0.0, 0.0], 0.0

    # Fetch 8 vertices
    v000 = grid[ix, iy, iz]
    v100 = grid[ix+1, iy, iz]
    v010 = grid[ix, iy+1, iz]
    v110 = grid[ix+1, iy+1, iz]
    v001 = grid[ix, iy, iz+1]
    v101 = grid[ix+1, iy, iz+1]
    v011 = grid[ix, iy+1, iz+1]
    v111 = grid[ix+1, iy+1, iz+1]

    def lerp(a, b, t): return a + t * (b - a)
    
    # Interpolate along x
    c00 = [lerp(v000[k], v100[k], fx) for k in range(28)]
    c01 = [lerp(v010[k], v110[k], fx) for k in range(28)]
    c10 = [lerp(v001[k], v101[k], fx) for k in range(28)]
    c11 = [lerp(v011[k], v111[k], fx) for k in range(28)]
    
    # Interpolate along y
    c0 = [lerp(c00[k], c01[k], fy) for k in range(28)]
    c1 = [lerp(c10[k], c11[k], fy) for k in range(28)]
    
    # Interpolate along z
    result = [lerp(c0[k], c1[k], fz) for k in range(28)]
    
    return result[:3], result[27]
```

**Parameters:**
*   **Initial Opacity:** 0.1 [S3].
*   **Initial Color Offset:** 0.5 added to initialize color to grey [S3].
*   **Sampling:** $N$ points sampled at regular intervals [S3].

**Edge Cases and Pitfalls:**
*   **Training Instability:** SH coefficients can change significantly during training, leading to instability. The grey initialization offset mitigates this [S3].
*   **Boundary Conditions:** Trilinear interpolation requires valid voxel neighbors. Points outside the sparse grid bounds must be handled (e.g., treated as transparent or background) [G].
*   **Precision:** The product $\sigma_i \delta_i$ must be dimensionless; ensure $\sigma$ is in inverse world units and $\delta$ is in world units to avoid overflow or underflow in the exponential term [G].

## Subtopics

### HDR-Plenoxels Volume Representation
A radiance representation using Spherical Harmonics (SH) in a voxel grid to model HDR irradiance, exploiting SH's ability to implicitly express non-Lambertian effects and span all colors over every direction of a sphere [S3]. It follows the standard Plenoxel interpolation and rendering pipeline but is specifically configured for High Dynamic Range output, often followed by an explicit tone mapping stage to convert HDR radiance to LDR images [S3].

## Operating characteristics
*   **Time Complexity:** Rendering requires $O(N)$ trilinear interpolations per ray, where $N$ is the number of samples. This is significantly faster than neural network queries (MLPs) used in standard NeRF, which involve multiple matrix multiplications per sample [G].
*   **Memory Complexity:** Memory usage is proportional to the number of voxels in the sparse grid. Each voxel vertex stores 28 floats (27 SH + 1 opacity) [G].
*   **Performance:** Plenoxels optimized with Instant-NGP algorithms achieve training speeds 2 orders of magnitude faster than JNeRF, with no loss in visual quality on standard benchmarks [S2].
*   **Strengths:** No neural network overhead; efficient ray marching; continuous representation avoids artifacts from piecewise constant assumptions [S1, S2].

## Background
Plenoxel was proposed by Fridovich-Keil et al. in 2022 [S1, S2]. It was introduced as a NeRF model without neural networks, representing the scene as a sparse 3D grid [S2]. It relaxes the PlenOctrees assumption [YLT* 21] by using trilinear interpolation to define a continuous function throughout the volume, directly optimizing voxel opacities and SH coefficients [S1].
