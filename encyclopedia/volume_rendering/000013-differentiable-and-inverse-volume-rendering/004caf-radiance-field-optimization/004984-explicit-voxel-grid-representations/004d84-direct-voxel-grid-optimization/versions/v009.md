# Direct Voxel Grid Optimization

Also called: DVG, Direct Voxel Density Optimization, Direct Voxel Grid Optimization Implementation, DirectVoxGo (DVGO)

## Overview
Direct Voxel Grid Optimization (DVGO) is a method for reconstructing per-scene radiance fields from calibrated images by directly optimizing a dense 3D voxel grid for volume density and a feature voxel grid for color, achieving convergence in less than 15 minutes on a single GPU [S1, S5]. It sets itself apart from implicit methods like NeRF by replacing large neural networks with explicit voxel grids, and from earlier voxel methods by training the grid directly from scratch without requiring a conversion step from a pre-trained implicit model [S1, S5]. Its key differentiators are post-activation interpolation for sharp surface modeling and specific priors to prevent suboptimal "cloud" artifacts in free space [S1].

## How it works
DVGO represents the scene using two primary data structures: a density voxel grid and a feature voxel grid, optimized via a two-stage process (coarse geometry search and fine detail reconstruction) [S1, S3].

### Inputs and Outputs
*   **Inputs:** A set of $N$ calibrated images with known camera poses (intrinsic and extrinsic parameters). The scene is assumed to be bounded within a tight bounding box (BBox) [S1, S3].
*   **Outputs:** Optimized density voxel grid $V^{(c)}$ and $V^{(f)}$, feature voxel grid $V^{(feat)}$, and a shallow MLP for color prediction. The result is a radiance field capable of rendering novel views [S1].

### Data Structures
1.  **Density Voxel Grid ($V$):** A 3D grid storing raw density values $\sigma$.
    *   **Coarse Stage ($V^{(c)}$):** Resolution $M^{(c)} \approx 100^3$ [S1, S5].
    *   **Fine Stage ($V^{(f)}$):** Resolution $M^{(f)} = 160^3$ (default) or $256^3$ [S1, S5].
    *   **Layout:** Dense 3D array. Values are queried via trilinear interpolation [S1].
2.  **Feature Voxel Grid ($V^{(feat)}$):** A 3D grid storing feature vectors.
    *   **Resolution:** Same as the fine density grid $V^{(f)}$ [S1].
    *   **Channels:** $D = 12$ [S1].
    *   **Layout:** Dense 3D array. Values are queried via trilinear interpolation [S1].
3.  **Shallow MLP:** A small network mapping features to view-dependent color.
    *   **Architecture:** 2 hidden layers, 128 channels per layer [S5].
    *   **Input:** Concatenation of interpolated features from $V^{(feat)}$ and positional encodings of position and viewing direction [S1, S5].
    *   **Output:** RGB color $\mathbf{c}$ [S1].

### Numbered Steps

#### 1. Initialization and Bounding Box
*   Automatically determine a BBox tightly enclosing the volume of interest to ensure parsimony [S1, S5].
*   Initialize the coarse density grid $V^{(c)}$ such that the initial activated alpha is $\alpha_{\text{init}}^{(c)} = 10^{-6}$ [S1, S5]. This low initialization avoids biasing geometry toward camera near planes [S1].
*   Initialize the fine density grid $V^{(f)}$ with $\alpha_{\text{init}}^{(f)} = 0.01$ [S1, S5].

#### 2. Coarse Geometry Search
*   **Grid:** Use $V^{(c)}$ (resolution $100^3$) and a simple color voxel grid (view-invariant) [S3].
*   **Sampling:** Sample $K$ points along each ray. The step size is $\delta^{(c)} = 0.5 \times s^{(c)}$, where $s^{(c)}$ is the voxel size [S5].
*   **Free Space Skipping:** Define known free space using threshold $\tau_c = 10^{-3}$. Skip query points where the interpolated density is below $\tau_c$ [S1].
*   **Optimization:**
    *   Iterate for 10,000 steps [S1, S5].
    *   Optimizer: Adam [S5].
    *   Learning Rate: Base LR for voxel grids is 0.1 [S1, S5].
    *   **View-Count Prior:** Apply a lower learning rate to voxels visible to fewer views to avoid redundant voxels allocated for explaining observations from a small number of views [S1, S5].
    *   Loss: Photometric loss $\mathcal{L}_{\text{photo}}$ (defined below) [S5].

#### 3. Fine Detail Reconstruction
*   **Grid:** Use $V^{(f)}$ (resolution $160^3$ or $256^3$) and $V^{(feat)}$ (12 channels) [S1, S5].
*   **Progressive Scaling:** Progressively scale the fine-stage voxel grid at checkpoints 1000, 2000, and 3000 [S1].
*   **Sampling:** Sample $K$ points along each ray. Step size $\delta^{(f)} = 0.5 \times s^{(f)}$ [S5].
*   **Unknown Space Skipping:** Skip low-density query points in unknown space using threshold $\tau_f = 10^{-4}$ [S1].
*   **Optimization:**
    *   Iterate for 20,000 steps [S1, S5].
    *   Optimizer: Adam [S5].
    *   Learning Rate: Base LR for voxel grids is 0.1; Base LR for shallow MLP is $10^{-3}$ [S1, S5].
    *   **View-Count Prior:** Apply lower learning rate to voxels visible to fewer views [S1, S5].
    *   Loss: Photometric loss $\mathcal{L}_{\text{photo}}$ plus auxiliary losses (point-wise RGB loss $w_{pt\_rgb}$ and background loss $w_{bg}$) [S1].
    *   Schedule: Exponential learning rate decay, downscaled by 0.1 at 20,000 iterations [S1].

#### 4. Rendering (Forward Model)
For a ray $\mathbf{r}$, sample $K$ points. For each point $i$:
1.  **Query Density:** Trilinearly interpolate raw density $\sigma_i$ from $V^{(c)}$ or $V^{(f)}$ [S1].
2.  **Post-Activation Interpolation:** Apply activation function (e.g., Softplus/ReLU) *after* trilinear interpolation to produce opacity $\alpha_i$ [S1, S5]. This allows modeling sharp surfaces within a single grid cell [S1].
    $$ \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
    where $\delta_i$ is the distance to the adjacent point [S1, S5].
3.  **Query Color:**
    *   Trilinearly interpolate feature vector $\mathbf{f}_i$ from $V^{(feat)}$ [S1].
    *   Compute positional encodings for position $\mathbf{x}_i$ (using $k_x=5$ frequencies) and viewing direction $\mathbf{d}_i$ (using $k_d=4$ frequencies) [S1].
    *   Pass $[\mathbf{f}_i; \gamma(\mathbf{x}_i); \gamma(\mathbf{d}_i)]$ through the shallow MLP to get color $\mathbf{c}_i$ [S1, S5].
4.  **Accumulate:** Compute transmittance $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$ and rendered color:
    $$ \hat{C}(\mathbf{r}) = \left( \sum_{i=1}^K T_i \alpha_i \mathbf{c}_i \right) + T_{K+1} \mathbf{c}_{\text{bg}} $$
    where $\mathbf{c}_{\text{bg}}$ is a pre-defined background color [S1, S5].

#### 5. Loss Function
Minimize the photometric loss:
$$ \mathcal{L}_{\text{photo}} = \frac{1}{|\mathcal{R}|} \sum_{\mathbf{r} \in \mathcal{R}} \left\| \hat{C}(\mathbf{r}) - C(\mathbf{r}) \right\|_2^2 $$
where $\mathcal{R}$ is the set of rays in a sampled mini-batch (batch size 8,192 rays) [S1, S5].

### Pseudocode

```python
import numpy as np

def dvgo_forward(ray_origin, ray_direction, voxel_grid_density, voxel_grid_feat, 
                 mlp, near_plane, far_plane, num_samples, bg_color):
    """
    Renders a single ray using DVGO representation.
    """
    # Sample points along the ray
    t_vals = np.linspace(near_plane, far_plane, num_samples)
    points = ray_origin + ray_direction * t_vals[:, np.newaxis]
    
    # Query density and apply post-activation interpolation
    # Interpolate raw density first, then apply activation
    raw_densities = trilinear_interpolate(voxel_grid_density, points)
    # Example activation: Softplus or ReLU, followed by alpha calculation
    # Note: DVGO uses 1 - exp(-sigma * delta) where sigma is the activated density
    # For simplicity, assuming raw_densities are already in a form compatible with alpha
    # or that the activation is implicit in the grid storage/query logic described in [S1]
    # The key is: interpolate sigma, then alpha = 1 - exp(-sigma * delta)
    
    alphas = 1.0 - np.exp(-raw_densities * (t_vals[1] - t_vals[0])) # delta is constant step
    
    # Query features and compute color
    features = trilinear_interpolate(voxel_grid_feat, points)
    
    # Positional encoding for position and direction
    pos_enc = positional_encoding(points, num_freqs=5)
    dir_enc = positional_encoding(ray_direction, num_freqs=4)
    
    # MLP input: concat features, pos_enc, dir_enc
    mlp_input = np.concatenate([features, pos_enc, dir_enc], axis=-1)
    colors = mlp_forward(mlp, mlp_input)
    
    # Volume rendering accumulation
    transmittance = np.ones(num_samples + 1)
    for i in range(num_samples - 1, -1, -1):
        transmittance[i] = transmittance[i+1] * (1.0 - alphas[i])
        
    rendered_color = np.zeros(3)
    for i in range(num_samples):
        rendered_color += transmittance[i] * alphas[i] * colors[i]
        
    rendered_color += transmittance[num_samples] * bg_color
    return rendered_color

def dvgo_optimize(images, poses, bbox, coarse_res=100, fine_res=160, 
                  num_coarse_iters=10000, num_fine_iters=20000):
    """
    Optimizes DVGO voxel grids.
    """
    # 1. Initialize grids
    # Initialize density grid with low alpha (10^-6)
    V_coarse = init_density_grid(coarse_res, alpha_init=1e-6)
    V_fine = init_density_grid(fine_res, alpha_init=0.01)
    V_feat = init_feature_grid(fine_res, channels=12)
    mlp = init_shallow_mlp()
    
    # 2. Coarse Stage
    for step in range(num_coarse_iters):
        rays = sample_rays(images, poses, batch_size=8192)
        for ray in rays:
            # Skip points in known free space (density < 1e-3)
            rendered = dvgo_forward(ray, V_coarse, None, mlp, ...) 
            # Note: Coarse stage uses color voxel grid, not MLP, for speed [S3]
            # But for simplicity in pseudocode, we assume a placeholder for coarse color
            loss = photometric_loss(rendered, ray.gt_color)
            # Backpropagate to V_coarse
            # Apply view-count based learning rate prior [S1]
            update(V_coarse, loss, lr=0.1)
            
    # 3. Fine Stage
    # Progressive scaling at checkpoints 1000, 2000, 3000 [S1]
    for step in range(num_fine_iters):
        rays = sample_rays(images, poses, batch_size=8192)
        for ray in rays:
            # Skip points in unknown space (density < 1e-4) [S1]
            rendered = dvgo_forward(ray, V_fine, V_feat, mlp, ...)
            loss = photometric_loss(rendered, ray.gt_color)
            # Backpropagate to V_fine, V_feat, mlp
            # Apply view-count based learning rate prior [S1]
            update(V_fine, loss, lr=0.1)
            update(V_feat, loss, lr=0.1)
            update(mlp, loss, lr=1e-3)
            
        # Exponential LR decay at step 20000 [S1]
        if step == 20000:
            decay_lr(0.1)
            
    return V_fine, V_feat, mlp
```

### Parameters
*   **Grid Resolution:** $160^3$ (default) or $256^3$ [S1, S5].
*   **Coarse Grid Resolution:** $100^3$ [S1, S5].
*   **Initial Alpha (Coarse):** $10^{-6}$ [S1, S5].
*   **Initial Alpha (Fine):** $0.01$ [S1, S5].
*   **Free Space Threshold (Coarse):** $10^{-3}$ [S1].
*   **Unknown Space Threshold (Fine):** $10^{-4}$ [S1].
*   **Sampling Step Size:** $0.5 \times$ voxel size [S5].
*   **Feature Channels:** 12 [S1].
*   **MLP Hidden Layers:** 2 layers, 128 channels [S5].
*   **Positional Encoding Frequencies:** $k_x=5$ (position), $k_d=4$ (direction) [S1].
*   **Optimizer:** Adam [S5].
*   **Learning Rates:** Voxel grids: 0.1; MLP: $10^{-3}$ [S1, S5].
*   **Batch Size:** 8,192 rays [S1, S5].
*   **Training Iterations:** Coarse: 10,000; Fine: 20,000 [S1, S5].

### Edge Cases and Pitfalls
*   **Suboptimal Geometry:** Direct voxel density optimization is prone to allocating "cloud" in free space to fit photometric loss instead of finding multi-view consistent geometry [S1]. Mitigated by low-density initialization and view-count-based learning rates [S1].
*   **Real-World Uncertainty:** Inconsistent lighting or SfM errors can lead to multi-view inconsistent and blurrier surfaces, reducing the advantage of post-activation for sharp surfaces [S1].
*   **Initialization Sensitivity:** Using $\alpha_{\text{init}}^{(c)} = 10^{-7}$ may require more iterations for the coarse stage in some scenes [S1].

## Subtopics

### [Ref-DVGO](6572-ref-dvgo.md)
A reflection-aware variant that combines DVGO's fast hybrid representation with Ref-NeRF's reflection direction reparameterization to handle specular reflections in reflective scenes, reducing GPU memory and training time compared to large spatial MLPs.

## Operating characteristics
*   **Time Complexity:** Training is significantly faster than NeRF. Convergence is about two orders of magnitude faster, reducing training time from 10-20 hours (NeRF) to 15-22 minutes per scene on a single NVIDIA RTX 2080 Ti GPU [S1, S5].
*   **Memory Complexity:** Uses dense voxel grids. A $160^3$ grid contains ~4 million voxels. Memory usage is higher than hash-based methods (like Instant-NGP) but lower than high-resolution NeRF MLPs for equivalent quality [S1].
*   **Rendering Speed:** Approximately 45x faster than NeRF (0.64 seconds vs 29 seconds per 800x800 image) [S1].
*   **Quality:** Achieves PSNR of 31.95 (160^3) and 32.80 (256^3) on standard benchmarks, surpassing NeRF's 31.01 [S1].
*   **Strengths:** Extremely fast training from scratch; no need for cross-scene pre-training; sharp surface modeling via post-activation interpolation [S1].
*   **Limitations:** Not designed for unbounded or forward-facing scenes (inward-facing only); real-world data noise can blur sharp surfaces [S1].
*   **When to Use:** Per-scene novel view synthesis where fast training is critical and the scene is bounded and inward-facing [S1, S5].
*   **When Not to Use:** Large-scale unbounded scenes, forward-facing scenes, or scenarios requiring cross-scene generalization without per-scene optimization [S1].

## Background
Direct Voxel Grid Optimization (DVGO) was introduced by Cheng Sun, Min Sun, and Hwann-Tzong Chen in 2022 [S1]. It addresses the bottleneck of lengthy training times in NeRF by directly optimizing explicit voxel grids, avoiding the need for conversion from implicit models [S1, S5]. The method builds on the principles of radiance-field optimization and explicit voxel representations [Parent]. It has been used on benchmarks such as Syn-NeRF, Syn-NSVF, BlendedMVS, and Tanks and Temples [S1].
