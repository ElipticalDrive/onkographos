# Symmetric Voxel Grid
Also called: Symmetric arrangement, Symmetric feature arrangement

## Overview
The Symmetric Voxel Grid is a feature arrangement strategy for explicit voxel grid decoders that places features symmetrically with respect to the scene center to ensure continuity at region boundaries [S1, S2]. It solves the discontinuity problem inherent in linear feature configurations without the model size overhead of overlapping regions [S1, S2]. While overlapping approaches increase the feature count by $3n^2 + 3n + 1$ in an explicit grid of size $n^3$, the symmetric method maintains a compact grid while forcing neighboring decoders to see identical features at seams [S1, S2].

## How it works
**Inputs and Outputs**
- Input: A scene bounding volume partitioned into a regular grid of regions, each with an associated density decoder [S1, S2].
- Output: A shared 3D voxel grid where features are assigned to vertices such that symmetry constraints are satisfied [S1, S2].

**Data Structures**
- The grid consists of discrete voxels where each vertex holds features accessed by adjacent decoders [S1, S2].
- Let $n$ be the number of subdivisions along one axis, yielding an explicit grid of $n^3$ features [S1, S2].
- The feature dimension at each vertex is set to 32 [S1, S2].

**Steps**
1. **Define Regions**: Partition the scene space into a regular grid of $n \times n \times n$ regions. Each region $e_i$ has an associated decoder $\theta_i$ [S1, S2].
2. **Symmetric Feature Assignment**: Assign features to voxel vertices such that any vertex $v$ on the boundary between two regions $e_1$ and $e_2$ presents the same feature value to both $\theta_1$ and $\theta_2$ [S1, S2]. This is achieved by mirroring feature values across the scene center [S1, S2].
3. **Decoder Initialization**: Initialize all density decoders $\theta_i$ with the same weights to further improve continuity during training [S1, S2].

**Formulas**
- Overhead of alternative overlapping method: The number of additional features required by overlapping regions in an explicit grid of size $n^3$ is:
  $$ \Delta N = 3n^2 + 3n + 1 $$
  This growth reduces the effectiveness of the explicit grid approach [S1, S2].

**Parameters**
- $n$: The number of subdivisions per axis. Not given in the sources.
- Feature dimension: 32 [S1, S2].

**Edge Cases and Pitfalls**
- **Linear Configuration Discontinuity**: Using a simple repeating linear order for features introduces discontinuities at seams because different decoders see different features at the boundary [S1, S2].
- **Model Size Explosion**: Attempting to fix linear discontinuities by overlapping regions increases the model size significantly by $3n^2 + 3n + 1$ features [S1, S2].
- **Pruning Benefits**: The symmetric configuration increases the probability of features being in empty space for all regions, allowing more aggressive pruning and reducing the final stored feature count [S1, S2].

**Pseudocode**
```python
def assign_symmetric_features(grid, n):
    """
    Assigns features to a voxel grid symmetrically with respect to the scene center.
    
    Args:
        grid: 3D array of shape (n, n, n) representing voxel vertices.
        n: Number of subdivisions per axis.
        
    Returns:
        grid: Modified 3D array with symmetric feature assignment.
    """
    for x in range(n):
        for y in range(n):
            for z in range(n):
                # Calculate symmetric counterpart indices relative to grid center
                x_sym = n - 1 - x
                y_sym = n - 1 - y
                z_sym = n - 1 - z
                
                # Ensure symmetry: feature at (x,y,z) must equal feature at (x_sym, y_sym, z_sym)
                if grid[x, y, z] is None:
                    grid[x, y, z] = grid[x_sym, y_sym, z_sym]
                else:
                    grid[x_sym, y_sym, z_sym] = grid[x, y, z]
    return grid

def initialize_decoders(decoders):
    """
    Initializes all density decoders with the same weights.
    
    Args:
        decoders: List of decoder objects.
    """
    # Initialize all density decoders with the same weights to improve continuity during training [S1, S2]
    for decoder in decoders:
        decoder.weights = 0.0
```

## Subtopics

### Linear Configuration
A naive arrangement where features are repeated in the same order for each region [S1, S2]. It introduces discontinuities at seams because different decoders see different features at the boundary [S1, S2]. [Voxel Grid Decoders](2219-voxel-grid-decoders.md)

### Overlapping Regions
An alternative approach where regions overlap to ensure shared features at boundaries [S1, S2]. It increases model size by $3n^2 + 3n + 1$ features compared to non-overlapping grids [S1, S2]. [Voxel Grid Decoders](2219-voxel-grid-decoders.md)

## Operating characteristics
- **Time Complexity**: Not given in the sources.
- **Memory Complexity**: The symmetric arrangement does not increase the number of features needed for seamless reconstruction compared to a non-overlapping grid [S1, S2]. It reduces the number of features stored after pruning because it increases the probability of features being in empty space for all regions [S1, S2].
- **Measured Performance**: The method is described as "very effective to improve the model quality and reduce its size" [S1, S2]. Specific metrics are not provided in the notes.
- **Strengths**: Avoids discontinuities without increasing model size; enables more aggressive pruning; improves training continuity via shared decoder initialization [S1, S2].

## Background
The Symmetric Voxel Grid was introduced in the paper "NeRFLight: Fast and Light Neural Radiance Fields using a Shared Feature Grid" by Rivas-Manzaneque et al. (CVPR 2023) [S1, S2]. It addresses issues in explicit neural field representations where linear feature arrangements cause seams [S1, S2]. The method builds on the concept of shared feature grids but specifically optimizes the spatial arrangement of those features to ensure continuity [S1, S2].
