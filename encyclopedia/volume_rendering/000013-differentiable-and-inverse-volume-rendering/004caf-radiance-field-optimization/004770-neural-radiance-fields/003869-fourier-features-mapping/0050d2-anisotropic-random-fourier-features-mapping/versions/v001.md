# Anisotropic Random Fourier Features Mapping

Also called: Anisotropic Fourier Features, Anisotropic Fourier Features Mapping, Anisotropic RFF Mapping

## Overview
Anisotropic Random Fourier Features Mapping (AFFM) is a feature encoding scheme that employs multiple bandwidths—one per input dimension—to model the heterogeneous frequency characteristics of multidimensional signals, such as plenoptic functions in image-based rendering [S1]. Unlike isotropic methods that treat all coordinates equally and suffer from imbalanced regression or loss of high-frequency details, AFFM allows independent smoothing control for each dimension, enabling the simultaneous capture of high-frequency spatial textures and low-frequency angular variations [S1].

## How it works
**Inputs:**
*   Input coordinate vector $x \in \mathbb{R}^d$.
*   Number of random features $m$.
*   Bandwidth parameters $\alpha = [\alpha_1, \dots, \alpha_d]$, where $\alpha_i > 0$ is the bandwidth for the $i$-th dimension.

**Outputs:**
*   Feature vector $\phi(x) \in \mathbb{R}^m$.

**Data Structures:**
*   **Bandwidth Vector:** A 1D array of size $d$ containing the bandwidth $\alpha_i$ for each dimension.
*   **Frequency Matrix:** A matrix $W \in \mathbb{R}^{m \times d}$ where each row $w_i$ is sampled from a multivariate normal distribution.
*   **Bias Vector:** A vector $b \in \mathbb{R}^m$ with elements sampled uniformly from $[0, 2\pi)$.

**Method Steps:**

1.  **Bandwidth Selection:** Determine the optimal bandwidth $\alpha_i$ for each dimension $i$. The optimal bandwidth is empirically determined by the density of training data and the signal’s frequency spectrum in that dimension [S1]. A large bandwidth corresponds to a dimension where the total curvature (variation) of the signal is small or the number of training points per unit is small [S1].
    *   *Search Algorithm:* To avoid computationally expensive grid searches, use an iterative algorithm based on linear golden-section search (GSS) to automatically search for multiple bandwidth parameters [S1]. This reduces training time from polynomial to logarithmic [S1]. Empirically, 5 iterations are sufficient for convergence [S1].

2.  **Frequency Sampling:** Sample the frequency vectors $w_i \in \mathbb{R}^d$ for $i = 1, \dots, m$ from a multivariate normal distribution. The covariance matrix $\Sigma$ is diagonal, where the $i$-th diagonal entry is $1/\alpha_i^2$ (Note: The source states the diagonal entry is $1/\alpha_i$, but standard Gaussian sampling for RFF with bandwidth $\alpha$ implies variance $\alpha^2$ or standard deviation $\alpha$. The source formula (2) defines $\alpha$ as the reciprocal of the standard deviation of frequencies, i.e., $\sigma = 1/\alpha$. Thus, the variance is $1/\alpha^2$. However, the text explicitly says "covariance is a diagonal matrix whose i-th diagonal entry is $1/\alpha_i$". We follow the explicit text instruction for implementation, noting the potential ambiguity with standard RFF definitions where variance is $\alpha^2$ [S1]).
    *   *Clarification:* The source states: "we sample frequencies $w_i$ from a multivariate normal distribution whose covariance is a diagonal matrix whose i-th diagonal entry is $1/\alpha_i$" [S1]. It also states $\alpha$ is the reciprocal of the standard deviation of frequencies [S1]. If $\alpha_i = 1/\sigma_i$, then $\sigma_i = 1/\alpha_i$ and variance $\sigma_i^2 = 1/\alpha_i^2$. The text's explicit instruction for the covariance diagonal entry is $1/\alpha_i$. We implement the explicit instruction [S1].

3.  **Bias Sampling:** Sample bias terms $b_j \in \mathbb{R}$ for $j = 1, \dots, m$ uniformly from $[0, 2\pi)$ [S1].

4.  **Feature Mapping:** Compute the anisotropic Fourier features $\phi(x)$ using the following formula:
    $$
    \phi(x) := \sqrt{\frac{2}{m}} \begin{bmatrix} \cos(w_1^T x + b_1) \\ \vdots \\ \cos(w_m^T x + b_m) \end{bmatrix}
    $$
    where $w_j^T x = \sum_{k=1}^d w_{j,k} x_k$ [S1].

5.  **Asymptotic Kernel:** As $m \to \infty$, the feature map converges to the Radial Basis Function (RBF) kernel with anisotropic bandwidths:
    $$
    \lim_{m \to \infty} \phi(x)\phi(x_0)^T = \exp\left(-\sum_{i=1}^d \frac{(x_i - x_{0,i})^2}{2\alpha_i^2}\right)
    $$
    where $\alpha_i$ denotes the bandwidth for the $i$-th dimension [S1].

    """
    Generates Anisotropic Random Fourier Features for input x.
    
    Args:
        x: Input coordinate vector of shape (d,).
        m: Number of random features.
        bandwidths: Array of bandwidths alpha_i for each dimension, shape (d,).
        seed: Optional random seed for reproducibility.
        
    Returns:
        phi: Feature vector of shape (m,).
    """
    if seed is not None:
        np.random.seed(seed)
        
    d = len(x)
    
    # Step 1: Sample frequencies from multivariate normal distribution
    # Covariance matrix is diagonal with entries 1/alpha_i as per source text [S1]
    # Note: Source states diagonal entry is 1/alpha_i. 
    # Standard RFF theory often uses variance alpha^2. 
    # We follow the explicit source instruction: covariance diagonal = 1/alpha_i.
    cov_matrix = np.diag(1.0 / bandwidths)
    
    # Sample m frequency vectors w_j from N(0, cov_matrix)
    # Each row w_j is a sample from the multivariate normal distribution
    W = np.random.multivariate_normal(mean=np.zeros(d), cov=cov_matrix, size=m)
    
    # Step 2: Sample biases uniformly from [0, 2*pi)
    b = np.random.uniform(0, 2 * np.pi, size=m)
    
    # Step 3: Compute features
    # phi(x) = sqrt(2/m) * cos(W @ x + b)
    # W is (m, d), x is (d,), so W @ x is (m,)
    projections = np.dot(W, x) + b
    phi = np.sqrt(2.0 / m) * np.cos(projections)
    
    return phi

## Subtopics

### Two-Bandwidth Gaussian Kernel for SLF
*   **What it is:** A specific instantiation of AFFM using two bandwidths for Surface Light Field (SLF) rendering.
*   **Difference:** It assigns one bandwidth to the spatial domain (high-frequency texture) and another to the angular domain (low color variation) [S1].
*   **When to choose:** Use when rendering surfaces where spatial texture varies rapidly but color changes smoothly with viewing angle [S1].
*   **Link:** [Two-Bandwidth Gaussian Kernel](52-two-bandwidth-gaussian-kernel.md)

### Two-Bandwidth Gaussian Kernel for Image-Based Relighting
*   **What it is:** A specific instantiation of AFFM for image-based relighting tasks.
*   **Difference:** It leverages the fact that BRDF reflectance shows more data coherence in the angular domain than in the spatial domain [S1].
*   **When to choose:** Use when regressing continuous reflectance functions $R(\omega, p)$ from discrete images [S1].
*   **Link:** [Two-Bandwidth Gaussian Kernel for Relighting](52-two-bandwidth-gaussian-kernel-relighting.md)

## Operating characteristics
*   **Time Complexity:** The feature mapping itself is $O(m \cdot d)$. The bandwidth search using golden-section search reduces the complexity from polynomial time (brute-force grid search) to logarithmic time [S1].
*   **Memory Complexity:** $O(m \cdot d)$ to store the frequency matrix $W$ and biases $b$ [S1].
*   **Measured Performance:** The method significantly outperforms isotropic Fourier features mapping (IFFM) in preserving fine texture details and smooth view transitions, especially when angular and spatial samples are highly imbalanced [S1]. It achieves visually lossless reconstruction and higher PSNR on strip-like pattern regression tests [S1].
*   **Strengths:** Handles heterogeneity of plenoptic functions across dimensions; avoids over-smoothing or under-smoothing in specific dimensions; efficient bandwidth search [S1].
*   **Limitations:** Requires careful selection or search of bandwidth parameters per dimension; more complex than isotropic methods [S1].
*   **When to use:** Neural image-based rendering and relighting tasks where input dimensions (e.g., spatial vs. angular) have different frequency characteristics [S1].
*   **When not to use:** When the signal is isotropic (similar frequency characteristics across all dimensions) or when computational resources for bandwidth search are extremely limited [S1].

## Background
*   **Origin:** Proposed in the paper "Anisotropic Fourier Features for Neural Image-Based Rendering and Relighting" [S1].
*   **History:** The method addresses limitations of Isotropic Fourier Features Mapping (IFFM) introduced by Tancik et al. (2020) [S1]. IFFM uses a single bandwidth, leading to imbalanced regression for multidimensional signals like plenoptic functions [S1]. The authors analyze the influence of bandwidth via the Neural Tangent Kernel (NTK) and Radial Basis Function (RBF) kernel composition [S1].
*   **Usage:** Applied to neural surface light-field rendering and image-based relighting [S1].
