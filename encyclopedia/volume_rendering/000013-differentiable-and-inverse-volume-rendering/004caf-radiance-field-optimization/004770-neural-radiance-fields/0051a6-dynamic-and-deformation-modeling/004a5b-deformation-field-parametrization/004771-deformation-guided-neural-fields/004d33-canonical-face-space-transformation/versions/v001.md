# Canonical Face Space Transformation

Also called: Canonical face coordinate, Rigid transform

## Overview
Canonical Face Space Transformation normalizes world coordinates to a canonical face space using a rigid transform to address face shape variations between training data and real-world inputs, making the NeRF robust to geometry and pose variations [S1, unofficial]. It sets itself apart from methods that rely on detailed mesh priors or non-rigid deformation fields by using only a rigid alignment derived from a mean geometry, avoiding the need for mesh details during view synthesis [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A point $x$ in the subject’s world coordinate system; viewing direction $\tilde{d}$ in world coordinates.
*   **Output:** A point $x'$ in the face canonical space; color and occlusion values retrieved from the MLP $f_\theta$.
*   **Parameters:** Optimized scale $s_m$, rotation $R_m$, and translation $t_m$ for subject $m$.

**Data Structures:**
*   **Facial Geometry ($F_m$):** Approximate 3D facial mesh for subject $m$, obtained from frontal image using a 3D morphable model and image-based landmark fitting [S1, unofficial].
*   **Mean Geometry ($F$):** Average of all facial geometries in the training dataset [S1, unofficial].
*   **Rigid Transform:** Tuple $(s_m, R_m, t_m)$ where $s_m$ is a scalar, $R_m$ is a $3 \times 3$ rotation matrix, and $t_m$ is a $3 \times 1$ translation vector [S1, unofficial].

**Steps:**
1.  **Compute Subject Geometry:** For each subject $m$ in the training data, compute approximate facial geometry $F_m$ from the frontal image using a 3D morphable model and image-based landmark fitting [S1, unofficial].
2.  **Compute Mean Geometry:** Calculate the mean geometry $F$ by averaging all facial geometries $F_m$ in the dataset [S1, unofficial].
3.  **Optimize Rigid Transform:** Optimize the rigid transform $(s_m, R_m, t_m)$ by minimizing the L2 loss between corresponding vertices of $F_m$ and $F$. This is achieved using SVD decomposition on vertex correspondences [S1, unofficial].
4.  **Warp Coordinates:** During prediction, warp the input coordinate $x$ from world space to canonical space using the optimized transform:
    $$ x' = s_m R_m x + t_m $$
    where $x$ is the point in the subject's world coordinate and $x'$ is the point in the face canonical space [S1, unofficial].
5.  **Query MLP:** Feed the warped coordinate $x'$ and the original viewing direction $\tilde{d}$ (kept in world coordinates) to the MLP network $f_\theta$ to retrieve color and occlusion [S1, unofficial].

**Pseudocode:**
```python
def canonical_face_space_transform(x_world, viewing_direction, subject_id):
    """
    Transforms world coordinates to canonical face space for a specific subject.
    
    Args:

        viewing_direction: numpy array, shape (3,), viewing direction in world coordinate.
        subject_id: int, identifier for the subject to retrieve pre-computed transform.
        
    Returns:
        x_canonical: numpy array, shape (3,), point in face canonical space.
        viewing_direction: numpy array, shape (3,), unchanged viewing direction.
    """
    # Retrieve pre-optimized rigid transform for the subject
    # s_m: scalar scale factor
    # R_m: 3x3 rotation matrix
    # t_m: 3x1 translation vector
    s_m, R_m, t_m = get_subject_transform(subject_id)
    
    # Apply rigid transform: x' = s_m * R_m * x + t_m
    # Note: Matrix multiplication order assumes R_m is applied first, then scaled, then translated.
    # Based on formula x' = sm Rm x + tm
    x_canonical = s_m * (R_m @ x_world) + t_m

    return x_canonical, viewing_direction
```

**Edge Cases and Pitfalls:**
*   The 3D mesh models are used *only* to obtain the rigid transform; mesh details and priors are not required or used in the view synthesis process itself [S1, unofficial].
*   The viewing direction $\tilde{d}$ is kept in the world coordinate and is *not* warped to canonical space [S1, unofficial].

## Subtopics

### Deformation-Guided Neural Fields
The parent method that uses deformation fields MLP guided by a morphable 3D face model. Canonical Face Space Transformation is a specific rigid alignment technique within this family. [Deformation-Guided Neural Fields](12044-deformation-guided-neural-fields.md)

## Operating characteristics
*   **Performance:** Using canonical coordinates yields better quality (higher PSNR/SSIM, lower LPIPS) than using world coordinates, particularly on chin and eyes [S1, unofficial].
    *   World Coordinate: PSNR 24.80, SSIM 0.8167, LPIPS 0.172
    *   Canonical Coordinate: PSNR 24.98, SSIM 0.8178, LPIPS 0.156 [S1, unofficial]
*   **Strengths:** Robust to variation in face geometry and poses in training and testing inputs [S1, unofficial].
*   **Limitations:** Relies on the accuracy of the initial 3D morphable model and landmark fitting to derive the mean geometry and subject geometries [S1, unofficial].

## Background
Canonical Face Space Transformation was introduced in "Portrait Neural Radiance Fields from a Single Image" [S1, unofficial]. It addresses the challenge of rendering novel views of faces from a single frontal image by normalizing geometric variations across different subjects into a shared canonical space, allowing a single pre-trained NeRF model to be fine-tuned for individual subjects.
