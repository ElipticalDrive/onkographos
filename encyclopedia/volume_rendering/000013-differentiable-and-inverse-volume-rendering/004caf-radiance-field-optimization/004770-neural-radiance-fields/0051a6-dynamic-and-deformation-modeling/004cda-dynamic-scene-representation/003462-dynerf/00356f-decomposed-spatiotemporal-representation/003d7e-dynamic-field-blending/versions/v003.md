# Dynamic Field Blending
## Overview
Dynamic Field Blending is a technique for modeling dynamic scenes by blending static and dynamic neural network predictions for opacity and radiance, evaluated via quadrature to compute the final RGB radiance [S1, unofficial]. It addresses the problem of rendering time-varying scenes by decomposing the scene representation into static and dynamic components, allowing the renderer to adaptively mix these components based on a learned blending weight [S1, unofficial]. It sets itself apart from sibling methods in the [Decomposed Spatiotemporal Representation](7525-decomposed-spatiotemporal-representation.md) family by explicitly linearly interpolating the opacity and premultiplied radiance terms rather than using separate volume rendering integrals or hard segmentation masks [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Camera position $\mathbf{x}$, view direction $\boldsymbol{\omega}_0$, time $\tau$, number of samples $N$, sample positions $\mathbf{x}_k$, step size $\Delta \mathbf{x}_k$, static network outputs ($\sigma^{\text{stat}}, L_s^{\text{stat}}$), dynamic network outputs ($\sigma^{\text{dyn}}, L_s^{\text{dyn}}$), and blending weights $b(\mathbf{x}_k, \tau)$ [S1, unofficial].
*   **Output:** Final RGB radiance $I_{\text{RGB}}(\mathbf{x}, \boldsymbol{\omega}_0, \tau)$ [S1, unofficial].

**Data Structures:**
The method relies on the outputs of two neural networks (static and dynamic) and a blending weight field [S1, unofficial].
*   Static Network Output: Volume density $\sigma^{\text{stat}}(\mathbf{x})$ and scattered radiance $L_s^{\text{stat}}(\mathbf{x}, \boldsymbol{\omega}_0)$ [S1, unofficial].
*   Dynamic Network Output: Volume density $\sigma^{\text{dyn}}(\mathbf{x}, \tau)$ and scattered radiance $L_s^{\text{dyn}}(\mathbf{x}, \boldsymbol{\omega}_0, \tau)$ [S1, unofficial].
*   Blending Weight Field: $b(\mathbf{x}, \tau)$, a scalar value indicating the contribution of the dynamic component [S1, unofficial].

**Numbered Steps:**
1.  For each sample point $\mathbf{x}_k$ along the ray (where $\mathbf{x}_k = \mathbf{x} - \boldsymbol{\omega}_0 k$ for $k=0 \dots N$):
    a. Query the static network for $\sigma^{\text{stat}}(\mathbf{x}_k)$ and $L_s^{\text{stat}}(\mathbf{x}_k, \boldsymbol{\omega}_0)$ [S1, unofficial].
    b. Query the dynamic network for $\sigma^{\text{dyn}}(\mathbf{x}_k, \tau)$ and $L_s^{\text{dyn}}(\mathbf{x}_k, \boldsymbol{\omega}_0, \tau)$ [S1, unofficial].
    c. Query the blending weight field for $b(\mathbf{x}_k, \tau)$ [S1, unofficial].
    d. Compute static opacity $\alpha^{\text{stat}}(\mathbf{x}_k)$ using Equation (13) [S1, unofficial].
    e. Compute dynamic opacity $\alpha^{\text{dyn}}(\mathbf{x}_k, \tau)$ using Equation (14) [S1, unofficial].
    f. Compute blended opacity $\alpha^{\text{blend}}(\mathbf{x}_k, \tau)$ using Equation (15) [S1, unofficial].
    g. Compute blended premultiplied radiance $\alpha^{\text{blend}}(\mathbf{x}_k, \tau) L_s^{\text{blend}}(\mathbf{x}_k, \boldsymbol{\omega}_0, \tau)$ using Equations (16) and (17) [S1, unofficial].
2.  Compute blended transmittance $\hat{T}^{\text{blend}}(\mathbf{x}, \mathbf{x}_k, \tau)$ for each sample using Equation (12) [S1, unofficial].
3.  Sum the contributions of all samples to compute the final radiance using Equation (11) [S1, unofficial].

**Formulas:**
*   **Blended Transmittance:**
    $$ \hat{T}^{\text{blend}}(\mathbf{x}, \mathbf{x}_k, \tau) = \prod_{j=0}^{k-1} \left(1 - \alpha^{\text{blend}}(\mathbf{x}_j, \tau)\right) \quad (12) $$
    where $\hat{T}^{\text{blend}}(\mathbf{x}, \mathbf{x}_0, \tau) = 1$ [S1, unofficial].
*   **Static Opacity:**
    $$ \alpha^{\text{stat}}(\mathbf{x}_k) = 1 - \exp(-\sigma^{\text{stat}}(\mathbf{x}_k) \Delta \mathbf{x}_k) \quad (13) $$
*   **Dynamic Opacity:**
    $$ \alpha^{\text{dyn}}(\mathbf{x}_k, \tau) = 1 - \exp(-\sigma^{\text{dyn}}(\mathbf{x}_k, \tau) \Delta \mathbf{x}_k) \quad (14) $$
*   **Blended Opacity:**
    $$ \alpha^{\text{blend}}(\mathbf{x}_k, \tau) = (1 - b(\mathbf{x}_k, \tau)) \cdot \alpha^{\text{stat}}(\mathbf{x}_k) + b(\mathbf{x}_k, \tau) \cdot \alpha^{\text{dyn}}(\mathbf{x}_k, \tau) \quad (15) $$
*   **Blended Premultiplied Radiance:**
    $$ \alpha^{\text{blend}}(\mathbf{x}_k, \tau) L_s^{\text{blend}}(\mathbf{x}_k, \boldsymbol{\omega}_0, \tau) = (1 - b(\mathbf{x}_k, \tau)) \cdot \alpha^{\text{stat}}(\mathbf{x}_k, \tau) L_s^{\text{stat}}(\mathbf{x}_k, \boldsymbol{\omega}_0) + b(\mathbf{x}_k, \tau) \cdot \alpha^{\text{dyn}}(\mathbf{x}_k, \tau) L_s^{\text{dyn}}(\mathbf{x}_k, \boldsymbol{\omega}_0, \tau) \quad (16, 17) $$
    The source explicitly writes $\alpha^{\text{stat}}(\mathbf{x}_k, \tau)$ in Equation (16) despite defining $\alpha^{\text{stat}}$ without time dependence in Equation (13) [S1, unofficial].
*   **Final Radiance:**
    $$ I_{\text{RGB}}(\mathbf{x}, \boldsymbol{\omega}_0, \tau) = \sum_{k=0}^N \hat{T}^{\text{blend}}(\mathbf{x}, \mathbf{x}_k, \tau) \alpha^{\text{blend}}(\mathbf{x}_k, \tau) L_s^{\text{blend}}(\mathbf{x}_k, \boldsymbol{\omega}_0, \tau) \quad (11) $$

**Parameters:**
*   $b(\mathbf{x}_k, \tau)$: The blending weight at position $\mathbf{x}_k$ and time $\tau$, used to linearly interpolate between static and dynamic opacity and radiance terms [S1, unofficial].
*   $N$: Number of samples along the ray. Not given in the sources.
*   $\Delta \mathbf{x}_k$: Step size between samples. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Precision:** The product in the transmittance calculation (Eq 12) can underflow to zero if the scene is dense, leading to numerical instability. Standard volume rendering techniques (e.g., using log-space accumulation) should be applied [G].
*   **Blending Weight Boundaries:** If $b(\mathbf{x}_k, \tau)$ is not constrained to $[0, 1]$, the blending may produce invalid opacity values (e.g., $>1$ or $<0$). The blending weight network should use a sigmoid activation or similar constraint [G].
*   **Temporal Consistency:** The blending weight $b(\mathbf{x}_k, \tau)$ must vary smoothly with time to avoid flickering artifacts. This is typically enforced via temporal regularization during training [G].

**Pseudocode:**
```python
import math

def dynamic_field_blending(ray_origin, ray_direction, time, num_samples, step_size, 
                           static_net, dynamic_net, blending_net):
    """
    Renders a single ray using Dynamic Field Blending.
    
    Args:
        ray_origin: 3D vector, camera position x.
        ray_direction: 3D vector, view direction omega_0.
        time: float, time tau.
        num_samples: int, N.
        step_size: float, Delta x_k.
        static_net: Function returning (sigma_stat, L_stat) for a given position.
        dynamic_net: Function returning (sigma_dyn, L_dyn) for a given position and time.
        blending_net: Function returning blending weight b for a given position and time.
        
    Returns:
        RGB radiance value.
    """
    total_radiance = 0.0
    transmittance = 1.0
    
    for k in range(num_samples + 1):
        # Sample position as defined in the source
        x_k = ray_origin - ray_direction * k
        
        # Query networks
        sigma_stat, L_stat = static_net(x_k)
        sigma_dyn, L_dyn = dynamic_net(x_k, time)
        b = blending_net(x_k, time)
        
        # Compute opacities
        alpha_stat = 1.0 - math.exp(-sigma_stat * step_size)
        alpha_dyn = 1.0 - math.exp(-sigma_dyn * step_size)
        
        # Compute blended opacity
        alpha_blend = (1.0 - b) * alpha_stat + b * alpha_dyn
        
        # Compute blended premultiplied radiance
        # Source explicitly writes alpha_stat(x_k, tau) in Eq 16
        premultiplied_radiance = ((1.0 - b) * alpha_stat * L_stat + 
                                  b * alpha_dyn * L_dyn)
        
        # Accumulate radiance
        total_radiance += transmittance * premultiplied_radiance
        
        # Update transmittance for next sample
        transmittance *= (1.0 - alpha_blend)
        
    return total_radiance
```

## Subtopics

### Static-Dynamic Decomposition
Separates the scene into static and dynamic components [S1, unofficial]. It is chosen when the scene contains both static background and dynamic foreground elements [G].

### Blending Weight Learning
Determines the contribution of static versus dynamic components via a learned scalar field [S1, unofficial]. It is chosen when smooth transitions between static and dynamic regions are required [G].

## Operating characteristics
*   **Time Complexity:** $O(N)$ per ray, where $N$ is the number of samples [S1, unofficial].
*   **Memory Complexity:** Depends on the size of the static, dynamic, and blending networks [G].
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Scales linearly with the number of samples and the complexity of the neural networks [S1, unofficial].
*   **Strengths:** Allows for smooth blending between static and dynamic components, avoiding hard edges [S1, unofficial].
*   **Limitations:** Requires training three networks (static, dynamic, blending) and learning the blending weight [S1, unofficial].
*   **When to Use:** When rendering dynamic scenes with significant static background [S1, unofficial].
*   **When Not to Use:** When the scene is entirely static or entirely dynamic [G].

## Background
Dynamic Field Blending was introduced in the TöRF (Time-of--Flight Radiance Fields) paper [S1, unofficial]. It is part of the DyNeRF family of methods for dynamic scene view synthesis [G]. The method builds on the idea of decomposing the scene into static and dynamic components and blending their contributions [S1, unofficial].
