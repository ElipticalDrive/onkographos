# Unified Neural Implicit Surface and Radiance Field Rendering

Also called: UNISURF, UNISURF rendering, Unified volume/surface rendering

## Overview
UNISURF is a unified framework for 3D reconstruction that combines the geometric precision of implicit surface rendering with the structural learning capabilities of volume rendering, enabling accurate surface reconstruction from multi-view RGB images without requiring per-pixel object masks [S1]. Unlike standard Neural Radiance Fields (NeRF) which rely on hierarchical two-stage sampling to resolve ambiguities, UNISURF eliminates this need by parameterizing occupancy directly via a continuous field and using a decaying sampling interval around the estimated surface [S1].

## How it works
The method unifies surface and volume rendering by replacing the volume density $\sigma$ with a continuous occupancy field $o_\theta$ [S1]. This allows the model to render both through the volume (for coarse structure) and directly on the surface (for geometric precision) [S1].

### Inputs and Outputs
*   **Inputs:** Multi-view RGB images, camera intrinsics and extrinsics. No object masks are required [S1].
*   **Outputs:** A trained occupancy field $o_\theta$, a color field $c_\theta$, and optionally a mesh extracted via MISE [S1].

### Data Structures and Network Architecture
The model consists of two neural networks:
1.  **Occupancy Network ($o_\theta$):** An 8-layer MLP with Softplus activation and hidden dimension 256 [S1]. It maps 3D coordinates $\mathbf{x}$ to occupancy values $o_\theta(\mathbf{x}) \in [0, 1]$ [S1].
    *   **Initialization:** The network is initialized such that the decision boundary (where $o_\theta(\mathbf{x}) = 0.5$) is a sphere [S1].
    *   **Encoding:** 3D locations $\mathbf{x}$ are encoded using Fourier features with $k=6$ octaves [S1].
2.  **Color Network ($c_\theta$):** A 4-layer ReLU MLP [S1]. It maps 3D coordinates, surface normals, geometry features, and viewing direction to color [S1].
    *   **Conditioning:** The color field is conditioned on the surface normal $\mathbf{n}$, a feature vector $\mathbf{h}$ from the geometry network, and the viewing direction $\mathbf{d}$ [S1].
    *   **Encoding:** Viewing directions $\mathbf{d}$ are encoded using Fourier features with $k=4$ octaves [S1].

### Rendering Formulation
The unified rendering equation allows for both volume and surface rendering [S1]:

**Volume Rendering:**
Samples $\{\mathbf{x}_i\}$ are drawn along the ray. The color is computed as:
$$
\hat{C}_v(\mathbf{r}) = \sum_{i=1}^N o_{\theta}(\mathbf{x}_i) \prod_{j < i} (1 - o_{\theta}(\mathbf{x}_j)) c_{\theta}(\mathbf{x}_i, \mathbf{n}_i, \mathbf{h}_i, \mathbf{d})
$$
where $o_\theta$ acts as the alpha value (occupancy indicator) [S1]. For solid objects, this selects the color of the first occupied sample [S1].

**Surface Rendering:**
The surface intersection $\mathbf{x}_s$ is found via root-finding. The color is computed directly:
$$
\hat{C}_s(\mathbf{r}) = c_\theta(\mathbf{x}_s, \mathbf{n}_s, \mathbf{h}_s, \mathbf{d})
$$
Surface rendering is approximately twice as fast as volume rendering [S1].

### Sampling Strategy
The core innovation is a training schedule that gradually decreases the sampling region [S1].

1.  **Surface Intersection ($\mathbf{x}_s$):**
    *   Find the root of $o_\theta(\mathbf{x}) = 0.5$ along the ray $\mathbf{r} = \mathbf{o} + t\mathbf{d}$ [S1].
    *   Use 256 uniformly sampled points along the ray [S1].
    *   Apply the secant method with 8 steps to find the depth $t_s$ [S1].
    *   If no surface intersection is found (ray misses the object), use stratified sampling on the entire ray [S1].

2.  **Volume Sampling Interval:**
    *   Define an interval $[t_s - \Delta, t_s + \Delta]$ centered at the surface depth $t_s$ [S1].
    *   Draw $N=64$ query points inside this interval using stratified sampling:
        $$
        t_i \sim \mathcal{U} \left[ t_s + \left( \frac{2i - 2}{N} - 1 \right) \Delta, t_s + \left( \frac{2i}{N} - 1 \right) \Delta \right]
        $$
    *   Draw 32 additional points in the free space between the camera and the lower bound of the interval ($t_s - \Delta$) to reduce free space artifacts [S1].

3.  **Interval Decay Schedule:**
    *   The interval width $\Delta$ decreases monotonically during training to bootstrap coarse geometry and refine the surface later [S1].
    *   Schedule:
        $$
        \Delta_k = \max(\Delta_{\max} \exp(-k\beta), \Delta_{\min})
        $$
        where $k$ is the iteration number [S1].

### Normal Computation
Surface normals are computed via double backpropagation through the occupancy field [S1]:
$$
\mathbf{n}(\mathbf{x}_s) = \frac{\nabla_{\mathbf{x}_s} o_\theta(\mathbf{x}_s)}{\|\nabla_{\mathbf{x}_s} o_\theta(\mathbf{x}_s)\|_2}
$$
The gradient $\nabla_{\mathbf{x}_s} o_\theta(\mathbf{x}_s)$ is obtained by differentiating the occupancy network output with respect to its input coordinates [S1].

### Loss Function
The total loss combines reconstruction and regularization terms [S1]:
$$
\mathcal{L} = \mathcal{L}_{rec} + \lambda \mathcal{L}_{reg}
$$
1.  **Reconstruction Loss ($\mathcal{L}_{rec}$):** L1 loss between rendered volume color and observed color.
    $$
    \mathcal{L}_{rec} = \sum_{\mathbf{r} \in \mathcal{R}} \|\hat{C}_v(\mathbf{r}) - C(\mathbf{r})\|_1
    $$
2.  **Surface Regularization Loss ($\mathcal{L}_{reg}$):** Encourages normal consistency by comparing the normal at a surface point $\mathbf{x}_s$ with the normal at a perturbed point $\mathbf{x}_s + \boldsymbol{\epsilon}$, where $\boldsymbol{\epsilon}$ is a small random uniform 3D perturbation.
    $$
    \mathcal{L}_{reg} = \sum_{\mathbf{x}_s \in \mathcal{S}} \|\mathbf{n}(\mathbf{x}_s) - \mathbf{n}(\mathbf{x}_s + \boldsymbol{\epsilon})\|_2
    $$

### Optimization Parameters
*   **Optimizer:** Adam, learning rate 0.0001 [S1].
*   **Batch Size:** $M=1024$ pixels per iteration [S1].
*   **Training Duration:** 450k total iterations [S1].
*   **Decay Steps:** Two decay steps occur after 200k and 400k iterations [S1].
*   **Decay Parameters:** $\beta = 1.5 \times 10^{-5}$, $\Delta_{\min} = 0.05$, $\Delta_{\max} = 1.0$ [S1].

### Mesh Extraction
*   Use the Multiresolution IsoSurface Extraction (MISE) algorithm [S1].
*   Initial resolution: $64^3$ [S1].
*   Up-sample in 3 steps without gradient-based refinement [S1].

### Pseudocode

```python
import torch
import torch.nn as nn
import math

class FourierEncoding(nn.Module):
    def __init__(self, num_octaves):
        super().__init__()
        self.num_octaves = num_octaves
        self.frequencies = 2.0 ** torch.linspace(0, num_octaves - 1, num_octaves)
        
    def forward(self, x):
        # x: (..., 3)
        x = x.unsqueeze(-1) * self.frequencies.view(1, 1, 1, -1)
        x = torch.cat([torch.sin(x), torch.cos(x)], dim=-1)
        return x.view(*x.shape[:-2], -1)

class OccupancyMLP(nn.Module):
    def __init__(self, hidden_dim=256, num_layers=8):
        super().__init__()
        layers = []
        for i in range(num_layers):
            layers.append(nn.Linear(hidden_dim if i > 0 else 3, hidden_dim))
            layers.append(nn.Softplus())
        self.net = nn.Sequential(*layers)
        
    def forward(self, x):
        return self.net(x).squeeze(-1)

class ColorMLP(nn.Module):
    def __init__(self, hidden_dim=256, num_layers=4):
        super().__init__()
        layers = []
        for i in range(num_layers):
            layers.append(nn.Linear(hidden_dim if i > 0 else 3, hidden_dim))
            layers.append(nn.ReLU())
        layers.append(nn.Linear(hidden_dim, 3))
        self.net = nn.Sequential(*layers)
        
    def forward(self, x):
        return self.net(x)

class FeatureExtractor(nn.Module):
    def __init__(self, out_dim=64):
        super().__init__()
        self.proj = nn.Linear(256, out_dim)
    def forward(self, x):
        # Extracts a fixed-size feature vector from the geometry network
        return self.proj(x)

class UNISURF:
    def __init__(self, config):
        self.occupancy_net = OccupancyMLP(hidden_dim=256, num_layers=8)
        self.color_net = ColorMLP(hidden_dim=256, num_layers=4)
        self.feature_net = FeatureExtractor(out_dim=64)
        
        self.beta = config['beta']
        self.delta_max = config['delta_max']
        self.delta_min = config['delta_min']
        self.num_samples_interval = 64
        self.num_samples_free = 32
        self.num_root_points = 256
        self.num_secant_steps = 8
        
        self.fourier_x = FourierEncoding(num_octaves=6)
        self.fourier_d = FourierEncoding(num_octaves=4)
        
        self.optimizer = torch.optim.Adam(list(self.occupancy_net.parameters()) + 
                                          list(self.color_net.parameters()) +
                                          list(self.feature_net.parameters()), lr=0.0001)

    def forward(self, rays_o, rays_d, iteration_k):
        M = rays_o.shape[0]
        
        # 1. Find surface intersection via root finding
        t_uniform = torch.linspace(0, 1.0, self.num_root_points).to(rays_o.device)
        t_uniform = t_uniform.unsqueeze(0).expand(M, -1)
        points_uniform = rays_o.unsqueeze(1) + t_uniform.unsqueeze(2) * rays_d.unsqueeze(1)
        
        occ_uniform = self.occupancy_net(self.fourier_x(points_uniform.view(-1, 3))).view(M, -1)
        t_s = self.secant_method(t_uniform, occ_uniform, target=0.5)
        
        # 2. Determine sampling interval
        delta = max(self.delta_max * math.exp(-iteration_k * self.beta), self.delta_min)
        
        # 3. Sample points in interval and free space
        t_interval = self.stratified_sampling(t_s, delta, self.num_samples_interval)
        points_interval = rays_o.unsqueeze(1) + t_interval.unsqueeze(2) * rays_d.unsqueeze(1)
        
        t_free_lower = torch.clamp(t_s - delta, min=0.0)
        t_free = self.stratified_sampling(t_free_lower, t_free_lower, self.num_samples_free)
        points_free = rays_o.unsqueeze(1) + t_free.unsqueeze(2) * rays_d.unsqueeze(1)
        
        t_all = torch.cat([t_free, t_interval], dim=1)
        points_all = torch.cat([points_free, points_interval], dim=1)
        
        # 4. Compute Occupancy and Color
        occ_all = self.occupancy_net(self.fourier_x(points_all.view(-1, 3))).view(M, -1, 1)
        
        points_all_flat = points_all.view(-1, 3)
        points_all_flat.requires_grad_(True)
        occ_all_flat = self.occupancy_net(self.fourier_x(points_all_flat)).view(M, -1)
        
        grad_occ = torch.autograd.grad(occ_all_flat.sum(), points_all_flat, create_graph=True)[0]
        grad_occ = grad_occ.view(M, -1, 3)
        normals = grad_occ / (grad_occ.norm(dim=2, keepdim=True) + 1e-8)
        
        h_all = self.feature_net(self.occupancy_net(self.fourier_x(points_all.view(-1, 3)))).view(M, -1, 64)
        
        d_encoded = self.fourier_d(rays_d.unsqueeze(1).expand(-1, points_all.shape[1], -1))
        
        points_all_flat = points_all.view(-1, 3)
        normals_flat = normals.view(-1, 3)
        h_all_flat = h_all.view(-1, 64)
        d_all_flat = d_encoded.view(-1, d_encoded.shape[-1])
        
        x_encoded = self.fourier_x(points_all_flat)
        color_input = torch.cat([x_encoded, normals_flat, h_all_flat, d_all_flat], dim=-1)
        colors = self.color_net(color_input).view(M, -1, 3)
        
        # 5. Volume Rendering
        alphas = occ_all.squeeze(-1)
        one_minus_alpha = 1.0 - alphas
        T = torch.cumprod(one_minus_alpha, dim=1)
        T = torch.cat([torch.ones(M, 1).to(T.device), T[:, :-1]], dim=1)
        
        weights = alphas * T
        C_v = torch.sum(weights.unsqueeze(2) * colors, dim=1)
        
        return C_v

    def secant_method(self, t, occ, target=0.5, num_steps=8):
        # Vectorized secant method for batched rays
        # t: (M, N), occ: (M, N)
        t_s = torch.zeros(t.shape[0], device=t.device)
        for m in range(t.shape[0]):
            # Find bracket where sign changes relative to target
            diff = occ[m] - target
            idx = torch.where(diff[:-1] * diff[1:] < 0)[0]
            if len(idx) == 0:
                t_s[m] = t[m, -1] # Fallback
                continue
            idx = idx[0].item()
            t0, t1 = t[m, idx], t[m, idx+1]
            f0, f1 = diff[idx], diff[idx+1]
            for _ in range(num_steps):
                if abs(f1 - f0) < 1e-8:
                    break
                t_new = t1 - f1 * (t1 - t0) / (f1 - f0)
                t0, f0 = t1, f1
                t1 = t_new
                f1 = self.occupancy_net(self.fourier_x(torch.cat([t1.unsqueeze(0)*rays_d[m], rays_o[m]]))) - target # Simplified for demo
            t_s[m] = t1
        return t_s

    def stratified_sampling(self, t_center, delta, N):
        # t_center: (M,), delta: scalar or (M,)
        # Returns: (M, N)
        lower = t_center - delta
        upper = t_center + delta
        w = (upper - lower) / N
        i = torch.arange(N).to(t_center.device)
        u = torch.rand_like(t_center).unsqueeze(1)
        t_samples = lower.unsqueeze(1) + (2*i - 1) * w.unsqueeze(0) + u * w.unsqueeze(0)
        return t_samples

    def compute_loss(self, C_v, C_obs, x_s, eps=1e-3):
        L_rec = torch.mean(torch.abs(C_v - C_obs))
        
        # Compute normals at surface points
        x_s.requires_grad_(True)
        occ_s = self.occupancy_net(self.fourier_x(x_s))
        grad_s = torch.autograd.grad(occ_s.sum(), x_s, create_graph=True)[0]
        n_s = grad_s / (grad_s.norm(dim=1, keepdim=True) + 1e-8)
        
        # Perturb and compute normals
        x_s_pert = x_s + torch.rand_like(x_s) * eps
        occ_s_pert = self.occupancy_net(self.fourier_x(x_s_pert))
        grad_s_pert = torch.autograd.grad(occ_s_pert.sum(), x_s_pert, create_graph=True)[0]
        n_s_pert = grad_s_pert / (grad_s_pert.norm(dim=1, keepdim=True) + 1e-8)
        
        L_reg = torch.mean((n_s - n_s_pert).norm(dim=1))
        return L_rec + 0.1 * L_reg
```

## Operating characteristics
*   **Time Complexity:** Surface rendering is twice as fast as volume rendering [S1]. The elimination of hierarchical two-stage sampling (required by NeRF) reduces computational overhead during inference [S1].
*   **Memory Complexity:** Not explicitly given in the sources.
*   **Performance:** On the DTU MVS dataset, UNISURF performs nearly on par with state-of-the-art implicit neural reconstruction methods like IDR, which use strong mask supervision, despite not using masks [S1].
*   **Strengths:** Does not require per-pixel object masks [S1]. Combines coarse geometry learning (volume) with precise surface refinement (surface) [S1]. Faster inference via surface rendering [S1].
*   **Limitations:** Requires careful tuning of the decay schedule parameters ($\beta, \Delta_{max}, \Delta_{min}$) [S1]. Initialization as a sphere is required [S1]. Free space artifacts can occur if not handled by the free-space sampling strategy [S1].

## Background
The publication year and author details are not given in the sources. The method builds on the principles of Neural Radiance Fields (NeRF) and implicit surface representations like those used in IDR [S1]. It addresses the limitation of surface rendering techniques that require input masks and the ambiguity of volume rendering techniques that do not optimize implicit surfaces directly [S1].
