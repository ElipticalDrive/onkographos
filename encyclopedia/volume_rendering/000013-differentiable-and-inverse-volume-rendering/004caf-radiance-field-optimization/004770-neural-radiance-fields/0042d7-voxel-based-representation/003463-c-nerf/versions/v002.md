# C-NeRF

Also called: Volume Basis

## Overview
C-NeRF is a voxel-based radiance field representation that uses a 3D convolutional neural network to generate feature volumes, which are then decoded by a NeRF-like multi-layer perceptron (MLP) to predict density and color [S2]. It serves as a baseline for dynamic scene representation by combining the spatial efficiency of voxel grids with the expressive power of neural networks [S1]. Unlike standard NeRF which uses a single shared MLP for all spatial locations, C-NeRF decouples feature extraction from radiance prediction, allowing for more localized detail capture, though it still tends to lose high-frequency details compared to methods using dynamic or decomposed representations [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D spatial coordinates $\mathbf{x} = (x, y, z)$ and viewing direction $\mathbf{d} = (d_x, d_y, d_z)$.
*   **Output:** Density $\sigma$ and view-dependent color $\mathbf{c}$.

**Data Structures:**
1.  **3D Feature Volume:** A 3D grid of tensors. Each cell at grid position $(i, j, k)$ contains a feature vector $\mathbf{f}_{ijk}$. The resolution of this volume is a hyperparameter.
2.  **MLP Decoder:** A standard MLP that takes the concatenated feature vector and viewing direction as input.

**Algorithm:**
1.  **Feature Extraction:** For a given 3D point $\mathbf{x}$, trilinearly interpolate the feature vector $\mathbf{f}$ from the 3D feature volume. Let the grid resolution be $R \times R \times R$. The feature vector $\mathbf{f}$ has dimension $D_f$.
2.  **Feature Concatenation:** Concatenate the interpolated feature vector $\mathbf{f}$ with the viewing direction $\mathbf{d}$ (projected to a fixed dimension if necessary, or directly if dimensions match) to form the input vector $\mathbf{v} = [\mathbf{f}; \mathbf{d}]$.
3.  **Radiance Prediction:** Pass $\mathbf{v}$ through the MLP decoder.
    *   The MLP consists of several fully connected layers with ReLU activations.
    *   The final layer outputs two values: density $\sigma$ and color $\mathbf{c}$.
    *   $\sigma$ is typically passed through a softplus or exponential activation to ensure positivity.
    *   $\mathbf{c}$ is passed through a sigmoid activation to bound values to $[0, 1]$.

**Formulas:**
The rendering equation remains the standard volume rendering equation [S1][S5]:
$$
\hat{C}(\mathbf{r}) = \sum_{i=1}^N T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i
$$
where $\sigma_i$ and $\mathbf{c}_i$ are obtained from the C-NeRF model at sample point $i$ along ray $\mathbf{r}$.

**Parameters:**
*   **Grid Resolution ($R$):** The resolution of the 3D feature volume. Typical values range from 16 to 96 depending on the scene complexity and memory constraints [S1].
*   **Feature Dimension ($D_f$):** The size of the feature vector stored in each voxel. Not explicitly given in sources, but implied by the MLP input size.
*   **MLP Architecture:** Not explicitly detailed in sources, but typically consists of 2-4 hidden layers with 256-512 units [S2].

**Edge Cases and Pitfalls:**
*   **High-Frequency Loss:** C-NeRF tends to lose details in high-frequency regions of the image due to its single shared MLP structure for decoding features [S2].
*   **Memory Usage:** The 3D feature volume scales with $R^3$. High resolutions can lead to significant memory consumption.
*   **Interpolation Artifacts:** Trilinear interpolation may introduce blurring compared to nearest-neighbor or higher-order interpolation methods.

**Pseudocode:**
```python
def c_nerf_forward(xyz, direction, feature_volume, mlp_decoder):
    """
    Forward pass for C-NeRF.
    
    Args:
        xyz: Tensor of shape (N, 3) containing 3D coordinates.
        direction: Tensor of shape (N, 3) containing viewing directions.
        feature_volume: 3D Tensor of shape (R, R, R, D_f) containing feature vectors.
        mlp_decoder: A function representing the MLP decoder.
        
    Returns:
        sigma: Tensor of shape (N,) containing density values.
        color: Tensor of shape (N, 3) containing color values.
    """
    # Normalize coordinates to [-1, 1] if not already done
    xyz_normalized = normalize_coordinates(xyz)
    
    # Trilinear interpolation to get feature vectors
    # Assuming feature_volume is indexed by grid coordinates
    # This step requires mapping xyz_normalized to grid indices and interpolating
    features = trilinear_interpolate(feature_volume, xyz_normalized)
    
    # Concatenate features with direction
    # Direction might need to be projected or embedded if dimensions don't match
    input_vector = concatenate(features, direction)
    
    # Pass through MLP decoder
    sigma, color = mlp_decoder(input_vector)
    
    # Ensure positivity for sigma
    sigma = softplus(sigma)
    
    # Ensure color is in [0, 1]
    color = sigmoid(color)
    
    return sigma, color
```

## Subtopics

### [MVSNeRF](11941-mvsnerf.md)
MVSNeRF is a method for fast, generalizable radiance field reconstruction from multi-view stereo that bypasses per-scene optimization by learning a data prior. It extracts 2D image features, maps them to a 3D voxelized cost volume via plane sweeping, and uses a pretrained 3D CNN to generate a 3D neural encoding volume. Unlike its parent C-NeRF, which uses a 3D CNN to produce feature volumes and appends a NeRF-like MLP, MVSNeRF constructs perspective frustum volumes for small-baseline rendering and jointly optimizes the 3D feature volume and the NeRF MLP during inference.

## Operating characteristics
*   **Time Complexity:** The feature extraction step is $O(N)$ where $N$ is the number of samples. The MLP decoding is also $O(N)$. The overall complexity is linear with respect to the number of samples.
*   **Memory Complexity:** The memory usage is dominated by the 3D feature volume, which is $O(R^3 \cdot D_f)$. This is significantly less than storing a full 3D grid of radiance values but more than a simple MLP-based NeRF which has $O(1)$ memory (excluding weights).
*   **Performance:** On the D-NeRF dataset with $R=24$, C-NeRF (referred to as Volume Basis in [S1]) achieves a PSNR of 30.329, SSIM of 0.962, and LPIPS of 0.051, with a training time of 14 minutes and 36 seconds [S1].
*   **Strengths:** Combines the spatial locality of voxel-based methods with the flexibility of neural networks. More efficient than pure MLP-based NeRF for high-resolution scenes.
*   **Limitations:** Loses high-frequency details compared to more advanced dynamic representations [S2]. Memory usage scales cubically with grid resolution.
*   **When to Use:** Suitable for static or slowly changing scenes where high-frequency detail is not critical, and memory efficiency is a concern compared to pure MLP methods.
*   **When Not to Use:** For dynamic scenes with complex motions or high-frequency details, methods like HexPlane or MVSNeRF may be more appropriate [S1][S2].

## Background
C-NeRF was introduced as a follow-up to Neural Volumes [S2]. Neural Volumes used a 3D deconvolutional network to produce RGB-Alpha volumes, which resulted in blurry results due to low volume resolution [S2]. C-NeRF improved upon this by using a 3D CNN to produce feature volumes and appending a NeRF-like MLP to predict radiance fields [S2]. It is often used as a baseline for comparing new dynamic scene representations, such as HexPlane and Dynamic MLP Maps [S1][S2]. The method is part of the broader effort to make neural radiance fields more efficient and scalable for dynamic scenes.
