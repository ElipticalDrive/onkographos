# RenderNet

Also called: RenderNet: A deep convolutional network for differentiable rendering from 3D shapes

## Overview
RenderNet is a differentiable rendering convolutional neural network that generates 2D images from 3D voxel grids by jointly learning visibility computation and pixel color calculation (shading) [S1, unofficial]. Unlike traditional rasterization or ray tracing which rely on discrete, non-differentiable operations like z-buffering, RenderNet uses a CNN to encode spatial occlusion and shading automatically [S1, unofficial]. It is distinguished from sibling methods like [FastNeRF](7183-fastnerf.md) and [VoxGRAF](12633-voxgraf.md) by its explicit use of a "Projection Unit" that collapses the 3D depth dimension into 2D feature maps while learning visibility, rather than relying on continuous volume rendering equations or sparse voxel structures [S1, unofficial]. It handles low-resolution or noisy voxel inputs more robustly than mesh-based differentiable renderers [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D voxel grid $V$ of dimensions $H_V \times W_V \times D_V \times C_V$ (height, width, depth, channel) [S1, unofficial]. Typical input resolution is $64 \times 64 \times 64 \times 1$ [S1, unofficial].
*   **Parameters:** Camera pose (azimuth $\theta$, elevation $\phi$, distance $R$) and lighting parameters (light direction $\tilde{l}$, ambient constant $a$) [S1, unofficial].
*   **Output:** A 2D RGB image $I$ of dimensions $H_I \times W_I \times C_I$ (height, width, channel) [S1, unofficial]. Typical output resolution is $512 \times 512 \times 3$ [S1, unofficial].

**Data Structures:**
The core data structure is a 4D tensor representing the voxel grid. During the projection phase, this is transformed into a "squeezed" 3D tensor $V'$ with dimensions $W \times H \times (D \cdot C)$ [S1, unofficial].

**Algorithm Steps:**

1.  **Coordinate Transformation:**
    Apply a rigid-body transformation to the input voxel grid $V$ to convert from world coordinates to camera coordinates. The camera is assumed to be axis-aligned, looking along the negative z-axis of the volumetric grid [S1, unofficial]. The transformation is parameterized by:
    *   Rotation around the y-axis (azimuth).
    *   Rotation around the z-axis (elevation).
    *   Distance $R$ (scaling factor determining object distance from camera) [S1, unofficial].
    The input grid is embedded into a larger grid to prevent clipping after rotation [S1, unofficial].

2.  **Trilinear Sampling:**
    Trilinearly sample the transformed voxel grid to retrieve feature values at query points [S1, unofficial]. This ensures differentiability with respect to the transformation parameters [S1, unofficial].

3.  **3D Feature Encoding:**
    Pass the sampled features through a sequence of 3D convolutions and PReLU activations to encode geometry [S1, unofficial]. The specific architecture described is:
    *   Conv3d
    *   PReLU
    *   Conv3d
    *   PReLU
    *   PReLU
    *   Down-conv3d [S1, unofficial]

4.  **Projection Unit (Visibility & Projection):**
    This is the core component that bridges 3D input and 2D output, learning visibility along the depth dimension [S1, unofficial].
    *   **Reshaping:** Collapse the depth dimension $D$ and channel dimension $C$ of the encoded features to map the 4D tensor to a 3D squeezed tensor $V'$ with dimensions $W \times H \times (D \cdot C)$ [S1, unofficial].
    *   **MLP via 1x1 Convolution:** Apply a Multilayer Perceptron (MLP) implemented as a $1 \times 1$ convolution on each $(D \cdot C)$ vector of the squeezed tensor. This allows the network to learn complex structures within the local receptive field and determine visibility of different parts of the 3D input along the depth axis, unlike max pooling which only creates a silhouette map [S1, unofficial].
    *   **Formula:** The projection unit produces a 3D tensor with $K$ channels. For pixel coordinates $(i, j)$ and image channel $k$:
        $$ I_{i,j,k} = \sum_{d_c} w_{k, d_c} \cdot V'_{i,j, d_c} + b_k $$
        where $d_c$ iterates over the squeezed depth-channel dimension, $w$ are weights, and $b$ are biases [S1, unofficial].

5.  **2D Shading and Rendering:**
    Apply 2D convolutions and PReLU activations to the projected features to generate the final RGB image [S1, unofficial]. The sequence is:
    *   Conv2d
    *   PReLU
    *   Conv2d
    *   PReLU
    *   Up-conv2d
    *   PReLU
    *   PReLU
    *   Up-conv2d [S1, unofficial]
    
    Optionally, the network can output a Normal Map. If Phong illumination is used, the final image $I$ is calculated as $I = A \cdot S$, where $A$ is the albedo map and $S$ is the shading factor $S = \max(0, \tilde{l} \cdot \tilde{n} + a)$, with $\tilde{n}$ being the normal vector from the normal map [S1, unofficial].

**Pseudocode:**

import torch
import torch.nn as nn
import torch.nn.functional as F

class RenderNet(nn.Module):
    def __init__(self, input_res=64, output_res=512, hidden_channels=16):
        super(RenderNet, self).__init__()
        # 3D Encoder
        self.conv3d_1 = nn.Conv3d(1, 16, kernel_size=3, padding=1)
        self.conv3d_2 = nn.Conv3d(16, 32, kernel_size=3, padding=1)
        self.conv3d_3 = nn.Conv3d(32, 64, kernel_size=3, padding=1)
        self.conv3d_down = nn.Conv3d(64, 128, kernel_size=3, stride=2, padding=1)
        
        # Projection Unit: 1x1 Conv acts as MLP on squeezed dimensions
        # Input to projection: W x H x (D * C_in)
        # Output: W x H x K
        self.projection_conv = nn.Conv2d(128 * input_res, 512, kernel_size=1)
        
        # 2D Decoder
        self.conv2d_1 = nn.Conv2d(512, 256, kernel_size=3, padding=1)
        self.conv2d_2 = nn.Conv2d(256, 128, kernel_size=3, padding=1)
        self.upconv2d_1 = nn.ConvTranspose2d(128, 64, kernel_size=4, stride=2, padding=1)
        self.upconv2d_2 = nn.ConvTranspose2d(64, 3, kernel_size=4, stride=2, padding=1)
        
        self.prelu = nn.PReLU()

    def forward(self, voxel_grid, azimuth, elevation, distance, light_dir, ambient_const):
        """
        voxel_grid: (B, 1, H, W, D)
        azimuth, elevation, distance: scalar or tensor for camera pose
        light_dir: (B, 3)
        ambient_const: scalar
        """
        # Step 1 & 2: Rigid Body Transformation and Trilinear Sampling
        # Note: In a full implementation, this involves creating a grid of coordinates
        # and using grid_sample with trilinear interpolation.
        # Here we assume a function `transform_and_sample` exists that handles
        # the rotation/translation/scaling and trilinear sampling.
        sampled_features = transform_and_sample(voxel_grid, azimuth, elevation, distance)
        
        # Step 3: 3D Feature Encoding
        x = self.prelu(self.conv3d_1(sampled_features))
        x = self.prelu(self.conv3d_2(x))
        x = self.prelu(self.conv3d_3(x))
        x = self.conv3d_down(x) # (B, 128, H/2, W/2, D/2)
        
        # Step 4: Projection Unit
        # Reshape: Collapse depth and channel dimensions
        B, C, H, W, D = x.shape
        # Squeeze to (B, C*D, H, W)
        x_squeezed = x.view(B, C * D, H, W)
        
        # Apply 1x1 Conv (MLP) to learn visibility and project to 2D features
        # Output: (B, 512, H, W)
        x_proj = self.projection_conv(x_squeezed)
        
        # Step 5: 2D Shading and Rendering
        x = self.prelu(self.conv2d_1(x_proj))
        x = self.prelu(self.conv2d_2(x))
        x = self.prelu(self.upconv2d_1(x))
        x = self.prelu(self.upconv2d_1(x)) # Note: Source lists two PReLUs before second UpConv
        x = self.upconv2d_2(x)
        
        # If Phong shading is required, the network might output Albedo and Normal maps
        # and combine them externally. For direct RGB output, this is the final tensor.
        return x

**Training:**
*   **Loss:** Pixel-space regression loss. Mean Squared Error (MSE) for colored images, Binary Cross Entropy for grayscale images [S1, unofficial].
*   **Optimizer:** Adam with learning rate $0.00001$ [S1, unofficial].
*   **Patch Training:** Train on random spatially cropped samples (width/height) keeping depth/channel intact. Patch size starts at $1/8$ of the full grid and increases to $1/2$ at the end of training. Full-sized grid is used only during inference [S1, unofficial].

**Inverse Rendering (Shape Reconstruction):**
To reconstruct shape from a single image, minimize the reconstruction loss:
$$ \min_{z, \theta, \phi, \eta} \| I - f(z, \theta, \phi, \eta) \|^2 $$
where $I$ is the observed image, $f$ is the pre-trained RenderNet, $z$ is the shape, $\theta/\eta$ are pose/lighting, and $\phi$ is texture [S1, unofficial].
*   **Pitfall:** Direct minimization leads to noisy, unstable results [S1, unofficial].
*   **Solution:** Use a shape prior (pre-trained 3D auto-encoder) to regularize. Optimize the latent representation $z'$ instead of $z$ directly:
    $$ \min_{z', \theta, \phi', \eta} \| I - f(g(z'), \theta, h(\phi'), \eta) \|^2 $$
    where $g$ is the decoder of the 3D auto-encoder and $h$ is the texture decoder [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not explicitly given in the sources. The use of 3D and 2D convolutions suggests complexity proportional to the number of voxels and output pixels.
*   **Memory Complexity:** Not explicitly given. The method uses a dense voxel grid ($64^3$), which is memory-intensive compared to sparse representations, though the source notes that computers are becoming more powerful and octrees can address inefficiency [S1, unofficial].
*   **Performance:** On the Phong-shaded chair dataset, RenderNet achieved a PSNR of 25.39. For comparison, EC model scored 22.37 and EC-Deep Phong scored 27.43 [S1, unofficial].
*   **Strengths:**
    *   Handles occlusion and complex shaders (ambient occlusion, cartoon shading) without explicit geometric visibility tests [S1, unofficial].
    *   Robust to erroneous, low-resolution, or noisy voxel inputs, unlike mesh renderers [S1, unofficial].
    *   Generalizes well to unseen categories (e.g., trained on chairs, renders Stanford Bunny) [S1, unofficial].
*   **Limitations:**
    *   Requires training data (rendered images from voxel grids) [S1, unofficial].
    *   Direct inverse rendering (shape reconstruction) is unstable without a shape prior [S1, unofficial].
    *   Perspective camera views are not explicitly incorporated in the basic architecture, though 3D convolutions allow for some morphing [S1, unofficial].

## Background
RenderNet was introduced by Thu Nguyen-Phuoc, Chuan Li, Stephen Balaban, and Yong-Liang Yang from the University of Bath and Lambda Labs [S1, unofficial]. The paper, titled "RenderNet: A deep convolutional network for differentiable rendering from 3D shapes," was published on arXiv in April 2019 (v3) [S1, unofficial]. It addresses the challenge of inverse rendering by providing a differentiable renderer that learns visibility and shading, overcoming the non-differentiability of traditional discrete operations like z-buffering [S1, unofficial].
