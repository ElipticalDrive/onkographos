# DeRF (Decomposed Radiance Fields)
Also called: Decomposed Radiance Fields

## Overview
DeRF mitigates the high computational cost of neural volume rendering by spatially decomposing a scene into multiple parts, each represented by a smaller neural network, allowing for near-constant inference time regardless of the number of parts [S1]. It addresses the diminishing returns in rendering quality when scaling network capacity by using multiple smaller networks instead of one large network, providing up to 3× more efficient inference than [Neural Radiance Fields](4972-neural-radiance-fields.md) with the same quality, or up to 1.0 dB PSNR improvement for the same cost [S1].

## How it works
DeRF builds on [Radiance-field optimization](44-radiance-field-optimization.md) by replacing the single global network with a set of $N$ local networks, activated via a differentiable spatial partition [S1].

**Inputs and Outputs:**
*   **Inputs:** Camera ray $\mathbf{r}$, number of decomposition parts $N$, Voronoi sites $\phi \in \mathbb{R}^{N \times 3}$, temperature $\beta$, and network weights $\theta = \{\theta_n\}_{n=1}^N$ [S1].
*   **Outputs:** Rendered color $\hat{C}(\mathbf{r})$ and gradients for optimization [S1].

**Data Structures:**
*   **Voronoi Sites ($\phi$):** A tensor of shape $(N, 3)$ storing the 3D coordinates of the $N$ Voronoi centers [S1].
*   **Network Heads ($\theta_n$):** $N$ pairs of neural networks $(\sigma_{\theta_n}, \mathbf{c}_{\theta_n})$ [S1]. Each network takes a 3D position $\mathbf{x}$ (and direction $\mathbf{d}$ for color) and outputs density and color [S1].
*   **Weights ($w_{\phi_n}(\mathbf{x})$):** Computed on-the-fly using the soft Voronoi formula [S1].

**Formulas:**
The radiance field functions $\sigma(\mathbf{x})$ and $\mathbf{c}(\mathbf{x}, \mathbf{d})$ are modeled as a weighted sum of $N$ separate functions [S1]:

$$
\sigma(\mathbf{x}) = \sum_{n=1}^{N} w_{\phi_n}(\mathbf{x}) \sigma_{\theta_n}(\mathbf{x})
$$

$$
\mathbf{c}(\mathbf{x}, \mathbf{d}) = \sum_{n=1}^{N} w_{\phi_n}(\mathbf{x}) \mathbf{c}_{\theta_n}(\mathbf{x}, \mathbf{d})
$$

The soft Voronoi weight $w_{\phi_n}(\mathbf{x})$ is computed using a softmax over squared distances to Voronoi sites $\phi$ [S1]:

$$
w_{\phi_n}(\mathbf{x}) = \frac{\exp(-\beta \|\mathbf{x} - \phi_n\|^2)}{\sum_{j=1}^{N} \exp(-\beta \|\mathbf{x} - \phi_j\|^2)}
$$

where $\beta > 0$ is a temperature parameter controlling the softness of the Voronoi approximation [S1]. As $\beta \to \infty$, the weights approach a hard partition where only one $w_{\phi_n}(\mathbf{x})$ is non-zero [S1].

**Parameters:**
*   $N$: Number of neural network heads. Typical values depend on scene complexity; the paper uses $N=16$ for experiments [S1].
*   $\beta$: Temperature parameter. Scheduled from a low value to a high value during training to transition from soft to hard partitioning [S1].

**Algorithm Steps:**
1.  **Pre-training:** Train coarse global networks $\sigma_{\text{coarse}}$ and $\mathbf{c}_{\text{coarse}}$ for the entire scene for approximately 100k iterations [S1].
2.  **Decomposition Optimization:** Optimize the coarse network weights $\theta_{\text{coarse}}$ and Voronoi sites $\phi$ separately [S1]. Minimize reconstruction loss $\mathcal{L}_{\text{radiance}}$ for $\theta_{\text{coarse}}$ and uniformity loss $\mathcal{L}_{\text{uniform}}$ for $\phi$ [S1].
    *   The uniformity loss is defined as $\mathcal{L}_{\text{uniform}} = \|\mathbb{E}_{\mathbf{r} \sim \mathcal{R}}[W_{\phi}(\mathbf{r})]\|_2^2$, where $W_{\phi}(\mathbf{r}) \in \mathbb{R}^N$ is the vector of soft Voronoi weights for points sampled along ray $\mathbf{r}$ [S1]. This encourages equal usage of all heads [S1].
    *   *Pitfall:* Do not allow $\mathcal{L}_{\text{uniform}}$ to affect the optimization of $\theta_{\text{coarse}}$, as it inhibits the density network's ability to learn scene structure [S1].
3.  **Local Network Training:** Fix $\phi$ and train the per-decomposition networks $\sigma_{\theta_n}$ and $\mathbf{c}_{\theta_n}$ using only $\mathcal{L}_{\text{radiance}}$ [S1].
4.  **Inference:** For a given ray $\mathbf{r}$, sample points $\mathbf{x}_i$ [S1]. Compute $w_{\phi_n}(\mathbf{x}_i)$ for all $n$ [S1]. Identify the index $n^*$ with the maximum weight to evaluate only the corresponding head $\sigma_{\theta_{n^*}}$ and $\mathbf{c}_{\theta_{n^*}}$, leveraging the Painter's Algorithm for compositing [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn

class DeRFHead(nn.Module):
    def __init__(self, hidden_dim):
        super().__init__()
        self.net_density = nn.Sequential(
            nn.Linear(3, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, 1)
        )
        self.net_color = nn.Sequential(
            nn.Linear(6, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, 3)
        )

    def forward(self, x, d):
        sigma = self.net_density(x)
        c = self.net_color(torch.cat([x, d], dim=-1))
        return sigma, c

class DeRF:
    def __init__(self, N, hidden_dim, beta_init=1.0, beta_final=1000.0):
        self.N = N
        self.beta_init = beta_init
        self.beta = beta_init
        self.beta_final = beta_final
        self.heads = nn.ModuleList([DeRFHead(hidden_dim) for _ in range(N)])
        self.phi = nn.Parameter(torch.randn(N, 3) * 10.0)
        self.coarse_sigma = nn.Linear(3, 1)
        self.coarse_color = nn.Linear(6, 3)

    def compute_weights(self, x):
        dists = torch.cdist(x, self.phi, p=2) ** 2
        return torch.softmax(-self.beta * dists, dim=-1)

    def forward(self, x, d, inference=False):
        weights = self.compute_weights(x)
        if inference:
            idx = torch.argmax(weights, dim=-1)
            sigma_n, c_n = self.heads[idx](x, d)
            return sigma_n, c_n
        else:
            sigma_sum = torch.zeros_like(x[:, :1])
            c_sum = torch.zeros_like(x[:, :3])
            for n in range(self.N):
                sigma_n, c_n = self.heads[n](x, d)
                w_n = weights[:, n:n+1]
                sigma_sum += w_n * sigma_n
                c_sum += w_n * c_n
            return sigma_sum, c_sum

    def schedule_beta(self, step, total_steps):
        self.beta = self.beta_init + (self.beta_final - self.beta_init) * (step / total_steps)
```

## Subtopics

### DeRF Training Schedule
A specific training protocol to stabilize the decomposition and local network training [S1].
1.  **Pre-train coarse networks:** Train $\sigma_{\text{coarse}}$ and $\mathbf{c}_{\text{coarse}}$ for the entire scene for ≈100k iterations [S1].
2.  **Separate Optimization:** Optimize $\theta_{\text{coarse}}$ and $\phi$ separately. Minimize $\mathcal{L}_{\text{radiance}}$ for $\theta_{\text{coarse}}$ and $\mathcal{L}_{\text{uniform}}$ for $\phi$ [S1].
3.  **Local Training:** Fix $\phi$ and train $\sigma_{\theta_n}$ and $\mathbf{c}_{\theta_n}$ using $\mathcal{L}_{\text{radiance}}$ only [S1].
*   **Pitfall:** Allowing $\mathcal{L}_{\text{uniform}}$ to affect $\theta_{\text{coarse}}$ inhibits density learning and causes instability [S1].

## Operating characteristics
*   **Time Complexity:** Near-constant inference time with respect to the number of decomposed parts $N$, as only one head is evaluated per point during inference [S1].
*   **Memory Complexity:** Lower than NeRF for equivalent quality, as smaller networks are used [S1].
*   **Performance:** Up to 3× more efficient inference than NeRF with the same rendering quality, or up to 1.0 dB PSNR improvement for the same inference cost on real-world scenes [S1].
*   **Strengths:** Mitigates diminishing returns of network capacity; compatible with Painter's Algorithm for GPU-friendly rendering [S1].
*   **Limitations:** Requires careful scheduling of $\beta$ and training phases; random decomposition is not appropriate due to memory access patterns [S1].

## Background
DeRF was proposed by Daniel Rebain, Wei Jiang, Soroosh Yazdani, Ke Li, Kwang Moo Yi, and Andrea Tagliasacchi from the University of British Columbia, University of Toronto, Simon Fraser University, and Google Research [S1]. It was published in arXiv:2011.12490v1 on 25 Nov 2020 and later in CVPR 2021 [S1]. The method addresses the computational intensity of NeRF by leveraging the observation that there are diminishing returns in employing larger networks, proposing spatial decomposition with smaller networks instead [S1].
