# GAN Training Procedure

Also called: Min-Max Game Training

## Overview
Generative Adversarial Networks (GANs) train a generator against a discriminator to produce perceptually realistic outputs rather than merely minimizing pixelwise error [S3, unofficial]. This perceptual advantage makes GANs well-suited for volume super-resolution, where Mean Squared Error (MSE)-optimized outputs tend toward oversmoothing [S3, unofficial]. The method solves the problem of generating high-fidelity volumetric visualizations by replacing explicit volume data with a computational process that maps viewpoints and transfer functions directly to images [Parent].

## How it works
The procedure consists of two neural networks: a generator that produces increasingly realistic images and a discriminator that distinguishes real images from generated ones, trained in a competitive framework [S4].

**Inputs and Outputs**
*   **Inputs:** Real images (ground truth), visualization parameters (e.g., viewpoint, transfer function), and optionally an opacity image (for translation GANs) [S2].
*   **Outputs:** Synthesized images from the generator; real/fake classification probabilities from the discriminator [S2][S3, unofficial].

**Data Structures**
*   **Generator ($G$):** Neural network mapping visualization parameters to image space [S2][S3, unofficial].
*   **Discriminator ($D$):** Neural network mapping image space to a scalar probability of being real [S2][S3, unofficial].
*   **Training Data:** Generated by performing volume rendering over a wide range of viewpoints and transfer functions (TFs) [S2]. For each instance, the viewpoint is randomly generated, and the opacity TF is sampled from a Gaussian Mixture Model (GMM) with 1 to 5 modes, each having a random mean, standard deviation, and amplitude relative to the scalar field range [S2].

**Algorithm Steps**
The GAN optimizes a min-max game using minibatch stochastic gradient descent [S2]. The parameters are updated iteratively from the computed gradients [S2]. The training loop alternates gradient descent steps for the discriminator and the generator [S2]:

1.  **Discriminator Update (Real):** Update discriminator parameters using a batch of real images and visualization parameters to minimize binary cross-entropy loss, encouraging the discriminator to predict these images as real [S2].
2.  **Synthesis:** Pass visualization parameters (and opacity image, if applicable) through the generator to synthesize images [S2].
3.  **Discriminator Update (Fake):** Update the discriminator to encourage a prediction of false for the synthesized images [S2].
4.  **Generator Update:** Update the generator’s parameters by tricking the discriminator, encouraging it to predict the synthesized images as being real [S2].

**Pseudocode**

```python
def train_gan(generator, discriminator, real_images, viz_params, opacity_images, 
              num_epochs, batch_size, lr, beta1, beta2, epsilon):
    """
    Trains a GAN using alternating gradient descent.
    """
    # Helper: Binary Cross-Entropy Loss
    def binary_cross_entropy(predictions, targets):
        predictions = max(min(predictions, 1.0 - 1e-7), 1e-7)
        return -mean(targets * log(predictions) + (1 - targets) * log(1 - predictions))

    # Helper: Adam Optimizer State and Step
    m_state = {}
    v_state = {}
    step_count = 0
    def adam_step(params):
        nonlocal step_count
        step_count += 1
        for p in params:
            if p not in m_state:
                m_state[p] = zeros_like(p)
                v_state[p] = zeros_like(p)
            m_state[p] = beta1 * m_state[p] + (1 - beta1) * gradients[p]
            v_state[p] = beta2 * v_state[p] + (1 - beta2) * gradients[p]**2
            m_hat = m_state[p] / (1 - beta1**step_count)
            v_hat = v_state[p] / (1 - beta2**step_count)
            p -= lr * m_hat / (sqrt(v_hat) + epsilon)

    for epoch in range(num_epochs):
        for i in range(0, len(real_images), batch_size):
            batch_real = real_images[i:i+batch_size]
            batch_viz = viz_params[i:i+batch_size]
            batch_opacity = opacity_images[i:i+batch_size] if opacity_images else None

            # --- Discriminator Update ---
            # 1. Train on real images
            pred_real = discriminator(batch_real)
            loss_D_real = binary_cross_entropy(pred_real, target=1.0)
            gradients = ∇_params(loss_D_real, discriminator.parameters()) # Backpropagation [S2]
            adam_step(discriminator.parameters())

            # 2. Synthesize fake images
            if batch_opacity is not None:
                fake_images = generator(batch_viz, batch_opacity)
            else:
                fake_images = generator(batch_viz)

            # 3. Train on fake images
            pred_fake = discriminator(fake_images.detach())
            loss_D_fake = binary_cross_entropy(pred_fake, target=0.0)
            gradients = ∇_params(loss_D_fake, discriminator.parameters())
            adam_step(discriminator.parameters())

            # --- Generator Update ---
            # 4. Update generator by tricking discriminator
            if batch_opacity is not None:
                fake_images = generator(batch_viz, batch_opacity)
            else:
                fake_images = generator(batch_viz)
            
            pred_fake_for_G = discriminator(fake_images)
            loss_G = binary_cross_entropy(pred_fake_for_G, target=1.0)
            gradients = ∇_params(loss_G, generator.parameters())
            adam_step(generator.parameters())
```

**Parameters**
*   **Optimizer:** ADAM [S2, S4].
*   **ADAM Hyperparameters:** $\epsilon = 10^{-8}$, $\beta_1 = 0.9$, $\beta_2 = 0.999$ [S5].
*   **L1 Loss Weight ($\lambda$):** In practice, $\lambda = 150$ preserves color and stabilizes training without overly blurring generated images [S2].

**Edge Cases and Pitfalls**
*   **Lack of 3D Shape Information:** Most current GAN-based image synthesis methods do not provide 3D shape information [S2].
*   **Limited Explicit Control:** They do not allow for explicit control of camera parameters such as the viewpoint and for fine control over the scene materials or lighting conditions [S2].
*   **Data Generation Constraints:** Randomly generated TFs from GMMs must cover the relevant scalar field range to ensure the training dataset adequately represents the target distribution [S2].

## Subtopics

### [Progressive GAN Discriminator](10312-progressive-gan-discriminator.md)
A convolutional discriminator that grows progressively in resolution to stabilize training and allow larger batch sizes at lower resolutions. It solves the instability inherent in training high-resolution GANs by starting with coarse shapes and gradually introducing fine details. Unlike standard ProgressiveGAN where the generator architecture grows, this variant keeps the generator fixed, increasing resolution by sampling rays more densely from the same implicit representation.

### Adversarial Loss for Ocean Geometry
Uses spatial discriminators for normal and roughness maps, and temporal discriminators for temporal coherence, to enforce that inferred data spatial distribution is similar to real data [S5]. The overall loss is defined as:
$$ L_{Total} = \alpha L_{Image} + \beta_1 L_{Dn} + \beta_2 L_{Dr} + \gamma_1 L_{Dtn} + \gamma_2 L_{Dtr} $$
where $\alpha, \beta_1, \beta_2, \gamma_1, \gamma_2$ are weights, and $L_{Dn}, L_{Dr}, L_{Dtn}, L_{Dtr}$ are the losses of the corresponding discriminators [S5]. Training involves alternating training of the four auxiliary discriminators and the generator, as typically done for GAN training [S5]. Sub-net1 and sub-net2 are trained together using $L_{Total}$ for 200 epochs [S5].

## Background
Generative Adversarial Networks (GANs) [81] and diffusion models [82] have emerged as pivotal techniques for generating and modifying high-quality images [S4]. GANs consist of two neural networks trained in a competitive framework [S4]. They have demonstrated effectiveness for a variety of tasks, including super-resolution, style transfer, and image-to-image translation [S4]. In the context of volume rendering, GANs are used to bypass explicit volume data, mapping viewpoints and transfer functions directly to images [Parent].
