# Deconvolutional Neural Network for Tomographic Reconstruction
Also called: Inverse CNN, Transposed Convolution Network

## Overview
This method reconstructs a 2D plasma radiation profile (image) from 1D line-integrated bolometer measurements (vector) by acting as the logical inverse of a standard Convolutional Neural Network (CNN) [S1]. Unlike traditional algebraic reconstruction techniques that explicitly invert the line-integral forward model, this approach learns the inverse mapping directly from data, enabling full-pulse reconstruction in seconds rather than days [S1]. It differs from sibling methods like [Neural Radiance Fields](13341-neural-radiance-fields-and-implicit-neural-representations.md) by operating on explicit 2D image outputs from 1D sensor inputs rather than implicit continuous fields, and from [Stretched Sinograms](18225-stretched-sinograms-for-neural-tomographic-reconstruction.md) by using a direct CNN-inversion architecture rather than sinogram manipulation.

## How it works
**Inputs and Outputs:**
*   **Input:** A 1D vector of $N=56$ bolometer measurements [S1].
*   **Output:** A 2D image of size $200 \times 120$ representing the plasma radiation profile [S1].

**Data Structures:**
The network consists of dense layers, a reshape operation, transposed convolutional layers, and a final convolutional layer [S1].
1.  **Dense Layers:** Two fully connected layers, each with 7500 nodes [S1].
2.  **Reshape:** The output of the second dense layer is reshaped into a 3D tensor of size $25 \times 15 \times 20$ [S1]. This is interpreted as 20 feature maps, each of spatial size $25 \times 15$ [S1].
3.  **Transposed Convolutions:** A series of transposed convolutional layers that upsample the feature maps [S1].
4.  **Final Convolution:** A standard convolutional layer with stride 1 [S1].

**Algorithm Steps:**
1.  **Input Processing:** The 56-element input vector is passed through the first dense layer (7500 nodes) [S1].
2.  **Hidden Representation:** The output of the first dense layer is passed through the second dense layer (7500 nodes) [S1].
3.  **Reshaping:** The 7500-element output vector is reshaped into a 3D tensor of shape $(25, 15, 20)$ [S1].
4.  **Upsampling:** A series of transposed convolutions are applied to the feature maps. Each transposed convolution uses a stride of 2 pixels to double the height and width of the feature maps [S1]. This process upsamples the feature maps from $25 \times 15$ to $200 \times 120$ [S1].
5.  **Output Generation:** A final convolutional layer with a stride of 1 is applied to the upsampled feature maps to generate the $200 \times 120$ output image [S1].

**Formulas:**
The transposed convolution is defined as the inverse of the standard convolution. If a sliding window is applied to the output of the transposed convolution, the result is the feature map given as input [S1]. Mathematically, learning a transposed convolution is equivalent to learning a weight matrix that is the transpose of a regular convolution weight matrix [S1].

**Parameters:**
*   **Upsampling Stride:** 2 pixels for all transposed convolutional layers [S1].
*   **Final Convolution Stride:** 1 [S1].
*   **Learning Rate:** $10^{-4}$ [S1].
*   **Batch Size:** 411 [S1].
*   **Optimizer:** Adaptive gradient descent algorithm [S1].
*   **Training Data:** 21,783 sample tomograms (90% of 24,203 total) [S1].
*   **Validation Data:** 2,420 sample tomograms (10% of 24,203 total) [S1].

### [Deep Learning for Plasma Tomography](19607-deep-learning-for-plasma-tomography.md)
Reconstructs a 3D plasma emissivity volume from 2D bolometer projection data using a fully convolutional neural network trained end-to-end. It differs from traditional algebraic reconstruction techniques by learning the inverse mapping directly from data, bypassing the explicit inversion of the line-integral forward model.

## Operating characteristics
*   **Time Complexity:** The method provides a large computational speedup compared to iterative constrained optimization methods. Full-pulse reconstruction (6000 reconstructions) takes seconds instead of 250 days [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:**
    *   **Hardware:** Nvidia Titan X GPU [S1].
    *   **Training Duration:** 60 hours (12,652 epochs) to reach minimum validation error at epoch 6,911 [S1].
    *   **Minimum Validation Error:** ~10 kW m$^{-3}$ (pixel-wise mean absolute error) [S1].
    *   **Quality Metrics (Validation Set):** Mean SSIM 0.9573, Mean PSNR 33.791, Mean NRMSE 0.0678 [S1].
*   **Scaling:** The network was trained on a wide range of pulses from 80000 (Aug. 2011) to 92504 (Nov. 2016), demonstrating robustness to potential bolometer system degradation over 5 years [S1].
*   **Strengths:** High accuracy with significant computational speedup; enables detailed time evolution analysis of radiation profiles; no data preprocessing required [S1].
*   **Limitations:** Prone to overfitting if training is not stopped early (e.g., at epoch 6911) [S1].

## Background
*   **Origin:** Based on previous work [14] which used deconvolutional networks with convolution+upsampling layers [S1]. This work improved the architecture by replacing those with proper transposed convolutions and removing data preprocessing requirements [S1].
*   **History:** The method was developed for the JET tokamak to analyze time evolution of radiation profiles during disruptions and impurity transport [S1]. It leverages the success of CNNs in image processing by inverting the typical CNN structure (input image, output vector) to suit tomography (input vector, output image) [S1].
