# Stretched Sinograms for Neural Tomographic Reconstruction

Also called: Stretched Sinograms

## Overview
Stretched Sinograms is a direct reconstruction method for limited-angle electron tomography that preprocesses tilt views by stretching them perpendicular to the tilt axis by a factor of $\sec(\theta)$, then feeds the stretched views into a 2-D U-Net to directly output a 3-D reconstruction, avoiding backprojection [S1, unofficial]. It differs from sibling methods like [Neural Radiance Fields and Implicit Neural Representations](13341-neural-radiance-fields-and-implicit-neural-representations.md) by operating on explicit 2-D image channels rather than implicit continuous fields, and from [Deep Learning and Neural Architectures](8282-deep-learning-and-neural-architectures.md) by incorporating a geometric preprocessing step (stretching) specifically designed to compensate for the missing wedge in limited-angle tomography before the neural network processes the data [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3-D tensor of 2-D tilt views $y \in \mathbb{R}^{n_{\text{view}} \times n_h \times n_w}$, assumed to be log-normalized and related to the object density via the Radon transform [S1, unofficial]. The views cover a limited angular range $(-\theta, +\theta)$ where $\theta < 90^\circ$ [S1, unofficial].
*   **Output:** A 3-D reconstruction volume $\hat{x} \in \mathbb{R}^{n_d \times n_h \times n_w}$ [S1, unofficial].

**Data Structures:**
*   **Tilt View Tensor ($y$):** Shape $(n_{\text{view}}, n_h, n_w)$ [S1, unofficial].
*   **Stretched Sinogram ($y_{\text{stretched}}$):** Shape $(n_{\text{view}}, n_h, n_w)$ [S1, unofficial].
*   **U-Net Input:** Treated as a 2-D image with $n_{\text{view}}$ input channels [S1, unofficial].
*   **U-Net Output:** Treated as a 2-D image where the channel dimension corresponds to the depth dimension $n_d$ of the output volume [S1, unofficial].

**Parameters:**
*   $n_{\text{view}}$: Number of tilt views [S1, unofficial].
*   $n_h, n_w$: Height and width of each tilt view [S1, unofficial].
*   $\theta$: Maximum tilt angle in the range $(-\theta, +\theta)$ [S1, unofficial].
*   $n_d$: Depth of the output volume [S1, unofficial].
*   $n_{\text{pixel}} = n_d \times n_h \times n_w$: Total number of pixels in the output reconstruction [S1, unofficial].
*   Optimizer: Adam with learning rate $0.001$ [S1, unofficial].
*   Normalization: Instance Normalization before every ReLU layer [S1, unofficial].

**Steps:**
1.  **Stretching:** For each tilt view $y(\theta, \cdot, \cdot)$, stretch the image in the direction perpendicular to the tilt axis by a factor of $\sec(\theta)$. The image size $(n_h \times n_w)$ is preserved. Bilinear interpolation is used, treating the center of each image as the origin [S1, unofficial].
2.  **Coordinate Transformation:** If the tilt axis is parallel to the $\hat{y}$ axis (stretching along $\hat{x}$), the stretched view is computed as:
    $$ y_{\text{stretched}}(\theta, i, j) = y(\theta, i, j \sec \theta) $$
    where $i, j$ are natural coordinates indexing rows and columns, with $(-1, -1)$ at the upper left and $(+1, +1)$ at the bottom right [S1, unofficial].
3.  **Matrix Formulation:** The stretching operation can be represented as a sparse linear operator $S$ such that $y_{\text{stretched}} = Sy$, mapping the raw views tensor to the stretched views tensor [S1, unofficial].
4.  **Network Input Preparation:** Treat the stretched sinogram $y_{\text{stretched}}$ as a 2-D image with $K = n_{\text{view}}$ input channels [S1, unofficial].
5.  **Neural Reconstruction:** Pass the stretched sinogram through a 2-D U-Net architecture $f_\omega$ [S1, unofficial].
6.  **Volume Assembly:** Treat the output channel dimension of the U-Net as the depth dimension of the output volume $\hat{x}$ [S1, unofficial].
7.  **Training:** Train the network using stochastic gradient descent on the Mean Squared Error (MSE) objective:
    $$ l(\omega) = \frac{1}{2 n_{\text{pixel}}} \| x - f_\omega(Sy) \|^2 $$
    where $x$ is the ground truth volume [S1, unofficial].
8.  **Optimization:** Use the Adam optimizer with a step-size of $0.001$ [S1, unofficial]. Use early stopping based on validation set error to select the network for test-set evaluation [S1, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

def stretch_sinogram(y, theta):
    """
    Stretches each tilt view in the sinogram by sec(theta) perpendicular to the tilt axis.
    
    Args:
        y: Tensor of shape (n_view, n_h, n_w). Log-normalized tilt views.
        theta: Maximum tilt angle in radians.
        
    Returns:
        y_stretched: Tensor of shape (n_view, n_h, n_w).
    """
    n_view, n_h, n_w = y.shape
    stretch_factor = 1.0 / torch.cos(torch.tensor(theta))
    
    # Create coordinate grids in natural coordinates (-1 to 1)
    # i corresponds to rows (height), j corresponds to columns (width)
    i_coords = torch.linspace(-1, 1, n_h, device=y.device)
    j_coords = torch.linspace(-1, 1, n_w, device=y.device)
    
    # Create meshgrid: I is (n_h, n_w), J is (n_h, n_w)
    I, J = torch.meshgrid(i_coords, j_coords, indexing='ij')
    
    # Stretch along the x-axis (columns/j) assuming tilt axis is parallel to y-axis
    # Formula: y_stretched(theta, i, j) = y(theta, i, j * sec(theta))
    # We map output grid coordinates back to input grid coordinates
    J_input = J * stretch_factor
    
    # Stack coordinates for grid_sample: (N, H, W, 2)
    # grid_sample expects coordinates in [-1, 1] as (x, y) -> (col, row)
    grid = torch.stack((J_input, I), dim=-1)
    
    # Expand y to have a batch dimension for grid_sample if necessary, 
    # or process per view. grid_sample works on (N, C, H, W).
    # Here, each view is a separate sample in a batch for grid_sample, 
    # or reshape to (n_view, 1, n_h, n_w).
    y_reshaped = y.unsqueeze(1) # (n_view, 1, n_h, n_w)
    
    # Perform bilinear interpolation
    # grid_sample requires grid of shape (N, H, W, 2)
    # We need to broadcast grid to match n_view views
    grid_expanded = grid.unsqueeze(0).expand(n_view, -1, -1, -1)
    
    y_stretched_reshaped = F.grid_sample(
        y_reshaped, 
        grid_expanded, 
        mode='bilinear', 
        padding_mode='zeros', 
        align_corners=True
    )
    
    # Remove channel dimension: (n_view, n_h, n_w)
    y_stretched = y_stretched_reshaped.squeeze(1)
    
    return y_stretched

class StretchedSinogramReconstructor(nn.Module):
    def __init__(self, n_view, n_d, n_h, n_w):
        super(StretchedSinogramReconstructor, self).__init__()
        # 2-D U-Net architecture
        # Input channels: n_view (number of tilt views)
        # Output channels: n_d (depth of the volume)
        self.unet = UNet2D(in_channels=n_view, out_channels=n_d)
        
    def forward(self, y, theta):
        """
        Reconstructs 3D volume from stretched sinogram.
        
        Args:
            y: Tensor of shape (n_view, n_h, n_w)
            theta: Maximum tilt angle in radians
            
        Returns:
            x_hat: Tensor of shape (n_d, n_h, n_w)
        """
        # Step 1: Stretch the sinogram
        y_stretched = stretch_sinogram(y, theta)
        
        # Step 2: Pass through U-Net
        # U-Net expects input shape (N, C_in, H, W). 
        # We treat the batch dimension as 1, and channels as n_view.
        # y_stretched is (n_view, n_h, n_w). Reshape to (1, n_view, n_h, n_w).
        y_stretched_batch = y_stretched.unsqueeze(0)
        
        # U-Net output shape: (1, n_d, n_h, n_w)
        unet_output = self.unet(y_stretched_batch)
        
        # Step 3: Extract volume
        # Remove batch dimension: (n_d, n_h, n_w)
        x_hat = unet_output.squeeze(0)
        
        return x_hat

class UNet2D(nn.Module):
    """
    Simplified 2-D U-Net with Instance Normalization before ReLU.
    Note: Exact U-Net architecture from paper appendix omitted; standard 2D U-Net provided [G].
    """
    def __init__(self, in_channels, out_channels):
        super(UNet2D, self).__init__()
        # Encoder
        self.enc1 = self._block(in_channels, 64)
        self.enc2 = self._block(64, 128)
        self.enc3 = self._block(128, 256)
        self.enc4 = self._block(256, 512)
        
        self.pool = nn.MaxPool2d(2)
        
        # Bottleneck
        self.bottleneck = self._block(512, 1024)
        
        # Decoder
        self.up4 = nn.ConvTranspose2d(1024, 512, 2, stride=2)
        self.dec4 = self._block(1024, 512)
        self.up3 = nn.ConvTranspose2d(512, 256, 2, stride=2)
        self.dec3 = self._block(512, 256)
        self.up2 = nn.ConvTranspose2d(256, 128, 2, stride=2)
        self.dec2 = self._block(256, 128)
        self.up1 = nn.ConvTranspose2d(128, 64, 2, stride=2)
        self.dec1 = self._block(128, 64)
        
        self.final = nn.Conv2d(64, out_channels, 1)
        
    def _block(self, in_channels, out_channels):
        return nn.Sequential(
            nn.Conv2d(in_channels, out_channels, 3, padding=1),
            nn.InstanceNorm2d(out_channels),
            nn.ReLU(inplace=True),
            nn.Conv2d(out_channels, out_channels, 3, padding=1),
            nn.InstanceNorm2d(out_channels),
            nn.ReLU(inplace=True)
        )
        
    def forward(self, x):
        # Encoder
        e1 = self.enc1(x)
        e2 = self.enc2(self.pool(e1))
        e3 = self.enc3(self.pool(e2))
        e4 = self.enc4(self.pool(e3))
        
        # Bottleneck
        b = self.bottleneck(self.pool(e4))
        
        # Decoder
        d4 = self.dec4(torch.cat([self.up4(b), e4], dim=1))
        d3 = self.dec3(torch.cat([self.up3(d4), e3], dim=1))
        d2 = self.dec2(torch.cat([self.up2(d3), e2], dim=1))
        d1 = self.dec1(torch.cat([self.up1(d2), e1], dim=1))
        
        return self.final(d1)

def train_stretched_sinogram(model, y, x_gt, theta, optimizer, n_pixel):
    """
    Training step for Stretched Sinogram reconstruction.
    
    Args:
        model: StretchedSinogramReconstructor instance
        y: Input tilt views tensor (n_view, n_h, n_w)
        x_gt: Ground truth volume tensor (n_d, n_h, n_w)
        theta: Maximum tilt angle
        optimizer: Adam optimizer
        n_pixel: Number of pixels in output volume (n_d * n_h * n_w)
    """
    optimizer.zero_grad()
    
    # Forward pass
    x_hat = model(y, theta)
    
    # Compute MSE loss
    loss = (1.0 / (2.0 * n_pixel)) * torch.sum((x_gt - x_hat) ** 2)
    
    # Backward pass
    loss.backward()
    optimizer.step()
    
    return loss.item()
```

**Edge Cases and Pitfalls:**
*   **Normalization:** Using Batch Normalization instead of Instance Normalization results in significantly higher test time error, likely because the U-Nets are trained with a batch size of 1 [S1, unofficial].
*   **Tilt Axis Orientation:** The formula $y_{\text{stretched}}(\theta, i, j) = y(\theta, i, j \sec \theta)$ assumes the tilt axis is parallel to the $\hat{y}$ axis (stretching along $\hat{x}$). For arbitrary tilt axes, the formula must be adjusted to stretch along a linear combination of $i$ and $j$ [S1, unofficial].
*   **Limited Angle:** The method is designed for limited-angle tomography where $\theta < 90^\circ$. The stretching compensates for the missing wedge but may introduce artifacts if the angle is too large or if the assumption of parallel beam geometry is violated [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources [S1, unofficial].
*   **Memory Complexity:** Not given in the sources [S1, unofficial].
*   **Measured Performance:** The method was evaluated on a 992×1000×1000 test set volume extracted from FIB-SEM images of fly brain tissue, broken into 124 non-overlapping patches of size 32×512×512 [S1, unofficial]. Inference and backpropagation were performed on a single ASUS RTX3090 Turbo 24GB GPU [S1, unofficial]. Forward/backward projections for comparison methods were distributed across 64 CPUs [S1, unofficial].
*   **Scaling:** Not given in the sources [S1, unofficial].
*   **Strengths:** Direct reconstruction without explicit backprojection; handles limited-angle tomography effectively; avoids artifacts associated with traditional FBP in limited-angle scenarios [S1, unofficial].
*   **Limitations:** Requires paired training data (tilt views and ground truth volumes); performance depends on the quality of the U-Net architecture and training; limited to parallel beam geometry assumptions [S1, unofficial].
*   **When to use:** Limited-angle electron tomography where traditional methods like FBP suffer from severe artifacts due to the missing wedge [S1, unofficial].
*   **When not to use:** Full-angle tomography (where FBP is sufficient and faster); non-parallel beam geometries without modification [S1, unofficial].

## Background
*   **Origin:** Proposed by Kyle Luther and H. Sebastian Seung from the Princeton Neuroscience Institute and Princeton Computer Science Department [S1, unofficial].
*   **Paper:** "Stretched sinograms for limited-angle tomographic reconstruction with neural networks" (arXiv:2306.10201v1, 16 Jun 2023) [S1, unofficial].
*   **History and Development:** The method builds on the idea of using convolutional neural networks for tomographic reconstruction, specifically addressing the limitations of limited-angle data by geometrically preprocessing the sinogram before neural processing [S1, unofficial].
*   **Usage:** Demonstrated on simulated tilt views from 3-D images of fly brain tissue acquired with Focused Ion Beam Scanning Electron Microscopy (FIB-SEM) [S1, unofficial].
