# Multi-View Feature Encoder

Also called: MuRF Feature Encoder

## Overview
The Multi-View Feature Encoder aggregates information from $K$ input images to construct a target volume that encodes appearance and geometry for subsequent radiance field prediction [S1]. It sets itself apart by combining a per-image 2D CNN with a joint multi-view Transformer to extract features, then explicitly quantifying multi-view consistency via pairwise cosine similarities to provide geometric cues for volume density prediction [S1]. This approach alleviates multi-view inconsistency and models 3D context more efficiently than full 3D CNNs [S1].

## How it works
**Inputs:** $K$ input images $\{I_k\}_{k=1}^K$.
**Outputs:** A target volume $z \in \mathbb{R}^{\frac{H}{8} \times \frac{W}{8} \times D \times C}$, where $H, W$ are image dimensions, $D$ is depth, and $C$ is the channel dimension [S1].

**Data Structures:**
1.  **Feature Maps:** Extracted at 1/8 resolution. Dimensions: $K \times \frac{H}{8} \times \frac{W}{8} \times M$, where $M$ is the feature dimension [S1].
2.  **Cosine Similarity Matrix:** Computed in parallel. A $K \times M$ matrix of normalized features is multiplied by its transpose. The upper triangle is extracted to obtain all $K(K-1)/2$ pairwise similarities [S1].
3.  **Volume:** $z \in \mathbb{R}^{\frac{H}{8} \times \frac{W}{8} \times D \times C}$ [S1].

**Steps:**

1.  **2D CNN Feature Extraction:**
    For each input image $I_k$, pass it through a weight-sharing 2D CNN consisting of 6 residual blocks [S1]. Every 2 residual blocks include a stride-2 convolutional layer to achieve 2× downsampling [S1]. This yields features at 1/2, 1/4, and 1/8 resolutions [S1].

2.  **Multi-View Transformer:**
    Feed the 1/8 resolution convolutional features into a joint multi-view Transformer [S1]. The Transformer extends a 2-view cross-attention architecture to $K$ views [S1]. The output is the final feature maps $\{f_i\}_{i=1}^K$ at 1/8 resolution [S1].

3.  **Window Sampling:**
    For each 3D point in the target volume, project it to the 2D plane of each input view [S1]. Sample a $9 \times 9$ window centered at this 2D projection from the feature maps of view $k$ to obtain a color vector $\tilde{c}_k$ and feature vector $f_k$ [S1]. The vector $\tilde{c}_k$ denotes the concatenation of colors within the window [S1].

4.  **Pairwise Cosine Similarity:**
    Compute pairwise cosine similarities to quantify multi-view consistency [S1].
    a. Normalize features $f_i$ to unit vectors.
    b. Collect them as a $K \times M$ matrix $F$ [S1].
    c. Compute $S = F F^T$.
    d. Extract the upper triangle of $S$ to get all pairwise similarities $\cos(f_i, f_j)$ for $i < j$ [S1].
    e. Use group-wise cosine similarities for improved expressiveness [S1].

5.  **Aggregation Weights:**
    Compute normalized learned weights $w_i$ and visibility weights $w_{ij}$ [S1].
    a. **Visibility weights $w_{ij}$:** Derived from the entropy of the depth distribution on each ray [S1].
    b. **Aggregation weights $w_i$:** Predicted by a small MLP network taking the concatenation of sampled features and the view direction difference between source and target views as input [S1].

6.  **Aggregated Similarity:**
    Compute the aggregated cosine similarity $\hat{s}$ using the weighted sum:
    $$ \hat{s} = \sum_{i<j} w_{ij} \cos(f_i, f_j) $$
    where $i, j = 1, \dots, K$ and $w_{ij}$ are the normalized visibility weights [S1].

7.  **Aggregated Color and Features:**
    Compute the aggregated color $\hat{c}$ and aggregated feature $\hat{f}$ using learned weights $w_i$:
    $$ \hat{c} = \sum_{i=1}^K w_i \tilde{c}_i $$
    $$ \hat{f} = \sum_{i=1}^K w_i f_i $$
    where $w_i$ are normalized learned weights [S1].

8.  **Volume Construction:**
    Concatenate the aggregated similarity $\hat{s}$, aggregated color $\hat{c}$, and aggregated feature $\hat{f}$ [S1]. Project this concatenation to a $C$-dimensional vector using a linear layer [S1]. This produces the target volume $z \in \mathbb{R}^{\frac{H}{8} \times \frac{W}{8} \times D \times C}$ for all 3D points [S1].

## Background
The Multi-View Feature Encoder is part of the MuRF (Multi-Baseline Radiance Fields) architecture [S1]. It was introduced in the paper "MuRF: Multi-Baseline Radiance Fields" [S1]. The method builds on the observation that multi-view features of a surface point tend to exhibit high multi-view consistency [S1]. It uses a Transformer architecture extended from GMFlow's 2-view Transformer [S1].
