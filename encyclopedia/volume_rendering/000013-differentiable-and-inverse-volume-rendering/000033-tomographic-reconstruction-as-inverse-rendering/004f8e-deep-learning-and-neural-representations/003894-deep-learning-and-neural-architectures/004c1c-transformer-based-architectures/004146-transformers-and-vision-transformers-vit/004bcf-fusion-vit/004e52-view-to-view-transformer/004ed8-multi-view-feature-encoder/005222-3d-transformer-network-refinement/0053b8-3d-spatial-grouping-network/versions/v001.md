# 3D Spatial Grouping Network

Also called: Stage 2 Network for 3D Serialization and Grouping

## Overview
The 3D Spatial Grouping Network is a Stage 2 refinement module that optimizes the geometric and appearance attributes of 3D Gaussian Splatting (GS) tokens by leveraging local attention mechanisms on sparse 3D points [S1, unofficial]. It builds on [3D Transformer Network Refinement](14648-3d-transformer-network-refinement.md) by explicitly handling the sparsity of 3D Gaussians through space-filling curve serialization and localized grouping, addressing the inefficiency of global attention on unstructured point clouds [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** 1024-dimensional GS tokens lifted into 3D space, concatenated with a 256-dimensional error feature map (comprising a 128-channel error branch and a 128-channel image branch) [S1, unofficial].
*   **Output:** A 1024-dimensional residual update applied to each GS token [S1, unofficial].

**Data Structures:**
*   **Voxel Grid:** A $384^3$ grid covering the scene bounding box [S1, unofficial].
*   **Serialization:** Points are serialized along four space-filling curves: Z-order, Hilbert, and their transposed variants [S1, unofficial].
*   **Grouping:** Points are grouped into blocks of $S=8$ consecutive points in the serialized order [S1, unofficial].

**Algorithm:**
1.  **Feature Fusion:** Project the 1024-dimensional GS token to 512 dimensions. Concatenate this with the 256-dimensional error feature. Project the result to a 512-dimensional point feature [S1, unofficial].
2.  **Voxelization:** Voxelize the GS tokens onto the $384^3$ grid [S1, unofficial].
3.  **Serialization:** Assign one of the four space-filling curves (Z-order, Hilbert, or their transposes) to each of the 4 transformer blocks [S1, unofficial].
4.  **Local Attention:** For each block, compute self-attention within groups of $S=8$ consecutive points based on the assigned serialization [S1, unofficial].
5.  **Residual Update:** Map the output of the transformer blocks back to a 1024-dimensional residual and add it to the original GS token [S1, unofficial].

**Network Structure:**
*   **Blocks:** 4 pre-norm transformer blocks [S1, unofficial].
*   **Feature Dimension:** 512 [S1, unofficial].
*   **MLP Ratio:** 4 [S1, unofficial].
*   **Self-Attention:** Computed in a 256-dimensional subspace with 16 heads of dimension 16 [S1, unofficial].
*   **Parameters:** 13.2M trainable parameters [S1, unofficial].
*   **Iteration:** Applied with $T=4$ steps, sharing weights across all steps [S1, unofficial].

**Pseudocode:**
```python
def spatial_grouping_network(gs_tokens_1024, error_feature_256, scene_bbox):
    """
    Refines GS tokens using 3D spatial grouping.
    
    Args:
        gs_tokens_1024: Tensor of shape (N, 1024) representing N Gaussian tokens.
        error_feature_256: Tensor of shape (N, 256) containing error and image features.
        scene_bbox: Bounding box for voxelization.
        
    Returns:
        Updated GS tokens of shape (N, 1024).
    """
    # Step 1: Feature Fusion
    # Project 1024-dim token to 512-dim
    gs_proj = linear_projection(gs_tokens_1024, in_dim=1024, out_dim=512)
    
    # Concatenate with error feature (256-dim)
    combined = concatenate(gs_proj, error_feature_256, axis=-1)
    
    # Project to 512-dim point feature
    point_features = linear_projection(combined, in_dim=768, out_dim=512)
    
    # Step 2 & 3: Voxelization and Serialization
    # Voxelize points onto 384^3 grid
    voxelized_points = voxelize(point_features, grid_size=384, bbox=scene_bbox)
    
    # Define serialization curves
    curves = [z_order, hilbert, z_order_transposed, hilbert_transposed]
    
    # Step 4: Local Attention Blocks
    # Initialize output as identity for residual connection
    residual_output = point_features
    
    for i in range(4):
        # Serialize points using the i-th curve
        serialized_indices = serialize(voxelized_points, curve=curves[i])
        
        # Group into blocks of S=8
        groups = group_consecutive(serialized_indices, group_size=8)
        
        # Compute local attention within each group
        # Self-attention in 256-dim subspace, 16 heads, head dim 16
        group_features = local_attention(
            inputs=voxelized_points[serialized_indices],
            groups=groups,
            attention_dim=256,
            num_heads=16,
            head_dim=16
        )
        
        # Update residual output (simplified: assuming block processes all points)
        # In practice, scatter gathered features back to original positions
        updated_features = scatter(group_features, serialized_indices, N)
        residual_output = residual_output + updated_features
        
    # Step 5: Final Linear Layer
    # Map output to 1024-dim residual
    final_residual = linear_projection(residual_output, in_dim=512, out_dim=1024)
    
    # Apply residual update to original GS tokens
    updated_gs_tokens = gs_tokens_1024 + final_residual
    
    return updated_gs_tokens
```

**Parameters:**
*   Grid Size: $384^3$ [S1, unofficial].
*   Group Size ($S$): 8 [S1, unofficial].
*   Number of Blocks: 4 [S1, unofficial].
*   Number of Iterations ($T$): 4 [S1, unofficial].
*   Feature Dimension: 512 [S1, unofficial].
*   Attention Subspace: 256 [S1, unofficial].
*   Number of Heads: 16 [S1, unofficial].
*   Head Dimension: 16 [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** Voxelization on a $384^3$ grid may lose precision for very small or widely dispersed Gaussians if the bounding box is not tightly fitted [G].
*   **Boundaries:** Points near the boundary of the bounding box may be truncated or incorrectly assigned if voxelization logic does not handle edge cases [G].
*   **Serialization Artifacts:** Space-filling curves can introduce discontinuities at block boundaries; however, local attention within groups of 8 mitigates this by limiting the receptive field [S1, unofficial].

## Subtopics

### View-wise Grouping Network
A hierarchical transformer network for Stage 1 that processes image patches with increasing coarseness, using frame-wise and view-wise attention to aggregate features across views [S1, unofficial]. It splits views into non-overlapping groups of two adjacent frames for view-wise group attention layers [S1, unofficial]. The network has 14 layers: Layers 1-2 use 4x4 patch tokens (256-dim) with frame-wise attention; Layers 3-6 use 8x8 patch tokens (512-dim) with frame-wise and view-wise group attention; Layers 7-14 use 16x16 patch tokens (1024-dim) with frame-wise and global attention [S1, unofficial]. All attention modules use a head dimension of 64 [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of Gaussians $N$ due to local attention within fixed-size groups ($S=8$) [S1, unofficial].
*   **Memory Complexity:** Dominated by the $384^3$ voxel grid and the storage of GS tokens and error features [S1, unofficial].
*   **Performance:** The network has 13.2M trainable parameters [S1, unofficial]. It is applied with $T=4$ steps with weight sharing, reducing inference time compared to applying distinct networks [S1, unofficial].
*   **Strengths:** Efficiently handles sparse 3D data by leveraging spatial locality via space-filling curves [S1, unofficial].
*   **Limitations:** Performance depends on the quality of the initial voxelization and the choice of space-filling curves [G].
*   **When to Use:** When refining 3D Gaussian tokens for high-fidelity novel view synthesis where geometric accuracy is critical [S1, unofficial].
*   **When Not to Use:** For scenes with extremely large bounding boxes where voxelization becomes memory-prohibitive [G].

## Background
The 3D Spatial Grouping Network is part of the FineSplat architecture, introduced in 2026 [S1, unofficial]. It follows Point Transformer V3 for 3D serialization and grouping [S1, unofficial]. The method is trained in three phases: Stage 1, Stage 2 (this network), and end-to-end fine-tuning [S1, unofficial].
