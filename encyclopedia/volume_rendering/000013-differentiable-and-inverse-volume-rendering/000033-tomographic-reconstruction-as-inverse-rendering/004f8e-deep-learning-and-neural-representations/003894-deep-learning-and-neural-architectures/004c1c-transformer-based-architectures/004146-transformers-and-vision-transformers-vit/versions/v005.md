# Transformers and Vision Transformers (ViT)
Also called: Vision Transformer

## Overview
Transformers compute pairwise attention over input tokens to capture long-range dependencies that local convolutions miss [S1, unofficial]. The Vision Transformer (ViT) adapts this architecture for image-like data by treating fixed-size patches as tokens [S1, unofficial]. In volume rendering, they are used for super-resolution and denoising, where attending across the full spatial extent of a subvolume helps recover large-scale structures [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   Input: A sequence of $N$ tokens, where each token is a vector of dimension $d$. For ViT, tokens are derived by splitting an input image (or volume slice) into fixed-size patches and projecting them.
*   Output: A sequence of $N$ transformed tokens of dimension $d$.

**Data Structures:**
*   Tokens: A matrix $X \in \mathbb{R}^{N \times d}$.
*   Learnable Parameters: Linear projection matrices $W_Q, W_K, W_V \in \mathbb{R}^{d \times d_k}$ (where $d_k$ is the key dimension, often $d_k = d$ or $d/h$ for multi-head attention), and a final output projection $W_O \in \mathbb{R}^{d \times d}$.
*   Positional Embeddings: A learnable or fixed matrix $E_{pos} \in \mathbb{R}^{N \times d}$.

**Steps:**
1.  **Tokenization (ViT specific):** Split the input image of size $H \times W$ into non-overlapping patches of size $P \times P$. The number of patches is $N = (H/P) \times (W/P)$. Flatten each patch and project it to dimension $d$ using a linear layer.
2.  **Add Positional Information:** Add positional embeddings to the patch tokens to preserve spatial order, as attention is permutation-invariant.
    $$ X_{input} = X_{patches} + E_{pos} $$
3.  **Linear Projections:** Compute Query, Key, and Value matrices for each token.
    $$ Q = X_{input} W_Q, \quad K = X_{input} W_K, \quad V = X_{input} W_V $$
4.  **Scaled Dot-Product Attention:** Compute attention scores and apply softmax.
    $$ \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V $$
    *   $QK^T$ computes pairwise similarity between all tokens.
    *   $\sqrt{d_k}$ scales the dot products to prevent vanishing gradients in softmax.
    *   Softmax normalizes scores to sum to 1.
    *   The result is a weighted sum of Values.
5.  **Multi-Head Attention (Optional but standard):** Repeat steps 3-4 with $h$ heads, where each head uses different projections to dimensions $d_k = d/h$. Concatenate the outputs and project back to $d$ using $W_O$.
6.  **Residual Connection and Layer Normalization:** Add the input to the attention output and apply Layer Normalization.
    $$ X_{out} = \text{LayerNorm}(X_{input} + \text{Attention}(Q, K, V)) $$
7.  **Feed-Forward Network (FFN):** Apply a position-wise fully connected network to each token.
    $$ \text{FFN}(x) = W_2 \cdot \text{GELU}(W_1 x + b_1) + b_2 $$
    where $W_1 \in \mathbb{R}^{d_{ff} \times d}$ and $W_2 \in \mathbb{R}^{d \times d_{ff}}$.
8.  **Residual Connection and Layer Normalization:**
    $$ X_{final} = \text{LayerNorm}(X_{out} + \text{FFN}(X_{out})) $$

**Parameters:**
*   $d$: Embedding dimension (e.g., 768, 1024).
*   $h$: Number of attention heads.
*   $d_k$: Key dimension ($d/h$).
*   $P$: Patch size (e.g., 16, 32).
*   $N$: Number of tokens ($N = HW/P^2$).

**Edge Cases and Pitfalls:**
*   **Sequence Length:** $N$ grows quadratically with image resolution. For high-resolution volumes, this leads to high memory usage.
*   **Positional Encoding:** Without positional embeddings, the model cannot distinguish spatial locations.
*   **Patch Boundary Artifacts:** Fixed patch splitting may introduce discontinuities at patch boundaries if not handled by the projection layer.

## Operating characteristics
*   **Time Complexity:** $O(N^2 \cdot d)$ per layer due to pairwise attention. For ViT, $N = HW/P^2$, so complexity is $O((HW/P^2)^2 \cdot d)$.
*   **Memory Complexity:** $O(N^2 \cdot d)$ to store attention matrices.
*   **Strengths:** Captures global context; effective for recovering large-scale structures in volume super-resolution and denoising [S1, unofficial].
*   **Limitations:** High computational cost for large $N$; sensitive to positional encoding choices.
*   **When to use:** When long-range dependencies are critical (e.g., volume SR, denoising) and computational resources allow for quadratic attention [S1, unofficial].
*   **When not to use:** For very high-resolution data where $N$ is extremely large, unless using efficient attention variants.

## Background
The Transformer was introduced by Vaswani et al. [146] for sequence modeling. The Vision Transformer (ViT) adapted this for images by Dosovitskiy et al. [25]. In scientific volume visualization, Transformers have been applied to super-resolution and denoising to leverage their ability to attend across the full spatial extent of subvolumes [S1, unofficial].
