# Transformer-based Tomographic Reconstruction

Also called: SSTrans-3D, Slice-by-slice transformer network

## Overview
Transformer-based Tomographic Reconstruction is a deep learning technique that reconstructs 3D single-photon emission computed tomography (SPECT) images using a slice-by-slice transformer network (SSTrans-3D) [S1][S2, unofficial]. It addresses the considerable artifacts caused by incomplete projection data in image reconstruction [S1][S2, unofficial]. It differs from siblings like [DuDoTrans](1409-dudotrans.md) and [DIOR](1409-dudotrans.md) by relying on a pure transformer architecture rather than combining deep learning with iterative optimization [S1][S2, unofficial].

## Background
The method was introduced in the context of addressing limitations of Convolutional Neural Networks (CNNs) in image reconstruction, where huge amounts of stacked layers can cause gradient-vanishing issues [S1][S2, unofficial]. Vision transformers were suggested to remove these restrictions [S1][S2, unofficial]. SSTrans-3D is specifically applied to 3D single-photon emission computed tomography (SPECT) [S1][S2, unofficial]. It is compared against Deep Iterative Optimization-based Residual-learning (DIOR), which combines deep learning and iterative optimization to reconstruct limited-angle CT and improve generalization [S1][S2, unofficial].
