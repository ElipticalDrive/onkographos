# Transformer-based Tomographic Reconstruction

Also called: SSTrans-3D, Slice-by-slice transformer network

## Overview
Transformer-based Tomographic Reconstruction is a deep learning technique that reconstructs 3D single-photon emission computed tomography (SPECT) images using a slice-by-slice transformer network (SSTrans-3D) [S1][S2, unofficial]. It addresses the problem of considerable artifacts caused by incomplete projection data in image reconstruction [S1][S2, unofficial]. Unlike Deep Iterative Optimization-based Residual-learning (DIOR), which combines deep learning with iterative optimization to handle limited-angle CT, this method relies purely on transformer architectures to remove the restrictions of Convolutional Neural Networks (CNNs) in capturing global context [S1][S2, unofficial].

## How it works
Inputs and outputs: The method takes incomplete projection data as input and outputs a reconstructed 3D SPECT image volume [S1][S2, unofficial].

Data structures: The input is discretized into slices. Each slice is processed by a transformer network [S1][S2, unofficial]. The specific internal data structures (e.g., token dimensions, patch sizes) are not given in the sources.

Numbered steps:
1. The 3D volume is decomposed into individual 2D slices [S1][S2, unofficial].
2. Each slice is processed by the Slice-by-slice transformer network (SSTrans-3D) [S1][S2, unofficial].
3. The transformer network applies attention mechanisms to reconstruct the slice, mitigating artifacts from incomplete data [S1][S2, unofficial].
4. The reconstructed slices are combined to form the final 3D SPECT image [S1][S2, unofficial].

Formulas: The core mechanism follows the scaled dot-product attention defined in the parent article [S1]. Specific architectural formulas for SSTrans-3D are not given in the sources.

Parameters: Typical values for hyperparameters (e.g., number of heads, layers, patch size) are not given in the sources.

Edge cases and pitfalls: Incomplete projection data causes considerable artifacts, which this method aims to reduce [S1][S2, unofficial].
