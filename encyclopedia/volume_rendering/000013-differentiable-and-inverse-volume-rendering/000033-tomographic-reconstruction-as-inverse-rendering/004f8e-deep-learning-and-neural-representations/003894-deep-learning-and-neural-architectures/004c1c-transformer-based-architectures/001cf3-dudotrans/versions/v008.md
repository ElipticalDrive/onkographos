# DuDoTrans

Also called: DuDoTransModel

## Overview
DuDoTrans is a dual-domain transformer architecture designed for sparse-view CT reconstruction, addressing the ill-posed nature of tomographic inversion when projection data is limited [S1, unofficial]. It distinguishes itself from standard transformer-based reconstruction methods by explicitly operating in both the image domain (via Swin Transformer blocks) and the projection domain (via a differentiable forward projection/backprojection module), allowing the network to learn complementary features from both representations [S1, unofficial]. Unlike [Generalizable Radiance Fields via Transformer Attention](8996-generalizable-radiance-fields-via-transformer-attention.md) which focuses on novel view synthesis, DuDoTrans is tailored for volumetric recovery from sparse angular samples.

## How it works
**Inputs and Outputs:**
- Input: A set of sparse 2D projection images (sinograms) and/or an initial reconstructed volume (e.g., from FBP). The implementation described processes 2D slices or volumes as 4D tensors $(B, H, W, C)$ where $B$ is batch size, $H, W$ are spatial dimensions, and $C$ is channel/embedding dimension [S1, unofficial].
- Output: A refined reconstructed volume or 2D slice with reduced artifacts compared to the input.

**Data Structures:**
- `relative_position_bias_table`: A learnable parameter tensor of shape $((2W_h - 1)(2W_w - 1), \text{num\_heads})$. Initialized with zeros and truncated normal distribution (std=0.02) [S1, unofficial].
- `relative_position_index`: A buffer tensor of shape $(W_h W_w, W_h W_w)$ containing integer indices into `relative_position_bias_table`. This is precomputed and constant for a given window size [S1, unofficial].

**Core Mechanism: Swin Transformer Block with Window Attention**
The method utilizes Swin Transformer blocks which employ Window-based Multi-Head Self-Attention (W-MSA) and Shifted Windows (SW-MSA) [S1, unofficial].

1.  **Window Partitioning:**
    The input tensor $x$ of shape $(B, H, W, C)$ is partitioned into non-overlapping windows of size $W_s \times W_s$.
    - Reshape $x$ to $(B, H/W_s, W_s, W/W_s, W_s, C)$.
    - Permute to $(B, H/W_s, W/W_s, W_s, W_s, C)$.
    - Flatten to $(num\_windows \cdot B, W_s, W_s, C)$, where $num\_windows = (H/W_s) \cdot (W/W_s)$ [S1, unofficial].

2.  **Relative Position Bias Calculation:**
    To incorporate spatial inductive bias within the window:
    - Generate coordinates: $coords_h = \text{arange}(W_h)$, $coords_w = \text{arange}(W_w)$, where $W_h=W_w=W_s$.
    - Create meshgrid and flatten to $(2, W_h W_w)$.
    - Compute relative coordinates: $relative\_coords = coords\_flatten[:, :, None] - coords\_flatten[:, None, :]$.
    - Permute to $(W_h W_w, W_h W_w, 2)$.
    - Shift indices: $relative\_coords[:, :, 0] += W_h - 1$, $relative\_coords[:, :, 1] += W_w - 1$.
    - Map to 1D index: $relative\_coords[:, :, 0] *= 2 W_w - 1$.
    - Sum to get final index: $relative\_position\_index = relative\_coords.sum(-1)$ [S1, unofficial].

3.  **Window Attention Forward (W-MSA):**
    - Compute Q, K, V via linear projection: $qkv = \text{Linear}(x)$.
    - Reshape $qkv$ to $(B_, N, 3, \text{num\_heads}, C/\text{num\_heads})$ and permute to $(3, B_, \text{num\_heads}, N, C/\text{num\_heads})$, where $N = W_s^2$ and $B_ = num\_windows \cdot B$ [S1, unofficial].
    - Scale Q: $q = q \cdot \text{scale}$, where $\text{scale} = qk\_scale$ if provided, else $head\_dim^{-0.5}$ [S1, unofficial].
    - Compute attention scores: $attn = q @ k^T$.
    - Add relative position bias: $bias = \text{table}[relative\_position\_index]$. Reshape bias to $(W_h W_w, W_h W_w, \text{num\_heads})$, permute to $(\text{num\_heads}, W_h W_w, W_h W_w)$, and add to $attn$ [S1, unofficial].
    - Apply softmax: $attn = \text{softmax}(attn)$.
    - Apply attention dropout.
    - Compute output: $x = (attn @ v)^T$. Reshape, project via linear layer, and apply projection dropout [S1, unofficial].

4.  **Window Reverse:**
    Reconstruct the image from windows to restore the original spatial layout.
    - Reshape windows $(B_, W_s, W_s, C)$ to $(B, H/W_s, W/W_s, W_s, W_s, C)$.
    - Permute to $(B, H/W_s, W_s, W/W_s, W_s, C)$.
    - Flatten to $(B, H, W, C)$ [S1, unofficial].

5.  **Shifted Window Partitioning (SW-MSA):**
    In alternating layers, windows are shifted by $shift\_size$. This involves cyclic shifting of the feature map before window partitioning and cyclic shifting back after window reverse to maintain connectivity across windows [S1, unofficial].

6.  **Multi-Layer Perceptron (MLP):**
    A standard feed-forward network is applied after the attention block. The hidden dimension is $mlp\_ratio \times C$ [S1, unofficial].

**Dual-Domain Integration:**
The architecture integrates the image-domain Swin Transformer with a differentiable forward projection/backprojection module. The forward projection maps the 3D volume to 2D sinograms, and backprojection maps sinograms back to the volume space, enabling gradient flow between the two domains during training [S1, unofficial].

**Parameters:**
- `window_size`: Height and width of the attention window. Default: $(7, 7)$ [S1, unofficial].
- `shift_size`: Shift size for SW-MSA. Default: $0$ [S1, unofficial].
- `mlp_ratio`: Ratio of MLP hidden dimension to embedding dimension. Default: $4.0$ [S1, unofficial].
- `qk_scale`: Override default QK scale. If None, defaults to $head\_dim^{-0.5}$ [S1, unofficial].

**Pitfalls:**
- If the input resolution is smaller than or equal to the window size, the shift size is forced to $0$ and the window size is reduced to the minimum input dimension to avoid invalid partitioning [S1, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class WindowAttention(nn.Module):
    def __init__(self, dim, window_size, num_heads, qkv_bias=True, qk_scale=None, attn_drop=0., proj_drop=0.):
        super().__init__()
        self.dim = dim
        self.window_size = window_size  # Wh, Ww
        self.num_heads = num_heads
        head_dim = dim // num_heads
        self.scale = qk_scale or head_dim ** -0.5

        # Relative position bias table
        self.relative_position_bias_table = nn.Parameter(
            torch.zeros((2 * window_size[0] - 1) * (2 * window_size[1] - 1), num_heads)
        )
        # Initialize with truncated normal (std=0.02) approximated by normal for simplicity in code structure
        nn.init.trunc_normal_(self.relative_position_bias_table, std=0.02)

        # Relative position index
        self.register_buffer("relative_position_index", self.get_relative_position_index())

        self.qkv = nn.Linear(dim, dim * 3, bias=qkv_bias)
        self.attn_drop = nn.Dropout(attn_drop)
        self.proj = nn.Linear(dim, dim)
        self.proj_drop = nn.Dropout(proj_drop)

        self.softmax = nn.Softmax(dim=-1)

    def get_relative_position_index(self):
        # Generate coordinates
        coords_h = torch.arange(self.window_size[0])
        coords_w = torch.arange(self.window_size[1])
        coords = torch.stack(torch.meshgrid([coords_h, coords_w]))  # 2, Wh, Ww
        coords_flatten = torch.flatten(coords, 1)  # 2, Wh*Ww

        # Relative coordinates
        relative_coords = coords_flatten[:, :, None] - coords_flatten[:, None, :]  # 2, Wh*Ww, Wh*Ww
        relative_coords = relative_coords.permute(1, 2, 0).contiguous()  # Wh*Ww, Wh*Ww, 2

        # Shift indices
        relative_coords[:, :, 0] += self.window_size[0] - 1
        relative_coords[:, :, 1] += self.window_size[1] - 1

        # Map to 1D index
        relative_coords[:, :, 0] *= 2 * self.window_size[1] - 1
        relative_position_index = relative_coords.sum(-1)  # Wh*Ww, Wh*Ww
        return relative_position_index

    def forward(self, x):
        B_, N, C = x.shape
        # N = Wh * Ww

        # QKV projection
        qkv = self.qkv(x).reshape(B_, N, 3, self.num_heads, C // self.num_heads).permute(2, 0, 3, 1, 4)
        q, k, v = qkv[0], qkv[1], qkv[2]  # B_, num_heads, N, head_dim

        # Scale Q
        q = q * self.scale

        # Attention scores
        attn = (q @ k.transpose(-2, -1))

        # Relative position bias
        relative_position_bias = self.relative_position_bias_table[self.relative_position_index.view(-1)].view(
            self.window_size[0] * self.window_size[1], self.window_size[0] * self.window_size[1], -1)  # Wh*Ww, Wh*Ww, nH
        relative_position_bias = relative_position_bias.permute(2, 0, 1).contiguous()  # nH, Wh*Ww, Wh*Ww
        attn += relative_position_bias

        attn = self.softmax(attn)
        attn = self.attn_drop(attn)

        # Output
        x = (attn @ v).transpose(1, 2).reshape(B_, N, C)
        x = self.proj(x)
        x = self.proj_drop(x)
        return x

class SwinTransformerBlock(nn.Module):
    def __init__(self, dim, input_resolution, num_heads, window_size=7, shift_size=0, mlp_ratio=4., qkv_bias=True, qk_scale=None, drop=0., attn_drop=0., drop_path=0.):
        super().__init__()
        self.dim = dim
        self.input_resolution = input_resolution
        self.num_heads = num_heads
        self.window_size = window_size
        self.shift_size = shift_size
        self.mlp_ratio = mlp_ratio

        self.norm1 = nn.LayerNorm(dim)
        self.attn = WindowAttention(
            dim, window_size=(self.window_size, self.window_size), num_heads=num_heads,
            qkv_bias=qkv_bias, qk_scale=qk_scale, attn_drop=attn_drop, proj_drop=drop)

        self.norm2 = nn.LayerNorm(dim)
        mlp_hidden_dim = int(dim * mlp_ratio)
        self.mlp = nn.Sequential(
            nn.Linear(dim, mlp_hidden_dim),
            nn.GELU(),
            nn.Dropout(drop),
            nn.Linear(mllp_hidden_dim, dim),
            nn.Dropout(drop)
        )

        if self.shift_size > 0:
            # Calculate shift mask
            H, W = self.input_resolution
            img_mask = torch.zeros((1, H, W, 1))
            h_slices = (slice(0, -self.window_size), slice(-self.window_size, -self.shift_size), slice(-self.shift_size, None))
            w_slices = (slice(0, -self.window_size), slice(-self.window_size, -self.shift_size), slice(-self.shift_size, None))
            cnt = 0
            for h in h_slices:
                for w in w_slices:
                    img_mask[:, h, w, :] = cnt
                    cnt += 1
            mask_windows = self.window_partition(img_mask)  # nW, Ws, Ws, 1
            attn_mask = mask_windows.unsqueeze(1) - mask_windows.unsqueeze(2)
            attn_mask = attn_mask.masked_fill(attn_mask != 0, float(-100.0)).masked_fill(attn_mask == 0, float(0.0))
            self.attn_mask = attn_mask
        else:
            self.attn_mask = None

    def forward(self, x):
        H, W = self.input_resolution
        B, L, C = x.shape
        assert L == H * W, "input feature has wrong size"

        shortcut = x
        x = self.norm1(x)
        x = x.view(B, H, W, C)

        # Cyclic shift
        if self.shift_size > 0:
            shifted_x = torch.roll(x, shifts=(-self.shift_size, -self.shift_size), dims=(1, 2))
        else:
            shifted_x = x

        # Window partition
        X_windows = self.window_partition(shifted_x)  # nW*B, Ws, Ws, C
        X_windows = X_windows.view(-1, self.window_size * self.window_size, C)  # nW*B, Ws*Ws, C

        # Window attention
        if self.attn_mask is not None:
            attn_mask = self.attn_mask.to(X_windows.device)
        else:
            attn_mask = None
            
        W_windows = self.attn(X_windows)  # nW*B, Ws*Ws, C

        # Window reverse
        W_windows = W_windows.view(-1, self.window_size, self.window_size, C)
        shifted_x = self.window_reverse(W_windows, H, W)  # B, H, W, C

        # Reverse cyclic shift
        if self.shift_size > 0:
            x = torch.roll(shifted_x, shifts=(self.shift_size, self.shift_size), dims=(1, 2))
        else:
            x = shifted_x

        x = x.view(B, H * W, C)
        x = shortcut + x

        # MLP
        x = x + self.mlp(self.norm2(x))
        return x

    def window_partition(self, x):
        B, H, W, C = x.shape
        x = x.view(B, H // self.window_size, self.window_size, W // self.window_size, self.window_size, C)
        windows = x.permute(0, 1, 3, 2, 4, 5).contiguous().view(-1, self.window_size, self.window_size, C)
        return windows

    def window_reverse(self, windows, H, W):
        B = int(windows.shape[0] / (H * W / self.window_size / self.window_size))
        x = windows.view(B, H // self.window_size, W // self.window_size, self.window_size, self.window_size, -1)
        x = x.permute(0, 1, 3, 2, 4, 5).contiguous().view(B, H, W, -1)
        return x

```

## Operating characteristics
- **Time Complexity:** Standard Multi-Head Self-Attention is $O(N^2)$ where $N$ is the number of tokens. DuDoTrans uses Window Attention, reducing complexity to $O(N \cdot W_s^2)$ where $W_s$ is the window size [S1, unofficial].
- **Memory Complexity:** Proportional to the number of tokens and window size. The relative position bias table size is $O(W_s^2 \cdot \text{num\_heads})$ [S1, unofficial].
- **Performance:** Effective for sparse-view CT reconstruction, reducing artifacts compared to traditional methods and standard transformers [S1, unofficial].
- **Strengths:** Local attention reduces computational cost; shifted windows allow cross-window communication; dual-domain design leverages both image and projection information [S1, unofficial].
- **Limitations:** Performance depends on window size selection; sparse views may still lead to ambiguities if not regularized properly [S1, unofficial].
