# Transformer-based Architectures
## Overview
Transformer-based architectures apply self-attention mechanisms to volume rendering and tomographic reconstruction to capture long-range dependencies that local convolutional operations miss [S1][S5]. They solve the problem of limited receptive fields in CNNs, enabling the modeling of global structural context for tasks such as sparse-view CT reconstruction, generalizable radiance fields, and artifact reduction in SPECT imaging [S1][S2, unofficial]. This family is distinguished from sibling methods like [Deep Image Prior Reconstruction](1221-deep-image-prior-reconstruction.md) and [R2-Gaussian](6090-r2-gaussian.md) by its reliance on pairwise token attention rather than iterative optimization priors or explicit geometric parameterizations [S1][S2, unofficial].
## Shared principles
The family shares the core mechanism of computing pairwise attention over input tokens to aggregate global context [S1]. The fundamental operation is the scaled dot-product attention:
$$
\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$
where $Q$, $K$, and $V$ are linear projections of the input tokens, and $d_k$ is the dimensionality of the key vectors [S1][S5]. Tokens are typically derived by discretizing input data (images, projections, or rays) into fixed-size patches and projecting them into a vector space of dimension $d$ [S1][S5]. Positional information is added to tokens to preserve spatial order, as the attention mechanism is permutation-invariant [S1][S5].
## Subtopics

### [DuDoTrans](1409-dudotrans.md)
DuDoTrans is a dual-domain transformer architecture designed for sparse-view CT reconstruction. It distinguishes itself by employing Window-based Multi-Head Self-Attention (W-MSA) within a Swin Transformer block structure, restricting global context modeling to local windows to reduce computational complexity while maintaining long-range dependency capture through shifted windows. Choose this method when computational efficiency is critical for high-resolution 2D slice processing in sparse-view scenarios.

### [Generalizable Radiance Fields via Transformer Attention](8996-generalizable-radiance-fields-via-transformer-attention.md)
This method replaces per-scene optimization with a feed-forward inference pipeline that predicts radiance fields directly from input images. It solves the limitation of standard NeRF by learning generalizable geometric priors from a source dataset using a transformer-based attention module to aggregate information across multiple source views. Unlike standard methods requiring dense views, it enables cross-dataset generalization by leveraging deep multiview stereo strategies. Choose this method for novel view synthesis from sparse or uncalibrated source images without per-scene tuning.

### [Transformers and Vision Transformers (ViT)](10441-transformers-and-vision-transformers-vit.md)
Transformers and Vision Transformers (ViT) compute pairwise attention over input tokens to capture long-range dependencies. In volume rendering, they are applied to super-resolution and denoising, where their ability to attend across the full spatial extent of a subvolume helps recover large-scale structures that local convolutions miss. Unlike convolutional operations, transformers compute pairwise interactions between all tokens, allowing the model to capture global structural context. Choose this method when global structural coherence is more important than local texture fidelity.

### [Transformer-based Tomographic Reconstruction](11047-transformer-based-tomographic-reconstruction.md)
This technique reconstructs 3D medical images, specifically Single-Photon Emission Computed Tomography (SPECT), using a slice-by-slice transformer network (SSTrans-3D). It addresses artifacts caused by incomplete projection data by leveraging the global context modeling of transformers to understand the whole image structure, unlike CNNs with limited receptive fields. It differs from hybrid approaches like DIOR by relying purely on transformer architectures rather than combining deep learning with iterative optimization steps. Choose this method for artifact reduction in SPECT reconstruction with incomplete data.

### Depth-Encoded Ray Transformer (DERT)
DERT is a transformer architecture that infers volume density by incorporating relative depth differences as position encoding, rather than absolute positions [S1]. It addresses varying scene scales by using relative depths. The steps are: 1. Sample $M$ points $p_m$ on ray $r$ with depths $t_m$. 2. Calculate relative depth encoding $E_m$ for each point using $\delta_m$. 3. Element-wise add $E_m$ to point feature $f_m$. 4. Pass through self-attention and feed-forward network to predict volume density $\sigma_m$ [S1]. The parameter $K$ is the length of the position encoding feature vector [S1].

### Transformer Proposer Architecture
A proposer network constrained to reduce computational cost, using a single transformer block for encoder and decoder with a single attention head [S2, unofficial]. Features are projected to 16-D [S2, unofficial].

### Masked Auto Encoder (MAE) for Generalizable NeRF
Uses Masked Auto Encoder combined with a 3D transformer-based architecture to learn a generalized representation capable of reconstructing unseen scenes [S3].

### X-ray Reconstruction Transformer
A large feedforward transformer model that encodes sparse-view X-ray projections into compact latent tokens and fuses them across views to reconstruct a 3D CT volume density field [S4, unofficial]. Steps: 1. Encode each X-ray projection $I_i$ independently using a feature extractor $F_{enc}$ (specifically DINO) to produce patch features $H_i$: $H_i = F_{enc}(I_i)$ for $i = 1, \dots, K$. 2. Inject camera geometry into the encoded features by applying ModLN with Plücker ray embeddings $R_i$: $\tilde{H}_i = ModLN(H_i, R_i)$ for $i = 1, \dots, K$. 3. Concatenate the modulated features from all $K$ views and process them through a 16-layer Fusion ViT (similar to ViT-B) using all-to-all self-attention $F_{fuse}$ to produce fused features $\{F_1, \dots, F_K\}$ [S4, unofficial]. Parameters: Fusion ViT depth is 16 layers, architecture similar to ViT-B; Encoder backbone is DINO transformer; Camera embedding is Plücker ray embedding $R_i$, derived from the cross product between camera location and ray direction, independent of scale, camera position, and focal length [S4, unofficial].

### NeRFormer
A model using Transformers for volume rendering, processing ray-depth-ordered feature sequences from multiple source views [S5]. It uses alternating pooling and ray-wise attention layers to enable effective joint feature aggregation and ray marching [S5].

## Background
Transformer architectures originated in natural language processing and were adapted for computer vision as Vision Transformers (ViT) [S1][S5]. In the context of volume rendering and tomography, they emerged to address the limitations of CNNs in capturing global dependencies [S1][S2, unofficial]. Early applications included generalizable radiance fields [S1] and sparse-view CT reconstruction [S1]. The use of relative depth encoding [S1] and Plücker ray embeddings [S4, unofficial] represents recent developments to better incorporate geometric priors into the attention mechanism.
