# Ray Transformer

Also called: A module based on linear attention that provides non-local information of other points along the ray to predict SRDF, addressing the non-local definition of SRDF

## Overview
The Ray Transformer is a neural module designed to predict Signed Ray Distance Functions (SRDF) by aggregating non-local information along a viewing ray. It addresses the limitation that SRDF values depend on the closest surface along the entire ray rather than being locally defined at a single point [S1][S2, unofficial]. Unlike standard local volume rendering, it uses linear attention to model dependencies between points ordered from near to far, building on the view aggregation of [Generalizable Radiance Fields via Transformer Attention](8996-generalizable-radiance-fields-via-transformer-attention.md).

## How it works
**Inputs:**
*   $M$: Number of sampling points along the ray.
*   $\mathbf{f}_v \in \mathbb{R}^{d_v}$: Volume feature at each point.
*   $\mathbf{f}_p \in \mathbb{R}^{d_p}$: Projection feature at each point.
*   $\gamma$: Positional encoding function.

**Outputs:**
*   $\{\tilde{\mathbf{f}}_j\}_{j=1}^{M}$: Attended features for each point.
*   SRDF values decoded from $\tilde{\mathbf{f}}_j$.

**Data Structures:**
*   Combined feature sequence: A list of tensors $\{\mathbf{c}_j\}_{j=1}^{M}$, where $\mathbf{c}_j = \text{cat}(\mathbf{f}_{v,j}, \mathbf{f}_{p,j}, \gamma_j)$.
*   Attended feature sequence: $\{\tilde{\mathbf{f}}_j\}_{j=1}^{M}$.

**Steps:**
1.  **Ordering:** Order the $M$ sampling points along the ray from near to far [S1].
2.  **Feature Concatenation:** For each point $j \in \{1, \dots, M\}$, concatenate the volume feature $\mathbf{f}_{v,j}$, the projection feature $\mathbf{f}_{p,j}$, and the positional encoding $\gamma_j$ to form the combined feature $\mathbf{c}_j$ [S1][S2, unofficial]. This adds a global shape prior.
3.  **Attention:** Apply the Ray Transformer module to the sequence of combined features to predict attended features $\{\tilde{\mathbf{f}}_j\}_{j=1}^{M}$ [S1][S2, unofficial]:
    $$ \{\tilde{\mathbf{f}}_j\}_{j=1}^{M} = \text{RayTrans}(\{\text{cat}(\mathbf{f}_{v,j}, \mathbf{f}_{p,j}, \gamma_j)\}_{j=1}^{M}) $$
    The module is based on linear attention [S1][S2, unofficial].
4.  **Decoding:** Use a Multi-Layer Perceptron (MLP) to decode the attended feature $\tilde{\mathbf{f}}_j$ into the SRDF value for each point $j$ [S1][S2, unofficial].

**Pseudocode:**
```python
def ray_transformer(volume_features, projection_features, positional_encoding_func):
    """
    volume_features: List of M tensors, each shape (d_v,)
    projection_features: List of M tensors, each shape (d_p,)
    positional_encoding_func: Function mapping index to positional encoding vector
    Returns: List of M attended feature tensors, and SRDF values via MLP
    """
    M = len(volume_features)
    combined_features = []
    
    # Step 1 & 2: Order points (assumed already ordered near-to-far) 
    # and concatenate features with positional encoding
    for j in range(M):
        # cat denotes concatenation along the feature dimension
        pos_enc = positional_encoding_func(j)
        combined = concatenate([volume_features[j], projection_features[j], pos_enc])
        combined_features.append(combined)
        
    # Step 3: Apply linear self-attention
    # RayTrans implements linear attention as per [19] cited in [S1][S2, unofficial]
    attended_features = linear_self_attention(combined_features)
    
    # Step 4: Decode SRDF using MLP
    # The MLP is defined in the source but specific architecture details are not provided
    # [G] Assuming a standard MLP: Linear -> Activation -> Linear
    srdf_values = []
    for f_tilde in attended_features:
        srdf = mlp_decode(f_tilde)
        srdf_values.append(srdf)
        
    return attended_features, srdf_values
```

**Parameters:**
*   $M$: Number of sampling points. Not given in the sources.
*   $\alpha$: Weight for depth loss in the total loss function $\mathcal{L} = \mathcal{L}_{\text{color}} + \alpha \mathcal{L}_{\text{depth}}$ [S1][S2, unofficial]. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Ordering:** Points must be strictly ordered from near to far for the attention mechanism to correctly model the ray's geometry [S1].
*   **Non-locality:** The method explicitly handles the non-local nature of SRDF, which standard local methods may fail to capture [S1][S2, unofficial].

## Operating characteristics
*   **Complexity:** The use of linear attention [S1][S2, unofficial] suggests $O(M)$ complexity with respect to the number of points $M$, compared to $O(M^2)$ for standard self-attention, though exact complexity analysis is not provided in the sources.
*   **Performance:** The method is part of VolRecon, which uses a combined loss of color and depth [S1][S2, unofficial]. Specific performance metrics (PSNR, SSIM) are not detailed in the provided notes.
*   **Strengths:** Provides non-local information along the ray, addressing the definition of SRDF [S1][S2, unofficial].
*   **Limitations:** Relies on the accuracy of the volume and projection features fed into it.

## Background
The Ray Transformer was introduced in the VolRecon paper [S1][S2, unofficial] for generalizable multi-view reconstruction using Signed Ray Distance Functions. It builds upon the concept that SRDF is not locally defined and depends on the closest surface along the entire ray [S1][S2, unofficial]. The attention mechanism is based on linear attention [S1][S2, unofficial].
