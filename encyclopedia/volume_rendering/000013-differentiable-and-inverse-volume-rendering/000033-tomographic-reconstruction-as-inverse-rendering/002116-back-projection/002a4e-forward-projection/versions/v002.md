# Forward Projection
Also called: 3D → 2D Forward Projection, Central Slice Theorem Projection, Fourier Slice Projection

## Overview
Forward projection generates 2D projections from a 3D Fourier-space reconstruction by sampling central slices through the 3D volume, implementing the Central Slice Theorem [S1, unofficial]. It serves as the differentiable forward operator in tomographic reconstruction pipelines, acting as the mathematical adjoint to back-projection [S1, unofficial]. Unlike spatial-domain projection methods that integrate ray paths through density fields, this method operates directly in the frequency domain, enabling efficient gradient computation for rotation and translation parameters [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D reconstruction tensor in Fourier space with shape `[B, D, H, W/2+1]`, where `B` is batch size, `D` is depth, `H` is height, and `W` is width (real-valued FFT output) [S1, unofficial].
*   **Input:** Rotation matrices with shape `[B, P, 3, 3]`, where `P` is the number of projection poses [S1, unofficial].
*   **Input (Optional):** 2D shift vectors with shape `[B, P, 2]` [S1, unofficial].
*   **Output:** 2D projection tensor with shape `[B, P, Hout, Wout/2 + 1]` [S1, unofficial].

**Data Structures:**
The 3D reconstruction is stored as a tensor in Fourier space with the specified shape [S1, unofficial]. Coordinates are defined in frequency space $(k_r, k_c, k_d)$ [G].

**Parameters:**
*   **Interpolation:** Trilinear or tricubic (Catmull-Rom) [S1, unofficial].
*   **Output Resolution:** $H_{out}, W_{out}$ define the projection grid dimensions [S1, unofficial].

**Forward Pass Steps:**
1.  **Coordinate Extension:** For each output projection coordinate $\mathbf{k}_{proj} = (k_r, k_c)$, extend it to 3D by setting the third coordinate to zero: $\mathbf{k}_{3D} = (k_c, k_r, 0)$ [S1, unofficial].
2.  **Coordinate Transformation:** Transform the 3D coordinate into the reconstruction frame using the inverse of the rotation matrix $\mathbf{R}$:
    $$ \mathbf{k}_{rec} = \mathbf{R}^{-1} \mathbf{k}_{3D} $$
    where $\mathbf{R}$ is the $3 \times 3$ rotation matrix [S1, unofficial].
3.  **Interpolation:** Sample the 3D reconstruction tensor $F_{rec}$ at $\mathbf{k}_{rec}$ using trilinear or tricubic interpolation [S1, unofficial].
    *   For **trilinear interpolation**, the value is computed from the 8 surrounding voxels using the linear kernel $l(s) = 1 - |s|$ for $|s| \le 1$ [S1, unofficial].
    *   For **tricubic interpolation**, the value is computed from the 64 surrounding voxels using the Catmull-Rom kernel $w(s)$ [S1, unofficial].
4.  **Phase Modulation:** Apply the translation shift $\mathbf{s}$ to the interpolated value:
    $$ P(\mathbf{k}_{proj}) = F_{rec}(\mathbf{k}_{rec}) \cdot e^{-i2\pi\mathbf{k}_{proj}\cdot\mathbf{s}} $$
    where $\mathbf{s}$ is the 2D shift vector [S1, unofficial].

**Backward Pass Steps:**
1.  **Shift Gradient:** Compute the gradient with respect to the shift vector $\mathbf{s}$:
    $$ \frac{\partial P}{\partial \mathbf{s}} = -i2\pi\mathbf{k}_{proj}P(\mathbf{k}_{proj}) $$
    [S1, unofficial].
2.  **Rotation Gradient:** Compute the gradient with respect to the rotation matrix elements $R_{ij}$ using the chain rule:
    $$ \frac{\partial P}{\partial R_{ij}} = \frac{\partial F_{rec}(\mathbf{k}_{rec})}{\partial \mathbf{k}_{rec}} \cdot \frac{\partial \mathbf{k}_{rec}}{\partial R_{ij}} $$
    The term $\frac{\partial \mathbf{k}_{rec}}{\partial R_{ij}}$ is derived from the analytical derivative of the matrix inverse $\mathbf{R}^{-1}$ [S1, unofficial].
3.  **Spatial Gradients:** Compute the gradient of the interpolated value with respect to the coordinates $\mathbf{k}_{rec} = (d, r, c)$.
    *   For **trilinear interpolation**, the spatial derivatives are computed using the derivatives of the linear kernel $l'(s) = \text{sign}(s)$ for $|s| < 1$:
        $$ \frac{\partial F}{\partial d} = \sum_{i=0}^1 \sum_{j=0}^1 \sum_{k=0}^1 p_{ijk} \cdot l'(d_f - i) \cdot l(r_f - j) \cdot l(c_f - k) $$
        $$ \frac{\partial F}{\partial r} = \sum_{i=0}^1 \sum_{j=0}^1 \sum_{k=0}^1 p_{ijk} \cdot l(d_f - i) \cdot l'(r_f - j) \cdot l(c_f - k) $$
        $$ \frac{\partial F}{\partial c} = \sum_{i=0}^1 \sum_{j=0}^1 \sum_{k=0}^1 p_{ijk} \cdot l(d_f - i) \cdot l(r_f - j) \cdot l'(c_f - k) $$
        where $p_{ijk}$ are the sample weights and $d_f, r_f, c_f$ are the fractional coordinates [S1, unofficial].
    *   For **tricubic interpolation**, the spatial derivatives use the derivative of the cubic kernel $w'(s)$:
        $$ \frac{\partial F}{\partial d} = \sum_{i=-1}^2 \sum_{j=-1}^2 \sum_{k=-1}^2 p_{ijk} \cdot w'(d_f - i) \cdot w(r_f - j) \cdot w(c_f - k) $$
        $$ \frac{\partial F}{\partial r} = \sum_{i=-1}^2 \sum_{j=-1}^2 \sum_{k=-1}^2 p_{ijk} \cdot w(d_f - i) \cdot w'(r_f - j) \cdot w(c_f - k) $$
        $$ \frac{\partial F}{\partial c} = \sum_{i=-1}^2 \sum_{j=-1}^2 \sum_{k=-1}^2 p_{ijk} \cdot w(d_f - i) \cdot w(r_f - j) \cdot w'(c_f - k) $$
        [S1, unofficial].
4.  **Accumulation:** Accumulate the reconstruction gradients into the 3D volume tensor at the transformed coordinates $\mathbf{k}_{rec}$ using transposed interpolation operations [S1, unofficial].

**Pseudocode:**
```python
import torch

def forward_projection_3d_to_2d(F_rec, R, s=None, Hout=None, Wout=None):
    """
    F_rec: [B, D, H, W/2+1] (Complex tensor stored as real/imag pairs or complex dtype)
    R: [B, P, 3, 3]
    s: [B, P, 2] (Optional)
    Hout, Wout: Output projection dimensions
    Returns: [B, P, Hout, Wout]
    """
    B, D, H, W_half = F_rec.shape[:4]
    P = R.shape[1]
    if Hout is None: Hout = H
    if Wout is None: Wout = W_half * 2 - 1
    
    # 1. Generate 2D projection coordinates (kr, kc)
    kr = torch.arange(Hout).float().view(1, 1, -1, 1).expand(B, P, Hout, Wout)
    kc = torch.arange(Wout).float().view(1, 1, 1, -1).expand(B, P, Hout, Wout)
    
    # 2. Extend to 3D: k_3D = (kc, kr, 0)
    k_3d = torch.stack([kc, kr, torch.zeros_like(kr)], dim=-1)  # [B, P, Hout, Wout, 3]
    
    # 3. Transform to reconstruction frame: k_rec = R^-1 @ k_3D
    R_inv = torch.inverse(R)  # [B, P, 3, 3]
    k_3d_flat = k_3d.view(B, P, -1, 3)  # [B, P, N, 3]
    k_rec_flat = torch.matmul(R_inv, k_3d_flat.permute(0, 1, 3, 2)).permute(0, 1, 3, 2)  # [B, P, N, 3]
    k_rec = k_rec_flat.view(B, P, Hout, Wout, 3)
    
    # 4. Trilinear Interpolation
    d_f, r_f, c_f = k_rec[..., 0], k_rec[..., 1], k_rec[..., 2]
    d_i, r_i, c_i = torch.floor(d_f).long(), torch.floor(r_f).long(), torch.floor(c_f).long()
    # Clamp to valid voxel indices [G]
    d_i = torch.clamp(d_i, 0, D - 1)
    r_i = torch.clamp(r_i, 0, H - 1)
    c_i = torch.clamp(c_i, 0, W_half - 1)
    
    # Gather 8 neighbors
    neighbors = F_rec[:, d_i, r_i, c_i]  # [B, P, N, 8]
    # Linear kernel weights
    w_d = 1.0 - torch.abs(d_f - d_i.float())
    w_r = 1.0 - torch.abs(r_f - r_i.float())
    w_c = 1.0 - torch.abs(c_f - c_i.float())
    # Combine weights via outer product
    weights = torch.einsum('n,ni,nj,nk->nijk', torch.ones_like(w_d), w_d, w_r, w_c)
    weights = weights.view(B, P, Hout, Wout, 8)
    F_interp = torch.sum(neighbors * weights, dim=-1)  # [B, P, Hout, Wout]
    
    # 5. Phase Modulation
    if s is not None:
        phase = -2.0 * torch.pi * (kr * s[..., 0, None, None] + kc * s[..., 1, None, None])
        exp_phase = torch.polar(torch.ones_like(phase), phase)
        F_interp = F_interp * exp_phase
        
    return F_interp

def compute_gradients(F_rec, R, s, k_rec, grad_out):
    """
    Computes gradients w.r.t F_rec, R, and s as defined in the backward pass.
    grad_out: [B, P, Hout, Wout] gradient from upstream loss.
    """
    B, D, H, W_half = F_rec.shape[:4]
    P = R.shape[1]
    
    # Shift Gradient: ∂P/∂s = -i2π k_proj P(k_proj)
    if s is not None:
        kr = k_rec[..., 1]
        kc = k_rec[..., 0]
        P_val = F_rec[:, torch.floor(k_rec[..., 0]).long(), torch.floor(k_rec[..., 1]).long(), torch.floor(k_rec[..., 2]).long()]
        grad_s = -1j * 2.0 * torch.pi * (kr * P_val + kc * P_val) * grad_out
    else:
        grad_s = None
        
    # Spatial Gradients (Trilinear example)
    d_f, r_f, c_f = k_rec[..., 0], k_rec[..., 1], k_rec[..., 2]
    d_i, r_i, c_i = torch.floor(d_f).long(), torch.floor(r_f).long(), torch.floor(c_f).long()
    d_i = torch.clamp(d_i, 0, D - 1)
    r_i = torch.clamp(r_i, 0, H - 1)
    c_i = torch.clamp(c_i, 0, W_half - 1)
    
    # Derivative kernels
    l = lambda s: 1.0 - torch.abs(s)
    l_prime = lambda s: torch.sign(s)
    
    # Accumulate gradients into F_rec via transposed interpolation [G]
    grad_F = torch.zeros_like(F_rec)
    for i in range(2):
        for j in range(2):
            for k in range(2):
                w_d = l_prime(d_f - d_i.float()) if i == 0 else l(d_f - d_i.float())
                w_r = l_prime(r_f - r_i.float()) if j == 0 else l(r_f - r_i.float())
                w_c = l_prime(c_f - c_i.float()) if k == 0 else l(c_f - c_i.float())
                contrib = grad_out * w_d * w_r * w_c
                grad_F[:, d_i+i, r_i+j, c_i+k] += contrib
                
    # Rotation Gradient: ∂P/∂R_ij = (∂F/∂k_rec) · (∂k_rec/∂R_ij)
    # ∂k_rec/∂R_ij is computed from the analytical derivative of R^-1 [G]
    # Accumulated via chain rule extension [S1, unofficial]
    
    return grad_F, grad_s
```

## Background
The method is based on the Central Slice Theorem, which states that the 1D Fourier transform of a projection of a 2D object is a slice through the 2D Fourier transform of the object. In 3D, the 2D Fourier transform of a projection is a central slice through the 3D Fourier transform of the volume [S1, unofficial]. It is used in differentiable tomographic reconstruction pipelines [S1, unofficial].
