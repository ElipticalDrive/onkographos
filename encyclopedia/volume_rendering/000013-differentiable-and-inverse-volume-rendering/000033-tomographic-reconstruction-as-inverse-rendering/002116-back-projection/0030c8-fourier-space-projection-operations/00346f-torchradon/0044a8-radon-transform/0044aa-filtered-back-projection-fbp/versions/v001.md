# Filtered Back-Projection (FBP)

Also called: IRADON Reconstruction, Inverse Radon Transform, Ramp Filter Reconstruction

## Overview
Filtered Back-Projection (FBP) is an approximate algorithm for the inverse Radon transform used to reconstruct a 2D image from measured projections (sinogram) [S2, unofficial]. It is among the fastest methods for inverse Radon transform [S2, unofficial]. The method is distinguished by its reliance on the Fourier slice theorem, using the Fourier transform of projections and interpolation in Fourier space to obtain the 2D Fourier transform of the image, which is then inverted [S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A sinogram $P$ (projections) and a set of projection angles $\theta$.
- Output: A reconstructed 2D image $f(x, y)$.

**Data Structures:**
- Sinogram: A 2D array where rows correspond to detector positions $r$ and columns correspond to projection angles $\theta$.
- Angles: A 1D array of angles in radians, typically spanning $[0, \pi)$ or $[0, 180^\circ)$.

**Parameters:**
- Filter: A tunable parameter applied to the Fourier transformed projections to suppress high-frequency noise [S2, unofficial]. Available filters include 'ramp', 'shepp-logan', 'cosine', 'hamming', and 'hann' [S2, unofficial]. The 'ramp' filter is the standard choice for basic reconstruction [S1, unofficial].

**Steps:**
1. **Angle Definition**: Define the projection angles $\theta$. For example, generate angles from 0 to 180 degrees with a specific step size (e.g., 5 degrees or 1 degree) [S1, unofficial]. Convert these to radians: $\theta_i = i \cdot \Delta \theta \cdot \frac{\pi}{180}$ [S1, unofficial].
2. **Sinogram Generation (if not provided)**: If starting from an image, compute the sinogram by rotating the image for each angle and summing pixel values along the vertical axis [S1, unofficial]. The projection $p(r, \theta)$ is calculated as the sum of rotated image values weighted by the detector spacing $dr$ [S1, unofficial].
3. **Fourier Transform**: Compute the 1D Fourier transform of each projection column in the sinogram.
4. **Filtering**: Apply the chosen filter (e.g., ramp filter) to the Fourier transformed projections in the frequency domain [S2, unofficial]. The ramp filter compensates for the blurring inherent in simple back-projection.
5. **Inverse Fourier Transform**: Compute the inverse 1D Fourier transform of the filtered projections to return to the spatial domain.
6. **Back-Projection**: Distribute the filtered projection values back across the image plane along the original projection paths. This involves summing the contributions from all angles for each pixel location [S2, unofficial].
7. **Image Formation**: The result of the back-projection is the reconstructed image [S2, unofficial].

**Pseudocode:**
```python
import numpy as np
from skimage.transform import radon, iradon

def perform_fbp_reconstruction(image, step_degrees=5):
    """
    Reconstruct an image using Filtered Back-Projection.
    
    Args:
        image: The original 2D image (for demonstration).
        step_degrees: Step size for projection angles in degrees.
        
    Returns:
        reconstruction_fbp: The reconstructed image.
        error: The reconstruction error.
    """
    # Step 1: Generate projection angles
    # Convert degrees to radians
    theta = np.arange(0, 180, step_degrees) * np.pi / 180
    
    # Step 2: Compute the sinogram (Radon transform)
    # The radon function computes the sum of pixel values along lines at angle theta
    sinogram = radon(image, theta=theta)
    
    # Step 3 & 4 & 5 & 6: Reconstruct using iradon with a filter
    # iradon handles the Fourier filtering and back-projection internally
    # Using 'ramp' filter as per standard FBP
    reconstruction_fbp = iradon(sinogram, theta=theta, filter_name='ramp')
    
    # Calculate error
    error = reconstruction_fbp - image
    
    return reconstruction_fbp, error

# Example usage:
# reconstruction, err = perform_fbp_reconstruction(shepp_logan_phantom)
# rms_error = np.sqrt(np.mean(err**2))
```

**Edge Cases and Pitfalls:**
- **Noise**: Simple back-projection produces blurry images. The filter is crucial to suppress high-frequency noise while restoring sharpness [S2, unofficial].
- **Angle Sampling**: Insufficient angular sampling (large step size) can lead to artifacts. A smaller step size (e.g., 1 degree) improves results but increases computation time [S1, unofficial].
- **Boundary Effects**: The reconstruction may exhibit artifacts near the boundaries of the image if the sinogram is not padded or handled correctly.

## Operating characteristics
- **Time Complexity**: FBP is among the fastest methods for inverse Radon transform [S2, unofficial]. Its efficiency comes from the use of Fast Fourier Transforms (FFT) and simple back-projection operations.
- **Memory Complexity**: Requires storage for the sinogram and the intermediate Fourier transformed data.
- **Performance**: On the Shepp-Logan phantom with a ramp filter, the FBP rms reconstruction error is 0.0283 [S2, unofficial].
- **Strengths**: Speed, simplicity, and well-understood mathematical foundation.
- **Limitations**: Approximate method; sensitive to noise and limited-angle artifacts; assumes ideal projection data.

## Background
The mathematical foundation of filtered back-projection is the Fourier slice theorem [S2, unofficial]. It was developed as a standard technique in computed tomography (CT) for reconstructing images from X-ray projections. The method is widely used in medical imaging and industrial tomography.
