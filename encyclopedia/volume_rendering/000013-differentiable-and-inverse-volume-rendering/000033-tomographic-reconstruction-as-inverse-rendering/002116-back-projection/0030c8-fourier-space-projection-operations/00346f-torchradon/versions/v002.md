# TorchRadon

Also called: Differentiable Radon Transform, Implementation Details (TorchRadon), TorchRadon library

## Overview
TorchRadon is a PyTorch-integrated library providing differentiable forward and backward Radon projection operators for 2D and 3D volumes [S2, unofficial]. It solves the problem of computing line integrals (projections) and their adjoints (backprojections) within a deep learning pipeline, enabling gradient-based optimization for tomographic reconstruction [S1, unofficial]. It distinguishes itself by offering high-performance GPU-accelerated routines with linear and cubic interpolation, supporting both parallel-beam and fan-beam geometries, and allowing end-to-end backpropagation through the projection operations [S2, unofficial].

## How it works
**Inputs and Outputs:**
- **Forward Projection:** Input is a volume tensor $x$ (shape $[N, C, H, W]$ for 2D or $[N, C, D, H, W]$ for 3D) and projection parameters (angles, detector geometry). Output is a sinogram tensor $y$ representing the line integrals.
- **Backward Projection:** Input is a sinogram tensor $y$ and the same projection parameters. Output is a backprojected volume tensor $\hat{x}$.

**Data Structures:**
The library uses standard PyTorch tensors. The geometry is defined by:
- `angles`: Array of sampling angles.
- `source_distance`: Distance from X-ray source to object center.
- `det_distance`: Distance from detector to object center.
- `det_count`: Number of detector pixels.
- `det_spacing`: Spacing between detector pixels.

**Parameters:**
- **Interpolation:** Linear or Cubic. Cubic provides higher accuracy but is more computationally expensive [S2, unofficial].
- **Geometry:** Parallel-beam (default) or Fan-beam [S2, unofficial].
- **Angles:** Equally spaced in $[0, \pi)$ for parallel-beam or $[0, 2\pi)$ for fan-beam [S2, unofficial].

**Steps:**
1. Initialize the Radon operator with volume size, angles, and geometry parameters.
2. Perform forward projection: $y = A x$, where $A$ is the projection matrix.
3. Perform backward projection: $\hat{x} = A^T y$, where $A^T$ is the adjoint matrix.
4. Gradients are computed automatically via PyTorch's autograd engine during backpropagation [S1, unofficial].

**Pseudocode:**
```python
import torch
import numpy as np
from torchradon import Radon, RadonFanbeam

# Example: Parallel Beam
angles = np.linspace(0, np.pi, 512, endpoint=False)
radon = Radon(512, angles, interp='linear') # or 'cubic'
x = torch.randn(1, 1, 512, 512) # Batch, Channel, Height, Width

# Forward Projection
sino = radon.forward(x)

# Backward Projection
bp = radon.backprojection(sino)

# Example: Fan Beam
angles_fb = np.linspace(0, 2 * np.pi, 512, endpoint=False)
radon_fb = RadonFanbeam(512, angles_fb, source_distance=512, det_distance=512)
sino_fb = radon_fb.forward(x)
bp_fb = radon_fb.backprojection(sino_fb)
```

**Edge Cases and Pitfalls:**
- **Boundary Conditions:** Rays passing outside the object volume should be handled (typically zero-filled) [S2, unofficial].
- **Precision:** Floating-point errors accumulate in backprojection; cubic interpolation reduces artifacts compared to linear [S2, unofficial].
- **Detector Coverage:** Ensure `det_spacing` and `det_count` are chosen such that rays cover the entire object [S2, unofficial].

## Subtopics

### [Radon Transform](11306-radon-transform.md)
The process of generating a sinogram by rotating the image and summing pixel values along the vertical axis for each rotation angle. It is the core forward operator implemented by TorchRadon for parallel-beam geometry.

### Fan-Beam Radon Transform
Computes Radon transforms for fan-beam geometry where X-rays originate from a point source. It is chosen when simulating realistic CT scanner geometries rather than idealized parallel beams. Parameters include `source_distance` (default 512) and `det_distance` (default equals `source_distance`). Angles are equally spaced in $[0, 2\pi)$. Relative error compared to Astra Toolbox is $8.34 \cdot 10^{-4}$ for forward projection and $4.84 \cdot 10^{-5}$ for backprojection [S2, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
- Time complexity is proportional to the number of voxels and detector pixels, optimized for GPU execution [S2, unofficial].
- Memory usage scales with the volume size and sinogram dimensions [S2, unofficial].

**Measured Performance:**
- On a $512 \times 512$ phantom, TorchRadon's forward projection has a relative error of $8.34 \cdot 10^{-4}$ and backprojection has $4.84 \cdot 10^{-5}$ compared to the Astra Toolbox [S2, unofficial].
- Cubic interpolation is slower than linear but provides higher accuracy [S2, unofficial].

**Strengths and Limitations:**
- **Strengths:** Differentiable, GPU-accelerated, supports multiple interpolation methods and geometries, easy integration with PyTorch [S1, unofficial][S2, unofficial].
- **Limitations:** Accuracy depends on interpolation method; fan-beam geometry may have higher error than parallel-beam [S2, unofficial].

**When to Use:**
- Use for differentiable tomographic reconstruction, neural network-based image reconstruction, or sensitivity analysis in CT simulations [S1, unofficial][S2, unofficial].
- Avoid if non-differentiable, CPU-only, or high-precision non-iterative reconstruction (like FBP with specific filters) is required without deep learning integration [S2, unofficial].

## Background
TorchRadon was introduced as a fast differentiable library for computed tomography routines in PyTorch [S2, unofficial]. It enables the computation and differentiation of Radon forward and backward projections, which correspond to matrix-vector products with $A$ and $A^T$ respectively [S1, unofficial]. The library supports filtered backprojection (FBP) with filters such as Ram-Lak, Shepp-Logan, cosine, Hamming, and Hann, implemented in the frequency domain [S2, unofficial]. It is widely used in research involving generative models for tomography and differentiable inverse problems [S1, unofficial].
