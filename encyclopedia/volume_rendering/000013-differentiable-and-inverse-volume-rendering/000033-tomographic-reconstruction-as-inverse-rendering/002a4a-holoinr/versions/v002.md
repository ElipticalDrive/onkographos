# HoloINR

Also called: Implicit Neural Representation for Near-Field Holotomography

## Overview
HoloINR solves the coupled inverse problem of near-field holotomography using Implicit Neural Representations (INRs) [S1, unofficial]. It explicitly models near-field physics via Fresnel propagation between the object and the detector, rather than assuming far-field propagation [S1, unofficial].

## How it works
**Inputs:** Holographic measurement data stored in HDF5 format containing `angles` (list of floating-point numbers in $[0, \pi)$) and `data` (holographic intensity measurements, where the first axis corresponds to angles and the last two axes correspond to the detector image) [S1, unofficial].

**Outputs:** A trained Implicit Neural Representation (INR) model that maps 3D spatial coordinates to complex-valued scattering potential or density, representing the reconstructed volume [S1, unofficial].

**Data Structures:**
The geometry and physics parameters are managed by a `ConeBeam` class with the following fields [S1, unofficial]:
*   `energy` (float): X-ray energy.
*   `_px_size` (float): Base pixel size.
*   `active_px_size` (float): Effective pixel size after downsampling.
*   `z02` (float): Source-to-detector distance ($z_{02}$).
*   `z01` (float): Source-to-object distance ($z_{01}$).

**Algorithm Steps:**

1.  **Ray point sampling:** Compute normalized t-values along the ray, interpolate between near and far bounds to get z-values, then compute 3D points as $pts = rays_o + rays_d \cdot z\_vals$ [S1, unofficial]. Clamp points to the bounding box $[-bound, bound]$ [S1, unofficial].
2.  **Chunked network evaluation:** Split rays into batches of size `netchunk` [S1, unofficial]. For each chunk, pass points to the INR model, sum the output over the z-dimension (`dim=-2`), and concatenate results along the ray dimension [S1, unofficial].
3.  **Segment distance weighting:** Compute segment distances as $dists = (z\_vals[..., 1:] - z\_vals[..., :-1]) \cdot ||rays_d||$ [S1, unofficial]. Append $1e-10$ to the last segment to prevent zero-length division [S1, unofficial].
4.  **Accumulation:** Compute the accumulated projection as $acc = \sum (raw \cdot dists, dim=-2)$, where `raw` is the network output at each sample point [S1, unofficial].
5.  **Fresnel propagation:** Propagate the complex field from the object plane to the detector plane [S1, unofficial]. Calculate the Fresnel number $Fr = \frac{dx_{eff}^2}{\lambda z_{eff}}$ where $dx_{eff} = \frac{active\_px\_size}{M}$, $z_{eff} = \frac{z_{12}}{M}$, $M = \frac{z_{12} + z_{01}}{z_{01}}$, and $z_{12} = z_{02} - z_{01}$ [S1, unofficial].
6.  **Loss computation:** Compare the simulated hologram with the measured holographic data [S1, unofficial].
7.  **Regularization:** Apply Isotropic Total Variation (TV) regularization to the volume representation [S1, unofficial]. Compute finite differences $dx, dy, dz$ along the x, y, and z axes [S1, unofficial]. The TV loss is calculated as $TV = \text{mean}(\sqrt{dx^2 + dy^2 + dz^2 + 1e-6})$ [S1, unofficial].
8.  **Optimization:** Update the INR weights using an optimizer (e.g., Adam) to minimize the total loss [S1, unofficial]. Apply `downsampling` factors (typically 4 or 8) to `n_samples` during optimization to reduce computation [S1, unofficial].

**Pseudocode:**

import torch
import torch.nn as nn

class HoloINRModel(nn.Module):
    def __init__(self, in_dim, hidden_dim, num_layers, skips, bound, last_activation):
        super().__init__()
        self.bound = bound
        self.in_dim = in_dim
        self.skips = set(skips)
        self.layers = nn.ModuleList([nn.Linear(self.in_dim, hidden_dim)])
        for i in range(1, num_layers - 1):
            if i in self.skips:
                self.layers.append(nn.Linear(hidden_dim + self.in_dim, hidden_dim))
            else:
                self.layers.append(nn.Linear(hidden_dim, hidden_dim))
        self.layers.append(nn.Linear(hidden_dim, 1))
        self.activations = nn.ModuleList([nn.LeakyReLU() for _ in range(num_layers - 1)])
        self.last_activation = last_activation

    def forward(self, x):
        x = x / self.bound
        h = x
        for i, layer in enumerate(self.layers):
            h = layer(h)
            if i < len(self.layers) - 1:
                if i in self.skips:
                    h = torch.cat([h, x], dim=-1)
                h = self.activations[i](h)
            else:
                if self.last_activation is not None:
                    h = self.last_activation(h)
        return h

def render_rays(rays_o, rays_d, z_vals, model, netchunk=1024):
    pts = rays_o.unsqueeze(-2) + rays_d.unsqueeze(-2) * z_vals.unsqueeze(-1)
    pts = torch.clamp(pts, -model.bound, model.bound)
    num_rays = rays_o.shape[0]
    all_raw = []
    for i in range(0, num_rays, netchunk):
        chunk_pts = pts[i:i+netchunk]
        raw = model(chunk_pts)
        all_raw.append(raw)
    raw = torch.cat(all_raw, dim=0)
    dists = z_vals[..., 1:] - z_vals[..., :-1]
    dists = dists * torch.norm(rays_d, dim=-1, keepdim=True)
    last_dist = torch.ones_like(dists[..., :1]) * 1e-10
    dists = torch.cat([dists, last_dist], dim=-1)
    acc = torch.sum(raw * dists, dim=-2)
    return acc

def compute_tv_loss(volume_grid):
    dx = volume_grid[:, 1:, :] - volume_grid[:, :-1, :]
    dy = volume_grid[:, :, 1:] - volume_grid[:, :, :-1]
    dz = volume_grid[1:, :, :] - volume_grid[:-1, :, :]
    tv = torch.mean(torch.sqrt(dx**2 + dy**2 + dz**2 + 1e-6))
    return tv

def optimize_holotomography(data, angles, model, optimizer, netchunk=1024, num_grad_samples=1000, downsampling=4):
    effective_n_samples = model.n_samples // downsampling
    for angle, hologram in zip(angles, data):
        # Ray generation: compute rays_o, rays_d, z_vals from geometry and angle
        rays_o, rays_d, z_vals = generate_rays(angle, model.geometry)
        if num_grad_samples < len(rays_o):
            indices = torch.randperm(len(rays_o))[:num_grad_samples]
            rays_o, rays_d, z_vals = rays_o[indices], rays_d[indices], z_vals[indices]
        acc = render_rays(rays_o, rays_d, z_vals, model, netchunk)
        # Fresnel propagation: apply frequency-domain phase shift using fresnel_number
        simulated_hologram = fresnel_propagate(acc, model.fresnel_number)
        loss = torch.nn.functional.mse_loss(simulated_hologram, hologram)
        tv_loss = compute_tv_loss(model.volume_grid)
        total_loss = loss + model.lambda_tv * tv_loss
        optimizer.zero_grad()
        total_loss.backward()
        optimizer.step()

**Parameters:**
*   `netchunk`: Controls VRAM usage by limiting the number of rays processed per network forward pass. Default: 1024 [S1, unofficial].
*   `num_grad_samples`: Maximum number of rays to compute gradients for during the render pass. Default: 1000 [S1, unofficial].
*   `downsampling`: Factor applied to `n_samples` during optimization to reduce computation. Typical values: 4 or 8 [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Zero-distance numerical instability:** The last segment distance is explicitly set to $1e-10$ to prevent division by zero or NaN propagation when computing $acc = \sum (raw \cdot dists)$ [S1, unofficial].
*   **Memory overflow during rendering:** If VRAM is exhausted, decrease `netchunk` or `num_grad_samples` to reduce per-pass ray counts and gradient samples [S1, unofficial].
*   **NaN/Inf propagation:** The render function explicitly checks for NaN or Inf values in the accumulated output and prints a warning if detected [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the number of rays, samples per ray, and network depth [S1, unofficial]. Chunking (`netchunk`) limits parallelism but controls memory [S1, unofficial]. Downsampling reduces the number of samples/rays, speeding up convergence at the cost of resolution [S1, unofficial].
*   **Memory Complexity:** Proportional to the number of parameters in the INR and the batch size (`netchunk`) [S1, unofficial].
*   **Performance:** Tested on Nvidia H100/H200 GPUs [S1, unofficial]. Performance is significantly slower on older GPUs [S1, unofficial].
*   **Strengths:** Resolution-independent reconstruction, natural handling of near-field wave optics (Fresnel propagation), and smooth volume representation [S1, unofficial].
*   **Limitations:** High computational cost, sensitive to VRAM limits, requires careful tuning of `netchunk` and `downsampling` [S1, unofficial].
*   **When to use:** Near-field holotomography where wave optics effects are significant and high-resolution, smooth reconstructions are desired [S1, unofficial].

## Background
HoloINR was introduced by Johannes Gruen, Sebastian Eberle, Imke Greving, Silja Flenner, Martin Burger, Christian G. Schroer, and Johannes Hagemann in 2026 at the IEEE International Conference on Acoustics, Speech and Signal Processing (ICASSP) [S1, unofficial]. The method addresses the limitations of traditional tomography in near-field setups by integrating holographic phase retrieval with neural implicit representations [S1, unofficial].
