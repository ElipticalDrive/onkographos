# 1D Slice Reconstruction with Piecewise Constant Model

Also called: 1D Piecewise Constant Slice Reconstruction, Constrained Minimization for 1D Slice Reconstruction

## Overview
This method reconstructs a 2D slice from parallel projections by modeling the slice as a 1D piecewise constant function defined by $n$ parameters [S1, unofficial]. It solves for these parameters by minimizing a constrained quadratic criterion that compares model projections against measured data [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Measured parallel projection data $p$ for a specific 2D slice.
*   **Output:** A vector of $n$ parameters defining the 1D piecewise constant model of the slice.

**Data Structures:**
The model represents the 2D slice as a function constant along one axis and piecewise constant along the orthogonal axis [S1, unofficial].
*   **Model Parameters:** A vector $\theta \in \mathbb{R}^n$ containing the values for each of the $n$ zones [S1, unofficial].
*   **Zones:** The domain is partitioned into $n$ contiguous zones [S1, unofficial].

**Steps:**
1.  **Model Definition:** Define the 1D piecewise constant model $f(x; \theta)$ for the slice, where $\theta$ contains $n$ parameters representing the values of $n$ zones [S1, unofficial].
2.  **Forward Projection:** Compute the theoretical projection $\hat{p}(\theta)$ of the model $f(x; \theta)$ using parallel ray geometry [S1, unofficial].
3.  **Criterion Formulation:** Construct a quadratic criterion $J(\theta)$ measuring the difference between the measured data $p$ and the model projection $\hat{p}(\theta)$ [S1, unofficial]:
    $$
    J(\theta) = \| p - \hat{p}(\theta) \|^2
    $$
4.  **Regularization:** Since the quadratic criterion $J(\theta)$ is non-differentiable due to the piecewise constant nature of the model, apply one of three proposed regularization techniques to handle this non-differentiability [S1, unofficial].
5.  **Constrained Minimization:** Solve for the optimal parameters $\theta^*$ by minimizing the regularized criterion subject to constraints [S1, unofficial]:
    $$
    \min_\theta J_{reg}(\theta) \quad \text{subject to constraints}
    $$
6.  **Noise Analysis (Optional):** Compute the covariance matrix of the estimated parameter vector $\theta$ to analyze sensitivity to noise in the input data [S1, unofficial].

## Background
This method originates from research on tomographic reconstruction [S1, unofficial]. The work first studied the reconstruction of a planar slice using a 1D model described by zones with $n$ parameters [S1, unofficial]. The approach was part of a broader investigation into modeling objects for reconstruction, which later extended to 3D models characterized by separating surfaces and density fields [S1, unofficial]. The specific techniques for regularization and noise analysis were proposed to address the challenges of non-differentiability and noise sensitivity in this constrained minimization framework [S1, unofficial].
