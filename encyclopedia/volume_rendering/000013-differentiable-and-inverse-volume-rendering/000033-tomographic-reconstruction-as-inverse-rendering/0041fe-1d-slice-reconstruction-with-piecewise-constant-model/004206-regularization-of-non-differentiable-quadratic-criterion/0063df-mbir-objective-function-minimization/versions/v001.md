# MBIR Objective Function Minimization

Also called: Conventional MBIR, MBIR, MBIR Reconstruction

## Overview
Conventional Model-Based Iterative Reconstruction (MBIR) solves the inverse problem of reconstructing a volume $\mathbf{f}$ from measured projection data $\mathbf{p}$ by minimizing a quadratic objective function [S2]. Unlike advanced methods that explicitly model and deblur motion or system blur, conventional MBIR relies on photon weighting within the forward model to handle noise and blur [S1]. It is distinguished from its parent method, Regularization of Non-Differentiable Quadratic Criterion, by its specific use of a simple L2-norm regularization term and gradient descent solver, rather than non-differentiable penalties or coordinate descent [S2][S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Measured projection data vector $\mathbf{p}$, forward projection operator $\mathbf{R}_s$, regularization parameter $\beta$.
*   **Output:** Reconstructed volume vector $\mathbf{f}$.

**Data Structures:**
*   $\mathbf{f}$: A vector representing the volume voxels. In typical implementations, this is initialized as a zero vector [S2].
*   $\mathbf{p}$: A vector of projection measurements. In the reference implementation, this corresponds to the projection of a $512 \times 512$ image using a specific forward model $\mathbf{R}_r$ with 8 times oversampling followed by $8 \times 8$ bin averaging [S2].
*   $\mathbf{R}_s$: The forward projection matrix/operator mapping the volume to the projection space [S2].

**Objective Function:**
The method minimizes the following convex objective function $\Psi(\mathbf{f})$ [S2]:

$$
\Psi(\mathbf{f}) = \frac{1}{2} \|\mathbf{R}_s \mathbf{f} - \mathbf{p}\|_2^2 + \frac{\beta}{2} \|\mathbf{f}\|_2^2
$$

Where:
*   $\|\cdot\|_2$ denotes the L2 norm (Euclidean norm).
*   $\mathbf{R}_s \mathbf{f}$ is the estimated projection of the current volume estimate.
*   $\mathbf{p}$ is the measured projection data.
*   $\beta$ is the regularization parameter.

**Parameters:**
*   $\beta$: Set to $2 \times 10^{-2}$ [S2]. This value ensures the strong convexity of the cost function $\Psi$, which guarantees the uniqueness of the minimizer [S2].
*   Iteration Count: 400 iterations are used for computing the baseline reconstruction [S1].

**Algorithm Steps:**
1.  **Initialization:** Initialize the volume vector $\mathbf{f}$ to the zero vector [S2].
2.  **Gradient Calculation:** Compute the gradient of the objective function $\Psi(\mathbf{f})$ with respect to $\mathbf{f}$. The gradient is given by:
    $$
    \nabla \Psi(\mathbf{f}) = \mathbf{R}_s^T (\mathbf{R}_s \mathbf{f} - \mathbf{p}) + \beta \mathbf{f}
    $$
    Where $\mathbf{R}_s^T$ is the adjoint (transpose) of the forward projection operator [S2][G].
3.  **Update:** Update the volume estimate using gradient descent:
    $$
    \mathbf{f}_{new} = \mathbf{f}_{old} - \alpha \nabla \Psi(\mathbf{f}_{old})
    $$
    Where $\alpha$ is the step size (learning rate). [G: The step size $\alpha$ is not explicitly defined in the sources; a standard constant or line-search strategy is implied by "simple gradient descent"].
4.  **Convergence Check:** Repeat steps 2 and 3 until convergence or until the maximum number of iterations (400) is reached [S1][S2].

**Pseudocode:**

```python
def mbir_minimize(p, R_s, R_s_T, beta, max_iterations=400, step_size=1e-3):
    """
    Minimizes the MBIR objective function using gradient descent.
    
    Args:
        p: Vector of measured projection data.
        R_s: Function implementing forward projection (R_s * f).
        R_s_T: Function implementing adjoint projection (R_s^T * r).
        beta: Regularization parameter (default 2e-2).
        max_iterations: Maximum number of iterations (default 400).
        step_size: Learning rate for gradient descent.
        
    Returns:
        f: Reconstructed volume vector.
    """
    # Initialize volume to zero vector
    f = zeros_like(p) # Assuming f has same dimensionality as the volume space, not p. 
                      # [G: Dimensionality of f is determined by the problem setup, not p directly. 
                      # In practice, f is initialized to zeros of size N_voxels.]
    
    # Correct initialization based on standard MBIR practice
    # Let N be the number of voxels.
    N = get_volume_size() # [G: Implementation detail to determine volume size]
    f = zeros(N)
    
    for i in range(max_iterations):
        # Forward projection: estimate projections from current volume
        p_est = R_s(f)
        
        # Compute residual
        residual = p_est - p
        
        # Compute gradient: R_s^T * residual + beta * f
        gradient = R_s_T(residual) + beta * f
        
        # Update volume
        f = f - step_size * gradient
        
    return f
```

**Edge Cases and Pitfalls:**
*   **Blur:** Conventional MBIR produces severely blurred images when applied to data acquired over large angular spans (e.g., $40.17^\circ$) because it lacks a forward model for motion blur [S1].
*   **Convexity:** The choice of $\beta$ is critical for ensuring strong convexity and uniqueness of the solution [S2].

## Subtopics

### MAP/Bayesian Reconstruction
Statistical Bayesian methods treat data and the object as realizations of a random process, using prior knowledge of the object $\mathbf{f}$ from a prior probability law $p(\mathbf{f})$ to increase image quality [S3, unofficial]. The solution is estimated by minimizing a functional with a cost function $c(\mathbf{f}, \mathbf{g})$ [S3, unofficial]. The Maximum A Posteriori (MAP) criterion uses the cost function $c(\mathbf{f}, \mathbf{g}) = 1 - \delta(\mathbf{f}, \mathbf{g})$, where $\delta$ is the Dirac distribution at point $\mathbf{f}$, leading to the solution $\mathbf{f}_{solution} = \arg \max_{\mathbf{f}} p(\mathbf{f} | \text{proj})$ [S3, unofficial]. This approach generalizes the quadratic criterion by incorporating probabilistic priors rather than just L2 regularization [S3, unofficial].

## Operating characteristics
*   **Complexity:** The method involves iterative matrix-vector multiplications with the forward and adjoint projection operators. The complexity per iteration is dominated by the cost of $\mathbf{R}_s$ and $\mathbf{R}_s^T$.
*   **Performance:** In the reference implementation, 400 iterations are required for baseline reconstruction [S1].
*   **Strengths:** Guarantees a unique minimizer due to strong convexity when $\beta > 0$ [S2]. Simple to implement using standard gradient descent [S2].
*   **Limitations:** Produces blurred images for large angular spans due to the lack of motion blur modeling in the forward model [S1]. The simple L2 regularization may not preserve sharp edges as effectively as non-differentiable regularizers (e.g., Total Variation) used in more advanced MBIR variants [S1][S2].
*   **Implementation:** Often implemented using packages like SVMBIR, which use cache-optimized iterative coordinate descent and Markov random field regularization [S1]. Note that the specific "Conventional MBIR" described here uses gradient descent and L2 regularization, whereas SVMBIR's default may differ [S1][S2].

## Background
Conventional MBIR is a baseline reconstruction method used in tomographic imaging, particularly in contexts involving coded exposures or sparse views [S1]. It was used as a comparison baseline in the CodEx framework for joint temporal de-blurring and tomographic reconstruction [S1]. The specific formulation with L2 regularization and gradient descent is detailed in studies on magnification-driven B-spline interpolation [S2].
