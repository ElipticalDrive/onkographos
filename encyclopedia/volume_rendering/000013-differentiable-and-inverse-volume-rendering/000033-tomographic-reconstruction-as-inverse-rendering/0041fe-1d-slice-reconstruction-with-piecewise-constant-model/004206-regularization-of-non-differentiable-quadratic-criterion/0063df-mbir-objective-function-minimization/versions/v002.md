# MBIR Objective Function Minimization

Also called: Conventional MBIR, MBIR, MBIR Reconstruction

## Overview
Conventional Model-Based Iterative Reconstruction (MBIR) solves the inverse problem of reconstructing a volume $\mathbf{f}$ from measured projection data $\mathbf{p}$ by minimizing a quadratic objective function [S2]. Unlike advanced methods that explicitly model and deblur motion or system blur, conventional MBIR does not deblur measured views and instead relies on photon weighting to handle noise and blur [S1]. It is distinguished from its parent method, Regularization of Non-Differentiable Quadratic Criterion, by its specific use of a simple L2-norm regularization term and a gradient descent solver [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** Measured projection data vector $\mathbf{p}$, forward projection operator $\mathbf{R}_s$, regularization parameter $\beta$, and the number of volume voxels $N$ [S2].
*   **Output:** Reconstructed volume vector $\mathbf{f}$ [S2].

**Data Structures:**
*   $\mathbf{f}$: A vector representing the volume voxels, initialized as a zero vector [S2].
*   $\mathbf{p}$: A vector of projection measurements, corresponding to the projection of a $512 \times 512$ image using a forward model $\mathbf{R}_r$ with 8 times oversampling followed by $8 \times 8$ bin averaging [S2].
*   $\mathbf{R}_s$: The forward projection matrix/operator mapping the volume to the projection space [S2].

**Objective Function:**
The method minimizes the following convex objective function $\Psi(\mathbf{f})$ [S2]:

$$
\Psi(\mathbf{f}) = \frac{1}{2} \|\mathbf{R}_s \mathbf{f} - \mathbf{p}\|_2^2 + \frac{\beta}{2} \|\mathbf{f}\|_2^2
$$

Where:
*   $\|\cdot\|_2$ denotes the L2 norm (Euclidean norm) [S2].
*   $\mathbf{R}_s \mathbf{f}$ is the estimated projection of the current volume estimate [S2].
*   $\mathbf{p}$ is the measured projection data [S2].
*   $\beta$ is the regularization parameter [S2].

**Parameters:**
*   $\beta$: Set to $2 \times 10^{-2}$ [S2]. This value ensures the strong convexity of the cost function $\Psi$, which guarantees the uniqueness of the minimizer [S2].
*   Iteration Count: 400 iterations are used for computing the baseline reconstruction [S1].

**Algorithm Steps:**
1.  **Initialization:** Initialize the volume vector $\mathbf{f}$ to the zero vector [S2].
2.  **Gradient Calculation:** Compute the gradient of the objective function $\Psi(\mathbf{f})$ with respect to $\mathbf{f}$ [S2]. The gradient is given by:
    $$
    \nabla \Psi(\mathbf{f}) = \mathbf{R}_s^T (\mathbf{R}_s \mathbf{f} - \mathbf{p}) + \beta \mathbf{f}
    $$
    Where $\mathbf{R}_s^T$ is the adjoint (transpose) of the forward projection operator [S2].
3.  **Update:** Update the volume estimate using gradient descent:
    $$
    \mathbf{f}_{new} = \mathbf{f}_{old} - \alpha \nabla \Psi(\mathbf{f}_{old})
    $$
    Where $\alpha$ is the step size (learning rate) [G: The step size $\alpha$ is not explicitly defined in the sources; a standard constant or line-search strategy is implied by "simple gradient descent"].
4.  **Convergence Check:** Repeat steps 2 and 3 until convergence or until the maximum number of iterations (400) is reached [S1][S2].

**Pseudocode:**

```python
def mbir_minimize(p, R_s, R_s_T, beta, N, max_iterations=400, step_size=1e-3):
    # Initialize volume to zero vector of size N
    f = [0.0] * N
    for _ in range(max_iterations):
        # Forward projection: estimate projections from current volume
        p_est = R_s(f)
        # Compute residual
        residual = [p_est[i] - p[i] for i in range(len(p))]
        # Compute gradient: R_s^T * residual + beta * f
        grad = R_s_T(residual)
        for i in range(N):
            grad[i] = grad[i] + beta * f[i]
        # Update volume
        # [G: step_size is not given in sources; a standard constant or line-search is implied]
        for i in range(N):
            f[i] = f[i] - step_size * grad[i]
    return f
```

**Edge Cases and Pitfalls:**
*   **Blur:** Conventional MBIR produces severely blurred images when applied to data acquired over large angular spans (e.g., $40.17^\circ$) because it lacks a forward model for motion blur [S1].
*   **Convexity:** The choice of $\beta$ is critical for ensuring strong convexity and uniqueness of the solution [S2].

## Subtopics

### [MAP/Bayesian Reconstruction](20222-map-bayesian-reconstruction.md)
MAP/Bayesian Reconstruction is a statistical inverse problem method that incorporates prior knowledge of the object to stabilize the reconstruction and improve image quality. It sets itself apart from standard least-squares or Maximum Likelihood methods by explicitly balancing the likelihood of the observed data against a prior probability distribution, allowing for constraints such as positivity, smoothness, or support.

## Operating characteristics
*   **Complexity:** Not given in the sources.
*   **Performance:** In the reference implementation, 400 iterations are required for baseline reconstruction [S1].
*   **Strengths:** Guarantees a unique minimizer due to strong convexity when $\beta > 0$ [S2]. Simple to implement using standard gradient descent [S2].
*   **Limitations:** Produces blurred images for large angular spans due to the lack of motion blur modeling in the forward model [S1]. The simple L2 regularization may not preserve sharp edges as effectively as non-differentiable regularizers used in more advanced MBIR variants [S1].
*   **Implementation:** Often implemented using packages like SVMBIR, which use cache-optimized iterative coordinate descent and Markov random field regularization [S1]. Note that the specific "Conventional MBIR" described here uses gradient descent and L2 regularization, whereas SVMBIR's default may differ [S1].

## Background
Conventional MBIR is a baseline reconstruction method used in tomographic imaging, particularly in contexts involving coded exposures or sparse views [S1]. It was used as a comparison baseline in the CodEx framework for joint temporal de-blurring and tomographic reconstruction [S1]. The specific formulation with L2 regularization and gradient descent is detailed in studies on magnification-driven B-spline interpolation [S2].
