# Noise Sensitivity Analysis via Covariance Matrix

Also called: Covariance-based Noise Sensitivity, Parameter Noise Analysis

## Overview
This method analyzes the sensitivity of the reconstructed parameter vector to noise present in the input projection data by computing the covariance matrix of the parameters [S1, unofficial]. It builds on [1D Slice Reconstruction with Piecewise Constant Model](10645-1d-slice-reconstruction-with-piecewise-constant-model.md), where a 2D slice is modeled as a 1D piecewise constant function with $n$ parameters, and reconstruction is achieved by minimizing a constrained quadratic criterion [S1, unofficial]. While the parent method solves for the parameters, this analysis quantifies the uncertainty and stability of those solutions in the presence of measurement noise [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: The reconstructed parameter vector $\mathbf{p}$ (of size $n$) obtained from the piecewise constant model, and the covariance matrix $\mathbf{C}$ of this vector [S1, unofficial].
- Output: The covariance matrix $\mathbf{C}$, which characterizes the noise sensitivity of each parameter and their correlations [S1, unofficial].

**Data Structures:**
- $\mathbf{p}$: A 1D array of length $n$, containing the estimated values of the piecewise constant parameters [S1, unofficial].
- $\mathbf{C}$: An $n \times n$ symmetric matrix [G]. The diagonal elements $C_{ii}$ represent the variance of the $i$-th parameter, and off-diagonal elements $C_{ij}$ represent the covariance between parameters $i$ and $j$ [G].

**Steps:**
1. **Reconstruction:** Perform the 1D slice reconstruction to obtain the parameter vector $\mathbf{p}$ by minimizing a constrained quadratic criterion [S1, unofficial]. The criterion is non-differentiable, so regularization techniques are applied [S1, unofficial].
2. **Covariance Determination:** Compute the covariance matrix $\mathbf{C}$ of the parameter vector $\mathbf{p}$ with respect to the noise in the input data [S1, unofficial]. The specific mathematical derivation of $\mathbf{C}$ depends on the linearization of the forward projection model and the noise statistics of the input data, which are not detailed in the provided sources [S1, unofficial].
3. **Sensitivity Analysis:** Use $\mathbf{C}$ to analyze the sensitivity of each parameter [S1, unofficial]. The standard deviation of the $i$-th parameter is $\sigma_i = \sqrt{C_{ii}}$ [S1, unofficial]. High values indicate high sensitivity to noise [S1, unofficial].

**Formulas:**
- $\sigma_i = \sqrt{C_{ii}}$ where $\sigma_i$ is the standard deviation of the $i$-th parameter and $C_{ii}$ is the $i$-th diagonal element of the covariance matrix [S1, unofficial].

**Parameters:**
- Not given in the sources.

**Edge Cases and Pitfalls:**
- The non-differentiability of the quadratic criterion requires regularization [S1, unofficial].
- The sources do not specify how the noise statistics of the input data are modeled or incorporated into the covariance calculation [S1, unofficial].

**Pseudocode:**
```python
import math

def noise_sensitivity_analysis(p, C):
    """
    Analyze noise sensitivity of reconstructed parameters.
    
    Args:
        p: list of floats, reconstructed parameter vector.
        C: list of lists of floats, covariance matrix of the parameters.
        
    Returns:
        std_devs: list of floats, standard deviations of each parameter.
        correlations: list of lists of floats, correlation matrix.
    """
    n = len(p)
    std_devs = [0.0] * n
    for i in range(n):
        std_devs[i] = math.sqrt(C[i][i])
        
    correlations = [[0.0] * n for _ in range(n)]
    for i in range(n):
        for j in range(n):
            denom = std_devs[i] * std_devs[j]
            if denom < 1e-10:
                denom = 1e-10
            correlations[i][j] = C[i][j] / denom
            
    return std_devs, correlations
```

## Subtopics

### Inverse Estimation via Linear Recurrence
Recovers constant absorption ($\sigma$) and source ($q$) parameters from a sequence of intensity measurements by fitting a linear recurrence relation $I_{k+1} = a I_k + b$ [S2, unofficial]. It is chosen when the data consists of a 1D sequence of intensity measurements with known step size $ds$ [S2, unofficial]. The method validates that `intensity.size() >= 3` and `ds > 0` [S2, unofficial]. It calculates sums $S_x, S_y, S_{xx}, S_{xy}$ over $k=0$ to $N-2$ where $N = \text{intensity.size()} - 1$, with $x = I_k$ and $y = I_{k+1}$ [S2, unofficial]. The determinant $D = N S_{xx} - S_x^2$ is computed; if $|D| \le 10^{-14}$, the result is invalid [S2, unofficial]. The coefficients are $a = (N S_{xy} - S_x S_y) / D$ and $b = (S_y - a S_x) / N$ [S2, unofficial]. The absorption is $\sigma = -\ln(a) / ds$ [S2, unofficial]. The source term is $q = b / ds$ if $|1 - a| < 10^{-8}$, otherwise $q = \sigma b / (1 - a)$ [S2, unofficial]. A pitfall is that if $a \notin (0, 1 + 10^{-10})$, the result is invalid [S2, unofficial]. RMSEs for the linear fit and a constant model are also computed [S2, unofficial].

## Background
This method originates from work on tomographic reconstruction from a small number of views [S1, unofficial]. The author proposed analyzing the sensitivity of the parameter vector to noise after determining its covariance matrix, as part of a broader approach involving 1D slice reconstruction with regularization and 3D model construction [S1, unofficial].
