# Gradient Estimation via Filtered Back-Projection

Also called: FBP-based Gradient Estimation, Gradient from Filtered Projections

## Overview
Gradient Estimation via Filtered Back-Projection estimates the spatial derivatives of a volumetric density function directly from filtered projection data, bypassing the intermediate step of reconstructing a 3D rectilinear grid. It differs from grid-based finite difference methods by eliminating interpolation errors associated with sampling a reconstructed volume, as it computes derivatives from the continuous projection functions themselves [S1].

## How it works
**Inputs:**
*   $K$: Number of projection angles $\theta_i$.
*   $Q_{\theta_i}(t)$: The filtered projection data for angle $\theta_i$, where $t$ is the detector coordinate.
*   $(x, y)$: The 2D spatial coordinates of the point at which the gradient is estimated.

**Outputs:**
*   $\tilde{f}_x$: The estimated partial derivative with respect to $x$.
*   $\tilde{f}_y$: The estimated partial derivative with respect to $y$.

**Data Structures:**
*   The filtered projections $Q_{\theta_i}$ are typically stored as 1D arrays or accessed via a filtering kernel. No 3D grid is allocated for the gradient estimation itself.

**Steps:**
1.  For each projection angle $i \in \{1, \dots, K\}$, calculate the projection coordinate $t_i$ corresponding to the point $(x, y)$:
    $$ t_i = x \cos \theta_i + y \sin \theta_i $$
2.  Compute the partial derivative with respect to $x$ ($\tilde{f}_x$) by summing the scaled derivatives of the filtered projections. The derivative of the projection is approximated using Newton's difference quotient with a small offset $\Delta x$:
    $$ \tilde{f}_x = \frac{\pi}{K} \sum_{i=1}^K \lim_{\Delta x \rightarrow 0} \frac{1}{\Delta x} \left( Q_{\theta_i}(t_i + \Delta x \cos \theta_i) - Q_{\theta_i}(t_i) \right) $$
    In practice, $\Delta x$ is chosen as a small value relative to the resolution of the projection data. The term $\cos \theta_i$ scales the derivative because the projection coordinate $t$ changes with $x$ at a rate of $\cos \theta_i$.
3.  Compute the partial derivative with respect to $y$ ($\tilde{f}_y$) analogously:
    $$ \tilde{f}_y = \frac{\pi}{K} \sum_{i=1}^K \lim_{\Delta y \rightarrow 0} \frac{1}{\Delta y} \left( Q_{\theta_i}(t_i + \Delta y \sin \theta_i) - Q_{\theta_i}(t_i) \right) $$
    Here, the derivative is scaled by $\sin \theta_i$.
4.  Higher-order derivatives can be obtained by applying the difference quotient multiple times to the projection data $Q_{\theta_i}$ [S1].

**Pseudocode:**
```python
def estimate_gradient_fbp(x, y, angles, filtered_projections, delta=1e-5):
    """
    Estimate gradients fx and fy using Filtered Back-Projection of derivatives.
    
    Args:
        x, y: Coordinates of the point to evaluate.
        angles: List of projection angles theta_i in radians.
        filtered_projections: List of 1D arrays Q_theta_i, indexed by angle.
        delta: Small offset for finite difference approximation.
        
    Returns:
        fx, fy: Estimated partial derivatives.
    """
    K = len(angles)
    sum_fx = 0.0
    sum_fy = 0.0
    
    for i in range(K):
        theta = angles[i]
        Q = filtered_projections[i]
        
        # Calculate base projection coordinate t_i
        t_i = x * cos(theta) + y * sin(theta)
        
        # Calculate offset coordinates for finite difference
        # For fx: shift t by delta * cos(theta)
        t_x = t_i + delta * cos(theta)
        
        # For fy: shift t by delta * sin(theta)
        t_y = t_i + delta * sin(theta)
        
        # Interpolate filtered projection values at t_i, t_x, t_y
        # Q is a 1D function/array; assume linear interpolation or similar
        q_base = interpolate(Q, t_i)
        q_x = interpolate(Q, t_x)
        q_y = interpolate(Q, t_y)
        
        # Compute scaled derivatives
        # Derivative of Q wrt t, scaled by chain rule factor
        dx_dt = cos(theta)
        dy_dt = sin(theta)
        
        # Approximate limit as delta -> 0
        dQ_dx = (q_x - q_base) / delta
        dQ_dy = (q_y - q_base) / delta
        
        # Accumulate sum
        # Note: The formula includes a factor of pi/K. 
        # This assumes the standard FBP reconstruction scaling.
        sum_fx += dQ_dx * dx_dt # Actually, the formula shows the scaling is inside the limit term
        # Re-reading formula: lim (1/dx) (Q(t + dx cos) - Q(t))
        # This IS the derivative of Q wrt x directly via chain rule.
        # So we just sum the difference quotients.
        
        # Correct accumulation based on formula:
        # fx_term = (Q(t + dx cos) - Q(t)) / dx
        # fy_term = (Q(t + dy sin) - Q(t)) / dy
        # fx = (pi/K) * sum(fx_term)
        
        fx_term = (q_x - q_base) / delta
        fy_term = (q_y - q_base) / delta
        
        sum_fx += fx_term
        sum_fy += fy_term
        
    fx = (pi / K) * sum_fx
    fy = (pi / K) * sum_fy
    
    return fx, fy
```

**Edge Cases and Pitfalls:**
*   **Precision:** The choice of $\Delta x$ and $\Delta y$ involves a trade-off between truncation error (large $\Delta$) and numerical noise (small $\Delta$). [G] A typical value is one pixel or voxel size in the projection domain.
*   **Boundaries:** If $t_i \pm \Delta x \cos \theta_i$ falls outside the bounds of the projection data $Q_{\theta_i}$, extrapolation or clamping is required. [G] Clamping to the nearest edge value is a common safeguard.
*   **Degenerate Input:** If $\cos \theta_i = 0$ (for $x$-gradient) or $\sin \theta_i = 0$ (for $y$-gradient), the shift in the projection coordinate becomes zero, making the difference quotient undefined or zero. This is handled naturally by the formula (the term becomes 0/0 if not careful, but physically the derivative component along that axis is zero for that specific projection). [G] In implementation, if the shift is zero, the contribution to that specific gradient component from that angle is zero.

## Subtopics

### Gradient-from-Reconstruction (GFR)
An approach where gradients are estimated in projection space and then reconstructed along with the density [S2, unofficial]. The gradient components parallel to the viewing direction are scaled by $\cos \theta$ and $\sin \theta$ [S2, unofficial]. The projection space gradient is stored in RGB color channels, while filtered density values are stored in the alpha channel [S2, unofficial]. The pipeline is formally described as $R_N((p \otimes g_p) \otimes h_p)$, where $p$ is projection data, $g_p$ is the gradient filter in projection space, $h_p$ is the interpolation filter, and $R_N$ is the reconstruction operator [S2, unofficial]. This method tends to produce images of lower perceived definition (sharpness) compared to Gradient-from-Sampling (GFS), especially when upsampling, because the gradient filter is applied before upsampling, potentially losing high-frequency information [S2, unofficial].

## Operating characteristics
*   **Accuracy:** Expects higher accuracy than traditional grid-based gradient estimation schemes [S1]. Grid-based central differences require 6 additional interpolated samples for a gradient, accumulating interpolation errors [S1]. FBP-based estimation uses density values as accurate as grid points, introducing no interpolation error [S1].
*   **Computational Cost:** Avoids the computational cost of computing a large 3D neighborhood of samples, which would require a large number of backprojections, especially for higher-order gradient estimation schemes [S1].
*   **Memory:** Does not require storing a 3D volume grid for gradient storage, reducing memory footprint compared to grid-based methods [S1].

## Background
This method exploits the Filtered Back-Projection (FBP) reconstruction scheme to compute derivatives directly from projection data. It was introduced in the context of Differentiable Volume Rendering (D2VR) to improve the quality of gradient-based rendering [S1][S2, unofficial]. The approach is particularly relevant for tomographic reconstruction as inverse rendering, where accurate gradients are needed for optimization or high-quality visualization without the artifacts of grid interpolation [S1][S2, unofficial].
