# Gradient Estimation via Filtered Back-Projection

Also called: FBP-based Gradient Estimation, Gradient from Filtered Projections

## Overview
Gradient Estimation via Filtered Back-Projection estimates the spatial derivatives of a volumetric density function directly from filtered projection data, bypassing the intermediate step of reconstructing a 3D rectilinear grid [S1]. It differs from grid-based finite difference methods by eliminating interpolation errors associated with sampling a reconstructed volume, as it computes derivatives from the continuous projection functions themselves [S1].

## How it works
**Inputs:**
* $K$: Number of projection angles $\theta_i$.
* $Q_{\theta_i}(t)$: Filtered projection data for angle $\theta_i$, where $t$ is the detector coordinate.
* $(x, y)$: 2D spatial coordinates of the evaluation point.

**Outputs:**
* $\tilde{f}_x$: Estimated partial derivative with respect to $x$.
* $\tilde{f}_y$: Estimated partial derivative with respect to $y$.

**Data Structures:**
* The filtered projections $Q_{\theta_i}$ are stored as 1D arrays [G]. No 3D grid is allocated for the gradient estimation itself [S1].

**Steps:**
1. For each projection angle $i \in \{1, \dots, K\}$, calculate the projection coordinate $t_i$ corresponding to $(x, y)$: $t_i = x \cos \theta_i + y \sin \theta_i$ [S1].
2. Compute the partial derivative with respect to $x$ ($\tilde{f}_x$) by summing the scaled derivatives of the filtered projections using Newton's difference quotient: $\tilde{f}_x = \frac{\pi}{K} \sum_{i=1}^K \lim_{\Delta x \rightarrow 0} \frac{1}{\Delta x} \left( Q_{\theta_i}(t_i + \Delta x \cos \theta_i) - Q_{\theta_i}(t_i) \right)$ [S1].
3. Compute the partial derivative with respect to $y$ ($\tilde{f}_y$) analogously: $\tilde{f}_y = \frac{\pi}{K} \sum_{i=1}^K \lim_{\Delta y \rightarrow 0} \frac{1}{\Delta y} \left( Q_{\theta_i}(t_i + \Delta y \sin \theta_i) - Q_{\theta_i}(t_i) \right)$ [S1].
4. Higher-order derivatives are obtained by applying the difference quotient multiple times to the projection data $Q_{\theta_i}$ [S1].

**Pseudocode:**
```python
def sample_projection(Q, t, t_min, t_max):
    idx = t - t_min
    if idx < 0 or idx >= len(Q) - 1:
        return Q[0] if idx < 0 else Q[-1]
    i = int(idx)
    w = idx - i
    return Q[i] * (1 - w) + Q[i + 1] * w

def estimate_gradient_fbp(x, y, angles, filtered_projections, t_bounds, delta=1e-5):
    K = len(angles)
    sum_fx = 0.0
    sum_fy = 0.0
    for i in range(K):
        theta = angles[i]
        Q = filtered_projections[i]
        t_i = x * cos(theta) + y * sin(theta)
        t_x = t_i + delta * cos(theta)
        t_y = t_i + delta * sin(theta)
        q_base = sample_projection(Q, t_i, t_bounds[0], t_bounds[1])
        q_x = sample_projection(Q, t_x, t_bounds[0], t_bounds[1])
        q_y = sample_projection(Q, t_y, t_bounds[0], t_bounds[1])
        fx_term = (q_x - q_base) / delta
        fy_term = (q_y - q_base) / delta
        sum_fx += fx_term
        sum_fy += fy_term
    fx = (pi / K) * sum_fx
    fy = (pi / K) * sum_fy
    return fx, fy
```

**Edge Cases and Pitfalls:**
* **Precision:** The choice of $\Delta x$ and $\Delta y$ trades truncation error against numerical noise [G]. A typical value is one pixel size in the projection domain [G].
* **Boundaries:** If $t_i \pm \Delta x \cos \theta_i$ or $t_i \pm \Delta y \sin \theta_i$ falls outside the projection bounds, values are clamped to the nearest edge [G].
* **Degenerate Input:** If $\cos \theta_i = 0$ or $\sin \theta_i = 0$, the coordinate shift vanishes, making the difference quotient exactly zero [G].

## Subtopics

### Gradient-from-Reconstruction (GFR)
An approach that estimates gradients in projection space and reconstructs them alongside the density [S2, unofficial]. Gradient components parallel to the viewing direction are scaled by $\cos \theta$ and $\sin \theta$ [S2, unofficial]. The projection space gradient is stored in RGB color channels while filtered density values occupy the alpha channel [S2, unofficial]. The pipeline is formally $R_N((p \otimes g_p) \otimes h_p)$, where $p$ is projection data, $g_p$ is the gradient filter in projection space, $h_p$ is the interpolation filter, and $R_N$ is the reconstruction operator [S2, unofficial]. This method produces images of lower perceived definition (sharpness) compared to Gradient-from-Sampling (GFS), particularly during upsampling, because the gradient filter is applied before upsampling, potentially discarding high-frequency information [S2, unofficial].

## Operating characteristics
* **Accuracy:** Expects higher accuracy than traditional grid-based gradient estimation schemes [S1]. Grid-based central differences require six additional interpolated samples for a gradient, accumulating interpolation errors [S1]. FBP-based estimation uses density values as accurate as grid points, introducing no interpolation error [S1].
* **Computational Cost:** Avoids the computational cost of computing a large 3D neighborhood of samples, which would require a large number of backprojections, especially for higher-order gradient estimation schemes [S1].
* **Memory:** Avoids storing a 3D rectilinear grid for gradient computation, reducing memory footprint compared to grid-based finite difference methods [S1].

## Background
This method exploits the Filtered Back-Projection (FBP) reconstruction scheme to compute derivatives directly from projection data [S1]. It was introduced in the context of Differentiable Volume Rendering (D2VR) to improve the quality of gradient-based rendering [S1][S2, unofficial]. The approach is particularly relevant for tomographic reconstruction as inverse rendering, where accurate gradients are needed for optimization or high-quality visualization without the artifacts of grid interpolation [S1][S2, unofficial].
