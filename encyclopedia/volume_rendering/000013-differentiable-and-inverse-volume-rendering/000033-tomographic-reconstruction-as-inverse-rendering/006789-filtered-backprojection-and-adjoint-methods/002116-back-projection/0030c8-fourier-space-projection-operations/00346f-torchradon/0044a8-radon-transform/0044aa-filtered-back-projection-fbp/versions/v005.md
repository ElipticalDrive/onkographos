# Filtered Back-Projection (FBP)

Also called: Filter Back Projection, RamLak Reconstruction

## Overview
Filtered Back-Projection (FBP) is a direct tomographic reconstruction algorithm that recovers a 2D image (or 3D volume in orthographic mode) from its measured projection profiles (sinogram) [S1, S3, S4, unofficial]. It solves the inverse Radon transform problem by applying a high-pass frequency-domain filter to the projections to correct for the inherent low-pass blurring of simple back-projection, followed by integrating the filtered data along sine-shaped paths [S1, S4, unofficial]. Unlike Fourier-based reconstruction methods which require interpolation between Cartesian and polar grids (leading to $O(N^2)$ complexity or interpolation artifacts), FBP operates directly on the projections with a time complexity of $O(N \log N)$ due to the use of Fast Fourier Transforms (FFT) [S4, S5, unofficial]. It is the most popular algorithm for computed tomography due to its speed and direct closed-form solution, though it requires projections over a full hemisphere and can produce artifacts if data is inconsistent or undersampled [S2, S3, unofficial].

## How it works
**Inputs:**
- Sinogram $R$: A 2D array of shape $(N_\rho, N_\theta)$, where $N_\rho$ is the number of radial samples per projection and $N_\theta$ is the number of projection angles.
- Angles $\Theta$: An array of $N_\theta$ angles, typically spanning $[0, \pi)$ radians.
- Radial sampling step $d_\rho$: The distance between adjacent samples in the projection domain.
- Filter type: e.g., 'ramp', 'hann', 'hamming', 'shepp-logan', 'cosine' [S5, S8, unofficial].
- Pixel kernel: The interpolation function used during back-projection (e.g., Dirac, Linear, Area) [S4, unofficial].

**Outputs:**
- Reconstructed image $I$: A 2D array of shape $(N, N)$, where $N$ is the image grid size.

**Data Structures:**
- The sinogram is stored as a contiguous 2D array.
- The frequency domain filter is a 1D array of length $N_\rho$.

**Steps:**

1.  **Generate Frequency Filter:**
    Compute the 1D frequency bins corresponding to the projection width. For a projection of length $N_\rho$, the frequencies $\nu$ range from $-\nu_{Nyquist}$ to $\nu_{Nyquist}$, where $\nu_{Nyquist} = \frac{1}{2 d_\rho}$ [S4, unofficial].
    Construct the base filter $H(\nu)$. The standard "Ram-Lak" filter is the ramp function $|\nu|$. To reduce high-frequency noise, this is often multiplied by a window function $W(\nu)$ [S1, S4, unofficial].
    The combined filter is:
    $$ H_{total}(\nu) = |\nu| \cdot W(\nu) $$
    Common windows include Hann and Hamming [S4, unofficial]:
    $$ W(\nu) = \begin{cases} a + (1-a)\cos\left(\frac{\pi\nu}{\nu_{Nyquist}}\right) & \text{if } |\nu| < \nu_{Nyquist} \\ 0 & \text{otherwise} \end{cases} $$
    Where $a = 0.5$ for Hann and $a = 0.54$ for Hamming [S4, unofficial].
    Other filters like Shepp-Logan or Cosine are defined differently [S8, unofficial]. For 'shepp-logan', the filter is $\text{sinc}(\omega)$ where $\omega = \pi \times \text{fftfreq}$ [S8, unofficial]. For 'cosine', it is $\text{FFTshift}(\sin(\text{linspace}(0, \pi, \text{size}+1)[:-1]))$ [S8, unofficial]. If no filter is specified, the filter is all ones [S8, unofficial].

2.  **Filter Projections:**
    For each projection angle $\theta_i \in \Theta$:
    a. Compute the 1D Discrete Fourier Transform (DFT) of the projection profile $R_{\theta_i}$:
       $$ \hat{R}_{\theta_i} = \text{FFT}(R_{\theta_i}) $$
    b. Multiply the spectrum by the frequency filter $H_{total}$:
       $$ \hat{R}_{\theta_i}^{filtered}[\nu] = \hat{R}_{\theta_i}[\nu] \cdot H_{total}[\nu] $$
    c. Compute the inverse 1D DFT to obtain the filtered projection $R_{\theta_i}^{BF}$:
       $$ R_{\theta_i}^{BF} = \text{IFFT}(\hat{R}_{\theta_i}^{filtered}) $$
       Note: The result should be taken as the real part, as the imaginary part should be negligible due to symmetry [S8, unofficial].

3.  **Back-Project:**
    Initialize the reconstructed image $I$ to zeros.
    For each filtered projection $R_{\theta_i}^{BF}$ and angle $\theta_i$:
    For each pixel $(x, y)$ in the image grid:
    a. Calculate the radial coordinate $\rho$ corresponding to the pixel's position at angle $\theta_i$:
       $$ \rho = x \cos \theta_i + y \sin \theta_i $$
    b. Sample the value from the filtered projection $R_{\theta_i}^{BF}$ at $\rho$. Since $\rho$ rarely aligns exactly with the discrete grid indices of the sinogram, interpolation is required. The choice of interpolation kernel (pixel kernel) affects quality. The 'Area' kernel provides the best SSIM and most uniform Point Spread Function (PSF) [S4, unofficial].
    c. Add the sampled value to the image pixel:
       $$ I(x, y) \leftarrow I(x, y) + R_{\theta_i}^{BF}(\rho) $$

4.  **Normalization:**
    Depending on the implementation, the accumulated values may need to be normalized by the number of projections or the angular step size $d\theta$ to maintain correct intensity scaling [S2, S4, unofficial].

**Pseudocode:**

```python
import numpy as np

def filtered_back_projection(sinogram, angles, d_rho, filter_type='ramp', window_param=0.5):
    """
    Reconstructs an image from a sinogram using Filtered Back-Projection.
    
    Parameters:
    sinogram: ndarray of shape (N_rho, N_theta)
    angles: ndarray of shape (N_theta,), in radians, range [0, pi)
    d_rho: float, radial sampling step
    filter_type: str, type of filter ('ramp', 'hann', 'hamming', etc.)
    window_param: float, parameter for window function (e.g., 0.5 for Hann)
    
    Returns:
    image: ndarray of shape (N, N)
    """
    N_rho, N_theta = sinogram.shape
    # Assume square image with same number of pixels as radial samples for simplicity
    # In practice, N might differ, but reconstruction grid usually matches sinogram width
    N = N_rho 
    
    # 1. Generate Frequency Filter
    # Frequency bins for FFT of length N_rho
    # fftfreq returns frequencies in cycles per sample. 
    # We need to scale by 1/d_rho to get physical frequency if d_rho is in physical units.
    # However, for reconstruction, relative frequencies matter. 
    # Nyquist frequency in cycles per sample is 0.5.
    freqs = np.fft.fftfreq(N_rho, d=1.0) # d=1.0 because we work in sample indices
    
    # Normalize frequencies to range [-0.5, 0.5)
    # The ramp filter is |nu|
    ramp_filter = np.abs(freqs)
    
    # Apply window if necessary
    if filter_type == 'hann':
        # Hann window: 0.5 - 0.5 * cos(2*pi*n/(N-1))
        # In frequency domain, this corresponds to the formula in [S4, unofficial]
        # H(nu) = a + (1-a)cos(pi*nu/nu_Nyquist)
        # nu_Nyquist corresponds to freq 0.5
        window = window_param + (1 - window_param) * np.cos(np.pi * freqs / 0.5)
        # Zero out frequencies beyond Nyquist (should be 0 already due to cos argument, but ensure)
        window[freqs < -0.5] = 0
        window[freqs > 0.5] = 0
        filter_kernel = ramp_filter * window
    elif filter_type == 'hamming':
        window = window_param + (1 - window_param) * np.cos(np.pi * freqs / 0.5)
        window[freqs < -0.5] = 0
        window[freqs > 0.5] = 0
        filter_kernel = ramp_filter * window
    elif filter_type == 'ramp':
        filter_kernel = ramp_filter
    elif filter_type == 'shepp-logan':
        # Shepp-Logan filter: sinc(omega) * |nu| ? Or just sinc?
        # [S8, unofficial] says for shepp-logan, multiply frequencies by sinc(omega)
        # omega = pi * fftfreq
        omega = np.pi * freqs
        sinc_filter = np.sinc(omega / np.pi) # sinc(x) = sin(pi*x)/(pi*x)
        filter_kernel = ramp_filter * sinc_filter
    elif filter_type == 'cosine':
        # [S8, unofficial] FFTshift(sin(linspace(0, pi, size+1)[:-1]))
        # This is a specific implementation detail. 
        # A simpler cosine filter is often just cos(pi*nu/2) for |nu|<1
        filter_kernel = np.cos(np.pi * freqs / 2)
        filter_kernel[freqs < -1] = 0
        filter_kernel[freqs > 1] = 0
    else:
        filter_kernel = np.ones(N_rho)

    # 2. Filter Projections
    filtered_sinogram = np.zeros_like(sinogram)
    for i in range(N_theta):
        proj = sinogram[:, i]
        # FFT
        proj_fft = np.fft.fft(proj)
        # Multiply by filter
        proj_fft_filtered = proj_fft * filter_kernel
        # IFFT
        filtered_proj = np.fft.ifft(proj_fft_filtered)
        filtered_sinogram[:, i] = np.real(filtered_proj)

    # 3. Back-Project
    image = np.zeros((N, N))
    
    # Precompute cos and sin for angles
    cos_angles = np.cos(angles)
    sin_angles = np.sin(angles)
    
    # Create coordinate grids
    # Center the image at (0,0)
    y, x = np.meshgrid(np.arange(N) - N/2 + 0.5, np.arange(N) - N/2 + 0.5, indexing='ij')
    
    for i in range(N_theta):
        theta = angles[i]
        c = cos_angles[i]
        s = sin_angles[i]
        
        # Calculate rho for each pixel
        rho = x * c + y * s
        
        # Interpolate from filtered_sinogram[:, i]
        # rho is in physical units relative to d_rho. 
        # Index in sinogram = rho / d_rho
        # We assume sinogram indices are 0 to N_rho-1
        # Center of sinogram is at N_rho/2
        # So index = (rho / d_rho) + N_rho/2
        
        # However, d_rho is often normalized to 1 in discrete implementations
        # If d_rho is not 1, we must scale.
        # Let's assume d_rho is the spacing between samples.
        # The sinogram array indices correspond to rho values:
        # index 0 -> rho = -N_rho/2 * d_rho
        # index k -> rho = (-N_rho/2 + k) * d_rho
        
        # So, index = rho / d_rho + N_rho/2
        
        indices = rho / d_rho + N_rho / 2
        
        # Clip indices to valid range
        indices = np.clip(indices, 0, N_rho - 1)
        
        # Linear interpolation
        idx0 = np.floor(indices).astype(int)
        idx1 = np.ceil(indices).astype(int)
        w = indices - idx0
        
        # Handle boundary cases where idx1 might be out of bounds
        idx1_safe = np.minimum(idx1, N_rho - 1)
        
        val0 = filtered_sinogram[idx0, i]
        val1 = filtered_sinogram[idx1_safe, i]
        
        interpolated_val = val0 + w * (val1 - val0)
        
        image += interpolated_val

    # 4. Normalization
    # Standard backprojection sums N_theta contributions.
    # To get the correct density, we divide by N_theta (or pi if angles are uniform and cover pi)
    # [S4, unofficial] implies direct summation. 
    # Common normalization is dividing by N_theta
    image /= N_theta
    
    return image
```

**Parameters:**
- $N_\theta$: Number of projection angles. SSIM plateaus when $N_\theta \ge 40$ for a $512^2$ image [S4, unofficial].
- $d_\rho$: Radial sampling step. SSIM increases for $d_\rho > 1$ (undersampling) and becomes constant when $d_\rho \le 1$ (standard/oversampling) [S4, unofficial].
- Filter: 'ramp', 'shepp-logan', 'cosine', 'hamming', 'hann' [S5, unofficial].
- Window parameter $a$: 0.54 for Hamming, 0.5 for Hann [S4, unofficial].
- Pixel Kernel: 'Area' kernel provides best SSIM and PSF uniformity [S4, unofficial].

**Edge Cases and Pitfalls:**
- **Interpolation:** Points on the backprojection paths do not align with measured grid locations, requiring interpolation. Low resolution (e.g., 512x512) can cause visible artifacts [S1, unofficial].
- **Noise Amplification:** The ramp filter amplifies high frequencies, which are sources of noise. Windowed filters (Hann, Hamming) are used to attenuate these very high frequencies to reduce artifacts [S4, unofficial].
- **Undersampling:** High radial resolution ($N_\rho$ increase) without sufficient angular coverage ($N_\theta < 40$) causes complete loss of contrast and luminance [S4, unofficial].
- **Inconsistent Data:** FBP can produce negative values in the presence of inconsistent data [S2, unofficial].

## Subtopics

### [Discrete Inverse Radon Transform](14348-discrete-inverse-radon-transform.md)
The Discrete Inverse Radon Transform reconstructs a 2D image from its Radon transform (sinogram) by summing projection values into image pixels, assuming parallel beam geometry. It is conventionally implemented via Filtered Back-Projection (FBP), which applies a frequency-domain filter to the sinogram before backprojecting to correct for the blurring inherent in simple summation. Unlike iterative methods, it provides a direct, closed-form solution but requires projections over a full hemisphere and can produce negative values in the presence of inconsistent data.

### [Iterative Reconstruction with Basis Expansion](16502-iterative-reconstruction-with-basis-expansion.md)
This method models an attenuation map as a linear combination of non-negative basis functions to solve the inverse problem of synthesizing attenuation-based displays from target light fields. It addresses the limitations of filtered back-projection [Filtered Back-Projection (FBP)](11308-filtered-back-projection-fbp.md) and the Discrete Inverse Radon Transform [Discrete Inverse Radon Transform](14348-discrete-inverse-radon-transform.md) when projections are inconsistent or limited in angle. By formulating the reconstruction as a convex non-negative linear least-squares optimization, it guarantees consistent views in the least-squares sense, unlike as-rigid-as-possible deformations used in visual hull reconstruction.

### Overscan Convolution Filter Generation
A method to generate a convolution filter for tomographic reconstruction that includes an overscan border (typically 30% extra pixels) to handle boundary conditions and ensure symmetry [S6, unofficial]. It calculates overscan dimensions ($w_{over} = \lceil w \cdot 0.3 \rceil$) and calls a filter builder with these dimensions. Overscanned filters preserve the parity (even/odd nature) of dimensions compared to non-overscanned filters, ensuring pixel alignment consistency [S6, unofficial].

### Ramp Filter
A frequency-domain filter applied to projections before backprojection to correct for the blurring inherent in simple backprojection [S7, unofficial]. It is computed by multiplying the FFT of the projection by the absolute value of the frequency bins [S7, unofficial].

### Fourier Slice Theorem
The mathematical foundation of FBP. It states that the 1D Fourier transform of a projection $R_\theta$ at angle $\theta$ is equal to a radial slice of the 2D Fourier transform of the original image $f(x,y)$ at the same angle $\theta$ [S4, unofficial]. This allows reconstruction by combining 1D Fourier transforms of all projections to fill the 2D Fourier space, which is then inverted [S4, unofficial].

### Filtered Backprojection Noise Shaping
Models and shapes CT noise from Poisson-distributed photon counting to a frequency-dependent Gaussian distribution via ramp filtering and interpolation during backprojection [S1, unofficial]. The ideal ramp filter amplifies high-frequency noise. Windowed ramp filters (Hanning, Hamming, Butterworth) create a band-pass noise spectrum. Re-sampling profiles during backprojection using interpolation (e.g., linear) further shapes the noise spectrum. The re-sampling rate can be increased via zoom reconstruction [S1, unofficial].

### CT Noise Filtering and Modeling
Models and shapes CT noise from Poisson-distributed photon counting to a frequency-dependent Gaussian distribution via ramp filtering and interpolation during backprojection [S1, unofficial].

### 1D Fourier Filter Generation
Generates a 1D frequency domain filter kernel for use in filtered backprojection [S8, unofficial]. For 'shepp-logan', it multiplies frequencies by $\text{sinc}(\omega)$. For 'cosine', it uses a shifted sine function. For 'hamming' or 'hann', it uses the respective window function. The base ramp filter array $f$ is defined as $f[0] = 0.25$, $f[1::2] = -1 / (\pi \times n)^2$, where $n = [1, 3, ..., \text{size}//2] \text{ concatenated with } [\text{size}//2-1, ..., 1]$. The filter is $2 \times \text{real}(\text{FFT}(f))$ [S8, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N \log N)$, making it competitive with Fourier methods [S4, unofficial].
- **Memory Complexity:** $O(N^2)$ for storing the sinogram and the reconstructed image.
- **Measured Performance:** FBP rms reconstruction error on Shepp-Logan phantom with ramp filter is 0.0283 [S5, unofficial].
- **Scaling:** The method is highly parallelizable because pixel contributions are independent, allowing for efficient GPU implementation [S4, unofficial].
- **Strengths:** Fast, direct closed-form solution, good conservation of contrast, and uniform PSF [S4, unofficial].
- **Limitations:** Requires projections over a full hemisphere ($\pi$ radians). Sensitive to noise (amplified by ramp filter) and undersampling. Can produce negative values with inconsistent data. Less robust to noise than iterative methods or Fourier methods with specific interpolations [S2, S4, unofficial].
- **When to Use:** Standard reconstruction for 2D CT slices from projection data when speed is critical and data is complete and consistent [S1, unofficial].
- **When Not to Use:** When projections are limited in angle or inconsistent, or when noise is extremely high and iterative regularization is preferred [S2, unofficial].

## Background
Filtered Back-Projection is the most popular algorithm for computed tomography [S3, unofficial]. It is based on the inversion of the Radon transform [S4, unofficial]. The method was introduced by Ramachandran and Lakshiminarayanan, hence the name "Ram-Lak" filter [S4, unofficial]. It is widely used in tomography and is cited as one of the most used direct methods [S4, unofficial]. In 3D, Feldkamp’s (FDK) algorithm is a popular extension for cone-beam CT, which acts as a 3D extension of 2D FBP in orthographic mode [S3, unofficial].
