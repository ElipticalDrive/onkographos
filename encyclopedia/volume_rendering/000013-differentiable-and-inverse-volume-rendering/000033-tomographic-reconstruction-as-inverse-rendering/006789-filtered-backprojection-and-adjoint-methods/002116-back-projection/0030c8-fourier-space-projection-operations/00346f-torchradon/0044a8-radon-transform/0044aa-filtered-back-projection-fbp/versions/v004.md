# Filtered Back-Projection (FBP)

Also called: Filter Back Projection, Inverse Radon Transform, RamLak Reconstruction, Rétroprojection des projections filtrées, Transformée inverse de Radon

## Overview
Filtered Back-Projection (FBP) is a direct tomographic reconstruction algorithm that recovers a 2D image from its measured projections (sinogram) by filtering the projection profiles in the frequency domain and then integrating them back into the image space [S1, S3, S4, unofficial]. It solves the inverse Radon transform problem, which standard back-projection alone cannot do accurately because simple back-projection induces a low-pass filtering effect (blurring) [S3, unofficial]. FBP compensates for this by applying a high-pass ramp filter, positioning it as a computationally efficient alternative to Fourier-based reconstruction methods that require complex grid interpolation [S3, S4, unofficial].

## How it works
**Inputs:**
*   Sinogram $R_\theta(\rho)$: A 2D array where rows correspond to projection angles $\theta$ and columns to radial positions $\rho$.
*   Angles $\Theta$: Array of projection angles in radians, typically spanning $[0, \pi)$ [S3, unofficial].
*   Radial sampling step $d_\rho$: Distance between samples in the projection [S3, unofficial].
*   Image dimensions $W \times H$: Width and height of the output image grid [S3, unofficial].
*   Filter type: e.g., 'ramp', 'hann', 'hamming' [S4, unofficial].

**Outputs:**
*   Reconstructed image $I(x, y)$: A 2D array of grey-values/attenuation coefficients [S1, S3, unofficial].

**Data Structures:**
*   `sinogram`: 2D float array of shape $(N_\theta, N_\rho)$.
*   `angles`: 1D float array of shape $(N_\theta)$.
*   `image`: 2D float array of shape $(H, W)$.

**Steps:**

1.  **Compute Nyquist Frequency:**
    Calculate the Nyquist frequency based on the radial sampling step $d_\rho$:
    $$ \nu_{Nyquist} = \frac{1}{2 d_\rho} $$
    [S3, unofficial]

2.  **Filter Projections:**
    For each projection angle $\theta \in \Theta$:
    a. Compute the 1D Fast Fourier Transform (FFT) of the projection profile $R_\theta$:
    $$ \hat{R}_\theta(\nu) = \mathcal{F}_{1D}\{R_\theta(\rho)\} $$
    [S3, unofficial]
    b. Define the filter kernel $H(\nu)$. The base filter is the ramp filter $|\nu|$. To reduce high-frequency noise, this is often multiplied by a window function $W(\nu)$:
    $$ H(\nu) = |\nu| \cdot W(\nu) $$
    [S3, unofficial]
    
    The window function $W(\nu)$ is defined as:
    $$ W(\nu) = \begin{cases} a + (1-a)\cos\left(\frac{\pi\nu}{\nu_{Nyquist}}\right) & \text{if } |\nu| < \nu_{Nyquist} \\ 0 & \text{otherwise} \end{cases} $$
    [S3, unofficial]
    
    Parameters for common windows [S3, unofficial]:
    *   **Hann:** $a = 0.5$
    *   **Hamming:** $a = 0.54$
    *   **Ram-Lak (No window):** $W(\nu) = 1$ for $|\nu| < \nu_{Nyquist}$ [S3, unofficial]
    
    c. Apply the filter in the frequency domain:
    $$ \hat{R}_\theta^{BF}(\nu) = \hat{R}_\theta(\nu) \cdot H(\nu) $$
    [S3, unofficial]
    d. Compute the inverse 1D FFT to obtain the filtered projection:
    $$ R_\theta^{BF}(\rho) = \mathcal{F}_{1D}^{-1}\{\hat{R}_\theta^{BF}(\nu)\} $$
    [S3, unofficial]

3.  **Back-Projection:**
    Initialize the output image $I(x, y)$ to zeros. For each pixel $(x, y)$ in the image grid:
    a. Initialize accumulator $sum = 0$.
    b. For each angle $\theta \in \Theta$:
    i. Calculate the radial coordinate $\rho$ corresponding to $(x, y)$ at angle $\theta$:
    $$ \rho = x \cos \theta + y \sin \theta $$
    [S3, unofficial]
    ii. Sample the filtered projection $R_\theta^{BF}$ at $\rho$. Since $\rho$ rarely aligns with integer grid indices, interpolation is required. Common kernels include Dirac (nearest neighbor), Linear, Spline, or Area [S3, unofficial].
    iii. Add the interpolated value to $sum$.
    c. Assign $I(x, y) = sum$ (or scaled by $\pi/N_\theta$ depending on normalization conventions, though the integral definition implies summation over $[0, \pi)$) [S3, unofficial].

    The mathematical definition of the inverse Radon transform (back-projection) is:
    $$ f(x,y) = \int_{0}^{\pi} \int_{-\infty}^{\infty} R_\theta(\rho) \delta(\rho - x \cos \theta - y \sin \theta) \, d\rho \, d\theta $$
    [S3, unofficial]
    In the discrete FBP implementation, the inner integral is resolved by filtering, and the outer integral is approximated by the summation over angles.

**Pseudocode:**

```python
import numpy as np

def filtered_back_projection(sinogram, angles, d_rho, image_shape):
    """
    Reconstructs an image from a sinogram using Filtered Back-Projection.
    
    Args:
        sinogram: np.ndarray of shape (N_theta, N_rho)
        angles: np.ndarray of shape (N_theta,) in radians
        d_rho: float, radial sampling step
        image_shape: tuple (H, W)
        
    Returns:
        image: np.ndarray of shape (H, W)
    """
    N_theta, N_rho = sinogram.shape
    H, W = image_shape
    
    # 1. Compute Nyquist Frequency
    nu_nyquist = 1.0 / (2.0 * d_rho)
    
    # 2. Define Frequency Axis for 1D FFT
    # FFT output frequencies: 0, 1, ..., N/2, -N/2+1, ..., -1
    freqs = np.fft.fftfreq(N_rho, d=d_rho)
    
    # 3. Define Filter Kernel (Ram-Lak with Hann Window as example)
    # Using Hann window parameters: a = 0.5
    a = 0.5
    abs_freqs = np.abs(freqs)
    
    # Window function H(ν)
    # Condition: |ν| < ν_Nyquist
    mask = abs_freqs < nu_nyquist
    window = np.zeros_like(freqs)
    window[mask] = a + (1 - a) * np.cos(np.pi * abs_freqs[mask] / nu_nyquist)
    
    # Ramp filter |ν|
    ramp = abs_freqs
    
    # Combined filter
    filter_kernel = ramp * window
    
    # 4. Filter Projections
    filtered_sinogram = np.zeros_like(sinogram)
    for i, theta in enumerate(angles):
        # 1D FFT of the projection
        proj_fft = np.fft.fft(sinogram[i, :])
        # Apply filter
        proj_fft_filtered = proj_fft * filter_kernel
        # Inverse 1D FFT
        filtered_proj = np.fft.ifft(proj_fft_filtered).real
        filtered_sinogram[i, :] = filtered_proj
        
    # 5. Back-Projection
    image = np.zeros((H, W))
    
    # Precompute pixel coordinates relative to center
    # Assuming image center is at (W/2, H/2)
    y_coords, x_coords = np.meshgrid(np.arange(H) - H/2, np.arange(W) - W/2, indexing='ij')
    
    for i, theta in enumerate(angles):
        # Calculate rho for all pixels
        rho = x_coords * np.cos(theta) + y_coords * np.sin(theta)
        
        # Interpolate filtered projection at rho values
        # rho values are continuous; map to indices in filtered_sinogram[i, :]
        # Indices range from 0 to N_rho - 1
        # Center of sinogram is at N_rho / 2
        # rho = 0 corresponds to index N_rho / 2
        
        # Shift rho to be relative to the center of the sinogram array
        rho_centered = rho + N_rho / 2.0
        
        # Clip to valid range to avoid out-of-bounds, though interpolation handles boundaries
        # Simple linear interpolation or nearest neighbor can be used here.
        # For implementation completeness, we use a generic interpolation function.
        # Note: In a real implementation, scipy.interpolate.interp1d or similar is used.
        
        # Create 1D array of indices for the current projection
        indices = np.arange(N_rho)
        
        # Interpolate
        # Using linear interpolation for robustness
        from scipy.interpolate import interp1d
        f_interp = interp1d(indices, filtered_sinogram[i, :], kind='linear', 
                            bounds_error=False, fill_value=0)
        
        projection_values = f_interp(rho_centered)
        
        # Accumulate
        image += projection_values
        
    # Normalize by number of angles (approximation of integral over [0, pi))
    # The integral is over 0 to pi. Summation is over N_theta angles.
    # Scaling factor depends on specific discretization. 
    # Standard simple backprojection sums over all angles.
    # FBP typically divides by pi or N_theta depending on normalization of sinogram.
    # Based on S3, the integral is defined directly. 
    # A common normalization is dividing by the number of angles if angles are uniform.
    image = image / N_theta
    
    return image
```

**Edge Cases and Pitfalls:**
*   **Interpolation:** Points on the back-projection paths do not align with measured grid locations, requiring interpolation. Low-resolution interpolation (e.g., Dirac/nearest neighbor) causes visible artifacts [S1, S3, unofficial]. The Area kernel provides the best SSIM and most uniform Point Spread Function (PSF) [S3, unofficial].
*   **Noise Amplification:** The ramp filter amplifies high frequencies, which are often dominated by noise. Windowed filters (Hann, Hamming) are necessary to attenuate these frequencies [S1, S3, unofficial].
*   **Sampling:** 
    *   Under-sampling (large $d_\rho$) maximizes SNR but degrades sharpness [S3, unofficial].
    *   High radial resolution ($N_\rho$) without sufficient angular coverage ($N_\theta < 40$ for $512^2$ images) causes loss of contrast and luminance [S3, unofficial].
    *   SSIM plateaus when $N_\theta \ge 40$ for a $512^2$ image [S3, unofficial].
*   **Boundary Conditions:** Overscan convolution filters can be used to handle boundary conditions and ensure symmetry, typically adding 30% extra pixels [S5, unofficial].

## Subtopics

### [Discrete Inverse Radon Transform](14348-discrete-inverse-radon-transform.md)
The Discrete Inverse Radon Transform (DIRT) is a method to estimate an attenuation map $\tilde{\mu}(x, y)$ or an image $I$ from a set of projections (sinogram) $p(u, a)$ or $R_\theta(\rho)$. It is conventionally implemented via filtered backprojection, where the inverse operation sums projection values back into the image domain. Unlike iterative reconstruction methods which handle inconsistent projections over limited angles via optimization, DIRT provides a direct, closed-form estimate.

### [Iterative Reconstruction with Basis Expansion](16502-iterative-reconstruction-with-basis-expansion.md)
This method models an attenuation map as a linear combination of non-negative basis functions to solve the inverse problem of synthesizing attenuation-based displays from target light fields. It addresses the limitations of filtered back-projection [Filtered Back-Projection (FBP)](11308-filtered-back-projection-fbp.md) and the Discrete Inverse Radon Transform [Discrete Inverse Radon Transform](14348-discrete-inverse-radon-transform.md) when projections are inconsistent or limited in angle. By formulating the reconstruction as a convex non-negative linear least-squares optimization, it guarantees consistent views in the least-squares sense, unlike as-rigid-as-possible deformations used in visual hull reconstruction.

### Overscan Convolution Filter Generation
A method to generate a convolution filter for tomographic reconstruction that includes an overscan border (typically 30% extra pixels) to handle boundary conditions and ensure symmetry [S5, unofficial]. It calculates overscan dimensions as $w_{over} = \lceil w \times 0.3 \rceil$ and $h_{over} = \lceil h \times 0.3 \rceil$ before building the filter [S5, unofficial]. This preserves the parity (even/odd nature) of dimensions compared to non-overscanned filters, ensuring pixel alignment consistency [S5, unofficial].

### Ramp Filter
A frequency-domain filter applied to projections before backprojection to correct for the blurring inherent in simple backprojection [S6, unofficial]. It is implemented by computing the FFT of the projection $p$, computing the frequency bins, and multiplying the FFT result by the absolute value of the frequency bins $|\nu|$ [S6, unofficial].

### Fourier Slice Theorem
The mathematical foundation of FBP, stating that the 1D Fourier transform of a projection $R_\theta$ at angle $\theta$ corresponds to a radial line in the 2D Fourier transform of the image $f$ at the same angle $\theta$ [S3, unofficial]. Specifically, $F_\theta(\nu) = F^{2D}(\psi, \nu)|_{\psi=\theta}$ [S3, unofficial]. Reconstruction involves combining these 1D transforms to fill the 2D Fourier space and applying a 2D inverse Fourier transform [S3, unofficial].

### CT Noise Filtering and Modeling
Models CT noise, which originates from Poisson-distributed photon counting (white noise) [S1, unofficial]. The ideal ramp filter attenuates low-frequency noise but amplifies high-frequency noise. Windowed ramp filters (Hanning, Hamming, Butterworth) create a band-pass noise spectrum, reducing high-frequency noise artifacts [S1, unofficial]. Re-sampling during backprojection (e.g., via zoom reconstruction) further shapes the noise spectrum and can reduce aliasing by increasing the sampling frequency [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N \log N)$, primarily due to the use of FFTs for filtering and the linear cost of back-projection [S3, S4, unofficial]. This makes it competitive with Fourier-based methods [S3, unofficial].
*   **Memory Complexity:** Requires storage for the sinogram, filtered sinogram, and output image. $O(N_\theta N_\rho + H W)$.
*   **Measured Performance:** On the Shepp-Logan phantom with a ramp filter, the RMS reconstruction error is approximately 0.0283 [S4, unofficial].
*   **Strengths:** 
    *   Fast execution speed [S4, unofficial].
    *   Simple implementation [S3, unofficial].
    *   GPU-parallelizable due to independent pixel contributions in back-projection [S3, unofficial].
    *   High SSIM (>0.8 in most cases with Area kernel) and uniform PSF [S3, unofficial].
*   **Limitations:**
    *   Sensitive to noise; requires windowing [S3, unofficial].
    *   Artifacts from under-sampling (angular or radial) [S3, unofficial].
    *   Less robust to noise than some Fourier methods or iterative techniques [S3, unofficial].
    *   Assumes consistent projections; fails with limited angles or inconsistent data without modification [S1, unofficial].
*   **When to Use:** Standard 2D CT slice reconstruction from full or near-full angular coverage projection data [S1, unofficial].
*   **When Not to Use:** Limited-angle tomography, highly noisy data without advanced filtering, or when iterative regularization is required for consistency [S1, S3, unofficial].

## Background
FBP was introduced by Ramachandran and Lakshiminarayanan (hence "Ram-Lak") as a computationally efficient alternative to Fourier reconstruction methods [S3, S4, unofficial]. It is based on the inversion of the Radon transform and the Fourier Slice Theorem [S3, S4, unofficial]. It is widely used in medical imaging (CT) and other tomographic applications [S1, S3, unofficial]. The method is considered one of the most used direct reconstruction methods in tomography [S3, unofficial].
