# Coupled Optimization


## Overview
Coupled Optimization is a tomographic reconstruction method that reconstructs fluid density and velocity fields by jointly optimizing for target image fidelity and physical transport consistency [S1]. It solves temporal incoherence in reconstruction by coupling the optimization of consecutive time steps through transport losses, significantly reducing transport error compared to forward-only reconstruction [S1].

## How it works
**Inputs:** A sequence of $n+1$ frames of input images $\{I_0, \dots, I_n\}$, a rendering function $R$, a transport operator $A$, and optimizer hyperparameters [S1].
**Outputs:** Reconstructed density fields $\{\rho_t\}_{t=0}^F$ and velocity fields $\{u_t\}_{t=0}^{F-1}$ for each frame $t$ in the sequence [S1].

**Data Structures:**
*   $\rho_t$: 3D tensor representing density at time $t$.
*   $u_t$: 3D vector field tensor representing velocity at time $t$.
*   $L_{tar}$: Target image loss (e.g., MSE between rendered and input image).
*   $L_A(\rho)$: Advection/Transport loss for density.
*   $L_A(u)$: Advection/Transport loss for velocity.
*   $L_{div}$: Divergence loss for velocity (incompressibility constraint).
*   $L_D$: Discriminator loss (optional) [S1].

**Formulas:**
The transport loss is defined as:
$$ L_A(\rho) = |A(\rho_{t-1}) - \rho_t|^2 $$
This term measures the deviation between the advected previous state and the current state [S1].

**Algorithm Steps:**
1.  **Initialization:** Initialize $\rho$ and $u$ via `ReconstructForward` [S1].
2.  **Iterative Optimization:** For each optimization step $i$ from $0$ to $n$:
    a.  **Discriminator Update (Optional):** If `useDiscriminator` is true, call `UpdateDiscriminator({ρ})` [S1].
    b.  **Temporal Loop:** For each time step $t$ from $0$ to $F$:
        i.  **Density Update:** Compute gradient $\nabla_\rho$ of $L_{total} = L_{tar} + L_A(\rho) + L_D$ with respect to $\rho$. Update $\rho_t$ using Adam optimizer. Clip negative densities: $\rho \leftarrow \max(\rho, 0)$ [S1].
        ii. **Velocity Update:** Compute gradient $\nabla_u$ of $L_{total} = L_A(\rho) + L_A(u) + L_{div}$ with respect to $u$. Update $u$ using Adam optimizer. Enforce boundary condition: $u_{F-1} \leftarrow A(u_{F-2}, u_{F-2})$ [S1].

**Pseudocode:**
```python
def CoupledOptimization(frames, render_func, transport_op, n, F, use_discriminator=False):
    # 1. Initialize via forward reconstruction [S1]
    rho, u = ReconstructForward(frames)
    opt_rho = AdamOptimizer(rho)
    opt_u = AdamOptimizer(u)
    opt_disc = AdamOptimizer(Discriminator()) if use_discriminator else None
    history_buffer = []

    for i in range(n):
        for t in range(F + 1):
            # Density update [S1]
            loss_rho = ComputeTargetLoss(rho[t], frames[t])
            if t > 0: loss_rho += ComputeTransportLoss(rho[t-1], rho[t])
            if use_discriminator: loss_rho += ComputeDiscriminatorLoss(rho[t])
            UpdateDensity(rho[t], loss_rho, opt_rho)

            # Velocity update [S1]
            loss_u = 0.0
            if t > 0: loss_u += ComputeTransportLoss(rho[t-1], rho[t])
            if t > 0: loss_u += ComputeTransportLoss(u[t-1], u[t])
            loss_u += ComputeDivergenceLoss(u[t])
            UpdateVelocity(u, loss_u, opt_u)

        # Optional discriminator update [S1]
        if use_discriminator:
            UpdateDiscriminator(rho, render_func, history_buffer, opt_disc)

def UpdateDensity(rho_t, loss, opt):
    grad_rho = ComputeGradient(loss, rho_t)
    opt.step(grad_rho)
    rho_t = [max(v, 0) for v in rho_t] # Clip negative density [S1]

def UpdateVelocity(u, loss, opt):
    grad_u = ComputeGradient(loss, u)
    opt.step(grad_u)
    u[F-1] = transport_op(u[F-2], u[F-2]) # Boundary condition [S1]

def UpdateDiscriminator(rho, render_func, history_buffer, opt_disc):
    real_samples = SampleRealImages() # Ir ~ R [S1]
    fake_samples = [render_func(r) for r in rho] # I^f <- R(ρ, L, f) [S1]
    history_buffer.extend(fake_samples) # history <- history ◦ I^f [S1]
    history_samples = SampleFromBuffer(history_buffer) # I^h ~ history [S1]
    all_samples = real_samples + history_samples
    loss_disc = ComputeDiscriminatorLoss(all_samples) # L_D(ρ, 1) [S1]
    opt_disc.step(ComputeGradient(loss_disc, opt_disc))
```

**Parameters:**
*   `n`: Number of global optimization iterations [S1].
*   `F`: Number of time steps [S1].
*   `use_discriminator`: Boolean flag to enable discriminator training [S1].
*   `batch_size`: 8 real samples and 4 rendered fake samples for discriminator training [S1].

**Edge Cases:**
*   **Negative Density:** Densities must be non-negative; clipping is applied after every update [S1].
*   **Temporal Boundaries:** Velocity at the final frame $F-1$ is updated using the transport operator on previous velocity states [S1].

## Subtopics

### Multi-Scale Coupled Optimization
A variant that activates multi-scale reconstruction during the coupled optimization phase [S1]. It improves the reconstruction of larger structures but increases transport error compared to the standard coupled version [S1].

## Operating characteristics
*   **Accuracy:** Coupled Optimization (C) improves transport accuracy to approximately 25% of the error of the forward-only version [S1].
*   **Trade-offs:** Standard Coupled Optimization balances density error and transport accuracy. Multi-Scale Coupled Optimization trades increased transport error for better reconstruction of large structures [S1].
*   **Performance:** The method involves iterative gradient updates for both density and velocity, making it computationally more expensive than analytic methods.
*   **Limitations:** The method is sensitive to the choice of transport operator $A$ and the balance between $L_{tar}$ and physical losses.

## Background
Coupled Optimization was introduced in the context of global transport for fluid reconstruction with learned self-supervision [S1]. It builds upon forward reconstruction methods by adding temporal coupling via transport losses [S1].
