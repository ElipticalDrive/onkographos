# Coupled Optimization


## Overview
Coupled Optimization is a differentiable volume rendering method that reconstructs fluid density and velocity fields by jointly optimizing for target image fidelity and physical transport consistency [S1]. It solves the problem of temporal incoherence in tomographic reconstruction by coupling the optimization of consecutive time steps through a transport loss, significantly reducing transport error compared to forward-only reconstruction [S1]. It sets itself apart from its siblings by explicitly incorporating the physics of advection into the gradient descent loop, whereas [Back-projection](2450-back-projection.md) and [FastFDK](3315-fastfdk.md) rely on analytic or single-step algebraic solutions without iterative physical coupling.

## How it works
**Inputs:** A sequence of $n+1$ frames of input images (or projections) $\{I_0, \dots, I_n\}$, a rendering function $R$, a transport operator $A$, and hyperparameters for the optimizer (e.g., Adam learning rate).
**Outputs:** Reconstructed density fields $\{\rho_t\}_{t=0}^F$ and velocity fields $\{u_t\}_{t=0}^{F-1}$ for each frame $t$ in the sequence.

**Data Structures:**
*   $\rho_t$: 3D tensor representing density at time $t$.
*   $u_t$: 3D vector field tensor representing velocity at time $t$.
*   $L_{tar}$: Target image loss (e.g., MSE between rendered and input image).
*   $L_A(\rho)$: Advection/Transport loss for density.
*   $L_A(u)$: Advection/Transport loss for velocity.
*   $L_{div}$: Divergence loss for velocity (incompressibility constraint).
*   $L_D$: Discriminator loss (optional, for learned self-supervision).

**Formulas:**
The transport operator $A$ models the state transition:
$$ A(\rho_t) = |A(\rho_{t-1}) - \rho_t|^2 $$
This term penalizes deviations from the physically advected state [S1].

**Algorithm Steps:**
1.  **Initialization:** Initialize $\rho$ and $u$ (e.g., via [ReconstructForward](19895-filtered-backprojection-and-adjoint-methods.md)).
2.  **Iterative Optimization:** For each optimization step $i$ from $0$ to $n$:
    a.  **Discriminator Update (Optional):** If a discriminator is used, update its parameters $\Theta_D$ using real samples $I_r$ and rendered fake samples $\hat{I}_f$ [S1].
    b.  **Temporal Loop:** For each time step $t$ from $0$ to $F$:
        i.  **Density Update:** Compute gradient $\nabla_\rho$ of the total loss $L_{total} = L_{tar} + L_A(\rho) + L_D$ with respect to $\rho$. Update $\rho_t$ using Adam optimizer. Clip negative densities: $\rho \leftarrow \max(\rho, 0)$ [S1].
        ii. **Velocity Update:** Compute gradient $\nabla_u$ of the loss $L_{total} = L_A(\rho) + L_A(u) + L_{div}$ with respect to $u$. Update $u$ using Adam optimizer. Enforce boundary conditions or transport consistency for velocity: $u_{F-1} \leftarrow A(u_{F-2}, u_{F-2})$ [S1].

**Pseudocode:**
```python
def CoupledOptimization(frames, render_func, transport_op, optimizer_cfg):
    # Initialize density and velocity fields
    rho = initialize_density(frames)
    u = initialize_velocity(frames)
    
    # Optimizers for rho and u
    opt_rho = Adam(rho.parameters(), **optimizer_cfg)
    opt_u = Adam(u.parameters(), **optimizer_cfg)
    
    # Optional: Discriminator setup
    discriminator = Discriminator()
    opt_disc = Adam(discriminator.parameters(), **optimizer_cfg)
    
    history_buffer = [] # Stores rendered fake samples
    
    for i in range(num_optimization_steps):
        # Optional: Update Discriminator
        if use_discriminator:
            update_discriminator(discriminator, opt_disc, rho, render_func, history_buffer)
        
        for t in range(num_frames):
            # 1. Update Density
            opt_rho.zero_grad()
            
            # Render current density
            rendered_img = render_func(rho[t])
            
            # Calculate losses
            loss_target = mse_loss(rendered_img, frames[t])
            loss_adv_rho = transport_op(rho[t-1], rho[t]) if t > 0 else 0.0
            loss_disc = discriminator_loss(discriminator, rendered_img) if use_discriminator else 0.0
            
            total_loss_rho = loss_target + loss_adv_rho + loss_disc
            total_loss_rho.backward()
            opt_rho.step()
            
            # Clip negative densities
            rho[t].data = torch.clamp(rho[t].data, min=0)
            
            # 2. Update Velocity
            opt_u.zero_grad()
            
            # Calculate velocity-related losses
            # Note: L_A(u) and L_div depend on specific physics implementation
            loss_adv_u = transport_op_u(u[t-1], u[t]) if t > 0 else 0.0
            loss_div = divergence_loss(u[t])
            
            # Note: L_A(rho) in velocity update implies coupling back to density
            # The source lists L_A(rho) in the velocity loss, suggesting joint dependency
            loss_coupling = transport_op_rho(rho[t-1], rho[t]) 
            
            total_loss_u = loss_coupling + loss_adv_u + loss_div
            total_loss_u.backward()
            opt_u.step()
            
            # Enforce velocity transport consistency at boundaries if needed
            if t > 0:
                u[t].data = transport_op(u[t-1], u[t-1])

def update_discriminator(discriminator, opt_disc, rho, render_func, history_buffer):
    # Sample real images
    real_samples = get_real_samples()
    
    # Render fake samples
    fake_samples = []
    for r in rho:
        fake = render_func(r)
        fake_samples.append(fake)
        
    # Update history buffer with new fake samples
    history_buffer.extend(fake_samples)
    
    # Sample from history for training
    history_samples = sample_from_buffer(history_buffer)
    
    # Combine real and history samples
    all_samples = real_samples + history_samples
    
    # Update discriminator
    opt_disc.zero_grad()
    loss = discriminator_loss(discriminator, all_samples)
    loss.backward()
    opt_disc.step()
```

**Parameters:**
*   `num_optimization_steps`: Number of global optimization iterations.
*   `num_frames`: Number of time steps $F$.
*   `use_discriminator`: Boolean flag to enable learned self-supervision [S1].
*   `batch_size`: 8 real samples and 4 rendered fake samples for discriminator training [S1].

**Edge Cases:**
*   **Negative Density:** Densities must be non-negative; clipping is applied after every update [S1].
*   **Temporal Boundaries:** Velocity at the final frame $F-1$ is updated using the transport operator on previous velocity states [S1].

## Subtopics

### Multi-Scale Coupled Optimization
A variant that activates multi-scale reconstruction during the coupled optimization phase [S1]. It improves the reconstruction of larger structures but increases transport error compared to the standard coupled version [S1]. Choose this when structural fidelity of large-scale features is prioritized over strict temporal transport accuracy.

## Operating characteristics
*   **Accuracy:** Coupled Optimization (C) improves transport accuracy to approximately 25% of the error of the forward-only version [S1].
*   **Trade-offs:** Standard Coupled Optimization balances density error and transport accuracy. Multi-Scale Coupled Optimization trades increased transport error for better reconstruction of large structures [S1].
*   **Performance:** The method involves iterative gradient updates for both density and velocity, making it computationally more expensive than analytic methods like [Back-projection](2450-back-projection.md). The inclusion of a discriminator adds further overhead [S1].
*   **Limitations:** The method is sensitive to the choice of transport operator $A$ and the balance between $L_{tar}$ and physical losses.

## Background
Coupled Optimization was introduced in the context of global transport for fluid reconstruction with learned self-supervision [S1]. It builds upon forward reconstruction methods by adding temporal coupling via transport losses [S1]. The method is part of a family of differentiable rendering techniques that aim to recover physically plausible fluid dynamics from sparse or noisy observations [S1].
