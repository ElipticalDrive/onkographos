# Dynamic Tomographic Reconstruction with Motion Identification (DynTomo)

Also called: DynART, DynTomo, Dynamic ART-P-DVC, Dynamic Tomographic Reconstruction with Displacement Field Identification, Dynamic Tomography, Dynamic reconstruction algorithm, PDVC

## Overview
DynTomo is a staggered iterative method for reconstructing deforming 3D volumes from 2D projection data acquired over time, simultaneously identifying the full 2D space-time displacement field [S1]. It solves the problem of motion artifacts in tomography by alternating between algebraic volume reconstruction (DynART) and projection-based digital volume correlation (PDVC) for motion identification [S1]. Unlike standard Algebraic Reconstruction Techniques (ART) which produce blurry or split reconstructions under large displacements, DynTomo corrects for motion to yield sharp edges and accurate gray levels [S1]. It builds on [Tomographic reconstruction as inverse rendering](45-tomographic-reconstruction-as-inverse-rendering.md) by incorporating a parametric displacement model into the optimization loop [S1].

## How it works
**Inputs:**
*   $p(r, \theta, t)$: Acquired sinogram (projections) at detector coordinates $r$, angles $\theta$, and time steps $t \in \{1, \dots, N_t\}$ [S1].
*   $N_t$: Number of time steps (projections) [S1].
*   $N_\theta$: Number of angles [S1].
*   $N_{scale}$: Number of multiscale levels [S1].
*   $\epsilon$: Convergence threshold for inner loops [S1].
*   Basis functions: $N_\tau$ time functions $\phi_i(t)$ and $N_s$ spatial shape functions $\Phi_j(x)$ [S1].

**Outputs:**
*   $f(x)$: Reconstructed reference volume [S1].
*   $u(x, t)$: Space-time displacement field [S1].

**Data Structures:**
*   **Displacement Field Parametrization:**
    The displacement field is represented as a linear combination of basis functions:
    $$ u(x, t) = \sum_{i=1}^{N_\tau} \sum_{j=1}^{N_s} \alpha_{ij} \phi_i(t) \Phi_j(x) $$
    where $\alpha_{ij}$ are the amplitude coefficients [S1]. The reference state is defined at $t=0$ such that $u(x, 0) = 0$, implying $\phi_i(0) = 0$ [S1].
*   **Spatial Basis:**
    $\Phi_j(x)$ are composed of $C^4$ mesh elements (4-node square elements with bilinear interpolation) [S1]. In the source tests, $N_s = 18$ degrees of freedom [S1].
*   **Time Basis:**
    $\phi_i(t)$ are time functions. In the source tests, $N_\tau = 2$ [S1].
*   **Gaussian Kernel:**
    Defined as $G_\lambda(r) = \frac{1}{2\pi\lambda^2} \exp\left(-\frac{|r|^2}{2\lambda^2}\right)$ [S1].

**Pseudocode:**
```python
def DynTomo(p, N_t, N_theta, N_scale, eps, N_tau, N_s, phi, Phi):
    # p: sinogram array [N_theta, N_t, H, W]
    # phi: time basis functions [N_tau]
    # Phi: spatial basis functions [N_s]
    u = zeros(volume_shape + (N_t,))  # Displacement field u(x, t)
    
    for i in range(N_scale, -1, -1):
        lam = 2**i
        # Convolve recorded projections with Gaussian kernel
        G_lam = (1/(2*pi*lam**2)) * exp(-r_norm**2 / (2*lam**2))
        p_check = convolve(p, G_lam)
        
        rho = p_check.copy()
        Residual = 1 + eps  # Force first loop
        
        while Residual > eps:
            # 1. Volume Reconstruction (DynART)
            f = DynART(p_check, u, N_t, N_theta, eps)
            
            # 2. Motion Identification (PDVC)
            u = PDVC(f, p_check, u, N_t, N_theta, eps, N_tau, N_s, phi, Phi)
            
            # 3. Scale Residual Update
            rho_old = rho.copy()
            f_warped = warp(f, u)
            rho = p_check - forward_projection(f_warped)
            Residual = norm(rho - rho_old)
            
    return f, u

def DynART(p_check, u, N_t, N_theta, eps):
    f = zeros(volume_shape)
    n = 1
    perm = permutation(N_t)  # Permutation over acquisition times
    
    for _ in range(60):  # N_DynART iterations
        for t_idx in range(N_t):
            tau = perm[t_idx]
            # Warp volume to current time
            f_tilde = warp(f, u[:, tau])
            # Forward projection
            proj = forward_projection(f_tilde, theta=tau)
            # Residual
            rho = p_check[:, tau] - proj
            # Backprojection
            df_tilde = back_projection(rho, theta=tau)
            # Unwarp update to reference space
            df = warp(df_tilde, -u[:, tau])
            # Update volume with normalization factor Δf̃ from source
            f = f + df / max(df_tilde)
            # Apply constraints (e.g., positivity)
            f = clip(f, 0, None)
            n += 1
    return f

def PDVC(f, p_check, u, N_t, N_theta, eps, N_tau, N_s, phi, Phi):
    u0 = u.copy()
    # Initialize residual
    f_warped = warp(f, u)
    rho_old = p_check - forward_projection(f_warped)
    Progress = 1 + eps
    
    while Progress > eps:
        f_warped = warp(f, u)
        rho = p_check - forward_projection(f_warped)
        Progress = norm(rho - rho_old)
        
        # Sensitivity computation
        H = zeros((N_tau * N_s, N_tau * N_s))
        b = zeros(N_tau * N_s)
        
        for i in range(N_tau):
            for j in range(N_s):
                # Compute projected sensitivities over all r, t
                chi_j = zeros_like(p_check)
                for t_idx in range(N_t):
                    grad_f = gradient(f_warped[:, t_idx])
                    chi_j[:, t_idx] = forward_projection(Phi[j] * grad_f, theta=t_idx)
                S_ij = phi[i] * chi_j  # S_ij(r, t) = phi_i(t) * chi_j
                
                # Assemble Hessian and second member
                for k in range(N_tau):
                    for l in range(N_s):
                        chi_k = zeros_like(p_check)
                        for t_idx in range(N_t):
                            grad_f = gradient(f_warped[:, t_idx])
                            chi_k[:, t_idx] = forward_projection(Phi[l] * grad_f, theta=t_idx)
                        S_kl = phi[k] * chi_k
                        H[i*N_s + j, k*N_s + l] = sum(S_ij * S_kl)
                b[i*N_s + j] = sum(rho * S_ij)
                
        # Solve linear system [H]δα = b
        delta_alpha = solve(H, b)
        # Update displacement field
        u = u + reshape(delta_alpha, (N_tau, N_s)) * outer(phi, Phi)
        rho_old = rho.copy()
        
    return u
```

**Parameters:**
*   **Convergence Threshold $\epsilon$:** Stops inner loops when residual or progress drops below this value [S1].
*   **Basis Functions:** $N_\tau$ time functions and $N_s$ spatial shape functions. Reference state $u(x, 0)=0$ implies $\phi_i(0)=0$ [S1].
*   **Iterations:** The source tests used 60 complete iterations per reconstruction cycle [S1].
*   **Gaussian Kernel Width:** Starts large ($\lambda = 2^{N_{scale}}$), progressively reduced by a factor of two at each scale level [S1].

**Pitfalls:**
*   **Motion Regularization:** Rapid variations in the displacement field can cause ill-conditioning. Weak regularization penalizes spatial/temporal variations; strong regularization uses smooth basis functions [S1].
*   **Optical Flow Assumption:** The base implementation assumes constant optical flow and does not model gray level variations [S1].
*   **Sensitivity Bottleneck:** Sensitivity computation requires deformed volumes over the entire time range, making it the computational bottleneck [S1].

## Operating characteristics
*   **Complexity:** The bottleneck is the computation of sensitivity fields, which requires projecting deformed volumes over the entire time range for every PDVC iteration [S1].
*   **Performance:** In tests with 512×512 pixel images and 300 projections, 60 iterations took approximately 1 hour [S1]. The checkerboard test (38 degrees of freedom) took approximately 2 hours [S1].
*   **Accuracy:**
    *   Shepp-Logan test (max displacement 37 pixels, 27% strain): Displacement error standard deviation of 3.10 pixels after 60 iterations [S1].
    *   Checkerboard test (max strain ~25%): Displacement error standard deviation < 1.2 pixel after 60 iterations [S1].
*   **Strengths:** Produces sharp edges and correct gray levels even with large displacements, unlike standard ART which produces blurry reconstructions with split parts [S1].
*   **Limitations:** Assumes constant optical flow; not robust to gray level variations without extension [S1]. Computationally expensive due to sensitivity calculation [S1].
*   **Usage:** Applicable to in situ mechanical tests, synchrotron beam-lines, and data assimilation [S1].

## Background
DynTomo was introduced in 2018 by [S1]. It is derived from Algebraic Reconstruction Techniques (ART) coupled with Projection-based Digital Volume Correlation (P-DVC) [S1]. The method was designed to handle large displacements and strains in dynamic tomography, such as those found in in situ mechanical testing [S1]. It was tested on numerical phantoms (Shepp-Logan and checkerboard) with parallel projection geometry [S1].
