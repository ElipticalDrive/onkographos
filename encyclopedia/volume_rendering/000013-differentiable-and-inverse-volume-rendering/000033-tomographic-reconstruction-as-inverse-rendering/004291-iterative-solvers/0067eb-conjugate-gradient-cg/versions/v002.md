# Conjugate Gradient (CG)


## Overview
Conjugate Gradient (CG) is an iterative descent method used to solve the linear system $R^T R f = R^T \text{proj}$ arising from the minimization of the quadratic error functional $J(f) = ||\text{proj} - Rf||^2$ in overdetermined tomographic reconstruction problems [S1, unofficial]. It is distinguished from sibling methods like Expectation-Maximization (EM) by its significantly faster convergence speed, though it lacks the inherent positivity guarantee of EM and may exhibit non-convergence issues more rapidly [S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Projection data vector $\text{proj}$, forward projection operator $R$ (or its action), initial estimate $f^{(0)}$ (typically zero or a filtered backprojection result) [G].
- Output: Reconstructed volume $f$ [G].

**Data Structures:**
- Vectors $f, r, p$ of size $N$ (number of voxels) [G].
- Scalars $\alpha_n, \beta_n$ [G].
- Matrix-vector products $R v$ and $R^T v$ are computed using the specific geometry of the tomographic setup (e.g., ray-driven or voxel-driven projection/backprojection) [G].

**Algorithm Steps:**
1. Initialize $f^{(0)} = 0$ (or another initial guess) [G].
2. Compute initial residual: $r_0 = R^T (\text{proj} - R f^{(0)})$ [G].
3. Set initial search direction: $p_1 = r_0$ [G].
4. For iteration $n = 1, 2, \dots$ until convergence:
   a. Compute step size: $\alpha_n = \frac{p_n^T p_n}{(R p_n)^T (R p_n)}$ [S1, unofficial].
   b. Update solution: $f^{(n+1)} = f^{(n)} + \alpha_n p_n$ [S1, unofficial].
   c. Compute new residual: $r_n = R^T (\text{proj} - R f^{(n)})$ [S1, unofficial].
   d. If $n > 1$, compute coefficient: $\beta_n = \frac{(R r_{n-1})^T (R p_n)}{(R p_{n-1})^T (R p_{n-1})}$ [S1, unofficial].
   e. Update search direction: $p_{n+1} = r_n - \beta_n p_n$ [S1, unofficial]. Conditions: $\langle p_{n+1}, r_n \rangle = 0$ and $\langle p_{n+1}, R^T R p_n \rangle = 0$ [S1, unofficial].

**Pseudocode:**
```python
def conjugate_gradient(proj, R_fwd, R_bwd, max_iter=100, tol=1e-6):
    """
    Solves R^T R f = R^T proj using Conjugate Gradient.
    R_fwd computes R * v. R_bwd computes R^T * v.
    """
    N = len(proj)
    f = [0.0] * N  # f^(0)
    r = R_bwd([proj[i] - R_fwd(f)[i] for i in range(N)])  # r_0
    p = r[:]  # p_1
    
    # Precompute R*p_1 and R*r_0 for the first beta calculation (n=2)
    R_p = R_fwd(p)
    R_r = R_fwd(r)
    
    for n in range(1, max_iter + 1):
        pTp = sum(p[i] * p[i] for i in range(N))
        RpTRp = sum(R_p[i] * R_p[i] for i in range(N))
        
        if RpTRp == 0:
            break
            
        alpha = pTp / RpTRp
        
        for i in range(N):
            f[i] += alpha * p[i]
            
        residual_vec = [proj[i] - R_fwd(f)[i] for i in range(N)]
        r = R_bwd(residual_vec)  # r_n
        
        r_norm_sq = sum(r[i] * r[i] for i in range(N))
        if r_norm_sq < tol:
            break
            
        if n > 1:
            beta = sum(R_r[i] * R_p[i] for i in range(N)) / sum(R_p_prev[i] * R_p_prev[i] for i in range(N))
            for i in range(N):
                p[i] = r[i] - beta * p[i]
        else:
            for i in range(N):
                p[i] = r[i]
                
        # Prepare for next iteration
        R_p_prev = R_p
        R_p = R_fwd(p)
        R_r = R_fwd(r)
        
    return f
```

**Parameters:**
- `max_iter`: Maximum number of iterations. Not given in the sources. [G] Typical values range from 10 to 100 for tomography, depending on convergence criteria.
- `tol`: Convergence tolerance. Not given in the sources. [G] Typical values are $10^{-6}$ to $10^{-4}$.

**Edge Cases and Pitfalls:**
- **Positivity:** The additive correction term does not guarantee that the estimated values remain positive [S2, unofficial]. This is a significant limitation for tomographic reconstruction where voxel values (e.g., density, attenuation) must be non-negative [G].
- **Convergence:** Non-convergence problems appear faster with CG compared to EM [S2, unofficial].
- **Conditioning:** The method assumes the system $R^T R$ is positive definite. If the system is ill-conditioned, convergence may be slow or unstable [G].

## Subtopics

### Filtered Conjugate Gradient with Surface Projection
A variant used to solve linear equations with surface constraints without degrading system conditioning or losing positive definiteness [S3, unofficial]. It projects residuals and solutions along the surface tangent plane during the conjugate gradient resolution and corrects particle positions by projecting them directly to the surface after resolution [S3, unofficial]. This avoids the numerical instabilities associated with augmenting the system with Lagrange multipliers, which can degrade conditioning and destroy positive definiteness [S3, unofficial]. The surface projection is performed using an iterative Newton-Raphson method [S3, unofficial].

## Operating characteristics
- **Time Complexity:** Each iteration requires two matrix-vector multiplications ($R p$ and $R^T r$) [G]. The total time is $O(k \cdot (N_{voxels} + N_{rays}))$ where $k$ is the number of iterations [G].
- **Memory Complexity:** $O(N_{voxels} + N_{rays})$ to store the volume, projections, and intermediate vectors [G].
- **Performance:** CG converges significantly faster than EM [S2, unofficial].
- **Strengths:** Rapid convergence for overdetermined systems [S1, unofficial].
- **Limitations:** Does not guarantee positivity [S2, unofficial]. More prone to non-convergence issues than EM [S2, unofficial]. Sensitive to the conditioning of $R^T R$ [G].

## Background
Conjugate Gradient is a classic descent method used for tomographic reconstruction [S2, unofficial]. It is based on the minimization of a quadratic functional, commonly the quadratic error [S1, unofficial]. The method is equivalent to the EM algorithm if a Gaussian distribution is chosen [S2, unofficial]. It is widely used in tomographic reconstruction due to its speed [S2, unofficial].
