# Expectation-Maximization (EM) Update

Also called: EM Update, Expectation Maximization, Expectation Maximization reconstruction, Maximum Likelihood Expectation Maximization

## Overview
The Expectation-Maximization (EM) Update is an iterative statistical reconstruction algorithm that finds the maximum likelihood estimate of a volume distribution from incomplete or missing projection data, specifically accounting for Poisson noise inherent in X-ray or emission tomography [S1, S2, unofficial]. Unlike algebraic methods such as [ART](6944-algebraic-reconstruction-technique-art.md) or [SIRT](3101-sirt-simultaneous-iterative-reconstruction-technique.md) which minimize least-squares errors, EM maximizes the likelihood function representing the probability that the reconstructed image generated the measured projections [S2, unofficial]. It is distinguished by its multiplicative update rule, which guarantees non-negativity and conservation of total events, but suffers from slow convergence and high-frequency noise amplification after many iterations [S1, S2, unofficial].

## How it works
**Inputs:**
*   `projections`: 1D or 2D array of measured projection data (sinogram). Must be non-negative ($proj_i \ge 0$) [S3, unofficial].
*   `volume`: Initial guess of the reconstruction volume. Must be strictly positive ($vol_j > 0$) for all voxels to avoid division by zero or log(0) errors [S3, unofficial].
*   `geometry`: Projection geometry object defining the forward projector $R$ and backprojector $R^*$ [S3, unofficial].
*   `iterations`: Integer number of EM updates [S3, unofficial].
*   `bounds` (optional): Tuple `[min_val, max_val]` for clipping the volume after each iteration [S3, unofficial].
*   `subsets` (optional): Integer $B$ for Ordered Subsets EM (OSEM) acceleration [S1, unofficial]. If 1, standard EM is used.

**Outputs:**
*   `volume`: The reconstructed volume array updated after `iterations` steps.

**Data Structures:**
*   `volume`: Array of shape matching the initial guess, dtype float.
*   `residual`: Temporary array matching projection shape, used to store the ratio of measured to estimated projections.

**Formulas:**
The goal is to minimize the log-likelihood function for Poisson data [S1, unofficial]:
$$ l(f) = \sum_i (proj_i \log (Rf)_i - (Rf)_i) $$
where $R$ is the forward projection operator and $f$ is the image vector [S1, unofficial].

The standard EM multiplicative update for iteration $k+1$ is [S2, unofficial]:
$$ f_j^{(k+1)} = f_j^{(k)} \frac{1}{s_j} \sum_i R_{ij} \frac{proj_i}{(R f^{(k)})_i} $$
where $s_j = \sum_i R_{ij}$ is the normalization factor (sum of the backprojected unity image) [S2, unofficial].

In matrix-vector notation, this is often written as [S1, unofficial]:
$$ f^{(k+1)} = f^{(k)} \odot \left( R^* \left( \frac{proj}{R f^{(k)}} \right) \right) / s $$
where $\odot$ denotes element-wise multiplication, and division is element-wise [S1, unofficial].

**Parameters:**
*   `iterations`: Typically ~12 steps before overfitting occurs [S1, unofficial].
*   `subsets`: Used in OSEM variants to decompose each iteration into $B$ sub-iterations [S1, unofficial].

**Pitfalls and Edge Cases:**
1.  **Negative Data:** If `projections.min() < 0`, the algorithm fails because the ratio $proj_i / (Rf)_i$ becomes negative or undefined in log-likelihood contexts. Check and reject or clip negative projections [S3, unofficial].
2.  **Zero Initial Guess:** If `volume.min() <= 0`, the forward projection $(Rf)_i$ may be zero, causing division by zero in the ratio step. Initialize with `numpy.ones_like(vol)` or a positive constant [S3, unofficial].
3.  **Noise Amplification:** EM produces images with excessive high-frequency details ("too many details") [S1, unofficial]. It is unstable after a large number of iterations. Solutions include early stopping (e.g., after 12 steps) or adding a penalty term $B(f)$ to minimize $l(f) - B(f)$, where $B(f) = (f - \bar{f})^T B (f - \bar{f})$ [S1, unofficial].
4.  **Conservation:** If initialized positively, all subsequent estimates remain positive. Voxels initialized to zero remain zero. Total number of events is conserved at each iteration [S2, unofficial].

**Pseudocode:**

```python
import numpy as np

def em_update(projections, volume, geometry, iterations, bounds=None, subsets=1):
    """
    Perform Expectation-Maximization reconstruction.
    
    Args:
        projections: 1D or 2D array of measured projections.
        volume: Initial positive guess of the volume.
        geometry: Object with forward_project and back_project methods.
        iterations: Number of EM steps.
        bounds: Optional tuple (min, max) to clip volume.
        subsets: Number of subsets for OSEM. 1 for standard EM.
        
    Returns:
        volume: Reconstructed volume.
    """
    # Validation from [S3, unofficial]
    if np.any(projections < 0):
        raise ValueError("Projections must be non-negative.")
    if np.any(volume <= 0):
        raise ValueError("Initial volume guess must be strictly positive.")

    # Precompute normalization factor s_j = sum_i R_ij [S2, unofficial]
    # forward_project computes sum_j R_ij * f_j for each projection ray
    unity_proj = np.ones_like(projections)
    s = geometry.back_project(unity_proj, volume.shape, geometry)
    # Guard against division by zero in unobservable voxels [G]
    s = np.where(s > 0, s, 1.0)

    for _ in range(iterations):
        # Forward project current estimate: estimated = R * volume [S1, S2, unofficial]
        estimated = geometry.forward_project(volume, geometry)
        
        # Compute ratio proj / estimated [S1, S2, unofficial]
        # Guard against zero estimates to prevent division by zero [G]
        ratio = np.where(estimated > 0, projections / estimated, 0.0)
        
        # Backproject ratio and normalize: volume = volume * (R^*(ratio) / s) [S1, S2, unofficial]
        # back_project computes sum_i R_ij * r_i for each voxel
        volume = volume * (geometry.back_project(ratio, volume.shape, geometry) / s)

        # Apply bounds if specified [S3, unofficial]
        if bounds is not None:
            volume = np.clip(volume, bounds[0], bounds[1])

    return volume
```

## Subtopics

### [Ordered Subsets EM (OSEM)](20046-ordered-subsets-em-osem.md)
Accelerated variant of EM that decomposes each iteration into $B$ sub-iterations using subsets of projection data, speeding up convergence but potentially leading to earlier divergence.

## Operating characteristics
*   **Convergence:** Slow compared to algebraic methods like SIRT or CG [S2, unofficial].
*   **Stability:** Unstable after a large number of iterations; requires regularization or post-filtering (e.g., Gaussian filter) to stabilize [S2, unofficial].
*   **Properties:** Guarantees non-negativity if initialized positively; conserves total number of events at each iteration [S2, unofficial].
*   **Noise Handling:** Statistically optimal for Poisson noise inherent in low-count X-ray or emission tomography data [S2, unofficial].
*   **Regularization:** Prone to high-frequency noise amplification; stabilization typically requires early stopping (~12 steps) or adding a penalty term $B(f)$ [S1, unofficial].

## Background
The EM algorithm was introduced as a general method for finding maximum likelihood estimates in the presence of incomplete data [S1, unofficial]. In tomography, it was adapted to handle Poisson noise in projection data [S2, unofficial]. The Ordered Subsets EM (OSEM) variant was introduced by Hudson and Larkin in 1994 to accelerate convergence [S1, unofficial]. It is widely used in medical imaging, particularly in SPECT and PET reconstruction, and in X-ray CT for low-dose scenarios [S1, S2, unofficial].
