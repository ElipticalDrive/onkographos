# Multiplicative ART

Also called: MART (Multiplicative ART), Multiplicative Algebraic Reconstruction Technique, Single-view-MART, Sv-MART

## Overview
Multiplicative ART (MART) is an iterative algebraic reconstruction algorithm that optimizes the Algebraic Reconstruction Technique (ART) by applying multiplicative updates instead of additive corrections [S2, unofficial]. It solves the linear system $P = Rf$ for positive projection data $P_i$ and positive system matrix coefficients $R_{ij}$, converging to a non-negative solution that maximizes entropy [S2, unofficial]. Unlike its parent [Adaptive Algebraic Reconstruction Technique (AART)](14387-adaptive-algebraic-reconstruction-technique-aart.md), which adjusts step sizes adaptively, MART uses a fixed relaxation parameter within a multiplicative framework [S4, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Measured projection data $P_i$ for each projection $i$; system matrix coefficients $R_{ij}$ representing the intersection length of projection line $i$ with voxel $j$; initial field distribution $f^{(0)}$; relaxation parameter $\lambda$ [S2, unofficial].
- Output: Reconstructed field distribution $f$ [S2, unofficial].

**Data Structures:**
- $f$: Array of size $M$ storing voxel values. Initialized to arbitrary positive values $f_j^{(0)} > 0$ [S2, unofficial].
- $P$: Array of size $N$ storing measured projection values.
- $R$: System matrix or sparse representation of coefficients $R_{ij}$ [S2, unofficial].

**Numbered Steps:**
1. Initialize the field distribution $f_j = f_j^{(0)}$ for all voxels $j$, ensuring $f_j^{(0)} > 0$ [S2, unofficial].
2. Cycle through each projection $i = 1, \dots, N$:
   a. Calculate the estimated projection $\hat{P}_i = \sum_{j} R_{ij} f_j$ [S2, unofficial].
   b. For each voxel $j$ intersected by projection line $i$, update its value using the multiplicative rule:
      $$f_j^{(new)} = f_j^{(old)} \left( \frac{P_i}{\hat{P}_i} \right)^{\lambda R_{ij}}$$
      where $\lambda$ is the relaxation parameter [S2, unofficial].
3. Repeat step 2 until the convergence criteria $\left| \frac{f_j^{(new)} - f_j^{(old)}}{f_j^{(old)}} \right| \le \epsilon$ is met for all voxels [S3].

**Formulas:**
- Update rule: $f_j^{(n+1)} = f_j^{(n)} \left( \frac{P_i}{\sum_{j=1}^{N_e} R_{ij} f_j^{(n)}} \right)^{\lambda R_{ij}}$ [S2, unofficial].
- Entropy minimization target: $E(f) = -\sum_{k=1}^{M} f_k \log f_k$ [S1, unofficial].
- Convergence criteria: $\left| \frac{f_v^{new} - f_v^{old}}{f_v^{old}} \right| \le \epsilon$ [S3].

**Parameters:**
- $\lambda$: Relaxation parameter. Typical range: $0.01 \le \lambda \le 0.1$ [S2, unofficial].
- $\epsilon$: Tolerance factor for convergence. Fixed value [S3].

**Edge Cases and Pitfalls:**
- Requires positive initialization: $f_j^{(0)} > 0$ is mandatory to maintain positivity throughout iterations [S2, unofficial].
- If $\hat{P}_i = 0$, division by zero occurs in the ratio $P_i/\hat{P}_i$. This happens if the initial guess is zero and no line passes through non-zero voxels, or if the geometry is degenerate. Guard against this by ensuring $f_j^{(0)} > 0$ and checking for zero denominators [G].
- The sequential processing of projections means the update order can influence convergence behavior [S4, unofficial].

**Pseudocode:**
```python
def multiplicative_art(projections, system_matrix, initial_f, lambda_param, epsilon):
    """
    projections: list of floats, P_i for each projection i
    system_matrix: list of lists of tuples, system_matrix[i] contains (j, R_ij) for voxels j intersected by projection i
    initial_f: list of floats, f_j^(0)
    lambda_param: float, relaxation parameter in [0.01, 0.1]
    epsilon: float, convergence tolerance
    """
    f = list(initial_f)
    num_projections = len(projections)
    
    while True:
        max_relative_change = 0.0
        converged = True
        
        for i in range(num_projections):
            P_i = projections[i]
            estimated_P = 0.0
            active_voxels = system_matrix[i]
            
            for j, R_ij in active_voxels:
                estimated_P += R_ij * f[j]
            
            if estimated_P == 0:
                continue
            
            ratio = P_i / estimated_P
            power = lambda_param
            
            for j, R_ij in active_voxels:
                old_f = f[j]
                new_f = old_f * (ratio ** (power * R_ij))
                
                if new_f < 0:
                    new_f = 0.0
                    
                f[j] = new_f
                
                if old_f != 0:
                    rel_change = abs((new_f - old_f) / old_f)
                    if rel_change > max_relative_change:
                        max_relative_change = rel_change
                else:
                    if new_f > 0:
                        max_relative_change = float('inf')
                        converged = False
        
        if max_relative_change <= epsilon and converged:
            break
            
    return f
```

## Subtopics

### Sparse MART (Sp-MART)
Sparse MART (Sp-MART) is an iterative algorithm that solves linear equations $P_{p,l} = \sum_v \alpha_{p,l,v} f_v$ by treating all projection lines as part of a single projection to reduce storage requirements [S3]. It updates field values using $f_v^{new} = f_v^{old} (1 - \beta (1 - \Delta P_{p,l}))$, where $\beta \in [0, 2]$ is a relaxation parameter and $\Delta P_{p,l}$ is the discrepancy between measured and calculated data [S3]. It is chosen when memory constraints require avoiding full coefficient matrix storage, though it necessitates a large number of projections and sensors to produce high-quality images [S3].

### Simultaneous MART (SMART)
Simultaneous MART (SMART) is the simultaneous variant of MART that applies to non-negative systems and updates all equations at each iteration, unlike MART which processes one equation per iteration [S2, unofficial]. It converges to a maximum entropy solution using the update rule $f_j^{(n+1)} = f_j^{(n)} \left( \prod_i \left( \frac{P_i}{\sum_{j=1}^{N_e} R_{ij} f_j^{(n)}} \right)^{\lambda R_{ij}} \right)^{1/N}$, where $N$ is the number of projections and $\lambda$ is the relaxation parameter [S2, unofficial]. It is chosen when faster convergence is needed at the cost of higher per-iteration computational load [S2, unofficial].

### [USCG-based Sp-MART](18906-uscg-based-sp-mart.md)
USCG-based Sp-MART is a tomographic reconstruction method that reduces space and time complexity by discretizing the image domain using a Uniformly Sampled Cylindrical Grid (USCG). It solves the radial deterioration of resolution found in conventional polar grid methods while accelerating line tracing by leveraging rotational symmetry and on-the-fly coefficient calculation. Compared to Cartesian grid-based methods, it enhances overall reconstruction speed by a factor of 2.5, and unlike the Feldkamp-Davis-Kress (FDK) algorithm, it produces high-quality images with a significantly limited number of projections and detectors, making it suitable for low-cost CT setups.

## Operating characteristics
**Time and Memory Complexity:**
- Time: $O(I \cdot N_p \cdot N_l \cdot N_v)$ per iteration, where $I$ is iterations, $N_p$ is projections, $N_l$ is lines per projection, and $N_v$ is active voxels per line [S3].
- Memory: $O(N^3)$ for the field $f$ and $O(N_{nonzero})$ for the system matrix if stored sparsely [S3].

**Measured Performance:**
- Performance depends heavily on the geometry and the sparsity of the system matrix [S3]. In cylindrical geometries, precomputing intersection points and sorting them by distance to the source improves cache locality and speed [S3].

**Scaling:**
- Scales linearly with the number of voxels and projections [S3].

**Strengths and Limitations:**
- Strengths: Enforces non-negativity naturally; converges to a physically meaningful maximum entropy solution [S2, unofficial].
- Limitations: Convergence can be slow; sensitive to the choice of $\lambda$; sequential nature limits parallelism compared to simultaneous methods like SIRT [S4, unofficial].

**When to Use:**
- Use when non-negativity is critical and the problem is ill-posed or noisy [S2, unofficial].
- Use when additive methods produce negative artifacts [S2, unofficial].

**When Not to Use:**
- Use when speed is paramount and non-negativity is not required (use SIRT or FBP) [S4, unofficial].
- Use when the system matrix is dense and memory is limited (use sparse variants or compressed sensing) [S3].

## Background
MART was developed as an optimization of the Algebraic Reconstruction Technique (ART) that uses multiplicative updates instead of additive corrections [S4, unofficial]. It converges to a solution minimizing entropy $E(f) = -\sum_{k=1}^{M} f_k \log f_k$, seeking only positive solutions [S1, unofficial]. The method was introduced in the context of improving reconstruction quality by using multiplicative updates instead of additive corrections [S4, unofficial]. It is widely used in medical imaging, industrial CT, and electron microscopy where non-negative density values are physically required [S1, unofficial][S2, unofficial].
