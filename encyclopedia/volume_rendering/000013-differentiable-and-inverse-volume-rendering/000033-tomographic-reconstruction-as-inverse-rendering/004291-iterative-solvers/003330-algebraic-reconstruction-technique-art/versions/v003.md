# Algebraic Reconstruction Technique (ART)

Also called: ART (Algebraic Reconstruction Technique), Frame-driven Kaczmarz method, Incremental learning in reflective tomography, Kaczmarz method, Reflective Tomography via Algebraic Reconstruction Technique (ART)

## Overview
Algebraic Reconstruction Technique (ART) is an iterative algebraic method for solving the linear inverse problem of tomographic reconstruction, minimizing the quadratic norm of the difference between acquired projections and the projected reconstructed volume [S1]. It avoids explicit storage of the system matrix by sequentially updating voxel values based on the residual error between the measured sinogram and the back-projected correction [S3, unofficial]. Unlike its sibling [Simultaneous Algebraic Reconstruction Technique (SART)](10119-simultaneous-algebraic-reconstruction-technique-sart.md), which aggregates updates from a full projection image, ART updates the volume one ray (or one projection pixel) at a time, making it memory-efficient but potentially slower to converge [S1][S3, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N_\theta$ acquired projection images (sinogram data) $p(r, \theta)$, where $r$ is the detector coordinate and $\theta$ is the view angle.
*   **Output:** A reconstructed 3D volume $f(x)$.

**Data Structures:**
*   **Volume $f$:** A 3D grid of voxel values. Initialized to zero.
*   **Residual $\rho$:** A 2D array matching the dimensions of the projection images, storing the difference between measured and computed projections.
*   **Permutation $\pi$:** An array of indices $1 \dots N_\theta$ defining the order in which angles are processed.

**Formulas:**
The method minimizes the functional [S1]:
$$ \Gamma_{ART}[\psi] = \sum_{r,\theta} \| \rho(r, \theta) \|^2 $$
where $\psi$ is the reconstructed volume estimate and the residual is defined as:
$$ \rho(r, \theta) = p(r, \theta) - R_\theta[\psi(x)] $$
Here, $R_\theta[\psi(x)]$ is the forward projection (X-ray transform) of the volume $\psi$ at angle $\theta$. The goal is to find $f = \text{Argmin}_\psi \Gamma_{ART}[\psi]$ [S1].

**Steps:**
1.  **Initialization:** Set iteration counter $n=1$. Initialize the volume estimate $f^{(1)}(x) = 0$. Initialize the residual $\rho(r, \theta) = p(r, \theta)$ for all $r, \theta$.
2.  **Permutation:** Choose a permutation $\pi$ over the $N_\theta$ angle indices to order angles non-consecutively. This accelerates convergence by ensuring large differences between successive angles [S1].
3.  **Iteration Loop:** While the norm of the residual $\|\rho(r, \theta)\| > \epsilon$ (where $\epsilon$ is a convergence threshold):
    1.  Iterate $k$ from $1$ to $N_\theta$.
    2.  Let $m = \pi(k)$ be the current angle index.
    3.  **Compute Residual for Current View:** Calculate the difference between the acquired projection and the forward projection of the current volume estimate:
        $$ \rho(r, \theta_m) \leftarrow p(r, \theta_m) - R_{\theta_m}[f^{(n)}(x)] $$
    4.  **Back-project Correction:** Compute the correction term by back-projecting the residual for the current view:
        $$ \Delta f^{(n+1)}(x) \leftarrow B_{\theta_m}[\rho(r, \theta_m)] $$
        Where $B_{\theta_m}$ is the back-projection operator for angle $\theta_m$.
    5.  **Update Volume:** Add the correction to the volume:
        $$ f^{(n+1)}(x) \leftarrow f^{(n)}(x) + \Delta f^{(n+1)}(x) $$
    6.  **Apply Constraints:** Enforce physical constraints, such as positivity:
        $$ f^{(n+1)}(x) = \max(f^{(n+1)}(x), 0) $$
    7.  Increment iteration counter: $n \leftarrow n + 1$.

**Parameters:**
*   **Convergence Threshold $\epsilon$:** A small value determining when to stop iterations, chosen with respect to noise and artifact acquisition levels [S1].
*   **Number of Iterations $N_{ART}$:** Typically, a few iterations are required for convergence [S1].

**Pitfalls:**
*   **Convergence Speed:** Convergence is significantly faster when angles are not sampled consecutively. Using a random or shuffled permutation $\pi$ is recommended [S1].
*   **Positivity:** Without positivity constraints, the solution may oscillate or produce negative values in non-absorbing regions [S1].

**Pseudocode:**
```python
def ART(projections, angles, forward_project, back_project, num_angles, epsilon):
    """
    Reconstruct volume using Algebraic Reconstruction Technique.
    
    Args:
        projections: List of 2D arrays, shape (H, W), one per angle.
        angles: List of angle values corresponding to projections.
        forward_project: Function f(volume, angle) -> 2D array.
        back_project: Function f(residual_2d, angle) -> 3D array.
        num_angles: Integer N_theta.
        epsilon: Float, convergence threshold.
        
    Returns:
        volume: 3D array, the reconstructed volume.
    """
    # Initialize volume to zeros
    # Note: Volume shape must be known or inferred from geometry. 
    # Assuming a standard grid for implementation context.
    volume = zeros_like_volume() 
    
    # Initialize residual with the acquired projections
    # We store residuals for all angles to check convergence norm
    residuals = [proj.copy() for proj in projections]
    
    # Create permutation of angle indices
    indices = list(range(num_angles))
    shuffle(indices) # Random permutation for faster convergence
    
    iteration = 0
    
    # Check initial residual norm
    residual_norm = sqrt(sum(sum(r**2) for r in residuals))
    
    while residual_norm > epsilon:
        iteration += 1
        
        for k in range(num_angles):
            m = indices[k]
            theta = angles[m]
            
            # 1. Compute residual for current view
            # R_theta[volume] is the forward projection of the current volume
            projected_volume = forward_project(volume, theta)
            residuals[m] = projections[m] - projected_volume
            
            # 2. Back-project the residual
            correction = back_project(residuals[m], theta)
            
            # 3. Update volume
            volume = volume + correction
            
            # 4. Apply positivity constraint
            volume = max(volume, 0)
            
        # Recalculate global residual norm for convergence check
        residual_norm = sqrt(sum(sum(r**2) for r in residuals))
        
    return volume
```

## Subtopics

### [Motion-Compensated Algebraic Reconstruction Technique](7422-motion-compensated-algebraic-reconstruction-technique.md)
DynART handles dynamic volumes by warping the volume estimate according to a displacement field before projection, unlike standard ART which assumes a static object.

### [Direct Linear Inversion (ART)](8506-direct-linear-inversion-art.md)
Solves the linear system $M \mathbf{v} = \mathbf{d}$ via pseudo-inverse in a single step, avoiding iterative updates entirely.

### [Simultaneous Algebraic Reconstruction Technique (SART)](10119-simultaneous-algebraic-reconstruction-technique-sart.md)
Updates the volume using all rays in a projection image simultaneously, offering faster convergence than ART's sequential ray-by-ray updates.

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of iterations and the number of rays processed per iteration. Convergence speed depends heavily on the angle permutation [S1].
*   **Memory Complexity:** Low. It does not require storing the full system matrix $M$, only the volume and projection data [S1].
*   **Strengths:** Flexible geometry (does not require circular rotation or specific acquisition constraints like FDK); handles missing angles and noise better than analytical methods when combined with regularization [S1]; suitable for reflective tomography with arbitrary camera positions [S2].
*   **Limitations:** Slower convergence compared to simultaneous methods like SART if angles are not well-permuted; sensitive to the choice of convergence threshold [S1].
*   **When to use:** When acquisition geometry is non-standard (e.g., reflective tomography, arbitrary camera views) or when memory constraints prevent storing the system matrix [S1, S2].
*   **When not to use:** When high-speed reconstruction is required and geometry is standard (use FBP or SART); when the number of projections is very small and regularization is critical (ART alone may not suffice without additional priors) [S1].

## Background
ART was introduced in the 1970s by Gordon, Bender, and Hertz [S3, unofficial]. It is based on the Kaczmarz method for solving linear systems [S3, unofficial]. The technique has been adapted for various fields, including X-ray tomography [S1] and reflective tomography for 3D multiple-view reconstruction using calibrated images [S2]. It is often compared to analytical methods like FDK, offering better quality at the expense of higher computational cost [S1].
