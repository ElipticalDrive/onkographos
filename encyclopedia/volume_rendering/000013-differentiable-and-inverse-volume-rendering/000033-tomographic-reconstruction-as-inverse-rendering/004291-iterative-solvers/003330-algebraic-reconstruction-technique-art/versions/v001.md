# Algebraic Reconstruction Technique (ART)

Also called: Kaczmarz method

## Overview
The Algebraic Reconstruction Technique (ART) is an iterative algebraic method for tomographic reconstruction that minimizes the quadratic norm of the difference between acquired projections and the projected reconstructed volume, avoiding the explicit storage of the large linear system matrix [S1]. It differs from simultaneous methods like SIRT by updating the volume estimate sequentially for each projection angle, and from analytical methods like FBP by solving the inverse problem via iterative optimization rather than direct inversion [S1].

## How it works
**Inputs and Outputs:**
- Input: Sinogram $p(r, \theta)$, where $r$ is the detector coordinate and $\theta$ is the projection angle.
- Input: Number of angles $N_\theta$.
- Output: Reconstructed volume $f(x)$.

**Data Structures:**
- Volume $f$: 3D grid of voxel values.
- Residual $\rho(r, \theta)$: 2D array matching the detector dimensions for the current angle.
- Permutation $\pi$: Array of indices $1 \dots N_\theta$ defining the order of angle processing.

**Formulas:**
The functional to minimize is:
$$
\Gamma_{ART}[\psi] = \sum_{r,\theta} \| \rho(r, \theta) \|^2
$$
where $\rho(r, \theta) = p(r, \theta) - R_\theta[\psi(x)]$ is the residual between the acquired projection $p$ and the forward projection $R_\theta$ of the current volume estimate $\psi$ [S1].

**Parameters:**
- Convergence threshold $\epsilon$: A small positive value determining when to stop iterations, dependent on noise and artifact levels [S1].
- Number of iterations $N_{ART}$: Typically a few iterations are required for convergence [S1].

**Steps:**
1. Initialize iteration counter $n=1$, volume $f^{(1)}(x) = 0$, and residual $\rho(r, \theta) = p(r, \theta)$ [S1].
2. Choose a permutation $\pi$ over $N_\theta$ indices to order angles non-consecutively, which accelerates convergence [S1].
3. While $\|\rho(r, \theta)\| > \epsilon$:
    a. For $k = 1$ to $N_\theta$:
        i. Let $m = \pi(k)$ be the current angle index.
        ii. Compute the residual for the current angle: $\rho(r, \theta_m) = p(r, \theta_m) - R_{\theta_m}[f^{(n)}(x)]$ [S1].
        iii. Back-project the residual: $\Delta f^{(n+1)}(x) = B_{\theta_m}[\rho(r, \theta_m)]$, where $B_{\theta_m}$ is the back-projection operator for angle $\theta_m$ [S1].
        iv. Update the volume: $f^{(n+1)}(x) = f^{(n)}(x) + \Delta f^{(n+1)}(x)$ [S1].
        v. Apply constraints (e.g., positivity: $f^{(n+1)}(x) = \max(f^{(n+1)}(x), 0)$) [S1].
    b. Increment $n \leftarrow n + 1$ [S1].

**Pseudocode:**
```python
def ART(p, N_theta, epsilon):
    # p: sinogram array [num_detectors, N_theta]
    # N_theta: number of projection angles
    # epsilon: convergence threshold
    
    # Initialize volume to zeros
    # f shape depends on voxel grid dimensions
    f = zeros_like_volume()
    
    # Create permutation of angle indices
    pi = permutation(range(N_theta))
    
    n = 1
    while True:
        # Check convergence on the full residual norm
        # Note: In practice, one might check the norm of the last updated residual
        # or the global residual. The source checks ||rho|| > epsilon.
        # We compute global residual norm for the stopping criterion.
        residual_norm = compute_global_residual_norm(p, f)
        if residual_norm <= epsilon:
            break
            
        for k in range(N_theta):
            m = pi[k]
            theta_m = get_angle(m)
            
            # 1. Forward project current volume to get estimated projection
            projected = forward_project(f, theta_m)
            
            # 2. Compute residual for this angle
            rho = p[:, m] - projected
            
            # 3. Back-project residual to get volume update
            delta_f = back_project(rho, theta_m)
            
            # 4. Update volume
            f = f + delta_f
            
            # 5. Apply constraints (e.g., positivity)
            f = max(f, 0)
            
        n += 1
        
    return f
```

**Edge Cases and Pitfalls:**
- Convergence is faster when angles are not sampled consecutively but with large differences between successive angles [S1].
- The method avoids explicit matrix storage, making it suitable for large-scale problems where memory is constrained [S1].
- Additional prior information (regularization) can be added to the functional to compensate for limited angle ranges or coarse sampling, improving quality over FBP at higher computational cost [S1].

## Operating characteristics
- **Time Complexity:** Iterative; convergence speed depends on the permutation of angles and the condition number of the system. Typically requires a few iterations for convergence [S1].
- **Memory Complexity:** Low, as it avoids storing the full system matrix, operating directly on projections and volume updates [S1].
- **Strengths:** Handles missing data and limited angles better than analytical methods when combined with regularization; computationally efficient in memory [S1].
- **Limitations:** Slower than analytical methods like FBP for simple cases; convergence can be sensitive to noise and the choice of permutation [S1].
- **When to use:** When memory is limited, or when dealing with incomplete/limited-angle data where regularization can improve results [S1].

## Background
The Algebraic Reconstruction Technique was introduced as an alternative to Fourier space reconstruction methods, which require ideal conditions like a continuous range of angles [S1]. It exploits the linear structure of the tomographic problem to solve the inverse problem iteratively, minimizing the quadratic norm of the projection residuals [S1]. It is widely used in materials science and medical imaging where limited angle access or noisy data is common [S1].
