# Algebraic Reconstruction Technique (ART)

Also called: ART (Algebraic Reconstruction Technique), Frame-driven Kaczmarz method, Incremental learning in reflective tomography, Kaczmarz method, Reflective Tomography via Algebraic Reconstruction Technique (ART)

## Overview
Algebraic Reconstruction Technique (ART) is an iterative algebraic method for solving the linear inverse problem of tomographic reconstruction, minimizing the quadratic norm of the difference between acquired projections and the projected reconstructed volume [S1]. It avoids explicit storage of the system matrix by sequentially updating voxel values based on the residual error between the measured sinogram and the back-projected correction [S3, unofficial]. The technique accepts general calibrated acquisition geometries, including arbitrarily located cameras, without requiring circular rotation constraints [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N_\theta$ acquired projection images (sinogram data) $p(r, \theta)$, where $r$ is the detector coordinate and $\theta$ is the view angle [S1].
*   **Output:** A reconstructed 3D volume $f(x)$ [S1].

**Data Structures:**
*   **Volume $f$:** A 3D grid of voxel values, initialized to zero [S1].
*   **Residual $\rho$:** A 2D array matching the dimensions of the projection images, storing the difference between measured and computed projections [S1].
*   **Permutation $\pi$:** An array of indices $1 \dots N_\theta$ defining the order in which angles are processed [S1].

**Formulas:**
The method minimizes the functional [S1]:
$$ \Gamma_{ART}[\psi] = \sum_{r,\theta} \| \rho(r, \theta) \|^2 $$
where $\psi$ is the reconstructed volume estimate and the residual is defined as:
$$ \rho(r, \theta) = p(r, \theta) - R_\theta[\psi(x)] $$
Here, $R_\theta[\psi(x)]$ is the forward projection (X-ray transform) of the volume $\psi$ at angle $\theta$ [S1]. The goal is to find $f = \text{Argmin}_\psi \Gamma_{ART}[\psi]$ [S1].

**Steps:**
1.  **Initialization:** Set iteration counter $n=1$. Initialize the volume estimate $f^{(1)}(x) = 0$. Initialize the residual $\rho(r, \theta) = p(r, \theta)$ for all $r, \theta$ [S1].
2.  **Permutation:** Choose a permutation $\pi$ over the $N_\theta$ angle indices to order angles non-consecutively [S1].
3.  **Iteration Loop:** While the norm of the residual $\|\rho(r, \theta)\| > \epsilon$ (where $\epsilon$ is a convergence threshold):
    1.  Iterate $k$ from $1$ to $N_\theta$.
    2.  Let $m = \pi(k)$ be the current angle index.
    3.  **Compute Residual for Current View:** Calculate the difference between the acquired projection and the forward projection of the current volume estimate:
        $$ \rho(r, \theta_m) \leftarrow p(r, \theta_m) - R_{\theta_m}[f^{(n)}(x)] $$
    4.  **Back-project Correction:** Compute the correction term by back-projecting the residual for the current view:
        $$ \Delta f^{(n+1)}(x) \leftarrow B_{\theta_m}[\rho(r, \theta_m)] $$
        Where $B_{\theta_m}$ is the back-projection operator for angle $\theta_m$ [S1].
    5.  **Update Volume:** Add the correction to the volume:
        $$ f^{(n+1)}(x) \leftarrow f^{(n)}(x) + \Delta f^{(n+1)}(x) $$
    6.  **Apply Constraints:** Enforce physical constraints, such as positivity: $f^{(n+1)}(x) = \max(f^{(n+1)}(x), 0)$ [S1].
    7.  Increment iteration counter: $n \leftarrow n + 1$ [S1].

**Parameters:**
*   **Convergence Threshold $\epsilon$:** A small value determining when to stop iterations, chosen with respect to noise and artifact acquisition levels [S1].
*   **Number of Iterations $N_{ART}$:** Typically, a few iterations are required for convergence [S1].

**Pitfalls:**
*   **Convergence Speed:** Convergence is significantly faster when angles are not sampled consecutively. Using a random or shuffled permutation $\pi$ is recommended [S1].
*   **Constraints:** Physical constraints like positivity can be applied to the volume update to enforce non-negative voxel values [S1].

**Pseudocode:**
```python
def ART(projections, angles, forward_project, back_project, num_angles, epsilon):
    # Initialize volume to zero. Shape must be known from acquisition geometry.
    volume = [[[0.0 for _ in range(Z)] for _ in range(Y)] for _ in range(X)]
    # Initialize residual with acquired projections
    residuals = [proj[:] for proj in projections]
    # Generate permutation of angle indices
    indices = list(range(num_angles))
    # Deterministic permutation for reproducibility
    for i in range(num_angles - 1, 0, -1):
        j = (i * 7 + 3) % (i + 1)
        indices[i], indices[j] = indices[j], indices[i]
    iteration = 1
    # Compute initial residual norm
    residual_norm = sum(r**2 for proj in residuals for r in proj) ** 0.5
    while residual_norm > epsilon:
        for k in range(num_angles):
            m = indices[k]
            theta = angles[m]
            # 1. Compute residual for current view
            projected_volume = forward_project(volume, theta)
            residuals[m] = [projections[m][i] - projected_volume[i] for i in range(len(projections[m]))]
            # 2. Back-project correction
            correction = back_project(residuals[m], theta)
            # 3. Update volume
            volume = [[[volume[x][y][z] + correction[x][y][z] for z in range(Z)] for y in range(Y)] for x in range(X)]
            # 4. Apply positivity constraint
            volume = [[[max(0.0, v) for z in range(Z)] for y in range(Y)] for x in range(X)]
        iteration += 1
        residual_norm = sum(r**2 for proj in residuals for r in proj) ** 0.5
    return volume
```

## Subtopics

### [Motion-Compensated Algebraic Reconstruction Technique](7422-motion-compensated-algebraic-reconstruction-technique.md)
DynART handles dynamic volumes by warping the volume estimate according to a displacement field before projection, unlike standard ART which assumes a static object.

### [Direct Linear Inversion (ART)](8506-direct-linear-inversion-art.md)
Solves the linear system $M \mathbf{v} = \mathbf{d}$ via pseudo-inverse in a single step, avoiding iterative updates entirely.

### [Simultaneous Algebraic Reconstruction Technique (SART)](10119-simultaneous-algebraic-reconstruction-technique-sart.md)
Updates the volume using all rays in a projection image simultaneously, offering faster convergence than ART's sequential ray-by-ray updates.

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of iterations and the number of rays processed per iteration [S1].
*   **Memory Complexity:** Low. It does not require storing the full system matrix, only the volume and projection data [S1].
*   **Strengths:** Flexible geometry (does not require circular rotation or specific acquisition constraints like FDK); handles missing angles and noise better than analytical methods when combined with regularization [S1]; suitable for reflective tomography with arbitrary camera positions [S2].
*   **Limitations:** Convergence speed depends heavily on the angle permutation [S1].
*   **When to use:** When acquisition geometry is non-standard (e.g., reflective tomography, arbitrary camera views) or when memory constraints prevent storing the system matrix [S1, S2].
*   **When not to use:** When high-speed reconstruction is required and geometry is standard (use FBP or SART); when the number of projections is very small and regularization is critical (ART alone may not suffice without additional priors) [S1].

## Background
ART was introduced in the 1970s by Gordon et al. [S3, unofficial]. It is based on the Kaczmarz method for solving linear systems [S3, unofficial]. The technique has been adapted for various fields, including X-ray tomography [S1] and reflective tomography for 3D multiple-view reconstruction using calibrated images [S2]. It is often compared to analytical methods like FDK, offering better quality at the expense of higher computational cost [S1].
