# Stochastic Tomography Sample Acceptance and Residual Splatting


## Overview
This method defines the acceptance criterion and state update mechanism for the Stochastic Tomography solver [8886-stochastic-tomography.md] [S1]. It determines whether a candidate sample improves the reconstruction by evaluating the change in squared residuals across all projections, and if accepted, updates the residual images using bilinear splatting [S1]. It distinguishes itself by allowing both positive and negative emissivity deposition to enable "rough-in" and refinement phases, and by rejecting samples outside the visual hull to avoid wasted computation [S1].

## How it works

### Inputs and Outputs
*   **Inputs**:
    *   Candidate sample position $\mathbf{x}_k$ [S1].
    *   Current residual images $\mathbf{r}_j$ for each projection $j$ [S1].
    *   Projection operator $\text{proj}_j(\cdot)$ mapping 3D space to 2D image coordinates [S1].
    *   Deposition emissivity magnitude $e_d$ [S1].
    *   Total observed emissivity $e_{tot}$ (average sum of measurements $o_i$ over all cameras) [S1].
    *   Chain length $N$ (mutations per chain) [S1].
    *   Scale factor $\alpha$ (typically 10–40) [S1].
*   **Outputs**:
    *   Updated residual images $\mathbf{r}_j$ [S1].
    *   Boolean acceptance flag for $\mathbf{x}_k$ [S1].
    *   The sample $\mathbf{x}_k$ is added to the volume representation if accepted [S1].

### Data Structures
*   **Residual Images**: A set of 2D arrays $\mathbf{r}_j$, one per camera/projection $j$ [S1]. Values represent the difference between measured and projected emissivity [S1].
*   **Sample List**: A collection of accepted 3D points $\{\mathbf{x}_k\}$ with associated emissivity signs [S1].

### Parameters
*   $e_d$: Quantized emissivity per sample. Controls quantization level if emissivity range is known [S1].
*   $N$: Chain length. Typical values: 1000 to 20000 [S1].
*   $\Gamma$: Total number of sampling chains. Determined by $\Gamma = \alpha \frac{e_{tot}}{N e_d}$ [S1].
*   $\alpha$: Scale factor for acceptance rate. Typical values: 10–40 [S1].

### Algorithm Steps

1.  **Visual Hull Check**: If $\mathbf{x}_k$ falls outside the visual hull for any image $j$ (i.e., the measured value in at least one camera is zero), reject $\mathbf{x}_k$ immediately [S1].
2.  **Project Candidate**: Compute the 2D projection coordinates for all views: $\mathbf{p}_{k,j} = \text{proj}_j(\mathbf{x}_k)$ [S1].
3.  **Evaluate Positive Change**: Calculate the change in squared residuals if positive emissivity $+e_d$ is deposited. Compute tentative residual: $\tilde{\mathbf{r}}_j^+ = \mathbf{r}_j - \text{splat}(\mathbf{0}, \mathbf{p}_{k,j}, +e_d)$. Compute squared residual difference: $\Delta^+ F(\mathbf{x}_k) = \sum_j \left( \|\mathbf{r}_j\|^2 - \|\tilde{\mathbf{r}}_j^+\|^2 \right)$ [S1].
4.  **Evaluate Negative Change**: Calculate the change in squared residuals if negative emissivity $-e_d$ is deposited. Compute tentative residual: $\tilde{\mathbf{r}}_j^- = \mathbf{r}_j - \text{splat}(\mathbf{0}, \mathbf{p}_{k,j}, -e_d)$. Compute squared residual difference: $\Delta^- F(\mathbf{x}_k) = \sum_j \left( \|\mathbf{r}_j\|^2 - \|\tilde{\mathbf{r}}_j^-\|^2 \right)$ [S1].
5.  **Select Sign**: Determine the best sign $s \in \{+1, -1\}$ that maximizes the residual reduction. $s = \arg\max_{s' \in \{+1, -1\}} \Delta^{s'} F(\mathbf{x}_k)$. $\Delta F(\mathbf{x}_k) = \max(\Delta^+ F(\mathbf{x}_k), \Delta^- F(\mathbf{x}_k))$ [S1].
6.  **Acceptance Test**: If $\Delta F(\mathbf{x}_k) > 0$ (i.e., the residual decreases), accept the sample. Otherwise, reject it [S1].
7.  **Residual Splatting**: If accepted, update the residual images by splatting the chosen emissivity $s \cdot e_d$ at the projected points $\mathbf{p}_{k,j}$ using bilinear weights. $\mathbf{r}_j \leftarrow \text{splat}(\mathbf{r}_j, \mathbf{p}_{k,j}, s \cdot e_d) \quad \forall j$ [S1].

### Pseudocode

```python
def accept_and_splat(x_k, r_j_list, proj_func, e_d, visual_hull_mask):
    # Step 1: Visual Hull Check
    # Reject if x_k projects to a zero-measured pixel in any view [S1]
    for j, r_j in enumerate(r_j_list):
        p_kj = proj_func(x_k, j)
        i, v = int(p_kj[0]), int(p_kj[1])
        if not (0 <= i < r_j.shape[0] and 0 <= v < r_j.shape[1] and visual_hull_mask[j][i, v] == 0):
            return r_j_list, False

    # Step 2: Project Candidate
    projected_points = [proj_func(x_k, j) for j in range(len(r_j_list))]

    # Helper: Compute squared residual reduction for a given sign
    def compute_delta_residual(sign):
        total_reduction = 0.0
        for j, r_j in enumerate(r_j_list):
            p_kj = projected_points[j]
            # Current squared norm
            current_norm_sq = sum(val**2 for row in r_j for val in row)
            # Compute tentative residual norm analytically using bilinear weights
            u, v = p_kj[0] - int(p_kj[0]), p_kj[1] - int(p_kj[1])
            i0, j0 = int(p_kj[0]), int(p_kj[1])
            # Weights for 4 surrounding pixels
            w00, w01, w10, w11 = (1-u)*(1-v), u*(1-v), (1-u)*v, u*v
            # Pixel values at the 4 corners (0 if out of bounds)
            p00 = r_j[i0, j0] if i0 < r_j.shape[0] and j0 < r_j.shape[1] else 0.0
            p01 = r_j[i0, j0+1] if i0 < r_j.shape[0] and j0+1 < r_j.shape[1] else 0.0
            p10 = r_j[i0+1, j0] if i0+1 < r_j.shape[0] and j0 < r_j.shape[1] else 0.0
            p11 = r_j[i0+1, j0+1] if i0+1 < r_j.shape[0] and j0+1 < r_j.shape[1] else 0.0
            # Tentative values after splatting sign*e_d
            t00 = p00 - sign * e_d * w00
            t01 = p01 - sign * e_d * w01
            t10 = p10 - sign * e_d * w10
            t11 = p11 - sign * e_d * w11
            # Sum of squares of modified pixels
            tentative_norm_sq = current_norm_sq - (p00**2 + p01**2 + p10**2 + p11**2) + (t00**2 + t01**2 + t10**2 + t11**2)
            reduction = current_norm_sq - tentative_norm_sq
            total_reduction += reduction
        return total_reduction

    # Step 3 & 4: Evaluate Positive and Negative Changes
    delta_plus = compute_delta_residual(1)
    delta_minus = compute_delta_residual(-1)

    # Step 5: Select Sign
    if delta_plus >= delta_minus:
        best_sign = 1
        delta_f = delta_plus
    else:
        best_sign = -1
        delta_f = delta_minus

    # Step 6: Acceptance Test
    if delta_f <= 0:
        return r_j_list, False

    # Step 7: Residual Splatting
    updated_r_j_list = []
    for j, r_j in enumerate(r_j_list):
        p_kj = projected_points[j]
        u, v = p_kj[0] - int(p_kj[0]), p_kj[1] - int(p_kj[1])
        i0, j0 = int(p_kj[0]), int(p_kj[1])
        w00, w01, w10, w11 = (1-u)*(1-v), u*(1-v), (1-u)*v, u*v
        new_r_j = [row[:] for row in r_j] # Deep copy
        if i0 < new_r_j.shape[0] and j0 < new_r_j.shape[1]: new_r_j[i0][j0] -= best_sign * e_d * w00
        if i0 < new_r_j.shape[0] and j0+1 < new_r_j.shape[1]: new_r_j[i0][j0+1] -= best_sign * e_d * w01
        if i0+1 < new_r_j.shape[0] and j0 < new_r_j.shape[1]: new_r_j[i0+1][j0] -= best_sign * e_d * w10
        if i0+1 < new_r_j.shape[0] and j0+1 < new_r_j.shape[1]: new_r_j[i0+1][j0+1] -= best_sign * e_d * w11
        updated_r_j_list.append(new_r_j)

    return updated_r_j_list, True
```

### Edge Cases and Pitfalls
*   **Visual Hull Rejection**: Samples outside the visual hull are automatically rejected. This prevents placing samples that cannot contribute to the reconstruction and avoids the need to "undo" them later [S1].
*   **Negative Emissivity**: The method explicitly allows negative emissivity deposition. This is crucial for "roughing in" areas and refining them later, and is necessary for regularizers to function properly [S1].
*   **Parameter Sensitivity**: The method is relatively insensitive to the chain length $N$ (1000–20000 works well). The total number of chains $\Gamma$ is determined by $e_{tot}$, $N$, $e_d$, and $\alpha$ [S1].

## Operating characteristics

*   **Time Complexity**: Not given in the sources.
*   **Memory Complexity**: Not given in the sources.
*   **Strengths**:
    *   Allows both positive and negative emissivity, improving convergence and enabling refinement [S1].
    *   Visual hull rejection avoids wasted computation on invalid samples [S1].
    *   Insensitive to chain length $N$ [S1].
*   **Limitations**:
    *   Requires visual hull information [S1].
    *   Parameter $\alpha$ is data-dependent (10–40) [S1].
    *   Bilinear splatting introduces smoothing, which may affect high-frequency details [G].

## Background

*   **Origin**: This method is part of the Stochastic Tomography framework introduced by [S1].
*   **History**: Developed for 3D imaging of mixing fluids, addressing the challenges of tomographic reconstruction using a matrix-free stochastic solver [S1].
*   **Usage**: Applied in 3D imaging of mixing fluids, where it minimizes a convex objective function by representing the volume estimate as a set of discrete samples [S1].
