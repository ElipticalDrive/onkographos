# SIRT (Simultaneous Iterative Reconstruction Technique)
Also called: SIRT Reconstruction, Simultaneous Iterative Reconstruction Technique

## Overview
SIRT is an iterative algebraic reconstruction technique for computed tomography that minimizes the discrepancy between measured and simulated projections by updating all voxels simultaneously [S1, unofficial][S3, unofficial]. It differs from its sibling [Algebraic Reconstruction Technique (ART)](6944-algebraic-reconstruction-technique-art.md) by applying a global correction using all projection lines at once, rather than updating sequentially per view [S1, unofficial][S3, unofficial].

## How it works
**Inputs:**
*   $y$: Vector of measured projection data (size $N_p$) [S1, unofficial].
*   $A$: System matrix representing the forward projection operator (size $N_p \times N_v$) [S1, unofficial].
*   $x^{(0)}$: Initial volume estimate [S1, unofficial].
**Outputs:**
*   $x^{(k)}$: Reconstructed volume vector (size $N_v$) [S1, unofficial].
**Data Structures:**
*   $x$: Volume vector, typically initialized to zeros [S1, unofficial].
*   $R$: Diagonal matrix for ray normalization [S1, unofficial].
*   $C$: Diagonal matrix for voxel sensitivity normalization [S1, unofficial].
*   $A^T$: Transpose of the system matrix, representing the backprojection operator [S1, unofficial].
**Formulas:**
The update rule for iteration $k$ is:
$$x^{(k+1)} = \max(0, x^{(k)} + C A^T R (y - A x^{(k)}))$$
Where:
*   $R$ is a diagonal matrix with entries $R_{jj} = \frac{1}{(A \mathbf{1})_j}$ if $(A \mathbf{1})_j > 0$, else $0$ [S1, unofficial]. Here $\mathbf{1}$ is a vector of ones. $R$ normalizes each ray residual by its total intersected length [S1, unofficial].
*   $C$ is a diagonal matrix with entries $C_{ii} = \frac{1}{(A^T \mathbf{1})_i}$ if $(A^T \mathbf{1})_i > 0$, else $0$ [S1, unofficial]. $C$ normalizes the backprojected update by the accumulated voxel sensitivity [S1, unofficial].
*   $\max(0, \cdot)$ enforces nonnegativity componentwise [S1, unofficial].
**Parameters:**
*   $x^{(0)}$: Initial guess, typically $x^{(0)} = 0$ [S1, unofficial].
*   $step\_size$ ($\alpha$): Relaxation parameter or learning rate. Default value is $10^{-2}$ [S2, unofficial]. The standard formulation above omits an explicit scalar step size, but implementations may include one [S1, unofficial][S2, unofficial].
*   $iters$: Number of iterations. The sources cite 200 iterations for measured walnut data [S1, unofficial] and 20 iterations for synthetic phantoms [S2, unofficial].
**Pseudocode:**
```python
def zeros(shape):
    return [0.0] * shape[0] if len(shape) == 1 else [zeros(shape[1:]) for _ in range(shape[0])]
def ones(shape):
    return [1.0] * shape[0] if len(shape) == 1 else [ones(shape[1:]) for _ in range(shape[0])]
def diag(vec):
    return [[vec[i] if i == j else 0.0 for j in range(len(vec))] for i in range(len(vec))]
def max(a, b):
    return [a[i] if a[i] > b[i] else b[i] for i in range(len(a))]
def sirt(projections, forward_project, backproject, vol_shape, iters=200):
    volume = zeros(vol_shape)
    ones_v = ones(vol_shape)
    ray_lengths = forward_project(ones_v)
    ones_p = ones(projections.shape)
    voxel_sensitivities = backproject(ones_p, vol_shape)
    R = diag([1.0 / ray_lengths[j] if ray_lengths[j] > 0 else 0.0 for j in range(len(ray_lengths))])
    C = diag([1.0 / voxel_sensitivities[i] if voxel_sensitivities[i] > 0 else 0.0 for i in range(len(voxel_sensitivities))])
    for k in range(iters):
        sim_proj = forward_project(volume)
        residual = [projections[j] - sim_proj[j] for j in range(len(projections))]
        normalized_residual = [sum(R[j][m] * residual[m] for m in range(len(residual))) for j in range(len(residual))]
        correction = backproject(normalized_residual, vol_shape)
        normalized_correction = [C[i][i] * correction[i] for i in range(len(correction))]
        volume = max(volume, normalized_correction)
    return volume
```
**Edge Cases and Pitfalls:**
*   **Zero Sensitivity:** If a voxel is never intersected by any ray, $(A^T \mathbf{1})_i = 0$, leading to division by zero in $C_{ii}$; the definition specifies setting $C_{ii} = 0$ in this case [S1, unofficial].
*   **Zero Ray Length:** If a ray does not intersect the volume, $(A \mathbf{1})_j = 0$, leading to division by zero in $R_{jj}$; the definition specifies setting $R_{jj} = 0$ in this case [S1, unofficial].

## Subtopics

### [SART (Simultaneous Algebraic Reconstruction Technique)](3277-sart-simultaneous-algebraic-reconstruction-technique.md)
SART is an iterative algebraic reconstruction technique based on the Kaczmarz projection method, used to solve the data fidelity term in tomographic reconstruction problems. It updates the reconstructed volume for each scan view, offering modest memory requirements and superior performance over direct methods like FDK in limited projection scenarios. It is preferred over Conjugate Gradient (CG) for sparse-view settings because CG suffers from numerical noise in matrix-free implementations and convergence issues with large sparse systems.

### Iterative Reconstruction (SIRT via Adjoint)
A classical Simultaneous Iterative Reconstruction Technique (SIRT) implementation using a custom backprojector, without autodiff [S2, unofficial]. It initializes the volume to zeros and iteratively computes the forward projection, residual error, backprojected correction, and volume update [S2, unofficial]. This variant omits the explicit normalization matrices $R$ and $C$ found in the theoretical definition, relying instead on a fixed `step_size` (default $10^{-2}$) to control convergence [S2, unofficial].

## Operating characteristics
*   **Performance:** SIRT requires multiple iterations to converge, such as 200 iterations for measured walnut data, compared to direct methods like FDK which compute the result in a single pass [S1, unofficial].
*   **Strengths:** The method enforces nonnegativity via the $\max(0, \cdot)$ operation [S1, unofficial]. Normalization by ray length and voxel sensitivity scales the updates to account for geometric coverage [S1, unofficial].
*   **Limitations:** Convergence is slower than direct methods. Implementations that omit the normalization matrices require careful tuning of the `step_size` parameter [S2, unofficial].

## Background
The method is implemented in open-source CT reconstruction libraries, including `diffct` and `physics-aware-ct-reconstruction` [S1, unofficial][S2, unofficial].
