# ACID (Adversarial Calibration Iterative Deep learning)

Also called: ACID scheme, ACID workflow, Adversarial Calibration Iterative Deep learning, Adversarial Convergence Iterative Deep learning

## Overview

ACID is an iterative reconstruction framework that stabilizes unstable deep learning-based tomographic reconstruction by combining a data-driven neural network prior with Compressed Sensing (CS)-based sparsity constraints and an explicit residual calibration step [S1]. It solves the problem of underdetermined inverse problems (where the number of measurements is less than the unknowns) where standard sparsity-promoting algorithms fail to recover null-space components and standalone deep networks produce unstable, artifact-ridden outputs [S1]. Unlike [Iterative Reconstruction (SIRT via Autodiff)](12326-iterative-reconstruction-sirt-via-autodiff.md), which relies on gradient descent through a differentiable forward model to minimize data fidelity, ACID uses a closed-form block coordinate descent update that alternates between calibrating projection-domain residuals and applying a sparsity-filtered neural network update, ensuring convergence even when the neural network is imperfect [S1].

## How it works

### Inputs and Outputs
*   **Inputs:**
    *   $p^{(0)} \in \mathbb{R}^m$: Original measured projection data.
    *   $A \in \mathbb{R}^{m \times N}$: System matrix (e.g., Radon transform for CT, Fourier transform for MRI). Note: $m < N$ (underdetermined).
    *   $\Phi(\cdot)$: A pre-trained deep neural network (recon-net) mapping projection data to image space.
    *   $H \in \mathbb{R}^{N \times N}$: Sparse transform matrix (e.g., wavelet or discrete gradient for Total Variation). $H^*$ is its adjoint.
    *   Hyperparameters: $\lambda > 0$, $\mu \ge 0$, $\xi > 0$.
*   **Outputs:**
    *   $f^{(K)}$: Reconstructed image after $K$ iterations.

### Data Structures
*   **Image $f$**: Vector of size $N$ (or 2D/3D array reshaped to $N$).
*   **Residual $p$**: Vector of size $m$.
*   **Transformed Image $\bar{f}$**: Vector of size $N$ (in the domain of $H$).

### Parameters
*   $\lambda$: Weight for data fidelity (measured noise energy).
*   $\mu$: Weight for residual error energy in the projection domain.
*   $\xi$: Weight for sparsity term $\|Hf\|_1$.
*   $\varepsilon = \xi / \lambda$: Effective soft-thresholding value.
*   $M_1 = \frac{\lambda}{1 + \lambda + \mu}$.
*   $M_2 = \frac{1 + \mu}{\lambda}$.
*   $M = \frac{M_1}{M_2} = \frac{1 + \mu}{1 + \lambda + \mu}$. Note that $M < 1$.

### Formulas
The method minimizes the objective function:
$$ L(p,f) := \frac{1}{2}\|\Phi(Af+p)-f\|_2^2 + \frac{\lambda}{2}\|p^{(0)}-Af-p\|_2^2 + \frac{\mu}{2}\|p\|_2^2 + \xi\|Hf\|_1 $$

The updates are derived via block coordinate descent with approximations $\frac{\partial \Phi}{\partial p} \cong A^{-1}$ and $A\Phi(p) \cong p$ [S1]:

1.  **Residual Update:**
    $$ p^{(k+1)} = M_1 (p^{(0)} - A f^{(k)}) $$
2.  **Intermediate Image Update:**
    $$ f^{(k+1/2)} = f^{(k)} + M_2 \Phi(p^{(k+1)}) $$
3.  **Image Update (Soft-Thresholding):**
    $$ f^{(k+1)} = H^* S_\varepsilon (H f^{(k+1/2)}) $$

Where $S_\varepsilon(x)$ is the soft-thresholding kernel:
$$ S_\varepsilon(x) = \begin{cases} 0 & \text{if } |x| < \varepsilon \\ x - \text{sgn}(x)\varepsilon & \text{otherwise} \end{cases} $$

**Total Variation (TV) Specifics:**
If $H$ is the non-unitary discrete gradient transform (TV minimization), $H^*$ acts as a pseudo-inverse. The update for pixel $(i_w, i_h)$ is:
$$ f^{(k+1)}_{(i_w,i_h)} = \frac{1}{4} \sum_{\text{neighbors } (j_w,j_h)} S^{-1}_\varepsilon(f^{(k+1/2)}_{(i_w,i_h)}, f^{(k+1/2)}_{(j_w,j_h)}) $$
Where the pseudo-inverse kernel $S^{-1}_\varepsilon(v_a, v_b)$ is:
$$ S^{-1}_\varepsilon(v_a, v_b) = \begin{cases} \frac{v_a+v_b}{2} & \text{if } |v_a-v_b| \le \varepsilon \\ v_a - \frac{\varepsilon}{2} & \text{if } v_a-v_b > \varepsilon \\ v_a + \frac{\varepsilon}{2} & \text{if } v_a-v_b < -\varepsilon \end{cases} $$

### Pseudocode

```python
import numpy as np

def soft_threshold(x, epsilon):
    """
    Applies soft-thresholding to array x with threshold epsilon.
    """
    return np.sign(x) * np.maximum(np.abs(x) - epsilon, 0)

def pseudo_inverse_soft_threshold(v_a, v_b, epsilon):
    """
    Computes the pseudo-inverse soft-thresholding value for two adjacent pixels.
    Used for Total Variation (TV) minimization with non-unitary gradient transform.
    """
    diff = v_a - v_b
    if abs(diff) <= epsilon:
        return (v_a + v_b) / 2.0
    elif diff > epsilon:
        return v_a - epsilon / 2.0
    else:
        return v_a + epsilon / 2.0

def acid_reconstruct(p0, A, Phi, H, H_adj, num_iterations, lambda_param, mu_param, xi_param, 
                     image_shape, use_tv=False):
    """
    Performs ACID reconstruction.
    
    Args:
        p0: Initial projection data (m,)
        A: System matrix function or object that computes A @ f (forward projection)
        Phi: Neural network function that computes Phi(p) (reconstruction)
        H: Sparse transform function that computes H @ f
        H_adj: Adjoint transform function that computes H^* @ f_bar
        num_iterations: Number of ACID steps
        lambda_param: Hyperparameter lambda
        mu_param: Hyperparameter mu
        xi_param: Hyperparameter xi
        image_shape: Shape of the image f (e.g., (N,)) or (H, W)
        use_tv: Boolean, if True uses TV-specific pseudo-inverse update for H^*
        
    Returns:
        f: Reconstructed image
    """
    # Hyperparameter constants
    M1 = lambda_param / (1.0 + lambda_param + mu_param)
    M2 = (1.0 + mu_param) / lambda_param
    epsilon = xi_param / lambda_param
    
    # Initialize f. 
    # Source assumes initial image Phi(p(0)) = f* + f(ob,0) + f(nl,0).
    # In practice, we start with the network's output on the raw data.
    f = Phi(p0)
    
    # If using TV, H is non-unitary gradient. 
    # We need to handle the H^* step carefully.
    # For standard unitary H (e.g. wavelets), H_adj(H(f)) is sufficient.
    
    for k in range(num_iterations):
        # Step 1: Update Residual p
        # p(k+1) = M1 * (p(0) - A * f(k))
        Af = A(f)
        residual = p0 - Af
        p_new = M1 * residual
        
        # Step 2: Neural Network Update
        # Delta_f = Phi(p(k+1))
        delta_f = Phi(p_new)
        
        # Step 3: Intermediate Image
        # f(k+1/2) = f(k) + M2 * Phi(p(k+1))
        f_intermediate = f + M2 * delta_f
        
        # Step 4: Sparsity/TV Filtering
        if use_tv:
            # Total Variation Minimization
            # f(k+1) = H^* S_epsilon (H f(k+1/2))
            # Since H is discrete gradient (non-unitary), we use the pixel-wise 
            # pseudo-inverse formulation described in the source.
            
            # 1. Apply Soft Thresholding to the gradients
            # H(f_intermediate) gives gradients (dx, dy)
            gradients = H(f_intermediate)
            
            # We need to reconstruct f from thresholded gradients.
            # The source defines f(iw, ih) as the average of pseudo-inverse 
            # soft-thresholding of neighbors.
            # This is an iterative solver step itself or a direct solve?
            # The source Eq 23 gives a direct formula for f(k+1) based on 
            # f(k+1/2) values. It implies a local averaging operation.
            
            # Let's implement the direct pixel update from Eq 23.
            # Note: This formula calculates f(k+1) directly from f(k+1/2).
            # It effectively solves the proximal operator for TV.
            
            f_new = np.zeros_like(f_intermediate)
            
            # Iterate over pixels to compute neighbors
            # Assuming f_intermediate is 2D (H, W)
            h, w = f_intermediate.shape
            
            for i in range(h):
                for j in range(w):
                    val_center = f_intermediate[i, j]
                    
                    # Define neighbors
                    neighbors = []
                    if i > 0: neighbors.append(f_intermediate[i-1, j])
                    if i < h-1: neighbors.append(f_intermediate[i+1, j])
                    if j > 0: neighbors.append(f_intermediate[i, j-1])
                    if j < w-1: neighbors.append(f_intermediate[i, j+1])
                    
                    # Sum of pseudo-inverse soft thresholds
                    sum_pinv = 0.0
                    count = len(neighbors)
                    
                    for neighbor_val in neighbors:
                        sum_pinv += pseudo_inverse_soft_threshold(val_center, neighbor_val, epsilon)
                    
                    f_new[i, j] = sum_pinv / count
            
            f = f_new
            
        else:
            # Standard Unitary Transform (e.g., Wavelets)
            # f(k+1) = H^* ( S_epsilon ( H ( f(k+1/2) ) ) )
            f_transformed = H(f_intermediate)
            f_thresholded = soft_threshold(f_transformed, epsilon)
            f = H_adj(f_thresholded)
            
    return f
```

### Edge Cases and Pitfalls
*   **Underdetermined System:** The system matrix $A$ has $m < N$. Without priors, the solution is not unique. ACID handles this by intersecting the solution space with sparse and deep prior spaces [S1].
*   **Non-Unitary $H$:** If using TV, $H$ is not invertible. The method interprets $H^*$ as a pseudo-inverse via the neighbor-averaging formula (Eq 23) [S1].
*   **Network Instability:** If the network $\Phi$ produces large artifacts, convergence is still guaranteed provided the relative error in the L2 norm is controlled (<100%) [S1].
*   **RIP Violation:** If the Restricted Isometry Property (RIP) is not satisfied, ACID may converge to a solution with a nonzero null-space component. However, it reduces the feasible space more effectively than sparsity-only methods [S1].
*   **Noise Floor:** The parameter $\varepsilon$ should match the system's noise tolerance level. For noise-free data, $\varepsilon \to 0$ implies artifact norm $\to 0$ [S1].

## Operating characteristics

*   **Time Complexity:** Each iteration involves one forward projection ($A$), one neural network inference ($\Phi$), one sparse transform ($H$), and one adjoint transform ($H^*$). The complexity is $O(K \cdot (T_A + T_\Phi + T_H))$, where $K$ is the number of iterations.
*   **Memory Complexity:** Requires storage for $f$ ($N$), $p$ ($m$), and intermediate buffers. $O(N + m)$.
*   **Performance:**
    *   In CT cases (Ell-50 network), ACID showed a maximum output-to-input variation ratio of 0.229 against additive white Gaussian noise (11-30 HU std dev) [S1].
    *   In MRI cases (DAGAN network), the ratio was 3.023 against similar noise [S1].
    *   The Lipschitz constant of ACID monotonically decreases and converges to a constant scale with respect to iterations [S1].
*   **Strengths:** Stabilizes unstable deep networks; recovers null-space components better than sparsity-only methods; resilient to adversarial attacks; converges even with imperfect networks [S1].
*   **Limitations:** Requires tuning of $\lambda, \mu, \xi$; relies on a pre-trained network $\Phi$; convergence bounds depend on noise level $\varepsilon$ [S1].
*   **When to use:** Few-view CT, sparse-sampling MRI, low-dose spectral CT where data is insufficient for unique reconstruction without strong priors [S1].

## Background

ACID was introduced by Wu et al. in 2022 as part of a series on stabilizing deep tomographic reconstruction [S1]. It addresses the "cardinal crime" of kernel awareness, where deep networks trained on limited data produce unstable results for inverse problems [S1]. The method builds on Compressed Sensing theory and integrates it with deep learning priors to ensure that the reconstruction lies in the intersection of measured data, sparse solutions, and data-driven solutions [S1].
