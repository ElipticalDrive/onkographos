# Signal-to-Noise Ratio (SNR) for Tomography

Also called: rapport signal sur bruit

## Overview
Signal-to-Noise Ratio (SNR) for Tomography is a diagnostic metric that evaluates the robustness of a tomographic reconstruction method against acquisition noise [S2, unofficial]. It quantifies how well a reconstruction algorithm preserves signal integrity when the input sinogram is corrupted by noise, specifically isolating sensitivity to input perturbations rather than absolute fidelity to a ground truth [S2, unofficial]. Unlike metrics such as SSIM or MSE which compare a reconstruction to an ideal target, SNR for Tomography compares two reconstructions: one derived from a clean sinogram and one derived from a noisy sinogram [S2, unofficial]. This distinguishes it from sibling metrics like [Explicit Radon Transform Analysis](9108-explicit-radon-transform-analysis.md) or [Error Volume Analysis](15301-error-volume-analysis.md), which assess structural or geometric deviations [G].

## How it works
**Inputs and Outputs:**
*   **Input 1:** A clean sinogram $R_\theta(\rho)$ representing an ideal, noise-free acquisition [S2, unofficial].
*   **Input 2:** A noisy sinogram $R_\theta^{noise}(\rho)$ generated by applying an acquisition noise model to the clean sinogram [S2, unofficial].
*   **Input 3:** A reconstruction algorithm $\mathcal{R}$ (e.g., Back Projection, Fourier Reconstruction) [G].
*   **Output:** The SNR value in decibels (dB), quantifying the reconstruction's robustness [S2, unofficial].

**Data Structures:**
*   **Sinogram:** A 2D array indexed by projection angle $\theta$ and detector position $\rho$ [S2, unofficial].
*   **Reconstructed Image:** A 2D or 3D array of pixel/voxel intensities $I(p)$ [S2, unofficial].

**Noise Model:**
Acquisition noise is modeled as additive white Gaussian noise [S2, unofficial]. The noisy sinogram is generated by adding a random perturbation $\epsilon$ to each value $R_\theta(\rho)$ of the clean sinogram:
$$
R_\theta^{noise}(\rho) = R_\theta(\rho) + \epsilon
$$
where $\epsilon$ is sampled uniformly from the interval $[-(A/2)R_\theta(\rho), +(A/2)R_\theta(\rho)]$ [S2, unofficial]. The parameter $A$ denotes the noise amplitude percentage; a standard evaluation value is $A = 10\%$ [S2, unofficial].

**Step-by-Step Method:**
1.  **Generate Noisy Sinogram:** Apply the noise model to the clean sinogram $R_\theta(\rho)$ using the specified amplitude $A$ [S2, unofficial].
2.  **Reconstruct Clean Image:** Apply the reconstruction algorithm $\mathcal{R}$ to the clean sinogram to obtain the reference reconstruction $J$ [S2, unofficial].
3.  **Reconstruct Noisy Image:** Apply the same algorithm $\mathcal{R}$ to the noisy sinogram to obtain the noisy reconstruction $J_B$ [S2, unofficial].
4.  **Compute Mean Squared Error (MSE):** Calculate the MSE between the reference image $I_{in} = J$ and the noisy image $I_{out} = J_B$:
    $$
    mse(I_{in}, I_{out}) = \frac{\sum_{p=1}^{N} (I_{in}(p) - I_{out}(p))^2}{N}
    $$
    where $N$ is the total number of pixels/voxels [S2, unofficial].
5.  **Calculate SNR:** Compute the SNR in decibels using the ratio of the squared mean intensity of the reference image to the MSE:
    $$
    snr(I_{in}, I_{out}) = 10 \log_{10} \left( \frac{\bar{I}_{in}^2}{mse(I_{in}, I_{out})} \right)
    $$
    where $\bar{I}_{in}$ is the mean intensity of $I_{in}$ [S2, unofficial]. The source notation writes this as $\log(\bar{I}_{in}/mse)$ but explicitly states the result is expressed in decibels, implying the standard $10 \log_{10}$ power-ratio conversion [S2, unofficial].

**Pseudocode:**
```python
import numpy as np

def generate_noisy_sinogram(clean_sinogram, noise_level_percent=0.10):
    """
    Adds uniform noise to the sinogram based on [S2, unofficial].
    Noise is uniform between -(A/2)*R and +(A/2)*R.
    """
    A = noise_level_percent
    noise = np.random.uniform(-A/2, A/2, size=clean_sinogram.shape)
    noisy_sinogram = clean_sinogram + (noise * clean_sinogram)
    return noisy_sinogram

def compute_mse(image_in, image_out):
    """
    Computes Mean Squared Error between two images [S2, unofficial].
    """
    N = image_in.size
    mse = np.sum((image_in - image_out) ** 2) / N
    return mse

def compute_snr_tomography(reconstruction_func, clean_sinogram, noisy_sinogram):
    """
    Computes SNR for Tomography as defined in [S2, unofficial].
    """
    J = reconstruction_func(clean_sinogram)
    J_B = reconstruction_func(noisy_sinogram)
    
    mse_val = compute_mse(J, J_B)
    mean_I_in = np.mean(J)
    
    if mse_val == 0:
        return float('inf')
        
    snr_db = 10 * np.log10((mean_I_in ** 2) / mse_val)
    return snr_db
```

**Parameters:**
*   $A$: Noise amplitude percentage. Typical evaluation value: $10\%$ [S2, unofficial].

**Edge Cases:**
*   **Zero MSE:** If the reconstruction algorithm perfectly suppresses the added noise, $mse = 0$, resulting in infinite SNR [S2, unofficial].
*   **Negative Intensities:** The noise model scales with $R_\theta(\rho)$, assuming positive sinogram values; negative reconstruction values can distort the mean intensity $\bar{I}_{in}$ and the SNR ratio [S2, unofficial].

## Subtopics

### [Contrast-to-Noise Ratio (CNR)](15731-contrast-to-noise-ratio-cnr.md)
[Contrast-to-Noise Ratio (CNR)](15731-contrast-to-noise-ratio-cnr.md) evaluates the perceptual contrast of specific structures within the final rendered volume relative to background noise, rather than the reconstruction's robustness to acquisition noise [Parent]. It is chosen when validating denoising strategies or interpolation methods where visual distinguishability matters more than input stability [Parent].

## Operating characteristics
*   **Time Complexity:** The SNR calculation itself is $O(N)$ for $N$ voxels/pixels [S2, unofficial]. The dominant cost is the dual reconstruction of clean and noisy volumes, scaling with the chosen algorithm (e.g., $O(N \cdot M)$ for Back Projection with $M$ projections) [G].
*   **Memory Complexity:** Requires storing two sinograms and two reconstructed volumes, $O(N)$ [G].
*   **Measured Performance:** Under 10% additive Gaussian noise on sinograms, Back Projection yields an SNR of 6.33 dB, while Fourier Reconstruction yields -0.44 dB [S2, unofficial]. This demonstrates Back Projection's significantly higher robustness to acquisition noise compared to Fourier methods [S2, unofficial].
*   **Strengths:** Directly quantifies algorithmic stability against input perturbations, independent of reconstruction-induced artifacts [S2, unofficial]. Computationally lightweight post-reconstruction [S2, unofficial].
*   **Limitations:** Does not measure absolute accuracy or structural fidelity to ground truth [S2, unofficial]. Sensitive to the chosen noise model and amplitude [S2, unofficial].
*   **When to use:** Comparing reconstruction algorithms for stability under noisy acquisition conditions [S2, unofficial].
*   **When not to use:** When absolute geometric accuracy or structural similarity to a reference is required [G].

## Background
The metric originates from French-language research on tomographic reconstruction quality and precision assessment, specifically detailed in the thesis "Précision et qualité en reconstruction tomographique : algorithmes et applications" [S2, unofficial]. It was developed to compare the robustness of classical reconstruction techniques, such as Back Projection and Fourier Reconstruction, against simulated acquisition noise [S2, unofficial]. It is widely used in medical imaging and cryo-electron tomography diagnostics [S1][S2, unofficial].
