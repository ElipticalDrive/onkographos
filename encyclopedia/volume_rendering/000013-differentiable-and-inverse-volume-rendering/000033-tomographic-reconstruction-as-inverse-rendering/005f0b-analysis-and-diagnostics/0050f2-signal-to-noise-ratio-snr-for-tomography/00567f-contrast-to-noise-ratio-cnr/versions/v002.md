# Contrast-to-Noise Ratio (CNR)


## Overview
Contrast-to-Noise Ratio (CNR) is a quantitative metric used to evaluate the quality of volume-rendered images by measuring the distinguishability of a feature of interest from its surrounding background relative to the noise level [S1, S2]. It serves as a diagnostic tool for validating reconstruction algorithms, interpolation methods, and denoising strategies, particularly in scenarios where visual assessment is insufficient [S1, S2]. Unlike [Signal-to-Noise Ratio (SNR) for Tomography](14356-signal-to-noise-ratio-snr-for-tomography.md), which measures reconstruction robustness to acquisition noise by comparing clean and noisy sinograms [Parent], CNR focuses on the perceptual contrast of specific structures within the final rendered volume [S1, S2].

## How it works
The calculation of CNR requires defining Regions of Interest (ROIs) on the rendered volume and computing statistical moments of the intensity values within those regions [S1, S2]. Two distinct formulations are documented in the literature, corresponding to different application domains (tomosynthesis vs. cryo-electron tomography) [S1, S2].

### Inputs and Outputs
**Inputs:**
1. Rendered volume or image $I$ [S1, S2].
2. Definition of ROIs: feature ROI(s) containing the structure of interest, and background ROI(s) containing uniform background or homogeneous areas [S1, S2].
3. (Optional) Number of paired regions $N_{pr}$ if using the paired formulation [S2].

**Outputs:**
* A scalar value representing the Contrast-to-Noise Ratio [S1, S2].

### Data Structures
The method operates on scalar intensity values extracted from the volume at specific voxel coordinates defined by the ROIs [S1, S2].
* **Intensity Array:** A 1D array or list of pixel/voxel values $v_i$ for each ROI [G].
* **Statistics:** Mean ($\mu$ or $l$) and Standard Deviation ($\sigma$ or $r$) of the intensity values in each ROI [G].

### Formulas and Definitions
Two primary formulas exist [S1, S2].

**Formula 1: Standard Difference-of-Means (Tomosynthesis/General)**
Used in [S1] for evaluating interpolation and sampling in breast tomosynthesis.

$$
CNR = \frac{\mu_{feat} - \mu_{BG}}{\sigma_{BG}}
$$

Where:
* $\mu_{feat}$: Mean pixel value in the Region of Interest (ROI) over the feature (e.g., a 5.0 mm disk) [S1].
* $\mu_{BG}$: Mean pixel value in the background ROI [S1].
* $\sigma_{BG}$: Mean of the standard deviations in the background ROIs [S1]. Note: If multiple background ROIs are used, $\sigma_{BG}$ is the average of their individual standard deviations [S1].

**Formula 2: Paired Variance-Based (Cryo-ET/Denoising)**
Used in [S2] for evaluating denoising strategies in cryo-electron tomography.

$$
CNR = \frac{l_f - l_u}{\frac{1}{\sqrt{N_{pr}}} \sqrt{0.5(r^2_f + r^2_u)}}
$$

Where:
* $N_{pr}$: Number of paired regions selected to compute the CNR [S2].
* $l_f$: Mean intensity in the selected regions containing features [S2].
* $r^2_f$: Variance in the selected regions containing features [S2].
* $l_u$: Mean intensity in the selected uniform (background) regions [S2].
* $r^2_u$: Variance in the selected uniform regions [S2].

### Parameters
* **ROI Selection:** Critical for reproducibility. In [S1], ROIs are drawn over a specific phantom feature (5.0 mm disk) and surrounding background [S1]. In [S2], regions are manually labeled on different slices of the reconstructed tomogram [S2].
* **Number of Paired Regions ($N_{pr}$):** In [S2], this is a user-defined parameter for the number of samples taken to estimate the metric [S2].

### Pseudocode
```python
import math

def calculate_cnr_standard(feature_values, background_values_list):
    """
    Calculates CNR using the standard difference-of-means formula [S1].
    """
    if not feature_values:
        return 0.0
    mu_feat = sum(feature_values) / len(feature_values)

    bg_means = []
    bg_stds = []
    for bg_vals in background_values_list:
        if not bg_vals:
            continue
        m = sum(bg_vals) / len(bg_vals)
        bg_means.append(m)
        var = sum((x - m) ** 2 for x in bg_vals) / len(bg_vals)
        bg_stds.append(math.sqrt(var))

    if not bg_stds:
        return 0.0

    mu_BG = sum(bg_means) / len(bg_means)
    sigma_BG = sum(bg_stds) / len(bg_stds)

    if sigma_BG == 0:
        return 0.0

    return (mu_feat - mu_BG) / sigma_BG

def calculate_cnr_paired(feature_means, feature_variances, uniform_means, uniform_variances, n_pr):
    """
    Calculates CNR using the paired variance-based formula [S2].
    """
    if n_pr == 0:
        return 0.0

    l_f = sum(feature_means) / len(feature_means)
    r2_f = sum(feature_variances) / len(feature_variances)
    l_u = sum(uniform_means) / len(uniform_means)
    r2_u = sum(uniform_variances) / len(uniform_variances)

    numerator = l_f - l_u
    denominator = (1.0 / math.sqrt(n_pr)) * math.sqrt(0.5 * (r2_f + r2_u))

    if denominator == 0:
        return 0.0

    return numerator / denominator
```

### Edge Cases and Pitfalls
1. **Zero Noise/Uniform Background:** If the background is perfectly uniform ($\sigma_{BG} = 0$), the denominator in Formula 1 becomes zero [G].
2. **ROI Definition Bias:** The metric is highly sensitive to ROI placement [S1, S2]. In [S1], the background ROIs must be drawn in the surrounding area, not overlapping the feature [S1]. In [S2], manual labeling introduces subjectivity [S2].
3. **Anisotropic Resolution:** In tomosynthesis, the z-direction has coarser resolution than xy [S1]. CNR calculations should account for this, as features may spread in z, affecting $\mu_{feat}$ and $\sigma_{BG}$ [S1].
4. **Paired Region Count:** In Formula 2, $N_{pr}$ must be consistent across comparisons [S2]. A small $N_{pr}$ leads to high variance in the metric estimate [S2].

## Operating characteristics
* **Time Complexity:** $O(N)$, where $N$ is the total number of pixels/voxels in the defined ROIs [G]. The calculation involves simple statistical aggregations (mean, variance) [G].
* **Memory Complexity:** $O(N)$ to store the intensity values of the ROIs, or $O(1)$ if computed on-the-fly during rendering/analysis [G].
* **Strengths:**
    * Provides an objective, numerical basis for comparing rendering configurations (e.g., interpolation methods, sampling distances) [S1].
    * Effective for evaluating denoising performance by quantifying contrast preservation vs. noise reduction [S2].
* **Limitations:**
    * Does not account for human visual perception directly (unlike SSIM or VDP) [G].
    * In [S1], it is noted that CNR alone is insufficient; it is often used alongside Smoothness and FWHM to provide a complete picture of image quality [S1].
* **When to use:** When optimizing volume rendering parameters (sampling, interpolation) or evaluating denoising algorithms where quantitative comparison is needed [S1, S2].
* **When not to use:** When subjective visual quality is the primary concern, or when the background is not well-defined/uniform [G].

## Background
CNR is a standard metric in medical imaging and scientific visualization. In the context of volume rendering diagnostics, it has been applied to:
1. **Breast Tomosynthesis (DBT):** Used to validate and compare interpolation methods (Linear, Cubic, Nearest-Neighbor, Sinc with various windows) and sampling distances. Studies showed that optimized parameters (e.g., Hamming window with BF(z)=2, sampling 0.025 mm) significantly improved CNR compared to default settings [S1].
2. **Cryo-Electron Tomography (cryo-ET):** Used to evaluate adaptive differentiable grids and denoising strategies. It measures how well a denoiser increases contrast between features and background [S2].

The metric is often part of a suite of quantitative image analysis metrics, including Smoothness and FWHM, to objectively evaluate volume rendering quality [S1].
