# Explicit Radon Transform Analysis

Also called: Radon Matrix Analysis, Sparse-View Radon Transform Null Space Analysis

## Overview
Explicit Radon Transform Analysis constructs and analyzes the explicit forward projection matrix $A$ (or operator $R_V$) for a given scanning geometry to diagnose the invertibility and stability of tomographic reconstruction [S1, S2, unofficial]. Unlike black-box differentiable rendering which relies on gradient descent, this method explicitly exposes the linear algebra structure of the forward operator, allowing for the computation of singular values and the identification of the null space [S1, S2, unofficial]. It is distinct from [Optimal Projection Angle Selection via Mutual Information Minimization](11067-optimal-projection-angle-selection-via-mutual-information-mi.md) because it analyzes the operator's spectral properties directly rather than optimizing information metrics, and from [Signal-to-Noise Ratio (SNR) for Tomography](14356-signal-to-noise-ratio-snr-for-tomography.md) by focusing on structural ambiguity (null space) rather than noise propagation [S1, S2, unofficial].

## How it works
**Inputs:**
- Scanning geometry parameters: number of angles $n_{angles}$, maximum angle range $\theta_{max}$, number of samples per ray $n_{samples}$, and detector dimensions $v_{large}, h_{large}$ [S2, unofficial].
- Volume dimensions: $v_{small}, h_{small}$ (or 3D extent $w$) [S1, S2, unofficial].
- Optional: `sparse_svd` flag to determine if full or sparse SVD is computed [S2, unofficial].

**Outputs:**
- The explicit Radon transform matrix $A$ (size $M \times N$, where $M$ is total detector pixels and $N$ is total volume voxels) [S2, unofficial].
- Singular values $W$ of the matrix $A$ [S2, unofficial].
- Visualization of the sparsity pattern of $A$ [S2, unofficial].

**Data Structures:**
- Matrix $A$: A sparse matrix where $A_{ij}$ represents the contribution of voxel $j$ to detector pixel $i$. The layout corresponds to the discretized line integrals [S2, unofficial].
- Singular Values $W$: A vector of length $\min(M, N)$ representing the decay of the operator's energy [S2, unofficial].

**Steps:**
1.  **Geometry Setup:** Define the volume geometry (`vol_geom`) and projection geometry (`proj_geom`) based on input parameters $n_{angles}, \theta_{max}, n_{samples}, v_{large}, h_{large}$ [S2, unofficial].
2.  **Matrix Construction:** Call the explicit Radon transform function `explicit_radon` (or equivalent constructor) with the geometry parameters and `sparse_svd=False` to generate the matrix $A$ and its singular values $W$ [S2, unofficial].
    *   *Note:* In practice, this may involve creating a sinogram using a library like ASTRA Toolbox (`create_sinogram`) and extracting the underlying projector matrix [S2, unofficial].
3.  **Spectral Analysis:** Compute the Singular Value Decomposition (SVD) of $A$ to obtain $W$. Analyze the decay of $W$ to determine the effective rank and condition number of the system [S2, unofficial].
4.  **Null Space Identification:** Identify the null space $\mathcal{N}(R_V)$ defined as:
    $$
    \mathcal{N}(R_V) = \{ \delta V \mid R_V(\delta V) = 0 \}
    $$
    where $R_V$ is the sparse-view Radon operator [S1, unofficial]. Vectors in this null space represent volumetric perturbations invisible to the projections [S1, unofficial].
5.  **Visualization:** Use `imshow` to visualize the matrix $A$ to observe the sparsity pattern corresponding to the scanning geometry (e.g., sparse vs. limited angles) [S2, unofficial].

**Formulas:**
The sparse-view Radon transform is defined as the concatenation of Radon operators along $K$ projection directions $V = \{v_1, \dots, v_K\}$ [S1, unofficial]:
$$
R_V(V) = (R_{v_1}(V), \dots, R_{v_K}(V)) \in \mathbb{R}^{K \times h \times w}
$$
where $V$ is the attenuation field, $R_v$ is the line-integral operator along direction $v$, and $K$ is the number of views [S1, unofficial].

For dense views ($K \to \infty$), $R$ is injective. For sparse views (finite $K$, e.g., $K \in \{10, 20, 25\}$), $R_V$ is strongly underdetermined, and $\mathcal{N}(R_V)$ is non-trivial [S1, unofficial].

**Parameters:**
- `n_angles`: Number of projection angles. Typical values: 10, 20, 25, 45 [S1, S2, unofficial].
- `max_angle`: Maximum angular range. Typical values: $\pi$ (sparse, full rotation) or limited ranges (limited angle) [S2, unofficial].
- `n_samples`: Number of samples per ray [S2, unofficial].
- `v_small, h_small`: Volume dimensions [S2, unofficial].
- `v_large, h_large`: Detector dimensions [S2, unofficial].

**Edge Cases and Pitfalls:**
- **Memory:** Explicitly storing $A$ requires $O(M \times N)$ memory, which is prohibitive for high-resolution 3D volumes. Sparse matrix formats are required [S2, unofficial].
- **Ill-posedness:** In sparse-view or limited-angle scenarios, the singular value decay is slow, indicating high ill-posedness. Regularization is necessary for reconstruction [S1, S2, unofficial].
- **Numerical Precision:** Small singular values may be dominated by noise, requiring truncation in SVD [S2, unofficial].

**Pseudocode:**
```python
import numpy as np
import matplotlib.pyplot as plt
# Assuming astra-like interface for geometry and projection
# from astra import create_volume, create_projector, create_sino

def explicit_radon_analysis(n_angles, max_angle, n_samples, v_small, h_small, v_large, h_large, sparse_svd=False):
    """
    Constructs the explicit Radon matrix and analyzes its properties.
    """
    # 1. Setup Geometry
    # vol_geom defines the 3D volume grid
    vol_geom = {
        'voxel_size': (1.0, 1.0, 1.0),
        'volume_size': (v_small, h_small, 1), # Assuming 2D slice for simplicity or 3D
        'origin': (0, 0, 0)
    }
    
    # proj_geom defines the detector and ray configuration
    proj_geom = {
        'detector_size': (h_large, v_large),
        'num_pixels': (h_large, v_large),
        'num_angles': n_angles,
        'angle_range': max_angle,
        'ray_spacing': 1.0
    }
    
    # 2. Construct Projector Matrix A
    # This step creates the explicit linear operator mapping volume to sinogram
    # In practice, this might use astra.projector.create or similar
    projector_id = create_projector('cuda', proj_geom, vol_geom) # [G] Library-specific call to build matrix
    
    # Initialize a dummy volume to determine matrix dimensions if needed
    dummy_vol = np.zeros((v_small, h_small, 1))
    
    # Create the explicit matrix A
    # A is of shape (num_detector_pixels, num_voxels)
    A = projector_id.get_matrix(dummy_vol) 
    
    # 3. Compute Singular Values
    if sparse_svd:
        # Use sparse SVD for large matrices
        U, S, Vt = sparse.linalg.svds(A, k=min(100, np.min(A.shape)))
        W = S
    else:
        # Full SVD (only feasible for small matrices)
        U, S, Vt = np.linalg.svd(A, full_matrices=False)
        W = S
        
    # 4. Visualize Sparsity Pattern
    plt.figure()
    plt.imshow(A.toarray() if hasattr(A, 'toarray') else A, cmap='hot')
    plt.title(f"Radon Matrix Sparsity (n={n_angles}, max_angle={max_angle})")
    plt.xlabel("Voxel Index")
    plt.ylabel("Detector Pixel Index")
    plt.show()
    
    # 5. Analyze Null Space
    # The null space is spanned by the right singular vectors corresponding to zero (or near-zero) singular values
    null_space_threshold = 1e-6
    null_space_vectors = Vt[W < null_space_threshold, :]
    
    return A, W, null_space_vectors

```

## Subtopics

### Sparse-View Analysis
Analyzes the operator when $K$ is small (e.g., 10-25 views) but the angular range is full ($\pi$). Characterized by a non-trivial null space due to insufficient angular sampling [S1, unofficial].

### Limited-Angle Analysis
Analyzes the operator when the angular range is restricted (e.g., $\theta_{max} < \pi$). Characterized by directional artifacts and a null space that depends on the missing angular sector [S2, unofficial].

### Comparison
Sparse-view (fixed $\theta_{max}=\pi$, varying $K$) vs. Limited-angle (fixed $K$, varying $\theta_{max}$) exhibit different singular value decay patterns and null space structures [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Constructing the explicit matrix $A$ is $O(M \times N)$ where $M$ is detector pixels and $N$ is voxels. SVD is $O(\min(M^2 N, M N^2))$ for full SVD, making it infeasible for large volumes [S2, unofficial]. Sparse SVD reduces this but still requires significant memory [S2, unofficial].
- **Memory Complexity:** $O(M \times N)$ for the explicit matrix. This is the primary limitation, restricting the method to low-resolution volumes or 2D slices [S2, unofficial].
- **Strengths:** Provides exact diagnostic information about the forward operator's invertibility and null space. Useful for designing regularizers that penalize null-space components [S1, unofficial].
- **Limitations:** Not scalable to high-resolution 3D volumes due to memory constraints. Does not provide a reconstruction itself, only analysis [S1, S2, unofficial].

## Background
Originating from the mathematical analysis of the Radon transform in computed tomography, this method was applied to 3D Gaussian tomography to diagnose optimization drift and null-space ambiguities in sparse-view settings [S1, unofficial]. The explicit matrix construction and SVD analysis are implemented in inverse problems toolboxes like the ASTRA Toolbox [S2, unofficial]. It is used to understand why sparse-view reconstructions fail and how to constrain the solution space [S1, unofficial].
