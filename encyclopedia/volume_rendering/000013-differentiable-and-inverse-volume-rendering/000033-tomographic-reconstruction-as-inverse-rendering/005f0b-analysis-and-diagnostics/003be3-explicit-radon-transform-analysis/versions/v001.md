# Explicit Radon Transform Analysis

Also called: Radon Matrix Analysis, Sparse-View Radon Transform Null Space Analysis

## Overview
Explicit Radon Transform Analysis constructs and analyzes the explicit forward projection matrix $A$ for a given scanning geometry to diagnose the ill-posedness of tomographic reconstruction [S2, unofficial]. It identifies the singular values and the null space of the operator, revealing volumetric perturbations that are invisible to the measurements [S1, unofficial]. Unlike iterative solvers that approximate the inverse, this method provides a direct algebraic characterization of the information loss in sparse or limited-angle scenarios [S2, unofficial].

## How it works
**Inputs:**
- Scanning geometry parameters: number of angles $n_{angles}$, maximum angle $\theta_{max}$, number of samples per projection $n_{samples}$, volume dimensions $v_{small}, h_{small}$, and detector dimensions $v_{large}, h_{large}$ [S2, unofficial].
- Attenuation field $V$ (optional, for generating test data) [S2, unofficial].

**Outputs:**
- Explicit Radon matrix $A$ (size $K \times (v \cdot h)$, where $K$ is total number of ray integrals) [S1, unofficial][S2, unofficial].
- Singular values $W$ of $A$ [S2, unofficial].
- Visualization of the sparsity pattern of $A$ [S2, unofficial].

**Data Structures:**
- Matrix $A$: A sparse matrix where each row corresponds to a single ray integral in the sinogram, and each column corresponds to a voxel in the 3D volume. The entry $A_{ij}$ represents the contribution of voxel $j$ to ray $i$ [S1, unofficial][S2, unofficial].
- Singular values $W$: A vector containing the singular values obtained from the Singular Value Decomposition (SVD) of $A$ [S2, unofficial].

**Steps:**
1.  **Define Geometry:** Configure the volume geometry (`vol_geom`) and projection geometry (`proj_geom`) based on the specified parameters ($n_{angles}, \theta_{max}, n_{samples}, v_{large}, h_{large}$) [S2, unofficial].
2.  **Construct Matrix:** Call the explicit Radon transform function (e.g., `explicit_radon`) with the geometry parameters and `sparse_svd=False` to compute the matrix $A$ and its singular values $W$ [S2, unofficial].
3.  **Analyze Sparsity:** Visualize the matrix $A$ using a 2D image plot (`imshow`) to observe the sparsity pattern, which reflects the connectivity between voxels and rays for the specific scanning geometry [S2, unofficial].
4.  **Inspect Singular Values:** Plot or analyze the decay of singular values $W$. A slow decay or a plateau of near-zero values indicates a high-dimensional null space, characteristic of sparse-view or limited-angle tomography [S2, unofficial].

**Formulas:**
The sparse-view Radon transform is defined as the concatenation of line-integral operators along $K$ projection views [S1, unofficial]:

$$
R_V(V) = (R_{v_1}(V), \dots, R_{v_K}(V)) \in \mathbb{R}^{K \times h \times w}
$$

where $V$ is the attenuation field, $R_v$ is the Radon operator along direction $v$, and $K$ is the number of views [S1, unofficial].

The null space $\mathcal{N}(R_V)$ is defined as the set of volumetric perturbations $\delta V$ that produce zero projection data [S1, unofficial]:

$$
\mathcal{N}(R_V) = \{ \delta V \mid R_V(\delta V) = 0 \}
$$

**Parameters:**
- $n_{angles}$: Number of projection angles. Typical values for sparse views: 10, 20, 25 [S1, unofficial].
- $\theta_{max}$: Maximum angular span. Fixed at $\pi$ for sparse angles, varied for limited angles [S2, unofficial].
- $n_{samples}$: Number of detector samples per projection [S2, unofficial].
- $v_{small}, h_{small}$: Dimensions of the reconstructed volume [S2, unofficial].
- $v_{large}, h_{large}$: Dimensions of the detector plane (e.g., 128x128) [S2, unofficial].

**Edge Cases and Pitfalls:**
- **Memory Usage:** Constructing the explicit matrix $A$ for high-resolution volumes is memory-intensive. For large $v \cdot h$, the matrix may not fit in RAM [S2, unofficial].
- **Singular Value Decay:** In sparse-view scenarios, the singular values decay rapidly, and many are effectively zero, indicating severe ill-posedness [S1, unofficial][S2, unofficial].
- **Limited vs. Sparse Angles:** Limited angles (fixed $n$, varying $\theta_{max}$) produce different null space structures compared to sparse angles (fixed $\theta_{max}=\pi$, varying $n$) [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Constructing the explicit matrix $A$ is $O(K \cdot N)$, where $K$ is the number of rays and $N$ is the number of voxels. SVD computation is $O(\min(K^2 N, K N^2))$ [S2, unofficial].
- **Memory Complexity:** $O(K \cdot N)$ to store the matrix $A$ [S2, unofficial].
- **Strengths:** Provides exact algebraic insight into the reconstruction problem; identifies the null space explicitly; useful for diagnosing why reconstructions fail [S1, unofficial][S2, unofficial].
- **Limitations:** Not scalable to high-resolution 3D volumes due to memory constraints; does not provide a reconstruction itself, only an analysis [S2, unofficial].
- **When to use:** When analyzing the feasibility of reconstruction from a specific sparse or limited-angle dataset; when diagnosing artifacts caused by the null space [S1, unofficial][S2, unofficial].

## Background
The method originates from the analysis of sparse-view and limited-angle tomography, where the Radon transform is strongly underdetermined [S1, unofficial]. It leverages the explicit construction of the projection matrix to study the singular value structure and null space, which is critical for understanding the limitations of iterative reconstruction methods in these regimes [S1, unofficial][S2, unofficial].
