# EmissivityRenderer

Also called: Differentiable renderer for multi-line neural tomography

## Overview
EmissivityRenderer is a differentiable volume renderer for multi-line neural tomography that recovers 3-D coronal electron density ($n_e$) and temperature ($T_e$) from multiview, multiline spectral-intensity images [S1, unofficial]. It performs ray marching and Line-of-Sight (LOS) integration of emissivity coefficients [S1, unofficial]. It builds on [Differentiable CT Execution Model](3066-differentiable-ct-execution-model.md).

## How it works
**Inputs:** Ray origin, ray direction, axis-aligned bounding box ($x_{AABB}$), `DensityMLP` model, temperature function $T(\mathbf{x})$, and emissivity coefficient function $c_{coef}(n_e, T, r)$ [S1, unofficial].
**Outputs:** Integrated spectral intensity along the ray and gradients for backpropagation [S1, unofficial].
**Data Structures:**
- **Occupancy Grid:** Hash grid for spatial acceleration with resolution `occ_res` (default 128) [S1, unofficial].
- **Ray Samples:** Array of points along the ray within $x_{AABB}$ [S1, unofficial].
**Parameters:**
- `occ_warmup`: Warmup steps for occupancy grid training. Default: 256 [S1, unofficial].
- `occ_res`: Occupancy grid resolution. Default: 128 [S1, unofficial].
- `step_size`: Step size for ray marching. Default: $1/256$ [S1, unofficial].
- `occ_decay`: Decay rate for occupancy grid updates. Range: $(0, 1)$. Default: 0.01 [S1, unofficial].
- `occ_alpha`: Alpha parameter for occupancy grid updates. Range: $[1, 2]$. Default: 1.5 [S1, unofficial].
- `sigma_scale`: Scale factor for importance sampling proportional to $n_e^{\alpha}$. Initialized as a learnable parameter [S1, unofficial].
- `occ_eval_fn_ne_width`: Width parameter for occupancy evaluation function related to electron density. Default: 0.25 [S1, unofficial].
- `occ_eval_fn_ne_mid`: Midpoint parameter for occupancy evaluation function related to electron density. Default: 7.25 [S1, unofficial].
- `min_samples_per_ray`: Minimum number of samples per ray. Default: 64 [S1, unofficial].
- `fallback_when_samples`: Threshold for triggering fallback when sample count is low. Default: 8 [S1, unofficial].
**Algorithm Steps:**
1. Sample points $\mathbf{x}_i$ along the ray within the axis-aligned bounding box $x_{AABB}$ [S1, unofficial].
2. Compute temperature $T(\mathbf{x}_i)$ at each sample point [S1, unofficial].
3. Compute radial distance $r_{xyz}$ from $x_{AABB}$ for each $\mathbf{x}_i$ [S1, unofficial].
4. Compute electron density $n_e$ using the `DensityMLP` model at each $\mathbf{x}_i$ [S1, unofficial].
5. Compute the emissivity coefficient $c_{coef}(n_e, T, r)$ for each sample [S1, unofficial].
6. Perform Line-of-Sight integration of $c_{coef}$ along the ray to obtain the final intensity [S1, unofficial].
**Pseudocode:**
```python
def render_ray(ray_origin, ray_direction, aabb_min, aabb_max, density_mlp, temp_fn, params):
    # 1. Intersect ray with AABB using slab method
    # Guard against zero direction components [G]
    inv_dir = [1.0 / d if d != 0 else float('inf') for d in ray_direction]
    t_min = max((aabb_min[i] - ray_origin[i]) * inv_dir[i] for i in range(len(ray_direction)))
    t_max = min((aabb_max[i] - ray_origin[i]) * inv_dir[i] for i in range(len(ray_direction)))
    if t_min > t_max:
        return 0.0

    # Determine number of samples
    num_samples = max(params['min_samples_per_ray'], int((t_max - t_min) / params['step_size']))
    t_vals = [t_min + i * (t_max - t_min) / (num_samples - 1) for i in range(num_samples)]

    # 2. Compute Temperature T(x_llr)
    T = [temp_fn(ray_origin + ray_direction * t) for t in t_vals]

    # 3. Compute radial distance r_xyz from x_AABB
    center = (aabb_min + aabb_max) / 2.0
    r = [norm(ray_origin + ray_direction * t - center) for t in t_vals]

    # 4. Compute electron density ne from DensityMLP
    ne = [density_mlp(ray_origin + ray_direction * t) for t in t_vals]

    # 5. Compute emissivity coefficient ccoef(ne, T, r)
    # Physical model or learned mapping not fully specified in sources [G]
    ccoef = [physical_emissivity(n, t, rr) for n, t, rr in zip(ne, T, r)]

    # 6. Perform LOS integral of ccoef
    step_length = (t_max - t_min) / (num_samples - 1)
    intensity = sum(ccoef) * step_length
    return intensity
```
**Edge Cases and Pitfalls:**
- **Non-determinism:** GPU hash-grid training is not bitwise-deterministic due to atomic scatter in the hash backward and LOS accumulation. Fixed seeds yield statistically equivalent, not identical, runs [S1, unofficial].
- **Low Sample Count:** If the number of samples falls below `fallback_when_samples` (default 8), a fallback mechanism is triggered [S1, unofficial].

## Subtopics

### [Differential Infrared Thermography (DIT)](16234-differential-infrared-thermography-dit.md)
A technique to estimate transmittance ($e^{-\delta_{max}}$) of a transmissive target from the Radiative Transfer Equation (RTE) to avoid direct inversion of the ill-posed integral source term. It simplifies the 3-D spray structure as a thin slab layer to measure the local attenuation coefficient by comparing measurements with two different radiating backgrounds, assuming the target's temperature/radiance remains constant between measurements. It sets itself apart from full volumetric tomography by providing an effective apparent temperature and total optical depth (TOD) without resolving the internal line-of-sight distribution, serving as a preprocessing step to recover the local extinction coefficient for subsequent RTE solving.

## Background
EmissivityRenderer is part of the CoroNeRF project, which focuses on neural tomography of the solar corona [S1, unofficial]. It builds on [Differentiable CT Execution Model](3066-differentiable-ct-execution-model.md) to provide a differentiable rendering pipeline for multi-line spectral data [S1, unofficial]. The method leverages physical models of coronal emission (e.g., CHIANTI) to compute emissivity coefficients, distinguishing it from purely data-driven approaches [S1, unofficial].
