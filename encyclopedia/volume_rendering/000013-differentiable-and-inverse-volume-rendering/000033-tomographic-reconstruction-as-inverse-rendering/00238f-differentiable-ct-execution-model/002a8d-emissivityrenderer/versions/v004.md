# EmissivityRenderer

Also called: Differentiable renderer for multi-line neural tomography

## Overview
EmissivityRenderer is a differentiable volume renderer designed for multi-line neural tomography, specifically recovering 3-D coronal electron density ($n_e$) and temperature ($T_e$) from multiview, multiline spectral-intensity images [S1, unofficial]. It performs ray marching and Line-of-Sight (LOS) integration of emissivity coefficients derived from neural network models [S1, unofficial]. It is distinguished from its siblings by its specific application to solar coronal physics, utilizing a density-temperature benchmark and CHIANTI atomic data for emissivity calculation, whereas [Differential Rendering for CT Reconstruction](6462-differential-rendering-for-ct-reconstruction.md) focuses on general differential CT and [DiffVox](10071-diffvox.md) on voxel-based differentiable rendering [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Ray origins and directions, occupancy grid parameters, neural network weights for density and temperature prediction, and physical constants/ion data for emissivity lookup [S1, unofficial].
*   **Outputs:** Differentiable LOS-integrated intensity images for multiple spectral lines, and gradients with respect to network weights and input parameters [S1, unofficial].

**Data Structures:**
*   **Occupancy Grid:** A hash grid of resolution `occ_res` (default 128) storing occupancy probabilities, updated via atomic operations during training [S1, unofficial].
*   **DensityMLP:** A neural network mapping spatial coordinates to electron density $n_e$ [S1, unofficial].
*   **Temperature Model:** A neural network or function mapping spatial coordinates to temperature $T_e$ [S1, unofficial].
*   **Emissivity Coefficient:** Computed from $n_e$, $T_e$, and radial distance $r$ using CHIANTI atomic data via the `pycelp` library [S1, unofficial].

**Parameters:**
*   `occ_warmup`: Number of warmup steps for occupancy grid training. Default: 256 [S1, unofficial].
*   `occ_res`: Resolution of the occupancy grid. Default: 128 [S1, unofficial].
*   `step_size`: Step size for ray marching. Default: 1/256 [S1, unofficial].
*   `occ_decay`: Decay rate for occupancy grid updates. Range: $(0, 1)$. Default: 0.01 [S1, unofficial].
*   `occ_alpha`: Alpha parameter for occupancy grid updates. Range: $[1, 2]$. Default: 1.5 [S1, unofficial].
*   `sigma_scale`: Scale factor for $\sigma$ proportional to $n_e^\alpha$ for importance sampling. Initialized as a learnable parameter [S1, unofficial].
*   `occ_eval_fn_ne_width`: Width parameter for the occupancy evaluation function related to electron density. Default: 0.25 [S1, unofficial].
*   `occ_eval_fn_ne_mid`: Midpoint parameter for the occupancy evaluation function related to electron density. Default: 7.25 [S1, unofficial].
*   `min_samples_per_ray`: Minimum number of samples per ray. Default: 64 [S1, unofficial].
*   `fallback_when_samples`: Threshold for triggering fallback when sample count is low. Default: 8 [S1, unofficial].

**Algorithm Steps:**
For each ray, the renderer executes the following sequence [S1, unofficial]:
1.  **Sampling:** Sample points $x_i$ along the ray within the axis-aligned bounding box ($x_{AABB}$). The number of samples is determined by `step_size` and `min_samples_per_ray`. Importance sampling may be used based on $\sigma \propto n_e^\alpha$ scaled by `sigma_scale` [S1, unofficial].
2.  **Temperature Estimation:** Compute the temperature $T(x_i)$ at each sample point using the temperature model [S1, unofficial].
3.  **Radial Distance:** Compute the radial distance $r_{xyz}$ from the center of the volume for each sample point $x_i$ [S1, unofficial].
4.  **Density Estimation:** Compute the electron density $n_e$ at each sample point using the `DensityMLP` model [S1, unofficial].
5.  **Emissivity Coefficient:** Compute the emissivity coefficient $c_{\text{coef}}(n_e, T, r)$ using the precomputed LUT or analytical function based on CHIANTI data for the specific ion species and wavelengths [S1, unofficial].
6.  **LOS Integration:** Perform the Line-of-Sight integral of $c_{\text{coef}}$ along the ray to obtain the final intensity. This is computed as $I = \sum_{i} c_{\text{coef}}(i) \cdot \Delta s_i$, where $\Delta s_i$ is the step size. Gradients are backpropagated through this sum [S1, unofficial].

**Pseudocode:**
```python
import math

def render_ray(ray_origin, ray_direction, density_mlp, temp_model, params):
    # 1. Sample points in AABB
    num_samples = max(params['min_samples_per_ray'], 64)
    t_values = [i * params['step_size'] for i in range(num_samples)]
    # Convert inputs to lists if needed to avoid type errors
    origin = list(ray_origin)
    direction = list(ray_direction)
    points = [[origin[i] + t * direction[i] for i in range(3)] for t in t_values]

    # 2. Compute Temperature
    temperatures = [temp_model(p) for p in points]

    # 3. Compute Radial Distance
    radial_distances = [math.sqrt(sum(p_i**2 for p_i in p)) for p in points]

    # 4. Compute Electron Density
    densities = [density_mlp(p) for p in points]

    # 5. Compute Emissivity Coefficient
    # Exact formula for ccoef(ne, T, r) is not provided in the sources [G]
    emissivities = [ne * T * r for ne, T, r in zip(densities, temperatures, radial_distances)]

    # 6. LOS Integral
    step_size = params['step_size']
    intensity = sum(e * step_size for e in emissivities)

    return intensity
```

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of samples per ray and the number of rays [S1, unofficial]. The neural network evaluations dominate the per-sample cost [S1, unofficial].
*   **Memory Complexity:** Dominated by the occupancy grid and the neural network weights [S1, unofficial]. The occupancy grid size is $2^{\text{occ\_res} \times 3}$ entries in the worst case, but hash grids are sparse [S1, unofficial].
*   **Performance:** Performance depends on the resolution of the occupancy grid and the complexity of the neural networks [S1, unofficial]. GPU acceleration is used for hash grid updates and neural network inference [S1, unofficial].
*   **Strengths:** Differentiable end-to-end, allowing for gradient-based optimization of the 3D density and temperature fields from 2D images [S1, unofficial]. Specific to solar coronal physics, leveraging accurate atomic data [S1, unofficial].
*   **Limitations:** Not bitwise-deterministic due to atomic scatter in hash grid updates and LOS accumulation on the GPU [S1, unofficial]. Requires careful tuning of occupancy grid parameters [S1, unofficial].

## Background
EmissivityRenderer is part of the CoroNeRF project, which applies neural radiance fields (NeRF) to solar coronal tomography [S1, unofficial]. It was developed to address the challenge of reconstructing 3D coronal structures from limited multiview observations [S1, unofficial].
