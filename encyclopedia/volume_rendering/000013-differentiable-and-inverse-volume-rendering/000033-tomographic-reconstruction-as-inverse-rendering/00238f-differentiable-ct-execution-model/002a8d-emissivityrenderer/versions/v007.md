# EmissivityRenderer

Also called: Differentiable renderer for multi-line neural tomography

## Overview
EmissivityRenderer is a differentiable volume renderer designed for multi-line neural tomography, specifically recovering 3-D coronal electron density ($n_e$) and temperature ($T_e$) from multiview, multiline spectral-intensity images [S1, unofficial]. It performs ray marching and Line-of-Sight (LOS) integration of emissivity coefficients derived from neural network models [S1, unofficial]. It sets itself apart from siblings like [DiffVox](10071-diffvox.md) by explicitly modeling the physical emissivity coefficient $c_{coef}$ as a function of density, temperature, and radial distance, rather than relying on generic volumetric opacity or density fields alone.

## How it works
**Inputs:**
- Ray origin and direction.
- Axis-Aligned Bounding Box (AABB) of the volume.
- Neural network models: `DensityMLP` (outputs $n_e$), and implicit functions for temperature $T(\mathbf{x})$ and radial distance $r(\mathbf{x})$.
- Lookup Table (LUT) or physical model for emissivity coefficient $c_{coef}(n_e, T, r)$.

**Outputs:**
- Integrated spectral intensity along the ray.
- Gradients with respect to $n_e$, $T$, and network parameters.

**Data Structures:**
- **Occupancy Grid:** A hash grid storing occupancy status for spatial acceleration.
  - Fields: `grid_size` (resolution), `hash_map` (sparse storage).
  - Resolution `occ_res` defaults to 128 [S1, unofficial].
- **Ray Samples:** Array of points along the ray within the AABB.
  - Step size `step_size` defaults to $1/256$ of the bounding box diagonal or extent [S1, unofficial].

**Parameters:**
- `occ_warmup`: Number of warmup steps for occupancy grid training. Default: 256 [S1, unofficial].
- `occ_res`: Resolution of the occupancy grid. Default: 128 [S1, unofficial].
- `step_size`: Step size for ray marching. Default: $1/256$ [S1, unofficial].
- `occ_decay`: Decay rate for occupancy grid updates. Range: $(0, 1)$. Default: 0.01 [S1, unofficial].
- `occ_alpha`: Alpha parameter for occupancy grid updates. Range: $[1, 2]$. Default: 1.5 [S1, unofficial].
- `sigma_scale`: Scale factor for importance sampling, proportional to $n_e^{\alpha}$. Initialized as a learnable parameter [S1, unofficial].
- `occ_eval_fn_ne_width`: Width parameter for occupancy evaluation function related to electron density. Default: 0.25 [S1, unofficial].
- `occ_eval_fn_ne_mid`: Midpoint parameter for occupancy evaluation function related to electron density. Default: 7.25 [S1, unofficial].
- `min_samples_per_ray`: Minimum number of samples per ray. Default: 64 [S1, unofficial].
- `fallback_when_samples`: Threshold for triggering fallback when sample count is low. Default: 8 [S1, unofficial].

**Algorithm Steps:**
1. **Sampling:** Sample points $\mathbf{x}_i$ along the ray within the AABB $x_{AABB}$.
2. **Temperature:** Compute temperature $T(\mathbf{x}_i)$ at each sample point.
3. **Radial Distance:** Compute radial distance $r_{xyz}$ from the center (or reference point) for each $\mathbf{x}_i$.
4. **Density:** Compute electron density $n_e$ using the `DensityMLP` model at each $\mathbf{x}_i$.
5. **Emissivity Coefficient:** Compute the emissivity coefficient $c_{coef}(n_e, T, r)$ for each sample. This typically involves physical models (e.g., CHIANTI) or learned mappings based on $n_e$, $T$, and $r$ [S1, unofficial].
6. **LOS Integration:** Perform Line-of-Sight integration of $c_{coef}$ along the ray to obtain the final intensity.

**Pseudocode:**
```python
def render_ray(ray_origin, ray_direction, aabb, density_mlp, temp_fn, occ_grid, params):
    # 1. Sample points in the AABB
    # Calculate intersection of ray with AABB
    t_min, t_max = intersect_aabb(ray_origin, ray_direction, aabb)
    if t_min > t_max:
        return 0.0
    
    # Determine number of samples based on step_size or min_samples
    num_samples = max(params['min_samples_per_ray'], int((t_max - t_min) / params['step_size']))
    
    # Generate sample points
    t_values = torch.linspace(t_min, t_max, num_samples)
    points = ray_origin + ray_direction.unsqueeze(1) * t_values.unsqueeze(0)
    
    # 2. Compute Temperature T(x_llr)
    T = temp_fn(points)
    
    # 3. Compute radial distance r_xyz from x_AABB (center)
    # Assuming center is known or derived from AABB
    center = (aabb.min + aabb.max) / 2.0
    r = torch.norm(points - center, dim=-1)
    
    # 4. Compute electron density ne from DensityMLP
    # DensityMLP takes coordinates as input
    ne = density_mlp(points)
    
    # 5. Compute emissivity coefficient ccoef(ne, T, r)
    # This function encapsulates the physical model or learned mapping
    ccoef = compute_emissivity_coefficient(ne, T, r)
    
    # 6. Perform LOS integral of ccoef
    # Simple Riemann sum or trapezoidal rule
    # Weight by step size
    step_length = (t_max - t_min) / (num_samples - 1)
    intensity = torch.sum(ccoef * step_length)
    
    return intensity
```

**Edge Cases and Pitfalls:**
- **Non-determinism:** GPU hash-grid training is not bitwise-deterministic due to atomic scatter in the hash backward and LOS accumulation. Fixed seeds yield statistically equivalent, not identical, runs [S1, unofficial].
- **Low Sample Count:** If the number of samples falls below `fallback_when_samples` (default 8), a fallback mechanism is triggered [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of samples per ray and the number of rays. The use of an occupancy grid accelerates empty space skipping.
- **Memory Complexity:** Dominated by the occupancy grid and the neural network models. The hash grid size depends on `occ_res` and the hash map capacity.
- **Performance:** Performance is highly dependent on the complexity of the `DensityMLP` and the physical model used for $c_{coef}$. Importance sampling based on $n_e^{\alpha}$ can reduce variance but adds computational overhead.
- **Strengths:** Physically grounded emissivity model allows for accurate recovery of coronal parameters. Differentiable nature enables end-to-end training.
- **Limitations:** Non-deterministic training results. Sensitivity to initial conditions and hyperparameters (e.g., `occ_alpha`, `sigma_scale`).

## Background
EmissivityRenderer is part of the CoroNeRF project, which focuses on neural tomography of the solar corona. It builds on the Differentiable CT Execution Model [3066-differentiable-ct-execution-model.md] to provide a differentiable rendering pipeline for multi-line spectral data. The method leverages physical models of coronal emission (e.g., CHIANTI) to compute emissivity coefficients, distinguishing it from purely data-driven approaches.
