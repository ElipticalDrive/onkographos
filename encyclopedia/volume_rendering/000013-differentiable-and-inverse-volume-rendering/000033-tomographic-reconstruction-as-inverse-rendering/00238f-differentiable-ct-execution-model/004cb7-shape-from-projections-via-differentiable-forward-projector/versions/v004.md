# Shape from Projections via Differentiable Forward Projector

Also called: CTDR, Differentiable Forward Projector for CT

## Overview
This method estimates 3D shapes represented by a triangular mesh directly from tomographic projection data [S1, unofficial]. It treats tomographic reconstruction as a rendering process, extending a differentiable rasterizer to optimize the 3D geometry [S1, unofficial].

## How it works
**Inputs:**
- A 3D triangular mesh (vertices and faces) [S1, unofficial].
- Tomographic projection data (2D sinograms or projection images) [S1, unofficial].
- Projection geometry parameters (source position, detector position, orientation) [G].

**Outputs:**
- Optimized 3D triangular mesh that minimizes the difference between simulated projections and input data [S1, unofficial].

**Data Structures:**
- Mesh: List of vertices (3D coordinates) and faces (indices into vertices) [G].
- Projections: 2D arrays representing intensity values [G].
- Geometry: Parameters defining the X-ray source and detector for each view [G].

**Steps:**
1. **Initialization:** Start with an initial guess of the 3D mesh [G].
2. **Forward Projection:** For each view, simulate the projection of the current mesh through the X-ray geometry [S1, unofficial]. This involves calculating the path length of rays through the mesh triangles [G].
3. **Loss Calculation:** Compare the simulated projections with the input tomographic data [S1, unofficial]. Compute a loss function (e.g., Mean Squared Error) [G].
4. **Backpropagation:** Compute gradients of the loss with respect to the mesh vertices using the differentiable forward projector [S1, unofficial].
5. **Optimization:** Update the mesh vertices using an optimizer (e.g., Adam) to minimize the loss [G].
6. **Iteration:** Repeat steps 2–5 until convergence or a maximum number of iterations is reached [G].

**Formulas:**
- Loss: $L = \sum_{i} (P_{\text{sim}}^{(i)} - P_{\text{true}}^{(i)})^2$ where $P_{\text{sim}}$ is the simulated projection and $P_{\text{true}}$ is the true projection [G].
- Gradient: $\frac{\partial L}{\partial V}$ where $V$ are the mesh vertices [G].

**Parameters:**
- Learning rate: Not given in the sources. [G]
- Number of iterations: Not given in the sources. [G]
- Optimizer: Adam [G].

**Pseudocode:**
```python
import torch
import torch.nn as nn

def ray_triangle_intersect(origin, direction, v0, v1, v2):
    # Differentiable ray-triangle intersection (Möller–Trumbore variant) [G]
    edge1 = v1 - v0
    edge2 = v2 - v0
    h = torch.cross(direction, edge2)
    a = torch.sum(edge1 * h)
    if torch.abs(a) < 1e-8: return -1.0
    f = 1.0 / a
    s = origin - v0
    u = f * torch.sum(s * h)
    if u < 0.0 or u > 1.0: return -1.0
    q = torch.cross(s, edge1)
    v = f * torch.sum(direction * q)
    if v < 0.0 or u + v > 1.0: return -1.0
    t = f * torch.sum(edge2 * q)
    if t > 1e-8: return t
    return -1.0

class DifferentiableForwardProjector(nn.Module):
    def __init__(self, geometry):
        super().__init__()
        self.geometry = geometry

    def forward(self, vertices, faces):
        projections = torch.zeros(self.geometry.detector_shape, device=vertices.device)
        for i in range(self.geometry.num_rays):
            origin = self.geometry.ray_origins[i]
            direction = self.geometry.ray_directions[i]
            max_t = float('inf')  # Fixed: must initialize to infinity to find closest intersection
            for face in faces:
                v0, v1, v2 = vertices[face[0]], vertices[face[1]], vertices[face[2]]
                t = ray_triangle_intersect(origin, direction, v0, v1, v2)
                if t > 0.0 and t < max_t:
                    max_t = t
            if max_t < float('inf'):
                proj_idx = self.geometry.ray_to_pixel[i]
                projections[proj_idx] += max_t
        return projections

def optimize_mesh(projections_true, geometry, initial_vertices, initial_faces, num_iterations=1000):
    vertices = nn.Parameter(initial_vertices.float(), requires_grad=True)
    faces = initial_faces
    projector = DifferentiableForwardProjector(geometry)
    optimizer = torch.optim.Adam([vertices], lr=0.01)
    for i in range(num_iterations):
        optimizer.zero_grad()
        projections_sim = projector(vertices, faces)
        loss = torch.mean((projections_sim - projections_true) ** 2)
        loss.backward()
        optimizer.step()
    return vertices.detach(), faces
```

## Subtopics

### [CTDR Optimization Loop with Regularization](13348-ctdr-optimization-loop-with-regularization.md)
An iterative optimization process that minimizes a composite loss function—combining data fidelity, edge, Laplacian, and flatness regularization terms—to reconstruct a 3D triangular mesh directly from 2D tomographic projection data. It distinguishes itself from standard differentiable rendering by explicitly enforcing topological constraints via collision rollback and utilizing robust loss functions (Student-t) to handle missing data or outliers in projection masks.
