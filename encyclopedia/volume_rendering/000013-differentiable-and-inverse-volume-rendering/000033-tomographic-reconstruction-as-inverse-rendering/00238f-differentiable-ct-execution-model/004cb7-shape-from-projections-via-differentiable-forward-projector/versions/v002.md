# Shape from Projections via Differentiable Forward Projector

Also called: CTDR, Differentiable Forward Projector for CT

## Overview
This method estimates 3D shapes represented by a triangular mesh directly from tomographic projection data [S1, unofficial]. It treats tomographic reconstruction as a rendering process, extending a differentiable rasterizer to optimize the 3D geometry [S1, unofficial]. Unlike volumetric approaches, it operates directly on surface meshes, distinguishing it from volumetric differentiable renderers like [DiffVox](10071-diffvox.md) or emissivity-based methods like [EmissivityRenderer](4811-emissivityrenderer.md).

## How it works
**Inputs:**
- A 3D triangular mesh (vertices and faces).
- Tomographic projection data (2D sinograms or projection images).
- Projection geometry parameters (source position, detector position, orientation).

**Outputs:**
- Optimized 3D triangular mesh that minimizes the difference between simulated projections and input data.

**Data Structures:**
- Mesh: List of vertices (3D coordinates) and faces (indices into vertices).
- Projections: 2D arrays representing intensity values.
- Geometry: Parameters defining the X-ray source and detector for each view.

**Steps:**
1. **Initialization:** Start with an initial guess of the 3D mesh.
2. **Forward Projection:** For each view, simulate the projection of the current mesh through the X-ray geometry. This involves calculating the path length of rays through the mesh triangles.
3. **Loss Calculation:** Compare the simulated projections with the input tomographic data. Compute a loss function (e.g., Mean Squared Error).
4. **Backpropagation:** Compute gradients of the loss with respect to the mesh vertices using the differentiable forward projector.
5. **Optimization:** Update the mesh vertices using an optimizer (e.g., Adam) to minimize the loss.
6. **Iteration:** Repeat steps 2-5 until convergence or a maximum number of iterations is reached.

**Formulas:**
- Loss: $L = \sum_{i} (P_{sim}^{(i)} - P_{true}^{(i)})^2$ where $P_{sim}$ is the simulated projection and $P_{true}$ is the true projection.
- Gradient: $\frac{\partial L}{\partial V}$ where $V$ are the mesh vertices.

**Parameters:**
- Learning rate: Not specified in sources.
- Number of iterations: Not specified in sources.
- Optimizer: Adam (implied by PyTorch usage).

**Edge Cases and Pitfalls:**
- Degenerate triangles: Ensure mesh validity.
- Missing data: Handle incomplete projections.
- Precision: Floating-point precision in gradient calculations.

## Subtopics

### [CTDR Optimization Loop with Regularization](13348-ctdr-optimization-loop-with-regularization.md)
An iterative optimization process that minimizes a composite loss function—combining data fidelity, edge, Laplacian, and flatness regularization terms—to reconstruct a 3D triangular mesh directly from 2D tomographic projection data. It distinguishes itself from standard differentiable rendering by explicitly enforcing topological constraints via collision rollback and utilizing robust loss functions (Student-t) to handle missing data or outliers in projection masks.

## Operating characteristics
- **Time Complexity:** Depends on the number of iterations, mesh complexity, and projection geometry. Each iteration involves forward projection and backpropagation.
- **Memory Complexity:** Proportional to the size of the mesh and the projection data.
- **Performance:** Not given in the sources.
- **Strengths:** Direct mesh optimization, differentiable geometry.
- **Limitations:** Requires differentiable projection implementation, sensitive to initialization.
- **When to use:** When a mesh representation is desired and tomographic data is available.
- **When not to use:** When volumetric representation is preferred or data is insufficient.

## Background
The method was introduced in the paper "Shape from Projections via Differentiable Forward Projector for Computed Tomography" published in Ultramicroscopy [S1, unofficial]. It builds on the idea of viewing tomographic reconstruction as a rendering process. The code is available on GitHub [S1, unofficial].
