# Volume Reconstruction via Linear System Inversion

Also called: Property Reconstruction, Tomographic Volume Reconstruction

## Overview
Volume Reconstruction via Linear System Inversion inverts the volume rendering process to optimize volume properties (emission, albedo, extinction) such that the rendered output matches user-defined target images [S1]. It solves the inverse problem by linearizing the volume rendering equation, reducing the optimization to solving a linear system $Wa = o$ [S1]. Unlike iterative gradient-based methods that rely on differentiable rendering pipelines, this method explicitly constructs the Jacobian-like matrix $W$ derived from the rendering equation and solves for the basis coefficients $a$ directly [S1].

## How it works
**Inputs:**
- Target constraint pixels $o$, a vector of size $N$ containing desired radiance values $L_{ki}$ for $N$ pixels [S1].
- Camera views defining rays with origins $x_k$ and directions $\omega_k$ [S1].
- Volume representation $V$ defined by basis functions $\upsilon_i(x)$ (e.g., box or triangle functions) [S1].
- Fixed properties not being optimized (e.g., outgoing radiance $L_o$, medium radiance $L_m$ if applicable) [S1].

**Outputs:**
- Coefficient vector $a$ representing the optimized volume properties (emission, albedo, or extinction) [S1].

**Data Structures:**
- **Matrix $W$**: Size $N \times M$, where $N$ is the number of constraint pixels and $M$ is the number of basis functions/unknowns. Entries $w_{ik}$ are derived from the volume rendering equation for ray $k$ and basis function $i$ [S1].
- **Vector $o$**: Size $N \times 1$, containing target pixel values [S1].
- **Vector $a$**: Size $M \times 1$, containing the solution coefficients [S1].

**Steps:**
1. **Define Basis Functions**: Choose basis functions $\upsilon_i(x)$ with local support (e.g., box functions for nearest-neighbor sampling or triangle functions for linear interpolation) to represent the volume property [S1].
2. **Linearize the Rendering Equation**: Depending on the property being reconstructed, linearize the volume rendering equation (Eq. 1 in [S1]) to form the linear system $o = Wa$ [S1].
   - For **Emission/Albedo**: The equation is linear in the coefficients if other properties are fixed [S1].
   - For **Extinction**: Requires assuming constant outgoing radiance $L_m$ and applying logarithms to linearize the exponential attenuation terms [S1].
3. **Construct Matrix $W$**: For each constraint pixel $k$ (ray $k$) and each basis function $i$, compute the entry $w_{ik}$ by integrating the basis function along the ray path through the volume, weighted by the appropriate transmittance and emission terms [S1].
   - For emission $L_{emit}$, the coefficient involves the integral of the basis function weighted by the transmittance from the ray origin to the voxel [S1].
   - For extinction $\sigma_t$, the coefficient involves the integral of the basis function weighted by the transmittance and logarithmic terms if linearized via log-space [S1].
4. **Solve the Linear System**: Since user input may be inconsistent (no exact solution exists), solve for $a$ in the least squares sense [S1]:
   $$ W^T o = W^T W a $$
   This minimizes the quadratic function $||Wa - o||_2$ [S1].
5. **Reconstruct Volume**: Use the computed coefficients $a$ and the basis functions $\upsilon_i(x)$ to reconstruct the volume property field [S1].

**Formulas:**
- **General Linear System**:
  $$ o = Wa $$
  where $o$ is the vector of constraint pixel values and $W$ is the matrix derived from the volume rendering equation [S1].
- **Least Squares Solution**:
  $$ W^T o = W^T W a $$
  minimizing $||Wa - o||_2$ [S1].
- **Extinction Reconstruction (Linearized)**:
  Assuming constant $L_m$, the rendering equation is linearized by taking the logarithm of the transmittance terms. The first summand (outgoing radiance) becomes:
  $$ L_o(x_k^s, \omega_k) \prod_i e^{-\sigma_{ti} \int_c \upsilon_i(x_t) dt} $$
  The second summand (medium emission) becomes:
  $$ L_m \left(1 - e^{-\int_0^s \sigma_t(x_t) dt}\right) $$
  Combining and applying logarithms allows the formation of linear equations for the extinction coefficients $\sigma_{ti}$ [S1].

**Parameters:**
- **Basis Functions**: Box functions (nearest-neighbor) for speed; triangle functions for linearly interpolated solutions [S1].
- **Regularization**: Not explicitly detailed in the core linear system formulation, but inconsistent input is handled via least squares [S1].

**Edge Cases and Pitfalls:**
- **Inconsistent Input**: User-defined targets may not have a valid solution. The least squares approach handles this by minimizing error rather than enforcing exact equality [S1].
- **Extinction Reconstruction Restriction**: Extinction can only be reconstructed if the outgoing radiance $L_m$ is constant ($L_m(x, \omega) = const$) [S1]. This is usually acceptable as extinction defines shape and is derived first [S1].
- **Non-linearity**: Extinction cannot be jointly optimized with emission or albedo in the same linear system because it involves a complex non-linear problem, even after log-linearization [S1]. It must be solved first [S1].

## Subtopics

### [Albedo Reconstruction](14422-albedo-reconstruction.md)
Recovers the scattering albedo ($\rho$) of a volume by solving a linear system under the single-scattering assumption. It is distinguished from Emission Reconstruction by solving for reflectivity rather than self-emission, though both use the same linear framework [14422-albedo-reconstruction.md].

### [Emission Reconstruction](14424-emission-reconstruction.md)
Recovers the self-emission field of a volume to match target images. It is distinguished from Albedo Reconstruction by solving for emission coefficients rather than albedo, using the same linear system inversion approach [14424-emission-reconstruction.md].

### Extinction Reconstruction
Reconstructs the extinction coefficient ($\sigma_t$) by linearizing the volume rendering equation under the assumption of constant outgoing radiance $L_m$. It is distinguished from Albedo and Emission Reconstruction by requiring log-linearization and being solved first due to its role in defining volume shape and its incompatibility with joint optimization of other properties [S1].

## Operating characteristics
- **Time Complexity**: Dominated by the construction of matrix $W$ ($O(N \cdot M)$ for integration) and solving the linear system ($O(M^3)$ for direct inversion or $O(M^2)$ for iterative solvers, where $M$ is the number of basis functions) [S1].
- **Memory Complexity**: $O(N \cdot M)$ to store matrix $W$ [S1].
- **Strengths**: Provides a direct solution for volume properties; handles inconsistent input via least squares; allows for local support basis functions for efficiency [S1].
- **Limitations**: Requires linearization of the rendering equation; extinction reconstruction is restricted to constant outgoing radiance; cannot jointly optimize extinction with emission/albedo in the same linear system [S1].
- **When to Use**: When a direct, non-iterative solution for volume properties is preferred, or when the rendering equation can be effectively linearized (e.g., single scattering, constant medium radiance) [S1].

## Background
Originated in the context of volume stylization and property manipulation, specifically in the paper "Property and Lighting Manipulations for Static Volume Stylization Using a Painting Metaphor" [S1]. The method allows users to define target images and automatically adjusts volume properties to match them, treating the problem as an inverse rendering task solvable via linear algebra [S1].
