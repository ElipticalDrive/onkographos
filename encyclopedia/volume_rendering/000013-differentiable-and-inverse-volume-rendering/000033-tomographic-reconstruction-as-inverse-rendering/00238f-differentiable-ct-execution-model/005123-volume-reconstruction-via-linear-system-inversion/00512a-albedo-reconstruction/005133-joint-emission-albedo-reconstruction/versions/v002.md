# Joint Emission & Albedo Reconstruction
## Overview
Jointly optimizes emission and diffuse albedo parameters by treating them as a single linear system, leveraging their linear independence to solve for both simultaneously [S1]. Unlike methods that fix one property to solve for the other, this approach updates both in a unified coefficient vector, reducing ambiguity in scenes where emission and reflected light are coupled [S1].

## How it works
**Inputs:**
*   Observed radiance values from multiple viewpoints [S2].
*   Known volume properties (extinction, geometry) required for the forward model [S1].
*   Initial estimate for albedo $\vec{\rho}$ [S2].

**Outputs:**
*   Optimized coefficient vector $\vec{a}$ containing both emission and albedo [S1].

**Data Structures:**
*   Coefficient vector $\vec{a}$: A concatenated vector where the first segment corresponds to emission values and the second to albedo values [S1].
    *   Layout: $\vec{a} = [\vec{L}_{emit}; \vec{\rho}]$ [S1].
    *   Size: $N_{emit} + N_{albedo}$, where $N$ represents the number of discretized volume elements or texture samples [S1].

**Steps:**
1.  **Initialize Albedo:** Set the initial diffuse albedo parameter $\vec{\rho}_0$ to the median of all observed radiance values [S2]. This ensures more plausible material parameters and prevents overfitting to noise, although it may not strictly decrease error metrics compared to unconstrained initialization [S2].
2.  **Initialize Emission:** Set initial emission values $\vec{L}_{emit,0}$. (Not given in the sources. [G]: Typically initialized to zero or a small constant.)
3.  **Formulate Linear System:** Construct the system matrix $\mathbf{M}$ and observation vector $\mathbf{b}$ based on the volume rendering equation [G]. The equation separates into summands for emission and albedo because they are linearly independent [S1].
4.  **Solve:** Solve the linear system $\mathbf{M}\vec{a} = \mathbf{b}$ for $\vec{a}$ [S1].
5.  **Extract:** Split $\vec{a}$ back into $\vec{L}_{emit}$ and $\vec{\rho}$ [S1].

**Formulas:**
The coefficient vector is defined as:
$$ \vec{a} = [\vec{L}_{emit}; \vec{\rho}] $$
where $\vec{L}_{emit}$ and $\vec{\rho}$ are linearly independent and enter as separate summands in the rendering equation (Eq. 2 in [S1]) [S1].

**Parameters:**
*   Albedo Initialization Strategy: Median of observations [S2].

**Edge Cases and Pitfalls:**
*   **Overfitting:** Unconstrained optimization may achieve low error but produce implausible material parameters [S2].
*   **Monte Carlo Noise:** In stochastic rendering contexts, noise can contaminate textured parameters [S2]. (Mitigation strategies like gradient clamping are mentioned in [S2] but not part of the core joint reconstruction definition.)

## Subtopics

### Albedo Initialization
Initializes the diffuse albedo parameter with the median of all observations [S2]. This strategy ensures more plausible results by preventing unconstrained optimization from overfitting to noise and generating implausible material parameters, even if it does not strictly minimize error metrics in all experiments [S2].

## Operating characteristics
*   **Time Complexity:** Not given in the sources. [G]: Depends on the solver (e.g., conjugate gradient) and system size $O((N_{emit}+N_{albedo})^3)$ for direct inversion or less for iterative solvers.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Exploits linear independence to solve for coupled properties simultaneously, reducing ambiguity [S1].
*   **Limitations:** Requires careful handling of volume properties; if extinction is also reconstructed, assumptions about constant outgoing radiance may be needed, though this restriction is usually not problematic as extinction is typically derived first [S1].
*   **When to use:** When both emission and albedo are unknown and need to be recovered from multi-view observations [S1].
*   **When not:** When one property is known or fixed [S1].

## Background
The method is part of a framework for differentiable volume rendering where material properties are optimized to match target images [S1]. It builds on the principle that emission and albedo are linearly independent in the rendering equation [S1].
