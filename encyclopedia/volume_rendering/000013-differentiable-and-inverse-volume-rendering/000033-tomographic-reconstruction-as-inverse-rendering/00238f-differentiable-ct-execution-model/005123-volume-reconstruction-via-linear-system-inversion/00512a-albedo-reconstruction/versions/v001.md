# Albedo Reconstruction

Also called: Property Reconstruction

## Overview
Albedo Reconstruction is a method within differentiable inverse volume rendering that recovers the scattering albedo ($\rho$) of a volume such that the rendered image matches a target. It solves the inverse problem by linearizing the volume rendering equation under the single-scattering assumption, reducing the optimization to a linear system inversion. It is distinguished from Emission Reconstruction by solving for the reflectivity property rather than the self-emission, though both rely on the same linear system framework.

## How it works
**Inputs:**
- Target pixel radiance $L^k_i(x_k, \omega_k)$ for pixel $k$.
- Known volume properties: extinction coefficient $\sigma_t(x)$, scattering phase function (embedded in $L_{scat}$).
- Known lighting: incident radiance $L_o(x^k_s, \omega_k)$ from scene boundaries.
- Known emission: $L_{emit}(x)$.
- Basis functions $\upsilon_i(x)$ for the albedo field.

**Outputs:**
- Albedo coefficients vector $\vec{\rho}$.

**Data Structures:**
- Observation vector $\mathbf{o}$: 1D array of size $N_{pixels}$, where each element $o_k$ corresponds to the residual radiance attributable to scattering.
- Weight matrix $\mathbf{W}$: 2D array of size $N_{pixels} \times N_{basis}$, where $W_{ki}$ is the contribution of basis $i$ to pixel $k$.
- Coefficient vector $\vec{\rho}$: 1D array of size $N_{basis}$.

**Steps:**
1. **Linearization:** Start with the volume rendering equation. Assume single scattering, meaning the scattered light term $L_{scat}$ is independent of the albedo $\rho$.
2. **Residual Calculation:** For each pixel $k$, compute the observation $o_k$ by subtracting known contributions from the target radiance:
   $$ o_k = L^k_i(x_k, \omega_k) - T_r(x_k, x^k_s) L_o(x^k_s, \omega_k) - \int_c T_r(x_k, x_t) \sigma_t(x_t) L_{emit}(x_t) dt $$
   Here, $T_r$ is the transmittance along the ray segment $c$.
3. **Basis Representation:** Represent the albedo field as a linear combination of basis functions:
   $$ \rho(x_t) = \sum_i \rho_i \upsilon_i(x_t) $$
4. **Integral Formulation:** Substitute the basis representation into the scattering integral. The observation equation becomes:
   $$ o_k = \int_c T_r(x_k, x_t) \sigma_t(x_t) L_{scat}(x_t, \omega_k) \left( \sum_i \rho_i \upsilon_i(x_t) \right) dt $$
5. **Matrix Assembly:** Rearrange to isolate $\rho_i$:
   $$ o_k = \sum_i \rho_i \left( \int_c T_r(x_k, x_t) \sigma_t(x_t) L_{scat}(x_t, \omega_k) \upsilon_i(x_t) dt \right) $$
   Define the weight $w_{ki}$ as the integral term:
   $$ w_{ki} = \int_c T_r(x_k, x_t) \sigma_t(x_t) L_{scat}(x_t, \omega_k) \upsilon_i(x_t) dt $$
   This yields the linear system:
   $$ o_k = \vec{\rho} \cdot \vec{w}_k $$
6. **Solving:** Solve the linear system $\mathbf{W} \vec{\rho} = \mathbf{o}$ for $\vec{\rho}$.

**Pseudocode:**
```python
def reconstruct_albedo(target_radiance, transmittance, extinction, emission, scattering_light, basis_functions):
    """
    Reconstructs albedo coefficients by solving a linear system derived from 
    the single-scattering volume rendering equation.
    
    Args:
        target_radiance: Array of target pixel radiances L^k_i.
        transmittance: Function/Array computing T_r(x_k, x_t) along rays.
        extinction: Array of extinction coefficients sigma_t(x).
        emission: Array of emission coefficients L_emit(x).
        scattering_light: Array/Function for L_scatter(x_t, omega_k).
        basis_functions: Array of basis values upsilon_i(x) at sample points.
        
    Returns:
        rho: Array of albedo coefficients.
    """
    # 1. Calculate known contributions to isolate the scattering residual
    # o_k = L_target - T_r * L_o - integral(T_r * sigma_t * L_emit)
    
    # Compute boundary term: T_r(x_k, x_s) * L_o(x_s, omega_k)
    # Assuming L_o is known or zero for simplicity if not provided
    boundary_term = compute_boundary_term(transmittance, target_radiance) 
    
    # Compute emission term: integral_c T_r(x_k, x_t) * sigma_t(x_t) * L_emit(x_t) dt
    emission_term = compute_emission_integral(transmittance, extinction, emission)
    
    # Observation vector o
    observation = target_radiance - boundary_term - emission_term
    
    # 2. Build the weight matrix W
    # w_ki = integral_c T_r(x_k, x_t) * sigma_t(x_t) * L_scatter(x_t, omega_k) * upsilon_i(x_t) dt
    num_pixels = len(target_radiance)
    num_basis = len(basis_functions[0]) # Assuming basis_functions is [basis_idx][sample_idx]
    
    W = zeros((num_pixels, num_basis))
    
    for k in range(num_pixels):
        for i in range(num_basis):
            # Perform ray marching integration for weight w_ki
            integral_sum = 0.0
            for t in samples_along_ray(k):
                T = transmittance(k, t)
                sigma = extinction[t]
                L_sc = scattering_light(t, k) # Depends on view direction omega_k
                upsilon = basis_functions[i][t]
                
                # Integrand: T_r * sigma_t * L_scatter * upsilon_i
                integrand = T * sigma * L_sc * upsilon
                integral_sum += integrand * dt # dt is step size
                
            W[k, i] = integral_sum
            
    # 3. Solve linear system W * rho = o
    # Using least squares if overdetermined, or direct inversion if square
    rho = solve_linear_system(W, observation)
    
    return rho
```

**Parameters:**
- Basis functions $\upsilon_i(x)$: Typically voxel-based or grid-based. Not given in the sources.
- Single-scattering assumption: Required for $L_{scat}$ to be independent of $\rho$.

**Edge cases:**
- Multi-scattering: The method fails if multiple scattering is significant, as $L_{scat}$ becomes dependent on $\rho$.
- Degenerate input: If $\sigma_t$ is zero, the integral vanishes.

## Subtopics

### Joint Emission & Albedo Reconstruction
Optimizes emission and albedo simultaneously. Since $L_{emit}$ and $\rho$ are linearly independent and appear as separate summands in the rendering equation, they can be combined into a single coefficient vector $\mathbf{a} = [\vec{L}_{emit}; \vec{\rho}]$. The linear system is expanded to include weights for emission basis functions alongside albedo weights. This is chosen when both properties are unknown and need to be recovered from the same set of constraints.

## Operating characteristics
- **Time Complexity:** Dominated by the construction of the weight matrix $\mathbf{W}$, which requires ray marching for each basis function and pixel. Solving the linear system is $O(N^3)$ for direct inversion or $O(N^2)$ for iterative methods, where $N$ is the number of unknowns (basis functions).
- **Memory Complexity:** $O(N_{pixels} \times N_{basis})$ to store $\mathbf{W}$.
- **Strengths:** Linear formulation allows for efficient, non-iterative solution (one step).
- **Limitations:** Restricted to single-scattering scenarios. Cannot handle complex lighting interactions involving multiple bounces.
- **When to use:** Stylization or reconstruction where single scattering is a valid approximation and emission is either known or handled separately.

## Background
Originated in the context of volume stylization and property manipulation. The method is described in "Property and Lighting Manipulations for Static Volume Stylization Using a Painting Metaphor" (2014) [S1]. It builds on the linearization of the volume rendering equation to allow artists or algorithms to "paint" properties like albedo directly into the volume.
