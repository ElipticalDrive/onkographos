# End-to-End Reconstruction Model Architecture

Also called: Simultaneous Reconstruction and Denoising Model, End-to-end differentiable architecture, Sinogram-Based Tomography Reconstruction, g(r) model

## Overview
This method is an end-to-end differentiable architecture for tomographic reconstruction that directly maps a noisy sinogram into a denoised reconstruction [S1, unofficial]. It combines reconstruction and denoising in a single forward pass to mitigate noise amplification caused by the ill-conditioning of the Radon transform [S1, unofficial]. Unlike traditional Filtered Back-Projection (FBP) which uses fixed linear filtration, or iterative methods that separate reconstruction and regularization, this model uses two trainable neural networks connected by a differentiable Radon back-projection operator [S1, unofficial]. It builds on [Deep Learning and Neural Architectures](8282-deep-learning-and-neural-architectures.md) by implementing the shared principle of end-to-end optimization via back-projection gradients [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Noisy sensor readings (sinogram) $r$.
*   **Output:** Denoised reconstructed image $x$.

**Data Structures:**
The model consists of two U-Net instances, $g_1$ and $g_2$.
*   $g_1$: Processes the sinogram $r$.
*   $g_2$: Processes the intermediate back-projected images.
*   $A^T$: The Radon back-projection operator (transpose of the discrete Radon transform $A$).

**Formulas:**
The core reconstruction function is:
$$ g(r) = g_2 (A^T g_1 (r)) $$
where:
*   $r$ is the noisy sinogram.
*   $g_1(r)$ outputs a multi-channel sinogram.
*   $A^T$ transforms each channel of $g_1(r)$ into an image.
*   $g_2$ takes the concatenated back-projected images and outputs the final reconstruction.

**Parameters:**
*   **U-Net Sizes:** XXS, XS, S, S-64, M, L, XL, XXL. The difference between S and S-64 is the number of channels [S1, unofficial].
*   **Residual Block Channels:** Doubled every two strided convolutions.
    *   First block of XXS, XS, S uses 32 channels.
    *   First block of S-64, M, L, XL, XXL uses 64 channels [S1, unofficial].
*   **Number of Residual Blocks:** Depends on resolution and model size (see Table C in [S1, unofficial]).
*   **Channels for Radon Backprojection:**
    *   Smallest model (XXS $g_1$, S-64 $g_2$) uses 16 channels.
    *   Other end-to-end models use 32 channels [S1, unofficial].

**Step-by-Step Method:**

1.  **Preprocessing $g_1$ Input:**
    The input sinogram $r$ passes through an "Embedding Conv 2D" layer, then a U-Net Block.

2.  **Processing $g_1$:**
    $g_1$ consists of a sequence of U-Net Blocks.
    *   **Down-sampling Block:** Strided Convolution followed by a sequence of Residual Blocks.
    *   **Up-sampling Block:**
        1.  Take output of previous block.
        2.  Double resolution using bilinear up-sampling.
        3.  Concatenate with skip connection from corresponding down-sampling block.
        4.  Weight concatenation channels using channel attention.
        5.  Shrink channels via $1 \times 1$ convolution.
        6.  Process via sequence of Residual Blocks.
    *   **Multi-input Blocks:** For blocks with multiple inputs (e.g., skip connections), up-sample each input to the largest resolution using bilinear up-sampling, then concatenate all inputs on the channel dimension [S1, unofficial].
    *   **Output:** The latest convolution of $g_1$ reduces the number of channels before Radon backprojection.

3.  **Radon Back-projection:**
    Apply $A^T$ to the output of $g_1$. Each channel of the multi-channel sinogram is transformed into an image [S1, unofficial].

4.  **Preprocessing $g_2$ Input:**
    The first layer of $g_2$ concatenates the input (shape $(ch, 256, 256)$) with a 4-dimensional positional embedding (shape $(4, 256, 256)$) to encode pixel coordinates [S1, unofficial]. This is followed by a "Pos Features Conv 2D" layer.

5.  **Processing $g_2$:**
    $g_2$ consists of a sequence of U-Net Blocks (same structure as $g_1$).

6.  **Training:**
    The model is trained end-to-end by jointly optimizing $g_1$ and $g_2$ to minimize an image reconstruction loss, leveraging the differentiability of the Radon back-projection [S1, unofficial].

## Subtopics

### [ResNet-Based CT Reconstruction](8264-resnet-based-ct-reconstruction.md)
Uses a ResNet neural network to map noisy filtered backprojection (FBP) reconstructions directly to ground truth images, learning to suppress artifacts and noise.

## Operating characteristics
*   **Time and Memory Complexity:** Not given in the sources.
*   **Measured Performance:** The source claims the end-to-end architecture produces more accurate reconstructions while using less parameters and time compared to existing approaches [S1, unofficial].
*   **Scaling:** Not given in the sources.
*   **Strengths:** Combines reconstruction and denoising to mitigate noise amplification caused by the ill-conditioning of the Radon transform; allows richer information flow via multi-channel sinogram output; end-to-end differentiability allows joint optimization [S1, unofficial].
*   **Limitations:** Relies on the differentiability of the Radon back-projection; performance depends on the choice of U-Net size and residual block counts [S1, unofficial].
*   **When to use:** When simultaneous reconstruction and denoising is desired, and differentiable tomographic reconstruction is feasible.
*   **When not:** When iterative methods with physical models are required for higher accuracy or uncertainty quantification (though a generative variant exists for this) [S1, unofficial].

## Background
The method was proposed by Matteo Ronchetti and Davide Bacciu from the University of Pisa in the paper "Generative Tomography Reconstruction" (arXiv:2010.14933v2, 25 Nov 2020) [S1, unofficial]. It is inspired by filtered back-projection (FBP) but replaces the fixed linear filtration with trainable neural networks [S1, unofficial].
