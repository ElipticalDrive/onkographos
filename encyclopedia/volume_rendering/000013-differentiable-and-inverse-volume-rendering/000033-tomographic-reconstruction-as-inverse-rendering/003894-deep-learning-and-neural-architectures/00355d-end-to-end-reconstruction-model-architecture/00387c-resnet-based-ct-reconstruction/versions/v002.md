# ResNet-Based CT Reconstruction
Also called: CNN Reconstruction, Deep Learning CT Reconstruction, Learned Post-Processing, Learned Post-Processing with ResNet

## Overview
ResNet-Based CT Reconstruction is a learned post-processing method that maps noisy filtered backprojection (FBP) reconstructions directly to ground truth images, learning to suppress artifacts and noise [S1, unofficial]. It differs from Gradient-Aware ResNet Reconstruction by treating the input as a static noisy image rather than conditioning on the explicit Radon matrix [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   Input: Noisy FBP reconstruction $f_{BP}$ (2D image tensor).
*   Output: Cleaned reconstruction $f_{pred}$ (2D image tensor).

**Data Structures:**
*   `ResNet`: A convolutional neural network model instance.
*   `inputs`: Tensor of shape `(batch_size, channels, height, width)`.
*   `targets`: Tensor of shape `(batch_size, channels, height, width)` containing ground truth images.

**Training Procedure:**
1.  **Dataset Generation:** Create synthetic ground truth images $f_{true}$ consisting of 5 to 20 overlapping ellipses of varying sizes [S1, unofficial]. Generate sinograms from $f_{true}$ using a projector and projection geometry [S1, unofficial]. Add noise to sinograms [S1, unofficial]. Reconstruct noisy sinograms using filtered backprojection (FBP) to obtain $f_{BP}$ [S1, unofficial].
2.  **Model Initialization:** Initialize the `ResNet()` model [S1, unofficial].
3.  **Loss Function:** Define the loss as Mean Squared Error (MSE) between the network output and the ground truth: $L = \text{MSE}(f_{pred}, f_{true})$ [S1, unofficial].
4.  **Optimization:** Use the Adam optimizer with a learning rate of 0.001 [S1, unofficial].
5.  **Training Loop:** Iterate for `num_epochs` (default 10) [S1, unofficial]. For each batch: forward pass `outputs = model(inputs.float())` [S1, unofficial]. Compute loss `loss = criterion(outputs, targets.float())` [S1, unofficial]. Backpropagate `loss.backward()` [S1, unofficial]. Update weights `optimizer.step()` [S1, unofficial].
6.  **Evaluation:** Evaluate on a validation set [S1, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.optim as optim

class ResNet(nn.Module):
    def __init__(self, in_channels=1, out_channels=1):
        super().__init__()
        self.conv1 = nn.Conv2d(in_channels, 32, kernel_size=3, padding=1)
        self.relu = nn.ReLU()
        self.conv2 = nn.Conv2d(32, out_channels, kernel_size=3, padding=1)

    def forward(self, x):
        return self.conv2(self.relu(self.conv1(x)))

def train_resnet_ct(model, train_loader, num_epochs=10, batch_size=32, lr=0.001):
    criterion = nn.MSELoss()
    optimizer = optim.Adam(model.parameters(), lr=lr)
    model.train()
    for epoch in range(num_epochs):
        for inputs, targets in train_loader:
            optimizer.zero_grad()  # Zero gradients before backward pass [G]
            outputs = model(inputs.float())
            loss = criterion(outputs, targets.float())
            loss.backward()
            optimizer.step()

def infer_resnet_ct(model, inputs):
    model.eval()
    with torch.no_grad():
        return model(inputs.float())
```

**Parameters:**
*   `lr`: Learning rate, default `0.001` [S1, unofficial].
*   `batch_size`: Training batch size, default `32` [S1, unofficial].
*   `num_epochs`: Number of training epochs, default `10` [S1, unofficial].

## Background
The method originates from the use of convolutional neural networks (CNNs) for medical image reconstruction, specifically leveraging ResNet architectures for artifact suppression in CT [S1, unofficial]. It builds on the concept of learned post-processing, where traditional reconstruction methods (like FBP) are used to generate an initial estimate, which is then refined by a deep learning model [S1, unofficial]. The specific implementation cited uses synthetic data with ellipsoidal phantoms to train the network [S1, unofficial].
