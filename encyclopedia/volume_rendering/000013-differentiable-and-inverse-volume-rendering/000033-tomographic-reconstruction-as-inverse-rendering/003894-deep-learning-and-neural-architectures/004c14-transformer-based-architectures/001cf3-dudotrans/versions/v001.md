# DuDoTrans

Also called: DuDoTransModel, Dual-Domain Transformer
## Overview
DuDoTrans is a dual-domain transformer architecture designed for sparse-view CT reconstruction, addressing the ill-posed nature of tomographic recovery when projection data is limited [S1, unofficial]. It distinguishes itself from standard self-attention methods by employing Window-based Multi-Head Self-Attention (W-MSA) to restrict global context to local windows, thereby reducing computational complexity from $O(N^2)$ to $O(N \cdot W_s^2)$ while maintaining long-range dependency modeling through shifted windows [S1, unofficial].
## How it works
### Inputs and Outputs
- **Input**: A 4D tensor $x$ of shape $(B, H, W, C)$, where $B$ is batch size, $H$ and $W$ are spatial dimensions (height and width), and $C$ is the channel dimension (embedding dimension).
- **Output**: A 4D tensor of the same shape $(B, H, W, C)$.

### Data Structures
The core component is the Swin Transformer block. Key internal structures include:

1.  **Relative Position Bias Table**:
    -   **Type**: Parameter tensor.
    -   **Shape**: $((2W_h - 1)(2W_w - 1), \text{num\_heads})$.
    -   **Initialization**: Zeros, followed by truncated normal distribution with standard deviation $\sigma = 0.02$ [S1, unofficial].
2.  **Relative Position Index**:
    -   **Type**: Buffer tensor (non-trainable).
    -   **Shape**: $(W_h W_w, W_h W_w)$.
    -   **Content**: Integer indices mapping spatial relative positions to the bias table [S1, unofficial].

### Parameters
-   `window_size`: Tuple $(W_h, W_w)$ defining the height and width of the attention window. Default: $(7, 7)$ [S1, unofficial].
-   `shift_size`: Integer defining the shift amount for shifted window partitioning. If 0, non-shifted windows are used. Default: $0$ [S1, unofficial].
-   `mlp_ratio`: Float ratio of the MLP hidden dimension to the embedding dimension. Default: $4.0$ [S1, unofficial].
-   `qk_scale`: Float overriding the default QK scaling factor. If `None`, defaults to $head\_dim^{-0.5}$ [S1, unofficial].

### Algorithm Steps

#### 1. Window Partitioning
Reshape the input tensor $x$ into local windows to restrict attention scope.
1.  Reshape $x$ from $(B, H, W, C)$ to $(B, H/W_s, W_s, W/W_s, W_s, C)$.
2.  Permute dimensions to $(B, H/W_s, W/W_s, W_s, W_s, C)$.
3.  Flatten the first and third spatial dimensions to produce $(num\_windows \cdot B, W_s, W_s, C)$, where $num\_windows = (H/W_s) \cdot (W/W_s)$ [S1, unofficial].

#### 2. Relative Position Bias Calculation
Compute indices to look up learned relative positional biases for attention scores.
1.  Generate coordinates: $coords_h = \text{arange}(W_h)$, $coords_w = \text{arange}(W_w)$.
2.  Create meshgrid and flatten to shape $(2, W_h W_w)$. Let this be $coords\_flatten$.
3.  Compute relative coordinates: $relative\_coords = coords\_flatten[:, :, \text{None}] - coords\_flatten[:, \text{None}, :]$. Shape: $(2, W_h W_w, W_h W_w)$.
4.  Permute to $(W_h W_w, W_h W_w, 2)$.
5.  Shift indices to make them non-negative:
    -   $relative\_coords[:, :, 0] += W_h - 1$
    -   $relative\_coords[:, :, 1] += W_w - 1$
6.  Map to 1D index space: $relative\_coords[:, :, 0] *= 2 W_w - 1$.
7.  Sum the last dimension to get the final index map: $relative\_position\_index = \text{sum}(relative\_coords, \text{axis}=-1)$. Shape: $(W_h W_w, W_h W_w)$ [S1, unofficial].

#### 3. Window Attention Forward
Compute attention within each window.
1.  **Linear Projection**: Compute $qkv = \text{Linear}(x)$. Reshape to $(B_, N, 3, \text{num\_heads}, C/\text{num\_heads})$ and permute to $(3, B_, \text{num\_heads}, N, C/\text{num\_heads})$, where $B_ = num\_windows \cdot B$ and $N = W_s^2$ [S1, unofficial].
2.  **Scale Q**: Extract $Q$ from $qkv$. Scale it: $Q = Q \cdot \text{scale}$, where $\text{scale} = \text{qk\_scale}$ or $head\_dim^{-0.5}$ [S1, unofficial].
3.  **Attention Scores**: Compute $attn = Q @ K^T$. Shape: $(B_, \text{num\_heads}, N, N)$ [S1, unofficial].
4.  **Add Bias**:
    -   Retrieve bias: $bias = \text{relative\_position\_bias\_table}[relative\_position\_index]$. Shape: $(N, N, \text{num\_heads})$.
    -   Reshape and permute bias to $(\text{num\_heads}, N, N)$.
    -   Add to attention scores: $attn = attn + bias$ [S1, unofficial].
5.  **Softmax**: Apply softmax along the last dimension: $attn = \text{softmax}(attn)$ [S1, unofficial].
6.  **Dropout**: Apply attention dropout [S1, unofficial].
7.  **Output Projection**:
    -   Compute $V_{out} = attn @ V$. Shape: $(B_, \text{num\_heads}, N, C/\text{num\_heads})$.
    -   Transpose and reshape to $(B_, N, C)$.
    -   Apply linear projection and projection dropout to get the final output for the window [S1, unofficial].

#### 4. Window Reverse
Reconstruct the full image tensor from the processed windows.
1.  Reshape windows from $(num\_windows \cdot B, W_s, W_s, C)$ to $(B, H/W_s, W/W_s, W_s, W_s, C)$.
2.  Permute to $(B, H/W_s, W_s, W/W_s, W_s, C)$.
3.  Flatten to $(B, H, W, C)$ [S1, unofficial].

### Pseudocode
```python
import torch
import torch.nn as nn
import torch.nn.functional as F
import math

class WindowAttention(nn.Module):
    def __init__(self, dim, window_size, num_heads, qkv_bias=True, qk_scale=None, attn_drop=0., proj_drop=0.):
        super().__init__()
        self.dim = dim
        self.window_size = window_size  # Wh, Ww
        self.num_heads = num_heads
        head_dim = dim // num_heads
        self.scale = qk_scale or head_dim ** -0.5

        # Relative position bias table shape: (2*Wh-1)*(2*Ww-1), num_heads
        self.relative_position_bias_table = nn.Parameter(
            torch.zeros((2 * window_size[0] - 1) * (2 * window_size[1] - 1), num_heads)
        )
        
        # Get pair-wise relative coordinates index
        coords_h = torch.arange(self.window_size[0])
        coords_w = torch.arange(self.window_size[1])
        coords = torch.stack(torch.meshgrid([coords_h, coords_w]))  # 2, Wh, Ww
        coords_flatten = torch.flatten(coords, 1)  # 2, Wh*Ww
        relative_coords = coords_flatten[:, :, None] - coords_flatten[:, None, :]  # 2, Wh*Ww, Wh*Ww
        relative_coords = relative_coords.permute(1, 2, 0).contiguous()  # Wh*Ww, Wh*Ww, 2
        relative_coords[:, :, 0] += self.window_size[0] - 1  # shift to start from 0
        relative_coords[:, :, 1] += self.window_size[1] - 1
        relative_coords[:, :, 0] *= 2 * self.window_size[1] - 1
        relative_position_index = relative_coords.sum(-1)  # Wh*Ww, Wh*Ww
        self.register_buffer("relative_position_index", relative_position_index)

        self.qkv = nn.Linear(dim, dim * 3, bias=qkv_bias)
        self.attn_drop = nn.Dropout(attn_drop)
        self.proj = nn.Linear(dim, dim)
        self.proj_drop = nn.Dropout(proj_drop)

        nn.init.trunc_normal_(self.relative_position_bias_table, std=.02)

    def forward(self, x, mask=None):
        """
        x: shape (B_, N, C) where N = Wh * Ww
        mask: shape (B_, num_heads, N, N) or None
        """
        B_, N, C = x.shape
        
        qkv = self.qkv(x).reshape(B_, N, 3, self.num_heads, C // self.num_heads).permute(2, 0, 3, 1, 4)
        q, k, v = qkv[0], qkv[1], qkv[2]  # B_, num_heads, N, head_dim

        q = q * self.scale
        attn = q @ k.transpose(-2, -1)

        # Add relative position bias
        relative_position_bias = self.relative_position_bias_table[self.relative_position_index.view(-1)].view(
            self.window_size[0] * self.window_size[1], self.window_size[0] * self.window_size[1], -1)  # Wh*Ww, Wh*Ww, nH
        relative_position_bias = relative_position_bias.permute(2, 0, 1).contiguous()  # nH, Wh*Ww, Wh*Ww
        attn = attn + relative_position_bias.unsqueeze(0)

        if mask is not None:
            nW = mask.shape[0]
            attn = attn.view(B_ // nW, nW, self.num_heads, N, N) + mask.unsqueeze(1).unsqueeze(0)
            attn = attn.view(-1, self.num_heads, N, N)
        
        attn = self.attn_drop(attn.softmax(dim=-1))

        x = (attn @ v).transpose(1, 2).reshape(B_, N, C)
        x = self.proj(x)
        x = self.proj_drop(x)
        return x

class SwinTransformerBlock(nn.Module):
    def __init__(self, dim, input_resolution, num_heads, window_size=7, shift_size=0, 
                 mlp_ratio=4., qkv_bias=True, qk_scale=None, drop=0., attn_drop=0., drop_path=0.):
        super().__init__()
        self.dim = dim
        self.input_resolution = input_resolution
        self.num_heads = num_heads
        self.window_size = window_size
        self.shift_size = shift_size
        self.mlp_ratio = mlp_ratio
        
        if min(self.input_resolution) <= self.window_size:
            # if window size is larger than input resolution, we don't partition windows
            self.shift_size = 0
            self.window_size = min(self.input_resolution)
        
        assert 0 <= self.shift_size < self.window_size, "shift_size must in 0-window_size"

        self.norm1 = nn.LayerNorm(dim)
        self.attn = WindowAttention(
            dim, window_size=(self.window_size, self.window_size), num_heads=num_heads,
            qkv_bias=qkv_bias, qk_scale=qk_scale, attn_drop=attn_drop, proj_drop=drop)

        self.drop_path = nn.Identity()
        self.norm2 = nn.LayerNorm(dim)
        mlp_hidden_dim = int(dim * mlp_ratio)
        self.mlp = Mlp(in_features=dim, hidden_features=mlp_hidden_dim, act_layer=nn.GELU, drop=drop)

    def forward(self, x):
        H, W = self.input_resolution
        B, L, C = x.shape
        assert L == H * W, "input feature has wrong size"

        shortcut = x
        x = self.norm1(x)
        x = x.view(B, H, W, C)

        # Pad feature map
        pad_l = pad_t = 0
        pad_r = (self.window_size - W % self.window_size) % self.window_size
        pad_b = (self.window_size - H % self.window_size) % self.window_size
        x = F.pad(x, (0, 0, pad_l, pad_r, pad_t, pad_b))
        _, Hp, Wp, _ = x.shape

        # cyclic shift
        if self.shift_size > 0:
            shifted_x = torch.roll(x, shifts=(-self.shift_size, -self.shift_size), dims=(1, 2))
        else:
            shifted_x = x

        # Partition windows
        x_windows = window_partition(shifted_x, self.window_size)  # nW*B, Wh, Ww, C
        x_windows = x_windows.view(-1, self.window_size * self.window_size, C)  # nW*B, Wh*Ww, C

        # W-MSA/SW-MSA
        attn_windows = self.attn(x_windows)  # nW*B, Wh*Ww, C

        # Merge windows
        attn_windows = attn_windows.view(-1, self.window_size, self.window_size, C)
        shifted_x = window_reverse(attn_windows, self.window_size, Hp, Wp)  # B H' W' C

        # Reverse cyclic shift
        if self.shift_size > 0:
            x = torch.roll(shifted_x, shifts=(self.shift_size, self.shift_size), dims=(1, 2))
        else:
            x = shifted_x

        if pad_r > 0 or pad_b > 0:
            x = x[:, :H, :W, :].contiguous()

        x = x.view(B, H * W, C)

        # FFN
        x = shortcut + self.drop_path(x)
        x = x + self.drop_path(self.mlp(self.norm2(x)))
        return x

def window_partition(x, window_size):
    """
    Args:
        x: (B, H, W, C)
        window_size (int): window size
    Returns:
        windows: (num_windows*B, window_size, window_size, C)
    """
    B, H, W, C = x.shape
    x = x.view(B, H // window_size, window_size, W // window_size, window_size, C)
    windows = x.permute(0, 1, 3, 2, 4, 5).contiguous().view(-1, window_size, window_size, C)
    return windows

def window_reverse(windows, window_size, H, W):
    """
    Args:
        windows: (num_windows*B, window_size, window_size, C)
        window_size (int): Window size
        H (int): Height of image
        W (int): Width of image
    Returns:
        x: (B, H, W, C)
    """
    B = int(windows.shape[0] / (H * W / window_size / window_size))
    x = windows.view(B, H // window_size, W // window_size, window_size, window_size, -1)
    x = x.permute(0, 1, 3, 2, 4, 5).contiguous().view(B, H, W, -1)
    return x

class Mlp(nn.Module):
    def __init__(self, in_features, hidden_features=None, out_features=None, act_layer=nn.GELU, drop=0.):
        super().__init__()
        out_features = out_features or in_features
        hidden_features = hidden_features or in_features
        self.fc1 = nn.Linear(in_features, hidden_features)
        self.act = act_layer()
        self.fc2 = nn.Linear(hidden_features, out_features)
        self.drop = nn.Dropout(drop)

    def forward(self, x):
        x = self.fc1(x)
        x = self.act(x)
        x = self.drop(x)
        x = self.fc2(x)
        x = self.drop(x)
        return x
```

### Edge Cases and Pitfalls
-   **Input Resolution vs Window Size**: If the input spatial dimensions ($H$ or $W$) are smaller than or equal to the `window_size`, the `shift_size` is forced to $0$ and the `window_size` is reduced to the minimum input dimension to avoid invalid partitioning [S1, unofficial].
-   **Precision**: The relative position bias calculation relies on integer arithmetic for index mapping; ensure no overflow occurs for very large window sizes, though typical values (7x7) are safe.
-   **Boundary Handling**: Padding is applied during window partitioning to handle cases where $H$ or $W$ are not divisible by `window_size`. This padding must be removed before the final output is returned [S1, unofficial].

## Operating characteristics
-   **Time Complexity**: The window-based attention reduces complexity from $O(N^2)$ to $O(N \cdot W_s^2)$, where $N$ is the number of tokens and $W_s$ is the window size [S1, unofficial].
-   **Memory Complexity**: Requires storage for the relative position bias table of size $((2W_h - 1)(2W_w - 1), \text{num\_heads})$ and intermediate tensors for window partitioning [S1, unofficial].
-   **Strengths**: Efficiently handles large images by limiting attention to local windows while capturing global context through shifted windows. Suitable for sparse-view CT where data is limited.
-   **Limitations**: Performance depends heavily on the choice of `window_size` and `shift_size`. Not given in the sources.
-   **When to Use**: Sparse-view CT reconstruction tasks where computational efficiency is critical and global context is needed.
-   **When Not to Use**: Dense-view CT where standard attention might be feasible, or when real-time inference on extremely low-power hardware is required without optimization.

## Background
DuDoTrans was introduced by Ce Wang, Kun Shang, Haimiao Zhang, Qian Li, and S. Kevin Zhou in the paper "DuDoTrans: Dual-Domain Transformer for Sparse-View CT Reconstruction", published in the International Workshop on Machine Learning for Medical Image Reconstruction in 2022 [S1, unofficial]. It adapts the Swin Transformer architecture, originally designed for natural images, to the domain of tomographic reconstruction, leveraging the dual-domain (spatial and frequency-like) properties of CT data.
