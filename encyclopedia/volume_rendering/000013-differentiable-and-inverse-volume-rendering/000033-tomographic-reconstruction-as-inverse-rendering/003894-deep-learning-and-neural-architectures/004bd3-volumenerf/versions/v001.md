# VolumeNeRF

Also called: CT VolumeNeRF, NeRF-based model for 3D CT reconstruction from a single-view X-ray image

## Overview
VolumeNeRF is a neural radiance field (NeRF)-based method that reconstructs 3D Computed Tomography (CT) volumes from a single 2D X-ray projection view [S1]. It addresses the ill-posed nature of single-view reconstruction by integrating prior anatomical knowledge—specifically average CT images and likelihood images—and explicit projection relationships via Projection Attention Modules (PAMs) [S1]. Unlike sibling methods that may lack structural priors, VolumeNeRF conditions a 3D encoder-decoder network on 2D style vectors derived from the input X-ray and priors, supervising the output through differentiable volume rendering of the synthesized X-ray [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A single 2D X-ray image $I$ (resolution $128 \times 128$), a Likelihood Image $L$ (same resolution as $I$), and a Mean CT Image $\bar{V}$ (2D slice or volume representation depending on implementation, treated as prior) [S1].
*   **Output:** A reconstructed 3D CT volume $\tilde{V}$ (resolution $128 \times 128 \times 128$ voxels) [S1].

**Data Structures and Layouts:**
*   **Voxel Grid:** The volume $\tilde{V}$ is represented as a 3D grid of size $D \times H \times W = 128 \times 128 \times 128$ [S1]. Each voxel stores an attenuation coefficient $\mu$ [S1].
*   **Feature Maps:**
    *   3D Feature Maps: $v_i \in \mathbb{R}^{C \times D \times H \times W}$ at various encoder/decoder stages [S1].
    *   2D Pixel Feature Maps: $y \in \mathbb{R}^{C \times H \times W}$ derived from the X-ray image via 2D convolutions [S1].
    *   Style Vectors: Generated by the ConvNeXt mapping network, used to modulate 3D features [S1].
*   **Projection Attention Module (PAM) State:**
    *   Offset Coordinates: Learned 2D coordinates $(u, v)$ for each voxel, constrained within the image bounds $[0, 128] \times [0, 128]$ [S1].
    *   Attention Weights: Scalar weights determining the contribution of specific pixels to a voxel's feature [S1].

**Numbered Steps:**

1.  **Data Preprocessing:**
    *   Resample all input CT scans to a voxel size of $2.5 \times 2.5 \times 2.5$ mm [S1].
    *   Crop a central $128 \times 128 \times 128$ voxel region from each scan [S1].
    *   Compute the Mean CT Image $\bar{V}$ by performing deformable registration to align all training CT volumes and averaging them [S1].
    *   Compute Likelihood Images $L$ for each volume. $L$ quantifies the difference between the patient's volume and the average volume; pixels with higher deviation from the prior distribution have higher log-likelihood values [S1].
    *   Synthesize training X-ray images $I$ using differentiable Digital Reconstructed Radiographs (DRR) from the ground truth CT volumes at a resolution of $128 \times 128$ [S1].

2.  **Style Vector Generation (2D Mapping):**
    *   Input the X-ray image $I$, Likelihood Image $L$, and Mean CT Image $\bar{V}$ into a ConvNeXt-based 2D mapping network [S1].
    *   The network generates style vectors $s$ that condition the subsequent 3D reconstruction, similar to the style modulation in StyleGAN2 [S1].

3.  **3D Volumetric Reconstruction:**
    *   Feed the style vectors $s$ into a 3D encoder-decoder network [S1].
    *   The 3D encoder extracts hierarchical 3D feature maps $v_i$ from the latent representation initialized by the style vectors [S1].
    *   The 3D decoder upsamples these features to generate the final volumetric representation $\tilde{V}$ [S1].

4.  **Projection Attention Module (PAM) Integration:**
    *   For each voxel in the 3D feature maps, the PAM learns spatial correspondence with 2D pixels in the X-ray image [S1].
    *   **Offset Learning:** An offset convolution layer predicts 2D offset coordinates for each voxel, mapping the voxel to a specific location in the 2D feature map $y$ derived from $I$ [S1].
    *   **Feature Aggregation:**
        *   Extract the 2D pixel feature map $y$ corresponding to the predicted offset coordinates [S1].
        *   Calculate attention weights (via Softmax and convolution operations) to weight the contribution of these pixels [S1].
        *   Concatenate the original 3D feature $v_{i+1}$ and the weighted 2D pixel feature map $y$ [S1].
        *   Fuse them using a 3D convolutional operator to generate the enhanced voxel feature map $v_{yi+1} \in \mathbb{R}^{C \times D \times H \times W}$ [S1].
    *   This process is repeated through the encoder-decoder stages to inject 2D projection priors into the 3D volume [S1].

5.  **Volume Rendering (Forward Projection):**
    *   To provide supervision, synthesize a rendered X-ray image $\hat{I}$ from the reconstructed volume $\tilde{V}$ using the same viewpoint as the input $I$ [S1].
    *   Apply the Lambert-Beer law for ray marching [S1]. For a ray $r$ passing through $N$ voxels:
        $$
        \hat{I} = I_0 \exp \left( - \sum_{i=1}^{N} \mu_i \delta_i \right)
        $$
        where $\mu_i$ is the attenuation coefficient of the $i$-th voxel, $\delta_i$ is the distance the beam propagates within that voxel, and $I_0$ is the initial intensity [S1].
    *   The rendered image $\hat{I}$ is compared against the input $I$ [S1].

6.  **Loss Calculation and Optimization:**
    *   Compute the total loss $\mathcal{L}_{total}$ as a weighted sum of three terms [S1]:
        $$
        \mathcal{L}_{total} = \lambda_{recon} \mathcal{L}_{recon} + \lambda_{edge} \mathcal{L}_{edge} + \lambda_{render} \mathcal{L}_{render}
        $$
    *   **Reconstruction Loss ($\mathcal{L}_{recon}$):** L1 loss between the reconstructed CT $\tilde{V}$ and the ground truth CT (if available during training) [S1].
    *   **Edge Loss ($\mathcal{L}_{edge}$):** L1 loss between the edges of the generated CT and real CT, where edges are extracted using the Scharr operator [S1].
    *   **Rendering Loss ($\mathcal{L}_{render}$):** L1 loss between the input X-ray image $I$ and the rendered X-ray image $\hat{I}$ [S1].
    *   Optimize the network parameters (ConvNeXt weights, 3D encoder-decoder weights, PAM parameters) using gradient descent [S1].

**Parameters:**
*   $\lambda_{recon} = 1$ [S1].
*   $\lambda_{edge} = 0.05$ [S1].
*   $\lambda_{render} = 0.001$ [S1].
*   Voxel size: $2.5 \times 2.5 \times 2.5$ mm [S1].
*   Volume resolution: $128 \times 128 \times 128$ [S1].
*   X-ray resolution: $128 \times 128$ [S1].

**Edge Cases and Pitfalls:**
*   **Boundary Constraints:** Voxels in distant planes have intersection points with the detector plane that fall outside the detection range. The learned offset coordinates are manually constrained within the X-ray image size range $[0, 128] \times [0, 128]$. Consequently, corresponding pixels for such distant voxels are located at the edges of the X-ray image, potentially limiting the accuracy of projection correspondence for deep structures [S1].
*   **Memory Limitations:** The method requires cropping to $128^3$ voxels due to memory constraints, which may discard peripheral anatomical information [S1].

## Operating characteristics
*   **Time and Memory Complexity:** Not explicitly given in the sources. Memory is constrained by the $128 \times 128 \times 128$ voxel grid and the 3D convolutional operations [S1].
*   **Measured Performance:** On the LIDC-IDRI dataset (1,018 chest CT volumes; 865 training, 51 validation, 102 testing), VolumeNeRF achieves a PSNR of $25.59 \pm 0.20$ and SSIM of $0.660 \pm 0.002$ [S1].
*   **Scaling:** The method is validated on chest CTs. Scaling to larger volumes or different anatomies requires re-evaluation of the cropping strategy and prior computation [S1].
*   **Strengths:** Incorporates anatomical priors (mean CT, likelihood) and explicit projection relationships (PAMs), addressing the ill-posedness of single-view reconstruction better than methods lacking these constraints [S1].
*   **Limitations:** Relies on differentiable DRR for training data synthesis, which may not perfectly capture all physical X-ray artifacts [S1]. Performance is limited by the fixed $128^3$ resolution and the manual constraint on offset coordinates [S1].

## Background
VolumeNeRF was proposed by J. Liu and X. Bai in 2024 [S1]. It is based on neural radiance fields (NeRF) and aims to reconstruct CT volumes from a single X-ray projection view, reducing radiation exposure and scan time compared to traditional multi-view CT [S1]. The method was validated on the LIDC-IDRI dataset [S1].
