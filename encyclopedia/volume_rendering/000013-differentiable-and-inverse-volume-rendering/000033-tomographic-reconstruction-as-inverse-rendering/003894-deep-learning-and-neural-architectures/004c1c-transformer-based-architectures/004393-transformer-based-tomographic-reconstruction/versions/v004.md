# Transformer-based Tomographic Reconstruction

Also called: SSTrans-3D, Slice-by-slice transformer network

## Overview
Transformer-based Tomographic Reconstruction is a deep learning technique that reconstructs 3D medical images, specifically Single-Photon Emission Computed Tomography (SPECT), using a slice-by-slice transformer network (SSTrans-3D) [S1][S2, unofficial]. It addresses the problem of considerable artifacts caused by incomplete projection data, which is common in tomographic acquisitions [S1][S2, unofficial]. Unlike convolutional neural networks (CNNs) that suffer from limited receptive fields, this method leverages the global context modeling of transformers to understand the whole image structure [S1][S2, unofficial]. It differs from hybrid approaches like Deep Iterative Optimization-based Residual-learning (DIOR) by relying purely on transformer architectures rather than combining deep learning with iterative optimization steps [S1][S2, unofficial].

## How it works
The method utilizes a slice-by-slice transformer network (SSTrans-3D) to reconstruct 3D volumes [S1][S2, unofficial]. The core innovation is the application of vision transformers to remove the restrictions of CNNs in image reconstruction, specifically their inability to capture global dependencies when local receptive fields are smaller than the image size [S1][S2, unofficial].

**Inputs and Outputs:**
*   **Input:** Incomplete or limited-angle projection data (or reconstructed initial estimates derived from such data) for SPECT imaging [S1][S2, unofficial].
*   **Output:** A reconstructed 3D SPECT image volume with reduced artifacts [S1][S2, unofficial].

**Data Structures:**
Not given in the sources.

**Steps:**
1.  **Tokenization:** The input 2D slices of the tomographic data are discretized into patches or tokens, similar to standard Vision Transformer (ViT) approaches [S1][S2, unofficial].
2.  **Attention Aggregation:** Self-attention mechanisms compute pairwise interactions between all tokens within the slice (and potentially across slices if implied by the 3D nature, though the name suggests slice-by-slice processing) to fuse information [S1][S2, unofficial]. This allows the model to capture global structural context that CNNs miss [S1][S2, unofficial].
3.  **Reconstruction:** The transformer layers process these aggregated features to produce the final high-quality 3D SPECT image, mitigating artifacts caused by incomplete data [S1][S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Incomplete Data:** The method is specifically designed for scenarios with incomplete projection data, where traditional methods fail [S1][S2, unofficial].
*   **Gradient Vanishing:** While not explicitly solved by the transformer itself, the method avoids the gradient-vanishing issues associated with very deep stacked CNN layers (like SRCNN) by using transformer architectures [S1][S2, unofficial].

## Subtopics

### SSTrans-3D
The specific implementation of slice-by-slice transformer network for 3D SPECT reconstruction. It is chosen when dealing with incomplete projection data in SPECT imaging where global context is critical to artifact reduction [S1][S2, unofficial].

### DIOR (Deep Iterative Optimization-based Residual-learning)
A comparative method that combines deep learning with iterative optimization for limited-angle CT. It is chosen when hybrid approaches are preferred, but SSTrans-3D is preferred for pure transformer-based global modeling [S1][S2, unofficial].

## Background
The method was introduced in the context of addressing limitations in traditional and deep learning image reconstruction techniques. Specifically, it was proposed to remove the restrictions of CNNs in image reconstruction, such as the inability to understand the whole image when receptive fields are smaller than the image size [S1][S2, unofficial]. It is compared against Deep Iterative Optimization-based Residual-learning (DIOR), which was suggested for reconstructing limited-angle CT [S1][S2, unofficial]. The work is cited in "A Novel Implicit Neural Representation for Volume Data" (2023) [S1][S2, unofficial].
