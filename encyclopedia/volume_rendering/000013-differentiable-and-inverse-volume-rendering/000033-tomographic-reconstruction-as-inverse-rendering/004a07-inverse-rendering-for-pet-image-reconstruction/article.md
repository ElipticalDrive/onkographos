# Inverse Rendering for PET Image Reconstruction

Also called: Differentiable PET Reconstruction, PET Inverse Rendering

## Overview
Inverse Rendering (IR) for Positron Emission Tomography (PET) reconstructs the highest-resolution spatial distribution of a radioactive tracer (the emission image) from measured sinograms by inverting a differentiable forward rendering process [S1]. Unlike traditional algebraic methods or standard Maximum Likelihood Expectation Maximization (MLEM), this approach treats reconstruction as a gradient-based optimization problem where the forward model simulates photon detection via hybrid Monte Carlo sampling coupled with an analytical projector [S1]. It sets itself apart by leveraging physical differentiability to directly optimize voxel values against measured data, achieving superior resolution (clearly separating 0.7 mm hot-spots) and intensity accuracy compared to MLEM and deep learning baselines [S1].

## How it works
The method reconstructs the 3D emission image $\mathbf{I}$ by minimizing the discrepancy between the measured sinogram $\mathbf{M}$ and a rendered sinogram $\mathcal{R}(\mathbf{I})$ generated by a differentiable forward model [S1].

### Inputs and Outputs
*   **Input:** Measured sinogram data $\mathbf{M}$, representing coincident photon detection events [S1].
*   **Output:** Reconstructed emission image $\hat{\mathbf{I}}$, a 3D volume representing the spatial distribution of the radiotracer [S1].

### Data Structures
*   **Emission Image ($\mathbf{I}$):** A 3D voxel grid representing the radioactive tracer distribution $f(x, y, z)$ [S1].
*   **Sinogram ($\mathbf{M}$):** A 4D dataset indexed by LOR parameters $(s, \theta, z, \delta)$ [S1].
    *   $s$: Distance between the axial axis and the projection of the Line of Response (LOR) onto the transaxial plane [S1].
    *   $\theta$: Angle between the projection and the transaxial axis (y-axis) [S1].
    *   $z$: Axial coordinate of the midpoint between the two detectors of the LOR [S1].
    *   $\delta$: Tangent of the angle between the LOR and the transaxial plane [S1].
    *   The set of all LORs is specified by $(s, \theta, z, \delta) \in \mathbb{R}^{M \times 4}$, where $M$ is the number of crystal pairs [S1].
*   **Time-of-Flight (TOF) Bins:** For TOF-capable scanners, each LOR is divided into multiple bins symmetrically centered around the LOR midpoint [S1].

### Forward Rendering Operator $\mathcal{R}(\mathbf{I})$
The forward model simulates the PET acquisition process [S1]. It uses hybrid Monte Carlo sampling to estimate line integrals of the source distribution along each LOR [S1]. For Time-of-Flight (TOF) rendering, the LOR is divided into $n$ TOF bins [S1]. For the $i$-th TOF bin, the rendered sinogram value is estimated by sampling the emission image at various points within the image domain [S1]. The Monte Carlo estimator for the rendered sinogram $\mathcal{R}(\mathbf{I})$ is defined as [S1]:

$$
\mathcal{R}(\mathbf{I}) = p(s, \theta, z, \delta) = \frac{1}{m} \sum_{i=1}^n \sum_{j=1}^m f_i\left(s \cdot \cos(\theta) - t_j \cdot \sin(\theta), \, s \cdot \sin(\theta) + t_j \cdot \cos(\theta)\right)
$$

Where:
*   $\mathcal{R}(\mathbf{I})$ is the rendered sinogram value for a specific LOR [S1].
*   $n$ is the total number of TOF bins [S1].
*   $m$ is the total number of sampling points in the $i$-th TOF bin [S1].
*   $f_i$ is the voxel value of the emission image at the sampled location [S1].
*   $t_j$ denotes the projection of the LOR in the transaxial plane from the axial position $z$, corresponding to the $j$-th sampling point [S1].
*   The coordinates $(s \cdot \cos(\theta) - t_j \cdot \sin(\theta), s \cdot \sin(\theta) + t_j \cdot \cos(\theta))$ map the LOR geometry to the 2D transaxial plane coordinates for sampling [S1].

### Optimization Loop
The reconstruction is performed by minimizing a loss function $\mathcal{L}$ that measures the alignment between the rendered sinogram $\mathcal{R}(\mathbf{I})$ and the measured sinogram $\mathbf{M}$ [S1].

1.  **Initialize:** Start with an initial estimate of the emission image $\mathbf{I}^0$ [G].
2.  **Forward Pass:** Compute the rendered sinogram $\mathcal{R}(\mathbf{I}^k)$ using the forward rendering operator described above [S1].
3.  **Loss Calculation:** Compute the loss $\mathcal{L}(\mathbf{M}; \mathcal{R}(\mathbf{I}^k))$ [S1]. The source specifies Mean Squared Error (MSE) as an example [S1].
    $$
    \hat{\mathbf{I}} = \operatorname{argmin}_{\mathbf{I}} \mathcal{L}(\mathbf{M}; \mathcal{R}(\mathbf{I}))
    $$
4.  **Gradient Computation:** Compute the gradient of the loss with respect to the emission image $\mathbf{I}^k$ [S1]. This requires differentiating the forward rendering operator $\mathcal{R}$ with respect to each voxel [S1]. The differentiable forward rendering process provides the estimation of how a change in sinogram $y$ can be achieved by modifying voxel values [S1].
5.  **Update:** Update the emission image using gradient descent [S1]:
    $$
    \mathbf{I}^{k+1} = \mathbf{I}^k - \eta \frac{\partial \mathcal{L}}{\partial \mathbf{I}^k}
    $$
    Where:
    *   $\eta$ is the learning rate [S1].
    *   $\frac{\partial \mathcal{L}}{\partial \mathbf{I}^k}$ is the gradient propagated from the loss function at iteration $k$ [S1].
6.  **Iterate:** Set $\mathbf{I}^k = \mathbf{I}^{k+1}$ and repeat until convergence or a maximum number of iterations is reached [S1].

```python
import math

def inverse_rendering_pet(measured_sinogram, lor_params, num_iterations, learning_rate, num_tof_bins, num_samples_per_bin):
    """
    Reconstructs PET emission image using inverse rendering.
    
    Args:
        measured_sinogram: List of lists of shape (M, num_tof_bins) containing measured sinogram data M.
        lor_params: List of tuples (s, theta, z, delta) for M crystal pairs.
        num_iterations: Number of optimization steps.
        learning_rate: Step size eta for gradient descent.
        num_tof_bins: Number of TOF bins n.
        num_samples_per_bin: Number of sampling points m per TOF bin.
        
    Returns:
        reconstructed_image: 3D list representing the emission image I.
    """
    M = len(lor_params)
    # Initialize emission image I^0 with zeros [G]
    img_dim = 100
    emission_image = [[[0.0 for _ in range(img_dim)] for _ in range(img_dim)] for _ in range(img_dim)]
    
    for k in range(num_iterations):
        # 1. Forward Pass: Compute rendered sinogram R(I^k) [S1]
        rendered_sinogram = [[0.0 for _ in range(num_tof_bins)] for _ in range(M)]
        
        for l in range(M):
            s, theta, z, delta = lor_params[l]
            for i in range(num_tof_bins): # Iterate over TOF bins
                # Generate sampling points t_j along the LOR projection [G]
                sampling_points_t = [float(j) * 2.0 - float(num_samples_per_bin) for j in range(num_samples_per_bin)]
                
                bin_sum = 0.0
                for j in range(num_samples_per_bin):
                    t_j = sampling_points_t[j]
                    # Map to 2D transaxial plane coordinates [S1]
                    x_prime = s * math.cos(theta) - t_j * math.sin(theta)
                    y_prime = s * math.sin(theta) + t_j * math.cos(theta)
                    
                    # Sample voxel value f_i at (x_prime, y_prime) at axial position z [S1]
                    # Clamp to image bounds [G]
                    x_idx = int(max(0, min(img_dim - 1, x_prime)))
                    y_idx = int(max(0, min(img_dim - 1, y_prime)))
                    z_idx = int(max(0, min(img_dim - 1, z)))
                    f_i = emission_image[x_idx][y_idx][z_idx]
                    bin_sum += f_i
                
                # Average over m samples [S1]
                rendered_sinogram[l][i] = bin_sum / num_samples_per_bin
        
        # 2. Loss Calculation: Compute MSE loss [S1]
        loss = 0.0
        count = 0
        for l in range(M):
            for i in range(num_tof_bins):
                diff = measured_sinogram[l][i] - rendered_sinogram[l][i]
                loss += diff * diff
                count += 1
        loss = loss / count
        
        # 3. Gradient Computation: Backpropagate through forward render [S1]
        # dL/dR for MSE is 2*(R - M) / (M * N) [G]
        dL_dR = [[0.0 for _ in range(num_tof_bins)] for _ in range(M)]
        for l in range(M):
            for i in range(num_tof_bins):
                dL_dR[l][i] = 2.0 * (rendered_sinogram[l][i] - measured_sinogram[l][i]) / count
        
        # Accumulate gradients into emission image [G]
        gradient_image = [[[0.0 for _ in range(img_dim)] for _ in range(img_dim)] for _ in range(img_dim)]
        for l in range(M):
            s, theta, z, delta = lor_params[l]
            for i in range(num_tof_bins):
                grad_val = dL_dR[l][i] / num_samples_per_bin
                sampling_points_t = [float(j) * 2.0 - float(num_samples_per_bin) for j in range(num_samples_per_bin)]
                for j in range(num_samples_per_bin):
                    t_j = sampling_points_t[j]
                    x_prime = s * math.cos(theta) - t_j * math.sin(theta)
                    y_prime = s * math.sin(theta) + t_j * math.cos(theta)
                    x_idx = int(max(0, min(img_dim - 1, x_prime)))
                    y_idx = int(max(0, min(img_dim - 1, y_prime)))
                    z_idx = int(max(0, min(img_dim - 1, z)))
                    gradient_image[x_idx][y_idx][z_idx] += grad_val
        
        # 4. Update: I^{k+1} = I^k - eta * dL/dI^k [S1]
        for x in range(img_dim):
            for y in range(img_dim):
                for z in range(img_dim):
                    emission_image[x][y][z] = emission_image[x][y][z] - learning_rate * gradient_image[x][y][z]
                    
    return emission_image
```

### Parameters
*   **Learning Rate ($\eta$):** The step size for gradient descent [S1].
*   **Number of TOF Bins ($n$):** Determines the temporal resolution of the forward model [S1].
*   **Number of Sampling Points ($m$):** The number of Monte Carlo samples per TOF bin [S1].
*   **Scanner Geometry:** Defined by $(s, \theta, z, \delta)$ for each of the $M$ crystal pairs [S1].

### Edge Cases and Pitfalls
*   **Ambiguity:** The inverse problem is inherently ambiguous; gradient-based optimization finds a local minimum [S1].
*   **Precision:** The Monte Carlo estimator introduces noise [S1].
*   **Boundaries:** Sampling coordinates must be clamped to the image domain to prevent out-of-bounds access [G].

## Operating characteristics
*   **Time Complexity:** The forward pass involves Monte Carlo sampling for each LOR and TOF bin [G]. Complexity is proportional to $M \times n \times m$, where $M$ is the number of LORs, $n$ is the number of TOF bins, and $m$ is the number of samples per bin [G]. The backward pass requires similar complexity for gradient accumulation [G].
*   **Memory Complexity:** Requires storing the 3D emission image $\mathbf{I}$ and the sinogram $\mathbf{M}$ [G]. Intermediate gradients also require memory proportional to the image size [G].
*   **Measured Performance:** In tests with a simulated hot-spot phantom, the IR model achieved clear separation for hot-spots with a minimum diameter of 0.7 mm, whereas MLEM only demonstrated optimal separation for 0.8 mm [S1]. The IR model also showed higher pixel intensity accuracy in gray matter and nearly no intensity in white matter compared to MLEM [S1].
*   **Strengths:** Higher resolution than MLEM; outperforms DNN-based methods in some metrics; physically grounded differentiable model [S1].
*   **Limitations:** Computationally expensive due to Monte Carlo sampling and iterative optimization; solution is ambiguous without regularization; sensitive to initialization [S1].
*   **When to Use:** High-resolution PET reconstruction where physical accuracy is prioritized over speed [S1].
*   **When Not to Use:** Real-time applications requiring fast reconstruction [G].

## Background
Inverse Rendering for PET was introduced by W. Jakob, B. Nicolet, Y. Li, Z. Wang, W. Tan, and Amirhossein Goldan [S1]. The work leverages Physically-Based Differentiable Rendering (PBDR) techniques, which have been used to differentiate image formation processes with respect to millions of parameters [S1]. This approach is similar to training a neural network but uses physical simulation instead of a learned model [S1]. The method aims to outperform Maximum Likelihood Expectation Maximization (MLEM) and Deep Neural Networks (DNNs) in PET image reconstruction [S1].
