# CodEx

Also called: CodEx Reconstruction Parameters, CodEx partial update settings, Coded Exposure Tomography, Joint Temporal De-blurring and Tomographic Reconstruction

## Overview
CodEx is a modular framework for joint temporal de-blurring and tomographic reconstruction that inverts motion blur introduced in sparse-view fly-scanning by encoding acquisition with a known binary code and using a non-convex Bayesian reconstruction algorithm [S1]. It differs from linear deconvolution methods by handling sparse view sampling without aliasing issues, and differs from previous iterative methods like DynTomo by not requiring dense view samples [S1].

## How it works
**Inputs and Outputs:**
- **Input:** Coded projection measurements $\bar{y}$ (vector of photon counts), the binary code $c$, the blur angle $\Delta \theta$, the number of micro-projections $K$, and the system geometry defining the forward projection operator $A$.
- **Output:** Reconstructed image $x$.

**Data Structures:**
- **Binary Code $c$:** A vector $[c_0, c_1, \dots, c_{K-1}]$ where $c_k \in \{0, 1\}$.
- **Coded Sum Matrix $C$:** A sparse matrix $C \in \mathbb{R}^{M_\theta M_d \times N_\theta M_d}$ that performs the coded sum. Each row sums to 1.
- **Forward Projection Operator $A$:** $A \in \mathbb{R}^{N_\theta M_d \times N}$, where $N_\theta$ is the number of unique micro-projection angles, $M_d$ is the number of detector pixels, and $N$ is the number of image voxels.
- **Photon Flux $\lambda_0$:** Scalar representing the photon-flux per unit rotation angle.

**Formulas:**
The expected photon counts for a standard boxcar exposure (no coding) at angle $\theta_0$ are:
$$ \bar{\Lambda}_{boxcar} = \Lambda_0 \int_{\theta_0}^{\theta_0 + \Delta \theta} \exp \{-A_\theta x\} d\theta $$
where $A_\theta \in \mathbb{R}^{M_d \times N}$ is the forward projection operator at angle $\theta$ [S1].

Discrete approximation over $K$ micro-projection angles:
$$ \bar{\lambda}_{boxcar} = \lambda_0 \sum_{k=0}^{K-1} \exp \left\{ -A_{\theta_0 + k\frac{\Delta \theta}{K}} x \right\} $$
where $K$ is the number of closely spaced angles (micro-projections) [S1].

Expected photon counts with coded exposure:
$$ \bar{\lambda}_{\theta_0} = \lambda_0 \sum_{k=0}^{K-1} c_k \exp \left\{ -A_{\theta_0 + k\frac{\Delta \theta}{K}} x \right\} $$
where $c = [c_0, c_1, \dots, c_{K-1}]$ is the binary code [S1].

Vectorized coded measurement model for all $M_\theta$ angles:
$$ \bar{\lambda} = \bar{c} \lambda_0 C \exp \{-Ax\} $$
where $\bar{\lambda} \in \mathbb{R}^{M_\theta M_d}$ is the vector of expected photon counts, $\bar{c} = \sum_{k=0}^{K-1} c_k$ is the normalizing constant, and $C$ is normalized such that each row sums to 1 [S1].

**Parameters:**
- $K$: Number of micro-projection angles used to discretize the blur integration range $\Delta \theta$.
- $\Delta \theta$: The blur-angle, representing the range of projection angles over which the detector integrates photons during a single view acquisition.
- $c$: The binary code vector.
- Partial update iterations: $n_p = 5$ iterations for computing the deblurring step $\tilde{F}_d$, and $n_t = 5$ iterations for computing the reconstruction step $\tilde{F}_t$ [S1].

**Algorithm Steps:**
The reconstruction uses the Alternating Direction Method of Multipliers (ADMM) to split the inverse problem into iterative deblurring and reconstruction sub-problems [S1].

1. **Initialization:** Initialize the image estimate $x$, auxiliary variables $z$ (for deblurring), and Lagrange multipliers $u$.
2. **Iterate until convergence:**
   a. **Deblurring Step ($\tilde{F}_d$):** Update $z$ by solving a non-linear deblurring problem that inverts the coded exposure model. This step uses $n_p = 5$ partial updates [S1].
   b. **Reconstruction Step ($\tilde{F}_t$):** Update $x$ by solving a Model Based Iterative Reconstruction (MBIR) problem using the updated $z$. This step uses $n_t = 5$ partial updates [S1].
   c. **Multiplier Update:** Update the Lagrange multipliers $u$ based on the difference between $x$ and $z$.

**Pseudocode:**
```python
def codex_reconstruction(y, c, lambda_0, C, A, K, n_p=5, n_t=5, max_iter=100):
    """
    y: observed photon counts (vector)
    c: binary code vector [c_0, ..., c_{K-1}]
    lambda_0: photon flux per unit angle
    C: coded sum sparse matrix
    A: forward projection operator
    K: number of micro-projections
    n_p: partial updates for deblurring
    n_t: partial updates for reconstruction
    """
    # Initialize variables
    x = zeros(N) # Image estimate
    z = zeros(M_theta * M_d) # Auxiliary variable for deblurring
    u = zeros(M_theta * M_d) # Lagrange multipliers
    
    # Precompute normalizing constant
    c_bar = sum(c)
    
    for iter in range(max_iter):
        # Step 1: Deblurring Update (F_tilde_d)
        # Solve for z given x and u. This involves inverting the coded blur.
        # The sources specify n_p partial updates for this step.
        # The deblurring problem is non-linear due to the Poisson statistics and coded model.
        # We approximate the inverse of the coded blur operator.
        
        # Initialize z for partial updates
        z_current = z
        
        for p in range(n_p):
            # Compute expected measurements for current x
            # exp(-Ax) is the transmission
            transmission = exp(-A @ x)
            
            # Apply coded sum matrix C
            # C performs the coded sum over micro-projections
            coded_transmission = C @ transmission
            
            # Expected counts
            lambda_expected = c_bar * lambda_0 * coded_transmission
            
            # Update z using a gradient-like step or proximal operator
            # The specific non-linear deblurring operation is not detailed in the sources
            # but is implied to be part of the ADMM split.
            # [G] Standard ADMM deblurring step often involves solving:
            # min_z ||y - lambda_expected||^2 + rho/2 ||z - x + u||^2
            # However, the non-linear nature requires iterative sub-steps.
            # We assume a simplified gradient descent for the deblurring part
            # for the purpose of this implementation sketch.
            residual = y - lambda_expected
            # Update z based on residual and coupling with x
            z_current = z_current + alpha * (residual + u) # alpha is a step size
            
        z = z_current

        # Step 2: Reconstruction Update (F_tilde_t)
        # Solve for x given z and u. This is an MBIR step.
        # The sources specify n_t partial updates for this step.
        
        x_current = x
        
        for t in range(n_t):
            # MBIR typically minimizes a data fidelity term plus a regularizer
            # Data fidelity: ||z - A @ x||^2 (assuming linearized model for this step)
            # Regularizer: e.g., Total Variation (TV) or similar prior
            # [G] Standard MBIR update involves solving a convex optimization problem.
            # We use a simplified gradient step for the data fidelity part.
            residual_recon = z - A @ x_current
            # Update x
            x_current = x_current + beta * (A.T @ residual_recon) # beta is a step size
            
            # Apply regularizer proximal operator (e.g., TV denoising)
            # [G] Assuming a generic denoising function denoise(x)
            x_current = denoise(x_current)
            
        x = x_current

        # Step 3: Multiplier Update
        u = u + (x - z)
        
    return x
```

**Edge Cases and Pitfalls:**
- Linear deconvolution as a preprocessing step fails for sparse view sampling because it cannot fully correct the aliasing introduced by sparse sampling [S1].
- Fast-rotation fly-scanning causes each view to be acquired over a significant blur angle, leading to blurry reconstructions if conventional reconstruction methods are used [S1].
- Modulating the photon flux results in loss of photons compared to the boxcar case, but many more photons are collected relative to the step-and-shoot case [S1].

## Operating characteristics
- **Time Complexity:** The method uses ADMM with partial updates ($n_p=5, n_t=5$) per iteration, making it practical to implement compared to full iterative solutions [S1].
- **Memory Complexity:** Depends on the size of the sparse matrix $C$ and the forward projection operator $A$.
- **Performance:** CodEx produces sharp reconstructions even with large blur angles (e.g., $40.17^\circ$) where MBIR produces blurry images [S1]. It outperforms MBIR on coded exposures by jointly solving for deblurring and reconstruction [S1].
- **Strengths:** Handles sparse view sampling without aliasing; modular framework; effective for fast-rotation fly-scanning.
- **Limitations:** Requires a known binary code for acquisition; non-linear reconstruction is computationally intensive compared to linear methods.
- **When to use:** When using fast-rotation fly-scanning with sparse views and motion blur is a significant issue.
- **When not to use:** When dense view sampling is available and linear deconvolution is sufficient, or when the acquisition system cannot modulate the X-ray flux with a known code.

## Background
CodEx was introduced in a paper by the authors of [S1] in 2021. It addresses the problem of motion blur in sparse-view fly-scanning CT. Previous methods like linear deconvolution [S1] or iterative methods like Cant et al. [S1] and Ching et al. [S1] required dense view sampling. CodEx combines a novel coded exposure acquisition method with a non-convex Bayesian reconstruction algorithm using ADMM. It has been demonstrated on simulated and binned experimental data [S1].
