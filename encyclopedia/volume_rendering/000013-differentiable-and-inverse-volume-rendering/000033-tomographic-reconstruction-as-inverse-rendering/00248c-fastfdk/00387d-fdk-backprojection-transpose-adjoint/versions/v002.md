# FDK Backprojection Transpose (Adjoint)

Also called: FDK Backprojection Transpose CUDA Kernel

## Overview
The FDK Backprojection Transpose computes the adjoint of the forward FDK backprojection, scattering voxel values from a 3D volume back to 2D projection panels using the same geometric mapping and weights [S1, unofficial]. It accumulates scattered values into projection buffers using `atomicAdd` [S1, unofficial].

## How it works
**Inputs:**
- `volume`: 3D tensor of shape `[batch, 1, depth, height, width]` containing voxel values.
- `matrices`: 4D tensor of shape `[batch, views, 12]` containing camera extrinsics (source and detector positions/orientations).
- `projection_shape`: Tuple `(views, rows, columns)` defining the output projection grid dimensions.
- `box`: Bounding box of the volume (used for ray clipping).

**Outputs:**
- `out`: 4D tensor of shape `[batch, 1, views, rows, columns]` initialized to zero, accumulating the scattered values.

**Data Structures:**
- `ViewColumn`: Struct containing precomputed geometric weights and ray parameters for a specific view.
- `Stencil`: Struct containing 4 indices and 4 weights for bilinear interpolation onto the projection panel.
- `ConeRay`: Struct containing ray origin, direction, and weight.

**Parameters:**
- `TT_FDK_DEPTH`: 4 (number of voxels processed per thread along the z-axis).
- `C`: Channel count (typically 1 for grayscale).

**Algorithm Steps:**

1.  **Initialization**:
    - Extract dimensions: `batch`, `depth`, `height`, `width` from `volume.shape`; `views`, `rows`, `columns` from `projection_shape` [S1, unofficial].
    - Detach and convert `matrices` to contiguous float32 [S1, unofficial].
    - Create zero-initialized output tensor `out` of shape `[batch, 1, views, rows, columns]` [S1, unofficial].
    - Get kernel function `"fdk_backproject_transpose_c1"` [S1, unofficial].

2.  **Kernel Launch**:
    - Iterate over each item in batch [S1, unofficial].
    - Execute kernel with grid `_volume_grid((depth, height, width))`, block `_VOLUME_BLOCK`, and arguments `[volume[item, 0].contiguous(), matrices, out[item, 0], width, height, depth, views, rows, columns]` [S1, unofficial].

3.  **Kernel Execution (Per Thread)**:
    - Each thread handles a block of voxels along the z-axis: `z0 = blockIdx.z * TT_FDK_DEPTH` [G].
    - Thread indices `(x, y)` map to volume coordinates [G].
    - Load `TT_FDK_DEPTH` voxel values from `volume` at `(x, y, z0...z0+3)` [S1, unofficial].
    - If all loaded values are zero, skip the view loop [S1, unofficial].

4.  **Scatter Loop (Per View)**:
    - For each view `v` from `0` to `views-1`:
        - Compute `ViewColumn` parameters from `matrices` [S1, unofficial].
        - For each of the `TT_FDK_DEPTH` voxels (index `j`):
            - If `value[j] == 0`, continue.
            - Compute detector coordinates and inverse distance scale from the `ConeRay` and voxel position [G].
            - For each of the 4 stencil points (bilinear interpolation corners on the detector):
                - If `s.weight[q] != 0`:
                    - Perform `atomicAdd(out[s.index[q]], s.weight[q] * value[j])` [S1, unofficial].

**Pseudocode:**

```python
import math

def fdk_backproject_transpose(volume, matrices, projection_shape, box):
    B, _, D, H, W = volume.shape
    V, R, C = projection_shape
    # Initialize 5D output tensor [batch, 1, views, rows, columns]
    out = [[[[[0.0] * C for _ in range(R)] for _ in range(V)] for _ in range(1)] for _ in range(B)]
    # Detach and convert matrices to contiguous float32
    mats = [m.detach().float().contiguous() if hasattr(m, 'detach') else m for m in matrices]
    # Kernel launch logic omitted; see steps 2-3
    return out

def panel_stencil(column, row, columns, rows, inverse):
    """Computes bilinear interpolation stencil indices and weights."""
    if not (-1 < column < columns and -1 < row < rows):
        return False, None
    column_floor = math.floor(column)
    row_floor = math.floor(row)
    c0 = int(column_floor)
    r0 = int(row_floor)
    dc = column - column_floor
    dr = row - row_floor
    scale = inverse * inverse
    wc0 = 1.0 - dc if c0 >= 0 else 0.0
    wc1 = dc if c0 + 1 < columns else 0.0
    wr0 = (1.0 - dr) * scale if r0 >= 0 else 0.0
    wr1 = dr * scale if r0 + 1 < rows else 0.0
    left = max(c0, 0)
    right = min(c0 + 1, columns - 1)
    top = max(r0, 0) * columns
    bottom = min(r0 + 1, rows - 1) * columns
    indices = [top + left, top + right, bottom + left, bottom + right]
    weights = [wr0 * wc0, wr0 * wc1, wr1 * wc0, wr1 * wc1]
    return True, (indices, weights)

def thread_kernel_logic(x, y, z0, volume, mats, out, W, H, D, V, R, C, box):
    TT_FDK_DEPTH = 4
    values = []
    for k in range(TT_FDK_DEPTH):
        z = z0 + k
        values.append(volume[x][y][z] if z < D else 0.0)
    if all(v == 0.0 for v in values):
        return
    for view in range(V):
        # Compute ViewColumn v from mats[view]
        # Compute ConeRay from source/detector positions and box
        for j in range(TT_FDK_DEPTH):
            if values[j] == 0.0:
                continue
            # Compute detector coordinates (column, row) and inverse distance scale
            # from ConeRay and voxel position (x, y, z0+j) [G]
            column, row, inverse = compute_detector_coords(ray, x, y, z0 + j, box)
            valid, stencil = panel_stencil(column, row, C, R, inverse)
            if valid:
                indices, weights = stencil
                for q in range(4):
                    if weights[q] != 0.0:
                        out[0][0][view][int(indices[q] // C)][int(indices[q] % C)] += weights[q] * values[j]
```

**Edge Cases and Pitfalls:**
- **Atomic Contention**: Multiple threads may write to the same projection pixel simultaneously, requiring `atomicAdd` [S1, unofficial].
- **Numerical Precision**: `float32` addition is not associative, so the order of accumulation matters for numerical consistency with the forward pass [S1, unofficial].
- **Boundary Conditions**: Stencil weights are clamped to zero if the interpolated coordinate falls outside the detector bounds `[0, rows) x [0, columns)` [S1, unofficial].
- **Zero Voxel Skip**: If all `TT_FDK_DEPTH` voxels loaded by a thread are zero, the view loop is skipped to save computation [S1, unofficial].

## Operating characteristics
- **Time Complexity**: Not given in the sources.
- **Memory Complexity**: $O(B \cdot V \cdot R \cdot C)$ for the output buffer [S1, unofficial].
- **Performance**: Limited by atomic contention on high-resolution projections or large batch sizes [S1, unofficial].
- **Strengths**: Efficiently computes the adjoint for differentiable tomography [S1, unofficial].
- **Limitations**: Atomic contention reduces throughput; non-associative floating-point addition may cause precision drift [S1, unofficial].

## Background
The FDK Backprojection Transpose is part of the `torchtomo` library by itu-biai, implementing the adjoint of the FDK (Feldkamp-Davis-Kress) projection operator for differentiable tomographic reconstruction [S1, unofficial]. It was developed to support end-to-end differentiable pipelines in medical imaging and materials science [S1, unofficial].
