# Voxel Coloring

Also called: Photorealistic Scene Reconstruction by Voxel Coloring, Voxel Colouring Reconstruction, Voxel-based 3D reconstruction

## Overview
Voxel Coloring is a volumetric reconstruction technique that computes photo-realistic 3D models from multiple color images by assigning colors (radiances) to voxels in a 3D volume, guaranteeing consistency with the input images [S1]. It distinguishes itself from sibling methods like [Voxel Carving](1213-voxel-carving.md) by using a "coloring" approach: it starts with an opaque volume and carves away voxels that fail a color consistency test, rather than starting with an empty volume and filling it [S2, unofficial]. Unlike [Generalized Voxel Coloring](5526-generalized-voxel-coloring.md), standard Voxel Coloring relies on an ordinal visibility constraint to simplify visibility checks, allowing for a single-scan reconstruction [S2, unofficial].

## How it works
**Inputs:**
- A set of $N$ color images $V_0, \dots, V_n$ [S1].
- Camera parameters for each image: position, focal angles (vertical and horizontal) [S1].
- Depth information accompanying each pixel (or a method to compute it, such as modified ray casting) [S1].
- A 3D grid defining the reconstruction volume, with initial voxel alpha values set to 0 (transparent) [S1].

**Outputs:**
- A 3D volume model where voxels have assigned color (RGB) and alpha (opacity) values, representing the reconstructed scene [S1].

**Data Structures:**
- **Voxel Grid:** A 3D array of voxels. Each voxel stores:
  - Color: 3 components (Red, Green, Blue) [S1].
  - Alpha: 1 component (transparency), typically 8-bit (0-255) [S1].
  - Initial state: All voxels are transparent (alpha=0) for the "coloring" variant [S1], or opaque for the "carving" variant [S2, unofficial]. *Note: The sources describe two variations. The "coloring" description [S1] starts transparent and fills. The "carving" description [S2, unofficial] starts opaque and removes. Standard Voxel Coloring is often described as carving [S2, unofficial], but the provided source [S1] describes a filling process. We present the filling process as described in [S1] as the primary method, noting the carving alternative in [S2, unofficial].*

**Parameters:**
- `thresh`: The maximum allowable correlation error threshold for color consistency [S1].
  - Low value: Precise but incomplete reconstruction [S1].
  - High value: Complete reconstruction with potential false voxels [S1].

**Steps:**

1.  **Initialize Grid:** Construct a 3D grid of transparent voxels (alpha = 0) [S1]. *Alternatively, if following the carving approach [S2, unofficial], initialize all voxels as opaque.*

2.  **Compute Transformation Matrix:** For each camera, compute the change of scale matrix $M$ between object space and camera space [S1]:
    $$ M = R_X \times R_Y \times T $$
    Where:
    - $R_X$ and $R_Y$ are rotation matrices that bring the vision vector to the OZ axis [S1].
    - $T$ is the translation matrix that brings the camera to the center of the scene [S1].

3.  **Project and Color:** For each pixel in each input image:
    a.  Determine the ray direction $D$ (normalized) and origin $O$ based on camera parameters [S1].
    b.  Use the depth information $\lambda$ accompanying the pixel to compute the 3D position $P$ of the point in space:
        $$ P = O + \lambda \times D $$
        Where $\lambda$ is the depth of the point [S1].
    c.  Map the 3D position $P$ to the corresponding voxel index in the grid [S1].
    d.  Assign the pixel's color to the found voxel [S1].
    e.  Set the voxel's alpha value to 255 (opaque) [S1].
    f.  Mark the pixel in the image to indicate it has been processed [S1].

4.  **Consistency Check (Carving Variant):** If using the carving approach [S2, unofficial]:
    a.  Traverse voxels in a monotonic order (near-to-far relative to each camera) to ensure correct visibility handling [S2, unofficial].
    b.  Test each opaque voxel for color consistency across all input images [S2, unofficial].
    c.  If a voxel is inconsistent, carve it (set alpha to 0) [S2, unofficial].
    d.  Repeat until all remaining opaque voxels are color consistent [S2, unofficial].

5.  **Termination:** The process stops when all voxels have been processed (coloring variant) or when all remaining opaque voxels are color consistent (carving variant) [S1][S2, unofficial].

**Edge Cases and Pitfalls:**
- **Ordinal Visibility Constraint:** Cameras must be arranged such that voxels can be visited in a single near-to-far scan relative to every camera. This prevents cameras from surrounding the scene, meaning surfaces not visible in any image cannot be reconstructed [S2, unofficial].
- **Threshold Selection:** A low `thresh` yields precise but incomplete reconstruction; a high `thresh` yields complete reconstruction with potential false voxels [S1].
- **Depth Information:** The method requires depth information accompanying each pixel. If not available, it must be computed, e.g., using modified ray casting [S1].

## Subtopics

### [Generalized Voxel Coloring](5526-generalized-voxel-coloring.md)
Generalized Voxel Coloring (GVC) is a voxel-based 3D reconstruction technique that computes photo-realistic volume models from multiple color images by assigning colors (radiances) to voxels while guaranteeing consistency with a set of base images. It improves upon standard Voxel Coloring by computing visibility exactly, rather than approximately, to obtain a color-consistent model. GVC is distinguished from its parent [Voxel Coloring](4418-voxel-coloring.md) by its explicit handling of visibility via Item Buffers (IB) or Layered Depth Images (LDI), and from [Multi-view Color Consistency and Smoothing](6445-multi-view-color-consistency-and-smoothing.md) by its foundational use of exact geometric visibility checks for voxel coloring.

### [Multi-view Color Consistency and Smoothing](6445-multi-view-color-consistency-and-smoothing.md)
Multi-view Color Consistency and Smoothing is a post-processing method for assigning colors to voxels in a fine volumetric reconstruction, designed to compensate for noise arising from camera calibration, imaging artifacts, imperfect light balance, and volume quantization. It distinguishes itself from basic voxel coloring by explicitly handling non-Lambertian reflectance and preventing visual blurring through a "blur group" mechanism that preserves sharp edges. It builds on [Voxel Coloring](4418-voxel-coloring.md) by refining the color attributes of already-identified surface voxels.

- **Strengths:**
  - Produces photo-realistic volume models [S1].
  - Guarantees consistency with input images [S1].
  - Simple visibility handling due to ordinal constraint (standard VC) [S2, unofficial].
- **Limitations:**
  - Requires depth information for each pixel [S1].
  - Ordinal visibility constraint limits camera placement; cameras cannot surround the scene [S2, unofficial].
  - Surfaces not visible in any image cannot be reconstructed [S2, unofficial].
  - Threshold selection affects completeness vs. precision [S1].
- **When to use:** When a photo-realistic volume model is needed from multiple color images with known depth information, and camera placement allows for an ordinal visibility constraint [S1][S2, unofficial].
- **When not to use:** When cameras surround the scene or when depth information is not available [S1][S2, unofficial].

## Background
Voxel Coloring was introduced by Seitz and Dyer in 1997 in the paper "Photorealistic Scene Reconstruction by Voxel Coloring" [S1]. It is a voxel-based 3D reconstruction technique that computes photo-realistic volume models from multiple color images by assigning colors (radiances) to voxels in a 3D volume, guaranteeing consistency with the input images [S1]. The method was developed to address the challenge of reconstructing 3D scenes from 2D images while preserving photorealistic appearance [S1].
