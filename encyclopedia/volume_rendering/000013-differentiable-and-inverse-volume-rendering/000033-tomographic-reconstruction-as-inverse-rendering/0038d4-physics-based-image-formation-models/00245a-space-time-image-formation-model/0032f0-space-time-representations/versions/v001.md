# Space-time representations

Also called: Space-time neural representations, Time-conditioned implicit representations

## Overview
Space-time representations model dynamic scenes by extending the query space of the rendering function to include time as a direct input, omitting the explicit deformation network used in warp-based methods [S1]. Unlike warp-based methods that separate geometry and appearance into a static canonical form and a dynamic transformation, space-time representations use a single unified function to directly regress dynamic properties, making them tolerant of topology changes but prone to time inconsistency [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A query tuple $q = (p, \mathbf{d}, t)$, where $p \in \mathbb{R}^3$ is the spatial position, $\mathbf{d}$ is the viewing direction, and $t$ is the time coordinate.
*   **Output:** A property vector $\xi$ (e.g., color, density, or feature vector).

**Data Structures:**
The representation is typically implemented as a neural network (MLP) or an explicit feature grid.
1.  **Neural Implicit Model:** An MLP with weights $\theta$ that takes an encoded query as input.
2.  **Feature Grid:** A set of 3D feature grids indexed by spatial coordinates and discrete time slots.

**Numbered Steps:**
1.  **Discretize Time:** Divide the continuous time interval into $N$ equally spaced time slots $t_1, t_2, \dots, t_N$ [S1].
2.  **Encode Query:** Apply an encoding function $\gamma$ or $\text{enc}$ to the position $p$, direction $\mathbf{d}$, and time $t$.
    *   *Approach A (Time-conditioned Network):* The encoding $\gamma$ includes time directly: $\gamma(p, \mathbf{d}, t)$ [S1].
    *   *Approach B (Time-conditioned Encoding):* The encoding function $\text{enc}$ depends on time, while the main network $f$ does not: $\text{enc}(p, t)$ [S1].
3.  **Compute Features:**
    *   If using an MLP-based approach, compute features at the discrete time slots. For a query time $t$ that falls between slots $t_i$ and $t_{i+1}$, interpolate the features or network parameters from these neighboring slots [S1].
    *   If using an explicit feature grid, store features for each spatial voxel at each time slot. Retrieve features for $p$ at time $t$ by interpolating between the grids at $t_i$ and $t_{i+1}$ [S1].
4.  **Regres Property:** Pass the encoded query through the network $f$ to output $\xi$.
    *   For Approach A: $\xi = f_{\theta}(\gamma(p, \mathbf{d}, t))$ [S1].
    *   For Approach B: $\xi = f(\text{enc}(p, t), [\text{enc}(\mathbf{d})])$ [S1].
5.  **Enforce Time Consistency (Optional):** To mitigate time inconsistency, use flow fields to define forward and backward mappings between neighboring time steps when available [S1].

**Formulas:**
The primary formulation extends the query space:
$$f_{\theta} : (\gamma(p, \mathbf{d}, t)) \rightarrow \xi \quad (12)$$
where $p$ is position, $\mathbf{d}$ is direction, $t$ is time, $\gamma$ is an encoding function, and $\xi$ is the output property [S1].

Alternatively, the encoding function incorporates time:
$$f : (\text{enc}(p, t), [\text{enc}(\mathbf{d})]) \rightarrow \xi \quad (13)$$
where $\text{enc}$ is a function of time, rather than the main function $f$ [S1].

**Parameters:**
*   **Time Slots:** Equally spaced intervals used to discretize the time domain for feature computation [S1]. The number of slots affects the trade-off between temporal resolution and computational cost.

**Pitfalls:**
*   **Time Inconsistency:** Due to the flexibility of the representation, the model may produce temporally inconsistent results, especially if the number of observations is limited [S1].
*   **Interpolation Artifacts:** Interpolating between discrete time slots can introduce artifacts if the motion is non-linear or if the time slots are too sparse [S1].

## Subtopics

### [Warp-based Dynamic Scene Representation](6886-warp-based-dynamic-scene-representation.md)
Warp-based dynamic scene representations model temporal changes by learning a temporally global 3D canonical representation and a learnable, time-dependent deformation field that warps canonical space to match observed scenes at each timestep. Unlike [Space-time representations](6885-space-time-representations.md), which extend the query space to include time directly, warp-based methods explicitly separate geometry and appearance into a static canonical form and a dynamic transformation, ensuring long-term correspondence and smooth temporal interpolation.

## Operating characteristics
*   **Time Complexity:** Depends on the encoding function and network depth. Using discrete time slots and interpolation can decrease computational burden compared to fully continuous time modeling [S1].
*   **Memory Complexity:** Can be high if storing explicit feature grids for each time slot. Neural implicit models require storing network weights, which are generally smaller than large feature grids but may require more compute per query [S1].
*   **Strengths:** Tolerant of topology changes; can model a wider range of motion than warp-based methods; simpler implementation by omitting the deformation network [S1].
*   **Limitations:** Prone to time inconsistency; performance depends on the number of observations; may struggle with complex topological changes if not regularized [S1].
*   **When to Use:** When the scene undergoes significant topological changes or when a simpler, unified representation is preferred over explicit deformation fields [S1].
*   **When Not to Use:** When long-term temporal consistency is critical and the scene has a stable topology, in which case warp-based methods may be superior [S1].

## Background
Space-time representations emerged as an alternative to warp-based methods in learning-based 3D representations, aiming to simplify the modeling of dynamic scenes by directly conditioning 3D representations with a time component [S1]. Early works included neural implicit models conditioned on time [GSKH21, LNSW21, XHKK21] and sets of 3D Gaussians with time-dependent parameters [LKLR24]. The approach gained traction for its ability to handle topology changes, though it required techniques like flow fields to enforce time consistency [S1].
