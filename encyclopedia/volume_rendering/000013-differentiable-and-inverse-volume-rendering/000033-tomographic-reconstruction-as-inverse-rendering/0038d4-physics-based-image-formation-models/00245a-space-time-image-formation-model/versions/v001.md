# Space-Time Image Formation Model
Also called: 4D density function model

## Overview
The Space-Time Image Formation Model represents a continuously deforming 3D object as a 4D density function $h(x, y, z, t)$, discretized into a sequence of static frames to enable tomographic reconstruction [S1, unofficial]. It differs from warp-based dynamic representations by treating temporal changes as distinct volumetric states rather than explicit deformations, allowing reconstruction from unique projection angles where each frame is solved independently yet jointly within a block-diagonal system [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A set of $N_p$ projection images (sinogram data) captured at unique angles over time.
*   **Output:** A 4D density volume represented as a vector $\mathbf{f} \in \mathbb{R}^{N_v N_k}$, containing $N_k$ reconstructed 3D frames.

**Data Structures**
The 4D density volume is flattened into a column vector $\mathbf{f}$ composed of sub-vectors for each time step:
$$ \mathbf{f} = \{\mathbf{f}_0, \mathbf{f}_1, \dots, \mathbf{f}_{N_k-1}\} $$
where $\mathbf{f}_t \in \mathbb{R}^{N_v}$ is the vector of voxel values for the $t$-th frame, and $N_v$ is the number of voxels per frame [S1, unofficial].

The measurement vector $\mathbf{p}$ contains all sinogram data:
$$ \mathbf{p} = \{\mathbf{p}_0, \mathbf{p}_1, \dots, \mathbf{p}_{N_k-1}\} $$
where $\mathbf{p}_t \in \mathbb{R}^{N_\theta M}$ is the vector of measured projections for frame $t$, $M$ is the number of pixels per projection, and $N_\theta$ is the number of projections contributing to frame $t$ [S1, unofficial].

**Algorithm**
1.  **Discretization:** Define the number of reconstructed frames $N_k$ such that $N_k \le N_p$. The number of projections per frame is typically set to $N_\theta = N_p / N_k$ [S1, unofficial].
2.  **Forward Operator Construction:** Construct the system matrix $\mathbf{A}$. This is a block-diagonal matrix where each diagonal block $\mathbf{A}_t \in \mathbb{R}^{N_\theta M \times N_v}$ models the Radon transform for the $N_\theta$ projections contributing to frame $t$. Off-diagonal blocks are zero, assuming no temporal overlap in the basic model [S1, unofficial].
3.  **Linear System Formulation:** Express the tomography problem as the linear system:
    $$ \mathbf{A} \cdot \mathbf{f} = \mathbf{p} $$
    Explicitly:
    $$ \begin{pmatrix} \mathbf{A}_1 & & & \\ & \ddots & & \\ & & \mathbf{A}_t & \\ & & & \ddots \\ & & & & \mathbf{A}_{N_k} \end{pmatrix} \cdot \begin{pmatrix} \mathbf{f}_1 \\ \vdots \\ \mathbf{f}_t \\ \vdots \\ \mathbf{f}_{N_k} \end{pmatrix} = \begin{pmatrix} \mathbf{p}_1 \\ \vdots \\ \mathbf{p}_t \\ \vdots \\ \mathbf{p}_{N_k} \end{pmatrix} $$
4.  **Optimization:** Solve for $\mathbf{f}$ by minimizing the loss between the measured sinogram $\mathbf{p}$ and the rendered projection $\hat{\mathbf{p}} = \mathbf{A}\mathbf{f}$, typically using an iterative solver suitable for ill-posed inverse problems (e.g., SIRT or regularized least squares) [S1, unofficial].

**Parameters**
*   $N_k$: Number of reconstructed frames. Constraint: $N_k \le N_p$ [S1, unofficial].
*   $N_\theta$: Number of projections per frame. Typical value: $N_\theta = N_p / N_k$. Larger values are possible if projections contribute to multiple frames [S1, unofficial].
*   $M$: Number of pixels in a single projection image [S1, unofficial].
*   $N_v$: Number of voxels in a single 3D frame [S1, unofficial].

**Edge Cases**
*   **Ill-posedness:** With few projections per frame ($N_\theta$ small), the problem is ill-posed. Regularization is required [S1, unofficial].
*   **Deformation Magnitude:** The sampling strategy is decoupled from the magnitude of deformation; $N_k$ can be chosen post-capture [S1, unofficial].

## Operating characteristics
*   **Complexity:** The block-diagonal structure allows independent processing of frames if decoupled, but the joint optimization couples them via the global solver. Memory scales with $N_k \times N_v$.
*   **Strengths:** Independent of deformation magnitude; unique angles provide extra information even for stationary geometry [S1, unofficial].
*   **Limitations:** Assumes each frame is approximately static; ill-posed with few projections [S1, unofficial].

## Background
Originated in the work of Zang (2020) for space-time tomographic reconstruction of deforming objects [S1, unofficial].
