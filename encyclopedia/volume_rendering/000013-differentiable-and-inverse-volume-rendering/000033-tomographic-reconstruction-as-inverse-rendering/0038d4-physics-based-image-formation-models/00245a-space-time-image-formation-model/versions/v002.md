# Space-Time Image Formation Model

Also called: 4D density function model

## Overview
The Space-Time Image Formation Model represents a continuously deforming 3D object as a 4D density function $h(x, y, z, t)$, discretized into a sequence of static frames to enable tomographic reconstruction of dynamic scenes [S1, unofficial]. It differs from warp-based methods by treating time as a direct dimension of the density field rather than applying a deformation network to a canonical static geometry, allowing it to handle topology changes but potentially suffering from temporal inconsistency [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N_p$ projection images (sinogram data) captured from unique angles over time.
*   **Output:** A 4D density volume represented as a vector $\mathbf{f} \in \mathbb{R}^{N_v N_k}$, where $N_v$ is the number of voxels per frame and $N_k$ is the number of reconstructed frames.

**Data Structures:**
The 4D density volume is flattened into a column vector $\mathbf{f}$ composed of $N_k$ sub-vectors, each representing the 3D volume at a specific time step:
$$
\mathbf{f} = \{\mathbf{f}_0, \mathbf{f}_1, \dots, \mathbf{f}_{N_k-1}\}
$$
where $\mathbf{f}_t \in \mathbb{R}^{N_v}$ is the vector of voxel values for the $t$-th frame [S1, unofficial].

**Parameters:**
*   $N_k$: Number of reconstructed frames. Constraint: $N_k \le N_p$.
*   $N_\theta$: Number of projections contributing to each frame. Typical value: $N_\theta = N_p / N_k$.
*   $M$: Number of pixels in a single projection image.
*   $N_v$: Number of voxels in the 3D grid for one frame.

**Method Steps:**
1.  **Discretization:** Divide the continuous 4D density function $h(x, y, z, t)$ into $N_k$ discrete time steps. Assume each frame $t$ is approximately static during the acquisition of its associated projections [S1, unofficial].
2.  **Forward Projection Matrix Construction:** Construct the system matrix $\mathbf{A}$. This matrix is block-diagonal, where each block $\mathbf{A}_t$ corresponds to the Radon transform operator for the $N_\theta$ projections contributing to frame $t$. The dimensions of each block are $\mathbf{A}_t \in \mathbb{R}^{N_\theta M \times N_v}$ [S1, unofficial].
3.  **Linear System Formulation:** Express the tomography problem as a linear system:
    $$
    \mathbf{A} \cdot \mathbf{f} = \mathbf{p}
    $$
    where $\mathbf{p}$ is the vector of measured sinogram data, concatenated from all frames:
    $$
    \mathbf{p} = \begin{pmatrix} \mathbf{p}_1 \\ \vdots \\ \mathbf{p}_t \\ \vdots \\ \mathbf{p}_{N_k} \end{pmatrix}, \quad \mathbf{p}_t \in \mathbb{R}^{N_\theta M}
    $$
    [S1, unofficial].
4.  **Optimization:** Solve the ill-posed inverse problem for $\mathbf{f}$ using a joint optimization framework (e.g., minimizing a loss function between the projected $\mathbf{A}\mathbf{f}$ and measured $\mathbf{p}$, potentially with regularization) [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Ill-posedness:** The problem is ill-posed, especially when few projections are used per frame ($N_\theta$ is small). Regularization is required [S1, unofficial].
*   **Static Assumption:** The model assumes each frame is approximately static. Significant deformation within the acquisition window of a single frame's $N_\theta$ projections violates this assumption and degrades quality [S1, unofficial].
*   **Sampling Strategy:** The sampling strategy is decoupled from the magnitude of deformation. The number of frames $N_k$ can be chosen post-capture, independent of the number of rounds [S1, unofficial].

## Subtopics

### [Space-time representations](6885-space-time-representations.md)
Models dynamic scenes by extending the query space to include time as a direct input, omitting explicit deformation networks. Tolerant of topology changes but prone to time inconsistency.

## Operating characteristics
*   **Complexity:** The system matrix $\mathbf{A}$ is block-diagonal with $N_k$ blocks. Solving the system involves inverting or optimizing over a space of size $N_v N_k$.
*   **Strengths:** Allows post-capture choice of temporal resolution ($N_k$). Each additional projection provides unique information, improving quality even for stationary geometry [S1, unofficial].
*   **Limitations:** Assumes static geometry per frame; ill-posed with few projections; potential for temporal inconsistency due to lack of explicit temporal smoothing or deformation constraints [S1, unofficial].

## Background
The model was introduced by Zang in a 2020 thesis, proposing a method for space-time tomographic reconstruction of deforming objects by treating the 4D density as a sequence of static frames [S1, unofficial].
