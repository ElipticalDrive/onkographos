# Direct Voxel Grid Optimization (DVGO)
Also called: DirectVoxGO

## Overview
Direct Voxel Grid Optimization (DVGO) is a volume rendering method that optimizes a voxel grid of density and color features directly, avoiding the need for a separate neural network to predict density from coordinates, thereby enabling faster training and inference compared to NeRF-like methods [S1, unofficial]. It sets itself apart from its siblings by using a dense voxel grid for density and a feature grid plus shallow MLP for view-dependent colors, offering a simpler representation than hierarchical or hash-based approaches while maintaining high quality [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
- Camera poses and intrinsics for a set of training images.
- Training images (RGB).
- Scene bounding box defined by `xyz_min` and `xyz_max`.
- Hyperparameters: `num_voxels`, `num_voxels_base`, `alpha_init`, `mask_cache_thres`, `fast_color_thres`, `density_type`, `k0_type`, `rgbnet_dim`, `rgbnet_direct`, `rgbnet_full_implicit`, `rgbnet_depth`, `rgbnet_width`, `viewbase_pe`, `stepsize`, `weight_distortion`.

**Outputs:**
- Optimized density grid.
- Optimized color feature grid (and MLP weights if `rgbnet_dim > 0`).
- Rendered images and depth maps.

### Initialization Steps
1.  **Initialize Density Bias Shift:**
    Calculate `act_shift` using:
    $$ \text{act\_shift} = \log\left(\frac{1}{1 - \alpha_{\text{init}}} - 1\right) $$
    Store as a buffer [S1, unofficial].
2.  **Initialize Density Grid:**
    Create grid of type `density_type` with 1 channel, world size determined by `num_voxels`, bounds `xyz_min` to `xyz_max` [S1, unofficial].
3.  **Initialize Color Representation:**
    -   If `rgbnet_dim <= 0`: Create color voxel grid `k0` with 3 channels (coarse stage) [S1, unofficial].
    -   If `rgbnet_dim > 0`: Create feature voxel grid `k0` with `rgbnet_dim` channels and an MLP `rgbnet` (fine stage) [S1, unofficial].
4.  **Initialize RGB MLP (if `rgbnet_dim > 0`):**
    -   Calculate input dimension `dim0`:
        $$ \text{dim0} = 3 + 3 \times \text{viewbase\_pe} \times 2 $$
        If `rgbnet_direct` is true:
        $$ \text{dim0} \leftarrow \text{dim0} + \text{k0\_dim} $$
        If `rgbnet_full_implicit` is false:
        $$ \text{dim0} \leftarrow \text{dim0} + (\text{k0\_dim} - 3) $$
    -   Construct MLP with `rgbnet_depth` layers, `rgbnet_width` neurons, ReLU activation.
    -   Last layer outputs 3 values.
    -   Initialize last layer bias to 0 [S1, unofficial].
5.  **Initialize Mask Cache:**
    -   If `mask_cache_path` is provided, load the mask.
    -   Otherwise, create a mask of ones.
    -   The mask is updated based on `mask_cache_thres` and `fast_color_thres` [S1, unofficial].

### Rendering and Optimization Steps
1.  **Activate Density to Alpha:**
    Apply `Raw2Alpha` function to density values. The `interval` parameter is set to `self.voxel_size_ratio` if not provided [S1, unofficial].
    $$ \alpha = 1 - \exp(-\sigma \cdot \delta) $$
    Where $\sigma$ is density and $\delta$ is step size.
2.  **Count Voxel Views:**
    Iterate over rays, sample points along rays within scene bounds, and accumulate gradients to count how many rays pass through each voxel. Rays are split into batches for memory efficiency [S1, unofficial].
3.  **Sample Points on Rays:**
    Use `render_utils_cuda.sample_pts_on_rays` to get ray points, mask out-of-bounds points, and ray IDs [S1, unofficial].
4.  **Hit Coarse Geometry:**
    Check if rays hit the solved coarse geometry by sampling points on rays and checking if they are within the mask cache [S1, unofficial].
5.  **Scale Volume Grid:**
    Resize density and color grids to a new number of voxels. Update mask cache based on new alpha values if new world size is small enough [S1, unofficial].
6.  **Update Occupancy Cache:**
    -   Sample density at grid points.
    -   Activate to alpha.
    -   Apply max pooling operation.
    -   Update mask based on threshold [S1, unofficial].
7.  **Mask Out Near Camera Voxels:**
    Calculate distance from each voxel to camera origin. Set density to -100 if distance < near clip distance [S1, unofficial].
8.  **Total Variation Gradient:**
    Add total variation regularization gradients to density and color grids. Weight scaled by `self.world_size.max() / 128` [S1, unofficial].

import torch.nn.functional as F

def raw2alpha(sigma, dist):
    """Convert density (sigma) and step size (dist) to alpha."""
    alpha = 1.0 - torch.exp(-sigma * dist)
    return alpha

def render_ray(ray_o, ray_d, grid_density, grid_color, mlp_rgb, 
               xyz_min, xyz_max, num_samples, stepsize, 
               rgbnet_dim, rgbnet_direct, rgbnet_full_implicit, 
               viewbase_pe, mask_cache):
    """
    Render a single ray.
    """
    # 1. Sample points on ray
    t_vals = torch.linspace(0, 1, num_samples)
    z_vals = ray_o + ray_d * t_vals * (xyz_max - xyz_min).norm() # Simplified bounding box intersection
    # More precise: intersect ray with bbox xyz_min, xyz_max
    
    # 2. Mask out-of-bounds
    in_bounds = (z_vals >= xyz_min.min()) & (z_vals <= xyz_max.max())
    
    # 3. Sample features from grids
    # Assuming trilinear interpolation or similar from grid_density and grid_color
    # grid_density: (Nx, Ny, Nz)
    # grid_color: (Nx, Ny, Nz, C)
    sampled_density = sample_grid(grid_density, z_vals)
    sampled_color_feat = sample_grid(grid_color, z_vals)
    
    # 4. Activate density
    # Apply bias shift if initialized
    # sigma = sampled_density + act_shift
    alpha = raw2alpha(sampled_density, stepsize)
    
    # 5. Masking
    # Apply mask_cache
    # Mask out near camera
    dist_to_cam = torch.norm(z_vals - ray_o, dim=-1)
    near_mask = dist_to_cam > near_clip
    
    # 6. Volume Rendering
    # T = product(1 - alpha)
    # C = sum(T_prev * alpha * color)
    
    # If rgbnet_dim > 0, use MLP for color
    if rgbnet_dim > 0:
        # Calculate input dim
        dim0 = 3 + 3 * viewbase_pe * 2
        if rgbnet_direct:
            dim0 += rgbnet_dim
        if not rgbnet_full_implicit:
            dim0 += (rgbnet_dim - 3)

        # Concatenate
        mlp_input = torch.cat([view_pe, sampled_color_feat], dim=-1) # Simplified
        rgb = mlp_rgb(mlp_input)
    else:
        rgb = sampled_color_feat # Coarse stage, direct RGB
        
    # Composite
    weights = alpha * torch.cumprod(torch.cat([torch.ones_like(alpha[:, :1]), 1. - alpha[:, :-1] + 1e-10], dim=-1), dim=-1)[:, :-1]
    color = torch.sum(weights.unsqueeze(-1) * rgb, dim=-2)
    
    return color, alpha

def train_step(model, batch, optimizer):
    """
    One training step.
    """
    ray_o, ray_d, gt_rgb = batch['ray_o'], batch['ray_d'], batch['gt_rgb']
    
    # 1. Update mask cache
    model.update_occupancy_cache()
    
    # 2. Render
    pred_rgb, alpha = model.render_ray(ray_o, ray_d)
    
    # 3. Loss
    loss = F.mse_loss(pred_rgb, gt_rgb)
    
    # 4. Regularization
    # Total variation
    tv_loss_density = model.density_total_variation_add_grad()
    tv_loss_color = model.k0_total_variation_add_grad()
    loss += tv_loss_density + tv_loss_color

    loss.backward()

    return loss.item()

### Parameters
-   `num_voxels`: Total number of voxels in the density grid [S1, unofficial].
-   `num_voxels_base`: Number of voxels used to calculate base voxel size for density bias shift [S1, unofficial].
-   `alpha_init`: Initial alpha value for density bias shift. Default None [S1, unofficial].
-   `mask_cache_thres`: Threshold for mask cache to determine occupied space [S1, unofficial].
-   `fast_color_thres`: Threshold for determining if a voxel is occupied based on alpha values for masking [S1, unofficial].
-   `density_type`: Type of grid for density. Default 'DenseGrid' [S1, unofficial].
-   `k0_type`: Type of grid for color feature. Default 'DenseGrid' [S1, unofficial].
-   `rgbnet_dim`: Dimension of color feature vector. If <= 0, coarse stage (3-channel color grid). If > 0, fine stage (feature grid + MLP) [S1, unofficial].
-   `rgbnet_direct`: Whether to pass color features directly to RGB network [S1, unofficial].
-   `rgbnet_full_implicit`: Whether RGB network takes only positional encoding and view direction, ignoring color features [S1, unofficial].
-   `rgbnet_depth`: Depth of RGB MLP [S1, unofficial].
-   `rgbnet_width`: Width of RGB MLP [S1, unofficial].
-   `viewbase_pe`: Number of frequency bands for positional encoding of view direction [S1, unofficial].

### Edge Cases and Pitfalls
-   **Precision:** Floating point precision in density accumulation can affect alpha calculation.
-   **Boundaries:** Out-of-bounds points must be masked correctly to avoid artifacts.
-   **Degenerate Input:** Empty scenes or scenes with no visible geometry may require careful initialization of `alpha_init` and `mask_cache_thres`.
-   **Memory:** Large `num_voxels` can lead to high memory usage. Batching rays is recommended.

## Operating characteristics
-   **Time Complexity:** O(N) for distortion loss calculation [S1, unofficial]. Training speed is faster than NeRF due to voxel grid lookup vs MLP evaluation.
-   **Memory Complexity:** O(V) where V is the number of voxels. Dense grid can be memory intensive for high resolutions.
-   **Performance:** Reported 2-3x speedup with PyTorch CUDA extension [S1, unofficial].
-   **Strengths:** Simple representation, fast training/inference, supports various datasets (bounded, unbounded, forward-facing) [S1, unofficial].
-   **Limitations:** Memory usage scales with grid resolution. May require scaling techniques (octree, hash) for very high resolutions [S1, unofficial].
-   **When to use:** When training speed is a priority and memory is sufficient for the desired resolution. Good starting point for new problems [S1, unofficial].
-   **When not to use:** When memory is extremely constrained or very high resolution is needed without scaling techniques.

## Background
Direct Voxel Grid Optimization was introduced in CVPR 2022 Oral [S1, unofficial]. It builds on the idea of replacing the MLP in NeRF with a voxel grid for density and a feature grid for color. The method aims to simplify the scene representation while maintaining quality. It is supported by the PyTorch implementation DirectVoxGO [S1, unofficial].
