# Training Losses for Implicit Surface Learning

Also called: Photometric and Occupancy Losses

## Overview
This method defines a set of loss functions to train the occupancy network $f_\theta$ and texture network $t_\theta$ using 2D image supervision [S1]. It categorizes sampled pixels into three sets—$P_0$ (inside mask, finite depth), $P_1$ (outside mask), and $P_2$ (inside mask, infinite depth)—to enforce photometric consistency, remove spurious geometry, and encourage surface presence where expected [S1]. It differs from sibling methods by explicitly handling the ambiguity of empty space ($P_1$) and missing surfaces ($P_2$) through targeted binary cross-entropy penalties, rather than relying solely on photometric error [S1].

## How it works

### Inputs and Outputs
*   **Inputs:**
    *   Training image $I_k$ and corresponding camera intrinsics/extrinsics [S1].
    *   Object mask $M_k$ indicating the silhouette of the object in $I_k$ [S1].
    *   Optional ground truth depth map $D_k$ [S1].
    *   Occupancy network $f_\theta(\mathbf{p})$ and texture network $t_\theta(\mathbf{p})$ [S1].
    *   Number of random pixels to sample $N_p$ [S1].
*   **Outputs:**
    *   Gradients for $\theta$ to update $f_\theta$ and $t_\theta$ [S1].

### Data Structures
*   **Pixel Set $P_0$:** Set of pixel coordinates $\mathbf{u}$ such that $\mathbf{u} \in M_k$ AND the predicted depth $\hat{d}$ is finite [S1].
*   **Pixel Set $P_1$:** Set of pixel coordinates $\mathbf{u}$ such that $\mathbf{u} \notin M_k$ [S1].
*   **Pixel Set $P_2$:** Set of pixel coordinates $\mathbf{u}$ such that $\mathbf{u} \in M_k$ AND the predicted depth $\hat{d}$ is infinite (no surface found) [S1].
*   **Ray $\mathbf{r}(d)$:** Function mapping a depth value $d$ to a 3D point in camera space [S1].
*   **Feature Extractor $\xi(\cdot)$:** Computes features from an image. Uses RGB values and optionally image gradients [S1].

### Numbered Steps
1.  Randomly sample $N_p$ points $\mathbf{u}$ on the image plane of image $I_k$ [S1].
2.  For each $\mathbf{u}$, predict the surface depth $\hat{d}$ using the current network parameters [S1].
3.  Classify each $\mathbf{u}$ into one of the three sets:
    *   If $\mathbf{u} \in M_k$ and $\hat{d}$ is finite, add $\mathbf{u}$ to $P_0$ [S1].
    *   If $\mathbf{u} \notin M_k$, add $\mathbf{u}$ to $P_1$ [S1].
    *   If $\mathbf{u} \in M_k$ and $\hat{d}$ is infinite, add $\mathbf{u}$ to $P_2$ [S1].
4.  Compute the RGB loss $\mathcal{L}_{\text{rgb}}$ for all $\mathbf{u} \in P_0$ [S1].
5.  If depth $D_k$ is available, compute the Depth loss $\mathcal{L}_{\text{depth}}$ for all $\mathbf{u} \in P_0$ [S1].
6.  Compute the Freespace loss $\mathcal{L}_{\text{freespace}}$ for all $\mathbf{u} \in P_1$ [S1].
7.  Compute the Occupancy loss $\mathcal{L}_{\text{occupancy}}$ for all $\mathbf{u} \in P_2$ [S1].
8.  Optionally, compute the Normal loss $\mathcal{L}_{\text{normal}}$ for all $\mathbf{u} \in P_0$ [S1].
9.  Sum all active losses and backpropagate to update $\theta$ [S1].

### Formulas
*   **RGB Loss (for $P_0$):**
    $$ \mathcal{L}_{\text{rgb}}(\theta) = \sum_{\mathbf{u} \in P_0} \|\xi(\mathbf{I})_{\mathbf{u}} - \xi(\hat{\mathbf{I}})_{\mathbf{u}}\| $$
    Where $\xi(\cdot)$ computes image features (RGB values and optionally image gradients) and $\|\cdot\|$ is a robust error metric (L1 loss in practice) [S1].

*   **Depth Loss (for $P_0$, if $D_k$ available):**
    $$ \mathcal{L}_{\text{depth}}(\theta) = \sum_{\mathbf{u} \in P_0} |d - \hat{d}|_1 $$
    Where $d$ is the ground truth depth value for pixel $\mathbf{u}$ and $\hat{d}$ is the predicted surface depth [S1].

*   **Freespace Loss (for $P_1$):**
    $$ \mathcal{L}_{\text{freespace}}(\theta) = \sum_{\mathbf{u} \in P_1} \text{BCE}(f_\theta(\hat{\mathbf{p}}), 0) $$
    Where $\hat{\mathbf{p}} = \mathbf{r}(\hat{d})$ is the predicted surface point. If no surface depth is predicted ($\hat{d}$ is infinite), apply BCE to a randomly sampled point on the ray instead [S1].

*   **Occupancy Loss (for $P_2$):**
    $$ \mathcal{L}_{\text{occupancy}}(\theta) = \sum_{\mathbf{u} \in P_2} \text{BCE}(f_{\theta}(\mathbf{r}(d_{\text{random}})), 1) $$
    Where $d_{\text{random}}$ are uniformly sampled depth values along the ray. In single-view experiments, use the visual hull depth (first point inside all object masks) or ground truth depth if available [S1].

*   **Normal Loss (optional, for $P_0$):**
    $$ \mathcal{L}_{\text{normal}}(\theta) = \sum_{\mathbf{u} \in P_0} \|\mathbf{n}(\mathbf{p}_{\mathbf{u}}) - \mathbf{n}(\mathbf{q}_{\mathbf{u}})\|_2 $$
    Where $\mathbf{n}(\cdot)$ is the normal vector, $\hat{\mathbf{p}}_{\mathbf{u}}$ is the predicted surface point, and $\mathbf{q}_{\mathbf{u}}$ is a randomly sampled neighbor of $\hat{\mathbf{p}}_{\mathbf{u}}$ [S1].

### Parameters
*   $N_p$: Number of random pixels sampled on the image plane per training step [S1].
*   $\xi(\cdot)$: Feature extractor for RGB loss. Uses RGB-values and optionally image gradients [S1].
*   $\|\cdot\|$: Robust error metric for RGB loss. Uses L1 loss in practice [S1].

### Edge Cases and Pitfalls
*   **Infinite Depth in $P_1$:** If a point $\mathbf{u} \in P_1$ has no predicted surface depth, the Freespace loss must still be applied to a randomly sampled point on the ray to penalize empty space [S1].
*   **Single-View Ambiguity:** For $P_2$ in single-view experiments, the target depth for Occupancy loss should be the visual hull depth (intersection of all object masks) rather than a random sample, to provide a meaningful target [S1].
*   **Unconstrained Areas:** The Normal loss is particularly useful for real-world data to enforce natural shapes in areas unconstrained by 2D/2.5D supervision [S1].

                freespace_loss += binary_cross_entropy(occ_val, 0.0)

        occupancy_loss = 0.0
        for u in P2:
            # Sample random depths
            d_random = sample_random_depth()
            p_random = ray_point(u, d_random)
            occ_val = f_theta(p_random)
            occupancy_loss += binary_cross_entropy(occ_val, 1.0)
        total_loss += occupancy_loss

    # 8. Normal Loss (optional) for P0

        normal_loss = 0.0

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of sampled pixels $N_p$ and the number of active sets ($P_0, P_1, P_2$) [S1].
*   **Memory Complexity:** Linear with respect to $N_p$ to store the sets and intermediate gradients [S1].
*   **Strengths:** Works with as little as one image per object [S1]. Can incorporate depth information if available [S1]. The occupancy loss helps refine initial occupancy using photometric and depth losses [S1].
*   **Limitations:** Relies on 2D/2.5D supervision, which may leave unconstrained areas; the normal loss is needed to enforce natural shapes in these areas [S1].
*   **When to use:** When training implicit neural representations with limited 2D image supervision, especially in single-view or sparse-view settings [S1].

## Background
This method was introduced in the paper "Differentiable Volumetric Rendering: Learning Implicit 3D Representations without 3D Supervision" [S1]. It addresses the challenge of training occupancy and texture networks without explicit 3D ground truth, using only 2D image masks and optionally depth maps [S1].
