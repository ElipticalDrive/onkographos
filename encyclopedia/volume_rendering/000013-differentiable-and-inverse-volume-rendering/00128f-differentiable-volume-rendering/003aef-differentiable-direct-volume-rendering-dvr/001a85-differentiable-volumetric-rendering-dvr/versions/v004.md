# Differentiable Volumetric Rendering (DVR)

Also called: Implicit Surface Differentiation, Implicit Surface Gradient via Implicit Differentiation, Implicit Surface Rendering, Learning Implicit 3D Representations without 3D Supervision

## Overview
Differentiable Volumetric Rendering (DVR) is a method for training implicit neural representations of 3D shape and texture using only 2D RGB image supervision, eliminating the need for 3D ground truth data [S1][S3, unofficial][S4, unofficial]. It sets itself apart from voxel-based differentiable renderers by deriving analytic gradients for surface depth via implicit differentiation, which allows it to avoid storing intermediate volumetric data in the forward pass, thereby making memory usage independent of sampling resolution [S1][S2][S4, unofficial]. Unlike [DiffDVR](1355-differentiable-direct-volume-rendering-diffdvr.md), which typically handles explicit volumetric grids or density fields, DVR operates on a continuous implicit surface defined by a level set, rendering colors by querying a texture network at the precise intersection point [S1][S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Camera parameters (origin $\mathbf{r}_0$, direction vector $\mathbf{w}$ for each pixel $\mathbf{u}$), network parameters $\theta$, and optionally a latent code $\mathbf{z}$ conditioned on an input image.
*   **Outputs:** Rendered color $\hat{\mathbf{I}}_\mathbf{u}$ for each pixel $\mathbf{u}$, and gradients $\frac{\partial \mathcal{L}}{\partial \theta}$ for optimization.

**Data Structures:**
The method uses a single neural network with two shallow heads sharing parameters $\theta$:
1.  **Occupancy Network ($f_\theta$):**
    *   Input: 3D coordinate $\mathbf{p} \in \mathbb{R}^3$ and latent code $\mathbf{z} \in \mathcal{Z}$.
    *   Output: Scalar occupancy probability $f_\theta(\mathbf{p}, \mathbf{z}) \in [0, 1]$.
    *   Signature: $f_\theta : \mathbb{R}^3 \times \mathcal{Z} \rightarrow [0, 1]$ [S1][S3, unofficial].
2.  **Texture Field Network ($t_\theta$):**
    *   Input: 3D coordinate $\mathbf{p} \in \mathbb{R}^3$ and latent code $\mathbf{z} \in \mathcal{Z}$.
    *   Output: RGB color vector $\mathbf{t}_\theta(\mathbf{p}, \mathbf{z}) \in \mathbb{R}^3$.
    *   Signature: $t_\theta : \mathbb{R}^3 \times \mathcal{Z} \rightarrow \mathbb{R}^3$ [S1][S3, unofficial].

**Parameters:**
*   $\tau$: Isosurface threshold. Typical value: $0.5$ [S1][S2][S4, unofficial]. Range: $[0, 1]$.
*   $n$: Number of equally-spaced samples on the ray for depth estimation. Starts at $16$, increases to $128$ during training [S1][S2][S4, unofficial].
*   $s_0$: Start depth of the sampling interval [S1][S2].
*   $\Delta s$: Step size for samples.
*   $\mathbf{w}$: Ray direction vector from $\mathbf{r}_0$ to pixel $\mathbf{u}$ [S1][S4, unofficial].

**Algorithm Steps:**

1.  **Ray Casting:** For each pixel $\mathbf{u}$, define the ray $\mathbf{r}(d) = \mathbf{r}_0 + d\mathbf{w}$ [S1][S2].
2.  **Forward Pass (Depth Estimation):**
    *   Evaluate $f_\theta$ at $n$ equally-spaced points $\mathbf{p}_j^{\text{ray}} = \mathbf{r}(j\Delta s + s_0)$ for $j=1 \dots n$ [S1][S2].
    *   Find the smallest index $j$ such that the occupancy changes from free space to occupied:
        $$ j = \operatorname{argmin}_{j'} \left( f_\theta(\mathbf{p}_{j'+1}^{\text{ray}}) \geq \tau > f_\theta(\mathbf{p}_{j'}^{\text{ray}}) \right) $$ [S1][S2].
    *   Approximate the surface depth $\hat{d}$ using the iterative secant method on the interval $[j\Delta s + s_0, (j+1)\Delta s + s_0]$ [S1][S2].
    *   Compute the intersection point $\hat{\mathbf{p}} = \mathbf{r}(\hat{d})$ [S1][S2].
3.  **Color Evaluation:**
    *   Compute the rendered color: $\hat{\mathbf{I}}_\mathbf{u} = t_\theta(\hat{\mathbf{p}})$ [S1][S2].
4.  **Backward Pass (Gradient Computation):**
    *   Compute the loss gradient with respect to the rendered image: $\frac{\partial \mathcal{L}}{\partial \hat{\mathbf{I}}_\mathbf{u}}$ [S1][S2].
    *   Apply the chain rule to find the gradient with respect to parameters $\theta$:
        $$ \frac{\partial \mathcal{L}}{\partial \theta} = \sum_\mathbf{u} \frac{\partial \mathcal{L}}{\partial \hat{\mathbf{I}}_\mathbf{u}} \cdot \frac{\partial \hat{\mathbf{I}}_\mathbf{u}}{\partial \theta} $$ [S1][S2].
    *   Expand $\frac{\partial \hat{\mathbf{I}}_\mathbf{u}}{\partial \theta}$ using the fact that $\hat{\mathbf{I}}_\mathbf{u} = t_\theta(\hat{\mathbf{p}})$:
        $$ \frac{\partial \hat{\mathbf{I}}_\mathbf{u}}{\partial \theta} = \frac{\partial t_\theta(\hat{\mathbf{p}})}{\partial \theta} + \frac{\partial t_\theta(\hat{\mathbf{p}})}{\partial \hat{\mathbf{p}}} \cdot \frac{\partial \hat{\mathbf{p}}}{\partial \theta} $$ [S1][S2].
    *   Derive $\frac{\partial \hat{\mathbf{p}}}{\partial \theta}$ using the ray equation $\hat{\mathbf{p}} = \mathbf{r}_0 + \hat{d}\mathbf{w}$:
        $$ \frac{\partial \hat{\mathbf{p}}}{\partial \theta} = \mathbf{w} \frac{\partial \hat{d}}{\partial \theta} $$ [S1][S2].
    *   Derive $\frac{\partial \hat{d}}{\partial \theta}$ using implicit differentiation of the constraint $f_\theta(\hat{\mathbf{p}}) = \tau$:
        $$ \frac{\partial \hat{d}}{\partial \theta} = - \left( \frac{\partial f_\theta(\hat{\mathbf{p}})}{\partial \hat{\mathbf{p}}} \cdot \mathbf{w} \right)^{-1} \frac{\partial f_\theta(\hat{\mathbf{p}})}{\partial \theta} $$ [S1][S2].
    *   **Implementation Optimization:** To compute the backward pass efficiently for a batch, rewrite the term $\lambda \frac{\partial \hat{d}}{\partial \theta}$ (where $\lambda = \frac{\partial \mathcal{L}}{\partial \hat{d}}$) as:
        $$ \mu \frac{\partial f_\theta(\hat{\mathbf{p}})}{\partial \theta} \quad \text{with} \quad \mu = - \left( \frac{\partial f_\theta(\hat{\mathbf{p}})}{\partial \hat{\mathbf{p}}} \cdot \mathbf{w} \right)^{-1} \lambda $$ [S1][S2].
    *   Multiply the incoming gradient $\lambda$ element-wise by the scalar factor $\mu$, then backpropagate the result through the occupancy network $f_\theta(\hat{\mathbf{p}})$ using reverse-mode automatic differentiation [S1][S2].

**Pseudocode:**

```python
import torch
import torch.nn as nn

class DVRNetwork(nn.Module):
    def __init__(self, latent_dim, hidden_dim):
        super().__init__()
        # Single network with two heads
        self.shared_layers = nn.Sequential(
            nn.Linear(3 + latent_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU()
        )
        self.occupancy_head = nn.Linear(hidden_dim, 1)
        self.texture_head = nn.Linear(hidden_dim, 3)

    def forward(self, points, z):
        """
        points: (N, 3)
        z: (N, latent_dim)
        """
        x = torch.cat([points, z], dim=-1)
        h = self.shared_layers(x)
        occ = self.occupancy_head(h)
        tex = self.texture_head(h)
        return occ.squeeze(-1), tex

def render_pixel(ray_origin, ray_direction, network, z, tau, n_samples, s0, ds):
    """
    Renders a single pixel (or batch of pixels) using DVR.
    ray_origin: (N, 3)
    ray_direction: (N, 3)
    network: DVRNetwork
    z: (N, latent_dim)
    tau: float
    n_samples: int
    s0: float
    ds: float
    """
    # 1. Forward Pass: Find depth
    # Sample points along the ray
    # p_j = r0 + (j*ds + s0) * w
    # We need n_samples points. Indices j=1 to n_samples.
    depths = torch.arange(1, n_samples + 1, device=ray_origin.device).float() * ds + s0
    # depths shape: (n_samples,)
    # Expand to (N, n_samples)
    depths = depths.unsqueeze(0).expand(ray_origin.shape[0], -1)
    
    # Points shape: (N, n_samples, 3)
    points = ray_origin.unsqueeze(1) + depths.unsqueeze(2) * ray_direction.unsqueeze(1)
    
    # Expand z to (N, n_samples, latent_dim)
    z_expanded = z.unsqueeze(1).expand(-1, n_samples, -1)
    
    # Evaluate occupancy network
    # occ shape: (N, n_samples)
    occ, _ = network(points.reshape(-1, 3), z_expanded.reshape(-1, z.shape[1]))
    occ = occ.view(ray_origin.shape[0], n_samples)
    
    # Find transition: f(p_j) < tau <= f(p_{j+1})
    # We look for the first j where occ[:, j+1] >= tau AND occ[:, j] < tau
    # Note: indices in code are 0-based, corresponding to j=1..n_samples in formula
    # Formula uses p_{j'+1} and p_{j'}. Let's find index k such that
    # occ[:, k] < tau and occ[:, k+1] >= tau.
    
    inside_mask = occ < tau
    outside_mask = occ >= tau
    
    # Transition occurs at index k if inside[k] and outside[k+1]
    # We need to handle the case where no transition is found (e.g., always inside or always outside)
    # For simplicity, assume valid intersection exists within bounds.
    
    # Create boolean masks for transition
    # trans[k] is True if occ[k] < tau and occ[k+1] >= tau
    # We check k from 0 to n_samples-2
    trans = (inside_mask[:, :-1] & outside_mask[:, 1:])
    
    # Find the first True index for each ray
    # argmax returns the index of the first True if we invert? No.
    # Use torch.argmax on the boolean tensor. If no True, it returns 0.
    # We need to ensure we pick the *first* transition.
    # Since trans is boolean, argmax works if we ensure only one transition or take the first.
    # In practice, objects are convex or simple.
    
    # Handle edge case: no transition found
    has_transition = trans.any(dim=1)
    # If no transition, set index to 0 (will likely result in invalid depth, handled by loss or mask)
    indices = trans.argmax(dim=1)
    
    # Get the depths of the two bounding samples
    # k is the index in the 0..n_samples-2 range
    # The interval is [depths[:, k], depths[:, k+1]]
    k = indices
    d_left = depths.gather(1, k.unsqueeze(1)).squeeze(1)
    d_right = depths.gather(1, (k + 1).unsqueeze(1)).squeeze(1)
    
    # Secant method to find precise depth d_hat
    # f(d_left) = occ_left, f(d_right) = occ_right
    # Linear interpolation: d_hat = d_left - f(d_left) * (d_right - d_left) / (f(d_right) - f(d_left))
    occ_left = occ.gather(1, k.unsqueeze(1)).squeeze(1)
    occ_right = occ.gather(1, (k + 1).unsqueeze(1)).squeeze(1)
    
    # Avoid division by zero
    denom = occ_right - occ_left
    denom = torch.where(denom == 0, torch.ones_like(denom), denom)
    
    d_hat = d_left - occ_left * (d_right - d_left) / denom
    
    # 2. Compute intersection point p_hat
    # p_hat = r0 + d_hat * w
    p_hat = ray_origin + d_hat.unsqueeze(1) * ray_direction
    
    # 3. Evaluate texture at p_hat
    # We need to re-evaluate the network at p_hat to get gradients correctly
    # Or use the cached values if we implement custom autograd.
    # Here we re-evaluate for clarity, but in practice, one would use the cached forward pass.
    # To match the paper's backward pass implementation, we need the gradient of f_theta at p_hat.
    
    # Re-evaluate f_theta and t_theta at p_hat
    # This is inefficient for the forward pass but correct for the logic.
    # In the actual implementation, the forward pass returns occ and tex at p_hat,
    # and the backward pass uses the gradient of f_theta at p_hat.
    
    # Let's assume we have a custom function that returns p_hat, occ_hat, tex_hat, and grad_f
    # For this pseudocode, we will just return the color.
    
    _, tex_hat = network(p_hat, z)
    
    return tex_hat

class DVRRenderFunction(torch.autograd.Function):
    @staticmethod
    def forward(ctx, ray_origin, ray_direction, network, z, tau, n_samples, s0, ds):
        # 1. Sample and find transition
        depths = torch.arange(1, n_samples + 1, device=ray_origin.device).float() * ds + s0
        depths = depths.unsqueeze(0).expand(ray_origin.shape[0], -1)
        points = ray_origin.unsqueeze(1) + depths.unsqueeze(2) * ray_direction.unsqueeze(1)
        z_expanded = z.unsqueeze(1).expand(-1, n_samples, -1)
        
        occ, _ = network(points.reshape(-1, 3), z_expanded.reshape(-1, z.shape[1]))
        occ = occ.view(ray_origin.shape[0], n_samples)
        
        inside_mask = occ < tau
        outside_mask = occ >= tau
        trans = (inside_mask[:, :-1] & outside_mask[:, 1:])
        k = trans.argmax(dim=1)
        
        d_left = depths.gather(1, k.unsqueeze(1)).squeeze(1)
        d_right = depths.gather(1, (k + 1).unsqueeze(1)).squeeze(1)
        occ_left = occ.gather(1, k.unsqueeze(1)).squeeze(1)
        occ_right = occ.gather(1, (k + 1).unsqueeze(1)).squeeze(1)
        
        denom = occ_right - occ_left
        denom = torch.where(denom == 0, torch.ones_like(denom), denom)
        d_hat = d_left - occ_left * (d_right - d_left) / denom
        
        p_hat = ray_origin + d_hat.unsqueeze(1) * ray_direction
        
        # 2. Evaluate texture and occupancy at p_hat for backward pass
        # We need to save p_hat, z, and potentially the network weights if not using standard autograd
        # But the paper suggests backpropagating through f_theta directly.
        
        occ_hat, tex_hat = network(p_hat, z)
        
        ctx.save_for_backward(p_hat, z, ray_direction)
        ctx.network = network
        ctx.tau = tau
        ctx.d_hat = d_hat
        
        return tex_hat

    @staticmethod
    def backward(ctx, grad_output):
        # grad_output: (N, 3) gradient of loss wrt tex_hat
        p_hat, z, w = ctx.saved_tensors
        d_hat = ctx.d_hat
        network = ctx.network
        
        # We need grad_f = df_theta/d_theta and grad_p_f = df_theta/d_p_hat at p_hat
        # To get these, we need to compute the forward pass of f_theta at p_hat again
        # and then compute gradients.
        
        # Re-evaluate f_theta at p_hat
        # Note: network returns (occ, tex). We only need occ for the implicit diff part.
        # But we need the gradient wrt theta.
        
        # Compute gradient of f_theta wrt theta
        # This requires a forward pass and backward pass through f_theta
        p_hat.requires_grad_(True)
        z.requires_grad_(True)
        
        # Forward pass for f_theta
        # We need to isolate f_theta. Assuming network.shared_layers and occupancy_head
        # It's easier to just call the network and extract the gradient.
        
        # However, the paper says: "backpropagating the result through the operator theta -> f_theta(p_hat)"
        # This implies we treat f_theta as a function of theta.
        
        # Let's compute grad_f_theta_theta and grad_f_theta_p
        # We need the gradient of the loss wrt theta.
        # L = sum_u || I_u - t_theta(p_hat) ||
        # dL/d_theta = sum_u [ dL/dI * dt/d_theta + dL/dI * dt/dp * dp/d_theta ]
        # dp/d_theta = w * dd/d_theta
        # dd/d_theta = - (df/dp . w)^-1 * df/d_theta
        
        # Let lambda = dL/d_d_hat (scalar per pixel)
        # lambda = dL/dI * dt/dp . w  (chain rule from color to depth)
        # Actually, grad_output is dL/d_tex_hat.
        # dL/d_d_hat = grad_output . (dt/dp_hat) . w ? No.
        # I_hat = t(p_hat). dI/d_d = dt/dp * dp/dd = dt/dp * w.
        # So lambda = grad_output @ (dt/dp_hat) @ w ? 
        # grad_output is (N, 3). dt/dp_hat is (N, 3, 3). w is (N, 3).
        # lambda = sum_k grad_output[:, k] * dt_k/dp * w
        # This is complex. The paper simplifies by computing mu.
        
        # Let's follow the paper's backward pass structure:
        # 1. Compute lambda = dL/d_d_hat
        # 2. Compute mu = - (df/dp . w)^-1 * lambda
        # 3. Compute grad_theta = mu * df/d_theta
        
        # Step 1: Compute dt/dp_hat at p_hat
        # We need the Jacobian of t_theta wrt p_hat.
        # This is expensive. The paper might assume we have it or compute it.
        # For the sake of the pseudocode, we assume we can compute dt/dp_hat.
        
        # Re-evaluate t_theta at p_hat to get gradients
        tex_val, _ = network(p_hat, z) # This is redundant, we have tex_hat from forward
        # But we need gradients.
        
        # Let's compute the necessary gradients using torch.autograd.grad
        # We need df/d_theta and df/d_p_hat at p_hat.
        
        # Forward pass for f_theta
        f_val, _ = network(p_hat, z)
        
        # Gradient of f_val wrt theta
        # We need to sum over the batch? No, element-wise.
        # df/d_theta is a tensor of shape (N, num_params).
        # We can compute this by calling torch.autograd.grad(f_val, network.parameters())
        
        # However, the paper says: "backpropagating the result through the operator theta -> f_theta(p_hat)"
        # This means we treat f_theta(p_hat) as the output.
        
        # Let's compute lambda first.
        # lambda = dL/dd_hat
        # dL/dd_hat = dL/dI * dI/dd_hat
        # dI/dd_hat = dt/dp_hat * dp/dd_hat = dt/dp_hat * w
        # So lambda = grad_output @ (dt/dp_hat) @ w ?
        # grad_output is (N, 3). dt/dp_hat is (N, 3, 3). w is (N, 3).
        # lambda_i = sum_j grad_output[i, j] * sum_k dt[i, j, k]/dp_k * w[i, k]
        
        # This requires computing dt/dp_hat.
        # Let's assume we have a function get_jacobian_t(p_hat, z)
        
        # For the purpose of this article, we state the formula.
        
        # Compute df/dp_hat
        grad_f_p = torch.autograd.grad(f_val.sum(), p_hat, retain_graph=True, create_graph=True)[0] # (N, 3)
        
        # Compute df/d_theta
        # This is the tricky part. We need the gradient of f_val wrt all parameters.
        # We can do this by summing f_val and backpropagating.
        grad_f_theta = torch.autograd.grad(f_val.sum(), list(network.parameters()), retain_graph=True)
        
        # Compute mu
        # df/dp . w is a dot product for each ray
        df_dot_w = (grad_f_p * w).sum(dim=1) # (N,)
        # mu = - lambda / (df_dot_w)
        # But we need lambda.
        
        # Compute dt/dp_hat
        tex_val, _ = network(p_hat, z)
        grad_t_p = torch.autograd.grad(tex_val.sum(), p_hat, retain_graph=True, create_graph=True)[0] # (N, 3, 3)
        
        # lambda = grad_output @ grad_t_p @ w
        # grad_output: (N, 3)
        # grad_t_p: (N, 3, 3)
        # w: (N, 3)
        # lambda_i = sum_j grad_output[i, j] * sum_k grad_t_p[i, j, k] * w[i, k]
        lambda_val = (grad_output.unsqueeze(2) * grad_t_p).sum(dim=1).sum(dim=1) # (N,)
        
        # mu = - lambda / (df_dot_w)
        mu = - lambda_val / df_dot_w # (N,)
        
        # grad_theta = mu * grad_f_theta
        # grad_f_theta is a list of tensors.
        # We need to scale each tensor by mu.
        grad_params = [m * g for m, g in zip(mu, grad_f_theta)]
        
        # Return gradients for inputs
        # grad_output is already provided
        return None, None, tuple(grad_params), None, None, None, None, None

def render_batch(ray_origin, ray_direction, network, z, tau, n_samples, s0, ds):
    return DVRRenderFunction.apply(ray_origin, ray_direction, network, z, tau, n_samples, s0, ds)
```

**Edge Cases and Pitfalls:**
*   **No Intersection:** If the ray does not intersect the isosurface within the sampling interval, the secant method may fail or produce invalid depths. This is typically handled by masking out such pixels during loss computation [S1][S2].
*   **Precision:** The secant method approximation introduces error. Increasing $n$ reduces this error [S1][S2].
*   **Gradient Discontinuities:** The argmin operation for finding the transition index $j$ is non-differentiable. However, the paper notes that the gradient is computed via implicit differentiation of the *refined* depth $\hat{d}$, bypassing the need to differentiate through the discrete search step [S1][S2].
*   **Memory:** Unlike voxel-based methods, DVR does not store intermediate volumetric data, making it memory-efficient [S1][S2][S4, unofficial].

## Operating characteristics
*   **Time Complexity:** Dominated by the forward pass evaluation of the neural network at $n$ samples per ray and the backward pass. The implicit differentiation step adds minimal overhead compared to storing volumetric data [S1][S2].
*   **Memory Complexity:** Independent of the sampling accuracy $n$ and resolution, as no intermediate volumetric data is stored in the forward pass [S1][S2][S4, unofficial].
*   **Performance:** Enables high-resolution reconstruction without the discretization artifacts of voxel-based methods [S1][S2].
*   **Strengths:** Memory-efficient, resolution-independent, learns from 2D images only [S1][S2][S4, unofficial].
*   **Limitations:** Requires iterative secant method for depth refinement; non-differentiable search step is bypassed but relies on smooth implicit surfaces [S1][S2].

## Background
DVR was introduced by Niemeyer et al. in 2020 [S1][S2][S4, unofficial]. It builds on the concept of occupancy networks [48] and texture fields [54], extending them to be differentiable with respect to 2D image supervision. The key insight was the application of implicit differentiation to derive analytic gradients for surface depth, enabling the training of implicit neural representations without 3D ground truth [S1][S2].
