# Differentiable Volumetric Rendering (DVR)

Also called: Implicit Surface Differentiation, Implicit Surface Gradient via Implicit Differentiation, Implicit Surface Rendering, Learning Implicit 3D Representation, Learning Implicit 3D Representations without 3D Supervision

## Overview
Differentiable Volumetric Rendering (DVR) is a method for training implicit neural representations of 3D shape and texture directly from 2D RGB images and object masks, without requiring 3D ground truth supervision [S1, S2][S5, unofficial]. It solves the problem of optimizing continuous implicit functions by casting rays, finding the intersection with the implicit isosurface, and backpropagating gradients through the rendering process using analytic implicit differentiation [S2][S5, unofficial]. It sets itself apart from voxel-based differentiable rendering by not storing intermediate volumetric data in the forward pass, making its memory footprint independent of sampling accuracy [S1, S2][S5, unofficial], and from mesh-based methods by avoiding discretization artifacts [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Camera parameters (origin $\mathbf{r}_0$, direction $\mathbf{w}$ for each pixel $\mathbf{u}$), network parameters $\theta$, latent code $\mathbf{z}$ (optional, for conditional generation), isosurface threshold $\tau$, sampling parameters ($n, \Delta s, s_0$).
*   **Outputs:** Rendered color $\hat{\mathbf{I}}_\mathbf{u}$ for each pixel, gradients $\frac{\partial \mathcal{L}}{\partial \theta}$ for optimization.

**Data Structures:**
*   **Occupancy Network $f_\theta$:** A neural network mapping $\mathbb{R}^3 \times \mathcal{Z} \rightarrow [0, 1]$. Input: 3D point $\mathbf{p}$ and latent code $\mathbf{z}$. Output: scalar occupancy probability.
*   **Texture Network $t_\theta$:** A neural network mapping $\mathbb{R}^3 \times \mathcal{Z} \rightarrow \mathbb{R}^3$. Input: 3D point $\mathbf{p}$ and latent code $\mathbf{z}$. Output: RGB color vector.
*   **Implementation:** $f_\theta$ and $t_\theta$ are implemented as a single neural network with two shallow output heads [S1, S2][S5, unofficial].

**Parameters:**
*   $\tau$: Isosurface threshold. Typical value: $0.5$ [S1, S2][S5, unofficial]. Range: $[0, 1]$ [S1, S2].
*   $n$: Number of equally-spaced samples on the ray. Starts at $16$, increases to $128$ during training [S1, S2][S5, unofficial].
*   $\Delta s$: Step size for samples.
*   $s_0$: Start of sampling interval (closest possible surface point) [S1, S2].
*   $\mathbf{z}$: Latent embedding vector, typically $256$-dimensional [S1, S2].

**Algorithm:**

1.  **Ray Casting and Surface Intersection (Forward Pass):**
    For a pixel $\mathbf{u}$ with ray $\mathbf{r}(d) = \mathbf{r}_0 + d\mathbf{w}$:
    a. Evaluate $f_\theta$ at $n$ equally-spaced points $\mathbf{p}_j^{\text{ray}} = \mathbf{r}(j\Delta s + s_0)$ for $j=1 \dots n$ [S1, S2][S5, unofficial].
    b. Find the smallest index $j$ such that $f_\theta(\mathbf{p}_{j+1}^{\text{ray}}) \geq \tau > f_\theta(\mathbf{p}_j^{\text{ray}})$ [S1, S2][S5, unofficial]. This identifies the interval containing the surface.
    c. Approximate the surface depth $\hat{d}$ using the iterative secant method on the interval $[j\Delta s + s_0, (j+1)\Delta s + s_0]$ [S1, S2][S5, unofficial].
    d. Compute the intersection point $\hat{\mathbf{p}} = \mathbf{r}(\hat{d})$ [S1, S2][S5, unofficial].

2.  **Color Evaluation:**
    Compute the rendered color $\hat{\mathbf{I}}_\mathbf{u} = t_\theta(\hat{\mathbf{p}})$ [S1, S2][S5, unofficial].

3.  **Gradient Computation (Backward Pass):**
    The goal is to compute $\frac{\partial \mathcal{L}}{\partial \theta}$. Using the chain rule:
    $$ \frac{\partial \mathcal{L}}{\partial \theta} = \sum_\mathbf{u} \frac{\partial \mathcal{L}}{\partial \hat{\mathbf{I}}_\mathbf{u}} \cdot \frac{\partial \hat{\mathbf{I}}_\mathbf{u}}{\partial \theta} $$
    where $\frac{\partial \hat{\mathbf{I}}_\mathbf{u}}{\partial \theta} = \frac{\partial t_\theta(\hat{\mathbf{p}})}{\partial \theta} + \frac{\partial t_\theta(\hat{\mathbf{p}})}{\partial \hat{\mathbf{p}}} \cdot \frac{\partial \hat{\mathbf{p}}}{\partial \theta}$ [S1, S2][S5, unofficial].

    The term $\frac{\partial \hat{\mathbf{p}}}{\partial \theta}$ is derived via implicit differentiation of $f_\theta(\hat{\mathbf{p}}) = \tau$:
    $$ \frac{\partial \hat{\mathbf{p}}}{\partial \theta} = \mathbf{w} \frac{\partial \hat{d}}{\partial \theta} $$
    $$ \frac{\partial \hat{d}}{\partial \theta} = - \left( \frac{\partial f_\theta(\hat{\mathbf{p}})}{\partial \hat{\mathbf{p}}} \cdot \mathbf{w} \right)^{-1} \frac{\partial f_\theta(\hat{\mathbf{p}})}{\partial \theta} $$
    [S1, S2][S5, unofficial].

    In practice, to compute the gradient of the loss with respect to $\theta$ efficiently without storing intermediate volumetric data:
    a. Let $\lambda = \frac{\partial \mathcal{L}}{\partial \hat{d}}$ be the incoming gradient from the loss with respect to depth.
    b. Compute the scalar factor $\mu = - \left( \frac{\partial f_\theta(\hat{\mathbf{p}})}{\partial \hat{\mathbf{p}}} \cdot \mathbf{w} \right)^{-1} \lambda$ [S1, S2].
    c. Multiply $\lambda$ element-wise by $\mu$ to get $\mu \lambda$ (Note: The source [S1] Eq 11 defines $\mu$ including $\lambda$, so the term to backpropagate is $\mu \frac{\partial f_\theta(\hat{\mathbf{p}})}{\partial \theta}$ where $\mu$ is the scalar computed above. More precisely, the gradient contribution from the depth dependency is $\mu \frac{\partial f_\theta(\hat{\mathbf{p}})}{\partial \theta}$ where $\mu = - (\frac{\partial f_\theta(\hat{\mathbf{p}})}{\partial \hat{\mathbf{p}}} \cdot \mathbf{w})^{-1} \lambda$ [S1]).
    d. Backpropagate through $f_\theta(\hat{\mathbf{p}})$ using reverse-mode automatic differentiation with the modified gradient [S1, S2].

**Pseudocode:**

```python
import torch
import torch.nn as nn

class DVRNetwork(nn.Module):
    def __init__(self, hidden_dim=256, latent_dim=256):
        super().__init__()
        # Shared encoder for geometry and texture
        self.shared_encoder = nn.Sequential(
            nn.Linear(3, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU()
        )
        # Occupancy head: outputs scalar probability
        self.occupancy_head = nn.Linear(hidden_dim, 1)
        # Texture head: outputs RGB color
        self.texture_head = nn.Linear(hidden_dim, 3)
        
        # Optional latent code conditioning
        self.latent_encoder = nn.Linear(latent_dim, hidden_dim)

    def forward(self, points, latent_code=None):
        """
        points: (N, 3) tensor of 3D coordinates
        latent_code: (N, latent_dim) tensor of latent codes (optional)
        Returns: occupancy (N, 1), texture (N, 3)
        """
        x = self.shared_encoder(points)
        if latent_code is not None:
            z_emb = self.latent_encoder(latent_code)
            x = x + z_emb
        
        occupancy = self.occupancy_head(x)
        texture = self.texture_head(x)
        return occupancy, texture

def render_pixel(ray_origin, ray_direction, network, latent_code, tau=0.5, n_samples=128, s0=0.0, ds=0.01):
    """
    Renders a single pixel using DVR.
    ray_origin: (3,) tensor
    ray_direction: (3,) tensor
    network: DVRNetwork instance
    latent_code: (latent_dim,) tensor
    tau: isosurface threshold
    n_samples: number of samples on ray
    s0: start distance
    ds: step size
    Returns: color (3,), depth_grad_factor (scalar) for backprop
    """
    # Forward pass: find surface intersection
    # Sample points along ray
    distances = torch.linspace(s0, s0 + n_samples * ds, n_samples)
    points = ray_origin.unsqueeze(0) + distances.unsqueeze(1) * ray_direction.unsqueeze(0) # (N, 3)
    
    # Evaluate occupancy
    occ, _ = network(points, latent_code.unsqueeze(0)) # (N, 1)
    
    # Find interval where occupancy crosses tau
    # f(p_j) < tau and f(p_{j+1}) >= tau
    inside = occ.squeeze(1) >= tau
    # Find first index j where inside[j+1] is True and inside[j] is False
    # We look for the transition
    transitions = (inside[1:] & ~inside[:-1])
    j = torch.argmax(transitions.float()) # Index of the first point in the interval
    
    # Secant method refinement within interval [distances[j], distances[j+1]]
    # p_j and p_{j+1}
    p_j = points[j]
    p_j1 = points[j+1]
    f_j = occ[j] - tau
    f_j1 = occ[j+1] - tau
    
    # Secant method: d = d_j - f_j * (d_{j+1} - d_j) / (f_{j+1} - f_j)
    # Avoid division by zero
    denom = f_j1 - f_j
    if denom.abs() < 1e-8:
        d_hat = distances[j]
    else:
        d_hat = distances[j] - f_j * (distances[j+1] - distances[j]) / denom
        
    # Intersection point
    p_hat = ray_origin + d_hat * ray_direction
    
    # Evaluate texture at intersection
    _, texture = network(p_hat.unsqueeze(0), latent_code.unsqueeze(0))
    color = texture.squeeze(0)
    
    # Compute gradient factor for backpropagation
    # We need to backpropagate through the implicit function f(p_hat) = tau
    # Gradient of loss L w.r.t d_hat is lambda
    # We compute mu = - (df/dp . w)^-1 * lambda
    # Then backprop df/dtheta with gradient mu * df/dtheta
    
    # Compute df/dp (gradient of occupancy w.r.t point p_hat)
    p_hat.requires_grad = True
    occ_hat, _ = network(p_hat.unsqueeze(0), latent_code.unsqueeze(0))
    f_val = occ_hat - tau
    df_dp = torch.autograd.grad(f_val.sum(), p_hat, create_graph=True)[0].squeeze(0) # (3,)
    
    # df/dtheta is computed automatically by autograd if we keep the graph
    # But we need to inject the gradient correctly
    
    # The term to backpropagate is mu * df/dtheta
    # mu = - (df_dp . ray_direction)^-1
    # Note: lambda is the gradient from the loss w.r.t d_hat, which is passed in or assumed to be 1 for color gradient
    # Here we return the factor mu to be multiplied by lambda before backprop
    
    df_dp_dot_w = torch.dot(df_dp, ray_direction)
    if df_dp_dot_w.abs() < 1e-8:
        mu = torch.tensor(0.0)
    else:
        mu = -1.0 / df_dp_dot_w
        
    return color, mu, p_hat, df_dp

def render_batch(ray_origins, ray_directions, network, latent_codes, tau=0.5, n_samples=128, s0=0.0, ds=0.01):
    """
    Renders a batch of pixels.
    ray_origins: (B, 3)
    ray_directions: (B, 3)
    latent_codes: (B, latent_dim)
    Returns: colors (B, 3), mu_factors (B,)
    """
    B = ray_origins.shape[0]
    colors = torch.zeros(B, 3)
    mu_factors = torch.zeros(B)
    
    for i in range(B):
        c, mu, _, _ = render_pixel(ray_origins[i], ray_directions[i], network, latent_codes[i], tau, n_samples, s0, ds)
        colors[i] = c
        mu_factors[i] = mu
        
    return colors, mu_factors

def render_and_backprop(ray_origins, ray_directions, network, latent_codes, target_colors, tau=0.5, n_samples=128, s0=0.0, ds=0.01):

    optimizer = torch.optim.Adam(network.parameters(), lr=1e-4)
    optimizer.zero_grad()
    
    B = ray_origins.shape[0]
    rendered_colors = torch.zeros(B, 3, requires_grad=True)
    
    # Forward pass
    for i in range(B):
        # Sample points
        distances = torch.linspace(s0, s0 + n_samples * ds, n_samples)
        points = ray_origins[i].unsqueeze(0) + distances.unsqueeze(1) * ray_directions[i].unsqueeze(0)
        
        # Evaluate occupancy
        occ, _ = network(points, latent_codes[i].unsqueeze(0))
        
        # Find interval
        inside = occ.squeeze(1) >= tau
        transitions = (inside[1:] & ~inside[:-1])
        j = torch.argmax(transitions.float())
        
        # Secant method
        p_j = points[j]
        p_j1 = points[j+1]
        f_j = occ[j] - tau
        f_j1 = occ[j+1] - tau
        denom = f_j1 - f_j
        if denom.abs() < 1e-8:
            d_hat = distances[j]
        else:
            d_hat = distances[j] - f_j * (distances[j+1] - distances[j]) / denom
            
        p_hat = ray_origins[i] + d_hat * ray_directions[i]
        
        # Evaluate texture
        _, texture = network(p_hat.unsqueeze(0), latent_codes[i].unsqueeze(0))
        rendered_colors[i] = texture.squeeze(0)
        
    # Loss
    loss = torch.mean(torch.abs(rendered_colors - target_colors))
    
    # Backward pass
    # 1. Compute gradient of loss w.r.t rendered_colors
    dL_dcolor = torch.sign(rendered_colors - target_colors) / B # Gradient of L1 loss
    
    # 2. Compute gradient of loss w.r.t p_hat via texture network
    # We need to backprop through texture network to get dL/dp_hat
    # But we also need to inject the gradient through the occupancy network
    
    # Let's compute dL/dp_hat from the texture gradient
    # dL/dp_hat = dL/dcolor * dt/dp_hat
    # We can get this by backpropagating dL/dcolor through the texture network
    
    # However, the secant method breaks the graph. We must manually inject gradients.

        distances = torch.linspace(s0, s0 + n_samples * ds, n_samples)
        points = ray_origins[i].unsqueeze(0) + distances.unsqueeze(1) * ray_directions[i].unsqueeze(0)

            d_hat = distances[j] - f_j * (distances[j+1] - distances[j]) / denom
        p_hat = ray_origins[i] + d_hat * ray_directions[i]
        
        # Compute df/dp
        p_hat.requires_grad = True
        occ_hat, _ = network(p_hat.unsqueeze(0), latent_codes[i].unsqueeze(0))
        f_val = occ_hat - tau
        df_dp = torch.autograd.grad(f_val.sum(), p_hat, create_graph=True)[0].squeeze(0)
        
        # Compute dL/dp_hat from texture
        # We need the gradient of texture w.r.t p_hat
        # Let's assume we have dL/dcolor from the loss
        # dL/dp_hat = dL/dcolor * dt/dp_hat
        # We can compute dt/dp_hat by backpropagating dL/dcolor through the texture network

        lambda_val = torch.dot(dL_dp_hat, ray_directions[i])

        df_dp_dot_w = torch.dot(df_dp, ray_directions[i])
        if df_dp_dot_w.abs() < 1e-8:
            mu = torch.tensor(0.0)
        else:
            mu = -lambda_val / df_dp_dot_w
```

## Operating characteristics
*   **Time Complexity:** Depends on the number of samples $n$ per ray and the cost of evaluating the neural network. $n$ increases from 16 to 128 during training [S1, S2][S5, unofficial].
*   **Memory Complexity:** Memory footprint is independent of sampling accuracy because no intermediate volumetric data is stored in the forward pass [S1, S2][S5, unofficial]. This contrasts with voxel-based methods which require storing all intermediate evaluations [S1][S5, unofficial].
*   **Performance:** Trained on a single NVIDIA V100 GPU with a batch size of 64 images with 1024 random pixels each [S1, S2].
*   **Strengths:** Memory-efficient, scalable to high resolutions, learns from 2D images without 3D supervision, produces watertight meshes [S1, S2][S5, unofficial].
*   **Limitations:** Requires careful tuning of sampling parameters ($n, \Delta s, s_0$) and threshold $\tau$ [S1, S2]. Implicit differentiation can be numerically unstable if the gradient of the occupancy function is small [S2].
*   **When to use:** When 3D ground truth is unavailable, and high-resolution continuous representations are needed.
*   **When not to use:** When explicit mesh or voxel output is required without post-processing, or when real-time rendering is critical without pre-training.

## Background
DVR was introduced by Niemeyer et al. in 2020 [S1, S2][S5, unofficial]. It builds on the concept of occupancy networks [48] and texture fields [54]. The key insight is that depth gradients can be derived analytically using implicit differentiation, allowing the learning of implicit shape and texture representations directly from RGB images [S1, S2][S5, unofficial]. It was developed to overcome the limitations of voxel-based and mesh-based differentiable rendering, which suffer from discretization artifacts and low resolution [S1, S2][S5, unofficial]. The method enables single-view and multi-view 3D reconstruction from 2D photographs [S1, S2][S5, unofficial].
