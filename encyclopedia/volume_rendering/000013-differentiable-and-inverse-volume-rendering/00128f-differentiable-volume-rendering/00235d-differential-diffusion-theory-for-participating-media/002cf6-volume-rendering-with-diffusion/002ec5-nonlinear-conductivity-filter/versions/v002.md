# Nonlinear Conductivity Filter

Also called: Proposed Nonlinear Conductivity Filter, Signed Difference Conductivity

## Overview
The Nonlinear Conductivity Filter is a variation of nonlinear diffusion used in scale-space computation for volume rendering to improve scale detection [S1, unofficial]. Unlike the standard Perona-Malik filter which stops diffusion at edges (causing false maxima), this method controls diffusion direction to favor movement towards the medial axis and prevent edge crossing [S1, unofficial]. It achieves this by using signed forward differences instead of gradient magnitude to compute conductivity [S1, unofficial].

## How it works
**Inputs and Outputs**
- Input: A scalar field $L$ defined on a regular grid [S1, unofficial].
- Output: A diffused scalar field at scale $t+\Delta t$ [S1, unofficial].

**Data Structures**
- The field $L$ is stored on a regular grid [S1, unofficial].
- Neighbors $N$ are defined by a discretization stencil, typically a 6-, 18-, or 26-point neighborhood [S1, unofficial].

**Parameters**
- $\lambda$: Sensitivity parameter for boundaries. Small values ($\lambda \in (0.01, 0.1)$) lead to better localized scale maxima, useful for convoluted structures [S1, unofficial]. Large values ($\lambda > 1$) make diffusion linear [S1, unofficial].
- $\Delta t$: Time step for integration. Stability requires $\Delta t \le 1$ [S1, unofficial].
- $\alpha_{ijk}$: Normalizing coefficients for neighbors [S1, unofficial].
- $N$: Set of indices pointing to neighbors of a given point $x$ [S1, unofficial].

**Algorithm**
The filter computes the scale space iteratively using forward Euler integration of the diffusion equation [S1, unofficial].
1. For each point $x$ in the grid, initialize the change $\Delta L = 0$ [S1, unofficial].
2. For each neighbor index $ijk \in N$, compute the signed difference $d = L(x_{ijk}) - L(x)$ [S1, unofficial].
3. Compute the conductivity $C(d)$ using the signed difference [S1, unofficial]:
   $$C(d) = \begin{cases} \frac{\lambda^2}{\lambda^2 + d^2} & \text{if } d > 0 \\ 1 & \text{otherwise} \end{cases}$$
4. Compute the flow contribution $\phi = d \cdot C(d)$ [S1, unofficial].
5. Accumulate the weighted flow: $\Delta L \leftarrow \Delta L + \alpha_{ijk} \cdot \phi$ [S1, unofficial].
6. Update the field: $L'(x) = L(x) + \Delta t \cdot \Delta L$ [S1, unofficial].

**Pseudocode**
```python
def nonlinear_conductivity_filter(L, neighbors, alpha, lambda_param, dt):
    """
    Applies the Nonlinear Conductivity Filter to a volume L.
    
    Args:
        L: 3D array of scalar values.
        neighbors: List of relative coordinate offsets (ijk) for the stencil.
        alpha: List of normalizing coefficients corresponding to neighbors.
        lambda_param: Sensitivity parameter lambda.
        dt: Time step (must be <= 1 for stability).
        
    Returns:
        L_new: Diffused 3D array.
    """
    L_new = L.copy()
    lambda_sq = lambda_param * lambda_param
    shape = L.shape
    
    for i in range(shape[0]):
        for j in range(shape[1]):
            for k in range(shape[2]):
                L_center = L[i, j, k]
                change = 0.0
                
                for idx, offset in enumerate(neighbors):
                    ni, nj, nk = i + offset[0], j + offset[1], k + offset[2]
                    L_neighbor = L[ni, nj, nk]
                    
                    d = L_neighbor - L_center
                    
                    if d > 0:
                        c = lambda_sq / (lambda_sq + d * d)
                    else:
                        c = 1.0
                    
                    phi = d * c
                    change += alpha[idx] * phi
                    
                L_new[i, j, k] = L_center + dt * change
    return L_new
```

**Edge Cases and Pitfalls**
- The continuous diffusion problem is ill-posed and requires regularization [S1, unofficial].
- In the discrete case, finite difference discretization acts as a regularizer, but stability requires $\Delta t \le 1$ [S1, unofficial].
- Small $\lambda$ values may result in slight deviations of scale maxima but are generally more robust to noise [S1, unofficial].

## Subtopics

### Iterative Nonlinear Diffusion
This is the general framework used to apply the Nonlinear Conductivity Filter. It computes the scale space iteratively using forward Euler integration of the diffusion equation [S1, unofficial]. The update rule is $L(x;t+\Delta t) = L(x;t) + \Delta t \sum_{ijk \in N} \alpha_{ijk} \Phi(L(x_{ijk};t) - L(x;t))$ where $\Phi(x) = x \cdot C(x)$ [S1, unofficial]. For the standard Perona-Malik variant, $C(||\nabla L||) = \frac{\lambda^2}{\lambda^2 + ||\nabla L||^2}$ [S1, unofficial]. As $\lambda$ grows, $C$ approaches 1 (linear diffusion) [S1, unofficial]. Small $\lambda$ favors homogeneous regions and preserves edges [S1, unofficial]. The pitfall remains that non-linear diffusion with variable conductivity is ill-posed in the continuous case, requiring $\Delta t \le 1$ for stability in the discrete case [S1, unofficial].

## Operating characteristics
- **Time Complexity**: Linear with respect to the number of voxels, the stencil size (6-, 18-, or 26-point), and the number of iterations [S1, unofficial].
- **Memory Complexity**: Requires storage for the current and next scale field, plus neighbor lookups [S1, unofficial].
- **Strengths**: Better localized scale maxima for convoluted structures compared to linear diffusion; more robust to noise than Perona-Malik which creates false maxima [S1, unofficial].
- **Limitations**: The continuous problem is ill-posed; requires careful tuning of $\Delta t$ for stability; slight deviations in scale maxima localization [S1, unofficial].
- **When to use**: When accurate scale detection is needed for complex, convoluted structures in volume rendering, and edge-crossing diffusion towards the medial axis is desired [S1, unofficial].
- **When not to use**: When linear diffusion is sufficient (large $\lambda$) or when strict edge preservation without any crossing is required (Perona-Malik may be preferred despite false maxima) [S1, unofficial].

## Background
The method was developed for scale detection in volume data to address the limitations of the Perona-Malik filter, which stops diffusion at edges and generates false maxima responses [S1, unofficial]. The authors derived this variation to control diffusion direction towards the medial axis, similar to applying smoothing and erosion filters progressively [S1, unofficial].
