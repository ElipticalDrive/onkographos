# Differential Vertex Sampling with MIS

Also called: Differential sampling with MIS

## Overview
Differential Vertex Sampling with MIS is a method to estimate the gradient of a loss function with respect to scene parameters by importance sampling an intermediate path vertex as the differential vertex [S1]. It solves the problem of high variance in gradient estimation, particularly for specular materials, by combining differential vertex sampling with standard BRDF sampling using Multiple Importance Sampling (MIS) [S1]. Unlike standard BRDF sampling, which treats all vertices identically, this method explicitly biases the sampling distribution to capture the boundary component of the gradient integral, significantly reducing variance for microfacet and mixture BRDFs [S1].

## How it works
**Inputs and Outputs:**
- **Inputs:** Path vertex state (position, incoming direction, throughput), scene parameters $\theta$, mixing probability $q$, random number generator [S1].
- **Outputs:** Accumulated gradient update $\delta\theta$, updated throughput $\beta$, updated MIS weights $w_1, w_2$ [S1].

**Data Structures:**
- `sampled_∂x`: Boolean flag indicating if the differential vertex has been sampled for the current path vertex [S1].
- `w1`, `w2`: MIS weights for the differential and standard sampling strategies, respectively [S1].
- `β`: Throughput term, which includes the product of densities $p_f$ from the mixture probability [S1].

**Numbered Steps:**
1. Initialize `sampled_∂x` to FALSE for the current path vertex [S1].
2. Generate a random number $R$ [S1].
3. If `!sampled_∂x` AND $R < q$:
    a. Sample the differential vertex: $(\omega', f) = \text{SAMPLE\_∂BRDF}(\text{state})$ [S1].
    b. Set `sampled_∂x` to TRUE [S1].
    c. Compute the gradient update: $\delta\theta \leftarrow \delta\theta + \text{BACKWARD\_GRAD}(f, \delta L \cdot L/f)$ [S1].
4. Else (if differential vertex was not sampled):
    a. Sample the standard BRDF vertex: $(\omega', f) = \text{SAMPLE\_BRDF}(\text{state})$ [S1].
    b. Update throughput: $\beta \leftarrow \beta \cdot \frac{f}{p_f(\omega', \text{state})}$ [S1].
    c. Update MIS weights:
       - $w_1 \leftarrow w_1 + w_2 \cdot q \cdot \frac{p_{\partial f}(\omega', \text{state})}{p_f(\omega', \text{state})}$ [S1]
       - $w_2 \leftarrow w_2 \cdot (1 - q)$ [S1]
5. Return the accumulated gradient $\delta\theta$ [S1]. The method integrates with Next Event Estimation (NEE), though NEE steps are omitted from the pseudocode for simplicity [S1].

**Formulas:**
The mixture probability $p_{mix}(x)$ for a path $x$ is defined as [S1]:
$$p_{mix}(x) = \left( \prod_{i=0}^{N} p_f(x_i) \right) \left( \sum_{i=1}^{N-1} p_{\partial f}(x_i) (1-q)^{i-1} q + (1-q)^{N-1} \right)$$
The MIS weights are updated as follows [S1]:
$$w_1 \leftarrow w_1 + w_2 \cdot q \cdot \frac{p_{\partial f}(\omega', \text{state})}{p_f(\omega', \text{state})}$$
$$w_2 \leftarrow w_2 \cdot (1 - q)$$
The gradient update is computed as [S1]:
$$\delta\theta \leftarrow \delta\theta + \text{BACKWARD\_GRAD}(f, \delta L \cdot L/f)$$

**Parameters:**
- $q$: The probability of sampling the differential vertex at the current step instead of the standard BRDF vertex. Typical value: 0.5 [S1]. This value balances early vertex contributions (higher $q$) with indirect lighting contributions from later vertices [S1].

**Edge Cases and Pitfalls:**
- **Precision:** The mixture probability involves products of densities, which can lead to underflow or overflow if not handled carefully [S1].
- **Boundaries:** The method integrates with Next Event Estimation (NEE), but NEE steps are omitted from the pseudocode [S1].
- **Degenerate Input:** If $q=0$, the method degenerates to standard BRDF sampling. If $q=1$, it degenerates to differential vertex sampling only [S1].

**Pseudocode:**
```python
def differential_vertex_sampling_with_mis(
    state, q, rng, sample_partial_brdf, sample_brdf, backward_grad,
    p_partial_f, p_f, delta_L, L, beta, w1, w2, sampled_partial_x, delta_theta
):
    R = rng.next()
    if not sampled_partial_x and R < q:
        omega_prime, f = sample_partial_brdf(state)
        sampled_partial_x = True
        delta_theta += backward_grad(f, delta_L * (L / f))
    else:
        omega_prime, f = sample_brdf(state)
        beta *= f / p_f(omega_prime, state)
        w1 += w2 * q * p_partial_f(omega_prime, state) / p_f(omega_prime, state)
        w2 *= (1 - q)
    return delta_theta, beta, w1, w2, sampled_partial_x
```

## Subtopics

### [Primary-Sample-Space Guided MIS with Edge Sorting](6385-primary-sample-space-guided-mis-with-edge-sorting.md)
This method estimates the boundary component of the gradient integral in differentiable rendering by combining Multiple Importance Sampling (MIS) with primary-sample-space guiding. It addresses the high variance in gradient estimates caused by occlusion and complex illumination, which makes standard light sampling ineffective for boundary segments. Unlike its parent method, Differential Vertex Sampling with MIS, which uses MIS to combine differential vertex sampling with standard BRDF sampling, this method uses MIS to combine two distinct strategies for sampling the boundary segment's direction: light sampling and direct direction sampling. It sets itself apart from baseline methods by producing significantly cleaner gradient estimates at equal time and sample counts, particularly around shadow boundaries.
