# Reparameterized Volume Sampling

Also called: Differentiable Volume Sampling, Inverse CDF Sampling

## Overview
Reparameterized Volume Sampling is a differentiable volume rendering technique that computes color estimates by sampling points on a ray using the inverse of the cumulative density function (CDF), allowing gradients to back-propagate through the sampling locations with respect to the density field [S1, unofficial]. Unlike [Reparameterized Monte Carlo Volume Rendering](4798-reparameterized-monte-carlo-volume-rendering.md) which may rely on auxiliary coarse models or hierarchical schemes, this method learns sampling points end-to-end without auxiliary networks [S1, unofficial]. Compared to standard importance sampling with uniform distribution, this stratified reparameterized sampling exhibits lower variance [S1, unofficial].

## How it works
**Inputs:**
- Ray $\mathbf{r}$ defined by origin $t_{r_1}$ and far plane $t_{r_k}$ (or $t_f$).
- Density field $\sigma_{\mathbf{r}}(t)$ along the ray.
- Radiance field $c_{\mathbf{r}}(t)$ along the ray.
- Number of samples per ray $k$ (typically 32) [S1, unofficial].
- Number of knots $m$ for piecewise linear approximation (typically 256) [S1, unofficial].

**Outputs:**
- Color estimate $C(\mathbf{r})$.
- Gradients $\frac{\partial C}{\partial \sigma_{\mathbf{r}}}$ and $\frac{\partial C}{\partial c_{\mathbf{r}}}$ for back-propagation.

**Data Structures:**
- **Knots:** A set of $m$ points $t_1, t_2, \dots, t_m$ along the ray. In implementation, these are typically a uniform grid slightly perturbed to avoid degeneracies [S1, unofficial].
- **Density Values:** $\sigma_i = \sigma_{\mathbf{r}}(t_i)$ for $i=1 \dots m$.
- **Radiance Values:** $c_i = c_{\mathbf{r}}(t_i)$ for $i=1 \dots m$.

**Method Steps:**

1.  **Approximate Density:** Approximate the density field $\sigma_{\mathbf{r}}(t)$ along the ray using a piecewise linear interpolation between knots. For $t \in [t_i, t_{i+1}]$:
    $$
    \sigma_{\mathbf{r}}(t) = \sigma_i + \frac{\sigma_{i+1} - \sigma_i}{t_{i+1} - t_i} (t - t_i)
    $$
    [S1, unofficial]

2.  **Compute CDF Integral:** The Cumulative Distribution Function (CDF) is defined as:
    $$
    F_{\mathbf{r}}(t) = 1 - \exp\left(-\int_{t_{r_1}}^t \sigma_{\mathbf{r}}(s) ds\right)
    $$
    [S1, unofficial]
    Due to the piecewise linear density, the integral $I(t) = \int_{t_{r_1}}^t \sigma_{\mathbf{r}}(s) ds$ is a piecewise quadratic function. Precompute the cumulative integral values at each knot $t_i$. Let $I_i = \int_{t_{r_1}}^{t_i} \sigma_{\mathbf{r}}(s) ds$. Note that $I_1 = 0$.

3.  **Generate Random Sample:** Generate a random number $u \in [0, 1]$. To reduce variance, stratified sampling can be used by dividing $[0,1]$ into $k$ intervals and sampling $u_j$ within each [S1, unofficial].

4.  **Target Opacity:** Compute the target cumulative opacity value $y_f u$. The equation to solve for the sample position $t$ is:
    $$
    y_f u = F_{\mathbf{r}}(t) = 1 - \exp\left(-\int_{t_{r_1}}^t \sigma_{\mathbf{r}}(s) ds\right)
    $$
    [S1, unofficial]
    Rewrite this to isolate the integral:
    $$
    -\log(1 - y_f u) = \int_{t_{r_1}}^t \sigma_{\mathbf{r}}(s) ds = I(t)
    $$
    [S1, unofficial]
    Let $Y = -\log(1 - y_f u)$. We need to find $t$ such that $I(t) = Y$.

5.  **Find Bin:** Evaluate the precomputed cumulative integrals $I_i$ at the knots. Find the index $n$ such that $I_n \le Y < I_{n+1}$. This identifies the interval $[t_n, t_{n+1}]$ containing the solution $t$.
    *Edge Case:* If $Y \ge I_m$, set $t = t_m$ (or $t_f$). If $Y < I_1$, set $t = t_1$.

6.  **Solve for $t$:** Within the bin $[t_n, t_{n+1}]$, the integral $I(t)$ is quadratic. Let $\Delta t = t - t_n$. The integral from $t_n$ to $t$ is:
    $$
    \int_{t_n}^t \sigma_{\mathbf{r}}(s) ds = \sigma_n \Delta t + \frac{\sigma_{n+1} - \sigma_n}{2(t_{n+1} - t_n)} (\Delta t)^2
    $$
    Set this equal to $Y - I_n$:
    $$
    \frac{\sigma_{n+1} - \sigma_n}{2(t_{n+1} - t_n)} (\Delta t)^2 + \sigma_n \Delta t - (Y - I_n) = 0
    $$
    This is a quadratic equation $A (\Delta t)^2 + B \Delta t + C = 0$ where:
    $$
    A = \frac{\sigma_{n+1} - \sigma_n}{2(t_{n+1} - t_n)}, \quad B = \sigma_n, \quad C = -(Y - I_n)
    $$
    Solve for $\Delta t$ using the quadratic formula. Since $\sigma \ge 0$ and $Y \ge I_n$, we select the positive root that lies within $[0, t_{n+1} - t_n]$.
    $$
    \Delta t = \frac{-B + \sqrt{B^2 - 4AC}}{2A} \quad \text{(if } A \neq 0 \text{)}
    $$
    If $A \approx 0$ (linear density), solve linearly: $\Delta t = -C/B$.
    Then $t = t_n + \Delta t$.
    [S1, unofficial]
    *Note:* The solution $t$ is a differentiable function of $\sigma_{\mathbf{r}}$ and $c_{\mathbf{r}}$, allowing gradients to back-propagate through $t$ [S1, unofficial].

7.  **Evaluate Radiance:** Evaluate the radiance $c_{\mathbf{r}}(t)$ at the computed sample position $t$. If $t$ falls between knots, interpolate $c_{\mathbf{r}}$ similarly to $\sigma_{\mathbf{r}}$ or use the nearest knot value depending on implementation [G].

8.  **Accumulate Color:** Accumulate the color estimate using the standard volume rendering equation with the computed sample weights derived from the CDF differences or exponential transmittance [S1, unofficial].

**Parameters:**
- $k=32$ samples per ray [S1, unofficial].
- $m=256$ knots [S1, unofficial].
- Activation function for density field: Softplus with $\beta=10$ [S1, unofficial].

**Pitfalls:**
- Using ReLU activation for the density field can result in zero gradients, hindering training [S1, unofficial].
- Numerical stability in solving the quadratic equation when $\sigma_{n+1} \approx \sigma_n$ [S1, unofficial].

## Subtopics

### [Boundary Path Integral Formulation](3389-boundary-path-integral-formulation.md)
Uses boundary terms for gradient estimation. Choose when ray endpoints are the primary differentiable parameters.

### [Reparameterized Monte Carlo Volume Rendering](4798-reparameterized-monte-carlo-volume-rendering.md)
Uses auxiliary coarse models for importance sampling. Choose when hierarchical sampling is required for complex scenes, but note it does not allow differentiating w.r.t. coarse model parameters directly.

## Operating characteristics
- **Time Complexity:** $O(m)$ to precompute integrals and find the bin, $O(1)$ to solve for $t$ per sample. Total $O(k)$ per ray for $k$ samples.
- **Memory Complexity:** $O(m)$ to store knot positions and cumulative integrals.
- **Performance:** In the 'foggy' density field test, 32 samples matched the baseline performance of 128 samples [S1, unofficial]. In 'Glass and wall' and 'Wall' fields, 4 samples matched baseline [S1, unofficial].
- **Strengths:** Lower variance than naive importance sampling [S1, unofficial]. End-to-end differentiable without auxiliary networks [S1, unofficial].
- **Limitations:** Requires piecewise linear approximation of density; piecewise constant was faster but delivered worse quality [S1, unofficial].

## Background
Originated in the paper "Differentiable Rendering With Reparameterized Volume Sampling" [S1, unofficial]. It applies reparameterization techniques to estimate gradients of path-traced images with respect to scene parameters [S1, unofficial]. It is used in 3D scene reconstruction based on image projections, benchmarked on synthetic data from NeRF [S1, unofficial].
