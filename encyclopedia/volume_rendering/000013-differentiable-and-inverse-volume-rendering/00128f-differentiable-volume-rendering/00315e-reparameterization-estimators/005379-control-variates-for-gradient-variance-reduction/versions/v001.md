# Control Variates for Gradient Variance Reduction

Also called: Gradient control variates, Variance reduction via control variates

## Overview
Control variates for gradient variance reduction is a technique that reduces the variance of gradient estimators in differentiable volume rendering by leveraging the statistical property that the expected gradient of the weight term is zero [S1]. It sets itself apart from sibling methods like shift maps by explicitly constructing a correlated control estimator from the Jacobian weights of the reparameterization, rather than relying solely on path correlation through random number reuse [S1]. It addresses the high variance inherent in the gradient of the weight term $w_i(\theta)$ when the integrand $f$ is smooth or constant [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Scene parameters $\theta$, reference parameters $\theta_0$ (typically the current parameters from the previous iteration or a fixed baseline), sampling points $y_i$ from a fixed reference domain, transformation $T(y_i, \theta)$, integrand $f(T(y_i, \theta), \theta)$, and probability density $k$.
*   **Outputs:** An unbiased gradient estimator $\frac{\partial E'}{\partial \theta}$ with reduced variance.

**Data Structures:**
*   **Weights $w_i(\theta)$:** A scalar value per sample $i$, defined as the ratio of the probability density at the transformed point under current parameters to that under reference parameters:
    $$ w_i(\theta) = \frac{k(T(y_i, \theta), \theta)}{k(T(y_i, \theta_0), \theta_0)} $$
*   **Control Variate Parameter $\alpha$:** A scalar coefficient, typically approximated as the average value of $f$ or a running average, which must be independent of the specific weights $w_i(\theta)$ of the current sample set to avoid bias [S1].

**Numbered Steps:**
1.  **Sample and Transform:** For each sample $i \in \{1, \dots, N\}$, generate $y_i$ from the fixed reference distribution and compute the transformed position $x_i = T(y_i, \theta)$.
2.  **Compute Weights:** Calculate the weight $w_i(\theta)$ for the current parameters $\theta$ and the reference weight $w_i(\theta_0)$ (which is typically 1 if $\theta_0$ is the primal state, but generally computed for consistency) [S1].
3.  **Evaluate Integrand:** Compute $f_i = f(T(y_i, \theta), \theta)$.
4.  **Construct Control Variate Estimator:** Form the intermediate estimator $E'$ using the control variate formula:
    $$ E' = \frac{1}{N} \sum_{i=1}^N \left[ f_i w_i(\theta) + \alpha(w_i(\theta) - w_i(\theta_0)) \right] $$
    Note that $\mathbb{E}[w_i(\theta) - w_i(\theta_0)] = 0$, so $E'$ is unbiased [S1].
5.  **Differentiate:** Compute the gradient of $E'$ with respect to $\theta$. Since $w_i(\theta_0)$ is constant with respect to $\theta$, its derivative is zero:
    $$ \frac{\partial E'}{\partial \theta} = \frac{1}{N} \sum_{i=1}^N \frac{\partial}{\partial \theta} \left[ f_i w_i(\theta) + \alpha w_i(\theta) \right] $$
    $$ \frac{\partial E'}{\partial \theta} = \frac{1}{N} \sum_{i=1}^N \left( \frac{\partial f_i}{\partial \theta} w_i(\theta) + f_i \frac{\partial w_i(\theta)}{\partial \theta} + \alpha \frac{\partial w_i(\theta)}{\partial \theta} \right) $$
    $$ \frac{\partial E'}{\partial \theta} = \frac{1}{N} \sum_{i=1}^N \left( \frac{\partial f_i}{\partial \theta} w_i(\theta) + (f_i + \alpha) \frac{\partial w_i(\theta)}{\partial \theta} \right) $$
6.  **Return Gradient:** Return the computed sum as the gradient estimate.

**Formulas:**
*   **Weight:** $w_i(\theta) = \frac{k(T(y_i, \theta), \theta)}{k(T(y_i, \theta_0), \theta_0)}$ [S1].
*   **Optimal $\alpha$:** $\alpha = -\frac{\text{Cov}(E, F)}{\text{Var}(F)}$, where $E$ is the original gradient estimator and $F$ is the control variate estimator $\frac{\partial F}{\partial \theta} = \frac{1}{N} \sum \frac{\partial w_i(\theta)}{\partial \theta}$ [S1]. In practice, $\alpha$ is approximated (e.g., as $-c$ if $f(x)=c$, or as a running average of $f$) [S1].
*   **Gradient Estimator:** $\frac{\partial E'}{\partial \theta} = \frac{1}{N} \sum \frac{\partial}{\partial \theta} [ f(T(y_i, \theta), \theta) w_i(\theta) + \alpha w_i(\theta) ]$ [S1].

**Parameters:**
*   **$\alpha$:** The control variate coefficient. Optimal value is $-\frac{\text{Cov}(E, F)}{\text{Var}(F)}$. Practical approximation: average of $f$ or constant $c$ if $f$ is constant [S1].
*   **$\theta_0$:** Reference parameters. Often set to $\theta$ for the primal pass, but for gradient estimation, it serves as the baseline for the weight ratio [S1].

**Edge Cases and Pitfalls:**
*   **Bias from $\alpha$:** The parameter $\alpha$ must be independent of the weights $w_i(\theta)$ to avoid introducing bias in the gradient of $E'$ [S1]. If $\alpha$ is computed using the same samples $w_i(\theta)$, the estimator becomes biased. Cross-weighting schemes or using uncorrelated estimates are required to estimate $\alpha$ without bias [S1].
*   **Constant Integrand:** If $f(x) = c$, the variance of the gradient can be completely eliminated if $\alpha = -c$ [S1].
*   **Smoothness:** The variance reduction is most effective when $f$ is a smooth function with small gradients with respect to $\theta$ [S1].

            # In many implementations, w_i(theta_0) is precomputed or 1.
            # Here we assume w_i_ref is the weight at theta_0.
            # If theta_0 is the "primal" state, w_i(theta_0) = 1.
            # Let's stick to the general formula: w_i(theta_0) = k(T(y_i, theta_0), theta_0) / k(T(y_i, theta_0), theta_0) = 1.

## Subtopics

### Variation Reduction for Gradient Estimators
A variant that reduces variance by tracing pairs of correlated paths that reuse certain random numbers and combining their estimates using control variates [S1]. It is similar to shift maps [Kettunen et al. 2015; Lehtinen et al. 2013] in sampling correlated paths, and similar to Rousselle et al. [2016] in applying control variates to gradient estimates [S1].

## Operating characteristics
*   **Time Complexity:** Adds minimal overhead to the standard reparameterization estimator, primarily the computation of the additional term $\alpha \frac{\partial w_i}{\partial \theta}$ and the storage of $\alpha$ [S1].
*   **Memory Complexity:** Requires storing the reference parameters $\theta_0$ and potentially precomputed weights $w_i(\theta_0)$ if not computed on the fly [S1].
*   **Performance:** Significant variance reduction is achieved with low performance overhead [S1]. For constant $f$, variance can be eliminated with optimal $\alpha$ [S1].
*   **Strengths:** Effective for smooth integrands; reduces variance of the weight gradient term which is often the dominant source of variance in reparameterization estimators [S1].
*   **Limitations:** Requires careful choice of $\alpha$ to avoid bias; $\alpha$ must be independent of the current weights [S1]. Performance gain depends on the correlation between $E$ and $F$ [S1].
*   **When to use:** When gradient variance is high due to the Jacobian weight term, especially for smooth scenes or constant integrands [S1].
*   **When not to use:** When $f$ has large gradients or discontinuities that break the smoothness assumption, or when computing $\alpha$ without bias is too costly [S1].

## Background
Originated in the context of differentiable rendering, specifically in the paper "Reparameterizing discontinuous integrands for differentiable rendering" [S1]. It builds on the general control variates method from statistics [S1] and applies it to the gradient of reparameterized rendering integrals. It is related to shift maps [Kettunen et al. 2015; Lehtinen et al. 2013] and Rousselle et al. [2016] who applied control variates to image-space gradients [S1].
