# Reparametrized Integral Gradients

Also called: Bias Removal via Reparameterization, Loubet et al. method, Moving visibility discontinuities, Path Space Sampling, Reparameterization for Discontinuous Integrands, Reparameterized Differentiable Path Tracing

## Overview
Reparametrized Integral Gradients is a technique for differentiable rendering that eliminates bias in gradients caused by visibility discontinuities moving with scene parameters [S1, S3]. Unlike explicit edge sampling methods that require detecting and sampling geometric boundaries, this method applies a change of variables to transform the integration domain such that discontinuities become static (parameter-independent) [S1][S2, unofficial]. This allows differentiation under the integral sign without boundary terms, making it computationally efficient for complex scenes, though it approximates gradients and has limitations with specular materials [S2, S5, unofficial].

## How it works
The method addresses the rendering integral $I(\theta)$ where the integrand $f(x, \theta)$ contains discontinuities at positions $T(\theta)$ that depend on parameters $\theta$ [S2, unofficial]. Naïve differentiation yields incorrect gradients because the domain of integration or the location of discontinuities shifts [S3].

**Inputs:**
*   Scene parameters $\theta$ (e.g., object position, shape coefficients).
*   Integrals over domains $\Omega_\theta$ containing discontinuities dependent on $\theta$.

**Outputs:**
*   Gradient $\frac{\partial I}{\partial \theta}$ estimated via Monte Carlo sampling on a fixed domain.

**Data Structures:**
*   Transformation function $T(\omega, \theta): \Omega \to \Omega_\theta$ mapping a fixed reference domain $\Omega$ to the parameter-dependent domain.
*   Jacobian determinant $J(\omega, \theta) = \left| \det \frac{\partial T}{\partial \omega} \right|$.

**Steps:**
1.  **Identify Discontinuities:** Locate points in the integrand where visibility or material properties change abruptly, and determine how these points $T(\theta)$ move as $\theta$ changes [S2, unofficial].
2.  **Construct Transformation:** Define a differentiable transformation $T(\omega, \theta)$ that "warps" the domain such that the discontinuity in the transformed integrand is stationary [S1][S4, unofficial]. Specifically, choose $T$ such that if the original discontinuity is at $T(\theta)$, the transformed discontinuity $\omega_0$ satisfies $T(\omega_0, \theta) = T(\theta)$ and $\frac{\partial \omega_0}{\partial \theta} = 0$ [S5, unofficial].
3.  **Reparameterize Integral:** Apply the change of variables to move the integral from $\Omega_\theta$ to the fixed domain $\Omega$:
    $$
    I(\theta) = \int_{\Omega} f(T(\omega, \theta), \theta) \left| \det \frac{\partial T}{\partial \omega} \right| d\omega
    $$
    The discontinuities in the new integrand $g(\omega, \theta) = f(T(\omega, \theta), \theta) \left| \det \frac{\partial T}{\partial \omega} \right|$ are now at fixed locations $\omega_0$ [S1][S2, unofficial].
4.  **Differentiate:** Since the domain $\Omega$ and discontinuity locations are static, differentiate under the integral sign:
    $$
    \frac{\partial I}{\partial \theta} = \int_{\Omega} \frac{\partial}{\partial \theta} \left[ f(T(\omega, \theta), \theta) \left| \det \frac{\partial T}{\partial \omega} \right| \right] d\omega
    $$
    No boundary term arises from the Reynolds Transport Theorem [S2, unofficial][S3].
5.  **Estimate:** Use Monte Carlo sampling on $\Omega$ to estimate the gradient:
    $$
    \hat{\nabla}_\theta I = \frac{1}{N} \sum_{i=1}^N \nabla_\theta \left[ \frac{f(T(\omega_i, \theta), \theta) \left| \det \frac{\partial T}{\partial \omega} \right|}{p(\omega_i)} \right]
    $$
    where $\omega_i \sim p(\omega)$ [S2, unofficial].

    N = len(samples)
    
    for omega in samples:
        # 1. Map reference sample to parameter-dependent domain
        x = transform(omega, theta)
        
        # 2. Compute Jacobian determinant of the transformation
        # Note: In practice, this requires analytical or AD-computed derivatives
        # of the warp field T with respect to omega.
        jacobian_det = compute_jacobian_determinant(omega, theta)
        
        # 3. Evaluate integrand at transformed point
        # f(x, theta) is the original rendering integrand (e.g., radiance)
        integrand_value = evaluate_integrand(x, theta)
        
        # 4. Form the transformed integrand
        # g(omega, theta) = f(T(omega, theta), theta) * |det(dT/domega)|
        transformed_integrand = integrand_value * abs(jacobian_det)
        
        # 5. Compute gradient of the transformed integrand w.r.t theta
        # This involves chain rule: df/dx * dx/dtheta + df/dtheta
        # The discontinuity in f is now static in omega, so standard AD works
        # on the composition, provided T is smooth enough.
        grad_integrand = compute_gradient_wrt_theta(transformed_integrand, theta)
        
        # 6. Accumulate gradient estimate
        # Weight by inverse PDF of the reference distribution p(omega)
        # Assuming uniform sampling for simplicity:
        grad_sum += grad_integrand / p(omega)
        
    return grad_sum / N

**Parameters:**
*   **Warp Field Construction:** The transformation $R$ (e.g., spherical rotation) must approximate the motion of the discontinuity such that $\frac{\partial R}{\partial \pi} \approx \frac{\partial T}{\partial \pi}$ [S5, unofficial].
*   **Sampling:** Samples $\omega$ are drawn from a fixed distribution $p(\omega)$ on the reference domain [S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Specular Materials:** The method does not support perfectly specular materials because the discontinuities in specular reflections cannot be easily reparameterized with a simple continuous warp [S2, unofficial].
*   **Dirac Delta Lights:** Degenerate light sources containing Dirac delta functions are not supported [S2, unofficial].
*   **Multiple Discontinuities:** The method struggles if multiple discontinuities exist within the support of the integrand, as a single global warp may not stabilize all of them [S2, unofficial].
*   **Approximation Error:** Gradients are approximated; if the warp field does not perfectly match the discontinuity motion, bias may remain [S2, S5, unofficial].
*   **Complexity:** Constructing the correct warp field can be non-trivial for complex geometries [S1].

## Subtopics

### Spherical Rotation Reparameterization
Spherical Rotation Reparameterization is a specific instance of reparametrized integral gradients introduced by Loubet et al. [S5, unofficial]. It reparameterizes spherical integrals (e.g., for environment lighting or reflection) using spherical rotations to avoid explicit sampling of discontinuities [S5, unofficial]. It sets the rotation $R$ such that $\partial R / \partial \pi = \partial T / \partial \pi$, making the discontinuity point $\omega_0$ independent of $\pi$ [S5, unofficial]. The integral becomes $I = \int_{S^2} f(R(\omega, \pi)) d\sigma(\omega)$ [S5, unofficial]. It is chosen when the primary discontinuities are on the sphere and can be approximated by rotations. It is limited by the approximation error of the rotation field [S5, unofficial].

## Operating characteristics
*   **Time Complexity:** Comparable to standard path tracing, as it avoids the overhead of explicit edge detection and sampling [S2, unofficial]. However, it requires computing the Jacobian and its derivative, which may add computational cost per sample [S2, unofficial].
*   **Memory Complexity:** Low, similar to standard path tracing, as it does not require storing edge lists or complex data structures for discontinuity tracking [S2, unofficial].
*   **Performance:** Computationally efficient for scenes with many moving discontinuities where edge sampling would be expensive [S2, unofficial].
*   **Strengths:** Eliminates bias from moving discontinuities without explicit edge sampling; works well with automatic differentiation [S1, S3].
*   **Limitations:** Does not support perfectly specular materials, Dirac delta lights, or multiple discontinuities in one integrand; gradients are approximate [S2, unofficial].
*   **When to Use:** When scene parameters cause visibility changes (e.g., object translation) and explicit edge sampling is too costly or complex.
*   **When Not to Use:** For scenes with specular reflections, point lights, or complex multi-discontinuity integrands [S2, unofficial].

## Background
Reparametrized Integral Gradients was introduced by Loubet et al. in "Reparameterizing Discontinuous Integrands for Differentiable Rendering" at SIGGRAPH Asia 2019 [S4, S5, unofficial]. It emerged as an alternative to explicit edge sampling (Li et al. 2018) and path space sampling (Zhang et al. 2020) to address bias in differentiable rendering caused by moving visibility discontinuities [S3][S4, unofficial]. The method is implemented in differentiable rendering systems like Mitsuba 3 [S4, unofficial].
