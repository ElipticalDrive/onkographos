# Reparametrized Integral Gradients

Also called: Reparameterized Integral Gradients, Loubet et al. method, Reparameterization for Discontinuous Integrands

## Overview
Reparametrized Integral Gradients is a technique for differentiable rendering that eliminates bias in gradients caused by visibility discontinuities moving with scene parameters [S3]. Unlike explicit edge sampling methods that require detecting and sampling geometric boundaries, this method applies a change of variables to transform the integration domain such that discontinuities become static (parameter-independent) [S1][S3]. This allows differentiation under the integral sign without boundary terms, making it computationally efficient for complex scenes, though it approximates gradients and has limitations with specular materials [S2, unofficial].

## How it works
The method addresses the rendering integral $I(\theta)$ where the integrand $f(x, \theta)$ contains discontinuities at positions dependent on parameters $\theta$ [S3]. Naïve differentiation yields incorrect gradients because the domain of integration or the location of discontinuities shifts [S3].

**Inputs:**
*   Scene parameters $\theta$ (e.g., camera position, light source position, triangle mesh vertices) [S3].
*   Integrals over domains $\Omega_\theta$ containing discontinuities dependent on $\theta$ [S3].

**Outputs:**
*   Gradient $\frac{\partial I}{\partial \theta}$ estimated via Monte Carlo sampling on a fixed domain [S3].

**Data Structures:**
*   Transformation function $T(\omega, \theta): \Omega \to \Omega_\theta$ mapping a fixed reference domain $\Omega$ to the parameter-dependent domain [S3].
*   Jacobian determinant $J(\omega, \theta) = \left| \det \frac{\partial T}{\partial \omega} \right|$ [S3].

**Steps:**
1.  **Identify Discontinuities:** Locate points in the integrand where visibility or material properties change abruptly, and determine how these points move as $\theta$ changes [S3].
2.  **Construct Transformation:** Define a differentiable transformation $T(\omega, \theta)$ that "warps" the domain such that the discontinuity in the transformed integrand is stationary [S1][S3]. Specifically, choose $T$ such that it yields the identity map when $\theta = \theta_0$ (the parameter value for which gradients are evaluated) [S3].
3.  **Reparameterize Integral:** Apply the change of variables to move the integral from $\Omega_\theta$ to the fixed domain $\Omega$:
    $$
    I(\theta) = \int_{\Omega} f(T(\omega, \theta), \theta) \left| \det \frac{\partial T}{\partial \omega} \right| d\omega
    $$
    The discontinuities in the new integrand $g(\omega, \theta) = f(T(\omega, \theta), \theta) \left| \det \frac{\partial T}{\partial \omega} \right|$ are now at fixed locations [S1][S3].
4.  **Differentiate:** Since the domain $\Omega$ and discontinuity locations are static, differentiate under the integral sign:
    $$
    \frac{\partial I}{\partial \theta} = \int_{\Omega} \frac{\partial}{\partial \theta} \left[ f(T(\omega, \theta), \theta) \left| \det \frac{\partial T}{\partial \omega} \right| \right] d\omega
    $$
    No boundary term arises from the Reynolds Transport Theorem [S3].
5.  **Estimate:** Use Monte Carlo sampling on $\Omega$ to estimate the gradient: Draw samples $y_i$ from a probability density function $p(y)$ that does not depend on $\theta$ [S3]. Evaluate the transformed integrand, density, and Jacobian determinant [S3]. Compute the estimator $E = \frac{1}{N} \sum \frac{f(T(y_i, \theta), \theta) |\det J_T|}{p(y_i)}$ [S3]. Apply automatic differentiation to $E$ with respect to $\theta$ to obtain the gradient [S3].

**Pseudocode:**
```python

    """
    Estimate gradient of rendering integral using reparameterization.
    theta: Current scene parameters.
    theta_0: Parameter value for which gradients are evaluated (identity point).
    samples: Array of points omega drawn from fixed reference distribution p(omega).
    p: PDF function for the reference distribution.
    integrand_fn: Function evaluating f(x, theta).
    """
    grad_sum = 0.0
    N = len(samples)
    for omega in samples:
        # 1. Map reference sample to parameter-dependent domain
        x = transform(omega, theta, theta_0)
        
        # 2. Compute Jacobian determinant |det(dT/domega)|
        jacobian_det = compute_jacobian_determinant(omega, theta, theta_0)
        
        # 3. Evaluate integrand at transformed point
        f_val = integrand_fn(x, theta)
        
        # 4. Form the transformed integrand
        transformed_val = f_val * abs(jacobian_det)
        
        # 5. Compute gradient of the transformed integrand w.r.t theta
        # Using automatic differentiation on the composition
        grad_val = compute_gradient_wrt_theta(transformed_val, theta)
        
        # 6. Accumulate gradient estimate weighted by inverse PDF
        grad_sum += grad_val / p(omega)
        
    return grad_sum / N
```

**Parameters:**
*   **Sample count:** The method produces high-quality gradients at low sample counts, specifically demonstrated at 64 samples per pixel (spp) [S3].
*   **$\theta_0$:** The specific value of the scene parameter $\theta$ for which gradients are evaluated; $T$ must be identity at this value [S3].
*   **Sampling density $p$:** Must not depend on $\theta$, otherwise discontinuities are reintroduced [S3].

**Edge Cases and Pitfalls:**
*   **Specular Materials:** The method does not support perfectly specular materials because the discontinuities in specular reflections cannot be easily reparameterized with a simple continuous warp [S2, unofficial].
*   **Dirac Delta Lights:** Degenerate light sources containing Dirac delta functions are not supported [S2, unofficial].
*   **Multiple Discontinuities:** The method struggles if multiple discontinuities exist within the support of the integrand, as a single global warp may not stabilize all of them [S2, unofficial].
*   **Approximation Error:** Gradients are approximated and may not always be accurate [S2, unofficial].
*   **Small Angular Support:** The method assumes integrands have small angular support (e.g., due to narrow BSDFs or small lights), where discontinuities consist of the silhouette of a single object [S3].

## Subtopics

### [Warped-Area Sampling](8835-warped-area-sampling.md)
Warped-Area Sampling (WAS) is an unbiased method for differentiable rendering that eliminates the need for explicit boundary sampling by reparameterizing boundary integrals into interior integrals using a continuous warp field. It builds on Reparametrized Integral Gradients but improves upon the biased spherical rotation approach of Loubet et al. by satisfying the strict continuity requirements of the divergence theorem.

### [Spherical Rotation Reparameterization](8848-spherical-rotation-reparameterization.md)
Spherical Rotation Reparameterization is a technique for differentiable volume rendering that eliminates discontinuities in gradient estimates by applying a spherical rotation to the integration domain. It solves the problem of non-differentiable integrals caused by scene parameters $\theta$ shifting discontinuity points across the sphere. Unlike Warped-Area Sampling, which explicitly samples and integrates over discontinuity boundaries, this method makes the discontinuity point parameter-independent through a change of variables, thereby removing the need for explicit boundary sampling.

## Operating characteristics
*   **Time Complexity:** Comparable to standard path tracing, as it avoids the overhead of explicit edge detection and sampling [S2, unofficial]. However, it requires computing the Jacobian and its derivative, which may add computational cost per sample [S2, unofficial].
*   **Memory Complexity:** Low, similar to standard path tracing, as it does not require storing edge lists or complex data structures for discontinuity tracking [S2, unofficial].
*   **Performance:** Computationally efficient for scenes with many moving discontinuities where edge sampling would be expensive [S2, unofficial].
*   **Strengths:** Eliminates bias from moving discontinuities without explicit edge sampling; works well with automatic differentiation [S1, S3].
*   **Limitations:** Does not support perfectly specular materials, Dirac delta lights, or multiple discontinuities in one integrand; gradients are approximate [S2, unofficial].
*   **When to Use:** When scene parameters cause visibility changes (e.g., object translation) and explicit edge sampling is too costly or complex [S3].
*   **When Not to Use:** For scenes with specular reflections, point lights, or complex multi-discontinuity integrands [S2, unofficial].

## Background
Reparametrized Integral Gradients was introduced by Loubet et al. in "Reparameterizing Discontinuous Integrands for Differentiable Rendering" at SIGGRAPH Asia 2019 [S5, unofficial]. Unlike previous work (e.g., Li et al. 2018) which requires explicit sampling of silhouette edges, this method avoids edge sampling entirely by using changes of variables [S3]. The open source implementation of the method is part of version 2 of the Mitsuba renderer [S3].
