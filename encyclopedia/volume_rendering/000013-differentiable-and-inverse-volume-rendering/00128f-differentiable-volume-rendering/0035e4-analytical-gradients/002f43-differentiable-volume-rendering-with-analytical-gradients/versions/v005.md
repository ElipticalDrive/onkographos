# Differentiable Volume Rendering with Analytical Gradients
Also called: Analytical Differentiable Rendering, DiffRenderer
## Overview
A rendering technique that computes radiance and its analytical derivatives with respect to volume density directly, avoiding the overhead of propagating gradients through long computational graphs inherent in automatic differentiation [S1]. It solves the problem of inefficient optimization for dynamic volumetric densities, such as in fluid reconstruction, by providing a closed-form gradient calculation that scales better than standard backpropagation [S1]. It sets itself apart from siblings like [Differentiable Volume Rendering via Box Splines](2449-differentiable-volume-rendering-via-box-splines.md) by relying on explicit chain-rule expansion of the discrete emission-absorption model rather than basis function properties.

## How it works
**Inputs:** Ray origin $\mathbf{x}_a$, ray direction $\boldsymbol{\omega}$, step size $\triangle d$, and volume density field $\sigma(\mathbf{x})$.
**Outputs:** Radiance $L(\mathbf{x}, \boldsymbol{\omega})$ and its analytical gradient with respect to density parameters.

**Data Structures:**
*   Ray state: Current position $x_u$, accumulated transmittance $\tau$, accumulated radiance $L_{ss}$.
*   Density field: Accessible via interpolation or lookup.

**Steps:**
1.  Initialize accumulated radiance $L_{ss} \leftarrow 0$ and transmittance $\tau \leftarrow 1$ [S1].
2.  Iterate along the ray from $x_a$ to $x_b$ with step size $\triangle d$ [S1].
3.  Advance ray position: $x_u \rightarrow x_u + \boldsymbol{\omega} \triangle d$ [S1].
4.  Sample density $\sigma_i$ at $x_u$.
5.  Compute local transmittance factor $T_i = \exp(-\sigma_i \triangle d)$.
6.  Update accumulated transmittance: $\tau \leftarrow \tau \cdot T_i$.
7.  Compute emitted radiance contribution: $J_{ss}(\mathbf{v}_{x_u}, \boldsymbol{\omega})$ based on the density and view direction [S1].
8.  Update accumulated radiance: $L_{ss}(\mathbf{x}, \boldsymbol{\omega}) \leftarrow L_{ss}(\mathbf{x}, \boldsymbol{\omega}) + \tau(\mathbf{v}_{x_u}, \mathbf{v}_{x_b}) \kappa_t(\dots)$ [S1].
9.  Compute analytical gradient $\frac{\partial L}{\partial \sigma_i}$ using the explicit chain rule expansion described in the parent article [S1].

**Pseudocode:**
```python
def render_and_gradient(ray_origin, ray_dir, density_field, step_size):
    # Initialization
    current_pos = ray_origin
    accumulated_transmittance = 1.0
    accumulated_radiance = 0.0
    gradient_accumulator = 0.0
    
    # Ray marching loop
    while current_pos is within bounds:
        # Advance ray position
        current_pos = current_pos + ray_dir * step_size
        
        # Sample density
        sigma = density_field.sample(current_pos)
        
        # Compute local transmittance
        local_transmittance = exp(-sigma * step_size)
        
        # Update accumulated transmittance
        accumulated_transmittance = accumulated_transmittance * local_transmittance
        
        # Compute emitted radiance contribution (simplified model)
        # Note: Exact emission function J_ss depends on specific physics model [S1]
        emission = compute_emission(sigma, current_pos, ray_dir)
        
        # Update accumulated radiance
        # Note: Exact weighting function depends on specific physics model [S1]
        accumulated_radiance = accumulated_radiance + accumulated_transmittance * emission
        
        # Compute analytical gradient w.r.t sigma
        # Term 1: Direct emission derivative
        # Term 2: Transmittance derivative affecting subsequent steps
        # dL/d_sigma = T_i * (1 - exp(-sigma*delta))' * c_i + sum_{j>i} ...
        # For single step approximation or specific physics model [S1]:
        grad_term_direct = accumulated_transmittance * step_size * exp(-sigma * step_size) * emission
        grad_term_indirect = -accumulated_radiance * step_size # Simplified propagation [S1]
        
        gradient_accumulator = gradient_accumulator + grad_term_direct + grad_term_indirect
        
    return accumulated_radiance, gradient_accumulator
```

**Parameters:**
*   Step size $\triangle d$: Determines sampling resolution. Not given in the sources.
*   Density field $\sigma(\mathbf{x})$: Typically a 3D grid or neural network. Not given in the sources.

**Edge cases:**
*   Singularities in density fields must be handled to ensure numerical stability of the analytical derivatives [S1].
*   Boundary conditions for ray marching must be defined to prevent out-of-bounds memory access.

## Subtopics

### [Differentiable Moment Bounds](8855-differentiable-moment-bounds.md)
Computes continuously differentiable upper and lower bounds on cumulative mass using power moments. It solves the truncated Hamburger moment problem and is distinguished by its robust, numerically stable implementation that handles singularities, enabling use in differentiable rendering pipelines where gradients with respect to scene parameters are required.

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of samples per ray, $O(N)$, similar to standard volume rendering, but with a higher constant factor due to gradient computation.
*   **Memory Complexity:** $O(1)$ auxiliary memory per ray, as it avoids storing the full computational graph required by automatic differentiation [S1].
*   **Strengths:** Significantly reduces overhead for optimizing dynamic volumetric densities compared to automatic differentiation [S1].
*   **Limitations:** Requires manual derivation of gradients for each specific rendering equation variant.
*   **When to use:** Fluid reconstruction tasks and dynamic volumetric density optimization where performance is critical [S1].

## Background
Originated in the context of physics-based differentiable rendering for fluid modeling from monocular video [S1]. The work builds upon insights that automatic differentiation (AD) fundamentally relies on propagating gradients through long computational graphs, which carries inherent overhead compared to direct analytical computation [S1]. The method was proposed to improve performance for optimizing dynamic volumetric densities [S1].
