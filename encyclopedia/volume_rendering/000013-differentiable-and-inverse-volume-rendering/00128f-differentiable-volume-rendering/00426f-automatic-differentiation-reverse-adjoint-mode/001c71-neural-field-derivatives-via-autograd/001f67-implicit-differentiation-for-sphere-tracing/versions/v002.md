# Implicit Differentiation for Sphere Tracing

Also called: Implicit Differentiation for Sphere Tracing Gradients, Sphere Tracing Gradients via Implicit Differentiation

## Overview
This method computes the gradients of the sphere tracing output with respect to input parameters (such as SDF parameters) using implicit differentiation, avoiding the need to backpropagate through the iterative sphere tracing loop [S1, unofficial]. It differs from naive backpropagation by treating the converged ray positions as fixed points and computing gradients via the chain rule on the SDF evaluation, while explicitly handling the convergence mask [S1, unofficial].

## How it works
**Inputs:**
- `signed_distance_function`: A differentiable function $f(\mathbf{p}, \theta)$ mapping 3D positions $\mathbf{p}$ and model parameters $\theta$ to signed distances [S1, unofficial].
- `positions`: The converged ray positions after sphere tracing, shape $(N, 3)$ [S1, unofficial].
- `directions`: The ray directions for each point, shape $(N, 3)$ [S1, unofficial].
- `converged`: A boolean mask indicating which rays successfully converged, shape $(N,)$ [S1, unofficial].
- `grad_outputs`: The upstream gradient flowing back from the loss with respect to the output positions, shape $(N, 3)$ [S1, unofficial].
- `parameters`: The learnable parameters $\theta$ of the SDF [S1, unofficial].

**Outputs:**
- `grad_parameters`: The gradients of the loss with respect to the model parameters $\theta$ [S1, unofficial].

**Data Structures:**
- Tensors are assumed to be floating-point tensors for positions, directions, and parameters, with a boolean tensor for the convergence mask [G].

**Steps:**
1. **Detach Positions:** The converged positions are detached from the computational graph to prevent backpropagation through the sphere tracing iterations [S1, unofficial].
2. **Re-evaluate SDF:** Compute the signed distance values and their gradients with respect to the detached positions [S1, unofficial].
   $$ d = f(\mathbf{p}, \theta) $$
   $$ \nabla_{\mathbf{p}} d = \frac{\partial d}{\partial \mathbf{p}} $$
   This is computed using automatic differentiation with `retain_graph=True` [S1, unofficial].
3. **Project Output Gradient:** Compute the dot product of the upstream gradient $\mathbf{g}_{\text{out}}$ and the ray direction $\mathbf{v}$ [S1, unofficial].
   $$ g_{\text{dot}} = \mathbf{g}_{\text{out}} \cdot \mathbf{v} = \sum_{i=1}^3 g_{\text{out}, i} v_i $$
   Shape: $(N, 1)$ [S1, unofficial].
4. **Project SDF Gradient:** Compute the dot product of the SDF spatial gradient $\nabla_{\mathbf{p}} d$ and the ray direction $\mathbf{v}$ [S1, unofficial].
   $$ p_{\text{dot}} = \nabla_{\mathbf{p}} d \cdot \mathbf{v} = \sum_{i=1}^3 \frac{\partial d}{\partial p_i} v_i $$
   Shape: $(N, 1)$ [S1, unofficial].
5. **Regularize Denominator:** To avoid division by zero when the ray direction is tangent to the surface ($p_{\text{dot}} \approx 0$), clamp the denominator away from zero [S1, unofficial]. If $p_{\text{dot}} > 0$, clamp to $\max(p_{\text{dot}}, \epsilon)$; if $p_{\text{dot}} \le 0$, clamp to $\min(p_{\text{dot}}, -\epsilon)$, where $\epsilon = 10^{-6}$ [S1, unofficial].
   $$ p_{\text{dot}}^{\text{reg}} = \begin{cases} \max(p_{\text{dot}}, 10^{-6}) & \text{if } p_{\text{dot}} > 0 \\ \min(p_{\text{dot}}, -10^{-6}) & \text{if } p_{\text{dot}} \le 0 \end{cases} $$
6. **Compute Intermediate Gradient:** Apply the implicit differentiation formula [S1, unofficial].
   $$ \mathbf{g}_{\text{param\_input}} = -\frac{g_{\text{dot}}}{p_{\text{dot}}^{\text{reg}}} $$
   Shape: $(N, 1)$ [S1, unofficial].
7. **Mask Unconverged Points:** Zero out gradients for rays that did not converge, as their positions are not well-defined by the SDF root [S1, unofficial].
   $$ \mathbf{g}_{\text{masked}} = \mathbf{g}_{\text{param\_input}} \odot \mathbb{I}(\text{converged}) $$
   Shape: $(N, 1)$ [S1, unofficial].
8. **Backpropagate to Parameters:** Compute the final gradients with respect to the model parameters $\theta$ using the masked scalar gradient [S1, unofficial].
   $$ \nabla_{\theta} L = \frac{\partial d}{\partial \theta} \cdot \mathbf{g}_{\text{masked}} $$
   This is computed via `autograd.grad` with `outputs=d`, `inputs=parameters`, and `grad_outputs=g_masked` [S1, unofficial].

**Pseudocode:**
```python
import torch

def implicit_diff_sphere_tracing(
    signed_distance_function,
    positions,
    directions,
    converged,
    grad_outputs,
    parameters
):
    """
    Compute gradients for sphere tracing using implicit differentiation.
    
    Args:
        signed_distance_function: Callable f(p, params) -> distances
        positions: Tensor (N, 3), converged ray positions
        directions: Tensor (N, 3), ray directions
        converged: Tensor (N,), boolean mask of converged rays
        grad_outputs: Tensor (N, 3), upstream gradients w.r.t positions
        parameters: Tensor or list of Tensors, model parameters
        
    Returns:
        grad_parameters: Gradients w.r.t parameters
    """
    # 1. Detach positions to break the iterative loop graph
    p_detached = positions.detach()
    p_detached.requires_grad_(True)
    
    # 2. Compute SDF and its spatial gradient
    signed_distances = signed_distance_function(p_detached, parameters)
    
    # Compute gradient of SDF w.r.t positions
    grad_positions, = torch.autograd.grad(
        outputs=signed_distances,
        inputs=p_detached,
        grad_outputs=torch.ones_like(signed_distances),
        retain_graph=True,
    )
    
    # 3. Dot product of output gradient and ray direction
    grad_outputs_dot_directions = torch.sum(grad_outputs * directions, dim=-1, keepdim=True)
    
    # 4. Dot product of SDF gradient and ray direction
    grad_positions_dot_directions = torch.sum(grad_positions * directions, dim=-1, keepdim=True)
    
    # 5. Regularize denominator to avoid division by zero
    epsilon = 1e-6
    grad_positions_dot_directions = torch.where(
        grad_positions_dot_directions > 0,
        torch.max(grad_positions_dot_directions, torch.full_like(grad_positions_dot_directions, epsilon)),
        torch.min(grad_positions_dot_directions, torch.full_like(grad_positions_dot_directions, -epsilon))
    )
    
    # 6. Compute intermediate gradient using implicit differentiation formula
    grad_intermediate = -grad_outputs_dot_directions / grad_positions_dot_directions
    
    # 7. Zero out gradients for unconverged points
    grad_intermediate = torch.where(converged.unsqueeze(-1), grad_intermediate, torch.zeros_like(grad_intermediate))
    
    # 8. Compute final parameter gradients
    grad_parameters = torch.autograd.grad(
        outputs=signed_distances,
        inputs=parameters,
        grad_outputs=grad_intermediate,
        retain_graph=True,
    )
    
    return grad_parameters
```

**Parameters:**
- `epsilon`: Regularization constant for the denominator. Default value: $10^{-6}$ [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Division by Zero:** Occurs when the ray direction is tangent to the surface, making $\nabla_{\mathbf{p}} d \cdot \mathbf{v} = 0$ [S1, unofficial].
- **Unconverged Rays:** Rays that fail to converge within the iteration limit or tolerance should have their gradients zeroed out, as the position is not a valid root of the SDF [S1, unofficial].
- **Graph Detachment:** It is critical to detach the positions before re-evaluating the SDF [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Strengths:** Avoids the computational overhead of backpropagating through the iterative sphere tracing loop [S1, unofficial].
- **Limitations:** Only valid for converged points and requires a differentiable SDF [S1, unofficial].
- **When to use:** When gradients with respect to SDF parameters are needed for differentiable rendering [S1, unofficial].
- **When not to use:** When gradients with respect to ray origins or directions are required [S1, unofficial].

## Background
This method is documented in a repository named Sphere-Tracing-PyTorch3D [S1, unofficial]. It leverages implicit differentiation to differentiate through the fixed-point iteration of sphere tracing, a common technique in differentiable rendering and inverse graphics [S1, unofficial]. The approach avoids the need to manually derive the Jacobian of the sphere tracing iteration or backpropagate through the loop [S1, unofficial].
