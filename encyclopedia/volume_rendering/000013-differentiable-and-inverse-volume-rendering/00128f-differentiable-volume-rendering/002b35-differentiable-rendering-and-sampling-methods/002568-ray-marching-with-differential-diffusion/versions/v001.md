# Ray Marching with Differential Diffusion

Also called: Differentiable Ray Marching with Gradient Recording, Ray Marching for Rendering and Gradient Accumulation

## Overview
Ray Marching with Differential Diffusion is a differentiable volume rendering method that computes single and multiple scattering radiance alongside their derivatives with respect to density simultaneously [S1, S2]. It solves the problem of efficient gradient accumulation for density optimization by storing intermediate gradient contributions in a dedicated structure, avoiding the need for a separate backward pass or on-the-fly recomputation [S1]. Unlike [Monte Carlo Radiance Estimate for Scene Reconstruction](1119-monte-carlo-radiance-estimate-for-scene-reconstruction.md) which relies on stochastic sampling, this method uses deterministic ray marching with pre-computed diffusion terms [S2]. It differs from [Image-based Transfer Function Optimization via Automatic Differentiation](4372-image-based-transfer-function-optimization-via-automatic-dif.md) by explicitly modeling the physics of participating media (single/multiple scattering) rather than optimizing transfer functions directly on image space [S2].

## How it works
### Inputs and Outputs
**Inputs:**
*   Density field $\rho$ [S1, S2].
*   Extinction coefficient $\kappa_t$ (where $\kappa_t = \sigma_t \rho$) [S1, S2].
*   Incoming radiance $L_{in}$ [S1, S2].
*   Pre-computed radiance terms $Q_{0,ri}, Q_{1,ri}$ and their derivatives $\dot{Q}_{0,ri}, \dot{Q}_{1,ri}$ [S1].
*   Source term field $S$ [S2].
*   Absorption coefficient $\kappa_a$ [S2].
*   Voxel edge length $h$ (uniform 3D grid assumption) [S2].
*   Sampling step length $\Delta d$ [S2].

**Outputs:**
*   Rendered image $L_{out}$ [S1, S2].
*   Gradient records `densityADRec` [S1].

### Data Structures
**densityADRec:**
For each pixel $(i, j)$, this structure contains two lists:
1.  `position`: Stores the voxel positions $x_u$ visited along the ray [S1].
2.  `grad`: Stores the corresponding gradient contributions $\dot{L}_{out}(x_u, \omega)$ [S1].

*Note: The gradient computed at $x_u$ is associated with the integer voxel coordinates $v_{x_u}$ containing $x_u$. During density updates, this gradient is implicitly scattered to the 8 neighbors of $v_{x_u}$ when trilinear updates are employed [S1].*

### Precomputation
Before ray marching, a precomputation function initializes variables to avoid redundant calculations during the march [S2].
1.  Solve the diffusion equation iteratively (e.g., using the Jacobi method) to compute diffusion radiance $L^0_d$, its derivative $\partial_\pi L^0_d$, and the diffusion radiance derivative $\vec{L}^1_d$ and its derivative $\partial_\pi \vec{L}^1_d$ [S2].
2.  Store $L_{ri}$, $L^0_d$, $\vec{L}^1_d$ and their derivatives $\partial_\pi L_{ri}$, $\partial_\pi L^0_d$, $\partial_\pi \vec{L}^1_d$ as voxels [S2].

### Ray Marching Steps
The algorithm marches along rays from the camera through the volume. The direction $\omega$ points from the view point into the scene (or vice versa depending on convention; S1 uses $\omega$ as direction of travel for scattering, S2 defines $\omega$ as ray direction). We follow the accumulation logic from the sources.

1.  **Initialize:** For each pixel, generate ray. Determine hit points $x_a$ (entry) and $x_b$ (exit) [S1, S2]. Set current position $x_u = x_b$ (S1) or $x_u = x_a$ (S2). *Note: S1 marches from back to front ($x_b$ to $x_a$), S2 marches from front to back ($x_a$ to $x_b$) but calculates transmittance back to $x_b$. We describe the general accumulation logic.* Let $D_b$ be the distance from the current position to the view point (or exit point) [S2]. Let $D_{max}$ be the total path length $\|x_b - x_a\|$ [S1].

2.  **Loop:** Repeat while the distance traveled or remaining exceeds the threshold (S1: $D_u > D_{max}$ is a typo in source, likely $D_u < D_{max}$ or loop until exit; S2: $D_u \ge D_b$) [S1, S2].
    *   **Fetch Data:** Sample $\rho(x_u)$, $\kappa_t(x_u)$, and pre-computed terms ($Q_{0,ri}, Q_{1,ri}, \dot{Q}_{0,ri}, \dot{Q}_{1,ri}$) using trilinear interpolation from their respective voxel grids [S1]. Identify voxel position $v_{x_u}$ [S1].
    *   **Compute In-Scattered Radiance:**
        *   Compute $J_{ss}(x_u, \omega)$ and $J_{ms}(x_u, \omega)$ using pre-computed terms and equations [S1, S2].
        *   Specifically, $J_{ss} = \Omega(Q_{0,ri} + Q_{1,ri}\omega)$ [S1].
    *   **Compute Derivatives:**
        *   Compute $\dot{J}_{ss}$ and $\partial_\pi J_{ms}$ using the derivatives of the pre-computed terms [S1, S2].
        *   Specifically, $\dot{J}_{ss} = \Omega(\dot{Q}_{0,ri} + \dot{Q}_{1,ri}\omega)$ [S1].
    *   **Accumulate Radiance and Gradient:**
        *   Calculate transmittance $\tau(v_{x_u}, v_{x_b})$ from current voxel to the exit/view point [S2].
        *   Update Single Scattering Radiance $L_{ss}$:
            $$L_{ss} \leftarrow L_{ss} + \tau(v_{x_u}, v_{x_b}) \kappa_t(v_{x_u}) J_{ss}(v_{x_u}, \omega) \Delta d$$ [S1, S2]
        *   Update Single Scattering Gradient $\dot{L}_{ss}$ (or $\partial_\pi L_{ss}$):
            $$\dot{L}_{ss} \leftarrow \dot{L}_{ss} + \tau \kappa_t \dot{J}_{ss} \Delta d + (\partial_\pi \tau \kappa_t + \tau \partial_\pi \kappa_t) J_{ss} \Delta d$$ [S2]
            *Note: S1 simplifies this by storing contributions in `densityADRec`. The term $\partial_\pi \tau$ depends on $\partial_\pi \kappa_t$.*
        *   Update Multiple Scattering Radiance $L_{ms}$ and Gradient $\partial_\pi L_{ms}$ similarly using $J_{ms}$ and $\partial_\pi J_{ms}$ [S2].
        *   Update Direct Transmission $L_{ri}$ and Gradient $\partial_\pi L_{ri}$ using pre-computed values [S2].
    *   **Store Gradient (S1 specific):** Store $x_u$ and $\dot{L}_{out}(x_u, \omega)$ in `densityADRec` [S1].
    *   **Advance:** $x_u \leftarrow x_u + \omega \Delta d$ [S1, S2]. Recalculate distance $D_u$ [S2].

3.  **Finalize:**
    *   Compute final $L_{ri}$ and $\partial_\pi L_{ri}$ if not fully accumulated during the loop [S1, S2].
    *   Sum components:
        $$L_{out} = L_{ms} + L_{ri} + L_{ss}$$ [S2]
        $$\partial_\pi L_{out} = \partial_\pi L_{ms} + \partial_\pi L_{ri} + \partial_\pi L_{ss}$$ [S2]
    *   Output $L_{out}$ and `densityADRec` [S1].

            L_ss += term_ss

### Pitfalls
*   **Memory Usage:** Storing `densityADRec` increases memory usage significantly compared to methods that recompute gradients on-the-fly, as it stores position and gradient contributions for every sample point along every ray [S1].
*   **Precision:** Trilinear interpolation is used for fetching data, which may introduce smoothing artifacts in gradients if the density field is highly discontinuous [S1].
*   **Boundary Conditions:** The hit point calculation ($x_a, x_b$) must be robust to avoid rays missing the volume or entering/exiting incorrectly, which would break the transmittance accumulation [S1, S2].

## Subtopics

### Precomputation of Diffusion Terms
Uses the diffusion equation to approximate multiple scattering and direct transmission, storing them as voxel grids to accelerate ray marching [S2].

### Gradient Recording (densityADRec)
A data structure that stores intermediate gradient contributions during the forward pass, enabling efficient density updates without a full backward pass [S1].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of samples per ray and the number of pixels. The precomputation step adds an initial cost proportional to the volume size [S1, S2].
*   **Memory Complexity:** High. Requires storage for the density grid, coefficient grids, pre-computed radiance grids, and the `densityADRec` structure which scales with the number of samples [S1].
*   **Strengths:** Efficient gradient computation for density optimization; avoids the variance of Monte Carlo methods; leverages pre-computation for speed [S1, S2].
*   **Limitations:** High memory consumption due to gradient recording; assumes uniform grid (S2) or requires careful interpolation (S1); limited to participating media with specific scattering models [S1, S2].
*   **When to use:** When optimizing density fields for smoke/volumetric reconstruction and memory is not the primary constraint [S1].
*   **When not to use:** When real-time performance is critical and memory is limited; when the volume is not represented on a uniform grid (S2 assumption) [S2].

## Background
This method originates from research in differentiable volume rendering for smoke reconstruction and participating media simulation [S1, S2]. It builds upon the physics-based differentiable renderer framework [S1] and differential diffusion theory for participating media [S2]. The approach was developed to address the computational cost of backpropagation in volumetric rendering by caching gradient contributions [S1].
