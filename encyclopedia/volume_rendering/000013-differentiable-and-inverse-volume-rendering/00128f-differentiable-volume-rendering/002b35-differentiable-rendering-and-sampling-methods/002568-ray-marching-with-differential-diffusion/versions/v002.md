# Ray Marching with Differential Diffusion

Also called: Differentiable Ray Marching with Gradient Recording, Ray Marching for Gradient Accumulation

## Overview
Ray Marching with Differential Diffusion computes single and multiple scattering radiance alongside their derivatives with respect to density simultaneously [S1, S2]. It solves the gradient accumulation problem for density optimization by storing intermediate gradient contributions in a dedicated structure, avoiding a separate backward pass or on-the-fly recomputation [S1]. Unlike [Monte Carlo Radiance Estimate for Scene Reconstruction](1119-monte-carlo-radiance-estimate-for-scene-reconstruction.md) which relies on stochastic sampling, this method uses deterministic ray marching with pre-computed diffusion terms [S2]. It differs from [Image-based Transfer Function Optimization via Automatic Differentiation](4372-image-based-transfer-function-optimization-via-automatic-dif.md) by explicitly modeling participating media physics rather than optimizing image-space transfer functions [S2].

## How it works
### Inputs and Outputs
**Inputs:**
*   Density field $\rho$ [S1, S2].
*   Extinction coefficient $\kappa_t = \sigma_t \rho$ [S1, S2].
*   Incoming radiance $L_{in}$ [S1, S2].
*   Pre-computed radiance terms $Q_{0,ri}, Q_{1,ri}$ and their derivatives $\dot{Q}_{0,ri}, \dot{Q}_{1,ri}$ [S1].
*   Source term field $S$ [S2].
*   Absorption coefficient $\kappa_a$ [S2].
*   Voxel edge length $h$ (uniform 3D grid assumption) [S2].
*   Sampling step length $\Delta d$ [S2].

**Outputs:**
*   Rendered image $L_{out}$ [S1, S2].
*   Gradient records `densityADRec` [S1].

### Data Structures
**densityADRec:**
For each pixel $(i, j)$, this structure contains two lists:
1.  `position`: Stores the voxel positions $x_u$ visited along the ray [S1].
2.  `grad`: Stores the corresponding gradient contributions $\dot{L}_{out}(x_u, \omega)$ [S1].
The gradient computed at $x_u$ is associated with the integer voxel coordinates $v_{x_u}$ containing $x_u$ [S1]. During density updates, this gradient is implicitly scattered to the 8 neighbors of $v_{x_u}$ when trilinear updates are employed [S1].

### Precomputation
Before ray marching, a precomputation function initializes variables to avoid redundant calculations during the march [S2].
1.  Solve the diffusion equation iteratively (e.g., using the Jacobi method) to compute diffusion radiance $L^0_d$, its derivative $\partial_\pi L^0_d$, and the diffusion radiance derivative $\vec{L}^1_d$ and its derivative $\partial_\pi \vec{L}^1_d$ [S2].
2.  Store $L_{ri}$, $L^0_d$, $\vec{L}^1_d$ and their derivatives $\partial_\pi L_{ri}$, $\partial_\pi L^0_d$, $\partial_\pi \vec{L}^1_d$ as voxels [S2].

### Ray Marching Steps
1.  **Initialize:** For each pixel, generate a ray and determine entry $x_a$ and exit $x_b$ points [S1, S2]. S1 initializes $x_u = x_b$ and marches back-to-front; S2 initializes $x_u = x_a$ and marches front-to-back [S1, S2]. Let $D_{max} = \|x_b - x_a\|$ [S1]. Let $D_b$ be the distance from the exit point to the view point [S2].
2.  **Loop:** S1 repeats while $D_u < D_{max}$; S2 repeats while $D_u \ge D_b$ [S1, S2].
    *   **Fetch Data:** Sample $\rho(x_u)$, $\kappa_t(x_u)$, and pre-computed terms ($Q_{0,ri}, Q_{1,ri}, \dot{Q}_{0,ri}, \dot{Q}_{1,ri}$) using trilinear interpolation from their voxel grids [S1]. Identify voxel position $v_{x_u}$ [S1].
    *   **Compute In-Scattered Radiance:** Compute $J_{ss}(x_u, \omega)$ using pre-computed terms [S1]. Specifically, $J_{ss} = \Omega(Q_{0,ri} + Q_{1,ri}\omega)$ [S1]. Compute $J_{ms}(x_u, \omega)$ using Equation 3 [S2].
    *   **Compute Derivatives:** Compute $\dot{J}_{ss}$ using the derivatives of the pre-computed terms [S1]. Specifically, $\dot{J}_{ss} = \Omega(\dot{Q}_{0,ri} + \dot{Q}_{1,ri}\omega)$ [S1]. Compute $\partial_\pi J_{ms}$ using Equation 8 [S2].
    *   **Accumulate Radiance and Gradient:** Calculate transmittance $\tau(v_{x_u}, v_{x_b})$ from the current voxel to the exit/view point [S2]. Update Single Scattering Radiance $L_{ss}$: $L_{ss} \leftarrow L_{ss} + \tau \kappa_t J_{ss} \Delta d$ [S1, S2]. Update Single Scattering Gradient: $\dot{L}_{ss} \leftarrow \dot{L}_{ss} + \tau \kappa_t \dot{J}_{ss} \Delta d + (\partial_\pi \tau \kappa_t + \tau \partial_\pi \kappa_t) J_{ss} \Delta d$ [S2]. Update Multiple Scattering Radiance $L_{ms}$ and Gradient $\partial_\pi L_{ms}$ similarly [S2]. Update Direct Transmission $L_{ri}$ and Gradient $\partial_\pi L_{ri}$ using pre-computed values [S2].
    *   **Store Gradient (S1 specific):** Store $x_u$ and $\dot{L}_{out}(x_u, \omega)$ in `densityADRec` [S1].
    *   **Advance:** $x_u \leftarrow x_u + \omega \Delta d$ [S1, S2]. Recalculate distance $D_u$ [S2].
3.  **Finalize:** Compute final $L_{ri}$ and $\partial_\pi L_{ri}$ if not fully accumulated during the loop [S1, S2]. Sum components: $L_{out} = L_{ms} + L_{ri} + L_{ss}$ [S2]. $\partial_\pi L_{out} = \partial_\pi L_{ms} + \partial_\pi L_{ri} + \partial_\pi L_{ss}$ [S2]. Output $L_{out}$ and `densityADRec` [S1].

def ray_marching_differential_diffusion(
    rho_grid, kappa_t_grid, L_in,
    Q0_ri_grid, Q1_ri_grid, Q0_dot_ri_grid, Q1_dot_ri_grid,
    S_grid, kappa_a_grid, h, delta_d, pixel_indices,
    volume_min, volume_max
):
    """
    Computes radiance and gradients for differentiable volume rendering.
    Implements S1's back-to-front march with gradient recording.
    """
    L_out = {}
    density_AD_Rec = {}

    for idx in pixel_indices:
        ray_origin, ray_direction = generate_ray(idx, pixel_indices, volume_min, volume_max)
        omega = -ray_direction  # Direction of travel into volume (3D vector)
        x_a, x_b = ray_box_intersection(ray_origin, omega, volume_min, volume_max)

        # S2: Precomputation step (simplified)
        Lri_grid, Lri_dot_grid = precompute_diffusion(S_grid, kappa_a_grid, kappa_t_grid, h)

        L_ms = 0.0
        L_ms_dot = 0.0
        L_ss = 0.0
        L_ss_dot = 0.0
        L_ri = 0.0
        L_ri_dot = 0.0

        # S1: March from back (xb) to front (xa)
        x_u = x_b
        D_max = norm(x_b - x_a)
        D_u = 0.0

        density_AD_Rec[idx] = {'position': [], 'grad': []}

        while D_u < D_max:
            # 1. Fetch Data
            rho_val = trilinear_interpolate(rho_grid, x_u)
            kappa_t_val = trilinear_interpolate(kappa_t_grid, x_u)
            
            Q0 = trilinear_interpolate(Q0_ri_grid, x_u)
            Q1 = trilinear_interpolate(Q1_ri_grid, x_u)
            Q0_dot = trilinear_interpolate(Q0_dot_ri_grid, x_u)
            Q1_dot = trilinear_interpolate(Q1_dot_ri_grid, x_u)
            
            v_xu = get_voxel_index(x_u, h)

            # 2. Compute In-Scattered Radiance (Single Scattering)
            J_ss = dot_3(Q1, omega) + Q0
            J_ss_dot = dot_3(Q1_dot, omega) + Q0_dot

            # 3. Compute Transmittance from xu to xb
            tau_xu_xb = compute_transmittance(kappa_t_grid, x_u, x_b, omega, delta_d)
            tau_xu_xb_dot = compute_transmittance_derivative(kappa_t_grid, x_u, x_b, omega, delta_d)

            # 4. Accumulate Single Scattering
            term_ss = tau_xu_xb * kappa_t_val * J_ss * delta_d
            L_ss += term_ss
            
            # Gradient contribution for S1
            grad_contrib_ss = (tau_xu_xb * kappa_t_val * J_ss_dot + 
                               (tau_xu_xb_dot * kappa_t_val + tau_xu_xb * kappa_t_val) * J_ss) * delta_d

            # 5. Store Gradient Record (S1)
            density_AD_Rec[idx]['position'].append(x_u)
            density_AD_Rec[idx]['grad'].append(grad_contrib_ss)

            # 6. Advance
            x_u = x_u + omega * delta_d
            D_u = norm(x_u - x_a)

        # Final Summation (S2)
        L_ri_val = trilinear_interpolate(Lri_grid, x_b)
        L_ri_dot_val = trilinear_interpolate(Lri_dot_grid, x_b)
        L_out[idx] = L_ss + L_ri_val
        density_AD_Rec[idx]['final_grad'] = sum(density_AD_Rec[idx]['grad']) + L_ri_dot_val

    return L_out, density_AD_Rec

### Pitfalls
*   **Memory Usage:** Storing `densityADRec` increases memory usage significantly compared to methods that recompute gradients on-the-fly, as it stores position and gradient contributions for every sample point along every ray [S1].
*   **Precision:** Trilinear interpolation is used for fetching data, which may introduce smoothing artifacts in gradients if the density field is highly discontinuous [S1].
*   **Boundary Conditions:** The hit point calculation ($x_a, x_b$) must be robust to avoid rays missing the volume or entering/exiting incorrectly, which would break the transmittance accumulation [S1, S2].

## Subtopics

### Precomputation of Diffusion Terms
Uses the diffusion equation to approximate multiple scattering and direct transmission, storing them as voxel grids to accelerate ray marching [S2].

### Gradient Recording (densityADRec)
A data structure that stores intermediate gradient contributions during the forward pass, enabling efficient density updates without a full backward pass [S1].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of samples per ray and the number of pixels. The precomputation step adds an initial cost proportional to the volume size [S1, S2].
*   **Memory Complexity:** High. Requires storage for the density grid, coefficient grids, pre-computed radiance grids, and the `densityADRec` structure which scales with the number of samples [S1].
*   **Strengths:** Efficient gradient computation for density optimization; avoids the variance of Monte Carlo methods; leverages pre-computation for speed [S1, S2].
*   **Limitations:** High memory consumption due to gradient recording; assumes uniform grid (S2) or requires careful interpolation (S1); limited to participating media with specific scattering models [S1, S2].
*   **When to use:** When optimizing density fields for smoke/volumetric reconstruction and memory is not the primary constraint [S1].
*   **When not to use:** When the volume is not represented on a uniform grid (S2 assumption) or when strict memory budgets prohibit storing per-sample gradient records [S1, S2].

## Background
This method originates from research in differentiable volume rendering for smoke reconstruction and participating media simulation [S1, S2]. It builds upon the physics-based differentiable renderer framework [S1] and differential diffusion theory for participating media [S2]. The approach was developed to address the computational cost of backpropagation in volumetric rendering by caching gradient contributions [S1].
