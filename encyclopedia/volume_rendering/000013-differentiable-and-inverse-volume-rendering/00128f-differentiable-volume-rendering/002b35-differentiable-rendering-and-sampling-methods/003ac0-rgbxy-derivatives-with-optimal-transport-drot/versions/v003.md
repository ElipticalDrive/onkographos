# RGBXY Derivatives with Optimal Transport (DROT)

Also called: Basic, Hybrid

## Overview
RGBXY Derivatives with Optimal Transport (DROT) is a differentiable rendering method that associates each screen-space pixel with a visible 3D geometric point (point proxy) to compute 5D RGBXY derivatives, measuring how 3D RGB color and 2D projected screen-space position change with respect to scene parameters [S1]. It combines these dense derivatives with an optimal transport-based loss function to find pixel matching between rendered and target images, solving the convergence problem in inverse rendering when initial and target object locations are not close [S1]. Unlike traditional methods that rely on sparse, local per-pixel color derivatives and L2 loss, DROT captures global and long-range object motions, making it superior for optimizing global translations and rotations [S1].

## How it works
**Inputs:**
*   Scene parameters $\theta$ (e.g., transformation matrices for furniture models) [S1].
*   Target image $I_{\text{target}}$ (resolution $256 \times 256$ in experiments) [S1].
*   Camera parameters (intrinsics and extrinsics) [S1].
*   Scene geometry (e.g., triangle meshes) [S1].

**Outputs:**
*   Optimized scene parameters $\theta^*$ [S1].
*   Rendered image $I_{\text{rendered}}$ [S1].

**Data Structures:**
*   **Point Proxy:** For each pixel $(u, v)$ in the rendered image, the point proxy is the visible 3D geometric point on the mesh covered by the center of the pixel [S1].
*   **RGBXY Derivative Vector:** A 5-dimensional vector for each point proxy containing partial derivatives of the 3D RGB color values and the 2D screen-space coordinates $(X, Y)$ with respect to $\theta$ [S1].

**Steps:**
1.  Associate each screen-space pixel with the visible 3D geometric point covered by the center of the pixel, referred to as the point proxy [S1].
2.  For each point proxy, compute its 5D RGBXY derivatives to measure how its 3D RGB color and 2D XY screen-space position change with respect to desired scene parameters [S1].
3.  Leverage optimal transport to find a pixel matching between rendered and target images [S1].
4.  Design a novel loss function based on the pixel matching obtained from optimal transport [S1].
5.  Optimize scene parameters using the computed gradients from the loss function [S1].

**Formulas:**
The derivative vector $D$ for a proxy is defined as:
$$ D = \left[ \frac{\partial C_r}{\partial \theta}, \frac{\partial C_g}{\partial \theta}, \frac{\partial C_b}{\partial \theta}, \frac{\partial X}{\partial \theta}, \frac{\partial Y}{\partial \theta} \right]^T $$
where $C_r, C_g, C_b$ are the red, green, and blue color components, and $X, Y$ are the screen-space coordinates [S1].

**Edge Cases and Pitfalls:**
*   **Precision:** Occlusions or self-intersections can lead to incorrect proxies [G].
*   **Boundaries:** The method is designed to handle cases where initial and target object locations are far apart, but the optimal transport step may struggle if the images are completely disjoint or have significant noise [S1, G].
*   **Degenerate Input:** If the mesh has no visible surface for a pixel (e.g., background), the point proxy is undefined [G].
*   **Assumption:** The method assumes a foreground object covers the pixels of interest [G].

## Subtopics

### Basic
The core DROT method using RGBXY derivatives and optimal transport [S1]. It is chosen when global object motions need to be optimized from a distant initialization [S1]. [Link](4973-differentiable-rendering-and-sampling-methods.md)

### Hybrid
A combination of DROT with traditional differentiable rendering methods [S1]. It is chosen to further improve accuracy in inverse rendering tasks by leveraging the strengths of both approaches [S1]. [Link](4973-differentiable-rendering-and-sampling-methods.md)

    *   **Living Room Scene:** Basic method achieves MAE 8.562mm / PSNR 29.52; Hybrid achieves MAE 7.903mm / PSNR 35.95. Compared against PyTorch3D (278.9/16.91) and Nvdiffrast (317.3/16.56) [S1].
*   **Scaling:** Not given in the sources. [S1]
*   **Strengths:** Dense RGBXY derivatives and optimal transport allow for robust convergence in inverse rendering, especially for global and long-range object motions when initial and target positions are far apart [S1].
*   **Limitations:** Traditional differentiable rendering approaches are hard to converge when initial and target object locations are not close, and per-pixel color derivatives are sparse and local [S1].
*   **When to use:** Automatic furniture layout adjustment and other inverse rendering tasks where global object motions need to be optimized from a distant initialization [S1].
*   **When not to use:** Fine-scale geometry refinement with sufficiently overlapped and aligned image regions, where traditional per-pixel color derivatives are naturally well suited [S1].

## Background
RGBXY Derivatives with Optimal Transport (DROT) was introduced by Jiankai Xing, Houde Qian, and Kun Xu from BNRist, Department of CS&T, Tsinghua University, China [S1]. The method is inspired by Lagrangian fluid simulation and aims to address the convergence issues in inverse rendering optimizations [S1]. It was presented in the paper "Differentiable Rendering Using RGBXY Derivatives and Optimal Transport" [S1].
