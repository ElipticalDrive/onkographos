# Albedo-based Parameterization for Extinction

Also called: Albedo/Sigma_t Decoupling

## Overview
This parameterization strategy represents the medium as an albedo volume paired with the extinction coefficient ($\sigma_t$), decoupling the scattering coefficient to keep optimization gradients stable [S1, unofficial]. It avoids the instability of $\sigma_s / \sigma_t$ derivatives as extinction goes to zero [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A heterogeneous medium definition specifying either an albedo volume ($\alpha$) or the scattering coefficient ($\sigma_s$) directly; the two are mutually exclusive [S1, unofficial].
*   **Output:** A differentiable scene representation where the integrator queries $\sigma_s$ for shading, but gradients are computed with respect to the albedo and $\sigma_t$ parameters [S1, unofficial].

**Data Structures:**
The medium stores parameters marked with `ParamFlags` [S1, unofficial].
*   `sigma_t`: Marked as `ParamFlags::Differentiable` [S1, unofficial].
*   `albedo` (or `sigma_s` depending on parameterization): Marked as `ParamFlags::Differentiable` [S1, unofficial].
*   `scale`: Marked as `ParamFlags::NonDifferentiable` [S1, unofficial].

**Steps:**
1.  **Scene Construction:** The scene author chooses one of two parameterizations for the heterogeneous medium [S1, unofficial]:
    *   **Albedo-based:** Provide an albedo volume $\alpha(\mathbf{x})$ and extinction $\sigma_t(\mathbf{x})$ [S1, unofficial].
    *   **Direct Sigma_s:** Provide $\sigma_s(\mathbf{x})$ directly [S1, unofficial].
    *   *Constraint:* The two cannot be provided simultaneously [S1, unofficial].
2.  **Traversal Setup:** The ray traversal function (e.g., `traverse`) exposes whichever parameterization the scene provided alongside $\sigma_t$, never both [S1, unofficial]. It marks the exposed parameters as `ParamFlags::Differentiable` [S1, unofficial].
3.  **Querying:** The integrator always queries the scattering coefficient $\sigma_s$ for shading calculations [S1, unofficial].
    *   If the **Albedo-based** parameterization is used, $\sigma_s$ is derived from $\alpha$ and $\sigma_t$ during shading, but gradients are propagated through $\alpha$ and $\sigma_t$ [S1, unofficial].
    *   If the **Direct Sigma_s** parameterization is used, $\sigma_s$ is queried directly [S1, unofficial].
4.  **Gradient Handling:** Differentiability is handled via `ParamFlags` [S1, unofficial]. The query surface is fixed; the parameterization choice is a scene-authoring decision [S1, unofficial]. The caller enables gradients only on the marked parameters [S1, unofficial].

**Formulas:**
The relationship between albedo, scattering, and extinction is:
$$ \sigma_s(\mathbf{x}) = \alpha(\mathbf{x}) \cdot \sigma_t(\mathbf{x}) $$
$$ \sigma_a(\mathbf{x}) = \sigma_t(\mathbf{x}) - \sigma_s(\mathbf{x}) $$
Where:
*   $\alpha(\mathbf{x})$ is the single-scattering albedo (dimensionless, range $[0, 1]$) [G].
*   $\sigma_t(\mathbf{x})$ is the extinction coefficient [G].
*   $\sigma_s(\mathbf{x})$ is the scattering coefficient [G].
*   $\sigma_a(\mathbf{x})$ is the absorption coefficient [G].

**Pitfalls:**
*   **0/0 Instability:** Rebuilding $\sigma_s / \sigma_t$ from albedo and extinction at runtime results in $0/0$ wherever extinction vanishes ($\sigma_t \to 0$) [S1, unofficial].
*   **Solution:** Use a direct albedo lookup (e.g., `Medium::get_albedo`) which is cheaper and better-conditioned than reconstructing coefficients from ratios [S1, unofficial].

**Pseudocode:**
```python
class ParamFlags:
    Differentiable = 1
    NonDifferentiable = 0

class Medium:
    def __init__(self, parameterization_type, albedo_volume=None, sigma_s_volume=None, sigma_t_volume=None):
        self.parameterization_type = parameterization_type  # 'albedo' or 'sigma_s'
        self.albedo_volume = albedo_volume
        self.sigma_s_volume = sigma_s_volume
        self.sigma_t_volume = sigma_t_volume

        # Validate mutual exclusivity
        if parameterization_type == 'albedo':
            assert albedo_volume is not None and sigma_t_volume is not None
            assert sigma_s_volume is None
        elif parameterization_type == 'sigma_s':
            assert sigma_s_volume is not None
            assert albedo_volume is None and sigma_t_volume is None
        else:
            raise ValueError("Unknown parameterization type")

    def get_sigma_s(self, position):
        """Query scattering coefficient for shading."""
        if self.parameterization_type == 'albedo':
            alpha = self.albedo_volume.query(position)
            sigma_t = self.sigma_t_volume.query(position)
            return alpha * sigma_t
        elif self.parameterization_type == 'sigma_s':
            return self.sigma_s_volume.query(position)

    def get_differentiable_params(self):
        """Return parameters marked as differentiable for optimization."""
        params = []
        if self.parameterization_type == 'albedo':
            params.append({'name': 'albedo', 'volume': self.albedo_volume, 'flags': ParamFlags.Differentiable})
            params.append({'name': 'sigma_t', 'volume': self.sigma_t_volume, 'flags': ParamFlags.Differentiable})
        elif self.parameterization_type == 'sigma_s':
            params.append({'name': 'sigma_s', 'volume': self.sigma_s_volume, 'flags': ParamFlags.Differentiable})
        params.append({'name': 'scale', 'value': 1.0, 'flags': ParamFlags.NonDifferentiable})
        return params

    def get_albedo(self, position):
        """Direct albedo lookup for better conditioning."""
        if self.parameterization_type == 'albedo':
            return self.albedo_volume.query(position)
        else:
            # Not applicable for sigma_s parameterization; avoids 0/0 reconstruction
            return 0.0
```

## Subtopics

### Subsurface Scattering Parameter Conversion
Converts artistic subsurface scattering parameters (medium color $A$ and scattering distance $d$) into physical extinction ($\sigma_t$) and scattering ($\sigma_s$) coefficients for a homogeneous medium [S2, unofficial].

**Formulas:**
1.  Calculate $\alpha$ (single-scattering albedo) from medium color $A$ (Vec3f):
    $$ \alpha = 1 - \exp(-5.09406 \cdot A + 2.61188 \cdot A^2 - 4.31805 \cdot A^3) $$
2.  Calculate scaling factor $s$ from medium color $A$:
    $$ s = 1.9 - A + 3.5 \cdot (A - 0.8)^2 $$
3.  Calculate extinction $\sigma_t$ from scattering distance $d$:
    $$ \sigma_t = \frac{1}{d \cdot s} $$
4.  Calculate scattering $\sigma_s$ and absorption $\sigma_a$:
    $$ \sigma_s = \alpha \cdot \sigma_t $$
    $$ \sigma_a = \sigma_t - \sigma_s $$

## Operating characteristics
*   **Stability:** Avoids division by zero in gradient calculations when $\sigma_t$ approaches zero, keeping optimization gradients stable [S1, unofficial].
*   **Performance:** Direct albedo lookup (`Medium::get_albedo`) is cheaper than reconstructing $\sigma_s/\sigma_t$ ratios [S1, unofficial]. Tested on an NVIDIA A40 under CUDA/OptiX [S1, unofficial].
*   **Use Case:** Suitable for differentiable volume rendering where medium properties are optimized from image data, particularly in heterogeneous media [S1, unofficial].
*   **Limitations:** Requires the scene to be defined with the specific parameterization; the two parameterizations are mutually exclusive [S1, unofficial].

## Background
This method follows the Differential Delta Tracking (DRT) implementation, which pairs albedo with $\sigma_t$ to decouple the two and keep optimization gradients stable [S1, unofficial]. It is implemented in research branches of rendering engines like Mitsuba 3, where it is used to test gradient mean and variance against DRT implementations [S1, unofficial].
