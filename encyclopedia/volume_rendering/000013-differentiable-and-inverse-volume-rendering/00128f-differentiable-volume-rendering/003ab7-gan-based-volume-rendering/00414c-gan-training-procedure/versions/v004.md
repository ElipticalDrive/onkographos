# GAN Training Procedure

Also called: Min-Max Game Training

## Overview
Generative Adversarial Networks (GANs) train a generator against a discriminator to produce perceptually realistic outputs rather than merely minimizing pixelwise error [S2, unofficial][S3]. This perceptual advantage makes GANs well-suited for volume super-resolution, where Mean Squared Error (MSE)-optimized outputs tend toward oversmoothing [S2, unofficial]. The method solves the problem of generating high-fidelity volumetric visualizations by replacing explicit volume data with a computational process that maps viewpoints and transfer functions directly to images [Parent].

## How it works
The procedure consists of two neural networks: a generator that produces increasingly realistic images and a discriminator that distinguishes real images from generated ones, trained in a competitive framework [S3].

**Inputs and Outputs**
*   **Inputs:** Real images (ground truth), visualization parameters (e.g., viewpoint, transfer function), and optionally an opacity image (for translation GANs) [S1].
*   **Outputs:** Synthesized images from the generator; real/fake classification probabilities from the discriminator [S1, S3].

**Data Structures**
*   **Generator ($G$):** Neural network mapping visualization parameters to image space [S1, S3].
*   **Discriminator ($D$):** Neural network mapping image space to scalar probability of being real [S1, S3].
*   **Training Data:** Generated by performing volume rendering over a wide range of viewpoints and transfer functions (TFs). For each instance, the viewpoint is randomly generated, and the opacity TF is generated by sampling from a Gaussian Mixture Model (GMM) [S1]. The GMM samples 1 to 5 modes, each with a random mean, standard deviation, and amplitude relative to the scalar field range [S1].

**Algorithm Steps**
The GAN is trained to optimize the min-max game using minibatch stochastic gradient descent [S1]. The parameters are updated using the ADAM optimizer [S1]. The training loop alternates gradient descent steps for the discriminator and the generator [S1]:

1.  **Discriminator Update (Real):** Update discriminator parameters using a batch of real images and visualization parameters to minimize binary cross-entropy loss, encouraging the discriminator to predict these images as real [S1].
2.  **Synthesis:** Pass visualization parameters (and opacity image, if applicable) through the generator to synthesize images [S1].
3.  **Discriminator Update (Fake):** Update the discriminator to encourage a prediction of false for the synthesized images [S1].
4.  **Generator Update:** Update the generator’s parameters by tricking the discriminator, encouraging it to predict the synthesized images as being real [S1].

**Pseudocode**

```python
def train_gan(generator, discriminator, real_images, viz_params, opacity_images, 
              num_epochs, batch_size, lr, beta1, beta2, epsilon):
    """
    Trains a GAN using alternating gradient descent.
    
    Args:
        generator: The generator network G.
        discriminator: The discriminator network D.
        real_images: Tensor of ground truth images.
        viz_params: Tensor of visualization parameters (viewpoint, TF).
        opacity_images: Tensor of opacity images (optional, for translation GAN).
        num_epochs: Total number of training epochs.
        batch_size: Number of samples per minibatch.
        lr: Learning rate for ADAM optimizer.
        beta1: Beta1 hyperparameter for ADAM.
        beta2: Beta2 hyperparameter for ADAM.
        epsilon: Epsilon hyperparameter for ADAM.
    """
    # Initialize optimizers for both networks
    opt_G = Adam(generator.parameters(), lr=lr, betas=(beta1, beta2), eps=epsilon)
    opt_D = Adam(discriminator.parameters(), lr=lr, betas=(beta1, beta2), eps=epsilon)
    
    for epoch in range(num_epochs):
        for batch_real_images, batch_viz_params, batch_opacity in zip(real_images, viz_params, opacity_images):
            # --- Discriminator Update ---
            opt_D.zero_grad()
            
            # 1. Train on real images
            # Minimize binary cross-entropy loss encouraging D to predict 1 for real images
            pred_real = discriminator(batch_real_images)
            loss_D_real = binary_cross_entropy(pred_real, target=1.0)
            loss_D_real.backward()
            
            # 2. Synthesize fake images
            # Pass visualization parameters through generator
            if batch_opacity is not None:
                fake_images = generator(batch_viz_params, batch_opacity)
            else:
                fake_images = generator(batch_viz_params)
            
            # 3. Train on fake images
            # Minimize binary cross-entropy loss encouraging D to predict 0 for fake images
            pred_fake = discriminator(fake_images.detach()) # Detach to stop gradient flow to G
            loss_D_fake = binary_cross_entropy(pred_fake, target=0.0)
            loss_D_fake.backward()
            
            opt_D.step()
            
            # --- Generator Update ---
            opt_G.zero_grad()
            
            # 4. Update generator by tricking discriminator
            # Encourage D to predict 1 for fake images
            # Re-run generator to get fresh predictions (or use cached)
            if batch_opacity is not None:
                fake_images = generator(batch_viz_params, batch_opacity)
            else:
                fake_images = generator(batch_viz_params)
            
            pred_fake_for_G = discriminator(fake_images)
            loss_G = binary_cross_entropy(pred_fake_for_G, target=1.0)
            loss_G.backward()
            
            opt_G.step()
```

**Parameters**
*   **Optimizer:** ADAM [S1, S4].
*   **ADAM Hyperparameters:** $\epsilon = 10^{-8}$, $\beta_1 = 0.9$, $\beta_2 = 0.999$ [S4].
*   **L1 Loss Weight ($\lambda$):** In practice, $\lambda = 150$ preserves color and stabilizes training without overly blurring generated images [S1].

**Edge Cases and Pitfalls**
*   **Oversmoothing:** Standard MSE-optimized outputs tend toward oversmoothing, which GANs mitigate via perceptual loss [S2, unofficial].
*   **Training Instability:** High-resolution GANs can be unstable; progressive training strategies may be required [S1, Subtopics].
*   **Degenerate Input:** Randomly generated TFs from GMMs must cover the relevant scalar field range to ensure generalization [S1].

## Subtopics

### [Progressive GAN Discriminator](10312-progressive-gan-discriminator.md)
A convolutional discriminator that grows progressively in resolution to stabilize training and allow larger batch sizes at lower resolutions. It solves the instability inherent in training high-resolution GANs by starting with coarse shapes and gradually introducing fine details. Unlike standard ProgressiveGAN where the generator architecture grows, this variant keeps the generator fixed, increasing resolution by sampling rays more densely from the same implicit representation.

### Adversarial Loss for Ocean Geometry
Uses spatial discriminators for normal and roughness maps, and temporal discriminators for temporal coherence, to enforce that inferred data spatial distribution is similar to real data [S4]. The overall loss is defined as:
$$ L_{Total} = \alpha L_{Image} + \beta_1 L_{Dn} + \beta_2 L_{Dr} + \gamma_1 L_{Dtn} + \gamma_2 L_{Dtr} $$
where $\alpha, \beta_1, \beta_2, \gamma_1, \gamma_2$ are weights, and $L_{Dn}, L_{Dr}, L_{Dtn}, L_{Dtr}$ are the losses of the corresponding discriminators [S4]. Training involves alternating training of the four auxiliary discriminators and the generator, as typically done for GAN training [S4]. Sub-net1 and sub-net2 are trained together using $L_{Total}$ for 200 epochs [S4].

## Operating characteristics
*   **Complexity:** Not given in the sources.
*   **Performance:** Demonstrated effectiveness for super-resolution, style transfer, and image-to-image translation [S3].
*   **Hardware:** Experiments conducted on a single NVIDIA GeForce RTX 2080 SUPER GPU [S4].
*   **Strengths:** Produces perceptually realistic outputs, avoiding the oversmoothing typical of MSE-based methods [S2, unofficial].
*   **Limitations:** Training can be unstable, particularly at high resolutions, requiring techniques like progressive growing [S1].

## Background
GANs [81] and diffusion models [82] have emerged as pivotal techniques for generating and modifying high-quality images [S3]. GANs consist of two neural networks trained in a competitive framework [S3]. They have demonstrated effectiveness for a variety of tasks, including super-resolution, style transfer, and image-to-image translation [S3]. In the context of volume rendering, GANs are used to bypass explicit volume data, mapping viewpoints and transfer functions directly to images [Parent].
