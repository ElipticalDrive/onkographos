# Second Directional Derivative

Also called: First derivative of the gradient, Segunda derivada direcional

## Overview
The second directional derivative is a scalar attribute used in volume rendering to distinguish sharp edges from overlapping volumetric regions where gradient magnitude alone is insufficient [S1, unofficial]. It measures the rate of change of the intensity function along the direction of the gradient, providing higher precision in edge localization compared to simpler approximations like the Laplacian [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Scalar intensity field $f(\mathbf{x})$, its gradient $\nabla f$, and its Hessian matrix $\mathbf{H}f$.
- Output: Scalar field $f''$ representing the second directional derivative at each voxel.

**Data Structures:**
- $\nabla f$: A 3D vector field $(\partial_x f, \partial_y f, \partial_z f)$.
- $\mathbf{H}f$: A $3 \times 3$ symmetric matrix field containing second-order partial derivatives:
  $$
  \mathbf{H}f = \begin{bmatrix}
  \partial_{xx} f & \partial_{xy} f & \partial_{xz} f \\
  \partial_{yx} f & \partial_{yy} f & \partial_{yz} f \\
  \partial_{zx} f & \partial_{zy} f & \partial_{zz} f
  \end{bmatrix}
  $$

**Formula:**
The second directional derivative $f''$ is calculated as [S1, unofficial]:
$$
f'' = \frac{1}{||\nabla f||^2} (\nabla f)^T \mathbf{H} f \nabla f
$$
Where:
- $||\nabla f||^2$ is the squared magnitude of the gradient.
- $(\nabla f)^T$ is the transpose of the gradient vector.
- $\mathbf{H} f$ is the Hessian matrix.
- $\nabla f$ is the gradient vector.

**Pseudocode:**
```python
def compute_second_directional_derivative(field):
    """
    Computes the second directional derivative f'' = (grad^T * H * grad) / |grad|^2
    Assumes field is a 3D numpy array or similar tensor structure.
    """
    # 1. Compute Gradient
    # Gradient is a 4D array: (x, y, z, 3)
    grad = compute_gradient(field)
    
    # 2. Compute Hessian Matrix
    # Hessian is a 6D array: (x, y, z, 3, 3)
    # Due to symmetry, we only need to compute upper triangle or use symmetric kernel
    hessian = compute_hessian(field)
    
    # 3. Compute Squared Gradient Magnitude
    # |grad|^2 = grad_x^2 + grad_y^2 + grad_z^2
    grad_sq_mag = sum(grad**2, axis=-1) # Sum over the last dimension (3)
    
    # 4. Compute Quadratic Form: grad^T * H * grad
    # This results in a 3D array (x, y, z)
    # For each voxel, calculate v^T * H * v where v is the gradient vector
    # v^T * H is a vector (1x3)
    # (v^T * H) * v is a scalar (1x1)
    
    # Initialize result array
    result = np.zeros_like(grad_sq_mag)
    
    # Iterate over voxels (vectorized operation preferred in implementation)
    # Let g be the gradient vector (3,) and H be the Hessian matrix (3,3)
    # result = sum(sum(H * g), axis=1) * g ... wait, simpler:
    # temp = H @ g  -> (3,)
    # result = temp @ g -> scalar
    
    # Vectorized implementation:
    # grad shape: (X, Y, Z, 3)
    # hessian shape: (X, Y, Z, 3, 3)
    
    # Matrix multiplication: (X, Y, Z, 3, 3) @ (X, Y, Z, 3, 1) -> (X, Y, Z, 3, 1)
    # Using einsum or batched matmul
    # hessian_grad = np.einsum('ijklm,ijkm->ijlm', hessian, grad) # Result shape (X,Y,Z,3)
    # Actually, standard matmul for batched tensors:
    # hessian_grad = np.matmul(hessian, grad[..., None])[..., 0] # Shape (X,Y,Z,3)
    
    hessian_grad = np.einsum('...ij,...j->...i', hessian, grad)
    
    # Dot product: sum(hessian_grad * grad)
    quadratic_form = np.sum(hessian_grad * grad, axis=-1)
    
    # 5. Normalize by squared gradient magnitude
    # Avoid division by zero
    epsilon = 1e-10
    safe_mag = np.maximum(grad_sq_mag, epsilon)
    
    second_dir_deriv = quadratic_form / safe_mag
    
    return second_dir_deriv
```

**Parameters:**
- Not given in the sources.

**Edge Cases and Pitfalls:**
- **Division by Zero:** When the gradient magnitude is zero (e.g., in homogeneous regions), the denominator $||\nabla f||^2$ becomes zero. A small epsilon or a conditional check is required to prevent NaNs [G].
- **Approximation:** The function $f''$ can be approximated by the Laplacian operator ($\nabla^2 f$). This requires less computational cost but yields less precise results than the Hessian-based approach [S1, unofficial].
- **Precision:** The Hessian-based approach is more precise than the Laplacian approximation [S1, unofficial].

## Subtopics

### Edge Detection via Derivative Maximum
A method to find the location of a step edge in continuous unsampled data by finding the maximum of the derivative of the step response, which corresponds to the point-spread function [S2, unofficial]. The location is found by searching for the zero crossing of the second order derivative [S2, unofficial]. The step response for a Gaussian point-spread function with $s=1$ is given by $S(x) = \frac{1}{2} \text{erf}\left(\frac{x}{\sqrt{2}}\right) + \frac{1}{2}$ [S2, unofficial]. This method cannot be easily extended to sampled data fields. While data can be reconstructed, getting an accurate estimation of the edge location is generally not possible due to the partial volume effect (blurring of the step edge over a transition area) [S2, unofficial]. In 1D, the derivative of linearly interpolated data is piece-wise constant, so there is no unique place at which the maximum is located [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Computing the Hessian matrix requires second-order derivatives, which is more expensive than first-order gradient computation. The quadratic form calculation involves matrix-vector multiplication per voxel.
- **Memory Complexity:** Requires storage for the gradient field and the Hessian matrix field in addition to the input scalar field.
- **Strengths:** Provides a more precise edge localization than gradient magnitude alone, helping to distinguish edges from overlapping volumetric regions [S1, unofficial].
- **Limitations:** Higher computational cost than gradient magnitude or Laplacian approximation [S1, unofficial]. Sensitive to noise in the data due to second-order differentiation [G].
- **When to use:** When gradient magnitude is insufficient to distinguish edges from overlapping volumes [S1, unofficial].
- **When not to use:** When computational resources are limited and the Laplacian approximation is acceptable [S1, unofficial].

## Background
The second directional derivative was introduced as an attribute to distinguish edges from overlapping volumetric regions when gradient magnitude is insufficient [S1, unofficial]. It is defined as the second directional derivative of the intensity function, obtained by combining gradient magnitude and the Hessian matrix [S1, unofficial]. The calculation is defined according to Kniss, Kindlmann, and Hansen (2002) [S1, unofficial]. The concept is related to curvature, which is a metric computed by convolution of signals that describes contours of local shapes [S1, unofficial].
