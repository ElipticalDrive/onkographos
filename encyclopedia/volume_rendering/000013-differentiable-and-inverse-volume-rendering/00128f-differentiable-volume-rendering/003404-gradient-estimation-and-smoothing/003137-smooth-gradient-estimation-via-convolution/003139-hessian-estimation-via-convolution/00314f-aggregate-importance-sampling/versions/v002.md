# Aggregate Importance Sampling

Also called: AIS

## Overview
Aggregate Importance Sampling (AIS) is a sampling strategy to reduce function evaluations by importance-sampling the average of the convolution kernels across all dimensions or elements, rather than each individually [S1]. Unlike non-aggregate importance sampling, which samples each dimension optimally but individually (requiring $O(n)$ or $O(n^2)$ evaluations), AIS samples from a mixture distribution requiring only one function evaluation per iteration [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A scalar field function $f(\mathbf{x})$, the dimensionality $n$, and the differential quantity to estimate (e.g., Hessian elements) [S1].
*   **Output:** An unbiased estimator for the differential quantity computed with a single function evaluation per iteration [S1].

**Data Structures:**
*   **Aggregate Kernel:** A weighted sum of individual convolution kernels $K_i$ corresponding to each element of the differential representation [S1]. For a Hessian in $n$ dimensions, there are $n^2$ elements [S1]. The aggregate kernel $K_{agg}$ is defined as the average:
    $$ K_{agg}(\mathbf{x}) = \frac{1}{n^2} \sum_{i=1}^{n^2} K_i(\mathbf{x}) $$
*   **Sampling Distribution:** The probability density function (PDF) $p(\mathbf{x})$ used for sampling is derived from the aggregate kernel [S1].

**Steps:**
1. Randomly decide which element of the differential representation to choose (e.g., which matrix element out of $n^2$ in the Hessian) [S1].
2. Compute the convolution sample for all $n^2$ elements using the same function value (single rendering call), weighting each by its respective kernel [S1].

**Pseudocode:**
```python
import random

def aggregate_importance_sampling(f, n, num_samples):
    """Estimate differential quantity using AIS."""
    n2 = n * n
    estimator = [0.0] * n2  # [G] Standard Monte Carlo accumulator initialization
    for _ in range(num_samples):
        # Step 1: Randomly decide which element of the differential representation to choose
        k = random.randint(0, n2 - 1)
        # Step 2: Sample position from the aggregate distribution
        # [Comment: Sources do not specify the exact sampling algorithm for the mixture PDF.]
        x = sample_mixture_pdf(n)
        # Single function evaluation
        val = f(x)
        # Compute the convolution sample for all n^2 elements using the same function value
        # [Comment: Sources do not specify the exact kernel evaluation routine.]
        weights = [evaluate_kernel(j, x) for j in range(n2)]
        # Weight each by its respective kernel
        # [Comment: Sources do not specify the exact unbiased estimator scaling formula.]
        estimator[k] += val * weights[k]
    return [v / num_samples for v in estimator]  # [G] Standard Monte Carlo averaging
```

**Parameters:**
*   **Number of Samples:** Determined by desired variance reduction. Convergence is linear in a log-log plot [S1].
*   **Kernel Width:** Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Variance Increase:** AIS increases variance because the average kernel is not identical to the individual kernels, though they share properties such as zero value at position 0 [S1].

## Subtopics

### Variance Analysis
All estimators converge linearly in a log-log plot [S1]. The optimal estimator has the lowest variance but requires quadratically many elements for Hessians [S1]. Aggregate sampling performs slightly worse than optimal but much better than uniform sampling [S1].

## Operating characteristics
*   **Time Complexity:** Reduces time complexity to $O(1)$ function evaluations for all methods (Gradient, Hessian, HVP) compared to $O(n)$ or $O(n^2)$ for non-aggregate importance sampling [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Drastically reduces the number of expensive function evaluations required for higher-order derivatives [S1].
*   **Limitations:** Higher variance than optimal per-element importance sampling due to the mismatch between the aggregate kernel and individual kernels [S1].
*   **When to Use:** When function evaluations are prohibitively expensive and a slight increase in estimator variance is acceptable for a massive reduction in computational cost [S1].
*   **When Not to Use:** When the lowest possible variance is required and computational resources allow for $O(n^2)$ evaluations [S1].

## Background
Aggregate Importance Sampling was introduced in the context of stochastic gradient estimation for higher-order differentiable rendering [S1]. It addresses the challenge of estimating second-order derivatives (Hessians) in optimization problems involving differentiable volume rendering, where the number of dimensions $n$ can be large, making standard finite difference or per-element importance sampling computationally infeasible [S1]. The method leverages the similarity between convolution kernels to form a mixture distribution, akin to Multiple Importance Sampling with the balance heuristic [S1].
