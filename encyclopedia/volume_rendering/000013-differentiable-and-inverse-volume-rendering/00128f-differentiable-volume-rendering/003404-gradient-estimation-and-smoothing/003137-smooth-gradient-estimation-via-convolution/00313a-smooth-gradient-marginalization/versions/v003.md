# Smooth Gradient Marginalization

Also called: Marginalization of Gaussian Gradient

## Overview
Smooth Gradient Marginalization is a technique to sample an $n$-dimensional Gaussian gradient by marginalizing the probability density function (PDF) over all dimensions except the one being differentiated, allowing individual dimension sampling [S1]. It differs from methods that only blur in the direction of differentiation by blurring all dimensions, which is more consistent with higher-order differentials [S1].

## How it works
**Inputs:** The $n$-dimensional Gaussian function $N(\tau)$, the dimension index $i$ to differentiate, and the standard deviation $\sigma$ [G].
**Outputs:** A marginal PDF $p_G(\tau_i)$ for dimension $i$ and the corresponding CDF for sampling [G].

**Data Structures:**
*   $\tau$: Vector of length $n$.
*   $N(\tau)$: Scalar value of the Gaussian at $\tau$.
*   $p_G(\tau_i)$: Scalar marginal PDF for dimension $i$.

**Formulas:**
The marginal PDF is obtained by integrating the joint gradient PDF over all dimensions $j \neq i$ [S1]:
$$ p_G(\tau_i) = \int p_G(\tau) \, d\tau_{j \neq i} $$
Since the Gaussian is separable, $N(\tau) = \prod_{j=1}^n N(\tau_j)$, the integration over all $N(\tau_j)$ for $j \neq i$ evaluates to 1, leaving the magnitude of the 1D gradient [S1]. The 1D Gaussian gradient with respect to $\tau_i$ is:
$$ \nabla_i N(\tau_i) = -\frac{\tau_i}{\sigma^2} N(\tau_i) $$
The marginal PDF is the positivized and scaled version of this gradient [S1].

**Hessian Elements:**
The diagonal element of the Hessian is:
$$ \nabla^2 N(\tau)_{ii} = \frac{\partial^2 N(\tau)}{\partial \tau_i^2} = \left(\frac{\tau_i^2}{\sigma^4} - \frac{1}{\sigma^2}\right) N(\tau) $$
The off-diagonal element ($i \neq j$) is:
$$ \nabla^2 N(\tau)_{ij} = \frac{\tau_i \tau_j}{\sigma^4} N(\tau) $$
A critical distinction is that the diagonal element is not a special case of the off-diagonal element because the variable appears twice in the differentiation ($d(u^2)/du = 2u$ vs $d(uv)/du = v$) [S1].

**Sampling Steps:**
1. Identify the roots of the second-order derivative at $\tau_i = \pm \sigma$ [S1].
2. Calculate the scaling constant $\beta$ using the gradient at $-\sigma$: $\beta = \frac{1}{4 \nabla N(-\sigma)}$ [S1].
3. Construct the CDF $P^H_{ii}(\tau_i)$ by positivizing and scaling the second-order derivative such that the integral over $[-\sigma, \sigma]$ is twice the integral outside, ensuring the CDF is $1/2$ at $-\sigma$ [S1].

**Pseudocode:**
```python
import math

def gaussian_1d(t: float, sigma: float) -> float:
    """Standard 1D Gaussian PDF."""
    return (1.0 / math.sqrt(2.0 * math.pi * sigma ** 2)) * math.exp(-0.5 * (t / sigma) ** 2)

def gradient_1d(t: float, sigma: float) -> float:
    """Derivative of the 1D Gaussian PDF."""
    return -(t / (sigma ** 2)) * gaussian_1d(t, sigma)

def compute_beta(sigma: float) -> float:
    """Scaling constant for Hessian diagonal sampling."""
    return 1.0 / (4.0 * gradient_1d(-sigma, sigma))

def marginal_gradient_pdf(tau_i: float, sigma: float) -> float:
    """Marginal PDF for the gradient along dimension i."""
    return abs(gradient_1d(tau_i, sigma))

def hessian_diagonal_cdf(tau_i: float, sigma: float) -> float:
    """CDF for sampling the diagonal of the Hessian."""
    beta = compute_beta(sigma)
    g = gradient_1d(tau_i, sigma)
    if tau_i < -sigma:
        return beta * g
    elif tau_i <= sigma:
        return 0.5 + beta * g
    else:
        return 1.0 - beta * g
```

## Subtopics

### Sampling Diagonal of Hessian
This variant samples the diagonal elements of the Hessian matrix [S1]. It derives the valid distribution of the second-order derivative of the one-dimensional Gaussian by positivization and scaling, which then applies to higher dimensions [S1]. The 1D Gaussian second-order derivative is $\beta \left( \frac{1}{\sigma^2} - \frac{\tau_i^2}{\sigma^4} \right) N(\tau_i)$ [S1]. The roots are at $\tau_i = \pm \sigma$ [S1]. The PDF is $p^H_{ii} = |\beta \nabla^2 N(\tau_i)|$ [S1]. The CDF is defined piecewise: $\beta \nabla N(\tau_i)$ if $\tau_i < -\sigma$; $1/2 + \beta \nabla N(\tau_i)$ if $\tau_i \in [-\sigma, \sigma]$; $1 - \beta \nabla N(\tau_i)$ if $\tau_i > \sigma$ [S1].

## Background
This method is described in "Stochastic Gradient Estimation for Higher-Order Differentiable Rendering" [S1]. It builds on the work of Fischer and Ritschel [7] who derived 1D Gaussian gradient sampling, but extends it to $n$-dimensions via marginalization [S1].
