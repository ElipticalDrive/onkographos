# Axis-Aligned Neighbor Smoothing

Also called: Weighted Axis-Aligned Smoothing

## Overview
Axis-Aligned Neighbor Smoothing is a post-processing filter applied to rendered images to mitigate the discontinuities inherent in differentiable volume rendering and rasterization. It solves the problem of vanishing gradients by smoothing the rendering integrand along a specific axis (typically depth or screen-space coordinates) using a weighted average of neighboring pixels. Unlike [Smooth Gradient Estimation via Convolution](6449-smooth-gradient-estimation-via-convolution.md) which applies isotropic convolution, this method restricts smoothing to a single axis to preserve structural coherence, and unlike [Non-local Approximated Gradients](6784-non-local-approximated-gradients.md) which operates on image statistics, it operates directly on pixel values using geometric priors (depth, normal, color) to preserve edges [S1, unofficial].

## How it works
The method implements a bilateral-like filter along a chosen axis. It assumes the existence of a depth buffer and a normal buffer packed into a single texture, alongside the color buffer.

**Inputs:**
- `color_texture`: A 2D texture of `vec4<f32>` (RGBA) at binding 0.
- `normal_depth_texture`: A 2D texture of `vec4<f32>` at binding 1. The layout is defined as:
  - `x`: Normal X component
  - `y`: Normal Y component
  - `z`: Normal Z component
  - `w`: Depth value ($d$)

**Outputs:**
- A `vec4<f32>` color value for the current fragment.

**Parameters:**
- `R`: Integer radius of the smoothing window. Default: `7` [S1, unofficial].
- `WINDOW`: Window size, calculated as `R * 2 + 1` [S1, unofficial].
- Constants:
  - `depth_scale`: `0.1` [S1, unofficial].
  - `depth_epsilon`: `0.01` [S1, unofficial].
  - `dist_scale`: `0.005` [S1, unofficial].
  - `color_scale`: `2.0` [S1, unofficial].

**Algorithm:**
For a fragment at screen coordinates $(u, v)$ with position $\mathbf{p}$, normal $\mathbf{n}$, depth $d$, and color $\mathbf{c}$:

1. Initialize `result_color = vec4(0.0)` and `sum_weight = 0.0`.
2. Iterate over offset $i$ from $-R$ to $R$ along the chosen axis (e.g., horizontal axis $u$):
   a. Calculate neighbor coordinate: $u' = u + i$.
   b. Sample neighbor data from `normal_depth_texture` at $(u', v)$:
      - $\mathbf{n}' = (n'_x, n'_y, n'_z)$
      - $d' = w'$
   c. Sample neighbor color $\mathbf{c}'$ from `color_texture` at $(u', v)$.
   d. Compute individual weights:
      - Depth weight: $w_z = \exp\left( - \frac{|d - d'| \cdot 0.1}{\text{fwidth}(d) + 0.01} \right)$ [S1, unofficial].
        *Note: $\text{fwidth}(d)$ is the derivative-based width of depth, used for scale invariance.*
      - Normal weight: $w_n = |\mathbf{n} \cdot \mathbf{n}'|$ [S1, unofficial].
      - Distance weight: $w_d = \exp( - i^2 \cdot 0.005 )$ [S1, unofficial].
      - Color weight: $w_c = \exp( - \|\mathbf{c} - \mathbf{c}'\|^2 \cdot 2.0 )$ [S1, unofficial].
   e. Total weight: $w = w_n \cdot w_z \cdot w_d \cdot w_c$ [S1, unofficial].
   f. Accumulate:
      - `result_color += c' * w`
      - `sum_weight += w`
3. Finalize:
   - If `sum_weight > 0`: `result_color *= 1.0 / sum_weight`.
   - Else: `result_color` remains zero (or original, depending on implementation guard) [S1, unofficial].

**Pseudocode:**
```python
def axis_aligned_neighbor_smoothing(u, v, R=7):
    # Current fragment data
    current_nd = sample_normal_depth_texture(u, v)
    current_color = sample_color_texture(u, v)
    
    n = vec3(current_nd.x, current_nd.y, current_nd.z)
    d = current_nd.w
    c = current_color
    
    result_color = vec4(0.0)
    sum_w = 0.0
    
    # Precompute fwidth for depth scale invariance [S1, unofficial]
    # In a shader, fwidth(d) is intrinsic. Here we assume it is available.
    fw = fwidth(d) 
    
    for i in range(-R, R + 1):
        u_neighbor = u + i
        
        # Sample neighbor data
        neighbor_nd = sample_normal_depth_texture(u_neighbor, v)
        neighbor_color = sample_color_texture(u_neighbor, v)
        
        n_prime = vec3(neighbor_nd.x, neighbor_nd.y, neighbor_nd.z)
        d_prime = neighbor_nd.w
        c_prime = neighbor_color
        
        # Compute weights [S1, unofficial]
        # Depth weight: exponential decay based on depth difference normalized by fwidth
        w_z = exp( - (abs(d - d_prime) * 0.1) / (fw + 0.01) )
        
        # Normal weight: dot product of normals
        w_n = abs(dot(n, n_prime))
        
        # Distance weight: exponential decay based on offset squared
        w_d = exp( - (i * i) * 0.005 )
        
        # Color weight: exponential decay based on color distance squared
        color_dist_sq = dot(c_prime - c, c_prime - c)
        w_c = exp( - color_dist_sq * 2.0 )
        
        # Total weight
        w = w_n * w_z * w_d * w_c
        
        # Accumulate
        result_color += c_prime * w
        sum_w += w
        
    # Normalize
    if sum_w > 0.0:
        result_color = result_color * (1.0 / sum_w)
    else:
        # Guard against division by zero; result remains zero [S1, unofficial]
        pass
        
    return result_color
```

## Subtopics

### K-Nearest Neighbor Feature Smoothing with Dropout
A variant used in Gaussian Splatting contexts where smoothing is applied to semantic features rather than pixel colors. It averages Gaussian semantic features with their $K$ nearest neighbors in 3D space. If a dropout rate is specified, a random subset of neighbors is selected for averaging to introduce regularization. It returns the original features if $K \le 1$ [S2, unofficial].

## Operating characteristics
- **Time Complexity:** $O(R)$ per pixel, where $R$ is the radius. Since it is axis-aligned, it is significantly faster than full 2D bilateral filtering ($O(R^2)$).
- **Memory Complexity:** $O(1)$ auxiliary memory per pixel, requiring only the input textures.
- **Strengths:** Preserves edges defined by depth discontinuities and normal changes; reduces noise in flat regions; provides smooth gradients for optimization.
- **Limitations:** Blurs along the axis direction if not constrained by depth/normal weights; sensitive to the choice of $R$ and weight scales; requires access to depth and normal buffers.
- **When to use:** When differentiable rendering suffers from noisy gradients due to aliasing or discrete sampling, and isotropic blurring would destroy geometric structure.

## Background
The method originates from implementations in differentiable volume rendering and rasterization pipelines, specifically noted in the `voxel_ray_demo` repository [S1, unofficial]. It is designed to address the "localness" problem where standard derivatives are zero almost everywhere, by providing a smooth approximation of the integrand that allows gradient flow across pixel boundaries while respecting geometric edges.
