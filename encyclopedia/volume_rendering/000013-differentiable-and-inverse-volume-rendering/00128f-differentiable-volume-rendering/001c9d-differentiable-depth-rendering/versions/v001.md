# Differentiable Depth Rendering

Also called: Differentiable Depth Rendering via Implicit Function Theorem, IFT-based gradients, Differentiable Depth via Implicit Function Theorem (IFT) Surrogate, IFT Surrogate, IFT-based differentiable rendering, surrogate gradient for depth

## Overview
Differentiable Depth Rendering computes exact gradients of rendered depth values with respect to implicit function parameters by applying the Implicit Function Theorem (IFT) [S2, unofficial]. It solves the problem of differentiating through robust, non-differentiable forward tracing algorithms (such as bisection or sphere tracing) by replacing the backward pass with a surrogate gradient expression [S2, unofficial]. Unlike [Differentiable Volumetric Rendering (DVR)](775-differentiable-volumetric-rendering-dvr.md) which integrates density along rays, this method targets implicit surfaces defined by zero-level sets, and unlike [Approximated Gradient Back-Propagation](5666-approximated-gradient-back-propagation.md), it retains exact gradient information by accounting for the dependence of sample points on latent codes [S2, unofficial].

## How it works
The method separates the forward pass, which uses a robust numerical solver (e.g., bisection) to find the surface intersection, from the backward pass, which computes gradients analytically using the IFT [S2, unofficial].

### Inputs and Outputs
**Inputs:**
*   `origins`: Ray origins, shape $(N, 3)$.
*   `directions`: Ray directions, shape $(N, 3)$.
*   `f`: Implicit function $f(\mathbf{x}, \boldsymbol{\theta}) \rightarrow \mathbb{R}$, where $\mathbf{x}$ is a 3D point and $\boldsymbol{\theta}$ are trainable parameters [S2, unofficial].
*   `grad_clamp`: Scalar, default $10^{-6}$, to prevent division by zero for grazing rays [S2, unofficial].
*   `dtype`: Torch dtype, `float64` recommended for numerical stability [S2, unofficial].

**Outputs:**
*   `depth`: Tensor of depth values $t$ for each ray, shape $(N,)$.
*   `grads`: Gradients $\frac{\partial t}{\partial \boldsymbol{\theta}}$ computed via autograd on the surrogate [S2, unofficial].

### Data Structures
*   `hit`: Boolean mask of shape $(N,)$ indicating rays that intersect the surface [S2, unofficial].
*   `t_det`: Detached depth values from the forward bisection pass, shape $(N,)$ [S2, unofficial].
*   `p_star`: Surface points in world space, shape $(N, 3)$ [S2, unofficial].
*   `f_vals`: Function values at surface points, shape $(N,)$ [S2, unofficial].
*   `grad_x`: Spatial gradients $\nabla_{\mathbf{x}} f$ at surface points, shape $(N, 3)$ [S2, unofficial].

### Steps
1.  **Forward Pass (Robust Tracing):**
    *   Execute a standard bisection or sphere tracing algorithm using NumPy or a detached PyTorch operation to find the intersection distance $t_{det}$ for each ray [S2, unofficial].
    *   Identify hit rays: `hit_idx = np.where(hit)[0]` [S2, unofficial].
    *   Extract distances: `t_np = trace.t[hit_idx]` [S2, unofficial].

2.  **Surface Point Reconstruction:**
    *   Compute the 3D coordinates of the intersection points:
        $$ \mathbf{p}^* = \mathbf{o} + t_{det} \mathbf{d} $$
        where $\mathbf{o}$ is the ray origin and $\mathbf{d}$ is the ray direction [S2, unofficial].
    *   Convert $\mathbf{p}^*$ to a PyTorch tensor with `requires_grad=True` [S2, unofficial].

3.  **Implicit Function Evaluation:**
    *   Evaluate the implicit function at $\mathbf{p}^*$:
        $$ f_{vals} = f(\mathbf{p}^*, \boldsymbol{\theta}) $$
    *   Compute the spatial gradient of $f$ with respect to $\mathbf{p}^*$ using automatic differentiation:
        $$ \nabla_{\mathbf{x}} f = \nabla_{\mathbf{p}^*} f(\mathbf{p}^*, \boldsymbol{\theta}) $$
        This requires `create_graph=True` in the autograd call to allow higher-order derivatives if needed, though typically first-order is sufficient for the IFT formula [S2, unofficial].

4.  **Directional Derivative Calculation:**
    *   Compute the directional derivative of $f$ along the ray direction $\mathbf{d}$:
        $$ \text{dot} = \nabla_{\mathbf{x}} f \cdot \mathbf{d} $$
        This is the dot product of the spatial gradient and the ray direction [S2, unofficial].

5.  **Clamping:**
    *   Clamp the directional derivative to avoid division by zero for grazing rays (where $\nabla_{\mathbf{x}} f \perp \mathbf{d}$):
        $$ \text{dot}_{clamped} = \begin{cases} \text{grad\_clamp} & \text{if } \text{dot} \ge 0 \text{ and } |\text{dot}| < \text{grad\_clamp} \\ -\text{grad\_clamp} & \text{if } \text{dot} < 0 \text{ and } |\text{dot}| < \text{grad\_clamp} \\ \text{dot} & \text{otherwise} \end{cases} $$
        [S2, unofficial]

6.  **IFT Surrogate Construction:**
    *   Construct the surrogate depth value $t_{surr}$ using the IFT formula:
        $$ t_{surr} = t_{det} - \frac{f(\mathbf{p}^*)}{\text{dot}_{clamped}} $$
        This surrogate equals the forward depth $t_{det}$ (since $f(\mathbf{p}^*) \approx 0$ on the surface) but has a gradient that matches the analytical IFT derivative $\frac{dt}{d\boldsymbol{\theta}} = -\frac{\partial f / \partial \boldsymbol{\theta}}{\nabla_{\mathbf{x}} f \cdot \mathbf{d}}$ [S2, unofficial].

7.  **Gradient Propagation:**
    *   Scatter $t_{surr}$ back into the full depth tensor at `hit_idx` [S2, unofficial].
    *   Call `loss.backward()` to propagate gradients through the surrogate expression to $\boldsymbol{\theta}$ [S2, unofficial].

### Pseudocode
```python
import torch
import numpy as np

def differentiable_depth_rendering(origins, directions, implicit_func, grad_clamp=1e-6):
    """
    origins: (N, 3) torch tensor
    directions: (N, 3) torch tensor
    implicit_func: callable f(x, theta) -> scalar
    grad_clamp: float
    """
    N = origins.shape[0]
    depth = torch.zeros(N, dtype=torch.float64, device=origins.device)
    
    # 1. Forward pass: robust bisection (detached from autograd)
    # Assume trace_bisection returns (hit_mask, t_detached)
    # t_detached is the result of a standard non-differentiable solver
    hit_mask, t_detached = trace_bisection(origins, directions, implicit_func)
    
    # 2. Extract hit rays
    hit_indices = torch.where(hit_mask)[0]
    if hit_indices.numel() == 0:
        return depth
    
    t_det = t_detached[hit_indices]
    o_hit = origins[hit_indices]
    d_hit = directions[hit_indices]
    
    # 3. Compute surface points p*
    p_star = o_hit + t_det[:, None] * d_hit
    p_star.requires_grad_(True)
    
    # 4. Evaluate f(p*) and gradient
    # implicit_func must support batched input (N, 3)
    f_vals = implicit_func(p_star) # Shape (N,)
    
    # Compute spatial gradient nabla_x f
    # sum() is required for autograd.grad to return a vector
    grad_x, = torch.autograd.grad(f_vals.sum(), p_star, create_graph=True)
    
    # 5. Directional derivative dot = nabla_x f . d
    dot = (grad_x * d_hit).sum(dim=1)
    
    # 6. Clamp
    abs_dot = torch.abs(dot)
    dot_clamped = torch.where(
        abs_dot < grad_clamp,
        torch.where(dot >= 0, torch.full_like(dot, grad_clamp), torch.full_like(dot, -grad_clamp)),
        dot
    )
    
    # 7. IFT Surrogate
    # t_surr = t_det - f(p*) / (nabla_x f . d)
    t_surr = t_det - f_vals / dot_clamped
    
    # 8. Scatter back
    depth[hit_indices] = t_surr
    
    return depth
```

### Parameters
*   `grad_clamp`: Minimum absolute value for the directional derivative $\nabla_{\mathbf{x}} f \cdot \mathbf{d}$ to prevent exploding gradients. Default $10^{-6}$ [S2, unofficial].
*   `dtype`: Floating-point precision. `float64` is recommended for numerical stability during the IFT calculation [S2, unofficial].

### Edge Cases and Pitfalls
*   **Grazing Rays:** When the ray direction is perpendicular to the surface normal, $\nabla_{\mathbf{x}} f \cdot \mathbf{d} \approx 0$, causing division by zero. Clamping is required [S2, unofficial].
*   **Non-Zero Residuals:** The surrogate assumes $f(\mathbf{p}^*) \approx 0$. If the bisection tolerance is loose, $f(\mathbf{p}^*)$ may not be negligible, introducing bias in the surrogate value. However, the gradient remains valid for the implicit surface definition [S2, unofficial].
*   **Implementation Gap:** The core library documentation mentions the feature but does not provide the PyTorch integration code in the main loop; it must be implemented as a custom autograd function or surrogate expression as described [S2, unofficial].

## Subtopics

### [Depth from Ray Distance](5665-depth-from-ray-distance.md)
Computes camera-space depth $z_c$ from Euclidean ray distance, providing exact IFT gradients and avoiding numerical instability of iterative bisection differentiation.

### [Approximated Gradient Back-Propagation](5666-approximated-gradient-back-propagation.md)
Reduces memory by ignoring high-order gradient terms in sphere tracing, sacrificing exactness for lower overhead compared to the IFT surrogate.

## Operating characteristics
*   **Time Complexity:** Dominated by the forward bisection/sphere tracing pass. The backward pass is $O(N)$ for gradient evaluation and dot products.
*   **Memory Complexity:** $O(N)$ for storing intermediate tensors ($\mathbf{p}^*$, gradients). Significantly lower than storing full computation graphs for every marching step [S2, unofficial].
*   **Strengths:** Exact gradients without differentiating through the solver; robust forward pass; low memory overhead compared to adjoint methods [S2, unofficial].
*   **Limitations:** Requires the implicit function to be differentiable; sensitive to clamping parameters for grazing rays; requires custom PyTorch integration [S2, unofficial].
*   **When to use:** When rendering implicit surfaces (SDFs) and exact depth gradients are needed for optimization, and memory is constrained [S2, unofficial].

## Background
The method is implemented in the `isoray` library, specifically in `isoray/torch/render.py` [S2, unofficial]. It leverages the Implicit Function Theorem to decouple the robustness of numerical solvers from the differentiability required for learning [S2, unofficial]. The approach is distinct from end-to-end differentiable rendering that backpropagates through bisection, offering a surrogate alternative [S2, unofficial].
