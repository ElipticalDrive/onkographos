# Robust Depth-Range Estimation

Also called: Robust Clipped Depth Range Estimation

## Overview
Estimates a robust clipped depth range $[z_{min}, z_{max}]$ for binning by sampling visible Gaussians, applying a near-depth shift, and selecting percentiles via exact order statistics. It sets itself apart from sibling methods like Median Depth Rendering by using percentile-based range estimation with exact order statistics rather than a single median value, ensuring the binning range covers the majority of contributing geometry while excluding outliers.

## How it works
**Inputs:**
*   Projected depths of visible Gaussians.
*   Gaussian scales (specifically maximum projected scale $s_{max}$).
*   Optional emitted flat IDs.
*   Near and far clipping planes ($z_{near}, z_{far}$).
*   Sample count $S = 8192$.
*   Near-depth shift parameters $\alpha = 1.0$, $\gamma = 0.25$.
*   Percentiles $p_{lo} = 1.0$, $p_{hi} = 99.0$.
*   Padding fraction $f_{pad} = 0.05$.
*   Numerical floor $\epsilon = 10^{-4}$.

**Outputs:**
*   Robust clipped range $[z_{min}, z_{max}]$.

**Data Structures:**
*   List of sampled depth candidates.

**Steps:**
1.  **Sampling:** Sample up to $S$ depth candidates from the visible Gaussians or emitted flat IDs.
2.  **Near-Depth Shift:** If near-depth mode is enabled (default), convert each sampled depth $z_c$ to a key $z_{key}$ using the formula:
    $$ z_{key} = z_c - \min(\alpha \cdot s_{max}, \gamma \cdot z_c) $$
    where $s_{max}$ is the Gaussian's maximum projected scale.
3.  **Filtering and Clamping:** Discard candidates where $z_{key} \le 0$. Clamp remaining values to the range $[\epsilon, z_{far}]$ (assuming $z_{near} \ge \epsilon$).
4.  **Percentile Selection:** Select the exact $p_{lo}$ and $p_{hi}$ percentile values of the sampled candidates using order statistics (e.g., `kthvalue`) to obtain $z_{lo}$ and $z_{hi}$.
5.  **Span Calculation:** Calculate the span:
    $$ \text{span} = \max(z_{hi} - z_{lo}, 10^{-6}) $$
6.  **Range Expansion:** Calculate the final bounds:
    $$ z_{min} = \max(z_{near}, z_{lo} - f_{pad} \cdot \text{span}) $$
    $$ z_{max} = \min(z_{far}, z_{hi} + f_{pad} \cdot \text{span}) $$
7.  **Return:** Return $[z_{min}, z_{max}]$.

**Pseudocode:**
```python
def robust_depth_range_estimation(
    projected_depths,
    gaussian_scales,
    z_near,
    z_far,
    S=8192,
    alpha=1.0,
    gamma=0.25,
    p_lo=1.0,
    p_hi=99.0,
    f_pad=0.05,
    epsilon=1e-4
):
    # Step 1: Sample up to S depth candidates
    # Note: Implementation details for sampling from visible Gaussians are assumed
    # to be handled by the caller or a preceding step.
    candidates = sample_candidates(projected_depths, gaussian_scales, S)
    
    if not candidates:
        return [z_near, z_far]

    z_keys = []
    
    # Step 2: Near-depth shift
    for i, (z_c, s_max) in enumerate(candidates):
        # Calculate shift term
        shift_term = min(alpha * s_max, gamma * z_c)
        z_key = z_c - shift_term
        z_keys.append(z_key)
        
    # Step 3: Filter and clamp
    valid_keys = []
    for z_key in z_keys:
        if z_key <= 0:
            continue
        # Clamp to [epsilon, z_far]
        clamped = max(epsilon, min(z_far, z_key))
        valid_keys.append(clamped)
        
    if not valid_keys:
        return [z_near, z_far]
        
    # Step 4: Percentile selection via order statistics
    # Sort to find percentiles
    valid_keys.sort()
    n = len(valid_keys)
    
    # Calculate indices for percentiles
    # Using linear interpolation or nearest rank? 
    # The source specifies "exact order statistics (kthvalue)".
    # Typically kthvalue implies selecting the k-th smallest element.
    # For percentile p, index k = floor(p/100 * (n-1)) or similar.
    # We assume standard percentile definition compatible with kthvalue.
    
    idx_lo = int(p_lo / 100.0 * (n - 1))
    idx_hi = int(p_hi / 100.0 * (n - 1))
    
    # Ensure indices are within bounds
    idx_lo = max(0, min(n - 1, idx_lo))
    idx_hi = max(0, min(n - 1, idx_hi))
    
    z_lo = valid_keys[idx_lo]
    z_hi = valid_keys[idx_hi]
    
    # Step 5: Span calculation
    span = max(z_hi - z_lo, 1e-6)
    
    # Step 6: Range expansion
    z_min = max(z_near, z_lo - f_pad * span)
    z_max = min(z_far, z_hi + f_pad * span)
    
    return [z_min, z_max]
```

**Parameters:**
*   $S = 8192$: Maximum number of depth candidates sampled.
*   $\alpha = 1.0, \gamma = 0.25$: Near-depth shift parameters.
*   $p_{lo} = 1.0, p_{hi} = 99.0$: Percentiles for robust range estimation.
*   $f_{pad} = 0.05$: Padding fraction (5% of clipped span) added to the percentile range.
*   $\epsilon = 10^{-4}$: Numerical floor for depth values.

**Pitfalls:**
*   The near-depth shift is used only to form the binning key; it does not change the projected Gaussian attributes or the alpha-compositing equations used by the raster kernel.
*   Precision issues may arise if $z_{hi} - z_{lo}$ is very small; the span is floored at $10^{-6}$ to prevent division by zero or degenerate ranges.

## Operating characteristics
*   **Time Complexity:** Dominated by sampling $S$ candidates and sorting them for order statistics, $O(S \log S)$. With $S=8192$, this is fast.
*   **Memory Complexity:** $O(S)$ to store candidates.
*   **Strengths:** Robust to outliers due to percentile selection. Exact order statistics avoid histogram approximation errors.
*   **Limitations:** Requires sorting or selection algorithm. Sensitive to the choice of percentiles $p_{lo}, p_{hi}$.
*   **When to use:** When accurate binning range is critical for performance and correctness in Gaussian Splatting rasterization.

## Background
Originated in the TileGS paper (2026) for tile-local depth binning in Gaussian Splatting rasterization. It improves upon previous methods by using exact order statistics instead of histogram approximations for percentile selection.
