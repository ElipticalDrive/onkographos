# Expected Term Ray Tracing

Also called: Expected Term Rendering Kernel, Plenoxel Expected Term Ray Tracing

## Overview
Expected Term Ray Tracing computes the expected distance to the first opaque surface (or significant density threshold) along a ray passing through a sparse voxel grid [S1, unofficial]. It differs from standard volume rendering by outputting a scalar expected depth value rather than a color or opacity-weighted sum, making it suitable for uncertainty estimation or specific depth-based loss functions [S1, unofficial]. It builds on [Expected Term Rendering](5952-expected-term-rendering.md) by providing the specific CUDA kernel implementation for this metric [S1, unofficial].

## How it works
**Inputs and Outputs:**
- `grid`: Sparse voxel grid containing `density_data` (trilinearly interpolatable density field) [S1, unofficial].
- `ray`: Ray specification including origin, direction, `tmin`, `tmax`, and `world_step` (physical length of one voxel step) [S1, unofficial].
- `opt`: Options struct containing `sigma_thresh` (density threshold for opacity calculation), `stop_thresh` (transmission threshold for early termination), and `step_size` (number of samples per voxel) [S1, unofficial].
- `out`: Output buffer for the computed expected term [S1, unofficial].

**Data Structures:**
- `grid.density_data`: Array of density values $\sigma$ [S1, unofficial].
- `ray`: Struct with `origin` (float3), `direction` (float3), `tmin` (float), `tmax` (float), `world_step` (float) [S1, unofficial].
- `opt`: Struct with `sigma_thresh` (float), `stop_thresh` (float), `step_size` (int) [S1, unofficial].

**Algorithm:**
1. Handle edge case: if `ray.tmin > ray.tmax`, set `*out = 0.f` and return [S2, unofficial].
2. Initialize `t = ray.tmin`, `outv = 0.f`, and `log_transmit = 0.f` [S2, unofficial].
3. Loop while `t <= ray.tmax`:
   a. Compute ray position and lattice indices identically to `trace_ray_cuvol` using `fmaf`, `clamp`, `floor`, and fractional position calculations [S1, unofficial].
   b. Trilinearly interpolate density $\sigma$ from `grid.density_data` at the current ray position [S1, unofficial].
   c. If $\sigma > \text{opt.sigma\_thresh}$:
      i. Compute $\text{pcnt} = \text{ray.world\_step} \cdot \sigma$ [S2, unofficial].
      ii. Calculate weight $w = e^{\text{log\_transmit}} \cdot (1 - e^{-\text{pcnt}})$ [S1, unofficial][S2, unofficial].
      iii. Update $\text{log\_transmit} \leftarrow \text{log\_transmit} - \text{pcnt}$ [S1, unofficial][S2, unofficial].
      iv. Accumulate expected term: $\text{outv} \leftarrow \text{outv} + w \cdot \frac{t}{\text{opt.step\_size}} \cdot \text{ray.world\_step}$ [S1, unofficial][S2, unofficial].
   d. If $e^{\text{log\_transmit}} < \text{opt.stop\_thresh}$: set $\text{log\_transmit} = -1000.0f$ and break [S1, unofficial][S2, unofficial].
   e. Advance $t \leftarrow t + \text{opt.step\_size}$ [S1, unofficial][S2, unofficial].
4. After loop, write `*out = outv` [S1, unofficial][S2, unofficial].

**Pseudocode:**
```python
import math

def trace_ray_expected_term(grid, ray, opt, out):
    # Edge case: invalid ray bounds
    if ray.tmin > ray.tmax:
        out[0] = 0.0
        return
        
    t = ray.tmin
    log_transmit = 0.0
    outv = 0.0
    world_step = ray.world_step
    sigma_thresh = opt.sigma_thresh
    stop_thresh = opt.stop_thresh
    step_size = opt.step_size
    
    while t <= ray.tmax:
        # Compute ray position and lattice indices identically to trace_ray_cuvol
        # [G] Standard sparse voxel traversal: pos = ray.origin + t * ray.direction
        # lattice = floor(pos / voxel_size), frac = (pos - lattice * voxel_size) / voxel_size
        # sigma = trilinear_interpolate(grid.density_data, lattice, frac)
        sigma = trilinear_interpolate(grid.density_data, ray.position(t))
        
        if sigma > sigma_thresh:
            pcnt = world_step * sigma
            weight = math.exp(log_transmit) * (1.0 - math.exp(-pcnt))
            log_transmit -= pcnt
            outv += weight * (t / step_size) * world_step
            
        if math.exp(log_transmit) < stop_thresh:
            log_transmit = -1000.0
            break
            
        t += step_size
        
    out[0] = outv
```

**Parameters:**
- `sigma_thresh`: Density threshold above which opacity is calculated. Typical value: Not given in the sources.
- `stop_thresh`: Transmission threshold for early termination. Typical value: Not given in the sources.
- `step_size`: Number of samples per voxel. Typical value: Not given in the sources.

**Edge Cases and Pitfalls:**
- If `ray.tmin > ray.tmax`, the function returns `0.f` immediately to avoid invalid traversal [S2, unofficial].
- If `sigma` never exceeds `sigma_thresh`, `outv` remains `0` [S1, unofficial].
- If `exp(log_transmit)` drops below `stop_thresh`, `log_transmit` is clamped to `-1000.0f` to prevent floating-point underflow and the loop terminates early [S1, unofficial][S2, unofficial].

## Subtopics

### [Plenoxel Sigma Threshold Ray Tracing](14911-plenoxel-sigma-threshold-ray-tracing.md)
A CUDA kernel function that finds the first sample along a ray where density exceeds a given threshold, returning the normalized distance to that sample.

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of samples along the ray, with early termination possible if transmission drops below `stop_thresh` [S1, unofficial].
- **Memory Complexity:** Constant, $O(1)$ auxiliary memory per ray, plus access to the sparse voxel grid [S1, unofficial].
- **Performance:** Implemented as a CUDA kernel for parallel execution on GPUs [S1, unofficial].
- **Strengths:** Efficient computation of expected depth metrics for differentiable rendering [S1, unofficial].
- **Limitations:** Requires a sparse voxel grid structure; performance depends on density distribution and threshold settings [S1, unofficial].
- **When to use:** When expected depth or uncertainty estimation is required for volume rendering [S1, unofficial].
- **When not to use:** When color or opacity-weighted accumulation is needed instead of a scalar depth metric [S1, unofficial].
