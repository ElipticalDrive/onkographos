# Sigma-Threshold Depth Rendering

Also called: Dex-NeRF depth rendering, Opaque Mask Computation, Sigma Threshold Rendering

## Overview
Sigma-Threshold Depth Rendering computes a binary mask indicating the sample index along a ray where the cumulative accumulated weight exceeds a specified threshold, effectively identifying the "surface" location for depth estimation [S1, S2, unofficial]. It renders a binary or thresholded output based on whether the volume density ($\sigma$) exceeds a given threshold along the ray [S2, unofficial]. This method is distinct from expected depth rendering (which computes a weighted average) and median depth rendering (which finds the median distance) by providing a hard segmentation of the ray's occupied volume [S1, S2, unofficial]. It is primarily used in differentiable volume rendering pipelines, such as those in Dex-NeRF, to provide gradient-friendly surface cues [S2, unofficial].

## How it works
**Inputs:**
- `rays`: A structure containing ray origins, directions, and bounds.
- `weights`: An array of density weights from the volume rendering process (typically derived from $\sigma$ and $\Delta t$).
- `sigma_thresh`: A float threshold value for density comparison [S2, unofficial].
- `depth_threshold`: A float accumulation threshold for depth termination (default 0.5) [S1, unofficial].

**Outputs:**
- `results`: A tensor of dtype and device matching `rays.origins`, size `{rays.origins.size(0)}`, with `requires_grad=false` [S2, unofficial]. The values represent the binary mask or depth index.

**Data Structures:**
- `SingleRaySpec`: A structure holding ray parameters (origin, direction, near, far) [S2, unofficial].
- `weights`: 1D array or tensor of shape `(num_rays, num_samples)` or flattened, representing the transmittance-weighted density at each sample point [S1, unofficial].

**Steps:**
1. **Compute Cumulative Sum:** Calculate the cumulative sum of the weights along the ray samples.
   $$ cum = \text{cumsum}(weights) $$
   [S1, unofficial]

2. **Create Boolean Mask:** Generate a boolean mask where the cumulative sum exceeds the `depth_threshold`.
   $$ op = cum \ge depth\_threshold $$
   [S1, unofficial]

3. **Shift Mask:** Shift the boolean mask `op` to the right by one position and pad with zeros at the beginning to identify the transition point.
   $$ op_{shifted} = [0, op[:-1]] $$
   [S1, unofficial]

4. **Compute XOR Mask:** Compute the element-wise XOR between the original mask and the shifted mask to find the first index where the condition becomes true. Cast the result to the weights' dtype.
   $$ mask = op \oplus op_{shifted} $$
   [S1, unofficial]

5. **Kernel Launch (CUDA Implementation):**
   - Create a result tensor of dtype and device matching `rays.origins`, size `{rays.origins.size(0)}`, with `requires_grad=false` [S2, unofficial].
   - Calculate the number of CUDA blocks needed:
     $$ \text{blocks} = \text{CUDA\_N\_BLOCKS\_NEEDED}(Q, \text{TRACE\_RAY\_CUDA\_THREADS}) $$
     where $Q$ is the number of rays [S2, unofficial].
   - Launch the kernel `device::render_ray_sigma_thresh_kernel` with the calculated grid, `rays`, optimization options `opt`, `sigma_thresh`, and the result data pointer [S2, unofficial].

**Pseudocode:**
```python
def sigma_threshold_depth_rendering(rays, weights, depth_threshold=0.5, sigma_thresh=0.0):
    """
    Computes depth using sigma-thresholding.
    
    Args:
        rays: Object containing ray origins, directions, and bounds.
        weights: Array of density weights from NeRF, shape (num_rays, num_samples).
        depth_threshold: Float, accumulation threshold for depth termination (default 0.5).
        sigma_thresh: Float threshold for sigma values (used in kernel launch).
        
    Returns:
        results: Tensor of depth indices or binary masks.
    """
    # Step 1: Compute cumulative sum of weights
    # Assuming weights are along the last dimension
    cum = np.cumsum(weights, axis=-1)
    
    # Step 2: Create boolean mask where cumulative sum exceeds threshold
    op = cum >= depth_threshold
    
    # Step 3: Shift op right by one and pad with zeros
    # op_shifted[i] = op[i-1] for i > 0, op_shifted[0] = 0
    op_shifted = np.zeros_like(op)
    op_shifted[:, 1:] = op[:, :-1]
    
    # Step 4: Compute XOR mask
    # Cast to weights dtype (e.g., float32)
    mask = (op ^ op_shifted).astype(weights.dtype)
    
    # Step 5: Kernel launch details are hardware-specific.
    # In a pure Python implementation, we might return the mask or the index.
    # The index is the argmax of the mask along the sample axis.
    # Note: The source [S2, unofficial] indicates the kernel writes to a result tensor.
    # Here we simulate the result extraction.
    
    # Find the first True in each row
    # np.argmax returns the first index of the maximum value (1 for True)
    # If no True, it returns 0, which might be incorrect if the threshold is never met.
    # A safer approach for indices:
    results = np.argmax(mask, axis=-1)
    
    # Handle cases where threshold is never met (all False)
    # argmax returns 0 in this case, which is the first sample.
    # We might want to return a specific value (e.g., far plane or -1)
    # However, the source [S2, unofficial] creates a result tensor of size {rays.origins.size(0)}.
    # The exact handling of "no hit" is not specified in the notes.
    
    return results
```

**Parameters:**
- `depth_threshold`: Default 0.5 [S1, unofficial].
- `sigma_thresh`: A float threshold for sigma values to determine depth, as used in Dex-NeRF [S2, unofficial]. The exact default value is not given in the sources.

**Edge Cases and Pitfalls:**
- **Precision:** Cumulative sum precision may affect the threshold crossing point, especially with many samples [G].
- **Boundaries:** If the cumulative weight never exceeds `depth_threshold`, the mask will be all zeros. The behavior of the kernel in this case is not specified in the sources [S2, unofficial].
- **Degenerate Input:** Empty rays or zero-length rays should be handled by the ray tracing infrastructure [G].

## Operating characteristics
**Time and Memory Complexity:**
- Time: $O(N \cdot S)$ for cumulative sum and mask operations, where $N$ is the number of rays and $S$ is the number of samples per ray. The CUDA kernel launch is $O(N)$ [S2, unofficial].
- Memory: $O(N \cdot S)$ for storing weights and intermediate masks [S1, unofficial].

**Measured Performance:**
- Not given in the sources.

**Scaling:**
- Scales linearly with the number of rays and samples [S2, unofficial].

**Strengths and Limitations:**
- Strengths: Provides a hard surface cue, useful for differentiable rendering where gradient flow to surface location is desired [S1, S2, unofficial].
- Limitations: Binary nature may lose information about the volume structure compared to expected depth [S1, unofficial]. Sensitive to the choice of `depth_threshold` [S1, unofficial].

**When to Use:**
- Use when a binary segmentation of the ray is needed for surface reconstruction or differentiable rendering [S1, S2, unofficial].
- Do not use when a smooth, weighted average depth is required [S1, unofficial].

## Background
Sigma-Threshold Depth Rendering originates from the Dex-NeRF method, which uses this technique for depth estimation in neural radiance fields [S2, unofficial]. It is implemented in the svox2 library as `render_ray_sigma_thresh_kernel` [S2, unofficial]. The method is part of the differentiable volume rendering pipeline, allowing gradients to flow through the depth estimation process [S1, S2, unofficial].
