# DVGO with Reparameterized Rendering

Also called: Direct Voxel Grid Optimization with proposed reparameterized estimates

## Overview
This method adapts the Direct Voxel Grid Optimization (DVGO) architecture by replacing its standard volume rendering integral with a reparameterized estimate based on differentiable ray point sampling [S1, unofficial]. It solves the problem of high computational cost in standard ray marching by allowing the number of radiance samples to be explicitly controlled and minimized, particularly during the coarse training stage [S1, unofficial]. It sets itself apart from standard DVGO by trading off rendering quality (PSNR) for significant training speed improvements in the coarse stage, while maintaining competitive performance in the fine stage only when sample counts are kept low [S1, unofficial].

## How it works
The method retains the DVGO data structures and training pipeline but modifies the forward rendering pass.

**Inputs and Outputs:**
*   **Inputs:** Ray origin $o$, ray direction $d$, density grid $\sigma$, radiance grid $C$, and an optional view-dependent MLP $C_{mlp}$ [S1, unofficial].
*   **Outputs:** Rendered color $C_{render}$ [G].

**Data Structures:**
The method uses the same grids as DVGO:
1.  **Density Grid:** A 3D tensor storing volume density $\sigma$ [S1, unofficial].
2.  **Radiance Grid:** A 3D tensor storing view-independent color $C$ [S1, unofficial].
3.  **View-Dependent Radiance (Fine Stage):** A combination of the radiance grid and a small MLP [S1, unofficial].
4.  **Auxiliary Mask:** A binary mask identifying empty space regions to skip optimization [S1, unofficial].

**Numbered Steps:**

1.  **Ray Sampling:** Instead of fixed-step ray marching, sample $k$ points along the ray segment within the bounding box. The points are sampled according to a stratified distribution [S1, unofficial].
2.  **Grid Interpolation:** For each sampled point, interpolate the density and color from the respective 3D grids using the same scheme as the parent DVGO architecture [S1, unofficial].
3.  **Reparameterized Estimate Calculation:** Compute the transmittance and color contribution using the reparameterized estimate formula (Equation 4 in [S1, unofficial]). The standard volume rendering integral is approximated by the sum over the $k$ samples:
    $$
    C_{render} = \sum_{i=1}^{k} T_i \alpha_i C_i
    $$
    where $\alpha_i$ is the opacity derived from $\sigma_i$ and the distance between samples, and $T_i$ is the accumulated transmittance up to sample $i$ [S1, unofficial].
4.  **Differentiable Backpropagation:** Compute gradients with respect to the grid values using the chain rule through the sampling and interpolation steps [S1, unofficial].

**Parameters:**
*   **Number of radiance samples ($k$):** Varies during evaluation and training. Tested values: 1, 8, 32, 64 [S1, unofficial].

**Pseudocode:**
```python
def render_reparameterized(ray_o, ray_d, density_grid, radiance_grid, k, bbox_min, bbox_max):
    # 1. Ray-box intersection (slab method)
    t_min = -float('inf')
    t_max = float('inf')
    for d in range(3):
        if abs(ray_d[d]) < 1e-8:
            if ray_o[d] < bbox_min[d] or ray_o[d] > bbox_max[d]:
                return [0.0, 0.0, 0.0]
        else:
            t1 = (bbox_min[d] - ray_o[d]) / ray_d[d]
            t2 = (bbox_max[d] - ray_o[d]) / ray_d[d]
            t_enter = min(t1, t2)
            t_exit = max(t1, t2)
            t_min = max(t_min, t_enter)
            t_max = min(t_max, t_exit)
    if t_min > t_max:
        return [0.0, 0.0, 0.0]

    # 2. Stratified sampling of k points along the valid ray segment
    t_values = [t_min + i * (t_max - t_min) / k for i in range(k + 1)]
    t_mid = [(t_values[i] + t_values[i+1]) / 2.0 for i in range(k)]

    # 3. Sample points along ray
    points = [[ray_o[j] + ray_d[j] * t_mid[i] for j in range(3)] for i in range(k)]

    # 4. Trilinear interpolation from grids
    sigma = [trilinear_interpolate(density_grid, p) for p in points]
    color = [[trilinear_interpolate(radiance_grid, p, c) for c in range(3)] for p in points]

    # 5. Compute opacity and transmittance
    delta_t = [t_values[i+1] - t_values[i] for i in range(k)]
    alpha = [1.0 - math.exp(-sigma[i] * delta_t[i]) for i in range(k)]

    # Accumulate transmittance T_i = product_{j<i} (1 - alpha_j)
    T = [1.0] * k
    prod = 1.0
    for i in range(1, k):
        prod *= (1.0 - alpha[i-1])
        T[i] = prod

    # 6. Compute final color
    color_render = [0.0, 0.0, 0.0]
    for i in range(k):
        for c in range(3):
            color_render[c] += T[i] * alpha[i] * color[i][c]
    return color_render

def trilinear_interpolate(grid, point, channel=None):
    # Standard trilinear interpolation
    ix, iy, iz = int(math.floor(point[0])), int(math.floor(point[1])), int(math.floor(point[2]))
    fx, fy, fz = point[0] - ix, point[1] - iy, point[2] - iz
    # Handle boundary clamping
    ix = max(0, min(ix, grid.shape[0] - 2))
    iy = max(0, min(iy, grid.shape[1] - 2))
    iz = max(0, min(iz, grid.shape[2] - 2))
    if channel is None:
        # Interpolate scalar density
        v00 = grid[ix][iy][iz] * (1-fx) + grid[ix+1][iy][iz] * fx
        v10 = grid[ix][iy+1][iz] * (1-fx) + grid[ix+1][iy+1][iz] * fx
        v01 = grid[ix][iy][iz+1] * (1-fx) + grid[ix+1][iy][iz+1] * fx
        v11 = grid[ix][iy+1][iz+1] * (1-fx) + grid[ix+1][iy+1][iz+1] * fx
        return v00 * (1-fy) * (1-fz) + v10 * fx * (1-fy) * (1-fz) + v01 * (1-fy) * fz + v11 * fx * (1-fy) * fz
    else:
        # Interpolate color channel
        v00 = grid[ix][iy][iz][channel] * (1-fx) + grid[ix+1][iy][iz][channel] * fx
        v10 = grid[ix][iy+1][iz][channel] * (1-fx) + grid[ix+1][iy+1][iz][channel] * fx
        v01 = grid[ix][iy][iz+1][channel] * (1-fx) + grid[ix+1][iy][iz+1][channel] * fx
        v11 = grid[ix][iy+1][iz+1][channel] * (1-fx) + grid[ix+1][iy+1][iz+1][channel] * fx
        return v00 * (1-fy) * (1-fz) + v10 * fx * (1-fy) * (1-fz) + v01 * (1-fy) * fz + v11 * fx * (1-fy) * fz
```

**Edge Cases and Pitfalls:**
*   **Variance:** Lower PSNR in the proposed method is caused by estimate variance during training, not just inference sampling [S1, unofficial].
*   **Sample Count Sensitivity:** Noise artifacts are visible for $k=1$ but disappear for $k=8$ [S1, unofficial].
*   **Training vs. Inference Robustness:** A model trained with 64 samples can achieve PSNR 34.33 even if only 16 samples are used during evaluation, indicating robustness to inference sample count if training was sufficient [S1, unofficial].

## Operating characteristics
*   **Training Speed (Coarse Stage):** Improves training time by 20-30% compared to standard DVGO due to fewer radiance samples [S1, unofficial].
*   **Training Speed (Fine Stage):** Improves training speed only when the number of samples is lower than DVGO's average radiance calls (13.4 in the tested scenario) [S1, unofficial].
*   **Rendering Quality (PSNR):** Generally lower than standard DVGO. On the Lego scene, DVGO achieved 34.60 PSNR. The proposed method achieved 34.15 (64 samples), 33.95 (32 samples), 33.29 (8 samples), and 29.84 (1 sample) [S1, unofficial].
*   **Memory Usage:** Memory usage is comparable to DVGO, as the grid structures remain the same [S1, unofficial].
*   **Implementation Note:** To achieve performance competitive with DVGO's custom CUDA kernels, the method requires optimization using PyTorch's just-in-time (JIT) compilation module [S1, unofficial].

## Background
This method was proposed in the paper "Differentiable Rendering With Reparameterized Volume Sampling" [S1, unofficial]. It builds upon the Direct Voxel Grid Optimization (DVGO) architecture, which was known for its fast training times due to lightning-fast architecture, progressive scaling, and custom CUDA kernels [S1, unofficial]. The authors tested their rendering algorithm on the official DVGO implementation, replacing only the rendering algorithm based on Equation 4 of their paper [S1, unofficial].
