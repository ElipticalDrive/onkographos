# Differentiable Volumetric Rendering (DVR)

Also called: Implicit Surface Differentiation, Implicit Surface Gradient via Implicit Differentiation, Implicit Surface Rendering

## Overview

Differentiable Volumetric Rendering (DVR) is a rendering method that predicts pixel color by casting a ray from a camera origin through a pixel, finding the first intersection with an implicit isosurface defined by a neural network, and querying a texture network at that point [S1, S2, S3]. It solves the problem of optimizing implicit neural representations of 3D shape and texture directly from 2D RGB images without requiring 3D ground truth supervision [S2, S3]. Unlike voxel-based differentiable rendering methods (e.g., [57, 79] cited in [S3]) or LSTM-based renderers [72] cited in [S3], DVR does not store intermediate volumetric data or unrolled computation graphs for the forward pass, making its memory footprint independent of sampling accuracy and allowing for higher resolution [S1, S2, S3].

## How it works

**Inputs and Outputs:**
*   **Inputs:** Camera origin $\mathbf{r}_0$, ray direction vector $\mathbf{w}$ (from $\mathbf{r}_0$ to pixel $u$), network parameters $\theta$, threshold $\tau$, sampling count $n$, step size $\Delta s$, and start depth $s_0$.
*   **Outputs:** Rendered color $\hat{\mathbf{I}}_u$ and gradients $\frac{\partial \mathcal{L}}{\partial \theta}$ with respect to a loss $\mathcal{L}$.

**Data Structures:**
*   **Occupancy Network $f_\theta$:** Maps $\mathbb{R}^3 \times \mathcal{Z} \rightarrow [0, 1]$. For unconditional rendering, $\mathcal{Z}$ is empty or fixed. It outputs an occupancy probability.
*   **Texture Network $t_\theta$:** Maps $\mathbb{R}^3 \times \mathcal{Z} \rightarrow \mathbb{R}^3$. It outputs an RGB color value.
*   **Implementation:** $f_\theta$ and $t_\theta$ are typically implemented as a single neural network with two shallow output heads sharing hidden layers [S2, S3].
*   **Latent Embedding $z$:** For single-view reconstruction, an encoder $g_\theta$ produces $z \in \mathcal{Z}$ conditioned on the input image, which modulates both heads [S2, S3].

**Parameters:**
*   $\tau$: Isosurface threshold. Typical value: $0.5$ [S1, S2, S3]. Range: $[0, 1]$.
*   $n$: Number of equally-spaced samples on the ray. Starts at $16$, increases to $128$ during training (doubling after 50k, 150k, 250k iterations) [S1, S2, S3].
*   $s_0$: Start depth of the sampling interval [S1, S2, S3].
*   $\Delta s$: Step size for samples [S1, S2, S3].
*   $\mathbf{w}$: Ray direction vector $\mathbf{w} = \mathbf{u} - \mathbf{r}_0$ (normalized or unnormalized depending on convention, but $\mathbf{r}(d) = \mathbf{r}_0 + d\mathbf{w}$ implies $\mathbf{w}$ scales with depth) [S1, S2, S3].

**Algorithm Steps:**

1.  **Ray Sampling:** Compute $n$ points along the ray $\mathbf{r}(d) = \mathbf{r}_0 + d\mathbf{w}$:
    $$ \mathbf{p}_j^{\text{ray}} = \mathbf{r}(j\Delta s + s_0) \quad \text{for } j = 1, \dots, n $$
    [S1, S2, S3]

2.  **Intersection Detection:** Find the smallest index $j$ where the occupancy changes from free space to occupied space:
    $$ j = \operatorname{argmin}_{j'} \left( f_\theta(\mathbf{p}_{j'+1}^{\text{ray}}) \geq \tau > f_\theta(\mathbf{p}_{j'}^{\text{ray}}) \right) $$
    [S1, S2, S3]
    *Edge Case:* If no such $j$ exists (ray never intersects or starts inside), the depth is undefined or handled by boundary conditions [G].

3.  **Depth Approximation:** Approximate the surface depth $\hat{d}$ using the iterative secant method on the interval $[j\Delta s + s_0, (j+1)\Delta s + s_0]$ [S1, S2, S3]. Let $\hat{\mathbf{p}} = \mathbf{r}(\hat{d})$ be the intersection point.

4.  **Color Prediction:** Compute the rendered color:
    $$ \hat{\mathbf{I}}_u = t_\theta(\hat{\mathbf{p}}) $$
    [S1, S2, S3]

5.  **Gradient Computation (Backward Pass):**
    The total loss gradient is:
    $$ \frac{\partial \mathcal{L}}{\partial \theta} = \sum_u \frac{\partial \mathcal{L}}{\partial \hat{\mathbf{I}}_u} \cdot \frac{\partial \hat{\mathbf{I}}_u}{\partial \theta} $$
    [S1, S2, S3]
    
    Using the chain rule on $\hat{\mathbf{I}}_u = t_\theta(\hat{\mathbf{p}})$:
    $$ \frac{\partial \hat{\mathbf{I}}_u}{\partial \theta} = \frac{\partial t_\theta(\hat{\mathbf{p}})}{\partial \theta} + \frac{\partial t_\theta(\hat{\mathbf{p}})}{\partial \hat{\mathbf{p}}} \cdot \frac{\partial \hat{\mathbf{p}}}{\partial \theta} $$
    [S1, S2, S3]
    
    Since $\hat{\mathbf{p}} = \mathbf{r}(\hat{d}) = \mathbf{r}_0 + \hat{d}\mathbf{w}$:
    $$ \frac{\partial \hat{\mathbf{p}}}{\partial \theta} = \mathbf{w} \frac{\partial \hat{d}}{\partial \theta} $$
    [S1, S2, S3]
    
    The depth gradient $\frac{\partial \hat{d}}{\partial \theta}$ is derived via implicit differentiation of $f_\theta(\hat{\mathbf{p}}) = \tau$:
    $$ \frac{\partial f_\theta(\hat{\mathbf{p}})}{\partial \theta} + \frac{\partial f_\theta(\hat{\mathbf{p}})}{\partial \hat{\mathbf{p}}} \cdot \frac{\partial \hat{\mathbf{p}}}{\partial \theta} = 0 $$
    Substituting $\frac{\partial \hat{\mathbf{p}}}{\partial \theta}$:
    $$ \frac{\partial f_\theta(\hat{\mathbf{p}})}{\partial \theta} + \frac{\partial f_\theta(\hat{\mathbf{p}})}{\partial \hat{\mathbf{p}}} \cdot \mathbf{w} \frac{\partial \hat{d}}{\partial \theta} = 0 $$
    Solving for $\frac{\partial \hat{d}}{\partial \theta}$:
    $$ \frac{\partial \hat{d}}{\partial \theta} = - \left( \frac{\partial f_\theta(\hat{\mathbf{p}})}{\partial \hat{\mathbf{p}}} \cdot \mathbf{w} \right)^{-1} \frac{\partial f_\theta(\hat{\mathbf{p}})}{\partial \theta} $$
    [S1, S2, S3]
    
    **Implementation Trick:** To compute the gradient efficiently using reverse-mode automatic differentiation without storing the forward pass of the secant method, rewrite the term $\lambda \frac{\partial \hat{d}}{\partial \theta}$ (where $\lambda = \frac{\partial \mathcal{L}}{\partial \hat{d}}$ is the incoming gradient from the loss) as:
    $$ \mu \frac{\partial f_\theta(\hat{\mathbf{p}})}{\partial \theta} \quad \text{with} \quad \mu = - \left( \frac{\partial f_\theta(\hat{\mathbf{p}})}{\partial \hat{\mathbf{p}}} \cdot \mathbf{w} \right)^{-1} \lambda $$
    [S1, S2, S3]
    
    The backward pass is implemented by:
    1.  Computing $\mu$ from the incoming gradient $\lambda$, the gradient of the occupancy network w.r.t. position $\frac{\partial f_\theta(\hat{\mathbf{p}})}{\partial \hat{\mathbf{p}}}$, and the ray direction $\mathbf{w}$.
    2.  Element-wise multiplying $\lambda$ by $\mu$ (broadcasting for batches).
    3.  Backpropagating the result through the occupancy network $f_\theta(\hat{\mathbf{p}})$ to get gradients w.r.t. $\theta$.
    4.  Adding the direct gradient from the texture network $t_\theta(\hat{\mathbf{p}})$ w.r.t. $\theta$ and the term $\frac{\partial t_\theta(\hat{\mathbf{p}})}{\partial \hat{\mathbf{p}}} \cdot \mathbf{w} \frac{\partial \hat{d}}{\partial \theta}$ (which can also be computed via the same $\mu$ trick or standard AD if the texture network is differentiated through the depth). Note: The source [S1] focuses on the depth gradient trick for the occupancy part. The texture gradient $\frac{\partial t_\theta(\hat{\mathbf{p}})}{\partial \theta}$ is standard. The term $\frac{\partial t_\theta(\hat{\mathbf{p}})}{\partial \hat{\mathbf{p}}} \cdot \mathbf{w} \frac{\partial \hat{d}}{\partial \theta}$ requires $\frac{\partial \hat{d}}{\partial \theta}$, which can be computed using the $\mu$ formula derived from $f_\theta$.

**Pseudocode:**

```python
import torch

def dvr_forward(f_theta, t_theta, r0, w, tau, n, ds, s0):
    """
    Forward pass for DVR.
    f_theta: Occupancy network (returns scalar occupancy prob)
    t_theta: Texture network (returns RGB color)
    r0: Camera origin (3,)
    w: Ray direction (3,)
    tau: Threshold
    n: Number of samples
    ds: Step size
    s0: Start depth
    """
    # 1. Sample points on ray
    # p_j = r0 + (j*ds + s0) * w
    depths = torch.arange(1, n + 1, device=r0.device) * ds + s0
    points = r0.unsqueeze(0) + depths.unsqueeze(1) * w.unsqueeze(0) # Shape: (n, 3)
    
    # 2. Evaluate occupancy
    # f_theta expects points, returns occupancy probs
    occupancies = f_theta(points) # Shape: (n,)
    
    # 3. Find intersection
    # Find first j where occ[j+1] >= tau > occ[j]
    # Note: indices in source are 1-based for p_j, but array is 0-based.
    # p_j corresponds to index j-1 in 0-based array if j starts at 1.
    # Source: p_j^ray for j=1..n.
    # Condition: f(p_{j'+1}) >= tau > f(p_{j'})
    # In 0-based indexing: occ[j'+1] >= tau > occ[j']
    # We look for j' such that this holds.
    
    # Create boolean masks
    free = occupancies < tau
    occupied = occupancies >= tau
    
    # Shift for comparison
    free_next = torch.roll(free, -1)
    free_next[-1] = False # Last point has no next
    
    # Intersection occurs where free_next is True and free is True?
    # No: free_next is True means occ[j+1] < tau (free).
    # We want occ[j+1] >= tau (occupied) AND occ[j] < tau (free).
    # So: occupied_next AND free
    intersect_mask = occupied * free # occ[j+1] >= tau AND occ[j] < tau
    
    # Find first index j' where intersect_mask is True
    j_prime = torch.argmax(intersect_mask.float())
    
    # If no intersection found, handle edge case [G]
    if not intersect_mask.any():
        return None, None
        
    # 4. Secant method for depth
    # Interval: [d_j, d_{j+1}] where d_j = j*ds + s0, d_{j+1} = (j+1)*ds + s0
    # Note: source uses j as the index of the first free point.
    # d_start = j_prime * ds + s0
    # d_end = (j_prime + 1) * ds + s0
    # f_start = occupancies[j_prime]
    # f_end = occupancies[j_prime + 1]
    
    d_start = j_prime * ds + s0
    d_end = (j_prime + 1) * ds + s0
    f_start = occupancies[j_prime]
    f_end = occupancies[j_prime + 1]
    
    # Secant method iteration
    # x_new = x1 - f1 * (x2 - x1) / (f2 - f1)
    # Iterate until convergence or max steps
    d_hat = d_start
    for _ in range(10): # [G] Fixed iterations for simplicity, source says "iterative"
        f_curr = f_start + (d_hat - d_start) * (f_end - f_start) / (d_end - d_start)
        if abs(f_curr - tau) < 1e-6:
            break
        # Update interval
        if f_curr < tau:
            d_start = d_hat
            f_start = f_curr
        else:
            d_end = d_hat
            f_end = f_curr
        d_hat = d_start + (tau - f_start) * (d_end - d_start) / (f_end - f_start)
        
    # 5. Compute intersection point
    p_hat = r0 + d_hat * w
    
    # 6. Compute color
    color = t_theta(p_hat)
    
    return d_hat, color, p_hat, f_theta, t_theta, r0, w, tau, n, ds, s0

def dvr_backward(loss_grad, d_hat, p_hat, f_theta, t_theta, r0, w):
    """
    Backward pass for DVR.
    loss_grad: Gradient of loss w.r.t. color (same shape as color)
    """
    # We need dL/d_theta.
    # dL/d_theta = dL/d_color * d_color/d_theta + dL/d_d * d_d/d_theta
    
    # 1. Gradient through texture network
    # d_color/d_theta is computed by standard autograd if t_theta is a torch.nn.Module
    # But we need to handle the dependency on p_hat which depends on d_hat
    
    # Let's compute gradients manually or via autograd on the whole forward pass?
    # Source says: "backpropagating the result through the operator theta -> f_theta(p_hat)"
    # and "multiplying incoming gradient lambda element-wise with factor mu"
    
    # Lambda = dL/dd_hat
    # We need dL/dd_hat first.
    # dL/dd_hat = dL/d_color * d_color/dd_hat
    # d_color/dd_hat = d_color/d_p * d_p/dd_hat = d_color/d_p * w
    
    # Compute d_color/d_p
    # Using autograd on t_theta(p_hat)
    t_theta.requires_grad_(True)
    p_hat.requires_grad_(True)
    
    # Forward texture
    color = t_theta(p_hat)
    
    # Backward color
    color.backward(loss_grad, retain_graph=True)
    
    # d_color/d_p_hat
    d_color_dp = p_hat.grad # Shape: (3,)
    
    # d_color/dd_hat = d_color/d_p * w
    d_color_dd = torch.dot(d_color_dp, w)
    
    # Lambda
    lambda_val = d_color_dd
    
    # 2. Compute mu
    # mu = - ( d_f/d_p * w )^-1 * lambda
    # d_f/d_p is gradient of occupancy w.r.t. position
    f_val = f_theta(p_hat)
    f_val.backward(torch.ones_like(f_val), retain_graph=True)
    d_f_dp = p_hat.grad # Shape: (3,)
    
    d_f_dp_w = torch.dot(d_f_dp, w)
    mu = - (1.0 / d_f_dp_w) * lambda_val
    
    # 3. Gradient through occupancy network
    # We want dL/d_theta from the depth part.
    # The term is mu * d_f/d_theta
    # We can compute d_f/d_theta by backpropagating mu through f_theta
    
    # Reset gradients for f_theta
    f_theta.zero_grad()
    
    # Forward occupancy
    f_out = f_theta(p_hat)
    
    # Backward with mu
    f_out.backward(mu)
    
    grad_f_theta = f_theta.grad
    
    # 4. Gradient through texture network parameters
    # We already have grad from step 1, but we need to accumulate it.
    # In step 1, we called backward on color. This populated t_theta.grad.
    grad_t_theta = t_theta.grad
    
    # 5. Combine
    # The total gradient is grad_t_theta + grad_f_theta?
    # Source Eq 5: dI/d_theta = d_t/d_theta + d_t/d_p * d_p/d_theta
    # d_p/d_theta = w * d_d/d_theta
    # d_d/d_theta = - (d_f/d_p * w)^-1 * d_f/d_theta
    # So the second term is d_t/d_p * w * [ - (d_f/d_p * w)^-1 * d_f/d_theta ]
    # This is exactly what we computed via mu.
    # mu * d_f/d_theta is the gradient contribution from the depth change.
    # But wait, mu * d_f/d_theta is a vector w.r.t theta?
    # Yes, d_f/d_theta is the gradient of f w.r.t theta.
    # So grad_f_theta is d_f/d_theta.
    # The term added to the gradient is mu * grad_f_theta.
    
    # However, in step 1, we computed d_color/d_theta directly via autograd on t_theta(p_hat).
    # This includes the d_t/d_theta term AND the d_t/d_p * d_p/d_theta term.
    # The d_p/d_theta term in the autograd result is computed using the stored forward graph of p_hat.
    # But p_hat depends on d_hat, which depends on f_theta.
    # If we use the "trick", we avoid storing the forward graph of the secant method.
    # The trick replaces the gradient flow through d_hat with mu * d_f/d_theta.
    
    # So, we should NOT use the autograd result for the depth-dependent part of the texture gradient.
    # We should only use autograd for the direct texture gradient d_t/d_theta.
    
    # Let's re-evaluate.
    # dI/d_theta = d_t/d_theta + d_t/d_p * w * d_d/d_theta
    # d_d/d_theta = - (d_f/d_p * w)^-1 * d_f/d_theta
    
    # Term 1: d_t/d_theta. Compute by backpropagating loss through t_theta(p_hat) BUT treating p_hat as constant?
    # No, p_hat is not constant.
    # The trick is to compute the gradient of the operator theta -> d_hat.
    # The operator is: theta -> f_theta -> d_hat.
    # The gradient of this operator is mu * d_f/d_theta.
    
    # So, total gradient:
    # dL/d_theta = dL/d_color * d_color/d_theta
    # d_color/d_theta = d_t/d_theta + d_t/d_p * d_p/d_theta
    # d_p/d_theta = w * d_d/d_theta
    
    # We can compute d_t/d_theta by backpropagating d_t/d_p * w * d_d/d_theta? No.
    
    # Correct approach from source:
    # 1. Compute lambda = dL/dd_hat.
    # 2. Compute mu = - (d_f/d_p * w)^-1 * lambda.
    # 3. Compute grad_f = d_f/d_theta (via backprop of f_theta).
    # 4. The gradient contribution from the depth change is mu * grad_f.
    # 5. The gradient contribution from the direct texture change is d_t/d_theta.
    
    # How to get d_t/d_theta without the depth dependency?
    # We can compute d_t/d_p * w * d_d/d_theta using the mu trick?
    # No, the mu trick is for d_d/d_theta.
    
    # Let's look at Eq 11: lambda * d_d/d_theta = mu * d_f/d_theta.
    # This replaces the gradient flow through d_d/d_theta.
    
    # So, if we have lambda, we can get the gradient w.r.t theta for the depth part.
    # But we also need the gradient w.r.t theta for the texture part.
    
    # dL/d_theta = dL/d_color * ( d_t/d_theta + d_t/d_p * w * d_d/d_theta )
    # = dL/d_color * d_t/d_theta + dL/d_color * d_t/d_p * w * d_d/d_theta
    # = dL/d_color * d_t/d_theta + lambda * d_t/d_p * w * d_d/d_theta / d_d/d_d ? No.
    
    # lambda = dL/dd_hat = dL/d_color * d_color/dd_hat = dL/d_color * d_t/d_p * w.
    # So the second term is lambda * d_d/d_theta.
    # And lambda * d_d/d_theta = mu * d_f/d_theta.
    
    # So, dL/d_theta = dL/d_color * d_t/d_theta + mu * d_f/d_theta.
    
    # We need dL/d_color * d_t/d_theta.
    # This is the gradient of the texture network if we treat p_hat as fixed.
    # But p_hat is not fixed.
    # However, the term d_t/d_p * d_p/d_theta is handled by the second part.
    # So we need the partial derivative of t_theta w.r.t theta, holding p_hat constant.
    
    # Implementation:
    # 1. Compute d_t/d_theta by backpropagating dL/d_color through t_theta(p_hat) but detaching p_hat?
    # No, p_hat is a function of theta.
    # We want d/d_theta t_theta(p_hat(theta)) = d_t/d_theta + d_t/d_p * d_p/d_theta.
    # We split this into:
    # A) d_t/d_theta (direct)
    # B) d_t/d_p * d_p/d_theta (via depth)
    
    # We computed B via the mu trick: B_grad = mu * d_f/d_theta.
    # We need A_grad = d_t/d_theta.
    
    # To get A_grad, we can backpropagate dL/d_color through t_theta, but we must ignore the gradient flowing back through p_hat.
    # This is done by detaching p_hat or using a custom autograd function.
    
    # Simplified:
    # grad_t_direct = dL/d_color * d_t/d_theta (computed by backprop with p_hat detached)
    # grad_depth = mu * d_f/d_theta
    
    # Total = grad_t_direct + grad_depth
    
    # Let's implement this.
    
    # Detach p_hat for direct texture gradient
    p_hat_detached = p_hat.detach()
    p_hat_detached.requires_grad_(True)
    
    color_detached = t_theta(p_hat_detached)
    color_detached.backward(loss_grad, retain_graph=True)
    
    grad_t_direct = t_theta.grad
    
    # Reset gradients
    t_theta.zero_grad()
    f_theta.zero_grad()
    
    # Compute mu and grad_f
    # (Already computed d_f_dp and d_f_dp_w above, but need to re-run backprop for d_f/d_theta)
    
    f_out = f_theta(p_hat)
    f_out.backward(torch.ones_like(f_out), retain_graph=True)
    grad_f_theta = f_theta.grad
    
    grad_depth = mu * grad_f_theta
    
    total_grad = grad_t_direct + grad_depth
    
    return total_grad
```

## Operating characteristics

*   **Time Complexity:** Dominated by the evaluation of the neural networks $f_\theta$ and $t_\theta$ at $n$ sample points per ray. $n$ increases during training from 16 to 128 [S1, S2, S3].
*   **Memory Complexity:** Memory footprint is independent of the sampling accuracy $n$ and the volume resolution because no intermediate volumetric data is stored in the forward pass [S1, S2, S3]. This contrasts with voxel-based methods which require storing all intermediate evaluations [S3].
*   **Performance:** Demonstrated on single NVIDIA V100 GPU with batch size 64 images, 1024 random pixels each [S1, S2, S3].
*   **Strengths:** Enables learning from 2D images without 3D supervision; high resolution due to no voxel grid; watertight meshes can be extracted [S2, S3].
*   **Limitations:** Requires finding the first intersection; sensitive to the threshold $\tau$; secant method convergence [G].

## Background

DVR was introduced by Niemeyer et al. in 2020 [S2, S3]. It builds on occupancy networks [48] and texture fields [54]. It addresses the limitation of previous implicit representation methods that required 3D ground truth [S2, S3]. It differs from voxel-based differentiable rendering [57, 79] and LSTM-based renderers [72] by being inherently differentiable without storing intermediate results [S3].
