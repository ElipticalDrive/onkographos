# SDF Prb Reparam Integrator


## Overview
A differentiable path tracer that computes gradients of radiance with respect to scene parameters (e.g., Signed Distance Function shape parameters) by warping random samples via reparameterization, supporting both forward and backward mode automatic differentiation [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Scene description containing an SDF field, camera parameters, random number generator state, and scene parameters $\theta$ (e.g., SDF coefficients) [S1, unofficial].
*   **Outputs:** Primal radiance image $L$ and gradient images $\nabla_\theta L$ (forward or backward) [S1, unofficial].

**Data Structures and Parameters:**
*   `self.primal_image`: Tensor storing the computed radiance [S1, unofficial].
*   `self.warp_field`: Optional field defining the reparameterization warp [S1, unofficial].
*   `reparam_max_depth`: Maximum depth for reparameterization rays [S1, unofficial].
*   `shade_gradient_max_depth`: Maximum depth for shading gradients, set equal to `reparam_max_depth` if `warp_field` is not None [S1, unofficial].
*   `reparam_rays`: Number of reparameterization rays (default 16) [S1, unofficial].
*   `reparam_kappa`: Parameter for reparameterization (default $10^5$) [S1, unofficial].
*   `reparam_exp`: Exponent for reparameterization (default 3.0) [S1, unofficial].
*   `rr_depth`: Depth at which Russian Roulette is applied (default 5) [S1, unofficial].
*   `use_aovs`: Boolean flag to enable Auxiliary Output Variables (default False) [S1, unofficial].
*   `hide_emitters`: Boolean flag to hide emitters (default False) [S1, unofficial].

**Core Algorithm:**
The integrator executes in two main phases depending on the differentiation mode, both following a consistent setup and sampling routine [S1, unofficial].

1. **Primal Setup:**
   *   Prepare the scene SDF via `self.prepare_sdf(scene)` [S1, unofficial].
   *   Suspend gradients for primal setup using `dr.suspend_grad()` [S1, unofficial].
   *   Prepare the sampler and generate primary rays with reparameterization if `self.warp_field` is not None [S1, unofficial].
   *   Compute primal radiance $L$ using `self.sample` with `mode=dr.ADMode.Primal` [S1, unofficial].
   *   Store primal image in `self.primal_image` [S1, unofficial].

2. **Gradient Computation:**
   *   **Forward Mode:** Resume gradients and compute sample position derivatives if enabled [S1, unofficial]. Compute forward-mode gradients by calling `self.sample` with `mode=dr.ADMode.Forward` [S1, unofficial]. Accumulate reparameterization result gradients into `result_grad` [S1, unofficial].
   *   **Backward Mode:** Prepare the scene SDF via `self.prepare_sdf(scene)` [S1, unofficial]. Suspend gradients for primal setup using `dr.suspend_grad()` [S1, unofficial]. Generate primary rays with reparameterization [S1, unofficial]. Compute primal radiance $L$ using `self.sample` with `mode=dr.ADMode.Primal` [S1, unofficial]. Resume gradients and enable gradient tracking on $L$ [S1, unofficial]. Set gradient of image to `grad_in` and enqueue backward pass [S1, unofficial]. Compute backward-mode gradients by calling `self.sample` with `mode=dr.ADMode.Backward` [S1, unofficial].

**Sampling Loop (`self.sample`):**
The sampling loop handles path construction and reparameterization integration [S1, unofficial].
1. Initialize loop state: `depth=0`, `L=0` (or `state_in`), $\beta=1$, $\eta=1$, `mis_em=1` [S1, unofficial].
2. Perform preliminary ray intersection to get `pi_cur` [S1, unofficial].
3. If `warp_field` is not None: Update `reparam_max_depth` to `max_reparam_depth` if `>= 0`, else $100,000$ [S1, unofficial]. Set `shade_gradient_max_depth` equal to `reparam_max_depth` [S1, unofficial].
4. If reparameterization requires `DRJIT_STRUCT`, start a loop named 'Path Replay Backpropagation' [S1, unofficial].
5. **Sphere Tracing Step:** Evaluate SDF value $s = \text{SDF}(p)$ and gradient $g = \nabla \text{SDF}(p)$ [S1, unofficial]. Compute silhouette weight $w_{sil}$:
   $$ w_{sil} = \frac{1}{(10^{-7} + |s| + \text{SIL\_WEIGHT\_OFFSET} \cdot (n \cdot d)^2)^3} $$
   where $n = g / \|g\|$, $d$ is the ray direction, and $\text{SIL\_WEIGHT\_OFFSET} = 0.05$ [S1, unofficial].
6. Compute segment length and update integrals for warp position estimation using the trapezoid rule:
   $$ W_{int} \leftarrow W_{int} + 0.5 \cdot \Delta t \cdot (w_{prev} + w_{sil}) $$
   $$ T_{warp} \leftarrow T_{warp} + 0.5 \cdot \Delta t \cdot (t_{prev} \cdot w_{prev} + t \cdot w_{sil}) $$
   where $\Delta t$ is the segment length [S1, unofficial].
7. Update ray position: $t \leftarrow t + s$ [S1, unofficial]. Check for intersection ($|s| < \epsilon$) and boundary conditions [S1, unofficial].

**Pseudocode:**

```python
import drjit as dr

def render_forward(scene, params):
    # [G] Standard AD framework context manager to suspend gradients during primal setup
    with dr.suspend_grad():
        sdf = scene.sdf_field
        # [G] Standard sampler initialization
        sampler = None
        # [G] Standard primary ray generation with optional warp application
        rays = None
        primal_image = sample(scene, rays, mode=dr.ADMode.Primal, sdf=sdf)
        scene.primal_image = primal_image

    # [G] Resume gradients and compute sample position derivatives
    dr.resume_grad()
    grad_image = sample(scene, rays, mode=dr.ADMode.Forward, sdf=sdf)
    # [G] Standard accumulation of reparameterization gradients
    result_grad = None
    return primal_image, result_grad

def render_backward(scene, params, grad_in):
    with dr.suspend_grad():
        sdf = scene.sdf_field
        sampler = None
        rays = None
        primal_image = sample(scene, rays, mode=dr.ADMode.Primal, sdf=sdf)

    dr.resume_grad()
    dr.enable_grad(primal_image)
    primal_image.grad = grad_in
    grad_image = sample(scene, rays, mode=dr.ADMode.Backward, sdf=sdf)
    return grad_image

def sample(scene, rays, mode, sdf):
    depth = 0
    L = 0.0
    beta = 1.0
    eta = 1.0
    mis_em = 1.0

    if scene.warp_field is not None:
        reparam_max_depth = scene.max_reparam_depth if scene.max_reparam_depth >= 0 else 100000
        shade_gradient_max_depth = reparam_max_depth
    else:
        reparam_max_depth = 0
        shade_gradient_max_depth = 0

    weight_integral = 0.0
    warp_t_integral = 0.0
    prev_sdf_value = 0.0
    prev_sil_w = 0.0
    t = 0.0
    active = True

    # Path Replay Backpropagation Loop
    while active and depth < shade_gradient_max_depth:
        # [G] Standard ray-scene intersection returning hit point and mask
        pi_cur = scene.intersect(rays)
        active = pi_cur.hit

        if active:
            p = pi_cur.position
            sdf_val = sdf.eval(p)
            sdf_grad = sdf.eval_grad(p)

            n = sdf_grad / dr.norm(sdf_grad)
            n_dot_d = dr.dot(rays.d, n)
            sil_weight_offset = 0.05
            w_sil = 1.0 / (1e-7 + dr.abs(sdf_val) + sil_weight_offset * n_dot_d**2)**3
            w_sil = dr.maximum(w_sil, 0.0)

            segment_length = dr.maximum(prev_sdf_value, 0.0)
            prev_t = t - prev_sdf_value

            weight_integral += 0.5 * segment_length * (prev_sil_w + w_sil)
            warp_t_integral += 0.5 * segment_length * (prev_t * prev_sil_w + t * w_sil)

            t += sdf_val
            prev_sdf_value = sdf_val
            prev_sil_w = w_sil
            depth += 1

            if dr.abs(sdf_val) < 1e-6:
                # [G] Standard BSDF evaluation and MIS weighting
                L += beta * 0.0
                break
        else:
            break

    # [G] Final warp position estimation from accumulated integrals
    if weight_integral > 0:
        warp_t_integral = warp_t_integral / weight_integral
    return L
```

## Operating characteristics
*   **Time Complexity:** Not given in the sources [S1, unofficial].
*   **Memory Complexity:** Not given in the sources [S1, unofficial].
*   **Performance:** Performance depends heavily on the complexity of the SDF evaluation. The use of `reparam_rays=16` provides a balance between gradient accuracy and computational cost [S1, unofficial].
*   **Strengths:** Provides stable gradients for SDF-based shape optimization. Supports both forward and backward mode AD, allowing flexibility in optimization setups [S1, unofficial].
*   **Limitations:** Requires the SDF to be differentiable. The reparameterization warping may introduce bias if the warp field is poorly conditioned [G]. High `reparam_kappa` ($10^5$) and `reparam_exp` (3.0) are used to stabilize the warping but may require tuning for specific scenes [S1, unofficial].
*   **When to use:** When optimizing SDF parameters for shape reconstruction or editing [S1, unofficial].
*   **When not to use:** When the scene does not involve SDFs or when memory is extremely constrained (due to path replay storage) [G].

## Background
The method originates from the work on Differentiable Signed Distance Function Rendering, specifically the implementation in the Mitsuba 3 renderer [S1, unofficial]. It builds on the differential path integral estimator framework, incorporating reparameterization techniques to handle the non-differentiable nature of ray-SDF intersections by warping the random samples [S1, unofficial]. The "Path Replay Backpropagation" loop is a key innovation to efficiently compute gradients through the iterative sphere tracing process [S1, unofficial].
