# À-trous Cross-Bilateral Filtering

Also called: Cross-Bilateral Filter, spatiotemporal gradient filtering

## Overview
À-trous cross-bilateral filtering is a spatial filtering technique applied to gradients and their associated first and second moment buffers in inverse rendering, implemented as a sequence of à-trous filters to enable fast optimization on regular 2D or 3D grids [S1]. It differs from standard bilateral filters by using parameter values $\theta$ rather than gradient values for the data term, which prevents over-smoothing across edges while leveraging the lower noise and dynamic range of parameters [S1]. Unlike [Smooth Gradient Estimation via Convolution](6449-smooth-gradient-estimation-via-convolution.md) which uses fixed convolution kernels, this method adapts weights based on parameter similarity, and unlike [Non-local Approximated Gradients](6784-non-local-approximated-gradients.md) which approximates gradients via differential filters, it explicitly smooths the optimization state variables [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Gradient $\nabla_\theta f_t$ at iteration $t$, first moment buffer $m_t$, second moment buffer $v_t$, parameter values $\theta$, and hyperparameters $F, \sigma_s, \sigma_d, \beta_1, \beta_2$ [S1].
*   **Output:** Filtered gradient $\widetilde{\nabla_\theta f_t}$, filtered moments $\tilde{m}_t, \tilde{v}_t$ [S1].

**Data Structures:**
*   $\theta, m_t, v_t, \nabla_\theta f_t$ are stored on regular 2D or 3D grids [S1].
*   Grid dimensions depend on the scene, e.g., $512^2$ for 2D texture recovery or $64^3$ for 3D volume recovery [S1].

**Formulas:**
The cross-bilateral filter for a function $h$ is defined as [S1]:
$$
\tilde{h}(x) = \frac{1}{z(x)} \int_{\Omega} h(y) w_s(x,y) w_d(\theta(y),\theta(x)) dy
$$
where:
*   $\Omega$ is the spatial domain [S1].
*   $w_s(x,y) = \exp(-||x-y||/\sigma_s)$ is the spatial isotropic low-pass filter weight [S1].
*   $w_d(\theta_x,\theta_y) = \exp(-||\theta_x-\theta_y||/\sigma_d)$ is the data term weight [S1].
*   $z(x) = \int_{\Omega} w_s(x,y) w_d(\theta(y),\theta(x)) dy$ is the normalization term [S1].
*   $\sigma_s$ controls the scale of the spatial weight $w_s$ [S1].
*   $\sigma_d$ controls the scale of the data weight $w_d$ [S1].

**Parameters:**
*   $F$: Number of à-trous filters in the sequence. Typical values: $F=5$ for texture recovery, $F=3$ for volume recovery and Laplacian smoothing [S1].
*   $\sigma_d$: Data term scale. Typical values: $0.1$ for texture recovery, $0.001$ for albedo $\rho$, and $0.2$ for density $\sigma_t$ in volume recovery [S1].
*   $\beta_1$: Temporal filtering coefficient for $m_t$. Typical value: $0.2$. Range: $(0.2, 0.5)$ [S1].
*   $\beta_2$: Temporal filtering coefficient for $v_t$. Set such that $1-\beta_1 = 1-\beta_2$ [S1].
*   $\alpha$: Learning rate. Typical values: $0.1$ (non-Adam) or $0.01$ (Adam) for texture; $0.008$ (Adam) or $0.02$ (others) for volume [S1].

**Algorithm Steps:**
1.  **Temporal Filtering:** Update $m_t$ and $v_t$ using coefficients $\beta_1$ and $\beta_2$ respectively [S1]. The standard exponential moving average recurrence is applied [G].
2.  **Spatial Pre-filtering:** Apply a sequence of $F$ à-trous cross-bilateral filters to the gradient $\nabla_\theta f_t$ [S1]. At each step $k \in \{1, \dots, F\}$, use a dilated $3 \times 3$ kernel for 2D or $3 \times 3 \times 3$ kernel for 3D [S1]. The dilation factor increases with each step to expand the support while keeping the number of non-zero elements fixed [S1]. The number of filters $F$ indirectly specifies $\sigma_s$ [S1].
3.  **Spatial Post-filtering:** Apply the identical cross-bilateral filter (same $\theta, \sigma_s, \sigma_d$) to both $m_t$ and $v_t$ [S1]. This ensures the ratio $|\tilde{m}_t|/\tilde{v}_t < 1$ remains bounded, preventing instability [S1].
4.  **Parameter Update:** Compute the update step using the filtered moments and learning rate $\alpha$ [G]. Using the same parameters $\theta$ for the data term $w_d$ across all operations ensures bounded steps analogous to Adam [S1].

**Pseudocode:**
```python
import math

def atrous_cross_bilateral_filter(h, theta, sigma_s, sigma_d, F):
    """
    Applies F steps of à-trous cross-bilateral filtering to h.
    h: 2D or 3D array of values to filter
    theta: 2D or 3D array of parameter values (same shape as h)
    sigma_s: spatial scale
    sigma_d: data scale
    F: number of filter passes
    """
    current_h = [row[:] for row in h] if h.ndim == 2 else [[[val for val in row] for row in plane] for plane in h]
    
    for step in range(F):
        dilation = 2 ** step
        shape = current_h.shape
        ndim = len(shape)
        
        # Initialize output and normalization arrays
        filtered_h = [[0.0] * shape[1] for _ in range(shape[0])] if ndim == 2 else [[[0.0]*shape[2] for _ in range(shape[1])] for _ in range(shape[0])]
        normalization = [[0.0] * shape[1] for _ in range(shape[0])] if ndim == 2 else [[[0.0]*shape[2] for _ in range(shape[1])] for _ in range(shape[0])]
        
        # Generate kernel offsets
        offsets = []
        for dx in [-dilation, 0, dilation]:
            for dy in [-dilation, 0, dilation]:
                if ndim == 2:
                    offsets.append((dx, dy))
                else:
                    for dz in [-dilation, 0, dilation]:
                        offsets.append((dx, dy, dz))
        
        # Apply filter
        for y in range(shape[0]):
            for x in range(shape[1]):
                if ndim == 2:
                    theta_x = theta[y][x]
                    for dx, dy in offsets:
                        ny = max(0, min(shape[0] - 1, y + dy))
                        nx = max(0, min(shape[1] - 1, x + dx))
                        dist = math.sqrt((dx * dilation)**2 + (dy * dilation)**2)
                        w_s = math.exp(-dist / sigma_s)
                        w_d = math.exp(-abs(theta[ny][nx] - theta_x) / sigma_d)
                        h_y = current_h[ny][nx]
                        filtered_h[y][x] += h_y * w_s * w_d
                        normalization[y][x] += w_s * w_d
                else:
                    theta_x = theta[y][x]
                    for x in range(shape[2]):
                        for dx, dy, dz in offsets:
                            ny = max(0, min(shape[0] - 1, y + dy))
                            nx = max(0, min(shape[1] - 1, x + dx))
                            nz = max(0, min(shape[2] - 1, z + dz))
                            dist = math.sqrt((dx * dilation)**2 + (dy * dilation)**2 + (dz * dilation)**2)
                            w_s = math.exp(-dist / sigma_s)
                            w_d = math.exp(-abs(theta[ny][nx][nz] - theta_x) / sigma_d)
                            h_y = current_h[ny][nx][nz]
                            filtered_h[y][x][z] += h_y * w_s * w_d
                            normalization[y][x][z] += w_s * w_d
        
        # Normalize
        for y in range(shape[0]):
            for x in range(shape[1]):
                if ndim == 2:
                    current_h[y][x] = filtered_h[y][x] / (normalization[y][x] + 1e-8)
                else:
                    for z in range(shape[2]):
                        current_h[y][x][z] = filtered_h[y][x][z] / (normalization[y][x][z] + 1e-8)
                        
    return current_h

def update_parameters(theta, grad, m, v, alpha, beta1, beta2, sigma_s, sigma_d, F):
    """
    Performs one step of optimization using à-trous cross-bilateral filtering.
    """
    # 1. Temporal Update (Standard EMA)
    m = [[m[y][x] * beta1 + (1 - beta1) * grad[y][x] for x in range(len(m[0]))] for y in range(len(m))]
    v = [[v[y][x] * beta2 + (1 - beta2) * (grad[y][x] ** 2) for x in range(len(v[0]))] for y in range(len(v))]
    
    # 2. Spatial Filtering of Gradient
    filtered_grad = atrous_cross_bilateral_filter(grad, theta, sigma_s, sigma_d, F)
    
    # 3. Spatial Filtering of Moments (Post-filtering)
    filtered_m = atrous_cross_bilateral_filter(m, theta, sigma_s, sigma_d, F)
    filtered_v = atrous_cross_bilateral_filter(v, theta, sigma_s, sigma_d, F)
    
    # 4. Parameter Update
    update = [[alpha * filtered_m[y][x] / (math.sqrt(filtered_v[y][x]) + 1e-8) for x in range(len(filtered_m[0]))] for y in range(len(filtered_m))]
    theta = [[theta[y][x] - update[y][x] for x in range(len(theta[0]))] for y in range(len(theta))]
    
    return theta, m, v
```

**Edge Cases and Pitfalls:**
*   Filtering only one of $m_t$ or $v_t$ violates the bound $|\tilde{m}_t|/\tilde{v}_t < 1$, resulting in much larger step sizes that significantly worsen recovery [S1].
*   Using different parameters $\theta$ for the data term in different filtering operations significantly degrades recovery and causes instability [S1].
*   Lower values of $\beta_1, \beta_2$ reduce temporal bias but increase noise; higher values increase bias and slow convergence [S1].

## Subtopics

### Grid-based Implementation of Cross-Bilateral Filtering
This method implements the cross-bilateral filter on regular 2D or 3D grids to enable real-time spatial filtering of gradients and associated buffers in inverse rendering [S1]. It differs from standard bilateral filters by decomposing the operation into a series of à-trous filters, which allows for fast optimization with a fixed number of non-zero elements per filter pass [S1]. It builds on [À-trous Cross-Bilateral Filtering](13139-trous-cross-bilateral-filtering.md) [S1].

### Purely Spatial Filtering
A configuration where temporal filtering is turned off by setting $\beta_1 = \beta_2 = 0$, making the optimizer memoryless and eliminating the need to maintain buffers $m_t$ and $v_t$ [S1]. This results in a 2/3rd reduction in memory usage compared to methods maintaining these buffers [S1]. Unlike Adam which makes constant sized steps, purely spatial filtering allows postfiltering to dynamically adjust learning rates, resulting in faster convergence [S1].

## Operating characteristics
*   **Time Complexity:** The method introduces little overhead (<4%) for both 2D and 3D filtering compared to standard optimizers, as the à-trous decomposition allows fixed-size kernels with increasing dilation [S1].
*   **Memory Complexity:** Requires storage for gradients, first moment $m_t$, and second moment $v_t$, same as Adam [S1]. Purely spatial variant reduces memory by 2/3 [S1].
*   **Performance:** Tested on NVIDIA GeForce RTX 3080 GPU using Mitsuba 3 and PyTorch with custom CUDA kernels [S1].
*   **Strengths:** Recovers fine details better than Laplacian smoothing and standard bilateral filtering; less noisy than Adam in texture recovery; bounded step sizes prevent instability [S1].
*   **Limitations:** Requires tuning of $\sigma_d$ and $F$ per application (texture vs. volume); sensitive to violating the constraint of using the same $\theta$ for data terms [S1].
*   **When to use:** Inverse rendering of textures and volumes where gradient noise is high and edge preservation is critical [S1].
*   **When not to use:** When memory is extremely constrained and purely spatial filtering is insufficient, or when the parameter space does not have clear discontinuities that benefit from cross-bilateral weighting [S1].

## Background
Originated in the work on spatiotemporal bilateral gradient filtering for inverse rendering [S1]. The method builds on the cross-bilateral filter concept introduced by Eisemann and Durand [2004] and Petschnigg et al. [2004], adapting it for gradient preconditioning in optimization [S1]. It was specifically designed to address the noise in gradients during inverse rendering, leveraging the fact that parameter values are less noisy and have a lower dynamic range than gradients [S1].
