# Aggregate Importance Sampling

Also called: AIS

## Overview
Aggregate Importance Sampling (AIS) is a sampling strategy to reduce function evaluations by importance-sampling the average of the convolution kernels across all dimensions or elements, rather than each individually [S1]. It addresses the high computational cost of non-aggregate importance sampling, which requires $O(n)$ or $O(n^2)$ evaluations for an $n$-dimensional output, by sampling from a mixture distribution representing the average of all convolution kernels [S1]. Unlike non-aggregate methods that optimize each dimension individually, AIS performs a single function evaluation per iteration, trading a slight increase in variance for a linear reduction in computational complexity [S1].

## How it works
AIS estimates the derivative of a scalar function $f$ with respect to $n$ parameters by approximating the convolution of $f$ with a differential kernel [S1]. The method reduces the number of rendering calls from proportional to the number of output elements to a constant $O(1)$ per iteration [S1].

**Inputs and Outputs:**
*   **Input:** A differentiable rendering function $f(\mathbf{x})$, where $\mathbf{x} \in \mathbb{R}^n$ is the parameter vector [S1]. A probability distribution $p(\mathbf{z})$ for sampling perturbation directions $\mathbf{z}$ [S1].
*   **Output:** An unbiased estimator for the differential quantity (e.g., gradient vector or Hessian matrix) [S1].

**Data Structures:**
*   **Differential Representation:** For a Hessian, this is an $n \times n$ matrix [S1]. For a gradient, it is a vector of size $n$ [S1].
*   **Kernel:** The convolution kernel $K(\mathbf{z})$ associated with the differential operator (e.g., second-order derivative kernel for Hessian) [S1].

**Algorithm Steps:**
1. Randomly decide which element of the differential representation to choose (e.g., which matrix element out of $n^2$ in the Hessian) [S1].
2. Compute the convolution sample for all $n^2$ elements using the same function value (single rendering call), weighting each by its respective kernel [S1].

**Formulas:**
Let $D$ be the differential operator (e.g., Hessian). The estimator for the $(i,j)$-th element $\hat{D}_{ij}$ after $T$ iterations is:
$$ \hat{D}_{ij} = \frac{1}{T_{ij}} \sum_{t=1}^{T_{ij}} \frac{f(\mathbf{x} + \mathbf{z}_t) K_{ij}(\mathbf{z}_t)}{p(\mathbf{z}_t)} $$
Where:
*   $T_{ij}$ is the number of times element $(i,j)$ was selected [S1].
*   $K_{ij}(\mathbf{z})$ is the kernel value for the $(i,j)$-th derivative at perturbation $\mathbf{z}$ [S1].
*   $p(\mathbf{z})$ is the probability density of the sampling distribution [S1].

**Parameters:**
*   **Sampling Distribution $p(\mathbf{z})$:** Typically a mixture distribution or a distribution matching the average kernel properties [S1]. The sources note that the average kernel shares properties like being zero at position 0 with individual kernels [S1].
*   **Selection Probability:** Uniform selection of the element index is implied by the "randomly decide" step [S1].

**Pseudocode:**
```python
import random

def aggregate_importance_sampling(f, x, n, num_iterations, sample_distribution, kernel_func):
    """
    Estimate the differential quantity of f at x using Aggregate Importance Sampling.
    """
    # Initialize accumulator and counts
    H = [[0.0] * n for _ in range(n)]
    counts = [[0] * n for _ in range(n)]

    for _ in range(num_iterations):
        # Step 1: Randomly decide which element of the differential representation to choose
        i = random.randint(0, n - 1)
        j = random.randint(0, n - 1)

        # Step 2: Sample perturbation from the mixture/average distribution
        z, p_z = sample_distribution()

        # Step 3: Compute the convolution sample using the same function value (single rendering call)
        f_val = f(x + z)

        # Step 4: Weight by the respective kernel for the selected element
        k_val = kernel_func(i, j, z)

        # Unbiased estimator contribution
        sample = (f_val * k_val) / p_z

        # Accumulate
        H[i][j] += sample
        counts[i][j] += 1

    # Normalize by counts to get the average estimate
    for i in range(n):
        for j in range(n):
            if counts[i][j] > 0:
                H[i][j] /= counts[i][j]

    return H
```

**Edge Cases and Pitfalls:**
*   **Variance Increase:** AIS increases variance compared to non-aggregate importance sampling because the average kernel is not identical to the individual kernels [S1].
*   **Zero-Kernel Positions:** Both average and individual kernels are zero at position 0, which must be handled correctly in the sampling distribution to avoid division by zero or undefined weights [S1].
*   **Uneven Sampling:** If certain elements are rarely selected, their estimates will have higher variance due to fewer samples [G].

## Subtopics

### [Sampling Convolutions](14972-sampling-convolutions.md)
Sampling Convolutions is a technique to compute accurate gradients in integrands with large support using spherical convolutions, specifically addressing the mismatch between standard hemispherical sampling and the full-sphere support of a convolution. It differs from naive convolution sampling by introducing a precomputed correction factor that compensates for the energy loss incurred when the sampling distribution (typically a BRDF) is restricted to a hemisphere while the convolution kernel extends over the full sphere.

## Operating characteristics
*   **Time Complexity:** $O(1)$ function evaluations per iteration for all differential methods (Gradient, Hessian, Hessian-Vector Product), compared to $O(n)$ or $O(n^2)$ for non-aggregate importance sampling [S1].
*   **Memory Complexity:** $O(n^2)$ to store the Hessian matrix and counts, assuming a Hessian is being estimated [G].
*   **Variance:** All estimators converge linearly in a log-log plot [S1]. The optimal estimator (sampling each dimension individually) has the lowest variance but requires quadratically many evaluations for Hessians. Aggregate sampling performs slightly worse than the optimal estimator but much better than uniform sampling [S1].
*   **Strengths:** Significant reduction in rendering calls, making higher-order derivatives feasible in differentiable rendering [S1].
*   **Limitations:** Higher variance than optimal sampling; requires careful design of the mixture sampling distribution to approximate the average kernel effectively [S1].

## Background
Aggregate Importance Sampling was proposed in the context of stochastic gradient estimation for higher-order differentiable rendering [S1]. It addresses the challenge of optimizing differentiable quantities where the number of parameters $n$ is large, making non-aggregate methods computationally prohibitive [S1]. The method is analogous to Multiple Importance Sampling (MIS) using the balance heuristic, where proposals are combined by sampling from a mixture [S1].
