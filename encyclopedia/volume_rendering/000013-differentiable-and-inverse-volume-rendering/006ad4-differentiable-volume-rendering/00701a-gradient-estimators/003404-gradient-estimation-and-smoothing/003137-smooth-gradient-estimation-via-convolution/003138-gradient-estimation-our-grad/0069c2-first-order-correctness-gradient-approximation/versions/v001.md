# First-Order Correctness Gradient Approximation

Also called: First-Order Correctness Definition, Local expansion gradient, Pre-filtered gradient rule

## Overview
First-Order Correctness Gradient Approximation is a gradient estimation method for differentiable volume rendering that computes the derivative of a pre-filtered function $\hat{f}$ by averaging the derivative of the original function $f$ over a local interval. It guarantees absolute first-order correctness for continuous functions and relative first-order correctness for discontinuous functions [S1]. It sets itself apart from siblings like the Dual-Buffer Gradient Estimator by explicitly defining correctness via kernel support integration and handling discontinuities through specific composition rules rather than dual-buffer accumulation [S1].

## How it works
**Inputs and Outputs:**
*   Input: A scalar function $f$ defined on domain $\text{dom}(f)$, a parameter vector $\vec{\theta}$, a spatial point $x$, and a kernel size $\epsilon$.
*   Output: An approximation of the gradient $\frac{\partial \hat{f}}{\partial \theta_i}$ at $(x, \vec{\theta})$ with kernel size $\epsilon$.

**Data Structures:**
*   The method operates on the function space $\bar{E}_c$, which includes functions that are either C-simple (continuous) or D-simple (discontinuous) at the evaluation point.
*   Discontinuities are classified by root order $n$. Discontinuities with roots of order $n \ge 2$ are excluded from the set $D_i$ (for $n=2$) or $\bar{E}_c$ (for $n \ge 3$) to prevent denominator degeneracy [S1].

**Definitions:**
1.  **Absolute First-Order Correctness:** A gradient approximation $\frac{\partial^k f}{\partial \theta_i}$ is absolutely first-order correct for parameter $\theta_i$ at $(x, \vec{\theta})$ with kernel size $\epsilon$ if [S1]:
    $$ \frac{\partial^k f}{\partial \theta_i}(x, \vec{\theta}; \epsilon) = \frac{\partial \hat{f}}{\partial \theta_i}(x, \vec{\theta}; \epsilon) + O(\epsilon) \quad (2) $$
2.  **Relative First-Order Correctness:** A gradient approximation is relatively first-order correct if [S1]:
    $$ \frac{\frac{\partial^k f}{\partial \theta_i}(x, \vec{\theta}; \epsilon)}{\frac{\partial \hat{f}}{\partial \theta_i}(x, \vec{\theta}; \epsilon)} = 1 + O(\epsilon) \quad (3) $$

**Steps:**
1.  **Classification:** For a function $f \in \bar{E}_c$, identify whether the point $(x, \vec{\theta})$ is C-simple (continuous with respect to $\theta_i$) or D-simple (discontinuous with respect to $\theta_i$) [S1].
2.  **Continuous Case (C-simple):** For C-simple points, compute the gradient using the integral average over the kernel support. The approximation matches the pre-filtered derivative up to error $O(\epsilon)$ [S1].
3.  **Discontinuous Case (D-simple):** For D-simple points, apply the composition rule or ternary select rule to handle discontinuities. The method ensures relative first-order correctness [S1].
4.  **Kernel Constraint:** Ensure $\epsilon$ is chosen small enough such that the kernel support $[x - \alpha\epsilon, x + \beta\epsilon]$ contains at most one discontinuity and remains within $\text{dom}(f)$ [S1].

**Parameters:**
*   $\epsilon$: Kernel size. Typical values depend on the resolution and the scale of discontinuities. It must be small enough to isolate single discontinuities [S1].

**Edge Cases and Pitfalls:**
*   **Discontinuities with roots of order $n \ge 2$:** These are excluded from $D_i$ (for $n=2$) or $\bar{E}_c$ (for $n \ge 3$) to prevent denominator degeneracy and ensure the composition rule's denominator $(g^+ - g^-)$ remains nonzero [S1].
*   **Boundary Conditions:** The kernel support must remain within $\text{dom}(f)$. If the kernel extends outside the domain, the approximation is invalid [S1].
*   **Multiple Discontinuities:** The kernel support must contain at most one discontinuity. If it contains more, the first-order correctness guarantee does not hold [S1].

## Subtopics

### Prefiltering-aware gradient metric estimation
This variant adapts the first-order correctness approximation for metric estimation in differentiable rendering. It approximates the gradient of the pre-filtered function using a 1D box kernel, where the kernel size is identical to the dimension of the gradient $g$. It decides the sampling axis (x or y) adaptively. It pre-filters along the chosen axis and samples along the orthogonal axis to compute the integrand [S1]. In contrast, Finite Difference (FD) directly samples the integrand using the original function value $f$, and Theoretical Error Gradient (TEG) handles image-space pre-filtering as integration and uses Monte-Carlo sampling for parameter-space pre-filtering outside the DSL [S1]. Ours uses $10^5$ samples for the RHS, $10^4$ for LHS quadrature, and 1 sample for LHS integrand pre-filtering. TEG uses 10 samples for the inner LHS integrand [S1]. Ours uses adaptive 1D axis prefiltering and dense outer sampling to smooth noise, while TEG uses 2D image-space integration, trapezoid rule for the outer integral, and fewer inner samples due to DSL constraints [S1].

## Operating characteristics
*   **Time Complexity:** The method requires evaluating the derivative of the original function $f$ and averaging it over the kernel support. The complexity depends on the cost of computing $f$ and its derivative. For the variant, it involves adaptive axis selection and pre-filtering, which adds overhead compared to direct sampling [S1].
*   **Memory Complexity:** Low, as it primarily operates on scalar values and small kernel supports.
*   **Measured Performance:** In experiments, the method (Ours) converges close to the target image for simple shapes like circles, similar to the Dual-Buffer Gradient Estimator (DVG). However, for complex shapes like rings, DVG may fail to converge due to bugs, while Ours remains robust [S1]. The dense outer sampling in Ours helps smooth out noisy integrand estimates [S1].
*   **Strengths:** Guarantees first-order correctness for continuous and discontinuous functions (under specific conditions). Robust to aliasing due to dense sampling in the variant.
*   **Limitations:** Requires careful selection of $\epsilon$ to avoid multiple discontinuities in the kernel support. Excludes higher-order discontinuities.
*   **When to Use:** When differentiating through shaders with discontinuities is required, and first-order accuracy is critical. Suitable for interactive applications where robustness is preferred over speed [S1].

## Background
The method originates from the paper "A $\delta$" by Yuting Yang, Connel… (full author list: Connelly Barnes, Andrew Adams, and Adam Finkelstein), published in ACM Transactions on Graphics, Vol. 41, No. 4, Article 135, July 2022 [S1]. It is part of a minimal DSL for differentiable rendering that ensures first-order correct gradient approximations for a subset of programs. The method was developed to address the challenges of gradient estimation in the presence of discontinuities, which are common in volume rendering and other graphics applications.
