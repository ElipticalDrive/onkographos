# Sampling Diagonal of Hessian

Also called: Diagonal Hessian PDF Derivation

## Overview
Sampling Diagonal of Hessian is a technique for constructing a probability density function (PDF) from the second-order derivative (Hessian) of a Gaussian function, enabling importance sampling of the diagonal elements of the Hessian matrix in differentiable volume rendering. It sets itself apart from standard gradient estimators by utilizing curvature information (second derivatives) rather than first-order gradients to determine sampling weights, which is particularly relevant for higher-order differentiable rendering and optimization [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** The standard deviation $\sigma$ of the 1D Gaussian $N(\tau_i)$.
*   **Output:** A Cumulative Distribution Function (CDF) $P^H_{ii}(\tau_i)$ and a scaling constant $\beta$, allowing for the generation of samples $\tau_i$ distributed according to the magnitude of the diagonal Hessian element.

**Data Structures:**
*   No complex data structures are required; the method relies on scalar arithmetic and standard mathematical functions (exponential, square root).

**Steps:**
1.  **Identify Roots:** Determine the roots of the second-order derivative of the Gaussian. The second-order derivative is zero when $\tau_i = \pm \sigma$ [S1].
2.  **Calculate Scaling Constant $\beta$:** Compute $\beta$ using the first-order gradient of the Gaussian evaluated at $-\sigma$. The formula is derived from the requirement that the integral of the positivized PDF over $[-\sigma, \sigma]$ is twice the integral outside this range, ensuring the CDF reaches $1/2$ at $\tau_i = -\sigma$ [S1].
    $$ \beta = \frac{1}{4 \nabla N(-\sigma)} $$
    Note: The source text contains a conflicting formula in the "step" notes ($\beta = \nabla z ...$) but the explicit derivation in the source passages (Eq. 50) and the CDF definition (Eq. 47) consistently use $\beta = \frac{1}{4 \nabla N(-\sigma)}$ [S1].
3.  **Construct the PDF:** The PDF for the diagonal Hessian is defined as the absolute value of the scaled second-order derivative:
    $$ p^H_{ii}(\tau_i) = |\beta \nabla^2 N(\tau_i)| $$
    The 1D Gaussian second-order derivative is given by:
    $$ \nabla^2 N(\tau_i) = \left( \frac{1}{\sigma^2} - \frac{\tau_i^2}{\sigma^4} \right) N(\tau_i) $$
    [S1]
4.  **Construct the CDF:** Define the CDF $P^H_{ii}(\tau_i)$ piecewise to ensure it is non-decreasing and integrates to 1. The function $\nabla N(\tau_i)$ is the first-order gradient of the Gaussian.
    $$
    P^H_{ii}(\tau_i) =
    \begin{cases}
    \beta \nabla N(\tau_i) & \text{if } \tau_i < -\sigma \\
    \frac{1}{2} + \beta \nabla N(\tau_i) & \text{if } \tau_i \in [-\sigma, \sigma] \\
    1 - \beta \nabla N(\tau_i) & \text{if } \tau_i > \sigma
    \end{cases}
    $$
    [S1]
    *Note:* The source states that for $\tau_i \in [-\sigma, \sigma]$, the function value of the raw gradient term is negative, requiring "positivization" via the piecewise construction (adding $1/2$ and adjusting signs) to form a valid CDF [S1].

## Subtopics

### Gram Matrix Accumulation
A related technique used in SplatQ for pruning 3D Gaussians, which computes the Gram matrix $R_b = J_b^T J_b$ and diagonal scores $D_i$ for a block by accumulating outer products of the sampled opacity Jacobian $J_b$ over batches. It differs from Sampling Diagonal of Hessian by operating on the Jacobian of the rendering equation (opacity response) rather than the analytic Hessian of the Gaussian basis function itself. It is chosen when block-wise pruning based on interaction-aware quadratic selection is required. The diagonal score $D_i$ is calculated as $(R_b)_{ii} = \sum_{(v,p) \in P_b} \sum_{q=1}^3 (J_b)_{(v,p,q),i}^2$ [S2, unofficial]. A pitfall is that if no valid pixels are sampled across selected views, the matrix remains zero-initialized [S2, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
The derivation of the PDF and CDF is $O(1)$ per sample. The sampling process itself requires numerical root-finding if a closed-form inverse is not used, which is typically $O(k)$ where $k$ is the number of iterations for convergence. Memory complexity is $O(1)$ as only scalar values are stored.

**Measured Performance:**
Not given in the sources.

**Strengths and Limitations:**
*   **Strengths:** Provides a principled way to sample based on curvature (Hessian), which can be more informative than gradient magnitude for optimization landscapes involving second-order effects.
*   **Limitations:** Requires computing second derivatives. The CDF inversion is not closed-form, necessitating numerical methods which can be slower and less stable than direct sampling from standard distributions.

**When to use/not use:**
Use when higher-order differentiable rendering or Hessian-based optimization (e.g., Adahessian) is employed. Not suitable for first-order gradient estimators where standard gradient-based sampling suffices.

## Background
The method originates from the paper "Stochastic Gradient Estimation for Higher-Order Differentiable Rendering" [S1]. It builds upon the concept of marginalizing the probability density function over dimensions to sample individual components of a multi-dimensional Gaussian gradient [S1]. The derivation relies on the properties of the Gaussian second-order derivative, specifically its roots at $\pm \sigma$ and its symmetry.
