# Axis-Aligned Neighbor Smoothing

Also called: Weighted Axis-Aligned Smoothing

## Overview
Axis-Aligned Neighbor Smoothing is a weighted smoothing filter that averages color values along a single axis using depth, normal, and color similarity to preserve edges and reduce noise [S1, unofficial]. It differs from [Smooth Gradient Estimation via Convolution](6449-smooth-gradient-estimation-and-smoothing.md) by restricting the kernel to a single axis and using feature-aware weights, and from [Non-local Approximated Gradients](6784-non-local-approximated-gradidents.md) by its strict axis-aligned locality and reliance on explicit geometric buffers [S1, unofficial].

## How it works
The method operates as a fragment shader pass that reads a color texture and a packed normal/depth texture, computes weighted averages of neighbors along a specified axis, and writes the smoothed color [S1, unofficial].

**Inputs and Outputs:**
*   Input 0: `color_texture` (`texture_2d<f32>`), containing the current frame's RGBA color [S1, unofficial].
*   Input 1: `normal_depth_texture` (`texture_2d<f32>`), containing packed normal vectors and depth values [S1, unofficial].
*   Output: `vec4f` at location 0, the smoothed color [S1, unofficial].

**Data Structures and Layout:**
The shader samples textures at coordinates offset by integer steps along the chosen `axis` [S1, unofficial]. The `normal_depth_texture` must provide $d$ (depth value), $\mathbf{n}$ (normal vector), $d'$ (neighbor depth), $\mathbf{n}'$ (neighbor normal), and $\mathbf{c}'$ (neighbor color) for each pixel [S1, unofficial].

**Parameters:**
*   `R`: Radius of the smoothing window. Default: `7` [S1, unofficial].
*   `WINDOW`: Window size, calculated as `R * 2 + 1` [S1, unofficial].
*   Constants: depth scale `0.1`, depth epsilon `0.01`, distance scale `0.005`, and color scale `2.0` [S1, unofficial].

**Algorithm Steps:**
1.  Initialize `result = vec4f(0.0)` and `sum_w = 0.0` [S1, unofficial].
2.  For each integer offset `i` in the range `[-R, R]` along `axis`:
    a.  Compute neighbor coordinate: `pos = frag_pos` with `pos[axis] += i` [S1, unofficial].
    b.  Load `normal_depth2` and `color2` at `pos` to get $\mathbf{n}'$, $d'$, and $\mathbf{c}'$ [S1, unofficial].
    c.  Compute weights: $w_z = \exp(-|d - d'| \cdot 0.1 / (\text{fwidth}(d) + 0.01))$, $w_n = |\mathbf{n} \cdot \mathbf{n}'|$, $w_d = \exp(-i^2 \cdot 0.005)$, $w_c = \exp(-\|\mathbf{c} - \mathbf{c}'\|^2 \cdot 2.0)$ [S1, unofficial].
    d.  Compute total weight: $w = w_n \cdot w_z \cdot w_d \cdot w_c$ [S1, unofficial].
    e.  Accumulate: `result += color2 * w` and `sum_w += w` [S1, unofficial].
3.  Compute `result *= 1.0 / sum_w` [S1, unofficial].
4.  Return `result` [S1, unofficial].

**Pseudocode:**
```python
def axis_aligned_neighbor_smoothing(frag_pos, axis, R=7):
    # frag_pos: (x, y) coordinates of the current pixel
    # axis: 'x' or 'y'
    # Returns smoothed vec4f

    # Standard texture sampling operation [G]
    def texture_2d_read(tex, uv):
        # Returns vec4f from tex at uv using standard filtering
        pass

    # Standard derivative magnitude approximation [G]
    def fwidth(val):
        return abs(val)

    # Current pixel data
    n, d = texture_2d_read(normal_depth_texture, frag_pos)
    c = texture_2d_read(color_texture, frag_pos)
    fw_d = fwidth(d)

    result = [0.0, 0.0, 0.0, 0.0]
    sum_w = 0.0

    for i in range(-R, R + 1):
        if axis == 'x':
            pos = (frag_pos[0] + i, frag_pos[1])
        else:
            pos = (frag_pos[0], frag_pos[1] + i)

        n_prime, d_prime = texture_2d_read(normal_depth_texture, pos)
        c_prime = texture_2d_read(color_texture, pos)

        w_z = exp(-(abs(d - d_prime) * 0.1) / (fw_d + 0.01))
        w_n = abs(dot(n, n_prime))
        w_d = exp(-(i * i) * 0.005)
        color_diff_sq = sum((c[k] - c_prime[k])**2 for k in range(4))
        w_c = exp(-color_diff_sq * 2.0)

        w = w_n * w_z * w_d * w_c
        for k in range(4):
            result[k] += c_prime[k] * w
        sum_w += w

    if sum_w > 0.0:
        result = [r * (1.0 / sum_w) for r in result]
    return result
```

**Edge Cases and Pitfalls:**
*   Division by zero in the depth weight denominator is avoided by adding `0.01` to `fwidth(d)` [S1, unofficial].
*   If `sum_w` is zero, the result remains zero [S1, unofficial].
*   Boundary conditions: Sampling outside the texture bounds must be handled (e.g., clamping or repeating) to avoid undefined behavior [G].

## Subtopics

### K-Nearest Neighbor Feature Smoothing with Dropout
A variant that smooths Gaussian semantic features rather than image colors [S2, unofficial]. It averages features with the K nearest neighbors in 3D space, optionally applying dropout to selected neighbors to prevent over-smoothing or mode collapse [S2, unofficial]. It is chosen when semantic consistency across spatially close primitives is required, such as in 3D Gaussian Splatting optimization [S2, unofficial].
*   **Definition:** Smoothing of Gaussian semantic features by averaging with K nearest neighbors, optionally applying dropout to selected neighbors [S2, unofficial].
*   **Steps:**
    1.  If $K \le 1$, return original `self.gaussian_semantic_features` [S2, unofficial].
    2.  Compute K-nearest neighbors indices for all Gaussians using `pytorch3d.ops.knn_points` on `xyz` and store in `self.feature_smooth_map` [S2, unofficial].
    3.  Normalize features: `normed_features = torch.nn.functional.normalize(self.gaussian_semantic_features, dim=-1, p=2)` [S2, unofficial].
    4.  If `0 < dropout < 1`, select random subset of neighbors: `select_point = torch.randperm(K)[: int(K * dropout)]` [S2, unofficial].
    5.  Gather features for selected neighbors and average: `ret = normed_features[select_idx, :].mean(dim=1)` [S2, unofficial].
    6.  If no dropout, average all K neighbors: `ret = normed_features[self.feature_smooth_map["m"], :].mean(dim=1)` [S2, unofficial].
*   **Parameters:** $K$: Number of nearest neighbors. Default: 16 [S2, unofficial].

## Background
The method originates from implementations in differentiable rendering and neural rendering pipelines, specifically within the `voxel_ray_demo` project by newDINO [S1, unofficial]. It is designed to stabilize gradient-based optimization in volume rendering or rasterization-based novel view synthesis by ensuring that the rendering integrand is sufficiently smooth to allow Leibniz's rule to exchange differentiation and integration [S1, unofficial].
