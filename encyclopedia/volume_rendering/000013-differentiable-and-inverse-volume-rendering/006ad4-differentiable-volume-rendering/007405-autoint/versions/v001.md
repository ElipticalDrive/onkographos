# AutoInt
Also called: Automatic Integration, Learning the volume integral directly

## Overview
AutoInt is a framework for learning efficient, closed-form solutions to integrals using coordinate-based neural networks, specifically applied to accelerate neural volume rendering [S1]. It solves the problem of extreme computational and memory requirements in neural volume rendering caused by Monte Carlo sampling, which requires hundreds of forward passes per ray to approximate integrals [S1]. Unlike standard differentiable volume rendering which relies on numerical quadrature or reverse-mode automatic differentiation through the rendering integral [S1][S5, unofficial], AutoInt learns an antiderivative network that allows definite integrals to be computed via two network evaluations using the Newton-Leibniz formula [S1]. This reduces the number of network queries from hundreds to just two, improving render times by greater than 10× compared to NeRF, at the cost of slightly reduced image quality [S1].

## How it works
AutoInt approximates the volume rendering equation (VRE) by separating it into piecewise sections, allowing the rendering step to use far fewer samples [S2]. The core mechanism involves training a "grad network" (representing the derivative of the output with respect to input coordinates) and automatically deriving an "integral network" (the antiderivative) from it [S1].

### Inputs and Outputs
*   **Inputs:** Training images $\mathbf{C}$ with known camera poses $(\mathbf{o}, \mathbf{d})$; ground truth pixel values.
*   **Outputs:** An optimized integral network $\Phi_{\theta^*}$ capable of evaluating definite integrals of the signal $f(\mathbf{x})$ (e.g., radiance weighted by transmittance) along rays.

### Data Structures
The method relies on two coordinate-based neural networks with shared parameters $\theta$:
1.  **Integral Network ($\Phi_\theta$):** A Multilayer Perceptron (MLP) representing the antiderivative.
    *   Architecture: $\Phi_\theta(\mathbf{x}) = \mathbf{W}_n(\phi_{n-1} \circ \dots \circ \phi_0)(\mathbf{x})$.
    *   Layer definition: $\phi_k(\mathbf{y}) = \text{NL}_k(\mathbf{W}_k \mathbf{y} + \mathbf{b}_k)$.
    *   Parameters: $\theta = \{\mathbf{W}_k \in \mathbb{R}^{N_k \times M_k}, \mathbf{b}_k \in \mathbb{R}^{M_k}, \forall k\}$.
    *   Nonlinearity: Swish is recommended for best generalization [S1].
2.  **Grad Network ($\Psi_\theta^i$):** Represents the partial derivative $\partial\Phi_\theta/\partial x_i$.
    *   Structure: Derived from the Directed Acyclic Graph (DAG) of $\Phi_\theta$.
    *   Computation: $\Psi_\theta^i(\mathbf{x}) = \hat{\phi}_{n-1} \circ (\phi_{n-2} \circ \dots \circ \phi_0)(\mathbf{x}) \odot \dots \odot \hat{\phi}_1 \circ \phi_0(\mathbf{x}) \odot \mathbf{W}_0 \mathbf{e}_i$.
    *   Helper: $\hat{\phi}_k(\mathbf{y}) = \mathbf{W}_k^T \text{NL}'_{k-1}(\mathbf{W}_{k-1} \mathbf{y} + \mathbf{b}_{k-1})$.
    *   $\mathbf{e}_i$ is the unit vector with 1 at the $i$-th component.
    *   $\odot$ is the Hadamard product.

### Positional Encoding
Inputs are mapped to a higher dimensional space using normalized positional encoding to improve performance in the grad network:
$$ \bar{w}(p) = (\dots, \omega_i^{-1} \sin(\omega_i p), \omega_i^{-1} \cos(\omega_i p), \dots) $$
where $\omega_i = 2^i \pi$. Standard positional encoding $\gamma(p)$ is avoided in the grad network as it introduces exponentially increasing amplitude scaling [S1].

### Numbered Steps

1.  **Instantiate Integral Network:** Choose MLP architecture (layers, features, nonlinearities) for $\Phi_\theta$.
2.  **Instantiate Grad Network:** Use a custom AutoDiff framework to trace the computational graph of $\Phi_\theta$ and explicitly instantiate $\Psi_\theta^i$ while maintaining shared parameters $\theta$. The graph is represented as a DAG using Python Networkx [S1].
3.  **Optimize Grad Network:** Optimize shared parameters $\theta$ by minimizing the loss:
    $$ \theta^* = \arg \min_\theta \mathcal{L}(\Psi_\theta^i(\mathbf{x}), f(\mathbf{x})) $$
    where $f(\mathbf{x})$ is the target signal (e.g., the integrand of the VRE). Use conventional AutoDiff and optimization tools (e.g., Adam) [S1].
4.  **Reassemble Integral Network:** After training, the optimized parameters $\theta^*$ are used to evaluate $\Phi_{\theta^*}$. The grad network is discarded or kept for reference, but inference uses $\Phi_{\theta^*}$ [S1].
5.  **Compute Definite Integrals:** Calculate any definite integral using the Newton-Leibniz formula:
    $$ \int_{a_i}^{b_i} \Psi_{\theta^*}^i(\mathbf{x}) \, dx_i = \Phi_{\theta^*}(\mathbf{x}) \Big|_{x_i=b_i} - \Phi_{\theta^*}(\mathbf{x}) \Big|_{x_i=a_i} $$
    This requires only two evaluations of the integral network [S1].

### Piecewise Volume Rendering Approximation
The VRE cannot be directly integrated due to nested integrals (transmittance). AutoInt approximates the ray with $N$ piecewise sections [S2].
1.  **Sampling Network:** Train a small MLP $S(\mathbf{o}, \mathbf{d})$ to predict interval lengths $\delta \in \mathbb{R}^N$. This allocates more sections in regions with large variations in density [S1].
2.  **Stratified Sampling:** Subdivide each interval $\delta_i$ into $M$ bins. Samples $t_{i,j}$ are drawn uniformly:
    $$ t_{i,j} \sim U\left[t_{i-1} + \frac{j-1}{M} \delta_i, t_{i-1} + \frac{j}{M} \delta_i\right] $$
    for $j = 1, \dots, M$ [S1].
3.  **Rendering:** Evaluate the integral network at the bounds of each piecewise section to compute the contribution, summing them to approximate the final color [S1].

import torch
import torch.nn as nn
import torch.optim as optim

class IntegralNetwork(nn.Module):
    """
    The integral network Phi_theta.
    Uses Swish nonlinearity.
    """
    def __init__(self, input_dim, hidden_dim, num_layers):
        super().__init__()
        layers = []
        for i in range(num_layers):
            in_dim = input_dim if i == 0 else hidden_dim
            out_dim = hidden_dim
            layers.append(nn.Linear(in_dim, out_dim))
            layers.append(nn.SiLU()) # Swish
        layers.append(nn.Linear(hidden_dim, 1)) # Output dimension depends on signal
        self.net = nn.Sequential(*layers)

    def forward(self, x):
        return self.net(x)

class GradNetwork(nn.Module):
    """
    The grad network Psi_theta^i.
    In practice, this is instantiated by tracing the IntegralNetwork
    and computing the derivative w.r.t input coordinate i.
    For implementation, one can use torch.autograd.grad or a custom DAG tracer.
    Here we show the conceptual structure for training.
    """
    def __init__(self, integral_net, input_dim, target_coord_index):
        super().__init__()
        self.integral_net = integral_net
        self.target_coord_index = target_coord_index
        # Note: In the actual AutoInt paper, a custom AutoDiff framework
        # explicitly builds this graph to share weights and avoid re-computation.
        # We simulate the forward pass of the derivative here for clarity.
        
    def forward(self, x):
        # Compute the derivative of the integral network output w.r.t x[target_coord_index]
        # This requires the integral network to output a scalar or we sum over outputs
        x.requires_grad_(True)
        y = self.integral_net(x)
        # Sum over output dimensions if y is multi-dimensional
        y_sum = y.sum()
        grad = torch.autograd.grad(
            y_sum, x, create_graph=True, retain_graph=True
        )[0]
        return grad[:, self.target_coord_index]

def normalized_positional_encoding(p, L=10):
    """
    Normalized positional encoding for AutoInt.
    """
    freq_bands = 2.0 ** torch.arange(L, device=p.device) * torch.pi
    # p shape: [..., 1]
    # freq_bands shape: [L]
    # Output shape: [..., 2*L]
    s = torch.sin(p * freq_bands)
    c = torch.cos(p * freq_bands)
    # Normalize by frequency to prevent amplitude explosion in derivatives
    s = s / freq_bands
    c = c / freq_bands
    return torch.cat([s, c], dim=-1)

def render_with_autoint(integral_net, ray_o, ray_d, bounds_t):
    """
    Render a single ray using the trained integral network.
    """
    # bounds_t is a list of t values [t_0, t_1, ..., t_N]
    # The integral over [t_i, t_{i+1}] is Phi(t_{i+1}) - Phi(t_i)
    
    rendered_color = 0.0
    
    for i in range(len(bounds_t) - 1):
        t_a = bounds_t[i]
        t_b = bounds_t[i+1]
        
        pos_a = ray_o + t_a * ray_d
        pos_b = ray_o + t_b * ray_d
        
        enc_pos_a = normalized_positional_encoding(pos_a, L=10)
        enc_pos_b = normalized_positional_encoding(pos_b, L=10)
        enc_d = normalized_positional_encoding(ray_d, L=4)
        
        input_a = torch.cat([enc_pos_a, enc_d], dim=-1)
        input_b = torch.cat([enc_pos_b, enc_d], dim=-1)
        
        phi_a = integral_net(input_a)
        phi_b = integral_net(input_b)
        
        segment_integral = phi_b - phi_a
        rendered_color += segment_integral
        
    return rendered_color

### Parameters
*   **Network Architecture:** 8 hidden layers, 256 hidden units [S1].
*   **Nonlinearity:** Swish [S1].
*   **Optimizer:** Adam, learning rate $5 \times 10^{-4}$ [S1].
*   **Batch Size:** 4, with 1024 rays sampled from each image [S1].
*   **Learning Rate Decay:** Factor of 0.2 every $10^5$ iterations [S1].
*   **Positional Encoding Depth:** $L=10$ for position $\mathbf{x}$, $L=4$ for direction $\mathbf{d}$ [S1].
*   **Sampling Configuration:** $M = 128/N$ samples within each piecewise interval for $N \in \{2, 4, 8, 16, 32, 64\}$ intervals [S1].

### Edge Cases and Pitfalls
*   **ReLU Nonlinearities:** Using ReLU in the integral network results in step functions in the grad network (derivative is zero almost everywhere), making training difficult [S1].
*   **Quality vs. Speed Trade-off:** Computational speedups come with a reduction in image quality compared to standard NeRF [S1].
*   **Precision:** The method relies on the accuracy of the learned antiderivative. Poor generalization of the nonlinearity (e.g., SIREN overfitting) can lead to errors [S1].

## Operating characteristics
*   **Time Complexity:** Rendering is $O(N)$ where $N$ is the number of piecewise intervals, but each interval requires only 2 network evaluations. Total evaluations per ray: $2N$. Standard NeRF requires hundreds of evaluations per ray.
*   **Memory Complexity:** Training memory is reduced by 15% compared to standard two-step AutoDiff [S1]. Inference memory is dominated by the network weights.
*   **Measured Performance:** On 8 Blender scenes, AutoInt ($N=16$) achieves 26.0 dB PSNR, 15.0 GB memory, and 4.8 s/frame runtime, compared to NeRF's 31.0 dB, 15.6 GB, and 30 s/frame [S1].
*   **Strengths:** >10× faster rendering than NeRF; reduced training iteration time by 1.8×; reduced memory by 15% [S1].
*   **Limitations:** Lower image quality (PSNR) than NeRF; trade-off between speed and quality controlled by $N$ [S1].
*   **When to use:** When rendering speed is critical and slight quality degradation is acceptable.
*   **When not to use:** When photorealistic quality (high PSNR/SSIM) is required.

## Background
AutoInt was introduced in the paper "AutoInt: Automatic Integration for Fast Neural Volume Rendering" [S1]. It is used for neural volume rendering on synthetic datasets with challenging geometries and reflectance properties, evaluated on Blender scenes, Local Light Field Fusion, and DeepVoxels datasets [S1]. It is analogous to conventional fast volume rendering methods like shear-warping and Fourier projection-slice methods, as all use approximations that trade image quality for computational efficiency [S1].
