# Caching for SCL Training

Also called: Standard-Codec-in-the-Loop (SCL) caching

## Overview
This method reduces the computational cost of invoking a standard codec round trip on every mini-batch during Standard-Codec-in-the-Loop (SCL) training, particularly for dynamic scenes where video codecs operate on sequences of frames [S1]. It maintains a per-frame cache of decoded feature planes and density volumes, refreshing them only when necessary based on time or parameter drift [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Current global training step $g$, cached last refresh step $g_{cache}$, current unquantized TriPlane features $P^{ax}_t$ for each axis $ax \in \{xy, xz, yz\}$, current unquantized density grid $D_t$, and a frame index $t$ with associated rays $\{(o, d)\}$ and camera pose $\pi$ [S1].
*   **Outputs:** Updated cached decoded planes $\widehat{P}^{ax}_t$, cached decoded density $\widehat{D}_t$, and the rendered image $I$ [S1].

**Data Structures:**
*   **Cache:** Stores the decoded TriPlane $\widehat{P}^{ax}_t$ and a snapshot of the raw plane $P^{ax}_t$ at the time of refresh for each axis $ax \in \{xy, xz, yz\}$ [S1].
*   **Cache:** Stores the decoded density grid $\widehat{D}_t$ and a snapshot of the raw density $D_t$ at the time of refresh [S1].
*   **Scalar:** $g_{cache}$, the global step at which the last cache refresh occurred [S1].

**Parameters:**
*   $M$: The maximum interval between step-based refreshes. Typical value: $M=128$ [S1].
*   $\epsilon$: Threshold for relative change (drift) to trigger change-based refresh. Measured by normalized $\ell_2$ difference. Value not given in the sources.

**Algorithm:**
1.  Sample a frame index $t$, rays $\{(o, d)\}$, and camera pose $\pi$ [S1].
2.  Determine if a refresh is required:
    *   **Step-based refresh:** If the cache is empty or $g - g_{cache} \ge M$, mark `refresh` as true [S1].
    *   **Change-based refresh:** Calculate the relative change between the current $(P^{ax}_t, D_t)$ and their cached snapshots. If this relative change exceeds $\epsilon$ (measured by normalized $\ell_2$ difference), mark `refresh` as true, even if $g - g_{cache} < M$ [S1].
3.  If `refresh` is true:
    *   Run the encode–decode codec round trip for the video segment to update the cache [S1].
    *   Update $g_{cache} \leftarrow g$ [S1].
4.  Perform Straight-Through Estimator (STE) substitution using cached reconstructions [S1]:
    *   For each axis $ax \in \{xy, xz, yz\}$:
        $$ \widehat{P}^{ax}_t \leftarrow \text{cached decoded plane} $$
        $$ \widetilde{P}^{ax}_t \leftarrow \widehat{P}^{ax}_t + (P^{ax}_t - \texttt{detach}(P^{ax}_t)) $$
    *   For density:
        $$ \widehat{D}_t \leftarrow \text{cached decoded density} $$
        $$ \widetilde{D}_t \leftarrow \widehat{D}_t + (D_t - \texttt{detach}(D_t)) $$
    Here, $\widehat{P}$ and $\widehat{D}$ are the quantized/cached values, $\widetilde{P}$ and $\widetilde{D}$ are the values used for rendering/loss, and $P$ and $D$ are the current unquantized values [S1].
5.  Render and compute losses:
    $$ I \leftarrow \mathcal{R}(\widetilde{\mathcal{P}}_t, \widetilde{D}_t, \pi; \phi) $$
    where $\mathcal{R}$ is the rendering function and $\phi$ represents the network parameters [S1].

**Pseudocode:**
```python
def scl_training_step_with_caching(
    global_step: int,
    frame_index: int,
    rays: List[Tuple[Vector3, Vector3]],
    camera_pose: CameraPose,
    current_planes: Dict[str, Tensor],  # Keys: 'xy', 'xz', 'yz'
    current_density: Tensor,
    cached_decoded_planes: Dict[str, Tensor],
    cached_raw_planes: Dict[str, Tensor],
    cached_decoded_density: Tensor,
    cached_raw_density: Tensor,
    last_refresh_step: int,
    refresh_interval: int = 128,
    drift_threshold: float = 0.01  # Example value, not specified in source
) -> Tuple[Tensor, int, Dict[str, Tensor], Tensor, Dict[str, Tensor], Tensor]:
    """
    Performs one step of SCL training with caching.
    
    Returns:
        rendered_image: The rendered image tensor.
        new_last_refresh_step: Updated last refresh step.
        new_cached_decoded_planes: Updated cached decoded planes.
        new_cached_raw_planes: Updated cached raw planes.
        new_cached_decoded_density: Updated cached decoded density.
        new_cached_raw_density: Updated cached raw density.
    """
    
    # Step 1: Determine if refresh is needed
    refresh_needed = False
    
    # Step-based refresh
    if last_refresh_step == -1 or (global_step - last_refresh_step) >= refresh_interval:
        refresh_needed = True
    
    # Change-based refresh
    if not refresh_needed:
        # Calculate relative change for planes
        plane_drift = 0.0
        for ax in ['xy', 'xz', 'yz']:
            current_p = current_planes[ax]
            cached_p = cached_raw_planes[ax]
            # Normalized L2 difference
            diff = current_p - cached_p
            norm_diff = torch.norm(diff)
            norm_current = torch.norm(current_p)
            if norm_current > 0:
                plane_drift += norm_diff / norm_current
        
        # Calculate relative change for density
        density_drift = 0.0
        current_d = current_density
        cached_d = cached_raw_density
        diff_d = current_d - cached_d
        norm_diff_d = torch.norm(diff_d)
        norm_current_d = torch.norm(current_d)
        if norm_current_d > 0:
            density_drift = norm_diff_d / norm_current_d
            
        # Combine drifts (simple sum, exact combination method not specified)
        total_drift = plane_drift + density_drift
        
        if total_drift > drift_threshold:
            refresh_needed = True

    # Step 2: Perform refresh if needed
    if refresh_needed:
        # Run encode-decode codec round trip for the video segment
        # This updates the cache with decoded values
        # Note: The exact implementation of the codec round trip is external
        # We assume it returns the decoded planes and density
        new_decoded_planes, new_decoded_density = run_codec_round_trip(
            frame_index, current_planes, current_density
        )
        
        # Update cached decoded values
        cached_decoded_planes = new_decoded_planes
        cached_decoded_density = new_decoded_density
        
        # Update cached raw snapshots (the unquantized values at refresh time)
        cached_raw_planes = {ax: current_planes[ax].clone().detach() for ax in current_planes}
        cached_raw_density = current_density.clone().detach()
        
        # Update last refresh step
        last_refresh_step = global_step
    else:
        # No refresh, use existing cache
        pass

    # Step 3: STE Substitution
    # For planes
    rendered_planes = {}
    for ax in ['xy', 'xz', 'yz']:
        cached_decoded_p = cached_decoded_planes[ax]
        current_p = current_planes[ax]
        # STE: Use cached decoded value, add gradient from current unquantized value
        # detach(current_p) ensures gradient flows only through the difference term
        # effectively passing the gradient of the unquantized value to the cached value
        rendered_planes[ax] = cached_decoded_p + (current_p - current_p.detach())
        
    # For density
    cached_decoded_d = cached_decoded_density
    current_d = current_density
    rendered_density = cached_decoded_d + (current_d - current_d.detach())
    
    # Step 4: Render
    # Render using the substituted (rendered) planes and density
    rendered_image = render_volume(rendered_planes, rendered_density, rays, camera_pose)
    
    return rendered_image, last_refresh_step, cached_decoded_planes, cached_raw_planes, cached_decoded_density, cached_raw_density
```

**Edge Cases and Pitfalls:**
*   **Precision:** The STE substitution relies on the difference between the current unquantized value and its detached version. If the quantization error is large, this difference may be significant, potentially affecting gradient stability [S1].
*   **Boundaries:** The change-based refresh depends on the normalized $\ell_2$ difference. If the current planes or density are near zero, the normalization factor becomes small, potentially leading to numerical instability or false triggers. The source does not specify a minimum norm threshold [S1].
*   **Degenerate Input:** If the cache is empty, a refresh is always triggered. This is handled by the step-based refresh condition ($g_{cache} == -1$ or similar) [S1].

## Operating characteristics
*   **Time Complexity:** The cost of the codec round trip is amortized over $M$ training steps. With $M=128$, the overhead is manageable while capturing most of the SCL training benefit [S1].
*   **Memory Complexity:** Requires storing additional cached decoded planes and density grids, as well as snapshots of the raw planes and density at the time of refresh. The size is proportional to the number of axes (3 for TriPlanes) and the resolution of the density grid [S1].
*   **Measured Performance:** Tab. 4 in [S1] shows that increasing $M$ yields a favorable trade-off between accuracy and training efficiency. $M=128$ captures most of the benefit of SCL training [S1].
*   **Strengths:** Reduces training time significantly for dynamic scenes by avoiding frequent codec invocations. The change-based refresh ensures responsiveness to rapid parameter changes early in training [S1].
*   **Limitations:** The cache may lag behind rapid parameter changes if the drift threshold $\epsilon$ is not set appropriately. The step-based refresh alone may not be sufficient for early training stages [S1].
*   **When to use:** When training SCL models on dynamic scenes where codec round trips are computationally expensive.
*   **When not to use:** When the scene is static and the codec overhead is negligible, or when real-time inference latency is critical and cache updates cannot be deferred [S1].

## Background
This caching mechanism was introduced in the CATRF (Codec-Adaptive TriPlane Radiance Fields) paper [S1]. It addresses the computational bottleneck of invoking standard codecs in the training loop, which is particularly problematic for dynamic scenes [S1].
