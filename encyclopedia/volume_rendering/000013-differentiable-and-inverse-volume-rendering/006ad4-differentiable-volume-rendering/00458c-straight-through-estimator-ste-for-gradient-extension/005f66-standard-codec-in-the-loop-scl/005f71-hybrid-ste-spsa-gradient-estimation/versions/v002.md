# Hybrid STE+SPSA Gradient Estimation

Also called: STE+SPSA

## Overview
Hybrid STE+SPSA is a gradient estimation strategy for differentiable volume rendering that combines vanilla Straight-Through Estimator (STE) with Simultaneous Perturbation Stochastic Approximation (SPSA) to handle non-differentiable codecs within a training loop [S1]. It uses vanilla STE during cached steps and applies SPSA only when the codec cache is refreshed [S1]. This hybrid approach avoids the prohibitive cost of applying SPSA at every step, though it yields the worst reconstruction quality and highest training time among tested methods due to high variance and poor signal-to-noise ratio from codec non-linearity [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Current parameter vector $\mathbf{P}$ (e.g., feature planes), codec cache state, perturbation scale $\epsilon$, and objective function $\mathcal{C}_q$ (e.g., reconstruction loss) [S1].
*   **Output:** Gradient estimate $\hat{g}(\mathbf{P})$ for the optimizer [S1].

**Data Structures:**
*   **Codec Cache:** Stores the output of the non-differentiable codec for the current parameters to avoid redundant encoding/decoding [S1].
*   **Perturbation Vector $\Delta$:** A vector of the same dimension as $\mathbf{P}$, where each element $\Delta_i$ is sampled independently from a symmetric Bernoulli distribution ($\Delta_i = \pm 1$ with probability $0.5$) [S1].

**Steps:**
1.  **Check Cache Status:** Determine if the codec cache is active (valid for current $\mathbf{P}$) or needs refresh [S1].
2.  **If Cache is Active:** Use vanilla STE [S1]. The gradient is computed by backpropagating through the decoder as if the codec were the identity function, copying the gradient directly to the pre-codec feature plane [S1].
3.  **If Cache is Refreshed:** Sample a random perturbation vector $\Delta$ where $\Delta_i = \pm 1$ with probability $0.5$ [S1]. Compute the perturbed parameters $\mathbf{P}^+ = \mathbf{P} + \epsilon \Delta$ and $\mathbf{P}^- = \mathbf{P} - \epsilon \Delta$ [S1]. Evaluate the objective function $\mathcal{C}_q$ for both perturbed states, which requires running two additional full codec round trips per iteration [S1]. Compute the SPSA gradient estimate for each component $i$ using the formula [S1]. Use this estimate for the optimizer step [S1].

**Parameters:**
*   **$\epsilon$ (Perturbation Scale):** A small scalar value. Not given in the sources.
*   **$\Delta_i$:** Random variable, $\pm 1$ with $p=0.5$ [S1].

**Pitfalls:**
*   **Computational Cost:** Applying SPSA at every step is prohibitively expensive because it requires multiple additional codec round trips per iteration [S1].
*   **Gradient Quality:** SPSA yields the worst reconstruction quality and highest training time among tested methods due to the high variance of zeroth-order estimates and poor signal-to-noise ratio from severe codec non-linearity [S1].
*   **Alignment:** Although SPSA is less biased in principle, its gradient estimates can be substantially noisier for complex black-box codec round-trips, making them less aligned with the descent direction needed for radiance-field optimization compared to vanilla STE [S1].

**Pseudocode:**
```python
import random

def compute_gradient_hybrid_ste_spsa(P, cache, epsilon, objective_fn):
    """
    Compute gradient using Hybrid STE+SPSA.
    Args:
        P: Current parameter vector (e.g., feature planes).
        cache: Codec cache object with is_valid(P) method.
        epsilon: Perturbation scale.
        objective_fn: Function computing loss C_q, handling codec encoding/decoding.
    Returns:
        gradient: Estimated gradient vector.
    """
    # Check if cache is valid for current P
    if cache.is_valid(P):
        # Step 1: Use vanilla STE for cached steps
        # Vanilla STE: Backpropagate through decoder assuming identity codec
        # Gradient is copied directly to pre-codec features
        loss = objective_fn(P, use_cache=True)
        loss.backward()
        return P.grad
    else:
        # Step 2: Cache needs refresh, use SPSA
        # Sample random perturbation vector Delta
        # Delta_i = +/- 1 with probability 0.5
        Delta = [1.0 if random.random() < 0.5 else -1.0 for _ in P]
        
        # Compute perturbed parameters
        P_plus = [p + epsilon * d for p, d in zip(P, Delta)]
        P_minus = [p - epsilon * d for p, d in zip(P, Delta)]
        
        # Evaluate objective function for both perturbed states
        # This triggers codec encoding/decoding, updating the cache
        C_plus = objective_fn(P_plus, use_cache=False)
        C_minus = objective_fn(P_minus, use_cache=False)
        
        # Compute SPSA gradient estimate
        # g_i = (C(P + e*Delta) - C(P - e*Delta)) / (2 * e * Delta_i)
        gradient = [(C_plus - C_minus) / (2 * epsilon * d) for d in Delta]
        
        return gradient
```

## Operating characteristics
*   **Time Complexity:** Significantly higher than vanilla STE [S1]. When the cache is refreshed, SPSA requires two additional full codec round trips per iteration [S1]. Applying SPSA at every step is described as "prohibitively expensive" [S1].
*   **Memory Complexity:** Requires storing the codec cache and the perturbation vector $\Delta$ [S1]. No additional major memory overhead compared to standard SCL with caching [S1].
*   **Measured Performance:** High-Rate: PSNR 29.63, SSIM 0.930, LPIPS 0.459, Training Time 3h 18m [S1]. Low-Rate: PSNR 27.94, SSIM 0.909, LPIPS 0.650, Training Time 3h 18m [S1]. Training time is reported as identical for high and low rates in the source [S1].
*   **Limitations:** Worst reconstruction quality and highest training time among compared methods (vanilla STE, mSTE, STE+SPSA) due to high variance and poor signal-to-noise ratio from codec non-linearity [S1].
*   **When to Use:** Only when cache refreshes are infrequent enough that the computational cost of SPSA is manageable, and when reducing bias during updates is critical [S1]. However, the source notes that vanilla STE is more robust and provides better overall quality, especially in low-bitrate regimes [S1].
*   **When Not to Use:** When computational efficiency is a priority, or when codec non-linearity introduces too much noise for zeroth-order estimates to be effective [S1]. Vanilla STE is preferred as the default due to robustness [S1].

## Background
The Hybrid STE+SPSA method was introduced in the context of Codec-Adaptive TriPlane Radiance Fields (CATRF) for volumetric content delivery [S1]. It was proposed as a way to improve upon vanilla STE by incorporating insights from black-box gradient approximation methods, specifically SPSA [S1]. The method was evaluated in ablation studies alongside vanilla STE and modified STE (mSTE) [S1]. The authors found that while SPSA is less biased in principle, its practical performance was inferior due to the specific challenges of differentiating through non-linear codecs [S1].
