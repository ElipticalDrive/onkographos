# Generative NeRF-to-NeRF Translation

Also called: Generative NeRF2NeRF Translation

## Overview
Generative NeRF-to-NeRF Translation (GenN2N) is a unified framework that lifts 2D image edits to 3D by modeling the distribution of edited Neural Radiance Fields (NeRFs) via a conditional generative model [S1]. Unlike task-specific editing methods, it employs a plug-and-play 2D image-to-image translator to generate edited views, then learns a latent distribution of 3D edits to ensure multi-view consistency [S1]. It achieves all NeRF editing tasks by performing editing in the 2D domain and lifting 2D edits into the 3D NeRF space [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N$ multi-view images $\{I_i\}_{i=0}^{N-1}$ of a scene [S1].
*   **Output:** A translated NeRF model capable of rendering multi-view consistent 3D scenes corresponding to a user-defined edit (e.g., text, style, super-resolution) [S1].

**Data Structures:**
*   **Edit Code Vector ($z_{ji}$):** A 64-dimensional real-valued vector ($z_{ji} \in \mathbb{R}^{64}$) characterizing the specific edit for a translated image [S1].
*   **Translated Image Set:** A set of $M$ edited images per view, denoted as $\{S_{ji}\}_{j=0}^{M-1}$ for each view $i \in [0, N-1]$ [S1].
*   **Latent Distill Module:** A tiny Multi-Layer Perceptron (MLP) network that maps features from a fixed pre-trained VAE encoder (from Stable Diffusion) to the edit code $z_{ji}$ [S1].

**Parameters:**
*   $N$: Number of source views [S1].
*   $M$: Number of edited images generated per view [S1].

**Steps:**
1.  **Original NeRF Training:** Train an original NeRF on the input multi-view images $\{I_i\}_{i=0}^{N-1}$ using Nerfstudio [S1].
2.  **2D Image Editing:** Use a plug-and-play 2D image-to-image translator to edit each source image $I_i$ [S1]. Generate $M$ distinct edited images $S_{ji}$ for each view $i$ by varying initial noise, forming the translated image set $\{S_{ji}\}_{j=0}^{M-1}$ [S1].
3.  **Latent Distillation:** Map each translated image $S_{ji}$ to an edit code vector $z_{ji}$ [S1]. This is done by passing $S_{ji}$ through a fixed pre-trained VAE encoder (from Stable Diffusion) to extract latent features, then passing these features through the trainable tiny MLP to produce $z_{ji} \in \mathbb{R}^{64}$ [S1].
4.  **Distribution Constraint:** Constrain the distribution of all edit code vectors $\{z_{ji}\}$ to a standard Gaussian distribution $\mathcal{N}(0, I)$ using a Kullback-Leibler (KL) loss, denoted as $\mathcal{L}_{KL}$ [S1].
5.  **NeRF Translation and Rendering:** Conditioned on the edit code $z_{ji}$, render multi-view images $\{C_i\}_{i=0}^{N-1}$ from the translated NeRF [S1].
6.  **Optimization:** Optimize the translated NeRF parameters and the MLP parameters in the Latent Distill Module using three loss functions [S1]:
    *   **Reconstruction Loss ($\mathcal{L}_{recon}$):** Ensures the rendered images match the edited 2D images [S1].
    *   **Adversarial Loss ($\mathcal{L}_{adv}$):** Improves the visual quality and realism of the rendered NeRF [S1].
    *   **Contrastive Loss ($\mathcal{L}_{contr}$):** Enforces 3D consistency and disentangles edits [S1]. It operates by rendering multiple views $C_{ji}$ and $C_{jl}$ from the same NeRF using the same edit code $z_{ji}$ (different poses), passing them back to the Latent Distill Module to extract $z_{ji}$ and $z_{jl}$, and aggregating them to ensure the same edit code yields consistent 3D semantics across views [S1]. For images $S_{ki}$ with different editing styles from $S_{ji}$, the loss increases the distance between their respective edit codes to disentangle different edits [S1].
7.  **Inference:** Sample a latent vector $z$ from the learned Gaussian distribution $\mathcal{N}(0, I)$ [S1]. Render the translated NeRF conditioned on $z$ to generate a multi-view consistent 3D scene with the desired edit [S1].

**Formulas:**
*   **Edit Code Mapping:**
    $$ z_{ji} = \text{MLP}(\text{Encoder}_{\text{SD}}(S_{ji})) $$
    where $\text{Encoder}_{\text{SD}}$ is the fixed VAE encoder from Stable Diffusion and MLP is the trainable network [S1].
*   **KL Loss:**
    $$ \mathcal{L}_{KL} = \text{KL}(q(z|S) || \mathcal{N}(0, I)) $$
    Constraining the aggregate distribution of $z_{ji}$ to a standard normal distribution [S1].
*   **Total Loss:**
    $$ \mathcal{L}_{total} = \mathcal{L}_{recon} + \mathcal{L}_{adv} + \mathcal{L}_{contr} + \lambda \mathcal{L}_{KL} $$
    where $\lambda$ is a weighting factor [G]. The total loss combines the reconstruction, adversarial, contrastive, and KL losses [S1].

**Edge Cases and Pitfalls:**
*   **2D Inconsistency:** The 2D translator may generate inconsistent content across views if different initial noises are used [S1]. The generative model mitigates this by learning a unified 3D distribution, but the quality depends on the diversity of the $M$ generated images [S1].
*   **Precision:** The edit code is a continuous 64-dimensional vector. Discretization or quantization is not mentioned [S1].

## Background
GenN2N was introduced in 2024 by Liu et al. in the paper "GenN2N: Generative NeRF2NeRF Translation" [S1]. It addresses the limitation of previous NeRF editing methods that were designed for individual tasks (e.g., only text editing or only colorization) and often failed to maintain 3D consistency when lifting 2D edits [S1]. The method builds on [Inverse Rendering and Optimization](8999-inverse-rendering-and-optimization.md) by optimizing NeRF parameters through differentiable rendering, but introduces a generative latent space to handle the ambiguity of 2D-to-3D lifting [S1]. It is used for various editing tasks including text-driven editing, colorization, super-resolution, and inpainting of human, item, indoor, and outdoor scenes [S1].
