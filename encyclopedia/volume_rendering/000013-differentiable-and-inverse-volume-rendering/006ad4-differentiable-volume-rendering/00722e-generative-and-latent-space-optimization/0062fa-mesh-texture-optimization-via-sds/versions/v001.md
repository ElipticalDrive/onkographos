# Mesh Texture Optimization via SDS


## Overview
This method optimizes the vertex texture map of a fixed 3D mesh geometry to match a text prompt using Score Distillation Sampling (SDS) gradients, without modifying the mesh vertices or faces [S1, unofficial]. It differs from NeRF optimization [NeRF Training Loop](52-name.md) by optimizing explicit vertex colors rather than implicit volumetric fields, and from image optimization [Iterative Optimization with Learnable Parameters for Diffusion-Guided Radiance Fields](8945-iterative-optimization-with-learnable-parameters-for-diffusi.md) by operating on a 3D geometric primitive with consistent lighting.

## How it works
**Inputs:**
- A text prompt string.
- A fixed 3D mesh defined by vertices $V \in \mathbb{R}^{N_v \times 3}$ and faces $F \in \mathbb{R}^{N_f \times 3}$ (indices).
- A frozen Stable Diffusion model (accessed via `sds` object).
- A soft mesh renderer (PyTorch3D `SoftRenderer`).

**Outputs:**
- Optimized vertex colors $C \in \mathbb{R}^{N_v \times 3}$ (RGB).

**Data Structures:**
- `ColorField`: A PyTorch `nn.Module` or tensor representing the optimizable vertex colors. Initialized by evaluating the field on input vertices.
- `Meshes`: A PyTorch3D object containing vertices, faces, and `TexturesVertex` initialized with the current `ColorField` output.
- `FoVPerspectiveCameras`: Camera object for rendering.

**Parameters:**
- Total iterations: 2000 [S1, unofficial].
- Learning rate: $5 \times 10^{-4}$ [S1, unofficial].
- Weight decay: 0 [S1, unofficial].
- Warmup steps: 100 [S1, unofficial].
- Image resolution: 512 $\times$ 512 [S1, unofficial].
- Camera distance: 3 [S1, unofficial].
- Camera elevation range: Uniform $[5^\circ, 85^\circ]$ [S1, unofficial].
- Camera azimuth range: Uniform $[0^\circ, 360^\circ]$ [S1, unofficial].
- Latent clamp range: $[-1, 1]$ [S1, unofficial].

**Steps:**

1.  **Embedding Preparation**: Create text embeddings from the prompt using `prepare_embeddings(sds, prompt, neg_prompt, view_dependent=False)`. This yields `embeddings["default"]` (conditional) and `embeddings["uncond"]` (unconditional) [S1, unofficial].
2.  **Mesh Initialization**:
    - Load mesh vertices $V$ and faces $F$.
    - Move vertices to the target device and add a batch dimension: $V_{batch} = V.unsqueeze(0)$ [S1, unofficial].
    - Initialize the `ColorField` (optimizable parameter).
    - Evaluate initial colors: $C_0 = \text{ColorField}(V_{batch})$.
    - Create a PyTorch3D `Meshes` object with `TexturesVertex` initialized by $C_0$ [S1, unofficial].
3.  **Renderer Setup**: Initialize a soft mesh renderer with point lights at position $[0, 0, -3]$ and image size 512 [S1, unofficial].
4.  **Optimizer Setup**: Create an AdamW optimizer for `color_field.parameters()` with learning rate $5 \times 10^{-4}$ and weight decay 0. Set up a cosine scheduler with a warmup period of 100 steps [S1, unofficial].
5.  **Training Loop**: For each iteration $i$ in range(2000):
    - Zero gradients.
    - **Update Texture**: Update the mesh textures: `mesh.textures = TexturesVertex(verts_features=color_field(vertices))` [S1, unofficial].
    - **Camera Sampling**: Randomly sample camera pose:
        - Distance: 3.
        - Elevation: $e \sim \text{Uniform}(5, 85)$ degrees.
        - Azimuth: $a \sim \text{Uniform}(0, 360)$ degrees.
        - Create `FoVPerspectiveCameras` with these parameters [S1, unofficial].
    - **Rendering**: Render the mesh with the current camera to get rendered image $I_{rend}$ of shape $(N, C, H, W)$ (permuted from $(N, H, W, C)$) [S1, unofficial].
    - **Encoding**: Encode the rendered image using `sds.encode_imgs(rend_img)` to get latents $z$ [S1, unofficial].
    - **Loss Computation**: Compute SDS loss: $\mathcal{L} = \text{sds.sds\_loss}(z, \text{embeddings["default"]}, \text{embeddings["uncond"]})$ [S1, unofficial].
    - **Backpropagation**: Backpropagate through $\mathcal{L}$.
    - **Optimization Step**: Step the optimizer and the scheduler [S1, unofficial].
    - **Clamping**: Clamp latents to $[-1, 1]$ using `latents.data = latents.data.clip(-1, 1)` [S1, unofficial].

**Pseudocode:**

```python
import torch
import numpy as np
from pytorch3d.structures import Meshes
from pytorch3d.renderer import (
    SoftSilhouetteShader,
    TexturesVertex,
    FoVPerspectiveCameras,
    MeshRenderer,
    RasterizationSettings,
    SoftRenderer
)
from torch.optim import AdamW
from torch.optim.lr_scheduler import CosineAnnealingLR

def mesh_texture_optimization(sds, prompt, vertices, faces, device, total_iter=2000):
    # Step 1: Prepare embeddings
    embeddings = sds.prepare_embeddings(prompt, neg_prompt="", view_dependent=False)
    
    # Step 2: Initialize mesh and color field
    vertices = vertices.unsqueeze(0).to(device)
    # Assume ColorField is a defined nn.Module or tensor
    color_field = ColorField(vertices.shape[1]) 
    color_field = color_field.to(device)
    
    # Initialize textures
    initial_colors = color_field(vertices)
    textures = TexturesVertex(verts_features=initial_colors)
    meshes = Meshes(verts=vertices, faces=faces, textures=textures)
    
    # Step 3: Setup renderer
    lights = PointLights(device=device, location=[[0, 0, -3]])
    raster_settings = RasterizationSettings(image_size=512)
    renderer = SoftRenderer(
        rasterizer=SoftRasterizer(raster_settings=raster_settings),
        shader=SoftSilhouetteShader()
    )
    # Note: The source mentions "soft mesh renderer with point lights". 
    # PyTorch3D SoftRenderer typically uses a shader. 
    # For color rendering, one might use SoftPhongShader or similar. 
    # We assume a generic render function that outputs RGB.
    
    # Step 4: Optimizer and Scheduler
    optimizer = AdamW(color_field.parameters(), lr=5e-4, weight_decay=0)
    scheduler = CosineAnnealingLR(optimizer, T_max=total_iter, eta_min=0)
    # Warmup is handled by the scheduler or a wrapper; 
    # standard CosineAnnealingLR does not have built-in warmup in basic form.
    # We assume a warmup scheduler wrapper is used or implemented.
    
    for i in range(total_iter):
        optimizer.zero_grad()
        
        # Step 5: Update mesh textures
        current_colors = color_field(vertices)
        meshes.textures = TexturesVertex(verts_features=current_colors)
        
        # Camera Sampling
        elevation = torch.tensor([np.random.uniform(5, 85)]).to(device)
        azimuth = torch.tensor([np.random.uniform(0, 360)]).to(device)
        # Distance is fixed at 3
        cameras = FoVPerspectiveCameras(
            device=device,
            elevation=elevation,
            azimuth=azimuth,
            R=torch.eye(3).unsqueeze(0).to(device), # Identity rotation for simplicity, 
                                                     # FoV is default or set
            fov=60 # Default FoV, adjust if needed
        )
        
        # Render
        rend_img = renderer(meshes, cameras=cameras, lights=lights)
        # Ensure shape is (N, C, H, W)
        if rend_img.shape[-1] == 3: # If (N, H, W, C)
            rend_img = rend_img.permute(0, 3, 1, 2)
            
        # Encode
        latents = sds.encode_imgs(rend_img)
        
        # Loss
        loss = sds.sds_loss(latents, embeddings["default"], embeddings["uncond"])
        
        # Backward
        loss.backward()
        
        # Step
        optimizer.step()
        scheduler.step()
        
        # Clamp latents for next iteration if they are stored, 
        # or clamp the input to the encoder if latents are recomputed.
        # The source says "clamp latents", implying they might be cached or 
        # the encoder output is clamped before loss computation if stateful.
        # However, sds_loss usually takes latents as input. 
        # If latents are not cached, this step might be redundant or apply to 
        # a cached latent buffer. We follow the source literally.
        latents.data = latents.data.clip(-1, 1)
        
    return color_field
```

## Operating characteristics
- **Time Complexity**: Linear with respect to the number of iterations (2000) and the cost of rendering + diffusion encoding per iteration.
- **Memory Complexity**: Proportional to the number of vertices (for color field) and the batch size (typically 1).
- **Performance**: The source reports a Mean PSNR of 27.717 and Mean SSIM of 0.926 on its evaluation set [S1, unofficial].
- **Strengths**: Produces textured 3D meshes directly from text prompts without requiring NeRF training or explicit UV unwrapping (vertex colors are used).
- **Limitations**: Geometry is fixed; cannot change shape. Vertex colors may suffer from aliasing or inconsistency across faces if not smoothed.
- **When to use**: When a textured mesh is required from a text prompt and the base geometry is known or fixed.
- **When not to use**: When geometry modification is needed (use NeRF or mesh deformation methods) or when high-fidelity lighting/shadows are critical without spherical harmonics extensions [S1, unofficial].

## Background
This method is part of the "Diffusion-guided-3D-Representations" project by Shashwat Chawla [S1, unofficial]. It extends the concept of Score Distillation Sampling (SDS) [Diffusion-Based Guidance for Radiance Field Optimization](8117-diffusion-based-guidance-for-radiance-field-optimization.md) from image and NeRF optimization to explicit mesh vertex textures. The approach was demonstrated in a course or project context (indicated by "15 points" in the source notes) [S1, unofficial].
