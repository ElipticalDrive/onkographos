# SAR Differentiable Rendering Model

Also called: SAR rendering model, inverse rendering model for SAR

## Overview
The SAR Differentiable Rendering Model is a simplified differentiable rendering technique that generates Synthetic Aperture Radar (SAR) images from a Digital Surface Model (DSM) and a radar backscattering coefficients map [S1]. It solves the problem of synthesizing SAR imagery for inverse rendering tasks by rasterizing piecewise-linear approximations of the terrain directly on the surface, rather than sampling the volume [S1]. This approach departs from standard volume rendering methods by leveraging the heightmap representation to select scatterers exclusively on the surface, which prevents the inefficiency and noise associated with sampling the volume in both angle and range [S1].

## How it works
**Inputs:**
*   Digital Surface Model (DSM) represented as a heightmap $Z(x,y)$ or a set of surface points [S1].
*   Radar backscattering coefficients map $B(x,y)$ [S1].
*   Radar acquisition parameters including azimuth cell resolution $\delta_a$ and range cell definitions [S1].

**Outputs:**
*   Estimated SAR intensity image $\hat{I}$, where $\hat{I}_m$ is the intensity for the $m$-th range cell [S1].

**Data Structures:**
The surface is discretized into $K+1$ points $P_k$ sampled uniformly in ground range, forming $K$ contiguous segments $[P_k, P_{k+1}]$ of length $l_k$ [S1]. These segments are stretched along the azimuth axis by $\delta_a$ to construct $K$ rectangular surface patches [S1].

**Parameters:**
*   $\xi$: Steepness parameter of the logistic sigmoid used for shadow calculation [S1].
*   $\mu$: Accuracy parameter for the smooth maximum function used for range cell contributions [S1].

**Steps:**

1.  **Discretization:** Decompose the surface into $K$ rectangular patches by joining $K+1$ uniformly sampled points $P_k$ into segments $[P_k, P_{k+1}]$ of length $l_k$, then stretching them along the azimuth axis by $\delta_a$ [S1].
2.  **Shadow Calculation:** Compute the shadow indicatrix $\hat{v}_k$ for each patch based on the slope of the line between the antenna and previous points [S1]. Initialize $v_0 = 1$ and $h_0 = 0$ [S1]. For $k \ge 0$, calculate the slope $\eta_k$ of the line between the antenna and point $P_k$ [S1]. Update iteratively: $v_{k+1} = S_\xi(\eta_k - h_k)$ and $h_{k+1} = \eta_k \cdot v_{k+1} + h_k \cdot (1 - v_{k+1})$ [S1]. The shadow indicatrix is $\hat{v}_k = v_{k+1}$, assuming the scatterer is illuminated if and only if its far extremity $P_{k+1}$ is illuminated [S1]. $S_\xi$ is a logistic sigmoid with steepness $\xi$ [S1].
3.  **Range Cell Contribution:** Calculate $\hat{w}_{m,k}$, the proportion of the segment $[P_k, P_{k+1}]$ belonging to the $m$-th range cell [S1]. Let $d_k^-$ and $d_k^+$ be the slant ranges of the segment extremities, and $r_m^-$ and $r_m^+$ be the lower and upper radii of the $m$-th range cell band [S1]. Define the smooth maximum function $M_\mu(a, b) = \frac{a+b}{2} + \frac{(a-b)^2}{2\sqrt{(a-b)^2 + \mu^2}}$ [S1]. Calculate $\hat{w}_{m,k} = \frac{M_\mu(d_k^-, r_m^+) + M_\mu(d_k^+, r_m^-)}{d_k^+ - d_k^-} - \frac{M_\mu(d_k^+, r_m^+) + M_\mu(d_k^-, r_m^-)}{d_k^+ - d_k^-}$ [S1]. This ensures the sum of contributions across cells does not exceed 1 [S1].
4.  **Normalized Radar Cross-Section:** Estimate $\sigma_k^0$ for the patch at the midpoint $P_{k+1/2} = P_k + \frac{P_{k+1}-P_k}{2}$ [S1]. Compute the surface normal $\vec{n}_k$ from the quadrilateral patch [S1]. Compute the local incidence unit vector $\vec{u}_k$ pointing from the sensor to $P_{k+1/2}$ [S1]. Calculate $\sigma_k^0(\vec{u}_k) = B(P_{k+1/2}) \cdot |\vec{u}_k \cdot \vec{n}_k|$ [S1]. This assumes a Lambertian surface with cosine attenuation [S1].
5.  **Intensity Synthesis:** Sum the contributions of all patches for each range cell $m$: $\hat{I}_m = \delta_a \sum_{k=0}^{K-1} \sigma_k^0 \cdot \hat{v}_k \cdot \hat{w}_{m,k} \cdot l_k$ [S1].

**Pseudocode:**

```python
import math

def sigmoid(x, xi):
    """Logistic sigmoid with steepness xi."""
    return 1.0 / (1.0 + math.exp(-xi * x))

def smooth_max(a, b, mu):
    """Smooth maximum function M_mu."""
    diff_sq = (a - b) ** 2
    return (a + b) / 2.0 + diff_sq / (2.0 * math.sqrt(diff_sq + mu ** 2))

def render_sar(points, backscattering_map, azimuth_res, range_cells, xi, mu, antenna_pos):
    """
    Render SAR image from surface points and backscattering map.
    
    Args:
        points: List of P_k points (x, y, z) ordered by increasing ground range.
        backscattering_map: Function B(x, y) returning backscattering coefficient.
        azimuth_res: Delta_a, azimuth cell resolution.
        range_cells: List of (r_min, r_max) for each range cell m.
        xi: Steepness parameter for shadow sigmoid.
        mu: Accuracy parameter for smooth maximum.
        antenna_pos: Tuple (ant_x, ant_y, ant_z) defining antenna location.
        
    Returns:
        intensities: List of intensities I_m for each range cell.
    """
    K = len(points) - 1
    intensities = [0.0] * len(range_cells)
    v_prev = 1.0
    h_prev = 0.0
    ant_x, ant_y, ant_z = antenna_pos

    for k in range(K):
        x_k, y_k, z_k = points[k]
        x_k1, y_k1, z_k1 = points[k + 1]

        l_k = math.sqrt((x_k1 - x_k)**2 + (y_k1 - y_k)**2 + (z_k1 - z_k)**2)

        mid_x, mid_y, mid_z = (x_k + x_k1) / 2.0, (y_k + y_k1) / 2.0, (z_k + z_k1) / 2.0
        B_val = backscattering_map(mid_x, mid_y)

        dx = x_k1 - x_k
        dz = z_k1 - z_k
        norm_len = math.sqrt(dx**2 + dz**2)
        n_k = (dz / norm_len, 0.0, -dx / norm_len) if norm_len > 0 else (0.0, 0.0, 1.0)

        eta_k = (z_k - ant_z) / math.sqrt((x_k - ant_x)**2 + (y_k - ant_y)**2) if math.sqrt((x_k - ant_x)**2 + (y_k - ant_y)**2) > 0 else 0.0

        v_next = sigmoid(eta_k - h_prev, xi)
        h_next = eta_k * v_next + h_prev * (1.0 - v_next)
        v_hat_k = v_next
        h_prev = h_next

        dist_mid = math.sqrt(mid_x**2 + mid_y**2 + mid_z**2)
        u_k = (mid_x / dist_mid, mid_y / dist_mid, mid_z / dist_mid) if dist_mid > 0 else (0.0, 0.0, 0.0)
        dot_prod = abs(u_k[0]*n_k[0] + u_k[1]*n_k[1] + u_k[2]*n_k[2])
        sigma_k0 = B_val * dot_prod

        d_k_minus = math.sqrt(x_k**2 + y_k**2 + z_k**2)
        d_k_plus = math.sqrt(x_k1**2 + y_k1**2 + z_k1**2)

        for m, (r_min, r_max) in enumerate(range_cells):
            denom = d_k_plus - d_k_minus
            if denom == 0:
                continue
            w_hat = (smooth_max(d_k_minus, r_max, mu) + smooth_max(d_k_plus, r_min, mu) -
                     smooth_max(d_k_plus, r_max, mu) - smooth_max(d_k_minus, r_min, mu)) / denom
            intensities[m] += azimuth_res * sigma_k0 * v_hat_k * w_hat * l_k

    return intensities
```

## Subtopics

### Coarse-to-Fine Surface Reconstruction Strategy
A training strategy that reduces sample count in early phases by using coarse scattering rates (larger patches) which contribute to several resolution cells, preventing gaps in synthesized images [S1]. It leverages the noise-free images the rendering model can synthesize from few samples [S1]. The method trains a Multi-Layer Perceptron (MLP) to fit the height $Z(x,y)$ and appearance $B(x,y)$ of a radar scene from a few SAR views [S1]. The MLP models elevation and backscattering coefficients within a bounding box of side $L$ [S1]. The input is $(x,y)$, a 2D position on the ground, encoded with Instant-NGP’s positional encoding $\gamma_P$ [S1]. The outputs are elevation $Z(x,y)$ and backscattering coefficient $B(x,y)$ [S1]. The activation for $B$ is exponential to ensure positive values [S1]. The activation for elevation is $L_8 \cdot \arctan$ to bound values within reasonable limits [S1].

## Operating characteristics
The method rasterizes piecewise-linear approximations of the terrain directly on the surface, leveraging the heightmap representation to select scatterers exclusively on the surface [S1]. This departs from volume rendering which requires sampling the whole volume, making it more efficient for surface reconstruction [S1]. When a coarse scattering rate is used (larger patches), each patch contributes to several resolution cells which prevents creating gaps in the synthesized images [S1]. This property is leveraged by the coarse-to-fine training strategy [S1]. The model is differentiable, allowing for gradient-based optimization of the DSM and backscattering map [S1].

## Background
The SAR Differentiable Rendering Model was introduced in a paper by researchers demonstrating surface reconstruction from SAR images using inverse rendering [S1]. The method draws inspiration from optical approaches and aims to exploit geometric disparities in SAR images [S1]. It was demonstrated on synthetic SAR image datasets produced by ONERA’s physically based EMPRISE® simulator [S1]. The work paves the way for multisensor data fusion and 3D reconstruction from unconstrained SAR images [S1].
