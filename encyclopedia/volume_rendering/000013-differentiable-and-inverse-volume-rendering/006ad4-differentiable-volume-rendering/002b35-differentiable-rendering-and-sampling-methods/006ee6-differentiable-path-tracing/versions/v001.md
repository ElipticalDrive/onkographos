# Differentiable Path Tracing


## Overview
Differentiable Path Tracing makes a full physics-based light transport simulation differentiable for inverse rendering tasks requiring high physical accuracy [S1]. It simulates global illumination effects like soft shadows, caustics, and inter-reflections by using Monte Carlo integration to estimate the rendering equation [S1]. Unlike [Ray Marching with Differential Diffusion](3547-ray-marching-with-differential-diffusion.md) which often relies on simplified volume approximations, this method provides a complete path integral formulation [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Scene parameters $\theta$ (e.g., material BRDFs, light source intensities, geometry), camera parameters, and target imagery.
*   **Outputs:** Rendered image $I$ and gradients $\frac{\partial I}{\partial \theta}$ with respect to scene parameters [S1].

**Steps:**
1.  **Path Generation:** Generate paths using Monte Carlo integration to estimate the rendering equation [S1].
2.  **Rendering:** Simulate global illumination effects including soft shadows, caustics, and inter-reflections [S1].
3.  **Gradient Estimation:** Employ gradient estimators, such as REINFORCE or reparameterization tricks, to compute gradients with respect to scene parameters (e.g., material BRDFs, light source intensities, geometry) [S1].
4.  **Optimization:** Use the computed gradients to optimize complex material properties and lighting conditions from multi-view imagery [S1].

## Subtopics

### [Differentiable Transient Rendering](23754-differentiable-transient-rendering.md)
Differentiable Transient Rendering computes the gradients of the transient path integral with respect to scene parameters, enabling inverse rendering tasks that require high physical accuracy in time-resolved light transport. Unlike steady-state differentiable rendering where scattering events are independent, this method accounts for the total time of flight $\text{tof}(\bar{\mathbf{x}})$, which couples scattering events and requires treating them as a multidimensional, evolving manifold. It approximates the material form of the differential transient path integral using two separate Monte Carlo estimators for interior and boundary integrals, allowing for efficient optimization of parameters such as geometry, light position, and material properties in transient scenarios.
