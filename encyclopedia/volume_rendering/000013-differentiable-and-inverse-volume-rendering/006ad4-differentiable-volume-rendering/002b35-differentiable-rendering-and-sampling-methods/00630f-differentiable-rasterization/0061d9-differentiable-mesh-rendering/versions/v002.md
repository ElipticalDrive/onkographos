# Differentiable Mesh Rendering


## Overview
Differentiable mesh rendering is a family of techniques that make the traditional triangle rasterization or ray-tracing pipeline differentiable, enabling gradient-based optimization of 3D scene parameters (geometry, textures, camera poses) directly from 2D image supervision [S2]. It solves the problem of non-differentiable visibility changes and discrete rasterization steps by introducing soft approximations or analytic gradient estimators [S1, unofficial]. What sets it apart from its siblings is the specific handling of mesh primitives: [Soft Rasterizer](6779-soft-rasterizer.md) and [Generalized Differentiable Renderer (GenDR)](11684-generalized-differentiable-renderer-gendr.md) focus on probabilistic or generalized soft rasterization, while [Stochastic Opacity Masking](20635-stochastic-opacity-masking.md) addresses stochastic visibility; differentiable mesh rendering encompasses both rasterization-based approaches (like OpenDR, NMR, PyTorch3D) and physically-based ray-tracing approaches (like Mitsuba 2, nvdiffrast) that operate on explicit mesh geometry [S1, unofficial][S2].

## Shared principles
The core mechanism involves transforming the discrete, non-differentiable operations of standard rendering into continuous, differentiable functions [S2]. This is achieved through two primary strategies:

1. **Soft Rasterization / Probabilistic Visibility:** Instead of hard occlusion tests, pixels are assigned a probabilistic occupancy based on the mesh's distance or coverage [S2].
2. **Analytic or Automatic Differentiation:** Gradients for attributes (vertex positions, texture coordinates, lighting) are computed either via handcrafted analytic functions that approximate the backward pass of visibility changes [S1, unofficial] or through automatic differentiation (AD) frameworks that track operations through the renderer [S1, unofficial].

The optimization objective typically minimizes a 2D loss (e.g., photometric or silhouette loss) by backpropagating through the differentiable renderer to update the 3D mesh parameters [S2].

## Subtopics

### Automatic Differentiation Frameworks
Renderers that wrap standard rasterization or ray-tracing pipelines in AD-compatible computation graphs [S1, unofficial]. Examples include OpenDR [LB14], which approximates a primary renderer and computes gradients via AD [S1, unofficial], and general-purpose physically based renderers like Mitsuba 2 [NDVZJ19] and Taichi [HLA*19, HAL*20] that support differentiable mesh rendering via AD [S1, unofficial].

### Analytic Gradient Approximations
Methods that derive explicit formulas for the gradient of the rasterization operation, particularly for visibility changes [S1, unofficial]. Neural Mesh Renderer (NMR) [KUH18] approximates the backward gradient using a handcrafted function for visibility changes [S1, unofficial]. Paparazzi [LTJ18] uses image filters for analytic differentiable rendering [S1, unofficial].

### Soft Blending and Probabilistic Maps
Techniques that render probabilistic maps of mesh triangles to allow gradient flow to occluded vertices [S1, unofficial]. Soft Rasterizer [LLCL19] aggregates these probabilistic maps [S1, unofficial]. Pix2Vex [PBDCO19] uses $C^\infty$ differentiable soft blending schemes of nearby triangles [S1, unofficial].

### Physically Based Differentiable Ray Tracing
Extending differentiability to physics-based effects like soft shadows and indirect illumination. [LHL*21] supports differentiable rendering of soft shadows [S1, unofficial]. [LADL18a] and [ALKN19] introduced differentiable ray tracers for physics-based rendering effects, handling camera position, lighting, and texture [S1, unofficial].

### Modern GPU-Accelerated Implementations
High-performance implementations optimized for deep learning frameworks [S2]. PyTorch3D and NVIDIA's nvdiffrast implement soft rasterization techniques, allowing for inverse graphics tasks such as fitting a 3D model to a 2D image [S2].

## Background
The concept of differentiable rendering bridges computer graphics and machine learning by making the image synthesis pipeline differentiable [S2]. Early work included OpenDR [LB14], which approximated a primary renderer and computed gradients via automatic differentiation [S1, unofficial]. The Neural Mesh Renderer (NMR) [KUH18] introduced handcrafted gradient approximations for visibility changes [S1, unofficial]. Subsequent developments included Paparazzi [LTJ18] using image filters [S1, unofficial], Pix2Vex [PBDCO19] with $C^\infty$ soft blending [S1, unofficial], and Soft Rasterizer [LLCL19] with probabilistic maps [S1, unofficial]. The field expanded to include physically based effects with soft shadows [LHL*21] and full ray tracing [LADL18a, ALKN19], as well as general-purpose AD-compatible renderers like Mitsuba 2 [NDVZJ19] and Taichi [HLA*19, HAL*20] [S1, unofficial]. Modern frameworks like PyTorch3D and nvdiffrast have popularized these techniques for inverse graphics [S2].
