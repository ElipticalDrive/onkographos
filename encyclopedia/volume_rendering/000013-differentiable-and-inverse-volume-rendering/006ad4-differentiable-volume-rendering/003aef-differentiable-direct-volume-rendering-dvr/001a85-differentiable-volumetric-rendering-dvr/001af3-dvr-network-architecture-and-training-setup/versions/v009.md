# DVR Network Architecture and Training Setup

Also called: DVR Implementation Details, DepthFunction, DepthModule, Differentiable Volumetric Rendering (Depth Estimation via Implicit Surface), Network Architecture and Training Configuration, Volume Rendering Integration

## Overview
This article details the neural network architecture, ray sampling strategy, and training configuration required to implement Differentiable Direct Volume Rendering (DVR) as described in [S4, unofficial]. It solves the problem of configuring the multi-layer perceptron (MLP) and its associated query pipeline to map 3D spatial coordinates and view directions to volumetric density and color, enabling gradient-based optimization of implicit surface representations [G]. It sets apart from siblings like [Direct Voxel Grid Optimization (DVGO)](2184-direct-voxel-grid-optimization-dvgo.md) by relying on a continuous MLP representation queried via equally-spaced ray sampling and a secant method for surface intersection, rather than a discrete voxel grid [G].

## How it works

### Inputs and Outputs
**Inputs:**
*   Ray origins $\mathbf{r}_0$ and directions $\mathbf{d}$ for a batch of pixels [G].
*   Camera parameters $\mathbf{c}$ (e.g., view direction or latent code) [S4, unofficial].
*   Training iteration count $it$ (optional, for adaptive sampling) [S1, unofficial].
*   Decoder network parameters $\theta$ [G].

**Outputs:**
*   Rendered color tensor $C \in \mathbb{R}^{N \times 3}$ [S2, unofficial].
*   Depth tensor $D \in \mathbb{R}^{N \times 1}$ [S2, unofficial].
*   Transmittance and density tensors for loss computation [G].

### Data Structures
**DepthModule Configuration:**
*   `tau` (float): Occupancy threshold. Default: 0.5 [S1, unofficial].
*   `n_steps` (tuple): Initial sampling steps range. Default: `[128, 129]` [S1, unofficial].
*   `n_secant_steps` (int): Refinement steps for root finding. Default: 8 [S1, unofficial].
*   `depth_range` (tuple): Depth interval $[s_0, s_{max}]$. Default: `[0., 2.4]` [S1, unofficial].
*   `schedule_ray_sampling` (bool): Enable adaptive sampling. Default: True [S1, unofficial].
*   `schedule_milestones` (list): Iterations for doubling resolution. Default: `[50000, 100000, 250000]` [S1, unofficial].
*   `init_resolution` (int): Initial sampling count. Default: 16 [S1, unofficial].
*   `max_points` (int): GPU memory limit for point batches. Default: 3,700,000 [S1, unofficial].
*   `check_cube_intersection` (bool): Intersect with unit cube. Default: True [S1, unofficial].
*   `chunk_size` (int): Batch size for forward pass to manage memory. Not given in the sources.

**Network Architecture:**
*   **Combined Network:** 5 fully-connected ResNet blocks with ReLU activation [S4, unofficial].
*   **Output Layer:** 4 dimensions: 1 for occupancy probability, 3 for texture (RGB) [S4, unofficial].
*   **Encoder (Single-View):** ResNet-18 encoder $g_\phi$ outputting a 256-dimensional latent code $\mathbf{z}$ [S4, unofficial].

### Numbered Steps

1.  **Initialization:** Initialize `DepthModule` with parameters listed in Data Structures. Set transmittance $T$ as a tensor of ones with shape $(N, 1)$ for the first segment [S1, unofficial][S2, unofficial].
2.  **Ray Sampling Schedule:** Determine the number of steps $n$ [S4, unofficial].
    *   If `schedule_ray_sampling` is False, use `n_steps` [S1, unofficial].
    *   If True, call `get_sampling_accuracy(it)`:
        *   If `schedule_milestones` is empty, return `[128, 129]` [S1, unofficial].
        *   Initialize `res = init_resolution`.
        *   Iterate through milestones: if $it <$ milestone, return `[res, res + 1]` [S1, unofficial]. Otherwise, double `res` (`res = res * 2`) and continue [S1, unofficial].
        *   Return `[res, res + 1]` after the loop [S1, unofficial].
3.  **Coarse Sampling:** Sample $n$ points along the ray at equal intervals $\Delta s$ [S4, unofficial]. The coordinates are computed as:
    $$ \mathbf{p}_j^{\text{ray}} = \mathbf{r}_0 + (j \Delta s + s_0) \mathbf{d}, \quad j = 0, \dots, n-1 $$
    where $s_0$ is the start of the ray sampling interval [S4, unofficial].
4.  **Implicit Function Evaluation:** Query the decoder network $f_\theta(\mathbf{p}, \mathbf{c})$ for occupancy logits at all sampled points [S4, unofficial].
5.  **Surface Intersection (Secant Method):**
    *   Identify the interval $[d_{low}, d_{high}]$ where the occupancy logit crosses the threshold $\tau$ [S4, unofficial]. Specifically, find $j$ such that $f_\theta(\mathbf{p}_j) < \tau$ and $f_\theta(\mathbf{p}_{j+1}) \geq \tau$ [S4, unofficial].
    *   Apply the secant method for `n_secant_steps` iterations to refine the depth $\hat{d}$:
        1.  Initialize $d_{pred} = (d_{low} + d_{high}) / 2$ [S1, unofficial].
        2.  For $i$ in range `n_secant_steps`:
            *   Compute midpoint $\mathbf{p}_{mid} = \mathbf{r}_0 + d_{pred} \mathbf{d}$ [S1, unofficial].
            *   Compute $f_{mid} = f_\theta(\mathbf{p}_{mid}, \mathbf{c}) - \tau$ [S1, unofficial].
            *   If $f_{mid} < 0$, set $d_{low} = d_{pred}$; else set $d_{high} = d_{pred}$ [S1, unofficial].
            *   Update $d_{pred} = 0.5 (d_{low} + d_{high})$ [S1, unofficial].
6.  **Density and Color Extraction:** Convert occupancy logits to density $\sigma$ and extract color $\mathbf{c}_i$ [S2, unofficial].
    *   Density: $\sigma_i = \text{ReLU}(y_i)$ or similar mapping from the network output [S2, unofficial].
    *   Color: $\mathbf{c}_i = \text{Sigmoid}(y_{:, 1:})$ [S2, unofficial].
7.  **Alpha Compositing:**
    *   Compute segment lengths $\delta_i$ by subtracting adjacent depth values [S2, unofficial]. Append a large value ($10^{10}$) for the last segment to handle ray termination [S2, unofficial].
    *   Compute transmittance: $T_i = T_{i-1} \cdot \exp(-\sigma_{i-1} \delta_{i-1} + \epsilon)$ [S2, unofficial].
    *   Compute weights: $w_i = T_i \cdot (1 - \exp(-\sigma_i \delta_i + \epsilon))$ [S2, unofficial].
    *   Aggregate color: $C = \sum w_i \mathbf{c}_i$ [S2, unofficial].
    *   Aggregate depth: $D = \sum w_i z_i$, where $z_i$ is the depth of the $i$-th sample [S2, unofficial].
8.  **Chunk Processing:** To manage memory, iterate over rays in batches of `chunk_size`, process steps 2-7, and concatenate results [S2, unofficial].

### Pseudocode

```python
import torch
import torch.nn as nn

class DepthFunction(torch.autograd.Function):
    @staticmethod
    def run_Bisection_method(d_low, d_high, n_secant_steps, ray0_masked, ray_direction_masked, decoder, c, logit_tau):
        d_pred = (d_low + d_high) / 2.
        for i in range(n_secant_steps):
            p_mid = ray0_masked + d_pred.unsqueeze(-1) * ray_direction_masked
            with torch.no_grad():
                f_mid = decoder(p_mid, c, batchwise=False, only_occupancy=True) - logit_tau
            ind_low = f_mid < 0
            d_low[ind_low] = d_pred[ind_low]
            d_high[ind_low == 0] = d_pred[ind_low == 0]
            d_pred = 0.5 * (d_low + d_high)
        return d_pred

    @staticmethod
    def forward(ctx, ray0, ray_direction, decoder, c, n_steps, n_secant_steps, tau, 
                depth_range, method, check_cube_intersection, max_points, eps=1e-4):
        n = n_steps[0]
        s0 = depth_range[0]
        ds = (depth_range[1] - s0) / n
        depths = torch.linspace(s0, depth_range[1], n)
        points = ray0.unsqueeze(1) + depths.unsqueeze(0).unsqueeze(0) * ray_direction.unsqueeze(1)
        
        occupancy_logits, colors = decoder(points, c)
        
        crossing_mask = occupancy_logits.squeeze(-1) >= tau
        # Handle case where no crossing is found
        no_crossing = ~crossing_mask.any(dim=1)
        j = torch.argmax(crossing_mask.int(), dim=1)
        j[no_crossing] = n - 1
        
        d_low = depths[j]
        d_high = depths[j + 1]
        d_pred = DepthFunction.run_Bisection_method(d_low, d_high, n_secant_steps, ray0, ray_direction, decoder, c, tau)
        
        fine_depths = torch.linspace(d_pred - ds, d_pred + ds, n).unsqueeze(1)
        fine_points = ray0.unsqueeze(1) + fine_depths * ray_direction.unsqueeze(1)
        fine_occupancy, fine_colors = decoder(fine_points, c)
        
        deltas = torch.diff(fine_depths, dim=1).squeeze(-1)
        deltas = torch.cat([deltas, torch.full((ray0.shape[0], 1), 1e10)], dim=1)
        sigma = torch.relu(fine_occupancy.squeeze(-1))
        
        T = torch.ones(ray0.shape[0], 1).to(ray0.device)
        C = torch.zeros(ray0.shape[0], 3).to(ray0.device)
        D = torch.zeros(ray0.shape[0], 1).to(ray0.device)
        
        for i in range(n):
            T = T * torch.exp(-sigma[:, i] * deltas[:, i] + eps)
            w = T * (1 - torch.exp(-sigma[:, i] * deltas[:, i] + eps))
            C += w.unsqueeze(1) * fine_colors[:, i]
            D += w.unsqueeze(1) * fine_depths[:, i]
            
        return C, D

    @staticmethod
    def backward(ctx, grad_output):
        # Backward pass not given in the sources.
        return None, None, None, None, None, None, None, None, None, None, None, None

        self.decoder = self._build_decoder()
        if cfg.single_view:
            self.encoder = nn.Sequential()

    def forward(self, ray0, ray_direction, c, iteration=None):
        if self.schedule_ray_sampling and iteration is not None:
            n_steps = self.get_sampling_accuracy(iteration)
        else:
            n_steps = self.n_steps
            
        color, depth = DepthFunction.apply(
            ray0, ray_direction, self.decoder, c, 
            n_steps, self.n_secant_steps, self.tau,
            self.depth_range, self.method, 
            self.check_cube_intersection, self.max_points
        )
        return color, depth

    def get_sampling_accuracy(self, it):
        res = self.init_resolution
        for milestone in self.schedule_milestones:
            if it < milestone:
                return [res, res + 1]
            res *= 2
        return [res, res + 1]
```

### Parameters
*   `tau`: Threshold for occupancy logits. Default: 0.5 [S1, unofficial].
*   `n_steps`: Number of evaluation steps. Default: `[128, 129]` [S1, unofficial].
*   `n_secant_steps`: Refinement steps. Default: 8 [S1, unofficial].
*   `depth_range`: Depth interval. Default: `[0., 2.4]` [S1, unofficial].
*   `schedule_ray_sampling`: Enable adaptive sampling. Default: True [S1, unofficial].
*   `schedule_milestones`: Iterations for doubling resolution. Default: `[50000, 100000, 250000]` [S1, unofficial].
*   `init_resolution`: Initial sampling count. Default: 16 [S1, unofficial].
*   `chunk_size`: Batch size for forward pass. Not given in the sources.
*   `white_background`: Composite against white background. Default: False [S2, unofficial].
*   `eps`: Small constant for numerical stability. Not given in the sources.

### Edge Cases and Pitfalls
*   **Precision:** The secant method relies on the occupancy logit crossing the threshold $\tau$. If the network output is flat or noisy, the interval may not be found [G]. Use `check_cube_intersection` to ensure rays intersect the volume of interest [S1, unofficial].
*   **Boundaries:** The last segment delta is set to $10^{10}$ to ensure the ray terminates correctly if the surface is not found within the sampled range [S2, unofficial].
*   **Memory:** Large batches of rays can exceed GPU memory. Use `chunk_size` to process rays in smaller batches [S2, unofficial].
*   **Degenerate Input:** If `n_steps[1] <= 1`, return a tensor of infinity to indicate no rendering [S1, unofficial].

## Subtopics

### [NeRF Model Initialization](1868-nerf-model-initialization.md)
NeRF Model Initialization establishes the neural network architecture, positional encoding functions, and sampling parameters required for Differentiable Direct Volume Rendering (DVR). It solves the problem of configuring the multi-layer perceptron (MLP) and its associated query pipeline to map 3D spatial coordinates and view directions to volumetric density and color. It sets apart from siblings like [Direct Voxel Grid Optimization (DVGO)](2184-direct-voxel-grid-optimization-dvgo.md) by relying on a continuous MLP representation queried via hierarchical sampling rather than a discrete voxel grid, requiring explicit setup of positional encoders and coarse/fine network pairs for importance sampling.

### [Direct Voxel Grid Optimization (DVGO)](2184-direct-voxel-grid-optimization-dvgo.md)
Direct Voxel Grid Optimization (DVGO) is a differentiable volume rendering method that replaces the multi-layer perceptron (MLP) used in NeRF with direct voxel grids for density and color features, enabling significantly faster training and inference. Unlike NeRF-like methods that query a neural network for density from coordinates, DVGO stores density and color directly in 3D grids, allowing for efficient trilinear interpolation and gradient accumulation. It sets itself apart from its sibling [NeRF Model Initialization](1868-nerf-model-initialization.md) by using a dense voxel grid representation rather than a coordinate-based MLP, trading off some representational flexibility for computational speed.

## Operating characteristics
*   **Time Complexity:** $O(N \cdot n \cdot d)$, where $N$ is the number of rays, $n$ is the number of samples per ray, and $d$ is the MLP depth [G].
*   **Memory Complexity:** $O(N \cdot n \cdot d_{out})$ for storing intermediate activations, where $d_{out}$ is the output dimension of the MLP [G]. Chunking reduces peak memory to $O(chunk\_size \cdot n \cdot d_{out})$ [S2, unofficial].
*   **Measured Performance:** Trained on a single NVIDIA V100 GPU with a batch size of 64 images with 1024 random pixels each [S4, unofficial].
*   **Scaling:** Adaptive sampling increases $n$ from 16 to 128 over 250,000 iterations, improving accuracy as training progresses [S4, unofficial].
*   **Strengths:** Differentiable surface intersection allows for gradient-based optimization of implicit surfaces. Adaptive sampling balances speed and accuracy [G].
*   **Limitations:** MLP queries are slower than voxel grid lookups. Secant method requires smooth occupancy fields [G].
*   **When to Use:** When high-quality implicit surface reconstruction is needed and computational resources allow for MLP queries [G].
*   **When Not to Use:** When real-time inference is required or memory is severely constrained; consider [DVGO](2184-direct-voxel-grid-optimization-dvgo.md) instead [G].

## Background
The method was developed to enable learning 3D implicit representations without explicit 3D supervision, using only RGB images [S4, unofficial]. The DVR approach integrates color and density along rays using alpha compositing, computing the final pixel color as a weighted sum of sampled features [S2, unofficial]. It is used in 3D reconstruction, shape editing, and generative modeling of 3D objects [S4, unofficial].
