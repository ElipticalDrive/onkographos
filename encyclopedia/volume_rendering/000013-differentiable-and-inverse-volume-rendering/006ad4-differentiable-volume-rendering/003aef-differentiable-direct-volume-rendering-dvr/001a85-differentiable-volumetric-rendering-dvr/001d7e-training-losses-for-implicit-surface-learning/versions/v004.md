# Training Losses for Implicit Surface Learning

Also called: Photometric and Occupancy Losses

## Overview
This method defines a set of loss functions to train an occupancy network $f_\theta$ and a texture network $t_\theta$ using 2D image supervision, categorizing pixels into three distinct sets: $\mathcal{P}_0$ (inside the object mask with finite predicted depth), $\mathcal{P}_1$ (outside the object mask), and $\mathcal{P}_2$ (inside the object mask but with infinite predicted depth) [S1]. It distinguishes itself from sibling methods by explicitly handling the ambiguity of empty space and missing geometry through specialized freespace and occupancy penalties, rather than relying solely on photometric consistency [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A single image $I_k$ with corresponding camera intrinsics and extrinsics, an object mask $M_k$, and optionally ground truth depth $D_k$ [S1].
*   **Outputs:** Gradients for $\theta$ (occupancy network parameters) and texture parameters.

**Data Structures:**
*   **Point Set $\mathcal{P}_0$:** Pixels $\mathbf{u}$ inside $M_k$ where the predicted depth $\hat{d}$ is finite [S1].
*   **Point Set $\mathcal{P}_1$:** Pixels $\mathbf{u}$ outside $M_k$ [S1].
*   **Point Set $\mathcal{P}_2$:** Pixels $\mathbf{u}$ inside $M_k$ where the predicted depth $\hat{d}$ is infinite [S1].
*   **Ray $\mathbf{r}(d)$:** The ray originating from the camera center through pixel $\mathbf{u}$ at depth $d$ [G].
*   **Surface Point $\hat{\mathbf{p}}$:** The point $\mathbf{r}(\hat{d})$ on the predicted surface [G].

**Parameters:**
*   $N_p$: Number of random pixels sampled on the image plane per training step [S1].
*   $\xi(\cdot)$: Feature extractor for RGB loss. Uses RGB values and optionally image gradients [S1].
*   $\|\cdot\|$: Robust error metric. Uses L1 loss in practice [S1].

**Steps:**
1.  Randomly sample an image $I_k$ and $N_p$ points $\mathbf{u}$ on the image plane [S1].
2.  Classify each $\mathbf{u}$ into sets $\mathcal{P}_0$, $\mathcal{P}_1$, or $\mathcal{P}_2$ based on the mask $M_k$ and the predicted surface depth $\hat{d}$ [S1].
3.  Compute the respective losses for each set (formulas below) [S1].
4.  Sum the losses and backpropagate [S1].

**Formulas:**

**RGB Loss (for $\mathcal{P}_0$):**
Photo-consistency loss using the feature extractor $\xi$ and robust metric $\|\cdot\|$ [S1]:
$$
\mathcal{L}_{\text{rgb}}(\theta) = \sum_{\mathbf{u} \in \mathcal{P}_0} \|\xi(\mathbf{I})_{\mathbf{u}} - \xi(\hat{\mathbf{I}})_{\mathbf{u}}\|
$$
In practice, $\xi$ returns RGB values and optional gradients, and $\|\cdot\|$ is the L1 norm [S1].

**Depth Loss (for $\mathcal{P}_0$, if depth $D_k$ is available):**
L1 loss on predicted vs. ground truth depth [S1]:
$$
\mathcal{L}_{\text{depth}}(\theta) = \sum_{\mathbf{u} \in \mathcal{P}_0} |d - \hat{d}|_1
$$
where $d$ is the ground truth depth and $\hat{d}$ is the predicted depth [S1].

**Freespace Loss (for $\mathcal{P}_1$):**
Binary Cross Entropy (BCE) penalizing occupancy where the surface should not exist [S1]. If a finite surface depth $\hat{d}$ is predicted for a point outside the mask, the network falsely predicts a surface point $\hat{\mathbf{p}} = \mathbf{r}(\hat{d})$. The loss is:
$$
\mathcal{L}_{\text{freespace}}(\theta) = \sum_{\mathbf{u} \in \mathcal{P}_1} \text{BCE}(f_\theta(\hat{\mathbf{p}}), 0)
$$
If no surface depth is predicted (infinite $\hat{d}$), the freespace loss is applied to a randomly sampled point on the ray [S1].

**Occupancy Loss (for $\mathcal{P}_2$):**
BCE encouraging occupancy along rays where a surface is expected but not found [S1]. Uniformly sample depth values $d_{\text{random}}$:
$$
\mathcal{L}_{\text{occupancy}}(\theta) = \sum_{\mathbf{u} \in \mathcal{P}_2} \text{BCE}(f_{\theta}(\mathbf{r}(d_{\text{random}})), 1)
$$
In single-view experiments, $d_{\text{random}}$ is replaced by the visual hull depth (first point inside all object masks) or ground truth depth if available [S1].

**Normal Loss (optional, for $\mathcal{P}_0$):**
Smoothness prior regularizing surface normals [S1]:
$$
\mathcal{L}_{\text{normal}}(\theta) = \sum_{\mathbf{u} \in \mathcal{P}_0} \|\mathbf{n}(\mathbf{p}_{\mathbf{u}}) - \mathbf{n}(\mathbf{q}_{\mathbf{u}})\|_2
$$
where $\mathbf{n}(\cdot)$ is the normal vector, $\hat{\mathbf{p}}_{\mathbf{u}}$ is the predicted surface point, and $\mathbf{q}_{\mathbf{u}}$ is a randomly sampled neighbor of $\hat{\mathbf{p}}_{\mathbf{u}}$ [S1].

**Pseudocode:**
```python
def compute_training_loss(image, mask, depth_gt, K, pose, occupancy_net, texture_net, Np, d_min, d_max, tau=0.5):
    # K: 3x3 intrinsics, pose: 4x4 extrinsics (camera-to-world)
    # Returns scalar total loss
    cam_center = pose[:3, 3]
    K_inv = np.linalg.inv(K)
    H, W = image.shape[:2]

    # 1. Sample Np pixels
    u_idx = np.random.randint(0, W, size=Np)
    v_idx = np.random.randint(0, H, size=Np)
    points = np.stack([u_idx, v_idx], axis=1)

    P0, P1, P2 = [], [], []
    d_hats = {}

    # 2. Classify points and predict depths
    for i, u in enumerate(points):
        uv1 = np.array([u[0], u[1], 1.0])
        ray_dir = K_inv @ uv1
        ray_dir = ray_dir / np.linalg.norm(ray_dir)
        ray_origin = cam_center

        # Predict depth by finding root of occupancy along ray
        d_hat = find_surface_depth(ray_origin, ray_dir, occupancy_net, d_min, d_max, tau)
        d_hats[i] = d_hat

        inside = mask[u[1], u[0]] > 0.5
        if inside:
            if np.isfinite(d_hat):
                P0.append(i)
            else:
                P2.append(i)
        else:
            P1.append(i)

    total_loss = 0.0

    # 3. Compute RGB Loss for P0
    if P0:
        features_gt = []
        features_pred = []
        for i in P0:
            u = points[i]
            d = d_hats[i]
            uv1 = np.array([u[0], u[1], 1.0])
            ray_dir = K_inv @ uv1
            ray_dir = ray_dir / np.linalg.norm(ray_dir)
            p = cam_center + d * ray_dir

            # Extract GT features (RGB + optional gradients)
            gt_feat = np.concatenate([image[u[1], u[0]], compute_image_gradients(image, u)])
            features_gt.append(gt_feat)

            # Predict texture at surface point
            pred_feat = texture_net(p)
            features_pred.append(pred_feat)

        features_gt = np.array(features_gt)
        features_pred = np.array(features_pred)
        total_loss += np.sum(np.abs(features_gt - features_pred))

    # 4. Compute Depth Loss for P0 (if available)
    if depth_gt is not None and P0:
        d_gt_vals = np.array([depth_gt[u[1], u[0]] for i in P0 for u in [points[i]]])
        d_hat_vals = np.array([d_hats[i] for i in P0])
        total_loss += np.sum(np.abs(d_gt_vals - d_hat_vals))

    # 5. Compute Normal Loss for P0 (optional)
    # [G] Implementation detail: Compute normals via finite differences or analytical gradient
    # l_normal = sum(norm(n(p_u) - n(q_u)) for u in P0)
    # total_loss += l_normal

    # 6. Compute Freespace Loss for P1
    if P1:
        l_freespace = 0.0
        for i in P1:
            u = points[i]
            uv1 = np.array([u[0], u[1], 1.0])
            ray_dir = K_inv @ uv1
            ray_dir = ray_dir / np.linalg.norm(ray_dir)
            ray_origin = cam_center
            d_hat = d_hats[i]

            if np.isfinite(d_hat):
                p_hat = ray_origin + d_hat * ray_dir
                occ = occupancy_net(p_hat)
                l_freespace += bce_loss(occ, 0.0)
            else:
                d_rand = np.random.uniform(d_min, d_max)
                p_rand = ray_origin + d_rand * ray_dir
                occ = occupancy_net(p_rand)
                l_freespace += bce_loss(occ, 0.0)
        total_loss += l_freespace

    # 7. Compute Occupancy Loss for P2
    if P2:
        l_occupancy = 0.0
        for i in P2:
            u = points[i]
            uv1 = np.array([u[0], u[1], 1.0])
            ray_dir = K_inv @ uv1
            ray_dir = ray_dir / np.linalg.norm(ray_dir)
            ray_origin = cam_center

            # Single-view or random depth sampling
            d_sample = np.random.uniform(d_min, d_max)
            # [G] In single-view experiments, d_sample is replaced by visual hull or GT depth
            p_sample = ray_origin + d_sample * ray_dir
            occ = occupancy_net(p_sample)
            l_occupancy += bce_loss(occ, 1.0)
        total_loss += l_occupancy

    return total_loss

def find_surface_depth(origin, direction, net, d_min, d_max, tau):
    # Simple bisection to find depth where occupancy crosses tau
    low, high = d_min, d_max
    for _ in range(20):
        mid = (low + high) / 2.0
        p = origin + mid * direction
        occ = net(p)
        if occ < tau:
            low = mid
        else:
            high = mid
    return (low + high) / 2.0 if high < d_max else np.inf

def compute_image_gradients(img, u):
    # [G] Simple finite difference gradient approximation
    h, w = img.shape[:2]
    dy = img[min(u[1]+1, h-1), u[0]] - img[max(u[1]-1, 0), u[0]]
    dx = img[u[1], min(u[0]+1, w-1)] - img[u[1], max(u[0]-1, w-1)]
    return np.array([dy, dx])

def bce_loss(pred, target):
    eps = 1e-7
    pred = np.clip(pred, eps, 1 - eps)
    return -(target * np.log(pred) + (1 - target) * np.log(1 - pred))
```

## Subtopics

### Normalized Object Coordinate Space (NOCS) Volume Rendering
A method focused on novel view synthesis of objects without background, using 3D bounding boxes and object masks to define Normalized Object Coordinate Spaces for per-object volume rendering [S2]. It sets itself apart by refining shape codes, appearance codes, and bounding boxes at test time using an occupancy loss [S2]. The occupancy loss is defined as $\mathcal{L}_{\text{occ}} = \frac{1}{|W_{\text{occ}}|} \sum_{\mathbf{u} \in W_{\text{occ}}} \log(Y_{\mathbf{u}} (1/2 - \alpha) + 1/2)$, where $Y$ is the object mask and $W_{\text{occ}}$ is either the set of foreground or background pixels [S2].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of sampled pixels $N_p$ and the number of points in each set $|\mathcal{P}_0|, |\mathcal{P}_1|, |\mathcal{P}_2|$ [S1].
*   **Memory Complexity:** Depends on the storage of the occupancy and texture networks and the sampled point coordinates [G].
*   **Strengths:** Works with as little as one image per object [S1]. Can incorporate depth information if available [S1]. The normal loss is useful for real-world data to enforce natural shapes in unconstrained areas [S1].
*   **Limitations:** Relies on accurate object masks [S1]. The freespace and occupancy losses depend on the correct classification of pixels, which can be sensitive to depth prediction errors [S1].
*   **When to use:** When training implicit neural representations with 2D image supervision, especially in single-view or sparse-view settings [S1].
*   **When not to use:** Not given in the sources.

## Background
This method originates from the work on learning implicit 3D representations without 3D supervision [S1]. It was developed to address the challenge of training occupancy networks and texture networks using only 2D image data, masks, and optionally depth [S1]. The approach builds on the differentiable volumetric rendering framework [Parent](775-differentiable-volumetric-rendering-dvr.md) [G].
