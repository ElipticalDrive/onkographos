# Symplectic Integration for Derivative Tracing

Also called: Symplectic Derivative Tracing, Symplectic Integration for Gradient of Loss

## Overview
Symplectic Integration for Derivative Tracing is a method to compute the Jacobians $\frac{\partial \mathbf{x}_{s^}}{\partial \mathbf{v}_0}$ and $\frac{\partial \mathbf{v}_{s^}}{\partial \mathbf{v}_0}$ required for the gradient of the loss function in Type-1 direct connections [S1]. It sets itself apart by using a symplectic integrator to propagate both the ray state and its sensitivity to the initial velocity, ensuring numerical stability and energy conservation during the optimization of initial conditions [S1].

## How it works
The method computes the derivatives of the ray's position $\mathbf{x}_{s^}$ and velocity $\mathbf{v}_{s^}$ with respect to the initial velocity $\mathbf{v}_0$ at a target geometric distance $s^$. These derivatives are necessary to calculate $\frac{d\mathcal{L}}{d\mathbf{v}_0}$ for BFGS optimization [S1].

**Inputs:**
- $n(\mathbf{x})$: Refractive index scalar field.
- $\nabla n(\mathbf{x})$: Gradient of the refractive index.
- $H_n(\mathbf{x})$: Hessian of the refractive index.
- $\text{ray}(\mathbf{x}, \mathbf{v})$: Current ray state containing position $\mathbf{x}$ and velocity $\mathbf{v}$.
- $\frac{\partial \mathbf{x}_{s^}}{\partial \mathbf{v}_0}$: Position Jacobian, initialized to the zero matrix $O_3$.
- $\frac{\partial \mathbf{v}_{s^}}{\partial \mathbf{v}_0}$: Velocity Jacobian, initialized to the identity matrix $I_3$.
- $n\text{Steps}$: Number of integration steps.
- $s$: Step size.

**Outputs:**
- $\frac{\partial \mathbf{x}_{s^}}{\partial \mathbf{v}_0}$: Updated position Jacobian.
- $\frac{\partial \mathbf{v}_{s^}}{\partial \mathbf{v}_0}$: Updated velocity Jacobian.

**Algorithm:**
The integration follows a symplectic leapfrog-like scheme. For each step $i$ from 1 to $n\text{Steps}$:

1.  **Half-step velocity update:**
    Update the velocity derivative using the current position derivative and the Hessian of the refractive index at the current ray position.
    $$ \frac{\partial \mathbf{v}_{s^}}{\partial \mathbf{v}_0} \leftarrow \frac{\partial \mathbf{v}_{s^}}{\partial \mathbf{v}_0} + 0.5s H_n(\text{ray}.\mathbf{x}) \frac{\partial \mathbf{x}_{s^}}{\partial \mathbf{v}_0} $$
    Simultaneously, update the ray's velocity vector for the next position step:
    $$ \text{ray}.\mathbf{v}_0 = 0.5s \nabla n(\text{ray}.\mathbf{x}) $$
    *(Note: The source notation $\text{ray}.\mathbf{v}_0$ in the update step likely refers to an intermediate velocity state or a typo for updating the ray's velocity vector $\mathbf{v}$ used in the subsequent position step. Based on standard symplectic integrators, this updates the velocity half-step.)*

2.  **Full-step position update:**
    Update the ray's position using the updated velocity and the refractive index:
    $$ \text{ray}.\mathbf{x}_0 = s \frac{\text{ray}.\mathbf{v}}{n(\text{ray}.\mathbf{x})} $$
    Update the position derivative:
    $$ \frac{\partial \mathbf{x}_{s^}}{\partial \mathbf{v}_0} \leftarrow \frac{\partial \mathbf{x}_{s^}}{\partial \mathbf{v}_0} + s \left( -\frac{\mathbf{v}_s \nabla n(\text{ray}.\mathbf{x})}{n(\text{ray}.\mathbf{x})^2} \frac{\partial \mathbf{x}_s}{\partial \mathbf{v}_0} + \frac{1}{n(\text{ray}.\mathbf{x})} \frac{\partial \mathbf{v}_s}{\partial \mathbf{v}_0} \right) $$
    *(Note: $\mathbf{v}_s$ and $\frac{\partial \mathbf{x}_s}{\partial \mathbf{v}_0}$ refer to the velocity and position derivative values at the start of the step or current state. The term $\frac{\partial \mathbf{x}_s}{\partial \mathbf{v}_0}$ in the source likely refers to the current accumulated position derivative.)*

3.  **Second half-step velocity update:**
    Update the velocity derivative again:
    $$ \frac{\partial \mathbf{v}_{s^}}{\partial \mathbf{v}_0} \leftarrow \frac{\partial \mathbf{v}_{s^}}{\partial \mathbf{v}_0} + 0.5s H_n(\text{ray}.\mathbf{x}) \frac{\partial \mathbf{x}_{s^}}{\partial \mathbf{v}_0} $$
    Update the ray's velocity vector again:
    $$ \text{ray}.\mathbf{v}_0 = 0.5s \nabla n(\text{ray}.\mathbf{x}) $$

**Pseudocode:**
```python
def symplectic_derivative_tracing(n, grad_n, hess_n, ray_x, ray_v, 
                                  dxdv, dvdv, n_steps, s):
    """
    Computes derivatives of ray state w.r.t initial velocity using symplectic integration.
    
    Args:
        n: Function returning refractive index n(x)
        grad_n: Function returning gradient of refractive index grad_n(x)
        hess_n: Function returning Hessian of refractive index hess_n(x)
        ray_x: Current ray position vector (3,)
        ray_v: Current ray velocity vector (3,)
        dxdv: Position Jacobian matrix (3, 3), initialized to zeros
        dvdv: Velocity Jacobian matrix (3, 3), initialized to identity
        n_steps: Integer number of steps
        s: Float step size
        
    Returns:
        dxdv: Updated position Jacobian
        dvdv: Updated velocity Jacobian
    """
    for _ in range(n_steps):
        # Evaluate fields at current position
        n_val = n(ray_x)
        g_n = grad_n(ray_x)
        h_n = hess_n(ray_x)
        
        # Half-step velocity derivative update
        # dvdv += 0.5 * s * h_n @ dxdv
        dvdv = dvdv + 0.5 * s * h_n @ dxdv
        
        # Update ray velocity for position step (half-step)
        # ray_v += 0.5 * s * g_n  [Interpreting ray.v_0 as intermediate velocity]
        # Note: Source uses ray.v_0 = 0.5s grad_n. This implies a reset or specific 
        # symplectic split. Standard leapfrog adds. Assuming additive update for 
        # consistency with symplectic nature, but source says "=". 
        # Given "ray.v_0 = 0.5s grad_n", it might be setting the velocity component 
        # derived from the gradient force. However, ray_v is also used in position step.
        # Let's follow source literally: ray_v is updated.
        ray_v = ray_v + 0.5 * s * g_n 
        
        # Full-step position update
        # ray_x += s * ray_v / n_val
        ray_x = ray_x + s * ray_v / n_val
        
        # Update position derivative
        # dxdv += s * ( - (ray_v * grad_n) / n^2 * dxdv + (1/n) * dvdv )
        # Note: "ray_v * grad_n" in source likely means outer product or element-wise 
        # depending on context. Given dxdv is (3,3), and result is (3,3), 
        # and term is multiplied by dxdv, it's likely a matrix multiplication 
        # involving a Jacobian of the force. 
        # The term -v grad(n) / n^2 is a vector. Multiplying a vector by a matrix (3,3) 
        # is not standard unless it's a diagonal matrix or outer product.
        # Source: - (v_s grad_n(x)) / n(x)^2 * dxdv. 
        # If v_s is a vector and grad_n is a vector, v_s * grad_n is ambiguous.
        # In ray tracing, the force is grad(n). The derivative of the force w.r.t x is H_n.
        # The derivative of the velocity update w.r.t x involves H_n.
        # The derivative of the position update w.r.t v involves 1/n.
        # The derivative of the position update w.r.t x involves -v/n^2 * grad(n).
        # So the term is: s * ( - (v / n^2) outer grad(n) @ dxdv + (1/n) @ dvdv )?
        # Or is it element-wise? 
        # Let's look at the structure: dxdv is (3,3). 
        # The term multiplying dxdv must be (3,3).
        # If it's - (v * grad_n) / n^2, and v, grad_n are vectors, this is likely 
        # an outer product v * grad_n^T or similar.
        # However, source writes: - (v_s grad_n(x)) / n(x)^2 dxdv.
        # Let's assume standard matrix calculus: d(v)/dx = H_n. 
        # The position update is x_new = x + s * v / n.
        # d(x_new)/dv = d(x)/dv + s * ( I/n - v * grad(n)^T / n^2 ) * d(dv)/dv ?
        # No, we are differentiating w.r.t v_0.
        # d(x_{k+1})/dv_0 = d(x_k)/dv_0 + s * d(v_k/n(x_k))/dv_0
        # = d(x_k)/dv_0 + s * ( (1/n) dv_k/dv_0 - (v_k/n^2) grad(n)^T dx_k/dv_0 )
        # So the term is: s * ( (1/n) dvdv - (v_k / n^2) (grad_n^T @ dxdv) )
        # The source writes: - (v_s grad_n(x)) / n(x)^2 dxdv.
        # This matches if "v_s grad_n" implies the outer product structure acting on dxdv.
        
        term1 = - (ray_v / (n_val**2)) * g_n.T @ dxdv  # Assuming outer product logic for vector-matrix mult
        # Correction: In Python, if v is (3,) and g is (3,), v * g is element-wise.
        # We need the Jacobian of the term v/n.
        # d(v/n)/dx = (1/n) I - (v/n^2) grad(n)^T
        # So the update to dxdv is:
        # dxdv += s * ( (1/n) dvdv - (v/n^2) (grad(n)^T @ dxdv) )
        
        # Let's implement the source formula as closely as possible to the text:
        # - (v_s grad_n(x)) / n(x)^2 dxdv
        # If we interpret v_s grad_n as a matrix M where M_ij = v_i * grad_j,
        # then M @ dxdv is the operation.
        
        v_g_outer = np.outer(ray_v, g_n)
        dxdv = dxdv + s * ( - (v_g_outer / (n_val**2)) @ dxdv + (1.0 / n_val) * dvdv )
        
        # Second half-step velocity derivative update
        dvdv = dvdv + 0.5 * s * h_n @ dxdv
        
        # Update ray velocity again
        ray_v = ray_v + 0.5 * s * g_n
        
    return dxdv, dvdv
```

## Operating characteristics
- **Time Complexity:** $O(n\text{Steps} \cdot d^2)$ where $d=3$ is the dimensionality, due to matrix-matrix multiplications in the Jacobian updates.
- **Memory Complexity:** $O(d^2)$ for storing the Jacobian matrices.
- **Strengths:** Symplectic integration preserves the geometric structure of the Hamiltonian system, leading to stable gradients over long integration paths, which is crucial for BFGS optimization [S1].
- **Limitations:** Requires access to the Hessian of the refractive index $H_n(\mathbf{x})$, which may be expensive to compute or approximate [S1].

## Background
The method is described in "Path tracing estimators for refractive radiative transfer" [S1]. It is used to compute gradients for optimizing initial ray velocities to hit specific surface points in refractive media, enabling differentiable rendering techniques that rely on Type-1 direct connections.
