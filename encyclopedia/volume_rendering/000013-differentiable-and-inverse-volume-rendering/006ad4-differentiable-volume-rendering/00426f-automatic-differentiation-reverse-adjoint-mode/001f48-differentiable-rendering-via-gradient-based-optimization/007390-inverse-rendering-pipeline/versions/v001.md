# Inverse Rendering Pipeline
Also called: Differentiable Rendering of Neural SDFs through Reparameterization

## Overview
This method performs inverse rendering by optimizing a neural Signed Distance Function (SDF) and shading network to match a target image, using a reparameterization technique that handles boundary gradients exactly. It differs from approximate differentiable volume rendering methods [4143-single-scattering-differentiable-volume-rendering.md] by computing unbiased gradients for surface boundaries via Monte-Carlo pixel integration, and from differential ratio tracing [4231-differential-ratio-tracing.md] by relying on nested automatic differentiation passes rather than analytical ratio derivations. It solves the problem of recovering geometry and appearance from images when the underlying representation is a neural implicit surface.

## How it works
The pipeline optimizes neural network parameters $\theta$ (SDF weights, shading weights, positional encoding biases) to minimize a loss $L$ between the rendered image and a target image. The rendering is defined by a transformation $T$ from pixel coordinates $u$ to 3D space, modulated by a warp $\mathcal{V}$, and evaluated via the SDF $f$.

**Inputs:**
- Target image $I_{target}$.
- Camera parameters (intrinsics, extrinsics).
- Initial neural network weights.

**Outputs:**
- Optimized SDF network $f$ and shading network.

**Data Structures:**
- **SDF Network:** Multi-layer perceptron (MLP). Input: 3D position $x$. Output: scalar distance $f(x)$. Width: 256 channels per layer [S1].
- **Shading Network:** MLP. Inputs: position $x$, viewing direction $v$, geometric feature vector (from SDF network). Output: radiance. Evaluated only at surface points [S1].
- **Positional Encoding:** 6-levels of sinusoidal positional encoding applied to input position $x$ [S1].
- **Pixel Sampling:** Monte-Carlo samples within each pixel to integrate the spatially-varying warp $\mathcal{V}$ [S1].

**Numbered Steps:**

1.  **Initialization:**
    - Initialize the geometric network to produce an approximate spherical SDF using the method of Atzmon and Lipman [S1].
    - Initialize positional encoding layer weights to 0 [S1].
    - Pad SDF weights with a small $\epsilon$ to avoid infinities during gradient computation [S1].

2.  **Pixel Sampling:**
    - For each optimization iteration, select a subset of pixels.
    - For each selected pixel, generate Monte-Carlo samples within the pixel area to integrate the warp $\mathcal{V}$, rather than using a single center ray [S1].

3.  **Forward Pass (Rendering):**
    - For each sample, compute the 3D position $x$ via the transformation $T(u, \theta)$.
    - Evaluate the SDF $f(x)$ to determine surface intersection.
    - Compute normals $\partial_x f$ using forward-mode automatic differentiation [S1].
    - Evaluate the shading network at the surface point to get radiance.
    - Compute the rendered pixel value by integrating radiance over the pixel samples.

4.  **Gradient Computation (3 Nested Derivative Passes):**
    The total gradient $\partial_\theta [L(T(u, \theta)) |\det(\partial_u T(u, \theta))|]$ is computed using JAX [S1] with nested forward+backward differentiation [S1]:
    - **(i) Normals:** Compute $\partial_x f$ using forward-mode AD [S1].
    - **(ii) Jacobian:** Compute $\partial_u T$ (Jacobian of the transformation) using forward-mode AD [S1].
    - **(iii) Full Pipeline:** Compute derivatives of the full pipeline loss with respect to $\theta$ using reverse-mode AD (backpropagation) [S1].

5.  **Regularization:**
    - Apply Eikonal regularization loss to enforce $|\nabla f(x)| = 1$ [S1].
    - Use a multi-scale pyramid of the target image to stabilize gradients, particularly for silhouette pixels [S1].

6.  **Optimization Step:**
    - Update $\theta$ using gradient descent.

**Formulas:**
- Loss: $L(T(u, \theta)) |\det(\partial_u T(u, \theta))|$ [S1].
- Eikonal Loss: $\mathcal{L}_{eikonal} = \mathbb{E}_{x \sim \text{samples}} [ (|\nabla f(x)| - 1)^2 ]$ [S1].

**Parameters:**
- SDF Network Width: 256 channels [S1].
- Positional Encoding Levels: 6 [S1].
- Epsilon Padding: Small $\epsilon$ (value not specified) [S1].

**Edge Cases and Pitfalls:**
- **Silhouette Gradients:** Unbiased derivatives are non-zero only for pixels partially covered by a surface. Using a subset of pixels makes sampling these pixels rare. Mitigated by multi-scale pyramid [S1].
- **Infinities:** SDF approximation may lead to infinities. Mitigated by padding weights with $\epsilon$ [S1].
- **Memory:** The method is memory-intensive. Mitigated by reducing SDF network width to 256 channels [S1].

## Operating characteristics
- **Time Complexity:** High due to nested automatic differentiation passes and Monte-Carlo sampling. Each iteration requires 3 derivative passes [S1].
- **Memory Complexity:** High. The method is memory-intensive, mitigated by reducing SDF network width to 256 channels [S1].
- **Measured Performance:** Not given in the sources.
- **Scaling:** Uses multi-scale pyramid to handle large images and stabilize gradients [S1].
- **Strengths:** Unbiased gradients for surface boundaries, handles complex geometry via neural SDF, robust initialization [S1].
- **Limitations:** Memory-intensive, slow due to nested AD and Monte-Carlo sampling, requires careful initialization [S1].
- **When to use:** When recovering high-quality geometry and appearance from images using neural implicit representations is required, and computational resources are sufficient.
- **When not to use:** When real-time performance is required, or when the scene is well-approximated by single-scattering volume rendering.

## Background
Originated from the paper "Differentiable Rendering of Neural SDFs through Reparameterization" [S1]. The method builds on neural SDF representations [Yariv et al. 2020] and geometric network initialization [Atzmon and Lipman 2020]. It addresses the limitations of approximate differentiable rendering methods by providing unbiased gradients for surface boundaries.
