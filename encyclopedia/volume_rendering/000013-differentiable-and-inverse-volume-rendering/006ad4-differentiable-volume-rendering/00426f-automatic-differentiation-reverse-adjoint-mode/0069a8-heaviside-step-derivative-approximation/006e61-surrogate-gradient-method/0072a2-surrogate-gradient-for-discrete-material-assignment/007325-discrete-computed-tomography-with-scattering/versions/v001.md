# Discrete Computed Tomography with Scattering

Also called: Discrete CT with Scattering, Discrete assignment with scattering, Inverse CT with scattering, Inverse Rendering for Discrete X-Ray CT with Scattering

## Overview
Discrete Computed Tomography with Scattering extends the discrete material assignment framework to incorporate X-ray scattering effects, treating scattered photons as informative signal rather than noise [S1]. It solves the inverse problem of assigning each voxel to one of $K$ known materials by modeling both absorption and in-scattered radiance, addressing the non-linear coupling where material changes affect local scattering and global transmittance [S1]. Unlike absorptive discrete CT, this method accounts for the angular redistribution of energy via phase functions, enabling reconstruction in scenarios where scattering significantly contributes to the detector signal [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ X-ray projections (detector intensities $I_{\text{det}}$), a dictionary of $K$ candidate materials, each defined by absorption coefficient $\mu_a^{(k)}$, scattering coefficient $\mu_s^{(k)}$, and phase function $p^{(k)}$. The geometry is defined by the source position, detector plane, and voxel grid.
*   **Outputs:** A discrete assignment map $X_i \in \{1, \dots, K\}$ for each voxel $i$, and the corresponding reconstructed volume.

**Data Structures:**
1.  **Voxel Grid:** A 3D array storing the current material assignment $X_i$ for each voxel.
2.  **Incident Radiance Grid ($L_i$):** A 3D voxel grid storing spherical harmonics (SH) coefficients. For each voxel, this stores the coefficients for the incident radiance field from the source, excluding direct illumination. The number of coefficients depends on the SH order $L$.
3.  **Material Dictionary:** A list of $K$ materials, each containing:
    *   $\mu_a^{(k)}$: Absorption coefficient.
    *   $\mu_s^{(k)}$: Scattering coefficient.
    *   $p^{(k)}$: Phase function parameters (e.g., Henyey-Greenstein anisotropy $g$).
    *   $P^{(k)}$: Precomputed zonal harmonic coefficients for the phase function.

**Precomputation:**
1.  For each material $k \in \{1, \dots, K\}$, expand the phase function $p^{(k)}(\boldsymbol{\omega}, \boldsymbol{\omega}')$ into zonal harmonics up to order $L$ [S1]:
    $$
    p^{(k)}(\boldsymbol{\omega}, \boldsymbol{\omega}') \approx \sum_{\ell=0}^L p_\ell^{(k)} Y_\ell^0(\boldsymbol{\omega} \cdot \boldsymbol{\omega}')
    $$
    where $Y_\ell^0$ are the zonal harmonic basis functions [S1].
2.  Store the coefficients $p_\ell^{(k)}$ for each material.

**Optimization Loop:**
The method uses a surrogate gradient approach, clamping voxels to discrete candidates while optimizing a continuous relaxation for the loss calculation [S1]. The core differentiable step involves evaluating the loss for candidate materials without full re-simulation.

1.  **Initialize:** Start with an initial material assignment or continuous relaxation.
2.  **Pass 1: Photon Tracing (Incident Radiance):**
    *   Trace $N_{\text{photons}}$ photons from the X-ray source using random walks [S1].
    *   For each photon, perform a random walk through the volume.
    *   At each step, deposit energy into the **Incident Radiance Grid ($L_i$)** based on the scattering events.
    *   Store the deposited energy as spherical harmonics coefficients in the corresponding voxel [S1].
    *   *Note:* Direct illumination from the source is handled analytically and is not stored in $L_i$ [S1].
    *   *Constraint:* In the discrete assignment step, $L_i$ is held fixed to decouple per-voxel loss evaluation from global light transport [S1].
3.  **Pass 2: Camera Ray Tracing (Forward Model):**
    *   For each camera ray (detector pixel), traverse the voxel grid using DDA [S1].
    *   Compute the total intensity $I(\boldsymbol{\theta}, \mathbf{r})$ at the detector position $\mathbf{r}$ and angle $\boldsymbol{\theta}$ using Equation 18 [S1]:
        $$
        I(\boldsymbol{\theta}, \mathbf{r}) = I_{\text{abs}}(\boldsymbol{\theta}, \mathbf{r}) + \int_0^\infty \hat{\mu}_s(\boldsymbol{\theta}, \mathbf{r}(t)) L_s(\mathbf{r}(t)) dt
        $$
        where $I_{\text{abs}}$ is the absorbed intensity (Beer-Lambert law) and $L_s$ is the scattered radiance [S1].
    *   Compute the scattered radiance $L_s$ at each point $\mathbf{x}$ along the ray using the spherical integral of the phase function and incident radiance (Equation 19) [S1]:
        $$
        L_s(\boldsymbol{\theta}, \mathbf{x}, \boldsymbol{\omega}) = \int_{S^2} \hat{p}(\boldsymbol{\theta}, \mathbf{x}, \boldsymbol{\omega}, \boldsymbol{\omega}') L_i(\boldsymbol{\theta}, \mathbf{x}, \boldsymbol{\omega}') d\boldsymbol{\omega}'
        $$
    *   Using the SH expansion, this integral reduces to an inner product $\langle L_i, p \rangle$ [S1].
    *   Rotate the phase function expansion $P^{(k)}$ into the coordinate frame of the current material assignment for the voxel [S1].
4.  **Loss Evaluation and Gradient Step:**
    *   Compute the loss between the simulated detector intensities and the measured projections.
    *   For each voxel $i$, evaluate the loss for all $K$ candidate materials $k$ by locally updating the optical depth (Equation 17) [S1]:
        $$
        \tau_i(\boldsymbol{\theta}, \mathbf{r}; k) = \tau(\boldsymbol{\theta}, \mathbf{r}) - \hat{\mu}_i \Delta_i + \mu^{(k)} \Delta_i
        $$
        where $\tau$ is the optical depth, $\hat{\mu}_i$ is the current material's coefficient, $\mu^{(k)}$ is the candidate material's coefficient, and $\Delta_i$ is the voxel length along the ray [S1].
    *   This local update allows evaluating all $m$ candidate losses per voxel without retracing the ray [S1].
    *   Traverse each ray twice via DDA: first to compute the base optical depth and residual, then to accumulate per-voxel gradients [S1].
    *   Clamp the voxel assignment to the material $k$ that minimizes the loss [S1].
    *   *Note:* The approximation of holding $L_i$ fixed does not propagate derivatives into the photon tracing portion of the two-pass scheme [S1].

**Pseudocode:**

```python
def discrete_ct_with_scattering(projections, geometry, materials, num_photons, sh_order):
    """
    Reconstructs discrete material assignments incorporating X-ray scattering.
    
    Args:
        projections: Array of measured detector intensities.
        geometry: Source position, detector plane, voxel grid definition.
        materials: List of K materials, each with mu_a, mu_s, phase_function_params.
        num_photons: Number of photons to trace for incident radiance estimation.
        sh_order: Order of spherical harmonics expansion for phase functions.
        
    Returns:
        voxel_assignments: Array of material indices for each voxel.
    """
    K = len(materials)
    voxel_grid = initialize_voxel_grid(geometry) # Initial assignments or continuous relaxation
    incident_radiance_grid = init_sh_grid(geometry, sh_order) # 3D grid of SH coefficients
    
    # Precompute phase function expansions for all materials
    phase_function_coeffs = []
    for mat in materials:
        # Expand phase function into zonal harmonics up to order L
        coeffs = expand_phase_function_zonal_harmonics(mat.phase_function_params, sh_order)
        phase_function_coeffs.append(coeffs)
        
    # Optimization loop (simplified for one step)
    for iteration in range(max_iterations):
        # Pass 1: Trace photons to build incident radiance field
        # Note: In the discrete assignment step, this is held fixed.
        # For the initial setup or continuous relaxation steps, this is updated.
        incident_radiance_grid = trace_photons(
            source=geometry.source,
            voxel_grid=voxel_grid,
            materials=materials,
            num_photons=num_photons,
            sh_order=sh_order
        )
        
        # Pass 2: Evaluate loss for each voxel's candidate materials
        for voxel in voxel_grid:
            current_material_idx = voxel.material_index
            best_loss = infinity
            best_material_idx = current_material_idx
            
            # Evaluate all K candidates
            for k in range(K):
                # Compute optical depth for candidate material k
                # Using local update to avoid full re-trace
                tau_candidate = compute_optical_depth_with_candidate(
                    ray=voxel.ray,
                    voxel=voxel,
                    candidate_material_idx=k,
                    current_material_idx=current_material_idx,
                    materials=materials
                )
                
                # Compute scattered radiance contribution
                # L_s = <L_i, p_k> rotated to voxel frame
                scattered_radiance = compute_scattered_radiance(
                    voxel=voxel,
                    incident_radiance=incident_radiance_grid[voxel],
                    phase_function_coeffs=phase_function_coeffs[k],
                    voxel_orientation=voxel.orientation
                )
                
                # Compute total intensity
                intensity = compute_total_intensity(
                    tau_candidate=tau_candidate,
                    scattered_radiance=scattered_radiance,
                    source_intensity=geometry.source_intensity
                )
                
                # Compute loss against measured projection
                loss = compute_loss(intensity, projections[voxel.detector_pixel])
                
                if loss < best_loss:
                    best_loss = loss
                    best_material_idx = k
            
            # Clamp voxel to best material
            voxel.material_index = best_material_idx
            
    return voxel_grid.material_indices

def expand_phase_function_zonal_harmonics(params, L):
    """
    Expands a phase function (e.g., Henyey-Greenstein) into zonal harmonics.
    """
    coeffs = []
    for l in range(L + 1):
        # Calculate coefficient p_l for order l
        # For Henyey-Greenstein with anisotropy g:
        # p_l = (2l + 1) * g^l / (1 - g^2) ... (simplified, actual formula depends on normalization)
        # [G] Standard zonal harmonic expansion for HG phase function
        coeff = calculate_zonal_harmonic_coefficient(l, params.anisotropy)
        coeffs.append(coeff)
    return coeffs

def trace_photons(source, voxel_grid, materials, num_photons, sh_order):
    """
    Traces photons from source, performing random walks and depositing energy
    into the incident radiance grid as SH coefficients.
    """
    grid = init_sh_grid(voxel_grid.shape, sh_order)
    
    for _ in range(num_photons):
        photon = Photon(source.position, source.direction)
        current_voxel = voxel_grid.get_voxel_at(photon.position)
        
        while photon.alive:
            # Determine step size based on extinction coefficient
            mu_ext = materials[current_voxel.material_index].mu_a + materials[current_voxel.material_index].mu_s
            step = -log(random()) / mu_ext
            
            # Move photon
            photon.position += photon.direction * step
            
            # Check if photon is still in volume
            if not voxel_grid.contains(photon.position):
                break
                
            current_voxel = voxel_grid.get_voxel_at(photon.position)
            
            # Deposit energy into incident radiance grid
            # [G] Energy deposition depends on scattering event
            # For simplicity, assume isotropic scattering for deposit direction
            # The energy is stored as SH coefficients
            energy = photon.weight * step
            deposit_energy_to_sh_grid(grid, current_voxel, photon.direction, energy)
            
            # Determine if scattering occurs
            if random() < materials[current_voxel.material_index].mu_s / mu_ext:
                # Scatter photon
                new_direction = sample_phase_function(
                    materials[current_voxel.material_index].phase_function_params,
                    photon.direction
                )
                photon.direction = new_direction
                photon.weight *= materials[current_voxel.material_index].mu_s / mu_ext
            else:
                # Absorbed
                photon.alive = False
                
    return grid

def compute_scattered_radiance(voxel, incident_radiance, phase_function_coeffs, voxel_orientation):
    """
    Computes scattered radiance L_s as inner product of incident radiance SH
    and phase function SH, rotated to voxel frame.
    """
    # Rotate phase function coefficients to voxel's local frame
    # [G] Rotation of zonal harmonics is efficient
    rotated_coeffs = rotate_zonal_harmonics(phase_function_coeffs, voxel_orientation)
    
    # Inner product of SH coefficients
    # L_s = sum_l (L_i_l * p_l)
    scattered_radiance = 0.0
    for l in range(len(rotated_coeffs)):
        scattered_radiance += incident_radiance[l] * rotated_coeffs[l]
        
    return scattered_radiance
```

**Parameters:**
*   **Spherical Harmonics Order ($L$):** 4 (used in the scattering reconstruction experiment) [S1].
*   **Anisotropy ($g$):** Range $[0.4, 0.5]$ for Henyey-Greenstein phase functions [S1].
*   **Number of Photons:** 5 million (used in the scattering experiment) [S1].

**Edge Cases and Pitfalls:**
*   **Fixed Incident Radiance:** Holding $L_i$ fixed during the discrete assignment step means derivatives are not propagated into the photon tracing portion of the two-pass scheme [S1]. This is an approximation; a fully differentiable scattering implementation is future work [S1].
*   **Non-linearity:** The system is non-linear because changing a voxel's material affects both its local scattering properties and the transmittance of scattered light from other voxels to the camera [S1].
*   **Precision:** The approximation of holding $L_i$ fixed may lead to inaccuracies in gradient estimation for voxels with high scattering contributions [S1].

## Operating characteristics
*   **Time Complexity:** The method involves a two-pass scheme. Pass 1 (photon tracing) is $O(N_{\text{photons}} \cdot N_{\text{steps}})$, where $N_{\text{steps}}$ is the average number of scattering events per photon. Pass 2 (camera ray tracing) is $O(N_{\text{rays}} \cdot N_{\text{voxels\_per\_ray}})$. The loss evaluation for each voxel involves $K$ candidate evaluations, each requiring $O(N_{\text{rays}})$ operations if done naively, but optimized to $O(1)$ per ray using the local optical depth update [S1].
*   **Memory Complexity:** $O(V \cdot (L+1)^2)$ for the incident radiance grid, where $V$ is the number of voxels and $L$ is the SH order. $O(K \cdot (L+1))$ for the phase function coefficients [S1].
*   **Measured Performance:** The method achieves high-fidelity reconstructions in synthetic experiments with 5 million photons and SH order 4 [S1].
*   **Strengths:** Incorporates scattering information, which can improve reconstruction accuracy compared to absorptive-only methods [S1]. Decouples per-voxel loss evaluation from global light transport, enabling efficient discrete assignment [S1].
*   **Limitations:** The fixed incident radiance approximation limits gradient accuracy [S1]. The method is computationally expensive due to photon tracing [S1].
*   **When to Use:** When X-ray scattering is significant and contributes useful information to the detector signal, and a discrete material assignment is required [S1].
*   **When Not to Use:** When scattering is negligible or treated as noise, or when computational resources are limited [S1].

## Background
*   **Origin:** The method extends the work of Geva et al. [2018], who solved an inverse problem for continuous material concentrations incorporating scattering [S1]. This work addresses the discrete assignment problem, building on the framework of [Parent](22571-surrogate-gradient-for-discrete-material-assignment.md) [S1].
*   **History:** X-ray scattering has traditionally been treated as an artifact mitigated by anti-scatter grids, which reduce signal quality [S1]. Geva et al. [2018] demonstrated that scattered photons carry useful information. This method adapts their continuous approach to the discrete setting [S1].
*   **Usage:** Used in X-ray CT reconstruction for multi-material phantoms, showing improved accuracy over methods like SIRT, DART, and TVR-DART [S1].
