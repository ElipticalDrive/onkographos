# Sigma-Threshold Depth Rendering

Also called: Dex-NeRF depth rendering, Opaque Mask Computation, Sigma Threshold Rendering, Sigma Threshold Rendering Kernel, volume_render_sigma_thresh [S2, unofficial]

## Overview
Sigma-Threshold Depth Rendering computes a binary mask indicating the sample index where cumulative weight accumulation exceeds a specified density threshold, effectively identifying a 'surface' location along the ray [S1, unofficial]. It serves as a differentiable depth estimation method that renders a binary or thresholded output based on whether volume density exceeds a given value, referencing the approach used in Dex-NeRF [S3, unofficial]. Unlike Expected Term Rendering which computes the mean distance, or Median Depth Rendering which finds the median, this method identifies the depth at which the accumulated opacity crosses a hard boundary [S1, S3, unofficial]. It builds on [Depth from Ray Distance](5665-depth-from-ray-distance.md) by introducing a termination condition based on accumulated sigma rather than fixed sample counts or probabilistic expectations [G].

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   `rays`: Ray origins and directions (tensor of shape `[Q, 3]`, where `Q` is the number of rays) [S2, S3, unofficial].
    *   `weights`: Array of density weights from the NeRF model for each sample along each ray [S1, unofficial].
    *   `sigma_thresh`: The density threshold value used for comparison [S2, S3, unofficial].
    *   `depth_threshold`: Float accumulation threshold for depth termination (default 0.5) [S1, unofficial].
*   **Outputs:**
    *   `results`: A result tensor of size `Q` (one value per ray), with dtype and device matching `rays.origins`, `requires_grad=False` [S2, S3, unofficial]. The value indicates the depth or sample index where the threshold was crossed [G].

**Data Structures:**
*   `SingleRaySpec`: A structure holding ray specification details (origin, direction, bounds) for a single ray [S3, unofficial].
*   `cum`: Cumulative sum of weights [S1, unofficial].
*   `op`: Boolean mask where `cum >= depth_threshold` [S1, unofficial].
*   `op_shifted`: `op` shifted right by one position, padded with zeros at the beginning [S1, unofficial].
*   `mask`: XOR of `op` and `op_shifted`, cast to weights dtype [S1, unofficial].

**Steps:**
1.  **Initialize Ray Specification:** For each ray, create a `SingleRaySpec` and find the intersection bounds with the volume grid [S3, unofficial].
2.  **Compute Cumulative Weights:** Calculate the cumulative sum of the per-sample weights along the ray:
    $$ cum = \text{cumsum}(weights) $$
    [S1, unofficial]
3.  **Create Threshold Mask:** Generate a boolean mask indicating where the cumulative weight exceeds the threshold:
    $$ op = cum \ge depth\_threshold $$
    [S1, unofficial]
4.  **Shift Mask:** Shift the boolean mask `op` to the right by one position and pad with a zero at the start to identify the *first* crossing:
    $$ op_{shifted} = [0, op[:-1]] $$
    [S1, unofficial]
5.  **Compute Crossing Mask:** Compute the XOR of the original and shifted masks to find the exact sample index where the threshold was crossed:
    $$ mask = op \oplus op_{shifted} $$
    Cast `mask` to the weights' data type [S1, unofficial].
6.  **Trace Ray (CUDA Implementation):**
    *   Launch the CUDA kernel `device::render_ray_sigma_thresh_kernel` [S3, unofficial].
    *   Calculate number of blocks: `blocks = CUDA_N_BLOCKS_NEEDED(Q, TRACE_RAY_CUDA_THREADS)` [S2, S3, unofficial].
    *   Pass `grid`, `rays`, `opt`, `sigma_thresh`, and the output tensor pointer to the kernel [S2, S3, unofficial].
    *   Inside the kernel, for each ray, march along the ray until the accumulated density exceeds `sigma_thresh` [S2, S3, unofficial].
7.  **Finalize Output:** Return the `results` tensor containing the depth or index for each ray [S2, S3, unofficial].

**Pseudocode:**
```python
def cumsum(arr, axis=1):
    """Standard cumulative sum along an axis."""
    result = []
    for i in range(len(arr)):
        row = []
        acc = 0.0
        for val in arr[i]:
            acc += val
            row.append(acc)
        result.append(row)
    return result

def sigma_threshold_depth_rendering(rays_origins, rays_directions, weights, sigma_thresh, depth_threshold=0.5, sample_distances=None):
    """
    Compute depth using sigma thresholding.
    
    Args:
        rays_origins: Tensor of ray origins [Q, 3].
        rays_directions: Tensor of ray directions [Q, 3].
        weights: Tensor of per-sample weights [Q, N].
        sigma_thresh: Density threshold for early termination.
        depth_threshold: Accumulation threshold for mask computation (default 0.5).
        sample_distances: Tensor of sample distances along each ray [Q, N].
        
    Returns:
        results: Tensor of depth values for each ray [Q].
    """
    Q = len(rays_origins)
    N = len(weights[0])
    results = [0.0] * Q
    
    # Step 1: Compute cumulative sum of weights
    cum = cumsum(weights, axis=1)
    
    # Step 2: Create boolean mask where cumulative weight exceeds threshold
    op = [[1 if c >= depth_threshold else 0 for c in row] for row in cum]
    
    # Step 3: Shift op right by one and pad with zeros
    op_shifted = [[0] + row[:-1] for row in op]
    
    # Step 4: Compute XOR mask to find the first crossing
    mask = [[op[i][j] ^ op_shifted[i][j] for j in range(N)] for i in range(Q)]
    
    # Step 5: Compute depth based on the mask
    for i in range(Q):
        depth = 0.0
        crossed = False
        for j in range(N):
            if mask[i][j] == 1:
                depth = sample_distances[i][j]
                crossed = True
                break
        results[i] = depth if crossed else 0.0 # Default to 0.0 if not crossed [G]
        
    # Step 6: CUDA kernel launch (implementation detail)
    # blocks = (Q + TRACE_RAY_CUDA_THREADS - 1) // TRACE_RAY_CUDA_THREADS
    # render_ray_sigma_thresh_kernel<<<blocks, TRACE_RAY_CUDA_THREADS>>>(grid, rays, opt, sigma_thresh, results_ptr)
    # The kernel performs the ray marching and threshold check directly on the density grid [S2, S3, unofficial].
    
    return results
```

**Parameters:**
*   `sigma_thresh`: Density threshold value for early ray termination during volume rendering [S2, S3, unofficial].
*   `depth_threshold`: Accumulation threshold for depth termination (default 0.5) [S1, unofficial].
*   `max_depth`: 10 (specific to ScanNet dataset) [S5].
*   `min_depth`: 0.001 (specific to ScanNet dataset) [S5].
*   `threshold_multiplier`: 0.0001 (applied to the depth range) [S5].

**Edge Cases and Pitfalls:**
*   **Threshold Not Reached:** If the cumulative weight never exceeds `depth_threshold`, the mask will be all zeros and the depth remains at its default initialization [G].
*   **Precision:** Floating-point precision in cumulative sum can affect the exact crossing point [S1, unofficial].
*   **Boundaries:** Ray bounds must be correctly computed to avoid sampling outside the volume [S2, S3, unofficial].

## Subtopics

### Depth Uncertainty Thresholding
A variant that uses a small threshold $\tau$ to evaluate the uncertainty of a depth map [S5]. The threshold is calculated as $\tau = (max\_depth - min\_depth) \cdot 0.0001$, where $max\_depth = 10$ and $min\_depth = 0.001$ for the ScanNet dataset [S5]. This method is used to assess depth reliability rather than just computing a single depth value [S5].

## Operating characteristics
*   **Time Complexity:** Not given in the sources [G].
*   **Memory Complexity:** Not given in the sources [G].
*   **Performance:** The CUDA implementation is optimized for GPU execution [S2, S3, unofficial]. The CUDA kernel allows for parallel processing of rays [S2, S3, unofficial].
*   **Strengths:** Provides a clear, binary surface indication, which can be useful for tasks requiring explicit depth boundaries [S1, unofficial]. It is differentiable, allowing for gradient-based optimization [S3, unofficial].
*   **Limitations:** Sensitive to the choice of threshold. If the threshold is too high or too low, it may fail to detect surfaces or detect noise [S1, S3, unofficial].
*   **When to Use:** When a binary surface mask is needed, or when the scene has clear density boundaries [S1, S3, unofficial].
*   **When Not to Use:** Not given in the sources [G].

## Background
Sigma-Threshold Depth Rendering was introduced in the context of Dex-NeRF, a method for neural radiance fields in robotic manipulation scenarios [S3, unofficial]. It is also referred to as "Opaque Mask Computation" in some implementations [S2, unofficial]. The method is used to compute depth based on a sigma threshold, referencing the approach used in Dex-NeRF [S3, unofficial].
