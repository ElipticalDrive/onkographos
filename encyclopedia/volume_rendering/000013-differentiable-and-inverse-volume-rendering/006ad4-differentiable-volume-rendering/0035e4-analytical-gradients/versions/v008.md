# Analytical Gradients
Also called: Explicit Gradients, Closed-form Gradients, Analytic Inversion

## Overview
Analytical gradients compute the derivatives of the rendering equation with respect to input parameters (such as density, geometry, or camera pose) by explicitly expanding the chain rule, rather than relying on automatic differentiation or finite differences [G]. This approach solves the problem of high memory consumption and computational overhead associated with reverse-mode AD, which requires storing $O(kn)$ intermediate states for $n$ pixels and $k$ samples . By deriving closed-form expressions for the gradients, this family reduces memory usage to $O(n)$ and enables efficient optimization of dynamic volumetric densities and geometric parameters [G]. It sets itself apart from [Automatic Differentiation (Reverse/Adjoint Mode)](7151-automatic-differentiation-reverse-adjoint-mode.md) by avoiding computational graph storage, and from [Differentiable Volume Rendering via Box Splines](2449-differentiable-volume-rendering-via-box-splines.md) and [Analytical Derivative of Rendering (Mesh)](6761-analytical-derivative-of-rendering-mesh.md) by providing the explicit mathematical formulation for the gradient computation itself [G].

## Shared principles
Analytical gradients compute derivatives by explicitly expanding the chain rule across the continuous stages of the rendering pipeline (projection, integration, or shading), bypassing the computational graph storage required by reverse-mode AD [G]. For volumetric methods, the rendering integral is differentiated term-by-term . The gradient with respect to a specific density $\sigma_k$ involves two components: the direct effect on the emitted radiance at step $k$, and the indirect effect on the transmittance $T_j$ for all subsequent steps $j > k$ . For mesh-based methods, gradients flow through differentiable projection matrices, barycentric interpolation, and shading models, while discrete visibility selection remains non-differentiable [G]. All implementations maintain $O(n)$ memory complexity relative to the output size, enabling single-pass or tightly coupled backward passes .

The standard emission-absorption model computes color $\hat{C}(\mathbf{r})$ for a ray $\mathbf{r}$ as:
$$
\hat{C}(\mathbf{r}) = \sum_{i=1}^N T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i
$$
where $\sigma_i$ is density, $\delta_i$ is step size, $\mathbf{c}_i$ is color, and $T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)$ is transmittance [G].

The analytical gradient with respect to density $\sigma_k$ is derived by differentiating the sum term-by-term :
$$
\frac{\partial \hat{C}}{\partial \sigma_k} = \underbrace{T_k (1 - \exp(-\sigma_k \delta_k))' \mathbf{c}_k}_{\text{Direct}} + \sum_{j=k+1}^N \frac{\partial T_j}{\partial \sigma_k} (1 - \exp(-\sigma_j \delta_j)) \mathbf{c}_j
$$
where $\frac{\partial T_j}{\partial \sigma_k} = -T_j \delta_k$ for $j > k$ .

The following pseudocode computes the forward radiance and the analytical gradient in a single pass by maintaining a transmittance sensitivity accumulator [G]:
```python
def analytical_gradient_rendering(ray_origin, ray_dir, density_field, step_size):
    x_u = ray_origin
    T = 1.0
    L = 0.0
    grad_sigma = 0.0
    grad_T = 0.0
    num_steps = 100
    for i in range(num_steps):
        sigma_i = density_field.sample(x_u)
        alpha_i = 1.0 - exp(-sigma_i * step_size)
        color_i = density_field.color(x_u)
        contribution = T * alpha_i * color_i
        L += contribution
        grad_sigma += grad_T * (-step_size * T * exp(-sigma_i * step_size)) + T * step_size * exp(-sigma_i * step_size) * color_i
        grad_T = grad_T * (1.0 - alpha_i) + T * alpha_i * color_i
        T *= (1.0 - alpha_i)
        x_u = x_u + ray_dir * step_size
    return L, grad_sigma
```

## Subtopics

### [Differentiable Volume Rendering via Box Splines](2449-differentiable-volume-rendering-via-box-splines.md)
Computes analytical gradients for ray-traced projections of volumes defined by box splines [G]. It sets itself apart by explicitly calculating geometry gradients for ray anchors and directions using specific adjoint functions, while using the standard adjoint transform for volume coefficients [G]. Choose it for geometry calibration in tomography where interpolation orders 0, 1, and 2 are required [G].

### [Differentiable Volume Rendering with Analytical Gradients](5983-differentiable-volume-rendering-with-analytical-gradients.md)
Provides closed-form gradients for the discrete emission-absorption model with respect to volume density [G]. It sets itself apart by relying on explicit chain-rule expansion of the DVR integral rather than basis function properties, making it suitable for dynamic fluid reconstruction [G].

### [Analytical Derivative of Rendering (Mesh)](6761-analytical-derivative-of-rendering-mesh.md)
Computes exact gradients for mesh-based rendering by differentiating continuous projection and shading stages [G]. It sets itself apart from volumetric methods by operating on explicit triangle meshes and excludes the non-differentiable discrete triangle selection step [G]. Choose it for geometry and material optimization where visibility is fixed [G].

## Background
The concept of analytical gradients in rendering originated from the need to optimize parameters in computer graphics without the prohibitive memory costs of reverse-mode automatic differentiation [G]. Early work in differentiable rendering focused on surface-based primitives, where analytical derivatives of the rasterization and shading pipelines were derived [G]. In volume rendering, the application of analytical gradients was developed to handle the high-dimensional parameter spaces of volumetric data, such as density fields in fluid simulation or neural radiance fields [G]. The method is primarily used in inverse rendering tasks, including tomography reconstruction, material optimization, and differentiable physics simulation [G].
