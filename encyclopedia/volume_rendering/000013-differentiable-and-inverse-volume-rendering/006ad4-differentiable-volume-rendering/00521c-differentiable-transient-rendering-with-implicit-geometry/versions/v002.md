# Differentiable Transient Rendering with Implicit Geometry

Also called: Differentiable Transient Rendering, Path-space differentiable transient rendering

## Overview
This method computes time-resolved illumination at sensor points by simulating third-bounce light transport between a laser source and a non-line-of-sight (NLOS) sensor using implicit surface geometry [S1]. It differs from standard differentiable volume rendering by operating in path space for transient measurements, discretizing continuous time-of-flight into bins via Gaussian smoothing, and bypassing explicit binary visibility checks by relying on volumetric intensities as a visibility estimator [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Implicit geometry representation $G$ with parameters $\Theta_G$, laser parameters $\Theta_{ls}$, sensor parameters, laser position $x_l$, sensor position $x_s$, and transient bin index $\tau$ [S1].
*   **Outputs:** Sensed transient data matrix $H_R(x_l, x_s, \tau)$ representing time-resolved illumination at the sensor [S1].

**Data Structures:**
*   **Implicit Surface:** Defined by parameters $\Theta_G$ [S1]. Points $x_g$ and normals $n_g$ are estimated from volumetric intensities [S1].
*   **Transient Bins:** Discrete time indices $\tau$ [S1]. Continuous time $t$ is mapped to $\tau$ via Gaussian weighting [S1].

**Steps:**

1.  **Ray Sampling:** Sample rays originating from the sensor points $x_s$ [S1].
2.  **Implicit Surface Estimation:** Estimate implicit surface points $x_g$ and normals $n_g$ along the sampled rays [S1]. The geometry is derived from volumetric intensities, which depend on illumination reaching the surface without occluders [S1].
3.  **Radiometric Contribution Calculation:** Compute the radiometric contribution $K(\bar{x}, t)$ for a path $\bar{x} \equiv x_l \to x_g \to x_s$ [S1]. This represents time-resolved transport in path space [S1]. The method avoids computing the binary visibility term $V$ (typically required for path throughput $\mathbb{T}$) because the implicit surface estimation relies on volumetric intensities that inherently reflect unoccluded illumination [S1].
4.  **Time Discretization:** Discretize the continuous time $t$ of the path contribution $K(\bar{x}, t)$ into transient bins $\tau$ using a differentiable Gaussian distribution [S1]:
    $$
    \hat{K}(\bar{x}, \tau) = |K(\bar{x}, t)| \exp \left( - \frac{(\tau - t)^2}{2\sigma_t^2} \right)
    $$
    where $\tau$ is the transient bin index, $t$ is the continuous time, and $\sigma_t$ is the standard deviation for time bin discretization [S1].
5.  **Path Summation:** Approximate the time-resolved measurement $H_r(x_l, x_s, \tau)$ by summing the discrete path contributions $\hat{K}(\bar{x}, \tau)$ for all paths $\bar{x}$ starting at $x_l$ and ending at $x_s$, sampled via concentric disk mapping [S1]:
    $$
    H_r(x_l, x_s, \tau) \approx \sum_{\bar{x} \in X} \hat{K}(\bar{x}, \tau)
    $$
    where $X$ is the set of such paths [S1].
6.  **Laser-Sensor Model Application:** Apply the joint laser-sensor model to obtain the final sensed transient data $H_R$ by convolving with the system response $\Psi(\tau)$ and adding an intensity offset $\eta_s$ [S1]:
    $$
    H_R(x_l, x_s, \tau) = \Psi(\tau) * H_r(x_l, x_s, \tau) + \eta_s
    $$
    where $\eta_s$ accounts for ambient light and sensor dark count rate [S1].

**Parameters:**
*   $\sigma_t$: Standard deviation for Gaussian discretization. Set to 0.62 to ensure the Full Width at Half Maximum (FWHM) covers a unit time bin [S1].
*   $\eta_s$: Intensity offset parameter for ambient light and dark count rate [S1].

**Pitfalls:**
*   Differentiating the binary visibility function $V$ is challenging [S1]. The method mitigates this by assuming volumetric intensities are a good estimator of geometry visible from both laser and sensor positions, thus avoiding explicit visibility computation [S1].

**Pseudocode:**

```python
import math

def differentiable_transient_rendering(implicit_geometry, laser_pos, sensor_pos, 
                                     sigma_t=0.62, eta_s=0.0, system_response=None,
                                     num_bins=100, c=1.0):
    """
    Computes time-resolved illumination H_R using implicit geometry.
    
    Args:
        implicit_geometry: Object providing ray sampling, surface estimation, 
                           and radiometric contribution calculation.
        laser_pos: 3D vector, position of the laser source x_l.
        sensor_pos: 3D vector, position of the sensor x_s.
        sigma_t: Float, standard deviation for time bin discretization (default 0.62).
        eta_s: Float, intensity offset for ambient light/dark count (default 0.0).
        system_response: List or array, Psi(tau) convolution kernel.
        num_bins: Integer, number of transient bins.
        c: Float, speed of light constant (default 1.0 for normalized units).
        
    Returns:
        H_R: List of sensed transient data indexed by tau.
    """
    # 1. Sample rays from sensor positions (standard ray generation)
    rays = implicit_geometry.sample_rays_from_sensor(sensor_pos)
    
    # 2. Estimate implicit surface points and normals
    surface_points = []
    surface_normals = []
    for ray in rays:
        x_g, n_g = implicit_geometry.estimate_surface_and_normal(ray)
        surface_points.append(x_g)
        surface_normals.append(n_g)
        
    # 3. Compute radiometric contribution K(x_bar, t) for each path
    path_contributions = []
    path_times = []
    
    for x_g, n_g in zip(surface_points, surface_normals):
        # Path x_bar = x_l -> x_g -> x_s
        dist_laser_to_surf = math.sqrt(sum((a - b) ** 2 for a, b in zip(laser_pos, x_g)))
        dist_surf_to_sensor = math.sqrt(sum((a - b) ** 2 for a, b in zip(x_g, sensor_pos)))
        total_dist = dist_laser_to_surf + dist_surf_to_sensor
        
        # Continuous time t
        t = total_dist / c
        
        # Radiometric contribution K (Equations 5-9 in source) [S1]
        # Binary visibility V is avoided; volumetric intensity acts as visibility estimator [S1]
        k_val = implicit_geometry.compute_radiometric_contribution(laser_pos, x_g, sensor_pos, n_g)
        path_contributions.append(k_val)
        path_times.append(t)
        
    # 4. Discretize into transient bins using Gaussian distribution
    H_r = [0.0] * num_bins
    
    for k_val, t in zip(path_contributions, path_times):
        for tau in range(num_bins):
            # Gaussian weighting: exp(-(tau - t)^2 / (2 * sigma_t^2))
            weight = math.exp(-((tau - t) ** 2) / (2 * sigma_t ** 2))
            H_r[tau] += abs(k_val) * weight
            
    # 5. Apply laser-sensor model
    # H_R = Psi * H_r + eta_s
    if system_response is not None:
        H_R = discrete_convolution(H_r, system_response)
        for i in range(len(H_R)):
            H_R[i] += eta_s
    else:
        H_R = list(H_r)
        
    return H_R

def discrete_convolution(signal, kernel):
    """Standard 1D discrete convolution."""
    out_len = len(signal) + len(kernel) - 1
    out = [0.0] * out_len
    for i, s in enumerate(signal):
        for j, k in enumerate(kernel):
            out[i + j] += s * k
    return out
```

## Operating characteristics
*   **Time Complexity:** Linear in the number of sampled paths and transient bins [G].
*   **Memory Complexity:** Requires storing intermediate path contributions and transient bins [G].
*   **Strengths:** Enables gradient-based optimization of NLOS scene parameters (geometry, albedo, system parameters) by providing differentiable transient measurements [G].
*   **Limitations:** Relies on the assumption that volumetric intensities approximate visibility, which may fail in highly occluded scenes [S1]. Discretization error depends on $\sigma_t$ [S1].
*   **When to use:** For inverse rendering problems involving NLOS transient measurements where implicit geometry representation is preferred or necessary [G].

## Background
Originated in the context of Non-Line-of-Sight (NLOS) inverse rendering, specifically for self-calibrating and fully differentiable NLOS reconstruction [S1]. The method addresses the challenge of differentiating through transient rendering pipelines by using implicit surfaces and Gaussian time discretization [S1].
