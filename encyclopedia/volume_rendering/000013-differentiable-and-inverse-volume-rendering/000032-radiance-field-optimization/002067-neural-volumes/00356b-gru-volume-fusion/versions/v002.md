# GRU Volume Fusion

Also called: Fusing Volumes for Global Reconstruction, Recurrent Fusion Module, Recurrent Neural Fusion

## Overview
GRU Volume Fusion incrementally fuses per-frame local radiance fields into a global sparse radiance field using a recurrent neural module [S1]. It distinguishes itself from static volume decoders by adaptively updating only voxels covered by incoming local reconstructions, enabling real-time incremental scene reconstruction [S1].

## How it works
**Inputs and Outputs:** The method takes the local sparse feature volume from frame $t$, denoted $\mathcal{V}_t$, and the global feature volume from frame $t-1$, denoted $\mathcal{V}_{t-1}^g$, as inputs [S1]. It outputs the updated global feature volume $\mathcal{V}_t^g$ [S1].

**Data Structures:** $\mathcal{V}_t$ and $\mathcal{V}_{t-1}^g$ are sparse 3D voxel grids [S1]. The exact sparse storage format is not specified, but operations are defined element-wise on voxel coordinates covered by $\mathcal{V}_t$ [S1]. The fusion networks $M_z$, $M_r$, and $M_t$ are deep neural networks composed of sparse 3D convolution layers [S1].

**Parameters:** The networks $M_z$ and $M_r$ use sigmoid activation functions, while $M_t$ uses a tanh activation function [S1]. Typical network depth or kernel sizes are not given in the sources.

**Formulas:**
$$z_t = M_z([\mathcal{V}_{t-1}^g, \mathcal{V}_t])$$
$$r_t = M_r([\mathcal{V}_{t-1}^g, \mathcal{V}_t])$$
$$\tilde{\mathcal{V}}_t^g = M_t([r_t * \mathcal{V}_{t-1}^g, \mathcal{V}_t])$$
$$\mathcal{V}_t^g = (1 - z_t) * \mathcal{V}_{t-1}^g + z_t * \tilde{\mathcal{V}}_t^g$$
where $*$ denotes element-wise multiplication, $[\cdot, \cdot]$ denotes concatenation, $z_t$ is the update gate, $r_t$ is the reset gate, and $\tilde{\mathcal{V}}_t^g$ is the candidate global volume [S1].

**Step-by-Step Method:**
1. For every voxel coordinate present in $\mathcal{V}_t$, concatenate the feature vector from $\mathcal{V}_{t-1}^g$ and $\mathcal{V}_t$ [S1].
2. Apply $M_z$ to the concatenated features to compute the update gate $z_t$ with sigmoid activation [S1].
3. Apply $M_r$ to the concatenated features to compute the reset gate $r_t$ with sigmoid activation [S1].
4. Element-wise multiply $\mathcal{V}_{t-1}^g$ by $r_t$, concatenate the result with $\mathcal{V}_t$, and apply $M_t$ to compute the candidate volume $\tilde{\mathcal{V}}_t^g$ with tanh activation [S1].
5. Compute the new global volume $\mathcal{V}_t^g$ by blending $\mathcal{V}_{t-1}^g$ and $\tilde{\mathcal{V}}_t^g$ using $z_t$ [S1].
6. Apply steps 1–5 only to voxels covered by $\mathcal{V}_t$; all other voxels in $\mathcal{V}_{t-1}^g$ remain unchanged [S1].

**Pseudocode:**
```python
def gru_volume_fusion(V_prev_global, V_local, M_z, M_r, M_t):
    """
    Incrementally fuses local feature volume into global volume using GRU.
    
    Args:
        V_prev_global: Sparse 3D volume (dict or sparse tensor) representing V_{t-1}^g.
        V_local: Sparse 3D volume (dict or sparse tensor) representing V_t.
        M_z: Sparse 3D CNN network for update gate.
        M_r: Sparse 3D CNN network for reset gate.
        M_t: Sparse 3D CNN network for candidate volume.
        
    Returns:
        V_curr_global: Updated sparse 3D volume V_t^g.
    """
    # Initialize current global volume as a copy of previous to preserve unchanged voxels
    V_curr_global = V_prev_global.copy()
    
    # Identify voxel coordinates covered by the local volume
    covered_coords = V_local.keys()
    
    for coord in covered_coords:
        # Get feature vectors; treat missing coordinates as zero vectors [G]
        v_prev = V_prev_global.get(coord, default=zero_vector)
        v_local = V_local.get(coord, default=zero_vector)
        
        # Step 1: Concatenate features along the channel dimension
        concat_input = np.concatenate([v_prev, v_local], axis=-1)
        
        # Step 2: Compute Update Gate z_t (M_z applies sigmoid internally)
        z_t = M_z(concat_input)
        
        # Step 3: Compute Reset Gate r_t (M_r applies sigmoid internally)
        r_t = M_r(concat_input)
        
        # Step 4: Compute Candidate Volume
        # Element-wise multiply reset gate and previous global feature
        reset_prev = r_t * v_prev
        # Concatenate with local feature
        candidate_input = np.concatenate([reset_prev, v_local], axis=-1)
        # M_t applies tanh internally
        v_candidate = M_t(candidate_input)
        
        # Step 5: Update Global Volume
        # Blend previous and candidate using update gate
        v_new = (1 - z_t) * v_prev + z_t * v_candidate
        
        # Step 6: Write back to global volume
        V_curr_global[coord] = v_new
        
    return V_curr_global
```

**Edge Cases and Pitfalls:**
*   **Uncovered Voxels:** Voxels not covered by $\mathcal{V}_t$ are kept unchanged, requiring the sparse data structure to preserve inactive voxels without zeroing or deletion [S1].
*   **Coordinate Alignment:** $\mathcal{V}_t$ and $\mathcal{V}_{t-1}^g$ must share the same coordinate system and voxel resolution for element-wise operations to be valid [G].

## Subtopics

### Voxel Grid Decoders
Decodes the global feature volume into RGB and alpha values for rendering. It sets itself apart by focusing on the final decoding stage rather than feature fusion, and should be chosen when the global features are already available and only view synthesis is required. ### RenderNet Architecture
Defines the specific neural network architecture used for the sparse 3D convolutions ($M_z, M_r, M_t$) and final decoding. It sets itself apart by providing the backbone for feature extraction in the fusion module, and should be chosen when implementing the sparse convolutional networks required for GRU Volume Fusion. ## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of active voxels in $\mathcal{V}_t$, as networks are applied only to covered voxels [S1].
*   **Memory Complexity:** Proportional to the size of the global volume $\mathcal{V}^g$, which grows as new areas are scanned but remains sparse [S1].
*   **Measured Performance:** Runs in real-time at 22 fps [S1]. Hardware specifications, resolution, and scene details are not given in the sources.
*   **Strengths:** Adaptively improves global reconstruction by filling holes and refining features while maintaining consistency; efficient due to sparse application [S1].
*   **Limitations:** Requires sequential frame processing; performance depends on the accuracy of the local volume reconstruction $\mathcal{V}_t$ [S1].
*   **When to use:** Large-scale scene reconstruction where incremental updates are needed and global consistency is critical [S1].

## Background
GRU Volume Fusion was introduced in "NeRFusion: Fusing Radiance Fields for Large-Scale Scene Reconstruction" [S1]. It builds on the Neural Volumes framework, which optimizes a deep 3D convolutional network to predict a discretized RGB$\alpha$ voxel grid and a 3D warp grid [Parent]. The method leverages Gated Recurrent Units (GRUs) to handle the temporal aspect of multi-view reconstruction, allowing the network to learn to recurrently fuse per-frame local reconstructions into a high-quality global radiance field [S1]. It is trained end-to-end with rendering losses on datasets like ScanNet, DTU, and Google Scanned Object, and can be further fine-tuned per scene to boost rendering quality [S1]. It is used for large-scale indoor and small-scale object scene reconstruction [S1].
