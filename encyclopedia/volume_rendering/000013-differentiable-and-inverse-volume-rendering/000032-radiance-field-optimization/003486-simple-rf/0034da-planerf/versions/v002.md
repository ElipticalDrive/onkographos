# PlaNeRF

Also called: SVD Unsupervised 3D Plane Regularization for NeRF

## Overview
PlaNeRF is an unsupervised 3D plane regularization method for Neural Radiance Fields (NeRF) designed to improve large-scale urban scene reconstruction [S1]. It addresses geometric instability in low-texture, flat-surface environments by appending two regularization terms to the standard L2 photometric loss: a patch-based SSIM term for geometry initialization and an SVD-based plane regularization term for enforcing planar geometry [S1]. Unlike sibling methods such as [NeRF with Softplus Activation and Importance Sampling](3524-nerf-with-softplus-activation-and-importance-sampling.md) or [GeCoNeRF](8905-geconerf.md), PlaNeRF targets the least-squares plane approximation of a patch rather than a plane orthogonal to the center ray, allowing the surface normal to converge in an unsupervised manner [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** RGB images, camera poses (estimated via COLMAP), and semantic segmentation maps (pre-computed via SegFormer) identifying flat surfaces such as roads, traffic lanes, and sidewalks [S1].
*   **Outputs:** Optimized NeRF parameters $\theta$ defining the radiance field $f_\theta: \mathbb{R}^3 \times S^2 \rightarrow [0, 1]^3 \times \mathbb{R}^+$ [S1].

**Data Structures**
*   **Ray Patch $R$:** A set of rays sampled for a square image patch of size $S_{patch} \times S_{patch}$ [S1].
*   **Point Cloud $P$:** A set of 3D points $\{p_r\}$ derived from the NeRF's predicted depth $\hat{d}_\theta(r)$ and ray direction $u_r$ for each ray $r \in R$:
    $$ p_r = o + \hat{d}_\theta(r) u_r $$
    where $o$ is the camera center [S1].
*   **Difference Matrix $A$:** An $N \times 3$ matrix where each row is the difference between a point $p_r$ and the barycenter $\hat{p}_c$ of the point cloud:
    $$ A = \begin{bmatrix} p_0 - \hat{p}_c \\ p_1 - \hat{p}_c \\ \vdots \\ p_{N-1} - \hat{p}_c \end{bmatrix} $$
    where $\hat{p}_c = \frac{1}{N} \sum_{r \in R} p_r$ and $N = S_{patch}^2$ [S1].

**Algorithm Steps**
1.  **Ray Sampling:** For a given training iteration, sample a batch of $B$ ray patches $R$ [S1].
2.  **Depth and Color Rendering:** For each ray $r$ in the patch, render the predicted color $\hat{c}_\theta(r)$ and depth $\hat{d}_\theta(r)$ using volumetric rendering [S1].
3.  **Point Cloud Construction:** Construct the point cloud $P$ for the patch using the rendered depths and ray origins/directions [S1].
4.  **SVD Plane Regularization ($L_{SVD}$):**
    a. Compute the barycenter $\hat{p}_c$ of $P$ [S1].
    b. Construct the difference matrix $A$ [S1].
    c. Perform Singular Value Decomposition (SVD) on $A$:
       $$ A = U S V^T $$
       where $U$ and $V$ are orthogonal matrices, and $S$ is a diagonal matrix of singular values $\sigma_i$ in descending order ($\sigma_1 \ge \sigma_2 \ge \sigma_3$) [S1].
    d. The least-squares plane normal $n$ is the right singular vector $v_3$ corresponding to the smallest singular value $\sigma_3$ [S1].
    e. The regularization loss is the smallest singular value:
       $$ L_{SVD}(\theta, R) = \sigma_3(\theta, R) $$
       Minimizing $\sigma_3$ forces the points in the patch to lie on a plane [S1].
5.  **Semantic Masking:** Apply a semantic mask $M$ to $L_{SVD}$ [S1]. The loss is only computed for pixels belonging to classes assumed to be single 3D planes (e.g., road, sidewalk, traffic lanes) [S1]. Pixels in other classes (e.g., walls, buildings) are excluded because they may contain multiple planes [S1].
6.  **SSIM Initialization ($L_{dSSIM}$):**
    a. Extract the RGB color patch $\hat{X}$ from the rendered colors and the ground truth patch $Y$ from the input image [S1].
    b. Compute the SSIM metric between $\hat{X}$ and $Y$:
       $$ \text{SSIM}(x, y) = \frac{(2\mu_x \mu_y + c_1)(\sigma_{xy} + c_2)}{(\mu_x^2 + \mu_y^2 + c_1)(\sigma_x^2 + \sigma_y^2 + c_2)} $$
       where $\mu$ are means, $\sigma^2$ are variances, $\sigma_{xy}$ is covariance, and $c_1, c_2$ are small constants to stabilize division [S1].
    c. Compute the dSSIM loss:
       $$ L_{dSSIM}(\theta, R) = \frac{1 - \text{SSIM}(\hat{X}, Y)}{2} $$
       This term supervises the 2D local structure to aid geometry initialization, particularly for low-texture surfaces [S1].
7.  **Total Loss Computation:**
    $$ L(\theta, R) = L_{MSE}(\theta, R) + \lambda_0 L_{dSSIM}(\theta, R) + \lambda_1 L_{SVD}(\theta, R) $$
    where $L_{MSE}$ is the standard L2 photometric loss [S1].
8.  **Optimization:** Update $\theta$ using the Adam optimizer [S1].

**Pseudocode**

```python
import torch
import torch.nn.functional as F

def pla_nerf_step(render_func, image_patch, semantic_mask, origins, directions, params):
    """
    One training step for PlaNeRF.
    
    Args:
        render_func: Function that takes ray origins and directions, returns (color, depth).
                     Returns tensors of shape (Spatch, Spatch, 3) and (Spatch, Spatch).
        image_patch: Ground truth RGB image patch, shape (Spatch, Spatch, 3).
        semantic_mask: Semantic mask for the patch, shape (Spatch, Spatch).
        origins: Ray origins for the patch pixels, shape (Spatch, Spatch, 3).
        directions: Ray directions for the patch pixels, shape (Spatch, Spatch, 3).
        params: Dictionary containing Spatch, lambda0, lambda1, and semantic_classes.
    
    Returns:
        total_loss: Scalar tensor.
    """
    # 1. Render color and depth for the patch
    pred_color, pred_depth = render_func(origins, directions)
    
    # 2. L2 Photometric Loss
    l_mse = F.mse_loss(pred_color, image_patch)
    
    # 3. dSSIM Loss for initialization
    c1 = 0.01 ** 2
    c2 = 0.03 ** 2
    
    # Compute local means and variances using 3x3 pooling
    mu_x = F.avg_pool2d(pred_color.permute(2, 0, 1).unsqueeze(0), kernel_size=3, stride=1, padding=1).squeeze(0).permute(1, 2, 0)
    mu_y = F.avg_pool2d(image_patch.permute(2, 0, 1).unsqueeze(0), kernel_size=3, stride=1, padding=1).squeeze(0).permute(1, 2, 0)
    
    sigma_x_sq = F.avg_pool2d((pred_color - mu_x)**2, kernel_size=3, stride=1, padding=1)
    sigma_y_sq = F.avg_pool2d((image_patch - mu_y)**2, kernel_size=3, stride=1, padding=1)
    sigma_xy = F.avg_pool2d((pred_color - mu_x) * (image_patch - mu_y), kernel_size=3, stride=1, padding=1)
    
    ssim_map = ((2 * mu_x * mu_y + c1) * (sigma_xy + c2)) / ((mu_x**2 + mu_y**2 + c1) * (sigma_x_sq + sigma_y_sq + c2))
    l_dssim = torch.mean((1 - ssim_map) / 2)
    
    # 4. SVD Plane Regularization Loss
    # Reshape to (N, 3) where N = Spatch * Spatch
    N = params['Spatch'] ** 2
    points = origins.view(-1, 3) + pred_depth.view(-1, 1) * directions.view(-1, 3)
    
    # Compute barycenter and difference matrix A
    barycenter = torch.mean(points, dim=0)
    A = points - barycenter
    
    # SVD: A = U S V^T. S is in descending order.
    U, S, Vh = torch.linalg.svd(A, full_matrices=False)
    sigma_3 = S[-1]
    l_svd = sigma_3
    
    # 5. Semantic Masking for SVD Loss
    # Filter points to only include valid semantic classes
    valid_mask = torch.zeros(N, dtype=torch.bool, device=points.device)
    for cls in params['semantic_classes']:
        valid_mask = valid_mask | (semantic_mask.view(-1) == cls)
    
    if valid_mask.sum() > 0:
        points_valid = points[valid_mask]
        if points_valid.shape[0] >= 3:
            barycenter_valid = torch.mean(points_valid, dim=0)
            A_valid = points_valid - barycenter_valid
            _, S_valid, _ = torch.linalg.svd(A_valid, full_matrices=False)
            l_svd = S_valid[-1]
        else:
            l_svd = torch.tensor(0.0, device=points.device)
    else:
        l_svd = torch.tensor(0.0, device=points.device)
    
    # 6. Loss Scheduling
    # lambda1 = 0 during the first epoch (handled in training loop)
    
    # 7. Total Loss
    total_loss = l_mse + params['lambda0'] * l_dssim + params['lambda1'] * l_svd
    
    return total_loss
```

**Parameters**
*   $\lambda_0$: Weight for dSSIM loss. Typical value: 0.1 [S1].
*   $\lambda_1$: Weight for SVD loss. Typical value: 0.01 [S1].
*   $S_{patch}$: Size of the rendered patch. Typical value: 20 [S1].
*   Optimizer: Adam [S1].
*   Learning Rate: Cosine decay from $10^{-2}$ to $10^{-4}$ [S1].
*   Batch Size: 128 patches [S1].
*   Training Duration: 100 epochs with early stopping [S1].
*   Semantic Classes: Road, traffic lanes, sidewalk [S1].

**Edge Cases and Pitfalls**
*   **Uninitialized Geometry:** Applying $L_{SVD}$ too early leads to inaccurate plane estimation [S1]. The loss scheduling sets $\lambda_1 = 0$ during the first epoch to mitigate this [S1].
*   **Semantic Ambiguity:** Classes like "wall" or "building" may contain multiple planes [S1]. Applying the single-plane assumption to these classes degrades performance [S1]. Semantic masking is required to exclude them [S1].
*   **Low Texture:** Without $L_{dSSIM}$, geometry initialization on low-texture surfaces is poor [S1]. The dSSIM term is crucial for this phase [S1].

## Operating characteristics
*   **Time Complexity:** Training takes approximately 1 to 4 hours per scene on a single NVIDIA GeForce RTX 3090 GPU [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** On the KITTI-360 NVS benchmark, PlaNeRF achieves a PSNR of 22.90, SSIM of 0.857, and LPIPS of 0.205 [S1]. It outperforms baseline NeRF (PSNR 21.18) and other regularization methods like RegNeRF (PSNR 22.50) [S1].
*   **Strengths:** Effective for large-scale urban scenes with flat surfaces; unsupervised plane normal convergence; improves geometry on low-texture surfaces [S1].
*   **Limitations:** Requires semantic segmentation maps; assumes single-plane geometry for specific classes; not suitable for complex non-planar structures without masking [S1].
*   **When to use:** Large-scale urban reconstruction (e.g., driving scenarios) where flat surfaces like roads and sidewalks are dominant [S1].
*   **When not to use:** Scenes where semantic segmentation maps are unavailable or where the single-plane assumption for flat classes is invalid [S1].

## Background
PlaNeRF was introduced in 2024 by authors publishing in the IEEE International Conference on 3D Vision (3DV) [S1]. It builds on the piecewise planar assumption introduced in RegNeRF [S1]. While RegNeRF regularizes patches towards a plane orthogonal to the center ray, PlaNeRF uses SVD to find the least-squares plane approximation, allowing the normal to converge unsupervised [S1]. The method is part of the Simple-RF family, which uses regularized radiance field models to constrain the main model [Parent]. It is specifically designed for large-scale urban scene reconstruction, leveraging semantic segmentation to guide the regularization [S1].
