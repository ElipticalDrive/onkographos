# Edge Guided Loss
Also called: Edge-Guided Loss Mask, Edge-aware loss for pose alignment

## Overview
Edge Guided Loss is a regularization technique used during the joint optimization of camera poses and radiance fields to mitigate weak and noisy gradient signals. It improves robustness by selectively amplifying the learning signal on edge pixels, which are critical for pose alignment, thereby stabilizing the optimization process when using smoothed 2D supervision [S1][S2, unofficial]. It sets itself apart from uniform weighting by dynamically adjusting the loss contribution based on local image structure, specifically targeting the high-frequency information preserved by edge detection [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Filtered 2D supervision images (rendered or ground truth), current learning rate $\eta$, and a binary edge mask $M$.
*   **Output:** Modified gradient updates for the pose parameters and radiance field parameters.

**Data Structures:**
*   **Edge Mask ($M$):** A 2D binary array of the same dimensions as the supervision images. $M_{i,j} = 1$ if pixel $(i,j)$ is detected as an edge, otherwise $0$.
*   **Learning Rate ($\eta$):** The base learning rate for the optimizer.

**Steps:**
1.  **Edge Detection:** Compute the edge mask $M$ by applying a Sobel filter to the filtered 2D supervision images. The Sobel filter calculates the gradient magnitude in the horizontal and vertical directions [S2, unofficial].
    *   Let $I$ be the filtered 2D image.
    *   Compute horizontal gradient $G_x$ and vertical gradient $G_y$ using Sobel kernels.
    *   Compute gradient magnitude $G = \sqrt{G_x^2 + G_y^2}$.
    *   Threshold $G$ to produce binary mask $M$. Pixels with magnitude above a threshold are set to $1$, others to $0$.
2.  **Loss Calculation:** Compute the standard rendering loss $L$ (e.g., MSE) between the rendered image and the supervision image.
3.  **Edge-Guided Scaling:** Apply the edge-guided scale alternately on every other training iteration [S2, unofficial].
    *   If the current iteration $t$ is even: Use standard loss $L$.
    *   If the current iteration $t$ is odd: Compute the edge-guided loss $L_{edge}$.
        $$ L_{edge} = \sum_{i,j} \left( M_{i,j} \cdot 1.5 \cdot (I_{rendered, i,j} - I_{target, i,j})^2 + (1 - M_{i,j}) \cdot (I_{rendered, i,j} - I_{target, i,j})^2 \right) $$
        This effectively increases the learning rate by $1.5\times$ for pixels in the edge region ($M_{i,j}=1$) and keeps it at $1\times$ for non-edge pixels ($M_{i,j}=0$) [S2, unofficial].
4.  **Backpropagation:** Compute gradients with respect to the model parameters (poses and radiance field) using $L$ or $L_{edge}$ depending on the iteration parity.

**Parameters:**
*   **Edge Scale Factor:** $1.5$ [S2, unofficial].
*   **Alternation Frequency:** Every other iteration [S2, unofficial].
*   **Edge Detection Method:** Sobel filter [S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Noise Sensitivity:** The Sobel filter may detect high-frequency noise as edges if the input images are not sufficiently smoothed. The method relies on the preceding "Smoothed 2D Supervision" step to mitigate this [S2, unofficial].
*   **Degenerate Input:** If the image is uniform (no edges), the mask $M$ will be all zeros, and the edge-guided loss will behave identically to the standard loss.
*   **Precision:** Ensure the threshold for edge detection is chosen carefully to balance between capturing true structural edges and ignoring noise [S2, unofficial].

**Pseudocode:**
```python
def compute_edge_guided_loss(rendered_image, target_image, base_learning_rate, iteration):
    """
    Computes the edge-guided loss for joint optimization.
    
    Args:
        rendered_image: 2D array of rendered pixel values.
        target_image: 2D array of target pixel values.
        base_learning_rate: The base learning rate eta.
        iteration: Current training iteration number.
        
    Returns:
        loss: The computed loss value.
        gradients: Gradients for optimization.
    """
    # Step 1: Edge Detection using Sobel Filter
    # Compute gradients
    gx = sobel_filter_horizontal(rendered_image)
    gy = sobel_filter_vertical(rendered_image)
    
    # Compute magnitude
    magnitude = sqrt(gx**2 + gy**2)
    
    # Threshold to create binary mask M
    # Note: Threshold value is not explicitly given in sources [G]
    threshold = 0.1 * magnitude.max() 
    edge_mask = (magnitude > threshold).astype(float)
    
    # Step 2: Compute standard pixel-wise squared error
    pixel_error = (rendered_image - target_image)**2
    
    # Step 3: Apply edge-guided scaling alternately
    if iteration % 2 == 1:
        # Odd iteration: Apply edge-guided loss
        # Increase learning rate by 1.5x for edge pixels
        weighted_error = edge_mask * 1.5 * pixel_error + (1 - edge_mask) * pixel_error
        loss = weighted_error.sum()
    else:
        # Even iteration: Use standard loss
        loss = pixel_error.sum()
        
    # Step 4: Backpropagation would be handled by the autograd framework
    # Here we return the loss for logging or manual gradient computation
    return loss
```

## Operating characteristics
*   **Time Complexity:** Adds minimal overhead due to the Sobel filter and mask application, which are $O(N)$ operations where $N$ is the number of pixels [S1].
*   **Memory Complexity:** Requires storing the edge mask $M$, which is $O(N)$ bits [S2, unofficial].
*   **Performance:** Experimentally proven crucial for successful pose refinement in ablation studies [S1]. It allows the method to converge in 50k iterations compared to 200k for previous methods, reducing training time to 25% [S1].
*   **Strengths:** Mitigates weak and noisy gradient problems caused by aggressive filtering [S2, unofficial]. Focuses optimization on edge areas, leading to more robust pose optimization [S2, unofficial].
*   **Limitations:** Relies on the quality of the edge detection; poor edge detection can lead to suboptimal gradient signals [S2, unofficial].
*   **When to use:** When joint optimization of camera poses and radiance fields suffers from instability or slow convergence due to noisy gradients [S1].
*   **When not to use:** When computational resources are extremely limited and the overhead of edge detection is prohibitive, or when the input images lack distinct edges [S2, unofficial].

## Background
Edge Guided Loss was introduced in the context of improving the robustness of joint optimization for camera poses and decomposed low-rank tensorial radiance fields (TensoRF) [S1]. The technique was developed to address the weak and noisy gradient problem that arises when using smoothed 2D supervision for pose alignment [S2, unofficial]. It is part of a suite of techniques including smoothed 2D supervision and randomly scaled kernel parameters, designed to enable rapid convergence and superior performance in novel view synthesis [S1]. The method was empirically validated through ablation studies showing its necessity for successful pose refinement [S1].
