# WildGaussians

Also called: 3D Reconstruction In the Wild (method)

## Overview
WildGaussians is a 3D Gaussian Splatting method designed for "in-the-wild" settings characterized by unconstrained photo collections, occlusions, transient objects, and varying illumination [S1, unofficial]. It integrates robust DINO features and a lightweight appearance modeling module within the standard 3DGS framework to handle these environmental variations while maintaining real-time rendering speeds [S1, unofficial]. It distinguishes itself from sibling methods like GS-W, which uses adaptive sampling and 2D visibility maps, and Wild-GS, which aligns pixel appearance features from image triplanes, by relying on global DINO feature integration for robustness against transient effects [S1, unofficial].

## How it works
**Inputs:** Unconstrained image collections (photos with varying lighting, occlusions, and transients).
**Outputs:** A set of 3D Gaussians with attributes optimized for appearance and geometry, enabling real-time rendering.

**Data Structures:**
The method extends the standard 3D Gaussian representation. Each Gaussian $i$ retains standard attributes: position $\mathbf{p}_i$, covariance $\mathbf{\Sigma}_i$, opacity $\alpha_i$, and spherical harmonics coefficients for color $\mathbf{c}_i$. Additionally, it incorporates:
1.  **DINO Features:** Robust semantic features extracted from a pre-trained DINO model, associated with the Gaussians to provide semantic consistency and robustness to appearance changes [S1, unofficial].
2.  **Appearance Modeling Module:** A lightweight module that maps the DINO features and view direction to color adjustments, handling varying illumination [S1, unofficial].

**Steps:**
1.  **Initialization:** Initialize 3D Gaussians from the input image set, similar to standard 3DGS initialization (e.g., using SfM points) [S1, unofficial].
2.  **Feature Extraction:** Extract DINO features from the input images. These features are robust to lighting and texture variations [S1, unofficial].
3.  **Optimization:** Optimize the Gaussian parameters (position, covariance, opacity, color, and appearance module weights) by minimizing a loss function. The loss includes:
    *   **Photometric Loss:** Standard $L_1$ and D-SSIM losses between rendered and input images [S1, unofficial].
    *   **Feature Consistency Loss:** Encourages consistency of DINO features across views, helping to mitigate transient objects and occlusions [S1, unofficial].
    *   **Appearance Loss:** Ensures the lightweight appearance module correctly models illumination changes [S1, unofficial].
4.  **Rendering:** Render the scene using standard 3DGS rasterization, with the appearance module adjusting colors based on the DINO features and view direction [S1, unofficial].

**Parameters:**
*   DINO model: Not specified in sources [G].
*   Loss weights: Not specified in sources [G].

**Edge Cases:**
*   **Transient Objects:** The method handles transients by leveraging DINO feature consistency, which is less affected by transient occlusions than raw pixel colors [S1, unofficial].
*   **Varying Illumination:** The lightweight appearance modeling module addresses this by decoupling intrinsic appearance from lighting conditions [S1, unofficial].

## Subtopics
## Operating characteristics
*   **Time Complexity:** Real-time rendering speeds, similar to standard 3DGS [S1, unofficial].
*   **Memory Complexity:** Not specified in sources [G].
*   **Performance:** Outperforms the original NeRF baseline in "in-the-wild" settings [S1, unofficial].
*   **Strengths:** Handles unconstrained photo collections, occlusions, transients, and varying illumination [S1, unofficial].
*   **Limitations:** Relies on the quality of DINO features and the effectiveness of the lightweight appearance module [S1, unofficial].
*   **When to use:** When reconstructing scenes from unconstrained, in-the-wild photo collections with environmental variations [S1, unofficial].
*   **When not to use:** For controlled studio settings where standard 3DGS is sufficient and simpler [S1, unofficial].

## Background
WildGaussians was introduced as part of recent work extending 3D Gaussian Splatting to "in-the-wild" settings [S1, unofficial]. It addresses the limitations of standard 3DGS, which assumes consistent lighting and no transients, by integrating robust DINO features and a lightweight appearance modeling module [S1, unofficial]. It is compared with other in-the-wild methods like GS-W and Wild-GS [S1, unofficial].
