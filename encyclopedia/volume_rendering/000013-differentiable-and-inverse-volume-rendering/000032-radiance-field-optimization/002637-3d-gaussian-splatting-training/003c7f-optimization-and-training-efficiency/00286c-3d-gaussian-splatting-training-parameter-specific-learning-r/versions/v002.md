# 3D Gaussian Splatting Training > Parameter-Specific Learning Rates

Also called: Adam parameter learning rates, Gaussian Optimizer Configuration, Per-parameter group learning rates, Training Optimizer Setup, X-Gaussian Hyperparameters, X-Gaussian Implementation Details

## Overview
Configures the Adam optimizer with distinct learning rates for each Gaussian parameter group (means, opacities, scales, colors) to stabilize training and prevent rapid divergence [S2, unofficial]. It sets apart from standard single-learning-rate approaches by decoupling the update magnitudes for geometric, photometric, and visibility parameters [S2, unofficial].

## How it works
**Inputs:**
- A list of Gaussian parameters to optimize, typically including:
  - `means`: 3D position values (tensor of shape $[N, 3]$).
  - `pre_act_opacities`: Pre-activation opacity values (tensor of shape $[N]$).
  - `pre_act_scales`: Pre-activation scale values (tensor of shape $[N, 3]$ or $[N]$ depending on isotropy).
  - `colours`: RGB color values (tensor of shape $[N, C]$ where $C$ is the number of spherical harmonic coefficients or 3 for RGB).
  - `quaternions`: 3D rotation quaternions (tensor of shape $[N, 4]$), if not in isotropic mode.
- Optimizer hyperparameters: $\beta_1, \beta_2, \epsilon$.

**Outputs:**
- An initialized Adam optimizer object with parameter groups.

**Data Structures:**
- **Parameter Groups:** A list of dictionaries, each containing:
  - `params`: The tensor(s) to optimize.
  - `lr`: The specific learning rate for this group.

**Steps:**
1. **Verify Trainability:** Ensure all required parameters are marked as trainable. If `isotropic=True`, quaternions must be excluded; attempting to include them raises a `RuntimeError` [S2, unofficial].
2. **Define Parameter Groups:** Create groups with specific learning rates. Two distinct configurations are cited in the sources:
   - **Configuration A (Standard/Unofficial Implementation):**
     - `pre_act_opacities`: $0.05$ [S2, unofficial]
     - `pre_act_scales`: $0.05$ [S2, unofficial]
     - `colours`: $0.05$ [S2, unofficial]
     - `means`: $0.05$ [S2, unofficial]
     - *Note:* Source [S2, unofficial] also lists alternative values for these groups: opacities $0.00085$, scales $0.001$, colours $0.02$, means $0.00015$ [S2, unofficial]. The source does not clarify which is the default or if they are context-dependent.
   - **Configuration B (X-Gaussian / Radiative GS):**
     - Position (means): Initially $1.9 \times 10^{-4}$, exponentially decaying to $1.9 \times 10^{-6}$ [S1].
     - Point features (colours/SH): $2 \times 10^{-3}$ [S1].
     - Opacity: $8 \times 10^{-3}$ [S1].
     - Scaling: $5 \times 10^{-3}$ [S1].
     - Rotation: $1 \times 10^{-3}$ [S1].
3. **Initialize Optimizer:** Instantiate `torch.optim.Adam` with the parameter groups.
   - Base `lr` is set to $0.0$ because learning rates are handled per group [S2, unofficial].
   - `eps` is set to $1 \times 10^{-15}$ [S1][S2, unofficial].
   - $\beta_1 = 0.9$, $\beta_2 = 0.999$ [S1][S2, unofficial].

**Pseudocode:**
```python
import torch

def setup_optimizer(gaussians, config_type="standard"):
    """
    Configures Adam optimizer with parameter-specific learning rates.
    
    Args:
        gaussians: Object containing trainable parameters.
                   Must have attributes: means, pre_act_opacities, 
                   pre_act_scales, colours, quaternions (optional).
        config_type: "standard" for [S2, unofficial] values, "x_gaussian" for [S1] values.
        
    Returns:
        torch.optim.Adam optimizer instance.
    """
    # Verify trainability
    if not hasattr(gaussians, 'check_if_trainable'):
        # [G] Placeholder for framework-specific check
        pass
    else:
        gaussians.check_if_trainable()

    params = []

    if config_type == "standard":
        # Configuration A from [S2, unofficial]
        # Note: [S2, unofficial] provides two sets of LR values. Using the explicit 
        # "pre_act" naming convention values as they are more detailed.
        params.append({
            'params': gaussians.pre_act_opacities,
            'lr': 0.05
        })
        params.append({
            'params': gaussians.pre_act_scales,
            'lr': 0.05
        })
        params.append({
            'params': gaussians.colours,
            'lr': 0.05
        })
        params.append({
            'params': gaussians.means,
            'lr': 0.05
        })
        
        # Add quaternions if present and trainable
        if hasattr(gaussians, 'quaternions') and gaussians.is_trainable('quaternions'):
            params.append({
                'params': gaussians.quaternions,
                'lr': 0.05 # [G] Inferred from other params in [S2, unofficial] as not explicitly listed for quat
            })

    elif config_type == "x_gaussian":
        # Configuration B from [S1]
        # Position LR decays exponentially
        base_lr_pos = 1.9e-4
        min_lr_pos = 1.9e-6
        
        params.append({
            'params': gaussians.means,
            'lr': base_lr_pos,
            'decay_lr': True,
            'min_lr': min_lr_pos
        })
        params.append({
            'params': gaussians.colours, # Point features
            'lr': 2e-3
        })
        params.append({
            'params': gaussians.pre_act_opacities,
            'lr': 8e-3
        })
        params.append({
            'params': gaussians.pre_act_scales,
            'lr': 5e-3
        })
        if hasattr(gaussians, 'quaternions') and gaussians.is_trainable('quaternions'):
            params.append({
                'params': gaussians.quaternions,
                'lr': 1e-3
            })

    else:
        raise ValueError("Unknown config_type")

    # Initialize Adam with lr=0.0 as rates are per-group
    optimizer = torch.optim.Adam(params, lr=0.0, eps=1e-15, betas=(0.9, 0.999))
    
    return optimizer

def update_learning_rates(optimizer, iteration, total_iterations):
    """
    Updates learning rates for parameters that require decay (e.g., X-Gaussian).
    """
    for group in optimizer.param_groups:
        if group.get('decay_lr', False):
            # Exponential decay from base_lr to min_lr
            # [G] Standard exponential decay formula implementation
            progress = iteration / total_iterations
            current_lr = group['lr'] * (1 - progress) + group.get('min_lr', 0) * progress
            # Or strictly exponential: current_lr = min_lr * (base_lr/min_lr)**(1-progress)
            # Source [S1] says "exponentially decays", but does not specify the exact function.
            # Linear interpolation is a common approximation if not specified.
            # However, "exponentially" usually implies: lr = min * (base/min)^(t/T)
            base = group['lr']
            min_l = group.get('min_lr', 0)
            if min_l > 0:
                current_lr = min_l * (base / min_l) ** (1 - progress)
            else:
                current_lr = base * (1 - progress)
            
            group['lr'] = current_lr
```

**Parameters:**
- $\beta_1 = 0.9$ [S1][S2, unofficial]
- $\beta_2 = 0.999$ [S1][S2, unofficial]
- $\epsilon = 1 \times 10^{-15}$ [S1][S2, unofficial]
- Training iterations: $2 \times 10^4$ [S1]

**Edge Cases and Pitfalls:**
- **Isotropic Mode:** Quaternions are excluded from optimization. If `isotropic=True` and quaternions are marked as trainable, `check_if_trainable` raises a `RuntimeError` [S2, unofficial].
- **Parameterization Differences:** Standard 3DGS uses logarithmic parameterization for scales ($\theta_\sigma = \log \sigma$) [S3]. BOGausS uses linear parameterization ($\theta_\sigma = \sigma$) to reduce sensitivity to strong updates [S3].

## Subtopics

### BOGausS Optimizer
A modified Stochastic Gradient Descent optimizer ensuring unbiased state estimation for sparsely-viewed and split Gaussians [S3]. It uses precision-aware updates for localization and size parameters [S3]. The instant $t$ in update equations is Gaussian-dependent, incremented only when a specific Gaussian is updated, referring to its lifespan [S3]. The update rules are:
$$
\begin{cases} 
\alpha_{s,t} &= \max(1/t, 1 - \beta_s^\star) \\ 
\widehat{g}_0 &= 0 \\ 
\widehat{g}_t &= \widehat{g}_{t-1} + \alpha_{1,t}(\nabla_\theta \mathcal{L}_t - \widehat{g}_{-1}) \\ 
\widehat{g}_t^2 &= \widehat{g}_{t-1}^2 + \alpha_{2,t}((\nabla_\theta \mathcal{L}_t)^2 - \widehat{g}_{-1}^2) \\ 
\theta_{t+1} &= \theta_t + \eta_\theta \Delta_\theta \frac{\widehat{g}_t}{\widehat{g}_t^2 + \epsilon} 
\end{cases}
$$
where $\eta_\theta$ is the learning rate, $\beta_s^\star$ are standard Adam parameters, and $\Delta_\theta$ is the scaling factor [S3]. For localization and sizes, $\Delta_\theta$ is the confidence interval $\Delta_i$; for other parameters, $\Delta_\theta = 1$ [S3]. Sizes parameters $\sigma_a$ are linearly parameterized ($\theta_\sigma = \sigma$), unlike the logarithmic parameterization in standard 3DGS [S3]. During splitting, gradient states are inherited: $t_{child} = \alpha_t \times t_{mother}$, $(g_{child})_t = \alpha_g \times (g_{mother})_t$, $(g_{child}^2)_t = (\alpha_g)^2 \times (g_{mother}^2)_t$ [S3].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Measured Performance:** Not given in the sources.
- **Strengths:** Stabilizes training by preventing rapid divergence through decoupled learning rates [S2, unofficial]. BOGausS variant ensures unbiased state estimation and adapts to scene content [S3].
- **Limitations:** Requires careful tuning of per-parameter rates. Logarithmic parameterization (standard) can be sensitive to strong updates, causing explosion or loss of Gaussians [S3].
- **When to use:** Standard 3DGS training [S2, unofficial]. X-ray novel view synthesis [S1]. Scenes with sparse views or requiring unbiased state estimation [S3].

## Background
Originated from the 3D Gaussian Splatting framework [S2, unofficial]. The parameter-specific configuration is a key implementation detail for stable optimization [S2, unofficial]. X-Gaussian adapted this for radiative Gaussian Splatting in X-ray novel view synthesis [S1]. BOGausS proposed a modified optimizer to address issues with standard Adam in the context of Gaussian splitting and sparse views [S3].
