# 3D Smoothing Filter

Also called: Maximal sampling rate filter, Mip-Splatting 3D filter

## Overview
The 3D smoothing filter prevents 3D Gaussian primitives from becoming smaller than the maximal sampling frequency induced by the training images, thereby mitigating aliasing artifacts when rendering at different sampling rates (e.g., varying focal length or camera distance) [S1, S2, unofficial]. It sets a lower bound on Gaussian scale based on the highest spatial frequency captured during training [S1, unofficial]. Unlike the 2D Mip filter which addresses projection aliasing, this filter operates in 3D space to constrain the intrinsic size of the Gaussians [S1, unofficial].

## How it works
**Inputs:**
- $\mathbf{s}_k$: Current scale vector of the $k$-th Gaussian.
- $\mu_k$: 3D center position of the $k$-th Gaussian.
- $o_k$: Current opacity of the $k$-th Gaussian.
- $\{\mathbf{K}_n\}_{n=1}^N$: Camera intrinsics for $N$ training views, specifically focal length $f_n$ (in pixels).
- $\{\mathbf{T}_n\}_{n=1}^N$: Camera extrinsics for $N$ training views.
- $\kappa_{3D}$: Hyperparameter controlling variance (default 0.2) [S1, unofficial].

**Outputs:**
- $\hat{\mathbf{s}}_k$: Filtered scale vector.
- $\hat{o}_k$: Filtered opacity (optional, see Simplified version).

**Data Structures:**
- The visibility indicator $\mathbb{1}_n(\mu_k)$ is a binary value (1 if visible, 0 if not) for each Gaussian $k$ in each view $n$.

**Steps:**

1. **Compute Maximal Sampling Rate ($\hat{\nu}_k$):**
   For each Gaussian $k$, calculate the maximal sampling rate across all $N$ training images:
   $$
   \hat{\nu}_k = \max \left( \left\{ \mathbb{1}_n(\mu_k) \cdot \frac{f_n}{d_n} \right\}_{n=1}^N \right)
   $$
   Where:
   - $\mathbb{1}_n(\mu_k)$ is 1 if $\mu_k$ is visible in view $n$, 0 otherwise [S1, unofficial].
   - $f_n$ is the focal length of view $n$ in pixels [S1, unofficial].
   - $d_n$ is the z-depth of $\mu_k$ in view $n$ (distance along the camera's optical axis) [S1, unofficial].
   - If $\hat{\nu}_k = 0$ (Gaussian not visible in any training image), the filter is inactive for that Gaussian [G].

2. **Apply Filter (Standard Version):**
   Compute the filtered scale and opacity:
   $$
   \hat{\mathbf{s}}_k = \sqrt{\mathbf{s}_k^2 + \frac{\kappa_{3D}}{\hat{\nu}_k^2}}
   $$
   $$
   \hat{o}_k = \sqrt{\frac{|\text{diag}(\mathbf{s}_k^2)|}{|\text{diag}(\mathbf{s}_k^2 + \frac{\kappa_{3D}}{\hat{\nu}_k})|}} o_k
   $$
   Note: The opacity adjustment is often omitted in practice [S1, unofficial].

3. **Apply Filter (Simplified/In-place Version):**
   Instead of modifying opacity and computing square roots, clip the scales from below after each optimizer step:
   $$
   \mathbf{s}_k = \max(\mathbf{s}_k, \frac{\sqrt{\kappa_{3D}}}{\hat{\nu}_k})
   $$
   This approach is significantly cheaper and retains the advantages of the filter [S1, unofficial].

4. **Update Frequency:**
   Recompute $\hat{\nu}_k$ for all Gaussians every 100 training iterations, as $\mu_k$ changes during optimization [S1, unofficial].

**Pseudocode:**
```python
def compute_max_sampling_rate(mu_k, camera_intrinsics, camera_extrinsics, visibility_cache):
    """
    Computes the maximal sampling rate for a Gaussian.
    mu_k: (3,) array, Gaussian center.
    camera_intrinsics: List of N arrays, each with 'f' (focal length in pixels).
    camera_extrinsics: List of N arrays, each with 'R' (3x3 rotation) and 'T' (3x1 translation).
    visibility_cache: Dict mapping (k, n) to boolean visibility.
    """
    max_nu = 0.0
    N = len(camera_intrinsics)
    for n in range(N):
        # Check visibility
        if not visibility_cache.get((mu_k, n), False):
            continue
        
        # Compute depth d_n
        # Transform Gaussian center to camera space
        R_n = camera_extrinsics[n]['R']
        T_n = camera_extrinsics[n]['T']
        mu_cam = R_n @ mu_k + T_n
        d_n = mu_cam[2] # Z-depth in camera coordinates
        
        if d_n <= 0:
            continue
            
        f_n = camera_intrinsics[n]['f']
        nu = f_n / d_n
        if nu > max_nu:
            max_nu = nu
            
    return max_nu

def apply_3d_smoothing_filter(s_k, nu_k, kappa_3d=0.2, use_simplified=True):
    """
    Applies the 3D smoothing filter to a Gaussian's scale.
    s_k: (3,) array, current scale.
    nu_k: float, maximal sampling rate.
    kappa_3d: float, variance hyperparameter.
    use_simplified: bool, if True, use in-place clipping.
    """
    if nu_k == 0:
        return s_k, None # No filter applied if not visible
        
    min_scale = sqrt(kappa_3d) / nu_k
    
    if use_simplified:
        # In-place clip scales from below
        s_filtered = max(s_k, min_scale)
        return s_filtered, None
    else:
        # Standard version with opacity adjustment
        s_filtered = sqrt(s_k**2 + kappa_3d / nu_k**2)
        
        # Opacity adjustment
        # Note: diag(s^2) is element-wise square
        s_sq = s_k**2
        s_filtered_sq = s_filtered**2
        opacity_factor = sqrt(sum(s_sq) / sum(s_filtered_sq)) # Simplified determinant ratio for diagonal matrix
        o_filtered = opacity_factor * o_k # o_k is input opacity
        return s_filtered, o_filtered
```

**Edge Cases and Pitfalls:**
- If a Gaussian is not visible in any training image ($\hat{\nu}_k = 0$), the filter cannot be applied. The implementation should guard against division by zero [G].
- Precision issues may arise if $d_n$ is very small or very large. Ensure $d_n$ is computed correctly in camera space [S1, unofficial].
- The simplified version does not adjust opacity, which is acceptable in practice [S1, unofficial].

## Subtopics

### Max Sampling for 4D Gaussian
A variant for 4D Gaussians (3D space + time) that computes the maximum sampling frequency $\hat{\nu}_k$ to constrain the frequency of the 4D Gaussian primitive [S2, unofficial]. It minimizes the ratio $f/d$ over $N$ cameras and $T$ time steps: $\hat{\nu}_k = \min_{n,t} \left( \mathbb{1}_n(p_k(t)) \cdot \frac{f_n(t)}{d_n(t)} \right)$ [S2, unofficial]. Here, $f_n(t)$ is the focal length at time $t$, and $d_n(t)$ is the depth of the primitive center $p_k(t)$ [S2, unofficial]. This is computationally expensive for large $T$, so approximations are often used [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Recomputing $\hat{\nu}_k$ for all Gaussians every 100 iterations is $O(N \cdot K)$, where $N$ is the number of training views and $K$ is the number of Gaussians [S1, unofficial]. A fused CUDA implementation can accelerate this [S1, unofficial].
- **Memory Complexity:** Requires storing visibility indicators for each Gaussian-view pair, or recomputing visibility on the fly [G].
- **Performance:** The simplified in-place clipping is significantly cheaper than the standard version and avoids gradient computation overhead [S1, unofficial].
- **Strengths:** Effectively prevents aliasing artifacts when rendering at different sampling rates [S1, unofficial].
- **Limitations:** Does not address 2D projection aliasing (requires the 2D Mip filter) [S1, unofficial].

## Background
The 3D smoothing filter was proposed by Yu et al. in Mip-Splatting [S1, unofficial]. It is an extension to the original 3D Gaussian Splatting method to handle anti-aliasing during optimization [S1, unofficial]. It is used in Faster-GS and other optimized 3DGS implementations [S1, unofficial].
