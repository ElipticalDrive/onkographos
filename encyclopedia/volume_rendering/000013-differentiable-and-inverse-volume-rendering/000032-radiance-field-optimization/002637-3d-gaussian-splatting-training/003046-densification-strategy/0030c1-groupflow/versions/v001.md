# GroupFlow

Also called: Groupwise SE(3) Motion Distillation

## Overview
GroupFlow is a motion compression technique for dynamic 3D Gaussian Splatting that replaces per-Gaussian neural deformation fields with shared SE(3) transformations for groups of Gaussians [S1, unofficial]. It solves the computational bottleneck of evaluating individual deformation networks for every primitive at every timestep, reducing the number of transformations from $N$ (per Gaussian) to $J$ (per group) [S1, unofficial]. Unlike sibling methods that may use global rigid transforms or dense neural fields, GroupFlow captures locally coherent motion by clustering Gaussians based on trajectory similarity and fitting a distinct SE(3) trajectory to each cluster [S1, unofficial].

## How it works
GroupFlow distills a dense, per-Gaussian neural motion field into a sparse set of groupwise SE(3) motions [S1, unofficial]. It operates on a dynamic scene represented by a set of 3D Gaussians $\mathcal{G}$, where each Gaussian $\mathcal{G}_i$ has a mean position $\mu_i$ that varies over time [S1, unofficial].

### Inputs and Outputs
*   **Inputs**:
    *   A set of $N$ Gaussians $\mathcal{G} = \{\mathcal{G}_i\}_{i=1}^N$.
    *   For each Gaussian $i$, a sequence of mean positions $\mathcal{M}_i = \{\mu_i^t\}_{t=0}^{F-1}$ across $F$ timesteps, obtained from the underlying deformation network or optimization [S1, unofficial].
    *   The number of groups $J$ (typically $J \ll N$) [S1, unofficial].
    *   A weighting factor $\lambda_r$ for the similarity score [S1, unofficial].
*   **Outputs**:
    *   $J$ control trajectories, defined by initial positions $h_j^0$ and time-varying SE(3) parameters $\{R_j^t, T_j^t\}_{t=0}^{F-1}$ for each group $j \in \{1, \dots, J\}$ [S1, unofficial].
    *   An assignment of each Gaussian $i$ to a group $j$ [S1, unofficial].

### Data Structures
*   **Gaussian Trajectories**: Each Gaussian $i$ is stored as a list of $F$ 3D vectors $\mu_i^t \in \mathbb{R}^3$.
*   **Control Trajectories**: Each group $j$ is defined by:
    *   $h_j^0 \in \mathbb{R}^3$: The initial position of the control point.
    *   $R_j^t \in \mathbb{R}^{3 \times 3}$: The rotation matrix at timestep $t$.
    *   $T_j^t \in \mathbb{R}^3$: The translation vector at timestep $t$.
*   **Group Assignment**: An array `group_id` of size $N$, where `group_id[i]` stores the index $j$ of the group to which Gaussian $i$ belongs.

### Steps
1.  **Initialize Control Points**: Select $J$ initial control points $\{h_j^0\}_{j=1}^J$ from the set of initial Gaussian means $\{\mu_i^0\}_{i=1}^N$ using farthest point sampling [S1, unofficial].
2.  **Compute Similarity Scores**: For each Gaussian $i$ and each control trajectory $j$, compute the trajectory similarity score $S_{i,j}$ using the formula below [S1, unofficial].
3.  **Assign Gaussians to Groups**: Assign each Gaussian $i$ to the group $j$ that minimizes the similarity score $S_{i,j}$ [S1, unofficial]. Let $\mathcal{M}^j$ be the set of means $\{\mu_i\}$ assigned to group $j$.
4.  **Fit Group-wise SE(3) Trajectories**: For each group $j$, optimize the parameters $\{h_j^0, R_j^t, T_j^t\}_{t=0}^{F-1}$ to fit the assigned means $\mathcal{M}^j$ over time [S1, unofficial]. This is done by minimizing the reconstruction error of the predicted means against the actual sampled means [S1, unofficial].
5.  **Predict Deformation**: At runtime, for any Gaussian $i$ assigned to group $j$, predict its mean position $\mu_i^t$ at timestep $t$ using the learned SE(3) transformation [S1, unofficial].

### Formulas
The trajectory similarity score $S_{i,j}$ between Gaussian $i$ and control trajectory $j$ is defined as [S1, unofficial]:

$$
S_{i,j} = \lambda_r \, \mathrm{std}_t(\| \mu_i^t - h_j^t \|) + (1-\lambda_r) \, \mathrm{mean}_t(\| \mu_i^t - h_j^t \|)
$$

Where:
*   $\mu_i^t$ is the mean position of Gaussian $i$ at time $t$.
*   $h_j^t$ is the position of control trajectory $j$ at time $t$. The predicted mean position $\mu_i^t$ for a Gaussian $i$ assigned to group $j$ at timestep $t$ is given by [S1, unofficial]:

$$
\mu_i^t = R_j^t (\mu_i^0 - h_j^0) + h_j^0 + T_j^t
$$

Where:
*   $\mu_i^0$ is the initial mean position of Gaussian $i$.
*   $h_j^0$ is the initial position of the control trajectory $j$.
*   $R_j^t$ is the rotation matrix for group $j$ at time $t$.
*   $T_j^t$ is the translation vector for group $j$ at time $t$.

### Pseudocode

```python
import numpy as np

def groupflow(gaussians_means_sequences, num_groups, lambda_r, num_timesteps):
    """
    Performs GroupFlow motion distillation.
    
    Args:
        gaussians_means_sequences: List of N arrays, each of shape (F, 3), 
                                   containing mu_i^t for t in 0..F-1.
        num_groups: J, the number of groups.
        lambda_r: Weighting factor for std vs mean in similarity score.
        num_timesteps: F, the number of timesteps.
        
    Returns:
        control_points: List of J control trajectories. Each is a dict with 
                        'h0' (3,), 'R' (F, 3, 3), 'T' (F, 3).
        group_assignments: Array of size N, containing group index for each Gaussian.
    """
    N = len(gaussians_means_sequences)
    
    # Step 1: Initialize Control Points via Farthest Point Sampling at t=0
    # Initialize J control points h_j^0 from the initial means mu_i^0
    initial_means = np.array([g[0] for g in gaussians_means_sequences]) # Shape (N, 3)
    control_h0 = farthest_point_sampling(initial_means, num_groups) # Shape (J, 3)
    
    # Initialize control trajectories R and T to identity/zero for simplicity, 
    # or use a simple linear interpolation if needed. 
    # The source says "fit a group-wise SE(3) trajectory", implying optimization.
    # We will initialize R to identity and T to zero.
    control_R = np.eye(3).reshape(1, 3, 3).repeat(num_timesteps, axis=0) # Shape (F, 3, 3)
    control_T = np.zeros((num_timesteps, 3)) # Shape (F, 3)
    
    # We need to optimize the control trajectories. 
    # The source says "shared flow parameters ... are optimized jointly with the scene".
    # For the purpose of this method description, we assume an optimization step.
    # Here, we will perform a simplified optimization loop.
    
    # Initialize group assignments
    group_assignments = np.zeros(N, dtype=int)
    
    # Optimization Loop (Simplified)
    # In practice, this would be part of the larger optimization loop.
    for iteration in range(10): # Arbitrary number of iterations for demonstration
        # Step 2 & 3: Compute Similarity and Assign
        # We need to estimate h_j^t for the similarity score.
        # Since we are optimizing, we can use the current control trajectory parameters.
        # However, the similarity score formula uses h_j^t.
        # Let's compute the current position of each control trajectory at each timestep.
        # h_j^t = R_j^t (h_j^0 - h_j^0) + h_j^0 + T_j^t = h_j^0 + T_j^t
        # This assumes the control point itself moves with the SE(3) transform relative to its initial position.
        # But the formula for mu_i^t is mu_i^t = R_j^t (mu_i^0 - h_j^0) + h_j^0 + T_j^t.
        # This implies the control trajectory's position at time t is h_j^t = h_j^0 + T_j^t?
        # No, the formula for mu_i^t is relative to h_j^0.
        # Let's re-read the formula: mu_i^t = R_j^t (mu_i^0 - h_j^0) + h_j^0 + T_j^t.
        # If mu_i^0 = h_j^0, then mu_i^t = h_j^0 + T_j^t.
        # So the position of the control trajectory at time t is h_j^t = h_j^0 + T_j^t.
        # This is a simplification. The source says "fit a group-wise SE(3) trajectory".
        # It might be that the control trajectory is defined by h_j^0, R_j^t, T_j^t.
        # And its position at time t is h_j^t = R_j^t (h_j^0 - h_j^0) + h_j^0 + T_j^t = h_j^0 + T_j^t.
        # So h_j^t is simply h_j^0 + T_j^t.
        
        control_positions = control_h0.reshape(1, 1, 3) + control_T.reshape(1, -1, 3) # Shape (J, F, 3)
        
        # Compute similarity scores S_{i,j}
        # S_{i,j} = lambda_r * std_t(||mu_i^t - h_j^t||) + (1-lambda_r) * mean_t(||mu_i^t - h_j^t||)
        # We need to compute this for all i, j.
        # gaussians_means_sequences: (N, F, 3)
        # control_positions: (J, F, 3)
        # Expand dimensions for broadcasting
        mu = np.array(gaussians_means_sequences) # (N, F, 3)
        h = control_positions # (J, F, 3)
        
        # Compute distances ||mu_i^t - h_j^t|| for all i, j, t
        # diff: (N, J, F, 3)
        diff = mu[:, np.newaxis, :, :] - h[np.newaxis, :, :, :]
        dist = np.linalg.norm(diff, axis=3) # (N, J, F)
        
        # Compute std and mean over t (axis=2)
        std_dist = np.std(dist, axis=2) # (N, J)
        mean_dist = np.mean(dist, axis=2) # (N, J)
        
        S = lambda_r * std_dist + (1 - lambda_r) * mean_dist # (N, J)
        
        # Assign each Gaussian to the group with the minimum score
        group_assignments = np.argmin(S, axis=1)
        
        # Step 4: Fit Group-wise SE(3) Trajectories
        # For each group j, optimize h_j^0, R_j^t, T_j^t to fit the assigned means.
        # This is a non-linear optimization problem. 
        # We will use a simplified approach: for each group, compute the mean of assigned means at each timestep,
        # and then fit an SE(3) transform to map the initial mean to the mean at each timestep.
        # This is a simplification. The source says "aligning sampled means over time".
        
        for j in range(num_groups):
            # Get indices of Gaussians in group j
            indices = np.where(group_assignments == j)[0]
            if len(indices) == 0:
                continue
            
            # Get the means of these Gaussians
            group_means = mu[indices] # (K, F, 3)
            
            # Compute the mean position of the group at each timestep
            group_mean_positions = np.mean(group_means, axis=0) # (F, 3)
            
            # The initial position of the control trajectory is h_j^0.
            # We can update h_j^0 to be the mean of the initial positions of the assigned Gaussians.
            control_h0[j] = np.mean(group_means[:, 0, :], axis=0)
            
            # Now, we need to fit R_j^t and T_j^t.
            # The formula is mu_i^t = R_j^t (mu_i^0 - h_j^0) + h_j^0 + T_j^t.
            # We want to minimize the error between the predicted mu_i^t and the actual mu_i^t.
            # This is a Procrustes problem for each timestep t.
            # For each t, we have a set of points {mu_i^0 - h_j^0} and {mu_i^t - h_j^0 - T_j^t}.
            # We can solve for R_j^t and T_j^t.
            # Let X_t = mu_i^0 - h_j^0 for all i in group j.
            # Let Y_t = mu_i^t - h_j^0 for all i in group j.
            # We want to find R_j^t and T_j^t such that Y_t approx R_j^t X_t + T_j^t.
            # This is a standard rigid body transformation estimation.
            
            for t in range(num_timesteps):
                # X_t: (K, 3)
                X_t = group_means[:, 0, :] - control_h0[j]
                # Y_t: (K, 3)
                Y_t = group_means[:, t, :] - control_h0[j]
                
                # Compute centroids
                centroid_X = np.mean(X_t, axis=0)
                centroid_Y = np.mean(Y_t, axis=0)
                
                # Center the points
                X_centered = X_t - centroid_X
                Y_centered = Y_t - centroid_Y
                
                # Compute covariance matrix
                H = X_centered.T @ Y_centered # (3, 3)
                
                # SVD
                U, S_vals, Vt = np.linalg.svd(H)
                
                # Rotation matrix
                R = Vt.T @ U.T
                if np.linalg.det(R) < 0:
                    Vt[-1, :] *= -1
                    R = Vt.T @ U.T
                
                control_R[t] = R
                
                # Translation vector
                # Y_t = R X_t + T_j^t
                # T_j^t = centroid_Y - R centroid_X
                control_T[t] = centroid_Y - R @ centroid_X
                
    return control_h0, control_R, control_T, group_assignments

def farthest_point_sampling(points, num_centers):
    """
    Simple farthest point sampling.
    """
    N = points.shape[0]
    centers = np.zeros((num_centers, 3), dtype=points.dtype)
    distances = np.full(N, np.inf)
    center_idx = 0
    
    for i in range(num_centers):
        centers[i] = points[center_idx]
        dist = np.linalg.norm(points - centers[i], axis=1)
        distances = np.minimum(distances, dist)
        center_idx = np.argmax(distances)
        
    return centers
```

### Parameters
*   $\lambda_r$: Weighting factor for the trajectory similarity score. Typical value not given in the sources. [S1, unofficial]
*   $J$: Number of groups. Typical value not given in the sources, but $J \ll N$. [S1, unofficial]
*   $F$: Number of timesteps. [S1, unofficial]

### Edge Cases and Pitfalls
*   **Empty Groups**: If a group $j$ has no assigned Gaussians, its parameters should not be updated. [S1, unofficial]
*   **Precision**: The optimization of SE(3) parameters can be sensitive to initialization. [S1, unofficial]
*   **Degenerate Input**: If all Gaussians in a group have the same initial position, the rotation estimation may be ill-posed. [G]

## Operating characteristics
*   **Time Complexity**: The assignment step is $O(N \cdot J \cdot F)$. The fitting step is $O(J \cdot F \cdot K)$, where $K$ is the average group size. The rendering step is $O(N)$ for splatting, but the deformation calculation is $O(1)$ per Gaussian instead of $O(D)$ for a neural network, where $D$ is the network depth. [S1, unofficial]
*   **Memory Complexity**: $O(N \cdot F)$ for storing the Gaussian trajectories, and $O(J \cdot F)$ for storing the control trajectories. [S1, unofficial]
*   **Measured Performance**: On the MonoDyGauBench, integrating GroupFlow into DeformableGS accelerates rendering by 13.71× and reduces training time by 2.53× compared to baselines. [S1, unofficial]
*   **Strengths**: Reduces computational cost, regularizes the motion field, improves temporal coherence. [S1, unofficial]
*   **Limitations**: Assumes locally coherent motion. May not capture complex, non-rigid deformations well if groups are too small or motion is too diverse. [S1, unofficial]
*   **When to use**: When rendering speed is critical and the scene exhibits locally coherent motion. [S1, unofficial]
*   **When not to use**: When the scene has highly complex, non-rigid deformations that cannot be approximated by SE(3) transforms. [S1, unofficial]

## Background
GroupFlow was introduced in the paper "SpeeDe3DGS: Speedy Deformable 3D Gaussian Splatting with Temporal Pruning and Motion Grouping" by the authors of the SpeeDe3DGS project. It is part of a suite of techniques including Temporal Sensitivity Pruning (TSP) and Temporal Sensitivity Sampling (TSS) to accelerate dynamic 3D Gaussian Splatting. [S1, unofficial]
