# Projected Color-Guided Dynamic NeRF

Also called: OD-NeRF

## Overview
Projected Color-Guided Dynamic NeRF (OD-NeRF) is an on-the-fly training method for dynamic scenes that conditions the neural radiance field on multi-view projected colors rather than explicit time or deformation fields [S1]. It solves the problem of slow convergence and poor temporal extrapolation in existing dynamic NeRFs by leveraging the relative invariance of projected colors for corresponding 3D points across consecutive frames [S1]. Unlike [D-DeRF](8660-d-nerf.md) which uses explicit deformation fields, or [Neural Transient Field (NeTF)](4692-neural-transient-field-netf.md) which models transient effects, OD-NeRF implicitly tracks correspondence through color statistics, requiring the minimum number of optimization iterations per frame [S1].

## How it works
The method operates on a frame-by-frame basis, updating the radiance field for the current frame using the optimized field from the previous frame as initialization [S1]. The core innovation is replacing temporal inputs with projected color statistics to guide optimization [S1].

### Inputs and Outputs
*   **Inputs**: Multi-view images of the current frame; the optimized radiance field (voxel grid and MLP weights) from the previous frame; camera poses for the current frame.
*   **Outputs**: Updated radiance field parameters; rendered images for the current frame.

### Data Structures
The implementation relies on two primary data structures, depending on the dataset type:

1.  **Hash Voxel Grid**: Used in both synthetic and real-world implementations, replacing the multi-scale voxel grid of the base TiNeuVox model [S1]. Implemented using `tiny-cuda-nn` [S1].
    *   **Layout**: A hash table mapping spatial coordinates to feature vectors. The specific bit-packing or hash function details are not provided in the sources, but it serves as the spatial feature query mechanism [S1].
2.  **Occupancy Grid**: Used for efficient sampling [S1].
    *   **Layout**: A grid storing occupancy values $\sigma_{occ}(\mathbf{x})$ for spatial points $\mathbf{x}$ [S1].
3.  **NeRF MLP**: A Multi-Layer Perceptron that outputs volume density $\sigma$ and color $\mathbf{c}$ [S1].
    *   **Input Vector**: Concatenation of spatial features (from the voxel grid) and projected color statistics (mean and variance) [S1].

### Numbered Steps

1.  **Initialization**: For the first frame, initialize the hash voxel grid and MLP. Apply a warm-up duration of 2 seconds for synthetic datasets to compensate for the slower convergence of hashed voxels compared to multi-scale voxels [S1]. For real-world datasets, initialize using the NerfAcc implementation of InstantNGP [S1].
2.  **Ray Sampling with Occupancy Guidance**:
    *   Generate uniform samples along the ray.
    *   Apply rejection sampling based on the transited and updated occupancy grid from the previous frame [S1].
    *   A sample $\mathbf{x}_i$ at index $i$ is rejected if:
        $$ \sigma_{occ}(\mathbf{x}_i) < \sigma_{min} \quad \text{AND} \quad \neg(i \mod R \equiv R // 2) $$
        where $\sigma_{min}$ is a density threshold and $R$ is a fixed interval [S1].
    *   This filters out empty space while retaining a sparse set of samples for efficient processing [S1].
3.  **Projected Color Calculation**:
    *   For each sampled point $\mathbf{x}$, project it into the training views of the *previous* frame (or current frame views, depending on implementation detail, but the source implies using previous frame guidance for correspondence) [S1].
    *   Compute the mean $\mu_c$ and variance $\sigma_c^2$ of the projected colors from these views [S1].
    *   *Note*: The sources state "projected colors of the sampled point" without explicitly detailing the projection matrix or view selection, but imply multi-view consistency [S1].
4.  **Feature Concatenation**:
    *   Query spatial features $\mathbf{f}_{spatial}$ from the hash voxel grid at $\mathbf{x}$ [S1].
    *   Concatenate $\mathbf{f}_{spatial}$ with $\mu_c$ and $\sigma_c^2$ to form the input vector $\mathbf{v}_{input}$ for the NeRF MLP [S1]:
        $$ \mathbf{v}_{input} = [\mathbf{f}_{spatial}, \mu_c, \sigma_c^2] $$
5.  **NeRF Forward Pass**:
    *   Pass $\mathbf{v}_{input}$ through the NeRF MLP to predict volume density $\sigma$ and color $\mathbf{c}$ [S1].
6.  **Rendering**:
    *   Compute the rendered color $C(r)$ using the standard volume rendering equation [S1]:
        $$ C(r) = \sum_{i=0}^{N-1} T_i (1 - \exp(-\sigma_i \delta_i)) c_i $$
        where $T_i = \exp\left(-\sum_{j=0}^{i-1} \sigma_j \delta_j\right)$ [S1].
7.  **Loss Computation and Optimization**:
    *   Compute the photometric loss between rendered and ground truth images [S1].
    *   For real-world datasets, add a depth smoothness regularization loss $L_{depth}$ to handle planar backgrounds:
        $$ L_{depth} = \frac{\text{std}(d_{far} / d_{3\times3})}{\text{std}(c_{3\times3})} $$
        where $d_{far}$ is the depth of the farthest sample, $d_{3\times3}$ is the depth of a $3\times3$ patch of rays, and $c_{3\times3}$ is the color of the same patch [S1].
    *   Update the MLP and voxel grid weights using gradient descent [S1].
    *   Decay the learning rate from 1.0 (at frame 1) to 0.05 (at frame 10) for better convergence [S1].
8.  **Occupancy Grid Update**:
    *   Update the occupancy grid for the next frame using a transition and update algorithm based on the current frame's density estimates [S1].

### Pseudocode

```python
def train_od_nerf_frame(frame_idx, current_images, prev_field, camera_poses):
    """
    Trains the OD-NeRF model for a single frame.
    
    Args:
        frame_idx: Integer index of the current frame.
        current_images: List of images for the current frame.
        prev_field: Object containing the hash voxel grid and MLP weights from the previous frame.
        camera_poses: Camera poses for the current frame.
        
    Returns:
        Updated field object for the next frame.
    """
    # Initialize or load field
    if frame_idx == 0:
        field = initialize_field()
        # Warm-up for synthetic datasets
        if dataset_type == "synthetic":
            warm_up_duration = 2.0 # seconds
            field.warm_up(warm_up_duration)
    else:
        field = prev_field

    # Learning rate decay schedule
    lr = 1.0 * (0.05 / 1.0) ** (frame_idx / 10.0) if frame_idx > 0 else 1.0
    
    # Optimization loop for the current frame
    for step in range(num_optimization_steps):
        optimizer.zero_grad()
        
        # Sample rays
        rays = sample_rays(camera_poses, num_samples_per_ray)
        
        # Render colors
        rendered_colors = []
        for ray in rays:
            # 1. Sample points along ray
            uniform_samples = generate_uniform_samples(ray, N)
            
            # 2. Rejection sampling based on occupancy grid
            valid_samples = []
            for i, x_i in enumerate(uniform_samples):
                sigma_occ = field.occupancy_grid.query(x_i)
                # Reject if low occupancy and not on fixed interval
                if sigma_occ < sigma_min and not (i % R == R // 2):
                    continue
                valid_samples.append(x_i)
            
            # 3. Compute projected color statistics for valid samples
            # Project sample points to previous frame views to get invariant color stats
            # Note: Source implies using previous frame's color invariance
            projected_colors = []
            for x in valid_samples:
                # Project x to previous frame views
                colors = []
                for view_idx in range(num_views):
                    proj_color = project_and_sample_color(x, prev_field, camera_poses[view_idx])
                    colors.append(proj_color)
                mu_c = mean(colors)
                sigma_c = std(colors)
                projected_colors.append((mu_c, sigma_c))
            
            # 4. Query spatial features and concatenate
            features = []
            for i, x in enumerate(valid_samples):
                f_spatial = field.hash_voxel_grid.query(x)
                mu_c, sigma_c = projected_colors[i]
                # Concatenate spatial feature with projected color stats
                v_input = concatenate([f_spatial, mu_c, sigma_c])
                features.append(v_input)
            
            # 5. Forward pass through MLP
            # features is a batch of v_input vectors
            sigma_pred, color_pred = field.mlp(features)
            
            # 6. Volume rendering for this ray
            # Use the valid samples and their predicted sigma/color
            T = compute_transmittance(sigma_pred)
            ray_color = compute_volume_rendering(T, sigma_pred, color_pred)
            rendered_colors.append(ray_color)
        
        # 7. Compute Loss
        gt_colors = get_ground_truth_colors(rays, current_images)
        loss = mse_loss(rendered_colors, gt_colors)
        
        # Add depth smoothness regularization for real-world datasets
        if dataset_type == "real_world":
            # Compute depth and color stats for 3x3 patches
            # This requires grouping rays into patches
            depth_stats = compute_depth_stats(rays)
            color_stats = compute_color_stats(rendered_colors)
            l_depth = depth_stats.std_far / depth_stats.std_patch / (color_stats.std_patch + epsilon)
            loss += l_depth_weight * l_depth
            
        # 8. Backpropagate and update
        loss.backward()
        optimizer.step(lr)

    # Update occupancy grid for next frame
    field.update_occupancy_grid(rendered_densities)
    
    return field
```

### Parameters
*   **Warm-up duration**: 2 seconds for the first frame in synthetic datasets [S1].
*   **Learning rate decay**: From 1.0 at frame 1 to 0.05 at frame 10 [S1].
*   **Density threshold ($\sigma_{min}$)**: Not given in the sources.
*   **Fixed interval ($R$)**: Not given in the sources.
*   **Laplacian/Depth regularization weight**: Not given in the sources.

### Edge Cases and Pitfalls
*   **Specular Surfaces**: Specular highlights violate the relative invariance of projected color, leading to artifacts [S1].
*   **Occluded Points**: Occlusion causes projected color invariance to break, leading to artifacts [S1].
*   **Planar Backgrounds**: Real-world datasets with large planar backgrounds (e.g., walls, tables) may fail to converge even for the first static frame due to constant colors [S1]. This is mitigated by the depth smoothness regularization [S1].
*   **Convergence Speed**: Hashed voxels converge slower than multi-scale voxels, necessitating the warm-up period [S1].

## Operating characteristics
*   **Time Complexity**: The method achieves an interactive speed of 6 FPS for training and rendering on synthetic dynamic scenes on-the-fly [S1]. It requires the minimum number of optimization iterations for each new frame compared to models with temporal input dimensions or deformation fields [S1].
*   **Memory Complexity**: Uses a hash voxel grid (InstantNGP style) which is generally more memory-efficient than dense voxel grids for high-resolution scenes, but the exact memory footprint is not given in the sources.
*   **Strengths**: Excellent temporal extrapolation capability; fast on-the-fly training; no need for explicit deformation fields or temporal input dimensions [S1].
*   **Limitations**: Fails on specular surfaces and occluded points; requires careful handling of planar backgrounds in real-world data [S1].
*   **When to use**: When real-time or near-real-time on-the-fly training of dynamic scenes is required, and the scene does not contain significant specularities or complex occlusions [S1].
*   **When not to use**: For scenes with strong specular reflections or heavy occlusion where color invariance is violated [S1].

## Background
OD-NeRF was introduced in the paper "OD-NeRF: Efficient Training of On-the-Fly Dynamic Neural Radiance Fields" [S1]. It addresses the limitations of existing dynamic NeRFs that rely on temporal input dimensions or explicit deformation fields, which often extrapolate poorly to unseen times and require many optimization iterations per frame [S1]. The method builds on [TiNeuVox](link) for synthetic datasets and [InstantNGP](link) for real-world datasets, integrating the hash voxel grid and occupancy grid techniques [S1].
