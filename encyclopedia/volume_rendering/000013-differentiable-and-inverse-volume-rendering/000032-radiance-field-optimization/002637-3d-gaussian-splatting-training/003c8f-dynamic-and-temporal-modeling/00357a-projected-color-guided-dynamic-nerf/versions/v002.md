# Projected Color-Guided Dynamic NeRF

Also called: OD-NeRF

## Overview
Projected Color-Guided Dynamic NeRF (OD-NeRF) is an on-the-fly training method for dynamic scenes that replaces temporal deformation fields with a NeRF model conditioned on multi-view projected color statistics [S1]. Unlike sibling methods such as [D-NeRF](8660-d-nerf.md) which rely on explicit temporal inputs or deformation fields that extrapolate poorly to unseen times, OD-NeRF leverages the relative invariance of projected colors to implicitly track point correspondence between consecutive frames [S1]. This allows the model to utilize radiance fields from previous frames effectively, requiring the minimum number of optimization iterations for each new frame while maintaining interactive training and rendering speeds [S1].

## How it works
The method operates in an on-the-fly setting where the radiance field is trained and rendered frame-by-frame [S1]. It builds on the architecture of [TiNeuVox](7582-on-the-fly-dynamic-nerf-training.md) for synthetic data or [InstantNGP](7582-on-the-fly-dynamic-nerf-training.md) via NerfAcc for real-world data, modifying the input conditioning and sampling strategy [S1].

### Inputs and Outputs
*   **Inputs:** Multi-view images of the current frame $t$ and the previous frame $t-1$; the occupancy grid from frame $t-1$; camera poses and intrinsics for both frames.
*   **Outputs:** A trained radiance field representation for frame $t$; rendered images for novel views at frame $t$.

### Data Structures
The core data structure is the **Hash Voxel Grid** (from InstantNGP), implemented using `tiny-cuda-nn` [S1]. This replaces the multi-scale voxel grid used in the base TiNeuVox model [S1]. The grid stores spatial features for 3D points. Additionally, an **Occupancy Grid** is maintained and updated between frames to guide efficient sampling [S1].

### Numbered Steps

1.  **Projected Color Computation:** For a sampled 3D point $\mathbf{x}$ along a ray in the current frame, compute its projected color from the training views. Calculate the mean $\mu_c$ and variance $\sigma_c^2$ of these projected colors [S1].
2.  **Feature Query:** Query the spatial feature vector $\mathbf{f}_{spatial}$ for point $\mathbf{x}$ from the hash voxel grid [S1].
3.  **Input Concatenation:** Concatenate the projected color statistics with the spatial feature to form the input to the NeRF MLP:
    $$ \mathbf{f}_{input} = [\mathbf{f}_{spatial}, \mu_c, \sigma_c^2] $$
    *Note: For synthetic datasets, the temporal deformation model and temporal information enhancement from the base TiNeuVox are removed [S1]. For real-world datasets, this concatenation is performed before inputting into the NeRF MLP [S1].*
4.  **NeRF Prediction:** Pass $\mathbf{f}_{input}$ through the NeRF Multi-Layer Perceptron (MLP) to predict density $\sigma$ and color $\mathbf{c}$ [S1].
5.  **Occupancy Grid Transition and Update:** Use the occupancy grid from the previous frame $t-1$ to guide sampling for frame $t$. The grid is updated to reflect the scene state at frame $t$ [S1].
6.  **Rejection Sampling:** To sample points efficiently based on the updated occupancy grid, use rejection sampling on uniform ray samples. A sample $x_i$ at index $i$ along the ray is rejected if:
    $$ \text{reject } x_i \text{ if } (\sigma_{occ}(x_i) < \sigma_{min}) \land \neg(i \mod R \equiv R // 2) $$
    where $\sigma_{occ}(x_i)$ is the occupancy value from the grid, $\sigma_{min}$ is a density threshold, and $R$ is a fixed interval [S1].
7.  **Optimization:** Optimize the radiance field parameters for the current frame using the rendered images and ground truth images. The number of optimization iterations is minimized compared to temporal-based methods [S1].

### Formulas and Parameters

**Rejection Sampling Condition:**
$$ \text{Reject } x_i \iff (\sigma_{occ}(x_i) < \sigma_{min}) \land \neg(i \mod R \equiv \lfloor R/2 \rfloor) $$
*   $\sigma_{occ}(x_i)$: Occupancy value at point $x_i$ from the occupancy grid [S1].
*   $\sigma_{min}$: Density threshold for rejection [S1].
*   $R$: Fixed interval for sampling [S1].
*   $i$: Index of the sample along the ray [S1].

**Depth Smoothness Regularization (Real-world datasets only):**
For real-world datasets, a depth smoothness regularization loss is applied to handle large planar backgrounds:
$$ L_{depth} = \frac{\text{std}(d_{far} / d_{3\times3})}{\text{std}(c_{3\times3})} $$
*   $d_{far}$: Depth of the farthest sample in the patch [S1].
*   $d_{3\times3}$: Mean depth of a $3 \times 3$ patch of rays [S1].
*   $c_{3\times3}$: Mean color of the $3 \times 3$ patch [S1].
*   $\text{std}(\cdot)$: Standard deviation operator [S1].

**Parameters:**
*   **Warm-up Duration:** A 2-second warm-up period is applied to the first frame for synthetic datasets to compensate for the slower convergence of hashed voxels compared to multi-scale voxels [S1].
*   **Optimization Schedule:** The optimization process starts with a higher learning rate or iteration count (e.g., 1 at frame 1) and decays (e.g., to 0.05 at frame 10) for better convergence [S1].

### Pseudocode

```python
def train_od_nerf_frame(frame_idx, images_prev, images_curr, poses_prev, poses_curr, 
                        occupancy_grid_prev, camera_params):
    """
    Trains the OD-NeRF model for a single frame in an on-the-fly manner.
    
    Args:
        frame_idx: Current frame index.
        images_prev: List of images from the previous frame.
        images_curr: List of images from the current frame.
        poses_prev: Camera poses for the previous frame.
        poses_curr: Camera poses for the current frame.
        occupancy_grid_prev: Occupancy grid from the previous frame.
        camera_params: Intrinsics and other camera parameters.
        
    Returns:
        Trained radiance field model for the current frame.
    """
    # Initialize model based on dataset type
    if is_synthetic_dataset:
        model = TiNeuVox_Synthetic()
        # Remove temporal deformation and temporal information enhancement
        model.remove_temporal_components()
        # Replace multi-scale voxel with hash voxel
        model.replace_voxel_with_hash_grid()
        # Apply warm-up for first frame
        if frame_idx == 0:
            apply_warm_up(duration_seconds=2)
    else:
        model = InstantNGP_RealWorld()
        # Use NerfAcc implementation
        model.use_nerfacc()
        
    # Update occupancy grid for current frame
    occupancy_grid_curr = transition_and_update_occupancy_grid(
        occupancy_grid_prev, images_prev, poses_prev, images_curr, poses_curr
    )
    
    # Optimization loop for current frame
    # Number of iterations is minimized compared to temporal methods
    for iteration in range(num_iterations):
        # Sample rays for current frame
        rays = sample_rays(poses_curr, camera_params, num_rays)
        
        # Render rays using the model
        rendered_colors, rendered_depths = [], []
        for ray in rays:
            # Generate uniform samples along the ray
            uniform_samples = generate_uniform_samples(ray, num_samples)
            
            # Apply rejection sampling based on occupancy grid
            valid_samples = []
            for i, sample in enumerate(uniform_samples):
                sigma_occ = query_occupancy_grid(occupancy_grid_curr, sample)
                # Check rejection condition
                if not (sigma_occ < sigma_min and not (i % R == R // 2)):
                    valid_samples.append(sample)
            
            # Query features and predict
            predicted_outputs = []
            for sample in valid_samples:
                # Compute projected color statistics from previous frame views
                projected_colors = get_projected_colors(sample, images_prev, poses_prev)
                mu_c = mean(projected_colors)
                sigma_c = variance(projected_colors)
                
                # Query spatial feature from hash voxel grid
                f_spatial = query_hash_voxel_grid(model.hash_grid, sample)
                
                # Concatenate features
                f_input = concatenate([f_spatial, mu_c, sigma_c])
                
                # Predict density and color
                sigma, color = model.mlp(f_input)
                predicted_outputs.append((sigma, color))
            
            # Volume rendering
            color_rendered = volume_render(predicted_outputs)
            rendered_colors.append(color_rendered)
            
        # Compute loss
        loss = compute_rendering_loss(rendered_colors, images_curr)
        
        # Add depth smoothness regularization for real-world datasets
        if not is_synthetic_dataset:
            depth_loss = compute_depth_smoothness_loss(rendered_depths)
            loss += depth_smoothness_weight * depth_loss
            
        # Backpropagate and update model parameters
        model.optimize(loss)
        
    return model
```

### Edge Cases and Pitfalls
*   **Specular Surfaces and Occlusion:** The implicit correspondence relies on the relative invariance of projected color. This assumption is violated by specular surfaces and occluded points, which can cause artifacts [S1]. Filtering these outliers or explicitly detecting occlusion is possible but incurs significant computational cost [S1].
*   **Convergence on Real-World Data:** The NerfAcc implementation of InstantNGP may not converge well on forward-facing dynamic datasets (e.g., MeetRoom, DyNeRF) even for the first static frame, potentially due to large planar backgrounds with constant colors [S1]. The depth smoothness regularization helps mitigate this [S1].
*   **Hashed Voxel Convergence:** Hashed voxels capture details better but converge slower than multi-scale voxels, necessitating the warm-up period for the first frame in synthetic datasets [S1].

## Operating characteristics
*   **Speed:** Achieves an interactive speed of 6 FPS for both training and rendering on synthetic dynamic scenes in an on-the-fly setting [S1]. It provides a significant speed-up compared to state-of-the-art methods on real-world dynamic scenes [S1].
*   **Optimization Efficiency:** Requires the minimum number of optimization iterations for each new frame compared to models with temporal input dimensions or deformation fields [S1].
*   **Temporal Extrapolation:** Exhibits excellent temporal extrapolation capability due to the implicit correspondence mechanism [S1].
*   **Limitations:** Performance degrades on scenes with strong specularities or significant occlusions due to the violation of projected color invariance [S1].

## Background
OD-NeRF was introduced in the paper "OD-NeRF: Efficient Training of On-the-Fly Dynamic Neural Radiance Fields" [S1]. It addresses the challenge of efficient on-the-fly training, where the radiance field is trained and rendered frame-by-frame, by effectively utilizing the radiance field estimated from previous frames [S1]. The method was implemented on top of TiNeuVox for synthetic datasets and InstantNGP (via NerfAcc) for real-world datasets [S1].
