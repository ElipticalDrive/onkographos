# D-NeRF

Also called: Deformable Neural Radiance Fields

## Overview
D-NeRF is a method for dynamic scene representation that decomposes the scene into a static canonical space and a learned deformation field [S1]. It solves the problem of novel view synthesis for non-rigidly moving objects by treating time $t$ as an additional input to the radiance field, allowing the system to render dynamic views by controlling both camera position and time variables [S2]. Unlike methods that model temporal changes directly in the observed space, D-NeRF maps dynamic observations to a canonical template, distinguishing it from siblings like NeTF which may use different temporal encoding strategies [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D spatial coordinates $\mathbf{x}$, viewing direction $\mathbf{d}$, and timestamp $t$.
*   **Outputs:** Volume density $\sigma$ and view-dependent color $\mathbf{c}$.

**Data Structures:**
The method utilizes a Multi-Layer Perceptron (MLP) that takes the concatenated vector $[\mathbf{x}, \mathbf{d}, t]$ as input. The deformation field is typically implemented as a separate MLP or a component of the main network that outputs a displacement vector $\Delta \mathbf{x}$ for a given $\mathbf{x}$ and $t$ [S1, S2].

**Steps:**
1.  **Deformation:** For a sampled point $\mathbf{x}$ at time $t$, compute the deformation offset $\Delta \mathbf{x} = \mathcal{D}(\mathbf{x}, t)$, where $\mathcal{D}$ is the deformation network [S2].
2.  **Canonical Mapping:** Map the point to the canonical space: $\mathbf{x}_c = \mathbf{x} + \Delta \mathbf{x}$ [S1, S2].
3.  **Radiance Field Query:** Query the static radiance field MLP with $\mathbf{x}_c$ and $\mathbf{d}$ to obtain density $\sigma$ and color $\mathbf{c}$ [S1, S2].
4.  **Volume Rendering:** Render the image using standard volume rendering integration along the ray, accounting for the deformed geometry [S2].

**Formulas:**
The rendering equation integrates intensity $I$ along the ray $h$ at time $t$:
$$ C(p, t) = \int_{h_n}^{h_f} I(h, t) \sigma(p(h, t)) c(p(h, t), \mathbf{d}) \, dh $$
where $p(h, t)$ is the deformed position of the sample point [S2].

**Parameters:**
*   Time $t$: Normalized to $[0, 1]$ or mapped via positional encoding [S2].
*   Typical values: Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Complex Motion:** Deformation fields are difficult to learn when complex scene motions exist, leading to blurry results similar to Neural Volumes [S1].
*   **Topology Changes:** The method assumes continuous deformation fields, making it difficult to simulate topological changes which require discontinuities [S2].
*   **Optical Effects:** The mapping from observed space to canonical space may fail to reconstruct optical effects like transparency or specular highlights if the canonical representation cannot capture them [S2].

## Subtopics

### Neural Transient Field (NeTF)
Uses a transient field to model time-varying appearance. Choose when temporal dynamics are primarily appearance-based rather than geometric deformation. [Neural Transient Field (NeTF)](4692-neural-transient-field-netf.md)

## Operating characteristics
*   **Time and Memory Complexity:** Not given in the sources.
*   **Measured Performance:** D-NeRF achieves competitive PSNR and SSIM but suffers from blur in complex motions [S1].
*   **Strengths and Limitations:** Strengths include handling non-rigid motion via canonical space. Limitations include difficulty with complex motions and topology changes [S1, S2].
*   **When to use:** Use for non-rigid dynamic scenes with continuous deformation. Avoid for scenes with topological changes or extreme complexity where deformation fields fail [S1, S2].

## Background
D-NeRF was proposed by Park et al. in 2021 [S1, S2]. It builds on the NeRF framework by introducing a deformation field to handle dynamic scenes, decomposing the problem into a static canonical representation and a time-dependent deformation [S1]. It is used in volumetric video representation and dynamic novel view synthesis [S1, S2].
