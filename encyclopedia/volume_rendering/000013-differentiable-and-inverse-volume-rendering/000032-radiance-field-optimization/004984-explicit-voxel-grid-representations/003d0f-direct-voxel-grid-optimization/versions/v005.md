# Direct Voxel Grid Optimization

Also called: DVG, Direct Voxel Density Optimization, Direct Voxel Grid Optimization Implementation, DirectVoxGo (DVGO)

## Overview
Direct Voxel Grid Optimization (DVGO) is a method for reconstructing per-scene radiance fields from calibrated images by directly optimizing a dense voxel grid for volume density and a feature voxel grid for color, achieving convergence in less than 15 minutes on a single GPU [S1, S4]. It sets itself apart from implicit MLP-based methods like NeRF by replacing the large spatial network with explicit voxel grids and a shallow MLP, and from previous voxel methods by training the grid directly from scratch without requiring a conversion step from a trained implicit model [S1, S4].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ calibrated images with known camera poses, intrinsics, and extrinsics. The scene is assumed to be bounded within a volume of interest.
*   **Outputs:** Optimized density voxel grid, feature voxel grid, shallow MLP weights, and a bounding box (BBox) enclosing the scene.

**Data Structures:**
1.  **Bounding Box (BBox):** A 3D axis-aligned box defined by minimum and maximum coordinates $(x_{min}, y_{min}, z_{min})$ and $(x_{max}, y_{max}, z_{max})$. It tightly encloses the volume of interest to ensure parsimony [S1, S4].
2.  **Density Voxel Grid ($V_{\sigma}$):** A 3D grid of size $M \times M \times M$ (typically $100^3$ for coarse, $160^3$ or $256^3$ for fine). Each voxel stores a raw density value $\sigma_{raw}$.
3.  **Feature Voxel Grid ($V_{feat}$):** A 3D grid of size $M \times M \times M$ (same resolution as fine density grid). Each voxel stores a feature vector of dimension $D$ (typically $D=12$) [S1, S4].
4.  **Color Voxel Grid ($V_{color}$):** (Coarse stage only) A 3D grid of size $M_c \times M_c \times M_c$ storing view-invariant color.
5.  **Shallow MLP:** A network with 2 hidden layers, 128 channels per layer, taking concatenated position features and viewing direction features as input to predict color [S4].

**Numbered Steps:**

1.  **Initialization:**
    *   Automatically find a BBox tightly enclosing the scene's volume of interest [S1, S4].
    *   Initialize the coarse density grid $V_{\sigma}^{(c)}$ with raw values such that the activated opacity is very close to zero everywhere. Specifically, set the initial activated alpha $\alpha_{init}^{(c)} = 10^{-6}$ [S1, S4]. This avoids geometry solutions being biased toward the cameras' near planes [S1].
    *   Initialize the fine density grid $V_{\sigma}^{(f)}$ with $\alpha_{init}^{(f)} = 0.01$ [S1, S4].
    *   Initialize the feature grid $V_{feat}^{(f)}$ and color grid $V_{color}^{(c)}$ to zeros or small random values [G].

2.  **Coarse Geometry Search:**
    *   Optimize the coarse density grid $V_{\sigma}^{(c)}$ and color grid $V_{color}^{(c)}$ for 10,000 iterations using the Adam optimizer with a base learning rate of 0.1 for voxel grids [S1, S4].
    *   Sample $K$ points along each ray $\mathbf{r}$ between near and far planes. The step size is $\delta^{(c)} = 0.5 \times s^{(c)}$, where $s^{(c)}$ is the voxel size [S4].
    *   **Free Space Skipping:** Define known free space using a threshold $\tau_c = 10^{-3}$. If the interpolated density at a query point is below $\tau_c$, skip the query for that point [S1].
    *   **View-Count Prior:** Apply a lower learning rate to voxels visible to fewer views to avoid allocating redundant voxels just to explain observations from a small number of views [S1, S4].
    *   **Rendering:** Query density $\sigma_i$ and color $\mathbf{c}_i$ (from $V_{color}^{(c)}$). Compute opacity $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ and transmittance $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$. Render color $\hat{C}(\mathbf{r})$ using volume rendering quadrature [S1, S4].
    *   **Loss:** Minimize photometric loss $\mathcal{L}_{\text{photo}}$ plus background loss with weight $w_{bg} = 10^{-2}$ [S1].

3.  **Fine Detail Reconstruction:**
    *   Optimize the fine density grid $V_{\sigma}^{(f)}$ and feature grid $V_{feat}^{(f)}$ for 20,000 iterations [S1, S4].
    *   **Progressive Scaling:** Progressively scale the fine-stage voxel grid at checkpoints 1000, 2000, and 3000 iterations [S1].
    *   Sample points with step size $\delta^{(f)} = 0.5 \times s^{(f)}$ [S4].
    *   **Low-Density Skipping:** Skip low-density query points in unknown space using threshold $\tau_f = 10^{-4}$ [S1].
    *   **Color Query:** Query feature vector $\mathbf{f}_i$ from $V_{feat}^{(f)}$ at position $\mathbf{x}_i$. Concatenate with positional encoding of $\mathbf{x}_i$ (5 frequencies) and viewing direction $\mathbf{d}_i$ (4 frequencies). Pass through the shallow MLP to predict view-dependent color $\mathbf{c}_i$ [S1, S4].
    *   **Learning Rates:** Use base learning rate 0.1 for voxel grids and $10^{-3}$ for the shallow MLP [S4]. Apply exponential learning rate decay, downscaled by 0.1 at 20,000 iterations [S1].
    *   **Loss:** Minimize photometric loss $\mathcal{L}_{\text{photo}}$ with weights $w_{photo}=1$, point-wise RGB loss $w_{pt\_rgb}=10^{-2}$, and background loss $w_{bg}=10^{-3}$ [S1, S4].

4.  **Post-Activation Interpolation:**
    *   Unlike previous methods that interpolate activated opacity or use nearest-neighbor interpolation, DVGO applies trilinear interpolation on the raw density values from the grid, then applies the activation function (e.g., Softplus or ReLU) to produce opacity [S1, S4]. This allows modeling sharp linear surfaces within a single grid cell [S1, S4].

**Formulas:**

Rendered color $\hat{C}(\mathbf{r})$ for a ray $\mathbf{r}$:
$$ \hat{C}(\mathbf{r}) = \left( \sum_{i=1}^K T_i \alpha_i \mathbf{c}_i \right) + T_{K+1} \mathbf{c}_{\text{bg}} $$
where:
*   $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ is the opacity at sample $i$.
*   $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$ is the accumulated transmittance.
*   $\sigma_i$ is the density at sample $i$.
*   $\delta_i$ is the distance to the adjacent sampled point.
*   $\mathbf{c}_i$ is the color at sample $i$.
*   $\mathbf{c}_{\text{bg}}$ is the background color [S1, S4].

Photometric Loss:
$$ \mathcal{L}_{\text{photo}} = \frac{1}{|\mathcal{R}|} \sum_{\mathbf{r} \in \mathcal{R}} \left\| \hat{C}(\mathbf{r}) - C(\mathbf{r}) \right\|_2^2 $$
where $\mathcal{R}$ is the set of rays in a sampled mini-batch and $C(\mathbf{r})$ is the observed pixel color [S4].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class DVGO:
    def __init__(self, bbox_min, bbox_max, coarse_res=100, fine_res=160, 
                 feat_dim=12, num_coarse_iters=10000, num_fine_iters=20000):
        self.bbox_min = torch.tensor(bbox_min)
        self.bbox_max = torch.tensor(bbox_max)
        self.coarse_res = coarse_res
        self.fine_res = fine_res
        self.feat_dim = feat_dim
        
        # Initialize grids
        # Density grid stores raw values. 
        # Initialize to yield alpha ~ 10^-6. 
        # alpha = 1 - exp(-sigma * delta). 
        # If we want alpha_init = 1e-6, and delta ~ voxel_size, 
        # sigma_raw needs to be small. 
        # The paper initializes activated alpha directly via the grid values 
        # after activation. We store raw sigma.
        # For coarse: alpha_init_c = 1e-6. 
        # For fine: alpha_init_f = 0.01.
        
        self.coarse_density = nn.Parameter(torch.zeros(coarse_res, coarse_res, coarse_res))
        self.fine_density = nn.Parameter(torch.zeros(fine_res, fine_res, fine_res))
        self.fine_feat = nn.Parameter(torch.zeros(fine_res, fine_res, fine_res, feat_dim))
        
        # Shallow MLP for color prediction
        self.mlp = nn.Sequential(
            nn.Linear(feat_dim + 5 + 4, 128), # pos_enc(5) + dir_enc(4) + feat
            nn.ReLU(),
            nn.Linear(128, 128),
            nn.ReLU(),
            nn.Linear(128, 3) # RGB
        )
        
        # Hyperparameters
        self.alpha_init_c = 1e-6
        self.alpha_init_f = 0.01
        self.tau_c = 1e-3
        self.tau_f = 1e-4
        self.lr_voxel = 0.1
        self.lr_mlp = 1e-3
        
    def get_voxel_size(self, res):
        return (self.bbox_max - self.bbox_min) / res

    def query_density(self, grid, coords, res):
        """
        Query density from a voxel grid using trilinear interpolation.
        coords: (N, 3) in [0, 1] range relative to grid dimensions.
        """
        # Trilinear interpolation
        density = F.grid_sample(
            grid.unsqueeze(0).unsqueeze(0), # (1, 1, D, D, D)
            coords.unsqueeze(0).unsqueeze(0).unsqueeze(0), # (1, 1, 1, N, 3)
            mode='bilinear', # Note: grid_sample expects 2D or 3D spatial. For 3D volume, use 'trilinear' if available or manual.
            align_corners=True
        ).squeeze()
        # Correction: grid_sample for 3D data (N, C, D, H, W) uses 'trilinear'
        # Here grid is (D, D, D). We treat it as (1, 1, D, D, D)
        # coords are normalized to [-1, 1] for grid_sample? 
        # PyTorch grid_sample expects coordinates in [-1, 1].
        # Let's assume a helper to normalize coords to [-1, 1]
        pass 

    def post_activation_density(self, raw_sigma, delta):
        """
        Apply activation after interpolation.
        raw_sigma: interpolated raw density value.
        delta: step size.
        """
        # The paper uses Softplus or ReLU on raw sigma before alpha calculation?
        # "trilinearly interpolate the raw density values ... then apply the activation function"
        # Usually sigma must be non-negative. Softplus is standard.
        sigma = F.softplus(raw_sigma)
        alpha = 1.0 - torch.exp(-sigma * delta)
        return sigma, alpha

    def render_ray(self, ray_origins, ray_directions, near, far, coarse=True):
        """
        Render a batch of rays.
        """
        if coarse:
            res = self.coarse_res
            grid = self.coarse_density
            alpha_init = self.alpha_init_c
            tau = self.tau_c
            lr = self.lr_voxel
        else:
            res = self.fine_res
            grid = self.fine_density
            alpha_init = self.alpha_init_f
            tau = self.tau_f
            lr = self.lr_voxel

        voxel_size = self.get_voxel_size(res)
        step_size = 0.5 * voxel_size.mean() # Approximation
        
        # Sample K points
        K = 128 # Example
        t = torch.linspace(near, far, K)
        points = ray_origins.unsqueeze(1) + ray_directions.unsqueeze(1) * t.unsqueeze(2) # (N, K, 3)
        
        # Normalize points to [0, 1] for grid sampling
        norm_points = (points - self.bbox_min) / (self.bbox_max - self.bbox_min)
        
        # Query density
        # Using grid_sample for trilinear interpolation
        # grid_sample input: (N, C, D, H, W) -> (1, 1, D, D, D)
        # grid_sample coords: (N, H_out, W_out, 2) or (N, D_out, H_out, W_out, 3)
        # We need to reshape for grid_sample
        grid_3d = grid.unsqueeze(0).unsqueeze(0) # (1, 1, D, D, D)
        norm_points_3d = norm_points.view(-1, 3) # (N*K, 3)
        
        # grid_sample expects coords in [-1, 1]
        coords_3d = 2.0 * norm_points_3d - 1.0
        coords_3d = coords_3d.view(1, 1, 1, -1, 3) # (1, 1, 1, N*K, 3)
        
        density_vals = F.grid_sample(grid_3d, coords_3d, mode='trilinear', align_corners=True)
        density_vals = density_vals.view(-1, K) # (N, K)
        
        # Apply post-activation
        # Initialize raw density to achieve alpha_init
        # alpha = 1 - exp(-sigma * delta) => sigma = -ln(1-alpha)/delta
        # We initialize the grid such that interpolated raw values yield this sigma.
        # For simplicity, we assume the grid stores raw sigma.
        
        sigma_vals, alpha_vals = self.post_activation_density(density_vals, step_size)
        
        # Free space skipping
        mask = sigma_vals > tau
        alpha_vals = alpha_vals * mask.float()
        
        # Compute transmittance
        T = torch.cumprod(1.0 - alpha_vals, dim=1)
        T = torch.cat([torch.ones_like(T[:, :1]), T[:, :-1]], dim=1)
        
        # Query color
        if coarse:
            # Use color grid
            feat_grid = self.coarse_color # Assuming this exists
            # Interpolate color directly
            color_vals = F.grid_sample(feat_grid.unsqueeze(0).unsqueeze(0), coords_3d, mode='trilinear', align_corners=True)
            color_vals = color_vals.view(-1, K, 3)
        else:
            # Use feature grid + MLP
            feat_vals = F.grid_sample(self.fine_feat.unsqueeze(0).unsqueeze(0), coords_3d, mode='trilinear', align_corners=True)
            feat_vals = feat_vals.view(-1, K, self.feat_dim)
            
            # Positional encoding for position
            # Simplified: assume pos_enc function
            pos_enc = positional_encoding(norm_points_3d, num_frequencies=5)
            pos_enc = pos_enc.view(-1, K, 10)
            
            # Positional encoding for direction
            dir_enc = positional_encoding(ray_directions, num_frequencies=4)
            dir_enc = dir_enc.unsqueeze(1).expand(-1, K, -1) # (N, K, 8)
            
            input_feat = torch.cat([feat_vals, pos_enc, dir_enc], dim=2)
            color_vals = self.mlp(input_feat) # (N, K, 3)
            
        # Background color
        c_bg = torch.tensor([0.0, 0.0, 0.0]) # Example
        
        # Composite
        weights = alpha_vals * T
        rendered_color = torch.sum(weights.unsqueeze(2) * color_vals, dim=1) + T[:, -1].unsqueeze(1) * c_bg
        
        return rendered_color

    def train_step(self, rays, images, coarse=True):
        rendered = self.render_ray(rays.origins, rays.directions, rays.near, rays.far, coarse)
        loss = F.mse_loss(rendered, images)
        
        # Add background loss if needed
        # Add point-wise RGB loss if needed
        
        optimizer = torch.optim.Adam([
            {'params': self.coarse_density if coarse else self.fine_density, 'lr': self.lr_voxel},
            {'params': self.fine_feat if not coarse else [], 'lr': self.lr_voxel},
            {'params': self.mlp.parameters(), 'lr': self.lr_mlp}
        ])
        
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        return loss.item()
```

## Subtopics

### [Ref-DVGO](6572-ref-dvgo.md)
Ref-DVGO is a reflection-aware neural rendering method that combines the fast hybrid implicit-explicit representation of Direct Voxel Grid Optimization (DVGO) with the reflection direction reparameterization of Ref-NeRF to achieve high-quality photorealistic novel view synthesis of reflective scenes with reduced training and rendering time. It sets itself apart from DVGO by explicitly modeling specular reflections via a reflection-aware reparameterization and from Ref-NeRF by replacing large spatial MLPs with six distinct voxel grids, significantly reducing GPU memory requirements and training time.

## Operating characteristics
**Time and Memory Complexity:**
*   **Training Time:** Approximately 15 minutes to train from scratch for a new scene on a single NVIDIA RTX 2080 Ti GPU for a $160^3$ grid, and 22 minutes for a $256^3$ grid [S1, S4]. This is about two orders of magnitude faster than NeRF (10-20 hours) [S1].
*   **Rendering Speed:** Approximately 45x faster than NeRF (0.64 seconds vs 29 seconds per 800x800 image) [S1].
*   **Memory:** The method uses dense voxel grids. A $160^3$ grid contains 4.096 million voxels. With 12 feature channels and float32 precision, the feature grid consumes ~20 MB. The density grid is ~16 MB. The shallow MLP is negligible. This is significantly less memory than large MLP-based NeRFs for high-resolution details.

**Scaling:**
*   The method scales with grid resolution. Higher resolutions ($256^3$) yield higher PSNR (32.80 vs 31.95) but require more training time and memory [S1].
*   The automatic BBox allocation ensures parsimony, avoiding unnecessary computation in empty space [S1, S4].

**Strengths and Limitations:**
*   **Strengths:** Extremely fast convergence from scratch; no cross-scene pretraining required; high rendering speed; sharp surface modeling via post-activation interpolation [S1, S4].
*   **Limitations:** Prone to suboptimal geometry solutions (allocating "cloud" in free space) if priors are not applied; real-world data uncertainty (lighting, SfM error) can lead to blurrier surfaces, lessening the advantage of post-activation [S1]; not designed for unbounded or forward-facing scenes [S1].

**When to Use:**
*   Use for per-scene novel view synthesis where fast training is critical and the scene is bounded and inward-facing [S1, S4].
*   Use when cross-scene pretraining is not feasible or desired [S1].

**When Not to Use:**
*   Do not use for unbounded scenes or forward-facing scenarios [S1].
*   Do not use if real-world data has significant multi-view inconsistency, as this may degrade quality more than in NeRF due to the explicit nature of the grid [S1].

## Background
Direct Voxel Grid Optimization (DVGO) was introduced by Cheng Sun, Min Sun, and Hwann-Tzong Chen in 2022 [S1, S4]. It was presented at the IEEE/CVF Conference on Computer Vision and Pattern Recognition (CVPR) 2022 [S1, S4]. The method addresses the bottleneck of lengthy training times in Neural Radiance Fields (NeRF) by directly optimizing a voxel grid representation from scratch, eliminating the need for conversion from implicit models or cross-scene pretraining [S1, S4]. It builds on the principles of [Voxel Grid Optimization](4131-voxel-grid-optimization.md) by using explicit voxel grids for density and feature storage, combined with a shallow MLP for view-dependent color [S2, S3].
