# NeuS

Also called: Learning Neural Implicit Surfaces by Volume Rendering for Multi-view Reconstruction, NeuS Volume Rendering with Softplus SDF, NeuS, NeuS2 Static Reconstruction, Neural Implicit Surface, Neural Surface

## Overview
NeuS is a neural surface reconstruction method that represents a surface as the zero-level set of a signed distance function (SDF) and trains it using a novel volume rendering scheme to avoid geometric bias inherent in standard volume rendering [S1, unofficial][S3]. It solves the problem of reconstructing high-quality 3D surfaces from multi-view 2D images by combining the robustness of neural radiance fields (NeRF) with the geometric precision of implicit SDFs [S1, unofficial][S3]. Unlike its siblings [Surface NeRF](7385-surface-nerf.md) and [VolSDF](10715-volsdf.md), which also use SDFs, NeuS introduces a specific S-density formulation based on the derivative of the sigmoid function to ensure unbiased surface reconstruction in the first-order approximation [S1, unofficial].

## How it works
**Inputs:** A set of posed images $\{I_k\}$ of a 3D object.
**Outputs:** A trained SDF network $f(\mathbf{x})$ and a color network $c(\mathbf{x}, \mathbf{v})$, from which a mesh is extracted via Marching Cubes [S1, unofficial][S2].

**Data Structures:**
The scene is represented by two Multi-layer Perceptrons (MLPs) [S1, unofficial]:
1.  **SDF Network ($f$):** Maps spatial position $\mathbf{x} \in \mathbb{R}^3$ to a signed distance scalar $d$.
    *   Architecture: 8 hidden layers, hidden size 256.
    *   Activation: Softplus with $\beta=100$ (replacing ReLU) [S1, unofficial].
    *   Skip connection: Input connected to the output of the 4th layer [S1, unofficial].
    *   Output: Tuple $(d, \mathbf{g})$ where $d$ is the SDF value and $\mathbf{g} \in \mathbb{R}^{15}$ is a geometry feature vector [S4].
2.  **Color Network ($c$):** Maps spatial location $\mathbf{p}$, viewing direction $\mathbf{v}$, normal $\mathbf{n}$, and feature $\mathbf{g}$ to color $\mathbf{c} \in \mathbb{R}^3$.
    *   Architecture: 4 hidden layers, size 256 [S1, unofficial].
    *   Inputs: Spatial location $\mathbf{p}$ (positional encoding, 6 frequencies), view direction $\mathbf{v}$ (positional encoding, 4 frequencies), normal $\mathbf{n} = \nabla f(\mathbf{p})$, and feature $\mathbf{g}$ [S1, unofficial].
    *   Stabilization: Weight normalization is applied [S1, unofficial].

**Ray Parameterization:**
A ray emitted from a pixel is denoted as $\mathbf{p}(t) = \mathbf{o} + t\mathbf{v}$ where $t \ge 0$, $\mathbf{o}$ is the camera center, and $\mathbf{v}$ is the unit direction vector [S1, unofficial].

**S-Density and Alpha Computation:**
Standard volume rendering applied directly to SDF-associated density causes inherent geometric errors (bias) [S1, unofficial]. NeuS defines an S-density function $\phi_s(f(\mathbf{x}))$ to replace the standard density $\sigma$ [S1, unofficial].
The S-density is the derivative of the Sigmoid function $\Phi_s(x) = (1 + e^{-sx})^{-1}$:
$$
\phi_s(x) = \frac{s e^{-sx}}{(1 + e^{-sx})^2}
$$
where $s$ is a trainable parameter controlling the sharpness of the distribution. The standard deviation is $1/s$, which approaches zero as training converges [S1, unofficial].

The cumulative distribution function is $\Phi_s(f(\mathbf{x}))$. For a ray segment between section points $q_i$ and $q_{i+1}$, the alpha value $\alpha_i$ is computed as [S1, unofficial]:
$$
\alpha_i = \max\left( \frac{\Phi_s(f(q_i)) - \Phi_s(f(q_{i+1}))}{\Phi_s(f(q_i))}, 0 \right)
$$
The color $c_i$ for the segment is computed using the color of the mid-point $p_i = \mathbf{o} + \frac{t_i + t_{i+1}}{2}\mathbf{v}$ [S1, unofficial].

**Rendering Equation:**
The rendered color $C(\mathbf{o}, \mathbf{v})$ is the integral of the weight function $w(t)$ times the color $c(\mathbf{p}(t), \mathbf{v})$ along the ray [S1, unofficial]:
$$
C(\mathbf{o}, \mathbf{v}) = \int_0^{+\infty} w(t) c(\mathbf{p}(t), \mathbf{v}) dt
$$
In discrete form, using transmittance $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$:
$$
\hat{C}(\mathbf{r}) = \sum_{i=1}^N T_i \alpha_i c_i
$$

**Sampling Strategy:**
1.  **Uniform Sampling:** 64 points are sampled uniformly along the ray [S1, unofficial].
2.  **Importance Sampling:** Iteratively conducted for $k=4$ times. In the $i$-th iteration, a fixed $s$ value is used for coarse probability estimation, set as $32 \times 2^i$. In each iteration, 16 additional points are sampled [S1, unofficial].
3.  **Total Points:** 128 points total [S1, unofficial].
4.  **Outside Sphere:** For the 'w/o mask' setting, 32 extra points are sampled outside the sphere to represent the background using NeRF++ [S1, unofficial].

**Loss Function:**
The training minimizes the color difference and enforces the Eikonal constraint [S4]:
$$
\mathcal{L} = \mathcal{L}_{\text{color}} + \beta \mathcal{L}_{\text{eikonal}}
$$
*   $\mathcal{L}_{\text{color}}$: Huber loss between rendered pixels $\hat{C}_i$ and ground truth pixels $C_i$ [S4].
*   $\mathcal{L}_{\text{eikonal}}$: Regularizes the SDF gradient magnitude to 1. $\mathcal{L}_{\text{eikonal}} = \frac{1}{mn} \sum_{k,i} (\|\mathbf{n}_{k,i}\| - 1)^2$, where $m$ is batch size, $n$ is number of sampled points, and $\mathbf{n}_{k,i}$ is the normal of the $k$-th sample on ray $i$ [S4].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class NeuSModel:
    def __init__(self):
        # SDF Network: 8 hidden layers, size 256, Softplus(beta=100), skip connection from input to 4th layer output
        self.sdf_mlp = SDFNetwork(hidden_size=256, num_layers=8, skip_layer=4, beta=100)
        # Color Network: 4 hidden layers, size 256
        self.color_mlp = ColorNetwork(hidden_size=256, num_layers=4)
        # Trainable sharpness parameter s
        self.s = nn.Parameter(torch.tensor(32.0))
        
    def positional_encoding(self, x, num_frequencies):
        # Standard positional encoding with num_frequencies frequencies
        # x shape: (..., 3) or (..., 2)
        pe = []
        for i in range(num_frequencies):
            freq = 2**i * torch.pi
            pe.append(torch.sin(x * freq))
            pe.append(torch.cos(x * freq))
        return torch.cat(pe, dim=-1)

    def compute_sdf_and_normal(self, x):
        # x shape: (N, 3)
        # Returns: sdf (N,), normal (N, 3)
        sdf_val = self.sdf_mlp(x) # Returns scalar SDF
        # Compute gradient for normal
        sdf_val.requires_grad_(True)
        grad_outputs = torch.ones_like(sdf_val)
        gradients = torch.autograd.grad(
            outputs=sdf_val,
            inputs=x,
            grad_outputs=grad_outputs,
            create_graph=True,
            retain_graph=True,
            only_inputs=True
        )[0]
        normal = gradients / (torch.norm(gradients, dim=-1, keepdim=True) + 1e-5)
        return sdf_val, normal

    def sigmoid_cdf(self, x, s):
        # Phi_s(x) = 1 / (1 + exp(-s*x))
        return 1.0 / (1.0 + torch.exp(-s * x))

    def compute_alpha(self, sdf_vals, s):
        # sdf_vals: (N+1,) section points SDF values
        # Returns alpha: (N,)
        # alpha_i = max((Phi_s(q_i) - Phi_s(q_{i+1})) / Phi_s(q_i), 0)
        phi_prev = self.sigmoid_cdf(sdf_vals[:-1], s)
        phi_next = self.sigmoid_cdf(sdf_vals[1:], s)
        
        # Avoid division by zero
        alpha = (phi_prev - phi_next) / (phi_prev + 1e-5)
        alpha = torch.clamp(alpha, min=0.0)
        return alpha

    def render_ray(self, origin, direction, num_samples=128):
        # origin: (3,), direction: (3,)
        # Sample points along ray
        # 1. Uniform 64 points
        t_uniform = torch.linspace(0, 1, 64) # Normalized t, scaled by scene bounds in practice
        t_samples = t_uniform
        
        # 2. Importance Sampling (4 iterations, 16 points each)
        # Note: Exact importance sampling logic requires computing weights from current s
        # Simplified: Just append points based on importance weights derived from current SDF
        # For implementation completeness, we assume a helper that returns refined t values
        # In original NeuS: coarse prob estimation uses fixed s = 32 * 2^i
        t_refined = []
        current_s = self.s
        for i in range(4):
            coarse_s = 32 * (2 ** i)
            # Compute weights based on current SDF and coarse_s
            # Sample 16 new points based on these weights
            # (Placeholder for actual importance sampling logic which depends on scene bounds and SDF query)
            pass 
        
        t_all = torch.cat([t_samples, torch.tensor(t_refined)])
        t_all.sort()
        
        # Section points q_i and mid-points p_i
        t_sections = t_all
        t_mids = (t_sections[:-1] + t_sections[1:]) / 2.0
        
        # 3D positions
        positions_sections = origin.unsqueeze(0) + t_sections.unsqueeze(1) * direction.unsqueeze(0)
        positions_mids = origin.unsqueeze(0) + t_mids.unsqueeze(1) * direction.unsqueeze(0)
        
        # Query SDF at section points
        sdf_sections, _ = self.compute_sdf_and_normal(positions_sections)
        
        # Compute Alpha
        alpha = self.compute_alpha(sdf_sections, self.s)
        
        # Query Color at mid-points
        # Need normals for color network. Compute normals at mid-points or approximate from section gradients
        # Original NeuS uses normal from SDF gradient at the point.
        # For mid-points, we query SDF and gradient again or interpolate.
        # Here we query at mid-points for accuracy.
        sdf_mids, normals_mids = self.compute_sdf_and_normal(positions_mids)
        
        # Color Network Inputs
        # Positional encoding for position (6 freq) and view direction (4 freq)
        pos_pe = self.positional_encoding(positions_mids, 6)
        dir_pe = self.positional_encoding(direction.unsqueeze(0).expand_as(positions_mids), 4)
        
        # Get geometry feature from SDF MLP (if implemented as returning tuple)
        # Assuming sdf_mlp returns (sdf, feature)
        # If not, feature might be intermediate layer output. 
        # Based on S4, SDF network outputs (d, g).
        # We need to modify compute_sdf_and_normal to return feature if needed.
        # For this pseudocode, we assume we can get feature g.
        # Let's assume a method get_sdf_feature(x) exists.
        _, feature_g = self.sdf_mlp(positions_mids) # Returns (sdf, feature)
        
        # Concatenate inputs for color network: pos_pe, dir_pe, normals_mids, feature_g
        color_input = torch.cat([pos_pe, dir_pe, normals_mids, feature_g], dim=-1)
        colors = self.color_mlp(color_input)
        
        # Transmittance
        # T_i = product(1 - alpha_j) for j < i
        # alpha shape: (N,)
        # 1 - alpha
        one_minus_alpha = 1.0 - alpha
        # Cumulative product
        T = torch.cumprod(one_minus_alpha, dim=0)
        # Prepend 1.0 for the first segment
        T = torch.cat([torch.ones(1, device=T.device), T[:-1]])
        
        # Weight w_i = T_i * alpha_i
        weights = T * alpha
        
        # Rendered Color
        rendered_color = torch.sum(weights.unsqueeze(-1) * colors, dim=0)
        
        # Eikonal Loss term for this ray
        # L_eikonal = (||n|| - 1)^2
        # Normals were computed in compute_sdf_and_normal
        # We need to return normals for loss calculation
        return rendered_color, weights, sdf_sections, normals_mids, t_sections

    def forward(self, rays_o, rays_d, gt_images):
        # rays_o: (B, 3), rays_d: (B, 3)
        # gt_images: (B, H, W, 3)
        # Flatten rays
        B, H, W, _ = gt_images.shape
        rays_o_flat = rays_o.view(-1, 3)
        rays_d_flat = rays_d.view(-1, 3)
        gt_flat = gt_images.view(-1, 3)
        
        rendered_colors = []
        all_normals = []
        
        for i in range(rays_o_flat.shape[0]):
            o = rays_o_flat[i]
            d = rays_d_flat[i]
            color, _, _, normals, _ = self.render_ray(o, d)
            rendered_colors.append(color)
            all_normals.append(normals)
            
        rendered_colors = torch.stack(rendered_colors)
        all_normals = torch.stack(all_normals)
        
        # Color Loss (Huber)
        L_color = F.huber_loss(rendered_colors, gt_flat)
        
        # Eikonal Loss
        # ||n|| should be 1
        norms = torch.norm(all_normals, dim=-1)
        L_eikonal = torch.mean((norms - 1.0) ** 2)
        
        # Total Loss
        beta = 1.0 # Typical value, though source says 'indispensable' without specific value in this context
        loss = L_color + beta * L_eikonal
        
        return loss, rendered_colors, L_color, L_eikonal
```

**Parameters:**
*   $s$: Trainable parameter for S-density sharpness. Initial value often related to 32. Standard deviation $1/s$ decreases during training [S1, unofficial].
*   Softplus $\beta$: 100 [S1, unofficial].
*   Learning Rate: Warmup from 0 to $5 \times 10^{-4}$ in first 5k iterations, then cosine decay to minimum $2.5 \times 10^{-5}$ [S1, unofficial].
*   Total Iterations: 300k [S1, unofficial].
*   Sampling: 64 uniform + 4 iterations of 16 importance samples = 128 total [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Geometric Bias:** Naive application of volume rendering to SDF density causes inherent geometric errors. NeuS formulation avoids this in the first-order approximation [S1, unofficial].
*   **Numerical Stability:** Division by zero in alpha calculation is prevented by adding epsilon (1e-5) [S5, unofficial].
*   **Spectral Bias:** Random initialization can produce axis-aligned artifacts due to positional encoding spectral bias. Geometric initialization avoids this [S1, unofficial].
*   **Textureless Regions:** Textureless areas are ambiguous and may fail to reconstruct correctly [S1, unofficial].

## Subtopics

### [HAME-NeRF](9325-hame-nerf.md)
HAME-NeRF is a two-stage framework for extracting high-fidelity, textured surface meshes from RGB images by defining volume density as a Secant Hyperbolic Function applied to a Signed Distance Function (SDF). It builds on [NeuS](6060-neus.md) by introducing a spatially-varying sharpness parameter $\beta(\mathbf{x})$ learned via an MLP, which enhances flexibility for complex surfaces compared to methods using fixed $\beta$ values. Unlike [NeuS](6060-neus.md) which focuses on differentiable volume rendering for surface representation, HAME-NeRF explicitly optimizes a mesh through differentiable rendering and iterative refinement, achieving superior geometric accuracy and visual quality on synthetic benchmarks compared to [NeRF2Mesh](52-nerf2mesh.md).

### [D-NeuS](10217-d-neus.md)
D-NeuS is a volume rendering-based neural implicit surface reconstruction method that recovers fine-level geometric details by extending NeuS with two additional loss functions: a geometry bias loss and a multi-view feature consistency loss. It addresses the ambiguity in geometry and appearance representation inherent in volume rendering by ensuring consistency between the rendered surface points (derived from alpha compositing) and the underlying signed distance field (SDF) zero-crossings. Unlike its parent NeuS, which suffers from geometry bias due to the non-linear transformation of SDF to density, D-NeuS explicitly penalizes this bias and enforces feature consistency on surface points rather than all sampled points, distinguishing it from siblings like HAME-NeRF and NeuS2.

### NeuS2
NeuS2 is a fast neural surface reconstruction approach for multi-view RGB input that achieves two orders of magnitude improvement in training speed over NeuS without compromising reconstruction quality, applicable to both static and dynamic scenes [S1, unofficial]. It sets itself apart by parameterizing the neural network-encoded Signed Distance Field (SDF) using multi-resolution hash tables of learnable feature vectors, as introduced in Instant-NGP, and by calculating second-order derivatives using a novel lightweight formula tailored to ReLU-based MLPs to leverage CUDA parallelism and reduce memory footprint [S1, unofficial].

### [HF-NeuS](12039-hf-neus.md)
HF-NeuS is an improvement on NeuS that separates low-frequency details into a base SDF and high-frequency details into a displacement function to increase reconstruction quality. It builds on [NeuS](6060-neus.md) by addressing the smoothness limitations of standard implicit SDF representations, which often fail to capture sharp geometric features.

### SparseNeus
SparseNeus is a method improving NeuS for sparse-view SDF reconstruction using a geometry encoding volume with learnable image features as a hybrid representation method [S3].

## Operating characteristics
*   **Time Complexity:** Training is slow. On a single Nvidia 2080Ti GPU, training takes ~14-16 hours for 300k iterations [S1, unofficial]. Rendering a 1600x1200 image takes ~320 seconds in default volume rendering setting, or ~60 seconds with sphere tracing acceleration [S1, unofficial].
*   **Memory Complexity:** Requires storing intermediate states for backpropagation through the volume rendering equation. The SDF and Color MLPs are relatively small (8 and 4 layers respectively), but the number of samples (128) per ray contributes to memory usage during training [S1, unofficial].
*   **Performance:** On the NeRF Synthetic dataset, NeuS achieved PSNR = 28.4 +- 0.8 dB [S2]. On the DTU dataset, it achieved the most accurate surface reconstruction with Chamfer distance = 0.62 +- 0.08 mm [S2].
*   **Strengths:** High-quality surface reconstruction, robust optimization for complex structures, unbiased surface representation in first-order approximation [S1, unofficial].
*   **Limitations:** Slow rendering and training speed compared to NeRF [S2]. Struggles with textureless regions [S1, unofficial].

## Background
NeuS was introduced in 2021 by Yen-Chen Liu et al. in the paper "NeuS: Learning Neural Implicit Surfaces by Volume Rendering for Multi-view Reconstruction" [S1, unofficial]. It was developed to address the limitations of existing neural implicit surface representations, such as IDR, which lacked sufficient surface constraints, and NeRF, which was not explicitly designed for surface extraction. NeuS combines the robustness of NeRF's volume rendering with the geometric accuracy of SDFs. It is widely used in 3D computer vision for multi-view reconstruction tasks [S1, unofficial][S3].
