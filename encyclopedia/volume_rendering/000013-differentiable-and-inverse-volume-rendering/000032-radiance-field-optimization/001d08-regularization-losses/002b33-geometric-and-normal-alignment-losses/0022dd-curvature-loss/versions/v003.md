# Curvature Loss


## Overview
Curvature loss is a geometric regularization term used in differentiable volume rendering and radiance-field optimization to penalize curvature in the predicted scalar field [S1, unofficial]. It differs from normal alignment losses by operating directly on the scalar field's derivatives rather than explicit normal vectors [S1, unofficial].

## How it works
### Inputs and Outputs
- **Input**: Model output (scalar field values $f$) [S1, unofficial].
- **Output**: Scalar curvature loss value [S1, unofficial].

### Steps
1. Retrieve the curvature loss weight $\lambda_{\text{curvature}}$ from the configuration [S1, unofficial].
2. Apply the curvature operator $C$ to the model output $f$ to compute curvature values [S1, unofficial].
3. Multiply the curvature values by $\lambda_{\text{curvature}}$ to obtain the loss [S1, unofficial].

### Formula
$$ L_{\text{curvature}} = \lambda_{\text{curvature}} \cdot C(f) $$
where $C(f)$ is the result of applying the curvature operator to the model output $f$ [S1, unofficial].

### Parameters
- **$\lambda_{\text{curvature}}$**: The weight for the curvature loss term, retrieved from `self.config.system.loss.lambda_curvature` [S1, unofficial].

## Subtopics

### SDF Edge Regularization Loss
A loss function that penalizes SDF values at edges where the sign changes, encouraging sharp features or correct topology at boundaries [S2, unofficial]. It gathers SDF values at edge endpoints, creates a mask for edges where signs differ, filters to those edges, and computes a binary cross-entropy loss between the first endpoint and the boolean second endpoint, and vice versa [S2, unofficial].

### Normal Smoothness Loss
A regularization loss that encourages consecutive normals along a ray to be similar, enforcing spatial smoothness [S3, unofficial]. The loss is calculated as $L = w \cdot (1 - \mathbf{n}_p \cdot \mathbf{n}_{prev})$, where $w$ is the weight (default 1.0), $\mathbf{n}_p$ is the normal at the current sample, and $\mathbf{n}_{prev}$ is the normal at the previous sample along the ray [S3, unofficial]. It requires tracking adjacent sample normals along a ray, which is not natively supported by the integrator in the referenced codebase and is currently a placeholder for future implementation [S3, unofficial].
