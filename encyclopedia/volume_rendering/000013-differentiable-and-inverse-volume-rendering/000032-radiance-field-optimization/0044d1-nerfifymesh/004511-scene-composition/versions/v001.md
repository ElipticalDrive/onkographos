# Scene Composition
Also called: Composed iVR-GS

## Overview
Scene Composition is a method for assembling multiple independent radiance-field models (specifically NeRFifyMesh or iVR-GS representations) into a single unified global scene without retraining. It solves the problem of scalable scene building by allowing pre-converted mesh-based models to be placed in a global coordinate system or integrated with existing NeRF models. It differs from monolithic training approaches by treating each model as an independent, transformable primitive that is composited at render time via depth-based blending.

## How it works
**Inputs:**
- A set of $N$ pre-trained local radiance-field models (e.g., NeRFifyMesh or iVR-GS).
- For each model $i$, a pose transformation matrix $T_{wi} \in SE(3)$ defining its position and orientation in the global world frame.
- For iVR-GS models: quantized attribute data, including exact values for mean $\mu$ and normal $n$, shared codebook indices for other attributes, and a global palette color $c_p$.

**Outputs:**
- A single composed radiance field representation.
- Rendered 2D images with correct occlusion handling between models.

**Data Structures:**
- **Local Model Parameters:**
  - NeRFifyMesh: Implicit neural network weights and bias terms.
  - iVR-GS: Explicit Gaussian primitives. Each primitive stores:
    - $\mu$: Mean position (exact float values).
    - $n$: Normal direction (exact float values).
    - Other attributes: Indices into shared codebooks.
    - $c_p$: Global palette color for the scene.
- **Global Scene List:** A single parameter list formed by concatenating the decompressed attribute values of all primitives from all basic models.

**Steps:**
1. **Normalization:** Each individual NeRFifyMesh model is normalized to fit within a unit cube and defined in its own local coordinate frame [S2, unofficial].
2. **Storage (iVR-GS specific):** For editable iVR-GS models, save the exact values of $\mu$ and $n$, and indices with shared codebooks for other attributes for each editable Gaussian. Store palette color $c_p$ as a global parameter for each basic scene [S1].
3. **Ray Casting:** Cast rays from a virtual camera in the global world frame. The ray is defined as:
   $$r_w(t) = o_w + t\vec{d}_w$$
   where $o_w$ is the ray origin and $\vec{d}_w$ is the ray direction [S2, unofficial].
4. **Coordinate Transformation:** For each model $i$, transform the world-frame ray into the model's local coordinate frame using the inverse of the model's pose:
   $$r_i(t) = T^{-1}_{wi} r_w(t)$$
   where $T_{wi} \in SE(3)$ is the pose of model $i$ in the world frame [S2, unofficial].
5. **Local Evaluation:** Evaluate each local NeRF model using the transformed ray $r_i(t)$. Each model returns RGB color values and depth values for the ray [S2, unofficial].
6. **Decompression and Composition (iVR-GS specific):** Decompress each model from its quantized format. Append the attribute values of primitives from all basic iVR-GS models into a single parameter list to form the composed model [S1].
7. **Depth-Based Blending:** Composite the per-model renderings in the 2D image plane. For each pixel, sort the models by depth (distance from camera). Blend the RGB outputs from different models back-to-front using the corresponding depth values to resolve occlusions [S2, unofficial].

**Pseudocode:**
```python
def compose_and_render(models, camera_origin, camera_direction, world_to_local_transforms):
    """
    models: List of local radiance field models.
    camera_origin: 3D vector o_w.
    camera_direction: 3D vector d_w.
    world_to_local_transforms: List of SE(3) matrices T_wi for each model.
    """
    # Step 3: Cast ray in world frame
    ray_w_origin = camera_origin
    ray_w_dir = camera_direction
    
    # Step 4 & 5: Transform ray and evaluate each model
    model_results = []
    for i, model in enumerate(models):
        T_wi = world_to_local_transforms[i]
        
        # Transform ray to local frame
        # r_i(t) = T_wi^-1 * r_w(t)
        # Note: For ray origin and direction, we apply the inverse transform.
        # In homogeneous coordinates, this is a 4x4 matrix multiplication.
        local_origin = apply_transform(T_wi.inverse(), ray_w_origin)
        local_dir = apply_transform_rotation(T_wi.inverse(), ray_w_dir)
        
        # Evaluate local model
        rgb, depth = model.evaluate(local_origin, local_dir)
        model_results.append({
            'model_index': i,
            'rgb': rgb,
            'depth': depth,
            'transform': T_wi
        })
    
    # Step 7: Composite using depth-based ordering
    # Sort models by depth for the current ray/pixel
    # Note: In practice, this is done per-pixel or per-ray batch.
    # Here we assume a simplified single-ray scenario for clarity.
    sorted_results = sorted(model_results, key=lambda x: x['depth'], reverse=True) # Back-to-front
    
    final_rgb = [0.0, 0.0, 0.0]
    accumulated_alpha = 0.0
    
    for result in sorted_results:
        rgb = result['rgb']
        # Assuming standard alpha blending; depth is used for sorting
        # Alpha is typically derived from the radiance field or Gaussian opacity
        alpha = result.get('alpha', 1.0) # Placeholder for alpha extraction if not explicit
        
        # Back-to-front blending
        # C_out = C_in + C_new * alpha_new * (1 - alpha_in)
        final_rgb = final_rgb + rgb * alpha * (1 - accumulated_alpha)
        accumulated_alpha += alpha * (1 - accumulated_alpha)
        
        if accumulated_alpha > 0.99: # Early termination threshold
            break
            
    return final_rgb

def compose_ivrgs_models(basic_models):
    """
    Composes iVR-GS models by appending their decompressed primitives.
    """
    composed_primitives = []
    for model in basic_models:
        # Step 6: Decompress and append
        decompressed = model.decompress()
        composed_primitives.extend(decompressed.primitives)
    
    return ComposedModel(primitives=composed_primitives)
```

**Parameters:**
- $T_{wi}$: Pose matrix. Typical values depend on the scene layout.
- Depth threshold: Not given in the sources.
- Early termination threshold: Not given in the sources (used in pseudocode for efficiency).

**Edge Cases and Pitfalls:**
- **Occlusion:** Incorrect depth sorting leads to visual artifacts where models intersect incorrectly. Depth-based ordering is critical [S2, unofficial].
- **Coordinate Systems:** Failure to correctly invert $T_{wi}$ results in models appearing in wrong positions or orientations [S2, unofficial].
- **Quantization Loss (iVR-GS):** While VQ provides ~4x compression, decompression must be exact for $\mu$ and $n$ to maintain geometric fidelity [S1].
- **Boundary Artifacts:** Models normalized to a unit cube may have discontinuities at their boundaries if not handled by the underlying radiance field [S2, unofficial].

## Operating characteristics
- **Time Complexity:** Rendering time scales linearly with the number of models $N$ and the number of primitives per model. Each ray must be evaluated against all models (or a spatial partitioning structure if implemented) before blending.
- **Memory Complexity:** Memory usage is the sum of the memory required for all individual models. For iVR-GS, this includes the decompressed primitives and codebooks [S1].
- **Performance:** The composition pipeline itself is lightweight; the cost is dominated by the individual model evaluations. NeRFifyMesh models are noted for capturing interior features due to geometry-based sampling, which may be more expensive than visibility-limited NeRFs [S2, unofficial].
- **Strengths:** Enables real-time scene editing for iVR-GS by adjusting editable Gaussian attributes [S1]. Allows modular scene building without retraining [S2, unofficial].
- **Limitations:** Requires pre-computation/normalization of each model. Occlusion handling is simplified to depth-based blending, which may not account for complex inter-model lighting or shadows [S2, unofficial].

## Background
Scene Composition was introduced as part of the NeRFifyMesh pipeline [S2, unofficial] and the iVR-GS framework [S1]. NeRFifyMesh was developed to convert textured mesh models into NeRF representations for robotics scene building, addressing the need for scalable scene assembly [S2, unofficial]. iVR-GS extended this concept to editable 3D Gaussian Splatting, allowing for composability and real-time editing [S1]. The method builds on the idea of treating radiance fields as modular components rather than monolithic entities.
