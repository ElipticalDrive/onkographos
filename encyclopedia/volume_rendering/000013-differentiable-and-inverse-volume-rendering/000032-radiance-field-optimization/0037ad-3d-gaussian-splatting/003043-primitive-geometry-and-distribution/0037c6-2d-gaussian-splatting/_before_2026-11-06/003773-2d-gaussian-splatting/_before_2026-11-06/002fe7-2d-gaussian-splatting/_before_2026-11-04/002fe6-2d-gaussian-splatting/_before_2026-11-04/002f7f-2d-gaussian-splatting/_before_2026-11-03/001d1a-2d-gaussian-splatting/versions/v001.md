# 2D Gaussian Splatting

Also called: 2DGS

## Overview
2D Gaussian Splatting (2DGS) is a scene representation method that replaces the volumetric 3D Gaussians of [Gaussian Splatting](946-gaussian-splatting.md) with 2D disks to improve spatial localization and recover high-resolution normal maps [S1, unofficial]. It addresses the limitation of 3D Gaussians in surface reconstruction by enforcing a flattened geometry, enabling more accurate mesh extraction and view synthesis [S1, unofficial].

## How it works
2DGS represents the scene as a set of $M$ 2D disks. Unlike 3D Gaussians which have a full 3D covariance matrix, 2D Gaussians are constrained to be planar.

**Inputs:**
- Camera parameters (view and projection matrices).
- A set of $M$ 2D Gaussian primitives, each defined by:
  - Center position $\mathbf{p} \in \mathbb{R}^3$.
  - Orientation $\mathbf{q} \in \mathbb{R}^4$ (unit quaternion) or rotation matrix $\mathbf{R} \in \mathbb{R}^{3 \times 3}$.
  - Scale $\mathbf{s} \in \mathbb{R}^2$ (intrinsic to the 2D plane).
  - Opacity $\alpha \in [0, 1]$.
  - Color $\mathbf{c} \in \mathbb{R}^3$ (or spherical harmonics coefficients).

**Data Structures:**
- Each primitive stores its 2D covariance in the local plane. The 3D covariance $\Sigma$ is derived from the 2D scale and orientation, with the third dimension (normal direction) having zero variance.

**Steps:**
1. **Covariance Construction:** Construct the 3D covariance matrix $\Sigma$ for each 2D Gaussian. Let the local 2D covariance be $\Sigma_{2D} = \text{diag}(s_1^2, s_2^2)$. The 3D covariance is $\Sigma = \mathbf{R} \begin{bmatrix} \Sigma_{2D} & \mathbf{0} \\ \mathbf{0}^T & 0 \end{bmatrix} \mathbf{R}^T$, where $\mathbf{R}$ is the rotation matrix from the quaternion $\mathbf{q}$ [S1, unofficial]. This ensures the determinant is near zero, enforcing planarity.
2. **Projection:** Project the 3D covariance $\Sigma$ to 2D screen space using the Jacobian of the perspective projection matrix $\mathbf{W}$ and the view matrix $\mathbf{V}$. The projected covariance is $\Sigma' = \mathbf{J} \mathbf{W} \Sigma \mathbf{W}^T \mathbf{J}^T$, where $\mathbf{J}$ is the Jacobian of the affine approximation of the projection [S1, unofficial].
3. **Rasterization:** Rasterize the 2D Gaussians onto the image plane. Each pixel receives contributions from overlapping Gaussians based on their 2D density function.
4. **Alpha Compositing:** Compute the final color $\mathbf{C}$ and opacity $\alpha$ for each pixel using standard volume rendering equation:
   $$
   \mathbf{C} = \sum_{i \in N} \mathbf{c}_i \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j)
   $$
   where $N$ is the set of sorted Gaussians covering the pixel.

**Parameters:**
- Typical values for scale $\mathbf{s}$ are learned during optimization.
- Opacity $\alpha$ is initialized to a small value and learned.

**Edge Cases:**
- Degenerate Gaussians (zero area) should be pruned.
- Precision issues in covariance inversion for very thin Gaussians.

## Subtopics

### [Flattened Gaussian Ellipsoid Rendering](1667-flattened-gaussian-ellipsoid-rendering.md)
Approximates 2D Gaussian ellipses by flattening 3D Gaussian ellipsoids. It differs from 2DGS by operating within a differentiable volume rendering framework that natively supports anisotropic ellipsoidal kernels and enforces a near-zero determinant covariance.

### [3D Surface Splatting](4524-3d-surface-splatting.md)
A differentiable surface splatting renderer for physically-based inverse rendering. Unlike 2DGS, which retains a volumetric rendering model with learnable opacity, 3DSS uses a surface rendering model where pixel coverage arises from accumulated EWA reconstruction weights within depth-separated layers, and shading is evaluated at the sample level before blending.

## Operating characteristics
- **Time Complexity:** Linear in the number of Gaussians $M$ and pixels $P$, $O(M + P)$, similar to 3DGS, but with potentially fewer primitives needed for surface detail.
- **Memory Complexity:** $O(M)$, storing 2D parameters instead of 3D.
- **Strengths:** Improved spatial localization, better surface reconstruction, high-resolution normal maps.
- **Limitations:** May struggle with highly volumetric scenes where 3D extent is significant.
- **When to use:** When surface geometry and normals are critical, or for mesh extraction.
- **When not to use:** For scenes with significant volumetric effects (fog, smoke) where 3D extent is necessary.

## Background
2D Gaussian Splatting was introduced to address the limitations of 3D Gaussian Splatting in surface reconstruction. By flattening 3D Gaussians into 2D disks, it enables more accurate localization and recovery of high-resolution normal maps [S1, unofficial]. It builds on the differentiable rendering framework of Gaussian Splatting.
