# 3D Gaussian Splatting with BRDF Embedding
Also called: 3D Gaussian Splatting (3DGS), Gao et al. BRDF Embedding, Gao et al. BRDF Method
## Overview
This method extends standard 3D Gaussian Splatting by embedding physically based rendering parameters into each Gaussian primitive, enabling per-point BRDF evaluation rather than simple view-dependent color interpolation [S1][S2, unofficial]. It distinguishes itself from sibling methods like [3DGS-DR](1471-3dgs-dr.md) by explicitly storing incident lighting and roughness/albedo data per Gaussian, allowing for direct lighting reconstruction via environment maps and indirect lighting via spherical harmonics [S1][S2, unofficial].
## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of 3D Gaussians (initialized from standard 3DGS or SfM points), camera poses, and input images [G].
*   **Outputs:** A rendered image with physically based shading, including specular highlights and albedo-consistent diffuse reflection [G].

**Data Structures:**
Each Gaussian $i$ in the scene representation stores the following fields beyond standard position, covariance, opacity, and SH coefficients [S1][S2, unofficial]:
1.  **Albedo ($\alpha_i$):** A 3D vector representing the diffuse base color [S1][S2, unofficial].
2.  **Roughness ($\rho_i$):** A scalar value controlling the specular spread [S1][S2, unofficial].
3.  **Surface Normal ($\mathbf{n}_i$):** A 3D vector, typically derived from the Gaussian's orientation or optimized directly [S1][S2, unofficial].
4.  **Incident Lighting:** Represented either as an environment map lookup or spherical harmonic coefficients for indirect illumination [S1][S2, unofficial].

**Numbered Steps:**
1.  **Initialization:** Initialize Gaussians with standard 3DGS parameters [G]. Assign initial BRDF parameters: uniform albedo, default roughness (e.g., 0.5), and normals estimated from local geometry or random initialization [G].
2.  **Differentiable Rendering:** For each pixel, project the 3D Gaussians to 2D [G]. Compute the contribution of each Gaussian to the pixel color using the standard alpha-blending equation, but replace the view-dependent SH color with a PBR shading model [S1][S2, unofficial].
3.  **Shading Model:**
    *   **Direct Lighting:** Sample the environment map at the direction of the light source relative to the surface normal $\mathbf{n}_i$ [S1][S2, unofficial]. The direct radiance $L_{\text{dir}}$ is computed using a BRDF (e.g., Cook-Torrance) with albedo $\alpha_i$ and roughness $\rho_i$ [G].
    *   **Indirect Lighting:** Compute the ambient/indirect radiance $L_{\text{ind}}$ using the Gaussian's spherical harmonic coefficients, which now represent the irradiance at that point rather than view-dependent color [S1][S2, unofficial].
    *   **Composite Color:** The final color $C$ for a Gaussian is:
        $$ C = \alpha_i \cdot L_{\text{ind}} + f_r(\omega_i, \omega_o, \mathbf{n}_i, \rho_i) \cdot L_{\text{dir}}(\omega_i) $$
        Where $f_r$ is the BRDF, $\omega_i$ is the incident light direction, and $\omega_o$ is the view direction [G].
4.  **Optimization:** Minimize the photometric loss between the rendered image and the ground truth [G]. Gradients flow through the PBR shading model to update albedo, roughness, normals, and standard Gaussian parameters [G].
5.  **Secondary Rays (Optional):** To model interreflections, spawn secondary rays (reflections/refractions) upon primary ray interaction with Gaussians, tracing them through the scene [S1][S2, unofficial].

**Parameters:**
*   **Roughness:** Typically optimized in the range $[0.0, 1.0]$ [G].
*   **Environment Map:** High-dynamic-range (HDR) cubemap or spherical harmonics for direct lighting [S1][S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Normal Ambiguity:** Surface normals derived from Gaussian covariance may be noisy in textureless regions, leading to incorrect specular highlights [G].
*   **Lighting Estimation:** Accurate direct lighting requires a known environment map [G]. If not provided, indirect lighting via SH may fail to capture sharp specular features [G].
*   **Optimization Stability:** BRDF parameters can diverge if not regularized [G]. Roughness should be clamped to avoid singularities in the BRDF evaluation [G].

**Pseudocode:**
```python
def render_3dgs_brdf(gaussians, camera, env_map):
    screen_gaussians = []
    for g in gaussians:
        pos_cam = camera.view_matrix @ g.position
        proj_pos = camera.proj_matrix @ pos_cam
        screen_gaussians.append({
            'pos_2d': proj_pos[:2] / proj_pos[2],
            'cov2d': compute_2d_cov(g.cov3d, camera.proj_matrix, camera.view_matrix),
            'opacity': g.opacity,
            'albedo': g.albedo,
            'roughness': g.roughness,
            'normal': g.normal,
            'sh_coeffs': g.sh_coeffs
        })
    screen_gaussians.sort(key=lambda g: g['pos_2d'][2])
    image = np.zeros((camera.height, camera.width, 3))
    for g in screen_gaussians:
        pdf = compute_pdf(g['pos_2d'], g['cov2d'])
        opacity = g['opacity'] * pdf
        if opacity < 1e-4:
            continue
        reflection_dir = reflect(camera.view_direction, g['normal'])
        direct_radiance = sample_env(env_map, reflection_dir)
        brdf_val = cook_torrance(g['normal'], camera.view_direction, reflection_dir, g['roughness'])
        indirect_radiance = eval_sh(g['sh_coeffs'], g['normal'])
        color = g['albedo'] * indirect_radiance + brdf_val * direct_radiance
        image = alpha_blend(image, color, opacity)
    return image

def compute_2d_cov(cov3d, proj_mat, view_mat):
    T = view_mat[:3, :3]
    W = proj_mat[:2, :2]
    return W @ T @ cov3d @ T.T @ W.T

def compute_pdf(pos_2d, cov2d):
    diff = pos_2d - np.array([0.5, 0.5])
    inv_cov = np.linalg.inv(cov2d)
    return np.exp(-0.5 * diff.T @ inv_cov @ diff)

def sample_env(env_map, direction):
    return env_map.sample(direction)

def cook_torrance(normal, view_dir, light_dir, roughness):
    half_vec = normalize(view_dir + light_dir)
    return max(np.dot(normal, half_vec), 0.0) ** (roughness * 10)

def eval_sh(coeffs, normal):
    return np.sum(coeffs * sh_basis(normal))

def alpha_blend(image, color, opacity):
    return image * (1 - opacity) + color * opacity
```
## Subtopics

### [3DGS-DR](1471-3dgs-dr.md)
A method that incorporates classical reflection and shading concepts into the 3DGS framework.

### SWAG
A method that extends 3DGS by conditioning Gaussians on learned appearance embeddings and training unsupervised transient Gaussians to ignore occluders, yielding state-of-the-art results on diverse photo scenes by handling transient effects and distractors [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Rendering is comparable to standard 3DGS, but shading evaluation per Gaussian is more expensive due to BRDF and environment map sampling [G].
*   **Memory Complexity:** Higher than standard 3DGS due to the storage of albedo, roughness, and normal vectors per Gaussian [G].
*   **Strengths:** Physically plausible rendering, ability to relight scenes, and consistent appearance under varying lighting conditions [G].
*   **Limitations:** Requires HDR environment maps for direct lighting; optimization is more complex and prone to local minima; normal estimation can be unstable [G].
*   **When to Use:** When physically based rendering, relighting, or material estimation is required [G].
*   **When Not to Use:** When only view-dependent appearance is needed, or when computational resources are limited [G].
## Background
Originated from the work of Gao et al., who embedded BRDF parameters into 3D Gaussians to enable per-point physically based rendering [S1][S2, unofficial]. This approach builds on the foundational 3D Gaussian Splatting method and integrates concepts from classical computer graphics rendering pipelines [G].
