# 3D Gaussian Splatting Adaptive Density Control

Also called: Opacity-Gradient Pruning, Gaussian pruning, Opacity pruning, Opacity-Gradient Based Pruning, Post-densification pruning, Pruning Strategy

## Overview
This method refines the Gaussian primitive set by removing unstable or low-contribution primitives that remain after the densification phase described in [Density Control and Densification](5337-density-control-and-densification.md). It distinguishes itself from sibling methods by combining per-pixel opacity gradients with training loss to identify primitives that are sensitive to optimization (unstable) or contribute little to the final image (low-contribution), rather than relying solely on static opacity thresholds or gradient magnitudes [S1, unofficial].

## How it works
**Inputs:**
*   Set of 3D Gaussians $\mathcal{G} = \{g_i\}$, where each $g_i$ has position $\mathbf{p}_i$, covariance $\Sigma_i$, opacity $\alpha_i$, and spherical harmonics coefficients $\mathbf{c}_i$.
*   Training loss $L_t$ at iteration $t$.
*   Gradients of the loss with respect to the opacity of each Gaussian at each covered pixel, $\frac{\partial L(P)}{\partial \alpha(P)}$.
*   Parameters: $K$ (number of iterations for score accumulation), $\tau_{opacity}$ (minimum opacity threshold), $\tau_{PS}$ (pruning score threshold).

**Outputs:**
*   Pruned set of Gaussians $\mathcal{G}' \subset \mathcal{G}$.

**Data Structures:**
*   `PruningScore`: A scalar value accumulated over $K$ iterations for each Gaussian. Initialized to 0.
*   `Opacity`: The current opacity value $\alpha_i$ of each Gaussian.

**Steps:**

1.  **Pixel-wise Score Calculation:**
    During the backward pass, for each pixel $P$ covered by a Gaussian $g_i$, compute the pixel-wise score $r(P)$:
    $$
    r(P) = \frac{1}{\alpha(P)} \left| \frac{\partial L(P)}{\partial \alpha(P)} \right|
    $$
    where $\alpha(P)$ is the opacity contribution of the Gaussian at pixel $P$, and $\frac{\partial L(P)}{\partial \alpha(P)}$ is the gradient of the loss at pixel $P$ with respect to that opacity [S1, unofficial]. This metric targets unstable Gaussians: a primitive with low opacity but large gradient yields a high score, indicating sensitivity to optimization [S1, unofficial].

2.  **View-level Score Aggregation:**
    For each Gaussian $g_i$, aggregate the pixel-wise scores over the region $\Omega_i$ covered by the Gaussian in the current view to obtain the view-level score $R_i$:
    $$
    R_i = \sum_{P \in \Omega_i} r(P)
    $$
    [S1, unofficial]

3.  **Pruning Score Accumulation:**
    Maintain a cumulative Pruning Score (PS) for each Gaussian. Over $K$ consecutive iterations (or views), weight the view-level score by the training loss $L_t$ at iteration $t$ and accumulate:
    $$
    PS_i = \frac{1}{K} \sum_{t=1}^K L_t \cdot R_{i,t}
    $$
    where $R_{i,t}$ is the view-level score for Gaussian $i$ at iteration $t$. Weighting by training loss prevents Gaussians in well-reconstructed regions from being penalized for moderate instability [S1, unofficial].

4.  **Pruning Decision:**
    Periodically (after densification steps), evaluate each Gaussian $g_i$:
    *   If $PS_i > \tau_{PS}$, mark $g_i$ for removal (unstable).
    *   If $\alpha_i < \tau_{opacity}$, mark $g_i$ for removal (low-contribution) [S1, unofficial].

5.  **Removal:**
    Remove all marked Gaussians from the set $\mathcal{G}$ [S1, unofficial].

**Pseudocode:**

```python
def compute_pruning_scores(gaussians, gradients, losses, K):
    """
    Computes the Pruning Score (PS) for each Gaussian over K iterations.
    
    Args:
        gaussians: List of Gaussian objects, each with attributes:
                   - covered_pixels: List of pixel indices P covered by this Gaussian.
                   - alpha(P): Function returning opacity at pixel P.
        gradients: List of tensors, where gradients[t][P] is dL/d_alpha(P) at iteration t.
        losses: List of scalar loss values L_t for each iteration t.
        K: Number of iterations to accumulate scores.
        
    Returns:
        ps_scores: Dictionary mapping Gaussian index to its accumulated Pruning Score.
    """
    ps_scores = {i: 0.0 for i in range(len(gaussians))}
    
    # Accumulate scores over K iterations
    for t in range(K):
        L_t = losses[t]
        for i, g in enumerate(gaussians):
            R_i = 0.0
            for P in g.covered_pixels:
                alpha_P = g.alpha(P)
                # Avoid division by zero; if alpha is effectively 0, gradient should also be negligible
                if alpha_P > 1e-6:
                    grad_P = gradients[t][P]
                    r_P = (1.0 / alpha_P) * abs(grad_P)
                    R_i += r_P
            
            # Weight by training loss and add to cumulative score
            ps_scores[i] += L_t * R_i
            
    # Average over K iterations
    for i in ps_scores:
        ps_scores[i] /= K
        
    return ps_scores

def prune_gaussians(gaussians, ps_scores, tau_opacity, tau_ps):
    """
    Removes Gaussians based on Pruning Score and Opacity thresholds.
    
    Args:
        gaussians: List of Gaussian objects.
        ps_scores: Dictionary mapping Gaussian index to Pruning Score.
        tau_opacity: Minimum opacity threshold.
        tau_ps: Pruning Score threshold.
        
    Returns:
        pruned_gaussians: List of Gaussians that survived pruning.
    """
    pruned_gaussians = []
    for i, g in enumerate(gaussians):
        # Check opacity threshold
        if g.alpha > tau_opacity:
            # Check Pruning Score threshold
            if ps_scores[i] <= tau_ps:
                pruned_gaussians.append(g)
    return pruned_gaussians
```

**Parameters:**
*   $K$: Number of iterations over which pruning scores are accumulated. Not given in the sources.
*   $\tau_{PS}$: Pruning score threshold. Not given in the sources.
*   $\tau_{opacity}$: Minimum opacity threshold. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Pruning Frequency:** If pruning is performed too infrequently (e.g., interval 1000, first prune at 16,000 iterations), it may remove Gaussians that are still useful, causing a drop in rendering quality [S1, unofficial]. If pruning is too frequent (e.g., interval 5000), the number of Gaussians (NGS) may become highest because Gaussians stabilize or become highly contributory, causing the strategy to remove fewer Gaussians [S1, unofficial].
*   **Zero Opacity:** Division by $\alpha(P)$ in $r(P)$ requires handling cases where opacity is near zero. [G] In practice, a small epsilon is added to the denominator or gradients are ignored if opacity is below a tiny threshold.

## Subtopics

### Visibility-Based Pruning
Removes surfels that were never reached during the backward pass due to persistent occlusion, being outside camera frustums, or failing the kernel cutoff test at every pixel [S2, unofficial]. At the end of each training epoch, surfels whose cumulative screen-space gradient magnitude across all views is zero are removed [S2, unofficial]. This is a simpler criterion than opacity-gradient pruning, relying on the absence of any gradient signal rather than the ratio of gradient to opacity [S2, unofficial].

### Coverage-Aware Pruning
Replaces base-opacity pruning score with maximum opacity across all training presets to ensure primitives needed by any preset survive [S3, unofficial]. A primitive survives if its maximum opacity $\kappa_i = \max_{T \in T_{train}} \bar{\alpha}_i(T)$ exceeds the pruning threshold under any training preset [S3, unofficial]. The score excludes camera-dependent attenuation $s_i^{view}$; standard geometric and screen-size pruning criteria remain active [S3, unofficial].

### Pruning Frequency
The iteration interval at which the pruning strategy is applied. Most frequencies have little effect on pruning, but extreme values impact NGS and rendering quality [S1, unofficial]. A larger number of Gaussians is removed only during the first pruning; subsequent prunings remove only a small number of Gaussians [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The pruning step itself is $O(N)$ per pruning event, where $N$ is the number of Gaussians, as it involves iterating over the Gaussian set and checking thresholds. However, the accumulation of scores requires maintaining state over $K$ iterations, adding memory overhead.
*   **Memory Complexity:** Requires storing the Pruning Score for each Gaussian, adding $O(N)$ memory.
*   **Measured Performance:** On the bicycle scene from Mip-NeRF 360, pruning reduced the number of Gaussians from 947,135 (Base) to 744,225, with training time increasing slightly to 211.7 seconds (from unspecified Base time), while maintaining SSIM at 0.751 and PSNR at 25.142 (vs 25.153 Base) [S1, unofficial]. On Mip-NeRF 360, pruning reduces NGS from 0.77M to 0.63M and training time from 245.7s to 233.7s compared to Base [S1, unofficial].
*   **Strengths:** Reduces the number of Gaussians and training time while maintaining competitive rendering quality [S1, unofficial]. It effectively targets redundant and unstable primitives [S1, unofficial].
*   **Limitations:** Requires careful tuning of pruning frequency and thresholds to avoid quality drops [S1, unofficial]. The accumulation of scores over $K$ iterations adds complexity to the training loop.

## Background
This method was introduced in "Loss-Guided Density Control and Efficient Backward Optimisation for Compact Gaussian Splatting" [S1, unofficial]. It builds upon the standard 3D Gaussian Splatting densification process by adding a post-densification pruning step that uses opacity gradients and training loss to guide the removal of primitives [S1, unofficial].
