# Steerable Densification with Sampling

Also called: Score-based ranking densification

## Overview
Steerable Densification with Sampling is a density control method for 3D Gaussian Splatting that uses a score-based ranking of Gaussians to select candidates for resampling, guided by image loss and per-Gaussian attributes [S1]. It sets itself apart from standard 3DGS densification by incorporating explicit photometric loss and saliency metrics into the selection probability, executed at a significantly reduced frequency (every 500 iterations) to prevent the duplication of misplaced primitives [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Set of $N$ training views $V=\{v_i\}_{i=1}^N$, set of $M$ Gaussians $G=\{g_j\}_{j=1}^M$, rendered views $R=\{r_i\}_{i=1}^N$, current loss maps, and hyperparameters $\lambda_1, \lambda_2$ and scoring weights.
*   **Outputs:** A set of $B$ new Gaussians generated by resampling existing ones based on computed scores.

**Data Structures:**
*   **Saliency Matrix $S_v$:** A 2D matrix of size $width \times height$ for each view $v$. Elements are floating-point values representing pixel-level saliency.
*   **Score Vector $S_G$:** A 1D vector of size $M$. $S_{g_j}$ is the scalar score for Gaussian $g_j$.

**Parameters:**
*   **Densification Frequency:** Every 500 iterations (one-fifth of the standard 3DGS frequency) [S1].
*   **Number of Views for Saliency ($N$):** 10 uniformly sampled training views [S1].
*   **Saliency Weights:** $\lambda_1 = 0.5$ (L1 loss), $\lambda_2 = 0.5$ (Laplacian) [S1].
*   **Scoring Function Weights:** $\nabla_g: 50$, $c_{gi}: 0.1$, $D_{gi}: 50$, $S_{vi}: 10$, $B_{gi}: 50$, $z_{gi}: 5$, $o_g: 100$, $s_g: 25$ [S1].
*   **Budget ($B$):** The target number of Gaussians to add per densification step [S1].

**Steps:**

1.  **Compute Per-View Saliency Matrices:**
    For each of the $N$ selected views $v$, compute the saliency matrix $S_v$ using the formula [S1]:
    $$
    S_v = \mathbb{1}_{ROI} \odot (\lambda_1 L_1(v, r_v) + \lambda_2 E(v))
    $$
    Where:
    *   $\mathbb{1}_{ROI}$ is a binary mask (0 or 1) indicating regions of interest.
    *   $L_1(v, r_v)$ is the pixel-wise L1 loss between the rendered view $r_v$ and the ground truth.
    *   $E(v)$ is the Laplacian filter applied to the rendered view $r_v$ to detect high-frequency details.
    *   $\odot$ denotes element-wise multiplication.

2.  **Compute Gaussian Scores ($S_G$):**
    For each Gaussian $g_j \in G$, compute a global score $S_{g_j}$ by summing a scoring function $F$ over all $N$ views [S1]:
    $$
    S_{g_j} = \sum_{i=1}^{N} F(\nabla_{g_j}, c_{g_j,i}, \mathbb{1}_{g_j,i}, D_{g_j,i}, S_{v_i}, B_{g_j,i}, z_{g_j,i}, o_{g_j}, s_{g_j})
    $$
    The scoring function $F$ aggregates the following attributes for Gaussian $g_j$ in view $i$:
    *   $\nabla_{g_j}$: Magnitude of the positional gradient of the Gaussian [S1].
    *   $c_{g_j,i}$: Number of pixels covered by $g_j$ in view $i$ [S1].
    *   $\mathbb{1}_{g_j,i}$: Binary matrix indicating which pixels are covered by $g_j$ in view $i$ [S1].
    *   $D_{g_j,i}$: Matrix of distances from each covered pixel to the center of $g_j$ in view $i$ [S1].
    *   $S_{v_i}$: The saliency value from the matrix $S_{v_i}$ at the corresponding pixel location [S1].
    *   $B_{g_j,i}$: Blending weight of $g_j$ for each covered pixel in view $i$ [S1].
    *   $z_{g_j,i}$: Depth of the Gaussian in view $i$ [S1].
    *   $o_{g_j}$: Opacity of the Gaussian [S1].
    *   $s_{g_j}$: Scale of the Gaussian [S1].

    **Scoring Function Implementation:**
    The function $F$ processes each parameter by first applying median scaling to remove outliers, then multiplying by the photometric loss (L1) for that view, and finally accumulating into a weighted sum [S1]. Specifically, for a parameter $p$, the contribution is weighted by $w_p$ [S1]:
    $$
    \text{Contribution} = w_p \cdot \text{MedianScale}(p) \cdot L_1(v_i, r_{v_i})
    $$
    The weights $w_p$ are: $\nabla_g=50, c_{gi}=0.1, D_{gi}=50, S_{vi}=10, B_{gi}=50, z_{gi}=5, o_g=100, s_g=25$ [S1].

3.  **Resampling:**
    Using the score vector $S_G$ as sampling weights, randomly resample $B$ primitives from the existing set of $M$ Gaussians to create new Gaussians [S1]. The probability of selecting Gaussian $g_j$ is proportional to $S_{g_j}$ [S1].

## Operating characteristics
*   **Time Complexity:** Adds an extra $O(N \times \text{width} \times \text{height})$ step for computing all $N$ saliency matrices $S_v$, plus an auxiliary rendering pass to obtain $S_G$ [S1].
*   **Memory Complexity:** Requires storing $N$ saliency matrices of size $\text{width} \times \text{height}$ and the score vector $S_G$ of size $M$ [S1].
*   **Strengths:** Interpretable and steerable; incorporates explicit loss guidance to target undersampled regions; reduced frequency prevents duplication of misplaced Gaussians [S1].
*   **Limitations:** Higher computational overhead per densification step due to saliency computation and auxiliary rendering; requires careful tuning of scoring weights [S1].
*   **When to use:** When high-quality radiance fields are needed with limited resources and interpretability of densification decisions is important [S1].
*   **When not to use:** When real-time performance is critical and the overhead of saliency computation is prohibitive [S1].

## Background
Originated in the paper "Taming 3DGS: High-Quality Radiance Fields with Limited Resources" [S1]. The method addresses the issue that standard 3DGS densification can lead to wasteful behavior and superfluous Gaussians if driven solely by gradient magnitude [S1]. By incorporating image loss and saliency, it aims to converge to the final scene with fewer primitives [S1].
