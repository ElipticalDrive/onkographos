# Gaussian Data Packing

Also called: GaussianData::pack

## Overview
Gaussian Data Packing is a method for serializing 3D Gaussian Splat attributes into a compact, fixed-width binary buffer to facilitate efficient GPU-side access during rasterization. It solves the problem of transferring large sets of Gaussian parameters from CPU memory to the GPU by packing 8-byte chunks of Gaussian data into a structured format. It differs from sibling methods like [SPZ Packed Format](3926-spz-packed-format.md) by using a specific interleaved texture-friendly layout with a fixed width of 8 uint32_t per Gaussian, whereas [PNG-based Gaussian Compression](4834-png-based-gaussian-compression.md) uses lossy image compression.

## How it works
**Inputs:** A set of $N$ 3D Gaussians, each defined by:
- Position: $\mathbf{p} = (x, y, z)$
- Scale: $\mathbf{s} = (s_x, s_y, s_z)$
- Rotation: Quaternion $\mathbf{q} = (w, x, y, z)$
- Color: $\mathbf{c} = (r, g, b, a)$ where components are in $[0, 1]$.

**Outputs:**
- `packedData`: A `std::vector<uint32_t>` of size $N \times 8$. It stores two `uvec4` per Gaussian.
- `worldPositions`: A `std::vector<float>` of size $N \times 3$, storing raw float positions.

**Data Structures:**
The `packedData` buffer is organized such that for the $i$-th Gaussian ($0 \le i < N$), the 8 `uint32_t` values are:
1. `packedData[i*8+0]`: Bit-reinterpretation of $x$.
2. `packedData[i*8+1]`: Bit-reinterpretation of $y$.
3. `packedData[i*8+2]`: Bit-reinterpretation of $z$.
4. `packedData[i*8+3]`: Selection flag (always 0).
5. `packedData[i*8+4]`: Packed half-precision floats for $\sigma_{xx}$ and $\sigma_{xy}$.
6. `packedData[i*8+5]`: Packed half-precision floats for $\sigma_{xz}$ and $\sigma_{yy}$.
7. `packedData[i*8+6]`: Packed half-precision floats for $\sigma_{yz}$ and $\sigma_{zz}$.
8. `packedData[i*8+7]`: Packed RGBA color (8 bits per channel).

**Steps:**
1. Initialize `packedData` with size $8N$ and `worldPositions` with size $3N$.
2. Loop over each Gaussian $i$ from $0$ to $N-1$:
    a. Extract position $\mathbf{p}$, scale $\mathbf{s}$, rotation $\mathbf{q}$, and color $\mathbf{c}$.
    b. Store raw position components in `worldPositions`:
       $$ \text{worldPositions}[3i] = x, \quad \text{worldPositions}[3i+1] = y, \quad \text{worldPositions}[3i+2] = z $$
    c. Reinterpret the float bits of $x, y, z$ as `uint32_t` using `std::memcpy` (or equivalent bit-cast) and store in `packedData[i*8+0]`, `packedData[i*8+1]`, `packedData[i*8+2]`.
    d. Set `packedData[i*8+3] = 0` as a selection flag.
    e. Convert rotation $\mathbf{q}$ to a $3 \times 3$ rotation matrix $\mathbf{R}$ using $\mathbf{R} = \text{mat3\_cast}(\mathbf{q})$.
    f. Create a diagonal scale matrix $\mathbf{S} = \text{diag}(s_x, s_y, s_z)$.
    g. Compute the transformation matrix $\mathbf{M} = \mathbf{R} \mathbf{S}$.
    h. Compute the symmetric 3D covariance matrix elements $\sigma_{jk}$ from $\mathbf{M}$:
       $$ \sigma_{xx} = M_{00}^2 + M_{10}^2 + M_{20}^2 $$
       $$ \sigma_{xy} = M_{00}M_{01} + M_{10}M_{11} + M_{20}M_{21} $$
       $$ \sigma_{xz} = M_{00}M_{02} + M_{10}M_{12} + M_{20}M_{22} $$
       $$ \sigma_{yy} = M_{01}^2 + M_{11}^2 + M_{21}^2 $$
       $$ \sigma_{yz} = M_{01}M_{02} + M_{11}M_{12} + M_{21}M_{22} $$
       $$ \sigma_{zz} = M_{02}^2 + M_{12}^2 + M_{22}^2 $$
    i. Pack $\sigma_{xx}$ and $\sigma_{xy}$ into `packedData[i*8+4]` using `packHalf2x16`.
    j. Pack $\sigma_{xz}$ and $\sigma_{yy}$ into `packedData[i*8+5]` using `packHalf2x16`.
    k. Pack $\sigma_{yz}$ and $\sigma_{zz}$ into `packedData[i*8+6]` using `packHalf2x16`.
    l. Pack color $\mathbf{c}$ into a single `uint32_t`:
       $$ \text{packedColor} = (r \ll 0) \mid (g \ll 8) \mid (b \ll 16) \mid (a \ll 24) $$
       Store in `packedData[i*8+7]`.

def gaussian_data_packing(gaussians: list) -> tuple:
    """
    Pack Gaussian data into the specified format.
    
    Args:
        gaussians: List of dicts with keys 'pos' (x,y,z), 'scale' (x,y,z), 
                   'rot' (w,x,y,z), 'color' (r,g,b,a).
    
    Returns:
        packed_data: List of uint32_t
        world_positions: List of float

    n = len(gaussians)
    packed_data = [0] * (n * 8)
    world_positions = [0.0] * (n * 3)
    
    for i in range(n):

        x, y, z = g['pos']
        sx, sy, sz = g['scale']
        w, qx, qy, qz = g['rot']
        r, g_c, b, a = g['color']
        
        # Store raw positions
        world_positions[3*i] = x
        world_positions[3*i+1] = y
        world_positions[3*i+2] = z
        
        # Reinterpret position as uint32
        packed_data[8*i] = float_to_uint32(x)
        packed_data[8*i+1] = float_to_uint32(y)
        packed_data[8*i+2] = float_to_uint32(z)
        
        # Selection flag
        packed_data[8*i+3] = 0

        # Convert quaternion to rotation matrix R
        R = quaternion_to_matrix(w, qx, qy, qz)
        
        # Scale matrix S
        S = np.diag([sx, sy, sz])
        
        # M = R * S
        M = np.dot(R, S)
        
        # Compute sigma elements
        sigma_xx = M[0,0]**2 + M[1,0]**2 + M[2,0]**2
        sigma_xy = M[0,0]*M[0,1] + M[1,0]*M[1,1] + M[2,0]*M[2,1]
        sigma_xz = M[0,0]*M[0,2] + M[1,0]*M[1,2] + M[2,0]*M[2,2]
        sigma_yy = M[0,1]**2 + M[1,1]**2 + M[2,1]**2
        sigma_yz = M[0,1]*M[0,2] + M[1,1]*M[1,2] + M[2,1]*M[2,2]
        sigma_zz = M[0,2]**2 + M[1,2]**2 + M[2,2]**2
        
        # Pack covariance
        packed_data[8*i+4] = pack_half2x16(sigma_xx, sigma_xy)
        packed_data[8*i+5] = pack_half2x16(sigma_xz, sigma_yy)
        packed_data[8*i+6] = pack_half2x16(sigma_yz, sigma_zz)
        
        # Pack color
        packed_color = (int(r * 255) & 0xFF) | \
                       ((int(g_c * 255) & 0xFF) << 8) | \
                       ((int(b * 255) & 0xFF) << 16) | \
                       ((int(a * 255) & 0xFF) << 24)
        packed_data[8*i+7] = packed_color
        
    return packed_data, world_positions

def float_to_uint32(f: float) -> int:
    """Reinterpret float bits as uint32."""
    return struct.unpack('I', struct.pack('f', f))[0]

**Edge Cases and Pitfalls:**
- **Precision:** The covariance matrix elements are stored as half-precision floats. This may lead to precision loss for very large or very small covariance values. [G] Ensure that the half-precision conversion handles denormals and infinities appropriately if such values are possible in the input.
- **Color Range:** The color components are assumed to be in $[0, 1]$. If they are outside this range, they should be clamped before packing.
- **Quaternion Normalization:** The input quaternion should be normalized before converting to a rotation matrix to ensure valid rotation.

## Subtopics

### [Gaussian Splat Texture Packing](3283-gaussian-splat-texture-packing.md)
Gaussian Splat Texture Packing is a method for storing 3D Gaussian Splat attributes in a 2D OpenGL texture to facilitate efficient GPU-side access during rasterization. It solves the problem of transferring large sets of Gaussian parameters from CPU memory to the GPU by packing 8-byte chunks of Gaussian data into a `GL_RGBA32UI` texture. It differs from sibling methods like [SPZ Packed Format](3926-spz-packed-format.md) by using a specific row-major texture layout with a fixed width of 1024 Gaussians per row, whereas [PNG-based Gaussian Compression](4834-png-based-gaussian-compression.md) uses lossy image compression.

### [SPZ Packed Format](3926-spz-packed-format.md)
SPZ Packed Format is a binary storage format for 3D Gaussian splats designed for low-precision, non-interleaved memory layouts with ZSTD compression support. It solves the problem of efficient serialization and transmission of large-scale Gaussian datasets by separating attributes into parallel buffers, allowing for optimized entropy coding (e.g., g-zipping) and variable spherical harmonics (SH) degrees up to 4. It is distinguished from interleaved formats by its parallel vector storage and from PNG-based compression by its native binary structure and ZSTD integration.

### [SPZ Packed Gaussian Unpacking](3927-spz-packed-gaussian-unpacking.md)
SPZ Packed Gaussian Unpacking decodes compressed Gaussian Splat attributes (positions, scales, rotations, alphas, colors, and spherical harmonics) from the SPZ file format into floating-point arrays, handling coordinate system conversion and quantization inversion. It differs from sibling methods like PNG-based compression by using a binary layout with ZSTD compression (v4) or gzip (v1-3) and specific fixed-point/quantized encodings for each attribute type.

### [PNG-based Gaussian Compression](4834-png-based-gaussian-compression.md)
A compression technique for trained 3D Gaussian splats that quantizes parameters to 8-bit or 16-bit and stores them as lossless PNG images, optionally using spatial sorting (Morton code) to improve compression ratios. It serves as a port of the PyTorch `gsplat` compression module to MLX. It achieves approximately 10x compression on standard 3DGS models. Unlike the PyTorch upstream which uses `torchpq` for k-means clustering of higher-order spherical harmonics, this method falls back to NPZ for higher-order bands due to library availability constraints.

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the number of Gaussians. Each Gaussian is processed in constant time.
- **Memory Complexity:** $O(N)$ for `packedData` ($8N$ uint32_t) and `worldPositions` ($3N$ float).
- **Measured Performance:** Not given in the sources.
- **Scaling:** Linear scaling with the number of Gaussians.
- **Strengths:** Compact representation, efficient GPU access, simple structure.
- **Limitations:** Loss of precision in covariance storage, fixed color range.
- **When to use:** When efficient GPU-side access to Gaussian parameters is required.
- **When not to use:** When high precision in covariance is critical or when compression is needed.
