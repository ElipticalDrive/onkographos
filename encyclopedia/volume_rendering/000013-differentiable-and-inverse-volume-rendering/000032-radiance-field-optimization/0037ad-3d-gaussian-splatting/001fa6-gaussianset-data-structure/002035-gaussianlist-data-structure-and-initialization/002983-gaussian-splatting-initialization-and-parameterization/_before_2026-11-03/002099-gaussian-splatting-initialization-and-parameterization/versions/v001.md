# Gaussian Splatting Initialization and Parameterization

Also called: 3D Gaussian Initialization, 3D Gaussian Splatting Training Initialization, Gaussian Initialization, Gaussian Parameter Initialization, Gaussians class init, Model Setup, pre-activation parameter setup

## Overview
This method establishes the initial state of the learnable 3D Gaussian point cloud for differentiable rendering training. It solves the problem of converting raw geometric data (typically from Structure-from-Motion pipelines like COLMAP) or random noise into a set of valid, differentiable parameters (means, covariances, opacities, and spherical harmonics) that can be optimized via gradient descent. It is distinguished from sibling methods like [LinPrim Population Control](2295-linprim-population-control.md) by focusing exclusively on the *creation* and *parameterization* of the initial set, rather than the dynamic modification of that set during training.

## How it works
The method initializes a set of $N$ 3D Gaussians. The parameters are stored as learnable tensors (typically `nn.Parameter` in PyTorch) on the GPU. The core challenge is ensuring that non-linear activation functions (sigmoid for opacity, exponential for scale) produce valid ranges immediately upon initialization, and that the covariance matrices are well-conditioned.

### Inputs and Outputs
**Inputs:**
- Source point cloud data: Typically a COLMAP `.ply` or `.bin` file containing $N$ points with coordinates $\mathbf{xyz} \in \mathbb{R}^3$ and RGB colors $\mathbf{c} \in [0, 1]^3$. [S2, S3, unofficial]
- Alternatively, a random distribution if no source data is provided. [S2, unofficial]
- Configuration flags: `isotropic` (boolean, default false), `load_path` (string). [S2, unofficial]

**Outputs:**
- A Gaussian object containing the following learnable parameters:
  - $\mathbf{\mu}$ (means): Shape $(N, 3)$. [S3, unofficial]
  - $\mathbf{s}$ (pre-activation scales): Shape $(N, 3)$ or $(N, 1)$ if isotropic. [S3, unofficial]
  - $\mathbf{q}$ (pre-activation rotations): Shape $(N, 4)$, stored as quaternions $[w, x, y, z]$. [S3, unofficial]
  - $\alpha_{logit}$ (pre-activation opacity): Shape $(N,)$. [S3, unofficial]
  - $\mathbf{f}_{dc}$ (DC spherical harmonics coefficients): Shape $(N, 1, 3)$. [S3, unofficial]
  - $\mathbf{f}_{rest}$ (rest spherical harmonics coefficients): Shape $(N, D, 3)$, initialized to zero. [S1, unofficial]

### Data Structures
The parameters are stored as dense tensors.
- **Means**: `float32`, shape $(N, 3)$. [S3, unofficial]
- **Scaling**: `float32`, shape $(N, 3)$. [S3, unofficial]
- **Rotation**: `float32`, shape $(N, 4)$. [S3, unofficial]
- **Opacity**: `float32`, shape $(N,)$. [S3, unofficial]
- **Features DC**: `float32`, shape $(N, 1, 3)$. [S3, unofficial]
- **Features Rest**: `float32`, shape $(N, \text{num_coeffs}, 3)$. [S1, unofficial]

### Steps

1. **Initialize Means ($\mathbf{\mu}$)**
   Copy the XYZ coordinates from the input point cloud directly to the GPU tensor. [S1, S3, unofficial]
   If the input is random, sample from a uniform or normal distribution within the scene bounds. [S2, unofficial]

2. **Initialize Rotations ($\mathbf{q}$)**
   Initialize all quaternions to the identity rotation $[1, 0, 0, 0]$. [S2, S3, unofficial]
   *Note:* Some implementations use random uniform quaternions generated via the Shoemake method [S1, unofficial], but the standard initialization for stable training often starts with identity to avoid initial orientation jitter, or uses random if the scene geometry is sparse. [S1, S3, unofficial]

3. **Initialize Scales ($\mathbf{s}$)**
   The scales are stored as pre-activation values (log-space) to allow the exponential activation during rendering to produce positive scales.
   
   **Method A (KNN-based, Standard):**
   1. Compute the distance to the $k$-nearest neighbors (typically $k=50$) for each point in the input cloud. [S2, unofficial]
   2. Calculate the mean distance $d_i$ for each point $i$. [S2, unofficial]
   3. Clamp $d_i$ to a minimum value (e.g., $10^{-7}$). [S3, unofficial]
   4. Set the pre-activation scale: $s_i = \log(\sqrt{d_i})$. [S3, unofficial]
   5. Replicate this value across the 3 dimensions (x, y, z) for isotropic scaling, or keep separate if anisotropic. [S2, S3, unofficial]
   
   **Method B (Fixed Base):**
   1. Use a fixed base distance $d_{base} = 0.1$. [S3, unofficial]
   2. Set $s_i = \log(\sqrt{d_{base}})$ for all $i$. [S3, unofficial]

4. **Initialize Opacity ($\alpha_{logit}$)**
   Opacity is stored as a logit (pre-activation value) so that $\alpha = \sigma(\alpha_{logit})$.
   1. Choose a target initial opacity $\alpha_{target}$. Common values are $0.1$ [S1, unofficial] or $0.5$ [S3, unofficial].
   2. Clamp $\alpha_{target}$ to a safe range, e.g., $[10^{-4}, 0.99]$, to prevent extreme logit values. [S3, unofficial]
   3. Compute the logit: $\alpha_{logit} = \ln\left(\frac{\alpha_{target}}{1 - \alpha_{target}}\right)$. [S1, S3, unofficial]
   4. *Alternative:* Some implementations initialize $\alpha_{logit}$ to a constant high value like $8.0$, which yields $\sigma(8.0) \approx 0.9997$. [S2, unofficial]

5. **Initialize Spherical Harmonics ($\mathbf{f}_{dc}, \mathbf{f}_{rest}$)**
   1. Normalize input RGB colors to the range $[-0.5, 0.5]$. [S1, unofficial]
   2. Compute the DC coefficient (degree 0) by dividing the normalized RGB by the SH basis constant $C_0 = 0.28209479177387814$. [S1, unofficial]
      $$ \mathbf{f}_{dc} = \frac{\mathbf{c}_{norm}}{C_0} $$
   3. Initialize all higher-order coefficients ($\mathbf{f}_{rest}$) to zero. [S1, unofficial]

6. **Construct Covariance Matrices (Runtime/Forward Pass)**
   While not stored directly, the covariance is derived from $\mathbf{s}$ and $\mathbf{q}$ for rendering.
   1. Create diagonal scaling matrix $\mathbf{S} = \text{diag}(\exp(\mathbf{s}))$. [S3, unofficial]
   2. Normalize quaternion $\mathbf{q}$ to unit length. [S3, unofficial]
   3. Convert $\mathbf{q}$ to rotation matrix $\mathbf{R}$ (shape $N \times 3 \times 3$). [S3, unofficial]
   4. Compute 3D covariance: $\Sigma = \mathbf{R} \mathbf{S} \mathbf{S}^T \mathbf{R}^T$. [S3, unofficial]

### Pseudocode

```python
import torch
import numpy as np

def initialize_gaussians(points_xyz, points_rgb, num_sh_coeffs=0, isotropic=False):
    """
    Initialize 3D Gaussian parameters from a point cloud.
    
    Args:
        points_xyz: (N, 3) array of XYZ coordinates.
        points_rgb: (N, 3) array of RGB colors in [0, 1].
        num_sh_coeffs: Number of higher-order SH coefficients (excluding DC).
        isotropic: If True, scales are shared across x, y, z.
        
    Returns:
        A dictionary of initialized learnable parameters.
    """
    N = points_xyz.shape[0]
    device = torch.device("cuda")
    
    # 1. Means
    means = torch.tensor(points_xyz, dtype=torch.float32, device=device, requires_grad=True)
    
    # 2. Rotations (Identity)
    # Quaternion format: [w, x, y, z]
    rotations = torch.zeros((N, 4), dtype=torch.float32, device=device, requires_grad=True)
    rotations[:, 0] = 1.0  # w = 1
    
    # 3. Scales (Pre-activation)
    # Compute KNN distances (simplified here as mean distance to all points for demo)
    # In practice, use a KD-tree for efficiency.
    # dists: (N,)
    # For this example, we use a fixed base distance if KNN is not implemented.
    base_dist = 0.1
    # If using KNN:
    # dists = compute_knn_mean_distance(points_xyz, k=50)
    # dists = torch.clamp(dists, min=1e-7)
    # scales_pre = torch.log(torch.sqrt(dists))
    
    # Using fixed base distance as per [S3, unofficial]
    scales_pre = torch.full((N, 3), np.log(np.sqrt(base_dist)), dtype=torch.float32, device=device, requires_grad=True)
    
    if isotropic:
        # Repeat the single scale value across 3 dimensions
        # scales_pre is already (N, 3) with identical values per row
        pass
    else:
        # If anisotropic, ensure 3 distinct values per point
        pass

    # 4. Opacity (Pre-activation logit)
    # Target opacity 0.1, clamped to [1e-4, 0.99]
    alpha_target = 0.1
    alpha_target = torch.clamp(torch.tensor(alpha_target), min=1e-4, max=0.99)
    opacity_logit = torch.logit(alpha_target).expand(N).to(device, requires_grad=True)
    
    # 5. Spherical Harmonics
    # Normalize RGB to [-0.5, 0.5]
    rgb_norm = (torch.tensor(points_rgb, dtype=torch.float32, device=device) - 0.5)
    
    C0 = 0.28209479177387814
    features_dc = rgb_norm / C0  # (N, 3) -> reshape to (N, 1, 3)
    features_dc = features_dc.unsqueeze(1)
    features_dc.requires_grad = True
    
    # Rest coefficients (zeros)
    # Shape: (N, num_sh_coeffs, 3)
    features_rest = torch.zeros((N, num_sh_coeffs, 3), dtype=torch.float32, device=device, requires_grad=True)
    
    return {
        "means": means,
        "scales": scales_pre,
        "rotations": rotations,
        "opacity_logit": opacity_logit,
        "features_dc": features_dc,
        "features_rest": features_rest
    }

def compute_covariance(scales, rotations):
    """
    Compute 3D covariance matrix from pre-activation scales and quaternions.
    
    Args:
        scales: (N, 3) pre-activation scales.
        rotations: (N, 4) quaternions [w, x, y, z].
        
    Returns:
        cov3d: (N, 3, 3) covariance matrices.
    """
    # Exponential activation for scales
    S = torch.exp(scales)  # (N, 3)
    
    # Diagonal scaling matrix
    # Construct diagonal matrix for each Gaussian
    # S_diag: (N, 3, 3)
    S_diag = torch.zeros((scales.shape[0], 3, 3), device=scales.device)
    S_diag[:, 0, 0] = S[:, 0]
    S_diag[:, 1, 1] = S[:, 1]
    S_diag[:, 2, 2] = S[:, 2]
    
    # Normalize quaternions
    q_norm = torch.nn.functional.normalize(rotations, p=2, dim=1)
    
    # Convert quaternion to rotation matrix
    # q_norm: (N, 4) -> w, x, y, z
    w, x, y, z = q_norm[:, 0], q_norm[:, 1], q_norm[:, 2], q_norm[:, 3]
    
    R = torch.zeros((rotations.shape[0], 3, 3), device=rotations.device)
    R[:, 0, 0] = 1 - 2 * (y**2 + z**2)
    R[:, 0, 1] = 2 * (x*y - w*z)
    R[:, 0, 2] = 2 * (x*z + w*y)
    R[:, 1, 0] = 2 * (x*y + w*z)
    R[:, 1, 1] = 1 - 2 * (x**2 + z**2)
    R[:, 1, 2] = 2 * (y*z - w*x)
    R[:, 2, 0] = 2 * (x*z - w*y)
    R[:, 2, 1] = 2 * (y*z + w*x)
    R[:, 2, 2] = 1 - 2 * (x**2 + y**2)
    
    # Covariance: Sigma = R * S * S^T * R^T
    # Since S is diagonal, S * S^T = S^2
    cov3d = R @ S_diag @ R.transpose(1, 2)
    
    return cov3d
```

### Parameters and Typical Values
- **$C_0$**: $0.28209479177387814$. [S1, unofficial]
- **Base Distance**: $0.1$. Used in Method B for scale initialization. [S3, unofficial]
- **Initial Opacity Target**: $0.1$ or $0.5$. [S1, S3, unofficial]
- **Opacity Pre-activation Constant**: $8.0$ (yields $\approx 0.9997$). [S2, unofficial]
- **Numerical Stability Bias**: $0.3$ added to the diagonal of the 2D projected covariance matrix to prevent singularity. [S3, unofficial]
- **Max Scale**: $10.0$. Applied via `torch.clamp(torch.exp(scales), max=10.0)` to prevent excessively large Gaussians. [S3, unofficial]
- **Adam Learning Rates**:
  - Means: $0.00016$. [S1, unofficial]
  - Scales: $0.005$. [S1, unofficial]
  - Quaternions: $0.001$. [S1, unofficial]
  - Features DC: $0.0025$. [S1, unofficial]
  - Features Rest: $0.000125$. [S1, unofficial]
  - Opacities: $0.05$. [S1, unofficial]

### Edge Cases and Pitfalls
- **Division by Zero**: In the Jacobian computation for perspective projection, depth $z$ is clamped with $10^{-7}$ to prevent division by zero. [S3, unofficial]
- **Singular Covariance**: Adding $0.3$ to the diagonal of the 2D covariance matrix ensures numerical stability. [S3, unofficial]
- **Quaternion Normalization**: Quaternions must be normalized to unit length before converting to rotation matrices. [S3, unofficial]
- **Extreme Logits**: Clamping the target opacity to $[10^{-4}, 0.99]$ prevents extreme logit values that could cause gradient explosion. [S3, unofficial]

## Operating characteristics
- **Time Complexity**: Initialization is $O(N)$ for copying means and features, but $O(N \log N)$ or $O(N^2)$ for KNN distance computation depending on the implementation. [S2, unofficial]
- **Memory Complexity**: $O(N \cdot D)$, where $D$ is the number of parameters per Gaussian (position, scale, rotation, opacity, SH coefficients). [S3, unofficial]
- **Strengths**: Provides a stable starting point for optimization. Pre-activation parameterization ensures valid ranges for non-linear activations. [S3, unofficial]
- **Limitations**: KNN computation can be slow for very large point clouds. Fixed base distance initialization may not capture local geometry variations as well as KNN-based methods. [S3, unofficial]
- **When to Use**: Always used at the start of training. KNN-based is preferred for dense point clouds; fixed base is simpler and faster for sparse clouds or random initialization. [S2, S3, unofficial]

## Background
The method originates from the 3D Gaussian Splatting paper by Kerbl et al. (2023). The specific parameterization using pre-activation values (logits for opacity, logs for scale) is a common technique in differentiable rendering to handle bounded parameters. The KNN-based scale initialization is a heuristic to ensure Gaussians are sized appropriately relative to the input point cloud density. [S1, S2, S3, unofficial]
