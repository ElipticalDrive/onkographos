# LinPrim Population Control
Also called: Adaptive Population Control, LinPrim-MCMC
## Overview
LinPrim Population Control manages the density of linear primitives (octahedra and tetrahedra) during differentiable volume rendering optimization by pruning, cloning, and splitting primitives to adapt to scene complexity [S1]. It differs from standard 3D Gaussian Splatting by redefining primitive size metrics to accommodate non-spherical kernels and adjusting sampling distributions to respect the anisotropic geometry of linear primitives [S1].
## How it works
### Inputs and Outputs
**Inputs:**
- Current set of primitives $\mathcal{P}$, each with position $\mathbf{p}$, color $\mathbf{c}$, distances to corners $\mathbf{d}$, rotation quaternion $\mathbf{q}$, and view-space positional gradient $\nabla_{\mathbf{p}}$ [S1].
- Camera parameters for known views [S1].
- Scene extent bounds [S1].

**Outputs:**
- Updated set of primitives $\mathcal{P}'$ with modified count, positions, and sizes [S1].

### Data Structures
Each primitive stores:
- `position`: 3D vector $\mathbf{p} \in \mathbb{R}^3$ [S1].
- `color`: 3D vector $\mathbf{c} \in \mathbb{R}^3$ [S1].
- `distances`: Array of distances to corner vertices. For octahedra, 3 values (along axes); for tetrahedra, 4 values (to vertices) [S1].
- `rotation`: Quaternion $\mathbf{q} \in \mathbb{R}^4$ [S1].
- `gradient_momentum`: 3D vector for optimizer state [S1].
- `type`: Enum (OCTAHEDRON, TETRAHEDRON) [S1].

### Steps

#### 1. Pruning
Remove primitives that fail fidelity or efficiency criteria [S1].

**Size Definition:**
- For **Octahedra**: Size $S_{oct} = 2 \cdot \max(\mathbf{d})$, where $\mathbf{d}$ are the distances along the principal axes [S1].
- For **Tetrahedra**: Size $S_{tet} \approx \sqrt{2} \cdot d_{max}$, where $d_{max}$ is the distance to the furthest corner vertex [S1].

**Criteria:**
A primitive is pruned if:
1. Opacity is below a threshold [S1].
2. Size exceeds a fraction of the scene extent [S1].
3. Screen-space area exceeds a threshold [S1].
(Specific threshold values are not given in the sources.)

#### 2. Initialization (One-time or Reset)
Initialize primitives from Structure-from-Motion (SfM) points [S1]:
1. For each SfM point $\mathbf{p}_i$ with color $\mathbf{c}_i$:
   - Find distance to closest SfM neighbor $d_{min}$ [S1].
   - Set initial distances $\mathbf{d} = d_{min}$ for all corners [S1].
   - Set rotation $\mathbf{q}$ to a uniformly random quaternion [S1].
   - Set position $\mathbf{p} = \mathbf{p}_i$ [S1].

#### 3. Cloning and Splitting
Select primitives with large view-space positional gradients $\|\nabla_{\mathbf{p}}\|$ [S1]. (Gradient threshold is not given in the sources.)

**Cloning (for small primitives):**
1. Create new primitive with identical features: $\mathbf{p}_{new} = \mathbf{p}$, $\mathbf{c}_{new} = \mathbf{c}$, $\mathbf{d}_{new} = \mathbf{d}$, $\mathbf{q}_{new} = \mathbf{q}$ [S1].
2. Reset gradient momentum to zero [S1].

**Splitting (for large primitives):**
1. Create two new primitives with smaller sizes [S1].
2. Sample positions from a PDF based on the original primitive's geometry [S1].

**Sampling Logic:**
- **Octahedra:**
  - Standard deviations $\sigma_i = d_i$ (corresponding distance for each axis) [S1].
  - Sample offset $\Delta \mathbf{p} \sim \mathcal{N}(\mathbf{0}, \text{diag}(\sigma^2))$ [S1].
  - Apply rotation afterwards to spread primitives along longer dimensions [S1].
- **Tetrahedra:**
  - Set $\sigma = \frac{1}{2} \max(\mathbf{d})$ for all dimensions [S1].
  - Sample offset $\Delta \mathbf{p} \sim \mathcal{N}(\mathbf{0}, \sigma^2 \mathbf{I})$ [S1].
  - Apply rotation afterwards [S1].

#### 4. LinPrim-MCMC (Optional Advanced Control)
Adapt GS-MCMC population control by treating primitives as equivalent Gaussians [S1].
1. Scale octahedron distances: $\mathbf{d}' = \mathbf{d} / 2.6$ [S1].
2. Use $\mathbf{d}'$ as Gaussian standard deviations for MCMC sampling [S1].
3. Perform MCMC steps to draw samples from the scene distribution, allowing precise control over final population size [S1].

### Edge Cases and Pitfalls
- **Tetrahedron Splitting:** Non-trivial to sample along principal axes due to lack of symmetry; use isotropic scaling with $\sigma = \frac{1}{2} \max(\mathbf{d})$ [S1].
- **Octahedron Anisotropy:** Must sample along local axes before rotating to spread along longer dimensions [S1].
- **Momentum Reset:** Cloned primitives must reset gradient momentum to avoid biased updates [S1].
- **Magnitude Mismatch:** Direct use of octahedron distances as Gaussian standard deviations is invalid; scaling by 2.6 is required for MCMC compatibility [S1].

- **Time Complexity:** Not given in the sources.

- **Limitations:** Requires careful tuning of size thresholds [S1].
- **When to Use:** When optimizing linear primitives for novel views or high-fidelity reconstruction where fixed initialization is insufficient [S1].

## Background
LinPrim Population Control originates from the LinPrim paper (2025), which adapts 3D Gaussian Splatting techniques to linear primitives (octahedra and tetrahedra) [S1]. It addresses the need for dynamic population management in differentiable volumetric rendering with non-Gaussian kernels [S1]. The method incorporates insights from GS-MCMC and Distribution Alignment to handle magnitude differences between linear primitive distances and Gaussian standard deviations [S1].
