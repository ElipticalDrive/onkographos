# Radiative Gaussian Point Cloud Model

Also called: Radiation Intensity Response Function, Radiative Gaussian, X-Gaussian point cloud model

## Overview
The Radiative Gaussian Point Cloud Model is a scene representation designed for X-ray imaging that replaces the view-dependent Spherical Harmonics (SH) used in standard RGB 3D Gaussian Splatting with a view-independent Radiation Intensity Response Function (RIRF). It solves the problem of modeling isotropic X-ray attenuation, where radiation intensity depends on radiodensity rather than view direction, thereby avoiding the complex computation of SH functions and accelerating both forward and backward passes [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A set of $N_p$ 3D Gaussian primitives $\mathcal{G}_x$, camera extrinsics $\mathbf{M}_{ext}$, and intrinsics $\mathbf{M}_{int}$.
*   **Output:** A rendered 2D radiation intensity image $\mathbf{I}$ [S1].

**Data Structures**
The scene is represented as a set of Gaussian points $\mathcal{G}_x$:
$$
\mathcal{G}_x = \{G_i(\boldsymbol{\mu}_i, \boldsymbol{\Sigma}_i, \alpha_i, \mathbf{f}_i) \mid i = 1, 2, \dots, N_p\}
$$
Each Gaussian $G_i$ contains:
*   $\boldsymbol{\mu}_i \in \mathbb{R}^3$: Center position.
*   $\boldsymbol{\Sigma}_i \in \mathbb{R}^{3\times3}$: Covariance matrix.
*   $\alpha_i \in \mathbb{R}$: Opacity.
*   $\mathbf{f}_i \in \mathbb{R}^{N_f}$: Learnable feature vector representing inherent radiative properties [S1].

**Parameters**
*   $N_f$: Dimensionality of the feature vector $\mathbf{f}$. Not given in the sources.

**Method Steps**
1.  **Feature Projection (RIRF):** For each Gaussian $i$, compute its scalar radiation intensity $\mathbf{i}_i$ using the Radiation Intensity Response Function. This function maps the learnable feature vector $\mathbf{f}_i$ to a scalar value, excluding view direction dependence [S1]:
    $$
    \mathbf{i}_i = \text{Sigmoid}(\boldsymbol{\lambda} \odot \mathbf{f}_i)
    $$
    Where:
    *   $\mathbf{i}_i \in \mathbb{R}$ is the radiation intensity.
    *   $\mathbf{f}_i \in \mathbb{R}^{N_f}$ is the feature vector.
    *   $\boldsymbol{\lambda} \in \mathbb{R}^{N_f}$ is a set of constant weights controlling the importance of each component of $\mathbf{f}_i$.
    *   $\odot$ denotes element-wise multiplication.
    *   $\text{Sigmoid}(x) = \frac{1}{1 + e^{-x}}$ [S1].

2.  **Differentiable Radiative Rasterization (DRR):** Render the image $\mathbf{I}$ by projecting the Gaussians onto the image plane and compositing them along rays. The specific rasterization algorithm is implemented via CUDA and is detailed in the sibling article [Radiative Gaussian Splatting](3040-radiative-gaussian-splatting.md).

```python
def compute_radiation_intensity(f: list[float], lambda_weights: list[float]) -> float:
    """
    Computes the radiation intensity using the Radiation Intensity Response Function (RIRF).
    
    Args:
        f: Feature vector of shape (N_f,).
        lambda_weights: Constant basis weights of shape (N_f,).
        
    Returns:
        Scalar radiation intensity.
    """
    # Element-wise multiplication
    dot_product = sum(f[j] * lambda_weights[j] for j in range(len(f)))
    
    # Sigmoid activation
    intensity = 1.0 / (1.0 + math.exp(-dot_product))
    return intensity
```

## Operating characteristics
*   **Performance:** The forward and backward processes are faster than original 3DGS because the RIRF avoids the complex computation of Spherical Harmonics functions [S1].
*   **Isotropy:** The model assumes isotropic radiation intensity, which is physically accurate for X-ray attenuation but not for natural light reflection [S1].
*   **Initialization:** Standard Structure-from-Motion (SfM) initialization is unsuitable for X-ray images due to lower contrast and overlapping layers. The model relies on a customized initialization strategy (Angle-pose Cuboid Uniform Initialization) described in the parent article [Radiative and Tomographic Gaussians](4971-radiative-and-tomographic-gaussians.md) [S1].

## Background
The model was introduced in the paper "Radiative Gaussian Splatting for Efficient X-Ray Novel View Synthesis" [S1]. It addresses the limitations of applying standard RGB 3D Gaussian Splatting to X-ray imaging, where the view-dependent nature of SH is inappropriate for the isotropic nature of X-ray transmission [S1].
