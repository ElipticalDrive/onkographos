# NeRF-MAE

Also called: Masked AutoEncoders for Self-Supervised 3D Representation Learning for Neural Radiance Fields, Masked voxel-grid pretraining, NeRF Masked Auto Encoders, NeRF-MAE Masked Radiance and Density Grid Pretraining

## Overview
NeRF-MAE is a self-supervised pretraining framework for Neural Radiance Fields (NeRF) that learns 3D scene representations by masking and reconstructing patches from an explicit radiance and density grid [S1]. Unlike implicit NeRFs or point-cloud-based methods, it operates directly on the regular, high-density volumetric grid extracted from a trained NeRF, allowing the use of standard 3D Vision Transformers without adaptation [S1]. It disentangles representation learning from NeRF training, enabling the use of large-scale unlabeled data from diverse sources to improve downstream tasks such as 3D object detection and semantic labeling [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Posed RGB images used to train an initial implicit NeRF, and the resulting explicit 4D radiance/density grid $G$.
*   **Output:** A reconstructed 4D volume $R \in \mathbb{R}^{H \times W \times D \times 4}$ containing predicted radiance (RGB) and opacity ($\alpha$).

**Data Structures:**
The core data structure is the explicit grid $G \in \mathbb{R}^{H \times W \times D \times 4}$, where $H, W, D$ are spatial dimensions and the 4 channels represent $(r, g, b, \alpha)$ [S1].
*   **Patches:** The grid is partitioned into cubic patches of size $P = p \times p \times p$ with $p=4$ [S1].
*   **Tokens:** Patches are converted into 3D tokens of size $\frac{H}{p} \times \frac{W}{p} \times \frac{D}{p} \times E$ via a 3D convolutional embedding layer [S1].
*   **Masking:** A binary mask $M$ indicates which patches are hidden. A masking ratio of $m=0.75$ is used [S1].

**Parameters:**
*   Grid dimensions: $H=W=D=160$ [S1].
*   Patch size: $p=4$ [S1].
*   Masking ratio: $m=0.75$ [S1].
*   Encoder Embedding dimension: $E=96$ [S1].
*   Swin Transformer block depths: $d=[2, 2, 18, 2]$ [S1].
*   Number of attention heads: $[3, 6, 12, 24]$ for the four stages [S1].
*   Window size: $W_{win}=4$ [S1].
*   Preset distance for opacity calculation: $\Delta x = 0.01$ [S1].

**Steps:**

1.  **Grid Extraction:**
    Train an implicit NeRF $f(x, \theta)$ (e.g., Instant-NGP) on posed images [S1]. Extract the explicit grid $G$ by querying the NeRF for all training camera viewing directions $\theta$ at each grid point $(i, j, k)$ and averaging the output [S1]:
    $$
    (r_{i, j, k}, g_{i, j, k}, b_{i, j, k}, \alpha_{i, j, k}) = \frac{1}{N} \sum_{\theta=1}^{N} f(x_{i, j, k}, \theta)
    $$
    where $N$ is the number of training images [S1]. The opacity $\alpha$ is derived from volume density $\sigma$ and a preset distance $\Delta x = 0.01$:
    $$
    \alpha = 1 - \exp(-\sigma \Delta x)
    $$
    [S1].

2.  **Masking:**
    Randomly mask out patches of size $p \times p \times p$ from $G$ with ratio $m=0.75$ to create the masked grid $M$ [S1].

3.  **Patch Partitioning and Embedding:**
    Divide $M$ into patches using a 3D convolutional operation that merges partitioning and linear embedding into one step, creating tokens of size $\frac{H}{p} \times \frac{W}{p} \times \frac{D}{p} \times E$ [S1].

4.  **Positional Encoding:**
    Add 3D positional embeddings to each token. No classification token is added [S1].

5.  **Encoder (3D Swin Transformer):**
    Process tokens through 4 stages. Each stage consists of Swin Transformer 3D blocks and patch merging layers (except the last stage) [S1].
    *   **Block Structure:** Each block contains local multi-head self-attention (W-MSA-3D) or shifted multi-head self-attention (SW-MSA-3D), a 2-layer MLP with GeLU activation, Linear Norm (LN) layers, and residual connections [S1].
    *   **Window Shifting:** Windows are displaced by $[\frac{W_{win}}{2}, \frac{W_{win}}{2}, \frac{W_{win}}{2}]$ every layer [S1].
    *   **Patch Merging:** Merges four volumetric patches, reducing spatial dimensions by 2 and increasing channel dimension by 2, followed by LN and MLP [S1].
    *   **Feature Pyramid:** Concatenate outputs of all 4 stages to form feature pyramid $F = [f_0, f_1, f_2, f_3]$ [S1]. The final encoder output has spatial size $5 \times 5 \times 5$ and channel dimension 768 [S1].

6.  **Decoder:**
    Reconstruct the grid using lightweight transposed 3D convolution decoders $D_i$ attached to the feature pyramid [S1].
    *   **Update Rule:** $d_i = \text{Conv}(d_{i-1} + D(f_i))$ with $d_0 = f_3$, where $D$ is a transposed 3D convolution with kernel size 3 [S1].
    *   **Output Prediction:** The final decoder output passes through a residual block with $3 \times 3 \times 3$ convolutions and a sigmoid activation to predict $R \in \mathbb{R}^{H \times W \times D \times 4}$ [S1].

7.  **Loss Computation:**
    Compute reconstruction loss $\mathcal{L}_{recon} = \mathcal{L}_{rad} + \mathcal{L}_{\alpha}$ [S1].
    *   Radiance Loss:
        $$
        \mathcal{L}_{rad} = \frac{1}{K} \sum_{i=1}^{N} (\hat{y}_{rad_i} - y_{rad_i})^2
        $$
        where $K$ is the number of voxels in the mask corresponding to patches where $\alpha > \Delta x$ ($\Delta x = 0.01$) [S1].
    *   Opacity Loss:
        $$
        \mathcal{L}_{\alpha} = \frac{1}{M} \sum_{j=1}^{M} (\hat{y}_{\alpha_j} - y_{\alpha_j})^2
        $$
        where $M$ is the number of voxels in the mask corresponding to removed 3D patches [S1].

## Operating characteristics
*   **Time Complexity:** The encoder uses shifted window attention, which reduces the quadratic complexity of global self-attention to linear with respect to the number of voxels, making it efficient for large volumes [S1].
*   **Memory Complexity:** The explicit grid storage requires $O(H \times W \times D)$ memory. For $160^3$, this is manageable. The attention mechanism's memory usage is proportional to the number of tokens and window size [S1].
*   **Performance:** NeRF-MAE significantly outperforms self-supervised 3D pretraining and NeRF scene understanding baselines on Front3D and ScanNet datasets, with an absolute performance improvement of over 20% AP50 and 8% AP25 for 3D object detection [S1].
*   **Strengths:** Utilizes standard 3D Transformers without adaptation; disentangles representation learning from NeRF training, allowing use of diverse data sources; handles dense volumetric information better than sparse point clouds [S1].
*   **Limitations:** Requires an initial trained NeRF to extract the grid; relies on posed images; the explicit grid extraction can be computationally expensive for very large scenes [S1].

## Background
NeRF-MAE was introduced by M.Z. Irshad et al. in 2024 [S1]. It builds on the success of Masked Autoencoders (MAE) in 2D vision [18] and extends it to 3D neural radiance fields. The method addresses the lack of large-scale self-supervised pretraining for NeRFs by leveraging the regular structure of the explicit radiance and density grid [S1]. It is used for downstream tasks such as 3D object detection, voxel-grid super-resolution, and semantic voxel labeling [S1].
