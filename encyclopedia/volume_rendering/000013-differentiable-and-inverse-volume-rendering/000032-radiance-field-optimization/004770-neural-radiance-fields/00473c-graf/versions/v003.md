# GRAF

Also called: GRAF (Generative Radiance Fields), Generative Radiance Fields

## Overview
GRAF is a generative model for 3D-aware image synthesis that learns a conditional radiance field from a collection of unposed 2D images using an adversarial framework [S2, unofficial]. It allows explicit control over camera rotation, translation, shape, and appearance by mapping latent codes and camera parameters to image patches via differentiable volume rendering [S2, unofficial]. Unlike voxel-based approaches (e.g., HoloGAN, PLATONIC GAN) which suffer from memory limitations and discretization artifacts, GRAF uses a continuous representation that scales well with image resolution and incorporates 3D consistency by design without learned projections [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Generator Input:** Camera matrix $K$, camera pose $\xi = [R|t]$, 2D sampling pattern $\nu = (u, s)$, shape code $z_s \in \mathbb{R}^{M_s}$, appearance code $z_a \in \mathbb{R}^{M_a}$ [S2, unofficial].
*   **Generator Output:** A predicted image patch $P_0$ of size $K \times K$ pixels [S2, unofficial].
*   **Discriminator Input:** A real image patch $P$ extracted from a real image $I$ and the predicted patch $P_0$ [S2, unofficial].
*   **Discriminator Output:** A scalar score indicating realness [S2, unofficial].

**Data Structures:**
1.  **Conditional Radiance Field $g_\theta$:** A fully connected neural network (MLP) [S2, unofficial].
    *   **Shape Encoding Head $h_\theta$:** Maps $(\gamma(x), z_s)$ to shape encoding $h \in \mathbb{R}^H$ [S2, unofficial].
    *   **Density Head $\sigma_\theta$:** Maps $h$ to volume density $\sigma \in \mathbb{R}^+$ [S2, unofficial].
    *   **Color Head $c_\theta$:** Maps $(h, \gamma(d), z_a)$ to RGB color $c \in \mathbb{R}^3$ [S2, unofficial].
    *   All heads use ReLU activations [S2, unofficial].
2.  **Discriminator $D_\phi$:** A convolutional neural network (CNN) [S2, unofficial].
    *   Uses spectral normalization and instance normalization [S2, unofficial].
    *   Takes a $K \times K$ patch as input [S2, unofficial].

**Numbered Steps:**

1.  **Sample Inputs:**
    *   Sample camera pose $\xi = [R|t]$ from distribution $p_\xi$. In experiments, use a uniform distribution on the upper hemisphere for camera location facing the origin, varying distance uniformly [S2, unofficial].
    *   Sample shape code $z_s \sim p_s$ and appearance code $z_a \sim p_a$. In experiments, use standard Gaussian distributions for both [S2, unofficial].
    *   Sample 2D sampling pattern $\nu = (u, s)$ where center $u \sim U(\Omega)$ (uniform over image domain $\Omega$) and scale $s \sim U([1, S])$. Ensure the entire $K \times K$ patch is within $\Omega$. $S = \min(W, H)/K$ where $W, H$ are target image dimensions [S2, unofficial].

2.  **Define Patch Coordinates:**
    *   Determine the $K \times K$ patch $P(u, s)$ coordinates as continuous real numbers:
        $$ P(u, s) = (sx + u, sy + v) \quad \text{for } x, y \in \{-K/2, \dots, K/2 - 1\} $$
    *   This allows continuous evaluation of the radiance field [S2, unofficial].

3.  **Ray Sampling:**
    *   Determine 3D rays uniquely from $P(u, s)$, camera pose $\xi$, and intrinsics $K$ [S2, unofficial].
    *   Denote normalized rays as $d_r$ and number of rays as $R$ ($R = K^2$ during training, $R = W \times H$ during inference) [S2, unofficial].

4.  **3D Point Sampling:**
    *   Sample $N$ points $\{x_{ir}\}$ along each ray $r$ using stratified sampling [S2, unofficial].

5.  **Evaluate Conditional Radiance Field:**
    *   Compute shape encoding: $h = h_\theta(\gamma(x), z_s)$ [S2, unofficial].
    *   Compute density: $\sigma = \sigma_\theta(h)$ [S2, unofficial].
    *   Compute color: $c = c_\theta(h, \gamma(d), z_a)$ [S2, unofficial].
    *   Note: $\sigma$ is computed independently of viewpoint $d$ and appearance code $z_a$ to encourage multi-view consistency [S2, unofficial].

6.  **Volume Rendering:**
    *   Perform volume rendering to obtain pixel color $c_r$ from $\{(c_{ir}, \sigma_{ir})\}$ along ray $r$ using the standard emission-absorption model (see [NeRF](4972-neural-radiance-fields.md) Shared principles) [S2, unofficial].
    *   Combine results of all $R$ rays to form predicted patch $P_0$ [S2, unofficial].

7.  **Discriminator Processing:**
    *   Extract real patch $P$ from real image $I$ using bilinear interpolation at coordinates $P(u, s)$ drawn from the same distribution $p_\nu$. Denote this as $\Gamma(I, \nu)$ [S2, unofficial].
    *   Compute discriminator scores for $P_0$ and $P$ [S2, unofficial].

8.  **Training Objective:**
    *   Train using non-saturating GAN objective with R1 regularization:
        $$ V(\theta, \phi) = \mathbb{E}_{z_s \sim p_s, z_a \sim p_a, \xi \sim p_\xi, \nu \sim p_\nu} [f(D_\phi(G_\theta(z_s, z_a, \xi, \nu)))] + \mathbb{E}_{I \sim p_D, \nu \sim p_\nu} [f(-D_\phi(\Gamma(I, \nu)))] - \lambda \|\nabla D_\phi(\Gamma(I, \nu))\|^2 $$
    *   Where $f(t) = -\log(1 + \exp(-t))$ and $\lambda$ controls the strength of the regularizer [S2, unofficial].

9.  **Inference:**
    *   Randomly sample $z_s, z_a, \xi$.
    *   Predict one color value for every pixel in the target image (full resolution $W \times H$) [S2, unofficial].

**Pseudocode:**

```python
import math

def positional_encoding(x, min_deg, max_deg):
    """Standard positional encoding for NeRF. x: list of floats."""
    encoded = []
    for val in x:
        for i in range(min_deg, max_deg + 1):
            scale = 2 ** i
            encoded.extend([math.sin(scale * val), math.cos(scale * val)])
    return encoded

def evaluate_conditional_radiance_field(x, d, z_s, z_a, h_net, sigma_net, c_net):
    """Evaluates the conditional radiance field g_theta."""
    # 1. Compute shape encoding h
    h_input = x + z_s  # Concatenation assumed as addition in vector space for brevity
    h = h_net(h_input)
    
    # 2. Compute density sigma (independent of d and z_a)
    sigma = sigma_net(h)
    
    # 3. Compute color c
    c_input = h + d + z_a
    c = c_net(c_input)
    
    return c, sigma

def volume_rendering(rays_o, rays_d, points, colors, sigmas):
    """Standard volume rendering (DVR) as per NeRF."""
    # Compute deltas between consecutive points
    deltas = []
    for i in range(len(points) - 1):
        dx = points[i+1][0] - points[i][0]
        dy = points[i+1][1] - points[i][1]
        dz = points[i+1][2] - points[i][2]
        deltas.append(math.sqrt(dx*dx + dy*dy + dz*dz))
    deltas.append(1e10)  # Last delta to far plane
    
    # Compute alpha
    alpha = [1.0 - math.exp(-sigmas[i] * deltas[i]) for i in range(len(sigmas))]
    
    # Compute transmittance T
    T = [1.0]
    for i in range(len(alpha) - 1):
        T.append(T[-1] * (1.0 - alpha[i] + 1e-10))
        
    # Compute weights and composite color
    comp_color = [0.0, 0.0, 0.0]
    for i in range(len(alpha)):
        w = alpha[i] * T[i]
        for c in range(3):
            comp_color[c] += w * colors[i][c]
            
    return comp_color

def extract_patch_bilinear(image, u_x, u_y, s, K, W, H):
    """Extracts a KxK patch from image at continuous coordinates u scaled by s using bilinear interpolation."""
    patch = []
    for y in range(K):
        row = []
        for x in range(K):
            # Continuous coordinates in image space
            px = s * (x - K/2) + u_x
            py = s * (y - K/2) + u_y
            
            # Bilinear interpolation
            x0, x1 = int(math.floor(px)), int(math.ceil(px))
            y0, y1 = int(math.floor(py)), int(math.ceil(py))
            x0, x1 = max(0, min(W-1, x0)), max(0, min(W-1, x1))
            y0, y1 = max(0, min(H-1, y0)), max(0, min(H-1, y1))
            
            fx = px - x0
            fy = py - y0
            
            val = (1-fx)*(1-fy)*image[y0][x0] + fx*(1-fy)*image[y0][x1] + \
                  (1-fx)*fy*image[y1][x0] + fx*fy*image[y1][x1]
            row.append(val)
        patch.append(row)
    return patch

def graf_train_step(generator, discriminator, real_image, K, W, H, N, lambda_r1):
    """One training step for GRAF."""
    # 1. Sample latent codes and camera parameters
    z_s = [random.gauss(0, 1) for _ in range(128)]
    z_a = [random.gauss(0, 1) for _ in range(128)]
    
    # Sample pose (simplified)
    R = [[1,0,0],[0,1,0],[0,0,1]]
    t = [0, 0, 0]
    xi = R + t
    
    # Sample 2D sampling pattern nu = (u, s)
    u_x = random.uniform(0, W)
    u_y = random.uniform(0, H)
    S = min(W, H) / K
    s = random.uniform(1, S)
    
    # 2. Generate Patch
    pred_patch = generator(K, xi, (u_x, u_y, s), z_s, z_a)
    
    # 3. Sample Real Patch
    real_patch = extract_patch_bilinear(real_image, u_x, u_y, s, K, W, H)
    
    # 4. Discriminator Forward
    score_gen = discriminator(pred_patch)
    score_real = discriminator(real_patch)
    
    # 5. Compute Losses
    # Non-saturating GAN loss: f(t) = -log(1 + exp(-t))
    loss_gen = -math.log(1 + math.exp(-score_gen))
    loss_disc_real = -math.log(1 + math.exp(-score_real))
    
    # R1 Regularization: lambda * || grad D(I) ||^2
    # Compute gradient of discriminator output w.r.t real patch (simplified)
    grad_real = [random.uniform(-1, 1) for _ in range(len(real_patch))]
    r1_reg = lambda_r1 * sum(g*g for g in grad_real)
    
    loss_disc = loss_disc_real + r1_reg
    
    # 6. Backprop (conceptual)
    # loss_disc.backward()
    # loss_gen.backward()
    
    return loss_gen, loss_disc
```

**Parameters:**
*   **Patch size $K \times K$:** Fixed size of the image patch predicted by the generator during training. Chosen such that the principal point is in the center of the image [S2, unofficial].
*   **$S$:** Maximum scale for the virtual patch, $S = \min(W, H)/K$ [S2, unofficial].
*   **$N$:** Number of 3D points sampled along each ray for numerical integration [S2, unofficial].
*   **$\lambda$:** Strength of the R1 regularization term [S2, unofficial].
*   **Learning Rate:** 0.0005 for the generator, 0.0001 for the discriminator [S2, unofficial].
*   **Batch Size:** 8 [S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Training Cost:** Predicting one color value per pixel is too expensive at training time. The solution is to predict a fixed $K \times K$ patch randomly scaled and rotated to provide gradients for the entire field [S2, unofficial].
*   **Continuous Coordinates:** The patch coordinates $P(u, s)$ are continuous real numbers, not discrete integers, allowing continuous evaluation of the radiance field [S2, unofficial].
*   **Discriminator Scale:** The discriminator is similar to PatchGAN but allows continuous displacements $u$ and scales $s$. It does not downsample the real image $I$ based on $s$, but queries sparse locations to retain high-frequency details [S2, unofficial].

## Operating characteristics
*   **Time and Memory Complexity:** The continuous representation scales well with image resolution and memory consumption compared to voxel-based methods [S2, unofficial]. Training uses a fixed patch size $K \times K$ regardless of the target image resolution, reducing computational cost [S2, unofficial].
*   **Measured Performance:**
    *   FID scores on Cars dataset at $64^2$ resolution: 34 (GRAF) vs 199 (PLATONIC GAN), 59 (HoloGAN), 59 (2D GAN) [S2, unofficial].
    *   FID scores on Faces dataset at $512^2$ resolution: 25 (GRAF) vs 134 (HoloGAN), 321 (PLATONIC GAN), 66 (2D GAN) [S2, unofficial].
    *   Reconstruction Accuracy (MMD-CD) on Cars: 0.044 (GRAF) vs 0.109 (HoloGAN) [S2, unofficial].
*   **Strengths:**
    *   Continuous representation avoids discretization artifacts and memory limitations of voxel-based methods [S2, unofficial].
    *   Incorporates 3D consistency by design through differentiable volume rendering, avoiding entangled latents common in learned projection methods [S2, unofficial].
    *   Allows explicit control over camera rotation, translation, shape, and appearance [S2, unofficial].
*   **Limitations:**
    *   Requires adversarial training which can be unstable [S2, unofficial].
    *   Relies on the quality of the conditional radiance field representation [S2, unofficial].
*   **When to Use:** Suitable for 3D-aware image synthesis from unposed 2D images where explicit control over camera and appearance is desired, and high resolution is needed [S2, unofficial].
*   **When Not to Use:** When posed images of a single scene are available (use standard NeRF), or when computational resources for adversarial training are limited [S2, unofficial].

## Background
GRAF (Generative Radiance Fields) was introduced in the paper "GRAF: Generative Radiance Fields for 3D-Aware Image Synthesis" [S2, unofficial]. It builds on the principles of Neural Radiance Fields (NeRF) [S1]. The method addresses the problem of 3D-aware image synthesis from unposed 2D images, a setting where traditional NeRF cannot be directly applied due to the lack of camera poses and the need for a generative model [S2, unofficial]. It was evaluated on synthetic datasets (Chairs, Cars) and real-world datasets (Faces, Cats, Birds) [S2, unofficial].
