# NeuS Training Loss

Also called: NeUDF loss, Neural Implicit Surface training objective, Training Loss, optimization objective

## Overview
The NeuS training loss is a composite objective function used to optimize neural implicit surface representations (specifically Signed Distance Fields or Unsigned Distance Fields) from multi-view images without 3D ground-truth supervision [S1][S2, unofficial]. It solves the problem of recovering high-fidelity open surfaces by combining photometric consistency with geometric regularization [S1]. It distinguishes itself from standard NeRF training [NeRF Training Configuration](1203-nerf-training-configuration.md) by explicitly enforcing the Eikonal equation on the SDF/UDF gradients and using a mask-based binary cross-entropy loss to drive opacity toward binary values, thereby stabilizing the thin-surface approximation [S1][S2, unofficial].

## How it works
The method optimizes a neural network that outputs a scalar field value (SDF or UDF) and an opacity value for any 3D point [S2, unofficial]. The total loss $\mathcal{L}$ is a weighted sum of color, geometric, and mask losses [S1].

### Inputs and Outputs
*   **Inputs**:
    *   Ground truth RGB images $I_{gt}$ for each camera pose [S2, unofficial].
    *   Ground truth binary foreground masks $M_{gt}$ (optional, but required for $\mathcal{L}_m$) [S2, unofficial].
    *   Ray origins $o$ and directions $d$ sampled from the image plane [S2, unofficial].
    *   Sample points $x_i$ along the rays, sampled according to the volume rendering integration strategy [S2, unofficial].
*   **Outputs**:
    *   Rendered RGB images $I_{pred}$ [S2, unofficial].
    *   Rendered opacity/mask values $\alpha_{pred}$ [S2, unofficial].
    *   Network gradients $\nabla S(x)$ at sample points [S2, unofficial].

### Data Structures
The implementation relies on tensors representing the batch of rays:
*   `rays_valid`: Boolean mask indicating which rays have valid ground truth data (non-background) [S2, unofficial].
*   `comp_rgb_full`: Tensor of shape $(N_{rays}, 3)$ containing the accumulated RGB color for each ray [S2, unofficial].
*   `sdf_grad_samples`: Tensor of shape $(N_{samples}, 3)$ containing the gradient $\nabla SDF$ for each sample point [S2, unofficial].
*   `opacity`: Tensor of shape $(N_{rays})$ or $(N_{samples})$ depending on the specific accumulation step, representing the transmittance/opacity contribution [S2, unofficial].

### Formulas and Parameters
The total loss is defined as [S1]:
$$ \mathcal{L} = \mathcal{L}_c + \alpha \mathcal{L}_e + \beta \mathcal{L}_m $$
Where:
*   $\mathcal{L}_c$: Color loss (photometric consistency) [S1].
*   $\mathcal{L}_e$: Eikonal loss (geometric regularization) [S1].
*   $\mathcal{L}_m$: Mask loss (binary opacity enforcement) [S1].
*   $\alpha$: Weight for Eikonal loss [S1].
*   $\beta$: Weight for Mask loss [S1].

**1. Color Loss ($\mathcal{L}_c$)**
Measures the difference between rendered and ground truth images [S1]. Sources indicate the use of L1 loss [S1] or MSE [S2, unofficial]. The implementation in [S2, unofficial] uses MSE masked by valid rays.
$$ \mathcal{L}_c = \text{MSE}(I_{pred}[rays\_valid], I_{gt}[rays\_valid]) $$
*   Parameter: `lambda_rgb_mse` (weight for MSE component) [S2, unofficial].

**2. Eikonal Loss ($\mathcal{L}_e$)**
Enforces that the gradient of the SDF/UDF has a unit norm everywhere, which is a property of distance fields [S1].
$$ \mathcal{L}_e = \text{mean}(\|\nabla SDF(x_i)\|_2 - 1)^2 $$
*   Parameter: `lambda_eikonal` (weight for Eikonal loss) [S2, unofficial].

**3. Mask Loss ($\mathcal{L}_m$)**
Encourages the predicted opacity to match the ground truth foreground mask [S2, unofficial]. It uses Binary Cross Entropy (BCE). To prevent numerical instability ($\log(0)$), opacity values are clamped to $[10^{-3}, 1-10^{-3}]$ [S2, unofficial].
$$ \mathcal{L}_m = \text{BCE}(\text{clamp}(\alpha_{pred}, 10^{-3}, 1-10^{-3}), M_{gt}) $$
*   Parameter: `lambda_mask` (weight for mask loss) [S2, unofficial]. Applied only if masks are provided.

**4. Additional Regularization Terms**
Source [S2, unofficial] lists several additional terms used to improve stability and quality:
*   **Opaque Loss**: Encourages opacity to be 0 or 1 [S2, unofficial].
    $$ \mathcal{L}_{opaque} = \text{BCE}(\alpha_{pred}, \alpha_{pred}) $$
    *   Parameter: `lambda_opaque` [S2, unofficial].
*   **Sparsity Loss**: Encourages the SDF to be positive (empty space) outside the surface [S2, unofficial].
    $$ \mathcal{L}_{sparsity} = \text{mean}(\exp(-\lambda_{sparsity} \cdot |SDF|)) $$
    *   Parameter: `sparsity_scale` (used as $\lambda_{sparsity}$ in the exponent) [S2, unofficial].
*   **Curvature Loss**: Uses the absolute mean of SDF Laplace samples [S2, unofficial].
    *   Requirement: Geometry model must compute `sdf_laplace_samples` using finite differences (`geometry.grad_type = 'finite_difference'`) [S2, unofficial].
    *   Parameter: `lambda_curvature` [S2, unofficial].
*   **Distortion Loss**: Based on MipNeRF360, penalizing the distortion of the ray sampling intervals [S2, unofficial].
    *   Parameter: `lambda_distortion` [S2, unofficial].
*   **Background Distortion Loss**: Similar to distortion loss but for learned background components [S2, unofficial].
    *   Parameter: `lambda_distortion_bg` [S2, unofficial].

### Pseudocode
The following Python-like pseudocode implements the core loss calculation and conditional optional terms as described in [S2, unofficial].

```python
import math

def compute_neus_loss(out, batch, config):
    """
    out: dict containing 'comp_rgb_full', 'rays_valid_full', 'sdf_grad_samples', 'opacity', 'sdf_samples', 'sdf_laplace_samples'
    batch: dict containing 'rgb', 'mask'
    config: object containing system.loss parameters and has_mask flag
    """
    loss = 0.0
    
    # 1. Color Loss (MSE)
    valid_mask = out['rays_valid_full'][..., 0]
    pred_rgb = [out['comp_rgb_full'][i] for i in range(len(out['comp_rgb_full'])) if valid_mask[i]]
    gt_rgb = [batch['rgb'][i] for i in range(len(batch['rgb'])) if valid_mask[i]]
    
    def mse(p, t):
        return sum((pv - tv)**2 for pv, tv in zip(p, t)) / len(p)
    loss += mse(pred_rgb, gt_rgb) * config.lambda_rgb_mse
    
    # 2. Eikonal Loss
    def l2_norm(vec):
        return math.sqrt(sum(v**2 for v in vec))
    grad_norms = [l2_norm(out['sdf_grad_samples'][i]) for i in range(len(out['sdf_grad_samples']))]
    loss_eikonal = sum((g - 1.0)**2 for g in grad_norms) / len(grad_norms)
    loss += loss_eikonal * config.lambda_eikonal
    
    # 3. Mask Loss (BCE)
    if config.has_mask:
        def clamp(val, lo, hi):
            return max(lo, min(hi, val))
        def bce(pred, target):
            pred_c = [clamp(p, 1e-3, 1 - 1e-3) for p in pred]
            return -sum(t * math.log(p) + (1 - t) * math.log(1 - p) for p, t in zip(pred_c, target)) / len(target)
        
        opacity_clamped = [clamp(out['opacity'][i], 1e-3, 1 - 1e-3) for i in range(len(out['opacity']))]
        gt_mask = [batch['mask'][i] for i in range(len(batch['mask'])) if valid_mask[i]]
        loss += bce(opacity_clamped, gt_mask) * config.lambda_mask
        
        # 4. Opaque Loss
        loss_opaque = bce(out['opacity'], out['opacity'])
        loss += loss_opaque * config.lambda_opaque
        
        # 5. Sparsity Loss
        sdf_values = out['sdf_samples']
        sparsity_scale = config.sparsity_scale
        loss_sparsity = sum(math.exp(-sparsity_scale * abs(s)) for s in sdf_values) / len(sdf_values)
        loss += loss_sparsity * config.lambda_sparsity
        
        # 6. Curvature Loss
        if 'sdf_laplace_samples' in out:
            loss_curvature = sum(abs(l) for l in out['sdf_laplace_samples']) / len(out['sdf_laplace_samples'])
            loss += loss_curvature * config.lambda_curvature
            
        # 7. Distortion Loss
        # Implementation details for MipNeRF360 distortion loss not provided in sources.
        if config.lambda_distortion > 0:
            pass 
            
        # 8. Background Distortion Loss
        if config.lambda_distortion_bg > 0:
            pass

    return loss
```

### Edge Cases and Pitfalls
*   **Numerical Stability**: Opacity values must be clamped away from 0 and 1 before computing Binary Cross Entropy to avoid $\log(0)$ instability [S2, unofficial].
*   **Curvature Loss Prerequisite**: The curvature loss requires the geometry model to explicitly compute SDF Laplace samples. The code must assert that `geometry.grad_type` is set to `'finite_difference'` to ensure `out['sdf_laplace_samples']` is populated [S2, unofficial].
*   **Mask Availability**: The mask loss $\mathcal{L}_m$ is only applied if foreground masks are provided in the dataset [S1]. The implementation checks `self.dataset.has_mask` before applying `lambda_mask` [S2, unofficial].
*   **Dynamic Ray Sampling**: Some implementations use a dynamic update rule for the number of rays $N_{rays}$ during training to balance computation and quality:
    $$ N_{rays}^{new} = \min\left(0.9 N_{rays}^{old} + 0.1 \left\lfloor N_{rays}^{old} \cdot \frac{N_{samples}}{\sum N_{samples}^{pred}} \right\rfloor, N_{rays}^{max}\right) $$
    [S2, unofficial].

## Subtopics

### [PG-NeuS](4251-pg-neus.md)
PG-NeuS is a point-guided neural implicit surface reconstruction method that enhances the base NeuS framework by modeling aleatoric uncertainty to capture point cloud noise distribution, using a Neural Projection module for geometric constraints, and employing a Bias Network to compensate for geometric bias between volume rendering and point modeling. It distinguishes itself from siblings like RegSDF and TUVR by estimating point reliability during geometry optimization via uncertainty modeling rather than using uniform smoothing or external MVS confidence maps, enabling robust handling of noisy and sparse point data.

## Background
The NeuS training loss was introduced in the context of Neural Implicit Surface (NeuS) reconstruction, building upon the foundations of Neural Radiance Fields (NeRF) [NeRF](1200-nerf.md). The original NeuS paper [53] (cited in [S1]) proposed using volume rendering with a signed distance field to achieve high-fidelity surface reconstruction. The loss function combines photometric consistency (color loss) with geometric regularization (Eikonal loss) and mask supervision. The NeUDF variant [S1] extends this to Unsigned Distance Fields, maintaining the same loss structure but adapting the SDF properties. Modern implementations like Instant-NSR-PL [S2, unofficial] have expanded the loss with additional terms like distortion and sparsity losses to improve robustness and training stability.
