# NeRF (Neural Radiance Fields)
Also called: NeRF: Representing Scenes as Neural Radiance Fields for View Synthesis, Neural Radiance Field (NeRF)

## Overview
NeRF is a neural rendering method that models a radiance field by incorporating both 3D position and view direction to correctly render specularities and transparency, which require view-dependent effects [S1, S3, S5, unofficial]. It solves the problem of synthesizing novel views of complex 3D scenes from a sparse set of posed 2D images by learning a continuous 5D function that maps spatial coordinates and viewing directions to volume density and emitted color [S3, S4, S6, unofficial]. What sets it apart from its siblings, such as [Explicit Radiance Fields](806-explicit-radiance-fields.md) and [Plenoxels](1501-plenoxels.md), is its use of a dense, fully-connected Multi-Layer Perceptron (MLP) to represent the scene implicitly, allowing for high-fidelity reconstruction of complex geometry and appearance without explicit mesh or voxel structures [S2, S3, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ posed training images $\{I_i\}$ with known camera poses (rotation $R_i$ and translation $t_i$) and intrinsics (focal length $f$).
*   **Outputs:** A rendered RGB image, depth map, and accumulation (opacity) map for a target camera pose.

**Data Structures:**
The scene is represented by two MLPs (often sharing weights or architecture): a coarse network and a fine network.
*   **Positional Encoding:** Inputs are transformed using sinusoidal positional encoding $\gamma(\mathbf{p})$. For input vector $\mathbf{v}$ and level $L$:
    $$ \gamma(\mathbf{v}) = (\sin(2^0 \mathbf{v}), \cos(2^0 \mathbf{v}), \dots, \sin(2^{L-1} \mathbf{v}), \cos(2^{L-1} \mathbf{v})) $$
    *   Position encoding ($L=10$): Input dimension $3 + 3 \times 2 \times 10 = 63$ [S4, S5, unofficial].
    *   Direction encoding ($L=4$): Input dimension $3 + 3 \times 2 \times 4 = 27$ [S4, S5, unofficial].
*   **MLP Architecture:**
    *   **Density Network:** 8 fully-connected layers with 256 hidden units each, using ReLU activation. A skip connection concatenates the original encoded position input to the output of layer 4 [S4, S5, S8, unofficial].
    *   **Color Network:** Takes the output of the density network (feature vector) and the encoded viewing direction. It consists of a few fully-connected layers (e.g., 128 units) followed by a final layer outputting 3 values (RGB) [S5, S8, unofficial].
    *   **Output Dimensions:** The final layer of the density network outputs 1 value (density $\sigma$) and a feature vector (e.g., 256 dims). The color network outputs 3 values (RGB). Total raw output per query is 4 values [S3, S8, unofficial].

**Numbered Steps:**

1.  **Ray Generation:** For each pixel $(u, v)$ in the target image, generate a ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$.
    *   Compute normalized image-plane coordinates: $x = (u - W/2)/f$, $y = -(v - H/2)/f$, $z = -1$ [S5, S7, unofficial].
    *   Transform direction to world space: $\mathbf{d}_{world} = R \cdot [x, y, 1]^T$, then normalize [S5, S7, unofficial].
    *   Set origin $\mathbf{o}$ to the camera center [S5, S7, unofficial].

2.  **Coarse Sampling:** Sample $N_c$ points along the ray within the interval $[t_{near}, t_{far}]$.
    *   Divide $[t_{near}, t_{far}]$ into $N_c$ equal bins.
    *   Draw one sample uniformly at random from each bin (stratified sampling) [S5, S6, unofficial].
    *   Typical values: $N_c = 64$, $t_{near} = 2.0$, $t_{far} = 6.0$ (for Blender datasets) [S4, S7, unofficial].

3.  **Coarse Network Query:**
    *   Apply positional encoding to the 3D positions of the sampled points.
    *   Pass through the coarse MLP to predict raw density $\sigma_c$ and feature vectors $\mathbf{f}_c$.
    *   Apply ReLU to $\sigma_c$ to ensure non-negativity [S3, S8, unofficial].

4.  **Importance Sampling (Hierarchical Sampling):**
    *   Compute weights for the coarse samples: $w_i = T_i \cdot (1 - \exp(-\sigma_{c,i} \delta_i))$, where $\delta_i$ is the distance between adjacent samples and $T_i$ is the accumulated transmittance [S6, unofficial].
    *   Normalize weights to form a Probability Density Function (PDF).
    *   Sample $N_f$ additional points using inverse-CDF sampling based on this PDF, concentrating samples in regions of high density [S5, S6, unofficial].
    *   Typical value: $N_f = 128$ [S4, unofficial].

5.  **Fine Network Query:**
    *   Combine coarse and fine sample points.
    *   Apply positional encoding to positions.
    *   Pass through the fine MLP to predict raw density $\sigma_f$ and feature vectors $\mathbf{f}_f$.
    *   Apply ReLU to $\sigma_f$ [S3, S8, unofficial].

6.  **Volume Rendering:**
    *   For each sample $i$, compute opacity $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ [S5, S6, unofficial].
    *   Compute transmittance $T_i = \prod_{j<i} (1 - \alpha_j)$ [S5, S6, unofficial].
    *   Compute rendering weights $W_i = T_i \alpha_i$ [S6, unofficial].
    *   Concatenate feature vector $\mathbf{f}_i$ with the encoded viewing direction $\gamma(\mathbf{d})$ [S1, S5, unofficial].
    *   Pass through the color network head to get RGB color $\mathbf{c}_i$. Apply Sigmoid to clamp RGB to $[0, 1]$ [S3, S8, unofficial].
    *   Compute final color: $\hat{C}(\mathbf{r}) = \sum_i W_i \mathbf{c}_i$ [S5, S6, unofficial].
    *   Compute depth: $\hat{D}(\mathbf{r}) = \sum_i W_i t_i$ [S3, unofficial].
    *   Compute accumulation: $\hat{A}(\mathbf{r}) = \sum_i W_i$ [S3, unofficial].

7.  **Training:**
    *   Minimize the Mean Squared Error (MSE) between the rendered color $\hat{C}(\mathbf{r})$ and the ground truth image color $C(\mathbf{r})$ [S2, S4, unofficial].
    *   Loss function: $\mathcal{L} = \sum_{\mathbf{r}} [\|\hat{C}_{coarse}(\mathbf{r}) - C(\mathbf{r})\|^2_2 + \|\hat{C}_{fine}(\mathbf{r}) - C(\mathbf{r})\|^2_2]$ [S6, unofficial].
    *   Use Adam optimizer with $\beta_1=0.9, \beta_2=0.999$, initial learning rate $5 \times 10^{-4}$ decaying exponentially to $5 \times 10^{-5}$ [S4, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn.functional as F

def positional_encoding(v, num_frequencies, include_input=True):
    """
    Applies sinusoidal positional encoding to input vector v.
    v: Tensor of shape [..., D]
    num_frequencies: int L
    Returns: Tensor of shape [..., D * (2*L + 1)] if include_input else [..., D * 2*L]
    """
    freq_bands = 2.0 ** torch.linspace(0, num_frequencies - 1, num_frequencies)
    # v[..., None] * freq_bands -> [..., D, L]
    # sin and cos -> [..., D, L, 2]
    encoded = torch.cat([torch.sin(v[..., None] * freq_bands), 
                         torch.cos(v[..., None] * freq_bands)], dim=-1)
    # Flatten last two dims -> [..., D * 2 * L]
    encoded = encoded.view(*v.shape[:-1], -1)
    if include_input:
        return torch.cat([v, encoded], dim=-1)
    return encoded

def nerf_mlp_forward(x_pos_enc, x_dir_enc, density_layers, color_head):
    """
    Forward pass through the NeRF MLP.
    x_pos_enc: Encoded position [..., 63]
    x_dir_enc: Encoded direction [..., 27]
    density_layers: List of linear layers for density network
    color_head: Linear layer for RGB output
    """
    h = x_pos_enc
    for i, layer in enumerate(density_layers):
        h = layer(h)
        if i < len(density_layers) - 1: # ReLU for hidden layers
            h = F.relu(h)
        if i == 3: # Skip connection at layer 4 (index 3)
            h = torch.cat([h, x_pos_enc], dim=-1)
    
    # Last layer outputs density and feature vector
    # Assuming the last layer is defined to output 1 + feature_dim
    raw_density = h[..., :1]
    feature_vec = h[..., 1:]
    
    # View-dependent color
    # Concatenate feature vector with direction encoding
    h_color = torch.cat([feature_vec, x_dir_enc], dim=-1)
    h_color = F.relu(h_color)
    rgb = color_head(h_color)
    
    return raw_density, rgb

def render_ray(rays_o, rays_d, near, far, n_coarse, n_fine, 
               pos_enc_pos, pos_enc_dir, 
               density_layers_coarse, density_layers_fine, 
               color_head_coarse, color_head_fine):
    """
    Renders a single ray (or batch of rays) using NeRF.
    """
    # 1. Coarse Sampling
    t_coarse = torch.linspace(near, far, n_coarse)
    # Stratified sampling
    dt = (far - near) / n_coarse
    t_coarse = t_coarse + torch.rand_like(t_coarse) * dt - dt/2
    
    # 2. Query Coarse Network
    pos_enc = positional_encoding(rays_o + rays_d.unsqueeze(-1) * t_coarse.unsqueeze(-1), 10)
    dir_enc = positional_encoding(rays_d, 4)
    
    raw_sigma_coarse, raw_rgb_coarse = nerf_mlp_forward(pos_enc, dir_enc, 
                                                        density_layers_coarse, 
                                                        color_head_coarse)
    
    # 3. Compute Coarse Weights for Importance Sampling
    deltas = t_coarse[..., 1:] - t_coarse[..., :-1]
    last_delta = torch.full_like(deltas[..., :1], 1e10)
    deltas = torch.cat([deltas, last_delta], dim=-1)
    deltas = deltas * rays_d.norm(dim=-1, keepdim=True)
    
    sigma_coarse = F.relu(raw_sigma_coarse)
    alpha_coarse = 1.0 - torch.exp(-sigma_coarse * deltas)
    
    # Transmittance
    transmittance_coarse = torch.cumprod(torch.cat([torch.ones_like(alpha_coarse[..., :1]), 
                                                    1.0 - alpha_coarse + 1e-10], dim=-1), dim=-1)[..., :-1]
    
    weights_coarse = transmittance_coarse * alpha_coarse
    
    # 4. Importance Sampling
    pdf = weights_coarse / (weights_coarse.sum(dim=-1, keepdim=True) + 1e-10)
    cdf = torch.cumsum(pdf, dim=-1)
    cdf = torch.cat([torch.zeros_like(cdf[..., :1]), cdf], dim=-1)
    
    u = torch.rand_like(cdf[..., :1]).expand(-1, n_fine)
    # Inverse CDF sampling (simplified binary search or searchsorted)
    inds = torch.searchsorted(cdf, u, right=True)
    below = torch.clamp(inds - 1, min=0)
    above = torch.clamp(inds, max=cdf.shape[-1] - 1)
    
    t_g = torch.stack([t_coarse[below], t_coarse[above]], dim=-1)
    cdf_g = torch.stack([cdf[below], cdf[above]], dim=-1)
    
    denom = cdf_g[..., 1] - cdf_g[..., 0]
    denom = torch.where(denom < 1e-5, torch.ones_like(denom), denom)
    
    t_fine = t_g[..., 0] + (u - cdf_g[..., 0]) / denom * (t_g[..., 1] - t_g[..., 0])
    
    # 5. Query Fine Network
    # Combine coarse and fine samples
    t_all = torch.cat([t_coarse, t_fine], dim=-1)
    pos_enc_all = positional_encoding(rays_o + rays_d.unsqueeze(-1) * t_all.unsqueeze(-1), 10)
    dir_enc_all = positional_encoding(rays_d, 4)
    
    raw_sigma_fine, raw_rgb_fine = nerf_mlp_forward(pos_enc_all, dir_enc_all, 
                                                    density_layers_fine, 
                                                    color_head_fine)
    
    # 6. Volume Rendering
    # Re-calculate deltas for all samples
    t_sorted, _ = torch.sort(t_all, dim=-1)
    deltas_fine = t_sorted[..., 1:] - t_sorted[..., :-1]
    last_delta_fine = torch.full_like(deltas_fine[..., :1], 1e10)
    deltas_fine = torch.cat([deltas_fine, last_delta_fine], dim=-1)
    deltas_fine = deltas_fine * rays_d.norm(dim=-1, keepdim=True)
    
    sigma_fine = F.relu(raw_sigma_fine)
    alpha_fine = 1.0 - torch.exp(-sigma_fine * deltas_fine)
    
    transmittance_fine = torch.cumprod(torch.cat([torch.ones_like(alpha_fine[..., :1]), 
                                                  1.0 - alpha_fine + 1e-10], dim=-1), dim=-1)[..., :-1]
    
    weights_fine = transmittance_fine * alpha_fine
    
    # Compute RGB
    rgb_fine = torch.sigmoid(raw_rgb_fine)
    rgb_map = torch.sum(weights_fine[..., None] * rgb_fine, dim=-2)
    
    # Compute Depth and Accumulation
    depth_map = torch.sum(weights_fine * t_sorted, dim=-1)
    acc_map = torch.sum(weights_fine, dim=-1)
    
    # Optional: White background
    # rgb_map = rgb_map + (1.0 - acc_map[..., None])
    
    return rgb_map, depth_map, acc_map
```

## Subtopics

### [NeRF Training Configuration](1203-nerf-training-configuration.md)
Defines the optimization loop, data handling, and regularization strategies required to train a NeRF model. It distinguishes itself by focusing on the standard MLP architecture and training dynamics, unlike [NeRF-SH](1348-nerf-sh.md) which modifies the output representation.

### [NeRF-SH](1348-nerf-sh.md)
Replaces direct RGB output with spherical harmonic coefficients, enabling efficient storage of view-dependent appearance and faster rendering.

### [Recursive-NeRF](3029-recursive-nerf.md)
Routes query points through a hierarchy of branch networks based on predicted uncertainty, adapting to scene complexity dynamically.

### [Mip-NeRF](3381-mip-nerf.md)
Renders anti-aliased conical frustums instead of infinitesimal rays to reduce aliasing artifacts and improve fine detail representation.

### [NeMF (Neural Microflake Field)](3387-nemf-neural-microflake-field.md)
Represents scenes as a distribution of microflakes to recover physical attributes like shape and reflectance under unknown illumination.

### [EgoNeRF](4096-egonerf.md)
Adapts NeRF for large-scale, unbounded scenes captured via egocentric video using a balanced spherical feature grid.

### [Intrinsic NeRF](4623-intrinsic-nerf.md)
Decouples geometry, illumination, and material properties for intrinsic image decomposition without supervised labels.

## Operating characteristics
*   **Time Complexity:** Training is computationally expensive. A typical run on the 'Lego' scene (400x400) takes ~200k iterations, which can take ~20 hours on a single GPU (e.g., 2080 Ti) [S4, unofficial]. Rendering is slower than explicit methods because it requires querying the MLP for every sample point along every ray [S3, unofficial].
*   **Memory Complexity:** The model weights are small (~5MB) [S3, unofficial], but rendering requires storing intermediate tensors for all sample points along all rays, which can be memory-intensive. Chunking (e.g., 4096 rays per batch) is used to manage GPU memory [S4, S8, unofficial].
*   **Performance:** On the NeRF-Synthetic benchmark (400x400, 100k-200k iterations), NeRF achieves high fidelity: Lego (~32.5 dB PSNR, 0.961 SSIM), Chair (~33.0 dB PSNR, 0.967 SSIM), Drums (~25.0 dB PSNR, 0.925 SSIM) [S4, S5, unofficial].
*   **Strengths:** High-quality novel view synthesis, handles complex geometry and view-dependent effects (specularity, transparency) naturally [S1, S3, unofficial].
*   **Limitations:** Slow training and rendering times compared to explicit methods [S8, unofficial]. Sensitive to hyperparameters like positional encoding frequencies and sampling strategies [S4, unofficial]. Can suffer from "floaters" or artifacts in unobserved regions if not regularized [S1, S2, unofficial].

## Background
NeRF was introduced by Ben Mildenhall, Pratul P. Srinivasan, Matthew Tancik, Jonathan T. Barron, Ravi Ramamoorthi, and Ren Ng in 2020 in the paper "NeRF: Representing Scenes as Neural Radiance Fields for View Synthesis" (arXiv:2003.08934) [S3, unofficial]. It builds on the concept of differentiable volume rendering and the use of Fourier features for neural networks [S2, S5, unofficial]. The method has become a foundational technique in neural rendering, inspiring numerous variants and applications in AR/VR, autonomous driving, and 3D reconstruction [S4, unofficial].
