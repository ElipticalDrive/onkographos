# Sparse Voxel Grid Optimization

Also called: Sparse Voxel Rasterization (SVRaster), SVRecon

## Overview
Sparse Voxel Grid Optimization is a method for optimizing explicit 3D voxel structures to minimize photometric loss between rendered and ground-truth images, building on [Hierarchical Grid Optimization](1414-hierarchical-grid-optimization.md). It differs from siblings like [Plenoxels](7440-plenoxels.md) by using a dynamic sparse octree that grows and prunes during training, allowing it to achieve high fidelity and real-time rendering speeds without requiring a fixed, memory-intensive uniform grid. Unlike [Explicit Radiance Fields](806-explicit-radiance-fields.md) which may use static structures, this method actively manages voxel occupancy to balance detail and performance.

## How it works
**Inputs:** A set of calibrated images with known camera poses.
**Outputs:** An optimized sparse octree representation containing density ($\sigma$) and color ($\mathbf{c}$) attributes per voxel, and optionally Signed Distance Function (SDF) values for surface reconstruction.

**Data Structures:**
The method uses an octree structure. Each node represents a voxel.
*   **Morton Code:** Used for sorting and spatial indexing. 48-bit Morton codes are used for 16 levels of hierarchy (3 bits per level) [S1].
*   **Voxel Attributes:**
    *   Density ($\sigma$): Stored as raw values, initialized to a negative constant.
    *   Color ($\mathbf{c}$): RGB values.
    *   SDF (optional): Values at voxel corners for surface reconstruction [S2, unofficial].
*   **Hierarchy:** Parent-child and sibling relations are tracked via Morton codes and auxiliary fine-grid indices [S2, unofficial].

**Algorithm Steps:**

1.  **Initialization:**
    *   Start with an empty space.
    *   Set initial raw density $\sigma_{init} = -10$ [S1].
    *   Initialize the octree to level $h_{lv} = 6$ (corresponding to a $64^3$ grid) for the foreground main region [S1].
    *   For unbounded scenes, add $h_{out} = 5$ background shell levels, with a voxel count ratio $h_{ratio} = 2$ times the foreground voxels [S1].
    *   If using SVRecon for surface reconstruction, initialize SDF signs based on $PI^3$ point-map priors aligned to ground-truth poses, flipping signs to account for visual occlusion [S2, unofficial].

2.  **Rendering (Differentiable Volume Rendering):**
    *   For each ray $\mathbf{r}$, intersect with the sparse octree to find active voxels.
    *   Sort voxels along the ray using Morton codes [S1].
    *   Compute transmittance $T_i$ and color $\hat{C}(\mathbf{r})$ using the standard emission-absorption model:
        $$
        \hat{C}(\mathbf{r}) = \sum_{i=1}^N T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i
        $$
        where $T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)$ [S1, S5].
    *   For SVRecon, use Alpha Blending with the NeuS Cumulative Distribution Function (CDF) [S2, unofficial].
    *   Apply early ray stopping if transmittance $T < h_T = 10^{-4}$ [S1].
    *   Use supersampling scale $h_{ss} = 1.5$ for standard rendering [S1].

3.  **Loss Computation:**
    *   Compute photometric loss $\mathcal{L}_R$ (per-point RGB loss) [S1].
    *   Compute SSIM loss $\mathcal{L}_{ssim}$ [S1].
    *   Compute transmittance loss $\mathcal{L}_T$ to encourage binary transmittance (0 or 1) [S1].
    *   Compute distortion loss $\mathcal{L}_{dist}$ [S1].
    *   Compute total variation loss $\mathcal{L}_{tv}$ on the sparse density grid [S1].
    *   For mesh reconstruction (SVRecon), add depth-normal consistency losses $\mathcal{L}_{n-dmean}$ and $\mathcal{L}_{n-dmed}$ [S1].
    *   For SVRecon, add Laplacian loss over fine grid cells and local Eikonal terms enforcing $|\nabla SDF| = 1$ [S2, unofficial].

    Total Loss:
    $$
    \mathcal{L} = \lambda_{ssim} \mathcal{L}_{ssim} + \lambda_T \mathcal{L}_T + \lambda_{dist} \mathcal{L}_{dist} + \lambda_R \mathcal{L}_R + \lambda_{tv} \mathcal{L}_{tv} + \lambda_{n-dmean} \mathcal{L}_{n-dmean} + \lambda_{n-dmed} \mathcal{L}_{n-dmed}
    $$
    where $\lambda$ are loss weights [S1].

4.  **Optimization and Structure Management:**
    *   Train for $h_{iter} = 20,000$ iterations [S1].
    *   Every $h_{every} = 1,000$ iterations, prune and subdivide voxels [S1].
    *   **Pruning:** Remove voxels with density below a threshold $h_{prune}$. The threshold is linearly scaled from 0.0001 to 0.05 over the training duration [S1].
    *   **Subdivision:** Subdivide voxels with density above a certain percentile (top $h_{percent} = 5\%$) [S1].
    *   **Gradient Computation:** Use reverse-mode automatic differentiation or analytic inversion to compute gradients with respect to $\sigma$ and $\mathbf{c}$ [S5].

**Pseudocode:**

```python
def sparse_voxel_optimization(images, poses, num_iterations=20000, every=1000):
    # 1. Initialization
    octree = Octree(level=6) # 64^3 initial grid
    octree.set_density(-10)  # h_geo = -10
    
    # 2. Training Loop
    for iter in range(num_iterations):
        # 2a. Render
        rendered_images = []
        for img, pose in zip(images, poses):
            rays = generate_rays(pose)
            # Sort rays/voxels by Morton code
            sorted_voxels = octree.sort_by_morton(rays)
            # Differentiable rasterization
            color = render_volume(sorted_voxels, rays)
            rendered_images.append(color)
            
        # 2b. Compute Loss
        loss = 0
        loss += lambda_ssim * ssim_loss(rendered_images, images)
        loss += lambda_R * rgb_loss(rendered_images, images)
        loss += lambda_T * transmittance_loss(rendered_images)
        loss += lambda_dist * distortion_loss(rendered_images)
        loss += lambda_tv * total_variation_loss(octree.density)
        
        # 2c. Backpropagation
        gradients = compute_gradients(loss, octree)
        update_octree(octree, gradients)
        
        # 2d. Structure Management
        if iter % every == 0:
            # Linearly scale pruning threshold from 0.0001 to 0.05
            prune_threshold = 0.0001 + (iter / num_iterations) * (0.05 - 0.0001)
            octree.prune(prune_threshold)
            octree.subdivide(percentile=5) # Subdivide top 5% densest voxels
            
    return octree
```

## Subtopics

### Adaptive Voxel Size
A technique where voxels are subdivided adaptively based on detail requirements, as opposed to uniform subdivision until a fixed grid resolution is reached. On the Mip-NeRF360 dataset, adaptive voxel size achieves LPIPS 0.200 and PSNR 28.01 at 171 FPS, outperforming uniform $512^3$ grids (LPIPS 0.326, PSNR 25.37, 190 FPS) and significantly beating Plenoxels ($640^3$ grid, LPIPS 0.452, PSNR 23.29, <10 FPS) [S1]. Uniform $1024^3$ grids cause Out Of Memory (OOM) on 24GB GPUs, while adaptive methods avoid this by only refining necessary regions [S1].

### SVRecon
A generalization of SVRaster to surface reconstruction by parametrizing each voxel with SDF values at its corners, enabling implicit geometry regularization and extraction of watertight meshes [S2, unofficial]. It uses trilinear interpolation for SDF values and Alpha Blending with the NeuS CDF [S2, unofficial]. Hierarchical data structures track parent-child relations via Morton codes, with bitmask-based occupancy and neighbor search for cross-voxel Laplacian smoothness [S2, unofficial]. Initialization uses $PI^3$ point-map priors, and regularization combines parent-child continuity, Laplacian loss, and local Eikonal terms [S2, unofficial]. SVRecon achieves a Chamfer distance of <5 mm on DTU (15 scenes) and an F1 score of <7 on Tanks-and-Temples in 12 minutes, outperforming SVRaster density-based reconstruction [S2, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
*   **Memory:** Uses significantly less memory than uniform grids (e.g., $1024^3$ causes OOM) but more than Gaussian primitives due to the number of voxel primitives [S1]. LiteVoxel variant reduces peak VRAM by up to 60% compared to standard SVRaster [S2, unofficial].
*   **Speed:** Rendering speed is comparable to 3DGS, with FPS varying by scene. On Mip-NeRF360, it achieves ~121 FPS (standard) and >2x FPS with fast-render settings ($h_{ss}=1.5, h_{prune}=0.15$) [S1]. Training time is ~15 minutes on Mip-NeRF360, with a fast-train variant achieving >3x speedup by scaling iteration-related hyperparameters by 0.3 [S1].

**Strengths and Limitations:**
*   **Strengths:** High fidelity (better LPIPS than 3DGS and Zip-NeRF), real-time rendering, scalable to higher resolutions without OOM, compatible with grid-based algorithms (Marching Cubes, Voxel Pooling) [S1][S2, unofficial].
*   **Limitations:** Struggles with severe exposure variation in training views, leading to brightness boundaries and floaters (worse PSNR/FPS on Tanks&Temples) [S1]. Disjoint voxel design requires explicit continuity losses for smooth geometry [S2, unofficial]. Depth-quantile pruning depends on robust view coverage [S2, unofficial].

## Background
Sparse Voxel Grid Optimization originated from the need for real-time, high-fidelity radiance field rendering. It builds on hierarchical grid optimization and sparse voxel technologies. The method was introduced in "Sparse Voxels Rasterization: Real-time High-fidelity Radiance Field Rendering" [S1] and further extended for surface reconstruction in "Sparse Voxel Rasterization (SVRaster)" [S2, unofficial]. It addresses the limitations of uniform grids (memory) and neural implicit fields (speed) by using a dynamic sparse structure.
