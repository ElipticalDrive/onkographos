# Sparse Voxel Grid Optimization

Also called: Sparse Voxel Rasterization (SVRaster) optimization, Sparse Voxel Grid Training

## Overview
Sparse Voxel Grid Optimization is a method for optimizing radiance fields using a dynamically managed sparse octree of voxels, enabling real-time novel-view synthesis and surface reconstruction. It differs from dense grid methods (like [Instant NGP](1414-hierarchical-grid-optimization.md)) by storing data only in occupied regions, and from Gaussian splatting ([3D Gaussian Splatting](1414-hierarchical-grid-optimization.md)) by using spatially disjoint, axis-aligned voxels with explicit continuity enforcement. It solves the memory bottleneck of high-resolution dense grids while maintaining high rendering speeds through direct voxel rasterization.

## How it works
**Inputs:** A set of calibrated images with known camera poses.
**Outputs:** A sparse octree representation of density and color, optimized for rendering.

**Data Structures:**
The core structure is a sparse octree. Each node at level $l$ represents a voxel.
*   **Morton Code:** Used for sorting and spatial indexing. For 16 levels, each level uses 3 bits, resulting in a 48-bit Morton code for ordering primitives [S1].
*   **Voxel Content:**
    *   For novel-view synthesis: Density ($\sigma$) and color ($\mathbf{c}$) per sample point.
    *   For mesh reconstruction: Signed Distance Function (SDF) values at voxel corners [S2, unofficial].
*   **Hierarchy:** Parent-child and sibling relations are tracked via Morton codes and auxiliary fine-grid indices [S2, unofficial].

**Optimization Steps:**

1.  **Initialization:**
    *   Start from empty space with raw density $\sigma = -10$ [S1].
    *   Initialize the octree level to $h_{lv} = 6$ (64$^3$ voxels) for bounded scenes or the foreground region of unbounded scenes [S1].
    *   For unbounded scenes, add $h_{out} = 5$ background shell levels with a ratio $h_{ratio} = 2$ times the number of foreground voxels [S1].
    *   [G] Ensure the root node exists and child pointers are initialized to null.

2.  **Rendering (Forward Pass):**
    *   Cast rays through the scene.
    *   Intersect rays with voxels in 3D space [S1].
    *   Sample points inside voxels: $K=1$ point for novel-view synthesis, $K=3$ points for mesh reconstruction [S1].
    *   Compute transmittance $T_i$ and color $\hat{C}(\mathbf{r})$ using the standard emission-absorption model [S1][S5]:
        $$ \hat{C}(\mathbf{r}) = \sum_{i=1}^N T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i $$
    *   Apply early ray stopping with threshold $h_T = 10^{-4}$ [S1].
    *   For SVRecon, use NeuS CDF for alpha blending and trilinear interpolation of SDFs [S2, unofficial].

3.  **Loss Computation:**
    *   **Novel-View Synthesis Loss:**
        $$ \mathcal{L} = \lambda_{\text{ssim}} \mathcal{L}_{\text{ssim}} + \lambda_{\text{T}} \mathcal{L}_{\text{T}} + \lambda_{\text{dist}} \mathcal{L}_{\text{dist}} + \lambda_{\text{R}} \mathcal{L}_{\text{R}} + \lambda_{\text{tv}} \mathcal{L}_{\text{tv}} $$
        where $\mathcal{L}_{\text{T}}$ encourages binary transmittance, $\mathcal{L}_{\text{dist}}$ is distortion loss, $\mathcal{L}_{\text{R}}$ is RGB loss, and $\mathcal{L}_{\text{tv}}$ is total variation on the sparse density grid [S1].
    *   **Mesh Reconstruction Loss:**
        $$ \mathcal{L}_{\text{mesh}} = \lambda_{\text{n-dmean}} \mathcal{L}_{\text{n-dmean}} + \lambda_{\text{n-dmed}} \mathcal{L}_{\text{n-dmed}} $$
        encouraging alignment between rendered normals and depth-derived normals [S1].
    *   **SVRecon Specifics:** Includes parent-child continuity, Laplacian loss over fine grid cells, and local Eikonal terms [S2, unofficial].

4.  **Backpropagation:**
    *   Compute gradients with respect to voxel densities, colors, and SDF values using the differentiable rendering operator [S1].

5.  **Sparse Structure Management (Pruning and Subdivision):**
    *   Perform pruning and subdivision every $h_{every} = 1,000$ iterations [S1].
    *   **Pruning:** Remove voxels with density below a threshold $h_{prune}$. Linearly scale $h_{prune}$ from 0.0001 to 0.05 during training [S1].
    *   **Subdivision:** Subdivide voxels if they exceed a detail threshold, maintaining a subdivision percentage $h_{percent} = 5$ [S1].
    *   [G] When subdividing, initialize child densities based on the parent's value or zero, depending on the specific implementation of the "empty space" start.

**Pseudocode:**

```python
def optimize_sparse_voxel_grid(images, poses, iterations=20000):
    # 1. Initialization
    octree = SparseOctree(initial_level=6)
    octree.set_raw_density(-10)
    
    # For unbounded scenes
    octree.add_background_shells(levels=5, ratio=2)
    
    optimizer = Adam(octree.parameters())
    
    for step in range(iterations):
        # 2. Random Ray Sampling
        ray = sample_random_ray(images, poses)
        
        # 3. Forward Rendering
        # Intersect ray with sparse voxels
        hits = octree.ray_intersect(ray)
        
        # Sample points within voxels
        samples = []
        for hit in hits:
            if is_mesh_task:
                samples.extend(hit.sample_points(K=3))
            else:
                samples.append(hit.sample_point(K=1))
        
        # Compute transmittance and color
        transmittance = 1.0
        color = vec3(0.0)
        for sample in samples:
            sigma = octree.get_density(sample)
            c = octree.get_color(sample)
            delta = sample.distance_to_next()
            
            alpha = 1.0 - exp(-sigma * delta)
            weight = transmittance * alpha
            color += weight * c
            transmittance *= (1.0 - alpha)
            
            if transmittance < 1e-4:
                break
        
        # 4. Loss Calculation
        loss = compute_loss(color, ray.gt_color)
        if is_mesh_task:
            loss += compute_mesh_loss(octree, ray)
            
        # 5. Backpropagation
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        # 6. Structure Management
        if step % 1000 == 0:
            prune_threshold = linear_scale(0.0001, 0.05, step / iterations)
            octree.prune(prune_threshold)
            octree.subdivide(percent=5)
```

## Subtopics

### Adaptive Voxel Size
Adaptive voxel size subdivides voxels based on detail requirements rather than reaching a fixed uniform grid resolution. It achieves higher quality (LPIPS 0.200, PSNR 28.01) than uniform 512$^3$ grids (LPIPS 0.326, PSNR 25.37) while using less memory, avoiding OOM errors seen at 1024$^3$ resolution. It outperforms Plenoxels (640$^3$) in both quality and speed [S1].

### SVRecon
SVRecon generalizes SVRaster to surface reconstruction by parametrizing each voxel with SDF values at its corners. It uses trilinear interpolation for SDFs, NeuS CDF for alpha blending, and bitmask-based neighbor search for Laplacian smoothness. It achieves better Chamfer distance on DTU (5 mm vs 6 mm) and higher F1 score on Tanks-and-Temples than SVRaster density-based methods [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Rendering speed is comparable to 3D Gaussian Splatting, with FPS varying by scene. Sorting 48-bit Morton codes is used for primitive ordering [S1].
*   **Memory Complexity:** Uses significantly less memory than dense grids (e.g., 1024$^3$ causes OOM on 24GB GPU) but more than Gaussian splatting due to voxel primitives [S1]. LiteVoxel variant reduces peak VRAM by up to 60% compared to standard SVRaster [S2, unofficial].
*   **Performance:** On Mip-NeRF-360, achieves 121 FPS with 15 minutes training time, LPIPS 0.185, PSNR 27.33 [S1]. Fast-render variant achieves >2x FPS with moderate quality reduction [S1]. Fast-train variant achieves >3x speedup [S1].
*   **Strengths:** High resolution scalability, real-time rendering, explicit geometry extraction (SVRecon).
*   **Limitations:** Struggles with severe exposure variations in training views, leading to brightness boundaries and floaters [S1]. Disjoint voxel design requires explicit continuity losses [S2, unofficial].

## Background
Sparse Voxel Grid Optimization originated from the need to combine the high fidelity of neural radiance fields with the efficiency of sparse voxel structures. It was introduced in "Sparse Voxels Rasterization: Real-time High-fidelity Radiance Field Rendering" (CVPR 2025) [S1]. The method builds on hierarchical grid optimization principles [1414-hierarchical-grid-optimization.md] and extends them with dynamic pruning and subdivision. SVRecon, a variant for surface reconstruction, was later proposed by Oh et al. (2025) [S2, unofficial].
