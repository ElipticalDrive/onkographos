# PlenOctree Conversion

Also called: NeRF-SH to PlenOctree conversion, PlenOctree extraction

## Overview
PlenOctree Conversion is a pipeline that transforms a trained NeRF-SH model into a sparse octree representation for real-time volume rendering [S1, unofficial]. It solves the performance bottleneck of conventional NeRFs, which require dense sampling and neural network inference for every ray step dependent on viewing direction [S1, unofficial]. Unlike [Analytic Derivatives of PlenOctree Rendering](1360-analytic-derivatives-of-plenoctree-rendering.md), which focuses on differentiable optimization of the octree structure, this method focuses on the construction and tabulation of the view-dependent volume from a pre-trained network [S1, unofficial].

## How it works
**Inputs:** A trained NeRF-SH model that outputs density $\sigma$ and spherical harmonics (SH) coefficients for a 3D position $\mathbf{x}$, removing the need for view-direction input to the network [S1, unofficial].
**Outputs:** A sparse octree where each leaf stores a density value $\sigma$ and SH coefficients representing view-dependent radiance [S1, unofficial].

**Data Structures:**
*   **Octree Leaf:** Stores a single density value $\sigma$ and a vector of SH coefficients [S1, unofficial].
*   **Voxel Grid:** A uniformly spaced 3D grid used during the initial evaluation phase [S1, unofficial].

**Parameters:**
*   $\tau_w$: Threshold for maximum ray weight to determine retained voxels [S1, unofficial].
*   $\tau_a$: Density threshold used to compute the scene bounding box for grid scaling [S1, unofficial].
*   $N_{\text{samples}}$: Number of random points sampled per voxel to reduce aliasing; value is 256 [S1, unofficial].
*   $\gamma$: Early-stopping transmittance threshold during rendering; value is 0.01 [S1, unofficial].

**Steps:**
1.  **Evaluation:** Evaluate the NeRF-SH model to obtain $\sigma$ values on a uniformly spaced 3D grid [S1, unofficial]. The grid is automatically scaled to tightly fit the scene by pre-evaluating $\sigma$ on a larger grid and finding the bounding box of all points where $\sigma \ge \tau_a$ [S1, unofficial].
2.  **Filtering:** Render alpha maps for all training views using the voxel grid to track the maximum ray weight $1 - \exp(-\sigma_i \delta_i)$ at each voxel, where $\delta_i$ is the segment length [S1, unofficial]. Eliminate voxels whose weights are lower than $\tau_w$ [S1, unofficial]. Filtering by maximum ray weight eliminates non-visible voxels and is superior to naively thresholding by $\sigma$ at each point [S1, unofficial].
3.  **Sampling:** For each remaining voxel, sample $N_{\text{samples}} = 256$ random points within the voxel volume [S1, unofficial]. Set the associated octree leaf to the mean of the sampled density and SH coefficients to reduce aliasing [S1, unofficial].

**Pseudocode:**
```python
import math
import random

class Voxel:
    def __init__(self, center, size):
        self.center = center
        self.size = size
        self.weight = 0.0
        self.sigma = 0.0
        self.sh_coeffs = []

class PlenOctree:
    def __init__(self):
        self.leaves = []
    def add_leaf(self, voxel):
        self.leaves.append(voxel)

def generate_large_uniform_grid():
    # [G] Standard grid generation returning a list of 3D points
    points = []
    for x in range(-10, 11):
        for y in range(-10, 11):
            for z in range(-10, 11):
                points.append([x * 0.5, y * 0.5, z * 0.5])
    return points

def convert_nerf_to_plenoctree(nerf_sh_model, training_views, tau_w, tau_a):
    # Step 1: Evaluation
    large_points = generate_large_uniform_grid()
    bounding_box_points = [p for p in large_points if nerf_sh_model(p)[0] >= tau_a]
    min_coord = [min(p[i] for p in bounding_box_points) for i in range(3)]
    max_coord = [max(p[i] for p in bounding_box_points) for i in range(3)]
    
    grid_size = 64
    voxel_size = [(max_coord[i] - min_coord[i]) / grid_size for i in range(3)]
    grid_voxels = []
    for x in range(grid_size):
        for y in range(grid_size):
            for z in range(grid_size):
                center = [min_coord[i] + voxel_size[i] * (x + 0.5) for i in range(3)]
                grid_voxels.append(Voxel(center, voxel_size))
    
    for v in grid_voxels:
        sigma, sh = nerf_sh_model(v.center)
        v.sigma = sigma
        v.sh_coeffs = sh

    # Step 2: Filtering
    for v in grid_voxels:
        max_w = 0.0
        for view in training_views:
            delta = v.size[0]
            w = 1.0 - math.exp(-v.sigma * delta)
            if w > max_w:
                max_w = w
        v.weight = max_w
    
    retained_voxels = [v for v in grid_voxels if v.weight >= tau_w]

    # Step 3: Sampling
    octree = PlenOctree()
    for v in retained_voxels:
        sample_sigs = []
        sample_shs = []
        for _ in range(256):
            offset = [random.uniform(-v.size[i]/2, v.size[i]/2) for i in range(3)]
            sample_pos = [v.center[i] + offset[i] for i in range(3)]
            s, sh = nerf_sh_model(sample_pos)
            sample_sigs.append(s)
            sample_shs.append(sh)
        
        mean_sig = sum(sample_sigs) / len(sample_sigs)
        mean_sh = [sum(c) / len(sample_sigs) for c in zip(*sample_shs)]
        
        v.sigma = mean_sig
        v.sh_coeffs = mean_sh
        octree.add_leaf(v)
        
    return octree
```

**Edge Cases and Pitfalls:**
*   **Precision:** The full extraction process takes approximately 15 minutes [S1, unofficial].
*   **Boundaries:** The grid must be tightly scaled to the scene to avoid wasting memory on empty space [S1, unofficial].
*   **Degenerate Input:** Setting $\tau_w$ too high removes too many voxels, causing visual artifacts; setting it too low retains non-visible voxels, reducing sparsity [S1, unofficial].

## Subtopics

### [PlenOctree](1366-plenoctree.md)
An octree-based 3D representation that enables real-time rendering of NeRFs by pre-tabulating view-dependent radiance into a sparse voxel structure. It stores density and SH coefficients at leaves, encoding view-dependent appearance. Unlike naive NeRF rendering, which cannot cache color values due to viewing direction dependency, PlenOctrees store these dependencies explicitly, allowing acceleration without sacrificing free-viewpoint quality. Rendering accelerates by skipping large voxels in one step and applying early-stopping when accumulated transmittance falls below $\gamma = 0.01$.

## Operating characteristics
*   **Time Complexity:** The conversion process (evaluation, filtering, sampling) takes about 15 minutes [S1, unofficial].
*   **Memory Complexity:** The sparse octree structure reduces memory requirements compared to dense voxel grids [S1, unofficial].
*   **Strengths:** Preserves view-dependent effects; enables real-time rendering by replacing online queries with direct lookups [S1, unofficial].
*   **Limitations:** Requires a trained NeRF-SH model; conversion time is non-trivial [S1, unofficial].
*   **When to use:** When real-time rendering of view-dependent scenes is required without sacrificing quality [S1, unofficial].

## Background
PlenOctree Conversion was introduced to address the slow rendering speed of NeRFs, which require dense sampling and neural network inference for every sample dependent on viewing direction [S1, unofficial]. The approach factorizes appearance via closed-form spherical basis functions, specifically spherical harmonics, to enable real-time rendering [S1, unofficial]. It builds on the concept of plenoptic functions by Adelson and Bergen [S1, unofficial].
