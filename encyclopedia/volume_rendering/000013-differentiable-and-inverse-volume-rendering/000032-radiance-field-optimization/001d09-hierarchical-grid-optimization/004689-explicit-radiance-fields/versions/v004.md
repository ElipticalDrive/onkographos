# Explicit Radiance Fields

Also called: Explicit Radiance Fields Reconstruction via Gauss-Newton, Non-linear least-squares volumetric reconstruction, PERF (Performant Explicit Radiance Fields), PERF reconstruction, Volumetric reconstruction with explicit voxels

## Overview
Explicit Radiance Fields (PERF) formulates image-based 3D reconstruction as a non-linear least-squares problem solved explicitly without neural networks [S2]. It represents the scene with a voxel grid for the foreground and a hierarchy of environment maps for the background, optimizing color and opacity values directly via a Gauss-Newton solver [S2]. Unlike [Plenoxels](7440-plenoxels.md) which uses neural networks for view-dependent color, PERF assumes diffuse surfaces and achieves significantly faster convergence by leveraging analytical gradients and iterative linear solvers [S2].

## How it works
**Inputs:** A set of calibrated images of a scene [S2].
**Outputs:** A voxel grid containing color ($C$) and differential opacity ($\sigma$) values, and a hierarchy of environment maps containing color and opacity texels [S2].

**Data Structures:**
1.  **Voxel Grid:** A 3D grid where each cell stores three color channels $C = \{c_r, c_g, c_b\}$ and one differential opacity $\sigma$ [S2].
2.  **Environment Maps:** A hierarchical set of cubemap environment maps surrounding the scene. Each texel stores color and opacity [S2]. The distance of the maps increases with the square of the distance to the voxel grid [S2].
3.  **Storage:** Grid data is stored in CUDA 3D surfaces; environment maps in cube maps. Backing storage is copied to regular memory for kernels using atomics. CUDA texture objects are bound to surfaces for hardware trilinear interpolation [S2].

**Algorithm Steps:**
1.  **Initialization:** Start at the lowest hierarchical level (e.g., $32^3$ voxels, $32 \times 32$ cubemap faces). Initialize colors randomly and opacity to low values [S2].
2.  **Hierarchical Loop:** For each level (typically 4-5 levels, doubling resolution each time):
    a.  **Optimization:** Run the Gauss-Newton solver for a fixed number of iterations (typically $N=30$) [S2].
    b.  **Upsampling:** Upon completion, store the result, reallocate buffers for the next level, and populate new buffers with old data via linear interpolation [S2].
3.  **Gauss-Newton Solver (per iteration):**
    a.  **Forward Pass (Rendering):** For each pixel, compute the accumulated color $\hat{H}$ and accumulated opacity $\hat{T}$ by ray-marching the voxel grid and intersecting environment maps [S2].
    b.  **Residual Calculation:** Compute residuals $r_i$ for each color channel of each pixel: $r_i = \hat{H}_i - C_i$ [S2].
    c.  **Gradient Computation:** Compute the Jacobian-vector products $J_r^T r$ and $J_r^T J_r p$ using analytical derivatives [S2].
    d.  **Linear Solve:** Solve $A \Delta = b$ where $A = J_r^T J_r$ and $b = -J_r^T r$ using Preconditioned Conjugate Gradient (PCG) [S2].
    e.  **Line Search:** Apply backtracking line search to determine step size $\gamma$ [S2].
    f.  **Update:** Update parameters $x_{new} = x_{old} + \gamma \Delta$ [S2].
4.  **Rendering (Evaluation):** Ray-march the voxel grid with jittered steps. Upon exit, intersect with environment maps in order from inner to outer [S2].

**Formulas:**

**Volume Rendering:**
The accumulated color $\hat{H}$ for a ray is computed discretely [S2]:
$$
\hat{H} = \sum_{t=t_n}^{t_f} \hat{T}(t)(1 - e^{-\sigma(t)\delta(t)})c(t)
$$
where transmittance $\hat{T}(t)$ is:
$$
\hat{T}(t) = e^{-\sum_{s=t_n}^{t} \sigma(s)\delta(s)}
$$
In iterative form for samples $i=1 \dots N$ [S2]:
$$
\hat{H} = \sum_{i=1}^N e^{-\sum_{j=1}^{i-1} \sigma_j \delta_j} (1 - e^{-\sigma_i \delta_i}) c_i
$$

**Objective Function:**
Minimize the sum of squared residuals [S2]:
$$
F = 0.5 \sum_{i=1}^{m} r_i(x)^2 = 0.5 \sum_{\text{pixels } p} \sum_{\text{channels } k} (\hat{H}_{p,k} - C_{p,k})^2
$$
where $x$ contains all color and opacity values [S2].

**Auxiliary Opacity Penalty:**
To mitigate view-dependent highlight artifacts (smoke-like artifacts), an auxiliary term $L$ penalizes opacity deviation from 0 or 1 [S2]:
$$
L = \lambda [-4(\hat{T} - 0.5)^2 + 1]
$$
where $\lambda = 0.1$ and $\hat{T}$ is the total accumulated opacity [S2]. This term is added to the residual sum.

**Analytical Derivatives:**
Partial derivatives of $\hat{H}$ with respect to color $c_i$ and opacity $\sigma_i$ are computed by traversing samples backwards [S2]:
$$
V = \sum_{j=1}^N \sigma_j \delta_j, \quad G = \mathbf{0}
$$
For $i = N$ down to $1$:
$$
V \leftarrow V - \sigma_i \delta_i
$$
$$
\frac{\partial \hat{H}}{\partial c_i} = e^{-V} (1 - e^{-\sigma_i \delta_i})
$$
$$
\frac{\partial \hat{H}}{\partial \sigma_i} = G + e^{-V} (1 - e^{-\sigma_i \delta_i}) c_i
$$
$$
G \leftarrow e^{-V} \delta_i e^{-\sigma_i \delta_i} c_i - \delta_i G
$$
*(Note: The source initializes $V$ as an exponential but updates it as a sum; the formula above corrects this to maintain dimensional consistency with the derivative equations.)*

**Linear System Solution (PCG):**
Solve $A \Delta = b$ where $A = J_r^T J_r$ and $b = -J_r^T r$ [S2]. The matrix-vector product $Ap$ is computed as [S2]:
$$
Ap = \sum_i \nabla r_i (\nabla r_i^T p)
$$
where $\nabla r_i$ is the gradient of the residual for ray $i$ [S2].

**Preconditioner:**
Diagonal Jacobi preconditioner $M$ [S2]:
$$
M = \text{diag}(J_r^T J_r) = \left[ \sum_i \left(\frac{\partial r_i}{\partial x_1}\right)^2, \dots, \sum_i \left(\frac{\partial r_i}{\partial x_n}\right)^2 \right]
$$
Preconditioning $M^{-1} r$ simplifies to element-wise division [S2].

**Pseudocode:**

```python
import math

def compute_derivatives(samples_sigma, samples_delta, samples_color):
    """
    Computes partial derivatives of accumulated color H with respect to 
    color c_i and opacity sigma_i for all samples in a ray.
    samples_sigma: list of float [N]
    samples_delta: list of float [N]
    samples_color: list of list of float [N, 3]
    Returns:
        dH_dc: list of list of float [N, 3]
        dH_dsigma: list of list of float [N, 3] (vector gradient)
    """
    N = len(samples_sigma)
    dH_dc = [[0.0, 0.0, 0.0] for _ in range(N)]
    dH_dsigma = [[0.0, 0.0, 0.0] for _ in range(N)]
    
    # V represents the sum of sigma*delta from current step to end
    V = sum(samples_sigma[j] * samples_delta[j] for j in range(N))
    G = [0.0, 0.0, 0.0]
    
    for i in range(N - 1, -1, -1):
        sigma_i = samples_sigma[i]
        delta_i = samples_delta[i]
        c_i = samples_color[i]
        
        # Transmittance from i to end
        exp_V = math.exp(-V)
        exp_sigma_delta = math.exp(-sigma_i * delta_i)
        
        # Derivative w.r.t color
        factor = exp_V * (1.0 - exp_sigma_delta)
        dH_dc[i] = [factor * c_i[0], factor * c_i[1], factor * c_i[2]]
        
        # Update G for opacity derivative
        # G = exp_V * delta_i * exp_sigma_delta * c_i - delta_i * G
        G = [exp_V * delta_i * exp_sigma_delta * c_i[k] - delta_i * G[k] for k in range(3)]
        
        # Derivative w.r.t opacity
        dH_dsigma[i] = [G[k] + factor * c_i[k] for k in range(3)]
        
        # Update V for next iteration (i-1)
        V = V - sigma_i * delta_i

    return dH_dc, dH_dsigma

def pcg_solve(A_func, b, x0, M_inv_func, max_iter=3, eps=1e-6):
    """
    Preconditioned Conjugate Gradient solver.
    A_func: function that computes A*p
    M_inv_func: function that computes M^-1*r
    """
    r = [b[k] - A_func(x0)[k] for k in range(len(b))]
    R_prev = sum(r[k] * r[k] for k in range(len(r)))
    z = M_inv_func(r)
    p = list(z)
    r_dot_z = sum(r[k] * z[k] for k in range(len(r)))
    k = 0
    while True:
        Ap = A_func(p)
        p_dot_Ap = sum(p[k] * Ap[k] for k in range(len(p)))
        alpha = r_dot_z / p_dot_Ap
        x_new = [x0[k] + alpha * p[k] for k in range(len(x0))]
        r_new = [r[k] - alpha * Ap[k] for k in range(len(r))]
        R = sum(r_new[k] * r_new[k] for k in range(len(r_new)))
        if R < eps or R / R_prev > 0.85:
            return x_new
        R_prev = R
        z = M_inv_func(r_new)
        r_new_dot_z = sum(r_new[k] * z[k] for k in range(len(r_new)))
        beta = r_new_dot_z / r_dot_z
        p = [z[k] + beta * p[k] for k in range(len(p))]
        r = r_new
        x0 = x_new
        r_dot_z = r_new_dot_z
        k += 1

def line_search(func_error, gamma_init=1.0, alpha_dec=0.7):
    """
    Backtracking line search.
    """
    gamma = gamma_init
    mu_prev = float('inf')
    while True:
        mu = func_error(gamma)
        if mu > mu_prev:
            return gamma / alpha_dec
        gamma = alpha_dec * gamma
        mu_prev = mu
```

**Edge Cases and Pitfalls:**
*   **Sparsity:** The Jacobian $J_r$ is very sparse. Explicit matrix formation is impossible (e.g., 4TB for $32^3$ grid). The algorithm exploits sparsity by computing $Ap$ as a sum over rays [S2].
*   **View Dependence:** The method does not model view-dependent effects. It mitigates artifacts by penalizing intermediate opacity values [S2].
*   **Convergence:** PCG iterations are limited (1-3) to save time. If convergence is slow, the solver exits early and proceeds to the next Gauss-Newton iteration [S2].
*   **Rendering Threshold:** During final rendering, if $(1.0 - \hat{T}) < 0.7$, the volume is considered fully transparent to remove "flying artifacts" [S2].

## Operating characteristics
*   **Time Complexity:** 2-3 orders of magnitude faster than neural network-based methods like NERF [S2]. Example: Pinecone scene ($512^3$ grid) took 24m 54s vs 23h 21m for NERF [S2].
*   **Memory Complexity:** High for the Hessian approximation $J_r^T J_r$, but avoided by iterative solvers. The grid and environment maps fit in GPU memory [S2].
*   **Strengths:** Fast convergence, real-time inspection during training, explicit representation allows clean separation of foreground and background in 360° scenes [S2].
*   **Limitations:** Assumes diffuse surfaces (no view-dependent color), sensitive to initial state, requires careful tuning of hierarchical levels and jittering [S2].
*   **When to use:** When reconstruction speed is critical and scenes are primarily diffuse [S2].
*   **When not to use:** For scenes with significant view-dependent effects (specularities, reflections) [S2].

## Background
Explicit Radiance Fields (PERF) was introduced by Sverker Rasmuson, Erik Sintorn, and Ulf Assarsson from Chalmers University of Technology in 2022 [S2]. The method addresses the slow convergence of neural network-based volume rendering (like NERF) by reformulating the problem as a non-linear least-squares optimization solvable with Gauss-Newton methods [S2]. It builds on the volume rendering equation and differentiable rendering principles [S2].
