# Explicit Radiance Fields

Also called: Explicit Radiance Fields Reconstruction via Gauss-Newton, Non-linear least-squares volumetric reconstruction, PERF (Performant Explicit Radiance Fields), PERF reconstruction, Volumetric reconstruction with explicit voxels

## Overview
Explicit Radiance Fields (also known as PERF) is a method for image-based 3D reconstruction of 360° scenes that formulates volumetric reconstruction as a non-linear least-squares problem solved explicitly without neural networks [S1]. It uses a voxel grid for the foreground and a hierarchical set of environment maps for the background, minimizing the sum of squared differences between accumulated ray colors and actual pixel colors [S1]. Unlike [Plenoxels](1501-plenoxels.md) which uses fixed hierarchical structures, or [Direct Voxel Grid Optimization](4694-direct-voxel-grid-optimization.md) which uses gradient descent, PERF employs a Gauss-Newton solver with Preconditioned Conjugate Gradient, achieving 2-3 orders of magnitude faster convergence than neural network-based methods like NERF [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of images of a scene with known camera poses [S1].
*   **Outputs:** A voxel grid containing color and differential opacity values, and a set of environment maps containing color and opacity values [S1].

**Data Structures:**
1.  **Voxel Grid:** A 3D grid where each cell contains three color channels $C = \{c_r, c_g, c_b\}$ and differential opacity $\sigma$ [S1]. Stored in a 3D surface for CUDA implementation [S1].
2.  **Environment Maps:** A hierarchical set of cubemap environment maps surrounding the object of interest, centered around it. Each texel contains color and opacity [S1]. Their distance increases with the square of the distance to the voxel grid [S1]. Stored in cube maps [S1].
3.  **Backing Storage:** For kernels using atomics, backing storage is copied to regular memory, as atomics are not supported for surfaces [S1]. CUDA texture objects are bound to surfaces for hardware trilinear interpolation [S1].

**Parameters:**
*   $\alpha$: Geometrical decimation factor for line search, set to 0.7 [S1].
*   $\lambda$: Weight for the auxiliary opacity penalty term, set to 0.1 [S1].
*   Hierarchical Levels: Typically 4-5 levels [S1]. Resolution doubles per level [S1]. Initial resolution: $32^3$ for voxel grid, $32 \times 32$ for cubemaps [S1].
*   Iterations per level: $N=30$ [S1].
*   PCG Iterations: Typically 1-3 iterations [S1].
*   Opacity Threshold: During rendering of converged scene, if $(1.0 - \hat{T}) < 0.7$, volume is considered fully transparent [S1].
*   Final Grid Resolution: Typically $256^3$ or $512^3$ [S1].
*   Environment Maps Resolution: $256^2$ or $512^2$ per cubemap face [S1].
*   Image Resolution: Synthetic scenes run at half image resolution. 360° scenes run at quarter image resolution [S1].

**Steps:**

1.  **Initialization:** Start with a low-resolution voxel grid ($32^3$) and environment maps ($32 \times 32$) [S1]. Initialize with random colors and low opacity [S1].
2.  **Hierarchical Optimization Loop:** For each hierarchical level:
    a.  **Ray Integration (Voxel Grid):** For each pixel, generate a ray [S1]. Ray origin jittering: Position within pixel chosen randomly using two uniformly distributed floats [S1]. Ray sample jittering: Randomize position of samples within half a raymarch step before and after uniform steps along the ray [S1]. Ray-march through the voxel grid using step length equal to the shortest side of a voxel cell [S1]. Compute accumulated color $\hat{H}$ using the discrete volume rendering equation [S1].
    b.  **Ray Integration (Environment Maps):** After exiting the voxel grid, perform intersection tests with environment maps in order from inner to outer [S1]. Accumulate contribution similarly to the voxel grid [S1].
    c.  **Residual Calculation:** Compute residuals $r_i$ for each pixel [S1]. Each pixel has 3 residuals (one per color channel), defined as the difference between pixel color $C$ and accumulated color $\hat{H}$ [S1].
    d.  **Auxiliary Term:** Compute auxiliary penalty $L = \lambda [-4(\hat{T} - 0.5)^2 + 1]$, where $\hat{T}$ is accumulated opacity [S1]. This penalizes opacity deviations from 0 or 1 to mitigate view-dependent highlight artifacts [S1].
    e.  **Derivative Computation:** Compute partial derivatives of the first degree analytically using the iterative algorithm described below [S1].
    f.  **Gauss-Newton Update:** Solve the linear system $A x = b$ where $A = J_r^T J_r$, $x = \Delta$, and $b = -J_r^T r$ [S1]. Use Preconditioned Conjugate Gradient (PCG) to solve for $\Delta$ [S1]. Update $x_{i+1} = x_i + \Delta$ [S1].
    g.  **Line Search:** Backtracking line search scales step size $\gamma$ by $\alpha = 0.7$ if the objective function increases [S1].
    h.  **Level Completion:** When a level completes (after $N=30$ iterations), store result temporarily, reallocate buffers, populate new buffers with old data via linear interpolation, and resume optimization at the new level [S1].

**Formulas:**
*   **Discrete Volume Rendering Equation:**
    $$ \hat{H} = \sum_{t=t_n}^{t_f} \hat{T}(t)(1 - e^{-\sigma(t)\delta(t)})c(t) $$
    where $\hat{T}(t) = e^{-\sum_{s=t}^{t_f} \sigma(s)\delta(s)}$ [S1].
    Expanded form:
    $$ \hat{H} = e^{-\sum_{j=1}^N \sigma_j \delta_j} (1 - e^{-\sigma_1 \delta_1}) c_1 + e^{-\sigma_1 \delta_1} (1 - e^{-\sigma_2 \delta_2}) c_2 + \dots + e^{-\sum_{j=1}^{N-1} \sigma_j \delta_j} (1 - e^{-\sigma_N \delta_N}) c_N $$
    [S1].

*   **Objective Function:**
    $$ F[c(t), \sigma(t)] = 0.5 \sum_{t=t_n}^{t_f} \sum_{i=1}^{3} (\hat{H}_i[c_i(t), \sigma(t)] - C_i)^2 $$
    [S1].

*   **Non-linear Least-Squares General Form:**
    $$ S(x) = 0.5 \sum_{i=1}^{m} r_i(x)^2 $$
    where $r_i$ are residuals [S1].

*   **Gauss-Newton Update:**
    $$ x_{i+1} = x_i - (J_r^T J_r)^{-1} J_r^T r(x_i) = x_i + \Delta $$
    [S1].

*   **PCG System:**
    $$ A p = J_r^T J_r p = \sum_i \nabla r_i (\nabla r_i^T p) $$
    [S1].

*   **Auxiliary Penalty:**
    $$ L = \lambda [-4(\hat{T} - 0.5)^2 + 1] $$
    [S1].

**Pseudocode:**

```python
import math

def compute_derivatives(sigma, delta, c, N):
    # Algorithm 1: Iterative computation of partial derivatives
    V = math.exp(-sum(sigma[i] * delta[i] for i in range(N)))
    G = 0.0
    dH_dc = [0.0] * N
    dH_dsigma = [0.0] * N
    for i in range(N - 1, -1, -1):
        V -= sigma[i] * delta[i]
        dH_dc[i] = math.exp(-V) * (1.0 - math.exp(-sigma[i] * delta[i]))
        dH_dsigma[i] = G + math.exp(-V) * (1.0 - math.exp(-sigma[i] * delta[i])) * c[i]
        G = math.exp(-V) * delta[i] * math.exp(-sigma[i] * delta[i]) * c[i] - delta[i] * G
    return dH_dc, dH_dsigma

def pcg_solve(A_p_func, b, M_inv, x0, eps=1e-6, max_iter=3):
    # Algorithm 2: Preconditioned Conjugate Gradient
    r = [b[i] - A_p_func(x0)[i] for i in range(len(b))]
    R_prev = sum(r[i] * r[i] for i in range(len(r)))
    z = M_inv(r)
    p = list(z)
    k = 0
    while True:
        Ap = A_p_func(p)
        alpha_k = sum(r[i] * z[i] for i in range(len(r))) / sum(p[i] * Ap[i] for i in range(len(p)))
        x_next = [x0[i] + alpha_k * p[i] for i in range(len(x0))]
        r_next = [r[i] - alpha_k * Ap[i] for i in range(len(r))]
        R = sum(r_next[i] * r_next[i] for i in range(len(r_next)))
        if R < eps or R / R_prev > 0.85:
            return x_next
        R_prev = R
        z_next = M_inv(r_next)
        beta_k = sum(r_next[i] * z_next[i] for i in range(len(r_next))) / sum(r[i] * z[i] for i in range(len(r)))
        p = [z_next[i] + beta_k * p[i] for i in range(len(z_next))]
        r = r_next
        x0 = x_next
        k += 1
        if k >= max_iter:
            return x_next

def line_search(gamma, alpha, error_func):
    # Algorithm 3: Backtracking line search
    mu_prev = float('inf')
    while True:
        mu = error_func(gamma)
        if mu > mu_prev:
            return gamma / alpha
        gamma *= alpha
        mu_prev = mu

def gauss_newton_optimization(x, rays, pixel_colors, voxel_grid, env_maps):
    # Main loop: compute residuals, gradients, solve, line search
    b = [0.0] * len(x)
    residuals = []
    for ray, C in zip(rays, pixel_colors):
        # [G] Standard volume rendering: ray-march voxel grid and environment maps to compute accumulated color H_hat
        H_hat = [0.0, 0.0, 0.0]
        residuals.append([H_hat[i] - C[i] for i in range(3)])
        # Compute derivatives for this ray
        dH_dc, dH_dsigma = compute_derivatives(...)
        # Accumulate gradient: b += -r * dH/dx
        for i in range(len(x)):
            b[i] -= sum(residuals[-1][j] * dH_dc[j] for j in range(3))
    # Preconditioner: Diagonal Jacobi M_inv(v) = v / diag(J_r^T J_r)
    def M_inv(v):
        diag_A = [sum(dH_dc[j]**2 for j in range(3)) for _ in range(len(x))]
        return [v[i] / diag_A[i] for i in range(len(v))]
    # A_p function: Ap = sum_i grad_r_i * (grad_r_i^T p)
    def A_p(p):
        Ap = [0.0] * len(x)
        for ray in rays:
            dH_dc, dH_dsigma = compute_derivatives(...)
            grad_r = dH_dc
            dot_prod = sum(grad_r[j] * p[j] for j in range(len(p)))
            for j in range(len(x)):
                Ap[j] += grad_r[j] * dot_prod
        return Ap
    # Solve for update step delta
    delta = pcg_solve(A_p, b, M_inv, x)
    # Line search
    gamma = 1.0
    alpha = 0.7
    new_x = [x[i] + gamma * delta[i] for i in range(len(x))]
    error_new = sum(sum((new_x[i] - pixel_colors[k][j])**2 for j in range(3)) for k, i in enumerate(rays))
    error_old = sum(sum((x[i] - pixel_colors[k][j])**2 for j in range(3)) for k, i in enumerate(rays))
    if error_new > error_old:
        gamma = line_search(gamma, alpha, lambda g: sum(sum((x[i] + g * delta[i] - pixel_colors[k][j])**2 for j in range(3)) for k, i in enumerate(rays)))
        new_x = [x[i] + gamma * delta[i] for i in range(len(x))]
    return new_x
```

**Edge Cases and Pitfalls:**
*   **Sparsity:** $J_r$ is very sparse because only a fraction of voxels/texels are hit by a given ray. This sparsity is exploited to avoid explicit matrix inversion [S1].
*   **View-Dependence:** The method does not consider view-dependent effects, which can lead to smoke-like artifacts [S1].
*   **Precision:** The matrix $A$ is too large to form explicitly (e.g., 4TB for a $32^3$ grid) [S1].
*   **Boundaries:** Environment maps are used to handle rays exiting the voxel grid, ensuring clean separation of foreground and background for 360° scenes [S1].

## Operating characteristics
*   **Time Complexity:** 2-3 orders of magnitude faster than NERF reference [S1]. Example: Pinecone 24m:54s (Ours) vs 23h:21m (NERF) on $512^3$ grid [S1].
*   **Memory Complexity:** The matrix $A$ is too large to form explicitly [S1]. The method uses iterative solvers and sparse operations to manage memory [S1].
*   **Measured Performance:** On Nvidia Titan V GPU [S1]. Synthetic scenes run at half image resolution. 360° scenes run at quarter image resolution [S1].
*   **Scaling:** Uses a hierarchical scheme with 4-5 levels, doubling resolution per level. Initial resolution $32^3$, final $256^3$ or $512^3$ [S1].
*   **Strengths:** Fast convergence due to Gauss-Newton solver. Real-time rendering possible during training [S1]. Clean separation of foreground and background for 360° scenes [S1].
*   **Limitations:** Does not consider view-dependent effects. Quality is comparable to NERF without view-dependence but lower than full NERF or SNeRG [S1].
*   **When to use:** When fast reconstruction of 360° scenes is required and view-dependent effects are not critical [S1].
*   **When not to use:** When high-fidelity view-dependent effects are required [S1].

## Background
Explicit Radiance Fields (PERF) was presented by Sverker Rasmuson, Erik Sintorn, and Ulf Assarsson from Chalmers University of Technology in 2022 [S1]. The method formulates volumetric reconstruction as a non-linear least-squares problem, solving it explicitly without neural networks [S1]. This allows the use of solvers with higher convergence rates than standard Stochastic Gradient Descent used for neural networks [S1]. The work builds on the NERF formulation but replaces the MLP and ADAM optimizer with explicit voxel/environment map representation and Gauss-Newton solver [S1].
