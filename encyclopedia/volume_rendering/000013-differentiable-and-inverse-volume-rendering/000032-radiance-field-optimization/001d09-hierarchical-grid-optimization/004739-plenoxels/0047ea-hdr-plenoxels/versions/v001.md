# HDR-Plenoxels

Also called: HDR radiance fields modeled by Plenoxels

## Overview
HDR-Plenoxels is a voxel-based volume rendering method that reconstructs 3D High Dynamic Range (HDR) radiance fields, scene geometry, and camera settings from multi-view Low Dynamic Range (LDR) images captured under varying exposure, white balance, and camera response functions (CRF) [S1, S2]. It extends Plenoxels by introducing a differentiable tone-mapping module that models the in-camera imaging pipeline, allowing the network to learn HDR radiance and self-calibrate camera parameters end-to-end [S2]. Unlike implicit neural fields, it uses explicit sparse voxel grids with spherical harmonics, achieving rendering speeds two orders of magnitude faster than NeRF while handling saturated regions and extreme exposure conditions robustly [S2].

## How it works
**Inputs:** Multi-view LDR images with varying radiometric settings (exposure, white balance, CRF) and their corresponding camera poses.
**Outputs:** A sparse voxel grid representing the 3D HDR radiance field, learned camera parameters (CRF, white balance), and the ability to render novel views with controllable radiometric settings.

**Data Structures:**
*   **Sparse Voxel Grid:** A 3D grid covering a bounded space of interest.
    *   **Voxel Content:** Each voxel stores:
        *   Opacity $\sigma$: A scalar value.
        *   SH Coefficients: A 27-dimensional vector (9 coefficients per RGB channel) representing view-dependent radiance using Spherical Harmonics (SH) of degree 2 [S2].
    *   **Initialization:** Opacity $\sigma$ is initialized to 0.1; SH coefficients are initialized to represent a grey color by adding an offset of 0.5 to the color values [S2].

**Algorithm Steps:**

1.  **Scene Preprocessing and Grid Initialization:**
    *   For real data, undistort images using camera calibration to correct lens distortion [S2].
    *   Compute rough 3D geometry and camera poses using COLMAP sparse reconstruction to determine the bounding box of the scene [S2].
    *   Initialize a sparse voxel grid. For synthetic data, start with resolution $(128, 128, 64)$; for real data, start with $(128, 128, 128)$ [S2].

2.  **Volume-Aware Rendering to HDR:**
    *   For each ray $\mathbf{r}$, perform volume rendering using the standard emission-absorption model [S1, S5] to compute the HDR radiance $\hat{C}_{HDR}(\mathbf{r})$.
    *   The color at each sample point is determined by interpolating the SH coefficients of the surrounding voxels and evaluating the SH basis functions for the ray direction $\mathbf{d}$ [S2].
    *   The final HDR color is composited as:
        $$ \hat{C}_{HDR}(\mathbf{r}) = \sum_{i=1}^N T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i(\mathbf{d}) $$
        where $\mathbf{c}_i(\mathbf{d})$ is the view-dependent color from SH evaluation [S2].

3.  **Differentiable Tone Mapping:**
    *   Map the composited HDR radiance $\hat{C}_{HDR}$ to LDR intensity $\hat{C}_{LDR}$ using a differentiable tone-mapping module consisting of two stages: White Balance and Camera Response Function (CRF) [S2].
    *   **White Balance:** Apply a scale factor to the RGB channels. The exposure value is represented by a scale of white balance. The basis white balance is set by channel-wise averaging of the full view's white balance values [S2].
    *   **CRF:** Apply a non-linear function modeling the camera's response. The CRF parameters are learned during training [S2].
    *   The tone-mapping function $f_{tone}$ is differentiable:
        $$ \hat{C}_{LDR} = f_{tone}(\hat{C}_{HDR}; \theta_{WB}, \theta_{CRF}) $$
        where $\theta_{WB}$ and $\theta_{CRF}$ are the learnable parameters for white balance and CRF [S2].

4.  **Loss Computation and Backpropagation:**
    *   Compute the loss $\mathcal{L}$ between the synthesized LDR image $\hat{C}_{LDR}$ and the captured LDR image $C_{LDR}$ [S2].
    *   Apply Total Variation (TV) loss to opacity $\sigma$ and SH coefficients to stabilize training, particularly in the early epochs before upsampling [S2].
        $$ \mathcal{L}_{TV} = \lambda_{TV,\sigma} \text{TV}(\sigma) + \lambda_{TV,SH} \text{TV}(\text{SH}) $$
        with $\lambda_{TV,\sigma} = 5 \cdot 10^{-4}$ and $\lambda_{TV,SH} = 1 \cdot 10^{-2}$ [S2].
    *   Backpropagate gradients through the tone-mapping module to update SH coefficients, opacity, and tone-mapping parameters [S2].

5.  **Coarse-to-Fine Optimization:**
    *   Upsample the voxel grid resolution to increase density.
    *   Prune voxels with occupancy below a threshold to reduce computational cost [S2].
    *   Repeat upsampling and pruning at specified intervals [S2].

**Pseudocode:**

```python
def initialize_grid(scene_bounds, initial_res):
    """
    Initialize sparse voxel grid with opacity and SH coefficients.
    """
    grid = SparseVoxelGrid(resolution=initial_res, bounds=scene_bounds)
    # Initialize opacity to 0.1
    grid.opacity = 0.1
    # Initialize SH coefficients to grey (offset 0.5)
    grid.sh_coeffs = 0.5
    return grid

def evaluate_sh(sh_coeffs, direction):
    """
    Evaluate Spherical Harmonics coefficients for a given direction.
    Returns RGB color vector.
    """
    # SH degree 2 basis functions evaluation
    basis = spherical_harmonics_basis_2(direction)
    # sh_coeffs shape: (3, 9) for RGB, 9 coefficients per channel
    # basis shape: (9,)
    color = np.zeros(3)
    for c in range(3):
        color[c] = np.dot(sh_coeffs[c, :], basis)
    return color

def volume_render_ray(ray, grid):
    """
    Render a single ray through the voxel grid to get HDR radiance.
    """
    samples = sample_ray(ray, grid.bounds)
    hdr_color = np.zeros(3)
    transmittance = 1.0
    
    for sample in samples:
        # Interpolate SH coefficients and opacity from grid
        sh_coeffs = interpolate_sh(grid, sample.position)
        opacity = interpolate_opacity(grid, sample.position)
        
        # Evaluate view-dependent color
        color = evaluate_sh(sh_coeffs, ray.direction)
        
        # Volume rendering step
        alpha = 1.0 - np.exp(-opacity * sample.distance)
        hdr_color += transmittance * alpha * color
        transmittance *= (1.0 - alpha)
        
    return hdr_color

def tone_mapping(hdr_color, wb_scale, crf_params):
    """
    Differentiable tone mapping from HDR to LDR.
    """
    # White Balance: Scale channels
    ldr_color = hdr_color * wb_scale
    
    # CRF: Apply non-linear response (e.g., learned function or standard sRGB)
    # Assuming a simple power law or learned mapping for demonstration
    ldr_color = np.power(ldr_color, crf_params)
    
    # Clamp to [0, 1]
    ldr_color = np.clip(ldr_color, 0.0, 1.0)
    return ldr_color

def train_step(images, poses, grid, wb_scales, crf_params, optimizer):
    """
    Single training step.
    """
    optimizer.zero_grad()
    
    synthesized_images = []
    for img, pose in zip(images, poses):
        ray = generate_ray(pose, img.resolution)
        hdr_radiance = volume_render_ray(ray, grid)
        ldr_rendered = tone_mapping(hdr_radiance, wb_scales, crf_params)
        synthesized_images.append(ldr_rendered)
        
    synthesized_images = np.stack(synthesized_images)
    
    # Compute loss
    loss = np.mean((synthesized_images - images) ** 2)
    
    # Add TV loss for stability
    tv_loss = compute_tv_loss(grid.opacity, grid.sh_coeffs)
    loss += 5e-4 * tv_loss_opacity + 1e-2 * tv_loss_sh
    
    loss.backward()
    optimizer.step()
    
    return loss

def coarse_to_fine_update(grid, iteration, upsampling_interval=25600):
    """
    Upsample grid and prune voxels.
    """
    if iteration % upsampling_interval == 0:
        grid.upsample()
        grid.prune(occupancy_threshold=0.01) # Threshold value not specified in sources
    return grid
```

**Parameters:**
*   **Initial Grid Resolution:** Synthetic: $(128, 128, 64)$; Real: $(128, 128, 128)$ [S2].
*   **Upsampling Schedule:** Synthetic: $(256, 256, 128) \rightarrow (512, 512, 256) \rightarrow (800, 800, 512)$ every 25,600 iterations. Real: $(256, 256, 256) \rightarrow (750, 600, 300)$ [S2].
*   **TV Loss Weights:** $\lambda_{TV,\sigma} = 5 \cdot 10^{-4}$, $\lambda_{TV,SH} = 1 \cdot 10^{-2}$ [S2].
*   **Occupancy Threshold:** Used for pruning. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Saturated Regions:** Wide dynamic range scenes cause saturation in LDR inputs. The differentiable tone-mapping module and robust learning of SH coefficients mitigate this [S2].
*   **Large Depth:** Synthetic Blender data may have large depth ranges hard to express with default grids. Solved by computing rough 3D geometry via COLMAP to define the grid bounds [S2].
*   **Lens Distortion:** Real images often have lens distortion. Solved by undistorting images via calibration before training [S2].
*   **Training Instability:** SH coefficients can change significantly during training. Mitigated by initializing color to grey (offset 0.5) and opacity to 0.1 [S2].

## Operating characteristics
*   **Time Complexity:** Training time is tens of minutes [S2].
*   **Memory Complexity:** Uses explicit voxel grids, which are more memory-efficient than dense neural fields for high-resolution scenes, but memory usage scales with grid resolution and SH coefficient storage [S2].
*   **Rendering Speed:** Two orders of magnitude faster than NeRF [S2].
*   **Strengths:** Fast convergence and rendering; handles varying camera settings (exposure, white balance, CRF) end-to-end; robust to saturated regions and extreme exposure conditions; controllable rendering of novel views [S2].
*   **Limitations:** Requires COLMAP for initial geometry and poses; performance degrades slightly with extreme exposure gaps (e.g., ±6EV) [S2].
*   **When to Use:** Novel view synthesis from multi-view LDR images with varying radiometric settings where fast rendering and HDR reconstruction are required [S2].
*   **When Not to Use:** When dense COLMAP results are unavailable or too expensive to compute; when implicit neural representations are preferred for unbounded scenes without grid constraints [S2].

## Background
HDR-Plenoxels was introduced by Kim et al. at POSTECH in November 2022 (arXiv:2208.06787v2) [S2]. It extends the Plenoxels method [53] for HDR radiance fields and adopts the coarse-to-fine training scheme from NSVF [17] [S2]. The method addresses the limitation of standard NeRF and Plenoxels in handling high dynamic range scenes and varying camera conditions by integrating a differentiable tone-mapping module [S2]. It is used for novel view synthesis in synthetic (Blender) and real-world datasets (Character, Desk, Plant, Coffee, Kitchen) [S2].
