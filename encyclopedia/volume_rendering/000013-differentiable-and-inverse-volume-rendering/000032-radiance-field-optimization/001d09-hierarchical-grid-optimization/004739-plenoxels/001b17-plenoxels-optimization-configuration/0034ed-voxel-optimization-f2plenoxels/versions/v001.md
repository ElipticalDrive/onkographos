# Voxel optimization (F2Plenoxels)
Also called: Depth-guided voxel pre-pruning with SH regularization

## Overview
F2Plenoxels is a voxel radiance field optimization method designed for few-shot view synthesis that eliminates neural networks by using depth-guided voxel pre-pruning and spherical harmonic (SH) regularization [S1]. It improves upon baseline Plenoxels by significantly reducing floaters and cluttered artifacts while maintaining high geometry accuracy and appearance fidelity [S1].

## How it works
**Inputs:** Pruned voxel grids for density ($V_D$) and SH coefficients ($V_{SH}$), input images $I = \{I_n\}_{n=1}^S$, camera intrinsics $K = \{K_n\}_{n=1}^S$, and extrinsics $P = \{P_n\}_{n=1}^S$ [S1].
**Outputs:** Optimized voxel grids $V_D$ and $V_{SH}$ [S1].

**Data Structures:**
*   $V_D$: Density voxel grid. Initialized to zeros.
*   $V_{SH}$: Spherical Harmonic coefficient voxel grid. Initialized to zeros.
*   $R$: Batch of training rays.
*   $C$: Batch of corresponding target colors.

**Parameters:**
*   Training duration: $E = 10$ epochs.
*   Iterations per epoch: $N = 2560$.
*   Batch size: 5000 rays.
*   SH degree: 2.
*   SH regularization iterations: $T = 1280$.
*   Density learning rate: Delayed exponential decay, scaled by 15, initial delay 3000 steps, decays to 0.05 at step 50000 [S1].
*   SH learning rate: Pure exponential decay, initial 0.01, decays to $5 \times 10^{-6}$ at step 50000 [S1].
*   Total Variation (TV) regularization weights ($\lambda_\sigma$ for density, $\lambda_k$ for SH):
    *   Blender dataset: $\lambda_\sigma = 5 \times 10^{-4}$, $\lambda_k = 5 \times 10^{-2}$ [S1].
    *   LLFF dataset: $\lambda_\sigma = 2.5 \times 10^{-3}$, $\lambda_k = 2.5 \times 10^{-2}$ [S1].

**Algorithm:**
1.  Initialize $V_D \leftarrow 0$, $V_{SH} \leftarrow 0$ [S1].
2.  Retrieve all training rays and colors: $R, C \leftarrow \text{GetAllTrainingRays}(K, P, I)$ [S1].
3.  For epoch $e$ from 1 to $E$:
    4.  Shuffle $R, C$ [S1].
    5.  For iteration $n$ from 1 to $N$:
        6.  Calculate global iteration count: $i \leftarrow (e - 1) \times N + n$ [S1].
        7.  Sample batch: $R, C \leftarrow \text{GetBatchTrainingRays}(R, C)$ [S1].
        8.  If $i \le T$: Apply SH regularization to $V_{SH}$ [S1].
        9.  Render ray colors: $\hat{C} \leftarrow \text{VolumeRendering}(R, V_D, V_{SH})$ [S1].
        10. Compute loss: $\mathcal{L}_{MSE} \leftarrow \text{MSELoss}(\hat{C}, C)$ [S1].
        11. Update $V_D$ and $V_{SH}$ using RMSProp optimizer with specified learning rate schedules [S1].

**Pseudocode:**
```python
def voxel_optimization(V_D, V_SH, K, P, I, E=10, N=2560, batch_size=5000, T=1280):
    # Initialization
    V_D = zeros_like(V_D)
    V_SH = zeros_like(V_SH)
    
    # Get all rays and colors
    R_all, C_all = GetAllTrainingRays(K, P, I)
    
    # Optimizer setup (RMSProp)
    optimizer_D = RMSProp(V_D, lr_schedule_density)
    optimizer_SH = RMSProp(V_SH, lr_schedule_SH)
    
    for e in range(1, E + 1):
        # Shuffle rays for this epoch
        R_all, C_all = ShuffleAllTrainingRays(R_all, C_all)
        
        for n in range(1, N + 1):
            i = (e - 1) * N + n
            
            # Get batch
            R_batch, C_batch = GetBatchTrainingRays(R_all, C_all, batch_size)
            
            # SH Regularization (only in initial iterations)
            if i <= T:
                V_SH = SHRegularization(V_SH, lambda_k)
                
            # Forward pass
            C_hat = VolumeRendering(R_batch, V_D, V_SH)
            
            # Loss computation
            loss = MSELoss(C_hat, C_batch)
            
            # Backward pass and update
            optimizer_D.zero_grad()
            optimizer_SH.zero_grad()
            
            # Note: The source mentions TV regularization weights lambda_sigma and lambda_k
            # but does not explicitly show the TV loss term in the pseudocode snippet.
            # Assuming TV loss is added to the total loss if applicable, or handled 
            # within the regularization step. Based on "4.1.4 Implementation details",
            # TV regularization is enabled. We add it here for completeness [G].
            tv_loss_density = TotalVariation(V_D) * lambda_sigma
            tv_loss_sh = TotalVariation(V_SH) * lambda_k
            
            total_loss = loss + tv_loss_density + tv_loss_sh
            
            total_loss.backward()
            
            optimizer_D.step()
            optimizer_SH.step()
            
    return V_D, V_SH
```

**Edge Cases and Pitfalls:**
*   **Near-camera overfitting:** Methods using depth priors like ReVoRF can produce blurriness due to near-camera overfitting [S1]. F2Plenoxels mitigates this through its specific depth-guided pre-pruning [S1].
*   **Artifacts:** Without proper regularization, methods like DNGaussian (3DGS-based) may produce cluttered needle-like artifacts [S1]. F2Plenoxels avoids these [S1].
*   **Precision:** The method relies on accurate depth priors for pre-pruning; incorrect depth estimates may lead to incorrect voxel pruning [S1].

## Operating characteristics
*   **Performance:** F2Plenoxels achieves better SSIM than other few-shot NeRF-based methods on the LLFF dataset and is superior in PSNR and LPIPS compared to other NeRF-based methods, though slightly inferior to some 3DGS-based methods in specific metrics [S1].
*   **Comparison:** It significantly reduces floaters compared to Plenoxels, MixNeRF, and SynergyNeRF [S1]. It produces less blurriness than ReVoRF [S1]. It avoids cluttered needle-like artifacts present in DNGaussian [S1]. It improves geometry accuracy and appearance fidelity over baseline Plenoxels [S1]. Its depth constraints are finer than SparseNeRF, VGOS, DiffusioNeRF, and FrugalNeRF, resulting in better texture details [S1].
*   **Efficiency:** The method is built on Plenoxels' codebase and uses RMSProp [S1]. Training time is reported on a single NVIDIA Quadro P5000 GPU [S1]. Specific training times are not given in the notes for F2Plenoxels, but Plenoxels baseline is 12 mins [S1].

## Background
F2Plenoxels was introduced in the paper "F2Plenoxels: fast voxel radiance fields without neural networks for few-shot view synthesis" [S1]. It builds on the Plenoxels framework [S1]. The method is evaluated on the Blender (Mildenhall et al. 2020) and LLFF (Mildenhall et al. 2019) datasets [S1].
