# Plenoxels Training

Also called: Plenoxels Training Implementation

## Overview
Plenoxels Training is the optimization procedure that produces the final sparse voxel grid representation from input images [S1, unofficial]. It builds on [Plenoxels Optimization Configuration](929-plenoxels-optimization-configuration.md) by executing gradient-based updates to persist learned opacity ($\sigma$) and spherical harmonic (SH) coefficients [S1, unofficial]. The implementation saves the final voxel grid at a fixed resolution of $128 \times 128 \times 128$ after approximately 30 minutes of training on a single GPU [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A dataset of multi-view images with known camera poses [S1, unofficial].
*   **Output:** A saved voxel grid file containing the optimized sparse voxels, where each voxel stores coordinates, density values, and SH coefficients [S1, unofficial][S2].

**Data Structures:**
The output is a sparse voxel grid consisting of two primary components [S2]:
1.  **Coordinates:** The 3D spatial positions of the active voxels [S2].
2.  **Features:** The radiance field parameters for each active voxel, specifically the density ($\sigma$) and the spherical harmonic coefficients representing view-dependent color [S1, unofficial][S2].

**Steps:**
1.  **Initialization:** Initialize the voxel grid parameters ($\sigma$ and SH coefficients) based on the configuration defined in [Plenoxels Optimization Configuration](929-plenoxels-optimization-configuration.md) [G].
2.  **Rendering:** Render images from the training views using differentiable volume rendering [G].
3.  **Loss Computation:** Calculate the difference between rendered images and ground truth images using a photometric loss [G].
4.  **Optimization:** Update the voxel parameters using a gradient-based optimizer to minimize the loss [G].
5.  **Iteration:** Repeat steps 2-4 for the specified number of iterations [S1, unofficial].
6.  **Saving:** Upon completion, save the final optimized voxel grid to disk [S1, unofficial].

**Formulas:**
The discrete volume rendering integral accumulates color $C$ along a ray:
$$C = \sum_{i=1}^{N} T_i (1 - e^{-\sigma_i \delta_i}) c_i$$
where $T_i = \prod_{j=1}^{i-1} e^{-\sigma_j \delta_j}$ is the transmittance, $\sigma_i$ is the opacity, $c_i$ is the color from SH coefficients, $\delta_i$ is the step size, and $N$ is the number of steps [G].

## Subtopics

### 3D Classification with Spatially Sparse Convolutions
This variant uses the trained Plenoxels grid as input for 3D classification tasks [S2]. It employs 3D convolutional networks (e.g., ResNet variants) implemented with spatially sparse convolutional layers [S2]. The input to the network consists of the sparse voxel coordinates and their features (SH coefficients and density values) [S2]. Training uses the SGD optimizer with an initial learning rate of 0.1, cosine annealing for 100K iterations, and a batch size of 16 on a single RTX 3090 GPU [S2]. Data augmentation includes geometric transformations (random rotation, coordinate dropout, horizontal flip, uniform translation, scaling) and feature-level jittering [S2]. A unique augmentation involves substituting the background of a scene with backgrounds from other scenes while preserving the foreground [S2].

## Operating characteristics
*   **Time Complexity:** Training takes approximately 30 minutes on a single GPU [S1, unofficial].
*   **Memory Complexity:** Depends on the sparsity of the voxel grid and the resolution ($128^3$ final grid) [S1, unofficial].
*   **Strengths:** Fast training time; produces a compact, sparse representation suitable for downstream tasks like classification [S1, unofficial][S2].
*   **Limitations:** Performance is tied to the specific hardware (RTX 3090) and configuration [S2].

## Background
Plenoxels Training was introduced as part of the Plenoxels framework, which aims to represent radiance fields using sparse voxels and spherical harmonics to enable fast rendering and training [S1, unofficial]. The implementation details, including the 30-minute training time on a single GPU, were documented in the associated repository [S1, unofficial]. The method has been extended to support perception tasks, such as 3D classification, by leveraging the sparse voxel features directly in convolutional networks [S2].
