# Plenoxel


## Overview
Plenoxel is a volume rendering method that represents a scene as a sparse 3D grid of voxels, calculating color and opacity via trilinear interpolation during ray casting without using neural networks [S2]. It solves the problem of high computational cost in neural radiance fields by relaxing the PlenOctrees assumption of constant opacity and spherical harmonic (SH) coefficients inside each voxel, instead defining a continuous function throughout the volume [S1]. Unlike its sibling [Plenoxels Optimization Configuration](929-plenoxels-optimization-configuration.md) which may assume piecewise constant attributes, Plenoxel explicitly interpolates attributes, allowing for smoother gradients and potentially higher fidelity at the cost of increased memory bandwidth during sampling [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A sparse 3D voxel grid containing learnable parameters; camera poses and viewing directions.
*   **Output:** Rendered HDR color image $\hat{C}(\mathbf{r})$ for given rays $\mathbf{r}$.

**Data Structures:**
The scene is represented by a voxel grid. Each vertex of the voxel grid stores a 28-dimensional vector [S3]:
1.  **SH Coefficients:** 27 values, corresponding to 9 coefficients per color channel (R, G, B) for degree-2 spherical harmonics.
2.  **Opacity:** 1 scalar value $\sigma$.

**Algorithm Steps:**
1.  **Initialization:** Initialize voxel opacities $\sigma$ to 0.1 and color coefficients to grey by adding an offset of 0.5 to the SH coefficients [S3].
2.  **Ray Definition:** For each pixel, define a ray $\mathbf{r} = \mathbf{o} + t\mathbf{d}$, where $\mathbf{o}$ is the camera center and $\mathbf{d}$ is the normalized viewing direction [S3].
3.  **Sampling:** Sample $N$ points along the ray at regular intervals $\delta_i = t_{i+1} - t_i$ [S3].
4.  **Interpolation:** For any 3D point $(x, y, z)$ and normalized viewing angle $(v_x, v_y, v_z)$ within the voxel grid, trilinearly interpolate the color $\mathbf{c}_i$ and opacity $\sigma_i$ from the eight nearby voxel vertices [S1, S3].
5.  **Rendering:** Compute the accumulated transmittance $T_i$ and the final color using the volume rendering integral [S3]:
    $$ \hat{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i \left( 1 - \exp(-\sigma_i \delta_i) \right) \mathbf{c}_i $$
    where the transmittance is defined as:
    $$ T_i = \exp\left( -\sum_{j=1}^{i-1} \sigma_j \delta_j \right) $$
6.  **Optimization:** Directly optimize the voxel opacities and SH coefficients using gradient-based optimizers, without neural network backpropagation through a MLP [S1].

**Pseudocode:**
```python
def render_plenoxel(ray_origin, ray_direction, voxel_grid, num_samples):
    """
    Renders a single ray using Plenoxel representation.
    
    Args:
        ray_origin: 3D vector (o)
        ray_direction: 3D vector (d), normalized
        voxel_grid: Sparse 3D grid storing 28D vectors per vertex
        num_samples: Integer N
        
    Returns:
        color: 3D vector (RGB)
    """
    # 1. Define ray and sample points
    # Assume bounding box limits for the scene are known
    t_min, t_max = get_ray_box_intersection(ray_origin, ray_direction)
    t_values = linspace(t_min, t_max, num_samples + 1)
    
    accumulated_transmittance = 1.0
    final_color = [0.0, 0.0, 0.0]
    
    for i in range(num_samples):
        t_i = t_values[i]
        t_next = t_values[i+1]
        delta = t_next - t_i
        
        # 2. Sample point position
        point_pos = ray_origin + ray_direction * t_i
        
        # 3. Trilinear Interpolation
        # Get color c_i and opacity sigma_i from voxel grid at point_pos
        # and viewing direction ray_direction
        c_i, sigma_i = trilinear_interpolate(voxel_grid, point_pos, ray_direction)
        
        # 4. Volume Rendering Step
        # T_i is accumulated transmittance up to point i
        # Note: T_1 = 1.0 (exp(0))
        
        weight = 1.0 - exp(-sigma_i * delta)
        final_color += accumulated_transmittance * weight * c_i
        
        # Update transmittance for next step
        accumulated_transmittance *= exp(-sigma_i * delta)
        
        # Early termination if transmittance is negligible
        if accumulated_transmittance < 1e-5:
            break
            
    return final_color
```

**Parameters:**
*   **Initial Opacity:** 0.1 [S3].
*   **Initial Color Offset:** 0.5 added to initialize color to grey [S3].
*   **Sampling:** $N$ points sampled at regular intervals [S3].

**Edge Cases and Pitfalls:**
*   **Training Instability:** SH coefficients can change significantly during training, leading to instability. The grey initialization offset mitigates this [S3].
*   **Boundary Conditions:** Trilinear interpolation requires valid voxel neighbors. Points outside the sparse grid bounds must be handled (e.g., treated as transparent or background) [G].

## Subtopics

### HDR-Plenoxels Volume Representation
A radiance representation using Spherical Harmonics (SH) in a voxel grid to model HDR irradiance, exploiting SH's ability to implicitly express non-Lambertian effects and span all colors over every direction of a sphere [S3]. It follows the standard Plenoxel interpolation and rendering pipeline but is specifically configured for High Dynamic Range output, often followed by an explicit tone mapping stage to convert HDR radiance to LDR images [S3].

## Operating characteristics
*   **Time Complexity:** Rendering requires $O(N)$ trilinear interpolations per ray, where $N$ is the number of samples. This is significantly faster than neural network queries (MLPs) used in standard NeRF, which involve multiple matrix multiplications per sample [S2].
*   **Memory Complexity:** Memory usage is proportional to the number of voxels in the sparse grid. Each voxel vertex stores 28 floats (27 SH + 1 opacity). Sparsity helps reduce this compared to dense grids [S2].
*   **Performance:** Plenoxels optimized with Instant-NGP algorithms achieve training speeds 2 orders of magnitude faster than JNeRF, with no loss in visual quality on standard benchmarks [S2].
*   **Strengths:** No neural network overhead; efficient ray marching; continuous representation avoids artifacts from piecewise constant assumptions [S1, S2].
*   **Limitations:** Trilinear interpolation may introduce blurring compared to higher-order methods; memory usage can be high for high-resolution grids [S1, S3].

## Background
Plenoxel was proposed by Fridovich-Keil et al. in 2022 [S1, S2]. It was introduced as a NeRF model without neural networks, representing the scene as a sparse 3D grid. It relaxes the PlenOctrees assumption [YLT* 21] by using trilinear interpolation to define a continuous function throughout the volume, directly optimizing voxel opacities and SH coefficients [S1].
