# Plenoxels Training Configuration (PeRFception variants)

Also called: PeRFception-CO3D training, PeRFception-ScanNet training

## Overview
This article defines the specific hyperparameter configurations and data preprocessing pipelines for training Plenoxels on the CO3D and ScanNet datasets, as implemented in the PeRFception framework. It addresses the problem of stabilizing gradient-based optimization for sparse voxel grids and handling dataset-specific noise, such as depth outliers in ScanNet or motion blur in CO3D. It differs from the base [Plenoxels Training](5979-plenoxels-training.md) method by enforcing distinct learning rates for density and spherical harmonic (SH) coefficients, applying specific total variation (TV) regularization weights, and utilizing dataset-specific initialization strategies (point cloud unprojection for ScanNet).

## How it works
The method consists of two distinct configurations: one for object-centric scenes (CO3D) and one for indoor scenes (ScanNet). Both share a common optimization backbone but differ in initialization, background handling, and pruning schedules.

### Inputs and Outputs
*   **Inputs:**
    *   Training images resized to $640 \times 480$ resolution.
    *   For ScanNet: Ground truth depth maps and camera parameters.
    *   For CO3D: Training images only.
*   **Outputs:**
    *   Optimized voxel grid containing density ($\sigma$) and 9-dimensional SH coefficients per RGB channel.

### Data Structures
The voxel grid is a 3D structure.
*   **ScanNet Initialization:** A point cloud is generated by unprojecting depth maps using ground truth camera parameters. Outliers are removed by discretizing the point cloud into coarse $5\text{cm}$ voxels and performing connected component analysis to remove disconnected components [S1]. This refined point cloud initializes the voxel grid [S1].
*   **CO3D Initialization:** Standard Plenoxels initialization (not explicitly detailed in sources, assumed to be uniform or empty) [S1].
*   **Voxel Grid Resolution:**
    *   ScanNet: $256^3$ [S1].
    *   CO3D: Not given in the sources.
*   **Spherical Harmonics:** 9-dimensional coefficients per RGB channel [S1].

### Parameters
The following parameters are used for both configurations unless specified otherwise [S1]:

*   **Learning Rates:**
    *   Density values: $30$ [S1].
    *   Spherical Harmonic coefficients: $10^{-2}$ [S1].
*   **Regularization Weights ($\lambda$):**
    *   Foreground densities: $5.0 \times 10^{-5}$ [S1].
    *   Foreground spherical harmonics: $5.0 \times 10^{-3}$ [S1].
    *   Background colors: $1.0 \times 10^{-3}$ [S1].
    *   Background densities: $1.0 \times 10^{-3}$ [S1].
*   **Loss Hyperparameters:**
    *   Beta loss lambda: $10^{-5}$ [S1].
    *   Sparsity loss lambda: $10^{-10}$ (10 times larger than the default Plenoxels configuration) [S1].
*   **Background:**
    *   Background brightness: $0.5$ [S1].
    *   Background rendering: Enabled for CO3D; Disabled for ScanNet (all points treated as foreground) [S1].
*   **Pruning:**
    *   Density threshold: $1.28$ [S1].

#### PeRFception-ScanNet Training
1.  **Data Generation:**
    *   Unproject depth maps into a point cloud using ground truth camera parameters [S1].
    *   Discretize the point cloud into $5\text{cm}$ coarse voxels [S1].
    *   Perform connected component analysis to remove disconnected voxels (outliers) [S1].
    *   Use the refined point cloud to initialize the voxel grid [S1].
2.  **Preprocessing:**
    *   Resize input images to $640 \times 480$ [S1].
    *   Exclude scenes with severe motion blur using OpenCV's blur detection algorithm with a threshold of 10 [S1].
3.  **Initialization:** Set voxel grid resolution to $256^3$ [S1]. Disable background rendering [S1].
4.  **Warm-up:** Skip foreground rendering for the first $1,000$ training steps [S1].
5.  **Optimization:**
    *   Train for $51,200$ iterations [S1].
    *   At iteration $25,600$, perform voxel pruning: remove voxels with density values below $1.28$ [S1].
    *   Apply Total Variation loss with weights: $\lambda_{\sigma, fg} = 5.0 \times 10^{-5}$, $\lambda_{SH, fg} = 5.0 \times 10^{-3}$, $\lambda_{C, bg} = 1.0 \times 10^{-3}$, $\lambda_{\sigma, bg} = 1.0 \times 10^{-3}$ [S1].
    *   Apply Beta loss with $\lambda = 10^{-5}$ [S1].
    *   Apply Sparsity loss with $\lambda = 10^{-10}$ [S1].
    *   Set background brightness to $0.5$ [S1].

```python
def train_plenoxels_perfception(dataset_type, images, depth_maps=None, camera_params=None):
    # 1. Preprocessing
    images = resize(images, 640, 480)
    
    if dataset_type == "scannet":
        # Filter motion blur
        images = filter_motion_blur(images, threshold=10)
        
        # Initialize voxel grid from depth
        point_cloud = unproject_depth(depth_maps, camera_params)
        point_cloud = remove_outliers(point_cloud, voxel_size=0.05) # 5cm
        voxel_grid = initialize_from_point_cloud(point_cloud, resolution=256)
        background_rendering = False
    else: # CO3D
        # Standard initialization assumed
        voxel_grid = initialize_plenoxels()
        background_rendering = True
        
    # 2. Hyperparameters
    lr_density = 30.0
    lr_sh = 1e-2
    lambda_tv_fg_sigma = 5.0e-5
    lambda_tv_fg_sh = 5.0e-3
    lambda_tv_bg_color = 1.0e-3
    lambda_tv_bg_sigma = 1.0e-3
    lambda_beta = 1e-5
    lambda_sparsity = 1e-10
    bg_brightness = 0.5
    prune_threshold = 1.28
    
    # 3. Training Loop
    for step in range(1, 51201): # Max iterations for ScanNet; CO3D duration not specified
        if step <= 1000:
            # Skip foreground rendering for first 1000 steps
            render_output = render_background_only(voxel_grid, bg_brightness) if background_rendering else None
            continue
            
        # Forward pass
        render_output = render(voxel_grid, camera_poses, background_rendering, bg_brightness)
        
        # Loss calculation
        loss = compute_reconstruction_loss(render_output, images)
        
        # Regularization
        loss += lambda_tv_fg_sigma * total_variation(voxel_grid.density, foreground=True)
        loss += lambda_tv_fg_sh * total_variation(voxel_grid.sh_coeffs, foreground=True)
        if background_rendering:
            loss += lambda_tv_bg_color * total_variation(voxel_grid.bg_color)
            loss += lambda_tv_bg_sigma * total_variation(voxel_grid.bg_density)
            
        loss += lambda_beta * beta_loss(render_output)
        loss += lambda_sparsity * sparsity_loss(voxel_grid.density)
        
        # Backward pass
        optimizer.step(loss)
        
        # Pruning
        if dataset_type == "scannet" and step == 25600:
            prune_voxels(voxel_grid, threshold=prune_threshold)
            
    return voxel_grid
```

### Edge Cases and Pitfalls
*   **Motion Blur:** ScanNet scenes with severe motion blur must be excluded. Scenes are considered defective if the number of frames is too low after filtering [S1].
*   **Depth Noise:** ScanNet depth maps contain noisy observations, necessitating the connected component analysis for outlier removal [S1].
*   **Unobserved Parts:** Plenoxels fail to reliably render frames when attempting to render parts significantly outside the training view coverage [S1].

## Operating characteristics
*   **Time Complexity:** Training takes up to 30 minutes per scene on a single RTX 3090 GPU [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Performance:**
    *   CO3D: Contains 18,618 object-centric scenes [S1].
    *   ScanNet: Uses 1,513 training scenes, with 16 excluded due to motion blur [S1].
*   **Scaling:** Resolution vs. rendering quality trade-off was analyzed on ScanNet. Training with lower (128) and higher (512) resolutions showed no direct correlation between resolution and average rendering quality [S1].
*   **Strengths:** Stabilizes training via warm-up and specific learning rates; handles noisy depth data effectively.
*   **Limitations:** Poor performance on unobserved parts of the scene [S1].

## Background
This configuration originates from the PeRFception paper, which utilizes the Plenoxels framework [S1]. The method was developed to improve perception tasks using radiance fields on specific datasets (CO3D and ScanNet) [S1].
