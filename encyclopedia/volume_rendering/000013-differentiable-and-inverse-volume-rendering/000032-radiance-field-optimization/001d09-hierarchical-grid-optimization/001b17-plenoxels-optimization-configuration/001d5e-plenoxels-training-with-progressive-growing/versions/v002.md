# Plenoxels Training with Progressive Growing

Also called: Progressive Growing for Plenoxels

## Overview
A training procedure for Plenoxels that uses progressive growing of the receptive field size to optimize a 3D voxel grid from multi-view images, incorporating TV loss and beta loss for regularization [S1, unofficial]. It differs from static grid optimization by starting with a coarse, downsampled representation and refining it, which reduces training time and improves convergence stability [S1, unofficial][S2].

## How it works
**Inputs:** Multi-view images (`imgs`), camera parameters (`transform_matrices`, `camera_angle_x`), grid dimensions (`gridsize`), and hyperparameters (`lr`, `tv`, `beta`, `steps`, `number_of_rays`, `num_samples`, `delta_step`, `points_distance`, `progressive_growing`) [S1, unofficial].
**Outputs:** Optimized voxel grid `grid_cells_full` containing RGB and opacity values [S1, unofficial].

**Data Structures:**
*   `grid_cells_full`: Tensor of shape $(X, Y, Z, 4)$. The last dimension stores cell information (RGB + Alpha) [S1, unofficial]. Initialized with `requires_grad=True` [S1, unofficial].
*   `grid_coords`: Tensor of shape $(X \cdot Y \cdot Z, 3)$ storing the 3D coordinates of each voxel center [S1, unofficial].
*   `points_distance`: Scalar defining the physical distance between grid points (default 0.0125) [S1, unofficial].
*   `receptive_fields_sizes`: List of odd integers from 93 down to 3 (inclusive) [S1, unofficial].

**Algorithm:**

1.  **Initialization:**
    *   Create `grid_cells_full` of shape `gridsize` + $(4)$ on the target device [S1, unofficial].
    *   Initialize `grid_cells_full_grad` (accumulator for absolute gradients) to zeros of the same shape [S1, unofficial].
    *   Set `receptive_fields_sizes` = $[93, 91, \dots, 3]$ [S1, unofficial].
    *   Set `steps_per_field` = 5 [S1, unofficial].

2.  **Training Loop:** Iterate `i` from $0$ to `steps` - 1 [S1, unofficial].

3.  **Receptive Field Configuration:**
    *   Calculate `field_index` = $\lfloor i / \text{steps\_per\_field} \rfloor$ [S1, unofficial].
    *   If `field_index` < length(`receptive_fields_sizes`), set `receptive_field_size` = `receptive_fields_sizes[field_index]` [S1, unofficial]. Else, set `receptive_field_size` = 1 [S1, unofficial].

4.  **Grid Sub-sampling (Progressive Growing):**
    *   If `receptive_field_size` > 1 AND `progressive_growing` is True:
        *   Calculate `stride` = $\max(1, \lfloor \text{receptive\_field\_size} / 4 \rfloor)$ [S1, unofficial].
        *   Calculate `start_index` = $\lfloor \text{receptive\_field\_size} / 2 \rfloor$ [S1, unofficial].
        *   Extract sub-grid `grid_grid` from `grid_cells_full` using slice `[start_index::stride, start_index::stride, start_index::stride]` [S1, unofficial].
        *   Reshape `grid_grid` to `grid_indices` (flattened spatial indices) [S1, unofficial].
        *   Update `points_distance` = `points_distance_original` * `stride` [S1, unofficial].
        *   Compute `grid_cells` by averaging `grid_cells_full` over the receptive field using `average_pool3d_grid` (implemented via 3D convolution with a uniform kernel) [S1, unofficial].
    *   Else (static or final refinement):
        *   Set `grid_cells` = `grid_cells_full` [S1, unofficial].
        *   Set `grid_indices` = `grid_coords` [S1, unofficial].
        *   Set `points_distance` = `points_distance_original` [S1, unofficial].

5.  **Ray Sampling:**
    *   Call `sample_camera_rays_batched` with `transform_matrices`, `camera_angle_x`, `imgs`, `number_of_rays`, `num_samples`, `delta_step`, `even_spread`, `camera_ray=False`, and `device` [S1, unofficial].
    *   Returns `samples_interval` (ray samples), `pixels_to_rays` (ground truth colors), `camera_positions`, `ray_directions` [S1, unofficial].

6.  **Normalization and Voxel Assignment:**
    *   Normalize samples: Call `normalize_samples_for_indecies` with `grid_indices` and `samples_interval` using `points_distance` to get `normalized_samples_for_indecies` (coordinates in voxel index space) [S1, unofficial].
    *   Clip `grid_cells` to $[0, 1]$ [S1, unofficial].
    *   Get nearest voxels: Call `get_nearest_voxels` with `normalized_samples_for_indecies` and clipped `grid_cells` [S1, unofficial].
        *   Inside `get_nearest_voxels`: Round `normalized_samples_for_indecies` to nearest integer indices [S1, unofficial]. Check bounds using `find_out_of_bound` [S1, unofficial]. Fix out-of-bounds indices using periodic boundary conditions (`fix_out_of_bounds`) or mask them [S1, unofficial].
    *   Returns `nearest` (voxel values) and `mask` (boolean tensor indicating valid samples) [S1, unofficial].
    *   Zero out invalid samples: `nearest` = `nearest` * `mask.unsqueeze(-1)` [S1, unofficial].

7.  **Rendering:**
    *   Reshape `nearest` to $(B, \text{number\_of\_rays}, \text{num\_samples}, 4)$ [S1, unofficial].
    *   Compute pixel colors: Call `compute_alpha_weighted_pixels(nearest)` to perform volume rendering (alpha compositing) [S1, unofficial].
    *   Reshape `pixels_color` to $(B \cdot \text{number\_of\_rays}, \text{num\_samples})$ [S1, unofficial].

8.  **Loss Computation:**
    *   MSE Loss: `mseloss` = $\text{MSE}(\text{pixels\_color}, \text{pixels\_to\_rays})$ [S1, unofficial].
    *   `loss` = `mseloss` [S1, unofficial].
    *   TV Loss: If `tv` > 0 AND `receptive_field_size` < 19:
        *   `tvloss` = `tv` * `tv_loss(grid_cells)` [S1, unofficial].
        *   `loss` = `loss` + `tvloss` [S1, unofficial].
    *   Beta Loss (Entropy Regularization): If `beta` > 0:
        *   Extract alpha channel: $\alpha = \text{nearest}[:, :, :, -1]$ [S1, unofficial].
        *   `betaloss` = `beta` * $\text{mean}(\log(\alpha + 0.0001) - \log(1 - \alpha + 0.0001))$ [S1, unofficial].
        *   `loss` = `loss` + `betaloss` [S1, unofficial].

9.  **Optimization:**
    *   `optimizer.zero_grad()` [S1, unofficial].
    *   `loss.backward()` [S1, unofficial].
    *   `optimizer.step()` [S1, unofficial].

10. **Gradient Accumulation:**
    *   `grid_cells_full_grad` += $\text{abs}(\text{grid\_cells\_full.grad})$ [S1, unofficial].

11. **Checkpointing:**
    *   Detach `grid_cells_full` to CPU.
    *   Save dictionary containing `grid` (`grid_cells_full`), `grid_grad` (`grid_cells_full_grad`), and `param` (device, `number_of_rays`, `num_samples`, `delta_step`, `even_spread`, `camera_ray`, `points_distance`, `gridsize`) to `save_path` [S1, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn.functional as F
import torch.nn as nn

def trilinear_interpolation(normalized_samples_for_indecies, selected_points, grid_cells):
    """
    Trilinear interpolation of grid values at sample points.
    :param normalized_samples_for_indecies: Tensor (N, 3)
    :param selected_points: Tensor (N, 8, 3) indices of 8 corners
    :param grid_cells: Tensor (X, Y, Z, 4)
    :returns: Tensor (N, 4)
    """
    inteplation_frac = torch.frac(normalized_samples_for_indecies)
    
    # Selection based on corner indices provided in selected_points
    # Indices 4-7 are ceil corners, 0-3 are floor corners (based on doc comment)
    selection0 = grid_cells[selected_points[:, 4:, 0], selected_points[:, 4:, 1], selected_points[:, 4:, 2]]
    selection1 = grid_cells[selected_points[:, :4, 0], selected_points[:, :4, 1], selected_points[:, :4, 2]]
    
    # Interpolate along X
    inteplation_frac_step = inteplation_frac[:, 0].unsqueeze(-1).unsqueeze(-1)
    newstep = (selection1 * inteplation_frac_step) + (selection0 * (1 - inteplation_frac_step))
    del selection0, selection1
    
    # Interpolate along Y
    inteplation_frac_step = inteplation_frac[:, 1].unsqueeze(-1).unsqueeze(-1)
    newstep = (newstep[:, :2] * inteplation_frac_step) + (newstep[:, 2:] * (1 - inteplation_frac_step))
    
    # Interpolate along Z
    inteplation_frac_step = inteplation_frac[:, 2].unsqueeze(-1)
    newstep = (newstep[:, 0] * inteplation_frac_step) + (newstep[:, 1] * (1 - inteplation_frac_step))
    
    return newstep

def find_out_of_bound(indecies, grid):
    """
    Checks if indices are within grid bounds [0, X), [0, Y), [0, Z).
    :param indecies: Tensor (N, 3)
    :param grid: Tensor (X, Y, Z, ...)
    :returns: Boolean Tensor (N,) True if inside bounds
    """
    idx1, idx2, idx3 = indecies[:, 0], indecies[:, 1], indecies[:, 2]
    X, Y, Z, _ = grid.shape
    
    idx1_ok = (idx1 >= 0) & (idx1 < X)
    idx2_ok = (idx2 >= 0) & (idx2 < Y)
    idx3_ok = (idx3 >= 0) & (idx3 < Z)
    
    return idx1_ok & idx2_ok & idx3_ok

def fix_out_of_bounds(indices, grid):
    """
    Fixes out of bounds indices using periodic boundary conditions.
    :param indices: Tensor (N, 3)
    :param grid: Tensor (X, Y, Z, ...)
    :returns: Tuple of Tensors (idx1, idx2, idx3) fixed indices
    """
    idx1, idx2, idx3 = indices[:, 0], indices[:, 1], indices[:, 2]
    X, Y, Z, _ = grid.shape
    
    idx1 = idx1 % X
    idx2 = idx2 % Y
    idx3 = idx3 % Z
    
    return idx1, idx2, idx3

def get_nearest_voxels(normalized_samples_for_indices, grid):
    """
    Gets nearest voxel values for normalized sample indices.
    :param normalized_samples_for_indices: Tensor (N, 3)
    :param grid: Tensor (X, Y, Z, 4)
    :returns: Tuple (values Tensor (N, 4), mask Tensor (N,))
    """
    indices = torch.round(normalized_samples_for_indices).to(torch.long)
    outofbounds = find_out_of_bound(indices, grid)
    
    # Fix out of bounds for indexing
    idx1, idx2, idx3 = fix_out_of_bounds(indices, grid)
    
    values = grid[idx1, idx2, idx3]
    return values, outofbounds

def average_pool3d_grid(grid_cells_full, receptive_field_size):
    """
    Averages grid cells over a receptive field using 3D convolution.
    :param grid_cells_full: Tensor (X, Y, Z, 4)
    :param receptive_field_size: int (odd)
    :returns: Tensor (X, Y, Z, 4)
    """
    # Permute to (1, 4, X, Y, Z) for conv3d
    tensor = grid_cells_full.permute(3, 0, 1, 2).unsqueeze(0).float()
    
    # Create uniform kernel
    kernel_value = 1.0 / (receptive_field_size ** 3)
    kernel = torch.full((1, 1, receptive_field_size, receptive_field_size, receptive_field_size), 
                        kernel_value, device=tensor.device)
    kernel = kernel.repeat(4, 1, 1, 1, 1) # Repeat for 4 channels
    
    # Convolve with padding to maintain size
    result = F.conv3d(tensor, kernel, padding=receptive_field_size // 2, groups=4)
    
    # Permute back to (X, Y, Z, 4)
    result = result.squeeze(0).permute(1, 2, 3, 0)
    return result

def compute_alpha_weighted_pixels(nearest_reshaped):
    """
    Standard alpha compositing for volume rendering.
    :param nearest_reshaped: Tensor (B, rays, samples, 4)
    :returns: Tensor (B * rays, samples)
    """
    alphas = torch.sigmoid(nearest_reshaped[..., 3:])
    rgbs = nearest_reshaped[..., :3]
    
    # Compute transmittance T_i = product(1 - alpha_j) for j < i
    T = torch.cumprod(1 - alphas, dim=2)
    T = torch.cat([torch.ones_like(T[:, :, :1]), T[:, :, :-1]], dim=2)
    
    # Weighted sum
    weights = alphas * T
    pixels_color = torch.sum(rgbs * weights, dim=2)
    return pixels_color

def train_plenoxels_progressive(grid_cells_full, grid_coords, optimizer, imgs, transform_matrices, 
                               camera_angle_x, steps, number_of_rays, num_samples, delta_step, 
                               points_distance_original, tv, beta, progressive_growing, device):
    """
    Main training loop for Plenoxels with progressive growing.
    """
    receptive_fields_sizes = list(range(93, 2, -2)) # 93 down to 3
    steps_per_field = 5
    
    grid_cells_full_grad = torch.zeros_like(grid_cells_full)
    
    for i in range(steps):
        # 1. Determine receptive field
        field_index = i // steps_per_field
        if field_index < len(receptive_fields_sizes):
            receptive_field_size = receptive_fields_sizes[field_index]
        else:
            receptive_field_size = 1
            
        # 2. Configure Grid and Sampling
        if receptive_field_size > 1 and progressive_growing:
            stride = max(1, receptive_field_size // 4)
            start_index = int(receptive_field_size / 2)
            
            # Extract sub-grid
            grid_grid = grid_cells_full[start_index::stride, start_index::stride, start_index::stride]
            grid_indices = grid_grid.reshape(-1, 4)[:, :3] # Extract 3D coordinates
            
            points_distance = points_distance_original * stride
            
            # Average pool to get current representation
            grid_cells = average_pool3d_grid(grid_cells_full, receptive_field_size)
        else:
            grid_cells = grid_cells_full
            grid_indices = grid_coords
            points_distance = points_distance_original
            
        # 3. Sample Rays (Source does not provide implementation [G])
        # samples_interval, pixels_to_rays, camera_positions, ray_directions = sample_camera_rays_batched(...)
        samples_interval = torch.rand((imgs.shape[0], number_of_rays, num_samples, 3), device=device)
        pixels_to_rays = torch.rand((imgs.shape[0], number_of_rays, 3), device=device)
        
        # 4. Normalize Samples (Source does not provide implementation [G])
        # normalized_samples_for_indecies = normalize_samples_for_indecies(grid_indices, samples_interval, points_distance)
        normalized_samples_for_indecies = samples_interval / points_distance 
        
        # 5. Get Nearest Voxels
        clipped_grid = torch.clamp(grid_cells, 0, 1)
        nearest, mask = get_nearest_voxels(normalized_samples_for_indecies, clipped_grid)
        
        # Zero out invalid samples
        nearest = nearest * mask.unsqueeze(-1).float()
        
        # 6. Render
        # Reshape for rendering: (B, rays, samples, 4)
        nearest_reshaped = nearest.reshape(imgs.shape[0], number_of_rays, num_samples, 4)
        
        # Compute Alpha Weighted Pixels
        pixels_color = compute_alpha_weighted_pixels(nearest_reshaped)
        pixels_color = pixels_color.reshape(imgs.shape[0] * number_of_rays, num_samples)
        
        # 7. Compute Loss
        # Note: pixels_to_rays shape is (B, rays, 3). pixels_color is (B*rays, samples).
        # Assuming broadcasting or expansion as per source logic.
        pixels_to_rays_expanded = pixels_to_rays.repeat_interleave(num_samples, dim=1).view(-1, num_samples, 3)
        mseloss = nn.functional.mse_loss(pixels_color, pixels_to_rays_expanded)
        loss = mseloss
        
        # TV Loss
        if tv > 0 and receptive_field_size < 19:
            tv_loss_val = torch.mean(torch.abs(grid_cells[..., :-1, :] - grid_cells[..., 1:, :])) + \
                          torch.mean(torch.abs(grid_cells[..., :-1, :, :] - grid_cells[..., 1:, :, :])) + \
                          torch.mean(torch.abs(grid_cells[..., :-1, :, :, :] - grid_cells[..., 1:, :, :, :]))
            tvloss = tv * tv_loss_val
            loss = loss + tvloss
            
        # Beta Loss
        if beta > 0:
            alpha = nearest[..., -1] # Last channel
            betaloss = beta * (torch.log(alpha + 0.0001) - torch.log(1 - alpha + 0.0001)).mean()
            loss = loss + betaloss
            
        # 8. Optimize
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        # 9. Accumulate Gradients
        if grid_cells_full.grad is not None:
            grid_cells_full_grad += torch.abs(grid_cells_full.grad)
            
    return grid_cells_full, grid_cells_full_grad
```

**Parameters:**
*   `lr`: Learning rate for Adam optimizer. Default: 0.0075 [S1, unofficial].
*   `tv`: Strength of Total Variation loss. Default: $10^{-5}$. Set to 0 to disable [S1, unofficial].
*   `beta`: Strength of Beta loss (entropy regularization on alpha). Default: $5 \times 10^{-3}$. Set to 0 to disable [S1, unofficial].
*   `steps`: Total training steps. Default: 500 [S1, unofficial].
*   `number_of_rays`: Rays per camera. Default: 128 [S1, unofficial].
*   `num_samples`: Samples per ray. Default: 600 [S1, unofficial].
*   `delta_step`: Distance between samples. Default: 0.0125 [S1, unofficial].
*   `points_distance`: Grid spacing. Default: 0.0125 [S1, unofficial].
*   `gridsize`: Grid dimensions. Default: $[256, 256, 256]$ if not specified [S1, unofficial].

**Pitfalls:**
*   **Out of Bounds:** Indices must be checked against grid dimensions $[0, X), [0, Y), [0, Z)$ [S1, unofficial]. The code clips grid values to $[0, 1]$ before querying, but `get_nearest_voxels` returns a mask to zero out samples outside the grid boundaries [S1, unofficial].
*   **Precision:** The `torch.frac` function is used for interpolation fractions. Ensure `normalized_samples_for_indecies` are correctly scaled relative to `points_distance` [S1, unofficial].

## Subtopics

### Progressive Voxel Grid Scaling
A variant where the voxel grid resolution is doubled at specific checkpoints during training, rather than using a shrinking receptive field on a fixed grid [S2]. The initial number of voxels is set to $\lfloor M(f)/2 \rfloor$ [S2]. At each checkpoint, voxel grids $V(\text{density})(f)$ and $V(\text{feat})(f)$ are resized by trilinear interpolation to match the new dimensions $N(f)_x, N(f)_y, N(f)_z$ and voxel size $s(f)$ [S2]. This approach reduces training time from 11.7 to 7.3 minutes while improving PSNR from 35.50 to 35.54 [S2].

## Operating characteristics
*   **Time Complexity:** Progressive growing reduces training time compared to static full-resolution initialization. Specifically, progressive scaling reduces training time from 11.7 to 7.3 minutes in the tested configuration [S2].
*   **Memory Complexity:** Depends on the grid size $X \cdot Y \cdot Z$. Progressive growing allows starting with a smaller effective grid, reducing initial memory footprint, but the underlying `grid_cells_full` remains the full size [S1, unofficial].
*   **Performance:** Improves PSNR from 35.50 to 35.54 compared to static initialization in the reported experiments [S2].
*   **Strengths:** Faster convergence, better quality, handles coarse-to-fine details effectively [S1, unofficial][S2].
*   **Limitations:** Requires careful tuning of `steps_per_field` and `receptive_fields_sizes`. Static mode (no progressive growing) may be simpler but slower or less stable [S1, unofficial].
