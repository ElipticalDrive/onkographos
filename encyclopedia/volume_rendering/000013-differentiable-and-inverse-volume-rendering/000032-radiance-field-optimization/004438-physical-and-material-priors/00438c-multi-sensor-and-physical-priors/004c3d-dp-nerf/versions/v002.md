# DP-NeRF

Also called: Deblurred Neural Radiance Field with Physical Scene Priors

## Overview
DP-NeRF is a framework for reconstructing clean 3D scenes from blurred input images (camera motion blur and defocus blur) by imposing two physical priors derived from the image acquisition process [S1]. It differs from prior methods like Deblur-NeRF by using 3D physical priors instead of 2D pixel-wise independent ray optimization, ensuring geometric and appearance consistency across views [S1]. Unlike Deblur-NeRF, which predicts a single blurred color, DP-NeRF employs two blurred color predictions to enable a coarse-to-fine optimization strategy [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of blurred RGB images $B_{sp}$ with known camera poses (calibrated via COLMAP) [S1].
*   **Outputs:** A trained "sharp" NeRF model capable of rendering clean novel views [S1].

**Data Structures:**
The method relies on the standard NeRF representation (MLPs for density $\sigma$ and color $\mathbf{c}$) augmented with two specific modules:
1.  **Rigid Blurring Kernel (RBK):**
    *   **Encoding Branch ($E$):** MLP with 4 fully-connected linear layers, each 64 dimensions, ReLU activation [S1].
    *   **Decoding Branches ($W, R, L$):** Each consists of one linear layer with 32 dimensions and an output linear layer [S1].
    *   **Outputs:**
        *   $m_s$: Motion weights, channel dimension $k$ (hyper-parameter controlling the number of rigid camera motions) [S1]. Normalized such that $\sum_{i=0}^{k} m_{s,i} = 1$ [S1].
        *   $r_s$: Rigid motion parameters, channel dimension $3k$ [S1].
        *   $v_s$: View-specific parameters, channel dimension $3k$ [S1].
    *   **Input:** View information $l_s$ embedded with 64 channels [S1].
2.  **Adaptive Weight Proposal (AWP):**
    *   Uses Feature Modulation (FM) and a Motion Feature Aggregation Module (MAM) [S1].
    *   **Inputs:** Depth features of samples for transformed rays, viewing direction, and view information [S1].
    *   **Notations (Default Values):**
        *   $l_s$: 64 channels [S1].
        *   $N_m$: Number of rigid motions ($k$) [S1].
        *   $N_s$: Total samples per ray ($N_c + N_f$) [S1].
        *   $N_c, N_f$: Coarse and fine samples (64 each) [S1].
        *   $\zeta_{motion}$: Motion feature (16 channels) [S1].
        *   $\zeta_{sample}$: Sample feature (16 channels) [S1].
        *   $\hat{\eta}_p$: Intermediate feature (32 channels) [S1].
        *   $\eta_p$: Final feature (32 channels) [S1].
        *   $C_{corr}$: Correlation operation [S1].

**Numbered Steps:**

1.  **Coarse Scene Initialization:** Train a pure NeRF for 1200 iterations to obtain a coarse scene representation [S1].
2.  **RBK Processing:**
    *   For each view, embed view information $l_s$ into 64 dimensions [S1].
    *   Pass $l_s$ through Encoding Branch $E$ [S1].
    *   Pass the encoded features through Decoding Branches $W, R, L$ to generate $m_s, r_s, v_s$ [S1].
    *   Use $r_s$ and $v_s$ to construct a 3D deformation field representing rigid camera motion, independent of 2D spatial ray position [S1].
    *   Compute a coarse blurred color prediction $\hat{B}_{sp}$ using the deformation field and the NeRF samples [S1].
3.  **AWP Processing:**
    *   For each ray, compute depth features for the transformed samples [S1].
    *   Aggregate motion features using MAM based on depth features, viewing direction, and view information [S1].
    *   Refine the composition weights using Feature Modulation [S1].
    *   Compute a fine blurred color prediction $\tilde{B}_{sp}$ [S1].
4.  **Loss Calculation:**
    *   Compute the coarse reconstruction loss $L_c = ||B_{sp} - \hat{B}_{sp}||$ [S1].
    *   Compute the fine reconstruction loss $L_f = ||B_{sp} - \tilde{B}_{sp}||$ [S1].
    *   Calculate the exponential decay weight $\lambda$ for the current iteration $e_c$:
        $$ \alpha = -\log(\lambda_s / \lambda_e) / (e_f - e_i) $$
        $$ \lambda = \lambda_s (\exp(\alpha(e_c - e_i))) $$
        where $e_i$ is the initial iteration (1200), $e_f$ is the final iteration (200,000), $\lambda_s = 0.9$, and $\lambda_e = 0.1$ [S1].
    *   Compute the final loss:
        $$ L_{final} = \lambda L_c + (1 - \lambda) L_f $$
        [S1].
5.  **Joint Optimization:**
    *   Optimize the RBK, AWP, and the sharp NeRF parameters jointly using the Adam optimizer [S1].
    *   Use only the reconstruction loss from the blurred input as supervision [S1].
    *   Train for 200,000 iterations total (80,000 iterations for the joint phase) [S1].
6.  **Inference:**
    *   Render clean novel views using only the trained sharp NeRF model, ignoring the RBK and AWP modules [S1].

**Parameters:**
*   $\lambda_s$: Initial weight for coarse-to-fine optimization, set to 0.9 [S1].
*   $\lambda_e$: Final weight for coarse-to-fine optimization, set to 0.1 [S1].
*   $k$: Hyper-parameter controlling the number of rigid camera motions in the RBK. Output channel dimensions for $m_s, r_s, v_s$ are $k, 3k, 3k$ respectively [S1].

**Edge Cases and Pitfalls:**
*   **Object Motion Blur:** The model assumes a static scene. It fails to reconstruct correct geometry for moving objects because it lacks multi-view data for a specific time instance [S1].
*   **Complex Depth/Textures:** The RBK alone may lose detail in regions with complex depth or similar textures; the AWP is required to refine these areas [S1].

## Operating characteristics
*   **Time Complexity:** Training involves joint optimization of NeRF, RBK, and AWP. The coarse-to-fine strategy stabilizes training but adds computational overhead due to the two parallel prediction paths (RBK and AWP) per ray [S1].
*   **Memory Complexity:** Standard NeRF memory usage plus overhead for RBK and AWP parameters. The RBK parameters are view-dependent but not ray-dependent, keeping memory usage manageable compared to per-pixel kernel methods [S1].
*   **Performance:** DP-NeRF achieves significant improvements in PSNR, SSIM, and LPIPS over Naive NeRF and Deblur-NeRF on synthetic and real scenes with camera motion and defocus blur [S1].
*   **Strengths:** Ensures 3D geometric and appearance consistency by using 3D physical priors (RBK) instead of 2D pixel-wise optimization [S1]. Handles both camera motion and defocus blur [S1].
*   **Limitations:** Cannot handle object motion blur due to the static scene assumption [S1]. Requires calibrated camera poses (COLMAP) [S1].

## Background
DP-NeRF was proposed in 2022 by the authors of the paper "DP-NeRF: Deblurred Neural Radiance Field with Physical Scene Priors" [S1]. It was developed to address the limitations of previous deblurring NeRF methods, specifically Deblur-NeRF, which relied on 2D pixel-wise independent ray optimization that broke 3D consistency [S1]. The method builds on the standard NeRF framework [26] and incorporates physical priors derived from the camera blurring process [S1]. It is used for novel view synthesis on synthetic and real scenes with blur [S1].
