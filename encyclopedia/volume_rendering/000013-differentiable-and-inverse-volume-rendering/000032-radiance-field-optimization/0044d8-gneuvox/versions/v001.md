# GNeuVox

Also called: Generalizable Neural Voxels

## Overview
GNeuVox is a rendering framework for fast, differentiable human body synthesis from monocular video [S1, unofficial]. It solves the high training cost of implicit NeRF-based methods by replacing the implicit MLP with an explicit representation of **generalizable neural voxels** for geometric priors and **individual neural voxels** for differential textures [S1, unofficial]. This explicit voxel-based approach significantly accelerates optimization, allowing a novel human body to be trained in approximately 5 minutes while maintaining rendering quality comparable to previous methods [S1, unofficial].

## How it works
GNeuVox computes a radiance field $f_\theta(\mathbf{x}, \mathbf{d})$ by combining explicit voxel features with a deformation network that maps observation coordinates to a canonical T-pose [S1, unofficial].

**Inputs and Outputs:**
*   **Inputs:** A monocular video sequence (images), initial human pose estimates $P$ (joint positions $J$ and rotation angles $\Omega$), and a learnable embedding vector $Z$.
*   **Outputs:** Rendered pixel color $\hat{C}(\mathbf{r})$ for a ray $\mathbf{r}$.

**Data Structures:**
1.  **General Voxels ($V_g$):** A 3D grid of features pretrained on various human bodies to represent a basic skeleton [S1, unofficial].
2.  **Individual Voxels ($V_i$):** A 3D grid of features specific to the target individual, optimized during fine-tuning [S1, unofficial].
3.  **Embedding ($Z$):** A learnable vector used to generate blend weights for deformation [S1, unofficial].

**Numbered Steps:**

1.  **Pose Refinement:** Adjust the initial pose $P$ to obtain a corrected pose $P_c$.
    $$P_c = (J_c, \Omega_c) = (J, \Omega \otimes \Delta\Omega)$$
    where $\otimes$ denotes the composition of rotation and translation: $(R_i \cdot \Delta R_i, T_i + \Delta T_i)$ [S1, unofficial]. $R_i, T_i$ and $\Delta R_i, \Delta T_i$ are derived from $\Omega$ and $\Delta\Omega$ respectively [S1, unofficial].

2.  **Coordinate Deformation:** Map observation coordinates $(x_o, y_o, z_o)$ to canonical space $(x_c, y_c, z_c)$ using the corrected pose $P_c$ and embedding $Z$.
    $$(x_c, y_c, z_c) = \mathbf{F}_d((x_o, y_o, z_o), P_c)$$
    The deformation function $\mathbf{F}_d$ uses the same structure as the skeletal deformation $T_{skel}$:
    $$T_{skel}(x, P_c) = \sum_{i=1}^K w^i(x)(R_c^i x + T_c^i)$$
    where $w^i(x)$ is the blend weight for the $i$-th bone [S1, unofficial].

3.  **Weight Generation:** Compute blend weights $w^i$ by mapping the learnable embedding $Z$ into a volume via 3D convolutional layers, followed by trilinear interpolation [S1, unofficial].

4.  **Feature Interpolation:** Interpolate features from both individual voxels $V_i$ and general voxels $V_g$ using the shifted canonical coordinates $(x_c, y_c, z_c)$ to obtain feature vectors $v_i$ and $v_g$ [S1, unofficial].

5.  **Radiance Field Query:** Feed $v_i$, $v_g$, the original observation coordinates $(x_o, y_o, z_o)$, ray direction $\mathbf{d}$, and timestamp $t$ into the radiance field network to obtain density $\sigma$ and color $\mathbf{c}$ [S1, unofficial].

6.  **Volume Rendering:** Accumulate colors along the ray $\mathbf{r}$:
    $$\hat{C}(\mathbf{r}) = \sum_{i=1}^N T_i(1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i$$
    where $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$, $\delta_i = t_{i+1} - t_i$ is the distance between adjacent points, and $N$ is the number of sampled points [S1, unofficial].

7.  **Loss Computation:** Optimize parameters to minimize the difference between rendered and ground truth colors:
    $$\mathcal{L} = \|\hat{C}(\mathbf{r}) - C(\mathbf{r})\|_2^2$$
    where $C(\mathbf{r})$ is the ground truth pixel color [S1, unofficial].

**Parameters:**
*   $L$: Controls the maximum frequency in positional encoding $\gamma(x) = (\sin(2^0 x), \cos(2^0 x), \dots, \sin(2^{L-1} x), \cos(2^{L-1} x))$ [S1, unofficial].

**Pseudocode:**

```python
def gneuvox_render(ray_origin, ray_direction, timestamp, initial_pose, 
                   general_voxels, individual_voxels, embedding_Z, 
                   pose_refinement_net, deformation_net, radiance_field, 
                   num_samples, L):
    """
    Renders a single ray using GNeuVox.
    
    Args:
        ray_origin: 3D vector (o)
        ray_direction: 3D vector (d)
        timestamp: float (t)
        initial_pose: tuple (J, Omega)
        general_voxels: 3D grid tensor
        individual_voxels: 3D grid tensor
        embedding_Z: learnable vector
        pose_refinement_net: function to compute Delta_Omega
        deformation_net: function implementing F_d
        radiance_field: function computing sigma and c from features
        num_samples: int N
        L: int for positional encoding
        
    Returns:
        rendered_color: 3D vector
    """
    
    # 1. Pose Refinement
    # Compute Delta_Omega from initial Omega
    delta_omega = pose_refinement_net(initial_pose.Omega)
    
    # Compose corrected pose Pc = (J, Omega otimes Delta_Omega)
    # otimes denotes (R_i * Delta_R_i, T_i + Delta_T_i)
    corrected_pose = compose_pose(initial_pose.J, initial_pose.Omega, delta_omega)
    
    # 2. Sample points along ray
    # Generate t_i from t_start to t_end, delta_i = t_{i+1} - t_i
    t_values = sample_points(num_samples)
    deltas = compute_deltas(t_values)
    
    rendered_color = 0.0
    transmittance = 1.0
    
    for i in range(num_samples):
        t_i = t_values[i]
        delta_i = deltas[i]
        
        # 3. Deform Coordinates
        # Observation coordinates
        x_obs = ray_origin + ray_direction * t_i
        
        # Map to canonical space using deformation network
        # F_d uses embedding Z and corrected_pose
        x_canonical = deformation_net(x_obs, corrected_pose, embedding_Z)
        
        # 4. Interpolate Features
        # Trilinear interpolation in general_voxels and individual_voxels
        v_g = trilinear_interpolate(general_voxels, x_canonical)
        v_i = trilinear_interpolate(individual_voxels, x_canonical)
        
        # 5. Radiance Field Query
        # Positional encoding for coordinates and direction
        pos_enc_coords = positional_encoding(x_obs, L)
        pos_enc_dir = positional_encoding(ray_direction, L)
        
        # Compute density and color
        sigma, color = radiance_field(v_g, v_i, pos_enc_coords, pos_enc_dir, timestamp)
        
        # 6. Volume Rendering Accumulation
        alpha = 1.0 - exp(-sigma * delta_i)
        weight = transmittance * alpha
        rendered_color += weight * color
        transmittance *= (1.0 - alpha)
        
    return rendered_color

def compose_pose(J, Omega, Delta_Omega):
    """
    Composes rotation and translation for pose refinement.
    Pc = (J, Omega otimes Delta_Omega)
    """
    # Extract R, T from Omega and Delta_R, Delta_T from Delta_Omega
    R, T = decompose_pose(Omega)
    Delta_R, Delta_T = decompose_pose(Delta_Omega)
    
    # Compose
    New_R = R @ Delta_R
    New_T = T + Delta_T
    
    return Pose(J, compose_rotation_translation(New_R, New_T))

def positional_encoding(x, L):
    """
    Computes positional encoding gamma(x).
    gamma(x) = (sin(2^0 x), cos(2^0 x), ..., sin(2^{L-1} x), cos(2^{L-1} x))
    """
    freq_bands = [2**i for i in range(L)]
    encoded = []
    for band in freq_bands:
        encoded.append(sin(band * x))
        encoded.append(cos(band * x))
    return concat(encoded)
```

## Operating characteristics
*   **Training Time:** Approximately 5 minutes for a novel human body [S1, unofficial].
*   **Performance:** Significantly higher training efficiency compared to previous NeRF-based methods, while maintaining similar rendering quality [S1, unofficial].
*   **Strengths:** Explicit neural voxel representation accelerates optimization; generalizable voxels provide strong geometric priors; fast fine-tuning for individual bodies.
*   **Limitations:** Requires monocular video input; relies on initial pose estimation (refined via pose refinement module); specific to human body rendering.
*   **When to use:** Fast training of dynamic human bodies from monocular video where implicit NeRF training is too slow.
*   **When not to use:** Static scenes, non-human subjects, or scenarios requiring high-fidelity generalization without per-scene fine-tuning.

## Background
GNeuVox was proposed in the paper "Generalizable Neural Voxels for Fast Human Radiance Fields" [S1, unofficial]. It builds on HumanNeRF [S1, unofficial], which introduced pose refinement and coordinate deformation networks for human body rendering. GNeuVox extends this by introducing explicit neural voxels (general and individual) to replace the implicit MLP, addressing the high computational cost of training NeRF-based methods for human bodies [S1, unofficial]. The method leverages the commonality of human skeletons across individuals by pretraining general voxels on various human bodies [S1, unofficial].
