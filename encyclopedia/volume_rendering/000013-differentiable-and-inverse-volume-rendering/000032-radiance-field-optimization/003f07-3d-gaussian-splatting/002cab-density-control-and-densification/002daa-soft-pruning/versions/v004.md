# Soft Pruning

Also called: Hessian-aware pruning, L1 loss pruning

## Overview
Soft Pruning is a density control method in 3D Gaussian Splatting that reduces the number of Gaussian primitives by removing those with low contribution to the training loss, specifically targeting the maintenance of a robust Hessian approximation [S1, S2]. It differs from its sibling [Hard Pruning](5591-hard-pruning.md) by occurring *during* the densification stage (immediately before opacity resets) rather than after, allowing the model to recover performance through subsequent refinement iterations [S1, S2].

## How it works
Soft Pruning is integrated into the densification pipeline to remove Gaussians when the L1 loss is small, ensuring that the remaining Gaussians provide a stable gradient signal for the Hessian-based optimization [S1].

**Inputs and Outputs:**
*   **Input:** The current set of 3D Gaussians $\{G_i\}$, the current training iteration $t$, and the accumulated L1 loss $\mathcal{L}_1$.
*   **Output:** A reduced set of Gaussians $\{G_i'\}$ with a specified pruning ratio.

**Data Structures:**
*   Each Gaussian $G_i$ retains its standard attributes: mean position $\mathbf{p}_i$, covariance matrix $\Sigma_i$ (or scale/rotation), opacity $\alpha_i$, and spherical harmonic coefficients.
*   The pruning decision is based on the magnitude of the L1 loss contribution or the accumulated gradient magnitude, though the specific "Efficient Pruning Score" formula is not explicitly detailed in the provided sources [S2]. The sources indicate that pruning is triggered when the L1 loss is small [S1].

**Steps:**
1.  **Check Pruning Condition:** Determine if the current iteration $t$ matches a predefined opacity reset iteration. The sources specify iterations 6000, 9000, and 12000 [S1].
2.  **Evaluate Pruning Score:** For each Gaussian $G_i$, compute a pruning score. The sources state that Soft Pruning uses an "Efficient Pruning Score" [S2] and is motivated by the observation that L1 loss becomes small by iteration 6000 [S1]. Gaussians with low scores (low loss contribution) are candidates for removal. [G: In the absence of the explicit score formula, the implementation should rank Gaussians by their accumulated L1 loss or gradient magnitude and select the bottom $R$ percent for removal, where $R$ is the pruning ratio.]
3.  **Apply Pruning Ratio:** Remove the bottom $R$ percent of Gaussians based on the score. The sources report that a pruning ratio of 80% preserves visual fidelity in experiments [S1].
4.  **Remove Gaussians:** Delete the selected Gaussians from the scene representation.
5.  **Continue Training:** Proceed with the opacity reset and subsequent densification steps (cloning/splitting) as defined in the parent [Density Control and Densification](5337-density-control-and-densification.md).

**Parameters:**
*   **Pruning Ratio ($R$):** The fraction of Gaussians to remove. Typical value: 0.8 (80%) [S1].
*   **Reset Iterations:** The iterations at which Soft Pruning is applied. Typical values: 6000, 9000, 12000 [S1].

**Edge Cases and Pitfalls:**
*   **Premature Pruning:** Pruning too early, before the L1 loss converges, may remove Gaussians that are still learning, leading to poor reconstruction. The method relies on the L1 loss being small [S1].
*   **Opacity Reset Interaction:** Soft Pruning is performed *immediately before* opacity resets. This timing is critical to maintain the Hessian approximation [S1].

**Pseudocode:**
```python
def soft_pruning(gaussians, current_iteration, reset_iterations, pruning_ratio):
    """
    Perform Soft Pruning on the set of Gaussians.
    
    Args:
        gaussians: List of Gaussian objects with attributes:
                   - p: mean position
                   - alpha: opacity
                   - loss: accumulated L1 loss or gradient magnitude
        current_iteration: int, current training iteration
        reset_iterations: list of int, iterations where opacity resets occur
        pruning_ratio: float, fraction of Gaussians to remove (e.g., 0.8)
        
    Returns:
        pruned_gaussians: List of Gaussian objects after pruning
    """
    # Step 1: Check if pruning is required at this iteration
    if current_iteration not in reset_iterations:
        return gaussians
    
    # Step 2: Evaluate pruning score
    # The sources mention an "Efficient Pruning Score" [S2] and L1 loss [S1].
    # We assume the score is inversely related to the loss/gradient magnitude.
    # Gaussians with lower scores are pruned.
    for g in gaussians:
        # [G] Placeholder for the specific Efficient Pruning Score formula.
        # Based on [S1], the method targets Gaussians with small L1 loss.
        # A simple implementation might use the accumulated L1 loss directly.
        g.pruning_score = g.loss 
        
    # Step 3: Sort Gaussians by pruning score (ascending, so lowest loss first)
    gaussians.sort(key=lambda g: g.pruning_score)
    
    # Step 4: Calculate number of Gaussians to remove
    num_to_remove = int(len(gaussians) * pruning_ratio)
    
    # Step 5: Remove the bottom R percent
    pruned_gaussians = gaussians[num_to_remove:]
    
    return pruned_gaussians
```

## Subtopics

### [Hard Pruning](5591-hard-pruning.md)
Hard Pruning is a density control method in 3D Gaussian Splatting that reduces model size by a constant ratio at fixed intervals after the densification stage. It differs from Soft Pruning by occurring post-densification rather than during it, relying on subsequent refinement iterations to recover performance.

## Operating characteristics
*   **Time Complexity:** The pruning step itself is $O(N \log N)$ due to sorting, where $N$ is the number of Gaussians. This is performed only at specific iterations (e.g., 6000, 9000, 12000), so the amortized cost per iteration is low [S1, S2].
*   **Memory Complexity:** Reduces memory usage by approximately 90% when combined with Hard Pruning, as it removes a significant portion of Gaussians [S2].
*   **Performance:** Improves rendering and training speed by reducing the number of primitives [S2]. Visual fidelity is preserved even with high pruning ratios (80%) [S1].
*   **Strengths:** Maintains Hessian approximation quality by pruning when loss is low [S1]. Integrates seamlessly into the existing densification pipeline [S2].
*   **Limitations:** Requires careful timing relative to opacity resets [S1]. The specific "Efficient Pruning Score" formula is not detailed, which may require empirical tuning [S2].

## Background
Soft Pruning was introduced in the "Speedy-Splat" paper [S1, S2]. It was developed to address the need for faster training and rendering in 3D Gaussian Splatting by reducing the number of Gaussians without sacrificing quality. The method leverages the observation that L1 loss converges quickly and remains low after initial training phases, allowing for aggressive pruning [S1].
