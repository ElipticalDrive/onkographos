# Steerable Densification with Sampling

Also called: Score-based ranking densification

## Overview
Steerable Densification with Sampling is a density control method for 3D Gaussian Splatting that replaces heuristic thresholding with a score-based ranking system to select candidates for resampling [S1]. It differs from standard 3DGS densification by incorporating image loss and per-pixel saliency directly into the selection probability, allowing for a significantly reduced densification frequency (every 500 iterations) while maintaining high quality [S1].

## How it works
**Inputs:**
*   Set of $N$ camera views $V = \{v_i\}_{i=1}^N$ [S1].
*   Set of $M$ fitted Gaussians $G = \{g_j\}_{j=1}^M$ [S1].
*   Set of $N$ rendered views $R = \{r_i\}_{i=1}^N$ [S1].
*   Budgeted target number of Gaussians to add $B$ [S1].
*   Hyperparameters: $\lambda_1=0.5, \lambda_2=0.5$ for saliency; weights for scoring function parameters [S1].

**Outputs:**
*   Updated set of Gaussians $G'$ with $B$ new primitives added via resampling [S1].

**Data Structures:**
*   **Saliency Matrix $S_v$**: A 2D matrix of size $H \times W$ (height $\times$ width) for each view $v$ [S1].
*   **Score Vector $S_G$**: A 1D vector of size $M$. $S_{g_j}$ is the accumulated score for Gaussian $g_j$ [S1].

**Numbered Steps:**

1.  **Compute Per-View Saliency Matrices:**
    For each view $v \in V$:
    $$ S_v = \mathbb{1}_{ROI} \odot (\lambda_1 L_1(v, r_v) + \lambda_2 E(v)) $$
    Where:
    *   $\mathbb{1}_{ROI}$ is a binary mask (0 or 1) indicating regions of interest [S1].
    *   $L_1(v, r_v)$ is the L1 loss between the rendered view and the ground truth [S1].
    *   $E(v)$ is the Laplacian filter applied to the rendered view to detect high-frequency information [S1].
    *   $\odot$ denotes element-wise multiplication [S1].

2.  **Compute Gaussian Scores:**
    For each Gaussian $g \in G$, compute its score $S_g$ by summing a scoring function $F$ over all $N$ views:
    $$ S_g = \sum_{i=1}^N F(\nabla_g, c_{gi}, \mathbb{1}_{gi}, D_{gi}, S_{vi}, B_{gi}, z_{gi}, o_g, s_g) $$
    The global score vector is $S_G = [S_{g_1}, \dots, S_{g_M}]^T$ [S1].

3.  **Resample Gaussians:**
    Randomly select $B$ primitives from the set $G$ using $S_G$ as sampling weights [S1]. The selected Gaussians are cloned or split (implementation detail of the underlying primitive operation, typically cloning at the same position with halved opacity/energy as per parent principles, though the source emphasizes the *selection* mechanism) to form the new set [S1].

**Scoring Function $F$:**
The function $F$ aggregates per-Gaussian and per-pixel metrics. Each parameter is median-scaled to remove outliers, multiplied by the photometric loss, and accumulated with specific weights [S1]:
$$ F = w_{\nabla} \cdot \text{scale}(\nabla_g) + w_{c} \cdot \text{scale}(c_{gi}) + w_{D} \cdot \text{scale}(D_{gi}) + w_{S} \cdot \text{scale}(S_{vi}) + w_{B} \cdot \text{scale}(B_{gi}) + w_{z} \cdot \text{scale}(z_{gi}) + w_{o} \cdot \text{scale}(o_g) + w_{s} \cdot \text{scale}(s_g) $$

**Parameters and Weights:**
*   $\nabla_g$: Magnitude of the positional gradient (Weight: 50). Acts as a 3D discontinuity detector [S1].
*   $c_{gi}$: Number of pixels covered by $g$ in view $i$ (Weight: 0.1) [S1].
*   $\mathbb{1}_{gi}$: Binary matrix indicating pixels covered by $g$ (Used in context of $c_{gi}$ or $D_{gi}$) [S1].
*   $D_{gi}$: Matrix of distances from each pixel to the center of $g$ (Weight: 50) [S1].
*   $S_{vi}$: Saliency value at the pixel location in view $i$ (Weight: 10) [S1].
*   $B_{gi}$: Blending weight of $g$ for each pixel (Weight: 50) [S1].
*   $z_{gi}$: Depth of $g$ in view $i$ (Weight: 5) [S1].
*   $o_g$: Opacity of $g$ (Weight: 100) [S1].
*   $s_g$: Scale of $g$ (Weight: 25) [S1].

**Pseudocode:**

```python
import random

def median(values):
    if not values: return 0.0
    s = sorted(values)
    n = len(s)
    mid = n // 2
    return s[mid] if n % 2 == 1 else (s[mid-1] + s[mid]) / 2.0

def weighted_sample(population, weights, k):
    total = sum(weights)
    if total <= 0: return random.sample(range(len(population)), min(k, len(population)))
    selected = []
    indices = list(range(len(population)))
    for _ in range(min(k, len(population))):
        r = random.uniform(0, total)
        cum = 0.0
        for idx in indices:
            cum += weights[idx]
            if cum >= r:
                selected.append(idx)
                indices.remove(idx)
                total -= weights[idx]
                break
    return selected

def compute_view_aggregates(g, view, S_v):
    # Simulates auxiliary rendering pass: projects Gaussian to view,
    # returns pixel count (c), mean distance (D), mean blending weight (B),
    # mean depth (z), and list of saliency values (S_vals) over covered pixels.
    # Implementation details depend on the specific rasterizer.
    return 10, 1.5, 0.8, 5.0, [0.5, 0.6, 0.4]

def steerable_densification(Gaussians, Views, Rendered_Views, Ground_Truth_Views, Budget_B, ROI_Masks=None):
    M = len(Gaussians)
    N = len(Views)
    if ROI_Masks is None:
        ROI_Masks = [[1.0] * len(Rendered_Views[0][0]) for _ in range(len(Rendered_Views[0]))]

    # Step 1: Compute Per-View Saliency Matrices
    saliency_matrices = []
    view_losses = []
    for i in range(N):
        r_v = Rendered_Views[i]
        gt_v = Ground_Truth_Views[i]
        roi = ROI_Masks[i] if i < len(ROI_Masks) else [[1.0] * len(r_v[0]) for _ in range(len(r_v))]
        h, w = len(r_v), len(r_v[0])
        # L1 loss
        l1 = [[abs(r_v[y][x] - gt_v[y][x]) for x in range(w)] for y in range(h)]
        # Laplacian filter (3x3)
        E_v = [[0.0]*w for _ in range(h)]
        for y in range(1, h-1):
            for x in range(1, w-1):
                E_v[y][x] = r_v[y-1][x] + r_v[y+1][x] + r_v[y][x-1] + r_v[y][x+1] - 4*r_v[y][x]
        # S_v = 1_ROI * (0.5 * L1 + 0.5 * E)
        lambda1, lambda2 = 0.5, 0.5
        S_v = [[roi[y][x] * (lambda1 * l1[y][x] + lambda2 * E_v[y][x]) for x in range(w)] for y in range(h)]
        saliency_matrices.append(S_v)
        view_losses.append(sum(sum(row) for row in l1) / (h * w))

    # Step 2: Compute Gaussian Scores
    raw_grads = [abs(g.grad_p) for g in Gaussians]
    raw_opacities = [g.opacity for g in Gaussians]
    raw_scales = [g.scale_norm for g in Gaussians]
    raw_c, raw_D, raw_B, raw_z, raw_S = [], [], [], [], []

    # Auxiliary rendering pass to gather per-view aggregates for each Gaussian
    for i in range(N):
        S_v = saliency_matrices[i]
        for g in Gaussians:
            c_ij, D_ij, B_ij, z_ij, S_vals = compute_view_aggregates(g, Views[i], S_v)
            raw_c.append(c_ij)
            raw_D.append(D_ij)
            raw_B.append(B_ij)
            raw_z.append(z_ij)
            raw_S.extend(S_vals)

    med_grad = median(raw_grads)
    med_c = median(raw_c)
    med_D = median(raw_D)
    med_B = median(raw_B)
    med_z = median(raw_z)
    med_S = median(raw_S)
    med_o = median(raw_opacities)
    med_s = median(raw_scales)

    w_grad, w_c, w_D, w_S, w_B, w_z, w_o, w_s = 50, 0.1, 50, 10, 50, 5, 100, 25
    scores = [0.0] * M

    for j, g in enumerate(Gaussians):
        score = 0.0
        s_grad = abs(g.grad_p) / med_grad if med_grad != 0 else 0.0
        s_o = g.opacity / med_o if med_o != 0 else 0.0
        s_s = g.scale_norm / med_s if med_s != 0 else 0.0

        for i in range(N):
            S_v = saliency_matrices[i]
            c_ij, D_ij, B_ij, z_ij, S_vals = compute_view_aggregates(g, Views[i], S_v)
            mean_S = sum(S_vals) / len(S_vals) if S_vals else 0.0

            s_c = c_ij / med_c if med_c != 0 else 0.0
            s_D = D_ij / med_D if med_D != 0 else 0.0
            s_B = B_ij / med_B if med_B != 0 else 0.0
            s_z = z_ij / med_z if med_z != 0 else 0.0
            s_S = mean_S / med_S if med_S != 0 else 0.0

            F_i = (w_grad * s_grad + w_c * s_c + w_D * s_D + w_S * s_S +
                   w_B * s_B + w_z * s_z + w_o * s_o + w_s * s_s)
            score += F_i * view_losses[i]
        scores[j] = score

    # Step 3: Resample
    selected_indices = weighted_sample(Gaussians, scores, Budget_B)
    new_gaussians = []
    for idx in selected_indices:
        g = Gaussians[idx]
        g_new = Gaussian(pos=g.pos, scale=g.scale, opacity=g.opacity / 2.0, rotation=g.rotation, features=g.features, grad_p=g.grad_p)
        new_gaussians.append(g_new)
    return Gaussians + new_gaussians
```

**Edge Cases and Pitfalls:**
*   **Zero Median:** If the median of a parameter is zero, scaling is undefined. The pseudocode handles this by returning 0 [G].
*   **High Opacity:** The source notes that high-opacity Gaussians (opacities > 1) can boost modeling of opaque surfaces and should be handled, potentially by conversion to clamped Gaussians [S1].
*   **Frequency:** Densification occurs every 500 iterations. Frequent densification with loss guidance can cause repeated duplication of misplaced Gaussians [S1].

## Operating characteristics
*   **Time Complexity:** Adds an extra $O(N \times \text{width} \times \text{height})$ step for computing all $N$ saliency matrices $S_v$, plus an auxiliary rendering pass to obtain $S_G$ [S1].
*   **Memory Complexity:** Requires storing $N$ saliency matrices of size $H \times W$ and intermediate projection data for all Gaussians across all views during the scoring phase [G].
*   **Performance:** Allows for high-quality radiance fields with limited resources (fewer Gaussians) by steering densification towards salient areas [S1].
*   **Strengths:** Interpretable, customizable sampling; reduces wasteful Gaussians compared to pure gradient-based methods; handles high-frequency details via Laplacian filter [S1].
*   **Limitations:** Higher computational overhead per densification step due to saliency computation and auxiliary rendering pass; requires careful tuning of weights [S1].

## Background
Steerable Densification with Sampling was introduced in "Taming 3DGS: High-Quality Radiance Fields with Limited Resources" (2024) [S1]. It addresses the issue of wasteful densification in standard 3D Gaussian Splatting by incorporating image loss and saliency into the selection process, allowing for a reduced densification frequency [S1].
