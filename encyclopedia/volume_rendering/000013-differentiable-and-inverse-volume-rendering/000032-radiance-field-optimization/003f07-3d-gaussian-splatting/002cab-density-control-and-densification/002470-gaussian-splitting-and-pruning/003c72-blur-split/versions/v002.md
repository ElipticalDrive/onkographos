# Blur Split

Also called: Blur Split strategy, Maximum contribution area splitting

## Overview
Blur Split is a densification technique for 3D Gaussian Splatting that addresses "under-reconstruction" and blur artifacts in regions with smooth color transitions where gradient-based methods fail [S1]. It identifies Gaussians with excessively large maximum contribution areas in screen space and splits them to improve local detail [S1]. Unlike standard pruning which removes large Gaussians, Blur Split actively refines them to resolve blurry regions [S1].

## How it works
**Inputs:**
- Set of Gaussians $\mathcal{G}$ with size $N$ [S1].
- Image resolution $H \times W$ [S1].
- Hyperparameter $\theta_{blur}$ [S1].

**Outputs:**
- Updated set of Gaussians $\mathcal{G}$, with oversized Gaussians replaced by split children [S1].

**Data Structures:**
- $\mathcal{G}$: List of Gaussian objects. Each Gaussian $G_i$ has properties: center, covariance (or scale/orientation), opacity, color, and a unique index $i \in [1, N]$ [G].
- $i_{max}(x)$: A buffer of size $H \times W$ storing the index of the Gaussian with the maximum weight at pixel $x$ [S1].
- $S_i$: A scalar value for each Gaussian representing its maximum contribution area [S1].

**Steps:**

1. **Forward Rasterization and Index Tracking:**
   During the standard alpha-blending rasterization pass, for each pixel $x$, determine the Gaussian $i$ that contributes the most to the final color [S1]. This is defined as:
   $$ i_{max}(x) = \arg \max_i w_i $$
   where $w_i$ is the weight of Gaussian $i$ at pixel $x$ [S1]. Store the index $i_{max}(x)$ for every pixel $x \in [1, H] \times [1, W]$ [S1].

2. **Compute Maximum Contribution Area ($S_i$):**
   For each Gaussian $i$, compute $S_i$, the number of pixels for which it is the maximum contributor:
   $$ S_i = \sum_{x=(1,1)}^{(H,W)} \delta(i(x) = i_{max}(x)) $$
   where $\delta$ is the indicator function (1 if true, 0 otherwise) [S1]. This sum can be accumulated during the forward rasterization pass by incrementing a counter for the winning Gaussian index at each pixel [S1].

3. **Identify Blurry Gaussians:**
   Calculate the threshold $\mathcal{T}_{blur}$:
   $$ \mathcal{T}_{blur} = \theta_{blur} \cdot H \cdot W $$
   Identify the set of Gaussians $\mathcal{G}^{blur}$ to be split:
   $$ \mathcal{G}^{blur} = \{ \mathcal{G}_i \mid S_i > \mathcal{T}_{blur} \wedge i \in [1, N] \} $$
   These Gaussians are considered to have large blurry areas and contribute to under-reconstruction [S1].

4. **Split Gaussians:**
   For each Gaussian $G_i \in \mathcal{G}^{blur}$, apply the gradient-based split and clone strategy from [17] to replace $G_i$ with smaller Gaussians [S1].

**Parameters:**
- $\theta_{blur}$: Hyperparameter controlling the extent of the blurry area. Empirically set to $2 \times 10^{-4}$ [S1].

## Operating characteristics
- **Time Complexity:** The identification step requires a full rasterization pass to compute $i_{max}(x)$ and accumulate $S_i$, which is $O(H \cdot W)$ per image [S1]. The splitting step is proportional to the number of Gaussians in $\mathcal{G}^{blur}$ [S1].
- **Memory Complexity:** Requires an additional buffer of size $H \cdot W$ to store $i_{max}(x)$ and an array of size $N$ to store $S_i$ [G].
- **Strengths:** Specifically targets "under-reconstruction" in smooth regions where gradient-based densification fails [S1]. Improves image clarity and reduces blur artifacts [S1].
- **Limitations:** Relies on the assumption that large maximum contribution areas correlate with blur/under-reconstruction [S1]. May increase the number of Gaussians significantly if many regions are blurry [G].
- **When to use:** When the reconstruction exhibits blurry artifacts in smooth color transition areas and gradient-based splitting is insufficient [S1].

## Background
Blur Split was introduced in "Mini-Splatting: Representing Scenes with a Constrained Number of Gaussians" [S1]. It addresses limitations of the original 3D Gaussian Splatting densification strategy, which relies on gradient magnitude and may fail in areas with smooth color transitions [S1]. The method leverages the observation that Gaussians with large maximum contribution areas in screen space are often responsible for under-reconstruction [S1].
