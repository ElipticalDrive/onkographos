# Coordinate System Conversion for Gaussian Splats

Also called: RUB to RDF conversion, convertCoordinates

## Overview
This method transforms Gaussian splat attributes (position, rotation, spherical harmonics) between different coordinate systems, such as converting from the Right-handed Up-Back (RUB) format used internally to the Right-handed Down-Forward (RDF) format used in PLY files [S1, unofficial]. It handles the specific axis flips and rotations required for quaternion and spherical harmonic consistency [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A `GaussianCloud` struct containing arrays of positions, rotations, scales, alphas, colors, and spherical harmonics (SH), along with metadata (`numPoints`, `shDegree`) [S1, unofficial].
- Output: The same `GaussianCloud` struct with attributes transformed to the target coordinate system [S1, unofficial].

**Data Structures:**
The `GaussianCloud` struct fields are: `numPoints` (`int32_t`), `shDegree` (`int32_t`), `antialiased` (`bool`), `positions` (`std::vector<float>`), `scales` (`std::vector<float>`), `rotations` (`std::vector<float>`), `alphas` (`std::vector<float>`), `colors` (`std::vector<float>`), `sh` (`std::vector<float>`), and `extensions` (`std::vector<SpzExtensionBasePtr>`) [S1, unofficial].
The `CoordinateConverter` struct `c` is computed via `coordinateConverter(from, to, shDegree)` and contains: `flipP` (array of 3 floats for position axis multipliers), `flipQ` (array of 3 floats for quaternion x, y, z multipliers), `flipSh` (array of floats for SH coefficient multipliers), `rotFlipPFunc` (optional function pointer for position transformation), `rotFlipQFunc` (optional function pointer for rotation transformation), and `rotFlipShFuncs` (array of optional function pointers for SH transformation) [S1, unofficial].

**Steps:**
1. If `numPoints` is 0, return immediately [S1, unofficial].
2. Compute the `CoordinateConverter` struct `c` for the source and target systems using `coordinateConverter(from, to, shDegree)` [S1, unofficial].
3. Transform positions: If `c.rotFlipPFunc` exists, call it for each point's 3 floats. Otherwise, multiply each axis $i$ by `c.flipP[i % 3]` [S1, unofficial].
4. Transform rotations: If `c.rotFlipQFunc` exists, call it for each point's 4 floats. Otherwise, multiply axes x, y, z by `c.flipQ[0..2]` respectively, leaving w untouched [S1, unofficial].
5. Transform Spherical Harmonics (SH): Calculate `numCoeffsPerPoint` from `sh.size() / 3 / numPoints`. If `c.rotFlipShFuncs[0]` exists (cross-family), iterate bands and channels, applying `rotFlipShFuncs` to temporary buffers. Otherwise (within-family), multiply all SH coefficients for each point by `c.flipSh[j]` [S1, unofficial].

**Formulas:**
- Volume calculation: $V = \frac{4}{3} \pi \exp(s_x + s_y + s_z)$, where $s_x, s_y, s_z$ are the log-scales [S1, unofficial].

**Parameters:**
- SH coefficient count per point depends on `shDegree`: 0→0, 1→9, 2→24, 3→45, 4→72 [S1, unofficial].
- The SH array layout uses the color channel as the inner axis and the coefficient index as the outer axis [S1, unofficial].

**Edge Cases and Pitfalls:**
- Precision issues may arise when flipping signs of quaternions if not handled correctly, though the method leaves $w$ untouched to preserve orientation [S1, unofficial].
- Cross-family SH transformations require temporary buffers and band/channel iteration, increasing implementation complexity compared to within-family multiplications [S1, unofficial].

**Pseudocode:**
```python
class CoordinateConverter:
    def __init__(self, flip_p, flip_q, flip_sh, rot_flip_p_func=None, rot_flip_q_func=None, rot_flip_sh_funcs=None):
        self.flip_p = flip_p
        self.flip_q = flip_q
        self.flip_sh = flip_sh
        self.rot_flip_p_func = rot_flip_p_func
        self.rot_flip_q_func = rot_flip_q_func
        self.rot_flip_sh_funcs = rot_flip_sh_funcs

def coordinate_converter(from_sys, to_sys, sh_degree):
    # The sources do not specify the internal implementation of this factory function.
    # It returns a CoordinateConverter instance with appropriate flip arrays and optional function pointers.
    return CoordinateConverter(
        flip_p=[1.0, 1.0, 1.0],
        flip_q=[1.0, 1.0, 1.0],
        flip_sh=[1.0],
        rot_flip_p_func=None,
        rot_flip_q_func=None,
        rot_flip_sh_funcs=[None]
    )

def convert_coordinates(cloud, from_sys, to_sys):
    if cloud.numPoints == 0:
        return

    c = coordinate_converter(from_sys, to_sys, cloud.shDegree)

    # Transform positions
    if c.rot_flip_p_func is not None:
        for i in range(cloud.numPoints):
            c.rot_flip_p_func(cloud.positions, i)
    else:
        for i in range(cloud.numPoints):
            base = i * 3
            cloud.positions[base] *= c.flip_p[0]
            cloud.positions[base + 1] *= c.flip_p[1]
            cloud.positions[base + 2] *= c.flip_p[2]

    # Transform rotations
    if c.rot_flip_q_func is not None:
        for i in range(cloud.numPoints):
            c.rot_flip_q_func(cloud.rotations, i)
    else:
        for i in range(cloud.numPoints):
            base = i * 4
            cloud.rotations[base] *= c.flip_q[0]
            cloud.rotations[base + 1] *= c.flip_q[1]
            cloud.rotations[base + 2] *= c.flip_q[2]
            # cloud.rotations[base + 3] (w) remains unchanged

    # Transform Spherical Harmonics
    num_coeffs_per_point = len(cloud.sh) // 3 // cloud.numPoints
    if c.rot_flip_sh_funcs[0] is not None:
        # Cross-family transformation using function pointers and temporary buffers.
        # The sources do not specify the exact temporary buffer management;
        # apply func to extracted coefficients and write back.
        for i in range(cloud.numPoints):
            for band in range(cloud.shDegree + 1):
                for channel in range(3):
                    func = c.rot_flip_sh_funcs[band][channel]
                    if func is not None:
                        pass
    else:
        # Within-family transformation using simple multiplication
        for i in range(cloud.numPoints):
            base = i * num_coeffs_per_point * 3
            for j in range(num_coeffs_per_point):
                for channel in range(3):
                    idx = base + j * 3 + channel
                    cloud.sh[idx] *= c.flip_sh[j]
```
