# 2D Skew-Normal Parameter Projection

Also called: 2D Kernel Parameter Projection, SN2D Projection, Skew-Normal 2D Parameter Computation

## Overview
Computes the parameters of a 2D Skew-Normal distribution (SN2D) resulting from the linear projection of a 3D Skew-Normal kernel (SN3) onto the image plane [S1, unofficial]. It sets apart from standard Gaussian splatting by preserving the asymmetry (skewness) of the 3D primitive during projection, allowing the 2D kernel to model one-sided surfaces and sharp boundaries that symmetric Gaussians cannot [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D Skew-Normal kernel parameters $\mathcal{X} \sim \text{SN3}(\mu, \Omega, \alpha)$, where $\mu \in \mathbb{R}^3$ is the mean, $\Omega \in \mathbb{R}^{3 \times 3}$ is the covariance, and $\alpha \in \mathbb{R}^3$ is the skewness parameter.
*   **Input:** Projection matrix $A \in \mathbb{R}^{2 \times 3}$ (typically the view-projection matrix rows corresponding to the image plane).
*   **Output:** 2D Skew-Normal parameters $\mathcal{Y} \sim \text{SN2}(\mu_Y, \Omega_Y, \alpha_Y)$, where $\mu_Y \in \mathbb{R}^2$, $\Omega_Y \in \mathbb{R}^{2 \times 2}$, and $\alpha_Y \in \mathbb{R}^2$.

**Data Structures:**
The 3D kernel is typically parameterized using a rotation matrix $R \in \mathbb{R}^{3 \times 3}$, a scale matrix $S \in \mathbb{R}^{3 \times 3}$ (diagonal), and a skewness vector $k \in \mathbb{R}^3$. The covariance is $\Omega = R S S^\top R^\top$. The skewness parameter is $\alpha = \omega R S^{-1} k$, where $\omega = (1 + k^\top k)^{-1/2}$ [S1, unofficial].

**Steps:**
1.  **Compute 2D Mean:**
    $$ \mu_Y = A \mu $$
2.  **Compute 2D Covariance:**
    $$ \Omega_Y = A \Omega A^\top $$
3.  **Compute Intermediate Vector $v$:**
    Calculate the term $\omega \delta$ from the 3D parameters. Using the structural definition $\alpha = \omega R S^{-1} k$, this simplifies to [S1, unofficial]:
    $$ \omega \delta = \frac{R S k}{\sqrt{1 + k^\top k}} $$
    Let $v = A (\omega \delta) = \frac{A R S k}{\sqrt{1 + k^\top k}}$.
4.  **Compute 2D Skewness $\alpha_Y$:**
    The skewness parameter $\alpha_Y$ is derived from $\delta_Y$ and the normalized covariance $\bar{\Omega}_Y = \Omega_Y^{-1/2} \Omega_Y \Omega_Y^{-1/2}$ (which simplifies to identity in the normalized space, but the formula uses the inverse covariance directly) [S1, unofficial]. The final projection formula is [S1, unofficial]:
    $$ \alpha_Y = \frac{\omega_Y \Omega_Y^{-1} v}{\sqrt{1 - v^\top \Omega_Y^{-1} v}} $$
    Substituting $v$:
    $$ \alpha_Y = \frac{\omega_Y \Omega_Y^{-1} \left( \frac{A R S k}{\sqrt{1 + k^\top k}} \right)}{\sqrt{1 - \left( \frac{A R S k}{\sqrt{1 + k^\top k}} \right)^\top \Omega_Y^{-1} \left( \frac{A R S k}{\sqrt{1 + k^\top k}} \right)}} $$
    Where $\omega_Y = (1 + \alpha_Y^\top \bar{\Omega}_Y \alpha_Y)^{-1/2}$ is the normalization factor for the 2D distribution, though in the derivation, the denominator term $\sqrt{1 - \delta_Y^\top \bar{\Omega}_Y^{-1} \delta_Y}$ handles the normalization implicitly via the relation $\delta_Y = \bar{\Omega}_Y^{1/2} \alpha_Y / \sqrt{1 + \alpha_Y^\top \bar{\Omega}_Y \alpha_Y}$ [S1, unofficial].

```python
import numpy as np

def project_skew_normal_3d_to_2d(mu_3d, R, S, k, A):
    """
    Projects a 3D Skew-Normal kernel to 2D.
    
    Args:
        mu_3d: (3,) array, 3D mean.
        R: (3, 3) array, rotation matrix.
        S: (3,) array, scale vector (diagonal elements of S matrix).
        k: (3,) array, skewness vector.
        A: (2, 3) array, projection matrix.
        
    Returns:
        mu_2d: (2,) array, 2D mean.
        Omega_2d: (2, 2) array, 2D covariance.
        alpha_2d: (2,) array, 2D skewness parameter.
    """
    # 1. Compute 2D Mean
    mu_2d = A @ mu_3d
    
    # 2. Compute 3D Covariance Omega = R * diag(S)^2 * R^T
    S_mat = np.diag(S)
    Omega_3d = R @ (S_mat @ S_mat.T) @ R.T
    
    # 3. Compute 2D Covariance
    Omega_2d = A @ Omega_3d @ A.T
    
    # 4. Compute intermediate vector v = A * (R * S * k / sqrt(1 + k^T k))
    # Note: S is diagonal, so S @ k is element-wise multiplication
    k_norm_sq = np.dot(k, k)
    scale_factor = 1.0 / np.sqrt(1.0 + k_norm_sq)
    
    # R @ (S @ k)
    R_S_k = R @ (S * k)

    v = scale_factor * (A @ R_S_k)

    Omega_2d_inv = np.linalg.inv(Omega_2d)
    
    numerator = Omega_2d_inv @ v
    denominator_term = v.T @ Omega_2d_inv @ v
    denominator = np.sqrt(1.0 - denominator_term)
    
    alpha_2d = numerator / denominator
    
    return mu_2d, Omega_2d, alpha_2d
```

**Edge Cases and Pitfalls:**
*   **Singularity:** If $\Omega_Y$ is singular (e.g., the kernel is viewed edge-on and collapses to a line), $\Omega_Y^{-1}$ does not exist. Regularization or culling is required [G].
*   **Domain Error:** The term $1 - v^\top \Omega_Y^{-1} v$ must be positive. If the projection results in a degenerate distribution where the skewness vector is too large relative to the covariance, the square root becomes imaginary. This indicates the 3D kernel is projected into a region where the Skew-Normal approximation is invalid or the kernel is too skewed for the 2D plane [S1, unofficial].

## Subtopics

### Skew-Normal CDF Evaluation
Evaluating the Skew-Normal distribution requires computing the Cumulative Distribution Function (CDF). The implementation uses the `erf` function for mathematical precision [S1, unofficial]. Using the precise `erf` function incurs moderate penalties on rendering speed compared to faster analytic approximations [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per kernel for the projection, dominated by matrix inversions ($2 \times 2$) and vector multiplications.
*   **Memory Complexity:** $O(1)$ additional memory per kernel for storing the projected parameters.
*   **Strengths:** Preserves asymmetry in the 2D projection, enabling better reconstruction of sharp edges and one-sided surfaces compared to symmetric Gaussian splatting [S1, unofficial].
*   **Limitations:** Requires careful handling of singular covariances and domain errors in the square root term. The use of `erf` for CDF evaluation slows down rendering compared to simpler approximations [S1, unofficial].

## Background
Originated in the paper "3D Skew-Normal Splatting" [S1, unofficial]. The method extends the standard Gaussian Splatting framework by replacing the symmetric 3D Gaussian kernel with the Azzalini Skew-Normal distribution to model asymmetric structures [S1, unofficial]. The 2D projection formula is derived from the properties of the Skew-Normal distribution under linear transformations [S1, unofficial].
