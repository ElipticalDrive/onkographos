# Spherical Harmonics Initialization


## Overview
Spherical Harmonics Initialization sets the initial view-dependent appearance parameters for 3D Gaussians by populating only the zeroth-order (DC) spherical harmonic coefficients with input RGB colors [S1, unofficial]. It solves the problem of providing a valid, view-independent color baseline for the radiance field before optimization begins. Unlike [Spherical Harmonics Evaluation](3848-spherical-harmonics-evaluation.md), which computes full view-dependent color from existing coefficients, this method initializes the storage structure itself [S1, unofficial]. It differs from [Spherical Harmonics Rotation](3985-spherical-harmonics-rotation.md) by not performing coordinate transformations, and from [Spherical Harmonics Decoding](7901-spherical-harmonics-decoding.md) by focusing on the initial assignment rather than unpacking [S6, S7, unofficial].

## How it works
**Inputs:**
- `N`: Number of 3D Gaussians.
- `colors`: An array or tensor of shape $(N, 3)$ containing the initial RGB color values for each Gaussian.

**Outputs:**
- `sh_coeffs`: A tensor of shape $(N, 27)$ containing the initialized spherical harmonic coefficients.

**Data Structures:**
- The SH coefficients are stored in a flattened format. For degree 3 (the standard in 3D Gaussian Splatting), there are 9 coefficients per color channel (R, G, B).
- Total coefficients per Gaussian: $3 \text{ channels} \times 9 \text{ coefficients/channel} = 27$.
- The layout corresponds to the standard SH basis ordering, where index 0 is the DC term for Red, index 1 for Green, and index 2 for Blue. Higher-order terms follow sequentially.

**Steps:**
1. Allocate a zero tensor `sh_coeffs` of shape $(N, 3, 9)$ to hold the coefficients for all $N$ Gaussians and 3 color channels.
2. For each Gaussian $i$ from $0$ to $N-1$:
   a. Retrieve the input RGB color vector $\mathbf{C} = [R, G, B]$.
   b. Compute the DC coefficient $c_0$ for each channel using the normalization constant $\alpha = 0.28209479177387814$.
   c. Assign the computed DC coefficient to the first index (index 0) of the corresponding channel in the tensor.
   d. All other coefficients (indices 1–8 for each channel) remain zero.
3. Flatten the last two dimensions of the tensor from shape $(N, 3, 9)$ to $(N, 27)$.

**Formula:**
The DC coefficient $c_0$ is derived from the input color $C$ (where $C$ is R, G, or B) as follows:

$$
c_0 = \frac{C}{\alpha}
$$

Where:
- $c_0$ is the zeroth-order spherical harmonic coefficient.
- $C$ is the input RGB value (normalized to $[0, 1]$ or $[0, 255]$ depending on the pipeline, but the division applies to the numeric value).
- $\alpha = 0.28209479177387814$ is the normalization constant for the zeroth-order spherical harmonic basis function $Y_0^0 = \frac{1}{\sqrt{4\pi}} \approx 0.28209479177387814$ [S1, unofficial].

**Parameters:**
- $\alpha = 0.28209479177387814$: The constant value of the zeroth-order SH basis function [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Color Range:** The input RGB values must be consistent with the expected range. If the input is in $[0, 255]$, the resulting coefficients will be scaled accordingly. If the input is in $[0, 1]$, the coefficients will be smaller. The optimization process must be aware of this scale [G].
- **Higher-Order Terms:** All higher-order SH coefficients (indices 1–26) are initialized to zero. This implies an isotropic, view-independent color at initialization. The optimizer must learn the view-dependent variations [S1, unofficial].
- **Tensor Shape:** Ensure the final output is flattened to $(N, 27)$ if the rendering pipeline expects a flat coefficient array. Some implementations may keep the $(N, 3, 9)$ shape; consistency with the rest of the pipeline is critical [G].

**Pseudocode:**

```python
import numpy as np

def initialize_sh(colors: np.ndarray) -> np.ndarray:
    """
    Initialize spherical harmonic coefficients for 3D Gaussian Splatting.
    
    Args:
        colors: Array of shape (N, 3) containing RGB values for N Gaussians.
        
    Returns:
        sh_coeffs: Array of shape (N, 27) containing initialized SH coefficients.
    """
    N = colors.shape[0]
    
    # Normalization constant for zeroth-order SH basis function Y_0^0
    alpha = 0.28209479177387814
    
    # Allocate zero tensor of shape (N, 3, 9)
    # 3 channels (R, G, B), 9 coefficients per channel (degree 3)
    sh_coeffs_3d = np.zeros((N, 3, 9))
    
    # Assign DC coefficients (index 0) for each channel
    # colors[:, 0] is Red, colors[:, 1] is Green, colors[:, 2] is Blue
    sh_coeffs_3d[:, 0, 0] = colors[:, 0] / alpha
    sh_coeffs_3d[:, 1, 0] = colors[:, 1] / alpha
    sh_coeffs_3d[:, 2, 0] = colors[:, 2] / alpha
    
    # Flatten to shape (N, 27)
    sh_coeffs = sh_coeffs_3d.reshape(N, 27)
    
    return sh_coeffs
```

## Operating characteristics
- **Time Complexity:** $O(N)$, where $N$ is the number of Gaussians. The operation involves a simple division and assignment for each Gaussian.
- **Memory Complexity:** $O(N)$, storing 27 coefficients per Gaussian.
- **Strengths:** Simple, fast, and provides a valid starting point for optimization. It ensures that the initial color is correctly scaled for the SH basis.
- **Limitations:** Does not provide any view-dependent appearance initially. The optimizer must learn all view-dependent effects from scratch.
- **When to Use:** Standard initialization for 3D Gaussian Splatting when RGB colors are available from a source (e.g., SfM points).
- **When Not to Use:** If view-dependent appearance is critical from the start and cannot be learned quickly, or if a different initialization strategy (e.g., geometry-aware) is preferred.

## Background
Spherical Harmonics Initialization is a standard step in the 3D Gaussian Splatting pipeline, as implemented in various open-source repositories [S1, unofficial]. It relies on the mathematical property that the zeroth-order SH basis function is a constant, allowing direct mapping of RGB colors to the DC coefficient. The normalization constant $\alpha$ is derived from the integral of the SH basis function over the sphere [S1, unofficial].
