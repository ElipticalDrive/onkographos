# Spherical Harmonics Initialization
## Overview
Spherical Harmonics Initialization sets the initial view-dependent color coefficients for 3D Gaussian splats by assigning input RGB colors to the zeroth-order (DC) spherical harmonic term while zeroing all higher-order coefficients [S1, unofficial]. It differs from [Angle-pose Cuboid Uniform Initialization (ACUI)](4503-angle-pose-cuboid-uniform-initialization-acui.md) and [DreamGaussian](5998-dreamgaussian.md) by handling only color parameterization rather than spatial attributes, and from [Spherical Harmonics Evaluation](3848-spherical-harmonics-evaluation.md) by preparing the static coefficient tensor for optimization rather than computing color at runtime [G].
## How it works
**Inputs and Outputs:**
- Input: An array of $N$ RGB colors, shape $(N, 3)$ [S1, unofficial].
- Output: A tensor of SH coefficients, shape $(N, 27)$ [S1, unofficial].
**Data Structures:**
- `sh_coeffs`: A float32 tensor of shape $(N, 3, 9)$ before flattening, organized as 3 color channels $\times$ 9 SH coefficients per Gaussian [S1, unofficial].
**Steps:**
1. Allocate a zero tensor `sh_coeffs` of shape $(N, 3, 9)$ [S1, unofficial].
2. For each Gaussian $i$ from $0$ to $N-1$:
   a. Retrieve the input RGB color vector $\mathbf{C} = [R, G, B]$ [S1, unofficial].
   b. Compute the DC coefficient $c_0$ for each color channel using the formula:
      $$ c_0 = \frac{\text{RGB}}{0.28209479177387814} $$
      where $0.28209479177387814$ is the normalization constant for the zeroth-order spherical harmonic basis function [S1, unofficial].
   c. Assign $c_0$ to index 0 of the SH coefficient array for that channel; indices 1 through 8 remain 0 [S1, unofficial].
3. Flatten the last two dimensions of `sh_coeffs` from $(N, 3, 9)$ to $(N, 27)$ [S1, unofficial].
**Pseudocode:**
```python
import numpy as np

def initialize_sh(rgb_colors: np.ndarray) -> np.ndarray:
    """
    Initialize spherical harmonic coefficients for 3D Gaussian splatting.
    
    Args:
        rgb_colors: Array of shape (N, 3) containing RGB values.
        
    Returns:
        Array of shape (N, 27) containing flattened SH coefficients.
    """
    N = rgb_colors.shape[0]
    # Allocate zero tensor of shape (N, 3, 9)
    sh_coeffs = np.zeros((N, 3, 9), dtype=np.float32)
    
    # Normalization constant for zeroth-order SH basis function
    SH_DC_NORMALIZATION = 0.28209479177387814
    
    # Assign scaled RGB values to the DC coefficient index (0) for all channels
    # rgb_colors shape: (N, 3)
    # sh_coeffs[:, :, 0] shape: (N, 3)
    sh_coeffs[:, :, 0] = rgb_colors / SH_DC_NORMALIZATION
    
    # Flatten the last two dimensions to produce a tensor of shape (N, 27)
    sh_coeffs_flat = sh_coeffs.reshape(N, 27)
    
    return sh_coeffs_flat
```
**Parameters:**
- `0.28209479177387814`: Normalization constant for the zeroth-order spherical harmonic basis function [S1, unofficial].
**Edge Cases and Pitfalls:**
- The source does not specify input RGB range conventions; implementations typically assume normalized $[0, 1]$ values consistent with the basis function scaling [G].
- Higher-order coefficients (indices 1–8 per channel) are explicitly zero-initialized, implying an isotropic initial color appearance [G].
## Subtopics

### [Splat Initialization from Normalized Coordinates](3595-splat-initialization-from-normalized-coordinates.md)
Initializes a single 3D Gaussian splat (SH degree 3) from normalized coordinates in $[-0.5, 0.5]^3$, setting uniform scale, identity rotation, full opacity, and deriving DC color from the spatial position. Choose this when tying initial color to scene geometry is desired. Differs from Spherical Harmonics Initialization by deriving color from coordinates rather than external RGB values [G].

### [Spherical Harmonics Evaluation](3848-spherical-harmonics-evaluation.md)
Computes view-dependent RGB color by projecting stored SH coefficients onto a viewing direction vector. Choose this for real-time rendering of anisotropic appearance. Differs from Spherical Harmonics Initialization by being a runtime rendering step rather than an initialization routine [G].
