# Inverse Gaussian Splattling

Also called: 2D to 3D Back-projection, Back-projection of 2D Gaussians, Geometric Back-projection, Inverse Gaussian Splattering, Inverse splatting

## Overview
Inverse Gaussian Splattling is a method for initializing 3D Gaussian primitives by back-projecting optimized 2D Gaussian kernels from image space into world space [S1, unofficial]. It solves the problem of generating high-quality initial geometric parameters (position, rotation, scale) for new 3D Gaussians from 2D renderings, specifically handling foreground-background ambiguity in boundary regions [S1, unofficial]. It differs from standard initialization by using Weighted Principal Component Analysis (WPCA) on clustered 3D points derived from depth maps, followed by a scaling calibration step to align the projected 3D covariance with the original 2D target [S1, unofficial].

## How it works
**Inputs:**
- `gaussian_2d`: A 2D Gaussian primitive with center $(u, v)$, covariance matrix $\hat{\Sigma}_{2D}$, and opacity/weight distribution.
- `depth_map`: A rendered depth map corresponding to the camera view.
- `camera`: Camera intrinsic and extrinsic parameters.

**Outputs:**
- `position`: 3D world-space coordinates.
- `rotation`: 3D Gaussian rotation (quaternion).
- `scaling`: 3D Gaussian scaling factors.
- `opacity_lobes`: View-dependent opacity parameters ($T, \beta$).
- `color`: Base color and opacity.

**Data Structures:**
- `pixels_world`: List of 3D points $(x, y, z)$ and their corresponding 2D Gaussian weights $w_i$.
- `groups`: Clusters of points from hierarchical clustering.

**Parameters:**
- `A`: Threshold multiplier. Initial value is 5.0 (derived from $5 \cdot \delta_d$ where $\delta_d$ is the world-space distance between adjacent pixels at the center depth) [S1, unofficial].
- `threshold_increase`: Factor by which to increase the clustering threshold if clustering fails. Value: 1.5 [S1, unofficial].

**Steps:**

1. **Compute 3D Coordinates:**
   For all pixels covered by the 2D Gaussian kernel (determined by the support of $\hat{\Sigma}_{2D}$), compute the 3D world coordinates using the depth map and camera parameters. Assign each point a weight equal to the 2D Gaussian distribution value at that pixel.

2. **Foreground-Background Separation (Clustering):**
   - Initialize `threshold` = $5 \cdot \delta_d$, where $\delta_d$ is the world-space distance between adjacent pixels at the depth of the Gaussian center [S1, unofficial].
   - Perform hierarchical clustering (single-linkage merging) on `pixels_world` using `threshold` as the distance limit [S1, unofficial].
   - Check if any cluster contains at least 3 points and covers the Gaussian center's pixel.
   - If no such cluster exists, select the largest cluster with at least 3 points.
   - If clustering fails to produce a valid cluster (or if the center is not covered), increase `threshold` by multiplying by 1.5 and repeat clustering [S1, unofficial].

3. **Weighted PCA (WPCA):**
   - Select the valid cluster from Step 2. Let this set be `filtered_points`.
   - Determine if the Gaussian center's pixel is included in `filtered_points` (boolean `INCLUDE_CENTER`) [S1, unofficial].
   - Compute WPCA on `filtered_points` using the 2D Gaussian weights.
   - The principal axes form the rotation matrix $R$ (converted to quaternion).
   - The standard deviations $\sigma_1, \sigma_2, \sigma_3$ from WPCA form the base scaling vector [S1, unofficial].

4. **Position Determination:**
   - If `INCLUDE_CENTER` is true:
     - Sample the depth value $d$ from the `depth_map` at the Gaussian center $(u, v)$ [S1, unofficial].
   - If `INCLUDE_CENTER` is false:
     - Compute the weighted average depth $\bar{d}$ of `filtered_points`, where weights are the 2D Gaussian distribution values [S1, unofficial].
     - Set $d = \bar{d}$.
   - Convert $(u, v, d)$ to world space using the camera parameters to get `position` [S1, unofficial].

5. **Scaling Calibration:**
   - Project the current 3D Gaussian (defined by `position`, `rotation`, and base `scaling` from WPCA) into the 2D image space to obtain the projected covariance matrix $\Sigma_{2D}$ [S1, unofficial].
   - The relationship is given by:
     $$ \Sigma_{2D} = J W_{RS} (J W_{RS})^T $$
     where $J \in \mathbb{R}^{2\times3}$ is the Jacobian of the projective transformation, $W$ is the world-to-view matrix, $R$ is the rotation matrix, and $S = \text{diag}(\sigma_1, \sigma_2, \sigma_3)$ is the scaling diagonal matrix [S1, unofficial].
   - Define $Q = \Sigma_{2D} / k^2$, where $k$ is the target scaling coefficient [S1, unofficial].
   - Minimize the Frobenius norm between the projected covariance and the target 2D covariance $\hat{\Sigma}_{2D}$:
     $$ \min_k ||\Sigma_{2D} - \hat{\Sigma}_{2D}||_F $$
   - The solution for $k$ is:
     $$ k = \sqrt{\frac{\sum_{ij} Q_{ij} \hat{\Sigma}_{2D_{ij}}}{||Q||_F^2}} $$
     where $||Q||_F$ is the Frobenius norm of $Q$ [S1, unofficial].
   - Update the scaling: $S_{final} = k \cdot \text{diag}(\sigma_1, \sigma_2, \sigma_3)$ [S1, unofficial].

6. **Opacity Lobe and Color Initialization:**
   - **Opacity Lobe Orientation:** Set to the unit vector from the Gaussian centroid to the camera [S1, unofficial].
   - **Width $T$:** Initialize as $c \bar{\theta}_i / \pi$, where $\bar{\theta}_i$ is the minimum angle between the viewing vector and the lobe orientation for visible cameras $C_i$, and $c$ is a constant [S1, unofficial].
   - **Sharpness $\beta$:** Initialize to 0 [S1, unofficial].
   - **Color/Opacity:** Initialize base color and opacity to the 2D primitive counterparts. Zero-initialize higher-order spherical harmonic coefficients [S1, unofficial].

**Pseudocode:**

```python
def inverse_splatting(gaussian_2d, depth_map, camera):
    # Step 1: Compute 3D coordinates for all pixels covered by the 2D Gaussian
    pixels_world = pixels_covered(gaussian_2d, depth_map, camera)
    
    # Step 2: Foreground-background separation
    # Initial threshold is 5 * world-space distance between adjacent pixels at center depth
    center_depth = sample_tex(depth_map, gaussian_2d.center)
    delta_d = world_space_pixel_distance(center_depth, camera)
    threshold = 5.0 * delta_d
    
    groups = None
    while True:
        groups = cluster_points(pixels_world, threshold)
        # Check for valid cluster: at least 3 points and covers center pixel
        valid_cluster = find_cluster_covering_center(groups, gaussian_2d.center, min_size=3)
        if valid_cluster is not None:
            break
        # If clustering fails or no valid cluster, increase threshold
        threshold = threshold * 1.5
        
    filtered_points = valid_cluster.points
    INCLUDE_CENTER = valid_cluster.includes_center
    
    # Step 3: Weighted Principal Component Analysis (WPCA)
    rotation, scaling_base = WPCA(filtered_points, gaussian_2d.weights)
    
    # Step 4: Position determination
    if INCLUDE_CENTER:
        depth = sample_tex(depth_map, gaussian_2d.center)
    else:
        depth = weighted_mean(filtered_points.depth, gaussian_2d.weights)
        
    position = depth_to_world(depth, gaussian_2d.center, camera)
    
    # Step 5: Scaling calibration
    # Project current 3D Gaussian to 2D
    Q = project_covariance(rotation, scaling_base, position, camera)
    # Q is Sigma_2D / k^2
    
    # Calculate scaling factor k
    numerator = sum(Q[i][j] * gaussian_2d.cov[i][j] for i in range(2) for j in range(2))
    denominator = frobenius_norm(Q) ** 2
    k = sqrt(numerator / denominator)
    
    scaling = k * scaling_base
    
    # Step 6: Opacity Lobe and Color Initialization
    # Opacity lobe orientation
    lobe_orientation = normalize(camera.position - position)
    
    # Width T (requires access to other camera views for theta_i)
    # T = c * min_angle_between_viewing_vector_and_lobe / pi
    # [Implementation detail: compute min angle across visible cameras]
    
    # Sharpness beta
    beta = 0.0
    
    # Color and SH
    color = gaussian_2d.color
    opacity = gaussian_2d.opacity
    sh_coeffs = zero_initialize_higher_order_sh()
    
    return position, rotation, scaling, lobe_orientation, beta, color, opacity, sh_coeffs
```

## Operating characteristics
- **Time Complexity:** Dominated by clustering and WPCA. Clustering is $O(N \log N)$ or $O(N^2)$ depending on implementation, where $N$ is the number of pixels covered by the 2D Gaussian. WPCA is $O(N)$ for fixed dimensionality.
- **Memory Complexity:** $O(N)$ to store the 3D points and weights for the covered pixels.
- **Strengths:** Handles foreground-background ambiguity effectively by clustering. Provides geometrically consistent initializations for view-dependent opacity models.
- **Limitations:** Requires accurate depth maps. Fails if the Gaussian covers too few points (<3) even after threshold adjustment. Relies on the assumption that the 2D Gaussian accurately represents the local surface structure.

## Background
Inverse Gaussian Splattling was introduced in "Augmented Radiance Field: A General Framework for Enhanced Gaussian Splatting" (ICLR 2026) [S1, unofficial]. It addresses the limitations of standard 3D Gaussian Splatting initialization by incorporating view-dependent opacity models (based on Phong shading) which require careful initialization of opacity lobes. The method back-projects 2D Gaussians optimized in image space to 3D space to serve as initializations for new 3D Gaussians, improving reconstruction fidelity, particularly in complex radiance distributions [S1, unofficial].
