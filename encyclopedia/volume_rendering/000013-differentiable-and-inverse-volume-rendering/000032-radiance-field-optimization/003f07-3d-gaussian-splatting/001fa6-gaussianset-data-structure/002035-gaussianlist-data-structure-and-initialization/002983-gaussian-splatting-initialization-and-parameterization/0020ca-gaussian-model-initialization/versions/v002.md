# Gaussian Model Initialization
## Overview
Gaussian Model Initialization populates learnable parameters (position, features, scaling, rotation, and opacity) from input data, typically a Structure-from-Motion (SfM) point cloud [S1, unofficial]. It sets itself apart from sibling methods like [Spherical Harmonics Initialization](3163-spherical-harmonics-initialization.md) by handling full geometric and attribute seeding rather than just color parameterization, and from [Angle-pose Cuboid Uniform Initialization (ACUI)](4503-angle-pose-cuboid-uniform-initialization-acui.md) by relying on sparse reconstruction data rather than uniform volumetric sampling [S1, 3163-spherical-harmonics-initialization.md, 4503-angle-pose-cuboid-uniform-initialization-acui.md, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A point cloud with $N$ points, where each point has a 3D position $\mathbf{p} \in \mathbb{R}^3$ and an RGB color $\mathbf{c} \in \mathbb{R}^3$ [S1, unofficial].
- Output: A `GaussianModel` instance containing tensors for $\mathbf{xyz}$, $\mathbf{features\_dc}$, $\mathbf{scaling}$, $\mathbf{rotation}$, and $\mathbf{opacity}$ [S1, unofficial].

**Data Structures:**
The model stores parameters as PyTorch tensors on the target device (CPU or CUDA) [S1, unofficial].
- `_xyz`: Shape $(N, 3)$, float32.
- `_features_dc`: Shape $(N, 1, 3)$, float32. Stores the zeroth-order spherical harmonic coefficients (DC color) [S1, 3163-spherical-harmonics-initialization.md, unofficial].
- `_scaling`: Shape $(N, 3)$, float32. Stores the log-scale of the Gaussian axes [S1, unofficial].
- `_rotation`: Shape $(N, 4)$, float32. Stores quaternions $(w, x, y, z)$ [S1, unofficial].
- `_opacity`: Shape $(N, 1)$, float32. Stores initial opacity values [S1, unofficial].

**Numbered Steps:**
1. **Model Instantiation:** Create the `GaussianModel` object and move it to the target device (CPU or CUDA) [S1, unofficial].
2. **Point Cloud Population:** Call `create_from_pcd(xyz, rgb)` to populate the model parameters [S1, unofficial].
   - **Position:** Initialize `_xyz` directly from the input point cloud coordinates [S1, unofficial].
   - **Color:** Initialize `_features_dc` with the input RGB colors; higher-order spherical harmonic coefficients remain zero [S1, 3163-spherical-harmonics-initialization.md, unofficial].
   - **Opacity:** Initialize `_opacity` to a uniform default value (e.g., 0.1) [G].
   - **Scaling:** Initialize `_scaling` based on the nearest neighbor distances of the point cloud to ensure appropriate initial Gaussian size [S2].
   - **Rotation:** Initialize `_rotation` to identity quaternions $(1, 0, 0, 0)$, implying no initial rotation [S2].
3. **Covariance Verification:** Ensure the computed covariance matrix $\Sigma$ is symmetric. The covariance is derived from scaling and rotation, and a test check verifies `torch.allclose(cov0, cov0.T, atol=1e-6)` [S1, unofficial].

**Parameters:**
- Learning rate for `_xyz`: $0.00016$ [S1, unofficial].
- Learning rate for `_features_dc`: $0.0025$ [S1, unofficial].

**Pseudocode:**
```python
import torch
import numpy as np

class GaussianModel:
    def __init__(self):
        self._xyz = None
        self._features_dc = None
        self._scaling = None
        self._rotation = None
        self._opacity = None
        self.device = 'cpu'

    def to(self, device):
        self.device = device
        return self

    def create_from_pcd(self, xyz, rgb):
        N = xyz.shape[0]
        self._xyz = torch.tensor(xyz, dtype=torch.float32, device=self.device)
        self._features_dc = torch.tensor(rgb, dtype=torch.float32, device=self.device).unsqueeze(1)
        self._opacity = torch.ones((N, 1), dtype=torch.float32, device=self.device) * 0.1

        # Scaling: nearest neighbor distance
        dists = np.linalg.norm(xyz[:, np.newaxis, :] - xyz[np.newaxis, :, :], axis=2)
        np.fill_diagonal(dists, np.inf)
        nn_dists = np.min(dists, axis=1)
        self._scaling = torch.tensor(np.tile(np.log(nn_dists + 1e-6), (3, 1)).T, dtype=torch.float32, device=self.device)

        # Rotation: identity quaternions
        self._rotation = torch.zeros((N, 4), dtype=torch.float32, device=self.device)
        self._rotation[:, 0] = 1.0

    def get_covariance(self):
        # R from quaternions (w, x, y, z)
        q = self._rotation / self._rotation.norm(dim=1, keepdim=True)
        w, x, y, z = q[:, 0], q[:, 1], q[:, 2], q[:, 3]
        R = torch.stack([
            1 - 2*(y**2 + z**2), 2*(x*y - w*z), 2*(x*z + w*y),
            2*(x*y + w*z), 1 - 2*(x**2 + z**2), 2*(y*z - w*x),
            2*(x*z - w*y), 2*(y*z + w*x), 1 - 2*(x**2 + y**2)
        ], dim=1).view(-1, 3, 3)
        # S from log-scale
        s = torch.exp(self._scaling)
        S = torch.zeros_like(R)
        S[:, 0, 0] = s[:, 0]
        S[:, 1, 1] = s[:, 1]
        S[:, 2, 2] = s[:, 2]
        # Sigma = R S S^T R^T
        cov = R @ (S @ S.transpose(1, 2)) @ R.transpose(1, 2)
        return cov
```

## Subtopics

### [Spherical Harmonics Initialization](3163-spherical-harmonics-initialization.md)
Sets the initial view-dependent color representation by populating only the zeroth-order (DC) spherical harmonic coefficients with the input RGB colors, while leaving higher-order coefficients at zero. It provides a valid, differentiable starting point for color optimization, focusing exclusively on color parameterization rather than geometric pose and scale distribution [G]. Choose when only color initialization is required.

### [Angle-pose Cuboid Uniform Initialization (ACUI)](4503-angle-pose-cuboid-uniform-initialization-acui.md)
A deterministic initialization strategy for X-ray novel view synthesis that computes camera parameters directly from scanner specifications and uniformly samples Gaussian centers within a bounding cuboid, replacing Structure-from-Motion (SfM). It solves feature detection failure in low-contrast, overlapping X-ray projections and significantly reduces training time compared to SfM-based initialization. Choose when SfM fails on volumetric or X-ray data.

### [DreamGaussian](5998-dreamgaussian.md)
A 2-stage text-to-3D method that SDS-optimizes Gaussians from a generated image and refines via UV-texture diffusion, generating a textured mesh in 2 minutes. Choose for text-driven 3D generation pipelines.

### R2-Gaussian Initialization
Uses the Feldkamp-Davis-Kress (FDK) algorithm to reconstruct a low-quality volume in under 1 second [S2]. Excludes empty spaces with a density threshold $\tau$ and randomly samples $M$ points as kernel positions [S2]. Sets Gaussian scales to nearest neighbor distances and assumes no rotation [S2]. Queries central densities from the FDK volume and scales them down by $k$ to compensate for kernel overlay [S2]. Parameters: $M = 50,000$ initial Gaussians, $\tau = 0.05$ density threshold, $k = 0.15$ scaling term [S2]. Choose for X-ray tomographic reconstruction.

### GS-W Sampling Coordinate Initialization
Initializes $K$ learnable sampling coordinates per Gaussian point to enable adaptive feature sampling on $K$ feature maps [S3]. Assigns each point $i$ coordinates $(sc_1^i, \dots, sc_K^i) \in \mathbb{R}^{K \times 2}$ [S3]. Randomly generates $K$ matrices $(M^1, \dots, M^K) \in \mathbb{R}^{K \times 2 \times 3}$ with row sums equal to 1 [S3]. Computes initial coordinates via $(sc_1^1, \dots, sc_K^K)_{init} = (M^1 X_i, \dots, M^K X_i)$ [S3]. Parameter: $K = 3$ feature maps [S3]. Choose when adaptive feature sampling across multiple maps is required.

### Persistent Material Descriptors
Attaches samples $(m_{ik}, b_{ik})$ with weights based on initial Gaussian support at sampled voxels, keeping identifiers and weights fixed during optimization [S4, unofficial]. Computes weight $w_{ik} \propto \exp\left(-\frac{1}{2}(\mathbf{x}_{ik} - \boldsymbol{\mu}_i)^\top \Sigma_i^{-1}(\mathbf{x}_{ik} - \boldsymbol{\mu}_i)\right)$, normalized to sum to 1 [S4, unofficial]. Clone and split children inherit descriptors from the nearest pre-existing primitive; pruning applies one mask to all attributes [S4, unofficial]. Pitfall: The descriptor is scale-aware; sub-voxel primitives concentrate on their own material, while larger primitives integrate over their footprint [S4, unofficial]. Choose for material-aware volume rendering where geometry optimization must not disrupt material assignments.

### PhysGaussian
Uses the Material Point Method (MPM) over Gaussians, providing a unified representation for both rendering and simulation of materials like cloth, jelly, sand, and snow [S5, unofficial]. Introduced in CVPR'24 [S5, unofficial]. Choose when physics-based simulation and rendering are required simultaneously.

### GaussianEditor
A text-driven local editing method using Hierarchical Gaussian Semantic Tracing and diffusion-guided refinement [S5, unofficial]. Introduced by Chen et al. in CVPR'24 [S5, unofficial]. Choose for semantic, text-guided local scene editing.

## Operating characteristics
- **Time Complexity:** Not given in the sources. FDK reconstruction for R2-Gaussian completes in under 1 second [S2].
- **Memory Complexity:** Not given in the sources.
- **Strengths:** Provides a geometrically grounded starting point for optimization using standard SfM data [S1, unofficial].
- **Limitations:** Relies entirely on the quality of the input point cloud; poor reconstruction yields poor initialization [S1, unofficial]. Does not natively handle volumetric data without variants like R2-Gaussian [S2].
- **When to use:** Standard 3DGS training on image collections with reliable SfM data [S1, unofficial].
- **When not to use:** Volumetric tomography (use R2-Gaussian) [S2], unconstrained collections needing adaptive features (use GS-W) [S3], or material/physics-aware rendering (use Persistent Material Descriptors/PhysGaussian) [S4, S5, unofficial].

## Background
Originated with the introduction of 3D Gaussian Splatting [S1, unofficial]. The `create_from_pcd` method populates the model with point cloud data (xyz, rgb) [S1, unofficial]. Variants extend the method to X-ray tomography (R2-Gaussian) [S2], adaptive feature sampling (GS-W) [S3], material descriptors (FactorSplat) [S4, unofficial], and physics/text-driven editing (PhysGaussian, GaussianEditor) [S5, unofficial].
