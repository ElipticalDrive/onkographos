# GaussianList Data Structure and Initialization

Also called: GaussianList

## Overview
The `GaussianList` is a column-major data structure that stores a batch of 3D Gaussian primitives for efficient differentiable volume rendering [S1, unofficial]. It organizes learnable parameters (means, covariances, opacities, and spherical harmonics) into a format suitable for batched linear algebra operations during optimization [S1, unofficial].

## How it works

### Inputs and Outputs
*   **Input**: A vector of Gaussian objects containing raw position, scale, opacity, rotation quaternion, and spherical harmonic coefficients [S1, unofficial].
*   **Output**: A populated `GaussianList` instance with pre-computed 3D covariance matrices [S1, unofficial].

### Data Structures
The `GaussianList` struct stores attributes in column-major matrices to facilitate batch processing [S1, unofficial]. The fields are:

1.  `positions`: `na::Matrix4xX<f32>` (4 rows $\times$ $N$ columns). Stores 4D homogeneous coordinates [S1, unofficial].
2.  `scales`: `na::Matrix3xX<f32>` (3 rows $\times$ $N$ columns). Stores scale components [S1, unofficial].
3.  `opacities`: `na::DVector<f32>` (1D vector of size $N$). Stores opacity values [S1, unofficial].
4.  `rotations`: `na::Matrix4xX<f32>` (4 rows $\times$ $N$ columns). Stores quaternion components [S1, unofficial].
5.  `sh`: `Matrix48xX<f32>` (48 rows $\times$ $N$ columns). Stores spherical harmonic coefficients [S1, unofficial].
6.  `num_gaussians`: `usize`. The count of Gaussians $N$ [S1, unofficial].
7.  `cov3d`: `na::Matrix3xX<f32>` (3 rows $\times$ $N$ columns). Pre-allocated zeros, filled by `compute_cov3d()` [S1, unofficial].

**Spherical Harmonics Layout**: Within each column of the `sh` matrix, coefficients are stored in the order: $C_{0,R}, C_{0,B}, C_{0,G}, C_{1,R}, C_{1,B}, C_{1,G}, \dots$, corresponding to RGB channels for each SH degree/order [S1, unofficial].

### Initialization Steps

1.  **Set Count**: Set `num_gaussians` to the length of the input Gaussian vector [S1, unofficial].
2.  **Construct Positions**: Iterate over the input Gaussians, clone position components $(x, y, z)$, and append $1.0$ to create 4D homogeneous coordinates [S1, unofficial].
3.  **Construct Scales**: Clone scale components $(s_x, s_y, s_z)$ into `scales` [S1, unofficial].
4.  **Construct Opacities**: Clone opacity values into `opacities` [S1, unofficial].
5.  **Construct Rotations**: Clone quaternion components $(q_x, q_y, q_z, q_w)$ into `rotations` [S1, unofficial].
6.  **Construct SH Coefficients**: Clone spherical harmonic coefficients into `sh` [S1, unofficial].
7.  **Initialize Covariance Buffer**: Initialize `cov3d` with zeros of size $3 \times N$ [S1, unofficial].
8.  **Compute Covariances**: Call `compute_cov3d()` to calculate the 3D covariance matrices based on rotations and scales [S1, unofficial].

### Centering the Gaussian Positions
To ensure numerical stability, the positions are centered around their centroid [S1, unofficial].

1.  Initialize `avg_pos` as a zero `Vector3` [S1, unofficial].
2.  Iterate over all $N$ Gaussians, adding each position $\mathbf{p}_i$ to `avg_pos` [S1, unofficial].
3.  Compute the mean: $\mathbf{\mu} = \frac{1}{N} \sum_{i=0}^{N-1} \mathbf{p}_i$ [S1, unofficial].
4.  Iterate over all $N$ Gaussians again, updating each position: $\mathbf{p}_i \leftarrow \mathbf{p}_i - \mathbf{\mu}$ [S1, unofficial].

### Computing 3D Covariance Matrices (`compute_cov3d`)
For each Gaussian $i$ from $0$ to $N-1$:

1.  Extract the rotation quaternion $\mathbf{q}_i$ from `rotations` column $i$ [S1, unofficial].
2.  Convert $\mathbf{q}_i$ to a `UnitQuaternion`, then to a $3 \times 3$ rotation matrix $\mathbf{R}_i$ [S1, unofficial].
3.  Create a diagonal scale matrix $\mathbf{S}_i$:
    $$
    \mathbf{S}_i = \begin{bmatrix}
    s_{x,i}^2 & 0 & 0 \\
    0 & s_{y,i}^2 & 0 \\
    0 & 0 & s_{z,i}^2
    \end{bmatrix}
    $$
    where $s_{x,i}, s_{y,i}, s_{z,i}$ are from `scales` column $i$ [S1, unofficial].
4.  Compute the covariance matrix $\mathbf{\Sigma}_i$:
    $$
    \mathbf{\Sigma}_i = \mathbf{R}_i \mathbf{S}_i \mathbf{R}_i^\top
    $$
    [S1, unofficial].
5.  Copy the resulting $3 \times 3$ matrix into `cov3d` at offset $i \times 3$ (column-major storage) [S1, unofficial].

### Projecting 3D Covariance to 2D Screen Space (`project_cov3d_to_screen`)
This function computes the 2D covariance matrix for a single Gaussian given a camera view [S1, unofficial].

**Inputs**:
*   `cov3d`: The $3 \times 3$ 3D covariance matrix for the Gaussian.
*   `pos_w`: The 3D position of the Gaussian in world space.
*   `viewmatrix`: The $4 \times 4$ view matrix.
*   `focal_x`, `focal_y`: Focal lengths in pixels.
*   `htanfovxy`: Tangent of half the horizontal and vertical FOV.

**Steps**:
1.  Convert `pos_w` to homogeneous vector: $\mathbf{p}_h = [x, y, z, 1.0]^\top$ [S1, unofficial].
2.  Transform to camera space: $\mathbf{p}_{cam} = \text{viewmatrix} \times \mathbf{p}_h$ [S1, unofficial].
3.  Compute tangents of the Gaussian center:
    $$
    t_x = \frac{p_{cam,x}}{p_{cam,z}}, \quad t_y = \frac{p_{cam,y}}{p_{cam,z}}
    $$
    [S1, unofficial].
4.  Clamp tangents to limits defined by $1.3 \times \tan(\text{FOV})$:
    $$
    t_x = \text{clamp}(t_x, -1.3 \cdot \tan(\text{FOV}_x), 1.3 \cdot \tan(\text{FOV}_x))
    $$
    $$
    t_y = \text{clamp}(t_y, -1.3 \cdot \tan(\text{FOV}_y), 1.3 \cdot \tan(\text{FOV}_y))
    $$
    Multiply back by $p_{cam,z}$ to get screen-space tangents $t.x$ and $t.y$ [S1, unofficial].
5.  Compute the Jacobian $J$ ($3 \times 3$ matrix) using $focal_x, focal_y, t.x, t.y, t.z$ (where $t.z = p_{cam,z}$) [S1, unofficial].
6.  Compute $W$ as the transpose of the top-left $3 \times 3$ submatrix of the view matrix [S1, unofficial].
7.  Compute $T = W \times J$ [S1, unofficial].
8.  Compute the projected 2D covariance:
    $$
    \mathbf{\Sigma}_{2D} = T^\top \mathbf{\Sigma}_{3D}^\top T
    $$
    [S1, unofficial].
9.  Extract the top-left $2 \times 2$ submatrix as `cov2d` [S1, unofficial].
10. Apply low-pass filter by adding $0.3$ to the diagonal elements:
    $$
    \mathbf{\Sigma}_{2D}[0,0] \leftarrow \mathbf{\Sigma}_{2D}[0,0] + 0.3
    $$
    $$
    \mathbf{\Sigma}_{2D}[1,1] \leftarrow \mathbf{\Sigma}_{2D}[1,1] + 0.3
    $$
    [S1, unofficial].
11. Return `cov2d` [S1, unofficial].

### Evaluating Color from Spherical Harmonics
1.  Pass the SH coefficients column for the given index, the SH dimension, and the viewing direction to `eval_spherical_harmonics` [S1, unofficial].
2.  Return the resulting color vector and the Gaussian's opacity [S1, unofficial].

### Pseudocode

```python
import numpy as np

def initialize_gaussian_list(input_gaussians):
    N = len(input_gaussians)
    num_gaussians = N
    positions = np.zeros((4, N))
    scales = np.zeros((3, N))
    opacities = np.zeros(N)
    rotations = np.zeros((4, N))
    sh = np.zeros((48, N))
    cov3d = np.zeros((3, N))
    for i in range(N):
        g = input_gaussians[i]
        positions[0:3, i] = g.position
        positions[3, i] = 1.0
        scales[:, i] = g.scale
        opacities[i] = g.opacity
        rotations[:, i] = g.rotation
        sh[:, i] = g.sh
    cov3d = compute_cov3d(scales, rotations, N)
    positions = center_positions(positions, N)
    return {'positions': positions, 'scales': scales, 'opacities': opacities, 'rotations': rotations, 'sh': sh, 'num_gaussians': num_gaussians, 'cov3d': cov3d}

def compute_cov3d(scales, rotations, N):
    cov3d = np.zeros((3, N))
    for i in range(N):
        q = rotations[:, i]
        R = quaternion_to_rotation_matrix(q)
        s_x, s_y, s_z = scales[0, i], scales[1, i], scales[2, i]
        S = np.diag([s_x**2, s_y**2, s_z**2])
        cov = R @ S @ R.T
        cov3d[:, i] = cov.flatten()
    return cov3d

def center_positions(positions, N):
    avg_pos = np.zeros(3)
    for i in range(N):
        avg_pos += positions[0:3, i]
    avg_pos /= N
    for i in range(N):
        positions[0:3, i] -= avg_pos
    return positions

def quaternion_to_rotation_matrix(q):
    x, y, z, w = q
    norm = np.sqrt(x**2 + y**2 + z**2 + w**2)
    x, y, z, w = x/norm, y/norm, z/norm, w/norm
    xx, yy, zz = x*x, y*y, z*z
    xy, xz, yz = x*y, x*z, y*z
    wx, wy, wz = w*x, w*y, w*z
    return np.array([
        [1 - 2*(yy + zz), 2*(xy - wz), 2*(xz + wy)],
        [2*(xy + wz), 1 - 2*(xx + zz), 2*(yz - wx)],
        [2*(xz - wy), 2*(yz + wx), 1 - 2*(xx + yy)]
    ])

def project_cov3d_to_screen(cov3d_col, pos_w, viewmatrix, focal_x, focal_y, htanfovxy):
    pos_h = np.array([pos_w[0], pos_w[1], pos_w[2], 1.0])
    pos_cam = viewmatrix @ pos_h
    tz = pos_cam[2]
    tx = pos_cam[0] / tz
    ty = pos_cam[1] / tz
    htan_fovx, htan_fovy = htanfovxy
    limit_x = 1.3 * htan_fovx
    limit_y = 1.3 * htan_fovy
    tx = np.clip(tx, -limit_x, limit_x)
    ty = np.clip(ty, -limit_y, limit_y)
    tx *= tz
    ty *= tz
    J = np.array([
        [focal_x / tz, 0, -focal_x * tx / (tz**2)],
        [0, focal_y / tz, -focal_y * ty / (tz**2)],
        [0, 0, 1]
    ])
    W = viewmatrix[:3, :3].T
    T = W @ J
    cov3d_mat = cov3d_col.reshape(3, 3)
    cov2d = T.T @ cov3d_mat.T @ T
    cov2d = cov2d[:2, :2]
    cov2d[0, 0] += 0.3
    cov2d[1, 1] += 0.3
    return cov2d
```

### Edge Cases and Pitfalls
*   **Division by Zero**: In `project_cov3d_to_screen`, if $z_{cam} = 0$, the tangent calculation fails. A guard value (e.g., $10^{-6}$) should be used [G].
*   **FOV Clamping**: The limit $1.3 \times \tan(\text{FOV})$ prevents extreme tangents that could cause numerical instability or incorrect projection for Gaussians near the frustum boundaries [S1, unofficial].
*   **Low-Pass Filter**: The constant $0.3$ ensures the Gaussian is at least one pixel wide/high, preventing aliasing and numerical issues with very small covariances [S1, unofficial].
*   **Quaternion Normalization**: Quaternions must be normalized before converting to rotation matrices to ensure valid rotation matrices [G].

## Subtopics

### [LinPrim Population Control](2295-linprim-population-control.md)
LinPrim Population Control manages the density of linear primitives (octahedra and tetrahedra) during differentiable volume rendering optimization by pruning, cloning, and splitting primitives to adapt to scene complexity. It differs from standard 3D Gaussian Splatting (3DGS) by redefining primitive size metrics to accommodate non-spherical kernels and adjusting sampling distributions to respect the anisotropic geometry of linear primitives. It builds on [GaussianList Data Structure and Initialization](2214-gaussianlist-data-structure-and-initialization.md) and adapts techniques from [Gaussian Splatting Initialization and Parameterization](2313-gaussian-splatting-initialization-and-parameterization.md).

### [Gaussian Splatting Initialization and Parameterization](2313-gaussian-splatting-initialization-and-parameterization.md)
This method establishes the initial state of the learnable 3D Gaussian point cloud for differentiable rendering training. It solves the problem of converting raw geometric data (typically from Structure-from-Motion pipelines like COLMAP) or random noise into a set of valid, differentiable parameters (means, covariances, opacities, and spherical harmonics) that can be optimized via gradient descent. It is distinguished from sibling methods like [LinPrim Population Control](2295-linprim-population-control.md) by focusing exclusively on the *creation* and *parameterization* of the initial set, rather than the dynamic modification of that set during training.

## Background
