# Composite Error Map and Densification/Pruning Scoring

Also called: EffGS density control, Frequency-aware mask scoring

## Overview
A density control mechanism for 3D Gaussian Splatting that uses a frequency-aware mask and photometric loss to compute densification and pruning scores for Gaussian primitives, reducing redundancy and improving fidelity compared to vanilla 3DGS [S1, unofficial]. It sets itself apart from visibility-based siblings like [Efficient Pruning Score](3598-efficient-pruning-score.md) by weighting counts with photometric loss rather than relying solely on projected footprint visibility, and from [Fisher Sensitivity Score](9664-fisher-sensitivity-score.md) by using a composite error mask rather than a Hessian approximation [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Set of Gaussian primitives $\mathcal{G}_t$ at update step $t$, a set of $K$ sampled training views, rendered images $I_{\text{rend}}$, ground-truth images $I_{\text{gt}}$, frequency-aware masks $M_{\text{freq}}$, and hyperparameters $\tau$ (error threshold), $\tau_p$ (pruning threshold), $\tau_d$ (densification threshold), $\tau_s$ (scale threshold), $\rho$ (pruning sample ratio), $\lambda_{\text{dssim}}$ (SSIM weight) [S1, unofficial].
*   **Outputs:** Updated set of Gaussian primitives $\mathcal{G}_{t+1}$ after pruning and densification [S1, unofficial].

**Data Structures:**
*   **Gaussian Primitive $i$:** Contains opacity $o_i$, learnable scale-modulation factor $\gamma_i$, unconstrained modulation parameter $\beta_i$ (where $\gamma_i = 2 \text{sigmoid}(\beta_i)$), positional gradient, base-scale components, and other attributes (position, rotation, scale, color) as defined in [Gaussian Data Structure](2273-gaussian-data-structure.md) [S1, unofficial].
*   **Active Primitive Set $\mathcal{A}_t$:** Subset of $\mathcal{G}_t$ containing primitives with valid projected footprints in sampled views [S1, unofficial].
*   **Composite Error Mask $M_{\text{err}}^j$:** Binary mask per view $j$ indicating pixels with significant reconstruction error [S1, unofficial].

**Numbered Steps:**

1.  **Compute Active Primitives $\mathcal{A}_t$:**
    *   Sample $K$ distinct training views uniformly without replacement [S1, unofficial].
    *   For each Gaussian $i \in \mathcal{G}_t$, determine the projected radius $r_i^j$ for each sampled view $j$ [S1, unofficial].
    *   Define the set of views with valid footprint: $\mathcal{V}_i = \{j : r_i^j > 0\}$. Count valid views as $|\mathcal{V}_i| = \sum_{j=1}^K \mathbb{I}[r_i^j > 0]$ [S1, unofficial].
    *   Define active set: $\mathcal{A}_t = \{i \in \mathcal{G}_t : |\mathcal{V}_i| > 0\}$ [S1, unofficial].
    *   If $\mathcal{A}_t = \emptyset$, skip density control [S1, unofficial].

2.  **Compute Composite Error Map $M_{\text{err}}^j$ for each sampled view $j$:**
    *   Compute raw per-pixel RGB reconstruction error:
        $$e^j(\mathbf{u}) = \frac{1}{3} \sum_{c=1}^3 \left| I_{\text{rend},c}^j(\mathbf{u}) - I_{\text{gt},c}^j(\mathbf{u}) \right|$$
    *   Normalize error over pixel grid $\mathcal{P}_j$ using min-max normalization $\mathcal{N}_{\mathcal{P}_j}$ (constant inputs mapped to zero):
        $$\bar{e}^j(\mathbf{u}) = \mathcal{N}_{\mathcal{P}_j}[e^j](\mathbf{u})$$
    *   Compute composite error mask using frequency-aware mask $M_{\text{freq}}^j$ and threshold $\tau \in (0, 1)$:
        $$M_{\text{err}}^j(\mathbf{u}) = \mathbb{I} \left[ \bar{e}^j(\mathbf{u}) > \tau \vee \left( M_{\text{freq}}^j(\mathbf{u}) = 1 \wedge \bar{e}^j(\mathbf{u}) > 0.5\tau \right) \right]$$
        where $\mathbb{I}$ is the indicator function [S1, unofficial].

3.  **Compute Densification Scores $s_d^i(t)$:**
    *   For each active primitive $i \in \mathcal{A}_t$, identify pixels $\Omega_i^j$ where $i$ contributes during compositing in view $j$ [S1, unofficial].
    *   Compute weighted pixel count per view:
        $$n_i^j = \sum_{\mathbf{u} \in \Omega_i^j} M_{\text{err}}^j(\mathbf{u})$$
    *   Compute valid-view average count:
        $$C_i = \frac{1}{|\mathcal{V}_i|} \sum_{j \in \mathcal{V}_i} n_i^j$$
    *   Apply clipped-linear schedule $\omega(t)$ (positive, nondecreasing over densification interval):
        $$s_d^i(t) = \omega(t)C_i$$

4.  **Compute Pruning Scores $s_p^i$:**
    *   Compute image-level photometric loss for view $j$:
        $$\mathcal{L}_1^j = \frac{1}{|\mathcal{P}_j|} \sum_{\mathbf{u} \in \mathcal{P}_j} e^j(\mathbf{u})$$
        $$E_{\text{photo}}^j = (1 - \lambda_{\text{dssim}}) \mathcal{L}_1^j + \lambda_{\text{dssim}} \left( 1 - \text{SSIM}(I_{\text{rend}}^j, I_{\text{gt}}^j) \right)$$
    *   Compute summed, loss-weighted count for primitive $i$:
        $$Q_i = \sum_{j \in \mathcal{V}_i} n_i^j E_{\text{photo}}^j$$
    *   Normalize pruning score over active set $\mathcal{A}_t$:
        $$s_p^i = \mathcal{N}_{\mathcal{A}_t}[Q](i)$$

5.  **Pruning:**
    *   Identify mandatory removals: $\mathcal{H}_t = \{i \in \mathcal{A}_t : o_i < 0.1 \vee \gamma_i < 0.01\}$ [S1, unofficial].
    *   Identify candidates: $\mathcal{P}_t = \{i \in \mathcal{A}_t \setminus \mathcal{H}_t : s_p^i > \tau_p\}$, where $0 \leq \tau_p < 1$ [S1, unofficial].
    *   Sample $b_t = \lfloor \rho |\mathcal{P}_t| \rfloor$ candidates without replacement using weights proportional to $s_p^i$, where $\rho \in [0, 1]$ [S1, unofficial].
    *   Removal set: $\mathcal{R}_t = \mathcal{H}_t \cup \text{sampled candidates}$ [S1, unofficial].
    *   Remove primitives in $\mathcal{R}_t$ from $\mathcal{G}_t$ [S1, unofficial].

6.  **Densification:**
    *   Select surviving active primitives with $s_d^i(t) > \tau_d$ [S1, unofficial].
    *   For each selected primitive $i$:
        *   If largest base-scale component $< \tau_s > 0$: Clone and shift along positional gradient [S1, unofficial].
        *   Otherwise: Replace with two smaller Gaussians [S1, unofficial].
    *   New primitives inherit parent's unconstrained modulation parameter $\beta_i \in \mathbb{R}$, with $\gamma_i = 2 \text{sigmoid}(\beta_i) \in (0, 2)$ [S1, unofficial]. Remaining attributes follow clone/split updates [S1, unofficial].
    *   Primitives outside $\mathcal{A}_t$ are unaffected [S1, unofficial].

**Parameters:**
*   $\tau$: Normalized error threshold, range $(0, 1)$ [S1, unofficial].
*   $\tau_p$: Pruning score threshold, range $[0, 1)$ [S1, unofficial].
*   $\tau_d$: Densification-score threshold, range $[0, \infty)$ [S1, unofficial].
*   $\tau_s$: Scale threshold for cloning vs. splitting, range $(0, \infty)$ [S1, unofficial].
*   $\rho$: Pruning sample ratio, range $[0, 1]$ [S1, unofficial].
*   $\lambda_{\text{dssim}}$: SSIM weight in photometric loss [S1, unofficial].
*   $K$: Number of sampled training views [S1, unofficial].

**Edge Cases and Pitfalls:**
*   When pruning and densification coincide, pruning must be applied first [S1, unofficial].
*   New primitives are scored only at the next density update to avoid using post-update scores for pre-update decisions [S1, unofficial].
*   Density control is skipped if $\mathcal{A}_t = \emptyset$ [S1, unofficial].
*   Min-max normalization maps constant inputs to zero [S1, unofficial].

**Pseudocode:**

```python
import math
import random

def sigmoid(x):
    return 1.0 / (1.0 + math.exp(-x))

def min_max_normalize(tensor):
    flat = [val for row in tensor for val in row]
    min_val, max_val = min(flat), max(flat)
    if max_val == min_val:
        return [[0.0]*len(row) for row in tensor]
    return [[(v - min_val) / (max_val - min_val) for v in row] for row in tensor]

def get_contributing_pixels(primitive_idx, view_idx):
    # Returns list of (r, c) pixels where primitive contributes during compositing
    return rasterizer.get_contributing_pixels(primitive_idx, view_idx)

def projected_radius(primitive_idx, view_idx):
    return rasterizer.get_projected_radius(primitive_idx, view_idx)

def max_base_scale_component(primitive_idx):
    return max(gaussians[primitive_idx].base_scale)

def clone_and_shift(primitive_idx):
    new_g = copy(gaussians[primitive_idx])
    new_g.position += 0.01 * new_g.position_gradient
    return new_g

def split_into_two(primitive_idx):
    g1, g2 = copy(gaussians[primitive_idx]), copy(gaussians[primitive_idx])
    g1.scale *= 0.5; g2.scale *= 0.5
    return g1, g2

def weighted_sample_without_replacement(items, weights, k):
    if k <= 0 or not items: return []
    selected, cur_items, cur_weights = [], items[:], weights[:]
    for _ in range(k):
        r = random.uniform(0, sum(cur_weights))
        cum = 0
        for idx, w in enumerate(cur_weights):
            cum += w
            if r <= cum:
                selected.append(cur_items.pop(idx))
                cur_weights.pop(idx)
                break
    return selected

def density_control(gaussians, views, rendered_images, gt_images, freq_masks, tau, tau_p, tau_d, tau_s, rho, lambda_dssim, schedule_weight):
    # Step 1: Compute Active Primitives
    active_primitives = [i for i in range(len(gaussians)) if sum(1 for j in views if projected_radius(i, j) > 0) > 0]
    if not active_primitives: return gaussians

    # Step 2: Compute Composite Error Maps
    composite_error_masks = {j: min_max_normalize(
        [[(1/3)*sum(abs(rendered_images[j][r][c][ch] - gt_images[j][r][c][ch]) for ch in range(3)) for c in range(W)] for r in range(H)]
    ) for j in views}

    # Step 3: Compute Densification Scores
    densification_scores = {}
    for i in active_primitives:
        valid_views = [j for j in views if projected_radius(i, j) > 0]
        if not valid_views: continue
        counts = [sum(composite_error_masks[j][r][c] for r, c in get_contributing_pixels(i, j)) for j in valid_views]
        densification_scores[i] = schedule_weight * (sum(counts) / len(counts))

    # Step 4: Compute Pruning Scores
    photo_losses = {}
    for j in views:
        raw_err = [[(1/3)*sum(abs(rendered_images[j][r][c][ch] - gt_images[j][r][c][ch]) for ch in range(3)) for c in range(W)] for r in range(H)]
        flat_err = [v for row in raw_err for v in row]
        mean_l1 = sum(flat_err) / len(flat_err)
        ssim_val = ssim(rendered_images[j], gt_images[j]) # Standard Structural Similarity Index
        photo_losses[j] = (1 - lambda_dssim) * mean_l1 + lambda_dssim * (1 - ssim_val)

    pruning_scores = {}
    for i in active_primitives:
        valid_views = [j for j in views if projected_radius(i, j) > 0]
        if not valid_views: continue
        pruning_scores[i] = sum(sum(composite_error_masks[j][r][c] for r, c in get_contributing_pixels(i, j)) * photo_losses[j] for j in valid_views)

    min_s, max_s = min(pruning_scores.values()), max(pruning_scores.values())
    normalized_scores = {i: 0 if max_s == min_s else (pruning_scores[i] - min_s) / (max_s - min_s) for i in pruning_scores}

    # Step 5: Pruning
    mandatory_removals = [i for i in active_primitives if gaussians[i].opacity < 0.1 or gaussians[i].gamma < 0.01]
    candidates = [i for i in active_primitives if i not in mandatory_removals and normalized_scores.get(i, 0) > tau_p]
    sampled_candidates = weighted_sample_without_replacement(candidates, [normalized_scores[i] for i in candidates], math.floor(rho * len(candidates)))
    removal_set = set(mandatory_removals + sampled_candidates)

    # Step 6: Densification
    new_gaussians = []
    for i in active_primitives:
        if i in removal_set: continue
        if densification_scores.get(i, 0) > tau_d:
            if max_base_scale_component(i) < tau_s:
                new_g = clone_and_shift(i)
                new_g.beta = gaussians[i].beta
                new_g.gamma = 2 * sigmoid(new_g.beta)
                new_gaussians.append(new_g)
            else:
                g1, g2 = split_into_two(i)
                g1.beta = gaussians[i].beta; g1.gamma = 2 * sigmoid(g1.beta)
                g2.beta = gaussians[i].beta; g2.gamma = 2 * sigmoid(g2.beta)
                new_gaussians.extend([g1, g2])
        else:
            new_gaussians.append(gaussians[i])
    return new_gaussians
```

## Subtopics

### [Efficient Pruning Score](3598-efficient-pruning-score.md)
The Efficient Pruning Score is a sensitivity-based metric used to identify and remove redundant 3D Gaussian primitives during the training of 3D Gaussian Splatting (3DGS) models. It solves the problem of high memory overhead and inefficient gradient flow associated with the original PUP 3D-GS pruning method, which requires storing a large Hessian matrix for every Gaussian. By reparameterizing the sensitivity score to depend on the scalar projected Gaussian value rather than the full 3D spatial parameters, it reduces storage requirements by 36×, enabling pruning to occur directly within the training pipeline.

### [Fisher Sensitivity Score](9664-fisher-sensitivity-score.md)
The Fisher Sensitivity Score is a pruning metric for 3D Gaussian primitives that estimates the impact of each Gaussian on the L2 reconstruction loss using a block-diagonal approximation of the Hessian. It sets itself apart from visibility-based siblings like [Efficient Pruning Score](3598-efficient-pruning-score.md) by evaluating geometric sensitivity through the log-determinant of parameter gradients, thereby avoiding the bias toward larger Gaussians inherent in pixel-coverage heuristics.

## Operating characteristics
*   **Time Complexity:** Depends on the number of sampled views $K$, the number of primitives $N$, and the image resolution. Computing error maps and masks is $O(K \cdot H \cdot W)$ where $H, W$ are image dimensions. Computing scores is $O(N \cdot K)$. Pruning and densification are $O(N)$.
*   **Memory Complexity:** Requires storing error maps and masks for $K$ views, adding $O(K \cdot H \cdot W)$ memory overhead. No Hessian matrices are stored, unlike some pruning methods.
*   **Measured Performance:** Improves fidelity compared to vanilla 3DGS and reduces redundancy [S1, unofficial].
*   **Strengths:** Reduces redundant primitives, improves fidelity, avoids Hessian storage overhead.
*   **Limitations:** Requires sampling views and computing error maps, adding computational overhead during density control steps.
*   **When to Use:** When training 3D Gaussian Splatting models and aiming to reduce redundancy and improve reconstruction fidelity.
*   **When Not to Use:** When computational resources are extremely limited and the overhead of error map computation is prohibitive, or when real-time inference speed is the primary concern and training-time optimization is less critical.
