# GaussianSet Data Structure

Also called: 3D Gaussian Representation, Gaussian Set

## Overview
The `GaussianSet` is a container class representing a collection of 3D Gaussian primitives, storing their geometric parameters (means, orientations, scales), opacity, and appearance (spherical harmonics coefficients), while providing methods to compute the resulting 3D covariance matrices [S1, unofficial]. It solves the problem of organizing learnable parameters for differentiable volume rendering by maintaining a unified state that supports batched processing and efficient memory access [S1, unofficial]. It differs from its sibling [GaussianList Data Structure and Initialization](2214-gaussianlist-data-structure-and-initialization.md) by defining the logical container and covariance computation logic, whereas the `GaussianList` explicitly defines the contiguous memory layout and initialization sequence required to compute covariances from raw parameters [S1, unofficial][S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Raw parameters stored in the set: `means` (N, 3), `quats` (N, 4), `scales` (N, 3), `opacities` (N), `sh_coefficients` (N, S, 3).
*   **Output:** A computed `covariances` tensor of shape (N, 3, 3) representing the world-space covariance for each Gaussian.

**Data Structures:**
The `GaussianSet` stores attributes as PyTorch tensors with the following exact layout [S1, unofficial]:
*   `means`: `Float32 Tensor` of shape `(N, 3)`.
*   `quats`: `Float32 Tensor` of shape `(N, 4)`.
*   `scales`: `Float32 Tensor` of shape `(N, 3)`.
*   `opacities`: `Float32 Tensor` of shape `(N,)`.
*   `sh_coefficients`: `Float32 Tensor` of shape `(N, S, 3)`, where S is the number of spherical harmonic coefficients per Gaussian.
*   `covariances`: `Float32 Tensor` of shape `(N, 3, 3)`.

**Steps:**
1.  **Normalization:** Normalize the quaternion tensor `quats` to unit length along the last dimension.
2.  **Exponentiation:** Apply the exponential function to the `scales` tensor to ensure positive scale values.
3.  **Sigmoid Activation:** Apply the sigmoid function to the `opacities` tensor to bound values between 0 and 1.
4.  **Concatenation:** Concatenate the spherical harmonic coefficients along the coefficient dimension if they are stored in separate chunks (e.g., degree 0 and degree N).
5.  **Covariance Computation:** For each Gaussian $i$, compute the world-space covariance matrix $Cov_i$ using the rotation matrix $R_i$ derived from the normalized quaternion and the diagonal scale matrix $S_i$ derived from the exponentiated scales.

**Formulas:**
The local covariance matrix $S$ is diagonal with variances equal to the squared scales [S1, unofficial]:
$$ S = \text{diag}(s_x^2, s_y^2, s_z^2) $$
where $s_x, s_y, s_z$ are the components of the exponentiated scale vector.

The world-space covariance matrix $Cov$ is computed as [S1, unofficial]:
$$ Cov = R S R^T $$
where $R$ is the $3 \times 3$ rotation matrix constructed from the normalized quaternion.

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def compute_covariances(means, quats, scales, opacities, sh_coefficients):
    """
    Computes the 3D covariance matrices for a set of Gaussians.
    
    Args:
        means: Tensor of shape (N, 3)
        quats: Tensor of shape (N, 4)
        scales: Tensor of shape (N, 3)
        opacities: Tensor of shape (N,)
        sh_coefficients: Tensor of shape (N, S, 3)
        
    Returns:
        covariances: Tensor of shape (N, 3, 3)
    """
    # Step 1: Normalize quaternions
    quats_norm = F.normalize(quats, p=2, dim=-1)
    
    # Step 2: Exponentiate scales
    scales_exp = torch.exp(scales)
    
    # Step 3: Sigmoid opacities (stored internally, not used in covariance)
    opacities_sig = torch.sigmoid(opacities)
    
    # Step 4: Concatenate SH coefficients if necessary (assumed already concatenated in input)
    # sh_coeffs = torch.cat([sh0, shN], dim=-2) # Handled by input format
    
    # Step 5: Compute Covariance
    # Convert quaternions to rotation matrices
    # R is shape (N, 3, 3)
    R = quaternion_to_rotation_matrix(quats_norm)
    
    # Create diagonal scale matrices S
    # S is shape (N, 3, 3)
    sx = scales_exp[:, 0]
    sy = scales_exp[:, 1]
    sz = scales_exp[:, 2]
    
    # Construct diagonal matrix
    S = torch.zeros_like(R)
    S[:, 0, 0] = sx * sx
    S[:, 1, 1] = sy * sy
    S[:, 2, 2] = sz * sz
    
    # Cov = R * S * R^T
    covariances = torch.bmm(R, torch.bmm(S, R.transpose(1, 2)))
    
    return covariances

def quaternion_to_rotation_matrix(quaternions):
    """
    Converts a batch of quaternions (N, 4) to rotation matrices (N, 3, 3).
    Assumes quaternions are normalized.
    """
    # Extract components
    w, x, y, z = quaternions[:, 0], quaternions[:, 1], quaternions[:, 2], quaternions[:, 3]
    
    # Precompute squares
    xx, yy, zz = x*x, y*y, z*z
    xy, xz, yz = x*y, x*z, y*z
    wx, wy, wz = w*x, w*y, w*z
    
    # Construct rotation matrix
    R = torch.stack([
        1 - 2*(yy + zz),     2*(xy - wz),       2*(xz + wy),
        2*(xy + wz),         1 - 2*(xx + zz),   2*(yz - wx),
        2*(xz - wy),         2*(yz + wx),       1 - 2*(xx + yy)
    ], dim=-1).reshape(-1, 3, 3)
    
    return R
```

**Edge Cases and Pitfalls:**
*   **Precision:** Quaternion normalization is critical to ensure the resulting rotation matrix is orthogonal. Failure to normalize can lead to skewed covariance matrices [S1, unofficial].
*   **Degenerate Input:** If scales are zero or negative before exponentiation, the resulting covariance will be singular or invalid. The exponential activation prevents negative scales [S1, unofficial].
*   **Memory:** Storing full $3 \times 3$ covariance matrices for all Gaussians requires $9N$ floats. This can be optimized by storing only the upper triangle or using the Cholesky factorization, but the standard `GaussianSet` layout stores the full matrix [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Covariance computation is $O(N)$ per Gaussian, involving matrix multiplications of fixed size ($3 \times 3$).
*   **Memory Complexity:** $O(N)$ for storing parameters. The covariance matrix adds $9N$ floats.
*   **Performance:** Efficient on GPU due to tensor operations. The explicit covariance computation allows for fast projection and rasterization.
*   **Strengths:** Explicit representation allows for real-time rendering. Differentiable parameters enable gradient-based optimization.
*   **Limitations:** Large memory footprint for high-N scenes. Compression techniques like ECoNGS are needed for efficient storage [S1, unofficial].

## Background
The `GaussianSet` data structure is a core component of 3D Gaussian Splatting (3DGS), a method for real-time novel view synthesis [S2, unofficial][S3, unofficial][S5]. It was introduced as part of the 3DGS framework to replace implicit neural fields with explicit Gaussian primitives [S3, unofficial]. The structure facilitates the optimization of Gaussian parameters to minimize photometric loss [S3, unofficial].
