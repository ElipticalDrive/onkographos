# FactorSplat

Also called: FactorSplat: Appearance-Controllable Gaussian Proxies for Medical Volume Rendering

## Overview
FactorSplat is a per-scene N-dimensional Gaussian splatting (N-DGS) proxy that accepts region-specific intensity-to-RGBA transfer function (TF) curves at inference time, allowing appearance changes without retraining or refitting [S1, unofficial]. It solves the problem of image-trained Gaussian proxies baking one transfer function into their appearance, which prevents supporting new presets without rebuilding the proxy [S1, unofficial]. Unlike VEG which stores scalar values and applies 1D mappings under emission-absorption, FactorSplat uses region-specific intensity TFs and cinematic-rendering supervision, combining direct lookup with an image-trained N-DGS proxy [S1, unofficial]. Unlike DeepONet which generates full weights with a hypernetwork, FactorSplat grounds function-valued TF inputs in each Gaussian's local support with per-primitive factors mapping local codes to appearance offsets [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N$ Gaussian primitives defined by centers $\boldsymbol{\mu}_i$, covariances $\boldsymbol{\Sigma}_i$, and opacity logits $o_i$. A bank of training presets $\mathcal{T}_{train}$ and their corresponding reference images. At inference, a target preset $T$ defined by region-specific intensity-to-RGBA curves $\mathbf{R}_T(m, h)$.
*   **Output:** Rendered images for the target preset $T$ using the shared geometry and TF-dependent appearance attributes.

**Data Structures:**
*   **Gaussian Primitives:** Each primitive $i$ stores:
    *   $\boldsymbol{\mu}_i \in \mathbb{R}^3$: Center.
    *   $\boldsymbol{\Sigma}_i \in \mathbb{R}^{3 \times 3}$: Covariance.
    *   $o_i \in \mathbb{R}$: Opacity logit.
    *   $\mathbf{C}^{base}_i \in \mathbb{R}^{Q_b \times 3}$: Spherical Harmonic (SH) coefficients for RGB, where $Q_b=4$ (degree-one SH: 1 DC + 3 directional).
    *   $\mathbf{z}_i \in \mathbb{R}^r$: Learned low-rank residual code (initialized and updated during training).
*   **Transfer Function Representation:**
    *   Presets are exported on a common grid of $S$ intensity samples $\{h_s\}_{s=1}^S$.
    *   Raw TF curves are averaged onto $B=64$ intensity bins to create $\mathbf{R}_T^{(B)} \in [0, 1]^{M \times B \times 4}$, where $M$ is the number of segmented regions/materials.
    *   Each region-intensity pair $(m, b)$ is encoded as a single integer $u = m \cdot B + b$.

**Parameters:**
*   $B = 64$: Number of intensity bins [S1, unofficial].
*   $K = 27$: Maximum number of valid samples in the voxel window [S1, unofficial].
*   $H, r$: Hidden and output dimensions of the local functional encoder MLP [S1, unofficial].
*   $T_0$: The base condition preset, centered such that the method yields exact identity at $T_0$ [S1, unofficial].

**Steps:**

1.  **Initialization:**
    *   Initialize Gaussian primitives with centers $\boldsymbol{\mu}_i$, covariances $\boldsymbol{\Sigma}_i$, and opacity logits $o_i$. The base opacity is $\sigma(o_i)$ where $\sigma$ is the logistic sigmoid [S1, unofficial].
    *   Initialize the learned residual code $\mathbf{z}_i$ to zero [S1, unofficial].
    *   Define the base preset $T_0$ [S1, unofficial].

2.  **TF Preprocessing (Offline/Per-Preset):**
    *   For a given preset $T$, export the intensity-to-RGBA curve $\mathbf{R}_T(m, h) = (\mathbf{p}_T(m, h), a_T(m, h)) \in [0, 1]^3 \times [0, 1]$ for each region $m \in \{0, \dots, M-1\}$ and intensity $h$ [S1, unofficial].
    *   Average the raw TF curves onto $B=64$ intensity bins to obtain $\mathbf{R}_T^{(B)} \in [0, 1]^{M \times B \times 4}$ [S1, unofficial].
    *   Compute the raw, unpremultiplied RGBA change relative to the base preset $T_0$:
        $$ \delta \mathbf{r}_T(m, b) = \mathbf{R}_T^{(B)}(m, b) - \mathbf{R}_{T_0}^{(B)}(m, b) \in \mathbb{R}^4 $$
        where $m$ is the region index and $b$ is the intensity bin index [S1, unofficial].

3.  **Local Descriptor Sampling (Per Primitive, at Initialization):**
    *   For each primitive $i$, sample the $3 \times 3 \times 3$ voxel window around its center $\boldsymbol{\mu}_i$ [S1, unofficial].
    *   Identify valid samples $k$. For each valid sample, determine the region channel $m_{ik}$ and the intensity-bin index $b_{ik}$ based on the voxel's value and the current TF binning [S1, unofficial].
    *   Let $K_i \le 27$ be the count of valid samples. If $K_i = 0$, set $\mathbf{d}_i = \mathbf{0}$ and $\mathbf{z}_i = \mathbf{0}$ and skip further processing for this primitive [S1, unofficial].
    *   Compute normalized nonnegative weights $w_{ik}$ such that $\sum_{k=1}^{K_i} w_{ik} = 1$ [S1, unofficial].
    *   Encode each pair $(m_{ik}, b_{ik})$ as a single integer $u_{ik} = m_{ik} \cdot B + b_{ik}$ [S1, unofficial].

4.  **Appearance Conditioning (At Inference/TF Switch):**
    *   **Physical Lookup:** Compute the physical local lookup offset $\mathbf{d}_i(T)$ by the weighted mean of the RGBA change over the primitive's samples:
        $$ \mathbf{d}_i(T) = \sum_{k=1}^{K_i} w_{ik} \delta \mathbf{r}_T(m_{ik}, b_{ik}) $$
        Here $\mathbf{d}_i = (\mathbf{d}^c_i, \mathbf{d}^\alpha_i) \in \mathbb{R}^3 \times \mathbb{R}$ represents the RGB and opacity offset [S1, unofficial].
    *   **Learned Residual:**
        *   Embed each RGBA difference using a bias-free pointwise MLP $\phi_\eta(\mathbf{v}) = \mathbf{W}_2 \text{ReLU}(\mathbf{W}_1 \mathbf{v})$, where $\mathbf{W}_1 \in \mathbb{R}^{H \times 4}$ and $\mathbf{W}_2 \in \mathbb{R}^{r \times H}$ [S1, unofficial].
        *   Pool the local codes for primitive $i$ using weighted sum:
            $$ \mathbf{z}_{i,T} = \sum_{k=1}^{K_i} w_{ik} \phi_\eta(\delta \mathbf{r}_T(m_{ik}, b_{ik})) \in \mathbb{R}^r $$
            If $K_i = 0$, $\mathbf{z}_{i,T} = \mathbf{0}$ [S1, unofficial].
    *   **Attribute Update:**
        *   The backbone opacity passed to the rasterizer is $\sigma(o_i) s_{view_i}(\pi)$, where $s_{view_i}(\pi)$ is the TF-independent opacity attenuation from the N-DGS backbone [S1, unofficial].
        *   Modify only the view-independent (DC) color and opacity using $\mathbf{d}_i(T)$ and $\mathbf{z}_{i,T}$. The directional SH coefficients remain TF-independent [S1, unofficial].
        *   Specifically, the DC color coefficient $\mathbf{C}^{base}_{i,0}$ is adjusted by the RGB part of $\mathbf{d}_i(T)$ and the contribution from $\mathbf{z}_{i,T}$ (mapped back to RGB space via the appearance response module, see Subtopics). The opacity logit $o_i$ is adjusted by the opacity part of $\mathbf{d}_i(T)$ and the contribution from $\mathbf{z}_{i,T}$ [S1, unofficial].

5.  **Rendering:**
    *   Rasterize the Gaussians using EWA splatting and front-to-back alpha compositing [S1, unofficial].
    *   Use the updated DC color and opacity for the final pixel colors [S1, unofficial].

## Subtopics

### [Factorized Appearance Response](4717-factorized-appearance-response.md)
Translates the local code into a DC-SH residual for color and an opacity-logit residual using low-rank factors.

## Operating characteristics
*   **Time Complexity:** The local lookup and residual computation are performed per primitive per TF switch. The lookup is $O(K_i)$ where $K_i \le 27$. The MLP evaluation is $O(H)$ per sample. The pooling is $O(K_i)$. Overall, conditioning is $O(N \cdot K_i \cdot H)$. Rendering is $O(N)$ per pixel using EWA splatting.
*   **Memory Complexity:** Stores $N$ Gaussians with shared geometry and SH coefficients. The learned residual codes add $O(N \cdot r)$ memory. The TF curves add $O(M \cdot B \cdot 4)$ memory.
*   **Measured Performance:** On seven CT and MR scans, FactorSplat improves mean PSNR and changed-region error over region-aware VEG across validation, interpolation, unseen composition, and out-of-distribution (OOD) edits [S1, unofficial].
*   **Strengths:** Supports unseen TFs without optimization or per-preset parameters. Combines direct lookup with an image-trained N-DGS proxy. Geometry and directional appearance are shared, reducing redundancy.
*   **Limitations:** Requires region segmentation for the TF curves. The learned residual may not perfectly capture complex cinematic rendering effects if the local support is insufficient.
*   **When to use:** When dynamic appearance changes are required for medical volume rendering without retraining.
*   **When not to use:** When region segmentation is not available or when the TFs are not region-specific.

## Background
FactorSplat was introduced in "FactorSplat: Appearance-Controllable Gaussian Proxies for Medical Volume Rendering" [S1, unofficial]. It addresses the limitations of image-trained Gaussian proxies that bake one transfer function into their appearance. The method builds on N-DGS [S1, unofficial] and combines ideas from VEG [S1, unofficial] and DeepONet [S1, unofficial], but differs by using region-specific intensity TFs and cinematic-rendering supervision.
