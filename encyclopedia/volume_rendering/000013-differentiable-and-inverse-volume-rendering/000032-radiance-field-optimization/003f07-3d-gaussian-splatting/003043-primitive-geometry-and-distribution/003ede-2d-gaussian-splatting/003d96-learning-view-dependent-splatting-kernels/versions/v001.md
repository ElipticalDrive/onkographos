# Learning View-Dependent Splatting Kernels

Also called: Learned Kernels, Learned View-Dependent Splatting Kernels, Neural 2D Splatting Kernels, Ours, View-Dependent 2D Gaussian Splatting

## Overview
Learning View-Dependent Splatting Kernels is a differentiable framework that automatically learns view-dependent 2D splatting kernels as an implicit representation of volumetric primitives, improving reconstruction quality and representation efficiency for novel 3D view synthesis [S1]. Unlike [2D Gaussian Splatting](6068-2d-gaussian-splatting.md) and vanilla 3DGS where the kernel shape is a fixed, view-independent function of the Mahalanobis distance, this method introduces learned view-dependency to serve as a form of data-driven consistency, allowing the kernel profile to vary with the camera view [S1]. It avoids the computation of line integrals over general 3D primitives by explicitly modeling the integral results via a neural projection and decoder [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of volumetric primitives defined by geometric attributes and a latent vector; camera parameters (viewing transformation, projection Jacobian).
*   **Output:** A view-dependent opacity value for each pixel within the projected bounding ellipse, which is passed to a standard splatting pipeline for coloring and alpha-blending.

**Data Structures:**
Each volumetric primitive stores the following attributes:
1.  **Center:** $\boldsymbol{\mu}_{3D}$ (3D vector).
2.  **Scaling factors:** $\mathbf{s}$ (3D vector).
3.  **Rotation:** $\mathbf{q}$ (4D quaternion).
4.  **3D-Kernel Latent:** $\mathbf{z}_{3D}$ (5D vector in most experiments) [S1].

**Neural Networks:**
1.  **Projection MLP ($\Phi_{\text{proj}}$):**
    *   Architecture: 4-layer MLP.
    *   Hidden layers: 64 neurons each.
    *   Activation: Leaky-ReLU after each layer except the last.
    *   Input: $\mathbf{z}_{3D}$, camera-space center $\boldsymbol{\mu}_{3D}^{\text{cam}}$, scaling factors $\mathbf{s}$, and primitive rotation matrix in camera space $\mathbf{R}^{\text{cam}}$.
    *   Output: $\mathbf{z}_{2D}$ (5D vector) [S1].
2.  **Kernel Decoder ($\Phi_{\text{dec}}$):**
    *   Architecture: 3-layer MLP.
    *   Hidden layers: 4 neurons each.
    *   Activation: Leaky-ReLU after each layer except the last.
    *   Final Layer: Sigmoid function to bound output.
    *   Input: Squared Mahalanobis distance $r^2$ and $\mathbf{z}_{2D}$.
    *   Output: Opacity $d$ [S1].

**Numbered Steps:**

1.  **Project the Bounding Ellipsoid:**
    Compute the 3D covariance matrix $\Sigma_{3D} = \mathbf{R}\mathbf{S}\mathbf{S}^T\mathbf{R}^T$, where $\mathbf{R}$ is the rotation matrix derived from $\mathbf{q}$ and $\mathbf{S}$ is the scaling matrix derived from $\mathbf{s}$ [S1].
    Compute the projected 2D covariance matrix $\Sigma_{2D}$ using the EWA splatting approximation [S1]:
    $$ \Sigma_{2D} = \mathbf{J} \mathbf{W} \Sigma_{3D} \mathbf{W}^T \mathbf{J}^T $$
    where $\mathbf{W}$ is the viewing transformation and $\mathbf{J}$ is the Jacobian of the affine approximation of the projection [S1]. The projected mean is denoted $\boldsymbol{\mu}_{2D}$ [S1].

2.  **Neural Projection:**
    Transform the 3D kernel latent to a 2D kernel latent using the projection MLP:
    $$ \mathbf{z}_{2D} = \Phi_{\text{proj}}(\mathbf{z}_{3D}, \boldsymbol{\mu}_{3D}^{\text{cam}}, \mathbf{s}, \mathbf{R}^{\text{cam}}) $$
    The inputs provide spatial, scale, and view awareness to the MLP [S1].

3.  **Pre-sample the Kernel Profile (Pre-training/Initialization):**
    To accelerate rasterization, pre-sample the 1D profile of the kernel decoder.
    *   Place $N$ uniform samples of $r^2$ to cover the range $[0,1]$, denoted $\{r_i^2\}_{1 \le i \le N}$. The default value for $N$ is 2 [S1].
    *   Compute $d_i = \Phi_{\text{dec}}(r_i^2, \mathbf{z}_{2D})$ for each sample.
    *   Store the results $\{d_i\}$ [S1].

4.  **Rasterization (Kernel Evaluation):**
    For a pixel with squared Mahalanobis distance $r^2$ relative to the projected primitive:
    *   Find the closest pre-sampled indices $c$ and $c+1$ such that $r_c^2 \le r^2 \le r_{c+1}^2$ [S1].
    *   Compute the interpolation factor:
        $$ \lambda = \frac{r^2 - r_c^2}{r_{c+1}^2 - r_c^2} $$
    *   Compute the final opacity via linear interpolation:
        $$ d = (1 - \lambda)d_c + \lambda d_{c+1} $$
    *   The resulting kernel shape is radially symmetric and bounded by the projected 2D ellipse [S1].

5.  **Joint Optimization:**
    The neural networks ($\Phi_{\text{proj}}$ and $\Phi_{\text{dec}}$) and per-primitive attributes ($\boldsymbol{\mu}_{3D}, \mathbf{s}, \mathbf{q}, \mathbf{z}_{3D}$) are jointly optimized with respect to input images [S1].

**Pre-training Procedure:**
*   Initialize $\mathbf{z}_{3D}$ to all zeros [S1].
*   Initialize weights in $\Phi_{\text{proj}}$ and $\Phi_{\text{dec}}$ with He initialization [S1].
*   Randomly sample $\boldsymbol{\mu}_{3D}^{\text{cam}}$, $\mathbf{s}$, and $\mathbf{R}^{\text{cam}}$.
*   Randomly sample $r^2$ to obtain target profile samples.
*   For the volumetric case, the target profile is a 1D cosine function: $d = \cos(r^2)$ [S1].
*   For the planar case, 2D Gaussian surfels are used as the target [S1].

**Pseudocode:**

```python
import math

def precompute_kernel_samples(z_2d, n_samples=2):
    """
    Pre-samples the kernel decoder for a given 2D latent.
    Returns lists of squared radii and corresponding opacities.
    """
    # Generate N uniform samples of r^2 in [0, 1]
    r_squared_samples = [i / (n_samples - 1) for i in range(n_samples)]
    
    # Evaluate decoder at these samples
    d_samples = []
    for r_sq in r_squared_samples:
        # Phi_dec is the kernel decoder MLP
        opacity = kernel_decoder_mlp(r_sq, z_2d)
        d_samples.append(opacity)
        
    return r_squared_samples, d_samples

def evaluate_kernel(r_squared, r_sq_samples, d_samples):
    """
    Interpolates the kernel opacity for a given squared Mahalanobis distance.
    """
    # Find the interval [r_c^2, r_{c+1}^2] containing r_squared
    # Assuming samples are sorted
    c = 0
    for i in range(len(r_sq_samples) - 1):
        if r_sq_samples[i] <= r_squared <= r_sq_samples[i+1]:
            c = i
            break
    else:
        # Fallback if r_squared is outside range or single sample
        c = 0
        
    r_c_sq = r_sq_samples[c]
    r_c1_sq = r_sq_samples[c+1]
    d_c = d_samples[c]
    d_c1 = d_samples[c+1]
    
    # Avoid division by zero if samples are identical
    if r_c1_sq == r_c_sq:
        return d_c
        
    # Linear interpolation
    lambda_val = (r_squared - r_c_sq) / (r_c1_sq - r_c_sq)
    opacity = (1 - lambda_val) * d_c + lambda_val * d_c1
    
    return opacity

def kernel_decoder_mlp(r_sq, z_2d):
    """
    Simulates the Kernel Decoder MLP (Phi_dec).
    Input: r_sq (scalar), z_2d (list of 5 floats)
    Output: opacity (scalar, bounded by sigmoid)
    """
    # Concatenate inputs: [r_sq, z_2d[0], ..., z_2d[4]]
    input_vec = [r_sq] + z_2d
    
    # Layer 1: 4 neurons, LeakyReLU
    h1 = leaky_relu(linear(input_vec, weights_l1, bias_l1))
    
    # Layer 2: 4 neurons, LeakyReLU
    h2 = leaky_relu(linear(h1, weights_l2, bias_l2))
    
    # Layer 3: 1 neuron, Sigmoid
    output = sigmoid(linear(h2, weights_l3, bias_l3))
    
    return output

def linear(x, weights, bias):
    """Standard linear transformation."""
    # weights is a list of lists, bias is a list
    out = []
    for i in range(len(bias)):
        val = bias[i]
        for j in range(len(x)):
            val += weights[i][j] * x[j]
        out.append(val)
    return out

def leaky_relu(x, alpha=0.01):
    return max(0, x) if x > 0 else alpha * x

def sigmoid(x):
    return 1 / (1 + math.exp(-x))
```

**Edge Cases and Pitfalls:**
*   **Radial Symmetry:** Using a general (non-radially symmetric) 2D kernel causes theoretical discontinuity in mapping arbitrary 3D view conditions to a 2D frame (hairy ball theorem), resulting in rapid rotation of the kernel around certain view directions during animation. Radial symmetry avoids this by eliminating the need for a 2D frame [S1].
*   **Parameter $\kappa$:** The parameter $\kappa$ (number of pre-samples $N$) controls the expressiveness of the learned kernels. Typical values are 2, 4, 8. Increasing $\kappa$ improves reconstruction quality only when the memory footprint is small. With a large footprint, the trend is not observed, likely because the average screen-space size per primitive becomes too small for higher kernel expressiveness to matter [S1].
*   **Precision:** The interpolation relies on $r^2$. Ensure $r^2$ is computed correctly as the squared Mahalanobis distance $(\mathbf{x} - \boldsymbol{\mu}_{2D})^T \Sigma_{2D}^{-1}(\mathbf{x} - \boldsymbol{\mu}_{2D})$ [S1].

## Subtopics

### Flattened Gaussian Ellipsoid Rendering
Uses flattened ellipsoids to approximate volumetric primitives, avoiding line integrals by assuming constant density along the ray slice. Choose when memory efficiency is critical and view-dependency is less important than geometric accuracy. [Link](1667-flattened-gaussian-ellipsoid-rendering.md)

### 3D Surface Splatting
Represents surfaces as 3D primitives with explicit normal maps. Choose when recovering high-resolution geometry and normals is the primary goal. [Link](4524-3d-surface-splatting.md)

### Spatially Varying Gaussian Splatting (SVGS)
Uses spatially varying parameters for Gaussians to handle complex lighting and geometry. Choose when local geometric variations are significant. [Link](8729-spatially-varying-gaussian-splatting-svgs.md)

### 4D Scale-adaptive Filter
Adapts the filter scale based on the 4D (space-time) context. Choose for dynamic scenes or video data. [Link](9868-4d-scale-adaptive-filter.md)

## Operating characteristics
*   **Time Complexity:** Rasterization is accelerated by pre-sampling the kernel decoder, reducing the per-pixel computation to a lookup and linear interpolation. The complexity is $O(1)$ per pixel per primitive after pre-computation, with pre-computation cost $O(N)$ per primitive where $N$ is the number of samples (default 2) [S1].
*   **Memory Complexity:** The memory footprint per primitive consists of the geometric attributes ($\boldsymbol{\mu}_{3D}, \mathbf{s}, \mathbf{q}$) and the 3D-kernel latent $\mathbf{z}_{3D}$ (5D vector). The memory footprint does not change with the parameter $\kappa$ (number of pre-samples) [S1].
*   **Measured Performance:** On the Tanks & Temples dataset with ~25MB memory footprint, the method (with $\kappa=4$) achieves 24.08 PSNR with 328K primitives at 102 FPS, outperforming 3DGS (23.12 PSNR, 446K, 295 FPS) and DBS (23.57 PSNR, 417K, 319 FPS) [S1].
*   **Strengths:** Superior representation efficiency and reconstruction quality compared to state-of-the-art techniques on analytical and learned kernels. The learned view-dependency serves as data-driven consistency [S1].
*   **Limitations:** Rendering speed decreases as $\kappa$ increases or as the number of primitives increases for high-quality results. The method requires pre-training of the neural networks [S1].
*   **When to use:** When high-fidelity novel view synthesis is required with limited memory budget, and view-dependent appearance variations are significant.
*   **When not to use:** When real-time performance with very high primitive counts is critical and the overhead of neural network evaluation (even with pre-sampling) is prohibitive, or when the scene is static and view-independent kernels suffice.

## Background
The method was introduced by Huakeng Ding, Zhanpeng Liu, Fan Pei, Kun Zhou, and Hongzhi Wu in 2026 [S1]. It builds upon the foundation of 3D Gaussian Splatting and 2D Gaussian Splatting, addressing the limitation that existing methods use view-independent kernels as a function of Mahalanobis distance [S1]. The work extends the idea to learn general 2D kernels for planar primitives in the context of 2D splatting, demonstrating efficiency in representing 2D images as well [S1].
