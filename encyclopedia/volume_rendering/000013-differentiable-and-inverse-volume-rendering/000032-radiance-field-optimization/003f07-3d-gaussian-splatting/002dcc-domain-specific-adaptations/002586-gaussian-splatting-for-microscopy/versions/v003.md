# Gaussian Splatting for Microscopy

Also called: Gaussian Splatting for Microscopy Volumes, nD Gaussian splatting

## Overview
Gaussian Splatting for Microscopy decomposes an $n$-dimensional fluorescence microscopy volume into a mixture of oriented, anisotropic Gaussian primitives, enabling interactive web visualization and efficient storage [S1, unofficial]. It solves the problem of data transfer and viewing of large $n$-dimensional datasets by representing images as fitted geometry that the GPU rasterizes directly, avoiding the need for intermediate voxel grids [S1, unofficial]. Unlike standard 3D Gaussian Splatting which relies on Structure-from-Motion points, this method adapts nD Gaussian splatting, initializes splats directly from voxel data, and uses blind-spot cross-validation to determine the optimal splat count, preventing overfitting to noise [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A preprocessed $n$-dimensional microscopy volume $V: \mathbb{R}^D \rightarrow \mathbb{R}_{\ge 0}$, typically normalized to $[0, 1]$ [S1, unofficial].
*   **Output:** A set of $K$ Gaussian splats, each defined by position, amplitude, and covariance, stored in a format suitable for streaming (e.g., Zarr archives) [S1, unofficial].

**Data Structures**
Each Gaussian splat $k$ is parameterized by:
*   $\mu_k \in \mathbb{R}^D$: The center position.
*   $a_k \in \mathbb{R}_{\ge 0}$: The amplitude (intensity), enforced non-negative via softplus activation and upper-bounded by a configurable $a_{max}$ [S1, unofficial].
*   $L_k \in \mathbb{R}^{D \times D}$: The lower-triangular Cholesky factor of the covariance matrix $\Sigma_k$, such that $\Sigma_k = L_k L_k^\top$ [S1, unofficial]. This parameterization stores $D(D+1)/2$ elements per splat (6 for 3D) and guarantees positive-definite covariance by construction [S1, unofficial]. The diagonal is parameterized as $\sigma_{min} + \text{softplus}(\cdot)$ with $\sigma_{min} = 1/\sqrt{12}$ voxels, ensuring no splat is narrower than a voxel's own spread [S1, unofficial].

**Preprocessing**
1.  **Registration and Fusion:** Multi-view images (e.g., light-sheet) are registered and fused, then deconvolved (e.g., ten iterations against the point-spread function) to produce a single fused volume per timepoint [S1, unofficial].
2.  **Normalization:** Source volumes (stored as 16-bit integers or float32) are normalized to $[0, 1]$ using an affine map of the intensity range [S1, unofficial].
3.  **Clipping:** Outlier voxels are clipped based on dataset-specific percentiles to stabilize optimization [S1, unofficial]:
    *   Plain min-max (no clipping): Kidney, Cells3D, Blastocyst, Tribolium, Mouse heart.
    *   1st–99.5th percentiles: OpenCell.
    *   1st–99.999th percentiles: C. elegans.
    *   0th–99.999th percentiles: Sparse Fly brain.
    *   0th–99.9th percentiles: Zebrafish, Drosophila.
    *   Neuromast channels: Background floors (e.g., 105.99 and 103.89 grey levels) are subtracted, then clipped to 0th–99.9th percentiles [S1, unofficial].
4.  **Background Floor Handling:** For quality benchmarks, no floor suppression is applied so PSNR references the original volume including its background pedestal [S1, unofficial]. For compression benchmarks, automatic floor suppression subtracts a constant background pedestal before fitting to improve compression [S1, unofficial].

**Initialization**
Initial positions are seeded automatically from the volume using gradient-weighted samples of the volume’s edges, complemented by a coarse uniform grid [S1, unofficial].

**Optimization**
The parameters are optimized using the Adam optimizer with an L1 loss function and regularization on splat amplitudes and extents [S1, unofficial]. The model prediction at voxel $x$ is:
$$ \hat{V}(x) = \sum_{k=1}^{K} a_k \exp\left(-\frac{1}{2} \|L_k^{-1} (x - \mu_k)\|^2\right) $$
where $a_k$ is the amplitude and $L_k$ is the Cholesky factor [S1, unofficial].

To maintain a constant optimizer tensor shape, a fixed-pool strategy is used: periodically, the least informative splats are relocated to regions of high reconstruction residual, acting as a fixed-pool analogue to the pruning-and-seeding cycle used in standard 3D Gaussian Splatting [S1, unofficial].

**Stopping Criterion (Blind-Spot Cross-Validation)**
The number of splats $K$ is determined by blind-spot cross-validation to balance PSNR and overfitting [S1, unofficial]:
1.  Mask 5% of voxels.
2.  Replace masked voxels with donut-median neighbourhood values.
3.  Score reconstruction on the held-out voxels.
4.  Stop fitting at the held-out PSNR peak. If the peak is interior or cull-limited, use the peak or the point where cull holds count constant [S1, unofficial].

**Viewer Evaluation**
The viewer uses a truncated Gaussian to ensure compact support:
$$ \hat{V}_{viewer}(x) = \sum_{k=1}^{K} a_k \max\left(0, \exp\left(-\frac{1}{2} \|L_k^{-1} (x - \mu_k)\|^2\right) - \frac{c_T}{1 - c_T}\right) $$
where $c_T = \exp(-T/2)$ at $T = 2.75$ standard deviations [S1, unofficial].

        v_min, v_max = np.min(volume), np.max(volume)
    elif dataset_name == 'OpenCell':
        v_min, v_max = np.percentile(volume, 1), np.percentile(volume, 99.5)
    elif dataset_name == 'C_elegans':
        v_min, v_max = np.percentile(volume, 1), np.percentile(volume, 99.999)
    elif dataset_name == 'Fly_brain_sparse':
        v_min, v_max = np.percentile(volume, 0), np.percentile(volume, 99.999)
    elif dataset_name in ['Zebrafish', 'Drosophila']:
        v_min, v_max = np.percentile(volume, 0), np.percentile(volume, 99.9)
    elif dataset_name == 'Neuromast':
        volume = np.maximum(volume - 105.99, 0)
        v_min, v_max = np.percentile(volume, 0), np.percentile(volume, 99.9)
    else:
        v_min, v_max = np.min(volume), np.max(volume)
    volume = np.clip(volume, v_min, v_max)
    return (volume - v_min) / (v_max - v_min + 1e-8)

def initialize_splats(volume, num_splats):
    """Seed positions from gradient-weighted samples and coarse uniform grid [S1, unofficial]."""
    D = volume.ndim
    gradients = np.gradient(volume)
    grad_mag = np.sqrt(sum(g**2 for g in gradients))
    grad_mag /= grad_mag.sum()
    n_grad = num_splats // 2
    indices = np.random.choice(grad_mag.size, size=n_grad, p=grad_mag.flatten())
    pos_grad = np.stack(np.unravel_index(indices, volume.shape), axis=1)
    grid_pts = int(np.ceil(num_splats ** (1.0 / D)))
    grids = np.meshgrid(*[np.linspace(0, s - 1, grid_pts) for s in volume.shape], indexing='ij')
    pos_grid = np.stack([g.flatten() for g in grids], axis=1)
    all_pos = np.vstack([pos_grad, pos_grid])
    return all_pos[:num_splats] if all_pos.shape[0] >= num_splats else np.pad(all_pos, ((0, num_splats - all_pos.shape[0]), (0, 0)))

    flat_vol = volume.flatten()
    result = flat_vol.copy()
    for idx in mask_indices:
        coords = np.unravel_index(idx, volume.shape)
        neighbors = []
        for offset in np.ndindex(*[range(-radius, radius + 1)] * volume.ndim):
            if np.sum(offset) == 0:
                continue
            neighbor_coords = tuple(c + o for c, o in zip(coords, offset))
            if all(0 <= c < s for c, s in zip(neighbor_coords, volume.shape)):
                neighbors.append(volume[neighbor_coords])
        if neighbors:
            result[idx] = np.median(neighbors)
    return result

    """Truncated Gaussian evaluation for viewer rendering [S1, unofficial]."""
    c_T = np.exp(-T / 2)
    threshold = c_T / (1 - c_T)
    def render(voxel_coords):
        diff = voxel_coords[np.newaxis, ...] - mu[:, np.newaxis, :]
        y = np.linalg.solve(L[:, :, np.newaxis, :], diff)
        dist_sq = np.sum(y ** 2, axis=1)

## Operating characteristics
*   **Time Complexity:** Fitting is the expensive side, taking minutes per volume on a single GPU (e.g., median 2.4 minutes at 32K budget on NVIDIA RTX 3070) [S1, unofficial]. Convergence is rapid; training PSNR is within 0.5 dB of the final value at 2,000 iterations for 77 of 85 volume-capacity cells [S1, unofficial]. Adding capacity outperforms adding iterations at lower fitting cost: 16K splats × 500 iterations beat 4K splats × 20,000 iterations by an average of +3.03 dB across 17 volumes at 10× fewer splat-iterations [S1, unofficial].
*   **Memory Complexity:** The representation is compact. Compression ratios range from 6× to 340× (median 99.3×) across 17 volumes at 26–67 dB PSNR [S1, unofficial].
*   **Performance:** On an RTX 3070 at 720p HDR, Gaussian splats maintain 60 FPS (16.7 ms budget) through $10^6$ elements [S1, unofficial].
*   **Strengths:** Direct GPU rasterization without voxel grids; efficient streaming for web browsers; automatic determination of model complexity via cross-validation; high compression ratios [S1, unofficial].
*   **Limitations:** Structures thinner than the local Gaussian scale (e.g., individual microtubules) blur; the representation is for visualization, not quantitative measurement; blind-spot cross-validation assumes independent noise, so on fused or deconvolved volumes a held-out peak is not guaranteed and a noise floor caps the budget from above [S1, unofficial].
*   **When to use:** Interactive web visualization of large microscopy datasets; sharing data via static file hosting; scenarios where bandwidth and client-side memory are constrained [S1, unofficial].
*   **When not to use:** Quantitative analysis, segmentation, or tracking tasks that require the original voxel data; fused or deconvolved volumes where noise is not independent across voxels and blind-spot cross-validation cannot reliably locate an optimum [S1, unofficial].

## Background
Gaussian Splatting for Microscopy is part of the Luxar framework, an open-source Python system for scalable interactive web visualization of multidimensional scientific data [S1, unofficial]. It adapts nD Gaussian splatting to microscopy volumes, using a fixed-pool optimiser that relocates splats rather than growing and pruning the Gaussian set [S1, unofficial]. The method was validated on 17 volumes from 12 datasets spanning spinning-disk, confocal, light-sheet, and structured-illumination modalities [S1, unofficial]. It complements desktop tools like napari and Fiji, and voxel-pyramid web viewers like Neuroglancer, by representing images as fitted geometry that mixes with points, lines, and meshes in one scene [S1, unofficial].
