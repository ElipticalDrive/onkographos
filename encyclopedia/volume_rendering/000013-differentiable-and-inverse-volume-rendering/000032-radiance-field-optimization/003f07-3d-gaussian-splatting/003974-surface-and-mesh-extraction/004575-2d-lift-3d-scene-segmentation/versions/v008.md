# 2D-Lift-3D Scene Segmentation

Also called: 2D-Lift-3D Segmentation for Partial Scene Editing, PSE with 2D-lift-3D segmentation

## Overview
This method segments 3D Gaussian primitives in a volume visualization scene by lifting 2D segmentation masks from a reference view into 3D space using multi-view label voting [S1]. It solves the problem of partial scene editing by decomposing a basic scene into distinct parts, allowing independent color, opacity, and lighting adjustments [S1]. Unlike sibling methods that require learnable feature vectors or density fields, this approach is training-free and relies on external segmentation models and geometric projection [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $N$ 3D Gaussian primitives $\mathcal{G} = \{g_1, \dots, g_N\}$ (defined by center $\boldsymbol{\mu}_i$, covariance $\boldsymbol{\Sigma}_i$, opacity $o_i$, and SH coefficients $\mathbf{c}_i$); a set of $V$ training view camera poses $\{C_v\}_{v=1}^V$; a reference view $C_{ref}$; and user-specified point prompts.
*   **Output:** A label assignment $L_i \in \{0, 1, \dots, K\}$ for each Gaussian $g_i$, where $K$ is the number of segmented parts.

**Data Structures:**
*   **Gaussian Primitives:** Standard 3DGS representation.
*   **2D Masks:** Binary or multi-class masks generated by SAM for each training view.
*   **Label Counts:** An array or hash map storing the vote count for each label for each Gaussian.

**Steps:**
1.  **Render Reference View:** Render an image from the current Gaussian scene using the TexGS-VolVis renderer from an arbitrary reference view $C_{ref}$ [S1].
2.  **Generate 2D Mask:** Use the Segment Anything Model (SAM) with user-specified point prompts on the rendered reference view to generate a 2D segmentation mask $M_{ref}$ [S1].
3.  **Propagate to Training Views:** Generate 2D segmentation masks $M_v$ for the corresponding parts across all $V$ training views. This is done by using SAM with point prompts derived from the 3D-to-2D projection of the reference mask or by re-running SAM on training views if point locations are known [S1].
4.  **Label Propagation:** For each training view $v$, project the 2D mask $M_v$ onto the 3D Gaussians. A Gaussian $g_i$ is considered "hit" by a label $k$ in view $v$ if the ray from camera $C_v$ through the center $\boldsymbol{\mu}_i$ intersects the region labeled $k$ in $M_v$. Assign temporary label $k$ to $g_i$ for view $v$ [S1].
5.  **Multi-View Label Voting:** Aggregate the labels from all views. For each Gaussian $g_i$, count the occurrences of each label $k$ across all views where $g_i$ was visible and hit by a mask region. The final label $L_i$ is the one with the highest vote count [S1].
6.  **Segmentation:** Gaussians with the same label $L_i$ form a segmented part. The scene is decomposed into these parts [S1].

def segment_gaussians(gaussians, training_views, reference_view, point_prompts):
    """
    gaussians: List of Gaussian primitives with properties:
               - center: (x, y, z)
               - cov3d: 3x3 covariance matrix
               - opacity: float
               - sh_coeffs: spherical harmonic coefficients

    """
    # Step 1: Render reference view
    ref_image = render_scene(gaussians, reference_view)
    
    # Step 2: Generate 2D mask on reference view using SAM
    # SAM takes the image and point prompts
    mask_ref = sam_predict(ref_image, point_prompts)
    
    # Step 3 & 4: Propagate labels and collect votes
    # Initialize vote counts for each Gaussian
    # votes[i] is a dictionary {label: count}
    votes = [{0: 0} for _ in gaussians]
    
    # Process reference view first
    # Project reference mask to 3D to initialize votes?

    # We assume the reference mask defines the initial labels.
    # However, the source says "lift the 2D mask to a 3D mask... using multi-view label voting".
    # This implies we need masks from other views to confirm.
    
    # Generate masks for all training views
    # Note: SAM needs point prompts for each view. 
    # The source says "generate a series of 2D segmentation masks ... across all training views".
    # This requires projecting the reference points or using consistent prompts.
    # We assume a function `get_prompts_for_view` exists to map reference prompts to training views.
    
    all_masks = []
    for view in training_views:
        # Render training view
        img = render_scene(gaussians, view)
        # Get prompts for this view (implementation detail not in source, assumed available)
        prompts = map_prompts_to_view(point_prompts, reference_view, view)
        mask = sam_predict(img, prompts)
        all_masks.append((view, mask))
        
    # Also include reference view in voting if considered a "training" view for consistency
    all_masks.append((reference_view, mask_ref))
    
    # Step 5: Multi-view Label Voting
    for view, mask in all_masks:
        for i, g in enumerate(gaussians):
            # Check if Gaussian is visible and hit by a label in this view
            # Project center to 2D
            center_2d = project_point(g.center, view.pose, view.intrinsics)
            
            # Check if point is within image bounds
            if not is_in_bounds(center_2d, mask.shape):
                continue
                
            # Check if point is occluded? 
            # Standard Gaussian splatting rendering handles opacity.
            # For segmentation, we assume if the ray hits the Gaussian, it contributes.
            # We need to know which label covers this pixel.
            label = mask[int(center_2d.y), int(center_2d.x)]
            
            if label != 0: # Assuming 0 is background
                if label not in votes[i]:
                    votes[i][label] = 0
                votes[i][label] += 1
                
    # Step 6: Determine final labels
    segmented_gaussians = []
    for i, g in enumerate(gaussians):
        if not votes[i]:
            g.label = 0 # Background or unsegmented
        else:
            # Argmax of votes
            best_label = max(votes[i], key=votes[i].get)
            g.label = best_label
        segmented_gaussians.append(g)
        
    return segmented_gaussians

**Parameters:**
*   **Point Prompts:** User-defined 2D coordinates. Accuracy is critical; vague prompts lead to errors [S1].
*   **SAM Model:** Segment Anything Model. Used for generating initial 2D masks [S1].
*   **Textures Attribute:** Uniformly represents non-stylized and stylized scenes, enabling color editing after stylization [S1].

**Edge Cases and Pitfalls:**
*   **Inefficiency:** The method cannot immediately generate a 3D segmentation from a single 2D mask created with point prompts. It may require multiple rounds of segmentation for certain scenes, which is inefficient [S1].
*   **Prompt Sensitivity:** Inaccurate or vague text/point prompts can lead to erroneous editing results [S1].
*   **Occlusion:** Multi-view voting helps resolve occlusions, but if a part is consistently occluded in all training views, it may not be segmented correctly.

## Operating characteristics
*   **Time Complexity:** Depends on the number of Gaussians $N$, number of views $V$, and SAM inference time. Rendering $V$ images and running SAM $V$ times dominates.
*   **Memory Complexity:** $O(N)$ to store labels. $O(V \cdot H \cdot W)$ for storing masks during processing.
*   **Strengths:** Training-free; flexible partial editing; supports post-stylization color and lighting edits via textures attribute and Blinn-Phong model [S1].
*   **Limitations:** Requires multiple rounds of segmentation for complex scenes; inefficient compared to learnable feature-based methods [S1].
*   **When to Use:** When real-time partial editing is needed without retraining; when high-quality segmentation is required for specific parts.
*   **When Not to Use:** When scene is highly dynamic or when prompt accuracy is low.

## Background
Originated in TexGS-VolVis, a 2DGS-based framework for volume visualization [S1]. It builds on SAGD [25] and other works [5, 8, 35] that tackle 2D-lift-3D segmentation. It addresses the limitation of StyleRF-VolVis, which only supports color editing before stylization and cannot adjust light direction after training [S1].
