# 2D-Lift-3D Scene Segmentation

Also called: 2D-Lift-3D Segmentation for Partial Scene Editing, PSE with 2D-lift-3D segmentation

## Overview
This method segments 3D Gaussian primitives in a volume visualization scene by lifting 2D segmentation masks from reference views into 3D space [S1]. It solves the problem of applying distinct editing effects (color, opacity, lighting) to specific parts of a volumetric scene represented by Gaussian splats [S1]. Unlike methods that require learnable feature vectors or complex optimization to define semantic boundaries, this approach is training-free and relies on multi-view label voting to assign labels to primitives [S1]. It is distinct from [Gaussian Opacity Fields (GOF) Mesh Extraction](3692-gaussian-opacity-fields-gof-mesh-extraction.md) and [Distance-based Gaussian Splatting](7411-distance-based-gaussian-splatting.md) as it targets semantic segmentation for editing rather than geometric mesh extraction [S1].

## How it works
**Inputs:**
*   A set of $N$ 3D Gaussian primitives $\mathcal{G} = \{g_1, \dots, g_N\}$, where each $g_i$ has center $\boldsymbol{\mu}_i$, covariance $\boldsymbol{\Sigma}_i$, opacity $o_i$, and spherical harmonic coefficients $\mathbf{c}_i$ [Parent].
*   A set of $V$ training views with known camera poses.
*   User-specified point prompts on a reference view image.

**Outputs:**
*   A label assignment $L_i \in \{0, 1, \dots, K\}$ for each Gaussian primitive $g_i$, where $K$ is the number of segmented parts [S1].

**Data Structures:**
*   **Gaussian List:** Array of size $N$. Each element stores $\boldsymbol{\mu}_i, \boldsymbol{\Sigma}_i, o_i, \mathbf{c}_i$.
*   **Label Counter:** Array of size $N$, initialized to zero, storing the vote count for each label per Gaussian.
*   **Label Map:** Dictionary or array mapping Gaussian index to final label.

**Steps:**

1.  **Render Reference View:** Render an image $I_{ref}$ from an arbitrary view using the current Gaussian set $\mathcal{G}$ [S1].
2.  **Generate 2D Mask:** Use the Segment Anything Model (SAM) with user-specified point prompts on $I_{ref}$ to generate a 2D segmentation mask $M_{ref}$ [S1].
3.  **Propagate to Training Views:** Generate 2D segmentation masks $M_v$ for all corresponding parts across all $V$ training views using SAM [S1].
4.  **Label Propagation:** For each training view $v \in \{1, \dots, V\}$:
    a. Project all Gaussian centers $\boldsymbol{\mu}_i$ onto the 2D image plane of view $v$ to obtain screen coordinates $(u_i, v_i)$ [G].
    b. For each Gaussian $g_i$, check if its projected center $(u_i, v_i)$ falls within a foreground region of the mask $M_v$ [S1].
    c. If the Gaussian is inside the mask, assign a temporary label $l_{i,v}$ to $g_i$ for this view [S1].
5.  **Multi-View Label Voting:** For each Gaussian $g_i$:
    a. Collect all temporary labels $\{l_{i,1}, \dots, l_{i,V}\}$ assigned in Step 4 [S1].
    b. Determine the final label $L_i$ by majority vote among the valid labels [S1].
    c. If no views contain the Gaussian in the mask, assign a background label [G].
6.  **Segmentation Result:** The set of Gaussians with label $k$ forms the $k$-th segmented part of the scene [S1].

**Pseudocode:**

```python
def segment_gaussians_2d_lift_3d(gaussians, training_views, user_prompts, sam_model):
    """
    gaussians: List of Gaussian objects with attributes .center (3D vector), .id
    training_views: List of View objects with attributes .camera (projection matrix), .image (rendered image)
    user_prompts: List of (x, y) coordinates on the reference view image
    sam_model: Function that takes image and points, returns binary mask
    """
    n = len(gaussians)
    # Initialize vote counts for each label. 
    # Note: Label IDs are determined dynamically by SAM outputs.
    # We use a dictionary of dictionaries: votes[gaussian_id][label_id] = count
    votes = {g.id: {} for g in gaussians}
    
    # Step 1 & 2: Get reference mask
    # Assume reference view is the first view or specified separately.
    # For simplicity, we assume we render the reference view or have it.
    ref_image = render_view(gaussians, training_views[0].camera) 
    ref_mask = sam_model(ref_image, user_prompts)
    
    # Step 3: Process all training views
    for view in training_views:
        # Render view if not pre-rendered
        view_image = render_view(gaussians, view.camera)
        
        # Generate mask for this view. 
        # In practice, SAM prompts might need to be adapted or the model 
        # used in zero-shot mode on the rendered image.
        # The source implies generating masks for "corresponding parts" across views.
        # We assume SAM is applied to the rendered image of the current view.
        # Since we don't have point prompts for every view, we rely on the 
        # consistency of the rendered scene and SAM's ability to segment 
        # the object in the new view, or use the reference mask to guide 
        # if cross-view prompting is supported. 
        # The source says "generate a series of 2D segmentation masks... 
        # across all training views".
        view_mask = sam_model(view_image, user_prompts) # Simplified: prompts might need projection
        
        # Step 4: Label Propagation
        for i, gaussian in enumerate(gaussians):
            # Project 3D center to 2D
            center_3d = gaussian.center
            center_2d = project_to_screen(center_3d, view.camera)
            
            # Check if point is inside the mask
            # Assuming mask is binary: 1 for foreground, 0 for background
            if is_inside_mask(center_2d, view_mask):
                # Get the label ID from the mask at this pixel
                # SAM might return a single mask or multiple. 
                # Assuming we are segmenting one specific part per run or 
                # SAM returns distinct IDs for distinct objects.
                label_id = get_label_at_pixel(view_mask, center_2d)
                
                if label_id is not None:
                    if label_id not in votes[gaussian.id]:
                        votes[gaussian.id][label_id] = 0
                    votes[gaussian.id][label_id] += 1

    # Step 5: Multi-View Label Voting
    final_labels = {}
    for gaussian in gaussians:
        if not votes[gaussian.id]:
            final_labels[gaussian.id] = 0 # Background
        else:
            # Find label with max votes
            best_label = max(votes[gaussian.id], key=votes[gaussian.id].get)
            final_labels[gaussian.id] = best_label
            
    return final_labels
```

**Parameters:**
*   **SAM Model:** Segment Anything Model, used for zero-shot segmentation [S1].
*   **Point Prompts:** User-defined 2D coordinates on the reference view [S1].
*   **Voting Threshold:** Not explicitly defined, but majority vote is used [S1].

**Edge Cases and Pitfalls:**
*   **Inefficiency:** The method cannot immediately generate a 3D segmentation from a single 2D mask created with point prompts. It may require multiple rounds of segmentation for certain scenes, which is inefficient [S1].
*   **Ambiguity:** If a Gaussian is not visible in any training view or falls outside all SAM-generated masks, it remains unsegmented [G].

## Operating characteristics
*   **Time Complexity:** Dominated by rendering $V$ views and running SAM $V$ times. SAM inference is $O(V \cdot H \cdot W)$ where $H, W$ are image dimensions. Label voting is $O(N \cdot V)$.
*   **Memory Complexity:** $O(N \cdot V)$ to store intermediate votes if not aggregated on the fly, or $O(N)$ if aggregated per Gaussian.
*   **Strengths:** Training-free; does not require optimizing learnable feature vectors per Gaussian [S1]; enables real-time partial scene editing (PSE) and non-photorealistic scene editing (NPSE) [S1].
*   **Limitations:** Relies on SAM's accuracy; inefficient for scenes requiring multiple segmentation rounds; cannot adjust light direction after training in some baselines, but this method supports it via Blinn-Phong shading [S1].
*   **When to use:** When real-time editing of specific parts of a Gaussian volume is required without retraining [S1].
*   **When not to use:** When high-precision geometric mesh extraction is needed instead of semantic segmentation [S1].

## Background
The method was introduced in **TexGS-VolVis** (2025) by the authors of [S1]. It builds on the concept of 2D-lift-3D segmentation [5,8,25,35] and is inspired by SAGD [25]. It addresses the limitation of previous methods like StyleRF-VolVis, which could not apply distinct edits to different parts of a basic scene or adjust lighting after stylization [S1]. The method is used in volume visualization (VolVis) for expressive scene editing [S1].
