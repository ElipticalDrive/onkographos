# 2D-Lift-3D Scene Segmentation

Also called: 2D-Lift-3D Segmentation for Partial Scene Editing, PSE with 2D-lift-3D segmentation

## Overview
This method segments 3D Gaussian primitives in a volume visualization scene by lifting 2D segmentation masks from a reference view into 3D space [S1]. It solves the problem of partial scene editing by decomposing a basic scene into distinct parts, allowing independent color, opacity, and lighting adjustments [S1]. Unlike sibling methods that may require learnable feature optimization or lack post-stylization editing capabilities, this approach uses a training-free multi-view label voting strategy to assign labels to Gaussians based on user prompts [S1].

## How it works
**Inputs:**
- A set of 2D Gaussian primitives representing the scene. Each primitive $i$ has position $\mathbf{p}_i$, covariance $\mathbf{\Sigma}_i$, opacity $\alpha_i$, and texture attribute $\mathbf{t}_i$ [S1].
- A reference view image rendered from the Gaussian scene.
- User-specified point prompts on the reference view.
- Camera parameters for all training views.

**Outputs:**
- A label $L_i \in \{1, \dots, K\}$ for each Gaussian primitive $i$, where $K$ is the number of segmented parts [S1].

**Data Structures:**
- **Gaussian Primitives:** A list of objects containing 3D position, 3x3 covariance matrix (or quaternion/scale representation), opacity, and a texture attribute vector [S1].
- **Label Map:** An integer array of size $N$ (number of Gaussians) storing the assigned label for each primitive [S1].
- **2D Masks:** Binary or multi-class masks for each training view [S1].

**Steps:**
1. **Render Reference View:** Render an image from the current Gaussian scene using the standard differentiable rasterization pipeline [S1].
2. **Generate 2D Mask:** Use the Segment Anything Model (SAM) with user-specified point prompts on the rendered reference view to generate a 2D segmentation mask [S1].
3. **Propagate to Training Views:** Generate 2D segmentation masks for the corresponding parts across all available training views using SAM [S1].
4. **Label Propagation:** For each training view, identify which Gaussian primitives project into the segmented regions. Assign temporary labels to these Gaussians based on the 2D mask [S1].
5. **Multi-View Label Voting:** Aggregate the labels from all training views for each Gaussian primitive. The final label $L_i$ is determined by majority voting among the views where the primitive is visible and segmented [S1].
6. **Decomposition:** Group Gaussian primitives by their final labels to form distinct 3D segments [S1].
7. **Editing:** Apply independent editing effects (color, opacity, lighting via Blinn-Phong model) to each segment [S1].

**Pseudocode:**
```python
def segment_gaussians(gaussians, reference_view, training_views, point_prompts):
    """
    Segments 3D Gaussian primitives using 2D-lift-3D segmentation.
    
    Args:
        gaussians: List of Gaussian primitives with position, covariance, opacity, texture.
        reference_view: Camera parameters for the reference view.
        training_views: List of camera parameters for all training views.
        point_prompts: List of 2D points on the reference view image for SAM.
        
    Returns:
        labels: Array of integer labels for each Gaussian primitive.
    """
    n_gaussians = len(gaussians)
    # Initialize vote counts for each label class. 
    # Assuming K classes, but K is determined dynamically by SAM output.
    # We use a dictionary or large enough array.
    label_votes = np.zeros((n_gaussians, MAX_LABELS), dtype=int)
    visibility_counts = np.zeros(n_gaussians, dtype=int)
    
    # Step 1: Generate 2D mask for reference view
    ref_image = render_scene(gaussians, reference_view)
    ref_mask = sam_segment(ref_image, point_prompts)
    
    # Step 2: Generate masks for all training views
    # Note: SAM is called for each view. The prompts must be mapped or re-specified.
    # The source implies SAM is used to generate masks for corresponding parts across all views.
    training_masks = []
    for view in training_views:
        view_image = render_scene(gaussians, view)
        # In practice, prompts might need to be transferred or user provides them per view.
        # The source states: "use SAM to automatically generate a series of 2D segmentation masks 
        # for the corresponding parts across all training views."
        view_mask = sam_segment(view_image, point_prompts) # Assuming prompt adaptation or re-use
        training_masks.append(view_mask)
        
    # Combine reference mask with training masks for voting
    all_masks = [ref_mask] + training_masks
    all_views = [reference_view] + training_views
    
    # Step 3 & 4: Label Propagation and Voting
    for mask, view in zip(all_masks, all_views):
        # Project all Gaussians to the current view
        projected = project_gaussians(gaussians, view)
        
        for i, proj in enumerate(projected):
            if proj.is_visible and proj.depth_valid:
                # Check if the projected pixel falls within the segmented region
                if mask[proj.u, proj.v] > 0:
                    label_id = mask[proj.u, proj.v] # Assuming mask contains label IDs
                    if label_id < MAX_LABELS:
                        label_votes[i, label_id] += 1
                        visibility_counts[i] += 1
                        
    # Step 5: Determine final labels via majority voting
    labels = np.argmax(label_votes, axis=1)
    
    return labels
```

**Parameters:**
- **SAM Model:** Used for 2D segmentation. Requires point prompts [S1].
- **Texture Attribute:** Uniformly represents both non-stylized and stylized scenes, enabling color editing after stylization [S1].
- **Shading Model:** Blinn-Phong model is used for lighting adjustments [S1].

**Edge Cases and Pitfalls:**
- The method cannot immediately generate a 3D segmentation from 2D masks created with point prompts on a single reference view. It requires multiple rounds of segmentation or multiple views, which can be inefficient for certain scenes [S1].
- Inaccurate or vague text prompts (if used in conjunction with IP2P) can lead to erroneous editing results [S1].

## Operating characteristics
- **Time Complexity:** Depends on the number of Gaussians $N$, the number of training views $V$, and the cost of SAM inference. Rendering and projection are $O(N)$ per view. SAM inference is $O(1)$ per view but heavy in absolute time.
- **Memory Complexity:** $O(N \cdot V)$ for storing vote counts if not optimized, or $O(N)$ if aggregated on the fly. Storage of 2D masks is $O(V \cdot W \cdot H)$.
- **Performance:** Supports real-time partial scene editing during inference [S1].
- **Strengths:** Training-free segmentation; supports post-stylization color and lighting edits via the texture attribute and Blinn-Phong model [S1].
- **Limitations:** Inefficient for scenes requiring multiple rounds of segmentation due to the inability to immediately lift 2D masks to 3D without multi-view voting [S1]. Cannot apply distinct edits to different parts of a basic scene in prior methods like StyleRF-VolVis, but this method enables it [S1].

## Background
The method was introduced in **TexGS-VolVis** (2025) by the authors of the source paper [S1]. It builds on the concept of 2D-lift-3D segmentation [5,8,25,35] and adapts the training-free strategy from SAGD [25] for volume visualization. It addresses limitations in previous works like StyleRF-VolVis, which lacked post-stylization editing and fine-grained partial scene control [S1].
