# GRay Optimization Settings

Also called: GRayLQ, GRayHQ

## Overview
GRay Optimization Settings define the hyperparameter configurations for training 3D Gaussian Splatting using the GRay ray-tracing renderer [S1]. They solve the problem of balancing training speed, final rendering frame rate, and visual fidelity by tuning opacity thresholds, pruning criteria, and spherical harmonic (SH) update strategies. Unlike standard 3DGS and 3DGRT, GRay does not use opacity resets and does not prune Gaussians based on size, relying instead on opacity and contribution thresholds [S1].

## How it works
The optimization process manages the population of 3D Gaussians through specific parameter presets that control pruning aggressiveness, opacity decay, and SH coefficient updates.

**Inputs and Outputs:**
*   **Input:** Initial set of Gaussians, camera poses, reference images, and a chosen preset (LQ or HQ).
*   **Output:** Optimized Gaussian attributes (position, covariance, opacity, SH coefficients) and final scene representation.

**Data Structures:**
The Gaussian attributes are stored in standard 3DGS structures. GRay modifies the optimization loop by:
1.  Disabling opacity resets [S1].
2.  Disabling size-based pruning [S1].
3.  Applying specific opacity and contribution thresholds for removal.

**Parameters and Steps:**
The core logic involves periodic evaluation of Gaussian significance. A Gaussian $g_k$ is pruned if its opacity $\alpha_k$ falls below a minimum threshold $\alpha_{\min}$ or its contribution falls below $\mu_{\text{prune}}$.

1.  **Initialization:** Generate initial Gaussians. Apply binning if enabled (default in GRay, disabled in GRayHQ) to remove initial floaters. The binning threshold $\alpha_{\text{bin}}$ is typically 0.04, removing over 15% of initial Gaussians with minimal quality loss [S1].
2.  **Optimization Loop:**
    *   Render image using GRay ray tracer.
    *   Compute loss against reference image.
    *   Backpropagate gradients.
    *   **Opacity Decay:** Apply scale decay factor $\eta_{\text{decay}}$ to opacity if enabled [S1].
    *   **SH Stepping:** Update SH coefficients lazily. If the number of iterations since the last SH update exceeds $\alpha_{\text{lazy}}$, perform the update [S1].
    *   **Pruning:** Every $N$ iterations (standard 3DGS schedule), evaluate Gaussians.
        *   If $\alpha_k < \alpha_{\min}$, mark for removal.
        *   If contribution $< \mu_{\text{prune}}$, mark for removal.
        *   Remove marked Gaussians from the active set.
3.  **Termination:** Stop after the specified number of iterations.

**Formulas:**
*   Pruning Condition: Remove $g_k$ if $\alpha_k < \alpha_{\min}$ OR $\text{contribution}(g_k) < \mu_{\text{prune}}$ [S1].
*   SH Update Frequency: Update SH if $\text{current\_iter} - \text{last\_sh\_iter} > \alpha_{\text{lazy}}$ [S1].

**Pseudocode:**
```python
# GRay Optimization Loop
def optimize_gaussians(gaussians, images, preset):
    # Extract preset parameters
    alpha_min = preset.alpha_min
    mu_prune = preset.mu_prune
    eta_decay = preset.eta_decay
    alpha_lazy = preset.alpha_lazy
    max_iters = preset.max_iters
    
    # Initialize SH update counter
    last_sh_iter = 0
    
    for iter in range(max_iters):
        # 1. Render and Compute Loss
        image = render_gray(gaussians, camera)
        loss = compute_loss(image, reference_image)
        
        # 2. Backpropagate
        gradients = compute_gradients(loss, gaussians)
        apply_gradients(gaussians, gradients)
        
        # 3. Opacity Decay (if enabled)
        if eta_decay is not None:
            gaussians.opacity *= eta_decay
            
        # 4. SH Stepping (Lazy Update)
        if iter - last_sh_iter > alpha_lazy:
            update_sh_coefficients(gaussians)
            last_sh_iter = iter
            
        # 5. Periodic Pruning (e.g., every 100-300 iterations)
        if iter % pruning_interval == 0:
            to_remove = []
            for g in gaussians:
                # Check opacity threshold
                if g.opacity < alpha_min:
                    to_remove.append(g.id)
                    continue
                # Check contribution threshold
                if g.contribution < mu_prune:
                    to_remove.append(g.id)
            remove_gaussians(gaussians, to_remove)
            
    return gaussians
```

**Edge Cases:**
*   **High Pruning Thresholds:** Setting $\tau_{\min}$ (opacity threshold for ray tracing stability) too high (e.g., 0.03) can cause catastrophic quality drops (PSNR 24.54) and failure to converge due to rapid Gaussian expansion [S1].
*   **DHT Disabling:** Disabling the Differentiable Hash Table (DHT) leads to rapid quality deterioration as truncation levels increase [S1].

## Subtopics

### GRayLQ Preset
A low-quality, high-speed configuration designed for rapid training and high frame rates. It uses aggressive pruning and decay settings.
*   **Parameters:** $\alpha_{\min}=0.02$, $\alpha_{\text{expo}}=3$, $\mu_{\text{prune}}=5\times10^{-7}$, $\eta_{\text{decay}}=0.9998$, SH stepping laziness at $\alpha_{\text{lazy}}=12$, iterations=7500 [S1].
*   **Performance:** At half resolution, achieves PSNR 26.23, SSIM 0.839, LPIPS 0.191. Init Time 01:58, Opt Time 00:46, FPS 1051. Initial Gaussians: 3.27M, Final: 0.48M [S1].
*   **Use Case:** When training speed and final rendering FPS are prioritized over maximum visual fidelity.

### GRayHQ Preset
A high-quality configuration that matches 3DGS opacity exponent and 3DGRT minimum opacity, with disabled scale decay and binning.
*   **Parameters:** $\alpha_{\min}=0.001$, $\alpha_{\text{expo}}=1$, $\tau_{\min}=0.001$, initialization binning disabled, pruning threshold $\mu_{\text{prune}}=10^{-9}$, scale decay disabled [S1].
*   **Performance:** At half resolution, achieves PSNR 27.41, SSIM 0.847, LPIPS 0.154. Init Time 01:58, Opt Time 36:11, FPS 55. Initial Gaussians: 3.97M, Final: 3.79M [S1].
*   **Use Case:** When visual quality is prioritized, approaching 3DGS-DI quality but with slower training.

## Operating characteristics
*   **Time Complexity:** Training time varies significantly by preset. GRayLQ trains in under a minute, while GRayHQ takes ~36 minutes [S1].
*   **Memory Complexity:** GRayLQ reduces Gaussian count from 3.27M to 0.48M, significantly lowering memory usage. GRayHQ retains nearly all initial Gaussians (3.97M to 3.79M) [S1].
*   **Performance:** GRayLQ achieves >1000 FPS at half resolution, more than doubling 3DGS's frame rate [S1]. GRayHQ achieves 55 FPS [S1].
*   **Strengths:** High rendering speed (LQ), reduced initial Gaussian count via binning, no opacity resets required.
*   **Limitations:** Quality drops significantly if pruning thresholds are too high or DHT is disabled [S1]. HQ preset is slower than standard 3DGS.

## Background
GRay is a ray-tracing based renderer for 3D Gaussian Splatting that aims to match the speed of splatting while offering higher quality [S1]. The optimization settings were developed to balance the trade-off between training time, final frame rate, and visual metrics (PSNR, SSIM, LPIPS) [S1]. The method distinguishes itself from 3DGS and 3DGRT by omitting opacity resets and size-based pruning [S1].
