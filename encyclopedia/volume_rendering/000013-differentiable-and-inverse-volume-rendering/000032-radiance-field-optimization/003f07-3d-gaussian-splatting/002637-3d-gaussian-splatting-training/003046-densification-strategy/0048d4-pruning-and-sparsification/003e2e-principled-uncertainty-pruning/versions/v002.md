# Principled Uncertainty Pruning

Also called: Fisher Information-based pruning score, PUP 3D-GS, PUP 3D-GS Pruning Score & Pipeline, Principled Uncertainty Pruning for 3D Gaussian Splatting

## Overview
Principled Uncertainty Pruning (PUP) is a post-hoc method for compressing pretrained 3D Gaussian Splatting (3D-GS) models by pruning Gaussians based on a sensitivity score derived from the Fisher Information matrix [S1]. Unlike heuristic-based siblings like [Significance-Aware Pruning](9676-significance-aware-pruning.md) or methods relying on visibility scores, PUP uses a second-order approximation of the reconstruction error to quantify the uncertainty of each Gaussian's spatial parameters, allowing for aggressive pruning (up to 90%) while preserving visual fidelity and foreground details [S1]. It employs a multi-round prune-refine pipeline to recover quality after each pruning step [S1].

## How it works
**Inputs:** A converged 3D-GS model $\mathcal{G}$ (set of Gaussians), training views $\mathcal{I}$ with poses $\Phi$, and target pruning percentage.
**Outputs:** A pruned set of Gaussians $\mathcal{G}'$ and fine-tuned parameters.

**Data Structures:**
*   **Gaussian Parameters:** Each Gaussian $i$ is defined by mean $\mu_i \in \mathbb{R}^3$, scale $s_i \in \mathbb{R}^3$, rotation $q_i \in \mathbb{R}^4$, and color coefficients. PUP focuses only on $\mu_i$ and $s_i$ [S1].
*   **Fisher Matrix Block:** For each Gaussian, a $6 \times 6$ block diagonal approximation of the Fisher Information matrix is computed, corresponding to the 3 mean and 3 scale parameters [S1].
*   **Pruning Score:** The log-determinant of the Fisher block for each Gaussian [S1].

**Step-by-Step Method:**

1.  **Compute L2 Loss:** Calculate the reconstruction loss over training views:
    $$L_2 = \frac{1}{2} \sum_{\phi \in \Phi} \|I_{\mathcal{G}}(\phi) - I_{gt}(\phi)\|_2^2$$
    where $I_{\mathcal{G}}(\phi)$ is the rendered image at pose $\phi$ and $I_{gt}$ is the ground truth [S1].

2.  **Approximate Hessian via Fisher:** The full Hessian of the loss is:
    $$\nabla_{\mathcal{G}}^2 L_2 = \sum_{\phi \in \Phi} \nabla_{\mathcal{G}} I_{\mathcal{G}}(\phi) \nabla_{\mathcal{G}} I_{\mathcal{G}}(\phi)^T + (I_{\mathcal{G}}(\phi) - I_{gt}) \nabla_{\mathcal{G}}^2 I_{\mathcal{G}}(\phi)$$
    On a converged model, the residual $(I_{\mathcal{G}} - I_{gt})$ approaches zero, vanishing the second-order term. The Hessian is approximated by the Fisher Information matrix:
    $$\nabla_{\mathcal{G}}^2 L_2 \approx \sum_{\phi \in \Phi} \nabla_{\mathcal{G}} I_{\mathcal{G}}(\phi) \nabla_{\mathcal{G}} I_{\mathcal{G}}(\phi)^T$$
    [S1]. This is equivalent to the variance of the score $E[(\nabla \log p)^2]$ [S1].

3.  **Compute Sensitivity Score:** For each Gaussian $i$, compute the $6 \times 6$ Fisher block $F_i$ using gradients of the rendered image with respect to the mean and scale parameters. The pruning score $S_i$ is the log-determinant of this block:
    $$S_i = \log \det(F_i)$$
    This score represents the entropy of the second-order Laplace approximation of the posterior distribution for that Gaussian [S1]. Lower entropy (lower score) implies higher uncertainty (parameters can be perturbed more without affecting loss), making the Gaussian a candidate for pruning [S1].

4.  **Multi-Round Prune-Refine Pipeline:**
    *   **Round 1:** Prune the bottom 80% of Gaussians based on score $S_i$. Fine-tune the remaining 20% for 5,000 iterations [S1].
    *   **Round 2:** Prune the bottom 50% of the *remaining* Gaussians based on updated scores. Fine-tune for another 5,000 iterations [S1].
    *   This two-round process yields ~90% total pruning [S1].

**Pseudocode:**

```python
def principled_uncertainty_pruning(gaussians, training_images, training_poses, 
                                  num_rounds=2, prune_ratios=[0.8, 0.5], 
                                  fine_tune_iters=5000):
    """
    Prunes 3D-GS model using Fisher Information-based uncertainty.
    
    Args:
        gaussians: List of Gaussian objects with attributes .mean, .scale, .render()
        training_images: List of ground truth images
        training_poses: List of camera poses
        prune_ratios: List of fractions to prune in each round
        fine_tune_iters: Number of fine-tuning steps per round
        
    Returns:
        pruned_gaussians: List of remaining Gaussian objects
    """
    current_gaussians = gaussians
    
    for round_idx, prune_ratio in enumerate(prune_ratios):
        # 1. Compute Fisher Information Matrix blocks for all current Gaussians
        fisher_blocks = []
        for g in current_gaussians:
            # Compute gradient of rendered image w.r.t mean (3) and scale (3)
            # Note: In practice, this uses automatic differentiation or finite differences
            # over the training views.
            grad_mean = compute_gradient(g, training_images, training_poses, param='mean')
            grad_scale = compute_gradient(g, training_images, training_poses, param='scale')
            
            # Stack gradients to form Jacobian J (num_views * img_size x 6)
            J = stack_gradients(grad_mean, grad_scale)
            
            # Fisher approximation: F = J^T @ J
            # We only need the block for this Gaussian
            F = J.T @ J
            
            # Score is log determinant
            score = log_det(F)
            fisher_blocks.append((score, g))
        
        # 2. Sort by score (ascending: lower score = higher uncertainty = prune first)
        fisher_blocks.sort(key=lambda x: x[0])
        
        # 3. Prune
        num_to_prune = int(len(fisher_blocks) * prune_ratio)
        kept_gaussians = [fb[1] for fb in fisher_blocks[num_to_prune:]]
        
        # 4. Fine-tune
        # Re-initialize optimizer with kept_gaussians
        # Run optimization for fine_tune_iters steps using L2 loss
        current_gaussians = fine_tune(kept_gaussians, training_images, training_poses, 
                                      iterations=fine_tune_iters)
        
    return current_gaussians

def compute_gradient(gaussian, images, poses, param):
    """
    Computes the gradient of the L2 loss w.r.t. a specific parameter.
    """
    # Render image
    rendered = gaussian.render(poses)
    
    # Compute L2 loss
    loss = 0.5 * sum((r - gt)**2 for r, gt in zip(rendered, images))
    
    # Compute gradient using backpropagation
    if param == 'mean':
        grad = torch.autograd.grad(loss, gaussian.mean, retain_graph=True)[0]
    elif param == 'scale':
        grad = torch.autograd.grad(loss, gaussian.scale, retain_graph=True)[0]
        
    return grad

def log_det(matrix):
    """
    Computes log determinant of a matrix.
    """
    # Use log-sum-exp trick for stability if necessary
    return torch.log(torch.det(matrix))
```

**Parameters:**
*   **Pruning Percentages:** 80% in Round 1, 50% in Round 2 [S1].
*   **Fine-tuning Iterations:** 5,000 per round [S1].
*   **Patch Size:** Sensitivity can be computed over image patches of size $2\times2$, $4\times4$, or $8\times8$. Default is $4\times4$ [S1].

**Edge Cases and Pitfalls:**
*   **Convergence Requirement:** The method assumes the scene is fully converged. The Fisher approximation relies on a small L1 residual; pruning before convergence degrades accuracy [S1].
*   **Memory Usage:** Including rotation parameters expands the Fisher block to $10\times10$, increasing memory by $2.78\times$. This causes OOM on 16GB GPUs (e.g., RTX A4000) [S1].
*   **Color Parameters:** Using RGB color parameters for the score degrades quality because it correlates with visibility rather than reconstruction error sensitivity [S1].

## Subtopics

### Significance-Aware Pruning
A sibling method that uses different heuristics for pruning. PUP is distinguished by its principled Fisher-based uncertainty score and multi-round refinement. See [Significance-Aware Pruning](9676-significance-aware-pruning.md).

## Operating characteristics
*   **Time Complexity:** The dominant cost is computing the Fisher matrices, which scales linearly with the number of Gaussians $N$ and the number of training views. The memory requirement is proportional to $N \times 36$ bytes (for the $6\times6$ block) [S1].
*   **Measured Performance:** On the Deep Blending playroom scene, PUP prunes from 2.65M to 0.265M Gaussians, increasing FPS from 76.65 to 318.06 (4.15x speed-up) [S1]. Across Mip-NeRF 360, Tanks & Temples, and Deep Blending, it achieves an average 3.56x speed-up after 90% pruning [S1].
*   **Strengths:** Preserves fine details and foreground information better than LightGaussian and other heuristics. Achieves higher PSNR/SSIM and lower LPIPS at ~90% pruning [S1].
*   **Limitations:** Requires a converged model. Memory intensive for large scenes if high-precision gradients are used, though $6\times6$ blocks fit on 16GB GPUs [S1].

## Background
PUP 3D-GS was introduced by Alex Hanson, Allen Tu, Vasu Singla, Mayuka Jayawardhana, Matthias Zwicker, and Tom Goldstein from the University of Maryland, College Park [S1]. It was published in 2025 at CVPR [S1]. The method builds on the observation that uncertainty in 3D-GS can be quantified via the Hessian of the reconstruction error, approximated by the Fisher Information matrix [S1]. It addresses the limitations of heuristic pruning methods like LightGaussian, which lose fine details at high compression ratios [S1].
