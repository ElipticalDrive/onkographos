# Gaussian Insertion and Pruning

Also called: Monocular Gaussian Initialization

## Overview
Gaussian Insertion and Pruning is a densification strategy designed for monocular and RGB-D SLAM systems using 3D Gaussian Splatting, specifically addressing the initialization of new primitives in unseen regions and the removal of geometrically unstable outliers [S1, unofficial]. Unlike standard offline densification which relies on gradient norms or screen-space error, this method uses visibility consistency across a sliding window of keyframes to validate new Gaussians [S1, unofficial]. It is distinct from [Adaptive Density Control](9188-adaptive-density-control.md) by prioritizing SLAM stability over reconstruction fidelity, and from [Score-based Densification](4705-score-based-densification.md) by using explicit depth sampling and cross-view visibility checks rather than accumulated loss gradients.

## How it works
**Inputs:**
*   Current set of 3D Gaussians $\mathcal{G}$.
*   Current camera pose and intrinsics.
*   Rendered depth map $D$ for the current frame.
*   Keyframe window $W_k$ containing recent keyframes.
*   Hyperparameters: $\sigma_D$ (depth noise scale), opacity threshold $\alpha_{thresh} = 0.7$, visibility count threshold $N_{vis} = 3$, insertion window $N_{ins} = 3$ keyframes.

**Outputs:**
*   Updated set of 3D Gaussians $\mathcal{G}'$ with new primitives inserted and unstable ones pruned.

**Data Structures:**
*   **Keyframe Window $W_k$:** A fixed-size buffer storing recent keyframe poses and associated data. Size $|W_k|$ is typically 8 (TUM) or 10 (Replica) [S1, unofficial].
*   **Gaussian Attributes:** Each Gaussian $i$ has mean $\mu_i$, covariance $\Sigma_i$, opacity $\alpha_i$, and color $c_i$.

**Steps:**

1.  **Depth Rendering:** Render the current scene to obtain a depth map $D$ and an accumulated alpha map $\alpha_{acc}$ for the current view. A Gaussian is considered "visible" from a view if it was used in rasterization and the ray's accumulated $\alpha$ has not yet reached 0.5 [S1, unofficial].

2.  **Gaussian Insertion:**
    *   Determine the number of new Gaussians to insert based on the number of pixels or regions requiring coverage.
    *   For each new Gaussian, sample a 3D position $\mu_W$:
        *   **RGB-D Case:** If physical depth measurements are available, back-project the depth measurement to initialize $\mu_W$ [S1, unofficial].
        *   **Monocular Case:** Use the rendered depth $D$.
            *   If pixel $p$ has a valid depth estimate $D_p$: Sample depth $z \sim \mathcal{N}(D_p, 0.2\sigma_D)$ [S1, unofficial].
            *   If pixel $p$ lacks a depth estimate: Sample depth $z \sim \mathcal{N}(\hat{D}, 0.5\sigma_D)$, where $\hat{D}$ is the median depth of the rendered image [S1, unofficial].
            *   Project the sampled depth $z$ and pixel coordinates to 3D space to get $\mu_W$ [S1, unofficial].
    *   Initialize the new Gaussian's covariance and color. Opacity is typically initialized low to allow optimization to converge [Parent].

3.  **Visibility-Based Pruning (Stability Check):**
    *   This step is performed only once the keyframe window $W_k$ is full [S1, unofficial].
    *   Identify Gaussians inserted within the last $N_{ins}=3$ keyframes.
    *   For each such Gaussian, count how many *other* frames in the current window $W_k$ observe it (i.e., the Gaussian contributes to the rendering of those frames without being occluded by higher $\alpha$).
    *   If a Gaussian is unobserved by at least $N_{vis}=3$ other frames in $W_k$, it is marked for removal as geometrically unstable [S1, unofficial].

4.  **Opacity Pruning:**
    *   Remove all Gaussians with current opacity $\alpha_i < 0.7$ [S1, unofficial].

**Pseudocode:**

```python
def gaussian_insertion_and_pruning(current_gaussians, current_view, keyframe_window, sigma_D):
    """
    current_gaussians: List of Gaussian objects
    current_view: Object containing camera pose, intrinsics, and rendered depth D
    keyframe_window: List of recent keyframe views (must be full for pruning)
    sigma_D: Depth noise scale parameter
    """
    
    # 1. Render Depth and Alpha
    D, alpha_acc = render_depth_and_alpha(current_gaussians, current_view)
    
    # 2. Insert New Gaussians
    new_gaussians = []
    # Determine pixels/regions needing new Gaussians (implementation detail not specified in source)
    target_pixels = get_target_pixels(D, current_view) 
    
    for p in target_pixels:
        if D[p] is valid:
            # Sample from rendered depth with low variance
            z = sample_normal(D[p], 0.2 * sigma_D)
        else:
            # Sample from median depth with high variance
            median_depth = median(D)
            z = sample_normal(median_depth, 0.5 * sigma_D)
        
        # Back-project to 3D
        mu_W = back_project(p, z, current_view.intrinsics)
        
        # Create new Gaussian
        g_new = Gaussian(mean=mu_W, covariance=initial_covariance(), opacity=0.01, color=initial_color())
        new_gaussians.append(g_new)
        
    current_gaussians.extend(new_gaussians)
    
    # 3. Visibility-Based Pruning (Only if window is full)
    if len(keyframe_window) >= MIN_WINDOW_SIZE:
        pruned_indices = []
        # Identify Gaussians inserted in last 3 keyframes
        recent_gaussians = get_gaussians_inserted_in_last_n_keyframes(current_gaussians, n=3)
        
        for g in recent_gaussians:
            visibility_count = 0
            # Check visibility in other frames in the window
            for other_view in keyframe_window:
                if other_view == current_view:
                    continue
                # Check if g is visible in other_view
                # Visibility defined as: used in rasterization AND accumulated alpha < 0.5
                if is_visible(g, other_view, alpha_acc_threshold=0.5):
                    visibility_count += 1
            
            # Prune if not observed by at least 3 other frames
            if visibility_count < 3:
                pruned_indices.append(g.id)
        
        current_gaussians = remove_gaussians(current_gaussians, pruned_indices)
        
    # 4. Opacity Pruning
    low_opacity_indices = [g.id for g in current_gaussians if g.opacity < 0.7]
    current_gaussians = remove_gaussians(current_gaussians, low_opacity_indices)
    
    return current_gaussians
```

## Operating characteristics
*   **Time Complexity:** Insertion is $O(N_{new})$ where $N_{new}$ is the number of inserted Gaussians. Visibility pruning is $O(N_{recent} \cdot |W_k|)$, where $N_{recent}$ is the number of recently inserted Gaussians. This is generally lighter than gradient-based densification which requires backward passes for all Gaussians.
*   **Memory Complexity:** Increases linearly with the number of inserted Gaussians. Pruning helps bound the growth.
*   **Strengths:** Effective at removing "floaters" and geometrically inconsistent Gaussians in SLAM contexts where depth is uncertain. Does not require gradient computation for densification decisions.
*   **Limitations:** Relies on the accuracy of rendered depth. In monocular settings, incorrect depth estimates lead to initial misplacement, requiring the pruning step to clean up. The opacity threshold (0.7) is aggressive and may remove valid but low-opacity primitives [S1, unofficial].
*   **When to use:** Monocular or RGB-D SLAM pipelines using 3DGS where tracking stability is critical and gradient-based methods are too slow or unstable.

## Background
This method was introduced in "Gaussian Splatting SLAM" [S1, unofficial], a preprint published in December 2023. It adapts the 3D Gaussian Splatting representation for simultaneous localization and mapping (SLAM), specifically addressing the challenges of initializing Gaussians in unseen areas and maintaining map consistency without strong depth priors. The approach is tailored for datasets like Replica and TUM RGB-D [S1, unofficial].
