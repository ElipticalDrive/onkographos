# Curriculum Learning with Slice and Voxel Supervision

Also called: Slice and Voxel Supervision Curriculum

## Overview
This method addresses the instability and incomplete volumetric reconstruction inherent in optimizing 3D Gaussian representations for shear-warp rendering by decoupling supervision signals over time. It sets itself apart from sibling methods like [Hybrid Coarse-to-Fine Strategy](7173-hybrid-coarse-to-fine-strategy.md) by explicitly leveraging the structural alignment between 2D slice-based sampling and the shear-warp rendering pipeline, rather than relying solely on geometric densification thresholds.

## How it works
**Inputs and Outputs:**
*   **Input:** A set of 3D volumetric data (e.g., MRI, Cryosection) and a target Gaussian representation $G = \{G_1, G_2, \dots, G_m\}$ initialized from voxel samples.
*   **Output:** Optimized Gaussian parameters (mean $\mu$, covariance $\Sigma$, opacity $\alpha$, color $c$) that minimize rendering error against ground-truth slices and voxels.

**Data Structures:**
*   **Gaussian Set $G$:** Each Gaussian $G_i$ is defined by learnable parameters: mean $\mu \in \mathbb{R}^3$, covariance matrix $\Sigma \in \mathbb{R}^{3 \times 3}$, opacity $\alpha \in [0, 1]$, and spherical harmonics coefficients for color $c$.
*   **Voxel Grid:** The source volume is discretized into a 3D grid.

**Steps:**
1.  **Initialization:** Initialize one Gaussian kernel centered at each sampled voxel position from the input volume [S1].
2.  **Stage 1: Slice Supervision:**
    *   In each training iteration, sample a plane with arbitrary orientation [S1].
    *   Select sparse pixels on the sampled plane [S1].
    *   Map each selected pixel to a 3D voxel coordinate [S1].
    *   Render the projection of the current Gaussian set onto this plane using shear-warp rendering principles.
    *   Compute loss between rendered slice and ground-truth slice data.
    *   Update Gaussian parameters to minimize this loss. This stage establishes local spatial continuity and texture coherence [S1].
3.  **Stage 2: Voxel Supervision:**
    *   After the slice supervision phase stabilizes local structures, introduce voxel supervision [S1].
    *   Sample voxels randomly from the volume with dense approximation [S1].
    *   Evaluate the Gaussian representation at these voxel coordinates.
    *   Compute loss between the predicted voxel values and ground-truth voxel data.
    *   Update Gaussian parameters. This stage provides global spatial guidance and ensures volumetric consistency [S1].

**Formulas:**
*   **Rendering:** The value $V$ at a pixel is computed via alpha-compositing along the ray, consistent with shear-warp rendering [S1].
*   **Loss:** The total loss $\mathcal{L}$ is a combination of slice loss $\mathcal{L}_{slice}$ and voxel loss $\mathcal{L}_{voxel}$, weighted by the curriculum stage [S1].

**Parameters:**
*   **Curriculum Schedule:** The transition from slice-only to combined slice-voxel supervision is not explicitly defined in iterations in the source, but is described as "progressive" [S1].
*   **Sampling Density:** Sparse pixels for slices and random voxels for global coverage [S1].

**Edge Cases and Pitfalls:**
*   **Instability with Random Voxels First:** Applying random voxel supervision before stable slice constraints leads to unstable global approximation and destabilizes learning [S1].
*   **Lack of Global Guidance with Slices Only:** Using only slice supervision (A4) limits accurate reconstruction of the full volumetric structure due to lack of global spatial guidance [S1].
*   **Random Voxel Instability:** Random voxel sampling without structured slice constraints leads to unstable global approximation [S1].

## Subtopics

### Curriculum Learning with Sparse Voxel and Slice Sampling
This variant explicitly aligns the sampling strategy with shear-warp volume rendering. It uses sparse voxels for global coverage and slice samples for spatially correlated regions encoding geometric structure and texture continuity. In each iteration, a plane with arbitrary orientation is sampled, sparse pixels are selected, and each pixel is mapped to a 3D voxel coordinate, allowing the Gaussian representation to learn spatial continuity across neighboring regions [S1].

## Operating characteristics
*   **Performance:** Combining slice and voxel supervision yields higher PSNR and SSIM compared to using only slice supervision (A4) or random voxel sampling alone [S1].
*   **Limitations:** Random voxel sampling without slice supervision leads to unstable global approximation [S1]. Slice-only supervision lacks global spatial guidance [S1].
*   **Strengths:** Efficiently learns both global volumetric consistency and local anatomical details [S1]. Aligns naturally with shear-warp rendering [S1].
*   **When to use:** For multimodal volumetric datasets (MRI, Cryosection) where efficient reconstruction and real-time selective visualization are required [S1].

## Background
The method originates from research on Gaussian Volumetric Representation for Efficient Shear-Warp Visualization, published in 2025 [S1]. It builds on the principle that shear-warp rendering operates on stacks of 2D slices, making slice-based supervision a natural fit for training Gaussian representations intended for this rendering pipeline. The approach is applicable to multimodal volumetric datasets including MRI and Cryosection volumes [S1].
