# Hybrid and Diffusion Representations

Also called: TriplaneGaussian, GaussianDiffusion

## Overview
Hybrid and Diffusion Representations address the problem of generating 3D Gaussian Splatting (3DGS) scenes from single images or text prompts, bypassing the iterative optimization required by standard inverse rendering. This family sets itself apart from sibling methods like [Adaptive Gaussian Refinement](11448-adaptive-gaussian-refinement.md) by using feed-forward neural networks or generative diffusion models to directly predict Gaussian parameters, rather than densifying an existing set of primitives.

## Shared principles
The family shares the goal of generating a complete set of 3D Gaussians $\mathcal{G} = \{ \mu_i, \Sigma_i, \alpha_i, c_i \}_{i=1}^{N'}$ from a compact input (image or text) without per-scene optimization. Common mechanisms include:
1.  **Implicit to Explicit Mapping:** Both subtopics map a continuous or structured latent representation (tri-planes or voxel grids) to explicit Gaussian parameters via a decoder (MLP or diffusion model).
2.  **Structural Regularization:** To ensure geometric consistency, methods incorporate structural constraints. TriplaneGaussian uses a point cloud to guide feature querying, while GaussianDiffusion uses structured noise to enforce multi-view consistency.
3.  **Direct Parameter Prediction:** Unlike [Densification Strategy](6234-densification-strategy.md) which modifies existing Gaussians, these methods output the final set of Gaussians directly from the network weights.

## Subtopics

### [TriplaneGaussian](7558-triplanegaussian.md)
TriplaneGaussian is a feed-forward method for generating 3D Gaussian Splatting (3DGS) representations from a single input image. It solves the problem of single-image 3D reconstruction by decoupling the generation of geometric structure (point cloud) and attribute encoding (tri-plane). It sets itself apart from sibling methods like [Adaptive Gaussian Refinement](11448-adaptive-gaussian-refinement.md), which generates a coarse 3DGS and upsamples it via a U-Net, by instead projecting a densified point cloud onto a tri-plane to query features that are then decoded into Gaussian attributes.

### [GaussianDiffusion](9190-gaussiandiffusion.md)
GaussianDiffusion is a method that trains a 3D diffusion model based on a **GaussianCube** representation to generate 3D Gaussian Splatting (3DGS) scenes. It addresses the "Janus problem" (inconsistent geometry across viewpoints) by incorporating structured noises from multiple viewpoints and mitigates spurious "floaters" through variational 3DGS objectives. It differs from sibling methods like TriplaneGaussian by operating directly in a voxelized Gaussian space rather than a triplane feature space.

## Background
The shift from iterative optimization to direct generation in 3DGS was driven by the need for faster scene synthesis and better generalization from limited inputs. TriplaneGaussian and GaussianDiffusion represent early attempts to integrate generative priors (from 2D diffusion models or tri-plane architectures) into the 3DGS framework. Text2Immersion and similar methods (like GALA3D and DreamScene mentioned in [S1]) further explore text-to-3D generation by combining object-level and scene-level diffusion models.
