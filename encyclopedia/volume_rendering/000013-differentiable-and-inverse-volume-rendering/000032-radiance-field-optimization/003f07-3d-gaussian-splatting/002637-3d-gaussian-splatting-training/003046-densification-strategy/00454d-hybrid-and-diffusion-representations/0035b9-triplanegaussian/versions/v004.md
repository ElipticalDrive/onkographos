# TriplaneGaussian

Also called: TriPlaneGS

## Overview
TriplaneGaussian is a feed-forward method for generating 3D Gaussian Splatting (3DGS) representations from a single input image [S1]. It solves the problem of single-image 3D reconstruction by proposing a hybrid representation that combines a point cloud with a tri-plane encoding of Gaussian attributes [S1]. It sets itself apart from sibling methods like [GaussianDiffusion](9190-gaussiandiffusion.md) by using a deterministic transformer-based decoder and tri-plane feature querying rather than a diffusion process, and from [Hybrid and Diffusion Representations](11473-hybrid-and-diffusion-representations.md) generally by explicitly decoupling geometry (point cloud) and attributes (tri-plane) before merging them [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A single RGB image $I$.
*   **Output:** A set of 3D Gaussians $\mathcal{G} = \{g_i\}$, where each Gaussian $g_i$ is defined by center $\mathbf{c}_i$, covariance $\mathbf{\Sigma}_i$, opacity $\alpha_i$, and spherical harmonic coefficients $\mathbf{c}_{SH}$ [S1].

**Data Structures:**
1.  **Point Cloud:** A set of 3D points $\mathbf{P} = \{\mathbf{p}_j\}$ representing the initial geometry.
2.  **Tri-Plane:** Three 2D feature planes $\mathcal{T} = \{T_x, T_y, T_z\}$, each of size $H_T \times W_T \times C_T$, encoding attribute information [S1].
3.  **Image Features:** Intermediate features extracted from the input image $I$ via a backbone network (e.g., ViT or ResNet), denoted as $F_{img}$ [S1].

**Parameters:**
*   $N_{coarse}$: Number of initial Gaussians generated by the coarse stage.
*   $N_{final}$: Number of Gaussians after upsampling.
*   $H_T, W_T$: Resolution of the tri-planes.
*   $C_T$: Channel dimension of the tri-planes.
*   Typical values are not given in the sources.

**Steps:**
1.  **Feature Extraction:** Extract image features $F_{img}$ from the input image $I$ using a backbone network [S1].
2.  **Coarse Generation:**
    a.  Generate a coarse point cloud $\mathbf{P}_{coarse}$ and a coarse tri-plane $\mathcal{T}_{coarse}$ from $F_{img}$ using a transformer-based point cloud decoder and a tri-plane decoder, respectively [S1].
    b.  The point cloud $\mathbf{P}_{coarse}$ is densified through an upsampling method to increase point density [S1].
    c.  Project the densified points $\mathbf{P}_{coarse}$ onto the tri-plane $\mathcal{T}_{coarse}$ to query features. For each point $\mathbf{p}_j = (x_j, y_j, z_j)$, sample features from $T_x, T_y, T_z$ at coordinates $(x_j, y_j), (x_j, z_j), (y_j, z_j)$ [S1].
    d.  Augment the queried tri-plane features with the projected image features $F_{img}$ [S1].
    e.  Translate the augmented features into 3D Gaussian attributes (center, covariance, opacity, SH) using a Multi-Layer Perceptron (MLP) [S1]. This produces a coarse 3DGS representation $\mathcal{G}_{coarse}$ [S1].
3.  **Super-Resolution:**
    a.  Upsample the coarse 3DGS $\mathcal{G}_{coarse}$ through a U-Net-based super-resolution module to improve fidelity [S1].
    b.  The output is the final 3DGS representation $\mathcal{G}_{final}$ [S1].

    # 1. Extract image features

## Subtopics

### [Hybrid Gaussian Representation with Geometry-Guided Constraints](10609-hybrid-gaussian-representation-with-geometry-guided-constrai.md)
This method is a 3D Gaussian Splatting rendering technique that adaptively selects between 2D and 3D Gaussian primitives based on local geometric cues to reduce redundancy in planar structures while maintaining volumetric accuracy. It integrates TensoSDF for global geometric consistency, enforcing implicit surface constraints during optimization. Unlike standard 3DGS which uses only 3D ellipsoids, or 2DGS which uses only tangent planes, this method dynamically switches representations to better fit both thin surfaces and volumetric details. It builds on [TriplaneGaussian](7558-triplanegaussian.md) by introducing explicit geometry-guided constraints via TensoSDF rather than relying solely on tri-plane initialization.

### [Volume-Based Densification](10710-volume-based-densification.md)
Volume-Based Densification is a refinement strategy for 3D Gaussian Splatting that replaces or supplements gradient-based Adaptive Density Control (ADC) with geometric volume analysis to manage primitive density. It solves the failure of traditional ADC in high-frequency, sparse regions (e.g., grass, wires) where positional gradients are insufficient to trigger densification, and where uncontrolled Gaussian growth leads to blurred artifacts. Unlike its sibling [Hybrid Gaussian Representation with Geometry-Guided Constraints](10609-hybrid-gaussian-representation-with-geometry-guided-constrai.md) which uses geometry-guided constraints, this method specifically leverages the ellipsoid volume and covariance condition number to drive cloning and splitting decisions.

### [Phys3DGS](11050-phys3dgs.md)
Phys3DGS is a physically-based inverse rendering method that resolves the "hidden Gaussian" problem, where Gaussians beneath the surface adversely affect pixel color in volume rendering, by employing deferred rendering and a mesh-3DGS hybrid representation. It differs from standard relightable 3DGS methods by decoupling geometry estimation from material learning via a two-step training process, and from naive deferred approaches by introducing specific regularizations to stabilize BRDF learning and prevent mesh extraction artifacts.

## Background
TriplaneGaussian was proposed in the context of recent advances in 3D Gaussian Splatting [S1]. It is cited as a method that explores utilizing existing 3D datasets and constructing large models to directly generate 3DGS representation from a single image [S1]. It is distinct from methods like LGM, which uses multi-view images, and BrightDreamer, which predicts deviations from fixed anchor points [S1].
