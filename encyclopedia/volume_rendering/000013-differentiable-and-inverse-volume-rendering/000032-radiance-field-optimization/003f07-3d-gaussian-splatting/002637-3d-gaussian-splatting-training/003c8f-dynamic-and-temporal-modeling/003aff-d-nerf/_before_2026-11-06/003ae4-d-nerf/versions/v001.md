# D-NeRF
Also called: Dynamic-NeRF, Neural Radiance Fields for Dynamic Scenes

## Overview
D-NeRF is a method for synthesizing novel views at an arbitrary point in time of dynamic scenes with complex non-rigid geometries [S1]. It optimizes an underlying deformable volumetric function from a sparse set of input monocular views without requiring ground-truth geometry or multi-view images at the same time instant [S1]. Unlike naive extensions of NeRF that map $(x, y, z, t)$ directly to density and radiance, D-NeRF decomposes learning into two modules: a deformation network mapping scene points to a common canonical configuration, and a canonical network regressing density and color from that configuration [S1]. This decomposition effectively exploits temporal redundancy, enabling the handling of rigid, articulated, and non-rigid motions [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** A sparse set of $T$ RGB images $\{I_t\}_{t=1}^T$ and their corresponding camera pose matrices $\{T_t\}_{t=1}^T$, where $I_t \in \mathbb{R}^{H \times W \times 3}$ and $T_t \in \mathbb{R}^{4 \times 4}$ is an SE(3) matrix [S1, S2]. Each time instant $t$ is captured by a single camera (monocular) [S1].
*   **Outputs:** Rendered pixel color $C'(p, t)$ for a pixel $p$ at time $t$ and camera view $(\theta, \phi)$ [S1].

**Data Structures**
The model consists of two deep fully connected networks (MLPs) without convolutional layers [S1]:
1.  **Deformation Network $\Psi_t$:**
    *   **Architecture:** 8-layer MLP with ReLU activations [S1].
    *   **Input:** Encoded 3D position $\mathbf{x}$ and time $t$.
    *   **Output:** Displacement vector $\Delta \mathbf{x} \in \mathbb{R}^3$. No non-linearity is applied to the output [S1].
2.  **Canonical Network $\Psi_x$:**
    *   **Architecture:** 8-layer MLP with ReLU activations [S1].
    *   **Input:** Encoded transformed position $\mathbf{x} + \Delta \mathbf{x}$ and viewing direction $\mathbf{d}$.
    *   **Output:** Volume density $\sigma \in \mathbb{R}$ and emitted color $\mathbf{c} \in \mathbb{R}^3$. A final sigmoid non-linearity is applied to both $\sigma$ and $\mathbf{c}$ [S1].

**Positional Encoding**
Raw coordinates are encoded into a higher-dimensional space using positional encoding $\gamma(\mathbf{p})$ [S1, S2]:
$$ \gamma(\mathbf{p}) = \left\langle (\sin(2^l \pi \mathbf{p}), \cos(2^l \pi \mathbf{p})) \right\rangle_{l=0}^{L-1} $$
The encoder is applied independently to each coordinate and camera view component [S1].
*   For spatial coordinates $\mathbf{x}$: $L = 10$ [S1, S2].
*   For viewing direction $\mathbf{d}$ and time $t$: $L = 4$ [S1, S2].

**Canonical Configuration**
The canonical scene is defined as the scene state at time $t=0$ [S1, S2]. The deformation network is constrained such that:
$$ \Psi_t(\mathbf{x}, 0) = \mathbf{0} \quad \text{and} \quad \Psi_t(\mathbf{x}, t) = \Delta \mathbf{x} \text{ for } t \neq 0 \quad \text{[S1]} $$
This interconnects all time instances through a common anchor [S1].

**Rendering Process**
Given a camera ray defined by origin $\mathbf{o}$ and direction $\mathbf{d}$, and near/far bounds $h_n, h_f$:
1.  Sample $N$ points $\{h_n\}_{n=1}^N$ along the ray using stratified sampling from evenly-spaced bins in $[h_n, h_f]$ [S1].
2.  For each sample $h$, compute the 3D point on the ray in world space: $\mathbf{x}(h) = \mathbf{o} + h\mathbf{d}$ [S1, S2].
3.  Transform $\mathbf{x}(h)$ to canonical space using the deformation network:
    $$ \Delta \mathbf{x} = \Psi_t(\mathbf{x}(h), t) $$
    $$ \mathbf{p}(h, t) = \mathbf{x}(h) + \Delta \mathbf{x} \quad \text{[S1, S2]} $$
4.  Query the canonical network with the transformed point and viewing direction:
    $$ [\mathbf{c}(\mathbf{p}(h, t), \mathbf{d}), \sigma(\mathbf{p}(h, t))] = \Psi_x(\mathbf{p}(h, t), \mathbf{d}) \quad \text{[S1, S2]} $$
5.  Compute opacity $\alpha$ and transmittance $T$ for the samples:
    $$ \delta_n = h_{n+1} - h_n $$
    $$ \alpha(h, t, \delta_n) = 1 - \exp(-\sigma(\mathbf{p}(h, t)) \delta_n) $$
    $$ T'(h_n, t) = \exp\left(-\sum_{m=1}^{n-1} \sigma(\mathbf{p}(h_m, t)) \delta_m\right) \quad \text{[S1]} $$
6.  Approximate the pixel color $C'(p, t)$:
    $$ C'(p, t) = \sum_{n=1}^{N} T'(h_n, t) \alpha(h_n, t, \delta_n) \mathbf{c}(\mathbf{p}(h_n, t), \mathbf{d}) \quad \text{[S1]} $$

**Training**
*   **Loss:** Mean Squared Error (MSE) between rendered pixels $C'$ and ground truth pixels $\hat{C}$ [S1, S2]:
    $$ \text{Loss} = \frac{1}{N_s} \sum_{i=1}^{N_s} \|\hat{C}(p_i, t) - C'(p_i, t)\|^2 $$
*   **Optimization:** Parameters of $\Psi_x$ and $\Psi_t$ are learned simultaneously [S1, S2].
*   **Optimizer:** Adam with learning rate $5 \times 10^{-4}$, $\beta_1=0.9$, $\beta_2=0.999$, decaying exponentially to $5 \times 10^{-5}$ [S1].
*   **Curriculum Learning:** Input images are sorted by timestamp. Images with higher timestamps are incrementally added to the training set to improve convergence [S1].
*   **Batch Sampling:** At each batch, a random set of $N_s$ pixels is sampled from the current time instant's image [S1, S2].

## Subtopics

### T-NeRF
A variant that represents the scene with a 6D input $(x, y, z, \theta, \phi, t)$ directly without considering an intermediate canonical configuration [S1]. It generally produces less satisfying results than D-NeRF because it does not effectively exploit temporal redundancy [S1].

### Neural Volumes (NV)
A method for generating 3D images and videos using deep learning based on representing 3D scenes as a set of volumetric data (e.g., voxels) [S2]. D-NeRF is compared against NV [S2].

### Scene Representation Networks (SRN)
A type of deep learning model used to generate 3D images and videos of scenes, aiming for high-quality consistency with input data [S2]. D-NeRF is compared against SRN [S2].

## Operating characteristics
*   **Complexity:** The method uses two 8-layer MLPs. The computational cost is dominated by the forward pass of these networks for each sample along each ray.
*   **Performance:** On the 'Hell Warrior' scene, D-NeRF achieves MSE $31 \times 10^{-4}$, PSNR 23.19, SSIM 0.93, LPIPS 0.08, compared to NeRF's MSE $44 \times 10^{-3}$, PSNR 13.52, SSIM 0.81, LPIPS 0.25 [S1]. On the 'T-Rex' scene, D-NeRF achieves MSE $5 \times 10^{-4}$, PSNR 32.80, SSIM 0.98, LPIPS 0.03, compared to NeRF's MSE $21 \times 10^{-3}$, PSNR 18.19, SSIM 0.89, LPIPS 0.14 [S1].
*   **Training Time:** Trained for 800k iterations on 400x400 images, batch size 4096 rays, 64 samples per ray, on a single Nvidia GTX 1080 for 2 days [S1].
*   **Strengths:** Can handle non-rigid deformations, articulated motion, and rigid motion from a single view per time instant [S1]. Produces complete 3D meshes as a side product [S1].
*   **Limitations:** Requires a sparse set of images; performance may degrade if the canonical configuration ($t=0$) is not representative or if deformations are extreme relative to the canonical state [G]. Naive extension (T-NeRF) fails to capture temporal redundancy effectively [S1].

## Background
D-NeRF was proposed by Albert Pumarola, Enric Corona, Gerard Pons-Moll, and Francesc Moreno-Noguer [S1]. The method was presented at CVPR 2021 (arXiv:2011.13961v1, Nov 2020) [S1]. It builds upon the Neural Radiance Fields (NeRF) framework [26] and generalizes it to handle dynamic, non-rigid scenes [S1]. The approach is inspired by classical 3D scene flow [44] and aims to exploit temporal redundancy by mapping deformed scenes to a canonical space [S1].
