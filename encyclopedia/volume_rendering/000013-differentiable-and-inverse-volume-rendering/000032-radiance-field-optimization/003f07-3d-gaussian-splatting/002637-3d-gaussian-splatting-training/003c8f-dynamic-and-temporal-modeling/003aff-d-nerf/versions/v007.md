# D-NeRF

Also called: Deformable Neural Radiance Fields, Dynamic-NeRF, Neural Radiance Fields for Dynamic Scenes

## Overview
D-NeRF synthesizes novel views at arbitrary time instants for dynamic scenes with complex non-rigid geometries, optimizing a deformable volumetric function from a sparse set of monocular input images without requiring ground-truth geometry or multi-view stereo data [S1]. Unlike naive extensions of NeRF that map $(x, y, z, t)$ directly to density and radiance, D-NeRF decomposes the learning process into a canonical spatial representation and a time-dependent deformation field, effectively exploiting temporal redundancy to handle rigid, articulated, and non-rigid motions [S1, S3].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A sparse set of $T$ RGB images $\{I_t\}_{t=1}^T$ and their corresponding camera pose matrices $\{T_t\}_{t=1}^T$, where $I_t \in \mathbb{R}^{H \times W \times 3}$ and $T_t \in \mathbb{R}^{4 \times 4}$ (SE(3)). Each time instant $t$ is captured by a single camera view [S1, S2].
*   **Outputs:** Rendered RGB color $C'(p, t)$ for a pixel $p$ at time $t$, given a camera ray defined by origin $o$ and direction $d$.

**Data Structures:**
The model consists of two deep fully connected networks (MLPs) without convolutional layers [S1]:
1.  **Deformation Network $\Psi_t$:** Maps a 3D point $x$ and time $t$ to a displacement vector $\Delta x$.
    *   Input: Encoded spatial coordinates $x$ and time $t$.
    *   Output: Displacement $\Delta x \in \mathbb{R}^3$.
    *   Architecture: 8-layer MLP with ReLU activations. No non-linearity on the output [S1].
2.  **Canonical Network $\Psi_x$:** Regresses volume density $\sigma$ and view-dependent RGB color $c$ from a point in canonical space and viewing direction.
    *   Input: Encoded canonical point $x_{can} = x + \Delta x$ and viewing direction $d$.
    *   Output: Color $c \in \mathbb{R}^3$ and density $\sigma \in \mathbb{R}$.
    *   Architecture: 8-layer MLP with ReLU activations. Final sigmoid non-linearity applied to $c$ and $\sigma$ [S1].

**Positional Encoding:**
Raw coordinates are encoded into a higher-dimensional space using $\gamma(p)$, applied independently to each coordinate component [S1]:
$$ \gamma(p) = \langle (\sin(2^l \pi p), \cos(2^l \pi p)) \rangle_{l=0}^{L-1} $$
*   $L=10$ for spatial coordinates $x$.
*   $L=4$ for viewing direction $d$ and time $t$ [S1].

**Numbered Steps:**
1.  **Canonical Configuration Definition:** Define the canonical scene as the scene state at $t=0$. Enforce that the deformation displacement is zero at this time: $\Psi_t(x, 0) = 0$ [S1]. This interconnects all time instances through a common anchor [S1].
2.  **Ray Sampling:** For a training batch, sample a random set of pixels $\{p_{t,i}\}$ corresponding to rays cast from camera position $T_t$ to pixels $i$ of image $I_t$. For each ray, draw $N$ samples $\{h_n\}_{n=1}^N$ from evenly-spaced ray bins in $[h_n, h_f]$ using stratified sampling [S1].
3.  **Deformation:** For each sample point $x(h) = o + h d$ along the ray at time $t$:
    *   Encode $x(h)$ and $t$ using $\gamma(\cdot)$.
    *   Compute displacement $\Delta x = \Psi_t(x(h), t)$ [S1].
    *   Transform to canonical space: $p(h, t) = x(h) + \Delta x$ [S1].
4.  **Canonical Query:**
    *   Encode $p(h, t)$ and viewing direction $d$ using $\gamma(\cdot)$.
    *   Query the canonical network: $[c(p(h, t), d), \sigma(p(h, t))] = \Psi_x(p(h, t), d)$ [S1].
5.  **Volume Rendering:** Approximate the volume rendering integral via numerical quadrature [S1]:
    $$ C'(p, t) = \sum_{n=1}^{N} T'(h_n, t) \alpha(h_n, t, \delta_n) c(p(h_n, t), d) $$
    Where:
    *   $\delta_n = h_{n+1} - h_n$ is the distance between quadrature points [S1].
    *   $\alpha(h, t, \delta) = 1 - \exp(-\sigma(p(h, t))\delta)$ is the opacity [S1].
    *   $T'(h_n, t) = \exp\left(-\sum_{m=1}^{n-1} \sigma(p(h_m, t))\delta_m\right)$ is the accumulated transmittance [S1].
6.  **Optimization:** Minimize the mean squared error (MSE) between the rendered pixel color $C'(p, t)$ and the ground truth pixel color $\hat{C}(p, t)$:
    $$ \mathcal{L} = \frac{1}{N_s} \sum_{i=1}^{N_s} \|\hat{C}(p_i, t) - C'(p_i, t)\|^2 $$
    where $N_s$ is the number of rays in the batch [S1].

**Pseudocode:**
```python
import math
import torch
import torch.nn as nn
import torch.nn.functional as F

class PositionalEncoding(nn.Module):
    def __init__(self, L):
        super().__init__()
        self.L = L

    def forward(self, x):
        # x shape: (..., 3) or (..., 1)
        # Apply encoding independently to each coordinate
        freq_bands = 2.0 ** torch.linspace(0, self.L - 1, self.L, device=x.device)
        # Expand dimensions for broadcasting
        # x: (..., D), freq_bands: (L,) -> output: (..., D*L*2)
        out = []
        for dim in range(x.shape[-1]):
            x_dim = x[..., dim:dim+1]
            s = torch.sin(x_dim * freq_bands * math.pi)
            c = torch.cos(x_dim * freq_bands * math.pi)
            out.append(s)
            out.append(c)
        return torch.cat(out, dim=-1)

class DeformationNetwork(nn.Module):
    def __init__(self, input_dim_enc, output_dim=3):
        super().__init__()
        layers = []
        current_dim = input_dim_enc
        for _ in range(8):
            layers.append(nn.Linear(current_dim, 256))
            layers.append(nn.ReLU())
            current_dim = 256
        layers.append(nn.Linear(256, output_dim))
        # No non-linearity on output
        self.net = nn.Sequential(*layers)

    def forward(self, x_enc, t_enc):
        # Concatenate encoded spatial and time inputs
        input_enc = torch.cat([x_enc, t_enc], dim=-1)
        return self.net(input_enc)

class CanonicalNetwork(nn.Module):
    def __init__(self, input_dim_enc, dir_dim_enc):
        super().__init__()
        # Input: encoded canonical point + encoded direction
        total_input = input_dim_enc + dir_dim_enc
        layers = []
        current_dim = total_input
        for _ in range(8):
            layers.append(nn.Linear(current_dim, 256))
            layers.append(nn.ReLU())
            current_dim = 256
        layers.append(nn.Linear(256, 4)) # 3 for color, 1 for density
        self.net = nn.Sequential(*layers)

    def forward(self, x_can_enc, d_enc):
        input_enc = torch.cat([x_can_enc, d_enc], dim=-1)
        out = self.net(input_enc)
        c = torch.sigmoid(out[..., :3])
        sigma = torch.sigmoid(out[..., 3:])
        return c, sigma

def render_ray(rays_o, rays_d, t, near, far, N_samples, 
               deform_net, canon_net, pos_enc_x, pos_enc_t, pos_enc_d):
    """
    Render a single ray at time t.
    rays_o: (3,)
    rays_d: (3,)
    t: scalar time
    """
    # 1. Sample points along ray
    # Stratified sampling in [near, far]
    t_vals = torch.linspace(near, far, N_samples)
    # Add jitter for stratified sampling
    jitter = torch.rand_like(t_vals)
    t_samples = t_vals + (t_vals[1] - t_vals[0]) * jitter
    
    # 2. Get 3D points on ray
    pts = rays_o.unsqueeze(0) + t_samples.unsqueeze(1) * rays_d.unsqueeze(0) # (N_samples, 3)
    
    # 3. Encode inputs
    pts_enc = pos_enc_x(pts)
    t_enc = pos_enc_t(torch.tensor([t] * N_samples).unsqueeze(1))
    d_enc = pos_enc_d(rays_d.unsqueeze(0).repeat(N_samples, 1))
    
    # 4. Deformation: Map to canonical space
    # Psi_t: (x, t) -> delta_x
    delta_x = deform_net(pts_enc, t_enc) # (N_samples, 3)
    pts_canonical = pts + delta_x
    
    # 5. Canonical Query: Psi_x: (x_can, d) -> (c, sigma)
    pts_can_enc = pos_enc_x(pts_canonical)
    c, sigma = canon_net(pts_can_enc, d_enc) # (N_samples, 3), (N_samples, 1)
    
    # 6. Volume Rendering
    # Distances between samples
    dists = t_samples[1:] - t_samples[:-1]
    dists = torch.cat([dists, torch.tensor([1e10]).to(dists.device)]) # Last sample distance dummy
    
    # Alpha
    alpha = 1.0 - torch.exp(-sigma.squeeze(-1) * dists) # (N_samples,)
    
    # Transmittance
    transmittance = torch.cumprod(1.0 - alpha + 1e-10, dim=0) # (N_samples,)
    # T_n = prod_{m=1}^{n-1} (1 - alpha_m)
    # torch.cumprod includes current element, so we need to shift or handle index 0
    # Standard NeRF formulation: T_n = exp(-sum_{m=1}^{n-1} sigma_m * delta_m)
    # Using cumulative product of (1-alpha) approximates this if alpha is small, 
    # but exact formula is preferred.
    # Let's use the exact exponential sum for robustness if sigma is large, 
    # but the source uses the product form approximation in Eq 9 context or direct exp sum.
    # Source Eq 9: T'(hn) = exp(-sum sigma * delta).
    # Let's compute weights directly.
    
    weights = alpha * transmittance # This is slightly wrong for standard NeRF weights.
    # Correct weights: w_n = alpha_n * T_n where T_n = prod_{m<n} (1-alpha_m)
    # T_0 = 1.0
    T = torch.ones_like(alpha)
    T[1:] = torch.cumprod(1.0 - alpha[:-1] + 1e-10, dim=0)
    weights = alpha * T
    
    color = torch.sum(weights.unsqueeze(-1) * c, dim=0)
    
    return color

def train_step(batch_rays_o, batch_rays_d, batch_t, batch_gt_color, 
               near, far, N_samples, deform_net, canon_net, optimizer):
    optimizer.zero_grad()
    
    # Render all rays in batch
    # Note: In practice, this is vectorized over the batch dimension
    rendered_colors = []
    for i in range(batch_rays_o.shape[0]):
        c = render_ray(
            batch_rays_o[i], batch_rays_d[i], batch_t[i], 
            near, far, N_samples, 
            deform_net, canon_net, 
            pos_enc_x, pos_enc_t, pos_enc_d
        )
        rendered_colors.append(c)
    
    rendered_colors = torch.stack(rendered_colors) # (Ns, 3)
    
    # Loss
    loss = F.mse_loss(rendered_colors, batch_gt_color)
    loss.backward()
    optimizer.step()
    
    return loss.item()
```

**Parameters:**
*   **Canonical Time:** $t=0$ [S1].
*   **Positional Encoding Depth:** $L=10$ for $x$, $L=4$ for $d$ and $t$ [S1].
*   **Network Depth:** 8 layers for both $\Psi_t$ and $\Psi_x$ [S1].
*   **Training Images:** $400 \times 400$ resolution [S1].
*   **Iterations:** 800,000 [S1].
*   **Batch Size:** $N_s = 4096$ rays [S1].
*   **Samples per Ray:** 64 [S1].
*   **Optimizer:** Adam, learning rate $5 \times 10^{-4}$, $\beta_1=0.9$, $\beta_2=0.999$, exponential decay to $5 \times 10^{-5}$ [S1].
*   **Curriculum Learning:** Input images are sorted by timestamp and added incrementally to improve convergence [S1].

**Edge Cases and Pitfalls:**
*   **Complex Motions:** Deformation fields are difficult to learn when complex scene motions exist, potentially leading to blurry results similar to Neural Volumes [S3].
*   **Topological Changes:** The method assumes continuous deformation fields and cannot handle topological changes (e.g., objects appearing/disappearing) because the deformation field must be continuous [S4].
*   **Single View per Time:** The method is designed for a single view per time instant. Multi-view per time is not required but not explicitly optimized for in the base formulation [S1].

## Subtopics

### [Dynamic NeRF Guided by Projected Colors](8882-dynamic-nerf-guided-by-projected-colors.md)
Replaces explicit temporal coordinate $t$ with multi-view projected color statistics to improve point correspondence estimation during on-the-fly training. Unlike standard D-NeRF which optimizes irregular temporal deformation fields, this approach maps inputs to a "space-color" coordinate system where correspondence is easier to track due to color invariance under motion.

## Operating characteristics
*   **Time Complexity:** Training requires 800k iterations on a single Nvidia GTX 1080, taking approximately 2 days [S1]. Rendering time is not explicitly quantified in milliseconds in the primary source, but inference involves two MLP queries per sample point [S1].
*   **Memory Complexity:** Depends on the MLP sizes (8 layers, 256 hidden units) and the number of samples per ray (64) [S1].
*   **Performance:**
    *   **Hell Warrior:** MSE $31 \times 10^{-4}$, PSNR 23.19, SSIM 0.93, LPIPS 0.08 [S1].
    *   **T-Rex:** MSE $5 \times 10^{-4}$, PSNR 32.80, SSIM 0.98, LPIPS 0.03 [S1].
    *   Compared to naive NeRF (which fails on dynamic scenes), D-NeRF significantly improves metrics (e.g., T-Rex PSNR 18.19 for NeRF vs 32.80 for D-NeRF) [S1].
    *   Compared to T-NeRF (6D input without canonical space), D-NeRF performs better (e.g., Hell Warrior PSNR 20.31 for T-NeRF vs 23.19 for D-NeRF) [S1].
*   **Strengths:** Handles rigid, articulated, and non-rigid motions; works with sparse monocular views; exploits temporal redundancy via canonical space [S1].
*   **Limitations:** Struggles with complex motions leading to blurriness; cannot handle topological changes; requires careful curriculum learning for convergence [S1, S3, S4].

## Background
D-NeRF was proposed by Albert Pumarola, Enric Corona, Gerard Pons-Moll, and Francesc Moreno-Noguer from Institut de Robòtica i Informàtica Industrial (CSIC-UPC) and Max Planck Institute for Informatics [S1]. It was published in 2021 (CVPR 2021) [S1]. The method builds on NeRF [26] and generalizes it to handle non-rigid scenes by decomposing the learning into a canonical scene and a scene flow deformation field, inspired by classical 3D scene flow [S1]. It is used for synthesizing novel views of dynamic scenes in applications such as augmented reality, virtual reality, and 3D content production [S1].
