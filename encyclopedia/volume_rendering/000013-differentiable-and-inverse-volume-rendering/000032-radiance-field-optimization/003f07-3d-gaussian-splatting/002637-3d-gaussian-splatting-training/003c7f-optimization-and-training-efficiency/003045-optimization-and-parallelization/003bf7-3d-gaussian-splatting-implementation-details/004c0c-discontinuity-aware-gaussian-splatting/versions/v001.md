# Discontinuity-aware Gaussian Splatting

Also called: DisC-GS

## Overview
Discontinuity-aware Gaussian Splatting (DisC-GS) is a framework that enables 3D Gaussian Splatting to represent and render sharp boundaries and discontinuities, addressing a key limitation of the original method which assumes smooth, continuous alpha blending [S1]. It distinguishes itself from standard Gaussian Splatting by introducing a "pre-scissoring" step that segments projected Gaussians along boundaries defined by cubic Bézier curves, combined with a Bézier-boundary gradient approximation strategy to maintain differentiability during optimization [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of 3D Gaussians representing the scene, each with center $\mu$, rotation matrix $R$, scale matrix $S$, opacity $\alpha$, and color $c$. For DisC-GS, each Gaussian also includes an additional attribute $c_{curve}$. Camera parameters (viewing matrix $W$, projection matrix $P$).
*   **Output:** A rendered 2D image $C(p)$ for each pixel $p$.

**Data Structures:**
*   **Gaussian Attributes:** Each Gaussian $i$ stores the standard attributes plus $c_{curve} \in \mathbb{R}^{4M \times 2}$.
    *   $M$: User-defined hyperparameter for the number of Bézier curves per Gaussian.
    *   $c_{curve}$: Stores $4M$ points in the Gaussian's local 2D subspace. The subspace is defined by origin $\mu$, x-axis $r_1$ (first column of $R$), and y-axis $r_2$ (second column of $R$). These points serve as control points for $M$ cubic Bézier curves [S1].
*   **Projected Control Points:** $c_{2D\_curve} \in \mathbb{R}^{4M \times 2}$, storing the 3D-to-2D projected control points for the current viewpoint [S1].

**Algorithm Steps:**

1.  **Pre-scissoring Setup (Boundary Representation):**
    For each Gaussian $i$:
    a.  **Local to World Transformation:** Transform the $4M$ control points from the Gaussian's local 2D subspace to 3D world space. For each point index $k \in \{0, \dots, 4M-1\}$:
        $$c_{3D\_curve}[k] = \mu + c_{curve}[k, 0] \times r_1 + c_{curve}[k, 1] \times r_2$$
        Note: $r_1$ and $r_2$ are unit vectors from the rotation matrix, so normalization is omitted [S1].
    b.  **World to Image Projection:** Project the 3D control points onto the image plane:
        $$c_{2D\_curve}[k] = P W c_{3D\_curve}[k]$$
        where $P$ is the projective transformation matrix and $W$ is the viewing transformation matrix [S1].

2.  **Indicator Function Construction:**
    For each pixel $p=(x_p, y_p)$ and each Gaussian $i$, determine if the pixel is "scissored out" (outside the boundary) using an implicit cubic Bézier curve representation.
    a.  **Implicitization:** Convert the parametric cubic Bézier curve defined by four control points $\omega_0, \omega_1, \omega_2, \omega_3$ into an implicit polynomial form:
        $$B_{imp}(x, y) = \gamma_{xxx} x^3 + \gamma_{xxy} x^2 y + \gamma_{xyy} x y^2 + \gamma_{yyy} y^3 + \gamma_{xx} x^2 + \gamma_{xy} xy + \gamma_{yy} y^2 + \gamma_x x + \gamma_y y + \gamma_0 = 0$$
        The coefficients $\gamma$ are computed via $O(1)$ arithmetic operations on the coordinates of the four control points [S1].
    b.  **Single-Curve Indicator:** For a single curve, define the indicator function $g_{sc}$:
        $$g_{sc}(\omega_0, \omega_1, \omega_2, \omega_3; p) = \begin{cases} 1 & \text{if } B_{imp}(x_p, y_p) > 0 \\ 0 & \text{otherwise} \end{cases}$$
        The condition $B_{imp} > 0$ determines if the point is inside the boundary defined by the curve orientation [S1].
    c.  **Multi-Curve Indicator:** For $M$ curves, combine the single-curve indicators using a product (logical AND):
        $$g_i(p) = \prod_{j=0}^{M-1} g_{sc}(c_{2D\_curve}[4j], c_{2D\_curve}[4j+1], c_{2D\_curve}[4j+2], c_{2D\_curve}[4j+3]; p)$$
        If $g_i(p) = 0$, the pixel is outside at least one boundary curve and is "scissored out" [S1].

3.  **Discontinuity-Aware Rendering:**
    Compute the color $C(p)$ using a modified $\alpha$-blending function that incorporates the indicator $g_i(p)$:
    $$C(p) = \sum_{i=1}^{N} c_i \beta_i \prod_{j=1}^{i-1} (1 - \beta_j)$$
    where the effective opacity $\beta_i$ for the $i$-th Gaussian is:
    $$\beta_i = \alpha_i g_i(p) e^{-\frac{1}{2} (p-\mu_i)^T (\Sigma_i^{2D})^{-1} (p-\mu_i)}$$
    Here, $\mu_i$ and $\Sigma_i^{2D}$ are the center and covariance of the projected 2D Gaussian. The term $g_i(p)$ zeros out the contribution of Gaussians where the pixel is scissored out [S1].

4.  **Bézier-Boundary Gradient Approximation (Backpropagation):**
    The indicator function $g(p)$ is piecewise constant, making the forward rendering non-differentiable and gradients zero almost everywhere. To enable learning:
    *   A gradient approximation strategy is applied during backpropagation. While the exact mathematical formulation of the approximation is not detailed in the provided text, the strategy allows gradients to pass through the modified $\alpha$-blending function, enabling the optimization of $c_{curve}$ and other Gaussian attributes [S1].

**Parameters:**
*   $M$: Number of Bézier curves per Gaussian. User-defined hyperparameter [S1].
*   Control Points: 4 points per curve, stored in $c_{curve}$ [S1].

**Edge Cases and Pitfalls:**
*   **Non-differentiability:** The indicator function $g(p)$ is piecewise constant. Naive integration makes the rendering non-differentiable, breaking backpropagation [S1]. The Bézier-boundary gradient approximation strategy is required to mitigate this [S1].
*   **Viewpoint Inconsistency:** Using 3D Gaussians can result in viewpoint inconsistency. For 2D Gaussians, the last column of the scale matrix $S$ must be fixed to a zero vector [S1].
*   **Collinear Control Points:** If the four control points of a Bézier curve are collinear, the curve reduces to a straight line, which is still valid for representing sharp boundaries [S1].

## Operating characteristics
*   **Complexity:** The implicitization of the cubic Bézier curve is $O(1)$ per curve per pixel. The indicator function evaluation is $O(M)$ per Gaussian per pixel. The rendering complexity remains dominated by the sorting and blending of $N$ Gaussians, but with an additional factor of $M$ for boundary checks [S1].
*   **Performance:** The method introduces computational overhead due to the projection of control points and the evaluation of implicit Bézier curves for every pixel and Gaussian. However, it enables the rendering of sharp boundaries which standard Gaussian Splatting fails to capture accurately [S1].
*   **Strengths:** First framework to enable Gaussian Splatting to render discontinuities and boundaries properly. Handles sharp corners and various boundary shapes via cubic Bézier curves [S1].
*   **Limitations:** Requires additional storage for $c_{curve}$ ($4M \times 2$ floats per Gaussian). The gradient approximation is necessary because the forward pass is inherently discontinuous [S1].

## Background
Discontinuity-aware Gaussian Splatting (DisC-GS) was proposed to address the intrinsic limitation of Gaussian Splatting in rendering discontinuities and boundaries accurately [S1]. It builds on the standard 3D Gaussian Splatting pipeline [S1].
