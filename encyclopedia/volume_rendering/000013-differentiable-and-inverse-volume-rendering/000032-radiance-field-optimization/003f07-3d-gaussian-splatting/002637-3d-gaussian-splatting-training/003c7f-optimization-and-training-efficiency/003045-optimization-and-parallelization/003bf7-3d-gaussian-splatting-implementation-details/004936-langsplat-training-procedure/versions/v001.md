# LangSplat Training Procedure

Also called: LangSplat Optimization

## Overview
LangSplat Training Procedure is a method for optimizing 3D Gaussian Splatting scenes to incorporate semantic language features alongside photometric rendering [S1, unofficial]. It extends the standard differentiable rendering pipeline by computing a loss against ground-truth language embeddings (e.g., CLIP features) when enabled, allowing the scene to support semantic queries [S1, unofficial]. It is distinguished from standard 3D Gaussian Splatting training by the conditional inclusion of language feature loss and the consequent disabling of densification and pruning operations during language-aware training [S1, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   Scene representation: A set of 3D Gaussians with parameters (position, covariance, opacity, spherical harmonics coefficients, color).
*   Camera parameters: Viewpoint camera matrices.
*   Ground truth data:
    *   Photometric: Original image pixels.
    *   Semantic (optional): Pre-computed language feature tensors and segmentation maps stored in a directory (`dataset.lf_path`) [S1, unofficial].
*   Hyperparameters: Defined in `opt` and `dataset` namespaces (see Parameters).

**Outputs:**
*   Optimized Gaussian parameters.
*   Rendered image and language features.

### Data Structures
The implementation relies on standard 3D Gaussian Splatting data structures extended with language feature handling:
*   `gaussians`: Object containing Gaussian attributes. Key fields include `max_radii2D` (2D projected radius squared) and methods for densification (`densify_and_prune`, `add_densification_stats`) and opacity management (`reset_opacity`, `oneupSHdegree`) [S1, unofficial].
*   `viewpoint_cam`: Object representing the current camera view. It provides methods to retrieve ground truth images (`original_image.cuda()`) and language features (`get_language_feature`) [S1, unofficial].
*   `render_pkg`: Tuple returned by the render function, containing:
    *   `image`: Rendered RGB image.
    *   `language_feature`: Rendered language feature tensor.
    *   `viewspace_point_tensor`: 3D points in viewspace.
    *   `visibility_filter`: Boolean mask indicating which Gaussians contributed to the image.
    *   `radii`: 2D radii of visible Gaussians [S1, unofficial].

### Parameters
*   `opt.include_feature` (bool): If `True`, trains using language feature loss. If `False`, trains using standard photometric loss [S1, unofficial].
*   `opt.lambda_dssim` (float): Weight for the SSIM component of the photometric loss [S1, unofficial].
*   `opt.densify_until_iter` (int): Iteration number after which densification stops [S1, unofficial].
*   `opt.densify_from_iter` (int): Iteration number after which densification begins [S1, unofficial].
*   `opt.densification_interval` (int): Frequency of densification steps [S1, unofficial].
*   `opt.opacity_reset_interval` (int): Frequency of opacity resets [S1, unofficial].
*   `opt.densify_grad_threshold` (float): Gradient magnitude threshold for densifying Gaussians [S1, unofficial].
*   `dataset.feature_level` (int): Specific level of language feature to use from the dataset [S1, unofficial].
*   `dataset.lf_path` (str): File path to the directory containing language feature data [S1, unofficial].

### Algorithm Steps
1.  **Initialization**: Initialize Gaussians and scene. Load checkpoint if provided. Set background color. Initialize CUDA timing events. Set `first_iter = 0` [S1, unofficial].
2.  **Iteration Loop**: For each iteration:
    a.  **Learning Rate**: Update learning rate schedule.
    b.  **SH Degree**: If `iteration % 1000 == 0`, increment Spherical Harmonics degree using `gaussians.oneupSHdegree()` [S1, unofficial].
    c.  **Camera Selection**: Pick a random camera from the training set.
    d.  **Rendering**: Call `render(viewpoint_cam, gaussians, pipe, background, opt)` to obtain `render_pkg` (image, language_feature, viewspace_points, visibility_filter, radii) [S1, unofficial].
    e.  **Loss Computation**:
        *   If `opt.include_feature` is `True`:
            1.  Retrieve ground truth language feature and mask: `gt_language_feature, language_feature_mask = viewpoint_cam.get_language_feature(language_feature_dir=dataset.lf_path, feature_level=dataset.feature_level)` [S1, unofficial].
            2.  Compute L1 loss between rendered and ground truth features, masked:
                $$L_{l1} = \text{L1Loss}(\text{language\_feature} \odot \text{language\_feature\_mask}, \text{gt\_language\_feature} \odot \text{gt\_language\_feature\_mask})$$
            3.  Set total loss: $L = L_{l1}$ [S1, unofficial].
        *   If `opt.include_feature` is `False`:
            1.  Retrieve ground truth image: `gt_image = viewpoint_cam.original_image.cuda()` [S1, unofficial].
            2.  Compute L1 loss: $L_{l1} = \text{L1Loss}(\text{image}, \text{gt\_image})$ [S1, unofficial].
            3.  Compute SSIM loss: $L_{ssim} = 1 - \text{SSIM}(\text{image}, \text{gt\_image})$ [S1, unofficial].
            4.  Set total loss: $L = (1.0 - \text{opt.lambda\_dssim}) \cdot L_{l1} + \text{opt.lambda\_dssim} \cdot L_{ssim}$ [S1, unofficial].
    f.  **Backpropagation**: Compute gradients and update Gaussian parameters using the optimizer [S1, unofficial].
    g.  **Logging**: Update EMA loss, log metrics, and save checkpoints as required [S1, unofficial].
    h.  **Densification and Pruning**:
        *   **Condition**: This step is **only** performed if `not opt.include_feature` [S1, unofficial].
        *   If `iteration < opt.densify_until_iter`:
            1.  Update max radii: `gaussians.max_radii2D[visibility_filter] = torch.max(gaussians.max_radii2D[visibility_filter], radii[visibility_filter])` [S1, unofficial].
            2.  Accumulate stats: `gaussians.add_densification_stats(viewspace_point_tensor, visibility_filter)` [S1, unofficial].
        *   If `iteration > opt.densify_from_iter` and `iteration % opt.densification_interval == 0`:
            1.  Determine size threshold: `size_threshold = 20` if `iteration > opt.opacity_reset_interval` else `None` [S1, unofficial].
            2.  Execute densification and pruning: `gaussians.densify_and_prune(opt.densify_grad_threshold, 0.005, scene.cameras_extent, size_threshold)` [S1, unofficial].
        *   If `iteration % opt.opacity_reset_interval == 0` or (`dataset.white_background` and `iteration == opt.densify_from_iter`):
            1.  Reset opacity: `gaussians.reset_opacity()` [S1, unofficial].

### Pseudocode

```python
def train_langsplat(gaussians, viewpoint_cam, dataset, opt, pipe, background, optimizer, iteration):
    # 1. Update SH degree every 1000 iterations
    if iteration % 1000 == 0:
        gaussians.oneupSHdegree()

    # 2. Render scene
    render_pkg = render(viewpoint_cam, gaussians, pipe, background, opt)
    image = render_pkg['image']
    language_feature = render_pkg['language_feature']
    viewspace_point_tensor = render_pkg['viewspace_point_tensor']
    visibility_filter = render_pkg['visibility_filter']
    radii = render_pkg['radii']

    # 3. Compute Loss
    if opt.include_feature:
        # Retrieve ground truth language features and mask
        gt_language_feature, language_feature_mask = viewpoint_cam.get_language_feature(
            language_feature_dir=dataset.lf_path,
            feature_level=dataset.feature_level
        )
        # Compute L1 loss on masked features
        Ll1 = l1_loss(
            language_feature * language_feature_mask,
            gt_language_feature * language_feature_mask
        )
        loss = Ll1
    else:
        # Retrieve ground truth image
        gt_image = viewpoint_cam.original_image.cuda()
        # Compute L1 loss
        Ll1 = l1_loss(image, gt_image)
        # Compute SSIM loss
        Lssim = 1.0 - ssim(image, gt_image)
        # Combine losses
        loss = (1.0 - opt.lambda_dssim) * Ll1 + opt.lambda_dssim * Lssim

    # 4. Backpropagate
    loss.backward()
    optimizer.step()
    optimizer.zero_grad()

    # 5. Densification and Pruning (Only if NOT including language feature)
    if not opt.include_feature:
        if iteration < opt.densify_until_iter:
            # Update max radii for visible Gaussians
            gaussians.max_radii2D[visibility_filter] = torch.max(
                gaussians.max_radii2D[visibility_filter],
                radii[visibility_filter]
            )
            # Add densification stats
            gaussians.add_densification_stats(viewspace_point_tensor, visibility_filter)

        if iteration > opt.densify_from_iter and iteration % opt.densification_interval == 0:
            # Determine size threshold
            if iteration > opt.opacity_reset_interval:
                size_threshold = 20
            else:
                size_threshold = None
            
            # Perform densification and pruning
            gaussians.densify_and_prune(
                opt.densify_grad_threshold,
                0.005,
                scene.cameras_extent,
                size_threshold
            )

        # Reset opacity periodically or at start of densification for white backgrounds
        if iteration % opt.opacity_reset_interval == 0 or (dataset.white_background and iteration == opt.densify_from_iter):
            gaussians.reset_opacity()

    return loss
```

### Edge Cases and Pitfalls
*   **Densification Disabled**: When `opt.include_feature` is `True`, densification and pruning are completely skipped. This prevents structural changes to the Gaussian cloud that might disrupt the semantic alignment learned from language features [S1, unofficial].
*   **Checkpoint Loading**: If loading a checkpoint that contains 12 model parameters (indicating language feature support), `opt.include_feature` must be `True`. If it is `False`, `first_iter` is reset to 0, potentially restarting training logic incorrectly [S1, unofficial].
*   **Feature Masking**: The language feature loss requires a valid `language_feature_mask`. If the mask is not correctly aligned with the rendered feature dimensions, the loss calculation will be incorrect or fail [S1, unofficial].

## Operating characteristics

### Time and Memory Complexity
*   **Time**: The core rendering complexity is $O(N)$ where $N$ is the number of Gaussians, similar to standard 3D Gaussian Splatting. The additional cost is the retrieval and L1 computation of language features, which is negligible compared to the rasterization and photometric loss computation [S1, unofficial].
*   **Memory**: Memory usage increases by the storage of language feature tensors per Gaussian and the ground truth feature data. The size depends on the embedding dimension (e.g., 512 for CLIP) and the number of Gaussians [S1, unofficial].

### Strengths and Limitations
*   **Strengths**: Enables semantic understanding and queryable 3D scenes without altering the core rendering pipeline significantly [S1, unofficial].
*   **Limitations**: Densification and pruning are disabled during language-aware training, which may limit the ability to adapt the Gaussian distribution to complex geometries or fine details compared to standard training [S1, unofficial].

### When to Use
*   Use when the goal is to create a 3D scene that supports semantic queries or language-based interaction [S1, unofficial].
*   Do not use if high-fidelity geometric reconstruction via densification is required during the training phase [S1, unofficial].

## Background

### Origin
LangSplat was introduced by Minghan Qin et al. as an extension of 3D Gaussian Splatting to incorporate language features [S1, unofficial].

### History and Development
The method builds upon the 3D Gaussian Splatting framework [9128-3d-gaussian-splatting-implementation-details.md] and integrates pre-trained vision-language models (like CLIP) to embed semantic information into the Gaussian attributes [S1, unofficial].

### Usage
It is used in the LangSplat repository for training scenes with language features [S1, unofficial].
