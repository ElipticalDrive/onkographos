# DARBF-Splatting

Also called: DARB-Splatting, Decaying Anisotropic Radial Basis Functions Splatting

## Overview
DARBF-Splatting is a method that replaces the standard Gaussian reconstruction kernels in 3D Gaussian Splatting with a broader class of non-exponential functions called Decaying Anisotropic Radial Basis Functions (DARBFs) [S1]. It solves the limitation of being restricted to the exponential family by allowing kernels such as half-cosine or inverse multiquadric, which can span larger regions with higher opacity for the same variance, thereby reducing the number of primitives needed [S1]. It sets itself apart from standard 3DGS by generalizing the kernel definition while introducing a correction factor to approximate the closed-form integration advantage of Gaussians, achieving faster training convergence and lower memory usage [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Sparse 3D point cloud from Structure-from-Motion (SfM) (e.g., COLMAP), multi-view images, camera poses.
*   **Outputs:** Optimized scene representation consisting of DARBF primitives, enabling differentiable rasterization and novel view synthesis.

**Data Structures:**
The scene is represented as a set of 3D primitives. Each primitive $i$ is defined by:
1.  **Mean Position:** $\boldsymbol{\mu}_i \in \mathbb{R}^3$.
2.  **Covariance Matrix:** $\boldsymbol{\Sigma}_i \in \mathbb{R}^{3 \times 3}$. This is a symmetric positive-definite matrix defining the anisotropic shape and orientation. In implementation, it is typically parameterized by a rotation matrix $R$ and a scale vector $S$ such that $\boldsymbol{\Sigma} = R S S^T R^T$, then optimized via gradients [S1, Parent].
3.  **Color:** $c_i$ (e.g., spherical harmonics coefficients).
4.  **Opacity:** $\alpha_i$ (scalar).

**The DARBF Kernel:**
Unlike Gaussians which use $e^{-d_M^2/2}$, DARBFs are non-negative functions of the Mahalanobis distance $d_M$ [S1]. The Mahalanobis distance from a point $\mathbf{x}$ to the center $\boldsymbol{\mu}$ with covariance $\boldsymbol{\Sigma}$ is:
$$ d_M(\mathbf{x}; \boldsymbol{\mu}, \boldsymbol{\Sigma}) = [(\mathbf{x} - \boldsymbol{\mu})^T \boldsymbol{\Sigma}^{-1} (\mathbf{x} - \boldsymbol{\mu})]^{\frac{1}{2}} $$
The kernel value $K(d_M)$ determines the weight/opacity contribution. Common variants include:
*   **Half-Cosine:** $K(d_M) = \cos\left(\frac{d_M^2}{\xi}\right)$ for $d_M^2 < \frac{\xi \pi}{2}$, and 0 otherwise, where $\xi > 0$ is a width parameter [S1].
*   **Inverse Multiquadric (Inverse MQ):** A decaying function with a wide spread [S1].
*   **Modified Raised Cosine:** Another variant mentioned in the source [S1].

**Correction Factor ($\psi$):**
Standard Gaussians benefit from a closed-form integration shortcut when projecting from 3D to 2D. Non-exponential functions do not share this property, leading to costly integration if computed naively [S1]. DARBF-Splatting introduces a correction factor $\psi$ to approximate this closure property and preserve computational efficiency [S1].
*   The source evaluates three cases for $\psi$: (1) no correction, (2) matrix $\psi$ from an MLP, (3) scalar $\psi$ precomputed from closed-form regression [S1].
*   The scalar $\psi$ is selected for its computational efficiency [S1].
*   The exact formula for applying $\psi$ to the kernel value or opacity is not explicitly detailed in the provided text, but it is applied as a multiplicative or additive adjustment to the kernel's contribution to match the integrated area/weight of a Gaussian [S1].

**Numbered Steps:**
1.  **Initialization:** Place DARBF primitives at 3D points from the SfM pipeline. Initialize $\boldsymbol{\mu}$, $\boldsymbol{\Sigma}$ (via $R, S$), color, and opacity [S1].
2.  **Projection:** For each camera view, transform the 3D covariance $\boldsymbol{\Sigma}$ to the camera frame. Compute the 2D projected covariance $\boldsymbol{\Sigma}_{2D}$ by skipping the third row and column of the 3D covariance matrix (assuming orthographic or standard perspective projection approximations used in 3DGS) [S1]. This bypasses costly 3D-to-2D integration [S1].
3.  **Splatting:** Project each primitive to the 2D image plane to create a footprint function (splat) [S1].
4.  **Kernel Evaluation:** For each pixel covered by a splat, calculate the Mahalanobis distance $d_M$ from the pixel center to the splat center [S1]. Evaluate the DARBF kernel $K(d_M)$ [S1].
5.  **Correction:** Apply the correction factor $\psi$ to the kernel value or resulting opacity to approximate Gaussian integration properties [S1].
6.  **Rasterization:** Sort splats by depth. Composite colors using alpha blending:
    $$ C = \sum_{i \in N} c_i \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    where $\alpha_i$ is the corrected opacity of the $i$-th splat [S1, Parent].
7.  **Optimization:** Compute loss (e.g., L1, D-SSIM) between rendered and ground truth images. Backpropagate gradients to update $\boldsymbol{\mu}$, $\boldsymbol{\Sigma}$, color, and opacity [S1].

**Pseudocode:**
```python
import numpy as np

def mahalanobis_distance(x, mu, sigma_inv):
    """
    Calculate Mahalanobis distance.
    x: (N, 3) points
    mu: (3,) center
    sigma_inv: (3, 3) inverse covariance
    """
    diff = x - mu
    # (x - mu)^T * Sigma^-1 * (x - mu)
    temp = np.dot(diff, sigma_inv)
    dist_sq = np.sum(temp * diff, axis=1)
    return np.sqrt(np.maximum(dist_sq, 0.0)) # Guard against negative due to precision

def darbf_kernel(d_m, kernel_type='half_cosine', xi=1.0):
    """
    Evaluate DARBF kernel.
    d_m: (N,) Mahalanobis distances
    """
    if kernel_type == 'half_cosine':
        # cos(d_m^2 / xi) for d_m^2 < xi * pi / 2
        threshold = xi * np.pi / 2.0
        d_m_sq = d_m ** 2
        mask = d_m_sq < threshold
        values = np.zeros_like(d_m)
        values[mask] = np.cos(d_m_sq[mask] / xi)
        return values
    elif kernel_type == 'inverse_mq':
        # Example: 1 / (1 + d_m^2)
        return 1.0 / (1.0 + d_m ** 2)
    else:
        raise ValueError("Unsupported kernel type")

def render_darbf_splatting(primitives, camera, correction_factor_psi):
    """
    Simplified rendering step for one pixel.
    primitives: list of dicts with 'mu', 'sigma_inv', 'color', 'opacity', 'kernel_type', 'xi'
    camera: object with projection method
    correction_factor_psi: scalar float
    """
    # 1. Project primitives to 2D
    # In full implementation, this involves Jacobian of projection and covariance transformation
    # Here we assume we have 2D centers and 2D covariance inverses for simplicity of pseudocode
    splats = []
    for prim in primitives:
        # Transform 3D mu to 2D center (u, v)
        center_2d = camera.project(prim['mu'])
        
        # Transform 3D Sigma to 2D Sigma by skipping 3rd row/col
        # Note: This is the shortcut mentioned in [S1]
        sigma_3d = prim['sigma'] # Assume stored as matrix
        sigma_2d = sigma_3d[:2, :2]
        sigma_2d_inv = np.linalg.inv(sigma_2d)
        
        splats.append({
            'center': center_2d,
            'sigma_inv': sigma_2d_inv,
            'color': prim['color'],
            'base_opacity': prim['opacity'],
            'kernel_type': prim['kernel_type'],
            'xi': prim['xi']
        })
    
    # Sort by depth (z)
    splats.sort(key=lambda s: s['depth']) # Assuming depth is computed during projection
    
    # 2. Rasterize
    final_color = np.zeros(3)
    accumulated_alpha = 0.0
    
    for splat in splats:
        # Calculate distance from pixel center to splat center
        # In a real rasterizer, this is done for all pixels in the bounding box
        # Here we simulate for a single pixel at (px, py)
        pixel_pos = np.array([px, py]) # Placeholder for current pixel
        # Note: In 3DGS, d_M is calculated in 2D screen space for the splat
        d_m = mahalanobis_distance(pixel_pos.reshape(1, 2), splat['center'], splat['sigma_inv'])
        
        # Evaluate kernel
        kernel_val = darbf_kernel(d_m, splat['kernel_type'], splat['xi'])
        
        # Apply correction factor and base opacity
        # The source states psi approximates the closure property.
        # Assuming multiplicative correction for opacity contribution
        effective_opacity = splat['base_opacity'] * kernel_val * correction_factor_psi
        
        # Clamp opacity
        effective_opacity = np.clip(effective_opacity, 0.0, 1.0)
        
        # Alpha blending
        if accumulated_alpha >= 1.0:
            break
            
        final_color += splat['color'] * effective_opacity * (1.0 - accumulated_alpha)
        accumulated_alpha += effective_opacity * (1.0 - accumulated_alpha)
        
    return final_color
```

**Parameters:**
*   $\xi$ (width parameter): Controls the support of the half-cosine kernel. Typical value not explicitly given, but Table 2 in [S1] specifies parameters for simulations (e.g., $\beta=2$ for modified half-cosine).
*   $\psi$ (correction factor): Scalar precomputed from closed-form regression. Value not explicitly given in the text, but its inclusion improves metrics (Table 6 in [S1]).

**Edge Cases and Pitfalls:**
*   **Unbounded Functions:** Functions that grow unbounded cause instability and are omitted in favor of decaying functions [S1].
*   **Integration Cost:** Using functions outside the Gaussian family without the correction factor $\psi$ incurs costly integration processes, making them computationally inefficient [S1].
*   **Precision:** The Mahalanobis distance calculation must handle numerical precision issues (e.g., negative values under square root due to floating-point errors) [G].

## Operating characteristics
*   **Time Complexity:** Training convergence is 34% faster than standard 3DGS [S1].
*   **Memory Complexity:** Memory usage is 15% lower than standard 3DGS [S1].
*   **Performance:** Achieves comparable PSNR, SSIM, and LPIPS results to 3DGS [S1].
*   **Strengths:** Faster training, lower memory footprint, ability to use wider-spread kernels (like half-cosine) which reduce the need for multiple splats to achieve the same accumulated value [S1].
*   **Limitations:** Requires a correction factor $\psi$ to approximate Gaussian integration, which adds complexity to the kernel definition. The exact optimal value of $\psi$ depends on the kernel type and scene [S1].
*   **When to use:** When computational savings (training time and memory) are critical, and comparable visual quality is acceptable. Particularly useful in repetitive industrial applications [S1].
*   **When not to use:** If the highest possible peak signal-to-noise ratio (PSNR) is required and the slight quality trade-off (if any) is unacceptable, or if the overhead of tuning $\psi$ is prohibitive.

## Background
DARBF-Splatting was introduced by Hashiru Pramuditha, Vinasirajan Viruthshaan, Vishagar Arunan, Saeedha Nazar, Sameera Ramasinghe, Simon Lucey, and Ranga Rodrigo from the University of Moratuwa and University of Adelaide [S1]. The paper "DARB-Splatting: Generalizing Splatting with Decaying Anisotropic Radial Basis Functions" was published in 2026 (WACV) [S1]. It addresses the limitation of 3D Gaussian Splatting (3DGS) [11] being restricted to the exponential family of functions, exploring non-exponential kernels like half-cosine and inverse multiquadric [S1].
