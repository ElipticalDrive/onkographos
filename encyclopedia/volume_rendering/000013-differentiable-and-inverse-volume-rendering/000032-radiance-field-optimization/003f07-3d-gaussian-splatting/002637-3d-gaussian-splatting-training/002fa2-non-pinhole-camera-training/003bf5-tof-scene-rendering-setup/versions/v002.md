# ToF Scene Rendering Setup

Also called: ToF Gaussian Splatting Setup, ToF render

## Overview
This method configures the rendering pipeline for Time-of-Flight (ToF) cameras within a 3D Gaussian Splatting framework, enabling the simultaneous optimization of color and ToF data (phasors, depth, amplitude) [S1, unofficial]. It differs from standard RGB-only splatting by maintaining separate rasterization settings for color and ToF views, handling multi-modal Gaussian attributes (such as phasor features), and supporting dynamic scene decomposition via motion masks [S1, unofficial].

## How it works
The setup initializes CUDA tensors for gradient tracking, computes camera projection parameters for both RGB and ToF sensors, and prepares Gaussian attributes for static and dynamic regions before invoking the respective rasterizers [S1, unofficial].

### Inputs and Outputs
**Inputs:**
- `pc`: GaussianModel instance containing attributes `xyz`, `opacity`, `scaling`, `rotation`, `features_color`, `features_phasor`, and `use_view_dependent_phase` [S1, unofficial].
- `viewpoint_camera`: Object containing `FoVx`, `FoVy`, `FoVx_tof`, `FoVy_tof`, `world_view_transform`, `full_proj_transform`, `camera_center`, `tof_image_height`, `tof_image_width`, and `depth_range` [S1, unofficial].
- `opt`: Optimization configuration containing `optimize_phase_offset` and `optimize_dc_offset` [S1, unofficial].
- `render_regions`: List of strings indicating which parts of the scene to render (e.g., `['static', 'dynamic']`) [S1, unofficial].
- `motion_mask`: Boolean tensor identifying dynamic Gaussians [S1, unofficial].

**Outputs:**
- `color_image`: Rendered RGB image [S1, unofficial].
- `tof_data`: Rendered ToF data including phasor, depth, pixel indices, and distribution [S1, unofficial].
- `screenspace_points`: Tensor storing gradients of 2D means [S1, unofficial].

### Data Structures
1.  **RasterizationSettings**:
    -   Fields: `image_height`, `image_width`, `tanfovx`, `tanfovy`, `bg`, `scale_modifier`, `viewmatrix`, `projmatrix`, `sh_degree`, `campos`, `prefiltered`, `debug`, `near_n`, `far_n` [S1, unofficial].
    -   ToF-specific fields: `depth_range`, `use_view_dependent_phase`, `optimize_phase_offset`, `optimize_dc_offset` [S1, unofficial].
2.  **Gaussian Attributes Tensors** (CUDA, `requires_grad=True`):
    -   `means3D`: Shape $(N, 3)$ [S1, unofficial].
    -   `means2D`: Shape $(N, 2)$ [S1, unofficial].
    -   `opacity`: Shape $(N, 1)$ [S1, unofficial].
    -   `scales`: Shape $(N, 3)$ [S1, unofficial].
    -   `rotations`: Shape $(N, 4)$ (quaternions) [S1, unofficial].
    -   `shs`: Shape $(N, K, 3)$ (Spherical Harmonics coefficients for color) [S1, unofficial].
    -   `shs_p`: Shape $(N, K, P)$ (Spherical Harmonics coefficients for phasor/ToF) [S1, unofficial].
    -   `screenspace_points`: Shape $(N, 2)$, initialized to zero, with `retain_grad()` called [S1, unofficial].

### Steps
1.  **Initialize Gradient Tensors**: Create `screenspace_points` on CUDA with `requires_grad=True` and call `retain_grad()` to preserve gradients for 2D mean updates [S1, unofficial].
2.  **Compute Field of View Tangents**: Calculate $\tan(\text{FoV}_x)$ and $\tan(\text{FoV}_y)$ for the RGB camera:
    $$
    \text{tanfovx} = \tan(\text{viewpoint\_camera.FoVx})
    $$
    $$
    \text{tanfovy} = \tan(\text{viewpoint\_camera.FoVy})
    $$
    [S1, unofficial]
3.  **Configure RGB Rasterization Settings**: Create `RasterizationSettings` for color using `image_height`, `image_width`, `tanfovx`, `tanfovy`, `bg`, `scale_modifier`, `viewmatrix` (`world_view_transform`), `projmatrix` (`full_proj_transform`), `sh_degree`, `campos` (`camera_center`), `prefiltered=False`, `debug=False`, `near_n` (`znear`), and `far_n` (`zfar`) [S1, unofficial].
4.  **Configure ToF Rasterization Settings** (if `viewpoint_camera.FoVx_tof` is not None): Create `RasterizationSettings` for ToF using `image_height` (`tof_image_height`), `image_width` (`tof_image_width`), `tanfovx` ($\tan(\text{viewpoint\_camera.FoVx\_tof})$), `tanfovy` ($\tan(\text{viewpoint\_camera.FoVy\_tof})$), `bg`, `scale_modifier`, `viewmatrix` (`world_view_transform_tof`), `projmatrix` (`full_proj_transform_tof`), `campos` (`camera_center_tof`), `prefiltered=False`, `debug=False`, `near_n` (`znear`), `far_n` (`zfar`), `depth_range` (`viewpoint_camera.depth_range.item()`), `use_view_dependent_phase` (`pc.use_view_dependent_phase`), `optimize_phase_offset` (`opt.optimize_phase_offset`), and `optimize_dc_offset` (`opt.optimize_dc_offset`) [S1, unofficial].
5.  **Initialize Gaussian Attribute Tensors**: Create zero tensors on CUDA for `means3D`, `means2D`, `opacity`, `scales`, `rotations`, `shs`, and `shs_p` matching the shapes of the corresponding `pc` attributes [S1, unofficial].
6.  **Populate Static Attributes**: If `'static'` is in `render_regions`, copy `pc.xyz`, `pc.opacity`, `pc.scaling`, `pc.rotation`, `pc.features_color`, and `pc.features_phasor` to the zero tensors, excluding Gaussians marked by `motion_mask` [S1, unofficial].
7.  **Populate Dynamic Attributes**: If `'dynamic'` is in `render_regions`, copy base attributes from `pc` and apply differentials: `means3D` adds `d_xyz`, `rotations` apply `rotation_activation` to `(_rotation + d_rot)`, `shs` adds `d_sh`, and `shs_p` adds `d_sh_p` [S1, unofficial].
8.  **Render Color Image**: Call the color rasterizer with `means3D`, `means2D`, `shs`, `shs_p`, `opacity`, `scales`, `rotations`, and `cov3D_precomp=None` [S1, unofficial].
9.  **Render ToF Data**: Call the ToF rasterizer with the same Gaussian attributes to produce phasor, depth, pixel, and distribution outputs [S1, unofficial].

### Pseudocode
```python
import torch
import math
import dataclasses

@dataclasses.dataclass
class RasterizationSettings:
    image_height: int
    image_width: int
    tanfovx: float
    tanfovy: float
    bg: torch.Tensor
    scale_modifier: float
    viewmatrix: torch.Tensor
    projmatrix: torch.Tensor
    sh_degree: int
    campos: torch.Tensor
    prefiltered: bool
    debug: bool
    near_n: float
    far_n: float
    depth_range: float = None
    use_view_dependent_phase: bool = False
    optimize_phase_offset: bool = False
    optimize_dc_offset: bool = False

def rotation_activation(q: torch.Tensor) -> torch.Tensor:
    """Normalize quaternions to unit length [G]."""
    return q / torch.norm(q, dim=-1, keepdim=True)

def rasterize_color(settings: RasterizationSettings, means3D, means2D, shs, shs_p, opacity, scales, rotations, cov3D_precomp):
    """Performs standard color rasterization using the provided settings and attributes."""
    # Standard rasterization step [S1, unofficial]
    return torch.zeros(settings.image_height, settings.image_width, 3, device='cuda')

def rasterize_tof(settings: RasterizationSettings, means3D, means2D, shs, shs_p, opacity, scales, rotations, cov3D_precomp):
    """Performs standard ToF rasterization using the provided settings and attributes."""
    # Standard rasterization step [S1, unofficial]
    return torch.zeros(settings.image_height, settings.image_width, 4, device='cuda')

def setup_tof_rendering(pc, viewpoint_camera, opt, render_regions, motion_mask):
    # Step 1: Initialize gradient tensors
    screenspace_points = torch.zeros(pc.xyz.shape[0], 2, device='cuda', requires_grad=True)
    screenspace_points.retain_grad()

    # Step 2: Compute FoV tangents for RGB
    tanfovx = math.tan(viewpoint_camera.FoVx)
    tanfovy = math.tan(viewpoint_camera.FoVy)

    # Step 3: Configure RGB Rasterization Settings
    rgb_settings = RasterizationSettings(
        image_height=viewpoint_camera.image_height,
        image_width=viewpoint_camera.image_width,
        tanfovx=tanfovx,
        tanfovy=tanfovy,
        bg=viewpoint_camera.bg,
        scale_modifier=viewpoint_camera.scale_modifier,
        viewmatrix=viewpoint_camera.world_view_transform,
        projmatrix=viewpoint_camera.full_proj_transform,
        sh_degree=pc.active_sh_degree,
        campos=viewpoint_camera.camera_center,
        prefiltered=False,
        debug=False,
        near_n=viewpoint_camera.znear,
        far_n=viewpoint_camera.zfar
    )

    # Step 4: Configure ToF Rasterization Settings
    tof_settings = None
    if viewpoint_camera.FoVx_tof is not None:
        tof_settings = RasterizationSettings(
            image_height=viewpoint_camera.tof_image_height,
            image_width=viewpoint_camera.tof_image_width,
            tanfovx=math.tan(viewpoint_camera.FoVx_tof),
            tanfovy=math.tan(viewpoint_camera.FoVy_tof),
            bg=viewpoint_camera.bg,
            scale_modifier=viewpoint_camera.scale_modifier,
            viewmatrix=viewpoint_camera.world_view_transform_tof,
            projmatrix=viewpoint_camera.full_proj_transform_tof,
            sh_degree=pc.active_sh_degree,
            campos=viewpoint_camera.camera_center_tof,
            prefiltered=False,
            debug=False,
            near_n=viewpoint_camera.znear,
            far_n=viewpoint_camera.zfar,
            depth_range=viewpoint_camera.depth_range.item(),
            use_view_dependent_phase=pc.use_view_dependent_phase,
            optimize_phase_offset=opt.optimize_phase_offset,
            optimize_dc_offset=opt.optimize_dc_offset
        )

    # Step 5: Initialize Gaussian Attribute Tensors
    N = pc.xyz.shape[0]
    means3D = torch.zeros(N, 3, device='cuda', requires_grad=True)
    means2D = torch.zeros(N, 2, device='cuda', requires_grad=True)
    opacity = torch.zeros(N, 1, device='cuda', requires_grad=True)
    scales = torch.zeros(N, 3, device='cuda', requires_grad=True)
    rotations = torch.zeros(N, 4, device='cuda', requires_grad=True)
    shs = torch.zeros(N, pc.active_sh_degree + 1, 3, device='cuda', requires_grad=True)
    shs_p = torch.zeros(N, pc.active_sh_degree + 1, pc.phasor_dim, device='cuda', requires_grad=True)

    # Step 6: Populate Static Attributes
    if 'static' in render_regions:
        static_mask = ~motion_mask
        means3D[static_mask] = pc.xyz[static_mask]
        opacity[static_mask] = pc.opacity[static_mask]
        scales[static_mask] = pc.scaling[static_mask]
        rotations[static_mask] = pc.rotation[static_mask]
        shs[static_mask] = pc.features_color[static_mask]
        shs_p[static_mask] = pc.features_phasor[static_mask]

    # Step 7: Populate Dynamic Attributes
    if 'dynamic' in render_regions:
        dynamic_mask = motion_mask
        # Base copy
        means3D[dynamic_mask] = pc.xyz[dynamic_mask]
        opacity[dynamic_mask] = pc.opacity[dynamic_mask]
        scales[dynamic_mask] = pc.scaling[dynamic_mask]
        rotations[dynamic_mask] = pc.rotation[dynamic_mask]
        shs[dynamic_mask] = pc.features_color[dynamic_mask]
        shs_p[dynamic_mask] = pc.features_phasor[dynamic_mask]
        
        # Apply differentials
        means3D[dynamic_mask] += pc.d_xyz[dynamic_mask]
        rotations[dynamic_mask] = rotation_activation(pc.rotation[dynamic_mask] + pc.d_rot[dynamic_mask])
        shs[dynamic_mask] += pc.d_sh[dynamic_mask]
        shs_p[dynamic_mask] += pc.d_sh_p[dynamic_mask]

    # Step 8: Render Color Image
    color_image = rasterize_color(
        settings=rgb_settings,
        means3D=means3D, means2D=means2D, shs=shs, shs_p=shs_p,
        opacity=opacity, scales=scales, rotations=rotations, cov3D_precomp=None
    )

    # Step 9: Render ToF Data
    tof_data = rasterize_tof(
        settings=tof_settings,
        means3D=means3D, means2D=means2D, shs=shs, shs_p=shs_p,
        opacity=opacity, scales=scales, rotations=rotations, cov3D_precomp=None
    )

    return color_image, tof_data, screenspace_points
```

### Parameters and Edge Cases
-   **Parameters**: `render_regions` controls which Gaussians are active, `motion_mask` distinguishes static from dynamic Gaussians, and `depth_range` limits ToF raycasting [S1, unofficial].
-   **Edge Cases**: If `viewpoint_camera.FoVx_tof` is `None`, ToF settings are skipped [S1, unofficial]. If `render_regions` is empty, no attributes are copied, resulting in empty renders [S1, unofficial]. Precision issues may arise in `rotation_activation` if quaternions are not normalized after adding differentials [G].

## Background
This method is part of the Gaussian Splatting framework extended for Time-of-Flight cameras, as implemented in the `gftorf` project [S1, unofficial]. It builds on [Non-Pinhole Camera Training](6088-non-pinhole-camera-training.md) by adding specific support for ToF sensor characteristics [S1, unofficial].
