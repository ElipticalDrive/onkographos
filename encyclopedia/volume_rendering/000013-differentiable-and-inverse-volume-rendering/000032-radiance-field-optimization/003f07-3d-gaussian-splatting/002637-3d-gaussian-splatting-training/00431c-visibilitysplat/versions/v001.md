# VisibilitySplat

Also called: VisibilitySplat: Ray-Traced Occlusion for Relighting with 3D Gaussian Splatting

## Overview
VisibilitySplat is a two-stage inverse rendering pipeline for 3D Gaussian Splatting (3DGS) that augments the standard rasterized pipeline with a sparse visibility oracle to estimate transmittance-weighted occlusion for Gaussian primitives from sampled lighting directions, enabling material and light decomposition [S1]. It addresses the limitation of standard 3DGS rasterization, which provides limited visibility information regarding cast shadows and mutual occlusion, by integrating a BVH-accelerated point-based ray tracer [S1]. Unlike NeRF-based methods that use implicit volumetric formulations, VisibilitySplat uses explicit point primitives via differentiable rasterization for real-time rendering while providing robust visibility signals for stabilizing material-light disentanglement under unknown illumination [S1].

## How it works
VisibilitySplat operates in two stages: pretraining the 3D Gaussian point cloud with standard attributes and depth-derived normals, followed by the addition of a sparse visibility oracle for joint optimization of material parameters and an HDR environment map [S1].

### Inputs and Outputs
**Inputs:**
- Multi-view images of the scene.
- Initial camera poses and intrinsics.

**Outputs:**
- Optimized 3D Gaussian point cloud with parameters $G_i$.
- Material parameters (diffuse/specular coefficients) for each Gaussian.
- A compact high-dynamic-range (HDR) environment map for relighting.

### Data Structures
**Gaussian Primitive $G_i$:**
Each Gaussian is defined by the parameter set $G_i = (\mu_i, \Sigma_i, \alpha_i, c_i)$ [S1]:
- $\mu_i \in \mathbb{R}^3$: Position (mean).
- $\Sigma_i \in \mathbb{R}^{3 \times 3}$: Covariance matrix encoding the ellipsoidal footprint.
- $\alpha_i$: Opacity.
- $c_i$: Color, stored as spherical harmonic (SH) coefficients.

**Covariance Decomposition:**
The covariance matrix is decomposed into a scaling matrix $S_i$ and a rotation matrix $R_i$ constructed from a unit quaternion $q$ [S1]:
$$ \Sigma_i = R_i S_i S_i^T R_i^T $$
where $S_i = \text{diag}(s_x, s_y, s_z)$ is the scaling matrix.

**Screen-Space Projection:**
Given the extrinsic camera matrix $T$ and intrinsic camera matrix $K$, the screen-space mean $\mu'_i$ and covariance $\Sigma'$ are computed as [S1]:
$$ \mu'_i = K T [\mu_i, 1]^T $$
$$ \Sigma' = J T \Sigma_i T^T J^T $$
where $J$ is the Jacobian matrix of the affine approximation of the perspective projection.

**Splat Weight:**
The weight $g_i$ for a Gaussian at pixel $u$ is defined as $g_i \equiv g_i(u | \mu'_i, \Sigma'_i)$, derived from the Gaussian function [S1]:
$$ g_i(x) = e^{-\frac{1}{2} (x-\mu'_i)^T (\Sigma')^{-1} (x-\mu'_i)} $$

### Numbered Steps

**Stage 1: Pretraining**
1.  **Initialize Gaussians:** Initialize the 3D Gaussian point cloud with standard 3DGS attributes.
2.  **Depth Estimation:** Render depth by linearly accumulating depth samples $z_i$ and normalizing by accumulated weight $W$ [S1]:
    $$ z_E = \frac{\sum_{i \in N} w_i z_i}{W} $$
    where $W = \sum_{i \in N} w_i$ and $w_i = T_i g_i \alpha_i$. Here, $T_i$ denotes the accumulated transmittance, defined as $T_i = \prod_{j=1}^{i-1} (1 - g_j \alpha_j)$ [S1].
3.  **Normal Estimation:** Assign each Gaussian $i$ a learnable unit normal $n_i$. Compute per-pixel predictions $\hat{n}$ using splatting weights $w_i$ [S1]:
    $$ \tilde{n} = \frac{\sum_{i=1}^N w_i n_i}{\sum_{i=1}^N w_i + \epsilon_n} $$
    $$ \hat{n} = \frac{\tilde{n}}{\|\tilde{n}\|_2 + \epsilon_n} $$
    where $\epsilon_n$ is a small constant for numerical stability.
4.  **Optimize Geometry:** Optimize $\mu_i, \Sigma_i, \alpha_i, c_i$ and $n_i$ using standard 3DGS training objectives until convergence.

**Stage 2: Inverse Rendering with Visibility Oracle**
1.  **Construct BVH:** Build a Bounding Volume Hierarchy (BVH) over the optimized Gaussian primitives to accelerate ray tracing [S1].
2.  **Define PBR Model:** Adopt a reduced principled microfacet model from the Disney family [S1]. Remove the metallic degree of freedom and fix the base reflectance $F_0 = 0.04$ for dielectric materials to reduce learnable appearance parameters [S1]. The specular BRDF component is [S1]:
    $$ f_{spec} = \frac{D(h)G(\omega_i, \omega_o)F(\omega_o \cdot h; F_0 = 0.04)}{4(n \cdot \omega_i)(n \cdot \omega_o)} $$
    where $D$ is the normal-distribution function, $G$ is the masking-shadowing term, and $F$ is the Fresnel term (Schlick).
3.  **Sparse Visibility Oracle:** For each lighting direction $\omega_i$ sampled during optimization, query the BVH-accelerated point-based ray tracer to compute transmittance-weighted visibility $V(x, \omega_i)$ for the Gaussians [S1]. This oracle estimates occlusion explicitly, unlike screen-space alpha compositing.
4.  **Surface Rendering Equation:** Compute the outgoing radiance $L_o$ using the surface rendering equation with geometric visibility [S1]:
    $$ L_o(x, \omega_o) = \int_{\Omega} f_r(x, \omega_i, \omega_o) L_i(x, \omega_i) V(x, \omega_i) (n \cdot \omega_i) d\omega_i $$
    where $x$ is the shaded point, $\omega_o$ is the outgoing view direction, $\omega_i$ is the incident lighting direction, $f_r$ is the BRDF ($f_r = f_{diff} + f_{spec}$), $L_i$ is the incident radiance from the environment map, and $V \in [0, 1]$ is the visibility/transmittance term.
5.  **Joint Optimization:** Optimize material parameters (diffuse/specular coefficients) and the compact HDR environment map $L_i$ jointly using the visibility oracle and the PBR formulation [S1]. The environment map parameterization is compact to account for the limited recoverable illumination bandwidth due to the BRDF's angular low-pass filtering effect [S1].

# VisibilitySplat Implementation Logic

class GaussianPrimitive:
    def __init__(self, mu, s, q, alpha, c, n):
        self.mu = mu          # Position (3,)
        self.s = s            # Scaling (3,)
        self.q = q            # Rotation quaternion (4,)
        self.alpha = alpha    # Opacity (scalar)
        self.c = c            # Color SH coefficients
        self.n = n            # Learnable unit normal (3,)
        
    def get_covariance(self):
        # Sigma = R S S^T R^T
        R = quaternion_to_rotation_matrix(self.q)
        S = diag(self.s)
        return R @ (S @ S.T) @ R.T

class VisibilitySplat:
    def __init__(self, gaussians, camera_intrinsics, camera_extrinsics):
        self.gaussians = gaussians
        self.K = camera_intrinsics
        self.T = camera_extrinsics
        self.bvh = None
        self.env_map = None
        self.material_params = None

    def stage_1_pretrain(self):
        """
        Stage 1: Pretrain 3DGS attributes and normals.
        """
        for epoch in range(num_epochs_stage1):
            for image, pose in training_data:
                # Project Gaussians to screen space
                projected_gaussians = []
                for g in self.gaussians:
                    mu_prime = self.K @ self.T @ np.append(g.mu, 1)
                    Sigma = g.get_covariance()
                    J = jacobian_affine_perspective_projection(self.T)
                    Sigma_prime = J @ self.T @ Sigma @ self.T.T @ J.T
                    projected_gaussians.append({
                        'mu_prime': mu_prime,
                        'Sigma_prime': Sigma_prime,
                        'alpha': g.alpha,
                        'n': g.n,
                        'c': g.c
                    })
                
                # Render Depth
                # Sort Gaussians front-to-back
                sorted_gaussians = sort_front_to_back(projected_gaussians, pose)
                accumulated_transmittance = 1.0
                depth_sum = 0.0
                weight_sum = 0.0
                
                for g in sorted_gaussians:
                    # Compute splat weight g_i at pixel
                    g_i = compute_gaussian_weight(g['mu_prime'], g['Sigma_prime'], pixel_coord)
                    w_i = accumulated_transmittance * g_i * g['alpha']
                    
                    # Accumulate depth
                    depth_sum += w_i * g.depth_sample
                    weight_sum += w_i
                    accumulated_transmittance *= (1 - g_i * g['alpha'])
                
                z_E = depth_sum / (weight_sum + epsilon)
                
                # Render Normal
                n_tilde = np.zeros(3)
                w_sum = 0.0
                for g in sorted_gaussians:
                    g_i = compute_gaussian_weight(g['mu_prime'], g['Sigma_prime'], pixel_coord)
                    w_i = accumulated_transmittance * g_i * g['alpha'] # Note: accumulated_transmittance here is per-pixel specific in full impl
                    n_tilde += w_i * g['n']
                    w_sum += w_i
                
                n_hat = n_tilde / (np.linalg.norm(n_tilde) + epsilon)
                
                # Compute Loss (Depth + Color) and Backpropagate
                loss = compute_loss(rendered_color, rendered_depth, gt_image, gt_depth)
                optimize_gaussians(loss)

    def stage_2_inverse_rendering(self):
        """
        Stage 2: Add visibility oracle and optimize materials/light.
        """
        # Build BVH for ray tracing
        self.bvh = build_bvh(self.gaussians)
        
        # Initialize environment map and material parameters
        self.env_map = init_compact_env_map()
        self.material_params = init_material_params()
        
        for epoch in range(num_epochs_stage2):
            for image, pose in training_data:
                # Sample lighting directions omega_i
                light_directions = sample_lighting_directions()
                
                rendered_colors = []
                for pixel in pixels:
                    # Get surface point x, normal n, view direction omega_o from Stage 1 geometry
                    x, n, omega_o = get_surface_info(pixel, pose)
                    
                    radiance = 0.0
                    for omega_i in light_directions:
                        # Query Visibility Oracle
                        # V(x, omega_i) is transmittance-weighted occlusion
                        V = query_visibility_oracle(self.bvh, x, omega_i)
                        
                        # Evaluate BRDF
                        h = normalize(omega_i + omega_o)
                        f_spec = compute_specular_brdf(n, omega_i, omega_o, h, F0=0.04)
                        f_diff = compute_diffuse_brdf(material_params)
                        f_r = f_diff + f_spec
                        
                        # Evaluate Environment Map
                        L_i = sample_env_map(self.env_map, omega_i)
                        
                        # Integrate
                        radiance += f_r * L_i * V * max(dot(n, omega_i), 0)
                    
                    rendered_colors.append(radiance)
                
                # Compute Loss and Backpropagate
                loss = compute_loss(rendered_colors, gt_image)
                optimize_materials_and_env_map(loss)

    def query_visibility_oracle(self, bvh, origin, direction):
        """
        Sparse visibility oracle using BVH-accelerated point-based ray tracing.
        Returns transmittance-weighted visibility V in [0, 1].
        """
        # Ray trace through the BVH to find occluding Gaussians
        # This is a sparse query, not full rasterization
        occlusion = compute_occlusion_via_bvh(bvh, origin, direction)
        return 1.0 - occlusion

### Parameters
- **Base Reflectance $F_0$:** Fixed to $0.04$ for dielectric materials [S1].
- **Metallic Degree of Freedom:** Removed from the Disney principled microfacet model [S1].
- **Environment Map:** Compact parameterization used to limit illumination bandwidth [S1].
- **$\epsilon_n$:** Small constant for numerical stability in normal estimation [S1].

### Edge Cases and Pitfalls
- **Normal Noise:** Purely gradient-based normals derived from rendered depth are sensitive to noise and lack multi-view consistency. This is handled by assigning each Gaussian a learnable unit normal and computing per-pixel predictions via splatting weights [S1].
- **Underconstrained Inverse Problem:** The inverse problem is underconstrained. This is handled by fixing $F_0 = 0.04$ and removing the metallic degree of freedom to reduce the number of learnable appearance parameters, improving stability [S1].
- **Visibility Signal Strength:** Screen-space alpha compositing provides limited visibility information about cast shadows and mutual occlusion. The sparse visibility oracle is crucial for robustly constraining shadows [S1].

## Operating characteristics
- **Time Complexity:** The method retains the training efficiency of the original 3DGS loop for the forward rendering pass [S1]. The visibility oracle is queried sparsely within the inverse-rendering objectives, avoiding the cost of full ray tracing for every pixel [S1].
- **Memory Complexity:** Uses explicit point primitives, which are more memory-efficient than implicit volumetric NeRF formulations [S1]. The BVH structure adds overhead but is necessary for the sparse visibility queries [S1].
- **Performance:** Enables real-time rendering and practical tooling compatibility, unlike costly NeRF-based methods [S1].
- **Strengths:** Explicit visibility modeling for relighting, material and light decomposition, real-time rendering capability, robust visibility signals for shadow estimation.
- **Limitations:** The inverse problem remains underconstrained without the simplifications (fixed $F_0$, no metallicity) [S1]. The visibility oracle is sparse, which may limit the accuracy of complex indirect lighting effects compared to full path tracing.

## Background
VisibilitySplat was introduced by Sven Kluge and Oliver Staadt from the University of Rostock [S1]. It addresses the challenge of inverse rendering with 3D Gaussian Splatting by introducing explicit visibility modeling. The work builds upon previous 3DGS-based inverse rendering systems like GS-IR and GIR, which attach BRDF parameters to Gaussians but may lack robust visibility estimation [S1]. It also contrasts with NeRF-based inverse rendering methods like NeRFactor and TensoIR, which use implicit volumetric formulations [S1]. The method was published in the Computer Science Research Notes (CSRN) in 2026 [S1].
