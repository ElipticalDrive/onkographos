# Gaussian Conditional Probability Formulation

Also called: Unnormalized 4D Gaussian probability distribution

## Overview
This method treats the unnormalized 4D Gaussian primitive as a special probability distribution over spatial coordinates $(u, v)$ and time $t$, enabling the factorization of the joint distribution into a temporal marginal and a conditional spatial component [S1, unofficial]. This formulation allows for the efficient computation of view-specific or time-specific Gaussians by conditioning on non-spatial dimensions, which is foundational for dynamic scene representation in 4D Gaussian Splatting [S1, S2, unofficial]. It sets apart from static 3D Gaussian Splatting by explicitly modeling temporal dependencies through conditional covariance and mean adjustments [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 4D Gaussian defined by mean $\boldsymbol{\mu} = [\boldsymbol{\mu}_{uv}, \mu_t]^\top$ and covariance $\boldsymbol{\Sigma} \in \mathbb{R}^{3 \times 3}$, where $\boldsymbol{\mu}_{uv} \in \mathbb{R}^2$ and $\mu_t \in \mathbb{R}$. The covariance is partitioned into blocks: $\boldsymbol{\Sigma}_{uv} \in \mathbb{R}^{2 \times 2}$, $\Sigma_t \in \mathbb{R}$, and $\boldsymbol{\Sigma}_{uv,t} \in \mathbb{R}^{2 \times 1}$ (with $\boldsymbol{\Sigma}_{t,uv} = \boldsymbol{\Sigma}_{uv,t}^\top$) [S1, unofficial].
*   **Output:** The conditional spatial distribution $p(u, v|t)$ and its parameters $\boldsymbol{\mu}_{uv|t}$ and $\boldsymbol{\Sigma}_{uv|t}$ for a given query time $t$ [S1, unofficial].

**Data Structures:**
The Gaussian is stored as a set of parameters:
1.  $\boldsymbol{\mu}_{uv}$: 2D vector (spatial mean).
2.  $\mu_t$: Scalar (temporal mean).
3.  $\boldsymbol{\Sigma}_{uv}$: $2 \times 2$ symmetric matrix (spatial covariance).
4.  $\Sigma_t$: Scalar (temporal variance).
5.  $\boldsymbol{\Sigma}_{uv,t}$: $2 \times 1$ vector (spatial-temporal cross-covariance).
*Note: The full $3 \times 3$ covariance $\boldsymbol{\Sigma}$ is reconstructed from these blocks as $\begin{bmatrix} \boldsymbol{\Sigma}_{uv} & \boldsymbol{\Sigma}_{uv,t} \\ \boldsymbol{\Sigma}_{t,uv} & \Sigma_t \end{bmatrix}$ [S1, unofficial].*

**Steps:**
1.  **Partition Covariance:** Decompose the global covariance $\boldsymbol{\Sigma}$ into spatial $\boldsymbol{\Sigma}_{uv}$, temporal $\Sigma_t$, and cross-terms $\boldsymbol{\Sigma}_{uv,t}$ and $\boldsymbol{\Sigma}_{t,uv}$ [S1, unofficial].
2.  **Compute Conditional Covariance:** Calculate the Schur complement to obtain the conditional spatial covariance $\boldsymbol{\Sigma}_{uv|t}$:
    $$ \boldsymbol{\Sigma}_{uv|t} = \boldsymbol{\Sigma}_{uv} - \boldsymbol{\Sigma}_{uv,t} \Sigma_t^{-1} \boldsymbol{\Sigma}_{t,uv} $$
    [S1, unofficial].
3.  **Compute Conditional Mean:** Calculate the conditional spatial mean $\boldsymbol{\mu}_{uv|t}$ (implied by standard Gaussian conditioning properties, though the explicit formula for $\boldsymbol{\mu}_{uv|t}$ is not provided in the source text, the structure follows $\boldsymbol{\mu}_{uv} + \boldsymbol{\Sigma}_{uv,t}\Sigma_t^{-1}(t - \mu_t)$) [G]. *Note: The source proves the determinant property and defines the density form but omits the explicit mean update formula in the provided text.*
4.  **Evaluate Density:** Compute the joint probability density $p(u, v, t)$ and the conditional density $p(u, v|t)$ using the normalized Gaussian PDF form scaled by the unnormalized factor [S1, unofficial]:
    $$ p(u, v, t) = (2\pi)^{-3/2} \det(\boldsymbol{\Sigma})^{-1/2} \mathcal{N}(u, v, t|\boldsymbol{\mu}, \boldsymbol{\Sigma}) $$
    $$ p(u, v|t) = (2\pi)^{-1} \det(\boldsymbol{\Sigma}_{uv|t})^{-1/2} \mathcal{N}(u, v | \boldsymbol{\mu}_{uv|t}, \boldsymbol{\Sigma}_{uv|t}) $$
    [S1, unofficial].
5.  **Factorization Verification:** The method relies on the property that $\det(\boldsymbol{\Sigma}) = \det(\Sigma_t) \det(\boldsymbol{\Sigma}_{uv|t})$, ensuring the factorization $p(u, v, t) = p(t)p(u, v|t)$ holds [S1, unofficial].

**Pseudocode:**
```python
def compute_conditional_gaussian(mu_uv, mu_t, Sigma_uv, Sigma_t, Sigma_uv_t, t_query):
    """
    Computes the conditional spatial Gaussian parameters given a time query.
    
    Args:
        mu_uv: np.array, shape (2,), spatial mean.
        mu_t: float, temporal mean.
        Sigma_uv: np.array, shape (2, 2), spatial covariance.
        Sigma_t: float, temporal variance.
        Sigma_uv_t: np.array, shape (2, 1), spatial-temporal cross-covariance.
        t_query: float, the time instance to condition on.
        
    Returns:
        mu_cond: np.array, shape (2,), conditional spatial mean.
        Sigma_cond: np.array, shape (2, 2), conditional spatial covariance.
    """
    # Step 1: Compute Conditional Covariance (Schur Complement)
    # Sigma_uv|t = Sigma_uv - Sigma_uv,t * Sigma_t^-1 * Sigma_t,uv
    # Note: Sigma_t,uv is the transpose of Sigma_uv_t
    Sigma_t_inv = 1.0 / Sigma_t
    Sigma_cond = Sigma_uv - np.dot(Sigma_uv_t, np.dot(Sigma_t_inv, Sigma_uv_t.T))
    
    # Step 2: Compute Conditional Mean
    # mu_uv|t = mu_uv + Sigma_uv,t * Sigma_t^-1 * (t_query - mu_t)
    # This is the standard Gaussian conditioning formula, inferred as [G] 
    # because the source text proves the determinant/covariance structure but 
    # omits the explicit mean equation in the provided excerpt.
    mu_cond = mu_uv + np.dot(Sigma_uv_t, Sigma_t_inv * (t_query - mu_t))
    
    return mu_cond, Sigma_cond
```

**Parameters:**
*   $\lambda$: Not given in the sources for this specific formulation (appears in 6DGS opacity modulation [S2, unofficial]).
*   Regularization: Not given in the sources.

**Edge Cases:**
*   **Singularity:** If $\Sigma_t$ is zero or near-zero, the inverse $\Sigma_t^{-1}$ becomes unstable. The source does not specify a guard, but numerically, a small epsilon should be added to $\Sigma_t$ before inversion [G].
*   **Degenerate Input:** If the Gaussian is static (no temporal variation), $\boldsymbol{\Sigma}_{uv,t}$ should be zero, reducing the conditional distribution to the marginal spatial distribution [S1, unofficial].

## Subtopics

### N-Dimensional Gaussian (6DGS/7DGS)
Extends the conditional probability formulation to non-spatial dimensions such as viewing direction or time [S2, unofficial]. 6DGS models a joint distribution over spatial ($X_p$) and directional ($X_d$) components, conditioning on the view $d$ to obtain a view-specific 3D Gaussian [S2, unofficial]. The conditional covariance is $\boldsymbol{\Sigma}_{cond} = \boldsymbol{\Sigma}_p - \boldsymbol{\Sigma}_{pd}\boldsymbol{\Sigma}_d^{-1}\boldsymbol{\Sigma}_{pd}^\top$, and the conditional mean is $\boldsymbol{\mu}_{cond} = \boldsymbol{\mu}_p + \boldsymbol{\Sigma}_{pd}\boldsymbol{\Sigma}_d^{-1}(d - \boldsymbol{\mu}_d)$ [S2, unofficial]. 7DGS further adds a temporal dimension $X_t$, conditioning on both time and view [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** The computation of the Schur complement and conditional mean is $O(1)$ per Gaussian per query, as the dimensions are fixed (2D spatial, 1D time/direction) [S1, S2, unofficial].
*   **Memory Complexity:** Requires storing the partitioned covariance blocks ($\boldsymbol{\Sigma}_{uv}, \Sigma_t, \boldsymbol{\Sigma}_{uv,t}$) instead of the full $3 \times 3$ matrix if optimized, though typically stored as the full matrix for simplicity. The source does not specify memory savings [S1, unofficial].
*   **Strengths:** Enables real-time dynamic rendering by decoupling temporal/spatial dependencies [S1, unofficial]. Allows for view-dependent appearance and geometry modeling [S2, unofficial].
*   **Limitations:** Requires careful handling of the covariance matrix to ensure positive definiteness after conditioning [G]. The source notes that for some scenes, it may only learn a background map rather than correct geometry [S1, unofficial].

## Background
The Gaussian Conditional Probability Formulation originates from the work on 4D Gaussian Splatting, specifically detailed in "Real-time Photorealistic Dynamic Scene Representation and Rendering with 4D Gaussian Splatting" [S1, unofficial]. It builds upon the mathematical properties of multivariate Gaussian distributions to handle dynamic scenes. The extension to N-dimensional Gaussians (6DGS/7DGS) was later proposed to incorporate view and time dependencies more explicitly [S2, unofficial].
