# Anti-Aliased Interlevel Loss

Also called: Blurred NeRF Loss, Prefiltered Loss

## Overview
The Anti-Aliased Interlevel Loss is a proposal supervision loss function designed to measure the distance between a NeRF histogram and a proposal histogram by blurring the NeRF histogram into a piecewise-linear spline and resampling it into the proposal's interval endpoints [S1]. Unlike the piecewise constant loss used in mip-NeRF 360, which suffers from aliasing when NeRF histogram bins are narrow or translate relative to the proposal, this method produces a smooth loss surface that prevents aliasing artifacts during training [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:**
    *   NeRF histogram endpoints $\mathbf{s} = \{s_0, \dots, s_N\}$ and weights $\mathbf{w} = \{w_0, \dots, w_{N-1}\}$, where $s_i$ are normalized distances in $[0, 1]$ and $w_i$ are the accumulated weights for interval $[s_i, s_{i+1}]$ [S1].
    *   Proposal histogram endpoints $\hat{\mathbf{s}} = \{\hat{s}_0, \dots, \hat{s}_M\}$ and weights $\hat{\mathbf{w}} = \{\hat{w}_0, \dots, \hat{w}_{M-1}\}$ [S1].
    *   Convolution radius $r$ [S1].
*   **Outputs:**
    *   Scalar loss value $\mathcal{L}_{\text{prop}}$ [S1].
    *   Resampled NeRF weights $\hat{\mathbf{w}}^{\mathbf{s}}$ (intermediate output used in loss calculation) [S1].

**Data Structures**
*   **NeRF Histogram:** Two arrays of size $N+1$ (endpoints) and $N$ (weights).
*   **Proposal Histogram:** Two arrays of size $M+1$ (endpoints) and $M$ (weights).
*   **Delta Functions:** A list of tuples `(position, value)` representing signed delta functions.

**Parameters**
*   $r$: The radius of the rectangular pulse used for convolution. Not given in the sources.
*   $\epsilon$: A small constant to prevent division by zero in the loss denominator. Not given in the sources.

**Algorithm Steps**
1.  **Normalize:** Convert NeRF weights $\mathbf{w}$ into a piecewise constant probability density function (PDF). For each interval $i$, compute the height $h_i = w_i / (s_{i+1} - s_i)$ [S1].
2.  **Convolve:** Convolve the piecewise constant PDF with a rectangular pulse of radius $r$ to obtain a piecewise linear PDF. This is implemented efficiently using a delta-function integration algorithm to handle arbitrary endpoint locations and avoid rasterization errors with narrow bins [S1].
    *   For each endpoint $s_i$ of the step function, create two signed delta functions:
        *   At position $s_i - r$ with value proportional to the change in height from the previous interval.
        *   At position $s_i + r$ with value proportional to the change in height to the next interval.
    *   Specifically, let $h_i$ be the height of interval $i$. The change at $s_i$ is $h_i - h_{i-1}$ (with $h_{-1}=0$) and at $s_{i+1}$ is $h_{i+1} - h_i$ (with $h_N=0$). The values are scaled by $1/(2r)$ to ensure the pulse integrates to 1 [S1].
    *   Sort all delta functions by position.
    *   Integrate the sorted delta functions twice to produce the piecewise linear PDF values at the query points [S1].
3.  **Integrate to CDF:** Integrate the piecewise linear PDF to produce a piecewise-quadratic Cumulative Distribution Function (CDF) [S1].
4.  **Resample:** Query the piecewise-quadratic CDF at each endpoint $\hat{s}_j$ of the proposal histogram using piecewise quadratic interpolation to obtain $CDF(\hat{s}_j)$ [S1].
5.  **Compute Resampled Weights:** Calculate the resampled NeRF weights $\hat{w}_i^{\mathbf{s}}$ for each proposal interval $i$ by taking the difference between adjacent interpolated CDF values: $\hat{w}_i^{\mathbf{s}} = CDF(\hat{s}_{i+1}) - CDF(\hat{s}_i)$ [S1].
6.  **Evaluate Loss:** Compute the loss as an element-wise function of the resampled NeRF weights $\hat{\mathbf{w}}^{\mathbf{s}}$ and the proposal weights $\hat{\mathbf{w}}$ [S1].

**Pseudocode**

```python
import numpy as np

def anti_aliased_interlevel_loss(s, w, s_hat, w_hat, r):
    """
    Computes the anti-aliased interlevel loss.
    
    Args:
        s: NeRF histogram endpoints, shape (N+1,)
        w: NeRF histogram weights, shape (N,)
        s_hat: Proposal histogram endpoints, shape (M+1,)
        w_hat: Proposal histogram weights, shape (M,)
        r: Convolution radius
        
    Returns:
        loss: Scalar loss value
    """
    N = len(w)
    M = len(w_hat)
    
    # Step 1: Normalize to piecewise constant PDF
    # h[i] is the height of the step function in interval i
    intervals = s[1:] - s[:-1]
    # Guard against zero-width intervals
    intervals = np.maximum(intervals, 1e-8)
    h = w / intervals
    
    # Step 2: Convolve with rectangular pulse using delta functions
    # Create delta functions at s[i] - r and s[i] + r
    # The value is proportional to the change in h
    # Change at s[i] is h[i] - h[i-1] (h[-1] = 0)
    # Change at s[i+1] is h[i+1] - h[i] (h[N] = 0)
    
    deltas = []
    
    # Handle first interval start
    # At s[0], change is h[0] - 0
    deltas.append((s[0] - r, h[0] / (2 * r)))
    deltas.append((s[0] + r, -h[0] / (2 * r)))
    
    # Handle internal boundaries
    for i in range(1, N):
        # At s[i], change is h[i] - h[i-1]
        delta_val = (h[i] - h[i-1]) / (2 * r)
        deltas.append((s[i] - r, delta_val))
        deltas.append((s[i] + r, -delta_val))
        
    # Handle last interval end
    # At s[N], change is 0 - h[N-1]
    deltas.append((s[N] - r, -h[N-1] / (2 * r)))
    deltas.append((s[N] + r, h[N-1] / (2 * r)))
    
    # Sort deltas by position
    deltas.sort(key=lambda x: x[0])
    
    # Step 3 & 4: Integrate twice to get CDF values at s_hat
    # First integration gives PDF values (piecewise linear)
    # Second integration gives CDF values (piecewise quadratic)
    
    # We need to evaluate the CDF at each s_hat[j]
    # The CDF is the double integral of the delta functions.
    # Let D be the sorted list of (pos, val).
    # The first integral (PDF) at point x is sum(val for pos, val in D if pos <= x)
    # The second integral (CDF) at point x is sum(val * (x - pos) for pos, val in D if pos <= x)
    # Note: The standard integration of a delta function delta(x-a) is H(x-a).
    # The integration of H(x-a) is (x-a)H(x-a).
    # So the CDF contribution from a delta at pos with value v is v * max(0, x - pos).
    
    cdf_values = np.zeros(M + 1)
    
    # Precompute cumulative sums for efficiency if needed, but M, N are small enough for direct computation
    for j in range(M + 1):
        x = s_hat[j]
        cdf_val = 0.0
        for pos, val in deltas:
            if pos <= x:
                cdf_val += val * (x - pos)
            else:
                # Since deltas are sorted, we could break, but we need to be careful
                # Actually, if pos > x, the term is 0.
                pass
        cdf_values[j] = cdf_val
        
    # Step 5: Compute resampled weights
    # w_hat_s[i] = CDF(s_hat[i+1]) - CDF(s_hat[i])
    w_hat_s = cdf_values[1:] - cdf_values[:-1]
    
    # Step 6: Evaluate loss
    # L_prop = sum_i (1 / w_hat_i) * max(0, stop_grad(w_hat_s_i) - w_hat_i)^2
    # Note: The formula uses stop_grad on w_hat_s. In practice, this means we detach the gradient
    # from the resampled weights before computing the loss with respect to the proposal network.
    # However, the loss is typically backpropagated through the resampling process to the NeRF.
    # The formula explicitly applies stop_grad to the term being compared against w_hat.
    
    # Using numpy for element-wise operations
    # max(0, ...) is equivalent to np.maximum(0, ...)
    diff = np.maximum(0, w_hat_s - w_hat)
    
    # Guard against division by zero in w_hat
    w_hat_safe = np.maximum(w_hat, 1e-8)
    
    loss = np.sum(diff**2 / w_hat_safe)
    
    return loss
```

**Edge Cases and Pitfalls**
*   **Narrow Bins:** Rasterizing the step function and performing convolution fails in the common case of extremely narrow histogram bins. The delta-function integration algorithm is required to handle this correctly [S1].
*   **Zero-Width Intervals:** If $s_{i+1} - s_i = 0$, the normalization step involves division by zero. A small epsilon should be added to the interval size [G].
*   **Zero Proposal Weights:** If $\hat{w}_i = 0$, the loss term involves division by zero. A small epsilon should be added to the proposal weights in the denominator [G].

## Operating characteristics
*   **Time Complexity:** The convolution step involves sorting $2(N+1)$ delta functions, which takes $O(N \log N)$ time. The CDF evaluation for $M+1$ points takes $O(M \cdot N)$ time in the naive implementation, or $O(M + N)$ with a sweep-line algorithm. The loss evaluation is $O(M)$. Overall, the complexity is dominated by the sorting and CDF evaluation, roughly $O(N \log N + M \cdot N)$ or $O(N \log N + M + N)$ with optimization.
*   **Memory Complexity:** $O(N + M)$ to store the histograms and delta functions.
*   **Strengths:** Produces a smooth loss surface that is robust to aliasing when NeRF histogram bins are narrow or translate relative to the proposal [S1].
*   **Limitations:** More computationally expensive than the piecewise constant loss used in mip-NeRF 360 due to the convolution and resampling steps [S1].
*   **When to use:** When training proposal networks for NeRFs where aliasing artifacts are a concern, particularly with narrow histogram bins.
*   **When not to use:** When computational efficiency is paramount and aliasing is not a significant issue.

## Background
The Anti-Aliased Interlevel Loss was introduced in the Zip-NeRF paper [S1]. It builds on the proposal supervision approach from mip-NeRF 360 [S1]. The key innovation is the use of a blurred, piecewise-linear representation of the NeRF histogram to enable smooth gradient flow during training, addressing the aliasing issues inherent in the piecewise constant comparison used in mip-NeRF 360 [S1].
