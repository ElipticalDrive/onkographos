# Mip-NeRF Optimization and Activation Details

Also called: JaxNeRF Training Procedure, Mip-NeRF Misc. Changes

## Overview
This article defines the specific implementation details for training mip-NeRF and JaxNeRF, focusing on activation functions, input encoding structures, and learning rate scheduling. These changes are designed to improve training stability and robustness, particularly against catastrophic failure modes, without significantly altering the model's accuracy or speed [S1]. Unlike standard NeRF implementations, this method removes identity concatenation from the MLP input and employs shifted/widened activation functions to handle edge cases in density and color prediction [S1].

## How it works
The method modifies the standard NeRF training loop through four key components: input encoding structure, density activation, color activation, and learning rate scheduling.

### Inputs and Outputs
*   **Inputs:** Ray parameters (origin, direction), integrated positional encoding (IPE) features, and iteration index $i$.
*   **Outputs:** Density $\tau$ and color $c$ for the ray segment.

### Data Structures
*   **Integrated Positional Encoding (IPE):** The MLP input consists solely of the IPE features derived from the ray's mean and covariance. The original position and view direction are **not** concatenated with the encoding [S1].
*   **View Direction Encoding:** The ray direction $d$ is normalized, then processed with a standard positional encoding function with $L=4$ frequencies [S1].

### Numbered Steps

1.  **Input Preparation:**
    *   Compute the IPE features for the ray segment.
    *   Pass these IPE features as the sole input to the MLP [S1].

2.  **Density Prediction ($\tau$):**
    *   The MLP produces a raw output value $x_\tau$.
    *   Apply the **shifted softplus** activation to obtain density:
        $$ \tau = \log(1 + \exp(x_\tau - 1)) $$
    *   This is equivalent to initializing the bias of the density output layer to $-1$, ensuring initial $\tau$ values are small [S1].

3.  **View Direction Injection:**
    *   Normalize the ray direction $d$.
    *   Apply positional encoding with $L=4$ to $d$.
    *   Inject these encoded view directions into the **last layer** of the MLP. This injection occurs after $\tau$ is predicted but before the final color $c$ is predicted [S1].

4.  **Color Prediction ($c$):**
    *   The MLP produces a raw output value $x_c$.
    *   Apply the **widened sigmoid** activation to obtain color:
        $$ c = \frac{1 + 2\epsilon}{1 + \exp(-x_c)} - \epsilon $$
    *   Use $\epsilon = 0.001$. This allows the output to saturate slightly outside the $[0, 1]$ range [S1].

5.  **Optimization Loop:**
    *   Use the Adam optimizer.
    *   Apply the learning rate schedule defined in the "Learning Rate Schedule" section below [S1].

### Formulas

**Density Activation:**
$$ \tau = \log(1 + \exp(x - 1)) $$
*   $x$: Raw MLP output for density.
*   Purpose: Prevents catastrophic failure where the MLP emits negative values everywhere, which would result in zero gradients for $\tau$ and halt optimization [S1].

**Color Activation:**
$$ c = \frac{1 + 2\epsilon}{1 + \exp(-x)} - \epsilon, \quad \epsilon = 0.001 $$
*   $x$: Raw MLP output for color.
*   Purpose: Avoids optimization failure when explaining black or white pixels by allowing saturation slightly outside $[0, 1]$ [S1].

**Learning Rate Schedule:**
$$ \eta_i = \left( \lambda_w + (1 - \lambda_w) \sin\left(\frac{\pi}{2} \operatorname{clip}\left(\frac{i}{n_w}, 0, 1\right)\right) \right) \times \left( \exp\left( (1 - \frac{i}{n}) \log(\eta_0) + \frac{i}{n} \log(\eta_n) \right) \right) $$
*   $i$: Current iteration index.
*   $n$: Total number of iterations ($1,000,000$).
*   $n_w$: Warmup iterations ($2,500$).
*   $\eta_0$: Initial learning rate ($5 \cdot 10^{-4}$).
*   $\eta_n$: Final learning rate ($5 \cdot 10^{-6}$).
*   $\lambda_w$: Warmup scale factor, annealed from $0.01$ to $1$ during the warmup period [S1].

### Parameters
*   **Optimizer:** Adam [S1].
*   **Total Iterations ($n$):** 1,000,000 [S1].
*   **Batch Size:** 4096 [S1].
*   **Warmup Iterations ($n_w$):** 2,500 [S1].
*   **Initial Learning Rate ($\eta_0$):** $5 \cdot 10^{-4}$ [S1].
*   **Final Learning Rate ($\eta_n$):** $5 \cdot 10^{-6}$ [S1].
*   **Warmup Start Factor ($\lambda_{w,start}$):** 0.01 [S1].
*   **Warmup End Factor ($\lambda_{w,end}$):** 1 [S1].
*   **View Direction PE Frequencies ($L$):** 4 [S1].

### Edge Cases and Pitfalls
*   **Negative Density:** Using standard ReLU for density can cause the MLP to emit negative values everywhere, leading to zero gradients and optimization failure. The shifted softplus prevents this [S1].
*   **Black/White Pixel Saturation:** Standard sigmoid saturation can cause training to fail when trying to explain extreme pixel values. The widened sigmoid mitigates this [S1].
*   **Identity Concatenation:** Concatenating original position/view direction with IPE is unnecessary and complicates the formalization of IPE features. Removing it simplifies the method without performance loss [S1].
*   **Alternative PE:** Concatenating positional encodings of mean and covariance square roots is sensitive to $L$ hyperparameters and less compact than IPE. IPE is preferred [S1].

### Pseudocode

```python
import math
import numpy as np

def shifted_softplus(x):
    """
    Density activation function.
    Equivalent to softplus(x - 1).
    """
    return np.log(1 + np.exp(x - 1))

def widened_sigmoid(x, epsilon=0.001):
    """
    Color activation function.
    Saturates slightly outside [0, 1].
    """
    return (1 + 2 * epsilon) / (1 + np.exp(-x)) - epsilon

def positional_encoding(x, L=4):
    """
    Standard positional encoding.
    Assumes x is a vector of shape (D,).
    Returns a vector of shape (2 * L * D,).
    """
    # Placeholder for standard PE implementation
    # Typically: [sin(2^0 * pi * x), cos(2^0 * pi * x), ..., sin(2^(L-1) * pi * x), cos(2^(L-1) * pi * x)]
    # For the purpose of this article, we assume this function exists and is standard.
    pass

def compute_learning_rate(i, n=1000000, n_w=2500, eta_0=5e-4, eta_n=5e-6):
    """
    Computes the learning rate at iteration i.
    """
    # Clip i/n_w to [0, 1]
    clip_val = min(max(i / n_w, 0.0), 1.0)
    
    # Compute lambda_w (warmup scale factor)
    # Annealed from 0.01 to 1
    lambda_w = 0.01 + (1 - 0.01) * (math.sin(math.pi / 2 * clip_val))
    
    # Compute logarithmic annealing factor
    log_eta = (1 - i / n) * math.log(eta_0) + (i / n) * math.log(eta_n)
    annealing_factor = math.exp(log_eta)
    
    return lambda_w * annealing_factor

def mip_nerf_forward(mlp, ray_origin, ray_direction, ipe_features):
    """
    Forward pass for a single ray segment.
    
    Args:
        mlp: The neural network model.
        ray_origin: Ray origin.
        ray_direction: Ray direction (unnormalized).
        ipe_features: Integrated positional encoding features.
        
    Returns:
        tau: Density.
        c: Color.
    """
    # Step 1: Input Preparation
    # The MLP input is ONLY the IPE features.
    # No concatenation with original position or view direction.
    mlp_input = ipe_features
    
    # Step 2: Density Prediction
    # The MLP outputs raw values. We assume the MLP has separate heads or layers
    # for tau and c, or we extract them from the final output.
    # Based on the description, tau is predicted before view direction injection.
    
    # Let's assume the MLP structure is:
    # Layer 1...Layer K-1 (shared) -> Output for tau -> Layer K (view dependent) -> Output for c
    
    # Forward pass to get raw tau
    # Note: In practice, this might be a single forward pass with intermediate extraction.
    # For pseudocode clarity, we assume we can get raw_tau from the network.
    raw_tau = mlp.get_raw_density_output(mlp_input)
    
    # Apply shifted softplus
    tau = shifted_softplus(raw_tau)
    
    # Step 3: View Direction Injection
    # Normalize direction
    d_normalized = ray_direction / np.linalg.norm(ray_direction)
    
    # Positional encoding of direction
    view_pe = positional_encoding(d_normalized, L=4)
    
    # Inject view_pe into the last layer.
    # This implies the MLP architecture must support this injection.
    # We assume the MLP has a method to combine view_pe with the hidden state
    # before the final color prediction.
    
    # Step 4: Color Prediction
    # Get raw color output after view injection
    raw_c = mlp.get_raw_color_output(mlp_input, view_pe)
    
    # Apply widened sigmoid
    c = widened_sigmoid(raw_c)
    
    return tau, c
```

## Operating characteristics
*   **Training Time:** Mip-NeRF is 13x faster to train than a brute-force supersampling baseline (16 rays/pixel) [S1].
*   **Evaluation Time:** Mip-NeRF is 16x faster to evaluate than the supersampling baseline [S1].
*   **Quality:** Mip-NeRF outperforms the 16x supersampling baseline in quality metrics (PSNR, SSIM, LPIPS) [S1].
*   **Stability:** The activation functions and learning rate schedule improve training stability, particularly with large learning rates, though the core accuracy remains similar to standard NeRF [S1].
*   **Memory:** The removal of identity concatenation makes the IPE features more compact, reducing memory usage compared to concatenated PE approaches [S1].
