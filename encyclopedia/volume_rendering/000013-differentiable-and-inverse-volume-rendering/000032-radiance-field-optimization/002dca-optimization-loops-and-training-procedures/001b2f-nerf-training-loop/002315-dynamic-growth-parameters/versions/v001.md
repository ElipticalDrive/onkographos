# Dynamic Growth Parameters

Also called: NeRF Growth Steps, Recursive NeRF Growth

## Overview
Dynamic Growth Parameters is an adaptive training strategy for Neural Radiance Fields that expands network capacity based on local scene complexity and prediction uncertainty [S1]. Unlike static architectures, it clusters high-uncertainty query points and grows parallel network branches to refine predictions in those regions, enabling coarse-to-fine representation without pre-defining the entire hierarchy [S1].

## How it works
**Inputs and Outputs:**
- Input: A set of 3D query points $X$, their associated 2D image coordinates, viewing directions $d$, and ground-truth colors.
- Output: A recursively structured neural field with multiple branches, where each branch predicts color $c_i$, density $\sigma_i$, uncertainty $\delta_i$, and a latent vector $y_i$.

**Data Structures:**
- **Network Branch:** A multi-layer perceptron (MLP) taking parent output $y_{p_i}$ and direction $d$ as input.
- **Cluster Centers:** $k$ centroids derived from k-means clustering of high-uncertainty points.
- **Growth State:** Tracks the current recursion depth and the set of active branches.

**Algorithm Steps:**
1. **Initial Training:** Train a base NeRF branch for $I_1$ iterations.
2. **Uncertainty Estimation:** Compute uncertainty $\delta_i$ for all sampled points $x_i$ using the current network.
3. **Clustering:** Identify points where $\delta_i > \tau$ (threshold). Apply k-means clustering with $k \in [2, 4]$ to these points, yielding $k$ cluster centers [S1].
4. **Network Growth:** Instantiate $k$ new child branches. Each child branch is initialized to predict residuals or refined features for its respective cluster [S1].
5. **Recursive Training:** Jointly train the parent and new child branches. Points are routed to the child branch corresponding to their cluster center.
6. **Early Termination:** During rendering, if uncertainty $\delta_i$ is below a threshold, terminate recursion and use the current branch's output; otherwise, pass the latent vector $y_i$ to the appropriate child branch [S1].
7. **Iteration:** Repeat steps 2–6. The total number of growth steps is limited to 3 by default [S1].

**Parameters:**
- $k$: Number of branches per growth step. Default: $k=2$ [S1].
- Total Growth Steps: Maximum 3 [S1].
- Threshold $\tau$: Uncertainty threshold for clustering. Not given in the sources.

**Pseudocode:**
```python
def dynamic_growth_training(points, directions, ground_truth_colors, max_steps=3, k=2):
    # Initialize base branch
    branch = initialize_neural_field()
    
    for step in range(max_steps):
        # 1. Train current branches
        branch.train(points, directions, ground_truth_colors)
        
        # 2. Estimate uncertainty for all points
        uncertainties = branch.predict_uncertainty(points)
        
        # 3. Identify high-uncertainty points
        high_uncertainty_mask = uncertainties > THRESHOLD
        high_uncertainty_points = points[high_uncertainty_mask]
        
        if len(high_uncertainty_points) == 0:
            break
            
        # 4. Cluster high-uncertainty points
        # k-means with k clusters
        cluster_centers = kmeans(high_uncertainty_points, k=k)
        
        # 5. Grow new branches
        new_branches = []
        for center in cluster_centers:
            # Initialize child branch
            child = initialize_child_branch(parent=branch, center=center)
            new_branches.append(child)
            
        # 6. Assign points to branches for next iteration
        # Points are assigned to the branch whose center is closest
        assignments = assign_points_to_clusters(high_uncertainty_points, cluster_centers)
        
        # Update branch structure
        branch.children = new_branches
        branch.assignments = assignments
        
    return branch
```

## Subtopics

### Dynamic Growth
An adaptive strategy that clusters uncertain queries at the current stage and grows deeper networks according to the clustering result. After $I_1$ iterations, points with uncertainty higher than a threshold are clustered using k-means with $k \in [2, 4]$. The network grows $k$ branches according to the cluster centers [S1].

## Operating characteristics
- **Time Complexity:** Increases with each growth step due to additional network branches and clustering overhead. Total steps are capped at 3 [S1].
- **Memory Complexity:** Scales with the number of branches. Each growth step adds $k$ new sets of weights.
- **Strengths:** Efficiently allocates capacity to complex regions; early termination speeds up rendering [S1].
- **Limitations:** Requires careful tuning of uncertainty thresholds and clustering parameters; training can be unstable if uncertainty estimates are noisy [S1].
- **When to Use:** Scenes with varying levels of detail where uniform resolution is inefficient.
- **When Not to Use:** Simple scenes with uniform detail; real-time applications requiring fixed latency.

## Background
Originated in Recursive-NeRF, published in IEEE Transactions on Visualization and Computer Graphics in 2022 [S1]. The method addresses the inefficiency of static NeRF architectures by dynamically expanding network depth based on learned uncertainty, allowing for coarse-to-fine scene representation without manual hierarchy design [S1].
