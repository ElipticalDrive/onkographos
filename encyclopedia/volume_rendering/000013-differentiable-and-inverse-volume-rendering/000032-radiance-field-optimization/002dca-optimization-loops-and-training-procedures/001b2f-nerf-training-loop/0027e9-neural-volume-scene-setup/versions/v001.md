# Neural Volume Scene Setup

Also called: Mitsuba Scene Construction for Neural Volumes

## Overview
Constructs a Mitsuba scene graph containing a volumetric cube and a custom neural radiance field integrator, initializing the density grid and spherical harmonics coefficients for differentiable volume rendering [S1, unofficial]. It differs from generic training setup by specifically binding the neural network parameters (density grid, SH coefficients) to the Mitsuba scene graph's heterogeneous volume and integrator components, enabling end-to-end gradient flow through the ray marching process [S1, unofficial].

## How it works
**Inputs:**
- `integrator_type`: String specifying the neural integrator variant. Supported values: `'prb_volpath'`, `'rf_prb'`, `'rf_prb_rt'`, `'rf_prb_drt'`, `'rf_eikonal'` [S1, unofficial].
- `grid_res`: Integer base resolution for the density grid. Default: 16 [S1, unofficial].
- `sh_degree`: Integer degree for spherical harmonics basis. Default: 2 [S1, unofficial].
- `use_relu`: Boolean flag enabling ReLU activation in the network. Default: True [S1, unofficial].
- `max_initial_density`: Float upper bound for density scaling. Default: 5.0 [S1, unofficial].

**Outputs:**
- A configured Mitsuba `Scene` object ready for training [S1, unofficial].

**Data Structures:**
- **Density Grid**: A 3D tensor of shape `(grid_res, grid_res, grid_res)` storing the initial scattering coefficient $\sigma_t$. Initialized to a constant value [S1, unofficial].
- **Spherical Harmonics Coefficients**: Parameters associated with the radiance field, determined by `sh_degree` [S1, unofficial].

**Steps:**
1. If `integrator_type` is `'prb_volpath'`:
   - Create a scene dictionary containing a `'cube'` object.
   - Define the cube's interior as `'heterogeneous'`.
   - Attach a `'gridvolume'` to the interior for $\sigma_t$.
   - Initialize the grid volume values to 0.002 at resolution `grid_res^3` [S1, unofficial].
2. If `integrator_type` is `'rf_prb'`, `'rf_prb_rt'`, `'rf_prb_drt'`, or `'rf_eikonal'`:
   - Instantiate the corresponding integrator class (e.g., `RadianceFieldPRB`).
   - Pass parameters: `grid_res`, `sh_degree`, `use_relu`, and `initial_density`.
   - Calculate `initial_density` as:
     $$ \text{initial\_density} = \frac{\text{max\_initial\_density}}{\text{grid\_res}} $$
   - Default `max_initial_density` is 5.0 [S1, unofficial].
3. Load the scene dictionary with the created integrator and a constant emitter [S1, unofficial].
4. Return the constructed scene [S1, unofficial].

**Pitfalls:**
- The `'rf_eikonal'` integrator is not implemented in the source codebase. The function falls back to `'RadianceFieldPRB'` with a warning comment [S1, unofficial].

**Pseudocode:**
```python
def create_neural_volume_scene(
    integrator_type: str,
    grid_res: int = 16,
    sh_degree: int = 2,
    use_relu: bool = True,
    max_initial_density: float = 5.0
) -> mi.Scene:
    """
    Construct a Mitsuba scene for neural volume rendering.
    
    Args:
        integrator_type: Type of neural integrator.
        grid_res: Base resolution for density grid.
        sh_degree: Degree of spherical harmonics.
        use_relu: Whether to use ReLU activation.
        max_initial_density: Upper bound for density scaling.
        
    Returns:
        Configured Mitsuba Scene.
    """
    # Calculate initial density parameter
    initial_density = max_initial_density / grid_res
    
    scene_dict = {}
    
    if integrator_type == 'prb_volpath':
        # Construct scene dict for volumetric path tracing
        scene_dict['cube'] = {
            'type': 'cube',
            'interior': {
                'type': 'heterogeneous',
                'gridvolume': {
                    'type': 'gridvolume',
                    'resolution': grid_res,
                    'values': 0.002  # Constant initial sigma_t
                }
            }
        }
        # Note: Specific integrator instantiation logic for prb_volpath 
        # is implied by the scene dict structure but not explicitly detailed 
        # in the source beyond the dict creation [S1, unofficial].
        integrator = None # Placeholder for specific integrator creation logic
    elif integrator_type in ['rf_prb', 'rf_prb_rt', 'rf_prb_drt', 'rf_eikonal']:
        # Instantiate neural radiance field integrator
        if integrator_type == 'rf_eikonal':
            print("Warning: rf_eikonal not implemented, falling back to RadianceFieldPRB")
            integrator_class = RadianceFieldPRB
        else:
            # Map string to class (implementation detail not fully specified in source)
            # Assuming a mapping exists or direct instantiation
            integrator_class = get_integrator_class(integrator_type)
            
        integrator = integrator_class(
            grid_res=grid_res,
            sh_degree=sh_degree,
            use_relu=use_relu,
            initial_density=initial_density
        )
        
        # Construct scene dict for RF integrators
        scene_dict['integrator'] = integrator
        scene_dict['emitter'] = {
            'type': 'constant'
        }
        # Cube and volume setup for RF integrators is handled by the integrator class 
        # or implied by the scene structure [S1, unofficial].
    else:
        raise ValueError(f"Unsupported integrator_type: {integrator_type}")
        
    # Load scene with integrator and emitter
    # The exact mi.Scene.load() call depends on the scene dict structure
    # constructed above. For prb_volpath, the cube is in scene_dict.
    # For RF types, the integrator is in scene_dict.
    
    scene = mi.Scene(scene_dict)
    
    return scene
```

## Operating characteristics
- **Time Complexity**: Not given in the sources.
- **Memory Complexity**: Proportional to `grid_res^3` for the density grid storage [S1, unofficial].
- **Strengths**: Provides a standardized way to initialize differentiable volume rendering scenes in Mitsuba with configurable neural network parameters [S1, unofficial].
- **Limitations**: Limited to specific integrator types supported by the `tlir` codebase; `'rf_eikonal'` is not functional [S1, unofficial].

## Background
Originated in the `tlir` (Tensor Light Transport) repository by Jack Zhou [S1, unofficial]. It is used to set up training environments for neural radiance fields and volume rendering optimization loops [S1, unofficial].
