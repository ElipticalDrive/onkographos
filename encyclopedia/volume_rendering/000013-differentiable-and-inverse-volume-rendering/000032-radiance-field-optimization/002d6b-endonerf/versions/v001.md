# EndoNeRF

Also called: EndoNeRF

## Overview
EndoNeRF is a method for deformable surgical scene reconstruction that utilizes a canonical radiance field and a time-dependent displacement field, optimized with stereo depth-cueing and supervision [S1]. It addresses the challenge of reconstructing non-rigid tissue dynamics in endoscopic videos by mapping input space-time coordinates to a static canonical space via a learned displacement field [S1]. Unlike static radiance field methods, it explicitly models temporal deformation, allowing for the querying of radiance and density at any continuous time step [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A sequence of endoscopic video frames (images) with known camera poses and timestamps $\tau$. Stereo depth cues may be used for supervision [S1].
*   **Outputs:** A rendered image for a given camera pose and time, and the underlying canonical radiance field parameters $\Theta$ and displacement field parameters $\Phi$ [S1].

**Data Structures:**
1.  **Canonical Radiance Field ($F_\Theta$):** An MLP that takes a 3D position $\mathbf{x}$ and viewing direction $\mathbf{d}$ as input, outputting density $\sigma$ and color $\mathbf{c}$ [S1].
2.  **Displacement Field ($G_\Phi$):** An MLP that takes a 3D position $\mathbf{x}$ and time $\tau$ as input, outputting a 3D displacement vector [S1].
3.  **Positional Encoding:** Input coordinates and time are mapped to Fourier features before being fed into the networks [S1].

**Parameters:**
*   **MLP Architecture for $F_\Theta$:** 8 fully connected ReLU layers, each with 256 channels [S1].
*   **MLP Architecture for $G_\Phi$:** Not specified in the sources [G].
*   **Loss Function:** L2 photometric reconstruction loss [S1].

**Steps:**
1.  **Positional Encoding:** For a query point $\mathbf{x}$ at time $\tau$ and viewing direction $\mathbf{d}$, compute the positional encoding $\gamma(\mathbf{x})$ and $\gamma(\tau)$ using Fourier features [S1].
2.  **Displacement Calculation:** Query the displacement field $G_\Phi$ with $\mathbf{x}$ and $\tau$ to obtain the displacement vector $\Delta \mathbf{x} = G_\Phi(\mathbf{x}, \tau)$ [S1].
3.  **Canonical Coordinate Mapping:** Compute the canonical position $\mathbf{x}' = \mathbf{x} + \Delta \mathbf{x}$ [S1].
4.  **Radiance Field Query:** Query the canonical radiance field $F_\Theta$ with $\mathbf{x}'$ and $\mathbf{d}$ to obtain density $\sigma$ and color $\mathbf{c}$ [S1].
5.  **Volume Rendering:** Render the image using the standard volume rendering equation (as defined in [44-radiance-field-optimization.md]) with the sampled $\sigma$ and $\mathbf{c}$ along the ray [S1].
6.  **Optimization:** Minimize the L2 photometric reconstruction loss between the rendered image and the ground truth image [S1]. Stereo depth cues are used to supervise the optimization [S1].

**Pseudocode:**
```python
def forward(x, d, tau, F_theta, G_phi, encode):
    """
    x: (3,) spatial coordinates
    d: (3,) viewing direction
    tau: (1,) time step
    F_theta: MLP for canonical radiance field
    G_phi: MLP for displacement field
    encode: function for positional encoding
    """
    # 1. Positional Encoding
    x_enc = encode(x)
    tau_enc = encode(tau)
    
    # 2. Displacement Calculation
    # G_phi takes concatenated spatial and temporal encodings
    displacement = G_phi(concat(x_enc, tau_enc))
    
    # 3. Canonical Coordinate Mapping
    x_canonical = x + displacement
    
    # 4. Radiance Field Query
    # F_theta takes canonical position and direction encodings
    x_can_enc = encode(x_canonical)
    d_enc = encode(d)
    sigma, color = F_theta(concat(x_can_enc, d_enc))
    
    return sigma, color

def render_ray(ray_o, ray_d, tau, F_theta, G_phi, encode, num_samples):
    """
    ray_o: (3,) ray origin
    ray_d: (3,) ray direction
    tau: (1,) time step
    """
    # Sample points along the ray
    t_vals = linspace(0, 1, num_samples)
    xyzs = ray_o + t_vals[:, None] * ray_d
    
    sigma_list = []
    color_list = []
    
    for i in range(num_samples):
        x = xyzs[i]
        sigma, color = forward(x, ray_d, tau, F_theta, G_phi, encode)
        sigma_list.append(sigma)
        color_list.append(color)
        
    # Volume Rendering (Standard DVR)
    # T_i = exp(-sum_{j=1}^{i-1} sigma_j * delta_j)
    # C = sum_{i=1}^N T_i * (1 - exp(-sigma_i * delta_i)) * c_i
    # Note: delta_i is step size along ray
    delta = distance_between_samples(t_vals)
    transmittance = compute_transmittance(sigma_list, delta)
    weights = transmittance * (1 - exp(-sigma_list * delta))
    color = sum(weights * color_list)
    
    return color
```

## Subtopics

### Canonical Volume + Deformation Field Framework
A framework for spatio-temporal reconstruction of objects from few X-ray projections, consisting of a canonical volume assigning density to every point in 3D space and a deformation field returning a displacement for every point as a function of time [S2, S2, unofficial]. It allows querying the neural radiance field at continuous temporal and spatial locations [S2, S2, unofficial]. The deformation field is posed as a B-spline field whose time-dependent weights are obtained from a neural network, using cubic B-splines with fixed control points and time-varying weights to impose a smooth efficient prior [S2, S2, unofficial]. The canonical volume is trained using a hybrid method where projection loss is supplemented by volumetric loss based on high-fidelity X-CT data typically available at initial and final timesteps [S2, S2, unofficial]. The deformation field is trained jointly for all timesteps and with all available data [S2, S2, unofficial]. It is preferred to train the canonical volume on the final step of deformation where the maximum amount of material is present in the field of view [S2, S2, unofficial]. The key assumption is that deformations preserve topology [S2, S2, unofficial].

## Operating characteristics
*   **Time and Memory Complexity:** EndoNeRF optimizes an entire spatial-temporal field, resulting in significant time and resource consumption [S1].
*   **Strengths:** It yields high-quality non-rigidity reconstruction in surgical scenes [S1].
*   **Limitations:** The optimization of the entire spatial-temporal field is computationally expensive [S1]. The complex MLP structure (8 layers, 256 channels) increases computational burden compared to lighter architectures [S1]. The method struggles with changes in scene topology due to the use of a displacement field [S1].

## Background
EndoNeRF emerged as a promising solution for deformable surgical scene reconstruction, utilizing NeRF with tool-guided ray casting, stereo depth-cueing ray marching, and stereo depth-supervised optimization [S1]. It is cited in the context of medical imaging applications of implicit representations [S1].
