# NeRF (Neural Radiance Fields)

Also called: NeRF: Representing Scenes as Neural Radiance Fields for View Synthesis, Neural Radiance Field, Neural Radiation Field, Original NeRF, Preliminaries: Neural Radiance Fields (NeRF), Radiance Fields (NeRF)

## Overview
NeRF represents a static 3D scene as a continuous volumetric function that maps 3D spatial coordinates and 2D viewing directions to emitted RGB color and volume density [S1][S3, S6, unofficial]. It solves the problem of novel view synthesis by replacing explicit geometric primitives (meshes or point clouds) with an implicit neural representation encoded in network weights, trained to reproduce input views via differentiable volume rendering [S1][S4, S13, unofficial]. It distinguishes itself from earlier implicit methods by explicitly incorporating viewing direction into the radiance prediction to model view-dependent effects like specularities and transparency, and by using hierarchical sampling to efficiently resolve the scene geometry [S2, S10, unofficial].

## How it works
**Inputs:** A set of $N$ posed 2D images $\{I_i\}$ with known camera intrinsics (focal length $f$, principal point) and extrinsics (rotation $R_i$, translation $t_i$) [S10, S15, unofficial].
**Outputs:** A trained neural network $F_\Theta$ that approximates the radiance field, and rendered novel views $\hat{C}(\mathbf{r})$ for arbitrary camera poses [S3, S6, unofficial].

**Data Structures:**
1.  **Neural Network ($F_\Theta$):** A Multi-Layer Perceptron (MLP) with parameters $\Theta$. The original implementation uses two separate MLPs:
    *   **Density Network ($F_{\Theta_\sigma}$):** An 8-layer MLP with 256 hidden units per layer, ReLU activations, and skip connections from input to layers 4, 5, 6, and 7 [S9, unofficial][S27].
    *   **Color Network ($F_{\Theta_c}$):** A 2-layer MLP with 256 hidden units, ReLU activations [S27].
    *   *Note:* Some implementations use a single shared MLP with a branching structure [S2, S6, unofficial].
2.  **Positional Encoding ($\gamma$):** A fixed Fourier feature mapping applied to input coordinates [S3, S12, unofficial].
3.  **Ray Data:** For each pixel, a ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ defined by origin $\mathbf{o}$ and unit direction $\mathbf{d}$ [S5][S10, unofficial].

**Parameters:**
*   **Positional Encoding Levels:** $L_x = 10$ for position (63 dimensions), $L_d = 4$ for direction (27 dimensions) [S9, unofficial].
*   **Sampling:**
    *   Coarse samples $N_c = 64$ per ray [S9, S15, unofficial].
    *   Fine samples $N_f = 128$ per ray [S15, unofficial].
    *   Sampling interval $[t_n, t_f]$ (near/far planes). Typical values for bounded scenes (Blender): $t_n=2.0, t_f=6.0$ [S15, S16, unofficial].
    *   Perturbation: Uniform noise added within sampling bins during training (`perturb=True`) to break symmetry [S10, S6, unofficial].
*   **Optimization:** Adam optimizer, batch size 4096 rays [S16, unofficial]. Loss: Mean Squared Error (MSE) between rendered and ground truth colors [S3, S26, unofficial].

**Numbered Steps:**

1.  **Ray Generation:** For each pixel $(u, v)$ in the target image, compute the ray origin $\mathbf{o}$ and direction $\mathbf{d}$ in world coordinates using the camera pose and intrinsics [S10, S15, unofficial].
    $$ \mathbf{d}_{cam} = K^{-1} \begin{bmatrix} u \\ v \\ 1 \end{bmatrix}, \quad \mathbf{d}_{world} = R \mathbf{d}_{cam} $$
    $$ \mathbf{o}_{world} = -R^T t $$

2.  **Stratified Sampling:** Divide the interval $[t_n, t_f]$ into $N$ equal bins. Sample one point $t_i$ uniformly from each bin $[t_n + \frac{i-1}{N}(t_f - t_n), t_n + \frac{i}{N}(t_f - t_n)]$ [S14, unofficial]. If `perturb=True`, add uniform noise $\mathcal{U}[-0.5/N, 0.5/N]$ to $t_i$ [S10, unofficial].

3.  **Positional Encoding:** Apply $\gamma(\cdot)$ to the 3D positions $\mathbf{x}_i = \mathbf{o} + t_i \mathbf{d}$ and the viewing direction $\mathbf{d}$ [S12, unofficial].
    $$ \gamma(\mathbf{p}) = [\sin(2^0 \pi \mathbf{p}), \cos(2^0 \pi \mathbf{p}), \dots, \sin(2^{L-1} \pi \mathbf{p}), \cos(2^{L-1} \pi \mathbf{p})] $$
    Concatenate $\gamma(\mathbf{x}_i)$ and $\gamma(\mathbf{d})$ to form the input vector [S6, unofficial].

4.  **Density Query:** Pass $\gamma(\mathbf{x}_i)$ through the Density Network $F_{\Theta_\sigma}$ to obtain volume density $\sigma_i$ [S18, S26, unofficial].
    $$ \sigma_i = \text{Softplus}(F_{\Theta_\sigma}(\gamma(\mathbf{x}_i))) \quad \text{or} \quad \text{ReLU}(\dots) \quad [G: \text{Sources cite Softplus [S9, unofficial] and ReLU [S18, S26, unofficial]. Softplus is preferred for smoother gradients.}] $$
    *Note:* The density network does *not* take the viewing direction as input [S2, S3, unofficial].

5.  **Opacity and Transmittance Calculation:** Compute segment length $\delta_i = t_{i+1} - t_i$ (with $\delta_N = 0$ or handled separately) [S10, unofficial]. Compute opacity $\alpha_i$ and transmittance $T_i$ [S10, unofficial]:
    $$ \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
    $$ T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right) = \prod_{j=1}^{i-1} (1 - \alpha_j) $$

6.  **Color Query:** Pass $\gamma(\mathbf{x}_i)$ and $\gamma(\mathbf{d})$ through the Color Network $F_{\Theta_c}$ to obtain RGB color $\mathbf{c}_i$ [S6, S26, unofficial].
    $$ \mathbf{c}_i = \text{Sigmoid}(F_{\Theta_c}(\gamma(\mathbf{x}_i), \gamma(\mathbf{d}))) $$
    *Note:* The direction $\mathbf{d}$ is only used in the final layers of the network [S2, S3, unofficial].

7.  **Volume Rendering:** Compute the rendered color $\hat{C}(\mathbf{r})$ by compositing the samples [S10, unofficial]:
    $$ \hat{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i $$
    If `white_bkgd=True`, add the unaccounted opacity $T_{N+1} = \prod_{j=1}^N (1-\alpha_j)$ multiplied by white background [S6, S10, unofficial].

8.  **Hierarchical Sampling (Optional but Standard):** Train two networks (coarse and fine). Use the coarse network's weights $w_i = T_i \alpha_i$ to form a discrete PDF. Sample additional points for the fine network using inverse-CDF sampling to concentrate samples in high-density regions [S10, S21, unofficial]. The final loss combines coarse and fine rendering errors [S14, unofficial].

9.  **Optimization:** Minimize the MSE loss $\mathcal{L} = \frac{1}{|\mathcal{R}|} \sum_{\mathbf{r} \in \mathcal{R}} \|\hat{C}(\mathbf{r}) - C(\mathbf{r})\|^2$ using gradient descent [S3, S26, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class PositionalEncoding(nn.Module):
    def __init__(self, num_bands):
        super().__init__()
        self.num_bands = num_bands

    def forward(self, x):
        # x shape: (..., 3) or (..., 2)
        # Apply sin/cos at frequencies 2^0, ..., 2^(num_bands-1)
        freq_bands = 2.0 ** torch.linspace(0, self.num_bands - 1, self.num_bands, device=x.device)
        x_expanded = x.unsqueeze(-1) * freq_bands.unsqueeze(0) # (..., 3, num_bands)
        x_sin = torch.sin(x_expanded)
        x_cos = torch.cos(x_expanded)
        return torch.cat([x_sin, x_cos], dim=-1).view(x.shape[0], -1) # Flatten last dims

class DensityNetwork(nn.Module):
    def __init__(self, input_dim, hidden_dim=256, num_layers=8):
        super().__init__()
        self.layers = nn.ModuleList([nn.Linear(input_dim, hidden_dim) for _ in range(num_layers)])
        self.skip_indices = [3, 4, 5, 6] # 0-indexed, corresponding to layers 4,5,6,7 in 1-indexed

    def forward(self, x):
        h = x
        for i, layer in enumerate(self.layers):
            h = F.relu(layer(h))
            if i in self.skip_indices:
                h = torch.cat([h, x], dim=-1)
        # Output density, ensure non-negative
        return F.softplus(self.layers[-1](h)) # Or linear output + softplus

class ColorNetwork(nn.Module):
    def __init__(self, input_dim, hidden_dim=256):
        super().__init__()
        self.layers = nn.ModuleList([nn.Linear(input_dim, hidden_dim) for _ in range(2)])

    def forward(self, h, d):
        # h is the output from density network (or shared feature)
        # d is the encoded direction
        x = torch.cat([h, d], dim=-1)
        for i, layer in enumerate(self.layers):
            x = F.relu(layer(x))
        return torch.sigmoid(self.layers[-1](x))

class NeRF:
    def __init__(self, pos_enc_bands_xyz=10, pos_enc_bands_dir=4, hidden_dim=256):
        self.gamma_xyz = PositionalEncoding(pos_enc_bands_xyz)
        self.gamma_dir = PositionalEncoding(pos_enc_bands_dir)
        # Input dim for density: 3 * 2 * 10 = 60
        self.density_net = DensityNetwork(input_dim=3 * 2 * pos_enc_bands_xyz, hidden_dim=hidden_dim)
        # Input dim for color: 256 (from density net) + 2 * 2 * 4 = 16
        self.color_net = ColorNetwork(input_dim=hidden_dim + 2 * 2 * pos_enc_bands_dir, hidden_dim=hidden_dim)

    def query(self, xyz, direction):
        """
        xyz: (..., 3)
        direction: (..., 3)
        Returns: sigma (..., 1), color (..., 3)
        """
        xyz_enc = self.gamma_xyz(xyz)
        dir_enc = self.gamma_dir(direction)
        
        sigma = self.density_net(xyz_enc)
        color = self.color_net(sigma, dir_enc)
        return sigma, color

    def render_ray(self, origin, direction, t_near, t_far, num_samples, perturb=False):
        """
        origin: (..., 3)
        direction: (..., 3)
        Returns: color (..., 3), depth (..., 1)
        """
        # Stratified sampling
        t_vals = torch.linspace(t_near, t_far, num_samples, device=origin.device)
        if perturb:
            # Add uniform noise in each bin
            t_bins = torch.linspace(t_near, t_far, num_samples + 1, device=origin.device)
            t_rand = torch.rand_like(t_vals) * (t_bins[1] - t_bins[0])
            t_vals = t_bins[:-1] + t_rand
        else:
            t_vals = t_vals

        # Compute deltas
        t_deltas = t_vals[1:] - t_vals[:-1]
        t_deltas = torch.cat([t_deltas, torch.tensor([1e10], device=origin.device)], dim=-1) # Last delta large

        # Sample points
        xyz = origin.unsqueeze(1) + direction.unsqueeze(1) * t_vals.unsqueeze(2) # (..., N, 3)
        
        # Query network
        sigma, color = self.query(xyz, direction.unsqueeze(1).expand_as(xyz)) # (..., N, 1), (..., N, 3)
        
        # Compute opacity and transmittance
        alpha = 1.0 - torch.exp(-sigma * t_deltas) # (..., N, 1)
        transmittance = torch.cumprod(torch.cat([torch.ones_like(alpha[..., :1]), 1.0 - alpha[..., :-1]], dim=-1), dim=-2) # (..., N, 1)
        # Note: Standard implementation often uses product of (1-alpha). 
        # T_i = exp(-sum_{j<i} sigma_j delta_j). 
        # Let's use the explicit product form for clarity in implementation if cumprod is tricky with 0s.
        # T_i = prod_{j=0}^{i-1} (1 - alpha_j)
        
        weights = transmittance * alpha # (..., N, 1)
        color_rendered = torch.sum(weights * color, dim=-2) # (..., 3)
        
        # Depth (expected distance)
        depth = torch.sum(weights * t_vals.unsqueeze(-1), dim=-2)
        
        return color_rendered, depth
```

## Subtopics

### [NeRF Training Configuration](1203-nerf-training-configuration.md)
Defines the optimization loop, data handling, and regularization strategies required to train a NeRF model, distinguishing itself by focusing on standard MLP dynamics rather than explicit surface constraints.

### [NeRF-SH](1348-nerf-sh.md)
Replaces direct RGB output with spherical harmonic coefficients to eliminate viewing direction as a network input, enabling efficient storage in octrees and faster rendering.

### [Recursive-NeRF](3029-recursive-nerf.md)
Routes query points through a hierarchy of branch networks based on uncertainty, reducing computational load in simple regions.

### [Mip-NeRF](3381-mip-nerf.md)
Renders anti-aliased conical frustums instead of infinitesimal rays to reduce aliasing artifacts.

### [NeMF (Neural Microflake Field)](3387-nemf-neural-microflake-field.md)
Models light transportation via microflake normals and roughness to handle complex geometry and translucency.

### [EgoNeRF](4096-egonerf.md)
Adapts NeRF for large-scale egocentric scenes using a spherical feature grid.

### [Intrinsic NeRF](4623-intrinsic-nerf.md)
Decouples geometry, illumination, and material properties for relighting tasks.

### [Sparse Neural Volume Representation](7055-sparse-neural-volume-representation.md)
Uses a sparse 3D grid of per-voxel neural features for scalability.

### [Instant Neural Graphics Primitives (Instant NGP)](8637-instant-neural-graphics-primitives-instant-ngp.md)
Accelerates NeRF using multi-resolution hash encoding to reduce training time to minutes.

### [Bayesian Uncertainty Quantification for SeaThru-NeRF](11861-bayesian-uncertainty-quantification-for-seathru-nerf.md)
Quantifies spatial uncertainty using Laplace approximation.

## Operating characteristics
- **Time Complexity:** Training is slow, typically requiring 10–20 hours on a single GPU for bounded scenes (e.g., Blender dataset) [S1][S21, unofficial]. Rendering is also slow, taking ~30 seconds per image at 1080p due to the need to query the MLP hundreds of times per ray [S1].
- **Memory Complexity:** The model size is small (~5 MB for weights) [S6, unofficial], but memory usage during training is dominated by the gradient storage for the large number of rays processed per batch [44-radiance-field-optimization.md].
- **Performance:** Achieves state-of-the-art photorealistic novel view synthesis on bounded scenes (e.g., PSNR ~31.0 dB on Blender) [S1]. Performance degrades on unbounded scenes without modifications (e.g., Mip-NeRF 360) [S1].
- **Strengths:** High fidelity, handles complex lighting and view-dependent effects (specularity, transparency) [S2, S6, unofficial]. No explicit mesh extraction required.
- **Limitations:** Slow training and rendering. Poor surface reconstruction accuracy (density field is not a signed distance function) [S1]. Struggles with unbounded scenes and reflective surfaces without specific modifications [S3, unofficial][S5].

## Background
NeRF was introduced by Mildenhall et al. in 2020 [S3, unofficial]. It builds on the concept of Implicit Neural Representations (INRs) and volumetric rendering [S13, unofficial]. The method was developed to address the limitations of explicit 3D representations in novel view synthesis, particularly for complex scenes with view-dependent appearance [S1][S6, unofficial]. It established the field of neural rendering, leading to numerous variants and accelerations [S1].
