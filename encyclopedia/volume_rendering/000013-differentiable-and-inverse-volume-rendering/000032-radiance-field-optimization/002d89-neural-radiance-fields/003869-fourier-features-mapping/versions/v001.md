# Fourier Features Mapping

Also called: FFM, Feature Mapping (Fourier Feature Mapping), Fourier Features

## Overview
Fourier Features Mapping (FFM) is a coordinate encoding technique used to overcome the spectral bias of vanilla Multi-Layer Perceptrons (MLPs), which tend to fail to capture high-frequency details in low-dimensional domains [S1][S2, unofficial]. It transforms input spatial coordinates into higher-dimensional vectors, enabling the network to converge faster and represent fine-grained scene details with fewer parameters [S1]. Unlike geometric approaches such as octrees or subdomain grids, FFM decouples the neural network design from the underlying data structure, allowing for flexible integration into sparse volume representations like NeuralVDB [S1].

## How it works
**Inputs and Outputs:**
- Input: A low-dimensional coordinate vector $\mathbf{x} \in \mathbb{R}^3$ (typically 3D spatial coordinates).
- Output: A high-dimensional feature vector $\mathbf{z} \in \mathbb{R}^{2LD}$, where $L$ is the number of frequency bands and $D$ is the input dimension (3).

**Data Structures:**
- **Random Matrix $B$**: A tall and skinny random matrix of shape $(L, D)$, where $L \gg D$. The entries are typically sampled from a Gaussian distribution or a uniform distribution over a specific bandwidth [S2, unofficial].
- **Frequency Bands**: The mapping effectively creates $L$ distinct frequency bands for the sine and cosine functions.

**Formulas:**
The Fourier feature mapping transforms the input $\mathbf{x}$ using the random matrix $B$ as follows [S2, unofficial]:

$$
\mathbf{z} = \gamma(\mathbf{x}) = \left[ \sin(2\pi B \mathbf{x}), \cos(2\pi B \mathbf{x}) \right]
$$

Where:
- $B \in \mathbb{R}^{L \times D}$ is the random projection matrix.
- $\mathbf{x} \in \mathbb{R}^D$ is the input coordinate.
- $\sin$ and $\cos$ are applied element-wise.
- The output $\mathbf{z}$ concatenates the sine and cosine components, resulting in a dimension of $2L$.

**Parameters:**
- **$L$ (Number of Frequencies)**: Determines the highest frequency the network can represent. Larger $L$ allows for higher resolution details but increases memory and computation. Typical values in NeRF literature range from 10 to 250 [S1][S2, unofficial].
- **Bandwidth of $B$**: Controls the distribution of frequencies. A common choice is sampling $B$ from a Gaussian distribution $\mathcal{N}(0, \sigma^2)$ or a uniform distribution [S2, unofficial].

**Steps:**
1. Initialize the random matrix $B \in \mathbb{R}^{L \times 3}$ with entries drawn from a specified distribution (e.g., Gaussian) [S2, unofficial].
2. For each input coordinate $\mathbf{x}$, compute the linear projection $\mathbf{y} = B \mathbf{x}$ [S2, unofficial].
3. Apply the sine and cosine functions to $\mathbf{y}$: $\mathbf{s} = \sin(2\pi \mathbf{y})$ and $\mathbf{c} = \cos(2\pi \mathbf{y})$ [S2, unofficial].
4. Concatenate $\mathbf{s}$ and $\mathbf{c}$ to form the final feature vector $\mathbf{z} = [\mathbf{s}; \mathbf{c}]$ [S1][S2, unofficial].
5. Feed $\mathbf{z}$ into the MLP for density and color prediction [S1].

**Pseudocode:**
```python
import numpy as np

def fourier_feature_mapping(x, B):
    """
    Applies Fourier Feature Mapping to input coordinates x using random matrix B.
    
    Args:
        x: numpy array of shape (N, 3), N input coordinates.
        B: numpy array of shape (L, 3), random projection matrix.
        
    Returns:
        z: numpy array of shape (N, 2*L), encoded features.
    """
    # Linear projection: y = B @ x.T -> shape (L, N)
    # Transpose to get (N, L) for element-wise operations
    y = x @ B.T 
    
    # Apply sine and cosine
    sin_y = np.sin(2 * np.pi * y)
    cos_y = np.cos(2 * np.pi * y)
    
    # Concatenate along the feature axis
    z = np.concatenate([sin_y, cos_y], axis=-1)
    
    return z
```

**Edge Cases and Pitfalls:**
- **Precision**: High-frequency components may lead to numerical instability if not properly scaled. The factor $2\pi$ ensures the frequencies are in cycles per unit, matching standard Fourier definitions [S2, unofficial].
- **Boundary Conditions**: The mapping is global; it does not inherently handle local variations better than positional encoding unless the bandwidth of $B$ is tuned per region [S2, unofficial].
- **Degenerate Input**: If $B$ has linearly dependent rows, the effective dimensionality is reduced, potentially limiting the frequency range [S2, unofficial].

## Subtopics

### Positional Encoding
A specific case of Fourier Feature Mapping where the random matrix $B$ is diagonal with entries sampled from a geometric progression [S2, unofficial]. It is simpler but less flexible than general FFM.

### Neural Hash Encoding
A sparse, learnable feature mapping that replaces the random projection with a hash table of trainable vectors [S1]. It is more memory-efficient for large scenes but requires careful hash collision management.

### One-Blob Encoding
Uses Gaussian radial basis functions instead of periodic sine/cosine functions [S1]. It provides smooth local support but may require more parameters to capture high frequencies.

## Operating characteristics
- **Time Complexity**: $O(L \cdot D)$ per coordinate, where $L$ is the number of frequency bands and $D$ is the input dimension (3). This is negligible compared to the MLP evaluation.
- **Memory Complexity**: $O(L \cdot D)$ to store the random matrix $B$. This is constant regardless of the scene size.
- **Performance**: Significantly improves the ability of MLPs to learn high-frequency details compared to vanilla MLPs, reducing training time and improving reconstruction quality [S1][S2, unofficial].
- **Strengths**: Simple to implement, differentiable, and effective at overcoming spectral bias. Decouples network design from data structure [S1].
- **Limitations**: Requires careful tuning of $L$ and the bandwidth of $B$. May overfit to high-frequency noise if $L$ is too large [S2, unofficial].

## Background
Fourier Features Mapping was introduced by Tancik et al. in 2020 to address the spectral bias of MLPs in coordinate-based neural representations [S1][S2, unofficial]. It was shown that standard MLPs act as low-pass filters, failing to capture high-frequency signals. By projecting inputs into a Fourier feature space, the effective Neural Tangent Kernel (NTK) becomes stationary with a tunable bandwidth, enabling the network to learn high-frequency functions [S2, unofficial]. The technique has become a standard component in Neural Radiance Fields (NeRF) and related methods [S1].
