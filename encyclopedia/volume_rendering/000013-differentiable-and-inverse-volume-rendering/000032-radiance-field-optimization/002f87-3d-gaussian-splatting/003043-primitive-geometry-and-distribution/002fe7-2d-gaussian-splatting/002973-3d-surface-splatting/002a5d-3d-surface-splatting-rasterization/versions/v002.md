# 3D Surface Splatting Rasterization

Also called: 3DSS rasterization, Depth-Interval Grouping, Interval-based surface separation, Multi-layer interval grouping, Per-pixel rasterization with depth-interval grouping

## Overview
This method is the per-pixel rasterization kernel for 3D Surface Splatting (3DSS), designed to resolve self-occlusion errors at high-curvature concavities by grouping overlapping surfels into distinct surface layers based on depth-interval gaps [S1, unofficial]. Unlike single-layer approaches or classical A-buffers that gather contributions across all depths, it partitions primitives into arbitrary surface groups, allowing multiple surface sheets to be composited independently per pixel [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A list of surfels $\mathcal{S}$, sorted by depth-interval start $z_{\text{start}}$ [S1, unofficial]. Each surfel $i$ has center $z^{(i)}$, half-thickness $\varepsilon_z^{(i)}$, pre-shaded radiance $\mathbf{c}_i$, and MIP-filtered covariance information [S1, unofficial].
*   **Output:** A composited HDR image, where each pixel contains a stack of surface layers, each with accumulated color and opacity [S1, unofficial].

**Data Structures:**
*   **Surfel:** Contains geometric parameters ($z^{(i)}, \varepsilon_z^{(i)}$), radiance ($\mathbf{c}_i$), and MIP covariance $\Sigma_{\text{mip}}$ [S1, unofficial].
*   **Group Accumulators:** Per pixel, maintains $\mathbf{C}_g$ (accumulated color, vector), $W_g$ (accumulated weight, scalar), and $z_{\text{end}}^{\max}$ (farthest depth extent of the current group, scalar) [S1, unofficial].

**Parameters:**
*   $r_{\text{cut}}$: Kernel cutoff radius. The condition $\rho_{\text{mip}}^2 \geq r_{\text{cut}}^2$ triggers skipping [S1, unofficial].
*   $n_f$: Front-facing normal factor (scalar) [S1, unofficial].
*   $\varepsilon_z^{(i)}$: Half-thickness of surfel $i$'s depth interval, used to define $z_{\text{start}}$ and $z_{\text{end}}$ [S1, unofficial].

**Algorithm Steps:**
1.  **Initialization:** For each pixel, initialize group accumulators $\mathbf{C}_g \leftarrow \mathbf{0}$, $W_g \leftarrow 0$, and $z_{\text{end}}^{\max} \leftarrow 0$ [S1, unofficial].
2.  **Iteration:** For each surfel $i$ in the sorted list:
    a.  Compute ray-surfel intersection to obtain local coordinates $(u, v)$ [S1, unofficial].
    b.  Evaluate the squared MIP-filtered distance $\rho_{\text{mip}}^2$ using the precomputed inverse covariance $\Sigma_{\text{mip}}^{-1}$ [S1, unofficial].
    c.  If $\rho_{\text{mip}}^2 \geq r_{\text{cut}}^2$, skip the surfel as it does not cover the pixel [S1, unofficial].
    d.  Calculate the weight $w = n_f \cdot \exp(-\frac{1}{2} \rho_{\text{mip}}^2)$ [S1, unofficial].
    e.  Define the depth interval $[z_{\text{start}}^{(i)}, z_{\text{end}}^{(i)}]$ where $z_{\text{start}}^{(i)} = z^{(i)} - \varepsilon_z^{(i)}$ and $z_{\text{end}}^{(i)} = z^{(i)} + \varepsilon_z^{(i)}$ [S1, unofficial].
    f.  **Gap Detection:** If $W_g > 0$ AND $z_{\text{start}}^{(i)} > z_{\text{end}}^{\max}$, a gap is detected between the current surfel and the active group [S1, unofficial]. Finalize the current layer via `FLUSHLAYER` (which applies Shepard normalization and stores the layer), then reset $\mathbf{C}_g \leftarrow \mathbf{0}$, $W_g \leftarrow 0$, and $z_{\text{end}}^{\max} \leftarrow 0$ [S1, unofficial].
    g.  Update the group's farthest extent: $z_{\text{end}}^{\max} \leftarrow \max(z_{\text{end}}^{\max}, z_{\text{end}}^{(i)})$ [S1, unofficial].
    h.  Accumulate the surfel's contribution: $\mathbf{C}_g \leftarrow \mathbf{C}_g + w \cdot \mathbf{c}_i$ and $W_g \leftarrow W_g + w$ [S1, unofficial].
3.  **Finalization:** After processing all surfels, finalize any remaining active group via `FLUSHLAYER` [S1, unofficial].
4.  **Compositing:** Composite the resulting layers front-to-back using coverage-based opacity defined in equation 9 of [S1, unofficial]. The accumulated weight $W_g$ within each layer serves as a coverage measure, mapped to opacity via a smooth, monotonically increasing function, replacing threshold-based clamping [S1, unofficial].

**Pseudocode:**
```python
def rasterize_pixel(surfels_sorted, r_cut_sq):
    # Initialize accumulators for the current surface group
    C_g = [0.0, 0.0, 0.0]
    W_g = 0.0
    z_end_max = 0.0
    layers = []

    for surfel in surfels_sorted:
        # 1. Ray-surfel intersection to get local coordinates (u, v)
        # [G] Standard ray-surfel intersection solving for local (u, v) coordinates.
        uv = compute_intersection(surfel)
        if uv is None:
            continue

        # 2. Evaluate MIP-filtered weight rho_mip^2 via precomputed Sigma_mip^{-1}
        # [G] Standard Mahalanobis distance computation using inverse covariance.
        rho_mip_sq = compute_mip_weight(surfel)

        # 3. Cutoff check
        if rho_mip_sq >= r_cut_sq:
            continue

        # 4. Calculate weight w
        n_f = surfel.n_f
        w = n_f * math.exp(-0.5 * rho_mip_sq)

        # 5. Define depth interval
        z_start_i = surfel.z - surfel.epsilon_z
        z_end_i = surfel.z + surfel.epsilon_z

        # 6. Gap detection and layer finalization
        if W_g > 0 and z_start_i > z_end_max:
            # Finalize current group via FLUSHLAYER (applies Shepard normalization)
            layer = flush_layer(C_g, W_g)
            layers.append(layer)
            C_g = [0.0, 0.0, 0.0]
            W_g = 0.0
            z_end_max = 0.0

        # 7. Expand group extent
        z_end_max = max(z_end_max, z_end_i)

        # 8. Accumulate contribution
        C_g = [C_g[j] + w * surfel.c_i[j] for j in range(3)]
        W_g += w

    # Finalize the last group if it has content
    if W_g > 0:
        layer = flush_layer(C_g, W_g)
        layers.append(layer)

    # 9. Composite layers front-to-back using coverage-based opacity
    return composite_layers(layers)
```

**Edge Cases and Pitfalls:**
*   **Self-occlusion:** Without depth-interval grouping, single-layer approaches produce self-occlusion errors at high-curvature concavities (e.g., inside ears, under chins) where distinct surface sheets project onto the same pixel [S1, unofficial].
*   **Silhouette Artifacts:** Single-layer methods can produce "crusty" shells or aliased contours at silhouettes [S1, unofficial]. This method avoids this by applying smooth coverage falloff independently on each layer [S1, unofficial].
*   **Precision:** The gap detection relies on comparing $z_{\text{start}}^{(i)}$ with $z_{\text{end}}^{\max}$ [S1, unofficial]. Precision issues in depth values could lead to incorrect gap detection or merging of distinct layers [G].

## Operating characteristics
*   **Time Complexity:** Not given in the sources. Sorting is done per-tile via radix sort [S1, unofficial].
*   **Memory Complexity:** Not given in the sources. Proportional to the number of surface layers per pixel [S1, unofficial].
*   **Strengths:** Resolves self-occlusion at concavities; produces anti-aliased silhouettes without post-process edge detection; differentiable for inverse rendering [S1, unofficial].
*   **Limitations:** Requires sorting and per-pixel state management; more complex than single-layer rasterization [S1, unofficial].
*   **When to use:** When rendering unstructured surface representations (surfels) that require accurate self-occlusion handling and physically-based inverse rendering [S1, unofficial].

## Background
3D Surface Splatting (3DSS) was introduced in the paper "3DSS: 3D Surface Splatting for Inverse Rendering" [S1, unofficial]. The rasterization method builds on the concept of depth-interval grouping to handle the challenges of rendering unstructured surfel clouds, particularly addressing the limitations of single-layer ternary depth tests and classical A-buffer approaches [S1, unofficial].
