# Spherical Harmonics Initialization


## Overview
Spherical Harmonics Initialization sets the initial view-dependent color representation for 3D Gaussians by populating only the zeroth-order (DC) spherical harmonic coefficients with the input RGB colors, while leaving higher-order coefficients at zero. It solves the problem of providing a valid, differentiable starting point for view-dependent color optimization in 3D Gaussian Splatting without introducing high-frequency artifacts or unnecessary complexity during the early stages of training. It sets itself apart from sibling methods like [Angle-pose Cuboid Uniform Initialization (ACUI)](4503-angle-pose-cuboid-uniform-initialization-acui.md) by focusing exclusively on the color parameterization rather than the geometric pose and scale distribution.

## How it works
**Inputs:**
- $N$: Number of 3D Gaussians.
- $\text{RGB}_i \in [0, 1]^3$: The initial RGB color for each Gaussian $i \in \{0, \dots, N-1\}$.

**Outputs:**
- $\mathbf{C} \in \mathbb{R}^{N \times 27}$: A tensor containing the initialized spherical harmonic coefficients for all Gaussians. The shape corresponds to $N$ Gaussians, 3 RGB channels, and 9 coefficients per channel (for degree 2, which is standard for the DC-only initialization in many implementations, though the tensor size is fixed at 27).

**Data Structures:**
- The SH coefficients are stored in a contiguous tensor. For each Gaussian, the coefficients for the three color channels (Red, Green, Blue) are interleaved or grouped. The standard layout in the source [S1, unofficial] implies a shape of $(N, 3, 9)$ before flattening, resulting in $(N, 27)$. The first 9 elements correspond to the Red channel, the next 9 to Green, and the last 9 to Blue. Within each channel, index 0 is the DC term, and indices 1–8 are higher-order terms.

**Steps:**
1.  **Allocation:** Create a zero-filled tensor $\mathbf{C}$ of shape $(N, 3, 9)$. This initializes all SH coefficients to zero.
2.  **DC Coefficient Calculation:** For each Gaussian $i$ and each color channel $c \in \{R, G, B\}$:
    -   Let $v$ be the input color value for channel $c$ of Gaussian $i$.
    -   Compute the DC coefficient $c_{0,i,c}$ using the formula:
        $$ c_{0,i,c} = \frac{v}{k} $$
        where $k = 0.28209479177387814$ is the normalization constant for the zeroth-order spherical harmonic basis function [S1, unofficial].
    -   Assign $c_{0,i,c}$ to the coefficient at index 0 for channel $c$ in $\mathbf{C}$.
3.  **Flattening:** Flatten the last two dimensions of $\mathbf{C}$ from $(N, 3, 9)$ to $(N, 27)$ to produce the final output tensor.

**Parameters:**
-   $k = 0.28209479177387814$: The normalization constant for the zeroth-order SH basis function [S1, unofficial].

**Edge Cases and Pitfalls:**
-   **Higher-Order Coefficients:** All coefficients with index $>0$ remain zero. This is intentional, as higher-order terms are optimized during training. Initializing them to non-zero values can cause instability or artifacts [S1, unofficial].
-   **Color Range:** The input RGB values are assumed to be in the range $[0, 1]$. If inputs are in a different range (e.g., $[0, 255]$), they must be normalized before applying the formula [S1, unofficial].
-   **Precision:** The division by $k$ is a simple scaling operation. Standard floating-point precision is sufficient.

**Pseudocode:**
```python
import numpy as np

def initialize_sh(rgb_colors: np.ndarray) -> np.ndarray:
    """
    Initialize spherical harmonic coefficients for 3D Gaussian splatting.
    
    Args:
        rgb_colors: Array of shape (N, 3) containing RGB values in [0, 1].
        
    Returns:
        Array of shape (N, 27) containing SH coefficients.
    """
    N = rgb_colors.shape[0]
    # Allocate zero tensor of shape (N, 3, 9)
    sh_coeffs = np.zeros((N, 3, 9))
    
    # Normalization constant for zeroth-order SH basis function
    k = 0.28209479177387814
    
    # Assign scaled RGB values to the DC coefficient index (0) for all channels
    # rgb_colors has shape (N, 3), we need to assign to sh_coeffs[:, :, 0]
    # sh_coeffs[:, 0, 0] = R / k
    # sh_coeffs[:, 1, 0] = G / k
    # sh_coeffs[:, 2, 0] = B / k
    sh_coeffs[:, :, 0] = rgb_colors / k
    
    # Flatten the last two dimensions to produce a tensor of shape (N, 27)
    sh_coeffs_flat = sh_coeffs.reshape(N, 27)
    
    return sh_coeffs_flat
```

## Subtopics

### Splat Initialization from Normalized Coordinates
This variant initializes a single splat object with specific geometric and color properties based on normalized coordinates. It is used in the JSplat library [S2, unofficial].
-   **SH Degree:** The splat is created with spherical harmonic degree 3 using `Splats.create(3)` [S2, unofficial].
-   **Position:** Position coordinates are set by scaling normalized inputs $(npx, npy, npz)$ with a constant `size`: `splat.setPositionX(npx * size)`, etc. [S2, unofficial].
-   **Scale:** Uniform scale is set using a constant `baseScale` for all axes [S2, unofficial].
-   **Rotation:** Identity rotation quaternion is set: $(0.0, 0.0, 0.0, 1.0)$ [S2, unofficial].
-   **Opacity:** Opacity is set by converting a fixed alpha value of 1.0 using `Splats.alphaToOpacity(1.0f)` [S2, unofficial].
-   **SH Coefficients:** Degree-0 SH coefficients are set based on normalized coordinates. A special case exists for the exact point $(-0.5, -0.5, -0.5)$, which uses 0.1 instead of the coordinate offset. Otherwise, the coefficient is `colorToDirectCurrent(npx + 0.5)` for Red, `npy + 0.5` for Green, and `npz + 0.5` for Blue [S2, unofficial].
-   **Append:** The configured splat is appended to the target list [S2, unofficial].

## Operating characteristics
-   **Time Complexity:** $O(N)$, where $N$ is the number of Gaussians. The operation involves a single pass over all Gaussians to compute the DC coefficient.
-   **Memory Complexity:** $O(N)$, storing 27 coefficients per Gaussian.
-   **Performance:** The initialization is extremely fast and negligible compared to the training time. It is performed once at the start of the optimization process.
-   **Strengths:** Simple, deterministic, and provides a stable starting point for color optimization. It avoids the need for complex color estimation from sparse point clouds.
-   **Limitations:** Does not account for view-dependent effects initially, as only the DC term is set. Higher-order terms must be learned during training.
-   **When to use:** Standard initialization for 3D Gaussian Splatting when no prior color information is available or when a simple baseline is desired.
-   **When not to use:** If high-fidelity view-dependent effects are critical from the start, other methods might be preferred, though SH initialization is still the standard starting point.

## Background
Spherical Harmonics Initialization is a core component of the 3D Gaussian Splatting pipeline, introduced in the original 3D Gaussian Splatting paper [S1, unofficial]. It leverages the mathematical properties of spherical harmonics to represent view-dependent colors in a compact and differentiable manner. The zeroth-order term corresponds to the average color (DC component), which is sufficient for initial setup. The method has become a standard practice in the field due to its simplicity and effectiveness.
