# Forplane Optimization Losses

Also called: Forplane Losses

## Overview
Forplane Optimization Losses are a set of regularization terms designed to stabilize the training of neural radiance fields that utilize orthogonal neural planes (Forplanes) for spatiotemporal volume representation [S1]. They solve the problem of entanglement between static and dynamic scene components in dynamic volume rendering, where the model may incorrectly assign dynamic motion to static geometry or vice versa [S1]. Unlike standard Total Variation regularization which smooths spatial features, Forplane losses specifically target the structural integrity of the orthogonal plane representations by enforcing spatial smoothness, temporal consistency, and static-field isolation [S1].

## How it works
The method operates on a representation where the 4D volume (3D space + time) is decomposed into a set of 2D orthogonal planes. The optimization minimizes a composite loss function comprising a photometric term and three specific regularization terms derived from the plane structures [S1].

### Inputs and Outputs
**Inputs:**
*   $\boldsymbol{\theta}$: Parameters of the density MLP.
*   $\boldsymbol{\phi}$: Parameters of the color MLP.
*   $\mathbf{V}_{sd}^s$: Set of static space planes (e.g., $G_{XY}, G_{YZ}, G_{XZ}$) [S1].
*   $\mathbf{V}_{3d}^d$: Set of dynamic space-time planes (e.g., $G_{XT}, G_{YT}, G_{ZT}$) [S1].
*   $\mathbf{V}_{sd}^v$: Set of space-time planes used for the disentangle loss (specifically those associated with the dynamic field initialization) [S1].
*   $\hat{\boldsymbol{C}}(\mathbf{r})$: Rendered color for ray $\mathbf{r}$.
*   $\boldsymbol{C}_i^{\text{gt}}(\mathbf{r})$: Ground truth color for ray $\mathbf{r}$ in image $I_i$ [S1].

**Outputs:**
*   $\mathcal{L}_{total}$: The scalar loss value to be minimized [S1].

### Data Structures
The Forplane representation consists of 2D grids (planes).
*   **Static Space Planes ($\mathbf{V}_{sd}^s$):** 2D arrays representing spatial slices (XY, YZ, XZ).
*   **Dynamic Space-Time Planes ($\mathbf{V}_{3d}^d$):** 2D arrays representing slices combining one spatial dimension and time (XT, YT, ZT) [S1].
*   **Values:** Each element $g$ in a plane $G$ is a scalar feature value [S1].

### Formulas
The total loss is defined as [S1]:

$$
\mathcal{L}_{total}(\boldsymbol{\theta}, \boldsymbol{\phi}) = \mathcal{L}_{rgb} + \lambda_d \mathcal{L}_D + \lambda_{tv} \mathcal{L}_{TV} + \lambda_{ts} \mathcal{L}_{TS} + \lambda_{de} \mathcal{L}_{DE}
$$

Where:
1.  **Photometric Loss ($\mathcal{L}_{rgb}$):**
    $$
    \mathcal{L}_{rgb}(\boldsymbol{\theta}, \boldsymbol{\phi}) = \sum_i \mathbb{E}_{\mathbf{r} \sim I_i} \left[ \left\| \hat{\boldsymbol{C}}(\mathbf{r}) - \boldsymbol{C}_i^{\text{gt}}(\mathbf{r}) \right\|_2^2 \right]
    $$
    where $\boldsymbol{C}_i^{\text{gt}}(\mathbf{r})$ is the ground truth color [S1].

2.  **Spatial Total Variation Loss ($\mathcal{L}_{TV}$):**
    $$
    \mathcal{L}_{TV} = \sum_{G \in \mathbf{V}_{sd}^s} \sum_{g \in G} \|\Delta_h^2(G, g) + \Delta_w^2(G, g)\|
    $$
    where $\mathbf{V}_{sd}^s = \{G_{XY}, G_{YZ}, G_{XZ}\}$ are the static space planes. $\Delta_h^2(G, g)$ is the squared difference between the $g$-th value in plane $G:=(i,j)$ and $G:=(i+1,j)$ normalized by resolution [S1].

3.  **Temporal Smoothness Loss ($\mathcal{L}_{TS}$):**
    $$
    \mathcal{L}_{TS} = \sum_{G \in \mathbf{V}_{3d}^d} \sum_{g \in G} \|\Delta_t^2(G, g)\|
    $$
    where $\mathbf{V}_{3d}^d = \{G_{XT}, G_{YT}, G_{ZT}\}$ are the space-time planes. $\Delta_t^2(G, g)$ represents the squared difference along the time axis [S1].

4.  **Disentangle Loss ($\mathcal{L}_{DE}$):**
    $$
    \mathcal{L}_{DE} = \sum_{G \in \mathbf{V}_{sd}^v} \sum_{g \in G} \|1 - g\|
    $$
    where $\mathbf{V}_{sd}^v$ refers to the space-time planes associated with the dynamic field initialization. This loss encourages features to remain at the initial value of 1 [S1].

### Parameters
*   $\lambda_d$: Weight for depth loss $\mathcal{L}_D$. Default: 1 [S1].
*   $\lambda_{tv}$: Weight for spatial TV loss. Default: 0.001 [S1].
*   $\lambda_{ts}$: Weight for temporal smoothness loss. Default: 0.05 [S1].
*   $\lambda_{de}$: Weight for disentangle loss. Default: 0.001 [S1] [G: These values are typical for the cited implementation; other implementations may vary].

    # 3. Temporal Smoothness Loss (L_TS)
    l_ts = 0.0
    for plane in dynamic_space_time_planes:
        # Delta_t^2: difference along the time axis
        # Assuming time is one of the axes (e.g., axis 1 for XT, YT, ZT)
        t_diff = square_diff_along_axis(plane, axis=1)
        l_ts += sum(t_diff)

        l_de += sum(abs(1.0 - plane))
        
    # Total Loss
    total_loss = l_rgb + (lambda_d * l_d) + (lambda_tv * l_tv) + (lambda_ts * l_ts) + (lambda_de * l_de)
    
    return total_loss

def square(tensor):
    return tensor * tensor

def sum(tensor):

def mean_squared_error(pred, target):
    return mean(square(pred - target))

def mean(tensor):

### Edge Cases and Pitfalls
*   **Initialization:** The dynamic field planes $\mathbf{V}_{3d}^d$ are initialized to 1 to ensure they do not influence the static field features during element-wise multiplication in the rendering procedure [S1]. Failure to initialize correctly may cause immediate entanglement.
*   **Boundary Conditions:** The definition of $\Delta_h^2$ and $\Delta_w^2$ involves differences between adjacent grid cells. Boundary handling (e.g., zero-padding vs. wrapping) is not explicitly detailed in the source notes [S1]. Standard practice suggests zero-padding or ignoring boundary terms to avoid artifacts [G].
*   **Monocular Input:** In endoscopic procedures with monocular cameras, the reliance on stereo depth can be limiting. The Forplane method is designed to work with monocular inputs, but the depth loss $\mathcal{L}_D$ may need adaptation or removal if depth supervision is unavailable [S1].

## Operating characteristics
*   **Time Complexity:** The regularization losses are computed directly on the plane tensors. $\mathcal{L}_{TV}$ and $\mathcal{L}_{TS}$ involve simple finite difference operations on the planes, which is $O(N_{planes} \times N_{cells})$. This is negligible compared to the rendering cost.
*   **Memory Complexity:** No additional memory is required beyond the plane tensors themselves.
*   **Strengths:** Effectively disentangles static and dynamic components, leading to cleaner reconstructions of dynamic scenes [S1]. The disentangle loss specifically prevents the dynamic field from learning static structures.
*   **Limitations:** Requires careful tuning of hyperparameters ($\lambda_{tv}, \lambda_{ts}, \lambda_{de}$) [S1]. The method assumes a specific orthogonal plane structure; it is not directly applicable to other volume representations like voxels or Gaussian splats without modification.

## Background
Forplane Optimization Losses were introduced in the context of "Efficient Deformable Tissue Reconstruction via Orthogonal Neural Plane" [S1]. The method builds upon the concept of Neural Fields and specifically the use of orthogonal planes (Forplanes) to represent 3D and 4D volumes efficiently. The specific losses ($\mathcal{L}_{TV}, \mathcal{L}_{TS}, \mathcal{L}_{DE}$) were proposed to address the challenges of reconstructing dynamic, deformable tissues (such as in endoscopic surgery) where static and dynamic elements coexist and must be separated for accurate modeling [S1].
