# Forplane Optimization Losses

Also called: Forplane Losses

## Overview
Forplane Optimization Losses are a set of regularization terms designed to constrain the optimization of orthogonal neural planes in spatiotemporal volume rendering, specifically for deformable tissue reconstruction [S1]. They solve the problem of entanglement between static and dynamic scene components by enforcing structural priors on the learned feature planes [S1]. Unlike general smoothness regularizers, these losses operate on specific orthogonal projections (space-space and space-time planes) to enforce sparsity in dynamic components and smoothness in static components [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** The set of learned feature planes $\mathbf{V}_{sd}^s$ (static space-space planes), $\mathbf{V}_{3d}^d$ (dynamic space-time planes), and $\mathbf{V}_{sd}^v$ (static space-time planes used for disentanglement); ground truth images $I_i$; ray samples $\mathbf{r}$; rendered colors $\hat{\boldsymbol{C}}(\mathbf{r})$.
*   **Outputs:** Scalar loss values $\mathcal{L}_{TV}$, $\mathcal{L}_{TS}$, $\mathcal{L}_{DE}$, and the total loss $\mathcal{L}_{total}$.

**Data Structures:**
The method operates on 2D feature planes extracted from 3D or 4D fields.
*   $\mathbf{V}_{sd}^s = \{G_{XY}, G_{YZ}, G_{XZ}\}$: Static space-space planes. Each plane $G$ has dimensions $H \times W$ corresponding to spatial resolution.
*   $\mathbf{V}_{3d}^d = \{G_{XT}, G_{YT}, G_{ZT}\}$: Dynamic space-time planes. Each plane $G$ has dimensions $H \times T$ (or $W \times T$), representing a spatial axis and the time axis.
*   $\mathbf{V}_{sd}^v$: Static space-time planes used for initialization and disentanglement.

**Numbered Steps:**

1.  **Initialize Dynamic Fields:** Initialize the dynamic 3D field $\mathbf{V}_{d}^{3d}$ values to 1. This ensures that during the initial rendering steps, the dynamic field does not influence the feature aggregation, allowing the static field to model the scene first [S1].
2.  **Compute Total Variation Loss ($\mathcal{L}_{TV}$):** This loss enforces smoothness on the static space-space planes.
    *   For each plane $G \in \{G_{XY}, G_{YZ}, G_{XZ}\}$:
    *   For each element $g$ in $G$:
        *   Compute horizontal squared difference: $\Delta_h^2(G, g) = \frac{(G_{i,j} - G_{i+1,j})^2}{\text{resolution}}$.
        *   Compute vertical squared difference: $\Delta_w^2(G, g) = \frac{(G_{i,j} - G_{i,j+1})^2}{\text{resolution}}$.
    *   Sum the norms: $\mathcal{L}_{TV} = \sum_{G \in \mathbf{V}_{sd}^s} \sum_{g \in G} \|\Delta_h^2(G, g) + \Delta_w^2(G, g)\|$ [S1].
3.  **Compute Total Smoothness Loss ($\mathcal{L}_{TS}$):** This loss enforces smoothness along the time axis for dynamic space-time planes.
    *   For each plane $G \in \{G_{XT}, G_{YT}, G_{ZT}\}$:
    *   For each element $g$ in $G$:
        *   Compute temporal squared difference: $\Delta_t^2(G, g) = (G_{t} - G_{t+1})^2$.
    *   Sum the norms: $\mathcal{L}_{TS} = \sum_{G \in \mathbf{V}_{3d}^d} \sum_{g \in G} \|\Delta_t^2(G, g)\|$ [S1].
4.  **Compute Disentanglement Loss ($\mathcal{L}_{DE}$):** This loss encourages the static space-time planes to remain at their initial value of 1, maximizing the use of the static field for static scene parts and pushing dynamic elements to the dynamic field.
    *   For each plane $G \in \mathbf{V}_{sd}^v$:
    *   For each element $g$ in $G$:
        *   Compute deviation from 1: $\|1 - g\|$.
    *   Sum the norms: $\mathcal{L}_{DE} = \sum_{G \in \mathbf{V}_{sd}^v} \sum_{g \in G} \|1 - g\|$ [S1].
5.  **Compute Photometric Loss ($\mathcal{L}_{rgb}$):** Standard mean squared error between rendered and ground truth colors.
    *   $\mathcal{L}_{rgb}(\boldsymbol{\theta}, \boldsymbol{\phi}) = \sum_i \mathbb{E}_{\mathbf{r} \sim I_i} \left[ \left\| \hat{\boldsymbol{C}}(\mathbf{r}) - \boldsymbol{C}_i^{\text{gt}}(\mathbf{r}) \right\|_2^2 \right]$ [S1].
6.  **Compute Total Loss:** Combine all terms with weights.
    *   $\mathcal{L}_{total}(\boldsymbol{\theta}, \boldsymbol{\phi}) = \mathcal{L}_{rgb} + \lambda_d \mathcal{L}_D + \lambda_{tv} \mathcal{L}_{TV} + \lambda_{ts} \mathcal{L}_{TS} + \lambda_{de} \mathcal{L}_{DE}$ [S1].

**Parameters:**
*   $\lambda_d = 1$: Weight for depth loss $\mathcal{L}_D$ (Note: $\mathcal{L}_D$ is not defined in the provided notes, but included in the total loss formula) [S1].
*   $\lambda_{tv} = 0.001$: Weight for Total Variation Loss [S1].
*   $\lambda_{ts} = 0.05$: Weight for Total Smoothness Loss [S1].
*   $\lambda_{de} = 0.001$: Weight for Disentanglement Loss [S1].

**Pseudocode:**

```python
def compute_forplane_losses(planes, gt_images, rendered_colors, resolution_h, resolution_w, time_steps):
    """
    Computes the Forplane optimization losses.
    
    Args:
        planes: Dictionary containing:
            - 'static_ss': List of 2D tensors [G_XY, G_YZ, G_XZ] of shape (H, W)
            - 'dynamic_st': List of 2D tensors [G_XT, G_YT, G_ZT] of shape (H, T) or (W, T)
            - 'static_st': List of 2D tensors for disentanglement [G_XT, G_YT, G_ZT] of shape (H, T)
        gt_images: List of ground truth color tensors for each image index i.
        rendered_colors: List of rendered color tensors for each image index i.
        resolution_h: Height of the spatial planes.
        resolution_w: Width of the spatial planes.
        time_steps: Number of time steps T.
        
    Returns:
        total_loss: Scalar tensor.
    """
    
    # 1. Photometric Loss (L_rgb)
    l_rgb = 0.0
    for c_hat, c_gt in zip(rendered_colors, gt_images):
        l_rgb += torch.mean((c_hat - c_gt) ** 2)
    
    # 2. Total Variation Loss (L_TV) on static space-space planes
    l_tv = 0.0
    for G in planes['static_ss']:
        # G is (H, W)
        # Horizontal difference: (i, j) vs (i+1, j)
        # Vertical difference: (i, j) vs (i, j+1)
        # Note: Source defines normalized squared difference. 
        # Assuming standard finite differences for implementation.
        
        # Shift for horizontal neighbor
        G_shifted_h = G[1:, :]  # (H-1, W)
        G_current_h = G[:-1, :] # (H-1, W)
        diff_h = (G_current_h - G_shifted_h) ** 2
        
        # Shift for vertical neighbor
        G_shifted_v = G[:, 1:]  # (H, W-1)
        G_current_v = G[:, :-1] # (H, W-1)
        diff_v = (G_current_v - G_shifted_v) ** 2
        
        # Normalize by resolution (Source says "normalized by resolution")
        # Usually implies dividing by the number of pixels or a constant factor.
        # We sum the squared differences.
        l_tv += torch.sum(diff_h + diff_v) / (resolution_h * resolution_w)
        
    # 3. Total Smoothness Loss (L_TS) on dynamic space-time planes
    l_ts = 0.0
    for G in planes['dynamic_st']:
        # G is (H, T) or (W, T). Assume last dim is time.
        # Temporal difference: (t) vs (t+1)
        G_shifted_t = G[:, 1:]  # Last dim - 1
        G_current_t = G[:, :-1] # Last dim - 1
        diff_t = (G_current_t - G_shifted_t) ** 2
        l_ts += torch.sum(diff_t)
        
    # 4. Disentanglement Loss (L_DE) on static space-time planes
    l_de = 0.0
    for G in planes['static_st']:
        # Encourage values to be 1
        diff_de = (1.0 - G) ** 2
        l_de += torch.sum(diff_de)
        
    # 5. Total Loss
    # Note: lambda_d * L_D is included in formula but L_D is not defined in notes.
    # Assuming L_D is a depth loss computed elsewhere or zero if not provided.
    lambda_d = 1.0
    lambda_tv = 0.001
    lambda_ts = 0.05
    lambda_de = 0.001
    
    # Placeholder for L_D if not computed in this function
    l_d = 0.0 
    
    total_loss = l_rgb + (lambda_d * l_d) + (lambda_tv * l_tv) + (lambda_ts * l_ts) + (lambda_de * l_de)
    
    return total_loss
```

**Edge Cases and Pitfalls:**
*   **Boundary Conditions:** The finite difference operations ($\Delta_h^2, \Delta_w^2, \Delta_t^2$) reduce the effective resolution of the planes by 1 in the differenced dimension. Ensure tensor shapes are handled correctly to avoid index out-of-bounds errors [S1].
*   **Initialization:** The dynamic field must be initialized to 1 to prevent it from interfering with the static field during early training stages [S1].
*   **Normalization:** The source specifies normalization by resolution for $\mathcal{L}_{TV}$. The exact scaling factor (e.g., dividing by $H \times W$ or just $H$) should be consistent with the implementation to match the reported loss magnitudes [S1].

## Operating characteristics
*   **Time Complexity:** The computation of these losses is linear with respect to the number of planes and the resolution of the planes ($O(N_{planes} \cdot H \cdot W)$ or $O(N_{planes} \cdot H \cdot T)$). It is lightweight compared to the rendering pass.
*   **Memory Complexity:** Minimal additional memory is required as it operates on the existing feature planes.
*   **Strengths:** Effectively disentangles static and dynamic components in deformable tissue reconstruction, preventing artifacts caused by entanglement [S1].
*   **Limitations:** Relies on the assumption that static components are smooth in space and dynamic components are smooth in time, which may not hold for all types of motion or texture [S1].
*   **When to use:** When optimizing orthogonal neural planes for spatiotemporal volume rendering, particularly in medical imaging (e.g., endoscopic procedures) where static anatomy and dynamic tissue deformation coexist [S1].

## Background
Forplane Optimization Losses were introduced in the context of "Efficient Deformable Tissue Reconstruction via Orthogonal Neural Plane" [S1]. The method addresses limitations in stereo depth reliance for monocular endoscopic procedures by using orthogonal neural planes to represent 3D/4D scenes [S1]. The specific losses $\mathcal{L}_{TV}$, $\mathcal{L}_{TS}$, and $\mathcal{L}_{DE}$ are designed to regularize the learned features in these planes to ensure physical plausibility and disentanglement [S1].
