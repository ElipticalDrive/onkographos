# Regularised Gaussian Fitting Loss

Also called: L1+Regularization Loss for Gaussians, Regularised Loss Function for Gaussian Fitting

## Overview
The Regularised Gaussian Fitting Loss is a composite objective function used to optimize 3D Gaussian splats for volumetric data reconstruction. It augments a base L1 reconstruction loss with regularization penalties on splat amplitude and extent (diagonal covariance) to prevent overfitting and enforce physical plausibility. It is distinguished from standard photometric losses by its explicit constraints on the Gaussian parameters' magnitude and spread, and from distortion losses by its focus on spatial smoothness rather than geometric consistency.

## How it works
**Inputs and Outputs:**
*   **Inputs:** Predicted volume parameters (amplitudes $a_k$, diagonal covariance entries $L_{k,ii}$), target volume data, learning rate $lr$, and regularization weights $\lambda_a, \lambda_d$.
*   **Outputs:** Scalar loss value $\mathcal{L}$ and gradients for the Gaussian parameters.

**Data Structures:**
*   **Splat Parameters:** For $K$ splats in $D$ dimensions, parameters are stored as tensors.
    *   Amplitude: $a_k \in \mathbb{R}$ per splat $k$.
    *   Diagonal Covariance: $L_{k,ii} \in \mathbb{R}$ for $k \in [1, K], i \in [1, D]$. These are softplus-activated parameters with a floor $\sigma_{min}$.

**Formulas:**
The total loss is defined as [S1, unofficial]:

$$
\mathcal{L} = \mathcal{L}_{recon} + \lambda_a \sum_{k=1}^{K} |a_k| + \lambda_d \sum_{k=1}^{K} \sum_{i=1}^{D} |L_{k,ii} - \sigma_{min}|
$$

Where:
*   $\mathcal{L}_{recon}$ is the L1 reconstruction loss between the predicted volume (rendered from the Gaussians) and the target volume.
*   $\lambda_a = 0.1 \times lr$ is the amplitude regularization weight.
*   $\lambda_d = 0.01 \times lr$ is the extent regularization weight.
*   $\sigma_{min}$ is the lower bound floor for the softplus-activated diagonal covariance parameters.
*   The regularization terms are means over the $K$ splats and $D$ dimensions, evaluated before any amplitude clamp $a_{max}$ is applied [S1, unofficial].

**Optional Boundary Term:**
An optional boundary-containment term $\mathcal{L}_{boundary}$ can be added with weight $\lambda_b$:

$$
\mathcal{L}_{boundary} = \sum_{k=1}^{K} \sum_{i=1}^{D} \left[ \max(0, r_{k,i} - \mu_{k,i})^2 + \max(0, r_{k,i} - (S_i - 1 - \mu_{k,i}))^2 \right]
$$

Where:
*   $r_{k,i} = \tau \sqrt{\sum_{j} L_{k,ij}}$ is the effective radius of splat $k$ along dimension $i$ at truncation threshold $\tau$.
*   $\mu_{k,i}$ is the center of the splat along dimension $i$.
*   $S_i$ is the volume extent along dimension $i$.
*   This term is disabled ($\lambda_b = 0$) in standard benchmarks [S1, unofficial].

**Parameters:**
*   Learning rate $lr = 0.01$ [S1, unofficial].
*   $\lambda_a = 10^{-3}$ [S1, unofficial].
*   $\lambda_d = 10^{-4}$ [S1, unofficial].
*   $\lambda_b = 0$ (disabled) [S1, unofficial].

**Pseudocode:**
```python
def regularised_gaussian_fitting_loss(predicted_volume, target_volume, amplitudes, diag_cov, lr, sigma_min, tau, centers, volume_extent, lambda_b=0):
    """
    Compute the Regularised Gaussian Fitting Loss.
    
    Args:
        predicted_volume: Tensor of rendered volume values.
        target_volume: Tensor of ground truth volume values.
        amplitudes: Tensor of shape (K,) containing splat amplitudes a_k.
        diag_cov: Tensor of shape (K, D) containing diagonal covariance entries L_{k,ii}.
        lr: Learning rate scalar.
        sigma_min: Float, floor for softplus-activated covariance.
        tau: Float, truncation threshold for effective radius.
        centers: Tensor of shape (K, D) containing splat centers mu_{k,i}.
        volume_extent: Tensor of shape (D,) containing volume sizes S_i.
        lambda_b: Float, weight for boundary term (default 0).
        
    Returns:
        loss: Scalar tensor.
    """
    # 1. L1 Reconstruction Loss
    # [G] Assuming element-wise L1 norm reduction
    l_recon = torch.mean(torch.abs(predicted_volume - target_volume))
    
    # 2. Amplitude Regularization
    # Weight lambda_a = 0.1 * lr
    lambda_a = 0.1 * lr
    l_amp = torch.mean(torch.abs(amplitudes))
    
    # 3. Extent (Diagonal Covariance) Regularization
    # Weight lambda_d = 0.01 * lr
    lambda_d = 0.01 * lr
    # [G] The source specifies the term is |L_{k,ii} - sigma_min|
    # evaluated on the softplus-activated parameters. 
    # Assuming diag_cov input is already the parameter value before clamp.
    l_ext = torch.mean(torch.abs(diag_cov - sigma_min))
    
    # 4. Boundary Containment (Optional)
    l_boundary = 0.0
    if lambda_b > 0:
        # Calculate effective radius r_{k,i} = tau * sqrt(sum_j L_{k,ij})
        # Note: Source uses sum_j L_{k,ij} inside sqrt. For diagonal covariance, 
        # this is just the specific diagonal entry if j=i, or sum of all if full.
        # Given "diagonal covariance" context, we assume L_{k,ij} is 0 for i!=j.
        # Thus sum_j L_{k,ij} = L_{k,ii}.
        effective_radii = tau * torch.sqrt(diag_cov) # Shape (K, D)
        
        mu = centers # Shape (K, D)
        S = volume_extent # Shape (D,)
        
        # Term 1: max(0, r - mu)^2
        term1 = torch.clamp(effective_radii - mu, min=0.0) ** 2
        
        # Term 2: max(0, r - (S - 1 - mu))^2
        # [G] S_i - 1 assumes 0-indexed volume coordinates of size S_i
        boundary_limit = S - 1 - mu
        term2 = torch.clamp(effective_radii - boundary_limit, min=0.0) ** 2
        
        l_boundary = torch.mean(term1 + term2)
        
    # 5. Total Loss
    loss = l_recon + (lambda_a * l_amp) + (lambda_d * l_ext) + (lambda_b * l_boundary)
    
    return loss
```

**Edge Cases and Pitfalls:**
*   **Amplitude Clamp:** The regularization is evaluated *before* the amplitude clamp $a_{max}$ is applied. This ensures the regularization weight does not scale with the number of splats $K$ as capacity is swept [S1, unofficial].
*   **Loss Selection:** L1 is preferred over MSE or Poisson deviance. L1 beats MSE on held-out PSNR for 11 of 17 tested volumes and never trails by more than 0.28 dB. MSE is not the best training-PSNR loss for these regularized, early-stopped fits [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear in the number of splats $K$ and dimensions $D$ for the regularization terms. The dominant cost is the reconstruction loss $\mathcal{L}_{recon}$, which depends on the rendering pipeline (e.g., ray marching or splatting).
*   **Memory Complexity:** $O(K \cdot D)$ to store the diagonal covariance and amplitude parameters. The regularization terms add negligible memory overhead.
*   **Performance:** The method is designed for early-stopped fits (e.g., 500 iterations). It achieves competitive PSNR while maintaining structural integrity.
*   **Strengths:** Prevents overfitting by penalizing large amplitudes and extreme extents. L1 reconstruction provides robustness to outliers.
*   **Limitations:** Requires tuning of $\lambda_a$ and $\lambda_d$ relative to the learning rate. The boundary term is optional and not standard in benchmarks.
*   **When to use:** When optimizing Gaussian splats for volumetric data where smoothness and physical plausibility of the Gaussian parameters are important, and when L1 reconstruction is preferred over MSE.

## Background
The Regularised Gaussian Fitting Loss was introduced in the context of "Luxar," a method for Gaussian splatting applied to microscopy and multidimensional scientific data visualization. It addresses the need for stable optimization of Gaussian representations in volumetric settings, where standard photometric losses alone may lead to unstable or overfitted splat parameters. The specific formulation with amplitude and extent regularization was detailed in the associated preprint [S1, unofficial].
