# MSE Loss and PSNR Conversion

Also called: Masked MSE and PSNR Computation, Masked Volume MSE/PSNR Computation, Mean Squared Error (MSE) Calculation, Mean Squared Error Loss, Photometric Loss Computation, img2mse

## Overview
This method computes the Mean Squared Error (MSE) between predicted and target RGB values (or volume voxels) to serve as the primary photometric loss for training neural volume rendering models, and converts this error into Peak Signal-to-Noise Ratio (PSNR) for logging and evaluation [S1, unofficial][S2, unofficial][S3, unofficial]. It distinguishes itself from structural metrics like SSIM by treating all pixel errors equally, making it sensitive to large smooth regions but less responsive to high-frequency details [S1, unofficial]. It also differs from perceptual losses by operating directly on raw intensity differences rather than high-level features [S1, unofficial].

## How it works
**Inputs:**
1.  `predicted_rgb`: Tensor of shape $(N, 3)$ or $(H, W, 3)$ containing predicted RGB values, typically normalized to $[0, 1]$.
2.  `target_rgb`: Tensor of the same shape containing ground-truth RGB values.
3.  `mask` (optional): Boolean tensor of the same spatial shape as the inputs, indicating valid pixels/voxels. If provided, only elements where `mask` is true are included in the loss calculation [S4, unofficial].

**Outputs:**
1.  `mse`: Scalar float representing the Mean Squared Error.
2.  `psnr`: Scalar float representing the Peak Signal-to-Noise Ratio.

**Data Structures:**
*   `predicted_rgb`, `target_rgb`: Floating-point tensors (typically `float32`).
*   `mask`: Boolean tensor. If not provided, it is implicitly all `True`.

**Steps:**

1.  **Compute Squared Error:** Calculate the element-wise squared difference between predicted and target values.
    $$
    \text{sq\_error}_i = (\text{predicted\_rgb}_i - \text{target\_rgb}_i)^2
    $$
    where $i$ indexes each pixel or voxel.

2.  **Apply Mask (Optional):** If a mask is provided, filter the squared errors to include only those where the mask is true. Let $M$ be the set of indices where the mask is true, and $N = |M|$ be the count of valid elements. If no mask is provided, $N$ is the total number of elements.
    $$
    \text{masked\_sq\_error}_i = \begin{cases} \text{sq\_error}_i & \text{if } i \in M \\ 0 & \text{otherwise} \end{cases}
    $$
    *Pitfall:* If $N=0$ (empty mask), raise a `RuntimeError` or handle appropriately to avoid division by zero [S4, unofficial].

3.  **Compute MSE:** Calculate the mean of the (masked) squared errors.
    $$
    MSE = \frac{1}{N} \sum_{i \in M} (\text{predicted\_rgb}_i - \text{target\_rgb}_i)^2
    $$
    [S1, unofficial][S4, unofficial]

4.  **Compute PSNR:** Convert MSE to PSNR.
    $$
    PSNR = \begin{cases} 20 \cdot \log_{10}\left(\frac{1}{\sqrt{MSE}}\right) & \text{if } MSE > 0 \\ \infty & \text{if } MSE = 0 \end{cases}
    $$
    This is equivalent to $-10 \cdot \log_{10}(MSE)$ [S1, unofficial][S4, unofficial].
    *Pitfall:* If $MSE=0$, PSNR is infinity. In practice, this may need to be capped or handled specifically to avoid numerical issues in logging [S4, unofficial].

**Pseudocode:**

```python
import math
import numpy as np

def compute_mse_and_psnr(predicted: np.ndarray, target: np.ndarray, mask: np.ndarray = None) -> tuple:
    """
    Computes MSE and PSNR between predicted and target arrays.
    
    Args:
        predicted: Array of predicted values (e.g., RGB images).
        target: Array of ground truth values.
        mask: Optional boolean array indicating valid pixels/voxels.
        
    Returns:
        mse: Mean Squared Error.
        psnr: Peak Signal-to-Noise Ratio.
    """
    # Step 1: Compute squared error
    sq_error = (predicted - target) ** 2
    
    # Step 2: Apply mask
    if mask is not None:
        # Ensure mask is boolean and has the same shape
        mask = np.asarray(mask, dtype=bool)
        if mask.shape != sq_error.shape:
            raise ValueError("Mask shape must match predicted/target shape")
        
        # Count valid elements
        n_valid = np.sum(mask)
        
        if n_valid == 0:
            raise RuntimeError("Mask has no true values (empty region)")
        
        # Compute mean over masked elements
        mse = np.sum(sq_error[mask]) / n_valid
    else:
        # No mask: mean over all elements
        mse = np.mean(sq_error)
        
    # Step 3: Compute PSNR
    if mse > 0:
        psnr = 20.0 * math.log10(1.0 / math.sqrt(mse))
    else:
        psnr = math.inf
        
    return mse, psnr
```

**Parameters:**
*   `mask_threshold_rel` (optional, for volume masks): Relative threshold applied to the normalized mask volume to create the boolean mask. Default value is `0.01` [S4, unofficial].
*   `batch_size`: Number of random pixels sampled per iteration for training [S3, unofficial].
*   `lr`: Adam learning rate used in the optimization step following loss computation [S3, unofficial].

**Edge Cases and Pitfalls:**
*   **Empty Mask:** If the boolean mask has no true values, the method should raise a `RuntimeError` [S4, unofficial].
*   **Zero MSE:** If the masked MSE is exactly 0.0, PSNR remains infinity to avoid division by zero in the log10 calculation [S4, unofficial].
*   **Precision:** Use floating-point arithmetic (e.g., `float32` or `float64`) to prevent precision loss during squaring and summation, especially for large images [S5, unofficial].

## Subtopics

### [PSNR Metric Calculation](2742-psnr-metric-calculation.md)
Peak Signal-to-Noise Ratio (PSNR) evaluates the quality of reconstructed images in novel view synthesis and volume rendering by comparing rendered output against ground-truth reference images. It quantifies the logarithmic ratio between the maximum possible pixel intensity and the Mean Squared Error (MSE) between the two images, providing a single scalar value where higher indicates better fidelity. Unlike structural metrics such as SSIM, PSNR measures pixel-level photometric error averaged over the entire frame, making it sensitive to large smooth regions but less responsive to small, high-frequency details like specular highlights.

### [SSIM Metric Calculation](3650-ssim-metric-calculation.md)
The Structural Similarity Index (SSIM) measures the perceived distortion between a rendered image and a ground truth image by comparing local patterns of pixel intensities, assuming the human visual system is highly adapted to structured natural scene information. It serves as a standard benchmark for image quality in radiance-field optimization, complementing pixel-wise metrics like MSE and PSNR. Unlike MSE, which treats all errors equally, SSIM accounts for luminance, contrast, and structural correlations, providing a value between -1 and 1 where 1 indicates identical images.

### [Normal-L2 Score Computation](3842-normal-l2-score-computation.md)
The Normal-L2 score evaluates surface geometry by computing the mean squared L2 distance between predicted surface normals and reference normals from a ground-truth mesh. It is computed only on the intersection of predicted and ground-truth masks, distinguishing it from silhouette metrics like iIoU which evaluate mask alignment separately.

### [Minkowski's Metric](4347-minkowski-s-metric.md)
Minkowski's Metric is a full-reference mathematical distance measure that treats images as 2D signals to quantify dissimilarity between a reference image $x$ and a test image $y$. It generalizes the Mean Squared Error (MSE) by allowing the exponent $\gamma$ to vary, thereby controlling the sensitivity to large errors versus small errors. Unlike its sibling [PSNR Metric Calculation](2742-psnr-metric-calculation.md) which is a logarithmic transformation of MSE, or [SSIM Metric Calculation](3650-ssim-metric-calculation.md) which models structural information, Minkowski's Metric operates directly on pixel-wise intensity differences.

### Masked Volume Metrics
A method to exclude empty froxels from evaluation metrics by including only froxels affected by radiance [S6, unofficial]. A froxel is included if any of its RGB channels contain a non-zero value at any point during the test scenario [S6, unofficial]. The Region of Interest (ROI) is computed separately for each tested algorithm, and the union of the scenario's ROI and the ground truth's ROI is used to create an effective ROI, ensuring only relevant froxels are included while excluding completely empty regions [S6, unofficial].
$$
ROI_{effective} = ROI_{scenario} \cup ROI_{truth}
$$
[S6, unofficial]

### MSE Bias-Variance Decomposition
Treating the TAA algorithm as a biased estimator to analyze correctness using Mean Squared Error (MSE), decomposed into variance and bias squared [S6, unofficial].
$$
MSE[F] = \mathbb{E}[(F - G)^2] = V[F] + \beta[F]^2
$$
where $F$ is the output of the estimator, $G$ is the true value (ground truth), $V[F]$ is the variance of the estimator, and $\beta[F]$ is its bias [S6, unofficial].

### Training Loss Computation with Huber and Masking
In some implementations, the Huber loss is used instead of MSE for robustness to outliers, combined with masking [S7, unofficial]. The predicted RGB is blended with the background to match rendering conditions, and per-ray Huber loss is computed with a delta parameter (e.g., 0.1), masked by ray validity, and averaged over valid rays [S7, unofficial].

### Area Loss Scaling
In multiscale datasets, the loss of each pixel is scaled by the area of that pixel's footprint in the original image to ensure low-resolution pixels have comparable influence to high-resolution pixels [S8]. For example, if an image is downsampled by a factor of 2, the area factor is 4, and the pixel loss is multiplied by 4 [S8].

## Operating characteristics
*   **Time Complexity:** $O(N)$, where $N$ is the number of pixels or voxels being compared. The computation involves element-wise subtraction, squaring, and summation [S5, unofficial].
*   **Memory Complexity:** $O(N)$ to store the squared error tensor if computed element-wise, or $O(1)$ if computed incrementally [S5, unofficial].
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Scales linearly with the number of pixels/voxels. For large volumes, masked computation reduces the effective $N$ to the number of non-empty froxels [S4, unofficial][S6, unofficial].
*   **Strengths:** Simple to implement, differentiable, and widely used as a baseline metric [S2, unofficial][S3, unofficial].
*   **Limitations:** Does not account for structural similarity or perceptual quality, potentially leading to optimized results that look blurry or lack high-frequency detail compared to SSIM or perceptual losses [S1, unofficial].
*   **When to use:** As a primary training loss for photometric consistency, or as a standard evaluation metric for comparing reconstruction accuracy [S2, unofficial][S3, unofficial].
*   **When not to use:** When structural fidelity or perceptual quality is more important than pixel-wise accuracy, or when dealing with scenes with significant occlusions or empty regions without masking [S1, unofficial][S4, unofficial].

## Background
The MSE loss and PSNR metric are foundational in image and volume processing. MSE was introduced as a standard error metric in signal processing [S1, unofficial]. PSNR is derived from MSE and is commonly used in image compression and reconstruction evaluation [S1, unofficial]. In the context of neural volume rendering, MSE loss was popularized by NeRF (Neural Radiance Fields) as the primary photometric loss for training [S2, unofficial][S3, unofficial]. Masked MSE/PSNR computation has been adapted for volumetric data to handle empty regions in froxel-based rendering [S4, unofficial][S6, unofficial].
