# MSE Loss and PSNR Conversion

Also called: Masked MSE and PSNR Computation, Masked Volume MSE/PSNR Computation, Mean Squared Error (MSE) Calculation, Mean Squared Error Loss, Photometric Loss Computation, img2mse

## Overview
This method computes the Mean Squared Error (MSE) between predicted and target RGB values to serve as the primary photometric loss for training neural volume rendering models, and converts this error into Peak Signal-to-Noise Ratio (PSNR) for logging and evaluation [S1, unofficial][S2, unofficial][S3, unofficial]. It differs from structural metrics like SSIM by treating all pixel errors equally based on intensity magnitude, and from distortion losses by operating directly on the final rendered color space rather than geometric parameters [S1, unofficial][S2, unofficial].

## How it works
**Inputs:**
*   `predicted_rgb`: Tensor of shape $(N, 3)$ or $(H, W, 3)$ containing predicted RGB values, typically normalized to $[0, 1]$.
*   `target_rgb`: Tensor of the same shape as `predicted_rgb` containing ground-truth RGB values.
*   `mask` (optional): Boolean tensor of shape $(N,)$ or $(H, W)$ indicating valid pixels/voxels. If provided, only elements where `mask` is true are included in the loss calculation [S4, unofficial].

**Outputs:**
*   `mse`: Scalar float representing the Mean Squared Error.
*   `psnr`: Scalar float representing the Peak Signal-to-Noise Ratio.

**Data Structures:**
*   The inputs are standard floating-point tensors (typically `float32`).
*   The mask is a boolean tensor. In volume rendering contexts, this may be derived from a density threshold or visibility mask [S4, unofficial].

**Steps:**

1.  **Compute Squared Errors:** Calculate the element-wise squared difference between predicted and target values.
    $$
    e_i = (p_i - t_i)^2
    $$
    where $p_i$ is the predicted value and $t_i$ is the target value for element $i$.

2.  **Apply Mask (Optional):** If a mask $M$ is provided, filter the errors. Let $I_{valid}$ be the set of indices where $M_i$ is true.
    $$
    e'_i = e_i \quad \text{for } i \in I_{valid}
    $$
    If no mask is provided, $I_{valid}$ includes all indices.

3.  **Compute MSE:** Calculate the mean of the squared errors over the valid set. Let $N$ be the number of valid elements ($|I_{valid}|$).
    $$
    MSE = \frac{1}{N} \sum_{i \in I_{valid}} (p_i - t_i)^2
    $$
    [S1, unofficial][S4, unofficial]

4.  **Compute PSNR:** Convert the MSE to PSNR.
    $$
    PSNR = 20 \cdot \log_{10}\left(\frac{1}{\sqrt{MSE}}\right) = -10 \cdot \log_{10}(MSE)
    $$
    [S1, unofficial][S4, unofficial]
    *Note:* The maximum possible pixel intensity is assumed to be 1.0 (consistent with normalized $[0,1]$ RGB data). If the data range is different, the formula adjusts to $20 \cdot \log_{10}(\frac{max\_val}{\sqrt{MSE}})$.

5.  **Edge Case Handling:**
    *   If $N = 0$ (no valid pixels/voxels), raise a `RuntimeError` or return undefined, as division by zero occurs in the mean calculation [S4, unofficial].
    *   If $MSE = 0$, $PSNR$ is mathematically infinity ($\infty$). In implementation, this is often represented as `float('inf')` or a large constant to avoid numerical issues in logging [S4, unofficial].

**Pseudocode:**

```python
import math
import numpy as np

def compute_mse_and_psnr(predicted: np.ndarray, target: np.ndarray, mask: np.ndarray = None) -> tuple:
    """
    Computes MSE and PSNR between predicted and target arrays.
    
    Args:
        predicted: Array of predicted values (e.g., RGB).
        target: Array of ground truth values.
        mask: Optional boolean array. If provided, only masked elements are used.
        
    Returns:
        mse: Mean Squared Error.
        psnr: Peak Signal-to-Noise Ratio.
    """
    # 1. Compute squared errors
    # Ensure inputs are floats to prevent overflow in subtraction if integers
    pred = np.asarray(predicted, dtype=np.float32)
    tgt = np.asarray(target, dtype=np.float32)
    
    squared_errors = (pred - tgt) ** 2
    
    # 2. Apply mask
    if mask is not None:
        # Broadcast mask if necessary, assuming mask matches spatial dimensions
        # For simplicity, assuming mask is boolean and compatible with pred/tgt shape
        masked_errors = squared_errors[mask]
        n_valid = np.sum(mask)
    else:
        masked_errors = squared_errors.flatten()
        n_valid = masked_errors.size
        
    # 3. Edge case: No valid elements
    if n_valid == 0:
        raise RuntimeError("Mask contains no valid elements (N=0). Cannot compute MSE.")
        
    # 4. Compute MSE
    mse = np.mean(masked_errors)
    
    # 5. Compute PSNR
    # Handle zero MSE to avoid log(0)
    if mse == 0.0:
        psnr = float('inf')
    else:
        # PSNR = 20 * log10(1 / sqrt(MSE)) = -10 * log10(MSE)
        psnr = -10.0 * math.log10(mse)
        
    return mse, psnr
```

**Parameters:**
*   `mask_threshold_rel` (optional): Used in volume rendering to generate the boolean mask from a density or opacity volume. It is a relative threshold applied to the maximum value of the mask volume. Default value is `0.01` [S4, unofficial].
*   `batch_size`: Number of random pixels or rays sampled per iteration for loss computation [S3, unofficial].

**Pitfalls:**
*   **Division by Zero:** If the mask excludes all pixels, the mean calculation fails. Always check $N > 0$ [S4, unofficial].
*   **Log of Zero:** If the prediction perfectly matches the target, $MSE=0$, leading to $\log(0)$. Handle this by returning infinity or a capped value [S4, unofficial].
*   **Dynamic Range:** The standard PSNR formula assumes a maximum pixel value of 1.0. If inputs are in $[0, 255]$, the formula must be adjusted to $20 \cdot \log_{10}(255/\sqrt{MSE})$ [S1, unofficial]. Most modern NeRF implementations normalize to $[0,1]$, so the $1/\sqrt{MSE}$ form is standard [S1, unofficial][S4, unofficial].

## Subtopics

### [PSNR Metric Calculation](2742-psnr-metric-calculation.md)
Peak Signal-to-Noise Ratio (PSNR) evaluates the quality of reconstructed images in novel view synthesis and volume rendering by comparing rendered output against ground-truth reference images. It quantifies the logarithmic ratio between the maximum possible pixel intensity and the Mean Squared Error (MSE) between the two images, providing a single scalar value where higher indicates better fidelity. Unlike structural metrics such as SSIM, PSNR measures pixel-level photometric error averaged over the entire frame, making it sensitive to large smooth regions but less responsive to small, high-frequency details like specular highlights.

### [SSIM Metric Calculation](3650-ssim-metric-calculation.md)
The Structural Similarity Index (SSIM) measures the perceived distortion between a rendered image and a ground truth image by comparing local patterns of pixel intensities, assuming the human visual system is highly adapted to structured natural scene information. It serves as a standard benchmark for image quality in radiance-field optimization, complementing pixel-wise metrics like MSE and PSNR. Unlike MSE, which treats all errors equally, SSIM accounts for luminance, contrast, and structural correlations, providing a value between -1 and 1 where 1 indicates identical images.

### [Normal-L2 Score Computation](3842-normal-l2-score-computation.md)
The Normal-L2 score evaluates surface geometry by computing the mean squared L2 distance between predicted surface normals and reference normals from a ground-truth mesh. It is computed only on the intersection of predicted and ground-truth masks, distinguishing it from silhouette metrics like iIoU which evaluate mask alignment separately.

### [Minkowski's Metric](4347-minkowski-s-metric.md)
Minkowski's Metric is a full-reference mathematical distance measure that treats images as 2D signals to quantify dissimilarity between a reference image $x$ and a test image $y$. It generalizes the Mean Squared Error (MSE) by allowing the exponent $\gamma$ to vary, thereby controlling the sensitivity to large errors versus small errors. Unlike its sibling [PSNR Metric Calculation](2742-psnr-metric-calculation.md) which is a logarithmic transformation of MSE, or [SSIM Metric Calculation](3650-ssim-metric-calculation.md) which models structural information, Minkowski's Metric operates directly on pixel-wise intensity differences.

### Masked Volume Metrics
A method to exclude empty froxels from evaluation metrics by including only froxels affected by radiance [S6, unofficial]. A froxel is included if any of its RGB channels contain a non-zero value at any point during the test scenario [S6, unofficial]. The Region of Interest (ROI) is computed separately for each tested algorithm; the union of the scenario's ROI and the ground truth's ROI is used to create an effective ROI, ensuring that only relevant froxels are included while excluding completely empty regions [S6, unofficial].
$$
ROI_{effective} = ROI_{scenario} \cup ROI_{truth}
$$
[S6, unofficial]

### MSE Bias-Variance Decomposition
Treating the TAA (Temporal Anti-Aliasing) algorithm as a biased estimator to analyze correctness using Mean Squared Error (MSE), decomposed into variance and bias squared [S6, unofficial]. This decomposition helps distinguish between constant reconstruction errors (ghosting, behaving as bias) and temporal instability (flickering, behaving as variance) [S6, unofficial].
$$
MSE[F] = \mathbb{E}[(F - G)^2] = V[F] + \beta[F]^2
$$
where $F$ is the output of the estimator, $G$ is the true value (ground truth), $V[F]$ is the variance of the estimator, and $\beta[F]$ is its bias [S6, unofficial].

### Training Loss Computation with Huber and Masking
An extension of MSE loss that uses Huber loss for RGB with masking by ray validity. It renders predicted RGB and depth, splits the tensor, blends ground truth RGB with background, and computes per-ray Huber loss (delta=0.1) masked by `ray_is_valid`, averaged over valid rays [S7, unofficial].

### Area Loss Scaling
Scaling the loss of each pixel by the area of that pixel's footprint in the original image to ensure low-resolution pixels have comparable influence to high-resolution pixels in multiscale datasets [S8]. For a downsampling factor of $k$, the area scaling factor is $k^2$ (e.g., factor 2 -> area factor 4) [S8].

## Operating characteristics
*   **Time Complexity:** $O(N)$, where $N$ is the number of pixels or voxels in the batch/mask. The computation involves element-wise subtraction, squaring, and reduction (mean).
*   **Memory Complexity:** $O(N)$ to store the squared errors before reduction, or $O(1)$ if computed in a streaming/reduction fashion.
*   **Strengths:** Simple to implement, differentiable everywhere (except at MSE=0 for PSNR, which is handled by infinity), and widely used as a baseline for photometric fidelity [S2, unofficial][S3, unofficial].
*   **Limitations:** Does not account for structural similarity or perceptual quality, often leading to blurry results compared to SSIM or perceptual losses [S1, unofficial]. Sensitive to outliers and large smooth regions [S1, unofficial].
*   **When to use:** Standard training loss for initial convergence, baseline evaluation metric, or when structural details are less critical than color accuracy.
*   **When not to use:** When perceptual quality is paramount (use SSIM/Perceptual), or when dealing with geometric consistency (use Normal-L2/Chamfer).

## Background
The MSE loss and PSNR metric are foundational in image processing and computer vision. In the context of neural volume rendering, they were popularized by the original NeRF paper and subsequent implementations [S1, unofficial][S2, unofficial]. The `img2mse` function is a standard utility in many NeRF codebases [S1, unofficial]. The masked volume variant is used in more advanced volume rendering pipelines to ignore empty space [S4, unofficial]. The bias-variance decomposition is applied in the context of temporal anti-aliasing for volumetric rendering [S6, unofficial].
