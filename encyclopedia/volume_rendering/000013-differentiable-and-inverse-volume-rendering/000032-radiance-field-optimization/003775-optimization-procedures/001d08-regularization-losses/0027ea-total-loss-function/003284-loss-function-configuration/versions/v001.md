# Loss Function Configuration

Also called: Loss Weighting Scheme, Training Loss Weights

## Overview
This method defines the scalar weights applied to individual loss components within a composite objective function for differentiable volume rendering. It solves the problem of balancing competing optimization goals—such as photometric fidelity, geometric consistency, and regularization—by tuning their relative influence on the gradient updates. It differs from sibling methods like [Composite Image Loss with Visibility Weighting](4262-composite-image-loss-with-visibility-weighting.md), which modulates loss per-pixel based on visibility, and [Sparse Depth Consistency Loss](7294-sparse-depth-consistency-loss.md), which provides a specific geometric constraint, by focusing on the global scalar coefficients that determine the magnitude of each loss term's contribution to the total loss.

## How it works
The configuration specifies the weights $w_i$ for each loss term $\mathcal{L}_i$ in the total loss function $\mathcal{L}$. The implementation requires selecting a weight set appropriate for the training stage (coarse vs. fine) and the scene characteristics (static vs. dynamic).

**Inputs:**
- Training stage identifier (e.g., 'coarse', 'fine').
- Scene motion magnitude indicator (e.g., 'large motion', 'static').

**Outputs:**
- Dictionary or tuple of weights $\{w_{ptc}, w_{bg}, w_{d\_norm}, w_{d\_tv}\}$ or $\{\lambda\}$ depending on the specific loss formulation being used.

**Data Structures:**
- Weight Map: A simple mapping from loss component name to float value.

**Steps:**
1. Determine the current training stage.
2. If the stage is 'coarse':
   - Set $w_{ptc} = 0.1$ [S1].
   - Set $w_{bg} = 0.01$ [S1].
   - Set $w_{d\_norm} = 0.1$ [S1].
   - Set $w_{d\_tv} = 1$ [S1].
3. If the stage is 'fine':
   - Set $w_{ptc} = 0.01$ [S1].
   - Set $w_{bg} = 0.001$ [S1].
   - Set $w_{d\_tv} = 1$ [S1].
4. Check for large motion scenes (e.g., 'Hell Warrior', 'Jumping Jacks', 'T-Rex') [S1].
5. If large motion is detected:
   - If stage is 'coarse', override $w_{d\_norm} = 0.01$ [S1].
   - If stage is 'fine', override $w_{d\_norm} = 0.001$ [S1].
6. Return the configured weights.

**Formulas:**
The total loss is computed as [S1]:
$$
\mathcal{L} = \mathcal{L}_{photo} + w_{ptc} \cdot \mathcal{L}_{ptc} + w_{bg} \cdot \mathcal{L}_{bg} + w_{d\_norm} \cdot \mathcal{L}_{d\_norm} + w_{d\_tv} \cdot \mathcal{L}_{d\_tv}
$$
Where:
- $\mathcal{L}_{photo}$: Photometric loss.
- $\mathcal{L}_{ptc}$: Point cloud consistency loss.
- $\mathcal{L}_{bg}$: Background loss.
- $\mathcal{L}_{d\_norm}$: Deformation norm regularization.
- $\mathcal{L}_{d\_tv}$: Total variation regularization.

**Pseudocode:**
```python
def get_loss_weights(stage: str, is_large_motion: bool) -> dict:
    """
    Returns loss weights for Neural Deformable Voxel Grid training.
    
    Args:
        stage: 'coarse' or 'fine'
        is_large_motion: True for scenes like 'Hell Warrior', 'Jumping Jacks', 'T-Rex'
        
    Returns:
        Dictionary with keys 'w_ptc', 'w_bg', 'w_d_norm', 'w_d_tv'
    """
    weights = {}
    
    if stage == 'coarse':
        weights['w_ptc'] = 0.1
        weights['w_bg'] = 0.01
        weights['w_d_tv'] = 1.0
        weights['w_d_norm'] = 0.1
    elif stage == 'fine':
        weights['w_ptc'] = 0.01
        weights['w_bg'] = 0.001
        weights['w_d_tv'] = 1.0
        weights['w_d_norm'] = 0.01
    else:
        raise ValueError(f"Unknown stage: {stage}")
        
    if is_large_motion:
        if stage == 'coarse':
            weights['w_d_norm'] = 0.01
        elif stage == 'fine':
            weights['w_d_norm'] = 0.001
            
    return weights
```

**Parameters:**
- $w_{ptc}$: Point cloud consistency weight.
- $w_{bg}$: Background loss weight.
- $w_{d\_norm}$: Deformation norm regularization weight.
- $w_{d\_tv}$: Total variation regularization weight.

**Edge Cases:**
- **Large Motion:** Using standard weights for scenes with large motion (e.g., 'Hell Warrior') leads to suboptimal results; $w_{d\_norm}$ must be reduced [S1].
- **Stage Transition:** Weights for $w_{ptc}$, $w_{bg}$, and $w_{d\_norm}$ are significantly smaller in the fine stage compared to the coarse stage to refine geometry without over-constraining [S1].

## Subtopics

### Loss Weight Configuration
A specific configuration study for Generative Volume Rendering focusing on the balance between L1 loss and Adversarial loss [S2]. It determines the optimal weight $\lambda$ for the L1 loss contribution relative to the adversarial loss [S2]. Tested values are $\lambda \in \{50, 150, 450\}$ [S2]. These correspond to L1 contributions of $1/3\times$, $1\times$, and $3\times$ the adversarial loss, respectively [S2]. The primary pitfall is that precisely setting $\lambda$ is challenging due to the dynamics of training GANs [S2]. In experiments on Combustion and Foot datasets (256x256, no illumination), $\lambda=150$ provided a compromise between detail preservation and color accuracy, while $\lambda=450$ failed to preserve highlighted details and $\lambda=50$ caused color shifts [S2].

## Operating characteristics
- **Time Complexity:** Negligible; weight configuration is a static lookup or simple conditional check performed once per stage or scene initialization.
- **Memory Complexity:** $O(1)$; stores a fixed number of scalar weights.
- **Performance Impact:** Incorrect weighting leads to slow convergence or poor quality. For NDVG, reducing $w_{d\_norm}$ for large motion scenes prevents over-regularization of deformation [S1]. For GAN-based volume rendering, higher $\lambda$ generally decreases RMSE but may blur details [S2].
- **Strengths:** Simple to implement; allows fine-tuning of trade-offs between photometric and geometric/regularization terms.
- **Limitations:** Requires empirical tuning; values may not transfer across different scene types or network architectures [S1, S2].

## Background
The configuration for Neural Deformable Voxel Grid (NDVG) was introduced in 2022 by the authors of "Neural Deformable Voxel Grid for Fast Optimization of Dynamic View Synthesis" [S1]. It addresses the need for coarse-to-fine optimization strategies where different stages require different regularization strengths [S1]. The GAN-based volume rendering configuration was introduced in 2018 by the authors of "A Generative Model for Volume Rendering" [S2], addressing the stability issues inherent in combining adversarial and reconstruction losses in volumetric GANs.
