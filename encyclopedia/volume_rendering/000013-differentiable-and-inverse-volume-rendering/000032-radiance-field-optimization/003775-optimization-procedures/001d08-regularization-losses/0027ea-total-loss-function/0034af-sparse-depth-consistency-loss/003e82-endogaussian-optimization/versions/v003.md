# EndoGaussian Optimization

## Overview
EndoGaussian Optimization is a training procedure for dynamic endoscopic scene reconstruction using 3D Gaussians, designed to handle non-rigid tissue deformation and tool occlusion in real-time [S1, unofficial]. It distinguishes itself from standard Gaussian Splatting by incorporating binocular and monocular depth constraints alongside spatiotemporal Total Variation (TV) regularization, specifically tailored for endoscopic video sequences where absolute depth consistency is challenging but structural coherence is critical [S1, unofficial]. The method employs a warmup phase for canonical Gaussians followed by joint optimization of the full deformable framework [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs:** A sequence of endoscopic images (RGB and depth, if available), binary tool masks $\mathbf{M}$, and camera poses [S1, unofficial].
*   **Outputs:** Optimized 3D Gaussian parameters (position, rotation, scale, opacity) that minimize the total loss $\mathcal{L}$ [S1, unofficial].

**Data Structures**
The method operates on a set of 3D Gaussians [S1, unofficial]. Each Gaussian $i$ is defined by position $\mathbf{p}_i \in \mathbb{R}^3$, rotation $\mathbf{q}_i \in \mathbb{R}^4$ (quaternion), scale $\mathbf{s}_i \in \mathbb{R}^3$, opacity $\alpha_i \in [0, 1]$, and spherical harmonic coefficients for color $\mathbf{c}_i$ [G]. The source explicitly notes that deformation of SH coefficients is not modeled, as position, rotation, scaling, and opacity are sufficient to capture tissue movement and shape variations [S1, unofficial].

**Numbered Steps**
1.  **Initialization:** Randomly sample 0.1% of the initial point cloud points to reduce redundancy and computational load [S1, unofficial].
2.  **Warmup:** Optimize the Canonical Gaussians (static representation) for 1,000 iterations [S1, unofficial].
3.  **Main Optimization:** Optimize the entire framework (including deformation fields and all Gaussian parameters) for 3,000 iterations using the Adam optimizer [S1, unofficial].

**Formulas**
The total loss $\mathcal{L}$ is a weighted sum of rendering constraints and spatiotemporal smoothness constraints [S1, unofficial]:
$$
\mathcal{L} = (\lambda_1 \mathcal{L}_{color} + \lambda_2 \mathcal{L}_{depth}^{-1} / \mathcal{L}_{depth}^{-1}) + (\lambda_3 \mathcal{L}_{spatial} + \lambda_4 \mathcal{L}_{temporal})
$$
Where $\lambda_1, \lambda_2, \lambda_3, \lambda_4$ are balancing weights [S1, unofficial]. The notation $\mathcal{L}_{depth}^{-1} / \mathcal{L}_{depth}^{-1}$ in the source denotes the combined binocular and monocular depth loss terms [S1, unofficial].

**Rendering Constraints:**
*   **Color Loss:** Minimizes the difference between predicted and real colors, masked by tool occlusion [S1, unofficial]:
    $$
    \mathcal{L}_{color} = \sum_{\mathbf{x} \in \mathcal{I}} \|\mathbf{M}(\mathbf{x})(\hat{\mathbf{C}}(\mathbf{x}) - \mathbf{C}(\mathbf{x}))\|_1
    $$
*   **Binocular Depth Loss:** Uses reciprocal depth for stability, masked by tool occlusion [S1, unofficial]:
    $$
    \mathcal{L}_{depth}^B = \sum_{\mathbf{x} \in \mathcal{I}} \|\mathbf{M}(\mathbf{x})(\hat{\mathbf{D}}^{-1}(\mathbf{x}) - \mathbf{D}^{-1}(\mathbf{x}))\|_1
    $$
*   **Monocular Depth Loss:** Uses correlation to align structure despite absolute depth inconsistencies, masked by tool occlusion [S1, unofficial]:
    $$
    \mathcal{L}_{depth}^M = 1 - \frac{Cov(\mathbf{M} \odot \hat{\mathbf{D}}, \mathbf{M} \odot \mathbf{D})}{\sqrt{Var(\mathbf{M} \odot \hat{\mathbf{D}})Var(\mathbf{M} \odot \mathbf{D})}}
    $$
*   **Depth Term in Total Loss:** The source notation $\mathcal{L}_{depth}^{-1} / \mathcal{L}_{depth}^{-1}$ appears to be a typographical error in the source text for a combined depth loss term (likely $\mathcal{L}_{depth}^B + \mathcal{L}_{depth}^M$ or similar) [S1, unofficial]. Given the context of "binocular/monocular input image sequence," the implementation should combine the binocular and monocular depth losses [S1, unofficial].

**Regularization Constraints:**
*   **Spatial TV Loss:** Enforces smoothness in predicted color and reciprocal depth to avoid black/white holes in tool-occluded regions [S1, unofficial]:
    $$
    \mathcal{L}_{spatial} = TV(\hat{\mathbf{C}}) + TV(\hat{\mathbf{D}}^{-1})
    $$
*   **Temporal TV Loss:** Constrains encoding voxels over time to ensure temporal smoothness [S1, unofficial].

**Parameters**
*   **Optimizer:** Adam [S1, unofficial].
*   **Initial Learning Rate:** $1.6 \times 10^{-3}$ [S1, unofficial].
*   **Warmup Iterations:** 1,000 [S1, unofficial].
*   **Main Optimization Iterations:** 3,000 [S1, unofficial].
*   **Balancing Weights ($\lambda_i$):** Not given in the sources [S1, unofficial].

**Pseudocode**
```python
import math
import random

def endo_gaussian_optimization(initial_points, images, masks, poses, binocular_depths, monocular_depths, 
                               num_warmup=1000, num_main=3000, lr=1.6e-3, lam1=1.0, lam2=1.0, lam3=1.0, lam4=1.0):
    # Step 1: Initialization
    # Randomly sample 0.1% of points to reduce redundancy
    sample_count = max(1, int(len(initial_points) * 0.001))
    sampled_points = random.sample(initial_points, sample_count)
    gaussians = initialize_gaussians(sampled_points)
    
    # Sources do not provide the Gaussian rasterization or initialization routines; 
    # these follow standard 3D Gaussian Splatting implementations [G].
    
    optimizer = AdamOptimizer(gaussians.parameters(), lr=lr)
    prev_rendered_depth_inv = None
    
    # Step 2: Warmup
    # Optimize Canonical Gaussians for 1k iterations
    for _ in range(num_warmup):
        optimizer.zero_grad()
        rendered_color, rendered_depth_inv = render_canonical(gaussians, poses)
        loss = compute_color_loss(rendered_color, images, masks)
        loss.backward()
        optimizer.step()
        
    # Step 3: Main Optimization
    # Optimize the whole framework for 3k iterations
    for _ in range(num_main):
        optimizer.zero_grad()
        total_loss = 0.0
        
        for img, mask, pose, b_depth, m_depth in zip(images, masks, poses, binocular_depths, monocular_depths):
            # Render current frame with deformation
            rendered_color, rendered_depth, rendered_depth_inv = render_deformable(gaussians, pose)
            
            # Rendering Constraints
            # Color Loss
            l_color = sum_l1_norm(mask * (rendered_color - img))
            
            # Binocular Depth Loss (using reciprocal depth)
            l_depth_b = sum_l1_norm(mask * (rendered_depth_inv - b_depth))
            
            # Monocular Depth Loss (using correlation)
            masked_pred = mask * rendered_depth
            masked_real = mask * m_depth
            cov = covariance(masked_pred, masked_real)
            var_pred = variance(masked_pred)
            var_real = variance(masked_real)
            l_depth_m = 1.0 - cov / math.sqrt(var_pred * var_real)
            
            # Combine depth losses (correcting source notation typo)
            l_depth = l_depth_b + l_depth_m
            
            # Regularization Constraints
            # Spatial TV Loss
            l_spatial = total_variation(rendered_color) + total_variation(rendered_depth_inv)
            
            # Temporal TV Loss
            if prev_rendered_depth_inv is not None:
                l_temporal = total_variation_temporal(rendered_depth_inv, prev_rendered_depth_inv)
            else:
                l_temporal = 0.0
                
            # Total Loss for this frame
            frame_loss = (lam1 * l_color + lam2 * l_depth + lam3 * l_spatial + lam4 * l_temporal)
            total_loss += frame_loss
            
        total_loss.backward()
        optimizer.step()
        prev_rendered_depth_inv = rendered_depth_inv
        
    return gaussians

class AdamOptimizer:
    def __init__(self, params, lr, beta1=0.9, beta2=0.999, eps=1e-8):
        self.params = params
        self.lr = lr
        self.beta1 = beta1
        self.beta2 = beta2
        self.eps = eps
        self.state = {}
    def zero_grad(self):
        for p in self.params:
            if p.grad is not None:
                p.grad.detach_()
                p.grad.zero_()
    def step(self):
        for p in self.params:
            if p.grad is None: continue
            g = p.grad
            if p not in self.state:
                self.state[p] = {'m': [0.0]*len(p), 'v': [0.0]*len(p), 't': 0}
            state = self.state[p]
            state['t'] += 1
            for i in range(len(p)):
                state['m'][i] = self.beta1 * state['m'][i] + (1 - self.beta1) * g[i]
                state['v'][i] = self.beta2 * state['v'][i] + (1 - self.beta2) * g[i]**2
                m_hat = state['m'][i] / (1 - self.beta1**state['t'])
                v_hat = state['v'][i] / (1 - self.beta2**state['t'])
                p[i] -= self.lr * m_hat / (math.sqrt(v_hat) + self.eps)

def compute_color_loss(rendered, targets, masks): return sum_l1_norm(masks * (rendered - targets))
def sum_l1_norm(tensor): return sum(abs(x) for x in tensor)
def covariance(a, b):
    mean_a = sum(a) / len(a)
    mean_b = sum(b) / len(b)
    return sum((a[i] - mean_a) * (b[i] - mean_b) for i in range(len(a))) / len(a)
def variance(tensor):
    mean = sum(tensor) / len(tensor)
    return sum((x - mean) ** 2 for x in tensor) / len(tensor)
def total_variation(tensor):
    return sum(abs(tensor[i+1] - tensor[i]) for i in range(len(tensor)-1))
def total_variation_temporal(curr, prev):
    return sum(abs(curr[i] - prev[i]) for i in range(len(curr)))
```

**Edge Cases and Pitfalls**
*   **Tool Occlusion:** The binary tool mask $\mathbf{M}$ is critical [S1, unofficial]. Failure to correctly mask tool regions leads to artifacts in color and depth, as the model tries to fit non-existent tissue behind the tool [S1, unofficial].
*   **Depth Scale Ambiguity:** Monocular depth loss uses correlation, which is invariant to scale and shift [S1, unofficial]. This is necessary because absolute depth from monocular cues is inconsistent [S1, unofficial]. However, this means the method cannot recover absolute metric depth from monocular data alone [S1, unofficial].
*   **Reciprocal Depth Stability:** Binocular depth loss uses reciprocal depth ($\mathbf{D}^{-1}$) for stability [S1, unofficial]. Implementers must ensure numerical stability when computing reciprocals for near-zero depth values [S1, unofficial].
*   **Deformation Modeling:** The method does not model deformation of SH coefficients, assuming position, rotation, scale, and opacity are sufficient for tissue movement [S1, unofficial]. This simplification may limit high-frequency appearance changes [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The method is optimized for real-time performance [S1, unofficial]. Training takes approximately 4,000 iterations (1k warmup + 3k main) [S1, unofficial].
*   **Memory Complexity:** Uses a single RTX 4090 GPU for training [S1, unofficial].
*   **Performance:** Achieves real-time inference speeds (FPS) comparable to or better than previous SOTA methods like EndoNeRF and EndoSurf, which require hours for optimization [S1, unofficial].
*   **Strengths:** Handles non-rigid deformation and tool occlusion effectively [S1, unofficial]. Real-time capability [S1, unofficial].
*   **Limitations:** Relies on accurate tool masks [S1, unofficial]. Monocular depth is relative [S1, unofficial].

## Background
EndoGaussian Optimization was introduced in the paper "EndoGaussian: Real-time Gaussian Splatting for Dynamic Endoscopic Scene Reconstruction" [S1, unofficial]. The method was evaluated on the ENDONERF and SCARED datasets, which contain in-vivo prostatectomy data and porcine cadaver abdominal anatomies, respectively [S1, unofficial].
