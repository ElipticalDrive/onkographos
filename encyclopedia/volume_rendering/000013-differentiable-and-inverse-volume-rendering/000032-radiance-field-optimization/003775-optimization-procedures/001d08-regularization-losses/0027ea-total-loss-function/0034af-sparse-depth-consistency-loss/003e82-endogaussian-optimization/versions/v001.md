# EndoGaussian Optimization

Also called: EndoGaussian optimization framework, spatiotemporal TV regularized Gaussian splatting optimization

## Overview
EndoGaussian Optimization is a training procedure for dynamic endoscopic scene reconstruction using 3D Gaussians, designed to handle non-rigid tissue deformation and tool occlusion in real-time [S1, unofficial]. It distinguishes itself from standard Gaussian Splatting by incorporating binocular and monocular depth constraints alongside spatiotemporal Total Variation (TV) regularization, specifically tailored for endoscopic video sequences where absolute depth consistency is challenging but structural coherence is critical [S1, unofficial]. Unlike static splatting methods, it employs a warmup phase for canonical Gaussians followed by joint optimization of the full deformable framework [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs:** A sequence of endoscopic images (RGB and depth, if available), binary tool masks $\mathbf{M}$, and camera poses.
*   **Outputs:** Optimized 3D Gaussian parameters (position, rotation, scale, opacity, SH coefficients) and deformation fields that minimize the total loss $\mathcal{L}$ [S1, unofficial].

**Data Structures**
The method operates on a set of 3D Gaussians. Each Gaussian $i$ is defined by:
*   Position $\mathbf{p}_i \in \mathbb{R}^3$
*   Rotation $\mathbf{q}_i \in \mathbb{R}^4$ (quaternion)
*   Scale $\mathbf{s}_i \in \mathbb{R}^3$
*   Opacity $\alpha_i \in [0, 1]$
*   Spherical Harmonic coefficients for color $\mathbf{c}_i$
*   Deformation parameters (implicit in the canonical-to-world mapping) [S1, unofficial].

**Numbered Steps**
1.  **Initialization:** Randomly sample 0.1% of the initial point cloud points to reduce redundancy and computational load [S1, unofficial].
2.  **Warmup:** Optimize the Canonical Gaussians (static representation) for 1,000 iterations [S1, unofficial].
3.  **Main Optimization:** Optimize the entire framework (including deformation fields and all Gaussian parameters) for 3,000 iterations using the Adam optimizer [S1, unofficial].

**Formulas**
The total loss $\mathcal{L}$ is a weighted sum of rendering constraints and spatiotemporal smoothness constraints [S1, unofficial]:

$$
\mathcal{L} = (\lambda_1 \mathcal{L}_{color} + \lambda_2 \mathcal{L}_{depth}^{-1} / \mathcal{L}_{depth}^{-1}) + (\lambda_3 \mathcal{L}_{spatial} + \lambda_4 \mathcal{L}_{temporal})
$$

Where $\lambda_1, \lambda_2, \lambda_3, \lambda_4$ are balancing weights [S1, unofficial].

**Rendering Constraints:**
*   **Color Loss:** Minimizes the difference between predicted and real colors, masked by tool occlusion [S1, unofficial]:
    $$
    \mathcal{L}_{color} = \sum_{\mathbf{x} \in \mathcal{I}} \|\mathbf{M}(\mathbf{x})(\hat{\mathbf{C}}(\mathbf{x}) - \mathbf{C}(\mathbf{x}))\|_1
    $$
*   **Binocular Depth Loss:** Uses reciprocal depth for stability, masked by tool occlusion [S1, unofficial]:
    $$
    \mathcal{L}_{depth}^B = \sum_{\mathbf{x} \in \mathcal{I}} \|\mathbf{M}(\mathbf{x})(\hat{\mathbf{D}}^{-1}(\mathbf{x}) - \mathbf{D}^{-1}(\mathbf{x}))\|_1
    $$
*   **Monocular Depth Loss:** Uses correlation to align structure despite absolute depth inconsistencies, masked by tool occlusion [S1, unofficial]:
    $$
    \mathcal{L}_{depth}^M = 1 - \frac{Cov(\mathbf{M} \odot \hat{\mathbf{D}}, \mathbf{M} \odot \mathbf{D})}{\sqrt{Var(\mathbf{M} \odot \hat{\mathbf{D}})Var(\mathbf{M} \odot \mathbf{D})}}
    $$
*   **Depth Term in Total Loss:** The source notation $\mathcal{L}_{depth}^{-1} / \mathcal{L}_{depth}^{-1}$ appears to be a typographical error in the source text for a combined depth loss term (likely $\mathcal{L}_{depth}^B + \mathcal{L}_{depth}^M$ or similar). Given the context of "binocular/monocular input image sequence," the implementation should combine the binocular and monocular depth losses. [S1, unofficial].

**Regularization Constraints:**
*   **Spatial TV Loss:** Enforces smoothness in predicted color and reciprocal depth to avoid black/white holes in tool-occluded regions [S1, unofficial]:
    $$
    \mathcal{L}_{spatial} = TV(\hat{\mathbf{C}}) + TV(\hat{\mathbf{D}}^{-1})
    $$
*   **Temporal TV Loss:** Constrains encoding voxels over time to ensure temporal smoothness [S1, unofficial].

**Parameters**
*   **Optimizer:** Adam [S1, unofficial].
*   **Initial Learning Rate:** $1.6 \times 10^{-3}$ [S1, unofficial].
*   **Warmup Iterations:** 1,000 [S1, unofficial].
*   **Main Optimization Iterations:** 3,000 [S1, unofficial].
*   **Balancing Weights ($\lambda_i$):** Not given in the sources. [S1, unofficial].

**Pseudocode**
```python
def endo_gaussian_optimization(initial_points, images, masks, poses, num_warmup=1000, num_main=3000, lr=1.6e-3):
    """
    Optimizes EndoGaussian parameters.
    
    Args:
        initial_points: Initial 3D point cloud.
        images: Sequence of RGB images.
        masks: Sequence of binary tool masks.
        poses: Camera poses for each image.
        num_warmup: Number of warmup iterations.
        num_main: Number of main optimization iterations.
        lr: Initial learning rate.
        
    Returns:
        Optimized Gaussian parameters.
    """
    # Step 1: Initialization
    # Randomly sample 0.1% of points to reduce redundancy
    sampled_points = random_sample(initial_points, fraction=0.001)
    gaussians = initialize_gaussians(sampled_points)
    
    # Step 2: Warmup
    # Optimize Canonical Gaussians for 1k iterations
    optimizer = Adam(gaussians.parameters(), lr=lr)
    for i in range(num_warmup):
        optimizer.zero_grad()
        # Render canonical view
        rendered_color, rendered_depth_inv = render_canonical(gaussians, poses)
        # Compute loss (simplified, assuming canonical loss is similar to main but static)
        loss = compute_color_loss(rendered_color, images, masks)
        loss.backward()
        optimizer.step()
        
    # Step 3: Main Optimization
    # Optimize the whole framework for 3k iterations
    for i in range(num_main):
        optimizer.zero_grad()
        total_loss = 0.0
        
        for img, mask, pose in zip(images, masks, poses):
            # Render current frame with deformation
            rendered_color, rendered_depth, rendered_depth_inv = render_deformable(gaussians, pose)
            
            # Rendering Constraints
            # Color Loss
            l_color = sum_l1_norm(mask * (rendered_color - img))
            
            # Binocular Depth Loss (using reciprocal depth)
            # Note: Requires binocular depth input D_inv
            if binocular_depth_available:
                l_depth_b = sum_l1_norm(mask * (rendered_depth_inv - binocular_depth_inv))
            else:
                l_depth_b = 0.0
                
            # Monocular Depth Loss (using correlation)
            # Note: Requires monocular depth input D
            if monocular_depth_available:
                # Covariance and Variance calculation
                masked_pred = mask * rendered_depth
                masked_real = mask * monocular_depth
                cov = covariance(masked_pred, masked_real)
                var_pred = variance(masked_pred)
                var_real = variance(masked_real)
                l_depth_m = 1.0 - cov / sqrt(var_pred * var_real)
            else:
                l_depth_m = 0.0
                
            # Combine depth losses (Assuming additive combination based on context)
            l_depth = l_depth_b + l_depth_m
            
            # Regularization Constraints
            # Spatial TV Loss
            l_spatial = total_variation(rendered_color) + total_variation(rendered_depth_inv)
            
            # Temporal TV Loss (requires previous frame's rendered output)
            if i > 0:
                l_temporal = total_variation_temporal(rendered_depth_inv, prev_rendered_depth_inv)
            else:
                l_temporal = 0.0
                
            # Total Loss for this frame
            # Note: Lambda weights are not specified in sources [S1, unofficial]
            frame_loss = (lambda1 * l_color + lambda2 * l_depth + 
                          lambda3 * l_spatial + lambda4 * l_temporal)
            total_loss += frame_loss
            
        total_loss.backward()
        optimizer.step()
        
        # Update previous frame for temporal loss
        prev_rendered_depth_inv = rendered_depth_inv
        
    return gaussians
```

**Edge Cases and Pitfalls**
*   **Tool Occlusion:** The binary tool mask $\mathbf{M}$ is critical. Failure to correctly mask tool regions leads to artifacts in color and depth, as the model tries to fit non-existent tissue behind the tool [S1, unofficial].
*   **Depth Scale Ambiguity:** Monocular depth loss uses correlation, which is invariant to scale and shift. This is necessary because absolute depth from monocular cues is inconsistent. However, this means the method cannot recover absolute metric depth from monocular data alone [S1, unofficial].
*   **Reciprocal Depth Stability:** Binocular depth loss uses reciprocal depth ($\mathbf{D}^{-1}$) for stability. Implementers must ensure numerical stability when computing reciprocals for near-zero depth values [S1, unofficial].
*   **Deformation Modeling:** The method does not model deformation of SH coefficients, assuming position, rotation, scale, and opacity are sufficient for tissue movement. This simplification may limit high-frequency appearance changes [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The method is optimized for real-time performance. Training takes approximately 4,000 iterations (1k warmup + 3k main) [S1, unofficial].
*   **Memory Complexity:** Uses a single RTX 4090 GPU for training [S1, unofficial].
*   **Performance:** Achieves real-time inference speeds (FPS) comparable to or better than previous SOTA methods like EndoNeRF and EndoSurf, which require hours for optimization [S1, unofficial].
*   **Strengths:** Handles non-rigid deformation and tool occlusion effectively. Real-time capability.
*   **Limitations:** Relies on accurate tool masks. Monocular depth is relative. [S1, unofficial].

## Background
EndoGaussian Optimization was introduced in the paper "EndoGaussian: Real-time Gaussian Splatting for Dynamic Endoscopic Scene Reconstruction" [S1, unofficial]. It builds upon the EndoNeRF framework [22] and other SOTA methods like EndoSurf [27] and LerPlane [24] [S1, unofficial]. The method was evaluated on the ENDONERF and SCARED datasets, which contain in-vivo prostatectomy data and porcine cadaver abdominal anatomies, respectively [S1, unofficial].
