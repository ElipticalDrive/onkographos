# Composite Image Loss with Visibility Weighting

Also called: Optimization Loss Function, Visibility-weighted Photometric Loss

## Overview
This method computes a composite photometric loss $\mathcal{L}_c$ for differentiable volume rendering by weighting pixel-wise reconstruction errors with a visibility map $\mathbf{V}_M$. It solves the problem of supervising rendered images $\mathbf{I}_r$ against ground-truth images $\mathbf{I}_{gt}$ in scenarios where occlusion or transparency makes naive pixel-wise comparison ineffective. It sets itself apart from standard photometric losses by explicitly masking the L1 and SSIM terms with visibility weights, while retaining an unweighted perceptual term, and is defined in [SRF-Loss](6978-srf-loss.md).

## How it works
**Inputs and Outputs:**
*   **Inputs:** Rendered image tensor $\mathbf{I}_r \in \mathbb{R}^{H \times W \times 3}$, ground-truth image tensor $\mathbf{I}_{gt} \in \mathbb{R}^{H \times W \times 3}$, visibility map tensor $\mathbf{V}_M \in \mathbb{R}^{H \times W}$ (scalar per pixel), and regularization loss values $\mathcal{L}_{sc}$ (sampling coordinate regularization) and $\mathcal{L}_{vm}$ (visibility map regularization).
*   **Outputs:** Composite image loss scalar $\mathcal{L}_c$ and total loss scalar $\mathcal{L}$.

**Data Structures:**
*   $\mathbf{I}_r, \mathbf{I}_{gt}$: Float32 tensors, shape $(H, W, 3)$, values typically in $[0, 1]$.
*   $\mathbf{V}_M$: Float32 tensor, shape $(H, W)$, values in $[0, 1]$. Represents the probability or weight of a pixel being visible/occluded.

**Parameters:**
*   $\lambda_1 = 0.8$ (L1 weight)
*   $\lambda_{SSIM} = 0.2$ (SSIM weight)
*   $\lambda_{LPIPS} = 0.005$ (Perceptual weight)
*   $\lambda_{sc} = 0.001$ (Sampling coord regularization weight)
*   $\lambda_{vm} = 0.15$ (Visibility map regularization weight)

**Steps:**
1.  Compute the Hadamard product $\mathbf{I}_r' = \mathbf{V}_M \odot \mathbf{I}_r$ and $\mathbf{I}_{gt}' = \mathbf{V}_M \odot \mathbf{I}_{gt}$. This masks the images where visibility is low.
2.  Compute the L1 loss $\mathcal{L}_1$ between $\mathbf{I}_r'$ and $\mathbf{I}_{gt}'$.
3.  Compute the SSIM loss $\mathcal{L}_{SSIM}$ between $\mathbf{I}_r'$ and $\mathbf{I}_{gt}'$. Note: SSIM is typically computed as $1 - \text{SSIM}_{index}$.
4.  Compute the Perceptual loss $\mathcal{L}_{LPIPS}$ between the original unmasked $\mathbf{I}_r$ and $\mathbf{I}_{gt}$.
5.  Combine these into the composite image loss $\mathcal{L}_c$ using the weighted sum.
6.  Add the regularization terms $\mathcal{L}_{sc}$ and $\mathcal{L}_{vm}$ scaled by their respective coefficients to form the total loss $\mathcal{L}$.

**Formulas:**
The composite image loss $\mathcal{L}_c$ is defined as [S1]:
$$ \mathcal{L}_c = \lambda_1 \mathcal{L}_1(\mathbf{V}_M \odot \mathbf{I}_r, \mathbf{V}_M \odot \mathbf{I}_{gt}) + \lambda_{SSIM} \mathcal{L}_{SSIM}(\mathbf{V}_M \odot \mathbf{I}_r, \mathbf{V}_M \odot \mathbf{I}_{gt}) + \lambda_{LPIPS} \mathcal{L}_{LPIPS}(\mathbf{I}_r, \mathbf{I}_{gt}) $$

The total loss $\mathcal{L}$ is defined as [S1]:
$$ \mathcal{L} = \mathcal{L}_c + \lambda_{sc} \mathcal{L}_{sc} + \lambda_{vm} \mathcal{L}_{vm} $$

Where:
*   $\odot$ denotes the Hadamard (element-wise) product.
*   $\mathcal{L}_1(\mathbf{A}, \mathbf{B}) = \frac{1}{N} \sum_{i} | \mathbf{A}(i) - \mathbf{B}(i) |$
*   $\mathcal{L}_{SSIM}(\mathbf{A}, \mathbf{B}) = 1 - \text{SSIM}(\mathbf{A}, \mathbf{B})$
*   $\mathcal{L}_{LPIPS}(\mathbf{A}, \mathbf{B})$ is the LPIPS metric computed on $\mathbf{A}$ and $\mathbf{B}$.

**Pseudocode:**
```python
def compute_composite_image_loss(I_r, I_gt, V_M, L_sc, L_vm, 
                                 lambda_1=0.8, lambda_ssim=0.2, 
                                 lambda_lpips=0.005, lambda_sc=0.001, 
                                 lambda_vm=0.15):
    """
    Computes the composite image loss with visibility weighting and total loss.
    
    Args:
        I_r: Rendered image tensor (H, W, 3)
        I_gt: Ground truth image tensor (H, W, 3)
        V_M: Visibility map tensor (H, W)
        L_sc: Sampling coordinate regularization loss scalar
        L_vm: Visibility map regularization loss scalar
        lambda_1: Weight for L1 loss
        lambda_ssim: Weight for SSIM loss
        lambda_lpips: Weight for LPIPS loss
        lambda_sc: Weight for sampling coordinate regularization
        lambda_vm: Weight for visibility map regularization
        
    Returns:
        L_c: Composite image loss scalar
        L: Total loss scalar
    """
    # Step 1: Apply visibility mask to images
    # Broadcasting V_M to (H, W, 1) for element-wise multiplication with RGB images
    I_r_masked = I_r * V_M.unsqueeze(-1)
    I_gt_masked = I_gt * V_M.unsqueeze(-1)
    
    # Step 2: Compute L1 loss on masked images
    # L1 is mean absolute error
    L1 = torch.mean(torch.abs(I_r_masked - I_gt_masked))
    
    # Step 3: Compute SSIM loss on masked images
    # SSIM index is typically computed via a function like torchmetrics.SSIM
    # Loss is 1 - SSIM_index
    ssim_index = compute_ssim(I_r_masked, I_gt_masked) # Assumes a standard SSIM implementation
    L_SSIM = 1.0 - ssim_index
    
    # Step 4: Compute Perceptual loss on unmasked images
    # LPIPS is computed on the original rendered and ground truth images
    L_LPIPS = compute_lpips(I_r, I_gt) # Assumes a standard LPIPS implementation
    
    # Step 5: Combine into composite image loss L_c
    L_c = (lambda_1 * L1) + (lambda_ssim * L_SSIM) + (lambda_lpips * L_LPIPS)
    
    # Step 6: Compute total loss L including regularization terms
    L = L_c + (lambda_sc * L_sc) + (lambda_vm * L_vm)
    
    return L_c, L
```

**Edge Cases and Pitfalls:**
*   **Visibility Map Zeroes:** If $\mathbf{V}_M$ is zero for a pixel, the L1 and SSIM contributions for that pixel become zero. This effectively ignores occluded or transparent regions for photometric supervision, which is the intended behavior but requires $\mathbf{V}_M$ to be accurately estimated.
*   **LPIPS Unmasked:** The LPIPS term is not masked by $\mathbf{V}_M$. This ensures perceptual quality is maintained globally, even in occluded regions, though it may introduce gradients in areas where photometric supervision is disabled.
*   **Gradient Flow:** The Hadamard product with $\mathbf{V}_M$ allows gradients to flow through the visibility map if it is a differentiable output of the network. If $\mathbf{V}_M$ is fixed or non-differentiable, gradients for those pixels stop at the masking operation.

## Subtopics

### [SRF-Loss](6978-srf-loss.md)
SRF-Loss is the composite objective function used to train SuRFNet for generating high-quality Sparse Radiance Fields (SRFs) from partial or noisy inputs. It addresses the problem of ensuring that generated 3D radiance fields not only match the input density and color statistics but also produce visually accurate renderings from novel views. It sets itself apart from simple pixel-wise reconstruction losses by incorporating a 3D-supervised density/radiance component and an online perceptual loss that explicitly optimizes for rendering quality.

## Operating characteristics
*   **Complexity:** The computational complexity is dominated by the SSIM and LPIPS calculations. L1 is $O(N)$. SSIM is $O(N \cdot k^2)$ where $k$ is the kernel size. LPIPS involves forward passes through a pretrained network (e.g., VGG), which is $O(N \cdot C \cdot H \cdot W)$ but constant per pixel relative to the network depth.
*   **Memory:** Requires storing $\mathbf{I}_r, \mathbf{I}_{gt}, \mathbf{V}_M$ and intermediate tensors for SSIM/LPIPS. LPIPS requires loading a pretrained model, adding significant memory overhead compared to pure L1/SSIM.
*   **Performance:** The use of LPIPS improves perceptual quality but increases training time significantly. The visibility weighting reduces the impact of noisy or occluded pixels, potentially stabilizing training in unconstrained image collections [S1].
*   **Strengths:** Robust to occlusion via visibility weighting; balances pixel-level accuracy (L1/SSIM) with perceptual quality (LPIPS).
*   **Limitations:** Computationally expensive due to LPIPS; relies on the accuracy of the visibility map $\mathbf{V}_M$.
*   **When to use:** When training radiance fields from unconstrained or noisy image collections where occlusion is prevalent and perceptual quality is critical [S1].
*   **When not to use:** When computational resources are limited and LPIPS is prohibitive, or when the visibility map is not available or unreliable.

## Background
The method originates from the "Gaussian in the Wild" paper, which introduces 3D Gaussian Splatting for unconstrained image collections [S1]. It is used in the optimization phase of training SuRFNet to generate Sparse Radiance Fields. The approach builds on standard differentiable rendering losses but adapts them for wild images by incorporating visibility weighting and perceptual metrics to handle the lack of structured scene data [S1].
