# Anisotropic Total Variation

## Overview
Anisotropic Total Variation (ATV) is a regularization prior for volumetric data defined as the sum of absolute differences along the three principal axes (x, y, z) for each voxel [S1, unofficial]. Unlike its sibling [Isotropic Total Variation](3276-isotropic-total-variation.md), which computes the Euclidean norm of the gradient, ATV computes the $L_1$ norm of the gradient components separately [S1, unofficial].

## How it works
**Inputs:** A 3D voxel grid $\mathbf{f}$ where $\mathbf{f}_{i,j,k}$ is the scalar value at index $(i, j, k)$ [S1, unofficial].
**Outputs:** The regularization energy value $h(\mathbf{f})$ [S1, unofficial].

**Data Structures:**
The voxel grid is stored as a dense 3D array [S1, unofficial]. The forward difference matrix $D$ is not stored explicitly to save memory [S1, unofficial]. Gradient and divergence operations are computed on-the-fly [S1, unofficial].

**Steps:**
1. **Compute Forward Differences:** For each voxel $(i, j, k)$, compute the differences with its immediate neighbors in the positive x, y, and z directions [S1, unofficial].
    * $\Delta_x \mathbf{f}_{i,j,k} = \mathbf{f}_{i+1,j,k} - \mathbf{f}_{i,j,k}$
    * $\Delta_y \mathbf{f}_{i,j,k} = \mathbf{f}_{i,j+1,k} - \mathbf{f}_{i,j,k}$
    * $\Delta_z \mathbf{f}_{i,j,k} = \mathbf{f}_{i,j,k+1} - \mathbf{f}_{i,j,k}$
2. **Calculate Energy:** Sum the absolute values of these differences over all voxels [S1, unofficial].
    $$h(\mathbf{f}) = \sum_{ijk} |\mathbf{f}_{i+1,j,k} - \mathbf{f}_{i,j,k}| + |\mathbf{f}_{i,j+1,k} - \mathbf{f}_{i,j,k}| + |\mathbf{f}_{i,j,k+1} - \mathbf{f}_{i,j,k}| \quad [S1, unofficial]$$
3. **Proximal Operator (for optimization):** If using an optimization algorithm requiring the proximal operator of the convex conjugate $\tilde{g}^*$, apply the projection onto the unit $L_\infty$ ball component-wise [S1, unofficial].
    $$\text{prox}_{\mu \tilde{g}^*}(\mathbf{q}) = \Pi_{B_\infty}(\mathbf{q})$$
    Defined component-wise for each element $q$ of $\mathbf{q}$:
    $$
    \text{proj}(q) = \begin{cases} 
    1 & \text{if } q > 1 \\
    q & \text{if } |q| \leq 1 \\
    -1 & \text{if } q < -1 
    \end{cases}
    $$
    This operation is applied element-wise to the vector $\mathbf{q}$ [S1, unofficial].

**Pseudocode:**
```python
def anisotropic_total_variation_energy(f, shape):
    """
    Computes the Anisotropic Total Variation energy for a 3D voxel grid f.
    f: flat list or array of voxel values
    shape: tuple (Nx, Ny, Nz)
    Returns: scalar energy value
    """
    energy = 0.0
    Nx, Ny, Nz = shape
    stride_x = 1
    stride_y = Nx
    stride_z = Nx * Ny
    
    # Forward differences along x
    for k in range(Nz):
        for j in range(Ny):
            for i in range(Nx - 1):
                idx = i * stride_x + j * stride_y + k * stride_z
                next_idx = (i + 1) * stride_x + j * stride_y + k * stride_z
                energy += abs(f[next_idx] - f[idx])
                
    # Forward differences along y
    for k in range(Nz):
        for j in range(Ny - 1):
            for i in range(Nx):
                idx = i * stride_x + j * stride_y + k * stride_z
                next_idx = i * stride_x + (j + 1) * stride_y + k * stride_z
                energy += abs(f[next_idx] - f[idx])
                
    # Forward differences along z
    for k in range(Nz - 1):
        for j in range(Ny):
            for i in range(Nx):
                idx = i * stride_x + j * stride_y + k * stride_z
                next_idx = i * stride_x + j * stride_y + (k + 1) * stride_z
                energy += abs(f[next_idx] - f[idx])
                
    return energy

def prox_atv(q):
    """
    Proximal operator for the convex conjugate of ATV prior.
    Projects q onto the unit L_infinity ball component-wise.
    q: list or array of values
    Returns: projected list
    """
    result = []
    for val in q:
        if val > 1.0:
            result.append(1.0)
        elif val < -1.0:
            result.append(-1.0)
        else:
            result.append(val)
    return result
```

**Parameters:**
* $\mu$: Weight of the regularization term in the overall loss function. Typical values depend on the specific application and noise level; not specified in sources [S1, unofficial].

**Edge Cases and Pitfalls:**
* **Memory:** Do not store the forward difference matrix $D$ explicitly. It is of size $3N \times N$ (where $N$ is the number of voxels) and is too large for high-resolution volumes. Compute gradients and divergences on-the-fly [S1, unofficial].
* **Laplacian Relation:** Note that $D^T D$ corresponds to the Laplace operator, which may be useful for certain solver implementations [S1, unofficial].
* **Boundaries:** Boundary conditions at the edges of the grid must be defined (e.g., zero-padding, periodic, or clamping). The source does not explicitly specify the boundary condition used in the cited experiments, but the on-the-fly computation implies handling indices carefully [S1, unofficial].

## Subtopics

### Sum of Absolute Differences (SAD)
A regularization prior defined as the sum of absolute differences between a voxel and all voxels in its 3x3 neighborhood (excluding itself) [S1, unofficial]. It is an extension of ATV that considers more edges per voxel instead of just three [S1, unofficial]. The energy function is:
$$h(\mathbf{f}) = \sum_{ijk} \sum_{\mathbf{f}_n \in N(\mathbf{f}_{i,j,k})} |\mathbf{f}_n - \mathbf{f}_{i,j,k}|$$
where $N(\mathbf{f}_{i,j,k})$ is the 3x3 neighborhood around voxel $\mathbf{f}_{i,j,k}$ excluding the voxel itself [S1, unofficial]. Its proximal operator is similar to ATV's, involving projection onto a unit ball [S1, unofficial]. SAD has been shown to produce excellent results in stochastic tomography reconstruction compared to other priors [S1, unofficial].

## Background
Anisotropic Total Variation is presented as a prior model for what a reconstructed volume should look like, alongside Isotropic TV and SAD [S1, unofficial]. The specific formulation and proximal operator details are discussed in the thesis "Space-Time Tomographic Reconstruction of Deforming Objects" [S1, unofficial].
