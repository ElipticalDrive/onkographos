# Staggered Optimization Scheme

Also called: Alternating Optimization, Staggered Shape and PSF Optimization, deltaMic optimization strategy

## Overview
The Staggered Optimization Scheme decomposes the coupled optimization of shape (mesh geometry) and Point Spread Function (PSF) parameters into two sequential, alternating sub-problems to manage computational cost and avoid bias [S1, unofficial]. Unlike methods that optimize all parameters simultaneously, this approach iterates between a shape update step using an approximate, narrow-band Fourier Transform (FT) and a PSF update step using an exact, full-spectrum FT [S1, unofficial]. It is specifically designed for differentiable rendering in 3D fluorescence microscopy where the forward pass is significantly slower than the backward pass, and where the narrow-band approximation introduces bias dependent on the current PSF state [S1, unofficial].

## How it works
The method operates on a nonmanifold multimaterial mesh representation with $n_v$ vertices (typically 1,000–10,000) and a Gaussian isotropic PSF defined by a covariance matrix $\Sigma$ [S1, unofficial]. The optimization alternates between minimizing a shape-specific loss and a PSF-specific loss, iterating until convergence [S1, unofficial].

### Inputs and Outputs
*   **Inputs:**
    *   Ground truth image volume $I_{GT}$.
    *   Initial mesh topology (e.g., foam-like multimaterial mesh) with $n_v$ vertices $v$.
    *   Initial PSF parameters (covariance matrix $\Sigma$).
    *   Number of optimization iterations.
*   **Outputs:**
    *   Optimized vertex positions $v$.
    *   Optimized PSF covariance matrix $\Sigma$.

### Data Structures
*   **Mesh:** Nonmanifold multimaterial mesh. Stores vertex positions $v \in \mathbb{R}^{n_v \times 3}$ and connectivity.
*   **Laplacian Matrix:** $L \in \mathbb{R}^{n_v \times n_v}$, the mesh Laplacian.
*   **PSF:** Gaussian isotropic PSF parameterized by covariance matrix $\Sigma$.
*   **Fourier Transform (FT):** Computed via the mesh FT operator. Two variants are used:
    *   *Narrow-band:* Approximate, fast, limited frequency range.
    *   *Exact:* Full frequency range, slower.

### Algorithm Steps

1.  **Initialization:** Generate an initial multimaterial mesh with the correct number of cells (topology) [S1, unofficial]. Initialize PSF parameters $\Sigma$.
2.  **Iteration Loop:** Repeat for the specified number of iterations (e.g., 10,000 for artificial benchmarks, 1k–10k for embryo data) [S1, unofficial]:
    *   **Step A: Shape Optimization**
        1.  Compute the rendered image $\hat{I}$ using the current mesh $v$ and current PSF $\Sigma$. Use the **narrow-band** approximation for the mesh FT to compute the gradient efficiently [S1, unofficial].
        2.  Compute the shape loss $L$:
            $$
            L = \frac{\langle I - I_{GT}, I - I_{GT} \rangle}{\langle I_{GT}, I_{GT} \rangle} = \frac{\frac{1}{N} \text{tr}((I - I_{GT})^2)}{\frac{1}{N} \text{tr}(I_{GT})}
            $$
            where $\langle \cdot, \cdot \rangle$ denotes the Frobenius inner product average, and $N$ is the number of pixels. This normalization downweights dark regions in $I_{GT}$ [S1, unofficial].
        3.  Compute the gradient $\frac{\partial L}{\partial v}$ via backpropagation through the narrow-band FT [S1, unofficial].
        4.  Update vertex positions $v$ using the regularized update rule:
            $$
            v \leftarrow v - \eta (1 + \lambda L)^{-2} \frac{\partial L}{\partial v}
            $$
            where $\eta$ is the learning rate, $\lambda = 50$, and $L$ is the mesh Laplacian [S1, unofficial].
        5.  **Implementation Note:** To avoid explicit memory-intensive inversion of $(1 + \lambda L)^{-2}$ for large $n_v$, solve the linear system:
            $$
            (1 + \lambda L)^{-2} A = \frac{\partial L}{\partial v}
            $$
            for $A$ using GPU-parallelized sparse Cholesky decomposition, then update $v \leftarrow v - \eta A$ [S1, unofficial].
        6.  Handle remeshing, collision detection, and topological transitions using the multimaterial mesh-based surface tracking method [S1, unofficial].
    *   **Step B: PSF Optimization**
        1.  Compute the rendered image $\hat{I}$ using the **fixed** updated mesh $v$ and current PSF $\Sigma$. Use the **exact** mesh FT (all frequencies) to avoid bias from the narrow-band threshold, which depends on PSF values [S1, unofficial].
        2.  Compute the PSF loss $L_0$:
            $$
            L_0 = \| I - I_{GT} \|_2
            $$
            This regular L2 norm is suitable for reconstructing both bright and dark regions [S1, unofficial].
        3.  Compute the gradient $\frac{\partial L_0}{\partial \Sigma}$ via backpropagation through the exact FT [S1, unofficial].
        4.  Update PSF parameters $\Sigma$ using the Adam optimizer [S1, unofficial].

### Pseudocode

```python
import numpy as np
from scipy.sparse import cholsolve # Pseudocode for GPU-parallelized sparse Cholesky

def staggered_optimization(mesh, I_GT, num_iterations, eta, lambda_reg):
    """
    Staggered optimization of mesh shape and PSF parameters.
    
    Args:
        mesh: Initial multimaterial mesh object with vertices v and Laplacian L.
        I_GT: Ground truth image array.
        num_iterations: Total number of alternating steps.
        eta: Learning rate for shape optimization.
        lambda_reg: Regularization parameter for shape update (default 50).
        
    Returns:
        mesh: Optimized mesh.
        Sigma: Optimized PSF covariance matrix.
    """
    # Initialize PSF parameters (e.g., isotropic Gaussian)
    Sigma = initialize_PSF() 
    
    for step in range(num_iterations):
        # --- Step A: Shape Optimization ---
        
        # 1. Render image using narrow-band FT for speed
        # narrow_band_mesh_ft computes the FT approximation limited by current PSF
        I_hat = render_with_narrow_band(mesh.v, Sigma)
        
        # 2. Compute Shape Loss: Normalized Frobenius norm
        # L = ||I - I_GT||_F^2 / ||I_GT||_F^2
        numerator = np.sum((I_hat - I_GT) ** 2)
        denominator = np.sum(I_GT ** 2)
        L_shape = numerator / denominator
        
        # 3. Compute gradient of loss w.r.t vertices
        # Backprop through narrow-band FT
        grad_L_v = compute_gradient_narrow_band(mesh, Sigma, I_hat, I_GT)
        
        # 4. Regularized Vertex Update
        # Solve (1 + lambda * L)^2 * A = grad_L_v for A
        # Note: (1 + lambda * L)^-2 applied to grad is equivalent to solving
        # (1 + lambda * L)^2 * A = grad. However, the source specifies solving
        # (1 + lambda * L)^-2 A = grad. 
        # Re-reading source: "v <- v - eta * (1 + lambda L)^-2 * dL/dv"
        # "solve the equivalent linear system (1 + lambda L)^-2 A = dL/dv"
        # This implies we solve for A such that (1 + lambda L)^-2 * A = grad_L_v.
        # Then v = v - eta * A.
        
        # Construct matrix M = (1 + lambda_reg * mesh.L)
        # We need to solve M^-2 * A = grad_L_v
        # This is equivalent to solving M * M * A = grad_L_v? 
        # No, M^-2 A = g => A = M^2 g. 
        # But source says "solve ... via Cholesky". Cholesky solves M x = b.
        # If we want A = M^2 g, we can solve M y = g, then M A = y.
        # Or if the source implies the update is v = v - eta * A where A is the 
        # result of applying the inverse squared Laplacian to the gradient.
        
        # Let's follow the source text strictly:
        # "solve the equivalent linear system (1 + lambda L)^-2 A = dL/dv"
        # This phrasing is slightly ambiguous. Usually, one solves (1 + lambda L) x = b.
        # Applying (1 + lambda L)^-2 twice is computationally expensive if done explicitly.
        # However, if we interpret "solve ... for A" as finding A, and the update is v - eta*A,
        # then A = (1 + lambda L)^-2 * grad.
        # To compute A efficiently:
        # Let M = (1 + lambda_reg * mesh.L)
        # Solve M * y = grad_L_v  => y = M^-1 * grad
        # Solve M * A = y         => A = M^-1 * y = M^-2 * grad
        
        M = np.eye(mesh.n_v) + lambda_reg * mesh.L
        # Solve M * y = grad_L_v using sparse Cholesky
        y = cholsolve(M, grad_L_v)
        # Solve M * A = y using sparse Cholesky
        A = cholsolve(M, y)
        
        # Update vertices
        mesh.v = mesh.v - eta * A
        
        # Handle remeshing/topology if necessary
        mesh.handle_topological_changes()
        
        # --- Step B: PSF Optimization ---
        
        # 1. Render image using exact FT to avoid bias
        # exact_mesh_ft computes the full spectrum FT
        I_hat_exact = render_with_exact_ft(mesh.v, Sigma)
        
        # 2. Compute PSF Loss: L2 norm
        L_psf = np.linalg.norm(I_hat_exact - I_GT)
        
        # 3. Compute gradient of loss w.r.t Sigma
        grad_L_Sigma = compute_gradient_exact_ft(mesh, Sigma, I_hat_exact, I_GT)
        
        # 4. Update PSF parameters using Adam
        Sigma = adam_update(Sigma, grad_L_Sigma)
        
    return mesh, Sigma
```

*   **Regularization ($\lambda$):** 50 [S1, unofficial].

*   **PSF Model:** Gaussian isotropic [S1, unofficial].

### Edge Cases and Pitfalls
*   **Computational Cost:** The forward pass is approximately 10 times slower than the backward pass. The narrow-band method is applied in the backward computation whenever possible to save time [S1, unofficial].
*   **Bias:** Using the narrow-band method for PSF optimization introduces bias because the threshold depends on the current PSF values. Therefore, the exact FT must be used during the PSF optimization step [S1, unofficial].
*   **Memory:** Explicit inversion of $(1 + \lambda L)^{-2}$ is memory-intensive for large vertex counts ($n_v$). The linear system solver approach is required [S1, unofficial].
*   **Topology:** Remeshing and collision detection are necessary for dynamic shapes. The method relies on a multimaterial mesh-based surface tracking method to handle these transitions [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The method is computationally expensive. The forward pass is ~10x slower than the backward pass. The narrow-band method is used for shape optimization to mitigate this, while the exact method is used for PSF optimization, which is slower but necessary for accuracy [S1, unofficial].
*   **Memory Complexity:** Memory usage is high for large vertex counts if explicit inversion is used. The sparse Cholesky decomposition approach reduces memory pressure by solving linear systems instead of inverting matrices [S1, unofficial].
*   **Performance:**
    *   **Artificial Benchmarks:** Converges to original shapes (sphere/torus) within 10,000 iterations [S1, unofficial].
    *   **Robustness:**
        *   *Zoom:* MSE ranges from 0.0042 (factor 0.9) to 0.0084 (factor 1.5) after 400 iterations [S1, unofficial].
        *   *Shift:* MSE ranges from 0.0039 to 0.0072 after 400 iterations [S1, unofficial].
        *   *Noise:* MSE increases from $6.58 \times 10^{-3}$ (level 0) to $9.66 \times 10^{-2}$ (level 0.1) after 400 iterations [S1, unofficial].
    *   **Comparison:** Outperforms DM3D on 15 mouse organoid 3D images across MSE, SSIM, and PSNR metrics [S1, unofficial].
*   **Strengths:**
    *   Avoids bias from narrow-band approximation by alternating with exact FT.
    *   Efficient shape optimization via narrow-band FT and regularized updates.
    *   Robust to noise and initial condition variations.
*   **Limitations:**
    *   Computationally intensive due to FT calculations.
    *   Requires careful handling of mesh topology and remeshing.
    *   Limited to specific applications (3D fluorescence microscopy, cell shape inference).

## Background
The Staggered Optimization Scheme was introduced in the context of differentiable rendering for 3D fluorescence microscopy, specifically for the deltaMic method [S1, unofficial]. It addresses the challenge of jointly optimizing mesh geometry and PSF parameters, which are coupled and computationally expensive to optimize simultaneously. The method was applied to infer cell shapes in early-stage embryos (mouse, ascidian, worm) from 3D fluorescence microscopy images acquired using single-view light-sheet, dual-view light-sheet, and point-scanning confocal microscopes [S1, unofficial].
