# Differentiable Inverse Graphics Framework

Also called: Analysis-by-synthesis with differentiable rendering, End-to-end differentiable inverse graphics

## Overview
The Differentiable Inverse Graphics Framework is a fully differentiable pipeline that infers latent 3D scene parameters—geometry, materials, and lighting—from images by optimizing them via gradient backpropagation from rendering losses [S1, unofficial]. It solves the inverse problem of determining the physical causes of an observed image by minimizing the difference between the observed image and a synthetic render generated by a differentiable renderer [S1, unofficial]. What sets it apart from its siblings is its foundational reliance on the analysis-by-synthesis loop where the rendering equation is explicitly implemented in the forward pass and gradients are propagated through the entire physical simulation (including Monte Carlo path tracing or neural surrogates) to update the parametric scene representation [S1, unofficial].

## Shared principles
The framework operates on a parametric scene representation $\theta$ and a differentiable rendering pipeline $R(\theta)$ [S1, unofficial].

**Scene Representation ($\theta$):**
The parameter vector $\theta$ encapsulates the latent variables of the scene. It typically includes:
*   **Geometry:** Mesh vertices, Signed Distance Field (SDF) weights, point clouds, or 2D/3D Gaussian splatting parameters [S1, unofficial].
*   **Materials:** Spatially-varying BRDF parameters, learnable material tensors, or basis coefficients for reflectance models [S1, unofficial].
*   **Lighting:** Explicit light source positions/intensities or neural lighting parameters [S1, unofficial].

**Rendering Equation:**
The forward pass implements the rendering equation to compute outgoing radiance $L_o$ at a surface point $x$ in direction $\omega_o$:
$$
L_o(x, \boldsymbol{\omega}_o) = L_e(x, \boldsymbol{\omega}_o) + \int_{\Omega} f_r(x, \boldsymbol{\omega}_i, \boldsymbol{\omega}_o) L_i(x, \boldsymbol{\omega}_i) (n \cdot \boldsymbol{\omega}_i) d\boldsymbol{\omega}_i
$$
where:
*   $L_e$ is emitted radiance.
*   $f_r$ is the BRDF.
*   $L_i$ is incoming radiance.
*   $n$ is the surface normal.
*   $\Omega$ is the hemisphere of incoming directions [S1, unofficial].

**Optimization Objective:**
The framework minimizes a loss function $\mathcal{L}(\theta)$ that compares the observed image $I_{\text{obs}}$ to the rendered image $\hat{I}(\theta) = R(\theta)$:
$$
\mathcal{L}(\theta) = \|I_{\text{obs}} - R(\theta)\|^2 + \lambda_{g}\, \text{GeomReg}(\theta) + \lambda_{m}\, \text{MatReg}(\theta) + \dots
$$
where $\lambda_{g}$ and $\lambda_{m}$ are regularization weights for geometry and material terms, respectively [S1, unofficial].

**Gradient Propagation:**
Gradients are computed via automatic differentiation (autodiff) or explicit estimators [S1, unofficial]. A key challenge is handling visibility discontinuities (e.g., silhouette edges) which cause gradient issues; these are mitigated using Monte Carlo (MC) edge sampling, area-sampling, or thin-band relaxed indicators [S1, unofficial].

**Neural Surrogates:**
When the renderer is not inherently differentiable, a neural imitator can be trained to approximate the renderer's output for given parameters, serving as a differentiable module [S1, unofficial].

### Neural Programmatic Scene Code Pipeline
A pipeline where an image is encoded into a discrete scene program (geometry, materials, arrangements) via an encoder and LLM/programmatic decoder, which is then rendered by any downstream renderer [S1, unofficial]. The pipeline flow is defined as:
$$
I \xrightarrow{\Phi} E \xrightarrow{f_\theta} (s_1, ..., s_N) \xrightarrow{h} S
$$
where $I$ is the input image, $E$ is the encoded representation, $f_\theta$ generates scene tokens/parameters $s_i$, and $h$ renders the scene program $S$ [S1, unofficial]. Training is performed purely on code or numeric losses, not image losses, allowing the discrete scene program to be optimized [S1, unofficial]. This approach supports zero-shot generalization across object categories and spatial reasoning without pixel-space supervision [S1, unofficial].

## Background
The framework emerged from the convergence of differentiable rendering and inverse graphics, aiming to bridge the gap between physical simulation and data-driven learning. It enables photorealistic relighting, interactive scene editing, and 3D synthesis by leveraging analysis-by-synthesis and modular loss composition [S1, unofficial].

**Performance Metrics:**
*   Physics-based Monte Carlo approaches achieve low reconstruction errors (RE $\approx$ 0.0087 vs Mitsuba's 0.0102) and normal MAE of 9.81° with sparse Gaussian basis [S1, unofficial].
*   Point-based splatting and hybrid methods achieve PSNR 38–43 dB and normal MAE $\approx$ 4–11° [S1, unofficial].
*   LLM-based pipelines show 99%+ attribute accuracy and 2.5$\times$ lower parameter generalization error on OOD test splits [S1, unofficial].

**Limitations:**
Limitations persist for extremely high-genus shapes and strongly non-Lambertian surfaces [S1, unofficial].
