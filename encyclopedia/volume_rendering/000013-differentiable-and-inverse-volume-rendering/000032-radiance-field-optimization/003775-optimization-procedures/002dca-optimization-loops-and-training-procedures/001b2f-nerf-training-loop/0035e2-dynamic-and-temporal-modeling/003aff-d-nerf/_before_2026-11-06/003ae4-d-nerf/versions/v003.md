# D-NeRF

Also called: Dynamic-NeRF, Neural Radiance Fields for Dynamic Scenes

## Overview
D-NeRF is a method for synthesizing novel views at an arbitrary point in time of dynamic scenes with complex non-rigid geometries, optimized from a sparse set of input monocular views without ground-truth geometry or multi-view images [S1]. It sets itself apart from naive extensions of NeRF that map $(x, y, z, t)$ directly to density and radiance by decomposing the learning process into two modules: a spatial mapping that encodes the scene into a canonical space, and a mapping that transforms this canonical representation into the deformed scene at a particular time [S1]. This decomposition effectively exploits temporal redundancy, which naive extensions fail to do, and differs from T-NeRF by using an intermediate canonical configuration rather than a direct 6D input mapping [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A sparse set of $T$ RGB images $\{I_t\}_{t=1}^T$ and their corresponding camera pose matrices $\{T_t\}_{t=1}^T$, where $I_t \in \mathbb{R}^{H \times W \times 3}$ is the image acquired under camera pose $T_t \in \mathbb{R}^{4 \times 4}$ (SE(3)) at time $t$. The method assumes a single view per time instant [S1].
*   **Outputs:** Rendered pixel colors $C'(p, t)$ for a given pixel $p$, viewing direction $d$, and time $t$ [S1].

**Data Structures:**
The model consists of two deep fully connected networks (MLPs) without convolutional layers [S1]:
1.  **Deformation Network ($\Psi_t$):** Maps scene deformations to a common canonical configuration.
    *   **Architecture:** 8-layer MLP with ReLU activations.
    *   **Input:** Encoded 3D position $x$ and time $t$.
    *   **Output:** Displacement vector $\Delta x$. No non-linearity is applied to the output [S1].
2.  **Canonical Network ($\Psi_x$):** Regresses volume density and view-dependent RGB color from the canonical representation.
    *   **Architecture:** 8-layer MLP with ReLU activations.
    *   **Input:** Encoded canonical position $(x + \Delta x)$ and viewing direction $d$.
    *   **Output:** Emitted color $c$ and volume density $\sigma$. A final sigmoid nonlinearity is applied to both $c$ and $\sigma$ [S1].

**Positional Encoding:**
Raw coordinates are encoded into a higher-dimensional space using sinusoidal positional encoding $\gamma(p)$ [S1]:
$$ \gamma(p) = \langle (\sin(2^l \pi p), \cos(2^l \pi p)) \rangle_{l=0}^{L-1} $$
The encoder is applied independently to each coordinate and camera view component [S1].
*   **Parameters:** $L=10$ for spatial coordinates $x$; $L=4$ for viewing direction $d$ and time $t$ [S1].

**Numbered Steps:**
1.  **Ray Sampling:** For a training batch, sample a random set of pixels $\{p_{t,i}\}_{i=1}^{N_s}$ corresponding to rays cast from camera position $T_t$ to pixels $i$ of image $t$. For each ray, draw $N$ samples $\{h_n\}_{n=1}^N$ from evenly-spaced ray bins in $[h_n, h_f]$ using stratified sampling [S1].
2.  **Deformation:** For each sample point $x(h) = o + h d$ along the ray at time $t$, transform the point to its canonical configuration using the deformation network:
    $$ \Delta x = \Psi_t(x(h), t) $$
    The canonical scene is defined as the scene at $t=0$, enforcing $\Psi_t(x, 0) = 0$ [S1].
3.  **Canonical Query:** Compute the canonical position $p(h, t) = x(h) + \Delta x$. Query the canonical network with the encoded canonical position and viewing direction to regress density and color:
    $$ [c(p(h, t), d), \sigma(p(h, t))] = \Psi_x(p(h, t), d) $$
4.  **Volume Rendering:** Approximate the volume rendering integral via numerical quadrature. Calculate the transmittance and alpha for each sample:
    $$ \alpha(h, t, \delta_n) = 1 - \exp(-\sigma(p(h, t)) \delta_n) $$
    $$ T'(h_n, t) = \exp\left(-\sum_{m=1}^{n-1} \sigma(p(h_m, t)) \delta_m\right) $$
    where $\delta_n = h_{n+1} - h_n$ is the distance between quadrature points [S1].
5.  **Pixel Color:** Compute the rendered pixel color:
    $$ C'(p, t) = \sum_{n=1}^{N} T'(h_n, t) \alpha(h_n, t, \delta_n) c(p(h_n, t), d) $$
6.  **Loss Calculation:** Minimize the mean squared error between rendered pixels $C'$ and ground truth pixels $\hat{C}$:
    $$ \text{Loss} = \frac{1}{N_s} \sum_{i=1}^{N_s} \|\hat{C}(p_i, t) - C'(p_i, t)\|^2 $$
7.  **Optimization:** Simultaneously update parameters of $\Psi_x$ and $\Psi_t$ using the Adam optimizer [S1].

**Pseudocode:**
```python
import numpy as np

def positional_encoding(p, L):
    """
    Applies sinusoidal positional encoding to input p.
    p: array of shape (..., D)
    L: number of frequency bands
    Returns: array of shape (..., D * 2 * L)
    """
    scales = np.array([2**l for l in range(L)])
    # p is scaled by 2^l, then sin/cos applied
    # Result is concatenated sin and cos components
    encoded = []
    for l in range(L):
        scaled_p = p * scales[l]
        encoded.append(np.sin(scaled_p))
        encoded.append(np.cos(scaled_p))
    return np.concatenate(encoded, axis=-1)

def deform_network(x_encoded, t_encoded):
    """
    8-layer MLP with ReLU activations.
    Input: concatenated encoded x and t.
    Output: displacement delta_x (no non-linearity).
    """
    # Placeholder for actual MLP weights and forward pass
    # In implementation, this is a standard dense network
    x_t = np.concatenate([x_encoded, t_encoded], axis=-1)
    h = x_t
    for i in range(8):
        h = np.maximum(0, np.dot(h, W[i]) + b[i]) # ReLU
    delta_x = np.dot(h, W_out) # Linear output
    return delta_x

def canonical_network(x_canonical_encoded, d_encoded):
    """
    8-layer MLP with ReLU activations.
    Input: concatenated encoded x_canonical and d.
    Output: color c and density sigma (sigmoid applied).
    """
    x_d = np.concatenate([x_canonical_encoded, d_encoded], axis=-1)
    h = x_d
    for i in range(8):
        h = np.maximum(0, np.dot(h, W[i]) + b[i]) # ReLU
    raw_out = np.dot(h, W_out)
    c = 1.0 / (1.0 + np.exp(-raw_out[:, :3])) # Sigmoid for color
    sigma = 1.0 / (1.0 + np.exp(-raw_out[:, 3])) # Sigmoid for density
    return c, sigma

def render_ray(ray_origin, ray_direction, t, h_near, h_far, N_samples):
    """
    Renders a single ray at time t.
    """
    # 1. Stratified sampling
    bins = np.linspace(h_near, h_far, N_samples + 1)
    samples = bins[:-1] + np.random.uniform(0, bins[1] - bins[0], size=N_samples)
    
    # 2. Get 3D points
    x_samples = ray_origin + ray_direction * samples[:, np.newaxis]
    
    # 3. Positional Encoding
    # L=10 for x, L=4 for d and t
    x_enc = positional_encoding(x_samples, L=10)
    d_enc = positional_encoding(ray_direction, L=4)
    t_enc = positional_encoding(np.full_like(x_samples[:, 0:1], t), L=4)
    
    # 4. Deformation
    delta_x = deform_network(x_enc, t_enc)
    
    # 5. Canonical Position
    x_canonical = x_samples + delta_x
    x_canonical_enc = positional_encoding(x_canonical, L=10)
    
    # 6. Canonical Network Query
    c, sigma = canonical_network(x_canonical_enc, d_enc)
    
    # 7. Volume Rendering
    deltas = samples[1:] - samples[:-1]
    deltas = np.concatenate([deltas, np.array([h_far - samples[-1]])])
    
    # Alpha and Transmittance
    alpha = 1.0 - np.exp(-sigma * deltas)
    transmittance = np.exp(-np.cumsum(sigma * deltas, axis=0))
    # Shift transmittance for T_i
    T = np.concatenate([np.ones_like(transmittance[:, 0:1]), transmittance[:, :-1]], axis=1)
    
    # Color contribution
    contribution = T * alpha[:, np.newaxis] * c
    color = np.sum(contribution, axis=0)
    
    return color

def train_step(images, poses, t_values, N_s=4096, N_samples=64):
    """
    One training step.
    """
    # Select random time t
    t_idx = np.random.randint(0, len(images))
    t = t_values[t_idx]
    image = images[t_idx]
    pose = poses[t_idx]
    
    # Sample N_s rays
    H, W, _ = image.shape
    ray_indices = np.random.randint(0, H * W, size=N_s)
    rays = []
    for idx in ray_indices:

    # Render

    for origin, direction in rays:
        color = render_ray(origin, direction, t, h_near, h_far, N_samples)
        rendered_colors.append(color)
    rendered_colors = np.array(rendered_colors)
    
    # Ground truth colors for sampled pixels
    gt_colors = []
    for idx in ray_indices:
        y, x = divmod(idx, W)
        gt_colors.append(image[y, x])
    gt_colors = np.array(gt_colors)
    
    # Loss
    loss = np.mean((gt_colors - rendered_colors) ** 2)
```

**Parameters:**
*   **Canonical Time:** $t=0$ [S1].
*   **Positional Encoding Depth:** $L=10$ for $x$, $L=4$ for $d$ and $t$ [S1].
*   **Network Depth:** 8 layers for both $\Psi_x$ and $\Psi_t$ [S1].
*   **Training Resolution:** $400 \times 400$ images [S1].
*   **Iterations:** 800k [S1].
*   **Batch Size:** $N_s = 4096$ rays [S1].
*   **Samples per Ray:** 64 [S1].
*   **Optimizer:** Adam, learning rate $5 \times 10^{-4}$, $\beta_1=0.9$, $\beta_2=0.999$, exponential decay to $5 \times 10^{-5}$ [S1].

**Edge Cases and Pitfalls:**
*   **Temporal Redundancy:** Naively mapping $(x, y, z, t)$ to density/radiance fails to produce satisfying results because it does not effectively exploit temporal redundancy [S1].
*   **Single View per Time:** The method is designed for a sparse set of images with a single view per time instant. It does not assume multiple views per time instance [S1].
*   **Convergence:** A curriculum learning strategy is used: input images are sorted by timestamp, and images with higher timestamps are incrementally added to improve convergence [S1].

## Subtopics

### [Dynamic NeRF Guided by Projected Colors](8882-dynamic-nerf-guided-by-projected-colors.md)
Replaces explicit temporal coordinate $t$ with multi-view projected color statistics to improve point correspondence estimation. It maps inputs to a "space-color" coordinate system where correspondence is easier to track due to color invariance under motion, unlike standard space-time dynamic NeRFs that optimize irregular temporal deformation fields.

## Operating characteristics
*   **Time and Memory Complexity:** Not given in the sources.
*   **Measured Performance:**
    *   **Hell Warrior:** MSE $31 \times 10^{-4}$, PSNR 23.19, SSIM 0.93, LPIPS 0.08 (vs NeRF: MSE $44 \times 10^{-3}$, PSNR 13.52, SSIM 0.81, LPIPS 0.25) [S1].
    *   **T-Rex:** MSE $5 \times 10^{-4}$, PSNR 32.80, SSIM 0.98, LPIPS 0.03 (vs NeRF: MSE $21 \times 10^{-3}$, PSNR 18.19, SSIM 0.89, LPIPS 0.14) [S1].
*   **Hardware:** Trained on a single Nvidia GTX 1080 for 2 days [S1].
*   **Strengths:** Can synthesize novel views at arbitrary times for scenes with rigid, articulated, and non-rigid motions from a single camera moving around the scene [S1]. Produces complete 3D meshes as a side product [S1].
*   **Limitations:** Requires a sparse set of input monocular views; performance on naive extensions (T-NeRF) is inferior to D-NeRF [S1].
*   **When to use:** When synthesizing novel views of dynamic scenes with non-rigid geometry from sparse monocular inputs is required.
*   **When not to use:** When multiple views per time instant are available and rigid scene assumptions hold (standard NeRF may be sufficient or more stable), or when ground-truth geometry is available.

## Background
D-NeRF was proposed by Albert Pumarola, Enric Corona, Gerard Pons-Moll, and Francesc Moreno-Noguer from Institut de Robòtica i Informàtica Industrial (CSIC-UPC) and Max Planck Institute for Informatics [S1]. It was published in CVPR 2021 (arXiv:2011.13961v1, 27 Nov 2020) [S1]. The method builds on NeRF [26] and generalizes it to handle non-rigid scenes. It is inspired by classical 3D scene flow [44] and decomposes learning into a canonical scene and scene flow, unlike T-NeRF which represents the scene with a 6D input directly [S1]. It is compared against Neural Volumes (NV), Scene Representation Networks (SRN), and Layered Light Field Fusion (LLFF) [S2].
