# Dynamic Object Embedding in Static Scenes

Also called: Lightweight Dynamic NeRF Modeling via Local Deformation Field, Local deformation field model

## Overview
This method integrates dynamic advertising objects into pre-existing static NeRF scenes by ensuring perspective consistency through spatial alignment and joint rendering with alpha blending [S1]. It distinguishes itself from full-scene dynamic NeRFs (like [D-NeRF](8660-d-nerf.md)) by maintaining a fixed static model for the background and using a lightweight local deformation field only for the dynamic region, reducing parameter count by 95% [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A pre-trained static NeRF model $F_{static}$ representing the background/exhibition stand; a local deformation field model $\Delta(\mathbf{x}, t)$ representing the dynamic object's motion; four corresponding marking points (e.g., corners) in both coordinate systems for alignment [S1].
*   **Outputs:** A rendered frame $C(r)$ combining the static scene and the dynamically deformed object [S1].

**Data Structures:**
1.  **Static NeRF ($F_{static}$):** A standard MLP-based radiance field. Parameters are fixed after initial reconstruction. It maps $(\mathbf{x}, \mathbf{d}) \to (\sigma, \mathbf{c})$ [S1].
2.  **Local Deformation Field ($\Delta$):** A 3-layer MLP.
    *   Input: Spatial coordinate $\mathbf{x} \in \mathbb{R}^3$ and time $t \in \mathbb{R}$.
    *   Hidden layers: 2 layers with dimension 128.
    *   Output: Displacement vector $\Delta \mathbf{x} \in \mathbb{R}^3$.
    *   Total parameters: 5 million [S1].

**Numbered Steps:**

1.  **Static Scene Reconstruction:** Generate a static NeRF model for the advertising scene (exhibition stand + background) using sparse input reconstruction. The model uses fixed parameters and contains no time dimension [S1].
2.  **Dynamic Object Modeling:** Train the local deformation field $\Delta(\mathbf{x}, t)$ on the dynamic object (e.g., a rotating watch) using 25–30 frames of video [S1].
3.  **Spatial Alignment:**
    *   Select four marking points (e.g., exhibition stand corners) in both the static scene and the dynamic object's coordinate system [S1].
    *   Use the RANSAC algorithm to align the coordinate system of the dynamic object with the static scene [S1].
    *   Goal: Ensure perspective consistency with an alignment error of less than 1 pixel [S1].
4.  **Joint Rendering:** For a ray $r$ intersecting the dynamic object at position $\mathbf{x}$ at time $t$:
    *   Calculate the deformation: $\Delta \mathbf{x} = \Delta(\mathbf{x}, t)$ [S1].
    *   Compute the deformed coordinate: $\mathbf{x}' = \mathbf{x} + \Delta \mathbf{x}$ [S1].
    *   Query the static NeRF: $(\sigma, \mathbf{c}) = F_{static}(\mathbf{x}', \mathbf{d})$ [S1].
    *   Fuse with the static scene using alpha blending. The blending factor is 0.95 [S1].

**Formulas:**
The dynamic radiation field is expressed as [S1]:
$$ F(\mathbf{x}, t) = F_{static}(\mathbf{x} + \Delta(\mathbf{x}, t)) $$

The final color is obtained via alpha blending with a factor of 0.95 [S1].

**Parameters:**
*   Deformation Field Architecture: 3-layer MLP, hidden dimension 128 [S1].
*   Blending Factor: 0.95 [S1].
*   Alignment Error Threshold: < 1 pixel [S1].
*   Training Rounds: 20,000 [S1].

**Edge Cases and Pitfalls:**
*   **Alignment Error:** If the RANSAC alignment error exceeds 1 pixel, perspective consistency is lost [S1].
*   **Dynamic Region Coverage:** This method assumes the dynamic region occupies $\le 20\%$ of the scene [S1].

**Pseudocode:**

```python
def render_frame(static_nerf, deformation_field, ray_origin, ray_direction, time_t, alignment_transform):
    """
    Renders a single frame by embedding a dynamic object into a static scene.
    
    Args:
        static_nerf: The pre-trained static NeRF model F_static.
        deformation_field: The 3-layer MLP model Delta(x, t).
        ray_origin: 3D vector, origin of the ray.
        ray_direction: 3D vector, direction of the ray.
        time_t: Float, current time step.
        alignment_transform: RANSAC-derived transformation matrix aligning dynamic object coords to static scene.
        
    Returns:
        color: 3D vector, final RGB color.
    """
    # 1. Intersect ray with dynamic object bounding volume
    # [G] Implementation detail: Standard ray-primitive intersection.
    # If no intersection, return static_nerf(ray_origin, ray_direction)
    intersection_point_x = intersect_dynamic_object(ray_origin, ray_direction)
    
    if intersection_point_x is None:
        return static_nerf.query(ray_origin, ray_direction)

    # 2. Apply spatial alignment to the intersection point
    # [G] Implementation detail: alignment_transform is a 4x4 matrix.
    # Homogeneous coordinate conversion and matrix multiplication.
    x_homogeneous = np.array([intersection_point_x[0], intersection_point_x[1], intersection_point_x[2], 1.0])
    x_aligned_homogeneous = alignment_transform @ x_homogeneous
    x_aligned = x_aligned_homogeneous[:3]

    # 3. Calculate deformation using the local deformation field
    # Input: Aligned spatial coordinate and time
    delta_x = deformation_field.forward(x_aligned, time_t)
    
    # 4. Compute deformed coordinate in canonical static space
    x_deformed = x_aligned + delta_x
    
    # 5. Query static NeRF at deformed position
    # Note: Direction d remains unchanged in this specific formulation [S1]
    sigma, color_dynamic = static_nerf.query(x_deformed, ray_direction)
    
    # 6. Alpha blending with static scene background
    # [G] Implementation detail: The source specifies a blending factor of 0.95.
    # Assuming the static background color is C_static.
    # The formula implies: C_final = 0.95 * C_dynamic + (1 - 0.95) * C_static ?
    # Or is 0.95 the opacity alpha? The text says "alpha blending (blending factor=0.95)".
    # Given the context of "fusing", we assume standard alpha compositing where
    # the dynamic object is the foreground.
    
    # Query static background at original intersection point for compositing
    sigma_static, color_static = static_nerf.query(intersection_point_x, ray_direction)
    
    # Standard alpha compositing: C_out = C_fg * alpha_fg + C_bg * (1 - alpha_fg)
    # Here, blending factor 0.95 likely refers to the weight of the dynamic object
    # or the alpha value. Given "blending factor", we treat it as the alpha weight.
    alpha = 0.95
    
    color_final = alpha * color_dynamic + (1.0 - alpha) * color_static
    
    return color_final
```

## Subtopics

### Neural Transient Field (NeTF)
Models light transport as a function of time-of-flight, often in spherical coordinates for NLOS [S1].

### Projected Color-Guided Dynamic NeRF
Uses features invariant across time (e.g., projected color statistics) to guide optimization without explicit deformation [S1].

### On-the-Fly Dynamic NeRF Training
Treats the radiance field as a hidden state updated incrementally with each new frame [S1].

### D-DeRF
Traditional dynamic NeRF requiring independent models per time step and over 100M parameters [S1].

## Operating characteristics
*   **Time and Memory Complexity:** The deformation field uses only 5 million parameters, which is 95% less than DyNeRF's 100M+ parameters [S1]. This makes it suitable for VR devices [S1].
*   **Measured Performance:** PSNR increased by $2.3 \pm 0.2$ dB under sparse input (mean $\pm$ std over 10 trials) [S1]. SSIM $\ge 0.92$ [S1].
*   **Strengths:** Significant parameter reduction; suitable for real-time rendering on VR devices; handles dynamic objects occupying $\le 20\%$ of the scene [S1].
*   **Limitations:** Requires accurate spatial alignment (RANSAC) with <1 pixel error; assumes static background [S1].
*   **When to use:** When integrating dynamic advertising objects into static exhibition stands or backgrounds with limited computational resources [S1].

## Background
This method was proposed in a 2026 paper by Y. Tao et al. titled "Efficient Sparse Input Scene Reconstruction and Real-Time Rendering for VR Advertising Using Optimized NeRF Framework" [S1]. It addresses the limitations of traditional dynamic NeRFs like DyNeRF, which require over 100M parameters and independent models per time step, making them unsuitable for VR devices [S1]. The approach focuses on lightweight dynamic NeRF modeling based on a local deformation field [S1].
