# On-the-Fly Dynamic NeRF Training

Also called: OD-NeRF

## Overview
On-the-fly dynamic NeRF training is a method for reconstructing dynamic scenes by optimizing the radiance field concurrently with the acquisition of training frames, enabling real-time streaming of the event as it unfolds [S1]. Unlike standard dynamic NeRFs that require full video sequences for offline 4D reconstruction, this approach minimizes optimization iterations per frame to achieve interactive speeds [S1]. It distinguishes itself from siblings like [Neural Transient Field (NeTF)](4692-neural-transient-field-netf.md) and [Projected Color-Guided Dynamic NeRF](7523-projected-color-guided-dynamic-nerf.md) by explicitly formulating the training process as a Hidden Markov Model (HMM) estimation problem, leveraging a first-order Markov assumption to maintain scalability over time [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A sequence of multi-view images $C_{0:K}$ captured by forward-facing cameras; the radiance field estimate from the previous time step $F_{k-1}$; an occupancy grid $G_{k-1}$ from the previous step [S1].
*   **Outputs:** The updated radiance field function $F_k$ and occupancy grid $G_k$ for the current time step $t_k$ [S1].

**Data Structures:**
*   **Radiance Field $F_k$:** A neural network mapping spatial coordinates $\mathbf{x} \in \mathbb{R}^3$ and viewing directions $\mathbf{d} \in \mathbb{R}^3$ to volume density $\sigma \in \mathbb{R}$ and RGB color $\mathbf{c} \in \mathbb{R}^3$ [S1].
*   **Occupancy Grid $G_k$:** A spatial data structure used for efficient ray sampling, updated from $G_{k-1}$ via a transition function [S1].

**Numbered Steps:**
1.  **Initialize:** Start with the radiance field $F_0$ and occupancy grid $G_0$ from the first frame.
2.  **Receive Frame:** Acquire the current set of images $C_k$ at time $t_k$ [S1].
3.  **Apply Markov Assumption:** Simplify the probability model by assuming the current radiance field $F_k$ is conditionally independent of all previous images and fields given the current image and previous field: $F_k \perp\!\!\!\perp \{C_{0:k-1}, F_{0:k-2}\} \mid \{C_k, F_{k-1}\}$ [S1]. This reduces the estimation target to $F_k = \arg\max_{F_k} P(F_k \mid C_k, F_{k-1})$ [S1].
4.  **Optimize Radiance Field:** Minimize the rendering loss to find $F_k$. The loss is defined as:
    $$ F_k = \arg\min_{F_k} \sum_{r \in R} ||\hat{C}_k(r) - C_k(r)||^2_2 $$
    where $R$ is the set of rays [S1].
5.  **Volume Rendering:** For each ray $r$, compute the rendered color $\hat{C}_k(r)$ by aggregating $N$ points with interval $\delta$ along the ray:
    $$ \hat{C}(r) = \sum_{i=0}^{N-1} T_i (1 - \exp(-\sigma_i \delta_i)) c_i $$
    $$ T_i = \exp\left(-\sum_{j=0}^{i-1} \sigma_j \delta_j\right) $$
    where $\sigma_i$ and $c_i$ are the density and color predicted by $F_k$ at the $i$-th point [S1].
6.  **Update Occupancy Grid:** Update the occupancy grid from $G_{k-1}$ to $G_k$ using a transition function $P(G_k \mid G_{k-1})$ to maintain efficient sampling for the next step [S1].
7.  **Stream:** Render novel views using $F_k$ for the current time step $t_k$ [S1].

**Pseudocode:**
```python
def on_the_fly_training_step(F_prev, G_prev, current_images):
    """
    Optimizes the radiance field for the current time step k.
    
    Args:
        F_prev: Radiance field function from time step k-1.
        G_prev: Occupancy grid from time step k-1.
        current_images: Set of images C_k at time t_k.
        
    Returns:
        F_curr: Optimized radiance field for time step k.
        G_curr: Updated occupancy grid for time step k.
    """
    # Step 1: Initialize F_curr as a copy or slight modification of F_prev
    # to leverage the transition from F_{k-1}
    F_curr = initialize_from(F_prev)
    
    # Step 2: Define the loss function based on the rendering loss
    def compute_loss(F):
        total_loss = 0
        for ray in get_rays(current_images):
            # Volume rendering as per Eq. 1
            rendered_color = volume_render_ray(ray, F)
            target_color = get_target_color(ray, current_images)
            total_loss += squared_error(rendered_color, target_color)
        return total_loss

    # Step 3: Optimize F_curr to minimize the loss
    # This step requires minimum optimization iterations for speed
    F_curr = optimize(F_curr, compute_loss, iterations=MIN_ITERATIONS)
    
    # Step 4: Update the occupancy grid
    # Apply transition function P(G_k | G_{k-1})
    G_curr = update_occupancy_grid(G_prev, F_curr)
    
    return F_curr, G_curr

def volume_render_ray(ray, F):
    """
    Aggregates color of N points along the ray.
    """
    points = sample_points_along_ray(ray)
    accumulated_transmittance = 1.0
    accumulated_color = 0.0
    
    for point in points:
        sigma, color = F(point.x, point.d)
        # Compute transmittance T_i
        # Note: In practice, T_i is accumulated iteratively
        # T_i = exp(-sum_{j=0}^{i-1} sigma_j * delta_j)
        
        # Compute weight w_i = T_i * (1 - exp(-sigma_i * delta_i))
        # Here we assume delta_i is the interval
        delta = point.delta
        transmittance_contribution = 1.0 - exp(-sigma * delta)
        weight = accumulated_transmittance * transmittance_contribution
        
        accumulated_color += weight * color
        accumulated_transmittance *= exp(-sigma * delta)
        
    return accumulated_color
```

**Parameters:**
*   **Optimization Iterations:** The method is designed to require minimum optimization iterations per frame to achieve interactive speed [S1]. The exact number is not specified in the sources [S1].
*   **Camera Setup:** Limited to dynamic scenes captured by multi-view forward-facing cameras [S1].

**Edge Cases and Pitfalls:**
*   **Scalability:** Estimating $F_k$ conditioned on all previous images $C_{0:k}$ is not scalable as time $t_k$ increases [S1]. The first-order Markov assumption is critical to mitigate this complexity growth [S1].
*   **Camera Constraints:** The method assumes static multi-view forward-facing cameras. Monocular setups are excluded due to the need for camera movement, which is cumbersome for prolonged streaming [S1]. 360-degree inward-facing setups are excluded due to hardware complexity [S1].

## Subtopics

### Projected Color-Guided Dynamic NeRF
Uses projected color mean and variance for implicit correspondence. Choose when explicit temporal coordinates are insufficient. [Projected Color-Guided Dynamic NeRF](7523-projected-color-guided-dynamic-nerf.md)

### Neural Transient Field (NeTF)
Reconstructs 4D space-time using transient fields. Choose for offline reconstruction of complex dynamic events. [Neural Transient Field (NeTF)](4692-neural-transient-field-netf.md)

## Operating characteristics
*   **Time Complexity:** Designed for interactive speed by minimizing optimization iterations per frame [S1]. The Markov assumption ensures that complexity does not grow with the number of time steps $K$ [S1].
*   **Memory Complexity:** Depends on the size of the radiance field $F_k$ and occupancy grid $G_k$. The Markov assumption avoids storing history of all previous fields $F_{0:k-2}$ [S1].
*   **Strengths:** Enables real-time streaming of dynamic scenes; scalable to long sequences due to the Markov assumption; leverages previous frame information for fast convergence [S1].
*   **Limitations:** Limited to multi-view forward-facing camera setups; requires efficient transition functions for occupancy grids to maintain performance [S1].
*   **When to Use:** When real-time streaming of a dynamic event is required, and the scene can be captured by a multi-view forward-facing camera rig [S1].
*   **When Not to Use:** For offline 4D reconstruction of complex dynamic scenes where full sequence access is available and real-time streaming is not needed; for scenes captured by monocular or inward-facing 360-degree cameras [S1].

## Background
On-the-fly dynamic NeRF training was introduced in the paper "OD-NeRF: Efficient Training of On-the-Fly Dynamic Neural Radiance Fields" [S1]. The work addresses the limitation of existing dynamic NeRFs that focus on reconstructing scenes from full training videos after the event has occurred [S1]. By applying the principles of Hidden Markov Models to radiance field estimation, the method enables the streaming of dynamic scenes for applications in social media, VR/AR, and gaming industries [S1]. The approach builds on the shared principles of dynamic modeling, specifically the first-order Markov assumption and occupancy grid transitions [S1].
