# Dynamic and Temporal Modeling

Also called: Dynamic NeRF, 4D NeRF, On-the-fly NeRF, Neural Transient Field

## Overview
Dynamic and Temporal Modeling extends static radiance field optimization to handle non-rigid motion and time-varying scenes, solving the problem of novel view synthesis for dynamic environments [S1, S2]. It distinguishes itself from static siblings like [Coarse-to-Fine NeRF](3406-coarse-to-fine-nerf.md) by introducing temporal dependencies, either through explicit deformation fields, implicit transient modeling, or on-the-fly state updates [S1, S2].

## Shared principles
The family shares the core volume rendering equation for synthesizing images from neural representations, but modifies the input domain to include time or transient state.

1.  **Radiance Field Representation**: The scene is represented by a function mapping spatial coordinates $\mathbf{x}$, viewing direction $\mathbf{d}$, and optionally time $t$ or transient parameters to volume density $\sigma$ and color $\mathbf{c}$ [S1, S2].
2.  **Volume Rendering**: The color $C(r)$ of a ray $r$ is computed by integrating along the ray:
    $$ C(r) = \sum_{i=0}^{N-1} T_i (1 - \exp(-\sigma_i \delta_i)) c_i $$
    where the transmittance $T_i$ is:
    $$ T_i = \exp\left(-\sum_{j=0}^{i-1} \sigma_j \delta_j\right) $$
    [S1]
3.  **Temporal/State Dependency**: Unlike static NeRF, the output $(\sigma, \mathbf{c})$ depends on the temporal state. This is achieved via:
    *   **Deformation**: Mapping dynamic points to a canonical static space [S2].
    *   **Transient Fields**: Modeling light transport over time explicitly [S1].
    *   **On-the-fly Updates**: Treating the radiance field as a hidden state in a Hidden Markov Model, updating it incrementally with new frames [S1].

## Subtopics

### [Neural Transient Field (NeTF)](4692-neural-transient-field-netf.md)
NeTF is a neural modeling framework for Non-Line-of-Sight (NLOS) imaging that recovers the 5D transient function implicitly represented by an MLP. Unlike NeRF, which parametrizes input training data along lines (rays), NeTF parametrizes input data on spherical wavefronts. It addresses sparse and unbalanced sampling in NLOS reconstruction through Markov chain Monte Carlo (MCMC) and a two-stage training strategy. Choose NeTF for NLOS reconstruction where light transport is modeled as transient wavefronts rather than direct visibility.

### [Projected Color-Guided Dynamic NeRF](7523-projected-color-guided-dynamic-nerf.md)
Projected Color-Guided Dynamic NeRF (OD-NeRF) is an on-the-fly training method for dynamic scenes that replaces explicit temporal inputs or deformation fields with conditioning on multi-view projected colors. By leveraging the invariance of projected color for corresponding 3D points across frames, it implicitly tracks correspondence, allowing the model to utilize radiance fields from previous frames to render the current frame with minimal optimization iterations. Unlike siblings such as [D-NeRF](8660-d-nerf.md) which rely on deformation fields that extrapolate poorly to unseen times, or [Neural Transient Field (NeTF)](4692-neural-transient-field-netf.md) which models transient artifacts explicitly, OD-NeRF achieves interactive speeds (6 FPS) by avoiding the computational overhead of temporal modeling. Choose OD-NeRF for real-time dynamic scene rendering where deformation fields are unstable or too slow.

### [On-the-Fly Dynamic NeRF Training](7582-on-the-fly-dynamic-nerf-training.md)
On-the-fly dynamic NeRF training is a method for reconstructing dynamic scenes by training the radiance field concurrently with the acquisition of training frames, enabling real-time streaming of the event as it unfolds. Unlike standard dynamic NeRFs that require full video sequences for offline 4D reconstruction, this approach minimizes optimization iterations per frame to achieve interactive speeds. It distinguishes itself from siblings like [Neural Transient Field (NeTF)](4692-neural-transient-field-netf.md) and [D-NeRF](8660-d-nerf.md) by treating the radiance field as a hidden state in a Hidden Markov Model, relying on a first-order Markov assumption to avoid storing full history. Choose this method for streaming applications where low-latency updates are critical and offline processing is impossible.

### [D-NeRF](8660-d-nerf.md)
D-NeRF is a method for dynamic scene representation that decomposes the scene into a static canonical space and a learnable deformation field. It solves the problem of novel view synthesis for non-rigidly moving objects by mapping dynamic points to a static template, distinguishing itself from methods that treat time as a direct input to the radiance field without spatial deformation. Choose D-NeRF for offline reconstruction of non-rigidly moving objects where a consistent canonical space is beneficial for view synthesis.

## Background
Dynamic NeRF methods originated from the need to extend the success of static NeRF [S1, S2]. D-NeRF introduced the canonical space and deformation field paradigm [S2]. Subsequent work explored on-the-fly training to enable real-time applications, treating the scene as a temporal sequence of states [S1]. Neural Transient Field adapted these concepts to the specific domain of Non-Line-of-Sight imaging, using spherical wavefronts instead of Cartesian rays [S1].
