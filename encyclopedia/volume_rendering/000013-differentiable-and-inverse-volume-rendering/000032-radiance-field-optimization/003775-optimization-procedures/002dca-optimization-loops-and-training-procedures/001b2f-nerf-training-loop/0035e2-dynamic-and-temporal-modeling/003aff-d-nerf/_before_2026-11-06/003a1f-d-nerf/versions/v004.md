# D-NeRF

Also called: Deformable Neural Radiance Fields

## Overview
D-NeRF is a method for synthesizing novel views of dynamic scenes by decomposing the representation into a static canonical radiance field and a time-dependent deformation field [S1, S2]. It differs from static NeRF by mapping dynamic scene points to a canonical space via learned deformations, and from methods like Neural Transient Field (NeTF) by explicitly modeling geometric motion rather than just appearance changes [S1, S2].

## How it works
**Inputs and Outputs**:
*   **Inputs**: Camera parameters (position, orientation), viewing direction $\mathbf{d}$, 3D spatial coordinate $\mathbf{x}$, and time $t$.
*   **Outputs**: Volume density $\sigma$ and color $\mathbf{c}$ for the deformed point.

**Data Structures**:
1.  **Deformation Network ($f_{\text{def}}$)**: A Multi-Layer Perceptron (MLP) that takes spatial coordinate $\mathbf{x}$ and time $t$ as input, and outputs a 3D displacement vector $\Delta \mathbf{x}$.
2.  **Canonical Radiance Field ($f_{\text{can}}$)**: A standard NeRF MLP that takes the deformed coordinate $\mathbf{x}' = \mathbf{x} + \Delta \mathbf{x}$ and viewing direction $\mathbf{d}$ as input, and outputs density $\sigma$ and color $\mathbf{c}$ [S1, S2].

**Numbered Steps**:
1.  **Ray Sampling**: For a given camera pose and time $t$, sample points $\mathbf{x}_i$ along the ray.
2.  **Deformation**: Compute the displacement for each point using the deformation network:
    $$ \Delta \mathbf{x}_i = f_{\text{def}}(\mathbf{x}_i, t) $$
3.  **Canonical Mapping**: Map the dynamic point to the canonical static space:
    $$ \mathbf{x}'_i = \mathbf{x}_i + \Delta \mathbf{x}_i $$
4.  **Radiance Field Query**: Query the canonical radiance field using the deformed coordinate and viewing direction:
    $$ (\sigma_i, \mathbf{c}_i) = f_{\text{can}}(\mathbf{x}'_i, \mathbf{d}) $$
5.  **Volume Rendering**: Compute the final color $C(r)$ using the standard volume rendering equation [S1, S2]:
    $$ C(r) = \sum_{i=0}^{N-1} T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i $$
    where $T_i = \exp\left(-\sum_{j=0}^{i-1} \sigma_j \delta_j\right)$.

**Parameters**:
*   Network depth and width for $f_{\text{def}}$ and $f_{\text{can}}$: Not given in the sources.
*   Number of samples $N$: Not given in the sources.

**Edge Cases and Pitfalls**:
*   **Complex Motion**: The deformation field is difficult to learn when scene motions are complex, leading to blurry results similar to Neural Volumes (NV) [S1].
*   **Topology Changes**: The method assumes continuous deformation fields, making it unable to simulate topological changes (e.g., object breaking) because the deformation field must be continuous [S2].
*   **Optical Effects**: The mapping from observation space to canonical space may fail to reconstruct optical effects caused by transparency or specularities in non-rigid scenes [S2].

**Pseudocode**:
```python
def dnerf_render(ray_origin, ray_direction, time_t, deformation_net, canonical_net, num_samples):
    # Sample points along the ray
    # t_vals is a linear spacing from 0 to 1
    t_vals = linspace(0, 1, num_samples)
    # Assuming ray length is normalized or scaled appropriately
    points = ray_origin + ray_direction * t_vals
    
    # Step 2: Deformation
    # deformation_net takes (x, t) and returns delta_x
    delta_x = deformation_net(points, time_t)
    
    # Step 3: Canonical Mapping
    canonical_points = points + delta_x
    
    # Step 4: Radiance Field Query
    # canonical_net takes (x_prime, d) and returns (sigma, color)
    # Note: ray_direction is constant for all points on the ray
    sigma, color = canonical_net(canonical_points, ray_direction)
    
    # Step 5: Volume Rendering
    # Compute deltas between samples
    deltas = t_vals[1:] - t_vals[:-1]
    # Add a small epsilon to avoid division by zero or log(0) issues
    # In standard NeRF, deltas are in world space, here we assume t_vals are scaled
    # to world distance or deltas are computed in world space directly.
    # For simplicity, assuming t_vals are in world units or scaled by ray length.
    # Let's assume t_vals are in world units for the delta calculation.
    # If t_vals are normalized [0,1], we need ray_length.
    # Standard implementation usually samples in world space.
    
    # Re-sampling in world space for clarity
    # near, far are clip distances
    t_vals_world = linspace(near, far, num_samples)
    deltas = t_vals_world[1:] - t_vals_world[:-1]
    points_world = ray_origin + ray_direction * t_vals_world
    
    delta_x_world = deformation_net(points_world, time_t)
    canonical_points_world = points_world + delta_x_world
    
    sigma, color = canonical_net(canonical_points_world, ray_direction)
    
    # Transmittance calculation
    alpha = 1.0 - exp(-sigma * deltas)
    transmittance = exp(-cumsum(sigma * deltas))
    # Pre-multiply transmittance for the first sample
    transmittance = concat([1.0, transmittance[:-1]])
    
    weights = alpha * transmittance
    color = sum(weights * color, axis=0)
    
    return color
```

## Subtopics

### Neural Transient Field (NeTF)
Models transient effects (like light transport) explicitly rather than geometric deformation. Choose when the dynamic element is light or transient phenomena rather than object motion [4692-neural-transient-field-netf.md].

### Projected Color-Guided Dynamic NeRF
Uses color guidance to improve dynamic rendering. Choose when color consistency across time is a primary challenge [7523-projected-color-guided-dynamic-nerf.md].

### On-the-Fly Dynamic NeRF Training
Updates the radiance field incrementally as new frames arrive. Choose for streaming or incremental learning scenarios [7582-on-the-fly-dynamic-nerf-training.md].

## Operating characteristics
*   **Time Complexity**: Depends on the number of samples and network depth. Not given in the sources.
*   **Memory Complexity**: Stores two MLPs (deformation and canonical). Not given in the sources.
*   **Measured Performance**: In comparisons, D-NeRF achieves lower PSNR and SSIM than the proposed "Dynamic MLP Maps" method, with PSNR of 29.25 and SSIM of 0.920 on the tested dataset, compared to 32.20 and 0.949 for the proposed method [S1].
*   **Strengths**: Decomposes dynamic scenes into static and dynamic components, allowing for novel view synthesis of dynamic objects [S1, S2].
*   **Limitations**: Struggles with complex scene motions, leading to blurry results [S1]. Cannot handle topological changes due to the continuity constraint of the deformation field [S2]. May lose high-frequency details in complex scenes [S1].

## Background
D-NeRF was proposed by Park et al. in 2021 [S1, S2]. It is a baseline method that treats time $t$ as an additional input for system rendering, controlling both camera view and time variables for dynamic rendering [S2]. It decomposes the dynamic scene into a static scene in the canonical space and a deformation field [S1].
