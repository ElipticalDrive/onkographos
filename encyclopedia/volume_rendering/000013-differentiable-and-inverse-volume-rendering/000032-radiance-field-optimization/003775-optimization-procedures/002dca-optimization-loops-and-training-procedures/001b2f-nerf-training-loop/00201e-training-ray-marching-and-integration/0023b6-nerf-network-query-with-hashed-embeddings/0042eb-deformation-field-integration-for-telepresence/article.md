# Deformation Field Integration for Telepresence

Also called: Telepresence Deformation, Fdeform Integration

## Overview
This method extends the FastNeRF architecture to support dynamic, expression-driven head avatars for telepresence by integrating a learnable deformation field network ($F_{deform}$) and a non-trainable skeletal deformation field ($F_{bone}$) into the ray marching process [S1, unofficial]. It solves the problem of rendering animatable 3D heads from static multi-view images by warping sample positions based on an expression vector before querying the radiance field [S1, unofficial]. It is distinguished from static NeRF variants by its explicit handling of temporal expression parameters and from other dynamic NeRF methods by its specific integration with the FastNeRF caching infrastructure and grid-based pruning [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A 3D sample position $\mathbf{p}$, an expression vector $\mathbf{e}$, and a viewing direction (implicit in the view-dependent network).
*   **Outputs:** Volume density $\sigma$ and view-dependent color coefficients $(\mathbf{u}, \mathbf{v}, \mathbf{w})$ [S1, unofficial].

**Data Structures:**
1.  **Deformation Network ($F_{deform}$):** A 6-layer Multi-Layer Perceptron (MLP). Each layer has 64 units. It takes the encoded position and expression vector as input and outputs a 3D offset vector [S1, unofficial].
2.  **Skeletal Deformation Field ($F_{bone}$):** A non-trainable function that maps $\mathbf{p}$ and $\mathbf{e}$ to a deformed position based on 3D model bones (shoulders and neck) [S1, unofficial].
3.  **Position-Dependent Network ($F_{pos}$):** The FastNeRF position network. It takes the deformed position and outputs $\sigma$ and $(\mathbf{u}, \mathbf{v}, \mathbf{w})$. It has 384 units per layer during training [S1, unofficial].
4.  **View-Dependent Network:** A 2-layer MLP with 32 units per layer, used for view-dependent color [S1, unofficial].
5.  **Sparse Volume (Pruning Cache):** A sparse 3D grid storing the minimum and maximum density values encountered for each grid cell around the face region [S1, unofficial].

**Numbered Steps:**

1.  **Positional Encoding:** Encode the input sample position $\mathbf{p}$ using the same positional encoding scheme as FastNeRF [S1, unofficial].
2.  **Skeletal Deformation:** Compute the bone-deformed position $\mathbf{p}_{bone} = \mathcal{F}_{bone}(\mathbf{p}, \mathbf{e})$. This step accounts for large rigid movements of the head and shoulders [S1, unofficial].
3.  **Deformation Field Query:** Compute the offset $\mathbf{o} = \mathcal{F}_{deform}(\mathbf{p}_{bone}, \mathbf{e})$. The network $F_{deform}$ is a 6-layer MLP with 64 units per layer [S1, unofficial].
4.  **Final Position:** Compute the warped position $\mathbf{p}_{warped} = \mathbf{p}_{bone} + \mathbf{o}$ [S1, unofficial].
5.  **Radiance Field Query:** Query the position-dependent network to get density and color features: $\{\sigma, (\mathbf{u}, \mathbf{v}, \mathbf{w})\} = \mathcal{F}_{pos}(\mathbf{p}_{warped})$ [S1, unofficial].
6.  **View-Dependent Color:** Use $(\mathbf{u}, \mathbf{v}, \mathbf{w})$ and the viewing direction to compute the final RGB color [S1, unofficial].

**Formulas:**
The composition of deformation fields and the position network is defined as [S1, unofficial]:
$$
\{\sigma, (\mathbf{u}, \mathbf{v}, \mathbf{w})\} = \mathcal{F}_{pos}(\mathcal{F}_{deform}(\mathcal{F}_{bone}(\mathbf{p}, \mathbf{e}), \mathbf{e}))
$$
where $\mathbf{e}$ is the expression vector [S1, unofficial].

The deformation network output is an offset applied to the position [S1, unofficial]:
$$
\mathbf{p}_{deform} = \mathcal{F}_{deform}(\mathbf{p}, \mathbf{e})
$$
Note: In the context of the full pipeline, this offset is added to the bone-deformed position [S1, unofficial].

**Parameters:**
*   **Training Samples:** 64 samples in the coarse stage, 64 additional samples in the fine stage [S1, unofficial].
*   **Test Samples:** 43 samples in the coarse stage. The fine stage is removed [S1, unofficial].
*   **Interpolation:** Additional samples are added by linearly interpolating between samples generated by the deformation network. These interpolated samples are looked up in the FastNeRF cache [S1, unofficial].
*   **Pruning Samples:** 50 randomly chosen samples of $\mathbf{e}$ are used to populate the sparse volume [S1, unofficial].

def query_deformation_field(p, e, F_deform, F_bone, F_pos):
    """
    Query the radiance field with deformation for telepresence.
    
    Args:
        p: 3D sample position (tensor of shape [3])
        e: Expression vector (tensor of shape [N])
        F_deform: 6-layer MLP (64 units/layer) for deformation offset
        F_bone: Non-trainable skeletal deformation function
        F_pos: Position-dependent network (384 units/layer)
        
    Returns:
        sigma: Volume density
        uvw: View-dependent color coefficients (u, v, w)
    """
    # Step 1: Skeletal deformation
    # F_bone moves samples based on 3D model bones (shoulders/neck)
    p_bone = F_bone(p, e)
    
    # Step 2: Deformation field offset
    # F_deform takes encoded position and expression, outputs offset
    # Position encoding is identical to FastNeRF
    offset = F_deform(p_bone, e)
    
    # Step 3: Warped position
    p_warped = p_bone + offset
    
    # Step 4: Radiance field query
    # F_pos outputs density and color features
    sigma, uvw = F_pos(p_warped)
    
    return sigma, uvw

def compute_pruning_volume(grid_positions, F_deform, F_pos, num_e_samples=50):
    """
    Pre-compute min/max density for grid-based pruning at test time.
    
    Args:
        grid_positions: List of 3D positions in the grid around the face
        F_deform: Deformation network
        F_pos: Position network
        num_e_samples: Number of random expression samples to test
        
    Returns:
        sparse_volume: Dictionary mapping grid index to (min_sigma, max_sigma)
    """
    sparse_volume = {}
    
    for idx, p_grid in enumerate(grid_positions):
        min_sigma = float('inf')
        max_sigma = float('-inf')
        
        # Sample 50 random expressions
        for _ in range(num_e_samples):
            e_random = random_expression_sample()
            
            # Compute deformation
            p_bone = F_bone(p_grid, e_random)
            offset = F_deform(p_bone, e_random)
            p_warped = p_bone + offset
            
            # Query density
            sigma, _ = F_pos(p_warped)
            
            if sigma < min_sigma:
                min_sigma = sigma
            if sigma > max_sigma:
                max_sigma = sigma
                
        sparse_volume[idx] = (min_sigma, max_sigma)
        
    return sparse_volume

def prune_and_query(p, e, sparse_volume, F_deform, F_bone, F_pos, grid_lookup):
    """
    Query with pruning based on sparse volume.
    
    Args:
        p: Sample position
        e: Expression vector
        sparse_volume: Pre-computed min/max density grid
        grid_lookup: Function to map position to grid index
        
    Returns:
        sigma, uvw or None if pruned
    """
    # Map position to grid index
    idx = grid_lookup(p)
    
    if idx in sparse_volume:
        min_sigma, max_sigma = sparse_volume[idx]
        
        # Prune if max density is 0 (empty)
        if max_sigma == 0:
            return None
            
        # Prune if ray would get saturated (estimate using min density)
        # If min_sigma is already high, the ray is saturated
        if min_sigma > saturation_threshold:
            return None
            
    # Proceed with full query
    p_bone = F_bone(p, e)
    offset = F_deform(p_bone, e)
    p_warped = p_bone + offset
    sigma, uvw = F_pos(p_warped)
    
    return sigma, uvw

**Edge Cases and Pitfalls:**
*   **Non-Linear Rays:** The deformation network changes sample positions along rays, meaning rays are no longer straight. This prevents the use of hardware-accelerated ray tracing described in the main FastNeRF paper [S1, unofficial].
*   **Identity Constraint:** Without an L2 regularizer constraining $F_{deform}$ to be an identity transform for a neutral expression, training is unstable [S1, unofficial].
*   **Performance Limit:** The approach is limited to rendering 300x300 pixel images with a reduced sample count to maintain 30FPS [S1, unofficial].
*   **Test-Time Optimization:** $F_{bone}$ is removed at test-time to improve performance, relying solely on $F_{deform}$ and caching for dynamic regions [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The primary bottleneck is the evaluation of $F_{deform}$ for all input samples. The grid-based pruning reduces the runtime of $F_{deform}$ by more than a factor of 2 [S1, unofficial].
*   **Memory Complexity:** Inherits the memory structure of FastNeRF, which is significantly more compact than standard NeRF due to the cache-based approach [S1, unofficial].
*   **Performance:** Renders 300x300 pixel images at 30FPS with 43 coarse samples and no fine stage at test time [S1, unofficial].
*   **Strengths:** Stabilizes training with L2 regularization; handles large movements via $F_{bone}$; efficient test-time rendering via pruning and caching.
*   **Limitations:** Cannot use hardware-accelerated ray tracing due to non-linear rays; limited resolution and frame rate compared to static NeRF; requires careful tuning of expression samples for pruning [S1, unofficial].
*   **When to Use:** Telepresence applications requiring real-time, expression-driven head avatars from static multi-view data.
*   **When Not to Use:** Scenes requiring high-resolution, high-frame-rate rendering with hardware ray tracing; scenes with complex, non-rigid deformations not captured by the expression vector [S1, unofficial].

## Background
This method was introduced by Garbin et al. in the FastNeRF paper as a proof-of-concept for telepresence scenarios [S1, unofficial]. It builds upon the FastNeRF architecture, which uses a cache-based approach to reduce memory usage [S1, unofficial]. The deformation field approach allows for the animation of 3D heads from static images by learning a mapping from expression parameters to spatial deformations [S1, unofficial].
