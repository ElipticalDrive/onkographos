# NeRF Network Query with Hashed Embeddings

Also called: HashNeRF query

## Overview
This method performs the neural network evaluation step within the NeRF training loop, mapping 3D spatial coordinates and viewing directions to density and color features using a multi-resolution hash grid. It solves the problem of efficient, differentiable feature lookup for millions of sample points per frame by replacing expensive high-dimensional coordinate embeddings with sparse, hashed feature grids [S1, unofficial]. It differs from standard NeRF point querying by utilizing a hash table to map integer coordinates to feature vectors, enabling higher resolution grids within limited memory, and differs from triplane-based methods by relying on 3D volumetric hashing rather than 2D planar projections [S1, unofficial][S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A batch of 3D sample points $\mathbf{x} \in \mathbb{R}^{N \times 3}$ and, optionally, viewing directions $\mathbf{d} \in \mathbb{R}^{N \times 3}$.
*   **Outputs:** Density values $\sigma \in \mathbb{R}^{N}$ and color features $\mathbf{c} \in \mathbb{R}^{N \times 3}$ (or higher dimensional appearance vectors depending on the MLP head).

**Data Structures:**
*   **Hash Grid:** A collection of $L$ levels. Each level $l$ has a resolution $R_l$ (e.g., $2^l$). A hash table maps hashed integer coordinates to feature vectors of dimension $F$ (typically 2 or 4).
*   **Embedding Functions:** `embed_fn` for position (e.g., positional encoding or hash lookup) and `embeddirs_fn` for direction.

**Parameters:**
*   `netchunk`: Batch size for network evaluation to manage GPU memory. Default: $1024 \times 64 = 65,536$ [S1, unofficial].
*   `inputs.shape[-1]`: Dimensionality of input coordinates (3 for position, 6 for position+direction).

**Steps:**
1.  **Reshape Inputs:** Flatten the spatial dimensions of the input positions to a 2D tensor of shape $(-1, 3)$ [S1, unofficial].
2.  **Position Embedding:** Apply the position embedding function `embed_fn` to the flattened positions. This function typically involves hashing the integer coordinates and interpolating features from the hash grid. The function also returns a validity mask `keep_mask` indicating which points are within the valid bounding box or grid bounds [S1, unofficial].
3.  **Direction Embedding (Optional):** If viewing directions are provided:
    *   Expand directions to match the batch size of positions.
    *   Reshape directions to $(-1, 3)$ [S1, unofficial].
    *   Apply the direction embedding function `embeddirs_fn` (e.g., spherical harmonics or positional encoding) [S1, unofficial].
4.  **Concatenation:** Concatenate the embedded position features and embedded direction features along the last dimension to form the final input tensor for the MLP [S1, unofficial].
5.  **Batched Network Evaluation:** Split the concatenated input tensor into chunks of size `netchchunk`. For each chunk, pass it through the neural network function `fn` (an MLP) to predict density and color [S1, unofficial].
6.  **Reshape Outputs:** Reshape the output tensors from the batched evaluation back to the original batch shape $(-1, \text{output\_dim})$ [S1, unofficial].
7.  **Masking Invalid Points:** Set the density $\sigma$ to 0 for any points where `keep_mask` is False. This prevents gradients from flowing through invalid or out-of-bounds samples [S1, unofficial].

**Pseudocode:**
```python
def query_hashnerf(positions, directions=None, embed_fn=None, embeddirs_fn=None, 
                   network_fn=None, netchunk=65536, keep_mask=None):
    """
    Query the HashNeRF network for density and color.
    
    Args:
        positions: Tensor of shape (..., 3) containing 3D coordinates.
        directions: Tensor of shape (..., 3) containing viewing directions (optional).
        embed_fn: Function to embed positions (hash lookup + interpolation).
        embeddirs_fn: Function to embed directions (e.g., spherical harmonics).
        network_fn: The MLP network.
        netchunk: Batch size for network evaluation.
        keep_mask: Boolean mask indicating valid points (from embed_fn or external check).
        
    Returns:
        sigma: Density values.
        features: Color/appearance features.
    """
    # 1. Reshape positions to flat list
    original_shape = positions.shape
    positions_flat = positions.reshape(-1, 3)
    
    # 2. Apply position embedding
    # embed_fn returns embedded positions and potentially a validity mask
    # If embed_fn does not return mask, we assume all points are valid or handle externally
    pos_embed, mask_from_embed = embed_fn(positions_flat)
    
    # Use provided mask or mask from embed_fn
    if keep_mask is None:
        if mask_from_embed is not None:
            keep_mask = mask_from_embed
        else:
            keep_mask = torch.ones(positions_flat.shape[0], dtype=torch.bool, device=positions_flat.device)
            
    # 3. Handle directions
    if directions is not None:
        # Expand directions to match input shape
        directions_expanded = directions.expand_as(positions)
        directions_flat = directions_expanded.reshape(-1, 3)
        dir_embed = embeddirs_fn(directions_flat)
        # Concatenate position and direction embeddings
        input_tensor = torch.cat([pos_embed, dir_embed], dim=-1)
    else:
        input_tensor = pos_embed
        
    # 4. Batched Network Evaluation
    num_points = input_tensor.shape[0]
    sigma_list = []
    features_list = []
    
    for i in range(0, num_points, netchunk):
        chunk = input_tensor[i:i+netchunk]
        sigma_chunk, features_chunk = network_fn(chunk)
        sigma_list.append(sigma_chunk)
        features_list.append(features_chunk)
        
    sigma = torch.cat(sigma_list, dim=0)
    features = torch.cat(features_list, dim=0)
    
    # 5. Reshape outputs
    sigma = sigma.reshape(original_shape[:-1] + (1,))
    features = features.reshape(original_shape[:-1] + (features.shape[-1],))
    
    # 6. Set sigma to 0 for invalid points
    # Expand mask to match sigma shape
    mask_expanded = keep_mask.reshape(original_shape[:-1] + (1,))
    sigma = torch.where(mask_expanded, sigma, torch.zeros_like(sigma))
    
    return sigma, features
```

## Subtopics

### HybridNeRF Model Architecture
This variant queries a differentiable radiance field using a hybrid of 3D feature grids and 2D triplanes. It fetches $K=4$ features per level from 3D feature grids at 3 resolution levels ($128^3, 256^3, 512^3$) via trilinear interpolation, and $K=4$ features per level from triplanes at 7 levels (from $128^2$ to $8,192^2$) via bilinear interpolation [S2]. Unlike standard concatenation, it sums the features across levels for both 3D grids and triplanes separately, then concatenates the summed features from the 3D grid to those from the triplanes to obtain a 16-dimensional MLP input ($4K=16$) [S2]. Viewing direction is encoded through spherical harmonics up to the 4th degree as an auxiliary input to the color MLP [S2]. Aliasing is handled as in VR-NeRF due to the multi-resolution feature grid [S2].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot L \cdot F)$, where $N$ is the number of sample points, $L$ is the number of hash levels, and $F$ is the feature dimension. Hash lookups are $O(1)$ on average.
*   **Memory Complexity:** $O(\sum_{l=0}^{L-1} R_l^3 \cdot F)$ for 3D grids or $O(\sum_{l=0}^{L-1} R_l^2 \cdot F)$ for triplanes, plus hash table overhead.
*   **Strengths:** High resolution within limited memory; fast lookup speeds; differentiable.
*   **Limitations:** Hash collisions can cause artifacts; requires careful tuning of hash table size and resolution levels; memory usage grows with resolution.
*   **When to use:** Real-time or near-real-time neural rendering; training NeRFs with high-resolution details.
*   **When not to use:** Scenes with extremely large bounding boxes where sparse hashing becomes inefficient; applications requiring strict memory bounds without sparse structures.

## Background
The method originates from the Instant-NGP paper by Müller et al. (2022), which introduced multi-resolution hash encoding for fast neural rendering [S1, unofficial][S2]. It was adopted by the HashNeRF implementation to accelerate training and inference by replacing traditional positional encoding with a learnable hash grid [S1, unofficial]. The HybridNeRF variant extends this by combining 3D and 2D representations for improved surface reconstruction [S2].
