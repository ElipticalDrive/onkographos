# LPIPS Evaluation Protocol
Also called: Learned Perceptual Image Patch Similarity

## Overview
LPIPS evaluates perceptual similarity between rendered images and ground truth using a pretrained VGG network, outputting a distance metric where lower values indicate higher similarity [S2, unofficial]. It is aggregated into the [Unified Metric Aggregation](3644-unified-metric-aggregation.md) alongside other per-view metrics [S1].

## How it works
**Inputs:** Rendered image tensor and Ground Truth (GT) image tensor [S2, unofficial].
**Outputs:** A scalar float representing the perceptual distance [S2, unofficial].

**Data Structures:**
*   Input tensors in $[0, 1]$ range.
*   Pretrained VGG network model [S2, unofficial].

**Steps:** 1. Load LPIPS VGG model and set to evaluation mode. 2. Scale render and GT tensors from $[0,1]$ to $[-1,1]$ via $x_{\text{scaled}} = 2.0 \cdot x - 1.0$. 3. Add batch dimension with `unsqueeze(0)`. 4. Pass through model. 5. Return mean of output tensor as float [S2, unofficial].

**Parameters:**
*   `net`: "vgg" (backbone architecture for perceptual features) [S2, unofficial].
*   Intensity scale: $[-1, 1]$ [S1].

**Edge Cases and Pitfalls:**
*   **Intensity Scale:** Using the default $[0, 1]$ range without scaling to $[-1, 1]$ yields incorrect results [S1].
*   **Network Weights:** The first execution downloads pretrained weights to the `TORCH_HOME` cache directory, requiring an internet connection or pre-cached weights [S2, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn as nn

def compute_lpips(render: torch.Tensor, gt: torch.Tensor, model: nn.Module) -> float:
    """
    Compute LPIPS perceptual distance.
    Inputs: render, gt tensors in [0, 1].
    Returns: float LPIPS score.
    """
    # 1. Load LPIPS VGG model and set to evaluation mode
    model.eval()
    
    # 2. Scale render and GT tensors from [0,1] to [-1,1]
    render_scaled = 2.0 * render - 1.0
    gt_scaled = 2.0 * gt - 1.0
    
    # 3. Add batch dimension with unsqueeze(0)
    if render_scaled.dim() == 3:
        render_scaled = render_scaled.unsqueeze(0)
    if gt_scaled.dim() == 3:
        gt_scaled = gt_scaled.unsqueeze(0)
        
    # 4. Pass through model
    with torch.no_grad():
        output = model(render_scaled, gt_scaled)
        
    # 5. Return mean of output tensor as float
    return output.mean().item()
```

### LPIPS Computation
Measures perceptual similarity using a pretrained VGG network, outputting a distance metric where lower values indicate higher similarity [S2, unofficial]. Steps: 1. Load LPIPS VGG model and set to evaluation mode. 2. Scale render and GT tensors from $[0,1]$ to $[-1,1]$ via `* 2.0 - 1.0`. 3. Add batch dimension with `unsqueeze(0)`. 4. Pass through model. 5. Return mean of output tensor as float [S2, unofficial]. Parameter: `net = "vgg"` [S2, unofficial]. Pitfall: First run downloads pretrained weights to `TORCH_HOME` cache; requires internet or pre-cached weights [S2, unofficial].

## Background
Introduced as a learned perceptual image patch similarity metric [S2, unofficial]. It is used to evaluate radiance field rendering quality [S1].
