# Progressive Inpainting-and-Erasing

Also called: PERF, PERF Algorithm

## Overview
Progressive Inpainting-and-Erasing (PERF) is a training strategy for single-view NeRF that avoids geometry conflicts between visible and invisible regions by computing a mask of conflicted regions and eliminating them from NeRF training [S1]. It sets itself apart from standard single-view NeRF methods by integrating a collaborative RGBD inpainting step with a progressive erasing mechanism to handle the ambiguity of unseen geometry, building on the [NeRF Training Loop](970-nerf-training-loop.md) by dynamically expanding the reference view set [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A single input panorama image $I_{rgb}$ [S1].
*   **Output:** A panoramic NeRF function $f_{nerf}$ [S1].

**Data Structures:**
*   **NeRF Representation:** Instant-NGP hash grid [S1]. The hash table size is $2^{19}$ with 16 levels of feature vectors of channel size 2 [S1].
*   **Reference Views Set ($I_{ref}$):** A set containing RGBD images (RGB + Depth) [S1].
*   **Trajectories ($\{p_k\}$):** A set of novel view camera poses generated based on the initial depth map [S1].

**Formulas:**
*   **NeRF Rendering:** The expected pixel color $\hat{C}(r)$ for a ray $r(t) = o + td$ is computed as [S1]:
    $$ \hat{C}(r) = \sum_{i=1}^{N} w_i c_i $$
    where $w_i = T_i (1 - \exp(-\sigma_i \delta_i))$, $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$, and $\delta_i = t_i - t_{i-1}$ [S1].
*   **Initial Depth Estimation:** The initial depth map $I_d$ is estimated from $I_{rgb}$ using Eq. (2) in [S1] to obtain $I_{rgbd}$ [S1].
*   **Single-View NeRF Training:** The initial NeRF $f_{nerf}$ is trained using $I_d$ and $I_{rgb}$ based on Eq. (3) in [S1].
*   **Invisible Regions:** Computed according to Eq. (4) in [S1].
*   **Collaborative RGBD Inpainting:** Performed using Stable Diffusion for RGB and a depth estimator for stitching, based on Eq. (5) in [S1].
*   **Conflicted Regions:** Computed for all $I_{ref} \in I_{ref}$ according to Eq. (6) in [S1].

**Parameters:**
*   **Initial Training Iterations:** 10,000 iterations for the single input panorama [S1].
*   **New View Sampling:** 32 new positions with approximately gradually increased distance from the original position [S1].
*   **Fine-tuning Iterations per New View:** 2,000 iterations total [S1].
    *   First 100 iterations: Supervision only from the new reference view [S1].
    *   Remaining 1,900 iterations: Supervision from all reference views [S1].
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** Initially $10^{-3}$, decayed to $10^{-4}$ with cosine annealing strategy for each learning stage of a newly sampled view [S1].
*   **Ray Sampling:** 2,048 rays sampled per iteration with ground-truth or inpainted colors and depth values [S1].

**Steps:**
1.  Estimate the initial depth map $I_d$ of the input single panorama $I_{rgb}$ using Eq. (2) to obtain $I_{rgbd}$ [S1].
2.  Train a single-view NeRF $f_{nerf}$ using $I_d$ and $I_{rgb}$ based on Eq. (3) [S1].
3.  Generate trajectories $\{p_k\}$ of novel views based on the depth map $I_d$ [S1].
4.  Initialize the set of reference views $I_{ref} = \{I_{rgbd}\}$ [S1].
5.  Iterate $n$ from 1 to `iters` (where `iters` corresponds to the 32 new positions):
    a.  Randomly sample a new camera view $p$ from $\{p_k\}$ [S1].
    b.  Compute invisible regions according to Eq. (4) [S1].
    c.  Perform collaborative RGBD inpainting using Stable Diffusion and a depth estimator (Eq. 5) to generate the completed panorama [S1].
    d.  For all $I_{ref} \in I_{ref}$, compute conflicted regions according to Eq. (6) and erase them [S1].
    e.  Add the new view to the reference views $I_{ref}$ [S1].
    f.  Fine-tune $f_{nerf}$ with the updated $I_{ref}$ [S1].

**Pseudocode:**
```python
def perfect_algorithm(I_rgb):
    # 1. Estimate initial depth and obtain RGBD
    I_d = estimate_depth(I_rgb) # Eq. (2)
    I_rgbd = combine_rgb_depth(I_rgb, I_d)
    
    # 2. Train initial single-view NeRF
    f_nerf = train_single_view_nerf(I_rgbd) # Eq. (3)
    
    # 3. Generate trajectories
    p_k = generate_trajectories(I_d)
    
    # 4. Initialize reference views
    I_ref = {I_rgbd}
    
    # 5. Progressive loop
    for n in range(1, 33): # 32 new positions
        # Sample new view
        p = random_sample(p_k)
        
        # Compute invisible regions
        invisible_regions = compute_invisible_regions(p, f_nerf) # Eq. (4)
        
        # Collaborative RGBD Inpainting
        # Uses Stable Diffusion for RGB and depth estimator for stitching
        inpainted_rgb = inpaint_rgb(invisible_regions, f_nerf) # Eq. (5)
        inpainted_depth = inpaint_depth(invisible_regions, f_nerf) # Eq. (5)
        new_view_rgbd = combine_rgb_depth(inpainted_rgb, inpainted_depth)
        
        # Erase conflicted regions from existing reference views
        for I_ref_view in I_ref:
            conflicted_regions = compute_conflicted_regions(I_ref_view, new_view_rgbd) # Eq. (6)
            erase_regions(I_ref_view, conflicted_regions)
        
        # Add new view to reference set
        I_ref.add(new_view_rgbd)
        
        # Fine-tune NeRF
        # First 100 iterations: only new view supervision
        # Next 1900 iterations: all reference views supervision
        fine_tune_nerf(f_nerf, I_ref, iterations=2000)
        
    return f_nerf
```

**Edge Cases and Pitfalls:**
*   **Perspective vs. Panorama:** The inpainting model (Stable Diffusion) is trained on perspective field-of-view camera projections, which may require global scale alignment between the predicted depth map of the reference view and the ground-truth depth map when generating novel views [S1].
*   **Geometry Conflict:** Without erasing, new views may conflict with already-learned reference views; the erasing step is critical to resolve this [S1].

## Subtopics

### Collaborative RGBD Inpainting
A method to guide NeRF training by completing RGB images and depth maps of regions of interest using Stable Diffusion and depth estimation [S1].

### Single-View NeRF with Depth Map
The foundational training step using a single panorama and estimated depth to initialize the NeRF [S1].

## Operating characteristics
*   **Time Complexity:** Training a scene usually takes about 2 hours on a single Nvidia V100 GPU [S1].
*   **Memory Complexity:** Uses 32G memory on the V100 GPU [S1].
*   **Strengths:** Avoids geometry conflicts between visible and invisible regions, enabling high-quality panoramic NeRF from a single input [S1].
*   **Limitations:** Relies on external models (Stable Diffusion, depth estimator) which may introduce artifacts if not properly aligned [S1].
*   **When to Use:** When only a single panorama is available and high-quality novel view synthesis is required [S1].
*   **When Not to Use:** When multiple views are available, as standard multi-view NeRF methods may be more efficient and accurate [S1].

## Background
*   **Origin:** Proposed in "PERF: Panoramic Neural Radiance Field From a Single Panorama" [S1].
*   **History:** The method builds on Instant-NGP [S1] and integrates recent advances in diffusion models for inpainting [S1].
*   **Usage:** Evaluated on the Replica dataset and in-the-wild data [S1].
