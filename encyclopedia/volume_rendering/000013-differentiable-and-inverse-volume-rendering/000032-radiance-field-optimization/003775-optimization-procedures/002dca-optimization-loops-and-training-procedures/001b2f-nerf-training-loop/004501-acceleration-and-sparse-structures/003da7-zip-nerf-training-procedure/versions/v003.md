# Zip-NeRF Training Procedure

Also called: Joint training for Zip-NeRF, Training Procedure, Zip-NeRF-based radiance cache training

## Overview
The Zip-NeRF Training Procedure is a two-stage optimization method for inverse rendering that jointly trains a physically-based material model, an environment map, and a hybrid radiance cache system (comprising a "fast cache" and a "NeRF-cache") to estimate incoming radiance. It solves the bottleneck of evaluating high-fidelity neural radiance fields for every importance sampling direction by using a lightweight approximation as a control variate. It sets itself apart from standard NeRF-based caches by using a fixed, small number of samples and direct distance prediction in the fast cache, while maintaining accuracy by serving as a control variate to correct the bias of the NeRF cache [S1].

## How it works
The method optimizes the parameters $\Phi$ of the physically-based model, environment map, fast cache, NeRF-cache, and occlusion-aware importance sampler. It proceeds in two distinct stages.

### Inputs and Outputs
*   **Inputs:** Ground truth images $I(\mathbf{o}, \boldsymbol{\omega}_o)$, camera poses, and scene geometry (implicit in the Zip-NeRF structure).
*   **Outputs:** Optimized parameters $\Phi$ for the material model, environment map, and both cache structures.

### Data Structures
The method relies on the structures defined in [Acceleration and Sparse Structures](11405-acceleration-and-sparse-structures.md). Specifically:
1.  **Fast Cache:** A lightweight, low-resolution hash grid and small MLP predicting incident radiance.
2.  **NeRF-cache:** A Zip-NeRF-based radiance cache storing high-frequency details.
3.  **Physically-based Model:** Defines surface reflectance properties.

### Numbered Steps

**Stage 1: Cache Training**
1.  **Initialize:** Set up the Zip-NeRF-based radiance cache.
2.  **Sample Rays:** Draw a batch of 16,384 rays.
3.  **Compute Loss:** Calculate the Charbonnier loss between the cache prediction and ground truth incoming radiance.
4.  **Optimize:** Update cache parameters using the learning rate schedule defined below.
5.  **Iterate:** Repeat for 100,000 iterations.

**Stage 2: Joint Training**
1.  **Initialize:** Load the optimized cache from Stage 1. Initialize the physically-based model, environment map, fast cache, and occlusion-aware importance sampler.
2.  **Sample Rays:** Draw a batch of 1,024 rays.
3.  **Estimate Incoming Radiance:**
    *   For each ray, estimate incoming radiance $\hat{L}_i$ using the hybrid cache.
    *   Use 64 secondary rays to estimate $\hat{L}_{fast}$ from the fast cache.
    *   Use 16 secondary rays to estimate $\Delta \hat{L}_o$ (the correction term) using the NeRF-cache.
    *   The total estimated radiance is a combination of these terms, where the fast cache serves as a control variate.
4.  **Compute Photometric Loss:**
    *   The target is the expected value $\mathbb{E}[\hat{L}_i]$. Since this lacks an analytic expression, the "gradient trick" is applied [S1].
    *   The loss function is:
        $$ \mathcal{L}_{\text{photometric}} = \frac{2 \left( I(\mathbf{o}, \boldsymbol{\omega}_o) - \hat{L}_i(\mathbf{o}, \boldsymbol{\omega}_o; \Phi) \right) \operatorname{stopgrad}\left( I(\mathbf{o}, \boldsymbol{\omega}_o) - \hat{L}_i(\mathbf{o}, \boldsymbol{\omega}_o; \Phi) \right)}{\operatorname{stopgrad}\left( \hat{L}_i^{\text{cache}}(\mathbf{o}, \boldsymbol{\omega}_o; \Phi) \right)} $$
    *   Here, $\operatorname{stopgrad}(\cdot)$ denotes the stop-gradient operation, ensuring gradients only flow through the physically-based model parameters $\Phi$ and not through the cache estimators during this stage.
5.  **Optimize:** Update all parameters ($\Phi$) using the specified learning rates.
6.  **Iterate:** Repeat for 40,000 iterations (TensoIR-synthetic) or 100,000 iterations (Open Illumination).

### Pseudocode

```python
def train_zip_nerf_stage1(cache, ground_truth_images, iterations=100000, batch_size=16384):
    """
    Stage 1: Optimize the Zip-NeRF-based radiance cache.
    """
    lr_schedule = LinearWarmupDecay(start_lr=0.0, peak_lr=0.01, warmup_steps=10000, end_lr=0.001, total_steps=iterations)
    
    for step in range(iterations):
        lr = lr_schedule.get_lr(step)
        optimizer = Optimizer(cache.parameters(), lr=lr)
        
        # Sample batch of rays
        rays = sample_rays(ground_truth_images, batch_size)
        
        # Predict incoming radiance using cache
        L_pred = cache.predict(rays)
        L_gt = rays.ground_truth_radiance
        
        # Charbonnier Loss
        loss = charbonnier_loss(L_pred, L_gt)
        
        # Backpropagate
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

def train_zip_nerf_stage2(model, env_map, fast_cache, nerf_cache, importance_sampler, 
                          ground_truth_images, iterations, batch_size=1024, 
                          fast_samples=64, nerf_samples=16):
    """
    Stage 2: Joint training of physically-based model, environment map, and caches.
    """
    lr_fast = 1.5625e-4
    lr_other = 3.125e-5
    
    optimizer_fast = Optimizer([fast_cache.parameters(), importance_sampler.parameters()], lr=lr_fast)
    optimizer_other = Optimizer([model.parameters(), env_map.parameters(), nerf_cache.parameters()], lr=lr_other)
    
    for step in range(iterations):
        rays = sample_rays(ground_truth_images, batch_size)
        
        # 1. Estimate Fast Cache Radiance (Control Variate)
        # Uses 64 secondary rays
        L_fast = fast_cache.predict(rays, num_samples=fast_samples)
        
        # 2. Estimate NeRF Cache Correction
        # Uses 16 secondary rays
        L_nerf_correction = nerf_cache.predict_correction(rays, num_samples=nerf_samples)
        
        # 3. Combine to get total estimated incoming radiance
        # L_i = L_fast + L_nerf_correction (conceptual combination based on control variate principle)
        L_i = combine_radiance(L_fast, L_nerf_correction)
        
        # 4. Compute Photometric Loss with Gradient Trick
        # Stop gradients through the cache estimators to ensure correct gradient expectation
        L_i_stopped = stop_gradient(L_i)
        I_gt = rays.ground_truth_image
        
        # Numerator: 2 * (I - L_i) * stopgrad(I - L_i)
        # Denominator: stopgrad(L_i_cache) - Note: In the formula, the denominator is 
        # stopgrad(L_i_cache) which acts as a normalization or variance reduction term 
        # in the specific RawNeRF variant used.
        numerator = 2.0 * (I_gt - L_i_stopped) * stop_gradient(I_gt - L_i_stopped)
        denominator = stop_gradient(L_i) # Using L_i as the cache estimator reference
        
        loss = numerator / denominator
        
        # 5. Backpropagate
        optimizer_fast.zero_grad()
        optimizer_other.zero_grad()
        
        loss.backward()
        
        optimizer_fast.step()
        optimizer_other.step()
```

### Parameters
*   **Stage 1 Learning Rate:** Warms up from 0 to 0.01 over the first 10,000 iterations, then linearly decreases to 0.001 for the remaining 90,000 iterations [S1].
*   **Stage 2 Learning Rate:**
    *   Fast cache and occlusion-aware importance sampler: $1.5625 \times 10^{-4}$ [S1].
    *   Physically-based model, environment map, and NeRF-cache: $3.125 \times 10^{-5}$ [S1].
*   **Batch Size:** 16,384 rays for Stage 1; 1,024 rays for Stage 2 [S1].
*   **Secondary Rays:** 64 for the fast cache; 16 for the NeRF-cache [S1].
*   **Iterations:** 100,000 for Stage 1; 40,000 (TensoIR-synthetic) or 100,000 (Open Illumination) for Stage 2 [S1].

### Edge Cases and Pitfalls
*   **Gradient Estimation:** The loss cannot be minimized directly because the expected value of the radiance estimator lacks an analytic expression. The gradient trick (stop-gradient on the estimator) is required to obtain correct gradients in expectation [S1].
*   **Precision:** The use of stop-gradient operations requires careful implementation to ensure that gradients flow only to the intended parameters (physically-based model) and not to the cache structures during joint training [S1].

## Subtopics

## Operating characteristics
*   **Time Complexity:** Stage 1 takes 5.5 hours on a single A100 for 100,000 iterations. Stage 2 takes 6.5 hours on a single A100 for 100,000 iterations [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Scaling:** The method uses a fixed number of secondary rays (64 for fast cache, 16 for NeRF-cache) per primary ray, which keeps the per-ray cost constant regardless of scene complexity, relying on the sparsity of the underlying Zip-NeRF structure [S1].
*   **Strengths:** Reduces bias in radiance caching by using a fast, low-resolution cache as a control variate for a high-fidelity NeRF cache. Efficient inference due to sparse sampling.
*   **Limitations:** Requires two-stage training. The accuracy of the control variate depends on the quality of the fast cache.
*   **When to use:** Inverse rendering tasks where high-fidelity material estimation is required, and computational efficiency is critical.
*   **When not to use:** Real-time rendering where pre-training is not feasible, or scenes with extremely high dynamic range where the fast cache approximation may be insufficient.

## Background
The Zip-NeRF Training Procedure is described in "Flash Cache: Reducing Bias in Radiance Cache Based Inverse Rendering" [S1]. It builds on the principles of Zip-NeRF [Acceleration and Sparse Structures](11405-acceleration-and-sparse-structures.md) and the RawNeRF loss formulation [S1]. The method was developed to address the bias introduced by approximating incoming radiance in inverse rendering pipelines.
