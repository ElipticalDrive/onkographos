# KNN-NeRF

Also called: KNN approach to training NeRF on point cloud, NeRFs trained on point clouds with KNN color assignment

## Overview
KNN-NeRF is a baseline method for training Neural Radiance Fields (NeRFs) using sparse 3D point clouds as supervision instead of multi-view images [S1]. It solves the problem of generating ground-truth color labels for rays that do not pass through existing points by assigning the color of the nearest point in the cloud to the ray [S1]. Unlike standard NeRF which relies on pixel colors from images, KNN-NeRF constructs a dense training signal from sparse geometry, though it struggles with sharp object borders due to the low-frequency bias of neural networks and the sparsity of the input [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A 3D point cloud $X \subset \mathbb{R}^6$ where each element $x \in X$ contains position $x_p \in \mathbb{R}^3$ and RGB color $x_c \in \mathbb{R}^3$ [S1].
*   **Input:** A set of rays $\mathcal{R}$, where each ray is defined by origin $o \in \mathbb{R}^3$ and direction $d \in \mathbb{R}^3$ [S1].
*   **Output:** A trained NeRF model that predicts color $\hat{C}(r)$ for any ray $r$ [S1].

**Data Structures**
*   **Point Cloud $X$:** A list or array of tuples/objects. Each entry has fields: `pos` (3D vector $(x, y, z)$) and `color` (3D vector $(r, g, b)$) [S1].
*   **Ray $r$:** Defined by origin $o \in \mathbb{R}^3$ and direction $d \in \mathbb{R}^3$ [S1]. Direction is normalized [G].

**Algorithm Steps**
1.  **Define Point Cloud:** Let $X$ be the input set where $x = (x_p, x_c)$ for $x_p \in \mathbb{R}^3$ and $x_c \in \mathbb{R}^3$ [S1].
2.  **Generate Rays:** Produce many rays not restricted to passing through points in $X$ [S1].
3.  **KNN Selection (Front Surface):** For a given ray origin $o$, find the $k$ nearest neighbors in $X$ based on Euclidean distance to $o$ [S1]. Let this subset be $KN_{o,k}(X)$ [S1]. This step approximates the front surface of the object relative to the camera origin [S1].
4.  **Nearest Point to Ray:** Within the subset $KN_{o,k}(X)$, find the point $\bar{x}$ that minimizes the geometric distance to the ray $r$ [S1]. The distance $d(x_p, r)$ from a point $x_p$ to a line defined by $o$ and $d$ is calculated as the length of the perpendicular vector from $x_p$ to the line [S1]. Formally:
    $$ C(X, r) = \bar{x} \in KN_{o,k}(X) : d(\bar{x}_p, r) \leq d(x_p, r) \quad \forall x \in KN_{o,k}(X) $$
    The ground truth color for the ray is $C_{gt} = \bar{x}_c$ [S1].
5.  **Training:** Train the NeRF to minimize the squared error between the predicted ray color $\hat{C}(r)$ and the assigned ground truth color $C_{gt}$ [S1].

**Formulas**
*   **Point-to-Line Distance:** $d(x_p, r) = \| (x_p - o) \times d \|$ where $\times$ denotes the cross product and $d$ is normalized [G].
*   **Ground Truth Assignment:** $C_{gt} = C_c(X, r) = \bar{x}_c$ where $\bar{x}$ is the point in $KN_{o,k}(X)$ minimizing $d(\bar{x}_p, r)$ [S1].
*   **Loss Function:** $L = \sum_{r \in \mathcal{R}} \|\hat{C}(r) - C_{gt}\|^2_2$ [S1].

**Pseudocode**
```python
import numpy as np

def distance_point_to_line(point_pos, line_origin, line_dir):
    """
    Calculates the perpendicular distance from a point to a line.
    line_dir is assumed to be normalized [G].
    """
    op = point_pos - line_origin
    return np.linalg.norm(np.cross(op, line_dir))

def get_ground_truth_color_knn(point_cloud, ray_origin, ray_dir, k):
    """
    point_cloud: List of tuples (pos, color)
    Returns the color of the nearest point in the k-nearest neighbors to the origin.
    """
    # Step 1: Find k nearest neighbors to the origin based on Euclidean distance [S1]
    distances_to_origin = []
    for i, (pos, color) in enumerate(point_cloud):
        dist = np.linalg.norm(pos - ray_origin)
        distances_to_origin.append((dist, i))
    
    # Sort by distance and take top k
    distances_to_origin.sort(key=lambda x: x[0])
    k_indices = [idx for _, idx in distances_to_origin[:k]]
    
    # Subset of points
    k_neighbors = [point_cloud[i] for i in k_indices]
    
    # Step 2: Find the point in k_neighbors closest to the ray line [S1]
    min_dist = float('inf')
    best_color = None
    
    for pos, color in k_neighbors:
        dist = distance_point_to_line(pos, ray_origin, ray_dir)
        if dist < min_dist:
            min_dist = dist
            best_color = color
            
    return best_color

def train_knn_nerf(point_cloud, rays, k, model):
    """
    Iterative training step.
    rays: List of (origin, direction) tuples.
    """
    total_loss = 0.0
    for ray_origin, ray_dir in rays:
        # Get ground truth color using KNN logic [S1]
        gt_color = get_ground_truth_color_knn(point_cloud, ray_origin, ray_dir, k)
        
        # Predict color from NeRF
        pred_color = model(ray_origin, ray_dir)
        
        # Calculate Loss: L = sum ||C_hat(r) - C_c(X, r)||^2_2 [S1]
        loss = np.sum((pred_color - gt_color) ** 2)
        total_loss += loss
```

**Parameters**
*   $k$: The number of nearest neighbors to consider from the origin. It is a hyperparameter [S1].

**Edge Cases and Pitfalls**
*   **Sparsity:** The method fails to reconstruct sharp object borders because the input point clouds are highly sparse [S1].
*   **Frequency Bias:** NeRFs are biased towards learning lower-frequency functions, making them unable to represent high-frequency variations in color and geometry present in sparse data [S1].
*   **Extrapolation:** If rays are generated in regions where no points exist nearby, the KNN selection may fail or pick distant, incorrect points, leading to artifacts [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources. Standard KNN search requires $O(N)$ per ray without spatial indexing [G].
*   **Memory Complexity:** Not given in the sources. Requires storing the point cloud $X$ and the KNN subset for each ray during training [G].
*   **Strengths:** Provides a direct way to train NeRFs on 3D point clouds without requiring multi-view image alignment or depth maps [S1].
*   **Limitations:** Cannot reconstruct sharp object borders; suffers from the low-frequency bias of neural networks when dealing with sparse data [S1].
*   **When to use:** As a baseline for training NeRFs on 3D point clouds [S1].
*   **When not to use:** When high-frequency detail or sharp geometry is required from sparse input data [S1].

## Background
KNN-NeRF was introduced in the paper "Points2NeRF: Generating Neural Radiance Fields from 3D point cloud" [S1]. It serves as a baseline method for adapting NeRF architectures to work with 3D point cloud data, addressing the need for ground-truth color assignment when rays do not intersect existing points [S1]. The authors note that while this approach is simple, it is insufficient for high-quality reconstruction due to sparsity and network bias, motivating their subsequent auto-encoder-based proposal [S1].
