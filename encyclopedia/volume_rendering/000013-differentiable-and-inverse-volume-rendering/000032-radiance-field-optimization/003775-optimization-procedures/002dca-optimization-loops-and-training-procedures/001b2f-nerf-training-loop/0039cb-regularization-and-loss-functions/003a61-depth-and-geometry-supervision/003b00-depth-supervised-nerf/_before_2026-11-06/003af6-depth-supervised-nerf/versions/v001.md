# Depth-supervised NeRF

Also called: DS-NeRF

## Overview
Depth-supervised NeRF (DS-NeRF) augments the standard NeRF training loop with a probabilistic depth regularization term to improve reconstruction quality and convergence speed, particularly in few-view settings [S1]. Unlike standard NeRF which relies solely on color reconstruction, DS-NeRF explicitly aligns the rendered ray termination distribution with sparse Structure-from-Motion (SfM) depth estimates, achieving peak PSNR in 2–3× fewer iterations [S1]. It differs from methods like MVSNeRF, which rely on dense multi-view stereo priors via Plane Sweep Volume initialization, by requiring only sparse keypoints and poses [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ training images with known camera poses (from COLMAP), sparse 3D keypoints, and their associated reprojection errors.
*   **Outputs:** A trained neural radiance field model (MLP) and associated data structures.

**Data Structures:**
*   **Keypoint Data:** For each image $j$ and keypoint $x_i$, store:
    *   $D_{ij}$: The COLMAP-estimated depth along the ray passing through $x_i$.
    *   $\hat{\sigma}_i$: The average reprojection error of keypoint $x_i$ across all views where it was detected. This serves as the variance of the depth noise model [S1].
*   **Ray Sampling:** Standard NeRF ray marching parameters (near/far bounds, number of samples $K$, sample positions $t_k$, and step sizes $\Delta t_k$) [S1].

**Algorithm:**
The method modifies the loss function of the NeRF training loop. The core innovation is the depth loss $L_{Depth}$, derived from minimizing the Kullback-Leibler (KL) divergence between the rendered ray termination distribution and a noisy depth distribution.

1.  **Depth Noise Model:** Model the true depth $D_{ij}$ as a random variable normally distributed around the COLMAP estimate with variance $\hat{\sigma}_i^2$:
    $$ D_{ij} \sim \mathcal{N}(D_{ij}, \hat{\sigma}_i) $$
    [S1]

2.  **Rendered Termination Distribution:** During ray marching, compute the probability mass $h_k$ assigned to each sample point $t_k$. This is derived from the volume density $\sigma$ and transmittance $T$ at $t_k$:
    $$ h_k = T(t_k) (1 - \exp(-\sigma(t_k) \Delta t_k)) $$
    where $T(t_k) = \exp(-\sum_{j=1}^{k-1} \sigma(t_j) \Delta t_j)$. This represents the probability that the first surface hit lies within the interval $[t_k, t_{k+1}]$ [S1].

3.  **Depth Loss Calculation:** Minimize the KL divergence between the noisy depth distribution and the rendered distribution $h(t)$. This simplifies to the following expectation over keypoints $x_i$ in image $X_j$:
    $$ L_{Depth} = \mathbb{E}_{x_i \in X_j} \left[ -\log h(t) \exp \left( -\frac{(t - D_{ij})^2}{2\hat{\sigma}_i^2} \right) \right] dt $$
    Discretizing over the $K$ sample points along the ray:
    $$ L_{Depth} \approx \mathbb{E}_{x_i \in X_j} \sum_{k=1}^{K} -\log h_k \exp \left( -\frac{(t_k - D_{ij})^2}{2\hat{\sigma}_i^2} \right) \Delta t_k $$
    [S1]

4.  **Total Loss:** Combine with the standard color reconstruction loss $L_{Color}$ (e.g., MSE between rendered and ground truth pixel colors):
    $$ L = L_{Color} + \lambda_D L_{Depth} $$
    where $\lambda_D$ is a hyperparameter balancing the two terms [S1].

5.  **Optimization:** Update the neural network parameters using gradient descent on $L$.

**Pseudocode:**
```python
def compute_depth_loss(keypoints, ray_samples, sigma, transmittance, delta_t):
    """
    Computes the DS-NeRF depth loss for a batch of rays.
    
    Args:
        keypoints: List of tuples (D_ij, sigma_i) for each keypoint on the ray.
                   D_ij: COLMAP depth estimate.
                   sigma_i: Reprojection error variance.
        ray_samples: Array of shape (K,) containing sample distances t_k along the ray.
        sigma: Array of shape (K,) containing volume density at each sample.
        transmittance: Array of shape (K,) containing transmittance T(t_k) at each sample.
        delta_t: Array of shape (K,) containing step sizes.
        
    Returns:
        depth_loss: Scalar loss value.
    """
    # Calculate probability mass h_k for each sample point
    # h_k = T(t_k) * (1 - exp(-sigma(t_k) * delta_t_k))
    # Note: transmittance array usually includes T(t_0)=1.0 at start.
    # We assume transmittance passed is T(t_k) for k=0..K-1
    
    # Avoid log(0) by clamping h_k
    h_k = transmittance * (1.0 - torch.exp(-sigma * delta_t))
    h_k = torch.clamp(h_k, min=1e-7)
    
    loss_sum = 0.0
    count = 0
    
    for D_ij, sigma_i in keypoints:
        # Compute the exponent term: -(t_k - D_ij)^2 / (2 * sigma_i^2)
        # sigma_i is the standard deviation (reprojection error)
        exponent = -((ray_samples - D_ij) ** 2) / (2.0 * (sigma_i ** 2))
        
        # Compute the term inside the sum: -log(h_k) * exp(exponent) * delta_t_k
        # We sum over k
        term = -torch.log(h_k) * torch.exp(exponent) * delta_t
        
        # Sum over all sample points k
        ray_loss = torch.sum(term)
        
        loss_sum += ray_loss
        count += 1
        
    if count == 0:
        return 0.0
        
    return loss_sum / count

    # Get sigma and transmittance values corresponding to the ray

    # 4. Total Loss
    loss = loss_color + lambda_D * loss_depth

    return loss.item()
```
[G] The transmittance $T(t_k)$ in the standard NeRF formulation is $T(t_k) = \exp(-\sum_{j=1}^{k-1} \sigma(t_j) \Delta t_j)$. The pseudocode assumes `transmittance` passed to the loss function is pre-computed for each sample $k$. The depth loss is only computed for keypoints whose depth $D_{ij}$ falls within the sampled ray interval $[near, far]$.

**Parameters:**
*   $\lambda_D$: Weight for depth loss. Value not given in the sources.
*   Training View Subsets:
    *   LLFF: 3, 6, 9 views [S1].
    *   NeRF Real: 2, 5, 10 views [S1].
    *   Redwood: 2, 5, 10 views [S1] [S1].
*   Image Resolution: $400 \times 300$ for training and evaluation [S1].
*   Camera Poses: Ground truth calibrated poses are used for COLMAP initialization in experiments [S1].

**Edge Cases and Pitfalls:**
*   **Domain Gap:** Models pre-trained on DTU (e.g., pixelNeRF-DTU, metaNeRF-DTU) struggle on NeRF Real data due to domain differences [S1].
*   **MVSNeRF Compatibility:** Adding depth supervision did not improve MVSNeRF because it already possesses a strong geometry prior via its Plane Sweep Volume (PSV) initialization [S1].
*   **Loss Choice:** Using Mean Squared Error (MSE) between rendered and sparse depth produces more artifacts than the KL divergence-based loss [S1].

## Operating characteristics
*   **Training Speed:** DS-NeRF achieves peak test PSNR in 2–3× fewer training iterations than standard NeRF [S1].
*   **Wall Time:** On a single RTX A5000, a DS-NeRF training loop takes $\sim 362.4$ ms/iter, compared to $\sim 359.8$ ms/iter for NeRF. In the 5-view case, DS-NeRF achieves NeRF’s peak PSNR approximately 13 hours faster [S1].
*   **Few-View Performance:** The benefits are magnified with fewer views. In the 2-view case, standard NeRF fails to render coherent novel views, while DS-NeRF succeeds [S1].
*   **Strengths:** Significantly faster convergence; robustness in sparse-view scenarios; reduces artifacts compared to MSE-based depth supervision.
*   **Limitations:** Requires sparse SfM keypoints and poses; performance degrades if there is a domain gap between pre-training data and target data (e.g., DTU to NeRF Real); does not benefit methods that already have strong geometric priors (like MVSNeRF) [S1].

## Background
*   **Origin:** Introduced by [S1] in "Depth-supervised NeRF: Fewer Views and Faster Training for Free" (CVPR 2022) [S1].
*   **Development:** The method builds on the observation that NeRF's termination distribution should align with the first surface encountered. It replaces the implicit geometry learning with explicit probabilistic supervision from SfM data [S1].
*   **Usage:** Evaluated on LLFF, NeRF Real, Redwood-3dscan, and DTU datasets [S1]. It has also been applied to improve other methods like pixelNeRF and IBRNet [S1].
