# Single-view NeRF Training with Depth Map

Also called: Depth-guided Single-view NeRF, Single-view NeRF with Depth Initialization

## Overview
This method addresses the under-constrained optimization problem of single-view NeRF reconstruction by initializing the geometry of visible regions using a 360-degree depth estimation prior [S1]. It sets itself apart from siblings like [Depth-Supervised NeRF](8687-depth-supervised-nerf.md) by explicitly handling the scale ambiguity and field-of-view limitations of monocular depth estimators through a deformable alignment step before NeRF training, rather than applying depth loss directly to raw estimates [S1].

## How it works
**Inputs:**
*   A single input panorama $I_{\text{rgb}}$.
*   A pre-trained monocular depth estimation model [S1].

**Outputs:**
*   A trained NeRF model $f_{\text{nerf}}$ representing the visible regions of the scene [S1].

**Data Structures:**
*   **Perspective Projections:** A set of $K$ perspective images $\{\bar{I}_{\text{rgb}}^k\}_{k=1}^K$ and their corresponding estimated depth maps $\{\bar{I}_d^k\}_{k=1}^K$.
*   **Canonical Panorama Depth Map:** A learnable depth map $I_d$ of the same resolution as $I_{\text{rgb}}$.
*   **Alignment Parameters:** For each perspective map $k$, a global scale factor $w_k$ and a local bias field $\{b_{k,i,j}\}$ corresponding to pixel coordinates $(i,j)$ [S1].

**Numbered Steps:**

1.  **Perspective Projection:** Project the single input panorama $I_{\text{rgb}}$ into $K$ perspective images $\{\bar{I}_{\text{rgb}}^k\}$ using different viewing directions. The standard value for $K$ is 20 [S1]. This is necessary because existing monocular depth estimators are trained on limited field-of-view images and fail on 360-degree panoramas warped into rectangular matrices [S1].
2.  **Monocular Depth Estimation:** Pass each perspective image $\bar{I}_{\text{rgb}}^k$ through the depth estimation model to obtain depth maps $\{\bar{I}_d^k\}$. Due to the scale ambiguity inherent in single-view depth estimation, depth values in overlapping regions between different perspectives may differ significantly [S1].
3.  **Deformable Alignment:** Align the perspective depth maps $\{\bar{I}_d^k\}$ to a canonical learnable panorama depth map $I_d$ by optimizing the alignment objective. This step resolves scale and bias inconsistencies across perspectives [S1].
4.  **NeRF Training:** Train the single-view NeRF using the RGB panorama $I_{\text{rgb}}$ and the aligned depth map $I_d$ by minimizing the combined color and depth reconstruction loss [S1].

**Formulas:**

**Depth Alignment Objective:**
The alignment is performed by optimizing the following equation [S1]:

$$
\sum_{k} \sum_{i,j} \left\| \bar{v}_{i,j}^k w_k + b_{k,i,j} - v_{M(i,j)} \right\| + L_s(b_{i,j+1}, b_{i,j}) + L_s(b_{i+1,j}, b_{i,j})
$$

Where:
*   $k$ iterates over the $K$ perspective views.
*   $(i,j)$ are pixel coordinates in the perspective depth map $\bar{I}_d^k$.
*   $\bar{v}_{i,j}^k$ is the pixel value of the estimated perspective depth map $\bar{I}_d^k$.
*   $w_k$ is the learnable scale factor for view $k$.
*   $b_{k,i,j}$ is the learnable local bias for pixel $(i,j)$ in view $k$.
*   $v_{M(i,j)}$ is the pixel value of the canonical panorama depth map $I_d$ at the coordinate mapped from $(i,j)$.
*   $M$ is a projective operation mapping perspective image coordinates to panorama image coordinates.
*   $L_s$ is the smooth L1 loss, acting as a total variation regularizer on the bias field to ensure spatial smoothness [S1].

**NeRF Training Loss:**
The NeRF is trained by minimizing [S1]:

$$
L_{\text{nerf}}' = \sum_{r \in R} \left( \|\hat{C}(r) - C(r)\|^2 + \|\hat{D}(r) - \bar{D}(r)\|^2 \right)
$$

Where:
*   $R$ is the set of rays sampled from the panorama.
*   $\hat{C}(r)$ is the expected pixel color rendered by the NeRF for ray $r$.
*   $C(r)$ is the ground-truth pixel color from $I_{\text{rgb}}$.
*   $\hat{D}(r)$ is the expected depth value rendered by the NeRF for ray $r$.
*   $\bar{D}(r)$ is the corresponding depth pixel value from the aligned depth map $I_d$ [S1].

**Parameters:**
*   $K$: Number of perspective projections. Typical value: 20 [S1].

**Pseudocode:**

```python
def single_view_nerf_with_depth(panorama_rgb, depth_estimator):
    """
    Trains a single-view NeRF using depth-guided initialization.
    
    Args:
        panorama_rgb: Input 360-degree panorama image.
        depth_estimator: Pre-trained monocular depth estimation model.
        
    Returns:
        trained_nerf: The trained NeRF model.
    """
    # Step 1: Project panorama to K perspective views
    K = 20
    perspective_images = []
    for k in range(K):
        # Project panorama to perspective view k
        # M_k maps panorama coordinates to perspective coordinates
        img_k = project_panorama_to_perspective(panorama_rgb, direction=k)
        perspective_images.append(img_k)
        
    # Step 2: Estimate depth for each perspective view
    perspective_depth_maps = []
    for img_k in perspective_images:
        # Estimate depth using monocular model
        # Note: Scale is ambiguous
        depth_k = depth_estimator(img_k)
        perspective_depth_maps.append(depth_k)
        
    # Step 3: Deformable Alignment
    # Initialize canonical panorama depth map
    I_d = initialize_depth_map(panorama_rgb.shape)
    
    # Initialize alignment parameters
    scales = [1.0 for _ in range(K)]
    biases = [zeros_like(depth_k) for depth_k in perspective_depth_maps]
    
    # Optimize alignment objective (Eq. 2)
    # Minimize: sum_k sum_i,j || v_bar_k * w_k + b_k - v_M || + TV(bias)
    optimizer = Adam([I_d, scales, biases])
    for alignment_step in range(num_alignment_steps):
        loss_align = 0.0
        for k in range(K):
            depth_k = perspective_depth_maps[k]
            w_k = scales[k]
            b_k = biases[k]
            
            # Map perspective coordinates to panorama coordinates
            # M maps (i,j) in perspective to (i',j') in panorama
            for i, j in coordinates_of(depth_k):
                i_pano, j_pano = M(i, j, view=k)
                v_bar = depth_k[i, j]
                v_pano = I_d[i_pano, j_pano]
                
                # Data alignment term
                diff = v_bar * w_k + b_k[i, j] - v_pano
                loss_align += smooth_l1_loss(diff)
                
                # Total variation regularization on bias
                if i < depth_k.height - 1:
                    loss_align += smooth_l1_loss(b_k[i+1, j] - b_k[i, j])
                if j < depth_k.width - 1:
                    loss_align += smooth_l1_loss(b_k[i, j+1] - b_k[i, j])
                    
        optimizer.zero_grad()
        loss_align.backward()
        optimizer.step()
        
    # Step 4: Train NeRF
    # Initialize NeRF model
    nerf = initialize_nerf()
    
    # Optimize NeRF loss (Eq. 3)
    optimizer_nerf = Adam(nerf.parameters())
    for training_step in range(num_training_steps):
        # Sample rays from panorama
        rays = sample_rays_from_panorama(panorama_rgb)
        
        loss_nerf = 0.0
        for r in rays:
            # Render color and depth from NeRF
            C_hat = nerf.render_color(r)
            D_hat = nerf.render_depth(r)
            
            # Get ground truth color and aligned depth
            C_gt = get_pixel_color(panorama_rgb, r)
            D_gt = get_depth_from_aligned_map(I_d, r)
            
            # Compute loss
            color_loss = l2_loss(C_hat, C_gt)
            depth_loss = l2_loss(D_hat, D_gt)
            loss_nerf += color_loss + depth_loss
            
        optimizer_nerf.zero_grad()
        loss_nerf.backward()
        optimizer_nerf.step()
        
    return nerf
```

**Edge Cases and Pitfalls:**
*   **Scale Ambiguity:** Monocular depth estimators produce depth maps with arbitrary scale. The deformable alignment step explicitly learns scale factors $w_k$ to resolve this, but if the alignment is not properly regularized, the canonical map $I_d$ may become unstable [S1].
*   **Field of View:** Standard depth estimators fail on 360-degree panoramas. Directly estimating depth on $I_{\text{rgb}}$ is not viable; projection to perspective views is required [S1].
*   **Visible Regions Only:** The trained NeRF $f_{\text{nerf}}$ only accurately represents visible regions. Invisible regions are not covered by this method and require separate inpainting procedures (e.g., using Stable Diffusion) [S1].

## Operating characteristics
*   **Time Complexity:** The method requires an initial alignment phase involving optimization over $K$ views and a subsequent NeRF training phase. The alignment cost scales with $K$ and the number of alignment iterations.
*   **Memory Complexity:** Requires storing $K$ perspective depth maps and the canonical panorama depth map $I_d$.
*   **Strengths:** Provides accurate geometry reconstruction for visible regions in single-view scenarios by leveraging strong monocular depth priors [S1].
*   **Limitations:** The reconstruction is limited to visible regions; invisible regions are not reconstructed by this specific loop [S1]. Performance depends on the quality of the monocular depth estimator [S1].

## Background
This method is part of the PERF (Panoramic Neural Radiance Field From a Single Panorama) framework [S1]. It was introduced to address the lack of geometry consistency in single-view NeRF methods, which often rely on random viewpoint generation or inpainting without explicit geometric constraints [S1]. The approach builds on 360MonoDepth [51] for depth estimation and integrates it into the NeRF training loop via a novel deformable alignment mechanism [S1].
