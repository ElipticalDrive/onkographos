# Depth Structural Consistency Regularization

Also called: RDSC

## Overview
Depth Structural Consistency Regularization (RDSC) is a geometric regularization term used in Neural Radiance Field (NeRF) training to enforce local depth continuity by aligning rendered depth values with structural priors from external depth maps, such as those generated by DepthAnythingV2 [S1]. It distinguishes itself from sibling methods like [Geometric Baseline Regularization](7475-geometric-baseline-regularization.md) by explicitly modeling the continuity of neighboring depth pixels using a k-nearest neighbors (KNN) approach and a boundary threshold, thereby preserving sharp structural edges while smoothing noise [S1, 10369-patch-based-depth-regularization.md].

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   $d^r$: Rendered depth map from the NeRF.
    *   $d^{V2}$: Prior depth map from an external model (e.g., DepthAnythingV2).
    *   $k$: Number of nearest neighbors.
    *   $m_{ar'}$: Boundary value (threshold) for minor depth variations.
*   **Output:**
    *   $\mathcal{L}_{DSC}$: The regularization loss value.

**Data Structures:**
*   Depth maps are treated as 2D grids of floating-point values.
*   KNN search is performed within a small local region of the prior depth map $d^{V2}$.

**Algorithm:**
1.  For each pixel $k_1$ in the rendered depth map $d^r$:
2.  Identify the corresponding location in the prior depth map $d^{V2}$.
3.  Find the $k$-nearest neighbors ($KNN$) of the depth value $d^{V2}_{k_2}$ within a small spatial region around $k_1$ in $d^{V2}$.
4.  For each neighbor $k_2$:
    *   Calculate the absolute difference between the rendered depth $d^r_{k_1}$ and the neighbor's rendered depth $d^r_{k_2}$.
    *   Compute the Huber-like penalty: $\max(|d^r_{k_1} - d^r_{k_2}| - m_{ar'}, 0)$.
5.  Sum these penalties over all pixels $k_1$ and their respective neighbors $k_2$.

**Formula:**
$$ \mathcal{L}_{DSC} = \sum_{k_1} \sum_{d^{V2}_{k_2} \in KNN(d^{V2}_{k_2})} \max(|d^r_{k_1} - d^r_{k_2}| - m_{ar'}, 0) $$

Where:
*   $k_1$ indexes pixels in the rendered depth map.
*   $KNN(\cdot)$ returns the $k$-nearest neighbors based on depth values within a small region.
*   $d^r_{k_1}$ and $d^r_{k_2}$ are the rendered depth values at pixels $k_1$ and $k_2$.
*   $m_{ar'}$ is a small boundary value accounting for minor depth variations between neighboring pixels [S1].

**Pseudocode:**
```python
def compute_rdsc_loss(rendered_depth, prior_depth, k_neighbors, boundary_value):
    """
    Computes the Depth Structural Consistency Regularization loss.
    
    Args:
        rendered_depth (Tensor): 2D tensor of shape (H, W) containing rendered depth values d^r.
        prior_depth (Tensor): 2D tensor of shape (H, W) containing prior depth values d^{V2}.
        k_neighbors (int): Number of nearest neighbors to consider.
        boundary_value (float): Threshold m_{ar'} for minor depth variations.
        
    Returns:
        Tensor: Scalar loss value.
    """
    loss = 0.0
    H, W = rendered_depth.shape
    
    # Iterate over each pixel in the rendered depth map
    for i in range(H):
        for j in range(W):
            # Get the rendered depth at current pixel k1
            d_r_k1 = rendered_depth[i, j]
            
            # Find k-nearest neighbors in the prior depth map within a small region
            # Note: The source specifies KNN based on depth values within a small region.
            # Implementation detail: Define a local window around (i, j) in prior_depth.
            # Extract depth values from this window.
            # Select the k neighbors with depth values closest to prior_depth[i, j] 
            # or simply the k closest spatial neighbors if "based on depth values" implies 
            # clustering. The source says "based on depth values within a small region".
            # We assume a local spatial window for efficiency and standard practice.
            
            # Define a small region (e.g., 3x3 or 5x5 window) around (i, j)
            # Exclude the center pixel itself if necessary, or include it (difference would be 0).
            # Let's assume we look at neighbors in the prior map to guide the rendered map's neighbors.
            
            # Get indices of neighbors in the rendered depth map corresponding to the prior map's neighbors
            # This requires mapping prior_depth indices to rendered_depth indices. 
            # Assuming aligned maps:
            
            neighbor_indices = get_k_nearest_neighbors(prior_depth, i, j, k_neighbors)
            
            for ni, nj in neighbor_indices:
                d_r_k2 = rendered_depth[ni, nj]
                
                # Calculate absolute difference
                diff = abs(d_r_k1 - d_r_k2)
                
                # Apply boundary value threshold
                penalty = max(diff - boundary_value, 0.0)
                
                loss += penalty
                
    return loss

def get_k_nearest_neighbors(depth_map, i, j, k):
    """
    Helper to find k-nearest neighbors in a small region.
    Simplified: Returns k closest spatial neighbors in a local window.
    """
    H, W = depth_map.shape
    candidates = []
    # Define a local window size, e.g., 3x3
    window_size = 1 
    for di in range(-window_size, window_size + 1):
        for dj in range(-window_size, window_size + 1):
            if di == 0 and dj == 0:
                continue
            ni, nj = i + di, j + dj
            if 0 <= ni < H and 0 <= nj < W:
                candidates.append((ni, nj, depth_map[ni, nj]))
    
    # Sort candidates by depth value difference from center? 
    # Source says "based on depth values within a small region".
    # This is ambiguous. It could mean KNN in depth-value space or spatial space.
    # Given "structural consistency", spatial proximity is key.
    # We will sort by spatial distance first, then pick k.
    candidates.sort(key=lambda x: (abs(x[0]-i) + abs(x[1]-j)))
    
    return [(c[0], c[1]) for c in candidates[:k]]
```

**Parameters:**
*   $k$: Number of nearest neighbors. Not given in the sources.
*   $m_{ar'}$: Boundary value for minor depth variations. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Misalignment:** If the rendered depth map and the prior depth map ($d^{V2}$) are not perfectly aligned, the KNN search may match incorrect pixels, leading to erroneous regularization [S1].
*   **Boundary Values:** The choice of $m_{ar'}$ is critical. If too small, it may penalize valid depth discontinuities; if too large, it fails to enforce continuity [S1].
*   **Sparse Views:** In sparse-view reconstruction, limited training views can result in loss of structural detail, making the regularization more important but also potentially noisier [S1].

## Subtopics

### [Patch-Based Depth Regularization](10369-patch-based-depth-regularization.md)
A technique that enforces geometric consistency by smoothing rendered depth maps while preserving sharp structural edges using bilateral or joint bilateral filters. It distinguishes itself by explicitly accounting for spatial proximity and intensity/depth similarity, reducing noise without blurring boundaries.

## Operating characteristics
*   **Time Complexity:** Depends on the KNN search. For a fixed window size and $k$, it is $O(N \cdot k)$ where $N$ is the number of pixels.
*   **Memory Complexity:** $O(N)$ to store depth maps.
*   **Strengths:** Enhances overall scene reconstruction quality by clarifying depth information for both neighboring and distant pixels [S1]. Effective in sparse-view scenarios where structural loss is common [S1].
*   **Limitations:** Relies on the quality of the external depth model (e.g., DepthAnythingV2) [S1]. Performance may degrade if the prior depth map contains significant errors or misalignments.
*   **When to use:** Sparse-view 3D reconstruction where structural continuity is critical and external depth priors are available [S1].
*   **When not to use:** When high-quality multi-view data is available, or when external depth priors are unreliable.

## Background
Depth Structural Consistency Regularization was introduced in the context of DASNeRF, which focuses on depth consistency optimization, adaptive sampling, and hierarchical structural fusion for sparse-view neural radiance fields [S1]. The method leverages modern depth estimation models like DepthAnythingV2 to provide robust depth priors, standardizing depth regularization and improving reconstruction precision [S1].
