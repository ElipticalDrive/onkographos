# Progressive Inpainting-and-Erasing

Also called: Conflicted Geometry Detection and Erasing, Inpainting-and-Erasing Strategy, PERF, PERF Algorithm

## Overview
Progressive Inpainting-and-Erasing (PERF) is a training strategy for single-view NeRF that avoids geometry conflicts between visible and invisible regions by computing a mask of conflicted regions and eliminating them from NeRF training [S1]. It sets itself apart from standard single-view NeRF methods by integrating a collaborative RGBD inpainting step with a progressive erasing mechanism to handle the ambiguity of unseen geometry, building on the [NeRF Training Loop](970-nerf-training-loop.md) by dynamically expanding the reference view set [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A single input panorama image $I_{rgb}$ [S1].
*   **Output:** A panoramic NeRF function $f_{nerf}$ [S1].

**Data Structures:**
*   **NeRF Representation:** Instant-NGP hash grid [S1]. The hash table size is $2^{19}$ with 16 levels of feature vectors of channel size 2 [S1].
*   **Reference Views Set ($I_{ref}$):** A list containing RGBD images (RGB + Depth) [S1].
*   **Trajectories ($\{p_k\}$):** A set of novel view camera poses generated based on the initial depth map [S1].

**Formulas:**
*   **NeRF Rendering:** The expected pixel color $\hat{C}(r)$ for a ray $r(t) = o + td$ is computed as [S1]:
    $$ \hat{C}(r) = \sum_{i=1}^{N} w_i c_i $$
    where $w_i = T_i (1 - \exp(-\sigma_i \delta_i))$, $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$, and $\delta_i = t_i - t_{i-1}$ [S1].
*   **Initial Depth Estimation:** The initial depth map $I_d$ is estimated from $I_{rgb}$ using Eq. (2) in [S1] to obtain $I_{rgbd}$ [S1].
*   **Single-View NeRF Training:** The initial NeRF $f_{nerf}$ is trained using $I_d$ and $I_{rgb}$ based on Eq. (3) in [S1].
*   **Invisible Regions:** Computed according to Eq. (4) in [S1].
*   **Collaborative RGBD Inpainting:** Performed using Stable Diffusion for RGB and a depth estimator for stitching, based on Eq. (5) in [S1].
*   **Conflicted Regions:** Computed for all $I_{ref} \in I_{ref}$ according to Eq. (6) in [S1].

**Parameters:**
*   **Initial Training Iterations:** 10,000 iterations for the single input panorama [S1].
*   **New View Sampling:** 32 new positions with approximately gradually increased distance from the original position [S1].
*   **Fine-tuning Iterations per New View:** 2,000 iterations total [S1].
    *   First 100 iterations: Supervision only from the new reference view [S1].
    *   Remaining 1,900 iterations: Supervision from all reference views [S1].
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** Initially $10^{-3}$, decayed to $10^{-4}$ with cosine annealing strategy for each learning stage of a newly sampled view [S1].
*   **Ray Sampling:** 2,048 rays sampled per iteration with ground-truth or inpainted colors and depth values [S1].

**Steps:**
1.  Estimate the initial depth map $I_d$ of the input single panorama $I_{rgb}$ using Eq. (2) to obtain $I_{rgbd}$ [S1].
2.  Train a single-view NeRF $f_{nerf}$ using $I_d$ and $I_{rgb}$ based on Eq. (3) [S1].
3.  Generate trajectories $\{p_k\}$ of novel views based on the depth map $I_d$ [S1].
4.  Initialize the set of reference views $I_{ref} = \{I_{rgbd}\}$ [S1].
5.  Iterate $n$ from 1 to 32:
    a.  Randomly sample a new camera view $p$ from $\{p_k\}$ [S1].
    b.  Compute invisible regions according to Eq. (4) [S1].
    c.  Perform collaborative RGBD inpainting using Stable Diffusion and a depth estimator (Eq. 5) to generate the completed panorama [S1].
    d.  For all $I_{ref} \in I_{ref}$, compute conflicted regions according to Eq. (6) and erase them [S1].
    e.  Add the new view to the reference views $I_{ref}$ [S1].
    f.  Fine-tune $f_{nerf}$ with the updated $I_{ref}$ [S1].

**Pseudocode:**
```python
def perfect_algorithm(I_rgb):
    # 1. Estimate initial depth map I_d from I_rgb using a monocular depth estimator [S1]
    I_d = estimate_depth(I_rgb)
    I_rgbd = np.stack([I_rgb, I_d], axis=-1)  # Combine RGB and depth channels [G]

    # 2. Train initial single-view NeRF f_nerf with I_d and I_rgb [S1]
    f_nerf = train_single_view_nerf(I_rgbd, iterations=10000, optimizer="Adam", lr=1e-3)

    # 3. Generate trajectories {p_k} of novel views based on I_d [S1]
    p_k = generate_trajectories(I_d, num_positions=32)

    # 4. Initialize reference views set
    I_ref = [I_rgbd]

    # 5. Progressive loop over 32 new positions [S1]
    for n in range(1, 33):
        # Randomly sample a new camera view p from {p_k} [S1]
        p = random_sample(p_k)

        # Compute invisible regions according to Eq. (4) [S1]
        invisible_mask = compute_invisible_regions(p, f_nerf, epsilon=1e-3)

        # Collaborative RGBD inpainting using Stable Diffusion and depth estimator [S1]
        inpainted_rgb = inpaint_rgb(invisible_mask, f_nerf)
        inpainted_depth = inpaint_depth(invisible_mask, f_nerf)
        new_view_rgbd = np.stack([inpainted_rgb, inpainted_depth], axis=-1)

        # For all I_ref in I_ref, compute conflicted regions and erase them [S1]
        final_conflict_mask = None
        for ref_view in I_ref:
            conflict_mask = compute_conflicted_regions(ref_view, new_view_rgbd, epsilon=1e-3)
            if final_conflict_mask is None:
                final_conflict_mask = conflict_mask
            else:
                final_conflict_mask = final_conflict_mask & conflict_mask  # Logic AND across views [S1]

        # Erase conflicted regions from supervision [S1]
        for i, ref_view in enumerate(I_ref):
            I_ref[i] = erase_regions(ref_view, final_conflict_mask)

        # Add new view to reference views [S1]
        I_ref.append(new_view_rgbd)

        # Fine-tune f_nerf with updated I_ref [S1]
        fine_tune_nerf(f_nerf, I_ref, iterations=2000, lr_schedule="cosine", lr_start=1e-3, lr_end=1e-4)

    return f_nerf

# Helper definitions to make pseudocode self-contained [G]
def estimate_depth(I_rgb):
    # Standard monocular depth estimation model [G]
    return depth_model(I_rgb)

def train_single_view_nerf(I_rgbd, iterations, optimizer, lr):
    # Standard NeRF training loop with given data and optimizer [G]
    nerf = InstantNGP(hash_table_size=2**19, levels=16, channels=2)
    for step in range(iterations):
        rays = sample_rays(I_rgbd, count=2048)
        loss = compute_loss(nerf, rays)
        optimizer.step(loss)
    return nerf

def generate_trajectories(I_d, num_positions):
    # Sample poses at gradually increasing distances from original position [S1]
    return [sample_pose_from_depth(I_d) for _ in range(num_positions)]

def random_sample(poses):
    return np.random.choice(poses)

def compute_invisible_regions(new_pose, nerf, epsilon):
    # Eq. (4): m'_{ij} = I(warp(v_{ij}) - v'_{ij} > epsilon) [S1]
    ref_depth = render_depth(nerf, new_pose)
    new_depth = get_depth_from_pose(new_pose)
    warped_ref = warp_depth(ref_depth, new_pose)
    return (warped_ref - new_depth > epsilon).astype(float)

def inpaint_rgb(mask, nerf):
    # Stable Diffusion inpainting for missing regions [S1]
    return stable_diffusion_inpaint(nerf.render(), mask)

def inpaint_depth(mask, nerf):
    # Depth estimator for stitching missing regions [S1]
    return depth_estimator_inpaint(nerf.render_depth(), mask)

def compute_conflicted_regions(ref_view, new_view, epsilon):
    # Eq. (6): m''_{ij} = I(v_{ij} - warp(v'_{ij}) > epsilon) [S1]
    ref_depth = ref_view.depth
    new_depth = new_view.depth
    warped_new = warp_depth(new_depth, ref_view.pose)
    return (ref_depth - warped_new > epsilon).astype(float)

def erase_regions(view, mask):
    # Set masked pixels to None/ignore in loss calculation [G]
    view.masked = mask
    return view

def fine_tune_nerf(nerf, ref_views, iterations, lr_schedule, lr_start, lr_end):
    # 2000 iterations: first 100 use only new view, next 1900 use all views [S1]
    optimizer = Adam(lr=lr_start)
    for step in range(iterations):
        if step < 100:
            rays = sample_rays(ref_views[-1], count=2048)
        else:
            rays = sample_rays(ref_views, count=2048)
        loss = compute_loss(nerf, rays, ignore_masked=True)
        current_lr = cosine_anneal(step, iterations, lr_start, lr_end)
        optimizer.set_lr(current_lr)
        optimizer.step(loss)
```

**Edge Cases and Pitfalls:**
*   **Perspective vs. Panorama:** The inpainting model (Stable Diffusion) is trained on perspective field-of-view camera projections, which may require global scale alignment between the predicted depth map of the reference view and the ground-truth depth map when generating novel views [S1].
*   **Geometry Conflict:** Without erasing, new views may conflict with already-learned reference views; the erasing step is critical to resolve this [S1].

## Subtopics

### Collaborative RGBD Inpainting
A method to guide NeRF training by completing RGB images and depth maps of regions of interest using Stable Diffusion and depth estimation. It sets itself apart from standard inpainting by jointly optimizing RGB and depth consistency for 3D geometry. Choose it when unseen regions must be filled while preserving geometric plausibility for novel view synthesis. See [Collaborative RGBD Inpainting](2199-training-ray-marching-and-integration.md).

### Single-View NeRF with Depth Map
The foundational training step using a single panorama and estimated depth to initialize the NeRF [S1]. It sets itself apart from multi-view initialization by relying on monocular depth priors rather than stereo or structure-from-motion [S1]. Choose it when only one panoramic image is available. See [Neural Volume Scene Setup](4168-neural-volume-scene-setup.md).

## Operating characteristics
*   **Time Complexity:** Training a scene usually takes about 2 hours on a single Nvidia V100 GPU [S1].
*   **Memory Complexity:** Uses 32G memory on the V100 GPU [S1].
*   **Strengths:** Avoids geometry conflicts between visible and invisible regions, enabling high-quality panoramic NeRF from a single input [S1].
*   **Limitations:** Relies on external models (Stable Diffusion, depth estimator) which may introduce artifacts if not properly aligned [S1].
*   **When to Use:** When only a single panorama is available and high-quality novel view synthesis is required [S1].
*   **When Not to Use:** When multiple views are available, as standard multi-view NeRF methods may be more efficient and accurate [S1].

## Background
*   **Origin:** Proposed in "PERF: Panoramic Neural Radiance Field From a Single Panorama" [S1].
*   **History:** The method builds on Instant-NGP [S1] and integrates recent advances in diffusion models for inpainting [S1].
*   **Usage:** Evaluated on the Replica dataset and in-the-wild data [S1].
