# Mip-NeRF 360 Proposal Sampling

Also called: Mip-NeRF 360 Proposal Network, Modified Resampling, Proposal Sampling, Proposal sampler, midpoint resampling

## Overview
Mip-NeRF 360 Proposal Sampling is an adaptive ray sampling strategy that uses a concurrently optimized proposal network to generate sample intervals concentrated in opaque regions, reducing aliasing and improving rendering quality in unbounded scenes [S1, S3]. It differs from standard uniform or hierarchical sampling by learning a density function $\Theta_{prop}$ to bound the weights produced by the main NeRF, and employs a midpoint resampling technique to mitigate aliasing artifacts caused by coarse histogram erosion [S1, S3].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Ray $r$, coarse NeRF $\Theta_{coarse}$ (or main NeRF $\Theta_{NeRF}$), proposal network $\Theta_{prop}$.
*   **Outputs:** A set of sample intervals (midpoints and endpoints) for volume rendering.

**Data Structures:**
*   **Proposal Network ($\Theta_{prop}$):** A small Multi-Layer Perceptron (MLP) mapping 3D positions to density.
    *   Architecture: 4 layers, 256 hidden units [S3].
    *   Input: 3D position $\vec{p} \in \mathbb{R}^3$.
    *   Output: Density $\sigma \in \mathbb{R}$ [S3].
*   **Coarse Histogram:** Weights $w$ computed from coarse samples.

**Formulas:**
The weight $w_i$ for a sample $i$ is calculated as [S3]:
$$ w_i = T_i(1 - \exp(-\sigma_i \delta_i)) $$
where $T_i$ is the transmittance up to sample $i$, $\sigma_i$ is the density, and $\delta_i$ is the distance between samples [S3].

**Steps:**
1.  **Coarse Sampling:** Sample $N_c$ points uniformly along the ray $r$ using $\Theta_{coarse}$ to produce a set of weights $w \in \mathbb{R}^{N_c}$ [S3].
2.  **Proposal Network Optimization:** The proposal network $\Theta_{prop}: \mathbb{R}^3 \rightarrow \mathbb{R}, \vec{p} \mapsto \sigma$ is concurrently optimized with the main NeRF to bound the weights $w$ produced by $\Theta_{NeRF}$ [S3].
3.  **Resampling (Midpoint Resampling):**
    *   Sample $n$ sorted values from the coarse histogram weights [S1].
    *   Use the midpoints of each adjacent sample pair as the endpoints for the new set of "fine" intervals [S1].
    *   Reflect the first sample around the first endpoint and the last sample around the last endpoint to handle boundary conditions [S1].
    *   *Note:* This modified resampling reduces aliasing compared to using sampled points directly as endpoints, as it prevents the "erosion" of the coarse histogram where samples fail to span the extent of each bin [S1].
4.  **Final Rendering:** Perform one final NeRF round using the generated intervals to render the image [S2].

**Parameters:**
*   **Proposal Network Size:** 4 layers, 256 hidden units [S3].
*   **Number of Proposal Rounds:** Two subsequent rounds of proposal sampling produce two sets of weights $\{\hat{w}_1, \hat{w}_2\}$ [S3].

**Edge Cases and Pitfalls:**
*   **Boundary Conditions:** Without reflection, the first and last intervals may be poorly defined. Reflecting the first/last sample around the first/last endpoint handles this [S1].
*   **Aliasing:** Direct use of coarse samples as endpoints can cause aliasing due to histogram erosion. Midpoint resampling mitigates this [S1].

**Pseudocode:**
```python
def mip_neRF_360_proposal_sampling(ray, theta_coarse, theta_prop, n_samples):
    """
    ray: Ray object with origin and direction
    theta_coarse: Coarse NeRF MLP
    theta_prop: Proposal Network MLP (4 layers, 256 units)
    n_samples: Number of fine samples to generate
    """
    # Step 1: Coarse Sampling
    # Uniformly sample Nc points along the ray
    coarse_positions = sample_uniform_along_ray(ray, Nc=64) # Typical Nc not explicitly given, but implied by context
    coarse_densities = theta_prop(coarse_positions) # Or theta_coarse depending on implementation phase
    # Calculate weights w_i = T_i * (1 - exp(-sigma_i * delta_i))
    coarse_weights = compute_weights(coarse_positions, coarse_densities, ray)
    
    # Step 2: Resampling (Midpoint Resampling)
    # Sample n sorted values from coarse histogram weights
    # Note: The source describes sampling values from the histogram, 
    # effectively selecting indices or positions based on weight distribution.
    # For implementation, we assume we select n indices from the coarse samples
    # proportional to their weights, or simply sort the coarse samples by position
    # and select n points. The source says "sample n sorted values from coarse histogram weights".
    # This implies selecting n indices i_1, ..., i_n such that the weights are representative.
    # A common interpretation in this context is to select n points from the coarse set
    # based on the cumulative weight distribution.
    
    # Simplified interpretation: Select n indices from coarse samples based on weights
    indices = sample_indices_proportional_to_weights(coarse_weights, n_samples)
    selected_positions = coarse_positions[indices]
    selected_positions.sort()
    
    # Use midpoints of adjacent sample pairs as endpoints
    # If selected_positions has n elements, we get n-1 intervals?
    # The source says "use midpoints... as endpoints for n-1 fine intervals".
    # But we want n fine samples? Or n intervals?
    # Mip-NeRF 360 typically generates a set of intervals.
    # Let's assume we want n fine intervals.
    # The source says "sample n sorted values... use midpoints... for n-1 fine intervals".
    # This implies the output is n-1 intervals.
    
    endpoints = []
    for i in range(len(selected_positions) - 1):
        midpoint = (selected_positions[i] + selected_positions[i+1]) / 2
        endpoints.append(midpoint)
        
    # Handle boundaries by reflection
    first_endpoint = endpoints[0]
    last_endpoint = endpoints[-1]
    
    # Reflect first sample around first endpoint
    reflected_first = first_endpoint + (first_endpoint - selected_positions[0])
    # Reflect last sample around last endpoint
    reflected_last = last_endpoint + (last_endpoint - selected_positions[-1])
    
    # Adjust endpoints to include reflections?
    # The source says "reflect the first and last sample around the first and last endpoint".
    # This likely means the first interval starts at reflected_first and ends at first_endpoint?
    # Or the endpoints are adjusted.
    # Let's assume the intervals are defined by:
    # Interval 0: [reflected_first, first_endpoint]
    # Interval i: [endpoints[i-1], endpoints[i]]
    # Interval n-2: [endpoints[n-3], reflected_last]
    
    fine_intervals = []
    fine_intervals.append((reflected_first, first_endpoint))
    for i in range(len(endpoints) - 1):
        fine_intervals.append((endpoints[i], endpoints[i+1]))
    fine_intervals.append((endpoints[-1], reflected_last))
    
    # Step 3: Final Rendering
    # Render using the fine intervals
    # This involves sampling within these intervals and using theta_neRF
    return render_with_intervals(fine_intervals, theta_neRF)
```

## Subtopics

### [Dynamic Optimal Sampling Layer](8681-dynamic-optimal-sampling-layer.md)
The Dynamic Optimal Sampling Layer is a three-stage sampling strategy (coarse, optimal, fine) that inserts an optimal sampling layer between coarse and fine sampling to adaptively adjust the number and locations of new sample points based on priorities from the previous stage, targeting high-weight regions. It builds on Mip-NeRF 360 Proposal Sampling by replacing uniform or fixed-density refinement with a priority-driven allocation mechanism that uses dilation to expand coverage in high-density areas, thereby improving sampling efficiency and rendering quality in sparse reconstruction scenarios.

### [NeRF-Casting Optimization and Representation](11489-nerf-casting-optimization-and-representation.md)
NeRF-Casting is a differentiable volume rendering method that extends NeRF with explicit reflection modeling to handle glossy surfaces and consistent view-dependent appearance. It solves the problem of inaccurate specular highlights and inconsistent reflections in standard neural radiance fields by introducing a reflection-dependent color MLP and a modified proposal sampling scheme. It builds on Mip-NeRF 360 Proposal Sampling and Zip-NeRF by adapting their adaptive sampling and hash grid structures to support reflected rays.

### [MCBlock](12607-mcblock.md)
MCBlock is a dynamic-resolution ray-sampling algorithm for Neural Radiance Field (NeRF) training that partitions training images into pixel blocks of varying sizes based on texture intensity, using Monte Carlo Tree Search (MCTS) to optimize the partition during training. It accelerates training by focusing high-frequency sampling on complex regions and low-frequency sampling on simple regions, addressing the inefficiency of uniform pixel-wise sampling and the artifacts of static multi-resolution methods. Unlike its siblings, it combines active sampling with dynamic block partitioning and block-wise novel view synthesis to eliminate high-frequency flaws in simple-texture regions.

### Inverse-Depth Uniform Sampling
Inverse-Depth Uniform Sampling is a sampling strategy for depth in the GeNeRF component, using uniform sampling in inverse-depth space [S4]. The number of inverse-depth samples is 64 for IBRNet and DBARF, and 128 for BARF and GARF [S4].

## Background
Mip-NeRF 360 Proposal Sampling was introduced in the paper "Mip-NeRF 360: Unbounded Anti-Aliased Neural Radiance Fields" [S1]. It builds on the original Mip-NeRF method [S1]. The proposal network $\Theta_{prop}$ is concurrently optimized with the main NeRF MLP [S3].
