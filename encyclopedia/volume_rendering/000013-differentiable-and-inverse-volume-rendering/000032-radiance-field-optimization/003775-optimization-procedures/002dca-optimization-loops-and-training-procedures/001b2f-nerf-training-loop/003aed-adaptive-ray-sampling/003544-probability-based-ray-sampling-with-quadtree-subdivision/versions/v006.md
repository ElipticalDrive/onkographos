# Probability-based Ray Sampling with Quadtree Subdivision

Also called: Adaptive Quadtree Subdivision, Fast Learning Radiance Fields by Shooting Much Fewer Rays method, Ours, Quadtree Subdivision

## Overview
This method accelerates radiance field training by dynamically adjusting ray distribution through context-based probability sampling and adaptive quadtree subdivision [S1]. It differs from sibling methods like [Mip-NeRF 360 Sampling and Training](3393-mip-nerf-360-sampling-and-training.md) and [Coarse-to-Fine NeRF](3406-coarse-to-fine-nerf.md) by using rendering error to decide node subdivision into four children rather than just adjusting point counts per fixed block, allowing the number of leaf nodes to change during training [S1].

## How it works
**Inputs:** Input views with height $H_i$ and width $W_i$; a radiance field model $\Theta$ (e.g., NeRF, Plenoxels, Instant-NGP, NeuS); a convergence threshold $\alpha$; a constant ray count for marked nodes $n_0$.
**Outputs:** A trained radiance field; rendered images with reduced training time.

**Data Structures:**
*   **Quadtree:** Constructed on each input view. Each leaf node $F$ represents a block of the image.
*   **Node State:** Each leaf node has a state: `unmarked` (active) or `marked` (converged).
*   **Probability Map:** A 2D array of size $H_i \times W_i$ storing the sampling probability density for each pixel.

**Steps:**

1.  **Initialization:**
    Construct a quadtree on each input view $I_i$. Initially, all nodes are unmarked. The number of rays emitted from image $I_i$ is $M_i = H_i \times W_i$ [S1].

2.  **Probability Density Calculation:**
    For each pixel $(u, v)$, calculate the probability density using the standard deviation of color in a $3 \times 3$ patch [S1]. Let $c(x, y)$ be the color of pixel $(x, y)$ and $\bar{c}$ be the mean color in the patch [S1].
    $$
    \text{variance}(c(u, v)) = \frac{1}{9} \sum_{x \in \{u-1, u, u+1\}} \sum_{y \in \{v-1, v, v+1\}} [c(x, y) - \bar{c}]^2
    $$
    The probability distribution $g'(u, v)$ is derived from this variance. A random sampling ratio is added to ensure trivial areas (smooth surfaces) are also learned [S1].

3.  **Ray Sampling:**
    For each leaf node $F$ in the quadtree:
    *   If $F$ is **unmarked**: Sample and shoot rays on $F$ according to the prior probability distribution $g'(u, v)$ [S1]. The number of sampled rays equals the number of pixels in the node [S1].
    *   If $F$ is **marked**: Sample only $n_0$ rays (typically $n_0 = 10$) [S1].

4.  **Rendering and Error Calculation:**
    Render the sampled rays using the current model $\Theta$. For each ray $r_i \in F$, let $V_\Theta(r_i)$ be the rendered color and $c_i$ be the ground truth color [S1]. Calculate the average rendering error $e_F$ over all emitted rays in node $F$:
    $$
    e_F = \text{mean}_{r_i \in F} (V_\Theta(r_i) - c_i)
    $$
    Note: The source formula uses subtraction, implying an absolute or signed error mean, though typically rendering error is squared or absolute. The source explicitly writes $V_\Theta(r_i) - c_i$ [S1].

5.  **Subdivision and Marking:**
    Compare $e_F$ with threshold $\alpha$:
    *   If $e_F < \alpha$: Mark leaf node $F$ as converged (`marked`). It will not be subdivided again [S1].
    *   If $e_F \ge \alpha$: Subdivide node $F$ into four smaller leaf nodes [S1].

6.  **Iteration:**
    Repeat steps 3-5 for subsequent training iterations. The total number of rays $M_{il}$ after $l$ subdivisions is:
    $$
    M_{il} = Q^l_1 \times \left(\frac{H_i \times W_i}{2^l}\right) + Q^l_2 \times n_0
    $$
    where $Q^l_1$ is the number of unmarked leaf nodes and $Q^l_2$ is the number of marked leaf nodes [S1].

**Pseudocode:**

```python
def initialize_quadtree(image_height, image_width):
    """
    Creates a quadtree where the root represents the entire image.
    Returns a list of leaf nodes, initially just the root.
    """
    root = Node(0, 0, image_height, image_width, state='unmarked')
    return [root]

def calculate_probability_density(image):
    """
    Calculates probability density for each pixel based on 3x3 color variance.
    Adds random sampling ratio to cover smooth areas.
    """
    h, w, _ = image.shape
    prob_map = np.zeros((h, w))
    
    # Calculate variance for each pixel using 3x3 patch
    for u in range(h):
        for v in range(w):
            # Define patch boundaries with clamping
            u_start = max(0, u - 1)
            u_end = min(h, u + 2)
            v_start = max(0, v - 1)
            v_end = min(w, v + 2)
            
            patch = image[u_start:u_end, v_start:v_end]
            mean_color = np.mean(patch)
            variance = np.mean((patch - mean_color) ** 2)
            prob_map[u, v] = variance
            
    # Normalize to sum to 1
    prob_map /= np.sum(prob_map)
    
    # Add random sampling ratio (e.g., 20% uniform, 80% context-based)
    # Note: Exact ratio is not specified, but ablation shows 20-90% range tested.
    # We assume a fixed ratio r_random for implementation.
    r_random = 0.2 
    uniform_prob = 1.0 / (h * w)
    context_prob = prob_map
    
    final_prob = r_random * uniform_prob + (1 - r_random) * context_prob
    final_prob /= np.sum(final_prob)
    return final_prob

def sample_rays_from_node(node, prob_map):
    """
    Samples rays for a specific node based on its area and the global probability map.
    If node is marked, returns n0 rays.
    """
    h, w = node.height, node.width
    if node.state == 'marked':
        # Sample n0 rays randomly within the node's bounds
        return sample_random_rays(node.x, node.y, h, w, n0=10)
    else:
        # Sample rays proportional to node area and probability map
        # The source says "number of sampled rays is equal to the number of pixels of the node"
        # for unmarked nodes initially, but implies dynamic adjustment.
        # For implementation, we sample all pixels in the node or a subset based on prob.
        # Given the formula M_il, it implies full pixel sampling for unmarked nodes 
        # relative to their size, but weighted by probability.
        # Simplified: Sample one ray per pixel in the node, weighted by prob_map.
        pixels = get_pixels_in_node(node)
        return sample_weighted_rays(pixels, prob_map)

def update_quadtree(leaf_nodes, model, ground_truth_images, threshold_alpha):
    """
    Evaluates error and subdivides or marks nodes.
    """
    new_leaf_nodes = []
    
    for node in leaf_nodes:
        # Render rays for this node
        rays = sample_rays_from_node(node, prob_map)
        rendered_colors = model.render(rays)
        ground_truth_colors = get_ground_truth_for_rays(rays, ground_truth_images)
        
        # Calculate average error
        # Source formula: mean(V_theta(ri) - ci)
        errors = rendered_colors - ground_truth_colors
        avg_error = np.mean(errors)
        
        if avg_error < threshold_alpha:
            node.state = 'marked'
            new_leaf_nodes.append(node)
        else:
            # Subdivide into 4 children
            child_h, child_w = node.height // 2, node.width // 2
            children = [
                Node(node.x, node.y, child_h, child_w, state='unmarked'),
                Node(node.x + child_w, node.y, child_h, child_w, state='unmarked'),
                Node(node.x, node.y + child_h, child_h, child_w, state='unmarked'),
                Node(node.x + child_w, node.y + child_h, child_h, child_w, state='unmarked')
            ]
            new_leaf_nodes.extend(children)
            
    return new_leaf_nodes

def train_loop():

    leaf_nodes = initialize_quadtree(H, W)

        for node in leaf_nodes:
            all_rays.extend(sample_rays_from_node(node, prob_map))
            
        # Train model on all_rays
        train_model(model, all_rays)
        
        # Update quadtree structure
        leaf_nodes = update_quadtree(leaf_nodes, model, ground_truth_images, threshold_alpha)
        
        # Calculate total rays for monitoring
        Q1 = sum(1 for n in leaf_nodes if n.state == 'unmarked')

        total_rays = Q1 * (H * W / (2 ** epoch)) + Q2 * n0
```

**Parameters:**
*   $\alpha$: Convergence threshold. Not given in the sources.
*   $n_0$: Constant number of rays sampled on marked leaf nodes. Typically $n_0 = 10$ [S1].
*   Patch Size: $3 \times 3$ is used. Alternatives ($5 \times 5, 7 \times 7, 9 \times 9$) and metrics (variation, entropy) were tested but found insensitive [S1].
*   Random Sampling Ratio: A ratio is added to the probability distribution. The exact value is not specified, but ablation shows performance peaks between 20% and 90% [S1].

**Edge Cases and Pitfalls:**
*   **Smooth Surfaces:** Context-based probability may ignore trivial areas. Adding random sampling mitigates this [S1].
*   **Precision:** The error calculation uses mean of $(V_\Theta(r_i) - c_i)$. If this is not absolute or squared, negative errors might cancel positive ones. The source does not specify absolute value or squaring [S1].
*   **Boundary Conditions:** Patch calculations require handling image boundaries (clamping or padding) [S1].

## Operating characteristics
*   **Time Complexity:** Training time is reduced by 15-40% compared to baselines [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:**
    *   **LLFF (Forward-Facing):** Training time reduced from 66.6 min (Plenoxels) to 40.4 min (39% reduction), PSNR increased from 24.60 to 25.12 [S1].
    *   **Tanks and Temples:** Instant-NGP training time reduced from 354s to 285s (19% reduction), PSNR increased from 27.91 to 28.25 [S1].
    *   **DTU:** NeuS training time reduced from 9.2h to 7.3h (21% reduction), Chamfer Distance improved from 0.87 to 0.73 [S1].
*   **Strengths:** Reduces training time while maintaining or improving accuracy (PSNR/SSIM/LPIPS/CD) [S1]. General framework applicable to NeRF, NeRF++, Plenoxels, Instant-NGP, Mip-NeRF 360, and NeuS [S1].
*   **Limitations:** Initial training time may increase slightly due to sampling and subdividing overhead [S1].

## Background
*   **Origin:** Proposed in "Fast Learning Radiance Fields by Shooting Much Fewer Rays" [S1].
*   **History:** The method addresses the high computational cost of radiance field training by reducing the number of rays needed in converged regions [S1].
*   **Usage:** Applied as a general framework to accelerate various radiance field methods [S1].
