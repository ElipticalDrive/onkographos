# NeuSample

Also called: Neural Sample Field

## Overview
NeuSample is a method for efficient novel view synthesis that replaces the coarse-to-fine hierarchical sampling stage of Neural Radiance Fields (NeRF) with a lightweight neural network called a Neural Sample Field [S1, unofficial]. It solves the problem of high computational overhead during inference by mapping a ray directly into a sampling distribution, enabling single-shot inference without the costly coarse stage [S1, unofficial]. Unlike NeRF's hierarchical sampling which requires two-stage inference, NeuSample discards the coarse stage entirely, saving approximately a quarter of inference time while achieving better or comparable rendering quality on standard benchmarks [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A ray $r = (o, d)$, where $o = (x_o, y_o, z_o)$ is the ray origin and $d = (\theta, \phi)$ is the view direction.
*   **Output:** $N$ relative sample positions $\hat{t}_1, \dots, \hat{t}_N \in [0, 1]$ from the Neural Sample Field, which are transformed into 3D coordinates $x_i$ and fed into the Radiance Field $R_\Theta$ to produce density $\sigma$ and color $c$. The final output is the accumulated pixel color via volume rendering.

**Data Structures**
*   **Neural Sample Field ($S_\Theta$):** A Multi-Layer Perceptron (MLP).
    *   **Input Layer:** Concatenated position-encoded ray origin and direction.
    *   **Hidden Layers:** 8 Fully Connected (FC) layers with ReLU activations.
    *   **Skip Connection:** The input is concatenated with the output of the 4th hidden layer.
    *   **Hidden Dimension:** 256.
    *   **Output Layer:** 1 FC layer mapping 256 features to $N$ dimensions, followed by a Sigmoid activation.
*   **Radiance Field ($R_\Theta$):** The standard NeRF MLP architecture [S1, unofficial].

**Parameters**
*   $N$: The number of samples output by the Neural Sample Field. The source uses $N=192$ in experiments, replacing the sum of coarse ($N_c$) and fine ($N_f$) samples used in standard NeRF [S1, unofficial].
*   Position Encoding: 10-frequency sine/cosine encoding applied to both ray origin and direction [S1, unofficial].

**Algorithm Steps**
1.  **Ray Generation:** Compute the ray origin $o$ and direction $d$ for a given pixel based on the camera pose [S1, unofficial].
2.  **Position Encoding:** Apply 10-frequency position encoding $\tilde{\tau}$ to the ray origin $o$ and direction $d$. Concatenate the encoded origin and direction to form the input vector [S1, unofficial].
3.  **Neural Sample Field Inference:** Pass the concatenated encoded input through the Neural Sample Field network $S_\Theta$.
    *   The input passes through 8 FC layers with ReLU activations.
    *   A skip connection concatenates the original input with the output of the 4th layer.
    *   The result passes through an additional FC layer mapping 256-dimension features into an $N$-dimension vector.
    *   Apply a Sigmoid activation to obtain relative sample positions $\hat{t}_1, \dots, \hat{t}_N \in [0, 1]$ [S1, unofficial].
4.  **Coordinate Transformation:** Map the relative positions $\hat{t}_i$ to absolute distances $t_i$ using the near bound $t_n$ and far bound $t_f$:
    $$ t_i = (1 - \hat{t}_i)t_n + \hat{t}_i t_f $$
    Compute the 3D coordinates of the $i$-th sample:
    $$ x_i = o + t_i d $$
    where $d$ is the normalized direction vector [S1, unofficial].
5.  **Radiance Field Evaluation:** Feed the 3D coordinates $x_i$ and the view direction $d$ into the Radiance Field network $R_\Theta$ to obtain density $\sigma_i$ and color $c_i$ for each sample [S1, unofficial].
6.  **Volume Rendering:** Perform volume rendering on the samples to generate the final pixel color $\hat{C}(r)$:
    $$ \hat{C}(r) = \sum_{i=1}^{N} T_i (1 - \exp(-\sigma_i \delta_i)) c_i $$
    where $\delta_i = t_{i+1} - t_i$ is the distance between adjacent samples, and $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ is the accumulated transmittance [S1, unofficial].

        freq_bands = 2.0 ** torch.linspace(0, self.num_frequencies - 1, self.num_frequencies)

def render_pixel(origin, direction, tn, tf, sample_field, radiance_field):
    """
    Single pixel rendering using NeuSample.
    """
    # 1. Get relative positions
    # sample_field expects batched input, so unsqueeze if necessary
    relative_t = sample_field(origin.unsqueeze(0), direction.unsqueeze(0)) # (1, N)
    
    # 2. Map to absolute distances
    # t_i = (1 - t_hat_i) * tn + t_hat_i * tf
    t_abs = (1 - relative_t) * tn + relative_t * tf # (1, N)
    
    # 3. Compute 3D coordinates
    # x_i = o + t_i * d
    # direction is assumed normalized
    samples = origin.unsqueeze(0) + t_abs.unsqueeze(-1) * direction.unsqueeze(0) # (1, N, 3)
    
    # 4. Evaluate Radiance Field
    # R_Theta takes (x, d)
    sigma, color = radiance_field(samples, direction.unsqueeze(0)) # (1, N, 3) for color, (1, N) for sigma
    
    # 5. Volume Rendering
    # Compute delta
    delta = torch.diff(t_abs, dim=-1, prepend=torch.zeros_like(t_abs[:, :1]))
    
    # Compute transmittance
    # T_i = exp(-sum_{j=1}^{i-1} sigma_j * delta_j)
    alpha = 1.0 - torch.exp(-sigma * delta)
    transmittance = torch.exp(-torch.cumsum(sigma * delta, dim=-1))
    # Adjust transmittance for the first term
    # Standard formula: C = sum T_i (1 - exp(-sigma_i delta_i)) c_i
    # T_i here is transmittance BEFORE sample i.
    # T_0 = 1. T_i = T_{i-1} * (1 - alpha_{i-1})
    
    # Recalculate T correctly for rendering equation
    # T_i = exp(-sum_{j=0}^{i-1} sigma_j delta_j)
    # Using cumsum of sigma*delta
    sigma_delta = sigma * delta
    T = torch.exp(-torch.cumsum(sigma_delta, dim=-1))
    # T[i] corresponds to transmittance arriving at sample i? 
    # No, cumsum[i] includes sample i. 
    # We need T_i = exp(-sum_{j=0}^{i-1} sigma_j delta_j)
    # So T_shifted = torch.cat([torch.ones_like(T[:, :1]), T[:, :-1]], dim=-1)
    
    T_shifted = torch.cat([torch.ones_like(T[:, :1]), T[:, :-1]], dim=-1)
    
    # Contribution
    contribution = T_shifted * alpha * color
    pixel_color = torch.sum(contribution, dim=-2) # Sum over N
    
    return pixel_color.squeeze(0)

**Edge Cases and Pitfalls**
*   **Precision:** The relative positions $\hat{t}_i$ are in $[0, 1]$. If the network outputs values outside this range before sigmoid, the sigmoid handles it, but gradients might vanish if saturated.
*   **Boundaries:** The near ($t_n$) and far ($t_f$) bounds must be consistent with the scene geometry. Incorrect bounds lead to samples being placed in empty space or missing geometry.
*   **Degenerate Input:** Rays with zero length or undefined direction should be handled by the camera pose generation step [S1, unofficial].

## Subtopics

### Sample Field Extraction
A method to compress the Neural Sample Field, reducing the number of samples (e.g., to 64) to further accelerate inference while maintaining competitive quality [S1, unofficial].

### Depth Boost
An initialization technique for real-world scenes where the output mean of the extracted sample field is forced to fit the depth predicted by a learned regular field [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Saves approximately 25% of inference time compared to standard NeRF [S1, unofficial].
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** On Realistic Synthetic 360° and Real ForwardFacing benchmarks, NeuSample achieves better or comparable PSNR to NeRF while being faster [S1, unofficial]. For example, it achieves +0.59 PSNR on Ficus and +0.63 PSNR on Lego compared to NeRF [S1, unofficial].
*   **Strengths:** Single-shot inference eliminates the coarse stage overhead; learns efficient sampling distributions directly.
*   **Limitations:** Requires training a separate network for sampling; performance may vary on scenes with complicated geometry structures without proper initialization (e.g., depth boost) [S1, unofficial].
*   **When to use:** When inference speed is critical and the scene geometry is relatively well-behaved or can be initialized with depth priors.
*   **When not to use:** When the highest possible quality from hierarchical sampling is required and latency is not a constraint.

## Background
NeuSample was proposed in the paper "NeuSample: Neural Sample Field for Efficient View Synthesis" [S1, unofficial]. It addresses the computational overhead of NeRF's coarse-to-fine hierarchical sampling by introducing a neural sample field that maps rays directly to sample distributions. The work builds on the foundational NeRF framework [S1, unofficial].
