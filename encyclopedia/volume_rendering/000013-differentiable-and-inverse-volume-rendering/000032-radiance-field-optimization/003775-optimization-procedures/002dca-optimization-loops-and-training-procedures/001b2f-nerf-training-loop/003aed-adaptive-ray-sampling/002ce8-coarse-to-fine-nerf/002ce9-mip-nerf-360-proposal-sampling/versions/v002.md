# Mip-NeRF 360 Proposal Sampling

Also called: Modified Resampling, Proposal Sampling, midpoint resampling

## Overview
Mip-NeRF 360 Proposal Sampling generates a second, finer set of sample intervals based on the weights of a coarse histogram to reduce aliasing [S1]. It sets itself apart from standard hierarchical sampling by using a "modified resampling" procedure that employs midpoints of adjacent samples as interval boundaries, which qualitatively reduces aliasing artifacts compared to using sampled points directly as endpoints [S1].

## How it works
### Inputs and Outputs
*   **Input:** Coarse histogram weights, a target number of samples $n$, and the scene extent endpoints ($t_{\text{start}}$, $t_{\text{end}}$) [S1].
*   **Output:** $n-1$ fine intervals defined by their endpoints, which are used to sample a fine network [S1].

### Data Structures
The proposal networks use a Hash Grid (NGP) structure [S2].
*   **Hierarchy:** The hierarchy is truncated at maximum grid sizes of 512 and 2048 [S2].
*   **Channels:** A single channel of features is used for each proposal NGP, as these models only need to predict density, not density and color [S2].

### Steps
1.  Sample $n$ sorted values from the coarse histogram weights [S1].
2.  Use the midpoints of each adjacent sample pair as the endpoints for the new set of $n-1$ fine intervals [S1].
3.  Reflect the first sample around the first endpoint and the last sample around the last endpoint to handle boundary conditions [S1].
4.  Perform two rounds of proposal sampling to bound scene geometry and recursively generate new sample intervals [S2].
5.  Perform one final NeRF round to render the final set of intervals into an image [S2].

### Pseudocode
```python
def modified_resampling(coarse_samples, first_endpoint, last_endpoint):
    """
    Generates fine intervals from coarse samples using midpoint resampling.
    Args:
        coarse_samples: List of n sorted sample positions from coarse histogram.
        first_endpoint: The start of the first coarse bin.
        last_endpoint: The end of the last coarse bin.
    Returns:
        List of n-1 fine intervals, where each interval is (start, end).
    """
    n = len(coarse_samples)
    fine_intervals = []
    
    # Step 2: Compute midpoints of adjacent sample pairs
    midpoints = []
    for i in range(n - 1):
        midpoint = (coarse_samples[i] + coarse_samples[i + 1]) / 2.0
        midpoints.append(midpoint)
        
    # Step 3: Reflect first and last samples around endpoints
    reflected_first = 2.0 * first_endpoint - coarse_samples[0]
    reflected_last = 2.0 * last_endpoint - coarse_samples[-1]
    
    # Construct intervals: [reflected_first, m0], [m0, m1], ..., [m_{n-2}, reflected_last]
    fine_intervals.append((reflected_first, midpoints[0]))
    for i in range(1, len(midpoints)):
        fine_intervals.append((midpoints[i - 1], midpoints[i]))
    fine_intervals.append((midpoints[-1], reflected_last))
    
    return fine_intervals

def sample_from_weights(weights, num_samples):
    """Standard inverse CDF sampling from discrete weights [G]."""
    import random
    cumulative = []
    total = 0.0
    for w in weights:
        total += w
        cumulative.append(total)
    cumulative = [c / total for c in cumulative]
    samples = []
    for _ in range(num_samples):
        r = random.random()
        lo, hi = 0, len(cumulative) - 1
        while lo < hi:
            mid = (lo + hi) // 2
            if cumulative[mid] < r:
                lo = mid + 1
            else:
                hi = mid
        samples.append(lo)
    return samples

def render_neRF(intervals):
    """Standard volume rendering pass over the given intervals [G]."""
    return intervals

def proposal_sampling_pipeline(coarse_histogram_weights, num_samples, first_endpoint, last_endpoint):
    """
    Executes the two-round proposal sampling process.
    """
    # Round 1: Sample from coarse histogram
    coarse_indices = sample_from_weights(coarse_histogram_weights, num_samples)
    coarse_samples = sorted(coarse_indices)
    
    # Generate fine intervals for Round 2
    fine_intervals_round1 = modified_resampling(coarse_samples, first_endpoint, last_endpoint)
    
    # Round 2: Recursive proposal
    round2_samples = []
    for _ in range(num_samples):
        interval_idx = random.randint(0, len(fine_intervals_round1) - 1)
        start, end = fine_intervals_round1[interval_idx]
        round2_samples.append(random.uniform(start, end))
    round2_samples.sort()
    
    # Generate final intervals for the fine network
    final_intervals = modified_resampling(round2_samples, first_endpoint, last_endpoint)
    
    # Final Round: Render using the final intervals
    image = render_neRF(final_intervals)
    
    return image
```

### Parameters
*   **Number of samples ($n$):** Not explicitly fixed in the sources.
*   **Grid Sizes:** Proposal NGP hierarchy truncated at maximum grid sizes of 512 and 2048 [S2].
*   **Channels:** Single channel for proposal NGP [S2].

### Edge Cases and Pitfalls
*   **Aliasing:** Using sampled points directly as endpoints "erodes" the coarse histogram because samples are unlikely to span the extent of each coarse bin, leading to aliasing [S1]. The midpoint resampling method mitigates this [S1].
*   **Boundary Conditions:** Without reflecting samples, the first and last intervals may not be properly bounded, leading to artifacts at the scene edges [S1].

## Operating characteristics
*   **Time and Memory Complexity:** Not given in the sources.
*   **Strengths:** Qualitatively reduces aliasing artifacts [S1]. Efficiently bounds scene geometry through recursive proposal sampling [S2].
*   **Limitations:** Requires two rounds of proposal sampling before the final render, increasing training steps [S2].
*   **When to use:** When training neural radiance fields where aliasing reduction via modified resampling is desired [S1].

## Background
Mip-NeRF 360 Proposal Sampling was introduced in the Mip-NeRF 360 paper [S1]. It was later adopted and adapted in Zip-NeRF, which uses two rounds of proposal sampling to bound scene geometry and recursively generate new sample intervals [S2]. The method addresses the limitations of standard hierarchical sampling by modifying the resampling procedure to reduce aliasing [S1].
