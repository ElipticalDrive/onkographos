# Coarse-to-Fine NeRF

Also called: Two-Stage NeRF, Coarse-Fine NeRF

## Overview
Coarse-to-Fine NeRF is a hierarchical sampling strategy that improves the learning of high-frequency details in neural radiance fields by allocating computational resources adaptively along rays [S1, S3, unofficial]. It solves the problem of uniform sampling being inefficient for sparse or complex geometry by using a coarse network to identify opaque regions and a fine network to densely sample those specific areas [S1, S3, unofficial]. Unlike standard uniform sampling which distributes points evenly across the entire ray segment, this method clusters additional samples near the object boundaries identified by the coarse pass, thereby improving detail reconstruction without a proportional increase in coarse sampling cost [S1, S3, unofficial].

## How it works
The method employs two separate Multi-Layer Perceptrons (MLPs), a coarse network and a fine network, which share the same architecture but maintain distinct parameters [S2, S3, unofficial]. Both networks are trained jointly to predict volume density and view-dependent color [S2, unofficial].

### Inputs and Outputs
*   **Inputs**: Ray origins $\mathbf{o} \in \mathbb{R}^3$, ray directions $\mathbf{d} \in \mathbb{R}^3$, near bound $t_{near}$, far bound $t_{far}$.
*   **Outputs**: Rendered color $\mathbf{C} \in \mathbb{R}^3$, depth map, accumulated alpha (opacity), and weights for each sample.

### Data Structures
*   **Coarse Samples**: A tensor of shape $(N, N_c)$ containing depth values $t_c$ along $N$ rays, where $N_c$ is the number of coarse samples per ray.
*   **Fine Samples**: A tensor of shape $(N, N_f)$ containing depth values $t_{fine}$, where $N_f$ is the number of fine samples per ray.
*   **Concatenated Samples**: A sorted tensor of shape $(N, N_c + N_f)$ containing all sample depths $t_f$.
*   **Raw Network Output**: A tensor of shape $(N, N_{samples}, 4)$, where the first 3 channels are RGB color (sigmoided to $[0,1]$) and the 4th channel is volume density $\sigma$ [S4, unofficial].

### Parameters
*   $N_c$: Number of coarse samples per ray. Default: 64 [S3, unofficial].
*   $N_f$: Number of fine samples per ray. Default: 128 [S3, unofficial].
*   `perturb`: Boolean flag to enable stratified sampling (jittering) during the coarse pass to break symmetry and reduce aliasing. Default: True [S3, unofficial].
*   `raw_noise_std`: Standard deviation of uniform noise added to volume density $\sigma$ before ReLU activation. Default: 0 [S4, unofficial].
*   `white_bkgd`: Boolean flag. If True, adds unaccounted transmittance $(1 - \alpha_{acc})$ to the RGB map, assuming a white background [S4, unofficial].
*   `pos_levels`: Number of frequency octaves for positional encoding. Default: 10 [S2, unofficial].
*   `dir_levels`: Number of frequency octaves for directional encoding. Default: 4 [S2, unofficial].

### Steps
1.  **Coarse Sampling**: Generate $N_c$ sample depths $t_c$ uniformly along the ray segment $[t_{near}, t_{far}]$. If `perturb` is enabled, apply stratified sampling by adding uniform noise within each bin to break symmetry [S3, S4, unofficial].
2.  **Coarse Query**: Convert $t_c$ to 3D points $\mathbf{p}_c = \mathbf{o} + t_c \mathbf{d}$. Query the coarse MLP with $\mathbf{p}_c$ and view directions to obtain raw outputs $\mathbf{raw}_c$ [S3, S4, unofficial].
3.  **Coarse Rendering**: Convert $\mathbf{raw}_c$ to weights $w_c$ using volume rendering equations (see Formulas). Compute the coarse color $\mathbf{rgb}_{coarse}$ and depth [S3, S4, unofficial].
4.  **Hierarchical Sampling**: Use the coarse weights $w_c$ to define a probability distribution. Sample $N_f$ new depths $t_{fine}$ from this distribution using inverse transform sampling (or `sample_pdf`) [S3, S4, unofficial].
    *   *Pitfall*: The sampling step is non-differentiable. Gradients must not flow back through this step to the coarse network. The weights $w_c$ and coarse samples $t_c$ must be detached from the computation graph before generating $t_{fine}$ [S3, S4, unofficial].
5.  **Concatenation and Sorting**: Concatenate the coarse samples $t_c$ and fine samples $t_{fine}$ into a single tensor $t_f = [t_c, t_{fine}]$. Sort $t_f$ in ascending order to ensure correct volume rendering integration [S3, S4, unofficial].
6.  **Fine Query**: Convert sorted $t_f$ to 3D points $\mathbf{p}_f = \mathbf{o} + t_f \mathbf{d}$. Query the fine MLP with $\mathbf{p}_f$ and view directions to obtain raw outputs $\mathbf{raw}_f$ [S3, S4, unofficial].
7.  **Fine Rendering**: Convert $\mathbf{raw}_f$ to final weights $w_f$ and compute the final color $\mathbf{rgb}_{fine}$ [S3, S4, unofficial].

### Formulas
**Distance between samples**:
$$ \delta_i := z_{i+1} - z_i $$
An infinite distance ($10^{10}$) is appended to the last column to maintain tensor shape and force the opacity of the last segment to 1 [S4, unofficial].

**Alpha Compositing**:
$$ \alpha_i = 1 - \exp(-\hat{\sigma}_i \cdot \delta_i) $$
Where $\hat{\sigma}_i = \text{ReLU}(\sigma_i + \mathcal{U}[0, 1] \cdot \text{raw\_noise\_std})$ [S4, unofficial].

**Transmittance**:
$$ T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right) $$
Computed as the cumulative product of $(1 - \alpha)$, prepended with 1. The last column (transmittance after the last sample) is discarded [S4, unofficial].

**Weights**:
$$ w_i = \alpha_i T_i $$

**Rendered Color**:
$$ \mathbf{C} = \sum_{i=1}^{N} w_i \mathbf{c}_i $$
If `white_bkgd` is True, add $(1 - \sum w_i) \cdot \mathbf{1}$ to $\mathbf{C}$ [S4, unofficial].

**Loss Function**:
$$ L = L_{coarse} + L_{fine} $$
$$ L_{coarse} = \text{mean}((\mathbf{rgb}_{coarse} - \mathbf{target})^2) $$
$$ L_{fine} = \text{mean}((\mathbf{rgb}_{fine} - \mathbf{target})^2) $$
Both coarse and fine predictions are supervised against the target pixel color [S3, unofficial].

### Pseudocode
```python
import torch
import torch.nn.functional as F

def raw2outputs(raw, z_vals, rays_d, raw_noise_std=0, white_bkgd=False):
    """
    Converts raw network outputs to radiance, depth, and weights.
    raw: (ray #, sample #, 4) -> RGB (0-1) and sigma
    z_vals: (ray #, sample #)
    rays_d: (ray #, 3)
    """
    # Calculate distances between samples
    dists = z_vals[..., 1:] - z_vals[..., :-1]
    # Append infinite distance for the last segment
    dists = torch.cat([dists, torch.full_like(dists[..., :1], 1e10)], dim=-1)
    # Scale by ray direction norm
    dists = dists * torch.norm(rays_d[..., None, :], dim=-1)

    # Extract RGB and Sigma
    rgb = torch.sigmoid(raw[..., :3])
    sigma_raw = raw[..., 3]

    # Add noise to sigma if enabled
    noise = 0.
    if raw_noise_std > 0.:
        noise = torch.randn(sigma_raw.shape) * raw_noise_std
        sigma_raw = sigma_raw + noise

    # Compute alpha: 1 - exp(-sigma * dist)
    # Apply ReLU to sigma before exponentiation
    sigma = F.relu(sigma_raw)
    alpha = 1. - torch.exp(-sigma * dists)

    # Compute transmittance T: cumprod(1 - alpha), prepended with 1
    # T_i = exp(-sum_{j=1}^{i-1} sigma_j * delta_j)
    ones = torch.ones_like(alpha[..., :1])
    # (1 - alpha) + epsilon for numerical stability
    transmittance_factors = 1. - alpha + 1e-10
    # Concatenate 1 at the start
    T_cumprod = torch.cumprod(torch.cat([ones, transmittance_factors], dim=-1), dim=-1)
    # Discard the last element (transmittance after the last sample)
    T = T_cumprod[..., :-1]

    # Weights: w_i = alpha_i * T_i
    weights = alpha * T

    # Rendered RGB
    rgb_map = torch.sum(weights[..., None] * rgb, dim=-2)

    # Rendered Depth
    depth_map = torch.sum(weights * z_vals, dim=-1)

    # Accumulated Alpha
    acc_map = torch.sum(weights, dim=-1)

    # White background assumption
    if white_bkgd:
        rgb_map = rgb_map + (1. - acc_map[..., None])

    return rgb_map, depth_map, acc_map, weights

def coarse_to_fine_render(rays_o, rays_d, near, far, n_coarse, n_fine, 
                          coarse_mlp, fine_mlp, perturb=True, raw_noise_std=0):
    """
    Implements the Coarse-to-Fine NeRF training step.
    """
    # 1. Coarse Sampling
    # Generate N_c evenly spaced bins
    t_vals = torch.linspace(near, far, n_coarse, device=rays_o.device)
    t_vals = t_vals.expand(rays_o.shape[0], n_coarse)

    if perturb:
        # Stratified sampling: jitter within bins
        mid = (t_vals[..., :-1] + t_vals[..., 1:]) / 2
        upper = torch.cat([mid, t_vals[..., -1:]], dim=-1)
        lower = torch.cat([t_vals[..., :1], mid], dim=-1)
        t_c = lower + (upper - lower) * torch.rand_like(t_vals)
    else:
        t_c = t_vals

    # 2. Coarse Query
    pts_c = rays_o.unsqueeze(1) + rays_d.unsqueeze(1) * t_c.unsqueeze(2)
    # Assume direction encoding is handled inside MLP or prepended
    raw_c = coarse_mlp(pts_c, rays_d) # Shape: (N, N_c, 4)

    # 3. Coarse Rendering
    rgb_coarse, _, _, weights_c = raw2outputs(raw_c, t_c, rays_d, raw_noise_std)

    # 4. Hierarchical Sampling (Fine)
    # Detach to prevent gradient flow back to coarse network
    weights_c_detached = weights_c.detach()
    t_c_detached = t_c.detach()
    
    # Sample N_f points from the distribution defined by weights_c
    # Using inverse transform sampling on the CDF of weights_c
    # This is a simplified representation of sample_pdf
    cdf = weights_c_detached / (weights_c_detached.sum(dim=-1, keepdim=True) + 1e-10)
    # Generate uniform random numbers for inverse transform
    u = torch.rand_like(t_c_detached)
    # Find indices where CDF >= u
    # In practice, this involves torch.searchsorted or similar logic
    # Here we assume a helper function sample_pdf exists or implement basic inverse transform
    # For completeness, we note that t_fine is drawn from the distribution of weights_c
    
    # Simplified implementation of sampling from weights:
    # Normalize weights to probabilities
    probs = weights_c_detached / (weights_c_detached.sum(dim=-1, keepdim=True) + 1e-10)
    # Cumulative sum
    cdf_probs = torch.cumsum(probs, dim=-1)
    # Pad with 0 at start and 1 at end
    cdf_probs = torch.cat([torch.zeros_like(cdf_probs[..., :1]), cdf_probs, 
                           torch.ones_like(cdf_probs[..., :1])], dim=-1)
    # Clip u to [0, 1]
    u = torch.clamp(u, min=0, max=1)
    # Find bin indices
    bin_indices = torch.searchsorted(cdf_probs, u, side='right') - 1
    # Linear interpolation within bins (standard inverse transform sampling)
    # Lower bound of bin
    t_low = t_c_detached.gather(1, bin_indices)
    # Upper bound of bin
    t_high = t_c_detached.gather(1, bin_indices + 1)
    # Normalize u within the bin's CDF range
    p = cdf_probs.gather(1, bin_indices + 1) - cdf_probs.gather(1, bin_indices)
    p = torch.clamp(p, min=1e-10)
    t_fine = t_low + (u - cdf_probs.gather(1, bin_indices)) / p * (t_high - t_low)

    # 5. Concatenation and Sorting
    t_f = torch.cat([t_c_detached, t_fine], dim=-1)
    t_f_sorted, _ = torch.sort(t_f, dim=-1)

    # 6. Fine Query
    pts_f = rays_o.unsqueeze(1) + rays_d.unsqueeze(1) * t_f_sorted.unsqueeze(2)
    raw_f = fine_mlp(pts_f, rays_d) # Shape: (N, N_c+N_f, 4)

    # 7. Fine Rendering
    rgb_fine, depth_fine, _, _ = raw2outputs(raw_f, t_f_sorted, rays_d, raw_noise_std)

    return rgb_coarse, rgb_fine, depth_fine
```

## Subtopics

### [Hexagonal Multisampling Pattern Derivation](3498-hexagonal-multisampling-pattern-derivation.md)
Constructs a multisampling pattern for a conical frustum by warping a zero-mean, identity-covariance hexagonal pattern from a cylinder. It ensures uniform distribution along the ray and in angles, minimizing sample count. It differs from [DONeRF Depth Oracle Filtering](4472-donerf-depth-oracle-filtering.md) by matching statistical moments rather than filtering depth, and from [Hierarchical Sampling for Hemispherical Wavefronts](4691-hierarchical-sampling-for-hemispherical-wavefronts.md) by using fixed hexagonal geometry.

### [DONeRF Depth Oracle Filtering](4472-donerf-depth-oracle-filtering.md)
A preprocessing step for depth oracle training targets in DONeRF to improve surface detection consistency. It distinguishes itself from [Hexagonal Multisampling Pattern Derivation](3498-hexagonal-multisampling-pattern-derivation.md) by operating on classification targets in image/depth space rather than deriving sampling patterns, and from [Hierarchical Sampling for Hemispherical Wavefronts](4691-hierarchical-sampling-for-hemispherical-wavefronts.md) by smoothing discontinuities in one-hot encoding targets.

### [Hierarchical Sampling for Hemispherical Wavefronts](4691-hierarchical-sampling-for-hemispherical-wavefronts.md)
A coarse-to-fine sampling scheme for 2D hemispherical wavefronts in Non-Line-of-Sight (NLOS) imaging. It addresses the intractability of explicit volumetric resampling on a hemisphere using a differentiable hierarchical approach, distinct from the 1D ray sampling in NeRF.

### [Mip-NeRF 360 Proposal Sampling](5408-mip-nerf-360-proposal-sampling.md)
A hierarchical sampling strategy for Mip-NeRF 360 that allocates samples efficiently to solve aliasing. It sets itself apart by using a "modified resampling" procedure with midpoints of adjacent samples as interval boundaries, reducing aliasing artifacts compared to using sampled points directly as endpoints.

### Single Multiscale MLP Architecture
A variant using a single MLP with parameters $\Theta$ for both coarse and fine stages, enabled by Implicit Positional Encoding (IPE) features that explicitly encode scale [S5]. The optimization problem balances coarse and fine losses with a hyperparameter $\lambda$ (default 0.1) [S5]. Unlike standard NeRF which uses two distinct MLPs because PE features only model one scale, this approach allows one MLP to learn a multiscale representation, cutting model size in half and improving efficiency [S5].

### Segmented Sampling
A strategy that selectively increases the sampling rate only within the bounding box of an object area to ensure detailed sampling without significantly increasing overall computational cost [S6]. It addresses the pitfall of direct composition where sparse sampling on small objects relative to the scene causes missing areas in rendered images and inaccurate PDF distribution in the fine stage [S6].

### DONeRF PDF Sampling
A method to translate depth oracle classification outputs into sample locations by treating the output vector as a piecewise-constant Probability Density Function (PDF) and sampling from its Cumulative Distribution Function (CDF) [S7]. Unlike NeRF, which builds a PDF from opacity outputs of a coarse shading network evaluated at multiple sample locations, DONeRF uses the output from a single oracle network evaluation [S7].

## Operating characteristics
*   **Time Complexity**: The method requires two forward passes per ray (coarse and fine), effectively doubling the number of MLP queries compared to a single-pass uniform sampler with the same total sample count, but providing higher quality. The total number of samples is $N_c + N_f$.
*   **Memory Complexity**: Requires storing outputs for both coarse and fine passes, including weights, colors, and depths for $N_c + N_f$ samples per ray.
*   **Performance**: Significantly improves reconstruction quality for high-frequency details compared to uniform sampling [S1, S3, unofficial].
*   **Strengths**: Efficiently allocates samples to opaque regions; reduces aliasing when combined with perturbation [S3, unofficial].
*   **Limitations**: Requires careful handling of the computation graph to prevent cyclic dependencies (detaching coarse samples) [S4, unofficial]. The non-differentiable sampling step prevents joint optimization of the sampling distribution with the network weights [S3, unofficial].

## Background
Coarse-to-Fine NeRF was introduced in the original NeRF paper by Mildenhall et al. [2020] as a hierarchical sampling procedure [S1, S3, unofficial][S7]. It was necessary because the original Positional Encoding (PE) features used in NeRF could only model a single scale, requiring separate coarse and fine networks [S5]. The method has since been adapted in various forms, such as Mip-NeRF which uses a single MLP with IPE features [S5], and DONeRF which adapts the sampling logic for depth oracle outputs [S7].
