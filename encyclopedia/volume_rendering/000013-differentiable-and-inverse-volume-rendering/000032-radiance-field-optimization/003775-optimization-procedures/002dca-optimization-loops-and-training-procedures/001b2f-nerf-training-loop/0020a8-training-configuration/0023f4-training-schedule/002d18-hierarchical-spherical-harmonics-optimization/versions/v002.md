# Hierarchical Spherical Harmonics Optimization

Also called: Band-by-band optimization, SH Band Strategy

## Overview
Hierarchical Spherical Harmonics (SH) Optimization is a training schedule strategy for radiance-field optimization that iteratively refines the directional color representation of a scene by optimizing SH coefficients from a starting band up to a target maximum band [S1, unofficial]. It sequentially activates bands, allowing the scene density and low-frequency color to stabilize before introducing higher-frequency details [S1, unofficial].

## How it works
The method controls the optimization of Spherical Harmonics coefficients by managing which bands are active and how their parameters are initialized during the training loop [S1, unofficial]. It relies on specific configuration flags to determine the starting band and initialization behavior [S1, unofficial].

### Inputs and Outputs
**Inputs:**
- `configs`: A configuration object containing:
  - `sphericalHarmonicsBand`: The maximum SH band index to optimize (integer) [S1, unofficial].
  - `hierarchyBandStrategy`: Boolean flag determining if SH bands are optimized hierarchically or all at once [S1, unofficial].
  - `SHsForTargetResoOnly`: Boolean flag; if true and not at minimum hierarchy, resets startBand to 0 [S1, unofficial].
  - `initialFromFile`: Boolean flag; if true and optimizingBand equals availableSHBand+1, density is not re-initialized [S1, unofficial].
  - `learningRate`: Base learning rate for scene parameters [S1, unofficial].
  - `shLearningRate`: Learning rate specifically for SH coefficients [S1, unofficial].
  - `epochs`: Total number of epochs per band stage [S1, unofficial].
  - `batchSize`: Number of rays per batch [S1, unofficial].
  - `solidStrategy`: Boolean flag; if false, self-sample offset is applied [S1, unofficial].
  - `varianceLossInterval`: Interval (in batches) for applying variance loss [S1, unofficial].
  - `varianceCoefficient`, `shCoefficient`: Weights for auxiliary losses [S1, unofficial].
  - `vairanceType`, `neighboorNums`: Parameters for variance loss calculation [S1, unofficial].
  - `maskLossCoefficient`, `huberDelta`: Parameters for RGB loss calculation [S1, unofficial].
  - `saveIntervals`: Interval (in epochs) for saving model checkpoints [S1, unofficial].
  - `justModel`: Boolean flag; if true, intermediate results are not saved [S1, unofficial].
- `scene`: The scene representation object, containing:
  - `optimizingBand`: The current SH band being optimized [S1, unofficial].
  - `stepSize`: The step size for ray marching [S1, unofficial].
  - `sparse`: Boolean flag indicating sparse representation [S1, unofficial].
  - `grayImage`: Boolean flag indicating if the scene is grayscale [S1, unofficial].
  - `setSelfSampleOffset(offset)`: Method to set sampling offset [S1, unofficial].
- `sceneOptimizer`: The optimizer object, containing:
  - `initialBand(band, densityInitialized)`: Initializes parameters for a specific band [S1, unofficial].
  - `initialAll()`: Initializes all parameters at once [S1, unofficial].
- `ray`: Ray data, containing:
  - `totalRays`: Total number of rays to process [S1, unofficial].
- `renderRes`: Rendering result structure, containing:
  - `grayImage`: Boolean flag indicating if the rendered output is grayscale [S1, unofficial].
- `lossesDevice`: GPU array for storing per-ray losses [S1, unofficial].
- `lossesHost`: CPU array for storing per-ray losses [S1, unofficial].
- `lossesPerEpochs`: Array for storing epoch metrics [S1, unofficial].
- `sampleRaysIndexGPU`: GPU array of ray indices [S1, unofficial].
- `currentHierarchy`, `minimumHierarchy`: Hierarchy level indicators [S1, unofficial].
- `availableSHBand`: The currently available SH band index [S1, unofficial].
- `rawLR`, `rawSHLR`: Initial raw learning rates for scene and SH parameters [S1, unofficial].
- `gpuElapsedTime`: Timer for GPU operations [S1, unofficial].
- `timeStep`: Current training time step [S1, unofficial].

**Outputs:**
- Updated scene parameters (density, SH coefficients, RGB) [S1, unofficial].
- Loss metrics (min, max, average) per epoch stored in `lossesPerEpochs` [S1, unofficial].
- Saved model checkpoints at specified intervals [S1, unofficial].

### Data Structures
The implementation relies on the following data structures as defined in the source code:
1. **Configuration Structure** (`configs`): Contains hyperparameters listed in Inputs [S1, unofficial].
2. **Scene Structure** (`scene`): Tracks `optimizingBand`, `stepSize`, `sparse`, and `grayImage` [S1, unofficial].
3. **Loss Arrays**: `lossesDevice` and `lossesHost` are arrays of `double` values sized to `actualBatchSize` [S1, unofficial].

### Numbered Steps
1. **Determine Starting Band**:
   - If `configs->hierarchyBandStrategy` is `false`, set `startBand = configs->sphericalHarmonicsBand` [S1, unofficial].
   - If `configs->SHsForTargetResoOnly` is `true` AND `currentHierarchy` is not `minimumHierarchy`, set `startBand = 0` [S1, unofficial].
2. **Iterate Through SH Bands**:
   - Loop `optimizingBand` from `startBand` to `configs->sphericalHarmonicsBand` (inclusive) [S1, unofficial].
3. **Set Current Band**:
   - Set `scene->optimizingBand = optimizingBand` [S1, unofficial].
4. **Initialize Parameters**:
   - Check condition: If `configs->hierarchyBandStrategy` is `true`, OR (`configs->hierarchyBandStrategy` is `false` AND `configs->SHsForTargetResoOnly` is `true` AND `currentHierarchy` is not `minimumHierarchy`):
     - Determine `densityInitialized`:
       - If `configs->initialFromFile` is `true` AND `optimizingBand == availableSHBand + 1`, then `densityInitialized = false` [S1, unofficial].
       - Otherwise, `densityInitialized = true` [S1, unofficial].
     - Call `sceneOptimizer.initialBand(optimizingBand, densityInitialized)` [S1, unofficial].
   - Else (if `configs->hierarchyBandStrategy` is `false` AND NOT (`configs->SHsForTargetResoOnly` is `true` AND `currentHierarchy` is not `minimumHierarchy`)):
     - Call `sceneOptimizer.initialAll()` [S1, unofficial].
5. **Reset Learning Rates**:
   - Set `configs->learningRate = rawLR` [S1, unofficial].
   - Set `configs->shLearningRate = rawSHLR` [S1, unofficial].
6. **Epoch Loop**:
   - Loop `epoch` from 0 to `configs->epochs` (inclusive) [S1, unofficial].
7. **Batch Calculation**:
   - Calculate `batchCount`:
     $$ \text{batchCount} = \lceil \frac{\text{ray.totalRays}}{\text{configs->batchSize}} \rceil = \frac{\text{ray.totalRays} + \text{configs->batchSize} - 1}{\text{configs->batchSize}} $$
     *(Integer division rounding up)* [S1, unofficial].
8. **Batch Loop**:
   - Loop `batchIndex` from 0 to `batchCount - 1` [S1, unofficial].
9. **Sample Index and Batch Size**:
   - Calculate `startSampleIndex = batchIndex * configs->batchSize` [S1, unofficial].
   - Calculate `actualBatchSize`:
     - If `startSampleIndex + configs->batchSize < ray.totalRays`, then `actualBatchSize = configs->batchSize` [S1, unofficial].
     - Else, `actualBatchSize = ray.totalRays - startSampleIndex` [S1, unofficial].
10. **Set Sampling Offset**:
    - If `!configs->solidStrategy`, call `scene->setSelfSampleOffset(scene->stepSize / 2.0)` [S1, unofficial].
11. **Render Rays (Grayscale/Basic)**:
    - Call `RenderUtils::renderRays(ray, scene, sampleRaysIndexGPU, startSampleIndex, actualBatchSize)` [S1, unofficial].
12. **Render Rays (RGB/Gradients)**:
    - If `renderRes.grayImage` is `false`:
      - Call `RenderUtils::renderRays_withGradients_RGB(sceneOptimizer, ray, scene, lossesDevice, sampleRaysIndexGPU, startSampleIndex, actualBatchSize, configs->maskLossCoefficient, configs->huberDelta)` [S1, unofficial].
13. **Copy Losses to Host**:
    - Copy `actualBatchSize` doubles from `lossesDevice` to `lossesHost` [S1, unofficial].
14. **Compute Loss**:
    - Calculate `loss = getMSEError(lossesHost, actualBatchSize)` [S1, unofficial].
    - If `isnan(loss)`:
      - Print error [S1, unofficial].
      - Free memory [S1, unofficial].
      - Return (terminate training) [S1, unofficial].
15. **Update Loss Statistics**:
    - If `loss > maxLoss`, set `maxLoss = loss` [S1, unofficial].
    - If `minLoss > loss` (or if `minLoss` is uninitialized), set `minLoss = loss` [S1, unofficial].
    - Accumulate `losses += loss` [S1, unofficial].
16. **Add Variance Loss**:
    - If `!scene->sparse` OR `batchIndex % configs->varianceLossInterval == 0`:
      - Call `RenderUtils::addVarianceLoss(scene, sceneOptimizer, configs->varianceCoefficient, configs->shCoefficient, configs->vairanceType, configs->neighboorNums)` [S1, unofficial].
17. **Update RGB Scene**:
    - If `scene->grayImage` is `false`:
      - Call `Optimizer::updateRGBScene(sceneOptimizer, scene, timeStep)` [S1, unofficial].
18. **Decay Learning Rates**:
    - Update `configs->learningRate`:
      $$ \text{configs->learningRate} = \frac{\text{configs->learningRate}}{2^{(1.0 / \text{batchCount}) / (\text{epoch} + 1.0)}} $$
    - Update `configs->shLearningRate`:
      $$ \text{configs->shLearningRate} = \frac{\text{configs->shLearningRate}}{2^{(1.0 / \text{batchCount}) / (\text{epoch} + 1.0)}} $$
      [S1, unofficial].
19. **Store Epoch Losses**:
    - After the batch loop, store metrics in `lossesPerEpochs` array at indices `epoch*4` to `epoch*4+3`:
      - `lossesPerEpochs[epoch*4+0] = minLoss` [S1, unofficial].
      - `lossesPerEpochs[epoch*4+1] = maxLoss` [S1, unofficial].
      - `lossesPerEpochs[epoch*4+2] = losses / batchCount` (Average loss) [S1, unofficial].
      - `lossesPerEpochs[epoch*4+3] = GPU elapsed time` [S1, unofficial].
20. **Save Model**:
    - If `!configs->justModel` AND `(epoch + 1) % configs->saveIntervals == 0`:
      - Save experiment results to directory named `"Band_%d"` (where `%d` is the current `optimizingBand`) [S1, unofficial].

### Pseudocode
```python
import math

def compute_mse_error(losses, n):
    return sum(l * l for l in losses) / n

def copy_device_to_host(src, dst, n):
    dst[:n] = src[:n]

def free_memory():
    pass

def save_experiment_results(directory_name):
    pass

def hierarchical_sh_optimization(configs, scene, scene_optimizer, ray, render_utils, optimizer,
                                 losses_device, losses_host, losses_per_epochs, render_res,
                                 sample_rays_index_gpu, current_hierarchy, minimum_hierarchy,
                                 available_sh_band, raw_lr, raw_sh_lr, gpu_elapsed_time, time_step):
    # 1. Determine Starting Band
    if not configs.hierarchy_band_strategy:
        start_band = configs.spherical_harmonics_band
    if configs.shs_for_target_reso_only and current_hierarchy != minimum_hierarchy:
        start_band = 0
        
    # 2. Iterate Through SH Bands
    for optimizing_band in range(start_band, configs.spherical_harmonics_band + 1):
        scene.optimizing_band = optimizing_band
        
        # 4. Initialize Parameters
        init_condition = configs.hierarchy_band_strategy or \
                         (not configs.hierarchy_band_strategy and configs.shs_for_target_reso_only and current_hierarchy != minimum_hierarchy)
        
        if init_condition:
            if configs.initial_from_file and optimizing_band == available_sh_band + 1:
                density_initialized = False
            else:
                density_initialized = True
            scene_optimizer.initial_band(optimizing_band, density_initialized)
        else:
            scene_optimizer.initial_all()
            
        # 5. Reset Learning Rates
        configs.learning_rate = raw_lr
        configs.sh_learning_rate = raw_sh_lr
        
        # 6. Epoch Loop
        for epoch in range(configs.epochs + 1):
            # 7. Batch Calculation
            batch_count = (ray.total_rays + configs.batch_size - 1) // configs.batch_size
            
            max_loss = float('-inf')
            min_loss = float('inf')
            total_loss = 0.0
            
            # 8. Batch Loop
            for batch_index in range(batch_count):
                start_sample_index = batch_index * configs.batch_size
                
                # 9. Sample Index and Batch Size
                if start_sample_index + configs.batch_size < ray.total_rays:
                    actual_batch_size = configs.batch_size
                else:
                    actual_batch_size = ray.total_rays - start_sample_index
                
                # 10. Set Sampling Offset
                if not configs.solid_strategy:
                    scene.set_self_sample_offset(scene.step_size / 2.0)
                
                # 11. Render Rays (Grayscale/Basic)
                render_utils.render_rays(ray, scene, sample_rays_index_gpu, start_sample_index, actual_batch_size)
                
                # 12. Render Rays (RGB/Gradients)
                if not render_res.gray_image:
                    render_utils.render_rays_with_gradients_rgb(
                        scene_optimizer, ray, scene, losses_device, 
                        sample_rays_index_gpu, start_sample_index, actual_batch_size,
                        configs.mask_loss_coefficient, configs.huber_delta
                    )
                
                # 13. Copy Losses to Host
                copy_device_to_host(losses_device, losses_host, actual_batch_size)
                
                # 14. Compute Loss
                loss = compute_mse_error(losses_host, actual_batch_size)
                if math.isnan(loss):
                    print("Error: Loss is NaN")
                    free_memory()
                    return
                
                # 15. Update Loss Statistics
                if loss > max_loss:
                    max_loss = loss
                if loss < min_loss:
                    min_loss = loss
                total_loss += loss
                
                # 16. Add Variance Loss
                if not scene.sparse or batch_index % configs.variance_loss_interval == 0:
                    render_utils.add_variance_loss(
                        scene, scene_optimizer, configs.variance_coefficient,
                        configs.sh_coefficient, configs.variance_type, configs.neighboor_nums
                    )
                
                # 17. Update RGB Scene
                if not scene.gray_image:
                    optimizer.update_rgb_scene(scene_optimizer, scene, time_step)
                
                # 18. Decay Learning Rates
                decay_factor = 2.0 ** ((1.0 / batch_count) / (epoch + 1.0))
                configs.learning_rate /= decay_factor
                configs.sh_learning_rate /= decay_factor
            
            # 19. Store Epoch Losses
            losses_per_epochs[epoch * 4 + 0] = min_loss
            losses_per_epochs[epoch * 4 + 1] = max_loss
            losses_per_epochs[epoch * 4 + 2] = total_loss / batch_count
            losses_per_epochs[epoch * 4 + 3] = gpu_elapsed_time
            
            # 20. Save Model
            if not configs.just_model and (epoch + 1) % configs.save_intervals == 0:
                save_experiment_results(directory_name=f"Band_{optimizing_band}")
```

- `configs->SHsForTargetResoOnly`: Boolean. Resets start band to 0 if true and not at minimum hierarchy [S1, unofficial].

### Edge Cases and Pitfalls
- **NaN Loss**: If the computed MSE loss is NaN, the training terminates immediately, freeing memory [S1, unofficial].
- **Boundary Conditions**: The last batch may have fewer rays than `batchSize`. The code explicitly calculates `actualBatchSize` to handle this [S1, unofficial].
- **Density Initialization**: The `densityInitialized` flag depends on `initialFromFile` and the relationship between `optimizingBand` and `availableSHBand`. If `optimizingBand == availableSHBand + 1` and `initialFromFile` is true, density is not re-initialized [S1, unofficial].
- **Learning Rate Decay**: The decay factor is applied per batch, not per epoch, which can lead to significant decay over many batches [S1, unofficial].

## Operating characteristics
- **Time Complexity**: The method adds overhead by iterating through SH bands. For each band, it runs a full training loop (epochs * batches). If the maximum band is $B$, and each band requires $E$ epochs and $N$ batches, the total complexity is roughly $O(B \cdot E \cdot N)$. However, since lower bands are simpler, the per-band cost may decrease, but the source does not provide specific timing data.
- **Memory Complexity**: Memory usage is dominated by the scene representation and the SH coefficients. Optimizing bands sequentially allows for potential memory savings if lower bands are discarded, but the source does not specify memory management details beyond the standard scene and loss arrays.
- **Performance**: The method aims to improve convergence stability by avoiding the initialization of high-frequency bands too early. This can lead to better final quality but increases total training time due to the sequential nature.
- **Strengths**: Prevents instability from high-frequency SH coefficients; allows for controlled refinement of detail.
- **Limitations**: Increases training time; requires careful tuning of band transition parameters (`hierarchyBandStrategy`, `SHsForTargetResoOnly`).
- **When to Use**: When training radiance fields with SH representations and experiencing instability or poor convergence with high-frequency details.
- **When Not to Use**: When training time is critical and the scene does not require high-frequency detail; or when using a representation that does not support SH bands.

## Background
Hierarchical Spherical Harmonics Optimization is a training schedule strategy used in differentiable volume rendering, specifically in the context of NeRF (Neural Radiance Fields) and related radiance-field optimizations. It is implemented in the `Clear-plenoxels` repository [S1, unofficial]. The method addresses the challenge of optimizing high-dimensional SH coefficients by breaking the problem into smaller, more manageable sub-problems (bands). This approach is similar to other hierarchical optimization techniques in graphics, such as multi-resolution rendering or progressive refinement.
