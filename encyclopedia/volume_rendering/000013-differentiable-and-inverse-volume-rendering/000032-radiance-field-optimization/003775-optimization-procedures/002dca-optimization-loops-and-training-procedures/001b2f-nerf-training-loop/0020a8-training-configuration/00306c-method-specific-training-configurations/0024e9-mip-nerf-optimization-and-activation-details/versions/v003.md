# Mip-NeRF Optimization and Activation Details

Also called: JaxNeRF Training Procedure, Mip-NeRF Misc. Changes

## Overview
This article defines the specific implementation details for training Mip-NeRF and JaxNeRF, focusing on activation functions, input encoding structures, and learning rate scheduling. These modifications are designed to improve training stability and robustness, particularly against catastrophic failure modes, without significantly altering the model's accuracy or computational speed [S1]. Unlike standard NeRF implementations, Mip-NeRF removes the identity concatenation from the MLP input and employs shifted/widened activation functions to ensure smoother optimization landscapes [S1].

## How it works
The method modifies the standard NeRF training loop through four key changes: input encoding structure, density activation, color activation, and view direction injection. These changes are applied to the Multi-Layer Perceptron (MLP) that predicts density $\tau$ and color $c$.

### Inputs and Outputs
*   **Inputs**: Integrated Positional Encoding (IPE) features for position and view direction; ray direction vector $d$.
*   **Outputs**: Density $\tau$ (scalar) and Color $c$ (RGB vector).

### Data Structures
The MLP architecture remains consistent with standard NeRF, but the input tensor and internal activations are modified:
1.  **Input Tensor**: Contains only the IPE features. It does **not** contain the original position or view direction vectors.
2.  **View Direction Injection**: The view direction is processed separately and injected into the final layer of the MLP.

### Numbered Steps

1.  **Remove Identity Encoding**:
    The input to the MLP is the Integrated Positional Encoding (IPE) only. The concatenation of the IPE with the original position and view direction (identity encoding) is removed. This simplifies the formalization of IPE features and removes a component found to contribute negligibly to performance [S1].

2.  **Compute Density Activation ($\tau$)**:
    The density output is computed using a shifted softplus function instead of ReLU. Let $x$ be the pre-activation value from the MLP layer predicting density. The density $\tau$ is calculated as:
    $$ \tau = \log(1 + \exp(x - 1)) $$
    This shift by $-1$ is equivalent to initializing the biases for the density output to $-1$, resulting in small initial density values. This prevents catastrophic failure where the MLP emits negative values everywhere, which would cause zero gradients and halt optimization [S1].

3.  **Compute Color Activation ($c$)**:
    The color output is computed using a "widened" sigmoid function instead of the standard sigmoid. Let $x$ be the pre-activation value from the MLP layer predicting color. The color $c$ is calculated as:
    $$ c = \frac{1 + 2\epsilon}{1 + \exp(-x)} - \epsilon $$
    where $\epsilon = 0.001$. This function saturates slightly outside the $[0, 1]$ range. This avoids optimization failure when the network attempts to explain black or white pixels by saturating activations, a mode that can trap optimization in local minima [S1].

4.  **Inject View Direction**:
    The ray direction $d$ is handled as follows:
    a. Normalize $d$.
    b. Apply positional encoding with $L=4$ levels.
    c. Inject these encoded features into the last layer of the MLP.
    d. This injection occurs **after** $\tau$ is predicted but **before** $c$ is predicted. This allows the color prediction to be view-dependent while keeping the density prediction view-independent [S1].

### Parameters
*   **Optimizer**: Adam [S1].
*   **Total Iterations ($n$)**: 1,000,000 [S1].
*   **Batch Size**: 4,096 [S1].
*   **Initial Learning Rate ($\eta_0$)**: $5 \times 10^{-4}$ [S1].
*   **Final Learning Rate ($\eta_n$)**: $5 \times 10^{-6}$ [S1].
*   **Warmup Iterations ($n_w$)**: 2,500 [S1].
*   **Warmup Start Factor ($\lambda_w$)**: 0.01 [S1].

### Pseudocode

```python
import math

def shifted_softplus(x):
    """
    Density activation function.
    Equivalent to softplus(x - 1).
    """
    return math.log(1 + math.exp(x - 1))

def widened_sigmoid(x, epsilon=0.001):
    """
    Color activation function.
    Saturates slightly outside [0, 1].
    """
    return (1 + 2 * epsilon) / (1 + math.exp(-x)) - epsilon

def compute_learning_rate(iteration_i, total_iterations_n, warmup_iterations_nw, 
                          initial_lr_eta0, final_lr_eta_n, warmup_start_lambda_w):
    """
    Computes the learning rate with logarithmic annealing and linear warmup.
    """
    # Logarithmic annealing component
    # exp((1 - i/n) * log(eta_0) + (i/n) * log(eta_n))
    log_lr_anneal = (1 - iteration_i / total_iterations_n) * math.log(initial_lr_eta0) + \
                    (iteration_i / total_iterations_n) * math.log(final_lr_eta_n)
    lr_anneal = math.exp(log_lr_anneal)
    
    # Warmup scaling component
    # clip(i/nw, 0, 1) ensures we don't divide by zero or exceed warmup period
    progress = min(iteration_i / warmup_iterations_nw, 1.0)
    warmup_scale = warmup_start_lambda_w + (1 - warmup_start_lambda_w) * math.sin((math.pi / 2) * progress)
    
    return warmup_scale * lr_anneal

def predict_density_and_color(mlp_features, ray_direction, mlp_model):
    """
    Simulates the forward pass of the Mip-NeRF MLP with specific activation and injection details.
    
    Args:
        mlp_features: Tensor of Integrated Positional Encodings (IPE).
        ray_direction: Normalized ray direction vector d.
        mlp_model: The MLP model structure.
        
    Returns:
        tau: Density scalar.
        c: Color vector.
    """
    # Step 1: Input is IPE only (Identity concatenation removed)
    # Input to MLP is mlp_features
    
    # Step 2: Predict Density (tau)
    # The MLP layer predicting density uses shifted softplus
    tau_pre_activation = mlp_model.layers.predict_density(mlp_features)
    tau = shifted_softplus(tau_pre_activation)
    
    # Step 3: Handle View Direction
    # Normalize direction (assumed already normalized in input, but explicit for clarity)
    d_normalized = ray_direction / (norm(ray_direction) + 1e-8)
    
    # Apply positional encoding with L=4
    view_pe = positional_encoding(d_normalized, levels=4)
    
    # Step 4: Inject View Direction into Last Layer
    # The view PE is added/injected into the last layer features before color prediction
    # This is a structural detail of the MLP architecture
    last_layer_features = mlp_model.layers.get_last_layer_features(mlp_features)
    last_layer_features_with_view = last_layer_features + view_pe # Or concatenation, depending on specific MLP impl
    
    # Step 5: Predict Color (c)
    # The MLP layer predicting color uses widened sigmoid
    c_pre_activation = mlp_model.layers.predict_color(last_layer_features_with_view)
    c = widened_sigmoid(c_pre_activation)
    
    return tau, c
```

### Edge Cases and Pitfalls
*   **Negative Density**: Using standard ReLU for density can lead to catastrophic failure if the MLP outputs negative values everywhere, resulting in zero gradients. The shifted softplus prevents this [S1].
*   **Black/White Pixel Saturation**: Standard sigmoid saturation can cause optimization failure when explaining extreme pixel values. The widened sigmoid mitigates this [S1].
*   **Identity Encoding**: While removing identity encoding simplifies the model, it must be noted that this is a deviation from the original NeRF paper. The sources indicate this change does not significantly impact accuracy [S1].

## Operating characteristics
*   **Training Time**: Mip-NeRF is 13x faster to train than a brute-force supersampling baseline (16 rays/pixel) [S1].
*   **Evaluation Time**: Mip-NeRF is 16x faster to evaluate than the supersampling baseline [S1].
*   **Quality**: Mip-NeRF outperforms the 16x supersampling baseline in quality metrics (PSNR, SSIM, LPIPS) [S1].
*   **Stability**: The activation functions and learning rate schedule improve training stability, particularly with large learning rates, though the core accuracy remains comparable to standard configurations [S1].
*   **Memory**: The removal of identity encoding slightly reduces input dimensionality, but the primary memory footprint is determined by the MLP size and batch size (4096) [S1].

## Background
Mip-NeRF was introduced by Barron et al. in 2021 [S1]. The optimization and activation details described here are part of the "miscellaneous" changes implemented in the JaxNeRF codebase to improve reproducibility and training robustness. These changes were found to be beneficial for training stability but did not significantly alter the final model performance compared to the baseline NeRF configuration [S1]. The work builds on the foundational differentiable volume rendering and ray sampling techniques established in the original NeRF paper [S3, S4, unofficial].
