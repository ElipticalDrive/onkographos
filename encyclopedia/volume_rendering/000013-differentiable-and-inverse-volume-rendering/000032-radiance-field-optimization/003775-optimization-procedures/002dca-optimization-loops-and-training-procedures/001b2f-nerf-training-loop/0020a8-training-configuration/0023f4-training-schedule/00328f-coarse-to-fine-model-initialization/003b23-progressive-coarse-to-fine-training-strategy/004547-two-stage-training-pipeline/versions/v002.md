# Two-Stage Training Pipeline

Also called: ActiveRMAP Fine Stage Optimization, ActiveRMAP Two-Stage Training, Coarse-to-Fine Voxel Training

## Overview
A coarse-to-fine training strategy that first recovers global shape at low resolution, then refines fine details at high resolution [S2, unofficial]. It sets itself apart from single-resolution training by decoupling structural coherence from high-frequency detail recovery, allowing the model to converge to a stable global geometry before committing computational resources to fine-grained optimization [S2, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** A coarse radiance field model $M_T$ (initialized from Stage 1), an image database $\{I_i\}_{i=0}^T$ containing training views, total fine-stage iterations $N$, and sampling interval $m$.
- **Outputs:** A refined fine radiance field model $M_f$.

**Data Structures:**
- $M_T$: Coarse model parameters (e.g., voxel grid or neural network weights) representing the global shape.
- $M_f$: Fine model parameters, initialized from or sharing structure with $M_T$, optimized to capture high-frequency details.
- $\{I_i\}_{i=0}^T$: Set of $T+1$ training images.

**Numbered Steps:**
1. **Initialization:** Initialize the fine model $M_f$ using the coarse model $M_T$ obtained from the previous stage. Initialize the image database $\{I_i\}_{i=0}^T$ with available training views [S1, unofficial].
2. **Iteration Loop:** Iterate $k$ from $0$ to $N$ [S1, unofficial].
3. **Ray Sampling:** If $k \mod m == 0$, sample new training pixels (rays) from the image database $\{I_i\}_{i=0}^T$ [S1, unofficial]. This step ensures diverse view coverage is maintained or expanded periodically during optimization [S1, unofficial].
4. **Optimization:** Optimize the Differentiable Voxel Grid Optimization (DVGO) to refine the fine model $M_f$ using the sampled rays [S1, unofficial]. This step minimizes the rendering loss between predicted and ground-truth images, adjusting high-resolution voxel features [S1, unofficial].
5. **Termination:** After $N$ iterations, the final $M_f$ represents the high-resolution reconstruction [S1, unofficial].

**Parameters:**
- $N$: Total number of fine-stage optimization iterations [S1, unofficial].
- $m$: Interval frequency for sampling new training pixels; new pixels are added every $m$ iterations [S1, unofficial].
- $M_T$: Coarse radiance field model initialized at the start of the fine stage [S1, unofficial].
- $M_f$: Fine radiance field model refined during each iteration of the loop [S1, unofficial].

**Pseudocode:**
```python
def two_stage_fine_training(M_T, image_database, N, m):
    """
    Refines a coarse radiance field model M_T into a fine model M_f.
    
    Args:
        M_T: Coarse radiance field model (e.g., from DVGO coarse stage).
        image_database: List of training images {I_i}_{i=0}^T.
        N: Total number of fine-stage optimization iterations.
        m: Interval frequency for sampling new training pixels.
        
    Returns:
        M_f: Refined fine radiance field model.
    """
    # Initialize fine model from coarse model
    M_f = initialize_fine_model(M_T)
    
    # Iterate through fine-stage optimization steps
    for k in range(N):
        # Periodically sample new training rays to ensure view diversity
        if k % m == 0:
            rays = sample_training_pixels(image_database)
        
        # Optimize the fine model using DVGO
        # This step updates M_f to minimize rendering error on sampled rays
        M_f = optimize_dvgo(M_f, rays)
        
    return M_f
```

**Edge Cases and Pitfalls:**
- **Resolution Scaling:** Increasing voxel grid resolution significantly increases training time. For example, moving from $128^3$ to $256^3$ increases training time from 11 minutes to 15 minutes (on specific hardware/configs) [S2, unofficial].
- **Detail vs. Structure:** If the coarse stage fails to produce a coherent global shape, the fine stage may struggle to recover fine details correctly [S2, unofficial].
- **Post-processing:** Removing Gaussian kernel smoothing during coarse training or post-processing can increase Chamfer Distance (CD) error from 0.715 to 0.720 or 0.72 to 0.74, respectively, indicating that smoothing aids in structural consistency [S2, unofficial].

## Subtopics

### Magic3D
A method targeting issues caused by low-resolution diffusion images using a two-stage coarse-fine approach [S3]. In the coarse stage, Magic3D uses Instant-NGP as the NeRF model trained from images generated from text prompts using the image diffusion model eDiff-I [S3]. In the fine stage, the coarse geometry extracted from Instant-NGP is placed on a mesh, which is optimized over in the fine stage using images generated with a latent diffusion model [S3]. Experiments over 397 prompts generated objects, each rated by three users, showed a preference toward Magic3D over DreamFusion [S3].

## Operating characteristics
- **Time Complexity:** Training time scales with voxel grid resolution. For a default resolution of $256^3$, training takes approximately 15 minutes, compared to 11 minutes for $128^3$, 12 minutes for $192^3$, and 17 minutes for $320^3$ [S2, unofficial].
- **Memory Complexity:** Memory usage is proportional to the voxel grid resolution. Higher resolutions ($320^3$) require more memory but offer diminishing returns in Chamfer Distance (CD) error compared to $256^3$ [S2, unofficial].
- **Performance:** The two-stage approach yields a coherent global shape in Stage 1, which is then refined for high-frequency details in Stage 2, resulting in lower CD errors than single-resolution methods [S2, unofficial].
- **Strengths:** Effective at recovering both global structure and fine details; robust to low-resolution input images when combined with diffusion models (as in Magic3D) [S2, unofficial][S3].
- **Limitations:** Requires careful tuning of resolution and sampling interval $m$; post-processing steps (e.g., Gaussian smoothing) may slightly sacrifice quantitative performance for visual quality [S2, unofficial].

## Background
The two-stage training pipeline was introduced in ActiveRMAP (2022) as part of a radiance field-based active mapping and planning framework [S1, unofficial]. It was further explored in Voxurf (2022) for voxel-based efficient and accurate neural surface reconstruction, where it was shown to improve Chamfer Distance metrics by separating coarse shape recovery from fine detail refinement [S2, unofficial]. The approach has also been adapted in Magic3D (2022) for text-to-3D generation, leveraging coarse-fine optimization to mitigate artifacts from low-resolution diffusion images [S3].
