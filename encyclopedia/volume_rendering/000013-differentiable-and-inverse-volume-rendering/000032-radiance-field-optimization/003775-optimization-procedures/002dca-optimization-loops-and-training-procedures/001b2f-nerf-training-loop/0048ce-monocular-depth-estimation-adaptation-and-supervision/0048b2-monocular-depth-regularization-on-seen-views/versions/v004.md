# Monocular Depth Regularization on Seen Views

Also called: Patch-wise depth alignment, Seen-view depth distillation

## Overview
This method applies a consistency loss between pseudo-depth maps from a pre-trained monocular depth estimation (MDE) network and depth rendered by a NeRF model, specifically for input views that are part of the training dataset [S1, unofficial]. It solves the problem of scale ambiguity in relative MDE outputs by computing local scale and shift parameters per image patch via least squares, preventing dominant objects from skewing the alignment and improving local geometric consistency [S1, unofficial]. Unlike global fitting methods which undermine local statistics, this patch-wise approach also mitigates the computational bottleneck of full-image rendering [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of seen view images $S$; a pre-trained MDE network $G_\phi$ with parameters $\phi$; a NeRF model $\mathcal{N}$; a patch definition $P$ (a set of pixels within a local region).
*   **Outputs:** A scalar loss value $L_{seen}$ added to the training objective.

**Data Structures:**
*   $D^*_i$: Relative pseudo-depth map for image $I_i$, output of $G_\phi(I_i)$.
*   $\bar{D}_i$: Rendered depth map for image $I_i$, output of $\mathcal{N}$.
*   $w_i, q_i$: Scalar scale and shift parameters for the current patch.

**Numbered Steps:**
1.  Iterate over each seen view image $I_i \in S$.
2.  Render the NeRF depth map $\bar{D}_i$ for the camera pose of $I_i$ using the standard volume rendering equation for expected distance:
    $$ \bar{D}_i(r) = \sum_{k=1}^{K} T(t_k) \alpha(\sigma(t_k)\delta_k) t_k $$
    where $t_k$ is the sample distance, $\sigma$ is density, $\delta_k$ is segment length, $\alpha$ is opacity, and $T$ is transmittance [Parent].
3.  Extract the pseudo-depth map $D^*_i = G_\phi(I_i)$ using the frozen pre-trained MDE network [S1, unofficial].
4.  For each patch $P$ in the image:
    a. Identify the set of pixels $p \in P$.
    b. Compute the scale $w_i$ and shift $q_i$ by solving the least squares problem to minimize the difference between the aligned pseudo-depth and the rendered depth:
    $$ \min_{w_i, q_i} \sum_{p \in P} \| (w_i \cdot D^*_i(p) + q_i) - \bar{D}_i(p) \|^2 $$
    [S1, unofficial].
    c. Apply the stop-gradient operator $\text{sg}(\cdot)$ to the pseudo-depth term to prevent gradients from flowing into the MDE network [S1, unofficial].
5.  Calculate the total loss $L_{seen}$ by summing the L1 norms of the differences between the aligned pseudo-depth and rendered depth over all seen views and patches:
    $$ L_{seen} = \sum_{I_i \in S} \sum_{p \in P} \| (w_i \cdot \text{sg}(D^*_i(p)) + q_i) - \bar{D}_i(p) \|_1 $$
    [S1, unofficial].

**Parameters:**
*   $w_i, q_i$: Learned per-patch alignment parameters.
*   $\text{sg}(\cdot)$: Stop-gradient operator [S1, unofficial].
*   Patch size: Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Global vs. Local Bias:** Using global scale/shift fitting favors dominant objects in the scene, leading to ill-fitted depths in less dominant sections due to inconsistencies in predicted depth differences [S1, unofficial]. The patch-wise adjustment alleviates this by computing parameters locally [S1, unofficial].
*   **Gradient Flow:** The stop-gradient is essential on the MDE output to keep the pre-trained network frozen during this specific loss term [S1, unofficial].

**Pseudocode:**
```python
def compute_seen_view_depth_loss(
    seen_views: List[Image],
    mde_network: Module,  # Frozen, G_phi
    nerf_model: Module,   # Trainable, N
    patch_size: int
) -> Tensor:
    """
    Computes the monocular depth regularization loss on seen views.
    """
    total_loss = 0.0
    
    for image in seen_views:
        # 1. Render NeRF depth
        # Assumes nerf_model.render() returns depth map D_bar for the image's camera pose
        d_bar = nerf_model.render_depth(image.camera_pose)
        
        # 2. Extract pseudo-depth
        # G_phi outputs relative depth D_star
        d_star = mde_network(image)
        
        # 3. Patch-wise alignment and loss accumulation
        # Iterate over patches. In practice, this is often vectorized.
        # Here we assume a helper to extract patches and compute least squares.
        
        # Get image dimensions
        H, W = d_star.shape
        
        # Define patches (simplified: non-overlapping grid for clarity)
        # Note: The source implies a set of pixels P within a patch.
        # We iterate through patches.
        
        for y in range(0, H, patch_size):
            for x in range(0, W, patch_size):
                y_end = min(y + patch_size, H)
                x_end = min(x + patch_size, W)
                
                # Extract patch masks
                mask_y = slice(y, y_end)
                mask_x = slice(x, x_end)
                
                # Extract patch data
                p_d_star = d_star[mask_y, mask_x]
                p_d_bar = d_bar[mask_y, mask_x]
                
                # Flatten for least squares
                # D_star is relative, D_bar is absolute (in NeRF space)
                # We want to find w, q such that w * D_star + q ≈ D_bar
                # Linear system: [D_star, 1] * [w; q] = D_bar
                
                # Construct design matrix A and target vector b
                # A = [D_star_flat, ones]
                # b = D_bar_flat
                
                d_star_flat = p_d_star.flatten().float()
                d_bar_flat = p_d_bar.flatten().float()
                
                # Add bias term (column of ones)
                ones = torch.ones_like(d_star_flat)
                A = torch.stack([d_star_flat, ones], dim=1)
                b = d_bar_flat
                
                # Solve least squares: min ||A * [w; q] - b||^2
                # [w; q] = (A^T A)^-1 A^T b
                # Using pseudo-inverse for stability
                try:
                    # w_q = torch.linalg.lstsq(A, b).solution
                    # Manual implementation for clarity/portability without numpy/linalg specific calls if needed,
                    # but torch.linalg.lstsq is standard.
                    w_q = torch.linalg.lstsq(A, b).solution
                    w = w_q[0]
                    q = w_q[1]
                except RuntimeError:
                    # Fallback if singular, though unlikely with valid depth
                    continue
                
                # Compute aligned pseudo-depth
                # Apply stop-gradient to pseudo-depth term
                d_star_aligned = w * torch.stop_gradient(d_star_flat) + q
                
                # Compute L1 loss for this patch
                patch_loss = torch.abs(d_star_aligned - d_bar_flat).sum()
                
                total_loss += patch_loss
                
    return total_loss
```

## Subtopics

### Transient-Aware Depth Prior
Incorporates geometric priors from a monocular depth network (DPT) into NeRF training, adjusted for scale/shift and filtered by transient confidence [S2, unofficial]. It differs from standard seen-view regularization by explicitly suppressing depth loss in areas with transient objects (e.g., moving people, reflections) using a confidence weight derived from the ratio of candidate density to shared density [S2, unofficial]. Choose this variant when dealing with unconstrained image collections containing transient artifacts. The depth loss is defined as $L_{depth}(r) = (1 - W_{depth}(r)) \| D^*_i(r) - \hat{D}_i(r) \|_1$, where $W_{depth}(r)$ is the transient confidence weight [S2, unofficial]. The scale $\eta_i$ and shift $\xi_i$ are learned per image, and the pseudo-depth is $D^*_i(r) = \frac{1}{\eta_i D^{inv}_i(r) + \xi_i}$ [S2, unofficial]. The weight $\lambda_d$ for the depth loss is typically 0.001 [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** The method adds overhead proportional to the number of seen views and the number of patches. Patch-wise least squares is computationally cheaper than full-image global fitting if patches are small, but the overhead of iterating patches exists [S1, unofficial].
*   **Memory Complexity:** Requires storing the rendered depth maps and pseudo-depth maps for the current batch of seen views. No additional large structures are needed beyond the standard NeRF and MDE network memory.
*   **Performance:** Improves geometry reconstruction, particularly in scenes with varying depth scales or dominant foreground objects that would skew global alignment [S1, unofficial].
*   **Strengths:** Handles local depth inconsistencies better than global fitting; reduces computational bottleneck of full-image rendering by operating on patches [S1, unofficial].
*   **Limitations:** Relies on the quality of the pre-trained MDE network; patch-wise computation can be slower than a single global fit if not vectorized efficiently; does not handle unseen views directly (that is a separate loss term) [S1, unofficial].

## Background
This method originates from the DaRF paper, which boosts radiance fields from sparse inputs using monocular depth adaptation [S1, unofficial]. It addresses the limitation of global scale fitting which undermines local statistics, as demonstrated in the source's Figure 2 [S1, unofficial]. The approach is part of a broader family of methods that adapt pre-trained monocular depth estimators to NeRF training, including variants like NerfingMVS and DäRF [Parent].
