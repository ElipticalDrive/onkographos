# Hierarchical Iterative Joint Optimization for Geometry and Appearance

Also called: Hierarchical Iterative Joint Optimization

## Overview
A joint optimization algorithm that simultaneously enhances geometric accuracy and appearance realism by balancing convergence speed and precision through a hierarchical iterative process [S1]. It distinguishes itself from standard NeRF training by explicitly decoupling geometry correction and appearance restoration into weighted phases within a single optimization loop, leveraging sparse geometric priors and semantic masks to accelerate convergence and improve detail fidelity under sparse input conditions [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** Sparse input images (15-20 images), COLMAP sparse point clouds (geometric prior), Mask R-CNN semantic masks, initial MLP parameters [S1].
*   **Outputs:** Optimized NeRF implicit function parameters, refined depth map, rendered texture with enhanced contrast [S1].

**Data Structures**
*   **MLP Parameters:** Initialized as random values within the range $[-0.01, 0.01]$ [S1].
*   **Geometric Parameters:** Constrained by depth priors to avoid random initialization bias [S1].
*   **Loss Weights:** Scalars $\alpha, \beta, \gamma$ summing to 1.0, adjusted per phase [S1].

**Formulas**
The total loss function is defined as [S1]:
$$ L_{total} = \alpha \cdot L_{geo} + \beta \cdot L_{app} + \gamma \cdot L_{reg} $$

Where:
*   $L_{geo}$: Geometric loss, calculated based on the difference between the depth prior point cloud and the NeRF predicted depth [S1].
*   $L_{app}$: Appearance loss, calculated as the L1 pixel difference between the NeRF rendered image and the input image [S1].
*   $L_{reg}$: Regularization loss, constraining the smoothness of implicit functions to avoid local overfitting [S1].

**Parameters**
*   **Optimizer:** AdamW [S1].
*   **Initial Learning Rate:** $5 \times 10^{-4}$ [S1].
*   **Learning Rate Decay:** Attenuates by 10% every 1000 rounds [S1].
*   **Convergence Threshold:** Relative change of $L_{total}$ between consecutive 500 rounds $< 10^{-5}$ [S1].
*   **Post-Processing Gaussian Filter:** $\sigma = 0.5$ [S1].
*   **Total Rounds:** 5000 (base) + up to 1000 (extension) [S1].

**Steps**
1.  **Initialization:** Initialize the implicit function parameters of NeRF using geometric priors from COLMAP sparse point clouds and semantic masks from Mask R-CNN [S1]. Set MLP initial parameters to random values within $[-0.01, 0.01]$ [S1]. Constrain geometric parameters by the depth prior [S1].
2.  **Iterative Optimization Phase 1 (Rounds 0-2000):** Focus on geometric structure correction [S1]. Set weights $\alpha=0.5, \beta=0.4, \gamma=0.1$ [S1]. This prioritizes aligning the predicted depth with the depth prior to correct scene distortion [S1].
3.  **Iterative Optimization Phase 2 (Rounds 2001-5000):** Focus on appearance detail restoration [S1]. Adjust weights to $\alpha=0.3, \beta=0.6, \gamma=0.1$ [S1]. This enhances texture detail fidelity (e.g., metal brushing, leather pores) [S1].
4.  **Convergence Judgment:** Check if the relative change of $L_{total}$ between consecutive 500 rounds is less than $10^{-5}$ [S1]. If convergence is not achieved after 5000 rounds, reduce the learning rate to $10^{-5}$ and optimize for an additional 1000 rounds to avoid local optima [S1].
5.  **Post-Processing:** Filter the predicted depth map using a Gaussian filter ($\sigma=0.5$) to smooth geometric noise [S1]. Perform histogram equalization on the rendered texture to enhance contrast consistency [S1].

**Pseudocode**
```python
def hierarchical_joint_optimization(images, colmap_points, semantic_masks):
    # Step 1: Initialization
    mlp_params = [random.uniform(-0.01, 0.01) for _ in range(num_params)]
    geo_params = constrain_by_depth_prior(colmap_points)

    optimizer = AdamW(params=mlp_params, lr=5e-4)
    prev_l_total = None
    converged = False

    # Step 2: Iterative Optimization
    for round in range(5000):
        # Adjust weights based on phase
        if round < 2000:
            alpha, beta, gamma = 0.5, 0.4, 0.1
        else:
            alpha, beta, gamma = 0.3, 0.6, 0.1

        # Decay learning rate every 1000 rounds
        current_lr = 5e-4 * (0.9 ** (round // 1000))
        optimizer.lr = current_lr

        # Forward pass and loss calculation
        predicted_depth = nerf_predict_depth(mlp_params, geo_params)
        rendered_image = nerf_render(mlp_params, geo_params)

        l_geo = calculate_geo_loss(predicted_depth, colmap_points)
        l_app = calculate_l1_loss(rendered_image, images)
        l_reg = calculate_smoothness_loss(mlp_params)

        l_total = alpha * l_geo + beta * l_app + gamma * l_reg

        # Backward pass
        optimizer.zero_grad()
        l_total.backward()
        optimizer.step()

        # Step 3: Convergence Judgment (every 500 rounds)
        if round % 500 == 0 and round > 0:
            if prev_l_total is not None and abs(l_total - prev_l_total) / prev_l_total < 1e-5:
                converged = True
                break
            prev_l_total = l_total

    # Handle non-convergence after 5000 rounds
    if not converged:
        optimizer.lr = 1e-5
        for extra_round in range(1000):
            predicted_depth = nerf_predict_depth(mlp_params, geo_params)
            rendered_image = nerf_render(mlp_params, geo_params)
            l_geo = calculate_geo_loss(predicted_depth, colmap_points)
            l_app = calculate_l1_loss(rendered_image, images)
            l_reg = calculate_smoothness_loss(mlp_params)
            l_total = alpha * l_geo + beta * l_app + gamma * l_reg
            optimizer.zero_grad()
            l_total.backward()
            optimizer.step()

    # Step 4: Post-Processing
    depth_map = filter_gaussian(predicted_depth, sigma=0.5)
    texture = histogram_equalization(rendered_image)

    return mlp_params, depth_map, texture

# Helper definitions
def constrain_by_depth_prior(points):
    return points # Constrained by depth prior to avoid random initialization bias

def nerf_predict_depth(params, geo_params):
    return compute_depth_from_implicit_function(params, geo_params)

def nerf_render(params, geo_params):
    return volume_render(params, geo_params)

def calculate_geo_loss(pred_depth, prior_points):
    return mean(abs(pred_depth - prior_points))

def calculate_l1_loss(rendered, input_img):
    return mean(abs(rendered - input_img))

def calculate_smoothness_loss(params):
    return mean(abs(diff(params)))

def filter_gaussian(depth, sigma):
    return convolve(depth, gaussian_kernel(sigma))

def histogram_equalization(texture):
    return equalize_histogram(texture)

class AdamW:
    def __init__(self, params, lr):
        self.params = params
        self.lr = lr
    def zero_grad(self):
        for p in self.params: p.grad = 0.0
    def step(self):
        for p in self.params:
            p.data -= self.lr * p.grad
```

**Edge Cases and Pitfalls**
*   **Local Optima:** If convergence criteria are not met by round 5000, the method explicitly extends training with a reduced learning rate to escape local optima [S1].
*   **Initialization Bias:** Random initialization of MLP parameters without geometric constraints can lead to bias; thus, geometric parameters are constrained by depth priors [S1].
*   **Geometric Noise:** Without post-processing, predicted depth maps may contain noise; a Gaussian filter is required to smooth this [S1].

## Operating characteristics
*   **Time Complexity:** Total training rounds are 5000, which is 75% shorter than the original NeRF's 20,000 rounds [S1].
*   **Performance:** Under sparse input conditions, PSNR increased by $2.3 \pm 0.2$ dB (mean $\pm$ std over 10 trials) compared to baseline methods [S1].
*   **Strengths:** Balances convergence speed and optimization precision; effectively handles sparse input by leveraging geometric and semantic priors; reduces training time significantly [S1].
*   **Limitations:** Requires pre-processing steps (COLMAP, Mask R-CNN) to generate priors and masks; relies on specific hyperparameter tuning for loss weights and learning rate decay [S1].
*   **When to Use:** Suitable for sparse input scene reconstruction (15-20 images) where geometric accuracy and appearance realism are critical, such as in VR advertising [S1].

## Background
This method was proposed in the paper "Efficient Sparse Input Scene Reconstruction and Real-Time Rendering for VR Advertising Using Optimized NeRF Framework" by Y. Tao et al., published in *Informatica* 50 (2026) [S1]. It addresses the challenges of blurred geometry, loss of detail, and slow convergence in sparse NeRF reconstruction by integrating geometric priors from COLMAP and semantic guidance from Mask R-CNN into a joint optimization framework [S1].
