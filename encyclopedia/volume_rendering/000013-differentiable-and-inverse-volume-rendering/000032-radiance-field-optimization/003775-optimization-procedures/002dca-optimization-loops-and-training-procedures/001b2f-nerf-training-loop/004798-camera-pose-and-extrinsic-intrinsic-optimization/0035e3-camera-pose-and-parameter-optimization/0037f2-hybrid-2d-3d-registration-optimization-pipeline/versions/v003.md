# Hybrid 2D/3D Registration Optimization Pipeline

Also called: Net+GradNCC, Two-Stage Similarity Optimization

## Overview
The Hybrid 2D/3D Registration Optimization Pipeline is a two-stage method for estimating camera poses in 2D/3D registration, combining a differentiable network-based similarity loss for global convergence with a traditional Gradient-based Normalized Cross-Correlation (Grad-NCC) loss for local refinement [S1]. It addresses the limitation of network-based losses being less sensitive to local textures compared to traditional image-based methods [S1]. By switching from the network loss ($L_N$) to Grad-NCC ($L_{GNNC}$) upon detecting convergence, it leverages the locally convex loss landscape of ZNCC to achieve precise alignment, serving as the local refinement stage for methods like [Gradient Descent Registration via ZNCC](9913-gradient-descent-registration-via-zncc.md).

## How it works
The pipeline optimizes pose parameters $\theta$ (rotation $R$ and translation $t$) in two sequential phases.

**Inputs:**
- Ground-truth 2D image (e.g., X-ray).
- 3D volume (CT) and optional segmentation.
- Initial pose estimate $\theta_{init}$ (often random).

**Outputs:**
- Optimized pose parameters $\theta^*$.

**Data Structures:**
- Pose parameters $\theta$: Vector containing rotation and translation components.
- Loss values: Scalar $L_N$ (network similarity) and $L_{GNNC}$ (Grad-NCC similarity).
- Convergence metric: Standard deviation of loss over a sliding window.

**Step 1: Global Optimization with Network Loss ($L_N$)**
1. Initialize pose parameters $\theta$.
2. Optimize $\theta$ to minimize $L_N$ using Stochastic Gradient Descent (SGD).
   - Optimizer settings: Momentum = 0.9.
   - Learning rate: Cyclic between $1 \times 10^{-6}$ and $1 \times 10^{-4}$ every 100 steps [S1].
3. Monitor convergence by calculating the standard deviation of $L_N$ over the last 10 iterations, denoted as $std_{L_N}$ [S1].
4. If $std_{L_N} < 3 \times 10^{-3}$, switch to Step 2. Otherwise, continue Step 1 [S1].

**Step 2: Local Refinement with Grad-NCC Loss ($L_{GNNC}$)**
1. Optimize $\theta$ to minimize $L_{GNNC}$ using SGD.
   - Optimizer settings: Momentum = 0.9.
   - Learning rate: Cyclic between $1 \times 10^{-3}$ and $3 \times 10^{-3}$ [S1].
2. Monitor convergence by calculating the standard deviation of $L_{GNNC}$ over the last 10 iterations, denoted as $std_{L_{GNNC}}$ [S1].
3. If $std_{L_{GNNC}} < 1 \times 10^{-5}$, stop and return $\theta$. Otherwise, continue Step 2 [S1].

**Pseudocode:**
```python
def hybrid_registration_pipeline(initial_pose, ground_truth_image, volume, segmentation):
    # Phase 1: Network-based global optimization
    theta = initial_pose
    lr_min = 1e-6
    lr_max = 1e-4
    lr_period = 100
    momentum = 0.9
    convergence_threshold_N = 3e-3
    window_size = 10
    loss_history_N = []

    while True:
        # Compute network similarity loss L_N
        # This involves differentiable rendering/projection using current theta
        L_N = compute_network_loss(theta, ground_truth_image, volume, segmentation)
        
        # Update pose using SGD with momentum and cyclic LR
        grad_L_N = compute_gradient(L_N, theta)
        theta = update_sgd(theta, grad_L_N, lr=get_cyclic_lr(current_step, lr_min, lr_max, lr_period), momentum=momentum)
        current_step += 1
        
        # Store loss for convergence check
        loss_history_N.append(L_N)
        if len(loss_history_N) > window_size:
            loss_history_N.pop(0)
        
        # Check convergence
        if len(loss_history_N) == window_size:
            std_L_N = standard_deviation(loss_history_N)
            if std_L_N < convergence_threshold_N:
                break

    # Phase 2: Grad-NCC local refinement
    lr_min_G = 1e-3
    lr_max_G = 3e-3
    convergence_threshold_GNNC = 1e-5
    loss_history_GNNC = []

    while True:
        # Compute Grad-NCC loss L_GNNC
        L_GNNC = compute_grad_ncc_loss(theta, ground_truth_image, volume)
        
        # Update pose using SGD with momentum and cyclic LR
        grad_L_GNNC = compute_gradient(L_GNNC, theta)
        theta = update_sgd(theta, grad_L_GNNC, lr=get_cyclic_lr(current_step, lr_min_G, lr_max_G, lr_period), momentum=momentum)
        current_step += 1
        
        # Store loss for convergence check
        loss_history_GNNC.append(L_GNNC)
        if len(loss_history_GNNC) > window_size:
            loss_history_GNNC.pop(0)
            
        # Check convergence
        if len(loss_history_GNNC) == window_size:
            std_L_GNNC = standard_deviation(loss_history_GNNC)
            if std_L_GNNC < convergence_threshold_GNNC:
                break

    return theta
```

**Parameters:**
- $std_{L_N}$ threshold: $3 \times 10^{-3}$ [S1].
- $std_{L_{GNNC}}$ threshold: $1 \times 10^{-5}$ [S1].
- Learning rate range (Phase 1): $[1 \times 10^{-6}, 1 \times 10^{-4}]$ [S1].
- Learning rate range (Phase 2): $[1 \times 10^{-3}, 3 \times 10^{-3}]$ [S1].
- Momentum: 0.9 [S1].
- Window size for STD calculation: 10 iterations [S1].

**Edge Cases and Pitfalls:**
- The switch criterion relies on the stability of the loss value. If the network loss oscillates significantly without converging, the switch may not trigger correctly [S1].
- The method assumes the network loss $L_N$ provides a sufficiently smooth global landscape to guide the optimizer close to the solution, after which the local convexity of Grad-NCC takes over [S1].

## Subtopics

### [Gradient Descent Registration via ZNCC](9913-gradient-descent-registration-via-zncc.md)
This method performs 6 Degrees of Freedom (DoF) slice-to-volume registration by minimizing the negative Zero-Normalized Cross-Correlation (ZNCC) between a fixed Digitally Reconstructed Radiograph (DRR) and a moving DRR using gradient descent. It serves as the local refinement stage of the Hybrid 2D/3D Registration Optimization Pipeline, leveraging the locally convex loss landscape of ZNCC to converge quickly from random initializations. Unlike the global network-based loss ($L_N$) in its parent pipeline, this method relies on traditional gradient descent with momentum, requiring differentiable DRR generation to compute gradients with respect to pose parameters.

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Measured Performance:** Tested on 150 simulation studies using 17 full-body CT scans and 100 registrations on real X-ray images from a cadaver specimen [S1].
- **Strengths:** Combines the global convergence capability of network-based losses with the local precision and texture sensitivity of Grad-NCC [S1].
- **Limitations:** Requires two distinct loss functions and convergence monitoring logic [S1].
- **When to use:** When high-precision 2D/3D registration is required and initial pose estimates may be far from the ground truth, benefiting from a global-to-local optimization strategy [S1].
- **When not to use:** When computational resources are extremely limited and a single-stage optimization is preferred, or when the network-based loss does not converge reliably [S1].

## Background
The method was introduced in the paper "Generalizing Spatial Transformers to Projective Geometry with Applications to 2D/3D Registration" [S1]. It addresses the trade-off between network-based methods, which are robust but less sensitive to local textures, and traditional image-based methods like Grad-NCC, which are sensitive to local textures but may struggle with global convergence [S1]. The pipeline was evaluated on simulated data with poses drawn from normal distributions $N(0, 37.5)$ mm for translation and $N(0, 15)$ degrees for rotation, and real X-ray images with poses drawn from $N(0, 30)$ mm for translation [S1].
