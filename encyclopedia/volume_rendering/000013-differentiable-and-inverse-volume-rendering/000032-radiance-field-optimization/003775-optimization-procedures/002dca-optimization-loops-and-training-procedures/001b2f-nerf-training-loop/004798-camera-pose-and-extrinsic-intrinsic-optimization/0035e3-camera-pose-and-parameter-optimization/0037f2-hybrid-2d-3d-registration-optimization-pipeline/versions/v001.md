# Hybrid 2D/3D Registration Optimization Pipeline
Also called: Net+GradNCC, Two-Stage Similarity Optimization

## Overview
This method is a two-stage optimization pipeline for 2D/3D registration that combines a differentiable network-based similarity loss for global convergence with a traditional Gradient-based Normalized Cross-Correlation (Grad-NCC) loss for local refinement [S1]. It addresses the trade-off between the robustness of network-based methods to local textures and the precision of traditional image-based methods [S1]. Unlike its siblings which often rely on a single loss function or specific frequency filtering (e.g., [BARF](6872-barf-bundle-adjusting-neural-radiance-fields.md), [L2G-NeRF](8671-l2g-nerf.md)), this pipeline explicitly switches optimizers and loss metrics based on convergence criteria to leverage the locally convex landscape of NCC for final accuracy [S1].

## How it works
**Inputs:**
*   Fixed target image $I_{target}$ (e.g., Digitally Reconstructed Radiograph or real X-ray).
*   Moving volume $V_{CT}$ and optional segmentation $V_{Seg}$.
*   Initial pose parameters $\theta$ (rotation and translation).

**Outputs:**
*   Optimized pose parameters $\theta^*$.

**Data Structures:**
*   Pose parameters $\theta$: Represented as rotation and translation components. In the source experiments, rotation is sampled from $N(0, 37.5)$ degrees and translation from $N(0, 37.5)$ mm [S1].
*   Loss values: Scalar values $L_N$ (network loss) and $L_{GNNC}$ (Grad-NCC loss).

**Steps:**
1.  **Stage 1: Network-Based Global Optimization**
    *   Initialize pose parameters $\theta$.
    *   Compute the network similarity loss $L_N$ between the rendered image from $V_{CT}$ (using current $\theta$) and $I_{target}$ [S1].
    *   Optimize $\theta$ using Stochastic Gradient Descent (SGD) with:
        *   Cyclic learning rate between $1e-6$ and $1e-4$ every 100 steps [S1].
        *   Momentum of 0.9 [S1].
    *   Monitor convergence by calculating the standard deviation of $L_N$ over the last 10 iterations, denoted as $std_{L_N}$ [S1].
    *   If $std_{L_N} < 3 \times 10^{-3}$, switch to Stage 2 [S1]. Otherwise, continue Stage 1.

2.  **Stage 2: Grad-NCC Local Refinement**
    *   Compute the Grad-NCC loss $L_{GNNC}$ [S1].
    *   Optimize $\theta$ using SGD with:
        *   Cyclic learning rate between $1e-3$ and $3e-3$ [S1].
        *   Momentum of 0.9 [S1].
    *   Monitor convergence by calculating the standard deviation of $L_{GNNC}$ over the last 10 iterations, denoted as $std_{L_{GNNC}}$ [S1].
    *   If $std_{L_{GNNC}} < 1 \times 10^{-5}$, stop and return $\theta$ [S1]. Otherwise, continue Stage 2.

**Pseudocode:**
```python
def hybrid_registration(V_CT, V_Seg, I_target, theta_init):
    # Stage 1: Network Loss Optimization
    theta = theta_init
    lr_min, lr_max = 1e-6, 1e-4
    lr_period = 100
    momentum = 0.9
    std_threshold_N = 3e-3
    
    # Initialize optimizer state for Stage 1
    optimizer = SGD(params=[theta], lr=lr_min, momentum=momentum)
    
    while True:
        # Compute network loss L_N
        # Note: The specific network architecture for L_N is not detailed in the source,
        # but it is described as a "differentiable network similarity loss" [S1].
        # We assume a function compute_network_loss exists.
        L_N = compute_network_loss(V_CT, V_Seg, I_target, theta)
        
        optimizer.zero_grad()
        L_N.backward()
        optimizer.step()
        
        # Update learning rate cyclically
        current_lr = lr_min + (lr_max - lr_min) * (step_count % lr_period) / lr_period
        set_learning_rate(optimizer, current_lr)
        
        # Check convergence

            std_L_N = standard_deviation(recent_L_N_values[-10:])
            if std_L_N < std_threshold_N:
                break
        
        recent_L_N_values.append(L_N)
        step_count += 1

    # Stage 2: Grad-NCC Loss Optimization
    lr_min_gnncc, lr_max_gnncc = 1e-3, 3e-3
    std_threshold_GNNC = 1e-5
    
    # Re-initialize or update optimizer for Stage 2
    optimizer = SGD(params=[theta], lr=lr_min_gnncc, momentum=momentum)
    recent_L_GNNC_values = []
    
    while True:
        # Compute Grad-NCC loss L_GNNC
        # Implemented as a PyTorch loss function [S1]
        L_GNNC = compute_grad_ncc_loss(V_CT, I_target, theta)
        
        optimizer.zero_grad()
        L_GNNC.backward()
        optimizer.step()
        
        # Update learning rate cyclically
        current_lr = lr_min_gnncc + (lr_max_gnncc - lr_min_gnncc) * (step_count % lr_period) / lr_period
        set_learning_rate(optimizer, current_lr)
        
        # Check convergence
        if step_count >= 10:
            std_L_GNNC = standard_deviation(recent_L_GNNC_values[-10:])
            if std_L_GNNC < std_threshold_GNNC:
                break
        
        recent_L_GNNC_values.append(L_GNNC)
        step_count += 1
        
    return theta
```

**Edge Cases and Pitfalls:**
*   **Convergence Detection:** The switch criterion relies on the standard deviation of the loss over a small window (10 iterations). If the loss oscillates due to high learning rates or noisy gradients, the switch may occur prematurely or not at all [S1].
*   **Local Minima:** While Grad-NCC is less sensitive to local textures than traditional methods, it may still get stuck in local minima if the initial pose from Stage 1 is too far off [S1].
*   **Precision:** The thresholds ($3 \times 10^{-3}$ and $1 \times 10^{-5}$) are specific to the experimental setup (Siemens CIOS Fusion C-Arm geometry) and may need adjustment for different resolutions or noise levels [S1].

## Subtopics

### [Gradient Descent Registration via ZNCC](9913-gradient-descent-registration-via-zncc.md)
This method performs 6 Degrees of Freedom (DoF) slice-to-volume registration by minimizing the negative Zero-Normalized Cross-Correlation (ZNCC) between a fixed Digitally Reconstructed Radiograph (DRR) and a moving DRR using gradient descent. It serves as the local refinement stage of the Hybrid 2D/3D Registration Optimization Pipeline, leveraging the locally convex loss landscape of ZNCC to converge quickly from random initializations. Unlike the global network-based loss ($L_N$) in its parent pipeline, this method relies on traditional gradient descent with momentum, requiring differentiable DRR generation to compute gradients with respect to pose parameters.

## Operating characteristics
*   **Time Complexity:** The method involves two sequential optimization stages. The total time is the sum of iterations required for Stage 1 to converge and Stage 2 to converge. The source does not provide explicit complexity formulas, but the use of SGD suggests linear complexity with respect to the number of iterations and batch size [S1].
*   **Memory Complexity:** Depends on the memory required to store the volume $V_{CT}$, the network weights (if $L_N$ uses a neural network), and the gradients during backpropagation [S1].
*   **Measured Performance:** Tested on 150 simulation studies using 17 full-body CT scans and 100 registrations on real X-ray images from a cadaver specimen [S1]. The pipeline was designed to be robust to initial pose errors, with rotation sampled from $N(0, 15)$ degrees and translation from $N(0, 30)$ mm for real X-ray studies [S1].
*   **Strengths:** Combines the global convergence properties of network-based methods with the local precision of Grad-NCC [S1].
*   **Limitations:** Requires implementing two different loss functions and switching logic. The performance is dependent on the specific learning rate schedules and convergence thresholds, which may need tuning for different datasets [S1].

## Background
The method was introduced in the paper "Generalizing Spatial Transformers to Projective Geometry with Applications to 2D/3D Registration" [S1]. It was developed to address the limitations of traditional image-based methods like Grad-NCC, which are sensitive to local textures, and network-based methods, which may lack precision [S1]. The pipeline was tested on simulated data from a Siemens CIOS Fusion C-Arm and real X-ray images from a cadaver specimen [S1].
