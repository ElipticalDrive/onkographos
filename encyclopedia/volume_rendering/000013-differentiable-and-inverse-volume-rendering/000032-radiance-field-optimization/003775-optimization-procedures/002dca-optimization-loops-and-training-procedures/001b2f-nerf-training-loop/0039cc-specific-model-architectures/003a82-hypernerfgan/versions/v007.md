# HyperNeRFGAN

Also called: HyperNeRFGAN

## Overview
HyperNeRFGAN is a generative model that uses a hypernetwork to produce the weights of a simplified NeRF target network, trained using the StyleGAN2 objective to generate 3D representations from a Gaussian noise distribution [S1, unofficial]. It solves the problem of 3D-aware image generation when camera positions are unavailable or difficult to estimate, by removing viewing directions from the NeRF input and using a hypernetwork to implicitly encode the 3D structure [S1, unofficial]. Unlike standard NeRF variants that condition on camera poses, HyperNeRFGAN generates a single 3D representation per noise vector that is view-independent in its input but renders view-dependent images via the volume rendering integral [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A noise vector $\mathbf{z}$ sampled from a standard Gaussian distribution $\mathcal{N}(0, I)$ [S1, unofficial].
*   **Output:** A 2D image $\mathbf{C}(\mathbf{r})$ rendered from the generated 3D representation [S1, unofficial].

**Data Structures:**
The model consists of two main components:
1.  **Generator ($G$):** A StyleGAN2-based hypernetwork that maps $\mathbf{z}$ to the weights $\theta$ of the target NeRF [S1, unofficial].
2.  **Target NeRF ($F_\theta$):** A single MLP that maps 3D spatial coordinates $\mathbf{x}$ to color $\mathbf{c}$ and density $\sigma$ [S1, unofficial].

The Target NeRF $F_\theta$ uses **Factorized Multiplicative Modulation (FMM)** layers instead of standard linear layers. An FMM layer is defined as:
$$
\mathbf{y} = \mathbf{W} \odot (\mathbf{A} \times \mathbf{B}) \cdot \mathbf{x}_{in} + \mathbf{b} = \tilde{\mathbf{W}} \cdot \mathbf{x}_{in} + \mathbf{b}
$$
where:
*   $\mathbf{W}$ and $\mathbf{b}$ are shared weight matrices and biases across all generated NeRFs [S1, unofficial].
*   $\mathbf{A}$ and $\mathbf{B}$ are modulation matrices generated by $G$, with dimensions $n_{out} \times k$ and $k \times n_{in}$ respectively [S1, unofficial].
*   $k$ is the rank parameter controlling the expressiveness and memory usage; the source uses $k=10$ [S1, unofficial].
*   $\odot$ denotes element-wise multiplication, and $\times$ denotes matrix multiplication [S1, unofficial].

**Parameters:**
*   **Hidden Layer Channels:** Reduced from the standard 256 to 128 to reduce computational expense [S1, unofficial].
*   **Network Depth:** Reduced from 8 layers to 4 layers in some experiments to reduce computational expense [S1, unofficial].
*   **Rank ($k$):** Set to 10 [S1, unofficial].
*   **Fine Network:** The standard NeRF "fine" network is rejected; only the "coarse" network is used [S1, unofficial].

**Numbered Steps:**
1.  Sample a noise vector $\mathbf{z} \sim \mathcal{N}(0, I)$ [S1, unofficial].
2.  Pass $\mathbf{z}$ through the Generator $G$ to obtain the modulation matrices $\mathbf{A}$ and $\mathbf{B}$ for all FMM layers in the target NeRF [S1, unofficial].
3.  Construct the target NeRF $F_\theta$ using the shared weights $\mathbf{W}, \mathbf{b}$ and the generated modulations $\mathbf{A}, \mathbf{B}$ [S1, unofficial].
4.  Define a camera ray $\mathbf{r}$ with origin $\mathbf{o}$ and direction $\mathbf{d}$ [S1, unofficial].
5.  Sample $N$ points $\mathbf{x}_i$ along the ray $\mathbf{r}$ [S1, unofficial].
6.  Query $F_\theta$ at each $\mathbf{x}_i$ to obtain color $\mathbf{c}_i$ and density $\sigma_i$. Note that $F_\theta$ does **not** take viewing direction $\mathbf{d}$ as input [S1, unofficial].
7.  Compute transmittance $T_i$ and alpha $\alpha_i$ using the volume rendering equations:
    $$
    \alpha_i = 1 - \exp(-\sigma_i \delta_i), \quad T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)
    $$
    where $\delta_i$ is the distance between samples [S1, unofficial].
8.  Render the final color $\mathbf{C}(\mathbf{r})$:
    $$
    \mathbf{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i
    $$
    [S1, unofficial].
9.  Train the Generator $G$ and Discriminator $D$ using the minimax game:
    $$
    \min_G \max_D V(D, G)
    $$
    where
    $$
    V(D, G) = \mathbb{E}_{\mathbf{x} \sim P_{data}}[\log D(\mathbf{x})] + \mathbb{E}_{\mathbf{z} \sim P_{noise}}[\log(1 - D(G(\mathbf{z})))]
    $$
    [S1, unofficial].

    def __init__(self, n_in, n_out, rank=10):
        super().__init__()
        self.rank = rank
        # Shared weights (initialized randomly or from a base network)
        self.W = nn.Parameter(torch.randn(n_out, n_in))
        self.b = nn.Parameter(torch.zeros(n_out))
        # Modulation matrices dimensions
        # A: n_out x k, B: k x n_in
        self.A = nn.Parameter(torch.randn(n_out, rank))
        self.B = nn.Parameter(torch.randn(rank, n_in))

    def forward(self, x_in, mod_A, mod_B):
        """
        x_in: (batch, n_in)
        mod_A: (batch, n_out, rank) - generated by G
        mod_B: (batch, rank, n_in) - generated by G
        """
        # Compute modulation matrix: A x B
        # mod_A: (batch, n_out, rank)
        # mod_B: (batch, rank, n_in)
        # matmul result: (batch, n_out, n_in)
        modulation = torch.bmm(mod_A, mod_B)

        h = x
        for i, layer in enumerate(self.layers):
            A, B = modulations[i]
            h = layer(h, A, B)
        
        c = self.color_head(h)

def render_ray(ray_o, ray_d, n_samples, nerf, modulations):
    """
    Renders a single ray using the volume rendering integral.
    """
    # Sample points along the ray
    t_vals = torch.linspace(0, 1, n_samples)
    z_vals = ray_o + ray_d * t_vals.unsqueeze(1) # (n_samples, 3)
    
    # Query NeRF
    c, sigma = nerf(z_vals, modulations)
    
    # Compute deltas
    deltas = t_vals[1:] - t_vals[:-1]
    # Handle first delta
    deltas = torch.cat([deltas, torch.tensor([1e10])]) # Approximate infinity for last delta
    
    # Compute alpha
    alpha = 1.0 - torch.exp(-sigma.squeeze() * deltas)
    
    # Compute transmittance
    T = torch.cumprod(torch.exp(-sigma.squeeze() * deltas), dim=0)
    T = torch.cat([torch.ones_like(T[:, :1]), 1.0 - T + alpha], dim=1) # Adjust for standard formulation
    
    # Standard formulation: T_i = exp(-sum_{j=1}^{i-1} sigma_j delta_j)
    # alpha_i = 1 - exp(-sigma_i delta_i)
    # C = sum T_i alpha_i c_i
    
    # Recalculate T properly

    T_cumprod = torch.cumprod(exp_neg_sigma_delta, dim=0)
    T = torch.cat([torch.ones_like(T_cumprod[:, :1]), T_cumprod[:, :-1]], dim=1)
    
    # Render
    weights = T * alpha
    color = torch.sum(weights.unsqueeze(1) * c, dim=0)
    
    return color

**Edge Cases and Pitfalls:**
*   **Viewing Directions:** The model does not accept viewing directions as input. If the dataset contains view-dependent effects (e.g., reflections), the quality may suffer [S1, unofficial].
*   **Fine Network:** The "fine" network from standard NeRF is omitted. This reduces training cost but may limit high-frequency detail recovery compared to multi-scale NeRFs [S1, unofficial].
*   **Rank $k$:** Higher $k$ increases expressiveness but also memory usage. The source fixes $k=10$ [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources, but the source notes that higher $k$ increases memory usage [S1, unofficial].
*   **Measured Performance:**
    *   **ShapeNet Car:** FID 29.6 (vs Point2NeRF 82.1) [S1, unofficial].
    *   **CARLA Dataset:** FID 20.5, KID 0.78, IS 4.20 (vs HoloGAN FID 67.5, GRAF FID 41.7, π-GAN FID 29.2) [S1, unofficial].
    *   **CelebA Dataset:** FID 15.04, KID 0.66, IS 2.63 (vs π-GAN FID 14.7, KID 0.39, IS 2.62) [S1, unofficial].
    *   **Medical (DRR):** Outperforms MedNeRF and UMedNeRF in FID and KID metrics [S1, unofficial].
*   **Strengths:** Does not require camera position estimation; suitable for datasets with few views or no pose information (e.g., medical data); superior performance on datasets where camera estimation is challenging [S1, unofficial].
*   **Limitations:** Cannot model view-dependent effects (e.g., reflections) due to lack of viewing direction input; simplified NeRF architecture (no fine network) may limit detail [S1, unofficial].
*   **When to Use:** When generating 3D-aware images from datasets without camera poses or with very few views per object [S1, unofficial].
*   **When Not to Use:** When view-dependent effects are important or when high-frequency detail recovery is critical and multi-scale rendering is needed [S1, unofficial].

## Background
HyperNeRFGAN was introduced in a paper titled "HyperNeRFGAN: Hypernetwork approach to 3D NeRF GAN" [S1, unofficial]. It builds on the hypernetwork paradigm [S1, unofficial] and the StyleGAN2 architecture [S1, unofficial]. It is designed to overcome the limitation of NeRF training requiring camera positions [S1, unofficial]. It is used for 3D object generation on ShapeNet (car, plane, chair) and CARLA datasets, and for medical applications on Digitally Reconstructed Radiographs (DRR) of chests and knees [S1, unofficial].
