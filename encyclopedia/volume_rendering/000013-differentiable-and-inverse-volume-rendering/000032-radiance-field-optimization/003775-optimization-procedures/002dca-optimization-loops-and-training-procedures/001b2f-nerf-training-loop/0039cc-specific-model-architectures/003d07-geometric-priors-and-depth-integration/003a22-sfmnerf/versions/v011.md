# SfMNeRF

Also called: SfM-NeRF

## Overview
SfMNeRF is a method to improve novel view synthesis and 3D-scene geometry reconstruction for Neural Radiance Fields (NeRF) under sparse input conditions by integrating Structure-from-Motion (SfM) constraints, including matched feature positions, epipolar geometry, and multi-view photometric consistency, into the view synthesis training [S1]. It sets itself apart from standard NeRF by explicitly constraining the 3D-scene geometry to avoid local minima and reduce shape-radiance ambiguity, and differs from its sibling [DASNeRF](8668-dasnerf.md) by relying on explicit geometric priors (SIFT matches, epipolar lines) rather than differentiable surface reconstruction or depth-aware rendering losses alone [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of images with known camera intrinsics $K$ and global poses $[\mathbf{r}_t, \mathbf{t}_t]$. For each training step, a reference image $I_r$ and a target image $I_t$ with overlapping regions are selected.
*   **Outputs:** An optimized NeRF model (MLP parameters $\theta$) that predicts volume density $\sigma_\theta$ and color $c_\theta$, producing novel views and depth maps.

**Data Structures:**
*   **Camera Intrinsic Matrix $K$:** $3 \times 3$ matrix.
*   **Global Pose:** $[\mathbf{r}_t, \mathbf{t}_t]$, where $\mathbf{r}_t$ is rotation and $\mathbf{t}_t$ is translation for image $t$.
*   **Relative Pose $T_{r \to t}$:** $4 \times 4$ transformation matrix derived from global poses.
*   **Mask Map $M$:** Binary map where $M(p(k))=1$ if point $p(k)$ is inside the minimum rectangle enclosing all matched SIFT features in the reference image, else $0$.
*   **Depth Map $D$:** Estimated depth for pixels in the patch.
*   **SIFT Features:** 2D coordinates in reference and target images, matched via Scale-Invariant Feature Transform.

**Numbered Steps:**

1.  **Pyramidal Construction:** Construct an $L$-level pyramid of the reference and target images ($I^0_r, \dots, I^{L-1}_r$ and $I^0_t, \dots, I^{L-1}_t$), where $I^n_r$ is downsampled from $I^{n-1}_r$ to half the resolution [S1].
2.  **Initialization:** Start optimization at the lowest level $L-1$ using images $I^{L-1}_r$ and $I^{L-1}_t$.
3.  **Feature Extraction:** Extract SIFT features in $I_r$ and $I_t$ and obtain matched correspondences [S1].
4.  **Sub-pixel Sampling:** Randomly select a patch $\Omega_p$ (size $32 \times 32$) from the reference image [S1]. For each pixel $p=(x,y)$ in the patch, generate sub-pixel coordinates:
    $$p = (x + x_{off}, y + y_{off})$$
    where $x_{off}, y_{off} \in (0, 1)$ are random offsets [S1].
5.  **Ground Truth Generation:** Compute the ground-truth color $\hat{I}(p)$ for each sub-pixel via bilinear interpolation of the four neighboring integer pixels $p^{ij}$ ($i \in \{top, bottom\}, j \in \{left, right\}$):
    $$\hat{I}(p) = \sum_{i \in \{top, bottom\}, j \in \{left, right\}} w^{ij} I(p^{ij})$$
    where weights $w^{ij}$ are linearly proportional to the inverse Euclidean distance between $p$ and $p^{ij}$ [S1].
6.  **NeRF Rendering:** Input sub-pixel coordinates and view directions $\mathbf{d}$ into the NeRF. Sample $N_c$ points along the ray with positions $\mathbf{o} + t_j \mathbf{d}$. Compute volume density $\sigma_j$ and color $c_j$.
7.  **3D Coordinate Estimation:** Calculate the 3D coordinate $\mathbf{x}_s$ of SIFT features and other points using the weighted sum of samples:
    $$\mathbf{x}_s = \sum_{j=1}^{N_c} w_j (\mathbf{o} + t_j \mathbf{d})$$
    where $w_j = T_j (1 - \exp(-\sigma_j \delta_j))$, $\delta_j = t_{j-1} - t_j$, and $T_j$ is the transmittance [S1].
8.  **Loss Computation:** Calculate the following loss components:
    *   **Rendering Loss ($L_{ren}$):** Mean squared error between synthesized color $\tilde{I}(p_i)$ and ground-truth $\hat{I}(p_i)$:
        $$L_{ren} = \frac{1}{m} \sum_{p_i \in \Omega_p} \left\| \hat{I}(p_i) - \tilde{I}(p_i) \right\|_2^2$$
    *   **Positions-of-Matched Features Loss ($L_{3D}$):** Minimize distance between 3D coordinates of matched SIFT features in reference ($\mathbf{x}_s^k$) and target ($\mathbf{x}_{s'}^k$) images:
        $$L_{3D} = \frac{1}{n} \sum_{k=1}^n \|\mathbf{x}_s^k - \mathbf{x}_{s'}^k\|_2^2$$
    *   **Epipolar Constraint Loss ($L_{epi}$):** For a point in the reference image, find the minimum distance to points on the epipolar line in the target image. Filter implausible epipolar points by color similarity (keep points where color difference is below a threshold) to improve efficiency [S1]:
        $$L_{epi} = \min_t \left\{ \left\| \mathbf{d}_{p_r} - \mathbf{d}_{p_t} \right\|_2^2 \right\}$$
        where $\mathbf{d}_{p_r}$ and $\mathbf{d}_{p_t}$ are estimated 3D coordinates [S1].
    *   **Photometric Consistency Loss ($L_{pc}$):**
        *   Warp pixels from the reference patch to the target view: $\hat{p}_t = K T_{r \to t} \mathbf{x}_p$, where relative pose $T_{r \to t} = [\mathbf{r}, \mathbf{t}]$ with $\mathbf{r} = \mathbf{r}_t^{-1}$ and $\mathbf{t} = -\mathbf{r}_t^{-1}\mathbf{t}_t$ [S1].
        *   **Photometric Reconstruction Loss ($L_{pr}$):**
            $$L_{pr} = \sum_{p(k) \in \Omega_p} M(p(k)) \left| \hat{I}_r(p(k)) - \hat{I}_t(\hat{p}_t(k)) \right|$$
        *   **SSIM Loss ($L_{SSIM}$):**
            $$L_{SSIM} = M \left( \frac{1 - SSIM_{r \to t}}{2} \right)$$
    *   **Depth Smooth Loss ($L_{ds}$):**
        $$L_{ds} = \sum_{p(k) \in \Omega_p} \left| \nabla D ( p(k) ) \cdot \left( e^{-|\hat{I}(p(k))|} \right) \right|$$
        where $\nabla$ is the 2D differential operator [S1].
9.  **Total Loss:**
    $$L_{total} = \lambda_{ren} L_{ren} + \lambda_{3D} L_{3D} + \lambda_{pr} L_{pr} + \lambda_{epi} L_{epi} + \lambda_{SSIM} L_{SSIM} + \lambda_{ds} L_{ds}$$
10. **Optimization:** Update NeRF parameters using Adam optimizer ($\beta_1=0.9, \beta_2=0.999$, learning rate $1e-3$) [S1].
11. **Pyramidal Recursion:** After optimizing level $n-1$, obtain depth map $D^{n-1}_r$. Move to level $n-2$. Add a depth loss to guide optimization:
    $$L_{depth} = \sum_{p(k) \in \Omega_p} |D(p(k)) - D_r^{L-1}(p(k)/2)|$$
    where $D_r^{L-1}(p(k)/2)$ is sampled via bilinear interpolation from the lower-resolution depth map [S1]. Repeat until level 0.

**Parameters:**
*   $\lambda_{ren} = 1.0$
*   $\lambda_{3D} = 1.0$
*   $\lambda_{pr} = 0.001$
*   $\lambda_{epi} = 0.0001$
*   $\lambda_{SSIM} = 0.008$
*   $\lambda_{ds} = 0.01$
*   Patch size: $32 \times 32$
*   Samples per ray: 64 (coarse) + 64 (importance) [S1]

**Edge Cases and Pitfalls:**
*   **Epipolar Points:** A large number of epipolar points causes computational inefficiency. Occluded points may not have corresponding points on the epipolar line. Color similarity filtering is required to eliminate implausible points [S1].
*   **Local Minima:** Large pixel motions can cause the photometric consistency loss to get stuck in local minima. The pyramidal strategy is necessary to handle this [S1].
*   **Masking:** The mask $M$ ensures that only pixels within the region of matched SIFT features contribute to the photometric loss, filtering out areas without correspondences [S1].

## Operating characteristics
*   **Time and Memory Complexity:** The method involves SIFT extraction, epipolar line sampling, and multi-view warping, which adds computational overhead compared to standard NeRF. The pyramidal strategy requires multiple passes over the data at different resolutions.
*   **Performance:** Evaluated on LLFF-NeRF, ScanNet, and DTU MVS datasets. It surpasses state-of-the-art approaches given sparse inputs [S1].
*   **Strengths:** Improves geometric accuracy and novel view synthesis quality under sparse input conditions by explicitly constraining 3D structure. Sub-pixel rendering improves generalization.
*   **Limitations:** Relies on the quality of SIFT matches and camera poses. Computationally more expensive due to explicit geometric constraints and pyramidal training.
*   **When to use:** Sparse input scenarios where standard NeRF fails to reconstruct moderate 3D structures.
*   **When not to use:** Dense input scenarios where standard NeRF performs well, or when computational resources are limited.

## Background
SfMNeRF was proposed to address the failure of existing NeRF-based methods to obtain moderate 3D structures under sparse input conditions, where novel view synthesis quality drops dramatically due to implicitly reconstructed inaccurate 3D-scene structure [S1]. It leverages knowledge from self-supervised depth estimation methods and Structure-from-Motion (SfM) principles to constrain the geometry during view synthesis training [S1]. The method was evaluated on public datasets including LLFF-NeRF, ScanNet, and DTU MVS [S1].
