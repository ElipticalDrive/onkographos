# Mega-NeRF Spatial Partitioning

Also called: Cell-based NeRF, Spatial Data Parallelism

## Overview
Mega-NeRF addresses the memory and training time bottlenecks of standard NeRF when applied to large-scale, outdoor scenes by decomposing the environment into spatial cells, each managed by a separate MLP submodule trained in parallel [S1]. Unlike monolithic architectures, it isolates scene regions to reduce the training dataset size per module by up to 20x through visibility partitioning and pruning, while maintaining visual continuity via an overlap factor [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** A set of calibrated training images with poses; a scene bounding volume.
*   **Outputs:** A set of centroids $\mathcal{N}$, a set of MLP submodules $\{f^n\}_{n \in \mathcal{N}}$, and appearance embeddings $\{l^{(a)}\}$ for each image $a$.

**Data Structures**
1.  **Centroids ($\mathcal{N}$):** A set of 3D points $n = (n_x, n_y, n_z)$. In the standard implementation, these are arranged in a top-down 2D grid with a fixed height $n_z$ for all centroids [S1].
2.  **Submodules ($f^n$):** Each centroid $n$ has an associated MLP $f^n$. The architecture consists of fully connected layers similar to the original NeRF [S1].
3.  **Appearance Embeddings ($l^{(a)}$):** A learnable vector associated with each training image $a$ to account for lighting variations [S1].
4.  **Trainsets ($\mathcal{T}_n$):** For each cell $n$, a subset of training pixels/rays. Initially derived from ray-cell intersection, then pruned [S1].

**Algorithm Steps**

1.  **Centroid Initialization:**
    Tessellate the scene into a top-down 2D grid. Fix the height of all centroids to a single value, justified by the small variance in altitude relative to latitude/longitude differences in the target scenes [S1]. Let $\mathcal{N}$ be the set of resulting centroids.

2.  **Model Initialization:**
    Initialize a separate MLP submodule $f^n$ for each centroid $n \in \mathcal{N}$. Initialize appearance embeddings $l^{(a)}$ for each training image $a$ [S1].

3.  **Visibility Partitioning (Initial Assignment):**
    For each training image $a$:
    a. Sample points along the camera rays corresponding to each pixel.
    b. Identify which spatial cells (centroids) these rays intersect.
    c. Assign the pixel to the trainset $\mathcal{T}_n$ only for the intersecting cells $n$.
    d. Apply an overlap factor (typically 15%) to the cell boundaries to minimize visual artifacts at cell interfaces [S1].

4.  **Spatial Data Pruning (Optional, Post-Coarse Training):**
    After an initial coarse training phase where the scene geometry is roughly known:
    a. Identify occluders (e.g., walls) inferred by specific submodules.
    b. Remove pixels from the trainsets $\mathcal{T}_n$ of other cells if they are occluded by geometry belonging to a different cell. For example, if cell $F$ infers a wall, prune pixels from cells $A$ and $B$ that are behind that wall [S1].

5.  **Query and Rendering:**
    For a query point $\mathbf{x}$, direction $\mathbf{d}$, and image $a$:
    a. Find the closest centroid $n^*$:
       $$ n^* = \argmin_{n \in \mathcal{N}} \| n - \mathbf{x} \|^2 $$
    b. Compute opacity $\sigma$ and color $\mathbf{c}$ using the weights of the closest submodule:
       $$ \sigma = f^{n^*}(\mathbf{x}) $$
       $$ \mathbf{c} = f^{n^*}(\mathbf{x}, \mathbf{d}, l^{(a)}) $$
    c. Integrate $\sigma$ and $\mathbf{c}$ along the ray using the standard volume rendering equation [S1].

**Parameters**
*   **Overlap Factor:** 15% (0.15) of cell width. Used to minimize visual artifacts near cell boundaries [S1].
*   **Centroid Height:** Fixed to a single value for all centroids, based on the assumption that altitude variance is small compared to horizontal variance [S1].

**Edge Cases and Pitfalls**
*   **Boundary Artifacts:** Without the overlap factor, discontinuities may appear at cell boundaries. The 15% overlap mitigates this but increases memory usage slightly [S1].
*   **Occlusion Pruning:** Pruning relies on a "coarse understanding" of the scene. If the initial training is insufficient, occlusion inference may be incorrect, leading to loss of valid data [S1].
*   **Altitude Variance:** The fixed-height centroid assumption may fail for scenes with significant vertical variation (e.g., multi-story buildings with large height differences between camera poses) [S1].

## Subtopics

### Foreground/Background Decomposition
Mega-NeRF can further subdivide the scene into a foreground volume (enclosing all camera poses) and a background volume, modeled with separate Mega-NeRFs [S1]. This is useful for scenes with distinct near and far components.

### Centroid Selection Methods
While the 2D grid is the primary method, k-means clustering and uncertainty-based partitioning were explored but found less practical due to complexity or preprocessing requirements [S1].

## Operating characteristics
*   **Memory:** Significantly reduced per-module memory usage. The total memory is distributed across $N$ submodules, each handling a fraction of the data.
*   **Training Time:** Parallelizable training of submodules. Visibility partitioning reduces the trainset size per module by 10x initially, and up to 20x with additional pruning [S1].
*   **Scalability:** Scales to large-scale outdoor scenes (e.g., city blocks) where a single NeRF would exceed memory limits [S1].
*   **Strengths:** Efficient handling of large scenes; reduced training time; parallelizable.
*   **Limitations:** Potential visual artifacts at cell boundaries (mitigated by overlap); fixed-height assumption may not suit all terrains; requires careful initialization of coarse geometry for pruning [S1].

## Background
Mega-NeRF was introduced in 2022 by Mildenhall et al. as an extension of NeRF to enable scalable construction of large-scale neural radiance fields for virtual fly-throughs [S1]. It builds on the principles of NeRF [S1] and incorporates ideas from NeRF++ regarding foreground/background decomposition [S1]. The method addresses the limitation of standard NeRF, which struggles with large scenes due to memory constraints and long training times [S1].
