# SfMNeRF

Also called: SfM-NeRF

## Overview
SfMNeRF is a method for novel view synthesis and 3D-scene geometry reconstruction that improves Neural Radiance Fields (NeRF) under sparse input conditions by integrating Structure-from-Motion (SfM) constraints into the training loop [S1]. It addresses the geometric inaccuracies and local minima common in sparse NeRF optimization by explicitly enforcing epipolar geometry, multi-view photometric consistency, depth smoothness, and feature position consistency [S1]. Unlike standard NeRF which relies solely on implicit volume rendering losses, SfMNeRF leverages sparse SIFT features and cross-view warping to constrain the 3D structure, combined with a pyramidal training strategy to handle large pixel motions [S1].

## How it works
### Inputs and Outputs
**Inputs:**
*   A set of $N$ images $\{I_i\}$ with known camera intrinsics $K$ and global poses $[\mathbf{r}_i, \mathbf{t}_i]$ [S1].
*   Matched Scale-Invariant Feature Transform (SIFT) correspondences between image pairs [S1].
*   A Neural Radiance Field model $f_\Theta$ (MLP) mapping $(\mathbf{x}, \mathbf{d}) \rightarrow (\sigma, \mathbf{c})$ [S1].

**Outputs:**
*   Optimized NeRF parameters $\Theta$ [S1].
*   Synthesized novel views and depth maps [S1].

### Data Structures
*   **Camera Intrinsic Matrix ($K$):** $3 \times 3$ matrix [S1].
*   **Global Pose:** $[\mathbf{r}_i, \mathbf{t}_i]$ where $\mathbf{r}_i \in SO(3)$ and $\mathbf{t}_i \in \mathbb{R}^3$ [S1].
*   **Relative Pose ($T_{r \to t}$):** $4 \times 4$ transformation matrix derived from global poses: $\mathbf{r} = \mathbf{r}_t^{-1}$, $\mathbf{t} = -\mathbf{r}_t^{-1}\mathbf{t}_t$ [S1].
*   **SIFT Features:** Set of matched 2D pixel coordinates $\{p^k\}$ between reference and target images [S1].
*   **Mask Map ($M$):** Binary mask where $M(p(k))=1$ if point $p(k)$ is within the minimum bounding rectangle of all matched SIFT features in the reference image, else $0$ [S1].
*   **Depth Map ($D$):** Estimated depth for each pixel [S1].
*   **Pyramid Levels:** $L$ levels of image representations $I^0, \dots, I^{L-1}$, where $I^n$ is half the resolution of $I^{n-1}$ [S1].

### Numbered Steps

1.  **Pyramidal Setup:** Construct an $L$-level image pyramid for the reference image $I_r$ and target image $I_t$. Start optimization at the lowest resolution level $L-1$ [S1].
2.  **Feature Extraction:** Extract SIFT features from $I_r$ and $I_t$. Match features to obtain correspondences [S1].
3.  **Sub-pixel Sampling:** For a random patch $\Omega_p$ in the reference image, generate sub-pixel coordinates $p = (x + x_{off}, y + y_{off})$ where $x_{off}, y_{off} \in (0, 1)$ [S1].
4.  **Ground Truth Interpolation:** Compute ground-truth color $\hat{I}(p)$ for sub-pixels via bilinear interpolation of the four nearest integer pixels in the reference image [S1].
5.  **NeRF Rendering:** Input sub-pixel coordinates and viewing directions into the NeRF MLP to obtain volume density $\sigma$ and color $\mathbf{c}$. Compute rendered color $\tilde{I}(p)$ and depth $D(p)$ using standard volume rendering integration [S1].
6.  **3D Coordinate Estimation:** Calculate the 3D coordinate $\mathbf{x}_s$ for each SIFT feature $k$ using the weighted sum of samples along the ray:
    $$ \mathbf{x}_s = \sum_{j=1}^{N_c} w_j (\mathbf{o} + t_j \mathbf{d}), \quad w_j = T_j (1 - \exp(-\sigma_j \delta_j)) $$
    where $\delta_j = t_{j-1} - t_j$ and $N_c$ is the number of samples [S1].
7.  **Loss Computation:** Calculate the following loss components:
    *   **Rendering Loss ($L_{ren}$):** Mean squared error between interpolated ground truth $\hat{I}(p)$ and rendered color $\tilde{I}(p)$ [S1].
    *   **Position-of-Matches Loss ($L_{3D}$):** Distance between 3D coordinates of matched SIFT features in reference and target views [S1].
    *   **Epipolar Loss ($L_{epi}$):** Minimum distance between the 3D coordinate of a reference point and points on the epipolar line in the target view, filtered by color similarity [S1].
    *   **Photometric Consistency Loss ($L_{pr}$):** L1 difference between reference patch colors and warped target patch colors, masked by $M$ [S1].
    *   **SSIM Loss ($L_{SSIM}$):** Structural Similarity index between reference and warped target patches, masked by $M$ [S1].
    *   **Depth Smoothness Loss ($L_{ds}$):** Weighted L1 norm of depth gradients, weighted by image gradient magnitude [S1].
    *   **Depth Prior Loss ($L_{depth}$):** (Only at levels $n < L-1$) L1 difference between current depth and bilinearly interpolated depth from the previous lower-resolution level [S1].
8.  **Optimization:** Minimize total loss $L_{total}$ using Adam optimizer [S1].
9.  **Pyramidal Progression:** Recursively move to level $n-2$, using the depth map from level $n-1$ as a prior via $L_{depth}$, until reaching level 0 [S1].

### Formulas

**Rendering Loss:**
$$ L_{ren} = \frac{1}{m} \sum_{p_i \in \Omega_p} \left\| \hat{I}(p_i) - \tilde{I}(p_i) \right\|_2^2 $$
where $\hat{I}(p_i)$ is the ground-truth color from bilinear interpolation and $\tilde{I}(p_i)$ is the synthesized pixel [S1].

**Sub-pixel Ground Truth:**
$$ \hat{I}(p) = \sum_{i \in \{top, bottom\}, j \in \{left, right\}} w^{ij} I(p^{ij}) $$
where $w^{ij}$ is proportional to the inverse Euclidean distance between $p$ and neighbor $p^{ij}$ [S1].

**3D Coordinate of SIFT Feature:**
$$ \mathbf{x}_s = \sum_{j=1}^{N_c} w_j (\mathbf{o} + t_j \mathbf{d}), \quad w_j = T_j (1 - \exp(-\sigma_j \delta_j)) $$
where $\mathbf{o}$ is ray origin, $\mathbf{d}$ is direction, $T_j$ is transmittance, and $\delta_j$ is sample spacing [S1].

**Position-of-Matched Features Loss:**
$$ L_{3D} = \frac{1}{n} \sum_{k=1}^n \|\mathbf{x}_s^k - \mathbf{x}_{s'}^k\|_2^2 $$
where $\mathbf{x}_s^k$ and $\mathbf{x}_{s'}^k$ are 3D coordinates of matched feature $k$ in reference and target images [S1].

**Epipolar Constraint Loss:**
$$ L_{epi} = \min_t \left\{ \left\| \mathbf{d}_{p_r} - \mathbf{d}_{p_t} \right\|_2^2 \right\} $$
where $\mathbf{d}_{p_r}$ is the 3D coordinate of the reference point and $\mathbf{d}_{p_t}$ are points on the epipolar line in the target view. Implausible points (large color difference or occlusion) are filtered out [S1].

**Warped Pixel Coordinate:**
$$ \hat{p}_t = K T_{r \to t} \mathbf{x}_p $$
where $\mathbf{x}_p$ is the 3D coordinate of pixel $p$ in the reference image, $K$ is the intrinsic matrix, and $T_{r \to t} = [\mathbf{r}, \mathbf{t}]$ is the relative pose with $\mathbf{r} = \mathbf{r}_t^{-1}$ and $\mathbf{t} = -\mathbf{r}_t^{-1}\mathbf{t}_t$ [S1].

**Photometric Reconstruction Loss:**
$$ L_{pr} = \sum_{p(k) \in \Omega_p} M(p(k)) \left| \hat{I}_r(p(k)) - \hat{I}_t(\hat{p}_t(k)) \right| $$
where $\hat{I}_r$ is reference color, $\hat{I}_t$ is interpolated target color at warped coordinate, and $M$ is the SIFT bounding box mask [S1].

**SSIM Loss:**
$$ L_{SSIM} = M \left( \frac{1 - SSIM_{r \to t}}{2} \right) $$
where $SSIM_{r \to t}$ is the structural similarity between the reference patch and the warped target patch [S1].

**Depth Smoothness Loss:**
$$ L_{ds} = \sum_{p(k) \in \Omega_p} \left| \nabla D ( p(k) ) \cdot \left( e^{-|\hat{I}(p(k))|} \right) \right| $$
where $\nabla$ is the 2D differential operator and the weight $e^{-|\hat{I}|}$ preserves edges [S1].

**Depth Prior Loss (Pyramidal):**
$$ L_{depth} = \sum_{p(k) \in \Omega_p} |D(p(k)) - D_r^{L-1}(p(k)/2)| $$
where $D_r^{L-1}(p(k)/2)$ is the depth from the previous lower-resolution level, sampled via bilinear interpolation at half coordinates [S1].

**Total Loss:**
$$ L_{total} = \lambda_{ren} L_{ren} + \lambda_{3D} L_{3D} + \lambda_{pr} L_{pr} + \lambda_{epi} L_{epi} + \lambda_{SSIM} L_{SSIM} + \lambda_{ds} L_{ds} + \lambda_{depth} L_{depth} $$
Note: $L_{depth}$ is added only in recursive steps. The base total loss (without depth prior) is:
$$ L_{total} = \lambda_{ren} L_{ren} + \lambda_{3D} L_{3D} + \lambda_{pr} L_{pr} + \lambda_{epi} L_{epi} + \lambda_{SSIM} L_{SSIM} + \lambda_{ds} L_{ds} $$ [S1].

### Parameters
*   **Loss Weights:** $\lambda_{ren} = 1.0$, $\lambda_{3D} = 1.0$, $\lambda_{pr} = 0.001$, $\lambda_{epi} = 0.0001$, $\lambda_{SSIM} = 0.008$, $\lambda_{ds} = 0.01$ [S1].
*   **Patch Size:** $32 \times 32$ pixels [S1].
*   **Samples:** 64 coarse samples, 64 importance samples (hierarchical sampling) [S1].
*   **Optimizer:** Adam with $\beta_1 = 0.9$, $\beta_2 = 0.999$, learning rate $1e-3$ [S1].

### Edge Cases and Pitfalls
*   **Epipolar Points:** A large number of epipolar points causes computational inefficiency. Occluded points may not have corresponding points on the epipolar line. Mitigation: Filter epipolar points using color similarity; only keep points where the color difference between the reference point and the epipolar point is below a threshold [S1].
*   **Local Minima:** Large pixel motions can cause the photometric consistency loss to get stuck in local minima. Mitigation: Use the pyramidal strategy, starting from low resolution and refining [S1].
*   **Masking:** Pixels outside the minimum bounding rectangle of matched SIFT features are excluded from photometric losses to avoid unreliable correspondences [S1].

## Operating characteristics
*   **Time Complexity:** Higher than standard NeRF due to additional loss computations (SIFT 3D coordinate estimation, epipolar geometry calculations, patch warping, and SSIM). The pyramidal strategy adds overhead but reduces the number of iterations needed for convergence at high resolutions [S1].
*   **Memory Complexity:** Requires storing depth maps for each pyramid level and intermediate 3D coordinates for SIFT features. The use of sub-pixel rendering increases the number of samples per pixel, slightly increasing memory usage during the forward pass [S1].
*   **Performance:** Evaluated on LLFF-NeRF, ScanNet, and DTU MVS datasets. It surpasses state-of-the-art approaches given sparse inputs (2, 5, and 8 input views) [S1].
*   **Strengths:** Explicitly constrains 3D geometry, reducing ambiguity in sparse scenes. Sub-pixel rendering improves generalization. Pyramidal strategy prevents local minima [S1].
*   **Limitations:** Computational inefficiency due to large number of epipolar points if not filtered. Relies on accurate SIFT matches and camera poses [S1].

## Background
SfMNeRF was proposed to address the failure of existing NeRF-based methods to obtain moderate 3D structures under sparse input conditions [S1]. It leverages knowledge from self-supervised depth estimation and Structure-from-Motion (SfM) to constrain the 3D-scene geometry during view synthesis training [S1]. The method was evaluated on LLFF-NeRF, ScanNet, and DTU MVS datasets [S1].
