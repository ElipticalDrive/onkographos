# AligNeRF

Also called: AligNeRF: High-Fidelity Neural Radiance Fields via Alignment-Aware Training

## Overview
AligNeRF is an alignment-aware training strategy for Neural Radiance Fields (NeRF) that addresses rendering artifacts caused by misalignment from moving objects or camera calibration errors, while improving high-frequency detail recovery in high-resolution settings [S1, S2]. It distinguishes itself from standard NeRF and its siblings by combining a convolution-augmented architecture with a staged training procedure that switches from random ray sampling to patch-based sampling, allowing the model to leverage 2D local neighborhood information and correct alignment inaccuracies [S1, S2].

## How it works
AligNeRF builds on [Specific Model Architectures](8585-specific-model-architectures.md) by modifying the baseline (specifically mip-NeRF 360) with a convolution-augmented architecture and an alignment-aware training procedure [S1].

### Inputs and Outputs
*   **Inputs:** 3D location $\mathbf{x} = (x, y, z)$, viewing direction $\mathbf{d} = (\theta, \phi)$, and ground truth image patches [S1].
*   **Outputs:** Rendered color $\mathbf{c} = (r, g, b)$ and volume density $\sigma$ [S1].

### Data Structures
*   **MLP:** A coordinate-to-value mapping function $F_\Theta: (\mathbf{x}, \mathbf{d}) \rightarrow (\mathbf{c}, \sigma)$ [S1].
*   **CNN:** A 3-layer convolutional network with ReLU activations and $3 \times 3$ kernels [S1].
*   **Perceptron:** A feed-forward layer converting feature space to RGB space [S1].
*   **Padding:** "Reflectance" padding is used for CNN inputs [S1].

### Numbered Steps

1.  **Pre-training (Normal Stage):** Train the baseline NeRF model using standard random ray sampling and RGB-space integration [S1].
2.  **Architecture Modification:**
    a. Switch from random ray sampling to patch-based sampling, gathering a local image region (e.g., $32 \times 32$ pixels) during each iteration [S1].
    b. Change the output channels of the MLP's last layer from 3 (RGB) to a larger number $N$ (feature space) [S1].
    c. Apply numerical integration along the ray in this feature space ($N$ channels) rather than in RGB space to gather richer representation [S1].
    d. Pass the rendered feature map through the 3-layer CNN ($3 \times 3$ kernels, ReLU) using reflectance padding [S1].
    e. Remove padding values in the CNN outputs to prevent checkerboard artifacts [S1].
    f. Pass the CNN output through a feed-forward perceptron to convert the representation from feature space to RGB space [S1].
3.  **Alignment-Aware Fine-tuning:**
    a. Sample a larger ground truth patch $G$ (e.g., $48 \times 48$ pixels) during each iteration [S1].
    b. Render a smaller patch $R$ (e.g., $32 \times 32$ pixels) [S1].
    c. Search over every possible subpatch $G_i$ of $G$ for the best match with $R$ [S1].
    d. Compute the loss using the alignment-aware metric defined below [S1].

### Formulas
The volume rendering equation remains:
$$ C(r) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i, \quad T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right), \quad \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
However, the integration is performed in the feature space of dimension $N$ [S1].

The alignment-aware loss function is:
$$ L_{PM}(G, R) = \min_{i=1,...,M} (D(G_i, R) + \lambda \cdot D_{coord}(G_i, R)) $$
where:
*   $G$ is the ground truth patch.
*   $R$ is the rendered patch.
*   $G_i$ is a subpatch of $G$.
*   $D(G_i, R) = \|G_i - R\|_2$ is the Euclidean distance between the subpatch and the rendered patch.
*   $D_{coord}(G_i, R) = \sqrt{\Delta x^2 + \Delta y^2}$ is the coordinate offset penalty, where $\Delta x$ and $\Delta y$ are the horizontal and vertical offsets between $G_i$ and $R$ [S1].
*   $\lambda$ is a regularization parameter, empirically set to 0.01 [S1].

### Parameters
*   **Patch size (rendered):** $32 \times 32$ pixels [S1].
*   **Patch size (ground truth):** $48 \times 48$ pixels [S1].
*   **Regularization $\lambda$:** 0.01 [S1].
*   **CNN Kernels:** $3 \times 3$ [S1].
*   **CNN Layers:** 3 layers with ReLU activations [S1].

### Edge Cases and Pitfalls
*   **Checkerboard Artifacts:** Prevented by using "reflectance" padding for CNN inputs and removing padding values in outputs [S1].
*   **Multiview Inconsistency:** Avoided because the CNN is shallow and does not perform upsampling [S1].
*   **Blurry Renderings:** The coordinate offset penalty $D_{coord}$ prevents the model from accepting blurry renderings that match multiple subpatches equally well [S1].

### Pseudocode

```python
def alignerf_training():
    # Stage 1: Normal Pre-training
    model = initialize_mlp()
    for epoch in range(pretrain_epochs):
        rays = sample_random_rays(batch_size)
        colors, densities = model(rays)
        loss = mse_loss(colors, ground_truth_pixels)
        optimize(model, loss)

    # Stage 2: Architecture Modification & Alignment-Aware Fine-tuning
    # Modify MLP output to N channels
    model.output_channels = N
    
    # Initialize CNN components
    cnn = ConvNet(layers=3, kernel_size=3, activation='relu')
    perceptron = FeedForwardPerceptron()
    
    for epoch in range(finetune_epochs):
        # Sample larger ground truth patch
        G = sample_ground_truth_patch(size=(48, 48))
        
        # Sample smaller rendered patch region
        R = render_patch(model, cnn, perceptron, patch_size=(32, 32))
        
        # Search for best matching subpatch in G
        best_loss = infinity
        best_offset = (0, 0)
        
        # Iterate over all possible subpatches Gi of G
        for i in range(number_of_subpatches):
            Gi = extract_subpatch(G, index=i)
            
            # Calculate Euclidean distance
            D_dist = l2_norm(Gi - R)
            
            # Calculate coordinate offset penalty
            dx, dy = get_offset(Gi, R)
            D_coord = sqrt(dx**2 + dy**2)
            
            # Combined loss
            current_loss = D_dist + 0.01 * D_coord
            
            if current_loss < best_loss:
                best_loss = current_loss
                best_offset = (dx, dy)
        
        # Backpropagate through the best match
        optimize(model, cnn, perceptron, best_loss)
```

## Operating characteristics
*   **Performance:** On outdoor datasets, AligNeRF achieves a PSNR more than 3 points higher than standard NeRF and better than the best mip-NeRF result [S2].
*   **Training Time:** Does not significantly increase training time compared to the baseline [S2].
*   **Strengths:** Improves high-frequency detail recovery and handles misalignment from moving objects or calibration errors [S1, S2].
*   **Limitations:** Requires patch-based sampling and additional CNN processing, increasing implementation complexity compared to standard NeRF [S1].

## Background
AligNeRF was introduced by Yifan Jiang, Peter Hedman, Ben Mildenhall, Dejia Xu, Jonathan T. Barron, Zhangyang Wang, and Tianfan Xue in 2022 [S1]. It addresses the limitations of training NeRF on high-resolution images, specifically the degradation caused by moving objects and the inability of standard MLPs to capture local neighborhood information [S2]. The method is designed as an easy-to-plug-in component for any NeRF-like models, including point-sampling and frustum-based approaches [S1].
