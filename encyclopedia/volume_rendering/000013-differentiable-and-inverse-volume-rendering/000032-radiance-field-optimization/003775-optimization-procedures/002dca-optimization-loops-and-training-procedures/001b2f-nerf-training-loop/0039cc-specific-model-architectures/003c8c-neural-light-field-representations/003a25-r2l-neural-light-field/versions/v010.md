# R2L (Neural Light Field)

Also called: Neural Light Field, R2L network

## Overview
R2L is a deep neural light field network trained via distillation from a pre-trained NeRF teacher to achieve efficient novel view synthesis with significantly reduced FLOPs [S1]. It differs from baseline NeRF by using a much deeper network with extensive internal residual blocks instead of standard skip connections, trading width for depth under the same FLOPs budget to consistently gain performance [S1]. It outperforms methods like DONeRF on reflection surfaces because it does not rely on ground-truth depth, which fails on reflective geometry [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 5D ray parameter $(x, y, \theta, \phi)$, where $(x, y)$ is the pixel coordinate and $(\theta, \phi)$ is the viewing direction [S1].
*   **Output:** Volume density $\sigma$ and view-dependent color $c$ [S1].

**Data Structures:**
The network architecture is defined by width $W$ and depth $D$. The sources specify two configurations:
1.  $W256D88$: Width 256, Depth 88 [S1].
2.  $W181D88$: Width 181, Depth 88 [S1].
The network consists of linear layers with extensive residual blocks in the internal layers [S1].

**Training Procedure:**
1.  **Teacher Initialization:** A pre-trained NeRF teacher model is required. The teacher is trained with a batch size of 1,024 and an initial learning rate of $5 \times 10^{-4}$ (decayed during training) for 200k iterations [S1].
2.  **Pseudo Data Generation:** Generate pseudo training data by sampling rays from the pre-trained NeRF teacher model to inflate the dataset. The default pseudo sample size $S$ is 10k images, though performance saturates around 5k images [S1].
3.  **Network Initialization:** Initialize the R2L network with the specified width and depth (e.g., W256D88) [S1].
4.  **Hard-Example Selection:** In each training batch, select a fraction $r$ of rays with small PSNR (hard examples) to focus optimization on fine-grained details. The default ratio is $r=0.2$ [S1].
5.  **Optimization:** Train the network for 1,000k iterations using the Adam optimizer with the same learning rate schedule as the teacher NeRF [S1]. The batch size is 98,304 rays per batch, sampled randomly from different images so they do not share the same origin [S1].

**Parameters:**
*   **Batch size:** 98,304 rays per batch [S1].
*   **Hard example ratio ($r$):** Fraction of hard examples per batch. Default 0.2. Tested values $\{0, 0.1, 0.2, 0.3\}$ [S1].
*   **Pseudo sample size ($S$):** Number of pseudo images used for training. Default 10k. Performance saturates around 5k images [S1].
*   **Hardware:** 8 NVIDIA V100 GPUs [S1].
*   **Framework:** PyTorch 1.9 [S1].

**Edge Cases and Pitfalls:**
*   **Overfitting:** Without sufficient pseudo data, the deep network overfits to the small number of original captured images (e.g., 0.1k images). Test PSNR saturates early while train PSNR rises sharply [S1].
*   **Trainability:** Without extensive residual blocks in the internal layers, the network is barely trainable [S1].
*   **Reflection Surfaces:** Methods relying on ground-truth depth (like DONeRF) fail on reflective surfaces (e.g., water, mirrors) because ground-truth depth does not apply to reflections. R2L handles these well as it does not rely on depth [S1].

## Operating characteristics
*   **Time and Memory Complexity:** The method achieves a 26–35× FLOPs reduction compared to NeRF [S1]. Storage footprint is 23.7 MB for the R2L network (W256D88) compared to 2.4 MB for the teacher NeRF [S1].
*   **Measured Performance:**
    *   On NeRF synthetic dataset: Ours-2 (Pseudo+real) achieves 31.87 PSNR (+1.40 over teacher), 0.9950 SSIM, 0.0340 LPIPS [S1].
    *   On DONeRF synthetic dataset: Ours-2 achieves 35.45 PSNR (+2.78 over teacher), 0.047 FLIP [S1].
*   **Speed:** Wall-time speedup is 28–31× faster than NeRF and 2× faster than DONeRF-16-noGT across GeForce 2080Ti, Tesla V100, and CPU benchmarks [S1].
*   **Strengths:** Significantly faster rendering than NeRF; better handling of reflection surfaces than depth-based methods; improved rendering quality over teacher NeRF when real data is included.
*   **Limitations:** Requires a pre-trained NeRF teacher; blurry parts of NeRF results may appear in R2L results since it learns from NeRF-generated data [S1].

## Background
R2L (R2L: Distilling Neural Radiance Field to Neural Light Field for Efficient Novel View Synthesis) was presented by H. Wang et al. in 2022 [S1]. It is the first deep neural light field network capable of representing complex synthetic and real-world scenes. The key innovation is the use of a much deeper network with extensive residual blocks, trained with abundant pseudo data generated from a NeRF teacher, to overcome the overfitting issues of deep networks on small datasets [S1].
