# Specific Model Architectures

Also called: SfMNeRF, DASNeRF, SinNeRF, NeRF in the Wild

## Overview
Specific Model Architectures refers to modifications of the standard Neural Radiance Field (NeRF) MLP and training pipeline to address specific limitations such as sparse input views, dynamic scenes, or complex lighting. Unlike the generic NeRF Training Loop [970-nerf-training-loop.md] which assumes a dense set of calibrated images, these architectures integrate external priors (e.g., monocular depth, SfM features) or structural changes (e.g., appearance embeddings) to improve geometry reconstruction and novel view synthesis under challenging conditions. They set themselves apart from sibling methods like [Mip-NeRF 360](3306-mip-nerf-360.md) (which focuses on angular resolution and sampling) by explicitly altering the model's internal representation or loss landscape to encode geometric or semantic constraints.

## How it works
The core NeRF model maps 5D coordinates $(x, y, z, \theta, \phi)$ to volume density $\sigma$ and color $c$ via an MLP [S2]. Specific architectures modify this mapping, the sampling strategy, or the optimization objective.

### Inputs and Outputs
*   **Inputs:** Camera poses $[R, t]$, intrinsic matrix $K$, input images $I$, and optionally external priors (depth maps $D_{prior}$, SIFT features, or temporal indices).
*   **Outputs:** Rendered color $\hat{C}(r)$ and depth $D(r)$ for query rays $r$.

### Data Structures
1.  **NeRF MLP:** A multi-layer perceptron. In standard NeRF, input is position encoding $\gamma(x)$ and direction $\gamma(d)$. In modified architectures (e.g., DASNeRF), the input may be fused with additional 5D vectors or embeddings [S2].
2.  **Depth Prior Map:** A 2D array of depth values estimated by a separate network (e.g., DepthAnythingV2) [S2].
3.  **SIFT Features:** A list of 2D keypoints and their descriptors, used to establish 3D correspondences [S1].
4.  **Pyramid Levels:** For pyramidal training, a hierarchy of downsampled images $I^0 \dots I^{L-1}$ [S1].

### Numbered Steps

1.  **Initialization and Prior Extraction:**
    *   If using depth priors (DASNeRF), run a monocular depth estimation network (e.g., DepthAnythingV2) on input images to obtain $D_{V2}$ [S2].
    *   If using SfM constraints (SfMNeRF), extract SIFT features from input images and match them across views to identify corresponding points [S1].

2.  **Ray Sampling:**
    *   For each pixel, generate a ray $r(t) = o + td$ bounded by $[t_n, t_f]$ [S2].
    *   Sample $N$ points along the ray. Standard NeRF uses uniform or hierarchical sampling. DASNeRF employs a three-layer dynamic sampling mechanism and 3D cone frustum sampling to obtain five-dimensional information (coordinates and ray info) [S2].
    *   For sub-pixel rendering (SfMNeRF), generate sub-pixel coordinates $p = (x + x_{off}, y + y_{off})$ where offsets are in $(0, 1)$ [S1].

3.  **Neural Evaluation:**
    *   Encode positions and directions using positional encoding $\gamma$ [S2].
    *   In DASNeRF, fuse the processed five-dimensional input information with features from the previous MLP layer at each layer [S2].
    *   In "NeRF in the Wild", append an Appearance embedding $e_a$ and Transient embedding $e_t$ to the input or intermediate features to model lighting changes and moving objects [S4, unofficial].
    *   Output density $\sigma$ and color $c$ from the final layer [S2].

4.  **Volume Rendering:**
    *   Compute transmittance $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$ and opacity $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ [S2].
    *   Render color: $\hat{C}(r) = \sum_{i=1}^{N} \omega_i c_i$, where $\omega_i = T_i \alpha_i$ [S2].
    *   Render depth: $d_r = \sum_{i=1}^{N} \omega_i t_i$ [S2].

5.  **Loss Calculation and Optimization:**
    *   Calculate the primary rendering loss $L_{nerf}$ (MSE between rendered and ground truth colors) [S2].
    *   Calculate specific architectural losses (see Formulas below).
    *   Update MLP weights using an optimizer (e.g., Adam) [S1].

### Formulas

**Standard NeRF Rendering [S2]:**
$$ \hat{C}(r) = \sum_{i=1}^{N} \omega_i c_i, \quad \omega_i = T_i \alpha_i $$
$$ T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right), \quad \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
$$ L_{nerf} = \sum_{r \in R} \| C(r) - \hat{C}(r) \|_2^2 $$

**SfMNeRF Constraints [S1]:**
*   **Sub-pixel Ground Truth:** $\hat{I}(p) = \sum_{i \in \{top, bottom\}, j \in \{left, right\}} w^{ij} I(p^{ij})$
*   **Rendering Loss:** $L_{ren} = \frac{1}{m} \sum_{p_i \in \Omega_p} \| \hat{I}(p_i) - \tilde{I}(p_i) \|_2^2$
*   **3D Feature Position Loss:** $\mathbf{x}_s = \sum_{j=1}^{N_c} w_j (\mathbf{o} + t_j \mathbf{d})$, where $w_j = T_j (1 - \exp(-\sigma_j \delta_j))$.
    $$ L_{3D} = \frac{1}{n} \sum_{k=1}^n \| \mathbf{x}_s^k - \mathbf{x}_{s'}^k \|_2^2 $$
*   **Epipolar Loss:** $L_{epi} = \min_t \{ \| d_{p_r} - d_{p_t} \|_2^2 \}$
*   **Photometric Consistency:**
    $$ \hat{p}_t = K T_{r->t} \mathbf{x}_p, \quad T_{r->t} = [\mathbf{r}, \mathbf{t}] $$
    $$ L_{pr} = \sum_{p(k) \in \Omega_p} M(p(k)) | \hat{I}_r(p(k)) - \hat{I}_t(\hat{p}_t(k)) | $$
    $$ L_{SSIM} = M \left( \frac{1 - SSIM_{r->t}}{2} \right) $$
*   **Depth Smoothness:** $L_{ds} = \sum_{p(k) \in \Omega_p} | \nabla D(p(k)) \cdot (e^{-|\hat{I}(p(k))|}) |$
*   **Total Loss:** $L_{total} = \lambda_{ren} L_{ren} + \lambda_{3D} L_{3D} + \lambda_{pr} L_{pr} + \lambda_{epi} L_{epi} + \lambda_{SSIM} L_{SSIM} + \lambda_{ds} L_{ds}$

**DASNeRF Constraints [S2]:**
*   **Depth Ordering Fidelity (DOF):**
    $$ L_{DOF} = \sum_{d_{V2}^{k1} \leq d_{V2}^{k2}} \max(d_r^{k1} - d_r^{k2} + m_{ar}, 0) $$
*   **Dynamic Boundary Adjustment:**
    $$ m_{ar} = \alpha \cdot \frac{1}{N} \sum_{i=1}^{N} | d_r^{k1}[i] - d_r^{k2}[i] | $$
*   **Depth Structural Consistency (DSC):**
    $$ R_{DSC} = \sum_{k1} \sum_{d_{V2}^{k2} \in KNN(d_{V2}^{k2})} \max(| d_r^{k1} - d_r^{k2} | - m_{ar}', 0) $$
*   **Total Loss:** $L = L_{nerf} + \lambda L_{DOF} + \gamma R_{DSC}$

**Pyramidal Strategy (SfMNeRF) [S1]:**
*   **Depth Prior Loss:** $L_{depth} = \sum_{p(k) \in \Omega_p} | D(p(k)) - D_r^{L-1}(p(k)/2) |$

### Parameters
*   **SfMNeRF Loss Weights [S1]:** $\lambda_{ren} = 1.0$, $\lambda_{3D} = 1.0$, $\lambda_{pr} = 0.001$, $\lambda_{epi} = 0.0001$, $\lambda_{SSIM} = 0.008$, $\lambda_{ds} = 0.01$.
*   **DASNeRF Loss Weights [S2]:** $\lambda = 0.2$ (for DOF), $\gamma = 0.02$ (for DSC).
*   **DASNeRF Hyperparameters [S2]:** $\alpha$ controls the magnitude of the margin in dynamic boundary adjustment.
*   **SfMNeRF Patch Size [S1]:** $32 \times 32$.
*   **Sampling:** Both methods use hierarchical sampling with 64 coarse and 64 fine samples [S1].

### Edge Cases and Pitfalls
*   **Epipolar Points:** A large number of epipolar points causes computational inefficiency. Occluded points may not have corresponding points on the epipolar line. SfMNeRF filters implausible points using color similarity thresholds [S1].
*   **Depth Ambiguity:** Standard NeRF suffers from shape-radiance ambiguity. Sparse inputs exacerbate this. Depth priors help but may introduce noise if the depth estimator fails on transparent/reflective surfaces [S2].
*   **Complex Interlacing:** Methods relying on geometric priors may fail to distinguish separation when entities and artifacts are complexly interlaced [S3].

## Subtopics

### [AdaNeRF](6195-adanerf.md)
AdaNeRF accelerates NeRF for real-time rendering by reducing sample points per ray. It splits the network into a lightweight Sampling Network and a heavier Shading Network. The Sampling Network predicts sample importance weights in a single evaluation, allowing for fixed sample positions and incremental sparsity introduction during training. It is chosen when rendering speed is critical and some quality trade-off is acceptable. Link: [AdaNeRF](6195-adanerf.md).

### SinNeRF
SinNeRF uses depth maps to constrain unobserved views via Adversarial loss and Perceptual loss [S4, unofficial]. It is designed to handle scenarios where depth information is available but views are sparse or missing, leveraging generative priors to fill in unseen geometry. Link: Not given in the sources.

### NeRF in the Wild
NeRF in the Wild modifies the standard architecture to handle real-world conditions. It adds an Appearance embedding to express different lighting conditions and a Transient embedding to model changing geometry (e.g., moving people, vehicles) [S4, unofficial]. It is chosen when training data contains varying illumination or dynamic elements that violate the static scene assumption. Link: Not given in the sources.

## Operating characteristics
*   **Time Complexity:** SfMNeRF and DASNeRF add overhead for prior extraction (SIFT matching, depth estimation) and additional loss computations (epipolar, DOF). SfMNeRF's pyramidal strategy increases training time due to multi-level optimization [S1]. DASNeRF's dynamic sampling adds minor overhead [S2].
*   **Memory Complexity:** Similar to standard NeRF, dominated by the MLP weights. SfMNeRF requires storing SIFT features and pyramid levels. DASNeRF requires storing depth priors [S1, S2].
*   **Performance:** Evaluated on LLFF-NeRF, ScanNet, and DTU MVS datasets. SfMNeRF surpasses state-of-the-art approaches given sparse inputs [S1]. DASNeRF improves sparse reconstruction details and is 10 times faster in depth inference than MiDaS-based alternatives [S2].
*   **Strengths:** Improved geometry accuracy with sparse views; robustness to lighting/dynamics (NeRF in the Wild); real-time capability (AdaNeRF).
*   **Limitations:** Dependence on external priors (depth/SfM) which may be inaccurate; increased training complexity; potential for artifacts if priors conflict with photometric data.

## Background
NeRF was introduced by Mildenhall et al. in 2020 [1]. Subsequent works addressed its limitations. SfMNeRF was proposed to improve novel view synthesis under sparse input conditions by integrating depth prediction and SfM constraints [S1]. DASNeRF was developed to enhance sparse reconstruction using DepthAnythingV2 and dynamic sampling [S2]. AdaNeRF targets real-time rendering [S1]. NeRF in the Wild and SinNeRF address dynamic scenes and unobserved views respectively [S4, unofficial]. These methods represent the evolution of NeRF from a dense-view, static assumption to robust, sparse-view, and dynamic-aware representations.
