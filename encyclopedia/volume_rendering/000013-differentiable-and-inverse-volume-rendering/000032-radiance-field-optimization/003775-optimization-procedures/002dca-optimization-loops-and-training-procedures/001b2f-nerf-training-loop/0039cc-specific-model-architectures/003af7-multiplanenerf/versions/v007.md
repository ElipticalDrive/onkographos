# MultiPlaneNeRF

Also called: MultiPlaneNeRF

## Overview
MultiPlaneNeRF is a radiance field optimization method that replaces the trainable, object-specific neural network weights of vanilla NeRF with a non-trainable 2D image-based representation [S1]. It solves the problems of long training times and poor generalization to unseen data by projecting 3D points onto a fixed set of 2D training images to create an aggregate feature vector, which is then processed by a small, shared implicit decoder [S1]. Unlike vanilla NeRF, which encodes shape and color in network weights requiring separate training per object, MultiPlaneNeRF allows a single decoder to generalize across many objects by simply swapping the input 2D images [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $n$ 2D training images $\{I_1, \dots, I_n\}$ with known camera poses (intrinsics and extrinsics) for a specific 3D object. A query ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ defined by origin $\mathbf{o}$ and direction $\mathbf{d}$.
*   **Output:** Volume density $\sigma$ and color $\mathbf{c}$ for each sample point along the ray, used to compute the final pixel color via standard volume rendering.

**Data Structures:**
*   **2D Representation:** A collection of $n$ images $I_j \in \mathbb{R}^{H \times W \times C}$ (typically $C=3$ for RGB, or more if depth/normal maps are included, though the source specifies RGB) [S1]. The source notes the aggregate vector dimension is $R^{5k}$ where $k$ relates to the number of images or channels [S1]. Given $n$ images and 3 channels, if $k=n$, the dimension is $3n$. The source specifies $R^{5k}$, implying either 5 channels per image (e.g., RGB + depth + mask) or a specific projection aggregation logic resulting in 5 features per image view [S1]. We assume the standard case of RGB images where the "5k" might refer to a specific implementation detail or a typo in the source for $3k$ or $5$ features per view including positional encoding. However, strictly following the source: the aggregate vector $Z(\mathbf{x}) \in \mathbb{R}^{5k}$ [S1].
*   **Implicit Decoder:** A small Multi-Layer Perceptron (MLP) $f_\theta$. The weights $\theta$ are shared across all objects and trained on a large dataset [S1].

**Steps:**
1.  **Dataset Splitting:** Split the initial set of $n$ 2D training images for a target object into two subsets:
    *   $S_{rep}$: Images used to build the 2D representation (input to the decoder).
    *   $S_{train}$: Images used as the training set to calculate the weights $\theta$ of the decoder [S1].
    *   *Note:* The source states the first subset builds the representation and the second is used for training. In practice, this implies the decoder is trained on a large diverse dataset (e.g., ShapeNet) using images from many objects, while $S_{rep}$ is specific to the inference-time object [S1].
2.  **Projection (Feature Aggregation):** For a 3D point $\mathbf{x} = (x, y, z)$, project it onto each image $I_j \in S_{rep}$ using the known camera parameters of image $j$.
    *   Let $p_j(\mathbf{x})$ be the 2D pixel coordinates in image $I_j$.
    *   Sample the color (and potentially other channels) from $I_j$ at $p_j(\mathbf{x})$. Let this be $\mathbf{v}_j(\mathbf{x})$.
    *   Aggregate these vectors from all $k$ images in $S_{rep}$ to form the input vector $Z(\mathbf{x}) \in \mathbb{R}^{5k}$ [S1]. The aggregation method is not explicitly detailed beyond "aggregate information," but typically involves concatenation or averaging of the projected pixel values [S1].
3.  **Decoding:** Pass $Z(\mathbf{x})$ through the small implicit decoder $f_\theta$:
    $$
    \sigma, \mathbf{c} = f_\theta(Z(\mathbf{x}))
    $$
    where $\sigma$ is the volume density and $\mathbf{c}$ is the color [S1].
4.  **Rendering:** Compute the pixel color $\mathbf{C}(\mathbf{r})$ using the standard volume rendering integral:
    $$
    \mathbf{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i
    $$
    where $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ and $T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)$ [S1, Parent].

**Pseudocode:**
```python
def multi_plane_nerf_render(ray_origin, ray_direction, images, camera_poses, decoder):
    """
    ray_origin: (3,)
    ray_direction: (3,)
    images: List of n images, each (H, W, C)
    camera_poses: List of n camera pose matrices (4, 4)
    decoder: Small MLP function f_theta
    """
    # 1. Sample points along the ray
    # Standard NeRF sampling strategy (e.g., uniform or stratified)
    t_vals = sample_t_vals(ray_origin, ray_direction, num_samples=N)
    points_3d = ray_origin + t_vals[:, None] * ray_direction[None, :] # (N, 3)
    
    # 2. Project 3D points to 2D images and aggregate features
    # Z shape: (N, 5*k) where k is number of images
    Z = []
    for i, (img, pose) in enumerate(zip(images, camera_poses)):
        # Project 3D points to 2D pixel coordinates
        # Assuming standard pinhole camera model
        points_2d = project_to_image(points_3d, pose) # (N, 2)
        
        # Sample image values at projected coordinates
        # Bilinear interpolation
        pixel_values = sample_image(img, points_2d) # (N, C)
        
        # The source specifies dimension R^{5k}. 
        # If C=3, we might need padding or additional features (e.g., depth, mask).
        # Assuming the source implies 5 channels per view or a specific expansion.
        # We pad or expand to match the expected decoder input dimension.
        # If the source strictly means 5 features per image:
        expanded_pixel = expand_to_5_channels(pixel_values) # (N, 5)
        Z.append(expanded_pixel)
        
    # Concatenate features from all k images
    Z = torch.cat(Z, dim=1) # (N, 5*k)
    
    # 3. Decode density and color
    sigma, color = decoder(Z) # (N,), (N, 3)
    
    # 4. Volume Rendering
    # Compute alphas and transmittance
    deltas = t_vals[1:] - t_vals[:-1]
    # Add epsilon to avoid division by zero or log(0)
    deltas = torch.cat([deltas, torch.tensor([1e10])]) 
    
    alpha = 1.0 - torch.exp(-sigma * deltas)
    T = torch.cumprod(torch.exp(-alpha), dim=0)
    T = torch.cat([torch.tensor([1.0]), T[:-1]])
    
    weights = alpha * T
    final_color = torch.sum(weights[:, None] * color, dim=0)
    
    return final_color
```

**Parameters:**
*   **Number of images ($n$):** The source uses 50 images per object in generalization experiments [S1].
*   **Image Resolution:** 200x200 pixels [S1].
*   **Decoder Size:** "Small implicit decoder" or "very shallow decoder" [S1]. Exact layer sizes are not given in the sources.
*   **Aggregate Vector Dimension:** $R^{5k}$ [S1].

**Edge Cases and Pitfalls:**
*   **Generalization vs. Quality:** Training on a large dataset results in slightly worse rendering quality compared to training each object separately (vanilla NeRF) [S1].
*   **Projection Accuracy:** The projection step is non-parametric and relies on accurate camera poses. Incorrect poses will lead to misaligned features [S1].
*   **Occlusion:** The method projects 3D points to 2D images. If a point is occluded in a specific view, the sampled pixel value may be incorrect. The source does not explicitly detail occlusion handling, but standard NeRF volume rendering handles occlusion along the ray; the 2D projection serves only as a feature prior [S1].

## Operating characteristics
*   **Time Complexity:** Training time is significantly reduced compared to vanilla NeRF because the decoder is small and shared, and the representation is non-trainable (pre-computed from images) [S1]. Inference time is also reduced due to the shallow decoder [S1].
*   **Memory Complexity:** Lower memory usage than vanilla NeRF as the network weights are small and shared. The 2D images are stored in memory, but they are non-trainable [S1].
*   **Strengths:** Generalizes to unseen objects by changing the input 2D images without retraining the decoder [S1]. Fewer parameters than vanilla NeRF or voxel-based methods [S1].
*   **Limitations:** Slightly worse rendering quality than object-specific training [S1]. Requires a set of 2D images with known poses for each object [S1].

## Background
MultiPlaneNeRF was proposed to address the limitations of vanilla NeRF, specifically long training times and poor generalization [S1]. It builds on the idea of using non-trainable representations (existing images) to encode 3D structure, similar to voxel-based methods but using 2D images [S1]. The method was demonstrated to achieve results comparable to state-of-the-art models for synthesizing new views and generalizing to unseen objects [S1]. It can also be used as a component in generative models like GANs (MultiPlaneGAN) [S1].
