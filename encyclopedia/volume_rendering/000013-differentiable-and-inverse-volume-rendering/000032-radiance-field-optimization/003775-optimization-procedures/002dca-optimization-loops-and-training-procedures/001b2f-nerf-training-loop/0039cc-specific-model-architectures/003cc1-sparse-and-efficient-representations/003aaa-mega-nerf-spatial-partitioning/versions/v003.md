# Mega-NeRF Spatial Partitioning

Also called: Cell-based NeRF, Spatial Data Parallelism

## Overview
Mega-NeRF Spatial Partitioning addresses the memory and training time bottlenecks of training large-scale Neural Radiance Fields by decomposing a scene into spatial cells, each managed by a separate MLP submodule trained in parallel [S1]. Unlike monolithic NeRF implementations, it assigns query points to the nearest centroid and prunes irrelevant training data based on visibility, reducing per-submodule dataset sizes by up to 20x [S1].

## How it works
**Inputs:** A set of calibrated training images with poses; scene bounds.
**Outputs:** A set of MLP submodules $\{f^n\}$, one per spatial cell $n \in \mathcal{N}$, and appearance embeddings $\{l^{(a)}\}$ for each image $a$.

**Data Structures:**
*   **Centroids ($\mathcal{N}$):** A set of 3D points $\mathbf{n} = (n_x, n_y, n_z)$. In the standard implementation, these are arranged in a top-down 2D grid with a fixed height $z$ for all centroids [S1].
*   **Submodules ($f^n$):** Each $f^n$ is a Multi-Layer Perceptron (MLP) with fully connected layers, structurally similar to the original NeRF network [S1].
*   **Appearance Embeddings ($l^{(a)}$):** A learnable vector associated with each input image $a$ to handle lighting variations [S1].
*   **Trainsets ($D^n$):** For each cell $n$, a subset of training pixels/rays.

**Parameters:**
*   **Overlap Factor:** 15% [S1]. Used to minimize visual artifacts at cell boundaries.
*   **Centroid Height:** Fixed to a single value, assuming small altitude variance relative to horizontal spread [S1].

**Algorithm Steps:**

1.  **Centroid Initialization:** Tessellate the scene into a top-down 2D grid. Set the $z$-coordinate for all centroids to a fixed value. Initialize the weights for each submodule $f^n$ and the appearance embeddings $l^{(a)}$ [S1].

2.  **Initial Data Assignment (Visibility Partitioning):**
    For each training image $a$:
    a. Sample points along the camera rays corresponding to each pixel.
    b. Identify which spatial cells $n \in \mathcal{N}$ these rays intersect.
    c. Add the pixel to the trainset $D^n$ only for the intersecting cells.
    d. Apply the overlap factor to include neighboring cells if the ray passes near a boundary [S1].

3.  **Coarse Training:** Train all submodules $f^n$ and embeddings $l^{(a)}$ in parallel using their respective trainsets $D^n$ and the volume rendering equation [S1].

4.  **Spatial Data Pruning:**
    After coarse training, use the inferred geometry to prune $D^n$:
    a. For each cell $n$, identify pixels in other cells' trainsets that are occluded by geometry rendered by $f^n$ (e.g., a wall in cell $F$ occludes pixels assigned to cells $A$ and $B$) [S1].
    b. Remove these occluded pixels from the trainsets of the occluded cells. This reduces trainset sizes by an additional factor of 2x [S1].

5.  **Fine Training:** Continue training the pruned submodules in parallel until convergence [S1].

**Querying:**
Given a query position $\mathbf{x}$, direction $\mathbf{d}$, and image index $a$:
1. Find the nearest centroid: $\mathbf{n} = \arg\min_{n \in \mathcal{N}} \|\mathbf{n} - \mathbf{x}\|^2$ [S1].
2. Compute opacity: $\sigma = f^\mathbf{n}(\mathbf{x})$ [S1].
3. Compute color: $\mathbf{c} = f^\mathbf{n}(\mathbf{x}, \mathbf{d}, l^{(a)})$ [S1].

```python
import numpy as np

def mega_nerf_spatial_partitioning(training_images, scene_bounds):
    """
    training_images: List of dicts with keys 'pose', 'image', 'id'
    scene_bounds: Bounding box of the scene
    Returns: List of MLP submodules, appearance embeddings
    """
    # 1. Centroid Initialization
    # Tessellate scene into 2D grid, fix height
    centroids = create_2d_grid(scene_bounds, fixed_z=True)
    num_cells = len(centroids)
    
    # Initialize submodules (MLPs) and appearance embeddings
    submodules = [init_mlp() for _ in range(num_cells)]
    appearance_embeddings = [init_embedding() for _ in range(len(training_images))]
    
    # 2. Initial Data Assignment
    trainsets = [set() for _ in range(num_cells)]
    
    for img in training_images:
        img_id = img['id']
        # Sample rays for this image
        rays = sample_rays(img['pose'], img['image'].shape)
        
        for ray in rays:
            # Find intersecting cells
            intersecting_cells = find_intersecting_cells(ray, centroids, overlap_factor=0.15)
            
            for cell_idx in intersecting_cells:
                # Add pixel data to the cell's trainset
                trainsets[cell_idx].add((img_id, ray))
                
    # 3. Coarse Training
    # Train all submodules in parallel
    for epoch in range(coarse_epochs):
        for cell_idx in range(num_cells):
            if not trainsets[cell_idx]:
                continue
            # Sample batch from trainsets[cell_idx]
            batch = sample_batch(trainsets[cell_idx])
            # Forward pass through submodule[cell_idx]
            # Loss computation using volume rendering
            # Backpropagate to submodule[cell_idx] and appearance_embeddings
            train_step(submodules[cell_idx], appearance_embeddings, batch)
            
    # 4. Spatial Data Pruning
    # Use coarse model to infer geometry and prune occluded rays
    for cell_idx in range(num_cells):
        # Render depth/opacity map for this cell's region
        depth_map = render_depth(submodules[cell_idx], centroids[cell_idx])
        
        # Identify rays in OTHER cells that are occluded by this cell's geometry
        occluded_rays = find_occluded_rays(depth_map, trainsets, cell_idx)
        
        # Remove occluded rays from other cells' trainsets
        for other_cell_idx, ray in occluded_rays:
            if (other_cell_idx, ray) in trainsets[other_cell_idx]:
                trainsets[other_cell_idx].remove((other_cell_idx, ray))
                
    # 5. Fine Training
    for epoch in range(fine_epochs):
        for cell_idx in range(num_cells):
            if not trainsets[cell_idx]:
                continue
            batch = sample_batch(trainsets[cell_idx])
            train_step(submodules[cell_idx], appearance_embeddings, batch)
            
    return submodules, appearance_embeddings

def query_mega_nerf(submodules, centroids, appearance_embeddings, x, d, img_id):
    """
    Query the nearest submodule for opacity and color.
    """
    # Find nearest centroid
    distances = [np.linalg.norm(n - x) for n in centroids]
    nearest_idx = np.argmin(distances)
    
    # Get appearance embedding
    l_a = appearance_embeddings[img_id]
    
    # Query submodule
    sigma = submodules[nearest_idx].forward(x)
    c = submodules[nearest_idx].forward(x, d, l_a)
    
    return sigma, c
```

## Operating characteristics
*   **Memory:** Scales linearly with the number of cells, as each cell stores its own MLP weights. This allows training scenes that exceed the memory capacity of a single GPU [S1].
*   **Training Time:** Parallel training of submodules reduces wall-clock time. Visibility partitioning reduces the dataset size per submodule by 10x initially, and further by 2x after pruning, significantly speeding up each epoch [S1].
*   **Scalability:** Effective for large-scale scenes (e.g., city blocks) where a single NeRF would be intractable [S1].
*   **Limitations:** Requires careful handling of boundaries to avoid artifacts; the fixed-height centroid assumption may not work for scenes with significant vertical variation (e.g., multi-story buildings with large height differences) [S1].

## Background
Mega-NeRF was introduced in 2022 by [S1] to enable the construction of large-scale NeRFs for virtual fly-throughs. It builds on the principles of NeRF [S1] and NeRF in the Wild [S1], extending them with spatial data parallelism. The method was developed to address the computational limits of training NeRFs on scenes covering large geographic areas [S1].
