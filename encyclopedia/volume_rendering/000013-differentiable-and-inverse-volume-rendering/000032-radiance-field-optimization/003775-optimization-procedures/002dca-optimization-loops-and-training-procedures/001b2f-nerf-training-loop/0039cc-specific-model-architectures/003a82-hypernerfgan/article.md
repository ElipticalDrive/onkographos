# HyperNeRFGAN

Also called: HyperNeRFGAN: Hypernetwork approach to 3D NeRF GAN

## Overview
HyperNeRFGAN is a generative adversarial network (GAN) that uses a hypernetwork to produce the weights of a simplified NeRF target network, enabling 3D-aware image generation without requiring camera position information during training [S1, unofficial]. It differs from standard NeRF by omitting viewing directions from the input and from other 3D-aware GANs (like GRAF or $\pi$-GAN) by using a hypernetwork to generate weights directly rather than conditioning a SIREN-based network [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A noise vector $\mathbf{z}$ sampled from a standard Gaussian distribution $P_{noise}$ [S1, unofficial].
*   **Output:** A rendered 2D image $\mathbf{x}$ generated by ray-marching the instantiated NeRF [S1, unofficial].

**Data Structures:**
1.  **Generator $G$:** A StyleGAN2-based architecture that maps $\mathbf{z}$ to the weights $\theta$ of the target NeRF [S1, unofficial].
2.  **Target NeRF $F_\theta$:** A single Multi-Layer Perceptron (MLP) that maps 3D spatial position $\mathbf{x} = (x, y, z)$ to color $\mathbf{c}$ and volume density $\sigma$ [S1, unofficial].
    *   **Architecture:** Uses Factorized Multiplicative Modulation (FMM) layers [S1, unofficial].
    *   **Dimensions:** Hidden layer channels are reduced to 128 (standard is 256) [S1, unofficial]. Depth is typically 4 layers (standard is 8) [S1, unofficial].
    *   **Input:** Only spatial coordinates $\mathbf{x}$; no viewing direction $\mathbf{d}$ [S1, unofficial].
    *   **Output:** Color $\mathbf{c}$ and density $\sigma$ [S1, unofficial].
3.  **Discriminator $D$:** A standard 2D discriminator that evaluates rendered images [S1, unofficial].

**Parameters:**
*   **Rank $k$:** Controls the rank of the modulation matrices in FMM layers. Default value is $k=10$ [S1, unofficial].
*   **Network Size:** Hidden channels = 128; Layers = 4 (or 8 in some experiments) [S1, unofficial].

**Algorithm:**
The model is trained using the standard GAN minimax objective [S1, unofficial].

1.  Sample a noise vector $\mathbf{z} \sim P_{noise}$ [S1, unofficial].
2.  Generate NeRF weights $\theta = G(\mathbf{z})$ [S1, unofficial].
3.  Instantiate the target NeRF $F_\theta$ using $\theta$ [S1, unofficial].
4.  Render a 2D image $\mathbf{x}_{gen}$ by ray-marching through $F_\theta$ from a random camera perspective [S1, unofficial].
5.  Sample a real image $\mathbf{x}_{real} \sim P_{data}$ [S1, unofficial].
6.  Update Discriminator $D$ and Generator $G$ by minimizing the loss function:
    $$ \min_G \max_D V(D, G) $$
    $$ V(D, G) = \mathbb{E}_{\mathbf{x} \sim P_{data}}[\log D(\mathbf{x})] + \mathbb{E}_{\mathbf{z} \sim P_{noise}}[\log(1 - D(G(\mathbf{z})))] $$
    [S1, unofficial]

**FMM Layer Implementation:**
The core building block of the target NeRF is the Factorized Multiplicative Modulation (FMM) layer. Given an input $\mathbf{x}_{in}$, the output $\mathbf{y}$ is computed as:
$$ \mathbf{y} = \mathbf{W} \odot (\mathbf{A} \times \mathbf{B}) \cdot \mathbf{x}_{in} + \mathbf{b} = \tilde{\mathbf{W}} \cdot \mathbf{x}_{in} + \mathbf{b} $$
Where:
*   $\mathbf{W}$ and $\mathbf{b}$ are shared weight matrices and biases across all generated 3D representations [S1, unofficial].
*   $\mathbf{A}$ is a modulation matrix of size $n_{out} \times k$ generated by $G$ [S1, unofficial].
*   $\mathbf{B}$ is a modulation matrix of size $k \times n_{in}$ generated by $G$ [S1, unofficial].
*   $k$ is the rank parameter (default 10) [S1, unofficial].
*   $\odot$ denotes element-wise multiplication [S1, unofficial].
*   $\times$ denotes matrix multiplication [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **View-Dependent Effects:** The model assumes training images lack view-dependent characteristics (e.g., reflections). If such effects are present, the view-independent NeRF will fail to capture them [S1, unofficial].
*   **Camera Poses:** The model does not require camera poses for training, but rendering novel views requires sampling camera perspectives. The source notes that "a single unlabeled view per object is sufficient for training" [S1, unofficial].
*   **Computational Cost:** The original NeRF uses a "fine" network for multi-scale rendering. HyperNeRFGAN rejects this to reduce cost, using only the "coarse" network [S1, unofficial].
*   **Rank $k$:** Higher $k$ increases expressiveness but also memory usage. The default $k=10$ is a trade-off [S1, unofficial].

## Subtopics

### AdaNeRF
Uses adaptive instance normalization (AdaIN) to condition the NeRF on image features. It retains viewing directions but modulates the network based on 2D image content. Choose when view-dependent effects are present and 2D features are available. [AdaNeRF](6195-adanerf.md)

### SfMNeRF
Uses Structure-from-Motion (SfM) points to initialize the NeRF. It relies on accurate camera poses and sparse geometry. Choose when high-quality SfM data is available. [SfMNeRF](8664-sfmnerf.md)

### DASNeRF
Integrates depth and surface normal priors into the NeRF. It uses external priors to guide the optimization. Choose when auxiliary depth/normal data is available. [DASNeRF](8668-dasnerf.md)

### R2L (Neural Light Field)
Uses a neural light field representation. It maps 2D pixel coordinates to 3D rays. Choose when working with light field data or when 2D pixel-based representations are preferred. [R2L (Neural Light Field)](8670-r2l-neural-light-field.md)

### AligNeRF
Focuses on aligning multiple NeRFs for large scenes. It uses spatial partitioning to manage large-scale environments. Choose for large-scale scene reconstruction. [AligNeRF](8695-alignerf.md)

### Mega-NeRF Spatial Partitioning
Decomposes the scene into independent sub-networks managed by spatial cells. Choose for very large scenes that do not fit in memory. [Mega-NeRF Spatial Partitioning](8776-mega-nerf-spatial-partitioning.md)

### MultiPlaneNeRF
Replaces raw 3D coordinates with 2D image projections. It uses multi-plane representations. Choose when 2D projections are a more natural representation. [MultiPlaneNeRF](8875-multiplanenerf.md)

### Sparse Radiance Field (SRF) Representation
Uses sparse voxel coordinates. It represents the scene as a sparse set of voxels. Choose for memory-efficient representation of large scenes. [Sparse Radiance Field (SRF) Representation](8876-sparse-radiance-field-srf-representation.md)

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources, but the rank $k$ parameter influences memory usage [S1, unofficial].
*   **Measured Performance:**
    *   **ShapeNet Car:** FID 29.6 (vs Point2NeRF 82.1) [S1, unofficial].
    *   **CARLA Dataset:** FID 20.5, KID 0.78, IS 4.20 (outperforming HoloGAN, GRAF, $\pi$-GAN) [S1, unofficial].
    *   **CelebA Dataset:** FID 15.04, KID 0.66, IS 2.63 (comparable to $\pi$-GAN) [S1, unofficial].
    *   **Medical (DRR):** Superior performance compared to MedNeRF and UMedNeRF in FID and KID metrics [S1, unofficial].
*   **Strengths:**
    *   Does not require camera position information during training [S1, unofficial].
    *   Simple architecture (single coarse MLP) reduces computational cost [S1, unofficial].
    *   Effective on datasets with few views or challenging camera estimation (e.g., medical data) [S1, unofficial].
*   **Limitations:**
    *   Cannot capture view-dependent effects (e.g., reflections) [S1, unofficial].
    *   Performance is comparable to but not always superior to $\pi$-GAN on CelebA [S1, unofficial].
*   **When to Use:** When camera poses are unavailable or unreliable, and the scene lacks strong view-dependent effects. Particularly suitable for medical imaging (DRR) and datasets with few views.
*   **When Not to Use:** When view-dependent effects are critical, or when high-quality camera poses are available and can be leveraged for better quality (e.g., standard NeRF or GRAF).

## Background
HyperNeRFGAN was introduced in the paper "HyperNeRFGAN: Hypernetwork approach to 3D NeRF GAN" [S1, unofficial]. It builds on the NeRF architecture and the GAN framework, specifically using the StyleGAN2 backbone for the generator [S1, unofficial]. The model addresses the limitation of NeRF requiring camera positions, which is often challenging in medical data and other domains [S1, unofficial]. It uses a hypernetwork to generate NeRF weights, avoiding the complexity of conditioning mechanisms used in models like GRAF and $\pi$-GAN [S1, unofficial].
