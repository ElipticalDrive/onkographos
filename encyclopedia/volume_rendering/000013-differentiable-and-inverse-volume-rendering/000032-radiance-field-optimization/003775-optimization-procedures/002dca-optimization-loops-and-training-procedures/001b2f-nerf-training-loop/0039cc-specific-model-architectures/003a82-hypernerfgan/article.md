# HyperNeRFGAN

Also called: Hypernetwork NeRF GAN, HyperNeRF

## Overview
HyperNeRFGAN is a generative model that synthesizes 3D-aware radiance fields by using a hypernetwork to generate the weights of a simplified NeRF target network from a Gaussian noise vector [S1, unofficial]. It solves the problem of 3D-aware image generation in scenarios where camera positions are unavailable or difficult to estimate, such as medical imaging or datasets with limited viewpoints [S1, unofficial]. Unlike standard NeRF variants that require viewing directions or complex conditioning mechanisms, HyperNeRFGAN omits viewing direction inputs and uses a standard 2D discriminator to train the generative process via a StyleGAN2-style adversarial objective [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Generator Input:** A noise vector $\mathbf{z}$ sampled from a standard Gaussian distribution $\mathcal{N}(0, I)$ [S1, unofficial].
*   **Generator Output:** The weights $\Theta$ of the target NeRF network [S1, unofficial].
*   **Target NeRF Input:** A 3D spatial coordinate $\mathbf{x} = (x, y, z)$ [S1, unofficial].
*   **Target NeRF Output:** Volume density $\sigma$ and color $\mathbf{c}$ [S1, unofficial].
*   **Discriminator Input:** 2D rendered images (real or generated) [S1, unofficial].
*   **Discriminator Output:** A scalar probability score indicating whether the image is real or fake [S1, unofficial].

**Data Structures:**
The target NeRF is a single Multi-Layer Perceptron (MLP) [S1, unofficial].
*   **Architecture:** The network consists of hidden layers using Factorized Multiplicative Modulation (FMM) layers [S1, unofficial].
*   **FMM Layer Layout:** An FMM layer transforms an input $\mathbf{x}_{in}$ to output $\mathbf{y}$ using shared weights $\mathbf{W}$ and $\mathbf{b}$, and modulation matrices $\mathbf{A}$ and $\mathbf{B}$ generated by the generator [S1, unofficial].
    *   $\mathbf{W} \in \mathbb{R}^{n_{out} \times n_{in}}$: Shared weight matrix.
    *   $\mathbf{b} \in \mathbb{R}^{n_{out}}$: Shared bias vector.
    *   $\mathbf{A} \in \mathbb{R}^{n_{out} \times k}$: Modulation matrix generated by $G$.
    *   $\mathbf{B} \in \mathbb{R}^{k \times n_{in}}$: Modulation matrix generated by $G$.
    *   $k$: Rank parameter controlling the expressiveness and memory usage of the modulation [S1, unofficial].
*   **Network Dimensions:**
    *   Hidden layer channels: 128 (reduced from standard 256) [S1, unofficial].
    *   Network depth: 4 or 8 layers (standard NeRF uses 8 layers for coarse and 8 for fine; HyperNeRFGAN uses only one network) [S1, unofficial].
    *   Rank $k$: Fixed at 10 [S1, unofficial].

**Numbered Steps:**
1.  **Sample Noise:** Sample a noise vector $\mathbf{z} \sim \mathcal{N}(0, I)$ [S1, unofficial].
2.  **Generate Weights:** Pass $\mathbf{z}$ through the Generator network $G$ to produce the modulation matrices $\mathbf{A}$ and $\mathbf{B}$ for all FMM layers in the target NeRF [S1, unofficial]. The shared weights $\mathbf{W}$ and $\mathbf{b}$ are global parameters of the NeRF architecture, but the effective weights are modulated by $\mathbf{A}$ and $\mathbf{B}$ [S1, unofficial].
3.  **Instantiate NeRF:** Construct the target NeRF function $F_\Theta(\mathbf{x})$ using the generated modulation parameters. The function maps $\mathbf{x} \rightarrow (\sigma, \mathbf{c})$ [S1, unofficial].
4.  **Render Image:** Sample rays from various camera perspectives. For each ray, sample points $\mathbf{x}_i$ along the ray. Query $F_\Theta$ for $\sigma_i$ and $\mathbf{c}_i$ at each point [S1, unofficial].
5.  **Volume Rendering:** Compute the final pixel color $C(r)$ using the standard volume rendering equation:
    $$ C(r) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i, \quad T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right), \quad \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
    where $\delta_j$ is the distance between adjacent samples [S1, unofficial]. Note: HyperNeRFGAN uses only the "coarse" network structure; it does not employ a separate "fine" network for multi-scale rendering [S1, unofficial].
6.  **Discriminator Evaluation:** Pass the rendered image $I_{gen}$ and a real image $I_{real}$ from the dataset to the Discriminator $D$ [S1, unofficial].
7.  **Adversarial Training:** Update Generator $G$ and Discriminator $D$ by minimizing the following minimax game objective:
    $$ \min_G \max_D V(D, G) = \mathbb{E}_{\mathbf{x} \sim P_{data}}[\log D(\mathbf{x})] + \mathbb{E}_{\mathbf{z} \sim P_{noise}}[\log(1 - D(G(\mathbf{z})))] $$
    [S1, unofficial].

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class FMMLayer(nn.Module):
    """
    Factorized Multiplicative Modulation Layer.
    y = W * (A @ B) * x_in + b
    Note: The source defines y = W ⊙ (A × B) · x_in + b.
    In matrix notation, if W is shared and A, B are modulations:
    The effective weight matrix is W_eff = W * (A @ B) where * is element-wise multiplication?
    Or is it W * (A @ B) where * is matrix multiplication?
    Source formula: y = W ⊙ (A × B) · x_in + b
    ⊙ usually denotes element-wise (Hadamard) product.
    × usually denotes matrix multiplication.
    So: Effective_W = W * (A @ B)  (Element-wise)
    Then y = Effective_W @ x_in + b
    """
    def __init__(self, n_in, n_out, k):
        super().__init__()
        self.n_in = n_in
        self.n_out = n_out
        self.k = k
        # Shared weights
        self.W = nn.Parameter(torch.randn(n_out, n_in) * 0.02)
        self.b = nn.Parameter(torch.zeros(n_out))
        
        # Modulation matrices will be provided by the generator
        # Dimensions: A is (n_out, k), B is (k, n_in)
        # We do not store A and B here as parameters; they are inputs.
        
    def forward(self, x_in, A, B):
        # A: (n_out, k), B: (k, n_in)
        # Compute modulation product
        modulation = torch.matmul(A, B) # (n_out, n_in)
        
        # Element-wise multiplication with shared weights
        effective_W = self.W * modulation 
        
        # Linear transformation
        y = torch.matmul(effective_W, x_in) + self.b
        return y

class HyperNeRFGAN_Generator(nn.Module):
    """
    Generator that produces modulation matrices A and B for the NeRF layers.
    Based on StyleGAN2 backbone principles [S1, unofficial].
    """
    def __init__(self, z_dim, layer_configs, k=10):
        super().__init__()
        self.layer_configs = layer_configs # List of (n_in, n_out)
        self.k = k
        # Standard StyleGAN2 mapping network and synthesis network logic would go here.
        # For implementation completeness, we assume a function `stylegan2_synthesis`
        # that takes z and outputs modulation parameters for each layer.
        # Since we cannot implement full StyleGAN2 from scratch in this snippet without
        # external libraries, we define the interface.
        self.synthesis = StyleGAN2Synthesis(z_dim, layer_configs, k)

    def forward(self, z):
        # Returns a list of (A, B) tuples for each layer
        return self.synthesis(z)

class HyperNeRFGAN_NeRF(nn.Module):
    """
    Target NeRF network using FMM layers.
    Input: x (3D coordinates)
    Output: sigma, color
    """
    def __init__(self, layer_configs, k=10):
        super().__init__()
        self.layers = nn.ModuleList()
        for i, (n_in, n_out) in enumerate(layer_configs):
            self.layers.append(FMMLayer(n_in, n_out, k))
            # Add activation (e.g., ReLU) except for the last layer
            if i < len(layer_configs) - 1:
                self.layers.append(nn.ReLU())
        
        # Final layers for sigma and color
        # Typically NeRF splits the output. 
        # Source says F_theta: x -> (c, sigma).
        # We assume the last FMM layer outputs a vector that is split.
        self.sigma_layer = nn.Linear(layer_configs[-1][1], 1)
        self.color_layer = nn.Linear(layer_configs[-1][1], 3)

    def forward(self, x, modulation_params):
        """
        x: (..., 3)
        modulation_params: list of (A, B) tuples
        """
        h = x
        for i, layer in enumerate(self.layers):
            if isinstance(layer, FMMLayer):
                A, B = modulation_params[i // 2] # Assuming alternating FMM and ReLU
                h = layer(h, A, B)
            else:
                h = layer(h)
        
        sigma = self.sigma_layer(h)
        color = self.color_layer(h)
        
        # Apply activation for sigma (e.g., softplus or exp) and color (sigmoid)
        # Standard NeRF uses exp for sigma and sigmoid for color.
        sigma = torch.exp(sigma)
        color = torch.sigmoid(color)
        
        return sigma, color

def render_ray(ray_origin, ray_direction, nerf, modulation_params, num_samples):
    """
    Renders a single ray using the volume rendering equation.
    """
    # Sample points along the ray
    t_vals = torch.linspace(0, 1, num_samples)
    z_vals = ray_origin + ray_direction * t_vals.unsqueeze(-1) # (num_samples, 3)
    
    # Query NeRF
    sigma, color = nerf(z_vals, modulation_params)
    
    # Compute deltas
    deltas = z_vals[1:, :] - z_vals[:-1, :]
    # Handle the last delta (approximate or zero)
    deltas = torch.cat([deltas, torch.zeros_like(deltas[-1:])], dim=0)
    dists = torch.norm(deltas, dim=-1)
    
    # Compute alpha
    alpha = 1.0 - torch.exp(-sigma * dists)
    
    # Compute transmittance
    T = torch.cumprod(torch.cat([torch.ones_like(alpha[:, :1]), 1.0 - alpha + 1e-10], dim=1)[:, :-1], dim=1)
    
    # Composite color
    weights = alpha * T
    color_composite = torch.sum(weights.unsqueeze(-1) * color, dim=1)
    
    return color_composite

def train_step(generator, discriminator, nerf, real_images, camera_params, optimizer_G, optimizer_D, optimizer_NeRF):
    """
    One step of the HyperNeRFGAN training loop.
    """
    # 1. Sample noise
    z = torch.randn(real_images.shape[0], generator.z_dim).to(real_images.device)
    
    # 2. Generate modulation parameters
    modulation_params = generator(z)
    
    # 3. Render fake images
    fake_images = []
    for i in range(real_images.shape[0]):
        # Assume camera_params[i] provides origin and direction for a random view
        origin = camera_params[i].origin
        direction = camera_params[i].direction
        # Render a patch or full image
        img = render_ray(origin, direction, nerf, modulation_params[i], num_samples=128)
        fake_images.append(img)
    fake_images = torch.stack(fake_images)
    
    # 4. Discriminator Loss
    # D(real)
    d_real = discriminator(real_images)
    loss_d_real = F.softplus(-d_real).mean()
    
    # D(fake)
    d_fake = discriminator(fake_images.detach())
    loss_d_fake = F.softplus(d_fake).mean()
    
    loss_D = loss_d_real + loss_d_fake
    
    optimizer_D.zero_grad()
    loss_D.backward()
    optimizer_D.step()
    
    # 5. Generator Loss
    # D(fake) - we want D(fake) to be 1 (real)
    d_fake_gen = discriminator(fake_images)
    loss_G = F.softplus(-d_fake_gen).mean()
    
    optimizer_G.zero_grad()
    loss_G.backward()
    optimizer_G.step()
    
    # Note: The NeRF weights (W, b) are also updated via the GAN loss gradient flow
    # through the rendering process.
    optimizer_NeRF.zero_grad()
    loss_G.backward(retain_graph=True) # Or combined in a single backward pass
    optimizer_NeRF.step()
    
    return loss_D.item(), loss_G.item()
```

**Parameters:**
*   **Rank $k$:** 10 [S1, unofficial].
*   **Hidden Channels:** 128 [S1, unofficial].
*   **Network Depth:** 4 or 8 layers [S1, unofficial].
*   **Noise Distribution:** Gaussian $\mathcal{N}(0, I)$ [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Viewing Directions:** The model does not accept viewing directions. If the dataset contains view-dependent effects (e.g., reflections), performance may degrade [S1, unofficial].
*   **Fine Network:** The standard NeRF "fine" network is omitted to reduce computational cost. This may limit the ability to render high-frequency details compared to full NeRF [S1, unofficial].
*   **Camera Estimation:** The method is designed for cases where camera estimation is challenging. If camera poses *are* available, this method does not explicitly leverage them, potentially missing out on geometric consistency benefits provided by pose-aware models [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Training time is reduced compared to standard NeRF GANs because it uses a single "coarse" network with reduced channels (128 vs 256) and depth (4-8 vs 16 total) [S1, unofficial].
*   **Memory Complexity:** The rank $k=10$ controls the memory usage of the modulation matrices. Higher $k$ increases expressiveness but also memory usage [S1, unofficial].
*   **Performance:**
    *   **ShapeNet Car:** FID 29.6 (vs Point2NeRF 82.1) [S1, unofficial].
    *   **CARLA Dataset:** FID 20.5, KID 0.78, IS 4.20 (outperforming HoloGAN, GRAF, and $\pi$-GAN) [S1, unofficial].
    *   **CelebA Dataset:** FID 15.04, KID 0.66, IS 2.63 (comparable to $\pi$-GAN) [S1, unofficial].
    *   **Medical (DRR):** Superior FID and KID scores compared to MedNeRF and UMedNeRF [S1, unofficial].
*   **Strengths:** Does not require camera poses; simple architecture; high-quality 3D-aware generation on datasets with limited views or no pose information.
*   **Limitations:** Cannot model view-dependent effects; lower detail resolution due to simplified network; relies on 2D discriminator which may not fully enforce 3D consistency.

## Background
HyperNeRFGAN was introduced in a 2023 preprint [S1, unofficial]. It builds on the hypernetwork paradigm [Ha et al., 2016] and the INR-GAN architecture [S1, unofficial], adapting them for 3D radiance fields. It addresses limitations of previous 3D-aware GANs like GRAF and $\pi$-GAN, which use SIREN networks and complex conditioning mechanisms [S1, unofficial]. HyperNeRFGAN is particularly relevant for medical imaging applications (e.g., Digitally Reconstructed Radiographs) where camera poses are not naturally available [S1, unofficial].
