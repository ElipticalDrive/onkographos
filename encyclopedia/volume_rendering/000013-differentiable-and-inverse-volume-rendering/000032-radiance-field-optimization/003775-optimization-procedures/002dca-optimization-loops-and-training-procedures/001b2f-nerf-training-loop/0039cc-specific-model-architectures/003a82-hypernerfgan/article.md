# HyperNeRFGAN

Also called: HyperNeRF GAN, Hypernetwork NeRF GAN

## Overview
HyperNeRFGAN is a generative model that produces 3D-aware image synthesis by using a hypernetwork to generate the weights of a simplified NeRF target network from a Gaussian noise vector [S1, unofficial]. It solves the problem of training NeRF-based generators on datasets where camera positions are unavailable or difficult to estimate, such as medical radiographs or single-view object photos [S1, unofficial]. Unlike standard NeRFs which require 5D input (position and viewing direction) and SIREN-based GANs which use conditioning mechanisms, HyperNeRFGAN uses a 3D-only input (position) and Factorized Multiplicative Modulation (FMM) layers to decouple the generative process from explicit camera parameters [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A noise vector $\mathbf{z}$ sampled from a standard Gaussian distribution $\mathcal{N}(0, I)$ [S1, unofficial].
- **Output:** A rendered 2D image $I$ from a specified virtual camera pose (defined by extrinsics/intrinsics during inference, but not used during training) [S1, unofficial].

**Data Structures:**
1.  **Generator $G$:** A StyleGAN2-based architecture that maps $\mathbf{z}$ to the weights $\theta$ of the target NeRF [S1, unofficial].
2.  **Target NeRF $F_\theta$:** A single Multi-Layer Perceptron (MLP) that maps 3D spatial coordinates $\mathbf{x} = (x, y, z)$ to volume density $\sigma$ and color $\mathbf{c}$ [S1, unofficial].
    -   **Architecture:** 4 to 8 layers (typically 4 in experiments to reduce cost), 128 hidden channels per layer [S1, unofficial].
    -   **Layers:** Uses Factorized Multiplicative Modulation (FMM) layers instead of standard linear layers [S1, unofficial].
3.  **Discriminator $D$:** A standard 2D CNN discriminator that evaluates the rendered 2D images [S1, unofficial].

**Factorized Multiplicative Modulation (FMM) Layer:**
The core building block of the target NeRF $F_\theta$. It allows the generator $G$ to modulate the shared weights of the NeRF. For a layer with input size $n_{in}$ and output size $n_{out}$:
$$ \mathbf{y} = \mathbf{W} \odot (\mathbf{A} \times \mathbf{B}) \cdot \mathbf{x}_{in} + \mathbf{b} = \tilde{\mathbf{W}} \cdot \mathbf{x}_{in} + \mathbf{b} $$
Where:
-   $\mathbf{W} \in \mathbb{R}^{n_{out} \times n_{in}}$ and $\mathbf{b} \in \mathbb{R}^{n_{out}}$ are shared parameters across all generated NeRFs [S1, unofficial].
-   $\mathbf{A} \in \mathbb{R}^{n_{out} \times k}$ and $\mathbf{B} \in \mathbb{R}^{k \times n_{in}}$ are modulation matrices generated by $G$ from $\mathbf{z}$ [S1, unofficial].
-   $k$ is the rank parameter, controlling the expressiveness and memory usage. The source uses $k=10$ [S1, unofficial].
-   $\odot$ denotes element-wise multiplication, and $\times$ denotes matrix multiplication [S1, unofficial].

**Numbered Steps:**
1.  **Sample Noise:** Sample a noise vector $\mathbf{z} \sim \mathcal{N}(0, I)$ [S1, unofficial].
2.  **Generate Weights:** Pass $\mathbf{z}$ through the Generator $G$ to obtain the modulation matrices $\mathbf{A}$ and $\mathbf{B}$ for each FMM layer in the target NeRF [S1, unofficial].
3.  **Instantiate NeRF:** Construct the target NeRF $F_\theta$ using the shared weights $\mathbf{W}, \mathbf{b}$ and the generated modulations $\mathbf{A}, \mathbf{B}$ [S1, unofficial]. Note that $F_\theta$ takes only $\mathbf{x}$ as input, not viewing direction $\mathbf{d}$ [S1, unofficial].
4.  **Render Image:** Use $F_\theta$ to render a 2D image $I_{gen}$ by sampling points along rays defined by a virtual camera pose and applying the volume rendering equation [S1, unofficial].
    -   The rendering uses only the "coarse" network (no "fine" network) to reduce computational cost [S1, unofficial].
5.  **Discriminate:** Pass the real image $I_{real}$ (from dataset) and generated image $I_{gen}$ to the Discriminator $D$ [S1, unofficial].
6.  **Update:** Minimize the GAN loss:
    $$ \min_G \max_D V(D, G) = \mathbb{E}_{\mathbf{x} \sim P_{data}}[\log D(\mathbf{x})] + \mathbb{E}_{\mathbf{z} \sim P_{noise}}[\log(1 - D(G(\mathbf{z})))] $$
    [S1, unofficial].

import torch
import torch.nn as nn
import torch.nn.functional as F

class FMMLayer(nn.Module):
    """Factorized Multiplicative Modulation Layer"""
    def __init__(self, n_in, n_out, rank_k):
        super().__init__()
        self.n_in = n_in
        self.n_out = n_out
        self.rank_k = rank_k
        # Shared weights
        self.W = nn.Parameter(torch.randn(n_out, n_in) * 0.02)
        self.b = nn.Parameter(torch.zeros(n_out))
        # Modulation matrices will be provided by the generator
        # A: (n_out, k), B: (k, n_in)

    def forward(self, x_in, A, B):
        # x_in: (batch, n_in)
        # A: (n_out, k), B: (k, n_in)
        # Compute modulation: W_tilde = W * (A @ B)
        # Note: Broadcasting handles batch dimension
        modulation = torch.matmul(A, B) # (n_out, n_in)
        W_tilde = self.W * modulation
        return torch.matmul(x_in, W_tilde.t()) + self.b

class TargetNeRF(nn.Module):
    """Simplified NeRF using FMM layers, no viewing direction input"""
    def __init__(self, n_layers=4, hidden_dim=128, rank_k=10):
        super().__init__()
        self.layers = nn.ModuleList()
        self.rank_k = rank_k
        
        # Input is 3D position (x, y, z)
        prev_dim = 3
        for i in range(n_layers):
            curr_dim = hidden_dim if i < n_layers - 1 else 4 # 3 for color, 1 for density
            self.layers.append(FMMLayer(prev_dim, curr_dim, rank_k))
            prev_dim = curr_dim

    def forward(self, x, A_list, B_list):
        # x: (batch, 3)
        # A_list, B_list: lists of modulation matrices for each layer
        h = x
        for i, layer in enumerate(self.layers):
            h = layer(h, A_list[i], B_list[i])
        
        # Split output into color (c) and density (sigma)
        # Assuming last layer outputs 4 values: c_r, c_g, c_b, sigma
        c = h[:, :3]
        sigma = h[:, 3:]
        return c, sigma

class Generator(nn.Module):
    """StyleGAN2-based generator producing modulation matrices"""
    def __init__(self, n_layers, hidden_dim, rank_k, z_dim=512):
        super().__init__()
        self.n_layers = n_layers
        self.hidden_dim = hidden_dim
        self.rank_k = rank_k
        self.z_dim = z_dim
        
        # Simplified StyleGAN2 backbone
        # In practice, this is a complex architecture mapping z -> A_i, B_i for each layer
        # Here we represent the output generation conceptually
        self.style_layers = nn.Sequential(
            nn.Linear(z_dim, 512),
            nn.ReLU(),
            nn.Linear(512, 512),
            nn.ReLU(),
            # ... more layers ...
        )
        
        # Projection heads to generate A and B for each FMM layer
        self.A_heads = nn.ModuleList([
            nn.Linear(512, hidden_dim * rank_k) for _ in range(n_layers)
        ])
        self.B_heads = nn.ModuleList([
            nn.Linear(512, rank_k * 3) for _ in range(n_layers) # Input dim is 3 for first layer
        ])
        # Note: The input dimension for B changes per layer. 
        # A more precise implementation would handle dynamic B dimensions or use a unified style vector.
        # For the purpose of this article, we assume the generator outputs the necessary tensors.

    def forward(self, z):
        # z: (batch, z_dim)
        style = self.style_layers(z) # (batch, 512)
        
        A_list = []
        B_list = []
        
        # Generate modulation matrices for each layer
        # This is a simplified representation. In reality, StyleGAN2 uses adaptive instance normalization (AdaIN)
        # or similar mechanisms. HyperNeRFGAN uses FMM, so the generator outputs A and B.
        for i in range(self.n_layers):
            # Get A: (n_out, k)
            A_flat = self.A_heads[i](style) # (batch, n_out * k)
            n_out = self.hidden_dim if i < self.n_layers - 1 else 4
            A = A_flat.view(-1, n_out, self.rank_k)
            A_list.append(A)
            
            # Get B: (k, n_in)
            # n_in depends on the previous layer's output
            n_in = 3 if i == 0 else self.hidden_dim
            B_flat = self.B_heads[i](style) # (batch, k * n_in)
            B = B_flat.view(-1, self.rank_k, n_in)
            B_list.append(B)
            
        return A_list, B_list

class Discriminator(nn.Module):
    """Standard 2D CNN Discriminator"""
    def __init__(self):
        super().__init__()
        self.net = nn.Sequential(
            # Conv layers...
            nn.Conv2d(3, 64, 4, stride=2, padding=1),
            nn.LeakyReLU(0.2, inplace=True),
            # ...
            nn.Flatten(),
            nn.Linear(64 * 8 * 8, 1), # Example output size
            nn.Sigmoid()
        )

    def forward(self, x):
        return self.net(x)

def render_image(x_samples, A_list, B_list, nerf, camera_params):
    """
    Render a 2D image from 3D samples using the target NeRF.
    x_samples: (batch, N, 3) sampled points along rays
    """
    c, sigma = nerf(x_samples, A_list, B_list)
    
    # Volume Rendering Equation
    # T_i = exp(-sum_{j=1}^{i-1} sigma_j * delta_j)
    # alpha_i = 1 - exp(-sigma_i * delta_i)
    # C = sum(T_i * alpha_i * c_i)
    
    # Compute delta (distance between samples)
    # Assuming uniform sampling for simplicity
    delta = 0.01 # Placeholder for actual ray step size
    
    # Compute alpha
    alpha = 1.0 - torch.exp(-sigma * delta)
    
    # Compute transmittance
    # T_i = product_{j=1}^{i-1} (1 - alpha_j)
    # Using cumulative product
    alpha_cumprod = torch.cat([torch.ones_like(alpha[:, :1]), 1.0 - alpha], dim=1)
    T = torch.cumprod(alpha_cumprod, dim=1)[:, :-1]
    
    # Weighted sum
    weights = T * alpha
    image = torch.sum(weights.unsqueeze(-1) * c, dim=1)
    
    return image

def train_step(batch, generator, discriminator, target_nerf, optimizer_G, optimizer_D):
    # 1. Sample noise
    z = torch.randn(batch.size(0), 512).to(batch.device)
    
    # 2. Generate weights (modulation matrices)
    A_list, B_list = generator(z)
    
    # 3. Render generated image
    # Assume we have pre-defined camera poses for the batch
    # x_samples would be generated based on camera poses
    # For simplicity, assume x_samples is available
    x_samples = ... # (batch, N, 3)
    img_gen = render_image(x_samples, A_list, B_list, target_nerf, None)
    
    # 4. Discriminator update
    optimizer_D.zero_grad()
    real_score = discriminator(batch)
    fake_score = discriminator(img_gen.detach())
    
    d_loss = -torch.mean(torch.log(real_score + 1e-8) + torch.log(1 - fake_score + 1e-8))
    d_loss.backward()
    optimizer_D.step()
    
    # 5. Generator update
    optimizer_G.zero_grad()
    fake_score_gen = discriminator(img_gen)
    g_loss = -torch.mean(torch.log(fake_score_gen + 1e-8))
    g_loss.backward()
    optimizer_G.step()
    
    return d_loss.item(), g_loss.item()

**Parameters:**
-   **Hidden layer channels:** 128 (reduced from standard 256) [S1, unofficial].
-   **Network depth:** 4 layers (reduced from 8) in some experiments [S1, unofficial].
-   **Rank $k$:** 10 [S1, unofficial].
-   **Noise vector:** Sampled from $\mathcal{N}(0, I)$ [S1, unofficial].

**Edge Cases and Pitfalls:**
-   **Viewing Direction:** The model does not use viewing directions. This is a deliberate simplification because the training datasets (e.g., medical DRRs, single-view objects) lack view-dependent characteristics like reflections [S1, unofficial]. If view-dependent effects are present, this architecture is not suitable without modification [S1, unofficial].
-   **Fine Network:** The "fine" network from standard NeRF is omitted to reduce training cost [S1, unofficial]. This may limit the quality of fine details compared to full NeRF, but is sufficient for the generative task [S1, unofficial].
-   **Camera Poses:** While camera poses are not used during training, they are required during inference to render novel views. The model generates a 3D representation that is consistent across views, but the rendering process still requires specifying a camera pose [S1, unofficial].

## Operating characteristics
-   **Time Complexity:** Training is faster than standard NeRF-based GANs (like GRAF) because it avoids the complex conditioning mechanism and uses a smaller, single-network NeRF [S1, unofficial]. The use of FMM layers adds some overhead compared to standard linear layers, but the reduced network size (128 channels, 4 layers) compensates [S1, unofficial].
-   **Memory Complexity:** The memory usage is determined by the shared weights of the NeRF and the modulation matrices. The rank $k=10$ controls the trade-off between expressiveness and memory [S1, unofficial].
-   **Performance:**
    -   **ShapeNet Car:** FID 29.6 (vs. Point2NeRF 82.1) [S1, unofficial].
    -   **CARLA:** FID 20.5, KID 0.78, IS 4.20 (outperforming HoloGAN, GRAF, and $\pi$-GAN) [S1, unofficial].
    -   **CelebA:** FID 15.04, KID 0.66, IS 2.63 (comparable to $\pi$-GAN) [S1, unofficial].
    -   **Medical (DRR):** Superior FID and KID scores compared to MedNeRF and UMedNeRF [S1, unofficial].
-   **Strengths:** Does not require camera poses; simple architecture; high-quality 3D-aware generation on datasets with limited views; effective for medical imaging.
-   **Limitations:** Cannot model view-dependent effects (specularities, reflections); relies on a single coarse network; performance may be lower than full NeRF for complex scenes with strong view dependence.

## Background
HyperNeRFGAN was introduced in 2023 by authors associated with the paper "HyperNeRFGAN: Hypernetwork approach to 3D NeRF GAN" [S1, unofficial]. It builds on the hypernetwork paradigm [Ha et al., 2016] and the StyleGAN2 architecture [Karras et al., 2020]. It addresses the limitations of previous 3D-aware GANs like GRAF and $\pi$-GAN, which rely on SIREN and complex conditioning mechanisms, by using a simplified NeRF with FMM layers [S1, unofficial]. It is particularly useful for applications where camera calibration is difficult, such as medical imaging (Digitally Reconstructed Radiographs) and single-view object generation [S1, unofficial].
