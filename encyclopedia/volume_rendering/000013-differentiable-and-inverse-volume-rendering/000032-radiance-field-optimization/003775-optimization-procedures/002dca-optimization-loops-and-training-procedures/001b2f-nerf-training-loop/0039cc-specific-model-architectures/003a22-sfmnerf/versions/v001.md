# SfMNeRF
Also called: SfM-NeRF

## Overview
SfMNeRF is a method for novel view synthesis and 3D-scene geometry reconstruction using Neural Radiance Fields (NeRF) under sparse input conditions [S1]. It improves geometric accuracy and avoids local minima by integrating Structure-from-Motion (SfM) constraints—specifically matched feature positions, epipolar geometry, and multi-view photometric consistency—into the view synthesis training loop [S1]. Unlike standard NeRF which relies solely on implicit photometric loss, SfMNeRF explicitly constrains the 3D structure using sparse feature matches and cross-view consistency, making it distinct from sibling methods like [AdaNeRF](6195-adanerf.md) or [DASNeRF](8668-dasnerf.md) that may focus on adaptive sampling or different architectural priors rather than explicit SfM geometric constraints.

## How it works
### Inputs and Outputs
**Inputs:**
*   A set of $N$ images $\{I_0, \dots, I_{N-1}\}$ with known camera intrinsics $K$ and global poses $[\mathbf{r}_i, \mathbf{t}_i]$.
*   Sparse matched feature correspondences (e.g., SIFT) between image pairs.
*   A Neural Radiance Field (MLP) parameterized by $\theta$, mapping 3D coordinates $\mathbf{x}$ and viewing directions $\mathbf{d}$ to color $\mathbf{c}$ and volume density $\sigma$.

**Outputs:**
*   Optimized NeRF parameters $\theta$.
*   Synthesized novel views and depth maps.

### Data Structures
*   **Camera Intrinsic Matrix $K$**: $3 \times 3$ matrix.
*   **Global Pose**: For image $i$, rotation $\mathbf{r}_i$ and translation $\mathbf{t}_i$.
*   **Relative Pose $T_{r \to t}$**: $4 \times 4$ transformation matrix from reference image $r$ to target image $t$, defined as $T_{r \to t} = [\mathbf{r}, \mathbf{t}]$ where $\mathbf{r} = \mathbf{r}_t^{-1}$ and $\mathbf{t} = -\mathbf{r}_t^{-1}\mathbf{t}_t$ [S1].
*   **Mask Map $M$**: Binary mask where $M(p(k))=1$ if point $p(k)$ is inside the minimum rectangle enclosing all matched SIFT features in the reference image, else $0$ [S1].
*   **Depth Map $D$**: Estimated depth for each pixel.
*   **SIFT Features**: 2D coordinates in images and their 3D world coordinates $\mathbf{x}_s$.

### Numbered Steps

1.  **Pyramidal Construction**: Construct an $L$-level pyramid for the reference image $I_r$ and target image $I_t$. Let $I^0_r = I_r$ and $I^0_t = I_t$. For level $n > 0$, $I^n_r$ is $I^{n-1}_r$ downsampled by half resolution, and similarly for $I^n_t$ [S1].
2.  **Initialization**: Start optimization at the lowest level $L-1$ using images $I^{L-1}_r$ and $I^{L-1}_t$.
3.  **Feature Extraction**: Extract SIFT features from $I^n_r$ and $I^n_t$. Obtain matched SIFT correspondences between the two images [S1].
4.  **Sub-pixel Patch Sampling**:
    *   Randomly select a patch region $\Omega_p$ from the reference image $I^n_r$.
    *   For each pixel $p=(x,y) \in \Omega_p$, generate a sub-pixel coordinate $p_{sub} = (x + x_{off}, y + y_{off})$ where $x_{off}, y_{off} \in (0, 1)$ are random offsets [S1].
5.  **Ground Truth Sub-pixel Color**:
    *   Compute the ground-truth color $\hat{I}(p_{sub})$ for the sub-pixel using bilinear interpolation of the four neighboring integer pixels in $I^n_r$ [S1].
    *   Formula: $\hat{I}(p_{sub}) = \sum_{i \in \{top, bottom\}, j \in \{left, right\}} w^{ij} I(p^{ij})$, where $w^{ij}$ is proportional to the inverse Euclidean distance between $p_{sub}$ and neighbor $p^{ij}$ [S1].
6.  **NeRF Rendering**:
    *   Input $p_{sub}$ and viewing direction $\mathbf{d}$ into the NeRF to obtain color $\tilde{I}(p_{sub})$ and depth $D(p_{sub})$ via volume rendering integration [S1].
7.  **3D Coordinate Estimation for Features**:
    *   For each matched SIFT feature $k$, estimate its 3D coordinate $\mathbf{x}_s^k$ by integrating along the ray defined by the feature's 2D position and camera pose [S1].
    *   Formula: $\mathbf{x}_s = \sum_{j=1}^{N_c} w_j (\mathbf{o} + t_j \mathbf{d})$, where $w_j = T_j (1 - \exp(-\sigma_j \delta_j))$, $\delta_j = t_{j-1} - t_j$, and $N_c$ is the number of samples [S1].
8.  **Loss Computation**:
    *   **Rendering Loss ($L_{ren}$)**: Mean squared error between ground-truth sub-pixel color $\hat{I}$ and synthesized color $\tilde{I}$ [S1].
        $$L_{ren} = \frac{1}{m} \sum_{p_i \in \Omega_p} \left\| \hat{I}(p_i) - \tilde{I}(p_i) \right\|_2^2$$
    *   **Positions-of-Matched Features Loss ($L_{3D}$)**: Enforce that matched features in reference and target images have the same 3D world coordinate [S1].
        $$L_{3D} = \frac{1}{n} \sum_{k=1}^n \|\mathbf{x}_s^k - \mathbf{x}_{s'}^k\|_2^2$$
        where $\mathbf{x}_s^k$ and $\mathbf{x}_{s'}^k$ are the 3D coordinates of feature $k$ in the reference and target images, respectively [S1].
    *   **Epipolar Constraint Loss ($L_{epi}$)**:
        *   Calculate the epipolar line in the target image corresponding to a point in the reference image.
        *   Filter implausible points on the epipolar line: keep only points where the color difference between the reference point and the epipolar point is below a threshold [S1].
        *   Minimize the distance between the estimated 3D coordinate of the reference point $d_{p_r}$ and the closest valid point on the epipolar line $d_{p_t}$ [S1].
        $$L_{epi} = \min_t \left\{ \left\| d_{p_r} - d_{p_t} \right\|_2^2 \right\}$$
    *   **Photometric Consistency Loss ($L_{pr}$)**:
        *   Warp pixels from the reference patch to the target image using the estimated 3D coordinates and relative pose [S1].
        *   Warped coordinate: $\hat{p}_t = K T_{r \to t} \mathbf{x}_p$ [S1].
        *   Compute L1 difference between the reference patch color and the warped target patch color, masked by $M$ [S1].
        $$L_{pr} = \sum_{p(k) \in \Omega_p} M(p(k)) \left| \hat{I}_r(p(k)) - \hat{I}_t(\hat{p}_t(k)) \right|$$
    *   **SSIM Loss ($L_{SSIM}$)**: Structural similarity between the reference patch and the warped target patch, masked by $M$ [S1].
        $$L_{SSIM} = M \left( \frac{1 - SSIM_{r \to t}}{2} \right)$$
    *   **Depth Smooth Loss ($L_{ds}$)**: Enforce smoothness of the estimated depth map, weighted by image gradients to preserve edges [S1].
        $$L_{ds} = \sum_{p(k) \in \Omega_p} \left| \nabla D ( p(k) ) \cdot \left( e^{-|\hat{I}(p(k))|} \right) \right|$$
9.  **Total Loss and Optimization**:
    *   Combine losses: $L_{total} = \lambda_{ren} L_{ren} + \lambda_{3D} L_{3D} + \lambda_{pr} L_{pr} + \lambda_{SSIM} L_{SSIM} + \lambda_{epi} L_{epi} + \lambda_{ds} L_{ds}$ [S1].
    *   Optimize NeRF parameters using Adam optimizer [S1].
10. **Pyramidal Recursion**:
    *   After optimizing level $n-1$, obtain the depth map $D^{n-1}_r$.
    *   Move to level $n-2$. Add a depth prior loss $L_{depth}$ to guide optimization [S1].
    *   Formula: $L_{depth} = \sum_{p(k) \in \Omega_p} |D(p(k)) - D_r^{n-1}(p(k)/2)|$, where $D_r^{n-1}(p(k)/2)$ is sampled via bilinear interpolation from the lower-resolution depth map [S1].
    *   Recursively proceed to the "zeroth" level (original resolution) [S1].

### Pseudocode

```python
def train_sfmnerf(images, poses, intrinsics, sift_matches, num_levels=4):
    """
    Train SfMNeRF using a pyramidal strategy.
    
    Args:
        images: List of images [I_0, ..., I_{N-1}]
        poses: List of global poses [r_i, t_i]
        intrinsics: Camera intrinsic matrix K
        sift_matches: List of matched SIFT features between image pairs
        num_levels: Number of pyramid levels L
        
    Returns:
        trained_nerf: Optimized NeRF model
    """
    
    # 1. Construct Pyramids
    # Downsample images to create L levels
    pyramid_images_r = [downsample(images[r], factor=2**i) for i in range(num_levels)]
    pyramid_images_t = [downsample(images[t], factor=2**i) for i in range(num_levels)]
    
    # Initialize NeRF
    nerf = NeRFMLP()
    
    # 2. Start from lowest level
    current_level = num_levels - 1
    
    while current_level >= 0:
        I_r = pyramid_images_r[current_level]
        I_t = pyramid_images_t[current_level]
        
        # 3. Extract SIFT features for current resolution
        # Note: SIFT matches must be scaled to current resolution
        matches = get_sift_matches(I_r, I_t, sift_matches, scale=2**current_level)
        
        # 4. Define Mask M based on minimum rectangle of SIFT matches
        M = create_mask_from_sift(matches, I_r.shape)
        
        # 5. Optimization Loop
        for step in range(num_training_steps):
            # Randomly select a patch Omega_p from I_r
            patch_coords, patch_gt_colors = sample_subpixel_patch(I_r, M)
            
            # Render from NeRF
            rendered_colors, rendered_depths = nerf_render(patch_coords, poses, intrinsics)
            
            # Compute Losses
            
            # Rendering Loss
            L_ren = mse(patch_gt_colors, rendered_colors)
            
            # 3D Feature Loss
            # Estimate 3D coords for SIFT matches
            feat_3d_r = estimate_3d_from_nerf(matches.r_coords, poses, intrinsics, nerf)
            feat_3d_t = estimate_3d_from_nerf(matches.t_coords, poses, intrinsics, nerf)
            L_3d = mse(feat_3d_r, feat_3d_t)
            
            # Epipolar Loss
            # Filter epipolar points by color similarity
            epipolar_points = get_epipolar_line(matches.r_coords, poses, intrinsics)
            valid_epipolar_points = filter_epipolar_by_color(epipolar_points, matches.r_colors, threshold=0.05)
            L_epi = min_distance_to_epipolar_line(feat_3d_r, valid_epipolar_points, nerf)
            
            # Photometric Consistency Loss
            # Warp reference patch to target view
            warped_coords = warp_to_target(patch_coords, poses, intrinsics)
            warped_colors = bilinear_interpolate(I_t, warped_coords)
            L_pr = l1(patch_gt_colors, warped_colors) * M
            
            # SSIM Loss
            L_ssim = ssim_loss(patch_gt_colors, warped_colors) * M
            
            # Depth Smooth Loss
            L_ds = depth_smooth_loss(rendered_depths, patch_gt_colors)
            
            # Total Loss
            L_total = (1.0 * L_ren + 
                       1.0 * L_3d + 
                       0.001 * L_pr + 
                       0.0001 * L_epi + 
                       0.008 * L_ssim + 
                       0.01 * L_ds)
            
            # Add Depth Prior Loss if not lowest level
            if current_level < num_levels - 1:
                # Sample from previous level's depth map
                prev_depth_map = get_depth_map_from_prev_level(current_level + 1)
                L_depth = l1(rendered_depths, interpolate_depth(prev_depth_map, patch_coords))
                L_total += L_depth
                
            # Backpropagate
            optimize(nerf, L_total)
            
        # Save depth map from this level for the next level's prior
        save_depth_map(current_level, nerf, poses, intrinsics)
        
        current_level -= 1
        
    return nerf

def estimate_3d_from_nerf(2d_coords, poses, intrinsics, nerf):
    """
    Estimate 3D coordinate of a 2D point by integrating NeRF samples along the ray.
    x_s = sum(w_j * (o + t_j * d))
    """
    rays = generate_rays(2d_coords, poses, intrinsics)
    samples = hierarchical_sampling(rays, nerf)
    weights = compute_transmittance_weights(samples)
    x_s = sum(weights * samples.positions)
    return x_s
```

### Parameters
*   **Loss Weights**: $\lambda_{ren} = 1.0$, $\lambda_{3D} = 1.0$, $\lambda_{pr} = 0.001$, $\lambda_{epi} = 0.0001$, $\lambda_{SSIM} = 0.008$, $\lambda_{ds} = 0.01$ [S1].
*   **Patch Size**: $32 \times 32$ pixels [S1].
*   **Sampling**: Hierarchical sampling with 64 coarse samples and 64 importance samples [S1].
*   **Optimizer**: Adam with $\beta_1 = 0.9$, $\beta_2 = 0.999$, learning rate $1e-3$ [S1].
*   **Pyramid Levels**: $L$ levels, where resolution halves at each step [S1].

### Edge Cases and Pitfalls
*   **Epipolar Points**: A large number of epipolar points causes computational inefficiency. Occluded points may not have corresponding points on the epipolar line. Solution: Filter implausible points using color similarity threshold [S1].
*   **Local Minima**: Large pixel motions can cause the photometric consistency loss to get stuck in local minima. Solution: Use the pyramidal strategy starting from low resolution [S1].
*   **Masking**: The mask $M$ must correctly identify pixels with valid correspondences. The minimum rectangle enclosing all SIFT features is used as a proxy [S1].

## Operating characteristics
*   **Time Complexity**: Higher than standard NeRF due to additional loss computations (SIFT matching, epipolar geometry, warping) and the pyramidal training strategy which requires multiple passes [S1].
*   **Memory Complexity**: Requires storing depth maps for each pyramid level and SIFT feature matches. The use of sub-pixel rendering increases the number of samples per pixel [S1].
*   **Performance**: Evaluated on LLFF-NeRF, ScanNet, and DTU MVS datasets. Surpasses state-of-the-art approaches given sparse inputs [S1].
*   **Strengths**: Improved geometric accuracy and novel view synthesis quality under sparse input conditions. Explicit constraints reduce 3D-shape ambiguity [S1].
*   **Limitations**: Computational cost of epipolar constraints and SIFT matching. Relies on the quality of SIFT feature matches.

## Background
SfMNeRF was proposed to address the failure of existing NeRF-based methods to obtain moderate 3D structures under sparse input conditions, where novel view synthesis quality drops dramatically due to implicitly reconstructed inaccurate 3D-scene structure [S1]. It leverages knowledge from self-supervised depth estimation methods to constrain the 3D-scene geometry during view synthesis training [S1]. The method integrates Structure-from-Motion (SfM) constraints, including matched feature positions, epipolar geometry, and multi-view photometric consistency, to explicitly reconstruct the 3D-scene structure [S1]. It was evaluated on LLFF-NeRF, ScanNet, and DTU MVS datasets [S1].
