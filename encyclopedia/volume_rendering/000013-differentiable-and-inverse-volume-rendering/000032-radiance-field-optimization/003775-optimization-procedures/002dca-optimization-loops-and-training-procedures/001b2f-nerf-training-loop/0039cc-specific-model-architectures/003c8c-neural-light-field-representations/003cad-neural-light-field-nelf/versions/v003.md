# Neural Light Field (NeLF)

Also called: Neural Light Field (NeLF) via R2L Distillation, Neural Light Field with Distillation, R2L (Neural Light Field with Distillation), R2L network

## Overview
Neural Light Field (NeLF) via R2L Distillation is a method for efficient novel view synthesis that represents a 3D scene as a Neural Light Field rather than a Neural Radiance Field (NeRF) [S1]. It maps camera ray origin and direction directly to RGB values, avoiding ray-marching and iterative sampling [S1]. The method distills a pre-trained NeRF teacher model into a deep residual MLP student model (NeLF), which maps a 4D oriented ray directly to 3D RGB color, bypassing the ray-marching and alpha-composition steps required by NeRF, resulting in a single forward pass per ray [S1]. It sets itself apart from shallow NeLF approaches by using an 88-layer deep residual network and from NeRF by eliminating the need for per-ray point sampling [S1].

## How it works
**Inputs and Outputs:**
The NeLF network $G_\phi$ takes a 4D oriented ray as input and outputs a 3D RGB color vector. The input ray is represented by concatenating the spatial coordinates of $K$ sampled points along the ray, forming a $3K$-dimensional vector [S1]. The output is the final pixel color $\mathbf{C}(\mathbf{r}) = (r, g, b)$ [S1].

**Data Structures:**
The network is a Multi-Layer Perceptron (MLP) with extensive residual blocks [S1].
*   **Architecture:** Deep Residual MLP. Configurations include W256D88 (12M FLOPs) and W181D88 (6M FLOPs), where W is width and D is depth [S1].
*   **Layers:** 88 layers total [S1].
*   **Internal Structure:** Uses intensive residual blocks [14] in internal layers [S1].
*   **Input Encoding:** Positional encoding is used to enrich input information, following NeRF [53] [S1].

**Parameters:**
*   $K$: Number of sampled points along a ray. Default value: 16 [S1].
*   $r$: Hard example mining selection rate. Default value: 0.2. Tested values: $\{0, 0.1, 0.2, 0.3\}$ [S1].
*   $S$: Pseudo sample size (number of pseudo images). Default: 10k. Performance saturates around 5k [S1].
*   Batch Size: 98,304 rays per batch [S1].
*   Iterations: 1,000k iterations [S1].
*   Learning Rate: Initial $5 \times 10^{-4}$, decayed during training [S1].
*   Optimizer: Adam [S1].
*   Hardware: 8 NVIDIA V100 GPUs [S1].
*   Framework: PyTorch 1.9 [S1].

**Algorithm Steps:**

1.  **Teacher Pre-training:** Train a standard NeRF teacher model $F_{\Theta^*}$ on the original training images to convergence [S1].
2.  **Pseudo Data Generation:**
    *   Infer a viewing bounding box from the training data camera poses [S1].
    *   Randomly sample ray origins $(x_o, y_o, z_o)$ and normalized directions $(x_d, y_d, z_d)$ from a uniform distribution $U$ within the bounding box [S1]:
        $$
        \begin{aligned}
        x_o &\sim U(x_{o,\min}, x_{o,\max}), & x_d &\sim U(x_{d,\min}, x_{d,\max}) \\
        y_o &\sim U(y_{o,\min}, y_{o,\max}), & y_d &\sim U(y_{d,\min}, y_{d,\max}) \\
        z_o &\sim U(z_{o,\min}, z_{o,\max}), & z_d &\sim U(z_{d,\min}, z_{d,\max})
        \end{aligned}
        $$
        [S1]
    *   Query the pre-trained NeRF teacher $F_{\Theta^*}$ with the sampled 6D input to obtain the target RGB value $(\hat{r}, \hat{g}, \hat{b})$ [S1]:
        $$
        (\hat{r}, \hat{g}, \hat{b}) = F_{\Theta^*}(x_o, y_o, z_o, x_d, y_d, z_d)
        $$
        [S1]
    *   Store the tuple $(x_o, y_o, z_o, x_d, y_d, z_d, \hat{r}, \hat{g}, \hat{b})$ as a pseudo training sample [S1].
    *   Repeat to generate $S$ pseudo images (default 10k) [S1].
3.  **NeLF Training Setup:**
    *   Initialize the deep residual MLP $G_\phi$ (e.g., W256D88) [S1].
    *   Initialize a hard example pool [S1].
4.  **Training Loop (for 1,000k iterations):**
    *   **Ray Sampling:** For each ray in the batch, sample $K=16$ points along the ray using **stratified sampling** to prevent overfitting to specific point locations [S1].
    *   **Input Construction:** Concatenate the spatial coordinates of the $K$ sampled points to form the $3K$-dimensional input vector [S1].
    *   **Forward Pass:** Compute the predicted RGB $\mathbf{C}_{pred} = G_\phi(\text{input})$ [S1].
    *   **Loss Calculation:** Compute the Mean Squared Error (MSE) loss between the NeLF output and the NeRF teacher's output [S1]:
        $$
        L = \text{MSE}(G_\phi(x_o, y_o, z_o, x_d, y_d, z_d), (\hat{r}, \hat{g}, \hat{b}))
        $$
        [S1]
    *   **Hard Example Mining:**
        *   Sort the batch losses in ascending order [S1].
        *   Add the top $r$ (default 0.2) fraction of samples to the hard example pool [S1].
        *   Randomly pick $r$ fraction of samples from the pool to augment the current training batch [S1].
    *   **Optimization:** Update $\phi$ using the Adam optimizer with the initial learning rate $5 \times 10^{-4}$ and the same decay schedule as the teacher NeRF [S1].
5.  **Inference (Testing):**
    *   For each ray, sample $K=16$ points **evenly spaced** along the ray [S1].
    *   Concatenate coordinates to form input [S1].
    *   Query $G_\phi$ once to get the final RGB color [S1].

    def __init__(self, width):
        super(ResidualBlock, self).__init__()

        self.fc2 = nn.Linear(width, width)

        identity = x

**Edge Cases and Pitfalls:**
*   **Trainability:** Deep networks for NeRF/NeLF suffer from diminishing returns if not designed carefully; residual connections are critical to enable greater depth. Without residuals, the network is barely trainable [S1].
*   **Overfitting:** Deep networks require abundant data. Using only original training images (typically <100) leads to severe overfitting. Pseudo data is essential [S1].
*   **Input Representation:** Concatenated coordinates perform better than Plücker coordinates for this specific architecture (PSNR 29.50 vs 29.08 on Lego) [S1].
*   **Reflections:** Unlike methods relying on ground-truth depth (e.g., DONeRF), NeLF does not fail on reflective surfaces because it does not use depth supervision [S1].

## Subtopics

### Neural Light Field Representations
The parent family of methods that compute a radiance field function $f_\theta(\mathbf{x}, \mathbf{d})$ or a light field function mapping rays to colors. NeLF is a specific instance that maps rays directly to RGB [Parent](9273-neural-light-field-representations.md).

### NeRF Training Loop
NeLF training relies on a pre-trained NeRF teacher, which is typically trained using the standard NeRF training loop [Parent](9273-neural-light-field-representations.md).

## Operating characteristics
*   **Time Complexity:** Single forward pass per ray. FLOPs reduction of 26–35× per camera ray compared to NeRF [S1].
*   **Memory Complexity:** Storage size of 23.7 MB for the W256D88 model, compared to 2.4 MB for the teacher NeRF (due to larger network size) [S1].
*   **Measured Performance:**
    *   **Speed:** 28–31× wall-time speedup on synthetic scenes compared to NeRF [S1]. 2× faster than DONeRF-16-noGT [S1].
    *   **Quality:** 1.4–2.8 dB average PSNR improvement over NeRF on synthetic scenes [S1]. On NeRF synthetic dataset, Ours-2 achieves 31.87 PSNR (+1.40 over teacher) [S1]. On DONeRF synthetic dataset, Ours-2 achieves 35.45 PSNR (+2.78 over teacher) [S1].
*   **Scaling:** Performance saturates with pseudo sample size around 5k images [S1]. Hard example ratio $r$ has diminishing returns above 0.1 [S1].
*   **Strengths:** Single forward pass, no ray marching, no ground-truth depth required, handles reflections well, high quality.
*   **Limitations:** Requires a pre-trained NeRF teacher, deep network training requires large pseudo datasets, storage size is larger than shallow NeRF variants.

## Background
*   **Origin:** Proposed by Wang et al. in "R2L: Distilling Neural Radiance Field to Neural Light Field for Efficient Novel View Synthesis" [S1].
*   **History:** The method addresses the efficiency bottleneck of NeRF, which requires multiple forward passes per ray. It builds on the idea of Neural Light Fields but improves quality and speed by using a deep residual network and knowledge distillation from NeRF [S1].
*   **Usage:** Used for efficient novel view synthesis in computer graphics and vision, particularly where real-time or high-speed rendering is required without sacrificing quality [S1].
