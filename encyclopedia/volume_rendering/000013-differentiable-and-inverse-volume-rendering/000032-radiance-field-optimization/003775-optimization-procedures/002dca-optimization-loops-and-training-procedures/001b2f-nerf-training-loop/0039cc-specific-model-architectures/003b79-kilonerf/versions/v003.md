# KiloNeRF

Also called: KiloNeRF: Speeding up Neural Radiance Fields with Thousands of Tiny MLPs

## Overview
KiloNeRF is a spatial decomposition method that accelerates Neural Radiance Field (NeRF) rendering by replacing a single large deep MLP with thousands of small, shallow MLPs arranged in a 3D grid [S1][S2, S3, unofficial]. It solves the problem of high per-point computational cost and memory overhead associated with standard NeRFs by distilling a teacher NeRF's knowledge into these lightweight student networks [S1][S2, unofficial]. Unlike sibling methods that may use octrees or voxel features, KiloNeRF explicitly uses a teacher-student training paradigm to ensure each tiny MLP captures only the local scene information required for its specific grid cell [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A pre-trained standard NeRF (the "teacher") serving as the knowledge source; a 3D grid structure defining spatial partitioning.
*   **Output:** A set of lightweight MLPs (the "students") and a cached sparse 3D grid for surface localization, enabling real-time rendering of novel views.

**Data Structures:**
1.  **3D Grid:** A spatial partitioning of the scene volume. The grid is sparse, caching only occupied regions to quickly locate the surface [S3, unofficial].
2.  **Student MLPs:** A collection of small, shallow neural networks. Each MLP is associated with a specific region or cell in the 3D grid [S1][S2, unofficial].
    *   **Layout:** Each MLP takes 3D coordinates $\mathbf{x}$ and viewing direction $\mathbf{d}$ as input and outputs volume density $\sigma$ and color $\mathbf{c}$ [S1][S2, unofficial].
    *   **Size:** Significantly smaller and shallower than the original NeRF MLP, as each only needs to capture local information [S2, unofficial].

**Algorithm Steps:**
1.  **Teacher Training:** Train a standard, deep NeRF on the scene data to convergence [S1].
2.  **Spatial Decomposition:** Partition the 3D space into a grid of cells [S1][S2, unofficial].
3.  **Student Initialization:** Initialize a lightweight MLP for each grid cell [S1][S3, unofficial].
4.  **Knowledge Distillation:** Distill the teacher NeRF's knowledge into the student MLPs. This involves training the students to mimic the teacher's outputs ($\sigma, \mathbf{c}$) for queries within their respective spatial regions [S1].
5.  **Surface Localization Cache:** Build a cached sparse 3D grid to accelerate surface localization during rendering, allowing the system to skip empty space [S3, unofficial].
6.  **Rendering:** For a given ray, use the sparse grid to identify relevant cells. Load the corresponding student MLPs dynamically and compute density and color [S2, unofficial].

**Formulas:**
The rendering equation remains the standard volume rendering integral [S1][S2, unofficial]:
$$
\mathbf{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i, \quad \alpha_i = 1 - \exp(-\sigma_i \delta_i), \quad T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)
$$
Where $\sigma_i$ and $\mathbf{c}_i$ are output by the specific student MLP associated with the spatial region containing sample point $i$ [S1][S2, unofficial].

**Parameters:**
*   **Grid Resolution:** Not given in the sources.
*   **Student MLP Depth/Width:** Not given in the sources, but described as "tiny" and "shallow" [S1][S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Memory Overhead:** Deploying a large number of MLPs incurs substantial memory overhead [S1].
*   **Dynamic Loading:** During rendering, a ray traverses different sets of NeRFs, each requiring a different number of samples. This necessitates dynamic parameter loading, which requires special CUDA kernels for proper speedup [S2, unofficial].

**Pseudocode:**
```python
# KiloNeRF Rendering Logic
# Assumes pre-trained Teacher NeRF and distilled Student MLPs are available

def render_ray_kilonerf(ray_origin, ray_direction, student_mpls, sparse_grid):
    """
    Renders a single ray using KiloNeRF.
    
    Args:
        ray_origin: 3D vector, origin of the ray.
        ray_direction: 3D vector, direction of the ray.
        student_mpls: Dictionary mapping grid_cell_id -> StudentMLP.
        sparse_grid: Sparse 3D grid structure for fast surface localization.
        
    Returns:
        color: 3D vector, rendered color.
    """
    # 1. Use sparse grid to find relevant cells along the ray
    # This step skips empty space, focusing on occupied regions [S3, unofficial]
    relevant_cells = sparse_grid.query_along_ray(ray_origin, ray_direction)
    
    # 2. Collect samples and compute radiance
    # Note: Dynamic loading of MLPs is required as different cells 
    # have different MLPs [S2, unofficial]
    total_color = [0.0, 0.0, 0.0]
    transmittance = 1.0
    
    # Sort cells by distance from camera to ensure correct ordering
    relevant_cells.sort(key=lambda cell: cell.distance_from_origin)
    
    for cell in relevant_cells:
        # Get the specific student MLP for this cell
        student_mlp = student_mpls[cell.id]
        
        # Sample points within this cell's bounds along the ray
        # The number of samples may vary per cell [S2, unofficial]
        samples = get_samples_along_ray_segment(ray_origin, ray_direction, cell.bounds)
        
        for sample in samples:
            # Query the student MLP for density and color
            # Input: 3D coordinate and viewing direction
            sigma, color = student_mlp.forward(sample.position, ray_direction)
            
            # Compute alpha
            delta = sample.distance_to_previous
            alpha = 1.0 - math.exp(-sigma * delta)
            
            # Accumulate color
            weight = transmittance * alpha
            total_color += weight * color
            
            # Update transmittance
            transmittance *= (1.0 - alpha)
            
            # Early termination if transmittance is negligible
            if transmittance < 1e-5:
                break
                
    return total_color
```

## Subtopics

### Spatial Decomposition
KiloNeRF decomposes the scene into small portions, allowing each MLP to be shallow [S2, unofficial]. Choose this when memory bandwidth and per-point computation are bottlenecks. See [Specific Model Architectures](8585-specific-model-architectures.md).

### Teacher-Student Distillation
The method relies on distilling a large teacher model into many small students [S1]. Choose this when high-quality initialization is needed for small models. See [Specific Model Architectures](8585-specific-model-architectures.md).

## Operating characteristics
*   **Time Complexity:** Acceleration of up to three orders of magnitude compared to the original NeRF [S1].
*   **Memory Complexity:** Substantial memory overhead due to the deployment of a large number of MLPs [S1].
*   **Strengths:** Significant speedup in rendering; efficient per-point computation due to small MLPs [S1][S2, unofficial].
*   **Limitations:** High memory usage; requires dynamic parameter loading which complicates implementation and requires specialized CUDA kernels [S2, unofficial].
*   **When to use:** When real-time or near-real-time rendering is required and memory is not the primary constraint.
*   **When not to use:** When memory bandwidth is severely limited or when a single global model is preferred for simplicity.

## Background
KiloNeRF was introduced by Reiser et al. in 2021 [S1]. It was developed to address the inefficiency of standard NeRFs, which sample the entire ray even though only a small fraction of samples contribute to the final image [S1]. The method builds on the idea of spatial decomposition and knowledge distillation to create a scalable solution for real-time view synthesis [S1][S2, unofficial].
