# HyperNeRFGAN

Also called: HyperNeRFGAN: Hypernetwork approach to 3D NeRF GAN

## Overview
HyperNeRFGAN is a generative adversarial network (GAN) architecture that synthesizes 3D-aware radiance fields by using a hypernetwork to generate the weights of a simplified NeRF target network from a Gaussian noise vector [S1, unofficial]. It solves the problem of 3D-aware image generation when camera positions are unavailable or difficult to estimate, which is common in medical imaging and datasets with limited viewpoints [S1, unofficial]. Unlike standard NeRF-based GANs (e.g., GRAF, π-GAN) that condition a SIREN network on viewing directions, HyperNeRFGAN removes viewing directions from the NeRF input entirely and uses Factorized Multiplicative Modulation (FMM) layers to inject the generated weights, enabling training on unlabeled views or single images per object [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A noise vector $\mathbf{z}$ sampled from a standard Gaussian distribution $P_{\text{noise}}$.
*   **Output:** A rendered 2D image $\mathbf{x}$ generated by ray-marching through the instantiated NeRF.

**Data Structures:**
1.  **Generator ($G$):** A StyleGAN2-based architecture that maps $\mathbf{z}$ to the weights of the target NeRF. It outputs modulation matrices $A$ and $B$ for each layer of the NeRF.
2.  **Target NeRF ($F_\theta$):** A single Multi-Layer Perceptron (MLP) that maps 3D spatial coordinates to color and density. It does not accept viewing directions.
    *   **Layer Structure:** Uses Factorized Multiplicative Modulation (FMM) layers.
    *   **FMM Layer Parameters:**
        *   $W$: Shared weight matrix (dimensions $n_{\text{out}} \times n_{\text{in}}$).
        *   $b$: Shared bias vector (dimensions $n_{\text{out}}$).
        *   $A$: Modulation matrix generated by $G$ (dimensions $n_{\text{out}} \times k$).
        *   $B$: Modulation matrix generated by $G$ (dimensions $k \times n_{\text{in}}$).
        *   $k$: Rank parameter controlling the expressiveness and memory usage of the modulation. Default value: $k=10$ [S1, unofficial].
3.  **Discriminator ($D$):** A standard 2D CNN discriminator that evaluates the realism of rendered 2D images.

**Parameters:**
*   **Hidden Layer Channels:** Reduced from the standard NeRF's 256 to 128 to reduce computational cost [S1, unofficial].
*   **Network Depth:** Reduced from the standard 8 layers to 4 layers in some experiments to reduce computational cost [S1, unofficial].
*   **Rendering Scale:** Only the "coarse" network is used; the "fine" network from standard NeRF is rejected to reduce training cost [S1, unofficial].

**Numbered Steps:**
1.  Sample a noise vector $\mathbf{z} \sim P_{\text{noise}}$ (Gaussian distribution) [S1, unofficial].
2.  Pass $\mathbf{z}$ through the Generator $G$ to obtain the modulation matrices $A$ and $B$ for each layer of the target NeRF [S1, unofficial].
3.  Instantiate the target NeRF $F_\theta$ using the shared weights $W, b$ and the generated modulations $A, B$. The FMM layer computes the output $\mathbf{y}$ for an input $\mathbf{x}_{\text{in}}$ as:
    $$ \mathbf{y} = W \odot (A \times B) \cdot \mathbf{x}_{\text{in}} + \mathbf{b} = \tilde{W} \cdot \mathbf{x}_{\text{in}} + \mathbf{b} $$
    where $\tilde{W} = W \odot (A \times B)$ [S1, unofficial].
4.  The instantiated NeRF $F_\theta$ takes a 3D spatial position $\mathbf{x} = (x, y, z)$ as input and outputs volume density $\sigma(\mathbf{x})$ and color $\mathbf{c}(\mathbf{x})$. Note that viewing direction $\mathbf{d}$ is **not** an input [S1, unofficial].
5.  Render a 2D image by ray-marching through the NeRF from a chosen camera perspective.
6.  Evaluate the rendered image and real images from the dataset using the Discriminator $D$.
7.  Update $G$ and $D$ by minimizing the GAN loss function:
    $$ \min_G \max_D V(D, G) $$
    where:
    $$ V(D, G) = \mathbb{E}_{\mathbf{x} \sim P_{\text{data}}}[\log D(\mathbf{x})] + \mathbb{E}_{\mathbf{z} \sim P_{\text{noise}}}[\log(1 - D(G(\mathbf{z})))] $$
    [S1, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class FMMLayer(nn.Module):
    """
    Factorized Multiplicative Modulation Layer.
    W, b are shared weights. A, B are generated by the hypernetwork.
    """
    def __init__(self, n_in, n_out, k):
        super().__init__()
        self.n_in = n_in
        self.n_out = n_out
        self.k = k
        # Shared weights
        self.W = nn.Parameter(torch.randn(n_out, n_in))
        self.b = nn.Parameter(torch.zeros(n_out))
        
    def forward(self, x_in, A, B):
        # A: (n_out, k), B: (k, n_in)
        # Compute effective weight matrix: W ~ (W * (A @ B))
        # Note: Broadcasting rules apply. 
        # W is (n_out, n_in). A@B is (n_out, n_in).
        effective_W = self.W * (A @ B)
        return effective_W @ x_in + self.b

class HyperNeRFGAN:
    def __init__(self, n_layers=4, hidden_dim=128, k=10):
        """
        Initialize HyperNeRFGAN.
        n_layers: Number of layers in the target NeRF.
        hidden_dim: Hidden dimension size (reduced from 256 to 128).
        k: Rank of modulation matrices.
        """
        super().__init__()
        self.k = k
        self.n_layers = n_layers
        self.hidden_dim = hidden_dim
        
        # Generator (Hypernetwork) - Simplified structure for illustration
        # In practice, this is a StyleGAN2 backbone
        self.generator = StyleGAN2Generator() 
        
        # Target NeRF Layers
        # Input: 3D position (x, y, z)
        # Output: Color (c) and Density (sigma)
        # We split the output into two heads or use two networks. 
        # The source describes a single MLP F_theta.
        # For implementation, we assume two parallel streams or a split output.
        # Here we define the layers.
        self.layers = nn.ModuleList()
        
        # Input layer
        self.layers.append(FMMLayer(3, hidden_dim, k))
        
        # Hidden layers
        for _ in range(n_layers - 2):
            self.layers.append(FMMLayer(hidden_dim, hidden_dim, k))
            
        # Output layer
        # Output size: 4 (3 for color + 1 for density)
        self.layers.append(FMMLayer(hidden_dim, 4, k))

    def get_modulations(self, z):
        """
        Generate modulation matrices A and B from noise z.
        Returns a list of tuples (A, B) for each layer.
        """
        # Placeholder for StyleGAN2 forward pass logic
        # The generator outputs parameters for A and B matrices
        modulations = []
        for i in range(self.n_layers):
            # In a real implementation, G(z) outputs specific tensors for A and B
            # Here we assume a helper function that produces A and B
            A, B = self.generator.get_layer_modulations(z, i)
            modulations.append((A, B))
        return modulations

    def render(self, z, rays):
        """
        Render an image given noise z and ray origins/directions.
        rays: Tensor of shape (H, W, 3) representing ray origins.
        Note: Viewing directions are NOT used in F_theta.
        """
        modulations = self.get_modulations(z)
        
        # Initialize ray marching state
        # This is a simplified ray marching loop
        # Standard NeRF uses coarse/fine networks. HyperNeRFGAN uses only coarse.
        
        # Sample points along rays
        # t_vals = ...
        # xyz = origins + directions * t_vals.unsqueeze(-1)
        # However, since we don't use directions in F_theta, 
        # we only pass xyz to the network.
        
        # Forward pass through NeRF
        x = xyz.reshape(-1, 3) # (N_points, 3)
        
        for i, layer in enumerate(self.layers):
            A, B = modulations[i]
            # A shape: (n_out, k), B shape: (k, n_in)
            # x shape: (N_points, n_in)
            x = layer(x, A, B)
            
        # Reshape output
        # x is now (N_points, 4) -> (sigma, r, g, b)
        sigma = x[..., 0]
        color = torch.sigmoid(x[..., 1:])
        
        # Standard volumetric rendering (alpha blending)
        # weights = ...
        # image = sum(weights * color)
        # This part is standard NeRF rendering, not specific to HyperNeRFGAN's unique architecture
        # but required to produce the output.
        image = standard_volume_rendering(xyz, sigma, color, rays)
        
        return image

    def train_step(self, real_images, z_batch):
        """
        One training iteration.
        """
        # 1. Generate fake images
        fake_images = self.render(z_batch, rays) # Rays sampled from camera poses
        
        # 2. Discriminator Loss
        # D(real) should be 1, D(fake) should be 0
        d_real = self.discriminator(real_images)
        d_fake = self.discriminator(fake_images.detach())
        
        loss_d = -torch.mean(torch.log(d_real + 1e-8)) - torch.mean(torch.log(1 - d_fake + 1e-8))
        
        # 3. Generator Loss
        d_fake_gen = self.discriminator(fake_images)
        loss_g = -torch.mean(torch.log(d_fake_gen + 1e-8))
        
        # 4. Update weights
        loss_d.backward()
        self.discriminator_optimizer.step()
        
        loss_g.backward()
        self.generator_optimizer.step()
        
        return loss_d, loss_g
```

**Edge Cases and Pitfalls:**
*   **View-Dependent Effects:** The model assumes training images lack view-dependent characteristics (e.g., reflections). If such effects are present, performance may degrade because viewing directions are omitted [S1, unofficial].
*   **Computational Cost:** The original NeRF's "fine" network is omitted. Using it would increase cost significantly [S1, unofficial].
*   **Rank $k$:** Higher values of $k$ increase expressiveness but also memory usage. The default $k=10$ is a trade-off [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Training time is reduced compared to standard NeRF-based GANs due to the use of a single "coarse" network, reduced hidden dimensions (128 vs 256), and reduced depth (4 vs 8 layers) [S1, unofficial].
*   **Memory Complexity:** Memory usage is controlled by the rank parameter $k$ of the FMM layers. Higher $k$ increases memory requirements [S1, unofficial].
*   **Performance:**
    *   **ShapeNet Car:** FID 29.6 (vs Point2NeRF 82.1) [S1, unofficial].
    *   **CARLA Dataset:** FID 20.5, KID 0.78, IS 4.20. Outperforms HoloGAN (FID 67.5), GRAF (FID 41.7), and $\pi$-GAN (FID 29.2) [S1, unofficial].
    *   **CelebA Dataset:** FID 15.04, KID 0.66, IS 2.63. Comparable to $\pi$-GAN (FID 14.7, KID 0.39, IS 2.62) [S1, unofficial].
    *   **Medical (DRR):** Superior performance compared to MedNeRF and UMedNeRF in FID and KID metrics [S1, unofficial].
*   **Strengths:**
    *   Does not require camera position information during training [S1, unofficial].
    *   Can be trained on datasets with limited viewpoints or even single unlabeled views per object [S1, unofficial].
    *   Simpler architecture than SIREN-based conditioning methods (GRAF, $\pi$-GAN) [S1, unofficial].
*   **Limitations:**
    *   Cannot model view-dependent effects (e.g., specular highlights) effectively [S1, unofficial].
    *   Quality may be inferior to SIREN-based models if view-dependent effects are present [S1, unofficial].

## Background
HyperNeRFGAN was introduced in a 2023 preprint by authors associated with the "HyperNeRFGAN: Hypernetwork approach to 3D NeRF GAN" paper [S1, unofficial]. It builds on the hypernetwork paradigm (Ha et al., 2016) and the INRGAN architecture, which uses StyleGAN2 to generate continuous image representations. It addresses limitations in existing 3D-aware GANs like GRAF and $\pi$-GAN, which rely on SIREN networks and require conditioning mechanisms that can be complex and less effective for certain datasets [S1, unofficial]. The model is particularly suited for medical applications (e.g., Digitally Reconstructed Radiographs) and datasets where camera calibration is challenging [S1, unofficial].
