# HyperNeRFGAN

Also called: HyperNeRF GAN, Hypernetwork NeRF GAN

## Overview
HyperNeRFGAN is a generative adversarial network (GAN) that synthesizes 3D-aware radiance fields by using a hypernetwork to generate the weights of a simplified NeRF target model from a Gaussian noise vector [S1, unofficial]. It solves the problem of 3D-aware image generation when camera positions are unavailable or unreliable, which is common in medical imaging and single-view datasets [S1, unofficial]. Unlike standard NeRF or other 3D-aware GANs (e.g., GRAF, π-GAN) that condition on viewing directions or use SIREN-based conditioning, HyperNeRFGAN removes viewing direction inputs entirely and employs Factorized Multiplicative Modulation (FMM) layers to allow the hypernetwork to modulate the target network's weights efficiently [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Generator Input:** A noise vector $\mathbf{z}$ sampled from a standard Gaussian distribution $\mathcal{N}(0, I)$ [S1, unofficial].
*   **Generator Output:** The weights $\Theta$ of the target NeRF network [S1, unofficial].
*   **Target NeRF Input:** A 3D spatial position $\mathbf{x} = (x, y, z)$ [S1, unofficial].
*   **Target NeRF Output:** Volume density $\sigma$ and emitted color $\mathbf{c}$ [S1, unofficial].
*   **Discriminator Input:** 2D rendered images (real or generated) [S1, unofficial].
*   **Discriminator Output:** A scalar probability indicating whether the image is real or fake [S1, unofficial].

**Data Structures:**
The target NeRF is a single Multi-Layer Perceptron (MLP) $F_\Theta$.
*   **Architecture:** The MLP consists of hidden layers using Factorized Multiplicative Modulation (FMM) layers.
*   **FMM Layer Parameters:**
    *   $W$: Shared weight matrix of size $n_{out} \times n_{in}$ [S1, unofficial].
    *   $b$: Shared bias vector of size $n_{out}$ [S1, unofficial].
    *   $A$: Modulation matrix of size $n_{out} \times k$, generated by the generator [S1, unofficial].
    *   $B$: Modulation matrix of size $k \times n_{in}$, generated by the generator [S1, unofficial].
    *   $k$: Rank parameter controlling the expressiveness and memory usage of the modulation. The source specifies $k=10$ [S1, unofficial].
*   **Target Network Dimensions:**
    *   Hidden layer channels: 128 (reduced from standard 256) [S1, unofficial].
    *   Network depth: 4 to 8 layers (standard NeRF uses 8 layers for coarse and 8 for fine; HyperNeRFGAN uses only the coarse network, reduced to 4 layers in some experiments) [S1, unofficial].

**Numbered Steps:**
1.  **Sample Noise:** Sample a noise vector $\mathbf{z} \sim \mathcal{N}(0, I)$ [S1, unofficial].
2.  **Generate Weights:** Pass $\mathbf{z}$ through the Generator network $G$ to produce the modulation matrices $A$ and $B$ for all FMM layers in the target NeRF [S1, unofficial].
3.  **Instantiate Target NeRF:** Construct the target NeRF model $F_\Theta$ using the shared weights $W, b$ and the generated modulation matrices $A, B$ [S1, unofficial].
4.  **Render Image:** Sample rays from various camera perspectives. For each ray, query the target NeRF $F_\Theta$ at discrete points $\mathbf{x}_i$ along the ray to obtain $\sigma_i$ and $\mathbf{c}_i$. Note that $\mathbf{d}$ is not an input [S1, unofficial].
5.  **Volume Integration:** Compute the pixel color $C(r)$ using standard volume rendering integration:
    $$ C(r) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i, \quad T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right), \quad \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
    [S1, unofficial] (Note: The source states the "fine" network is rejected, so only the "coarse" network is used for rendering) [S1, unofficial].
6.  **Discriminator Evaluation:** Feed the rendered image and real images into the Discriminator $D$ [S1, unofficial].
7.  **Update Weights:** Update the Generator $G$ and Discriminator $D$ using the standard GAN minimax objective [S1, unofficial].

**Formulas:**
The FMM layer operation is defined as [S1, unofficial]:
$$ \mathbf{y} = W \odot (A \times B) \cdot \mathbf{x}_{in} + \mathbf{b} = \tilde{W} \cdot \mathbf{x}_{in} + \mathbf{b} $$
Where $\odot$ is element-wise multiplication, $\times$ is matrix multiplication, and $\tilde{W} = W \odot (A \times B)$ is the effective weight matrix [S1, unofficial].

The GAN training objective is [S1, unofficial]:
$$ \min_G \max_D V(D, G) $$
$$ V(D, G) = \mathbb{E}_{\mathbf{x} \sim P_{data}}[\log D(\mathbf{x})] + \mathbb{E}_{\mathbf{z} \sim P_{noise}}[\log(1 - D(G(\mathbf{z})))] $$
Where $P_{data}$ is the distribution of real 2D images and $P_{noise}$ is the Gaussian noise distribution [S1, unofficial].

**Parameters:**
*   $k$ (Rank of modulation): 10 [S1, unofficial].
*   Hidden channels: 128 [S1, unofficial].
*   Layers: 4–8 [S1, unofficial].

**Pseudocode:**

import torch
import torch.nn as nn
import torch.nn.functional as F

class FMMLayer(nn.Module):
    """
    Factorized Multiplicative Modulation Layer.
    W and b are shared and fixed during GAN training (weights of the NeRF).
    A and B are generated by the Generator G for each sample.
    """
    def __init__(self, n_in, n_out, k):
        super().__init__()
        # Shared weights (part of the NeRF structure, not optimized directly)
        self.W = nn.Parameter(torch.randn(n_out, n_in) * 0.02)
        self.b = nn.Parameter(torch.zeros(n_out))
        self.k = k
        self.n_in = n_in
        self.n_out = n_out

    def forward(self, x_in, A, B):
        # A: (n_out, k), B: (k, n_in)
        # Effective weight matrix: W_mod = W * (A @ B)
        # Note: Source uses element-wise multiplication for W and matrix product for A@B
        # y = W * (A @ B) @ x_in + b
        W_mod = self.W * (A @ B)
        return F.linear(x_in, W_mod, self.b)

            nn.Linear(z_dim, n_in * k + n_out * k) for _ in range(n_layers)

class TargetNeRF(nn.Module):
    """
    The target NeRF model whose weights are modulated by the Generator.
    Input: x (3D position). Output: sigma, color.
    """
    def __init__(self, n_layers, n_in, n_out, k):
        super().__init__()
        self.layers = nn.ModuleList()
        # First layer
        self.layers.append(FMMLayer(n_in, n_out, k))
        # Hidden layers
        for _ in range(n_layers - 2):
            self.layers.append(FMMLayer(n_out, n_out, k))
        # Output layer (separate for sigma and color usually, but source implies single MLP output)
        # Source says F_theta: x -> (c, sigma). 
        # We'll assume two output heads or concatenated output.
        self.sigma_head = FMMLayer(n_out, 1, k)
        self.color_head = FMMLayer(n_out, 3, k)

    def forward(self, x, modulations):
        """
        x: (B, 3)
        modulations: list of (A, B) tuples for each layer
        """
        h = x
        for i, layer in enumerate(self.layers):
            A, B = modulations[i]
            h = layer(h, A, B)
        
        sigma = self.sigma_head(h, modulations[-1][0], modulations[-1][1])
        color = self.color_head(h, modulations[-1][0], modulations[-1][1])
        
        return sigma, color

def render_ray(ray_origin, ray_direction, t_near, t_far, nerf, modulations, n_samples):
    """
    Standard volume rendering along a single ray.
    """
    t_vals = torch.linspace(t_near, t_far, n_samples)
    deltas = t_vals[1:] - t_vals[:-1]
    deltas = torch.cat([deltas, torch.tensor([0.001])], dim=0)
    
    xyz = ray_origin.unsqueeze(1) + ray_direction.unsqueeze(1) * t_vals.unsqueeze(0).T
    
    sigma, color = nerf(xyz, modulations)
    
    # Alpha calculation
    alpha = 1.0 - torch.exp(-sigma * deltas)
    
    # Transmittance
    T = torch.cumprod(torch.exp(-torch.cat([torch.zeros_like(sigma[:, :1]), sigma[:, :-1] * deltas[:, :-1]]), dim=1), dim=1)
    
    # Contribution
    contributions = alpha * T * color
    
    # Final color
    final_color = torch.sum(contributions, dim=1)
    
    return final_color

    fake_images = []
    for cam in camera_params:

        pass
    fake_images = torch.stack(fake_images)
    
    # 3. Discriminator Loss
    real_pred = discriminator(real_images)
    fake_pred = discriminator(fake_images.detach())
    
    d_loss = -torch.mean(torch.log(real_pred + 1e-8)) - torch.mean(torch.log(1 - fake_pred + 1e-8))
    
    optimizer_d.zero_grad()
    d_loss.backward()

    fake_pred_gen = discriminator(fake_images)
    g_loss = -torch.mean(torch.log(fake_pred_gen + 1e-8))
    
    optimizer_g.zero_grad()
    g_loss.backward()
    optimizer_g.step()
    
    return d_loss, g_loss

**Edge Cases and Pitfalls:**
*   **Viewing Direction:** The model explicitly omits viewing direction $\mathbf{d}$ from the NeRF input. This is a design choice for datasets lacking camera poses, but it means the model cannot represent view-dependent effects like specular reflections [S1, unofficial].
*   **Fine Network:** The standard NeRF "fine" network is discarded to reduce computational cost. This may limit the quality of fine details compared to full NeRF [S1, unofficial].
*   **Rank $k$:** The parameter $k$ controls the trade-off between expressiveness and memory. A higher $k$ increases memory usage significantly [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Training is computationally expensive due to the hypernetwork generating weights for every iteration, but less expensive than full NeRF optimization per image because it uses only the coarse network and reduced hidden dimensions (128 channels, 4-8 layers) [S1, unofficial].
*   **Memory Complexity:** Memory usage is influenced by the rank $k$ of the modulation matrices. The source specifies $k=10$ [S1, unofficial].
*   **Performance:**
    *   **ShapeNet Car:** FID 29.6 (vs Point2NeRF 82.1) [S1, unofficial].
    *   **CARLA:** FID 20.5, KID 0.78, IS 4.20 (outperforms HoloGAN, GRAF, and is comparable to $\pi$-GAN) [S1, unofficial].
    *   **CelebA:** FID 15.04, KID 0.66, IS 2.63 (comparable to $\pi$-GAN) [S1, unofficial].
    *   **Medical (DRR):** Superior performance over MedNeRF and UMedNeRF in FID/KID metrics [S1, unofficial].
*   **Strengths:** Does not require camera poses; simple architecture; high-quality 3D-aware generation on datasets with few views or no poses.
*   **Limitations:** Cannot model view-dependent effects (no $\mathbf{d}$ input); limited by the "coarse" network only; performance on complex scenes with reflections may be lower than SIREN-based methods if poses are available.

## Background
HyperNeRFGAN was introduced in a paper titled "HyperNeRFGAN: Hypernetwork approach to 3D NeRF GAN" [S1, unofficial]. It builds on the hypernetwork paradigm [Ha et al., 2016] and the INR-GAN architecture [S1, unofficial], adapting them to NeRF. It addresses the limitations of previous 3D-aware GANs like GRAF and $\pi$-GAN, which rely on SIREN and conditioning mechanisms that are complex to integrate with NeRF's volumetric rendering [S1, unofficial]. The method is particularly targeted at medical imaging applications (Digitally Reconstructed Radiographs) and datasets like CARLA where camera estimation is difficult [S1, unofficial].
