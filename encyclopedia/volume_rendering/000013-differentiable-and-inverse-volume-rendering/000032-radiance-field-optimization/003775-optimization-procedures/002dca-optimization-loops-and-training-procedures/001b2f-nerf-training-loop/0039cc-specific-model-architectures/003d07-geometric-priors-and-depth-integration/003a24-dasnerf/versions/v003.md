# DASNeRF

Also called: Depth consistency optimization, adaptive sampling, and hierarchical structural fusion for sparse view neural radiance fields

## Overview
DASNeRF is an optimized Neural Radiance Field (NeRF) approach designed for sparse input views, improving reconstruction details by integrating accurate monocular depth estimation priors and a dynamic optimal sampling layer [S1]. It sets itself apart from standard NeRF by fusing five-dimensional input vectors (coordinates and ray info) into every MLP layer and enforcing depth consistency via Depth Ordering Fidelity Loss and Depth Structural Consistency Regularization, rather than relying solely on color reconstruction loss [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Sparse set of RGB images with known camera poses; pre-computed depth maps from DepthAnythingV2.
*   **Outputs:** Rendered RGB images and depth maps for novel views.

**Data Structures:**
*   **MLP Network:** A multi-layer perceptron where each layer performs input fusion.
*   **Input Vector:** A 5-dimensional vector per sample point, containing 3D coordinates $(x, y, z)$ and ray information (likely viewing direction or ray origin/direction components, though the source specifies "coordinates and ray information" resulting in 5 dimensions) [S1].
*   **Depth Maps:** $d_{V2}$ from DepthAnythingV2 and rendered depth $d_r$ from the NeRF model.

**Numbered Steps:**

1.  **Depth Prior Extraction:** Use the pre-trained DepthAnythingV2 model to obtain depth maps $d_{V2}$ for all input views [S1]. DepthAnythingV2 is preferred over MiDaS for its ability to handle transparent/reflective objects, reduced noise, and 10x faster inference [S1]. The depth data is processed using relative inverse depth [S1].
2.  **Dynamic Optimal Sampling:** Employ a three-layer dynamic sampling mechanism combined with 3D cone frustum sampling (from Mip-NeRF) to determine sample points along rays [S1]. This reduces the impact of lighting variations on detail reconstruction [S1].
3.  **Input Fusion:** For each sampled point, construct a five-dimensional input vector containing coordinates and ray information [S1].
4.  **MLP Forward Pass with Per-Layer Fusion:** The MLP processes the radiance field. Unlike standard NeRF which concatenates position encoding once, DASNeRF fuses the processed five-dimensional input information with the features from the previous layer at **each** MLP layer [S1].
    *   Let $h_l$ be the hidden state at layer $l$.
    *   Let $v$ be the processed five-dimensional input vector.
    *   The input to layer $l$ is a combination of $h_{l-1}$ and $v$ [S1].
5.  **Output Generation:** The final MLP layer outputs volumetric density $\sigma$ and color $\mathbf{c}$ [S1].
6.  **Volume Rendering:** Render pixel color $\hat{C}(r)$ and depth $d_r$ for ray $r(t) = o + td$ bounded by $t_n$ and $t_f$ [S1].
    *   Divide ray into $N$ points $t_i$.
    *   Calculate weights $\omega_i = T_i \alpha_i$.
    *   Rendered color: $\hat{C}(r) = \sum_{i=1}^{N} \omega_i \mathbf{c}_i$.
    *   Rendered depth: $d_r = \sum_{i=1}^{N} \omega_i t_i$.
    *   Transmittance: $T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)$.
    *   Alpha: $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$.
7.  **Loss Calculation:** Compute the total loss $L$ [S1]:
    $$ L = L_{nerf} + \lambda L_{DOF} + \gamma R_{DSC} $$
    *   **Color Loss ($L_{nerf}$):** Mean squared error between ground truth color $C(r)$ and rendered color $\hat{C}(r)$ [S1]:
        $$ L_{nerf} = \sum_{r \in R} \| C(r) - \hat{C}(r) \|_2^2 $$
    *   **Depth Ordering Fidelity Loss ($L_{DOF}$):** Enforces relative depth ordering consistency between rendered depth $d_r$ and prior depth $d_{V2}$ [S1]:
        $$ L_{DOF} = \sum_{d_{V2}^{k1} \leq d_{V2}^{k2}} \max(d_r^{k1} - d_r^{k2} + m_{ar}, 0) $$
        Where $k_1, k_2$ are 2D pixel coordinates. The condition $d_{V2}^{k1} \leq d_{V2}^{k2}$ means pixel $k_1$ is closer (or equal) than $k_2$ in the prior. $m_{ar}$ is a dynamic margin [S1].
    *   **Dynamic Margin ($m_{ar}$):** Adapts to local depth variations [S1]:
        $$ m_{ar} = \alpha \cdot \frac{1}{N} \sum_{i=1}^{N} |d_r^{k1}[i] - d_r^{k2}[i]| $$
        Where $\alpha$ is a hyperparameter, $N$ is the number of samples, and $d_r^{k}[i]$ is the depth of pixel $k$ at sample $i$ [S1].
    *   **Depth Structural Consistency Regularization ($R_{DSC}$):** Enforces continuity for neighboring pixels [S1]:
        $$ R_{DSC} = \sum_{k1} \sum_{d_{V2}^{k2} \in KNN(d_{V2}^{k2})} \max(|d_r^{k1} - d_r^{k2}| - m_{ar}', 0) $$
        Where $KNN(\cdot)$ returns k-nearest neighbors based on depth values in a small region, and $m_{ar}'$ is a small boundary value for minor variations [S1].

**Parameters:**
*   $\lambda = 0.2$: Weight for Depth Ordering Fidelity Loss [S1].
*   $\gamma = 0.02$: Weight for Depth Structural Consistency Regularization [S1].
*   $\alpha$: Tunable hyperparameter for dynamic margin magnitude [S1].

import torch
import torch.nn as nn
import torch.nn.functional as F

class DASNeRFMLP(nn.Module):
    """
    MLP with per-layer input fusion of 5D vector.
    """
    def __init__(self, input_dim=5, hidden_dim=256, num_layers=8, output_dim=4):
        super().__init__()
        self.layers = nn.ModuleList()
        self.num_layers = num_layers
        
        # First layer takes 5D input
        self.layers.append(nn.Linear(input_dim, hidden_dim))
        
        # Subsequent layers take hidden_dim + 5D input
        for _ in range(num_layers - 2):
            self.layers.append(nn.Linear(hidden_dim + input_dim, hidden_dim))
            
        # Final layer outputs sigma and color
        self.layers.append(nn.Linear(hidden_dim + input_dim, output_dim)) # 1 sigma + 3 color
        
        self.relu = nn.ReLU()

    def forward(self, x_5d):
        """
        x_5d: Tensor of shape (N, 5) containing coordinates and ray info.
        """
        h = x_5d
        for i, layer in enumerate(self.layers):
            if i == 0:
                h = layer(h)
            else:
                # Concatenate original 5D input with previous hidden state
                h = torch.cat([h, x_5d], dim=-1)
                h = layer(h)
            
            if i < self.num_layers - 1:
                h = self.relu(h)
                
        return h # Shape (N, 4): [sigma, r, g, b]

## Operating characteristics
*   **Time Complexity:** Higher than standard NeRF due to the additional depth prior extraction (DepthAnythingV2) and the computation of depth regularization terms ($L_{DOF}$ and $R_{DSC}$) which involve pairwise or k-NN comparisons over pixels [S1]. The dynamic sampling adds overhead compared to uniform sampling [S1].
*   **Memory Complexity:** Increased memory usage for storing depth priors and intermediate depth maps for regularization calculations [S1].
*   **Performance:** Designed for sparse views, where standard NeRF fails. DepthAnythingV2 provides 10x faster inference than MiDaS, aiding in rapid depth map generation [S1].
*   **Strengths:** Improved detail preservation in sparse inputs; robust handling of transparent/reflective objects and complex geometries via DepthAnythingV2; adaptive depth regularization reduces blurring [S1].
*   **Limitations:** Relies on the quality of the monocular depth estimator; complex loss computation may slow down training; hyperparameters $\lambda$ and $\gamma$ require tuning (though default values are provided) [S1].

## Background
DASNeRF was proposed to address the limitation of NeRF requiring hundreds of images for high-fidelity reconstruction, aiming for sparse view 3D reconstruction [S1]. It builds on the implicit radiance field concept of NeRF [S1] and incorporates insights from Mip-NeRF for sampling [S1]. The method utilizes DepthAnythingV2, a state-of-the-art monocular depth estimation model trained on 600,000 synthetic and 62 million real unlabeled images, selected for its superior handling of complex scenes compared to MiDaS [S1].
