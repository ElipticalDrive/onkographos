# DASNeRF

Also called: Depth consistency optimization, adaptive sampling, and hierarchical structural fusion for sparse view neural radiance fields

## Overview
DASNeRF is an optimized Neural Radiance Field (NeRF) approach designed for sparse input views, improving reconstruction details by integrating accurate monocular depth estimation priors and a dynamic optimal sampling layer [S1]. It distinguishes itself from standard NeRF and its siblings by fusing a five-dimensional coordinate/ray vector into every layer of the MLP via per-layer input fusion, while enforcing depth consistency through Depth Ordering Fidelity Loss and Depth Structural Consistency Regularization derived from DepthAnythingV2 [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A sparse set of $M$ input views (RGB images $I$ and poses $P$); pre-computed depth maps $D_{V2}$ from DepthAnythingV2 for each input view.
*   **Outputs:** Rendered pixel colors $\hat{C}(r)$ and rendered depths $d_r$ for new camera poses.

**Data Structures:**
*   **Ray:** Defined by origin $o$ and direction $d$, parameterized as $r(t) = o + td$.
*   **Sample Points:** A sequence of $N$ points along the ray within bounds $[t_n, t_f]$.
*   **5D Vector:** A vector containing spatial coordinates and ray direction information, processed for MLP fusion.
*   **MLP:** A multi-layer perceptron where each layer receives both the output of the previous layer and the processed 5D vector.

**Numbered Steps:**

1.  **Depth Prior Extraction:** Use the pre-trained DepthAnythingV2 model to estimate depth maps $D_{V2}$ for all input views [S1]. DepthAnythingV2 is preferred over MiDaS for its superior handling of transparent/reflective objects, noise reduction, and 10x faster inference [S1].
2.  **Dynamic Optimal Sampling:** For each ray $r$, employ a three-layer dynamic sampling mechanism combined with 3D cone frustum sampling (from Mip-NeRF) to determine sample positions $t_i$ along the ray [S1]. This reduces lighting impact and monitors key regions [S1].
3.  **5D Vector Construction:** For each sample point $t_i$, extract its 3D coordinates $\mathbf{x}_i$ and the ray direction $\mathbf{d}$. Process this into a five-dimensional vector $\mathbf{v}_i$ [S1].
4.  **MLP Forward Pass with Per-Layer Fusion:**
    *   Initialize the first layer input with $\mathbf{v}_i$ [S1].
    *   For each subsequent layer $l$, compute the output $\mathbf{h}_l$ by fusing the previous layer's output $\mathbf{h}_{l-1}$ and the processed 5D vector $\mathbf{v}_i$ [S1].
    *   The network outputs volumetric density $\sigma_i$ and color $\mathbf{c}_i$ for each sample [S1].
5.  **Volume Rendering:**
    *   Compute transmittance $T_i$ and opacity $\alpha_i$:
        $$ \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
        $$ T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right) $$
        where $\delta_i$ is the interval between samples [S1].
    *   Render pixel color $\hat{C}(r)$:
        $$ \hat{C}(r) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i $$
    *   Render depth $d_r$ for the ray:
        $$ d_r = \sum_{i=1}^{N} \omega_i t_i $$
        where $\omega_i = T_i \alpha_i$ [S1].
6.  **Loss Calculation:**
    *   **Color Loss ($L_{nerf}$):** Mean squared error between ground truth color $C(r)$ and rendered color $\hat{C}(r)$:
        $$ L_{nerf} = \sum_{r \in R} \| C(r) - \hat{C}(r) \|_2^2 $$
    *   **Depth Ordering Fidelity Loss ($L_{DOF}$):** Enforces relative depth ordering consistency between rendered depth $d_r$ and prior depth $D_{V2}$:
        $$ L_{DOF} = \sum_{d_{V2}^{k1} \leq d_{V2}^{k2}} \max(d_r^{k1} - d_r^{k2} + m_{ar}, 0) $$
        where $k_1, k_2$ are 2D pixel coordinates, and $m_{ar}$ is the dynamic boundary adjustment [S1].
    *   **Depth Structural Consistency Regularization ($R_{DSC}$):** Enforces continuity for neighboring pixels:
        $$ R_{DSC} = \sum_{k1} \sum_{d_{V2}^{k2} \in KNN(d_{V2}^{k2})} \max(|d_r^{k1} - d_r^{k2}| - m_{ar}', 0) $$
        where $KNN(\cdot)$ returns k-nearest neighbors based on depth values in a small region [S1].
    *   **Total Loss:**
        $$ L = L_{nerf} + \lambda L_{DOF} + \gamma R_{DSC} $$
7.  **Optimization:** Update MLP parameters $\theta$ using gradient descent on $L$ [S1].

**Formulas and Definitions:**
*   **Dynamic Boundary Adjustment ($m_{ar}$):**
    $$ m_{ar} = \alpha \cdot \frac{1}{N} \sum_{i=1}^{N} |d_r^{k1}[i] - d_r^{k2}[i]| $$
    where $\alpha$ is a tunable hyperparameter, $N$ is the number of depth samples, and $d_r^{k1}[i], d_r^{k2}[i]$ are depth values at the $i$-th sampling layer for pixels $k_1, k_2$ [S1].
*   **Relative Inverse Depth:** The source notes that data from the depth model is processed using relative inverse depth [S1].

**Parameters:**
*   $\lambda$: Weight for $L_{DOF}$. Typical value: 0.2 [S1].
*   $\gamma$: Weight for $R_{DSC}$. Typical value: 0.02 [S1].
*   $\alpha$: Hyperparameter for dynamic boundary adjustment magnitude [S1].
*   $N$: Number of samples per ray [S1].

**Edge Cases and Pitfalls:**
*   **Transparent/Reflective Objects:** Standard depth estimators fail here; DepthAnythingV2 is specifically chosen to mitigate this [S1].
*   **Depth Discontinuities:** The dynamic boundary adjustment $m_{ar}$ adapts to varying depth levels to prevent blurring [S1].
*   **Sparse Views:** The method is specifically optimized for sparse inputs, where standard NeRF struggles with detail [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class DASNeRF:
    def __init__(self, num_layers, hidden_dim, alpha_margin=0.1):
        """
        Initialize DASNeRF model.
        :param num_layers: Number of MLP layers.
        :param hidden_dim: Dimension of hidden layers.
        :param alpha_margin: Hyperparameter alpha for dynamic boundary adjustment.
        """
        self.num_layers = num_layers
        self.hidden_dim = hidden_dim
        self.alpha_margin = alpha_margin
        self.lambda_loss = 0.2
        self.gamma_loss = 0.02
        
        # MLP with per-layer input fusion
        # Each layer takes previous output + 5D vector
        self.layers = nn.ModuleList()
        for i in range(num_layers):
            # Input dim: hidden_dim (from prev) + 5 (5D vector)
            in_dim = hidden_dim + 5 if i > 0 else 5
            out_dim = hidden_dim if i < num_layers - 1 else 4 # 3 for color, 1 for density
            self.layers.append(nn.Linear(in_dim, out_dim))
            
    def get_5d_vector(self, coords, ray_direction):
        """
        Construct the 5D vector from coordinates and ray direction.
        :param coords: (N, 3) 3D coordinates of samples.
        :param ray_direction: (N, 3) Ray direction.
        :return: (N, 5) Processed 5D vector.
        """
        # Note: Exact processing of 5D vector not specified in sources beyond "processed"
        # We concatenate coordinates and direction, then apply a projection to 5D
        # assuming the source implies a specific embedding or selection.
        # Based on "five-dimensional information... includes coordinates and ray information"
        # and standard NeRF practices, we assume a linear projection or specific selection.
        # Since the source says "processed five-dimensional input information", 
        # and doesn't give the exact projection matrix, we use a learnable projection.
        if not hasattr(self, 'proj_5d'):
            self.proj_5d = nn.Linear(6, 5) # Concat coords(3) + dir(3) -> 5D
        combined = torch.cat([coords, ray_direction], dim=-1)
        return self.proj_5d(combined)

    def forward(self, coords, ray_direction):
        """
        Forward pass through the MLP with per-layer fusion.
        :param coords: (N, 3) 3D positions.
        :param ray_direction: (N, 3) Viewing directions.
        :return: sigma (N, 1), color (N, 3)
        """
        v_5d = self.get_5d_vector(coords, ray_direction)
        
        x = v_5d
        for i, layer in enumerate(self.layers):
            if i == 0:
                h = layer(x)
            else:
                # Per-layer input fusion: concat previous output and 5D vector
                x_fused = torch.cat([h, v_5d], dim=-1)
                h = layer(x_fused)
            
            # Apply ReLU to hidden layers, no activation for final output
            if i < self.num_layers - 1:
                h = F.relu(h)
        
        # Split output into sigma and color
        sigma = h[:, 3:4]
        color = h[:, 0:3]
        return sigma, color

    def render_ray(self, ray_origin, ray_direction, t_near, t_far, num_samples):
        """
        Render a single ray using volume rendering.
        """
        # 1. Dynamic Optimal Sampling (Simplified to uniform for implementation baseline)
        # Source mentions "three-layer dynamic sampling mechanism" and "3D cone frustum"
        # Exact algorithm for dynamic sampling is not fully detailed in text, 
        # so we use uniform sampling as a placeholder for the geometric distribution.
        t_vals = torch.linspace(t_near, t_far, num_samples)
        deltas = t_vals[1:] - t_vals[:-1]
        deltas = torch.cat([deltas, torch.tensor([0.001])]) # Last delta
        
        # 2. Query MLP
        # Interpolate coords along ray
        coords = ray_origin.unsqueeze(0) + t_vals.unsqueeze(1) * ray_direction.unsqueeze(0)
        sigma, color = self.forward(coords, ray_direction)
        
        # 3. Volume Rendering
        alpha = 1.0 - torch.exp(-sigma * deltas)
        transmittance = torch.cumprod(torch.exp(-torch.cat([torch.zeros_like(sigma[:, :1]), sigma[:, :-1] * deltas[:-1]])), dim=1)
        weights = alpha * transmittance
        
        color_rendered = torch.sum(weights * color, dim=1)
        depth_rendered = torch.sum(weights * t_vals, dim=1)
        
        return color_rendered, depth_rendered, weights, t_vals

    def compute_losses(self, gt_color, gt_depth, pred_color, pred_depth, depth_prior, ray_weights, t_vals):
        """
        Compute total loss including NeRF, DOF, and DSC.
        """
        # L_nerf
        l_nerf = torch.mean((gt_color - pred_color) ** 2)
        
        # L_DOF and R_DSC require pixel-wise depth comparison
        # This function assumes batched inputs for a full image
        # L_DOF = sum_{d_v2_k1 <= d_v2_k2} max(d_r_k1 - d_r_k2 + m_ar, 0)
        # R_DSC = sum_{k1} sum_{d_v2_k2 in KNN} max(|d_r_k1 - d_r_k2| - m_ar_prime, 0)
        
        # Note: Implementing KNN and pairwise comparisons efficiently in pure Python/PyTorch 
        # without external libraries is complex. We outline the logic.
        
        # 1. Get local regions P from RGB image I and corresponding poses
        # 2. Extract d_r (rendered depth) and d_v2 (prior depth) for these regions
        # 3. Compute m_ar dynamically
        
        # m_ar = alpha * mean(|d_r_k1[i] - d_r_k2[i]|) over samples i
        # This requires comparing depths at the same pixel coordinates across different rays/views
        
        # Placeholder for complex depth regularization logic
        l_dof = torch.tensor(0.0)
        r_dsc = torch.tensor(0.0)
        
        # In a full implementation, one would:
        # - Map rendered depths to 2D image space

        # - Compute pairwise ordering constraints for DOF
        # - Compute KNN consistency for DSC
        
        total_loss = l_nerf + self.lambda_loss * l_dof + self.gamma_loss * r_dsc
        return total_loss, l_nerf, l_dof, r_dsc
```

## Operating characteristics
*   **Time Complexity:** The per-layer input fusion increases the MLP input dimensionality, potentially increasing computation per sample compared to standard NeRF. However, the dynamic sampling aims to reduce the number of samples needed in less critical regions, potentially offsetting this [S1]. DepthAnythingV2 inference is 10x faster than MiDaS, aiding preprocessing speed [S1].
*   **Memory Complexity:** Requires storing the MLP parameters and the depth priors ($D_{V2}$) for all input views. The 5D vector fusion does not significantly increase memory overhead compared to standard positional encoding.
*   **Performance:** Designed for sparse views, where standard NeRF fails to capture details. It improves reconstruction quality by leveraging accurate depth priors [S1].
*   **Strengths:** Handles sparse inputs effectively; robust to lighting variations via dynamic sampling; superior depth estimation compared to MiDaS [S1].
*   **Limitations:** Relies on the quality of the pre-trained DepthAnythingV2 model; complex regularization terms ($L_{DOF}, R_{DSC}$) require careful tuning of $\lambda, \gamma, \alpha$ [S1].
*   **When to use:** Sparse view reconstruction where high-fidelity detail is required and standard NeRF produces blurry or incomplete results [S1].
*   **When not to use:** Dense view scenarios where standard NeRF or other optimized variants (like Instant-NGP) might be more efficient; scenes with extreme transparency where even DepthAnythingV2 may struggle (though it is better than MiDaS) [S1].

## Background
DASNeRF was introduced to address the limitations of NeRF in sparse view settings, where hundreds of images are typically required for high-fidelity reconstruction [S1]. The method integrates concepts from Mip-NeRF (cone frustum sampling) and leverages recent advances in monocular depth estimation, specifically DepthAnythingV2, which uses a DPT architecture with a DINOv2 backbone [S1]. It was developed to improve sparse reconstruction details by guiding NeRF learning with accurate depth priors and reducing lighting impact through dynamic sampling [S1].
