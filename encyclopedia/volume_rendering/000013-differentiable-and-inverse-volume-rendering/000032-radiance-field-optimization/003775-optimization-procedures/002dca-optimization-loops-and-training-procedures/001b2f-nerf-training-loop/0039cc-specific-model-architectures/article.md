# Specific Model Architectures

Also called: NeRF Architecture Variants, Radiance Field Network Designs

## Overview
Specific Model Architectures refers to the diverse modifications of the canonical Neural Radiance Field (NeRF) Multi-Layer Perceptron (MLP) and its surrounding data structures to address limitations in rendering speed, geometric accuracy, generalization, and robustness to sparse or unstructured inputs [S1, unofficial][S2]. While the parent [NeRF Training Loop](970-nerf-training-loop.md) defines the optimization procedure, these architectures define the function $f_\Theta(\mathbf{x}, \mathbf{d})$ or its discrete equivalents. They set themselves apart from sibling methods like [Training Ray Marching and Integration](2199-training-ray-marching-and-integration.md) by altering the representational capacity of the field itself—ranging from splitting networks for efficiency [AdaNeRF](6195-adanerf.md) and replacing MLPs with voxel grids [Sparse Radiance Field (SRF) Representation](8876-sparse-radiance-field-srf-representation.md) to integrating external geometric priors [DASNeRF](8668-dasnerf.md) or generative constraints [HyperNeRFGAN](8765-hypernerfgan.md).

## Shared principles
The canonical NeRF architecture maps a 3D position $\mathbf{x}$ and viewing direction $\mathbf{d}$ to volume density $\sigma$ and view-dependent color $\mathbf{c}$ using a fully connected MLP [S1, unofficial]. Specific architectures generally maintain this input-output interface or a close variant to remain compatible with standard volume rendering integration:
$$
\mathbf{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i, \quad T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right), \quad \alpha_i = 1 - \exp(-\sigma_i \delta_i)
$$
However, they diverge in how $\sigma$ and $\mathbf{c}$ are computed:
1.  **Network Topology:** Modifications include splitting the network into separate sampling and shading heads [AdaNeRF](6195-adanerf.md), increasing depth significantly while reducing width [R2L (Neural Light Field)](8670-r2l-neural-light-field.md), or replacing the single global MLP with a collection of local sub-networks [Mega-NeRF Spatial Partitioning](8776-mega-nerf-spatial-partitioning.md) or tiny MLPs in a grid [KiloNeRF](8942-kilonerf.md).
2.  **Input Representation:** Inputs may be augmented with appearance embeddings [NeRF in the Wild](#nef-r-in-the-wild), transient embeddings [NeRF in the Wild](#nef-r-in-the-wild), or replaced entirely by 2D pixel coordinates [R2L (Neural Light Field)](8670-r2l-neural-light-field.md). Some methods fuse positional information at every layer [DASNeRF](8668-dasnerf.md).
3.  **Discretization:** Some architectures abandon continuous MLPs for discrete structures, such as sparse voxel grids [Sparse Radiance Field (SRF) Representation](8876-sparse-radiance-field-srf-representation.md) or 2D image projections [MultiPlaneNeRF](8875-multiplanenerf.md).
4.  **Generative Constraints:** Architectures may be embedded within GAN frameworks, where weights are generated by a hypernetwork [HyperNeRFGAN](8765-hypernerfgan.md) or the network outputs SDFs for explicit geometry [DE-NeRF](#de-nerf).

## Subtopics

### [AdaNeRF](6195-adanerf.md)
AdaNeRF employs a fixed set of sample positions along each ray and incrementally introduces sparsity during training to achieve real-time rendering. It sets itself apart from siblings by splitting the NeRF network into a lightweight Sampling Network ($\mathcal{N}_s$) and a heavier Shading Network ($\mathcal{N}_c$). The Sampling Network predicts importance weights for $N$ fixed samples in a single evaluation, allowing the Shading Network to process only the top-$k$ most significant samples, thereby reducing the number of MLP evaluations required per ray.

### [SfMNeRF](8664-sfmnerf.md)
SfMNeRF is designed for novel view synthesis and 3D geometry reconstruction under sparse input conditions. It improves upon standard NeRF by integrating Structure-from-Motion (SfM) constraints—specifically matched feature positions, epipolar geometry, and multi-view photometric consistency—into the training loop. Unlike implicit NeRF which relies solely on photometric rendering loss, SfMNeRF explicitly constrains the 3D structure using cross-view geometric priors and a pyramidal optimization strategy to reduce geometric ambiguity and avoid local minima.

### [DASNeRF](8668-dasnerf.md)
DASNeRF is an optimized NeRF approach for sparse input views that uses accurate monocular depth estimation to guide learning. It sets itself apart by integrating a pre-trained depth model (DepthAnythingV2) as a prior and employing a dynamic sampling mechanism combined with per-layer input fusion. Specifically, it merges each MLP layer's input with a five-dimensional vector containing coordinates and ray information to enhance detail preservation, distinguishing it from siblings like [AdaNeRF](6195-adanerf.md) which focuses on adaptive sampling without explicit depth priors.

### [R2L (Neural Light Field)](8670-r2l-neural-light-field.md)
R2L is a deep neural light field network designed for efficient novel view synthesis by distilling a pre-trained NeRF teacher into a student architecture that operates on 2D pixel coordinates. Unlike canonical NeRF which maps 3D positions and directions, R2L maps 2D image coordinates directly to radiance, significantly reducing computational complexity. It distinguishes itself by employing an unprecedented network depth (88 layers) with extensive internal residual blocks, trading width for depth under a fixed FLOPs budget to capture fine-grained details.

### [AligNeRF](8695-alignerf.md)
AligNeRF addresses rendering artifacts caused by misalignment from moving objects or camera calibration errors, while improving high-frequency detail recovery. It sets itself apart by combining a convolution-augmented architecture with a staged, alignment-aware fine-tuning procedure. The architecture uses an MLP feature head followed by a convolutional post-processing network with reflectance padding, and the training loop explicitly searches for the best-matching subpatch in ground truth images to correct spatial misalignment during optimization.

### [HyperNeRFGAN](8765-hypernerfgan.md)
HyperNeRFGAN is a generative adversarial network that uses a hypernetwork to produce the weights of a simplified NeRF target network, enabling 3D-aware image generation without requiring camera position information during training. It differs from standard NeRF by omitting viewing directions from the input and from other 3D-aware GANs by using a hypernetwork to generate weights directly via Factorized Multiplicative Modulation (FMM) layers rather than conditioning a SIREN-based network.

### [Mega-NeRF Spatial Partitioning](8776-mega-nerf-spatial-partitioning.md)
Mega-NeRF Spatial Partitioning decomposes a large-scale scene into independent spatial cells, each managed by a separate MLP submodule, to enable parallel training and reduce memory consumption. Unlike monolithic NeRF architectures, it assigns query points to the nearest cell centroid, allowing the system to scale to city-scale environments by limiting each submodule's training data to only the pixels relevant to its spatial region.

### [MultiPlaneNeRF](8875-multiplanenerf.md)
MultiPlaneNeRF replaces the trainable, object-specific neural weights of vanilla NeRF with a non-trainable 2D image-based representation. It solves the problems of long training times and poor generalization to unseen data by projecting 3D points onto a fixed set of 2D images to create an aggregate feature vector, which is then decoded by a small, shared implicit decoder. Unlike vanilla NeRF, which requires separate training for each object, MultiPlaneNeRF allows a single decoder to generalize across many objects by simply swapping the input 2D image set.

### [Sparse Radiance Field (SRF) Representation](8876-sparse-radiance-field-srf-representation.md)
A Sparse Radiance Field (SRF) is a voxel-based representation that encodes volume density and view-dependent radiance into a sparse grid. It serves as a structured alternative to the continuous MLP used in standard NeRF, enabling efficient optimization and direct mesh extraction via Marching Cubes. Unlike its sibling [Mega-NeRF Spatial Partitioning](8776-mega-nerf-spatial-partitioning.md), which manages independent sub-networks for spatial cells, the SRF stores explicit feature vectors directly in the voxel coordinates, treating the radiance field as a discrete, irregular volumetric data structure.

### [KiloNeRF](8942-kilonerf.md)
KiloNeRF adopts a teacher-student training paradigm where a standard NeRF is trained first, and its knowledge is distilled into a set of lightweight MLPs arranged in a 3D grid. It accelerates rendering by replacing the single large MLP with thousands of tiny MLPs and using a cached sparse 3D grid to quickly locate the surface, thereby skipping empty space.

### [Pool proposer architecture](8953-pool-proposer-architecture.md)
The Pool proposer is a trainable network component used in NeRF-ID to generate fine sampling positions from coarse features. It solves the problem of adaptive ray sampling by learning to propose new points based on the density and color features of existing coarse samples. It is distinguished from the MLPMix proposer by its use of average pooling operations, which results in higher variance and significantly worse performance on specific scenes like Blender: Materials and Blender: Mic, though it remains competitive on average.

### SinNeRF
SinNeRF uses a depth map to constrain unobserved views via Adversarial loss and Perceptual loss [S1, unofficial].

### NeRF in the Wild
NeRF in the Wild adds an Appearance embedding to express different lighting conditions and a Transient embedding to model changing geometry [S1, unofficial].

### StyleNeRF
StyleNeRF is a 3D-aware generative model that merges 3D scene representation with style-based generative models [S2]. It uses NeRF to generate low-resolution feature maps and samples them to high resolution to avoid super-computation volume rendering, applying regularization terms to improve 3D consistency [S2].

### CLIP-NeRF
CLIP-NeRF adds CLIP (a text-image pre-trained multimodal model) to provide greater freedom in shape operations and global deformation, using a disentangled conditional NeRF architecture [S2]. It applies a learned deformation network to shape modulation, embeds appearance codes into volume rendering to map color output, and allows control over both shape and appearance [S2].

### NeRF-RPN
NeRF-RPN uses a multi-scale Object-NeRF architecture where the scene branch encodes geometry and appearance via a voxel representation of 3D neural volume features, and the object branch encodes each independent object [S2].

### JacobiNeRF
JacobiNeRF synthesizes a NeRF model based on second-order information (Jacobian matrix) to maximize mutual information between highly correlated entities under random scene perturbations [S2]. The rendering equation used is:
$$
\hat{C}(r, z_s, z_c) = \sum_{i=1}^{N_c-1} c_i \alpha_i \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)
$$
where $a_i = 1 - \exp(-\sigma_i \delta_i)$ is consistent with discrete volume rendering [S2].

### DE-NeRF
DE-NeRF decomposes lighting, geometry, and appearance to allow relighting of high-frequency environments and appearance editing [S3]. It trains a signed distance field (SDF) function using 2D images to reconstruct a display grid as the input scene for the MLP. It decomposes the scene into geometric features and appearance features (diffuse reflection, roughness, specular tint). Input geometric features, appearance features, and distance $h$ (from sampling point to grid) are fed into four corresponding MLPs to predict diffuse albedo, roughness value, and specular tint. Diffuse reflectance is integrated with the environment map to get diffuse color $c_d$. A specular lighting MLP $F_s$ is trained to get specular lighting $c_l$, which is multiplied with specular hue to get specular color $c_s$. The final color $c$ is calculated as $c_s + c_d$ [S3]. On NeRF Synthetic and Shiny Blender data sets, PSNR is 2 points higher than latest papers [S3].

### RefSR-NeRF
RefSR-NeRF is a reference-guided super-resolution neural radiation field framework combining NeRF and RefSR-CNN to achieve high-quality new perspective synthesis while balancing memory and speed [S3]. Stage 1 modifies NeRF sampling strategy to adopt patch ray sampling on the high-resolution input image to obtain a low-resolution image. RefSR-CNN yields feature maps from the detail-dominant information module and the degradation-dominant information module. These two feature maps are fused to reconstruct a high-resolution image [S3]. On the NeRF-LLFF data set, PSNR is nearly one point higher than the best paper [S3].

### RelightingNeRF
RelightingNeRF is proposed for handling unstructured photographs and free-viewpoint reconstruction, changing model architecture to output SDF values and latent features [S3]. It inputs sampling point position into the first MLP, which outputs SDF values and latent features. Normals, shadow cues, and specular cues are obtained from the SDF values. Sampling point positions, lighting positions, and viewing directions, along with latent features from the first MLP, are provided to the second MLP, which produces the final color [S3].

### DiffusioNeRF
DiffusioNeRF utilizes a denoising diffusion model to learn priors for scene geometry and color, normalizing the geometry and color of the scene to achieve better quality in reconstructed geometry under sparse input views [S3]. During NeRF training, random RGBD patches are rendered. The estimated gradients of the log-likelihood are backpropagated to the color and density fields to normalize the geometry and color [S3]. On the LLFF dataset, the PSNR indicators in 3, 6, and 9 input views are 1-2 points higher. Among three input views, the PSNR index is nearly 1 point higher than ViP-NeRF [S3].

### GeoNeRF
GeoNeRF is a model with two parts: a geometric morphology reasoner and a renderer [S2]. The reasoner builds a cascaded cost volume for source view sequences. The renderer infers geometric and appearance representations using a Transformer-based attention mechanism and cascaded cost volumes, then renders fine images using volume rendering [S2].

### Canonical Radiance Field with Voxel Grid
Canonical Radiance Field with Voxel Grid is a representation of a static scene at canonical time using a learnable voxel radiance feature grid and a lightweight MLP, replacing the heavy MLP in NeRF to allow querying finite 3D points [S4]. The canonical radiance field is defined as:
$$
\mathbf{V}_{\text{grid}}^{\text{R}}_{\text{Can}} = \text{RadNet} (\mathbf{V}_{\text{grid}}^{\text{p}}_{\text{Can}}, \mathbf{V}_{\text{grid}}^{\text{Rf}}_{\text{Can}})
$$
where $\mathbf{V}_{\text{grid}}^{\text{R}}_{\text{Can}} = \{V_{\sigma}^{\text{Can}}, V_{cf}^{\text{Can}}\}$ consists of density voxel grid $V_{\sigma}$ and color feature voxel grid $V_{cf}$. $V_{p}^{\text{Can}}$ are the 3D coordinates of the voxel grid in canonical space, embedded according to NeRF [26] [S4]. $F_{\theta1}$ is a lightweight MLP network used to model the radiance [S4].

### Transformer Proposer Architecture
Transformer Proposer Architecture is a proposer network constrained to reduce computational cost, using a single transformer block for encoder and decoder with a single attention head [S5, unofficial]. Features are projected to 16-D [S5, unofficial].

### Generalizable Radiance Fields via Transformer Attention
Generalizable Radiance Fields via Transformer Attention is a generalizable approach using a transformer-based attention module to aggregate source views information [S6].

### Masked Auto Encoder (MAE) for Generalizable NeRF
Masked Auto Encoder (MAE) for Generalizable NeRF uses Masked Auto Encoder combined with a 3D transformer-based architecture to learn a generalized representation capable of reconstructing unseen scenes [S6].

## Background
The canonical NeRF architecture, introduced by Mildenhall et al. in 2020 [S1, unofficial][S2], established the paradigm of mapping 3D coordinates and viewing directions to density and color via a fully connected MLP. Early extensions focused on improving rendering speed and geometric fidelity. AdaNeRF and KiloNeRF introduced architectural splits and grid-based distillation to accelerate inference [S1, unofficial][S2]. SfMNeRF and DASNeRF integrated external geometric priors (SfM features, monocular depth) to address the ambiguity inherent in sparse input views [S1, unofficial]. Generative approaches like HyperNeRFGAN and StyleNeRF merged NeRF with GANs and style-based generators to enable 3D-aware synthesis [S1, unofficial][S2]. Large-scale and unstructured scene handling led to architectures like Mega-NeRF for spatial partitioning [S1, unofficial] and NeRF in the Wild for handling lighting and transient changes [S1, unofficial]. More recent works have explored discrete representations like SRF [S1, unofficial] and generalizable architectures using Transformers and MAEs [S5, unofficial][S6].
