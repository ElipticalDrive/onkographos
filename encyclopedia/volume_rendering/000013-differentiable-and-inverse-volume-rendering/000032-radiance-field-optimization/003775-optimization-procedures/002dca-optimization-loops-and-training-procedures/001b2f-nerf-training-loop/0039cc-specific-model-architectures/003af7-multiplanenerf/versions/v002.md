# MultiPlaneNeRF

Also called: MultiPlaneNeRF

## Overview
MultiPlaneNeRF is a neural radiance field architecture that replaces the trainable 3D representation of vanilla NeRF with a non-trainable, image-based representation [S1]. It solves the problems of long training times and poor generalization to unseen data by projecting 3D points onto a fixed set of 2D training images to create an aggregate feature vector, which is then processed by a small, shared implicit decoder [S1]. Unlike vanilla NeRF, which encodes object-specific geometry and color in network weights, MultiPlaneNeRF allows the decoder to generalize across many objects, enabling the synthesis of new views for unseen objects simply by swapping the input image set without retraining the network [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $n$ 2D training images $\{I_1, \dots, I_n\}$ with known camera poses; a 3D query point $\mathbf{x} = (x, y, z)$; and a viewing direction $\mathbf{d}$.
*   **Outputs:** Volume density $\sigma$ and color $\mathbf{c} = (R, G, B)$.

**Data Structures:**
*   **Image Set:** A collection of $n$ images, each of resolution $H \times W$ (typically $200 \times 200$ in experiments) with transparent backgrounds [S1].
*   **Aggregate Information Vector:** A vector $\mathbf{Z}(\mathbf{x}) \in \mathbb{R}^{5k}$, where $k$ is a parameter related to the number of images or channels used in the aggregation [S1]. The source specifies the dimension as $5k$ but does not explicitly define $k$ in terms of $n$ or channel counts, other than implying it relates to the input image set size [S1].
*   **Implicit Decoder:** A shallow Multi-Layer Perceptron (MLP) with weights $\Theta$ [S1].

**Numbered Steps:**

1.  **Dataset Splitting:** Split the initial set of $n$ 2D training images into two subsets:
    *   **Representation Set ($S_{rep}$):** Used to build the non-trainable 2D representation.
    *   **Training Set ($S_{train}$):** Used to calculate the weights $\Theta$ of the implicit decoder via standard NeRF rendering loss [S1].
2.  **Projection and Aggregation:** For a 3D point $\mathbf{x}$, project it onto each image $I_j \in S_{rep}$ using the known camera intrinsics and extrinsics. Collect the pixel values (RGB and potentially depth or alpha) from the projected locations across all images in $S_{rep}$ to form the aggregate information vector $\mathbf{Z}(\mathbf{x})$ [S1].
3.  **Decoding:** Pass $\mathbf{Z}(\mathbf{x})$ through the implicit decoder $F_\Theta$ to predict density and color:
    $$ (\sigma, \mathbf{c}) = F_\Theta(\mathbf{Z}(\mathbf{x})) $$
    The source notes that the decoder is "very shallow" and "small" [S1].
4.  **Rendering:** Use the predicted $\sigma$ and $\mathbf{c}$ in the standard volume rendering equation to compute the final pixel color [S1].

**Parameters:**
*   **Number of Images ($n$):** The source uses 50 images per object in experiments [S1].
*   **Image Resolution:** $200 \times 200$ pixels [S1].
*   **Aggregate Vector Dimension:** $\mathbb{R}^{5k}$ [S1]. The exact value of $k$ is not explicitly defined, but it relates to the number of images or channels [S1].
*   **Decoder Depth:** "Very shallow" [S1]. Exact layer count and hidden units are not given in the sources [S1].

**Edge Cases and Pitfalls:**
*   **Generalization vs. Quality:** Training on a large dataset (for generalization) results in slightly worse rendering quality compared to training each object separately [S1].
*   **Projection Boundaries:** Points projected outside the image bounds or behind the camera must be handled. The source does not specify the exact handling mechanism [S1]. [G] Zero-padding or masking is a standard approach.
*   **Missing Depth/Alpha:** The source mentions "transparent background images" [S1], implying alpha or depth information might be part of the 5-channel vector, but the exact composition of the 5 channels is not specified [S1].

## Operating characteristics
*   **Time Complexity:** Training time is significantly reduced compared to vanilla NeRF because the 3D representation is non-trainable (pre-computed from images) and the decoder is small and shallow [S1]. Inference time is also reduced due to the small decoder [S1].
*   **Memory Complexity:** Memory usage is dominated by the storage of the $n$ input images and the small decoder weights. It uses fewer parameters than vanilla NeRF or voxel-based NSFV [S1].
*   **Measured Performance:** Achieves results comparable to state-of-the-art models (vanilla NeRF, voxel-based NSFV) on synthesizing new views, using fewer parameters [S1].
*   **Strengths:** Fast training, ability to generalize to unseen objects by changing the input image set without retraining the decoder, fewer parameters [S1].
*   **Limitations:** Slightly worse rendering quality when trained for generalization compared to per-object training [S1].

## Background
MultiPlaneNeRF was proposed to address the limitations of vanilla NeRF, specifically long training times and poor generalization to unseen data [S1]. It was introduced in the paper "MultiPlaneNeRF: Neural radiance field with non-trainable representation" [S1]. The method is inspired by the idea of using existing 2D images as a non-trainable representation of 3D structure, similar to how TriPlane representations are used in generative models [S1]. It has been used as a component in large generative models like GANs, specifically in MultiPlaneGAN [S1].
