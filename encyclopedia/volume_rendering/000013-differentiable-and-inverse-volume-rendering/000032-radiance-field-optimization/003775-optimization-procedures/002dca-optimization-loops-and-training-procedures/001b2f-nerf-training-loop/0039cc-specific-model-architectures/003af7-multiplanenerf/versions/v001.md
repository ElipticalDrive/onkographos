# MultiPlaneNeRF

Also called: MultiPlaneNeRF

## Overview
MultiPlaneNeRF is a radiance field optimization method that replaces the fully trainable implicit representation of vanilla NeRF with a non-trainable 2D image-based representation [S1]. It solves the problems of long training times and poor generalization to unseen data by projecting 3D points onto a fixed set of 2D training images to create an aggregate feature vector, which is then processed by a small, trainable implicit decoder [S1]. Unlike vanilla NeRF, which encodes object-specific geometry and color in network weights requiring separate training per object, MultiPlaneNeRF allows a single decoder to generalize across many objects by simply swapping the input 2D image set [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $n$ 2D training images $\{I_1, ..., I_n\}$ with known camera poses (intrinsics and extrinsics) for a specific 3D object. A 3D point coordinate $\mathbf{p} = (x, y, z)$ and a viewing direction $\mathbf{d}$.
*   **Output:** Volume density $\sigma$ and color $\mathbf{c}$ (RGB) for the point $\mathbf{p}$ in direction $\mathbf{d}$.

**Data Structures:**
*   **2D Representation:** A collection of $n$ images. The source specifies using $200 \times 200$ images with transparent backgrounds [S1].
*   **Aggregate Information Vector:** $Z(\mathbf{p}) \in \mathbb{R}^{5k}$, where $k$ relates to the number of images or channels used in the projection [S1]. The exact value of $k$ is not specified beyond the dimensionality formula [S1].
*   **Implicit Decoder:** A small Multi-Layer Perceptron (MLP) [S1]. The architecture details (layers, activation functions) are not provided in the sources [S1].

**Numbered Steps:**

1.  **Data Splitting:** Split the initial set of $n$ 2D training images into two subsets:
    *   **Representation Set:** Used to build the non-trainable 2D representation (input to the decoder).
    *   **Training Set:** Used as the ground-truth target to calculate the weights of the implicit decoder [S1].
    *   *Note:* The source does not specify the ratio of the split or how the training set images are used for supervision (e.g., if they are rendered and compared, or if the representation set images are used for supervision) [S1].

2.  **Projection (Non-Trainable):** For a query 3D point $\mathbf{p} = (x, y, z)$, project it onto each of the $n$ images in the Representation Set using their known camera poses. This yields a set of 2D pixel coordinates and corresponding pixel values (RGB) for each image [S1].

3.  **Aggregation:** Aggregate the projected pixel information from all $n$ images into a single vector $Z(\mathbf{p}) \in \mathbb{R}^{5k}$ [S1]. The specific aggregation function (e.g., concatenation, averaging, attention) is not defined in the sources [S1].

4.  **Decoding:** Pass $Z(\mathbf{p})$ and the viewing direction $\mathbf{d}$ (if required by the decoder architecture, though not explicitly stated as an input to the MLP in the text, standard NeRF decoders use direction) into the small implicit decoder [S1]. The decoder outputs the volume density $\sigma$ and color $\mathbf{c}$ [S1].

5.  **Rendering:** Use the standard volume rendering equation to compute the pixel color for a camera ray [S1]:
    $$ C(r) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i, \quad T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right), \quad \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
    where $\sigma_i$ and $\mathbf{c}_i$ are the density and color sampled along the ray $r$ at points $i$, and $\delta_i$ is the distance between samples [S1].

6.  **Optimization:** Optimize the weights of the implicit decoder using gradient-based methods (e.g., Adam) to minimize the difference between rendered images and the ground-truth images from the Training Set [S1].

## Subtopics

### MultiPlaneGAN
A GAN-based generative model that uses the MultiPlaneNeRF decoder as a component [S1]. It leverages the ability of MultiPlaneNeRF to generalize across objects by changing the image-based representation without additional training [S1].

### Comparison with Vanilla NeRF
MultiPlaneNeRF differs from vanilla NeRF by using non-trainable 2D image representations instead of encoding object-specific data in network weights, enabling generalization to unseen objects without retraining the decoder [S1].

### Comparison with Voxel-based Methods
MultiPlaneNeRF achieves similar reconstruction quality to voxel-based methods (like NSFV) but with fewer parameters and potentially faster inference due to the shallow decoder [S1].

## Operating characteristics
*   **Time Complexity:** Training time is reduced compared to vanilla NeRF because the representation is non-trainable and the decoder is small [S1]. Inference time is also reduced due to the shallow decoder [S1].
*   **Memory Complexity:** Uses less memory than vanilla NeRF as it does not store large network weights for each object's geometry and color [S1].
*   **Measured Performance:** Achieves results comparable to state-of-the-art models (including vanilla NeRF and voxel-based NSFV) on synthesizing new views [S1].
*   **Scaling:** Can be trained on a large dataset (e.g., ShapeNet) to generalize across many objects [S1].
*   **Strengths:** Generalizes to unseen objects by changing the input 2D images without additional training; fewer parameters; faster training and inference [S1].
*   **Limitations:** Slightly worse rendering quality when trained on a large dataset for generalization compared to training each object separately [S1].

## Background
MultiPlaneNeRF was proposed to address the limitations of vanilla NeRF, specifically long training times and poor generalization to unseen data [S1]. It was introduced in the paper "MultiPlaneNeRF: Neural radiance field with non-trainable representation" [S1]. The method builds on the idea of using non-trainable representations (existing images) to encode 3D structure, similar to concepts in TriPlane representations [S1]. It has been used as a component in larger generative models like MultiPlaneGAN [S1].
