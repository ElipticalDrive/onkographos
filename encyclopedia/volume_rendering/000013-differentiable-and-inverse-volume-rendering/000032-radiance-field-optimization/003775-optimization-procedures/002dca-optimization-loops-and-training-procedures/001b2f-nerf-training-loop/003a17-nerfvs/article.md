# NeRFVS

Also called: Neural Radiance Fields for Free View Synthesis via Geometry Scaffolds

## Overview
NeRFVS is a method for indoor scene free view synthesis (FVS) that uses a geometry scaffold from an off-the-shelf neural reconstruction method to guide NeRF optimization, reducing distortions and floaters in extrapolation [S1]. It enables NeRF to perform free navigation and extrapolation for indoor scenes by using a neural-reconstructed geometric scaffold to guide optimization, boosted by depth and variance constraints with dynamical adjustment based on view coverage [S1]. Unlike standard NeRF, which struggles with extrapolation and sparse views, NeRFVS minimizes per-pixel loss to avoid distortions, unlike SVS which suffers from noticeable artifacts [S1].

## How it works
**Inputs and Outputs**
*   **Inputs:** A collection of RGB images $\{I_i\}_{i=0}^{N-1}$, camera intrinsic parameters $K_i \in \mathbb{R}^{3 \times 3}$, and poses $p_i \in \mathbb{R}^6$ [S1].
*   **Outputs:** A trained NeRF model capable of rendering novel views and depth maps for arbitrary camera poses [S1].

**Data Structures**
*   **Geometry Scaffold:** A 3D geometric representation (e.g., point cloud or mesh) generated by an off-the-shelf neural reconstruction method using the input images and camera parameters [S1]. The specific format depends on the chosen reconstruction method [S1].
*   **View Coverage Map:** An approximation tracking the number of training observations per region. It is stored as $V_i \in [1, N]^{H \times W \times 1}$, representing the count of views covering each pixel in the image plane [S1]. This map ignores emitting directions [S1].

**Formulas**
1.  **Volume Rendering Equation:**
    $$ \hat{\mathbf{C}}(\mathbf{r}) = \int_{t_n}^{t_f} w(\mathbf{r}(t)) \mathbf{c}(\mathbf{r}(t), \mathbf{d}) dt $$
    where $w(\mathbf{r}(t)) = T(t)\sigma(\mathbf{r}(t))$, $T(t) = \exp(-\int_{t_n}^t \sigma(\mathbf{r}(s))ds)$, $t_n$ and $t_f$ are near and far bounds, $\sigma$ is volume density, and $\mathbf{c}$ is emitted color [S1].

2.  **Depth Rendering Equation:**
    $$ \hat{D}(\mathbf{r}) = \int_{t_n}^{t_f} w(\mathbf{r}(t)) t dt $$
    where $t$ is the distance along the ray [S1].

3.  **Photometric Loss:**
    $$ \mathcal{L}_{\text{color}}(\mathbf{r}) = \|\hat{\mathbf{C}}(\mathbf{r}) - \mathbf{C}(\mathbf{r})\|_2^2 $$
    where $\mathbf{C}(\mathbf{r})$ is the ground truth color [S1].

4.  **Robust Depth Loss:**
    The specific formula for the robust depth loss is not provided in the sources, but it is described as alleviating the influence of pseudo depth errors from the scaffold [S1]. It is applied to guide optimization [S1].

5.  **Variance Loss:**
    The variance loss comprises two components, $L_w^{var}(\mathbf{r})$ and $L_{var}(\mathbf{r})$, as defined in Eq. (5) and Eq. (6) of the source [S1]. The exact formulas are not provided in the notes, but the loss regularizes the variance of predicted density distribution and color values along each ray to decrease ambiguity in low-texture areas [S1].

**Parameters**
*   **View Coverage Map:** Tracks the number of views covering each pixel [S1].
*   **Regularization Strength:** Dynamically adjusted based on the view coverage map [S1].

**Steps**
1.  **Generate Geometry Scaffold:** Use an off-the-shelf neural reconstruction method to generate a geometry scaffold from the input images and camera parameters [S1].
2.  **Compute View Coverage Map:** Calculate the view coverage map $V_i$ for each input view, representing the count of views covering each pixel [S1].
3.  **Initialize NeRF:** Initialize a NeRF model [S1].
4.  **Optimize NeRF:**
    a.  Render color $\hat{\mathbf{C}}(\mathbf{r})$ and depth $\hat{D}(\mathbf{r})$ for training rays [S1].
    b.  Compute photometric loss $\mathcal{L}_{\text{color}}(\mathbf{r})$ [S1].
    c.  Compute robust depth loss using the scaffold's pseudo depth [S1].
    d.  Compute variance loss $L_w^{var}(\mathbf{r}) + L_{var}(\mathbf{r})$ [S1].
    e.  Dynamically adjust the intensity of the depth and variance losses based on the view coverage map [S1]. Areas with low coverage receive weaker regularization [S1].
    f.  Update NeRF parameters using the combined loss [S1].
5.  **Repeat Step 4** until convergence [S1].

**Pseudocode**

```python
def nerfvs_train(images, camera_params, scaffold_method, num_iterations):
    # Step 1: Generate Geometry Scaffold
    scaffold = scaffold_method(images, camera_params)
    
    # Step 2: Compute View Coverage Map
    # V_i is the count of views covering each pixel
    view_coverage_map = compute_view_coverage(images, camera_params)
    
    # Step 3: Initialize NeRF
    nerf_model = initialize_nerf()
    
    for iteration in range(num_iterations):
        # Sample training rays
        rays = sample_rays(images, camera_params)
        
        # Step 4a: Render
        rendered_color, rendered_depth, weights, densities, colors = render_rays(nerf_model, rays)
        
        # Step 4b: Photometric Loss
        gt_colors = get_gt_colors(rays, images)
        loss_color = mean_squared_error(rendered_color, gt_colors)
        
        # Step 4c: Robust Depth Loss
        # Pseudo depth from scaffold
        pseudo_depths = get_scaffold_depth(rays, scaffold)
        loss_depth = robust_depth_loss(rendered_depth, pseudo_depths)
        
        # Step 4d: Variance Loss
        # Regularize variance of density and color along rays
        loss_variance = compute_variance_loss(weights, densities, colors)
        
        # Step 4e: Dynamic Adjustment
        # Adjust regularization strength based on view coverage
        # Low coverage -> weaker regularization
        coverage = get_coverage_for_rays(rays, view_coverage_map)
        alpha_depth = adjust_strength(loss_depth, coverage)
        alpha_variance = adjust_strength(loss_variance, coverage)
        
        # Step 4f: Update
        total_loss = loss_color + alpha_depth * loss_depth + alpha_variance * loss_variance
        update_nerf(nerf_model, total_loss)
        
    return nerf_model
```

**Edge Cases and Pitfalls**
*   **Inaccurate Geometry Scaffold:** Inaccurate geometry scaffolds degrade extrapolation performance [S1].
*   **View Coverage Map Approximation:** The view coverage map approximation fails in extreme cases like holes and thin objects [S1].
*   **Ignoring Emitting Directions:** Ignoring emitting directions in coverage calculation degrades view-dependent appearance [S1].
*   **Poor Geometry in Few-Shot Regions:** Reliance on pseudo depth in few-shot regions may cause poor extrapolation if geometry is exceptionally poor [S1].

## Subtopics

### Geometry Scaffold Generation
The process of creating the initial 3D geometric representation from input images. This is a prerequisite step using off-the-shelf methods [S1].

### Robust Depth Loss
A loss function designed to handle errors in the pseudo depth from the scaffold, preventing artifacts from inaccurate geometry [S1].

### Variance Regularization
A technique to reduce ambiguity in low-texture areas by regularizing the variance of density and color distributions [S1].

### View Coverage Adjustment
A strategy to dynamically adjust regularization strength based on the number of training observations per region [S1].

## Operating characteristics
*   **Time and Memory Complexity:** Not given in the sources.
*   **Measured Performance:** On ScanNet (extrapolation setting), the full model achieves PSNR 23.714, SSIM 0.829, LPIPS 0.414 [S1].
    *   Without Depth Loss: PSNR 23.187, SSIM 0.821, LPIPS 0.428 [S1].
    *   Without Var Loss: PSNR 23.435, SSIM 0.822, LPIPS 0.431 [S1].
    *   Without Adjustment: PSNR 23.172, SSIM 0.821, LPIPS 0.429 [S1] [S1].
*   **Scaling:** Not given in the sources.
*   **Strengths:** Improves extrapolation ability of NeRF-based methods for indoor scenes [S1]. Can be integrated into instant-NGP to boost extrapolation performance [S1].
*   **Limitations:** Relies on pseudo depth in few-shot regions, which may result in poor extrapolation if geometry is exceptionally poor [S1]. The view coverage map is an adequate approximation in plainer regions but may cause errors in extreme cases like holes and thin objects [S1]. Ignoring emitting directions may cause degradation in view-dependent appearance [S1].
*   **When to use:** Indoor scene free view synthesis where extrapolation to novel views is required [S1].
*   **When not to use:** When the geometry scaffold is exceptionally poor, or when high-fidelity view-dependent appearance is critical and the view coverage map approximation is insufficient [S1].

## Background
NeRFVS was introduced in the paper "NeRFVS: Neural Radiance Fields for Free View Synthesis via Geometry Scaffolds" [S1]. It addresses the issue that NeRF suffers for novel views that are significantly different from the training views, particularly in indoor scenes [S1]. The method leverages holistic priors, including pseudo depth maps and view coverage information, from neural reconstruction to guide the learning of implicit neural representations of 3D indoor scenes [S1].
