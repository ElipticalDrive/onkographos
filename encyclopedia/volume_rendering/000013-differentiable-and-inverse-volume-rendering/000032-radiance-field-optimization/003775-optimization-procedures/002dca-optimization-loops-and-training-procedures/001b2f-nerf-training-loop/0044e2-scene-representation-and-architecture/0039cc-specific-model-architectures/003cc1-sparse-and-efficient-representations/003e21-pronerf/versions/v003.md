# ProNeRF

Also called: ProNeRF-12, ProNeRF-32, ProNeRF-8, Projection-Aware Ray Sampling for Fine-Grained Implicit Neural Radiance Fields

## Overview
ProNeRF is a sparse, sampler-based neural rendering method that uses a Projection-Aware Sampling (PAS) network to predict a small set of 3D sampling points and opacity adjustments, enabling high-quality volumetric rendering with significantly fewer samples than standard NeRF [S1]. It achieves a superior trade-off between speed and quality, being 15–23× faster than vanilla NeRF while delivering higher PSNR, by leveraging color-to-ray projections from a fixed subset of reference views to guide sampling density [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A target ray $\mathbf{r}$ defined by origin $\mathbf{r}_o$ and direction $\mathbf{r}_d$, bounded by near $t_n$ and far $t_f$ distances. A fixed set of $N_n$ neighboring reference views (camera poses and images) from the training set.
*   **Output:** Rendered color $\hat{\mathbf{c}}(\mathbf{r})$ for the target ray.

**Data Structures and Network Layout:**
The method consists of three main neural components:
1.  **Coarse MLP Head ($F_{\theta_c}$):** 6 fully connected layers, 256 neurons each, ELU activations. Inputs: Plucker-encoded ray. Outputs: Coarse distances $T'$, opacity shifts/scales $A_t, B_t$, coarse color $\hat{\mathbf{c}}_c$, and auxiliary weights $W, M$.
2.  **Feature MLP Head ($F_{\theta_f}$):** 6 fully connected layers, 256 neurons each, ELU activations. Inputs: Plucker-encoded ray and aggregated projection features. Outputs: Refinement weights $\Delta_T$, and auxiliary weights $W, M$.
3.  **Shading Network ($F_{\theta_s}$):** 8 fully connected layers, 256 neurons each. Inputs: 3D points. Outputs: Density $\sigma$ and color $\mathbf{c}$.
4.  **Pruning Head ($F_{\theta_m}$):** (Optional, for ProNeRF-8 prune) Same complexity as $F_{\theta_c}$. Outputs: Error prediction between fast and full rendering.

**Plucker Ray-Point Encoding:**
The ray is encoded using $N_{pr}$ points evenly spaced between $t_n$ and $t_f$. Let $\mathbf{t}_{nf}$ be a vector of $N_{pr}$ elements evenly spaced in $[t_n, t_f]$. The Plucker representation $\mathbf{r}_{pr}$ is:
$$ \mathbf{r}_{pr} = [\mathbf{r}_d, \mathbf{r}_o + \mathbf{r}_d \odot \mathbf{t}_{nf}, (\mathbf{r}_o + \mathbf{r}_d \odot \mathbf{t}_{nf}) \odot \mathbf{r}_d] $$
where $\odot$ is the Hadamard product and $[\cdot, \cdot]$ is concatenation [S1].

**Algorithm Steps:**

1.  **Coarse Sampling:** Encode $\mathbf{r}$ into $\mathbf{r}_{pr}$. Pass $\mathbf{r}_{pr}$ through $F_{\theta_c}$ to obtain coarse distances $T' = \{t'_1, \dots, t'_{N_s}\}$, opacity parameters $A_t, B_t$, coarse color $\hat{\mathbf{c}}_c$, and auxiliary weights $W, M$.
2.  **Color-to-Ray Projection:** For each coarse point $p_i = \mathbf{r}(t'_i)$, trace lines to the camera centers of $N_n$ neighboring reference views. Collect the colors at the intersection points to form projection features $\mathbf{f}_{p_i} = [c^1_{p_i}, \dots, c^{N_n}_{p_i}]$ [S1].
3.  **Refinement:** Concatenate $\mathbf{r}_{pr}$ with all projection features $[\mathbf{f}_{p_1}, \dots, \mathbf{f}_{p_{N_s}}]$. Pass through $F_{\theta_f}$ to obtain refinement weights $\Delta_T$. Compute refined distances $T$ by linear interpolation between consecutive elements of the expanded set $\dot{T} = \{t_n, t'_1, \dots, t'_{N_s}, t_f\}$:
    $$ T = \left\{ \frac{1}{2} \left( (\dot{T}_i + \dot{T}_{i+1}) + \Delta_{T_i}(\dot{T}_{i+2} - \dot{T}_i) \right) \right\}_{i=1}^{N_s} $$
    where indices are handled appropriately for boundaries [S1].
4.  **Fast Rendering (AVR):** Use the projected colors $\mathbf{c}^k_{p_i}$ and weights $W, M$ to approximate the Volume Rendering Equation (VRE) via Approximated Volumetric Rendering (AVR):
    $$ c^k_{avr} = \sum_{i=1}^{N_s} W_i c^k_{p_i} $$
    Aggregate across views: $\hat{\mathbf{c}}_f = \sum_{k=1}^{N_n} M_k c^k_{avr}$ [S1].
5.  **Full Rendering (Shading):** Query $F_{\theta_s}$ at points $\mathbf{r}(t)$ for $t \in T$ to get densities $\sigma_i$ and colors $\mathbf{c}_i$. Compute opacities $\alpha_i = 1 - e^{-\sigma_i(t_{i+1} - t_i)}$. Adjust opacities using $A_t, B_t$ (as per Eq. 4 in [S1], though exact formula for adjustment is not explicitly detailed in the provided text, it is used in the VRE step). Render final color $\hat{\mathbf{c}}(\mathbf{r})$ using standard alpha compositing:
    $$ \hat{\mathbf{c}}(\mathbf{r}) = \sum_{i=1}^{N_s} \left( \prod_{j=1}^{i-1} 1 - \hat{\alpha}_j \right) \hat{\alpha}_i \mathbf{c}_i $$
    [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import math

class ProNeRF:
    def __init__(self, N_s=8, N_n=4, N_pr=48, N_explore=64):
        self.N_s = N_s
        self.N_n = N_n
        self.N_pr = N_pr
        self.N_explore = N_explore
        # Initialize networks F_theta_c, F_theta_f, F_theta_s, F_theta_m (optional)
        self.F_c = CoarseMLP()
        self.F_f = FeatureMLP()
        self.F_s = ShadingMLP()
        self.F_m = PruningMLP() # Optional

    def encode_ray(self, r_o, r_d, t_n, t_f):
        # Plucker ray-point encoding
        t_nf = torch.linspace(t_n, t_f, self.N_pr, device=r_o.device)
        # r_o + r_d * t_nf
        pts = r_o.unsqueeze(1) + r_d.unsqueeze(1) * t_nf.unsqueeze(0)
        # r_d * pts
        pts_dot = pts * r_d.unsqueeze(1)
        # Concatenate r_d, pts, pts_dot
        r_pr = torch.cat([r_d.unsqueeze(1), pts, pts_dot], dim=-1)
        return r_pr

    def get_projections(self, coarse_points, ref_cameras, ref_images):
        # coarse_points: [N_s, 3]
        # ref_cameras: list of [R, t] or similar
        # ref_images: list of [H, W, 3]
        projections = []
        for i in range(self.N_s):
            p_i = coarse_points[i]
            view_colors = []
            for k in range(self.N_n):
                # Trace line from p_i to camera center k
                # Intersect with image plane k to get color
                # This is a placeholder for the actual projection logic
                c_k = trace_and_sample(p_i, ref_cameras[k], ref_images[k])
                view_colors.append(c_k)
            projections.append(torch.stack(view_colors))
        return torch.stack(projections) # [N_s, N_n, 3]

    def forward(self, r_o, r_d, t_n, t_f, ref_cameras, ref_images, mode='full'):
        r_pr = self.encode_ray(r_o, r_d, t_n, t_f)
        
        # 1. Coarse Sampling
        out_c = self.F_c(r_pr)
        T_prime = out_c['distances'] # [N_s]
        A_t, B_t = out_c['opacity_shift'], out_c['opacity_scale']
        c_c = out_c['color']
        W, M = out_c['weights_W'], out_c['weights_M']
        
        # 2. Projections
        coarse_pts = r_o + r_d * T_prime.unsqueeze(1) # [N_s, 3]
        F_p = self.get_projections(coarse_pts, ref_cameras, ref_images) # [N_s, N_n, 3]
        
        # 3. Refinement
        # Concatenate r_pr and flattened F_p
        F_p_flat = F_p.view(self.N_s, -1)
        input_f = torch.cat([r_pr, F_p_flat], dim=-1)
        out_f = self.F_f(input_f)
        Delta_T = out_f['refinement']
        
        # Expanded set for interpolation
        T_expanded = torch.cat([torch.tensor([t_n], device=r_o.device), T_prime, torch.tensor([t_f], device=r_o.device)])
        # Refine T
        T = 0.5 * ((T_expanded[:-2] + T_expanded[1:-1]) + Delta_T * (T_expanded[2:] - T_expanded[:-2]))
        
        # 4. Fast Rendering (AVR)
        # c_avr_k = sum(W_i * c_k_pi)
        # c_f = sum(M_k * c_avr_k)
        # This is a simplified aggregation based on Eq 10 and 11
        # W is [N_s], F_p is [N_s, N_n, 3]
        c_avr = torch.sum(W.unsqueeze(1).unsqueeze(1) * F_p, dim=0) # [N_n, 3]
        c_f = torch.sum(M.unsqueeze(1) * c_avr, dim=0) # [3]
        
        if mode == 'fast':
            return c_f

        # 5. Full Rendering
        pts = r_o + r_d * T.unsqueeze(1) # [N_s, 3]
        sigma, c_s = self.F_s(pts)
        
        # Compute opacities
        # t_i+1 - t_i needs to be handled carefully for boundaries
        # Assuming T is sorted and represents sample positions
        # Standard NeRF opacity calculation
        dt = torch.diff(torch.cat([torch.tensor([t_n], device=r_o.device), T]))
        alpha = 1.0 - torch.exp(-sigma * dt)
        
        # Apply adjustments A_t, B_t? The text mentions A_t, B_t are predicted but 
        # the exact formula for their application to alpha is not fully explicit in the provided snippets 
        # other than "adjusting alpha_i in Eq. 4". Eq 4 is not provided in the notes.
        # We assume standard alpha compositing for now, or that A_t/B_t modify sigma/alpha directly.
        # For implementation, one might apply: alpha_adj = alpha * B_t + A_t (hypothetical)
        # Given the ambiguity, we stick to standard VRE with the provided alpha.
        
        transmittance = torch.cumprod(1.0 - alpha, dim=0)
        transmittance = torch.cat([torch.ones(1, device=r_o.device), transmittance[:-1]])
        
        c_full = torch.sum(transmittance.unsqueeze(1) * alpha.unsqueeze(1) * c_s, dim=0)
        
        return c_full, c_c, c_f

    def train_step(self, ray, gt_color, iteration):
        # Exploration/Exploitation logic
        if iteration % 2 == 0 and iteration < 400000:
            # Exploration
            N_s_plus = torch.randint(self.N_s, self.N_explore, (1,)).item()
            T_plus = sample_around(self.T, N_s_plus) + noise
            sigma, c_s = self.F_s(ray.origin + ray.dir * T_plus)
            c_pred = render_vre(T_plus, sigma, c_s)
            loss = mse(c_pred, gt_color)
            # Update only F_theta_s
            update_optimizer(self.opt_s, loss)
        else:
            # Exploitation
            c_full, c_c, c_f = self.forward(ray, mode='full')
            loss = mse(c_full, gt_color)
            if iteration < 400000:
                loss += mse(c_c, gt_color) + mse(c_f, gt_color)
            # Update all networks
            update_optimizer(self.opt_all, loss)
```

**Parameters:**
*   $N_s$: Number of fine samples (e.g., 8, 12, 32).
*   $N_n$: Number of neighboring reference views for projection (small fixed subset).
*   $N_{pr}$: Number of points in Plucker encoding (48).
*   $N$: Maximum exploration samples (64).
*   $\lambda$: Auxiliary loss weight (1 for first 60% of training, 0 thereafter).
*   Learning Rate: $5 \times 10^{-4}$, exponentially decayed over 700K iterations.
*   Batch Size: 4,096 rays [S1].

**Edge Cases and Pitfalls:**
*   **Boundary Conditions:** The interpolation for $T$ requires careful handling of $t_n$ and $t_f$ indices in $\dot{T}$ [S1].
*   **Auxiliary Loss:** Removing the auxiliary loss $l_a$ causes an almost 1 dB drop in PSNR, indicating its critical role in regularization [S1].
*   **Plucker Encoding:** Removing Plucker ray-point encoding causes an almost 0.5 dB PSNR drop [S1].

## Subtopics

### ProNeRF-8
The variant with 8 samples. Achieves 26.78 dB PSNR on LLFF, outperforming vanilla NeRF (26.50 dB) by 0.28 dB while being >20x faster [S1].

### ProNeRF-12
The variant with 12 samples. Achieves 27.15 dB PSNR on LLFF, 0.65 dB higher than vanilla NeRF, while being ~15x faster [S1].

### ProNeRF-32
Evaluated on Blender dataset, achieving 31.92 dB PSNR and 3.2 FPS after pruning [S1].

### ProNeRF-8 Prune
Uses a pruning head $F_{\theta_m}$ to predict rendering error. If error is low, uses fast AVR output; otherwise, runs shading network. 23% faster than standard ProNeRF-8 with negligible quality drop [S1].

## Operating characteristics
*   **Speed:** 15–23× faster than vanilla NeRF [S1]. ProNeRF-8 is >20x faster; ProNeRF-12 is ~15x faster [S1].
*   **Quality:** 0.65 dB higher PSNR than vanilla NeRF on LLFF; 0.95 dB higher PSNR than HyperReel [S1].
*   **Memory:** Similar to NeRF. Pruning adds 3.3 MB overhead [S1].
*   **Scaling:** Uses a fixed subset of reference views, ensuring consistent memory footprint regardless of total training views [S1].
*   **Strengths:** High speed, high quality, efficient sampling.
*   **Limitations:** Requires multi-view training data; relies on accurate camera poses for projections [S1].

## Background
ProNeRF was proposed in 2024 by the authors of the source paper [S1]. It addresses the quality degradation in sampler-based methods and the memory issues in generalizable radiance fields by using a projection-aware sampling network and an exploration-exploitation training strategy [S1]. It is evaluated on LLFF and Blender datasets [S1].
