# HyperNeRFGAN

Also called: HyperNeRFGAN: Hypernetwork approach to 3D NeRF GAN

## Overview
HyperNeRFGAN is a generative adversarial network (GAN) architecture that synthesizes 3D-aware radiance field representations from 2D images without requiring camera pose information during training [S1, unofficial]. It solves the limitation of standard NeRF-based generators, which depend on known camera positions, by employing a hypernetwork to generate the weights of a simplified NeRF target network directly from a Gaussian noise vector [S1, unofficial]. Unlike sibling methods such as GRAF or $\pi$-GAN that condition SIREN networks, HyperNeRFGAN uses a hypernetwork paradigm to produce NeRF weights, enabling 3D-aware image generation on datasets where camera estimation is challenging or impossible [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A noise vector $\mathbf{z}$ sampled from a standard Gaussian distribution $P_{\text{noise}}$ [S1, unofficial].
*   **Output:** A generated 2D image rendered from the instantiated NeRF representation [S1, unofficial].

**Data Structures:**
1.  **Generator ($G$):** A StyleGAN2-based network that acts as the hypernetwork. It maps $\mathbf{z}$ to the weights of the target NeRF [S1, unofficial].
2.  **Target NeRF ($F_\theta$):** A simplified Multi-Layer Perceptron (MLP) representing the radiance field.
    *   **Architecture:** Single MLP.
    *   **Input:** Spatial location $\mathbf{x} = (x, y, z)$ only. Viewing direction $\mathbf{d}$ is omitted [S1, unofficial].
    *   **Output:** Color $\mathbf{c}$ and volume density $\sigma$ [S1, unofficial].
    *   **Layers:** Uses Factorized Multiplicative Modulation (FMM) layers instead of standard linear layers [S1, unofficial].
    *   **Dimensions:** Hidden layer channels reduced to 128 (standard is 256). Depth reduced to 4 or 8 layers [S1, unofficial].
    *   **Scope:** Only the "coarse" network is used; the "fine" network from standard NeRF is rejected to reduce computational cost [S1, unofficial].
3.  **Discriminator ($D$):** A standard 2D CNN discriminator that evaluates rendered 2D images [S1, unofficial].

**Parameters:**
*   **Rank $k$:** Controls the rank of the modulation matrices in FMM layers. Default value: $k=10$ [S1, unofficial].
*   **Hidden Channels:** 128 [S1, unofficial].
*   **Network Depth:** 4 or 8 layers [S1, unofficial].

**Formulas:**
The rendering process follows the standard volume rendering integral defined in the parent article [Parent](8585-specific-model-architectures.md). The NeRF function is defined as:
$$
F_\theta: \mathbf{x} \rightarrow (\mathbf{c}, \sigma)
$$
where $\mathbf{x} \in \mathbb{R}^3$ [S1, unofficial].

The Factorized Multiplicative Modulation (FMM) layer computes the output $\mathbf{y}$ from input $\mathbf{x}_{\text{in}}$ as:
$$
\mathbf{y} = \mathbf{W} \odot (\mathbf{A} \times \mathbf{B}) \cdot \mathbf{x}_{\text{in}} + \mathbf{b} = \tilde{\mathbf{W}} \cdot \mathbf{x}_{\text{in}} + \mathbf{b}
$$
where:
*   $\mathbf{W}$ and $\mathbf{b}$ are shared weight matrices and bias vector across all generated 3D representations [S1, unofficial].
*   $\mathbf{A}$ is a modulation matrix of size $n_{\text{out}} \times k$ generated by $G$ [S1, unofficial].
*   $\mathbf{B}$ is a modulation matrix of size $k \times n_{\text{in}}$ generated by $G$ [S1, unofficial].
*   $\odot$ denotes element-wise multiplication [S1, unofficial].
*   $\times$ denotes matrix multiplication [S1, unofficial].
*   $n_{\text{in}}$ and $n_{\text{out}}$ are the input and output dimensions of the layer [S1, unofficial].

**Training Objective:**
The model is trained using the minimax game of the StyleGAN2 objective [S1, unofficial]:
$$
\min_G \max_D V(D, G)
$$
where:
$$
V = \mathbb{E}_{\mathbf{x} \sim P_{\text{data}}}[\log D(\mathbf{x})] + \mathbb{E}_{\mathbf{z} \sim P_{\text{noise}}}[\log(1 - D(G(\mathbf{z})))]
$$
Here, $P_{\text{data}}$ is the distribution of real 2D images, and $G(\mathbf{z})$ is the rendered image from the generated NeRF weights [S1, unofficial].

**Numbered Steps:**
1.  Sample a noise vector $\mathbf{z}$ from the Gaussian distribution $P_{\text{noise}}$ [S1, unofficial].
2.  Pass $\mathbf{z}$ through the Generator $G$ to obtain the weights $\theta$ for the target NeRF model $F_\theta$ [S1, unofficial].
3.  Instantiate the target NeRF model $F_\theta$ using the generated weights [S1, unofficial].
4.  Render 2D images from various perspectives using $F_\theta$ [S1, unofficial].
5.  Evaluate the rendered images and real images using the Discriminator $D$ [S1, unofficial].
6.  Update $G$ and $D$ by minimizing the adversarial loss $V(D, G)$ [S1, unofficial].

import torch
import torch.nn as nn
import torch.nn.functional as F

class FMMLayer(nn.Module):
    """
    Factorized Multiplicative Modulation Layer.
    y = W * (A @ B) * x_in + b
    """
    def __init__(self, n_in, n_out, k=10):
        super().__init__()
        self.n_in = n_in
        self.n_out = n_out
        self.k = k
        # Shared weights (initialized once, not generated by G)
        self.W = nn.Parameter(torch.randn(n_out, n_in))
        self.b = nn.Parameter(torch.zeros(n_out))
        # Modulation matrices A and B are generated by the hypernetwork G
        # Dimensions: A is (n_out, k), B is (k, n_in)

    def forward(self, x_in, A, B):
        # A: (n_out, k), B: (k, n_in)
        # Modulation matrix M = A @ B
        M = torch.matmul(A, B)
        # Element-wise multiplication with shared W
        W_mod = self.W * M
        # Linear transformation
        y = torch.matmul(x_in, W_mod.t()) + self.b
        return y

class HyperNeRFGAN:

        """

        # The Discriminator D is a standard 2D image discriminator
        self.discriminator = self._build_discriminator()

**Edge Cases and Pitfalls:**
*   **Viewing Direction:** Standard NeRF requires viewing directions $\mathbf{d}$. HyperNeRFGAN omits this input because the training datasets (e.g., medical DRR, faces) lack view-dependent characteristics like reflections [S1, unofficial]. If view-dependent effects are present, this architecture may fail to capture them [S1, unofficial].
*   **Fine Network:** The "fine" network from standard NeRF is excluded to reduce training cost. This may limit the quality of fine details compared to full NeRF implementations [S1, unofficial].
*   **Rank $k$:** Higher $k$ increases expressiveness but also memory usage. The default $k=10$ is a trade-off [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Training is faster than standard NeRF-based GANs due to the simplified NeRF architecture (single coarse network, reduced hidden dimensions) and the hypernetwork approach which avoids complex conditioning mechanisms [S1, unofficial].
*   **Memory Complexity:** Memory usage is influenced by the rank $k$ of the modulation matrices. Higher $k$ increases memory requirements for the hypernetwork [S1, unofficial].
*   **Performance:**
    *   **ShapeNet Car:** FID 29.6 (vs. Point2NeRF 82.1) [S1, unofficial].
    *   **CARLA:** FID 20.5, KID 0.78, IS 4.20 (outperforming HoloGAN, GRAF, $\pi$-GAN) [S1, unofficial].
    *   **CelebA:** FID 15.04, KID 0.66, IS 2.63 (comparable to $\pi$-GAN) [S1, unofficial].
    *   **Medical (DRR):** Superior FID and KID scores compared to MedNeRF and UMedNeRF [S1, unofficial].
*   **Strengths:** Does not require camera pose estimation; suitable for datasets with few views or no pose information (e.g., medical images, single-view faces); high-quality 3D-aware generation [S1, unofficial].
*   **Limitations:** Cannot model view-dependent effects (e.g., specular highlights) due to the omission of viewing directions [S1, unofficial].

## Background
HyperNeRFGAN was introduced in a paper titled "HyperNeRFGAN: Hypernetwork approach to 3D NeRF GAN" [S1, unofficial]. It builds on the hypernetwork paradigm (Ha et al., 2016) and the StyleGAN2 architecture [S1, unofficial]. It addresses the limitations of previous 3D-aware GANs like GRAF and $\pi$-GAN, which rely on SIREN networks and complex conditioning mechanisms [S1, unofficial]. The method was applied to ShapeNet, CARLA, CelebA, and medical DRR datasets [S1, unofficial].
