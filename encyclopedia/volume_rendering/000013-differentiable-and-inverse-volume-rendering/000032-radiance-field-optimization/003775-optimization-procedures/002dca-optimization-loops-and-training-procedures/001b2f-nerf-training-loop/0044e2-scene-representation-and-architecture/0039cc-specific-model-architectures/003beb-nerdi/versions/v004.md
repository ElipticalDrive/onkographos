# NeRDi


## Overview
NeRDi is a single-view synthesis method that leverages general image priors from a pre-trained 2D diffusion model to optimize a Neural Radiance Field (NeRF) [S2]. It solves the problem of novel view synthesis from a single input image by minimizing the diffusion loss of rendered arbitrary views under input view constraints [S2]. Unlike traditional NeRF which relies on multi-view consistency or explicit geometric supervision, NeRDi uses a pre-trained diffusion model as a regularizer, supplemented by semantic and geometric guidance to ensure multi-view consistency and 3D structural validity [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A single input image $I_{in}$.
*   **Output:** A NeRF model $F_\Theta$ capable of rendering novel views of the scene depicted in $I_{in}$ [S2].

**Data Structures:**
*   **NeRF Model $F_\Theta$:** A multi-layer perceptron (MLP) mapping 3D position $\mathbf{x}$ and viewing direction $\mathbf{d}$ to volume density $\sigma$ and RGB color $\mathbf{c}$, as defined in [Specific Model Architectures](8585-specific-model-architectures.md).
*   **Visual Language Model (VLM):** A pre-trained model used to extract text embeddings from the input image [S1].
*   **Diffusion Model:** A pre-trained 2D image diffusion model used for computing the diffusion loss [S2].
*   **Depth Estimator:** A module used to estimate depth maps from rendered views for geometric loss calculation [S2].

**Parameters:**
*   **Learning Rate:** Not given in the sources.
*   **Diffusion Model Steps:** Not given in the sources.
*   **Loss Weights:** Not given in the sources.

**Steps:**
1.  **Semantic Guidance Extraction:** Given the input image $I_{in}$, use a pre-trained visual language model to generate two language guides [S1]:
    *   $s_0$: An image title containing overall semantics [S1].
    *   $s^*$: A text embedding extracted from $I_{in}$ capturing visual clues [S1].
2.  **NeRF Rendering:** Sample rays through the NeRF model $F_\Theta$ to render an arbitrary view $I_{render}$ [S2].
3.  **Diffusion Loss Calculation:** Compute the diffusion loss by conditioning the pre-trained 2D diffusion model on the semantic guides $s_0$ and $s^*$, and comparing the model's prediction against the rendered view $I_{render}$ [S2]. This step minimizes the discrepancy between the rendered image and the prior distribution of natural images enforced by the diffusion model [S2].
4.  **Geometric Loss Calculation:** Estimate a depth map $D_{render}$ from the rendered view $I_{render}$ [S2]. Compute a geometric loss based on $D_{render}$ to regularize the underlying 3D geometry of the NeRF [S2].
5.  **Optimization:** Update the NeRF parameters $\Theta$ by minimizing the combined loss (Diffusion Loss + Geometric Loss) [S2].

**Pseudocode:**
```python
def nerdi_train(input_image, nerf_model, diffusion_model, vlm_model, depth_estimator, optimizer):
    # Step 1: Extract semantic guidance
    s0 = vlm_model.generate_title(input_image)
    s_star = vlm_model.extract_embedding(input_image)
    
    # Step 2-4: Forward pass and loss computation
    # Render arbitrary view from current NeRF
    rendered_image = nerf_model.render_arbitrary_view()
    
    # Compute diffusion loss conditioned on semantic guides
    # The diffusion model predicts noise or score based on s0, s_star, and rendered_image
    diffusion_loss = compute_diffusion_loss(diffusion_model, rendered_image, s0, s_star)
    
    # Estimate depth from rendered image
    estimated_depth = depth_estimator.predict(rendered_image)
    
    # Compute geometric loss to regularize 3D structure
    geometric_loss = compute_geometric_loss(estimated_depth)
    
    # Combined loss
    total_loss = diffusion_loss + geometric_loss
    
    # Step 5: Update NeRF parameters
    optimizer.zero_grad()
    total_loss.backward()
    optimizer.step()
    
    return total_loss
```

**Edge Cases and Pitfalls:**
*   **Single View Ambiguity:** Without multi-view constraints, the NeRF may converge to a 2D plane or inconsistent geometry. The geometric loss and diffusion prior are critical to mitigate this [S2].
*   **Semantic Misalignment:** If the VLM extracts incorrect semantics ($s_0, s^*$), the diffusion guidance may enforce incorrect structures. [S1]

## Subtopics

### Semantic Guidance
Uses VLM-extracted text embeddings ($s_0, s^*$) to condition the diffusion model, improving multi-view content consistency [S1].

### Geometric Regularization
Uses estimated depth maps to enforce 3D structural validity, preventing flat or inconsistent reconstructions [S2].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** On the DTU dataset, the PSNR is twice as high as that of traditional NeRF [S1].
*   **Strengths:** Suitable for zero-shot NeRF synthesis from a single image; improves multi-view consistency through diffusion priors [S1, S2].
*   **Limitations:** Relies on the quality of pre-trained models (VLM, Diffusion); computational cost of diffusion model inference during training is not specified but likely high [S2].
*   **When to use:** Single-view synthesis where multi-view data is unavailable [S2].
*   **When not to use:** When high-frequency details are critical and the diffusion prior fails to capture them, or when multi-view data is available for more stable optimization [S2].

## Background
NeRDi was proposed by Deng et al. in 2023 [S2]. It is inspired by classic multi-view stereo methods but adapts them for single-view synthesis using 2D diffusion models [S2]. The method builds on the concept of using general image priors to regularize NeRF optimization, addressing the limitations of traditional NeRF which struggles with single-view inputs due to lack of geometric constraints [S2].
