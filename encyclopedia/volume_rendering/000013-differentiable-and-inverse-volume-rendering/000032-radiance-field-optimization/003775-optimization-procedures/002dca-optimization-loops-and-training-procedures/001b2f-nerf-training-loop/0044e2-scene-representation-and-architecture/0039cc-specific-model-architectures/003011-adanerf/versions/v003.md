# AdaNeRF

Also called: AdaNeRF: Adaptive Sampling for Real-time Rendering of Neural Radiance Fields

## Overview
AdaNeRF is a method that employs fixed sample positions along each ray and incrementally introduces sparsity during training to achieve real-time rendering [S1]. It reduces the number of sample points by training a sampling network to predict all weights for points on a line in one go, thereby reducing the number of sample points required for rendering [S2, unofficial]. It sets itself apart from siblings like SfMNeRF and DASNeRF by focusing on adaptive weight prediction via a split-network architecture rather than geometric priors or feature map fusion.

## How it works
**Inputs and Outputs:**
- Input: Camera parameters (position, orientation, intrinsics), scene data (images).
- Output: Rendered image pixels.

**Data Structures:**
The method splits the standard NeRF MLP into two distinct networks:
1.  **Sampling Network:** A lightweight network.
2.  **Shading Network:** A heavier network.

**Steps:**
1.  **Initialization:** Initialize the Sampling Network and Shading Network. The Shading Network is typically initialized from a pre-trained NeRF to achieve the best results, as the method can be trained end-to-end but benefits from this initialization [S1].
2.  **Fixed Sampling:** Define a fixed set of sample positions along each view ray. Unlike adaptive sampling methods that query the network for new positions, AdaNeRF uses these fixed locations [S1].
3.  **Weight Prediction:** The Sampling Network evaluates once per ray to predict importance weights for all fixed sample points [S1]. This allows the system to identify which samples are significant.
4.  **Selective Shading:** The Shading Network processes only the most significant samples identified by the Sampling Network [S1]. This reduces the computational cost per ray.
5.  **Sparsity Introduction:** During training, sparsity is incrementally introduced. This encourages the Sampling Network to concentrate weights on fewer points [S1].
6.  **Fine-tuning:** Fine-tune the model to the desired number of samples to create a compact neural representation [S1].
7.  **Rendering:** Render using the weighted sum of colors from the shaded samples.

**Pseudocode:**
```python
def render_ray(ray_origin, ray_direction, sampling_network, shading_network, fixed_samples):
    """
    fixed_samples: List of relative distances along the ray [t1, t2, ..., tN]
    """
    # Step 1: Get absolute positions
    positions = ray_origin + ray_direction * fixed_samples
    
    # Step 2: Sampling Network predicts weights for all fixed samples
    # The network evaluates once per ray
    weights = sampling_network(positions)
    
    # Step 3: Identify significant samples based on weights
    # Threshold or top-k selection logic [G]
    significant_indices = select_significant(weights)
    significant_positions = [positions[i] for i in significant_indices]
    
    # Step 4: Shading Network processes only significant samples
    # Returns density (sigma) and color (c)
    sigmas, colors = shading_network(significant_positions)
    
    # Step 5: Volume Rendering with selected samples and original weights
    # Note: Weights from sampling network act as importance factors
    # Standard volume rendering formula applied to selected points
    # T_i = exp(-sum(sigma_j * delta_j))
    # C(r) = sum(T_i * alpha_i * c_i)
    
    rendered_color = volume_render(significant_positions, sigmas, colors, weights[significant_indices])
    
    return rendered_color
```

**Parameters:**
- Number of fixed samples: Not given in the sources.
- Sparsity schedule: Not given in the sources.

**Edge Cases:**
- Geometrically ambiguous regions: AdaNeRF improves quality in these regions without the need for a depth map [S1].

## Operating characteristics
- **Time Complexity:** Reduced compared to standard NeRF due to fewer shading network evaluations per ray. The sampling network is lightweight.
- **Memory Complexity:** Compact neural representation after fine-tuning [S1].
- **Performance:** Can be rendered in real-time after fine-tuning to the desired number of samples [S1]. Adaptable to meet performance targets for real-time applications [S1].
- **Strengths:** Real-time rendering capability, no depth map required, handles geometric ambiguity well.
- **Limitations:** Requires a pre-trained NeRF for initialization for best results [S1].

## Background
AdaNeRF was introduced by Kurz et al. [KNL* 22] in the paper "AdaNeRF: Adaptive Sampling for Real-time Rendering of Neural Radiance Fields" presented at ECCV 2022 [S2, unofficial]. It is part of the broader effort to accelerate neural radiance fields by reducing sampling costs [S2, unofficial].
