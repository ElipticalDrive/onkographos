# Drone-NeRF Training

Also called: NeRF Training in Drone-View Block

## Overview
Drone-NeRF Training optimizes large-scale 3D scene reconstruction from aerial imagery by addressing unbounded space representation and varying camera exposure [S1]. It differs from standard NeRF training by using view frustum sampling for anti-aliasing, a pose optimizer for joint pose refinement, appearance embeddings for exposure balancing, and a spatial contraction function to map unbounded scenes into a bounded domain [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   A set of drone-view images $I_i$ with associated camera poses $P_i$ (extrinsics) and intrinsics $K$ [S1].
*   A predefined number of samples $N$ for the initial stage [S1].
*   A spatial distortion correction scope parameter (implicit in the contraction function) [S1].

**Outputs:**
*   Optimized neural network weights (MLP parameters for density $\sigma$ and color $c$) [S1].
*   Optimized camera poses $P_i$ [S1].
*   Appearance embeddings for each image [S1].

### Data Structures
*   **Image Pyramid:** A list of downsampled versions of the input image $I_i$, used to guide sampling density [S1].
*   **View Frustum:** Defined by the camera intrinsics $K$ and extrinsics $P_i$ [G]. For a pixel $(u, v)$, the frustum is approximated by the volume between the near and far planes intersected by the pixel's angular extent [G].
*   **MLP:** A Multi-Layer Perceptron taking encoded position, direction, and appearance embedding as input, outputting volume density $\sigma$ and RGB color $c$ [G].
*   **Appearance Embedding:** A learnable vector $e_i$ associated with each image $i$, concatenated with position/direction encodings [S1].

### Steps

1.  **Image Pyramid Construction:**
    Generate a pyramid of downsampled images from the input $I_i$ to focus on details at various spatial scales and enhance adaptability to diverse scene structures [S1].

2.  **View Frustum Sampling:**
    For each pixel $(u, v)$ in the target image, sample points within a viewing frustum rather than a single ray to achieve anti-aliasing and better represent intricate details; the pixel area utilized is an approximation [S1].

3.  **Spatial Contraction:**
    Apply a spatial distortion correction function $f(x)$ to warp scene coordinates, ensuring scene shrinkage warps unbounded samples into bounded space for effective rendering [S1]. The function is defined as:
    $$f(x) = \begin{cases} x & \|x\| \leq 1 \\ \left(2 - \frac{1}{\|x\|}\right) \cdot \frac{x}{\|x\|} & \|x\| > 1 \end{cases}$$
    where $\|x\| = \sqrt{x^2}$ is the Euclidean norm. The $L_\infty$ contraction is preferred for cube-space scenes to reduce edge distortion compared to spherical ($L_2$) contraction [S1].

4.  **Multi-Stage Stratified Sampling:**
    *   **Stage 1 (Pre-sampling):** Perform pre-sampling based on the targeted number of samples $N$ using a predefined sampler. Transform the sampled points into Euclidean space to identify samples that contribute significantly to the final color rendering [S1].
    *   **Stage 2 (PDF Sampling):** Use the weights from Stage 1 to construct a Probability Distribution Function (PDF). Perform stratified sampling according to this PDF, intensifying sampling density in regions with larger weights [S1].

5.  **Neural Network Forward Pass:**
    Encode the sampled positions and view directions using positional encoding. Concatenate the appearance embedding $e_i$ (specific to image $i$) with the encoded position and direction. Pass the concatenated vector through the MLP to predict volume density $\sigma$ and RGB color $c$ [S1]. The appearance embedding resolves discrepancies arising from variations in camera exposure, balancing brightness differences across images [S1].

6.  **Volume Rendering:**
    Compute the rendered color $C$ for each pixel using standard volume rendering integration over the sampled points along the frustum rays:
    $$C = \sum_{i=1}^{N} T_i \alpha_i c_i$$
    where $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$, $T_i = \exp(-\sum_{j=1}^{i-1} \sigma_j \delta_j)$, and $\delta_i$ is the distance between samples [G].

7.  **Pose Optimization:**
    Direct the ray bundle (formed by the viewing frustum) into a Pose Optimizer. Back-propagate the loss gradients to the input pose calculation $P_i$ to optimize the pose parameters, iteratively refining them to enhance rendering precision [S1].

8.  **Loss Computation and Update:**
    Compute the loss between the rendered image and the ground truth image $I_i$. Update the MLP weights, appearance embeddings, and camera poses using gradient descent [G].

def sample_frustum(pixel_coords, pose, intrinsics, num_samples):
    """Samples points within a viewing frustum for anti-aliasing [S1]."""
    # Approximates pixel area by generating rays within the pixel's angular extent [G]
    return [pose.origin + t * pose.direction for t in range(1, num_samples + 1)]

def spatial_contraction(x):
    """Applies spatial distortion correction function f(x) to warp unbounded space [S1]."""
    norm_x = math.sqrt(sum(v**2 for v in x))
    if norm_x <= 1.0:
        return x
    return [(2.0 - 1.0 / norm_x) * (v / norm_x) for v in x]

def encode_positions_and_directions(positions, directions):
    """Applies standard positional encoding to positions and view directions [G]."""
    return positions, directions

def concat(*arrays):
    """Concatenates multiple vectors along the last dimension."""
    return [val for arr in arrays for val in arr]

def compute_sample_weights(densities, samples):

    return [math.exp(-d) for d in densities]

def stratified_pdf_sampling(samples, pdf, num_samples):
    """Intensifies sampling density in high-weight regions using PDF [S1]."""
    # Resamples points according to probability distribution [G]
    return samples[:num_samples]

def volume_rendering(samples, sigmas, colors):
    """Standard volume rendering integration [G]."""
    rendered = [0.0, 0.0, 0.0]
    T = 1.0
    for sigma, color in zip(sigmas, colors):
        alpha = 1.0 - math.exp(-sigma)
        rendered = [rendered[i] + T * alpha * color[i] for i in range(3)]

### Parameters and Typical Values
*   **Number of Samples (Stage 1):** Predefined, e.g., 64 [S1].
*   **Number of Samples (Stage 2):** Determined by PDF, e.g., 128 [S1].
*   **Contraction Type:** $L_\infty$ is preferred for cube-space scenes to reduce edge distortion [S1].
*   **Appearance Embedding Dimension:** Not given in the sources.

### Edge Cases and Pitfalls
*   **Spatial Distortion Scope:** If the space warp scope is not suitable for the scene, the scene within the original reasonable field of view will be distorted and deformed [S1].
*   **Frustum Approximation:** The pixel area utilized in frustum sampling is an approximation [S1].
*   **Exposure Discrepancies:** Without appearance embeddings, variations in camera exposure will cause rendering artifacts [S1].

## Operating characteristics

### Time and Memory Complexity
*   **Time:** Higher than standard NeRF due to multi-stage sampling and pose optimization. The frustum sampling adds overhead per pixel compared to single-ray sampling [S1].
*   **Memory:** Increased memory usage due to storing appearance embeddings for each image and maintaining image pyramids [S1].

### Measured Performance
*   Not given in the sources.

### Scaling
*   The method is designed for large-scale drone surveys by dividing the scene into sub-scenes (blocks) [S1].

### Strengths and Limitations
*   **Strengths:** Handles unbounded scenes effectively via spatial contraction; improves rendering quality for intricate details via frustum sampling and anti-aliasing; robust to exposure variations via appearance embeddings; improves pose accuracy via joint optimization [S1].
*   **Limitations:** Sensitive to the choice of spatial warp scope; computational cost of multi-stage sampling and pose optimization is higher than standard NeRF [S1].

## Background

### Origin
Drone-NeRF was introduced in the paper "Drone-NeRF: Efficient NeRF based 3D scene reconstruction for large-scale drone survey" [S1].

### History and Development
The method builds upon NeRF and addresses specific challenges in aerial photogrammetry, such as unbounded scene representation and exposure variations. It integrates techniques from differentiable rendering and pose optimization [S1].

### Usage
Used for 3D scene reconstruction from drone-captured images, particularly in large-scale surveying applications [S1].
