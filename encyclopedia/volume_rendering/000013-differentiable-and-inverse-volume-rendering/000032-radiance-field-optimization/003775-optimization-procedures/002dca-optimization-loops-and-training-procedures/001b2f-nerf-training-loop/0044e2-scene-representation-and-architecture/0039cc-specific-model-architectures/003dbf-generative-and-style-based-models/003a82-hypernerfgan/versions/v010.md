# HyperNeRFGAN

Also called: HyperNeRFGAN

## Overview
HyperNeRFGAN is a generative model that uses a hypernetwork to produce the weights of a simplified NeRF target network, trained using the StyleGAN2 objective to generate 3D representations from a Gaussian noise distribution [S1, unofficial]. It solves the problem of 3D-aware image generation when camera positions are unavailable or unreliable by removing viewing directions from the NeRF input and using a hypernetwork to implicitly encode 3D structure [S1, unofficial]. Unlike siblings such as [Latent-NeRF](9110-latent-nerf.md) which optimize latent codes for specific instances, HyperNeRFGAN generates the network parameters themselves, allowing for the synthesis of novel 3D objects from noise [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A noise vector $\mathbf{z}$ sampled from a standard Gaussian distribution $\mathcal{N}(0, I)$.
*   **Output:** A rendered 2D image $\mathbf{C}(\mathbf{r})$ from a specified camera perspective, and the discriminator's classification of the image.

**Data Structures:**
1.  **Generator $G$ (Hypernetwork):** A StyleGAN2-based architecture. It takes $\mathbf{z}$ and outputs modulation matrices $\mathbf{A}$ and $\mathbf{B}$ for each layer of the target network.
2.  **Target Network $F_\theta$ (NeRF):** A single MLP that maps 3D spatial coordinates to color and density. It does not take viewing direction as input.
    *   **Layer Structure:** The network uses Factorized Multiplicative Modulation (FMM) layers.
    *   **Shared Weights:** Matrices $\mathbf{W}$ and bias $\mathbf{b}$ are shared across all generated 3D representations (instances).
    *   **Modulation:** The effective weight matrix $\tilde{\mathbf{W}}$ for a layer is computed as $\tilde{\mathbf{W}} = \mathbf{W} \odot (\mathbf{A} \times \mathbf{B})$.
    *   **Dimensions:**
        *   $\mathbf{W} \in \mathbb{R}^{n_{out} \times n_{in}}$
        *   $\mathbf{b} \in \mathbb{R}^{n_{out}}$
        *   $\mathbf{A} \in \mathbb{R}^{n_{out} \times k}$
        *   $\mathbf{B} \in \mathbb{R}^{k \times n_{in}}$
        *   $k$ is the rank parameter, controlling the expressiveness and memory usage. The source specifies $k=10$ [S1, unofficial].
3.  **Discriminator $D$:** A standard 2D CNN discriminator that evaluates the rendered images.

**Parameters:**
*   **Hidden Layer Channels:** Reduced from the standard 256 to 128 to reduce computational expense [S1, unofficial].
*   **Network Depth:** Reduced from 8 layers to 4 layers in some experiments to reduce computational expense [S1, unofficial].
*   **Rank $k$:** Fixed at 10 [S1, unofficial].

**Numbered Steps:**
1.  **Sample Noise:** Sample a noise vector $\mathbf{z} \sim \mathcal{N}(0, I)$ [S1, unofficial].
2.  **Generate Weights:** Pass $\mathbf{z}$ through the Generator $G$ to obtain the modulation matrices $\mathbf{A}_l$ and $\mathbf{B}_l$ for each layer $l$ of the target network [S1, unofficial].
3.  **Instantiate Target Network:** Construct the target NeRF $F_\theta$ using the shared weights $\mathbf{W}_l, \mathbf{b}_l$ and the generated modulation matrices $\mathbf{A}_l, \mathbf{B}_l$. The effective transformation for layer $l$ is:
    $$ \mathbf{y}_l = \tilde{\mathbf{W}}_l \mathbf{x}_{in} + \mathbf{b}_l = (\mathbf{W}_l \odot (\mathbf{A}_l \times \mathbf{B}_l)) \mathbf{x}_{in} + \mathbf{b}_l $$
    where $\mathbf{x}_{in}$ is the input to the layer (either spatial coordinates $\mathbf{x}$ or the output of the previous layer) [S1, unofficial].
4.  **Render Image:** Query the instantiated $F_\theta$ along rays $\mathbf{r}$ defined by the desired camera perspective. Since $F_\theta$ does not take viewing direction $\mathbf{d}$ as input, it outputs $\sigma(\mathbf{x})$ and $\mathbf{c}(\mathbf{x})$. Compute the pixel color $\mathbf{C}(\mathbf{r})$ using the standard volume rendering integral:
    $$ \mathbf{C}(\mathbf{r}) = \sum_{i=1}^{N} T_i \alpha_i \mathbf{c}_i $$
    where $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ and $T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right)$ [S1, unofficial].
5.  **Discriminator Evaluation:** Pass the rendered image and real images from the dataset through the Discriminator $D$ to obtain scores [S1, unofficial].
6.  **Update Weights:** Update $G$ and $D$ using the StyleGAN2 minimax objective:
    $$ \min_G \max_D V(D, G) $$
    $$ V(D, G) = \mathbb{E}_{\mathbf{x} \sim P_{data}}[\log D(\mathbf{x})] + \mathbb{E}_{\mathbf{z} \sim P_{noise}}[\log(1 - D(G(\mathbf{z})))] $$
    [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Viewing Direction:** The model does not use viewing directions. If the dataset contains view-dependent effects (e.g., reflections), the model may fail to capture them accurately [S1, unofficial].
*   **Fine Network:** The model rejects the "fine" network used in standard NeRF for multi-scale rendering, using only the "coarse" network. This reduces training cost but may limit rendering quality at high resolutions [S1, unofficial].
*   **Rank $k$:** Higher values of $k$ increase expressiveness but also memory usage. The source fixes $k=10$ [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Training time is reduced compared to standard NeRF due to the use of only the "coarse" network and reduced hidden layer channels (128 vs 256) and layers (4 vs 8) [S1, unofficial].
*   **Memory Complexity:** Memory usage is influenced by the rank $k$ of the modulation matrices. Higher $k$ increases memory usage [S1, unofficial].
*   **Performance:**
    *   **ShapeNet Car:** FID 29.6 (vs Point2NeRF 82.1) [S1, unofficial].
    *   **CARLA:** FID 20.5, KID 0.78, IS 4.20 (vs HoloGAN FID 67.5, GRAF FID 41.7, $\pi$-GAN FID 29.2) [S1, unofficial].
    *   **CelebA:** FID 15.04, KID 0.66, IS 2.63 (comparable to $\pi$-GAN FID 14.7, KID 0.39, IS 2.62) [S1, unofficial].
*   **Strengths:** Does not require camera position information; suitable for datasets where camera estimation is challenging (e.g., medical data); superior performance on datasets with few perspectives per object [S1, unofficial].
*   **Limitations:** Cannot model view-dependent effects; relies on the quality of the hypernetwork to generate appropriate NeRF weights; limited to static objects (no time dimension) [S1, unofficial].

## Background
HyperNeRFGAN was introduced in 2023 by authors who sought to overcome the limitation of NeRF training requiring camera positions [S1, unofficial]. It builds on the hypernetwork paradigm [Ha et al., 2016] and the StyleGAN2 architecture [Karras et al., 2020]. It is compared to other 3D-aware GANs such as HoloGAN, GRAF, and $\pi$-GAN [S1, unofficial]. It has been applied to 3D object generation on ShapeNet (car, plane, chair) and CARLA datasets, and for medical applications on Digitally Reconstructed Radiographs (DRR) of chests and knees [S1, unofficial].
