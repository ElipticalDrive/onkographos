# HyperNeRFGAN

Also called: Hypernetwork NeRF GAN, HyperNeRF

## Overview
HyperNeRFGAN is a generative model that uses a hypernetwork to produce the weights of a simplified NeRF target network, trained using the StyleGAN2 objective to generate 3D representations from a Gaussian noise distribution [S1, unofficial]. It solves the problem of 3D-aware image generation when camera positions are unavailable or difficult to estimate, by removing viewing directions from the NeRF input and using a hypernetwork to implicitly encode 3D structure [S1, unofficial]. It sets itself apart from siblings like [Latent-NeRF](9110-latent-nerf.md) and [Generative and Style-based Models](9572-generative-and-style-based-models.md) by generating the *weights* of the radiance field directly via a hypernetwork, rather than conditioning a fixed network on latent codes or camera parameters [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A noise vector $\mathbf{z}$ sampled from a standard Gaussian distribution $\mathcal{N}(0, I)$ [S1, unofficial].
*   **Output:** A set of weights $\theta$ for the target NeRF network $F_\theta$, which maps a 3D spatial position $\mathbf{x} \in \mathbb{R}^3$ to volume density $\sigma \in \mathbb{R}$ and RGB color $\mathbf{c} \in \mathbb{R}^3$ [S1, unofficial].

**Data Structures:**
1.  **Generator $G$:** A StyleGAN2-based architecture that takes $\mathbf{z}$ and outputs the modulation matrices $A$ and $B$ for the Factorized Multiplicative Modulation (FMM) layers [S1, unofficial].
2.  **Target Network $F_\theta$:** A single MLP consisting of $L$ hidden layers. It contains FMM layers instead of standard linear layers. The weights $W$ and biases $b$ are shared and fixed during the GAN training loop (or updated via the hypernetwork's modulation) [S1, unofficial].
3.  **Discriminator $D$:** A standard 2D CNN discriminator that evaluates rendered 2D images [S1, unofficial].

**Factorized Multiplicative Modulation (FMM) Layer:**
The core building block of the target network $F_\theta$ is the FMM layer. For an input $\mathbf{x}_{in}$, the output $\mathbf{y}$ is computed as:
$$
\mathbf{y} = \mathbf{W} \odot (\mathbf{A} \times \mathbf{B}) \cdot \mathbf{x}_{in} + \mathbf{b} = \tilde{\mathbf{W}} \cdot \mathbf{x}_{in} + \mathbf{b}
$$
where:
*   $\mathbf{W} \in \mathbb{R}^{n_{out} \times n_{in}}$ and $\mathbf{b} \in \mathbb{R}^{n_{out}}$ are shared weight matrices and bias vector [S1, unofficial].
*   $\mathbf{A} \in \mathbb{R}^{n_{out} \times k}$ and $\mathbf{B} \in \mathbb{R}^{k \times n_{in}}$ are modulation matrices generated by $G$ [S1, unofficial].
*   $k$ is the rank parameter controlling the expressiveness and memory usage. The source uses $k=10$ [S1, unofficial].
*   $\tilde{\mathbf{W}} = \mathbf{W} \odot (\mathbf{A} \times \mathbf{B})$ is the effective weight matrix [S1, unofficial].

**Numbered Steps:**
1.  **Sample Noise:** Sample a noise vector $\mathbf{z} \sim \mathcal{N}(0, I)$ [S1, unofficial].
2.  **Generate Weights:** Pass $\mathbf{z}$ through the generator $G$ to obtain the modulation matrices $\mathbf{A}$ and $\mathbf{B}$ for all FMM layers in the target network [S1, unofficial].
3.  **Instantiate Target Network:** Construct the target NeRF $F_\theta$ using the shared weights $\mathbf{W}, \mathbf{b}$ and the generated modulations $\mathbf{A}, \mathbf{B}$ [S1, unofficial].
4.  **Render Image:** Sample points $\mathbf{x}_i$ along rays. Since the model omits viewing directions, $F_\theta$ takes only $\mathbf{x}_i$ as input to predict $\sigma_i$ and $\mathbf{c}_i$. Render the 2D image $I_{gen}$ using volumetric rendering:
    $$
    C(\mathbf{r}) = \sum_{i=1}^N T_i \alpha_i \mathbf{c}_i, \quad \alpha_i = 1 - \exp(-\sigma_i \delta_i), \quad T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)
    $$
    where $\delta_i$ is the distance between samples [S1, unofficial].
5.  **Discriminator Evaluation:** Pass the rendered image $I_{gen}$ and real images $I_{real}$ from the dataset to the discriminator $D$ [S1, unofficial].
6.  **Update GAN:** Minimize the GAN loss:
    $$
    \min_G \max_D V(D, G) = \mathbb{E}_{\mathbf{x} \sim P_{data}}[\log D(\mathbf{x})] + \mathbb{E}_{\mathbf{z} \sim P_{noise}}[\log(1 - D(G(\mathbf{z})))]
    $$
    [S1, unofficial].

**Parameters:**
*   **Hidden Layer Channels:** Reduced from standard 256 to 128 to reduce computational expense [S1, unofficial].
*   **Network Depth:** Reduced from 8 layers to 4 layers in some experiments to reduce computational expense [S1, unofficial].
*   **Rank $k$:** Set to 10 [S1, unofficial].
*   **Fine Network:** Rejected. Only the "coarse" network is used to reduce training cost [S1, unofficial].

**Pitfalls:**
*   **View-Dependent Effects:** The model assumes training images lack view-dependent characteristics (e.g., reflections). It cannot model specular highlights or view-dependent colors because viewing direction is not an input [S1, unofficial].
*   **Camera Poses:** While it removes the need for camera poses during training, it still requires a variety of perspectives to render novel views. If the training data consists of only a single view per object, novel view synthesis is limited to that single perspective [S1, unofficial].

## Subtopics

### Hypernetworks
A network that generates weights for another network. HyperNeRFGAN uses this to map noise to NeRF weights, avoiding explicit conditioning mechanisms [S1, unofficial].

### Factorized Multiplicative Modulation (FMM)
A layer type used in HyperNeRFGAN's target network. It allows the generator to modulate the weights of the target network efficiently using low-rank matrices [S1, unofficial].

### StyleGAN2
The backbone architecture used for the generator $G$ in HyperNeRFGAN, providing the style-based control over the generated weights [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Training is computationally expensive due to the GAN adversarial loop and the need to render images for the discriminator in every step. However, it is cheaper than full NeRF training because it uses only the "coarse" network and reduces hidden layer channels [S1, unofficial].
*   **Memory Complexity:** The memory usage is influenced by the rank $k$ of the FMM layers. Higher $k$ increases expressiveness but also memory usage [S1, unofficial].
*   **Performance:**
    *   **ShapeNet Car:** FID 29.6 (vs. Point2NeRF 82.1) [S1, unofficial].
    *   **CARLA:** FID 20.5, KID 0.78, IS 4.20 (outperforming HoloGAN, GRAF, and $\pi$-GAN) [S1, unofficial].
    *   **CelebA:** FID 15.04, KID 0.66, IS 2.63 (comparable to $\pi$-GAN) [S1, unofficial].
*   **Strengths:** Does not require camera pose estimation; suitable for datasets with few views or unknown poses (e.g., medical DRRs); produces high-quality 3D-aware images [S1, unofficial].
*   **Limitations:** Cannot model view-dependent effects; limited to objects without strong specularities; requires a generator network which adds complexity compared to direct NeRF optimization [S1, unofficial].

## Background
HyperNeRFGAN was introduced in 2023 by authors who sought to combine the quality of Neural Radiance Fields (NeRFs) with the generative capabilities of GANs, specifically addressing the limitation that NeRF training typically requires known camera positions [S1, unofficial]. It builds on the hypernetwork paradigm [Ha et al., 2016] and the INR-GAN architecture, adapting them for 3D representation [S1, unofficial]. It is used for 3D object generation on ShapeNet (car, plane, chair) and CARLA datasets, and for medical applications on Digitally Reconstructed Radiographs (DRR) of chests and knees [S1, unofficial].
