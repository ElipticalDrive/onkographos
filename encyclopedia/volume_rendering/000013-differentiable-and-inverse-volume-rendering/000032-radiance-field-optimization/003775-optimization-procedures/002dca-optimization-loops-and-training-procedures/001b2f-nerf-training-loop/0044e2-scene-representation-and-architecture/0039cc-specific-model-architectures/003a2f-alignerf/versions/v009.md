# AligNeRF

Also called: Alignment-Aware Training for NeRF

## Overview
AligNeRF is a training strategy and architectural modification for Neural Radiance Fields that addresses rendering artifacts caused by misalignment from moving objects or camera calibration errors, while improving high-frequency detail recovery in high-resolution settings [S1, S2]. It sets itself apart from standard NeRF implementations by combining a convolution-augmented architecture with a staged, alignment-aware fine-tuning procedure that utilizes patch-based sampling and optical flow estimation to correct spatial inconsistencies [S1, S2].

## How it works
AligNeRF builds on [Specific Model Architectures](8585-specific-model-architectures.md) by modifying the baseline (specifically mip-NeRF 360) to support local neighborhood information and robust alignment.

### Inputs and Outputs
*   **Inputs:** Camera poses, intrinsic parameters, training images (high-resolution), and estimated optical flow between frames.
*   **Outputs:** Rendered high-fidelity images with reduced blur and misalignment artifacts.

### Data Structures
The method modifies the standard NeRF output structure. Instead of outputting RGB directly, the primary MLP outputs a feature vector.
*   **Feature Space:** The last layer of the MLP outputs $N$ channels (where $N > 3$) instead of 3 (RGB).
*   **Patch Data:** During training, data is organized as $32 \times 32$ pixel patches for rendering and loss computation. Ground truth patches are sampled at $48 \times 48$ pixels to allow for sub-patch searching [S1].

### Algorithm Steps
The training process consists of two stages: Normal Pre-training and Alignment-Aware Fine-tuning [S1].

1.  **Normal Pre-training:**
    *   Train the standard NeRF model (MLP mapping $(\mathbf{x}, \mathbf{d}) \to (\sigma, \mathbf{c})$) using random ray sampling for a standard number of iterations to establish a baseline radiance field [S1].

2.  **Architectural Modification (Applied during Fine-tuning):**
    *   **Feature Output:** Change the MLP's final output layer to produce $N$ feature channels instead of 3 RGB channels [S1].
    *   **Feature Rendering:** Perform numerical integration along the ray in the $N$-dimensional feature space rather than RGB space. This gathers richer representation per ray [S1].
    *   **Convolutional Post-processing:** Apply a 3-layer convolutional network (ReLU activations, $3 \times 3$ kernels) to the rendered feature map.
        *   Use "reflectance" padding for convolution inputs.
        *   Remove padding values in outputs to prevent checkerboard artifacts [S1].
    *   **RGB Projection:** Use a feed-forward perceptron layer at the end of the CNN to convert the processed feature representation back to RGB space [S1].

3.  **Alignment-Aware Fine-tuning:**
    *   **Patch-Based Sampling:** Switch from random ray sampling to patch-based sampling. Gather a $32 \times 32$ local image region during each iteration [S1].
    *   **Ground Truth Patch Sampling:** Sample a larger ground truth patch $G$ of size $48 \times 48$ pixels for each iteration [S1].
    *   **Optical Flow Estimation:** Estimate optical flow to handle moving objects and misalignments [S1].
    *   **Alignment Loss Calculation:**
        *   Render a patch $R$ ($32 \times 32$) from the current model.
        *   Search over every possible subpatch $G_i$ within the larger ground truth patch $G$ to find the best match with $R$.
        *   Compute the loss $L_{PM}$ using the minimum distance over all candidate subpatches, regularized by coordinate offset:
            $$
            L_{PM}(G, R) = \min_{i=1,...,N} \left( D(G_i, R) + \lambda \cdot D_{coord}(G_i, R) \right)
            $$
            where:
            *   $D(G_i, R) = \|G_i - R\|_2$ is the Euclidean distance between the rendered patch and the candidate ground truth subpatch.
            *   $D_{coord}(G_i, R) = \sqrt{\Delta x^2 + \Delta y^2}$ is the Euclidean distance in coordinate space, where $\Delta x$ and $\Delta y$ are the horizontal and vertical offsets between $G_i$ and $R$.
            *   $\lambda$ is a regularization weight, empirically set to $0.01$ [S1].
        *   This regularization penalizes the search space, preventing the model from accepting blurry renders that match multiple ground truth locations equally well [S1].

### Pseudocode

```python
def train_alignerf(model, training_data, optical_flow_estimator, num_iterations):
    """
    Trains AligNeRF using staged training.
    """
    # Stage 1: Normal Pre-training
    for iteration in range(num_pretrain_iterations):
        rays = sample_random_rays(training_data)
        sigma, rgb = model.forward(rays.xyz, rays.direction)
        color = volume_rendering(rays, sigma, rgb)
        loss = mse_loss(color, training_data.targets)
        optimizer.step(loss)

    # Stage 2: Alignment-Aware Fine-tuning
    # Modify model architecture
    model.modify_last_layer_output_channels(N=64) # N is larger than 3, e.g., 64
    model.add_convolutional_post_processor(layers=3, kernel_size=3, padding='reflect')
    model.add_perceptron_layer(input_channels=N, output_channels=3)

    for iteration in range(num_finetune_iterations):
        # Patch-based sampling
        patch_coords = sample_patch_centers(training_data, patch_size=32)
        
        # Render feature maps
        # 1. Sample points along rays in the patch
        points = sample_points_along_rays(patch_coords, near_far_planes)
        
        # 2. Query MLP for sigma and feature vector (N channels)
        sigma, features = model.mlp.forward(points.xyz, points.direction)
        
        # 3. Volume rendering in feature space
        rendered_features = volume_rendering_features(points, sigma, features)
        
        # 4. Convolutional post-processing on the rendered feature map
        # Apply 3-layer CNN with reflectance padding
        processed_features = model.cnn.forward(rendered_features)
        
        # 5. Project to RGB
        rendered_patch_R = model.perceptron.forward(processed_features)
        
        # 6. Alignment Loss Calculation
        # Sample larger ground truth patch G (48x48)
        gt_patch_G = get_gt_patch(patch_coords, size=48)
        
        # Search for best matching subpatch Gi in G
        min_loss = infinity
        best_offset = (0, 0)
        
        # Iterate over all valid subpatches of size 32x32 within 48x48 G
        for i in range(num_subpatches):
            Gi = extract_subpatch(gt_patch_G, i, size=32)
            
            # Euclidean distance in pixel space
            dist_pixel = l2_norm(Gi - rendered_patch_R)
            
            # Coordinate offset penalty
            dx, dy = get_offset(i, rendered_patch_R)
            dist_coord = sqrt(dx**2 + dy**2)
            
            # Regularized loss
            current_loss = dist_pixel + 0.01 * dist_coord
            
            if current_loss < min_loss:
                min_loss = current_loss
                best_offset = (dx, dy)
        
        loss = min_loss
        optimizer.step(loss)
```

### Parameters
*   **Patch Size (Rendered):** $32 \times 32$ pixels [S1].
*   **Patch Size (Ground Truth):** $48 \times 48$ pixels [S1].
*   **Regularization Weight ($\lambda$):** $0.01$ [S1].
*   **Convolution Kernel:** $3 \times 3$ [S1].
*   **Feature Channels ($N$):** Larger than 3; exact value not specified in sources, but implied to be sufficient for feature representation [S1].

### Edge Cases and Pitfalls
*   **Checkerboard Artifacts:** Mitigated by using "reflectance" padding and removing padding values in the CNN output [S1].
*   **Blurry Renders:** The coordinate regularization term ($\lambda \cdot D_{coord}$) prevents the model from accepting blurry renders that align with multiple ground truth subpatches equally well [S1].
*   **Multiview Inconsistency:** The CNN is shallow and performs no upsampling, which avoids introducing multiview inconsistencies [S1].

## Operating characteristics
*   **Performance:** On outdoor datasets, AligNeRF achieves a PSNR more than 3 points higher than standard NeRF and better than the best mip-NeRF results [S2].
*   **Efficiency:** The method does not significantly increase training time compared to the baseline [S2].
*   **Scalability:** The convolutional post-processing is applied after rendering, keeping the per-ray computation cost of the MLP unchanged, though the patch-based sampling and subpatch search add overhead during the fine-tuning stage [S1, S2].
*   **Strengths:** Improves high-frequency detail recovery and handles moving objects/camera misalignment effectively [S1, S2].
*   **Limitations:** Requires estimated optical flow for the alignment-aware strategy [S1].

## Background
AligNeRF was introduced by Yifan Jiang, Peter Hedman, Ben Mildenhall, Dejia Xu, Jonathan T. Barron, Zhangyang Wang, and Tianfan Xue in 2022/2023 [S1]. It addresses the limitations of standard NeRF training on high-resolution images, specifically the degradation caused by misalignment from moving objects and the inability to capture high-frequency details due to the low-frequency bias of MLPs [S1, S2]. The method is designed as a plug-in component for NeRF-like models, including point-sampling and frustum-based approaches [S1].
