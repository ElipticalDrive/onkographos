# Ref-NeRF

Also called: Structured View-Dependent Appearance for Neural Radiance Fields

## Overview
Ref-NeRF is a neural radiance field method that replaces NeRF's parameterization of view-dependent outgoing radiance with a representation of reflected radiance, structured using spatially-varying scene properties to improve specular reflection realism [S1]. It sets itself apart from standard NeRF and its sibling [Anisotropic Neural Representation Learning](9475-anisotropic-neural-representation-learning.md) by explicitly decomposing radiance into diffuse and specular components and reparameterizing the directional input using the reflection of the viewing vector about the local normal, rather than the viewing vector itself [S1].

## How it works
Ref-NeRF builds on the [Appearance and Lighting Decomposition](11061-appearance-and-lighting-decomposition.md) framework. The core mechanism remains the parametric function $F_\Theta$ mapping 3D position $\mathbf{x}$ and viewing direction $\mathbf{d}$ to density $\sigma$ and color $\mathbf{c}$, rendered via volumetric integration [Parent]. Ref-NeRF modifies the directional input and output structure of this function.

### Inputs and Outputs
*   **Inputs:** 3D position $\mathbf{x} \in \mathbb{R}^3$, viewing direction $\mathbf{d} \in \mathbb{R}^3$ (unit vector), and a latent code $\mathbf{z}$ for appearance variation if applicable.
*   **Outputs:** Volume density $\sigma \in \mathbb{R}$, diffuse color $\mathbf{c}_{diff} \in \mathbb{R}^3$, and specular color $\mathbf{c}_{spec} \in \mathbb{R}^3$.

### Data Structures
The model consists of two primary neural networks (MLPs), typically sharing a spatial encoder:
1.  **Spatial Network:** Encodes $\mathbf{x}$ (and potentially $\mathbf{z}$) to produce a feature vector $\mathbf{f}$. It also predicts the surface normal $\mathbf{n}$ at $\mathbf{x}$.
2.  **Directional Network:** Takes $\mathbf{f}$ and the reparameterized direction $\mathbf{d}'$ as input. It outputs the specular color $\mathbf{c}_{spec}$. The diffuse color $\mathbf{c}_{diff}$ is typically predicted directly from $\mathbf{f}$ or a separate branch.

### Method Steps

1.  **Normal Estimation:**
    Compute the surface normal $\mathbf{n}$ at position $\mathbf{x}$. In standard NeRF, normals are derived from the gradient of the density field $\nabla \sigma(\mathbf{x})$. Ref-NeRF applies a novel regularizer to $\sigma$ to concentrate density around surfaces, reducing "foggy" geometry and noisy normals [S1]. The normal is computed as:
    $$
    \mathbf{n} = -\frac{\nabla \sigma(\mathbf{x})}{\|\nabla \sigma(\mathbf{x})\|}
    $$
    [G] The negative sign ensures the normal points outward from the surface if $\sigma$ increases towards the interior.

2.  **Reparameterization of Direction:**
    Instead of using $\mathbf{d}$ directly, compute the reflection of the viewing vector about the local normal $\mathbf{n}$. The reflected direction $\mathbf{d}'$ is:
    $$
    \mathbf{d}' = 2(\mathbf{d} \cdot \mathbf{n})\mathbf{n} - \mathbf{d}
    $$
    This reparameterization makes the reflected radiance function smoother and more consistent across the scene, as it is invariant to surface orientation changes under distant illumination [S1].

3.  **Integrated Directional Encoding (IDE):**
    Apply Integrated Directional Encoding to $\mathbf{d}'$. This technique couples the encoding of the direction with the separation of diffuse and specular colors to enable smooth interpolation of the reflected radiance function across scenes with varying materials [S1].
    [G] Standard positional encoding $\gamma(\mathbf{d}')$ is used, but the specific formulation of IDE involves integrating the encoding over the hemisphere or using specific frequency bands tailored for directional smoothness. The exact mathematical formulation of IDE is not fully detailed in the provided notes, but it serves to make the directional MLP a better interpolation kernel [S1].

4.  **Radiance Decomposition:**
    The directional MLP outputs the specular color $\mathbf{c}_{spec}$ based on $\mathbf{f}$ and $\mathbf{d}'$. The diffuse color $\mathbf{c}_{diff}$ is predicted separately (e.g., from $\mathbf{f}$). This separation allows the reflected radiance function (driving speculars) to remain smooth despite variations in material and texture [S1].

5.  **Rendering:**
    Combine the components to form the final color $\mathbf{c}$ for volumetric rendering:
    $$
    \mathbf{c} = \mathbf{c}_{diff} + \mathbf{c}_{spec}
    $$
    The pixel color $C(\mathbf{r})$ is computed via the standard volume rendering equation:
    $$
    C(\mathbf{r}) = \sum_{i=1}^N T_i \alpha_i \mathbf{c}_i, \quad \text{where } \alpha_i = 1 - \exp(-\sigma_i \delta_i), \quad T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)
    $$

### Pseudocode

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class RefNeRF(nn.Module):
    def __init__(self, D=8, W=256, input_ch=3, input_ch_dir=3, 
                 output_ch=4, skips=[4], use_diffuse=True):
        super(RefNeRF, self).__init__()
        # Spatial MLP
        self.spatial_mlp = self._build_spatial_mlp(D, W, input_ch, skips)
        # Directional MLP
        self.dir_mlp = self._build_dir_mlp(D, W, input_ch_dir, skips)
        self.use_diffuse = use_diffuse
        if use_diffuse:
            self.diffuse_head = nn.Linear(W, 3)
        self.specular_head = nn.Linear(W, 3)

    def _build_spatial_mlp(self, D, W, input_ch, skips):
        layers = []
        in_ch = input_ch
        for i in range(D):
            layers.append(nn.Linear(in_ch, W))
            if i < D - 1:
                layers.append(nn.ReLU())
                if i in skips:
                    layers.append(nn.Linear(W + input_ch, W))
                    in_ch = W + input_ch
                else:
                    in_ch = W
        return nn.Sequential(*layers)

    def _build_dir_mlp(self, D, W, input_ch_dir, skips):
        layers = []
        in_ch = input_ch_dir
        for i in range(D):
            layers.append(nn.Linear(in_ch, W))
            if i < D - 1:
                layers.append(nn.ReLU())
                if i in skips:
                    layers.append(nn.Linear(W + input_ch_dir, W))
                    in_ch = W + input_ch_dir
                else:
                    in_ch = W
        return nn.Sequential(*layers)

    def forward(self, x, d, sigma_grad=None):
        """
        x: (N, 3) position
        d: (N, 3) viewing direction
        sigma_grad: (N, 3) pre-computed gradient of sigma for normal estimation. 
                    If None, compute from spatial_mlp output.
        """
        # 1. Spatial Encoding
        # Assume spatial_mlp outputs feature vector f and sigma
        # Note: In practice, spatial_mlp might output sigma separately or as part of f
        # For this pseudocode, we assume a standard NeRF-like spatial network structure
        # where the last layer outputs sigma, and intermediate layers output f.
        # However, Ref-NeRF often shares the spatial encoder. 
        # Let's assume spatial_mlp returns (f, sigma).
        f, sigma = self.spatial_mlp(x) # Simplified assumption
        
        # 2. Normal Estimation
        if sigma_grad is None:
            # Compute gradient of sigma w.r.t x
            sigma_grad = torch.autograd.grad(
                outputs=sigma.sum(), 
                inputs=x, 
                create_graph=True
            )[0]
        
        # Normalize to get normal
        n = -sigma_grad / (sigma_grad.norm(dim=1, keepdim=True) + 1e-8)
        
        # 3. Reparameterize Direction
        # d' = 2(d . n)n - d
        dot_product = torch.sum(d * n, dim=1, keepdim=True)
        d_reflected = 2 * dot_product * n - d
        
        # 4. Integrated Directional Encoding (IDE)
        # Apply positional encoding to reflected direction
        # d_reflected_enc = positional_encoding(d_reflected)
        # Note: IDE is a specific technique. For implementation, we use standard PE 
        # as a placeholder for the smooth interpolation kernel described in [S1].
        d_reflected_enc = positional_encoding(d_reflected)
        
        # 5. Directional Network
        dir_input = torch.cat([f, d_reflected_enc], dim=-1)
        dir_out = self.dir_mlp(dir_input)
        
        # 6. Radiance Decomposition
        c_spec = self.specular_head(dir_out)
        
        if self.use_diffuse:
            c_diff = self.diffuse_head(f)
            c = c_diff + c_spec
        else:
            c = c_spec
            
        return sigma, c, n

def positional_encoding(x, min_deg=0, max_deg=10, append_identity=True):
    """Standard positional encoding."""
    scales = torch.tensor([2**i for i in range(min_deg, max_deg)])
    scaled_x = x.unsqueeze(-1) * scales.unsqueeze(0)
    encoded = torch.sin(torch.cat([scaled_x, scaled_x + torch.pi/2], dim=-1))
    if append_identity:
        return torch.cat([x] + [encoded], dim=-1)
    return encoded
```

### Parameters and Edge Cases
*   **Regularizer:** A novel regularizer is applied to volume density $\sigma$ to concentrate it around surfaces. This is critical because NeRF's geometry is naturally "foggy," leading to noisy normals that are unsuitable for computing reflection directions [S1]. Without this, the reflection vector $\mathbf{d}'$ is inaccurate.
*   **Normal Noise:** If normals are noisy, the reflection calculation fails. The regularizer mitigates this [S1].
*   **Material Variation:** The separation of diffuse and specular colors allows the model to handle scenes with varying materials and textures while keeping the reflected radiance function smooth [S1].

## Operating characteristics
*   **Performance:** On the evaluated dataset, Ref-NeRF achieves 35.6dB PSNR and 11.5 degrees Mean Angular Error (MAE) for normals, compared to mip-NeRF's 30.3dB PSNR and 59.5 degrees MAE [S1].
*   **Strengths:** Significantly improves the realism and accuracy of specular reflections. The internal representation is interpretable and useful for scene editing [S1].
*   **Limitations:** Relies on accurate normal estimation, which requires the density regularizer. Standard NeRF geometry is insufficient for this purpose [S1].
*   **When to use:** When realistic specular reflections are required and the scene contains glossy surfaces.
*   **When not to use:** If the scene is purely diffuse or if computational resources are limited, as the additional normal estimation and directional reparameterization add complexity.

## Background
Ref-NeRF was introduced by Dor Verbin, Peter Hedman, Ben Mildenhall, Todd Zickler, Jonathan T. Barron, and Pratul P. Srinivasan from Harvard University and Google Research [S1]. It was published as arXiv:2112.03907v1 on Dec 7, 2021 [S1]. The method addresses the limitation of NeRF-based techniques in accurately capturing glossy surfaces by reparameterizing the view-dependent appearance using reflected radiance [S1].
