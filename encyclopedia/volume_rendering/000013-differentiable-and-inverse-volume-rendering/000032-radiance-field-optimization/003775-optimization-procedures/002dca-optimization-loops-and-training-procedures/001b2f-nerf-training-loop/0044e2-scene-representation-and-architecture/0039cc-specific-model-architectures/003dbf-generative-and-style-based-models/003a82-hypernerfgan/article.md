# HyperNeRFGAN

Also called: Hypernetwork NeRF GAN, HyperNeRF

## Overview
HyperNeRFGAN is a generative model that employs a hypernetwork to produce the weights of a simplified NeRF target network, trained using the StyleGAN2 objective to generate 3D-aware representations from a Gaussian noise distribution [S1, unofficial]. It solves the problem of 3D-aware image generation when camera positions are unavailable or difficult to estimate, which is common in medical imaging and datasets with limited viewpoints [S1, unofficial]. Unlike standard NeRFs that require viewing directions, HyperNeRFGAN omits direction inputs, relying on a single MLP that maps only spatial location to color and density [S1, unofficial]. It distinguishes itself from siblings like [Latent-NeRF](9110-latent-nerf.md) by using a hypernetwork to directly generate NeRF weights via Factorized Multiplicative Modulation (FMM) layers, rather than conditioning a SIREN-based network or using latent codes to modulate a fixed architecture [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A noise vector $\mathbf{z}$ sampled from a standard Gaussian distribution $\mathcal{N}(0, I)$ [S1, unofficial].
- **Output:** A rendered 2D image $C(\mathbf{r})$ from a specified camera perspective, and the discriminator's classification of the image as real or fake [S1, unofficial].

**Data Structures:**
The architecture consists of two main neural networks:
1.  **Generator ($G$):** A StyleGAN2-based hypernetwork. It takes $\mathbf{z}$ and outputs modulation matrices $\mathbf{A}$ and $\mathbf{B}$ for the target network's FMM layers.
2.  **Target Network ($F_\theta$):** A simplified NeRF MLP. It does not store weights as parameters but receives them dynamically from $G$. It takes spatial coordinates $\mathbf{x} \in \mathbb{R}^3$ and outputs density $\sigma \in \mathbb{R}$ and color $\mathbf{c} \in \mathbb{R}^3$.
3.  **Discriminator ($D$):** A standard 2D CNN discriminator that evaluates rendered images [S1, unofficial].

**Target Network Architecture ($F_\theta$):**
The target network is a single MLP that maps $\mathbf{x}$ to $(\mathbf{c}, \sigma)$. It omits viewing direction $\mathbf{d}$ [S1, unofficial].
-   **Layers:** Uses Factorized Multiplicative Modulation (FMM) layers instead of standard linear layers [S1, unofficial].
-   **FMM Layer Definition:** For an input $\mathbf{x}_{in}$ and output $\mathbf{y}$:
    $$
    \mathbf{y} = \mathbf{W} \odot (\mathbf{A} \times \mathbf{B}) \cdot \mathbf{x}_{in} + \mathbf{b} = \tilde{\mathbf{W}} \cdot \mathbf{x}_{in} + \mathbf{b}
    $$
    where:
    -   $\mathbf{W}$ and $\mathbf{b}$ are shared weight matrices and biases across all generated instances (fixed for the hypernetwork structure).
    -   $\mathbf{A}$ is a modulation matrix of size $n_{out} \times k$.
    -   $\mathbf{B}$ is a modulation matrix of size $k \times n_{in}$.
    -   $k$ is the rank parameter, controlling the expressiveness and memory usage. The source specifies $k=10$ [S1, unofficial].
    -   $\tilde{\mathbf{W}} = \mathbf{W} \odot (\mathbf{A} \times \mathbf{B})$ is the effective weight matrix computed at runtime [S1, unofficial].
-   **Dimensions:**
    -   Hidden layer channels: Reduced from standard 256 to 128 to reduce computational expense [S1, unofficial].
    -   Network depth: Standard is 8 layers, but reduced to 4 layers in some experiments to reduce cost [S1, unofficial].
    -   The network rejects the "fine" network used in standard NeRF multi-scale rendering, employing only the "coarse" network [S1, unofficial].

**Rendering Integration:**
The target network $F_\theta$ is instantiated with weights $\theta$ generated by $G$. Rays are sampled at points $\mathbf{x}_i$ along the ray. The network predicts $\sigma_i$ and $\mathbf{c}_i$. The pixel color $C(\mathbf{r})$ is computed via volumetric rendering:
$$
C(\mathbf{r}) = \sum_{i=1}^N T_i \alpha_i \mathbf{c}_i, \quad \text{where } \alpha_i = 1 - \exp(-\sigma_i \delta_i), \quad T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)
$$
and $\delta_i$ is the distance between samples [Parent].

**Training Procedure:**
The model is trained using a minimax game between the generator $G$ and discriminator $D$:
$$
\min_G \max_D V(D, G)
$$
where:
$$
V(D, G) = \mathbb{E}_{\mathbf{x} \sim P_{data}}[\log D(\mathbf{x})] + \mathbb{E}_{\mathbf{z} \sim P_{noise}}[\log(1 - D(G(\mathbf{z})))]
$$
This is the standard GAN objective adapted for the StyleGAN2 framework [S1, unofficial].

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class FMMLayer(nn.Module):
    """
    Factorized Multiplicative Modulation Layer.
    W_shared and b_shared are fixed parameters of the hypernetwork structure.
    A and B are modulation matrices generated by the hypernetwork G.
    """
    def __init__(self, n_in, n_out, k, W_shared, b_shared):
        super().__init__()
        self.n_in = n_in
        self.n_out = n_out
        self.k = k
        self.W_shared = W_shared # Shape: (n_out, n_in)
        self.b_shared = b_shared # Shape: (n_out,)
        
    def forward(self, x_in, A, B):
        # x_in: (batch, n_in)
        # A: (batch, n_out, k)
        # B: (batch, k, n_in)
        
        # Compute effective weight matrix: W_tilde = W_shared * (A @ B)
        # Element-wise multiplication (broadcasting handles dimensions)
        # A @ B results in (batch, n_out, n_in)
        W_tilde = self.W_shared * (A @ B) # Shape: (batch, n_out, n_in)
        
        # Linear transformation: y = W_tilde @ x_in + b_shared
        # x_in: (batch, n_in) -> (batch, 1, n_in) for matmul
        y = torch.bmm(W_tilde, x_in.unsqueeze(1)).squeeze(1) + self.b_shared
        return y

class HyperNeRFGAN:
    def __init__(self, generator, discriminator, fmm_configs):
        """
        generator: StyleGAN2-based hypernetwork G(z) -> [A, B] modulation matrices
        discriminator: 2D CNN D(image) -> scalar
        fmm_configs: List of dicts with keys 'n_in', 'n_out', 'k', 'W_shared', 'b_shared'
        """
        self.G = generator
        self.D = discriminator
        self.fmm_configs = fmm_configs
        self.k = 10 # Fixed rank parameter
        
    def instantiate_target_network(self, A_list, B_list):
        """
        Constructs the target NeRF MLP F_theta using modulation matrices from G.
        Returns the forward function of the target network.
        """
        layers = []
        for i, config in enumerate(self.fmm_configs):
            # Create FMM layer with shared weights
            layer = FMMLayer(
                n_in=config['n_in'],
                n_out=config['n_out'],
                k=self.k,
                W_shared=config['W_shared'],
                b_shared=config['b_shared']
            )
            layers.append((layer, i))
        
        def forward_target(x):
            # x: (batch, 3) spatial coordinates
            h = x
            for layer, idx in layers:
                # Get modulation matrices for this layer
                A = A_list[idx]
                B = B_list[idx]
                h = layer(h, A, B)
                # Apply activation (e.g., ReLU) except for the last layer
                if idx < len(self.fmm_configs) - 1:
                    h = F.relu(h)
            
            # Split output into color and density
            # Assuming last layer outputs n_out = 4 (3 for RGB, 1 for sigma)
            c = h[:, :3]
            sigma = h[:, 3:]
            return c, sigma
            
        return forward_target

    def render_ray(self, target_forward, ray_origin, ray_direction, num_samples):
        """
        Renders a single ray using the target network.
        """
        # Sample points along the ray
        t = torch.linspace(0, 1, num_samples)
        x = ray_origin + ray_direction * t.unsqueeze(1) # (num_samples, 3)
        
        # Get predictions from target network
        c, sigma = target_forward(x)
        
        # Compute alpha and transmittance
        # delta is distance between samples (assume uniform for simplicity)
        delta = 1.0 / num_samples 
        alpha = 1.0 - torch.exp(-sigma * delta)
        
        # Transmittance T_i = product(1 - alpha_j) for j < i
        T = torch.cumprod(1.0 - alpha, dim=0)
        T = torch.cat([torch.ones_like(T[:1]), T[:-1]], dim=0)
        
        # Volume rendering
        color = torch.sum(T * alpha * c, dim=0)
        return color

    def train_step(self, real_images, batch_size, num_rays, num_samples):
        """
        One training iteration.
        """
        # 1. Sample noise
        z = torch.randn(batch_size, self.G.z_dim)
        
        # 2. Generate modulation matrices
        A_list, B_list = self.G(z)
        
        # 3. Instantiate target network
        target_forward = self.instantiate_target_network(A_list, B_list)
        
        # 4. Render images from random perspectives
        # Note: In practice, this involves sampling ray origins and directions
        # and calling render_ray for each pixel or batch of rays.
        # For brevity, assume render_batch returns generated_images
        generated_images = self.render_batch(target_forward, batch_size, num_rays, num_samples)
        
        # 5. Train Discriminator
        # D(real) should be 1, D(fake) should be 0
        loss_D_real = -torch.mean(torch.log(self.D(real_images) + 1e-8))
        loss_D_fake = -torch.mean(torch.log(1.0 - self.D(generated_images.detach()) + 1e-8))
        loss_D = loss_D_real + loss_D_fake
        
        # 6. Train Generator
        # D(fake) should be 1
        loss_G = -torch.mean(torch.log(self.D(generated_images) + 1e-8))
        
        # 7. Update weights
        loss_D.backward()
        self.D.optimizer.step()
        self.D.optimizer.zero_grad()
        
        loss_G.backward()
        self.G.optimizer.step()
        self.G.optimizer.zero_grad()
        
        return loss_D.item(), loss_G.item()
```

**Parameters:**
-   **Rank $k$:** Controls the rank of the modulation matrix product $\mathbf{A} \times \mathbf{B}$. Set to 10 [S1, unofficial].
-   **Hidden Channels:** 128 (reduced from 256) [S1, unofficial].
-   **Network Depth:** 4 or 8 layers (reduced from standard 8, but often further reduced to 4 for cost) [S1, unofficial].
-   **Noise Vector:** Sampled from $\mathcal{N}(0, I)$ [S1, unofficial].

**Edge Cases and Pitfalls:**
-   **Viewing Direction:** The model does not accept viewing directions. If the dataset contains view-dependent effects (e.g., reflections), the model will fail to capture them [S1, unofficial].
-   **Fine Network:** The "fine" network from standard NeRF is omitted. This reduces training cost but may limit detail in complex scenes [S1, unofficial].
-   **Precision:** The use of FMM layers involves matrix multiplications $\mathbf{A} \times \mathbf{B}$ which can be computationally expensive if $k$ is large. However, $k=10$ is small enough to be efficient [S1, unofficial].

## Operating characteristics
-   **Time Complexity:** Training is faster than standard NeRF-based GANs (like GRAF) because it avoids the complex conditioning mechanism and uses a smaller target network (128 channels, 4-8 layers, no fine network) [S1, unofficial].
-   **Memory Complexity:** Memory usage is controlled by the rank $k$ of the FMM layers. Higher $k$ increases memory but also expressiveness. $k=10$ is used as a balance [S1, unofficial].
-   **Performance:**
    -   On ShapeNet Car: FID 29.6 (vs. Point2NeRF 82.1) [S1, unofficial].
    -   On CARLA: FID 20.5, KID 0.78, IS 4.20 (outperforming HoloGAN, GRAF, and comparable to $\pi$-GAN) [S1, unofficial].
    -   On CelebA: FID 15.04, KID 0.66, IS 2.63 (comparable to $\pi$-GAN) [S1, unofficial].
-   **Strengths:** Does not require camera poses; simple architecture; high quality on datasets with limited viewpoints; suitable for medical data [S1, unofficial].
-   **Limitations:** Cannot model view-dependent effects; relies on the quality of the hypernetwork to generate diverse NeRF weights; limited to static objects (no time dimension) [S1, unofficial].
-   **When to Use:** When camera positions are unknown or unreliable, and the scene/object lacks strong view-dependent effects. Ideal for medical imaging (DRR) and datasets with few views per object [S1, unofficial].
-   **When Not to Use:** When view-dependent effects (specular highlights, reflections) are critical, or when high-fidelity multi-scale detail is required (due to omission of the fine network) [S1, unofficial].

## Background
HyperNeRFGAN was introduced in 2023 by authors associated with the paper "HyperNeRFGAN: Hypernetwork approach to 3D NeRF GAN" [S1, unofficial]. It builds on the hypernetwork paradigm [Ha et al., 2016] and the StyleGAN2 architecture [Karras et al., 2020]. It addresses limitations of previous 3D-aware GANs like GRAF and $\pi$-GAN, which use SIREN networks with conditioning mechanisms that are complex and may not capture NeRF-level quality [S1, unofficial]. It also overcomes the need for camera poses required by standard NeRF training [S1, unofficial]. It has been applied to ShapeNet, CARLA, CelebA, and medical datasets (DRR of chests and knees) [S1, unofficial].
