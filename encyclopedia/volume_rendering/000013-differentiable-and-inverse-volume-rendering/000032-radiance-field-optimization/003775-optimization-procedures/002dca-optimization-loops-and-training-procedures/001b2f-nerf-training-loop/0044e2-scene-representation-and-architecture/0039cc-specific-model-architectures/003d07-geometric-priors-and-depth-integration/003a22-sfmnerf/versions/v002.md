# SfMNeRF

Also called: SfM-NeRF

## Overview
SfMNeRF is a method for novel view synthesis and 3D-scene geometry reconstruction that improves upon standard Neural Radiance Fields (NeRF) under sparse input conditions by integrating Structure-from-Motion (SfM) constraints into the training loop [S1]. It explicitly constrains the 3D geometry using matched feature positions, epipolar geometry, and multi-view photometric consistency, thereby reducing geometric ambiguity and preventing the model from getting stuck in local minima [S1]. Unlike standard NeRF which relies solely on implicit volume rendering, SfMNeRF adds explicit geometric priors derived from sparse feature matches and cross-view consistency [S1].

## How it works
SfMNeRF optimizes a NeRF by minimizing a composite loss function that combines standard rendering loss with explicit geometric constraints derived from SIFT features and multi-view photometric consistency. The method employs a pyramidal training strategy to handle large pixel motions and avoid local minima.

### Inputs and Outputs
**Inputs:**
*   A set of $m$ training images $\{I_i\}_{i=1}^m$ with known camera intrinsics $K$ and global poses $[\mathbf{r}_i, \mathbf{t}_i]$.
*   Matched SIFT feature correspondences between pairs of images (reference and target).
*   A pyramidal representation of the images for multi-scale optimization.

**Outputs:**
*   Optimized NeRF parameters $\Theta$ defining the radiance field $f_\Theta$.
*   Synthesized novel views and reconstructed 3D geometry (depth maps).

### Data Structures
*   **Camera Intrinsic Matrix ($K$):** $3 \times 3$ matrix mapping 3D world coordinates to 2D image coordinates.
*   **Global Pose ($[\mathbf{r}_i, \mathbf{t}_i]$):** Rotation matrix $\mathbf{r}_i \in \mathbb{R}^{3 \times 3}$ and translation vector $\mathbf{t}_i \in \mathbb{R}^3$ for image $i$.
*   **Relative Pose ($T_{r \to t}$):** $4 \times 4$ transformation matrix from reference image $r$ to target image $t$, defined as $T_{r \to t} = [\mathbf{r}, \mathbf{t}]$ where $\mathbf{r} = \mathbf{r}_t^{-1}$ and $\mathbf{t} = -\mathbf{r}_t^{-1}\mathbf{t}_t$ [S1].
*   **Mask Map ($M$):** Binary mask where $M(p(k)) = 1$ if point $p(k)$ is inside the minimum rectangle enclosing all matched SIFT features in the reference image, else $0$ [S1].
*   **Depth Map ($D$):** Estimated depth for each pixel, derived from the NeRF's volume rendering integration.
*   **SIFT Features ($\mathbf{x}_s$):** 3D coordinates of matched keypoints, computed as a weighted sum of samples along the ray [S1].

### Numbered Steps

1.  **Pyramidal Construction:** Construct an $L$-level pyramid for the reference image $I_r$ and target image $I_t$. Let $I^0_r = I_r$ and $I^0_t = I_t$. For level $n > 0$, $I^n_r$ and $I^n_t$ are downsampled versions of $I^{n-1}_r$ and $I^{n-1}_t$ with half the resolution [S1].

2.  **Sub-pixel Sampling:** For a selected patch $\Omega_p$ in the reference image at the current pyramid level, generate sub-pixel coordinates. For any integer pixel coordinate $(x, y) \in \Omega_p$, create a sub-pixel coordinate $p$:
    $$ p = (x + x_{off}, y + y_{off}) $$
    where $x_{off}, y_{off} \in (0, 1)$ are random offsets [S1].

3.  **Ground Truth Sub-pixel Color:** Compute the ground-truth color $\hat{I}(p)$ for the sub-pixel $p$ using bilinear interpolation of the four neighboring integer pixels $p^{ij}$ (top/bottom, left/right) from the reference image $I_r$:
    $$ \hat{I}(p) = \sum_{i \in \{top, bottom\}, j \in \{left, right\}} w^{ij} I_r(p^{ij}) $$
    where $w^{ij}$ is proportional to the inverse Euclidean distance between $p$ and $p^{ij}$ [S1].

4.  **NeRF Forward Pass (Volume Rendering):** For each sub-pixel $p$ and its corresponding viewing direction $\mathbf{d}$, sample $N_c$ points along the ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$. Query the NeRF for volume density $\sigma_j$ and color $\mathbf{c}_j$ at each sample $j$. Compute the rendered color $\tilde{I}(p)$ and depth $D(p)$ using standard volume rendering integration [S1, S4]:
    $$ \tilde{I}(p) = \sum_{j=1}^{N_c} T_j \alpha_j \mathbf{c}_j, \quad T_j = \exp\left(-\sum_{k=1}^{j-1} \sigma_k \delta_k\right), \quad \alpha_j = 1 - \exp(-\sigma_j \delta_j) $$
    where $\delta_j = t_{j-1} - t_j$ [S1].

5.  **3D Coordinate Estimation for Features:** For matched SIFT features, estimate their 3D coordinates $\mathbf{x}_s$ by treating the NeRF's density as a probability distribution along the ray:
    $$ \mathbf{x}_s = \sum_{j=1}^{N_c} w_j (\mathbf{o} + t_j \mathbf{d}) $$
    where $w_j = T_j (1 - \exp(-\sigma_j \delta_j))$ [S1].

6.  **Loss Computation:** Calculate the following loss components:

    *   **Rendering Loss ($L_{ren}$):** Mean squared error between the ground-truth sub-pixel color $\hat{I}(p)$ and the rendered color $\tilde{I}(p)$ over the patch $\Omega_p$:
        $$ L_{ren} = \frac{1}{|\Omega_p|} \sum_{p \in \Omega_p} \left\| \hat{I}(p) - \tilde{I}(p) \right\|_2^2 $$
        [S1]

    *   **Positions-of-Matched Features Loss ($L_{3D}$):** Enforce that matched SIFT features have consistent 3D coordinates in both reference and target views. Let $\mathbf{x}_s^k$ and $\mathbf{x}_{s'}^k$ be the estimated 3D coordinates of matched feature $k$ in the reference and target images, respectively:
        $$ L_{3D} = \frac{1}{n} \sum_{k=1}^n \left\| \mathbf{x}_s^k - \mathbf{x}_{s'}^k \right\|_2^2 $$
        [S1]

    *   **Epipolar Constraint Loss ($L_{epi}$):** For a point $p_r$ in the reference image with estimated 3D coordinate $d_{p_r}$, find the point $p_t$ on the epipolar line in the target image that minimizes the distance to the back-projected ray. Let $\{p_t\}$ be points on the epipolar line with estimated 3D coordinates $d_{p_t}$:
        $$ L_{epi} = \min_{t} \left\{ \left\| d_{p_r} - d_{p_t} \right\|_2^2 \right\} $$
        To improve efficiency and handle occlusions, filter implausible epipolar points by color similarity: only keep points on the epipolar line where the color difference between the reference point and the epipolar point is below a threshold [S1].

    *   **Photometric Reconstruction Loss ($L_{pr}$):** Warp pixels from the reference patch to the target view. For each pixel $p(k)$ in the patch, compute its 3D coordinate $\mathbf{x}_p$ via Eq. (7), project it to the target image $\hat{p}_t = K T_{r \to t} \mathbf{x}_p$, and interpolate the color $\hat{I}_t(\hat{p}_t)$ from the target image. Compare with the reference color $\hat{I}_r(p(k))$:
        $$ L_{pr} = \sum_{p(k) \in \Omega_p} M(p(k)) \left| \hat{I}_r(p(k)) - \hat{I}_t(\hat{p}_t(k)) \right| $$
        [S1]

    *   **SSIM Loss ($L_{SSIM}$):** Compute the Structural Similarity index between the reference patch and the warped target patch:
        $$ L_{SSIM} = M \left( \frac{1 - SSIM_{r \to t}}{2} \right) $$
        [S1]

    *   **Depth Smooth Loss ($L_{ds}$):** Enforce smoothness in the estimated depth map $D$, weighted by image gradients to preserve edges:
        $$ L_{ds} = \sum_{p(k) \in \Omega_p} \left| \nabla D(p(k)) \cdot e^{-|\hat{I}(p(k))|} \right| $$
        where $\nabla$ is the 2D differential operator [S1].

    *   **Depth Prior Loss ($L_{depth}$):** (Used in pyramidal strategy) Compare the current depth estimate $D(p(k))$ with the depth map from the previous, lower-resolution level $D_r^{L-1}$, sampled via bilinear interpolation at coordinate $p(k)/2$:
        $$ L_{depth} = \sum_{p(k) \in \Omega_p} \left| D(p(k)) - D_r^{L-1}(p(k)/2) \right| $$
        [S1]

7.  **Total Loss:** Combine all losses with weights $\lambda$:
    $$ L_{total} = \lambda_{ren} L_{ren} + \lambda_{3D} L_{3D} + \lambda_{pr} L_{pr} + \lambda_{epi} L_{epi} + \lambda_{SSIM} L_{SSIM} + \lambda_{ds} L_{ds} + \lambda_{depth} L_{depth} $$
    [S1]

8.  **Optimization:** Update NeRF parameters $\Theta$ using the Adam optimizer to minimize $L_{total}$ [S1].

9.  **Pyramidal Progression:** After optimizing at the lowest pyramid level $L-1$, obtain the depth map $D^{L-1}_r$. Move to level $n-2$, re-initialize or continue training, and add $L_{depth}$ to the loss to use the lower-resolution depth as a prior. Repeat recursively until the "zeroth" level (original resolution) is reached [S1].

### Parameters
*   **Loss Weights:** $\lambda_{ren} = 1.0$, $\lambda_{3D} = 1.0$, $\lambda_{pr} = 0.001$, $\lambda_{epi} = 0.0001$, $\lambda_{SSIM} = 0.008$, $\lambda_{ds} = 0.01$ [S1].
*   **Patch Size:** $32 \times 32$ pixels [S1].
*   **Sampling:** Hierarchical sampling with 64 samples for coarse and 64 for fine stages (as per NeRF [1]) [S1].
*   **Optimizer:** Adam with $\beta_1 = 0.9$, $\beta_2 = 0.999$, learning rate $1e-3$ [S1].

### Edge Cases and Pitfalls
*   **Epipolar Point Filtering:** A large number of epipolar points causes computational inefficiency. Occluded points may not have corresponding points on the epipolar line. The method filters implausible points using color similarity thresholds to mitigate this [S1].
*   **Local Minima:** Without the pyramidal strategy, the photometric consistency loss may get stuck in local minima due to large pixel motions between views [S1].
*   **Masking:** The mask $M$ ensures that only pixels within the region of interest (defined by the minimum rectangle of SIFT matches) contribute to the photometric and SSIM losses, preventing noise from unobserved regions [S1].

## Operating characteristics
*   **Time Complexity:** The method is computationally more expensive than standard NeRF due to the additional loss computations (epipolar constraints, photometric warping, SIFT feature processing) and the pyramidal training strategy which requires multiple passes over the data at different resolutions [S1].
*   **Memory Complexity:** Requires storing pyramid representations of images and depth maps, as well as intermediate 3D coordinates for SIFT features and epipolar points [S1].
*   **Performance:** Evaluated on LLFF-NeRF, ScanNet, and DTU MVS datasets. It outperforms state-of-the-art approaches under sparse input conditions (2, 5, and 8 input views) [S1].
*   **Strengths:** Improves geometric accuracy and novel view synthesis quality in sparse settings by explicitly constraining 3D structure. The sub-pixel rendering strategy improves generalization by increasing the number of training samples [S1].
*   **Limitations:** Computational inefficiency due to the large number of epipolar points and the need for SIFT feature extraction and matching. Requires known camera poses and intrinsics [S1].

## Background
SfMNeRF was proposed to address the limitations of NeRF in reconstructing accurate 3D structures under sparse input conditions. It builds on the implicit representation of NeRF and integrates concepts from self-supervised depth estimation and Structure-from-Motion (SfM) [S1]. The method was evaluated on public datasets including LLFF-NeRF, ScanNet, and DTU MVS [S1]. The code is available at https://github.com/XTU-PR-LAB/SfMNeRF [S1].
