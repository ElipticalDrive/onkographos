# ProNeRF

Also called: ProNeRF-12, ProNeRF-32, ProNeRF-8, Projection-Aware Ray Sampling for Fine-Grained Implicit Neural Radiance Fields

## Overview
ProNeRF is a sparse sampling neural rendering method that achieves high-quality volumetric rendering with significantly fewer samples than vanilla NeRF by using a Projection-Aware Sampling (PAS) network to predict optimal 3D sampling points and opacity adjustments [S1]. It distinguishes itself from generalizable radiance fields (e.g., IBRNet, NeuRay) by using a fixed, small subset of reference views for color-to-ray projection, ensuring a consistent memory footprint regardless of the total number of training views, and from other sparse methods (e.g., HyperReel) by achieving higher PSNR through an alternating exploration-exploitation training strategy [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A target ray $\mathbf{r}$ defined by origin $\mathbf{r}_o$ and direction $\mathbf{r}_d$, and a set of $N_n$ neighboring reference views from a fixed pool of $N_t$ training views.
*   **Output:** A rendered pixel color $\hat{\mathbf{c}}(\mathbf{r})$.

**Data Structures and Network Layout:**
ProNeRF consists of three main MLP components:
1.  **Coarse Sampler ($F_{\theta_c}$):** 6 fully connected layers, 256 neurons, ELU activations.
2.  **Fine Sampler ($F_{\theta_f}$):** 6 fully connected layers, 256 neurons, ELU activations.
3.  **Shading Network ($F_{\theta_s}$):** 8 fully connected layers, 256 neurons (based on DoNeRF).
4.  **Pruning Head ($F_{\theta_m}$):** (Optional, for ProNeRF-8 prune) Same complexity as $F_{\theta_c}$.

**Plücker Ray-Point Encoding:**
The ray is encoded using $N_{pr}$ points evenly spaced between near ($t_n$) and far ($t_f$) bounds. For each point $t_{nf}$ in the vector $\mathbf{t}_{nf}$, the Plücker representation $\mathbf{r}_{pr}$ is calculated as [S1]:
$$
\mathbf{r}_{pr} = [\mathbf{r}_d, \mathbf{r}_o + \mathbf{r}_d \odot \mathbf{t}_{nf}, (\mathbf{r}_o + \mathbf{r}_d \odot \mathbf{t}_{nf}) \odot \mathbf{r}_d]
$$
where $\odot$ is the Hadamard product. The default $N_{pr}$ is 48 [S1].

**Algorithm Steps:**

1.  **Coarse Sampling:**
    Compute the encoded ray $\mathbf{r}_{pr}$. Pass it through $F_{\theta_c}$ to obtain coarse sampling distances $\mathbf{T}' = \{t'_1, \dots, t'_{N_s}\}$, opacity shifts $\Delta_t$, opacity scales $B_t$, a coarse light-field color $\hat{\mathbf{c}}_c$, and auxiliary weights [S1]:
    $$
    [\mathbf{T}', \Delta_t, B_t, \hat{\mathbf{c}}_c, \dots] = F_{\theta_c}(\mathbf{r}_{pr})
    $$
    $N_s$ is the number of fine samples (e.g., 8, 12, or 32) [S1].

2.  **Color-to-Ray Projection:**
    For each coarse point $p_i = \mathbf{r}(t'_i)$, trace lines from $p_i$ to the camera centers of $N_n$ neighboring reference views. Collect the colors at these intersection points to form projection vectors $\mathbf{f}_{p_i} = [c^1_{p_i}, \dots, c^{N_n}_{p_i}]$ [S1].

3.  **Refined Sampling and AVR:**
    Pass the encoded ray $\mathbf{r}'_{pr}$ and the aggregated projections $[\mathbf{f}_{p_1}, \dots, \mathbf{f}_{p_{N_s}}]$ through $F_{\theta_f}$ to obtain refinement weights $\Delta_T$, weights $W$, and mixing coefficients $M$ [S1]:
    $$
    [\Delta_T, W, M] = F_{\theta_f}([\mathbf{r}'_{pr}, \mathbf{f}_{p_1}, \dots, \mathbf{f}_{p_{N_s}}])
    $$
    Compute refined distances $\mathbf{T}$ by linear interpolation between consecutive elements of the expanded set $\dot{\mathbf{T}} = \{t_n, t'_1, \dots, t'_{N_s}, t_f\}$ using $\Delta_T$ [S1]:
    $$
    T_i = \frac{1}{2} \left( (\dot{T}_i + \dot{T}_{i+1}) + \Delta_{T_i}(\dot{T}_{i+2} - \dot{T}_i) \right), \quad i=1 \dots N_s
    $$
    Compute the Approximated Volumetric Rendering (AVR) color $\hat{\mathbf{c}}_f$ using the projected colors and weights $W, M$ [S1]:
    $$
    \hat{\mathbf{c}}_f = \sum_{k=1}^{N_n} M_k \left( \sum_{i=1}^{N_s} W_i c^k_{p_i} \right)
    $$

4.  **Volumetric Rendering:**
    Query the shading network $F_{\theta_s}$ at the refined points $\mathbf{T}$ to get densities $\sigma_i$ and colors $\mathbf{c}_i$:
    $$
    \{\sigma_i, \mathbf{c}_i\}_{i=1}^{N_s} = F_{\theta_s}(\mathbf{r}_o + \mathbf{r}_d \odot \mathbf{T})
    $$
    Compute adjusted opacities $\hat{\alpha}_i$ using the shifts $\Delta_t$ and scales $B_t$ from the coarse network [S1]:
    $$
    \hat{\alpha}_i = 1 - \exp(-(\sigma_i + \Delta_{t_i}) B_{t_i} \delta_i)
    $$
    Render the final color $\hat{\mathbf{c}}(\mathbf{r})$ using alpha compositing [S1]:
    $$
    \hat{\mathbf{c}}(\mathbf{r}) = \sum_{i=1}^{N_s} \left( \prod_{j=1}^{i-1} (1 - \hat{\alpha}_j) \right) \hat{\alpha}_i \mathbf{c}_i
    $$

5.  **Pruning (Optional, ProNeRF-8 prune):**
    If $F_{\theta_m}$ predicts a low error between $\hat{\mathbf{c}}_f$ and the full render $\hat{\mathbf{c}}$, output $\hat{\mathbf{c}}_f$ (AVR). Otherwise, output $\hat{\mathbf{c}}$ [S1].

**Training Strategy (Exploration-Exploitation):**
Training alternates between two passes over $7 \times 10^5$ iterations [S1].

*   **Exploration Pass (Every 2nd iteration, first $4 \times 10^5$ iters):**
    1.  Sample a random number of samples $N^+_s \in [N_s, N]$ where $N=64$ [S1].
    2.  Sample distances $\mathbf{T}^+$ randomly around $\mathbf{T}$ and add Gaussian noise [S1].
    3.  Query $F_{\theta_s}$ at $\mathbf{T}^+$ to get $\{\sigma_i, \mathbf{c}_i\}$.
    4.  Render $\hat{\mathbf{c}}(\mathbf{r})$ using standard VRE (Eq. 1 in [S1]).
    5.  Compute loss $l = \|\hat{\mathbf{c}}(\mathbf{r}) - \mathbf{c}(\mathbf{r})\|_2$.
    6.  Back-propagate to update only $F_{\theta_s}$ [S1].

*   **Exploitation Pass (Every 2nd iteration):**
    1.  Query $F_{\theta_s}$ at the PAS-predicted $\mathbf{T}$ to get $\{\sigma_i, \mathbf{c}_i\}$.
    2.  Render $\hat{\mathbf{c}}(\mathbf{r})$ using PAS-guided VRE (Eq. 5 in [S1]).
    3.  Compute primary loss $l = \|\hat{\mathbf{c}}(\mathbf{r}) - \mathbf{c}(\mathbf{r})\|_2$.
    4.  If iteration $< 4 \times 10^5$, add auxiliary loss $l_a = \|\hat{\mathbf{c}}_c - \mathbf{c}(\mathbf{r})\|_2 + \|\hat{\mathbf{c}}_f - \mathbf{c}(\mathbf{r})\|_2$ [S1].
    5.  Total loss $l_T = l + \lambda l_a$, where $\lambda=1$ for first 60% of training, then 0 [S1].
    6.  Back-propagate to update all networks ($F_{\theta_c}, F_{\theta_f}, F_{\theta_s}$) [S1].

**Parameters:**
*   Batch size $N_r = 4,096$ rays [S1].
*   Learning rate: $5 \times 10^{-4}$, exponentially decayed [S1].
*   Reference views: Fixed subset $N_n \ll N_t$ [S1].
*   Pruning memory overhead: 3.3 MB [S1].

**Edge Cases and Pitfalls:**
*   Removing the auxiliary loss $l_a$ causes an almost 1 dB drop in PSNR [S1].
*   Removing Plücker ray-point encoding causes an almost 0.5 dB PSNR drop [S1].
*   The number of neighboring views $N_n$ for inference must be significantly smaller than total training views $N_t$ to maintain efficiency [S1].

## Operating characteristics
*   **Speed:** ProNeRF is 15-23× faster than vanilla NeRF [S1]. ProNeRF-8 is >20× faster; ProNeRF-8 prune is 23% faster than standard ProNeRF-8 [S1].
*   **Quality:** ProNeRF-12 achieves 27.15 dB PSNR on LLFF, 0.65 dB higher than vanilla NeRF (26.50 dB) [S1]. ProNeRF-8 achieves 26.78 dB PSNR, 0.28 dB higher than NeRF [S1]. ProNeRF-32 achieves 31.92 dB PSNR on Blender [S1].
*   **Memory:** Similar to NeRF (3.8 MB base) [S1]. Pruning adds 3.3 MB [S1].
*   **Strengths:** High quality with very few samples; consistent memory footprint independent of training view count; faster than HyperReel and K-Planes [S1].
*   **Limitations:** Requires alternating training strategy; pruning adds slight complexity [S1].
*   **When to use:** When inference speed is critical but quality must exceed sparse baselines like HyperReel, and memory cannot scale with training data size.
*   **When not to use:** When ground truth depth is available (other methods may be simpler) or when extremely high sample counts are acceptable for maximum quality (vanilla NeRF may be simpler to implement).

## Background
ProNeRF was proposed in 2024 by authors publishing in IEEE Access [S1]. It addresses the quality degradation in sampler-based methods compared to vanilla NeRF and the high memory requirements of generalizable radiance fields that store all training images [S1]. It builds on the implicit neural radiance field representation [S1].
