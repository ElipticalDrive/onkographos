# GIRAFFE

Also called: Compositional Generative Neural Feature Fields, GIRAFFE Scene Composition

## Overview
GIRAFFE represents scenes as a composition of $N$ distinct entities (objects and a background), where each entity possesses its own separate neural feature field and learnable affine transformation. This architecture enables explicit control over the pose, shape, and appearance of individual entities within a generated scene [S1]. It differs from standard NeRF by decoupling scene composition into discrete, transformable latent components rather than a single monolithic field, allowing for generative manipulation of scene elements [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Camera pose $\xi$, number of entities $N$, latent shape codes $\mathbf{z}_s^i$, latent appearance codes $\mathbf{z}_a^i$, and per-entity transformations $\mathbf{T}_i = \{\mathbf{s}_i, \mathbf{t}_i, \mathbf{R}_i\}$ for $i=1 \dots N$.
*   **Outputs:** A synthesized RGB image $\hat{\mathbf{I}} \in \mathbb{R}^{H \times W \times 3}$.

**Data Structures:**
1.  **Feature Field ($h_\theta$):** A Multi-Layer Perceptron (MLP) shared by all object entities ($i=1 \dots N-1$).
    *   **Architecture:** 8 hidden layers, hidden dimension 128, ReLU activations.
    *   **Heads:** Density head (dim 1), Feature head (dim $M_f$).
    *   **Background Field ($h_\theta^N$):** Uses half the layers and hidden dimension of the object field.
2.  **Neural Renderer ($\pi_\theta^{\text{neural}}$):** A 2D CNN mapping low-resolution feature maps to high-resolution RGB.
    *   **Architecture:** 2D CNN with Leaky ReLU. Combines nearest-neighbor upsampling with $3 \times 3$ convolutions.
    *   **Skip Connections:** Maps feature image to RGB at every spatial resolution via $3 \times 3$ conv, adds to previous output via bilinear upsampling.
    *   **Output Activation:** Sigmoid.
3.  **Discriminator ($D_\phi$):** A CNN with Leaky ReLU activation [S1].

**Parameters:**
*   $N$: Number of entities. Fixed or varied per dataset. Index $N$ is the background.
*   $M_f$: Feature vector dimension. 128 for $64 \times 64$ output; 256 for $256 \times 256$ output [S1].
*   $N_s$: Number of sample points per ray. Value: 64 [S1].
*   $L_x$: Positional encoding bands for position. Value: $2 \cdot 3 \cdot 10 = 60$ dimensions [S1].
*   $L_d$: Positional encoding bands for direction. Value: $2 \cdot 3 \cdot 4 = 24$ dimensions [S1].
*   Feature Image Resolution ($H_V \times W_V$): $16 \times 16$ pixels [S1].
*   Optimizer: RMSprop.
*   Learning Rates: Generator $1 \times 10^{-4}$ (or $2.5 \times 10^{-4}$ for $256 \times 256$); Discriminator $5 \times 10^{-4}$ [S1].
*   Batch Size: 32 [S1].
*   EMA Decay: 0.999 for generator weights [S1].
*   GAN Penalty $\lambda$: 10 [S1].

**Steps:**

1.  **Sampling:** During training, sample $N \sim p_N$, latent codes $\mathbf{z}_s^i, \mathbf{z}_a^i \sim \mathcal{N}(0, I)$, camera pose $\xi \sim p_\xi$, and transformations $\mathbf{T}_i \sim p_T$. $p_\xi$ is uniform over dataset-dependent camera elevation angles; $p_T$ is uniform over valid object transformations [S1].

2.  **Transformation to Scene Space:** For each entity $i$, define the transformation from object space to scene space $k_i(\mathbf{x})$:
    $$
    k_i(\mathbf{x}) = \mathbf{R}_i \begin{bmatrix} s_{i,1} & 0 & 0 & 0 \\ 0 & s_{i,2} & 0 & 0 \\ 0 & 0 & s_{i,3} & 0 \\ 0 & 0 & 0 & s_{i,3} \end{bmatrix} \mathbf{x} + \mathbf{t}_i
    $$
    For the background entity ($i=N$), fix $\mathbf{s}_N$ and $\mathbf{t}_N$ to span the entire scene and center it at the origin. Other objects have learnable $\mathbf{s}_i, \mathbf{t}_i, \mathbf{R}_i$ [S1].

3.  **Feature Field Evaluation:** For a ray $\mathbf{d}$ and sample point $\mathbf{x}_j$ along it, evaluate the feature field in canonical object space by applying the inverse transformation $k_i^{-1}$:
    $$
    (\sigma_{i,j}, \mathbf{f}_{i,j}) = h_\theta(\gamma(k_i^{-1}(\mathbf{x}_j)), \gamma(k_i^{-1}(\mathbf{d})), \mathbf{z}_s^i, \mathbf{z}_a^i)
    $$
    where $\gamma(\cdot)$ is the positional encoding [S1].

4.  **Composition:** Combine the outputs of all $N$ entities using the composition operator $C$. The total density is the sum of individual densities, and the combined feature is the density-weighted mean:
    $$
    C(\mathbf{x}_j, \mathbf{d}) = \left( \sigma_j, \frac{1}{\sigma_j} \sum_{i=1}^N \sigma_{i,j} \mathbf{f}_{i,j} \right), \quad \text{where } \sigma_j = \sum_{i=1}^N \sigma_{i,j}
    $$
    This ensures gradient flow to all entities with $\sigma_{i,j} > 0$ [S1].

5.  **Volume Rendering (Feature Image):** Render the $M_f$-dimensional feature vector $\mathbf{f}$ for each pixel by integrating along the ray with $N_s$ samples:
    $$
    \mathbf{f} = \sum_{j=1}^{N_s} \tau_j \alpha_j \mathbf{f}_j, \quad \tau_j = \prod_{k=1}^{j-1} (1 - \alpha_k), \quad \alpha_j = 1 - e^{-\sigma_j \delta_j}
    $$
    where $\delta_j = \|\mathbf{x}_{j+1} - \mathbf{x}_j\|_2$ is the distance between samples. This produces a low-resolution feature image $\mathbf{I}_V \in \mathbb{R}^{16 \times 16 \times M_f}$ [S1].

6.  **2D Neural Rendering:** Upsample $\mathbf{I}_V$ to the final output resolution ($64 \times 64$ or $256 \times 256$) using the neural renderer $\pi_\theta^{\text{neural}}$:
    $$
    \hat{\mathbf{I}} = \pi_\theta^{\text{neural}}(\mathbf{I}_V)
    $$
    The renderer uses nearest-neighbor upsampling combined with $3 \times 3$ convolutions and skip connections with bilinear upsampling to refine spatial details [S1].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class PositionalEncoding(nn.Module):
    def __init__(self, L_x, L_d):
        super().__init__()
        self.L_x = L_x
        self.L_d = L_d

    def forward(self, x, d):
        # x: (..., 3), d: (..., 3)
        # Standard NeRF positional encoding
        def pe(coord, L):
            scales = torch.tensor([2**i for i in range(L)], dtype=coord.dtype, device=coord.device)
            scaled_coord = coord.unsqueeze(-1) * scales * torch.pi
            h = torch.cat([torch.sin(scaled_coord), torch.cos(scaled_coord)], dim=-1)
            return h
        
        return pe(x, self.L_x), pe(d, self.L_d)

class FeatureFieldMLP(nn.Module):
    def __init__(self, hidden_dim, M_f, num_layers=8, is_background=False):
        super().__init__()
        layers = []
        input_dim = 128 # Output of PE
        if is_background:
            num_layers = num_layers // 2
            hidden_dim = hidden_dim // 2
        
        for i in range(num_layers):
            layers.append(nn.Linear(input_dim, hidden_dim))
            layers.append(nn.ReLU())
            input_dim = hidden_dim
            
        self.net = nn.Sequential(*layers)
        self.sigma_head = nn.Linear(hidden_dim, 1)
        self.f_head = nn.Linear(hidden_dim, M_f)

    def forward(self, x_pe, d_pe, z_s, z_a):
        # Concatenate latent codes if needed by specific implementation details not fully explicit in formula 7
        # Assuming z_s, z_a are concatenated or added to the MLP input or intermediate features.
        # Based on formula 7, they are inputs to h_theta. 
        # Standard GIRAFFE implementation often concatenates latents to the input or intermediate layers.
        # Here we assume they are concatenated to the positional encoding input for simplicity in this generic structure,
        # or passed as additional inputs to the MLP. 
        # Note: The source formula 7 shows z_s, z_a as inputs. 
        # A common implementation concatenates them to the input vector.
        input_vec = torch.cat([x_pe, d_pe, z_s, z_a], dim=-1)
        
        h = self.net(input_vec)
        sigma = self.sigma_head(h)
        f = self.f_head(h)
        return sigma, f

class NeuralRenderer(nn.Module):
    def __init__(self, H_V, W_V, M_f, H, W):
        super().__init__()
        self.H_V = H_V
        self.W_V = W_V
        self.H = H
        self.W = W
        
        # 2D CNN with Leaky ReLU
        # Combines nearest neighbor upsampling with 3x3 convs
        # Skip connections via bilinear upsampling
        self.conv1 = nn.Conv2d(M_f, 64, 3, padding=1)
        self.conv2 = nn.Conv2d(64, 128, 3, padding=1)
        self.conv3 = nn.Conv2d(128, 3, 3, padding=1) # Final RGB
        
        # Leaky ReLU
        self.leaky_relu = nn.LeakyReLU(0.2)

    def forward(self, I_V):
        # I_V: (B, M_f, 16, 16)
        x = self.leaky_relu(self.conv1(I_V))
        
        # Upsample to next resolution
        x_up = F.interpolate(x, scale_factor=2, mode='nearest')
        x_up_conv = self.leaky_relu(self.conv2(x_up))
        
        # Skip connection from original x via bilinear
        x_skip = F.interpolate(x, scale_factor=4, mode='bilinear', align_corners=False)
        x_combined = x_up_conv + x_skip
        
        # Final RGB
        out = self.conv3(x_combined)
        out = torch.sigmoid(out)
        return out

def compose_entities(sigma_list, f_list):
    # sigma_list: list of tensors (..., 1)
    # f_list: list of tensors (..., M_f)
    sigma_total = sum(sigma_list)
    # Avoid division by zero
    sigma_total = torch.clamp(sigma_total, min=1e-6)
    
    weighted_f_sum = sum(s * f for s, f in zip(sigma_list, f_list))
    f_combined = weighted_f_sum / sigma_total
    
    return sigma_total, f_combined

def volume_render_feature(sigma_samples, f_samples, delta):
    # sigma_samples: (N_s, 1)
    # f_samples: (N_s, M_f)
    # delta: (N_s,) distance between samples
    
    alpha = 1 - torch.exp(-sigma_samples.squeeze(-1) * delta)
    # Transmittance
    T = torch.cumprod(1 - alpha, dim=0)
    T = torch.cat([torch.ones_like(T[:1]), T[:-1]], dim=0)
    
    f_rendered = torch.sum(T.unsqueeze(-1) * alpha.unsqueeze(-1) * f_samples, dim=0)
    return f_rendered

def transform_point(x, T):
    # x: (..., 3)
    # T: dict with 's', 't', 'R'
    s = T['s']
    t = T['t']
    R = T['R']
    
    # Scale matrix
    S = torch.diag(torch.cat([s, torch.tensor([s[2]])])) # s3 used for w component in homogeneous? 
    # Formula 6: diag(s1, s2, s3, s3). x is 3D. 
    # Implementation: x is 3D. We treat it as homogeneous (x, 1) or just apply affine.
    # The formula shows a 4x4 matrix acting on x. Assuming x is treated as (x,y,z,1) implicitly or the matrix is applied to (x,y,z) with translation added.
    # Let's follow the matrix multiplication strictly.
    # x_hom = torch.cat([x, torch.ones_like(x[..., :1])], dim=-1) # (..., 4)
    # x_scene_hom = R @ S @ x_hom.T ... 
    # Simpler: x_scene = R @ (S @ x) + t
    
    # S @ x
    x_scaled = x * s.unsqueeze(0) # Broadcasting
    x_rotated = torch.matmul(R, x_scaled.T).T # (..., 3)
    x_scene = x_rotated + t.unsqueeze(0)
    return x_scene

def inverse_transform_point(x_scene, T):
    # x_scene = R @ S @ x_obj + t
    # x_obj = S^-1 @ R^-1 @ (x_scene - t)
    s = T['s']
    t = T['t']
    R = T['R']
    
    x_centered = x_scene - t.unsqueeze(0)
    x_rotated = torch.matmul(R.T, x_centered.T).T # R is orthogonal, R^-1 = R.T
    s_inv = 1.0 / s.unsqueeze(0)
    x_obj = x_rotated * s_inv
    return x_obj

def render_image(camera_poses, entities, feature_field, neural_renderer, pe, N_s=64):
    # camera_poses: list of (R_cam, t_cam) or similar
    # entities: list of dicts with 'z_s', 'z_a', 'T', 'is_background'
    
    H, W = neural_renderer.H, neural_renderer.W
    H_V, W_V = 16, 16
    M_f = feature_field.M_f
    
    # Initialize feature image buffer
    I_V = torch.zeros((H_V, W_V, M_f), device=feature_field.device)
    
    for y in range(H_V):
        for x in range(W_V):
            # Get ray direction and origin for pixel (x,y)
            # This depends on camera intrinsics/extrinsics not detailed in source
            # Assuming ray_d and ray_o are computed
            ray_d, ray_o = get_ray(camera_poses, x, y, H, W)
            
            # Sample points along ray
            t_vals = torch.linspace(0, 1, N_s) # Placeholder for actual sampling strategy
            x_samples = ray_o.unsqueeze(0) + ray_d.unsqueeze(0) * t_vals.unsqueeze(-1)
            delta = torch.diff(t_vals, dim=0) # Placeholder for actual delta calculation
            
            sigma_list = []
            f_list = []
            
            for entity in entities:
                T = entity['T']
                z_s = entity['z_s']
                z_a = entity['z_a']
                
                # Inverse transform to object space
                x_obj = inverse_transform_point(x_samples, T)
                d_obj = inverse_transform_point(ray_d, T) # Direction transformation is more complex, usually just R^T d
                
                # PE
                x_pe, d_pe = pe(x_obj, d_obj)
                
                # Feature Field
                sigma, f = feature_field(x_pe, d_pe, z_s, z_a)
                
                sigma_list.append(sigma)
                f_list.append(f)
                
            # Composition
            sigma_total, f_combined = compose_entities(sigma_list, f_list)
            
            # Volume Render
            f_pixel = volume_render_feature(sigma_total, f_combined, delta)
            
            I_V[y, x] = f_pixel
            
    # Neural Rendering
    I_V_tensor = I_V.permute(2, 0, 1).unsqueeze(0) # (1, M_f, 16, 16)
    I_RGB = neural_renderer(I_V_tensor)
    return I_RGB
```

## Operating characteristics
*   **Complexity:** Rendering speed is improved by rendering low-resolution ($16 \times 16$) feature maps and upscaling via 2D CNN, rather than high-resolution volumetric rendering [S1].
*   **Memory:** Requires storing separate latent codes and transformations for each entity. The shared MLP weights reduce parameter count compared to independent fields for each object [S1].
*   **Strengths:** Enables explicit control over individual object pose, shape, and appearance. Allows for scene composition with varying numbers of objects [S1].
*   **Limitations:** Assumes objects are non-solid and can be combined via density summation. Performance depends on the quality of the 2D neural renderer for high-resolution output [S1].
*   **When to use:** When generative control over individual scene elements is required, or when scenes consist of distinct, separable objects [S1].

## Background
GIRAFFE was introduced by Kong et al. in the paper "GIRAFFE: Representing Scenes as Compositional Generative Neural Feature Fields" [S1]. It extends the NeRF framework to generative modeling by decomposing the scene into compositional parts, allowing for the synthesis of novel scenes with controlled object attributes [S1].
