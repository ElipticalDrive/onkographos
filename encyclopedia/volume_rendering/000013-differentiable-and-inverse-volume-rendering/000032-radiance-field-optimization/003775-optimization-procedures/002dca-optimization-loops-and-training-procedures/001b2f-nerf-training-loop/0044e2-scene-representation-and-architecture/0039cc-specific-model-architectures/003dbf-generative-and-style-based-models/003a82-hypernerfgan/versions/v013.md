# HyperNeRFGAN

Also called: HyperNeRFGAN: Hypernetwork approach to 3D NeRF GAN

## Overview
HyperNeRFGAN is a generative adversarial network (GAN) that synthesizes 3D-aware image representations by using a hypernetwork to generate the weights of a simplified NeRF target network from a Gaussian noise vector [S1, unofficial]. It solves the problem of 3D-aware image generation in scenarios where camera positions are unavailable or difficult to estimate, such as medical imaging or datasets with limited viewpoints, by removing viewing directions from the NeRF input and replacing the standard deterministic optimization with a generative adversarial objective [S1, unofficial]. Unlike sibling methods like Latent-NeRF which optimize a latent code for a fixed network, HyperNeRFGAN generates the network weights themselves, allowing for diverse 3D structures from noise without requiring explicit conditioning mechanisms [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A noise vector $\mathbf{z}$ sampled from a standard Gaussian distribution $P_{noise}$ [S1, unofficial].
- **Output:** A rendered 2D image $C(\mathbf{r})$ generated by the instantiated NeRF, and the discriminator's classification of real vs. fake images [S1, unofficial].

**Data Structures:**
1.  **Generator ($G$):** A StyleGAN2-based architecture that maps $\mathbf{z}$ to modulation parameters [S1, unofficial].
2.  **Target NeRF ($F_\theta$):** A single Multi-Layer Perceptron (MLP) that maps 3D spatial coordinates $\mathbf{x} = (x, y, z)$ to volume density $\sigma$ and color $\mathbf{c}$ [S1, unofficial].
    -   **Architecture:** Uses Factorized Multiplicative Modulation (FMM) layers instead of standard linear layers [S1, unofficial].
    -   **Dimensions:** Hidden layer channels are reduced to 128 (standard is 256) [S1, unofficial]. Depth is typically 4 layers (standard is 8) [S1, unofficial].
    -   **Input:** Only spatial location $\mathbf{x}$; no viewing direction $\mathbf{d}$ [S1, unofficial].
    -   **Output:** $\sigma(\mathbf{x})$ and $\mathbf{c}(\mathbf{x})$ [S1, unofficial].
3.  **Discriminator ($D$):** A standard 2D CNN discriminator that evaluates rendered 2D images [S1, unofficial].

**Parameters:**
-   **Rank $k$:** Controls the rank of the modulation matrices in FMM layers. Default value is $k=10$ [S1, unofficial].
-   **Network Depth:** 4 layers (reduced from 8) [S1, unofficial].
-   **Hidden Channels:** 128 (reduced from 256) [S1, unofficial].

**Numbered Steps:**
1.  Sample a noise vector $\mathbf{z} \sim P_{noise}$ [S1, unofficial].
2.  Pass $\mathbf{z}$ through the Generator $G$ to produce modulation matrices $A$ and $B$ [S1, unofficial].
3.  Construct the effective weight matrix $\tilde{W}$ for the target NeRF layers using Factorized Multiplicative Modulation (FMM):
    $$
    \tilde{W} = W \odot (A \times B)
    $$
    where $W$ is the shared base weight matrix, $A$ is of size $n_{out} \times k$, and $B$ is of size $k \times n_{in}$ [S1, unofficial].
4.  Instantiate the target NeRF $F_\theta$ using the computed weights $\tilde{W}$ and biases $b$ [S1, unofficial].
5.  Render 2D images from various perspectives using $F_\theta$ via standard volume rendering:
    $$
    C(\mathbf{r}) = \sum_{i=1}^N T_i \alpha_i \mathbf{c}_i, \quad \alpha_i = 1 - \exp(-\sigma_i \delta_i), \quad T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)
    $$
    where $\mathbf{r}$ is the ray, $\mathbf{c}_i$ and $\sigma_i$ are color and density at sample point $i$, and $\delta_i$ is the distance between samples [S1, unofficial]. Note: Only the "coarse" network is used; the "fine" network is omitted to reduce cost [S1, unofficial].
6.  Compute the GAN loss using the minimax game:
    $$
    \min_G \max_D V(D, G)
    $$
    where
    $$
    V(D, G) = \mathbb{E}_{\mathbf{x} \sim P_{data}}[\log D(\mathbf{x})] + \mathbb{E}_{\mathbf{z} \sim P_{noise}}[\log(1 - D(G(\mathbf{z})))]
    $$
    [S1, unofficial].
7.  Update $G$ and $D$ using gradient descent [S1, unofficial].

**Pseudocode:**

import torch
import torch.nn as nn
import torch.nn.functional as F

class FMMLayer(nn.Module):
    """Factorized Multiplicative Modulation Layer"""
    def __init__(self, n_in, n_out, k=10):
        super().__init__()
        self.n_in = n_in
        self.n_out = n_out
        self.k = k
        # Shared base weights and biases
        self.W = nn.Parameter(torch.randn(n_out, n_in))
        self.b = nn.Parameter(torch.zeros(n_out))
        # Modulation matrices A and B are generated by the hypernetwork (G)
        # Here we define the forward pass assuming A and B are provided
        self.k = k

    def forward(self, x, A, B):
        # x: (batch, n_in)
        # A: (n_out, k)
        # B: (k, n_in)
        # Compute effective weight: W_tilde = W * (A @ B)
        # Note: Element-wise multiplication with broadcasting
        modulation = A @ B  # (n_out, n_in)
        W_tilde = self.W * modulation
        return F.linear(x, W_tilde, self.b)

class HyperNeRFGAN:
    def __init__(self, generator, discriminator, n_layers=4, hidden_dim=128, k=10):
        self.generator = generator
        self.discriminator = discriminator
        self.n_layers = n_layers
        self.hidden_dim = hidden_dim
        self.k = k
        # The target NeRF is not a fixed module but a function constructed from weights
        # We store the base weights for the FMM layers
        self.base_weights = []
        self.base_biases = []
        for i in range(n_layers):
            n_in = hidden_dim if i > 0 else 3 # Input is 3D coordinate
            n_out = hidden_dim
            layer = FMMLayer(n_in, n_out, k)
            self.base_weights.append(layer.W)
            self.base_biases.append(layer.b)

    def instantiate_nerf(self, modulation_params):
        """
        Constructs the NeRF forward function using modulation parameters from G.
        modulation_params: list of tuples (A, B) for each layer
        """
        def nerf_forward(x):
            # x: (batch, 3)
            h = x
            for i in range(self.n_layers):
                A, B = modulation_params[i]
                # Apply FMM layer
                # Note: In a real implementation, this would be a custom autograd function
                # or a specific layer class that handles the weight modulation dynamically
                modulation = A @ B
                W_tilde = self.base_weights[i] * modulation
                h = F.linear(h, W_tilde, self.base_biases[i])
                if i < self.n_layers - 1:
                    h = F.relu(h)
            # Final layer outputs sigma and color
            # Assuming last layer splits output into sigma and color
            # This is a simplification; typically separate heads or split output
            return h # Returns concatenated sigma and color
        return nerf_forward

    def render(self, nerf_fn, rays):
        """
        Standard volume rendering.
        rays: (batch, 3) origin, (batch, 3) direction
        """
        # Sample points along rays
        # This is a placeholder for the actual sampling logic
        # Points: (batch, N, 3)
        # Deltas: (batch, N)
        points = ... # Sample points
        deltas = ... # Distances
        
        # Get sigma and color from NeRF
        # nerf_fn expects (batch, 3)
        outputs = nerf_fn(points.reshape(-1, 3))
        outputs = outputs.reshape(points.shape[0], points.shape[1], -1)
        
        sigma = outputs[..., :1]
        color = outputs[..., 1:]
        
        # Compute alpha and transmittance
        alpha = 1.0 - torch.exp(-sigma * deltas)
        T = torch.cumprod(torch.cat([torch.ones_like(alpha[..., :1]), 1.0 - alpha[..., :-1]], dim=-1), dim=-1)
        
        # Composite color
        weights = T * alpha
        image = torch.sum(weights * color, dim=-2)

        # 1. Generate modulation parameters
        modulation_params = self.generator(z)
        
        # 2. Instantiate NeRF and render

        # 4. Generator loss

        loss_g = -torch.mean(d_fake_gen)
        
        return loss_d, loss_g

**Edge Cases and Pitfalls:**
-   **Viewing Directions:** Standard NeRF requires viewing directions $\mathbf{d}$. HyperNeRFGAN omits this input, assuming view-independent appearance (no reflections/specularities) [S1, unofficial]. If the dataset contains view-dependent effects, performance may degrade [S1, unofficial].
-   **Fine Network:** The "fine" network from standard NeRF is omitted to reduce computational cost. This may limit the quality of fine details compared to full NeRF [S1, unofficial].
-   **Rank $k$:** Higher $k$ increases expressiveness but also memory usage. $k=10$ is used as a balance [S1, unofficial].

## Subtopics

### Latent-NeRF
Optimizes a latent code for a fixed NeRF network. HyperNeRFGAN generates the network weights directly, allowing for more diverse 3D structures from noise without explicit conditioning [S1, unofficial].

### GRAF / $\pi$-GAN
Use SIREN with conditioning mechanisms. HyperNeRFGAN uses a hypernetwork to generate NeRF weights, avoiding the complexity of conditioning while maintaining 3D awareness [S1, unofficial].

## Operating characteristics
-   **Time Complexity:** Training time is reduced compared to standard NeRF due to the omission of the fine network and reduced hidden dimensions (128 channels, 4 layers) [S1, unofficial].
-   **Memory Complexity:** Memory usage is controlled by the rank $k$ of the modulation matrices. $k=10$ is used to balance expressiveness and memory [S1, unofficial].
-   **Performance:**
    -   **ShapeNet Car:** FID 29.6 (vs. Point2NeRF 82.1) [S1, unofficial].
    -   **CARLA:** FID 20.5, KID 0.78, IS 4.20 (outperforming HoloGAN, GRAF, $\pi$-GAN) [S1, unofficial].
    -   **CelebA:** FID 15.04, KID 0.66, IS 2.63 (comparable to $\pi$-GAN) [S1, unofficial].
-   **Strengths:** Does not require camera positions; suitable for medical data and limited-view datasets; simple architecture [S1, unofficial].
-   **Limitations:** Assumes view-independent appearance; may lack fine detail due to omission of fine network [S1, unofficial].

## Background
HyperNeRFGAN was introduced in 2023 by Zimny et al. [S1, unofficial]. It builds on the hypernetwork paradigm (Ha et al., 2016) and StyleGAN2 (Karras et al., 2020) to generate NeRF weights. It addresses the limitations of standard NeRF training, which requires camera poses, and the complexity of conditioning mechanisms in other generative NeRF models [S1, unofficial]. It has been applied to ShapeNet, CARLA, CelebA, and medical datasets (DRR of chests and knees) [S1, unofficial].
