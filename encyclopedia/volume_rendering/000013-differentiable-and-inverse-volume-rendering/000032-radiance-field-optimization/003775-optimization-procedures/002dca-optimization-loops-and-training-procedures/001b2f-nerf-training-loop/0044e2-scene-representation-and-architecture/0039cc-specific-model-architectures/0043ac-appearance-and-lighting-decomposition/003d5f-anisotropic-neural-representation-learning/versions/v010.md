# Anisotropic Neural Representation Learning

Also called: Anisotropic NeRF, SH-guided anisotropic features

## Overview
Anisotropic Neural Representation Learning (ANRL) is a method for neural volume rendering that models volumetric density and latent features as view-dependent functions using spherical harmonics (SH) to eliminate directional ambiguity [S1]. Unlike standard NeRF which assumes isotropic point-sampled features, ANRL replaces the initial MLP output with SH coefficients, allowing the representation to capture anisotropy directly without shape-based sampling parameterization [S1]. This approach improves reconstruction quality in scenes with complex lighting or reflective surfaces while maintaining rendering efficiency [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Ray origin $\mathbf{o}$, direction $\mathbf{d}$, near/far bounds $t_n, t_f$.
*   **Output:** Pixel color $C(\mathbf{r})$.

**Data Structures:**
The method modifies the first Multi-Layer Perceptron (MLP) of the standard NeRF architecture.
1.  **Positional Encoding:** Input coordinates $\mathbf{x}$ and directions $\mathbf{d}$ are mapped using positional encoding $\gamma(\cdot)$ [S1, S3]:
    $$
    \gamma(\mathbf{x}) = (\sin(2^0 \pi \mathbf{x}), \cos(2^0 \pi \mathbf{x}), \dots, \sin(2^{L-1} \pi \mathbf{x}), \cos(2^{L-1} \pi \mathbf{x}))
    $$
    where $L$ is the number of frequency bands [S1, S3].
2.  **SH-MLP ($F_{SH}$):** Takes $\gamma(\mathbf{x})$ as input. It consists of $L$ hidden layers with ReLU activations and skip connections from the input to every 4th layer [S1, S3]. Instead of outputting raw density $\sigma$ and latent features, it outputs coefficients for spherical harmonic basis functions [S1].
3.  **Appearance MLP ($F_c$):** Takes the evaluated view-dependent features, $\gamma(\mathbf{x})$, and $\mathbf{d}$ as input to compute final color $\mathbf{c}$ [S1, S3].

**Numbered Steps:**
1.  **Ray Sampling:** Sample $N$ points $t_i$ along the ray within bounds $[t_n, t_f]$ in near-to-far order [S1]. Define intervals $I_i = [t_i, t_{i+1}]$ [S1].
2.  **SH Coefficient Prediction:** For each sample point $\mathbf{x}_i$, pass $\gamma(\mathbf{x}_i)$ through $F_{SH}$ to obtain SH coefficients $\mathbf{w}_i$ [S1].
3.  **Anisotropic Feature Evaluation:** Evaluate the SH basis functions at the query viewing direction $\mathbf{d}$ using coefficients $\mathbf{w}_i$ to produce view-dependent density $\sigma_i$ and latent features $\mathbf{f}_i$ [S1]. This step captures anisotropy explicitly [S1].
4.  **Regularization (Training Only):** Decompose anisotropic elements from the predicted density and latent features. Apply a point-wise operation to penalize the energy of anisotropy in the geometry representation to prevent over-fitting and shape-radiance ambiguity [S1].
5.  **Color Computation:** Pass $\mathbf{f}_i$, $\gamma(\mathbf{x}_i)$, and $\mathbf{d}$ through $F_c$ to obtain color $\mathbf{c}_i$ [S1, S3].
6.  **Volume Rendering:** Compute pixel color using the discrete Riemann sum approximation [S1]:
    $$
    \hat{C}(\mathbf{r}) = \sum_{i=0}^{N} \mathbf{c}_i T_i (1 - \exp(-\sigma_i (t_{i+1} - t_i)))
    $$
    where $T_i = \exp\left(-\sum_{j=0}^{i-1} \sigma_j (t_{j+1} - t_j)\right)$ represents occlusion [S1].

```python
import numpy as np

def spherical_harmonics_eval(direction, coefficients, degree):
    """
    Evaluates spherical harmonics basis functions for a given direction.
    direction: (3,) array, viewing direction d.
    coefficients: (K,) array, SH coefficients w.
    degree: int, maximum degree of SH.
    Returns: scalar value representing the anisotropic feature.
    """
    # Implementation of SH basis evaluation
    # Standard SH basis functions Y_l^m(theta, phi) derived from direction
    # Dot product of coefficients and basis vector
    basis = compute_sh_basis(direction, degree)
    return np.dot(coefficients, basis)

def compute_sh_basis(direction, degree):
    """
    Computes the vector of SH basis functions for a direction.
    """
    # Normalize direction
    d = direction / np.linalg.norm(direction)
    x, y, z = d[0], d[1], d[2]
    
    # Example for degree 0 and 1 (compact representation)
    # Degree 0: 1 basis function
    # Degree 1: 3 basis functions
    # Total K = (degree + 1)^2
    K = (degree + 1)**2
    basis = np.zeros(K)
    
    # Degree 0
    basis[0] = 1.0 / np.sqrt(4 * np.pi)
    
    # Degree 1
    if degree >= 1:
        inv_sqrt = 1.0 / np.sqrt(3 * np.pi)
        basis[1] = z * inv_sqrt
        basis[2] = x * inv_sqrt
        basis[3] = y * inv_sqrt

    # [G] Full SH basis implementation omitted for brevity, 
    # assuming standard mathematical definition of SH basis functions.
    return basis

    Forward pass for Anisotropic Neural Representation Learning.
    x_samples: (N, 3) array, sampled points on ray.
    d: (3,) array, ray direction.
    sh_mlp: function, predicts SH coefficients from positional encoded x.
    color_mlp: function, predicts color from features and direction.
    degree: int, SH degree.
    t_bounds: (2,) array, [t_n, t_f].
    """
    N = x_samples.shape[0]
    
    # 1. Positional Encoding
    # [G] Assuming a standard positional encoding function gamma
    gamma_x = positional_encoding(x_samples, L=10) 
    
    # 2. Predict SH Coefficients
    # sh_mlp outputs coefficients for each sample
    sh_coeffs = sh_mlp(gamma_x) # Shape: (N, K)
    
    # 3. Evaluate Anisotropic Features (Density and Latent)
    # [G] The source states SH evaluation produces density and latent features.
    # We assume the SH coefficients are split or mapped to these properties.
    # For simplicity, we evaluate the SH basis to get a scalar "anisotropy factor"
    # which modulates the base density/feature predicted by a separate mechanism 
    # or directly represents the view-dependent component.
    # The source says: "model the density and latent features ... as view-dependent functions using SH".
    # This implies the SH output *is* the view-dependent part.
    
    # Evaluate SH basis for direction d
    sh_basis = compute_sh_basis(d, degree) # Shape: (K,)
    
    # Project coefficients onto direction to get view-dependent values
    # [G] The source implies the SH coefficients are evaluated at d.
    # If the MLP outputs coefficients for density and features separately,
    # we would have two sets of coefficients. 
    # Here we assume a single set of coefficients modulates the representation.
    # A more precise interpretation: The MLP outputs coefficients for the 
    # view-dependent component. The isotropic component might be handled 
    # by the base MLP structure or added. 
    # Given the source "predict the geometry explicitly in terms of spherical harmonics",
    # we treat the SH evaluation as the primary output mechanism for view-dependence.
    
    # Let's assume the MLP outputs coefficients for density (sigma) and features (f)
    # Splitting sh_coeffs into sigma_coeffs and f_coeffs
    # [G] Exact split not specified, assuming equal split or separate heads.
    # For implementation completeness, we assume the MLP outputs a vector 
    # that is interpreted as SH coefficients for density and latent features.
    
    # Evaluate for density
    sigma_view_dep = np.dot(sh_coeffs, sh_basis) # Shape: (N,)
    
    # Evaluate for latent features (assuming same basis or separate coefficients)
    # [G] Source does not specify if features use same SH basis. 
    # Assuming they do for compactness.
    f_view_dep = np.dot(sh_coeffs, sh_basis) # Shape: (N,)

    # Source implies the SH representation *replaces* the isotropic point features.
    sigma = sigma_view_dep
    features = f_view_dep

    t_n, t_f = t_bounds
    # Sample points t_i

    # Transmittance
    # T_i = exp(-sum_{j=0}^{i-1} sigma_j * delta_j)
    # Cumulative sum of sigma * delta
    sigma_delta = sigma * deltas
    alpha = 1.0 - np.exp(-sigma_delta)

    weights = transmittance[:-1] * alpha
    color = np.sum(weights[:, np.newaxis] * colors, axis=0)
    
    return color
```

**Parameters:**
*   $N$: Number of samples on the ray within near and far bounds ($t_n$ and $t_f$) [S1].
*   $L$: Number of frequency bands for positional encoding [S1, S3].
*   SH Degree: Determines the number of coefficients $K = (degree + 1)^2$ [S1].

**Edge Cases and Pitfalls:**
*   **Shape-Radiance Ambiguity:** Training with only color reconstruction loss causes strong anisotropy and ambiguity [S1]. This is mitigated by the point-wise regularization of anisotropy energy [S1].
*   **Precision:** Evaluating SH basis functions at arbitrary directions requires careful normalization of the direction vector $\mathbf{d}$ [S1].

## Operating characteristics
*   **Time Complexity:** Similar to standard NeRF per forward pass, but with additional overhead for SH basis evaluation and coefficient prediction [S1].
*   **Memory Complexity:** Increased memory usage due to storing SH coefficients instead of scalar density/feature values [S1].
*   **Strengths:** Eliminates directional ambiguity; improves reconstruction quality for anisotropic materials; plug-and-play with various NeRF frameworks [S1].
*   **Limitations:** Requires regularization to prevent over-fitting of anisotropy; computational cost of SH evaluation [S1].
*   **When to Use:** Scenes with complex lighting, reflections, or anisotropic materials where standard isotropic NeRF fails [S1].
*   **When Not to Use:** Simple scenes with diffuse materials where isotropic representation is sufficient [S1].

## Background
Anisotropic Neural Representation Learning was proposed to address the limitations of standard NeRF in handling directional ambiguity [S1]. It builds on the principle of decoupling view-independent geometry from view-dependent lighting [Parent]. The method was introduced in "Improving Neural Volume Rendering via Learning View-Dependent Integral Approximation" [S1].
