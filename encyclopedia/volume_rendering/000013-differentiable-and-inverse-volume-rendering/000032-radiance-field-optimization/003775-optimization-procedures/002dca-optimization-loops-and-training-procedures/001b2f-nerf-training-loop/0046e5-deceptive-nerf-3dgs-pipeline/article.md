# Deceptive-NeRF/3DGS Pipeline

Also called: Deceptive-3DGS, Deceptive-NeRF

## Overview
Deceptive-NeRF/3DGS is a sparse-view reconstruction method that enhances NeRF or 3D Gaussian Splatting (3DGS) by continuously densifying input observations with synthetic pseudo-observations generated by a diffusion model during training [S1]. It distinguishes itself from sibling methods by introducing an uncertainty map derived from view-consistency warping to guide the diffusion process, ensuring that generated pseudo-observations adhere to epipolar constraints and 3D geometry, rather than relying on ensemble learning or variational inference for uncertainty estimation [S1].

## How it works
**Inputs:** A set of $W$ input images $I = \{I_1, \dots, I_W\}$ with calibrated camera poses.
**Outputs:** A trained radiance field (NeRF or 3DGS) and a set of accumulated pseudo-observations.

**Data Structures:**
*   **Radiance Field:** Standard NeRF or 3DGS representation.
*   **ControlNet:** A copy of a pre-trained 2D diffusion model (e.g., Stable Diffusion) with trainable weights, conditioned on five channels: 3 for RGB, 1 for depth, 1 for uncertainty [S1].
*   **Text Embedding:** A composite vector $s = [s_0, s^*]$ combining a captioning prompt $s_0$ and an optimized latent embedding $s^*$ [S1].

**Numbered Steps:**

1.  **Initial Training:** Train the NeRF/3DGS representation using the few-view input images $I$ with their calibrated poses [S1].
2.  **Coarse Reconstruction:** After a set number of epochs, obtain a coarse reconstruction of the scene [S1].
3.  **Novel View Sampling:** Randomly sample novel viewpoints within a bounding box defined by the outermost input views [S1].
4.  **Rendering:** At a novel viewpoint $A$, render the RGB image $\hat{I}_A$, depth map $D_A$, and uncertainty map $U_A$ [S1].
    *   **Depth Rendering:** Compute depth as a weighted sum of distances traveled:
        $$ \hat{\mathbf{D}} = \sum_{k=1}^K \hat{T}(t_k)\alpha (\sigma (t_k)\delta _k) $$
        where $\hat{T}(t_k)$ is transmittance, $\alpha$ is opacity, $\sigma$ is density, and $\delta_k$ is the distance traveled [S1].
    *   **Uncertainty Map Generation:**
        1.  Identify $B$, the nearest input viewpoint to the novel view $A$ [S1].
        2.  Warp the ground truth image $I_B$ to the novel view $A$ using the rendered depth $D_A$ and the viewpoint difference $R_{B\rightarrow A}$:
            $$ I_{B\rightarrow A} = \psi (I_B; D_A, R_{B\rightarrow A}) $$
        3.  Transform pixel locations $p$ in $\hat{I}_A$ to $q$ in $I_B$ using the camera parameter matrix $K$:
            $$ q = K R_{B\rightarrow A} D_A(p) K^{-1} p $$
        4.  Compute the uncertainty map as the squared difference between the warped image and the rendered image:
            $$ U_A = (I_{B \rightarrow A} - \hat {I}_A)^2 $$
            This measure enforces view consistency by leveraging correspondence matching and epipolar constraints [S1].
5.  **Text Embedding Derivation:**
    1.  Generate a text prompt $s_0$ using a pre-trained image captioning network on the coarse image [S1].
    2.  Optimize a shared latent text embedding $s^*$ shared by all input observations and coarse images using textual inversion to counteract captioning errors on low-quality images [S1].
    3.  Form the composite feature $s = [s_0, s^*]$ by concatenating the embeddings [S1].
6.  **Pseudo-Observation Generation:** Generate the pseudo-observation $P_A$ using the Deceptive Diffusion Model $G$, conditioned on the rendered RGB, depth, uncertainty, and text embedding:
    $$ P_A = \operatorname {G}(\hat {I}_A, D_A, U_A) $$
    The model $G$ is a fine-tuned latent diffusion model (ControlNet) where the denoiser $\epsilon_\theta$ minimizes:
    $$ \min _{\theta}\mathbb {E}_{z\sim \mathcal {E},t,\epsilon \sim \mathcal {N}(0,1)}\|\epsilon -\epsilon _{\theta }(z_t,t,c(I_{\text {coarse}},D,U,s))\|_2^2 $$
    where $z \sim \mathcal{E}$ is the latent code, $t \sim [1, 1000]$ is the diffusion time step, $\epsilon$ is noise, and $c$ is the embedding of the coarse image, depth, uncertainty, and text [S1].
7.  **Filtering:** Discard 20% of the generated pseudo-observations that have the lowest perceptual similarity to the input images, quantified via the LPIPS metric [S1].
8.  **Accumulation and Training:** Accumulate the valid pseudo-observations. Continue training the NeRF/3DGS representation using the combination of real input images and the accumulated pseudo-observations [S1].
9.  **Iteration:** Repeat steps 3–8 until a sufficient number of observations are accumulated [S1].

```python
def deceptive_nerf_pipeline(input_images, input_poses, num_epochs_coarse, num_iterations):
    # 1. Initial Training
    nerf_model = train_nerf(input_images, input_poses, epochs=num_epochs_coarse)
    
    # 5. Text Embedding Derivation (Pre-computed or updated periodically)
    s0 = captioning_network.generate_prompt(nerf_model.render_coarse())
    s_star = textual_inversion.optimize_shared_embedding(input_images, nerf_model)
    text_embedding = concatenate(s0, s_star)
    
    # 4. Data Augmentation for Diffusion (Offline/Preparation)
    # Construct dataset of quartets (Ifine, Icoarse, D, U)
    # Option A: Train coarse/fine NeRF duos (coarse uses 1/5 images)
    # Option B: Add Gaussian noise (std=0.3) to 60,000 Hypersim images
    diffusion_dataset = prepare_diffusion_dataset(nerf_model, source="Hypersim_CO3D")
    
    # Fine-tune Deceptive Diffusion Model G (ControlNet)
    # Loss: ||epsilon - epsilon_theta(z_t, t, c(I_coarse, D, U, s))||^2
    deceptive_diffusion_model = fine_tune_controlnet(diffusion_dataset, text_embedding)
    
    pseudo_observations = []
    
    for iteration in range(num_iterations):
        # 3. Novel View Sampling
        novel_view_A = sample_random_view(outermost_bounds(input_poses))
        
        # 4. Rendering
        I_hat_A = nerf_model.render_rgb(novel_view_A)
        D_A = nerf_model.render_depth(novel_view_A)
        
        # Uncertainty Map Generation
        B = find_nearest_input_view(novel_view_A, input_poses)
        R_BtoA = compute_viewpoint_difference(novel_view_A, input_poses[B])
        K = input_poses[B].camera_matrix
        
        # Warp nearest input view to novel view
        # Pixel transformation: q = K * R_BtoA * D_A(p) * K^-1 * p
        I_B_warped = warp_image(input_images[B], D_A, R_BtoA, K)
        
        # Uncertainty: Squared distance between warped and rendered
        U_A = square_difference(I_B_warped, I_hat_A)
        
        # 6. Pseudo-Observation Generation
        # Condition on 5 channels: 3 RGB, 1 Depth, 1 Uncertainty
        P_A = deceptive_diffusion_model.generate(I_hat_A, D_A, U_A, text_embedding)
        
        # 7. Filtering
        if perceptual_similarity(P_A, input_images) > threshold:
            pseudo_observations.append(P_A)
        else:
            discard(P_A)
            
        # 8. Training with Pseudo-Observations
        # Discard bottom 20% of accumulated pseudo-observations based on LPIPS
        pseudo_observations = filter_bottom_20_percent(pseudo_observations, input_images)
        
        combined_images = input_images + pseudo_observations
        nerf_model = train_nerf(combined_images, input_poses, epochs=1)
        
    return nerf_model
```

**Parameters:**
*   **Discard Rate:** 20% of pseudo-observations with the lowest LPIPS similarity are discarded [S1].
*   **Gaussian Noise Std:** 0.3, used for data augmentation on Hypersim images [S1].
*   **ControlNet Channels:** 5 channels (3 RGB, 1 Depth, 1 Uncertainty) [S1].
*   **Image Resolution:** Randomly cropped to 512 × 512 [S1].
*   **Training Dataset Size:** 200 scenes, ~20,000 images (Hypersim and CO3D contribute half each) [S1].
*   **Coarse NeRF Data:** Trained on one-fifth of input images [S1].

**Edge Cases and Pitfalls:**
*   **Captioning Efficacy:** Image captioning efficacy diminishes for low-quality images or those with pronounced artifacts. Textual inversion is used to optimize a shared latent embedding $s^*$ to counteract this [S1].
*   **Noisy Augmentation:** When training with noisy RGB-depth data augmentation (Gaussian noise), uncertainty maps are not fed into the diffusion model [S1].

## Operating characteristics
*   **Time Complexity:** The method requires iterative training loops alternating between NeRF/3DGS optimization and diffusion model inference. The diffusion model fine-tuning adds significant overhead during the preparation phase, requiring a dataset of ~20,000 images [S1].
*   **Memory Complexity:** Requires storing the radiance field, the ControlNet weights, and the accumulated pseudo-observations. The use of ControlNet preserves the weights of the pre-trained 2D diffusion model, avoiding the need to train a new large model from scratch [S1].
*   **Performance:** On the LLFF dataset, Deceptive-NeRF achieves a PSNR of 19.87 (3-view) and 25.30 (9-view), while Deceptive-3DGS achieves 19.95 (3-view) and 25.34 (9-view), outperforming baselines like PixelNeRF and DietNeRF [S1].
*   **Strengths:** Enforces 3D consistency via uncertainty maps derived from epipolar constraints without modifying the underlying radiance field representation [S1].
*   **Limitations:** Relies on the quality of the initial coarse reconstruction and the pre-trained diffusion model's priors. Performance may degrade if the initial NeRF/3DGS is poor [S1].

## Background
Deceptive-NeRF/3DGS was introduced by Liu et al. in 2023 [S1]. It addresses the challenge of sparse-view reconstruction by leveraging the generative priors of 2D diffusion models to fill in missing views, a technique termed "deceptive" because the model refines unnatural NeRF artifacts into photorealistic pseudo-observations [S1]. The method builds on latent diffusion models [S1] and ControlNet [S1] to condition generation on geometric cues (depth and uncertainty).
