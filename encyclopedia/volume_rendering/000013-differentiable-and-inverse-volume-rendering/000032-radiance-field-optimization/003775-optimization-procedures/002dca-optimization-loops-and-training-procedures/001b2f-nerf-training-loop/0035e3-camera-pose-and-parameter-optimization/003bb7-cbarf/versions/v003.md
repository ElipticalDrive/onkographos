# CBARF
Also called: CBARF (Cascaded Bundle-Adjusting Neural Radiance Fields), Cascaded BA

## Overview
CBARF is a 3D reconstruction model that optimizes imperfect camera poses using a cascaded bundle-adjustment (BA) structure to progressively refine poses and rectify erroneous ones [S1]. It sets itself apart from its sibling [BARF](6872-barf-bundle-adjusting-neural-radiance-fields.md) by employing a coarse-to-fine cascaded optimization strategy with specific modulation factors, allowing it to handle larger initial pose errors (e.g., 30.4° rotation deviation) where BARF tends to overfit or diverge [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of images with imperfect camera poses $\hat{P}$, a NeRF backbone (typically BARF), and ground-truth images for photometric loss.
*   **Outputs:** Refined camera poses $Q$, a trained NeRF representation, and synthesized images.

**Data Structures:**
*   **Camera Pose $P$:** Represented as a $3 \times 4$ matrix $P = [R_p \ t_p] \in \mathbb{R}^{3 \times 4}$, where $R_p \in SO(3)$ and $t_p \in \mathbb{R}^3$ [S1].
*   **Lie Algebra Noise $n$:** A 6-dimensional vector $n \in \mathbb{R}^6$ representing perturbations in $se(3)$ [S1].
*   **Refine Parameters $p$:** A 6-dimensional vector $p \in se(3)$ optimized during training [S1].

**Numbered Steps:**

1.  **Simulate Imperfect Poses (Initialization):**
    Generate noise $n$ from a 6-dimensional normal distribution scaled by a coefficient $\alpha = 0.35$:
    $$ n = 0.35 \mathcal{N}(0, I) \in \mathbb{R}^6 $$
    [S1]
    Transform $n$ into a transform matrix $N = [R_n \ t_n]$ using the exponential map from $se(3)$ to $SO(3) \times \mathbb{R}^3$ [S1]. Compose with the reference pose $P = [R_p \ t_p]$ to create the imperfect initial pose $\hat{P}$:
    $$ \hat{P} = [R_p R_n \ t_p + t_n] $$
    [S1]
    *Note: This noise corresponds to an average deviation of 30.4° in rotation and 0.56 in translation [S1].*

2.  **Cascaded Optimization Structure:**
    The optimization proceeds through three stages: Coarse, Recursive, and Fine [S1]. Each stage uses a "compact BA module" based on the BARF network [S1].

3.  **Pose Refinement Loop (per stage):**
    For each stage, optimize the refine parameters $p \in se(3)$:
    a. Convert $p$ to a transform matrix $P_r = [R_r \ t_r]$ [S1].
    b. Compose $P_r$ with the current imperfect pose $\hat{P}$ to obtain the refined pose $Q$:
    $$ Q = [R_p R_n R_r \ t_p + t_n + t_r] $$
    [S1]
    c. Render images using $Q$ and the current NeRF parameters.
    d. Compute photometric loss between rendered images and ground-truth images.
    e. Update $p$ and NeRF parameters $\Theta$ using gradient descent (Adam) [S1].

4.  **Learning Rate Schedule:**
    Use exponential interpolation with a modulation factor $\mu$ to bias the learning rate towards the initial high value [S1]. The learning rate $\eta(t)$ at iteration $t$ is modulated by $\mu$. Typical values for $\mu$ are:
    *   Coarse stage: $\mu = 10.0$
    *   Recursive stage: $\mu = 3.0$
    *   Fine stage: $\mu = 1.0$
    [S1]

5.  **Stage Transitions:**
    *   **Coarse Stage:** Iterations = 20,000 [S1].
    *   **Recursive Stage:** Iterations = 20,000 [S1].
    *   **Fine Stage:** Iterations = 200,000 [S1]
    [S1]
    The output pose $Q$ from one stage becomes the input $\hat{P}$ for the next stage.

6.  **Incomplete Pose Handling (Optional):**
    If 10% of poses are missing, assign an initial pose $P_{ini}$ to the missing set $F$ and jointly optimize poses for the training set $T$ and test set $F$ [S1].

7.  **Evaluation Alignment:**
    Apply Procrustes analysis to align the optimized poses with ground-truth poses before calculating error metrics to remove global coordinate system misalignment [S1].

**Edge Cases and Pitfalls:**
*   **Local Minima:** Poor initialization can lead to divergence. The cascaded structure mitigates this by starting with coarse updates [S1].
*   **Coordinate Misalignment:** Optimized poses may have a global offset relative to ground truth. Procrustes analysis is required before evaluation [S1].
*   **Missing Poses:** If 10% of poses are missing, they must be initialized and jointly optimized with known poses [S1].

## Operating characteristics
*   **Time Complexity:** High. Requires multiple stages of optimization (240k+ iterations total) and full NeRF training at each stage [S1].
*   **Memory Complexity:** Standard NeRF memory usage plus storage for pose parameters [S1].
*   **Performance:** Successfully optimizes poses with large initial errors (30.4° rotation) where BARF fails [S1]. Rendering quality (PSNR, SSIM) is comparable to ground-truth pose rendering [S1].
*   **Strengths:** Robust to large initial pose errors; handles incomplete pose sets [S1].
*   **Limitations:** Computationally expensive due to cascaded stages; requires careful tuning of modulation factors [S1].

## Background
CBARF was proposed in 2024 by authors publishing in the IEEE Transactions on Multimedia [S1]. It builds on the BARF method [S1] to address the limitation that BARF struggles with large initial pose errors. The method introduces a cascaded bundle-adjustment structure and a neighbor-replacement strategy to rectify erroneous poses [S1].
