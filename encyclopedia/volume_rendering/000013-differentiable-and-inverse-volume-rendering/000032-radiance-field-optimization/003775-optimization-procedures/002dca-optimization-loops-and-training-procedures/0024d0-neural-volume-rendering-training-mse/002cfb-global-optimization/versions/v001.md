# Global Optimization

Also called: Global Solver, Global Compressive Rendering

## Overview
Global Optimization is a method for reconstructing a complete image or volume from a sparse subset of measurements by solving for all pixels/voxels simultaneously across the entire domain. It sets itself apart from local or block-based solvers by considering the global context of the entire image during the optimization process, which can improve reconstruction quality at the cost of higher memory usage and computational complexity per iteration. It is primarily used in compressive rendering and tomographic reconstruction where data is incomplete.

## How it works
Global Optimization typically involves two distinct contexts found in the literature: iterative gradient-based reconstruction for sparse data (Compressive Rendering) and differentiable volume rendering optimization (Neural Volume Rendering).

### Context 1: Compressive Rendering (Global Solver)
This approach reconstructs a full image from a subset of pixels using a gradient solver that operates on the entire image domain.

**Inputs and Outputs:**
- Input: A sparse image $I_{sparse}$ containing only a subset of valid pixels, with missing pixels marked as unknown.
- Output: A reconstructed full image $I_{full}$ of size $m \times n$.

**Data Structures:**
- $I_{full}$: A 2D array of size $m \times n$, initialized with known pixel values from $I_{sparse}$ and zeros or interpolated values for missing pixels.
- Mask $M$: A binary 2D array of size $m \times n$, where $M_{ij} = 1$ if the pixel is known, and $0$ otherwise.

**Steps:**
1. **Initialization**: Initialize the full image $I_{full}$ with the known values from the input subset.
2. **Iteration Loop**: Repeat until convergence or a fixed number of iterations:
   a. **Gradient Computation**: Compute the gradient of the reconstruction error with respect to $I_{full}$. The error is typically defined only on the known pixels.
   b. **Update**: Update $I_{full}$ using a gradient descent step:
      $$ I_{full}^{(t+1)} = I_{full}^{(t)} - \alpha \nabla E(I_{full}^{(t)}) $$
      where $\alpha$ is the learning rate.
   c. **Constraint Enforcement**: Ensure that known pixels remain unchanged (or are re-projected to their known values) to maintain fidelity to the input data.
3. **Termination**: Stop when the change in $I_{full}$ between iterations is below a threshold or after a fixed number of iterations.

**Parameters:**
- Iterations: Can be fixed or allowed to run multiple times until a desired solution is reached [S2, unofficial].
- Learning Rate $\alpha$: Not specified in sources.

**Pseudocode:**
```python
def global_solver_compressive_rendering(I_sparse, mask, iterations=100, alpha=0.1):
    """
    Reconstructs a full image from a sparse subset using a global gradient solver.
    
    Args:
        I_sparse: 2D array with known pixel values and NaN/0 for missing.
        mask: 2D binary array (1 for known, 0 for missing).
        iterations: Number of optimization steps.
        alpha: Learning rate for gradient descent.
        
    Returns:
        I_full: Reconstructed 2D image.
    """
    # Initialize full image with known values, 0 for missing
    I_full = I_sparse.copy()
    
    for t in range(iterations):
        # Compute gradient of error on known pixels
        # Error E = sum((I_full - I_sparse)^2) for known pixels
        # Gradient dE/dI_full = 2 * (I_full - I_sparse) for known pixels, 0 otherwise
        error = I_full - I_sparse
        gradient = error * mask * 2.0
        
        # Update image
        I_full = I_full - alpha * gradient
        
        # Enforce constraints: known pixels must remain unchanged
        I_full = I_full * (1 - mask) + I_sparse * mask
        
    return I_full
```

### Context 2: Differentiable Volume Rendering Optimization
This approach optimizes a 3D volume representation (e.g., Gaussian splats) by projecting it back to the 2D image domain and minimizing the difference between rendered and reference images.

**Inputs and Outputs:**
- Input: A 3D volume representation $V$ (e.g., set of 3D Gaussians), reference projection $P$.
- Output: Optimized volume representation $V'$ that minimizes the loss.

**Data Structures:**
- $V$: Representation of the 3D volume (e.g., list of Gaussian parameters: mean, covariance, opacity, color).
- $P$: Reference 2D projection image of size $m \times n \times p$ (where $p$ is channels, e.g., RGB).
- $\hat{P}$: Estimated projection of size $m \times n \times p$.

**Steps:**
1. **Projection**: Project the reconstructed 3D volume $V$ back to the projection domain using a transformation $\mathcal{T}$:
   $$ \hat{P} = \mathcal{T}(V) $$
   where $\hat{P} \in \mathbb{R}^{m \times n \times p}$ denotes the estimated projection [S1].
2. **Loss Computation**: Compute the total loss function combining L1 loss, SSIM loss, and Total Variation (TV) loss:
   $$ \mathcal{L}_{\text{total}} = \lambda_1 \mathcal{L}_1(\hat{P}, P) + \lambda_2 \mathcal{L}_{\text{SSIM}}(\hat{P}, P) + \lambda_3 \mathcal{L}_{\text{TV}}(V) $$
   where $P$ is the reference projection [S1].
3. **Optimization**: Update the parameters of $V$ to minimize $\mathcal{L}_{\text{total}}$ using gradient descent.
4. **Adaptive Density Control**: Enhance optimization by:
   - Cloning under-reconstructed Gaussians.
   - Splitting over-reconstructed Gaussians into smaller ones.
   - Pruning Gaussians with near-zero gradient magnitudes [S1].

**Parameters:**
- Loss weights: $\lambda_1 = 0.6$ (L1), $\lambda_2 = 0.2$ (SSIM), $\lambda_3 = 1$ (TV) [S1].

**Pseudocode:**
```python
def global_optimizer_volume_rendering(V, P, lambda1=0.6, lambda2=0.2, lambda3=1.0, iterations=1000):
    """
    Optimizes a 3D volume representation by minimizing projection error.
    
    Args:
        V: 3D volume representation (e.g., Gaussian splats).
        P: Reference projection image.
        lambda1: Weight for L1 loss.
        lambda2: Weight for SSIM loss.
        lambda3: Weight for TV loss.
        iterations: Number of optimization steps.
        
    Returns:
        V_opt: Optimized volume representation.
    """
    for t in range(iterations):
        # Project volume to 2D
        P_hat = project_volume(V)  # T(V)
        
        # Compute losses
        l1_loss = compute_l1_loss(P_hat, P)
        ssim_loss = compute_ssim_loss(P_hat, P)
        tv_loss = compute_tv_loss(V)
        
        # Total loss
        total_loss = lambda1 * l1_loss + lambda2 * ssim_loss + lambda3 * tv_loss
        
        # Compute gradients and update V
        gradients = compute_gradients(total_loss, V)
        V = update_parameters(V, gradients)
        
        # Adaptive density control
        V = adaptive_density_control(V)
        
    return V
```

## Subtopics

### Compressive Rendering (Global Solver)
A variant of global optimization specifically for reconstructing images from sparse pixel data. It uses a gradient solver that operates on the entire image, as opposed to block-based approaches. It is chosen when global consistency is more important than computational speed per iteration. The main time-consuming operation is convolution, which can be slow due to CPU-GPU memory transfers if not optimized [S2, unofficial].

## Operating characteristics
- **Time Complexity**: Depends on the number of iterations and the cost of gradient computation. For compressive rendering, convolution is the most time-consuming operation, and performance is affected by the number of iterations [S2, unofficial]. For volume rendering, each iteration involves projecting the 3D volume and computing losses, which can be expensive but avoids the need for many iterations compared to standard approaches (e.g., requiring 30K iterations for standard methods) [S1].
- **Memory Complexity**: Requires storing the full image or volume representation, which can be high for large resolutions.
- **Strengths**: Can produce higher quality reconstructions by leveraging global context. Compatible with various CT settings (Fan-Beam, Cone-Beam, Sparse-View, Limited-Angle) [S1].
- **Limitations**: Slower per iteration due to global operations. Memory intensive. For compressive rendering, CPU-GPU memory copying can result in very slow reconstruction if not optimized [S2, unofficial].
- **When to use**: When reconstruction quality is prioritized over speed, and when global consistency is important. Suitable for sparse-view or limited-angle CT reconstruction.
- **When not to use**: When real-time performance is required, or when memory is constrained.

## Background
Global optimization in the context of compressive rendering was proposed in a thesis on GPU-based compressive volume rendering, which suggested a parallel-based approach for reconstruction [S2, unofficial]. In the context of neural volume rendering, global optimization using differentiable rendering and adaptive density control was introduced in a paper on discretized Gaussian representation for tomographic reconstruction, showing substantial improvement over standard approaches [S1].
