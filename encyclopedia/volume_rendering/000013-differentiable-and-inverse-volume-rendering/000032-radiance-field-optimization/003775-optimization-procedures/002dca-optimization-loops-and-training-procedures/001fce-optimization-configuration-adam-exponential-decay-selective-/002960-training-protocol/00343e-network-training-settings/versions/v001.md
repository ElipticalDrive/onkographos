# Network Training Settings

Also called: Activation and Dropout, General Network Configuration

## Overview
This article defines the standard hyperparameter configuration for neural networks in radiance-field optimization, specifically focusing on activation functions, dropout regularization, and latent space dimensionality validation. It addresses the problem of stabilizing training and preventing overfitting in differentiable rendering pipelines. It is distinguished from general optimization loops by its focus on architectural regularization (dropout) and non-linearities (PReLU) rather than gradient descent dynamics. It builds on [Training Protocol](4528-training-protocol.md).

## How it works

### Inputs and Outputs
- **Inputs**: Network architecture definition (layer types, residual blocks), training dataset (e.g., Combustion dataset), and hyperparameter search space (latent dimensions).
- **Outputs**: A trained network with optimized weights, validated latent space dimensionality, and final model performance metrics (RMSE, EMD).

### Steps
1. **Initialize Network**: Construct the network using 3D or 2D convolutional layers.
2. **Apply Activation**: Use Parametric ReLU (PReLU) for all layers except the final output layer, which uses Sigmoid [S1, unofficial].
3. **Apply Dropout**: During training, apply dropout with probability $p=0.5$ after every convolutional layer, excluding those within residual blocks [S1, unofficial].
4. **Validate Latent Dimensionality**:
   - Test latent space dimensions $d \in \{4, 8, 16, 32, 64\}$ [S2].
   - Modify architecture to produce $64 \times 64$ resolution images by removing last upsampling layers to reduce computational cost [S2].
   - Set loss weight $\lambda = 0$ in the loss function (Equation 9 from [S2]) to remove L1 loss influence, as latent space primarily affects shape, not color [S2].
   - Evaluate on Combustion dataset without illumination [S2].
   - Select dimension that minimizes color image RMSE while maintaining opacity image quality [S2].
5. **Finalize Configuration**: Use the validated dimension (typically 8) for full-resolution training [S2].

### Formulas
- **Loss Function (Modified)**:
  $$ L = L_{adv} + \lambda L_{L1} $$
  Where $\lambda = 0$ during latent dimension validation [S2].
- **Dropout**: Applied with probability $p=0.5$ [S1, unofficial].

### Parameters
- **Activation**: PReLU for hidden layers, Sigmoid for output [S1, unofficial].
- **Dropout Probability**: 0.5 [S1, unofficial].
- **Latent Space Dimensions Tested**: 4, 8, 16, 32, 64 [S2].
- **Optimal Latent Dimension**: 8 [S2].
- **Resolution for Validation**: $64 \times 64$ [S2].
- **Loss Weight ($\lambda$)**: 0 during validation [S2].

### Edge Cases and Pitfalls
- **Overestimating Dimensionality**: Using a latent space dimension larger than necessary (e.g., >8) can result in poorer generalization and makes the TF latent space more difficult to sample [S2].
- **Color vs. Shape**: Latent space dimensionality has minimal impact on opacity image quality but significant impact on color image quality [S2].
- **Computational Burden**: Full-resolution training for all dimensions is computationally expensive; validation uses reduced resolution [S2].

### Pseudocode
```python
def initialize_network():
    # Define layers
    layers = []
    for layer in architecture:
        if layer.type == 'conv':
            # Add convolutional layer
            conv_layer = Conv2d(layer.in_channels, layer.out_channels, layer.kernel_size, layer.stride)
            # Add PReLU activation for all layers except last
            if layer.is_last:
                activation = Sigmoid()
            else:
                activation = PReLU()
            layers.append(ConvBlock(conv_layer, activation))
    return Sequential(layers)

def apply_dropout(network, training=True):
    if training:
        for layer in network.modules():
            if isinstance(layer, Conv2d) and not is_in_residual_block(layer):
                layer.dropout = Dropout(p=0.5)
    return network

def validate_latent_dimension(dataset, dimensions=[4, 8, 16, 32, 64]):
    best_dim = None
    best_rmse = float('inf')
    
    for dim in dimensions:
        # Modify architecture for faster validation
        model = create_model(latent_dim=dim, resolution=(64, 64))
        
        # Train with modified loss (lambda=0)
        for epoch in range(num_epochs):
            for batch in dataset:
                # Forward pass
                output = model(batch)
                # Loss calculation with lambda=0
                loss = adversarial_loss(output, batch) # L1 term excluded
                # Backward pass and update
                optimizer.zero_grad()
                loss.backward()
                optimizer.step()
        
        # Evaluate on Combustion dataset
        rmse = compute_color_rmse(model, dataset)
        if rmse < best_rmse:
            best_rmse = rmse
            best_dim = dim
            
    return best_dim

def is_in_residual_block(layer):
    # Check if layer is part of a residual block
    # Implementation depends on specific architecture definition
    return layer.parent_block_type == 'residual'
```

## Subtopics

### Latent Space Dimensionality Validation
A validation process comparing networks with different latent space dimensionalities (4, 8, 16, 32, 64) to determine the optimal dimension for capturing shape variations. It sets $\lambda=0$ in the loss function to isolate shape impact from color. The optimal dimension found was 8, as higher dimensions lead to poorer generalization and sampling difficulties. Use this when determining the capacity of the latent space for a new dataset. [S2]

### Strengths and Limitations
- **Strengths**: PReLU and Dropout help stabilize training and prevent overfitting. Validating latent dimensionality ensures a balance between detail capture and generalization.
- **Limitations**: High-dimensional latent spaces are difficult to sample and may generalize poorly. Validation requires reduced resolution, which may not fully reflect full-resolution performance.

### When to Use It and When Not
- **Use**: When training deep convolutional networks for differentiable rendering, especially when dealing with 3D shape and color reconstruction.
- **Do Not Use**: When computational resources are extremely limited and latent space validation is not feasible; consider using a fixed, smaller dimension (e.g., 4) with caution.

## Background
Originated in the context of differentiable rendering and neural radiance fields. The activation and dropout settings are based on [S1, unofficial] (RenderNet, 2018). The latent space dimensionality validation is based on [S2] (A Generative Model for Volume Rendering, 2018). These methods are used in volume rendering pipelines that require generative models for shape and color synthesis.
