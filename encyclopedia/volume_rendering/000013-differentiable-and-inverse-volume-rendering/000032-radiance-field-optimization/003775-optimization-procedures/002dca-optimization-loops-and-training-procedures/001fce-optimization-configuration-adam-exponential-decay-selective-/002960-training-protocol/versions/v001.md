# Training Protocol

Also called: Standard Optimization Procedure

## Overview
The Training Protocol defines the standard optimization procedure for neural networks in volume rendering, encompassing optimizer settings, learning rate scheduling, and data augmentation strategies [S1]. It serves as the baseline configuration for training coordinate-based neural representations, ensuring stable convergence and robust generalization [S1]. It differs from the [Gradient Descent Solver](3280-gradient-descent-solver.md) by employing adaptive moment estimation (Adam) with specific hyperparameters and decay schedules, rather than simple stochastic gradient descent [S1].

## How it works
**Inputs:** Neural network parameters (weights and biases), training data (e.g., point clouds, voxel grids, or images), and hyperparameters.
**Outputs:** Optimized neural network parameters.

**Data Structures:**
*   **Optimizer State:** Maintains first and second moment estimates for Adam.
*   **Learning Rate:** Scalar value, initialized to $0.0001$.
*   **Batch:** Single shape/sample per batch (batch size = 1) [S1].

**Parameters:**
*   Adam $\beta_1 = 0.9$ [S1].
*   Adam $\beta_2 = 0.999$ [S1].
*   Initial Learning Rate $\eta = 0.0001$ [S1].
*   Decay Interval: 100 epochs [S1].
*   Gaussian Noise Standard Deviation $\sigma = 0.5$ (for point cloud augmentation) [S1].
*   Loss Functions: Same as UNDC (Unified Neural Dual Contouring) [S1].

**Steps:**
1.  **Initialization:** Initialize network weights randomly. Set learning rate $\eta = 0.0001$.
2.  **Iteration Loop:** For each epoch (up to 400 for SDF/voxel inputs, or 250 for point cloud inputs) [S1]:
    a.  **Data Augmentation:**
        i.  Apply random scaling and translation to input data [S1].
        ii. If input is a point cloud, add Gaussian noise with standard deviation $\sigma = 0.5$ to simulate real scan noise [S1].
    b.  **Forward Pass:** Compute network output (e.g., SDF values, colors, densities) for the batch.
    c.  **Loss Computation:** Calculate loss using the same functions as UNDC [S1].
    d.  **Backward Pass:** Compute gradients with respect to network parameters.
    e.  **Optimization Step:** Update parameters using Adam optimizer with $\beta_1=0.9$, $\beta_2=0.999$, and current learning rate $\eta$ [S1].
3.  **Learning Rate Decay:** Every 100 epochs, halve the learning rate: $\eta \leftarrow \eta / 2$ [S1].
4.  **Termination:** Stop after 400 epochs (SDF/voxel) or 250 epochs (point cloud) [S1].

**Edge Cases and Pitfalls:**
*   **Noisy Real Scans:** For reconstruction from noisy real scans, replace standard 3x3x3 conv3d layers with 8 residual blocks to handle increased complexity and noise [S1].
*   **Precision:** Standard floating-point precision is assumed; no specific bit-packing is mentioned for the optimizer state [S1].

## Subtopics

### Learned Initializations for Neural Fields
A technique to address the inefficiency of optimizing a coordinate-based network from randomly initialized weights for each new signal [S2, unofficial]. It applies standard meta-learning algorithms to learn initial weight parameters based on the underlying class of signals (e.g., images of faces or 3D models of chairs) [S2, unofficial]. These learned initial weights enable faster convergence during optimization and serve as a strong prior over the signal class, resulting in better generalization when only partial observations are available [S2, unofficial].

### Pilot Network for Early Training
A small neural network used during the early training stage to aid the model in finding coarse geometry, preventing convergence failure caused by feature integration of all samples [S3]. The pilot network has two hidden layers, each with 64 neurons [S3]. It is used only in the first 300 training steps. After 300 steps, the pilot network is discarded, and the model switches to the proposed VFR (Volume Feature Rendering) framework for the remaining training steps (e.g., total 20K steps) [S3]. This approach has a negligible effect on overall training time [S3].

### Training Protocol with Augmented Backgrounds and Density Prior
A variant that introduces background augmentation and density regularization to stabilize optimization and refine scene representation [S4].
*   **Background Augmentation:** For the first 25 steps, backgrounds are constant color (random shade of gray) to prevent instability. After step 25, background augmentation (noise pattern or random Fourier feature) is applied for the remainder of optimization [S4].
*   **Density Prior:** Applied only beginning at step 100 to ensure the general scene is well-represented before refining density bias [S4].
*   **Regularization Weights:** The weight for density regularization $\lambda_1$ is set to $2 \cdot 10^{-5}$ [S4]. The weight for color regularization is set to $8 \cdot 10^{-4}$ [S4].

## Operating characteristics
*   **Time Complexity:** Not explicitly given in the sources. The pilot network variant adds negligible time overhead [S3].
*   **Memory Complexity:** Not explicitly given. Standard Adam optimizer memory overhead applies [S1].
*   **Measured Performance:** The protocol is designed for stability and generalization [S1]. The pilot network variant prevents convergence failure in early stages [S3]. The density prior variant improves material representation and reduces transparency artifacts [S4].
*   **Strengths:** Robust to noise (with augmentation), stable convergence (with pilot network and background handling), and generalizes well to partial observations (with learned initializations) [S1][S2, unofficial][S3, S4].
*   **Limitations:** Requires careful tuning of augmentation and regularization weights [S4]. The pilot network adds implementation complexity [S3].
*   **When to Use:** Standard training for neural volume rendering [S1]. Use pilot network if convergence fails early [S3]. Use augmented backgrounds and density prior for semantic or text-based transfer function design [S4]. Use learned initializations for fast adaptation to new signals [S2, unofficial].

## Background
The standard training protocol is based on the Neural Dual Contouring method [S1]. Learned initializations for neural fields were proposed by Mildenhall et al. [S2, unofficial]. The pilot network approach is from Volume Feature Rendering for Fast Neural Radiance Field Reconstruction [S3]. The training protocol with augmented backgrounds and density prior is from Text-based transfer function design for semantic volume rendering [S4].
