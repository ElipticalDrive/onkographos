# L1 Shearlet Regularized CT Reconstruction (ADMM)
Also called: ADMM Shearlet Reconstruction, Bubba et al. Algorithm

## Overview
This method solves the L1 shearlet regularized Computed Tomography (CT) reconstruction problem using the Alternating Direction Method of Multipliers (ADMM) [S1, unofficial]. It is designed to produce high-quality reconstructions from limited-angle or sparse sinogram data by enforcing sparsity in the shearlet domain while maintaining data consistency [S1, unofficial]. It differs from standard Filtered Backprojection (FBP) by incorporating a non-linear prior that preserves edges and reduces artifacts, and it differs from other ADMM solvers by specifically structuring the proximal operators for shearlet sparsity and non-negativity constraints [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Measured sinogram $y$ (vector or batch), Radon forward operator $R$ (limited angles), Shearlet transform $SH$, and hyperparameters $\rho_0, \rho_1$.
*   **Output:** Reconstructed volume $f$ (non-negative).

**Data Structures:**
*   $f$: Current estimate of the volume, shape matches the image grid (e.g., $512 \times 512$).
*   $z_1$: Primal variable for shearlet coefficients, shape matches shearlet coefficient space.
*   $z_2$: Primal variable for the data fidelity constraint, shape matches volume grid.
*   $u_1$: Dual variable (scaled Lagrange multiplier) for shearlet consistency, shape matches shearlet coefficient space.
*   $u_2$: Dual variable for non-negativity/data consistency, shape matches volume grid.
*   $w$: Weights for the L1 norm, calculated based on shearlet scales.

**Parameters:**
*   $\rho_0$: Scaling factor for the data fidelity term. Typical value: $0.02$ [S1, unofficial].
*   $\rho_1$: Scaling factor for the shearlet regularization term. Typical value: $0.1$ [S1, unofficial].
*   $n_{scales}$: Number of shearlet scales. Typical value: $5$ [S1, unofficial].
*   $w_i = 3^{s_i} / 400$, where $s_i$ is the scale index [S1, unofficial].

**Algorithm Steps:**
1.  **Initialization:** Initialize all primal and dual variables to zero:
    $$ u_2 \leftarrow 0, \quad z_2 \leftarrow 0, \quad u_1 \leftarrow 0, \quad z_1 \leftarrow 0, \quad f \leftarrow 0 $$
    [S1, unofficial]

2.  **Iteration Loop:** For `num_iterations`:
    a.  **Compute CG RHS:** Calculate the right-hand side for the conjugate gradient solver:
        $$ cg\_y = \rho_0 \cdot bp + \rho_1 \cdot SH^T(z_1 - u_1) + (z_2 - u_2) $$
        where $bp$ is the backprojected sinogram ($R^T y$) [S1, unofficial].
    b.  **Solve for $f$:** Solve the linear system for $f$ using Conjugate Gradient Least Squares (CGLS):
        $$ f \leftarrow \text{CGLS}\left( x \mapsto \rho_0 R^T R x + (1 + \rho_1) x, \quad f_{old}, \quad cg\_y, \quad \text{max\_iter}=50 \right) $$
        [S1, unofficial]
    c.  **Shearlet Transform:** Compute the shearlet transform of the current estimate:
        $$ sh\_f \leftarrow SH(f) $$
        [S1, unofficial]
    d.  **Update $z_1$:** Apply soft-thresholding (shrinkage) to enforce L1 sparsity:
        $$ z_1 \leftarrow \text{shrink}(sh\_f + u_1, \frac{\rho_0}{\rho_1} w) $$
        [S1, unofficial]
    e.  **Update $z_2$:** Enforce non-negativity constraint:
        $$ z_2 \leftarrow \max(0, f + u_2) $$
        [S1, unofficial]
    f.  **Update Dual Variables:**
        $$ u_1 \leftarrow u_1 + sh\_f - z_1 $$
        $$ u_2 \leftarrow u_2 + f - z_2 $$
        [S1, unofficial]

**Shrinkage Function:**
The soft-thresholding operator is defined as:
$$ \text{shrink}(a, b) = \max(|a| - b, 0) \cdot \text{sign}(a) $$
[S1, unofficial]

**Pseudocode:**
```python
def l1_shearlet_admm(sinogram, radon, shearlet, num_iterations=100, rho0=0.02, rho1=0.1, n_scales=5):
    # Initialize variables
    bp = radon.backward(sinogram)
    sc_shape = shearlet.forward(torch.zeros_like(bp)).shape
    u2 = torch.zeros_like(bp)
    z2 = torch.zeros_like(bp)
    u1 = torch.zeros_like(sc_shape)
    z1 = torch.zeros_like(sc_shape)
    f = torch.zeros_like(bp)
    
    # Compute weights
    # Assuming shearlet.scales provides a list/array of scale indices or values
    # Formula: w = 3**shearlet.scales / 400
    # Reshape w to broadcast correctly over shearlet coefficients
    w = (3 ** shearlet.scales / 400).view(1, -1, 1, 1) 
    
    for i in range(num_iterations):
        # 1. Compute CG RHS
        # shearlet.backward(z1 - u1) computes the adjoint shearlet transform
        cg_y = rho0 * bp + rho1 * shearlet.backward(z1 - u1) + (z2 - u2)
        
        # 2. Solve linear system for f using CGLS
        # The operator is: A(x) = rho0 * radon.backward(radon.forward(x)) + (1 + rho1) * x
        def linear_op(x):
            return rho0 * radon.backward(radon.forward(x)) + (1 + rho1) * x
        
        f = cg(linear_op, f.clone(), cg_y, max_iter=50)
        
        # 3. Compute shearlet transform of f
        sh_f = shearlet.forward(f)
        
        # 4. Update z1 using shrinkage
        threshold = (rho0 / rho1) * w
        z1 = shrink(sh_f + u1, threshold)
        
        # 5. Update z2 by clamping minimum 0
        z2 = torch.clamp(f + u2, min=0)
        
        # 6. Update dual variables
        u1 = u1 + sh_f - z1
        u2 = u2 + f - z2
        
    return f

def shrink(a, b):
    return torch.clamp(torch.abs(a) - b, min=0) * torch.sign(a)
```

## Operating characteristics
*   **Time Complexity:** Dominated by the Radon forward/backward projections and Shearlet transforms within each iteration, plus the CGLS solver. The CGLS solver is limited to 50 iterations per step [S1, unofficial].
*   **Memory Complexity:** Requires storage for $f, z_1, z_2, u_1, u_2$ and intermediate shearlet coefficients. All operations are performed on GPU, avoiding CPU-GPU memory copies in the main loop [S1, unofficial].
*   **Performance:** On a Tesla V100 GPU, the implementation runs in 1.6 seconds per image, compared to 2.5 minutes on an Intel i7 CPU in the original paper, representing a 125x speedup [S1, unofficial]. With batch processing, the average time is 1.2 seconds per image [S1, unofficial].
*   **Strengths:** High-quality reconstruction for limited-angle tomography; significant speedup via GPU implementation; supports batch processing [S1, unofficial].
*   **Limitations:** Requires careful tuning of $\rho_0$ and $\rho_1$; convergence depends on the number of iterations; limited to problems where shearlet sparsity is a valid prior [S1, unofficial].

## Background
The method is based on the work by Bubba et al. [4], who proposed using L1 shearlet regularization for CT reconstruction, particularly in limited-angle scenarios [S1, unofficial]. The implementation described in [S1, unofficial] adapts this method using TorchRadon for differentiable Radon transforms and PyTorch for the ADMM solver, achieving significant performance improvements over the original CPU-based implementation [S1, unofficial].
