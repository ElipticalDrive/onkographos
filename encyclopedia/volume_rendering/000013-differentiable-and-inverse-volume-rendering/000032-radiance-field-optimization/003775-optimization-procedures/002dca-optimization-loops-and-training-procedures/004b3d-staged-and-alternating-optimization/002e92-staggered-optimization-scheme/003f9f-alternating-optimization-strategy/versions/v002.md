# Alternating Optimization Strategy
Also called: Block Coordinate Descent (BCD) inspired strategy

## Overview
The Alternating Optimization Strategy mitigates optimization instability caused by the highly coupled influence of base geometric attributes (rotation and scaling) and skewness parameters on a primitive's spatial footprint [S1, unofficial]. It partitions shape-related parameters into two disjoint groups and optimizes them alternately, decoupling the update process to prevent degenerate primitive shapes [S1, unofficial]. Unlike joint optimization where all parameters are updated simultaneously, this method stabilizes gradient descent by freezing one group while optimizing the other [S1, unofficial].

## How it works
**Inputs and Outputs**
- **Inputs**: Current iteration step $t$, warm-up threshold $T_{start}$, cycle length $C$, base phase duration $C_{base}$, base shape parameters $\Theta_{base}$, skewness parameters $\Theta_{skew}$, and an optimizer (e.g., Adam or SGHMC) [S1, unofficial].
- **Outputs**: Updated parameters $\Theta_{base}$ and $\Theta_{skew}$ [S1, unofficial].

**Data Structures**
- $\Theta_{base}$: Set of base shape parameters, defined as $\{R, S\}$, representing Rotation and Scaling [S1, unofficial].
- $\Theta_{skew}$: Set of skewness parameters, defined as $\{d_k, m_k\}$ [S1, unofficial].

**Parameters**
- $T_{start}$: Warm-up threshold iteration. Before this iteration, all parameters are optimized jointly [S1, unofficial].
- $C$: Cycle length for the alternating optimization phase [S1, unofficial].
- $C_{base}$: Base phase duration. The number of steps within a cycle where base shape parameters are optimized while skewness is frozen [S1, unofficial].

**Algorithm Steps**
1. Compute loss $L$ and initial gradients for all parameters [S1, unofficial].
2. If $t > T_{start}$, enter the alternating phase:
   a. Calculate $stepcycle = t \pmod C$ [S1, unofficial].
   b. If $stepcycle < C_{base}$:
      i. Freeze $\Theta_{skew}$ (e.g., zero gradients and learning rate) [S1, unofficial].
      ii. Unfreeze $\Theta_{base}$ [S1, unofficial].
   c. Else ($stepcycle \ge C_{base}$):
      i. Freeze $\Theta_{base}$ (e.g., zero gradients and learning rate) [S1, unofficial].
      ii. Unfreeze $\Theta_{skew}$ [S1, unofficial].
3. Else ($t \le T_{start}$):
   a. Unfreeze all $\Theta_{base}$ and $\Theta_{skew}$ for joint optimization during the warm-up phase [S1, unofficial].
4. Apply the optimizer step to update only the unfrozen parameters [S1, unofficial].

**Pseudocode**
```python
def alternating_optimization_step(t, Tstart, C, Cbase, Theta_base, Theta_skew, optimizer):
    # 1. Compute loss L and initial gradients for all parameters
    loss = compute_loss(Theta_base, Theta_skew)
    gradients = compute_gradients(loss, Theta_base, Theta_skew)

    # 2. Determine which parameters to update based on iteration t
    if t > Tstart:
        stepcycle = t % C
        if stepcycle < Cbase:
            # Base Phase: Optimize base shape, freeze skewness
            gradients['Theta_skew'] = zero_like(gradients['Theta_skew'])
        else:
            # Skew Phase: Optimize skewness, freeze base shape
            gradients['Theta_base'] = zero_like(gradients['Theta_base'])
    else:
        # Warm-up Phase: Joint Optimization
        # All parameters remain unfrozen; gradients are used as computed
        pass

    # 3. Apply optimizer step to update only the unfrozen parameters
    optimizer.step(Theta_base, Theta_skew, gradients)
```

**Edge Cases and Pitfalls**
- **Optimization Instability**: Jointly optimizing base geometric attributes with skewness parameters can lead to instability due to their highly coupled influence on the primitive's spatial footprint [S1, unofficial]. This is mitigated by the alternating strategy [S1, unofficial].
- **Degenerate Shapes**: Without decoupling, the optimization may result in degenerate primitive shapes [S1, unofficial].

In ablation studies (Table 4 in [S1, unofficial]), the Full SNS (including k-decomposition and Alternating Optimization) generally outperforms ablated versions. For example, on the "Playroom Blending Deep" scene, the Full SNS achieved a PSNR of 30.7130, compared to 30.6745 for a version without the full combination [S1, unofficial]. On average across datasets, the Full SNS achieved a PSNR of 30.3034, compared to 30.2969 for a baseline without the full combination [S1, unofficial].

**Strengths and Limitations**
- **Strengths**: Stabilizes gradient descent by decoupling highly coupled parameters [S1, unofficial]. Prevents degenerate primitive shapes [S1, unofficial].
- **Limitations**: Introduces complexity in managing parameter freezing/unfreezing [S1, unofficial]. Requires careful tuning of $T_{start}$, $C$, and $C_{base}$ [S1, unofficial].

**When to Use**
Use when optimizing primitive shape parameters that exhibit strong coupling between base geometric attributes and skewness, leading to instability in joint optimization [S1, unofficial].

## Background
The Alternating Optimization Strategy is inspired by Block Coordinate Descent (BCD) [S1, unofficial]. It was introduced in the context of 3D Skew-Normal Splatting (SNS) to address optimization instability in primitive shape parameters [S1, unofficial]. The method is part of the SNS model, which includes k-decomposition and this optimization strategy [S1, unofficial].
