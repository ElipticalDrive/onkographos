# Staggered Optimization Scheme

Also called: Alternating Optimization, Staggered Shape and PSF Optimization, deltaMic optimization strategy

## Overview
The Staggered Optimization Scheme decomposes the coupled optimization of geometric shape and Point Spread Function (PSF) parameters into two sequential sub-problems to manage computational cost and avoid bias [S1, unofficial]. Unlike joint optimization where all parameters are updated simultaneously, this method stabilizes gradient descent by freezing one group while optimizing the other, specifically addressing the instability caused by the highly coupled influence of base geometric attributes and skewness parameters on a primitive's spatial footprint [S1, unofficial]. It is primarily used in differentiable volume rendering for 3D fluorescence microscopy to infer cell shapes from single-view or dual-view light-sheet and point-scanning confocal images [S1, unofficial].

## How it works
The method operates on nonmanifold multimaterial meshes with 1000–10000 vertices [S1, unofficial]. The optimization alternates between shape updates (vertex positions) and PSF updates (covariance matrix), iterating until convergence.

### Inputs and Outputs
*   **Inputs:**
    *   Ground truth image $I_{GT}$.
    *   Initial mesh: A foam-like multimaterial mesh with the correct number of cells [S1, unofficial].
    *   PSF parameters: Initial covariance matrix $\Sigma$ [S1, unofficial].
    *   Hyperparameters: Learning rate $\eta$, regularization weight $\lambda = 50$, number of iterations (e.g., 10,000 for artificial benchmarks, 1k–10k for embryo data) [S1, unofficial].
*   **Outputs:**
    *   Optimized vertex positions $v$.
    *   Optimized PSF covariance matrix $\Sigma$.

### Data Structures
*   **Mesh:** Nonmanifold multimaterial mesh.
    *   Vertices $v \in \mathbb{R}^{n_v \times 3}$.
    *   Laplacian matrix $L \in \mathbb{R}^{n_v \times n_v}$ [S1, unofficial].
*   **PSF:** Covariance matrix $\Sigma$ [S1, unofficial].
*   **Images:** $I$ (rendered), $I_{GT}$ (ground truth) [S1, unofficial].

### Algorithm Steps

1.  **Initialization:** Generate an initial foam-like multimaterial mesh with the correct number of cells [S1, unofficial]. Initialize PSF parameters $\Sigma$.

2.  **Iteration Loop:** Repeat for the specified number of iterations:

    **Step A: Shape Optimization**
    1.  Compute the rendered image $I$ using the current mesh vertices $v$ and fixed PSF $\Sigma$.
    2.  Compute the gradient of the shape loss $\frac{\partial L}{\partial v}$ using the narrow-band approximation for the mesh Fourier Transform (FT) to save computational time [S1, unofficial].
    3.  Solve the linear system for the update direction $A$:
        $$ (1 + \lambda L)^{-2} A = \frac{\partial L}{\partial v} $$
        This is solved using GPU-parallelized sparse Cholesky decomposition to avoid explicit memory-intensive inversion for large $n_v$ [S1, unofficial].
    4.  Update vertex positions:
        $$ v \leftarrow v - \eta A $$
        The optimizer used is AdamUniform [S1, unofficial].

    **Step B: PSF Optimization**
    1.  Compute the rendered image $I$ using the fixed mesh vertices $v$ and current PSF $\Sigma$.
    2.  Compute the gradient of the PSF loss $L_0$ using the **exact** mesh FT across all available frequencies. This avoids bias from the narrow-band threshold, which depends on the current PSF values [S1, unofficial].
    3.  Update PSF parameters $\Sigma$ using the Adam optimizer [S1, unofficial].

3.  **Termination:** Stop when convergence criteria are met or the maximum number of iterations is reached.

### Loss Functions

**Shape Loss ($L$):**
$$ L = \frac{\langle I - I_{GT}, I - I_{GT} \rangle}{\langle I_{GT}, I_{GT} \rangle} = \frac{\frac{1}{N} \text{tr}((I - I_{GT})^2)}{\frac{1}{N} \text{tr}(I_{GT})} $$
Where $\langle \cdot, \cdot \rangle$ denotes the Frobenius inner product average. This formulation downweights dark regions in $I_{GT}$ to focus optimization on informative signal [S1, unofficial].

**PSF Loss ($L_0$):**
$$ L_0 = ||I - I_{GT}||_2 $$
A regular L2 norm minimization suitable for reconstructing both bright and dark regions [S1, unofficial].

### Pseudocode

```python
def staggered_optimization(mesh, I_GT, num_iterations, eta, lambda_reg):
    """
    Staggered optimization of mesh shape and PSF parameters.
    
    Args:
        mesh: Nonmanifold multimaterial mesh object with vertices v and Laplacian L.
        I_GT: Ground truth image tensor.
        num_iterations: Total number of optimization steps.
        eta: Learning rate for shape optimization.
        lambda_reg: Regularization weight (default 50).
        
    Returns:
        mesh: Optimized mesh.
        Sigma: Optimized PSF covariance matrix.
    """
    # Initialize PSF covariance matrix Sigma
    Sigma = initialize_PSF()
    
    # Precompute mesh Laplacian L if not already available
    L = compute_mesh_laplacian(mesh.v)
    
    for i in range(num_iterations):
        # --- Step A: Shape Optimization ---
        
        # 1. Render image with current mesh and fixed PSF
        I = render_mesh(mesh.v, Sigma, use_narrow_band=True)
        
        # 2. Compute Shape Loss
        # L = trace((I - I_GT)^2) / trace(I_GT^2)
        numerator = sum((I - I_GT) ** 2)
        denominator = sum(I_GT ** 2)
        loss_shape = numerator / denominator
        
        # 3. Compute gradient of loss w.r.t vertices using narrow-band FT
        # Note: Narrow-band is used here for speed in backward pass
        grad_L_v = compute_gradient_narrow_band(mesh, Sigma, I, I_GT)
        
        # 4. Solve linear system: (1 + lambda * L)^-2 * A = grad_L_v
        # Using GPU-parallelized sparse Cholesky decomposition
        # Let M = (1 + lambda * L)
        # Solve M * M * A = grad_L_v
        M = identity_matrix(mesh.n_v) + lambda_reg * L
        # Solve M * x = grad_L_v for x
        x = sparse_cholesky_solve(M, grad_L_v)
        # Solve M * A = x for A
        A = sparse_cholesky_solve(M, x)
        
        # 5. Update vertices
        mesh.v = mesh.v - eta * A
        
        # --- Step B: PSF Optimization ---
        
        # 1. Render image with fixed mesh and current PSF
        # Use EXACT FT to avoid bias from narrow-band threshold
        I = render_mesh(mesh.v, Sigma, use_narrow_band=False)
        
        # 2. Compute PSF Loss (L2 norm)
        loss_psf = sum((I - I_GT) ** 2)
        
        # 3. Compute gradient of loss w.r.t Sigma
        grad_L_Sigma = compute_gradient_exact(mesh, Sigma, I, I_GT)
        
        # 4. Update Sigma using Adam optimizer
        Sigma = adam_update(Sigma, grad_L_Sigma)
        
    return mesh, Sigma
```

### Edge Cases and Pitfalls
*   **Computational Cost:** The forward pass is approximately 10 times slower than the backward pass. The narrow-band method is applied in the backward computation whenever possible to save time [S1, unofficial].
*   **Bias:** Using the narrow-band method for PSF optimization introduces bias because the threshold depends on current PSF values. Therefore, the exact FT must be used for PSF optimization [S1, unofficial].
*   **Memory:** Explicit inversion of $(1 + \lambda L)^{-2}$ is memory-intensive for large vertex counts $n_v$. The linear system must be solved via sparse Cholesky decomposition [S1, unofficial].
*   **Remeshing:** The method uses a multimaterial mesh-based surface tracking method to handle remeshing, collision detection, and topological transitions [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The method is computationally expensive due to the Fourier Transform (FT) computations. The forward pass is ~10x slower than the backward pass [S1, unofficial].
*   **Memory Complexity:** Solving the linear system requires sparse matrix storage. Explicit inversion is avoided to prevent memory issues for large $n_v$ [S1, unofficial].
*   **Performance:**
    *   **Artificial Benchmarks:** Converges to original shapes (sphere/torus) within 10,000 iterations [S1, unofficial].
    *   **Robustness (Zoom):** MSE for Spot reference mesh (400 iterations): Zoom 0.9: 0.0042; 1.0: 0.0048; 1.1: 0.0045; 1.2: 0.0055; 1.5: 0.0084 [S1, unofficial].
    *   **Robustness (Shift):** MSE for Spot reference mesh (400 iterations): Shift 0: 0.0048; 0.1: 0.0059; 0.2: 0.0039; 0.3: 0.0070; 0.5: 0.0072 [S1, unofficial].
    *   **Robustness (Noise):** MSE for Spot reference mesh (400 iterations): Noise 0: $6.58 \times 10^{-3}$; 0.001: $6.58 \times 10^{-3}$; 0.01: $8.98 \times 10^{-3}$; 0.02: $1.50 \times 10^{-2}$; 0.03: $2.07 \times 10^{-2}$; 0.05: $4.22 \times 10^{-2}$; 0.1: $9.66 \times 10^{-2}$ [S1, unofficial].
    *   **Comparison:** Outperforms DM3D on 15 mouse organoid 3D images across MSE, SSIM, and PSNR metrics [S1, unofficial].
*   **Strengths:** Stabilizes optimization by decoupling shape and PSF updates; robust to noise and initial condition variations; handles topological transitions via multimaterial meshes.
*   **Limitations:** Computationally intensive; requires careful handling of narrow-band vs. exact FT to balance speed and bias.

## Background
The Staggered Optimization Scheme is part of the deltaMic pipeline, which uses differentiable rendering for 3D fluorescence microscopy [S1, unofficial]. It was developed to address the computational bottlenecks and optimization instability inherent in jointly optimizing mesh geometry and PSF parameters. The method was applied to infer cell shapes in early-stage embryos (mouse, ascidian, worm) from 3D fluorescence microscopy images acquired with single-view light-sheet, dual-view light-sheet, and point-scanning confocal microscopes [S1, unofficial].
