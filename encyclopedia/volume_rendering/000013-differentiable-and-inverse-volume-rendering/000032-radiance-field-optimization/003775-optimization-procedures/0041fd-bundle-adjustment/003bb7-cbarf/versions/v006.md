# CBARF
Also called: CBARF (Cascaded Bundle-Adjusting Neural Radiance Fields), Cascaded BA

## Overview
CBARF is a 3D reconstruction model that optimizes imperfect camera poses using a cascaded bundle-adjustment (BA) structure to progressively refine poses and rectify erroneous ones [S1]. It builds on [BARF (Bundle-Adjusting Neural Radiance Fields)](6872-barf-bundle-adjusting-neural-radiance-fields.md) by introducing a coarse-to-fine optimization strategy with distinct stages, allowing it to handle larger initial pose errors (e.g., 30.4° rotation deviation) where BARF typically overfits [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of images with imperfect camera poses $\hat{P}$, initial NeRF weights $\Theta$, and a learning rate schedule.
*   **Outputs:** Refined camera poses $Q$ and optimized NeRF weights $\Theta$.

**Data Structures:**
*   **Camera Pose:** Represented as $P \in \mathbb{R}^{3 \times 4}$, defined as $P = [R_p \ t_p]$ where $R_p \in SO(3)$ and $t_p \in \mathbb{R}^3$ [S1]. The last row of the standard $4 \times 4$ transformation matrix is dropped [S1].
*   **Lie Algebra Perturbation:** Noise and refinement parameters are represented as $n, p \in \mathbb{R}^6$ from the Lie algebra $se(3)$ [S1].

**Numbered Steps:**

1.  **Initialization:**
    *   Initialize NeRF weights $\Theta$ (following BARF settings) [S1].
    *   Generate imperfect initial poses $\hat{P}$ by adding noise to reference poses $P$. The noise $n$ is drawn from a 6-dimensional normal distribution: $n = 0.35\mathcal{N}(0, I) \in \mathbb{R}^6$ [S1]. This corresponds to an average deviation of 30.4° in rotation and 0.56 in translation [S1].
    *   Transform noise $n$ into a camera transform matrix $N = [R_n \ t_n]$ [S1].
    *   Compose noise with reference pose $P$ to get imperfect poses: $\hat{P} = [R_p \ R_n \ t_p + t_n]$ [S1].

2.  **Cascaded Optimization Stages:**
    CBARF employs a coarse-to-fine structure with compact BA modules, using BARF as the backbone for each stage [S1]. The process consists of three stages: Coarse, Recursive, and Fine [S1].

    *   **Stage 1: Coarse Stage**
        *   Optimize camera refine parameters $p \in se(3)$ [S1].
        *   Convert $p$ to a transform matrix $P_r = [R_r \ t_r]$ [S1].
        *   Compose $P_r$ with $\hat{P}$ to obtain refined poses $Q$: $Q = [R_p \ R_n \ R_r \ t_p + t_n + t_r]$ [S1].
        *   Run for 20k iterations [S1].
        *   Modulation factor for learning rate: 10.0 [S1].

    *   **Stage 2: Recursive Stage**
        *   Use the refined poses $Q$ from Stage 1 as the new base.
        *   Optimize new refine parameters $p \in se(3)$.
        *   Compose to update poses.
        *   Run for 20k iterations [S1].
        *   Modulation factor for learning rate: 3.0 [S1].

    *   **Stage 3: Fine Stage**
        *   Use the refined poses from Stage 2 as the new base.
        *   Optimize new refine parameters $p \in se(3)$.
        *   Compose to update poses.
        *   Run for 200k iterations [S1].
        *   Modulation factor for learning rate: 1.0 [S1].

3.  **Learning Rate Schedule:**
    *   Use exponential interpolation to calculate a gradually decreasing learning rate [S1].
    *   Introduce a modulation factor $\alpha$ to bias the learning rate towards the initial high value. A larger $\alpha$ keeps the learning rate higher for longer [S1].
    *   The modulation factor $\alpha$ is set to 10.0, 3.0, and 1.0 for the coarse, recursive, and fine stages, respectively [S1].

4.  **Incomplete Poses Handling (Optional):**
    *   If camera poses are incomplete, randomly drop 10% of poses to form a test set $F$ [S1].
    *   Assign an initial pose $P_{ini}$ to images in $F$ [S1].
    *   Jointly optimize poses for both the training set $T$ and test set $F$ during training [S1].

5.  **Evaluation Alignment:**
    *   Use Procrustes analysis to align optimized poses with ground-truth before evaluation to remove global offset [S1].

**Parameters:**
*   **Noise Coefficient:** 0.35 for CBARF (vs 0.15 in BARF) [S1].
*   **Iterations:** 20k for Coarse and Recursive stages; 200k for Fine stage [S1].
*   **Image Resolution:** 400x400 (half of 800x800 training resolution) [S1].
*   **Modulation Factors:** 10.0 (Coarse), 3.0 (Recursive), 1.0 (Fine) [S1].

**Edge Cases and Pitfalls:**
*   **Overfitting:** BARF may overfit before completing optimization with large initial errors; CBARF mitigates this via cascaded stages [S1].
*   **Coordinate Misalignment:** Optimized poses may have a global offset relative to ground truth. Procrustes analysis is required for evaluation [S1].
*   **Incomplete Poses:** If 10% of poses are missing, they are assigned an initial pose and jointly optimized [S1].

## Operating characteristics
*   **Time Complexity:** The cascaded structure increases total training time compared to single-stage BA. The fine stage dominates with 200k iterations [S1].
*   **Memory Complexity:** Similar to BARF, as it uses the same backbone and resolution (400x400) [S1].
*   **Strengths:** Handles large initial pose errors (30.4° rotation deviation) effectively; rectifies erroneous poses that BARF cannot [S1].
*   **Limitations:** Requires careful tuning of modulation factors and iteration counts per stage; more complex to implement than single-stage BA [S1].
*   **When to use:** When camera poses are significantly inaccurate or when BARF fails to converge due to large initial errors [S1].
*   **When not to use:** When poses are already accurate (BARF is sufficient and faster) [S1].

## Background
CBARF was proposed in 2024 by authors publishing in the IEEE Transactions on Multimedia [S1]. It extends the BARF method [S1] to address the limitation of BARF in handling large initial pose errors. The method was developed to improve 3D reconstruction quality from imperfect camera poses, demonstrating superiority in both pose optimization and view synthesis [S1].
