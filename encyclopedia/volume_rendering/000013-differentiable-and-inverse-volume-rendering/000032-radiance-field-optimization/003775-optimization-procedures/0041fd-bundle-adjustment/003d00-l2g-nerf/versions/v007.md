# L2G-NeRF

Also called: Local-to-Global Registration for Bundle-Adjusting Neural Radiance Fields

## Overview
L2G-NeRF is a bundle-adjusting method that jointly optimizes neural 3D representations and camera poses by combining a local photometric alignment objective with a global geometric alignment objective [S1]. It solves the problem of suboptimal solutions caused by poor initialization in parametric methods and the inability to handle large displacements in non-parametric methods [S1]. It sets itself apart from siblings like [BARF](6872-barf-bundle-adjusting-neural-radiance-fields.md) by computing gradients with respect to local pixel-wise poses rather than global poses, allowing it to tolerate larger noise perturbations before divergence [S1].

## How it works
**Inputs:** A set of $M$ images $\{I_i\}_{i=1}^M$ with unknown camera poses.
**Outputs:** Neural field parameters $\Theta$, camera poses $\{T_i\}_{i=1}^M$, and local transformation fields.

**Data Structures:**
1.  **Neural Field MLP ($f_R$):**
    *   Input: 3D coordinate $x \in \mathbb{R}^3$ (or 2D for 2D alignment).
    *   Output: 4D vector $[c; \sigma] \in \mathbb{R}^4$ (RGB color $c$ and volume density $\sigma$) for 3D NeRF, or 3D vector for 2D images [S1].
    *   Parameters: $\Theta$ [S1].
2.  **Warp Neural Field MLP ($f_W$):**
    *   Input: 2D coordinate $x \in \mathbb{R}^2$ and frame-dependent embedding $\ell_i \in \mathbb{R}^d$.
    *   Output: Lie algebra vector (se(2) or sl(3)) [S1].
    *   Parameters: $\Phi$ [S1].
3.  **Camera Pose:** $T_i = [R_i | t_i] \in SE(3)$, where $R_i = \exp(r_i)$ via exponential map from $\mathfrak{so}(3)$ to $SO(3)$, and $t_i \in \mathbb{R}^3$ [S1].
4.  **Local Transformation:** $T_{ji} = W(x_j; \ell_i, \Phi)$, where $W(x; \ell, \Phi) = \exp(f_W(x; \ell, \Phi))$ [S1].

**Parameters:**
*   $\lambda$: Weighting factor for the global constraint term. Set to $1 \times 10^2$ for synthetic/object-centric scenes; floated between $1 \times 10^2$ and $1 \times 10^5$ for forward-facing LLFF scenes [S1].
*   $n_r$: Base rotation noise multiplier. Scene-dependent values range from 0.01 to 0.09 [S1].
*   $n_t$: Base translation noise multiplier. Scene-dependent values range from 0.3 to 0.7 [S1].
*   $K$: Number of points sampled along a ray for discretizing the volume rendering integral [S1].

**Steps:**

1.  **Initialization:** Initialize all camera poses to identity transformation $T_i = I \forall i$ [S1]. Perturb initial poses using right multiplication to alter viewing directions and distances [S1]. Initialize $\Theta$ and $\Phi$ [S1].

2.  **Local Alignment (Non-parametric):**
    *   For each image $i$ and pixel $j$ with coordinate $x_j$, predict a local transformation $T_{ji}$ using the warp neural field: $T_{ji} = \exp(f_W(x_j; \ell_i, \Phi))$ [S1].
    *   Render the image using the local transformation: $R(T_{ji} x_j; \Theta)$ [S1].
    *   Compute the local photometric loss: $\mathcal{L}_{local} = \sum_{i=1}^M \sum_{j=1}^N \| R(T_{ji} x_j; \Theta) - I_i(x_j) \|^2$ [S1].

3.  **Global Alignment (Parametric):**
    *   For each image $i$, solve for the global transformation $T^*_i$ that best aligns the local transformations $T_{ji}$ to a rigid frame-wise transformation. This is an orthogonal Procrustes problem:
        $$ T^*_i = \arg \min_{T_i} \sum_{j=1}^N \| T_{ji} x_j - T_i x_j \|^2 $$
    *   The closed-form solution is derived via SVD of the covariance matrix $H = \sum_{j=1}^N (x_j - \bar{x})(T_{ji} x_j - T^*_i \bar{x})^T = U S V^T$ [S1].
    *   The optimal rotation is $R^*_i = V U^T$ and translation is $t^*_i = -R^*_i \bar{x} + \overline{T^*_i x}$, where $\bar{x}$ is the centroid of $x_j$ [S1].
    *   Compute the global geometric loss: $\mathcal{L}_{global} = \lambda \sum_{i=1}^M \sum_{j=1}^N \| T_{ji} x_j - T^*_i x_j \|^2$ [S1].

4.  **Joint Optimization:**
    *   Minimize the combined objective:
        $$ \min_{\{T_{ji}\}, \Theta} \sum_{i=1}^M \sum_{j=1}^N \| R(T_{ji} x_j; \Theta) - I_i(x_j) \|^2 + \lambda \| T_{ji} x_j - T^*_i x_j \|^2 $$
    *   Gradients flow from $\mathcal{L}_{global}$ to $T_{ji}$ via the differentiable Procrustes solver, and from $\mathcal{L}_{local}$ to $\Theta$ and $T_{ji}$ via backpropagation through the rendering integral [S1].
    *   Update $\Theta$, $\Phi$, and $\ell_i$ using an optimizer (e.g., Adam) [S1].

5.  **Convergence Schedule:**
    *   Linearly increase noise multipliers $n_r$ and $n_t$ by a common factor $\{n_c\}_{c=2}^9$ starting from base values $n_r=0.01, n_t=0.1$ [S1].

**Pseudocode:**

```python
import numpy as np
import torch
import torch.nn as nn
import torch.optim as optim

class WarpNeuralField(nn.Module):
    """Warp neural field f_W: R^2 x R^d -> R^k (Lie algebra)"""
    def __init__(self, dim_in, dim_embed, dim_out):
        super().__init__()
        self.mlp = nn.Sequential(
            nn.Linear(dim_in + dim_embed, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, dim_out)
        )
    
    def forward(self, x, embed):
        # x: (N, 2), embed: (N, d)
        input = torch.cat([x, embed], dim=-1)
        return self.mlp(input)

class NeRF(nn.Module):
    """Neural field f_R: R^3 -> R^4 (color, density)"""
    def __init__(self, dim_in, hidden_dim=256):
        super().__init__()
        self.mlp = nn.Sequential(
            nn.Linear(dim_in, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 4) # RGB + sigma
        )
    
    def forward(self, x):
        return self.mlp(x)

def exp_so3(r):
    """Exponential map from so(3) to SO(3)"""
    # r: (3,)
    theta = torch.norm(r)
    if theta < 1e-8:
        return torch.eye(3)
    r_hat = skew_symmetric(r / theta)
    return torch.eye(3) + torch.sin(theta) * r_hat + (1 - torch.cos(theta)) * r_hat @ r_hat

def skew_symmetric(v):
    return torch.tensor([[0, -v[2], v[1]],
                         [v[2], 0, -v[0]],
                         [-v[1], v[0], 0]])

def solve_procrustes(points_src, points_dst):
    """
    Solve orthogonal Procrustes problem: min || T * src - dst ||^2
    Returns R, t such that dst ~ R * src + t
    """
    # points_src: (N, 3), points_dst: (N, 3)
    mean_src = points_src.mean(dim=0)
    mean_dst = points_dst.mean(dim=0)
    
    # Center points
    src_centered = points_src - mean_src
    dst_centered = points_dst - mean_dst
    
    # Covariance matrix H
    H = src_centered.T @ dst_centered
    
    # SVD
    U, S, Vt = torch.linalg.svd(H)
    V = Vt.T
    
    # Rotation
    R = V @ U.T
    
    # Check for reflection
    if torch.det(R) < 0:
        V[:, -1] *= -1
        R = V @ U.T
        
    # Translation
    t = mean_dst - R @ mean_src
    
    return R, t

def volume_rendering(ray_origins, ray_directions, nerf_model, K=128):
    """
    Standard NeRF volume rendering
    """
    # Sample points along ray
    t_vals = torch.linspace(0, 1, K)
    z_vals = 0.1 * t_vals + 0.9 * t_vals * 2 # Near and far bounds example
    points = ray_origins.unsqueeze(1) + ray_directions.unsqueeze(1) * z_vals.unsqueeze(0).unsqueeze(-1)
    
    # Query NeRF
    raw = nerf_model(points.reshape(-1, 3)).reshape(points.shape[0], K, 4)
    rgb = raw[..., :3]
    sigma = raw[..., 3:]
    
    # Compute weights
    deltas = z_vals[1:] - z_vals[:-1]
    alpha = 1 - torch.exp(-torch.relu(sigma) * deltas)
    T = torch.cumprod(1 - alpha + 1e-10, dim=-1)
    weights = alpha * T
    
    # Composite
    rgb_final = (weights.unsqueeze(-1) * rgb).sum(dim=-1)
    return rgb_final

def main():
    # Hyperparameters
    M = 10 # Number of images
    N = 1000 # Number of pixels sampled per image
    dim_embed = 16
    lambda_global = 1e2
    
    # Initialize models
    nerf = NeRF(3)
    warp_field = WarpNeuralField(2, dim_embed, 6) # se(3) dim is 6, but for 2D alignment it might be se(2) or sl(3)
    # Note: For 3D NeRF, local transformations T_ji are applied to 3D points.
    # The paper describes T_ji = W(x_j; l_i, Phi) where W outputs Lie algebra.
    # For 3D, this is likely se(3).
    
    # Initialize embeddings and poses
    embeddings = nn.Parameter(torch.randn(M, dim_embed))
    poses = [torch.eye(3, 4) for _ in range(M)] # T_i = [R|t]
    
    # Optimization loop
    optimizer = optim.Adam(list(nerf.parameters()) + list(warp_field.parameters()) + [embeddings], lr=1e-3)
    
    for epoch in range(10000):
        optimizer.zero_grad()
        
        local_loss = 0
        global_loss = 0
        
        for i in range(M):
            # Sample pixels x_j
            x_j = torch.rand(N, 2) # Normalized coordinates
            
            # Get local transformation T_ji
            # Warp field outputs Lie algebra vector
            lie_alg = warp_field(x_j, embeddings[i:i+1].expand(N, -1))
            # Reshape to 6 for se(3) or 3 for se(2) depending on implementation
            # Assuming 3D NeRF, we need se(3)
            # The paper says T_ji = W(x_j; l_i, Phi)
            # And T_ji is used to transform 3D points.
            
            # Construct T_ji matrix from Lie algebra
            # This step requires implementing exp_se3
            T_ji_matrix = exp_se3(lie_alg) # (N, 3, 4)
            
            # Render using local transformation
            # Ray origin and direction are derived from T_ji
            # For simplicity, assume we have ray origins/directions in world space
            # and T_ji transforms world points to camera space? 
            # Or T_ji transforms camera points to world space?
            # The paper says: R(T_ji x_j; Theta). x_j is pixel coord.
            # In 3D, x_j is homogeneous [u, v, 1]. T_ji is 3x4?
            # Actually, the paper formulates R(T x; Theta) where T is the camera pose.
            # So T_ji acts as the camera pose for pixel j.
            
            # Generate rays for pixel j with pose T_ji
            # This is complex to implement from scratch without specific ray generation code.
            # We assume a helper function exists.
            rays = generate_rays_from_pose(T_ji_matrix, x_j)
            
            # Render
            rendered_color = volume_rendering(rays.origins, rays.directions, nerf)
            
            # Get target image patch I_i(x_j)
            target_color = get_image_patch(i, x_j)
            
            local_loss += torch.mean((rendered_color - target_color)**2)
            
            # Global Alignment
            # Solve Procrustes for frame i
            # Points in local space: x_j (homogeneous)
            # Points in global space: T_ji * x_j (homogeneous)
            # We want to find T_i such that T_i * x_j approx T_ji * x_j
            
            # Convert x_j to 3D homogeneous
            x_j_hom = torch.cat([x_j, torch.ones(N, 1)], dim=-1) # (N, 3)
            
            # Transform by T_ji
            # T_ji is (N, 3, 4). x_j_hom is (N, 3).
            # Result is (N, 3) in 3D space?
            # T_ji * x_j_hom^T -> (3, N). Transpose -> (N, 3)
            transformed_points = (T_ji_matrix @ x_j_hom.unsqueeze(-1)).squeeze(-1).transpose(1, 2)
            
            # Solve Procrustes
            R_i, t_i = solve_procrustes(x_j_hom[:, :2], transformed_points[:, :2]) # Using 2D for simplicity in example
            # In 3D, we use 3D points.
            
            # Construct T_i
            T_i = torch.eye(3, 4)
            T_i[:, :3] = R_i
            T_i[:, 3] = t_i
            
            # Global loss: || T_ji x_j - T_i x_j ||^2
            # T_i x_j
            T_i_x_j = (T_i.unsqueeze(0) @ x_j_hom.unsqueeze(-1)).squeeze(-1).transpose(1, 2)
            
            global_loss += torch.mean((transformed_points - T_i_x_j)**2)
            
        total_loss = local_loss + lambda_global * global_loss
        total_loss.backward()
        optimizer.step()
```

## Operating characteristics
*   **Time Complexity:** More efficient than global registration methods like BARF because it computes gradients with respect to local pose [S1]. Training time on NVIDIA GeForce RTX 2080 Ti is ~4.5 hours for synthetic objects and ~8 hours for real-world scenes, compared to ~8 and ~10.5 hours for BARF [S1].
*   **Memory Complexity:** Requires storing parameters for both the NeRF MLP and the Warp MLP, plus frame embeddings [S1].
*   **Strengths:** Robust to poor initialization; tolerates larger noise perturbations (up to $n_c=8$) before divergence compared to BARF ($n_c=4$) [S1].
*   **Limitations:** Fails to recover camera poses from identity transformation for inward-facing 360° scenes with large rotation displacements [S1]. Large $\lambda$ ($1 \times 10^5$) improves geometric accuracy but reduces robustness, causing divergence on some scenes (e.g., Flower) [S1].
*   **When to use:** When camera poses are unknown and initialization is poor, especially for forward-facing or object-centric scenes [S1].
*   **When not to use:** For inward-facing 360° scenes with large initial rotation errors [S1].

## Background
L2G-NeRF was proposed in the paper "Local-to-Global Registration for Bundle-Adjusting Neural Radiance Fields" [S1]. It addresses the limitations of parametric methods (susceptible to suboptimal solutions if poorly initialized) and non-parametric methods (trouble with large displacements) by combining both in a local-to-global process [S1]. It is applicable to both 2D neural images and 3D Neural Radiance Fields [S1].
