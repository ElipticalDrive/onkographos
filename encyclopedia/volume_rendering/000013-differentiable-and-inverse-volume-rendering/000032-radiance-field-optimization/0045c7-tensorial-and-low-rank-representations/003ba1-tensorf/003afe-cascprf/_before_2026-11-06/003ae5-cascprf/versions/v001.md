# CasCPRF

Also called: Cascaded Tensorial Radiance Fields, IRCasTRF

## Overview
CasCPRF is a multi-scale implicit scene representation that uses a cascaded structure of tensor decompositions to control frequency bands, separating low spatial/high angular frequency content (coarse scale) from high spatial/low angular frequency content (fine scale) for compact reconstruction [S1]. It differs from standard NeRF by explicitly disentangling frequency bands across hierarchical levels to facilitate compact tensor approximation, and it extends the optimization loop into an "exploitation stage" that extracts a mesh and refines topology, materials, and lighting using physics-based rendering [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Multi-view images, camera poses, and optionally an initial mesh (for texture indexing).
*   **Outputs:** Novel view images, a refined 3D mesh with materials and textures, and an environment map for lighting.

**Data Structures:**
1.  **Cascaded Feature Volumes ($\mathcal{V}_\sigma, \mathcal{V}_c$):** Represented via tensor decomposition. For cascaded level $d$ and rank $r$, the volume is factorized into rank-one vectors $\mathbf{v}_{r,x,d}, \mathbf{v}_{r,y,d}, \mathbf{v}_{r,z,d}$.
    *   The number of rows in mode $n$ at level $d$ is $I_{n,d} = I_n / 2^{d-1}$.
    *   Default cascaded levels $D=3$.
    *   Base voxel grid size $I_{x,1} \times I_{y,1} \times I_{z,1} = 125^3$, upsampled to max $250^3$ [S1].
2.  **Mesh Data:** Vertices $\mathbf{v}$, per-vertex deformation vectors $\Delta \mathbf{v}_i \in \mathbb{R}^3$, and global movement vector $\Delta \mathbf{m} \in \mathbb{R}^3$.
3.  **Material Parameters:** Diffuse term $b_d$, roughness $r$, metalness $m$.
4.  **Environment Map:** $\mathbf{M} \in \mathbb{R}^{6 \times 512 \times 512}$ across 6 mip levels [S1].

**Numbered Steps:**

1.  **Initialization:** Initialize the cascaded structure in a binary-tree style. Set the number of rows for rank-one vectors in mode $n$ and level $d$ as $I_{n,d} = I_n / 2^{d-1}$ [S1]. Initialize global movement vector $\Delta \mathbf{m}$ randomly within $[-0.3, 0.3]$ [S1]. Initialize environment lighting to 0.5 [S1].

2.  **Exploration Stage (Implicit Rendering):**
    2.1. Sample $N_s$ points per ray along the camera's viewing direction to cast the radiance field feature volume [S1].
    2.2. Grid sample the radiance field feature volumes $\mathcal{V}_\sigma$ and $\mathcal{V}_c$ to produce density features $F_\sigma$ and color features $F_c$ for each spatial point $\mathbf{x}$ [S1].
    2.3. Compute density $\sigma = \text{ReLU}(F_\sigma)$ [S1].
    2.4. Compute viewing direction encoding $\text{PE}(\omega_o)$ using sinusoidal positional encoding:
    $$ \text{PE}(x) = [\sin(2^0 \cdot x), \cos(2^0 \cdot x), \dots, \sin(2^{N_q-1} \cdot x), \cos(2^{N_q-1} \cdot x)] $$
    where $N_q$ is the number of frequency bands [S1].
    2.5. Compute color $c = \text{MLP}_c(F_c, \text{PE}(\omega_o))$. $\text{MLP}_c$ is a two-layer MLP with 128 nodes and ReLU activation [S1].
    2.6. Apply volume rendering to calculate accumulated transmittance $T_i$ and render color prediction $C$:
    $$ T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right), \quad C(r) = \sum_{i=1}^{N_s} T_i \alpha_i c_i, \quad \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
    where $\delta_j$ is the distance between adjacent sampled points [S1].
    2.7. Extract preliminary mesh $M$ from the density volume using the Marching Cubes (MC) algorithm [S1].
    2.8. Optimize parameters using Adam optimizer. Learning rate for CasCPRF is 0.02, for $\text{MLP}_c$ is 0.0001. Total iterations: 30,000. Batch size: 4096 [S1]. Loss function:
    $$ L_{explor} = \|C - \hat{C}\|_2^2 + \lambda_{tv} L_{tv}(\mathbf{v}) $$
    where $L_{tv}$ is total variation loss on vectors $\mathbf{v}$ to enforce smoother surfaces [S1].

3.  **Exploitation Stage (Physics-based Shading):**
    3.1. **Global Alignment:** Learn global movement vector $\Delta \mathbf{m}$ during warm-up iterations (first 150 iterations) to ensure accurate positioning [S1].
    3.2. **Topology Finetune:** After warm-up, disable $\Delta \mathbf{m}$ and enable per-vertex deformation vectors $\Delta \mathbf{v}_i$ to alter topology [S1].
    3.3. **Material Model:** Use Disney material model. Calculate specular term $b_s$ as:
    $$ b_s = (1 - m) \cdot 0.04 + m \cdot b_d $$
    Constraints: $b_d \in [0, 1]$, $r \ge 0.08$ [S1].
    3.4. **Texturing:** Use learnable parameters for 2D texture initialized from input mesh in Blender. Fixed indexes between vertices and texture map [S1].
    3.5. **Lighting:** Use differentiable split-sum approximation for image-based lighting with environment cube map $\mathbf{M}$. Coarser levels are constructed from the base level using a pre-filtering approach to increase roughness [S1].
    3.6. **Optimization:** Optimize over 5,000 iterations with Adam optimizer, learning rate 0.03 (falloff from 1.0 to 0.1 exponentially). Batch size: 8 images (512x512). Loss function includes $L_1$ norm on tone-mapped colors $\Gamma(\cdot)$ and light regularizer $L_{light}$:
    $$ L_{light} = \frac{1}{3} \sum_{i=0}^3 |C_{bar_i} - \frac{1}{3} \sum_{i=0}^3 C_{bar_i}| $$
    This penalizes color shifts to assume white lighting [S1].

**Pseudocode:**

```python
def cas_cprf_explore(images, poses, N_s=64, D=3, I_base=125):
    # Initialize cascaded tensor factors
    # I_n,d = I_n / 2^(d-1)
    V_sigma_factors = initialize_cascaded_tensors(D, I_base, mode='sigma')
    V_color_factors = initialize_cascaded_tensors(D, I_base, mode='color')
    
    # Initialize MLP_c: 2 layers, 128 nodes, ReLU
    mlp_c = TwoLayerMLP(input_dim=..., hidden_dim=128, output_dim=3)
    
    # Optimizers
    opt_cprf = Adam(V_sigma_factors + V_color_factors, lr=0.02)
    opt_mlp = Adam(mlp_c.parameters(), lr=0.0001)
    
    for iteration in range(30000):
        # Sample rays
        rays = sample_rays(images, poses, batch_size=4096)
        
        # Sample points along rays
        points = sample_points_along_rays(rays, N_s)
        
        # Grid sample features from cascaded volumes
        # V_sigma(x) -> F_sigma, V_color(x) -> F_color
        F_sigma = grid_sample_cascaded(V_sigma_factors, points)
        F_color = grid_sample_cascaded(V_color_factors, points)
        
        # Compute density
        sigma = relu(F_sigma)
        
        # Compute color
        # PE(x) = [sin(2^0*x), cos(2^0*x), ..., sin(2^(Nq-1)*x), cos(2^(Nq-1)*x)]
        directions = rays.directions
        PE_dirs = sinusoidal_pos_enc(directions, N_q)
        c = mlp_c(concat(F_color, PE_dirs))
        
        # Volume rendering
        delta = compute_delta(points)
        T = compute_transmittance(sigma, delta)
        alpha = 1 - exp(-sigma * delta)
        C = sum(T * alpha * c, axis=ray_sample_axis)
        
        # Loss
        gt_colors = rays.gt_colors
        L_recon = mse(C, gt_colors)
        L_tv = total_variation(V_sigma_factors)
        L_total = L_recon + lambda_tv * L_tv
        
        # Backprop
        opt_cprf.zero_grad()
        opt_mlp.zero_grad()
        L_total.backward()
        opt_cprf.step()
        opt_mlp.step()
        
    # Extract mesh
    density_volume = reconstruct_volume(V_sigma_factors)
    mesh = marching_cubes(density_volume)
    return mesh, V_sigma_factors, V_color_factors

def cas_cprf_exploit(mesh, images, poses, D=3):
    # Initialize deformation vectors
    delta_m = random_vector(-0.3, 0.3) # Global movement
    delta_v = zeros_like(mesh.vertices) # Per-vertex deformation
    
    # Material parameters
    b_d = random_clamped(0, 1) # Albedo
    r = random_clamped(0.08, 1.0) # Roughness
    m = random_clamped(0, 1) # Metalness
    
    # Environment map
    M = initialize_env_map(6, 512, 512, init_val=0.5)
    
    opt_mesh = Adam([delta_m, delta_v], lr=0.03)
    opt_mat = Adam([b_d, r, m], lr=0.03)
    opt_light = Adam(M, lr=0.03)
    
    for iteration in range(5000):
        # Learning rate decay
        current_lr = 0.03 * (1.0 - iteration/5000) * 0.1 + 0.03 * (1.0 - iteration/5000) # Exponential falloff approx
        
        # Warm-up phase (first 150 iters)
        if iteration < 150:
            enable_global_movement = True
            enable_per_vertex_movement = False
        else:
            enable_global_movement = False
            enable_per_vertex_movement = True
            
        # Update vertex positions
        if enable_global_movement:
            vertices = mesh.vertices + delta_m
        elif enable_per_vertex_movement:
            vertices = mesh.vertices + delta_v
        else:
            vertices = mesh.vertices
            
        # Render using physics-based shading
        # Disney material model
        b_s = (1 - m) * 0.04 + m * b_d
        # Split-sum approximation for lighting
        C_rendered = render_mesh(vertices, mesh.faces, M, b_d, b_s, r, poses)
        
        # Loss
        gt_colors = images.ray_colors
        L_color = l1(tone_map(C_rendered), tone_map(gt_colors))
        L_light = compute_light_regularizer(C_rendered)
        L_total = L_color + L_light
        
        # Backprop
        opt_mesh.zero_grad()
        opt_mat.zero_grad()
        opt_light.zero_grad()
        L_total.backward()
        opt_mesh.step()
        opt_mat.step()
        opt_light.step()
        
    return mesh, b_d, r, m, M
```

## Operating characteristics
*   **Time Complexity:** Exploration stage takes ~25 minutes on a single Nvidia A100 GPU (40GB) for 30,000 iterations with batch size 4096 [S1]. Exploitation stage takes ~1 hour on a single Nvidia A100 GPU (40GB) for 5,000 iterations with batch size 8 (512x512) [S1].
*   **Memory Complexity:** Depends on the voxel grid size ($125^3$ to $250^3$) and the number of cascaded levels ($D=3$). The tensor decomposition provides a compact representation compared to dense voxel grids [S1].
*   **Strengths:** Produces superior reconstruction quality compared to single-scale counterparts with the same model size budget. The separation of frequency bands allows efficient learning of both specular patterns (low spatial/high angular frequency) and texture details (high spatial/low angular frequency) [S1].
*   **Limitations:** Requires an initial mesh for texture indexing in the exploitation stage. The two-stage process (exploration then exploitation) increases total training time compared to single-stage NeRF variants.
*   **When to use:** When high-fidelity novel view synthesis and physically-based material/lighting estimation are required, and computational resources (GPU memory and time) allow for a two-stage optimization process.

## Background
CasCPRF (Cascaded Tensorial Radiance Fields), also known as IRCasTRF, was introduced by Wenpeng Xing, Jie Chen, Ka Chun Cheung, and Simon See in 2023 [S1]. It builds on the success of NeRF's high-frequency Fourier features while addressing the spectral bias of MLPs by proposing a multi-scale scene representation using tunable frequency bandwidths via cascaded tensor decompositions [S1]. The method integrates inverse rendering techniques, specifically physics-based shading and differentiable rendering, to refine geometry, materials, and lighting from multi-view images [S1].
