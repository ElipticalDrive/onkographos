# Macro-Cell Trimming

Also called: Culling Empty Cap-Level Macrocells

## Overview
Macro-cell trimming is an optimization that reduces the number of local rays by trimming each macro-cell to the smallest cuboid containing its portions of the iso-surfaces, rather than projecting the entire macro-cell [S1, unofficial]. It sets itself apart from sibling methods like [Triangulated Active Brick Boundary Mesh for Space Skipping](1426-triangulated-active-brick-boundary-mesh-for-space-skipping.md) by operating on axis-aligned bounding boxes derived from cell occupancy rather than explicit mesh geometry, and from [Adaptive Ray Marching with Macrocell DDA](1500-adaptive-ray-marching-with-macrocell-dda.md) by focusing on pre-projection culling of the pixel footprint rather than adaptive step sizing during traversal.

## How it works
**Inputs:**
- A macro-cell containing a grid of cells (typically at the finest available octree depth, i.e., cap nodes).
- An isovalue threshold defining the iso-surface.
- The spatial bounds of the macro-cell.

**Outputs:**
- A trimmed bounding cuboid (axis-aligned bounding box) that tightly encloses all cells within the macro-cell intersecting the isovalue.
- A reduced set of pixels (u,v slice extents) for ray casting.

**Data Structures:**
- **Macro-cell Grid:** A 3D array of cells. Each cell contains a scalar value (density or field value).
- **Trimmed Cuboid:** Defined by minimum and maximum coordinates $(x_{min}, y_{min}, z_{min})$ and $(x_{max}, y_{max}, z_{max})$. Initialized to an invalid or zero-size state.

**Steps:**
1. **Initialize Cuboid:** Set the trimmed cuboid to a size of zero or an invalid state [S1, unofficial].
2. **Iterate Cells:** Loop through all cells within the macro-cell [S1, unofficial].
3. **Check Iso-surface Intersection:** For each cell, determine if it contains the isovalue (i.e., if the cell's value crosses the threshold) [S2, unofficial].
4. **Extend Cuboid:** If a cell contains the isovalue:
   - Calculate the spatial bounds of the cell.
   - Update the trimmed cuboid's min/max coordinates to include the cell's bounds [S1, unofficial].
   - Specifically, update $x_{min}, x_{max}, y_{min}, y_{max}, z_{min}, z_{max}$ to the minimum/maximum values encountered so far [S1, unofficial].
5. **Compute Slice Extents:** After iterating all cells, compute the u,v slice extents based on the minimum and maximum u,v coordinates of the trimmed cuboid [S2, unofficial].
6. **Cull Empty Macro-cells:** If the macro-cell is empty (no cells contain the isovalue), omit it from extent computation entirely [S2, unofficial]. The u,v slice is clamped to tightly enclose only nodes with the desired isovalue [S2, unofficial].
7. **Project:** Project the resulting trimmed cuboid onto the image plane instead of the full macro-cell [S1, unofficial].
8. **Cast Rays:** Cast local rays only for pixels covered by the projected trimmed cuboid [S1, unofficial].

**Pseudocode:**
```python
def trim_macro_cell(macro_cell, isovalue):
    """
    Trims a macro-cell to the smallest cuboid containing iso-surface portions.
    
    Args:
        macro_cell: A 3D grid of cells with scalar values.
        isovalue: The threshold value for the iso-surface.
        
    Returns:
        A tuple (u_min, u_max, v_min, v_max) representing the trimmed slice extents,
        or None if the macro-cell is empty.
    """
    # Initialize cuboid bounds to None (invalid)
    x_min = None
    x_max = None
    y_min = None
    y_max = None
    z_min = None
    z_max = None
    
    # Iterate through all cells in the macro-cell
    for cell in macro_cell:
        # Check if the cell contains the isovalue
        # Note: Implementation detail [G]: Typically involves checking if the cell's
        # value (or interpolated values at corners) crosses the isovalue.
        if cell.contains_isovalue(isovalue):
            # Get spatial bounds of the cell
            cell_bounds = cell.get_bounds()
            
            # Update cuboid min/max
            if x_min is None or cell_bounds.x_min < x_min:
                x_min = cell_bounds.x_min
            if x_max is None or cell_bounds.x_max > x_max:
                x_max = cell_bounds.x_max
            if y_min is None or cell_bounds.y_min < y_min:
                y_min = cell_bounds.y_min
            if y_max is None or cell_bounds.y_max > y_max:
                y_max = cell_bounds.y_max
            if z_min is None or cell_bounds.z_min < z_min:
                z_min = cell_bounds.z_min
            if z_max is None or cell_bounds.z_max > z_max:
                z_max = cell_bounds.z_max

    # If no cells contained the isovalue, the macro-cell is empty
    if x_min is None:
        return None

    # Compute u,v slice extents based on the trimmed cuboid
    # Note: Implementation detail [G]: Mapping 3D bounds to 2D screen coordinates (u,v)
    # requires the camera projection matrix. This is assumed to be handled by the
    # caller or a helper function.
    u_min, v_min, u_max, v_max = project_cuboid_to_screen(x_min, x_max, y_min, y_max, z_min, z_max)
    
    return (u_min, u_max, v_min, v_max)
```

**Edge Cases and Pitfalls:**
- **Empty Macro-cells:** Must be detected and omitted to avoid unnecessary processing [S2, unofficial].
- **Precision:** Ensure that the cuboid extension logic correctly handles floating-point precision when updating min/max values [S1, unofficial].
- **Boundary Conditions:** The cuboid must be initialized correctly to handle the first surface cell encountered [S1, unofficial].

## Operating characteristics
- **Performance:** Macro-cell trimming saves about 28 percent of overall rendering time on average [S1, unofficial].
- **Dependency:** The time gain is very much dependent on the data set and the position of the view point [S1, unofficial].
- **Complexity:** The trimming step adds a linear scan over the macro-cell cells, but this is offset by the reduction in ray casting operations.
- **Strengths:** Reduces unnecessary calculations and octree lookups by focusing only on relevant pixels [S1, S2, unofficial].
- **Limitations:** Effectiveness varies with data set topology and viewpoint [S1, unofficial].

## Background
Macro-cell trimming was introduced as part of cell-based first-hit ray casting techniques to optimize volume rendering performance [S1, unofficial]. It is also referred to as "Culling empty cap-level macrocells" in the context of interactive ray tracing of implicit surfaces [S2, unofficial]. The method leverages the coherence of octree structures to efficiently cull empty regions before ray casting begins [S2, unofficial].
