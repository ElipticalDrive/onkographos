# Ray Marcher with Macrocell Empty Space Skipping

Also called: Macrocell Acceleration, Macrocell Zero-Density Skipping, Macrocell rendering with zero-density skip, Ray marcher with macrocell, Skipping macrocells with zero density

## Overview
This method accelerates volume rendering by dividing the volume into coarse grid elements (macrocells) and precomputing a boolean or aggregate value for each to identify and skip regions containing only zero-density cells during ray marching [S1][S2, unofficial]. It builds on the parent [Empty-space skipping](1002-empty-space-skipping.md) by applying the concept to a fixed coarse grid hierarchy rather than dynamic traversal structures.

## How it works
**Inputs and Outputs:**
*   **Input:** A structured volume dataset, a transfer function mapping density to opacity/color, and a set of camera rays [S1][S2, unofficial].
*   **Output:** Rendered image with reduced computational load in empty regions [S1][S2, unofficial].

**Data Structures:**
*   **Macrocell Grid:** A 3D array aligned with the volume, where each element corresponds to a macrocell [S1][S2, unofficial].
*   **Macrocell Values:** Each macrocell stores a precomputed boolean indicating if the surface passes through it, or an aggregate density value computed from its constituent fine cells [S1][S2, unofficial]. If the value indicates zero density, the macrocell is considered empty [S1][S2, unofficial].

**Steps:**
1.  **Precomputation:** For each macrocell in the coarse grid, compute the aggregate density value or boolean skip flag from its constituent fine cells based on the transfer function densities [S1][S2, unofficial].
2.  **Ray Traversal:** For each pixel, generate a ray and use a 3D Digital Differential Analyzer (3DDDA) to traverse the macrocell grid [S1].
3.  **Macrocell Check:** At each macrocell intersection, fetch the precomputed boolean or aggregate value [S1][S2, unofficial].
4.  **Skip Decision:** If the macrocell contains only zero-density cells (boolean is false or aggregate is zero), skip processing the entire macrocell and advance the ray to the next macrocell boundary [S1][S2, unofficial].
5.  **Marching:** If the macrocell is not empty, perform standard ray marching within the macrocell, sampling fine cells and accumulating opacity/color [S1][S2, unofficial].
6.  **Termination:** Stop when the ray exits the volume [S1][S2, unofficial].

**Formulas:**
*   Let $M_{ijk}$ be the aggregate density or boolean flag of macrocell at indices $(i,j,k)$ [S1][S2, unofficial].
*   Let $C_{lmn}$ be the density of fine cell at indices $(l,m,n)$ [S1][S2, unofficial].
*   Skip condition: If $M_{ijk} = 0$ (or boolean is false), skip macrocell [S1][S2, unofficial].
*   Aggregation method: Not given in the sources.

**Parameters:**
*   **Macrocell Size:** The number of voxels per macrocell dimension. 23 voxels per macrocell is recommended for best performance; 13, 43, and 83 are also tested [S1].
*   **Threshold:** Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Overhead Dominance:** Performance degrades if the fraction of skippable macrocells is small, because the extra memory access for retrieving macrocell values and condition checks per coarse element adds overhead without sufficient savings [S2, unofficial].
*   **Transfer Function Dependency:** Performance gains depend heavily on the transfer function, as macrocell values are computed from transfer function densities [S2, unofficial].
*   **Dataset Variability:** On datasets with very few zero-density macrocells (e.g., Engine dataset with 12) or high overhead per check (e.g., Agulhas dataset with 1,395,619 skipped), macrocell skipping can be slower than standard ray marching [S2, unofficial].

**Pseudocode:**
```python
def compute_macrocells(volume, macrocell_dims):
    """
    volume: 3D list of fine cell densities
    macrocell_dims: tuple (Dx, Dy, Dz) defining the size of each macrocell
    Returns: 3D list of macrocell aggregates
    """
    vol_shape = (len(volume), len(volume[0]), len(volume[0][0]))
    macro_shape = (
        (vol_shape[0] + macrocell_dims[0] - 1) // macrocell_dims[0],
        (vol_shape[1] + macrocell_dims[1] - 1) // macrocell_dims[1],
        (vol_shape[2] + macrocell_dims[2] - 1) // macrocell_dims[2]
    )
    macrocells = [[[0.0 for _ in range(macro_shape[2])] for _ in range(macro_shape[1])] for _ in range(macro_shape[0])]
    
    for i in range(macro_shape[0]):
        for j in range(macro_shape[1]):
            for k in range(macro_shape[2]):
                x_start, x_end = i * macrocell_dims[0], min((i + 1) * macrocell_dims[0], vol_shape[0])
                y_start, y_end = j * macrocell_dims[1], min((j + 1) * macrocell_dims[1], vol_shape[1])
                z_start, z_end = k * macrocell_dims[2], min((k + 1) * macrocell_dims[2], vol_shape[2])
                
                max_val = 0.0
                for x in range(x_start, x_end):
                    for y in range(y_start, y_end):
                        for z in range(z_start, z_end):
                            if volume[x][y][z] > max_val:
                                max_val = volume[x][y][z]
                macrocells[i][j][k] = max_val
    return macrocells

def ray_march_with_macrocell_skip(ray_origin, ray_direction, volume, macrocells, macrocell_dims):
    """
    ray_origin: (x, y, z)
    ray_direction: (dx, dy, dz) normalized
    volume: 3D list of fine cell densities
    macrocells: 3D list of macrocell aggregates
    macrocell_dims: tuple (Dx, Dy, Dz)
    Returns: (final_color, final_opacity)
    """
    vol_shape = (len(volume), len(volume[0]), len(volume[0][0]))
    macro_shape = (len(macrocells), len(macrocells[0]), len(macrocells[0][0]))
    
    t = 0.0
    step_size = 1.0
    accumulated_opacity = 0.0
    accumulated_color = [0.0, 0.0, 0.0]
    
    while t < max(vol_shape):
        current_x = ray_origin[0] + ray_direction[0] * t
        current_y = ray_origin[1] + ray_direction[1] * t
        current_z = ray_origin[2] + ray_direction[2] * t
        
        macro_i = int(current_x // macrocell_dims[0])
        macro_j = int(current_y // macrocell_dims[1])
        macro_k = int(current_z // macrocell_dims[2])
        
        macro_i = max(0, min(macro_i, macro_shape[0] - 1))
        macro_j = max(0, min(macro_j, macro_shape[1] - 1))
        macro_k = max(0, min(macro_k, macro_shape[2] - 1))
        
        if macrocells[macro_i][macro_j][macro_k] == 0.0:
            x_exit = (macro_i + 1) * macrocell_dims[0]
            y_exit = (macro_j + 1) * macrocell_dims[1]
            z_exit = (macro_k + 1) * macrocell_dims[2]
            
            t_x = (x_exit - current_x) / ray_direction[0] if ray_direction[0] != 0 else float('inf')
            t_y = (y_exit - current_y) / ray_direction[1] if ray_direction[1] != 0 else float('inf')
            t_z = (z_exit - current_z) / ray_direction[2] if ray_direction[2] != 0 else float('inf')
            
            t_skip = min(t_x, t_y, t_z)
            t += t_skip
            continue
            
        x_exit = (macro_i + 1) * macrocell_dims[0]
        y_exit = (macro_j + 1) * macrocell_dims[1]
        z_exit = (macro_k + 1) * macrocell_dims[2]
        
        t_x = (x_exit - current_x) / ray_direction[0] if ray_direction[0] != 0 else float('inf')
        t_y = (y_exit - current_y) / ray_direction[1] if ray_direction[1] != 0 else float('inf')
        t_z = (z_exit - current_z) / ray_direction[2] if ray_direction[2] != 0 else float('inf')
        
        t_exit = min(t_x, t_y, t_z)
        
        while t < t_exit:
            sample_x = ray_origin[0] + ray_direction[0] * t
            sample_y = ray_origin[1] + ray_direction[1] * t
            sample_z = ray_origin[2] + ray_direction[2] * t
            
            density = sample_volume(volume, sample_x, sample_y, sample_z)
            color, opacity = apply_transfer_function(density)
            
            alpha = opacity * (1.0 - accumulated_opacity)
            accumulated_color[0] += color[0] * alpha
            accumulated_color[1] += color[1] * alpha
            accumulated_color[2] += color[2] * alpha
            accumulated_opacity += alpha
            
            if accumulated_opacity >= 1.0:
                break
                
            t += step_size
            
        if accumulated_opacity >= 1.0:
            break
            
    return accumulated_color, accumulated_opacity

def sample_volume(volume, x, y, z):
    ix, iy, iz = int(x), int(y), int(z)
    ix = max(0, min(ix, len(volume)-1))
    iy = max(0, min(iy, len(volume[0])-1))
    iz = max(0, min(iz, len(volume[0][0])-1))
    return volume[ix][iy][iz]

def apply_transfer_function(density):
    return [density, density, density], density
```

## Subtopics

### [Triangulated Active Brick Boundary Mesh for Space Skipping](1426-triangulated-active-brick-boundary-mesh-for-space-skipping.md)
A GPU-accelerated space-skipping technique for structured volumes that replaces clustered proxy boxes with a triangle mesh bounding the surface between active and inactive macrocells. It solves the host-GPU transfer bottleneck and high depth complexity of prior proxy-box methods by generating the boundary geometry entirely on the GPU and using native RTX hardware for ray-triangle intersection.

### [Adaptive Ray Marching with Macrocell DDA](1500-adaptive-ray-marching-with-macrocell-dda.md)
Adaptive Ray Marching with Macrocell DDA is a ray traversal technique that accelerates volume rendering by combining a 3D Digital Differential Analyzer (DDA) for coarse macrocell traversal with adaptive step sizing based on opacity upper bounds. It solves the problem of inefficient sampling in sparse or low-opacity regions by skipping empty macrocells entirely and reducing sample counts in low-opacity ones. Unlike its parent [Ray Marcher with Macrocell Empty Space Skipping](1009-ray-marcher-with-macrocell-empty-space-skipping.md), which primarily focuses on binary empty-space skipping, this method introduces granularity by adapting the step size within non-empty cells. It differs from [Triangulated Active Brick Boundary Mesh for Space Skipping](1426-triangulated-active-brick-boundary-mesh-for-space-skipping.md) by using a regular grid structure rather than a mesh.

### Macro-Cell Trimming
An optimization that reduces the number of local rays by trimming each macro-cell to the smallest cuboid containing its portions of the iso-surfaces, rather than projecting the entire macro-cell [S3, unofficial]. It works by initializing a cuboid to size zero and iterating through all cells of the macro-cell; whenever a surface cell is encountered, the cuboid is extended to the smallest necessary size so that it contains this cell [S3, unofficial]. The resulting cuboid is then projected instead of the macro-cell [S3, unofficial]. This saves about 28 percent of overall rendering time on average, though this gain is dependent on the data set and viewpoint position [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** Precomputation is $O(N)$ where $N$ is the number of fine cells [S1]. Ray marching time is reduced proportionally to the fraction of skipped macrocells [S2, unofficial].
*   **Memory Complexity:** $O(M)$ where $M$ is the number of macrocells [S2, unofficial].
*   **Measured Performance:**
    *   **MRI Dataset:** Increasing skipped macrocells from 0 to 1,190 reduces rendering time from 44.83 ms to 26.05 ms [S2, unofficial].
    *   **Heptane Dataset:** Improves time from 51.92 ms to 46.3 ms [S2, unofficial].
    *   **Advection Dataset:** Improves time from 58.14 ms to 46.29 ms [S2, unofficial].
    *   **Engine Dataset:** Only 12 macrocells have zero density, leading to worse performance (43.61 ms with macrocell vs 41.46 ms without) [S2, unofficial].
    *   **Agulhas Dataset:** 1,395,619 skipped macrocells, but performance is worse (55.34 ms with macrocell vs 41.53 ms without) due to overhead [S2, unofficial].
    *   **Fiber Surface Dataset:** Performance without macrocells is 4x-8x slower than with 23-voxel macrocells [S1].
*   **Strengths:** Simple implementation, effective for sparse volumes with large empty regions [S1][S2, unofficial].
*   **Limitations:** Overhead can dominate if skipping fraction is low. Performance is transfer-function dependent [S2, unofficial].
*   **When to Use:** Sparse volumes with significant empty space [S2, unofficial].
*   **When Not to Use:** Dense volumes or when the transfer function results in few zero-density macrocells [S2, unofficial].

## Background
The method originates from research on direct multifield volume ray casting of fiber surfaces [S1] and direct volume rendering of tree-based tetrahedral adaptive mesh refinement data [S2, unofficial]. It was developed as an optimization to handle sparse data and improve rendering performance by avoiding unnecessary computations in transparent regions [S1][S2, unofficial]. It is used in interactive fiber surface exploration and tree-based AMR volume rendering pipelines [S1][S2, unofficial].
