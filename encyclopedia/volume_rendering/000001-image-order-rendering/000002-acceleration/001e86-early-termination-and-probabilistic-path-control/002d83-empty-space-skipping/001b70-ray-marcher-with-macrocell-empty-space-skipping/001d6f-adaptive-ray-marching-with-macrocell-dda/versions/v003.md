# Adaptive Ray Marching with Macrocell DDA

Also called: Adaptive Macrocell Ray Marching

## Overview
Adaptive Ray Marching with Macrocell DDA is a ray marching technique that traverses a volumetric grid using a 3D Digital Differential Analyzer (DDA) over macrocells, adapting the sampling step size based on opacity upper bounds to skip empty or low-opacity regions [S1, unofficial][S2]. It differs from its parent [Ray Marcher with Macrocell Empty Space Skipping](1009-ray-marcher-with-macrocell-empty-space-skipping.md) by explicitly varying the sampling density within occupied macrocells based on local opacity estimates, rather than only skipping entirely empty cells. It differs from [Triangulated Active Brick Boundary Mesh for Space Skipping](1426-triangulated-active-brick-boundary-mesh-for-space-skipping.md) by using a regular grid-based DDA traversal instead of geometric boundary meshes.

## How it works
The method combines coarse-grained space skipping with fine-grained adaptive sampling. It uses a precomputed macrocell grid to determine if a region is empty. If a macrocell is occupied, it enters a sampling loop where the step size is dynamically adjusted based on an opacity upper bound estimate for that cell. This allows larger steps in low-opacity regions and smaller steps in high-opacity regions, improving performance and quality.

### Inputs and Outputs
**Inputs:**
*   Ray origin `org` and direction `dir` in world space.
*   Ray interval `[tMin, tMax]` defining the segment to traverse.
*   Volume data structure containing:
    *   `macrocell_dims`: Dimensions of the macrocell grid.
    *   `macrocell_spacings_rcp`: Reciprocal of macrocell spacing in world units.
    *   Opacity upper bound estimation function `opacityUpperBound(self, cell)`.
*   Base sampling step size `step`.
*   `ADAPTIVE_SAMPLING`: Preprocessor macro enabling/disabling adaptive logic.
*   `float_epsilon`: Small constant for empty cell detection.

**Outputs:**
*   Accumulated color and opacity along the ray.
*   Boolean flag indicating if the ray was terminated early (e.g., due to full opacity or empty space).

### Data Structures
The core data structure is `DeviceVolume`, which contains:
*   `macrocell_dims`: Integer vector specifying the number of macrocells in each dimension.
*   `macrocell_spacings_rcp`: Float vector containing the reciprocal of the macrocell spacing. This is used to transform world-space coordinates into macrocell-space coordinates efficiently.

### Algorithm Steps
1.  **Macrocell Space Transformation**: Transform the ray origin and direction into macrocell space.
    $$ m_{org} = org \times macrocell\_spacings\_rcp $$
    $$ m_{dir} = dir \times macrocell\_spacings\_rcp $$
2.  **DDA Initialization**: Initialize a 3D DDA iterator with `m_org`, `m_dir`, `tMin`, `tMax`, `dims` (volume dimensions), and debug/lambda parameters. The DDA yields cells `(cell, t0, t1)` where `t0` and `t1` are the entry and exit times of the ray within the current macrocell.
3.  **Empty Cell Check**: For each macrocell `(cell, t0, t1)` returned by the DDA:
    *   Calculate the opacity upper bound: $ r = opacityUpperBound(self, cell) $.
    *   If $ |r| \le float\_epsilon $, the cell is considered empty. Skip this macrocell entirely (return true to continue to the next cell).
4.  **Adaptive Step Size Calculation**: If the cell is not empty:
    *   Estimate the adaptive sampling rate based on $ r $ and the base `step`.
    *   Calculate the adaptive step size $ ss $:
        $$ ss = sample\_size\_scaler(adaptiveSamplingRate(step, r), t0, t1) $$
    *   Initialize the sampling interval $ t = (t0, \min(t1, t0 + ss)) $.
5.  **Sampling Loop**: While $ t.y > t.x $:
    *   Evaluate the volume at the current position $ t.x $ (calling `body(t)`).
    *   Update the interval: $ t.x = t.y $.
    *   Update the end of the interval: $ t.y = \min(t.x + ss, t1) $.
    *   If `body(t)` returns true (e.g., ray terminated), stop processing this macrocell.
6.  **Termination**: Return true if the body function indicates termination; otherwise, continue to the next macrocell.

### Non-Adaptive Fallback
If `ADAPTIVE_SAMPLING` is not defined, the method falls back to fixed-step marching:
1.  Initialize $ t = (tMin, \min(tMax, tMin + step)) $.
2.  While $ t.y > t.x $ and `body(t)` is true:
    *   $ t.x = t.y $
    *   $ t.y = \min(t.x + step, tMax) $

### Pseudocode
```python
def adaptive_ray_marching_with_macrocell_dda(org, dir, tMin, tMax, volume, step):
    # 1. Transform to macrocell space
    m_org = org * volume.macrocell_spacings_rcp
    m_dir = dir * volume.macrocell_spacings_rcp
    
    # 2. Initialize DDA
    dda = DDA3D(m_org, m_dir, tMin, tMax, volume.dims)
    
    # 3. Traverse macrocells
    for cell, t0, t1 in dda:
        # 4. Check for empty cell
        r = opacity_upper_bound(volume, cell)
        if abs(r) <= float_epsilon:
            continue  # Skip empty macrocell
            
        # 5. Calculate adaptive step size
        # adaptiveSamplingRate returns a scalar factor based on r and step
        rate = adaptive_sampling_rate(step, r)
        ss = sample_size_scaler(rate, t0, t1)
        
        # 6. Initialize interval
        t_start = t0
        t_end = min(t1, t0 + ss)
        
        # 7. Sampling loop
        while t_end > t_start:
            # Evaluate volume at t_start
            if body(t_start):
                return True  # Ray terminated
            
            # Advance interval
            t_start = t_end
            t_end = min(t_start + ss, t1)
            
    return False  # Ray completed without termination
```

### Parameters
*   `ADAPTIVE_SAMPLING`: Preprocessor macro. If defined, adaptive logic is used; otherwise, fixed-step marching is used.
*   `float_epsilon`: Small constant (e.g., $10^{-6}$) used to determine if a cell is empty.
*   `step`: Base sampling step size. Modified by `adaptiveSamplingRate` to produce the adaptive step size `ss`.

### Edge Cases and Pitfalls
*   **Empty Cells**: Empty cells are skipped entirely by checking the opacity upper bound against `float_epsilon`. This prevents unnecessary sampling in empty space.
*   **Precision**: The use of reciprocal spacing (`macrocell_spacings_rcp`) requires careful handling of floating-point precision to avoid artifacts at macrocell boundaries.
*   **Degenerate Input**: If `tMin >= tMax`, the ray interval is invalid and should be handled as a no-op.

## Subtopics

### [Resumable Ray Marching Iterator](1505-resumable-ray-marching-iterator.md)
The Resumable Ray Marching Iterator is a GPU-based ray marching algorithm that traverses a volumetric grid using a 3D Digital Differential Analyzer (DDA) over macrocells, adapting the sampling step size based on opacity upper bounds to skip empty regions. It differs from its parent [Adaptive Ray Marching with Macrocell DDA](1500-adaptive-ray-marching-with-macrocell-dda.md) by explicitly supporting interruption and resumption of the ray traversal state, allowing the algorithm to pause mid-ray for external operations (such as data streaming or neural network inference) and resume later without losing progress. Unlike [Network Ray Marching Iterator](1510-network-ray-marching-iterator.md), which may handle network-specific traversal, this method focuses on general volumetric density grids with macrocell-based empty space skipping.

### [Network Ray Marching Iterator](1510-network-ray-marching-iterator.md)
The Network Ray Marching Iterator is a ray marching algorithm designed for distributed or networked rendering environments, typically leveraging GPU ray tracing APIs such as NVIDIA OptiX. It extends the parent [Adaptive Ray Marching with Macrocell DDA](1500-adaptive-ray-marching-with-macrocell-dda.md) by introducing block-level divergence control via `block_any` to manage thread synchronization across macrocell boundaries. This method is distinct from its siblings because it explicitly tracks the "alive" status of rays in a distributed context, ensuring that inactive threads do not waste computation while maintaining adaptive sampling rates based on opacity upper bounds.

### [Macrocell Grid Traversal with Majorant Densities](1528-macrocell-grid-traversal-with-majorant-densities.md)
This method accelerates volumetric path tracing by combining a coarse spatial partition (macrocells) with Delta Tracking (Woodcock tracking) to skip empty or low-opacity regions more efficiently than fixed-step marching. It sets itself apart from its parent [Adaptive Ray Marching with Macrocell DDA](1500-adaptive-ray-marching-with-macrocell-dda.md) by explicitly using the alpha component of the transfer function as a majorant extinction coefficient to determine probabilistic free-flight distances, allowing larger steps in homogeneous cells while maintaining unbiased Monte Carlo estimation.

### [Voxel Ray Marching with Cube-Level DDA](3069-voxel-ray-marching-with-cube-level-dda.md)
Voxel Ray Marching with Cube-Level DDA is a GPU-based fragment shader technique that renders voxel volumes by casting rays through a hierarchical grid of voxel cubes and individual voxels. It uses a two-level Digital Differential Analyzer (DDA) to efficiently skip empty space: the outer loop traverses 16x16x16 voxel cubes to find occupied regions, while the inner loop traverses individual voxels within those cubes to find the first opaque surface. This method differs from its parent [Adaptive Ray Marching with Macrocell DDA](1500-adaptive-ray-marching-with-macrocell-dda.md) by using fixed-size macrocells (cubes) rather than adaptive step sizes based on opacity bounds, and from its siblings [Resumable Ray Marching Iterator](1505-resumable-ray-marching-iterator.md) and [Network Ray Marching Iterator](1510-network-ray-marching-iterator.md) by relying on a strict two-level DDA structure implemented entirely in the fragment shader.

### Space Skipping with 3DDDA
A mechanism to skip empty regions in sparse volume data using a uniform grid and 3DDDA algorithm [S2]. The fragment shader traverses the macrocell grid using 3DDDA in an outer loop. If a macrocell is nonempty, it enters the volume rendering loop with peak finding tests between samples. To begin sampling, it finds the first $t$ at which to sample when entering a macrocell by solving for the maximum $x$ after $T_{enter}$:
$$ x^2/2 + bx = T_{enter} \quad x_{tenter} = (-b + \sqrt{b^2 + 2aT_{enter}})/a $$
It then computes the floor values $\lfloor x_{tenter} \rfloor$, $T(\lfloor x_{tenter} \rfloor)$ and $\frac{\partial T}{\partial x}(\lfloor x_{tenter} \rfloor)$, and samples and increments as in Equation 17. To avoid duplicate samples, it stores the greatest $t$ at which it already sampled, and uses the maximum of that and $T_{enter}$ [S2].

### Adaptive Ray Marching with Occupancy Grid
For each ray, it iterates through spatial steps. It checks occupancy using a bitfield: `sity_bitfield[ti.u32(idx//8)] & (1 << ti.u32(idx%8))`. If occupied (`occ` is true), it stores the current position `xyz`, direction `ray_d`, time `t`, and delta `dt` into buffers `xyzs`, `dirs`, `ts`, `deltas` at index `sn = start_idx + s`. It sets `run_model_ind[sn] = 1` to mark for network evaluation. It increments `t` by `dt` and `s` by 1. If not occupied, it calculates the distance to the next grid boundary. It computes `txyz` using:
$$ txyz = (((nxyz+0.5+0.5*ti.math.sign(ray_d))*grid\_size\_inv*2-1)*mip\_bound-xyz)*d\_inv $$
It determines the target time $ t_{target} = t + \max(0, txyz.min()) $. It advances time $t$ using `calc_dt` in a `while t < t_target` loop to skip empty space until the next grid boundary is reached. After the loop, it stores the total number of effective samples for the ray in `self.N_eff_samples[n] = s`. If no samples were collected (`s == 0`), it marks the ray as dead by setting `self.alive_indices[n*2+c_index] = -1` [S3, unofficial].

## Operating characteristics
*   **Time Complexity**: $O(N)$ where $N$ is the number of macrocells intersected by the ray, with adaptive sampling reducing the effective number of samples within occupied cells.
*   **Memory Complexity**: $O(M)$ where $M$ is the size of the macrocell grid, which is significantly smaller than the full voxel grid.
*   **Performance**: Adaptive sampling improves performance in sparse volumes by skipping low-opacity regions. However, purely adaptive methods based on local gradients can perform poorly on GPUs due to poor thread coherence. Per-macrocell adaptive sampling balances performance and coherence [S2].
*   **Strengths**: Efficient space skipping, adaptive sampling for quality/performance trade-off, simple implementation.
*   **Limitations**: Requires precomputed macrocell data, may suffer from thread divergence if opacity bounds vary significantly within a macrocell.

## Background
Adaptive Ray Marching with Macrocell DDA is based on the work presented in "Interactive Volume Visualization Via Multi-Resolution Hash Encoding Based Neural Representation" by Qi Wu, Michael J. Doyle, and Kwan-Liu Ma, published in IEEE Transactions on Visualization and Computer Graphics in 2023 [S1, unofficial]. The method builds upon earlier work on space skipping with 3DDDA [S2] and occupancy grid-based adaptive marching [S3, unofficial].
