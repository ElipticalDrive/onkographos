# Adaptive Ray Marching with Voxel Skipping

Also called: Sparse Ray Marching

## Overview
Adaptive Ray Marching with Voxel Skipping is a two-pass algorithm that determines optimal sampling positions for rays traversing a volumetric density grid, skipping empty space to reduce computational load [S1, unofficial]. It solves the problem of inefficient uniform sampling in sparse volumes by dynamically adjusting step sizes based on local density [S1, unofficial]. It differs from its parent, the Resumable Ray Marching Iterator, by pre-computing the exact number of steps and their locations in a dedicated pass, allowing for compact, contiguous memory storage of samples, whereas the parent yields samples on-the-fly [S1, unofficial]. It differs from [Woodcock Collision Estimation (Standard)](3331-woodcock-collision-estimation-standard.md) by using deterministic DDA-based boundary traversal rather than probabilistic collision estimation [S1, unofficial].

## How it works
The method operates on a 3D density grid and a set of rays, producing a compact list of sampled points [S1, unofficial]. It uses a two-pass approach: the first pass estimates the number of valid steps per ray to allocate memory, and the second pass writes the actual sample data [S1, unofficial].

### Inputs and Outputs
**Inputs:**
*   `rays_o`: Ray origins, shape `[N, 3]` [S1, unofficial].
*   `rays_d`: Ray directions, shape `[N, 3]` [S1, unofficial].
*   `grid`: 3D density grid of shape `[H, H, H]`, flattened to 1D [S1, unofficial].
*   `bound`: Half-width of the cubic scene volume `[-bound, bound]` [S1, unofficial].
*   `H`: Grid resolution (assumed cubic) [S1, unofficial].
*   `density_thresh`: Threshold for occupancy. Default: `10.0f` [S1, unofficial].
*   `MAX_STEPS`: Maximum steps per ray. Default: `1024` [S1, unofficial].
*   `MIN_NEAR`: Minimum near clipping distance. Default: `0.05f` [S1, unofficial].
*   `DT_GAMMA`: Step size scaling factor. Default: `1.0f / 256.0f` [S1, unofficial].
*   `perturb`: Boolean flag for jittering start position [S1, unofficial].

**Outputs:**
*   `xyzs`: Sampled point positions, shape `[M, 3]` [S1, unofficial].
*   `dirs`: Ray directions at sampled points, shape `[M, 3]` [S1, unofficial].
*   `deltas`: Step sizes (distances) at sampled points, shape `[M]` [S1, unofficial].
*   `rays`: Metadata buffer, shape `[N, 3]`. Each row `i` contains `[ray_index, start_point_index, num_steps]` [S1, unofficial].

### Data Structures
*   **Grid**: A 3D array of floats representing density. The implementation uses a single resolution `128x128x128` grid [S1, unofficial]. Accessed via linear index `nx * H * H + ny * H + nz` [S1, unofficial].
*   **Rays Metadata**: A 1D array of size `3 * N` storing the start index and step count for each ray in the output buffers [S1, unofficial].

### Parameters
*   `bound`: Scene half-width [S1, unofficial].
*   `rbound`: `1.0f / bound` [S1, unofficial].
*   `dt_min`: Minimum step size in world units. Calculated as `MIN_STEPSIZE() * bound`, where `MIN_STEPSIZE() = 2 * sqrt(3) / MAX_STEPS()` [S1, unofficial].
*   `dt_max`: Maximum step size. Calculated as `2 * bound / (H - 1)` [S1, unofficial].
*   `dt_gamma`: Scaling factor for adaptive step size. If `bound > 1`, `dt_gamma = DT_GAMMA()`, else `0.0f` [S1, unofficial].

### Algorithm Steps

1.  **Ray-Box Intersection**:
    For each ray `n` with origin `ox, oy, oz` and direction `dx, dy, dz`:
    *   Compute inverse direction components: `rdx = 1.0f / dx`, `rdy = 1.0f / dy`, `rdz = 1.0f / dz`.
    *   Compute near and far intersections for each axis with bounding box `[-bound, bound]`:
        *   `near_x = (-bound - ox) * rdx`
        *   `far_x = (bound - ox) * rdx`
        *   Swap `near_x` and `far_x` if `near_x > far_x`.
        *   Repeat for `y` and `z`.
    *   Compute entry and exit distances:
        *   `t_near = max(near_x, near_y, near_z)`
        *   `t_far = min(far_x, far_y, far_z)`
    *   Clamp `t_near` to `max(t_near, MIN_NEAR())`.
    *   If `t_near >= t_far`, the ray misses the volume; set `num_steps = 0` and skip to next ray.

2.  **Initialization**:
    *   Initialize step size limits: `dt_min = MIN_STEPSIZE() * bound` and `dt_max = 2 * bound / (H - 1)`.
    *   Initialize `dt_gamma` as `DT_GAMMA()` if `bound > 1`, else `0.0f`.
    *   If `perturb` is true, add random jitter to the starting position `t0` using a PCG32 random number generator seeded by ray index `n` [S1, unofficial].

3.  **First Pass: Step Estimation**:
    *   Initialize `t = t0`.
    *   Initialize `num_steps = 0`.
    *   Loop while `t < t_far` and `num_steps < MAX_STEPS()`:
        *   Calculate current position `x, y, z` clamped to `[-bound, bound]`.
        *   Map to grid indices `nx, ny, nz` using `nx = clamp(0.5 * (x * rbound + 1) * H, 0.0f, (float)(H - 1))` (and similarly for `y`, `z`).
        *   Query `density = grid[nx * H * H + ny * H + nz]`.
        *   If `density > density_thresh`, increment `num_steps` and advance `t` by `dt = clamp(t * dt_gamma, dt_min, dt_max)`.
        *   Else, calculate distance to next voxel boundary `tt` and advance `t` in small steps until `t >= tt` [S1, unofficial].
    *   Store `num_steps` for ray `n`.

4.  **Memory Allocation**:
    *   Use atomic additions to compute start indices in the output buffers.
    *   `point_index = atomicAdd(counter, num_steps)` and `ray_index = atomicAdd(counter + 1, 1)`.
    *   Store ray metadata in `rays`: `rays[ray_index * 3] = n`, `rays[ray_index * 3 + 1] = point_index`, `rays[ray_index * 3 + 2] = num_steps` [S1, unofficial].

5.  **Second Pass: Sample Writing**:
    *   Reset `t = t0`.
    *   Initialize `step = 0`.
    *   Loop while `t < t_far` and `step < num_steps`:
        *   Calculate position, grid indices, and density (same as First Pass).
        *   If `density > density_thresh`, write `x, y, z` to `xyzs`, `dx, dy, dz` to `dirs`, and `dt` to `deltas`.
        *   Advance `t` by `dt = clamp(t * dt_gamma, dt_min, dt_max)`.
        *   Increment pointers and `step`.
        *   Else, skip to next voxel boundary `tt` using the same logic as the first pass [S1, unofficial].

### Pseudocode

```python
import math

def clamp(v, lo, hi):
    return max(lo, min(hi, v))

def adaptive_ray_marching(rays_o, rays_d, grid, H, bound, density_thresh, MAX_STEPS, MIN_NEAR, DT_GAMMA, perturb=False):
    N = len(rays_o)
    rbound = 1.0 / bound
    dt_min = (2.0 * math.sqrt(3.0) / MAX_STEPS) * bound
    dt_max = 2.0 * bound / (H - 1)
    dt_gamma = DT_GAMMA if bound > 1 else 0.0
    
    rays_meta = []
    all_xyzs = []
    all_dirs = []
    all_deltas = []
    current_point_idx = 0
    
    for n in range(N):
        ox, oy, oz = rays_o[n]
        dx, dy, dz = rays_d[n]
        
        rdx = 1.0 / dx
        rdy = 1.0 / dy
        rdz = 1.0 / dz
        
        near_x = (-bound - ox) * rdx
        far_x = (bound - ox) * rdx
        if near_x > far_x: near_x, far_x = far_x, near_x
            
        near_y = (-bound - oy) * rdy
        far_y = (bound - oy) * rdy
        if near_y > far_y: near_y, far_y = far_y, near_y
            
        near_z = (-bound - oz) * rdz
        far_z = (bound - oz) * rdz
        if near_z > far_z: near_z, far_z = far_z, near_z
            
        t_near = max(near_x, near_y, near_z)
        t_far = min(far_x, far_y, far_z)
        t_near = max(t_near, MIN_NEAR)
        
        if t_near >= t_far:
            rays_meta.append([n, current_point_idx, 0])
            continue
            
        t = t_near
        if perturb:
            t += (0.5 - (n % 1000) / 1000.0) * dt_min  # Simplified PCG32 jitter [G]
            
        num_steps = 0
        
        while t < t_far and num_steps < MAX_STEPS:
            x = clamp(ox + t * dx, -bound, bound)
            y = clamp(oy + t * dy, -bound, bound)
            z = clamp(oz + t * dz, -bound, bound)
            
            nx = int(clamp(0.5 * (x * rbound + 1.0) * H, 0.0, H - 1))
            ny = int(clamp(0.5 * (y * rbound + 1.0) * H, 0.0, H - 1))
            nz = int(clamp(0.5 * (z * rbound + 1.0) * H, 0.0, H - 1))
            
            density = grid[nx * H * H + ny * H + nz]
            
            if density > density_thresh:
                num_steps += 1
                dt = clamp(t * dt_gamma, dt_min, dt_max)
                t += dt
            else:
                next_grid_x = nx + 1 if dx > 0 else nx
                next_grid_y = ny + 1 if dy > 0 else ny
                next_grid_z = nz + 1 if dz > 0 else nz
                
                x_bound = (next_grid_x / H - 0.5) * 2 * bound
                y_bound = (next_grid_y / H - 0.5) * 2 * bound
                z_bound = (next_grid_z / H - 0.5) * 2 * bound
                
                t_x = (x_bound - ox) / dx if dx != 0 else float('inf')
                t_y = (y_bound - oy) / dy if dy != 0 else float('inf')
                t_z = (z_bound - oz) / dz if dz != 0 else float('inf')
                
                tt = min(t_x, t_y, t_z)
                while t < tt:
                    t += dt_min
                    
        start_idx = current_point_idx
        rays_meta.append([n, start_idx, num_steps])
        current_point_idx += num_steps
        
        t = t_near
        step = 0
        while t < t_far and step < num_steps:
            x = clamp(ox + t * dx, -bound, bound)
            y = clamp(oy + t * dy, -bound, bound)
            z = clamp(oz + t * dz, -bound, bound)
            
            nx = int(clamp(0.5 * (x * rbound + 1.0) * H, 0.0, H - 1))
            ny = int(clamp(0.5 * (y * rbound + 1.0) * H, 0.0, H - 1))
            nz = int(clamp(0.5 * (z * rbound + 1.0) * H, 0.0, H - 1))
            
            density = grid[nx * H * H + ny * H + nz]
            
            if density > density_thresh:
                all_xyzs.append([x, y, z])
                all_dirs.append([dx, dy, dz])
                dt = clamp(t * dt_gamma, dt_min, dt_max)
                all_deltas.append(dt)
                step += 1
                t += dt
            else:
                next_grid_x = nx + 1 if dx > 0 else nx
                next_grid_y = ny + 1 if dy > 0 else ny
                next_grid_z = nz + 1 if dz > 0 else nz
                
                x_bound = (next_grid_x / H - 0.5) * 2 * bound
                y_bound = (next_grid_y / H - 0.5) * 2 * bound
                z_bound = (next_grid_z / H - 0.5) * 2 * bound
                
                t_x = (x_bound - ox) / dx if dx != 0 else float('inf')
                t_y = (y_bound - oy) / dy if dy != 0 else float('inf')
                t_z = (z_bound - oz) / dz if dz != 0 else float('inf')
                
                tt = min(t_x, t_y, t_z)
                while t < tt:
                    t += dt_min

    return all_xyzs, all_dirs, all_deltas, rays_meta
```

### Edge Cases and Pitfalls
*   **Empty Rays**: Rays that do not intersect the bounding box or have `num_steps == 0` are handled by storing `0` steps in metadata. The composite kernel checks for this and returns early [S1, unofficial].
*   **Max Steps Exceeded**: If a ray requires more than `MAX_STEPS` to traverse the volume, the loop terminates. The composite kernel checks `offset + num_steps >= M` to prevent buffer overflows [S1, unofficial].
*   **Density Threshold**: The source notes uncertainty about how to decide `density_thresh` (`// TODO: how to decide this threshold ?`) [S1, unofficial]. The default is `10.0f`.
*   **Precision**: Grid index mapping uses floating-point arithmetic. Clamping is essential to prevent out-of-bounds access.

## Operating characteristics
*   **Time Complexity**: Two passes over the rays. The first pass estimates steps, the second writes them. The cost is proportional to the number of voxels traversed, but empty space is skipped. The adaptive step size reduces the number of samples in dense regions compared to uniform sampling if `dt_gamma` is small, but increases them if `dt_gamma` is large [S1, unofficial].
*   **Memory Complexity**: Output buffers `xyzs`, `dirs`, `deltas` are sized to `M`, the total number of steps across all rays. `M` is determined dynamically [S1, unofficial].
*   **Strengths**: Efficiently skips empty space. Adaptive step size allows for finer sampling near the camera (small `t`) and coarser sampling far away, or vice versa depending on `dt_gamma` [S1, unofficial].
*   **Limitations**: Requires two passes (or atomic operations) to determine memory layout. The density grid must be available and updated. The choice of `density_thresh` is heuristic [S1, unofficial].

## Background
This method is part of the Instant Neural Graphics Primitives (instant-ngp) implementation, specifically the CUDA kernel `march_rays_train` [S1, unofficial]. It is designed for training NeRF models with hash encodings, where efficient sampling is critical for performance. The implementation assumes a scene bounded in `[-bound, bound]` and uses a single resolution density grid for pruning [S1, unofficial].
