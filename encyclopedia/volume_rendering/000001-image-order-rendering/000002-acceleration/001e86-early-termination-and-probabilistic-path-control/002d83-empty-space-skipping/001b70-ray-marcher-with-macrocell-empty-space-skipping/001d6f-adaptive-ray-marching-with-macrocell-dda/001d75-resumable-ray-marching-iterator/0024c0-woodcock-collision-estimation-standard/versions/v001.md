# Woodcock Collision Estimation (Standard)
Also called: castRayWoodcock
## Overview
A ray marching technique for volume rendering that uses Woodcock collision estimation (delta tracking) to skip empty space, avoiding the need for spatial acceleration structures for sampling but requiring a global maximum density estimate [S1, unofficial]. It differs from sibling methods like [Adaptive Ray Marching with Voxel Skipping](3870-adaptive-ray-marching-with-voxel-skipping.md) by not requiring hierarchical traversal or voxel grid lookups, instead relying on probabilistic step sizing based on a global density bound.
## How it works
**Inputs:** Ray origin $\mathbf{o}$, ray direction $\mathbf{d}$ (normalized), ray near/far clip planes $t_{near}, t_{far}$, volume bounding box $B$, global maximum density $\rho_{max}$, transfer function $TF(\rho) \rightarrow (C, \alpha)$, random number generator `sampler`, step size setting $S_{step}$, density scale $S_{dens}$, and epsilon $\epsilon = 0.0001$ [S1, unofficial].
**Outputs:** Boolean indicating if a collision (interaction) occurred, and the intersection position $\mathbf{p}$ if true.

**Data Structures:**
*   `Ray`: struct with fields `origin` (Vec3), `direction` (Vec3).
*   `Sampler`: object with method `nextFloat()` returning uniform random float in $[0, 1)$.
*   `Settings`: struct with fields `stepSize` (float), `densityScale` (float).

**Steps:**
1.  Compute the intersection of the ray with the volume's bounding box $B$. Let $t_{min}$ and $t_{max}$ be the entry and exit parameters. If the ray does not intersect $B$, return false [S1, unofficial].
2.  Clamp $t_{min}$ to $t_{near}$ and $t_{max}$ to $t_{far}$. If $t_{min} \ge t_{max}$, return false [S1, unofficial].
3.  Initialize the current ray parameter $t$. Calculate the initial offset using exponential distribution sampling:
    $$ t = t_{min} + (-\ln(u_1)) \cdot S_{step} $$
    where $u_1 = \text{sampler.nextFloat()}$ [S1, unofficial].
4.  Loop while $t \le t_{max}$:
    a. Calculate position $\mathbf{p} = \mathbf{o} + \mathbf{d} \cdot t$.
    b. Sample the volume density $\rho$ at $\mathbf{p}$.
    c. Evaluate the transfer function: $(C, \alpha) = TF(\rho)$. Let $w = \alpha$ be the opacity weight [S1, unofficial].
    d. Perform the collision test. Calculate the acceptance probability $P_{acc}$:
       $$ P_{acc} = w \cdot \frac{1}{\rho_{max}} \cdot S_{dens} \cdot S_{step} $$
       Generate $u_2 = \text{sampler.nextFloat()}$.
       If $u_2 < P_{acc}$, record the intersection at $\mathbf{p}$ and return true [S1, unofficial].
    e. If no collision, advance $t$ by a random step size scaled by the inverse maximum density:
       $$ t = t + (-\ln(u_3)) \cdot \frac{1}{\rho_{max}} \cdot S_{step} $$
       where $u_3 = \text{sampler.nextFloat()}$ [S1, unofficial].
5.  If the loop completes without a collision, return false [S1, unofficial].

**Parameters:**
*   $\epsilon = 0.0001$: Small epsilon to prevent infinite loops or precision issues [S1, unofficial].
*   $\rho_{max}$: Global maximum density, initialized to $1.0$ if not provided [S1, unofficial].
*   $S_{step}$: Base step size setting.
*   $S_{dens}$: Density scale setting.

**Edge Cases:**
*   If $\rho_{max} = 0$, division by zero occurs. Guard against this by ensuring $\rho_{max} \ge \epsilon$ [G].
*   If $P_{acc} > 1$, the probability is invalid. Clamp $P_{acc}$ to $1.0$ or ensure $S_{step}$ and $S_{dens}$ are chosen such that $w \cdot \frac{1}{\rho_{max}} \cdot S_{dens} \cdot S_{step} \le 1$ [G].
*   Precision issues near $t_{max}$ may cause overshoot. Use $\epsilon$ to clamp $t$ or check bounds strictly [S1, unofficial].
