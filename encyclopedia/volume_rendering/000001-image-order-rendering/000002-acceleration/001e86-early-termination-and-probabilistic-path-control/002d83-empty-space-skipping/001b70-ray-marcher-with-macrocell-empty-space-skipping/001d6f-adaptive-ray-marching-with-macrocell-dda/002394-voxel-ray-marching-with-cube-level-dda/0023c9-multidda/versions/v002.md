# MultiDDA

Also called: Nested DDA for hierarchical grids, Two-level DDA with brickmap

## Overview
MultiDDA is a ray traversal algorithm for sparse voxel grids that uses a two-level Digital Differential Analyzer (DDA) to skip empty space efficiently [S1, unofficial]. It builds on [Voxel Ray Marching with Cube-Level DDA](3069-voxel-ray-marching-with-cube-level-dda.md) by structuring the grid into bricks of $8^3$ voxels, allowing the ray to step through the top-level brick grid before entering the inner voxel loop [S1, unofficial]. It differs from its parent by explicitly separating the traversal into two distinct DDA loops: one for the brick map and one for the voxel sub-grid within occupied bricks [S1, unofficial].

## How it works
**Inputs:** Ray origin $\mathbf{o}$, ray direction $\mathbf{d}$ (normalized), brick map dimensions, brick size $B=8$ [S1, unofficial].
**Outputs:** Sequence of occupied voxel coordinates $(x, y, z)$ intersected by the ray [G].

**Data Structures:**
1. **Brick Map:** 3D array of size $\lceil W/B \rceil \times \lceil H/B \rceil \times \lceil D/B \rceil$ storing occupancy flags (boolean or bitmask) for each $B^3$ block [S1, unofficial].
2. **Voxel Data:** Flat or sparse array storing per-voxel properties (e.g., density, color) [G].

**Algorithm:**
1. **Initialize Brick DDA:** Compute initial brick coordinates $(bx, by, bz)$ containing $\mathbf{o}$. Compute step directions $(dx, dy, dz)$ and initial $t$-values for crossing brick boundaries [G].
2. **Brick Traversal Loop:** While the ray remains within grid bounds:
   a. Check if the current brick $(bx, by, bz)$ is occupied.
   b. If occupied, enter the **Voxel Traversal Loop** starting from the ray's entry point into the brick.
   c. Advance the brick DDA to the next brick along the ray.
3. **Voxel Traversal Loop (Inner):**
   a. Initialize voxel DDA relative to the brick entry point.
   b. Compute initial voxel coordinates $(vx, vy, vz)$ and $\Delta t$ values for crossing voxel boundaries.
   c. While the ray parameter $t$ is less than the brick exit $t$:
      i. Process the current voxel $(vx, vy, vz)$ [G].
      ii. Advance the voxel DDA to the next voxel.
   d. Exit when the ray leaves the brick.

**Formulas:**
*   Brick coordinates: $bx = \lfloor x / B \rfloor$, $by = \lfloor y / B \rfloor$, $bz = \lfloor z / B \rfloor$ [G].
*   Voxel coordinates within brick: $vx = \lfloor (x - bx \cdot B) / v \rfloor$, etc. [G].
*   DDA step: $t_{next} = t_{current} + \Delta t_{min}$, where $\Delta t_{min}$ is the smallest positive $t$ to cross a boundary in $x, y,$ or $z$ [G].
*   Distance to next boundary: $t_{max} = (t_{next\_boundary} - t_{origin}) / d$ [G].
*   Delta $t$ per cell: $\Delta t = 1 / |d|$ [G].

**Parameters:**
*   Brick size $B=8$ [S1, unofficial].
*   Voxel size $v=1$ [G].

**Edge Cases:**
*   **Ray origin outside grid:** Return empty sequence [G].
*   **Empty bricks:** Skip inner loop entirely [S1, unofficial].
*   **Ray grazing boundaries:** Standard DDA handles this; use epsilon bias if double-counting occurs [G].

**Pseudocode:**
```python
import math

def multi_dda(ray_origin, ray_direction, brick_map, brick_size=8):
    # Standard DDA initialization [G]
    bx = int(ray_origin[0] // brick_size)
    by = int(ray_origin[1] // brick_size)
    bz = int(ray_origin[2] // brick_size)
    
    step_x = 1 if ray_direction[0] > 0 else -1
    step_y = 1 if ray_direction[1] > 0 else -1
    step_z = 1 if ray_direction[2] > 0 else -1
    
    t_max_x = (bx * brick_size + (brick_size if step_x > 0 else 0) - ray_origin[0]) / ray_direction[0] if ray_direction[0] != 0 else math.inf
    t_max_y = (by * brick_size + (brick_size if step_y > 0 else 0) - ray_origin[1]) / ray_direction[1] if ray_direction[1] != 0 else math.inf
    t_max_z = (bz * brick_size + (brick_size if step_z > 0 else 0) - ray_origin[2]) / ray_direction[2] if ray_direction[2] != 0 else math.inf
    
    delta_t_x = brick_size / abs(ray_direction[0]) if ray_direction[0] != 0 else math.inf
    delta_t_y = brick_size / abs(ray_direction[1]) if ray_direction[1] != 0 else math.inf
    delta_t_z = brick_size / abs(ray_direction[2]) if ray_direction[2] != 0 else math.inf
    
    while True:
        # Bounds check [G]
        if not (0 <= bx < brick_map.shape[0] and 0 <= by < brick_map.shape[1] and 0 <= bz < brick_map.shape[2]):
            break
            
        if brick_map[bx, by, bz]:
            # Compute brick entry/exit [G]
            brick_origin_x = bx * brick_size
            brick_origin_y = by * brick_size
            brick_origin_z = bz * brick_size
            
            t_enter = 0.0
            t_exit = math.inf
            for i in range(3):
                if ray_direction[i] != 0:
                    t1 = (brick_origin_x if i==0 else brick_origin_y if i==1 else brick_origin_z) / ray_direction[i]
                    t2 = (brick_origin_x + brick_size if i==0 else brick_origin_y + brick_size if i==1 else brick_origin_z + brick_size) / ray_direction[i]
                    t_enter = max(t_enter, min(t1, t2))
                    t_exit = min(t_exit, max(t1, t2))
                else:
                    if ray_origin[i] < (brick_origin_x if i==0 else brick_origin_y if i==1 else brick_origin_z) or \
                       ray_origin[i] >= (brick_origin_x + brick_size if i==0 else brick_origin_y + brick_size if i==1 else brick_origin_z + brick_size):
                        return [] # Ray misses brick
            
            if t_enter < t_exit:
                # Initialize voxel DDA [G]
                vx = int((ray_origin[0] + t_enter * ray_direction[0]) // 1)
                vy = int((ray_origin[1] + t_enter * ray_direction[1]) // 1)
                vz = int((ray_origin[2] + t_enter * ray_direction[2]) // 1)
                
                v_step_x = 1 if ray_direction[0] > 0 else -1
                v_step_y = 1 if ray_direction[1] > 0 else -1
                v_step_z = 1 if ray_direction[2] > 0 else -1
                
                v_t_max_x = (vx + (1 if v_step_x > 0 else 0)) - (ray_origin[0] + t_enter * ray_direction[0])
                v_t_max_y = (vy + (1 if v_step_y > 0 else 0)) - (ray_origin[1] + t_enter * ray_direction[1])
                v_t_max_z = (vz + (1 if v_step_z > 0 else 0)) - (ray_origin[2] + t_enter * ray_direction[2])
                
                v_delta_t_x = 1.0 / abs(ray_direction[0]) if ray_direction[0] != 0 else math.inf
                v_delta_t_y = 1.0 / abs(ray_direction[1]) if ray_direction[1] != 0 else math.inf
                v_delta_t_z = 1.0 / abs(ray_direction[2]) if ray_direction[2] != 0 else math.inf
                
                while t_enter < t_exit:
                    # Process voxel (vx, vy, vz) [G]
                    
                    # Advance voxel DDA
                    if v_t_max_x < v_t_max_y:
                        if v_t_max_x < v_t_max_z:
                            vx += v_step_x
                            t_enter += v_delta_t_x
                            v_t_max_x += v_delta_t_x
                        else:
                            vz += v_step_z
                            t_enter += v_delta_t_z
                            v_t_max_z += v_delta_t_z
                    else:
                        if v_t_max_y < v_t_max_z:
                            vy += v_step_y
                            t_enter += v_delta_t_y
                            v_t_max_y += v_delta_t_y
                        else:
                            vz += v_step_z
                            t_enter += v_delta_t_z
                            v_t_max_z += v_delta_t_z
                            
        # Advance brick DDA
        if t_max_x < t_max_y:
            if t_max_x < t_max_z:
                bx += step_x
                t_max_x += delta_t_x
            else:
                bz += step_z
                t_max_z += delta_t_z
        else:
            if t_max_y < t_max_z:
                by += step_y
                t_max_y += delta_t_y
            else:
                bz += step_z
                t_max_z += delta_t_z
```

## Subtopics

### [VRI Ray Advancement](3187-vri-ray-advancement.md)
A three-level hierarchy method that separates traversal into draining I1 DDA, stepping I2 DDA, and advancing root entries. Choose when deeper hierarchy is needed for very large scenes.

## Operating characteristics
*   **Time Complexity:** $O(N_{bricks} + N_{voxels})$, where $N_{bricks}$ is the number of bricks traversed and $N_{voxels}$ is the number of occupied voxels [G].
*   **Memory Complexity:** $O(W \cdot H \cdot D / B^3)$ for the brick map, plus $O(N_{voxels})$ for voxel data [G].
*   **Performance:** Offers good performance relative to its simplicity [S1, unofficial]. However, it suffers from SIMD divergence due to control-flow divergence when entering the inner traversal loop, as not all SIMD lanes hit a brick at the same time, causing stalls [S1, unofficial].
*   **Strengths:** Simple to implement, effective space skipping for coherent rays [S1, unofficial].
*   **Limitations:** Poor performance with incoherent rays due to SIMD divergence [S1, unofficial].
*   **When to use:** Coherent ray batches, simple hardware, or when implementation complexity must be minimized [S1, unofficial].
*   **When not to use:** Highly incoherent rays, SIMD-heavy architectures, or scenes with very large empty spaces where deeper hierarchy (e.g., [eXtendedBrickMap](3070-extended-brickmap.md)) is beneficial [S1, unofficial].

## Background
MultiDDA is part of the VoxelRT project, which benchmarks various voxel rendering acceleration structures [S1, unofficial]. It is a straightforward extension of flat DDA to a hierarchical grid, designed to balance simplicity and performance for brick-based voxel representations [S1, unofficial].
