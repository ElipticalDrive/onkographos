# Voxel Ray Marching with Cube-Level DDA

Also called: 2-Level DDA Voxel Rendering, DDA voxel traversal, Two-level DDA

## Overview
Voxel Ray Marching with Cube-Level DDA is a GPU-based fragment shader technique that renders voxel volumes by casting rays through a hierarchical grid of voxel cubes and individual voxels [S1, unofficial]. It uses a two-level Digital Differential Analyzer (DDA) to efficiently skip empty space: the outer loop traverses 16x16x16 voxel cubes to find occupied regions, while the inner loop traverses individual voxels within those cubes to find the first opaque surface [S1, unofficial]. This method differs from its parent [Adaptive Ray Marching with Macrocell DDA](1500-adaptive-ray-marching-with-macrocell-dda.md) by using fixed-size macrocells (cubes) rather than adaptive step sizes based on opacity bounds, and from its siblings [Resumable Ray Marching Iterator](1505-resumable-ray-marching-iterator.md) and [Network Ray Marching Iterator](1510-network-ray-marching-iterator.md) by relying on a strict two-level DDA structure implemented entirely in the fragment shader [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input Geometry:** A simple box mesh with 8 vertices and 12 faces, rendered with front-face culling (`cull_front`) to allow viewing from inside or outside [S1, unofficial].
*   **Input Data:** Voxel grid data accessed via samplers (e.g., `get_cube`, `get_voxel`) which return voxel existence, opacity, and material properties [S1, unofficial].
*   **Output:** Depth, light vertex position, and PBR material properties (Albedo, Emission, Normal, Roughness, Specular, Metallic, AO) for the first opaque voxel hit, or transparent blending results if no opaque voxel is found [S1, unofficial].

**Data Structures:**
*   **DDA Structure (`DDA`):** Contains position (integer coordinates), step direction, and distance to the next voxel/cube boundary.
*   **Cube Size:** Fixed at 16x16x16 voxels [S1, unofficial].
*   **Max Steps:** 49 steps per cube and 49 steps per voxel [S1, unofficial].

**Vertex Shader Precomputation:**
1.  Calculate `MODEL_SIZE_REC = 1.0 / vec3(model_size)` [S1, unofficial].
2.  Pass `MODELVIEW_MATRIX` as `_MODELVIEW_MATRIX` [S1, unofficial].
3.  Compute `RAY` in model space: `RAY = safe_vector(VERTEX - (inverse(MODEL_MATRIX) * vec4(CAMERA_POSITION_WORLD, 1.0)).xyz)` [S1, unofficial].
4.  Store `VERTEX` as `BACK` [S1, unofficial].

**Fragment Shader Algorithm:**

1.  **Ray Initialization:**
    *   Compute `ray_rec = 1.0 / ray` [S1, unofficial].
    *   Compute `front = to_front_face(BACK, ray, ray_rec)` to find the entry point of the ray into the voxel box [S1, unofficial].
    *   Initialize outer DDA structure `ddc` using `dda_init(ddc, model_size, front, ray, ray_rec)` [S1, unofficial].

2.  **Outer Loop (Cube Traversal):**
    *   Initialize `csteps = 0`, `found = false`, `no_more_cubes = false` [S1, unofficial].
    *   Loop while `csteps < 49`:
        *   Call `get_cube(ddc.position, layer, has_opaque)` to check if the current cube contains any opaque voxels [S1, unofficial].
        *   If `has_opaque` is true:
            *   Initialize inner DDA structure `ddv` using `dda_init_inner(ddv, ddc, model_size, MODEL_SIZE_REC, ray, ray_rec, origin)` [S1, unofficial].
            *   Initialize `vsteps = 0` [S1, unofficial].
            *   **Inner Loop (Voxel Traversal):**
                *   Loop while `vsteps < 49`:
                    *   Call `get_voxel(ddv.position, layer, tpos, voxel, color, opaque)` to retrieve voxel data [S1, unofficial].
                    *   If `opaque` is true:
                        *   Calculate hit point: `hit = origin + dda_voxel_face_hit(ddv, vec3(1.0 / 16.0)) * MODEL_SIZE_REC` [S1, unofficial].
                        *   Transform `hit` to view space: `light_vertex = calc_vertex(hit, PROJECTION_MATRIX, _MODELVIEW_MATRIX, depth)` [S1, unofficial].
                        *   If `light_vertex.z < 0.0` (in front of camera):
                            *   Set `DEPTH = depth`, `LIGHT_VERTEX = light_vertex` [S1, unofficial].
                            *   Compute normals: `dda_voxel_face_normals(ddv, NORMALS, NORMAL, TANGENT, BINORMAL)` [S1, unofficial].
                            *   Compute UVs: `dda_voxel_face_uv(ddv, model_size, hit, face)` [S1, unofficial].
                            *   Fetch material: `get_opaque_material(tpos, voxel, color, face, uv, ALBEDO, EMISSION, normal_map, rsma)` [S1, unofficial].
                            *   Set `found = true` and `break` inner loop [S1, unofficial].
                        *   Else:
                            *   Step to next voxel: `dda_step(ddv)` [S1, unofficial].
                            *   If `dda_step(ddv)` returns true (end of cube), `break` inner loop [S1, unofficial].
                    *   Else (transparent/empty):
                        *   Step to next voxel: `dda_step(ddv)` [S1, unofficial].
                        *   If `dda_step(ddv)` returns true, `break` inner loop [S1, unofficial].
        *   Else (no opaque voxels in cube):
            *   Step to next cube: `no_more_cubes = dda_step(ddc)` [S1, unofficial].
        *   If `found` or `no_more_cubes` is true, `break` outer loop [S1, unofficial].

3.  **Finalization:**
    *   If `!found`, `discard` fragment [S1, unofficial].
    *   For transparent pass, accumulate transmittance and blend with background if no opaque voxel was hit [S1, unofficial].

**Pseudocode:**

```python
# Vertex Shader
def vertex_shader(VERTEX, MODEL_MATRIX, MODELVIEW_MATRIX, CAMERA_POSITION_WORLD, model_size):
    # Pass matrices to fragment shader
    _MODELVIEW_MATRIX = MODELVIEW_MATRIX
    NORMALS = normalize(MODELVIEW_MATRIX[0:3, 0:3])
    MODEL_SIZE_REC = 1.0 / vec3(model_size)
    BACK = VERTEX
    # Ray in model space
    RAY = safe_vector(VERTEX - (inverse(MODEL_MATRIX) * vec4(CAMERA_POSITION_WORLD, 1.0)).xyz)
    VERTEX = MODELVIEW_MATRIX * vec4(VERTEX, 1.0)

# Fragment Shader
def fragment_shader(BACK, RAY, model_size, PROJECTION_MATRIX, _MODELVIEW_MATRIX):
    ray = RAY
    ray_rec = 1.0 / ray
    front = to_front_face(BACK, ray, ray_rec)
    
    ddc = dda_init(model_size, front, ray, ray_rec)
    found = False
    no_more_cubes = False
    
    for csteps in range(49):
        layer, has_opaque = get_cube(ddc.position)
        
        if has_opaque:
            ddv, origin = dda_init_inner(ddc, model_size, MODEL_SIZE_REC, ray, ray_rec)
            
            for vsteps in range(49):
                tpos, voxel, color, opaque = get_voxel(ddv.position, layer)
                
                if opaque:
                    hit = origin + dda_voxel_face_hit(ddv, vec3(1.0 / 16.0)) * MODEL_SIZE_REC
                    light_vertex = calc_vertex(hit, PROJECTION_MATRIX, _MODELVIEW_MATRIX)
                    
                    if light_vertex.z < 0.0:
                        DEPTH = light_vertex.z # or depth value
                        LIGHT_VERTEX = light_vertex
                        NORMAL, TANGENT, BINORMAL = dda_voxel_face_normals(ddv)
                        uv, face = dda_voxel_face_uv(ddv, model_size, hit)
                        ALBEDO, EMISSION, normal_map, rsma = get_opaque_material(tpos, voxel, color, face, uv)
                        found = True
                        break
                else:
                    if dda_step(ddv):
                        break
            if found:
                break
        else:
            no_more_cubes = dda_step(ddc)
            
        if found or no_more_cubes:
            break
            
    if not found:
        discard()
```

## Subtopics

### [MultiDDA](3123-multidda.md)
MultiDDA is a ray traversal algorithm for sparse voxel grids that uses a two-level Digital Differential Analyzer (DDA) to skip empty space efficiently. It builds on [Voxel Ray Marching with Cube-Level DDA](3069-voxel-ray-marching-with-cube-level-dda.md) by structuring the grid into bricks of $8^3$ voxels, allowing the ray to step through the top-level brick grid before entering the inner voxel loop. It differs from its parent by explicitly separating the traversal into two distinct DDA loops: one for the brick map and one for the voxel sub-grid within occupied bricks.

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of cubes and voxels traversed along the ray, bounded by a maximum of 49 steps per cube and 49 steps per voxel [S1, unofficial].
*   **Memory Complexity:** Low, as it operates entirely in the fragment shader with minimal state storage [S1, unofficial].
*   **Performance:** Efficient for sparse voxel grids due to empty space skipping at the cube level [S1, unofficial].
*   **Strengths:** Simple implementation, GPU-friendly, allows runtime voxel changes, supports viewing from inside or outside the volume [S1, unofficial].
*   **Limitations:** Fixed cube size (16x16x16) may not be optimal for all grid densities; transparency handling relies on screen texture sampling which can have limitations [S1, unofficial].
*   **When to use:** Real-time voxel rendering in games or applications where performance is critical and voxel data is sparse [S1, unofficial].
*   **When not to use:** When adaptive step sizes are required for highly non-uniform voxel densities, or when complex transparency effects beyond simple transmittance are needed [S1, unofficial].

## Background
This method is based on a 2-level DDA algorithm implemented 100% on the GPU as a fragment shader, as described in the Godot Voxel addon documentation [S1, unofficial]. It was developed by Viktor Ferenczi for the Godot Engine [S1, unofficial]. The approach allows for good performance and enables runtime changes to voxels at a relatively low cost [S1, unofficial].
