# Adaptive Ray Marching with Macrocell DDA

Also called: Adaptive Macrocell Ray Marching

## Overview
Adaptive Ray Marching with Macrocell DDA is a ray marching algorithm that uses a 3D Digital Differential Analyzer (DDA) to traverse macrocells of a volume [S1]. It adapts the sampling step size based on an opacity upper bound estimate for the current macrocell to skip empty or low-opacity regions [S1]. It solves the problem of inefficient sampling in sparse or low-opacity regions by skipping empty macrocells entirely and reducing sample counts in low-opacity ones [S1]. Unlike its parent [Ray Marcher with Macrocell Empty Space Skipping](1009-ray-marcher-with-macrocell-empty-space-skipping.md), which primarily focuses on binary empty-space skipping, this method introduces granularity by adapting the step size within non-empty cells [S1]. It differs from [Triangulated Active Brick Boundary Mesh for Space Skipping](1426-triangulated-active-brick-boundary-mesh-for-space-skipping.md) by using a regular grid structure rather than a mesh [S2].

## How it works
The method traverses a volume using a hierarchical approach: a coarse macrocell grid guides the ray, and within each active macrocell, samples are taken at adaptive intervals [S1].

### Inputs and Outputs
*   **Input**: Ray origin $\mathbf{o}$, ray direction $\mathbf{d}$, near plane $t_{min}$, far plane $t_{max}$ [S1].
*   **Input**: Volume data structure containing macrocell metadata (dimensions, spacing reciprocals, opacity upper bounds) [S1].
*   **Output**: Accumulated color and opacity for the ray [S1].

### Data Structures
The core data structure is the `DeviceVolume` (or equivalent), which must contain:
*   `macrocell_dims`: A 3D vector representing the number of macrocells in x, y, and z dimensions [S1].
*   `macrocell_spacings_rcp`: A 3D vector storing the reciprocal of the macrocell spacing in world units, used to transform ray origin and direction into macrocell index space via multiplication [S1].
*   `opacity_upper_bounds`: A 3D array (or flattened 1D array) mapping macrocell indices to a scalar value representing the maximum possible opacity contribution of that cell [S1].

### Parameters
*   `step`: The base sampling step size in world units [S1].
*   `float_epsilon`: A small constant used to determine if a cell is effectively empty [S1].
*   `ADAPTIVE_SAMPLING`: A preprocessor macro that enables or disables the macrocell-based adaptive sampling logic; if defined, the adaptive path is taken, otherwise fixed-step marching is used [S1].

### Algorithm Steps
1.  **Transform Ray to Macrocell Space**: Calculate the ray origin and direction in macrocell index space: $\mathbf{m}_{org} = \mathbf{o} \times \text{macrocell\_spacings\_rcp}$ and $\mathbf{m}_{dir} = \mathbf{d} \times \text{macrocell\_spacings\_rcp}$ [S1].
2.  **Initialize DDA**: Initialize a 3D DDA iterator with $\mathbf{m}_{org}$, $\mathbf{m}_{dir}$, $t_{min}$, $t_{max}$, and `macrocell_dims` [S1].
3.  **Iterate Macrocells**: For each macrocell $(cell, t_0, t_1)$ returned by the DDA, retrieve the opacity upper bound $r = \text{opacityUpperBound}(cell)$ [S1].
4.  **Skip Empty Cells**: If $|r| \le \text{float\_epsilon}$, the cell is considered empty and skipped [S1].
5.  **Determine Step Size**: Estimate the adaptive step size: $ss = \text{sample\_size\_scaler}(\text{adaptiveSamplingRate}(step, r), t_0, t_1)$ [S1].
6.  **Initialize Interval**: Set $t = (t_x, t_y) = (t_0, \min(t_1, t_0 + ss))$ [S1].
7.  **Sample Within Macrocell**: Loop while $t_y > t_x$: evaluate volume at $t_x$, accumulate color/opacity, update $t_x = t_y$, update $t_y = \min(t_x + ss, t_1)$ [S1].
8.  **Non-Adaptive Fallback**: If `ADAPTIVE_SAMPLING` is false, initialize $t = (t_{min}, \min(t_{max}, t_{min} + step))$ and loop while $(t_y > t_x) \land \text{body}(t)$, updating $t_x = t_y$ and $t_y = \min(t_x + step, t_{max})$ [S1].

### Pseudocode
```python
def adaptive_ray_march_with_macrocell_dda(ray_origin, ray_direction, t_min, t_max, volume):
    # 1. Transform to macrocell space
    m_org = ray_origin * volume.macrocell_spacings_rcp
    m_dir = ray_direction * volume.macrocell_spacings_rcp
    
    # 2. Initialize DDA iterator
    # Yields tuples of (cell_index, t_enter, t_exit)
    dda = dda3(m_org, m_dir, t_min, t_max, volume.macrocell_dims)
    
    accumulated_color = vec3(0.0)
    accumulated_opacity = 0.0
    
    # 3. Traverse macrocells
    for cell_index, t_enter, t_exit in dda:
        # 4. Get opacity upper bound
        r = volume.opacity_upper_bounds[cell_index]
        
        # 5. Skip empty cells
        if abs(r) <= float_epsilon:
            continue
            
        # 6. Calculate adaptive step size
        # [G] Standard heuristic: increases step size for lower opacity bounds
        base_step = adaptive_sampling_rate(volume.base_step, r)
        # [G] Clamps step to fit within [t_enter, t_exit]
        step_size = sample_size_scaler(base_step, t_enter, t_exit)
        
        # 7. Initialize sampling interval
        t_curr = t_enter
        t_next = min(t_exit, t_curr + step_size)
        
        # 8. Loop while interval is valid
        while t_next > t_curr:
            # Evaluate volume density and transfer function at t_curr
            density = sample_volume(volume, ray_origin + ray_direction * t_curr)
            color, alpha = transfer_function(density)
            
            # Standard front-to-back volume compositing [G]
            accumulated_color += color * alpha * (1.0 - accumulated_opacity)
            accumulated_opacity += alpha * (1.0 - accumulated_opacity)
            
            if accumulated_opacity >= 1.0:
                return accumulated_color
                
            # Update interval
            t_curr = t_next
            t_next = min(t_curr + step_size, t_exit)
            
    return accumulated_color
```

### Edge Cases and Pitfalls
*   **Precision**: When $t_{enter}$ and $t_{exit}$ are very close, floating-point errors may cause the loop condition $t_y > t_x$ to fail prematurely or infinitely; a small epsilon should be used for comparisons [S1].
*   **Zero Direction Components**: If `ray_direction` has a zero component, `m_dir` will have a zero component, requiring the DDA implementation to handle degenerate traversal correctly [S1].
*   **Opacity Upper Bound Accuracy**: If `opacity_upper_bounds` are inaccurate (too high), adaptive sampling may not skip enough samples; if too low, empty cells might be sampled unnecessarily [S1].

## Subtopics

### [Resumable Ray Marching Iterator](1505-resumable-ray-marching-iterator.md)
The Resumable Ray Marching Iterator is a GPU-based ray traversal method designed to handle out-of-core volume rendering by pausing ray execution when data is missing from GPU memory and resuming it in subsequent passes. It builds on [Adaptive Ray Marching with Macrocell DDA](1500-adaptive-ray-marching-with-macrocell-dda.md) by adding state persistence via Multiple Render Targets (MRTs) and Z-buffer culling to ensure only active rays are processed during data loading. Unlike [Network Ray Marching Iterator](1510-network-ray-marching-iterator.md) which may rely on different streaming heuristics, or [Macrocell Grid Traversal with Majorant Densities](1528-macrocell-grid-traversal-with-majorant-densities.md) which focuses on density bounds, this method explicitly manages the CPU-GPU synchronization required for dynamic data loading.

### [Network Ray Marching Iterator](1510-network-ray-marching-iterator.md)
The Network Ray Marching Iterator is a ray marching algorithm designed for distributed or networked rendering environments, typically leveraging GPU ray tracing APIs such as NVIDIA OptiX. It extends the parent [Adaptive Ray Marching with Macrocell DDA](1500-adaptive-ray-marching-with-macrocell-dda.md) by introducing block-level divergence control via `block_any` to manage thread synchronization across macrocell boundaries. This method is distinct from its siblings because it explicitly handles the "alive" status of rays in a distributed context, ensuring that inactive threads do not waste computation while maintaining adaptive sampling rates based on opacity upper bounds.

### [Macrocell Grid Traversal with Majorant Densities](1528-macrocell-grid-traversal-with-majorant-densities.md)
This method accelerates volumetric path tracing by combining a coarse spatial partition (macrocells) with Delta Tracking (Woodcock tracking) to skip empty or low-opacity regions more efficiently than fixed-step marching. It sets itself apart from its parent [Adaptive Ray Marching with Macrocell DDA](1500-adaptive-ray-marching-with-macrocell-dda.md) by explicitly using the alpha component of the transfer function as a majorant extinction coefficient to determine probabilistic free-flight distances, allowing larger steps in homogeneous cells while maintaining unbiased Monte Carlo estimation.

### Space Skipping with 3DDDA
Space Skipping with 3DDDA is a mechanism to skip empty regions in sparse volume data using a uniform grid and 3DDDA algorithm [S2]. The fragment shader traverses the macrocell grid using 3DDDA in an outer loop [S2]. If a macrocell is nonempty, it enters the volume rendering loop with peak finding tests between samples [S2]. To begin sampling, it finds the first $t$ to sample when entering a macrocell by solving for the maximum $x$ after $T_{enter}$: $x^2/2 + bx = T_{enter} \implies x_{tenter} = \frac{-b + \sqrt{b^2 + 2aT_{enter}}}{a}$ [S2]. It then computes the floor values $\lfloor b x_{tenter} \rfloor$, $T(\lfloor b x_{tenter} \rfloor)$ and $\frac{\partial T}{\partial x}(\lfloor b x_{tenter} \rfloor)$, then samples and increments as in Equation 17 of the source [S2]. To avoid duplicate samples, it stores the greatest $t$ at which it already sampled, and uses the maximum of that and $T_{enter}$ [S2]. The uniform grid stores min-max values of enclosed voxels, and coarse grids (e.g., $64^3$ cells) work best on the GPU [S2].

## Operating characteristics
*   **Time Complexity**: $O(N)$ where $N$ is the number of samples taken, with a significantly reduced constant factor by skipping empty macrocells and reducing samples in low-opacity regions [S1].
*   **Memory Complexity**: $O(M)$ where $M$ is the number of macrocells, as the macrocell grid is much smaller than the full volume grid [S1].
*   **Performance**: Performance gains are most significant in sparse volumes or volumes with large empty regions [S1]. Fairly coarse grids (e.g., $64^3$ cells) work best on the GPU [S2].
*   **Strengths**: Simple uniform grid structure that works well on GPUs [S2].
*   **Limitations**: Requires precomputed opacity upper bounds [S1].
*   **When to Use**: Sparse volumes, interactive rendering, and out-of-core rendering (with resumable variant) [S1, S2].

## Background
Adaptive Ray Marching with Macrocell DDA originates from the `instantvnr` project, an interactive volume visualization tool based on multi-resolution hash encoding based neural representation [S1]. The method was developed by Qi Wu, Michael J. Doyle, and Kwan-Liu Ma, and published in IEEE Transactions on Visualization and Computer Graphics in 2023 [S1]. The use of 3DDDA for space skipping in volume rendering has earlier roots, as seen in work by Knoll et al. on volume ray casting with peak finding [S2]. The integration of adaptive sampling based on opacity bounds is a key innovation in `instantvnr` to handle the sparsity of neural volume representations efficiently [S1].
