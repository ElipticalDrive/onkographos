# Orthogonal BSP Tree Construction

Also called: BSP tree conversion, Orthogonal BSP

## Overview
This method converts a set of arbitrarily positioned and sized grown boxes into an orthogonal Binary Space Partitioning (BSP) tree where every splitting plane is object-aligned [S1]. It solves the problem that arbitrary box layouts prevent trivial visibility sorting, which is required for efficient empty-space skipping and occlusion clipping in texture-based volume rendering [S1]. Unlike uniform partitioning, this method ensures that the resulting tree structure allows for deterministic front-to-back or back-to-front traversal without complex geometric intersection tests [S1].

## How it works
**Inputs:** A list of grown boxes generated by Growing Boxes Partitioning [S1]. Each box has a defined bounding box and a type (uniform, gradient, or other) based on enclosed voxel properties [S1].
**Outputs:** An orthogonal BSP tree where leaf nodes contain exactly one box (either an original grown box or a child box generated from splitting) [S1].

**Data Structures:**
*   **BSP Node:** Contains a list of boxes and a bounding box of their union, referred to as the "room" [S1].
*   **Box:** Defined by its spatial bounds, type, and an optional parent reference [S1].
*   **Hierarchy Constraint:** There is only one level of parent-child hierarchy [S1]. Parent boxes reside on non-leaf nodes; rendering uses only leaf nodes [S1]. No box can be both a child and a parent simultaneously [S1].

**Algorithm Steps:**

1.  **Initialization:** Create a root BSP node [S1]. Assign the list of all input grown boxes to the root [S1]. Calculate the root's room as the bounding box of the union of all these boxes [S1].
2.  **Node Splitting:** Split nodes until each leaf node contains exactly one box [S1]. To split a node:
    a.  Create two child nodes: `front` and `back` [S1].
    b.  **Choose Partitioning Plane:** Select an object-aligned plane that coincides with the faces of at least two boxes in the current node's list to minimize the number of boxes that need to be split [S1]. The plane splits the current node's room into two new boxes, which become the rooms of the `front` and `back` children [S1].
    c.  **Distribute Boxes:** Iterate through each box in the current node's list:
        i.  If the box is completely enclosed in the `front` room, move it to the `front` child's box list [S1].
        ii. If the box is completely enclosed in the `back` room, move it to the `back` child's box list [S1].
        iii. If the box is cut by the partitioning plane:
            1.  Create two new boxes by splitting the original box along the plane [S1].
            2.  Place one new box in the `front` child's list and the other in the `back` child's list [S1].
            3.  Manage parentage:
                *   If the original box is an original grown box (has no parent), set the original box as the parent of the two new boxes [S1].
                *   If the original box already has a parent, set that parent as the parent of the two new boxes [S1].
                *   Delete the original box from the current node's list [S1].
    d.  Repeat the splitting procedure for child nodes until every leaf node contains exactly one box [S1].
3.  **Bottom-Up Merging:** After the initial split phase, the number of leaf boxes may be significantly greater than the original count [S1]. Reduce the tree by merging child nodes if the following conditions are met:
    a.  Both children are uniform, and the merged box (union of their rooms) is still uniform [S1].
    b.  Both children are "other" boxes or both are "gradient" boxes [S1].
    c.  One of the boxes is tiny or very thin (size along one axis is smaller than a threshold) [S1].
    d.  If two child nodes being merged have different parent boxes, delete those parent boxes and make all their children parentless (i.e., they become candidates for merging at the next level up) [S1].
    e.  The type of the resulting merged box is redetermined based on the enclosed voxel properties [S1].

def is_enclosed(box_bounds, room_bounds):
    return all(box_bounds.min[i] >= room_bounds.min[i] and box_bounds.max[i] <= room_bounds.max[i] for i in range(3))

def is_cut_by_plane(box_bounds, plane):
    # plane is defined by axis `a` and coordinate `c`
    return box_bounds.min[plane.axis] < plane.c and box_bounds.max[plane.axis] > plane.c

def split_box(box_bounds, plane):
    # Returns two new bounds split along plane.axis at plane.c
    b1_min = box_bounds.min.copy()
    b1_max = box_bounds.max.copy()
    b2_min = box_bounds.min.copy()
    b2_max = box_bounds.max.copy()
    b1_max[plane.axis] = plane.c
    b2_min[plane.axis] = plane.c

def union_bounds(b1, b2):

def is_uniform(box):

    return any(box.max[i] - box.min[i] < threshold for i in range(3))

    # Split room into two boxes for children

    boxes_to_process = list(node.boxes)
    for box in boxes_to_process:
        if is_enclosed(box.bounds, front.room):
            front.boxes.append(box)
            node.boxes.remove(box)
        elif is_enclosed(box.bounds, back.room):
            back.boxes.append(box)
            node.boxes.remove(box)
        elif is_cut_by_plane(box.bounds, plane):
            box_front_bounds, box_back_bounds = split_box(box.bounds, plane)
            box_front = Box(box_front_bounds, box.type)
            box_back = Box(box_back_bounds, box.type)
            
            front.boxes.append(box_front)
            back.boxes.append(box_back)
            
            if box.parent is None:
                box_front.parent = box
                box_back.parent = box
            else:
                box_front.parent = box.parent
                box_back.parent = box.parent
                node.boxes.remove(box)

    if len(front.boxes) > 1:
        split_node(front, threshold)
    if len(back.boxes) > 1:
        split_node(back, threshold)

**Edge Cases and Pitfalls:**
*   **Hierarchy Constraint:** Ensure no box is both a child and a parent. The algorithm enforces this by retaining original grown boxes as parents of split children, while deleting intermediate split boxes from their parent lists [S1].
*   **Texture Sharing:** Child boxes share the texture of their parent with siblings to avoid replicating texels along boundaries [S1]. This prevents increased memory requirements that would result from dividing textures and replicating texels for interpolation [S1].
*   **Plane Selection:** The partitioning plane must coincide with the faces of at least two boxes to minimize splits [S1]. Failure to do so may result in excessive box fragmentation [S1].
*   **Merging Threshold:** The threshold for "tiny or very thin" boxes must be defined to prevent merging boxes that are structurally distinct but small [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources. The splitting phase depends on the number of boxes and the efficiency of plane selection [S1]. The merging phase is bottom-up [S1].
*   **Memory Complexity:** Not given in the sources. The method aims to keep the total number of boxes comparable to the original set before conversion [S1]. Texture sharing reduces memory overhead compared to replicating textures [S1].
*   **Strengths:** Enables trivial visibility sorting for 3D texture rendering by ensuring object-aligned splitting planes [S1]. Handles arbitrary box sizes and positions from adaptive partitioning [S1].
*   **Limitations:** The initial split phase may generate significantly more leaf boxes than the original input, requiring a merging phase to reduce complexity [S1].
*   **When to use:** When using adaptive partitioning (like Growing Boxes Partitioning) where boxes are not aligned to a uniform grid, and efficient visibility sorting is required for empty-space skipping [S1].

## Background
This method was introduced by Mueller et al. in the context of empty-space skipping and occlusion clipping for texture-based volume rendering [S1]. It addresses the limitation of uniform partitioning, where visibility sorting is trivial, by converting arbitrary grown boxes into a BSP tree structure that supports similar efficient traversal [S1].
