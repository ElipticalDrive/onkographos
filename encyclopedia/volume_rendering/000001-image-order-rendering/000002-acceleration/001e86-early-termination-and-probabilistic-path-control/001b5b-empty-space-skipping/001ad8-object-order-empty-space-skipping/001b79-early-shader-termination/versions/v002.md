# Early Shader Termination

Also called: Early End of Computation, Early z-test optimization, Two-pass empty space culling

## Overview
Early Shader Termination is an optimization technique that discards the execution of complex decoding shaders for fragments likely to represent empty space by using an early z-test in a two-pass rendering approach [S1]. It builds on [Object-Order Empty Space Skipping](865-object-order-empty-space-skipping.md) by adding a lightweight pre-check to avoid expensive shader execution in empty regions [G]. Compared to rendering uncompressed data, this approach initially perceives a loss in performance of a factor of 2-3 due to complex shaders and texture indirections; however, in empty regions, it results in a considerable speed-up because only one texture fetch is needed to check the mean [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A compressed volume dataset where each block (macro-cell) has an associated index texture $I$ storing metadata (specifically the mean value in the R-component) and dependent data textures $C_1, C_2$ [S1]. A slicing polygon representing the current view frustum or volume boundary [G].
*   **Output:** A rendered image where empty space fragments are skipped, and depth values are correctly updated to allow subsequent fragments to pass depth tests [G].

**Data Structures:**
*   **Index Texture $I$:** Stores block metadata. The R-component holds the mean value of the block [S1].
*   **Dependent Textures $C_1, C_2$:** Store difference information or raw data, addressed using components of $I$ [S1].

**Steps:**
1.  **First Pass (Empty Space Detection):** Render the slicing polygon twice. In the first pass, issue a simple pixel shader program [S1]. In the shader, access index texture $I$ and check the mean value stored in the R-component [S1]. If the mean value is zero, render the fragment with color and opacity set to zero. This does not affect the color buffer but sets the depth value in the depth buffer [S1]. If the mean value is not zero, discard the fragment using a `kill` instruction. This prevents the fragment from affecting the color or depth buffer [S1].
2.  **Second Pass (Complex Rendering):** Render the slicing polygon again with the complex shader [S1]. Set the depth test to `GL_GREATER` in the second pass [S1]. The early z-test only lets fragments pass that were discarded in the first pass (where mean $\neq 0$). All other fragments (where mean $= 0$) are discarded before entering the complex shader [S1].

**Pseudocode:**

```python
def early_shader_termination(fragments, index_texture_I, complex_decode_func):
    """
    Simulates the two-pass early shader termination optimization.
    fragments: list of objects with .block_id and .z (depth)
    index_texture_I: dict mapping block_id to objects with .R (mean value)
    complex_decode_func: callable that returns decoded color for non-empty blocks
    """
    depth_buffer = []
    pass1_discarded = []

    # Pass 1: Simple pixel shader
    for frag in fragments:
        mean_val = index_texture_I[frag.block_id].R
        if mean_val == 0:
            # Empty space: write depth, zero color/opacity
            depth_buffer.append(frag.z)
            pass1_discarded.append(False)
        else:
            # Non-empty space: discard via kill instruction
            # Depth buffer retains the last valid depth
            pass1_discarded.append(True)

    # Pass 2: Complex shader with depth test
    final_output = []
    for i, frag in enumerate(fragments):
        if pass1_discarded[i]:
            # Early z-test with GL_GREATER logic:
            # Hardware compares frag.z against depth_buffer.
            # Since pass 1 wrote depth for mean==0 blocks,
            # pass 2 automatically skips them via depth test.
            decoded = complex_decode_func(frag, index_texture_I)
            final_output.append(decoded)
    return final_output
```

**Parameters:**
*   **Depth Test Function:** Must be set to `GL_GREATER` in the second pass to leverage the early z-test correctly [S1].
*   **Mean Threshold:** Zero is used as the threshold for empty space [S1].

**Edge Cases and Pitfalls:**
*   **Depth Buffer Consistency:** If a fragment is discarded in the shader (via `kill`), the depth value of the fragment rendered last is still valid in the depth buffer. This must be accounted for when using depth tests, as the discarded fragment does not update the depth buffer [S1].
*   **Performance Overhead:** The two-pass approach introduces overhead. The initial performance loss compared to uncompressed rendering is a factor of 2-3 due to the complexity of the shaders and texture indirections [S1].

### [Early Scanline Termination](988-early-scanline-termination.md)
Adds spatial coherence checks along the scanline direction to skip entire segments of empty space within a macro-cell projection. It builds on Early Shader Termination by optimizing the scope of the termination check.

## Operating characteristics
*   **Time Complexity:** In empty regions, the complexity is reduced to one texture fetch per block to check the mean [S1]. In non-empty regions, the full complex shader is executed [S1].
*   **Memory Complexity:** Requires storage for the index texture $I$ and dependent textures $C_1, C_2$ [S1].
*   **Measured Performance:** On an Intel P4 1900 MHz machine, this approach saves another 5 percent of overall rendering time on average when combined with other optimizations like Early End of Computation [S2, unofficial].
*   **Strengths:** Considerable speed-up in empty regions, which are frequent in numerical simulation results [S1].
*   **Limitations:** Initial performance loss of 2-3x compared to uncompressed rendering due to shader complexity and indirections [S1]. Requires hardware support for early z-test [S1].

## Background
The technique was proposed in the context of compression domain volume rendering to address performance losses caused by complex shader programs and texture indirections [S1]. It leverages the early z-test feature available on target graphics architectures to avoid executing pixel shaders for fragments that are likely to decode empty space [S1]. The concept of terminating computation early is also discussed in the context of cell-based first-hit ray casting, where rendering ends as soon as all pixels are covered, saving approximately 5 percent of overall rendering time [S2, unofficial].
