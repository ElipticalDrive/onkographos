# Adaptive sampling and reconstruction
Also called: Weiss et al
## Overview
An end-to-end pipeline that uses neural networks to predict where high sample density is needed, convert importance values to adaptive sample positions, and reconstruct full-resolution images from sparse samples [S1, unofficial]. It differs from sibling methods by replacing heuristic error metrics with a learned importance network and a differentiable sampler, followed by a reconstruction network rather than direct ray casting [S1, unofficial].
## How it works
**Inputs and outputs:**
*   Input: A 128×128 low-resolution view of the volume (or importance map).
*   Output: A full-resolution rendered image.

**Data structures:**
1.  **Importance Network:** A neural network predicting a scalar importance value $I(x,y)$ for each pixel.
2.  **Differentiable Sampler:** Converts importance values $I$ into a set of sample positions $\{p_i\}$ and weights.
3.  **Reconstruction Network:** A neural network combining pull-push inpainting with a residual CNN to generate the final image from sparse samples.

**Parameters:**
*   Soft-max approximation parameter $\alpha \approx 50$ [S1, unofficial].
*   Sample density: 5–10% for isosurfaces, 10% for DVR [S1, unofficial].

**Steps:**
1.  **Train Importance Network:** Train a network to predict where high sample density is needed from a 128×128 input [S1, unofficial].
2.  **Generate Adaptive Samples:** Use a differentiable sampler to convert importance values to adaptive sample positions via soft-max approximation with $\alpha \approx 50$ [S1, unofficial].
3.  **Reconstruct Image:** Use a reconstruction network combining pull-push inpainting with a residual CNN to reconstruct full-resolution images from the sparse samples [S1, unofficial].

**Pseudocode:**
```python
def adaptive_sampling_and_reconstruction(volume_data, view_params):
    # 1. Generate low-res importance map
    # Input: 128x128 view
    low_res_view = render_low_res_view(volume_data, view_params, resolution=128)
    importance_map = importance_network(low_res_view)
    
    # 2. Differentiable sampling
    # Convert importance to sample positions using soft-max approximation
    # alpha is the temperature parameter for the soft-max
    alpha = 50
    sample_positions, sample_weights = differentiable_sampler(
        importance_map, 
        alpha=alpha,
        target_density=0.1  # 10% for DVR
    )
    
    # 3. Sparse rendering (optional intermediate step or direct to reconstruction)
    # The method reconstructs from sparse samples, implying the samples 
    # are used to query the volume or serve as input features.
    sparse_samples = query_volume(volume_data, sample_positions)
    
    # 4. Reconstruction
    # Combine pull-push inpainting with residual CNN
    full_res_image = reconstruction_network(sparse_samples, sample_weights, low_res_view)
    
    return full_res_image
```

**Edge cases and pitfalls:**
*   Reconstruction network overhead is approximately 90ms regardless of volume size, making it slower than optimized ray casting for volumes smaller than $1024^3$ or images smaller than $1024^2$ [S1, unofficial].
*   Quality degrades when test transfer functions use color ranges absent from training [S1, unofficial].
*   Networks struggle with small-scale color variations from complex transfer functions, leading to uniform sampling and poor reconstruction in textured regions [S1, unofficial].

## Operating characteristics
*   **Performance:** Achieves PSNR > 30 dB and SSIM > 0.95 with only 5–10% of samples [S1, unofficial].
*   **Speedup:** 1.5–2× speedup for large volumes ($2048^3$) at high resolutions ($\ge 1536^2$) [S1, unofficial].
*   **Limitations:** Slower than optimized ray casting for small volumes ($< 1024^3$) or small images ($< 1024^2$) due to fixed reconstruction overhead [S1, unofficial].
*   **Generalization:** Poor generalization to unseen transfer functions or complex small-scale color variations [S1, unofficial].

## Background
Weiss et al. [156] proposed this method to address the inefficiency of uniform sampling, which allocates equal computational resources to all image regions regardless of visual importance [S1, unofficial]. The approach uses an end-to-end pipeline trained with image losses (PSNR, SSIM, LPIPS) on final reconstruction quality [S1, unofficial].
