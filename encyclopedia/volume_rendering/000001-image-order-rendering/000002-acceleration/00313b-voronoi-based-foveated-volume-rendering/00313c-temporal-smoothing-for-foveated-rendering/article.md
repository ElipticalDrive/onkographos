# Temporal Smoothing for Foveated Rendering
Also called: Temporal filter for foveated rendering, Temporal smoothing filter, Temporal smoothing filter for foveated rendering

## Overview
A temporal filter applied to peripheral vision regions to attenuate artifacts caused by low sampling density, while also providing implicit anti-aliasing and hiding sharp-to-blurry transitions during rapid eye movements [S1]. It sets itself apart from spatial-only foveated methods by leveraging temporal coherence to smooth undersampling artifacts, though it introduces a small computational overhead and is disabled during interactive changes to prevent motion blur [S1].

## How it works
**Inputs and Outputs**
- Input: Current frame's peripheral pixel values, previous $n$ frames' peripheral pixel values [S1].
- Output: Temporally smoothed peripheral pixel values [S1].
- The foveal region is rendered at high resolution and is not smoothed [S1].

**Data Structures**
- A circular buffer storing the pixel values of the last $n$ frames for the peripheral region, with size $(n+1) \times \text{height} \times \text{width}$ [G].
- The peripheral region is defined by the sampling mask generated by the parent method, [Voronoi-Based Foveated Volume Rendering](6463-voronoi-based-foveated-volume-rendering.md) [S1].

**Parameters**
- $n$: Number of previous frames to average. Typical value: $n = 8$ [S1]. This value is a compromise between sufficient smoothing, perceived fade, and perceived frame rate [S1].

**Steps**
1. Render the current frame using the foveated sampling strategy [S1].
2. Identify the peripheral region pixels (those outside the high-acuity foveal zone) [S1].
3. For each peripheral pixel, compute the average of its value in the current frame and the values from the previous $n$ frames stored in the buffer [S1].
4. Update the buffer with the current frame's peripheral pixel values [G].
5. Composite the smoothed peripheral region with the unsmoothed foveal region [G].

**Formula**
Let $P_t(x, y)$ be the pixel value at coordinates $(x, y)$ in the peripheral region at frame $t$. The smoothed pixel value $P'_t(x, y)$ is:

$$P'_t(x, y) = \frac{1}{n+1} \sum_{i=0}^{n} P_{t-i}(x, y)$$

Where $P_{t-i}(x, y)$ is the pixel value from $i$ frames ago [S1].

**Edge Cases and Pitfalls**
- **Interaction and Dynamic Data:** Applying the filter during image-altering changes (camera manipulation, transfer function modifications) introduces unwanted motion blur [S1]. The filter must be disabled during such changes [S1].
- **Dynamic Data:** The filter may induce undesired motion blur effects during interaction and dynamic data; it is recommended to refrain from using the filter in these scenarios [S1].
- **Eye Tracking Latency:** The filter helps hide the transition from blurry to sharp during rapid eye movements that can be noticeable if the screen update lags behind the eye movement [S1]. It also helps with eye-tracking devices with low sampling rates [S1].

**Pseudocode**

```python
def temporal_smooth_peripheral(current_frame_pixels, buffer, write_index, n):
    """
    Applies temporal smoothing to peripheral pixels.
    Args:
        current_frame_pixels: 2D list of pixel values for the current frame's peripheral region.
        buffer: Circular buffer of size n+1 storing previous peripheral pixel frames.
        write_index: Current index in the buffer to write the new frame.
        n: Number of previous frames to average (typically 8).
    Returns:
        smoothed_pixels: 2D list of smoothed peripheral pixel values.
        new_write_index: Updated write index for the buffer.
    """
    height = len(current_frame_pixels)
    width = len(current_frame_pixels[0]) if height > 0 else 0
    buffer_size = n + 1
    smoothed_pixels = [[0.0] * width for _ in range(height)]

    for y in range(height):
        for x in range(width):
            pixel_sum = 0.0
            for i in range(buffer_size):
                read_index = (write_index - i) % buffer_size
                if i == 0:
                    pixel_sum += current_frame_pixels[y][x]
                else:
                    pixel_sum += buffer[read_index][y][x]
            smoothed_pixels[y][x] = pixel_sum / buffer_size

    buffer[write_index] = [row[:] for row in current_frame_pixels]
    new_write_index = (write_index + 1) % buffer_size
    return smoothed_pixels, new_write_index
```

## Operating characteristics
- **Performance:** The reduced number of rays (less than 8% of regular rendering) indicates potential for significant performance gains, but actual speedups are limited by other factors [S1].
- **Speedup:** Achieved average speedups between factor 1.8 and 3.2 depending on data set and transfer function [S1]. Speedup is higher for volumes with less empty space [S1].
- **Overhead:** The overhead of natural neighbor interpolation amounts to $1.5 \pm 0.157$ ms for all data sets, plus general overhead (kernel invocation, etc.) [S1].
- **Limitations:** Sparse peripheral regions often correspond to rays accelerated by empty space skipping, limiting potential performance gains from ray reduction [S1]. Caching is less efficient compared to regular volume rendering due to non-consecutive voxel-access pattern [S1].
- **When to use:** Suitable for static or slowly changing data where peripheral undersampling artifacts are noticeable and motion blur is not a concern [G].
- **When not to use:** Not suitable for interactive scenarios, camera manipulation, transfer function modifications, or dynamic data where motion blur artifacts are undesirable [S1].

## Background
- **Origin:** The method is part of the Voronoi-Based Foveated Volume Rendering approach, presented by Bruder et al. in 2019 [S1].
- **Development:** The temporal smoothing filter was introduced to address undersampling artifacts in peripheral vision regions, which are sensitive to contrast changes and movement [S1]. The choice of $n=8$ frames was determined as a compromise between smoothing quality and perceived frame rate [S1].
- **Usage:** Implemented in a single-pass volume raycasting system using OpenCL 1.2, rendered at 1024×1024 px on a 1080p screen, tested with a Tobii Pro Spectrum eyetracker (1200 Hz) and NVIDIA GeForce GTX 1070 [S1].
