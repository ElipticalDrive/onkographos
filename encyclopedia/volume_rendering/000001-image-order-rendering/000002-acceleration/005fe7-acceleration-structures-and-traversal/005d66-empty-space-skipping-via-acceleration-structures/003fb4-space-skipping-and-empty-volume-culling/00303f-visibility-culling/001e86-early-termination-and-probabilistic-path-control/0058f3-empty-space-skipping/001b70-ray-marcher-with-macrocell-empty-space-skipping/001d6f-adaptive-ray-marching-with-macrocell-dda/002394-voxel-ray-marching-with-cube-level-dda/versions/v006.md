# Voxel Ray Marching with Cube-Level DDA

Also called: 2-Level DDA Voxel Rendering, DDA voxel traversal, Two-level DDA

## Overview
Voxel Ray Marching with Cube-Level DDA is a GPU-based fragment shader technique for rendering voxel volumes by casting rays through a hierarchical grid of voxel cubes and individual voxels, using a two-level Digital Differential Analyzer (DDA) to skip empty space efficiently [S1, unofficial]. It builds on [Adaptive Ray Marching with Macrocell DDA](1500-adaptive-ray-marching-with-macrocell-dda.md) by replacing the adaptive macrocell traversal with a fixed two-level DDA structure: a coarse traversal over $16 \times 16 \times 16$ voxel blocks to skip empty regions, followed by a fine traversal over individual voxels within occupied blocks to find the first opaque surface [S1, unofficial].

## How it works
The method renders a voxel volume by mapping a view ray into model space and traversing a 3D grid composed of $16 \times 16 \times 16$ voxel cubes [S1, unofficial]. The algorithm operates in two nested loops: an outer loop traverses the cubes, and an inner loop traverses the voxels within a cube if it is occupied [S1, unofficial].

### Inputs and Outputs
**Inputs:**
*   `model_size`: The dimensions of the voxel volume in voxels ($vec3$) [S1, unofficial].
*   `MODEL_MATRIX`, `MODELVIEW_MATRIX`, `PROJECTION_MATRIX`: Transformation matrices [S1, unofficial].
*   `CAMERA_POSITION_WORLD`: World-space camera position [S1, unofficial].
*   `SCREEN_TEXTURE`: Background texture for transparency blending [S1, unofficial].
*   Voxel data: Accessed via custom samplers (`get_cube`, `get_voxel`) [S1, unofficial].

**Outputs:**
*   Fragment color (`ALBEDO`), depth (`DEPTH`), and geometry properties (`NORMAL_MAP`, `ROUGHNESS`, etc.) [S1, unofficial].
*   Discard: If no surface is hit, the fragment is discarded [S1, unofficial].

### Data Structures
The algorithm uses a `DDA` structure to track the current position and step direction in the grid [S1, unofficial]. The structure contains `position` (current integer grid coordinate) and internal DDA state for boundary distances [G].

**Initialization:**
The vertex shader computes the ray in model space:
$$ \mathbf{RAY} = \text{safe\_vector}(\mathbf{VERTEX} - (\mathbf{MODEL\_MATRIX}^{-1} \cdot [CAMERA\_POSITION\_WORLD, 1]^T).xyz) $$
$$ \mathbf{MODEL\_SIZE\_REC} = \frac{1}{\mathbf{model\_size}} $$
The fragment shader initializes the outer DDA (`ddc`) for cubes [S1, unofficial]. The front face intersection is calculated as:
$$ \mathbf{front} = \text{to\_front\_face}(\mathbf{BACK}, \mathbf{ray}, \mathbf{ray\_rec}) $$
where $\mathbf{ray\_rec} = 1.0 / \mathbf{ray}$ [S1, unofficial].

### Pseudocode
The following pseudocode implements the opaque pass logic described in [S1, unofficial]. It assumes standard DDA helper functions (`dda_init`, `dda_step`, `dda_voxel_face_hit`) and custom voxel samplers (`get_cube`, `get_voxel`) [S1, unofficial].

```python
# Vertex Shader Pre-computation
MODEL_SIZE_REC = 1.0 / model_size
RAY = safe_vector(VERTEX - inverse(MODEL_MATRIX) * vec4(CAMERA_POSITION_WORLD, 1.0)).xyz
BACK = VERTEX

# Fragment Shader
ray = RAY
ray_rec = 1.0 / ray
front = to_front_face(BACK, ray, ray_rec)

# Initialize outer DDA for 16x16x16 cubes
ddc = dda_init(model_size, front, ray, ray_rec)

found = False
no_more_cubes = False

# Outer Loop: Traverse Cubes
for csteps in range(49):
    layer = 0  # Placeholder for layer index if multi-layered
    has_opaque = False

    # Check if current cube contains any opaque voxels
    if get_cube(ddc.position, layer, has_opaque) and has_opaque:
        # Initialize inner DDA for individual voxels within the cube
        origin = ddc.position * 16.0  # Cube start in voxel coordinates [G]
        ddv = dda_init_inner(ddc, model_size, MODEL_SIZE_REC, ray, ray_rec, origin)

        # Calculate exit point of the cube
        exit_point = dda_voxel_face_hit(ddc, MODEL_SIZE_REC)
        exit_vertex = calc_vertex(exit_point, PROJECTION_MATRIX, _MODELVIEW_MATRIX, depth)

        # Skip cube if behind or on the camera plane
        if exit_vertex.z >= 0.0:
            no_more_cubes = dda_step(ddc)
            if found or no_more_cubes:
                break
            continue

        # Inner Loop: Traverse Voxels
        for vsteps in range(49):
            tpos = vec3(0)
            voxel = 0
            color = vec3(0)
            opaque = False

            # Retrieve voxel data
            if get_voxel(ddv.position, layer, tpos, voxel, color, opaque):
                if opaque:
                    # Calculate precise hit point in model coordinates
                    hit = origin + dda_voxel_face_hit(ddv, vec3(1.0 / 16.0)) * MODEL_SIZE_REC

                    # Transform hit point to view space
                    light_vertex = calc_vertex(hit, PROJECTION_MATRIX, _MODELVIEW_MATRIX, depth)

                    # Check if voxel is in front of the view plane
                    if light_vertex.z < 0.0:
                        DEPTH = depth
                        LIGHT_VERTEX = light_vertex

                        # Compute surface geometry
                        dda_voxel_face_normals(ddv, NORMALS, NORMAL, TANGENT, BINORMAL)
                        dda_voxel_face_uv(ddv, model_size, hit, face)

                        # Fetch material properties
                        get_opaque_material(tpos, voxel, color, face, uv, ALBEDO, EMISSION, normal_map, rsma)

                        # Map to shader outputs
                        NORMAL_MAP = normal_map.xy
                        NORMAL_MAP_DEPTH = normal_map.z
                        ROUGHNESS = rsma.r
                        SPECULAR = rsma.g
                        METALLIC = rsma.b
                        AO = rsma.a

                        found = True
                        break  # Stop inner loop on first opaque voxel

            # Step to next voxel
            if dda_step(ddv):
                break  # End of cube reached

        if found:
            break  # Stop outer loop
    else:
        no_more_cubes = dda_step(ddc)

    if found or no_more_cubes:
        break

if not found:
    raise StopIteration("discard")  # Shader intrinsic: discard fragment
```

### Parameters
*   **Cube Size**: $16 \times 16 \times 16$ voxels [S1, unofficial]. This determines the step size for the inner DDA: `vec3(1.0 / 16.0)` [S1, unofficial].
*   **Max Steps**: 49 steps per cube and 49 steps per voxel [S1, unofficial].

### Edge Cases and Pitfalls
*   **View Plane Culling**: Voxels or cubes behind the camera plane ($z \ge 0$ in view space) are skipped to avoid rendering artifacts and unnecessary computation [S1, unofficial].
*   **Transparent Background**: If no opaque voxel is found, the fragment is discarded, resulting in a transparent background [S1, unofficial].
*   **Precision**: The algorithm relies on `ray_rec` (reciprocal of ray direction) for DDA stability [S1, unofficial]. Zero components in the ray direction must be handled (e.g., by `safe_vector`) to avoid division by zero [S1, unofficial].
*   **Inside/Outside Viewing**: The mesh uses front-face culling (`cull_front`), allowing the ray to enter from the back face, enabling viewing from inside the volume [S1, unofficial].

## Subtopics

### [MultiDDA](3123-multidda.md)
MultiDDA is an acceleration method for volume rendering that performs incremental Digital Differential Analyzer (DDA) traversal over a two-level hierarchical grid to skip empty space more efficiently than a flat grid. It builds on [Voxel Ray Marching with Cube-Level DDA](3069-voxel-ray-marching-with-cube-level-dda.md) by replacing the single-level voxel traversal with a nested approach: a coarse traversal over "bricks" ($8^3$ voxel blocks) followed by a fine traversal over individual voxels only within occupied bricks. It differs from its parent by introducing a dedicated coarse occupancy grid layer, whereas the parent uses a flat voxel grid traversal without hierarchical skipping.

### [Efficient Voxel Marking for Hierarchical Volumetric Fusion](12765-efficient-voxel-marking-for-hierarchical-volumetric-fusion.md)
This method marks hierarchical macro-cells as either empty or intersected by a noisy depth surface, enabling efficient culling in volumetric fusion pipelines. Unlike gathering-type approaches that project geometry to screen space and suffer from high thread divergence, this method is input-driven (scattering type), assigning one GPU thread per depth image pixel to traverse the macro-voxel grid, thereby automatically ignoring invisible cells and minimizing divergence.

## Operating characteristics
*   **Time Complexity**: Not given in the sources.
*   **Memory Complexity**: Not given in the sources.
*   **Performance**: The method is designed for GPU fragment shaders, leveraging parallelism across pixels [S1, unofficial]. The two-level DDA reduces branching overhead compared to single-level traversal by skipping entire cubes [S1, unofficial].
*   **Strengths**: Efficient empty space skipping, simple implementation, supports runtime voxel updates, allows viewing from inside or outside [S1, unofficial].
*   **Limitations**: Fixed cube size ($16^3$) may not be optimal for all volumes [S1, unofficial]. Transparency handling is limited (grayscale alpha fallback mentioned in plans) [S1, unofficial].

## Background
The method is implemented as part of the "Voxel rendering addon for Godot 4.3+" by Viktor Ferenczi [S1, unofficial]. It is based on an efficient 2-level DDA algorithm, implemented 100% on the GPU as a fragment shader [S1, unofficial]. The approach allows for good performance and opens up the possibility of making runtime changes to voxels at a relatively low cost [S1, unofficial]. The shader code is designed to be reusable, allowing custom samplers for different PBR materials and voxel types [S1, unofficial].
