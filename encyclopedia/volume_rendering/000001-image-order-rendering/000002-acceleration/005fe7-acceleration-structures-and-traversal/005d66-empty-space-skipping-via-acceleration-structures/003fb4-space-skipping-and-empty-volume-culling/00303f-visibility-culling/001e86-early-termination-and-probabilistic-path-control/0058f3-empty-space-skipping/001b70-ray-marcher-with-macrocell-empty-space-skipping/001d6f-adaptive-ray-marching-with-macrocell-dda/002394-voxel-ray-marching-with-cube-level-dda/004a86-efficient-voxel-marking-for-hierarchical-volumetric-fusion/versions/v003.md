# Efficient Voxel Marking for Hierarchical Volumetric Fusion
Also called: Multi-level DDA ray-casting for macro-voxel marking, Scattering type macro-voxel marking
## Overview
This method marks hierarchical macro-cells as either empty or intersected by a noisy depth surface, enabling efficient culling in volumetric fusion pipelines [S1, unofficial]. Unlike gathering-type approaches that project geometry to screen space and suffer from high thread divergence, this method is input-driven (scattering type), assigning one GPU thread per depth image pixel to traverse the macro-voxel grid, thereby automatically ignoring invisible cells and minimizing divergence [S1, unofficial].
## How it works
**Inputs and Outputs:**
- **Inputs:** A depth image with associated camera intrinsics and extrinsics [S1, unofficial]. A hierarchical voxel grid where the top level consists of macro-voxels [S1, unofficial]. A truncation distance parameter $d_{\text{trunc}}$ [S1, unofficial].
- **Outputs:** A status descriptor for each macro-voxel indicating its intersection and emptiness state [S1, unofficial].

**Data Structures:**
Each macro-voxel is represented by a single 32-bit word [S1, unofficial]. The layout contains the index of the block of child-voxels, the intersection flag, the emptiness flag, and a counter showing how many times the complete macro-cell was found empty [S1, unofficial]. The intersection and emptiness flags are placed in different bytes to allow independent modification without atomic operations [S1, unofficial]. The exact bit allocation for the child-voxel index and the counter within the 32-bit word is not given in the sources [S1, unofficial].

**Algorithm Steps:**
1. **Thread Assignment:** Assign one GPU thread to every pixel of the depth image [S1, unofficial].
2. **Ray Interval Definition:** For each thread, retrieve the depth value $z$ at the pixel [S1, unofficial]. Construct a truncation interval $[z_{\min}, z_{\max}]$ where $z_{\min} = z - d_{\text{trunc}}$ and $z_{\max} = z + d_{\text{trunc}}$ [S1, unofficial].
3. **Ray Generation:** Form a ray originating from the camera center passing through the pixel [G].
4. **Multi-level DDA Traversal:** Execute a DDA-based voxel traversal method on the higher-level macro-voxel grid to identify cells intersected by the ray [S1, unofficial].
5. **Flag Updating:**
   - **Empty Check:** If the ray parameter at the exit point of the current cell ($t_{\text{exit}}$) is lower than $z_{\min}$, mark the visited cell as empty [S1, unofficial].
   - **Intersection Check:** If the entry-exit interval of the ray parameter $[t_{\text{entry}}, t_{\text{exit}}]$ overlaps with the truncation interval $[z_{\min}, z_{\max}]$, mark the macro-voxel as intersected [S1, unofficial].
   - **Atomic-Free Update:** Since the intersection and emptiness flags are stored in different bytes of the descriptor word, threads can update these flags independently [S1, unofficial]. A thread sets a flag bit without modifying the other byte, avoiding write collisions and the need for atomic operations [S1, unofficial]. The result is independent of the order of thread execution [S1, unofficial].
6. **Final State Interpretation:** After all threads complete:
   - If both flags are cleared, the macro-voxel is not affected [S1, unofficial].
   - If the intersection flag is set, the surface intersects the macro-voxel regardless of the empty flag state [S1, unofficial].
   - If only the empty flag is set, the macro-voxel does not contain surface and its children are either empty or not seen [S1, unofficial].

**Formulas:**
- Truncation interval bounds: $z_{\min} = z - d_{\text{trunc}}$, $z_{\max} = z + d_{\text{trunc}}$ [S1, unofficial].
- Empty condition: $t_{\text{exit}} < z_{\min}$ [S1, unofficial].
- Intersection condition: $t_{\text{entry}} < z_{\max} \land t_{\text{exit}} > z_{\min}$ [S1, unofficial].
- Symbol definitions: $z$ is the depth value at the pixel, $d_{\text{trunc}}$ is the truncation distance, $t_{\text{entry}}$ and $t_{\text{exit}}$ are the ray parameters at the entry and exit points of the macro-voxel bounding box, respectively [S1, unofficial].

**Parameters:**
- **Truncation Distance ($d_{\text{trunc}}$):** The threshold defining the interval around the depth value. Voxels are affected if the difference between the depth value and the distance from the camera is less than this value [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Write Collisions:** Different rays may intersect the same macro-cell [S1, unofficial]. This is handled by separating flags into different bytes, allowing independent updates without atomics [S1, unofficial].
- **Frame Delay:** The method may tolerate a one-frame delay in updates, which can be combined with the ICP ray-casting step to reduce computational cost [S1, unofficial].
- **Noise:** The method is robust to depth camera noise due to the truncation interval [S1, unofficial].

**Pseudocode:**
```python
def mark_macro_voxels(depth_image, camera_intrinsics, camera_extrinsics, d_trunc, macro_grid):
    camera_center = camera_extrinsics.inverse() * [0, 0, 0, 1]
    for u, v in depth_image.pixels():
        z = depth_image[u, v]
        z_min = z - d_trunc
        z_max = z + d_trunc
        pixel_world = camera_intrinsics.inverse() * [u, v, z, 1]
        ray_dir = normalize(pixel_world - camera_center)
        ray_origin = camera_center

        # Multi-level DDA traversal on macro-voxel grid [S1, unofficial]
        # DDA state initialization and stepping follows standard 3D DDA [G]
        current_cell = macro_grid.start(ray_origin, ray_dir)
        while current_cell is not None:
            t_entry, t_exit = intersect_box(ray_origin, ray_dir, current_cell.bounding_box)

            if t_exit < z_min:
                # Set emptiness flag in a distinct byte independently [S1, unofficial]
                current_cell.descriptor |= (1 << 8)

            if t_entry < z_max and t_exit > z_min:
                # Set intersection flag in a distinct byte independently [S1, unofficial]
                current_cell.descriptor |= (1 << 0)

            current_cell = macro_grid.next(current_cell, ray_dir)

def intersect_box(origin, direction, bbox):
    t_min = -float('inf')
    t_max = float('inf')
    for i in range(3):
        if abs(direction[i]) < 1e-8:
            if origin[i] < bbox.min[i] or origin[i] > bbox.max[i]:
                return float('inf'), -float('inf')
        else:
            t1 = (bbox.min[i] - origin[i]) / direction[i]
            t2 = (bbox.max[i] - origin[i]) / direction[i]
            t_min = max(t_min, min(t1, t2))
            t_max = min(t_max, max(t1, t2))
    return t_min, t_max
```
## Operating characteristics
- **Time Complexity:** Linear with respect to the number of depth image pixels and the average number of macro-voxels intersected per ray [S1, unofficial].
- **Memory Complexity:** Linear with respect to the number of macro-voxels [S1, unofficial].
- **Measured Performance:** Runs at real-time on NVIDIA GeForce GTX 690 GPUs [S1, unofficial].
- **Scaling:** The hierarchical representation allows reducing voxel edge length from 8 mm to 1 mm compared to Microsoft KinectFusion while using the same amount of GPU memory [S1, unofficial].
- **Strengths:** Low thread divergence, no atomic operations required, automatically ignores invisible cells, simple implementation [S1, unofficial].
- **Limitations:** Requires a hierarchical grid structure. May miss updates if a single frame is skipped, though this is tolerable due to depth camera noise [S1, unofficial].
- **When to use:** Suitable for real-time hierarchical volumetric fusion on GPUs where depth camera noise and memory constraints are primary concerns [S1, unofficial].
- **When not to use:** Unsuitable for non-hierarchical uniform grids or scenarios requiring strict per-frame atomic consistency without the one-frame delay tolerance [S1, unofficial].
## Background
- **Origin:** Proposed by researchers from Budapest University of Technology and Economics, Hungary [S1, unofficial].
- **History and Development:** Developed to address limitations in hierarchical volumetric fusion, specifically the high divergence and complexity of gathering-type algorithms like Scalable KinectFusion [S1, unofficial]. The method replaces screen-space projection of hexagons with an input-driven scattering approach that traverses the macro-voxel grid directly [S1, unofficial].
- **Usage:** Implemented in CUDA for hierarchical volumetric fusion, compared against Microsoft KinectFusion [S1, unofficial].
