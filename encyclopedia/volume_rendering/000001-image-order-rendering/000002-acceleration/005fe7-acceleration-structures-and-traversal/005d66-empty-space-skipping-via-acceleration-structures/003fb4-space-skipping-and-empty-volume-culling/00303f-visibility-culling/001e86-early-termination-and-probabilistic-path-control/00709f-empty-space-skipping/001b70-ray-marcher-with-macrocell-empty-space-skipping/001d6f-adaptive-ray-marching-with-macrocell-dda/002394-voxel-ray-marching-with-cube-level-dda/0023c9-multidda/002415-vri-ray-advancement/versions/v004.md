# VRI Ray Advancement

## Overview
VRI Ray Advancement advances a Volume Ray Intersection (VRI) state machine to the next leaf voxel intersection by managing a three-level hierarchical traversal of I2 nodes, I1 nodes, and leaf voxels using Digital Differential Analyzer (DDA) stepping [S1, unofficial]. It differs from its parent [MultiDDA](3123-multidda.md) by explicitly separating the traversal into three distinct phases: draining the current I1 DDA for leaf hits, stepping the I2 DDA to find the next active I1 child, and advancing to the next pre-sorted root entry when the hierarchy is exhausted [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A ray defined by origin $O$ and direction $D$; a pre-sorted list of root entries `state.roots`, where each entry is a tuple $(t_{min}, \text{I2\_node})$; and the current `state` containing DDA iterators and node references for I2 and I1 levels [S1, unofficial].
*   **Output:** A `LeafIntersection` object containing $t_{enter}$, $t_{exit}$, and the leaf voxel reference, along with the updated `state`; or `nothing` if no further intersections exist [S1, unofficial].

**Data Structures:**
*   **I2 Node:** Contains a `child_mask` (bitmask), a `children` array of I1 nodes, and an `origin` coordinate [S1, unofficial].
*   **I1 Node:** Contains a `child_mask` (bitmask), a `children` array of leaf voxels, and an `origin` coordinate [S1, unofficial].
*   **Leaf Voxel:** Contains an `origin` coordinate and represents the finest granularity of the hierarchical grid [S1, unofficial].
*   **DDA State:** `state.i2_ndda`, `state.i1_ndda` store the current DDA iterators; `state.i2_node`, `state.i1_node` store the current node references; `state.root_idx` tracks the current root entry index [S1, unofficial].

**Parameters:**
*   Leaf voxel size: $8$ units [S1, unofficial].
*   I1 brick size: $16$ units [S1, unofficial].
*   I2 node size: $128$ units [S1, unofficial].
*   Root block size: $32$ units [S1, unofficial].

**Algorithm Steps:**
1.  **Phase 1: Drain Current I1 DDA for Leaf Hits.** While `state.i1_ndda` is not `nothing`, query `node_dda_query(ndda)` for `inside` and `child_idx` [S1, unofficial]. If `!inside`, break [S1, unofficial]. If `is_on(state.i1_node.child_mask, child_idx)`, calculate `idx = count_on_before(state.i1_node.child_mask, child_idx) + 1` [S1, unofficial]. Get `leaf = state.i1_node.children[idx]` [S1, unofficial]. Compute `bbox = BBox(o, Coord(o[1] + s - Int32(1), o[2] + s - Int32(1), o[3] + s - Int32(1)))` where `s = Int32(8)` [S1, unofficial]. Intersect ray with `bbox` [S1, unofficial]. If hit, return `(LeafIntersection{T}(t_enter, t_exit, leaf), state)` and step DDA [S1, unofficial].
2.  **Phase 2: Step I2 DDA to Find Next I1 Child.** If Phase 1 drained, set `state.i1_ndda = nothing` and `state.i1_node = nothing` [S1, unofficial]. While `state.i2_ndda` is not `nothing`, query `node_dda_query(ndda)` [S1, unofficial]. If `inside` and `is_on(state.i2_node.child_mask, child_idx)`, get `i1_node = state.i2_node.children[idx]` [S1, unofficial]. Compute `aabb` from `o` to `o + 128.0` [S1, unofficial]. If ray intersects `aabb` at `tmin`, initialize `state.i1_ndda = node_dda_init(ray, tmin, o, Int32(16), Int32(8))`, set `state.i1_node = i1_node`, step DDA, set `found_i1 = true`, and break [S1, unofficial].
3.  **Phase 3: Advance to Next Pre-Sorted Root Entry.** If no I1 found, set `state.i2_ndda = nothing` and `state.i2_node = nothing` [S1, unofficial]. Increment `state.root_idx` [S1, unofficial]. If `state.root_idx > length(state.roots)`, return `nothing` [S1, unofficial]. Otherwise, get `tmin, i2_node = state.roots[state.root_idx]` [S1, unofficial]. Initialize `state.i2_ndda = node_dda_init(ray, tmin, o, Int32(32), Int32(128))` and set `state.i2_node = i2_node` [S1, unofficial]. Loop back to Phase 1 [S1, unofficial].

**Pseudocode:**
```python
def is_on(mask, idx):
    return (mask >> idx) & 1 == 1

def count_on_before(mask, idx):
    return bin(mask & ((1 << idx) - 1)).count('1')

def intersect_ray_aabb(origin, direction, aabb_min, aabb_max):
    tmin = -float('inf')
    tmax = float('inf')
    for i in range(3):
        if direction[i] == 0:
            if origin[i] < aabb_min[i] or origin[i] > aabb_max[i]:
                return None
        else:
            t1 = (aabb_min[i] - origin[i]) / direction[i]
            t2 = (aabb_max[i] - origin[i]) / direction[i]
            tmin = max(tmin, min(t1, t2))
            tmax = min(tmax, max(t1, t2))
    return tmin if tmax >= tmin else None

class DDAState:
    def __init__(self, ray_origin, ray_dir, t_min, origin, block_size, cell_size):
        self.t_min = t_min
        self.origin = origin
        self.block_size = block_size
        self.cell_size = cell_size
        self.current_cell = [0, 0, 0]
        self.t_enter = t_min
        self.t_exit = t_min + cell_size
        self.step = [1 if d > 0 else -1 for d in ray_dir]
        self.t_max = [t_min + cell_size if d != 0 else float('inf') for d in ray_dir]

    def query(self):
        inside = self.t_enter < self.t_min + self.block_size
        stride = self.block_size // self.cell_size
        child_idx = self.current_cell[0] * (stride ** 2) + self.current_cell[1] * stride + self.current_cell[2]
        return inside, child_idx

    def step(self):
        min_t_idx = 0
        if self.t_max[1] < self.t_max[min_t_idx]: min_t_idx = 1
        if self.t_max[2] < self.t_max[min_t_idx]: min_t_idx = 2
        self.t_enter = self.t_max[min_t_idx]
        self.current_cell[min_t_idx] += self.step[min_t_idx]
        self.t_max[min_t_idx] += self.cell_size

def vri_advance(state, ray, roots):
    while True:
        # Phase 1: Drain current I1 DDA for leaf hits
        while state.i1_ndda is not None:
            inside, child_idx = state.i1_ndda.query()
            if not inside:
                break
            if is_on(state.i1_node.child_mask, child_idx):
                idx = count_on_before(state.i1_node.child_mask, child_idx) + 1
                leaf = state.i1_node.children[idx]
                o = leaf.origin
                s = 8
                bbox_min = o
                bbox_max = (o[0] + s - 1, o[1] + s - 1, o[2] + s - 1)
                t_enter = intersect_ray_aabb(ray.origin, ray.direction, bbox_min, bbox_max)
                if t_enter is not None:
                    return (t_enter, t_enter + 8.0, leaf), state
                state.i1_ndda.step()

        # Phase 2: Step I2 DDA to find next I1 child
        state.i1_ndda = None
        state.i1_node = None
        found_i1 = False
        while state.i2_ndda is not None:
            inside, child_idx = state.i2_ndda.query()
            if inside and is_on(state.i2_node.child_mask, child_idx):
                idx = count_on_before(state.i2_node.child_mask, child_idx) + 1
                i1_node = state.i2_node.children[idx]
                o = state.i2_node.origin
                aabb_min = o
                aabb_max = (o[0] + 128.0, o[1] + 128.0, o[2] + 128.0)
                t_min = intersect_ray_aabb(ray.origin, ray.direction, aabb_min, aabb_max)
                if t_min is not None:
                    state.i1_ndda = DDAState(ray, t_min, o, 16, 8)
                    state.i1_node = i1_node
                    state.i2_ndda.step()
                    found_i1 = True
                    break

        # Phase 3: Advance to next pre-sorted root entry
        if not found_i1:
            state.i2_ndda = None
            state.i2_node = None
            state.root_idx += 1
            if state.root_idx >= len(roots):
                return None, state
            t_min, i2_node = roots[state.root_idx]
            o = i2_node.origin
            state.i2_ndda = DDAState(ray, t_min, o, 32, 128)
            state.i2_node = i2_node
```

**Edge Cases and Pitfalls:**
*   **Precision:** DDA stepping can suffer from floating-point precision errors at large distances; use double precision for DDA coordinates if necessary [G].
*   **Boundaries:** Ensure `intersect_ray_aabb` handles edge cases where the ray is parallel to a face or originates inside the volume [G].
*   **Degenerate Input:** If `roots` is empty, the method should immediately return `nothing` [G].
*   **Mask Handling:** `is_on` and `count_on_before` must correctly handle the bitmasks; `child_idx` is the bit position returned by the DDA query, used directly to index the mask [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** Designed for GPU execution (CUDA/JULIA KernelAbstractions) [S1, unofficial].
*   **Strengths:** Efficient empty-space skipping; leverages pre-sorted root entries for coherent traversal [S1, unofficial].
*   **Limitations:** Requires a pre-built hierarchical grid; overhead of managing multiple DDA states [S1, unofficial].

## Background
VRI Ray Advancement is a traversal method implemented in the Lyr.jl codebase that advances a Volume Ray Intersection (VRI) state machine [S1, unofficial]. It is designed to compete with other high-performance volume rendering phases (C: device-cache, D: fused-spp, E: CuTexture) [S1, unofficial]. The method is used in the `gpu_render_volume` phase of the engine [S1, unofficial].
