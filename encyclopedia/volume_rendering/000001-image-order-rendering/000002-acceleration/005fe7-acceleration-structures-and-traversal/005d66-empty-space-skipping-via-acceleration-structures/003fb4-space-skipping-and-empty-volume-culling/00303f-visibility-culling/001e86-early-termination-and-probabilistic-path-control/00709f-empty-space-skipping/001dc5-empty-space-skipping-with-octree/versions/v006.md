# Empty Space Skipping with Octree

Also called: Octree-based Empty Space Skipping, Min-Max Octree Empty Space Skipping, Empty space leaping

## Overview
Empty Space Skipping with Octree is an acceleration technique for semi-transparent volume rendering that skips empty regions using an octree spatial data structure to reduce the number of reconstruction samples [S1, S2]. It differs from sibling methods like [Brick Classification and Empty Space Skipping](2830-brick-classification-and-empty-space-skipping.md) by storing conservative min/max scalar ranges at every node of a recursive tree, allowing rays to leap over intervals where the maximum value is below the opacity threshold [S2, S3]. Unlike [Octree Traversal with Min/Max Pruning](1739-octree-traversal-with-min-max-pruning.md) which focuses on finer resolution pruning for unclassified volumes, this method provides the foundational hierarchical traversal logic for culling entire empty blocks [S1, S3].

## How it works
**Inputs:**
*   Volume dataset $V$ with voxel values.
*   Transfer function $T(v)$ mapping voxel values to color and opacity.
*   Ray $R(t) = O + tD$ for each pixel.
*   Precomputed Octree structure.

**Outputs:**
*   Final pixel color and opacity.
*   Reduced number of ray marching steps.

**Data Structures:**
The volume is recursively subdivided into an octree. Each node stores the minimum and maximum scalar values of its subtree [S2, S3].
*   **Node Layout:**
    *   `is_leaf`: Boolean.
    *   `min_val`: Scalar minimum of the region.
    *   `max_val`: Scalar maximum of the region.
    *   `children`: Array of 8 child nodes (if not leaf).
*   **Leaf Node Layout:**
    *   `min_val`, `max_val`: Conservative estimates of the min/max values in the leaf's region.
    *   `data`: Pointer to the underlying voxel data or polynomial coefficients [S3, S5].
*   **Pre-classification Histograms (Optional but recommended for correctness):**
    *   To avoid false transparent/opaque classification in pre-classification scenarios, quantized binary histograms are used [S1].
    *   `histogram_v`: List of size $s$ (e.g., 255 for 8-bit voxels), quantized into buckets of size 32. Flags are set for every voxel value $v$ present in the brick.
    *   `histogram_o`: Similar histogram for opacity values.
    *   A brick is classified as fully transparent only if all buckets in both histograms indicate transparency [S1].

**Algorithm Steps:**

1.  **Preprocessing (Octree Construction):**
    1.  Subdivide the volume recursively into an octree.
    2.  For leaf nodes, estimate min/max values.
        *   If using B-splines, use the convex combination property of the basis functions [S3].
        *   If using polynomial pieces (e.g., Bezier-Bernstein), construct BB-forms for tetrahedral pieces and set the cell's min/max to the min/max of these coefficients [S5].
    3.  Propagate min/max values from leaves to the root. For each internal node, `node.min_val = min(children.min_val)` and `node.max_val = max(children.max_val)` [S3].
    4.  (Optional) For pre-classification, build quantized binary histograms for voxel values and opacities for each brick/leaf to ensure conservative transparency checks [S1].

2.  **Ray Traversal (Empty Space Skipping):**
    1.  Start traversal at the root of the octree.
    2.  Intersect the ray with the current node's bounding box. If no intersection, return empty.
    3.  Check if the node is empty:
        *   **Min/Max Check:** If `node.max_val < opacity_threshold` (or isovalue), the region is empty. Skip this entire branch. Update the ray's entry point to the exit point of this node's bounding box and return to the parent to continue traversal [S2][S4, unofficial].
        *   **Histogram Check (Pre-classification):** If histograms indicate all values map to zero opacity, skip the branch [S1].
    4.  If the node is not empty:
        *   If it is a leaf, perform standard ray marching/sampling within this region.
        *   If it is an internal node, recursively traverse its 8 children.
    5.  Update ray entry/exit points as the ray leaps over empty segments [S2].

**Pseudocode:**

```python
def traverse_octree(ray, node, opacity_threshold):
    """
    Recursively traverse the octree to skip empty space.
    Returns the accumulated color and opacity, or None if skipped.
    """
    # 1. Intersect ray with node bounding box
    t_min, t_max = intersect_bounding_box(ray, node.bbox)
    
    # If ray does not intersect this node's space, skip
    if t_max < ray.t_min or t_min > ray.t_max:
        return None

    # 2. Check for empty space using min/max values
    # Conservative check: if max value in this region is below threshold, it's transparent
    if node.max_val < opacity_threshold:
        # Skip this entire branch
        # Update ray's t_min to skip past this node's exit point
        ray.t_min = max(ray.t_min, t_max)
        return None

    # 3. If leaf, perform sampling
    if node.is_leaf:
        return sample_volume_ray(ray, node.data, opacity_threshold)

    # 4. If internal node, traverse children
    # Note: Order of children traversal can be optimized for coherence
    accumulated_color = (0.0, 0.0, 0.0, 0.0)
    
    for child in node.children:
        # Recursively traverse
        result = traverse_octree(ray, child, opacity_threshold)
        
        # If result is not None, we hit something
        if result is not None:
            # Composite result into accumulated_color
            # Standard volume compositing:
            # C_out = C_in + C_new * alpha_new * (1 - alpha_in)
            # alpha_out = alpha_in + alpha_new * (1 - alpha_in)
            accumulated_color = composite(accumulated_color, result)
            
            # Early ray termination if opaque enough
            if accumulated_color[3] >= 0.99:
                break
                
    return accumulated_color

def sample_volume_ray(ray, data, opacity_threshold):
    """
    Sample the volume data along the ray segment within the leaf node.
    """
    # Intersect ray with leaf bounding box to get precise entry/exit
    t_start, t_end = intersect_bounding_box(ray, data.bbox)
    
    color = (0.0, 0.0, 0.0, 0.0)
    t = t_start
    step_size = data.resolution / 10.0 # Example step size
    
    while t < t_end:
        # Sample voxel value at ray position
        v = sample_voxel(ray, t, data)
        
        # Map to opacity
        alpha = transfer_function_opacity(v)
        
        # Composite
        color = composite(color, (sample_color(v), alpha))
        
        # Early termination
        if color[3] >= 0.99:
            break
            
        t += step_size
        
    return color
```

**Parameters:**
*   `opacity_threshold`: The minimum opacity value required to consider a region non-empty. Typical value: 0.01 to 0.1 depending on transfer function [S2].
*   `bucket_size`: Size of quantized histogram buckets. Typical value: 32 [S1].
*   `b`: Trade-off factor for leaf node granularity (group of $b^3$ polynomials). Higher $b$ reduces tree depth but increases memory and reduces skipping efficiency [S3].

**Edge Cases and Pitfalls:**
*   **Pre-classification False Positives:** In pre-classification, a voxel value might map to zero opacity, but interpolation could yield non-zero color/opacity. Using min/max alone can lead to false transparent classification (skipping visible regions). Use quantized binary histograms to ensure conservative classification (transparent regions may be classified as opaque, but not vice versa) [S1].
*   **Precision:** Min/max values must be conservative estimates. If the estimated max is lower than the true max, empty space skipping will incorrectly skip visible regions [S3].
*   **Boundary Conditions:** Ensure ray intersection with bounding boxes is robust to avoid gaps between nodes [S2].

## Subtopics

### [Octree Traversal with Min/Max Pruning](1739-octree-traversal-with-min-max-pruning.md)
Octree Traversal with Min/Max Pruning is an acceleration technique for volume rendering that uses a hierarchical data structure storing the minimum and maximum scalar values of voxel regions to prune transparent space and determine precise ray entry points. It is specifically designed for unclassified volumes where the opacity transfer function or classification parameters change frequently, avoiding the expensive preprocessing required by pre-classified rendering methods. Unlike block-based entry point determination, it operates at a finer resolution than block granularity, significantly reducing the number of rays intersecting transparent regions.

### [Octree Empty Block Culling](2687-octree-empty-block-culling.md)
Octree Empty Block Culling is a visibility culling technique that recursively traverses an octree to determine if a node contains any non-empty data blocks, returning a status of `EMPTY` or `NONEMPTY` to enable early ray termination or skipping. It builds on [Empty Space Skipping with Octree](1610-empty-space-skipping-with-octree.md) by providing the specific recursive logic required to classify nodes based on the presence of underlying data blocks. Unlike [Octree Traversal with Min/Max Pruning](1739-octree-traversal-with-min-max-pruning.md) which uses bounding volume overlaps, this method relies on explicit block existence checks.

### [View-Dependent Working Set Generation](4965-view-dependent-working-set-generation.md)
This method constructs a view-dependent working set of non-empty octree nodes for out-of-core volume rendering, hiding I/O latency through asynchronous data loading. It differs from static culling methods by dynamically refining a sorted set of visible nodes based on screen-space projection and transfer-function opacity, ensuring only necessary data resides in GPU memory.

### [Adaptive Empty Node Aggregation into Bounding Volumes](19790-adaptive-empty-node-aggregation-into-bounding-volumes.md)
This method reduces ray intersection tests in empty space by adaptively clustering empty octree nodes into bounding volumes, allowing rays to skip blank areas faster. It sets itself apart from [Octree Traversal with Min/Max Pruning](1739-octree-traversal-with-min-max-pruning.md) and [Octree Empty Block Culling](2687-octree-empty-block-culling.md) by explicitly merging multiple empty nodes into a single larger bounding volume, rather than just culling individual nodes or using min/max bounds for pruning. It builds on [Empty Space Skipping with Octree](1610-empty-space-skipping-with-octree.md) by optimizing the storage and traversal of those empty regions.

### Adaptive Slice DVR with Octree
An adaptive slice DVR algorithm based on 3DTM that partitions the volume into transparent and non-transparent regions for efficient empty space skipping [S6]. It partitions the volume into transparent and non-transparent regions, uses axis-aligned bounding boxes to enclose the opaque regions, and uses an octree to encode these boxes for efficient empty space skipping [S6].

### Hardware Accelerated Space Carving
A fast hardware-accelerated Space Carving method using texture mapping, optimized with an octree structure and adaptive subdivision [S7, unofficial]. It uses an octree structure and adaptive subdivision methods to keep track of the set of consistent voxels throughout the carving process [S7, unofficial].

## Operating characteristics
*   **Time Complexity:** Preprocessing is $O(N)$ where $N$ is the number of voxels, as each voxel is visited once to compute min/max. Traversal is $O(K)$ where $K$ is the number of non-empty nodes visited. In sparse volumes, $K \ll N$.
*   **Memory Complexity:** $O(N)$ for the octree nodes. Each node stores min/max values. The tree size is proportional to the number of nodes, which is at most $8 \times$ the number of leaf nodes in a full octree. Quantized histograms add $O(N/32)$ memory per brick [S1].
*   **Measured Performance:** Octree-based ESL provides speedups of up to 10x in sparse datasets like CT scans [S2].
*   **Strengths:** Effective for sparse volumes with large empty regions. Reduces reconstruction samples significantly.
*   **Limitations:** Preprocessing overhead. Min/max bounds can be conservative, leading to false positives (skipping less likely than false negatives). Not as effective for dense volumes where most regions are non-empty.
*   **When to use:** Sparse volumes, medical imaging (CT scans), scientific visualization with large empty regions.
*   **When not to use:** Dense volumes, volumes with high-frequency details where min/max bounds are too conservative, or when preprocessing time is prohibitive.

## Background
Empty space skipping with octrees was introduced by Levoy as an optimization for volume ray casting, allowing rays to advance more quickly through coherent regions of empty voxels [S4, unofficial]. The technique exploits ray coherence between frames to further optimize leaping decisions, resulting in interactive rendering rates for moderately sized volumes [S2]. It is a fundamental acceleration technique in semi-transparent volume rendering, reducing the number of reconstruction samples by skipping empty regions using spatial data structures like octrees, BVHs, and kd-trees [S1].
