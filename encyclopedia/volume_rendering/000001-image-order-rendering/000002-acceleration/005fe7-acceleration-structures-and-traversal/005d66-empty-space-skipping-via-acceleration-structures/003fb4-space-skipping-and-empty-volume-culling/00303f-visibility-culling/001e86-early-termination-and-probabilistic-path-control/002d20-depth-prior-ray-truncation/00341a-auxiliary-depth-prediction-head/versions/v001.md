# Auxiliary Depth Prediction Head

Also called: Depth-guided point sampling, Pseudo-depth Guided Sampling

## Overview
The Auxiliary Depth Prediction Head is a module that predicts depth maps and confidence scores jointly with radiance field reconstruction to supervise rendered depth, narrow the depth range, and guide point sampling [S1, unofficial]. It differs from methods relying on third-party depth estimation (e.g., COLMAP) by learning depth implicitly through the network, resulting in more compact geometry learning [S1, unofficial]. In streaming contexts, it can also refer to leveraging truncated depth from reference frames to predict early stopping positions for tiles, balancing workload and excluding distant geometry [S2].

## How it works
The method operates in two distinct contexts found in the literature: multi-scale neural radiance field reconstruction [S1, unofficial] and streaming 3D Gaussian Splatting [S2].

### Inputs and Outputs
**Inputs:**
*   Source images (for reconstruction) or Reference frame $F_{ref}$, scene depth map $D_{ref}$, truncated depth max map $D_{ref}^{max}$, reference viewpoint $V_{ref}$, target viewpoint $V_{tgt}$ (for streaming) [S1, unofficial][S2].
*   Encoding volumes $V^l$ at each scale $l$ [S1, unofficial].

**Outputs:**
*   Predicted depth map $D^l$ and confidence score $U^l$ [S1, unofficial].
*   Target frame $F_{tgt}$ and tile-level truncated depth map $D_{T}^{max}$ [S2].

### Data Structures
*   **Encoding Volume $V^l$**: Multi-scale feature volume. The depth head is appended after each scale encoding volume [S1, unofficial].
*   **Depth Map $D^l$**: 2D map of predicted depth values per pixel at scale $l$ [S1, unofficial].
*   **Confidence Map $U^l$**: 2D map of confidence scores associated with the depth prediction [S1, unofficial].
*   **Tile Group $T$**: Set of tiles covering the target frame [S2].

### Parameters
*   **Number of encoding points $[N^A_l]$**: $[48, 32, 8]$ for three levels [S1, unofficial].
*   **Reduction factor $\alpha_l$**: $[1/6, 1/4, 1/2]$ for three levels [S1, unofficial].
*   **Depth range reduction factor $\beta_l$**: $[1/6, 1/16]$ (Note: Source lists two values for three levels, implying a potential typo or missing value in the source text) [S1, unofficial].
*   **Rerendering threshold $N_0$**: Heuristic threshold for valid pixel count in a tile [S2].

### Steps

#### Context 1: Multi-Scale Radiance Field Reconstruction [S1, unofficial]

1.  **Depth Prediction**: For each scale $l$, apply a convolutional layer $F_{depth}$ to the encoding volume $V^l$ to predict depth $D^l$ and confidence $U^l$:
    $$ D^l, U^l = F_{depth}(V^l) $$
    [S1, unofficial]

2.  **Depth Supervision**: Train the head in an unsupervised manner using the same loss function as standard unsupervised MVS tasks [S1, unofficial]. This loss supervises the pixel depth calculated by volume rendering [S1, unofficial].

3.  **Narrow Depth Range**: For the next level $l+1$, narrow the depth range $R_{l+1}$ to be centered on the predicted depth value $D^l$ with a width reduced by factor $\beta_l$:
    $$ R_{l+1} = R_l \times \beta_l $$
    [S1, unofficial]

4.  **Guide Point Sampling**: Use the predicted depth map $D^l$ to guide the placement of sampling points, reducing the number of points needed compared to uniform sampling [S1, unofficial].

#### Context 2: Streaming 3D Gaussian Splatting [S2]

1.  **Initialize**: Initialize target frame $F_{tgt}$ and tile-level truncated depth map $D_{T}^{max}$ [S2].

2.  **Project to 3D**: Project reference frame pixels to 3D points using reference depth:
    $$ P_{ref}, P_{ref}^{max} \leftarrow \text{ProjectTo3D}(F_{ref}, D_{ref}, D_{ref}^{max}) $$
    [S2]

3.  **View Transfer**: Transform 3D points to the target viewpoint:
    $$ P_{tgt}, P_{tgt}^{max} \leftarrow \text{ViewTransfer}(P_{ref}, P_{ref}^{max}) $$
    [S2]

4.  **Reproject**: Reproject points back to the target image plane:
    $$ F_{tgt}, D_{tgt} \leftarrow \text{Reproject}(P_{tgt}, P_{tgt}^{max}) $$
    [S2]

5.  **Tile Processing**: For each tile $t$ in $T$:
    *   Count valid pixels $N = \text{ValidPixelSum}(F_{tgt}, t)$ [S2].
    *   If $N > N_0$: Interpolate color $F_{tgt}$ for tile $t$ [S2].
    *   Else:
        *   Set tile truncated depth $D_{T}^{max} = \text{Max}(D_{tgt}, t)$ [S2].
        *   Re-render tile $t$ [S2].

6.  **Gaussian Culling**: Exclude any Gaussians with depth beyond the predicted early stopping depth (tile-level $D_{T}^{max}$) from the sorting stage in the target frame [S2].

### Pseudocode

```python
def auxiliary_depth_prediction_head(encoding_volume, scale_level):
    """
    Context 1: Multi-Scale Radiance Field Reconstruction
    Predicts depth and confidence from encoding volume.
    """
    # F_depth is a convolutional layer
    depth_map, confidence_map = F_depth(encoding_volume)
    return depth_map, confidence_map

def streaming_depth_guided_culling(reference_frame, ref_depth, ref_depth_max, 
                                   ref_viewpoint, target_viewpoint, threshold_N0):
    """
    Context 2: Streaming 3D Gaussian Splatting
    Predicts early stopping depth for tiles to cull distant Gaussians.
    """
    # Initialize outputs
    target_frame = Initialize()
    tile_truncated_depth_map = Initialize()
    
    # Step 2: Project to 3D
    points_3d, points_3d_max = ProjectTo3D(reference_frame, ref_depth, ref_depth_max)
    
    # Step 3: View Transfer
    points_tgt, points_tgt_max = ViewTransfer(points_3d, points_3d_max)
    
    # Step 4: Reproject
    target_frame, depth_tgt = Reproject(points_tgt, points_tgt_max)
    
    tiles = GetTiles(target_frame)
    
    for tile in tiles:
        # Step 5: Tile Processing
        valid_pixel_count = ValidPixelSum(target_frame, tile)
        
        if valid_pixel_count > threshold_N0:
            # Interpolate if enough valid pixels
            Interpolate(target_frame, tile)
        else:
            # Estimate early stopping depth for this tile
            max_depth = Max(depth_tgt, tile)
            tile_truncated_depth_map[tile] = max_depth
            
            # Re-render if sparse
            ReRender(target_frame, tile)
            
    return target_frame, tile_truncated_depth_map
```

### Edge Cases and Pitfalls
*   **Missing Parameter Value**: The source for multi-scale reconstruction lists two values for $\beta_l$ ($[1/6, 1/16]$) but specifies three levels ($[48, 32, 8]$ and $[1/6, 1/4, 1/2]$). The implementation should verify if the third value is missing or if the list is truncated [S1, unofficial].
*   **Occlusion and Lighting**: Geometric information in point volume features may be inaccurate due to occlusion or lighting variations, which affects the reliability of the predicted depth for guiding sampling [S1, unofficial].
*   **Threshold Selection**: The rerendering threshold $N_0$ is a heuristic; improper selection may lead to excessive re-rendering or inaccurate depth estimation [S2].

## Operating characteristics
*   **Time Complexity**: In the streaming context, the viewpoint transformation and tile processing allow for workload balancing and culling of distant Gaussians, reducing sorting and rendering load for tiles with sufficient valid pixels [S2]. In the reconstruction context, it adds the cost of the depth head convolution but reduces the number of sampling points required for radiance field rendering [S1, unofficial].
*   **Memory Complexity**: Requires storing additional depth and confidence maps per scale [S1, unofficial].
*   **Strengths**: Enables more compact geometry learning compared to third-party depth methods; allows for accurate load estimation and balanced task allocation in streaming scenarios [S1, unofficial][S2].
*   **Limitations**: Relies on the accuracy of the unsupervised depth prediction; performance may degrade in regions with poor texture or severe occlusion [S1, unofficial].

## Background
The concept originates from improving Neural Radiance Fields (NeRF) and Multi-View Stereo (MVS) by integrating depth prediction directly into the learning pipeline. Jingliang Li et al. proposed the "Improved Neural Radiance Fields Using Pseudo-depth and Fusion" method, which trains an auxiliary depth prediction head jointly with radiance field reconstruction to guide sampling and supervise depth [S1, unofficial]. Later, the concept was adapted for streaming 3D Gaussian Splatting to handle viewpoint transformations efficiently by leveraging truncated depth from reference frames to predict early stopping points [S2].
