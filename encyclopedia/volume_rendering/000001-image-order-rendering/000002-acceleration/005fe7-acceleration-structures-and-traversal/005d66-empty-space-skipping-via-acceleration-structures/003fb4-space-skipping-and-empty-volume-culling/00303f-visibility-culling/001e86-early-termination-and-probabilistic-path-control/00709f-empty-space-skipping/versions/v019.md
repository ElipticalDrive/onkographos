# Empty-space skipping

Also called: ESS, Early Ray Termination (ERT), Empty Region Skipping, Empty Space Rendering, Empty space culling

## Overview
Empty-space skipping is an acceleration technique for volume rendering that reduces computational cost by identifying and bypassing regions of the volumetric dataset that are transparent or contain no relevant data [S1, S2, S3, unofficial]. It solves the problem of wasted computation when ray marching through empty space, which constitutes a significant portion of the processing time in standard ray casting [S3, S7, unofficial]. Unlike [Early Stop](1790-early-stop.md) which terminates rays based on accumulated opacity, or [Russian Roulette](1371-russian-roulette.md) which probabilistically terminates rays, empty-space skipping uses auxiliary data structures (such as octrees, bounding volumes, or occupancy grids) to determine the boundaries of empty regions and "jump" over them [S2, S9, unofficial][S10]. It sets itself apart from [Bounding Volume Culling](1239-bounding-volume-culling.md) by operating on the internal density distribution of the volume rather than just the external geometric bounds, allowing it to skip holes and transparent interiors [S7, unofficial].

## How it works
**Inputs:**
*   Ray origin $\mathbf{o}$ and direction $\mathbf{d}$.
*   Volume dataset $V$ (scalar field).
*   Transfer function $TF$ mapping scalar values to color/opacity.
*   Empty-space data structure $D$ (e.g., octree, bounding hull, occupancy grid).

**Outputs:**
*   Final pixel color $C_{final}$.
*   List of sampled points (for debugging/analysis).

**Data Structures:**
The specific layout depends on the variant, but common structures include:
1.  **Octree/BSP Tree:** Nodes store min/max scalar values or boolean occupancy flags for their sub-volume [S9, S13, unofficial].
2.  **Bounding Hull:** A set of primitives (triangles/quads) enclosing the non-empty region [S3, unofficial].
3.  **Occupancy Grid:** A 3D texture or array where each voxel indicates if the region is empty (0) or occupied (1) [S5, unofficial][S18].
4.  **Distance Map:** Stores the distance to the nearest occupied voxel for each cell [S4, unofficial].

**Algorithm Steps:**

1.  **Initialize Ray:** Determine the entry point into the volume or the bounding hull. If a hull is used, compute the intersection of the ray with the hull to find the start parameter $t_{start}$ [S1, S3, unofficial]. If no hull is used, start at the near clipping plane or the first non-empty voxel detected by the acceleration structure [S1, unofficial].

2.  **Traversal Loop:** While the ray is within the volume bounds and has not reached full opacity (if Early Ray Termination is combined):
    a.  **Query Empty Space:** Check the current ray segment against the data structure $D$.
        *   If using a **Tree**: Traverse the tree. If a node is marked empty (e.g., max value below opacity threshold, or occupancy flag false), skip the entire subtree [S9, S13, unofficial].
        *   If using a **Hull**: The ray is already inside the hull; sample until exit [S3, unofficial].
        *   If using an **Occupancy Grid/Distance Map**: Sample the grid at the current position. If empty, calculate the skip distance $\Delta t_{skip}$ based on the distance to the next occupied cell [S4, S5, unofficial].
    b.  **Advance Ray:**
        *   If empty space is detected, advance the ray parameter $t$ by $\Delta t_{skip}$ (or the size of the empty block) [S6][S9, unofficial].
        *   If non-empty space is detected, or if the structure does not support skipping (e.g., standard ray casting without acceleration), advance by the standard step size $\Delta t$ [S4, unofficial].
    c.  **Sample Volume:** At the new position $\mathbf{p} = \mathbf{o} + t\mathbf{d}$, evaluate the volume density $\sigma(\mathbf{p})$ and color $\mathbf{c}(\mathbf{p})$ using the transfer function [S4, unofficial].
    d.  **Composite:** Update the accumulated color and opacity using front-to-back compositing:
        $$ \alpha_{sample} = 1 - e^{-\sigma(\mathbf{p}) \Delta t} $$
        $$ C_{acc} = C_{acc} + \mathbf{c}(\mathbf{p}) \cdot \alpha_{sample} \cdot (1 - \alpha_{acc}) $$
        $$ \alpha_{acc} = \alpha_{acc} + \alpha_{sample} \cdot (1 - \alpha_{acc}) $$
    e.  **Check Termination:** If $\alpha_{acc}$ exceeds a threshold (e.g., 0.98), terminate the ray [S4, unofficial][S6].

3.  **Output:** Return $C_{acc}$ as the final pixel color.

**Pseudocode (Generic ESS with Distance Map/Grid):**

```python
def render_ray_with_ess(ray_origin, ray_dir, volume_texture, ess_structure, step_size):
    # Initialize accumulation
    acc_color = vec3(0.0)
    acc_alpha = 0.0
    
    # Determine start point
    # If using hull, compute intersection. Here we assume starting from volume entry.
    t = 0.0
    max_t = volume_extent_length # Precomputed or derived from volume bounds
    
    # Step size for standard sampling
    dt = step_size
    
    while t < max_t and acc_alpha < 0.98:
        # Current position
        pos = ray_origin + ray_dir * t
        
        # 1. Query Empty Space Structure
        # Get the distance to the next non-empty region from the current pos
        dist_to_next = ess_structure.query_distance(pos)
        
        # 2. Determine Step
        # If dist_to_next is 0 or very small, we are in or near empty space.
        # We can skip up to dist_to_next.
        # However, we must ensure we don't skip over the actual data.
        # A safe skip is min(dist_to_next, dt * multiplier) or just dist_to_next if precise.
        
        if dist_to_next > 0:
            # We are in empty space. Skip to the boundary.
            # Clamp skip to not overshoot volume bounds
            skip_dist = min(dist_to_next, max_t - t)
            t += skip_dist
            continue # Skip sampling for this step
            
        # 3. Sample Volume (if not skipped)
        # Fetch density/value from volume texture
        value = volume_texture.sample(pos)
        
        # Apply Transfer Function to get color and opacity
        color, alpha = transfer_function(value)
        
        # Front-to-back compositing
        # Note: alpha here is the sample's opacity contribution
        sample_alpha = alpha * (1.0 - acc_alpha)
        acc_color += color * sample_alpha
        acc_alpha += sample_alpha
        
        # 4. Advance by standard step
        t += dt
        
    return acc_color
```

**Parameters:**
*   `step_size`: The base sampling distance. Typical values depend on volume resolution and desired quality [S4, unofficial].
*   `alpha_threshold`: Threshold for early ray termination. Typical value: $10^{-4}$ for transmittance or $0.98$ for accumulated opacity [S4, S5, unofficial].
*   `empty_threshold`: The density/opacity value below which a region is considered empty. Typical value: $10^{-2}$ [S5, unofficial].
*   `skip_multiplier`: In simple implementations, the factor by which step size is increased in empty space. Typical value: 6 [S6].

**Edge Cases and Pitfalls:**
*   **Degenerate Rays:** Rays with infinite length, NaN components, or length $> \sqrt{3}$ (in normalized coordinates) should be terminated immediately to prevent performance regressions [S4, unofficial].
*   **Backtracking:** When using distance maps, if the distance to the next occupied voxel is 0 (meaning the ray is exactly on a boundary or the map is coarse), the algorithm may need to backtrack or use a smaller step to ensure no data is missed [S4, unofficial].
*   **Transfer Function Dependency:** Empty space is often defined by the transfer function (e.g., low density regions). If the TF changes, the acceleration structure may need to be rebuilt or updated [S1, S8, unofficial].
*   **Load Imbalance:** In parallel rendering, tiles with less volume coverage may finish much faster than those with dense data, causing load imbalance if work assignment is static [S15, unofficial].
*   **Intermediate Pass Overhead:** In some GPU implementations, an intermediate pass is required to check for empty space and update z-values for early-z testing. This pass cannot be discarded even if Early Ray Termination is active, adding overhead [S8, unofficial].

### TF-Adaptive Empty-Space Skip
A raymarch acceleration technique that skips volume cells provably contributing zero opacity by checking if the cell's stored max deviation is below a cutoff derived from live contrast/trim uniforms [S20, unofficial]. It declares a binding (the max pyramid) in the fragment shader and consults it coarse-to-fine (level 1, then level 0) before paying for a full-res sample [S20, unofficial]. When a skip occurs, it lands back on the fixed step grid defined by $t_{min} + jitter + k \cdot stepLength$ to ensure bit-identical results [S20, unofficial]. The cutoff is calculated as $cutoff = (deadband - 0.05)$, where $deadband$ is derived from $applyContrastWindow$; if the cell's max deviation is less than this cutoff, the cell is skipped [S20, unofficial]. A pitfall is that in dense cosmic-web structures (volume-inside pose), the coarse+fine pyramid check rarely proves a cell empty, adding two $textureLoad$ + slab-test pairs per step with no skip payoff, causing a net regression (+47% volume, +65% scalar-volume per-layer) [S20, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the data structure. Tree traversal is $O(\log N)$ per ray segment, while grid lookup is $O(1)$. The number of samples is reduced by a factor proportional to the empty space ratio [S7, unofficial].
*   **Memory Complexity:** Requires additional storage for the acceleration structure. For an octree, this is typically $O(N)$ where $N$ is the number of voxels, but often much less if the tree is sparse [S9, unofficial]. Occupancy grids add $O(N)$ bits per voxel [S5, unofficial].
*   **Measured Performance:** In typical real-world examples with opaque structures and empty regions, Empty-Space Skipping (RC-β) significantly outperforms standard Ray Casting (RC). For example, on a Head dataset, RC-β achieved 23.4 fps compared to 4.8 fps for RC and 14.4 fps for RC with only Early Ray Termination [S8, unofficial]. Other implementations report 2.3x to 5x performance gains [S17, unofficial]. In neural rendering contexts, ESS increased rendering speed from 1345 ms to 133 ms for a single shared MLP model [S18].
*   **Strengths:** Significant speedup for sparse volumes; reduces memory bandwidth usage by skipping texture fetches in empty regions [S5, unofficial][S10].
*   **Limitations:** Overhead of building and traversing the acceleration structure; less effective for dense volumes with little empty space; transfer function changes may require structure updates [S8, S13, unofficial].
*   **When to Use:** Sparse volumes, large datasets with significant background/empty space, interactive applications requiring high frame rates [S1, unofficial][S10].
*   **When Not to Use:** Dense volumes with minimal empty space, where the overhead of traversal outweighs the savings from skipping [S7, unofficial].

## Background
Empty-space skipping originated as a fundamental optimization in volume ray casting to address the high computational cost of evaluating hundreds to thousands of samples per ray [S7, unofficial]. Early methods involved rasterizing bounding geometry to skip empty space before and after the object [S7, unofficial]. Later, hierarchical structures like octrees and BSP trees were introduced to allow skipping of internal empty regions [S9, S13, unofficial]. The technique has been widely adopted in GPU-based volume rendering, with implementations by Klein et al. and Lee and Shin exploiting spatial coherence and frame-to-frame estimates [S10]. It remains a core component of modern volume rendering pipelines, including neural radiance fields (NeRFs) where occupancy grids are used to prune empty space during training and inference [S5, unofficial][S18].
