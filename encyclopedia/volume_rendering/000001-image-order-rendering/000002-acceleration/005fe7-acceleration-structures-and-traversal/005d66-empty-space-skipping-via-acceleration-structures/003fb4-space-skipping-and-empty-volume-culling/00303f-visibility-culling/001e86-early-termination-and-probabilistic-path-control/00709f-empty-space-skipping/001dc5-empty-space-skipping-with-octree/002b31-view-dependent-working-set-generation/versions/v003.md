# View-Dependent Working Set Generation

Also called: Incremental refinement procedure

## Overview
This method constructs a view-dependent working set of non-empty octree nodes for out-of-core volume rendering, hiding I/O latency through asynchronous data loading [S1]. It differs from static culling methods by dynamically refining a sorted set of visible nodes based on screen-space projection and transfer-function opacity, ensuring only necessary data resides in GPU memory [S1].

## How it works
**Inputs:** Octree root node, current camera view parameters, isovalue (for isosurface) or transfer function (for volume rendering), GPU cache capacity, CPU cache capacity.
**Outputs:** A set of leaf nodes (the "cut") representing the current view-dependent working set, loaded into GPU texture caches.

**Data Structures:**
1.  **Working Set:** A sorted list of octree nodes. Initially contains only the root.
2.  **CPU Cache:** A pool of blocks stored in system memory, managed via LRU policy. Acts as a level-2 cache to avoid disk I/O for recently used blocks [S1].
3.  **GPU Texture Cache:** A preallocated 3D texture pool.
    *   **Value Texture:** 16-bit single channel [S1].
    *   **Gradient Texture:** RGBA8 format. RGB components store normalized gradients; Alpha component stores gradient norm [S1].
    *   Updates are performed incrementally using `glTexSubImage` calls [S1].

**Algorithm Steps:**

1.  **Initialization:** Initialize the working set $W$ with the octree root node [S1].
2.  **Sorting:** Sort $W$ by decreasing projected screen-space size of the voxels represented by the nodes. Visibility information (frustum culling) can be incorporated here to exclude occluded zones [S1].
3.  **Refinement Loop:** While termination conditions are not met:
    a.  Select the highest-priority node $n$ from $W$ (top of sorted list).
    b.  **Check Availability:** Determine if the data for $n$'s children is available in the CPU cache or must be fetched asynchronously from disk. If data is not immediately available, skip refinement for this node and proceed to the next in the sorted list (asynchronous loading hides latency) [S1].
    c.  **Empty Node Determination:** Check if $n$ is empty.
        *   *Isosurface Rendering:* $n$ is non-empty if the isovalue $I$ satisfies:
            $$ \min(n) \le I \le \max(n) $$
            where $\min(n)$ and $\max(n)$ are the minimum and maximum values within the cell [S1].
        *   *Volume Rendering:* Use summed-area tables (SAT) of transfer function opacity. Let $T_{min}$ and $T_{max}$ be the SAT entries for the minimum and maximum block values. The node is non-empty if:
            $$ \text{Opacity}(T_{max}) - \text{Opacity}(T_{min}) > \epsilon $$
            where $\epsilon$ is a small threshold [S1].
    d.  **Frustum Check:** If $n$ is outside the view frustum, mark as terminal (empty for rendering purposes) [S1].
    e.  **Subdivision:** If $n$ is non-empty and inside the frustum:
        i.  Remove $n$ from $W$.
        ii. Add $n$'s children to $W$.
        iii. Load child data into CPU/GPU caches if not present.
4.  **Termination:** Stop when:
    *   All nodes in $W$ are adequately refined (e.g., max depth reached).
    *   No data is currently available in-core to perform further refinement (and async load is not ready).
    *   No more space is available in the GPU cache for further subdivision [S1].
5.  **Cache Management:** Maintain LRU policy for both CPU and GPU caches to evict least recently used blocks [S1].

**Pseudocode:**

```python
def generate_working_set(root, camera, isovalue, transfer_function, gpu_cache_size, cpu_cache):
    # W is the sorted list of nodes to refine
    W = [root]
    
    while not is_terminated(W, gpu_cache_size, cpu_cache):
        # Sort by projected screen size (largest first)
        W.sort(key=lambda node: node.projected_screen_area, reverse=True)
        
        refined_any = False
        for i, node in enumerate(W):
            # Check frustum
            if not camera.frustum_contains(node.bounding_box):
                continue # Terminal due to visibility
            
            # Check if children data is available
            if not cpu_cache.has_data(node.children):
                # Data not available; skip this node for now.
                # Async loader will fetch it.
                continue
            
            # Determine if node is empty
            is_empty = False
            if isosurface_mode:
                if not (isovalue >= node.min_val and isovalue <= node.max_val):
                    is_empty = True
            else:
                # Volume rendering with SAT
                opacity_diff = transfer_function_opacity(node.max_val) - transfer_function_opacity(node.min_val)
                if opacity_diff < EPSILON:
                    is_empty = True
            
            if is_empty:
                continue # Terminal node
            
            # Refine: remove node, add children
            W.pop(i)
            for child in node.children:
                # Ensure child data is in cache
                cpu_cache.ensure_loaded(child)
                gpu_cache.ensure_loaded(child)
                W.append(child)
            
            refined_any = True
            # Note: In a real implementation, one might break or continue
            # based on cache pressure. The source implies processing the
            # sorted list until termination conditions hit.
        
        # If no refinement happened in this pass due to cache misses,
        # the loop continues, relying on async data arrival.
        if not refined_any:
            # Wait for async data or check termination
            if not cpu_cache.has_pending_data():
                break

    return W

def is_terminated(W, gpu_cache_size, cpu_cache):
    # Condition 1: All nodes adequately refined (e.g., max depth)
    if all(node.is_leaf() for node in W):
        return True
    
    # Condition 2: No data available in-core to perform refinement
    # AND no pending async data
    if not any(cpu_cache.has_data(node.children) for node in W if not node.is_leaf()):
        if not cpu_cache.has_pending_data():
            return True
            
    # Condition 3: No space in GPU cache
    if gpu_cache_size.is_full():
        return True
        
    return False
```

Uses memory mapping to page in active nodes from a static on-disk octree, decoupling refinement and rendering to hide I/O latency.

## Operating characteristics
*   **Latency Hiding:** Relies on asynchronous data access requests performed by a separate thread to hide out-of-core disk I/O latency [S1].
*   **Cache Efficiency:** Uses LRU policy for both CPU (system memory) and GPU (texture) caches. The CPU cache acts as a level-2 cache, reducing disk accesses for recently used blocks [S1].
*   **Update Frequency:** Due to temporal and spatial coherence, the number of updated nodes per frame is generally small, allowing efficient incremental updates via `glTexSubImage` [S1].
*   **Limitations:** Performance depends on the effectiveness of the sorting heuristic (screen-space size) and the accuracy of the empty-node determination. If visibility culling is not integrated, occluded zones may be unnecessarily refined [S1].

## Background
This method was introduced in the context of interactive out-of-core volume rendering frameworks, specifically designed to reduce GPU stalls by exploiting renderer feedback to avoid loading occluded zones [S1]. It builds upon earlier work on empty-space skipping and summed-area tables for opacity estimation [S1].
