# Empty-space skipping

Also called: ESS, Empty Region Skipping, Empty Space Rendering, Empty space culling

## Overview
Empty-space skipping is an acceleration technique for volume rendering that reduces computational cost by identifying and bypassing regions of the volumetric dataset that are transparent or contain no relevant data [S1, S2, S3, unofficial]. It solves the problem of wasted computation when ray marching through empty space, which constitutes a significant portion of the processing time in standard ray casting [S3, S7, unofficial]. Unlike [Early Stop](1790-early-stop.md) which terminates rays based on accumulated opacity, or [Russian Roulette](1371-russian-roulette.md) which probabilistically terminates rays, empty-space skipping uses auxiliary data structures (such as octrees, bounding volumes, or occupancy grids) to determine the boundaries of empty regions and "jump" over them [S2, S9, unofficial][S10]. It sets itself apart from [Bounding Volume Culling](1239-bounding-volume-culling.md) by operating on the internal density distribution of the volume rather than just the external geometric bounds, allowing it to skip holes and transparent interiors [S7, unofficial].

## How it works
**Inputs:**
*   Ray origin $\mathbf{o}$ and direction $\mathbf{d}$ [S4, S9, unofficial].
*   Volume dataset $V$ (scalar field) [S1, S4, unofficial].
*   Transfer function $TF$ mapping scalar values to color/opacity [S1, S4, unofficial].
*   Empty-space data structure $D$ (e.g., octree, bounding hull, occupancy grid) [S2, S4, S9, S13, unofficial].

**Outputs:**
*   Final pixel color $C_{final}$ [S4, unofficial].

**Data Structures:**
The specific layout depends on the variant, but common structures include:
1.  **Octree/BSP Tree:** Nodes store min/max scalar values or boolean occupancy flags for their sub-volume [S9, S13, unofficial].
2.  **Bounding Hull:** A set of primitives (triangles/quads) enclosing the non-empty region [S3, unofficial].
3.  **Occupancy Grid:** A 3D texture or array where each voxel indicates if the region is empty (0) or occupied (1) [S5, unofficial][S18].
4.  **Distance Map:** Stores the distance to the nearest occupied voxel for each cell [S4, unofficial].

**Algorithm Steps:**

1.  **Initialize Ray:** Determine the entry point into the volume or the bounding hull. If a hull is used, compute the intersection of the ray with the hull to find the start parameter $t_{start}$ [S1, S3, unofficial]. If no hull is used, start at the near clipping plane or the first non-empty voxel detected by the acceleration structure [S1, unofficial].
2.  **Traversal Loop:** While the ray is within the volume bounds and has not reached full opacity (if Early Ray Termination is combined):
    a.  **Query Empty Space:** Check the current ray segment against the data structure $D$ [S2, S9, unofficial].
        *   If using a **Tree**: Traverse the tree. If a node is marked empty (e.g., max value below opacity threshold, or occupancy flag false), skip the entire subtree [S9, S13, unofficial].
        *   If using a **Hull**: The ray is already inside the hull; sample until exit [S3, unofficial].
        *   If using an **Occupancy Grid/Distance Map**: Sample the grid at the current position. If empty, calculate the skip distance $\Delta t_{skip}$ based on the distance map value [S4, S5, unofficial].
    b.  **Advance Ray:**
        *   If empty space is detected, advance the ray parameter $t$ by $\Delta t_{skip}$ (or the size of the empty block) [S6][S9, unofficial].
        *   If non-empty space is detected, or if the structure does not support skipping (e.g., standard ray casting without acceleration), advance by the standard step size $\Delta t$ [S4, unofficial].
    c.  **Sample Volume:** At the new position $\mathbf{p} = \mathbf{o} + t\mathbf{d}$, evaluate the volume density $\sigma(\mathbf{p})$ and color $\mathbf{c}(\mathbf{p})$ using the transfer function [S4, unofficial].
    d.  **Composite:** Update the accumulated color and opacity using front-to-back compositing:
        $$ \alpha_{sample} = 1 - e^{-\sigma(\mathbf{p}) \Delta t} $$
        $$ C_{acc} = C_{acc} + \mathbf{c}(\mathbf{p}) \cdot \alpha_{sample} \cdot (1 - \alpha_{acc}) $$
        $$ \alpha_{acc} = \alpha_{acc} + \alpha_{sample} \cdot (1 - \alpha_{acc}) $$
    e.  **Check Termination:** If $\alpha_{acc}$ exceeds a threshold (e.g., $0.98$ [S4, unofficial] or $0.99$ [S6]), terminate the ray.
3.  **Output:** Return $C_{acc}$ as the final pixel color [S4, unofficial].

**Pseudocode (Generic ESS with Distance Map/Grid):**

```python
def render_ray_with_ess(ray_origin, ray_dir, volume_texture, ess_structure, step_size, volume_bounds):
    # volume_bounds: [[min_x, min_y, min_z], [max_x, max_y, max_z]]
    t_near = 0.0
    t_far = float('inf')
    for i in range(3):
        inv_dir = 1.0 / ray_dir[i]
        t1 = (volume_bounds[0][i] - ray_origin[i]) * inv_dir
        t2 = (volume_bounds[1][i] - ray_origin[i]) * inv_dir
        t_near = max(t_near, min(t1, t2))
        t_far = min(t_far, max(t1, t2))
        
    if t_near > t_far or t_far < 0:
        return [0.0, 0.0, 0.0] # Ray misses volume
        
    acc_color = [0.0, 0.0, 0.0]
    acc_alpha = 0.0
    t = t_near
    
    while t < t_far and acc_alpha < 0.98:
        pos = [ray_origin[i] + ray_dir[i] * t for i in range(3)]
        
        # Query distance to nearest occupied region from ESS structure (implementation depends on data structure type)
        dist_to_occupied = ess_structure.query_distance(pos)
        
        if dist_to_occupied > step_size * 0.5:
            skip_dist = min(dist_to_occupied, t_far - t)
            t += skip_dist
            continue
            
        value = volume_texture.sample(pos)
        color = [value * 0.5, value * 0.5, value * 0.5]
        alpha = min(value * 0.1, 1.0)
        
        sample_alpha = alpha * (1.0 - acc_alpha)
        acc_color = [acc_color[i] + color[i] * sample_alpha for i in range(3)]
        acc_alpha += sample_alpha
        
        t += step_size
        
    return acc_color
```

**Parameters:**
*   `step_size`: The base sampling distance. Typical values depend on volume resolution and desired quality [S4, unofficial].
*   `alpha_threshold`: Threshold for early ray termination. Typical value: $10^{-4}$ for transmittance or $0.98$ for accumulated opacity [S4, S5, unofficial].
*   `empty_threshold`: The density/opacity value below which a region is considered empty. Typical value: $10^{-2}$ [S5, unofficial].
*   `skip_multiplier`: In simple implementations, the factor by which step size is increased in empty space. Typical value: 6 [S6].

**Edge Cases and Pitfalls:**
*   **Degenerate Rays:** Rays with infinite length, NaN components, or length $> \sqrt{3}$ (in normalized coordinates) should be terminated immediately to prevent performance regressions [S4, unofficial].
*   **Backtracking:** When using distance maps, if the distance to the next occupied voxel is 0 (meaning the ray is exactly on a boundary or the map is coarse), the algorithm may need to backtrack or use a smaller step to ensure no data is missed [S4, unofficial].
*   **Transfer Function Dependency:** Empty space is often defined by the transfer function (e.g., low density regions). If the TF changes, the acceleration structure may need to be rebuilt or updated [S1, S8, unofficial].
*   **Load Imbalance:** In parallel rendering, tiles with less volume coverage may finish much faster than those with dense data, causing load imbalance if work assignment is static [S15, unofficial].
*   **Intermediate Pass Overhead:** In some GPU implementations, an intermediate pass is required to check for empty space and update z-values for early-z testing. This pass cannot be discarded even if Early Ray Termination is active, adding overhead [S8, unofficial].

## Subtopics

### [Ray Marcher with Macrocell Empty Space Skipping](1009-ray-marcher-with-macrocell-empty-space-skipping.md)
Divides a volume into coarse macrocells and precomputes boolean occupancy flags to skip zero-density data. It sets itself apart from sibling methods by using a fixed, uniform grid hierarchy rather than a dynamic tree structure. Choose it for uniform grids where tree traversal overhead is undesirable.

### [Empty Space Skipping with Orthogonal BSP Tree](1054-empty-space-skipping-with-orthogonal-bsp-tree.md)
Partitions a volume into sub-volumes based on voxel properties and reorganizes them into an orthogonal Binary Space Partitioning (BSP) tree to skip transparent sub-volumes. It sets itself apart by handling arbitrary slicing plane orientations inherent in 3D texture rendering, requiring new sorting strategies compared to 2D texture stacks. Choose it for 3D texture rendering pipelines.

### [Empty Space Skipping with Octree](1610-empty-space-skipping-with-octree.md)
Skips empty regions using an octree spatial data structure to reduce reconstruction samples. It differs from siblings by storing conservative min/max scalar ranges at every node, allowing rays to leap over intervals where the maximum value is below the opacity threshold. Choose it for sparse volumes requiring large skips.

### [Spatial Skipping (Occupancy Grid)](1614-spatial-skipping-occupancy-grid.md)
Improves uniform sampling by identifying empty regions and skipping them, effectively creating a transmittance estimator based on the ratio of occupied steps. Choose it for dynamic scenes or when a simple, flat acceleration structure is preferred.

### [Brick Classification and Empty Space Skipping](2830-brick-classification-and-empty-space-skipping.md)
Categorizes volume bricks into skipped, early-terminated, or sampled states to bypass unnecessary computation. It distinguishes itself by maintaining a shared, per-brick classification table on both host and GPU memory, enabling ray-guided feedback where the renderer updates brick states during traversal. Choose it for GPU-accelerated pipelines requiring runtime feedback.

### [Free Space Skipping](4656-free-space-skipping.md)
Avoids computing expensive view-dependent color models for points in transparent or low-density regions by querying a hierarchy of density representations and discarding samples below alpha thresholds. Choose it for view-dependent radiance field models.

### [Parallel Tree-Construction for Empty-Space Skipping](5037-parallel-tree-construction-for-empty-space-skipping.md)
Enables run-time re-construction of acceleration data structures for empty-space skipping, primarily to accommodate dynamic changes in the transfer function. It distinguishes itself by allowing the hierarchy to be rebuilt on the GPU at interactive frame rates. Choose it for applications with frequently changing transfer functions.

### [Transfer-Function Independent Empty-Space Skipping](5038-transfer-function-independent-empty-space-skipping.md)
Stores visibility information in the acceleration structure independent of the transfer function, thereby avoiding reconstruction after transfer-function changes. It decouples spatial culling from opacity evaluation, enabling real-time transfer function adjustments without structural overhead. Choose it for interactive applications requiring rapid TF adjustments.

### [Homogeneity Acceleration](5754-homogeneity-acceleration.md)
Extends empty-space skipping by approximating the contribution of uniform, non-empty regions instead of sampling them voxel-by-voxel. It distinguishes itself by handling regions that contain data but lack internal variation, thereby reducing computational load where presence acceleration alone would still require per-sample evaluation. Choose it for smooth gradients or homogeneous regions.

## Operating characteristics
*   **Time Complexity:** Depends on the data structure. Tree traversal requires multiple look-ups per segment, while grid lookup is $O(1)$ [S7, unofficial]. The number of samples is reduced by a factor proportional to the empty space ratio [S7, unofficial].
*   **Memory Complexity:** Requires additional storage for the acceleration structure [S8, unofficial]. Occupancy grids add $O(N)$ bits per voxel [S5, unofficial].
*   **Measured Performance:** In typical real-world examples with opaque structures and empty regions, Empty-Space Skipping (RC-β) significantly outperforms standard Ray Casting (RC) [S8, unofficial]. For example, on a Head dataset, RC-β achieved 23.4 fps compared to 4.8 fps for RC and 14.4 fps for RC with only Early Ray Termination [S8, unofficial]. Other implementations report 2.3x to 5x performance gains [S17, unofficial]. In neural rendering contexts, ESS increased rendering speed from 1345 ms to 133 ms for a single shared MLP model [S18].
*   **Strengths:** Significant speedup for sparse volumes; reduces memory bandwidth usage by skipping texture fetches in empty regions [S5, unofficial][S10].
*   **Limitations:** Overhead of building and traversing the acceleration structure; less effective for dense volumes with little empty space; transfer function changes may require structure updates [S8, S13, unofficial].
*   **When to Use:** Sparse volumes, large datasets with significant background/empty space, interactive applications requiring high frame rates [S1, unofficial][S10].
*   **When Not to Use:** Dense volumes with minimal empty space, where the overhead of traversal outweighs the savings from skipping [S7, unofficial].

## Background
Empty-space skipping originated as a fundamental optimization in volume ray casting to address the high computational cost of evaluating hundreds to thousands of samples per ray [S7, unofficial]. Early methods involved rasterizing bounding geometry to skip empty space before and after the object [S7, unofficial]. Later, hierarchical structures like octrees and BSP trees were introduced to allow skipping of internal empty regions [S9, S13, unofficial]. The technique has been widely adopted in GPU-based volume rendering, with implementations by Klein et al. and Lee and Shin exploiting spatial coherence and frame-to-frame estimates [S10]. It remains a core component of modern volume rendering pipelines, including neural radiance fields (NeRFs) where occupancy grids are used to prune empty space during training and inference [S5, unofficial][S18].
