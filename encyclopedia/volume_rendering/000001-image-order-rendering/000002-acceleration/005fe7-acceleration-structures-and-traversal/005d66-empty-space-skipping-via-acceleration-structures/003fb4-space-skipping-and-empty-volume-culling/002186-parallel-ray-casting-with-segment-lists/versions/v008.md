# Parallel Ray Casting with Segment Lists


## Overview
Parallel Ray Casting with Segment Lists is a parallel rendering algorithm that distributes image rows across MPI ranks and OpenMP threads to accelerate volume rendering [S1, unofficial]. It uses segment lists to skip empty space and calculates sampling points based on a step length [S1, unofficial].

## How it works
**Inputs:** Image dimensions (width, height), camera parameters (position, direction, field of view), volume data structure (with block/brick layout), configuration (sampling rate, thread counts, MPI size) [S1, unofficial].
**Outputs:** Rendered image (pixel colors) [G].

**Data Structures:**
*   `raytracer` struct: Fields `m_start_x`, `m_start_y`, `m_end_x`, `m_end_y`, `m_width`, `m_height`, `m_depth`, `m_writer`, `m_threadId` [S2, unofficial].
*   `Segment`: Pair of floats `(s_beg, s_end)` representing the start and end distances of an active ray segment within the volume [S1, unofficial].
*   `point_list`: List of floats representing sampling positions along the ray [S1, unofficial].
*   `seg_list`: List of segment pairs returned by the volume structure [S1, unofficial].

**Parameters:**
*   `sampling_rate`: Controls step length. Typical value 1.0 [S1, unofficial].
*   `thread_nums`: Number of OpenMP threads. Default 4 [S1, unofficial].

**Steps:**
1.  **Calculate Step Length:**
    $$ step\_len = \frac{1.0}{sampling\_rate \cdot \|dims\|} $$
    where $\|dims\|$ is the norm of the volume dimension vector [S1, unofficial].
2.  **Determine Job Count:**
    If `config::multi_threading` is true, `jobs = config::core_count * config::core_thread_count`; else `jobs = 1` [S2, unofficial].
3.  **Calculate Row Distribution:**
    $$ line\_nums = \lceil \frac{height}{comm\_size} \rceil $$
    $$ t\_line\_nums = \lceil \frac{line\_nums}{thread\_nums} \rceil $$
    [S1, unofficial].
4.  **Precompute Block Offsets:**
    Iterate over brick dimensions $(k, j, i)$ [S1, unofficial]. Get block. If block is null, offset is -1. Else offset is `block->data - buf_base` [S1, unofficial].
5.  **Parallel Region:**
    For each thread `t_id`, iterate over `t_line_nums` [S1, unofficial]. Calculate row index:
    $$ row = my\_rank + (t\_id \cdot t\_line\_nums + i) \cdot comm\_size $$
    Break if $row \ge height$ [S1, unofficial].
6.  **Ray Generation:**
    For each column `col`, calculate pixel coordinates $u$ and $v$:
    $$ u = \left(-0.5 + \frac{col + 0.5}{width}\right) \cdot aspect $$
    $$ v = -0.5 + \frac{row + 0.5}{height} $$
    Calculate `ray_dir` using `cal_ray_dir` [S1, unofficial]. Normalize `ray_dir` [S1, unofficial].
7.  **Get Ray Distance to Volume BBox:**
    $$ seg = volume \rightarrow getRayDistance(cam\_pos, ray\_dir) $$
    [S1, unofficial].
8.  **Get Segment List:**
    $$ volume \rightarrow getSegList(*seg\_list, cam\_pos, ray\_dir) $$
    Clear `point_list` [S1, unofficial].
9.  **Iterate Over Segments:**
    For each segment $(s\_beg, s\_end)$ in `seg_list`:
    Align $s\_beg$ to step grid:
    $$ s\_beg = seg.x + \left\lceil \frac{s\_beg - seg.x}{step\_len} \right\rceil \cdot step\_len $$
    While $s\_beg \le s\_end$:
    Push $s\_beg$ to `point_list`.
    $s\_beg += step\_len$ [S1, unofficial].

**Pseudocode:**
```python
import math

def parallel_ray_casting_segment_lists(width, height, cam_pos, volume, config):
    # Step 1: Calculate step length
    dims = volume.get_dimensions()
    sampling_rate = config.get('sampling_rate', 1.0)
    step_len = 1.0 / (sampling_rate * math.sqrt(dims[0]**2 + dims[1]**2 + dims[2]**2))

    # Step 2: Determine job count
    if config.get('multi_threading', True):
        jobs = config.get('core_count', 1) * config.get('core_thread_count', 1)
    else:
        jobs = 1

    # Step 3: Calculate row distribution
    comm_size = config.get('comm_size', 1)
    thread_nums = config.get('thread_nums', 4)
    line_nums = math.ceil(height / comm_size)
    t_line_nums = math.ceil(line_nums / thread_nums)

    # Step 4: Precompute block offsets
    buf_base = volume.get_base_address()
    block_offsets = {}
    for k in range(volume.get_depth()):
        for j in range(volume.get_height()):
            for i in range(volume.get_width()):
                block = volume.get_block(k, j, i)
                if block is None:
                    block_offsets[(k, j, i)] = -1
                else:
                    block_offsets[(k, j, i)] = block.data - buf_base

    # Step 5 & 6: Parallel Region
    for t_id in range(thread_nums):
        for i in range(t_line_nums):
            row = config.get('my_rank', 0) + (t_id * t_line_nums + i) * comm_size
            if row >= height:
                break

            for col in range(width):
                u = (-0.5 + (col + 0.5) / width) * config.get('aspect', 1.0)
                v = -0.5 + (row + 0.5) / height
                ray_dir = cal_ray_dir(u, v, cam_pos, config)
                ray_dir = normalize(ray_dir)

                # Step 7: Get ray distance to volume bbox
                seg = volume.get_ray_distance(cam_pos, ray_dir)

                # Step 8: Get segment list
                seg_list = volume.get_seg_list(cam_pos, ray_dir)
                point_list = []

                # Step 9: Iterate over segments
                for s_beg, s_end in seg_list:
                    aligned_beg = seg.x + math.ceil((s_beg - seg.x) / step_len) * step_len
                    current_pos = aligned_beg
                    while current_pos <= s_end:
                        point_list.append(current_pos)
                        current_pos += step_len

                # Compositing loop [G]
                C_acc = [0.0, 0.0, 0.0]
                alpha_acc = 0.0
                for s in point_list:
                    C_sample, alpha_sample = volume.sample(
                        cam_pos[0] + ray_dir[0]*s, 
                        cam_pos[1] + ray_dir[1]*s, 
                        cam_pos[2] + ray_dir[2]*s
                    )
                    for k in range(3):
                        C_acc[k] += C_sample[k] * alpha_sample * (1.0 - alpha_acc)
                    alpha_acc += alpha_sample * (1.0 - alpha_acc)
                    if 1.0 - alpha_acc < 1e-4:
                        break
                # Clamp and set pixel [G]
                config.get('image').set_pixel(row, col, tuple(max(0, min(255, int(c))) for c in C_acc))

def cal_ray_dir(u, v, cam_pos, config):
    # Standard pinhole camera ray generation [G]
    return [u, v, -1.0]

def normalize(v):
    mag = math.sqrt(v[0]**2 + v[1]**2 + v[2]**2)
    return [v[0]/mag, v[1]/mag, v[2]/mag] if mag > 0 else [0, 0, 1]
```

## Subtopics

### Parallel Ray Casting on SIMD
A parallel implementation of ray casting on a SIMD architecture where data is aligned in the view direction [S3, unofficial]. A viewing ray is assigned to each processor of a massively parallel SIMD computer [S3, unofficial]. Pre-processing transforms data values so they are aligned in the view direction, and rotation is decomposed so communication between neighboring processors is only necessary along the main axes [S3, unofficial]. Ray-integration and integration for all pixels are performed in parallel [S3, unofficial]. One voxel is assigned to each processor [S3, unofficial]. This method cannot simultaneously scale the dataset [S3, unofficial]. Computing times vary from 5 to 30 seconds for a medium size dataset of $128^3$ nodes, depending on precision and illumination model complexity [S3, unofficial].
