# Empty Space Skipping via Acceleration Structures
## Overview
Empty space skipping via acceleration structures accelerates volume rendering by identifying and bypassing transparent or empty regions of the volume data before expensive sampling and compositing occur [G]. It sets itself apart from [SparseLeap](5152-sparseleap.md) by typically using scalar min/max values or occupancy flags rather than rasterized segment lists, and from [Hierarchical Bounding Box Tree for Empty-Space Skipping](8182-hierarchical-bounding-box-tree-for-empty-space-skipping.md) by employing fixed-grid brick structures or specific tree traversals rather than generic bounding box hierarchies [G].

## Shared principles
The core mechanism shared by all children is the reduction of work units (samples, voxels, or pixels) processed per frame while maintaining acceptable visual fidelity [G]. This is achieved through three primary strategies:
1. **Culling/Skipping:** Identifying regions of the volume or ray path that do not contribute to the final image (e.g., empty space, occluded voxels) and bypassing their evaluation [G].
2. **Termination:** Halting the integration loop when the accumulated contribution becomes negligible (e.g., high opacity, low transmittance) [G].
3. **Adaptation:** Varying the computational effort based on local scene complexity or global performance budgets [G].

Mathematically, these methods modify the standard front-to-back compositing loop [G]:
$$ C_{acc} = C_{acc} + C_{sample} \cdot \alpha_{sample} \cdot (1 - \alpha_{acc}) $$
$$ \alpha_{acc} = \alpha_{acc} + \alpha_{sample} \cdot (1 - \alpha_{acc}) $$
by introducing conditions that break the loop early, skip iterations, or reduce the number of $C_{sample}$ queries [G].

## Subtopics

### [SparseLeap](5152-sparseleap.md)
SparseLeap is a hybrid object-order (rasterization) and image-order (ray-casting) method for efficient empty space skipping in large, sparse volumes with fine structures. It decouples empty space skipping data structures from the underlying volume representation, avoiding the space fragmentation and hierarchy traversal overhead typical of standard octree-based approaches. By rasterizing view-independent occupancy geometry into per-pixel linked lists of ray segments, it moves the major cost of empty space skipping from the ray-casting shader to GPU hardware rasterization. Choose when rendering highly sparse volumes where traditional hierarchical traversal overhead dominates.

### [Hierarchical Bounding Box Tree for Empty-Space Skipping](8182-hierarchical-bounding-box-tree-for-empty-space-skipping.md)
This method accelerates traditional front-to-back ray casting for large-scale volumetric data (specifically aerosols like smoke, fog, and dust) by combining a Hierarchical Bounding Box Tree (BVH) for empty-space culling, early termination of the compositing loop, and adaptive sampling with grouped linear interpolation. It addresses the low efficiency and high resource consumption of standard ray casting when processing large scalar fields. Unlike sibling methods that may rely on octrees or sparse grids, this approach uses a BVH to avoid recording numerous empty nodes, thereby reducing computational complexity and allowing for dynamic updates when the dataset changes. Choose when rendering large-scale dynamic aerosols where BVH construction overhead is amortized over many frames.

### [SparseLeap Ray-Casting with Occupancy Misses](9818-sparseleap-ray-casting-with-occupancy-misses.md)
SparseLeap is a volume rendering technique that separates meta-data for empty space skipping from the volume data itself, using a ray-guided framework where ray segments are processed in a list. It extends standard ray-casting by adding an outer loop over ray segments and handling 'occupancy misses' to delay the determination of whether a brick is empty or non-empty until it is actually needed. Unlike octree-based skipping which incurs high depth complexity due to fragmented space subdivision, SparseLeap limits depth complexity significantly by substituting homogeneous sub-trees in the occupancy histogram tree on-the-fly. Choose when memory bandwidth is the bottleneck and lazy evaluation of occupancy can be leveraged.

### [Space Skipping and Empty Volume Culling](10063-space-skipping-and-empty-volume-culling.md)
Space Skipping and Empty Volume Culling refers to a family of acceleration techniques in volume rendering that reduce computational load by identifying and excluding primitives, voxels, or ray segments that do not contribute to the final image. It sets itself apart from sibling methods like [Hierarchical Bounding Box Tree for Empty-Space Skipping](8182-hierarchical-bounding-box-tree-for-empty-space-skipping.md) by encompassing a broader range of strategies, including geometric bounding volumes, visibility masks, and parallel segment lists, rather than relying solely on hierarchical tree traversal. It differs from [Early Termination and Probabilistic Path Control](1791-early-termination-and-probabilistic-path-control.md) by focusing on pre-computed or geometrically derived exclusion zones rather than just dynamic ray state termination. Choose when a flexible, geometry-agnostic culling strategy is needed across diverse rendering pipelines.

### [Empty-space skipping via Acceleration Structure](13062-empty-space-skipping-via-acceleration-structure.md)
This method accelerates direct volume rendering by using a hierarchical min/max acceleration structure to skip transparent regions of the volume data. It reduces the number of samples taken per ray by jumping over blocks that contain no visible data, distinct from sibling methods that may use sparse voxel grids or hierarchical bounding box trees. Choose when working with uniform or regularly structured volumes where a fixed-grid min/max acceleration structure can be efficiently pre-computed and traversed.

### [Progressive Ray Casting for Volumetric Models on Mobile Devices](16346-progressive-ray-casting-for-volumetric-models-on-mobile-devi.md)
This method addresses the computational constraints of interactive volume rendering on mobile devices by combining multiresolution data structures with acceleration techniques. It solves the trade-off between frame rate and visual fidelity by using a lower-resolution dataset for exploration and progressively refining high-resolution details in regions of interest. It distinguishes itself from sibling methods by explicitly targeting mobile hardware limitations and integrating Empty Space Skipping (ESS) and Early Ray Termination (ERT) within a progressive refinement framework. Choose when rendering on mobile GPUs with strict memory and compute budgets.

### Auxiliary terms for empty space skipping and smoke mitigation
A method to skip empty space using a hierarchical formulation to reduce computational impact, and a quadratic term on visibility to mitigate smoke-like artifacts in real scenes [S1, unofficial]. For each hierarchical level above the first, the voxel grid of the previous level is stored; if the density value for a voxel in that grid is smaller than a threshold $\lambda_v = 1.0$, the voxel is skipped and treated as empty [S1, unofficial]. An auxiliary loss $L_s = \lambda_s (-4(T - 0.5)^2 + 1)$ is applied, where $T$ is the total visibility for each ray and $\lambda_s = 0.1$, to mitigate smoke-like artifacts and keep real scenes sparse [S1, unofficial].

## Background
The concept of empty space skipping is fundamental to efficient volume rendering, particularly for large-scale datasets where most of the volume is transparent or empty [G]. The auxiliary terms for smoke mitigation were introduced in the context of view-dependent radiance fields to address shape-radiance ambiguity [S1, unofficial].
