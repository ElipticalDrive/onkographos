# Empty-space skipping via Acceleration Structure

Also called: Empty space skipping via the acceleration structure

## Overview
This method accelerates direct volume rendering by using a hierarchical min/max acceleration structure to skip transparent regions of the volume data [S2, unofficial]. It reduces the number of samples taken per ray by jumping over blocks that contain no visible data, distinct from sibling methods that may use sparse voxel grids or hierarchical bounding box trees [S1][S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A source volumetric dataset (e.g., $512 \times 512 \times 512$) and a pre-computed acceleration structure [S2, unofficial].
*   **Output:** A rendered image with reduced computational cost [S2, unofficial].

**Data Structures:**
The acceleration structure is a small two-channel volumetric dataset [S2, unofficial].
*   **Dimensions:** $16 \times 16 \times 16$ cells [S2, unofficial].
*   **Layout:** Each cell corresponds to a $32 \times 32 \times 32$ block in the source dataset [S2, unofficial].
*   **Content:** Each cell stores the minimum and maximum values found within its corresponding source block [S2, unofficial].
*   **Alternative Layout:** Some implementations use a per-field min/max structure organized in $32 \times 32 \times 32$ bricks [S1].

**Algorithm Steps:**
1.  For each ray, determine the intersection with the acceleration structure grid [S2, unofficial].
2.  Traverse the acceleration structure cells along the ray path using a 3D grid traversal algorithm [G].
3.  For each cell, retrieve the stored minimum and maximum values [S2, unofficial].
4.  Check if the space corresponding to the cell is transparent by comparing the maximum value against a visibility threshold [S2, unofficial].
5.  If the cell is transparent, skip the entire $32 \times 32 \times 32$ block and advance the ray to the next cell boundary [S2, unofficial].
6.  If the cell is not transparent, sample the source data within that block and perform standard front-to-back compositing [S2, unofficial].

**Pseudocode:**
```python
def render_ray(o, d, V, A, step=0.5, threshold=0.0):
    B = 32  # Block size in voxels
    N = 16  # Acceleration structure dimensions
    C_acc = [0.0, 0.0, 0.0]
    alpha_acc = 0.0

    # Initialize DDA for the 16x16x16 acceleration grid
    ix, iy, iz = int(o[0] // B), int(o[1] // B), int(o[2] // B)
    if not (0 <= ix < N and 0 <= iy < N and 0 <= iz < N):
        return C_acc

    t_max_x = ((ix + 1) * B - o[0]) / d[0] if d[0] != 0 else float('inf')
    t_max_y = ((iy + 1) * B - o[1]) / d[1] if d[1] != 0 else float('inf')
    t_max_z = ((iz + 1) * B - o[2]) / d[2] if d[2] != 0 else float('inf')
    t_delta_x = B / abs(d[0]) if d[0] != 0 else float('inf')
    t_delta_y = B / abs(d[1]) if d[1] != 0 else float('inf')
    t_delta_z = B / abs(d[2]) if d[2] != 0 else float('inf')
    step_x = 1 if d[0] > 0 else -1
    step_y = 1 if d[1] > 0 else -1
    step_z = 1 if d[2] > 0 else -1

    t_min = 0.0
    while 0 <= ix < N and 0 <= iy < N and 0 <= iz < N:
        t_next = min(t_max_x, t_max_y, t_max_z)
        if t_next < t_min:
            t_next = t_min

        min_val, max_val = A[ix, iy, iz]
        if max_val < threshold:
            t_min = t_next
            if t_next == t_max_x: ix += step_x; t_max_x += t_delta_x
            if t_next == t_max_y: iy += step_y; t_max_y += t_delta_y
            if t_next == t_max_z: iz += step_z; t_max_z += t_delta_z
            continue

        # Process volume block
        t_sample = t_min
        while t_sample < t_next and alpha_acc < 1.0:
            pos = [o[0] + d[0] * t_sample, o[1] + d[1] * t_sample, o[2] + d[2] * t_sample]
            # Standard volume lookup (e.g., trilinear interpolation or nearest-neighbor) [G]
            c_sample, a_sample = V[pos[0]], V[pos[1]], V[pos[2]]
            alpha_acc += a_sample * (1.0 - alpha_acc)
            C_acc[0] += c_sample[0] * a_sample * (1.0 - alpha_acc)
            C_acc[1] += c_sample[1] * a_sample * (1.0 - alpha_acc)
            C_acc[2] += c_sample[2] * a_sample * (1.0 - alpha_acc)
            t_sample += step
            if alpha_acc >= 1.0:
                break
        t_min = t_next
        if t_next == t_max_x: ix += step_x; t_max_x += t_delta_x
        if t_next == t_max_y: iy += step_y; t_max_y += t_delta_y
        if t_next == t_max_z: iz += step_z; t_max_z += t_delta_z

    return C_acc
```

**Parameters:**
*   **Block Size:** $32 \times 32 \times 32$ voxels [S2, unofficial].
*   **Acceleration Structure Resolution:** $16 \times 16 \times 16$ cells [S2, unofficial].
*   **Source Resolution Example:** $512 \times 512 \times 512$ [S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** Min/max values must accurately represent the range of the source block to avoid false negatives (skipping visible data) or false positives (skipping empty data) [S2, unofficial].
*   **Boundary Conditions:** Ray traversal must correctly handle entry and exit from the acceleration structure grid [S2, unofficial].

## Operating characteristics
*   **Performance:** Accelerates visualization by 1.5–2× compared to non-skipping methods [S3, unofficial].
*   **Complexity:** Time complexity scales with the number of non-empty cells traversed; measured speedup is 1.5–2× [S3, unofficial]. Memory complexity is dominated by the acceleration structure, which is significantly smaller than the source volume ($16^3$ vs $512^3$) [S2, unofficial].
*   **Strengths:** Simple to implement on GPU; effective for volumes with large transparent regions [S2, unofficial].
*   **Limitations:** Requires pre-computation of the acceleration structure [S2, unofficial].

## Background
This technique is an extension of CPU-based empty space skipping methods to GPU implementations [S2, unofficial]. It is used in direct volume rendering to optimize ray casting by avoiding unnecessary sampling of transparent regions [S1][S2, unofficial].
