# Adaptive Depth Sampling with Voxel Layer Alignment

Also called: Optimal Interpolation for Ray Casting

## Overview
Adaptive Depth Sampling with Voxel Layer Alignment is an acceleration technique for ray casting that reduces the computational cost of trilinear interpolation by aligning sample points with voxel grid layers to enable bilinear interpolation, while skipping intermediate samples via adaptive depth sampling [S2, unofficial]. It differs from standard trilinear interpolation by exploiting ray direction to align samples with voxel layers, allowing bilinear interpolation (lower cost) for half the points, and skipping intermediate points via adaptive depth sampling [S2, unofficial].

## How it works
The method operates on a regular 3D voxel grid. It assumes the volume data is stored in a 3D array where voxels are aligned to integer coordinates. The goal is to minimize the number of expensive trilinear interpolation operations during ray traversal.

**Inputs:**
*   Ray origin $\mathbf{o}$ and direction $\mathbf{d}$ (normalized).
*   Volume bounding box defined by min/max coordinates.
*   Voxel grid dimensions $W \times H \times D$ and physical spacing $\Delta x, \Delta y, \Delta z$.

**Outputs:**
*   A sequence of sample positions along the ray.
*   Interpolated density/value at those positions.

**Data Structures:**
*   Voxel Grid: A 3D array $V$ of size $W \times H \times D$.
*   Ray parameters: $t_{min}, t_{max}$ (entry/exit distances).

**Algorithm Steps:**

1.  **Determine Reference Axis:**
    Identify the axis ($x, y,$ or $z$) perpendicular to the parallel voxel layers that the ray traverses fastest. This is the axis with the smallest absolute component in the ray direction $\mathbf{d}$. Let this axis be $k$ and the corresponding spacing be $\Delta k$.
    *   If $|d_x| < |d_y|$ and $|d_x| < |d_z|$, then $k=x, \Delta k = \Delta x$.
    *   If $|d_y| < |d_x|$ and $|d_y| < |d_z|$, then $k=y, \Delta k = \Delta y$.
    *   Otherwise, $k=z, \Delta k = \Delta z$.

2.  **Decide First Sampling Position:**
    Calculate the entry point $t_{entry}$ where the ray intersects the volume bounding box. The first sample position $t_1$ is chosen such that the sample lies exactly on a voxel layer perpendicular to axis $k$.
    Let $p_k(t) = o_k + t \cdot d_k$ be the coordinate of the ray along axis $k$ at distance $t$.
    Find the smallest integer $n$ such that $p_k(t_{entry}) \le n \cdot \Delta k$.
    Set $t_1$ such that $p_k(t_1) = n \cdot \Delta k$.
    $$ t_1 = \frac{n \cdot \Delta k - o_k}{d_k} $$
    If $d_k = 0$, the ray is parallel to the layers; handle as a special case (e.g., use standard trilinear or skip if outside bounds) [G].

3.  **Calculate Sampling Interval:**
    Calculate the sampling interval $l$ along the ray such that every *alternate* sampling point lies exactly on a voxel layer perpendicular to axis $k$.
    The distance between two consecutive voxel layers along axis $k$ is $\Delta k$.
    The distance along the ray corresponding to $\Delta k$ is $\Delta t = \frac{\Delta k}{|d_k|}$.
    To have every alternate point on a layer, the step size $l$ must be half of $\Delta t$:
    $$ l = \frac{\Delta t}{2} = \frac{\Delta k}{2 |d_k|} $$
    This ensures that samples at $t_1, t_1 + 2l, t_1 + 4l, \dots$ lie on voxel layers, while samples at $t_1 + l, t_1 + 3l, \dots$ lie between layers.

4.  **Adaptive Depth Sampling and Interpolation:**
    Iterate along the ray starting from $t_1$ with step $l$. For each sample position $t_i$:
    *   **If $i$ is odd (1st, 3rd, ...):** The sample lies on a voxel layer. Use **bilinear interpolation** on the plane perpendicular to axis $k$. This requires 4 texture fetches and 3 multiplications/additions per axis, significantly cheaper than trilinear.
    *   **If $i$ is even (2nd, 4th, ...):** The sample lies between voxel layers. Use **simplified trilinear interpolation**. This requires 8 texture fetches and more arithmetic.
    *   **Adaptive Skipping:** To further accelerate, skip the time-consuming points between layers. The source states that skipping every other sample point (i.e., only processing the points on voxel layers) saved about 70% of ray traversal time [S1, unofficial][S2, unofficial].
        *   Implementation choice: If adaptive depth sampling is enabled, only evaluate samples at $t_1, t_1 + 2l, t_1 + 4l, \dots$ (the points on voxel layers). The points between layers are skipped entirely.
        *   If full resolution is required, evaluate all points but use the cheaper bilinear for the on-layer points.

**Pseudocode:**

```python
def adaptive_depth_sampling_ray_cast(ray_origin, ray_direction, volume_grid, bounds):
    # 1. Determine reference axis
    dx, dy, dz = ray_direction
    abs_dx, abs_dy, abs_dz = abs(dx), abs(dy), abs(dz)
    
    if abs_dx < abs_dy and abs_dx < abs_dz:
        axis = 'x'
        delta_k = volume_grid.spacing_x
        d_k = dx
    elif abs_dy < abs_dx and abs_dy < abs_dz:
        axis = 'y'
        delta_k = volume_grid.spacing_y
        d_k = dy
    else:
        axis = 'z'
        delta_k = volume_grid.spacing_z
        d_k = dz
        
    # Handle parallel ray case
    if abs(d_k) < 1e-9:
        return standard_trilinear_cast(ray_origin, ray_direction, volume_grid, bounds)

    # 2. Decide first sampling position
    # Find entry t
    t_min, t_max = compute_ray_box_intersection(ray_origin, ray_direction, bounds)
    if t_max < 0:
        return None # Ray does not hit volume
        
    # Calculate t1 such that sample lies on a voxel layer
    # p_k(t) = o_k + t * d_k = n * delta_k
    # t = (n * delta_k - o_k) / d_k
    o_k = ray_origin[axis]
    
    # Find smallest integer n such that o_k + t_min * d_k <= n * delta_k
    # We want the first layer >= entry point
    entry_k = o_k + t_min * d_k
    n = ceil(entry_k / delta_k)
    
    t1 = (n * delta_k - o_k) / d_k
    
    # Ensure t1 is within bounds
    if t1 < t_min:
        t1 = t_min
    if t1 > t_max:
        return None

    # 3. Calculate sampling interval
    # l = delta_k / (2 * |d_k|)
    l = delta_k / (2.0 * abs(d_k))
    
    # 4. Adaptive Depth Sampling Loop
    # Skip every other point to save time (70% speedup reported)
    # Only process points on voxel layers (odd indices in the sequence t1, t1+l, t1+2l...)
    # Sequence of t: t1, t1+2l, t1+4l...
    
    t = t1
    result = 0.0
    
    while t <= t_max:
        # Check if t is within volume bounds (redundant if t_max is correct, but safe)
        if t >= t_min:
            # Sample position
            pos = ray_origin + t * ray_direction
            
            # Interpolation
            if (t - t1) / (2 * l) % 2 == 0: # On voxel layer (0th, 2nd, 4th... in the 2l sequence)
                # Bilinear interpolation on plane perpendicular to axis
                val = bilinear_interpolate(volume_grid, pos, axis)
            else:
                # Simplified trilinear interpolation for points between layers
                # Note: If skipping, this branch is not taken
                val = trilinear_interpolate(volume_grid, pos)
                
            # Accumulate result (compositing logic omitted for brevity)
            result = composite(result, val)
            
        t += 2 * l # Skip intermediate points
        
    return result
```

**Edge Cases and Pitfalls:**
*   **Parallel Rays:** If the ray is parallel to the voxel layers ($d_k \approx 0$), the interval calculation divides by zero. The method must fall back to standard trilinear interpolation or a different strategy [G].
*   **Precision:** Floating-point errors in $t$ calculation may cause samples to drift off the exact voxel layer. Rounding to the nearest voxel coordinate before interpolation may be necessary [G].
*   **Boundary Conditions:** Ensure $t_1$ does not exceed $t_{max}$. If $t_1 > t_{max}$, no samples are taken.

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of samples along the ray. However, the constant factor is significantly reduced.
*   **Memory Complexity:** $O(1)$ auxiliary memory per ray.
*   **Performance:** Experimental results showed that this algorithm saved about 70% of ray traversal time by skipping over every other sample point along each ray [S1, unofficial][S2, unofficial].
*   **Strengths:** Reduces interpolation cost by using bilinear interpolation for half the samples. Adaptive depth sampling further reduces the number of samples.
*   **Limitations:** Requires regular voxel grid. May introduce aliasing if the skipping rate is too high. Not suitable for non-uniform grids without modification.

## Background
This method was proposed as part of a high-performance parallel volume rendering algorithm. It is described in the NASA Technical Reports Server document "Time-Critical Volume Rendering" [S1, unofficial][S2, unofficial]. The technique is also referred to as "Optimal Interpolation for Ray Casting" [S2, unofficial]. It builds on the idea of adaptive image sampling [5] (Levoy) by applying similar principles to the depth dimension along the ray.
