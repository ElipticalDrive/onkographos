# Adaptive Depth Sampling with Voxel Layer Alignment

Also called: Layered Interpolation, Optimal Interpolation, Optimal Interpolation for Ray Casting

## Overview
Adaptive Depth Sampling with Voxel Layer Alignment is an acceleration technique for ray traversal that reduces the computational cost of trilinear interpolation by aligning sample points with voxel layers to enable bilinear interpolation, while skipping intermediate samples via adaptive depth sampling [S1, S2, unofficial]. It differs from standard trilinear interpolation by exploiting ray direction to align samples with voxel layers, allowing bilinear interpolation for half the points, and skipping intermediate points via adaptive depth sampling [S2, unofficial].

## How it works
The method operates on a regular 3D grid where voxels are aligned to a uniform spacing [S2, unofficial]. Standard ray casting inputs (ray origin, direction, volume bounds, and voxel spacing) are assumed [G]. The algorithm produces a sequence of sample positions and their interpolated values [G]. No auxiliary data structures are required beyond the volume data and ray parameters [S2, unofficial].

**Steps:**

1. **Determine the reference axis:** Identify the axis perpendicular to the parallel voxel layers that are traversed fastest by the current ray [S2, unofficial]. This corresponds to the axis with the largest absolute component in the ray direction vector [G]. Let this axis be $k \in \{x, y, z\}$.
2. **Decide the first sampling position:** Set the initial sampling position to the point where the ray enters the volume [S1, S2, unofficial].
3. **Calculate sampling interval $l$:** Compute the interval $l$ along the ray such that every alternate sampling point lies exactly on a voxel layer perpendicular to the reference axis $k$ [S2, unofficial]. The sources specify the condition but do not provide the explicit mathematical formula; the interval is derived from the voxel spacing along $k$ and the ray's direction component along $k$ [G].
4. **Sample and Interpolate:** Use bilinear interpolation for each sampling point lying on a voxel layer, and simplified trilinear interpolation for points between layers [S2, unofficial]. Apply adaptive depth sampling to skip the time-consuming points between layers [S2, unofficial]. Specifically, skip every other sample point along the ray [S1, S2, unofficial].

    # Standard slab intersection to find entry/exit t values [G]
    t_min = -float('inf')
    t_max = float('inf')
    for i in range(3):
        if abs(ray_direction[i]) < 1e-9:
            if ray_origin[i] < volume_min[i] or ray_origin[i] > volume_max[i]:
                return []
        else:
            t1 = (volume_min[i] - ray_origin[i]) / ray_direction[i]
            t2 = (volume_max[i] - ray_origin[i]) / ray_direction[i]
            t_min = max(t_min, min(t1, t2))
            t_max = min(t_max, max(t1, t2))
    if t_min > t_max:
        return []

    # Step 3: Calculate interval l so every alternate point lands on a voxel layer along ref_axis [S2, unofficial]
    delta_k = voxel_spacing[ref_axis]
    d_k = ray_direction[ref_axis]
    if abs(d_k) < 1e-9:
        return [] # Ray parallel to voxel layers; fallback required [G]
    l = 2.0 * delta_k / abs(d_k)

    # Step 2: First sampling position at volume entry [S1, S2, unofficial]
    t = t_min
    samples = []

    while t <= t_max:
        pos = ray_origin + t * ray_direction
        # Check if sample lies on a voxel layer along the reference axis [G]
        grid_coord = pos[ref_axis] / delta_k
        is_on_layer = abs(grid_coord - round(grid_coord)) < 1e-6

        if is_on_layer:

            val = bilinear_interpolation(pos, voxel_spacing, ref_axis)
            samples.append((pos, val))

        t += l

    return samples

**Parameters:**
* Sampling interval $l$: Chosen so every alternate sampling point lies exactly on a voxel layer [S2, unofficial].
* Adaptive depth factor: Skip every other sample point along the ray [S1, S2, unofficial].

**Edge Cases and Pitfalls:**
* **Ray parallel to a voxel layer:** If the direction component along the reference axis is near zero, the ray is parallel to the voxel layers and the interval calculation divides by zero [G]. This requires a fallback to standard traversal or axis selection [G].
* **Precision:** Floating-point accumulation errors may cause points that should be on a layer to drift slightly off; a tolerance threshold is required when checking layer alignment [G].
* **Boundary conditions:** The slab intersection must correctly handle rays originating inside or outside the volume to avoid out-of-bounds sampling [G].

## Operating characteristics
* **Time Complexity:** The method reduces the number of interpolation operations by half and lowers the cost of the remaining interpolations from trilinear to bilinear [S2, unofficial]. Experimental results show the algorithm saved about 70% of ray traversal time by skipping over every other sample point along each ray [S1, S2, unofficial].
* **Memory Complexity:** No additional memory structures are required beyond the volume data and ray parameters [S2, unofficial].
* **Strengths:** Significant speedup in ray traversal time by exploiting the regular structure of the voxel grid [S2, unofficial].
* **Limitations:** Only applicable to regular 3D grids [S2, unofficial].
* **When to use:** When rendering regular 3D volumes with high performance requirements and ray traversal is the bottleneck, particularly when combined with boundary cell-based ray casting [S2, unofficial].

## Background
The method was proposed in the context of high-performance parallel volume rendering as part of a fast serial ray casting algorithm [S2, unofficial]. It is described in the NASA Technical Reports Server publication "Time-Critical Volume Rendering" [S1, S2, unofficial]. The technique is somewhat similar to Levoy's optimization of adaptive image sampling within the image plane [S1, S2, unofficial].
