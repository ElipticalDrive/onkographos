# Prediction Buffer Voxel Traversal

Also called: Local Traversal, Modified Depth Buffer Traversal, Prediction Buffer, Sparse Traversal

## Overview
Prediction Buffer Voxel Traversal is a GPU-accelerated dataset traversal technique that exploits frame-to-frame coherence during camera rotation to accelerate isosurface volume rendering [S1, unofficial]. It uses a modified depth buffer, called the prediction buffer, to store ray-cast results from the previous frame, allowing the renderer to skip large portions of the volume or refine local searches instead of performing a full traversal for every pixel [S1, unofficial]. Unlike C-buffer or image cache techniques that store coordinates or iso-maps and suffer from aliasing or lack data parallelism on GPUs, the prediction buffer stores depth distances and is designed for high-performance GPU parallelism [S1, unofficial].

## How it works

### Inputs and Outputs
*   **Inputs:**
    *   Ray $\mathbf{R}$ for each pixel, defined by origin $\mathbf{o}$ and direction $\mathbf{d}$.
    *   Volume dataset with bounding box defined by $t_{min}$ and $t_{max}$.
    *   Isosurface value $\rho_{iso}$.
    *   Prediction buffer from the previous frame.
    *   Step size parameter $dt$ (adaptive based on data variance).
*   **Outputs:**
    *   Intersection distance $t$ along the ray where $\rho(t) = \rho_{iso}$.
    *   Updated prediction buffer for the current frame.

### Data Structures
**Prediction Buffer:** A 2D array (one value per pixel) storing a single floating-point value $d_{ij}$ for pixel $p_{ij}$. The value represents the distance from the eye to the interaction point along the ray. The value types are:
1.  **Positive number ($d_{ij} > 0$):** The ray hit the isosurface in the previous frame. The value is the distance to that hit.
2.  **Negative flag ($d_{hitBoxMissSurf}$):** The ray missed the isosurface but hit the volume bounding box in the previous frame.
3.  **Negative flag ($d_{missBox}$):** The ray missed the volume bounding box completely in the previous frame.
4.  **No information ($d_{noInfo}$):** No data available (e.g., first frame).

### Parameters
*   **$\kappa_{max}, \kappa_{min}$:** Experimentally determined constants for adaptive step size. Typical values are $\kappa_{max} = 0.3$ and $\kappa_{min} = 0.1$ [S1, unofficial].
*   **$\alpha$:** Frequency of full traversal to correct errors. Typical value is $\alpha = 10$ (perform full traversal every 10 frames) [S1, unofficial].
*   **$dt$:** Step size for sparse traversal, calculated based on local data variance [S1, unofficial].

### Algorithm Steps

1.  **Ray Casting:** Cast one ray for each pixel in the final rendered image.
2.  **Prediction Retrieval:** Retrieve the prediction buffer value $d_{ij}$ for the current pixel from the previous frame.
3.  **Traversal Mode Selection:**
    *   If $d_{ij} = d_{missBox}$ or $d_{ij} = d_{noInfo}$, perform **Full Traversal** (standard DDA or dense sampling).
    *   If $d_{ij} = d_{hitBoxMissSurf}$, perform **Local Traversal** (refine search near bounding box entry).
    *   If $d_{ij} > 0$, perform **Sparse Traversal** (skip to predicted depth).
    *   *Note:* Every $\alpha$ frames, force Full Traversal for all pixels to prevent error accumulation [S1, unofficial].
4.  **Adaptive Step Size Calculation:** Calculate $dt$ using the variance $v$ of the data in the current brick/region, and global min/max variances $v_{min}, v_{max}$:
    $$ dt = \kappa_{min} + (\kappa_{max} - \kappa_{min}) \frac{v - v_{min}}{v_{max} - v_{min}} $$
    [S1, unofficial]
5.  **Traversal Execution:**
    *   **Sparse Traversal:** Start at $t_{start} = t_{min} + d_{ij}$. Use the algorithm below to find the intersection.
    *   **Local Traversal:** Start at $t_{start} = d_{ij}$. Search in both forward and backward directions from $t_{start}$ until the isosurface is found or volume bounds are exceeded.
6.  **Prediction Buffer Update:** Store the result of the current frame's ray cast into the prediction buffer for the next frame.

def prediction_buffer_traversal(ray_o, ray_d, t_min, t_max, rho_iso, prediction_buffer, frame_count, alpha):
    """
    Main entry point for prediction buffer voxel traversal.
    """
    pixel_id = get_pixel_id_from_ray(ray_o, ray_d)
    
    # Force full traversal periodically to correct drift
    if frame_count % alpha == 0:
        return full_traversal(ray_o, ray_d, t_min, t_max, rho_iso)

    # Retrieve prediction
    d_prev = prediction_buffer[pixel_id]

    # Determine traversal mode
    if d_prev == d_missBox or d_prev == d_noInfo:
        return full_traversal(ray_o, ray_d, t_min, t_max, rho_iso)
    elif d_prev == d_hitBoxMissSurf:
        return local_traversal(ray_o, ray_d, t_min, t_max, rho_iso, d_prev)
    else:
        # d_prev > 0 (hit isosurface)
        return sparse_traversal(ray_o, ray_d, t_min, t_max, rho_iso, d_prev)

def local_traversal(ray_o, ray_d, t_min, t_max, rho_iso, d_prev):
    """
    Local traversal starting from predicted depth, searching both forward and backward.
    """
    dt = calculate_adaptive_dt(ray_o, ray_d, t_min, t_max)
    
    t_start = d_prev
    
    # Forward search
    t_curr_fwd = t_start + dt
    t_prev_fwd = t_start
    
    rho_prev_fwd = trilinear_sample(ray_o, ray_d, t_prev_fwd)
    rho_curr_fwd = trilinear_sample(ray_o, ray_d, t_curr_fwd)
    
    while t_curr_fwd <= t_max:
        if rho_iso is between rho_prev_fwd and rho_curr_fwd:
            return bisection_find(t_prev_fwd, t_curr_fwd, rho_iso)
        t_prev_fwd = t_curr_fwd
        t_curr_fwd = t_prev_fwd + dt
        rho_prev_fwd = rho_curr_fwd
        rho_curr_fwd = trilinear_sample(ray_o, ray_d, t_curr_fwd)

    # Backward search (if forward failed)
    t_curr_bwd = t_start - dt
    t_prev_bwd = t_start
    
    rho_prev_bwd = trilinear_sample(ray_o, ray_d, t_prev_bwd)
    rho_curr_bwd = trilinear_sample(ray_o, ray_d, t_curr_bwd)
    
    while t_curr_bwd >= t_min:
        if rho_iso is between rho_prev_bwd and rho_curr_bwd:
            return bisection_find(t_curr_bwd, t_prev_bwd, rho_iso)
        t_prev_bwd = t_curr_bwd
        t_curr_bwd = t_prev_bwd - dt
        rho_prev_bwd = rho_curr_bwd
        rho_curr_bwd = trilinear_sample(ray_o, ray_d, t_curr_bwd)
        
    return -1.0

### Edge Cases and Pitfalls
*   **Skipping Isosurface:** Sparse traversal may skip an isosurface if $dt$ is too large, introducing artifacts. This is minimized by choosing $dt$ based on data variance [S1, unofficial].
*   **Local Traversal Failure:** Local traversal may fail to find the isosurface if the surface moves significantly between frames or if the local search exits volume bounds before finding the surface, producing incorrect results compared to Full Traversal [S1, unofficial].
*   **Error Accumulation:** To remedy the risk of missing surfaces due to coherence errors, the method performs a full traversal every $\alpha$ frames [S1, unofficial].

## Operating characteristics

*   **Time Complexity:** Significantly faster than full traversal during camera rotation due to skipped voxels. Sparse traversal contains no branching, yielding higher performance on CUDA architectures compared to regular traversal which has divergent branching penalties [S1, unofficial].
*   **Memory Complexity:** Requires one additional floating-point value per pixel for the prediction buffer.
*   **Performance:** The method can double the rendering speed compared to standard techniques [S1, unofficial]. Performance is influenced by block size, shared memory usage, and texture vs. global memory access patterns [S1, unofficial].
*   **Strengths:** High parallelism on GPUs; no divergent branching in sparse traversal; effective for interactive rotation.
*   **Limitations:** Not suitable for large camera movements (coherence breaks); potential for visual artifacts if $dt$ is poorly chosen or if the surface moves rapidly; requires periodic full traversal to correct errors.
*   **When to use:** Interactive volume rendering with small camera rotations on GPU architectures.
*   **When not to use:** Large viewpoint changes, static scenes with no coherence, or when strict visual accuracy is required without periodic correction.

## Background

*   **Origin:** The technique was proposed by Braley et al. in "GPU Accelerated Voxel Traversal using the Prediction Buffer" [S1, unofficial].
*   **History:** It builds upon earlier work on C-buffers and image caches [Yoon et al. 1997], which were not suited for GPU architectures due to lack of data parallelism. It also relates to temporal coherence techniques by Klein et al. [2005] [S1, unofficial].
*   **Usage:** Implemented using NVIDIA's CUDA toolkit (version 2.2 in the source) for massively parallel isosurface volume rendering [S1, unofficial].
