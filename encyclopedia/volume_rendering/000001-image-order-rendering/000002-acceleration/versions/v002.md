# Acceleration

Also called: Volume rendering acceleration, Ray tracing acceleration, Spatial acceleration

## Overview
Acceleration methods in image-order volume rendering reduce the computational cost of ray marching by minimizing the number of density/color evaluations and memory accesses required to produce a pixel's color. While the parent [Image-order rendering](16-image-order-rendering.md) defines the fundamental loop of intersecting rays with the volume domain and sampling along their path, acceleration techniques optimize this loop by skipping empty space, culling invisible regions, adapting sample density, or reusing temporal information. What sets this family apart from its siblings—such as [Ray-grid traversal](17-ray-grid-traversal.md) which optimizes data access patterns, or [Direct volume ray casting](19-direct-volume-ray-casting.md) which defines the basic sampling/compositing loop—is the specific mechanism used to bypass computation: whether through spatial data structures, heuristic parameter adjustments, or temporal coherence.

## Shared principles
All acceleration methods in this family share the goal of reducing the number of expensive operations (MLP evaluations, texture fetches, or arithmetic) per ray without significantly degrading visual fidelity. They operate within the standard image-order loop defined in [Image-order rendering](16-image-order-rendering.md). Common mechanisms include:
1.  **Empty Space Skipping:** Using acceleration structures (grids, trees, bitfields) to determine if a ray segment intersects non-zero density, allowing the renderer to jump over empty regions [S4, S5][S6, unofficial].
2.  **Early Termination:** Halting ray traversal when accumulated transmittance drops below a threshold (e.g., $10^{-3}$) or opacity saturates, as further samples contribute negligibly to the final color [S1, S6, unofficial].
3.  **Adaptive Sampling:** Dynamically adjusting the step size $\Delta t$ or the number of samples based on local density or error metrics, allocating more resources to complex regions and fewer to simple ones [S1, unofficial][S5].
4.  **Temporal Coherence:** Reusing results from previous frames or using motion vectors to interpolate/reproject data, reducing the need for full recomputation in stable scenes [S1, unofficial].

## Subtopics

### [GL-NeRF](803-gl-nerf.md)
A training-free method for Neural Radiance Fields that replaces stochastic sampling with deterministic point selection based on Gauss-Laguerre quadrature. It modifies only the integration logic, requiring no additional representation or training, and reduces MLP calls by selecting points where accumulated optical depth equals Laguerre polynomial roots.

### [Adaptive Sampling and Resolution](1412-adaptive-sampling-and-resolution.md)
Dynamically adjusts computational effort (sample count or resolution) based on local scene complexity or global performance budgets. It allocates more resources near boundaries or high-variance regions while skipping empty space or using lower fidelity elsewhere.

### [Kernel Selection](1647-kernel-selection.md)
A pre-processing strategy for Gaussian ellipsoids that uses coarse rasterization and density thresholds to select a fixed number of nearest neighbors for ray tracing, discarding distant or low-density primitives before the heavy blending stage.

### [Inference Ray Marching and Integration](2148-inference-ray-marching-and-integration.md)
A GPU-accelerated pipeline for real-time inference from NeRFs or sparse grids. It uses density bitfields or occupancy grids for acceleration and early termination, disabling gradient flow and using fixed step sizes to prioritize latency over optimization stability.

### [Ray-guided volume rendering with missing brick reporting](2815-ray-guided-volume-rendering-with-missing-brick-reporting.md)
An out-of-core technique that determines the working set dynamically during ray casting. It streams only bricks accessed by rays and reports "missing bricks" to a paging subsystem, ensuring optimal accuracy by never loading unused data.

### [Acceleration Structure Rebuild](3266-acceleration-structure-rebuild.md)
Maintains spatial coherence in animated scenes by discarding the previous frame's acceleration structure and constructing a new one from scratch every frame, relying on parallel reconstruction speed rather than incremental updates.

### [Visibility Feedback with Screen Space Subdivision](3439-visibility-feedback-with-screen-space-subdivision.md)
Uses visibility information gathered during rendering to optimize data management in the loader. It prevents loading or refining occluded areas by using screen-space subdivision to schedule occlusion queries for specific octree nodes.

### [Adaptive Undersampling](5397-adaptive-undersampling.md)
Replaces full volume integral calculation for a subset of pixels with interpolation, storing pre-computed integral values over fixed intervals to allow partial recomputation for pixels where interpolation is inaccurate.

### [Visibility Culling](6226-visibility-culling.md)
Identifies and skips processing of data regions or rays that do not contribute to the final image, focusing on geometric or scalar-based determination of visible vs. invisible primitives before expensive integration occurs.

### [Performance Optimization Techniques](6301-performance-optimization-techniques.md)
A collection of heuristic strategies (quarter-resolution raymarching, adaptive stepping, temporal reprojection, bilateral upsampling) that trade visual fidelity for frame rate stability by reducing shader evaluations and memory accesses.

### [Temporal Coherence and Caching](6372-temporal-coherence-and-caching.md)
Exploits similarity between consecutive frames by reusing or skipping work that has not changed, operating across time rather than space and relying on scene stability rather than perceptual error metrics.

### [Context-Based Adaptive Ray Sampling with Quadtree Subdivision](8164-context-based-adaptive-ray-sampling-with-quadtree-subdivisio.md)
A training-stage strategy using a quadtree to partition image space, sampling more rays in high-error areas to reduce training burden while capturing details.

### [Efficient Space Skipping & Adaptive Sampling of Unstructured Volumes Using H.W. Accel. Ray Tracing](8217-efficient-space-skipping-adaptive-sampling-of-unstructured-v.md)
Leverages hardware-accelerated ray tracing to accelerate acceleration structure traversal and point-in-element tests for unstructured volumes, reducing samples via empty space skipping and adaptive sampling.

### Parsimonious Ray Sampling and Fused Rendering
- [S1, unofficial] A rendering optimization that infers ray-BBox intersection to sample query points only within the scene bounding box, applicable only to bounded scenes. It fuses approximately ten point-wise operations for the forward and backward pass of the density-to-alpha function conversion. In the volume rendering accumulation, it halts tracking a ray once the accumulated transmittance falls below $10^{-3}$.

### Image-Order Volumetric Compositing
- [S2, unofficial] A volume rendering framework proposed by Levoy, implemented on PIXEL-PLANES 5 hardware, using image-order volumetric compositing. It uses empty space skipping and occlusion culling to accelerate rendering speed, achieving real-time or near real-time performance.

### Raw Volume Rendering
- [S3] A rendering algorithm that does not use any precomputed data structures. It is significantly slower than the other two algorithms and is useful only for single renderings from a volume. The steps are: load the volume data, choose the classification function, set the view and shading parameters, and render with `vpRenderRawVolume()`. It differs from the Min-Max Octree algorithm only in that there is no need to compute the min-max octree.

### Hierarchical Bounding Box Tree for Empty-Space Skipping
- [S4] A method for visualizing large-scale aerosols (smoke, fog, dust) by optimizing traditional ray casting to avoid sampling empty spaces and invalid voxels, reducing hardware load and improving speed. It optimizes the traditional ray casting algorithm through the hierarchical bounding box tree and combines an illumination model to enhance the color rendering of each voxel. It reduces unnecessary space debris to lower hardware load and improve rendering speed, meeting real-time rendering requirements for large-scale aerosols.

### Surface Localization Acceleration
- [S5] Acceleration methods that localize the surface interface and concentrate samples only in relevant regions, effectively skipping empty space, because only 10-20% of evaluated samples have non-zero density. It refines the sampling strategy to focus solely on the localized surface. Standard volumetric rendering is inefficient because it samples the entire ray; surface localization reduces the number of required MLP evaluations by skipping empty space.

### Early Z-Test Acceleration
- [S6, unofficial] A mechanism applied before the shader program is executed for a particular fragment to avoid execution, enabling the fragment processor to process the next incoming fragment. It is used to integrate early ray termination and empty-space skipping. The early z-test is only enabled if all other per-fragment tests are disabled and the fragment's depth value is not modified in the shader. Performance gain up to a factor of 3 for typical renditions of volumetric data sets on the ATI 9700 graphics card.

## Background
Acceleration techniques in volume rendering have evolved from early hardware-specific optimizations to sophisticated neural field inference pipelines. Early work by Levoy [S2, unofficial] demonstrated real-time performance on PIXEL-PLANES 5 using image-order compositing with empty space skipping. VolPack [S3] introduced software-based acceleration using min-max octrees for unclassified volumes. With the advent of GPUs, techniques like Early Z-Test [S6, unofficial] leveraged fixed-function hardware to skip fragment processing. More recently, the rise of Neural Radiance Fields (NeRF) has driven new acceleration methods like GL-NeRF [S1, unofficial] and Inference Ray Marching [S1, unofficial], which address the high cost of MLP evaluations through deterministic sampling and bitfield acceleration. Surface localization [S5] has also emerged as a key area, focusing on the fact that only a small fraction of samples contribute to the final image.
