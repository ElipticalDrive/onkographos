# Prediction Buffer Voxel Traversal

Also called: Local Traversal, Modified Depth Buffer Traversal, Prediction Buffer, Sparse Traversal

## Overview
Prediction Buffer Voxel Traversal is a GPU-accelerated dataset traversal technique that exploits frame-to-frame coherence during camera rotation to accelerate isosurface volume rendering [S1, unofficial]. It uses a modified depth buffer, called the prediction buffer, to store the distance to the isosurface intersection from the previous frame, allowing the renderer to skip large portions of the volume or refine a local search rather than performing a full traversal from the volume entry point [S1, unofficial]. Unlike C-buffer or image cache techniques that store coordinates or iso-maps and suffer from aliasing or lack data parallelism on GPUs, the prediction buffer stores depth distances and is designed for high-performance GPU parallelism [S1, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   Ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ for each pixel $p_{ij}$ in the final image.
*   Volume data grid and its bounding box.
*   Isosurface value $\rho_{iso}$.
*   Prediction buffer from the previous frame.
*   Step size parameter $dt$ (adaptive based on data variance).

**Outputs:**
*   Rendered pixel color.
*   Updated prediction buffer for the current frame.

### Data Structures
**Prediction Buffer:**
A 2D buffer aligned with the image resolution. For each pixel $p_{ij}$, it stores a single floating-point value $d_{ij}$ representing the distance from the eye to the interaction point along the ray. The value types are:
1.  **Positive number $d_{ij}$:** The ray hit the isosurface at distance $d_{ij}$ [S1, unofficial].
2.  **Negative flag $d_{hitBoxMissSurf}$:** The ray hit the volume bounding box but missed the isosurface [S1, unofficial].
3.  **Negative flag $d_{missBox}$:** The ray missed the volume bounding box completely [S1, unofficial].
4.  **$d_{noInfo}$:** No information available (e.g., first frame) [S1, unofficial].

### Parameters
*   **$dt$:** The step size for sparse traversal. It is not constant but determined by the local data variance to minimize artifacts.
*   **$\kappa_{min}, \kappa_{max}$:** Experimental constants used to scale the step size based on variance. Typical values are $\kappa_{min} = 0.1$ and $\kappa_{max} = 0.3$ [S1, unofficial].
*   **$\alpha$:** The frequency of full traversal to correct accumulated errors. Typically $\alpha = 10$ frames [S1, unofficial].

### Algorithm Steps

1.  **Initialization:** For each pixel $p_{ij}$, cast a ray. Retrieve the prediction buffer value $t_{predict}$ from the previous frame.
2.  **Traversal Mode Selection:**
    *   If $t_{predict} = d_{noInfo}$ or $t_{predict} = d_{missBox}$, perform **Full Traversal** (standard DDA or dense sampling) [S1, unofficial].
    *   If $t_{predict} = d_{hitBoxMissSurf}$, perform **Local Traversal** starting near the bounding box entry [S1, unofficial].
    *   If $t_{predict}$ is a positive distance, perform **Sparse Traversal** or **Local Traversal** centered around $t_{predict}$ [S1, unofficial].
    *   Every $\alpha$ frames, force **Full Traversal** for all pixels to reset coherence errors [S1, unofficial].
3.  **Step Size Calculation:** Calculate $dt$ based on the variance $v$ of the data in the current region:
    $$ f(v, v_{max}, v_{min}) = \kappa_{min} + \frac{\kappa_{max} - \kappa_{min}}{v_{max} - v_{min}} (v - v_{min}) $$
    $$ dt = f(v, v_{max}, v_{min}) $$
    Where $v_{max}$ and $v_{min}$ are the maximum and minimum variances over all bricks [S1, unofficial].
4.  **Traversal Execution:**
    *   **Sparse Traversal:** Starts at $t_{min}$ and advances in steps of $dt$.
    *   **Local Traversal:** Starts at $t_{predict}$ and advances in both forward and backward directions with step $dt$ until the isosurface is found or volume bounds are exceeded [S1, unofficial].
5.  **Prediction Buffer Update:** After traversal, update the prediction buffer for pixel $p_{ij}$ with the new intersection distance or appropriate flag.

### Pseudocode

```python
def prediction_buffer_traversal(ray_o, ray_d, volume, isosurface_value, prediction_buffer, frame_count):
    """
    Main entry point for prediction buffer voxel traversal.
    """
    pixel_id = get_pixel_id_from_ray(ray_o, ray_d)
    
    # Check if full traversal is forced
    if frame_count % 10 == 0:
        t_hit = full_traversal(ray_o, ray_d, volume, isosurface_value)
        update_prediction_buffer(pixel_id, t_hit)
        return t_hit

    # Get prediction from previous frame
    t_predict = prediction_buffer_get(pixel_id)
    
    # Determine traversal type based on prediction
    if t_predict == NO_INFO or t_predict == MISS_BOX:
        t_hit = full_traversal(ray_o, ray_d, volume, isosurface_value)
    elif t_predict == HIT_BOX_MISS_SURF:
        t_hit = local_traversal(ray_o, ray_d, volume, isosurface_value, t_predict)
    else:
        # Positive distance indicates a hit; use sparse or local refinement
        # Using local traversal for robustness around predicted hit
        t_hit = local_traversal(ray_o, ray_d, volume, isosurface_value, t_predict)
        
    update_prediction_buffer(pixel_id, t_hit)
    return t_hit

def local_traversal(ray_o, ray_d, volume, isosurface_value, t_predict):
    """
    Variant of sparse traversal that searches forward and backward from t_predict.
    """
    # Calculate adaptive dt based on local variance
    v = get_variance_at(ray_o, ray_d, t_predict)
    dt = calculate_dt(v)
    
    t_min = ray_entry_time(ray_o, ray_d, volume.bounding_box)
    t_max = ray_exit_time(ray_o, ray_d, volume.bounding_box)
    
    # Clamp prediction to valid range
    t_start = clamp(t_predict, t_min, t_max)
    
    # Search forward
    t_curr = t_start
    t_prev = t_start - dt
    
    # Ensure we don't go below t_min
    if t_prev < t_min:
        t_prev = t_min
        t_curr = t_prev + dt
        
    rho_prev = trilinear_sample(volume, ray_o + t_prev * ray_d)
    rho_curr = trilinear_sample(volume, ray_o + t_curr * ray_d)
    
    while t_curr <= t_max:
        if isosurface_value in [rho_prev, rho_curr]:
            return bisection_find(t_prev, t_curr, isosurface_value)
        t_prev = t_curr
        t_curr = t_curr + dt
        rho_prev = rho_curr
        rho_curr = trilinear_sample(volume, ray_o + t_curr * ray_d)
        
    # Search backward from start if forward didn't find it
    t_curr = t_start
    t_prev = t_start + dt
    
    if t_prev > t_max:
        return -1.0 # Missed volume entirely or prediction was bad
        
    rho_prev = trilinear_sample(volume, ray_o + t_curr * ray_d)
    rho_curr = trilinear_sample(volume, ray_o + t_prev * ray_d)
    
    while t_prev >= t_min:
        if isosurface_value in [rho_prev, rho_curr]:
            return bisection_find(t_curr, t_prev, isosurface_value)
        t_curr = t_prev
        t_prev = t_prev - dt
        rho_prev = rho_curr
        rho_curr = trilinear_sample(volume, ray_o + t_prev * ray_d)
        
    return -1.0

def sparse_traversal(ray_o, ray_d, volume, isosurface_value):
    """
    Standard sparse traversal starting from t_min.
    """
    t_min = ray_entry_time(ray_o, ray_d, volume.bounding_box)
    t_max = ray_exit_time(ray_o, ray_d, volume.bounding_box)
    
    # Use a fixed or variance-based dt. Here we assume a global or local dt is passed/derived.
    # For simplicity, assuming dt is derived from global variance or passed.
    dt = calculate_dt(get_global_variance()) 
    
    t_curr = t_min + dt
    t_prev = t_min
    
    rho_prev = trilinear_sample(volume, ray_o + t_prev * ray_d)
    rho_curr = trilinear_sample(volume, ray_o + t_curr * ray_d)
    
    while t_curr <= t_max:
        if isosurface_value in [rho_prev, rho_curr]:
            return bisection_find(t_prev, t_curr, isosurface_value)
        t_prev = t_curr
        t_curr = t_curr + dt
        rho_prev = rho_curr
        rho_curr = trilinear_sample(volume, ray_o + t_curr * ray_d)
        
    return -1.0

def full_traversal(ray_o, ray_d, volume, isosurface_value):
    """
    Standard dense DDA or sampling traversal.
    """
    # Implementation depends on specific DDA variant, but guarantees no misses.
    # For this article, we assume a standard step size of 1 voxel or smaller.
    t_min = ray_entry_time(ray_o, ray_d, volume.bounding_box)
    t_max = ray_exit_time(ray_o, ray_d, volume.bounding_box)
    
    # Step size for full traversal is typically small enough to guarantee intersection detection
    dt = get_voxel_size_along_ray(ray_d) 
    
    t_curr = t_min
    while t_curr <= t_max:
        rho = trilinear_sample(volume, ray_o + t_curr * ray_d)
        if rho == isosurface_value: # Or within epsilon
            return t_curr
        t_curr += dt
        
    return -1.0

def calculate_dt(variance):
    """
    Calculate step size based on data variance.
    """
    # Constants from source
    kappa_min = 0.1
    kappa_max = 0.3
    v_max = get_max_variance()
    v_min = get_min_variance()
    
    if v_max == v_min:
        return kappa_min
    
    f = kappa_min + ((kappa_max - kappa_min) / (v_max - v_min)) * (variance - v_min)
    return f

def bisection_find(t_a, t_b, target_rho):
    """
    Find precise intersection between t_a and t_b.
    """
    # Standard bisection method
    for _ in range(10): # Fixed iterations for precision
        t_mid = (t_a + t_b) / 2.0
        rho_mid = trilinear_sample(volume, ray_o + t_mid * ray_d)
        if rho_mid < target_rho:
            t_a = t_mid
        else:
            t_b = t_mid
    return (t_a + t_b) / 2.0
```

### Edge Cases and Pitfalls
*   **Skipping Isosurface:** Sparse traversal may skip an isosurface if $dt$ is too large, introducing artifacts. This is minimized by choosing $dt$ based on data variance [S1, unofficial].
*   **Local Traversal Failure:** Local traversal may fail to find the isosurface if the surface moves significantly between frames or if the local search exits volume bounds before finding the surface, producing incorrect results compared to Full Traversal [S1, unofficial].
*   **Coherence Errors:** Over many frames without reset, errors accumulate. The method performs full traversal every $\alpha$ frames (typically 10) to remedy this [S1, unofficial].

## Operating characteristics

**Time Complexity:**
*   **Sparse Traversal:** $O(N/dt)$ where $N$ is the number of voxels along the ray. Since $dt$ is adaptive and often larger than 1 voxel, this is significantly faster than full traversal $O(N)$.
*   **Local Traversal:** $O(k)$ where $k$ is the number of steps in the local neighborhood. Typically $k \ll N$.
*   **Full Traversal:** $O(N)$.

**Memory Complexity:**
*   Requires a 2D prediction buffer of size equal to the image resolution (one float per pixel) [S1, unofficial].

**Performance:**
*   On NVIDIA CUDA architectures, sparse traversal yields higher performance than regular traversal because it contains no branching, avoiding divergent branching penalties within warps [S1, unofficial].
*   The technique can double the rendering speed compared to standard traversal [S1, unofficial].

**Strengths:**
*   High performance on GPUs due to lack of branching in sparse traversal.
*   Exploits frame-to-frame coherence effectively during rotation.
*   Hardware-accelerated trilinear interpolation makes the sampling cost negligible [S1, unofficial].

**Limitations:**
*   Potential for visual artifacts if $dt$ is too large or if the camera moves too quickly between frames.
*   Not suitable for static scenes or scenes with no frame-to-frame coherence.
*   Requires careful tuning of $\kappa$ parameters and $\alpha$ reset frequency.

## Background

**Origin:**
The method was proposed by Braley et al. in the paper "GPU Accelerated Voxel Traversal using the Prediction Buffer" [S1, unofficial]. It was developed to address the computational bottleneck of dataset traversal in interactive volume rendering of large datasets.

**History:**
Prior techniques included the C-buffer, which stored coordinates of the nearest opaque voxel, and the image cache, which used an iso-map as a modified depth buffer. The image cache approach, while novel, was not suited for GPU architectures due to a lack of data parallelism [S1, unofficial]. The prediction buffer technique was introduced as a GPU-friendly alternative that stores depth distances directly, enabling massive parallelism.

**Usage:**
The method is used in GPU-based volume rendering applications, particularly those involving interactive rotation of large volumetric datasets, such as medical imaging or scientific visualization. It was implemented using NVIDIA’s CUDA toolkit [S1, unofficial].
