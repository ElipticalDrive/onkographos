# Spatial Skipping (Occupancy Grid)

Also called: Instant-NGP Sampling, Occupancy Grid, Occupancy Grid Pruning

## Overview
Spatial Skipping (Occupancy Grid) is an acceleration technique that improves uniform sampling by identifying empty regions in the volume and skipping them, effectively creating a transmittance estimator based on the ratio of occupied steps [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A radiance field (implicit or explicit), a ray defined by origin $o$ and direction $d$, and a set of uniformly sampled points $t_i$ along the ray interval $[t_n, t_f]$ [S1].
*   **Output:** A set of valid samples with associated importance weights (PDF) and transmittance values, allowing the renderer to skip samples in empty space [S1].

**Data Structures:**
*   **Occupancy Grid:** An explicit voxel grid storing cached density values $\sigma(t_i)$ for each spatial location, updated using an Exponential Moving Average (EMA) over optimization iterations [S1].
*   **Packed Tensors:** To handle varying numbers of valid samples per ray, samples are stored in a packed tensor of shape `(all_samples, ...)` rather than a padded `(n_rays, n_samples, ...)` tensor, with an associated `ray_id` array mapping each sample to its originating ray [S1].

**Parameters:**
*   **Threshold ($\tau$):** A conservative density threshold used to binarize density, where $\sigma(t_i) > \tau$ marks a sample as occupied [S1].
*   **EMA Decay ($\gamma$):** The decay factor for the Exponential Moving Average update of cached densities [S1].

**Steps:**
1.  **Uniform Sampling:** Generate $n$ uniformly spaced sample points $t_i$ along the ray [S1].
2.  **Density Evaluation:** Evaluate the density $\sigma(t_i)$ at each sample point using the radiance field [S1].
3.  **Binarization:** Compute the binarized density $\hat{\sigma}(t_i)$:
    $$
    \hat{\sigma}(t_i) = \begin{cases} 
    1 & \text{if } \sigma(t_i) > \tau \\
    0 & \text{otherwise}
    \end{cases}
    $$
    [S1]
4.  **PDF Estimation:** Calculate the piece-wise constant probability density function (PDF) for each sample:
    $$
    p(t_i) = \frac{\hat{\sigma}(t_i)}{\sum_{j=1}^{n} \hat{\sigma}(t_j)}
    $$
    [S1]
5.  **Transmittance Estimation:** Calculate the piece-wise linear transmittance estimator $T(t_i)$:
    $$
    T(t_i) = 1 - \frac{\sum_{j=1}^{i-1} \hat{\sigma}(t_j)}{\sum_{j=1}^{n} \hat{\sigma}(t_j)}
    $$
    [S1]
6.  **EMA Update (Optimization Phase):** During training, update the cached density in the occupancy grid using Exponential Moving Average over iteration $k$:
    $$
    \sigma_{\text{cached}}(t_i) = \gamma \cdot \sigma_{\text{cached}}(t_i) + (1 - \gamma) \cdot \sigma_{\text{new}}(t_i)
    $$
    Note: The source notation uses $\sigma(t_i)^k = \gamma \cdot \sigma(t_i)^{k-1} + (1 - \gamma) \cdot \sigma(t_i)^k$, where the RHS term denotes the newly evaluated density at iteration $k$ [S1].
7.  **Sample Filtering (Optional Variant):** For samples identified as potentially in empty or occluded spaces, evaluate transmittance without computing gradients and discard those with transmittance below $10^{-4}$ [S1].

**Pseudocode:**
```python
import math
from itertools import accumulate

def spatial_skipping_occupancy_grid(ray_origin, ray_direction, num_samples,
                                    radiance_field, occupancy_grid, threshold, gamma):
    """
    Performs spatial skipping using an occupancy grid.
    
    Args:
        ray_origin: (3,) list, ray origin coordinates.
        ray_direction: (3,) list, ray direction vector.
        num_samples: int, number of uniform samples.
        radiance_field: callable, returns density sigma at 3D points.
        occupancy_grid: dict mapping (x,y,z) tuples to cached density floats.
        threshold: float, density threshold for binarization.
        gamma: float, EMA decay factor.
        
    Returns:
        sample_points: list of (x,y,z) tuples.
        pdfs: list of floats, importance weights.
        transmittances: list of floats, transmittance values.
        ray_ids: list of ints, ray index for each sample.
    """
    # 1. Uniform Sampling
    t_vals = [i / (num_samples - 1) for i in range(num_samples)]
    sample_points = [(ray_origin[0] + t * ray_direction[0],
                      ray_origin[1] + t * ray_direction[1],
                      ray_origin[2] + t * ray_direction[2]) for t in t_vals]
    
    # 2. Density Evaluation
    densities = [radiance_field(p) for p in sample_points]
    
    # 3. Binarization
    occupied = [1.0 if d > threshold else 0.0 for d in densities]
    
    # 4. PDF Estimation
    total_occupied = sum(occupied)
    if total_occupied == 0:
        return [], [], [], []
    pdfs = [o / total_occupied for o in occupied]
    
    # 5. Transmittance Estimation
    cumsum_occupied = list(accumulate(occupied))
    transmittances = [1.0 - (c / total_occupied) for c in cumsum_occupied]
    
    # 6. EMA Update (Optimization Phase)
    # In practice, coordinates must be quantized to voxel grid indices [G]
    for i in range(num_samples):
        pos = sample_points[i]
        prev_sigma = occupancy_grid.get(pos, 0.0)
        new_sigma = gamma * prev_sigma + (1 - gamma) * densities[i]
        occupancy_grid[pos] = new_sigma
        
    # 7. Return packed data
    ray_ids = [0] * num_samples
    return sample_points, pdfs, transmittances, ray_ids
```

**Edge Cases and Pitfalls:**
*   **Aliasing:** The voxel-based representation of the transmittance estimator can suffer from aliasing issues [S1].
*   **Occluded Areas:** The method still samples uniformly within occupied but occluded areas that contribute little to the final rendering [S1].
*   **Inaccurate Estimation:** Inaccurate transmittance estimations from importance sampling can result in samples lying in empty or occluded spaces, which may require additional filtering [S1].

## Subtopics

### No Gradient Filtering
A technique to filter out samples lying in empty or occluded spaces by evaluating their transmittance without computing gradients, detaching the sampling process from the differentiable computational graph to maximize speed [S1]. It is chosen when training speed is prioritized over gradient accuracy in empty regions [S1]. It is approximately 10x faster than keeping all samples in the computation graph because backward passes are not required for these samples [S1]. The process involves: 1. Performing importance sampling (e.g., using Occupancy Grid) [S1]. 2. Identifying samples potentially in empty or occluded spaces [S1]. 3. Evaluating transmittance for these samples using the radiance field with gradients disabled [S1]. 4. Disregarding samples with transmittance below $10^{-4}$ [S1]. 5. Including remaining samples in the differentiable computation graph [S1]. The transmittance threshold is $10^{-4}$ [S1]. This method is inspired by Instant-NGP's implementation [S1].

## Operating characteristics
*   **Time Complexity:** Faster than uniform sampling in empty scenes, but slower than PDF-based estimators in complex scenes due to uniform sampling within occupied regions [S1]. The "No Gradient Filtering" variant is approximately 10x faster than standard differentiable sampling for filtered samples [S1].
*   **Memory Complexity:** Uses an explicit voxel grid for the occupancy estimator, which generally consumes more memory than implicit estimators but enables faster lookups [S1]. Packed tensors are used to store samples efficiently, avoiding the memory overhead of padded tensors for rays with few valid samples [S1].
*   **Strengths:** Simple to implement, efficient in empty spaces, and compatible with various radiance field representations such as HashEncoding in Nerfacto [S1].
*   **Limitations:** Suffers from aliasing, samples uniformly in occluded areas, and may require careful threshold tuning [S1].
*   **When to Use:** When rendering scenes with large empty spaces and computational efficiency is critical, or in in-the-wild settings when combined with hybrid representations [S1].
*   **When Not to Use:** When high accuracy in occluded regions is required or when the scene is densely occupied, reducing the benefit of skipping [S1].

## Background
Spatial Skipping via Occupancy Grid was introduced in Instant-NGP as a method to accelerate neural volume rendering by skipping empty regions during sampling [S1]. It is part of a broader class of importance sampling techniques that view sampling through the lens of transmittance estimation [S1]. The technique has been adopted and extended in various NeRF-related methods, including NerfAcc and Nerfstudio, often in conjunction with other efficient representations like HashEncoding [S1].
