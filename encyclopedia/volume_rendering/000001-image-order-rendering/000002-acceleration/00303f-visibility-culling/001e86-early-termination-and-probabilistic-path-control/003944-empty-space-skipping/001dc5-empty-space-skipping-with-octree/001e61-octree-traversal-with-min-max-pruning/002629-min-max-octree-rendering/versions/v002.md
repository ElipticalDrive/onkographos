# Min-Max Octree Rendering

Also called: Unclassified Volume Rendering, Unclassified Volume Rendering with Min-Max Octree, vpRenderRawVolume algorithm

## Overview
Min-Max Octree Rendering is an acceleration technique for ray-casting unclassified scalar volumes, designed for scenarios where classification parameters change frequently [S1]. It differs from pre-classified rendering by storing raw voxel data and using a hierarchical min-max structure to prune empty space and skip nodes that do not contain the target isovalue range, avoiding the costly recomputation of classification tables [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Unclassified volume data (scalar field), classification function (transfer function), view and shading parameters [S1].
*   **Output:** Rendered image [S1].
*   **Auxiliary Input:** Precomputed Min-Max Octree [S1].

**Data Structures:**
The core structure is the Min-Max Octree, a hierarchical data structure containing minimum and maximum values for each field used to index the classification tables [S1]. The smallest nodes in the octree have a side length equal to `base_node_size` in voxels [S1].

**Parameters:**
*   `base_node_size`: The side length in voxels of the smallest node in the octree [S1]. Smaller values provide better pruning resolution at the expense of increased memory usage [S1]. Typical value: 4 [S1].
*   `range`: A range of table indices for a parameter considered 'small' [S1]. The opacity of a voxel should not vary much if the table index is changed by the amount specified in range [S1]. Choosing a value too small or too large may reduce performance benefit [S1].

**Steps:**
1.  **Define Volume:** Initialize the unclassified volume using `vpSetVolumeSize()`, `vpSetVoxelSize()`, `vpSetVoxelField()`, and `vpSetRawVoxels()` [S1]. Initialize the volume data array [S1].
2.  **Configure Thresholds:** For each classification table parameter, call `vpMinMaxOctreeThreshold(param_num, range)` to define the "small" range for that parameter [S1].
3.  **Build Octree:** Call `vpCreateMinMaxOctree(root_node_size, base_node_size)` to compute the min-max octree from the raw volume data and store it in the rendering context [S1].
4.  **Render Loop:**
    a. Choose the classification function (transfer function) [S1].
    b. Set view and shading parameters [S1].
    c. Render the volume using `vpRenderRawVolume()` [S1]. The octree is used automatically during this call [S1].

**Pseudocode:**
```python
class Context:
    def __init__(self):
        self.volume_size = None
        self.voxel_size = None
        self.voxel_field = None
        self.raw_voxels = None
        self.min_max_octree = None
        self.classification_tables = {}
        self.view_matrix = None
        self.shading_model = None

def initialize_volume(ctx, size, voxel_size, field, raw_data):
    ctx.volume_size = size
    ctx.voxel_size = voxel_size
    ctx.voxel_field = field
    ctx.raw_voxels = raw_data

def configure_thresholds(ctx, param_num, range_val):
    ctx.classification_tables[param_num] = range_val

def build_octree(ctx, base_node_size):
    # Reads raw_voxels, computes min/max bounds per octree node, stores in ctx.min_max_octree
    ctx.min_max_octree = compute_min_max_octree(ctx.raw_voxels, base_node_size)

def render(ctx):
    # Uses ctx.min_max_octree automatically to prune empty space and skip nodes
    # during ray traversal based on classification tables and view/shading parameters
    image = ray_cast_with_pruning(ctx.raw_voxels, ctx.min_max_octree,
                                  ctx.classification_tables,
                                  ctx.view_matrix, ctx.shading_model)
    return image

# Initialization
ctx = Context()
initialize_volume(ctx, size=(W, H, D), voxel_size=(dx, dy, dz),
                  field="scalar", raw_data=voxel_array)

# Configure pruning thresholds for each parameter in the transfer function
for param_num, range_val in transfer_function_params.items():
    configure_thresholds(ctx, param_num, range_val)

# Build the acceleration structure
build_octree(ctx, base_node_size=4)

# Rendering Loop
while rendering_needed:
    set_classification_function(ctx, transfer_function)
    set_view_and_shading_parameters(ctx, view_matrix, shading_model)
    render(ctx)

    # If volume data changes, the octree must be rebuilt
    if volume_data_changed:
        build_octree(ctx, base_node_size=4)
```

**Edge Cases and Pitfalls:**
*   If the volume data is modified, `vpCreateMinMaxOctree()` must be called again; otherwise, renderings will be incorrect [S1].
*   The `root_node_size` parameter in `vpCreateMinMaxOctree` is currently not used but is reserved for future use [S1].
*   The `range` parameter requires experimentation; suboptimal values reduce performance benefits but do not break correctness [S1].

## Operating characteristics
*   **Memory Complexity:** Requires additional memory for the min-max octree [S1]. The size increases as `base_node_size` decreases [S1].
*   **Strengths:** Ideal for interactive applications where classification (transfer function) is adjusted frequently, as it avoids recomputing the classified volume [S1].
*   **Limitations:** Slower than pre-classified rendering for static classification scenarios [S1]. Requires precomputation step [S1].
*   **When to use:** When many renderings are made from the same volume with varying classification functions [S1].
*   **When not to use:** When only a single rendering is needed (use raw ray-casting) or when classification is static (use pre-classified rendering) [S1].

## Background
Min-Max Octree Rendering is part of the VolPack library [S1]. It is specifically designed to accelerate the rendering of unclassified volumes by leveraging hierarchical min-max bounds to skip irrelevant regions during ray casting [S1].
