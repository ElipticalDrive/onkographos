# Empty Space Skipping with Octree

Also called: BB-Coef Min/Max Skipping, Min-Max Octree Empty Space Skipping, Octree Ray Casting, Octree-based Empty Space Skipping

## Overview
Empty Space Skipping with Octree is an acceleration technique for isosurface rendering that uses an octree structure storing conservative minimum and maximum scalar value estimates to skip transparent or irrelevant regions [S1][S2]. It solves the problem of expensive spline evaluations in empty space by allowing rays to bypass nodes that do not contain the target isovalue [S2]. Unlike standard empty-space skipping which may rely on coarse bricks, this method uses hierarchical min/max ranges to prune nodes, allowing for interactive transfer function changes without rebuilding geometry [S1739]. It sets itself apart by embedding the acceleration structure and scalar data in a single octree, leveraging the duality between voxels and cells to define cell primitives for ray intersection [S1739].

## How it works
**Inputs:**
- Scalar volume data (typically represented as B-spline coefficients or wavelet coefficients).
- Target isovalue $I$.
- Ray origin $\mathbf{o}$ and direction $\mathbf{d}$.
- Leaf size parameter $b$ (trade-off between skipping efficiency and memory) [S1].

**Outputs:**
- Intersection points with the isosurface, or early termination if the ray passes through empty space.

**Data Structures:**
- **Octree Node:** Stores `min_val` and `max_val` representing the conservative bounds of the scalar field in the subtree.
- **Leaf Node:** Corresponds to a group of $b^3$ adjacent polynomials [S1].
- **Cube Representation:** For traversal, cubic cells are represented with vertices storing 2D texture coordinates containing the min/max values of the cell [S2].

**Pre-processing Steps:**
1.  **Leaf Min/Max Estimation:** For each leaf node, estimate the minimum and maximum scalar values using the convex combination property of the B-spline basis [S1].
    -   Alternatively, for each cubic cell, construct Bernstein-Bézier (BB) forms of its five tetrahedral polynomial pieces [S2].
    -   Set the min/max values of the cubic cell to the min/max values of those BB-coefficients [S2].
2.  **Propagation:** Propagate the min/max values from the leaves towards the root of the octree. Each internal node stores the conservative estimate (min of children mins, max of children maxes) of the minimum and maximum value appearing in its subtree [S1].

**Rendering Steps:**
1.  **Traversal:** Perform a GPU-enabled parametric octree traversal [S1].
2.  **Culling:** For each visited node, check if the target isovalue $I$ lies within $[node.min\_val, node.max\_val]$. If not, skip the node [S1][S2].
3.  **Entry/Exit Point Computation:**
    -   Render cubes corresponding to one level of the min/max octree instead of the whole volume [S2].
    -   Compute exit points: Render cubes with `glCullFace(GL FRONT)` and `glDepthFunc(GL LESS)` [S2].
    -   Compute entry points: Render cubes again with `glCullFace(GL BACK)` and `glDepthFunc(GL GREATER)` [S2].
4.  **Fragment Shader Logic:** In the fragment shader, discard the fragment if the cube is empty or does not contain the isosurface level [S2].

**Pseudocode:**

```python
def traverse_octree(ray_origin, ray_direction, isovalue, root_node):
    """
    Recursively traverse the octree to find isosurface intersections.
    """
    # Base case: Leaf node
    if root_node.is_leaf:
        # Evaluate spline/polynomials within the leaf
        # Return intersection points or None
        return evaluate_leaf_polynomials(ray_origin, ray_direction, isovalue, root_node)

    # Pruning check
    if isovalue < root_node.min_val or isovalue > root_node.max_val:
        return None  # Empty space skipping

    # Recursive step
    # Determine which children the ray intersects (bounding box test)
    children_to_visit = get_intersecting_children(root_node, ray_origin, ray_direction)

    closest_intersection = None

    for child in children_to_visit:
        # Intersect ray with child's bounding box to update ray segment
        t_min, t_max = intersect_ray_bbox(ray_origin, ray_direction, child.bbox)
        
        if t_max <= 0:
            continue

        # Recurse
        intersection = traverse_octree(ray_origin, ray_direction, isovalue, child)
        
        if intersection is not None:
            if closest_intersection is None or intersection.t < closest_intersection.t:
                closest_intersection = intersection

    return closest_intersection

def evaluate_leaf_polynomials(ray_origin, ray_direction, isovalue, leaf_node):
    """
    Evaluate the B-spline basis or BB-forms within a leaf node.
    """
    # Use Horner scheme for efficient evaluation [S1]
    # Check if isovalue is contained in the leaf's range (already checked in parent, but verify locally)
    if not (leaf_node.min_val <= isovalue <= leaf_node.max_val):
        return None
    
    # Find intersection with isosurface defined by the polynomials
    # This involves solving for t where f(ray_origin + t * ray_direction) = isovalue
    # Using the convex combination property [S1] or BB-coefficients [S2]
    return solve_isosurface_intersection(ray_origin, ray_direction, isovalue, leaf_node.polynomials)
```

**Parameters:**
- $b$: Leaf size factor. Larger $b$ reduces tree depth and memory overhead but reduces skipping granularity [S1].

**Edge Cases and Pitfalls:**
- **Precision:** Conservative estimates must be tight enough to avoid false negatives (skipping valid regions) but loose enough to allow pruning. Inaccurate min/max propagation leads to incorrect culling [S1].
- **Boundary Conditions:** Ensure ray bounding box intersection tests handle rays parallel to axes or originating inside nodes correctly [G].

## Operating characteristics
- **Time Complexity:** Traversal is proportional to the number of non-empty nodes intersected by the ray. Pruning reduces this significantly in sparse volumes.
- **Memory Complexity:** $O(N)$ where $N$ is the number of leaf nodes, plus overhead for the octree structure. The leaf size $b$ affects the constant factor [S1].
- **Performance:** Reduces the number of expensive spline evaluations by skipping empty regions [S2].
- **Strengths:** Interactive transfer function changes without geometry rebuild; efficient for large datasets [S1].
- **Limitations:** Requires pre-processing to build the octree and compute min/max values; overhead may not be justified for very small or dense volumes.

## Background
Originated in wavelet-based multiresolution isosurface rendering [S1]. The method leverages the properties of B-spline bases and octree structures to enable efficient empty space skipping [S1][S2]. It is used in high-performance volume rendering systems for scientific visualization [S1].
