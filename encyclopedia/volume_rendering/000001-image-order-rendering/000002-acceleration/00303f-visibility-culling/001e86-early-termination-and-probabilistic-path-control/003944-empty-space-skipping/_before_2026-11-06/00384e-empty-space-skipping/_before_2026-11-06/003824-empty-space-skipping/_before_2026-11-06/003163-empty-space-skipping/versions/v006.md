# Empty-space skipping

Also called: Block Empty Space Skipping, Chebyshev Empty Space Skipping, Empty Region Skipping, Occupancy Grid Pruning

## Overview
Empty-space skipping is an acceleration technique for volume rendering that minimizes computation by skipping the sampling of empty space in a volumetric dataset [S2, S4, S5, unofficial]. It solves the problem of wasted computation time when raycasters sample points at fixed intervals through regions containing no or irrelevant data [S2, unofficial][S8, book]. It sets itself apart from its siblings by explicitly using an additional data structure (e.g., octree, occupancy grid, or distance map) to encode empty space and modulate sampling distance or jump over regions, whereas [Early ray termination](1019-early-ray-termination.md) relies on accumulated opacity thresholds and [Bounding Volume Culling](1239-bounding-volume-culling.md) relies on geometric hulls [S1, S2, S5, unofficial].

## How it works
Empty-space skipping accelerates ray marching by determining regions of empty space that do not require extensive sampling, effectively reducing the number of samples evaluated [S5, unofficial]. The method generally involves precomputing or maintaining a data structure that identifies empty regions, and then querying this structure during the ray marching loop to skip samples or jump to the next non-empty region [S1, S3, S6, unofficial].

### Inputs and Outputs
*   **Inputs:**
    *   Volume dataset (3D texture or grid).
    *   Ray origin $\mathbf{o}$ and direction $\mathbf{d}$.
    *   Empty-space data structure (e.g., occupancy grid, distance map, octree, or brick classification table) [S1, S3, S4, unofficial][S11].
    *   Transfer function (for opacity/density evaluation) [S3, S13, unofficial].
*   **Outputs:**
    *   Rendered pixel color and opacity.
    *   Reduced number of volume samples and data structure lookups [S5, unofficial].

### Data Structures
The specific data structure varies by variant, but common layouts include:
*   **Occupancy Grid:** A binary grid cached and updated during training or pre-processing. Each cell stores a boolean or integer indicating if the region is empty (e.g., opacity $\alpha_i < 10^{-2}$) [S4, unofficial].
*   **Distance Map / Occupancy Map:** A 3D texture storing distance or occupancy values. Accessed via `texelFetch` [S3, unofficial].
*   **Octree:** A hierarchical structure where each node stores statistical information, such as min/max bounds or scalar value ranges, to determine if a region contains the target isovalue or density [S6, S1610-empty-space-skipping-with-octree.md, unofficial].
*   **Brick Classification Table:** An array of 32-bit integers, one per brick, storing state (skipped/empty, early termination/saturated, or sampled densely) [S11].
*   **Max Pyramid:** A coarse-to-fine pyramid structure storing max deviation values for transfer-function-independent skipping [S13, unofficial].

### Numbered Steps (General Algorithm)
1.  **Cast Ray:** Initialize ray parameters (origin, direction, length) [S6, unofficial].
2.  **Check Degeneracy:** If the ray is degenerate (infinite, NaN, or length $> \sqrt{3}$), terminate immediately to prevent performance regressions [S3, unofficial].
3.  **Query Empty-Space Structure:** At the current sampling position (or block boundary), query the empty-space data structure [S3, S6, unofficial].
    *   If using a **Distance Map/Occupancy Grid**: Fetch the value at the mapped coordinate [S3, unofficial].
    *   If using an **Octree**: Traverse the tree to find the first non-empty node [S6, unofficial].
    *   If using **Brick Classification**: Check the brick state table [S11].
4.  **Skip or Sample:**
    *   **If Empty:** Calculate a skip delta (step count) to jump over the empty region. Update the loop index or ray parameter to the next non-empty boundary [S3, S6, unofficial].
    *   **If Non-Empty:** Perform standard volume sampling (evaluate density, apply transfer function, compute lighting) [S3, unofficial].
5.  **Update Accumulators:** Composite the sample color and opacity using front-to-back blending [S3, unofficial].
6.  **Early Termination Check:** If accumulated opacity exceeds a threshold (e.g., 0.98) or transmittance drops below a threshold (e.g., $10^{-4}$), break the loop [S3, S4, unofficial].
7.  **Repeat:** Continue until the ray exits the volume or terminates [S6, unofficial].

### Formulas
*   **Standard Ray Marching Step:**
    $$ \mathbf{p}_i = \mathbf{o} + i \cdot \mathbf{step\_vector} $$
    Where $\mathbf{step\_vector} = \frac{\mathbf{d}}{N} \cdot \text{ray\_length}$ [S3, unofficial].
*   **Transmittance:**
    $$ T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right) $$
    Where $\sigma_j$ is density and $\delta_j$ is step size [S4, unofficial].
*   **Block Empty Space Skipping (ESS) Skip Delta:**
    For a distance map lookup with value $dist$ at index $u_i$:
    $$ r = \text{clamp}(u_i - u, -1.0, 0.0) $$
    $$ i_{\delta\_xyz} = (\text{step}(0.0, \text{step\_dist\_texel\_inv}) + r) \cdot \text{step\_dist\_texel\_inv} $$
    For Chebyshev ESS (distance-based):
    $$ i_{\delta\_xyz} = (\text{step}(0.0, -\text{step\_dist\_texel\_inv}) + \text{sign}(\text{step\_dist\_texel\_inv}) \cdot dist + r) \cdot \text{step\_dist\_texel\_inv} $$
    Final delta:
    $$ i_{\delta} = \max(1, \lceil \min(i_{\delta\_xyz}.x, i_{\delta\_xyz}.y, i_{\delta\_xyz}.z) \rceil) $$
    [S3, unofficial].
*   **TF-Adaptive Skip Cutoff:**
    $$ \text{cutoff} = \text{deadband} - 0.05 $$
    If cell max deviation $< \text{cutoff}$, skip the cell [S13, unofficial].

### Parameters
*   **$\alpha_{thre}$ (Opacity Threshold):** Threshold below which a region is considered empty. Typical value: $10^{-2}$ [S4, unofficial].
*   **$early\_stop\_eps$ (Transmittance Threshold):** Transmittance below which ray marching terminates. Typical value: $10^{-4}$ [S4, unofficial].
*   **$sampling\_factor$:** Controls the number of steps relative to volume dimensions [S3, unofficial].
*   **$essType$:** Integer flag selecting ESS variant. 1 = Block Empty Space Skipping; 2 = Chebyshev Empty Space Skipping [S3, unofficial].
*   **$\tau^{(c)}, \tau^{(f)}$ (Free Space Thresholds):** Thresholds for coarse and fine density grids. Typical values: $\tau^{(c)} = 10^{-3}$, $\tau^{(f)} = 10^{-4}$ [S12].

### Pseudocode
```python
def empty_space_skipping_raymarch(ray_origin, ray_direction, volume_texture, 
                                  occupancy_map, volume_size, sampling_factor):
    """
    Generic empty-space skipping raymarcher using an occupancy/distance map.
    """
    # 1. Initialize ray parameters
    ray_length = length(volume_size) # Simplified bounding box diagonal
    step_vector = normalize(ray_direction) * (ray_length / (sampling_factor - 1))
    
    # 2. Check for degenerate rays
    if not is_finite(ray_direction) or length(ray_direction) > sqrt(3):
        return (0.0, 0.0) # Return black/transparent

    accumulated_color = vec3(0.0)
    accumulated_alpha = 0.0
    i = 0
    
    # Precompute distance map parameters
    dim_distance_map = textureSize(occupancy_map, 0).xyz
    block_size = ceil(volume_size / dim_distance_map)
    volume_to_distance_map = volume_size / (block_size * dim_distance_map)
    step_dist_texel = step_vector * volume_size / block_size
    step_dist_texel_inv = 1.0 / step_dist_texel
    
    # Determine distance map index based on ray direction signs
    distance_map_idx = 0
    if ray_direction.z < 0: distance_map_idx += 1
    if ray_direction.y < 0: distance_map_idx += 2
    if ray_direction.x < 0: distance_map_idx += 4
    
    # 3. Main Loop
    while i < sampling_factor:
        # Calculate sampling position
        sampling_pos = ray_origin + float(i) * step_vector
        
        # Map to distance map coordinates
        pos_distance_map = volume_to_distance_map * sampling_pos
        u = pos_distance_map * dim_distance_map
        u_i = ivec3(clamp(floor(u), ivec3(0), dim_distance_map - 1))
        
        # Fetch occupancy/distance value
        # Note: In a real implementation, texelFetch would be used.
        # Here we assume a function get_occupancy_value returns the stored value.
        dist = get_occupancy_value(occupancy_map, u_i, distance_map_idx)
        
        # Calculate fractional offset
        r = clamp(u_i - u, -1.0, 0.0)
        
        # Calculate step delta for Block ESS (essType == 1)
        # If dist indicates empty space, skip
        if dist == 0: # Assuming 0 means empty in this context
            # Backtracking logic if empty space reached but no skip possible
            i_delta_backwards = -ceil(sampling_factor)
            i = max(i + i_delta_backwards, 0)
            continue # Skip this sample
            
        # Calculate skip delta
        i_delta_xyz = (step(0.0, step_dist_texel_inv) + r) * step_dist_texel_inv
        i_delta = max(1, int(ceil(min(min(i_delta_xyz.x, i_delta_xyz.y), i_delta_xyz.z))))
        
        # If the delta is small (non-empty region), sample; otherwise skip
        if i_delta == 1:
            # Sample volume
            voxel_value = get_volume_intensity(sampling_pos, volume_texture)
            color = apply_transfer_function(voxel_value)
            
            # Front-to-back compositing
            color.rgb *= color.a
            accumulated_color = accumulated_color + (1.0 - accumulated_alpha) * color.rgb
            accumulated_alpha = accumulated_alpha + color.a * (1.0 - accumulated_alpha)
            
            # Early Ray Termination
            if accumulated_alpha > 0.98:
                break
        else:
            # Skip empty region
            i += i_delta
            
    return (accumulated_color, accumulated_alpha)
```

### Edge Cases and Pitfalls
*   **Degenerate Rays:** Rays with infinite, NaN, or excessively long directions must be terminated immediately to prevent performance regressions [S3, unofficial].
*   **Backtracking:** When empty space is detected but no skip is possible (e.g., `dist==0` in some implementations), the index may need to backtrack to the last occupied step, clamped to `i_min` [S3, unofficial].
*   **Transfer Function Changes:** In methods like Brick Classification, changing the transfer function invalidates the metadata. Recomputation must be offloaded to a background thread; until complete, unprocessed bricks are treated as 'missing', potentially causing the renderer to request and filter empty bricks [S11].
*   **Threshold Tuning:** Setting thresholds too low (e.g., $\tau^{(c)}=0$) can cause out-of-memory errors or degrade quality. Low-density initialization and free space skipping cannot be applied simultaneously [S12].
*   **Dense Structures:** In very dense volumes (e.g., cosmic-web structures), empty-space skipping checks may add overhead (texture loads) without providing skip payoffs, leading to net performance regression [S13, unofficial].

## Subtopics

### [Ray Marcher with Macrocell Empty Space Skipping](1009-ray-marcher-with-macrocell-empty-space-skipping.md)
Divides volume into coarse macrocells and precomputes boolean/aggregate values to skip zero-density regions. Best for fixed coarse grid hierarchies.

### [Empty Space Skipping with Orthogonal BSP Tree](1054-empty-space-skipping-with-orthogonal-bsp-tree.md)
Partitions volume into sub-volumes based on voxel properties into an orthogonal BSP tree for visibility sorting. Best for texture-based rendering with arbitrary slicing planes.

### [Empty Space Skipping with Octree](1610-empty-space-skipping-with-octree.md)
Uses an octree storing conservative min/max scalar value estimates to skip transparent regions. Best for isosurface rendering and avoiding expensive spline evaluations.

### [Spatial Skipping (Occupancy Grid)](1614-spatial-skipping-occupancy-grid.md)
Uses a simple, explicit voxel-based occupancy grid with a conservative density threshold to binarize density. Best for uniform sampling acceleration and NeRF-style training.

### [Parallel Tree-Construction for Empty-Space Skipping](5037-parallel-tree-construction-for-empty-space-skipping.md)
Enables run-time re-construction of acceleration data structures on the GPU to accommodate dynamic transfer function changes. Best for interactive applications with frequent TF adjustments.

### [Transfer-Function Independent Empty-Space Skipping](5038-transfer-function-independent-empty-space-skipping.md)
Stores visibility information independent of the transfer function, decoupling spatial culling from opacity evaluation. Best for real-time TF adjustments without structural overhead.

### [Homogeneity Acceleration](5754-homogeneity-acceleration.md)
Approximates the contribution of uniform, non-empty regions instead of sampling voxel-by-voxel. Best for regions with data but no internal variation.

### Brick Classification and Empty Space Skipping
Classifies bricks into three categories (skipped/empty, early termination/saturated, or sampled densely) to bypass large sets of work. Maintains state in a shared array on GPU and host memory. If a brick is empty, the renderer leaps over it. Metadata is stored as one 32-bit integer per brick. When the transfer function changes, metadata becomes invalid and is recomputed in a background thread; unprocessed bricks are treated as 'missing' until complete [S11].

### Free Space Skipping
Skips sampled points in known free space by checking optimized density grids $V^{(\text{density})}_{(c)}$ and $V^{(\text{density})}_{(f)}$. Points are skipped if activated alpha is below thresholds $\tau^{(c)}$ and $\tau^{(f)}$. Only queries view-dependent color models if points pass both thresholds. Optimal thresholds are $\tau^{(c)} = 10^{-3}$ and $\tau^{(f)} = 10^{-4}$. Setting thresholds to zero causes OOM or quality degradation [S12].

### SparseLeap
A method that optimizes both the number of samples to evaluate and the number of look-ups into the empty-space skipping data structure. It is agnostic of the data structure used (e.g., page-table hierarchies or octrees) and can be used in conjunction with them [S5, unofficial].

### TF-Adaptive Empty-Space Skip
Skips volume cells provably contributing zero opacity by checking if the cell's stored max deviation is below a cutoff derived from live contrast/trim uniforms. Consults a max pyramid coarse-to-fine (level 1, then level 0) before paying for a full-res sample. Skips land back on the fixed step grid to ensure bit-identical results. Can cause performance regression in dense structures where skips are rare [S13, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the data structure. Octrees require $O(\log N)$ lookups per step but reduce samples significantly. Occupancy grids allow $O(1)$ lookups but may require more frequent queries. Brick classification allows $O(1)$ brick-level skips [S5, unofficial][S11].
*   **Memory Complexity:** Requires additional memory for the empty-space data structure (e.g., occupancy grid, octree, distance map). This can be significant for large volumes but is often much smaller than the full volume dataset [S4, S6, unofficial].
*   **Measured Performance:** Provides a 2.3x to 5x performance gain in some implementations [S10, unofficial]. NerfAcc reports pruning up to 98% of samples in dense scenes [S4, unofficial].
*   **Strengths:** Significantly reduces the number of samples and function evaluations, especially in volumes with large empty regions. Can be combined with other acceleration techniques [S5, unofficial].
*   **Limitations:** Requires precomputation or maintenance of the data structure. Performance can degrade in dense volumes where empty space is rare [S13, unofficial]. Changing transfer functions may require expensive recomputation [S11].
*   **When to Use:** Volumes with significant empty space, interactive applications requiring fast frame rates, NeRF training where memory efficiency is critical [S4, unofficial][S11].
*   **When Not to Use:** Very dense volumes with little empty space, where the overhead of querying the data structure outweighs the benefits [S13, unofficial].

## Background
Empty-space skipping was introduced as an optimization to reduce the computational cost of volume rendering, particularly raycasting, which samples points at fixed intervals even in empty space [S2, unofficial][S8, book]. Early methods used hierarchical representations like octrees or distance fields to adapt step sizes [S6, unofficial][S8, book]. More recent approaches, such as Occupancy Grid Pruning in NeRF acceleration (e.g., NerfAcc, Instant-NGP), use binary grids updated during training to skip empty and occluded regions [S4, unofficial]. Brick classification techniques have been used in GPU-based ray-guided rendering to manage large datasets [S11]. The technique is widely used in both scientific visualization and real-time rendering applications [S7, S11].
