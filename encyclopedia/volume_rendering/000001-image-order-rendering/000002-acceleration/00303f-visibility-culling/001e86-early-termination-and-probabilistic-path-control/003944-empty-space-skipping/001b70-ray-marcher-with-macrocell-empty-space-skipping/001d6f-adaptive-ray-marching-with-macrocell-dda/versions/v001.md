# Adaptive Ray Marching with Macrocell DDA

Also called: Adaptive Macrocell Ray Marching

## Overview
Adaptive Ray Marching with Macrocell DDA is a ray traversal technique that accelerates volume rendering by combining a 3D Digital Differential Analyzer (DDA) for coarse macrocell traversal with adaptive step sizing based on opacity upper bounds. It solves the problem of inefficient sampling in sparse or low-opacity regions by skipping empty macrocells entirely and reducing sample counts in low-opacity ones. Unlike its parent [Ray Marcher with Macrocell Empty Space Skipping](1009-ray-marcher-with-macrocell-empty-space-skipping.md), which primarily focuses on binary empty-space skipping, this method introduces granularity by adapting the step size within non-empty cells. It differs from [Triangulated Active Brick Boundary Mesh for Space Skipping](1426-triangulated-active-brick-boundary-mesh-for-space-skipping.md) by using a regular grid structure rather than a mesh, offering simpler implementation and better cache coherence on GPUs.

## How it works
The method traverses a volume using a hierarchical approach: a coarse macrocell grid guides the ray, and within each active macrocell, samples are taken at adaptive intervals.

### Inputs and Outputs
*   **Input**: Ray origin $\mathbf{o}$, ray direction $\mathbf{d}$, near plane $t_{min}$, far plane $t_{max}$.
*   **Input**: Volume data structure containing macrocell metadata (dimensions, spacing reciprocals, opacity upper bounds).
*   **Output**: Accumulated color and opacity for the ray.

### Data Structures
The core data structure is the `DeviceVolume` (or equivalent), which must contain:
*   `macrocell_dims`: A 3D vector (e.g., `int3`) representing the number of macrocells in x, y, and z dimensions.
*   `macrocell_spacings_rcp`: A 3D vector (e.g., `float3`) storing the reciprocal of the macrocell spacing in world units. This allows conversion from world space to macrocell index space via multiplication.
*   `opacity_upper_bounds`: A 3D array (or flattened 1D array) mapping macrocell indices to a scalar value representing the maximum possible opacity contribution of that cell. This value is used to estimate if a cell is empty or to determine step size.

### Parameters
*   `step`: The base sampling step size in world units.
*   `float_epsilon`: A small constant (e.g., $10^{-6}$) used to determine if a cell is effectively empty.
*   `ADAPTIVE_SAMPLING`: A boolean flag or preprocessor macro. If true, adaptive logic is used; if false, fixed-step marching is used.

### Algorithm Steps

1.  **Transform Ray to Macrocell Space**:
    Calculate the ray origin and direction in macrocell index space.
    $$ \mathbf{m}_{org} = \mathbf{o} \times \text{macrocell\_spacings\_rcp} $$
    $$ \mathbf{m}_{dir} = \mathbf{d} \times \text{macrocell\_spacings\_rcp} $$
    Note: $\mathbf{m}_{dir}$ may need normalization or handling if it contains zeros to avoid division by zero in DDA.

2.  **Initialize DDA**:
    Initialize a 3D DDA iterator with $\mathbf{m}_{org}$, $\mathbf{m}_{dir}$, $t_{min}$, $t_{max}$, and `macrocell_dims`. The DDA yields tuples of `(cell_index, t_enter, t_exit)` for each macrocell intersected by the ray.

3.  **Iterate Macrocells**:
    For each macrocell $(cell, t_0, t_1)$ returned by the DDA:
    
    a. **Check Opacity Upper Bound**:
    Retrieve the opacity upper bound $r$ for the current cell.
    $$ r = \text{opacityUpperBound}(cell) $$
    
    b. **Skip Empty Cells**:
    If $|r| \le \text{float\_epsilon}$, the cell is considered empty. Skip to the next macrocell. [S1, unofficial]

    c. **Determine Step Size**:
    Calculate the adaptive step size $ss$.
    $$ ss = \text{sample\_size\_scaler}(\text{adaptiveSamplingRate}(step, r), t_0, t_1) $$
    The `adaptiveSamplingRate` function typically reduces the step size as opacity $r$ increases, or keeps it constant if $r$ is low. `sample_size_scaler` ensures $ss$ fits within the macrocell bounds $[t_0, t_1]$. [S1, unofficial]

    d. **Sample Within Macrocell**:
    Initialize interval $t = (t_x, t_y) = (t_0, \min(t_1, t_0 + ss))$.
    While $t_y > t_x$:
    i. Evaluate volume density and transfer function at $t_x$.
    ii. Accumulate color and opacity.
    iii. Update $t_x = t_y$.
    iv. Update $t_y = \min(t_x + ss, t_1)$.
    
    e. **Early Termination**:
    If accumulated opacity reaches 1.0 (or a threshold), terminate the ray.

4.  **Non-Adaptive Fallback**:
    If `ADAPTIVE_SAMPLING` is false, skip the opacity check and adaptive step calculation. Use a fixed step size:
    $$ t = (t_x, t_y) = (t_{min}, \min(t_{max}, t_{min} + step)) $$
    Loop while $t_y > t_x$ and body returns true, updating $t_x = t_y$ and $t_y = \min(t_x + step, t_{max})$. [S1, unofficial]

### Pseudocode

```python
def adaptive_ray_march_with_macrocell_dda(ray_origin, ray_direction, t_min, t_max, volume):
    """
    ray_origin: vec3
    ray_direction: vec3
    t_min: float
    t_max: float
    volume: DeviceVolume struct containing macrocell_dims, macrocell_spacings_rcp, opacity_upper_bounds
    """
    
    # 1. Transform to macrocell space
    m_org = ray_origin * volume.macrocell_spacings_rcp
    m_dir = ray_direction * volume.macrocell_spacings_rcp
    
    # 2. Initialize DDA
    # dda3 returns an iterator that yields (cell_index, t_enter, t_exit)
    dda = dda3(m_org, m_dir, t_min, t_max, volume.macrocell_dims)
    
    accumulated_color = vec3(0.0)
    accumulated_opacity = 0.0
    
    # 3. Traverse macrocells
    for cell_index, t_enter, t_exit in dda:
        
        # 4. Get opacity upper bound
        r = volume.opacity_upper_bounds[cell_index]
        
        # 5. Skip empty cells
        if abs(r) <= float_epsilon:
            continue
            
        # 6. Calculate adaptive step size
        # adaptiveSamplingRate returns a multiplier or direct step based on r
        base_step = adaptive_sampling_rate(volume.base_step, r)
        
        # sample_size_scaler ensures step fits in [t_enter, t_exit]
        step_size = sample_size_scaler(base_step, t_enter, t_exit)
        
        # 7. Sample within macrocell
        t_curr = t_enter
        t_next = min(t_exit, t_curr + step_size)
        
        while t_next > t_curr:
            # Evaluate volume at t_curr
            density = sample_volume(volume, ray_origin + ray_direction * t_curr)
            color, alpha = transfer_function(density)
            
            # Composite
            # C_out = C_in + C * alpha * (1 - A_in)
            # A_out = A_in + alpha * (1 - A_in)
            accumulated_color += color * alpha * (1.0 - accumulated_opacity)
            accumulated_opacity += alpha * (1.0 - accumulated_opacity)
            
            if accumulated_opacity >= 1.0:
                return accumulated_color
                
            t_curr = t_next
            t_next = min(t_curr + step_size, t_exit)
            
    return accumulated_color
```

### Edge Cases and Pitfalls
*   **Precision**: When $t_{enter}$ and $t_{exit}$ are very close, floating-point errors may cause the loop condition $t_y > t_x$ to fail prematurely or infinitely. Use a small epsilon for comparisons.
*   **Zero Direction Components**: If `ray_direction` has a zero component, `m_dir` will have a zero component. The DDA implementation must handle this correctly (typically by stepping only in non-zero directions or treating the cell as fully traversed in that dimension).
*   **Opacity Upper Bound Accuracy**: If `opacity_upper_bounds` are inaccurate (too high), adaptive sampling may not skip enough samples. If too low, empty cells might be sampled unnecessarily. [S1, unofficial]

## Subtopics

### [Resumable Ray Marching Iterator](1505-resumable-ray-marching-iterator.md)
The Resumable Ray Marching Iterator is a GPU-based ray traversal method designed to handle out-of-core volume rendering by pausing ray execution when data is missing from GPU memory and resuming it in subsequent passes. It builds on [Adaptive Ray Marching with Macrocell DDA](1500-adaptive-ray-marching-with-macrocell-dda.md) by adding state persistence via Multiple Render Targets (MRTs) and Z-buffer culling to ensure only active rays are processed during data loading. Unlike [Network Ray Marching Iterator](1510-network-ray-marching-iterator.md) which may rely on different streaming heuristics, or [Macrocell Grid Traversal with Majorant Densities](1528-macrocell-grid-traversal-with-majorant-densities.md) which focuses on density bounds, this method explicitly manages the CPU-GPU synchronization required for dynamic data loading.

### [Network Ray Marching Iterator](1510-network-ray-marching-iterator.md)
The Network Ray Marching Iterator is a ray marching algorithm designed for distributed or networked rendering environments, typically leveraging GPU ray tracing APIs such as NVIDIA OptiX. It extends the parent [Adaptive Ray Marching with Macrocell DDA](1500-adaptive-ray-marching-with-macrocell-dda.md) by introducing block-level divergence control via `block_any` to manage thread synchronization across macrocell boundaries. This method is distinct from its siblings because it explicitly handles the "alive" status of rays in a distributed context, ensuring that inactive threads do not waste computation while maintaining adaptive sampling rates based on opacity upper bounds.

### [Macrocell Grid Traversal with Majorant Densities](1528-macrocell-grid-traversal-with-majorant-densities.md)
This method accelerates volumetric path tracing by combining a coarse spatial partition (macrocells) with Delta Tracking (Woodcock tracking) to skip empty or low-opacity regions more efficiently than fixed-step marching. It sets itself apart from its parent [Adaptive Ray Marching with Macrocell DDA](1500-adaptive-ray-marching-with-macrocell-dda.md) by explicitly using the alpha component of the transfer function as a majorant extinction coefficient to determine probabilistic free-flight distances, allowing larger steps in homogeneous cells while maintaining unbiased Monte Carlo estimation.

### Space Skipping with 3DDDA
Space Skipping with 3DDDA is a mechanism to skip empty regions in sparse volume data using a uniform grid and 3DDDA algorithm [S2]. The fragment shader traverses the macrocell grid using 3DDDA in an outer loop. If a macrocell is nonempty, it enters the volume rendering loop with peak finding tests between samples. To begin sampling, it finds the first $t$ to sample when entering a macrocell by solving for the maximum $x$ after $T_{enter}$:
$$ x^2/2 + bx = T_{enter} \implies x_{tenter} = \frac{-b + \sqrt{b^2 + 2aT_{enter}}}{a} $$
It then computes the floor values $\lfloor b x_{tenter} \rfloor$, $T(\lfloor b x_{tenter} \rfloor)$ and $\frac{\partial T}{\partial x}(\lfloor b x_{tenter} \rfloor)$, then samples and increments as in Equation 17 of the source. To avoid duplicate samples, it stores the greatest $t$ at which it already sampled, and uses the maximum of that and $T_{enter}$ [S2]. The uniform grid stores min-max values of enclosed voxels, and coarse grids (e.g., $64^3$ cells) work best on the GPU [S2].

## Operating characteristics
*   **Time Complexity**: $O(N)$ where $N$ is the number of samples taken. However, the constant factor is significantly reduced by skipping empty macrocells and reducing samples in low-opacity regions.
*   **Memory Complexity**: $O(M)$ where $M$ is the number of macrocells. The macrocell grid is much smaller than the full volume grid.
*   **Performance**: Performance gains are most significant in sparse volumes or volumes with large empty regions. In dense, uniformly opaque volumes, the overhead of DDA and opacity checks may slightly reduce performance compared to fixed-step marching. [S1, unofficial]
*   **Strengths**: Simple to implement, efficient for sparse data, good cache coherence on GPUs due to regular grid structure. [S1, unofficial][S2]
*   **Limitations**: Less effective for highly heterogeneous volumes where opacity varies rapidly within macrocells. Requires precomputed opacity upper bounds. [S1, unofficial]
*   **When to Use**: Sparse volumes, interactive rendering, out-of-core rendering (with resumable variant). [S1, unofficial][S2]
*   **When Not to Use**: Dense, uniformly opaque volumes where fixed-step marching is simpler and faster. [S1, unofficial]

## Background
Adaptive Ray Marching with Macrocell DDA originates from the `instantvnr` project, an interactive volume visualization tool based on multi-resolution hash encoding based neural representation [S1, unofficial]. The method was developed by Qi Wu, Michael J. Doyle, and Kwan-Liu Ma, and published in IEEE Transactions on Visualization and Computer Graphics in 2023 [S1, unofficial]. The use of 3DDDA for space skipping in volume rendering has earlier roots, as seen in work by Knoll et al. on volume ray casting with peak finding [S2]. The integration of adaptive sampling based on opacity bounds is a key innovation in `instantvnr` to handle the sparsity of neural volume representations efficiently.
