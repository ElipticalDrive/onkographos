# Adaptive Ray Traversal


## Overview
Adaptive ray traversal is a visibility culling technique for direct volume rendering that accelerates ray marching by distinguishing between empty space and regions near data. It solves the problem of excessive sampling in large empty volumes by using a low-precision traversal algorithm for empty regions and switching to a high-precision algorithm when approaching data. It differs from standard empty-space skipping by dynamically adjusting precision based on proximity to data, rather than using a static skip distance or hierarchical structure like [Adaptive Ray Marching with Voxel Skipping](3870-adaptive-ray-marching-with-voxel-skipping.md).

## How it works
**Inputs:** A 3D volume grid, a set of rays, and a pre-computed "vicinity flag" for each voxel.
**Outputs:** Accumulated color and opacity for each pixel.
**Data Structures:**
*   **Volume Grid:** A 3D array of voxels. Each voxel contains a data value (e.g., density) and a boolean `vicinity_flag`.
*   **Vicinity Flag:** A boolean field set to `true` for all empty voxels that are immediate neighbors (6-connected or 26-connected) of at least one non-empty (data) voxel. All other empty voxels have `vicinity_flag = false`. [S1, unofficial]

**Algorithm Steps:**
1.  **Pre-processing:** Iterate through all voxels. For every voxel with non-zero data, mark all its empty neighbors as having `vicinity_flag = true`. [S1, unofficial]
2.  **Ray Initialization:** For each ray, determine the starting voxel index.
3.  **Traversal Loop:** While the ray is within the volume bounds:
    a.  **Check Current Voxel:** Let the current voxel be $V$.
    b.  **Precision Selection:**
        *   If $V$ is empty and `V.vicinity_flag` is `false`: Use the **Low-Precision Algorithm**. This algorithm skips multiple voxels at once (e.g., using a coarse step size or integer arithmetic) to rapidly traverse empty space. [S1, unofficial]
        *   If $V$ is empty and `V.vicinity_flag` is `true`: Switch to the **High-Precision Algorithm**. This algorithm steps one voxel at a time (or with fine granularity) to accurately sample the transition region. [S1, unofficial]
        *   If $V$ is non-empty: Use the **High-Precision Algorithm** to sample the data. [S1, unofficial]
    c.  **Advance Ray:** Update the ray position and voxel index based on the selected algorithm's step size.
    d.  **Termination:** If the ray exits the volume or reaches a maximum opacity threshold, stop.

**Pseudocode:**
```python
def adaptive_ray_traversal(ray, volume_grid, vicinity_flags):
    # ray: object with origin, direction, t_max
    # volume_grid: 3D array of voxel data
    # vicinity_flags: 3D array of booleans
    
    # Initialize ray parameters
    t = 0.0
    x, y, z = ray.origin
    dx, dy, dz = ray.direction
    
    # Determine initial voxel
    ix, iy, iz = voxel_indices(x, y, z)
    
    while t < ray.t_max and inside_volume(ix, iy, iz):
        is_empty = volume_grid[ix, iy, iz] == 0
        is_near_data = vicinity_flags[ix, iy, iz]
        
        if is_empty and not is_near_data:
            # Low-precision traversal: skip multiple voxels
            step_size = COARSE_STEP # e.g., 4 or 8 voxels
            # Calculate next voxel index directly
            ix, iy, iz = next_voxel_coarse(ix, iy, iz, dx, dy, dz, step_size)
            t += step_size * ray.step_length
        else:
            # High-precision traversal: step one voxel or small amount
            step_size = FINE_STEP # e.g., 1 voxel or sub-voxel
            # Sample if non-empty or near data
            if not is_empty or is_near_data:
                sample_color = volume_grid[ix, iy, iz]
                accumulate(sample_color)
            
            # Advance ray precisely
            t += step_size * ray.step_length
            x, y, z = ray.origin + t * ray.direction
            ix, iy, iz = voxel_indices(x, y, z)
            
    return accumulated_color

def voxel_indices(x, y, z):
    # Convert world coordinates to voxel indices
    # [G] Implementation depends on grid origin and spacing
    return int(x / spacing), int(y / spacing), int(z / spacing)

def next_voxel_coarse(ix, iy, iz, dx, dy, dz, step_size):
    # [G] Simple integer stepping for empty space
    # Assumes ray direction components are non-zero for simplicity
    # In practice, use a DDA-like approach but with larger steps
    new_ix = ix + int(sign(dx) * step_size)
    new_iy = iy + int(sign(dy) * step_size)
    new_iz = iz + int(sign(dz) * step_size)
    return new_ix, new_iy, new_iz
```

**Parameters:**
*   `COARSE_STEP`: Step size for empty space. Typical value: 4–8 voxels. [S1, unofficial]
*   `FINE_STEP`: Step size for vicinity/data regions. Typical value: 1 voxel or sub-voxel. [S1, unofficial]

**Edge Cases:**
*   **Degenerate Rays:** Rays parallel to grid axes may cause division by zero in DDA. Handle by checking for zero direction components. [G]
*   **Precision Errors:** Low-precision skipping might overshoot a vicinity voxel if the step size is too large. Ensure `COARSE_STEP` is small enough to guarantee detection of the vicinity boundary. [G]

## Subtopics

### Proximity Clouds
Proximity clouds is an extension of adaptive ray traversal where the distance to the nearest data voxel is pre-computed for each empty voxel. Instead of a binary vicinity flag, each empty voxel stores an integer $n$ representing the number of voxels to the nearest data voxel. When a ray encounters a proximity voxel with value $n$, it skips the next $n$ voxels directly. This allows for larger, data-aware skips than standard vicinity flags. [S1, unofficial]

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of voxels intersected by rays, but with a significantly reduced constant factor due to skipping. The speedup depends on the volume of empty space.
*   **Memory Complexity:** $O(V)$ where $V$ is the number of voxels, for storing the vicinity flags or proximity values.
*   **Strengths:** Efficient for sparse volumes with large empty regions. Simple to implement compared to hierarchical methods.
*   **Limitations:** Pre-processing time to compute vicinity flags. Performance degrades if the volume is dense (few empty voxels). Precision trade-off between skip speed and accuracy.
*   **When to Use:** Sparse volumes with well-defined object boundaries.
*   **When Not to Use:** Dense volumes, volumes with no clear empty space, or when high precision is required throughout.

## Background
Adaptive ray traversal was introduced as a method to accelerate direct volume rendering by exploiting the sparsity of data. It was described in the context of various volume rendering techniques, including PARC (Polygon assisted ray casting). The method relies on pre-computing spatial information (vicinity flags) to guide the ray marching process. [S1, unofficial]
