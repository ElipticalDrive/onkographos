# Delta Tracking with DDA Iteration (Macrocell-based)

Also called: DDAIter-based Delta Tracking, SpacePartition_SingleMC Delta Tracking

## Overview
A ray-marching technique for volume rendering that combines a Discrete Differential Analyzer (DDA) for traversing a coarse spatial partition (macrocells) with Delta Tracking (Russian Roulette) for sampling absorption and scattering events within those cells. It handles sparse or heterogeneous media by skipping empty macrocells and using a majorant density. It sets itself apart from standard DDA by replacing uniform step sizes with probabilistic free-flight distances derived from the majorant, allowing it to skip non-interacting regions within a macrocell more efficiently than fixed-step marching, while avoiding the overhead of full per-voxel traversal.

## How it works
**Inputs and Outputs**
- **Inputs**: Ray origin `ray_org`, ray direction `ray_dir`, ray near/far bounds `ray_tnear`, `ray_tfar`, macrocell grid dimensions `dims`, spatial inverse scale `spac_rcp`, majorant density accessor `access_majorant`, density scale constant, total extinction coefficient `sigma_t`, and an initial optical depth budget `tau`.
- **Outputs**: Boolean `found_hit` indicating if an interaction occurred, and the hit distance `rayt`.

**Data Structures**
- **Macrocell Iterator (`DDAIter`)**: A stateful iterator that computes the sequence of macrocells intersected by a ray. It maintains current cell coordinates and exit distances.
- **Spatial Parameters (`sp`)**: Contains `spac_rcp` (reciprocal of spatial scale) for normalizing coordinates to grid space.

**Numbered Steps**
1. **Initialize Macrocell Iterator**: Convert ray origin and direction to macrocell grid space.
   - Compute normalized origin: $m_{org} = ray_{org} \times sp.spac\_rcp$.
   - Compute normalized direction: $m_{dir} = ray_{dir} \times sp.spac\_rcp$.
   - Call `DDAIter::init(m_org, m_dir, ray_tnear, ray_tfar, dims)` to set up the traversal state.
2. **Initialize Loop State**:
   - Set `found_hit = false`.
   - Determine the starting $t$ for the first cell segment: $t = next\_cell\_begin + ray_{tnear}$. (Note: `next_cell_begin` is typically 0 or the entry $t$ of the first cell).
   - Initialize `tau` (optical depth budget) externally. This value represents the accumulated optical depth budget before entering the loop.
3. **Loop over Macrocells**:
   - While `DDAIter::next()` returns a valid cell $c$ with entry $t_0$ and exit $t_1$:
     a. **Retrieve Majorant**: Get the majorant density for cell $c$: $majorant = sp.access\_majorant(c) \times density\_scale$.
     b. **Skip Empty Cells**: If $|majorant| \le \epsilon$ (where $\epsilon$ is a small float epsilon, e.g., $10^{-6}$), the cell is empty. Return `true` from the current lambda/function to advance to the next macrocell without processing interaction logic. [S1, unofficial]
     c. **Update Optical Depth Budget**: Subtract the optical thickness of the current cell segment from `tau`. The segment length is $(t_1 - t)$. The optical thickness is $(t_1 - t) \times (majorant \times \sigma_t)$.
        $$ \tau \leftarrow \tau - (t_1 - t) \times (majorant \times \sigma_t) $$
     d. **Check for Event**: If $\tau > 0.f$, an interaction (scattering or absorption) occurred within the previous segment or the budget was exhausted. Return `true` to advance to the next macrocell. [S1, unofficial]
     e. **Calculate Hit Position**: If $\tau \le 0.f$, the interaction occurs within the current cell segment. Calculate the exact hit position $t_{hit}$:
        $$ t_{hit} = t + \frac{\tau}{majorant \times \sigma_t} $$
        *Warning*: This division can cause a division by zero error if `majorant` is zero but passed the epsilon check, or if `sigma_t` is zero. [S1, unofficial]
     f. **Record Hit**:
        - Set `found_hit = true`.
        - Update `next_cell_begin = t_{hit} - ray_{tnear}`.
        - Set output `rayt = t_{hit}`.
        - Return `false` to terminate the loop.
4. **Return Result**: After the loop completes (ray exits all macrocells or `tau` budget remains positive without hitting), return `found_hit`.

**Pseudocode**
```python
def delta_tracking_dda_iter(ray_org, ray_dir, ray_tnear, ray_tfar, dims, spac_rcp, access_majorant, density_scale, sigma_t, tau):
    # Step 1: Initialize Macrocell Iterator
    m_org = ray_org * spac_rcp
    m_dir = ray_dir * spac_rcp
    dda_iter = DDAIter()
    dda_iter.init(m_org, m_dir, ray_tnear, ray_tfar, dims)
    
    # Step 2: Initialize Loop State
    found_hit = False
    # next_cell_begin is the t-value where the current macrocell segment begins relative to ray_tnear
    # Initially, this is 0 if the ray starts at tnear, or the entry t of the first cell minus tnear
    next_cell_begin = 0.0 
    t = next_cell_begin + ray_tnear
    
    # Step 3: Loop over Macrocells
    while dda_iter.next():
        c = dda_iter.current_cell
        t0 = dda_iter.entry_t
        t1 = dda_iter.exit_t
        
        # Retrieve majorant density
        majorant = access_majorant(c) * density_scale
        
        # Skip empty cells
        if abs(majorant) <= 1e-6: # float_epsilon
            # Return true to advance to next macrocell (skip processing)
            # In a lambda/closure context, this might be 'continue' or returning a specific status
            # Here we simulate the control flow: skip to next iteration
            t = t1
            next_cell_begin = t1 - ray_tnear
            continue
            
        # Update optical depth budget
        segment_length = t1 - t
        optical_thickness = segment_length * (majorant * sigma_t)
        tau -= optical_thickness
        
        # Check for scattering/absorption event
        if tau > 0.0:
            # Event occurred in previous segment or budget exhausted
            # Advance to next macrocell
            t = t1
            next_cell_begin = t1 - ray_tnear
            continue
            
        # Calculate exact hit position within the current cell
        # Warning: Division by zero if majorant * sigma_t is zero
        if majorant * sigma_t == 0.0:
            # Handle degenerate case, e.g., skip or break
            t = t1
            next_cell_begin = t1 - ray_tnear
            continue
            
        t_hit = t + tau / (majorant * sigma_t)
        
        # Record hit
        found_hit = True
        next_cell_begin = t_hit - ray_tnear
        rayt = t_hit
        return found_hit, rayt
        
    return found_hit, None
```

**Parameters**
- `density_scale`: Constant multiplier for the majorant density. Typically hardcoded to `1.0`. [S1, unofficial]
- `sigma_t`: Total extinction coefficient. Typically hardcoded to `1.0`. [S1, unofficial]

**Edge Cases and Pitfalls**
- **Division by Zero**: The calculation `tau / (majorant * sigma_t)` is performed after checking `fabsf(majorant) <= float_epsilon`. If `majorant` is exactly zero but passes the epsilon check (or if epsilon is too large), division by zero occurs. The source code explicitly warns: `// can have division by zero error`. [S1, unofficial]
- **Epsilon Sensitivity**: The choice of `float_epsilon` for skipping empty cells must be small enough to avoid skipping cells with very low but non-zero density, but large enough to handle numerical noise.

## Operating characteristics
- **Time Complexity**: $O(N_{cells})$ in the worst case, where $N_{cells}$ is the number of macrocells intersected by the ray. However, empty cells are skipped in $O(1)$, making it efficient for sparse media.
- **Memory Complexity**: $O(1)$ additional memory per ray, assuming the macrocell grid is pre-computed and accessible.
- **Measured Performance**: Not given in the sources.
- **Scaling**: Scales linearly with the number of macrocells intersected. Performance improves with larger macrocells (fewer cells to traverse) but may lose precision in heterogeneous media.
- **Strengths**: Efficiently skips empty space; handles heterogeneous media via majorants; simple implementation.
- **Limitations**: Potential for division by zero; requires pre-computed majorants; may overshoot interactions if majorant is loose.
- **When to use**: Sparse or heterogeneous volumetric data where empty space skipping is beneficial.
- **When not to use**: Dense, homogeneous media where fixed-step marching might be simpler and faster.

## Background
This method is part of the Open Volume Renderer project by VIDILabs. It is an implementation detail within a larger modular volume rendering framework. The specific implementation is found in the `ovr/renderer_macro.h` and related source files. [S1, unofficial]
