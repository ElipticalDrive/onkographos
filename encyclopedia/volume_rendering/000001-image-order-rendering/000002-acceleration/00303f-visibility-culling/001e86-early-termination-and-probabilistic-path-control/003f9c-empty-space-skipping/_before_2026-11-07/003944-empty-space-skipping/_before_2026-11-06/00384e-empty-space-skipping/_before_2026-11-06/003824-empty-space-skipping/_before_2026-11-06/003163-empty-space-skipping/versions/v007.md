# Empty-space skipping

Also called: Block Empty Space Skipping, Chebyshev Empty Space Skipping, Empty Region Skipping, Occupancy Grid Pruning

## Overview
Empty-space skipping is a ray-marching acceleration technique that minimizes computation by skipping the sampling of empty space in a volumetric dataset [S2, unofficial][S4, unofficial][S10, unofficial]. It solves the problem of wasted computation where standard raycasting samples points at fixed intervals even in empty space [S2, unofficial]. It sets itself apart from its siblings by using an additional data structure (e.g., Oct-tree, Occupancy Grid, or Distance Map) encoding empty space to modulate sampling distance or jump over transparent regions [S1, unofficial][S4, unofficial]. Unlike [Early ray termination](1019-early-ray-termination.md) which stops based on accumulated opacity, or [Bounding Volume Culling](1239-bounding-volume-culling.md) which uses geometric hulls, empty-space skipping explicitly identifies and bypasses volumetric voids during traversal [S1, unofficial][S2, unofficial].

## How it works
**Inputs:** Ray origin $\mathbf{o}$, ray direction $\mathbf{d}$, volume dimensions $V_{dim}$, sampling factor $s_f$, empty-space data structure (Occupancy Map, Distance Map, or Octree), and transfer function.
**Outputs:** Final pixel color $C_{out}$ and opacity $\alpha_{out}$.

**Data Structures:**
1.  **Occupancy Map / Distance Map:** A 3D texture (or grid) storing precomputed values.
    *   *Block ESS:* Stores binary occupancy or block boundaries.
    *   *Chebyshev ESS:* Stores distance to the nearest non-empty voxel.
2.  **Brick Classification Table (Variant):** An array of 32-bit integers, one per brick, storing state: `0` (empty/skipped), `1` (saturated/early terminate), `2` (sample densely) [S11].

**Numbered Steps:**

1.  **Ray Initialization:**
    Calculate the step vector and number of steps for the full volume traversal to establish a baseline [S3, unofficial]:
    $$ n_{steps} = \lceil \frac{V_{dim, max} \cdot \| \mathbf{d} \| \cdot s_f}{1} \rceil $$
    $$ \mathbf{step\_vector} = \frac{\mathbf{d}}{\| \mathbf{d} \|} \cdot \frac{\| \mathbf{d} \|}{n_{steps} - 1} = \frac{\mathbf{d}}{n_{steps} - 1} $$
    *Note: If the ray is degenerate (infinite, NaN, or length $> \sqrt{3}$), terminate immediately [S3, unofficial].*

2.  **Empty-Space Query (ESS):**
    Determine the current sampling position $\mathbf{p}_{sample}$ along the ray. Map this position to the coordinates of the empty-space data structure [S3, unofficial]:
    $$ \mathbf{u} = \mathbf{p}_{sample} \cdot \frac{V_{dim}}{V_{dim} / \text{map\_dim}} $$
    Fetch the value $val$ from the map at index $\mathbf{u}_i = \lfloor \mathbf{u} \rfloor$ [S3, unofficial].

3.  **Calculate Skip Delta:**
    Based on the ESS variant (`essType`), calculate the number of steps to skip ($i_{delta}$) [S3, unofficial]:
    *   **Block ESS (`essType == 1`):** If the region is empty, jump to the next block boundary.
        $$ i_{delta} = \max(1, \lceil \min(\mathbf{i}_{delta\_xyz}) \rceil) $$
        Where $\mathbf{i}_{delta\_xyz}$ is derived from the block size and fractional offset $r$ [S3, unofficial].
    *   **Chebyshev ESS (`essType == 2`):** If distance $dist > 0$, jump by that distance.
        $$ i_{delta} = \max(1, \lceil \text{sign}(step\_dist\_texel\_inv) \cdot dist \cdot step\_dist\_texel\_inv \rceil) $$
    *   **Occupancy Grid (NerfAcc):** If $\alpha < \alpha_{thre}$ (e.g., $10^{-2}$), skip [S4, unofficial].

4.  **Update Index and Backtracking:**
    Update the loop index $i \leftarrow i + i_{delta}$. If the distance is 0 (empty space reached but no skip possible or backtracking needed), apply a backward step to ensure the ray re-enters the occupied region correctly, clamping to the minimum index $i_{min}$ [S3, unofficial]:
    $$ i_{delta\_backwards} = -\lceil s_f \rceil $$
    $$ i = \max(i + i_{delta\_backwards}, i_{min}) $$

5.  **Sampling and Compositing:**
    If the ray is in a non-empty region (or ESS is disabled):
    *   Sample volume intensity $V$ at $\mathbf{p}_{sample}$ [S3, unofficial].
    *   Lookup color/opacity $\mathbf{c}, \alpha$ from Transfer Function [S3, unofficial].
    *   Compute lighting (gradient, diffuse, specular) [S3, unofficial].
    *   Composite using front-to-back blending:
        $$ C_{acc} = C_{acc} + \mathbf{c} \cdot \alpha \cdot (1 - \alpha_{acc}) $$
        $$ \alpha_{acc} = \alpha_{acc} + \alpha \cdot (1 - \alpha_{acc}) $$

6.  **Early Termination:**
    If $\alpha_{acc} > 0.98$ (or predefined threshold), terminate the ray [S3, unofficial][S8, book].

**Pseudocode (Block/Chebyshev ESS Implementation):**

```python
def render_ray(ray_origin, ray_dir, volume_size, map_size, occupancy_map, distance_map, sampling_factor, ess_type):
    # 1. Initialize Ray Parameters
    ray_length = length(ray_dir)
    if ray_length == 0 or ray_length > sqrt(3):
        return (0.0, 0.0, 0.0, 0.0) # Degenerate ray

    n_steps = ceil(volume_size.max() * ray_length * sampling_factor)
    step_vector = normalize(ray_dir) * ray_length / (n_steps - 1)
    
    # Precompute mapping factors
    volume_to_map = volume_size / (map_size * 1.0) # Assuming map is normalized or scaled
    step_dist_texel = step_vector * volume_size / map_size
    step_dist_texel_inv = 1.0 / step_dist_texel
    
    # Dithering for anti-aliasing
    random_val = fract(sin(gl_frag_coord.x * 12.9898 + gl_frag_coord.y * 78.233) * 43758.5453)
    
    out_color = vec4(0.0)
    i = 0
    
    # Determine distance map index based on ray direction signs (for 6-face distance map)
    # Simplified: assuming single map or appropriate lookup
    dist_map_idx = 0 
    
    while i < n_steps:
        # 2. Calculate Sampling Position
        sampling_pos = ray_origin + (i + random_val) * step_vector
        
        # 3. Map to Texture Coordinates
        pos_map = sampling_pos * volume_to_map
        u = pos_map * map_size
        u_i = clamp(floor(u), ivec3(0), map_size - 1)
        
        # 4. Fetch Empty Space Data
        if ess_type == 1: # Block ESS
            dist = texelFetch(occupancy_map, u_i, 0).x
        else: # Chebyshev ESS
            dist = texelFetch(distance_map, u_i, 0).x
            
        # 5. Calculate Skip Delta
        r = clamp(u_i - u, -1.0, 0.0)
        
        if ess_type == 1:
            # Block ESS delta calculation
            i_delta_xyz = (step(0.0, step_dist_texel_inv) + r) * step_dist_texel_inv
        else:
            # Chebyshev ESS delta calculation
            i_delta_xyz = (step(0.0, -step_dist_texel_inv) + sign(step_dist_texel_inv) * float(dist) + r) * step_dist_texel_inv
            
        i_delta = max(1, int(ceil(min(min(i_delta_xyz.x, i_delta_xyz.y), i_delta_xyz.z))))
        
        # Handle backtracking if dist is 0 (empty but no forward skip possible)
        if dist == 0:
            i_delta_backwards = -int(ceil(sampling_factor))
            i = max(i + i_delta_backwards, 0)
            continue
            
        i += i_delta
        
        # 6. Sample Volume if not skipped
        # (In a real implementation, the loop index 'i' would be updated by i_delta 
        # and the sampling would happen at the NEW 'i' if the skip was applied, 
        # or at the current 'i' if no skip occurred. 
        # The logic above assumes 'i' is advanced by the skip amount to jump OVER empty space.)
        
        # Re-calculate position for the actual sample point after skip
        actual_pos = ray_origin + (i + random_val) * step_vector
        voxel_val = get_volume_value(actual_pos, volume_size)
        
        # Transfer Function
        color = texture(transfer_function, vec2(voxel_val)).rgba
        color.a = pow(color.a, gamma) if gamma_correction else color.a
        
        # Lighting (Simplified)
        normal = -get_gradient(actual_pos, volume_size, voxel_val)
        diffuse = max(0.0, dot(normal, light_dir))
        color.rgb = color.rgb * (1.0 + diffuse)
        
        # Composite
        color.rgb *= color.a
        out_color.rgb += (1.0 - out_color.a) * color.rgb
        out_color.a += color.a * (1.0 - out_color.a)
        
        # Early Ray Termination
        if out_color.a > 0.98:
            break
            
    return out_color
```

## Subtopics

### [Empty Space Skipping with Octree](1610-empty-space-skipping-with-octree.md)

Uses a simple voxel-based occupancy grid with a conservative density threshold to binarize density.

### [Transfer-Function Independent Empty-Space Skipping](5038-transfer-function-independent-empty-space-skipping.md)
Stores visibility information independent of the transfer function to avoid reconstruction on TF changes.

### [Homogeneity Acceleration](5754-homogeneity-acceleration.md)
Approximates uniform, non-empty regions instead of sampling them voxel-by-voxel.

### Brick Classification and Empty Space Skipping
Classifies bricks into three categories: skipped (empty), early termination (saturated), or sampled densely [S11]. Maintains a shared 32-bit integer array per brick on GPU and host [S11]. If a brick is empty, the renderer leaps over it. When the transfer function changes, metadata is recomputed in a background thread; until complete, unprocessed bricks are treated as 'missing' and filtered by the empty check [S11]. Performance: ~7.5 million bricks/sec for metadata updates [S11].

### Free Space Skipping
Skips points in known free space by checking coarse density grid $V^{(\text{density})}_{(c)}$ and fine density grid $V^{(\text{density})}_{(f)}$ [S12]. If activated alpha $< \tau^{(c)}$ ($10^{-3}$) or $\tau^{(f)}$ ($10^{-4}$), the point is ignored [S12]. Only queries view-dependent color if both thresholds are passed [S12]. Pitfall: Setting thresholds to 0 causes OOM or quality degradation [S12].

### SparseLeap
Optimizes both the number of samples and the number of look-ups into the empty-space skipping data structure [S5, unofficial]. It is agnostic of the underlying data structure (e.g., page-tables, octrees) and can be used in conjunction with them [S5, unofficial].

### TF-Adaptive Empty-Space Skip
Skips cells provably contributing zero opacity by checking if the cell's stored max deviation is below a cutoff derived from live contrast/trim uniforms [S13, unofficial]. Consults a max pyramid coarse-to-fine (level 1, then level 0) before full-res sampling [S13, unofficial]. Cutoff formula: $cutoff = deadband - 0.05$ [S13, unofficial]. Pitfall: In dense structures, the check adds overhead without skip payoff, causing performance regression [S13, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the data structure. Octrees require $O(\log N)$ lookups per ray segment but reduce sampling count significantly [S5, unofficial]. Occupancy grids provide $O(1)$ lookups but may have lower granularity [S4, unofficial].
*   **Memory Complexity:** Requires additional storage for the acceleration structure (Octree, Distance Map, or Occupancy Grid) [S1, unofficial][S6, unofficial]. NerfAcc's occupancy grid is cached and updated during training [S4, unofficial].
*   **Performance:** Provides 2.3x to 5x performance gain in some implementations [S10, unofficial]. NerfAcc can prune 98% of samples in dense scenes [S4, unofficial].
*   **Strengths:** Significantly reduces computation in sparse volumes; avoids memory bottlenecks by skipping empty regions [S7].
*   **Limitations:** Requires precomputation or runtime construction of the acceleration structure [S1, unofficial]. Performance can degrade if the volume is dense (e.g., cosmic-web structures) where skips are rare [S13, unofficial].
*   **When to use:** Non-opaque datasets with significant empty space [S1, unofficial]. Interactive applications requiring fast frame rates [S7].
*   **When not to use:** Fully opaque volumes or volumes where empty space is minimal [S1, unofficial].

## Background
Empty-space skipping was introduced as a fundamental optimization for volume rendering to address the high computational cost of sampling empty regions [S8, book]. Early methods used hierarchical representations like Octrees [S2, unofficial][S6, unofficial]. The technique has evolved to include GPU-based implementations using OpenCL [S2, unofficial], CUDA [S1, unofficial], and modern NeRF acceleration techniques like Occupancy Grids [S4, unofficial]. It is widely used in medical imaging, scientific visualization, and real-time rendering [S7].
