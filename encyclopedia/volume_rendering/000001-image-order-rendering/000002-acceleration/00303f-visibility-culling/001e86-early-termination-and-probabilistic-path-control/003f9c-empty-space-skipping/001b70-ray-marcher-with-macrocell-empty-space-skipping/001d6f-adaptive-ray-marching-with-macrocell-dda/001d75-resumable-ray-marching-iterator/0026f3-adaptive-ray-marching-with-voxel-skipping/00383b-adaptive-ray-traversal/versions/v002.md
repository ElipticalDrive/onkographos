# Adaptive Ray Traversal


## Overview
Adaptive ray traversal is a technique for traversing tree-based adaptive mesh refinement (TB-AMR) data that skips empty space and adapts the integration step size to the width of the leaf cell being sampled, thereby avoiding the over-sampling or under-sampling artifacts inherent in fixed-step rendering [S2]. It distinguishes itself from fixed-step methods by dynamically adjusting the sampling resolution to the local data granularity while using low-precision algorithms for rapid empty-space traversal and high-precision algorithms near data [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A TB-AMR volume (octree structure), a ray (origin and direction), and a transfer function.
*   **Output:** Computed sample values and accumulated opacity along the ray.

**Data Structures:**
*   **Octree Nodes:** Contain value ranges (min/max) used for opacity culling.
*   **Stack:** A software-maintained stack used for top-down traversal, storing node IDs and bitmask information for parallel corner queries [S2].
*   **Vicinity Flags:** A boolean flag assigned to empty voxels neighboring a data voxel [S1, unofficial].

**Steps:**
1.  **Preprocessing (Vicinity Flags):** Assign all empty voxels neighboring a data voxel a 'vicinity flag' [S1, unofficial].
2.  **Ray-Octree Traversal:** Traverse the octree top-down using a software-maintained stack [S2].
3.  **Culling:** For each node, query the maximum opacity over its value range using the preintegrated transfer function [S2].
    *   If the maximum opacity is 0, skip the node and its children [S2].
    *   Otherwise, proceed to sample [S2].
4.  **Adaptive Step Sizing:** Advance the ray to the next sample point, where the step size is equal to the width of the leaf cell currently being sampled [S2].
5.  **Interpolation (Dual Cell):** When interpolating within a non-boundary region, find the values of the eight corners of the dual cell [S2].
    *   Traverse all eight points at once using a bitmask to track which query points require traversal of each child node [S2].
    *   Store the bitmask and node ID in the stack [S2].
6.  **Boundary Handling:** When interpolating at a level boundary, find the corresponding leaf cells that enclose the virtual unstructured element using a `findLeafCell` traversal, which takes a query point and traverses it to the bottom of the tree [S2].
7.  **Sample Computation:** Compute samples for the ray interval using a user-selected reconstruction kernel (e.g., finest, octant, or GTI method) [S2].

**Pseudocode:**
```python
def adaptive_ray_traversal(ray, octree, transfer_function):
    # Stack stores (node_id, bitmask) for parallel corner traversal
    stack = []
    stack.append((octree.root_id, 0))
    
    accumulated_opacity = 0.0
    color = (0.0, 0.0, 0.0)
    
    # Current ray position and step size
    t = ray.origin
    step_size = 0.0
    
    while stack:
        node_id, bitmask = stack.pop()
        node = octree.get_node(node_id)
        
        # Culling: Check if node is fully transparent
        max_opacity = transfer_function.query_max_opacity(node.value_range)
        if max_opacity == 0:
            continue
            
        # Determine step size based on leaf cell width
        # If node is leaf, step_size = leaf_width
        # If node is internal, we may need to traverse deeper or use a heuristic
        # For this implementation, we assume we process leaves or subdivide
        if node.is_leaf:
            step_size = node.width
            # Compute sample at current t
            sample_value = compute_sample(ray, t, node, transfer_function)
            alpha = transfer_function.get_opacity(sample_value)
            
            # Front-to-back compositing
            color = color + (1.0 - accumulated_opacity) * alpha * sample_value
            accumulated_opacity = accumulated_opacity + (1.0 - accumulated_opacity) * alpha
            
            # Advance ray
            t = t + ray.direction * step_size
            
            # Check if ray is still in volume
            if not ray.intersects_volume(t):
                break
        else:
            # Internal node: push children to stack
            # In a full implementation, children are pushed in back-to-front order
            for child_id in node.children:
                stack.append((child_id, 0))
                
    return color, accumulated_opacity

def find_dual_cell_corners(ray, t, octree):
    """
    Finds the 8 corners of the dual cell for interpolation.
    Uses bitmask to track which children need traversal.
    """
    corners = []
    # Define the 8 corner offsets relative to the cell center
    corner_offsets = get_corner_offsets() 
    
    for i, offset in enumerate(corner_offsets):
        query_point = t + offset
        # Traverse octree to find leaf cell containing query_point
        leaf_cell = octree.find_leaf_cell(query_point)
        corners.append(leaf_cell)
        
    return corners
```

**Parameters:**
*   **Reconstruction Kernel:** User-selected method for computing sample values (e.g., finest, octant, GTI) [S2].
*   **Transfer Function:** Preintegrated transfer function supporting arbitrary 1D opacity configurations [S2].

**Edge Cases and Pitfalls:**
*   **Level Boundaries:** Interpolation at level boundaries requires finding corresponding leaf cells for virtual unstructured elements, which is more complex than non-boundary regions [S2].
*   **Precision:** Empty space traversal uses a low-precision algorithm for speed, switching to accurate algorithms only when vicinity voxels are encountered [S1, unofficial].

## Subtopics

### Proximity Clouds
An extension of adaptive ray traversal where the distance to the nearest data voxel is pre-computed for each empty voxel [S1, unofficial]. When a ray encounters a proximity voxel with value $n$, it skips the next $n$ voxels because there are no data voxels in between [S1, unofficial]. This allows for larger skips in empty regions compared to simple vicinity flags [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the depth of the octree and the density of data. Empty space skipping reduces the number of nodes visited. Adaptive step sizing reduces the number of samples in coarse regions.
*   **Memory Complexity:** Requires storage for the octree structure, vicinity flags (or proximity clouds), and the traversal stack.
*   **Strengths:** Avoids over-sampling in coarse regions and under-sampling in fine regions, which are artifacts of fixed-step rendering [S2]. Efficiently skips empty space [S1, unofficial].
*   **Limitations:** Requires preprocessing to assign vicinity flags or compute proximity clouds [S1, unofficial]. More complex traversal logic than fixed-step methods [S2].
*   **When to use:** TB-AMR data with significant variation in resolution and large empty regions [S2].
*   **When not to use:** Uniform grid data where fixed-step rendering is sufficient and simpler [S2].

## Background
Adaptive ray traversal was developed to address the limitations of fixed-step ray traversal in OSPRay 1.8, which could not dynamically adjust opacity when changing step size [S2]. The method was implemented in OSPRay 2.0 to support TB-AMR data [S2]. The concept of assigning vicinity flags to empty voxels and using low-precision traversal for empty space was introduced in earlier literature on direct volume rendering techniques [S1, unofficial]. Proximity clouds were proposed as an extension to further optimize empty space skipping [S1, unofficial].
