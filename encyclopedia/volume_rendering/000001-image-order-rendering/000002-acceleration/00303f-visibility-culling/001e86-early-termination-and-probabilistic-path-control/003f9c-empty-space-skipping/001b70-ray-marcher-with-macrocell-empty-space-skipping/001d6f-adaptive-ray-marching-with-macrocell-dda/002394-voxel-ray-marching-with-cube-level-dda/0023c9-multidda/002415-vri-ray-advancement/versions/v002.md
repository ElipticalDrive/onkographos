# VRI Ray Advancement

## Overview
VRI Ray Advancement advances a Volume Ray Intersection (VRI) state machine to the next leaf voxel intersection by managing a three-level hierarchical traversal of I2 nodes, I1 nodes, and leaf voxels using Digital Differential Analyzer (DDA) stepping [S1, unofficial]. It differs from its parent [MultiDDA](3123-multidda.md) by explicitly separating the traversal into three distinct phases: draining the current I1 DDA for leaf hits, stepping the I2 DDA to find the next active I1 child, and advancing to the next pre-sorted root entry when the hierarchy is exhausted [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A ray defined by origin $O$ and direction $D$; a pre-sorted list of root entries `state.roots`, where each entry is a tuple $(t_{min}, \text{I2\_node})$; and the current `state` containing DDA iterators and node references for I2 and I1 levels [S1, unofficial].
*   **Output:** A `LeafIntersection` object containing $t_{enter}$, $t_{exit}$, and the leaf voxel reference, along with the updated `state`; or `nothing` if no further intersections exist [S1, unofficial].

**Data Structures:**
*   **I2 Node:** Represents a coarse block. Contains a `children` array of I1 nodes and a `child_mask` bitmask [S1, unofficial].
*   **I1 Node:** Represents a $8^3$ voxel sub-grid (brick). Contains a `child_mask` and a `children` array of leaf voxels [S1, unofficial].
*   **Leaf Voxel:** The finest granularity [S1, unofficial].
*   **DDA State:** `state.i2_ndda`, `state.i1_ndda` store the current DDA iterators. `state.i2_node`, `state.i1_node` store the current node references. `state.root_idx` tracks the current root entry [S1, unofficial].

**Parameters:**
*   I1 brick size: $8^3$ voxels [S1, unofficial].
*   I2 node size: $128$ units (implied by $16 \times 8$) [S1, unofficial].
*   Root block size: $32$ units (implied by DDA init) [S1, unofficial].
*   Leaf voxel size: $1$ unit [S1, unofficial].

**Algorithm Steps:**
1.  **Phase 1: Drain Current I1 DDA for Leaf Hits.** While `state.i1_ndda` is not `nothing`, query `node_dda_query(ndda)` for `inside` and `child_idx`. If `!inside`, break. If `is_on(state.i1_node.child_mask, child_idx)`, calculate `idx = count_on_before(state.i1_node.child_mask, child_idx) + 1`. Get `leaf = state.i1_node.children[idx]`. Compute `bbox = BBox(o, Coord(o[1] + s - 1, o[2] + s - 1, o[3] + s - 1))` where `s = 8`. Intersect ray with `bbox`. If hit, return `(LeafIntersection(t_enter, t_exit, leaf), state)` and step DDA.
2.  **Phase 2: Step I2 DDA to Find Next I1 Child.** If Phase 1 drained, set `state.i1_ndda = nothing` and `state.i1_node = nothing`. While `state.i2_ndda` is not `nothing`, query `node_dda_query(ndda)`. If `inside` and `is_on(state.i2_node.child_mask, child_idx)`, get `i1_node = state.i2_node.children[idx]`. Compute `aabb` from `o` to `o + 128.0`. If ray intersects `aabb` at `tmin`, initialize `state.i1_ndda = node_dda_init(ray, tmin, o, 16, 8)`, set `state.i1_node = i1_node`, step DDA, set `found_i1 = true`, and break.
3.  **Phase 3: Advance to Next Pre-Sorted Root Entry.** If no I1 found, set `state.i2_ndda = nothing` and `state.i2_node = nothing`. Increment `state.root_idx`. If `state.root_idx > length(state.roots)`, return `nothing`. Otherwise, get `tmin, i2_node = state.roots[state.root_idx]`. Initialize `state.i2_ndda = node_dda_init(ray, tmin, o, 32, 128)` and set `state.i2_node = i2_node`. Loop back to Phase 1.

**Pseudocode:**
```python
def is_on(mask, idx):
    return (mask >> idx) & 1 == 1

def count_on_before(mask, idx):
    return bin(mask & ((1 << idx) - 1)).count('1')

def vri_advance(state, ray, roots):
    while True:
        # Phase 1: Drain current I1 DDA for leaf hits
        while state.i1_ndda is not None:
            inside, child_idx = node_dda_query(state.i1_ndda)
            if not inside:
                break
            if is_on(state.i1_node.child_mask, child_idx):
                idx = count_on_before(state.i1_node.child_mask, child_idx) + 1
                leaf = state.i1_node.children[idx]
                o = leaf.origin
                s = 8
                bbox = BBox(o, Coord(o[0] + s - 1, o[1] + s - 1, o[2] + s - 1))
                t_enter, t_exit = intersect_ray_bbox(ray, bbox)
                if t_enter is not None:
                    return LeafIntersection(t_enter, t_exit, leaf), state
                step_dda(state.i1_ndda)

        # Phase 2: Step I2 DDA to find next I1 child
        state.i1_ndda = None
        state.i1_node = None
        found_i1 = False
        while state.i2_ndda is not None:
            inside, child_idx = node_dda_query(state.i2_ndda)
            if inside and is_on(state.i2_node.child_mask, child_idx):
                i1_node = state.i2_node.children[child_idx]
                o = state.i2_node.origin
                aabb = BBox(o, Coord(o[0] + 128.0, o[1] + 128.0, o[2] + 128.0))
                t_min = intersect_ray_aabb(ray, aabb)
                if t_min is not None:
                    state.i1_ndda = node_dda_init(ray, t_min, o, 16, 8)
                    state.i1_node = i1_node
                    step_dda(state.i2_ndda)
                    found_i1 = True
                    break

        # Phase 3: Advance to next pre-sorted root entry
        if not found_i1:
            state.i2_ndda = None
            state.i2_node = None
            state.root_idx += 1
            if state.root_idx >= len(roots):
                return None, state
            t_min, i2_node = roots[state.root_idx]
            o = i2_node.origin
            state.i2_ndda = node_dda_init(ray, t_min, o, 32, 128)
            state.i2_node = i2_node
            # Loop back to Phase 1
```

**Edge Cases and Pitfalls:**
*   **Precision:** DDA stepping can suffer from floating-point precision errors at large distances. Use double precision for DDA coordinates if necessary [G].
*   **Boundaries:** Ensure `intersect_ray_bbox` and `intersect_ray_aabb` handle edge cases where the ray is parallel to a face or originates inside the volume [G].
*   **Degenerate Input:** If `roots` is empty, the method should immediately return `nothing` [G].
*   **Mask Handling:** `is_on` and `count_on_before` must correctly handle the bitmasks. `child_idx` is the linear index in the DDA, not the bit position [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of leaf voxels intersected, but with a significantly reduced constant factor due to skipping empty space at multiple levels. The hierarchical DDA allows skipping large empty regions in $O(1)$ per level hop [S1, unofficial].
*   **Memory Complexity:** $O(M)$ where $M$ is the size of the hierarchical grid (I2 and I1 nodes). The state machine uses minimal additional memory [S1, unofficial].
*   **Performance:** Designed for GPU execution (CUDA/JULIA KernelAbstractions) [S1, unofficial]. Outperforms flat DDA in sparse volumes [S1, unofficial].
*   **Strengths:** Efficient empty-space skipping; leverages pre-sorted root entries for coherent traversal [S1, unofficial].
*   **Limitations:** Requires a pre-built hierarchical grid; overhead of managing multiple DDA states [S1, unofficial].

## Background
VRI Ray Advancement is a traversal method implemented in the Lyr.jl codebase that advances a Volume Ray Intersection (VRI) state machine [S1, unofficial]. It is designed to compete with other high-performance volume rendering phases (C: device-cache, D: fused-spp, E: CuTexture) [S1, unofficial]. The method is used in the `gpu_render_volume` phase of the engine [S1, unofficial].
