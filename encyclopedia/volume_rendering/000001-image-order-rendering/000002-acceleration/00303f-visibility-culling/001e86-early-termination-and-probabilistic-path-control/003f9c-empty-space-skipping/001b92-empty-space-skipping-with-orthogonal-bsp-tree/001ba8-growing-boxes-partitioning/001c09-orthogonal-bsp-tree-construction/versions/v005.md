# Orthogonal BSP Tree Construction

Also called: BSP tree conversion, Orthogonal BSP

## Overview
Orthogonal BSP Tree Construction converts a set of arbitrarily sized and positioned grown boxes into an orthogonal Binary Space Partitioning (BSP) tree where every splitting plane is object-aligned [S1]. This structure enables trivial visibility sorting for 3D texture rendering, solving the problem that arbitrary box positions and cyclic orders from specific viewpoints prevent simple sorting [S1]. Unlike uniform partitioning which allows trivial sorting by default, this method explicitly organizes adaptive boxes into a strict hierarchical tree to guarantee correct draw order [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of grown boxes produced by the parent method [S1].
*   **Output:** An orthogonal BSP tree where leaf nodes contain exactly one box (either an original grown box or a child box generated from splitting) [S1]. Non-leaf nodes contain lists of boxes and a "room" (the bounding box of their union) [S1].

**Data Structures:**
*   **Box:** A 3D axis-aligned bounding box defined by `min` and `max` corner vectors. It may hold a `parent` pointer [S1].
*   **BSP Node:**
    *   `room`: A 3D axis-aligned bounding box representing the union of all boxes in this node's list [S1].
    *   `box_list`: A list of boxes associated with this node [S1].
    *   `front_child`: Pointer to the front child node [S1].
    *   `back_child`: Pointer to the back child node [S1].
    *   `type`: The classification of the enclosed voxels (uniform, gradient, or other) [S1].

**Algorithm Steps:**

1.  **Initialization:** Create a root BSP node [S1]. Set its `room` to the bounding box of the union of all input grown boxes [S1]. Add all input grown boxes to the root's `box_list` [S1].
2.  **Node Splitting:** Recursively split nodes until each leaf node contains exactly one box [S1].
    *   **2.1 Create Children:** Create two child nodes, `front` and `back` [S1].
    *   **2.2 Choose Partitioning Plane:** Select a splitting plane that coincides with the faces of at least two boxes in the current node's `box_list` [S1]. The selection criterion minimizes the number of boxes cut by the plane [S1].
    *   **2.3 Define Child Rooms:** Split the current node's `room` into two boxes using the chosen plane [S1]. Set these two boxes as the `room` for `front` and `back` respectively [S1].
    *   **2.4 Distribute Boxes:** Iterate through each box in the current node's `box_list`:
        *   If the box is completely enclosed in the `front` room, move it to `front.box_list` [S1].
        *   If the box is completely enclosed in the `back` room, move it to `back.box_list` [S1].
        *   If the box is cut by the plane:
            *   Create two new boxes by splitting the original box along the plane [S1].
            *   Place one new box in `front.box_list` and the other in `back.box_list` [S1].
            *   **Parent Hierarchy:** If the original box has no parent (it is an original grown box), set the original box as the `parent` of the two new boxes [S1]. If the original box has a parent, set the original box's `parent` as the `parent` of the two new boxes [S1].
            *   Delete the original box from the current node's list [S1].
    *   **2.5 Recurse:** Recursively apply splitting to `front` and `back` until leaf nodes contain exactly one box [S1].
3.  **Bottom-Up Merging:** Reduce the BSP tree size by merging child nodes where possible to keep the total number of boxes comparable to the original set [S1].
    *   **3.1 Merge Conditions:** Merge `front` and `back` children into a single node if *any* of the following conditions are true: (1) Both children contain uniform boxes, and the merged box (union of their rooms) is also uniform; (2) Both children contain "other" boxes or both contain "gradient" boxes; (3) One of the boxes is tiny or very thin (size along one axis is smaller than a threshold) [S1].
    *   **3.2 Merge Execution:** Create a new parent node [S1]. Set its `room` to the union of the `front` and `back` rooms [S1]. Combine the `box_list` from both children [S1]. If the children had different parent boxes, delete those parent boxes and set all their children (now in the new list) as parentless [S1]. Redetermine the type of the merged box based on the enclosed voxel properties [S1].
    *   **3.3 Recurse:** Apply merging bottom-up from the leaves to the root [S1].

**Pseudocode:**

```python
class Box:
    def __init__(self, min_c, max_c, parent=None):
        self.min = min_c
        self.max = max_c
        self.parent = parent

    def is_enclosed_in(self, room):
        return all(self.min[i] >= room.min[i] and self.max[i] <= room.max[i] for i in range(3))

    def is_cut_by(self, plane):
        axis, coord = plane
        return self.min[axis] < coord and self.max[axis] > coord

    def split(self, plane):
        axis, coord = plane
        b1 = Box(self.min, self.max, self.parent)
        b2 = Box(self.min, self.max, self.parent)
        b1.max[axis] = coord
        b2.min[axis] = coord
        return b1, b2

class BSPNode:
    def __init__(self, room=None, box_list=None):
        self.room = room
        self.box_list = box_list if box_list is not None else []
        self.front_child = None
        self.back_child = None
        self.type = None

    def split(self, plane):
        axis, coord = plane
        r1 = Box(self.room.min, (self.room.min[0], self.room.min[1], coord))
        r2 = Box((coord, coord, coord), self.room.max)
        return BSPNode(room=r1), BSPNode(room=r2)

def union_boxes(boxes):
    if not boxes: return None
    min_c = list(boxes[0].min)
    max_c = list(boxes[0].max)
    for b in boxes:
        for i in range(3):
            if b.min[i] < min_c[i]: min_c[i] = b.min[i]
            if b.max[i] > max_c[i]: max_c[i] = b.max[i]
    return Box(tuple(min_c), tuple(max_c))

def choose_optimal_plane(box_list, room):
    best_plane = None
    min_cuts = float('inf')
    for box in box_list:
        for axis in range(3):
            for coord in [box.min[axis], box.max[axis]]:
                cuts = sum(1 for b in box_list if b.min[axis] < coord and b.max[axis] > coord)
                if cuts < min_cuts:
                    min_cuts = cuts
                    best_plane = (axis, coord)
    return best_plane

def is_tiny_or_thin(box, threshold=1e-6):
    return any(box.max[i] - box.min[i] < threshold for i in range(3))

def split_node(node):
    if len(node.box_list) <= 1:
        return node

    front = BSPNode()
    back = BSPNode()

    plane = choose_optimal_plane(node.box_list, node.room)
    front.room, back.room = node.room.split(plane)

    for box in list(node.box_list):
        if box.is_enclosed_in(front.room):
            front.box_list.append(box)
        elif box.is_enclosed_in(back.room):
            back.box_list.append(box)
        elif box.is_cut_by(plane):
            box_front, box_back = box.split(plane)
            front.box_list.append(box_front)
            back.box_list.append(box_back)

            if box.parent is None:
                box_front.parent = box
                box_back.parent = box
            else:
                box_front.parent = box.parent
                box_back.parent = box.parent
            # Original box is removed from current node's list
        # Boxes outside the room are ignored

    node.box_list = []
    front = split_node(front)
    back = split_node(back)
    node.front_child = front
    node.back_child = back
    return node

def merge_nodes(front, back):
    # [G] Standard voxel property aggregation logic not specified in sources.
    cond1 = (front.type == 'uniform' and back.type == 'uniform')
    cond2 = (front.type in ('other', 'gradient') and back.type in ('other', 'gradient'))
    cond3 = is_tiny_or_thin(front.box_list[0]) or is_tiny_or_thin(back.box_list[0])

    if cond1 or cond2 or cond3:
        merged = BSPNode()
        merged.room = union_boxes([front.room, back.room])
        merged.box_list = front.box_list + back.box_list

        p1 = front.box_list[0].parent if front.box_list else None
        p2 = back.box_list[0].parent if back.box_list else None
        if p1 != p2:
            if p1 is not None:
                p1.parent = None
                for b in front.box_list: b.parent = None
            if p2 is not None:
                p2.parent = None
                for b in back.box_list: b.parent = None

        # [G] Type redetermination based on enclosed voxel properties not specified in sources.
        merged.type = 'uniform' # Placeholder for aggregation logic
        return merged
    return None

def merge_bottom_up(node):
    if node.front_child is None and node.back_child is None:
        return node

    node.front_child = merge_bottom_up(node.front_child)
    node.back_child = merge_bottom_up(node.back_child)

    merged = merge_nodes(node.front_child, node.back_child)
    return merged if merged is not None else node

def build_orthogonal_bsp(grown_boxes):
    root = BSPNode()
    root.room = union_boxes(grown_boxes)
    root.box_list = grown_boxes
    root = split_node(root)
    root = merge_bottom_up(root)
    return root
```

**Parameters:**
*   **Threshold for tiny/thin box:** Not given in the sources [S1].
*   **Partitioning Plane Selection Criterion:** Minimize the number of boxes cut by the plane [S1].

**Edge Cases and Pitfalls:**
*   **Hierarchy Constraint:** No box can be a child and a parent at the same time [S1]. There is only one level of parent-child hierarchy [S1]. Parent boxes reside on non-leaf nodes; rendering uses only leaf nodes [S1].
*   **Texture Sharing:** Child boxes share the texture of their parent with siblings to avoid replicating texels along boundaries, which would increase memory requirements [S1].
*   **Box Count:** The total number of boxes at leaf nodes after splitting can be significantly greater than the original grown boxes, necessitating the bottom-up merging step [S1].

## Subtopics

### [K-D Tree Hierarchy Construction](2300-k-d-tree-hierarchy-construction.md)
K-D Tree Hierarchy Construction is a spatial partitioning method that organizes polygons into a binary tree structure to enable efficient ray traversal and early termination in volume rendering. It solves the problem of explicitly clipping polygons against view frustums or traversal planes by associating each polygon with the smallest node region that completely contains it. Unlike its parent method, Orthogonal BSP Tree Construction, which uses object-aligned splitting planes, the K-D tree splits regions along axis-aligned hyperplanes, typically bisecting the space. This approach avoids subdividing polygons, ensuring they are stored only in leaf or internal nodes where they fit entirely, thereby simplifying the active polygon list during rendering.

## Operating characteristics
*   **Time Complexity:** Not given in the sources [S1].
*   **Memory Complexity:** Not given in the sources [S1].
*   **Strengths:** Enables trivial visibility sorting for 3D texture rendering by converting arbitrary grown boxes into an orthogonal BSP tree [S1]. Keeps the total number of boxes comparable to the original set through merging [S1].
*   **Limitations:** The splitting process can significantly increase the number of leaf boxes before merging [S1]. Requires careful handling of parent-child relationships and texture sharing to avoid memory bloat [S1].
*   **When to use:** When using grown boxes for volume rendering and trivial visibility sorting is required [S1].
*   **When not to use:** When the overhead of maintaining the BSP tree structure and handling texture sharing is prohibitive compared to other acceleration structures [S1].

## Background
Orthogonal BSP Tree Construction is part of the "Empty Space Skipping and Occlusion Clipping for Texture-based Volume Rendering" methodology [S1]. It addresses the issue that adaptive partitioning results in arbitrary box sizes and positions, which prevents trivial visibility sorting as seen in uniform partitioning [S1]. The method was introduced in the paper "Empty Space Skipping and Occlusion Clipping for Texture-based Volume Rendering" [S1].
