# Ray Marching with Dithering and Early Termination

Also called: Dithered Ray Marching with Early Termination

## Overview
This method performs volume rendering by marching rays through a volume dataset, applying dithering to the starting position to mitigate aliasing artifacts, and using early termination to skip empty space once accumulated opacity exceeds a threshold [S1, unofficial]. It distinguishes itself from standard ray marching by explicitly combining positional jitter (dithering) with a fixed-opacity cutoff, whereas siblings like [Empty-space skipping](1002-empty-space-skipping.md) rely on spatial data structures and [Early ray termination](1019-early-ray-termination.md) may use different termination criteria or no dithering.

## How it works
**Inputs:**
- Volume texture (`voltex`): 3D texture storing scalar density/intensity values.
- Transfer function texture (`tftex`): 1D or 2D texture mapping intensity to RGBA color.
- Normal matrix (`normalmatrix`): 3x3 matrix for transforming normals from object to world space.
- Camera parameters: `start` (ray origin), `end` (ray end point), `screen_width`, `screen_height`.
- Parameters: `nsamples` (number of steps), `SHADING_THRES` (0.10), `DELTA` (0.005), `shading_mode` (0, 1, or 2).

**Outputs:**
- Final pixel color `outcolor` (vec4).

**Data Structures:**
- `pos`: Current ray position (vec3).
- `delta`: Step vector (vec3).
- `color`: Sampled color from transfer function (vec4).
- `outcolor`: Accumulated color (vec4).
- `intensity`: Sampled density value (float).

**Steps:**
1.  **Initialization:**
    - Calculate normalized screen coordinates: `norm_coord = gl_FragCoord.st / vec2(screen_width, screen_height)`.
    - Determine ray direction: `direction = end - start`.
    - Calculate ray length: `len = length(direction)`.
    - Calculate step size: `stepsize = len / nsamples`.
    - Normalize direction: `direction = normalize(direction)`.
    - Calculate delta vector: `delta = direction * stepsize`.
    - Apply dithering to starting position to hide aliasing: `pos = start + delta * rand()`, where `rand()` is a random float in $[0, 1)$.
    - Initialize loop variables: `pos = start`, `outcolor = vec4(0.0)`, `color = vec4(0.0)`, `f_max_i = 0`.

2.  **Ray Marching Loop:**
    - Iterate `i` from 0 to `nsamples` while `len > 0`:
        - Increment position: `pos = pos + delta`.
        - Decrement remaining length: `len = len - stepsize`.
        - Sample volume intensity: `intensity = texture(voltex, pos).r`.
        - Map intensity to color via transfer function: `color = texture(tftex, intensity)`.

3.  **Shading (Conditional):**
    - If `color.a > SHADING_THRES` (0.10) AND `shading_mode != 3` AND `nsamples > 500`:
        - Compute normal using central difference: `N = gradient_central_diff(pos, DELTA)`.
        - Transform normal to world space and normalize: `N = normalize(vec3(normalmatrix * N))`.
        - Calculate light vector `L` and view vector `V` in world space.
        - Apply shading based on `shading_mode`:
            - Mode 0: Blinn-Phong.
            - Mode 1: Blinn-Phong + Edge Enhancement.
            - Mode 2: Toon shading.
        - [G] The specific shading equations are not provided in the source; assume standard implementations for the respective modes.

4.  **Compositing:**
    - Apply compositing based on `shading_mode`:
        - Mode 0: Front-to-Back compositing.
        - Mode 1: Maximum Intensity Projection (MIP).
        - Mode 2: Minimum Intensity Projection (MIDA).
    - For Front-to-Back (Mode 0):
        $$ C_{\text{acc}} = C_{\text{acc}} + C_{\text{sample}} \cdot \alpha_{\text{sample}} \cdot (1 - \alpha_{\text{acc}}) $$
        $$ \alpha_{\text{acc}} = \alpha_{\text{acc}} + \alpha_{\text{sample}} \cdot (1 - \alpha_{\text{acc}}) $$
        Where $C_{\text{acc}}$ and $\alpha_{\text{acc}}$ are components of `outcolor`.
    - For MIP (Mode 1): Update `outcolor` with maximum intensity encountered.
    - For MIDA (Mode 2): Update `outcolor` with minimum intensity encountered.

5.  **Early Termination:**
    - If `outcolor.a > 0.95`, break the loop.

## Subtopics

## Operating characteristics
- **Time Complexity:** $O(N)$ per pixel, where $N$ is `nsamples`. Early termination reduces the average number of steps, but worst-case remains $N$.
- **Memory Complexity:** $O(1)$ per ray (excluding texture storage).
- **Performance:** Dithering requires a random number generator per pixel. Early termination provides significant speedup in sparse volumes.
- **Strengths:** Simple to implement; dithering effectively reduces staircase aliasing from undersampling.
- **Limitations:** Dithering does not prevent aliasing from sharp transfer functions or shading discontinuities. Early termination is biased if not handled carefully (though the fixed threshold is a common heuristic).
- **When to use:** Real-time volume rendering where performance is critical and visual quality can tolerate some bias.
- **When not to use:** High-quality offline rendering requiring unbiased results or precise isosurface extraction.
