# Early Ray Termination with Binary Mask

Also called: Alpha-blending with binary skip

## Overview
Early Ray Termination with Binary Mask is an acceleration technique for alpha-blending volume rendering that combines front-to-back compositing with a binary mask to skip fully transparent regions [S1, unofficial]. It terminates the ray evaluation when the accumulated transmittance drops below a predefined threshold, thereby ignoring the ray tail [S1, unofficial]. It is distinguished from sibling methods by its use of a pre-computed binary mask to jump directly to opaque voxels, avoiding the evaluation of empty space entirely, whereas siblings like [Empty-space skipping](1002-empty-space-skipping.md) may rely on hierarchical structures or [Conservative Early Ray Termination](1949-conservative-early-ray-termination.md) may use different termination criteria.

## How it works
**Inputs:**
- Volume data `volume[z][y][x]` containing color and opacity for each voxel.
- Binary mask `mask[i][y][x]` where `i` indexes 32-voxel blocks along the Z-axis.
- Image coordinates `x`, `y`.
- Termination threshold `threshold` (transmittance value).

**Outputs:**
- Final pixel color `rgb`.

**Data Structures:**
- `volume`: Array of voxels. Each voxel `v` has fields `v.color` (RGB) and `v.opacity` (scalar).
- `mask`: 3D array of integers. `mask[i][y][x]` is a 32-bit integer where the $z$-th bit (0-indexed) is set if the voxel at $z = 32i + z$ has at least one opaque corner (is non-transparent).
- `Depth(segment)`: A helper function that returns the index of the least significant bit set to 1 in `segment`. If `segment` is 0, it returns 0 or indicates no bits remain.

**Parameters:**
- `threshold`: A pre-defined value for accumulated transparency. If `trans < threshold`, the ray evaluation terminates. Typical values are not specified in the source, but standard early termination thresholds (e.g., 0.95 or 1.0 for opacity, or corresponding low values for transmittance) are implied by the context of early ray termination [S1, unofficial].

**Algorithm Steps:**
1. Initialize `trans = 1.0` (accumulated transmittance) and `color = BLACK`.
2. Calculate `i_max = (Z + 31) / 32`, where `Z` is the total depth of the volume in voxels.
3. Loop `i` from `0` to `i_max - 1`:
    a. Retrieve `segment = mask[i][y][x]`.
    b. While `segment` is non-zero:
        i. Find the position of the next non-zero bit: `z = Depth(segment)`.
        ii. Calculate the absolute Z-coordinate: `z_abs = 32 * i + z`.
        iii. Retrieve the voxel: `v = volume[z_abs][y][x]`.
        iv. Update transmittance: `trans = trans * (1.0 - v.opacity)`.
        v. Check termination: If `trans < threshold`, return `color`.
        vi. Update color using front-to-back compositing: `color = color + v.color * v.opacity * trans`.
        vii. Remove the processed bit from the segment: `segment = segment & ~(0x80000000 >> z)`.
4. Return `color`.

**Pseudocode:**
```python
def alpha_blending_binary_mask(x: int, y: int, volume: List[Voxel], mask: List[List[int]], threshold: float) -> RGB:
    trans = 1.0
    color = RGB(0, 0, 0)
    Z = volume.depth  # Total depth in voxels
    i_max = (Z + 31) // 32
    
    for i in range(i_max):
        segment = mask[i][y][x]
        while segment != 0:
            # Find the index of the least significant bit set to 1
            z = depth_of_first_bit(segment)
            
            # Calculate absolute z-coordinate
            z_abs = 32 * i + z
            
            # Retrieve voxel data
            v = volume[z_abs][y][x]
            
            # Update accumulated transmittance
            trans *= (1.0 - v.opacity)
            
            # Early termination check
            if trans < threshold:
                return color
            
            # Front-to-back compositing
            color += v.color * v.opacity * trans
            
            # Clear the processed bit
            # 0x80000000 is 1 << 31. Shifting right by z gives a mask for bit z.
            # Inverting and ANDing clears the bit.
            segment &= ~(0x80000000 >> z)
            
    return color

def depth_of_first_bit(segment: int) -> int:
    """Returns the index of the least significant bit set to 1."""
    # Implementation depends on hardware/OS. 
    # In Python, this can be done via bit manipulation or log2.
    # For a pure Python implementation without builtins:
    if segment == 0:
        return 0
    z = 0
    while (segment & 1) == 0:
        segment >>= 1
        z += 1
    return z
```

**Edge Cases and Pitfalls:**
- **Precision:** Floating-point precision in `trans` accumulation may affect termination timing.
- **Boundary Conditions:** The calculation of `i_max` must correctly handle volumes where `Z` is not a multiple of 32. The mask should be padded or handled such that out-of-bounds accesses do not occur.
- **Degenerate Input:** If the mask is all zeros, the loop terminates immediately, returning black. If `threshold` is set too high (close to 1.0 for transmittance, i.e., low opacity threshold), premature termination may occur, causing visual artifacts.

## Operating characteristics
- **Time Complexity:** Proportional to the number of non-transparent voxels along the ray, up to the termination point. The binary mask allows skipping transparent voxels in $O(1)$ per 32-voxel block, reducing the number of memory accesses and compositing operations.
- **Memory Complexity:** Requires storage for the binary mask, which is $Z \times Y \times X / 32$ bits.
- **Performance:** Significantly faster than naive ray marching in sparse volumes. Performance gain depends on the sparsity of the volume and the threshold.
- **Strengths:** Efficiently skips empty space; simple implementation; low memory overhead for the mask.
- **Limitations:** Requires pre-computation of the binary mask; termination bias if threshold is not set carefully; not suitable for transparent surfaces where the tail contributes significantly to color.
- **When to use:** Sparse volumes with large empty regions; real-time rendering where performance is critical.
- **When not to use:** Dense volumes where most voxels are opaque; applications requiring unbiased results.
