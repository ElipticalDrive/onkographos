# Depth Map Rendering and Visualization

## Overview
This method renders a set of camera views from a trained dense point cloud, prunes points near the camera, and saves rendered images, depth maps, and colored depth maps [S1, unofficial]. It distinguishes itself by explicitly accumulating a near-camera mask across all views before rendering to prevent artifacts [S1, unofficial].

## How it works
**Inputs:**
- A trained Gaussian model (`gaussians`) containing 3D positions (`get_xyz`), opacities, and spherical harmonics coefficients [S1, unofficial].
- A list of camera viewpoints (`views`), each containing a `camera_center` position [S1, unofficial].
- A `near` distance threshold parameter [S1, unofficial].
- A background color tensor (`background`) [S1, unofficial].
- A rendering pipeline (`pipeline`) and renderer function (`render`) [S1, unofficial].

**Outputs:**
- Directory `render_path` containing:
  - `{idx:05d}.png`: Color image [S1, unofficial].
  - `depth_{idx:05d}.png`: Inverted normalized depth map [S1, unofficial].
  - `cdepth_{idx:05d}.png`: Colored depth map using the 'turbo' colormap [S1, unofficial].
- Video files for render, depth, and colored depth sequences [S1, unofficial].

**Data Structures:**
- `gaussians.get_xyz`: Tensor of shape $(N, 3)$ [S1, unofficial].
- `mask_near`: Boolean tensor of shape $(N, 1)$ accumulating points near any camera [S1, unofficial].

**Parameters:**
- `near`: Float distance threshold for pruning points near the camera [S1, unofficial].

**Steps:**
1. **Initialize Output Directory:** Create `render_path = os.path.join(model_path, name, "ours_{}".format(iteration))` [S1, unofficial].
2. **Prune Near-Camera Points:** Initialize `mask_near` as `None` [S1, unofficial]. For each view, compute `mask_temp = (gaussians.get_xyz - view.camera_center.repeat(gaussians.get_xyz.shape[0], 1)).norm(dim=1, keepdim=True) < near` [S1, unofficial]. Accumulate the mask: `mask_near = mask_near + mask_temp if mask_near is not None else mask_temp` [S1, unofficial]. Call `gaussians.prune_points_inference(mask_near)` to remove these points [S1, unofficial].
3. **Render Views:** For each view (indexed by `idx`), render with `torch.no_grad()`: `render_pkg = render(view, gaussians, pipeline, background, inference=True)` [S1, unofficial].
4. **Normalize and Compute Depth:** Extract `rendering = render_pkg["render"]` and compute `depth = (render_pkg['depth'] - render_pkg['depth'].min()) / (render_pkg['depth'].max() - render_pkg['depth'].min()) + 1 * (1 - render_pkg["alpha"])` [S1, unofficial].
5. **Save Color Image:** Save `rendering` as `{idx:05d}.png` [S1, unofficial].
6. **Save Inverted Depth Map:** Save `1 - depth` as `depth_{idx:05d}.png` [S1, unofficial].
7. **Generate Colored Depth Map:** Convert `depth` to NumPy: `depth_est = depth.squeeze().cpu().numpy()` [S1, unofficial]. Define `depth_curve_fn = lambda x: -np.log(x + np.finfo(np.float32).eps)` [S1, unofficial]. Apply colormap: `depth_est = visualize_cmap(depth_est, np.ones_like(depth_est), cm.get_cmap('turbo'), curve_fn=depth_curve_fn).copy()` [S1, unofficial]. Convert to tensor, permute to $(C, H, W)$, and save as `cdepth_{idx:05d}.png` [S1, unofficial].
8. **Create Videos:** Use `ffmpeg` to generate video outputs for render, depth, and colored depth images [S1, unofficial].

**Pseudocode:**
```python
import os
import numpy as np
import torch
import torchvision.utils
import matplotlib.cm as cm

def visualize_cmap(data, alpha, cmap, curve_fn):
    """Applies a curve function and colormap to depth data."""
    data = curve_fn(data)
    data_min, data_max = data.min(), data.max()
    if data_max - data_min > 0:
        data = (data - data_min) / (data_max - data_min)
    else:
        data = np.zeros_like(data)
    colored = cmap(data)
    return colored[..., :3]

def depth_map_rendering(gaussians, views, near, model_path, name, iteration, render_fn, pipeline, background):
    render_path = os.path.join(model_path, name, "ours_{}".format(iteration))
    os.makedirs(render_path, exist_ok=True)

    mask_near = None
    for view in views:
        cam_center = view.camera_center.unsqueeze(0)
        gaussians_xyz = gaussians.get_xyz
        diff = gaussians_xyz - cam_center.repeat(gaussians_xyz.shape[0], 1)
        dists = torch.norm(diff, dim=1, keepdim=True)
        mask_temp = dists < near
        if mask_near is None:
            mask_near = mask_temp
        else:
            mask_near = mask_near + mask_temp
    if mask_near is not None:
        gaussians.prune_points_inference(mask_near)

    for idx, view in enumerate(views):
        with torch.no_grad():
            render_pkg = render_fn(view, gaussians, pipeline, background, inference=True)

        rendering = render_pkg["render"]
        depth_raw = render_pkg['depth']
        alpha = render_pkg['alpha']

        d_min = depth_raw.min()
        d_max = depth_raw.max()
        depth_norm = (depth_raw - d_min) / (d_max - d_min) + 1 * (1 - alpha)

        torchvision.utils.save_image(rendering, os.path.join(render_path, '{0:05d}'.format(idx) + ".png"))

        depth_inv = 1 - depth_norm
        torchvision.utils.save_image(depth_inv, os.path.join(render_path, 'depth_{0:05d}'.format(idx) + ".png"))

        depth_est = depth_norm.squeeze().cpu().numpy()
        eps = np.finfo(np.float32).eps
        depth_curve_fn = lambda x: -np.log(x + eps)
        depth_est = visualize_cmap(depth_est, np.ones_like(depth_est), cm.get_cmap('turbo'), curve_fn=depth_curve_fn).copy()

        depth_est_tensor = torch.as_tensor(depth_est).permute(2, 0, 1)
        torchvision.utils.save_image(depth_est_tensor, os.path.join(render_path, 'cdepth_{0:05d}'.format(idx) + ".png"))

    # ffmpeg commands to create videos for render, depth, and cdepth sequences [S1, unofficial]
```

**Edge Cases and Pitfalls:**
- **Division by Zero:** If all depth values in a view are identical, `d_max - d_min` is zero. The source does not include a guard for this case [G].
- **Mask Accumulation:** The mask is accumulated across all views in the set, meaning a point is pruned if it is near any camera, not just the current one [S1, unofficial].
- **Depth Normalization:** The normalization is per-view, using the minimum and maximum depth values from `render_pkg['depth']` for that specific view [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Strengths:** Removes near-camera artifacts and generates standardized visualization outputs [S1, unofficial].
- **Limitations:** Pruning modifies the model state permanently for the inference run [S1, unofficial].
- **When to use:** Generating evaluation metrics, visualizations, or video sequences from a fixed Gaussian model [S1, unofficial].

## Background
This method originates from the DNGaussian repository and is part of the inference pipeline for 3D Gaussian Splatting variants [S1, unofficial]. It is used to produce clean depth maps and color images for downstream tasks such as novel view synthesis evaluation and video generation [S1, unofficial].
