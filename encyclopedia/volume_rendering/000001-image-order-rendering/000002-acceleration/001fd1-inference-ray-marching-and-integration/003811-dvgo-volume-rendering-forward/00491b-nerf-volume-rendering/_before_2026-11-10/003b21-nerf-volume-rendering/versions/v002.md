# NeRF Volume Rendering

Also called: NeRF Rendering Equation, Vanilla NeRF Volume Rendering, Volume Rendering from Voxel Grid

## Overview
This method renders pixel colors from a pre-computed radiance voxel grid using volume rendering techniques, specifically addressing the "one-to-many" warping holes found in forward warping approaches by utilizing an inpainted voxel grid [S1]. It differs from standard NeRF [NeRF Rendering (Alpha Compositing)](5124-nerf-rendering-alpha-compositing.md) by retrieving density and color features via trilinear interpolation from a 3D voxel grid rather than evaluating a neural network at query points [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A warped and inpainted radiance voxel grid $V^{Rt}_{Inp}$, a camera ray $r(w) = o + wd$ defined by origin $o$ and direction $d$, the number of sampled points $K$, and the sampling step size $\delta$ [S1].
*   **Output:** The final pixel color $\mathbf{C}(\mathbf{r})$ [S1].

**Data Structures:**
*   **Voxel Grid ($V^{Rt}_{Inp}$):** A 3D grid storing density $\sigma$ and color features $\mathbf{c_f}$ at each voxel, generated by an inpaint network (3D U-Net) that fills holes left by forward warping [S1].
*   **Ray Samples:** A sequence of $K$ points $w_k$ along the ray [S1].

**Steps:**
1.  **Ray Intersection and Sampling:** Determine the intersection of ray $r$ with the voxel grid bounds or use a fixed step size to generate points [G]. Sample $K$ points $w_k$ along the ray segment within the grid. Calculate $\delta_k$, the distance between adjacent samples $w_k$ and $w_{k+1}$ [S1].
2.  **Trilinear Interpolation:** For each sample point $w_k$, retrieve the density $\sigma(w_k)$ and color feature $\mathbf{c_f}(w_k)$ from $V^{Rt}_{Inp}$ using trilinear interpolation [S1]:
    $$ (\sigma, \mathbf {c_f}) = F_{\text {inter}}(V^{Rt}_{Inp}, w_k) $$
3.  **Color Computation:** Compute the view-dependent color $\mathbf{c}(w_k)$ from $\mathbf{c_f}(w_k)$ and ray direction $\mathbf{d}$ [S1]:
    $$ \mathbf {c} = \begin {cases} \mathbf {c_f} & \text {if } \mathbf {c_f} \in \mathbb {R}^3,\\ \ViewNet (\mathbf {c_f}, \mathbf {d}) & \text {otherwise}, \end {cases} $$
    where $\ViewNet$ is a small MLP network [S1].
4.  **Alpha Compositing:** Compute the accumulated transmittance $T(w_k)$ and the final color $\mathbf{C}(\mathbf{r})$ using the volume rendering equation [S1]:
    $$ \mathbf {C}(\mathbf {r}) = \sum \nolimits _{k=1}^{K} T(w_k) \, (1 - \exp(-\sigma (w_k) \delta _{k})) \, \mathbf {c}(w_k) $$
    $$ T(w_k) = \exp \left (-\sum \nolimits _{j=1}^{k-1} \sigma (w_{j}) \delta _{j} \right ) $$
    Here, $\alpha (\sigma(w_k )\delta_k ) = 1 - \exp(-\sigma(w_k )\delta_k )$ represents the opacity of the $k$-th segment [S1].

**Parameters:**
*   $K$: Number of sampled points along the ray [S1].
*   $\delta_k$: Distance between adjacent samples along the ray [S1].

**Pseudocode:**
```python
import math

def render_voxel_grid(ray_origin, ray_direction, voxel_grid, K, step):
    """
    Renders a pixel color from a radiance voxel grid.
    
    Args:
        ray_origin: 3D vector (o)
        ray_direction: 3D vector (d), normalized
        voxel_grid: Object providing trilinear interpolation for (sigma, c_f)
        K: Integer, number of samples
        step: Float, distance between adjacent samples (delta_k)
        
    Returns:
        color: 3D vector (RGB)
    """
    # 1. Sample points along the ray using fixed step size
    points = [ray_origin + i * step * ray_direction for i in range(K)]
    delta = step

    # 2. Sample density and color features
    samples = []
    for p in points:
        sigma, c_f = voxel_grid.trilinear_interpolate(p)
        samples.append((sigma, c_f))

    # 3. Compute view-dependent colors
    colors = []
    for sigma, c_f in samples:
        if len(c_f) == 3:
            c = c_f
        else:
            # [G] Simple linear projection for view-dependent color if c_f is not RGB
            c = [sum(c_f[j] * 0.33 for j in range(len(c_f))) for _ in range(3)]
        colors.append(c)

    # 4. Volume Rendering (Alpha Compositing)
    color_accum = [0.0, 0.0, 0.0]
    transmittance = 1.0

    for k in range(K):
        sigma = samples[k][0]
        c = colors[k]

        # Alpha for this segment
        alpha = 1.0 - math.exp(-sigma * delta)
        alpha = max(0.0, min(1.0, alpha))

        # Contribution
        for i in range(3):
            color_accum[i] += transmittance * alpha * c[i]

        # Update transmittance for next sample
        transmittance *= (1.0 - alpha)

        # Early termination optimization
        if transmittance < 1e-4:
            break

    return color_accum
```

**Edge Cases and Pitfalls:**
*   **Voxel Grid Holes:** The method assumes the input voxel grid $V^{Rt}_{Inp}$ has been inpainted to resolve "one-to-many" warping holes [S1]. Rendering on an un-inpainted grid may produce artifacts.
*   **Grid Bounds:** The exact near/far intersection distances for the voxel grid are not specified in the sources; implementers must compute ray-AABB intersection or use a fixed sampling range [G].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of samples $K$ per ray, as it requires $K$ trilinear interpolations and a summation [S1].
*   **Memory Complexity:** Dominated by the storage of the 3D voxel grid $V^{Rt}_{Inp}$ [S1].
*   **Strengths:** Efficient rendering via hardware-accelerated trilinear interpolation compared to MLP evaluation; handles dynamic scenes by warping and inpainting [S1].
*   **Limitations:** Resolution is limited by the voxel grid size; requires pre-computation of the warped and inpainted grid [S1].
*   **When to use:** Novel view synthesis for dynamic scenes where forward warping is used, requiring efficient rendering from a voxel representation [S1].

## Background
This method is described in the context of "Forward Flow for Novel View Synthesis of Dynamic Scenes" [S1]. It addresses issues with forward warping, such as holes in the voxel grid, by proposing an inpaint network (3D U-Net) to fill these holes before rendering [S1]. The volume rendering equation itself is a standard technique in computer graphics, adapted here for voxel-based radiance fields [S1].
