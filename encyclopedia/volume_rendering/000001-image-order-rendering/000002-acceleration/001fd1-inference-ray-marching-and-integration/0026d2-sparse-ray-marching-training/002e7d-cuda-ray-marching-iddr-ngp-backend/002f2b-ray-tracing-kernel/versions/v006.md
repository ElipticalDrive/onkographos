# Ray Tracing Kernel


## Overview
The Ray Tracing Kernel is a CUDA compute kernel that performs forward and backward volumetric rendering through a sparse hashed density grid using spherical harmonics (SH) for color representation [S1, unofficial][S2, unofficial]. It serves as the core inference and training step for the IDDR-NGP backend, computing final pixel colors and log-transmittance in the forward pass, and gradients for SH coefficients and grid outputs in the backward pass [S1, unofficial][S2, unofficial]. It differs from standard uniform ray marching by utilizing a sparse grid structure with specific boundary handling and SH evaluation, and from dense voxel cone tracing by operating on a hashed grid with adaptive step sizing logic managed by the parent CUDA Ray Marching kernel [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Forward:** Ray origins, directions, grid density data, grid SH data, ray bounds, and options (step size, thresholds). Outputs: pixel color, log-transmittance.
*   **Backward:** Gradients of output color, color cache, log-transmittance, beta-loss, sparsity-loss, and grid parameters. Outputs: gradients for SH coefficients and grid density.

**Data Structures:**
*   `ray_spec`: Array of `SingleRaySpec` structs stored in shared memory. Size: `TRACE_RAY_CUDA_RAYS_PER_BLOCK`. Fields: `origin` (float3), `dir` (float3), `tmin`, `tmax` [S1, unofficial][S2, unofficial].
*   `sphfunc_val`: 2D float array `[TRACE_RAY_CUDA_RAYS_PER_BLOCK][9]` storing SH function values for the current block [S1, unofficial][S2, unofficial].
*   `grad_sphfunc_val`: 2D float array `[TRACE_RAY_CUDA_RAYS_PER_BLOCK][9]` storing SH gradient values [S1, unofficial].
*   `temp_storage`: Array of `WarpReducef::TempStorage` structs, size `TRACE_RAY_CUDA_RAYS_PER_BLOCK`, for warp-level reductions [S1, unofficial].
*   `grid`: Contains `density_data`, `sh_data`, `stride_x`, `size` (dimensions), `sh_data_dim`, `basis_dim`, `background_nlayers`, `background_brightness` [S1, unofficial].

**Parameters:**
*   `TRACE_RAY_CUDA_RAYS_PER_BLOCK`: Number of rays processed per CUDA block [S1, unofficial].
*   `TRACE_RAY_BKWD_CUDA_THREADS`: Threads per block for backward kernel [S1, unofficial].
*   `opt.sigma_thresh`: Density threshold for sampling [S1, unofficial].
*   `opt.stop_thresh`: Log-transmittance threshold for early termination [S1, unofficial].
*   `opt.last_sample_opaque`: Boolean flag for final sample handling [S1, unofficial].
*   `opt.step_size`: Step size for ray advancement [S1, unofficial].
*   Warp size: 32 threads. `lane_id = threadIdx.x & 0x1F` [S2, unofficial].

**Algorithm (Forward):**
1.  **Initialization:**
    *   Calculate `ray_blk_id = threadIdx.x >> 5` and `lane_id = threadIdx.x & 0x1F` [S1, unofficial].
    *   If `lane_id >= grid.sh_data_dim`, return early [S1, unofficial][S2, unofficial].
    *   Load ray origin and direction into `ray_spec[ray_blk_id]` [S1, unofficial].
    *   Compute SH function values `calc_sphfunc` for the ray direction, storing in `sphfunc_val[ray_blk_id]` [S1, unofficial].
    *   Synchronize warps: `__syncwarp((1U << grid.sh_data_dim) - 1)` [S1, unofficial][S2, unofficial].
    *   Find ray bounds within the grid using `ray_find_bounds` [S1, unofficial][S2, unofficial].

2.  **Ray Marching Loop:**
    *   Initialize `log_transmit = 0.0f`, `outv = 0.0f` [S1, unofficial].
    *   While `t < ray.tmax`:
        *   Compute position: `ray.pos[j] = fmaf(t, ray.dir[j], ray.origin[j])` [S1, unofficial].
        *   Clamp position to `[0, grid.size[j]-1]` [S1, unofficial].
        *   Compute lattice index: `l[j] = min(floor(pos[j]), size[j]-2)` [S1, unofficial].
        *   Compute fractional position: `pos[j] -= l[j]` [S1, unofficial].
        *   Interpolate density `sigma` from `grid.density_data` using `trilerp_cuvol_one` [S1, unofficial].
        *   If `opt.last_sample_opaque` is true and `t + opt.step_size > ray.tmax`, set `ray.world_step = 1e9` [S1, unofficial].
        *   If `sigma > opt.sigma_thresh`:
            *   Interpolate SH color value from `grid.sh_data` using `trilerp_cuvol_one` [S1, unofficial].
            *   Multiply by `sphfunc_val` to get `lane_color` [S1, unofficial].
        *   Compute weight: `pcnt = ray.world_step * sigma` [S1, unofficial].
        *   `weight = exp(log_transmit) * (1 - exp(-pcnt))` [S1, unofficial].
        *   Update `log_transmit -= pcnt` [S1, unofficial].
        *   Accumulate color: `outv += weight * max(lane_color_total + 0.5f, 0.f)` [S1, unofficial].
        *   If `exp(log_transmit) < opt.stop_thresh`, set `log_transmit = -1e3f` and break [S1, unofficial].
        *   Advance `t += opt.step_size` [S1, unofficial].

3.  **Post-Processing:**
    *   If `grid.background_nlayers == 0`, add background: `outv += exp(log_transmit) * opt.background_brightness` [S1, unofficial].
    *   Reduce `lane_color` across the warp using `WarpReducef::HeadSegmentedSum` with mask `lane_colorgrp_id == 0` to get `lane_color_total` [S1, unofficial].
    *   If `lane_colorgrp_id == 0`, write `out[lane_colorgrp] = outv` and `*out_log_transmit = log_transmit` if output buffer is provided [S1, unofficial].

**Algorithm (Backward):**
1.  **Initialization:**
    *   Calculate indices and check `lane_id` bounds as in forward [S1, unofficial].
    *   Initialize gradient SH values to 0.0f for `lane_id < grid.basis_dim` [S1, unofficial].
    *   Compute SH function values for backward pass [S1, unofficial].
    *   Find ray bounds (only by lane 0 to avoid redundancy) [S1, unofficial].
    *   Synchronize warps [S1, unofficial].

2.  **Gradient Calculation:**
    *   Calculate gradient output:
        *   If `grad_out_is_rgb` is true: `resid = color_cache - grad_output`, `grad_out[i] = resid * norm_factor` where `norm_factor = 2.f / (3 * Q)` [S1, unofficial].
        *   Else: `grad_out[i] = grad_output[i]` [S1, unofficial].
    *   Call `trace_ray_cuvol_backward` with `grad_out`, `color_cache`, `log_transmit_in`, `beta_loss`, `sparsity_loss`, `grads`, etc. [S1, unofficial].
    *   Compute SH gradients using `calc_sphfunc_backward` [S1, unofficial].

**Pseudocode (Forward):**

```python
# Pseudocode for render_ray_kernel forward pass
# Assumes shared memory arrays: ray_spec, sphfunc_val, temp_storage
# Assumes global memory: grid, rays, out, out_log_transmit

def render_ray_kernel_forward(rays, grid, out, out_log_transmit, opt):
    # Thread indices
    ray_blk_id = threadIdx.x >> 5
    lane_id = threadIdx.x & 0x1F
    
    # Early exit if lane exceeds SH data dimension
    if lane_id >= grid.sh_data_dim:
        return

    # Initialize ray spec
    ray_spec[ray_blk_id].origin = rays[ray_id].origin
    ray_spec[ray_blk_id].dir = rays[ray_id].dir
    
    # Compute SH function values
    calc_sphfunc(grid, lane_id, ray_id, ray_spec[ray_blk_id].dir, sphfunc_val[ray_blk_id])
    
    # Synchronize shared memory writes
    __syncwarp((1 << grid.sh_data_dim) - 1)
    
    # Find ray bounds
    ray_find_bounds(ray_spec[ray_blk_id], grid, opt, ray_id)
    
    # Initialize accumulators
    log_transmit = 0.0f
    outv = 0.0f
    t = ray_spec[ray_blk_id].tmin
    
    while t < ray_spec[ray_blk_id].tmax:
        # Compute position
        pos = fmaf(t, ray_spec[ray_blk_id].dir, ray_spec[ray_blk_id].origin)
        
        # Clamp and compute lattice index
        for j in 0..2:
            pos[j] = clamp(pos[j], 0.0f, grid.size[j] - 1.0f)
            l[j] = min(floor(pos[j]), grid.size[j] - 2)
            pos[j] -= l[j]
            
        # Interpolate density
        sigma = trilerp_cuvol_one(grid.links, grid.density_data, grid.stride_x, grid.size[2], 1, l, pos, 0)
        
        # Handle last sample opaque condition
        if opt.last_sample_opaque and (t + opt.step_size > ray_spec[ray_blk_id].tmax):
            ray_spec[ray_blk_id].world_step = 1e9
        else:
            ray_spec[ray_blk_id].world_step = opt.step_size
            
        # Interpolate SH color if density is significant
        lane_color = 0.0f
        if sigma > opt.sigma_thresh:
            sh_color = trilerp_cuvol_one(grid.links, grid.sh_data, grid.stride_x, grid.size[2], grid.sh_data_dim, l, pos, lane_id)
            lane_color = sh_color * sphfunc_val[ray_blk_id][lane_id]
            
        # Reduce lane color across warp group
        # Note: WarpReducef::HeadSegmentedSum is a warp-level primitive
        lane_color_total = warp_reduce_sum(lane_color, mask=(lane_colorgrp_id == 0))
        
        # Compute weight and update log_transmit
        pcnt = ray_spec[ray_blk_id].world_step * sigma
        weight = exp(log_transmit) * (1.0f - exp(-pcnt))
        log_transmit -= pcnt
        
        # Accumulate color
        outv += weight * max(lane_color_total + 0.5f, 0.0f)
        
        # Early termination
        if exp(log_transmit) < opt.stop_thresh:
            log_transmit = -1e3f
            break
            
        t += opt.step_size
        
    # Add background if no background layers
    if grid.background_nlayers == 0:
        outv += exp(log_transmit) * opt.background_brightness
        
    # Write output
    if lane_colorgrp_id == 0:
        out[lane_colorgrp] = outv
        if out_log_transmit is not None:
            out_log_transmit[lane_colorgrp] = log_transmit
```

## Subtopics

### [TracingKernel](13916-tracingkernel.md)
A CUDA compute shader variant that performs volumetric light transport with dynamic step size and cascade resolution adjustment based on distance from the center. It is chosen when logarithmic expansion factors are needed for sparse grid optimization, differing from the standard Ray Tracing Kernel by its specific adaptive sampling strategy.

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of samples along the ray, which depends on ray length and step size. Warp-level reductions add logarithmic overhead relative to warp size (32).
*   **Memory Complexity:** Shared memory usage is proportional to `TRACE_RAY_CUDA_RAYS_PER_BLOCK` for `ray_spec`, `sphfunc_val`, and `temp_storage`. Global memory access is coalesced for ray data but may be uncoalesced for sparse grid lookups depending on hash distribution.
*   **Performance:** Optimized for GPU execution via warp-level primitives and shared memory for SH evaluation. Performance scales with the number of rays per block and the sparsity of the grid.
*   **Strengths:** Efficient handling of sparse volumes, support for SH color representation, and integrated backward pass for training.
*   **Limitations:** Performance may degrade if the grid is dense or if rays traverse many empty voxels without early termination. Precision issues may arise with very small or large `log_transmit` values.
*   **When to use:** For training and inference of neural radiance fields using sparse hashed grids with SH color.
*   **When not to use:** For dense voxel grids where cone tracing might be more efficient, or for scenes without SH color requirements.

## Background
The Ray Tracing Kernel is part of the NeRF-Factory project by POSTECH, KAIST, and Kakao Brain Corp., released in 2022 [S1, unofficial]. It is designed to work with the IDDR-NGP backend, which uses a sparse hashed density grid for efficient volumetric rendering. The kernel supports both forward rendering for image generation and backward rendering for gradient computation, enabling end-to-end training of neural radiance fields [S1, unofficial][S2, unofficial].
