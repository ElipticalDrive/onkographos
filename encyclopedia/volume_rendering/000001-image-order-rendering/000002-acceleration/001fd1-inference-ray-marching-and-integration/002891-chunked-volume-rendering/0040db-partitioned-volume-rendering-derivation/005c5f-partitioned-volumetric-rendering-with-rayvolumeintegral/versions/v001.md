# Partitioned Volumetric Rendering with RayVolumeIntegral

Also called: Partitioned Volumetric Rendering

## Overview
Partitioned Volumetric Rendering with RayVolumeIntegral performs volumetric rendering over a partition of possible $t$ values in the union of rendering volumes, combining results from disjoint volume integrals and a void model for empty space [S1, unofficial]. It sets itself apart from standard single-volume ray marching by explicitly handling multiple disjoint volume bounds and accumulating transmittance across partitions, ensuring correct alpha compositing when rays traverse empty space between volumes [S1, unofficial].

## How it works

### Inputs and Outputs
*   **Inputs**:
    *   `rays`: Origin and direction vectors for each pixel.
    *   `results_i`: A sequence of `RayVolumeIntegralResults` objects, each containing `volume_range` (start/end $t$), `raw` (raw network outputs like density/color), and `transmittance`.
    *   `void_model`: A function or model that queries background color/transmittance for empty space.
    *   `origin`, `direc`: Ray origins and directions.
    *   `importance_sampling_options`: Configuration for the sampler.
*   **Outputs**:
    *   `results`: A combined `RayVolumeIntegralResults` object containing the final rendered channels and transmittance.

### Data Structures

**RayVolumeIntegral**
A dataclass holding the rendering configuration [S1, unofficial]:
*   `model`: `NeRFModel` instance.
*   `volume`: `Volume` instance.
*   `sampler`: `RaySampler` instance.
*   `n_samples`: Integer, number of samples per ray segment.

**RayVolumeIntegralResults**
Holds the state of integration for a specific volume partition [S1, unofficial]:
*   `volume_range`: Defines the $t$ interval $[t_0, t_1]$.
*   `raw`: Raw outputs from the neural network (density, color, etc.).
*   `transmittance`: Scalar or tensor representing transmittance at the end of the interval.
*   `output`: Rendered channels (e.g., RGB).

### Algorithm Steps

1.  **Initialization**: Initialize `origin`, `direc` from `rays`. Set `prev_raw_outputs` to a list of `None`s. Initialize `samplers` list, `raw_outputs` list, `t0` to `None`, and `results` to `None` [S1, unofficial].
2.  **Loop over Volume Partitions**: For each `results_i` in the sequence of volume results:
    a.  **Sampler Creation**: Create an `ImportanceRaySampler` using `results_i.volume_range`, `results_i.raw`, and `importance_sampling_options`. Append this sampler to `samplers` [S1, unofficial].
    b.  **Raw Output Storage**: Append `results_i.raw` to `raw_outputs` [S1, unofficial].
    c.  **Update Start Time**: Update `t0` to `results_i.volume_range.next_t0()` [S1, unofficial].
    d.  **Combine Results**: If `results` is `None`, set `results = results_i`. Otherwise, update `results` by combining it with `results_i` using the partitioned combination rule [S1, unofficial].
3.  **Void Background Addition**: After the loop, add the void background to the final result:
    $$ \text{results.output.channels} = \text{results.output.channels} + \text{results.transmittance} \cdot \text{void\_model}(\text{Query}(origin, direc)) $$
    [S1, unofficial].

### RayVolumeIntegral.render_rays

This method handles the sampling and integration for a single volume partition defined by `self.volume`.

1.  **Intersection and Sampling**:
    *   Intersect rays with the volume: `vrange = self.volume.intersect(origin, direction, t0_lower=t0)` [S1, unofficial].
    *   Sample $t$ values: `ts = self.sampler.sample(vrange.t0, vrange.t1, self.n_samples)` [S1, unofficial].
2.  **Position and Interval Calculation**:
    *   Compute sample positions: `positions = origin.unsqueeze(-2) + ts * directions` [S1, unofficial].
    *   Compute midpoints: `mids = (ts[..., 1:, :] + ts[..., :-1, :]) / 2` [S1, unofficial].
3.  **Model Query**:
    *   Query the neural network model with positions, optional directions, and interval bounds:
        ```python
        t_min = torch.cat([vrange.t0[..., None, :], mids], dim=-2)
        t_max = torch.cat([mids, vrange.t1[..., None, :]], dim=-2)
        raw = Query(position=positions, direction=optional_directions, t_min=t_min, t_max=t_max)
        ```
        [S1, unofficial].
4.  **Integration**:
    *   Call `self.integrate_samples(vrange, raw)` to obtain `output` and `transmittance` [S1, unofficial].
5.  **Masking Non-Intersected Rays**:
    *   Mask transmittance: `transmittance = torch.where(vrange.intersected, transmittance, torch.ones_like(transmittance))` [S1, unofficial].
    *   Mask output tensors: `output = output.map(map_fn=_mask_fn, should_map=_is_tensor)` where `_mask_fn` returns `torch.where(vrange.intersected, tensor, torch.zeros_like(tensor))` [S1, unofficial].

### RayVolumeIntegral.integrate_samples

This method computes the discrete volume integral approximation.

1.  **Density and Transmittance Calculation**:
    *   Calculate interval lengths: `dt = volume_range.partition(raw.ts)` [S1, unofficial].
    *   Compute optical depth increments: `ddensity = raw.density * dt` [S1, unofficial].
    *   Compute cumulative optical depth: `mass = torch.cumsum(ddensity, dim=-2)` [S1, unofficial].
    *   Compute final transmittance: `transmittance = torch.exp(-mass[..., -1, :])` [S1, unofficial].
    *   Compute per-sample alphas: `alphas = 1.0 - torch.exp(-ddensity)` [S1, unofficial].
    *   Compute per-sample transmittances $T_s$:
        $$ T_s = \exp\left(\text{cat}([0, -\text{mass}[..., :-1, :]], \text{dim}=-2)\right) $$
        [S1, unofficial].
    *   Compute weights: `weights = alphas * Ts` [S1, unofficial].
2.  **Weighted Summation**:
    *   Integrate using `_integrate(key, samples, weights)` which returns `torch.sum(samples * weights, dim=-2)` for keys other than 'density' [S1, unofficial].
    *   Handle auxiliary losses with detached weights if `no_weight_grad_aux_losses` is enabled: use `weights.detach()` [S1, unofficial].

### Combination Rule

When combining results from disjoint volume partitions $[t_0, t_1]$ and $[t_1, t_2]$, the integral over $[t_0, t_2]$ is the sum of the integral over $[t_0, t_1]$ and the transmittance at $t_1$ times the integral over $[t_1, t_2]$ [S1, unofficial]:

$$ \int_{t_0}^{t_2} = \int_{t_0}^{t_1} + \text{transmittance}(t_1) \cdot \int_{t_1}^{t_2} $$

Implemented as: `prev_val + prev_transmittance * cur_val` [S1, unofficial].

### Pseudocode

```python
import torch

def render_partitioned_volumes(rays, volume_results_list, void_model, cfg):
    """
    Renders volumes by partitioning the ray space and combining results.
    
    Args:
        rays: Tuple of (origins, directions).
        volume_results_list: List of RayVolumeIntegralResults objects.
        void_model: Function to query background color.
        cfg: Configuration object.
        
    Returns:
        Combined RayVolumeIntegralResults.
    """
    origins, directions = rays
    prev_raw_outputs = [None] * len(volume_results_list)
    samplers = []
    raw_outputs = []
    t0 = None
    results = None
    
    for i, results_i in enumerate(volume_results_list):
        # Step 2a: Create Importance Ray Sampler
        sampler = ImportanceRaySampler(
            volume_range=results_i.volume_range,
            raw=results_i.raw,
            options=cfg.importance_sampling_options
        )
        samplers.append(sampler)
        
        # Step 2b: Store raw outputs
        raw_outputs.append(results_i.raw)
        
        # Step 2c: Update t0
        t0 = results_i.volume_range.next_t0()
        
        # Step 2d: Combine results
        if results is None:
            results = results_i
        else:
            # Combine using the partitioned rule: prev + prev_trans * cur
            # Assuming results_i has 'output' (channels) and 'transmittance'
            combined_channels = results.output.channels + results.transmittance * results_i.output.channels
            # Transmittance updates to the end of the current partition
            combined_transmittance = results.transmittance * results_i.transmittance
            
            # Reconstruct results object (simplified)
            results = RayVolumeIntegralResults(
                volume_range=results_i.volume_range, # Or unioned range
                raw=results_i.raw,
                output=CombinedOutput(channels=combined_channels),
                transmittance=combined_transmittance
            )
            
    # Step 3: Add void background
    # Query void model at ray origin/direction
    void_color = void_model(Query(origin=origins, direction=directions))
    
    # Add void contribution weighted by final transmittance
    final_channels = results.output.channels + results.transmittance * void_color
    
    # Update final results with combined channels
    results.output.channels = final_channels
    
    return results

def integrate_samples(vrange, raw, n_samples):
    """
    Integrates raw network outputs along a ray segment.
    
    Args:
        vrange: Volume range object with t0, t1, and intersected mask.
        raw: Dict of raw outputs (density, color, etc.) with ts (sample t values).
        n_samples: Number of samples.
        
    Returns:
        output: Rendered channels.
        transmittance: Final transmittance.
    """
    # Step 1: Calculate dt, ddensity, mass
    # Assuming raw.ts contains the sampled t values sorted
    ts = raw.ts
    dt = torch.diff(ts, dim=-2) # Partition lengths
    # Handle boundaries if necessary, e.g., prepend/append t0/t1
    
    ddensity = raw.density * dt
    mass = torch.cumsum(ddensity, dim=-2)
    
    # Final transmittance
    transmittance = torch.exp(-mass[..., -1, :])
    
    # Alphas
    alphas = 1.0 - torch.exp(-ddensity)
    
    # Ts (transmittance at start of each interval)
    # Prepend 0 to mass for T_0 = exp(0) = 1
    mass_padded = torch.cat([torch.zeros_like(mass[..., :1, :]), mass[..., :-1, :]], dim=-2)
    Ts = torch.exp(-mass_padded)
    
    # Weights
    weights = alphas * Ts
    
    # Step 2: Integrate
    # For each channel key (e.g., 'rgb'), sum samples * weights
    output_channels = {}
    for key in raw.keys():
        if key == 'density':
            continue
        samples = raw[key]
        # Ensure samples shape matches weights
        integrated = torch.sum(samples * weights, dim=-2)
        output_channels[key] = integrated
        
    output = RawOutput(channels=output_channels)
    
    # Step 4: Mask non-intersected rays
    if not vrange.intersected.all():
        # Mask transmittance to 1.0 for non-intersected
        transmittance = torch.where(vrange.intersected, transmittance, torch.ones_like(transmittance))
        # Mask output to 0.0 for non-intersected
        for key in output_channels:
            output_channels[key] = torch.where(vrange.intersected, output_channels[key], torch.zeros_like(output_channels[key]))
            
    return output, transmittance
```

### Parameters and Typical Values
*   `n_samples`: Number of samples per ray segment. Not given in the sources.
*   `importance_sampling_options`: Configuration for sampling strategy. Not given in the sources.
*   `void_model`: Background color model. Typically a constant color or a skybox. Not given in the sources.

### Edge Cases and Pitfalls
*   **Non-Intersected Rays**: Rays that do not intersect the volume must have their transmittance set to 1.0 and output set to 0.0 before combining with the void background [S1, unofficial].
*   **Precision**: Cumulative sum of optical depth (`mass`) can suffer from precision issues for very long rays or high densities. Not given in the sources.
*   **Boundary Conditions**: The calculation of `dt` and `Ts` requires careful handling of the first and last sample intervals to ensure they align with `vrange.t0` and `vrange.t1` [S1, unofficial].

## Operating characteristics

### Time and Memory Complexity
*   **Time**: Linear in the number of samples per ray and the number of volume partitions. Each partition requires a forward pass through the neural network and an integration step.
*   **Memory**: Proportional to the number of samples and the number of channels stored in `raw` outputs. Not given in the sources.

### Measured Performance
Not given in the sources.

### Scaling
Scales with the number of disjoint volumes. Each volume requires separate intersection, sampling, and integration steps. Not given in the sources.

### Strengths and Limitations
*   **Strengths**: Correctly handles multiple disjoint volumes and empty space between them. Allows for importance sampling within each partition.
*   **Limitations**: Requires explicit partitioning of the ray space. Performance depends on the number of partitions. Not given in the sources.

### When to Use
Use when rendering scenes with multiple disjoint volumetric objects or when empty space between volumes needs to be explicitly modeled. Not given in the sources.

### When Not to Use
Use standard ray marching for single, continuous volumes. Not given in the sources.
