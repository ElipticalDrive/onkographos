# Point Cloud Optimization via Pointersect

Also called: Inverse rendering with pointersect, Pointersect Inverse Rendering Optimization

## Overview
This method optimizes the position and color of a noisy point cloud to minimize the photometric difference between images rendered via the Pointersect differentiable renderer and input ground-truth RGB images with foreground masks [S1]. It distinguishes itself from sibling methods like [Gradient-Based SE(3) Optimization](7526-gradient-based-se-3-optimization.md) by jointly optimizing geometry (point positions) and appearance (point colors) rather than just camera poses, and from [Test-Time Photometric Optimization](12699-test-time-photometric-optimization.md) by utilizing Pointersect’s specific cloud-ray intersection mechanism to provide dense, differentiable surface normal and hit estimates that regularize the optimization [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** $N$ input RGB images $I = \{I_1, \dots, I_N \mid I_i \in \mathbb{R}^{h \times w \times 3}\}$, corresponding foreground masks $Y = \{Y_1, \dots, Y_N \mid Y_i \in [0, 1]^{h \times w}\}$, camera extrinsic and intrinsic matrices, and an initial noisy point cloud $P = \{(p_1, c_1), \dots, (p_n, c_n)\}$ where $p_i$ is position and $c_i$ is color [S1].
*   **Outputs:** Optimized point cloud $P' = \{(p'_1, c'_1), \dots, (p'_n, c'_n)\}$ [S1].

**Data Structures:**
The point cloud is stored as a list of points, each containing:
*   `p`: 3D position vector $(x, y, z)$ [S1].
*   `c`: RGB color vector [S1].
*   `rd`: Ray direction feature (extracted from camera pose) [S1].
*   `u, v`: Auxiliary coordinates (extracted from camera pose) [S1].
*   `z`: Depth feature (extracted from camera pose) [S1].
*   $\ell_c$: Binary indicator for RGB validity (1 if valid, 0 if dropped) [S1].
*   $\ell_a$: Binary indicator for auxiliary features ($u, v, z, rd$) validity (1 if valid, 0 if dropped) [S1].

**Numbered Steps:**

1.  **Ray Sampling:** For each iteration, select a target camera [S1]. The target camera has a resolution of $50 \times 50$ (2500 query rays) [S1]. The camera points to a random point in a centered box of width 1 unit and is positioned 0.5 to 3 units from the origin [S1]. For each ray $r^j_k$ from the $j$-th input image (or target view), calculate the target color $\hat{c}(r^j_k)$ and foreground mask value $\hat{y}(r^j_k)$ using bilinear interpolation on the input image and mask [S1].

2.  **Data Augmentation:** Randomly drop RGB features and auxiliary features ($u, v, z, rd$) independently with 50% probability [S1]. Set $\ell_c = 0$ if RGB is dropped, and $\ell_a = 0$ if auxiliary features are dropped [S1]. If dropped, set the corresponding feature values to zero [S1]. During inference, only $xyz$ and $rgb$ are used [S1].

3.  **Rendering:** Render the current point cloud $P$ using Pointersect to obtain:
    *   Color estimate $c(r^j_k, P)$ [S1].
    *   Hit estimate $h(r^j_k, P)$ [S1].
    *   Surface normal estimate $n(r^j_k, P)$ [S1].

4.  **Loss Calculation:** Compute the loss function $\mathcal{L}$ [S1]:
    $$
    \mathcal{L} = \sum_{j=1}^{N} \sum_{r^j_k} \left[ \| \hat{c}(r^j_k) - c(r^j_k, P) \|^2_2 - \hat{y}(r^j_k) \log h(r^j_k, P) - (1 - \hat{y}(r^j_k)) \log (1 - h(r^j_k, P)) + (n(r^j_k, P) \times n(r^j_{k+1_u}, P))^2 + (n(r^j_k, P) \times n(r^j_{k+1_v}, P))^2 \right]
    $$
    where $k+1_u$ and $k+1_v$ denote adjacent rays in the u and v directions respectively [S1].

5.  **Optimization:** Update $P$ using gradient descent [S1]. The parameters optimized are the positions $p$ and colors $c$ of the points [S1].

**Pseudocode:**

```python
import torch
import torch.nn.functional as F

def optimize_point_cloud_via_pointersect(
    images: torch.Tensor,      # Shape: [N, H, W, 3]
    masks: torch.Tensor,       # Shape: [N, H, W]
    cameras: list,             # List of camera extrinsic/intrinsic matrices
    initial_points: torch.Tensor, # Shape: [M, 6] (x, y, z, r, g, b)
    num_iterations: int = 350000,
    learning_rate_schedule=None
):
    """
    Optimizes point cloud positions and colors using Pointersect rendering.
    """
    # Initialize learnable parameters
    points = initial_points[:, :3].clone().detach().requires_grad_(True)
    colors = initial_points[:, 3:].clone().detach().requires_grad_(True)
    
    optimizer = torch.optim.Adam([points, colors], lr=0.0, betas=(0.9, 0.98))
    
    # Precompute target colors and masks for input views
    target_colors_input = []
    target_masks_input = []
    
    for j in range(len(images)):
        # Bilinear interpolation to get target color and mask for specific rays
        target_colors_input.append(images[j])
        target_masks_input.append(masks[j])

    for iteration in range(num_iterations):
        optimizer.zero_grad()
        
        # 1. Sampling Diversity & Augmentation
        # Randomly select input camera index j
        j = torch.randint(0, len(images), (1,)).item()
        
        # Randomly set resolution for input camera (30x30 to 300x300)
        # and position (1 to 3 units from origin)
        # [G] Helper to generate camera pose based on random resolution and position constraints
        cam_j = generate_random_camera_pose(cameras[j], min_dist=1.0, max_dist=3.0)
        res_j = torch.randint(30, 301, (1,)).item()
        
        # Generate rays for this camera
        rays_j = generate_rays(cam_j, res_j, res_j)
        
        # Data Augmentation: Randomly drop features
        # 50% chance to drop RGB
        drop_rgb = torch.rand(1) > 0.5
        # 50% chance to drop auxiliary features (u, v, z, rd)
        drop_aux = torch.rand(1) > 0.5
        
        # Extract features from camera pose for each point
        # [G] Helper to extract u, v, z, rd from camera pose relative to point
        aux_features = extract_auxiliary_features(points, cam_j)
        
        # Apply dropout masks
        if drop_rgb:
            current_colors = torch.zeros_like(colors)
        else:
            current_colors = colors
            
        if drop_aux:
            current_aux = torch.zeros_like(aux_features)
        else:
            current_aux = aux_features
            
        # 2. Rendering with Pointersect
        # Pointersect takes points, colors, and auxiliary features
        # Returns color, hit probability, and normal for each ray
        rendered_colors, hit_probs, normals = pointersect_render(
            points, 
            current_colors, 
            current_aux,
            rays_j
        )
        
        # 3. Target Interpolation
        # Interpolate target color and mask from input image/mask
        # [G] Helper to sample interpolated values from input image using ray pixel coordinates
        target_colors = interpolate_image(target_colors_input[j], rays_j)
        target_masks = interpolate_image(target_masks_input[j], rays_j)
        
        # 4. Loss Calculation
        # Photometric loss
        color_loss = F.mse_loss(rendered_colors, target_colors)
        
        # Hit loss (Binary Cross Entropy)
        hit_loss = - (target_masks * torch.log(hit_probs + 1e-8) + 
                      (1 - target_masks) * torch.log(1 - hit_probs + 1e-8))
        hit_loss = hit_loss.mean()
        
        # Normal smoothness loss
        # Compute normals for adjacent rays in u and v directions
        # [G] Helper to identify grid neighbors for u/v direction dot products
        normals_u = get_neighbor_normals(normals, rays_j, direction='u')
        normals_v = get_neighbor_normals(normals, rays_j, direction='v')
        
        normal_loss_u = torch.sum((normals * normals_u) ** 2)
        normal_loss_v = torch.sum((normals * normals_v) ** 2)
        
        total_loss = color_loss + hit_loss + normal_loss_u + normal_loss_v
        
        # 5. Backpropagation
        total_loss.backward()
        
        # Update learning rate
        current_lr = learning_rate_schedule(iteration) if learning_rate_schedule else 2e-6
        for param_group in optimizer.param_groups:
            param_group['lr'] = current_lr
            
        optimizer.step()
        
        # Project RGB values to [0, 1] every iteration (for the Stanford Bunny setup)
        with torch.no_grad():
            colors.clamp_(0, 1)

    return points.detach(), colors.detach()
```

**Parameters:**
*   **Optimizer:** ADAM with $\beta_1 = 0.9$, $\beta_2 = 0.98$ [S1].
*   **Learning Rate:** Warm-up for 4,000 iterations increasing to $2 \times 10^{-6}$, then gradual decrease [S1].
*   **Iterations:** 350,000 iterations [S1].
*   **Hardware:** 8 A100 GPUs [S1].
*   **Alternative Setup (Stanford Bunny):** SGD with learning rate 0.01 for 10,000 iterations [S1]. Each iteration selects a point, projects to all input images, casts rays from a local $10 \times 10$ patch (approx 10,000 rays) [S1]. Every 150 iterations, use ground-truth foreground masks for silhouette carving to remove invalid points and insert new points using Pointersect's estimates [S1].

**Edge Cases and Pitfalls:**
*   **Noise Sensitivity:** Unlike Poisson reconstruction, Pointersect is unaffected by small noise in vertex normals because it does not use vertex normals for surface reconstruction [S1].
*   **Feature Dropping:** The method supports point clouds with only $xyz$ information by randomly dropping features during training [S1].
*   **Precision:** RGB values must be projected to $[0, 1]$ every iteration in the alternative setup [S1].

## Subtopics

### Silhouette Carving
A technique used in the alternative optimization setup where ground-truth foreground masks are used to remove invalid points and insert new points based on Pointersect's position/color estimates [S1].

### Normal Regularization
The use of surface normal estimates from Pointersect to enforce smoothness via dot products with adjacent ray normals, preventing noisy geometry [S1].

## Operating characteristics
*   **Time Complexity:** Training takes 10 days on 8 A100 GPUs for 350,000 iterations [S1].
*   **Memory Complexity:** Not given in the sources [S1].
*   **Measured Performance:**
    *   **Stanford Bunny (100 input views, 144 novel views):**
        *   PSNR (Input): 10.1±0.5 dB (before) $\rightarrow$ 54.0±0.9 dB (after) [S1].
        *   PSNR (Novel): 24.6±0.5 dB (before) $\rightarrow$ 25.7±1.2 dB (after) [S1].
        *   Normal Angle (Input): 0.46±0.08° (before) $\rightarrow$ 13.9±0.8° (after) [S1].
        *   Depth RMSE (Input): 0.09±0.06 (before) $\rightarrow$ 0.10±0.07 (after) [S1].
    *   **Chamfer Distance ($\times 10^{-3}$):**
        *   ShapeNet: 0.29±0.48 (Pointersect) vs. 0.51±1.98 (Poisson), 1.58±4.30 (Neural Points), 2.32±9.55 (Visibility Splatting) [S1].
        *   Sketchfab: 0.87±2.19 (Pointersect) vs. 0.30±0.43 (Poisson), 0.98±2.47 (Neural Points), 13.33±25.53 (Visibility Splatting) [S1].
*   **Strengths:** Does not require vertex normals, making it robust to noise compared to Poisson reconstruction [S1].
*   **Limitations:** Computationally expensive (10 days on 8 GPUs) [S1].

## Background
The method is based on the Pointersect paper, which introduces neural rendering with cloud-ray intersection [S1]. Pointersect allows for differentiable rendering of point clouds, enabling inverse rendering optimization of geometry and appearance [S1]. The specific optimization setup was demonstrated on the Stanford Bunny and ShapeNet datasets to show the potential of the method [S1].
