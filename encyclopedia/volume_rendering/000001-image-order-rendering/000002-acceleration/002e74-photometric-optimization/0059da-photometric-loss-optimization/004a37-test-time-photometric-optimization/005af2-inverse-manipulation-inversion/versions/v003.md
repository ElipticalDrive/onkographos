# Inverse Manipulation (Inversion)
Also called: CLIP-Driven Inverse Manipulation, EM-based Inverse Projection

## Overview
Inverse Manipulation is an iterative optimization method that inversely projects an input image $I_r$ onto the generation manifold of a pre-trained conditional NeRF by optimizing the generation conditions: shape code $z_s$, appearance code $z_a$, and camera pose $v$ [S1]. It distinguishes itself from direct latent code retrieval by using an Expectation-Maximization (EM) style alternating optimization to find the specific latent codes and camera parameters that best reconstruct the input image, enabling subsequent text-driven or attribute-based manipulations [S1]. Unlike [Test-Time Photometric Optimization](12699-test-time-photometric-optimization.md) which may optimize for general fidelity, this method specifically targets the disentangled latent space of a conditional NeRF to enable precise editing [S1].

## How it works
**Inputs:**
*   Input image $I_r$ belonging to the training category (e.g., chairs, cars) [S1].
*   Pre-trained conditional NeRF generator $\hat{F}_\theta$ with fixed weights [S1].
*   Pre-trained CLIP image encoder $\hat{E}_i$ [S1].
*   Initial estimates for shape code $\hat{z}_s$, appearance code $\hat{z}_a$, and camera pose $v$ (often sampled or initialized from the manifold distribution) [S1].

**Outputs:**
*   Optimized shape code $z_s^*$, appearance code $z_a^*$, and camera pose $v^*$ that minimizes the reconstruction and CLIP consistency losses [S1].

**Data Structures:**
*   $z_s \in \mathbb{R}^{d_s}$: Shape latent code.
*   $z_a \in \mathbb{R}^{d_a}$: Appearance latent code.
*   $v$: Camera pose parameters (extrinsics/intrinsics).
*   $n_z \in \mathbb{R}^{d_n}$: Random noise vector.
*   $\lambda_n \in [0, 1]$: Noise scaling factor.

**Parameters:**
*   $\lambda_v$: Weight for the CLIP consistency term in the camera loss. Typical value: $\lambda_v = 0.1$ [S1].
*   $\lambda_s, \lambda_a$: Weights for the CLIP consistency terms in the shape and appearance losses respectively. Not given in the sources.
*   $\lambda_n$: Linearly decays from 1 to 0 throughout the optimization iterations [S1].
*   $n_z$: Random standard Gaussian noise vector sampled at each step [S1].

**Algorithm Steps:**
The method follows an EM-like iterative procedure [S1]. In each iteration, the following three steps are performed sequentially:

1.  **Camera Optimization:** Optimize the camera pose $v$ while keeping $z_s$ and $z_a$ fixed [S1]. The loss $L_v$ combines pixel reconstruction error and CLIP image consistency:
    $$ L_v = \| \hat{F}_\theta(v, \hat{z}_s, \hat{z}_a) - I_r \|^2 + \lambda_v D_{CLIP}(\hat{F}_\theta(v, \hat{z}_s, \hat{z}_a), I_r) $$
    where $D_{CLIP}$ is the CLIP distance (typically $1 - \text{cosine similarity}$) [S1].

2.  **Shape Code Update:** Update the shape code $z_s$ by minimizing $L_s$ [S1]. The update uses a perturbed shape code $z_s + \lambda_n n_z$ to improve robustness:
    $$ L_s = \| \hat{F}_\theta(\hat{v}, z_s + \lambda_n n_z, \hat{z}_a) - I_r \|^2 + \lambda_s D_{CLIP}(\hat{F}_\theta(\hat{v}, z_s + \lambda_n n_z, \hat{z}_a), I_r) $$
    Here, $\hat{v}$ is the camera pose optimized in Step 1 [S1].

3.  **Appearance Code Update:** Update the appearance code $z_a$ by minimizing $L_a$, similarly using a perturbed appearance code [S1]:
    $$ L_a = \| \hat{F}_\theta(\hat{v}, \hat{z}_s, z_a + \lambda_n n_z) - I_r \|^2 + \lambda_a D_{CLIP}(\hat{F}_\theta(\hat{v}, \hat{z}_s, z_a + \lambda_n n_z), I_r) $$
    Here, $\hat{z}_s$ is the shape code from Step 2 [S1].

**Pseudocode:**
```python
def inverse_manipulation(F_theta, E_i, I_r, z_s, z_a, v, 
                         lambda_v, lambda_s, lambda_a, num_iterations, learning_rate):
    """
    Inverse Manipulation: Optimize z_s, z_a, v to match I_r.
    """
    # lambda_n linearly decays from 1.0 to 0.0
    lambda_n_schedule = [1.0 - step / (num_iterations - 1) for step in range(num_iterations)]
    
    for step in range(num_iterations):
        lambda_n = lambda_n_schedule[step]
        
        # n_z is a random standard Gaussian noise vector sampled in each step
        n_z = [random.gauss(0, 1) for _ in range(len(z_s))]
        
        # Step 1: Optimize Camera v while keeping z_s and z_a fixed
        v = optimize_step(v, lambda_v, F_theta, E_i, I_r, z_s, z_a, 'camera', learning_rate)
        
        # Step 2: Update Shape z_s by minimizing Ls
        z_s = optimize_step(z_s, lambda_s, F_theta, E_i, I_r, v, z_a, 'shape', learning_rate, lambda_n, n_z)
        
        # Step 3: Update Appearance z_a by minimizing La
        z_a = optimize_step(z_a, lambda_a, F_theta, E_i, I_r, v, z_s, 'appearance', learning_rate, lambda_n, n_z)
        
    return z_s, z_a, v

def optimize_step(param, weight, F_theta, E_i, I_r, v, z_s, z_a, loss_type, lr, lambda_n=0, n_z=None):
    """Gradient descent step for a specific parameter based on loss type."""
    # Construct perturbed inputs for forward pass
    if loss_type == 'camera':
        v_in, zs_in, za_in = v, z_s, z_a
    elif loss_type == 'shape':
        v_in, zs_in, za_in = v, [z + lambda_n * n for z, n in zip(z_s, n_z)], z_a
    else: # appearance
        v_in, zs_in, za_in = v, z_s, [z + lambda_n * n for z, n in zip(z_a, n_z)]
        
    # Render image
    rendered_img = F_theta(v_in, zs_in, za_in)
    
    # Pixel reconstruction loss
    pixel_loss = sum((r - i) ** 2 for r, i in zip(rendered_img, I_r)) / len(rendered_img)
    
    # CLIP distance loss
    feat_rendered = E_i(rendered_img)
    feat_input = E_i(I_r)
    cosine_sim = dot_product(feat_rendered, feat_input) / (norm(feat_rendered) * norm(feat_input))
    clip_loss = 1.0 - cosine_sim
    
    # Total loss
    loss = pixel_loss + weight * clip_loss
    
    # Gradient descent update
    grad = gradient(loss, param)
    return [p - lr * g for p, g in zip(param, grad)]
```

**Edge Cases and Pitfalls:**
*   **Precision:** The method relies on gradient-based optimization, which can be sensitive to local minima if the initial codes are far from the manifold [S1].
*   **Noise Scaling:** The linear decay of $\lambda_n$ from 1 to 0 is critical for robustness; failing to decay it may prevent convergence to a precise solution [S1].
*   **Input Domain:** The method assumes the input image $I_r$ belongs to the same training category as the NeRF generator (e.g., chairs for a chair NeRF) [S1].

## Subtopics

### [Text-driven Manipulation via Inversion](17409-text-driven-manipulation-via-inversion.md)
A method to find an optimal latent code $w$ by gradient-based optimization that maximizes the cosine similarity between rendered images and a target text embedding in CLIP space. It sets itself apart from sibling methods by directly optimizing the latent representation against a text prompt rather than reconstructing a specific input image or interpolating between fixed codes.

## Operating characteristics
*   **Time Complexity:** Iterative gradient-based optimization. Each iteration requires rendering the NeRF and computing CLIP features, which is computationally expensive [G].
*   **Memory Complexity:** Requires storing the latent codes $z_s, z_a$, camera parameters $v$, and gradients during backpropagation. The NeRF weights are fixed [G].
*   **Performance:** Evaluated on Photoshapes (150K chairs, 128×128) and Carla (10K cars, 256×256) [S1].
*   **Strengths:** Enables text-driven and attribute-based editing of NeRFs by finding precise latent codes for input images [S1].
*   **Limitations:** Computationally intensive due to iterative optimization.
*   **When to use:** When precise inversion of an input image into a latent space is required for subsequent editing [G].
*   **When not to use:** When real-time performance is required or when the input image is out-of-distribution for the NeRF generator [G].

## Background
Inverse Manipulation is an iterative optimization method designed to inversely project an input image $I_r$ onto the generation manifold of a pre-trained conditional NeRF [S1]. It builds on latent image manipulation methods and applies the EM algorithm to optimize generation conditions [S1]. The method was evaluated on public datasets like Photoshapes and Carla [S1].
