# Dynamic Volume Resolution & Alpha Mask Update

Also called: Dynamic Resolution and Mask Update

## Overview
This method dynamically adjusts the spatial resolution of the underlying volume representation and the density of the sampling process during training to balance computational cost and reconstruction quality. It solves the problem of inefficient resource usage in early training stages (where the volume is sparse or low-resolution) and late stages (where high-frequency details are required). It sets itself apart from static resolution methods by coupling the geometric pruning of empty space (via an alpha mask) with the explicit upscaling of the voxel grid and the adaptive adjustment of samples per ray, all triggered by predefined iteration schedules [S1, unofficial].

## How it works
The method operates as a periodic update routine invoked at specific training iterations. It manages three coupled resources: the spatial extent of the volume (via an alpha mask), the discretization density (voxel resolution and samples per ray), and the optimization state (learning rate and optimizer momentum).

### Inputs and Outputs
*   **Inputs**: Current training iteration number, current volume representation (`tensorf`), current bounding box (`aabb`), camera rays (`allrays`), ground truth colors (`allrgbs`), and configuration arguments (`args`).
*   **Outputs**: Updated volume representation with new resolution, updated optimizer state, and potentially filtered ray sets.

### Data Structures
*   **`reso_cur`**: A tuple `(res_x, res_y, res_z)` representing the current voxel grid resolution.
*   **`reso_mask`**: A tuple representing the resolution of the alpha mask grid. Capped at $256^3$ to prevent excessive memory usage [S1, unofficial].
*   **`update_AlphaMask_list`**: A sorted list of integers specifying the iterations at which the alpha mask should be regenerated.
*   **`upsamp_list`**: A sorted list of integers specifying the iterations at which the volume resolution should be upsampled.
*   **`N_voxel_list`**: A list of target voxel counts corresponding to `upsamp_list`.

### Numbered Steps
1.  **Alpha Mask Update Check**:
    *   If the current iteration is in `update_AlphaMask_list`:
        *   Determine mask resolution: If `reso_cur[0] * reso_cur[1] * reso_cur[2] < 256^3`, set `reso_mask = reso_cur`; otherwise, cap `reso_mask` to maintain a manageable grid size [S1, unofficial].
        *   Generate new alpha mask: Call `new_aabb = tensorf.updateAlphaMask(tuple(reso_mask))`. This involves generating a binary mask from the density field to identify occupied space [S1, unofficial].
        *   Shrink Volume: If this is the first update, shrink the volume grid to the new `new_aabb` using `tensorf.shrink(new_aabb)`.
        *   Adjust Regularization: Switch the L1 regularization weight to `args.L1_weight_rest` to adapt to the new geometry [S1, unofficial].
        *   Filter Rays (Conditional): If `args.ndc_ray` is false (i.e., using standard world-space rays) and this is the second update iteration, filter out rays that fall outside the new bounding box: `allrays, allrgbs = tensorf.filtering_rays(allrays, allrgbs)`. Reinitialize the sampler with the new ray count: `trainingSampler = SimpleSampler(allrgbs.shape[0], args.batch_size)` [S1, unofficial].

2.  **Resolution Upsampling Check**:
    *   If the current iteration is in `upsamp_list`:
        *   Pop the next target voxel count: `n_voxels = N_voxel_list.pop(0)` [S1, unofficial].
        *   Convert to Resolution: Calculate the new 3D resolution from the voxel count and current AABB: `reso_cur = N_to_reso(n_voxels, tensorf.aabb)`.
        *   Adjust Samples per Ray: Calculate the new number of samples per ray to maintain consistent sampling density relative to the new resolution: `nSamples = min(args.nSamples, cal_n_samples(reso_cur, args.step_ratio))`. This ensures that as resolution increases, the step size decreases or sample count increases appropriately [S1, unofficial].
        *   Upsample Grid: Interpolate the existing volume data to the new resolution: `tensorf.upsample_volume_grid(reso_cur)` [S1, unofficial].
        *   Adjust Learning Rate:
            *   If `args.lr_upsample_reset` is true, set `lr_scale = 1`.
            *   Otherwise, apply decay: `lr_scale = args.lr_decay_target_ratio ** (iteration / args.n_iters)` [S1, unofficial].
        *   Reinitialize Optimizer: Create new parameter groups with scaled learning rates: `grad_vars = tensorf.get_optparam_groups(args.lr_init * lr_scale, args.lr_basis * lr_scale)`. Create a new Adam optimizer instance: `optimizer = torch.optim.Adam(grad_vars, betas=(0.9, 0.99))`. Note that this discards previous momentum states [S1, unofficial].

### Formulas and Parameters
*   **Sample Count Calculation**:
    $$ nSamples = \min(\text{args.nSamples}, \text{cal\_n\_samples}(\text{reso\_cur}, \text{args.step\_ratio})) $$
    Where `cal_n_samples` typically scales inversely with the voxel size to maintain constant error bounds along the ray [S1, unofficial].
*   **Learning Rate Scale**:
    $$ \text{lr\_scale} = \begin{cases} 1 & \text{if } \text{args.lr\_upsample\_reset} \\ \text{args.lr\_decay\_target\_ratio}^{(\text{iteration} / \text{args.n\_iters})} & \text{otherwise} \end{cases} $$

*   **Parameters**:
    *   `update_AlphaMask_list`: List of iterations for mask updates [S1, unofficial].
    *   `upsamp_list`: List of iterations for resolution upscaling [S1, unofficial].
    *   `args.lr_upsample_reset`: Boolean. If true, resets LR to initial on upsample; otherwise applies decay [S1, unofficial].
    *   `args.lr_decay_target_ratio`: Float. Multiplier for LR decay during upscaling if `lr_upsample_reset` is false [S1, unofficial].
    *   `args.nSamples`: Maximum samples per ray before dynamic adjustment [S1, unofficial].
    *   `args.step_ratio`: Float. Controls sample density relative to resolution during upscaling [S1, unofficial].
    *   `args.lr_init`, `args.lr_basis`: Initial learning rates for main and basis parameters [S1, unofficial].
    *   `args.ndc_ray`: Boolean. If false, enables spatial bounding box culling for rays [S1, unofficial].

### Edge Cases and Pitfalls
*   **Ray Filtering**: Ray filtering (`filtering_rays`) is only applied if `args.ndc_ray` is false. NDC rays bypass spatial bounding box culling, which may cause wasted computation on empty space if the mask is not used correctly [S1, unofficial].
*   **Optimizer State Loss**: The optimizer is completely reinitialized on upsample, discarding momentum states. This may cause training instability if not intended or if the learning rate scale is not adjusted carefully [S1, unofficial].
*   **Mask Resolution Cap**: The mask resolution is capped at $256^3$ to prevent excessive memory usage, which may limit the precision of the alpha mask for very large volumes [S1, unofficial].

## Subtopics

### Alpha Mask Generation
Generates an alpha mask from the dense density field to prune empty space, using a threshold and max pooling for smoothing. It computes dense alpha values on a grid spanning the AABB, applies 3D max pooling with kernel size 3 and padding 1 to smooth the alpha mask, binarizes alpha values based on a threshold (default 0.5), and creates an `AlphaGridMask` object with the new mask. The new AABB is calculated based on the bounding box of valid (alpha > 0.5) voxels. Parameters include `gridSize` (default: (200, 200, 200)) and `alphaMask_thres` (threshold for binarizing alpha values) [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: The alpha mask generation and volume upsampling are $O(N)$ with respect to the number of voxels in the current grid. Ray filtering is $O(R)$ with respect to the number of rays. The optimizer reinitialization is $O(P)$ with respect to the number of parameters. These operations are performed periodically, not every iteration, so the average overhead is low.
*   **Memory Complexity**: The memory usage scales with the volume resolution. The alpha mask adds an overhead of $O(R_{mask}^3)$, capped at $256^3$ [S1, unofficial].
*   **Performance**: By starting with a low resolution and sparse mask, the method reduces initial training time and memory footprint. As the volume fills in, the resolution increases, allowing for higher fidelity. This is particularly effective for scenes with large empty spaces [S1, unofficial].
*   **Strengths**: Efficient resource utilization, automatic adaptation to scene complexity, improved convergence in early stages.
*   **Limitations**: Requires careful tuning of update schedules (`update_AlphaMask_list`, `upsamp_list`). Reinitializing the optimizer can lead to instability. NDC ray handling requires special care to avoid wasted computation [S1, unofficial].
*   **When to Use**: Suitable for novel view synthesis and NeRF training where the scene geometry is unknown or sparse initially.
*   **When Not to Use**: Not suitable for real-time rendering where latency is critical, or for scenes with known, fixed geometry where static resolution is sufficient.

## Background
This method is derived from implementations in Collaborative Neural Radiance Fields for Novel View Synthesis, specifically the codebase by Zhenyang Liu et al. It addresses the common issue in NeRF training where a fixed high resolution is computationally prohibitive for large scenes or early training stages [S1, unofficial]. The approach of dynamically adjusting resolution and pruning empty space has been explored in various forms in the NeRF literature, but this specific implementation couples it with optimizer reinitialization and ray filtering for robustness [S1, unofficial].
