# Dynamic Volume Resolution & Alpha Mask Update

Also called: Dynamic Resolution and Mask Update

## Overview
This method dynamically adjusts the spatial resolution of a volumetric representation and prunes empty space via an alpha mask during training to improve efficiency and convergence. It solves the problem of fixed-resolution training wasting compute on empty space or lacking detail in complex regions. It differs from [Level-of-detail (LOD) methods](1007-level-of-detail-lod-methods.md) by modifying the underlying grid resolution and occupancy mask globally rather than selecting pre-computed representations based on camera distance.

## How it works
The method operates by monitoring the training iteration count against two predefined lists: `update_AlphaMask_list` and `upsamp_list`. When the current iteration matches an entry in these lists, specific updates to the volume grid, sampling strategy, and optimizer state are triggered.

### Inputs and Outputs
*   **Inputs**: Current training iteration, current volume resolution `reso_cur`, current bounding box `aabb`, current ray data `allrays`, current ground truth colors `allrgbs`, and hyperparameters (`args`).
*   **Outputs**: Updated volume grid, updated alpha mask, updated sampling parameters, and reinitialized optimizer.

### Data Structures
*   `reso_cur`: A tuple `(res_x, res_y, res_z)` representing the current voxel resolution.
*   `tensorf`: The neural field object containing the volume grid and optimization state.
*   `update_AlphaMask_list`: A sorted list of integers representing iterations where the alpha mask should be updated.
*   `upsamp_list`: A sorted list of integers representing iterations where the resolution should be upsampled.
*   `N_voxel_list`: A list of target voxel counts corresponding to `upsamp_list`.

### Steps

1.  **Alpha Mask Update Check**:
    *   If the current iteration is in `update_AlphaMask_list`:
        *   Determine the mask resolution `reso_mask`. If `reso_cur[0] * reso_cur[1] * reso_cur[2] < 256**3`, set `reso_mask = reso_cur`. Otherwise, `reso_mask` is typically a lower resolution (implementation detail: often fixed or scaled, but the source caps it at `reso_cur` if the volume is small) [S1, unofficial].
        *   Call `tensorf.updateAlphaMask(tuple(reso_mask))` to generate a new alpha mask. This involves computing dense alpha values, applying 3D max pooling (kernel 3, padding 1), binarizing with a threshold (default 0.5), and determining the new active bounding box [S1, unofficial].
        *   Call `tensorf.shrink(new_aabb)` to restrict the volume to the new active bounding box.
        *   Update the L1 regularization weight: `L1_reg_weight = args.L1_weight_rest` [S1, unofficial].
        *   If NDC rays are not used (`args.ndc_ray` is false) and this is the second alpha mask update iteration:
            *   Filter rays outside the new bounding box: `allrays, allrgbs = tensorf.filtering_rays(allrays, allrgbs)` [S1, unofficial].
            *   Reinitialize the sampler: `trainingSampler = SimpleSampler(allrgbs.shape[0], args.batch_size)` [S1, unofficial].

2.  **Resolution Upsampling Check**:
    *   If the current iteration is in `upsamp_list`:
        *   Pop the next target voxel count: `n_voxels = N_voxel_list.pop(0)` [S1, unofficial].
        *   Convert voxel count to resolution: `reso_cur = N_to_reso(n_voxels, tensorf.aabb)` [S1, unofficial].
        *   Update samples per ray: `nSamples = min(args.nSamples, cal_n_samples(reso_cur, args.step_ratio))` [S1, unofficial].
        *   Upsample the volume grid: `tensorf.upsample_volume_grid(reso_cur)` [S1, unofficial].
        *   Calculate learning rate scale:
            *   If `args.lr_upsample_reset` is true, `lr_scale = 1`.
            *   Else, `lr_scale = args.lr_decay_target_ratio ** (iteration / args.n_iters)` [S1, unofficial].
        *   Get new parameter groups with scaled learning rates: `grad_vars = tensorf.get_optparam_groups(args.lr_init * lr_scale, args.lr_basis * lr_scale)` [S1, unofficial].
        *   Reinitialize the Adam optimizer: `optimizer = torch.optim.Adam(grad_vars, betas=(0.9, 0.99))` [S1, unofficial].

        # Generate new alpha mask and shrink volume
        new_aabb = tensorf.updateAlphaMask(tuple(reso_mask))
        tensorf.shrink(new_aabb)
        
        # Update L1 weight
        L1_reg_weight = args.L1_weight_rest

    if iteration in upsamp_list:
        # Pop next target voxel count
        if N_voxel_list:
            n_voxels = N_voxel_list.pop(0)
        else:
            n_voxels = None # Should not happen if lists are aligned
            
        if n_voxels is not None:
            # Convert voxel count to resolution
            reso_cur = N_to_reso(n_voxels, tensorf.aabb)
            
            # Update samples per ray

            tensorf.upsample_volume_grid(reso_cur)
            
            # Calculate LR scale
            if args.lr_upsample_reset:
                lr_scale = 1
            else:
                lr_scale = args.lr_decay_target_ratio ** (iteration / args.n_iters)
            
            # Get new parameter groups
            grad_vars = tensorf.get_optparam_groups(
                args.lr_init * lr_scale,

            )
            
            # Reinitialize optimizer

### Parameters
*   `update_AlphaMask_list`: List of iterations triggering alpha mask updates.
*   `upsamp_list`: List of iterations triggering volume resolution upscaling.
*   `args.lr_upsample_reset`: Boolean. If true, resets learning rate to initial on upsample; otherwise applies decay [S1, unofficial].
*   `args.lr_decay_target_ratio`: Float. Multiplier for LR decay during upscaling if `lr_upsample_reset` is false [S1, unofficial].
*   `args.nSamples`: Maximum samples per ray before dynamic adjustment [S1, unofficial].
*   `args.step_ratio`: Float. Controls sample density relative to resolution during upscaling [S1, unofficial].
*   `args.lr_init`, `args.lr_basis`: Initial learning rates for main and basis parameters [S1, unofficial].
*   `alphaMask_thres`: Threshold for binarizing alpha values. Values >= this become 1, < this become 0. Default: 0.5 [S1, unofficial].
*   `gridSize`: Resolution of the alpha mask grid. Default: (200, 200, 200) [S1, unofficial].

### Edge Cases and Pitfalls
*   **Ray Filtering**: `filtering_rays` is only applied if `args.ndc_ray` is false. NDC rays bypass spatial bounding box culling, which may cause wasted computation on empty space [S1, unofficial].
*   **Optimizer State**: The optimizer is completely reinitialized on upsample, discarding momentum states. This may cause training instability if not intended [S1, unofficial].
*   **Mask Resolution Cap**: If the current volume resolution is less than $256^3$, the mask resolution is capped at the current volume resolution [S1, unofficial].

## Subtopics

### Alpha Mask Generation
Generates an alpha mask from the dense density field to prune empty space, using a threshold and max pooling for smoothing. It computes dense alpha values on a grid spanning the AABB, applies 3D max pooling (kernel size 3, padding 1) to smooth the alpha mask, binarizes alpha values based on a threshold (default 0.5), creates an AlphaGridMask object, and calculates the new AABB based on the bounding box of valid (alpha > 0.5) voxels. It is chosen when the goal is to explicitly remove empty space from the training domain to save memory and compute. It differs from implicit pruning by explicitly maintaining a binary occupancy grid.

## Operating characteristics
*   **Time Complexity**: The alpha mask update involves a forward pass through the network to compute densities, max pooling, and binarization, which is $O(V)$ where $V$ is the number of voxels in the mask grid. The resolution upsample involves interpolating the existing grid to a higher resolution, which is $O(V_{new})$. Ray filtering is $O(R)$ where $R$ is the number of rays.
*   **Memory Complexity**: The alpha mask requires $O(V_{mask})$ memory. The volume grid memory scales with the resolution. Upsampling increases memory usage.
*   **Performance**: Improves training efficiency by focusing compute on occupied space and allowing higher resolution in complex areas.
*   **Strengths**: Reduces memory footprint, accelerates convergence by removing empty space, allows dynamic resolution scaling.
*   **Limitations**: Requires careful tuning of update intervals. Reinitializing the optimizer can cause instability. NDC rays are not compatible with spatial culling.
*   **When to use**: When training on scenes with significant empty space or when memory is constrained. When high resolution is needed only in specific regions.
*   **When not to use**: When using NDC rays without custom filtering logic. When training stability is critical and optimizer momentum is important.
