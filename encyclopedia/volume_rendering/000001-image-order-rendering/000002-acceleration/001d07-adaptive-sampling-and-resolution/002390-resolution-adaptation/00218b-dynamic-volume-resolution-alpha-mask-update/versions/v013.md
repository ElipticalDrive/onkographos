# Dynamic Volume Resolution & Alpha Mask Update

Also called: Dynamic Resolution and Mask Update

## Overview
This method dynamically adjusts the voxel grid resolution and the active spatial bounding box of a volume representation during training to balance memory usage and rendering fidelity. It solves the problem of inefficiently allocating resources to empty space or overly dense regions by periodically pruning the volume based on an alpha mask and upscaling the grid resolution at scheduled intervals. It differs from sibling methods like [Dynamic Resolution Adaptation](2683-dynamic-resolution-adaptation.md) by coupling resolution changes with explicit spatial culling (AABB shrinking) and optimizer reinitialization, rather than relying solely on per-pixel error metrics or fixed LOD hierarchies.

## How it works
The method operates on a periodic schedule defined by two lists of training iterations: `update_AlphaMask_list` and `upsamp_list`. It modifies the internal state of a neural volume field (e.g., a TensorF or NeRF variant) by updating the active axis-aligned bounding box (AABB), regenerating the voxel grid, and resetting the optimizer state.

### Inputs and Outputs
*   **Inputs:**
    *   `iteration`: Current training step index.
    *   `update_AlphaMask_list`: List of integers specifying iterations where the alpha mask and AABB are updated.
    *   `upsamp_list`: List of integers specifying iterations where the voxel grid resolution is increased.
    *   `reso_cur`: Current voxel grid dimensions $(res_x, res_y, res_z)$.
    *   `tensorf`: The volume field object containing parameters, AABB, and optimization state.
    *   `allrays`, `allrgbs`: Current training rays and target colors.
    *   `args`: Configuration object containing hyperparameters (see Parameters).
*   **Outputs:**
    *   Updated `tensorf` state (parameters, AABB, voxel grid).
    *   Updated `optimizer` state (learning rates, momentum buffers).
    *   Filtered `allrays`, `allrgbs` (if spatial culling is active).

### Data Structures
*   **Voxel Grid:** A 3D tensor of dimensions $(res_x, res_y, res_z)$. The method ensures the total voxel count does not exceed $256^3$ for mask generation.
*   **AABB:** A 2x3 tensor or array defining the minimum and maximum coordinates of the active volume.
*   **Optimizer:** An Adam optimizer instance. The method explicitly discards momentum states by reinitializing the optimizer.

### Parameters
*   `args.update_AlphaMask_list`: List of iteration indices.
*   `args.upsamp_list`: List of iteration indices.
*   `args.lr_upsample_reset`: Boolean. If `True`, resets learning rate to `args.lr_init` on upsample; if `False`, applies decay.
*   `args.lr_decay_target_ratio`: Float. Multiplier for LR decay if `lr_upsample_reset` is `False`.
*   `args.nSamples`: Integer. Maximum samples per ray.
*   `args.step_ratio`: Float. Controls sample density relative to resolution.
*   `args.lr_init`: Float. Initial learning rate for main parameters.
*   `args.lr_basis`: Float. Initial learning rate for basis parameters.
*   `args.ndc_ray`: Boolean. If `False`, enables ray filtering outside the bounding box.
*   `args.L1_weight_rest`: Float. L1 regularization weight applied after shrinkage.

### Algorithm Steps
1.  **Alpha Mask Update Check:** If `iteration` is in `update_AlphaMask_list`:
    *   Determine mask resolution `reso_mask`. If `reso_cur[0] * reso_cur[1] * reso_cur[2] < 256**3`, set `reso_mask = reso_cur`. Otherwise, cap `reso_mask` to maintain a maximum volume of $256^3$ voxels for the mask computation [S1, unofficial].
    *   Compute the new alpha mask and active bounding box: `new_aabb = tensorf.updateAlphaMask(tuple(reso_mask))` [S1, unofficial].
    *   Shrink the volume field to the new AABB: `tensorf.shrink(new_aabb)` [S1, unofficial].
    *   Update the L1 regularization weight: `L1_reg_weight = args.L1_weight_rest` [S1, unofficial].
    *   **Ray Filtering:** If `args.ndc_ray` is `False` and this is the second update iteration (or subsequent updates where rays may be invalid), filter rays that fall outside the new `new_aabb`:
        *   `allrays, allrgbs = tensorf.filtering_rays(allrays, allrgbs)` [S1, unofficial].
        *   Reinitialize the training sampler: `trainingSampler = SimpleSampler(allrgbs.shape[0], args.batch_size)` [S1, unofficial].
        *   [G] Note: The condition "second update iteration" implies a state check or counter is maintained externally to distinguish the first mask update from subsequent ones.

2.  **Resolution Upsampling Check:** If `iteration` is in `upsamp_list`:
    *   Pop the next target voxel count: `n_voxels = N_voxel_list.pop(0)` [S1, unofficial].
    *   Convert voxel count to grid resolution: `reso_cur = N_to_reso(n_voxels, tensorf.aabb)` [S1, unofficial].
    *   Calculate samples per ray: `nSamples = min(args.nSamples, cal_n_samples(reso_cur, args.step_ratio))` [S1, unofficial].
    *   Upsample the volume grid to the new resolution: `tensorf.upsample_volume_grid(reso_cur)` [S1, unofficial].
    *   **Learning Rate Adjustment:**
        *   If `args.lr_upsample_reset` is `True`, set `lr_scale = 1`.
        *   Else, set `lr_scale = args.lr_decay_target_ratio ** (iteration / args.n_iters)` [S1, unofficial].
    *   **Optimizer Reinitialization:**
        *   Get new parameter groups with scaled learning rates: `grad_vars = tensorf.get_optparam_groups(args.lr_init * lr_scale, args.lr_basis * lr_scale)` [S1, unofficial].
        *   Reinitialize the Adam optimizer: `optimizer = torch.optim.Adam(grad_vars, betas=(0.9, 0.99))` [S1, unofficial].

### Pseudocode
```python
def step_dynamic_resolution(tensorf, iteration, allrays, allrgbs, args, N_voxel_list):
    """
    Executes dynamic resolution and alpha mask updates for a volume field.
    
    Args:
        tensorf: The volume field object with methods updateAlphaMask, shrink, 
                 filtering_rays, upsample_volume_grid, get_optparam_groups.
        iteration: Current training step.
        allrays: Current rays tensor.
        allrgbs: Current target colors tensor.
        args: Configuration object with hyperparameters.
        N_voxel_list: List of target voxel counts for upsampling.
        
    Returns:
        updated_tensorf, updated_allrays, updated_allrgbs, updated_optimizer
    """
    optimizer = tensorf.optimizer # Assume optimizer is attached to tensorf or passed
    
    # 1. Alpha Mask Update
    if iteration in args.update_AlphaMask_list:
        # Determine mask resolution
        current_voxel_count = tensorf.reso_cur[0] * tensorf.reso_cur[1] * tensorf.reso_cur[2]
        if current_voxel_count < 256**3:
            reso_mask = tensorf.reso_cur
        else:
            # Cap mask resolution to ensure volume <= 256^3
            # Implementation detail: N_to_reso or similar logic to fit 256^3
            reso_mask = N_to_reso(256**3, tensorf.aabb)
            
        # Update alpha mask and get new AABB
        new_aabb = tensorf.updateAlphaMask(tuple(reso_mask))
        
        # Shrink volume to new AABB
        tensorf.shrink(new_aabb)
        
        # Update L1 weight
        tensorf.L1_reg_weight = args.L1_weight_rest
        
        # Ray filtering (only if NDC is not used)
        if not args.ndc_ray:
            # Filter rays outside the new bounding box
            allrays, allrgbs = tensorf.filtering_rays(allrays, allrgbs)
            # Reinitialize sampler
            trainingSampler = SimpleSampler(allrgbs.shape[0], args.batch_size)
            
    # 2. Resolution Upsampling
    if iteration in args.upsamp_list:
        if not N_voxel_list:
            raise ValueError("No more voxel counts in N_voxel_list")
            
        # Pop next target voxel count
        n_voxels = N_voxel_list.pop(0)
        
        # Convert to resolution
        reso_cur = N_to_reso(n_voxels, tensorf.aabb)
        
        # Update samples per ray
        nSamples = min(args.nSamples, cal_n_samples(reso_cur, args.step_ratio))
        
        # Upsample volume grid
        tensorf.upsample_volume_grid(reso_cur)
        
        # Calculate LR scale
        if args.lr_upsample_reset:
            lr_scale = 1.0
        else:
            lr_scale = args.lr_decay_target_ratio ** (iteration / args.n_iters)
            
        # Get new parameter groups with scaled LR
        grad_vars = tensorf.get_optparam_groups(
            args.lr_init * lr_scale, 
            args.lr_basis * lr_scale
        )
        
        # Reinitialize optimizer (discards momentum)
        optimizer = torch.optim.Adam(grad_vars, betas=(0.9, 0.99))
        
    return tensorf, allrays, allrgbs, optimizer
```

### Edge Cases and Pitfalls
*   **NDC Rays:** If `args.ndc_ray` is `True`, ray filtering is skipped. This may lead to wasted computation on empty space if the bounding box shrinks significantly, as NDC rays are not spatially bounded in the same way [S1, unofficial].
*   **Optimizer Instability:** Reinitializing the Adam optimizer discards all momentum states. This can cause training instability or require a longer warm-up period if the learning rate reset is not carefully managed [S1, unofficial].
*   **Mask Resolution Capping:** If the current resolution is very high, capping the mask resolution to $256^3$ may result in a coarse mask, potentially leaving some empty space unpruned or pruning too aggressively if the thresholding is sensitive.

## Subtopics

### [Alpha Mask Generation](3048-alpha-mask-generation.md)
Creates a binary occupancy grid from a dense density field to prune empty space. It differs by explicitly combining density thresholding with multi-scale max pooling to smooth mask boundaries before updating the active bounding box.

## Operating characteristics
*   **Time Complexity:** The alpha mask update involves a forward pass through the volume to compute occupancy, which is $O(V)$ where $V$ is the number of voxels in the mask resolution. Upsampling involves interpolating existing parameters to a new grid, also $O(V_{new})$. Ray filtering is $O(R)$ where $R$ is the number of rays.
*   **Memory Complexity:** Memory usage is dominated by the voxel grid, scaling with $res_x \times res_y \times res_z$. The method actively manages this by shrinking the AABB and capping mask resolution.
*   **Performance:** Reduces memory footprint by removing empty space. Improves training efficiency by focusing computation on active regions. However, frequent upscaling and optimizer reinitialization can increase overhead and potentially slow down convergence if not scheduled appropriately.
*   **Strengths:** Effective for scenes with large empty spaces. Simple to implement within a training loop with scheduled updates.
*   **Limitations:** Discontinuous changes in resolution and optimizer state may affect training stability. Not suitable for real-time rendering where resolution changes must be smooth and frequent.

## Background
This method is derived from implementations in Collaborative Neural Radiance Fields for Novel View Synthesis, where dynamic resolution and alpha mask updates are used to optimize the training of neural volume representations [S1, unofficial]. It builds on the principles of adaptive sampling and resolution, specifically focusing on the spatial culling aspect of resolution adaptation.
