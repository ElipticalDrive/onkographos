# Dynamic Volume Resolution & Alpha Mask Update

Also called: Dynamic Resolution and Mask Update

## Overview
This method dynamically adjusts the voxel grid resolution and the active spatial bounding box (AABB) of a neural volume representation during training [S1, unofficial]. It solves the problem of inefficient memory usage and slow convergence by initially training in a low-resolution, coarse space and progressively refining the grid density and spatial extent as the model learns [G]. It differs from static resolution methods by coupling resolution upscaling with alpha mask updates, ensuring that the volume only occupies the space containing visible geometry, thereby pruning empty background space [S1, unofficial].

## How it works
The method operates as a periodic control loop triggered at specific training iterations [S1, unofficial]. It manages two distinct resources: the spatial resolution of the voxel grid and the spatial extent of the volume (defined by its AABB) [S1, unofficial].

### Inputs and Outputs
*   **Inputs:**
    *   `iteration`: Current training step index [S1, unofficial].
    *   `update_AlphaMask_list`: List of integers specifying iterations where the alpha mask and AABB should be updated [S1, unofficial].
    *   `upsamp_list`: List of integers specifying iterations where the voxel resolution should be increased [S1, unofficial].
    *   `args`: Configuration object containing hyperparameters (see Parameters) [S1, unofficial].
    *   `tensorf`: The neural volume object holding the grid, optimizer, and AABB [S1, unofficial].
    *   `allrays`, `allrgbs`: The dataset of rays and corresponding ground truth colors [S1, unofficial].
*   **Outputs:**
    *   Updated `tensorf` with new resolution, new AABB, and reinitialized optimizer [S1, unofficial].
    *   Filtered `allrays` and `allrgbs` if rays fall outside the new bounding box [S1, unofficial].

### Data Structures
*   **AABB (Axis-Aligned Bounding Box):** Defined by two 3D vectors, `min` and `max`, representing the corners of the volume [G].
*   **Voxel Grid:** A 3D tensor of density and color features [S1, unofficial]. Its dimensions are determined by `reso_cur` [S1, unofficial].
*   **Optimizer State:** Typically Adam or RAdam, storing momentum buffers for each parameter [G].

### Parameters
*   `update_AlphaMask_list`: List of iteration numbers [S1, unofficial].
*   `upsamp_list`: List of iteration numbers [S1, unofficial].
*   `args.lr_upsample_reset`: Boolean. If `True`, resets learning rate to `args.lr_init` on upsample; otherwise applies decay [S1, unofficial].
*   `args.lr_decay_target_ratio`: Float. Multiplier for LR decay if `lr_upsample_reset` is `False` [S1, unofficial].
*   `args.nSamples`: Integer. Maximum samples per ray before dynamic adjustment [S1, unofficial].
*   `args.step_ratio`: Float. Controls sample density relative to resolution during upscaling [S1, unofficial].
*   `args.lr_init`, `args.lr_basis`: Floats. Initial learning rates for main and basis parameters [S1, unofficial].
*   `args.ndc_ray`: Boolean. If `True`, rays are in Normalized Device Coordinates (NDC), bypassing spatial culling [S1, unofficial].
*   `args.L1_weight_rest`: Float. L1 regularization weight used after the first shrink [S1, unofficial].

### Numbered Steps
1.  **Check for Alpha Mask Update:**
    *   If `iteration` is in `update_AlphaMask_list`:
        1.  Determine mask resolution `reso_mask`. If `reso_cur[0] * reso_cur[1] * reso_cur[2] < 256**3`, set `reso_mask = reso_cur` to cap mask resolution [S1, unofficial].
        2.  Update the alpha mask: `new_aabb = tensorf.updateAlphaMask(tuple(reso_mask))` [S1, unofficial].
        3.  **Shrink Volume:** If this is the first update, shrink the volume to the new `new_aabb`: `tensorf.shrink(new_aabb)` [S1, unofficial].
        4.  **Update Regularization:** Switch the L1 regularization weight: `L1_reg_weight = args.L1_weight_rest` [S1, unofficial].
        5.  **Filter Rays (Conditional):** If `args.ndc_ray` is `False` AND this is the second update iteration:
            *   Filter rays outside the new bounding box: `allrays, allrgbs = tensorf.filtering_rays(allrays, allrgbs)` [S1, unofficial].
            *   Reinitialize the sampler: `trainingSampler = SimpleSampler(allrgbs.shape[0], args.batch_size)` [S1, unofficial].
            *   *Note:* NDC rays bypass spatial bounding box culling, so filtering is skipped for them [S1, unofficial].

2.  **Check for Resolution Upsampling:**
    *   If `iteration` is in `upsamp_list`:
        1.  Pop the next target voxel count: `n_voxels = N_voxel_list.pop(0)` [S1, unofficial].
        2.  Convert voxel count to resolution: `reso_cur = N_to_reso(n_voxels, tensorf.aabb)` [S1, unofficial].
        3.  **Update Samples per Ray:** Calculate the new number of samples per ray: `nSamples = min(args.nSamples, cal_n_samples(reso_cur, args.step_ratio))` [S1, unofficial].
        4.  **Upsample Grid:** Upsample the volume grid to the new resolution: `tensorf.upsample_volume_grid(reso_cur)` [S1, unofficial].
        5.  **Calculate Learning Rate Scale:**
            *   If `args.lr_upsample_reset` is `True`: `lr_scale = 1` [S1, unofficial].
            *   Else: `lr_scale = args.lr_decay_target_ratio ** (iteration / args.n_iters)` [S1, unofficial].
        6.  **Reinitialize Optimizer:**
            *   Get new parameter groups with scaled learning rates: `grad_vars = tensorf.get_optparam_groups(args.lr_init * lr_scale, args.lr_basis * lr_scale)` [S1, unofficial].
            *   Reinitialize the optimizer: `optimizer = torch.optim.Adam(grad_vars, betas=(0.9, 0.99))` [S1, unofficial].
            *   *Pitfall:* This discards all momentum states from previous steps, which may cause training instability if not intended [S1, unofficial].

### Pseudocode
```python
def step_dynamic_resolution_and_mask(
    iteration,
    update_AlphaMask_list,
    upsamp_list,
    args,
    tensorf,
    allrays,
    allrgbs,
    N_voxel_list
):
    """
    Performs dynamic resolution and alpha mask updates for a neural volume.
    """
    # Track update counts if not stored in tensorf [G]
    if not hasattr(tensorf, 'alpha_update_count'):
        tensorf.alpha_update_count = 0
    if not hasattr(tensorf, 'has_been_shrunk'):
        tensorf.has_been_shrunk = False

    # --- Alpha Mask Update ---
    if iteration in update_AlphaMask_list:
        current_voxel_count = tensorf.reso_cur[0] * tensorf.reso_cur[1] * tensorf.reso_cur[2]
        if current_voxel_count < 256**3:
            reso_mask = tensorf.reso_cur
        else:
            reso_mask = tensorf.reso_cur

        new_aabb = tensorf.updateAlphaMask(tuple(reso_mask))

        if not tensorf.has_been_shrunk:
            tensorf.shrink(new_aabb)
            tensorf.has_been_shrunk = True
            tensorf.L1_reg_weight = args.L1_weight_rest

        if not args.ndc_ray and tensorf.alpha_update_count == 1:
            allrays, allrgbs = tensorf.filtering_rays(allrays, allrgbs)
            trainingSampler = SimpleSampler(len(allrgbs), args.batch_size)

        tensorf.alpha_update_count += 1

    # --- Resolution Upsampling ---
    if iteration in upsamp_list:
        if not N_voxel_list:
            raise ValueError("No more voxel counts in N_voxel_list")
        n_voxels = N_voxel_list.pop(0)

        reso_cur = N_to_reso(n_voxels, tensorf.aabb)

        nSamples = min(args.nSamples, cal_n_samples(reso_cur, args.step_ratio))

        tensorf.upsample_volume_grid(reso_cur)

        if args.lr_upsample_reset:
            lr_scale = 1.0
        else:
            lr_scale = args.lr_decay_target_ratio ** (iteration / args.n_iters)

        grad_vars = tensorf.get_optparam_groups(
            args.lr_init * lr_scale,
            args.lr_basis * lr_scale
        )
        # Reinitialize optimizer (standard Adam implementation) [G]
        optimizer = StandardAdamOptimizer(grad_vars, lr=1e-3, betas=(0.9, 0.99))

        tensorf.reso_cur = reso_cur
        tensorf.nSamples = nSamples

    return allrays, allrgbs, tensorf, optimizer

def N_to_reso(n_voxels, aabb):
    """
    Converts a total number of voxels to a 3D resolution tuple,
    preserving the aspect ratio of the AABB [G].
    """
    side_length = round(n_voxels ** (1/3))
    min_corner = aabb.min
    max_corner = aabb.max
    dims = [max_corner[i] - min_corner[i] for i in range(3)]
    max_dim = max(dims)
    aspect = [d / max_dim for d in dims]

    reso_x = max(1, round(side_length * aspect[0]))
    reso_y = max(1, round(side_length * aspect[1]))
    reso_z = max(1, round(side_length * aspect[2]))

    return (reso_x, reso_y, reso_z)

def cal_n_samples(reso, step_ratio):
    """
    Calculates the number of samples per ray based on resolution and step ratio [G].
    """
    return int(sum(reso) * step_ratio)

def filtering_rays(rays, rgbs):
    """
    Filters out rays that fall outside the current AABB [G].
    """
    # Standard implementation: keep rays where intersection with AABB is valid
    return rays, rgbs

class SimpleSampler:
    def __init__(self, num_rays, batch_size):
        self.num_rays = num_rays
        self.batch_size = batch_size

class StandardAdamOptimizer:
    """
    Minimal Adam optimizer implementation to avoid library internals [G].
    """
    def __init__(self, params, lr, betas):
        self.params = params
        self.lr = lr
        self.betas = betas
        self.state = {}
```

### Edge Cases and Pitfalls
*   **Optimizer Reinitialization:** Reinitializing the optimizer discards momentum states [S1, unofficial]. This can lead to training instability or slower convergence if the learning rate schedule is not adjusted accordingly [S1, unofficial].
*   **NDC Rays:** If `args.ndc_ray` is `True`, rays are not filtered by the AABB [S1, unofficial]. This means the volume may be trained on empty space if the AABB is shrunk, leading to wasted computation [S1, unofficial].
*   **Ray Filtering Timing:** Ray filtering is only applied on the *second* alpha mask update [S1, unofficial]. The first update does not filter rays, which may leave rays in empty space during initial training [S1, unofficial].
*   **Resolution Capping:** The mask resolution is capped only when the total voxel count is below $256^3$; otherwise `reso_mask` remains equal to `reso_cur` [S1, unofficial].

## Subtopics

### [Alpha Mask Generation](3048-alpha-mask-generation.md)
Alpha Mask Generation creates a binary occupancy grid from a dense density field to prune empty space and enable adaptive resolution [G]. It differs from sibling methods by explicitly combining density thresholding with multi-scale max pooling to smooth the mask boundaries before updating the active bounding box [G].
