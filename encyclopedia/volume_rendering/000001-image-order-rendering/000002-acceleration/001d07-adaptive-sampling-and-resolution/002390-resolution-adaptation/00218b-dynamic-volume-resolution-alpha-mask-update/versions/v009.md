# Dynamic Volume Resolution & Alpha Mask Update

Also called: Dynamic Resolution and Mask Update

## Overview
This method dynamically adjusts the voxel grid resolution and the active spatial bounding box of a volume representation during training to balance rendering fidelity and computational cost. It solves the problem of inefficiently sampling empty space or using excessive resolution for static background regions by periodically pruning the volume and upscaling the grid only when necessary. It differs from [Dynamic Resolution Adaptation](2683-dynamic-resolution-adaptation.md) by explicitly managing the 3D voxel grid structure and alpha masks rather than just screen-space resolution, and from [Level-of-detail (LOD) methods](1007-level-of-detail-lod-methods.md) by using a global grid upscaling strategy rather than hierarchical data structures.

## How it works
The method operates on a periodic schedule defined by two lists of training iterations: `update_AlphaMask_list` and `upsamp_list`. It modifies the underlying 3D tensor field (`tensorf`) by shrinking its active region and increasing its sampling density.

**Inputs:**
- `iteration`: Current training step.
- `args`: Configuration object containing hyperparameters.
- `tensorf`: The neural volume field object with methods `updateAlphaMask`, `shrink`, `filtering_rays`, `upsample_volume_grid`, `get_optparam_groups`, and internal attributes `aabb` (axis-aligned bounding box) and `reso_cur` (current resolution).
- `allrays`, `allrgbs`: Current training data (ray origins/directions and target colors).
- `optimizer`: Current Adam optimizer instance.

**Outputs:**
- Updated `tensorf` with new resolution and bounding box.
- Updated `optimizer` with new parameter groups and learning rates.
- Updated `allrays` and `allrgbs` filtered to the new bounding box.
- Updated `trainingSampler`.

**Data Structures:**
- `reso_cur`: A tuple `(R_x, R_y, R_z)` representing the current voxel grid resolution.
- `aabb`: A 2x3 tensor or array representing the min/max coordinates of the active volume.
- `update_AlphaMask_list`: List of integers (iterations).
- `upsamp_list`: List of integers (iterations).
- `N_voxel_list`: List of integers representing target voxel counts for upscaling steps.

**Parameters:**
- `args.update_AlphaMask_list`: List of iterations for mask updates.
- `args.upsamp_list`: List of iterations for resolution upscaling.
- `args.lr_upsample_reset`: Boolean. If `True`, resets learning rate to `args.lr_init` on upsample; otherwise applies decay.
- `args.lr_decay_target_ratio`: Float. Multiplier for LR decay if `lr_upsample_reset` is `False`.
- `args.n_iters`: Total number of training iterations.
- `args.nSamples`: Maximum samples per ray.
- `args.step_ratio`: Float. Controls sample density relative to resolution.
- `args.L1_weight_rest`: Float. L1 regularization weight for the rest of the network after shrinkage.
- `args.ndc_ray`: Boolean. If `True`, uses Normalized Device Coordinates (bypasses spatial culling).
- `args.lr_init`, `args.lr_basis`: Initial learning rates.

**Steps:**

1.  **Alpha Mask Update Phase:**
    Check if `iteration` is in `update_AlphaMask_list`. If not, skip to Step 2.
    
    1.1. **Determine Mask Resolution:**
    Calculate the current voxel count: $V_{cur} = R_x \times R_y \times R_z$.
    If $V_{cur} < 256^3$, set `reso_mask` = `reso_cur`. Otherwise, `reso_mask` is typically derived from `reso_cur` or a downsampled version (implementation detail: often `reso_mask` is set to `reso_cur` or a fixed lower bound to ensure mask stability). [S1, unofficial]
    
    1.2. **Generate Alpha Mask:**
    Call `new_aabb = tensorf.updateAlphaMask(tuple(reso_mask))`. This method computes a binary occupancy grid from the density field, thresholding empty space, and returns the new tight bounding box `new_aabb`. [S3, unofficial]
    
    1.3. **Shrink Volume:**
    Call `tensorf.shrink(new_aabb)`. This reinitializes the volume grid to the new, smaller bounding box, discarding parameters for empty space.
    
    1.4. **Update Regularization:**
    Set `L1_reg_weight = args.L1_weight_rest`. This adjusts the regularization strength for the remaining parameters. [S1, unofficial]
    
    1.5. **Filter Rays (Conditional):**
    If `args.ndc_ray` is `False` AND this is the second update iteration (or subsequent), filter rays that fall outside `new_aabb`.
    `allrays, allrgbs = tensorf.filtering_rays(allrays, allrgbs)`
    Reinitialize the sampler: `trainingSampler = SimpleSampler(allrgbs.shape[0], args.batch_size)`. [S1, unofficial]
    *Note: If `args.ndc_ray` is `True`, rays are not filtered, potentially wasting computation on empty space.* [S1, unofficial]

2.  **Resolution Upscaling Phase:**
    Check if `iteration` is in `upsamp_list`. If not, skip to Step 3.
    
    2.1. **Determine Target Resolution:**
    Pop the next target voxel count: `n_voxels = N_voxel_list.pop(0)`.
    Convert voxel count to 3D resolution: `reso_cur = N_to_reso(n_voxels, tensorf.aabb)`. This function distributes `n_voxels` evenly or according to aspect ratio across the current `aabb`. [S1, unofficial]
    
    2.2. **Adjust Samples per Ray:**
    Calculate the new number of samples per ray:
    $$nSamples = \min(\text{args.nSamples}, \text{cal\_n\_samples}(\text{reso\_cur}, \text{args.step\_ratio}))$$
    Where `cal_n_samples` likely scales the sample count based on the new resolution and step ratio to maintain visual quality. [S1, unofficial]
    
    2.3. **Upsample Volume Grid:**
    Call `tensorf.upsample_volume_grid(reso_cur)`. This interpolates the existing volume parameters to the new, higher resolution grid. [S1, unofficial]
    
    2.4. **Calculate Learning Rate Scale:**
    If `args.lr_upsample_reset` is `True`:
    $$lr\_scale = 1$$
    Else:
    $$lr\_scale = \text{args.lr\_decay\_target\_ratio}^{(\text{iteration} / \text{args.n\_iters})}$$
    [S1, unofficial]
    
    2.5. **Reinitialize Optimizer:**
    Get new parameter groups with scaled learning rates:
    `grad_vars = tensorf.get_optparam_groups(args.lr_init * lr_scale, args.lr_basis * lr_scale)`
    Reinitialize the Adam optimizer:
    `optimizer = torch.optim.Adam(grad_vars, betas=(0.9, 0.99))`
    *Note: This discards momentum states, which may cause training instability.* [S1, unofficial]

3.  **End of Step:**
    Proceed to the next training iteration.

**Pseudocode:**

```python
def dynamic_resolution_and_mask_update_step(
    iteration, args, tensorf, allrays, allrgbs, optimizer, N_voxel_list
):
    """
    Performs dynamic resolution and alpha mask updates based on iteration schedule.
    """
    
    # --- Alpha Mask Update Phase ---
    if iteration in args.update_AlphaMask_list:
        # 1. Determine mask resolution
        reso_cur = tensorf.reso_cur
        voxel_count = reso_cur[0] * reso_cur[1] * reso_cur[2]
        
        # Cap mask resolution if current volume is small
        if voxel_count < 256**3:
            reso_mask = reso_cur
        else:
            # Implementation detail: often reso_mask is reso_cur or a downsampled version
            # For this implementation, we assume reso_mask is derived from reso_cur
            # If not specified, we use reso_cur as a safe default for mask generation
            reso_mask = reso_cur 
            
        # 2. Generate Alpha Mask and get new AABB
        new_aabb = tensorf.updateAlphaMask(tuple(reso_mask))
        
        # 3. Shrink volume to new AABB
        tensorf.shrink(new_aabb)
        
        # 4. Update L1 weight
        args.L1_reg_weight = args.L1_weight_rest
        
        # 5. Filter rays if not using NDC and it's not the first update
        # Note: "second update iteration" implies a check against a counter or list index
        # Assuming a simple check: if we have filtered before, filter again.
        # For simplicity, we check if filtering has been done previously.
        if not args.ndc_ray:
            # Check if this is a subsequent update (simplified logic)
            # In practice, track if filtering has occurred
            if hasattr(tensorf, 'filtered_rays'):
                allrays, allrgbs = tensorf.filtering_rays(allrays, allrgbs)
                trainingSampler = SimpleSampler(allrgbs.shape[0], args.batch_size)
            else:
                # First update, no filtering needed if NDC is false? 
                # Or filter immediately? The source says "if not using NDC rays and it's the second update iteration"
                # So we skip filtering on the first mask update.
                pass

    # --- Resolution Upscaling Phase ---
    if iteration in args.upsamp_list:
        # 1. Pop next voxel count
        if not N_voxel_list:
            raise ValueError("No more upscaling steps defined in N_voxel_list")
        n_voxels = N_voxel_list.pop(0)
        
        # 2. Convert voxel count to resolution
        reso_cur = N_to_reso(n_voxels, tensorf.aabb)
        
        # 3. Update samples per ray
        nSamples = min(args.nSamples, cal_n_samples(reso_cur, args.step_ratio))
        
        # 4. Upsample volume grid
        tensorf.upsample_volume_grid(reso_cur)
        
        # 5. Calculate LR scale
        if args.lr_upsample_reset:
            lr_scale = 1.0
        else:
            lr_scale = args.lr_decay_target_ratio ** (iteration / args.n_iters)
        
        # 6. Reinitialize optimizer
        grad_vars = tensorf.get_optparam_groups(
            args.lr_init * lr_scale, 
            args.lr_basis * lr_scale
        )
        optimizer = torch.optim.Adam(grad_vars, betas=(0.9, 0.99))

    return allrays, allrgbs, optimizer, reso_cur
```

## Subtopics

### [Alpha Mask Generation](3048-alpha-mask-generation.md)
Creates a binary occupancy grid from a dense density field to prune empty space and enable adaptive resolution. It differs from sibling methods by explicitly combining density thresholding with multi-scale max pooling to smooth the mask boundaries before updating the active bounding box.

## Operating characteristics
- **Time Complexity:** The alpha mask update is $O(V)$ where $V$ is the number of voxels in the mask resolution. The upscaling step is $O(V_{new})$ for interpolation and reinitialization. Ray filtering is $O(N_{rays})$.
- **Memory Complexity:** The volume grid memory scales with the resolution $R^3$. Shrinking reduces memory usage, while upscaling increases it. The optimizer state is reinitialized, so memory usage remains proportional to the number of parameters.
- **Measured Performance:** Not given in the sources.
- **Scaling:** The method scales well with resolution increases, as it only upsamples when necessary. However, frequent upscaling can lead to training instability due to optimizer reinitialization.
- **Strengths:** Efficiently prunes empty space, reducing memory and computation. Allows for high-resolution rendering in complex regions.
- **Limitations:** The global upscaling strategy may not be optimal for all regions. The reinitialization of the optimizer can cause training instability. Ray filtering is not applicable for NDC rays.
- **When to use:** When the scene has large empty regions or when training a volume representation from scratch where the initial resolution is too high.
- **When not to use:** When the scene is fully dense and small, or when NDC rays are required and spatial culling is not possible.

## Background
This method is derived from implementations in Collaborative Neural Radiance Fields for Novel View Synthesis [S1, unofficial]. It builds on the principles of adaptive sampling and resolution from [Resolution Adaptation](3063-resolution-adaptation.md).
