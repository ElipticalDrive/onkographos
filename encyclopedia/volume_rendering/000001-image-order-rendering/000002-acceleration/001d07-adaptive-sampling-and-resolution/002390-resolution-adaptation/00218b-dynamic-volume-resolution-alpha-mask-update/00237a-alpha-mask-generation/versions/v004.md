# Alpha Mask Generation

Also called: Density Thresholding, TensorBase Alpha Mask Update, Alpha Mask Update & Volume Resolution Adjustment, Dense Alpha Mask Generation, getDenseAlpha, updateAlphaMask

## Overview
Alpha Mask Generation creates a binary occupancy grid from a dense density field to prune empty space and enable adaptive resolution [S3, unofficial]. It differs from sibling methods by explicitly combining density thresholding with multi-scale max pooling to smooth mask boundaries before updating the active bounding box [S3, unofficial].

## How it works
**Inputs:**
*   Dense density field (implicitly accessed via `self.compute_alpha`) [S1, unofficial].
*   Current bounding box `self.aabb` (min/max coordinates) [S1, unofficial].
*   Current resolution `reso_cur` [S1, unofficial].
*   Update schedule `update_AlphaMask_list` [S1, unofficial].
*   Grid size `gridSize` (default: `(200, 200, 200)`) [S3, unofficial].
*   Threshold `alphaMask_thres` for binarizing alpha values [S3, unofficial].

**Outputs:**
*   `AlphaGridMask` object containing the binary mask and the new active bounding box `new_aabb` [S1, unofficial].

**Data Structures:**
*   `AlphaGridMask`: Contains a 3D binary tensor (voxels) and the AABB bounds [S1, unofficial].
*   `reso_cur`: Tuple `(x, y, z)` representing current voxel counts [S1, unofficial].

**Steps:**
1.  **Initialization Check:** If the current iteration is not in `update_AlphaMask_list`, skip [S1, unofficial]. If `reso_cur[0] * reso_cur[1] * reso_cur[2] < 256^3`, set `reso_mask = reso_cur` [S1, unofficial].
2.  **Mask Update:** Call `tensorf.updateAlphaMask(tuple(reso_mask))` to obtain `new_aabb` [S1, unofficial].
3.  **Shrinkage (First Update):** If this is the first update time, call `tensorf.shrink(new_aabb)` and set `L1_reg_weight = args.L1_weight_rest` [S1, unofficial].
4.  **Coordinate Grid Generation:** Generate a 3D grid of normalized coordinates $(0 \dots 1)$ using `torch.meshgrid` with resolution `gridSize` [S1, unofficial].
5.  **World Space Mapping:** Map normalized coordinates to world space `dense_xyz` using linear interpolation between `self.aabb[0]` and `self.aabb[1]` [S1, unofficial].
6.  **Alpha Computation:** Iterate over the first dimension of the grid to compute alpha values for each slice using `self.compute_alpha` [S1, unofficial].
7.  **Smoothing (Coarse):** Apply 3D max pooling with kernel size 5 and padding 2 to the alpha values [S1, unofficial].
8.  **Thresholding:** Binarize alpha values: set to 1 if $\ge$ `alphaMask_thres`, else 0 [S3, unofficial].
9.  **Smoothing (Fine):** Apply 3D max pooling with kernel size 3 and padding 1 to the binarized mask [S3, unofficial].
10. **AABB Recalculation:** Calculate the new bounding box based on the min and max coordinates of voxels where alpha > 0.5 [S1, S3, unofficial].
11. **Finalization:** Create and return an `AlphaGridMask` object with the final mask and `new_aabb` [S1, S3, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

class AlphaGridMask:
    def __init__(self, mask, aabb):
        self.mask = mask
        self.aabb = aabb

def generate_alpha_mask(self, iteration, update_AlphaMask_list, args, grid_size=(200, 200, 200)):
    # Step 1: Check update schedule
    if iteration not in update_AlphaMask_list:
        return None

    # Step 2: Determine resolution
    voxel_count = self.reso_cur[0] * self.reso_cur[1] * self.reso_cur[2]
    if voxel_count < 256**3:
        reso_mask = self.reso_cur
    else:
        reso_mask = self.reso_cur

    # Step 3: Initial mask update to get AABB
    new_aabb = self.tensorf.updateAlphaMask(tuple(reso_mask))

    # Step 4: Handle first update shrinkage
    if iteration == update_AlphaMask_list[0]:
        self.tensorf.shrink(new_aabb)
        self.L1_reg_weight = args.L1_weight_rest

    # Step 5: Generate normalized coordinate grid
    x = torch.linspace(0, 1, grid_size[0])
    y = torch.linspace(0, 1, grid_size[1])
    z = torch.linspace(0, 1, grid_size[2])
    grid_x, grid_y, grid_z = torch.meshgrid(x, y, z, indexing='ij')
    
    # Step 6: Map to world space
    dense_xyz = torch.stack([
        grid_x * (self.aabb[1][0] - self.aabb[0][0]) + self.aabb[0][0],
        grid_y * (self.aabb[1][1] - self.aabb[0][1]) + self.aabb[0][1],
        grid_z * (self.aabb[1][2] - self.aabb[0][2]) + self.aabb[0][2]
    ], dim=-1)

    # Step 7: Compute alpha values
    alpha_values = []
    for i in range(grid_size[0]):
        slice_xyz = dense_xyz[i, :, :, :]
        alpha_slice = self.compute_alpha(slice_xyz)
        alpha_values.append(alpha_slice)
    alpha_grid = torch.stack(alpha_values, dim=0)

    # Step 8: Coarse smoothing (Kernel 5, Padding 2)
    alpha_pooled_coarse = F.max_pool3d(
        alpha_grid.unsqueeze(0).unsqueeze(0), kernel_size=5, padding=2
    ).squeeze(0).squeeze(0)

    # Step 9: Thresholding
    # [G] Default threshold not provided in sources; implementer must supply or tune.
    alphaMask_thres = 0.01
    binary_mask = (alpha_pooled_coarse >= alphaMask_thres).float()

    # Step 10: Fine smoothing (Kernel 3, Padding 1)
    binary_mask_pooled = F.max_pool3d(
        binary_mask.unsqueeze(0).unsqueeze(0), kernel_size=3, padding=1
    ).squeeze(0).squeeze(0)

    # Step 11: Recalculate AABB
    valid_voxels = torch.nonzero(binary_mask_pooled > 0.5)
    # [G] Guard against empty volume; returns None if no valid voxels exist.
    if valid_voxels.numel() == 0:
        return None

    min_idx = valid_voxels.min(dim=0)[0]
    max_idx = valid_voxels.max(dim=0)[0]
    
    new_aabb_min = torch.tensor([
        min_idx[0] / grid_size[0] * (self.aabb[1][0] - self.aabb[0][0]) + self.aabb[0][0],
        min_idx[1] / grid_size[1] * (self.aabb[1][1] - self.aabb[0][1]) + self.aabb[0][1],
        min_idx[2] / grid_size[2] * (self.aabb[1][2] - self.aabb[0][2]) + self.aabb[0][2]
    ])
    new_aabb_max = torch.tensor([
        max_idx[0] / grid_size[0] * (self.aabb[1][0] - self.aabb[0][0]) + self.aabb[0][0],
        max_idx[1] / grid_size[1] * (self.aabb[1][1] - self.aabb[0][1]) + self.aabb[0][1],
        max_idx[2] / grid_size[2] * (self.aabb[1][2] - self.aabb[0][2]) + self.aabb[0][2]
    ])
    new_aabb = (new_aabb_min, new_aabb_max)

    # Step 12: Return AlphaGridMask
    return AlphaGridMask(binary_mask_pooled, new_aabb)
```

**Parameters:**
*   `gridSize`: Resolution of the alpha mask grid. Default: `(200, 200, 200)` [S3, unofficial].
*   `alphaMask_thres`: Threshold for binarizing alpha values. Values $\ge$ this become 1, $<$ this become 0 [S3, unofficial].
*   `update_AlphaMask_list`: List of iterations at which to update the mask [S1, unofficial].

**Edge Cases:**
*   **Empty Volume:** If no voxels exceed the threshold, the mask is empty [G]. The pseudocode handles this by returning `None` if `valid_voxels` is empty [G].
*   **Small Resolution:** If `reso_cur` volume is less than $256^3$, the mask resolution is set to `reso_cur` [S1, unofficial].
*   **Precision:** Linear interpolation and thresholding are sensitive to floating-point precision. Max pooling helps mitigate noise but may blur boundaries [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** Dominated by `self.compute_alpha` calls for every voxel in the `gridSize` grid. Not given in the sources.
*   **Memory Complexity:** $O(gridSize^3)$ for storing the alpha grid and mask. Not given in the sources.
*   **Strengths:** Effectively prunes empty space, reducing rendering cost. Max pooling smooths artifacts [S3, unofficial].
*   **Limitations:** Requires full evaluation of the density field over the grid. Thresholding is static and may not adapt to complex density variations without tuning [S3, unofficial].
*   **When to Use:** Not given in the sources.
*   **When Not to Use:** Not given in the sources.
