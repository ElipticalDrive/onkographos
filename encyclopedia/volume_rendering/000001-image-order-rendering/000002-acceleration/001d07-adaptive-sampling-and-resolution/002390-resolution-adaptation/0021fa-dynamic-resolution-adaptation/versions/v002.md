# Dynamic Resolution Adaptation

Also called: ComputeReductionFactor, Frame Rate Maintenance via Resolution Adjustment

## Overview
Dynamic Resolution Adaptation is a runtime technique that adjusts the spatial resolution of the rendered viewport to maintain a target frame rate [S1, unofficial]. It solves the problem of performance instability in volume rendering, where small parametric changes (e.g., transfer function modifications) can cause frame rate dips leading to cybersickness [S1, unofficial]. It sets itself apart from static resolution schemes by continuously shifting the "anchor points" between resolution levels based on the gradient of recent frame times, rather than using fixed blending factors [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Previous frame render time ($T_{draw}$), allocated time budget for the next frame ($T_{alloc}$), and the current reduction factor ($R_{curr}$).
*   **Outputs:** A new reduction factor ($R_{new}$) in the range $(0.0, 1.0]$.

**Data Structures:**
*   $R_{curr}$: A floating-point scalar representing the current viewport reduction factor.
*   $T_{draw}$: A floating-point scalar representing the time taken to render the previous frame.
*   $T_{alloc}$: A floating-point scalar representing the target time budget per frame.

**Steps:**
1.  **Evaluate Performance:** Measure the time taken to render the previous frame, denoted as $T_{draw}$ [S1, unofficial].
2.  **Compute Target:** Determine the new reduction factor $R_{new}$ based on the ratio of the allocated time budget to the actual draw time [S1, unofficial]. The specific formula is not provided in the source, but the goal is to ensure the frame completes within $T_{alloc}$ [S1, unofficial].
3.  **Clamp:** Ensure the computed $R_{new}$ stays within the valid range $(0.0, 1.0]$ [S1, unofficial].
4.  **Apply:** Update the render viewport dimensions using $R_{new}$ for the next frame [S1, unofficial].

### [Dynamic Frame Rate Adaptation](8221-dynamic-frame-rate-adaptation.md)
Dynamic Frame Rate Adaptation is a runtime adjustment system that tracks rendering performance and adjusts the distribution of resolution levels on the fly to maintain a consistently high update rate above a set threshold. It solves the problem of performance instability in volume rendering, where small parametric changes (e.g., transfer function modifications) can cause frame rate dips leading to cybersickness. It sets itself apart from static resolution schemes by continuously shifting the "anchor points" between resolution levels based on the gradient of recent frame times, rather than using fixed blending factors.
