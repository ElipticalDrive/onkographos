# View-Dependent Adaptive Refinement

Also called: Distance-dependent Mesh Refinement, Error-based Adaptive Refinement

## Overview
View-Dependent Adaptive Refinement is a technique for displaying large-volume data at interactive frame rates by adaptively refining meshes in regions of interest (close to the viewpoint or line of sight) while using lower resolution for distant regions [S1]. Decisions on resolution levels are automatically made by applying error metrics and viewing parameters [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A multiresolution mesh hierarchy (typically tetrahedral), a viewpoint position, a maximum sight distance $d_{max}$, a maximum approximation error $E_{max}$, and a decline rate parameter $\alpha$ [S1].
*   **Output:** A refined mesh where tetrahedra are subdivided or kept coarse based on their distance-dependent error threshold [S1].

**Data Structures:**
*   **Mesh Hierarchy:** The method uses a hierarchy of tetrahedra created via longest-edge bisection [S1]. This structure supports both regular and irregular tetrahedral meshes [S1].
*   **Constraint:** The subdivision process must not generate mesh inconsistencies such as hanging nodes [S1]. The method is independent of the specific subdivision method used to create the hierarchy, provided continuity is maintained [S1].

**Algorithm Steps:**
1. Iterate over each tetrahedron $T$ in the visible region, optionally restricted to a view frustum defined by $d_{max}$ and a maximum deviation angle from the line of sight [S1].
2. Compute the distance $d(T)$ from the tetrahedron $T$ to the viewpoint [G].
3. Compute the approximation error $E(T)$ for the tetrahedron $T$ using an appropriate error metric for the scalar field [S1].
4. Compute the distance-dependent threshold.
5. If $E(T)$ exceeds the threshold, subdivide tetrahedron $T$ [S1].
6. Repeat the process iteratively until no further subdivisions are required or a maximum depth is reached [G].

**Formula:**
$$ E(T) > \frac{d(T)}{d_{max}} \alpha E_{max} $$
where $E(T)$ is the approximation error for tetrahedron $T$, $d(T)$ is the distance from $T$ to the viewpoint, $d_{max}$ is the maximum distance from the viewpoint (range of sight), $E_{max}$ is the maximum approximation error, and $\alpha$ determines how quickly resolution decreases with distance [S1].

**Parameters:**
*   $E_{max}$: Maximum approximation error. Application-specific and user-controlled [S1].
*   $d_{max}$: Maximum distance from the viewpoint (range of sight). Application-specific and user-controlled [S1].
*   $\alpha$: Parameter determining how quickly resolution decreases with distance. Typical values correspond to linear or quadratic decline [S1].

**Edge Cases and Pitfalls:**
*   **Hanging Nodes:** The subdivision method must ensure that adjacent tetrahedra do not create hanging nodes, which would break mesh continuity [S1].
*   **Frustum Restriction:** To optimize performance, subdivision can be restricted to regions within a view frustum defined by $d_{max}$ and a maximum deviation angle from the line of sight [S1].
*   **Error Metric Dependency:** The accuracy of the refinement depends on the quality of the error metric $E(T)$ used [S1].
*   **Precision and Boundaries:** The threshold scales linearly or quadratically with distance, requiring careful handling of floating-point precision near $d_{max}$ [G].
*   **Degenerate Input:** Tetrahedra with zero volume or coincident vertices must be filtered before error computation to avoid division by zero or invalid distances [G].

**Pseudocode:**
```python
def view_dependent_adaptive_refinement(tetrahedra, viewpoint, d_max, E_max, alpha):
    """
    Refines a tetrahedral mesh based on view-dependent error.
    
    Args:
        tetrahedra: List of tetrahedron objects, each with attributes:
            - error: Approximation error E(T)
            - center: Center point of the tetrahedron
        viewpoint: 3D vector representing the camera position
        d_max: Maximum distance from viewpoint (range of sight)
        E_max: Maximum approximation error threshold
        alpha: Rate of resolution decline with distance
        
    Returns:
        Refined list of tetrahedra
    """
    refined_tetrahedra = []
    for T in tetrahedra:
        # [G] Compute Euclidean distance from tetrahedron center to viewpoint
        d_T = ((T.center.x - viewpoint.x)**2 + (T.center.y - viewpoint.y)**2 + (T.center.z - viewpoint.z)**2)**0.5
        if d_T > d_max:
            refined_tetrahedra.append(T)
            continue
        E_T = T.error
        threshold = (d_T / d_max) * alpha * E_max
        if E_T > threshold:
            # [G] Subdivide T via longest-edge bisection; sources do not specify the exact implementation
            # children = T.subdivide()

            pass
        else:
            refined_tetrahedra.append(T)
    return refined_tetrahedra
```

## Subtopics

### [ROAM (Real Time Optimally Adapting Meshes)](12568-roam-real-time-optimally-adapting-meshes.md)
A view-dependent LOD algorithm that dynamically generates an optimal triangulation for terrain meshes per frame based on the camera viewpoint. It solves high CPU overhead of continuous LOD methods by using a bottom-up approach that maintains mesh continuity without global remeshing. It differs from top-down LOD methods by starting from a coarse mesh and refining only where necessary. Choose it for real-time terrain rendering where mesh continuity and low CPU overhead are prioritized.
