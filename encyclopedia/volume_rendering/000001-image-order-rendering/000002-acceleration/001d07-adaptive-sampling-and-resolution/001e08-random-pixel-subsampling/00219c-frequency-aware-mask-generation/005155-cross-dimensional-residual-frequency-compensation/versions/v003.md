# Cross-Dimensional Residual Frequency Compensation

Also called: Frequency-domain compensation scheme, High-frequency residual injection

## Overview
Cross-Dimensional Residual Frequency Compensation is a frequency-domain optimization technique designed to mitigate the inherent blurring artifacts caused by Gaussian kernels in 3D Gaussian Splatting [S1, unofficial]. It addresses the limitation of spatial-domain optimization, which struggles to fit high-frequency details, by extracting high-frequency components from the rendering residual and injecting them directly into primitive attributes [S1, unofficial].

## How it works
**Inputs and Outputs**
- **Inputs**: Ground truth image $I_{gt}$, current rendered image $I_{render}$, scaling coefficient $\lambda$, spatial weighting term $W_i$ [S1, unofficial].
- **Outputs**: Update amount $\Delta p_i$ for primitive attributes [S1, unofficial].

**Data Structures**
- $I_{gt}$: 2D tensor of ground truth pixel values [S1, unofficial].
- $I_{render}$: 2D tensor of rendered pixel values [S1, unofficial].
- $R$: Spatial residual map, computed as $I_{gt} - I_{render}$ [S1, unofficial].
- $\hat{R}_{high}$: Complex-valued frequency domain tensor representing high-frequency components [S1, unofficial].
- $\Delta p_i$: Update vector for primitive $i$ [S1, unofficial].
- Bit packing and exact memory layouts: Not given in the sources. [G]

**Numbered Steps**
1. Compute the spatial residual map $R$ by subtracting the rendered image from the ground truth image: $R = I_{gt} - I_{render}$ [S1, unofficial].
2. Transform the residual map into the frequency domain using the Fast Fourier Transform (FFT): $\hat{R} = \mathcal{F}(R)$ [S1, unofficial].
3. Apply a high-pass filter to isolate high-frequency components, resulting in $\hat{R}_{high}$: $\hat{R}_{high} = \text{HighPass}(\hat{R})$ [S1, unofficial].
4. Scale the high-frequency components by the frequency scaling coefficient $\lambda$: $\hat{R}_{scaled} = \lambda \cdot \hat{R}_{high}$ [S1, unofficial].
5. Distribute the scaled frequency energy to the spatial locations corresponding to primitive $i$ using the normalized spatial weighting term $W_i$: $\hat{U}_i = \hat{R}_{scaled} \cdot W_i$ [S1, unofficial].
6. Transform the weighted frequency update back to the spatial domain using the Inverse Fast Fourier Transform (IFFT) to calculate the update amount $\Delta p_i$: $\Delta p_i = \mathcal{F}^{-1}(\hat{U}_i)$ [S1, unofficial].
7. Apply $\Delta p_i$ to update the primitive attributes [S1, unofficial].

**Formulas**
- Residual extraction: $\hat{R}_{high} = \text{HighPass}(\mathcal{F}(I_{gt} - I_{render}))$ (9) [S1, unofficial].
- Primitive update: $\Delta p_i = \mathcal{F}^{-1}(\lambda \cdot \hat{R}_{high} \cdot W_i)$ (10) [S1, unofficial].

**Symbol Definitions**
- $I_{gt}$: Ground truth image [S1, unofficial].
- $I_{render}$: Current rendered image [S1, unofficial].
- $\mathcal{F}$: Fast Fourier Transform [S1, unofficial].
- $\mathcal{F}^{-1}$: Inverse Fast Fourier Transform [S1, unofficial].
- $\text{HighPass}(\cdot)$: High-pass filtering operation isolating fine texture details [S1, unofficial].
- $\lambda$: Frequency scaling coefficient controlling the intensity of frequency injection [S1, unofficial].
- $W_i$: Normalized spatial weighting term distributing frequency energy to corresponding spatial locations for primitive $i$ [S1, unofficial].
- $\Delta p_i$: Update amount for primitive attributes [S1, unofficial].

**Parameters**
- $\lambda$ (also referred to as $\lambda_A$ in implementation): Frequency scaling coefficient. Typical value: 1.0 [S1, unofficial]. This value balances high-frequency detail injection and numerical stability [S1, unofficial].

**Edge Cases and Pitfalls**
- **Precision**: The method relies on FFT/IFFT operations which are sensitive to numerical precision [G].
- **Boundary Conditions**: The high-pass filter must be defined to avoid removing essential low-frequency structure while targeting blurring artifacts [G].
- **Weighting Normalization**: $W_i$ must be properly normalized to ensure energy conservation during the projection back to spatial domain [G].
- **Gaussian Blurring**: The method specifically targets the inherent blurring artifacts of Gaussian kernels by injecting high-frequency energy directly into primitive attributes via frequency domain compensation [S1, unofficial].

**Pseudocode**
```python
import torch
import torch.fft

def cross_dimensional_residual_frequency_compensation(I_gt, I_render, lambda_val, W_i):
    """
    Computes the update delta_p_i for a primitive based on frequency-domain residual compensation.
    
    Args:
        I_gt (torch.Tensor): Ground truth image tensor.
        I_render (torch.Tensor): Rendered image tensor.
        lambda_val (float): Frequency scaling coefficient (e.g., 1.0).
        W_i (torch.Tensor): Normalized spatial weighting term for primitive i.
        
    Returns:
        torch.Tensor: Update amount delta_p_i.
    """
    # Step 1: Compute spatial residual
    R = I_gt - I_render
    
    # Step 2: Transform to frequency domain
    R_hat = torch.fft.fft2(R)
    
    # Step 3: Apply high-pass filter
    # The source does not specify the exact high-pass filter implementation [G].
    # A standard zero-centered high-pass mask is applied here.
    H, W = R_hat.shape[-2], R_hat.shape[-1]
    freq_h = torch.fft.fftfreq(H)
    freq_w = torch.fft.fftfreq(W)
    Freq_H, Freq_W = torch.meshgrid(freq_h, freq_w, indexing='ij')
    distance = torch.sqrt(Freq_H**2 + Freq_W**2)
    max_dist = distance.max()
    mask = (distance > 0.1 * max_dist).to(R_hat.dtype)
    R_hat_high = R_hat * mask
    
    # Step 4: Scale by lambda
    R_hat_scaled = lambda_val * R_hat_high
    
    # Step 5: Distribute energy using spatial weighting W_i
    # Formula (10) multiplies W_i directly in the frequency domain.
    U_hat_i = R_hat_scaled * W_i
    
    # Step 6: Inverse transform to spatial domain
    delta_p_i = torch.fft.ifft2(U_hat_i).real
    
    return delta_p_i
```

## Background
The method was introduced in the paper "ACE-GS: Acing the Trade-off with Accurate, Compact and Efficient 3D Gaussian Splatting" [S1, unofficial]. It is part of the ACE-GS framework, which aims to balance accuracy, compactness, and efficiency in 3D Gaussian Splatting [S1, unofficial]. The approach builds on the observation that Gaussian kernels inherently blur high-frequency details, which are difficult to optimize in the spatial domain alone [S1, unofficial]. By leveraging frequency-domain analysis, the method compensates for this limitation [S1, unofficial]. The implementation is built upon the 3DGS codebase using PyTorch [S1, unofficial].
