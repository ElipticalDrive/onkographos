# Adaptive Sampling with Monotonically Decreasing Density Function

Also called: Adaptive Sampling using f(x) = b/(1+kx), Nonlinear Adaptive Sampling

## Overview
This method determines sampling density along a ray using a monotonically decreasing function of distance from the eye, simulating photographic clarity where distant objects are vague (sparse sampling) and close objects are clear (dense sampling) [S1]. It improves upon the Weghorst et al. method by stabilizing the step calculation, preventing the under-sampling and aliasing artifacts that occur when using simple inverse distance functions [S1]. It achieves higher structural similarity (SSIM > 0.95) with significantly reduced execution time compared to uniform linear sampling [S1].

## How it works
**Inputs:**
- Ray origin and direction.
- Volumetric data dimensions and bounds in unnormalized space.
- Parameters: $k$ (slope scaler, typical ~4), $x_0$ (initial step length, typical 0.01), `Maxsteps` (max samples, typical 100), `MaxAlpha` (termination threshold, typically 1.0) [S1].

**Outputs:**
- Accumulated color $C$ for the pixel.

**Data Structures:**
- **Unnormalized Coordinate System:** The volumetric data is treated as a box where the longest edge is scaled to 1.0, and other dimensions are scaled proportionally (e.g., a $128 \times 128 \times 64$ volume becomes a $1 \times 1 \times 0.5$ box) [S1]. This prevents out-of-bound buffer reading issues common with normalized coordinates when dimensions are dissimilar [S1].

**Formulas:**
The sampling density function is defined as:
$$ f(x) = \frac{b}{1 + kx} $$
where $x$ is the distance from the eye, $b$ is a constant (fixed at 5 in experiments), and $k$ controls the slope [S1].

The condition for constant difference in sampling density between consecutive points is:
$$ f(x_i) - f(x_{i+1}) = f(x_{i+1}) - f(x_{i+2}) $$
$$ \frac{b}{1 + kx_i} - \frac{b}{1 + kx_{i+1}} = \frac{b}{1 + kx_{i+1}} - \frac{b}{1 + kx_{i+2}} $$
This implies that $f(x)$ forms an arithmetic progression with respect to the sample index, guaranteeing a fixed difference in sampling density between every two consecutive points [S1].

The direct implementation of $f(x) = 1/x$ leads to overflow when $x_i$ is too close to the current step size, causing ill-conditioned under-sampling and noise [S1]. The stabilized recurrence for the next position $x_{i+1}$ is determined by solving for the step such that the density difference is preserved, regularized by $k$ [S1]. The parameter $b$ does not influence the relative step differences, only the absolute density scale [S1].

The compositing equation is standard front-to-back:
$$ C_i = C_{i-1}(1 - \alpha(x_{i-1})) + c(x_{i-1})\alpha(x_{i-1}) $$
where $C_i$ is the accumulated color, $c(x_{i-1})$ is the color at the previous sample, and $\alpha(x_{i-1})$ is the opacity [S1].

**Pseudocode:**
```python
def render_adaptive_density(ray_origin, ray_direction, volume_bounds, k=4.0, b=5.0, initial_step=0.01, max_steps=100, max_alpha=1.0):
    # volume_bounds: (min_x, max_x, min_y, max_y, min_z, max_z) in unnormalized space
    # Ray-box intersection (slab method) to find entry and exit distances
    t_enter = -float('inf')
    t_exit = float('inf')
    for axis in range(3):
        inv_d = 1.0 / ray_direction[axis] if ray_direction[axis] != 0 else float('inf')
        t1 = (volume_bounds[axis * 2] - ray_origin[axis]) * inv_d
        t2 = (volume_bounds[axis * 2 + 1] - ray_origin[axis]) * inv_d
        t_enter = max(t_enter, min(t1, t2))
        t_exit = min(t_exit, max(t1, t2))
    if t_enter > t_exit:
        return (0.0, 0.0, 0.0)  # Ray misses volume

    current_pos = t_enter
    accumulated_color = (0.0, 0.0, 0.0)
    accumulated_alpha = 0.0

    # First step calculation to establish delta_f
    x_prev = current_pos
    x_curr = current_pos + initial_step
    f_prev = b / (1.0 + k * x_prev)
    f_curr = b / (1.0 + k * x_curr)
    delta_f = f_prev - f_curr

    for i in range(max_steps):
        # Sample volume at current position (standard trilinear interpolation)
        c, alpha = sample_volume(current_pos, volume_bounds)

        # Front-to-back compositing
        weight = alpha * (1.0 - accumulated_alpha)
        accumulated_color = (
            accumulated_color[0] + c[0] * weight,
            accumulated_color[1] + c[1] * weight,
            accumulated_color[2] + c[2] * weight
        )
        accumulated_alpha += weight

        if accumulated_alpha >= max_alpha:
            break

        # Calculate next position using constant density difference recurrence
        f_next_target = f_curr - delta_f
        if f_next_target <= 0:
            break  # Density difference condition violated or step too large

        # Solve for x_{i+1} from f(x) = b / (1 + kx)
        x_next = (b / f_next_target - 1.0) / k

        # Update for next iteration
        x_prev = x_curr
        x_curr = x_next
        f_prev = f_curr
        f_curr = b / (1.0 + k * x_curr)
        current_pos = x_curr

        if current_pos > t_exit:
            break

    return accumulated_color
```

**Edge Cases and Pitfalls:**
- **Instability of $1/x$:** Using $f(x) = 1/x$ directly causes instability and under-sampling. If $x_i$ is too close to the current step size, the next step overflows, resulting in ill-conditioned under-sampling and noise [S1].
- **Weghorst Method Limitations:** The Weghorst et al. method results in only 32 sampling points, causing visible aliasing and low SSIM (~0.5575) [S1].
- **Out-of-Bounds:** Using normalized coordinates with dissimilar dimensions can cause out-of-bound buffer reading. The unnormalized coordinate system prevents this [S1].
- **Parameter Sensitivity:** The $k$ value influences sampling quality by interfering with differences between consecutive step values. Typical optimal value is ~4 [S1]. The $b$ value does not affect the relative step differences [S1].

## Operating characteristics
- **Time Complexity:** The method reduces total sampling points compared to linear sampling. Execution time is typically < 1ms for the tested configurations, compared to > 1.6ms for linear sampling [S1].
- **Memory Complexity:** Standard volume rendering memory requirements. The unnormalized coordinate system does not add significant overhead [S1].
- **Measured Performance:** On an Intel quad-core 3.2GHz and NVIDIA GTX 1070, with $k=4$, the method achieved SSIM 0.9523, MSE 285.3498, and Time 0.908ms [S1].
- **Strengths:** High quality (SSIM > 0.95) with fewer samples than linear methods. Stable step calculation compared to $1/x$ approaches.
- **Limitations:** Requires tuning of $k$. The unnormalized coordinate system is optional but recommended for dissimilar dimensions [S1].

## Background
- **Origin:** The method is inspired by the work of Weghorst et al., which used a monotonically decreasing function for sampling [S1]. The specific modification using $f(x) = b/(1+kx)$ was applied to the Weghorst et al. method to stabilize step calculation and prevent under-sampling artifacts [S1].
- **History:** The approach was tested on ultra-sound biomicroscopic (UBM) volumetric images of monkey ciliary muscles [S1].
- **Usage:** Implemented in OpenCL kernels for GPU-based volume rendering [S1].
