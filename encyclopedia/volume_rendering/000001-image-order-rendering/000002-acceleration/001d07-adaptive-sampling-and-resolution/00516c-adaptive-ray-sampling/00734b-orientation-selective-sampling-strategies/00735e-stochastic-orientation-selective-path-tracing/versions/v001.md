# Stochastic Orientation-selective Path Tracing

Also called: Angular selectivity masking

## Overview
Stochastic Orientation-selective Path Tracing accelerates volume rendering by masking Gabor kernels based on the alignment angle between the ray direction and the kernel's frequency modulation direction [S1]. It builds on [Orientation-Selective Sampling Strategies](22709-orientation-selective-sampling-strategies.md) by applying importance sampling to angular bins, reducing the number of ray-primitive intersections per sample [S1]. Unlike deterministic pruning which culls low-contributing orientations at the cost of bias, this method stochastically selects orientations proportional to their contribution, trading increased variance for reduced traversal time [S1].

## How it works
**Inputs:** Ray direction $\vec{v}$; pre-binned Gabor kernels (grouped by orientation and frequency); bin representative orientations $\vec{k}_i$ and frequencies $f_{0,i}$.
**Outputs:** Set of primitives to intersect for the current ray.

**Data Structures:**
*   **Kernel Bins:** A list of bins. Each bin $i$ contains:
    *   `representative_orientation`: Unit vector $\vec{k}_i$ indicating the frequency modulation direction.
    *   `frequency`: Scalar $f_{0,i}$ (carrier frequency).
    *   `primitives`: List of scene primitives associated with kernels in this bin.

**Steps:**
1.  **Pre-processing:** Bin all Gabor kernels by the orientation and frequency of their modulation. Store the representative orientation $\vec{k}_i$ and frequency $f_{0,i}$ for each bin [S1].
2.  **Alignment Calculation:** For the current ray with direction $\vec{v}$, compute the alignment factor $a_i$ for each bin $i$:
    $$ a_i = |\cos \theta_i| = |\vec{v} \cdot \vec{k}_i| $$
    where $\theta_i$ is the angle between $\vec{v}$ and $\vec{k}_i$. Note that $a_i \in [0, 1]$ [S1].
3.  **Weight Calculation:** Compute the sampling weight $w_i$ for each bin based on the dampened contribution of the projected frequency:
    $$ w_i = e^{-f_{0,i}^2 a_i^2 / 2} $$
    This weight reflects the magnitude of the cosine modulation along the ray [S1].
4.  **Stochastic Selection:** Sample bins stochastically with probability proportional to $w_i$. Include the primitives in the selected bins in the set to be intersected. Bins with low weights (high alignment $a_i$ where destructive interference occurs) are less likely to be sampled [S1].
5.  **Intersection:** Perform ray-primitive intersection tests only against the primitives in the selected bins [S1].

**Pseudocode:**
```python
def select_primitives_stochastic(ray_direction, bins):
    """
    Select primitives to intersect based on stochastic orientation sampling.
    
    Args:
        ray_direction: Unit vector v.
        bins: List of dicts, each with keys 'k' (unit vector), 'f0' (float), 'primitives' (list).
        
    Returns:
        List of primitives to intersect.
    """
    weights = []
    for bin in bins:
        # Compute alignment factor a = |cos(theta)|
        # dot_product is the dot product of two vectors
        cos_theta = dot_product(ray_direction, bin['k'])
        a = abs(cos_theta)
        
        # Compute weight w = exp(-f0^2 * a^2 / 2)
        # exp is the exponential function
        w = exp(- (bin['f0'] ** 2) * (a ** 2) / 2.0)
        weights.append(w)
    
    # Normalize weights to form a probability distribution
    total_weight = sum(weights)
    if total_weight == 0:
        # Fallback: if all weights are zero (e.g., infinite frequency), 
        # sample uniformly or return empty set depending on implementation.
        # [G] Assuming uniform selection if all weights are zero.
        indices = range(len(bins))
        probabilities = [1.0 / len(bins)] * len(bins)
    else:
        probabilities = [w / total_weight for w in weights]
        indices = range(len(bins))
    
    # Stochastic selection: sample one bin index based on probabilities
    # [G] Using a standard discrete sampling method.
    selected_bin_index = sample_categorical(indices, probabilities)
    
    # Return primitives from the selected bin
    return bins[selected_bin_index]['primitives']
```

**Parameters:**
*   $f_{0,i}$: Frequency of the Gabor kernel in bin $i$. Typical values depend on the Gabor Fields asset [S1].
*   Number of bins: Determined by the pre-processing step [S1].

**Edge Cases and Pitfalls:**
*   **Parallel Rays ($a=1$):** When the ray is parallel to the frequency direction, destructive interference significantly reduces the contribution. The weight $w$ becomes $e^{-f_0^2 / 2}$, which can be very small for high frequencies, leading to low sampling probability [S1].
*   **Perpendicular Rays ($a=0$):** When the ray is perpendicular to the frequency direction, the cosine modulation contributes uniformly. The weight $w$ is $1.0$, making these bins highly likely to be sampled [S1].
*   **Precision:** Computing $a = |\cos \theta|$ requires accurate dot products. For high frequencies, the exponential decay is rapid, so small errors in $a$ can lead to large errors in weight [S1].

## Operating characteristics
*   **Time Complexity:** Reduces the number of ray-primitive intersections per sample by culling or stochastically selecting bins [S1]. The cost of computing weights is $O(B)$ where $B$ is the number of bins, which is typically small compared to the number of primitives.
*   **Memory Complexity:** Requires storing bins with representative orientations and frequencies [S1].
*   **Strengths:** Effective for high-frequency content where analytic rendering is expensive, as it reduces the number of intersections [S1].
*   **Limitations:** Introduces variance due to stochastic selection [S1]. Deterministic pruning (not this method) introduces bias [S1].
*   **When to use:** When rendering Gabor Fields with high-frequency content and performance is critical [S1].
*   **When not to use:** When low variance is required and performance is not a bottleneck, or when the scene has low-frequency content where angular selectivity is less pronounced [S1].

## Background
Originated in "Gabor Fields: Orientation-Selective Level-of-Detail for Volume Rendering" [S1]. The method exploits the angular selectivity of 3D Gabor kernels to accelerate rendering by masking kernels based on ray alignment [S1].
