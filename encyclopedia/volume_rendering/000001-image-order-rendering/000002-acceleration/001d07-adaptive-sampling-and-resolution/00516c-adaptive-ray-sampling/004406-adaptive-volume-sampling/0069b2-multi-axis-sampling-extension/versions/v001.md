# Multi-Axis Sampling Extension

Also called: Adaptive Multi-Axis Sampling for Discontinuities

## Overview
This method extends adaptive volume sampling to scenarios involving multiple sampling axes, such as 2D image grids, by using separate 1D kernels for each axis and combining gradient approximations [S1]. It solves the problem where a naive choice of a single axis risks ignoring discontinuities parallel to that axis, while multidimensional prefiltering kernels require computationally challenging $n-1$ dimensional integration [S1]. Unlike its siblings, it ensures discontinuities in any orientation can be sampled with nonzero probability by adaptively selecting the axis closest to perpendicular to the discontinuity [S1].

## How it works
**Inputs:**
- A set of $n$ sampling axes.
- A discontinuity function $d(x)$.
- Evaluation locations on the grid.

**Outputs:**
- Gradient approximations derived from the selected sampling axis.

**Data Structures:**
- The method does not define complex persistent data structures. It operates on local evaluation locations and draws samples dynamically.
- For $n$ sampling axes, the compiler draws $2n + 1$ samples per location [S1]. These samples can be potentially shared between neighboring locations [S1].

**Steps:**
1. **Quantify Discontinuity Feature:** For a discontinuity $d(x)$, calculate the feature value for each sampling axis. The feature is quantified as:
   $$ \left| \frac{dx}{d\theta} \right| $$
   This term corresponds to the denominator in the gradient approximation formula (Equation 1 in the source) [S1].

2. **Select Axis:** Choose the sampling axis that yields the largest value of $\left| \frac{dx}{d\theta} \right|$ [S1].
   - **Rationale:** A larger value in the denominator leads to approximate gradients with smaller magnitude and, consequently, smaller variance [S1].
   - **Intuition:** The chosen axis is ideally the one closest to perpendicular to the discontinuity, allowing fixed-size small steps along that axis to have a larger probability of sampling the discontinuity [S1].

3. **Sample:** Draw $2n + 1$ samples using the selected axis's 1D kernel [S1].

4. **Combine:** Combine the gradient approximations from the different sampling axes after the sampling step [S1].

**Pseudocode:**
```python
def multi_axis_sampling(discontinuity_function, axes, location):
    """
    Selects the best sampling axis for a discontinuity at a given location
    and returns the gradient approximation.
    
    Args:
        discontinuity_function: Function d(x) describing the discontinuity.
        axes: List of available sampling axes (e.g., [axis_x, axis_y]).
        location: Current evaluation point.
        
    Returns:
        gradient_approx: The computed gradient approximation.
    """
    best_axis = None
    max_feature_value = -infinity
    
    # Step 1 & 2: Quantify and Select Axis
    for axis in axes:
        # Calculate | dx / dθ | for the current axis
        # Note: The exact implementation of dx/dθ depends on the specific 
        # discontinuity function and axis definition. 
        # This is a placeholder for the derivative calculation relative to the axis.
        feature_value = compute_discontinuity_feature(discontinuity_function, axis, location)
        
        if feature_value > max_feature_value:
            max_feature_value = feature_value
            best_axis = axis
            
    # Step 3: Sample
    # Draw 2n + 1 samples along the best_axis.
    # n is the number of axes.
    n = len(axes)
    samples = draw_samples(best_axis, location, count=2*n + 1)
    
    # Step 4: Combine
    # Compute gradient approximation from samples.
    # This combines the gradient approximations from the selected axis.
    gradient_approx = compute_gradient(samples, best_axis)
    
    return gradient_approx

def compute_discontinuity_feature(discontinuity_function, axis, location):
    """
    Computes | dx / dθ | for a specific axis.
    This corresponds to the denominator in the gradient approximation formula.
    """
    # Implementation detail: This requires calculating the derivative of the 
    # discontinuity parameterization with respect to the axis direction.
    # [G] Assuming a standard parameterization where dx/dθ represents the 
    # rate of change of the discontinuity position along the axis.
    # In practice, this might be approximated by finite differences or 
    # analytical derivatives if available.
    return abs(discontinuity_function.derivative(axis, location))
```

**Edge Cases and Pitfalls:**
- **Parallel Discontinuities:** Naively choosing one axis risks ignoring discontinuities parallel to that axis, resulting in measure-zero sampling [S1]. This method mitigates this by adaptively choosing the perpendicular axis.
- **Precision:** The choice of axis depends on the magnitude of $\left| \frac{dx}{d\theta} \right|$. Small errors in this calculation could lead to suboptimal axis selection.
- **Sample Sharing:** The note mentions that samples can be shared between neighboring locations. Implementers must ensure that the sample grid is consistent across neighbors to allow this sharing, which may require careful coordinate management [S1].

## Operating characteristics
**Time and Memory Complexity:**
- The method draws $2n + 1$ samples per location for $n$ axes [S1]. This is linear in the number of axes.
- It avoids the computational burden of $n-1$ dimensional integration required by multidimensional prefiltering kernels [S1].

**Strengths and Limitations:**
- **Strengths:** Robustly samples discontinuities in any orientation without the complexity of multidimensional integration [S1]. Simpler to implement than multidimensional prefiltering [S1].
- **Limitations:** Still relies on 1D kernels, which may be less efficient than a single optimal multidimensional kernel if one could be computed cheaply [S1]. The adaptive choice requires calculating the discontinuity feature for all axes.

**When to Use:**
- Use when dealing with multiple sampling axes (e.g., 2D image grids) and discontinuities that may be parallel to any of the axes [S1].
- Use when multidimensional prefiltering is too computationally expensive [S1].

**When Not to Use:**
- If only a single sampling axis is available, this extension is not applicable.
- If the discontinuity is known to be aligned with a specific axis and that axis is always chosen, the adaptive overhead may be unnecessary.

## Background
**Origin:**
- The method is described in the paper "A $\delta$" [S1].
- It extends the techniques discussed in Section 4.2 of the source to handle multiple sampling axes [S1].

**History and Development:**
- The problem of handling multiple sampling axes arises in shader applications where the program is evaluated on a multi-dimensional grid [S1].
- Previous approaches included naively choosing one axis (risking missed discontinuities) or using multidimensional prefiltering kernels (requiring challenging integration) [S1].
- The multi-axis extension was proposed as a simpler alternative to multidimensional prefiltering, using separate 1D kernels and adaptive selection [S1].

**Usage:**
- Used in volume rendering and shader applications where discontinuities need to be sampled robustly across multiple dimensions [S1].
