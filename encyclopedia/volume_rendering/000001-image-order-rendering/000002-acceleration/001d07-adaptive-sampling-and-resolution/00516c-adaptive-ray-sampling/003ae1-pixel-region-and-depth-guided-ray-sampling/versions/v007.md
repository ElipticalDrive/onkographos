# Pixel Region and Depth Guided Ray Sampling


## Overview
Pixel Region and Depth Guided Ray Sampling is a training-time ray sampling strategy that increases sampling probability in pixel areas exhibiting significant color and depth variation, thereby reducing redundant rays in flat regions to accelerate network convergence and improve geometry perception [S1]. Unlike conventional NeRF which uses uniform distribution, this method samples varying ray densities based on depth boundaries and pixel regions to simultaneously accelerate convergence and improve geometry perception [S1]. It is distinct from sibling methods like [Mip-NeRF 360 Sampling and Training](3393-mip-nerf-360-sampling-and-training.md) which focuses on cone-based anti-aliasing, and [Truncated Depth-Based Sampling](10613-truncated-depth-based-sampling.md) which focuses on surface proximity; instead, it explicitly combines 2D color variance and 3D depth estimates to guide ray density [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of $N$ source training images $I_i$ with known camera poses; a pre-trained or concurrently trained depth estimation module (specifically from the ENeRF framework) that provides rough depth information and a cost volume for each pixel [S1].
*   **Outputs:** A set of sampled rays $\mathbb{R}_i$ for each image $I_i$, where the number of rays $M$ is fixed per image but their spatial distribution is non-uniform, biased toward high-variance regions [S1].

**Data Structures:**
*   **Depth Map $D_i$:** A 2D array of size $H_i \times W_i$ containing estimated depth values for each pixel $(u, v)$ in image $I_i$, derived from the ENeRF cost volume [S1].
*   **Color Image $I_i$:** A 2D array of size $H_i \times W_i$ containing RGB values for each pixel [S1].
*   **Sampling Probability Map $P_i$:** A 2D array of size $H_i \times W_i$ where $P_i(u, v) \in [0, 1]$ represents the probability of casting a ray through pixel $(u, v)$ [S1].

**Numbered Steps:**
1.  **Depth Estimation:** Obtain the rough depth map $D_i$ for each source image $I_i$ using the depth estimation module from the ENeRF framework [S1]. This module leverages the cost volume to provide depth information for each pixel [S1].
2.  **Probability Calculation:** Calculate the sampling probability $P_i(u, v)$ for each pixel $(u, v)$ based on two factors:
    *   **Color Variation:** Measure the local color variance or gradient magnitude at $(u, v)$. High variation indicates texture or edges, requiring more samples [S1].
    *   **Depth Variation:** Measure the local depth variance or gradient magnitude in $D_i$ at $(u, v)$. High variation indicates depth discontinuities or geometric complexity, requiring more samples [S1].
    *   The final probability $P_i(u, v)$ is a function of these two variation metrics. While the exact normalization formula is not explicitly detailed in the source, the logic dictates that pixels with high color or depth variation have higher $P_i(u, v)$ [S1].
3.  **Ray Sampling:** For each image $I_i$, select $M$ pixels to cast rays from. The selection is performed by sampling $M$ pixels $(u, v)$ from the distribution defined by $P_i$. This means additional rays are sampled in pixel areas exhibiting substantial color variation and regions where geometric depth varies markedly [S1].
4.  **Volume Rendering:** For each sampled ray $r_i^k$, sample points along the ray and evaluate the neural radiance field network $F_\Theta$ to obtain density $\sigma$ and color $c$. Perform volume rendering to output the predicted color $\hat{c}_i^k$ [S1].
5.  **Loss Computation:** Compute the volume rendering loss $\mathcal{L}$ by comparing the predicted colors $\hat{c}_i^k$ with the true colors $c_i^k$ of the source images [S1].

**Formulas:**
The optimization goal minimizes the volume rendering loss [S1]:
$$
\min_{\Theta} \mathcal{L} = \frac{1}{NM} \sum_{r_i^k \in \mathbb{R}_i} \|V_{\Theta}(r_i^k) - c_i^k\|_2^2
$$
where:
*   $\Theta$: Network parameters.
*   $N$: Number of trained images (source views) [S1].
*   $M$: Number of sampled rays per image [S1].
*   $r_i^k$: The $k$-th ray sampled from the $i$-th training image $I_i$ [S1].
*   $\mathbb{R}_i$: The set of $M$ rays sampled from image $I_i$ [S1].
*   $V_{\Theta}(r_i^k)$: The volume rendering function outputting the predicted color for ray $r_i^k$ [S1].
*   $c_i^k$: The true color of the pixel corresponding to ray $r_i^k$ [S1].

For comparison, uniform ray sampling assumes rays follow a uniform distribution [S1]:
$$
r_i(u, v) \sim U(I_i), \quad u \in [0, H_i], v \in [0, W_i]
$$
where $H_i$ and $W_i$ are the height and width of image $I_i$ [S1].

**Parameters:**
*   $N$: The number of trained images (source views). Typical values depend on the dataset (e.g., 20-100 for standard NeRF datasets) [S1].
*   $M$: The number of sampled rays per image. This is a hyperparameter controlling the total computational budget per iteration [S1].
*   $\Theta$: The network parameters optimized by minimizing the color error [S1].

**Edge Cases and Pitfalls:**
*   **Depth Estimation Errors:** If the depth estimation module from ENeRF provides inaccurate depth maps, the depth-guided sampling may incorrectly target empty space or miss actual geometry, leading to inefficient sampling or artifacts [S1].
*   **Flat Regions:** In regions with low color and depth variation, the probability $P_i(u, v)$ will be low. If $M$ is too small, these regions might be undersampled, potentially causing blurring or lack of detail in smooth areas [S1].
*   **Initialization:** The method relies on the ENeRF depth estimation module. If this module is not initialized or trained concurrently, the initial depth maps may be noisy, affecting early training steps [S1].

**Pseudocode:**
```python
def pixel_region_depth_guided_sampling(I, depth_map, M):
    """
    I: Input image (H, W, 3)
    depth_map: Estimated depth map (H, W)
    M: Number of rays to sample per image
    Returns: List of pixel coordinates (u, v) to cast rays from
    """
    H, W, _ = I.shape
    
    # Calculate color variance/gradient
    # Using Sobel filters to estimate color magnitude
    gray = np.mean(I, axis=2)
    grad_x = np.abs(sobel(gray, axis=1))
    grad_y = np.abs(sobel(gray, axis=0))
    color_var = grad_x + grad_y
    
    # Calculate depth variance/gradient
    depth_grad_x = np.abs(sobel(depth_map, axis=1))
    depth_grad_y = np.abs(sobel(depth_map, axis=0))
    depth_var = depth_grad_x + depth_grad_y
    
    # Combine color and depth variation to form probability map
    # Normalize to [0, 1]
    combined_var = color_var + depth_var
    max_var = np.max(combined_var)
    if max_var > 0:
        prob_map = combined_var / max_var
    else:
        prob_map = np.zeros((H, W))
        
    # Flatten probability map
    flat_prob = prob_map.flatten()
    flat_prob = flat_prob / np.sum(flat_prob) # Ensure it sums to 1
    
    # Sample M pixels based on probability
    indices = np.random.choice(H * W, size=M, replace=False, p=flat_prob)
    
    # Convert flat indices to (u, v) coordinates
    u_coords = indices // W
    v_coords = indices % W
    
    return list(zip(u_coords, v_coords))
```
[G] The pseudocode uses standard numpy/scipy operations for Sobel filtering and random sampling, which are assumed to be available in the implementation environment. The exact combination of color and depth variation is assumed to be additive as per the description "based on its color value and the estimated depth information" [S1].

## Subtopics

### Superpixel-based Efficient Sampling
A sampling method for learning neural fields from large input images that optimizes pixel-level ray sampling by segmenting the error map into superpixels and dynamically updating their errors to increase ray sampling in areas with higher rendering errors [S2]. Unlike quadtree or fixed-shape patch sampling methods which may cause fragmented image information, superpixels reduce redundancy while considering local information [S2]. Unlike color-guided ray sampling which does not simultaneously consider rendering errors, SES uses rendering errors to guide sampling [S2]. It segments the input image into various superpixels using the SLIC algorithm, where each superpixel represents unique local information [S2]. It treats superpixels as the smallest processing unit for sampling decisions, setting different sampling probabilities for various superpixels based on their rendering errors, and continuously updates the superpixel errors during the training process [S2].

## Operating characteristics
*   **Time Complexity:** The sampling step itself is $O(H \times W)$ to compute the probability map, but the dominant cost remains the neural network evaluations for the $M$ sampled rays. By reducing redundant rays in flat regions, the effective number of expensive MLP evaluations is reduced compared to uniform sampling for the same visual quality, accelerating convergence [S1].
*   **Memory Complexity:** Requires storing the depth map $D_i$ ($H \times W$) and the probability map $P_i$ ($H \times W$) for each image during training [S1].
*   **Measured Performance:** Applied to the ENeRF framework, this method achieves state-of-the-art performance on both view synthesis and training time, enabling faster per-scene optimization and achieving the same convergence effect in minutes through fine-tuning reconstructions from given views [S1].
*   **Strengths:** Accelerates network convergence; improves geometry perception, especially for rich-texture regions; reduces redundant rays in flat areas [S1].
*   **Limitations:** Relies on the accuracy of the depth estimation module (ENeRF); may undersample flat regions if $M$ is too low; requires additional computation to estimate depth and calculate probabilities [S1].
*   **When to use:** When training time is a bottleneck and the scene has significant texture and geometric complexity; when using the ENeRF framework or similar depth-aware architectures [S1].
*   **When not to use:** When depth estimation is unreliable or unavailable; when the scene is very simple and uniform sampling is sufficient; when computational resources for depth estimation are limited [S1].

## Background
The method was introduced in the paper "Efficient ray sampling for radiance fields reconstruction" [S1]. It builds on the ENeRF framework [S1], which uses a cost volume for depth estimation. The authors observed that uniform ray sampling fails to capture the non-uniform distribution of color differences and depth boundaries in real-world scenes, leading to redundant sampling in flat regions [S1]. The method was applied to the ENeRF framework to achieve state-of-the-art performance on view synthesis and training time [S1].
