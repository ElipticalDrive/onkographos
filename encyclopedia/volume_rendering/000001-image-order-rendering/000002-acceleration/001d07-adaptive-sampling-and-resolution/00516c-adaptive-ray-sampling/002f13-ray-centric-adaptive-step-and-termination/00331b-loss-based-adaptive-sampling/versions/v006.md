# Loss-based Adaptive Sampling

Also called: Grid-based Loss Sampling

## Overview
Loss-based Adaptive Sampling is a ray sampling strategy that allocates more samples to image regions exhibiting higher rendering loss, thereby prioritizing areas with inadequate convergence or high-frequency detail [S1]. It partitions the image into a fixed 8×8 spatial grid to compute local loss statistics per region [S1]. This approach concentrates computational resources on regions with drastic color or depth changes, accelerating training convergence for radiance fields [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of source views; a current neural radiance field model; a total sample count per image $n_i$ [S1].
*   **Output:** A set of sampled pixels (rays) for the next training iteration, weighted by region loss [S1].

**Data Structures:**
*   **Grid:** The image is partitioned into $G \times G$ regions, where $G=8$, resulting in 64 regions $R_j$ ($j=1 \dots 64$) [S1].
*   **Loss Statistics:** A vector $\mathcal{H}_i$ of size 64, storing the mean loss per region for iteration $i$ [S1].
*   **Probability Distribution:** A vector $f_i$ of size 64, storing the normalized sampling probability for each region [S1].

**Parameters:**
*   **Grid Size:** $8 \times 8$ (64 regions) [S1].
*   **$n_i$:** Total number of pixels to sample per image for the next iteration [S1].
*   **Loss Components:** Gradient loss $e_i^g$ and pixel loss $e_i^p$ [S1].

**Steps:**
1.  **Uniform Sampling:** Randomly sample a uniform distribution of pixels $s_i$ from the input source views [S1].
2.  **Loss Computation:** For each region $R_j$, compute the mean loss $\mathcal{H}_i[j]$ using the pixels $r_j$ uniformly sampled from that region ($r_j = s_i \cap R_j$) [S1]. The loss is the sum of gradient and pixel losses:
    $$ \mathcal{H}_i[j] = \frac{1}{|r_j|} \sum_{(u,v) \in r_j} e_i^g[u, v] + e_i^p[u, v] $$
    where $|r_j|$ is the number of sampled pixels in region $R_j$ [S1].
3.  **Normalization:** Normalize the region losses into a probability distribution $f_i$:
    $$ f_i[j] = \frac{\mathcal{H}_i[j]}{\sum_{m=1}^{64} \mathcal{H}_i[m]} $$
    [S1].
4.  **Resampling:** Allocate $n_i \cdot f_i[j]$ samples to each region $R_j$ for the next iteration, ensuring regions with higher loss receive more samples [S1].

**Pseudocode:**
```python
import random

def loss_based_adaptive_sampling(image_width, image_height, grid_size=8, total_samples_ni=1000):
    """
    Implements Loss-based Adaptive Sampling.
    Args:
        image_width (int): Width of the source images.
        image_height (int): Height of the source images.
        grid_size (int): Size of the grid (default 8, resulting in 64 regions).
        total_samples_ni (int): Total number of samples to allocate per image.
    Returns:
        list: A list of sampled pixel coordinates (u, v) for the next iteration.
    """
    # Step 1: Uniform Sampling
    # Randomly sample a uniform distribution of pixels s_i from the input source views [S1].
    uniform_samples = []
    for _ in range(total_samples_ni):
        u = random.randint(0, image_width - 1)
        v = random.randint(0, image_height - 1)
        uniform_samples.append((u, v))

    # Step 2: Loss Computation
    # Partition image into grid_size x grid_size regions R_j [S1].
    region_loss_sum = [0.0] * (grid_size * grid_size)
    region_pixel_count = [0] * (grid_size * grid_size)

    for (u, v) in uniform_samples:
        # Determine region index j
        row = min(v // (image_height // grid_size), grid_size - 1)
        col = min(u // (image_width // grid_size), grid_size - 1)
        j = row * grid_size + col

        # [G] Standard rendering and loss computation steps
        rendered_color = render_pixel(u, v)
        ground_truth_color = get_ground_truth(u, v)
        pixel_loss = compute_pixel_loss(rendered_color, ground_truth_color)
        gradient_loss = compute_gradient_loss(rendered_color, ground_truth_color)

        region_loss_sum[j] += pixel_loss + gradient_loss
        region_pixel_count[j] += 1

    # Calculate mean loss per region H_i[j]
    mean_region_loss = []
    for j in range(grid_size * grid_size):
        if region_pixel_count[j] > 0:
            mean_region_loss.append(region_loss_sum[j] / region_pixel_count[j])
        else:
            mean_region_loss.append(0.0)  # [G] Guard for empty regions

    # Step 3: Normalization
    # Normalize region losses into probability distribution f_i[j] [S1]
    total_loss = sum(mean_region_loss)
    if total_loss == 0:
        prob_distribution = [1.0 / (grid_size * grid_size)] * (grid_size * grid_size)  # [G] Uniform fallback
    else:
        prob_distribution = [loss / total_loss for loss in mean_region_loss]

    # Step 4: Resampling
    # Allocate n_i * f_i[j] samples to each region R_j for the next iteration [S1]
    sampled_pixels = []
    for j in range(grid_size * grid_size):
        num_samples = int(round(total_samples_ni * prob_distribution[j]))
        row = j // grid_size
        col = j % grid_size
        y_min = row * (image_height // grid_size)
        y_max = (row + 1) * (image_height // grid_size)
        x_min = col * (image_width // grid_size)
        x_max = (col + 1) * (image_width // grid_size)

        for _ in range(num_samples):
            u = random.randint(x_min, x_max - 1)
            v = random.randint(y_min, y_max - 1)
            sampled_pixels.append((u, v))

    return sampled_pixels
```

**Edge Cases and Pitfalls:**
*   **Empty Regions:** If a region $R_j$ has no uniformly sampled pixels ($|r_j|=0$), the mean loss is undefined [G]. The implementation assigns a default loss of zero to prevent division by zero [G].
*   **Zero Total Loss:** If all region losses are zero, the probability distribution is undefined [G]. A uniform fallback distribution is applied [G].
*   **Precision:** Ensure that the loss calculation is stable and does not suffer from numerical underflow or overflow, especially when summing over many pixels [G].

## Subtopics

### [Patch-based Ray Sampling](11953-patch-based-ray-sampling.md)
Groups rays into spatially adjacent 2D patches to enforce local spatial coherence for local-structure losses like DWT loss. Chosen when local texture coherence is critical.

### [Error-Guided Adaptive Sampling (Bubbling)](17132-error-guided-adaptive-sampling-bubbling.md)
Maintains a continuous PDF map updated iteratively per image, pruning low-error pixels. Chosen for dynamic scene reconstruction focusing on thin geometry.

## Background
Originating from the Nice-SLAM paper (2021) and detailed in subsequent works like "Efficient ray sampling for radiance fields reconstruction" (2023), this method draws analogy to sample mining in conventional deep learning [S1]. It addresses the slow fitting efficiency in regions with high-frequency details in NeRF models [S1].
