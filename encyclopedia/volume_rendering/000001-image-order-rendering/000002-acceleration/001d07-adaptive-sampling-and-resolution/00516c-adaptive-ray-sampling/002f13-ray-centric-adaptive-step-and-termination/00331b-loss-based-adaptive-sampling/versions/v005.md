# Loss-based Adaptive Sampling

Also called: Grid-based Loss Sampling

## Overview
Loss-based Adaptive Sampling is a ray sampling strategy that allocates more samples to image regions exhibiting higher rendering loss, thereby prioritizing areas with inadequate convergence or high-frequency detail [S1]. It distinguishes itself from sibling methods by partitioning the image into a fixed spatial grid (typically 8x8) to compute local loss statistics, rather than using random global sampling or continuous probability density functions [S1]. This approach ensures that computational resources are concentrated on regions with drastic color or depth changes, accelerating training convergence for radiance fields [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of source views; a current neural radiance field model; a total sample count per image $n_i$.
*   **Output:** A set of sampled pixels (rays) for the next training iteration, weighted by region loss.

**Data Structures:**
*   **Grid:** The image is partitioned into $G \times G$ regions, where $G=8$, resulting in 64 regions $R_j$ ($j=1 \dots 64$) [S1].
*   **Loss Statistics:** A vector $\mathcal{H}_i$ of size 64, storing the mean loss per region for iteration $i$ [S1].
*   **Probability Distribution:** A vector $f_i$ of size 64, storing the normalized sampling probability for each region [S1].

**Parameters:**
*   **Grid Size:** $8 \times 8$ (64 regions) [S1].
*   **$n_i$:** Total number of pixels to sample per image for the next iteration [S1].
*   **Loss Components:** Gradient loss $e_i^g$ and pixel loss $e_i^p$ [S1].

**Steps:**
1.  **Uniform Sampling:** Randomly sample a uniform distribution of pixels $s_i$ from the input source views [S1].
2.  **Loss Computation:** For each region $R_j$, compute the mean loss $\mathcal{H}_i[j]$ using the pixels $r_j$ uniformly sampled from that region ($r_j = s_i \cap R_j$) [S1]. The loss is the sum of gradient and pixel losses:
    $$ \mathcal{H}_i[j] = \frac{1}{|r_j|} \sum_{(u,v) \in r_j} e_i^g[u, v] + e_i^p[u, v] $$
    where $|r_j|$ is the number of sampled pixels in region $R_j$ [S1].
3.  **Normalization:** Normalize the region losses into a probability distribution $f_i$:
    $$ f_i[j] = \frac{\mathcal{H}_i[j]}{\sum_{m=1}^{64} \mathcal{H}_i[m]} $$
    [S1].
4.  **Resampling:** Allocate $n_i \cdot f_i[j]$ samples to each region $R_j$ for the next iteration, ensuring regions with higher loss receive more samples [S1].

**Pseudocode:**
```python
def loss_based_adaptive_sampling(image_width, image_height, grid_size=8, total_samples_ni, source_views, model):
    """
    Implements Loss-based Adaptive Sampling.
    
    Args:
        image_width (int): Width of the source images.
        image_height (int): Height of the source images.
        grid_size (int): Size of the grid (default 8, resulting in 64 regions).
        total_samples_ni (int): Total number of samples to allocate per image.
        source_views (list): List of source view images or camera parameters.
        model: The neural radiance field model used to compute loss.
        
    Returns:
        list: A list of sampled pixel coordinates (u, v) for the next iteration.
    """
    # Step 1: Uniform Sampling
    # Randomly sample a uniform distribution of pixels s_i from source views.
    # For simplicity, assume we sample uniformly across the image grid.
    # In practice, this might involve selecting random pixels from available source views.
    uniform_samples = []
    # Example: Sample N_uniform pixels uniformly across the image
    N_uniform = 1000 # Placeholder for sufficient initial coverage
    for _ in range(N_uniform):
        u = random.randint(0, image_width - 1)
        v = random.randint(0, image_height - 1)
        uniform_samples.append((u, v))
        
    # Step 2: Loss Computation
    # Partition image into grid_size x grid_size regions
    region_loss = [0.0] * (grid_size * grid_size)
    region_pixel_count = [0] * (grid_size * grid_size)
    
    for (u, v) in uniform_samples:
        # Determine region index j
        j = (v // (image_height // grid_size)) * grid_size + (u // (image_width // grid_size))
        
        # Compute loss for this pixel
        # e_i^g: gradient loss, e_i^p: pixel loss
        # This requires rendering the pixel and comparing with ground truth
        rendered_color, gradient = model.render(u, v, source_views)
        ground_truth_color = get_ground_truth(u, v, source_views) # [G] Helper to get GT
        
        pixel_loss = compute_pixel_loss(rendered_color, ground_truth_color)
        gradient_loss = compute_gradient_loss(gradient, ground_truth_color) # [G] Helper
        
        region_loss[j] += pixel_loss + gradient_loss
        region_pixel_count[j] += 1
        
    # Calculate mean loss per region
    mean_region_loss = []
    for j in range(grid_size * grid_size):
        if region_pixel_count[j] > 0:
            mean_region_loss.append(region_loss[j] / region_pixel_count[j])
        else:
            mean_region_loss.append(0.0) # [G] Avoid division by zero; regions with no samples get 0 loss
            
    # Step 3: Normalization
    # Normalize into probability distribution f_i
    total_loss = sum(mean_region_loss)
    if total_loss == 0:
        # Fallback to uniform if all losses are zero
        prob_distribution = [1.0 / (grid_size * grid_size)] * (grid_size * grid_size)
    else:
        prob_distribution = [loss / total_loss for loss in mean_region_loss]
        
    # Step 4: Resampling
    # Allocate n_i * f_i[j] samples to each region
    sampled_pixels = []
    for j in range(grid_size * grid_size):
        # Number of samples for this region
        num_samples = int(round(total_samples_ni * prob_distribution[j]))
        
        # Determine region boundaries
        row = j // grid_size
        col = j % grid_size
        y_min = row * (image_height // grid_size)
        y_max = (row + 1) * (image_height // grid_size)
        x_min = col * (image_width // grid_size)
        x_max = (col + 1) * (image_width // grid_size)
        
        # Uniformly sample within the region
        for _ in range(num_samples):
            u = random.randint(x_min, x_max - 1)
            v = random.randint(y_min, y_max - 1)
            sampled_pixels.append((u, v))
            
    return sampled_pixels
```

**Edge Cases and Pitfalls:**
*   **Empty Regions:** If a region $R_j$ has no uniformly sampled pixels ($|r_j|=0$), the mean loss is undefined. The implementation must handle this, e.g., by assigning a default loss or skipping the region [G].
*   **Zero Total Loss:** If all region losses are zero, the probability distribution is undefined. A uniform fallback should be used [G].
*   **Precision:** Ensure that the loss calculation is stable and does not suffer from numerical underflow/overflow, especially when summing over many pixels [G].

## Subtopics

### [Patch-based Ray Sampling](11953-patch-based-ray-sampling.md)
Groups rays into spatially adjacent 2D patches to enforce local spatial coherence for local-structure losses like DWT loss. Chosen when local texture coherence is critical.

### [Error-Guided Adaptive Sampling (Bubbling)](17132-error-guided-adaptive-sampling-bubbling.md)
Maintains a continuous PDF map updated iteratively per image, pruning low-error pixels. Chosen for dynamic scene reconstruction focusing on thin geometry.

## Operating characteristics
*   **Time Complexity:** The method requires an initial uniform sampling pass to compute loss statistics, followed by a resampling step. The complexity is dominated by the loss computation for the initial samples.
*   **Memory Complexity:** Requires storing loss statistics for each grid region (constant space relative to image resolution, proportional to grid size squared).
*   **Performance:** Improves training convergence by focusing on high-loss regions, particularly those with drastic color or depth changes [S1].
*   **Strengths:** Simple to implement; effectively targets areas of high detail or error.
*   **Limitations:** Relies on a fixed grid, which may not adapt well to arbitrarily shaped high-error regions; requires an initial uniform sampling pass.

## Background
Originating from the Nice-SLAM paper (2021) and detailed in subsequent works like "Efficient ray sampling for radiance fields reconstruction" (2023), this method draws analogy to sample mining in conventional deep learning [S1]. It addresses the slow fitting efficiency in regions with high-frequency details in NeRF models [S1].
