# Loss-based Adaptive Sampling

Also called: Grid-based Loss Sampling

## Overview
Loss-based Adaptive Sampling is a training-phase strategy that dynamically adjusts ray sampling density based on reconstruction error, specifically targeting missing or thin geometry during the 'bubble' step [S2]. It partitions the image into a fixed grid (e.g., 8x8) to compute mean loss per region, normalizing these into a probability distribution to resample pixels [S1]. This method differs from sibling methods like [Adaptive Sampling](1385-adaptive-sampling.md) by operating on a coarse spatial grid of regions rather than individual pixels or rays, and from [Adaptive Sampling Step with Early Ray Termination](4573-adaptive-sampling-step-with-early-ray-termination.md) by focusing on training convergence rather than inference-time ray traversal optimization.

## How it works
**Inputs:**
*   Current network parameters and state.
*   Input source views (images).
*   Total sample count per image $n_i$.
*   Grid dimensions (typically 8x8, yielding 64 regions).
*   Pruning threshold $P_{min}$ (typically 0.05) [S2].

**Outputs:**
*   A set of resampled pixels/regions for the next training iteration.
*   Updated Probability Density Function (PDF) map.

**Data Structures:**
*   **Region Loss Map:** An array of size $N_{regions}$ (e.g., 64) storing $\mathcal{H}_i[j]$.
*   **PDF Map:** An array of size $N_{regions}$ storing $f_i[j]$.
*   **Pixel Set:** A list of $(u, v)$ coordinates for the current batch.

**Steps:**

1.  **Uniform Sampling:** Randomly sample a uniform distribution of pixels $s_i$ from the input source views [S1].
2.  **Grid Partitioning:** Partition the image into a grid of $N_{regions}$ square regions $R_j$ (where $j=1 \dots 64$) [S1].
3.  **Loss Computation:** For each region $R_j$, compute the mean loss $\mathcal{H}_i[j]$ using the pixels $r_j$ uniformly sampled from that region ($r_j = s_i \cap R_j$) [S1]:
    $$ \mathcal{H}_i[j] = \frac{1}{|r_j|} \sum_{(u,v) \in r_j} e_i^g[u, v] + e_i^p[u, v] $$
    where $e_i^g$ is the gradient loss and $e_i^p$ is the pixel loss [S1].
4.  **Normalization:** Normalize the region losses into a probability distribution $f_i[j]$ [S1]:
    $$ f_i[j] = \frac{\mathcal{H}_i[j]}{\sum_{m=1}^{N_{regions}} \mathcal{H}_i[m]} $$
5.  **Pruning (Optional/Phase-Dependent):** During specific training phases (e.g., the 'bubble' step), apply a pruning threshold $P_{min}$ to filter low-error samples. If $f_i[j] < P_{min}$, the region may be excluded or its weight reduced to 0 if the geometry is well-reconstructed (e.g., light balls) [S2].
6.  **Resampling:** Allocate $n_i \cdot f_i[j]$ samples to each region $R_j$ for the next iteration. This allocates more samples to areas exhibiting elevated loss [S1].

**Pseudocode:**

```python
def loss_based_adaptive_sampling(image, network, n_i, grid_size=8, p_min=0.05):
    """
    Performs loss-based adaptive sampling for a single training step.
    
    Args:
        image: Input source view image.
        network: Current neural network state.
        n_i: Total sample count per image.
        grid_size: Dimension of the grid (e.g., 8 for 8x8).
        p_min: Pruning threshold for low-error regions.
        
    Returns:
        sampled_pixels: List of (u, v) coordinates for the next batch.
        pdf_map: Normalized probability distribution over regions.
    """
    num_regions = grid_size * grid_size
    region_losses = [0.0] * num_regions
    region_counts = [0] * num_regions
    
    # Step 1 & 2: Uniform sampling and grid partitioning
    # For implementation, we assume we can sample uniformly from the image
    # and map pixels to regions.
    # In practice, this might involve iterating over a coarse grid first.
    
    # Step 3: Compute mean loss per region
    # Note: In a real implementation, 'image' would be processed to get gradients
    # and pixel values. Here we assume helper functions exist.
    for j in range(num_regions):
        # Get pixels belonging to region j
        pixels_in_region = get_pixels_in_region(image, j, grid_size)
        
        if len(pixels_in_region) == 0:
            region_losses[j] = 0.0
            continue
            
        total_loss = 0.0
        for u, v in pixels_in_region:
            # Compute gradient loss and pixel loss
            # e_g and e_p are specific to the network's output and ground truth
            e_g = compute_gradient_loss(network, image, u, v)
            e_p = compute_pixel_loss(network, image, u, v)
            total_loss += e_g + e_p
            
        region_counts[j] = len(pixels_in_region)
        region_losses[j] = total_loss / len(pixels_in_region)
        
    # Step 4: Normalization
    total_loss_sum = sum(region_losses)
    if total_loss_sum == 0:
        # Fallback to uniform if all losses are zero
        pdf_map = [1.0 / num_regions] * num_regions
    else:
        pdf_map = [loss / total_loss_sum for loss in region_losses]
        
    # Step 5: Pruning (Phase-dependent)
    # This is typically applied during specific training stages like the 'bubble' step
    # For general applicability, we keep the logic but note it's conditional.
    # If pruning is active:
    for j in range(num_regions):
        if pdf_map[j] < p_min:
            pdf_map[j] = 0.0
            
    # Renormalize after pruning if any values were zeroed
    if sum(pdf_map) == 0:
        pdf_map = [1.0 / num_regions] * num_regions
    else:
        total_pdf_sum = sum(pdf_map)
        pdf_map = [p / total_pdf_sum for p in pdf_map]
        
    # Step 6: Resampling
    # Allocate samples based on PDF
    sampled_pixels = []
    for j in range(num_regions):
        # Number of samples for this region
        num_samples = int(round(n_i * pdf_map[j]))
        
        # Sample uniformly from the region
        region_pixels = get_pixels_in_region(image, j, grid_size)
        if len(region_pixels) > 0:
            # Select 'num_samples' pixels from the region
            # If num_samples > len(region_pixels), sample with replacement or repeat
            selected = random.sample_with_replacement(region_pixels, num_samples)
            sampled_pixels.extend(selected)
            
    return sampled_pixels, pdf_map
```

**Parameters:**
*   **Grid Size:** 8x8, resulting in 64 regions [S1].
*   **$n_i$:** Total sample count per image used for resampling allocation [S1].
*   **$P_{min}$:** Pruning threshold, typically 0.05 [S2].

**Edge Cases and Pitfalls:**
*   **Empty Regions:** If a region has no uniformly sampled pixels, its loss is undefined. The pseudocode handles this by setting loss to 0.0, which may result in 0 probability if not handled by the normalization fallback.
*   **Zero Total Loss:** If all region losses are 0, the normalization denominator is 0. A fallback to uniform distribution is required [G].
*   **Pruning Zeroing All:** If pruning removes all regions (e.g., all $f_i[j] < P_{min}$), the PDF sum becomes 0. A fallback to uniform distribution is required [G].
*   **Temporal Consistency:** The PDF map is recomputed per iteration. Care must be taken to ensure that the resampling does not introduce bias or oscillation in training [S1].

## Subtopics

### [Patch-based Ray Sampling](11953-patch-based-ray-sampling.md)
Patch-based ray sampling is a strategy where rays are grouped into spatially adjacent 2D patches to form local image grids, ensuring the adjacency required for local-structure losses like Discrete Wavelet Transform (DWT) loss. It is distinguished from random ray sampling, which is used for global-structure losses (e.g., MSE), by enforcing local spatial coherence within each sampling batch.

## Operating characteristics
*   **Time Complexity:** $O(N_{pixels})$ for loss computation and $O(N_{regions})$ for normalization and resampling. The dominant cost is the loss computation over the uniformly sampled pixels.
*   **Memory Complexity:** $O(N_{regions})$ for storing the loss and PDF maps.
*   **Performance:** Improves convergence speed by focusing computational resources on difficult regions (e.g., thin geometry, high-frequency details) [S1, S2].
*   **Strengths:** Effective for training neural radiance fields and SDFs, particularly in reconstructing complex scenes with varying levels of detail [S1, S2].
*   **Limitations:** Requires a training phase to compute losses; not directly applicable to inference without modification. The grid size is a hyperparameter that may need tuning for different scene scales [S1].
*   **When to Use:** During the training of neural implicit representations (NeRF, SDF) where reconstruction error varies significantly across the image [S1, S2].
*   **When Not to Use:** For inference-time rendering where latency is critical, or for scenes with uniform complexity where uniform sampling is sufficient.

## Background
Loss-based Adaptive Sampling was introduced in the context of Neural Implicit Scalable Encoding for SLAM (Nice-SLAM) and Intrinsic Indoor Scene Reconstruction and Editing via Raytracing in Neural SDFs ($I^2$-SDF) [S1, S2]. It is analogous to sample mining in conventional deep learning, aiming to identify pixels with inadequate convergence and confer greater priority [S1]. The method has been shown to accelerate the reconstruction of thin components and missing geometry during the 'bubble' step of training [S2].
