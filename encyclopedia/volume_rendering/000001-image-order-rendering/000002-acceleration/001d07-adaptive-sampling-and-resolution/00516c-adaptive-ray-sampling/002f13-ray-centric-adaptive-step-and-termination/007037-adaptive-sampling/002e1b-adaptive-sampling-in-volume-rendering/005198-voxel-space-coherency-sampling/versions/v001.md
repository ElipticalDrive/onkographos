# Voxel-Space Coherency Sampling

Also called: Coarse-to-Fine Adaptive Sampling with Pyramid Detection

## Overview
Voxel-Space Coherency Sampling is an image-space optimization that exploits object-space coherency between voxels to avoid redundant sampling in uniform regions and adapt step sizes based on local frequency [S1, S2, unofficial]. It starts with low-frequency sampling (large steps) and refines density only where large value differences are detected, distinguishing it from parent methods by explicitly using a volume pyramid to detect variation rather than relying solely on per-ray density estimates [S1, S2, unofficial].

## How it works
**Inputs:**
- Volume dataset $V$ with resolution $N_x \times N_y \times N_z$.
- Camera parameters defining ray origins and directions.
- Precomputed volume pyramid $P$ (see Data structures).

**Outputs:**
- Final image with adaptive sampling density.

**Data structures:**
- **Volume Pyramid $P$:** A hierarchy of volumes where each level $l$ stores precomputed statistics for neighborhoods of size $2^l \times 2^l \times 2^l$.
  - Fields per voxel at level $l$:
    - $min\_val$: Minimum voxel value in the neighborhood.
    - $max\_val$: Maximum voxel value in the neighborhood.
    - $range$: $max\_val - min\_val$.
  - Level 0 is the original volume. Higher levels are downsampled.
  - Not given in the sources: Exact downsampling filter (e.g., min/max pooling) or number of levels. [G] Typically, level $l$ covers a $2^l$ radius neighborhood.

**Algorithm:**
1. **Initialize Ray:** For each pixel, cast a ray into the volume.
2. **Coarse Sampling:** Start sampling at a large step size $S_{large}$ (low frequency). Sample at positions $t_0, t_1, \dots$ along the ray.
3. **Check Coherency:** For each pair of adjacent samples $(t_i, t_{i+1})$:
   - Retrieve voxel values $v_i = V(t_i)$ and $v_{i+1} = V(t_{i+1})$.
   - Compute difference $\Delta = |v_i - v_{i+1}|$.
   - Alternatively, use the pyramid: query $P$ at the midpoint or interval to get local $range$. If $range > \tau$ (threshold), high frequency is detected.
4. **Refine if Necessary:** If $\Delta > \tau$ (or pyramid range exceeds threshold):
   - Insert additional samples between $t_i$ and $t_{i+1}$ to resolve ambiguities.
   - Use a smaller step size $S_{small}$ for these inserted samples.
5. **Skip Uniform Regions:** If $\Delta \le \tau$ and the region is homogeneous (low opacity contribution or low variation), skip further sampling in that interval.
6. **Interpolation for Empty Pixels:** For pixels not directly sampled (e.g., if sampling every other pixel), assign interpolated values from neighbors [S2, unofficial].

**Pseudocode:**
```python
def voxel_space_coherency_sampling(ray, volume, pyramid, threshold):
    # Step 1: Initialize coarse step
    step_size = LARGE_STEP
    t = ray.origin
    samples = []
    
    while t is within volume bounds:
        # Sample current position
        val = trilinear_sample(volume, t)
        samples.append((t, val))
        
        # Move to next coarse position
        t_next = t + ray.direction * step_size
        
        if t_next is out of bounds:
            break
            
        val_next = trilinear_sample(volume, t_next)
        
        # Step 2: Check for large value difference
        diff = abs(val - val_next)
        
        # Optional: Use pyramid for neighborhood range check
        # range_val = pyramid.query_range(t, t_next)
        # if range_val > threshold: diff = max(diff, range_val)
        
        if diff > threshold:
            # Step 3: Refine - insert intermediate samples
            # Use smaller step size
            refined_samples = []
            t_mid = t
            while t_mid < t_next:
                refined_samples.append(trilinear_sample(volume, t_mid))
                t_mid += ray.direction * SMALL_STEP
            samples.extend(refined_samples)
        else:
            # Step 4: Skip uniform region
            pass
            
        t = t_next
        
    return samples
```

**Parameters:**
- $S_{large}$: Large step size. Not given in the sources. [G] Typically related to voxel size or brick size.
- $S_{small}$: Small step size. Not given in the sources. [G] Typically 1 voxel or sub-voxel.
- $\tau$: Threshold for value difference. Not given in the sources. [G] Depends on volume dynamic range.

**Edge cases:**
- **Degenerate input:** Uniform volume with no variation. The method should skip all but the first sample.
- **Boundary conditions:** Ensure ray termination at volume bounds.
- **Precision:** Floating point errors in $t$ accumulation may cause gaps or overlaps. Use robust ray marching.

## Operating characteristics
- **Time Complexity:** $O(N)$ in worst case (high frequency everywhere), but significantly faster in uniform regions.
- **Memory Complexity:** $O(V)$ for the volume pyramid, where $V$ is the number of voxels.
- **Strengths:** Reduces sampling in homogeneous regions; exploits spatial coherency.
- **Limitations:** Requires precomputed pyramid; may miss high-frequency details if threshold is too high.
- **When to use:** Large volumes with significant uniform regions; real-time rendering where performance is critical.
- **When not to use:** Highly heterogeneous volumes with no uniform regions; where exact high-frequency detail is required.

## Background
Originated from observations of object-space coherency in volume rendering [S1, unofficial]. Extended by Van Walsum et al. to use volume pyramids for detecting low presence or low variation [S2, unofficial]. Used in real-time volume visualization to improve performance.
