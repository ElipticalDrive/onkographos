# Context-Based Adaptive Ray Sampling with Quadtree Subdivision

Also called: Adaptive Quadtree Subdivision, Fast Learning Radiance Fields by Shooting Much Fewer Rays method, Ours, Prior/Posterior Probability Sampling, Probability-based Ray Sampling with Quadtree Subdivision, Quadtree Subdivision

## Overview
This method is a training-stage sampling strategy that accelerates radiance field learning by dynamically adjusting ray distribution across input views using a quadtree structure [S1]. It solves the problem of excessive computational cost in uniform sampling by identifying "trivial" (low complexity) and "nontrivial" (high complexity) regions, shooting fewer rays in the former and refining the latter [S1]. It sets itself apart from sibling methods like [Adaptive Sparse Ray Sampling](8313-adaptive-sparse-ray-sampling.md) by using a hierarchical quadtree subdivision driven by rendering error to prune redundant blocks, and from [Hard Sample Mining](8673-hard-sample-mining.md) by integrating context-based probability density for intra-block sampling rather than global loss-based point selection [S1].

## How it works
The method operates in two phases: a prior probability-based sampling for initial ray placement and a posterior probability-based quadtree subdivision for adaptive refinement. It is applied only during the training stage; at test time, full-resolution rendering is performed [S1].

### Inputs and Outputs
*   **Inputs:** A set of input views $I_i$ with height $H_i$ and width $W_i$; a radiance field model $\Theta$ (e.g., NeRF, Instant-NGP); ground truth colors $c_i$; hyperparameters including subdivision threshold $\alpha$, initial quadtree depth $D_{init}$, subdivision frequency $F_{sub}$, random sampling ratio $r_{rand}$, and constant ray count for marked nodes $n_0$ [S1].
*   **Outputs:** A trained radiance field model; reduced training time with comparable or improved PSNR/SSIM/LPIPS metrics [S1].

### Data Structures
*   **Quadtree:** Constructed independently for each input view. Each node represents a rectangular block of the image.
    *   **Leaf Node:** Represents a block. Contains a state flag `marked` (boolean) and a counter for accumulated rendering error.
    *   **Internal Node:** Contains four children (quadrants).
    *   **Initialization:** The quadtree is initialized to depth $D_{init}$ (typically 2 or 3) to rapidly distinguish trivial and nontrivial areas [S1].
*   **Probability Map:** A 2D array of the same dimensions as the input image, storing the prior probability density for each pixel based on local color variance [S1].

### Algorithm Steps

1.  **Initialization:**
    *   For each input view $I_i$, construct a quadtree of depth $D_{init}$.
    *   Calculate the prior probability distribution $g'(u, v)$ for every pixel $(u, v)$ in the image based on the standard deviation of color in a local patch [S1].
    *   Set the initial number of rays $M_i = H_i \times W_i$ [S1].

2.  **Prior Probability Sampling (Per Iteration):**
    *   Traverse all leaf nodes $F$ of the quadtree.
    *   If $F$ is **marked** (converged):
        *   Sample $n_0$ rays uniformly or randomly within the block $F$ [S1].
    *   If $F$ is **unmarked**:
        *   Determine the number of rays to sample in $F$. The total rays for the image at subdivision level $l$ is given by:
            $$ M_{il} = Q_{l1} \times \frac{H_i \times W_i}{2^{2l}} + Q_{l2} \times n_0 $$
            where $Q_{l1}$ is the number of unmarked leaf nodes, $Q_{l2}$ is the number of marked leaf nodes, and $l$ is the current subdivision depth [S1].
        *   Sample rays within $F$ according to the prior probability distribution $g'(u, v)$. Specifically, sample $50\%$ of rays based on $g'(u, v)$ and $50\%$ randomly to ensure trivial areas are not ignored [S1].

3.  **Rendering and Error Collection (Per Epoch):**
    *   Render the sampled rays using the current model $\Theta$.
    *   For each leaf node $F$, calculate the average rendering error $e_F$ over all rays $r_i$ emitted from pixels in $F$:
        $$ e_F = \text{mean}_{r_i \in F} (V_\Theta(r_i) - c_i) $$
        where $V_\Theta(r_i)$ is the rendered color and $c_i$ is the ground truth color [S1].

4.  **Quadtree Subdivision (Every $F_{sub}$ Epochs):**
    *   Traverse all leaf nodes $F$.
    *   If $e_F < \alpha$ (threshold, typically $10^{-3}$):
        *   Mark $F$ as **converged** (`marked = true`).
        *   $F$ will not be subdivided further.
    *   If $e_F \ge \alpha$:
        *   Subdivide $F$ into four smaller child leaf nodes.
        *   Reset error accumulation for the new children [S1].

5.  **Finetuning (Last Epoch):**
    *   After training completes, randomly sample rays across the entire image (ignoring quadtree structure) to finetune the radiance field, allowing pruned regions to converge locally [S1].

### Probability Density Calculation
The prior probability density $g'(u, v)$ is derived from the variance of color in a $3 \times 3$ patch centered at $(u, v)$ [S1]:
$$ \text{variance}(c(u, v)) = \frac{1}{9} \sum_{x \in \{u-1, u, u+1\}} \sum_{y \in \{v-1, v, v+1\}} [c(x, y) - \bar{c}]^2 $$
where $\bar{c}$ is the mean color in the patch. This variance is normalized to form the probability distribution. Alternative metrics (variation, entropy) and patch sizes ($5 \times 5, 7 \times 7, 9 \times 9$) were tested but found to be insensitive; $3 \times 3$ variance is used [S1].

### Parameters
*   **Subdivision Threshold ($\alpha$):** $10^{-3}$ [S1].
*   **Subdivision Frequency ($F_{sub}$):** Every 3 epochs [S1].
*   **Initial Quadtree Depth ($D_{init}$):** 2 or 3 [S1].
*   **Random Sampling Ratio ($r_{rand}$):** 50% of rays per leaf node are sampled randomly, while the other 50% follow the probability distribution [S1].
*   **Marked Node Rays ($n_0$):** Constant number of rays sampled on marked leaf nodes, typically $n_0 = 10$ [S1].

### Pseudocode

```python
def train_with_quadtree_adaptive_sampling(model, views, epochs, alpha=1e-3, 
                                          freq_sub=3, n0=10, r_rand=0.5, 
                                          d_init=2):
    """
    model: Radiance field model (e.g., NeRF)
    views: List of input views, each with image data, height H, width W, and ground truth colors
    epochs: Total number of training epochs
    alpha: Threshold for marking a leaf node as converged
    freq_sub: Frequency of quadtree subdivision in epochs
    n0: Number of rays sampled on marked leaf nodes
    r_rand: Ratio of random sampling within unmarked leaf nodes
    d_init: Initial depth of the quadtree
    """
    
    # Initialize quadtrees for each view
    quadtrees = []
    for view in views:
        qt = Quadtree(view.H, view.W, depth=d_init)
        qt.calculate_prior_probability(view.image) # Uses 3x3 color variance
        quadtrees.append(qt)

    for epoch in range(epochs):
        for view_idx, view in enumerate(views):
            qt = quadtrees[view_idx]
            rays_to_sample = []
            
            # 1. Sample rays based on quadtree state
            for leaf in qt.get_all_leaves():
                if leaf.is_marked:
                    # Sample n0 rays randomly or uniformly in this block
                    rays = sample_rays_in_block(leaf, n0)
                else:
                    # Determine number of rays for this unmarked leaf
                    # Total rays for image is distributed among unmarked leaves
                    # Here we assume uniform distribution of available rays among unmarked leaves
                    # or proportional to leaf area. The source implies Mi is calculated globally,
                    # but per-leaf sampling uses the probability map.
                    # Simplified: Sample rays proportional to leaf area using probability map
                    num_rays = calculate_leaf_ray_count(leaf, qt) 
                    
                    # Split sampling: r_rand random, (1-r_rand) probability-based
                    n_rand = int(num_rays * r_rand)
                    n_prob = num_rays - n_rand
                    
                    rays_rand = sample_rays_random(leaf, n_rand)
                    rays_prob = sample_rays_probability(leaf, n_prob, leaf.prior_prob_map)
                    rays = rays_rand + rays_prob
                
                rays_to_sample.extend(rays)

            # 2. Render and collect errors
            rendered_colors = model.render(rays_to_sample)
            errors = compute_error(rendered_colors, view.ground_truth_colors)
            
            # 3. Accumulate errors for leaf nodes
            for leaf in qt.get_all_leaves():
                leaf_errors = [errors[i] for i, ray in enumerate(rays_to_sample) if ray.is_in(leaf)]
                if leaf_errors:
                    leaf.avg_error = mean(leaf_errors)

        # 4. Subdivide quadtrees periodically
        if (epoch + 1) % freq_sub == 0:
            for qt in quadtrees:
                for leaf in qt.get_all_leaves():
                    if leaf.avg_error < alpha:
                        leaf.mark_converged()
                    else:
                        leaf.subdivide()

    # 5. Finetuning on last epoch
    # Randomly sample rays across the whole image for all views
    final_rays = sample_rays_global(views)
    model.render(final_rays) # Finetune step
```

### Edge Cases and Pitfalls
*   **Trivial Area Ignorance:** Pure probability-based sampling may ignore smooth surfaces. The random sampling ratio ($r_{rand}=50\%$) mitigates this [S1].
*   **Test-Time Rendering:** The quadtree structure is not used during inference. Full-resolution rendering is required, so inference speed is not accelerated, only training time [S1].
*   **Threshold Sensitivity:** The threshold $\alpha$ determines convergence. If too high, nodes are marked too early, losing detail. If too low, subdivision continues unnecessarily, increasing overhead [S1].

## Subtopics

### [Hierarchical Viewing Cube Sampling](10010-hierarchical-viewing-cube-sampling.md)
Uses a quadtree hierarchy to place viewing cubes along rays for scattering convolutions, balancing accuracy and performance by interpolating higher-order terms. It differs by operating in scattering space rather than image-space ray sampling for radiance fields.

## Operating characteristics
*   **Time Complexity:** Training time is reduced by 15-40% compared to uniform sampling baselines. For example, on the Realistic Synthetic 360° dataset, NeRF training time dropped from 22.0h to 16.9h (23% reduction), and Plenoxels from 25.6min to 19.6min (23% reduction) [S1]. On Instant-NGP, time reduced from 264s to 217s (18% reduction) with improved PSNR (32.44 vs 32.04) [S1]. On the LLFF dataset, Plenoxels training time reduced from 66.6min to 40.4min (39% reduction) with PSNR increase from 24.60 to 25.12 [S1]. On DTU, NeuS training time reduced from 9.2h to 7.3h (21% reduction) with Chamfer Distance improvement from 0.87 to 0.73 [S1].
*   **Memory Complexity:** Requires storing quadtree structures for each view, which is negligible compared to the radiance field model. The number of rays stored in memory per iteration decreases as training progresses and more nodes are marked [S1].
*   **Strengths:** Significantly reduces training time while maintaining or improving visual quality (PSNR, SSIM, LPIPS). Effective across various radiance field methods (NeRF, NeRF++, Plenoxels, Instant-NGP, Mip-NeRF 360, NeuS) [S1].
*   **Limitations:** Only accelerates training, not inference. Requires careful tuning of subdivision frequency and threshold. Initial subdivision overhead may slightly increase early training time [S1].
*   **When to Use:** When training time is a bottleneck and the scene has varying complexity (some trivial, some detailed).
*   **When Not to Use:** When inference speed is critical, or when the scene is uniformly simple/complex (no benefit from adaptive sampling).

## Background
The method was introduced in "Fast Learning Radiance Fields by Shooting Much Fewer Rays" (2023) [S1]. It builds upon the observation that uniform ray sampling is inefficient for scenes with varying detail. It distinguishes itself from prior work like iMap by using rendering error for quadtree subdivision (rather than point count per block) and context-based probability sampling within blocks [S1]. It is applicable to a wide range of neural radiance field frameworks [S1].
