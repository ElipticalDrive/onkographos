# Coarse-to-Fine NeRF

Also called: Coarse-Fine NeRF, Hierarchical Rendering (Original NeRF), Two-Stage NeRF

## Overview
Coarse-to-Fine NeRF is a hierarchical sampling strategy that improves the learning of high-frequency details in Neural Radiance Fields by performing two tiers of volume sampling [S1, S3, unofficial]. It solves the problem of inefficient uniform sampling, where most samples fall in empty space, by using a coarse network to identify opaque regions and then clustering a second set of samples near those regions to train a fine network [S1, S4, unofficial]. It sets itself apart from standard uniform sampling by adaptively concentrating computational effort on visible geometry, and from its sibling [TermiNeRF](8828-terminerf.md) by not explicitly modeling termination probabilities but rather relying on opacity-based importance sampling [S1, S4, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Ray origins $\mathbf{o} \in \mathbb{R}^3$, ray directions $\mathbf{d} \in \mathbb{R}^3$, near bound $t_{near}$, far bound $t_{far}$, number of coarse samples $N_c$, number of fine samples $N_f$ [S4, unofficial].
*   **Outputs:** Rendered RGB color $\mathbf{C}(\mathbf{r})$, depth map, accumulated alpha, and weights for both coarse and fine passes [S5, unofficial].

**Data Structures:**
*   **Networks:** Two separate Multi-Layer Perceptrons (MLPs), `network_coarse` and `network_fine`. Both share the same architecture (hidden dimensions, layers) but have distinct parameters [S3, unofficial].
*   **Positional Encoding:** Input coordinates are encoded using positional encoding with `pos_levels` (default 10) and view directions with `dir_levels` (default 4) [S3, unofficial].
*   **Raw Output Tensor:** For each sample, the network outputs a tensor of shape `(ray_count, sample_count, 4)` [S5, unofficial]. The first 3 channels are RGB (sigmoided to $[0,1]$), and the 4th channel is the raw volume density $\sigma$ [S5, unofficial].

**Parameters:**
*   `n_coarse`: Number of coarse samples per ray. Default: 64 [S4, unofficial].
*   `n_fine`: Number of fine samples per ray. Default: 128 [S4, unofficial].
*   `perturb`: Boolean flag to enable perturbation of uniform samples during the coarse pass to break symmetry and reduce aliasing. Default: True [S4, unofficial].
*   `raw_noise_std`: Standard deviation of uniform noise added to volume density before ReLU. Default: 0 [S5, unofficial].
*   `white_bkgd`: Boolean flag. If True, adds unaccounted transmittance to RGB assuming a white background [S5, unofficial].

**Steps:**

1.  **Coarse Sampling:** Generate $N_c$ depth values $t_c$ uniformly spaced between $t_{near}$ and $t_{far}$ [S4, S5, unofficial]. If `perturb` is True, apply perturbation to uniform samples to break symmetry and reduce aliasing [S4, unofficial].
2.  **Coarse Query:** Convert depth values to 3D points $\mathbf{p}_c = \mathbf{o} + t_c \mathbf{d}$ [S5, unofficial]. Query `network_coarse` with $\mathbf{p}_c$ to obtain raw outputs $\mathbf{raw}_c$ [S4, S5, unofficial].
3.  **Coarse Rendering:** Convert $\mathbf{raw}_c$ to alpha compositing weights $w_c$ using volume rendering equations [S5, unofficial]. Compute the coarse RGB color $\mathbf{C}_c$ and depth [S5, unofficial].
4.  **Hierarchical Sampling:** Use the coarse weights $w_c$ to define a probability distribution [S4, S5, unofficial]. Sample $N_f$ new depth values $t_f$ from this distribution using inverse transform sampling (or `sample_pdf`) [S4, S5, unofficial].
    *   *Pitfall:* The sampling step is non-differentiable [S4, S5, unofficial]. Gradients must not flow back through this step to the coarse network [S4, S5, unofficial]. The coarse samples/weights used for fine sampling must be detached from the computation graph [S4, S5, unofficial].
5.  **Fine Sampling Preparation:** Concatenate coarse and fine depth values: $t_{fine\_all} = \text{sort}([t_c, t_f])$ [S4, S5, unofficial]. Convert these to 3D points $\mathbf{p}_{fine\_all}$ [S4, S5, unofficial].
6.  **Fine Query:** Query `network_fine` with $\mathbf{p}_{fine\_all}$ to obtain $\mathbf{raw}_f$ [S5, unofficial].
7.  **Fine Rendering:** Convert $\mathbf{raw}_f$ to weights $w_f$ and compute the final RGB color $\mathbf{C}_f$ [S5, unofficial].

**Formulas:**

*   **Distance between samples:**
    $$ \delta_i = z_{i+1} - z_i $$
    An infinite distance ($10^{10}$) is appended to the last column to ensure the opacity of the last segment is 1 [S5, unofficial].

*   **Alpha (Opacity):**
    $$ \alpha = 1 - \exp(-\sigma \cdot \delta) $$
    Where $\sigma$ is the volume density from the network output, optionally perturbed by noise $\mathcal{U}[0,1]$ if `raw_noise_std` > 0, and passed through ReLU [S5, unofficial].

*   **Transmittance:**
    $$ T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right) $$
    Computed as the cumulative product of $(1 - \alpha)$, prepended with 1. The last column is discarded [S5, unofficial].

*   **Weights:**
    $$ w_i = \alpha_i \cdot T_i $$

*   **RGB Rendering:**
    $$ \mathbf{C} = \sum_{i=1}^{N} w_i \mathbf{c}_i $$
    If `white_bkgd` is True: $\mathbf{C} = \mathbf{C} + (1 - \sum w_i) \cdot \mathbf{1}$ [S5, unofficial].

*   **Loss Function:**
    $$ L = L_{coarse} + L_{fine} $$
    $$ L_{coarse} = \text{mean}((\mathbf{C}_{coarse} - \mathbf{C}_{target})^2) $$
    $$ L_{fine} = \text{mean}((\mathbf{C}_{fine} - \mathbf{C}_{target})^2) $$
    Both networks are supervised against the target pixel color [S4, unofficial].

**Pseudocode:**

```python
import math
import random

def raw2outputs(raw, z_vals, rays_d, raw_noise_std=0.0, white_bkgd=False):
    """
    Converts raw network outputs to radiance and weights.
    raw: list of lists [ray_count][sample_count][4] -> RGB and sigma
    z_vals: list of lists [ray_count][sample_count]
    rays_d: list of lists [ray_count][3]
    """
    ray_count = len(z_vals)
    sample_count = len(z_vals[0])
    
    # Calculate distances between samples
    dists = []
    for r in range(ray_count):
        row = []
        for i in range(sample_count - 1):
            row.append(z_vals[r][i+1] - z_vals[r][i])
        row.append(1e10)  # Infinite distance for last segment
        dists.append(row)
        
    # Scale by ray direction norm
    for r in range(ray_count):
        norm = math.sqrt(rays_d[r][0]**2 + rays_d[r][1]**2 + rays_d[r][2]**2)
        for i in range(sample_count):
            dists[r][i] *= norm
            
    # Extract RGB and Sigma
    rgb = [[raw[r][i][:3] for i in range(sample_count)] for r in range(ray_count)]
    sigma_raw = [[raw[r][i][3] for i in range(sample_count)] for r in range(ray_count)]
    
    # Add noise to sigma if specified
    noise = [[0.0]*sample_count for _ in range(ray_count)]
    if raw_noise_std > 0.0:
        for r in range(ray_count):
            for i in range(sample_count):
                noise[r][i] = random.gauss(0, 1) * raw_noise_std
                
    # Apply ReLU and compute alpha
    alpha = [[0.0]*sample_count for _ in range(ray_count)]
    for r in range(ray_count):
        for i in range(sample_count):
            sigma = max(0.0, sigma_raw[r][i] + noise[r][i])
            alpha[r][i] = 1.0 - math.exp(-sigma * dists[r][i])
            
    # Compute transmittance T
    # T_i = prod_{j<i} (1 - alpha_j)
    T = [[0.0]*sample_count for _ in range(ray_count)]
    for r in range(ray_count):
        prod = 1.0
        for i in range(sample_count):
            T[r][i] = prod
            prod *= (1.0 - alpha[r][i] + 1e-10)
            
    # Compute weights
    weights = [[alpha[r][i] * T[r][i] for i in range(sample_count)] for r in range(ray_count)]
    
    # Render RGB
    rgb_map = []
    for r in range(ray_count):
        r_sum = [0.0, 0.0, 0.0]
        for i in range(sample_count):
            for c in range(3):
                r_sum[c] += weights[r][i] * rgb[r][i][c]
        rgb_map.append(r_sum)
        
    # Render Depth
    depth_map = []
    for r in range(ray_count):
        d_sum = 0.0
        for i in range(sample_count):
            d_sum += weights[r][i] * z_vals[r][i]
        depth_map.append(d_sum)
        
    # Accumulated Alpha
    acc_map = []
    for r in range(ray_count):
        a_sum = 0.0
        for i in range(sample_count):
            a_sum += weights[r][i]
        acc_map.append(a_sum)
        
    # White background
    if white_bkgd:
        for r in range(ray_count):
            for c in range(3):
                rgb_map[r][c] += (1.0 - acc_map[r])
                
    return rgb_map, depth_map, acc_map, weights

def stratified_sample(near, far, N_c, ray_o, ray_d, perturb=True):
    """
    Uniform stratified sampling along rays.
    Returns: pts [B][N_c][3], dirs [B][N_c][3], t_vals [B][N_c]
    """
    ray_count = len(ray_o)
    t_vals = []
    for r in range(ray_count):
        t_vals.append([near + (far - near) * (i + 1) / N_c for i in range(N_c)])
        
    if perturb:
        for r in range(ray_count):
            mid = [(t_vals[r][i] + t_vals[r][i+1]) / 2.0 for i in range(N_c - 1)]
            upper = mid + [t_vals[r][-1]]
            lower = [t_vals[r][0]] + mid
            t_vals[r] = [lower[i] + (upper[i] - lower[i]) * random.random() for i in range(N_c)]
        
    pts = []
    dirs = []
    for r in range(ray_count):
        pts_r = []
        dirs_r = []
        for i in range(N_c):
            pts_r.append([ray_o[r][0] + t_vals[r][i]*ray_d[r][0],
                          ray_o[r][1] + t_vals[r][i]*ray_d[r][1],
                          ray_o[r][2] + t_vals[r][i]*ray_d[r][2]])
            dirs_r.append(ray_d[r][:])
        pts.append(pts_r)
        dirs.append(dirs_r)
        
    return pts, dirs, t_vals

def sample_pdf(bins, weights, N_f, perturb=True):
    """
    Hierarchical sampling based on coarse weights.
    bins: list of lists [B][N_c] sorted depth values from coarse pass
    weights: list of lists [B][N_c] alpha compositing weights from coarse pass
    Returns: t_fine [B][N_f]
    """
    ray_count = len(bins)
    sample_count = len(bins[0])
    t_fine = []
    
    for r in range(ray_count):
        # Normalize weights to sum to 1 per ray
        w_sum = sum(weights[r]) + 1e-5
        pdf = [w / w_sum for w in weights[r]]
        cdf = []
        acc = 0.0
        for p in pdf:
            acc += p
            cdf.append(acc)
        cdf = [0.0] + cdf
        
        # Sample uniform values
        u = [random.random() for _ in range(N_f)]
        
        # Inverse transform sampling
        t_row = []
        for val in u:
            # Find bin index
            idx = 0
            while idx < len(cdf) - 1 and cdf[idx+1] < val:
                idx += 1
            idx = min(idx, len(cdf) - 2)
            
            # Linear interpolation within bins
            bin_low = bins[r][idx]
            bin_high = bins[r][idx+1]
            cdf_low = cdf[idx]
            cdf_high = cdf[idx+1]
            
            t = bin_low + (bin_high - bin_low) * ((val - cdf_low) / (cdf_high - cdf_low + 1e-5))
            
            if perturb:
                t += random.random() * (bin_high - bin_low)
            t_row.append(t)
        t_fine.append(t_row)
        
    return t_fine

def render_rays(rays_o, rays_d, network_coarse, network_fine, 
                near, far, n_coarse=64, n_fine=128, 
                raw_noise_std=0.0, white_bkgd=False, perturb=True):
    """
    Full coarse-to-fine rendering pipeline.
    """
    # 1. Coarse Sampling
    pts_coarse, dirs_coarse, t_coarse = stratified_sample(
        near, far, n_coarse, rays_o, rays_d, perturb
    )
    
    # 2. Coarse Query
    raw_coarse = network_coarse(pts_coarse, dirs_coarse)
    
    # 3. Coarse Rendering
    rgb_coarse, depth_coarse, acc_coarse, weights_coarse = raw2outputs(
        raw_coarse, t_coarse, rays_d, raw_noise_std, white_bkgd
    )
    
    # 4. Hierarchical Sampling
    # Detach to prevent gradient flow from fine to coarse sampling logic
    weights_coarse_detached = [[w for w in row] for row in weights_coarse]
    t_coarse_detached = [[t for t in row] for row in t_coarse]
    
    t_fine = sample_pdf(t_coarse_detached, weights_coarse_detached, n_fine, perturb)
    
    # 5. Fine Sampling Preparation
    t_fine_all = []
    for r in range(len(t_coarse_detached)):
        t_fine_all.append(sorted(t_coarse_detached[r] + t_fine[r]))
        
    pts_fine_all = []
    dirs_fine_all = []
    for r in range(len(t_fine_all)):
        pts_r = []
        dirs_r = []
        for i in range(len(t_fine_all[r])):
            pts_r.append([rays_o[r][0] + t_fine_all[r][i]*rays_d[r][0],
                          rays_o[r][1] + t_fine_all[r][i]*rays_d[r][1],
                          rays_o[r][2] + t_fine_all[r][i]*rays_d[r][2]])
            dirs_r.append(rays_d[r][:])
        pts_fine_all.append(pts_r)
        dirs_fine_all.append(dirs_r)
        
    # 6. Fine Query
    raw_fine = network_fine(pts_fine_all, dirs_fine_all)
    
    # 7. Fine Rendering
    rgb_fine, depth_fine, acc_fine, weights_fine = raw2outputs(
        raw_fine, t_fine_all, rays_d, raw_noise_std, white_bkgd
    )
    
    return {
        'rgb_coarse': rgb_coarse,
        'depth_coarse': depth_coarse,
        'rgb_fine': rgb_fine,
        'depth_fine': depth_fine,
        'weights_coarse': weights_coarse,
        'weights_fine': weights_fine
    }
```

## Subtopics

### Single Multiscale MLP Architecture
A variant that uses a single MLP with parameters $\Theta$ for both coarse and fine stages, enabled by Integrated Positional Encoding (IPE) which explicitly encodes scale into input features [S6]. Unlike standard NeRF which requires two distinct MLPs because standard PE only models one scale, this approach allows one MLP to learn a multiscale representation [S6]. The optimization balances coarse and fine losses using a hyperparameter $\lambda$ (default 0.1) [S6].

### Segmented Sampling
A strategy that selectively increases the sampling rate only within the bounding box of an object area to ensure detailed sampling without significantly increasing overall computational cost [S7]. It addresses the pitfall where standard uniform sampling results in sparse points on small objects relative to the scene, causing missing areas in rendered images due to inaccurate PDF in the fine stage [S7].

### DONeRF PDF Sampling
A method used in DONeRF to translate depth oracle classification outputs into sample locations [S8]. It treats the classified depth output vector from a single oracle network evaluation as a piecewise-constant Probability Density Function (PDF) and samples from its Cumulative Distribution Function (CDF) [S8]. Unlike standard NeRF which builds a PDF from opacity outputs of a coarse shading network evaluated at multiple locations, this uses the oracle's direct output [S8].

## Operating characteristics
*   **Time Complexity:** $O(N_c + N_f)$ network queries per ray, where $N_c$ is coarse samples and $N_f$ is fine samples [G]. Typically $N_c=64, N_f=128$ [S4, unofficial].
*   **Memory Complexity:** Stores outputs for both coarse and fine passes [G]. The compute graph must be static; the coarse-to-fine edge is cut via `.detach()` to prevent cyclic definitions [S5, unofficial].
*   **Performance:** Improves detail learning by clustering samples near opaque regions, unlike evenly distributed sampling [S1, unofficial]. It prevents dense sampling at fine scales in empty space, improving computational efficiency compared to uniformly dense sampling [S2].
*   **Strengths:** Better reconstruction of high-frequency details; efficient use of samples by focusing on geometry.
*   **Limitations:** Requires two network passes (or two networks); non-differentiable sampling step breaks gradient flow from fine to coarse [S4, S5, unofficial].

## Background
Coarse-to-Fine NeRF, also known as Hierarchical Rendering, was introduced in the original NeRF paper by Mildenhall et al. [S2][S4, unofficial]. It was designed to improve computational efficiency and rendering quality by using a coarse network to guide the sampling of a fine network [S2]. The method has become a standard component in many subsequent NeRF variants [S2].
