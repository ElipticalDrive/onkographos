# Coarse-to-Fine NeRF

Also called: Coarse-Fine NeRF, Hierarchical Rendering (Original NeRF), Two-Stage NeRF

## Overview
Coarse-to-Fine NeRF is a hierarchical sampling strategy that decouples the estimation of the scene's opacity distribution from the final color prediction to improve rendering quality and computational efficiency [S1, unofficial][S2][S3, unofficial]. It solves the problem of sparse uniform sampling missing high-frequency details by first querying a coarse network to identify opaque regions, then clustering a denser set of fine samples around those regions [S1, S4, unofficial]. Unlike standard uniform sampling, which distributes points evenly across the entire ray segment, this method concentrates computational effort where the scene geometry is present, allowing the fine network to learn detailed textures without the prohibitive cost of uniformly dense sampling [S1, S4, unofficial].

## How it works
**Inputs and Outputs:**
The method processes a batch of rays defined by origins $\mathbf{o} \in \mathbb{R}^{B \times 3}$ and directions $\mathbf{d} \in \mathbb{R}^{B \times 3}$, bounded by near $n$ and far $f$ planes [S3, S5, unofficial]. It outputs rendered RGB images, depth maps, and accumulation maps for both the coarse and fine passes [S4, S5, unofficial].

**Data Structures:**
*   **Coarse Samples:** A tensor $t_c \in \mathbb{R}^{B \times N_C}$ containing depth values along the ray [S3, unofficial].
*   **Fine Samples:** A tensor $t_f \in \mathbb{R}^{B \times N_F}$ containing depth values sampled hierarchically [S3, unofficial].
*   **Raw Outputs:** Tensors of shape $(B, N, 4)$ from the MLP, where the first 3 channels are raw RGB (sigmoided to $[0,1]$) and the 4th channel is raw volume density $\sigma$ [S5, unofficial].
*   **Weights:** A tensor $w \in \mathbb{R}^{B \times N}$ representing the alpha compositing weights for each sample [S5, unofficial].

**Parameters:**
*   $N_C$: Number of coarse samples per ray. Default: 64 [S4, unofficial].
*   $N_F$: Number of fine samples per ray. Default: 128 [S4, unofficial].
*   `perturb`: Boolean flag to enable jittering of uniform samples during the coarse pass to break symmetry and reduce aliasing. Default: True [S4, unofficial].
*   `raw_noise_std`: Standard deviation of uniform noise added to volume density before ReLU activation. Default: 0 [S5, unofficial].
*   `white_bkgd`: Boolean flag. If True, adds unaccounted transmittance $(1 - \text{accumulated alpha})$ to the RGB map, assuming a white background [S5, unofficial].
*   `pos_levels`: Number of frequency octaves for positional encoding. Default: 10 [S3, unofficial].
*   `dir_levels`: Number of frequency octaves for directional encoding. Default: 4 [S3, unofficial].

**Numbered Steps:**

1.  **Coarse Sampling:** Generate $N_C$ depth values $t_c$ uniformly (or stratified) between $n$ and $f$. If `perturb` is True, jitter the samples within their bins to break symmetry [S3, S4, unofficial].
2.  **Coarse Query:** Convert $t_c$ to 3D points $\mathbf{p}_c = \mathbf{o} + t_c \cdot \mathbf{d}$ [S5, unofficial]. Query the coarse MLP $\text{MLP}_{coarse}$ at these points to obtain raw outputs $\mathbf{r}_c \in \mathbb{R}^{B \times N_C \times 4}$ [S4, unofficial].
3.  **Coarse Rendering:** Convert $\mathbf{r}_c$ to weights $w_c$ using alpha compositing (see Formula below). Compute the coarse RGB image $\mathbf{C}_{coarse}$ [S4, S5, unofficial].
4.  **Gradient Cut:** Detach $t_c$ and $w_c$ from the computation graph to prevent gradients from flowing back through the non-differentiable sampling step to the coarse network [S4, S5, unofficial].
5.  **Hierarchical Sampling:** Compute the midpoints $t_{mid}$ between adjacent coarse samples. Use inverse transform sampling on the cumulative distribution function (CDF) of $w_c$ to generate $N_F$ fine depth values $t_{fine}$ clustered around opaque regions [S4, S5, unofficial].
6.  **Fine Preparation:** Concatenate coarse and fine depths: $t_{all} = \text{sort}([t_c, t_{fine}])$ [S4, unofficial]. Convert $t_{all}$ to 3D points $\mathbf{p}_{all} = \mathbf{o} + t_{all} \cdot \mathbf{d}$ [S5, unofficial].
7.  **Fine Query:** Query the fine MLP $\text{MLP}_{fine}$ at $\mathbf{p}_{all}$ to obtain raw outputs $\mathbf{r}_{fine}$ [S4, unofficial].
8.  **Fine Rendering:** Convert $\mathbf{r}_{fine}$ to weights $w_{fine}$ and compute the final RGB image $\mathbf{C}_{fine}$ using alpha compositing [S4, S5, unofficial].

**Formulas:**

*   **Segment Length:** $\delta_i = t_{i+1} - t_i$. An infinite distance ($10^{10}$) is appended to the last segment to ensure the opacity of the last segment is 1 [S5, unofficial].
*   **Alpha:** $\alpha_i = 1 - \exp(-\hat{\sigma}_i \delta_i)$, where $\hat{\sigma}_i = \text{ReLU}(\sigma_i + \mathcal{U}[0, 1] \cdot \text{raw\_noise\_std})$ [S5, unofficial].
*   **Transmittance:** $T_i = \exp\left(-\sum_{j=1}^{i-1} \hat{\sigma}_j \delta_j\right)$ [S5, unofficial].
*   **Weight:** $w_i = \alpha_i T_i$ [S5, unofficial].
*   **RGB Map:** $\mathbf{C} = \sum_{i=1}^{N} w_i \mathbf{c}_i$ [S5, unofficial].
*   **Loss:** $L = L_{coarse} + L_{fine}$, where $L_{coarse} = \text{mean}((\mathbf{C}_{coarse} - \mathbf{C}^*)^2)$ and $L_{fine} = \text{mean}((\mathbf{C}_{fine} - \mathbf{C}^*)^2)$ [S4, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn.functional as F

def raw2outputs(raw, z_vals, rays_d, raw_noise_std=0, white_bkgd=False):
    """
    Converts raw MLP outputs to radiance and weights.
    raw: (ray #, sample #, 4) -> RGB (sigmoided), sigma
    z_vals: (ray #, sample #)
    rays_d: (ray #, 3)
    """
    # Calculate segment lengths
    dists = z_vals[..., 1:] - z_vals[..., :-1]
    # Append infinite distance for the last segment
    dists = torch.cat([dists, torch.Tensor([1e10]).expand(dists[..., :1].shape).to(z_vals.device)], -1)
    # Scale by ray direction norm
    dists = dists * torch.norm(rays_d[..., None, :], dim=-1)

    # Extract RGB and Sigma
    rgb = torch.sigmoid(raw[..., :3])
    sigma_raw = raw[..., 3]

    # Add noise to sigma
    noise = 0.
    if raw_noise_std > 0.:
        noise = torch.randn(sigma_raw.shape) * raw_noise_std

    # Compute alpha: 1 - exp(-sigma * dist)
    # Apply ReLU to sigma before computing alpha
    alpha = 1. - torch.exp(-F.relu(sigma_raw + noise) * dists)

    # Compute transmittance T: cumprod(1 - alpha)
    # Prepend 1.0 for the start of the ray
    ones = torch.ones_like(alpha[..., :1])
    recips = 1. - alpha + 1e-10
    T = torch.cumprod(torch.cat([ones, recips], -1), -1)[:, :-1]

    # Compute weights: w_i = alpha_i * T_i
    weights = alpha * T

    # Compute RGB map
    rgb_map = torch.sum(weights[..., None] * rgb, -2)

    # Compute depth map
    depth_map = torch.sum(weights * z_vals, -1)

    # Compute accumulation map
    acc_map = torch.sum(weights, -1)

    # Handle white background
    if white_bkgd:
        rgb_map = rgb_map + (1. - acc_map[..., None])

    return rgb_map, depth_map, acc_map, weights

def render_rays(rays_o, rays_d, coarse_mlp, fine_mlp, n_coarse=64, n_fine=128, perturb=True):
    """
    Renders rays using Coarse-to-Fine NeRF.
    """
    near, far = 2.0, 6.0 # Example bounds
    batch_size = rays_o.shape[0]
    device = rays_o.device

    # 1. Coarse Sampling
    t_vals = torch.linspace(near, far, n_coarse, device=device)
    t_vals = t_vals.expand(batch_size, n_coarse)

    if perturb:
        mid = (t_vals[..., :-1] + t_vals[..., 1:]) / 2
        upper = torch.cat([mid, t_vals[..., -1:]], dim=-1)
        lower = torch.cat([t_vals[..., :1], mid], dim=-1)
        t_vals = lower + (upper - lower) * torch.rand_like(t_vals)

    # Convert to 3D points
    pts_coarse = rays_o.unsqueeze(-2) + rays_d.unsqueeze(-2) * t_vals.unsqueeze(-1)

    # 2. Coarse Query
    # Assume mlp returns (B, N, 4)
    raw_coarse = coarse_mlp(pts_coarse)

    # 3. Coarse Rendering
    rgb_coarse, depth_coarse, acc_coarse, weights_coarse = raw2outputs(
        raw_coarse, t_vals, rays_d, raw_noise_std=0.0
    )

    # 4. Gradient Cut
    # Detach weights and t_vals to prevent gradients flowing back to coarse mlp
    weights_coarse_detached = weights_coarse.detach()
    t_vals_detached = t_vals.detach()

    # 5. Hierarchical Sampling
    # Compute midpoints for sampling
    z_vals_mid = 0.5 * (t_vals_detached[..., 1:] + t_vals_detached[..., :-1])

    # Importance sampling from weights_coarse
    # Sample_pdf is a helper that performs inverse transform sampling
    # Here we implement a simplified version assuming uniform binning for clarity
    # In practice, sample_pdf uses the CDF of weights_coarse
    u = torch.rand_like(t_vals_detached)
    # This is a placeholder for the actual inverse CDF sampling logic
    # which maps uniform random u to t_fine based on weights_coarse
    # For implementation completeness, we assume a function `sample_pdf` exists
    # or implement the inverse transform sampling explicitly:
    
    # Cumulative sum of weights
    cdf = torch.cumsum(weights_coarse_detached, -1)
    cdf = torch.cat([torch.zeros_like(cdf[..., :1]), cdf], -1)
    cdf = cdf.detach() # Ensure detached
    
    # Normalize cdf to [0, 1]
    cdf = cdf / cdf[..., -1:]
    
    # Find indices where u falls
    indices = torch.searchsorted(cdf, u, side='right')
    # Clamp indices
    indices = torch.clamp(indices, 1, n_coarse - 1)
    
    # Linear interpolation between z_vals_mid
    z0 = t_vals_detached.gather(1, indices - 1)
    z1 = t_vals_detached.gather(1, indices)
    
    # Interpolate
    f0 = cdf.gather(1, indices - 1)
    f1 = cdf.gather(1, indices)
    denom = f1 - f0 + 1e-10
    t_fine = z0 + (u - f0) / denom * (z1 - z0)

    # 6. Fine Preparation
    t_all = torch.cat([t_vals_detached, t_fine], -1)
    t_all_sorted, _ = torch.sort(t_all, dim=-1)
    
    pts_fine = rays_o.unsqueeze(-2) + rays_d.unsqueeze(-2) * t_all_sorted.unsqueeze(-1)

    # 7. Fine Query
    raw_fine = fine_mlp(pts_fine)

    # 8. Fine Rendering
    rgb_fine, depth_fine, acc_fine, weights_fine = raw2outputs(
        raw_fine, t_all_sorted, rays_d, raw_noise_std=0.0
    )

    return {
        'rgb_coarse': rgb_coarse,
        'depth_coarse': depth_coarse,
        'rgb_fine': rgb_fine,
        'depth_fine': depth_fine
    }
```

## Subtopics

### Single Multiscale MLP Architecture
A variant that uses a single MLP with parameters $\Theta$ for both coarse and fine stages, enabled by Implicit Positional Encoding (IPE) which explicitly encodes scale into input features [S6]. Unlike standard NeRF which requires two distinct MLPs because standard PE features only model one scale, this approach allows one MLP to learn a multiscale representation [S6]. The optimization balances coarse and fine losses using a hyperparameter $\lambda$ (default 0.1) [S6].

### Segmented Sampling
A strategy that selectively increases the sampling rate only within the bounding box of an object area to ensure detailed sampling without significantly increasing overall computational cost [S7]. It addresses the pitfall where standard uniform sampling results in sparse points on small objects relative to the scene, causing parts of the object to fall between sampled points and leading to inaccurate PDFs in the fine stage [S7].

### DONeRF PDF Sampling
A method that translates depth oracle classification outputs into sample locations by treating the output vector as a piecewise-constant Probability Density Function (PDF) and sampling from its Cumulative Distribution Function (CDF) [S8]. Unlike NeRF, which builds a PDF from opacity outputs of a coarse shading network evaluated at multiple sample locations, DONeRF uses the output from a single oracle network evaluation [S8].

## Operating characteristics
*   **Time Complexity:** The method requires two passes per ray: $N_C$ queries for the coarse network and $N_C + N_F$ queries for the fine network. Total MLP evaluations per ray are $2N_C + N_F$. With typical values $N_C=64, N_F=128$, this is 256 evaluations, compared to 192 for uniform sampling with similar detail [S4, unofficial][S6].
*   **Memory Complexity:** Requires storing intermediate tensors for coarse outputs, weights, and fine samples. The memory footprint is proportional to $B \times (N_C + N_F)$ [S5, unofficial].
*   **Performance:** Improves rendering quality by clustering samples near opaque regions, reducing aliasing and improving detail learning [S1, unofficial]. It is more computationally expensive than single-pass uniform sampling but more efficient than uniformly dense sampling for the same level of detail [S2][S4, unofficial].
*   **Strengths:** Efficiently allocates samples to high-detail areas; reduces noise and artifacts from sparse sampling [S1, S4, unofficial].
*   **Limitations:** Requires careful tuning of $N_C$ and $N_F$; the gradient cut prevents joint optimization of the sampling distribution with the coarse network's density prediction [S4, S5, unofficial].

## Background
Coarse-to-Fine NeRF, also known as Hierarchical Rendering, was introduced in the original NeRF paper by Mildenhall et al. in 2020 [S2, S8]. It was designed to improve computational efficiency and rendering quality by using a coarse network to guide the sampling of a fine network [S2]. The method has become a standard component in many NeRF variants and acceleration techniques [S2].
