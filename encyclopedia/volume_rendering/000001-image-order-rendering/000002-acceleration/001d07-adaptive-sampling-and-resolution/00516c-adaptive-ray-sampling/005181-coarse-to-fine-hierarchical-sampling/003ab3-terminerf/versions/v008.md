# TermiNeRF

Also called: Ray Termination Prediction, TermiNeRF Sampling Distribution Learning

## Overview
TermiNeRF is a method for efficient neural rendering that jointly trains a sampling network and a color network to predict ray termination weights, allowing for fewer color network evaluations by concentrating samples where opacity is high [S1]. It splits the NeRF network into a sampling network and a shading network, where the sampling network predicts suitable sample locations with a single evaluation per view ray, and the shading network adaptively shades only the most significant samples [S2]. It sets itself apart from siblings like [Coarse-to-Fine NeRF](3406-coarse-to-fine-nerf.md) by learning a direct mapping from camera rays to ideal sampling distributions rather than relying on hierarchical coarse-to-fine depth estimation, and from [NeRF-ID](8867-nerf-id.md) by conditioning the sampling network on the density of a pretrained NeRF without requiring explicit depth maps [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A viewing ray defined by origin $O$ and direction $d$, and a pre-trained color network (NeRF).
*   **Output:** A rendered pixel color $C$ computed via volumetric rendering using a sparse set of samples determined by the sampling network.

**Data Structures:**
*   **Sampling Network:** An MLP with 8 hidden layers, 256 units per layer, and a skip connection to the fifth layer [S1]. It takes the ray representation as input and outputs $N$ weights corresponding to $N$ bins along the ray.
*   **Ray Representation:** To avoid ambiguity in ray parameterization, rays are discretized into segments of constant length $\ell$ [S1].
    *   A segment is defined by two points $A$ and $B$ such that $|B - A| = \ell$.
    *   The direction is $\vec{d} = B - A$.
    *   The midpoint of the segment is the closest point to the scene origin: $O = \frac{A+B}{2}$ [S1].
    *   The segment length $\ell$ is set to 4.0 [S1].
*   **Sample Points:** The bins are delimited by boundary points. For a segment with boundaries $A$ and $B$, the sample points are centered-logarithmically spaced:
    $$ \{A, A + s_2 \cdot \vec{d}, \dots, A + s_{N-1} \cdot \vec{d}, B\} $$
    where $\vec{d} = B - A$ [S1]. The scalars $s_i$ are formed by concatenating $l$ and $u$:
    $$ l_i = 1 - 2^{\frac{1-i}{N/2-1}} \quad \text{for } i \in \{1, \dots, N/2 - 1\} $$
    $$ u_j = 2^{\frac{j-N/2}{N/2-1}} \quad \text{for } j \in \{1, \dots, N/2\} $$
    The last bin spans from the last boundary point up to infinity [S1].

**Training Procedure:**
1.  **Pre-train Color Network:** Train the standard NeRF color network until convergence [S1].
2.  **Generate Ground Truth Weights:** For each ray, evaluate the fine NeRF network 64+128 times to obtain 196 tuples of $(z_i, w_i)$, where $z_i$ is the distance from the ray origin and $w_i$ is the weight [S1]. The ground truth weight for sample $i$ is:
    $$ w_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right) (1 - \exp(-\sigma_i \delta_i)) $$
    where $\delta_i = z_{i+1} - z_i$ is the distance between neighboring samples [S1].
3.  **Normalize Weights:** Normalize the weights such that $\hat{w}_i = \frac{w_i}{\sum_{j=0}^{N} w_j}$ [S1].
4.  **Distribution Matching (Max-Resampling):** Because the ground truth weights are defined at arbitrary $z$-values, they must be mapped to the fixed bins of the sampling network. Perform max-resampling to assign weight $\hat{w}_j$ to new bin $b_j$ delimited by $[\hat{z}_j, \hat{z}_{j+1}]$:
    $$ \hat{w}_j = \max \{ w_i | \hat{z}_j \le z_i \le \hat{z}_{j+1} \} \cup \{ w'_j, w'_{j+1} \} $$
    where $w'_j$ is the linear interpolation of weights from the old distribution for $\hat{z}_j$ [S1]. This step ensures peaks in the original distribution appear in the resampled variant and preserves importance regardless of local sample density [S1].
5.  **Gaussian Blur:** Apply Gaussian blur to the resampled weights to smooth noise. The Euclidean distance covered by the blur window is $d = \frac{K}{N_{samples}} * \ell$. Typical parameters are window size $K=9$ and sigma $\sigma=3.0$ [S1].
6.  **Normalize Again:** Normalize the blurred and resampled weights [S1].
7.  **Train Sampling Network:** Train the sampling network using MSE loss against the normalized, blurred, and distribution-matched weights [S1]. The sampling network is conditioned on the density of the pretrained NeRF [S2].
8.  **Joint Fine-Tuning:** Alternate updates of the color and sampling networks. Sample 128 points from the predicted distribution and add 64 equidistantly sampled points along the whole ray between near and far $z$-values to ensure density values are acquired for unsampled regions [S1]. Use Adam optimizer with initial learning rate $5 \cdot 10^{-4}$ for the sampling network and $5 \cdot 10^{-5}$ for the color network [S1].

**Rendering Procedure:**
1.  For each viewing ray, evaluate the sampling network once to estimate the distribution of ideal sampling locations [S1].
2.  Draw ray points stochastically according to the predicted distribution [S1].
3.  Evaluate the color network at these sampled points.
4.  Aggregate the final color via volumetric rendering [S1].

    Generate sample points between A and B using centered-logarithmic spacing.
    Returns list of points.
    """

    points = [A, B]

        points.append(A + s * d)

def interpolate_weight(z, w, target_z):
    """
    Linear interpolation of weight at target_z given z and w arrays.
    """
    # Find indices
    idx = torch.searchsorted(z, target_z)
    if idx == 0:
        return w[0]
    if idx >= len(z):
        return w[-1]
    
    z0, z1 = z[idx-1], z[idx]
    w0, w1 = w[idx-1], w[idx]
    
    if z1 == z0:
        return w0
    
    t = (target_z - z0) / (z1 - z0)
    return w0 + t * (w1 - w0)

## Subtopics

### Coarse-to-Fine NeRF
Uses hierarchical sampling with coarse and fine networks to estimate depth and refine samples. TermiNeRF replaces this with a single sampling network predicting a distribution, avoiding the need for coarse depth estimation [S1].

### NeRF-ID
Uses importance sampling based on density. TermiNeRF differs by explicitly learning a sampling distribution network conditioned on pretrained density, rather than using static or heuristic importance sampling [S2].

## Operating characteristics
*   **Time Complexity:** Rendering time is reduced to $\le 1$ second for an image, compared to up to 30 seconds for standard NeRF on an 800x800 image [S1].
*   **Speedup:** TermiNeRF achieves a 14x speedup relative to standard NeRF [S1]. It achieves similar or higher PSNR/LPIPS than NeRF with significantly fewer forward passes (e.g., 7.32x speedup for TermiNeRF 32 vs NeRF 8+16) [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Fast rendering, efficient fine-tuning (scene fine-tuned up to the penultimate step in only three minutes on GTX1080) [S1]. Does not require a depth map, improving quality in geometrically ambiguous regions [S2].
*   **Limitations:** Requires a pre-trained NeRF to initialize the color network to achieve the best results [S2]. Uneven segment lengths in sphere intersection representations can create computational pressure, handled by enforcing constant length segments [S1].
*   **When to use:** When fast rendering and fine-tuning of neural radiance fields are required, and a pre-trained NeRF is available.
*   **When not to use:** When real-time rendering without pre-training is necessary, or when depth maps are available and hierarchical sampling is preferred.

## Background
TermiNeRF was introduced by Martin Piala and Ronald Clark at Imperial College London in 2021 [S1]. It addresses the slow rendering times of neural fields by learning a direct mapping from camera rays to locations along the ray that are most likely to influence the pixel's final appearance [S1]. The method builds on the concept of splitting the NeRF network into a sampling network and a shading network [S2].
