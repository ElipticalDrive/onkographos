# TermiNeRF

Also called: Ray Termination Prediction, TermiNeRF Sampling Distribution Learning

## Overview
TermiNeRF is a method for efficient neural rendering that jointly trains a lightweight sampling network alongside a color network to predict the distribution of ideal sampling locations along a viewing ray [S1]. By concentrating samples where opacity is high and skipping free space, it significantly reduces the number of color network evaluations required per pixel [S1]. Unlike [Coarse-to-Fine NeRF](3406-coarse-to-fine-nerf.md) which uses a coarse network to estimate weights for hierarchical sampling, TermiNeRF uses a single sampling network evaluation per ray to predict a full weight distribution, enabling rendering speeds up to 14x faster than standard NeRF while maintaining comparable image quality [S1].

## How it works
TermiNeRF splits the neural field into a **Sampling Network** and a **Color (Shading) Network**. The sampling network predicts weights for predefined bins along the ray, which are then used to stochastically sample points for the color network [S1].

### Inputs and Outputs
*   **Input:** Camera ray defined by origin $\mathbf{o}$ and direction $\mathbf{d}$.
*   **Output:** A set of sample points $\{z_i\}$ and their corresponding weights $\{w_i\}$ for the sampling network; final rendered color $\mathbf{C}$ for the color network.

### Data Structures and Ray Parameterization
To avoid ambiguity in ray parameterization and uneven segment lengths, TermiNeRF uses a specific geometric representation [S1]:
1.  **Line Segment:** A segment of constant length $\ell$ (typically $\ell = 4.0$) is defined by endpoints $A$ and $B$ such that $|B - A| = \ell$ [S1].
2.  **Ray Direction:** The direction is given by $\mathbf{d} = B - A$ [S1].
3.  **Origin Projection:** The midpoint of the segment is the closest point to the scene origin: $\mathbf{O} = \frac{A+B}{2}$ [S1].
4.  **Sample Points:** $N$ points are placed within the segment using **centered-logarithmic sampling**. The points are $\{A, A + s_2 \cdot \mathbf{d}, \dots, A + s_{N-1} \cdot \mathbf{d}, B\}$ [S1].
    *   The spacing factors $s_i$ are formed by concatenating two sequences $l$ and $u$:
        $$ l_i = 1 - 2^{\frac{1-i}{N/2-1}}, \quad i \in \{1, \dots, N/2 - 1\} $$
        $$ u_j = 2^{\frac{j-N/2}{N/2-1}}, \quad j \in \{1, \dots, N/2\} $$
    *   The full set of $s$ is $[l_1, \dots, l_{N/2-1}, u_1, \dots, u_{N/2}]$ [S1].
    *   These points define the boundaries of $N$ bins. The last bin extends from the last boundary point to infinity [S1].

### Network Architecture
*   **Sampling Network:** An MLP with 8 hidden layers, 256 units per layer, and a skip connection to the fifth layer [S1]. It takes the ray parameters (derived from $A$ and $B$) as input and outputs $N$ raw weights [S1].
*   **Color Network:** Standard NeRF MLP (coarse and fine) [S1].

### Training Procedure
The training occurs in three phases to ensure stable convergence [S1]:
1.  **Pre-training:** Train the Color Network alone using standard NeRF rendering (e.g., 64 coarse + 128 fine samples) until convergence [S1].
2.  **Sampling Network Training:** Train the Sampling Network using the pre-trained Color Network to generate ground truth weights.
3.  **Joint Fine-tuning:** Alternate updates of both networks. During joint training, sample $N_{pred}$ points from the predicted distribution and add $N_{eq}$ equidistantly spaced points along the whole ray (e.g., 128 predicted + 64 equidistant) to ensure density values are acquired for unsampled regions [S1].

### Ground Truth Weight Generation
To train the sampling network, ground truth weights $w_i$ are computed from the fine Color Network [S1]:
1.  Evaluate the fine network at $N_{total}$ points (e.g., 196 points: 64 coarse + 128 fine) to get densities $\sigma_j$ [S1].
2.  Compute weights using alpha compositing:
    $$ w_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right) (1 - \exp(-\sigma_i \delta_i)) $$
    where $\delta_i = z_{i+1} - z_i$ is the distance between neighboring samples [S1].

### Distribution Matching and Smoothing
The raw weights from the Color Network are noisy and defined on irregular bins. They must be transformed to match the Sampling Network's fixed bin structure [S1]:
1.  **Max-Resampling:** Map the irregular ground truth weights to the fixed bins. For a new bin $b_j$ delimited by $[\hat{z}_j, \hat{z}_{j+1}]$, the weight $\hat{w}_j$ is:
    $$ \hat{w}_j = \max \{ w_i \mid \hat{z}_j \le z_i \le \hat{z}_{j+1} \} \cup \{ w'_j, w'_{j+1} \} $$
    where $w'_j$ is the linear interpolation of weights from the old distribution at $\hat{z}_j$ [S1].
2.  **Gaussian Blurring:** Apply a Gaussian blur to the resampled weights to smooth noise. The blur window size $K$ (e.g., $K=9$) and sigma $\sigma$ (e.g., $\sigma=3.0$) are fixed [S1]. The Euclidean distance covered by the window is $d = \frac{K}{N_{samples}} \cdot \ell$ [S1].
3.  **Normalization:** Normalize the final weights so they sum to 1:
    $$ \hat{w}_i = \frac{w_i}{\sum_{j=0}^{N} w_j} $$
    [S1]

### Rendering Pipeline
1.  **Sampling Network Evaluation:** For each ray, evaluate the Sampling Network once to get $N$ raw weights [S1].
2.  **Normalization:** Normalize the output weights [S1].
3.  **Stochastic Sampling:** Draw $N_{samples}$ points along the ray according to the predicted distribution [S1].
4.  **Color Network Evaluation:** Evaluate the Color Network at the sampled points [S1].
5.  **Volumetric Rendering:** Aggregate the colors using alpha compositing [S1].

## Operating characteristics
*   **Speed:** TermiNeRF achieves a 14x speedup relative to standard NeRF [S1]. It reduces rendering time to $\le 1$ second for an image [S1]. It achieves a 7.32x speedup compared to NeRF with 8+16 samples when using 32 samples [S1].
*   **Quality:** Achieves similar or higher PSNR/LPIPS than standard NeRF [S1].
*   **Memory:** The sampling network is small (8 layers, 256 units), adding minimal memory overhead [S1].
*   **Training Time:** Fine-tuning a scene can take as little as 3 minutes on a GTX 1080 [S1].
*   **Limitations:** Requires a pre-trained NeRF to initialize the color network for best results [S2]. The method relies on a fixed segment length $\ell$, which may not adapt to scenes with varying scales without adjustment [S1].

## Background
TermiNeRF was introduced by Martin Piala and Ronald Clark at Imperial College London in 2021 [S1]. It was presented at the 2021 International Conference on 3D Vision (3DV) [S1]. The method addresses the slow rendering times of neural radiance fields (NeRF) by learning a direct mapping from camera rays to important sample locations [S1].
