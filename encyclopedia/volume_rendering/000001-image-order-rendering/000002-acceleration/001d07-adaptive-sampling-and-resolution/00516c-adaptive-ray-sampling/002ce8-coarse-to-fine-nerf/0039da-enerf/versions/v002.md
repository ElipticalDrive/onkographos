# ENeRF
Also called: Cascade Cost Volume NeRF
## Overview
ENeRF is a method for efficient neural radiance field training that replaces uniform ray sampling with geometry-aware sampling guided by a cascade cost volume [S1]. It builds on [Coarse-to-Fine NeRF](3406-coarse-to-fine-nerf.md) by introducing a 3D feature volume to predict coarse depth and confidence maps, allowing the fine network to sample points near the scene surface [S1]. This reduces the number of sample points per ray by up to 128× while maintaining competitive accuracy [S1].
## How it works
**Inputs:** A set of calibrated multi-view images with known camera poses [S1][S2, unofficial].
**Outputs:** A fine radiance field model and associated geometry-aware features [S1].

**Data Structures:**
1. **Cascade Cost Volume (3D Feature Volume):** A 3D grid storing features derived from multi-view image patches, used to predict coarse geometry [S1].
2. **Depth Map:** A 2D tensor predicting the distance to the scene surface for each pixel [S1].
3. **Confidence Map:** A 2D tensor indicating the reliability of the depth prediction [S1].

**Steps:**
1. **Build Cascade Cost Volume:** Construct a 3D feature volume from the input multi-view images by aggregating geometric information across views [S1].
2. **Predict Coarse Geometry:** Use the 3D feature volume to predict a coarse depth map and a confidence map for each input view [S1].
3. **Sample Near Surface:** For each ray, use the predicted depth and confidence to sample a small number of points located near the estimated scene surface [S1]. This reduces sample points compared to uniform or hierarchical sampling [S1].
4. **Train Radiance Field:** Train the fine radiance field MLP using the samples from Step 3. The 3D feature volume also provides rich geometry-aware features to aid in constructing the generalizable radiance field [S1].

**Parameters:**
* Sample count per ray: Reduced by up to 128× compared to baseline methods [S1].
* Thresholds for depth/confidence: Not given in the sources.

**Edge Cases and Pitfalls:**
* The method struggles without high-quality depth supervision [S1].
* Precision issues may arise in the depth prediction step if the cost volume resolution is insufficient [G].

## Subtopics

### Cascade Cost Volume
A 3D feature volume used to predict coarse geometry [S1]. It aggregates geometric information across views to construct a generalizable radiance field [S1].

### Geometry-Aware Sampling
Sampling points near the predicted surface depth [S2, unofficial]. It differs from uniform sampling by focusing computational effort on relevant geometry, reducing sample counts by up to 128× [S1].

## Operating characteristics
* **Time Complexity:** Rendering speed is significantly improved due to reduced sample counts (up to 128× reduction) [S1].
* **Memory Complexity:** Requires storage for the 3D feature volume (cascade cost volume) [S1].
* **Strengths:** High rendering speed, competitive accuracy, uses multi-view geometry to reduce sampling overhead [S1][S2, unofficial].
* **Limitations:** Requires high-quality depth supervision for optimal performance [S1].
* **When to use:** When multi-view input is available and reducing sample counts is prioritized [S1][S2, unofficial].
* **When not to use:** When depth supervision is unavailable or low-quality [S1].
## Background
ENeRF was introduced in "Efficient Neural Radiance Fields for Interactive Free-viewpoint Video" (SIGGRAPH Asia 2022) [S1]. It was inspired by deep learning techniques for multiview stereo [S1]. It addresses the limitations of earlier cost volume methods that were not end-to-end trainable and struggled without high-quality depth supervision [S1].
