# Deformed Space Sampling

Also called: Backward Mapping Sampling, Deformed-to-Canonical Sampling

## Overview
Deformed Space Sampling is a technique for adaptive ray sampling in volume rendering that decouples the sampling locations from the evaluation domain. It addresses the inefficiency of sampling uniformly in canonical space when the underlying geometry or appearance is non-rigid or highly anisotropic. By sampling along rays in a deformed (or local) coordinate system and evaluating the neural network in canonical space, it concentrates queries where deformation or detail is highest, reducing redundant volume queries compared to fixed canonical sampling.

## How it works
The method relies on a backward mapping scheme where the spatial domain is split into two representations: a deformed space for determining *where* to sample, and a canonical space for determining *what* to evaluate.

**Inputs:**
- Ray origin $\mathbf{o}$ and direction $\mathbf{d}$.
- Deformation field or local coordinate transformation function $T(\mathbf{x})$ that maps canonical coordinates $\mathbf{x}_c$ to deformed coordinates $\mathbf{x}_d$.
- Neural network (e.g., NeRF) $\mathcal{N}$ defined in canonical space.

**Outputs:**
- Set of sample points $\{\mathbf{x}_i\}$ and their corresponding weights or contributions.

**Data Structures:**
- A deformation field or grid storing local transformations.
- The canonical volume representation (e.g., MLP or voxel grid).

**Steps:**
1. **Ray Parameterization in Deformed Space:**
   Instead of parameterizing the ray uniformly in canonical space ($\mathbf{x}_c(t) = \mathbf{o}_c + t\mathbf{d}_c$), the ray is parameterized in the deformed space. This often involves finding the intersection of the ray with the deformed geometry or using a local coordinate system that adapts to the deformation. Let the sampling positions in deformed space be $\mathbf{x}_d^{(i)}$.

2. **Backward Mapping:**
   For each sample point $\mathbf{x}_d^{(i)}$ in deformed space, compute the corresponding canonical coordinate $\mathbf{x}_c^{(i)}$ using the inverse of the deformation transformation:
   $$ \mathbf{x}_c^{(i)} = T^{-1}(\mathbf{x}_d^{(i)}) $$
   If the deformation is defined as a forward map $T: \mathbf{x}_c \to \mathbf{x}_d$, this step requires solving for $\mathbf{x}_c$. In many implementations (like NeRFshop), this is handled by evaluating the deformation field to find the canonical position that maps to the deformed sample location.

3. **Canonical Evaluation:**
   Evaluate the neural network $\mathcal{N}$ at the canonical coordinates $\mathbf{x}_c^{(i)}$ to obtain density $\sigma$ and color $\mathbf{c}$:
   $$ \sigma_i, \mathbf{c}_i = \mathcal{N}(\mathbf{x}_c^{(i)}) $$

4. **Compositing:**
   Composite the results using standard volume rendering integration over the deformed space intervals, but using the values evaluated in canonical space.

**Pseudocode:**
```python
def deformed_space_sampling(ray_origin, ray_direction, deformation_field, nerf_model):
    # 1. Determine sampling points in deformed space
    # This might involve intersecting with deformed geometry or adaptive sampling
    # based on local deformation metrics.
    deformed_samples = compute_deformed_samples(ray_origin, ray_direction, deformation_field)
    
    canonical_samples = []
    for x_d in deformed_samples:
        # 2. Backward mapping: Deformed -> Canonical
        # T_inv is the inverse of the deformation transformation
        x_c = deformation_field.inverse_transform(x_d)
        canonical_samples.append(x_c)
        
    # 3. Evaluate in canonical space
    densities = []
    colors = []
    for x_c in canonical_samples:
        sigma, c = nerf_model(x_c)
        densities.append(sigma)
        colors.append(c)
        
    # 4. Composite using deformed space intervals
    # The step sizes dt are determined in deformed space
    return composite(densities, colors, deformed_samples)
```

**Edge Cases:**
- **Non-invertible Deformations:** If the deformation field is not bijective, $T^{-1}$ may be ambiguous. [G] In practice, this is handled by using the nearest canonical point or regularizing the deformation field.
- **Precision Loss:** Mapping between spaces can introduce floating-point errors. [G] Using double precision for coordinate transformations is recommended.

## Subtopics

### [Multi-scale Interactive Ray Sampling](18926-multi-scale-interactive-ray-sampling.md)
Multi-scale Interactive Ray Sampling is a technique for projecting high-dimensional interaction features into a compact 4D space ($\mathbb{R}^4$) using ray sampling, allowing the retrieval of deformable features from local 4D deformable fields by maximizing sampling probability. It builds on [Deformed Space Sampling](18731-deformed-space-sampling.md) by factorizing high-dimensional interaction variables into a 4D representation compressed via K-Planes, enabling efficient iterative sampling from coarse to fine scales.

## Operating characteristics
- **Time Complexity:** Depends on the cost of the inverse deformation transformation. If $T^{-1}$ is expensive, it can dominate the per-sample cost.
- **Memory Complexity:** Requires storing the deformation field in addition to the canonical volume representation.
- **Strengths:** Reduces sampling redundancy in regions of high deformation or detail. Improves convergence for dynamic scenes.
- **Limitations:** Requires a valid deformation field. Inverse transformations may be computationally expensive or ill-posed.

## Background
Deformed Space Sampling is used in neural rendering methods that handle non-rigid scenes, such as NeRFshop. It was introduced to address the limitations of static canonical sampling in dynamic environments.
