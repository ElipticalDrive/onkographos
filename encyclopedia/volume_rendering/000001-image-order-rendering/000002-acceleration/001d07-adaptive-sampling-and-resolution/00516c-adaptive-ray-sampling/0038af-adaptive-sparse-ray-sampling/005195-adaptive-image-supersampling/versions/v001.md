# Adaptive Image Supersampling
Also called: Adaptive image sampling optimization, adaptive sampling with synchronization

## Overview
Adaptive Image Supersampling is an acceleration method that exploits pixel-space coherency by casting rays from a sparse subset of screen pixels and interpolating values for empty pixels, while selectively increasing ray density in regions of high image gradient or depth variance [S2, S2, unofficial][S1]. It differs from its parent, Adaptive Sparse Ray Sampling, by explicitly defining the mechanism for handling the "empty" pixels between the sparse grid (interpolation) and the specific criterion for refinement (image gradient/depth discontinuity) rather than just general complexity [S2, S2, unofficial][S1].

## How it works
**Inputs and Outputs:**
- Input: A volume dataset, a camera configuration, and a sparse ray grid (e.g., every other pixel).
- Output: A rendered image with adaptive resolution.

**Data Structures:**
- `ImageBuffer`: A 2D array of color/depth values corresponding to screen pixels.
- `RayGrid`: A boolean mask or coordinate list indicating which pixels have been explicitly ray-cast.

**Steps:**
1. **Sparse Ray Casting:** Cast rays only from a subset of screen pixels. A common pattern is a regular grid, such as every other pixel in both dimensions [S2, S2, unofficial].
2. **Interpolation:** For pixels not explicitly cast ("empty pixels"), assign values by interpolating from the nearest cast pixels. This step assumes pixel-space coherency, meaning adjacent pixels with similar values can be approximated without explicit ray casting [S2, S2, unofficial].
3. **Gradient Analysis:** Compute the local image gradient (or depth variance) for the interpolated image. Regions with significant gradients indicate edges or depth discontinuities [S1][S2, S2, unofficial].
4. **Adaptive Refinement:** In areas where the image gradient exceeds a threshold, cast additional rays to resolve ambiguities. This effectively performs supersampling only where necessary [S1][S2, S2, unofficial].

**Pseudocode:**
```python
def adaptive_image_supersampling(volume, camera, threshold):
    # Step 1: Cast rays from a sparse subset (e.g., every other pixel)
    sparse_pixels = get_sparse_grid(camera.resolution, stride=2)
    image_buffer = initialize_image(camera.resolution)
    
    for pixel in sparse_pixels:
        ray = camera.generate_ray(pixel)
        color = cast_ray(volume, ray)
        image_buffer[pixel] = color
        
    # Step 2: Interpolate empty pixels
    # Note: Specific interpolation kernel (bilinear, nearest) is not detailed in sources [G]
    interpolate_empty_pixels(image_buffer, sparse_pixels)
    
    # Step 3 & 4: Analyze gradient and refine
    gradients = compute_image_gradients(image_buffer)
    
    for pixel in camera.all_pixels():
        if gradients[pixel] > threshold:
            # Cast additional rays for this pixel (supersampling)
            # Note: Number of additional rays and pattern (jittered/grid) not specified [G]
            additional_rays = generate_supersample_rays(camera, pixel)
            refined_color = average_colors([cast_ray(volume, r) for r in additional_rays])
            image_buffer[pixel] = refined_color
            
    return image_buffer
```

**Parameters:**
- `stride`: The spacing of the initial sparse grid. Typical value: 2 (every other pixel) [S2, S2, unofficial].
- `threshold`: The gradient magnitude above which additional rays are cast. Not given in the sources.

**Edge Cases:**
- **Uniform Regions:** If the volume is homogeneous, interpolation suffices, and no additional rays are cast, maximizing efficiency [S1][S2, S2, unofficial].
- **High-Frequency Details:** If the initial sparse grid undersamples high-frequency details, aliasing may occur before refinement. The threshold must be tuned to detect these early [S1].

## Operating characteristics
**Time and Memory Complexity:**
- Time complexity is reduced compared to full supersampling because rays are only cast for a subset of pixels initially. The complexity depends on the fraction of pixels requiring refinement.
- Memory complexity is dominated by the image buffer and the sparse ray grid.

**Measured Performance:**
- Not given in the sources.

**Strengths and Limitations:**
- **Strengths:** Exploits pixel-space coherency to skip empty space and uniform regions, providing significant speedup without affecting image quality in smooth areas [S2, S2, unofficial].
- **Limitations:** Relies on the assumption of coherency; may fail in highly textured or noisy volumes. Interpolation artifacts may appear if the sparse grid is too coarse [S2, S2, unofficial].

**When to Use:**
- Use when the volume has large homogeneous regions or smooth gradients.
- Use when computational resources are limited and a trade-off between quality and speed is acceptable.

**When Not to Use:**
- Avoid for volumes with high-frequency noise or complex, non-coherent structures where interpolation is inaccurate.

## Background
Adaptive image supersampling was originally developed for traditional ray-tracing and later adapted to volume rendering [S2, S2, unofficial]. It extends the concept of supersampling, which casts multiple rays per pixel to approximate integrals, by varying the number of rays based on local depth variance or image gradient [S1]. This approach balances quality and efficiency by allocating more samples to regions with significant depth discontinuities (edges) and fewer in uniform areas [S1].
