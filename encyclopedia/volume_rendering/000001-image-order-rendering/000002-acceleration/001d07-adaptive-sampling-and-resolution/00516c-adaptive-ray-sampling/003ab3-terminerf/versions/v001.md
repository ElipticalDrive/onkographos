# TermiNeRF

Also called: Ray Termination Prediction, TermiNeRF Sampling Distribution Learning

## Overview
TermiNeRF is a method for efficient neural rendering that jointly trains a sampling network and a color network to predict the distribution of ideal sampling locations along a viewing ray, allowing the color network to skip points in free space [S1]. It sets itself apart from sibling methods like [Coarse-to-Fine NeRF](3406-coarse-to-fine-nerf.md) by learning a direct mapping from camera rays to importance weights with a single network evaluation per ray, rather than relying on hierarchical coarse-to-fine evaluation or explicit depth maps [S1, S2].

## How it works
**Inputs and Outputs:**
- **Input:** A viewing ray defined by origin $O$ and direction $d$.
- **Output:** A set of sample positions along the ray and their associated importance weights, which are used to query the color network for final pixel color via volumetric rendering [S1].

**Data Structures:**
- **Ray Representation:** To avoid ambiguity in ray parameterization, rays are discretized into segments of constant length $\ell$. A segment is defined by two boundary points $A$ and $B$ such that $|B - A| = \ell$. The direction is $\vec{d} = B - A$. The midpoint of the segment is the closest point to the scene origin $O$ [S1].
- **Sampling Network Architecture:** An MLP with 8 hidden layers, 256 units per layer, and a skip connection to the fifth layer [S1].
- **Color Network:** The standard NeRF MLP (coarse and fine networks) [S1].

**Numbered Steps:**

1.  **Pre-training:** Pre-train the color network (NeRF) on the scene data until convergence [S1].
2.  **Ray Discretization:** For each viewing ray, define the segment boundaries $A$ and $B$ using the constant length $\ell$ (typically 4.0) and the ray's position relative to the scene center [S1].
3.  **Ground Truth Weight Generation:** Evaluate the pre-trained fine color network at $N_{fine} = 128$ points and the coarse network at $N_{coarse} = 64$ points along the ray. This yields 196 tuples of $(z_i, w_i)$, where $z_i$ is the distance from the ray origin and $w_i$ is the contribution weight [S1].
    - The weight for sample $i$ is calculated as:
      $$ w_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right) (1 - \exp(-\sigma_i \delta_i)) $$
      where $\delta_i = z_{i+1} - z_i$ is the distance between neighboring samples [S1].
4.  **Centered-Logarithmic Sampling Points:** Define the target bin boundaries for the sampling network using centered-logarithmic sampling. Given boundaries $A$ and $B$, the sample points $s_i$ are formed by concatenating lower ($l$) and upper ($u$) sequences:
    $$ \{A, A + s_2 \cdot \vec{d}, \dots, A + s_{N-1} \cdot \vec{d}, B\} $$
    where $\vec{d} = B - A$, and:
    $$ l_i = 1 - 2^{\frac{1-i}{N/2-1}}, \quad i \in \{1, \dots, N/2 - 1\} $$
    $$ u_j = 2^{\frac{j-N/2}{N/2-1}}, \quad j \in \{1, \dots, N/2\} $$
    These points form the boundaries of the bins for which the sampling network will predict weights [S1].
5.  **Distribution Matching (Max-Resampling):** Because the ground truth weights from Step 3 are defined at arbitrary $z_i$ values, they must be mapped to the fixed bin boundaries from Step 4. Perform max-resampling to assign weight $\hat{w}_j$ to new bin $b_j$ delimited by $[\hat{z}_j, \hat{z}_{j+1}]$:
    $$ \hat{w}_j = \max \{ w_i \mid \hat{z}_j \le z_i \le \hat{z}_{j+1} \} \cup \{ w'_j, w'_{j+1} \} $$
    where $w'_j$ is the linear interpolation of weights from the old distribution for $\hat{z}_j$ [S1].
6.  **Blurring:** Apply Gaussian blurring to the resampled weights to reduce noise. The blur window size $K$ and sigma $\sigma$ are fixed parameters. The Euclidean distance covered by the window is $d = \frac{K}{N_{samples}} \cdot \ell$. For the Lego dataset with 128 samples and $\ell=4.0$, this distance is calculated accordingly. The number of elements in the window varies with local density [S1].
7.  **Normalization:** Normalize the blurred, resampled weights:
    $$ \hat{w}_i = \frac{w_i}{\sum_{j=0}^{N} w_j} $$
    These normalized weights serve as the ground truth labels for the sampling network [S1].
8.  **Sampling Network Training:** Train the sampling network using Mean Squared Error (MSE) loss against the normalized ground truth weights. The sampling network takes the ray parameters (derived from $A$ and $B$) as input and outputs $N$ weights corresponding to the bins [S1].
9.  **Joint Fine-Tuning:** After the sampling network is trained, jointly fine-tune both the sampling and color networks.
    - **Sampling Strategy:** Sample 128 points from the distribution predicted by the sampling network. Additionally, add 64 equidistantly sampled points along the whole ray between near and far $z$-values. This ensures density values are acquired for unsampled regions, preventing the sampling network from getting stuck in local minima where it never sees geometry in free space [S1].
    - **Optimization:** Use the Adam optimizer. Initial learning rate is $5 \cdot 10^{-4}$ for the sampling network and $5 \cdot 10^{-5}$ for the color network [S1].

                return w_vals[-1]

            w0, w1 = w_vals[idx-1], w_vals[idx]
            
            if z1 == z0:
                return w0
            t = (z_target - z0) / (z1 - z0)
            return w0 + t * (w1 - w0)

        candidates = list(local_weights) + [w_prime_start, w_prime_end]
        w_bin = max(candidates)
        w_new.append(w_bin)
        
    return np.array(w_new)

- Gaussian blur window size $K=9$, sigma $\sigma=3.0$ [S1].
- Adam optimizer initial learning rate: $5 \cdot 10^{-4}$ for sampling network, $5 \cdot 10^{-5}$ for color network [S1].
- Segment length $\ell = 4.0$ [S1].

**Edge Cases and Pitfalls:**
- **Uneven Segment Lengths:** Using sphere intersection representations creates uneven segment lengths, which puts computational pressure on the network. This is handled by enforcing a constant length segment $\ell$ [S1].
- **Arbitrary Training Signals:** Training both networks jointly from the beginning is inefficient because the sampling network receives arbitrary training signals from the untrained color network. Therefore, the color network must be pre-trained first [S1].
- **Unsampled Regions:** If only samples from the predicted distribution are used, the color network never sees density values in free space, and the sampling network never learns geometry in those regions. This is mitigated by adding equidistant samples along the whole ray during joint fine-tuning [S1].

## Operating characteristics
- **Time Complexity:** Rendering time is reduced to $\le 1$ second per image, compared to up to 30 seconds for standard NeRF on an 800x800 image [S1].
- **Speedup:** TermiNeRF achieves a 14x speedup relative to standard NeRF [S1]. It achieves similar or higher PSNR/LPIPS with significantly fewer forward passes (e.g., 7.32x speedup for TermiNeRF 32 vs NeRF 8+16) [S1].
- **Memory Complexity:** Not given in the sources.
- **Strengths:** Fast rendering and fine-tuning (scene fine-tuned up to the penultimate step in 3 minutes on GTX1080) [S1]. No depth map required [S2].
- **Limitations:** Requires a pre-trained NeRF to initialize the color network for best results [S2].

## Background
TermiNeRF was introduced by Martin Piala and Ronald Clark from Imperial College London in 2021 [S1]. It addresses the slow rendering times of neural radiance fields by learning a sampling distribution. It is used for efficient neural rendering and rapid scene editing [S1].
