# Spatiotemporal Importance Sampling

Also called: Spatiotemporal importance sampling strategy

## Overview
Spatiotemporal importance sampling is an adaptive sampling strategy for volume rendering that assigns higher sampling probabilities to pixels occluded by tools or exhibiting extensive motion, while assigning lower probabilities to stationary tissues [S1]. It solves the problem of inefficient training and poor reconstruction quality in surgical scenes where tool occlusion leads to infrequent representation of tissue pixels, and stationary tissues cause redundant training updates [S1]. Unlike uniform sampling, it addresses the varying learning difficulty across pixels, thereby speeding up convergence and improving the rendering quality of occluded areas [S1].

## How it works
**Inputs:**
- A sequence of $T$ frames (or training images) $\{I_i\}_{i=1}^T$ [S1].
- A sequence of binary tool masks $\{M_i\}_{i=1}^T$, where $M_i$ indicates the presence of a tool in frame $i$ [S1].
- Hyper-parameters: $\alpha$ (lower-bound for weights), $\beta$ (balance factor), $n$ (temporal window radius) [S1].

**Outputs:**
- A sequence of sampling weight maps $\{W_i\}_{i=1}^T$, where each $W_i$ contains the sampling probability for each pixel/ray in frame $i$ [S1].

**Data Structures:**
- $I_i$: Image tensor of shape $(H, W, 3)$, where $H, W$ are height and width, and $3$ represents RGB channels [S1].
- $M_i$: Binary mask tensor of shape $(H, W)$, values $\{0, 1\}$ [S1].
- $W_i$: Weight map tensor of shape $(H, W)$ [S1].
- $\Omega_i$: Occlusion frequency scaling map of shape $(H, W)$ [S1].

**Steps:**
1. **Calculate Temporal Differences:** For each frame $i$, compute the temporal difference with respect to its neighbors within a window of size $n$ [S1]. The difference is calculated on the tool-occluded regions of the images [S1].
2. **Compute Occlusion Frequency Scaling ($\Omega_i$):** Calculate the frequency of tool occlusion for each pixel across the entire sequence [S1].
3. **Compute Raw Weights:** Combine the temporal difference and the occlusion frequency scaling to form the raw sampling weights [S1].
4. **Apply Lower Bound:** Ensure no weight is zero by applying the lower bound $\alpha$ [S1].
5. **Normalize (Optional):** The weights $W_i$ represent relative probabilities and can be normalized to sum to $1$ per frame for actual sampling [S1].

**Formulas:**
The sampling weight map $W_i$ for frame $i$ is defined as [S1]:

$$ W_i = \min \left( \max_{\substack{i-n < j < i+n}} \frac{\| I_i \odot M_i - I_j \odot M_j \|_1}{3}, \alpha \right) \odot \Omega_i $$

$$ \Omega_i = \beta \frac{T M_i}{\sum_{k=1}^T M_k} $$

Where:
- $\odot$ denotes element-wise multiplication [S1].
- $\| \cdot \|_1$ is the $L_1$ norm [S1].
- The division by $3$ normalizes the $L_1$ difference for RGB images (3 channels) [S1].
- $\max_{\substack{i-n < j < i+n}}$ computes the maximum temporal difference within the window $(i-n, i+n)$ [S1].
- $\alpha$ is a lower-bound to avoid zero weight among unchanged pixels [S1].
- $\Omega_i$ specifies higher importance scaling for tissue areas with higher occlusion frequencies [S1].
- $\beta$ is a hyper-parameter for balancing augmentation among frequently occluded areas and time-variant areas [S1].
Note: The source formula uses $\min(\dots, \alpha)$, but the accompanying text describes $\alpha$ as a lower-bound; the implementation follows the source formula exactly [S1].

**Pseudocode:**
```python
def compute_spatiotemporal_weights(frames, masks, T, n, alpha, beta):
    """
    frames: List of T images, shape (H, W, 3), dtype float.
    masks: List of T masks, shape (H, W), dtype float (0 or 1).
    T: Number of time steps.
    n: Temporal window radius.
    alpha: Lower-bound for weights.
    beta: Hyper-parameter for balancing.
    Returns: List of T weight maps, shape (H, W).
    """
    H, W = len(masks[0]), len(masks[0][0])
    weight_maps = []
    
    # Precompute total occlusion count per pixel across all frames
    total_occlusion = [[sum(masks[t][r][c] for t in range(T)) for c in range(W)] for r in range(H)]

    for i in range(T):
        # 1. Calculate maximum temporal difference within window
        max_diff = [[0.0] * W for _ in range(H)]
        for j in range(max(0, i - n), min(T, i + n)):
            if j == i:
                continue
            for r in range(H):
                for c in range(W):
                    # L1 difference per pixel on occluded regions, normalized by 3
                    diff = sum(abs(frames[i][r][c][k] * masks[i][r][c] - frames[j][r][c][k] * masks[j][r][c]) for k in range(3)) / 3.0
                    if diff > max_diff[r][c]:
                        max_diff[r][c] = diff

        # 2. Compute occlusion frequency scaling Omega_i
        omega = [[0.0] * W for _ in range(H)]
        for r in range(H):
            for c in range(W):
                denom = total_occlusion[r][c]
                omega[r][c] = (beta * T * masks[i][r][c]) / denom if denom > 0 else 0.0

        # 3. Combine weights: min(max_diff, alpha) * omega
        w_map = [[0.0] * W for _ in range(H)]
        for r in range(H):
            for c in range(W):
                capped_diff = max_diff[r][c] if max_diff[r][c] < alpha else alpha
                w_map[r][c] = capped_diff * omega[r][c]
        weight_maps.append(w_map)
    return weight_maps
```

## Operating characteristics
- **Time Complexity:** $O(T \cdot H \cdot W \cdot n)$, where $T$ is the number of frames, $H, W$ are image dimensions, and $n$ is the temporal window radius [S1].
- **Memory Complexity:** $O(T \cdot H \cdot W)$ to store the input frames, masks, and output weight maps [S1].
- **Strengths:** Improves convergence speed and rendering quality for occluded tissues in surgical scenes by prioritizing difficult-to-learn pixels [S1]. Reduces redundant training on stationary tissues [S1].
- **Limitations:** Requires accurate binary masks for tool occlusion [S1]. Performance depends on the choice of hyper-parameters $\alpha$ and $\beta$ [S1]. The formula's handling of zero weights and occlusion frequency scaling contains ambiguities that may require tuning [S1].
- **When to use:** When reconstructing dynamic scenes with significant tool occlusion, such as robotic surgery, where uniform sampling leads to poor reconstruction of occluded areas [S1].
- **When not to use:** For static scenes without occlusion, or when tool masks are unavailable [S1].

## Background
Spatiotemporal importance sampling was introduced in the context of efficient deformable tissue reconstruction in surgical scenes [S1]. It addresses the challenges posed by tool occlusion and stationary tissue redundancy, which exacerbate learning complexity and reduce efficiency in neural radiance field (NeRF) based reconstruction [S1]. The method draws inspiration from EndoNeRF [S1]. It was proposed in "Efficient Deformable Tissue Reconstruction via Orthogonal Neural Plane" [S1].
