# Two-stage NeRF Rendering

Also called: Coarse and Fine Sampling, Rendering Sampling Strategy

## Overview
Two-stage NeRF Rendering is a volume rendering method that decouples the estimation of scene density from the final color synthesis by using two distinct neural networks: a coarse network and a fine network [S1]. It solves the problem of balancing rendering fidelity with computational cost by allocating samples hierarchically: the coarse network identifies high-density regions, while the fine network refines the appearance within those regions [S1]. It differs from single-stage NeRF by explicitly separating the density estimation and high-frequency detail capture into two passes, allowing for more efficient sample distribution than uniform sampling [S1].

## How it works
**Inputs and Outputs**
*   **Input:** Camera ray parameters (origin $\mathbf{o}$, direction $\mathbf{d}$), near/far bounds ($t_n, t_f$), and the trained coarse and fine neural networks.
*   **Output:** Pixel color $C(\mathbf{r})$ and alpha $\alpha(\mathbf{r})$.

**Data Structures**
*   **Coarse Network:** A multi-layer perceptron (MLP) taking positional encoding of position $\gamma(\mathbf{x})$ and direction $\gamma(\mathbf{d})$ as input. It outputs density $\sigma$ and RGB color $C$.
*   **Fine Network:** A second MLP with similar architecture, taking the same inputs. It outputs refined density $\sigma$ and RGB color $C$.
*   **Sample Points:** A list of 1D coordinates $t_i$ along the ray.

**Numbered Steps**
1.  **Coarse Sampling:** Generate $K_c = 64$ sample points uniformly (or stratified) along the ray segment $[t_n, t_f]$ [S1].
2.  **Coarse Network Query:** Evaluate the coarse network at each of the $K_c$ points to obtain density $\sigma_c$ and color $C_c$ [S1].
3.  **Coarse Rendering:** Compute the transmittance and accumulated color using the standard volume rendering integral with the coarse samples [S1].
4.  **Fine Sampling:** Generate $K_f = 128$ additional sample points. These are typically distributed based on the density estimates from the coarse pass to concentrate samples in opaque regions [S1]. The total number of fine samples is $K_{total\_fine} = 64 + 128 = 192$ [S1].
5.  **Fine Network Query:** Evaluate the fine network at all $K_{total\_fine}$ points to obtain refined density $\sigma_f$ and color $C_f$ [S1].
6.  **Fine Rendering:** Compute the final pixel color using the volume rendering integral with the fine samples [S1].

**Formulas**
The volume rendering integral for a ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ is:
$$ C(\mathbf{r}) = \sum_{i=1}^{K} T_i (1 - \exp(-\sigma_i \delta_i)) C_i $$
$$ T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right) $$
where $\delta_i = t_{i+1} - t_i$ is the distance between samples, $\sigma_i$ is the density, and $C_i$ is the color at sample $i$ [S1].

**Parameters**
*   Coarse samples per ray ($K_c$): 64 [S1].
*   Additional fine samples ($K_{add}$): 128 [S1].
*   Total fine samples ($K_f$): 192 [S1].
*   Total network queries per ray: 256 [S1].

**Edge Cases and Pitfalls**
*   **Precision:** The method relies on accurate density estimation from the coarse network to guide the fine sampling. Poor coarse density estimates may lead to undersampling in complex regions [S1].
*   **Boundaries:** The near and far bounds must be carefully chosen to avoid clipping visible geometry or including excessive empty space [S1].

**Pseudocode**
```python
def render_two_stage_neRF(ray_o, ray_d, t_near, t_far, coarse_net, fine_net):
    # Step 1: Coarse Sampling
    t_coarse = stratified_sample(t_near, t_far, 64)
    
    # Step 2: Coarse Network Query
    sigma_coarse, color_coarse = coarse_net(t_coarse, ray_o, ray_d)
    
    # Step 3: Coarse Rendering (Optional, often used for training loss but not final output)
    # T_coarse, C_coarse = volume_render(t_coarse, sigma_coarse, color_coarse)
    
    # Step 4: Fine Sampling
    # Generate 128 additional samples based on coarse density
    t_fine_extra = importance_sample(t_coarse, sigma_coarse, 128)
    t_fine = sort_concatenate(t_coarse, t_fine_extra)
    
    # Step 5: Fine Network Query
    sigma_fine, color_fine = fine_net(t_fine, ray_o, ray_d)
    
    # Step 6: Fine Rendering
    T_fine, C_fine = volume_render(t_fine, sigma_fine, color_fine)
    
    return C_fine
```

## Subtopics

### [Combined Sampling (Occupancy Grid + Proposal Network)](1626-combined-sampling-occupancy-grid-proposal-network.md)
A method that stacks an occupancy grid on top of a proposal network to reduce the number of rays and shrink the near-far plane for remaining rays, leveraging the transmittance estimation from both.

### [VF-NeRF Rendering Pipeline](3302-vf-nerf-rendering-pipeline.md)
The VF-NeRF rendering pipeline is a two-stage volume rendering method that uses a vector field network to predict surface normals, features, and Jacobians for density estimation and shading. It differs from standard NeRF by deriving density from the directional derivative of the vector field rather than a direct scalar field prediction, enabling explicit surface representation within the implicit volume. It builds on [Two-stage NeRF Rendering](925-two-stage-nerf-rendering.md) by integrating vector field-based density computation into the coarse and fine sampling passes.

### [Hierarchical NeRF Rendering](3366-hierarchical-nerf-rendering.md)
Hierarchical NeRF Rendering is a two-pass volume rendering pipeline that first estimates scene density with a coarse uniform or stratified pass, then uses the resulting sample weights to importance-sample a fine pass. It distinguishes itself from uniform ray marching by adaptively concentrating samples in high-density regions identified by the coarse network, thereby reducing computational waste in empty space while maintaining high-frequency detail.

## Operating characteristics
*   **Time Complexity:** $O(K_c + K_f)$ network queries per ray, where $K_c=64$ and $K_f=192$ [S1].
*   **Memory Complexity:** Depends on the size of the two MLPs. The original implementation uses fully connected layers with 256 channels [S1].
*   **Measured Performance:** On an NVIDIA V100, rendering a frame with 640k rays (synthetic) or 762k rays (real scenes) takes approximately 30 seconds, resulting in 150-200 million network queries per image [S1].
*   **Strengths:** Improves visual quality by allowing the fine network to focus on high-frequency details in dense regions [S1].
*   **Limitations:** Requires two network evaluations per ray (or at least two passes), increasing computational cost compared to single-stage methods [S1].
*   **When to Use:** When high-fidelity novel view synthesis is required and computational resources allow for multiple network queries per ray [S1].
*   **When Not to Use:** When real-time performance is critical and the overhead of two network evaluations is prohibitive [S1].

## Background
Two-stage NeRF Rendering was introduced by Mildenhall et al. in the paper "NeRF: Representing Scenes as Neural Radiance Fields for View Synthesis" [S1]. The method was developed to address the limitations of single-stage neural radiance fields, which struggled to capture high-frequency details without excessive sampling [S1]. The approach has become a standard baseline in neural rendering research [S1].
