# Two-stage NeRF Rendering

Also called: Coarse and Fine Sampling, Rendering Sampling Strategy

## Overview
Two-stage NeRF Rendering is a volume rendering method that evaluates a scene using two distinct neural network passes per ray [S1]. It differs from its siblings by explicitly separating the sampling strategy into a coarse pass and a fine pass with fixed sample counts, whereas [Adaptive Sampling](1412-adaptive-sampling.md) adjusts sample counts based on variance, and [Random Pixel Subsampling](1668-random-pixel-subsampling.md) skips pixels entirely rather than refining them [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Input:** Camera ray origin $\mathbf{o} \in \mathbb{R}^3$ and direction $\mathbf{d} \in \mathbb{R}^3$; coarse network $N_c$ and fine network $N_f$ [S1].
*   **Output:** Pixel color $C(\mathbf{r})$ [S1].

**Data Structures:**
*   **Ray:** Defined by origin $\mathbf{o} \in \mathbb{R}^3$ and direction $\mathbf{d} \in \mathbb{R}^3$ [S1].
*   **Network Input:** Position $\mathbf{x} \in \mathbb{R}^3$ and viewing direction $\mathbf{d} \in \mathbb{R}^3$ [S1].
*   **Network Output:** Density $\sigma \in \mathbb{R}$ and RGB color $\mathbf{c} \in \mathbb{R}^3$ [S1].

**Numbered Steps:**

1.  **Coarse Sampling:**
    *   Sample $K_c = 64$ points uniformly along the ray segment $[t_n, t_f]$ [S1].
    *   Let the sampled points be $\mathbf{x}_i$ for $i = 1 \dots K_c$ [S1].
    *   Query the coarse network $N_c(\mathbf{x}_i, \mathbf{d})$ to obtain density $\sigma_i$ and color $\mathbf{c}_i$ [S1].
    *   Compute transmittance $T_i$ and accumulated color $C_c$ using standard volume rendering integration [G]:
        $$ T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \delta_j\right) $$
        $$ C_c = \sum_{i=1}^{K_c} T_i (1 - \exp(-\sigma_i \delta_i)) \mathbf{c}_i $$
        where $\delta_j$ is the distance between adjacent samples [G].

2.  **Fine Sampling:**
    *   Sample $K_f = 128$ additional points $\mathbf{x}'_j$ along the ray [S1].
    *   The exact placement strategy for these additional points is not specified in the sources [G].
    *   The total number of fine samples is $K_{total} = K_c + K_f = 192$ [S1].
    *   Query the fine network $N_f(\mathbf{x}_k, \mathbf{d})$ for all $K_{total}$ points to obtain refined density $\sigma'_k$ and color $\mathbf{c}'_k$ [S1].
    *   Re-integrate using the combined set of samples to produce the final color $C_f$ [G]:
        $$ C_f = \sum_{k=1}^{K_{total}} T'_k (1 - \exp(-\sigma'_k \delta'_k)) \mathbf{c}'_k $$

3.  **Rendering:**
    *   The final pixel color is $C_f$ [S1].

**Parameters:**
*   Coarse samples per ray ($K_c$): 64 [S1].
*   Additional fine samples ($K_f$): 128 [S1].
*   Total samples per ray: 256 [S1].

**Edge Cases and Pitfalls:**
*   **Boundary Conditions:** The near and far clipping planes ($t_n, t_f$) must be set appropriately to avoid sampling empty space or missing geometry [G].

**Pseudocode:**

```python
import math

def render_two_stage_ray(ray_origin, ray_direction, coarse_net, fine_net, t_near, t_far):
    # Step 1: Coarse Sampling
    num_coarse = 64
    t_coarse = [t_near + i * (t_far - t_near) / (num_coarse - 1) for i in range(num_coarse)]
    x_coarse = [[ray_origin[j] + t * ray_direction[j] for j in range(3)] for t in t_coarse]
    
    # Query coarse network
    sigma_coarse, color_coarse = coarse_net(x_coarse, ray_direction)
    
    # Compute transmittance and coarse color
    delta = [t_coarse[i] - t_coarse[i-1] if i > 0 else t_coarse[0] - t_near for i in range(num_coarse)]
    T = [1.0]
    for i in range(num_coarse):
        T.append(T[-1] * math.exp(-sigma_coarse[i] * delta[i]))
    T = T[:-1]
    
    weight = [T[i] * (1.0 - math.exp(-sigma_coarse[i] * delta[i])) for i in range(num_coarse)]
    color_coarse_final = [sum(weight[i] * color_coarse[i][j] for i in range(num_coarse)) for j in range(3)]
    
    # Step 2: Fine Sampling
    num_fine_add = 128
    # The exact placement strategy for the 128 additional points is not specified in the sources [G].
    t_fine_add = [t_near + i * (t_far - t_near) / (num_fine_add - 1) for i in range(num_fine_add)]
    x_fine_add = [[ray_origin[j] + t * ray_direction[j] for j in range(3)] for t in t_fine_add]
    
    # Combine coarse and fine points
    t_all = t_coarse + t_fine_add
    x_all = x_coarse + x_fine_add
    
    # Sort by depth to ensure correct integration order
    sort_idx = sorted(range(len(t_all)), key=lambda k: t_all[k])
    t_all = [t_all[i] for i in sort_idx]
    x_all = [x_all[i] for i in sort_idx]
    
    # Query fine network for all points
    sigma_fine, color_fine = fine_net(x_all, ray_direction)
    
    # Re-integrate
    delta_all = [t_all[i] - t_all[i-1] if i > 0 else t_all[0] - t_near for i in range(len(t_all))]
    T_fine = [1.0]
    for i in range(len(t_all)):
        T_fine.append(T_fine[-1] * math.exp(-sigma_fine[i] * delta_all[i]))
    T_fine = T_fine[:-1]
    
    weight_fine = [T_fine[i] * (1.0 - math.exp(-sigma_fine[i] * delta_all[i])) for i in range(len(t_all))]
    color_final = [sum(weight_fine[i] * color_fine[i][j] for i in range(len(t_all))) for j in range(3)]
    
    return color_final
```

## Subtopics

### Combined Sampling (Occupancy Grid + Proposal Network)
A method that stacks an occupancy grid on top of a proposal network to reduce the number of rays and shrink the near-far plane for remaining rays, leveraging the transmittance estimation from both [S2]. It uses the proposal network to estimate transmittance and select initial samples, then applies the occupancy grid to further filter rays or shrink the near-far bounds for the remaining rays, performing final sampling based on the combined transmittance estimates [S2]. On the NeRF-Synthetic dataset using HashEncoding from Instant-NGP, this approach improved quality from 31.40dB to 32.35dB PSNR and reduced training time from 5.2min to 4.3min [S2]. It is more effective than using only the proposal network on the NeRF-Synthetic dataset because that dataset contains more empty space that can be skipped effectively by the occupancy grid [S2].

## Operating characteristics
*   **Time Complexity:** The method requires $K_c + K_f = 256$ network queries per ray [S1].
*   **Measured Performance:** On an NVIDIA V100, rendering a frame with 640k rays (synthetic dataset) or 762k rays (real scenes) takes approximately 30 seconds, resulting in 150-200 million network queries per image [S1].

## Background
Two-stage NeRF Rendering was introduced in the seminal paper "NeRF: Representing Scenes as Neural Radiance Fields for View Synthesis" by Mildenhall et al. [S1]. The approach has become a standard baseline in the NeRF literature, influencing subsequent methods such as [VF-NeRF Rendering Pipeline](3302-vf-nerf-rendering.md) and [Hierarchical NeRF Rendering](3366-hierarchical-nerf-rendering.md) [S1, S2].
