# Hierarchical Importance Sampling
## Overview
Hierarchical Importance Sampling is a strategy for efficiently selecting sample points along rays in Neural Radiance Fields (NeRF) by using coarse density estimates to guide the placement of fine samples [S1][S2, unofficial]. It employs multiple levels of importance sampling to reduce the number of samples required for rendering [S2, unofficial]. For the NeRF synthetic dataset, it uses an occupancy grid for efficient sampling, while for real-world 360 datasets, it uses two levels of importance sampling implemented by Multiresolution Hash Grids (MHGs) [S1][S2, unofficial]. It builds on [Combined Sampling (Occupancy Grid + Proposal Network)](1626-combined-sampling-occupancy-grid-proposal-network.md) [S1][S2, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Ray origin $\mathbf{o}$ and direction $\mathbf{d}$.
- Input: Coarse density field $\rho_{coarse}(\mathbf{x})$ and fine density field $\rho_{fine}(\mathbf{x})$ (implemented via MHGs) [S1][S2, unofficial].
- Input: Number of samples per proposal level $N_{proposal}$ (64) [S2, unofficial].
- Input: Number of final samples on the radiance field $N_{fine}$ (32) [S1][S2, unofficial].
- Output: Set of $N_{fine}$ sample positions $\{\mathbf{x}_i\}_{i=1}^{N_{fine}}$ along the ray [G].

**Data Structures:**
- **Multiresolution Hash Grid (MHG):** A hash table mapping 3D coordinates to feature vectors, used to model density fields [S1][S2, unofficial].
  - Structure: Array of hash tables, one per resolution level.
  - Hashing levels ($L$): 10 [S1][S2, unofficial].
  - Feature channels per level ($C$): 1 [S1][S2, unofficial].
  - The density at a point $\mathbf{x}$ is computed by aggregating features from the grid levels and passing them through a small network or linear layer to produce $\rho(\mathbf{x})$ [S1][S2, unofficial].

**Steps:**
1. **First-Level Proposal:** Generate initial sample points along the ray segment [S2, unofficial]. Evaluate the first MHG density field at these points [S1][S2, unofficial]. Use importance sampling to select $N_{proposal}$ points, concentrating them in high-density regions [S2, unofficial].
2. **Second-Level Proposal:** Evaluate the second MHG density field at the first-level points [S1][S2, unofficial]. Use importance sampling again to select another $N_{proposal}$ points, further refining the distribution [S1][S2, unofficial].
3. **Final Sampling:** From the refined distribution, select $N_{fine}$ final samples to query the radiance field for color and density [S2, unofficial].

**Parameters:**
- $N_{proposal}$: 64 samples per level [S2, unofficial].
- $N_{fine}$: 32 samples on the radiance field [S1][S2, unofficial].
- MHG Hashing Levels: 10 [S1][S2, unofficial].
- MHG Feature Channels: 1 per level [S1][S2, unofficial].

**Pseudocode:**
```python
import random

def hierarchical_importance_sampling(ray_o, ray_d, coarse_mhg, fine_mhg, n_proposal=64, n_fine=32):
    """
    ray_o: (3,) ray origin
    ray_d: (3,) ray direction
    coarse_mhg: callable returning density at points
    fine_mhg: callable returning density at points
    n_proposal: number of samples per proposal level (64)
    n_fine: number of final samples (32)
    """
    # Step 1: Generate initial candidates along the ray parameter t
    t_candidates = [random.uniform(0, 1) for _ in range(n_proposal * 2)]
    t_candidates.sort()
    points_candidates = [ray_o + t * ray_d for t in t_candidates]

    # Step 2: First-level importance sampling
    densities_1 = [coarse_mhg(p) for p in points_candidates]
    t_proposal_1 = importance_sample(t_candidates, densities_1, n_proposal)
    points_proposal_1 = [ray_o + t * ray_d for t in t_proposal_1]

    # Step 3: Second-level importance sampling
    densities_2 = [fine_mhg(p) for p in points_proposal_1]
    t_proposal_2 = importance_sample(t_proposal_1, densities_2, n_proposal)
    points_proposal_2 = [ray_o + t * ray_d for t in t_proposal_2]

    # Step 4: Final sampling
    # Evaluate second MHG at the second-level points to get densities for final selection
    densities_3 = [fine_mhg(p) for p in points_proposal_2]
    t_final = importance_sample(t_proposal_2, densities_3, n_fine)
    points_final = [ray_o + t * ray_d for t in t_final]

    return points_final

def importance_sample(t_values, densities, n_samples):
    # [G] Standard discrete importance sampling
    total_density = sum(densities)
    if total_density == 0:
        return t_values[:n_samples]
    probs = [d / total_density for d in densities]
    cdf = []
    acc = 0.0
    for p in probs:
        acc += p
        cdf.append(acc)
    samples = []
    for _ in range(n_samples):
        u = random.random()
        idx = 0
        while idx < len(cdf) - 1 and cdf[idx] < u:
            idx += 1
        samples.append(t_values[idx])
    return samples
```

**Edge Cases:**
- **Zero Density:** If all densities are zero, uniform sampling is a fallback [G].
- **Boundary Conditions:** Ensure ray segments are clipped to the bounding box of the hash grid [G].
- **Degenerate Input:** Handle rays with zero direction or origin outside bounds [G].

## Operating characteristics
- **Time Complexity:** Dominated by hash grid lookups and density evaluations at each sampling level [S2, unofficial]. Two levels of sampling increase density queries compared to single-level, but reduce the number of expensive fine radiance field evaluations [S2, unofficial].
- **Memory Complexity:** Depends on the size of the MHG. With 10 levels and 1 feature channel, the memory footprint is constrained [S1][S2, unofficial].
- **Performance:** Reduces the number of samples required for rendering, specifically lowering the final valuable sampling count to 32 [S2, unofficial]. Measured on an RTX 3090 GPU [S1][S2, unofficial].
- **Strengths:** Efficiently focuses samples on geometry, reducing noise and improving quality with fewer samples [S2, unofficial].
- **Limitations:** Requires training and maintaining multiple hash grids [S1][S2, unofficial].

## Background
- **Origin:** Described in Volume Feature Rendering for fast NeRF reconstruction [S1][S2, unofficial].
- **Development:** Adapts Zip-NeRF's two-level importance sampling approach to the Volume Feature Rendering framework [S1][S2, unofficial].
- **Usage:** Applied to NeRF synthetic and real-world 360 datasets [S1][S2, unofficial].
