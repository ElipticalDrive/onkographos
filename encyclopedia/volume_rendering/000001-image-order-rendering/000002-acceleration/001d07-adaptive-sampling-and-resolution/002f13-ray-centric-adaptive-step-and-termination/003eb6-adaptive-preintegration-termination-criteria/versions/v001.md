# Adaptive Preintegration Termination Criteria
Also called: Preintegration-based Adaptive Termination

## Overview
Adaptive Preintegration Termination Criteria is a method for determining when to stop subdividing a ray segment during volume rendering, specifically within the context of adaptive preintegration. It solves the problem of balancing rendering accuracy against computational cost by recursively subdividing ray intervals only when the estimated error exceeds a threshold. It sets itself apart from standard adaptive sampling [1385-adaptive-sampling.md] by operating on preintegrated segment contributions rather than raw scalar samples, and from simple opacity-based termination [5938-ray-centric-adaptive-step-and-termination.md] by using a relative error metric between coarse and fine approximations of the segment integral.

## How it works
The method uses a recursive subdivision scheme. The core inputs are the ray segment endpoints, the preintegration tables (opacity, color), and the accumulated opacity $\alpha$ from previous segments. The output is the final color contribution of the segment, computed with sufficient precision to satisfy the error bound.

### Data Structures
*   **Segment Interval:** Defined by start distance $d_i$ and end distance $d_{i+1}$ along the ray.
*   **Preintegration Tables:** Lookup tables mapping scalar value and segment length to accumulated opacity and color.
*   **Accumulated Opacity ($\alpha$):** The opacity accumulated from all previous segments up to $d_i$.

### Algorithm Steps
1.  **Initial Approximation ($C_1$):** Compute the color contribution $C_1$ for the interval $[d_i, d_{i+1}]$ using the preintegration tables with the full interval length $L = d_{i+1} - d_i$. This assumes a constant or average scalar value over the interval, or uses the endpoints if the preintegration scheme supports it. Let the midpoint be $d_{i+1/2} = (d_i + d_{i+1})/2$.
2.  **Refined Approximation ($C_2$):** Subdivide the interval into $[d_i, d_{i+1/2}]$ and $[d_{i+1/2}, d_{i+1}]$. Compute the color contribution for each sub-segment using the preintegration tables with lengths $L/2$. Combine these contributions using front-to-back compositing, taking into account the accumulated opacity $\alpha$ at $d_i$ and the intermediate opacity $\alpha_{i+1/2}$ at $d_{i+1/2}$.
    *   Note: The intermediate opacity $\alpha_{i+1/2}$ must be computed first, as it is required for the termination check of the second sub-interval if further subdivision occurs.
3.  **Error Estimation:** Calculate the relative error between the coarse approximation $C_1$ and the refined approximation $C_2$. The magnitude of a color vector is $|C| = \sqrt{C.r^2 + C.g^2 + C.b^2}$. The relative error is approximated as $|C_1 - C_2|/|C_2|$.
4.  **Opacity Adaptation:** Multiply the relative error by $(1 - \alpha_i)$, where $\alpha_i$ is the accumulated opacity at the start of the interval. This adapts the sampling density as the ray becomes more opaque.
5.  **Termination Check:** The final termination criteria is:
    $$ (1 - \alpha_i) \frac{|C_1 - C_2|}{|C_1|} < \varepsilon $$
    If this condition is met, the segment is considered sufficiently accurate, and $C_1$ (or a weighted average, though $C_1$ is often used as the base approximation) is returned. If not, the interval is subdivided further, and the process repeats recursively on the sub-intervals.
6.  **Extrema Check (Optional Variant):** If the scalar field is not monotonic, check for extrema within the interval. An interval $[d_i, d_{i+1}]$ is subdivided if:
    $$ D_{\mathbf{v}}(f(\mathbf{x}(d_i))) D_{\mathbf{v}}(f(\mathbf{x}(d_{i+1}))) < 0 $$
    where $D_{\mathbf{v}}(f(\mathbf{x})) = \nabla f(\mathbf{x}) \cdot \mathbf{v}$ is the directional derivative of the scalar field $f$ in the ray direction $\mathbf{v}$. This ensures isosurfaces near extrema are not missed.

### Parameters
*   $\varepsilon$: The error threshold. Not given in the sources.
*   $l_{max}, l_{min}$: Bounds on the interval length. Not given in the sources.

### Pseudocode
```python
def adaptive_preintegration_subdivide(d_start, d_end, accumulated_opacity_alpha, preintegration_tables, epsilon, use_extrema_check=False):
    """
    Recursively subdivide a ray segment until the error criterion is met.
    """
    # 1. Compute coarse approximation C1 for the full interval
    length_full = d_end - d_start
    # Assume preintegration tables provide color and opacity for a given length and scalar value
    # For simplicity, assume we have scalar values at endpoints or an average
    scalar_start = get_scalar_at(d_start)
    scalar_end = get_scalar_at(d_end)
    scalar_avg = (scalar_start + scalar_end) / 2.0
    
    # Get preintegrated color and opacity for the full interval
    color_full, opacity_full = preintegration_tables.lookup(scalar_avg, length_full)
    
    # Composite with accumulated opacity
    # C_seg = T * alpha_seg
    # alpha_seg = 1 - exp(-sigma * L) approximated by preintegration
    # For preintegration, we often get the transmittance T and color C directly
    # Let's assume the table returns (T, C) for the segment
    T_full, C_full = preintegration_tables.lookup_color_transmittance(scalar_avg, length_full)
    
    # Contribution of this segment to the final color
    # C_contrib = C_full * (1 - accumulated_opacity_alpha)
    C1 = C_full * (1.0 - accumulated_opacity_alpha)
    
    # 2. Compute refined approximation C2 by splitting at midpoint
    d_mid = (d_start + d_end) / 2.0
    length_half = length_full / 2.0
    
    # First half
    T_half1, C_half1 = preintegration_tables.lookup_color_transmittance(scalar_avg, length_half)
    # Second half
    T_half2, C_half2 = preintegration_tables.lookup_color_transmittance(scalar_avg, length_half)
    
    # Composite: C2 = C_half1 * (1 - alpha) + C_half2 * T_half1 * (1 - alpha)
    # Note: The second half is modulated by the transmittance of the first half
    C2 = C_half1 * (1.0 - accumulated_opacity_alpha) + C_half2 * T_half1 * (1.0 - accumulated_opacity_alpha)
    
    # 3. Error Estimation
    # |C| = sqrt(C.r^2 + C.g^2 + C.b^2)
    norm_C1 = magnitude(C1)
    norm_C2 = magnitude(C2)
    
    if norm_C1 == 0 or norm_C2 == 0:
        # Avoid division by zero
        error = 0.0
    else:
        error = (1.0 - accumulated_opacity_alpha) * magnitude(C1 - C2) / norm_C1
        
    # 4. Termination Check
    if error < epsilon:
        return C1
    
    # 5. Extrema Check (if enabled)
    if use_extrema_check:
        grad_start = get_gradient_at(d_start)
        grad_end = get_gradient_at(d_end)
        ray_direction = get_ray_direction()
        
        deriv_start = dot(grad_start, ray_direction)
        deriv_end = dot(grad_end, ray_direction)
        
        if deriv_start * deriv_end < 0:
            # Extrema detected, force subdivision
            # Recurse on both halves
            C_left = adaptive_preintegration_subdivide(d_start, d_mid, accumulated_opacity_alpha, preintegration_tables, epsilon, use_extrema_check)
            # Update accumulated opacity for the second half
            # We need the opacity contributed by the first half
            # This requires tracking opacity through recursion, which is complex
            # For simplicity, assume we recompute or pass opacity
            alpha_mid = 1.0 - T_half1 * (1.0 - accumulated_opacity_alpha) # Approximation
            C_right = adaptive_preintegration_subdivide(d_mid, d_end, alpha_mid, preintegration_tables, epsilon, use_extrema_check)
            return C_left + C_right
            
    # 6. Recursive Subdivision
    # Recurse on both halves
    C_left = adaptive_preintegration_subdivide(d_start, d_mid, accumulated_opacity_alpha, preintegration_tables, epsilon, use_extrema_check)
    
    # Calculate opacity at midpoint for the second half
    # T_mid = T_half1 * (1 - accumulated_opacity_alpha) + T_half1 * accumulated_opacity_alpha? No.
    # Transmittance at midpoint relative to start: T_mid = T_half1
    # Opacity at midpoint: alpha_mid = 1 - T_mid * (1 - accumulated_opacity_alpha) is incorrect.
    # Correct: alpha_mid = 1 - (1 - accumulated_opacity_alpha) * T_half1
    alpha_mid = 1.0 - (1.0 - accumulated_opacity_alpha) * T_half1
    
    C_right = adaptive_preintegration_subdivide(d_mid, d_end, alpha_mid, preintegration_tables, epsilon, use_extrema_check)
    
    return C_left + C_right
```

## Subtopics

### Extrema-Based Subdivision
A subdivision scheme that forces subdivision at scalar function extrema to recover isosurfaces that might be missed if the function is not monotonic over an interval. It sets itself apart by using directional derivatives to detect sign changes, indicating an extrema. Choose it when the scalar field is not guaranteed to be monotonic, such as with MLS reconstructions. Pitfall: The accuracy of the termination criteria heavily depends on the accuracy of the computed gradient $\nabla f(\mathbf{x})$ [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the error threshold $\varepsilon$. In smooth regions, few subdivisions are needed. In complex regions, many subdivisions occur. The recursive nature can lead to high overhead if not optimized.
*   **Memory Complexity:** Low, as it primarily uses preintegration tables and recursion stack.
*   **Strengths:** Automatically optimal for constant transfer functions and linear scalar fields, as $C_1$ and $C_2$ will be equal within numerical errors [S1, unofficial]. Efficiently handles varying density by adapting to error.
*   **Limitations:** Requires accurate gradient computation for extrema detection. Recursive implementation can be inefficient on GPUs due to divergence.
*   **When to use:** When high accuracy is required in complex scalar fields, and preintegration is used.
*   **When not to use:** When scalar fields are simple and monotonic, or when GPU performance is critical and recursion is prohibitive.

## Background
Originated in the context of Volume MLS Ray Casting, which uses Moving Least Squares (MLS) for scalar field reconstruction. The method was proposed to handle the non-monotonic nature of MLS reconstructions and to provide an adaptive termination criterion for preintegration-based rendering. It builds on the work of Lum et al. [24] for incremental subrange preintegration.
