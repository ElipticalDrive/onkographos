# Adaptive Point Insertion Strategy
Also called: Adaptive point sampling strategy, Quality-driven insertion approach
## Overview
The Adaptive Point Insertion Strategy optimizes the distribution of sampling points in signed distance field reconstruction by prioritizing topologically critical regions [S1]. It solves the problem of insufficient geometric fidelity in complex areas where uniform sampling fails, ensuring superior topological preservation with a constrained sampling budget [S1]. It sets itself apart from uniform sampling by using quality-driven criteria to strategically add points, directly correlating reconstruction quality with the proportion of adaptively inserted samples [S1].
## How it works
**Inputs and Outputs:**
- Input: An initial uniform grid resolution and a target total point count [S1].
- Output: A refined set of sampling points and their corresponding surface projections [S1].

**Data Structures:**
- The method maintains two collections: a set of sampling points and a set of surface projections, with the total count explicitly including both collections [S1].

**Steps:**
1. **Initialization:** Start with a coarse uniform grid of resolution $8^3$ [S1].
2. **Quality Assessment:** Evaluate the current point set to identify regions of high curvature variation or low site density, which are classified as topologically critical [S1].
3. **Insertion:** Iteratively insert new points into the identified critical regions using quality-driven criteria [S1].
4. **Projection:** For each newly inserted sampling point, compute its corresponding surface projection [S1].
5. **Termination:** Repeat steps 2–4 until the combined total of sampling points and projections reaches the target count of $50^3$ [S1].

**Formulas:**
- The sources do not provide explicit mathematical formulas for the scoring function or insertion criterion [S1].
- Reconstruction quality correlates directly with the proportion of adaptively inserted samples: a higher percentage of points added via quality-driven criteria yields superior topological fidelity [S1].

**Parameters:**
- Initial adaptive grid resolution: $8^3$ [S1].
- Total points for adaptive expansion: $50^3$ (including sample points and projections) [S1].

**Edge Cases and Pitfalls:**
- Uniform sampling produces reconstructions with notable topological artifacts and missing features in geometrically complex regions [S1].
- The strategy is particularly critical for high-genus models where intricate details (e.g., chair backs) must be preserved [S1].

The DCCVT Upsampling Strategy is an adaptive refinement method for Differentiable Clipped Centroidal Voronoi Tessellation (DCCVT) that improves mesh quality by inserting new Voronoi sites in regions of high curvature or low site density. It solves the problem of insufficient site resolution in complex topological regions by using a scoring function based on local spacing and curvature to guide importance sampling. It sets itself apart from uniform upsampling by preserving local connectivity through tetrahedral insertion and aligning new sites with the SDF gradient.
