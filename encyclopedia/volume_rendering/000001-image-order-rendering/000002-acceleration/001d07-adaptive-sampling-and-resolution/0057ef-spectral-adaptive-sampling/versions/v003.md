# Spectral Adaptive Sampling

Also called: Adaptive GPU Ray Casting Based on Spectral Analysis, Frequency-based adaptive sampling, Spectral adaptive ray casting

## Overview
Spectral Adaptive Sampling is a volume rendering acceleration technique that determines the sampling step size based on the spectral decomposition (maximal frequency) of the composite signal formed by the volume data and the transfer function [S1]. Unlike heuristic methods that rely solely on the gradient of the scalar data, this method analyzes the frequency content of the transfer function to prevent aliasing artifacts caused by non-linear opacity mappings [S1]. It sets itself apart from sibling methods by explicitly incorporating the transfer function's spectral properties into the step size calculation, allowing for dynamic transfer function adjustments without re-computing global frequencies [S1].

## How it works
### Inputs and Outputs
**Inputs:**
*   Volume dataset $f(x)$ (scalar field) [S1].
*   Transfer function $g(s)$ mapping scalar values to optical properties [S1].
*   Optional affine transformation parameters $a_\Psi, b_\Psi$ for dynamic transfer function modification [S1].
*   Maximal step size parameter $T_{max}$ (typically 8) [S1].
*   Oversampling factor (typically 2) to compensate for linear reconstruction filters [S1].

**Outputs:**
*   Adaptive sampling step size $T$ for each ray segment [S1].
*   Rendered image with reduced sample count compared to regular sampling [S1].

### Data Structures
1.  **Importance Volume:** A 3D texture with the same dimensions as the input dataset [S1]. It stores the max-filtered gradient magnitudes [S1]. For each voxel, the gradient $f'(x)$ is computed in all spatial directions, and a max-filter with width $2T_{max}$ is applied to estimate the maximal gradient over the region covered by the next sampling step [S1].
2.  **Frequency Texture:** A 2D texture storing the maximal frequency $v_g(I)$ of the transfer function $g$ for specific value intervals $I = [s_{min}, s_{max}]$ [S1]. This is pre-computed via FFT on $g$ [S1].

### Algorithm Steps
1.  **Pre-processing (Offline/Interactive Setup):**
    1.  Compute the gradient $f'(x)$ of the volume data $f$ for every voxel [S1].
    2.  Apply a max-filter with width $2T_{max}$ to the gradients in the importance volume [S1].
    3.  Store the result back in the importance volume to ensure the gradient estimate covers the potential range of the next step [S1].
    4.  Perform a Fast Fourier Transform (FFT) on the transfer function $g$ to determine its spectral decomposition [S1].
    5.  Store the maximal frequency $v_g(I)$ for various intervals $I$ in the Frequency Texture [S1].
2.  **Runtime (Per Ray Step):**
    1.  Let $x_0$ be the current sample position and $f(x_0)$ be the scalar value at that position [S1].
    2.  Fetch the local gradient magnitude $|f'(x_0)|$ from the Importance Volume [S1].
    3.  Estimate the value interval $I = [s_{min}, s_{max}]$ covered by the next sampling step using a first-order Taylor expansion around $x_0$:
        $$ s_{min} = f(x_0) - |f'(x_0)| T_{max} $$
        $$ s_{max} = f(x_0) + |f'(x_0)| T_{max} $$
        [S1]
    4.  If the transfer function is modified by an affine map $\Psi(t) = a_\Psi t + b_\Psi$, adjust the frequency lookup or the step size calculation to account for the scaling factor $|a_\Psi|$ [S1].
    5.  Fetch the local maximal frequency $v_g(I)$ from the Frequency Texture corresponding to the interval $I$ [S1].
    6.  Calculate the sampling period $T$ using the formula:
        $$ T = \frac{1}{2 \cdot v_g(I) \cdot |a_\Psi| \cdot \max |f'(x)|} $$
        where $\max |f'(x)|$ is the gradient magnitude fetched in step 2 [S1]. The factor 2 represents the oversampling factor [S1].
    7.  Advance the ray by $T$ and repeat [S1].

### Pseudocode
```python
import math
import numpy as np

def compute_gradient_volume(volume_data):
    """Compute gradient magnitude for every voxel using finite differences."""
    grad = np.zeros_like(volume_data)
    for i in range(1, volume_data.shape[0] - 1):
        for j in range(1, volume_data.shape[1] - 1):
            for k in range(1, volume_data.shape[2] - 1):
                dx = volume_data[i+1, j, k] - volume_data[i-1, j, k]
                dy = volume_data[i, j+1, k] - volume_data[i, j-1, k]
                dz = volume_data[i, j, k+1] - volume_data[i, j, k-1]
                grad[i, j, k] = math.sqrt(dx*dx + dy*dy + dz*dz)
    return grad

def max_filter(volume, width):
    """Apply a 3D max-filter with a cubic window of given width."""
    half_w = width // 2
    result = np.zeros_like(volume)
    for i in range(volume.shape[0]):
        for j in range(volume.shape[1]):
            for k in range(volume.shape[2]):
                i_min, i_max = max(0, i - half_w), min(volume.shape[0], i + half_w + 1)
                j_min, j_max = max(0, j - half_w), min(volume.shape[1], j + half_w + 1)
                k_min, k_max = max(0, k - half_w), min(volume.shape[2], k + half_w + 1)
                result[i, j, k] = np.max(volume[i_min:i_max, j_min:j_max, k_min:k_max])
    return result

def compute_transfer_function_frequencies(transfer_function, num_intervals=256):
    """Compute maximal frequency v_g for value intervals using FFT."""
    # Perform FFT on the transfer function
    fft_vals = np.fft.fft(transfer_function)
    magnitudes = np.abs(fft_vals)
    # Determine max frequency for each interval
    v_g_lookup = np.zeros(num_intervals)
    interval_step = 1.0 / num_intervals
    for idx in range(num_intervals):
        s_min = idx * interval_step
        s_max = (idx + 1) * interval_step
        # Find max frequency component active in this interval
        v_g_lookup[idx] = np.argmax(magnitudes) * interval_step
    return v_g_lookup

def pre_process_volume(volume_data, transfer_function, T_max):
    """Offline setup: compute importance volume and frequency texture."""
    gradients = compute_gradient_volume(volume_data)
    importance_volume = max_filter(gradients, width=2 * T_max)
    frequency_texture = compute_transfer_function_frequencies(transfer_function)
    return importance_volume, frequency_texture

def compute_step_size(x0, f_x0, importance_volume, frequency_texture, 
                      a_Psi=1.0, b_Psi=0.0, T_max=8.0, oversampling=2.0):
    """Runtime: calculate adaptive step size for current ray position."""
    # Fetch local gradient magnitude from Importance Volume
    grad_mag = importance_volume[x0]
    
    # Estimate value interval I using Taylor expansion
    s_min = f_x0 - grad_mag * T_max
    s_max = f_x0 + grad_mag * T_max
    
    # Fetch maximal frequency v_g(I) from Frequency Texture
    # Map interval to texture index
    interval_step = 1.0 / frequency_texture.shape[0]
    idx = int((s_min + s_max) / 2.0 / interval_step)
    idx = max(0, min(idx, frequency_texture.shape[0] - 1))
    v_g = frequency_texture[idx]
    
    # Calculate step size T
    denominator = oversampling * v_g * abs(a_Psi) * grad_mag
    
    if denominator == 0:
        return T_max  # Fallback to max step size if no frequency/gradient
        
    T = 1.0 / denominator
    return T
```

### Parameters and Edge Cases
*   **$T_{max}$:** The maximal step size used for the max-filter width and Taylor expansion bounds. Typical value: 8 [S1].
*   **Oversampling Factor:** 2. This compensates for errors introduced by the linear (tent) filter kernel used in ray casting reconstruction [S1].
*   **Dynamic Transfer Functions:** If the transfer function is shifted or scaled via $\Psi(t) = a_\Psi t + b_\Psi$, the step size must incorporate $|a_\Psi|$ [S1]. This allows interactive changes without re-running the FFT on the entire dataset [S1].
*   **Approximation Error:** The estimate $v_h = v_g \max |f'(x)|$ is not tight; the actual maximal frequency might be higher [S1]. However, signal energy decays exponentially above this estimate, so no visible artifacts occur even without additional oversampling beyond the factor of 2 [S1].
*   **Memory:** The Importance Volume requires memory equal to the dataset size [S1]. It contains redundancy due to the max-filter and can be compressed [S1].

## Operating characteristics
*   **Time Complexity:** The pre-processing step involves FFT and gradient computation, which is done once or infrequently [S1]. Per step, the cost is two texture fetches (gradient and frequency) and a few floating-point operations [S1].
*   **Memory Complexity:** Requires an additional 3D texture (Importance Volume) of the same size as the dataset, plus a 2D Frequency Texture [S1].
*   **Performance:** Reduces sample points by 50-80% compared to non-adaptive methods without quality loss [S1].
    *   **Hand Dataset (300x300x300):** Regular sampling: 430 samples/pixel, 1.2 FPS. Adaptive: 88 samples/pixel, 5.5 FPS. Direct sampling (theoretical optimal): 75 samples/pixel, 6.5 FPS [S1].
    *   **Abdomen Dataset (512x512x101):** Regular sampling: 752 samples/pixel, 5 FPS. Adaptive: 404 samples/pixel, 6.2 FPS. Direct sampling: 197 samples/pixel, 8.1 FPS [S1].
*   **Strengths:** Handles non-linear transfer functions effectively; supports dynamic TF changes; significant speedup over regular sampling [S1].
*   **Limitations:** Less efficient than "direct sampling" (which uses global pre-computed frequencies) because it uses local approximations; requires extra memory for the Importance Volume; approximation may underestimate frequency, though artifacts are minimal [S1].

## Background
The method is based on the spectral analysis of function composition by Bergner et al. (2006) [S1]. It was implemented as a module for the Visualization Toolkit (VTK) using C++ and OpenGL/GLSL, tested on an NVIDIA GeForce GTX 280 [S1]. It addresses the limitation of heuristic gradient-based methods which fail to account for high-frequency components introduced by non-linear transfer functions [S1].
