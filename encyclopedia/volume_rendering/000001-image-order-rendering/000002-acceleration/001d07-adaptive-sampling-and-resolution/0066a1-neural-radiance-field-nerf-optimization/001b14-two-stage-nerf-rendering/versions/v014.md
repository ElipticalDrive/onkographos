# Two-stage NeRF Rendering

Also called: Coarse and Fine Sampling, Proposal Network Sampler, Rendering Sampling Strategy

## Overview
Two-stage NeRF Rendering is a hierarchical volume rendering technique that decouples density estimation from detailed color and density evaluation to improve sampling efficiency and image quality [S1][S2, S3, unofficial]. It solves the problem of uniform sampling wasting queries on empty space or low-detail regions by first performing a coarse pass to estimate the scene's density distribution, then using that distribution to importance-sample a fine pass [S2, S3, unofficial]. It sets itself apart from single-stage methods by explicitly separating the rough density estimation from the detailed evaluation, and from simple stratified sampling by concentrating computational effort on high-density regions identified in the first pass [S2, S3, unofficial].

## How it works
The method executes two distinct rendering passes per ray bundle. The inputs are the camera parameters (position, orientation, intrinsics) defining a ray bundle, and the trained neural network parameters (coarse and fine networks). The outputs are the rendered RGB images, depth maps, and auxiliary losses for training.

### Data Structures
*   **Ray Bundle:** A list or tensor of rays, each defined by origin $\mathbf{o}$ and direction $\mathbf{d}$.
*   **Coarse Network:** A neural network (MLP or Hash Grid-based) predicting density $\sigma_c$ and color $\mathbf{c}_c$.
*   **Fine Network:** A neural network predicting density $\sigma_f$ and color $\mathbf{c}_f$.
*   **Samples:** A list of 3D points $\mathbf{x}_i$ along each ray, parameterized by distance $t_i$ from the camera origin.

### Numbered Steps

1.  **Coarse Sampling:**
    For each ray, generate $N_c$ sample points. The original NeRF implementation uses stratified sampling [S1]. The number of coarse samples $N_c$ is typically 64 [S1, S6].
    *   *Note:* Some variants use a "Proposal Network" to generate these samples based on learned density priors rather than uniform stratification [S3, unofficial].

2.  **Coarse Rendering:**
    Query the Coarse Network at each sample point $\mathbf{x}_i$ to obtain density $\sigma_c(\mathbf{x}_i)$ and color $\mathbf{c}_c(\mathbf{x}_i)$.
    Compute the transmittance $T_i$ and weight $w_i$ for each sample:
    $$
    \sigma_i = \max(\sigma_c(\mathbf{x}_i), \epsilon)
    $$
    $$
    \alpha_i = 1 - \exp(-\sigma_i \Delta t_i)
    $$
    $$
    T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_j \Delta t_j\right)
    $$
    $$
    w_i = T_i \alpha_i
    $$
    where $\Delta t_i$ is the distance between adjacent samples.
    Compute the coarse color $\mathbf{C}_c$ and coarse depth $D_c$:
    $$
    \mathbf{C}_c = \sum_{i=1}^{N_c} w_i \mathbf{c}_c(\mathbf{x}_i)
    $$
    $$
    D_c = \sum_{i=1}^{N_c} w_i t_i
    $$

3.  **Fine Sampling (Importance Sampling):**
    Use the weights $w_i$ from the coarse pass to sample $N_f$ points for the fine pass. The original method uses stratified sampling within the bins defined by the coarse samples [S1].
    *   *Note:* In Proposal Network variants, the fine samples are drawn directly from the proposal distribution learned by the network [S3, unofficial].
    The number of fine samples $N_f$ is typically 128 additional samples, resulting in a total of 192 fine samples per ray (64 initial + 128 additional) [S1].

4.  **Fine Rendering:**
    Query the Fine Network at each fine sample point $\mathbf{x}_j$ to obtain density $\sigma_f(\mathbf{x}_j)$ and color $\mathbf{c}_f(\mathbf{x}_j)$.
    Compute the final transmittance $T_j$ and weight $w_j$:
    $$
    \sigma_j = \max(\sigma_f(\mathbf{x}_j), \epsilon)
    $$
    $$
    \alpha_j = 1 - \exp(-\sigma_j \Delta t_j)
    $$
    $$
    T_j = \exp\left(-\sum_{k=1}^{j-1} \sigma_k \Delta t_k\right)
    $$
    $$
    w_j = T_j \alpha_j
    $$
    Compute the final color $\mathbf{C}$ and depth $D$:
    $$
    \mathbf{C} = \sum_{j=1}^{N_f} w_j \mathbf{c}_f(\mathbf{x}_j)
    $$
    $$
    D = \sum_{j=1}^{N_f} w_j t_j
    $$

5.  **Background Handling (Optional):**
    If the scene has a background, an outer volume is rendered. Rays that do not intersect the foreground volume are sampled using a stratified sampler over the background volume [S2, unofficial].

### Parameters
*   $N_c$: Number of coarse samples per ray. Typical value: 64 [S1, S6].
*   $N_f$: Number of fine samples per ray. Typical value: 192 (64 + 128) [S1].
*   $\epsilon$: Minimum density value to prevent division by zero or numerical instability. Not given in the sources.
*   $channel\_scale$: Multiplier for output channels (e.g., 255.0 for 8-bit images) [S2, unofficial].

### Edge Cases and Pitfalls
*   **Empty Space:** If a ray passes through empty space, the coarse pass may assign low weights to all samples. The fine pass, relying on these weights, may also undersample, leading to noise. Proposal networks mitigate this by learning to allocate samples to empty space if necessary [S3, unofficial].
*   **Precision:** The exponential decay in transmittance can lead to underflow for deep scenes. Using log-space computations or clamping $\sigma$ is recommended [G].
*   **Degenerate Input:** If the ray direction is zero or the origin is undefined, the sampling process fails. Guard against this by validating ray inputs [G].

### Pseudocode

```python
import numpy as np

def render_two_stage(rays, coarse_model, fine_model, n_coarse=64, n_fine=192, epsilon=1e-4):
    """
    Render a batch of rays using two-stage NeRF rendering.
    
    Args:
        rays: List of Ray objects, each with origin (3,) and direction (3,).
        coarse_model: Function or object that returns (sigma, color) given points.
        fine_model: Function or object that returns (sigma, color) given points.
        n_coarse: Number of samples for the coarse pass.
        n_fine: Number of samples for the fine pass.
        epsilon: Minimum density value.
        
    Returns:
        colors: Rendered RGB images.
        depths: Rendered depth maps.
    """
    colors = []
    depths = []
    
    for ray in rays:
        # Step 1: Coarse Sampling
        # Generate n_coarse points along the ray
        t_coarse = np.linspace(ray.t_min, ray.t_max, n_coarse + 1)
        t_coarse_mid = (t_coarse[:-1] + t_coarse[1:]) / 2
        points_coarse = ray.origin + ray.direction * t_coarse_mid[:, np.newaxis]
        
        # Step 2: Coarse Rendering
        sigma_coarse, color_coarse = coarse_model(points_coarse)
        sigma_coarse = np.maximum(sigma_coarse, epsilon)
        
        # Compute weights
        delta_t = t_coarse[1] - t_coarse[0]
        alpha_coarse = 1.0 - np.exp(-sigma_coarse * delta_t)
        T_coarse = np.exp(-np.cumsum(sigma_coarse * delta_t) + sigma_coarse * delta_t)
        T_coarse = np.concatenate(([1.0], T_coarse[:-1]))
        weights_coarse = T_coarse * alpha_coarse
        
        # Compute coarse color and depth
        color_c = np.sum(weights_coarse[:, np.newaxis] * color_coarse, axis=0)
        depth_c = np.sum(weights_coarse * t_coarse_mid, axis=0)
        
        # Step 3: Fine Sampling (Importance Sampling)
        # Sample n_fine points based on coarse weights
        # Using stratified sampling within the bins defined by coarse samples
        indices = np.random.choice(n_coarse, size=n_fine, p=weights_coarse / np.sum(weights_coarse))
        # Add jitter within each bin
        t_fine = np.zeros(n_fine)
        for i in range(n_fine):
            idx = indices[i]
            t_min_bin = t_coarse[idx]
            t_max_bin = t_coarse[idx + 1]
            t_fine[i] = np.random.uniform(t_min_bin, t_max_bin)
        
        points_fine = ray.origin + ray.direction * t_fine[:, np.newaxis]
        
        # Step 4: Fine Rendering
        sigma_fine, color_fine = fine_model(points_fine)
        sigma_fine = np.maximum(sigma_fine, epsilon)
        
        # Compute weights
        # Sort points by distance to ensure correct transmittance calculation
        sort_idx = np.argsort(t_fine)
        t_fine_sorted = t_fine[sort_idx]
        sigma_fine_sorted = sigma_fine[sort_idx]
        color_fine_sorted = color_fine[sort_idx]
        
        delta_t_fine = np.diff(np.concatenate(([ray.t_min], t_fine_sorted, [ray.t_max])))
        # Approximate delta_t as constant for simplicity, or use actual differences
        delta_t_fine = np.mean(delta_t_fine)
        
        alpha_fine = 1.0 - np.exp(-sigma_fine_sorted * delta_t_fine)
        T_fine = np.exp(-np.cumsum(sigma_fine_sorted * delta_t_fine) + sigma_fine_sorted * delta_t_fine)
        T_fine = np.concatenate(([1.0], T_fine[:-1]))
        weights_fine = T_fine * alpha_fine
        
        # Compute final color and depth
        color = np.sum(weights_fine[:, np.newaxis] * color_fine_sorted, axis=0)
        depth = np.sum(weights_fine * t_fine_sorted, axis=0)
        
        colors.append(color)
        depths.append(depth)
        
    return np.array(colors), np.array(depths)
```

## Subtopics

### [Combined Sampling (Occupancy Grid + Proposal Network)](1626-combined-sampling-occupancy-grid-proposal-network.md)
Combined sampling stacks an occupancy grid on top of a proposal network to reduce the number of rays processed and shrink the near-far plane for remaining rays. It leverages transmittance estimation from both structures to skip empty space more effectively than either method alone. It differs from [VF-NeRF Rendering Pipeline](3302-vf-nerf-rendering-pipeline.md) by using a learned proposal network for initial density estimation rather than a fixed grid, and from [Coarse-Fine Sampling](8172-coarse-fine-sampling.md) by explicitly combining a sparse spatial index with a neural density prior to prune rays before the final fine sampling stage.

### [VF-NeRF Rendering Pipeline](3302-vf-nerf-rendering-pipeline.md)
The VF-NeRF rendering pipeline is a two-stage volume rendering method that uses a vector field network to predict surface normals, features, and Jacobians for density estimation and shading. It differs from standard NeRF by deriving density from the directional derivative of the vector field rather than a direct scalar field prediction, enabling explicit surface representation within the implicit volume. It builds on [Two-stage NeRF Rendering](925-two-stage-nerf-rendering.md) by integrating vector field-based density computation into the coarse and fine sampling passes.

### [Coarse-Fine Sampling](8172-coarse-fine-sampling.md)
Coarse-Fine Sampling is a two-pass rendering technique for Neural Radiance Fields (NeRF) that improves image quality and sampling efficiency by first estimating the scene's density distribution with a coarse pass, then using that distribution to importance-sample a fine pass. It sets itself apart from uniform sampling by concentrating computational effort on high-density regions identified in the first pass, and from single-stage methods by decoupling the rough density estimation from the detailed color/density evaluation.

### [Semantic Loss Computation](15616-semantic-loss-computation.md)
Semantic Loss Computation computes the cross-entropy loss over coarse and fine semantic predictions for query rays to train a generalizable semantic field. It differs from standard photometric NeRF losses by enforcing semantic consistency across views via ray-based feature projection, allowing the model to learn contextual geometry for semantic information rather than just color. It is a core component of the Two-stage NeRF Rendering pipeline, specifically enabling the training of the semantic head alongside the geometry-aware network.

## Operating characteristics
*   **Time Complexity:** $O(N \cdot (N_c + N_f))$ where $N$ is the number of rays, $N_c$ is coarse samples, and $N_f$ is fine samples. The original NeRF implementation requires 256 network queries per ray (64 coarse + 192 fine) [S1].
*   **Memory Complexity:** $O(N \cdot (N_c + N_f))$ to store intermediate densities and colors for backpropagation.
*   **Measured Performance:** On an NVIDIA V100, rendering a realistic synthetic dataset (640k rays/image) or real scenes (762k rays/image) takes approximately 30 seconds per frame, resulting in 150-200 million network queries per image [S1].
*   **Scaling:** Performance scales linearly with the number of rays and samples. Proposals networks can reduce the effective number of samples needed by focusing on high-density regions [S3, unofficial].
*   **Strengths:** Improved image quality compared to uniform sampling; reduced computational cost by avoiding unnecessary queries in empty space.
*   **Limitations:** Requires training two networks (coarse and fine); increased memory usage due to storing intermediate values for both passes.
*   **When to Use:** When high-quality novel view synthesis is required and computational resources allow for two passes per ray.
*   **When Not to Use:** When real-time performance is critical and the scene is simple enough that uniform sampling suffices.

## Background
Two-stage NeRF Rendering was introduced in the original NeRF paper by Mildenhall et al. in 2020 [S1]. It was designed to address the inefficiency of uniform sampling in neural radiance fields. The method has since been extended with proposal networks [S3, unofficial] and combined with occupancy grids [S1] to further improve efficiency. It is widely used in modern NeRF implementations and variants [S2, unofficial][S4, S6, S7].
