# Two-stage NeRF Rendering

Also called: Coarse and Fine Sampling, Proposal Network Sampler, Rendering Sampling Strategy

## Overview
Two-stage NeRF Rendering is a hierarchical sampling technique for Neural Radiance Fields that decouples density estimation from detailed color rendering to improve computational efficiency and image quality [S1][S2, unofficial][S3]. It solves the problem of uniform sampling wasting queries on empty space or low-detail regions by first using a coarse pass to estimate the scene's density distribution, then using that distribution to importance-sample a fine pass [S2, unofficial][S3]. It sets itself apart from single-stage methods by explicitly separating the rough density estimation from the detailed color/density evaluation, and from simple uniform sampling by concentrating computational effort on high-density regions identified in the first pass [S2, unofficial][S3].

## How it works
The method operates in two distinct phases: a coarse sampling phase to build a probability distribution over the ray, and a fine sampling phase to render the final pixel color using samples drawn from that distribution.

### Inputs and Outputs
*   **Inputs:** Ray bundle $r$ (origin $o$, direction $d$), near/far bounds $[t_n, t_f]$, coarse network $N_c$, fine network $N_f$.
*   **Outputs:** Rendered color $C(r)$, depth $D(r)$, accumulated transmittance $T(t)$.

### Data Structures
*   **Ray Samples:** A list of 3D points $t_i$ along the ray and their corresponding density $\sigma_i$ and color $c_i$ returned by the networks.
*   **Weights:** A list of importance weights $w_i$ derived from the coarse density estimates, used to guide the placement of fine samples.

### Steps

1.  **Coarse Sampling:**
    *   Sample $N_c$ points uniformly or with single jitter along the ray interval $[t_n, t_f]$ [S2, unofficial].
    *   Query the coarse network $N_c$ at these points to obtain densities $\sigma_c$ and colors $c_c$ [S1].
    *   Compute the accumulated transmittance $T(t_i)$ and weights $w_i$ for the coarse samples:
        $$ T(t_i) = \exp\left(-\sum_{j=1}^{i-1} \sigma_c(t_j) \Delta t_j\right) $$
        $$ w_i = T(t_i) (1 - \exp(-\sigma_c(t_i) \Delta t_i)) $$
    *   Normalize the weights to form a probability distribution $p_i = w_i / \sum w_j$ [S3].

2.  **Fine Sampling:**
    *   Sample $N_f$ points from the distribution defined by $p_i$ [S3]. This is typically done via stratified sampling or inverse transform sampling based on the cumulative distribution function (CDF) of the coarse weights [S2, unofficial].
    *   Query the fine network $N_f$ at these new points to obtain densities $\sigma_f$ and colors $c_f$ [S1].

3.  **Rendering:**
    *   Combine the coarse and fine samples (or use only fine samples, depending on the specific variant) to compute the final volume integral:
        $$ C(r) = \sum_{i=1}^{N} w_i c_i $$
        where $w_i$ are the final importance weights derived from the combined density estimates [S1, S3].

### Parameters
*   **Coarse samples per ray ($N_c$):** Typically 64 [S1].
*   **Fine samples per ray ($N_f$):** Typically 128 additional samples, resulting in 192 total fine samples (64 initial + 128 additional) [S1].
*   **Total samples per ray:** 256 (64 coarse + 192 fine) [S1].
*   **Initial Sampler:** Can be 'uniform' with single jitter or 'piecewise' [S2, unofficial].
*   **Update Schedule:** Determines how often proposal networks are updated during training [S2, unofficial].

### Edge Cases and Pitfalls
*   **Precision:** Floating-point precision in transmittance calculation can lead to underflow in long rays with high density, causing artifacts [G].
*   **Boundaries:** Incorrect handling of near/far plane clipping can result in samples outside the valid range [G].
*   **Degenerate Input:** If the coarse network predicts zero density everywhere, the importance sampling distribution becomes uniform, negating the efficiency gain [G].

### Pseudocode

```python
def two_stage_render(ray_origin, ray_direction, t_near, t_far, coarse_net, fine_net):
    # Step 1: Coarse Sampling
    # Sample N_c points uniformly with single jitter
    N_c = 64
    coarse_t = uniform_sample_with_jitter(N_c, t_near, t_far)
    
    # Query coarse network
    coarse_sigma, coarse_color = coarse_net(ray_origin, ray_direction, coarse_t)
    
    # Compute coarse weights for importance sampling
    # Delta t is the distance between samples
    delta_t = np.diff(coarse_t, prepend=t_near, append=t_far)
    # Transmittance T(t_i) = exp(-sum_{j<i} sigma_j * delta_t_j)
    alpha = 1 - np.exp(-coarse_sigma * delta_t)
    T = np.exp(-np.cumsum(coarse_sigma * delta_t))
    # Weights w_i = T(t_i) * (1 - exp(-sigma_i * delta_t_i))
    coarse_weights = T * alpha
    
    # Normalize weights to get probability distribution
    p = coarse_weights / np.sum(coarse_weights)
    
    # Step 2: Fine Sampling
    # Sample N_f points from the coarse distribution
    N_f = 128
    fine_t = sample_from_distribution(p, N_f, t_near, t_far)
    
    # Query fine network
    fine_sigma, fine_color = fine_net(ray_origin, ray_direction, fine_t)
    
    # Step 3: Rendering
    # Compute final weights for fine samples
    # Note: In some implementations, coarse and fine samples are combined.
    # Here we assume standard hierarchical rendering using fine samples only for final color,
    # or combining them as per the specific variant.
    # For simplicity, we use the fine samples' own density for final integration.
    fine_delta_t = np.diff(fine_t, prepend=t_near, append=t_far)
    fine_alpha = 1 - np.exp(-fine_sigma * fine_delta_t)
    fine_T = np.exp(-np.cumsum(fine_sigma * fine_delta_t))
    fine_weights = fine_T * fine_alpha
    
    # Final color
    color = np.sum(fine_weights * fine_color)
    
    return color
```

## Subtopics

### [Combined Sampling (Occupancy Grid + Proposal Network)](1626-combined-sampling-occupancy-grid-proposal-network.md)
Combined sampling stacks an occupancy grid on top of a proposal network to reduce the number of rays processed and shrink the near-far plane for remaining rays. It leverages transmittance estimation from both structures to skip empty space more effectively than either method alone. It differs from [VF-NeRF Rendering Pipeline](3302-vf-nerf-rendering-pipeline.md) by using a learned proposal network for initial density estimation rather than a fixed grid, and from [Coarse-Fine Sampling](8172-coarse-fine-sampling.md) by explicitly combining a sparse spatial index with a neural density prior to prune rays before the final fine sampling stage.

### [VF-NeRF Rendering Pipeline](3302-vf-nerf-rendering-pipeline.md)
The VF-NeRF rendering pipeline is a two-stage volume rendering method that uses a vector field network to predict surface normals, features, and Jacobians for density estimation and shading. It differs from standard NeRF by deriving density from the directional derivative of the vector field rather than a direct scalar field prediction, enabling explicit surface representation within the implicit volume. It builds on [Two-stage NeRF Rendering](925-two-stage-nerf-rendering.md) by integrating vector field-based density computation into the coarse and fine sampling passes.

### [Coarse-Fine Sampling](8172-coarse-fine-sampling.md)
Coarse-Fine Sampling is a two-pass rendering technique for Neural Radiance Fields (NeRF) that improves image quality and sampling efficiency by first estimating the scene's density distribution with a coarse pass, then using that distribution to importance-sample a fine pass. It sets itself apart from uniform sampling by concentrating computational effort on high-density regions identified in the first pass, and from single-stage methods by decoupling the rough density estimation from the detailed color/density evaluation.

### [Semantic Loss Computation](15616-semantic-loss-computation.md)
Semantic Loss Computation computes the cross-entropy loss over coarse and fine semantic predictions for query rays to train a generalizable semantic field. It differs from standard photometric NeRF losses by enforcing semantic consistency across views via ray-based feature projection, allowing the model to learn contextual geometry for semantic information rather than just color. It is a core component of the Two-stage NeRF Rendering pipeline, specifically enabling the training of the semantic head alongside the geometry-aware network.

## Operating characteristics
*   **Time Complexity:** $O(N_c + N_f)$ network queries per ray, where $N_c$ and $N_f$ are the number of coarse and fine samples.
*   **Memory Complexity:** $O(N_c + N_f)$ to store intermediate densities and colors.
*   **Measured Performance:** On an NVIDIA V100, rendering a realistic synthetic dataset (640k rays/image) or real scenes (762k rays/image) takes approximately 30 seconds per frame, resulting in 150-200 million network queries per image [S1].
*   **Strengths:** Significantly reduces the number of network queries required for high-quality images by focusing computation on relevant regions [S1, S3].
*   **Limitations:** Requires training two networks (coarse and fine) or a multi-stage proposal system, increasing training complexity [S2, unofficial][S3].
*   **When to Use:** When rendering high-quality novel views from a trained NeRF is required, and computational resources are limited [S1].
*   **When Not to Use:** For real-time applications where the overhead of two-stage sampling is prohibitive, or for scenes with uniform density where uniform sampling is sufficient [S5, S6].

## Background
Two-stage NeRF Rendering was introduced in the original NeRF paper by Mildenhall et al. in 2020 [S1]. It was developed to address the inefficiency of uniform sampling in neural radiance fields, which often wastes queries on empty space. The method has since become a standard component in many NeRF variants, including those using proposal networks [S2, unofficial][S3] and semantic guidance [S1].
