# Adaptive sampling and reconstruction
Also called: Weiss et al

## Overview
Adaptive sampling and reconstruction is an end-to-end neural pipeline that predicts high-density sampling locations using an importance network, converts these predictions into sparse sample positions via a differentiable sampler, and reconstructs full-resolution images from the sparse data using a reconstruction network [S1, unofficial]. It addresses the inefficiency of uniform sampling by allocating computational resources only to visually important regions, achieving high fidelity with significantly fewer volume queries [S1, unofficial]. Unlike sibling methods that rely on heuristic metrics or fixed subdivision rules, this method learns the sampling distribution and reconstruction jointly through image-level loss optimization [S1, unofficial].

## How it works
The method consists of three jointly trained neural components: an importance network, a differentiable sampler, and a reconstruction network.

**Inputs and Outputs:**
*   **Input:** A low-resolution view (typically $128 \times 128$) or view parameters.
*   **Output:** A full-resolution rendered image.
*   **Intermediate:** Sparse set of sample positions and their corresponding volume values.

**Data Structures:**
*   **Importance Map:** A scalar field predicted by the importance network, representing the probability density for sampling at each pixel location.
*   **Sample Positions:** A set of 2D coordinates $(u, v)$ and associated 3D ray parameters derived from the importance map.
*   **Sparse Samples:** A list of tuples $(ray\_id, t, value)$, where $ray\_id$ is the pixel index, $t$ is the sample position along the ray, and $value$ is the accumulated color/opacity or scalar value at that point.

**Parameters:**
*   **Soft-max approximation parameter ($\alpha$):** Controls the sharpness of the sampling distribution. Typical value: $\alpha \approx 50$ [S1, unofficial].
*   **Sample Density:** The fraction of total possible samples used. Typical values: 5–10% for isosurface rendering, 10% for Direct Volume Rendering (DVR) [S1, unofficial].

**Steps:**
1.  **Importance Prediction:** The importance network takes a low-resolution input (e.g., $128 \times 128$) and outputs an importance map $I(x, y)$ for each pixel. This network learns to identify silhouettes and high-curvature regions without explicit feature descriptors [S1, unofficial].
2.  **Differentiable Sampling:** The importance map $I(x, y)$ is converted into a probability distribution. Sample positions are drawn from this distribution using a soft-max approximation with parameter $\alpha$. This process is differentiable, allowing gradients to flow back to the importance network during training [S1, unofficial].
3.  **Volume Query:** For each selected sample position, a ray is cast into the volume, and the value is queried. This results in a sparse set of samples, significantly reducing the number of volume queries compared to uniform sampling [S1, unofficial].
4.  **Reconstruction:** The reconstruction network takes the sparse samples and the original low-resolution view as input. It combines pull-push inpainting with a residual CNN to predict the missing pixel values and reconstruct the full-resolution image [S1, unofficial].
5.  **Training:** The entire pipeline is trained end-to-end using image losses (PSNR, SSIM, LPIPS) computed on the final reconstructed image. The goal is to minimize the difference between the reconstructed image and the ground truth rendered at high sample density [S1, unofficial].

**Pseudocode:**
```python
def adaptive_sampling_and_reconstruction(volume, view_params, importance_net, reconstruction_net, alpha=50, density=0.1):
    """
    Performs adaptive sampling and reconstruction for volume rendering.
    
    Args:
        volume: The volume dataset (e.g., 3D texture or grid).
        view_params: Camera parameters (position, orientation, FOV).
        importance_net: Neural network predicting importance map from low-res view.
        reconstruction_net: Neural network reconstructing full-res image from sparse samples.
        alpha: Soft-max approximation parameter for sampling.
        density: Fraction of samples to use (e.g., 0.1 for 10%).
        
    Returns:
        full_res_image: Reconstructed full-resolution image.
    """
    # Step 1: Generate low-resolution view for importance prediction
    # Note: In practice, this might be a coarse render or a learned feature map.
    low_res_view = generate_low_res_view(volume, view_params, resolution=(128, 128))
    
    # Step 2: Predict importance map
    importance_map = importance_net(low_res_view)
    
    # Step 3: Convert importance map to sample positions
    # The differentiable sampler draws samples based on the importance distribution.
    # The number of samples is determined by the density parameter.
    # For a 128x128 image, total pixels = 16384.
    # Number of samples = int(16384 * density).
    num_samples = int(128 * 128 * density)
    
    # Sample positions are drawn from the importance map using soft-max approximation.
    # This is a differentiable operation.
    sample_positions = differentiable_sampler(importance_map, num_samples, alpha)
    
    # Step 4: Query volume at sample positions
    # For each sample position, cast a ray and query the volume.
    sparse_samples = []
    for pos in sample_positions:
        ray = cast_ray(view_params, pos)
        value = query_volume(volume, ray)
        sparse_samples.append((pos, value))
        
    # Step 5: Reconstruct full-resolution image
    full_res_image = reconstruction_net(low_res_view, sparse_samples)
    
    return full_res_image
```

**Edge Cases and Pitfalls:**
*   **Reconstruction Overhead:** The reconstruction network has a fixed overhead of approximately 90ms, regardless of volume size. This makes the method slower than optimized ray casting for volumes smaller than $1024^3$ or images smaller than $1024^2$ [S1, unofficial].
*   **Transfer Function Mismatch:** Quality degrades significantly when test transfer functions use color ranges that were absent during training. The network struggles to reconstruct textures if the color distribution is out-of-distribution [S1, unofficial].
*   **Complex Transfer Functions:** Networks struggle with small-scale color variations from complex transfer functions, often defaulting to uniform sampling and resulting in poor reconstruction in textured regions [S1, unofficial].

## Operating characteristics
*   **Performance:** Achieves PSNR > 30 dB and SSIM > 0.95 with only 5–10% of the samples used in uniform sampling [S1, unofficial].
*   **Speedup:** Demonstrates a 1.5–2× speedup for large volumes ($2048^3$) at high resolutions ($\ge 1536^2$) [S1, unofficial].
*   **Memory:** The method requires memory for the neural networks (importance and reconstruction) and the sparse sample storage. The reconstruction network overhead is constant (~90ms), independent of volume size [S1, unofficial].
*   **Strengths:** Reduces computational cost by focusing samples on important regions; learns sampling strategy without explicit feature engineering; high visual fidelity with sparse samples.
*   **Limitations:** High reconstruction overhead for small volumes/images; sensitive to transfer function changes; struggles with complex, small-scale textures; requires training data and joint optimization.
*   **When to Use:** Large volumes ($\ge 1024^3$) and high resolutions ($\ge 1024^2$) where the reconstruction overhead is amortized; scenarios where transfer functions are stable and known during training.
*   **When Not to Use:** Small volumes or low resolutions; dynamic or unknown transfer functions; scenes with highly complex, small-scale textures that were not present in training data.

## Background
The method was proposed by Weiss et al. [156] as a learned optimization for volume visualization, addressing the inefficiency of uniform sampling [S1, unofficial]. It represents a shift from heuristic-based adaptive sampling to data-driven, neural network-based approaches. The approach is part of a broader trend in scientific visualization and computer graphics to leverage deep learning for rendering acceleration and quality improvement [S1, unofficial].
