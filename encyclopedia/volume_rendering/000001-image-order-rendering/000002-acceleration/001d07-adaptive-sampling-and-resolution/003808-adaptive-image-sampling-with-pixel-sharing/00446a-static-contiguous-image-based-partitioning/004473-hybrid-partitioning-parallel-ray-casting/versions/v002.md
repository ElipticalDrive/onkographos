# Hybrid Partitioning Parallel Ray Casting

Also called: High Performance Parallel Ray Casting, Hybrid Partitioning Parallel RC

## Overview
Hybrid Partitioning Parallel Ray Casting is a parallel volume rendering algorithm for shared-memory MIMD architectures (e.g., SGI Power Challenge) that combines object-based partitioning for boundary cell projection with image-based partitioning for ray traversal to achieve load balancing [S1, unofficial]. It sets itself apart from its parent [Static Contiguous Image-Based Partitioning](11259-static-contiguous-image-based-partitioning.md) by decoupling the partitioning strategy: it uses object-based partitioning to handle the uneven distribution of boundary cells and image-based partitioning to handle the uneven distribution of ray traversal work, thereby avoiding the replicated ray casting costs associated with adaptive image sampling at processor boundaries [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D volume dataset, camera parameters (view direction, projection matrix), number of processors $P$, and the set of ray casting optimizations (early ray termination, adaptive depth sampling, adaptive image sampling) [S1, unofficial].
*   **Output:** A 2D image buffer containing the final rendered pixel values.

**Data Structures:**
*   **Projection Buffers ($Z_n, Z_r$):** Two arrays of size $W \times H$ (image width and height). $Z_n[u, v]$ stores the nearest depth intersection, initialized to $\infty$. $Z_r[u, v]$ stores the farthest depth intersection, initialized to $-\infty$. These define the valid integration intervals for each ray [S1, unofficial].

**Numbered Steps:**

1.  **Preprocessing (Boundary Detection):** Identify all boundary cells in the volume [S1, unofficial].
2.  **Object-Based Partitioning (Projection Phase):** Divide the volume into $P$ subsets, each containing an equal number of boundary cells [S1, unofficial]. Each processor independently scans its assigned subset and projects every detected boundary cell onto the image plane to create partial projection buffers ($Z_n^p, Z_r^p$) [S1, unofficial]. Combine all partial buffers to form the complete global projection buffers ($Z_n, Z_r$) [S1, unofficial].
3.  **Image-Based Partitioning (Traversal Phase):** Divide the image into $P$ large blocks of consecutive scanlines, one block per processor [S1, unofficial]. Each processor performs ray integrals within the bounded intervals $[Z_n[u, v], Z_r[u, v]]$ for viable pixels in its assigned block [S1, unofficial]. Empty scanlines are skipped using the projection buffer information [S1, unofficial]. Ray-independent optimizations (early ray termination, adaptive depth sampling) are applied directly along individual rays [S1, unofficial]. Ray-dependent optimizations (adaptive image sampling) require extra attention to avoid replicated ray casting costs at pixels shared by image sections assigned to different processors [S1, unofficial].

**Pseudocode:**

```python
def hybrid_partitioning_parallel_ray_casting(volume, camera, P):
    # Step 1: Preprocessing
    boundary_cells = find_boundary_cells(volume)  # [G] Standard boundary detection

    # Step 2: Object-Based Partitioning
    # Divide volume into P subsets with equal boundary cell counts
    volume_subsets = divide_volume_by_boundary_cells(boundary_cells, P)  # [G] Static contiguous partitioning

    # Initialize global projection buffers
    W, H = camera.image_width, camera.image_height
    Z_n = [[float('inf')] * H for _ in range(W)]
    Z_r = [[float('-inf')] * H for _ in range(W)]

    # Parallel Projection (simulated sequentially for Python validity)
    for p in range(P):
        local_Z_n = [[float('inf')] * H for _ in range(W)]
        local_Z_r = [[float('-inf')] * H for _ in range(W)]

        for voxel in volume_subsets[p]:
            if is_boundary(voxel):  # [G] Check voxel opacity/neighbor status
                u, v, z = project(voxel, camera)
                if 0 <= u < W and 0 <= v < H:
                    if z < local_Z_n[u][v]:
                        local_Z_n[u][v] = z
                    if z > local_Z_r[u][v]:
                        local_Z_r[u][v] = z

        # Combine with global buffers
        for u in range(W):
            for v in range(H):
                if local_Z_n[u][v] < Z_n[u][v]:
                    Z_n[u][v] = local_Z_n[u][v]
                if local_Z_r[u][v] > Z_r[u][v]:
                    Z_r[u][v] = local_Z_r[u][v]

    # Step 3: Image-Based Partitioning
    # Divide image into P contiguous scanline blocks
    scanline_blocks = divide_image_into_scanline_blocks(W, H, P)  # [G] Static contiguous division

    image = [[0.0] * H for _ in range(W)]

    for p in range(P):
        u_start, u_end = scanline_blocks[p]
        for v in range(H):
            for u in range(u_start, u_end):
                # Check viability
                if Z_n[u][v] == float('inf') or Z_r[u][v] == float('-inf'):
                    continue

                # Cast ray and integrate within bounds
                ray_origin, ray_direction = cast_ray(camera, u, v)  # [G] Standard ray generation
                color = 0.0
                alpha = 0.0

                # March from Z_n to Z_r
                t = Z_n[u][v]
                while t < Z_r[u][v]:
                    step_size = adaptive_step(ray_direction, t)  # [G] Adaptive depth sampling
                    sample = trilinear_interpolate(volume, ray_origin + ray_direction * t)  # [G] Standard interpolation

                    color, alpha = composite_step(sample, color, alpha)  # [G] Standard volume compositing

                    if alpha > 1.0 - 1e-6:  # Early ray termination
                        break

                    t += step_size

                image[u][v] = color

    return image
```

**Parameters:**
*   $P$: Number of processors. Typical values depend on hardware (e.g., SGI Power Challenge had multiple CPUs) [S1, unofficial].
*   $\epsilon$: Threshold for early ray termination. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Replicated Ray Casting:** Ray-dependent optimizations like adaptive image sampling can cause replicated work if pixels shared by different processor blocks are evaluated independently. The static contiguous image-based partitioning completely avoids this cost without extra synchronization overhead [S1, unofficial].

## Subtopics

### Parallel Ray Casting with Static Image-Based Partitioning
A variant that incorporates adaptive image sampling and early ray termination optimizations from the serial version. Adaptive depth sampling is used to skip time-consuming points between voxel layers. It is chosen when static contiguous scanline blocks are sufficient for load balancing and serial optimizations must be preserved [S2, unofficial].

### Parallel Ray Casting on MIMD
An implementation focusing on data coherence and load balancing on MIMD computers. Work is assigned to processors to exploit data coherence, meaning a single processor works on neighboring rays whenever possible. It is chosen when hardware architecture favors spatial locality, accepting the trade-off that computational costs for different rays can vary by several orders of magnitude [S3, unofficial].

## Operating characteristics
*   **Time and Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Tested on an SGI Power Challenge shared-memory MIMD architecture [S1, unofficial].
*   **Strengths:** Avoids the dilemma of choosing between object-based and image-based partitioning. Leverages optimizations from the serial algorithm. No extra synchronization overhead for adaptive image sampling [S1, unofficial].
*   **Limitations:** Requires a shared-memory architecture. The static nature of the partitioning may lead to load imbalance if the distribution of boundary cells or viable pixels is highly skewed, though the equal boundary cell division mitigates this for the projection phase [S1, unofficial].

## Background
The method was developed for time-critical volume rendering on shared-memory MIMD architectures, specifically the SGI Power Challenge [S1, unofficial]. It builds on a serial ray casting algorithm that included optimizations like adaptive image sampling and early ray termination [S1, unofficial]. The hybrid approach was proposed to overcome the limitations of existing parallel algorithms that had to choose between object-based or image-based partitioning, giving up the advantages of the other [S1, unofficial].
