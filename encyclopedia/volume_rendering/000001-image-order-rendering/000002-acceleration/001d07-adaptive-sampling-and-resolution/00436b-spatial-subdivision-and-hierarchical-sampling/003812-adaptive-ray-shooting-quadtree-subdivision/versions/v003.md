# Adaptive Ray Shooting & Quadtree Subdivision

Also called: Adaptive quadtree subdivision, Image context based probability distribution

## Overview
Adaptive Ray Shooting & Quadtree Subdivision is a general strategy to accelerate the training of radiance field-based methods by reducing ray redundancy during volume rendering [S1]. It solves the problem of excessive computational cost in multi-view volume rendering by dynamically adjusting the number of rays cast per pixel based on local image complexity [S1]. Unlike specialized architectures such as Plenoxels, TensoRF, or Instant-NGP that require specific data structures like sparse voxel grids or hash coding, this method is a general framework applicable to almost all radiance field methods without architectural modification [S1].

## How it works
The method operates as a preprocessing step for the volume rendering loop, determining which rays to evaluate based on a quadtree decomposition of the image plane.

**Inputs and Outputs**
*   **Input:** A set of $N$ training images $\mathcal{I}$, where each image $I_i$ has a resolution. A radiance field model $F_\Theta$ that maps a 5D point to color and density.
*   **Output:** A subset of rays $R_i \subset \text{All Rays}_i$ for each image $I_i$, selected via adaptive subdivision.

**Data Structures**
*   **Quadtree:** Each image $I_i$ is represented as a quadtree. The root node covers the entire image. Each node has four children covering quadrants.
*   **Node Metric:** Each node stores the average rendering error of the rays passing through its region.
*   **5D Point Representation:** Points are defined as $\mathbf{x} = (x, y, z) \in \mathbb{R}^3$ and viewing direction $\mathbf{d} = (\theta, \phi) \in \mathbb{R}^2$ [S1].

**Algorithm Steps**
1.  **Initialization:** For each training image $I_i \in \mathcal{I}$, initialize a quadtree with a single root node covering the full image dimensions.
2.  **Initial Ray Casting:** Cast a uniform set of rays for all pixels in the initial quadtree nodes.
3.  **Error Computation:** For each node in the quadtree, compute the average rendering error. Let $E_j$ be the error for node $j$. The error is derived from the difference between the rendered color and the target pixel color.
4.  **Subdivision Decision:** Compare the average error $E_j$ of each node against a threshold. If $E_j$ exceeds the threshold, subdivide the node into four children. Repeat this process recursively until a maximum depth is reached or the error is below the threshold.
5.  **Adaptive Ray Shooting:** For leaf nodes in the final quadtree:
    *   If the node is in a "complex" region (high error), cast more rays (higher sampling density).
    *   If the node is in a "simple" region (low error), cast fewer rays (lower sampling density).
    *   Specifically, rays are shot primarily at pixels with dramatic color change [S1].
6.  **Volume Rendering:** For each selected ray $r_{ki}$, sample 5D points along the ray. The network $F_\Theta$ predicts color $c$ and density $\sigma$. Render the pixel color $\hat{c}_{ki}$ using standard volume rendering integration.
7.  **Loss Calculation:** Compute the loss $L$ over all selected rays:
    $$ L = \frac{1}{NM} \sum_{I_i \in \mathcal{I}} \sum_{r_{ki} \in R_i} ||V_\Theta(r_{ki}) - c_{ki}||_2^2 $$
    Where:
    *   $N$ is the number of training images [S1].
    *   $M$ is the number of rays per image (total rays selected) [S1].
    *   $\mathcal{I}$ is the set of all training images [S1].
    *   $R_i$ is the set of rays generated from $I_i$ [S1].
    *   $r_{ki}$ is the $k$-th ray from the $i$-th training image [S1].
    *   $V_\Theta$ is the volume rendering function mapping a ray to rendered color $\hat{c}_{ki}$ [S1].
    *   $c_{ki}$ is the target pixel color [S1].
8.  **Optimization:** Update network parameters $\Theta$ to minimize $L$.
9.  **Iteration:** Repeat steps 2-8 for subsequent training iterations, updating the quadtree structure based on the latest rendering errors.

**Pseudocode**

```python
def adaptive_ray_shooting_quadtree(images, radiance_field, max_depth, error_threshold):
    """
    images: List of training images I_i
    radiance_field: Function F_Theta(x, d) -> (c, sigma)
    max_depth: Maximum depth for quadtree subdivision
    error_threshold: Threshold for node subdivision
    """
    # Initialize quadtrees for each image
    quadtrees = []
    for I_i in images:
        qt = Quadtree(root_node=Node(image_width=I_i.width, image_height=I_i.height, depth=0))
        quadtrees.append(qt)

    for epoch in range(num_epochs):
        total_loss = 0.0
        total_rays = 0

        for idx, I_i in enumerate(images):
            qt = quadtrees[idx]
            
            # Step 1: Subdivide Quadtree based on previous error or initial guess
            # If first epoch, use uniform sampling or image gradient as proxy for error
            if epoch == 0:
                qt.subdivide_based_on_gradient(error_threshold, max_depth)
            else:
                qt.subdivide_based_on_rendering_error(error_threshold, max_depth, radiance_field)

            # Step 2: Generate rays from leaf nodes
            rays_to_render = []
            for leaf in qt.get_leaf_nodes():
                # Determine number of rays based on node complexity/error
                # Higher error -> more rays
                num_rays = leaf.calculate_ray_count()
                rays = leaf.generate_rays(num_rays)
                rays_to_render.extend(rays)

            # Step 3: Render rays
            rendered_colors = []
            for ray in rays_to_render:
                # Sample 5D points along ray
                points_5d = sample_5d_points_along_ray(ray)
                # Render using volume rendering
                c_hat = volume_render(ray, points_5d, radiance_field)
                rendered_colors.append(c_hat)

            # Step 4: Compute Loss and Update Quadtree Metrics
            target_colors = I_i.get_pixel_colors()
            loss = compute_l2_loss(rendered_colors, target_colors)
            total_loss += loss
            total_rays += len(rays_to_render)

            # Update node errors for next iteration's subdivision
            qt.update_node_errors(rendered_colors, rays_to_render)

        # Normalize loss
        N = len(images)
        M = total_rays
        avg_loss = total_loss / (N * M)
        
        # Update radiance field parameters
        radiance_field.update_parameters(avg_loss)

    return radiance_field
```

**Parameters**
*   **Error Threshold:** Controls the granularity of the quadtree. Not given in the sources.
*   **Max Depth:** Limits the recursion depth of the quadtree. Not given in the sources.
*   **Ray Density Multiplier:** Factor determining how many more rays are cast in complex regions vs. simple regions. Not given in the sources.

**Edge Cases and Pitfalls**
*   **Precision:** Rendering error computation must be stable to avoid oscillating subdivision patterns.
*   **Boundaries:** Quadtree nodes must align with pixel boundaries to ensure correct ray mapping.
*   **Degenerate Input:** If an image is uniform, the quadtree will remain at the root level, casting minimal rays. If an image is highly noisy, the quadtree may reach max depth everywhere, resulting in uniform sampling.

## Operating characteristics
*   **Time Complexity:** The method reduces the total number of rays $M$ significantly compared to uniform sampling, thereby reducing the time spent in volume rendering per epoch. However, the overhead of quadtree management and error computation adds a small constant cost.
*   **Memory Complexity:** Requires storing the quadtree structure for each image. The size is proportional to the number of nodes, which is bounded by $4 \times \text{Image Resolution}$ in the worst case (full subdivision).
*   **Measured Performance:** Evaluated with NeRF and Plenoxels under widely used benchmarks, achieving comparable accuracy to state-of-the-art methods with much faster training [S1].
*   **Strengths:** General applicability to various radiance field methods; reduces training burden by focusing on complex regions; barely affects accuracy [S1].
*   **Limitations:** Requires an initial pass or heuristic to determine error before accurate subdivision can occur; overhead of dynamic ray generation.
*   **When to Use:** When training radiance fields is computationally expensive and the scene has varying levels of detail.
*   **When Not to Use:** When real-time inference is the primary concern (this is a training acceleration method); when the scene is uniformly simple (overhead may not be justified).

## Background
The method was introduced in the paper "Fast Learning Radiance Fields by Shooting Much Fewer Rays" [S1]. It addresses the limitation of specialized fast training methods (like Plenoxels, TensoRF, Instant-NGP) that require specific architectures [S1]. The key insight is that radiance fields can be perceived without dramatically sacrificing accuracy by shooting fewer rays in redundant regions [S1]. The method leverages the fact that pixels with dramatic color change contain more information and require more samples [S1].
