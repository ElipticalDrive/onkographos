# Random Variable Augmentation for Optimization

Also called: Auxiliary Random Variables, Random Variable Augmentation, Random Variable Augmentation for Discontinuity Sampling, Stochastic Parameter Augmentation

## Overview
Random Variable Augmentation is a technique for optimizing shader parameters in volume rendering by introducing uniformly distributed random variables to Dirac parameters, ensuring that discontinuities (such as Z-ordering or object boundaries) are sampled more frequently during gradient estimation. It solves the problem where vanilla gradient methods fail because the rendered image only exposes one branch of a discrete choice, causing the discontinuity to be missed on the 2D spatial grid. Unlike vanilla methods that sample discontinuities only at the ring contour, this method extends the sampling space to include Dirac parameters, allowing discontinuities to be sampled at many more pixels via speckling in overlapping regions.

## How it works
**Inputs and Outputs**
- **Inputs:** Shader parameters controlling discrete choices (Dirac parameters), specifically those affecting Z-ordering or object boundaries.
- **Outputs:** Optimized parameter values and associated random variable scales.

**Data Structures**
- **Dirac Parameters:** Parameters that control discrete decisions (e.g., Z-values for depth sorting).
- **Random Variable Scales:** A tunable scalar parameter associated with every Dirac parameter, controlling the magnitude of the added noise.

**Steps**
1. **Identify Dirac Parameters:** Select parameters that control discrete choices, such as Z-values for depth sorting or object boundary definitions. Exclude parameters dependent on `RaymarchingLoop` primitives [S1].
2. **Augment with Random Variables:** For each selected Dirac parameter $p$, augment its value by adding a per-pixel, uniformly distributed, independently distributed random variable $r$:
   $$ p' = p + r $$
   where $r \sim \text{Uniform}(-\sigma, \sigma)$ and $\sigma$ is the scale parameter associated with $p$ [S1].
3. **Optimize Scales:** Treat the scale $\sigma$ of each random variable as a tunable parameter. Optimize these scales alongside the Dirac parameters during the optimization process [S1].
4. **Gradient Estimation:** Compute gradients using a stochastic direction in the parameter space. The sample spacing is scaled by both the image grid spacing $\epsilon$ and the maximum scale $\sigma_{max}$ among all random variables [S1].
5. **Convergence:** At convergence, the optimized scales $\sigma$ are typically so small that the random noise is not perceived during rasterization [S1].

**Formulas**
- **Augmented Parameter:** $p' = p + r$, where $r \sim \text{Uniform}(-\sigma, \sigma)$ [S1].
- **Pre-filtering Kernel Width:** The width of the pre-filtering kernel is of the form $O(\epsilon) + O(\sigma)$, where $\epsilon$ is the image grid spacing and $\sigma$ is the random variable scale [S1].
- **Approximation Error:** The error bound changes from $O(\epsilon)$ to $O(\epsilon) + O(\sigma)$. As $\sigma \to 0$, the error becomes similar to that without random noise [S1].

**Parameters**
- **Scale ($\sigma$):** A tunable parameter associated with every Dirac parameter. Typical values are optimized to be small at convergence [S1].

**Edge Cases and Pitfalls**
- **RaymarchingLoop:** Random variables cannot be combined with `RaymarchingLoop` for implicitly defined geometry because the assumptions made in its gradient derivation are violated by random variables [S1].
- **Vanilla Method Failure:** Vanilla methods fail to optimize Z-values when the interlock pattern is wrong because the discontinuity generated by comparing Z-values between overlapping rings may not be sampled on the current image grid if the rendered image only exposes one branch [S1].

**Pseudocode**
```python
def augment_dirac_parameters(dirac_params, scales):
    """
    Augments Dirac parameters with random variables.
    
    Args:
        dirac_params: List of Dirac parameters (e.g., Z-values).
        scales: List of scale parameters associated with each Dirac parameter.
        
    Returns:
        Augmented parameters.
    """
    augmented_params = []
    for p, sigma in zip(dirac_params, scales):
        # Generate a per-pixel, uniformly distributed random variable
        # Note: In practice, this is done per-pixel during rendering/optimization
        r = uniform_random_variable(-sigma, sigma)
        augmented_params.append(p + r)
    return augmented_params

def compute_gradient_with_augmentation(shader, params, scales, epsilon):
    """
    Computes gradient using stochastic direction in parameter space.
    
    Args:
        shader: The shader function.
        params: Original parameters.
        scales: Scales of random variables.
        epsilon: Image grid spacing.
        
    Returns:
        Gradient estimate.
    """
    # Sample along a stochastic direction
    # The sample spacing is scaled by both epsilon and max(scales)
    max_scale = max(scales)
    step_size = epsilon + max_scale
    
    # Compute gradient using finite differences or automatic differentiation
    # with the augmented parameters
    augmented_params = augment_dirac_parameters(params, scales)
    gradient = compute_gradient(shader, augmented_params, step_size)
    return gradient
```

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Measured Performance:** Not given in the sources.
- **Scaling:** Not given in the sources.
- **Strengths:** Allows discontinuities to be sampled at many more pixels by creating speckling color in overlapping regions, where each pair of pixel neighbors with disagreeing color represents the discontinuity [S1].
- **Limitations:** Cannot be combined with `RaymarchingLoop` for implicitly defined geometry [S1]. Larger scale in the random variable increases approximation error [S1].
- **When to Use:** When vanilla gradient methods fail to optimize parameters due to discontinuities not being sampled on the 2D image grid, such as in Z-ordering of overlapping rings [S1].
- **When Not to Use:** When the shader involves `RaymarchingLoop` for implicitly defined geometry [S1].

## Background
- **Origin:** The technique was introduced in the paper "A δ" [S1].
- **History and Development:** The method was developed to address the limitations of vanilla gradient methods in optimizing shader parameters with discrete choices. It extends the sampling space from 2D spatial coordinates to a higher-dimensional space including Dirac parameters [S1].
- **Where it is Used:** In shader optimization for volume rendering, particularly for handling discontinuities in Z-ordering and object boundaries [S1].
