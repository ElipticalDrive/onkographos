# Temporal Gradient Denoising

Also called: Temporal denoising of gradient image, Temporal denoising on gradients

## Overview
Temporal Gradient Denoising is a technique that reduces noise in volume rendering by applying temporal reprojection and blending to gradient images rather than the final radiance image [S1, S2]. It solves the problem of high noise levels in Monte Carlo volume rendering, particularly in high-order scattering-dominant media, while avoiding the visible bias and artifacts that occur when denoising the original image directly [S1, S2]. It sets itself apart from standard temporal accumulation by operating on the derivative of the radiance with respect to a source parameter (albedo), leveraging the fact that denoising artifacts in the gradient domain are not directly visible in the final color [S1, S2].

## How it works
**Inputs and Outputs:**
- **Inputs:** A sequence of rendered gradient images $G_k$ for $k \in [0, N-1]$, where $k=0$ is the target frame; motion vectors $d$ and velocities $v_d$ in screen space; smoothing factor $w_a$; number of frames $N$; time $t$ [S1, S2].
- **Outputs:** A denoised gradient image $G_{\text{denoised}}$ for the target frame [S1, S2].

**Data Structures:**
- **Gradient Image:** A 2D array of floating-point values representing the gradient of radiance with respect to albedo at each pixel. Layout is standard screen-space raster format.
- **Motion Vector:** A 2D vector $(d_x, d_y)$ per pixel or globally, derived from camera movement [S2].

**Steps:**
1. **Compute Motion Parameters:** Determine the motion vector $d$ and velocity $v_d$ in screen space based on the camera's moving direction and velocity [S2].
2. **Reproject Pixels:** For each pixel $i$ in the target frame, calculate the corresponding pixel coordinate in neighboring frames using the reprojection function $f_{\text{proj}}$ [S1, S2].
3. **Blend Gradients:** Compute the weighted average of the reprojected gradient values from neighboring frames to produce the denoised gradient [S1, S2].

**Formulas:**
The reprojection function maps a pixel $i$ in the target frame to a coordinate in a neighboring frame at distance $k$:
$$ f_{\text{proj}}(i) = i + d \cdot v_d \cdot t $$
where $t$ is the time offset [S1, S2].

The denoised gradient $G_{\text{denoised}}(i)$ is calculated as:
$$ G_{\text{denoised}}(i) = \frac{\sum_{k=0}^{N-1} w_a^k (1-w_a)^{-1} G_k(f_{\text{proj}}^{-1}(i))}{1 - (1-w_a)^N} $$
where:
- $k$ is the frame distance (number of frames between the source image and the target image, with $k=0$ being the target) [S1, S2].
- $G_k$ is the gradient image at distance $k$ [S1, S2].
- $w_a$ is the smoothing factor [S1, S2].
- $N$ is the number of frames used for denoising [S1, S2].
- $f_{\text{proj}}^{-1}$ is the reciprocal reprojection function, mapping the target pixel $i$ back to the source frame coordinate [S2].

*Note on Formula Discrepancy:* Source [S2] presents a slightly different formulation in Equation (10) involving $(1-w_a)^{-1}$ inside the summation term differently, but the structure remains a weighted temporal blend. The formula above combines the consistent elements from both sources [S1, S2]. Specifically, [S2] writes:
$$ G_{\text{denoised}}(i) = \left[ \sum_{k=0}^{N-1} w_a^k (1 - (1-w_a)^{-1} (1-w_a) G_k(f_{\text{proj}}^{-1}(i))) \right]^{-1} $$
This appears to contain a typographical error in the source text regarding the placement of the inverse and the term $(1-w_a)$. The standard interpretation of temporal blending with exponential decay (as implied by $w_a^k$) is the weighted sum divided by the normalization factor. The first formula provided is the standard interpretation of the weighted sum described in [S1] and the intent of [S2].

**Parameters:**
- **Smoothing factor ($w_a$):** Set to 0.1 in all test scenes [S1, S2].
- **Number of frames ($N$):** Set to 11 in the implementation [S1, S2].

**Pitfalls:**
- **Direct Image Denoising:** Denoising the original radiance image directly causes visible bias and artifacts. Denoising the gradient prevents this because such artifacts are not directly visible in the gradient domain [S1, S2].
- **Precision:** The reciprocal reprojection $f_{\text{proj}}^{-1}$ requires careful handling of boundary conditions where projected coordinates fall outside the image bounds [S2].

**Pseudocode:**
```python
def temporal_gradient_denoise(target_gradient, neighbor_gradients, motion_vector, velocity, smoothing_factor, num_frames):
    """
    Denoises the target gradient image using temporal reprojection and blending.
    
    Args:
        target_gradient: 2D array, gradient image for the current frame (k=0).
        neighbor_gradients: List of 2D arrays, gradient images for previous frames (k=1 to N-1).
        motion_vector: 2D tuple (dx, dy), motion vector d.
        velocity: 2D tuple (vx, vy), velocity v_d.
        smoothing_factor: float, w_a.
        num_frames: int, N.
        
    Returns:
        denoised_gradient: 2D array.
    """
    # Initialize accumulator for weighted sum and normalization factor
    weighted_sum = np.zeros_like(target_gradient)
    normalization_factor = 0.0
    
    # Process the target frame (k=0)
    # For k=0, f_proj^-1(i) = i
    weighted_sum += (smoothing_factor ** 0) * (1 - smoothing_factor) ** (-1) * target_gradient
    normalization_factor += (smoothing_factor ** 0) * (1 - smoothing_factor) ** (-1)
    
    # Process neighboring frames (k=1 to N-1)
    for k in range(1, num_frames):
        if k > len(neighbor_gradients):
            break
            
        neighbor_grad = neighbor_gradients[k-1]
        
        # Calculate reprojection offset
        # t is implicitly handled by the frame index k in the context of the sequence
        # Assuming t=1 per frame step for simplicity as per standard temporal reprojection
        # The formula uses d * v_d * t. If t is time delta, it should be passed.
        # Here we assume the motion vector provided is already scaled for the frame step or t=1.
        offset = np.array([motion_vector[0] * velocity[0], motion_vector[1] * velocity[1]])
        
        # Create grid for reprojection
        # f_proj^-1(i) maps target pixel i to source pixel coordinate
        # We need to sample neighbor_grad at coordinates shifted by -offset
        # Since f_proj(i) = i + offset, f_proj^-1(i) = i - offset
        
        # Generate pixel coordinates for the target frame
        h, w = target_gradient.shape
        y, x = np.meshgrid(np.arange(h), np.arange(w), indexing='ij')
        
        # Calculate source coordinates
        src_y = y - offset[0]
        src_x = x - offset[1]
        
        # Sample the neighbor gradient at the reprojected coordinates
        # Using bilinear interpolation for robustness
        reprojected_grad = bilinear_sample(neighbor_grad, src_x, src_y)
        
        # Calculate weight for this frame
        weight = (smoothing_factor ** k) * (1 - smoothing_factor) ** (-1)
        
        # Accumulate
        weighted_sum += weight * reprojected_grad
        normalization_factor += weight
        
    # Compute final denoised gradient
    denoised_gradient = weighted_sum / normalization_factor
    
    return denoised_gradient

def bilinear_sample(image, x, y):
    """
    Performs bilinear interpolation on the image at coordinates x, y.
    Handles boundary conditions by clamping or returning 0 for out-of-bounds.
    """
    h, w = image.shape
    # Clamp coordinates to valid range
    x_clamped = np.clip(x, 0, w - 1)
    y_clamped = np.clip(y, 0, h - 1)
    
    # Get integer and fractional parts
    x0 = np.floor(x_clamped).astype(int)
    y0 = np.floor(y_clamped).astype(int)
    x1 = np.minimum(x0 + 1, w - 1)
    y1 = np.minimum(y0 + 1, h - 1)
    
    # Fractional parts
    dx = x_clamped - x0
    dy = y_clamped - y0
    
    # Get pixel values
    val00 = image[y0, x0]
    val01 = image[y0, x1]
    val10 = image[y1, x0]
    val11 = image[y1, x1]
    
    # Interpolate
    result = (1 - dx) * (1 - dy) * val00 + dx * (1 - dy) * val01 + \
             (1 - dx) * dy * val10 + dx * dy * val11
             
    return result
```

## Subtopics

### [Spatiotemporal Volume Denoising with Background Fusion](15105-spatiotemporal-volume-denoising-with-background-fusion.md)
This method denoises Monte Carlo volume rendering images by combining temporal reprojection with a learned kernel prediction network and fusing the result with the background using an alpha map. It addresses the specific challenge of preserving semi-transparent structures and sharp edges in volumetric data while maintaining real-time performance. Unlike direct prediction methods (e.g., FDAE) that rely solely on pixel-wise regression, this approach generates weighted combinations of neighboring samples, offering better structural preservation at the cost of struggling with extreme high-intensity outliers.

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of pixels and the number of frames $N$ [S1, S2]. The reprojection and blending operations are per-pixel.
- **Memory Complexity:** Requires storing $N$ gradient images and their corresponding motion vectors [S1, S2].
- **Measured Performance:** In test scenes (Bunny, Candle, Lucy) with resolution 256x256, the method produced less error than denoised path tracing and path tracing without denoising, both visually and quantitatively [S1]. The method was implemented with $N=11$ and $w_a=0.1$ [S1, S2].
- **Strengths:** Effectively reduces noise in high-order scattering-dominant media; avoids visible bias/artifacts associated with direct image denoising; improves quality over standard path tracing with equal time [S1, S2].
- **Limitations:** Requires a sequence of frames (temporal coherence); performance gain over path tracing is specific to gradient denoising, as temporal denoising on path tracing itself does not perform better than path tracing with equal time [S1].
- **When to use:** When rendering sequences of volume data with high noise levels, particularly in participating media with high albedo, and when temporal coherence is available [S1, S2].
- **When not to use:** For single-image rendering; when extreme high-intensity outliers are present and structural preservation is critical without learned kernels [S1].

## Background
The method was proposed in the context of efficient participating media rendering using differentiable volumetric path tracing [S1, S2]. It was introduced to address the high noise levels in gradient images computed with respect to albedo, which are used to predict radiance for different albedo values without re-rendering [S2]. The approach leverages the common practice of rendering image sequences with moving cameras [S1, S2]. The work was published in 2023 [S1, S2].
