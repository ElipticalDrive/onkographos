# Spatiotemporal Volume Denoising with Background Fusion

Also called: Kernel prediction denoising with background fusion, Real-time volume-rendering image denoising based on kernel prediction

## Overview
This method denoises Monte Carlo volume rendering images by combining temporal reprojection with a learned kernel prediction network and fusing the result with the background using an alpha map [S1, unofficial]. It addresses the specific challenge of preserving semi-transparent structures and sharp edges in volumetric data while maintaining real-time performance [S1, unofficial]. Unlike direct prediction methods (e.g., FDAE) that rely solely on pixel-wise regression, this approach generates weighted combinations of neighboring samples, offering better structural preservation at the cost of struggling with extreme high-intensity outliers [S1, unofficial].

## How it works
The method operates on image-order rendering outputs [S1, unofficial]. It takes the current noisy frame, the previous frame's denoised data, and the background color as inputs, producing a final denoised radiance image [S1, unofficial].

### Data Structures and Layout
*   **Input Images:** 1024x1024 resolution, 32-bit floating-point format [S1, unofficial].
*   **Alpha Map $A(i,j)$:** A single-channel map representing the transparency of the volume data at pixel coordinates $(i,j)$ [S1, unofficial].
*   **Background $B(i,j)$:** The color/value of the background at pixel coordinates $(i,j)$ [S1, unofficial].
*   **Training Patches:** 256x256 image patches extracted from the rendered images (four patches per image) [S1, unofficial].

### Numbered Steps
1.  **Reprojection:** Reproject the previous frame's denoised volume data into the current frame's coordinate space using camera motion and depth information [S1, unofficial].
2.  **Kernel Prediction:** Use a neural network (kernel prediction network) to predict spatial and temporal weight kernels based on the current noisy frame and the reprojected historical data [S1, unofficial].
3.  **Weighted Filtering:** Perform pixel-wise weighted filtering on the reprojected historical frame and the current noisy frame using the predicted kernels to obtain an intermediate denoised volume data $x_n'(i,j)$ [S1, unofficial].
4.  **Background Fusion:** Blend the intermediate denoised data $x_n'(i,j)$ with the background $B(i,j)$ using the alpha map $A(i,j)$ to produce the final denoised pixel value $x_n''(i,j)$ [S1, unofficial].
5.  **Failure Handling:** If the camera undergoes rapid motion, abrupt illumination changes, or if a ray passes entirely through transparent regions (where historical frame failure rate can reach 70%), copy the current frame's pixel value to replace the historical frame value, effectively degenerating to spatial denoising for that pixel [S1, unofficial].

### Formulas
**Background Fusion:**
The final denoised pixel value $x_n''$ is calculated as:
$$ x_n''(i,j) = A(i,j) \times x_n'(i,j) + (1 - A(i,j)) \times B(i,j) $$
where $A(i,j)$ is the alpha map and $B(i,j)$ is the background [S1, unofficial].

**Training Loss Functions:**
The model is trained using a weighted sum of gradient loss and Mean Squared Error (MSE) loss [S1, unofficial].

Gradient Loss $L_{grad}(I,R)$:
$$ L_{grad}(I,R) = \|\nabla_x I - \nabla_x R\|_2^2 + \|\nabla_y I - \nabla_y R\|_2^2 $$
where $I$ is the predicted image, $R$ is the reference image, and $\nabla_x, \nabla_y$ are the x and y gradients [S1, unofficial].

MSE Loss $L_{mse}(I,R)$:
$$ L_{mse}(I,R) = \|I - R\|_2^2 $$
where $\| \cdot \|_2^2$ denotes the squared L2 norm [S1, unofficial].

Total Loss $L_{total}(I,R)$:
$$ L_{total}(I,R) = w_{grad} \cdot L_{grad}(I,R) + w_{mse} \cdot L_{mse}(I,R) $$
where $w_{grad}$ and $w_{mse}$ are the weights for gradient and MSE losses, respectively [S1, unofficial].

**Evaluation Metrics:**
MSE:
$$ MSE(I,R) = \frac{1}{mn} \sum_{i=0}^{m-1} \sum_{j=0}^{n-1} [I(i,j) - R(i,j)]^2 $$
where $m,n$ are image dimensions [S1, unofficial].

PSNR:
$$ PSNR(I,R) = 10 \times \lg \frac{255^2}{MSE(I,R)} $$
where $\lg$ is the base-10 logarithm [S1, unofficial].

SSIM:
$$ SSIM(I,R) = \frac{(2\mu_I\mu_R+c_1)(\delta_{IR}+c_2)}{(\mu_I^2+\mu_R^2+c_1)(\delta_I^2+\delta_R^2+c_2)} $$
where $\mu_I, \mu_R$ are means, $\delta_I, \delta_R$ are standard deviations, and $\delta_{IR}$ is the covariance between images $I$ and $R$ [S1, unofficial].

Temporal PSNR (tPSNR):
$$ tPSNR(I,R) = PSNR(I_t - I_{t-1}, R_t - R_{t-1}) $$
where $t$ is the time index [S1, unofficial].

### Parameters
*   **$w_{grad}$:** Weight for gradient loss. Set to 0.4 to improve visual edge preservation [S1, unofficial].
*   **$w_{mse}$:** Weight for MSE loss. Set to 0.6 [S1, unofficial].
*   **Learning Rate:** 0.0001 (Adam optimizer) [S1, unofficial].
*   **Batch Size:** 4 [S1, unofficial].
*   **Training Epochs:** Converges after approximately 300 epochs [S1, unofficial].

### Edge Cases and Pitfalls
*   **High Gradient Weight:** If $w_{grad}$ is set too high (above 0.5), the image exhibits slight color distortion for some data [S1, unofficial].
*   **Transparent Regions:** In ray tracing, if a ray passes entirely through transparent regions, the historical frame failure rate can be as high as 70%. The method handles this by copying the current frame's pixel value to replace the historical value, degenerating to spatial denoising [S1, unofficial].
*   **Rapid Motion/Changes:** Historical frames become unusable if the camera undergoes rapid motion, illumination changes abruptly, or the transfer function varies quickly [S1, unofficial].
*   **Outliers:** The kernel prediction method struggles with highlighted outliers (e.g., channel values > 200 at 800 samples per pixel) that direct prediction methods can suppress [S1, unofficial].

import math

class Image:
    def __init__(self, width, height, channels=3):
        self.width = width
        self.height = height
        self.channels = channels
        self.data = [[[0.0] * channels for _ in range(width)] for _ in range(height)]
    def get(self, x, y):
        return self.data[y][x]
    def set(self, x, y, val):
        self.data[y][x] = val

def reproject(src_img, camera_transform, depth_map):
    # [G] Standard inverse reprojection: maps each target pixel to source coordinates
    # using the camera projection matrix and depth buffer, then samples with clamping.
    dst = Image(src_img.width, src_img.height, src_img.channels)
    for y in range(dst.height):
        for x in range(dst.width):
            # 1. Unproject (x, y, depth) to world space using inverse camera matrix
            # 2. Transform to previous frame's camera space
            # 3. Project to previous frame's 2D coordinates (u, v)
            # 4. Clamp (u, v) to [0, width-1] x [0, height-1]
            # 5. Bilinear interpolation from src_img
            u, v = 0.0, 0.0 # Placeholder for exact matrix math [G]
            u = max(0, min(dst.width - 1, u))
            v = max(0, min(dst.height - 1, v))
            dst.set(x, y, src_img.get(int(u), int(v)))
    return dst

def predict_kernels(current_frame, historical_frame):
    # [G] The source describes a learned kernel prediction network trained end-to-end.
    # The exact architecture is not provided, so we model it as a function that
    # outputs a weight tensor for a 3x3 neighborhood based on input features.
    kernel_size = 3
    weights = [[[0.0] * current_frame.channels for _ in range(kernel_size)] for _ in range(kernel_size)]
    # In practice, a convolutional neural network processes current_frame and historical_frame
    # to generate these weights. Here we return a uniform kernel as a structural placeholder.
    return weights

def weighted_filter(current_frame, historical_frame, kernels):
    # Pixel-wise weighted filtering on historical reprojection and current frame
    result = Image(current_frame.width, current_frame.height, current_frame.channels)
    kernel_size = len(kernels)
    half = kernel_size // 2
    for y in range(current_frame.height):
        for x in range(current_frame.width):
            acc = [0.0] * current_frame.channels
            total_weight = 0.0
            for ky in range(kernel_size):
                for kx in range(kernel_size):
                    sy = y + ky - half
                    sx = x + kx - half
                    sy = max(0, min(current_frame.height - 1, sy))
                    sx = max(0, min(current_frame.width - 1, sx))
                    w = kernels[ky][kx][0] # Use first channel weight as scalar
                    c_curr = current_frame.get(sx, sy)
                    c_hist = historical_frame.get(sx, sy)
                    # Blend current and historical based on kernel weights
                    for c in range(current_frame.channels):
                        acc[c] += w * (0.5 * c_curr[c] + 0.5 * c_hist[c])
                    total_weight += w
            for c in range(current_frame.channels):
                result.set(x, y, acc[c] / total_weight if total_weight > 0 else 0.0)
    return result

def spatiotemporal_denoising_with_background_fusion(
    current_noisy_frame: Image,
    previous_denoised_frame: Image,
    alpha_map: Image,
    background: Image,
    camera_transform: list,
    depth_map: Image
) -> Image:
    # Step 1: Reprojection
    reprojected_frame = reproject(previous_denoised_frame, camera_transform, depth_map)

    # Step 2: Kernel Prediction
    weight_kernels = predict_kernels(current_noisy_frame, reprojected_frame)

    # Step 3: Weighted Filtering
    intermediate_denoised = weighted_filter(current_noisy_frame, reprojected_frame, weight_kernels)

    # Step 4: Failure Handling
    # If rapid motion, illumination change, or high transparency detected,
    # copy current frame to replace historical frame value.
    # [G] Implementation: Check temporal correlation or transparency threshold.
    # For this pseudocode, we assume the kernel prediction or a guard handles it.
    # If failure: intermediate_denoised = current_noisy_frame

    # Step 5: Background Fusion
    final_denoised = Image(current_noisy_frame.width, current_noisy_frame.height, current_noisy_frame.channels)
    for y in range(current_noisy_frame.height):
        for x in range(current_noisy_frame.width):
            a = alpha_map.get(x, y)[0]
            curr = intermediate_denoised.get(x, y)
            bg = background.get(x, y)
            final_val = [a * curr[c] + (1 - a) * bg[c] for c in range(current_noisy_frame.channels)]
            final_denoised.set(x, y, final_val)

    return final_denoised

## Subtopics

### Temporal Gradient Denoising
The parent method that applies denoising to gradient images using temporal reprojection. Spatiotemporal Volume Denoising with Background Fusion extends this by incorporating background fusion and kernel prediction for volume data. [Temporal Gradient Denoising](15080-temporal-gradient-denoising.md)

### Kernel Prediction Denoising
A class of methods that predict filtering kernels rather than direct pixel values. This method uses kernel prediction to produce outputs as weighted combinations of neighboring samples, distinguishing it from direct prediction methods like FDAE. ## Operating characteristics
*   **Time Complexity:** Inference time has an approximately quadratic relationship with input resolution [S1, unofficial].
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** Prediction time is below 30 ms per frame across multiple test sets, comparable to WRLS, achieving real-time performance [S1, unofficial].
*   **Hardware:** Tested on NVIDIA GeForce RTX 4080 Ti GPU (12 GB VRAM) and Intel i7-12700KF CPU (32 GB RAM) [S1, unofficial].
*   **Strengths:** Preserves sharp features and reduces blurring; handles semi-transparent structures well; real-time performance [S1, unofficial].
*   **Limitations:** Struggles with highlighted outliers (e.g., channel values > 200); sensitive to rapid camera motion or illumination changes; historical frames can fail in transparent regions [S1, unofficial].
*   **When to Use:** Real-time volume rendering with semi-transparent structures where edge preservation is critical [S1, unofficial].
*   **When Not to Use:** Scenes with extreme high-intensity outliers or rapid, unpredictable camera/illumination changes [S1, unofficial].

## Background
The method was proposed in a study on real-time volume-rendering image denoising based on kernel prediction [S1, unofficial]. It was developed to address the noise in Monte Carlo volume rendering while preserving the complex translucent structures (smoke, blood vessels, soft tissues) and dynamic shadows typical in volume data [S1, unofficial]. The approach combines temporal coherence (reprojection) with a learned kernel prediction network and a final background fusion step [S1, unofficial]. The training dataset consisted of 65 rendered image sequences from eight different volume data sets, including CT scans, with a resolution of 1024x1024 [S1, unofficial]. The model was trained using PyTorch on an NVIDIA RTX 4080 Ti GPU, converging after 300 epochs [S1, unofficial].
