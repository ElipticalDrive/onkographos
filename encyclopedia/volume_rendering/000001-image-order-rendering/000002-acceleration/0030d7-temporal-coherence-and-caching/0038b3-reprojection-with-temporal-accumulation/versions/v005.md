# Reprojection with Temporal Accumulation

Also called: Temporal Anti-Aliasing (TAA) via reprojection

## Overview
Reprojection with Temporal Accumulation stabilizes voxel rendering over time by blending the current frame's color with an accumulated color buffer from the previous frame, using camera motion vectors to align pixels [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Current frame color buffer (`colour_attachment`), current frame world position buffer (`position_attachment`), previous frame accumulation buffer (`accumulation_attachment`), camera matrices for current and previous frames (`trace_uniforms.current_camera`, `trace_uniforms.last_camera`), and parameters `reprojection_factor` and `indirect_lighting` [S1, unofficial].
*   **Outputs:** Final output color buffer [S1, unofficial].

**Data Structures:**
*   `colour_attachment`: `texture_2d<f32>`, binding 3. Stores current frame RGB color [S1, unofficial].
*   `position_attachment`: `texture_storage_2d<rgba32float, read_write>`, binding 3. Stores world-space positions for each pixel [S1, unofficial].
*   `accumulation_attachment`: `texture_storage_2d<rgba16float, read_write>`, binding 1. Stores the accumulated color from the previous frame [S1, unofficial].

**Steps:**
1.  **Load Current Data:** Read the current frame's color $C_{curr}$ from `colour_attachment` at sample position $(u, v)$. Read the current frame's world position $P_{world}$ from `position_attachment` at $(u, v)$ [S1, unofficial].
2.  **Guard Check:** If `indirect_lighting` is zero OR `reprojection_factor` $\le 0.0$, skip reprojection and return $C_{curr}$ directly [S1, unofficial].
3.  **Compute Local Bounds:** To detect edges and prevent bleeding, compute local color bounds using the current pixel and its 8 neighbors ($sample_0$ to $sample_8$) [S1, unofficial]. Calculate `min_col` as the average of the minimum values in the 'plus' pattern (cross: center, up, down, left, right) and `max_col` as the average of the maximum values in the 'square' pattern (3x3 block) [S1, unofficial]. Let $B_{min}$ and $B_{max}$ be these computed bounds [S1, unofficial].
4.  **Reproject Position:** Transform $P_{world}$ to the previous frame's clip space using `trace_uniforms.last_camera` [S1, unofficial]. $P_{clip} = M_{last} \times P_{world}$ [G]. Convert $P_{clip}$ to Normalized Device Coordinates (NDC): $NDC = P_{clip} / P_{clip.w}$ [G]. Convert NDC to texture coordinates for the accumulation buffer: $T_{proj} = (NDC.xy + 1.0) / 2.0$ [G].
5.  **Validate Projection:** Check if $T_{proj}$ is within the valid NDC range $[-1, 1]$ (or texture coordinates $[0, 1]$) [G]. If the projected position is outside this range (indicating the pixel is newly visible or occluded), treat the history as invalid and skip blending [S1, unofficial].
6.  **Fetch History:** Load the accumulated color $C_{hist}$ from `accumulation_attachment` at $T_{proj}$ [S1, unofficial].
7.  **Blend:** Compute the mixed color $C_{mixed}$ using the `reprojection_factor` (denoted as $\alpha$ or `mix_amount` in sources):
    $$ C_{mixed} = C_{curr} \times (1.0 - \alpha) + C_{hist} \times \alpha $$
    where $\alpha = \text{reprojection\_factor}$ [S1, unofficial].
8.  **Clamp:** Clamp $C_{mixed}$ to the local bounds $[B_{min}, B_{max}]$ to prevent ghosting and color bleeding across edges:
    $$ C_{final} = \text{clamp}(C_{mixed}, B_{min}, B_{max}) $$
9.  **Return:** Output $C_{final}$ [S1, unofficial].

**Accumulation Step:**
After the reprojection pass, a separate accumulation shader stores the current frame's final color into `accumulation_attachment` for use in the next frame [S1, unofficial].

**Pseudocode:**
```python
def reprojection_pass(u, v, colour_attachment, position_attachment, accumulation_attachment, 
                      last_camera_matrix, reprojection_factor, indirect_lighting):
    # 1. Load current data
    C_curr = colour_attachment.sample(u, v)
    P_world = position_attachment.sample(u, v)
    
    # 2. Guard check
    if indirect_lighting == 0 or reprojection_factor <= 0.0:
        return C_curr
    
    # 3. Compute local bounds (min/max) using current pixel and 8 neighbors
    # 'Plus' pattern offsets: center, up, down, left, right
    plus_offsets = [(0, 0), (-1, 0), (1, 0), (0, -1), (0, 1)]
    min_plus = float('inf')
    max_plus = float('-inf')
    for dy, dx in plus_offsets:
        val = colour_attachment.sample(u + dx, v + dy)
        if val < min_plus: min_plus = val
        if val > max_plus: max_plus = val
    
    # 'Square' pattern offsets: 3x3 block
    min_square = float('inf')
    max_square = float('-inf')
    for dy in [-1, 0, 1]:
        for dx in [-1, 0, 1]:
            val = colour_attachment.sample(u + dx, v + dy)
            if val < min_square: min_square = val
            if val > max_square: max_square = val
    
    # Average of plus bounds and square bounds
    B_min = (min_plus + min_square) / 2.0
    B_max = (max_plus + max_square) / 2.0
    
    # 4. Reproject position
    # Transform world position to previous frame's clip space
    P_clip = last_camera_matrix * P_world
    
    # Convert to NDC
    NDC = P_clip.xyz / P_clip.w
    
    # Convert to texture coordinates
    T_proj = (NDC.xy + 1.0) / 2.0
    
    # 5. Validate projection
    if not (0.0 <= T_proj.x <= 1.0 and 0.0 <= T_proj.y <= 1.0):
        return C_curr # Invalid history, use current color
    
    # 6. Fetch history
    C_hist = accumulation_attachment.sample(T_proj.x, T_proj.y)
    
    # 7. Blend
    alpha = reprojection_factor
    C_mixed = C_curr * (1.0 - alpha) + C_hist * alpha
    
    # 8. Clamp to local bounds
    C_final = max(min(C_mixed, B_max), B_min)
    
    return C_final
```

**Parameters:**
*   `reprojection_factor`: Float uniform controlling the blend weight between the current frame and the accumulation buffer. If $\le 0.0$, reprojection is skipped [S1, unofficial].
*   `indirect_lighting`: Unsigned integer uniform. Reprojection is only performed if this is non-zero [S1, unofficial].

## Subtopics

### Alpha-Max Quasi-Depth Motion Vector
A method to compute screen-space motion vectors for direct volume rendering (DVR) by using the 3D position of the point with maximum alpha along the ray as a proxy for depth, enabling temporal reprojection despite the lack of a single surface depth value [S2]. Unlike standard reprojection which relies on a Z-buffer or explicit depth attachment, this variant identifies the point $p$ in world space where the alpha value is maximum along the ray passing through the volume [S2]. It then reprojects this world space position $p$ back to the previous frame's coordinate system using previous camera transformation matrices to obtain coordinates $(u', v')$ [S2]. The screen-space motion vector is calculated as the difference between the current coordinates $(u, v)$ and the reprojected coordinates $(u', v')$ [S2]. This heuristic is chosen because the point of maximum alpha has the maximum contribution to the final accumulated sample, providing an acceptable approximation for motion estimation in volumetric data [S2].

### Frame Averaging at Rest
A post-processing technique where, when the camera stops, consecutive frames are averaged with tiny sub-pixel offsets so the image settles into a clean still [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(1)$ per pixel for the reprojection pass, as it involves a constant number of texture lookups and arithmetic operations [G]. The accumulation pass is also $O(1)$ per pixel [G].
*   **Memory Complexity:** Requires storage for the current color buffer, position buffer, and accumulation buffer [S1, unofficial]. The accumulation buffer typically uses `rgba16float` to balance precision and memory usage [S1, unofficial].
*   **Performance:** Reduces per-pixel noise and flickering, allowing for lower sample counts or faster rendering times by leveraging temporal coherence [S1, unofficial][S2].
*   **Strengths:** Effective at stabilizing images over time, reducing high-frequency noise, and mitigating aliasing artifacts caused by camera motion [S1, unofficial][S2].
*   **Limitations:** Prone to ghosting artifacts if disocclusion is not handled correctly (e.g., if the projected position is invalid but history is still used) [S2].
*   **When to use:** When rendering dynamic volumes with camera motion where temporal stability is desired and computational budget for per-frame sampling is limited [S1, unofficial][S2].
*   **When not to use:** Not given in the sources.

## Background
Reprojection with Temporal Accumulation is a technique adapted from real-time rasterization (Temporal Anti-Aliasing) for use in voxel and volume rendering [G]. The concept of using temporal coherence to reduce noise in volume rendering has been explored in academic contexts, such as in the context of super-resolution for medical volume visualization, where motion vectors are estimated using alpha-max quasi-depth for reprojection [S2]. Implementation details for voxel reprojection, including attachment layouts and blending uniforms, are documented in open-source voxel engine projects [S1, unofficial].
