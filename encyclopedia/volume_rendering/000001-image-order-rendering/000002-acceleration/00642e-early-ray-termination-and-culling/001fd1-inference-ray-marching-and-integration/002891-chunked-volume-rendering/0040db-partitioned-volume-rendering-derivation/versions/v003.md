# Partitioned Volume Rendering Derivation

Also called: Distributed Volume Rendering Equations

## Overview
Partitioned Volume Rendering Derivation provides the mathematical foundation for distributing volumetric rendering across multiple disjoint spatial segments (partitions) along a ray [S1]. It solves the problem of correctly accumulating color, transmittance, and auxiliary losses (such as distortion) when a ray traverses multiple independent volume tiles, which may be processed by different compute units [S1]. It sets itself apart from standard single-volume ray marching by explicitly decomposing global integrals into sums of local segment integrals weighted by upstream transmittance, enabling parallel prefix-scan accumulation [S1].

## How it works
The method relies on decomposing the continuous volume rendering integral into discrete segments $[t_k, t_{k+1}]$ defined by the boundaries of spatial partitions [S1].

**Inputs and Outputs**
*   **Inputs:** Ray origin $o$, direction $d$, and a set of $N$ partition boundaries $t_1, t_2, \dots, t_{N+1}$ along the ray parameter $t$ [S1]. For each segment $k$, the local density $\sigma(t)$ and color $c(t)$ are available [S1].
*   **Outputs:** Global accumulated color $C(t_1 \rightarrow t_{N+1})$, global distortion loss $\mathcal{L}_{dist}(t_1 \rightarrow t_{N+1})$, and intermediate terms required for parallel reduction [S1].

**Data Structures**
The derivation assumes the ray is divided into $N$ segments [S1]. Each segment $k$ corresponds to a spatial tile [S1]. The key intermediate values computed per segment are:
*   $A(t_k \rightarrow t_{k+1})$: Accumulated weight (alpha) within the segment.
*   $D(t_k \rightarrow t_{k+1})$: Accumulated depth-weight within the segment.
*   $T(t_k \rightarrow t_{k+1})$: Transmittance through the segment.

**Formulas**
Let $w(t) = T(t_1 \rightarrow t) \sigma(t)$ be the contribution weight at $t$ [S1]. The standard volume rendering equation for color is:
$$ C(t_1 \rightarrow t_{N+1}) = \int_{t_1}^{t_{N+1}} w(t) c(t) dt $$
This is decomposed into a sum over $N$ segments:
$$ C(t_1 \rightarrow t_{N+1}) = \sum_{k=1}^N T(t_1 \rightarrow t_k) C(t_k \rightarrow t_{k+1}) $$
where the local segment color is:
$$ C(t_k \rightarrow t_{k+1}) = \int_{t_k}^{t_{k+1}} T(t_k \rightarrow t) \sigma(t) c(t) dt $$
Here, $T(t_1 \rightarrow t_k)$ is the transmittance from the ray origin to the start of segment $k$, acting as a weight for the local result [S1].

For distortion loss, we define the accumulated weight $A$ and accumulated depth $D$ over an interval $[t_a, t_b]$ as:
$$ A(t_a \rightarrow t_b) = \int_{t_a}^{t_b} w(t) dt $$
$$ D(t_a \rightarrow t_b) = \int_{t_a}^{t_b} w(t) t dt $$
The global distortion loss is defined as:
$$ \mathcal{L}_{dist}(t_1 \rightarrow t_{N+1}) = 2 \int_{t_1}^{t_{N+1}} w(t) \left( t - \frac{D(t_1 \rightarrow t_{N+1})}{A(t_1 \rightarrow t_{N+1})} \right) A(t_1 \rightarrow t) dt $$
The derivation shows this global loss can be computed from local segment losses using an intermediate term $S$:
$$ S(t_1 \rightarrow t_k) = D(t_k \rightarrow t_{k+1})A(t_1 \rightarrow t_k) - A(t_k \rightarrow t_{k+1})D(t_1 \rightarrow t_k) $$
The final decomposed distortion loss is:
$$ \mathcal{L}_{dist}(t_1 \rightarrow t_{N+1}) = 2 \sum_{k=1}^N T(t_1 \rightarrow t_k) S(t_1 \rightarrow t_k) + \sum_{k=1}^N T(t_1 \rightarrow t_k)^2 \mathcal{L}_{dist}(t_k \rightarrow t_{k+1}) $$
where $\mathcal{L}_{dist}(t_k \rightarrow t_{k+1})$ is the local distortion loss within segment $k$ [S1].

**Parameters**
*   $N$: The number of segments (partitions) along the ray, corresponding to the number of tiles the ray intersects [S1].

**Pseudocode**
The following pseudocode computes the global color and distortion loss from pre-computed local segment statistics [S1]. It assumes `local_A[k]`, `local_D[k]`, `local_C[k]`, and `local_L_dist[k]` are computed independently for each segment $k \in [0, N-1]$ [S1].

```python
def partitioned_rendering(local_segments):
    """
    local_segments: list of N dicts, each containing:
        - 'A': accumulated weight A(t_k -> t_{k+1})
        - 'D': accumulated depth D(t_k -> t_{k+1})
        - 'C': local color C(t_k -> t_{k+1})
        - 'L_dist': local distortion loss L_dist(t_k -> t_{k+1})
        - 'T': transmittance T(t_k -> t_{k+1})
    """
    N = len(local_segments)
    global_color = 0.0
    global_dist_loss = 0.0
    A_prefix = 0.0
    D_prefix = 0.0
    T_prefix = 1.0
    
    for k in range(N):
        seg = local_segments[k]
        A_local = seg['A']
        D_local = seg['D']
        C_local = seg['C']
        L_dist_local = seg['L_dist']
        T_local = seg['T']
        
        # 1. Accumulate Color
        global_color += T_prefix * C_local
        
        # 2. Compute Intermediate Term S
        S = D_local * A_prefix - A_local * D_prefix
        
        # 3. Accumulate Distortion Loss
        term1 = 2.0 * T_prefix * S
        term2 = (T_prefix ** 2) * L_dist_local
        global_dist_loss += term1 + term2
        
        # Update prefix sums for next segment
        A_prefix += A_local
        D_prefix += D_local
        T_prefix *= T_local
        
    return global_color, global_dist_loss
```

## Subtopics

### [Partitioned Volumetric Rendering with RayVolumeIntegral](17112-partitioned-volumetric-rendering-with-rayvolumeintegral.md)
Performs volumetric rendering over a partition of possible $t$ values in the union of rendering volumes, combining results from disjoint volume integrals and a void model for empty space. It sets itself apart from standard single-volume ray marching by explicitly handling multiple disjoint volume bounds and accumulating transmittance across partitions, ensuring correct alpha compositing when rays traverse empty space between volumes.

## Operating characteristics
*   **Time Complexity:** Linear in the number of segments $N$ for the accumulation step, assuming local segment computations are parallelized [S1].
*   **Memory Complexity:** Requires storing intermediate $A, D, C, L_{dist}$ for each segment. The memory footprint scales with $N$ and the number of rays [S1].
*   **Strengths:** Enables efficient distribution of rendering work across multiple GPUs by minimizing communication (only per-ray aggregates need reduction) [S1].
*   **Limitations:** Requires precise spatial partitioning to ensure correct transmittance accumulation across disjoint volume bounds [S1].
*   **When to use:** Large-scale NeRF training/inference where a single GPU cannot hold the volume or process all rays efficiently [S1].

## Background
The derivation originates from **NeRF-XL**, which scales NeRFs with multiple GPUs [S1]. It builds on the spatial partitioning scheme described in Appendix A.3, where space is divided recursively using CDF-based splitting to create nearly cubic partitions [S1]. The method allows distributed NeRFs to compute global integrals from local segment results, facilitating batched asynchronous send/receive operations and parallel prefix scans [S1].
