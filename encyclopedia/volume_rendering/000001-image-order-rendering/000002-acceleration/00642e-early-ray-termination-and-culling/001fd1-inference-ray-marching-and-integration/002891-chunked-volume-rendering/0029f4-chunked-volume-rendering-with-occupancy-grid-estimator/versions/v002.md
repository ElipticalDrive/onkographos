# Chunked Volume Rendering with Occupancy Grid Estimator

Also called: OccGrid Estimator Rendering Loop, OccGridEstimator Rendering

## Overview
This method accelerates volume rendering by combining chunked ray batching with an OccGridEstimator to sample along rays, query a radiance field for density and color at sample midpoints, and composite the result per chunk [S1, unofficial]. It differs from its parent [Chunked Volume Rendering](4310-chunked-volume-rendering.md) by integrating a hierarchical occupancy grid for adaptive sampling, and from its sibling [Block-based Volume Rendering Strategy](13140-block-based-volume-rendering-strategy.md) by using a continuous grid-based estimator rather than discrete block structures [G].

## How it works
**Inputs:**
- Ray origins: Tensor of shape $(H, W, 3)$ or $(N, 3)$ [S1, unofficial].
- View directions: Tensor of shape $(H, W, 3)$ or $(N, 3)$ [S1, unofficial].
- Radiance field: Object with `query_density(positions)` and `query_color(positions)` methods [S1, unofficial][S2, unofficial].
- OccGridEstimator: Object with `sampling(...)` method [S1, unofficial].
- Parameters: `near_plane`, `far_plane`, `render_step_size`, `alpha_thre`, `cone_angle`, `test_chunk_size` [S1, unofficial][S2, unofficial].

**Outputs:**
- RGB image: Shape $(H, W, 3)$ [S1, unofficial].
- Depth image: Shape $(H, W)$ [S1, unofficial].
- Opacity image: Shape $(H, W)$ [S1, unofficial].
- Extras: Additional per-sample data [S1, unofficial].

**Data Structures:**
- `RaySamples`: Contains `vals` (flattened sample data), `ray_indices` (mapping samples to rays), and `packed_info` (chunk boundaries) [S2, unofficial].
- `OccGrid`: Hierarchical grid storing occupancy probabilities, updated via exponential moving average [S1, unofficial].

**Steps:**
1. **Reshape Rays:** If ray origins and directions are 3D tensors of shape $(H, W, 3)$, reshape them to 2D tensors of shape $(N, 3)$ where $N = H \times W$. Store the original shape for final reshaping [S1, unofficial].
2. **Chunking:** Divide the $N$ rays into chunks of size `test_chunk_size`. If in training mode, use `max(int32)` to process all rays at once [S1, unofficial][S2, unofficial].
3. **Define Density Function:** For each chunk, define a function `sigma_fn(t_starts, t_ends, ray_indices)` that calculates sample midpoints: $pos = origins[ray\_indices] + dirs[ray\_indices] \times \frac{t\_starts + t\_ends}{2.0}$, and queries the radiance field for density: $\sigma = radiance\_field.query\_density(pos)$. If temporal scenes are supported, pass timestamps to the query [S1, unofficial].
4. **Sampling:** Call `estimator.sampling(sigma_fn, near_plane, far_plane, render_step_size, stratified, cone_angle, alpha_thre)`. This returns `ray_indices`, `t_starts`, and `t_ends` [S1, unofficial].
5. **Rendering:** Call the rendering composite function with `t_starts`, `t_ends`, `ray_indices`, `n_rays`, and a combined function `rgb_sigma_fn` (which queries both color and density). This returns `rgb`, `opacity`, `depth`, and `extras` for the chunk [S1, unofficial].
6. **Concatenation:** Concatenate results from all chunks along dimension 0 [S1, unofficial].
7. **Reshape:** Reshape the concatenated results back to the original image dimensions $(H, W, 3)$ for RGB, $(H, W)$ for depth/opacity [S1, unofficial].

**Pseudocode:**
```python
import torch

def render_image_with_occgrid_test(
    radiance_field,
    estimator,
    origins,
    viewdirs,
    near_plane=0.0,
    far_plane=1e10,
    render_step_size=1e-3,
    alpha_thre=0.0,
    cone_angle=0.0,
    test_chunk_size=8192,
    is_training=False
):
    # 1. Reshape rays
    if origins.dim() == 3:
        rays_shape = origins.shape[:-1]
        origins = origins.view(-1, 3)
        viewdirs = viewdirs.view(-1, 3)
    else:
        rays_shape = (origins.shape[0],)
        origins = origins.view(-1, 3)
        viewdirs = viewdirs.view(-1, 3)

    n_rays = origins.shape[0]
    
    # 2. Chunking
    chunk_size = 2**31 - 1 if is_training else test_chunk_size

    all_rgb = []
    all_depth = []
    all_opacity = []
    all_extras = []

    for i in range(0, n_rays, chunk_size):
        chunk_end = min(i + chunk_size, n_rays)
        chunk_origins = origins[i:chunk_end]
        chunk_dirs = viewdirs[i:chunk_end]

        # 3. Define sigma_fn for this chunk
        def sigma_fn(t_starts, t_ends, ray_indices):
            midpoints = chunk_origins[ray_indices] + chunk_dirs[ray_indices] * (t_starts + t_ends) / 2.0
            densities = radiance_field.query_density(midpoints)
            return densities

        # 4. Sampling
        ray_indices, t_starts, t_ends = estimator.sampling(
            sigma_fn=sigma_fn,
            near_plane=near_plane,
            far_plane=far_plane,
            render_step_size=render_step_size,
            stratified=True,
            cone_angle=cone_angle,
            alpha_thre=alpha_thre
        )

        # 5. Rendering (explicit front-to-back volume compositing)
        def rgb_sigma_fn(t_starts, t_ends, ray_indices):
            midpoints = chunk_origins[ray_indices] + chunk_dirs[ray_indices] * (t_starts + t_ends) / 2.0
            densities = radiance_field.query_density(midpoints)
            colors = radiance_field.query_color(midpoints)
            return colors, densities

        n_samples = len(t_starts)
        chunk_ray_count = chunk_end - i
        chunk_rgb = torch.zeros(chunk_ray_count, 3, device=origins.device)
        chunk_opacity = torch.zeros(chunk_ray_count, device=origins.device)
        chunk_depth = torch.zeros(chunk_ray_count, device=origins.device)
        
        # Sort samples by t_starts for each ray in the chunk
        sorted_indices = torch.argsort(t_starts)
        t_starts_s = t_starts[sorted_indices]
        t_ends_s = t_ends[sorted_indices]
        ray_idx_s = ray_indices[sorted_indices]
        
        colors_s, densities_s = rgb_sigma_fn(t_starts_s, t_ends_s, ray_idx_s)
        alphas_s = 1.0 - torch.exp(-densities_s * (t_ends_s - t_starts_s))
        transmittance_s = torch.ones(chunk_ray_count, device=origins.device)
        
        for k in range(n_samples):
            r = ray_idx_s[k]
            alpha = alphas_s[k]
            transmittance_s[r] *= (1.0 - alpha)
            chunk_rgb[r] += colors_s[k] * alpha * transmittance_s[r]
            chunk_opacity[r] += alpha * transmittance_s[r]
            chunk_depth[r] += t_starts_s[k] * alpha * transmittance_s[r]
        
        chunk_depth = torch.where(chunk_opacity > 0, chunk_depth / chunk_opacity, chunk_depth)
        
        all_rgb.append(chunk_rgb)
        all_depth.append(chunk_depth)
        all_opacity.append(chunk_opacity)
        all_extras.append({})

    # 6. Concatenation
    final_rgb = torch.cat(all_rgb, dim=0)
    final_depth = torch.cat(all_depth, dim=0)
    final_opacity = torch.cat(all_opacity, dim=0)

    # 7. Reshape
    final_rgb = final_rgb.view(*rays_shape, 3)
    final_depth = final_depth.view(*rays_shape)
    final_opacity = final_opacity.view(*rays_shape)

    return final_rgb, final_depth, final_opacity, all_extras
```

**Parameters:**
- `near_plane`: Float, default 0.0. Minimum distance for ray marching [S1, unofficial][S2, unofficial].
- `far_plane`: Float, default 1e10. Maximum distance for ray marching [S1, unofficial][S2, unofficial].
- `render_step_size`: Float, default 1e-3. Base step size for sampling [S1, unofficial][S2, unofficial].
- `alpha_thre`: Float, default 0.0. Alpha threshold for filtering samples [S1, unofficial][S2, unofficial].
- `cone_angle`: Float, default 0.0. Cone angle for adaptive sampling [S1, unofficial][S2, unofficial].
- `test_chunk_size`: Int, default 8192. Number of rays per chunk during inference [S1, unofficial][S2, unofficial].
