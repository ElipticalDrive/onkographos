# Training Ray Marching (Forward Only)

Also called: Ray Marching with Sparse Voxel Grid (Training), two-pass ray marching

## Overview
A two-pass GPU algorithm that samples a ray through a sparse voxel grid (density bitfield) to collect 3D positions, directions, step sizes (deltas), and t-values for training neural radiance fields [S1, unofficial]. It sets itself apart from its siblings by explicitly decoupling the counting of occupied samples from the data writing phase to enable dynamic memory allocation based on estimated density, optimizing training throughput by avoiding over-allocation [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** `rays_o` (N_rays, 3), `rays_d` (N_rays, 3), `hits_t` (N_rays, 2), `density_bitfield` (uint8_t*), `noise` (N_rays, 1). Parameters: `cascades` (int), `scale` (float), `exp_step_factor` (float), `grid_size` (int), `max_samples` (int), `bound` (float), `density_grid` (float array [H, H, H]), `mean_density` (float), `iter_density` (float), `step_counter` (int array [2], optional), `mean_count` (int), `perturb` (bool), `force_all_rays` (bool) [S1, unofficial][S2, unofficial].
*   **Outputs:** `rays_a` (N_rays, 3, int64_t) storing [ray_idx, start_idx, N_samples]; `xyzs` (N_rays*max_samples, 3); `dirs` (N_rays*max_samples, 3); `deltas` (N_rays*max_samples); `ts` (N_rays*max_samples); `counter` (2, int32_t) [S1, unofficial].

**Data Structures:**
*   `rays`: int array [N, 3], stores ray metadata: column 0 is ray ID, column 1 is offset into the xyzs/dirs/deltas arrays, column 2 is number of steps for that ray [S2, unofficial].
*   `density_bitfield`: A bit-packed array where each byte represents the occupancy of 8 voxels. Occupancy is checked via `density_bitfield[idx/8] & (1<<(idx%8))` [S1, unofficial].

**Parameters:**
*   `threads`: 256 threads per block [S1, unofficial].
*   `blocks`: `(N_rays+threads-1)/threads` blocks [S1, unofficial].
*   `M` (Max points): Default `N * 1024`. If `mean_count > 0` and `force_all_rays` is false, `M` is set to `mean_count` [S2, unofficial]. If `align > 0`, `M` is padded to the next multiple of `align` [S2, unofficial].

**Algorithm Steps:**

1.  **Initialization:** Reshape `rays_o` and `rays_d` to contiguous views of shape `[-1, 3]`. Get `N` (num rays) from `rays_o.shape[0]` and `H` (grid resolution) from `density_grid.shape[0]` [S2, unofficial]. Initialize `t = t1` (start t), `N_samples = 0` [S1, unofficial]. Initialize `rays` tensor of shape `[N, 3]` with dtype int32 [S2, unofficial]. If `step_counter` is None, initialize it as a zero tensor of shape `[2]` with dtype int32 [S2, unofficial].

2.  **First Pass (Counting):** Loop condition: `while (0<=t && t<t2 && N_samples<max_samples)` [S1, unofficial].
    *   **Position:** Calculate current 3D position: `x = ox+t*dx`, `y = oy+t*dy`, `z = oz+t*dz` [S1, unofficial].
    *   **Step Size:** Calculate step size `dt` using helper: `dt = calc_dt(t, exp_step_factor, max_samples, grid_size, scale)` [S1, unofficial].
    *   **MIP Level:** Determine MIP level `mip` as the maximum of position-based and dt-based selection: `mip = max(mip_from_pos(x, y, z, cascades), mip_from_dt(dt, grid_size, cascades))` [S1, unofficial].
    *   **MIP Bound:** Calculate MIP bound and its inverse: `mip_bound = fminf(scalbnf(1.0f, mip-1), scale)` and `mip_bound_inv = 1/mip_bound` [S1, unofficial].
    *   **Grid Coordinates:** Map position to grid coordinates `nx, ny, nz` by rounding down to nearest grid position: `nx = clamp(0.5f*(x*mip_bound_inv+1)*grid_size, 0.0f, grid_size-1.0f)` (similarly for y, z) [S1, unofficial].
    *   **Occupancy Check:** Compute linear index in the bitfield using Morton code: `idx = mip*grid_size3 + __morton3D(nx, ny, nz)` where `grid_size3 = grid_size*grid_size*grid_size` [S1, unofficial]. Check occupancy: `occ = density_bitfield[idx/8] & (1<<(idx%8))` [S1, unofficial].
    *   **Advance Ray:**
        *   If occupied (`occ` is true): increment `t` by `dt` (`t += dt`) and increment sample count (`N_samples++`) [S1, unofficial].
        *   If not occupied: calculate target t to skip to next voxel boundary. Compute `tx, ty, tz` as distances to the next voxel face in each axis: `tx = (((nx+0.5f+0.5f*signf(dx))*grid_size_inv*2-1)*mip_bound-x)*dx_inv` (similarly for ty, tz). Set `t_target = t + fmaxf(0.0f, fminf(tx, fminf(ty, tz)))`. Advance `t` in a do-while loop: `do { t += calc_dt(...) } while (t < t_target);` [S1, unofficial].

3.  **Memory Allocation:** After the first pass, allocate output indices using atomic operations on a shared counter: `start_idx = atomicAdd(counter, N_samples)` and `ray_count = atomicAdd(counter+1, 1)` [S1, unofficial]. Store ray metadata: `rays_a[ray_count][0] = r`, `rays_a[ray_count][1] = start_idx`, `rays_a[ray_count][2] = N_samples` [S1, unofficial].

4.  **Second Pass (Writing):** Reset `t = t1`, `samples = 0`. Loop condition: `while (t<t2 && samples<N_samples)` [S1, unofficial].
    *   Repeat steps 2a-2d (Position, Step Size, MIP, Grid Coords, Occupancy) to re-traverse the ray [S1, unofficial].
    *   If occupied: write sample data to global arrays at index `s = start_idx + samples`. `xyzs[s] = {x,y,z}`, `dirs[s] = {dx,dy,dz}`, `ts[s] = t`, `deltas[s] = dt`. Increment `t` by `dt` and `samples` [S1, unofficial].

5.  **Post-Processing:** If `force_all_rays` or `mean_count <= 0`, retrieve the actual number of points `m` from `step_counter[0].item()` and pad `m` to the next multiple of `align` if `align > 0` [S2, unofficial]. Slice `xyzs`, `dirs`, and `deltas` to size `m` if the condition in the previous step was met [S2, unofficial].

## Subtopics

### [NeuralPointsRayMarching](6818-neuralpointsraymarching.md)
NeuralPointsRayMarching is a PyTorch module that performs ray marching for neural point rendering by aggregating sampled neural point features and blending them along rays. It estimates the maximum number of points to allocate based on mean count from previous epochs, enabling faster training by avoiding over-allocation, while supporting force-all-rays mode for stability. It sets itself apart from standard volume rendering by operating on discrete, learned point entities rather than continuous volumetric fields.

## Operating characteristics
*   **Time Complexity:** Two passes over the ray space. The first pass counts occupied samples, the second writes data. Complexity is proportional to the number of rays and the average number of steps per ray [S1, unofficial].
*   **Memory Complexity:** Allocates `M * (3 + 3 + 1 + 1)` floats for `xyzs`, `dirs`, `deltas`, `ts`, plus `N * 3` int64s for `rays_a`. `M` is estimated to avoid over-allocation [S1, unofficial][S2, unofficial].
*   **Measured Performance:** Optimizes training throughput by avoiding over-allocation of memory for samples [S2, unofficial].
*   **Scaling:** Scales with the number of rays `N` and the grid resolution `H` (via density grid lookup) [S1, unofficial][S2, unofficial].
*   **Strengths:** Dynamic memory allocation based on density estimation reduces memory waste. Two-pass approach ensures exact sample counts before allocation [S1, unofficial][S2, unofficial].
*   **Limitations:** If `mean_count` underestimates the required points, rays may be randomly ignored unless `force_all_rays` is enabled [S2, unofficial]. Requires CUDA backend for efficient execution [S2, unofficial].

## Background
Originated in the context of training neural radiance fields with sparse voxel grids, specifically within the NVIDIA Instant Neural Graphics Primitives (NGP) framework [S1, unofficial]. It is used to efficiently sample rays for training, balancing memory usage and computational cost [S1, unofficial][S2, unofficial].
