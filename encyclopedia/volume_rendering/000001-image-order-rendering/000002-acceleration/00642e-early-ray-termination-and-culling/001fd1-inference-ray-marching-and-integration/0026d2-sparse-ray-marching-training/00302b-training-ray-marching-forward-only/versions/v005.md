# Training Ray Marching (Forward Only)

Also called: Ray Marching with Sparse Voxel Grid (Training), two-pass ray marching

## Overview
A two-pass GPU algorithm that samples a ray through a sparse voxel grid (density bitfield) to collect 3D positions, directions, step sizes (deltas), and t-values for training neural radiance fields [S1, unofficial]. It sets itself apart from its siblings by explicitly decoupling the counting of occupied samples from the writing of sample data, allowing for dynamic memory allocation based on actual occupancy rather than fixed worst-case bounds, while supporting an optimization where the maximum allocation size is estimated from previous training epochs [S1, unofficial][S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   `rays_o`: Origin positions, shape `[N_rays, 3]` [S1, unofficial].
    *   `rays_d`: Direction vectors, shape `[N_rays, 3]` [S1, unofficial].
    *   `hits_t`: Hit intervals, shape `[N_rays, 2]` [S1, unofficial].
    *   `density_bitfield`: Sparse voxel occupancy bitfield, `uint8_t*` [S1, unofficial].
    *   `noise`: Perturbation noise, shape `[N_rays, 1]` [S1, unofficial].
    *   `cascades`: Number of MIP cascades, `int` [S1, unofficial].
    *   `scale`: Spatial boundary scale, `float` [S1, unofficial].
    *   `exp_step_factor`: Exponential step factor, `float` [S1, unofficial].
    *   `grid_size`: Density grid resolution, `int` [S1, unofficial].
    *   `max_samples`: Hard limit on samples per ray, `int` [S1, unofficial].
    *   `mean_count`: Estimated max points from previous epoch, `int` [S2, unofficial].
    *   `force_all_rays`: Boolean flag to ignore `mean_count` and process all rays, `bool` [S2, unofficial].
    *   `perturb`: Boolean flag to enable perturbation, `bool` [S2, unofficial].
    *   `align`: Alignment padding value, `int` [S2, unofficial].
*   **Outputs:**
    *   `rays_a`: Ray metadata, shape `[N_rays, 3]`, dtype `int64_t`. Columns: `[ray_idx, start_idx, N_samples]` [S1, unofficial].
    *   `xyzs`: Sample positions, shape `[M, 3]` [S1, unofficial].
    *   `dirs`: Sample directions, shape `[M, 3]` [S1, unofficial].
    *   `deltas`: Step sizes, shape `[M]` [S1, unofficial].
    *   `ts`: T-values, shape `[M]` [S1, unofficial].
    *   `counter`: Atomic counter, shape `[2]`, dtype `int32_t` [S1, unofficial].

**Data Structures:**
*   `rays`: Internal int array `[N, 3]` storing ray metadata: column 0 is ray ID, column 1 is offset into the `xyzs`/`dirs`/`deltas` arrays, column 2 is number of steps for that ray [S2, unofficial].
*   `density_bitfield`: Bit-packed occupancy grid. Index `idx` corresponds to voxel `(nx, ny, nz)` via Morton code [S1, unofficial].

**Parameters:**
*   `threads`: 256 threads per block [S1, unofficial].
*   `blocks`: `(N_rays + threads - 1) / threads` blocks [S1, unofficial].
*   `bound`: Spatial boundary, default `1e-4` [S2, unofficial].
*   `density_grid`: Float array `[H, H, H]` [S2, unofficial].
*   `mean_density`: Mean density value [S2, unofficial].
*   `iter_density`: Density value for current iteration [S2, unofficial].
*   `step_counter`: Optional int array `[2]`, defaults to zeros if `None` [S2, unofficial].

**Algorithm Steps:**

1.  **Reshape Inputs:** Reshape `rays_o` and `rays_d` to contiguous views of shape `[-1, 3]` [S2, unofficial].
2.  **Initialize Loop Variables:** For each ray, set `t = t1` (start t from `hits_t`), `N_samples = 0` [S1, unofficial].
3.  **Calculate Position:** Compute current 3D position: `x = ox + t*dx`, `y = oy + t*dy`, `z = oz + t*dz` [S1, unofficial].
4.  **Calculate Step Size:** Compute `dt` using helper function: `dt = calc_dt(t, exp_step_factor, max_samples, grid_size, scale)` [S1, unofficial].
5.  **Determine MIP Level:** Calculate MIP level `mip` as the maximum of position-based and dt-based selection: `mip = max(mip_from_pos(x, y, z, cascades), mip_from_dt(dt, grid_size, cascades))` [S1, unofficial].
6.  **Calculate MIP Bound:** Compute MIP bound and its inverse: `mip_bound = fminf(scalbnf(1.0f, mip-1), scale)` and `mip_bound_inv = 1.0f / mip_bound` [S1, unofficial].
7.  **Map to Grid Coordinates:** Map position to grid coordinates `nx, ny, nz` by rounding down to nearest grid position:
    `nx = clamp(0.5f * (x * mip_bound_inv + 1.0f) * grid_size, 0.0f, grid_size - 1.0f)` (similarly for `y`, `z`) [S1, unofficial].
8.  **Compute Morton Index:** Compute linear index in the bitfield: `idx = mip * grid_size^3 + __morton3D(nx, ny, nz)` where `grid_size^3 = grid_size * grid_size * grid_size` [S1, unofficial].
9.  **Check Occupancy:** Check occupancy: `occ = density_bitfield[idx / 8] & (1 << (idx % 8))` [S1, unofficial].
10. **Advance Ray:**
    *   If occupied (`occ` is true): Increment `t` by `dt` (`t += dt`) and increment sample count (`N_samples++`) [S1, unofficial].
    *   If not occupied: Calculate target t to skip to next voxel boundary. Compute `tx, ty, tz` as distances to the next voxel face in each axis:
        `tx = (((nx + 0.5f + 0.5f * signf(dx)) * grid_size_inv * 2 - 1) * mip_bound - x) * dx_inv` (similarly for `ty`, `tz`).
        Set `t_target = t + fmaxf(0.0f, fminf(tx, fminf(ty, tz)))`.
        Advance `t` in a do-while loop: `do { t += calc_dt(...) } while (t < t_target);` [S1, unofficial].
11. **Loop Condition:** Continue while `0 <= t && t < t2 && N_samples < max_samples` [S1, unofficial].
12. **First Pass Allocation:** After the first pass, allocate output indices using atomic operations on a shared counter:
    `start_idx = atomicAdd(counter, N_samples)` and `ray_count = atomicAdd(counter + 1, 1)` [S1, unofficial].
13. **Store Ray Metadata:** Store ray metadata: `rays_a[ray_count][0] = r`, `rays_a[ray_count][1] = start_idx`, `rays_a[ray_count][2] = N_samples` [S1, unofficial].
14. **Second Pass Initialization:** Reset `t = t1`, `samples = 0` [S1, unofficial].
15. **Second Pass Loop:** Loop condition: `while (t < t2 && samples < N_samples)` [S1, unofficial].
16. **Second Pass Traversal:** Repeat steps 3-11 to re-traverse the ray [S1, unofficial].
17. **Write Sample Data:** If occupied: write sample data to global arrays at index `s = start_idx + samples`:
    `xyzs[s] = {x, y, z}`, `dirs[s] = {dx, dy, dz}`, `ts[s] = t`, `deltas[s] = dt`. Increment `t` by `dt` and `samples` [S1, unofficial].
18. **Memory Allocation Optimization:**
    *   Initialize `M` (max points) to `N * 1024` as a hardcoded default [S2, unofficial].
    *   If not `force_all_rays` and `mean_count > 0`, use `mean_count` as `M` [S2, unofficial].
    *   If `align > 0`, pad `M` to the next multiple of `align` [S2, unofficial].
    *   Initialize output tensors `xyzs`, `dirs`, `deltas` with zeros of shape `[M, 3]`, `[M, 3]`, `[M]` respectively [S2, unofficial].
    *   Initialize `rays` tensor of shape `[N, 3]` with dtype `int32` [S2, unofficial].
    *   If `step_counter` is `None`, initialize it as a zero tensor of shape `[2]` with dtype `int32` [S2, unofficial].
    *   If `force_all_rays` or `mean_count <= 0`, retrieve the actual number of points `m` from `step_counter[0].item()` and pad `m` to the next multiple of `align` if `align > 0` [S2, unofficial].
    *   Slice `xyzs`, `dirs`, and `deltas` to size `m` if the condition in the previous step was met [S2, unofficial].

## Subtopics

### [NeuralPointsRayMarching](6818-neuralpointsraymarching.md)
NeuralPointsRayMarching is a PyTorch module that performs ray marching for neural point rendering by aggregating sampled neural point features and blending them along rays. It estimates the maximum number of points to allocate based on mean count from previous epochs, enabling faster training by avoiding over-allocation, while supporting force-all-rays mode for stability. It sets itself apart from standard volume rendering by operating on discrete, learned point entities rather than continuous volumetric fields.

## Operating characteristics
*   **Time Complexity:** Two passes over the ray space. The first pass counts occupied samples, the second pass writes them. Complexity is proportional to the number of rays and the average number of occupied samples per ray.
*   **Memory Complexity:** Memory allocation is dynamic based on `mean_count` or `max_samples`. The `xyzs`, `dirs`, `deltas`, and `ts` tensors are allocated up to size `M`.
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Scales with the number of rays `N_rays` and the density of the voxel grid.
*   **Strengths:** Avoids over-allocation by using `mean_count` from previous epochs. Supports `force_all_rays` for stability.
*   **Limitations:** If `mean_count` underestimates the required points, rays may be randomly ignored unless `force_all_rays` is enabled [S2, unofficial].
*   **When to use:** Training neural radiance fields with sparse voxel grids where memory efficiency is critical.
*   **When not to use:** Inference where fixed allocation is preferred for simplicity, or when `mean_count` is not available.

## Background
Originating from the NVIDIA Instant Neural Graphics Primitives (NGP) framework, this method was adapted for PyTorch Lightning training pipelines [S1, unofficial]. It is used in training neural radiance fields to efficiently sample sparse voxel grids [S1, unofficial].
