# Sparse Grid Volume Rendering (Foreground)

Also called: Plenoxel Ray Tracing (Forward)

## Overview
Sparse Grid Volume Rendering (Foreground) is a CUDA kernel that performs image-order volume rendering through a sparse 3D voxel grid using trilinear interpolation and spherical harmonics (SH) coefficients [S1, unofficial]. It solves the problem of efficiently rendering high-frequency radiance fields by skipping transparent regions and accumulating color and opacity along rays [S1, unofficial]. It is distinguished from its siblings by its specific implementation in the NeRF-Factory/Plenoxels ecosystem, utilizing warp-level reductions for SH evaluation and specific sparsity-aware early termination [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Ray origin, direction, and current step size $t$; Sparse grid data structures (`grid.density_data`, `grid.sh_data`, `grid.links`, `grid.stride_x`, `grid.size`, `grid.basis_dim`); Optimization options (`opt.step_size`, `opt.sigma_thresh`, `opt.stop_thresh`, `opt.last_sample_opaque`, `opt.background_brightness`, `grid.background_nlayers`).
*   **Output:** Accumulated color `outv`, log-transmittance `log_transmit` (optional).

**Data Structures:**
*   `grid.density_data`: 1D array of density ($\sigma$) values.
*   `grid.sh_data`: 1D array of SH coefficients.
*   `grid.links`: Sparse voxel linking structure (format not fully specified in sources, assumed compatible with `trilerp_cuvol_one`) [S1, unofficial].
*   `grid.size`: Array of 3 integers defining grid dimensions $[N_x, N_y, N_z]$ [S1, unofficial].
*   `grid.stride_x`: Stride for density data access [S1, unofficial].
*   `grid.basis_dim`: Number of SH basis functions per color channel [S1, unofficial].

**Pseudocode:**
The following pseudocode implements the forward pass. It assumes a warp-level parallelism where `lane_id` is the thread index within a warp (0-31) and `lane_colorgrp_id` groups threads for SH evaluation.

```python
def render_ray_kernel_forward(ray_origin, ray_dir, t, grid, opt, outv, out_log_transmit=None):
    # Initialize accumulators
    log_transmit = 0.0
    accum_color = 0.0
    
    # Warp-level variables for SH reduction
    lane_color = 0.0
    lane_colorgrp_id = lane_id % grid.basis_dim # Assuming basis_dim <= warp size or grouped appropriately
    lane_id_in_group = lane_id // grid.basis_dim # Not explicitly defined, but implied by reduction mask
    
    # Ray marching loop
    while t < ray.tmax:
        # 1. Compute ray position
        # pos = origin + t * dir
        pos_x = fmaf(t, ray_dir[0], ray_origin[0])
        pos_y = fmaf(t, ray_dir[1], ray_origin[1])
        pos_z = fmaf(t, ray_dir[2], ray_origin[2])
        
        # Clamp position to grid bounds [0, size[j]-1]
        pos_x = clamp(pos_x, 0.0, float(grid.size[0] - 1))
        pos_y = clamp(pos_y, 0.0, float(grid.size[1] - 1))
        pos_z = clamp(pos_z, 0.0, float(grid.size[2] - 1))
        
        # Compute integer lattice index
        l_x = min(int(pos_x), grid.size[0] - 2)
        l_y = min(int(pos_y), grid.size[1] - 2)
        l_z = min(int(pos_z), grid.size[2] - 2)
        
        # Compute fractional position
        frac_x = pos_x - l_x
        frac_y = pos_y - l_y
        frac_z = pos_z - l_z
        
        # 2. Sample density sigma
        # Use trilerp_cuvol_one for sparse trilinear interpolation
        sigma = trilerp_cuvol_one(
            grid.links, 
            grid.density_data, 
            grid.stride_x, 
            grid.size[2], 
            1, 
            [l_x, l_y, l_z], 
            [frac_x, frac_y, frac_z], 
            0
        )
        
        # 3. Handle last sample opacity
        if opt.last_sample_opaque and (t + opt.step_size > ray.tmax):
            ray.world_step = 1e9
        else:
            ray.world_step = opt.step_size
            
        # 4. Sample SH color if density is significant
        if sigma > opt.sigma_thresh:
            # Interpolate SH coefficients
            sh_coeffs = trilerp_cuvol_one(
                grid.links, 
                grid.sh_data, 
                grid.stride_x, 
                grid.size[2], 
                grid.basis_dim, 
                [l_x, l_y, l_z], 
                [frac_x, frac_y, frac_z], 
                lane_id # Or lane_id_in_group depending on implementation detail
            )
            
            # Evaluate SH basis function for current direction
            # sphfunc_val depends on ray_dir and lane_colorgrp_id
            sph_val = evaluate_spherical_harmonics(ray_dir, lane_colorgrp_id)
            
            # Compute weighted color contribution for this lane
            lane_color = sh_coeffs * sph_val
        else:
            lane_color = 0.0
            
        # 5. Warp-level reduction for SH color
        # Sum lane_color across the warp group where lane_colorgrp_id == 0
        # Note: The source specifies reduction with mask lane_colorgrp_id == 0.
        # This implies a segmented sum or specific warp shuffle pattern.
        lane_color_total = warp_reduce_head_segmented_sum(lane_color, mask=(lane_colorgrp_id == 0))
        
        # 6. Calculate weight and update transmittance
        # pcnt = ray.world_step * sigma
        pcnt = ray.world_step * sigma
        weight = exp(log_transmit) * (1.0 - exp(-pcnt))
        log_transmit -= pcnt
        
        # 7. Accumulate color
        # Clamp SH sum to non-negative: max(lane_color_total + 0.5f, 0.f)
        # Note: The source adds 0.5f before clamping. This is a specific Plenoxels detail.
        color_contrib = max(lane_color_total + 0.5, 0.0)
        accum_color += weight * color_contrib
        
        # 8. Early termination
        if exp(log_transmit) < opt.stop_thresh:
            log_transmit = -1e3f
            break
            
        # 9. Advance ray
        t += opt.step_size
        
    # 10. Background contribution
    if grid.background_nlayers == 0:
        accum_color += exp(log_transmit) * opt.background_brightness
        
    # 11. Write output
    if lane_colorgrp_id == 0:
        outv = accum_color
        if out_log_transmit is not None:
            out_log_transmit = log_transmit
```

**Formulas:**
*   **Ray Position:** $\mathbf{p} = \mathbf{o} + t \mathbf{d}$ [S1, unofficial].
*   **Weight:** $w = e^{T} (1 - e^{-\sigma \Delta t})$, where $T$ is log-transmittance, $\sigma$ is density, $\Delta t$ is step size [S1, unofficial].
*   **Transmittance Update:** $T_{new} = T_{old} - \sigma \Delta t$ [S1, unofficial].
*   **Color Accumulation:** $C = \sum w \cdot \max(\text{SH}_{\text{sum}} + 0.5, 0)$ [S1, unofficial].
*   **Gradient for Sigma (Backward):** $\frac{\partial L}{\partial \sigma} = \Delta t \left( C_{\text{total}} e^{T} - C_{\text{accum}} \right)$ [S1, unofficial].

**Parameters:**
*   `opt.step_size`: Fixed step size for ray marching [S1, unofficial].
*   `opt.sigma_thresh`: Density threshold for skipping samples [S1, unofficial].
*   `opt.stop_thresh`: Transmission threshold for early termination [S1, unofficial].
*   `opt.last_sample_opaque`: Boolean flag to force the last sample to be opaque [S1, unofficial].
*   `grid.basis_dim`: Number of SH basis functions per color channel [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** Use `fmaf` for fused multiply-add to maintain precision in ray position calculation [S1, unofficial].
*   **Boundaries:** Clamp ray positions to grid bounds to prevent out-of-bounds memory access [S1, unofficial].
*   **SH Clamping:** The addition of 0.5 before clamping to 0 is a specific heuristic to handle negative SH coefficients [S1, unofficial].
*   **Warp Reduction:** The reduction mask `lane_colorgrp_id == 0` implies a specific warp grouping strategy that must be implemented correctly to avoid data races or incorrect sums [S1, unofficial].

## Subtopics

### Sparse Packed Radiance Field Tracer
Uses a different sparse data structure (packed) compared to the linked-list based approach implied by `grid.links` in this method. Choose when memory locality is prioritized over the specific sparsity patterns handled by Plenoxels. [Link](13126-sparse-packed-radiance-field-tracer.md)

### CUDA Ray Marching (IDDR-NGP Backend)
Uses the Instant Neural Graphics Primitives (NGP) hash grid backend instead of sparse voxels. Choose when higher resolution is needed at the cost of increased memory usage. [Link](5788-cuda-ray-marching-iddr-ngp-backend.md)

A simplified version that only performs the forward pass without the full backward pass logic for gradients. Choose for inference-only scenarios. [Link](6205-training-ray-marching-forward-only.md)

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of steps along the ray, but effectively sub-linear due to early termination and sparse sampling [S1, unofficial].
*   **Memory Complexity:** Linear with respect to the number of non-empty voxels in the sparse grid [S1, unofficial].
*   **Performance:** Optimized for CUDA with warp-level reductions, making it efficient on NVIDIA GPUs [S1, unofficial].
*   **Strengths:** High efficiency for sparse scenes; early termination reduces computation for transparent regions; SH representation allows compact storage of directional information [S1, unofficial].
*   **Limitations:** Requires careful tuning of `sigma_thresh` and `stop_thresh`; trilinear interpolation on sparse grids can be complex to implement efficiently [S1, unofficial].
*   **When to use:** Rendering large-scale scenes with significant empty space where dense voxel grids would be wasteful [S1, unofficial].
*   **When not to use:** Scenes with high-frequency details that require very small step sizes or dense sampling, where hash-based methods might be more efficient [S1, unofficial].

## Background
Sparse Grid Volume Rendering (Foreground) is part of the Plenoxels method, originally developed by Alex Yu et al. [S1, unofficial]. It was integrated into the NeRF-Factory project by POSTECH, KAIST, and Kakao Brain Corp. [S1, unofficial]. The method adapts the sparse voxel representation from Plenoxels to work with spherical harmonics for color representation, enabling efficient rendering of novel views from sparse training data [S1, unofficial].
