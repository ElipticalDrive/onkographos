# Sparse Grid Volume Rendering (Foreground)

Also called: Fused Sparse Voxel Volume Rendering (CuVol), JNeRF volume rendering, Plenoxel Ray Tracing (Forward)

## Overview
Sparse Grid Volume Rendering (Foreground) is a CUDA-based volume rendering method that traces rays through a sparse voxel grid to compute final color and log-transmittance using volume rendering with spherical harmonics (SH) coefficients [S1, unofficial]. It differs from its siblings by explicitly managing warp-level parallelism for SH basis evaluation and accumulation, utilizing shared memory for warp-local data to minimize global memory traffic, and employing early termination based on transmission thresholds [S3, unofficial]. Unlike [CUDA Ray Marching (IDDR-NGP Backend)](5788-cuda-ray-marching-iddr-ngp-backend.md) which uses hash encoding, or [Sparse Packed Radiance Field Tracer](13126-sparse-packed-radiance-field-tracer.md) which may use different interpolation schemes, this method relies on trilinear interpolation over a sparse connectivity structure [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
- `rays`: Array of ray origins and directions.
- `grid`: A `PackedSparseGridSpec` structure containing sparse voxel data.
- `opt`: `RenderOptions` structure controlling marching parameters.
- `outv`: Output buffer for rendered colors.
- `out_log_transmit`: Optional output buffer for log-transmittance.

**Outputs:**
- `outv`: Rendered color per ray.
- `out_log_transmit`: Log-transmittance per ray (if provided).

### Data Structures
**PackedSparseGridSpec:**
- `links`: Sparse connectivity structure for voxel lookup.
- `stride_x`: Stride for density data lookup.
- `size[3]`: Grid dimensions (width, height, depth).
- `density_data`: Density values ($\sigma$) stored in a sparse format.
- `sh_data`: Spherical Harmonics coefficients for color.
- `sh_data_dim`: Number of SH bands/dimensions (typically 9 for 3rd order).
- `basis_dim`: Number of SH basis functions per color channel.
- `background_nlayers`: Number of background layers (0 implies simple background).
- `background_brightness`: Scalar background color value.

**SingleRaySpec:**
- `origin[3]`: Ray origin coordinates.
- `dir[3]`: Ray direction vector.
- `tmin`: Near bound of the ray segment within the grid.
- `tmax`: Far bound of the ray segment within the grid.
- `pos[3]`: Current ray position.
- `l[3]`: Integer voxel coordinates.
- `world_step`: Step size in world units.

**RenderOptions:**
- `step_size`: Fixed step size for ray marching.
- `sigma_thresh`: Density threshold below which samples are skipped.
- `stop_thresh`: Transmission threshold below which ray marching terminates early.
- `last_sample_opaque`: Boolean flag; if true, sets `world_step` to $10^9$ for the last sample.
- `background_brightness`: Scalar background color.
- `randomize`: Boolean flag for randomization (not used in forward pass logic described).
- `random_sigma_std`: Float for randomization (not used in forward pass logic described).

### Algorithm Steps
The kernel launches with `TRACE_RAY_CUDA_THREADS = 128` threads per block, processing `TRACE_RAY_CUDA_RAYS_PER_BLOCK = 4` rays per block (since `WARP_SIZE = 32`) [S3, unofficial].

1. **Initialization:**
   - Compute thread ID `tid = blockIdx.x * blockDim.x + threadIdx.x` [G].
   - Compute `ray_id = tid // 32` (integer division by 32) [G].
   - Compute `lane_id = threadIdx.x % 32` (modulo 32) [G].
   - If `lane_id >= grid.sh_data_dim`, return early [S3, unofficial].
   - Copy `rays.origins[ray_id]` and `rays.dirs[ray_id]` into shared memory `ray_spec[ray_blk_id]` where `ray_blk_id = tid // 32` [S3, unofficial].
   - Compute ray bounds `tmin` and `tmax` for the ray intersecting the grid [G].
   - If `tmin > tmax`, the ray is outside the grid. Output `background_brightness` if `grid.background_nlayers == 0`, else 0. Set `log_transmit` to 0 if `out_log_transmit` is not null [S2, unofficial].

2. **Shared Memory Allocation:**
   - `__shared__ float sphfunc_val[4][9]` for SH basis values [S3, unofficial].
   - `__shared__ SingleRaySpec ray_spec[4]` for ray data [S3, unofficial].
   - `__shared__ WarpReducef::TempStorage temp_storage[4]` for warp reductions [S3, unofficial].

3. **Spherical Harmonics Evaluation:**
   - Compute SH basis values for the ray direction `ray_spec[ray_blk_id].dir` using `calc_sphfunc(grid, lane_id, ray_id, ray_spec[ray_blk_id].dir, sphfunc_val[ray_blk_id])` [S3, unofficial].
   - This fills `sphfunc_val[ray_blk_id]` with 9 values (assuming 3rd order SH) [S3, unofficial].
   - Synchronize warp: `__syncwarp((1 << grid.sh_data_dim) - 1)` to ensure all lanes have computed SH values [S3, unofficial].

4. **Ray Marching Loop:**
   - Initialize `t = ray_spec[ray_blk_id].tmin` [S3, unofficial].
   - While `t <= ray_spec[ray_blk_id].tmax`:
     a. **Position Computation:**
        - `ray.pos[j] = fmaf(t, ray_spec[ray_blk_id].dir[j], ray_spec[ray_blk_id].origin[j])` for $j=0,1,2$ [S3, unofficial].
        - Clamp `ray.pos[j]` to `[0, grid.size[j] - 1]` [S3, unofficial].
        - Compute integer voxel coordinates: `ray.l[j] = min(static_cast<int32_t>(ray.pos[j]), grid.size[j] - 2)` [S3, unofficial].
        - Compute fractional part: `ray.pos[j] -= static_cast<float>(ray.l[j])` [S3, unofficial].

     b. **Density Sampling:**
        - Sample density $\sigma$ using trilinear interpolation:
          $$ \sigma = \text{trilerp\_cuvol\_one}(grid.links, grid.density_data, grid.stride_x, grid.size[2], 1, ray.l, ray.pos, 0) $$
          [S3, unofficial].

     c. **Threshold Check:**
        - If $\sigma \le opt.sigma\_thresh$, skip sampling and continue to next step (advance `t`) [S3, unofficial].

     d. **Color Sampling:**
        - Sample SH color coefficients:
          $$ lane\_color = \text{trilerp\_cuvol\_one}(grid.links, grid.sh_data, grid.stride_x, grid.size[2], grid.sh\_data\_dim, ray.l, ray.pos, lane\_id) $$
          [S3, unofficial].
        - Multiply by SH basis value:
          $$ lane\_color *= sphfunc\_val[ray\_blk\_id][lane\_id] $$
          [S3, unofficial].

     e. **Weight Computation:**
        - Compute optical depth increment: $pcnt = ray\_spec[ray\_blk\_id].world\_step \times \sigma$ [S3, unofficial].
        - Compute weight:
          $$ weight = \exp(log\_transmit) \times (1 - \exp(-pcnt)) $$
          [S3, unofficial].
        - Update log-transmittance:
          $$ log\_transmit -= pcnt $$
          [S3, unofficial].

     f. **Accumulation:**
        - Reduce `lane_color` across the warp using `WarpReducef::HeadSegmentedSum` with mask `lane_colorgrp_id == 0` (where `lane_colorgrp_id` groups lanes by SH basis index) [S3, unofficial]. Let result be `lane_color_total` [S3, unofficial].
        - Add to output:
          $$ outv += weight \times \max(lane\_color\_total + 0.5f, 0.f) $$
          [S3, unofficial]. This clamps the color to non-negative values [S3, unofficial].

     g. **Last Sample Handling:**
        - If $opt.last\_sample\_opaque$ is true and $t + opt.step\_size > ray\_spec[ray\_blk\_id].tmax$, set $ray\_spec[ray\_blk\_id].world\_step = 10^9$ to make the last sample fully opaque [S3, unofficial].

     h. **Step Advancement:**
        - $t += opt.step\_size$ [S3, unofficial].

     i. **Early Termination:**
        - If $\exp(log\_transmit) < opt.stop\_thresh$, set $log\_transmit = -1000.0f$ and break the loop [S3, unofficial].

5. **Background Addition:**
   - If $grid.background\_nlayers == 0$, add background contribution:
     $$ outv += \exp(log\_transmit) \times opt.background\_brightness $$
     [S3, unofficial].

6. **Output:**
   - If `lane_id == 0`, write `out[lane_id] = outv` and if `out_log_transmit` is not null, write `*out_log_transmit = log_transmit` [S3, unofficial].

### Pseudocode
```python
# CUDA Kernel: render_ray_kernel
# Inputs: rays, grid, opt, outv, out_log_transmit
# Constants: TRACE_RAY_CUDA_THREADS = 128, WARP_SIZE = 32, TRACE_RAY_CUDA_RAYS_PER_BLOCK = 4

def compute_ray_bounds(ray, grid):
    # Standard AABB ray-box intersection [G]
    tmin, tmax = -float('inf'), float('inf')
    for j in range(3):
        inv_dir = 1.0 / ray.dir[j] if ray.dir[j] != 0 else float('inf')
        t0 = (0.0 - ray.origin[j]) * inv_dir
        t1 = (grid.size[j] - 1.0 - ray.origin[j]) * inv_dir
        tmin = max(tmin, min(t0, t1))
        tmax = min(tmax, max(t0, t1))
    return tmin, tmax

def render_ray_kernel(rays, grid, opt, outv, out_log_transmit):
    tid = blockIdx.x * blockDim.x + threadIdx.x
    ray_id = tid // 32
    lane_id = threadIdx.x % 32
    ray_blk_id = tid // 32  # 0 to 3

    if lane_id >= grid.sh_data_dim:
        return

    # Shared memory allocation
    shared_ray_spec = __shared__ SingleRaySpec[4]
    shared_sphfunc_val = __shared__ float[4][9]
    shared_temp_storage = __shared__ WarpReducef::TempStorage[4]

    # Initialize ray data in shared memory
    shared_ray_spec[ray_blk_id].origin = rays.origins[ray_id]
    shared_ray_spec[ray_blk_id].dir = rays.dirs[ray_id]

    # Compute ray bounds
    tmin, tmax = compute_ray_bounds(shared_ray_spec[ray_blk_id], grid)

    # Handle rays outside grid
    if tmin > tmax:
        if grid.background_nlayers == 0:
            outv[ray_id] = opt.background_brightness
        else:
            outv[ray_id] = 0.0
        if out_log_transmit is not None:
            out_log_transmit[ray_id] = 0.0
        return

    # Compute SH basis values
    calc_sphfunc(grid, lane_id, ray_id, shared_ray_spec[ray_blk_id].dir, shared_sphfunc_val[ray_blk_id])
    __syncwarp((1 << grid.sh_data_dim) - 1)

    # Initialize ray marching
    t = tmin
    log_transmit = 0.0
    out_color = 0.0
    world_step = opt.step_size

    while t <= tmax:
        # Position computation
        pos = [0.0, 0.0, 0.0]
        for j in range(3):
            pos[j] = t * shared_ray_spec[ray_blk_id].dir[j] + shared_ray_spec[ray_blk_id].origin[j]
            pos[j] = max(0.0, min(pos[j], grid.size[j] - 1.0))
        
        l = [int(pos[j]) for j in range(3)]
        for j in range(3):
            l[j] = min(l[j], grid.size[j] - 2)
            pos[j] -= l[j]

        # Density sampling
        sigma = trilerp_cuvol_one(grid.links, grid.density_data, grid.stride_x, grid.size[2], 1, l, pos, 0)

        # Threshold check
        if sigma <= opt.sigma_thresh:
            t += opt.step_size
            continue

        # Color sampling
        lane_color = trilerp_cuvol_one(grid.links, grid.sh_data, grid.stride_x, grid.size[2], grid.sh_data_dim, l, pos, lane_id)
        lane_color *= shared_sphfunc_val[ray_blk_id][lane_id]

        # Weight computation
        pcnt = world_step * sigma
        weight = exp(log_transmit) * (1.0 - exp(-pcnt))
        log_transmit -= pcnt

        # Warp reduction for color
        lane_color_total = WarpReducef(shared_temp_storage[ray_blk_id]).HeadSegmentedSum(lane_color, lane_id == 0)

        # Accumulation
        out_color += weight * max(lane_color_total + 0.5, 0.0)

        # Last sample handling
        if opt.last_sample_opaque and t + opt.step_size > tmax:
            world_step = 1e9

        # Step advancement
        t += opt.step_size

        # Early termination
        if exp(log_transmit) < opt.stop_thresh:
            log_transmit = -1000.0
            break

    # Background addition
    if grid.background_nlayers == 0:
        out_color += exp(log_transmit) * opt.background_brightness

    # Output
    if lane_id == 0:
        outv[ray_id] = out_color
        if out_log_transmit is not None:
            out_log_transmit[ray_id] = log_transmit
```

### Parameters
- `grid.basis_dim`: Number of SH basis functions per color channel [S1, unofficial].
- `opt.step_size`: Fixed step size for ray marching [S1, unofficial].
- `opt.sigma_thresh`: Density threshold below which samples are skipped [S1, unofficial].
- `opt.stop_thresh`: Transmission threshold below which ray marching terminates early [S1, unofficial].
- `opt.last_sample_opaque`: Boolean flag; if true, sets `world_step` to $10^9$ for the last sample [S1, unofficial].

### Edge Cases and Pitfalls
- If `ray.tmin > ray.tmax`, the ray is outside the grid. Output `background_brightness` if `grid.background_nlayers == 0`, else 0. Set `log_transmit` to 0 if `out_log_transmit` is not null [S2, unofficial].
- Precision issues may arise from repeated floating-point additions in the ray marching loop; using `fmaf` helps maintain precision [S2, unofficial].
- The SH basis evaluation must be synchronized across the warp before color accumulation to ensure correct reduction [S2, unofficial].

## Subtopics

### Forward Volume Rendering with Spherical Harmonics
Launches the kernel with blocks = `CUDA_N_BLOCKS_NEEDED(Q * WARP_SIZE, cuda_n_threads)`, where Q is the number of rays and `cuda_n_threads = TRACE_RAY_CUDA_THREADS` [S2, unofficial]. Each thread block processes `TRACE_RAY_CUDA_RAYS_PER_BLOCK` rays. Thread index `tid` maps to `ray_id = tid >> 5`, `ray_blk_id = threadIdx.x >> 5`, `lane_id = threadIdx.x & 0x1F` [S2, unofficial]. Loads ray origin and direction into `ray_spec[ray_blk_id]`, computes direction vector `vdir[3]` [S2, unofficial]. Evaluates spherical harmonics basis values per lane: `calc_sphfunc(grid, lane_id, ray_id, vdir, sphfunc_val[ray_blk_id])` [S2, unofficial]. Computes ray traversal bounds: `ray_find_bounds(ray_spec[ray_blk_id], grid, opt, ray_id)` [S2, unofficial]. Traces ray through grid and accumulates color/transmittance: `trace_ray_cuvol(grid, ray_spec[ray_blk_id], opt, lane_id, sphfunc_val[ray_blk_id], temp_storage[ray_blk_id], out + ray_id * 3, log_transmit_out)` [S2, unofficial]. If `grid.background_links` is defined and non-empty, allocates `log_transmit` tensor and launches `render_background_kernel` to composite background using `log_transmit` [S2, unofficial]. Input: `PackedSparseGridSpec grid`, `PackedRaysSpec rays`, `RenderOptions opt`. Output: `torch::Tensor results` of shape `[Q, 3]` (float, RGB) [S2, unofficial].

## Operating characteristics
- **Measured Performance:** On RTX 3090, Instant-NGP implemented in JNeRF achieves about 133 iterations per second for the lego dataset [S3, unofficial].

## Background
Sparse Grid Volume Rendering (Foreground) is derived from Plenoxels, which introduced the use of sparse voxel grids with spherical harmonics for radiance field representation [S1, unofficial]. The implementation in NeRF-Factory and JNeRF adapts this for efficient CUDA execution, leveraging warp-level operations for SH evaluation [S1, unofficial].
