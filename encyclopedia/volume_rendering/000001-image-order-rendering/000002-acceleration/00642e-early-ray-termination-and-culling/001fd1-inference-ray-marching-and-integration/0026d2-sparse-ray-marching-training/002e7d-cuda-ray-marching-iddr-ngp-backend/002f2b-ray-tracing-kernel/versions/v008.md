# Ray Tracing Kernel


## Overview
The Ray Tracing Kernel is a CUDA compute kernel that performs forward and backward volumetric ray marching through a sparse hashed density grid using spherical harmonics (SH) for color representation [S1, unofficial][S2, unofficial]. It serves as the core inference and training step for the IDDR-NGP backend, computing final pixel colors and log-transmittance in the forward pass, and gradients for SH coefficients and grid outputs in the backward pass [S1, unofficial][S2, unofficial]. It differs from standard uniform ray marching by utilizing warp-level parallelism for SH evaluation and adaptive step sizes, and from dense voxel cone tracing by operating on a sparse grid structure with specific boundary handling [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Forward:** Ray origins, directions, grid density data, grid SH data, ray bounds, options (step size, thresholds). Outputs: pixel color, log-transmittance.
*   **Backward:** Gradient of output color, color cache, input log-transmittance, SH values, gradients. Outputs: gradients for SH coefficients and grid data.

**Data Structures:**
*   `ray_spec[TRACE_RAY_CUDA_RAYS_PER_BLOCK]`: Shared memory array of `SingleRaySpec` structs storing ray origin and direction for each ray in the block [S1, unofficial][S2, unofficial].
*   `sphfunc_val[TRACE_RAY_CUDA_RAYS_PER_BLOCK][9]`: Shared memory 2D float array storing spherical harmonic function values [S1, unofficial][S2, unofficial].
*   `grad_sphfunc_val[TRACE_RAY_CUDA_RAYS_PER_BLOCK][9]`: Shared memory 2D float array storing gradients for spherical harmonic values [S1, unofficial].
*   `temp_storage[TRACE_RAY_CUDA_RAYS_PER_BLOCK]`: Shared memory for `WarpReducef::TempStorage` used in warp-level reductions [S1, unofficial].
*   `grid.links`, `grid.density_data`, `grid.sh_data`: Sparse grid data structures accessed via global memory [S1, unofficial].

**Parameters:**
*   `TRACE_RAY_CUDA_RAYS_PER_BLOCK`: Number of rays processed per CUDA block [S1, unofficial].
*   `TRACE_RAY_BKWD_CUDA_THREADS`: Number of threads per block for the backward kernel [S1, unofficial].
*   `grid.basis_dim`: Number of SH basis functions per color channel [S1, unofficial].
*   `grid.sh_data_dim`: Dimension of SH data, used to mask threads [S2, unofficial].
*   `opt.sigma_thresh`: Density threshold for sampling [S1, unofficial].
*   `opt.stop_thresh`: Log-transmittance threshold for early termination [S1, unofficial].
*   `opt.background_brightness`: Background color contribution [S1, unofficial].
*   `opt.last_sample_opaque`: Flag to ensure the last sample is opaque [S1, unofficial].
*   `opt.step_size`: Step size for ray marching [S1, unofficial].
*   `opt.background_nlayers`: Number of background layers [S1, unofficial].

**Algorithm (Forward):**
1.  **Initialization:**
    *   Calculate block and lane indices: `ray_blk_id = threadIdx.x >> 5`, `lane_id = threadIdx.x & 0x1F` [S1, unofficial].
    *   If `lane_id >= grid.sh_data_dim`, return early [S1, unofficial][S2, unofficial].
    *   Initialize `ray_spec[ray_blk_id]` with origin and direction from input rays for `ray_id` [S1, unofficial].
    *   Calculate spherical harmonic function values: `calc_sphfunc(grid, lane_id, ray_id, ray_spec[ray_blk_id].dir, sphfunc_val[ray_blk_id])` [S1, unofficial].
    *   Synchronize warps: `__syncwarp((1U << grid.sh_data_dim) - 1)` to ensure shared memory visibility [S1, unofficial][S2, unofficial].

2.  **Ray Bounds:**
    *   Find ray bounds within the grid: `ray_find_bounds(ray_spec[ray_blk_id], grid, opt, ray_id)` [S1, unofficial][S2, unofficial].

3.  **Ray Marching Loop:**
    *   Initialize `log_transmit = 0.0f`, `outv = 0.0f` [S1, unofficial].
    *   While `t < ray.tmax`:
        *   Compute ray position: `ray.pos[j] = fmaf(t, ray.dir[j], ray.origin[j])` [S1, unofficial].
        *   Clamp position to `[0, grid.size[j]-1]` [S1, unofficial].
        *   Compute integer lattice index: `l[j] = min(floor(pos[j]), size[j]-2)` [S1, unofficial].
        *   Compute fractional position: `pos[j] -= l[j]` [S1, unofficial].
        *   If `opt.last_sample_opaque` is true and `t + opt.step_size > ray.tmax`, set `ray.world_step = 1e9` [S1, unofficial].
        *   Trilinearly interpolate density `sigma` from `grid.density_data` using `trilerp_cuvol_one(grid.links, grid.density_data, grid.stride_x, grid.size[2], 1, ray.l, ray.pos, 0)` [S1, unofficial].
        *   If `sigma > opt.sigma_thresh`:
            *   Trilinearly interpolate SH color value from `grid.sh_data` using `trilerp_cuvol_one(..., grid.sh_data_dim, ..., lane_id)` [S1, unofficial].
            *   Multiply by `sphfunc_val[lane_colorgrp_id]` [S1, unofficial].
        *   Reduce `lane_color` across the warp group using `WarpReducef::HeadSegmentedSum` with `lane_colorgrp_id == 0` mask. Let result be `lane_color_total` [S1, unofficial].
        *   Calculate weight: `weight = exp(log_transmit) * (1 - exp(-pcnt))`, where `pcnt = ray.world_step * sigma` [S1, unofficial].
        *   Update `log_transmit -= pcnt` [S1, unofficial].
        *   Accumulate color: `outv += weight * max(lane_color_total + 0.5f, 0.f)` [S1, unofficial].
        *   If `exp(log_transmit) < opt.stop_thresh`, set `log_transmit = -1e3f` and break loop (early termination) [S1, unofficial].
        *   Advance `t += opt.step_size` [S1, unofficial].

4.  **Finalization:**
    *   If `grid.background_nlayers == 0`, add background contribution: `outv += exp(log_transmit) * opt.background_brightness` [S1, unofficial].
    *   If `lane_colorgrp_id == 0`, write `out[lane_colorgrp] = outv` and if `out_log_transmit` is not null, write `*out_log_transmit = log_transmit` [S1, unofficial].

**Algorithm (Backward):**
1.  **Initialization:**
    *   Initialize gradient SH values to `0.0f` for all lanes less than `grid.basis_dim` [S1, unofficial].
    *   Calculate SH function values for backward pass, similar to forward pass [S1, unofficial].
    *   Find ray bounds (performed only by lane 0 to avoid redundancy) [S1, unofficial].

2.  **Gradient Output Calculation:**
    *   If `grad_out_is_rgb` is true, calculate `resid = color_cache - grad_output`, then `grad_out[i] = resid * norm_factor` where `norm_factor = 2.f / (3 * Q)` [S1, unofficial].
    *   Otherwise, `grad_out[i] = grad_output[i]` [S1, unofficial].

3.  **Backward Trace:**
    *   Synchronize warps within the active mask [S1, unofficial].
    *   Call `trace_ray_cuvol_backward` with grid, `grad_out`, `color_cache`, ray spec, options, lane ID, `sphfunc_val`, `grad_sphfunc_val`, temp storage, `log_transmit_in`, `beta_loss`, `sparsity_loss`, grads, `accum_out`, and `log_transmit_out` [S1, unofficial].

4.  **SH Gradient Calculation:**
    *   Call `calc_sphfunc_backward` with grid, lane ID, ray ID, `vdir`, `sphfunc_val`, `grad_sphfunc_val`, and `grads.grad_basis_out` [S1, unofficial].

**Pseudocode (Forward):**
```python
# Pseudocode for forward ray tracing kernel
# Assumes shared memory arrays: ray_spec, sphfunc_val, temp_storage
# Assumes global memory: grid.links, grid.density_data, grid.sh_data, rays, out, out_log_transmit

def render_ray_kernel(rays, grid, opt, out, out_log_transmit):
    ray_blk_id = threadIdx.x >> 5
    lane_id = threadIdx.x & 0x1F
    
    # Early exit if lane exceeds SH data dimension
    if lane_id >= grid.sh_data_dim:
        return

    # Initialize ray spec
    ray_id = ... # Derived from blockIdx and threadIdx
    ray_spec[ray_blk_id].origin = rays[ray_id].origin
    ray_spec[ray_blk_id].dir = rays[ray_id].dir
    
    # Calculate SH function values
    calc_sphfunc(grid, lane_id, ray_id, ray_spec[ray_blk_id].dir, sphfunc_val[ray_blk_id])
    
    # Synchronize to ensure shared memory visibility
    __syncwarp((1U << grid.sh_data_dim) - 1)
    
    # Find ray bounds
    ray_find_bounds(ray_spec[ray_blk_id], grid, opt, ray_id)
    
    log_transmit = 0.0f
    outv = 0.0f
    t = ray_spec[ray_blk_id].tmin
    
    while t < ray_spec[ray_blk_id].tmax:
        # Compute ray position
        ray.pos = fmaf(t, ray_spec[ray_blk_id].dir, ray_spec[ray_blk_id].origin)
        
        # Clamp position
        ray.pos = clamp(ray.pos, 0.0f, grid.size - 1.0f)
        
        # Compute lattice index and fractional position
        ray.l = min(floor(ray.pos), grid.size - 2)
        ray.pos_frac = ray.pos - ray.l
        
        # Handle last sample opaque condition
        if opt.last_sample_opaque and (t + opt.step_size > ray_spec[ray_blk_id].tmax):
            ray.world_step = 1e9
        else:
            ray.world_step = opt.step_size
            
        # Interpolate density
        sigma = trilerp_cuvol_one(
            grid.links, grid.density_data, grid.stride_x, grid.size[2], 1, 
            ray.l, ray.pos_frac, 0
        )
        
        lane_color = 0.0f
        if sigma > opt.sigma_thresh:
            # Interpolate SH color
            sh_color = trilerp_cuvol_one(
                grid.links, grid.sh_data, grid.stride_x, grid.size[2], 
                grid.sh_data_dim, ray.l, ray.pos_frac, lane_id
            )
            lane_color = sh_color * sphfunc_val[ray_blk_id][lane_id]
            
        # Warp reduction
        lane_color_total = WarpReducef::HeadSegmentedSum(lane_color, lane_id == 0)
        
        # Weight calculation
        pcnt = ray.world_step * sigma
        weight = exp(log_transmit) * (1.0f - exp(-pcnt))
        
        # Accumulate color
        outv += weight * max(lane_color_total + 0.5f, 0.0f)
        
        # Update log transmittance
        log_transmit -= pcnt
        
        # Early termination
        if exp(log_transmit) < opt.stop_thresh:
            log_transmit = -1e3f
            break
            
        t += opt.step_size
        
    # Background contribution
    if grid.background_nlayers == 0:
        outv += exp(log_transmit) * opt.background_brightness
        
    # Write output
    if lane_id == 0:
        out[ray_blk_id] = outv
        if out_log_transmit is not None:
            out_log_transmit[ray_blk_id] = log_transmit
```

## Subtopics

### [TracingKernel](13916-tracingkernel.md)
`TracingKernel` is a CUDA compute shader that performs volumetric light transport by stepping through a 3D grid, dynamically adjusting step size and cascade resolution based on distance from the center, and accumulating transmittance (alpha). It is designed for the IDDR-NGP backend, where it serves as the core inference step for sparse ray marching, optimizing performance by coarser sampling in distant regions and finer sampling near the center. It differs from standard uniform ray marching by using a logarithmic expansion factor to vary step sizes and cascade levels, and from dense voxel cone tracing by operating on a sparse grid structure with specific boundary handling.

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of samples per ray, which depends on ray length and step size. Warp-level parallelism reduces overhead for SH evaluation.
*   **Memory Complexity:** Shared memory usage is proportional to `TRACE_RAY_CUDA_RAYS_PER_BLOCK`. Global memory access is sparse, dependent on grid density.
*   **Performance:** Optimized for GPU execution using CUDA. Performance scales with the number of rays and grid sparsity. Early termination based on log-transmittance can significantly reduce computation for transparent regions.
*   **Strengths:** Efficient handling of sparse volumes, adaptive step sizes, parallel SH evaluation.
*   **Limitations:** Dependent on grid structure and sparsity. Precision issues may arise with very small or large step sizes.
*   **When to use:** Suitable for real-time or near-real-time volumetric rendering on GPUs, especially with sparse data structures.
*   **When not to use:** Not suitable for dense, uniform volumes where simpler methods may be more efficient, or on hardware without sufficient shared memory or warp-level primitives.

## Background
The Ray Tracing Kernel is part of the NeRF-Factory project by POSTECH, KAIST, and Kakao Brain Corp. [S1, unofficial]. It is designed to work with the IDDR-NGP backend, which uses a sparse hashed density grid for efficient volumetric rendering. The kernel supports both forward rendering and backward gradient computation for training neural radiance fields (NeRFs) [S1, unofficial][S2, unofficial].
