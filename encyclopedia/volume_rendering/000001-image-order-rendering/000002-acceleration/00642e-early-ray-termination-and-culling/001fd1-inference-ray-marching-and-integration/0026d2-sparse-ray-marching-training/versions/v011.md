# Sparse Ray Marching (Training)

Also called: Grid-based ray marching, Ray Marching (Training), RayMarcherTaichi, Sparse Ray Marching with Density Bitfield

## Overview
Sparse Ray Marching (Training) is a GPU-accelerated algorithm that traces rays through a hierarchical sparse voxel grid to collect 3D positions, directions, step sizes, and t-values for training neural radiance fields [S1, S2, unofficial]. It solves the inefficiency of uniform sampling by skipping empty regions using a density bitfield, dynamically allocating memory based on actual occupancy rather than fixed worst-case bounds [S1, S2, unofficial]. It differs from its siblings by explicitly decoupling the counting of occupied samples from the writing of sample data, allowing for dynamic memory allocation based on actual occupancy rather than fixed worst-case bounds [S1, unofficial][S2, unofficial].

## How it works
**Inputs:**
*   `rays_o`: Ray origins, shape `(N, 3)`, float32 [S1, unofficial].
*   `rays_d`: Ray directions, shape `(N, 3)`, float32 [S1, unofficial].
*   `hits_t`: Ray segment bounds `[t1, t2]`, shape `(N, 2)`, float32 [S1, unofficial].
*   `density_bitfield`: Bit-packed occupancy grid, shape `(M,)`, uint8 [S1, unofficial].
*   `cascades`: Number of mip levels in the density bitfield [S1, unofficial].
*   `scale`: Spatial extent (bounding box size) of the scene, used to normalize coordinates [S1, unofficial].
*   `exp_step_factor`: Factor used in step size calculation [S1, unofficial].
*   `grid_size`: Base resolution of the voxel grid [S1, unofficial].
*   `max_samples`: Maximum number of samples allowed per ray [S1, unofficial].
*   `noise`: Uniform random perturbation added to the first sample of each ray [S1, unofficial].
*   `perturb`: Boolean flag enabling random jittering of the initial sampling position [S2, unofficial].
*   `bound`: Spatial extent of the grid [S2, unofficial].
*   `H`: Resolution of the cubic density grid ($H \times H \times H$) [S2, unofficial].
*   `density_thresh`: Threshold for occupied space [S2, unofficial].
*   `dt_min`, `dt_max`: Minimum and maximum step sizes [S2, unofficial].
*   `dt_gamma`: Scaling factor for step size calculation [S2, unofficial].
*   `rays_alive`: List of active ray indices [S2, unofficial].
*   `rays_t`: Array of current t-values for active rays [S2, unofficial].
*   `counter`: Global counter for total samples [S1, unofficial].

**Outputs:**
*   `xyzs`: 3D coordinates of occupied samples, shape `(Total_Samples, 3)`, float32 [S1, unofficial].
*   `dirs`: Ray direction vectors for each sample, shape `(Total_Samples, 3)`, float32 [S1, unofficial].
*   `deltas`: Step size `dt` for each sample, shape `(Total_Samples,)`, float32 [S1, unofficial].
*   `ts`: T-values for each sample, shape `(Total_Samples,)`, float32 [S1, unofficial].
*   `rays_a`: Ray metadata, shape `(N, 3)`, int32. Column 0: original ray index, Column 1: start index in output buffers, Column 2: number of samples [S1, unofficial].

**Data Structures:**
*   `density_bitfield`: Bit-packed occupancy grid where each byte stores 8 voxels' occupancy status [S1, unofficial].
*   `rays_a`: Stores ray index, start index, and sample count for each ray to enable packed output buffers [S1, unofficial].

**Parameters:**
*   `N_THREAD`: Number of threads per block in the CUDA kernel launch, set to 256 [S2, unofficial].
*   `mean_density`: Average density of the grid, used as a fallback density threshold if the specific threshold function returns a lower value [S2, unofficial].

**Algorithm Steps:**

1.  **Initialization:** For each active ray, load its index and current t-value [S3, unofficial]. If `perturb` is true, initialize a random number generator and add `dt_min * rng.next_float()` to `t` to jitter the first sample [S3, unofficial].
2.  **First Pass (Counting):** Loop while `t < t2` and sample count `< max_samples` [S1, unofficial]. Calculate current position, clamp to `[-bound, bound]`, and map to grid indices [S3, unofficial]. Query density. If occupied, calculate step size `dt = clamp(t * dt_gamma, dt_min, dt_max)`, advance `t`, and increment sample count [S1, S3, unofficial]. If empty, calculate distance to the next voxel boundary using ray-plane intersections, and advance `t` in a loop until it reaches the boundary [S1, S3, unofficial]. Record the ray index, start index (from global counter), and sample count in `rays_a` [S1, unofficial].
3.  **Second Pass (Writing):** Reset `t` to `t1` [S1, unofficial]. Loop while `t < t2` and samples `< N_samples` [S1, unofficial]. Repeat position calculation and occupancy check [S1, unofficial]. If occupied, write `xyz`, `dir`, `dt`, and `t` to the global output buffers at `start_idx + samples_written` [S1, unofficial]. Advance `t` by `dt`. If empty, use the same skipping logic as the first pass [S1, unofficial].
4.  **Finalization:** Update the global sample counter using atomic addition [S1, S2, unofficial]. The output buffers contain all samples packed contiguously, indexed by `rays_a` [S1, unofficial].

**Pseudocode:**

```python
def sparse_ray_marching_train(rays_o, rays_d, hits_t, density_bitfield, cascades, scale, exp_step_factor, grid_size, max_samples, noise, perturb, bound, H, density_thresh, dt_min, dt_max, dt_gamma, rays_alive, rays_t, counter, rays_a, xyzs, dirs, deltas, ts):
    n_alive = len(rays_alive)
    rbound = 1.0 / bound
    grid_size_inv = 1.0 / grid_size
    mip_bound = scale

    for n in range(n_alive):
        if n >= n_alive:
            break
        ray_idx = rays_alive[n]
        t = rays_t[n]
        ox, oy, oz = rays_o[ray_idx]
        dx, dy, dz = rays_d[ray_idx]
        d_inv = (1.0 / dx if dx != 0 else float('inf'),
                 1.0 / dy if dy != 0 else float('inf'),
                 1.0 / dz if dz != 0 else float('inf'))
        t1, t2 = hits_t[ray_idx]

        # Perturbation [S3, unofficial]
        if perturb:
            t += dt_min * 0.5  # [G] placeholder for PCG32 rng.next_float()

        # First pass: count samples [S1, S3, unofficial]
        N_samples = 0
        current_t = t
        last_t = t

        while current_t < t2 and N_samples < max_samples:
            # Clamp and map to grid [S3, unofficial]
            x = max(-bound, min(bound, ox + current_t * dx))
            y = max(-bound, min(bound, oy + current_t * dy))
            z = max(-bound, min(bound, oz + current_t * dz))

            nx = int(max(0, min(H - 1, 0.5 * (x * rbound + 1) * H)))
            ny = int(max(0, min(H - 1, 0.5 * (y * rbound + 1) * H)))
            nz = int(max(0, min(H - 1, 0.5 * (z * rbound + 1) * H)))

            # Query occupancy from bitfield [S1, unofficial]
            idx = (nx * grid_size + ny) * grid_size + nz
            occ = (density_bitfield[idx // 8] >> (idx % 8)) & 1

            if occ:
                dt = max(dt_min, min(dt_max, current_t * dt_gamma))
                current_t += dt
                N_samples += 1
                last_t = current_t
            else:
                # Skip empty space [S1, unofficial]
                sign_x = 1.0 if dx > 0 else -1.0
                sign_y = 1.0 if dy > 0 else -1.0
                sign_z = 1.0 if dz > 0 else -1.0
                txyz = (((nx + 0.5 + 0.5 * sign_x) * grid_size_inv * 2 - 1) * mip_bound - x) * d_inv[0]
                tyz = (((ny + 0.5 + 0.5 * sign_y) * grid_size_inv * 2 - 1) * mip_bound - y) * d_inv[1]
                tz = (((nz + 0.5 + 0.5 * sign_z) * grid_size_inv * 2 - 1) * mip_bound - z) * d_inv[2]
                t_target = current_t + max(0.0, min(txyz, tyz, tz))

                while current_t < t_target:
                    dt = max(dt_min, min(dt_max, current_t * dt_gamma))
                    current_t += dt

        # Record metadata [S1, unofficial]
        start_idx = counter[0]
        counter[0] += N_samples
        rays_a[ray_idx][0] = ray_idx
        rays_a[ray_idx][1] = start_idx
        rays_a[ray_idx][2] = N_samples

        # Second pass: store samples [S1, unofficial]
        current_t = t1
        samples_written = 0
        last_t = t1

        while current_t < t2 and samples_written < N_samples:
            x = max(-bound, min(bound, ox + current_t * dx))
            y = max(-bound, min(bound, oy + current_t * dy))
            z = max(-bound, min(bound, oz + current_t * dz))

            nx = int(max(0, min(H - 1, 0.5 * (x * rbound + 1) * H)))
            ny = int(max(0, min(H - 1, 0.5 * (y * rbound + 1) * H)))
            nz = int(max(0, min(H - 1, 0.5 * (z * rbound + 1) * H)))

            idx = (nx * grid_size + ny) * grid_size + nz
            occ = (density_bitfield[idx // 8] >> (idx % 8)) & 1

            if occ:
                idx_buf = start_idx + samples_written
                xyzs[idx_buf] = (x, y, z)
                dirs[idx_buf] = (dx, dy, dz)
                dt = max(dt_min, min(dt_max, current_t * dt_gamma))
                deltas[idx_buf] = dt
                ts[idx_buf] = current_t
                samples_written += 1
                current_t += dt
                last_t = current_t
            else:
                sign_x = 1.0 if dx > 0 else -1.0
                sign_y = 1.0 if dy > 0 else -1.0
                sign_z = 1.0 if dz > 0 else -1.0
                txyz = (((nx + 0.5 + 0.5 * sign_x) * grid_size_inv * 2 - 1) * mip_bound - x) * d_inv[0]
                tyz = (((ny + 0.5 + 0.5 * sign_y) * grid_size_inv * 2 - 1) * mip_bound - y) * d_inv[1]
                tz = (((nz + 0.5 + 0.5 * sign_z) * grid_size_inv * 2 - 1) * mip_bound - z) * d_inv[2]
                t_target = current_t + max(0.0, min(txyz, tyz, tz))

                while current_t < t_target:
                    dt = max(dt_min, min(dt_max, current_t * dt_gamma))
                    current_t += dt
```

**Edge Cases and Pitfalls:**
*   **Precision:** Floating-point precision issues may arise when clamping coordinates or calculating boundary distances. Use appropriate epsilon values [G].
*   **Boundaries:** Rays starting outside the bound or hitting the bound exactly need careful handling to avoid infinite loops or out-of-bounds access [G].
*   **Degenerate Input:** Rays with zero length or direction need to be filtered out or handled specially [G].
*   **Empty Space Skipping:** The algorithm must correctly calculate the exit time from the current voxel to avoid sampling empty space. It uses the intersection of the ray with the voxel boundary (`txyz`) to determine the next valid `t` [S1, unofficial].
*   **Memory Allocation:** Dynamic allocation based on occupancy requires careful management of output buffers to avoid overflow. Pre-allocation with a safety margin is common [G].

## Subtopics

### [CUDA Ray Marching (IDDR-NGP Backend)](5788-cuda-ray-marching-iddr-ngp-backend.md)
A GPU-accelerated ray marching kernel that samples points along rays using a hashed density grid, supporting adaptive step sizes and perturbation. It differs from standard uniform ray marching by integrating adaptive stepping and perturbation directly into the sampling loop, and from dense voxel tracing by operating on a sparse hashed grid structure.

### [Training Ray Marching (Forward Only)](6205-training-ray-marching-forward-only.md)
A two-pass GPU algorithm that samples a ray through a sparse voxel grid (density bitfield) to collect 3D positions, directions, step sizes (deltas), and t-values for training neural radiance fields. It sets itself apart from its siblings by explicitly decoupling the counting of occupied samples from the writing of sample data, allowing for dynamic memory allocation based on actual occupancy rather than fixed worst-case bounds.

### [Sparse Packed Radiance Field Tracer](13126-sparse-packed-radiance-field-tracer.md)
The Sparse Packed Radiance Field Tracer is a differentiable rendering method for sparse, packed radiance fields that generates a variable number of samples per ray, packed into a flat tensor structure. It solves the inefficiency of standard ray marching by using a sparse acceleration structure to sample only within occupied cells, resulting in a custom number of samples per ray rather than a fixed grid. Unlike its siblings, it explicitly manages the "packed" data layout where rays with different intersection counts share a single contiguous buffer, requiring specific reduction operations to handle boundaries between rays.

### [Sparse Grid Volume Rendering (Foreground)](15051-sparse-grid-volume-rendering-foreground.md)
Sparse Grid Volume Rendering (Foreground) is a CUDA-based volume rendering method that traces rays through a sparse voxel grid to compute final color and log-transmittance using volume rendering with spherical harmonics (SH) coefficients. It differs from its siblings by explicitly managing warp-level parallelism for SH basis evaluation and accumulation, utilizing shared memory for warp-local data to minimize global memory traffic, and employing early termination based on transmission thresholds. Unlike [CUDA Ray Marching (IDDR-NGP Backend)](5788-cuda-ray-marching-iddr-ngp-backend.md) which uses hash encoding, or [Sparse Packed Radiance Field Tracer](13126-sparse-packed-radiance-field-tracer.md) which may use different interpolation schemes, this method relies on trilinear interpolation over a sparse connectivity structure.

### Differentiable Ray Marching (SRN variant)
A technique using LSTM to adaptively sample points along a query ray until it finds the intersection with the scene, then passing this point to a pixel generator network [S4, unofficial]. It employs an LSTM to adaptively sample points along the query ray, continuing sampling until the intersection of the query ray with the scene is found, and then passes the intersection point through a pixel generator network to yield color directly [S4, unofficial].

### Object-space AImC
An approach to avoid suppression of context behind the focus object by suppressing only those samples of the context object that are in front of the focus object [S5]. The countersink geometry defines the region of different levels of sparseness, but the starting position of the ray is not changed [S5]. During the ray traversal of final image synthesis, each sample location is evaluated whether it belongs to the countersink area or not [S5]. Outside the countersink area, the context is represented using a more dense representation, and inside, a more sparse form is chosen [S5]. Unlike image-space AImC where the level of sparseness is constant for all samples of one object along a particular ray, object-space AImC has a level of sparseness that is not constant for one object along a particular ray [S5].

## Operating characteristics
*   **Time Complexity:** Depends on the sparsity of the grid and the distribution of occupied space [G]. In the worst case (fully occupied), it is $O(N \cdot M)$ where $N$ is the number of rays and $M$ is the maximum samples per ray [S1, unofficial]. In practice, it is significantly faster due to skipping empty space [G].
*   **Memory Complexity:** $O(N \cdot M)$ for output buffers if pre-allocated, or $O(\text{total\_samples})$ if dynamically resized [G]. The density bitfield size depends on the grid resolution and hierarchy [S1, S2, unofficial].
*   **Measured Performance:** Tested with RTX 2080 Ti, CUDA 11.3, 32GB RAM [S1, unofficial].
*   **Strengths:** Efficiently skips empty space, reducing computational waste. Dynamic memory allocation based on occupancy [G].
*   **Limitations:** Requires careful management of dynamic memory. Performance depends on the quality of the sparse grid and density threshold [G].
*   **When to Use:** Training neural radiance fields where most of the scene is empty or background [G].
*   **When Not to Use:** Dense scenes with little empty space, or when real-time inference with fixed latency is required (use Inference Ray Marching instead) [G].

## Background
Sparse Ray Marching (Training) is a method used in the context of Neural Radiance Fields (NeRF) and related techniques for training [S1, S2, unofficial]. It was popularized by implementations such as `ngp_pl` [S1, unofficial] and `cv-master-ex` [S2, unofficial]. The method builds on the idea of sparse voxel grids for efficient volume rendering [S1, S2, unofficial].
