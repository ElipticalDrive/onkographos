# Fine-Scale Occlusion Map Culling
Also called: Average occlusion map, Fine-Scale Occlusion Map
## Overview
Fine-Scale Occlusion Map Culling is a visibility culling technique that determines voxel rasterization eligibility using an occlusion map where each pixel represents the average of all pixels within a box-neighborhood footprint [S1, unofficial]. It performs occlusion culling on a finer scale than the box-basis of an octree decomposition, offering an alternative that does not reduce the volume’s frequency content by ways of averaging [S1, unofficial].
## How it works
### Inputs and outputs
- **Input**: Voxel screen-space coordinates and a pre-computed average occlusion map [S1, unofficial].
- **Output**: A rasterization decision for each voxel indicating whether its footprint must be rasterized [S1, unofficial].
### Data structures
- **Occlusion Map**: A 2D grid aligned with the screen where each cell stores a scalar value representing the average of all pixels within the box-neighborhood covered by a footprint [S1, unofficial].
- **Footprint**: A box-shaped neighborhood in screen space corresponding to the projection of a voxel or group of voxels [S1, unofficial].
### Steps
1. **Construct the Average Occlusion Map**: For each pixel in the target resolution, calculate the average of all pixels within the box-neighborhood covered by a footprint [S1, unofficial].
2. **Index the Map for Voxel Culling**: For each voxel to be rendered, determine its screen-space coordinate [S1, unofficial].
3. **Evaluate Occlusion**: Retrieve the value from the occlusion map at the voxel's screen-space coordinate [S1, unofficial].
4. **Rasterization Decision**: Check if the footprint must be rasterized based on the indexed occlusion map value [S2, book].
### Formulas
$M(u,v) = \frac{1}{N} \sum_{i \in \text{footprint}} P_i$, where $M(u,v)$ is the occlusion map value at screen coordinate $(u,v)$, $N$ is the number of pixels in the box-neighborhood footprint, and $P_i$ is the opacity of each pixel [S1, unofficial].
### Pseudocode
```python
def fine_scale_culling(voxel_screen_coords, occlusion_map, threshold=0.99):
    """
    Determine if a voxel should be rasterized based on the fine-scale occlusion map.
    
    Args:
        voxel_screen_coords: List of (u, v) tuples representing screen coordinates of voxels.
        occlusion_map: 2D array where each cell contains the average opacity of its footprint.
        threshold: Opacity threshold below which a voxel is considered occluded.
        
    Returns:
        List of booleans indicating whether each voxel should be rasterized.
    """
    culling_results = []
    H, W = occlusion_map.shape
    for u, v in voxel_screen_coords:
        if 0 <= u < W and 0 <= v < H:
            avg_opacity = occlusion_map[v][u]
            should_rasterize = avg_opacity < threshold
            culling_results.append(should_rasterize)
        else:
            culling_results.append(True)
    return culling_results
```
### Parameters
- **Footprint Size**: The size of the box-neighborhood averaged per pixel. Not given in the sources. [G]
- **Threshold**: The opacity value used to decide culling. Not given in the sources. [G]
### Edge cases and pitfalls
- **Boundary Conditions**: Voxels projecting outside the screen bounds must be handled explicitly [G].
- **Degenerate Input**: If the volume has no opacity, the map will be all zeros, and no culling occurs [G].

## Operating characteristics
- **Time Complexity**: Not given in the sources. [G]
- **Memory Complexity**: Requires storage for the occlusion map. The size depends on the screen resolution and footprint size. Not given in the sources. [G]
- **Strengths**: Retains volume frequency content better than hierarchical decomposition by using averaging rather than binary culling at node levels [S1, unofficial].
- **Limitations**: Not given in the sources. [G]
- **When to use**: When fine-scale visibility culling is needed without losing high-frequency details, potentially in combination with octree culling [S1, unofficial].
- **When not to use**: Not given in the sources. [G]
## Background
The method was described in the context of volume rendering acceleration, offering an alternative to octree-based space skipping. It was proposed to benefit from both large-scale culling (via octrees) and fine-scale culling (via average occlusion maps) [S1, unofficial].
