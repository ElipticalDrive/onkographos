# Visibility Prefiltering

Also called: Depth Distribution Prefiltering, Mode-based Depth Storage

## Overview
Visibility Prefiltering is a technique used in hierarchical volumetric shadowing to reduce correlated artifacts inherent in Riemann sum integration by storing a distribution of blocker depths rather than a single depth value per integration sample [S1]. It approximates the percentage of visibility changes along the angular axis ($\beta$) for each sample, converting structured aliasing into less objectionable noise similar to Monte Carlo sampling while requiring significantly fewer light rays [S1].

## How it works
Visibility Prefiltering modifies the standard Riemann sum integration by replacing the scalar blocker depth $S[\gamma]$ with a weighted set of depth modes [S1]. This allows the integration step to account for partial visibility within a single integration interval $\Delta \gamma$, rather than assuming binary occlusion based on a single depth query [G].

### Inputs and Outputs
*   **Input:** The rectified coordinate $\gamma$ for a light ray segment and the integration interval $\Delta \gamma$ [S1].
*   **Output:** A set of depth modes $\{(d_i, w_i)\}$ inserted into the termination depths structure, where $d_i$ is the depth and $w_i$ is the fractional weight of the mode [S1].

### Data Structures
The method updates the **termination depths structure** [S1]. While the specific internal layout of this structure is defined in the parent article [Two-pass Adaptive Screen Sampling with Interval Partitioning](5460-two-pass-adaptive-screen-sampling-with-interval-partitioning.md), Visibility Prefiltering interacts with it by performing **fractional updates** [S1]. If a segment yields $k$ modes, the corresponding tree node is updated $k$ times, each time with a fraction of the light intensity equal to the mode's weight $w_i$ [S1].

### Algorithm Steps
1.  **Sample:** For each integration interval $\Delta \gamma$ in the rectification loop, sample the blocker depth four times along the interval [S1].
2.  **Cluster:** Group the four depth values into one or more modes by clustering values that differ by at most a small constant [S1]. For each cluster, calculate the mode depth (e.g., the mean of the cluster) and the weight $w_j$ equal to the fraction of samples comprising that mode [S1].
3.  **Insert:** For each mode $(d_j, w_j)$, update the termination depths structure at the segment's location [S1]. When there is more than one mode, the tree node at the segment's location is updated once for every mode at different $\beta$ coordinates, assigning a fraction of the light corresponding to the mode's weight [S1].

### Pseudocode
```python
def visibility_prefiltering(segment_gamma, delta_gamma, sample_blocker_depth, epsilon):
    """
    Prefilters visibility for a single integration interval.
    
    Args:
        segment_gamma: The base rectified gamma coordinate for the segment.
        delta_gamma: The width of the integration interval.
        sample_blocker_depth: A function that returns the blocker depth at a given gamma.
        epsilon: A small constant for clustering depth values [G].
        
    Returns:
        A list of tuples (depth, weight) representing the depth distribution.
    """
    # Step 1: Sample blocker depth four times along the interval [S1]
    # Exact sampling positions along Δγ are implementation-defined [G]
    samples = []
    for i in range(4):
        offset = (i + 0.5) * delta_gamma / 4.0
        gamma_pos = segment_gamma + offset
        depth = sample_blocker_depth(gamma_pos)
        samples.append(depth)
        
    # Step 2: Cluster nearby depths into modes [S1]
    samples.sort()
    modes = []
    if not samples:
        return modes
        
    current_cluster = [samples[0]]
    
    for i in range(1, len(samples)):
        if samples[i] - samples[i-1] <= epsilon:
            current_cluster.append(samples[i])
        else:
            # Finalize previous cluster
            mode_depth = sum(current_cluster) / len(current_cluster)
            mode_weight = len(current_cluster) / 4.0
            modes.append((mode_depth, mode_weight))
            current_cluster = [samples[i]]
            
    # Finalize last cluster
    mode_depth = sum(current_cluster) / len(current_cluster)
    mode_weight = len(current_cluster) / 4.0
    modes.append((mode_depth, mode_weight))
    
    return modes
```

### Parameters
*   **Number of samples:** 4 [S1].
*   **Clustering threshold ($\epsilon$):** "A small constant" [S1]. Not given in the sources. [G] A value relative to the depth precision or scene scale is required.

### Edge Cases and Pitfalls
*   **Single Mode:** In the common case where a segment hits a single continuous surface, all four depth values are close to each other, resulting in a single mode with weight 1.0 [S1].
*   **Multiple Modes:** Multiple modes only occur for light rays that terminate on depth discontinuities as seen from the light [S1].
*   **Precision:** The method relies on the ability to distinguish depth values. If the clustering threshold is too large, distinct occluders may be merged, causing overestimation of visibility [G].

## Operating characteristics
*   **Complexity:** The prefiltering step adds a constant overhead (4 samples and clustering) per integration interval. The insertion into the termination depths structure scales with the number of modes (typically 1, occasionally >1) [S1].
*   **Performance:** Compared to basic Riemann sums, which require approximately 10x the number of samples for equal visual quality, Visibility Prefiltering reduces the required number of light rays significantly [S1]. It converts correlated artifacts to less objectionable noise, similar to Monte Carlo sampling, but with fewer rays [S1].
*   **Visual Quality:** The improvements are particularly noticeable in animated sequences, where correlated artifacts manifest as flickering, while differences are hard to spot in still images [S1].
*   **Limitations:** It does not eliminate aliasing entirely but mitigates its visual impact. It is specific to the hierarchical shadowing context and relies on the underlying termination depths structure [G].

## Background
Visibility Prefiltering was introduced in the context of hierarchical volumetric shadow algorithms for single scattering [S1]. The general idea is similar to shadow mapping techniques that store depth distributions to enable linear filtering of shadow maps [S1]. It addresses the limitation of Riemann sums in volumetric integration, which produce correlated artifacts unless a very large number of samples is used [S1].
