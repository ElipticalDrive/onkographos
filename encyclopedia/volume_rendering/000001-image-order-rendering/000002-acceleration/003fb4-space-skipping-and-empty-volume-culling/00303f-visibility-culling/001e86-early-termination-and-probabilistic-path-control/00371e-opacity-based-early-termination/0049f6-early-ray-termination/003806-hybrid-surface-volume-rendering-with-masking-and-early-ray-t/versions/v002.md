# Hybrid Surface-Volume Rendering with Masking and Early Ray Termination

Also called: Fast Surface and Volume Rendering Based on Shear-Warp Factorization, Masking in Sheared Image Space, Spine Biopsy Simulator (SBS) rendering method

## Overview
This method accelerates the hybrid rendering of a volume-rendered organ and a surface-rendered instrument by combining early ray termination for the volume data with spatial masking in the sheared image space for the instrument [S1, S2]. It solves the performance bottleneck of real-time surgical simulators where a moving instrument must be composited over a large volume dataset [S1, S2]. Unlike standard early ray termination which only stops volume traversal, this method explicitly tracks the instrument's motion in 2D sheared space to limit recomputation to only the affected pixels, achieving speed-ups of up to 2.84x compared to full recomputation [S1, S2].

## How it works
### Inputs and Outputs
**Inputs:**
- Volume dataset: 3D array of voxel values, typically sized $256 \times 256 \times 256$ [S1, S2].
- Instrument geometry: Surface model defined by vertices $(x, y, z)$ [S1, S2].
- View parameters: View direction defined by angles $(\theta, \phi)$ [S1, S2].
- Previous frame state: Previous mask $N_{t-1}(u,v)$ [S1, S2].

**Outputs:**
- Combined image $C(K,v)$ containing the volume-rendered organ and the surface-rendered instrument [S1, S2].

### Data Structures
1. **Volume Data:** 3D array of voxel values [S1, S2].
2. **Instrument Geometry:** List of vertices $(x, y, z)$ and surface normals/faces [S1, S2].
3. **Mask $N_t(u,v)$:** 2D binary array of size equal to the image resolution. $N_t(u,v) = 1$ if the pixel $(u,v)$ requires update (instrument present or changed), $0$ otherwise [S1, S2].
4. **Shear Coefficients:** $s_x = \tan\theta$, $s_y = \tan\phi$ [S1, S2].
5. **Accumulated Opacity $a_{acc}(u,v)$:** 2D array storing the accumulated opacity of the volume ray traversal up to the termination point [S1, S2].

### Numbered Steps

1. **Calculate Shear Coefficients:** Determine the shear coefficients based on the view direction $(\theta, \phi)$ [S1, S2]. The first rotation is counterclockwise about the y-axis by $\theta$, and the second is counterclockwise about the x-axis by $\phi$ [S1, S2]:
   $$ s_x = \tan\theta $$
   $$ s_y = \tan\phi $$

2. **Transform Instrument to Sheared Space:** Transform the instrument's 3D geometry $(x, y, z)$ into the 3D sheared space $(x_s, y_s, z_s)$ using an affine transform matrix for shear [S1, S2]. This allows the depth of the instrument to be represented simply by the z-coordinate in the sheared space [S1, S2].

3. **Update Mask:** Determine the region of the image that needs updating based on the instrument's motion [S1, S2].
   - If the instrument position changes, identify the pixels $(u,v)$ where the instrument exists at time $t$ [S1, S2].
   - Update the mask $N_t(u,v)$ using binary OR with the previous mask $N_{t-1}(u,v)$ [S1, S2]:
     $$ N_t(u,v) = N_{t-1}(u,v) \text{ OR } N_t(u,v) \quad \text{if the instrument exists at } (u,v) \text{ at time } t $$
     $$ N_t(u,v) = N_{t-1}(u,v) \quad \text{otherwise} $$
   - This ensures that once a pixel is marked as requiring an update, it remains marked until the viewer position changes or the mask is reset [S1, S2].

4. **Volume Rendering with Early Ray Termination:** For each pixel $(u,v)$ in the image:
   - If $N_t(u,v) == 1$, perform ray casting through the volume [S1, S2].
   - Terminate the ray when the accumulated opacity exceeds a given threshold OR when the ray intersects the surface of the instrument [S1, S2].
   - Assume instrument opacity is 1; once the ray meets the instrument, no further volume computation is needed for that ray [S1, S2].
   - Calculate the depth of the organ intersection $d_{org}$ and the accumulated opacity $a_{acc}(u,v)$ up to the termination point $Z_B(u,v)$ [S1, S2].

5. **Depth Comparison:** Compare the depth of the instrument $d_2$ (in the 3D sheared space, $d_2 = z_s$) with the depth of the organ $d_{org}$ (Euclidean distance $d_1$ or sheared depth) [S1, S2].
   - If the organ depth is longer than the instrument depth, the instrument is in front of the organ [S1, S2].
   - The depth $d_2$ is used instead of Euclidean distance $d_1$ to reduce computation time [S1, S2].
   - Euclidean distance is defined as:
     $$ d_1 = \sqrt{d_x^2 + d_y^2 + d_z^2} $$
     where $d_x, d_y, d_z$ are distances along the axes between the voxel and the pixel [S1, S2].

6. **Composite Instrument and Volume:** Combine the surface-rendered instrument image $f_{inst}(u,v)$ with the volume-rendered organ image $I_{org}(u,v)$ using alpha-blending [S1, S2]. The instrument's contribution is weighted by the remaining accumulated opacity of the organs [S2]. Sources differ on the exact weighting formula; S1 proposes $C(K,v) = f_{inst}(u,v) + (1 - a_{inst}(u,v)) \cdot I_{org}(u,v) / a_{acc}(u,v)$, while S2 uses $C(K,v) = f_{inst}(u,v) + I_{org}(u,v) \cdot (1 - a_{acc}(u,v))$ [S1, S2].
   Where:
   - $C(K,v)$ is the combined image pixel [S1, S2].
   - $f_{inst}(u,v)$ is the pixel value of the 2D instrument image [S1, S2].
   - $I_{org}(u,v)$ is the pixel value of the volume-rendered organ image from ray traversal up to $Z_B(u,v)$ [S1, S2].
   - $a_{acc}(u,v)$ is the accumulated opacity of the organs [S1, S2].
   - As $a_{acc}(u,v)$ increases, the weight of the instrument decreases [S1, S2].

import math

def hybrid_render(volume_data, instrument_geometry, view_theta, view_phi, prev_mask, image_width, image_height, threshold=0.95):
    # 1. Calculate Shear Coefficients
    s_x = math.tan(view_theta)
    s_y = math.tan(view_phi)

    # 2. Transform Instrument to Sheared Space
    # Apply shear transformation: x_s = x + s_x * z, y_s = y + s_y * z, z_s = z
    instrument_sheared = []
    for vertex in instrument_geometry:
        x, y, z = vertex
        instrument_sheared.append((x + s_x * z, y + s_y * z, z))

    # 3. Update Mask
    # Determine current instrument projection in 2D image space
    current_instrument_pixels = get_instrument_pixel_mask(instrument_sheared, image_width, image_height)
    # Binary OR with previous mask
    new_mask = [[prev_mask[v][u] | current_instrument_pixels[v][u] for u in range(image_width)] for v in range(image_height)]

    # 4. Initialize Output Image
    combined_image = [[(0.0, 0.0, 0.0) for _ in range(image_width)] for _ in range(image_height)]

    # 5. Render Pixels
    for v in range(image_height):
        for u in range(image_width):
            if new_mask[v][u] == 0:
                continue

            # Ray casting through volume
            accumulated_opacity = 0.0
            organ_color = [0.0, 0.0, 0.0]
            termination_depth = float('inf')
            instrument_hit = False

            # Traverse ray through volume
            for sample_depth in range(0, 100, 1):
                # Check for instrument intersection
                if check_instrument_intersection(u, v, sample_depth, instrument_sheared):
                    termination_depth = sample_depth
                    instrument_hit = True
                    break

                # Early termination condition
                if accumulated_opacity > threshold:
                    termination_depth = sample_depth
                    break

                # Volume compositing (front-to-back)
                color, opacity = sample_volume_color(volume_data, u, v, sample_depth)
                weight = (1.0 - accumulated_opacity) * opacity
                organ_color = [organ_color[i] + color[i] * weight for i in range(3)]
                accumulated_opacity += weight

            # Get instrument color if it was in front
            instrument_color = get_instrument_color_at_depth(u, v, termination_depth, instrument_sheared) if instrument_hit else None

            # 6. Composite
            if instrument_color is not None:
                remaining_opacity = 1.0 - accumulated_opacity
                combined_image[v][u] = [
                    instrument_color[i] + organ_color[i] * remaining_opacity for i in range(3)
                ]
            else:
                combined_image[v][u] = organ_color

    return combined_image, new_mask

def get_instrument_pixel_mask(instrument_sheared, width, height):
    mask = [[0 for _ in range(width)] for _ in range(height)]
    if not instrument_sheared:

    min_x = min(v[0] for v in instrument_sheared)
    max_x = max(v[0] for v in instrument_sheared)

### Parameters
- **Threshold:** Accumulated opacity threshold for early ray termination. Not given in the sources.
- **Data Size:** $256 \times 256 \times 256$ voxels [S1, S2].
- **Hardware:** 400-MHz Pentium PC with 256 MB memory [S1, S2].

### Edge Cases and Pitfalls
- **Overhead:** Rendering time does not decrease proportionally to the voxel count reduction because the compositing function has overheads, such as determining the masking region and the voxel-skipping procedure with ray termination in the intermediate image [S1, S2].
- **Resampling:** The shear-warp algorithm involves two resampling steps: every slice is resampled during compositing, and the intermediate image is resampled [S1, S2].
- **Viewer Position Change:** The mask is only updated based on instrument motion. If the viewer's position changes, the mask must be reset or recomputed for the entire image [S1, S2].

## Operating characteristics
- **Time Complexity:** The method reduces the number of voxels contributing to volume rendering from ~2,650,000 to ~20,000-35,000 (about 1% of the total) when the instrument moves 7.03 mm in x- and z-directions [S1, S2].
- **Measured Performance:**
  - **Torso Scene (Skin, Lung, Spine):** Color rendering time reduced from 0.91 s to 0.32 s (2.84x faster) [S1, S2].
  - **Spine Only Scene (Half Needle Overlap):** Color rendering time reduced from 0.36 s to 0.22 s (1.64x faster) [S1, S2].
- **Strengths:** Significant speed-up for hybrid rendering of moving instruments over large volumes. Effective for simulators requiring real-time feedback [S1, S2].
- **Limitations:** Speed-up is limited by the overhead of mask management and shear-warp resampling. Performance gain decreases when the volume rendering region is smaller (e.g., spine only vs. full torso) [S1, S2].
- **When to Use:** Real-time surgical simulators or medical training systems where a surface-rendered instrument (e.g., needle) must be interactively moved over a volume-rendered organ dataset [S1, S2].
- **When Not to Use:** Static scenes where the instrument does not move, or scenes where the viewer position changes frequently, as the mask optimization becomes less effective or requires full recomputation [S1, S2].

## Background
This method was developed for the Spine Biopsy Simulator (SBS) system, which helps medical students train for spine biopsy procedures virtually [S1, S2]. The system combines volume-rendered organs and a surface-rendered needle image to provide realistic visualization and haptic feedback [S1, S2]. The approach leverages the shear-warp factorization algorithm for fast volume rendering and extends it with masking and early ray termination to handle the dynamic instrument [S1, S2].
