# Ray Marching with Dithering and Early Termination

Also called: Dithered Ray Marching with Early Termination

## Overview
This method performs volume rendering by marching rays through a volume dataset, applying dithering to the ray start position to mitigate aliasing artifacts, and using an early termination condition to skip computation in opaque regions. It is distinguished from standard ray marching by the explicit addition of stochastic dithering to the integration path and a hard opacity threshold for loop breakage, offering a trade-off between visual smoothness and rendering performance. It builds on [Early Termination and Probabilistic Path Control](1791-early-termination-and-probabilistic-path-control.md).

## How it works
**Inputs:**
*   Volume texture (`voltex`): 3D texture containing scalar density/intensity values.
*   Transfer function texture (`tftex`): 2D texture mapping intensity to RGBA color.
*   Normal matrix: 3x3 matrix for transforming normals from object to world space.
*   Screen dimensions: `screen_width`, `screen_height`.
*   Ray start (`start`) and end (`end`) positions in world space.
*   Number of samples (`nsamples`).
*   Shading mode (0: Blinn-Phong, 1: Blinn-Phong + Edge Enhancement, 2: Toon, 3: None).

**Outputs:**
*   Final accumulated color (`outcolor`) and alpha.

**Data Structures:**
*   `pos`: Current ray position (vec3).
*   `delta`: Step vector (vec3).
*   `color`: Sampled color from transfer function (vec4).
*   `outcolor`: Accumulated color (vec4).
*   `N`: Surface normal (vec3).

**Parameters:**
*   `SHADING_THRES`: 0.10. Minimum alpha to trigger shading computation [S1, unofficial].
*   `DELTA`: 0.005. Offset for gradient central difference calculation [S1, unofficial].
*   Early termination threshold: 0.95. If accumulated alpha exceeds this, the loop breaks [S1, unofficial].

**Steps:**
1.  **Initialization:**
    *   Calculate normalized screen coordinates: `norm_coord = gl_FragCoord.st / vec2(screen_width, screen_height)`.
    *   Calculate ray direction: `direction = end - start`.
    *   Calculate ray length: `len = length(direction)`.
    *   Calculate step size: `stepsize = len / nsamples`.
    *   Normalize direction: `direction = normalize(direction)`.
    *   Calculate delta vector: `delta = direction * stepsize`.
    *   Apply dithering to the starting position to hide aliasing: `pos = start + delta * rand()`, where `rand()` is a uniform random number in $[0, 1)$ [S1, unofficial].
    *   Initialize loop variables: `pos = start`, `outcolor = vec4(0.0)`, `color = vec4(0.0)`.

2.  **Ray Marching Loop:**
    *   Iterate `i` from 0 to `nsamples` while `len > 0`:
        *   Increment position: `pos = pos + delta`.
        *   Decrement remaining length: `len = len - stepsize`.
        *   Sample volume intensity: `intensity = texture(voltex, pos).r`.
        *   Map intensity to color via transfer function: `color = texture(tftex, intensity)`.
        *   **Shading (Conditional):**
            *   If `color.a > SHADING_THRES` (0.10) AND `shading_mode != 3` AND `nsamples > 500`:
                *   Compute normal using central differences: `N = gradient_central_diff(pos, DELTA)`.
                *   Transform normal to world space: `N = normalize(vec3(normalmatrix * N))`.
                *   Calculate light vector `L` and view vector `V` in world space.
                *   Apply shading based on `shading_mode`:
                    *   Mode 0: Blinn-Phong.
                    *   Mode 1: Blinn-Phong + Edge Enhancement.
                    *   Mode 2: Toon shading.
                *   Update `color` with shaded result.
        *   **Compositing:**
            *   Apply compositing based on `shading_mode` (or specific compositing mode if separate):
                *   Mode 0: Front-to-Back blending:
                    $$ C_{acc} = C_{acc} + C_{sample} \cdot \alpha_{sample} \cdot (1 - \alpha_{acc}) $$
                    $$ \alpha_{acc} = \alpha_{acc} + \alpha_{sample} \cdot (1 - \alpha_{acc}) $$
                *   Mode 1: Maximum Intensity Projection (MIP).
                *   Mode 2: Minimum Intensity Projection (MIDA).
        *   **Early Termination:**
            *   If `outcolor.a > 0.95`, break the loop [S1, unofficial].

3.  **Final Output:**
    *   Return `outcolor`.

**Pseudocode:**
```python
def ray_march_dithered_early_term(start, end, nsamples, voltex, tftex, normal_matrix, shading_mode):
    # 1. Initialization
    direction = end - start
    length = length(direction)
    stepsize = length / nsamples
    direction = normalize(direction)
    delta = direction * stepsize
    
    # Dithering: offset start position by random fraction of step
    # rand() returns uniform float in [0, 1)
    pos = start + delta * rand()
    
    outcolor = vec4(0.0)
    
    # 2. Loop
    for i in range(nsamples):
        if length <= 0:
            break
            
        pos = pos + delta
        length = length - stepsize
        
        # Sample volume
        intensity = texture(voltex, pos).r
        color = texture(tftex, intensity)
        
        # Shading logic
        if color.a > 0.10 and shading_mode != 3 and nsamples > 500:
            # Compute normal via central difference
            N = gradient_central_diff(pos, 0.005)
            # Transform to world space
            N = normalize(vec3(normal_matrix * N))
            
            # Calculate L and V (implementation depends on scene lights/camera)
            L = ... 
            V = ...
            
            # Apply shading
            if shading_mode == 0:
                color = blinn_phong(color, N, L, V)
            elif shading_mode == 1:
                color = blinn_phong_edge(color, N, L, V)
            elif shading_mode == 2:
                color = toon_shading(color, N, L, V)
        
        # Compositing
        if shading_mode == 0:
            # Front-to-Back
            outcolor = outcolor + color * color.a * (1.0 - outcolor.a)
            outcolor.a = outcolor.a + color.a * (1.0 - outcolor.a)
        elif shading_mode == 1:
            # MIP
            if color.r > outcolor.r:
                outcolor = color
        elif shading_mode == 2:
            # MIDA
            if color.r < outcolor.r:
                outcolor = color
                
        # Early Termination
        if outcolor.a > 0.95:
            break
            
    return outcolor
```

## Subtopics

## Operating characteristics
*   **Time Complexity:** $O(N)$ per ray, where $N$ is the number of samples. Early termination reduces the average number of samples per ray, particularly in opaque regions.
*   **Memory Complexity:** $O(1)$ additional memory per ray (excluding texture storage).
*   **Performance:** Reduces rendering time by skipping shading and compositing calculations for rays that have already reached high opacity. The dithering adds negligible computational cost but requires a random number generator.
*   **Strengths:** Reduces staircase aliasing artifacts caused by undersampling. Improves performance in dense volumes.
*   **Limitations:** Does not prevent aliasing from the transfer function or shading discontinuities. The early termination threshold (0.95) introduces bias by discarding contributions from deeper, potentially visible structures. The condition `nsamples > 500` for shading may lead to inconsistent visual quality if `nsamples` varies dynamically.
*   **When to use:** When visual smoothness is prioritized over perfect accuracy, and performance is a concern in dense volumes. Suitable for real-time applications where shading is expensive.
*   **When not to use:** When accurate quantitative visualization is required (early termination discards data). When the volume is sparse (early termination provides little benefit). When shading artifacts are the primary concern (dithering does not fix transfer function aliasing).

## Background
This method is implemented in the `qvrc` project, a Qt-based volume rendering application. It leverages OpenGL Shader Model 3.0 features for dynamic branching within the fragment shader. The technique combines standard ray marching with specific optimizations for interactive visualization, including dithering to handle undersampling and early termination for performance. The specific parameters (shading threshold 0.10, gradient delta 0.005, termination threshold 0.95) are derived from the implementation details of this software.
