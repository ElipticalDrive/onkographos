# Ray Marching with Dithering and Early Termination

Also called: Dithered Ray Marching with Early Termination

## Overview
This method performs volume rendering by marching rays through a volume dataset, applying shading and compositing in a single pass, while using dithering to reduce aliasing artifacts and early termination to improve performance [S1, unofficial]. It is distinguished from its siblings by its specific implementation of a fixed-step ray marcher that integrates shading calculations (such as normals and lighting) directly within the accumulation loop, rather than relying solely on opacity thresholds for termination [S1, unofficial]. Unlike [Empty-space skipping](1002-empty-space-skipping.md) which skips empty regions, this method samples every step but skips expensive shading computations when opacity is low [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Volume texture (`voltex`), Transfer Function texture (`tftex`), Camera matrices (Projection, Model, View), Screen dimensions (`screen_width`, `screen_height`), Ray start/end points, Number of samples (`nsamples`).
*   **Output:** Final color buffer (`outcolor`).

**Data Structures:**
*   `voltex`: 3D texture storing volume intensity (scalar field).
*   `tftex`: 1D or 2D texture storing the transfer function mapping intensity to RGBA color.
*   `outcolor`: Accumulated color and opacity vector `vec4`.

**Parameters:**
*   `SHADING_THRES`: 0.10 [S1, unofficial].
*   `DELTA`: 0.005 (gradient step size) [S1, unofficial].
*   `Early Termination Threshold`: 0.95 (accumulated opacity) [S1, unofficial].
*   `nsamples`: Number of steps per ray. If `nsamples <= 500`, shading is disabled [S1, unofficial].

**Steps:**
1.  **Ray Setup:** Calculate normalized screen coordinates `norm_coord = gl_FragCoord.st / vec2(screen_width, screen_height)`. Determine ray direction `direction = end - start` and length `len = length(direction)`. Calculate step size `stepsize = len / nsamples`. Normalize direction and compute delta vector `delta = direction * stepsize`.
2.  **Dithering:** Apply dithering to the starting position to hide staircase aliasing: `pos = start + delta * rand()`, where `rand()` is a random value in $[0, 1)$ [S1, unofficial].
3.  **Initialization:** Initialize loop variables: `pos = start`, `outcolor = vec4(0.0)`, `color = vec4(0.0)`.
4.  **Marching Loop:** Iterate `i` from 0 to `nsamples` while `len > 0`:
    a.  **Advance:** Increment position `pos = pos + delta`. Decrement remaining length `len = len - stepsize`.
    b.  **Sample:** Sample volume intensity `intensity = texture(voltex, pos).r`.
    c.  **Transfer Function:** Map intensity to color `color = texture(tftex, intensity)`.
    d.  **Shading (Conditional):** If `color.a > SHADING_THRES` AND `shading_mode != 3` AND `nsamples > 500`:
        i.  Compute normal using central differences with `DELTA`: `N = gradient_central_diff(pos, DELTA)`.
        ii. Transform normal to world space: `N = normalize(vec3(normalmatrix * N))`.
        iii. Calculate light vector `L` and view vector `V` in world space.
        iv. Apply shading based on `shading_mode`: 0 (Blinn-Phong), 1 (Blinn-Phong + Edge Enhancement), or 2 (Toon) [S1, unofficial].
    e.  **Compositing:** Update `outcolor` using the selected compositing mode: 0 (Front-to-Back), 1 (Maximum Intensity Projection - MIP), or 2 (MIDA) [S1, unofficial].
    f.  **Early Termination:** If `outcolor.a > 0.95`, break the loop [S1, unofficial].

**Pseudocode:**
```python
def ray_march_dithered_early_term(start, end, nsamples, voltex, tftex, normalmatrix, shading_mode):
    # 1. Ray Setup
    direction = end - start
    len = length(direction)
    stepsize = len / nsamples
    direction = normalize(direction)
    delta = direction * stepsize
    
    # 2. Dithering
    # rand() returns a uniform random float in [0, 1)
    pos = start + delta * rand()
    
    # 3. Initialization
    outcolor = vec4(0.0)
    
    # 4. Marching Loop
    for i in range(nsamples):
        if len <= 0:
            break
            
        # a. Advance
        pos = pos + delta
        len = len - stepsize
        
        # b. Sample
        intensity = sample_volume(voltex, pos) # texture(voltex, pos).r
        
        # c. Transfer Function
        color = sample_transfer_function(tftex, intensity) # texture(tftex, intensity)
        
        # d. Shading (Conditional)
        if color.a > 0.10 and shading_mode != 3 and nsamples > 500:
            # Compute normal using central differences
            N = compute_normal_central_diff(pos, voltex, delta=0.005)
            # Transform to world space
            N = normalize(vec3(normalmatrix * vec4(N, 0.0)))
            
            # Calculate L and V (implementation depends on light/camera setup)
            L = compute_light_vector(pos)
            V = compute_view_vector(pos)
            
            # Apply shading
            if shading_mode == 0:
                color.rgb = blinn_phong(N, L, V, color.rgb)
            elif shading_mode == 1:
                color.rgb = blinn_phong_edge(N, L, V, color.rgb)
            elif shading_mode == 2:
                color.rgb = toon_shading(N, L, V, color.rgb)
        
        # e. Compositing
        if shading_mode == 0:
            # Front-to-Back
            outcolor = outcolor + color * (1.0 - outcolor.a)
        elif shading_mode == 1:
            # MIP
            outcolor = max(outcolor, color)
        elif shading_mode == 2:
            # MIDA (Not fully specified in source, assumed similar to FTFB or specific variant)
            # [G] Assuming standard front-to-back for MIDA if not specified, 
            # but source lists it as a mode. Without formula, we note the mode.
            outcolor = outcolor + color * (1.0 - outcolor.a) # Placeholder for MIDA logic if identical to FTFB
            
        # f. Early Termination
        if outcolor.a > 0.95:
            break
            
    return outcolor

def sample_volume(tex, pos):
    # Returns the red channel (intensity) of the 3D texture
    return tex[pos].r

def sample_transfer_function(tex, intensity):
    # Returns the RGBA color from the transfer function texture
    return tex[intensity]

def compute_normal_central_diff(pos, tex, delta):
    # Central difference gradient
    grad_x = (sample_volume(tex, pos + vec3(delta, 0, 0)) - sample_volume(tex, pos - vec3(delta, 0, 0))) / (2 * delta)
    grad_y = (sample_volume(tex, pos + vec3(0, delta, 0)) - sample_volume(tex, pos - vec3(0, delta, 0))) / (2 * delta)
    grad_z = (sample_volume(tex, pos + vec3(0, 0, delta)) - sample_volume(tex, pos - vec3(0, 0, delta))) / (2 * delta)
    return vec3(grad_x, grad_y, grad_z)
```

**Edge Cases and Pitfalls:**
*   **Aliasng:** Dithering hides woodgrain/staircase aliasing from undersampling but does not prevent aliasing from the transfer function or shading calculations [S1, unofficial].
*   **Shading Performance:** Shading is skipped if `nsamples <= 500` to maintain performance, which may result in flat shading for low-resolution renders [S1, unofficial].
*   **Termination Bias:** Early termination at 0.95 opacity introduces systematic bias by ignoring the ray tail, similar to [Early Stop](1790-early-stop.md) [S1, unofficial].

## Subtopics

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of samples per ray, but effectively reduced by early termination. Shading computation is $O(1)$ per sample but conditional.
*   **Memory Complexity:** $O(1)$ per ray for accumulation variables. Volume texture storage is external.
*   **Performance:** Early termination significantly speeds up rendering for opaque volumes. Dithering adds negligible computational cost but requires a random number generator.
*   **Strengths:** Reduces aliasing artifacts (staircasing) without increasing sample count. Combines shading and compositing in a single pass.
*   **Limitations:** Early termination introduces bias. Dithering does not fix transfer function aliasing. Shading is disabled for low sample counts.
*   **When to Use:** Real-time volume rendering where aliasing is visible and performance is critical. Suitable for dynamic volumes [S1, unofficial].
*   **When Not to Use:** When unbiased results are required (early termination is biased). When high-frequency details in the transfer function need to be preserved without aliasing.

## Background
This method is implemented in the `qvrc` project by Fargiolas [S1, unofficial]. It leverages Shader Model 3.0 features to perform ray marching within the fragment shader, supporting dynamic volumes composed of overlapping spherical sources [S1, unofficial]. It extends Krüger’s method by integrating shading and compositing modes (Blinn-Phong, MIP, MIDA) directly into the ray march loop [S1, unofficial].
