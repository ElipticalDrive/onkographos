# Free Space Skipping

Also called: Coarse/Fine Density Threshold Skipping, Training-Time Bounding Box, Two-stage Free Space Skipping

## Overview
Free space skipping is an acceleration technique for volume rendering that avoids computing expensive view-dependent color models for points located in transparent or low-density regions of the scene [S1, S2]. It operates by querying a hierarchy of density representations—typically a coarse voxel grid followed by a fine voxel grid—and discarding samples where the activated alpha falls below specific thresholds [S1, S2].

## How it works
**Inputs:**
*   Ray origin $\mathbf{x}_0$ and direction $\mathbf{d}$ [S2].
*   Coarse density voxel grid $V^{(\text{density})}_{(c)}$ [S1].
*   Fine density voxel grid $V^{(\text{density})}_{(f)}$ [S1].
*   Thresholds $\tau^{(c)}$ and $\tau^{(f)}$ [S1].
*   Bounding box (BBox) of the scene [S2].

**Outputs:**
*   A set of valid sample points $\{\mathbf{x}_i\}$ for which the view-dependent color model must be evaluated [S1].

**Data Structures:**
*   $V^{(\text{density})}_{(c)}$: A 3D tensor storing density values. Access is performed via trilinear interpolation [S2].
*   $V^{(\text{density})}_{(f)}$: A 3D tensor storing higher-resolution density values. Access is performed via trilinear interpolation [S2].

**Parameters:**
*   $\tau^{(c)}$: Coarse threshold. Typical value: $10^{-3}$ [S1].
*   $\tau^{(f)}$: Fine threshold. Typical value: $10^{-4}$ [S1].

**Algorithm:**
1.  **Ray-BBox Intersection:** Determine the intersection interval $[t_{\text{near}}, t_{\text{far}}]$ of the ray with the scene BBox [S2]. If the ray origin $\mathbf{x}_0$ is already inside the BBox, $t_{\text{near}}$ remains $0$ and $t_{\text{far}}$ is the exit distance [S2]. Otherwise, $t_{\text{near}}$ and $t_{\text{far}}$ are the entry and exit distances [S2].
2.  **Ray Filtering:** Filter out rays that do not intersect the known free space (the BBox or region defined by the coarse grid) [S2].
3.  **Sampling Loop:** For each sample point $\mathbf{x}$ along the ray within $[t_{\text{near}}, t_{\text{far}}]$:
    a.  **Coarse Check:** Query the coarse density grid $V^{(\text{density})}_{(c)}$ at $\mathbf{x}$ to obtain density $\sigma_c$ [S1].
    b.  **Coarse Skip:** If the activated alpha derived from $\sigma_c$ is less than $\tau^{(c)}$, skip this point (treat as known free space) [S1].
    c.  **Fine Check:** If the coarse check passes, query the fine density grid $V^{(\text{density})}_{(f)}$ at $\mathbf{x}$ to obtain density $\sigma_f$ [S1].
    d.  **Fine Skip:** If the activated alpha derived from $\sigma_f$ is less than $\tau^{(f)}$, skip this point (filters unknown space with low activation) [S1, S2].
    e.  **Color Evaluation:** If both checks pass, query the view-dependent color model for the color and opacity at $\mathbf{x}$ [S1].

**Pseudocode:**
```python
def free_space_skip_ray(x0, d, bbox_min, bbox_max, V_coarse, V_fine, V_color, tau_c, tau_f, step_size):
    # 1. Ray-BBox Intersection (Slab method)
    t_min, t_max = 0.0, float('inf')
    for i in range(3):
        if d[i] == 0:
            if x0[i] < bbox_min[i] or x0[i] > bbox_max[i]:
                return []
        else:
            t1 = (bbox_min[i] - x0[i]) / d[i]
            t2 = (bbox_max[i] - x0[i]) / d[i]
            t_min = max(t_min, min(t1, t2))
            t_max = min(t_max, max(t1, t2))
            
    if t_min > t_max or t_max < 0:
        return []
        
    # Adjust t_near if origin is inside bbox [S2]
    inside = all(bbox_min[i] <= x0[i] <= bbox_max[i] for i in range(3))
    t_near = 0.0 if inside else t_min
    t_far = t_max
    
    valid_points = []
    t = t_near
    while t <= t_far:
        x = x0 + t * d
        
        # 2a. Coarse Check
        sigma_c = V_coarse(x)
        if sigma_c < tau_c:
            t += step_size
            continue
            
        # 2b. Fine Check
        sigma_f = V_fine(x)
        if sigma_f < tau_f:
            t += step_size
            continue
            
        # 2c. Color Evaluation
        color = V_color(x)
        valid_points.append((x, color))
        
        t += step_size
        
    return valid_points
```

**Edge Cases and Pitfalls:**
*   **Zero Thresholds:** Setting $\tau^{(c)} = 0$ and $\tau^{(f)} = 0$ disables skipping, leading to out-of-memory (OOM) errors during the fine stage due to excessive memory usage [S1].
*   **Quality Degradation:** Setting $\tau^{(c)} = 0$ while keeping $\tau^{(f)} > 0$ degrades rendering quality because the coarse stage's priors are ignored [S1].
*   **Initialization Conflict:** Low-density initialization and free space skipping cannot be applied simultaneously [S1].
*   **Precision:** The thresholds $\tau^{(c)}$ and $\tau^{(f)}$ must be chosen carefully; too high values may clip valid geometry, while too low values reduce acceleration benefits [S1].

## Subtopics

### Coarse/Fine Density Threshold Skipping
The primary implementation using two distinct voxel grids [S1]. It applies thresholds to both coarse and fine density grids to filter samples [S1].

### Two-stage Free Space Skipping
Refers to the sequential filtering process where points are first checked against the coarse grid and then the fine grid [S1]. It improves fine-stage efficiency during training and testing [S1].

### Training-Time Bounding Box
Adjusts the ray near- and far-bounds to the intersection endpoints with the scene BBox, skipping rays that do not intersect [S2].

## Operating characteristics
*   **Time Complexity:** The coarse grid query is faster than the fine grid query, which is faster than querying the view-dependent color model [S1, S2]. Free space skipping improves fine-stage efficiency in both training and testing [S1].
*   **Memory Complexity:** Reduces memory consumption by skipping points in free space, preventing out-of-memory errors when thresholds are properly set [S1].
*   **Strengths:** Removes irrelevant samples in transparent regions; improves training efficiency [S1].
*   **Limitations:** Requires careful threshold tuning; low-density initialization and free space skipping cannot be applied simultaneously [S1].
*   **When to use:** Scenes with significant transparent/empty space using voxel-based representations [S1].
*   **When not to use:** Fully opaque scenes or when memory is unconstrained [S1].

## Background
Free space skipping was introduced in Direct Voxel Grid Optimization by Sun et al. in 2022 [S1]. It addresses the computational bottleneck of querying view-dependent color models for every sample point [S1]. By leveraging efficient voxel grid lookups, it enables super-fast convergence in radiance field reconstruction [S1]. It is primarily used in neural rendering pipelines utilizing multi-resolution voxel grids [S1].
