# Empty-space skipping

Also called: Block Empty Space Skipping, Chebyshev Empty Space Skipping, Empty Region Skipping, Occupancy Grid Pruning

## Overview
Empty-space skipping is a ray-marching acceleration technique that minimizes computation by skipping the sampling of empty space in a volumetric dataset, using a bounding primitive hull or hierarchical data structure to limit ray traversal [S2, S3, S4, unofficial]. It sets itself apart from its siblings like [Early Stop](1790-early-stop.md) and [Russian Roulette](1371-russian-roulette.md) by physically jumping over regions of zero or negligible density rather than terminating the ray based on accumulated opacity or probabilistic survival [S3, S4, unofficial]. Unlike [Bounding Volume Culling](1239-bounding-volume-culling.md) which typically only culls the entry and exit of the volume, empty-space skipping can skip internal voids, effectively reducing the number of samples evaluated by orders of magnitude in sparse scenes [S5, unofficial][S11].

## How it works
**Inputs and Outputs:**
*   **Input:** Ray origin $\mathbf{o}$, ray direction $\mathbf{d}$ (normalized), volume dataset $V$, and an acceleration structure encoding empty space (e.g., occupancy grid, distance map, or octree) [S3, S6, unofficial].
*   **Output:** Accumulated color $C_{acc}$ and opacity $\alpha_{acc}$ for the pixel.

**Data Structures:**
The acceleration structure varies by variant. Common layouts include:
1.  **Occupancy Grid / Distance Map:** A 3D texture or array where each voxel stores a binary flag (occupied/empty) or a distance value to the nearest occupied voxel [S3, S4, unofficial]. In [S3, unofficial], `texOccupancyMap` and `texDistanceMap` are accessed via `texelFetch`.
2.  **Octree:** Nodes store conservative min/max scalar value estimates or occupancy flags for their bounding box [S6, S10, unofficial].
3.  **Brick Classification:** An array of 32-bit integers, one per brick, storing state (empty, saturated, sampled) [S12].

**Algorithm Steps:**
The core loop modifies standard front-to-back ray marching by inserting a skip check.

1.  **Initialization:**
    *   Compute the step vector $\mathbf{s}$ and total number of steps $N$ based on volume dimensions and sampling factor [S3, unofficial]:
        $$ N = \lceil \text{dim}_{\max} \cdot \|\mathbf{d}\| \cdot \text{sampling\_factor} \rceil $$
        $$ \mathbf{s} = \frac{\mathbf{d} \cdot \|\mathbf{d}\|}{N - 1} $$
    *   Initialize accumulated color $C_{acc} = (0,0,0,0)$ and opacity $\alpha_{acc} = 0$ [Parent].
    *   Initialize loop index $i = 0$ [S3, unofficial].

2.  **Ray Marching Loop:**
    While $i < N$:
    *   **Calculate Sampling Position:**
        $$ \mathbf{p}_i = \mathbf{o} + (i + \text{random}) \cdot \mathbf{s} $$
        where `random` is a dithering value to reduce aliasing [S3, unofficial].
    *   **Empty Space Check:**
        Query the acceleration structure at $\mathbf{p}_i$ (or the current block) to determine if the region is empty.
        *   *Occupancy Grid:* Check if the occupancy value is 0 [S4, unofficial].
        *   *Distance Map:* Calculate the distance to the nearest occupied voxel. If the distance is greater than the remaining step size or a threshold, skip [S3, unofficial].
        *   *Octree:* Traverse the tree. If the current node is marked empty (e.g., min/max density does not intersect transfer function), skip the entire node [S6, S10, unofficial].
    *   **Skip Logic:**
        If the region is empty:
        *   Calculate the skip delta $\Delta i$ based on the distance to the next occupied region or the size of the empty block [S3, unofficial].
        *   Update $i \leftarrow i + \Delta i$.
        *   If backtracking is required (e.g., to ensure coverage of the boundary), clamp $i$ to a minimum valid index [S3, unofficial].
        *   Continue to next iteration.
    *   **Sampling:**
        If the region is occupied:
        *   Sample the volume intensity $v = V(\mathbf{p}_i)$ [S3, unofficial].
        *   Apply Transfer Function: Get color $C_{sample}$ and opacity $\alpha_{sample}$ from $v$ [S3, unofficial].
        *   **Compositing:**
            $$ C_{acc} = C_{acc} + C_{sample} \cdot \alpha_{sample} \cdot (1 - \alpha_{acc}) $$
            $$ \alpha_{acc} = \alpha_{acc} + \alpha_{sample} \cdot (1 - \alpha_{acc}) $$
        *   **Early Termination Check:**
            If $\alpha_{acc} > \tau$ (e.g., 0.98) or transmittance $T < \epsilon$, break loop [S3, Parent, unofficial].
        *   Increment $i \leftarrow i + 1$ [S3, unofficial].

**Pseudocode (Block/Chebyshev ESS Variant):**
This implementation follows the specific logic from [S3, unofficial], which provides a complete, implementable shader-like structure.

```python
def empty_space_skipping_raymarch(ray_origin, ray_dir, volume_texture, 
                                  occupancy_map, distance_map, 
                                  volume_size, dim_distance_map, 
                                  sampling_factor, ess_type, dithering_mode):
    """
    ray_origin: vec3
    ray_dir: vec3 (normalized)
    volume_texture: 3D texture for volume data
    occupancy_map: 3D texture for occupancy (binary)
    distance_map: 3D texture for distance to nearest occupied voxel
    volume_size: vec3 (dimensions of volume)
    dim_distance_map: vec3 (dimensions of distance/occupancy maps)
    sampling_factor: float (steps per unit length relative to max dim)
    ess_type: int (1=Block, 2=Chebyshev)
    dithering_mode: int (1=procedural, 2=texture)
    """
    
    # 1. Initialize parameters
    dim_max = max(volume_size.x, volume_size.y, volume_size.z)
    ray_length = length(ray_dir) # Usually 1.0 if normalized, but kept for generality
    
    # Calculate number of steps
    n_steps = int(ceil(float(dim_max) * ray_length * sampling_factor))
    if n_steps < 2:
        n_steps = 2
        
    step_vector = normalize(ray_dir) * ray_length / float(n_steps - 1)
    
    # Precompute distance map scaling factors
    block_size = vec3(ceil(volume_size / vec3(dim_distance_map)))
    volume_to_distance_map = volume_size / (vec3(block_size) * vec3(dim_distance_map))
    
    # Step distance in texel coordinates
    step_dist_texel = step_vector * volume_size / vec3(block_size)
    step_dist_texel_inv = 1.0 / step_dist_texel
    
    # Initialize dithering random value
    if dithering_mode == 1:
        # Procedural noise based on fragment coords (placeholder for actual shader logic)
        # In a real implementation, this would use gl_FragCoord or similar
        random = fract(sin(12.9898 + 78.233) * 43758.5453) 
    else:
        # Sample from noise texture (placeholder)
        random = 0.5 
        
    # Initialize compositing state
    out_color = vec4(0.0, 0.0, 0.0, 0.0)
    
    # Handle degenerate rays
    if ray_length == 0.0 or isnan(ray_length) or ray_length > sqrt(3.0):
        return out_color

    # 2. Ray Marching Loop
    for i in range(n_steps):
        # Calculate sampling position
        sampling_pos = ray_origin + float(i + random) * step_vector
        
        # Map to distance map coordinates
        pos_distance_map = volume_to_distance_map * sampling_pos
        u = pos_distance_map * vec3(dim_distance_map)
        u_i = ivec3(clamp(floor(u), ivec3(0), dim_distance_map - 1))
        
        # Fetch distance/occupancy value
        if ess_type == 1: # Block ESS
            dist = texelFetch(occupancy_map, u_i, 0).x
        else: # Chebyshev ESS
            dist = texelFetch(distance_map, u_i, 0).x
            
        # Calculate fractional offset for block ESS
        r = clamp(u_i - u, -1.0, 0.0)
        
        # Calculate step delta
        if ess_type == 1:
            # Block ESS: skip based on occupancy
            i_delta_xyz = (step(0.0, step_dist_texel_inv) + r) * step_dist_texel_inv
        else:
            # Chebyshev ESS: skip based on distance
            i_delta_xyz = (step(0.0, -step_dist_texel_inv) + sign(step_dist_texel_inv) * float(dist) + r) * step_dist_texel_inv
            
        # Determine integer delta to skip
        i_delta = max(1, int(ceil(min(min(i_delta_xyz.x, i_delta_xyz.y), i_delta_xyz.z))))
        
        # Check if we are in empty space (dist == 0 for occupancy, or large dist for distance map)
        # Note: In [S3, unofficial], dist=0 implies empty space for occupancy map. 
        # For distance map, dist > 0 implies distance to occupied. 
        # The logic in [S3, unofficial] uses 'dist' directly in the delta calculation.
        # If the calculated delta is small or zero, we might need to backtrack or sample.
        
        if ess_type == 1 and dist == 0:
            # Empty space detected in occupancy map
            # Apply skip
            i += i_delta
            # Handle backtracking if necessary to ensure boundary coverage
            # [S3, unofficial] mentions: i_delta_backwards = -int(ceil(sampling_factor))
            # i = max(i + i_delta_backwards, i_min)
            # For simplicity, we just skip. If i goes out of bounds, loop ends.
            continue
        elif ess_type == 2 and dist == 0:
             # Distance map indicates we are far from occupied? 
             # [S3, unofficial] logic implies dist is used to calculate delta. 
             # If dist is large, delta is large.
             i += i_delta
             continue
             
        # If not skipping, sample the volume
        # Get volume intensity
        voxel_value = get_volume_intensity(sampling_pos, volume_texture, volume_size)
        
        # Transfer function lookup
        color = texture_transfer_function(voxel_value)
        
        # Gamma correction on alpha
        color.a = pow(color.a, 2.2) # Typical gamma
        
        # Lighting (simplified)
        normal = -get_gradient(sampling_pos, volume_texture, volume_size)
        light_dir = normalize(vec3(0.0, 1.0, 1.0))
        diffuse = max(0.0, dot(normal, light_dir))
        color.rgb = color.rgb * (0.5 + 0.5 * diffuse)
        
        # Front-to-back compositing
        color.a = clamp(1.0 * (1.0 - pow(1.0 - color.a, 1.0/sampling_factor)), 0.0, 1.0)
        color.rgb *= color.a
        
        out_color = out_color + (1.0 - out_color.a) * color
        
        # Early Ray Termination
        if out_color.a > 0.98:
            out_color.a = 1.0
            break
            
    return out_color

def get_volume_intensity(pos, tex, size):
    # Normalize pos to [0,1]
    uv = pos / size
    return texture(tex, uv).r

def texture_transfer_function(val):
    # Placeholder for TF lookup
    return vec4(val, val, val, val)

def get_gradient(pos, tex, size):
    # Placeholder for gradient calculation
    return vec3(0.0, 0.0, 0.0)
```

**Parameters:**
*   `sampling_factor`: Controls step density. Typical values depend on volume resolution [S3, unofficial].
*   `alpha_thre`: Opacity threshold for considering a region empty in occupancy grids. Typical value: $10^{-2}$ [S4, unofficial].
*   `early_stop_eps`: Transmittance threshold for early termination. Typical value: $10^{-4}$ [S4, unofficial].
*   `ess_type`: Integer flag. 1 = Block Empty Space Skipping; 2 = Chebyshev Empty Space Skipping [S3, unofficial].

**Edge Cases and Pitfalls:**
*   **Degenerate Rays:** Rays with zero length, NaN, or length $> \sqrt{3}$ should be terminated immediately to prevent performance regressions [S3, unofficial].
*   **Backtracking:** When empty space is detected at a boundary, the algorithm may need to backtrack to ensure the first occupied voxel is sampled. The index must be clamped to a minimum valid value ($i_{min}$) [S3, unofficial].
*   **Precision:** Floating-point errors in mapping sampling positions to distance map coordinates can cause missed skips or double sampling. Clamping and floor operations are critical [S3, unofficial].
*   **Transfer Function Dependency:** Standard occupancy grids are transfer-function independent. If the TF changes, the occupancy grid may become invalid, requiring recomputation [S12].

## Subtopics

### [Ray Marcher with Macrocell Empty Space Skipping](1009-ray-marcher-with-macrocell-empty-space-skipping.md)
Uses fixed, uniform macrocells with precomputed boolean occupancy flags. Chosen for simplicity and cache efficiency over dynamic trees.

### [Empty Space Skipping with Orthogonal BSP Tree](1054-empty-space-skipping-with-orthogonal-bsp-tree.md)
Partitions volume into sub-volumes based on voxel properties and sorts them. Chosen for lit rendering to minimize lighting computations in empty space.

### [Empty Space Skipping with Octree](1610-empty-space-skipping-with-octree.md)
Uses hierarchical min/max scalar value estimates to skip nodes. Chosen for isosurface rendering and sparse volumes where hierarchical pruning is effective.

### [Spatial Skipping (Occupancy Grid)](1614-spatial-skipping-occupancy-grid.md)
Uses a simple, explicit voxel-based occupancy grid with a conservative density threshold. Chosen for uniform sampling acceleration with minimal storage overhead.

### [Parallel Tree-Construction for Empty-Space Skipping](5037-parallel-tree-construction-for-empty-space-skipping.md)
Rebuilds acceleration structures on the GPU at runtime. Chosen for dynamic scenes or transfer function changes.

### [Transfer-Function Independent Empty-Space Skipping](5038-transfer-function-independent-empty-space-skipping.md)
Stores visibility information independent of the TF. Chosen for interactive applications where TF changes frequently.

### [Homogeneity Acceleration](5754-homogeneity-acceleration.md)
Approximates uniform, non-empty regions instead of sampling voxel-by-voxel. Chosen for homogeneous regions to reduce computational load further.

### Brick Classification and Empty Space Skipping
Classifies bricks into skipped, early-termination, or sampled categories using a shared metadata array. Chosen for GPU-based ray-guided rendering to bypass large sets of work. Pitfall: Metadata becomes invalid on TF change, requiring background recomputation [S12].

### Free Space Skipping
Uses coarse and fine density grids with thresholds ($\tau^{(c)}=10^{-3}, \tau^{(f)}=10^{-4}$) to skip points in free or unknown space. Chosen for NeRF training/inference to optimize query efficiency. Pitfall: Setting thresholds to 0 causes OOM or quality degradation [S13].

### SparseLeap
Optimizes both the number of samples and data structure look-ups. Chosen for its agnosticism to the underlying data structure (octrees, page-tables) [S5, unofficial].

### TF-Adaptive Empty-Space Skip
Skips cells if their max deviation is below a cutoff derived from contrast/trim uniforms. Chosen for raymarch acceleration with live TF adjustments. Pitfall: In dense structures, the overhead of pyramid checks can cause net regression [S14, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the acceleration structure. Octrees and BSPs add traversal overhead ($O(\log N)$ per ray segment) but reduce sampling ($O(K)$ where $K \ll N$). Occupancy grids add $O(1)$ lookup overhead. In sparse volumes, total time is significantly reduced [S5, unofficial][S11].
*   **Memory Complexity:** Requires additional storage for the acceleration structure. Occupancy grids add minimal overhead (e.g., 8 MB for 300 frames of video) [S11]. Octrees and BSPs require more memory for node structures [S6, unofficial].
*   **Measured Performance:** Provides 2.3x to 5x performance gains in some implementations [S10, unofficial]. In NeRF contexts, ESS can increase rendering speed from 1345 ms to 133 ms (10x) [S11].
*   **Strengths:** Drastically reduces computation in sparse volumes; prevents performance regressions from degenerate rays; compatible with various data structures [S3, S5, unofficial].
*   **Limitations:** Requires precomputation or online maintenance of the acceleration structure; performance can degrade in dense volumes where skips are rare [S14, unofficial]; transfer-function dependent variants require recomputation on TF change [S12].
*   **When to Use:** Sparse volumetric datasets; interactive applications requiring high frame rates; scenes with large empty regions [S7, S11].
*   **When Not to Use:** Dense, fully occupied volumes where traversal overhead outweighs sampling savings [S14, unofficial]; real-time applications with frequent TF changes if using static occupancy grids [S12].

## Background
Empty-space skipping was introduced as an optimization to address the primary bottleneck of raycasting: sampling empty space [S2, unofficial]. Early methods used bounding primitives to limit traversal [S2, unofficial]. Later, hierarchical structures like octrees were employed to encode empty space [S1, S6, unofficial]. The technique has been widely adopted in GPU-based volume rendering, including implementations by Klein et al. and Lee and Shin, often combined with frame-to-frame coherence [S7]. In recent years, it has become a standard component in Neural Radiance Field (NeRF) acceleration, such as in Instant-NGP and NerfAcc, using occupancy grids to prune empty and occluded regions during training and inference [S4, unofficial][S11].
