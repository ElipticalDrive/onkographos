# Adaptive Ray Marching with Macrocell DDA

Also called: Adaptive Macrocell Ray Marching

## Overview
Adaptive Ray Marching with Macrocell DDA is a ray marching technique that traverses a volumetric grid using a 3D Digital Differential Analyzer (DDA) over macrocells, adapting the sampling step size based on opacity upper bounds to skip empty or low-opacity regions [S1, unofficial]. It differs from its parent [Ray Marcher with Macrocell Empty Space Skipping](1009-ray-marcher-with-macrocell-empty-space-skipping.md) by dynamically adjusting the step size within occupied macrocells rather than only skipping entirely empty ones, and from its sibling [Triangulated Active Brick Boundary Mesh for Space Skipping](1426-triangulated-active-brick-boundary-mesh-for-space-skipping.md) by relying on a uniform grid structure with DDA traversal rather than explicit boundary meshes [S1, unofficial].

## How it works
The method combines coarse-grained space skipping with fine-grained adaptive sampling. It uses a 3D DDA to traverse a grid of macrocells. For each macrocell, it estimates an opacity upper bound. If the bound is negligible, the cell is skipped. Otherwise, the step size for sampling within the cell is scaled inversely to the opacity, allowing larger steps in transparent regions and smaller steps in dense regions.

### Inputs and Outputs
*   **Input**: Ray origin $O$, ray direction $D$ (normalized), ray interval $[t_{min}, t_{max}]$, volume data structure containing macrocell metadata.
*   **Output**: Accumulated color and opacity, or a boolean indicating if the ray hit an opaque surface.

### Data Structures
The volume is represented by a `DeviceVolume` structure (or equivalent) containing:
*   `macrocell_dims`: Dimensions of the macrocell grid (e.g., $N_x, N_y, N_z$).
*   `macrocell_spacings_rcp`: Reciprocal of the macrocell spacing in world units. This allows conversion from world coordinates to macrocell indices via multiplication.
*   `opacity_upper_bounds`: A data structure (e.g., array or hash map) storing the maximum opacity estimate for each macrocell.

### Parameters
*   `ADAPTIVE_SAMPLING`: A preprocessor macro or boolean flag. If enabled, adaptive logic is used; otherwise, fixed-step marching is performed [S1, unofficial].
*   `float_epsilon`: A small constant (e.g., $10^{-6}$) used to determine if a macrocell is effectively empty. If the opacity upper bound $r \le \text{float\_epsilon}$, the cell is skipped [S1, unofficial].
*   `step`: The base sampling step size. This is the default step size before adaptive scaling is applied [S1, unofficial].

### Algorithm Steps

1.  **Transform Ray to Macrocell Space**:
    Calculate the ray origin and direction in macrocell index space.
    $$ m_{org} = O \times \text{macrocell\_spacings\_rcp} $$
    $$ m_{dir} = D \times \text{macrocell\_spacings\_rcp} $$

2.  **Initialize DDA**:
    Initialize a 3D DDA iterator with $m_{org}$, $m_{dir}$, and the ray interval $[t_{min}, t_{max}]$. The DDA must handle the mapping from world distance $t$ to macrocell boundaries. Let the DDA yield a sequence of macrocells $(cell, t_0, t_1)$, where $t_0$ and $t_1$ are the entry and exit distances of the ray from the current macrocell in world units.

3.  **Iterate Macrocells**:
    For each macrocell $(cell, t_0, t_1)$ returned by the DDA:
    
    a. **Check Opacity Bound**:
    Retrieve the opacity upper bound $r$ for the current cell:
    $$ r = \text{opacityUpperBound}(cell) $$
    
    b. **Skip Empty Cells**:
    If $|r| \le \text{float\_epsilon}$, the cell is considered empty. Skip to the next macrocell.
    
    c. **Calculate Adaptive Step Size**:
    Determine the scaling factor based on the opacity bound. Let $ss$ be the adaptive step size.
    $$ ss = \text{sample\_size\_scaler}(\text{adaptiveSamplingRate}(step, r), t_0, t_1) $$
    *Note: `adaptiveSamplingRate` typically returns a factor that increases as $r$ decreases. `sample_size_scaler` ensures the step fits within the remaining interval $[t_0, t_1]$.*
    
    d. **Sample Within Macrocell**:
    Initialize the current sampling interval $t$ within the macrocell:
    $$ t_{start} = t_0 $$
    $$ t_{end} = \min(t_1, t_0 + ss) $$
    
    While $t_{end} > t_{start}$:
    i. Evaluate the volume rendering body function (sample density, apply transfer function, accumulate color/opacity) at the current position defined by $t_{start}$.
    ii. If the body function indicates the ray is fully opaque or terminated, return immediately.
    iii. Advance the interval:
    $$ t_{start} = t_{end} $$
    $$ t_{end} = \min(t_1, t_{start} + ss) $$

4.  **Termination**:
    If the ray exits the volume or is fully absorbed, return the accumulated result.

### Pseudocode

```python
def adaptive_ray_march(ray_origin, ray_direction, t_min, t_max, volume):
    """
    Adaptive ray marching using macrocell DDA.
    
    Args:
        ray_origin: vec3, ray origin in world space.
        ray_direction: vec3, normalized ray direction in world space.
        t_min: float, near plane distance.
        t_max: float, far plane distance.
        volume: DeviceVolume object containing macrocell data.
        
    Returns:
        vec4: Accumulated color and opacity.
    """
    # 1. Transform to macrocell space
    m_org = ray_origin * volume.macrocell_spacings_rcp
    m_dir = ray_direction * volume.macrocell_spacings_rcp
    
    # 2. Initialize DDA
    # dda3 yields (cell_index, t_entry, t_exit) for each macrocell intersected
    dda = DDA3(m_org, m_dir, t_min, t_max, volume.macrocell_dims)
    
    accumulated_color = vec3(0.0)
    accumulated_opacity = 0.0
    
    # 3. Iterate macrocells
    for cell, t0, t1 in dda:
        # Get opacity upper bound for this macrocell
        r = volume.get_opacity_upper_bound(cell)
        
        # Skip empty cells
        if abs(r) <= float_epsilon:
            continue
            
        # Calculate adaptive step size
        # adaptiveSamplingRate returns a scalar factor based on r and base step
        # sample_size_scaler clamps the step to the current interval [t0, t1]
        base_step = volume.base_step_size
        step_factor = adaptive_sampling_rate(base_step, r)
        ss = sample_size_scaler(step_factor, t0, t1)
        
        # 4. Sample within the macrocell
        t_current = t0
        t_next = min(t1, t0 + ss)
        
        while t_next > t_current:
            # Sample position
            pos = ray_origin + ray_direction * t_current
            
            # Evaluate volume (density, color, etc.)
            # This function updates accumulated_color and accumulated_opacity
            # It returns true if the ray is terminated (fully opaque)
            if volume_render_body(pos, accumulated_color, accumulated_opacity):
                return vec4(accumulated_color, accumulated_opacity)
            
            # Advance
            t_current = t_next
            t_next = min(t1, t_current + ss)
            
    return vec4(accumulated_color, accumulated_opacity)

def adaptive_sampling_rate(base_step, opacity_bound):
    """
    Returns a scaling factor for the step size.
    Higher opacity bound -> smaller step (more samples).
    Lower opacity bound -> larger step (fewer samples).
    """
    # Example implementation: inverse relationship
    # Avoid division by zero
    if opacity_bound < float_epsilon:
        return 1.0
    # Scale factor could be tuned; e.g., 1.0 / opacity_bound
    # Or a more complex function mapping [0,1] to step multipliers
    return 1.0 / max(opacity_bound, float_epsilon)

def sample_size_scaler(step_factor, t0, t1):
    """
    Ensures the step size does not exceed the remaining interval.
    """
    # step_factor is the desired step size in world units
    # It might be derived from base_step * factor
    # Here we assume step_factor is already the desired world-unit step
    return min(step_factor, t1 - t0)
```

### Edge Cases and Pitfalls
*   **Precision**: When $t_0$ and $t_1$ are very close, floating-point errors may cause $t_{next} \le t_{current}$, leading to infinite loops. Ensure `t_next` is strictly greater than `t_current` or add a minimum step size guard [G].
*   **Boundary Conditions**: The DDA must correctly handle rays that start or end inside a macrocell. The initial $t_0$ and final $t_1$ must be clamped to the ray interval $[t_{min}, t_{max}]$ [S1, unofficial].
*   **Opacity Bound Accuracy**: If the opacity upper bound is too loose (overestimates opacity), the algorithm will take small steps unnecessarily, reducing performance. If it is too tight (underestimates), it may miss details or cause aliasing [S1, unofficial].

### Space Skipping with 3DDDA
A mechanism to skip empty regions in sparse volume data using a uniform grid and 3DDDA algorithm [S2]. The fragment shader traverses the macrocell grid using 3DDDA in an outer loop. If a macrocell is nonempty, it enters the volume rendering loop with peak finding tests between samples. To begin sampling, it finds the first $t$ to sample when entering a macrocell by solving for the maximum $x$ after $T_{enter}$: $x_{tenter} = (-b + \sqrt{b^2 + 2aT_{enter}})/a$. It then computes floor values and samples as in Equation 17 of [S2]. Coarse grids (64^3 cells) work best on GPU [S2].

### Adaptive Ray Marching with Occupancy Grid
A variant that uses a bitfield occupancy grid to skip empty space [S3, unofficial]. For each ray, it iterates through spatial steps. It checks occupancy using a bitfield: `sity_bitfield[ti.u32(idx//8)] & (1 << ti.u32(idx%8))`. If occupied, it stores position, direction, time, and delta into buffers and marks for network evaluation. If not occupied, it calculates the distance to the next grid boundary using `txyz = (((nxyz+0.5+0.5*ti.math.sign(ray_d))*grid_size_inv*2-1)*mip_bound-xyz)*d_inv` and advances time to skip empty space until the next boundary is reached [S3, unofficial].

## Operating characteristics
*   **Time Complexity**: $O(N_{macrocells} + N_{samples})$, where $N_{macrocells}$ is the number of macrocells traversed and $N_{samples}$ is the total number of samples taken. Adaptive sampling reduces $N_{samples}$ in transparent regions.
*   **Memory Complexity**: $O(N_{macrocells})$ for storing opacity upper bounds.
*   **Performance**: Significantly faster than fixed-step marching in sparse volumes. Performance depends on the accuracy of the opacity upper bounds. Poor bounds lead to either excessive sampling or visual artifacts [S1, unofficial].
*   **Strengths**: Efficient space skipping, adaptive resolution, simple implementation on GPU.
*   **Limitations**: Requires precomputed opacity bounds. May suffer from thread divergence if opacity bounds vary significantly within a warp/block [S1, unofficial].

## Background
The method is based on the `instantvnr` project, which implements interactive volume visualization via multi-resolution hash encoding based neural representation [S1, unofficial]. The core idea of using macrocells with DDA for space skipping is common in volume rendering, with early implementations using uniform grids and 3DDDA for peak finding and differential sampling [S2]. The adaptive sampling aspect was introduced to improve performance on GPUs where purely adaptive methods based on local gradients suffer from poor thread coherence [S1, unofficial][S2].
