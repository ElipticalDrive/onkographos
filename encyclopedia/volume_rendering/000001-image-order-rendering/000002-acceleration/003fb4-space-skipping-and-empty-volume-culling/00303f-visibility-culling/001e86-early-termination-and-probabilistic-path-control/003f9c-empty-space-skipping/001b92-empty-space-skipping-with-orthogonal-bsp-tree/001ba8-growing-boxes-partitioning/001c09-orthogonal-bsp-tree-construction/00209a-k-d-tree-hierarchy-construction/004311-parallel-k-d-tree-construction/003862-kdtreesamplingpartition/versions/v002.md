# KDTreeSamplingPartition

Also called: DIY2 block sampling, Distributed sample distribution, KDTree Sampling Partitioning

## Overview
KDTreeSamplingPartition is a domain decomposition algorithm for distributing volume rendering samples across multiple compute blocks in a distributed-memory system [S1, unofficial]. It builds a k-d tree structure over spatial data points by recursively splitting blocks along coordinate dimensions using a sampling-based approach to determine split positions [S1, unofficial]. It differs from static partitioning methods by dynamically computing split planes via random sampling and managing neighbor links via a reduce proxy to handle wrap-around or boundary conditions [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Spatial points distributed across processing blocks, the spatial dimension `dim_`, the number of samples to draw `samples_`, a `Partners` object managing communication rounds, dimensions, swap flags, wrap-around, and domain bounds, and an `SRP` (Splitting Reduce Proxy) object managing communication links, global ID, and current round [S1, unofficial].
*   **Output:** A partitioned set of points where each block holds points within its assigned k-d tree leaf region, and updated neighbor links for subsequent communication or rendering steps [S1, unofficial].

**Data Structures:**
*   `dim_`: Integer representing the spatial dimension [S1, unofficial].
*   `points_`: Pointer to a member `std::vector<Point>` inside the `Block` structure [S1, unofficial].
*   `samples_`: Size_t specifying the number of samples to draw [S1, unofficial].
*   `Partners`: Manages `rounds()`, `dim(round)`, `swap_round(round)`, `sub_round(round)`, `wrap`, and `domain` [S1, unofficial].
*   `SRP`: Manages `in_link()`, `out_link()`, `gid()`, and `round()` [S1, unofficial].

**Numbered Steps:**
1.  **Initialization:** Assign an equal number of samples to each processing block [S1, unofficial]. Update inter-block links to handle wrap-around or boundary conditions across the domain [S1, unofficial].
2.  **Iterative Splitting:** For each round `r` from 0 to `partners.rounds() - 1`:
    a. Determine the current splitting dimension `dim`: if `srp.round() < partners.rounds()`, `dim = partners.dim(srp.round())`; else `dim = partners.dim(srp.round() - 1)` [S1, unofficial].
    b. If `srp.round() == partners.rounds()`, call `update_links(b, srp, dim, partners.sub_round(srp.round() - 2), partners.swap_rounds(), partners.wrap, partners.domain)` to finalize links [S1, unofficial].
    c. If `partners.swap_round(srp.round())` is true (and not a link round): receive samples via `receive_samples(b, srp, samples)`, then enqueue exchange via `enqueue_exchange(b, srp, dim, samples)` [S1, unofficial].
    d. If `partners.sub_round(srp.round()) == 0`: if `srp.round() > 0`, update links for the previous dimension `prev_dim = (dim - 1 < 0) ? dim_ + dim - 1 : dim - 1` via `update_links`; then compute local samples via `compute_local_samples(b, srp, dim)` [S1, unofficial].
    e. Else (final sample aggregation): add local samples via `add_samples(b, srp, samples)` [S1, unofficial]. If `samples.size() != 1`, find the median using `std::nth_element` on the `samples` vector, swap the median to index 0, resize the vector to 1, and forward via `forward_samples(b, srp, samples)` [S1, unofficial].

**Pseudocode:**

    # Initialization
    assign_equal_samples(block, partners.num_blocks())
    update_inter_block_links(block, srp, partners.wrap, partners.domain)

    for r in range(partners.rounds()):
        # Determine splitting dimension
        if srp.round() < partners.rounds():
            dim = partners.dim(srp.round())
        else:
            dim = partners.dim(srp.round() - 1)

        # Final link update condition
        if srp.round() == partners.rounds():
            update_links(block, srp, dim, partners.sub_round(r - 2),
                         partners.swap_rounds(), partners.wrap, partners.domain)

        # Swap round handling
        if partners.swap_round(r):
            receive_samples(block, srp, samples)
            enqueue_exchange(block, srp, dim, samples)

        # Sub-round 0 handling
        if partners.sub_round(r) == 0:
            if r > 0:
                prev_dim = dim_ + dim - 1 if dim - 1 < 0 else dim - 1
                update_links(block, srp, prev_dim, partners.sub_round(r - 2),
                             partners.swap_rounds(), partners.wrap, partners.domain)
            compute_local_samples(block, srp, dim)
        else:
            # Final sample aggregation
            add_samples(block, srp, samples)
            if len(samples) != 1:
                samples.sort() # Placeholder for std::nth_element logic
                median = samples[len(samples) // 2]
                samples[0] = median
                samples = samples[:1]
                forward_samples(block, srp, samples)

def compute_local_samples(block, srp, dim):
    points_size = len(block.points_)
    n = min(points_size, samples_)
    coords = []
    for _ in range(n):
        idx = rand() % points_size
        coord = block.points_[idx][dim]
        coords.append(coord)
    srp.out_link().target(0).enqueue(coords)

def update_links(block, srp, dim, prev_dim, swap_rounds, wrap, domain):
    link_map = {target: idx for idx, target in enumerate(link.targets)}
    splits = []
    dirs = []
    for link in srp.in_link():
        data = link.dequeue()
        splits.append(data.split)
        dirs.append(-data.dir) # Reverse direction

    lower = not (gid & (1 << (rounds - 1 - round)))
    for entry in link_map:
        d = dirs[entry]
        if d[dim] != 0:
            if (d[dim] < 0 and lower) or (d[dim] > 0 and not lower):
                neighbor_gid = divide_gid(gid, lower, rounds, round)
                update_neighbor_bounds(new_link.bounds, lower, splits[entry], dim)
                if wrap: add_wrap(new_link, neighbor_gid)
                new_link.add(neighbor_gid)
        else:
            for j in range(2):
                neighbor_gid = divide_gid(gid, lower, rounds, round)
                update_neighbor_bounds(new_link.bounds, lower, splits[entry], dim)
                if intersects(new_link.bounds, domain, wrap, dim):
                    new_link.add(neighbor_gid)
    # Add dual block neighbor
    dual_gid = divide_gid(gid, not lower, rounds, round)
    update_neighbor_bounds(new_link.bounds, not lower, splits[entry], dim)
    new_link.add(dual_gid, direction="right" if lower else "left")
    link = new_link

def divide_gid(gid, lower, rounds, round):
    bit = 1 << (rounds - 1 - round)
    if lower:
        return gid & ~bit
    else:
        return gid | bit

def find_split(changed, original, dim_):
    for i in range(dim_):
        if changed.min[i] != original.min[i]:
            return changed.min[i]
        if changed.max[i] != original.max[i]:
            return changed.max[i]
    assert False, "No difference found"

def intersects(x, y, wrap, domain, dim):
    if wrap:
        return (x.min[dim] == domain.min[dim] and y.max[dim] == domain.max[dim]) or \
               (y.min[dim] == domain.min[dim] and x.max[dim] == domain.max[dim])
    return x.min[dim] <= y.max[dim] and y.min[dim] <= x.max[dim]

def update_neighbor_bounds(bounds, lower, split, dim):
    if lower:
        bounds.max[dim] = split
    else:
        bounds.min[dim] = split

def forward_samples(block, srp, samples):
    for target in srp.out_link():
        target.enqueue(samples)

def receive_samples(block, srp, samples):
    samples = srp.in_link().target(0).gid.dequeue()

**Edge Cases and Pitfalls:**
*   The current implementation does not perform a perfect subsample; it should randomly select samples so the total equals `samples * nblocks` [S1, unofficial].
*   Random sampling relies on the legacy C `rand()` function, which must be seeded externally before use [S1, unofficial].
*   Validation of point coordinates during `dequeue_exchange` throws a `std::runtime_error` if a point is outside the expected bounds `[link->core().min[dim], link->core().max[dim]]` [S1, unofficial].
