# Bounding Volume Culling

Also called: Distance-based Culling, Ray Termination by Distance

## Overview
Bounding Volume Culling is an optimization that limits raymarching to a specific bounding volume, dropping rays that exceed a certain distance from the eye to speed up rendering [S1, unofficial]. It differs from its siblings, such as [Empty-space skipping](1002-empty-space-skipping.md) which skips empty regions, and [Early Stop](1790-early-stop.md) which terminates based on opacity, by using a hard geometric distance limit to discard rays entirely [S1, unofficial]. Unlike [Depth-Prior Ray Truncation](5456-depth-prior-ray-truncation.md) which uses scene depth data, this method relies solely on the accumulated step distance [S1, unofficial].

## How it works
**Inputs:** Ray origin $\mathbf{o}$, ray direction $\mathbf{d}$, maximum travel distance $T_{max}$, and a distance field function $S(\mathbf{p})$ returning the distance to the closest surface.
**Outputs:** Intersection point or null (ray terminated).
**Data Structures:** Scalar variable $t$ tracking total distance traveled.

**Steps:**
1. Initialize total distance $t = 0$.
2. While $t < T_{max}$:
   a. Evaluate $S(\mathbf{p})$ at current position $\mathbf{p} = \mathbf{o} + t\mathbf{d}$.
   b. If $S(\mathbf{p}) < \epsilon$ (hit), return intersection.
   c. Advance $t \leftarrow t + S(\mathbf{p})$.
3. If loop completes without hit, return null (ray terminated by distance).

**Parameters:**
- $T_{max}$: Predefined limit. Typical values depend on scene scale; e.g., 64 steps equivalent distance or world units [S1, unofficial].

**Edge Cases:**
- If $T_{max}$ is too small, valid intersections may be missed.
- Precision errors in $t$ accumulation may cause early termination or infinite loops if $S(\mathbf{p})$ is very small but non-zero [G].

```python
def bounding_volume_culling(ray_origin, ray_direction, max_distance, distance_field, epsilon=1e-4):
    t = 0.0
    while t < max_distance:
        p = ray_origin + t * ray_direction
        dist = distance_field(p)
        if dist < epsilon:
            return p
        t += dist
    return None
```

## Subtopics

### Heap-based Bounding Volume Culling for Sphere Tracing
An algorithm to find the closest object in a collection by maintaining a heap of bounding volume distances [S2]. It computes distances to bounding volumes first, then contents, culling based on the smallest bounding volume distance [S2]. It differs from standard Bounding Volume Culling by optimizing the search for the *closest* object among many, rather than just terminating a single ray by global distance [S2]. When to choose: When raymarching a collection of implicit objects and sphere tracing is used [S2].

1. Compute distances to each bounding volume in the union/collection.
2. Create a heap of these distances.
3. Initialize $d_{min} = \infty$.
4. Loop:
   a. Let $d_{content}$ be $\min(d_{min}, \text{distance to contents of top BV})$.
   b. Remove top of heap.
   c. Let $d_{bv}$ be distance to new top BV.
   d. Stop if $d_{content} < d_{bv}$ or heap empty.
5. Return $d_{content}$ [S2].

**Parameters:**
- $d_{bv}$: The distance to the bounding volume currently at the top of the heap [S2].

## Operating characteristics
**Time Complexity:** $O(1)$ per ray for simple distance culling; $O(N \log N)$ for heap-based culling with $N$ objects [S2].
**Memory Complexity:** $O(N)$ for heap storage [S2].
**Strengths:** Simple to implement; significantly reduces raymarching iterations for distant rays [S1, unofficial].
**Limitations:** Does not handle occlusion within the volume; requires a defined global bound [S1, unofficial].
**When to use:** When rays frequently traverse large empty spaces or when the scene has a known maximum extent [S1, unofficial].

## Background
Originated in the context of raymarching distance fields and sphere tracing [S1, unofficial][S2]. The concept of limiting raymarching to a bounding volume is discussed in early raymarching tutorials [S1, unofficial]. The heap-based variant for sphere tracing was formalized in the context of geometric methods for antialiased ray tracing of implicit surfaces [S2].
