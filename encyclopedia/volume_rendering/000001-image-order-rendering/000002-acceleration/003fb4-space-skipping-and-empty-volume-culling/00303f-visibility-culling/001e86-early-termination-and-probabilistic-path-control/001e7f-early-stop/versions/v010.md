# Early Stop

Also called: Early stop+0, Early stop+1

## Overview
Early Stop (ES) is an optimization for sphere tracing procedural volumes that limits the computation of noise frequencies ($f_i$) by breaking the evaluation loop as soon as the ray position is determined to be outside the bounding volume of the current frequency level [S1]. It solves the problem of unnecessary function evaluations when a ray has moved sufficiently far from the isosurface, thereby reducing the computational cost per step [S1]. Unlike standard sphere tracing which computes all octaves up to $n$ at every step, ES dynamically determines the minimum necessary octave $i_{min}$ based on BVH bounds, trading potential step size reduction for significant savings in function evaluations [S1]. It builds on [Early Termination and Probabilistic Path Control](1791-early-termination-and-probabilistic-path-control.md) by applying early loop breaks specifically to hierarchical noise evaluation [S1].

## How it works
**Inputs:**
- Ray origin $\mathbf{o}$ and direction $\mathbf{d}$ [G].
- Procedural volume defined by a sum of noise functions $F_n(\mathbf{p}) = \sum_{i=0}^{n} f_i(\mathbf{p})$ [S1].
- Isovalue $v$ defining the isosurface [S1].
- BVH structure where each level $i$ provides an upper bound function $BVH_{i+}(\mathbf{p})$ and optionally a lower bound $BVH_{i-}(\mathbf{p})$ [S1].
- Parameter $k$: the number of additional frequencies to compute beyond the minimum required (typically $k=1$) [S1].

**Outputs:**
- Intersection distance $t$ along the ray [G].
- Normal $\mathbf{n}$ at the intersection point [G].

**Data Structures:**
- **BVH Levels:** A hierarchy where level $i$ corresponds to the bounding volume of the noise function $f_i$ [S1]. Each level $i$ provides a cheap-to-evaluate inclusion function $BVH_{i+}(\mathbf{p})$ which bounds the range of $f_i(\mathbf{p})$ [S1].
- **Frequency Functions:** $f_i(\mathbf{p})$, typically octaves of a noise function (e.g., FBM), which are more expensive to evaluate than the BVH bounds [S1].

**Algorithm Steps:**
1. **Initialize:** Start sphere tracing from the ray origin $\mathbf{o}$ [G]. Let current position be $\mathbf{p} = \mathbf{o}$ and accumulated distance $t = 0$ [G].
2. **Determine Minimum Index ($i_{min}$):** For the current position $\mathbf{p}$, find the smallest index $i$ such that the upper bound of the BVH at that level is strictly below the isovalue $v$ [S1]. This indicates that the position is outside the bounding volume of $f_i$ [S1].
   $$ i_{\min} = \min\{i \mid \text{BVH}_{i+}(\mathbf{p}) < v\} $$
   If searching for the isosurface from inside the volume, this can equivalently be defined using the lower bound: $\text{BVH}_{i-}(\mathbf{p}) > v$ [S1].
3. **Compute Frequencies:** Evaluate the noise functions $f_i(\mathbf{p})$ starting from $i_{min}$ up to $i_{min} + k$ [S1].
   - Compute $\text{BVH}_{i+}(\mathbf{p})$ for each $i$ as you compute $f_i(\mathbf{p})$ [S1].
   - If $\text{BVH}_{i+}(\mathbf{p}) < v$, the position is outside the bounding volume for level $i$ [S1].
   - Stop evaluating further $f_i$ functions once $i > i_{min} + k$ [S1].
4. **Calculate Step Size:** Use the computed sum $F_{i_{min}+k}(\mathbf{p})$ to determine the step size $\Delta t$ for sphere tracing [G]. The step size is typically derived from the distance to the isosurface estimate provided by the current frequency sum [G].
5. **Advance Ray:** Update position $\mathbf{p} \leftarrow \mathbf{p} + \Delta t \cdot \mathbf{d}$ and accumulate $t \leftarrow t + \Delta t$ [G].
6. **Check Termination:** If the ray has exited the volume or converged to the isosurface within a tolerance, return the result [G]. Otherwise, go to Step 2 [G].

**Pseudocode:**
```python
import math

def early_stop_sphere_trace(ray_origin, ray_dir, isovalue, k, max_steps, max_dist):
    # Standard sphere tracing initialization [G]
    p = list(ray_origin)
    t = 0.0
    MAX_OCTAVES = 16  # Maximum BVH depth [G]
    MIN_STEP = 1e-4   # Prevents infinite loops on flat regions [G]
    TOLERANCE = 1e-3  # Convergence threshold [G]

    for step in range(max_steps):
        # Step 1: Find i_min
        i_min = 0
        while i_min < MAX_OCTAVES:
            # Evaluate BVH upper bound for current level [G]
            if evaluate_bvh_upper_bound(i_min, p) < isovalue:
                break
            i_min += 1
        if i_min == MAX_OCTAVES:
            break  # Reached maximum depth without leaving volume

        # Step 2: Compute frequencies from i_min to i_min + k
        current_sum = 0.0
        grad_mag = 0.0
        for i in range(i_min, i_min + k + 1):
            # Evaluate octave and its gradient [G]
            f_val = evaluate_octave(i, p)
            grad = evaluate_octave_gradient(i, p)
            current_sum += f_val
            grad_mag += sum(abs(g) for g in grad)

        # Step 3: Determine step size [G]
        dist_to_surface = abs(current_sum - isovalue)
        grad_mag = max(1.0, grad_mag)
        delta_t = dist_to_surface / grad_mag

        # Safety clamp [G]
        delta_t = max(delta_t, MIN_STEP)
        if t + delta_t > max_dist:
            break

        # Step 4: Advance ray
        t += delta_t
        p = [ray_origin[j] + delta_t * ray_dir[j] for j in range(3)]

        # Step 5: Check convergence
        if dist_to_surface < TOLERANCE:
            # Compute normal from accumulated gradient [G]
            normal = [0.0, 0.0, 0.0]
            for i in range(i_min, i_min + k + 1):
                normal = [normal[j] + evaluate_octave_gradient(i, p)[j] for j in range(3)]
            norm_len = math.sqrt(sum(c**2 for c in normal))
            if norm_len > 0:
                normal = [c / norm_len for c in normal]
            return t, normal

    return None, None

# Standard mathematical evaluations [G]
def evaluate_bvh_upper_bound(level, p):
    # Returns a conservative upper bound for octave `level` at position `p`
    # Implementation depends on the specific inclusion function used [G]
    return 1.0 - 0.1 * level

def evaluate_octave(level, p):
    # Evaluates the noise octave `level` at position `p`
    # Typically a fractal Brownian motion component [G]
    scale = 2.0 ** level
    return math.sin(p[0] * scale) * math.cos(p[1] * scale) * math.sin(p[2] * scale) * (0.5 ** level)

def evaluate_octave_gradient(level, p):
    # Returns the analytical or numerical gradient of octave `level` at `p`
    # Used for step size estimation [G]
    eps = 1e-5
    f = evaluate_octave(level, p)
    gx = (evaluate_octave(level, (p[0]+eps, p[1], p[2])) - f) / eps
    gy = (evaluate_octave(level, (p[0], p[1]+eps, p[2])) - f) / eps
    gz = (evaluate_octave(level, (p[0], p[1], p[2]+eps)) - f) / eps
    return (gx, gy, gz)
```

**Parameters:**
- $k$: The number of additional frequencies to compute beyond $i_{min}$ [S1]. Typical value is $k=1$ [S1].
- $v$: Isovalue for the isosurface [S1].

**Edge Cases and Pitfalls:**
- **Early Stop+0 ($k=0$):** Computing only $f_{i_{min}}$ causes slow convergence at every level of the BVH traversal [S1]. The ray steps safely to the current outer bounding volume and repeats, massively increasing the total number of steps [S1]. This is particularly bad for grazing rays (rays passing close to but not entering a bounding volume) [S1].
- **Step Size Reduction:** Stopping early reduces the number of $f_i$ computed, which may result in smaller step sizes [S1]. This can increase the total number of steps required to converge, potentially raising the final cost [S1]. A trade-off must be found [S1].
- **Grazing Rays:** Rays passing very close to a bounding volume without entering it can be significantly slowed down if $k$ is too small [S1]. Early Stop+1 mitigates this by considering one extra level of the BVH [S1].

## Subtopics

### [Early Stop + k](1938-early-stop-k.md)
Early Stop + k (ES+k) is an optimization for sphere tracing procedural volumes that prevents unnecessary intermediate convergence checks during BVH traversal by computing $k$ additional octaves per traversal step. It builds on [Early Stop](1790-early-stop.md) by trading a small increase in per-step function evaluations for a significant reduction in the total number of BVH traversal steps. Unlike standard Early Stop (ES+0), which may converge too slowly and incur high step counts, ES+k maintains a balance between step reduction and computational overhead, with ES+1 generally offering the best performance across diverse scenes.

## Operating characteristics
- **Time Complexity:** The cost per step is reduced from $O(n)$ function evaluations to $O(i_{min} + k)$ [S1]. However, the total number of steps may increase due to smaller step sizes, especially if $k$ is small [S1].
- **Memory Complexity:** Minimal additional memory is required, primarily for storing the BVH structure and the current state of the ray marching [S1]. The BVH bounds are evaluated on the fly as the corresponding $f_i$ functions are computed [S1].
- **Measured Performance:** Early Stop+1 ($k=1$) provides results very similar to full sphere tracing (computing all $f_i$ up to $n$) but with significantly reduced computational cost [S1]. It drastically diminishes the performance loss associated with grazing rays and slow convergence seen in Early Stop+0 [S1].
- **Strengths:** Reduces the number of expensive noise function evaluations [S1]. Effective for large and detailed scenes where many parts of the volume are empty or far from the isosurface [S1].
- **Limitations:** May increase the total number of steps if step sizes become too small [S1]. The benefit diminishes for $k > 1$ as the added cost of computing more $f_i$ is not worth the small gains in step size [S1].
- **When to Use:** Use when rendering procedural volumetric noise with sphere tracing, especially for large scenes with complex BVH structures [S1]. Use $k=1$ for the best balance between performance and accuracy [S1]. Avoid $k=0$ due to severe performance degradation on grazing rays [S1].

## Background
Early Stop was introduced in the context of fast sphere tracing of procedural volumetric noise for very large and detailed scenes [S1]. It leverages the hierarchical structure of the noise function (often represented as a BVH) to avoid unnecessary computations [S1]. The method addresses the inefficiency of standard sphere tracing, which evaluates all octaves at every step, regardless of whether they are necessary for the current position [S1].
