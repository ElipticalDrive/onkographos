# Early Stop

Also called: Early stop+0, Early stop+1

## Overview
Early Stop (ES) is an optimization for sphere tracing procedural volumes that limits the computational cost of evaluating noise frequencies by breaking the summation loop early based on the ray's position relative to a Bounding Volume Hierarchy (BVH) [S1]. It solves the problem of excessive function evaluations in detailed scenes by recognizing that higher-frequency noise components are bounded by coarser BVH levels; if a position lies outside a coarse bounding volume, the corresponding fine-grained noise functions cannot contribute to the isosurface intersection [S1]. Unlike standard sphere tracing which evaluates all octaves, ES reduces per-step cost, though it requires careful tuning of the "early stop depth" to avoid performance degradation from slow convergence [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Ray origin $\mathbf{o}$, ray direction $\mathbf{d}$, isovalue $v$, BVH structure where each node $i$ provides an upper bound function $BVH_{i+}(\mathbf{p})$ and lower bound function $BVH_{i-}(\mathbf{p})$, and the noise function components $f_i(\mathbf{p})$ (e.g., octaves of FBM).
*   **Output:** Intersection distance $t$ along the ray, or null if no intersection is found.

**Data Structures:**
*   **BVH:** A hierarchical structure where each level $i$ corresponds to a subset of noise frequencies. Each node at level $i$ provides inclusion functions (bounds) for the sum of frequencies up to $i$. Specifically, $BVH_{i+}(\mathbf{p})$ is the upper bound of the function sum at level $i$ for position $\mathbf{p}$ [S1].

**Algorithm Steps:**
1.  **Initialize:** Set current position $\mathbf{p} = \mathbf{o}$ and step size $t = 0$.
2.  **Loop:** While $\mathbf{p}$ is within the scene bounds and not converged:
    a.  **Find Minimum Index ($i_{min}$):** Determine the smallest index $i$ such that the position $\mathbf{p}$ is outside the bounding volume at level $i$. This is defined by the condition:
        $$ i_{min} = \min\{i \mid BVH_{i+}(\mathbf{p}) < v\} $$
        If searching for an isosurface from inside the volume, this can equivalently be defined using the lower bound: $BVH_{i-}(\mathbf{p}) > v$ [S1].
    b.  **Compute Step Size:** Calculate the sphere tracing step size using the noise function sum $F_{i_{min}}(\mathbf{p})$ (or a conservative estimate based on $BVH_{i_{min}+}$). The step size is typically proportional to the distance to the isovalue [S1].
    c.  **Advance Ray:** Update $\mathbf{p} \leftarrow \mathbf{p} + t \cdot \mathbf{d}$.
    d.  **Check Convergence:** If the distance to the isosurface is below a threshold, terminate and return $t$.
    e.  **Early Stop Check:** If using **Early Stop + k**, compute the noise functions $f_j$ for $j$ from $i_{min}$ to $i_{min} + k$. Break the evaluation loop for higher frequencies $f_j$ where $j > i_{min} + k$ because their contribution is guaranteed to be bounded by the BVH structure and insufficient to affect the intersection at this precision [S1].
    f.  **Repeat.**

**Parameters:**
*   **$k$:** The number of additional noise functions (octaves) to compute beyond $i_{min}$ before breaking the loop.
    *   $k=0$: **Early Stop+0**. Computes only $f_{i_{min}}$.
    *   $k=1$: **Early Stop+1**. Computes $f_{i_{min}}$ and $f_{i_{min}+1}$.
    *   $k>1$: Computes more octaves.
*   **$v$:** The isovalue used for comparison against BVH bounds [S1].

**Pseudocode:**
```python
def sphere_trace_early_stop(ray_origin, ray_direction, isovalue, bvh, k=1):
    """
    Ray march using Early Stop optimization.
    
    Args:
        ray_origin: 3D vector
        ray_direction: 3D vector (normalized)
        isovalue: float, the threshold for the noise function
        bvh: Object providing method get_upper_bound(level, point) -> float
        k: int, number of extra octaves to compute beyond min_level
        
    Returns:
        float: distance to intersection, or None
    """
    t = 0.0
    max_steps = 1000
    step_size_threshold = 1e-4
    
    for step in range(max_steps):
        p = ray_origin + ray_direction * t
        
        # 1. Find i_min: the first level where the upper bound is below isovalue
        # This means the position is outside the bounding volume for that level
        i_min = 0
        while True:
            # Assume bvh.get_upper_bound returns the max possible value of the 
            # noise sum at that level for point p
            upper_bound = bvh.get_upper_bound(i_min, p)
            if upper_bound < isovalue:
                break
            i_min += 1
            # Safety break if level exceeds available BVH depth
            if i_min >= bvh.max_depth:
                return None 

        # 2. Compute step size based on the function at i_min
        # In standard sphere tracing, step size is distance to isosurface.
        # Here, we use the value of the function F_i_min to estimate distance.
        # Note: The exact step size formula depends on the specific sphere tracing 
        # variant (e.g., distance to isovalue). We assume a helper function 
        # compute_step_size that uses F_i_min.
        f_val = compute_noise_sum(p, i_min) # Sum f_0 to f_i_min
        step = compute_step_size(f_val, isovalue)
        
        if step < step_size_threshold:
            return t # Convergence reached
            
        t += step
        
        # 3. Early Stop: Decide how many more octaves to compute for the NEXT step
        # The optimization applies to the evaluation of the function for the 
        # *next* step size calculation or for refining the current position.
        # According to [S1], we break the loop of evaluating f_i after i_min + k.
        
        # For the next iteration, we will re-evaluate i_min. 
        # The "Early Stop" logic primarily saves computation by NOT evaluating 
        # f_j for j > i_min + k when determining the step size or checking 
        # inclusion.
        
        # Implementation detail: When computing the noise value for step size 
        # estimation or convergence check, we only sum up to i_min + k.
        
    return None # Max steps exceeded

def compute_noise_sum(p, max_level, k=1):
    """
    Compute noise sum up to max_level + k.
    """
    total = 0.0
    # Assume get_octave(level, point) returns f_level(point)
    for i in range(max_level + k + 1):
        total += bvh.get_octave(i, p)
    return total
```

**Edge Cases and Pitfalls:**
*   **Early Stop+0 (k=0):** This strategy computes only the minimum number of functions $f_i$ necessary for the first step. It causes slow convergence at every level of the BVH traversal because the ray steps safely to the current outer bounding volume and repeats. This massively increases the total number of steps, particularly for "grazing rays" (rays passing close to but not entering a bounding volume) [S1].
*   **Step Size Reduction:** Stopping early reduces the number of $f_i$ computed, which may result in smaller step sizes. This can increase the total number of steps required to converge, potentially raising the final computational cost [S1].
*   **Grazing Rays:** Rays that graze the boundary of a BVH node can trigger frequent re-evaluations of $i_{min}$, leading to performance loss if $k$ is too small [S1].

## Subtopics

### [Early Stop + k](1938-early-stop-k.md)
A variant where the loop breaks after computing $k$ additional octaves beyond $i_{min}$. ES+1 is generally recommended as it balances step reduction and computational overhead, avoiding the slow convergence of ES+0 without the diminishing returns of $k>1$.

## Operating characteristics
*   **Time Complexity:** Depends on the number of noise functions $f_i$ computed per step. ES reduces the per-step cost from $O(N)$ to $O(i_{min} + k)$, where $N$ is the total number of octaves. However, it may increase the total number of steps due to smaller step sizes [S1].
*   **Memory Complexity:** Requires storing the BVH structure. The BVH nodes store inclusion functions (bounds) for the noise sums [S1].
*   **Performance:** ES+1 drastically diminishes performance loss from grazing rays at negligible cost compared to ES+0 [S1]. Using $k>1$ provides diminishing returns; the added cost of computing more $f_i$ is usually not worth the small gains in step size or convergence stability [S1].
*   **Strengths:** Significant reduction in function evaluations for rays far from the isosurface or in empty space.
*   **Limitations:** Potential for increased step counts if $k$ is too low. Not suitable for scenes where high-frequency details are critical near the isosurface if $i_{min}$ is low [S1].

## Background
Early Stop was introduced in the context of fast sphere tracing of procedural volumetric noise for very large and detailed scenes [S1]. It leverages the hierarchical nature of procedural noise (like FBM) and BVH structures to avoid unnecessary computations. The method addresses the inefficiency of standard sphere tracing, which evaluates all noise octaves at every step, regardless of whether the finer details are relevant to the current ray position [S1].
