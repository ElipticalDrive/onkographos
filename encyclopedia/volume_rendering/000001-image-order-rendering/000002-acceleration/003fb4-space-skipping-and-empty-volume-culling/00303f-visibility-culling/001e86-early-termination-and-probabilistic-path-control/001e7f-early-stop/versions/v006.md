# Early Stop

Also called: Early stop+0, Early stop+1

## Overview
Early Stop (ES) is an optimization for sphere tracing procedural volumes that limits the computation of noise frequencies ($f_i$) during ray marching by breaking the evaluation loop early based on the ray's position relative to a Bounding Volume Hierarchy (BVH) [S1]. It solves the problem of excessive computational cost in sphere tracing, where evaluating high-frequency noise terms is expensive, by avoiding unnecessary function evaluations when the ray is far from the isosurface [S1]. Unlike standard sphere tracing which computes all octaves, ES uses BVH bounds to determine the minimum necessary octave index $i_{min}$, and unlike Early Stop+0 which suffers from slow convergence on grazing rays, variants like Early Stop+1 balance step size and evaluation cost to maintain performance [S1].

## How it works
**Inputs:**
*   Ray origin $\mathbf{o}$ and direction $\mathbf{d}$.
*   Isosurface value $v$.
*   BVH structure where each level $i$ has an upper bound function $BVH_{i+}(\mathbf{p})$ and a noise function $f_i(\mathbf{p})$ [S1].
*   Parameter $k$: The number of additional functions to compute beyond $i_{min}$ (typically $k=1$) [S1].

**Outputs:**
*   Intersection distance or null if no intersection is found within the ray length.

**Data Structures:**
*   **BVH:** A hierarchy of bounding volumes. For each level $i$, the structure provides:
    *   $BVH_{i+}(\mathbf{p})$: An inclusion function providing an upper bound on the noise value at point $\mathbf{p}$ for octave $i$.
    *   $f_i(\mathbf{p})$: The noise function (e.g., FBM component) for octave $i$.
*   **Position $\mathbf{p}$:** The current point along the ray being evaluated.

**Algorithm Steps:**
1.  **Initialize:** Start sphere tracing from the ray origin. Let current position be $\mathbf{p} = \mathbf{o}$.
2.  **Find Minimum Index ($i_{min}$):** For the current position $\mathbf{p}$, determine the smallest index $i$ such that the upper bound of the BVH at that level is strictly below the isovalue $v$ [S1]. This indicates the position is outside the bounding volume for that octave and all higher octaves [S1].
    $$ i_{min} = \min\{i \mid BVH_{i+}(\mathbf{p}) < v\} $$
    *Note:* If the position is inside the volume and searching for the isosurface, $i_{min}$ can equivalently be defined using the lower bound: $BVH_{i-}(\mathbf{p}) > v$ [S1].
3.  **Compute Sum with Early Stop:** Evaluate the noise function sum starting from $i_{min}$ up to $i_{min} + k$ [S1].
    $$ F(\mathbf{p}) = \sum_{j=i_{min}}^{i_{min}+k} f_j(\mathbf{p}) $$
    *   If $k=0$ (Early Stop+0), only $f_{i_{min}}$ is computed.
    *   If $k=1$ (Early Stop+1), $f_{i_{min}}$ and $f_{i_{min}+1}$ are computed.
    *   The loop breaks immediately after computing $f_{i_{min}+k}$; remaining $f_i$ for $i > i_{min}+k$ are not computed [S1].
4.  **Step Size Calculation:** Use the computed sum $F(\mathbf{p})$ to determine the step size $\Delta t$ for sphere tracing. The step size is typically derived from the difference between the isovalue $v$ and the computed function value, scaled by a safety factor or derivative bound [S1].
5.  **Advance Ray:** Update position: $\mathbf{p} \leftarrow \mathbf{p} + \Delta t \cdot \mathbf{d}$.
6.  **Termination Check:**
    *   If $|F(\mathbf{p}) - v| < \epsilon$ (convergence threshold), return intersection.
    *   If ray length limit exceeded, return null.
    *   Otherwise, return to Step 2.

**Pseudocode:**
```python
def early_stop_sphere_trace(ray_origin, ray_direction, isovalue, bvh, k=1):
    """
    Performs sphere tracing with Early Stop optimization.
    
    Args:
        ray_origin: 3D vector, start of the ray.
        ray_direction: 3D vector, direction of the ray (normalized).
        isovalue: float, the target isosurface value v.
        bvh: Object providing BVH_i_plus(p) and f_i(p) for levels i.
        k: int, number of extra octaves to compute beyond i_min (default 1).
        
    Returns:
        float: Distance to intersection, or None if not found.
    """
    t = 0.0
    max_steps = 1000  # Implementation detail [G]
    
    for step in range(max_steps):
        p = ray_origin + t * ray_direction
        
        # Step 2: Find i_min
        # Find the first level i where the upper bound is below the isovalue
        i_min = 0
        while True:
            # Check if position is outside the bounding volume for level i
            # BVH_i_plus(p) returns the upper bound of the noise function at p for level i
            upper_bound = bvh.bvh_i_plus(i_min, p)
            if upper_bound < isovalue:
                break
            i_min += 1
            # Safety break if BVH depth exceeded [G]
            if i_min >= bvh.max_depth:
                return None

        # Step 3: Compute sum from i_min to i_min + k
        noise_value = 0.0
        for j in range(i_min, i_min + k + 1):
            # Evaluate the noise function f_j at p
            noise_value += bvh.f_j(j, p)
            
        # Step 4: Calculate step size
        # Standard sphere tracing step size logic [G]
        # Assuming a Lipschitz constant L or derivative bound is available or estimated
        # For FBM, step size often scales with the amplitude of the current octave
        # Here we use a simplified difference-based step for demonstration
        diff = isovalue - noise_value
        # Avoid division by zero
        if abs(diff) < 1e-6:
            return t
        
        # Estimate step size. In practice, this depends on the specific sphere tracing
        # variant (e.g., using derivative bounds). A common simple approach for signed
        # distance fields or similar is proportional to the error.
        # For procedural noise sphere tracing, step size is often limited by the 
        # wavelength of the current octave i_min.
        step_size = abs(diff) * bvh.wavelength(i_min)
        
        # Safety factor to prevent overshooting [G]
        step_size *= 0.5
        
        # Step 5: Advance
        if step_size < 1e-6:
            return None # Too close to converge
            
        t += step_size
        
        # Step 6: Check convergence
        # Re-evaluate noise at new position to check if we hit the surface
        # This is implicit in the loop structure, but explicit check helps
        p_new = ray_origin + t * ray_direction
        # Find i_min for new position to re-evaluate accurately if needed
        # However, standard sphere tracing checks the function value at the new point
        # against the isovalue.
        
        # To be precise, we should check if the surface was crossed.
        # A simple check is if the noise value at the new point is close to isovalue
        # or if the step size became very small.
        
        # For robustness, we re-calculate i_min and noise at p_new
        i_min_new = 0
        while True:
            if bvh.bvh_i_plus(i_min_new, p_new) < isovalue:
                break
            i_min_new += 1
            if i_min_new >= bvh.max_depth:
                return None
                
        noise_new = 0.0
        for j in range(i_min_new, i_min_new + k + 1):
            noise_new += bvh.f_j(j, p_new)
            
        if abs(noise_new - isovalue) < 1e-4: # Convergence threshold
            return t
            
    return None
```

**Parameters:**
*   $k$: The number of additional functions to compute beyond $i_{min}$. Typical value is $1$ (Early Stop+1) [S1].
*   $v$: The isovalue used for comparison against BVH bounds [S1].

**Edge Cases and Pitfalls:**
*   **Early Stop+0 ($k=0$):** Computing only the minimum $f_i$ causes slow convergence at every level of the BVH traversal because the ray steps safely to the current outer bounding volume and repeats [S1]. This massively increases total steps and is particularly bad for grazing rays (rays passing close to but not entering a bounding volume) [S1].
*   **Grazing Rays:** Rays passing very close to a bounding volume without entering it can be considerably slowed down if $k$ is too low [S1].
*   **Step Size Reduction:** Stopping early reduces the number of $f_i$ computed but may result in smaller step sizes, potentially increasing the total number of steps required to converge, which could raise final cost [S1].
*   **Diminishing Returns:** Using $k > 1$ provides diminishing returns. It slightly increases step size but makes convergence issues even less likely. However, the added cost of computing more $f_i$ is usually not worth the small gains [S1].

## Subtopics

### [Early Stop + k](1938-early-stop-k.md)
Early Stop + k (ES+k) is an optimization for sphere tracing procedural volumes that prevents unnecessary intermediate convergence checks during BVH traversal by computing $k$ additional octaves per traversal step. It builds on [Early Stop](1790-early-stop.md) by trading a small increase in per-step function evaluations for a significant reduction in the total number of BVH traversal steps. Unlike standard Early Stop (ES+0), which may converge too slowly and incur high step counts, ES+k maintains a balance between step reduction and computational overhead, with ES+1 generally offering the best performance across diverse scenes.

## Operating characteristics
*   **Time Complexity:** Depends on the number of $f_i$ computed per step and the total number of steps [S1]. Early Stop reduces the number of $f_i$ evaluated per step compared to full sphere tracing, but may increase the number of steps if step sizes are smaller [S1].
*   **Memory Complexity:** Requires storage for the BVH structure [S1].
*   **Performance:** Early Stop+1 ($k=1$) drastically diminishes the performance loss associated with Early Stop+0 at a negligible cost (computing one extra $f_i$) [S1]. It is highly recommended over $k=0$ [S1]. Values of $k > 1$ offer diminishing returns and are generally not worth the extra computation [S1].
*   **Strengths:** Reduces computational cost by avoiding unnecessary high-frequency noise evaluations; handles large and detailed scenes efficiently [S1].
*   **Limitations:** Introduces bias if not carefully implemented (though the source focuses on cost reduction rather than unbiasedness); sensitive to grazing rays if $k$ is too low [S1].
*   **When to Use:** When rendering procedural volumetric noise with sphere tracing, especially for large and detailed scenes where high-frequency octaves are expensive [S1].
*   **When Not to Use:** When $k=0$ is used, due to severe performance degradation on grazing rays [S1].

## Background
Early Stop was introduced in the context of fast sphere tracing of procedural volumetric noise for very large and detailed scenes [S1]. It leverages the hierarchical nature of Bounding Volume Hierarchies (BVH) used to bound the noise functions to optimize the sphere tracing loop [S1]. The method addresses the inefficiency of computing all noise octaves at every step, which is particularly costly for high-frequency components [S1].
