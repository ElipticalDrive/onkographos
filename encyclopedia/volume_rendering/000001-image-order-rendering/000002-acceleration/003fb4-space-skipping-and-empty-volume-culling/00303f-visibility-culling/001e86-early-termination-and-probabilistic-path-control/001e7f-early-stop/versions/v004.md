# Early Stop

Also called: Early stop+0, Early stop+1

## Overview
Early Stop (ES) is an optimization for sphere tracing procedural volumes that limits the computation of noise frequencies ($f_i$) during ray marching to reduce computational cost [S1]. It solves the problem of excessive function evaluations by breaking the summation loop early based on the position's relation to Bounding Volume Hierarchy (BVH) bounding volumes [S1]. Unlike standard sphere tracing which computes all octaves, ES trades a small increase in per-step function evaluations (in variants like ES+1) for a significant reduction in the total number of BVH traversal steps, avoiding the slow convergence and "grazing ray" penalties associated with ES+0 [S1].

## How it works
**Inputs:**
*   Ray origin $\mathbf{o}$ and direction $\mathbf{d}$.
*   Isosurface value $v$.
*   BVH structure where each level $i$ has an upper bound inclusion function $BVH_{i+}(\mathbf{p})$ and lower bound $BVH_{i-}(\mathbf{p})$ [S1].
*   Noise frequency functions $f_i(\mathbf{p})$ for $i = 0, \dots, n$ [S1].
*   Parameter $k$: The number of additional functions to compute beyond the minimum index $i_{min}$ before breaking the loop [S1].

**Outputs:**
*   Intersection distance $t$ or null if no intersection is found within the ray length [S1].

**Data Structures:**
*   **BVH:** A hierarchy of bounding volumes. For each level $i$, the structure provides an upper bound function $BVH_{i+}(\mathbf{p})$ which returns the maximum possible value of the noise function $f_i(\mathbf{p})$ within that volume [S1].

**Algorithm Steps:**
1.  **Initialize:** Start sphere tracing from the ray origin. Let current position be $\mathbf{p}$ and step size $s$ [S1].
2.  **Find Minimum Index:** For the current position $\mathbf{p}$, determine the minimum index $i_{min}$ such that the position is outside the bounding volume at level $i_{min}$ [S1]. This is defined as:
    $$ i_{min} = \min\{i \mid BVH_{i+}(\mathbf{p}) < v\} $$
    If the position is inside the volume and searching for the isosurface, $i_{min}$ can equivalently be defined using the lower bound: $BVH_{i-}(\mathbf{p}) > v$ [S1].
3.  **Compute Sum:** Evaluate the noise sum $F(\mathbf{p})$ starting from $i_{min}$. The loop computes $f_i(\mathbf{p})$ for $i$ from $i_{min}$ up to $i_{min} + k$ [S1].
    *   During this computation, check $BVH_{i+}(\mathbf{p})$ for each $i$. If $BVH_{i+}(\mathbf{p}) < v$, the position is outside the bounding volume for that frequency, and further higher-frequency terms are unnecessary for determining the step size at this specific precision level [S1].
4.  **Step:** Calculate the step size $s$ based on the computed sum $F(\mathbf{p})$ and the isovalue $v$ [S1].
5.  **Advance:** Move the ray forward by $s$ [S1].
6.  **Repeat:** Return to Step 2 until the isosurface is hit or the ray exits the scene [S1].

**Parameters:**
*   $k$: The number of additional functions to compute beyond $i_{min}$ [S1]. Typical value is $k=1$ [S1].
*   $v$: The isovalue used for comparison against BVH bounds [S1].

**Edge Cases and Pitfalls:**
*   **Grazing Rays with ES+0:** Using $k=0$ (Early stop+0) causes slow convergence at every level of the BVH traversal because it steps safely to the current outer bounding volume and repeats [S1]. This massively increases total steps and is particularly bad for grazing rays (rays passing close to but not entering a bounding volume) [S1].
*   **Step Size Reduction:** Stopping early reduces the number of $f_i$ computed but may result in smaller step sizes, potentially increasing the total number of steps required to converge, which could raise final cost [S1].
*   **Diminishing Returns for $k>1$:** Using $k > 1$ provides diminishing returns. It slightly increases step size but makes convergence issues even less likely. However, the added cost of computing more $f_i$ is usually not worth the small gains compared to $k=1$ [S1].

## Subtopics

### [Early Stop + k](1938-early-stop-k.md)
An optimization that computes $k$ additional octaves per traversal step. ES+1 is generally recommended as it balances step reduction and computational overhead, avoiding the slow convergence of ES+0 without the diminishing returns of higher $k$.

## Operating characteristics
*   **Time Complexity:** Depends on the number of $f_i$ computed per step and the total number of steps [S1]. ES reduces the number of steps by allowing larger steps when far from the isosurface (by ignoring high-frequency noise that doesn't affect the coarse step size) [S1].
*   **Memory Complexity:** Requires storage for the BVH structure [S1].
*   **Strengths:** Drastically reduces performance loss from grazing rays compared to ES+0 at negligible cost (computing one extra $f_i$) [S1]. Avoids unnecessary function evaluations for high-frequency noise when the position is outside the corresponding BVH level [S1].
*   **Limitations:** May result in smaller step sizes if too few frequencies are computed, potentially increasing the total number of steps [S1]. ES+0 is inefficient due to slow convergence [S1].
*   **When to Use:** Use ES+1 ($k=1$) for most procedural volume sphere tracing scenarios to balance performance and accuracy [S1]. Avoid ES+0 due to grazing ray penalties [S1]. Avoid $k>1$ unless specific accuracy requirements justify the marginal step size increase [S1].

## Background
Early Stop was introduced in the context of fast sphere tracing of procedural volumetric noise for very large and detailed scenes [S1]. It leverages the hierarchical nature of Bounding Volume Hierarchies (BVH) applied to noise functions (such as Fractional Brownian Motion) to prune unnecessary computations [S1]. The method addresses the inefficiency of standard sphere tracing which evaluates all noise octaves at every step, regardless of whether the high-frequency details are relevant to the current step size or intersection detection [S1].
