# Adaptive Multi-Step Empty Voxel Skipping

Also called: Improved Ray Casting with Empty Voxel Skipping and Multi-Step Length, Space leap empty voxel ray-casting algorithm, Three-step jump algorithm

## Overview
Adaptive Multi-Step Empty Voxel Skipping is an acceleration technique for direct volume rendering that combines space leaping (empty voxel skipping) with adaptive variable step-size sampling [S1]. It solves the problem of redundant computation in large datasets containing significant empty space, such as medical CT scans, by bypassing empty regions entirely and adjusting sampling density based on local voxel occupancy [S1]. Unlike traditional equidistant ray casting, this method reduces computational overhead without altering the input data structure, distinguishing itself from siblings like [Occlusion Clipping with Orthogonal Opacity Map](990-occlusion-clipping-with-orthogonal-opacity-map.md) by operating directly on the ray traversal logic rather than pre-computed opacity maps [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D volume dataset (e.g., CT scan), camera parameters, and ray generation state.
*   **Output:** A 2D image with accumulated color and opacity.

**Data Structures:**
The algorithm is implemented by extending the base ray casting function interface. In the referenced implementation, a new class `vtkMyVolumeRayCastFunction` inherits from `vtkVolumeRayCastingFunction` [S1]. The core data structure is the ray state, which tracks the current position along the ray and its current operational mode [S1].

**Ray States:**
The ray operates in one of two mutually exclusive states [S1]:
1.  **Search State:** The ray traverses empty voxels to find the next non-empty voxel. No compositing occurs.
2.  **Accumulation State:** The ray samples non-empty voxels, accumulating color and transparency using front-to-back compositing.

**Algorithm Steps:**
1.  **Pre-check Validity:** Before processing a ray, determine if any non-empty voxels exist along the ray's path within the volume bounds. If no non-empty voxels are detected, mark the ray as invalid and skip all further operations for that ray [S1].
2.  **Initialize Ray State:** Set the ray to the **Search State** [S1].
3.  **Adaptive Step Selection:** Calculate the step length $s$ based on the local voxel density at the current ray position [S1]:
    *   If the current region contains many empty voxels, set $s$ to a longer value.
    *   If the voxel density is high (non-empty regions), set $s$ to a shorter value to maintain accuracy [S1].
4.  **Traverse and Compositing Loop:**
    *   While the ray is within the volume bounds:
        *   If in **Search State**: Advance the ray position by the current step length $s$. Check if the current voxel is non-empty. If non-empty, switch to **Accumulation State**. If empty, remain in **Search State** and repeat.
        *   If in **Accumulation State**: Sample the voxel at the current position. Accumulate color $C$ and opacity $\alpha$ using the standard front-to-back compositing equations. Update the ray position by $s$. Re-evaluate the local density to potentially adjust $s$ for the next step. If the accumulated opacity $\alpha_{acc}$ reaches a threshold (e.g., 1.0) or the ray exits the volume, terminate [S1].
5.  **Resample and Synthesize:** Perform resampling and compositing only on the identified non-empty voxels, skipping invalid computations on empty regions [S1].

**Pseudocode:**
```python
def render_ray(ray_origin, ray_direction, volume_data, volume_bounds):
    # Check if ray intersects volume bounds
    if not intersects_volume(ray_origin, ray_direction, volume_bounds):
        return transparent_color

    # Pre-check: Detect if any non-empty voxels exist along the ray
    # This is a simplified check; in practice, this might involve a bounding volume hierarchy or sparse grid lookup
    if not has_non_empty_voxels(ray_origin, ray_direction, volume_bounds, volume_data):
        return transparent_color

    # Initialize ray state
    current_pos = ray_origin
    ray_state = "SEARCH"  # SEARCH or ACCUMULATE
    accumulated_color = (0.0, 0.0, 0.0, 0.0)
    accumulated_opacity = 0.0
    
    # Initial step length (can be a default or derived from global density)
    step_length = get_initial_step_length(volume_data)

    while current_pos is within volume_bounds:
        voxel_value = sample_voxel(current_pos, volume_data)
        
        if ray_state == "SEARCH":
            if voxel_value is non_empty:
                ray_state = "ACCUMULATE"
                # Perform initial accumulation for the first non-empty voxel
                color, alpha = transfer_function(voxel_value)
                accumulated_color = color * alpha
                accumulated_opacity = alpha
            else:
                # Skip empty voxel
                current_pos = current_pos + ray_direction * step_length
                # Re-evaluate step length based on local density if needed
                step_length = adaptive_step_length(current_pos, volume_data)
                
        elif ray_state == "ACCUMULATE":
            # Accumulate current voxel
            color, alpha = transfer_function(voxel_value)
            # Front-to-back compositing
            # C_acc = C_acc + C_sample * alpha_sample * (1 - alpha_acc)
            # alpha_acc = alpha_acc + alpha_sample * (1 - alpha_acc)
            accumulated_color = accumulated_color + (color * alpha * (1.0 - accumulated_opacity))
            accumulated_opacity = accumulated_opacity + (alpha * (1.0 - accumulated_opacity))
            
            # Advance ray
            current_pos = current_pos + ray_direction * step_length
            
            # Re-evaluate step length based on new position's density
            step_length = adaptive_step_length(current_pos, volume_data)
            
            # Early termination if fully opaque
            if accumulated_opacity >= 1.0:
                break

    return accumulated_color

def adaptive_step_length(position, volume_data):
    # Determine local density around position
    density = compute_local_density(position, volume_data)
    if density is low:
        return LONG_STEP
    else:
        return SHORT_STEP
```

**Parameters:**
*   **Step Length ($s$):** A variable step size. It is not fixed. Typical values are not explicitly defined in the sources, but the logic dictates $s_{empty} > s_{dense}$ [S1].
*   **Thresholds:** Opacity threshold for early termination is not explicitly defined, but standard practice implies $\alpha_{acc} \ge 1.0$ [S1, G].

**Edge Cases and Pitfalls:**
*   **Porphyritic Artifacts:** The combination of empty voxel jumping and uneven (adaptive) sampling can cause a patchy or mottled appearance in the rendered image, particularly noticeable during rotation interactions [S1].
*   **Precision:** The method relies on accurate detection of empty vs. non-empty voxels. Incorrect classification leads to visual artifacts or missed data [S1].
*   **Boundary Conditions:** Rays that do not intersect the volume or pass entirely through empty space must be handled efficiently to avoid unnecessary computation [S1].

## Operating characteristics
*   **Time Complexity:** Reduces the number of samples per ray by skipping empty voxels. The complexity depends on the sparsity of the volume. In sparse volumes, it approaches $O(1)$ for empty rays and $O(N_{non-empty})$ for rays passing through data, compared to $O(N_{total})$ for equidistant sampling [S1].
*   **Memory Complexity:** Requires storage for the volume data and potentially auxiliary structures for empty voxel detection (e.g., bounding volumes or sparse grids). The VTK implementation inherits from `vtkVolumeRayCastingFunction`, implying minimal additional memory overhead beyond the base class [S1].
*   **Measured Performance:** Tested on Windows 7, Visual Studio 2010, VTK 5.10.1, using virtual human head CT scan data. Rendering speed was measured by rotation time. The method achieved significant speedup compared to traditional ray casting [S1].
*   **Strengths:** Reduces computational overhead without changing the input 2D sequence images. Maintains visual quality almost identical to the original method, despite artifacts [S1].
*   **Limitations:** Can introduce visual artifacts (porphyritic appearance) due to uneven sampling [S1]. The effectiveness depends on the sparsity of the volume; dense volumes may not benefit as much [S1].
*   **When to Use:** Suitable for large-volume datasets with significant empty space, such as medical CT scans [S1].
*   **When Not to Use:** Not suitable for dense volumes where empty space is minimal, as the overhead of adaptive step calculation may not be justified [S1].

## Background
*   **Origin:** The method was proposed in a paper titled "The research of improved ray casting algorithm on VTK" [S1].
*   **History:** It builds upon the traditional ray-casting algorithm proposed by Marc Levoy [S1, S8]. The algorithm was implemented using the Visualization Toolkit (VTK) [S1, S10].
*   **Development:** The method combines space leaping (empty voxel skipping) [S7] with adaptive multi-step length sampling [S1]. It was tested on VTK 5.10.1 [S1].
*   **Usage:** Primarily used in medical image visualization, specifically for CT scan data [S1].
