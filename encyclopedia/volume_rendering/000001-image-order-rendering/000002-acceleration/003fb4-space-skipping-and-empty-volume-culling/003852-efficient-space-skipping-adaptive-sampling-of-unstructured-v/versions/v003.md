# Efficient Space Skipping & Adaptive Sampling of Unstructured Volumes Using H.W. Accel. Ray Tracing

Also called: Space Skipping and Adaptive Sampling for Unstructured Volumes

## Overview
This method enables interactive visualization of large unstructured volumes (e.g., finite element simulations) by leveraging hardware-accelerated ray tracing to accelerate acceleration structure traversal and point-in-element tests [S1, unofficial]. It solves the bottleneck of traditional rasterization, which requires expensive front-to-back sorting of 20–40 GB of elements when the camera moves, and the limitation of existing space-skipping techniques that assume regular grids [S1, unofficial]. It sets itself apart from siblings like [SparseLeap](5152-sparseleap.md) by explicitly targeting unstructured meshes via KD-tree partitioning and using hardware ray tracing to handle both transparent element culling and large void region skipping without significant overhead [S1, unofficial].

## How it works
**Inputs:** An unstructured mesh (e.g., tetrahedral mesh) with scalar field values and a transfer function mapping scalar values to opacity and color.
**Outputs:** A rendered image with adaptive sampling rates and skipped empty space.

**Data Structures:**
1.  **KD-Tree:** Built over the mesh elements. It partitions the elements into a set of convex, disjoint regions (partitions) [S1, unofficial].
2.  **Partition Metadata:** For each region in the KD-tree, the following precomputed values are stored:
    *   $S_{min}$: Minimum scalar field value in the region.
    *   $S_{max}$: Maximum scalar field value in the region.
    *   $O_{max}$: Maximum opacity derived from the transfer function applied to $[S_{min}, S_{max}]$.
    *   $V_{color}$: Color variance within the region, calculated based on the transfer function output over the scalar range [S1, unofficial].

**Parameters:**
*   $R_{min}$: User-specified minimum sampling rate.
*   $R_{max}$: User-specified maximum sampling rate [S1, unofficial].

**Algorithm Steps:**
1.  **Build KD-Tree:** Construct a KD-tree over the input unstructured mesh elements to create convex disjoint regions [S1, unofficial].
2.  **Compute Metadata:** For each region, compute $S_{min}$, $S_{max}$, $O_{max}$, and $V_{color}$ [S1, unofficial].
3.  **Ray Traversal:** Use hardware-accelerated ray tracing (e.g., OptiX) to iterate rays through the active partitions [S1, unofficial].
4.  **Empty Space Skipping:** During traversal, skip any partition where $O_{max} = 0$ (entirely transparent elements) or where the partition is unoccupied (large void regions due to data sparsity) [S1, unofficial].
5.  **Adaptive Sampling:** For each partition that is not skipped, determine the sampling rate $R$ based on the local color variance $V_{color}$ [S1, unofficial].
6.  **Interpolation:** Interpolate $R$ between $R_{min}$ and $R_{max}$ based on $V_{color}$. High variance regions use $R_{max}$; low variance regions use $R_{min}$ [S1, unofficial].
7.  **Sampling:** Take samples along the ray within the partition at rate $R$ [S1, unofficial].
8.  **Termination:** Iterate steps 3–7 until the ray reaches maximum capacity (maximum number of samples) or exits the bounds of all partitions [S1, unofficial].

        s_max = max(region.scalar_values)

        v_color = compute_color_variance(region, s_min, s_max)
        partitions.append({
            's_min': s_min,
            's_max': s_max,
            'o_max': o_max,
            'v_color': v_color
        })
    return partitions

def compute_sampling_rate(v_color, v_min, v_max, r_min, r_max):
    """
    Interpolates sampling rate based on normalized color variance.
    """
    if v_max == v_min:
        return r_min
    normalized_v = (v_color - v_min) / (v_max - v_min)
    return r_min + normalized_v * (r_max - r_min)

        if partition['o_max'] == 0:
            continue  # Skip transparent partitions

        # Determine local sampling rate based on variance
        # Note: In a real implementation, v_min and v_max might be global

        # or a local range if not specified.
        # [G] Assuming global min/max variance for interpolation range.
        # If not provided, a safe default is to use the partition's own

**Edge Cases and Pitfalls:**
*   **Overhead:** The overhead introduced by the technique must be low; otherwise, it overshadows the performance benefits gained from reduced sampling [S1, unofficial].
*   **Data Sparsity:** Two forms of empty space exist: entirely transparent elements and large void regions due to sparsity. Both must be handled [S1, unofficial].
*   **Regular Grid Assumption:** Existing techniques often assume a regular grid, which does not apply to unstructured data. This method avoids that assumption [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the KD-tree traversal and the number of samples taken. Adaptive sampling reduces the number of samples in low-variance regions, while space skipping eliminates work in transparent/empty regions.
*   **Memory Complexity:** Requires storing the KD-tree and partition metadata. The datasets tested range from 12 million to 366 million tetrahedra, requiring up to 37 GB of GPU memory [S1, unofficial].
*   **Measured Performance:**
    *   **Segel Haas Dataset:** ~3.5x performance improvement by adaptively sampling and empty space skipping, preserving details in high-variance regions [S1, unofficial].
    *   **Japan Earthquake Dataset:** ~7x performance improvement, largely because a large portion of the volume has very similar data values allowing for adaptive sampling [S1, unofficial].
    *   **Small Dataset with Empty Space:** Performance improved from 4 to 20 frames per second using space skipping [S1, unofficial].
*   **Hardware:** Tested on RTX 8000 GPU (48 GB memory) using OptiX 6 and CUDA 10 [S1, unofficial].
*   **Strengths:** Handles large unstructured volumes (up to 37 GB) interactively; preserves details in high-variance regions; reduces overhead compared to rasterization sorting.
*   **Limitations:** Performance gain depends on data type; adaptive sampling works better than space skipping alone on datasets with little empty space but high variance [S1, unofficial].
