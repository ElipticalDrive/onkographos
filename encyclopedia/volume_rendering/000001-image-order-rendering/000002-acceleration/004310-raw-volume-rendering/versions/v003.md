# Raw Volume Rendering

Also called: Single Rendering Algorithm, vpRenderRawVolume

## Overview
Raw Volume Rendering is a direct rendering routine that processes raw voxel data and stores the result in the current image array, optionally accelerating the process if an octree is present in the context [S1]. It is designed for scenarios where the volume data or the opacity transfer function changes between renderings, distinguishing it from preclassified rendering which requires fixed classification [S1]. The variant that skips precomputation entirely is significantly slower and useful only for single renderings [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** A voxel array containing raw scalar or vector data, a classification function (opacity transfer function), view parameters, and shading parameters [S1, S2].
*   **Output:** The composited image stored in the current image array [S1].

**Data Structures:**
*   **Voxel Array:** The raw volume data [S1]. The layout and field specifications must be valid; otherwise, `VPERROR_BAD_VOXEL` is returned [S1].
*   **Intermediate Image:** An internal work buffer used to hold temporary results during rendering [S1].
*   **Octree (Optional):** If present in the context (created via `vpCreateMinMaxOctree`), it is used to accelerate rendering by skipping empty space [S1]. The variant that does not use any precomputed data structures skips octree construction entirely [S2].

**Parameters:**
*   **Maximum Opacity Threshold (`VP_MAX_RAY_OPACITY`):** A value specifying the threshold for pixel opacity [S1]. If reached, no more voxels are composited [S1]. Default is 1.0. A typical good value is 0.95. Values closer to 1.0 result in longer rendering times but less error [S1].
*   **Intermediate Image Hints (`VP_INT_WIDTH_HINT`, `VP_INT_HEIGHT_HINT`):** Specify the maximum size of the internal work buffer to avoid reallocation overhead [S1]. If no scaling is present, the max dimension is twice the largest volume dimension [S1].
*   **Intermediate Image Queries (`VP_INTERMEDIATE_WIDTH`, `VP_INTERMEDIATE_HEIGHT`):** Used to find the precise bound for the intermediate image size required for rendering with current viewing parameters [S1].

**Steps:**
1.  Load the volume data [S2].
2.  (Optional) Precompute the min-max octree with `vpCreateMinMaxOctree()` if acceleration is desired and the volume is static [S2]. If this step is skipped, the rendering is significantly slower and suitable only for single renderings [S2].
3.  Choose the classification function (opacity transfer function) [S2].
4.  Set the view and shading parameters [S2].
5.  Render with `vpRenderRawVolume()` [S2].

def set_volume_parameters(vpc, data):
    vpc.volume_size = data.shape
    vpc.voxel_size = data.voxel_size
    vpc.voxel_fields = data.fields
    if not vpc.volume_size or not vpc.voxel_size:
        return VPERROR_BAD_VOLUME
    if not vpc.voxel_fields:
        return VPERROR_BAD_VOXEL
    return VP_OK

    vpc.opacity_tables = func.tables
    vpc.field_mapping = func.field_mapping
    if not vpc.opacity_tables or not vpc.field_mapping:
        return VPERROR_BAD_CLASSIFIER
    return VP_OK

    if not is_matrix_non_singular(vpc.view_matrix):

    return VP_OK

**Edge Cases and Pitfalls:**
*   **Shading Lookup Tables Error (`VPERROR_BAD_SHADER`):** Occurs if tables are sized incorrectly, voxel fields used to index are invalid, or the number of material types is invalid [S1].
*   **Singular Matrix Error (`VPERROR_SINGULAR`):** Occurs if one of the current view transformation matrices is singular [S1].
*   **Bad Volume Error (`VPERROR_BAD_VOLUME`):** Occurs if volume size has not been set or is invalid, or there is no volume data [S1].
*   **Bad Voxel Error (`VPERROR_BAD_VOXEL`):** Occurs if voxel size or voxel fields have not been specified or have been incorrectly specified [S1].
*   **Bad Classifier Error (`VPERROR_BAD_CLASSIFIER`):** Occurs if opacity transfer function tables have invalid sizes, are associated with invalid voxel fields, or have been incorrectly specified [S1]. This error is specific to `vpRenderRawVolume` [S1].
*   **Bad Shadow Error (`VPERROR_BAD_SHADOW`):** Occurs if the angle between the shadow light vector and the viewing direction is too large (must be less than 45 degrees) [S1]. Either change light direction or disable shadows [S1].

## Operating characteristics
*   **Performance:** Raw Volume Rendering is significantly slower than rendering with a precomputed min-max octree or using `vpRenderClassifiedVolume` [S1, S2].
*   **Acceleration:** Rendering with an octree is significantly faster than without, but still slower than rendering with `vpRenderClassifiedVolume` [S1].
*   **Use Cases:** It is useful only for single renderings from a volume [S2]. `vpRenderClassifiedVolume` is preferred when the same volume is rendered multiple times with the same opacity transfer function [S1].
*   **Memory:** Uses an intermediate image work buffer. The size of this buffer depends on the volume size and view transformation [S1]. Reallocation overhead can be avoided by setting size hints (`VP_INT_WIDTH_HINT`, `VP_INT_HEIGHT_HINT`) [S1].

## Background
Raw Volume Rendering is part of the VolPack library, a software library for volume rendering [S1, S2]. It is one of three main rendering algorithms provided by VolPack, alongside `vpRenderClassifiedVolume` and the Min-Max Octree algorithm [S2]. The method is implemented via the `vpRenderRawVolume` routine [S1].
