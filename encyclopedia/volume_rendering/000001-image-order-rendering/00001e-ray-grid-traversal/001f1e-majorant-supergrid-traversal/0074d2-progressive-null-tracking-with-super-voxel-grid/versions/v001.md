# Progressive Null-Tracking with Super-Voxel Grid

Also called: progressive medium clamping, spatially varying bounding extinctions

## Overview
Progressive Null-Tracking with Super-Voxel Grid is a technique to make null-tracking methods resilient to non-bounding extinctions by progressively estimating and updating spatially varying bounding extinctions ($\mu_t$) on a coarse grid during rendering [S1]. It builds on [Majorant Supergrid Traversal](1967-majorant-supergrid-traversal.md) by allowing the bounding extinction to adapt to local density variations rather than relying on a single global worst-case bound. Unlike progressive photon mapping or many-light methods, which introduce bias in every iteration (e.g., from blurring or loss of short-range transport), this approach's individual passes become unbiased once a bounding extinction is reached [S1].

## How it works
**Inputs and Outputs:**
- Input: A volumetric medium defined by spatially varying extinction $\mu_e(\mathbf{x})$, a rendering pass index $k$, and a coarse grid of super-voxels covering the medium extents.
- Output: Updated bounding extinction values $\mu_t^{(k+1)}$ for each super-voxel, used in the subsequent rendering pass.

**Data Structures:**
- **Super-Voxel Grid:** A 3D grid of resolution $N^3$ (typically $80^3$) fitting the medium extents [S1].
- **Grid Cell Layout:** Each cell stores a single floating-point value representing the estimated bounding extinction $\mu_t$ for the portion of the medium it spans [S1].
- **Initialization:** $\mu_t^{(1)} = 0.01$ for all super-voxels to simulate a near-worst-case scenario for prior methods [S1].

**Numbered Steps:**
1. **Initialization:** Set the bounding extinction for all super-voxels in the grid to $\mu_t^{(1)} = 0.01$ [S1].
2. **Rendering Pass $k$:** Render the scene using the current bounding extinction grid $\mu_t^{(k)}$. Rays traverse the medium using null-tracking, where the probability of interaction is determined by $\mu_t^{(k)}$ [S1].
3. **Density Evaluation:** For each super-voxel, evaluate the actual extinction $\mu_e(\mathbf{x})$ along rays passing through that voxel during pass $k$ [S1].
4. **Update Bounding Extinction:** Independently for each super-voxel, update the total extinction $\mu_t^{(k+1)}$ for the next pass based on the density evaluations from pass $k$ [S1]. The update formula is not explicitly provided in the sources, but it is described as a "scene-adaptive and spatially-adaptive update formula" [S1].
5. **Multithreading:** Separate threads write updated bounding extinctions into the super-voxel grid independently with no synchronization [S1]. The method is resilient to race conditions, though intermediate states are non-deterministic [S1].
6. **Iteration:** Increment $k$ and repeat steps 2-5 until convergence or a maximum number of passes is reached [S1].

**Formulas:**
- $\mu_t^{(k+1)}$: Bounding extinction for super-voxel $i$ at pass $k+1$ [S1].
- $\mu_t^{(1)} = 0.01$: Initial bounding extinction for all super-voxels [S1].
- $\mu_e(\mathbf{x})$: Actual spatially varying extinction at position $\mathbf{x}$ [S1].

**Parameters:**
- Grid Resolution: $80^3$ super-voxels covering the medium extents [S1].
- Initial Extinction: $\mu_t^{(1)} = 0.01$ for all super-voxels [S1].

**Edge Cases and Pitfalls:**
- **Race Conditions:** The naive multithreading scheme is resilient to race conditions, but intermediate states are non-deterministic. A more sophisticated multithreading scheme is needed if fully deterministic intermediate behavior is desired [S1].
- **Convergence:** The method relies on the bounding extinction eventually reaching a value that bounds the actual extinction. If the update formula is not robust, convergence may be slow or fail [S1].
- **Initialization:** Initializing with a very low value (0.01) creates a near-worst-case scenario for prior methods, highlighting the robustness of the progressive approach [S1].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** $O(N^3)$ for the super-voxel grid, where $N=80$ [S1].
- **Measured Performance:** Not given in the sources.
- **Scaling:** Not given in the sources.
- **Strengths:** Resilient to non-bounding extinctions; individual passes become unbiased once a bounding extinction is reached; robust to race conditions in multithreading [S1].
- **Limitations:** Intermediate states are non-deterministic with naive multithreading; requires multiple rendering passes to converge [S1].
- **When to Use:** When the medium has significant spatial variation in extinction and a global bounding extinction is inefficient [S1].
- **When Not to Use:** When deterministic intermediate behavior is required without sophisticated synchronization [S1].

## Background
- **Origin:** The technique was introduced by Davidovič et al. in 2012 [S1].
- **History and Development:** The method is an extension of null-tracking techniques, aiming to improve efficiency in volumetric rendering by adapting bounding extinctions to local density variations [S1].
- **Usage:** Implemented in PBRT for testing and comparison, with plans to incorporate it into production renderers [S1].
