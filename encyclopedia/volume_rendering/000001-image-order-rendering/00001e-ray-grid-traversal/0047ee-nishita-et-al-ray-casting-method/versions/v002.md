# Nishita et al. Ray Casting Method
Also called: Nishita Ray Casting
## Overview
A ray casting technique for rendering participating media that integrates radiance only over segments of a ray that are illuminated by light sources, utilizing precomputed shadow and illumination volumes [S1]. It distinguishes itself from standard ray marching by avoiding integration in shadowed regions and from Max’s original scan-line approach by operating in ray space, while extending support to spotlights with angular distributions beyond parallel light sources [S1]. Builds on [Ray-grid traversal](17-ray-grid-traversal.md).
## How it works
The method computes the radiance along a ray by intersecting it with shadow volumes generated by occluding geometry and illumination volumes generated by light sources, integrating only where these volumes overlap (lit segments) [S1].

**Inputs and Outputs:**
- Input: Scene geometry (polygons), light sources (parallel or spotlights), participating medium properties (density, phase function) [S1].
- Output: Pixel color/intensity [G].

**Data Structures:**
- Shadow Volumes: Constructed from scene polygons relative to light sources [S1].
- Illumination Volumes: Constructed from light source geometry [S1].
- Ray Data: Origin $\mathbf{o}$, direction $\mathbf{d}$ [G].

**Steps:**
1. **Volume Construction:** Generate shadow volumes for all occluders relative to each light source, and illumination volumes for each light source [S1].
2. **Ray Intersection:** For each pixel, cast a ray from the camera and intersect it with the shadow and illumination volumes to determine intervals of shadow and light [S1].
3. **Segment Identification:** Identify "lit segments" where the ray is inside an illumination volume but outside any shadow volume [S1].
4. **Integration:** For each lit segment, integrate the radiance transfer equation along the ray interval [S1]. For a point light source and constant density medium with isotropic scattering, this yields an analytical function of distance [S1]. For parallel light and layered density, numerical integration is used [S1].
5. **Accumulation:** Sum the contributions from all lit segments [S1].

**Formulas:**
Not given in the sources.

**Parameters:**
- Light type: Parallel or Spotlight [S1].
- Medium density: Constant or layered [S1].

**Edge Cases:**
- Spotlights with angular distributions require specific volume construction compared to parallel lights [S1].
- Degenerate cases where shadow and illumination boundaries coincide must be handled to avoid double counting or gaps [G].

**Pseudocode:**
```python
def nishita_ray_casting(ray_origin, ray_direction, shadow_intervals, illum_intervals, medium):
    # 1. Intersect ray with shadow and illumination volumes to get t-intervals
    shadow_t = list(shadow_intervals)
    illum_t = list(illum_intervals)
    
    # 2. Determine lit segments (illumination minus shadow)
    lit_segments = []
    for i_start, i_end in illum_t:
        current_start = i_start
        for s_start, s_end in shadow_t:
            if s_start < i_end and s_end > i_start:
                if s_start > current_start:
                    lit_segments.append((current_start, s_start))
                current_start = max(current_start, s_end)
        if current_start < i_end:
            lit_segments.append((current_start, i_end))
            
    total_radiance = 0.0
    
    # 3. Integrate over lit segments
    for start, end in lit_segments:
        # Integration logic depends on light type and medium density [S1]
        # For point light and constant density: analytical function of distance [S1]
        # For parallel light and layered density: numerical integration [S1]
        # Not given in the sources.
        segment_radiance = 0.0 
        total_radiance += segment_radiance
        
    return total_radiance
```
## Subtopics

### Watt's Backward Beam Tracing
Applies Nishita’s method to consider light/water interaction in a two-pass backward beam tracing method to display underwater shafts of light [S1]. It is chosen when rendering complex light/water interactions in underwater scenes [S1].

### [Stam and Fiume Blob Renderer](12227-stam-and-fiume-blob-renderer.md)
A volumetric rendering approach for gaseous phenomena that models non-uniformly modified density blobs convected by wind fields and diffusion processes. It differs from standard particle systems by treating blobs as spherical particles with normally distributed gas volumes, rendered using diffusion equations. It applies a front-to-back strategy to handle turbulent fields.

## Operating characteristics
The method avoids integration in shadowed regions, potentially reducing computation compared to full ray marching [S1]. However, it requires the construction of shadow and illumination volumes, which adds preprocessing complexity [S1].
## Background
Originated from Nishita et al. [62], building on Max’s ideas of shadow and illumination volumes but shifting from scan-line to ray casting [S1]. Extended to handle spotlights with angular distributions [S1]. Used in computer graphics for rendering participating media, particularly for effects like shafts of light in fog or water [S1].
