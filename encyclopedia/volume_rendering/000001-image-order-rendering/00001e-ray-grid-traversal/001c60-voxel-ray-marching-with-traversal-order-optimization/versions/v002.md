# Voxel Ray Marching with Traversal Order Optimization

Also called: 33 float points ray marching, 3D Texture Path Tracer, Volume Ray Marching

## Overview
Voxel Ray Marching with Traversal Order Optimization renders a 3D voxel texture by marching rays from the camera through the volume, compositing samples with front-to-back alpha blending to visualize the volume [S1, unofficial]. It differs from standard fixed-step ray marching by optimizing the traversal order of voxel boundaries using precomputed time deltas ($t_{\Delta}$) and maximum boundary times ($t_{max}$), minimizing floating-point operations per step [S2, unofficial]. The algorithm advances analytically from one cell boundary to the next, avoiding fixed-distance sampling steps [S5, S7, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   Ray origin ($r_{origin}$) and direction ($r_{direction}$), normalized [S2, unofficial].
    *   Voxel grid dimensions ($V_{grid} = (W, H, D)$) in number of voxels [S2, unofficial].
    *   Physical volume size ($V_{size}$) [S2, unofficial].
    *   3D texture sampler ($T_{3D}$) containing RGBA voxel data [S1, S2, unofficial].
    *   Alpha clip threshold ($\alpha_{clip}$) [S2, unofficial].
    *   (Optional) Front/Back FBO textures for ray origin determination [S1, unofficial].
*   **Outputs:**
    *   Computed color ($C_{out}$) and hit status [S1, S2, unofficial].

**Data Structures:**
*   `recordVolume`: A structure holding the ray hit result.
    *   `hit` (bool): True if an opaque voxel was found.
    *   `color` (vec3): The accumulated or hit color.
    *   `position` (vec3): The world-space position of the hit.
    *   `normal` (vec3): The surface normal at the hit point.
    *   `t` (float): The distance along the ray to the hit.

**Precomputation:**
1.  **Step Direction:** Determine the integer step direction for each axis based on the sign of the ray direction components:
    $$
    stepX = \begin{cases} 1 & \text{if } r_{direction}.x > 0 \\ -1 & \text{otherwise} \end{cases}
    $$
    (Similarly for $stepY$ and $stepZ$) [S2, unofficial].
2.  **Time Delta ($t_{\Delta}$):** Calculate the time to travel one voxel unit along each axis. This represents the distance between adjacent voxel boundaries projected onto the ray [S2, unofficial].
    $$
    t_{\Delta X} = \frac{|V_{size} / W|}{|r_{direction}.x|}
    $$
    $$
    t_{\Delta Y} = \frac{|V_{size} / H|}{|r_{direction}.y|}
    $$
    $$
    t_{\Delta Z} = \frac{|V_{size} / D|}{|r_{direction}.z|}
    $$
    [S2, unofficial].
3.  **Initial Position and Index:**
    *   Calculate the current world position on the ray: $pos = r_{origin} + r_{direction} \times t_{entry}$ (where $t_{entry}$ is the distance to the volume entry point) [S2, unofficial].
    *   Convert to voxel indices:
        $$
        X = \lfloor pos.x / V_{size} \times W \rfloor
        $$
        $$
        Y = \lfloor pos.y / V_{size} \times H \rfloor
        $$
        $$
        Z = \lfloor pos.z / V_{size} \times D \rfloor
        $$
    *   **Boundary Guard:** If any index equals the grid dimension (e.g., $X == W$), decrement it by 1 to stay within valid bounds $[0, \text{dim}-1]$ [S2, unofficial].
4.  **Next Boundary Index:** Determine the index of the next voxel boundary along each axis:
    $$
    nextX = \begin{cases} 1 & \text{if } r_{direction}.x > 0 \\ 0 & \text{otherwise} \end{cases}
    $$
    (Similarly for $nextY$ and $nextZ$) [S2, unofficial].
5.  **Initial $t_{max}$:** Calculate the time to reach the next voxel boundary along each axis [S2, unofficial]. First, get the world position of the next boundary:
    $$
    nextPos = \text{getPosbyIndex}(X + nextX, Y + nextY, Z + nextZ)
    $$
    Then:
    $$
    t_{max X} = \frac{nextPos.x - pos.x}{r_{direction}.x}
    $$
    $$
    t_{max Y} = \frac{nextPos.y - pos.y}{r_{direction}.y}
    $$
    $$
    t_{max Z} = \frac{nextPos.z - pos.z}{r_{direction}.z}
    $$
    [S2, unofficial].

**Main Algorithm:**
1.  **Initial Sample:** Sample the voxel at $(X, Y, Z)$. If the alpha value is greater than $\alpha_{clip}$, set `rec.hit = true`, store the color, position, and normal, and return [S2, unofficial].
2.  **Marching Loop:** While `!rec.hit`:
    *   Compare $t_{max X}$, $t_{max Y}$, and $t_{max Z}$ to determine the next boundary to cross [S2, unofficial].
    *   **Case 1: $t_{max X}$ is smallest:**
        *   Increment $X$ by $stepX$.
        *   Check boundary: If $X < 0$ or $X \ge W$, break loop [S2, unofficial].
        *   Update $t_{max X} \leftarrow t_{max X} + t_{\Delta X}$ [S2, unofficial].
        *   Set potential normal to $(-stepX, 0, 0)$ [S2, unofficial].
    *   **Case 2: $t_{max Z}$ is smallest (and $t_{max X} > t_{max Z}$):**
        *   Increment $Z$ by $stepZ$.
        *   Check boundary: If $Z < 0$ or $Z \ge D$, break loop [S2, unofficial].
        *   Update $t_{max Z} \leftarrow t_{max Z} + t_{\Delta Z}$ [S2, unofficial].
        *   Set potential normal to $(0, 0, -stepZ)$ [S2, unofficial].
    *   **Case 3: $t_{max Y}$ is smallest (and $t_{max X} > t_{max Y}$ and $t_{max Z} > t_{max Y}$):**
        *   Increment $Y$ by $stepY$.
        *   Check boundary: If $Y < 0$ or $Y \ge H$, break loop [S2, unofficial].
        *   Update $t_{max Y} \leftarrow t_{max Y} + t_{\Delta Y}$ [S2, unofficial].
        *   Set potential normal to $(0, -stepY, 0)$ [S2, unofficial].
    *   **Case 4: $t_{max Z}$ is smallest (remaining case):**
        *   Increment $Z$ by $stepZ$.
        *   Check boundary: If $Z < 0$ or $Z \ge D$, break loop [S2, unofficial].
        *   Update $t_{max Z} \leftarrow t_{max Z} + t_{\Delta Z}$ [S2, unofficial].
        *   Set potential normal to $(0, 0, -stepZ)$ [S2, unofficial].
    *   **Sample New Voxel:** After updating indices, sample $T_{3D}(X, Y, Z)$ [S2, unofficial]. If alpha $> \alpha_{clip}$, set `rec.hit = true`, store color, position ($r_{origin} + r_{direction} \times potentialTime$), and normal, and break loop [S2, unofficial].

**Alternative Fixed-Step Approach (S1):**
Some implementations use a fixed step size ($STEP\_LENGTH = 0.005$) instead of boundary traversal [S1, unofficial].
1.  Compute step count: $N = \text{length}(direction) \times INV\_STEP\_LENGTH$ [S1, unofficial].
2.  Loop $step$ from 0 to $N$:
    *   $currentPoint = origin + step \times STEP\_LENGTH \times direction$ [S1, unofficial].
    *   Sample texture at scaled/biased coordinate [S1, unofficial].
    *   Composite: $color_{new} = color_{old} + (1.0 - color_{old}.a) \times sample_{rgb}$ [S1, unofficial].
    *   Stop if $color.a \ge 0.99$ or step limit reached [S1, unofficial].
    *   Apply gamma correction: $pow(color.rgb, 1.0/2.2)$ [S1, unofficial].

**Pseudocode (Optimized Traversal):**

```python
def raymarch_volume(r_origin, r_direction, volume_size, volume_grid, texture_3d, alpha_clip):
    """
    r_origin: vec3
    r_direction: vec3 (normalized)
    volume_size: float (physical size of the volume)
    volume_grid: vec3 (W, H, D in voxels)
    texture_3d: 3D texture sampler
    alpha_clip: float (threshold)
    """
    # 1. Precompute step directions [S2, unofficial]
    step_x = 1 if r_direction.x > 0.0 else -1
    step_y = 1 if r_direction.y > 0.0 else -1
    step_z = 1 if r_direction.z > 0.0 else -1

    # 2. Precompute t_delta (time to cross one voxel) [S2, unofficial]
    # Guard against zero direction components to prevent division by zero [G]
    t_delta_x = float('inf') if r_direction.x == 0.0 else abs((volume_size / volume_grid.x) / r_direction.x)
    t_delta_y = float('inf') if r_direction.y == 0.0 else abs((volume_size / volume_grid.y) / r_direction.y)
    t_delta_z = float('inf') if r_direction.z == 0.0 else abs((volume_size / volume_grid.z) / r_direction.z)

    # 3. Initial position and voxel index [S2, unofficial]
    pos = r_origin
    X = int(floor(pos.x / volume_size * volume_grid.x))
    Y = int(floor(pos.y / volume_size * volume_grid.y))
    Z = int(floor(pos.z / volume_size * volume_grid.z))

    # Boundary guard: clamp to valid range [0, dim-1] [S2, unofficial]
    if X >= volume_grid.x: X -= 1
    if Y >= volume_grid.y: Y -= 1
    if Z >= volume_grid.z: Z -= 1
    if X < 0: X = 0
    if Y < 0: Y = 0
    if Z < 0: Z = 0

    # 4. Determine next boundary indices [S2, unofficial]
    next_x_offset = 1 if r_direction.x > 0.0 else 0
    next_y_offset = 1 if r_direction.y > 0.0 else 0
    next_z_offset = 1 if r_direction.z > 0.0 else 0

    # 5. Initial t_max [S2, unofficial]
    # Compute world position of the next boundary plane [G]
    voxel_size_x = volume_size / volume_grid.x
    voxel_size_y = volume_size / volume_grid.y
    voxel_size_z = volume_size / volume_grid.z
    
    next_pos_x = vec3((X + next_x_offset + 0.5) * voxel_size_x, (Y + 0.5) * voxel_size_y, (Z + 0.5) * voxel_size_z)
    next_pos_y = vec3((X + 0.5) * voxel_size_x, (Y + next_y_offset + 0.5) * voxel_size_y, (Z + 0.5) * voxel_size_z)
    next_pos_z = vec3((X + 0.5) * voxel_size_x, (Y + 0.5) * voxel_size_y, (Z + next_z_offset + 0.5) * voxel_size_z)

    t_max_x = (next_pos_x.x - pos.x) / r_direction.x if r_direction.x != 0.0 else float('inf')
    t_max_y = (next_pos_y.y - pos.y) / r_direction.y if r_direction.y != 0.0 else float('inf')
    t_max_z = (next_pos_z.z - pos.z) / r_direction.z if r_direction.z != 0.0 else float('inf')

    potential_time = 0.0
    potential_normal = vec3(0, 0, 0)

    # 6. Initial Sample [S2, unofficial]
    sample = texture_3d.sample(X, Y, Z)
    if sample.a > alpha_clip:
        return {'hit': True, 'color': sample.rgb, 'position': pos, 'normal': potential_normal}

    # 7. Marching Loop
    while True:
        # Independent if checks for ties as per mathematical foundation [S5]
        if t_max_x <= t_max_y and t_max_x <= t_max_z:
            X += step_x
            if X < 0 or X >= volume_grid.x: break
            t_max_x += t_delta_x
            potential_time = t_max_x
            potential_normal = vec3(-float(step_x), 0, 0)

        if t_max_y <= t_max_x and t_max_y <= t_max_z:
            Y += step_y
            if Y < 0 or Y >= volume_grid.y: break
            t_max_y += t_delta_y
            potential_time = t_max_y
            potential_normal = vec3(0, -float(step_y), 0)

        if t_max_z <= t_max_x and t_max_z <= t_max_y:
            Z += step_z
            if Z < 0 or Z >= volume_grid.z: break
            t_max_z += t_delta_z
            potential_time = t_max_z
            potential_normal = vec3(0, 0, -float(step_z))

        # Sample New Voxel [S2, unofficial]
        sample = texture_3d.sample(X, Y, Z)
        if sample.a > alpha_clip:
            return {'hit': True, 'color': sample.rgb, 'position': pos + r_direction * potential_time, 'normal': potential_normal}

    return {'hit': False}
```

### [Voxel Raymarching with Screen Filters](2555-voxel-raymarching-with-screen-filters.md)
Extends the standard traversal loop with a switchable set of screen filters (Normal, Position, Iterations, Flat Color, Depth, and Toon) that override or modify the final output color based on ray metadata, rather than relying solely on pre-filtered screen-space accumulation or hierarchical structures.

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of voxels traversed along the ray. The traversal logic is $O(1)$ per voxel step, making it highly efficient for dense grids compared to hierarchical methods which have overhead for tree traversal [S2, unofficial].
*   **Memory Complexity:** $O(W \times H \times D)$ for the dense voxel grid. No additional acceleration structures are required [S2, unofficial].
*   **Performance:** The method is noted for high efficiency due to minimal floating-point operations per step (33 float points calculation reference) [S2, unofficial]. It is suitable for real-time rendering on GPUs [S1, S2, unofficial].
*   **Strengths:** Simple implementation, low memory overhead for acceleration structures, predictable performance [S2, unofficial].
*   **Limitations:** Performance degrades with large empty spaces in the volume (no culling). Requires dense grid storage. Sensitive to ray direction being exactly zero on any axis (division by zero in $t_{\Delta}$ and $t_{max}$) [S2, unofficial].

## Background
The method is described in "A Voxel PathTracing Engine" by Jiayu He, which references a paper explaining the "33 float points" calculation optimization [S2, unofficial]. The technique is a specific application of DDA (Digital Differential Analyzer) traversal adapted for 3D voxel textures [S2, unofficial].
