# Tiled Ray Marching with Grid Sampling

Also called: Python-loop renderer, Tiled rendering

## Overview
Renders a single view of a 3D volume by generating rays, sampling density via grid sampling, and accumulating attenuation [S1, unofficial]. It supports tiling to manage memory usage for large images [S1, unofficial]. It differs from [Voxel Ray Marching with Traversal Order Optimization](1251-voxel-ray-marching-with-traversal-order-optimization.md) by using dense grid sampling (e.g., `grid_sample`) rather than sparse voxel traversal, and by explicitly tiling the image plane to bound peak memory usage [S1, unofficial].

## How it works
**Inputs:**
- `density`: Volume density tensor of shape $(C, W, H, D)$ or $(1, C, W, H, D)$ [S1, unofficial].
- `camera_matrix`: Camera-to-world or world-to-camera matrix $(4, 4)$ or batched $(B, 4, 4)$ [S1, unofficial].
- `ijk2ras`: Transformation matrix from IJK (voxel) space to RAS (world) space $(4, 4)$ [S1, unofficial].
- `ras2ijk`: Transformation matrix from RAS to IJK space $(4, 4)$ [S1, unofficial].
- `ray_samples`: Number of samples per ray [S1, unofficial].
- `near`, `far`: Clipping distances in mm [S1, unofficial].
- `tile_h`, `tile_w`: Tile dimensions for memory management (default 256x256) [S1, unofficial].
- `use_beer_lambert`: Boolean flag for accumulation model [S1, unofficial].
- `density_factor`: Scaling factor for non-Beer-Lambert mode [S1, unofficial].
- `scatter`: Optional scatter channels [S1, unofficial].
- `apply_poisson`: Boolean flag for noise injection [S1, unofficial].

**Outputs:**
- Rendered image tensor (color/transmission) [S1, unofficial].
- Optional optical depth $\tau$ [S1, unofficial].

**Data Structures:**
- `dirs_cam`: Camera-space view directions tensor of shape $(H, W, 3)$ [S1, unofficial].
- `dirs_world`: World-space view directions tensor of shape $(H, W, 3)$ [S1, unofficial].
- `dirs_ijk`: IJK-space view directions tensor of shape $(H, W, 3)$ [S1, unofficial].
- `origin_ijk`: IJK-space camera origin tensor of shape $(3)$ [S1, unofficial].
- `depths`: Sample depths along ray tensor of shape $(ray\_samples)$ [S1, unofficial].
- `ijk`: IJK coordinates for all samples tensor of shape $(ray\_samples, H, W, 3)$ [S1, unofficial].

**Steps:**

1. **Initialize Camera Directions:**
   Compute vertical field of view (fov) in radians. Generate normalized camera-space view directions `dirs_cam` of shape $(H, W, 3)$ [S1, unofficial].

2. **Extract Camera Parameters:**
   Extract camera-to-world rotation `cam2world` and position `cam_pos` from `camera_matrix`. If the translation norm of `camera_matrix[:, :3, 3]` is less than 1.0, invert the matrix to get camera-to-world [S1, unofficial].
   $$ \text{dirs\_world} = \text{einsum}('ij,hwj->hwi', \text{cam2world}, \text{dirs\_cam}) $$
   [S1, unofficial]

3. **Transform to IJK Space:**
   Extract RAS-to-IJK rotation $R$ and translation $t$ from `ras2ijk`. Compute scale factor:
   $$ s = \frac{2.0}{\text{vol\_shape} - 1} $$
   where `vol_shape` is $(D, H, W)$ [S1, unofficial].
   Transform world-space directions to IJK space:
   $$ \text{dirs\_ijk} = \text{dirs\_world} @ R^T $$
   Transform camera position to IJK space:
   $$ \text{origin\_ijk} = \text{cam\_pos} @ R^T + t $$
   [S1, unofficial]

4. **Generate Sample Depths:**
   Compute sample depths along the ray:
   $$ \text{depths} = \text{near} + (\text{far} - \text{near}) \times \text{linspace}(0, 1, \text{ray\_samples}) $$
   [S1, unofficial]

5. **Compute IJK Coordinates:**
   Compute IJK coordinates for all samples:
   $$ \text{ijk} = s \times (\text{origin\_ijk} + \text{dirs\_ijk} \times \text{depths}[:, \text{None}, \text{None}, \text{None}]) - 1 $$
   Resulting shape is $(ray\_samples, H, W, 3)$ [S1, unofficial].

6. **Prepare Density Tensor:**
   Unsqueeze density tensor to shape $(1, C, W, H, D)$ for `grid_sample` [S1, unofficial].

7. **Render Tile Function:**
   For a given tile of coordinates `coords_tile` of shape $(1, D, H_{tile}, W_{tile}, 3)$:
   - Sample density:
     $$ \text{dens\_tile} = \text{F.grid\_sample}(\text{density\_b}, \text{coords\_tile}, \text{align\_corners}=\text{False}) $$
     [S1, unofficial]
   - If `use_beer_lambert` is True:
     - Compute optical depth:
       $$ \tau = \sum (\text{dens\_tile} \times \text{step\_size}, \text{dim}=2) $$
       where $\text{step\_size} = 0.1 \times (\text{far} - \text{near}) / \text{ray\_samples}$ [S1, unofficial].
     - If `return_tau` is True, apply Poisson noise to $\tau$.
     - Otherwise, apply Poisson noise to $\exp(-\tau)$ and return $1 - \text{noisy\_transmission}$ [S1, unofficial].
   - If `use_beer_lambert` is False:
     - Compute density contribution:
       $$ d = \text{density\_factor} \times \text{dens\_tile} / \text{ray\_samples} $$
       [S1, unofficial]
     - Compute transmission:
       $$ \text{transmission} = \text{cumprod}(1.0 - d, \text{dim}=2) $$
       [S1, unofficial]
     - Compute weight:
       $$ \text{weight} = d \times \text{transmission} $$
       [S1, unofficial]
     - Compute alpha:
       $$ \alpha = 1 - \prod (1.0 - d, \text{dim}=2) $$
       [S1, unofficial]
     - Return:
       $$ \text{result} = \left( \frac{\sum \text{weight}, \text{dim}=2}{\sum \text{weight}, \text{dim}=2 + 10^{-6}} \right) \times \alpha $$
       [S1, unofficial]

8. **Tiling:**
   If image size is smaller than $2 \times \text{tile\_h} \times 2 \times \text{tile\_w}$, call `render_tile` with the full grid [S1, unofficial].
   Otherwise, iterate over $H$ and $W$ in steps of `tile_h` and `tile_w`. For each tile, extract corresponding grid coordinates, call `render_tile`, and concatenate outputs along $W$ and $H$ axes [S1, unofficial].

    near: float,

    tile_w: int = 256,
    use_beer_lambert: bool = True,
    density_factor: float = 1.0,
    apply_poisson: bool = False,
    margin: float = 30.0
) -> torch.Tensor:
    """
    Renders a volume using tiled ray marching with grid sampling.
    """
    # 1. Initialize Camera Directions
    # Assume dirs_cam is precomputed or computed from fov
    # dirs_cam shape: (H, W, 3)
    H, W, _ = dirs_cam.shape
    
    # 2. Extract Camera Parameters
    # Handle batched or single camera matrix
    if camera_matrix.ndim == 3:
        is_batched = True
        batch_size = camera_matrix.shape[0]
    else:
        is_batched = False
        batch_size = 1
        camera_matrix = camera_matrix.unsqueeze(0)
        
    # Determine if inversion is needed
    test_pos = camera_matrix[:, :3, 3]
    translation_norm = torch.norm(test_pos, dim=1)
    needs_invert = translation_norm < 1.0
    
    cam_to_world_all = torch.inverse(camera_matrix)
    pos_if_inv = cam_to_world_all[:, :3, 3]
    dir_if_inv = cam_to_world_all[:, :3, 2]
    pos_if_noninv = camera_matrix[:, :3, 3]
    dir_if_noninv = camera_matrix[:, :3, 2]
    
    mask = needs_invert.view(-1, 1)
    cam_pos_ras = torch.where(mask, pos_if_inv, pos_if_noninv)
    view_dir = torch.where(mask, dir_if_inv, dir_if_noninv)
    
    # Normalize view directions
    view_dir = view_dir / torch.norm(view_dir, dim=1, keepdim=True)
    
    # Transform camera-space view directions to world space
    # dirs_cam shape: (H, W, 3)
    # cam2world shape: (B, 3, 3)
    # dirs_world shape: (B, H, W, 3)
    dirs_world = torch.einsum('bij,hwj->bihw', cam_to_world_all[:, :3, :3], dirs_cam)
    
    # 3. Transform to IJK Space
    # ras2ijk shape: (4, 4)
    R = ras2ijk[:3, :3]
    t = ras2ijk[:3, 3]
    
    vol_shape = density.shape[-3:] # (D, H, W)
    scale = 2.0 / (torch.tensor(vol_shape, dtype=density.dtype) - 1)
    
    # Transform world-space directions to IJK space
    # dirs_world shape: (B, H, W, 3)
    # dirs_ijk shape: (B, H, W, 3)
    dirs_ijk = dirs_world @ R.T
    
    # Transform camera position to IJK space
    # cam_pos_ras shape: (B, 3)
    # origin_ijk shape: (B, 3)
    origin_ijk = cam_pos_ras @ R.T + t
    
    # 4. Generate Sample Depths
    # depths shape: (ray_samples,)
    depths = near + (far - near) * torch.linspace(0, 1, ray_samples)
    
    # 5. Compute IJK Coordinates
    # origin_ijk shape: (B, 3) -> (B, 1, 1, 3)
    # dirs_ijk shape: (B, H, W, 3)
    # depths shape: (ray_samples,) -> (ray_samples, 1, 1, 1)
    # ijk shape: (B, ray_samples, H, W, 3)
    ijk = scale * (origin_ijk.unsqueeze(1).unsqueeze(2) + dirs_ijk.unsqueeze(0) * depths[:, None, None, None]) - 1
    
    # 6. Prepare Density Tensor
    # density shape: (C, W, H, D) -> (1, C, W, H, D)
    density_b = density.unsqueeze(0)
    
    # 7. Render Tile Function
    def render_tile(coords_tile: torch.Tensor) -> torch.Tensor:
        # coords_tile shape: (1, D, H_tile, W_tile, 3)
        # density_b shape: (1, C, W, H, D)
        # dens_tile shape: (1, C, H_tile, W_tile)
        dens_tile = F.grid_sample(density_b, coords_tile, align_corners=False)
        
        step_size = 0.1 * (far - near) / ray_samples
        
        if use_beer_lambert:
            # dens_tile shape: (1, C, H_tile, W_tile)
            # sum over ray_samples (dim=2 in original ijk, but here dens_tile is sampled)
            # Note: In the source, dens_tile is already sampled, so we sum over the sample dimension
            # However, grid_sample returns (1, C, H, W). The sample dimension is collapsed.
            # The source code implies dens_tile has a sample dimension or is summed differently.
            # Re-reading source: "dens_tile = F.grid_sample(...)" then "tau = sum(dens_tile * step_size, dim=2)"
            # This implies dens_tile might be (1, C, ray_samples, H, W) or similar.
            # But grid_sample with coords (1, D, H, W, 3) returns (1, C, H, W).
            # The source code snippet: "dens_tile = F.grid_sample(density_b, coords_tile, align_corners=False)"
            # Then "tau = sum(dens_tile * step_size, dim=2)"
            # This suggests coords_tile might be (1, ray_samples, H, W, 3) or density_b is expanded.

            # If coords_tile is (1, ray_samples, H, W, 3), grid_sample returns (1, C, ray_samples, H, W)
            # if mode='bilinear' and align_corners=False? No, grid_sample expects (N, H, W, 2) or (N, D, H, W, 3).
            # The source says "ijk = ... shape (D, H, W, 3)" which is likely a typo for (ray_samples, H, W, 3).
            # Let's assume coords_tile is (1, ray_samples, H, W, 3).
            # Then dens_tile is (1, C, ray_samples, H, W).
            # tau = sum(dens_tile * step_size, dim=2) -> (1, C, H, W)
            tau = torch.sum(dens_tile * step_size, dim=2)
            
            if apply_poisson:
                # Apply Poisson noise to tau
                # Not given in the sources exactly how Poisson noise is applied.
                # [G] Assuming standard Poisson noise: tau_noisy = torch.poisson(tau)
                tau_noisy = torch.poisson(tau)
                return tau_noisy
            else:
                # Apply Poisson noise to exp(-tau)
                # [G] Assuming standard Poisson noise
                transmission = torch.exp(-tau)
                transmission_noisy = torch.poisson(transmission)
                return 1.0 - transmission_noisy
        else:
            # Non-Beer-Lambert
            # dens_tile shape: (1, C, ray_samples, H, W)
            d = density_factor * dens_tile / ray_samples
            # transmission shape: (1, C, ray_samples, H, W)
            transmission = torch.cumprod(1.0 - d, dim=2)
            # weight shape: (1, C, ray_samples, H, W)
            weight = d * transmission
            # alpha shape: (1, C, H, W)
            alpha = 1.0 - torch.prod(1.0 - d, dim=2)
            # result shape: (1, C, H, W)
            w_sum = torch.sum(weight, dim=2)
            result = (w_sum / (w_sum + 1e-6)) * alpha
            return result

    # 8. Tiling

        # coords_full shape: (1, ray_samples, H, W, 3)
        coords_full = ijk[0].unsqueeze(0) # Assuming batch size 1 for simplicity
        return render_tile(coords_full)

        for y in range(0, H, tile_h):
            for x in range(0, W, tile_w):
                y_end = min(y + tile_h, H)
                x_end = min(x + tile_w, W)
                # Extract tile coordinates
                # ijk shape: (ray_samples, H, W, 3)
                # coords_tile shape: (1, ray_samples, y_end-y, x_end-x, 3)
                coords_tile = ijk[:, y:y_end, x:x_end, :].unsqueeze(0)
                out = render_tile(coords_tile)
                outputs.append(out)

**Parameters:**
- `tile_h`, `tile_w`: Tile dimensions used to bound peak memory. Default 256x256. Ignored if image is smaller than $2 \times \text{tile\_h} \times 2 \times \text{tile\_w}$ [S1, unofficial].
- `use_checkpointing`: Boolean flag. If True and training, use `torch.utils.checkpoint.checkpoint` to save memory during backprop [S1, unofficial].
- `use_beer_lambert`: Boolean flag. If True, use Beer-Lambert law (exponential attenuation). If False, use a different accumulation model (cumulative product of $(1-d)$) [S1, unofficial].
- `scatter`: Optional scatter function. If present, scatter channels are processed separately and concatenated with non-scatter channels [S1, unofficial].
- `density_factor`: Scaling factor applied to density in the non-Beer-Lambert mode [S1, unofficial].

**Edge Cases and Pitfalls:**
- Precision: The use of `grid_sample` with `align_corners=False` may introduce interpolation artifacts [S1, unofficial].
- Boundaries: The near and far clipping distances are computed by projecting volume corners along the view direction, with a margin of 30.0 mm [S1, unofficial].
- Degenerate Input: If the camera matrix translation norm is less than 1.0, it is inverted to ensure correct camera-to-world transformation [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Bounded by tile size. Peak memory is proportional to $H_{tile} \times W_{tile} \times \text{ray\_samples}$ [S1, unofficial].
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales with image resolution by tiling [S1, unofficial].
- **Strengths:** Memory efficient for large images [S1, unofficial].
- **Limitations:** Tiling introduces overhead and complexity [S1, unofficial].
- **When to use:** When rendering large volumes with limited memory [S1, unofficial].
- **When not to use:** When memory is not a constraint and simpler rendering is preferred [S1, unofficial].
