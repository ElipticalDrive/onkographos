# Voxel Ray Marching with Sector-Based Indexing

Also called: NoiseSDFCompute Voxel Marching, VoxelScene Ray Marching

## Overview
A ray marching algorithm for rendering voxel scenes that utilizes a sector-based storage layout to index voxels and a bounding box intersection test to step through the volume [S1, unofficial]. It builds on [Voxel Raymarching with Screen Filters](2555-voxel-raymarching-with-screen-filters.md) by organizing voxel data into fixed-size sectors for spatial indexing [S1, unofficial].

## How it works
**Inputs and Outputs**
Input: ray origin ($O$), ray direction ($D$), voxel data array (`voxelData`), world dimensions ($W_X, W_Y, W_Z$), sector dimensions ($S_X, S_Y, S_Z$), world offset ($O_{world}$), maximum steps ($maxSteps$), maximum distance ($maxDist$), minimum step size ($minDist$) [S1, unofficial]. Output: hit distance or miss indicator [S1, unofficial].

**Data Structures**
Voxel data is stored in a flat array of 32-bit unsigned integers (`u32`) [S1, unofficial]. Each `u32` word stores the solidity status of 32 voxels as individual bits [S1, unofficial]. The layout is organized into sectors to facilitate spatial indexing [S1, unofficial].

**Indexing Logic**
To determine if a voxel at world position $P$ is solid:
1. Convert world position to voxel coordinates: $v_x = \lfloor P_x - O_{world\_x} \rfloor$, $v_y = \lfloor P_y - O_{world\_y} \rfloor$, $v_z = \lfloor P_z - O_{world\_z} \rfloor$ [S1, unofficial].
2. Check bounds: if $0 \le v_x < W_X$, $0 \le v_y < W_Y$, $0 \le v_z < W_Z$, proceed [S1, unofficial].
3. Calculate sector index: $idx_{sector} = \lfloor v_z / S_Z \rfloor + N_{sectors\_Z} \times \lfloor v_x / S_X \rfloor$ [S1, unofficial].
4. Calculate local index within the sector: $idx_{local} = (v_z \pmod{S_Z}) + S_Z \times ((v_x \pmod{S_X}) + S_X \times v_y)$ [S1, unofficial].
5. Calculate global index in the flat array: $idx_{global} = idx_{sector} \times (S_X \times S_Y \times S_Z) + idx_{local}$ [S1, unofficial].
6. Check bit value: $\text{solid} = (\text{voxelData}[\lfloor idx_{global} / 32 \rfloor] \gg (idx_{global} \pmod{32})) \& 1$ [S1, unofficial].

**Algorithm Steps**
1. Initialize $totalDist = 0.0$ [S1, unofficial].
2. Loop $i$ from $0$ to $maxSteps$:
   a. Calculate $pos = O + D \times totalDist$ [S1, unofficial].
   b. Calculate distance to nearest solid voxel (or SDF) from $pos$ [S1, unofficial].
   c. If distance $< minDist$, return hit [S1, unofficial].
   d. If $totalDist > maxDist$, return miss [S1, unofficial].
   e. $totalDist += distance$ [S1, unofficial].

**Ray-Box Intersection**
Calculate inverse direction: $D_{inv} = 1.0 / D$ [S1, unofficial]. Calculate near and far intersections: $near = (B_{min} - O) \times D_{inv}$, $far = (B_{max} - O) \times D_{inv}$ [S1, unofficial]. Calculate $t_0 = \max(\max(near_x, near_y), near_z)$ and $t_1 = \min(\min(far_x, far_y), far_z)$ [S1, unofficial]. If $\max(t_0, 0.0) > t_1$, return $\infty$ (miss), else return $t_0$ [S1, unofficial].

**Pseudocode**
```python
def voxel_ray_march(origin, direction, voxel_data, world_size, sector_size, world_offset, max_steps, max_dist, min_dist):
    wx, wy, wz = world_size
    sx, sy, sz = sector_size
    ox, oy, oz = world_offset
    sectors_x = wx // sx
    sectors_z = wz // sz

    inv_dir_x = 1.0 / direction[0]
    inv_dir_y = 1.0 / direction[1]
    inv_dir_z = 1.0 / direction[2]

    near_x = (ox - origin[0]) * inv_dir_x
    near_y = (oy - origin[1]) * inv_dir_y
    near_z = (oz - origin[2]) * inv_dir_z
    far_x = (ox + wx - origin[0]) * inv_dir_x
    far_y = (oy + wy - origin[1]) * inv_dir_y
    far_z = (oz + wz - origin[2]) * inv_dir_z

    t0 = max(max(near_x, near_y), near_z)
    t1 = min(min(far_x, far_y), far_z)

    if max(t0, 0.0) > t1:
        return None

    total_dist = 0.0
    for _ in range(max_steps):
        if total_dist > max_dist:
            return None

        pos_x = origin[0] + direction[0] * total_dist
        pos_y = origin[1] + direction[1] * total_dist
        pos_z = origin[2] + direction[2] * total_dist

        vx = int(pos_x - ox)
        vy = int(pos_y - oy)
        vz = int(pos_z - oz)

        if not (0 <= vx < wx and 0 <= vy < wy and 0 <= vz < wz):
            return None

        sector_index = (vz // sz) + sectors_z * (vx // sx)
        local_index = (vz % sz) + sz * ((vx % sx) + sx * vy)
        sector_volume = sx * sy * sz
        global_index = sector_index * sector_volume + local_index

        word_index = global_index // 32
        bit_index = global_index % 32
        is_solid = (voxel_data[word_index] >> bit_index) & 1

        if is_solid:
            return total_dist

        dist = compute_dist_to_solid(pos_x, pos_y, pos_z, direction, voxel_data, world_size, sector_size, world_offset)
        if dist < min_dist:
            return total_dist

        total_dist += dist
    return None

def compute_dist_to_solid(px, py, pz, dir, voxel_data, world_size, sector_size, world_offset):
    # [G] The source notes state "Calculate dist to nearest solid voxel (or SDF)" without specifying the exact method.
    # A standard implementation computes the distance to the next voxel boundary along the ray direction.
    step_x = (1.0 if dir[0] > 0 else 0.0) - (px - world_offset[0])
    step_y = (1.0 if dir[1] > 0 else 0.0) - (py - world_offset[1])
    step_z = (1.0 if dir[2] > 0 else 0.0) - (pz - world_offset[2])
    return min(step_x / dir[0], step_y / dir[1], step_z / dir[2])
```

**Parameters**
$WORLD\_SIZE\_X, WORLD\_SIZE\_Y, WORLD\_SIZE\_Z$: 256 [S1, unofficial]. $SECTOR\_SIZE\_X$: 16, $SECTOR\_SIZE\_Y$: 256, $SECTOR\_SIZE\_Z$: 16 [S1, unofficial]. $WORLD\_OFFSET\_X$: -128, $WORLD\_OFFSET\_Y$: 0, $WORLD\_OFFSET\_Z$: -128 [S1, unofficial]. $maxSteps$: 128 [S1, unofficial]. $maxDist$: 100.0 [S1, unofficial]. $minDist$: 0.01 [S1, unofficial].

**Edge Cases and Pitfalls**
Precision errors may accumulate over many steps; using double precision for $totalDist$ is recommended [G]. Zero direction components cause division by zero in $D_{inv}$; clamp or handle axis-aligned rays explicitly [G]. Out-of-bounds voxel coordinates must be rejected before indexing to prevent array overflows [S1, unofficial].

## Operating characteristics
Time complexity is $O(maxSteps)$ per ray, bounded by the maximum iteration count [S1, unofficial]. Memory complexity is $O(W_X \times W_Y \times W_Z / 32)$ for the voxel data array [S1, unofficial]. Sector-based indexing improves cache locality for spatially coherent rays [G]. Binary voxel data limits shading to simple hit/miss queries [G]. Distance calculation requires an SDF or neighbor search, which is not detailed in the source [S1, unofficial]. It is suitable for real-time rendering of binary voxel scenes where memory bandwidth is a constraint [G]. It is not suitable for scenes requiring complex shading, transparency, or non-binary voxel data [G].

## Background
The method is documented in an open-source repository [S1, unofficial]. It is part of a suite of voxel rendering techniques aimed at efficient real-time rendering of voxel worlds [S1, unofficial].
