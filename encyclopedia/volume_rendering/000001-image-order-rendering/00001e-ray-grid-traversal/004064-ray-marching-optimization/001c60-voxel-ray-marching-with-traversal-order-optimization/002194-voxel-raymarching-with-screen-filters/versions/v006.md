# Voxel Raymarching with Screen Filters

Also called: Voxel Transparency Shader

## Overview
Voxel Raymarching with Screen Filters is a fragment shader technique for rendering voxelized data that combines ray traversal through a 3D texture with screen-space visual effects [S1, unofficial]. It differs from its parent [Voxel Ray Marching with Traversal Order Optimization](1251-voxel-ray-marching-with-traversal-order-optimization.md) by applying screen-space filters (normal, position, depth, iterations, flat color, and toon) to the final color output rather than relying solely on traversal optimization [S1, unofficial]. It is distinct from the [Voxel Visualization Ray Marcher](3432-voxel-visualization-ray-marcher.md) by using these screen filters and a complex lighting model with specular and diffuse directions, rather than a fixed-step traversal with explicit alpha compositing [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Ray origin, ray direction, scene data (including `worldWidth`, `time`, `screenFilter` flag, `tonemap` flag), camera data (`prevPosition`, `prevRotation`), previous depth texture, color texture, position texture [S1, unofficial].
*   **Outputs:** Final color written to `colorTexture`, velocity written to `velocityTexture`, depth written to `currentDepthTexture` [S1, unofficial].

**Data Structures:**
*   `RayHit`: Contains `status` (int), `position` (vec3<f32>), `normal` (vec3<f32>), `voxelData` (u32), `uv` (vec2<f32>), `worldUV` (vec2<f32>), `iterations` (u32) [S1, unofficial].
*   `VoxelData` (u32): Packed 32-bit integer. Bits 7–4 store `albedoIndex` (4 bits). Bits 3–0 store `materialIndex` (4 bits) [S1, unofficial].
*   `Material`: Contains `emissive` (bool), `specular` (float) [S1, unofficial].
*   `SceneData`: Contains `worldWidth` (int), `time` (float), `screenFilter` (int), `tonemap` (int) [S1, unofficial].
*   `CameraData`: Contains `position` (vec3<f32>), `prevPosition` (vec3<f32>), `prevRotation` (mat4x4<f32>) [S1, unofficial].

**Pseudocode:**

```python
def voxel_raymarching_with_screen_filters(pixel_pos, ray_origin, ray_dir, scene_data, camera_data, previous_depth_texture):
    max_steps = 50
    ray_pos = (int(ray_origin[0]), int(ray_origin[1]), int(ray_origin[2]))
    ray_step = tuple(1.0 if d >= 0 else -1.0 for d in ray_dir)
    
    # Precompute traversal deltas [S1, unofficial]
    max_translation = tuple(((0.5 + ray_pos[i]) + 0.5 * ray_step[i] - ray_origin[i]) / ray_dir[i] for i in range(3))
    delta_translation = tuple(ray_step[i] / ray_dir[i] for i in range(3))
    
    steps = 0
    hit_world = False
    result_hit = None
    
    while steps < max_steps:
        if any(p >= scene_data['worldWidth'] or p < 0 for p in ray_pos):
            break
            
        # [G] GetVoxel returns 32-bit packed data at ray_pos
        voxel_data = get_voxel(ray_pos)
        
        if voxel_data != 0:
            intersection_depth = ray_box_intersect(ray_origin, ray_dir, ray_pos, (ray_pos[0]+1, ray_pos[1]+1, ray_pos[2]+1))
            if intersection_depth is None: intersection_depth = 0.0
            intersection_position = tuple(ray_origin[i] + ray_dir[i]*intersection_depth for i in range(3))
            
            direction = tuple(intersection_position[i] - (ray_pos[i] + 0.5) for i in range(3))
            abs_dir = tuple(abs(d) for d in direction)
            
            if abs_dir[1] > abs_dir[0] and abs_dir[1] > abs_dir[2]:
                intersection_normal = (0.0, 1.0 if direction[1] > 0 else -1.0, 0.0)
            else:
                intersection_normal = (0.0, 0.0, 1.0 if direction[2] > 0 else -1.0)
                
            result_hit = {'status': 2, 'position': intersection_position, 'normal': intersection_normal, 
                          'voxelData': voxel_data, 'iterations': steps}
            hit_world = True
            break
            
        ray_advance_mask = tuple(max_translation[i] <= min(max_translation[(i+1)%3], max_translation[(i+2)%3]) for i in range(3))
        max_translation = tuple(max_translation[i] + ray_advance_mask[i]*delta_translation[i] for i in range(3))
        ray_pos = tuple(ray_pos[i] + int(ray_advance_mask[i])*ray_step[i] for i in range(3))
        steps += 1
        
    if not hit_world:
        result_hit = {'status': 3, 'position': tuple(ray_origin[i] + ray_dir[i]*1000.0 for i in range(3)), 
                      'normal': (0.0, 0.0, 0.0), 'voxelData': 0, 'iterations': steps}

    color = (0.0, 0.0, 0.0)
    throughput = (1.0, 1.0, 1.0)
    
    if hit_world:
        albedo_index = (result_hit['voxelData'] >> 4) & 0xF
        material_index = result_hit['voxelData'] & 0xF
        albedo = COLORS[albedo_index]
        material = MATERIALS[material_index]
        
        # Guard against division by zero [S1, unofficial]
        y_denom = pixel_pos[1] if pixel_pos[1] != 0 else 1.0
        seed = tuple((result_hit['position'][i] + scene_data['time'] * [17.0, 29.0, 41.0][i]) * pixel_pos[0] / y_denom for i in range(3))
        
        specular_dir = reflect(ray_dir, result_hit['normal'])
        diffuse_dir = normalize(tuple(result_hit['normal'][i] + random_direction(seed)[i] for i in range(3)))
        
        if material['emissive']:
            color = tuple(color[i] + throughput[i]*albedo[i] for i in range(3))
            
        if material['specular'] > 0.0:
            throughput = tuple(t * (1.0 - material['specular'] * 0.1) for t in throughput)
            
        sun_contribution = sunlight(result_hit['position'], result_hit['normal'])
        color = tuple(color[i] + throughput[i]*(albedo[i]*sun_contribution)*(1.0 - material['specular']) for i in range(3))
        throughput = tuple(t * a for t, a in zip(throughput, albedo))
        
        # [G] Update ray for next march: ray_pos = intersection_position - 0.001*ray_dir; ray_dir = mix(diffuse_dir, specular_dir, material.specular)
    else:
        color = tuple(color[i] + throughput[i]*skybox(ray_dir)[i] for i in range(3))

    if hit_world and scene_data['screenFilter'] != 0:
        f = scene_data['screenFilter']
        if f == 1:
            color = tuple(n/2.0 + 0.5 for n in result_hit['normal'])
        elif f == 2:
            color = tuple(p/scene_data['worldWidth'] for p in result_hit['position'])
        elif f == 3:
            color = tuple(1.0 - steps/50.0 for _ in range(3))
        elif f == 4:
            norm = tuple(n/2.0 + 0.5 for n in result_hit['normal'])
            brightness = sum(norm[i]*[0.2, 0.4, 0.6][i] for i in range(3))
            color = tuple(a*brightness for a in albedo)
        elif f == 5:
            depth_val = distance(camera_data['position'], result_hit['position'])
            color = tuple(1.0 - depth_val/scene_data['worldWidth']*2.0 for _ in range(3))
        elif f == 6:
            d0 = sample_depth(previous_depth_texture, pixel_pos)
            d1 = sample_depth(previous_depth_texture, (pixel_pos[0]+1, pixel_pos[1]))
            d2 = sample_depth(previous_depth_texture, (pixel_pos[0], pixel_pos[1]+1))
            d3 = sample_depth(previous_depth_texture, (pixel_pos[0]+1, pixel_pos[1]+1))
            mean = (d0 + d1 + d2 + d3) / 4.0
            variance = sum((d - mean)**2 for d in [d0, d1, d2, d3]) / 4.0
            color = tuple((1.0 - variance)*a for a in albedo)
    else:
        # [G] Write pixelWorldPosition to positionTexture
        if scene_data['tonemap'] == 0:
            color = tonemap_aces(color)
        elif scene_data['tonemap'] == 1:
            color = tonemap_reinhard(color)
            
    color = gamma_correct(color)
    
    if not hit_world:
        write_velocity(velocity_texture, pixel_pos, (1e9, 1e9, 0.0, 0.0))
    else:
        prev_pixel_pos = world_to_clip_space(result_hit['position'], camera_data['prevPosition'], camera_data['prevRotation'])
        pixel_velocity = (pixel_pos[0] - prev_pixel_pos[0], pixel_pos[1] - prev_pixel_pos[1])
        write_velocity(velocity_texture, pixel_pos, (pixel_velocity[0], pixel_velocity[1], 0.0, 0.0))
        
    if not hit_world:
        write_depth(current_depth_texture, pixel_pos, (1e9, 1e9, 0.0, 0.0))
    else:
        depth_val = distance(camera_data['position'], result_hit['position'])
        write_depth(current_depth_texture, pixel_pos, (depth_val, 0.0, 0.0, 0.0))
        
    return color

def ray_box_intersect(ray_origin, ray_dir, box_min, box_max):
    """Standard slab method for ray-AABB intersection, handling zero direction components correctly [G]."""
    t_min = 0.0
    t_max = float('inf')
    for i in range(3):
        if ray_dir[i] == 0.0:
            if ray_origin[i] < box_min[i] or ray_origin[i] > box_max[i]:
                return None
        else:
            t1 = (box_min[i] - ray_origin[i]) / ray_dir[i]
            t2 = (box_max[i] - ray_origin[i]) / ray_dir[i]
            if t1 > t2: t1, t2 = t2, t1
            t_min = max(t_min, t1)
            t_max = min(t_max, t2)
        if t_min > t_max:
            return None
    return t_min if t_max > 0.0 else None

# [G] Standard math helpers: reflect(v, n), normalize(v), random_direction(seed), sunlight(pos, n), skybox(d), tonemap_aces(c), tonemap_reinhard(c), gamma_correct(c), world_to_clip_space(pos, prev_pos, prev_rot), sample_depth(tex, uv), write_velocity(tex, uv, val), write_depth(tex, uv, val), distance(a, b)
# [G] Global lookups: COLORS, MATERIALS, velocity_texture, current_depth_texture
```

**Parameters:**
*   `max_steps`: 50 (inferred from Filter 3 normalization divisor) [S1, unofficial].
*   `worldWidth`: Size of the voxel world in units [S1, unofficial].
*   `screenFilter`: Integer 0-6. 0 disables filters [S1, unofficial].
*   `tonemap`: Integer 0 (ACES) or 1 (Reinhard) [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Division by Zero:** The random seed calculation divides by `pixelPos.y`. If `pixelPos.y` is 0, this results in infinity or NaN. A guard is required [S1, unofficial].
*   **Transparency Limitations:** Transparency falls back to grayscale when used outside the same voxel volume due to alpha channel limitations [S2, unofficial].
*   **Unimplemented Features:** Transparency is not tested in the current project; a test project is planned for later [S2, unofficial].
*   **Typo in Source:** The source refers to `previousDeptTexture` (typo for Depth) [S1, unofficial].

## Subtopics

### [Voxel Visualization Ray Marcher](3432-voxel-visualization-ray-marcher.md)
A fragment shader technique that ray marches through a 3D texture to visualize voxelized data by accumulating color along a ray until opacity saturates or the ray exits the volume. It differs from its parent [Voxel Raymarching with Screen Filters](2555-voxel-raymarching-with-screen-filters.md) by using a fixed-step traversal loop with explicit alpha compositing in the fragment shader, rather than relying on pre-filtered screen-space accumulation or hierarchical traversal structures.

### [Voxel Ray Marching with Sector-Based Indexing](6915-voxel-ray-marching-with-sector-based-indexing.md)
A ray marching algorithm for rendering voxel scenes that utilizes a sector-based storage layout to index voxels and a bounding box intersection test to step through the volume. It differs from its parent [Voxel Raymarching with Screen Filters](2555-voxel-raymarching-with-screen-filters.md) by explicitly organizing voxel data into fixed-size sectors to optimize memory access patterns during traversal, rather than relying solely on screen-space filtering heuristics. It is distinct from the [Voxel Visualization Ray Marcher](3432-voxel-visualization-ray-marcher.md) by its specific use of sector-based indexing for global voxel lookup.

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of steps taken until a hit or exit [G]. The screen filters add constant time overhead per pixel [G].
*   **Memory Complexity:** Low, primarily storing the voxel texture and screen buffers (depth, velocity, color) [G].
*   **Performance:** Performance depends heavily on the density of the voxel world and the `max_steps` limit. The use of screen filters requires additional texture samples (e.g., for the Toon filter), increasing memory bandwidth usage [S1, unofficial].
*   **Strengths:** Provides flexible visual debugging and stylized rendering via screen filters. Integrates lighting calculations directly into the raymarching loop [S1, unofficial].
*   **Limitations:** Transparency support is incomplete/untested [S2, unofficial]. The Toon filter requires sampling neighboring depth values, which can be costly [S1, unofficial]. The random seed calculation is sensitive to pixel coordinates [S1, unofficial].

## Background
This method originates from a WebGPU voxel raymarching implementation [S1, unofficial]. It is also associated with a Godot voxel project [S2, unofficial]. The technique combines standard raymarching traversal with screen-space post-processing effects [S1, unofficial].
