# Loosely Nested Grids

Also called: Bottom-up hierarchical grid construction, Cazals et al. hierarchical grid

## Overview
Loosely Nested Grids (LNG) is a hierarchical grid construction method for volume rendering and ray tracing that organizes scene primitives into a recursive grid structure using a bottom-up approach [S1]. Unlike top-down adaptive subdivision methods, LNG builds the hierarchy by clustering primitives and constructing local grids for those clusters, allowing for efficient traversal of complex scenes with varying density [S1].

## How it works
The method constructs a data structure viewed as a loosely nested recursive grid [S1]. The construction process is defined by a specific sequence of filtering and clustering steps [S1].

**Inputs:** A set of scene primitives.
**Outputs:** A hierarchical grid structure where each node represents a grid covering a cluster of primitives.

**Data Structures:**
The structure is a tree of grids. Each node in the hierarchy contains a grid (typically a 3D array or hash table) that stores references to primitives or child nodes. The exact bit-packing or field layout of the grid cells is not specified in the sources, but the logical structure is a recursive grid [S1].

**Algorithm Steps:**
The construction follows four main steps [S1]:

1.  **Organize Primitives:** Group the primitives of the scene into subsets of similar size [S1].
2.  **Cluster Neighbors:** For each group of primitives, group the neighboring primitives into clusters [S1].
3.  **Construct Local Grids:** Construct a grid for each identified cluster [S1].
4.  **Build Hierarchy:** Construct a hierarchy of these grids, linking the local grids into a recursive structure [S1].

## Subtopics

### Adaptive grid data structure (Klimaszewski and Sederberg)
An adaptive grid data structure proposed by Klimaszewski and Sederberg [KS97] that builds local grids acting as bounding boxes in densely populated areas [S1]. The resulting data structure is also seen as a loosely nested recursive grid [S1]. The fast bottom-up building algorithm consists of four steps: 1) for each primitive, surround it with a bounding box (for unstructured grids); 2) for all bounding boxes, merge close boxes (creating a structured grid); 3) for all remaining boxes, insert the box into a tree using a minimum surface criterion; 4) for all bounding boxes in the hierarchy, build a local grid [S1]. Like the Cazals et al. method, this work has a greater build cost against general bottom-up strategies [S1].

## Background
The Loosely Nested Grids method was proposed by Cazals et al. in 1995 [CDP95] [S1]. It was introduced as a hierarchical grid building method capable of handling very complex scenes [S1]. The approach contrasts with other methods that subdivide their structure adaptively in a top-down manner by using a bottom-up construction via filtering and clustering [S1]. A related adaptive grid data structure was proposed by Klimaszewski and Sederberg in 1997 [KS97] [S1].
