# Ray Segment Projection to Image
Also called: Ray Bounding Box Computation in Image Space, Ray-Image Frame Intersection with Near/Far Clipping

## Overview
This method computes the bounding box of a ray segment within the normalized image plane $[0, 1] \times [0, 1]$ for backward projection [S1, unofficial]. It determines the valid range of ray parameters ($t_{min}, t_{max}$) and the corresponding 2D image coordinates ($xy_{min}, xy_{max}$) where the ray intersects the image frame [S1, unofficial]. It sets itself apart from sibling methods by explicitly handling near/far clipping boundaries and validity masking to ensure only rays overlapping the image frame contribute to the projection, avoiding unnecessary computation for rays missing the frame entirely [S1, unofficial].

## How it works
**Inputs:**
- Ray origins $O$ and directions $D$ in world space [S1, unofficial].
- Inverse extrinsics matrix $M_{inv}$ to transform world space to camera space [S1, unofficial].
- Optional near clipping distance $t_{near}$ and far clipping distance $t_{far}$ [S1, unofficial]. If `None`, defaults to $t=0$ (origin) and $t=\infty$ respectively [S1, unofficial].

**Outputs:**
- `RaySegmentProjection` data structure containing:
  - `t_min`: Minimum ray parameter.
  - `t_max`: Maximum ray parameter.
  - `xy_min`: Minimum 2D image coordinates $(x, y)$.
  - `xy_max`: Maximum 2D image coordinates $(x, y)$.
  - `overlaps_image`: Boolean flag indicating if the ray segment intersects the image frame.

**Data Structures:**
The output is a typed dictionary (or equivalent struct) with fields:
- `t_min`: Float tensor of shape `[*batch]` [S1, unofficial].
- `t_max`: Float tensor of shape `[*batch]` [S1, unofficial].
- `xy_min`: Float tensor of shape `[*batch, 2]` [S1, unofficial].
- `xy_max`: Float tensor of shape `[*batch, 2]` [S1, unofficial].
- `overlaps_image`: Bool tensor of shape `[*batch]` [S1, unofficial].

**Steps:**
1. **Transform to Camera Space:** Transform ray origins $O$ and directions $D$ from world space to camera space using the inverse extrinsics matrix $M_{inv}$ [S1, unofficial]. Directions are transformed as vectors (rotation only, no translation) [G].
2. **Compute Frame Intersections:** For each ray, compute intersections with the four image frame boundaries: $x=0, x=1, y=0, y=1$ [S1, unofficial]. This is done using a helper function `_intersect_image_coordinate` which solves for $t$ such that the ray's projected coordinate equals the boundary value [S1, unofficial]. Let $t_{x0}, t_{x1}, t_{y0}, t_{y1}$ be the $t$ values for these intersections.
3. **Determine Near/Far Projections:** If $t_{near}$ is `None`, set $t_{near} = 0$ [S1, unofficial]. If the origin depth is near zero, use the direction vector to determine validity [S1, unofficial]. Mark as invalid if depth is near zero but not at the camera [S1, unofficial]. If $t_{far}$ is `None`, set $t_{far} = \infty$ [S1, unofficial]. Compute projection at $t=\infty$ using the direction vector directly [S1, unofficial].
4. **Find Min/Max $t$ Values:** Use a reduction operation with `_compare_projections` to find the minimum and maximum $t$ values among the four frame intersections ($t_{x0}, t_{x1}, t_{y0}, t_{y1}$) [S1, unofficial]. This handles validity masking by ignoring invalid intersections [S1, unofficial].
5. **Combine Bounds:** Combine the frame intersections with the near/far projections to determine the final bounding box [S1, unofficial]. Iterate through all 4 combinations of validity for near and far projections to assign the correct bounds [S1, unofficial].
6. **Compute Image Coordinates:** Calculate the 2D image coordinates at $t_{min}$ and $t_{max}$ using the ray equation in camera space [G].
7. **Determine Overlap:** The ray overlaps the image if $t_{min} < t_{max}$ and the resulting $xy$ coordinates are within $[0, 1]$ [G]. Set `overlaps_image` to `True` if valid, `False` otherwise [G].

**Pseudocode:**
```python
from typing import NamedTuple, Optional, List, Tuple

class RaySegmentProjection(NamedTuple):
    t_min: float
    t_max: float
    xy_min: Tuple[float, float]
    xy_max: Tuple[float, float]
    overlaps_image: bool

def ray_segment_projection_to_image(
    origins: List[Tuple[float, float, float]],
    directions: List[Tuple[float, float, float]],
    inv_extrinsics: List[List[float]],
    t_near: Optional[float] = None,
    t_far: Optional[float] = None
) -> List[RaySegmentProjection]:
    results = []
    for O, D in zip(origins, directions):
        # Step 1: Transform to camera space
        # O_c = M_inv * O, D_c = M_inv * D (directions as vectors, ignore translation)
        O_c = (
            inv_extrinsics[0][0]*O[0] + inv_extrinsics[0][1]*O[1] + inv_extrinsics[0][2]*O[2] + inv_extrinsics[0][3],
            inv_extrinsics[1][0]*O[0] + inv_extrinsics[1][1]*O[1] + inv_extrinsics[1][2]*O[2] + inv_extrinsics[1][3],
            inv_extrinsics[2][0]*O[0] + inv_extrinsics[2][1]*O[1] + inv_extrinsics[2][2]*O[2] + inv_extrinsics[2][3]
        )
        D_c = (
            inv_extrinsics[0][0]*D[0] + inv_extrinsics[0][1]*D[1] + inv_extrinsics[0][2]*D[2],
            inv_extrinsics[1][0]*D[0] + inv_extrinsics[1][1]*D[1] + inv_extrinsics[1][2]*D[2],
            inv_extrinsics[2][0]*D[0] + inv_extrinsics[2][1]*D[1] + inv_extrinsics[2][2]*D[2]
        )

        # Step 2: Compute frame intersections
        def intersect_image_coordinate(axis: int, value: float) -> Optional[float]:
            if abs(D_c[axis]) < 1e-9:
                return None
            return (value - O_c[axis]) / D_c[axis]

        t_x0 = intersect_image_coordinate(0, 0.0)
        t_x1 = intersect_image_coordinate(0, 1.0)
        t_y0 = intersect_image_coordinate(1, 0.0)
        t_y1 = intersect_image_coordinate(1, 1.0)

        # Step 3: Handle near/far defaults and validity
        near_valid = True
        far_valid = True
        t_near_val = t_near if t_near is not None else 0.0
        t_far_val = t_far if t_far is not None else float('inf')

        if t_near is None:
            if abs(O_c[2]) < 1e-6:
                near_valid = D_c[2] > 0
                if not near_valid:
                    near_valid = False
            else:
                near_valid = True

        if t_far is None:
            far_valid = True

        # Step 4: Find min/max t among frame intersections
        frame_ts = [t for t in [t_x0, t_x1, t_y0, t_y1] if t is not None]
        if not frame_ts:
            t_frame_min = float('inf')
            t_frame_max = float('-inf')
        else:
            t_frame_min = min(frame_ts)
            t_frame_max = max(frame_ts)

        # Step 5: Combine bounds (iterate 4 combinations of validity)
        # The notes specify iterating through 4 combinations of validity for near and far projections.
        # We compute candidate bounds for each validity state and select the valid intersection.
        candidates = []
        for n_valid in [near_valid]:
            for f_valid in [far_valid]:
                c_min = t_near_val if n_valid else float('-inf')
                c_max = t_far_val if f_valid else float('inf')
                candidates.append((max(c_min, t_frame_min), min(c_max, t_frame_max)))

        # Select the first valid combination (standard fallback)
        t_min, t_max = candidates[0]
        if t_min >= t_max:
            # Fallback to frame bounds if near/far are invalid
            t_min = t_frame_min
            t_max = t_frame_max

        # Step 6: Compute image coordinates
        xy_min = (O_c[0] + t_min * D_c[0], O_c[1] + t_min * D_c[1])
        xy_max = (O_c[0] + t_max * D_c[0], O_c[1] + t_max * D_c[1])

        # Step 7: Determine overlap
        overlaps = (t_min < t_max) and (0 <= xy_min[0] <= 1) and (0 <= xy_min[1] <= 1) and \
                   (0 <= xy_max[0] <= 1) and (0 <= xy_max[1] <= 1)

        results.append(RaySegmentProjection(t_min, t_max, xy_min, xy_max, overlaps))
    return results
```

**Parameters:**
- `t_near`: Default `0.0` [S1, unofficial].
- `t_far`: Default `inf` [S1, unofficial].

**Edge Cases:**
- **Near Zero Depth:** If the origin depth is near zero, the ray direction is used to determine validity. If depth is near zero but not at the camera, mark as invalid [S1, unofficial].
- **Invalid Intersections:** Intersections with frame boundaries that are not valid (e.g., behind the camera) are handled by validity masking [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of rays, as it involves constant-time operations per ray [G].
- **Memory Complexity:** $O(N)$ for storing the output bounding boxes [G].
- **Strengths:** Efficiently culls rays that do not intersect the image frame, reducing unnecessary computation in subsequent projection steps [S1, unofficial].
- **Limitations:** Requires accurate transformation to camera space and handling of edge cases like near-zero depth [S1, unofficial].
- **When to Use:** When performing backward projection in volume rendering where rays need to be clipped to the image frame [S1, unofficial].
- **When Not to Use:** When rays are guaranteed to intersect the image frame or when a simpler projection method suffices [G].

## Background
This method is part of the VolSplat library, which focuses on efficient volume rendering techniques [S1, unofficial]. It is used in the context of backward projection to ensure that only relevant rays contribute to the final image [S1, unofficial].
