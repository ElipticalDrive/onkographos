# Restart Trail

Also called: Short stack traversal with restart trail

## Overview
Restart trail is a stackless or short-stack traversal algorithm for ray casting against hierarchical scene structures, specifically designed to enable restarts from the root without a full stack [S1, unofficial]. It solves the problem that kd-tree traversal can use ray shortening to avoid re-entering processed nodes, but BVHs cannot because child nodes overlap [S1, unofficial]. By storing one bit of data per hierarchy level to track visited status, it allows traversal to resume from the correct point after a short stack overflow, avoiding the need for a full stack [S1, unofficial]. It sets itself apart from skip-node pointers by allowing processing of the nearer node before the farther node, adapting to ray direction [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A ray, a BVH (or similar hierarchy) with a root node, and a short stack (optional, size $N \ge 0$).
*   **Output:** The closest primitive hit by the ray, or null if no hit occurs.

**Data Structures:**
*   **Trail Register (`trailReg`):** A single 32-bit or 64-bit integer register storing the restart trail bits.
    *   Bit 0 (LSB) is unused or reserved.
    *   Bit 1 corresponds to the root node.
    *   Bit $i$ corresponds to the node at hierarchy level $i$.
    *   The most significant bit (MSB) acts as a sentinel.
*   **Level Register (`levelReg`):** A register with exactly one bit set.
    *   Initialized to $1000\dots0_2$ (1 followed by zeros), corresponding to the sentinel bit position (bit 0).
    *   The position of the set bit indicates the current hierarchy depth relative to the trail. Specifically, if `levelReg` has bit $k$ set, it points to `trailReg` bit $k$.
*   **Pop Level (`popLevel`):** An integer tracking the level where the last stack pop would have taken the traversal. Initialized to `NONE`.
*   **Short Stack:** A small fixed-size stack storing nodes to be visited later.

**Semantics of Trail Bits:**
For any node at level $i$ (bit $i$ in `trailReg`):
*   **Bit = 0:** The node has not been visited yet, OR the node has two children to be traversed and the subtree under the near child has not been fully traversed yet.
*   **Bit = 1:** The node has one child to be traversed, OR the node has two children to be traversed and the subtree under the near child has already been fully traversed.

**Algorithm Steps:**

1.  **Initialization:**
    *   Set `node` to `ROOT`.
    *   Set `trailReg` to 0.
    *   Set `levelReg` to $1 \ll 0$ (bit 0 set, pointing to sentinel).
    *   Set `popLevel` to `NONE`.
    *   Clear the short stack.

2.  **Main Loop:**
    *   While `node` is not `NULL`:
        *   **Node Intersection:** Intersect the ray against the children of `node`.
        *   **Case 1: Both children intersected.**
            *   Identify `near` child (smaller $t_{min}$) and `far` child (greater $t_{min}$).
            *   Increment depth: `levelReg` = `levelReg` >> 1.
            *   Check trail: If `(trailReg & levelReg) != 0`:
                *   The near child is already processed (or skipped). Set `node` = `far`.
            *   Else:
                *   Set `node` = `near`.
                *   Push `far` onto the short stack.
        *   **Case 2: Exactly one child intersected.**
            *   Increment depth: `levelReg` = `levelReg` >> 1.
            *   If `levelReg` does not correspond to `popLevel`:
                *   Set the trail bit: `trailReg` = `trailReg` | `levelReg`.
                *   Set `node` to the intersected child.
            *   Else (`levelReg` corresponds to `popLevel`):
                *   This indicates the far child was culled during the processing of the near child. Invoke `POP()`.
        *   **Case 3: No children intersected.**
            *   Invoke `POP()`.
        *   **Leaf Processing:**
            *   If `node` is a leaf:
                *   Intersect the ray against primitives in the leaf.
                *   If a closer primitive is found, shorten the ray at the end ($t_{max}$).
                *   Invoke `POP()`.

3.  **POP() Subroutine:**
    *   Find the largest $i$ such that $i \le \text{current level}$ and bit $i$ in `trailReg` is 0.
    *   Update `trailReg`:
        *   Clear bits below the new level: `trailReg` = `trailReg` & (-`levelReg`).
        *   Set the new level bit and clear bits above it up to the first zero: `trailReg` = `trailReg` + `levelReg`.
        *   *Note:* The expression `trailReg += levelReg` clears all set bits at and above `levelReg` until the first zero bit, which is flipped to one. The preceding AND operation clears bits below `levelReg`.
    *   Update `levelReg` to point to the lowest set bit in `trailReg`:
        *   `temp` = `trailReg` >> 1.
        *   `levelReg` = `((temp - 1) ^ temp) + 1`.
    *   Check termination: If bit 0 (sentinel) in `trailReg` is 1, terminate traversal.
    *   Save state: Set `popLevel` to the index of the new `levelReg` bit.
    *   Resume:
        *   If short stack is exhausted:
            *   Set `node` = `ROOT`.
            *   Reset `levelReg` to sentinel position ($1 \ll 0$).
        *   Else:
            *   Pop `node` from the short stack.

**Pseudocode:**

```python
def cast_ray(ray, root, short_stack_capacity=0):
    # Initialization
    node = root
    trail_reg = 0
    # level_reg has bit 0 set (sentinel position)
    level_reg = 1 
    pop_level = None
    
    while node is not None:
        # Intersect ray against children of node
        hits = intersect_children(node, ray)
        
        if len(hits) == 2:
            # Both children intersected
            near_child, far_child = sort_by_tmin(hits)
            
            # Increment level: shift right
            level_reg = level_reg >> 1
            
            # Check if near child is already processed (bit is 1)
            if (trail_reg & level_reg) != 0:
                node = far_child
            else:
                node = near_child
                if short_stack_capacity > 0:
                    short_stack.push(far_child)
                else:
                    # Stackless: far child is effectively lost unless restart trail handles it
                    # However, restart trail semantics ensure we can return to far child
                    # by setting its parent's bit to 1.
                    pass
                    
        elif len(hits) == 1:
            # One child intersected
            level_reg = level_reg >> 1
            
            # Check if we are returning to a node where the far child was culled
            current_level_idx = bit_index(level_reg)
            
            if pop_level is None or current_level_idx != pop_level:
                # Normal descent: mark this node as having one child to process
                trail_reg = trail_reg | level_reg
                node = hits[0]
            else:
                # Far child was culled during near child processing
                node = pop(trail_reg, level_reg, short_stack, root)
                # Note: pop() updates node, trail_reg, level_reg, and pop_level
                
        else:
            # No children intersected
            node = pop(trail_reg, level_reg, short_stack, root)
            
        # If node is still not None and loop continues, check if it's a leaf
        if node is not None and is_leaf(node):
            hit = intersect_primitives(node, ray)
            if hit is not None and hit.t < ray.t_max:
                ray.t_max = hit.t
            node = pop(trail_reg, level_reg, short_stack, root)
            
    return ray.hit

def pop(trail_reg, level_reg, short_stack, root):
    # Find largest i <= current level where trail[i] == 0
    # This is implicitly handled by the bitwise operations below
    
    # Clear bits below level_reg
    trail_reg = trail_reg & (-level_reg)
    
    # Set the next highest zero bit and clear bits above it
    trail_reg = trail_reg + level_reg
    
    # Update level_reg to point to the lowest set bit in trail_reg
    temp = trail_reg >> 1
    level_reg = (((temp - 1) ^ temp) + 1)
    
    # Check sentinel (bit 0)
    if (trail_reg & 1) != 0:
        return None # Termination
        
    # Save pop level for next iteration check
    # pop_level is stored in the caller's scope or returned
    # For this self-contained function, we assume pop_level is updated externally
    # or we return the new state.
    
    if short_stack is empty:
        # Restart from root
        level_reg = 1 # Reset to sentinel
        return root
    else:
        return short_stack.pop()
```

**Parameters:**
*   **Short Stack Size:** A size of 1 reduces the node visit multiplier to 1.3–1.4 compared to full stack. A size of 3 yields 5–8% extraneous node visits [S1, unofficial].
*   **Register Width:** 32 or 64 bits, sufficient for typical hierarchy depths [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Culled Far Child:** If a node has two intersecting children, but the far child becomes culled during the processing of the near child (due to ray shortening), the algorithm must detect this via `popLevel` to avoid re-entering the near branch. If `level` equals `popLevel` in the single-child branch, it indicates the far child was culled, and `POP()` must be invoked [S1, unofficial].
*   **Infinite Loops:** Care must be taken to ensure that equal $t$ values after a restart do not cause re-entering already processed branches, leading to infinite loops, especially with zero-thickness nodes [S1, unofficial].
*   **BVH vs KD-Tree:** BVHs may cause a slight increase in extraneous visits compared to kd-trees because rays intersect both children more frequently, causing more stack pushes and restarts [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Stackless traversal visits approximately 2.2–2.4 times as many nodes as ordinary traversal with a full stack [S1, unofficial]. A short stack with one entry reduces this multiplier to 1.3–1.4 [S1, unofficial].
*   **Memory Complexity:** Uses $O(1)$ auxiliary memory for the trail (one bit per level, stored in a register) and $O(N)$ for the short stack, where $N$ is the stack size. This is significantly less than a full stack [S1, unofficial].
*   **Performance:** Preliminary tests on NVIDIA G80 and GT200 hardware with CUDA ray cast kernels indicate that the memory bandwidth benefits of short stacks do not outweigh the costs of restarts, SIMD divergence, and extra instructions [S1, unofficial]. However, avoiding a full stack is beneficial for hardware hierarchy traversal units where registers are limited but full stacks cannot be stored locally [S1, unofficial].
*   **Strengths:** Enables stackless traversal for BVHs; allows near-first traversal order; low memory footprint.
*   **Limitations:** Higher node visit count than full-stack traversal; potential performance overhead on older GPU architectures due to divergence and restart costs.

## Background
*   **Origin:** Introduced by Tero Laine et al. in "Restart Trail for Stackless BVH Traversal" (2010) [S1, unofficial].
*   **History:** Prior to this, stackless traversal for BVHs was difficult because kd-tree techniques like ray shortening do not work for overlapping BVH nodes. Skip-node pointers existed but constrained traversal order [S1, unofficial].
*   **Usage:** Useful for hardware hierarchy traversal units and environments with limited stack space [S1, unofficial].
