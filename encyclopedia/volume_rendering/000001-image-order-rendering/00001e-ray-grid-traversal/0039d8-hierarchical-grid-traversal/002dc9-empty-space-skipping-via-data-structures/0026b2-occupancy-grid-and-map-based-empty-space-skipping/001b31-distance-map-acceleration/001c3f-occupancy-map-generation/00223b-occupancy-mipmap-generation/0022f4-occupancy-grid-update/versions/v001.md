# Occupancy Grid Update

Also called: Density-Based Grid Update, Grid Density Thresholding, Occupancy Grid Update from Density

## Overview
This method periodically refreshes a 3D occupancy grid by querying a Neural Radiance Field (NeRF) model for density values at voxel centers, marking voxels as occupied if the density exceeds a specified threshold [S1, unofficial]. It solves the problem of stale acceleration structures in dynamic or evolving NeRF training by ensuring the empty-space skipping mechanism reflects the current neural network's predictions [S1, unofficial]. It differs from its parent, [Occupancy Mipmap Generation](2700-occupancy-mipmap-generation.md), by operating on a single-resolution grid using direct density thresholding rather than hierarchical convolutional smoothing, and from its child, [Density Grid Update with EMA](3884-density-grid-update-with-ema.md), by using binary occupancy states instead of continuous exponential moving averages [S1, S2].

## How it works
**Inputs and Outputs:**
- Input: A trained or partially trained NeRF model, the current training iteration count, the 3D grid resolution, the Axis-Aligned Bounding Box (AABB) defining the scene bounds, and a density threshold.
- Output: A 3D boolean occupancy grid of shape $(R, R, R)$ where $R$ is the resolution.

**Data Structures:**
- `grid`: A 3D tensor of shape $(R, R, R)$ containing boolean values (`True` for occupied, `False` for empty).
- `aabb_min`, `aabb_max`: 3D vectors defining the lower and upper bounds of the scene in world coordinates.
- `resolution`: Integer $R$, the number of voxels along each axis.

**Steps:**
1. **Generate Grid Coordinates:** Create a meshgrid of integer indices for the 3D grid.
   $$ \text{grid\_coords} = \text{meshgrid}(x, y, z, \text{indexing}='ij').\text{reshape}(-1, 3) $$
   where $x, y, z = \text{linspace}(0, R-1, R)$.
2. **Convert to World Positions:** Map grid indices to world coordinates using the AABB.
   $$ \text{positions} = \text{aabb\_min} + \left( \frac{\text{grid\_indices} + 0.5}{R} \right) \times (\text{aabb\_max} - \text{aabb\_min}) $$
   Here, $\text{grid\_indices}$ are the float values of the voxel centers (index + 0.5).
3. **Query Densities:** Batch the world positions and query the NeRF model for density values $\sigma$.
   - If the model supports a `forward_with_density_only` method, call it with the positions.
   - Otherwise, call the model with dummy view directions and extract the density output.
4. **Update Grid:** Compare densities against the threshold.
   $$ \text{occupied} = \sigma > \text{threshold} $$
   Reshape the boolean array to $(R, R, R)$ and update `self.grid`.

**Parameters:**
- `resolution` ($R$): Integer, default 128 [S1, unofficial].
- `density_threshold`: Float, default 0.01 [S1, unofficial].
- `update_grid_every`: Integer, iteration interval for updates (e.g., 500) [S1, unofficial].
- `occupancy_threshold`: Float, synonym for density threshold in some implementations [S1, unofficial].

**Pseudocode:**
```python
def update_occupancy_grid(model, aabb_min, aabb_max, resolution, threshold, batch_size=10000):
    """
    Updates the occupancy grid based on current NeRF density predictions.
    """
    # 1. Generate grid coordinates
    x = torch.linspace(0, resolution - 1, resolution)
    y = torch.linspace(0, resolution - 1, resolution)
    z = torch.linspace(0, resolution - 1, resolution)
    grid_coords = torch.stack(torch.meshgrid(x, y, z, indexing='ij'), dim=-1)
    grid_coords_flat = grid_coords.reshape(-1, 3)
    
    # 2. Convert to world positions
    # positions = aabb_min + ((grid_indices + 0.5) / resolution) * (aabb_max - aabb_min)
    grid_indices_float = grid_coords_flat.float()
    positions = aabb_min + ((grid_indices_float + 0.5) / resolution) * (aabb_max - aabb_min)
    
    # 3. Query densities in batches
    densities = []
    num_voxels = positions.shape[0]
    for i in range(0, num_voxels, batch_size):
        batch_positions = positions[i:i+batch_size]
        if hasattr(model, 'forward_with_density_only'):
            batch_densities = model.forward_with_density_only(batch_positions)
        else:
            # Dummy directions are required if the model expects view-dependent input
            dummy_dirs = torch.zeros_like(batch_positions)
            output = model(batch_positions, dummy_dirs)
            # Extract density from output (assumed to be the first channel or specific field)
            batch_densities = output[..., 0] # [G] Assumption: density is first output channel
        densities.append(batch_densities)
    
    all_densities = torch.cat(densities, dim=0)
    
    # 4. Update grid
    occupied = all_densities > threshold
    self.grid = occupied.reshape(resolution, resolution, resolution)
```

**Edge Cases and Pitfalls:**
- **Precision:** Ensure `grid_indices` are converted to float before world position calculation to avoid integer division errors [S1, unofficial].
- **Boundaries:** The formula uses `+ 0.5` to sample at voxel centers, ensuring coverage of the entire AABB [S1, unofficial].
- **Degenerate Input:** If the NeRF model is not yet trained (all densities near zero), the grid will remain empty. Updates should only occur after sufficient training iterations [S1, unofficial].

## Subtopics

### [Density Grid Update with EMA](3884-density-grid-update-with-ema.md)
Uses Exponential Moving Average of densities for smoother transitions and better gradient flow during training. Choose this when training stability and continuous density representation are prioritized over binary occupancy speed.

## Operating characteristics
- **Time Complexity:** $O(R^3)$ per update, where $R$ is the grid resolution. The cost is dominated by the NeRF inference queries.
- **Memory Complexity:** $O(R^3)$ for the occupancy grid storage.
- **Measured Performance:** In Instant-NGP implementations, a resolution of 128 with updates every 500 iterations provides a good balance between acceleration speed and update overhead [S1, unofficial].
- **Strengths:** Simple to implement; effectively skips empty space in static scenes; low memory overhead compared to hierarchical structures.
- **Limitations:** Stale grid if updates are infrequent; binary thresholding can lead to aliasing artifacts at boundaries; requires periodic full-grid queries which can be costly if done too frequently.
- **When to Use:** Static or slowly changing scenes; training phases where the geometry is stabilizing.
- **When Not to Use:** Highly dynamic scenes requiring per-frame updates; scenes with fine details smaller than the voxel size.

## Background
The method originates from Instant-NGP, introduced by Müller et al. in 2022, which popularized hash-based neural radiance fields and occupancy grids for real-time rendering [S1, unofficial]. It is widely used in modern NeRF training pipelines to accelerate ray marching by skipping empty space. The specific implementation details cited here are from the FLASH project, an experimental implementation of Instant-NGP [S1, unofficial].
