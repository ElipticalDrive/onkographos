# Distance Map Acceleration

Also called: Accelerated Volume Rendering with Chebyshev Distance Maps, Chebyshev Distance Maps, Chebyshev distance map ray traversal, Distance Field Ray Marching Acceleration, Empty space skipping using distance maps, Ray Traversal with Distance Map Skipping

## Overview
Distance Map Acceleration is a ray traversal technique that uses a precomputed Chebyshev distance map, derived from an occupancy map, to skip sampling points in empty regions of a volumetric image [S1]. It solves the problem of excessive texture memory bandwidth and computational cost when ray marching through large volumes with significant empty space [S1]. Unlike its sibling [Two-stage Ray Marching with Empty-Space Skipping](2985-two-stage-ray-marching-with-empty-space-skipping.md), which typically uses binary occupancy checks, Distance Map Acceleration computes the exact distance to the nearest occupied block, allowing the ray to leap directly to the next region of interest rather than stepping block-by-block [S1]. It builds on [Occupancy Grid and Map-Based Empty Space Skipping](3852-occupancy-grid-and-map-based-empty-space-skipping.md) by adding the distance field computation step.

## How it works
**Inputs and Outputs:**
*   **Inputs:** High-resolution volume texture ($d_{\text{vol}}$), transfer function parameters (for occupancy generation), camera ray origin and direction.
*   **Outputs:** Rendered image with reduced sample count.
*   **Precomputed Data:** Occupancy map ($d_{\text{occ}}$), Distance map ($d_{\text{occ}}$), Gradient map (optional, $d_{\text{vol}}$).

**Data Structures:**
1.  **Volume Texture:** 3D texture of size $d_{\text{vol}} \times d_{\text{vol}} \times d_{\text{vol}}$ (or anisotropic).
2.  **Occupancy Map:** 3D texture of size $d_{\text{occ}} = d_{\text{vol}} / B$. Each voxel is a binary flag (1 if occupied, 0 if empty).
3.  **Distance Map:** 3D texture of size $d_{\text{occ}}$. Each voxel stores the Chebyshev distance (L-infinity norm) to the nearest occupied voxel in the occupancy map.
4.  **Gradient Map:** 3D texture of size $d_{\text{vol}}$. Stores precomputed gradient magnitudes for 2D transfer functions [S1].

**Parameters:**
*   $B \in \mathbb{N}^3$: Block size. Default $B=4$ [S2, unofficial].
*   $f \ge 1$: Sampling factor for quality adjustment [S1].
*   `imin`, `imax`: Intensity thresholds for transfer function. Default `imin`=0.1, `imax`=1.0 [S2, unofficial].
*   `gmin`, `gmax`: Gradient thresholds. Default `gmin`=0.0, `gmax`=0.2 [S2, unofficial].
*   `clip_distance`: Distance from camera for volume clipping. Default 1.0f [S2, unofficial].

**Algorithm Steps:**

1.  **Precomputation (Offline/Update Time):**
    1.  **Gradient Map Generation:** If using 2D transfer functions, compute gradient magnitudes for all voxels using the tetrahedron method [S1].
        *   For a voxel at `pos`, sample 4 neighbors: `pos + k.xyy`, `pos + k.yyx`, `pos + k.yxy`, `pos + k.xxx` where `k = ivec2(1, -1)` [S1].
        *   Compute gradient direction:
            $$ \mathbf{g} = 0.25 \cdot (k_{xyy} \cdot v_{xyy} + k_{yyx} \cdot v_{yyx} + k_{yxy} \cdot v_{yxy} + k_{xxx} \cdot v_{xxx}) $$
            where $v$ are the sampled scalar values [S1].
        *   Store $\|\mathbf{g}\|$ in the gradient map [S1].
    2.  **Occupancy Map Generation:**
        *   For volume rendering: A block is occupied if it contains any voxel with non-zero alpha (based on `imin`/`imax` and `gmin`/`gmax`) [S1].
        *   For isosurface rendering: A block is occupied if the isosurface threshold lies between the min/max voxel values in the block, including a 1-voxel halo around the block boundary [S1].
        *   Write binary flags to the occupancy map [S1].
    3.  **Distance Map Computation:**
        *   Compute the Chebyshev distance map from the occupancy map. This encodes the distance to the nearest occupied block for every block in the occupancy grid [S1].

2.  **Ray Traversal (Per Ray):**
    1.  **Ray Setup:** Calculate the number of samples $n$ and step size $\Delta t$ [S1]:
        $$ n = \lceil \max \vec{x}(\mathbf{d}) \cdot \|\mathbf{t}_{\text{exit}} - \mathbf{t}_{\text{entry}}\| \cdot f \rceil $$
        $$ \Delta t = \frac{t_{\text{exit}} - t_{\text{entry}}}{n - 1} $$
        where $\mathbf{d}$ is the ray direction, $\mathbf{t}_{\text{entry}}$ and $\mathbf{t}_{\text{exit}}$ are the normalized entry and exit points [S1].
    2.  **Initial Position:** Start at $\mathbf{t}_0 = \mathbf{t}_{\text{entry}}$ [S1].
    3.  **Loop:** For each sample $i$ from 0 to $n-1$:
        1.  Map current normalized texture coordinate $\mathbf{t}_i$ to occupancy map coordinate $\mathbf{u}_{\text{occ}}$:
            $$ \mathbf{u}_{\text{occ}} = \frac{d_{\text{vol}}}{B} \mathbf{t}_i $$
            (Note: Exact mapping accounts for $d_{\text{vol}}$ not being evenly divisible by $B \cdot d_{\text{occ}}$) [S1].
        2.  Lookup the distance value $D$ at $\mathbf{u}_{\text{occ}}$ in the distance map [S1].
        3.  **Skip Logic:**
            *   If $D > 0$ (empty region): The ray can skip ahead. The number of steps $\Delta i_j$ to the next occupied region along dimension $j$ is calculated. The ray advances by the maximum of these steps across all dimensions to ensure it lands outside the empty block [S1].
            *   Specifically, for dimension $j$:
                $$ \Delta i_j = \begin{cases} \lceil (1 + \lfloor u_j \rfloor - u_j) / \Delta u_j \rceil, & \text{if } \Delta u_j > 0 \\ \lceil (\lfloor u_j \rfloor - u_j) / \Delta u_j \rceil, & \text{otherwise} \end{cases} $$
                where $u_j$ is the occupancy coordinate and $\Delta u_j$ is the change in occupancy coordinate per sample [S1].
            *   Advance the ray index $i$ by $\max_j(\Delta i_j)$ [S1].
            *   If the new $i \ge n$, terminate.
        4.  **Sampling:** If the block is occupied ($D=0$ or ray is inside an occupied block):
            *   Map $\mathbf{t}_i$ to volume texture coordinates.
            *   Sample the volume texture (and gradient map if used) [S1].
            *   Apply transfer function and accumulate color/opacity [S1].
    4.  **Clipping:** Clip the volume against a plane at `clip_distance` from the camera to allow the viewpoint to enter the volume. Compute box-plane intersection vertices in a vertex shader [S2, unofficial]. Clip rendered volumes against the depth buffer [S2, unofficial].

**Pseudocode:**

```python
def distance_map_ray_march(ray_origin, ray_direction, volume_tex, occupancy_tex, distance_tex, block_size, sampling_factor):
    """
    Performs ray marching with distance map acceleration.
    """
    # 1. Calculate ray bounds and sample count
    t_entry, t_exit = compute_ray_volume_intersection(ray_origin, ray_direction)
    if t_entry > t_exit:
        return 0.0 # No intersection

    # Normalized coordinates (0 to 1)
    t_entry_norm = t_entry
    t_exit_norm = t_exit
    
    # Number of samples
    max_dir = max(abs(ray_direction.x), abs(ray_direction.y), abs(ray_direction.z))
    n = ceil(max_dir * (t_exit_norm - t_entry_norm) * sampling_factor)
    
    if n <= 0:
        n = 1
        
    delta_t = (t_exit_norm - t_entry_norm) / (n - 1) if n > 1 else 0.0
    
    # Occupancy map dimensions
    d_vol = volume_tex.dimensions # e.g., (512, 512, 512)
    d_occ = d_vol / block_size
    
    color = vec3(0.0)
    alpha = 0.0
    
    for i in range(n):
        # Current normalized position
        t_current = t_entry_norm + i * delta_t
        
        # Map to occupancy coordinate
        # u_occ = (d_vol / B) * t_vol
        u_occ = (d_vol / block_size) * t_current
        
        # Lookup distance in distance map
        # Note: u_occ might be float, need to index appropriately (e.g., floor)
        dist = distance_tex.sample(u_occ)
        
        if dist > 0:
            # Empty region: Calculate skip steps
            # Calculate steps to next block boundary in occupancy space
            skip_steps = 0
            for j in range(3): # x, y, z
                u_j = u_occ[j]
                delta_u_j = delta_t * (d_vol[j] / block_size[j]) # Change in occ coord per sample
                
                if delta_u_j > 0:
                    steps_j = ceil((1 + floor(u_j) - u_j) / delta_u_j)
                else:
                    steps_j = ceil((floor(u_j) - u_j) / delta_u_j)
                
                skip_steps = max(skip_steps, steps_j)
            
            # Advance i by skip_steps
            i += skip_steps - 1 # Loop will increment i, so subtract 1
            if i >= n:
                break
            continue
        
        # Occupied region: Sample volume
        # Map t_current to volume texture coordinates
        t_vol = t_current # Assuming normalized 0-1 volume coords
        
        # Sample volume
        val = volume_tex.sample(t_vol)
        
        # Apply transfer function and accumulate
        # ... (standard volume rendering accumulation)
        pass
        
    return color
```

## Operating characteristics
*   **Time Complexity:** Precomputation is $O(d_{\text{occ}}^3)$ for occupancy and distance map generation. Ray traversal is $O(n)$ in the worst case (fully occupied), but significantly faster in sparse volumes due to skipping.
*   **Memory Complexity:** Occupancy map is $1/B^3$ the size of the volume. Distance map is same size as occupancy map. Gradient map is same size as volume [S1].
*   **Performance:** Reduces texture samples and improves frame rates for volume and isosurface rendering [S1]. Default block size $B=4$ reduces occupancy map memory to 1/64th of the volume [S1].
*   **Strengths:** Efficient empty space skipping, supports viewpoint entry into volume, single subpass rendering [S2, unofficial].
*   **Limitations:** Requires precomputation of distance map. Depth testing can be hacky if using depth buffer for clipping [S2, unofficial].

## Background
The method was introduced by Lachlan Deakin and Mark Knackstedt in 2019 in the paper "Accelerated Volume Rendering with Chebyshev Distance Maps" [S1]. It is implemented in the open-source Vulkan renderer `VkVolume` [S2, unofficial].
