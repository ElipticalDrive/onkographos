# Density Grid Update with EMA

Also called: EMA Occupancy Grid Update

## Overview
This method periodically refreshes a 3D hierarchical density grid using an Exponential Moving Average (EMA) of newly queried densities to stabilize training and refine the representation of occupied space [S1, unofficial][S2, unofficial]. It builds on [Occupancy Grid Update](2916-occupancy-grid-update.md) by maintaining a continuous density value per voxel rather than just binary occupancy, allowing for smoother transitions and better gradient flow during neural radiance field optimization. It sets itself apart from sibling methods like [MERF Baking](10179-merf-baking.md) by performing online, step-wise updates during training rather than offline baking, and from [Occupancy Grid Transition and Update](7522-occupancy-grid-transition-and-update.md) by using EMA smoothing instead of hard thresholding or transition maps.

## How it works
**Inputs:**
- `step`: Current training iteration integer.
- `occ_eval_fn`: A callable function that takes sample locations `(N, 3)` and returns occupancy values `(N, 1)`.
- `occ_thre`: Float threshold for binary occupancy determination.
- `ema_decay`: Float decay factor for the EMA.
- `warmup_steps`: Integer number of initial steps to sample all cells.
- `n`: Integer frequency of updates (update every `n` steps).
- `self.density_grid`: The current 3D density tensor of shape `(resolution, resolution, resolution)` or hierarchical equivalent.
- `self.occs`: The current occupancy values tensor.
- `self.binaries`: The current binary occupancy grid.
- `self.resolution`: Grid resolution.
- `self.levels`: Number of hierarchical levels.
- `self.aabbs`: Axis-aligned bounding boxes for each level, shape `(levels, 6)`.
- `self.cells_per_lvl`: Number of cells per level.
- `self.grid_coords`: Precomputed grid coordinates for all cells.
- `self.bound`: World-space bounding box size.

**Outputs:**
- Updated `self.density_grid`.
- Updated `self.mean_density`.
- Updated `self.binaries` (derived from `self.occs`).

**Data Structures:**
- `density_grid`: 3D tensor (or hierarchical structure) storing density values $\sigma$.
- `occs`: 1D or 3D tensor storing continuous occupancy values $o \in [0, 1]$.
- `binaries`: Boolean tensor indicating occupied voxels ($o > \text{thre}$).
- `aabbs`: Tensor of shape `(levels, 6)` storing `[min_x, min_y, min_z, max_x, max_y, max_z]` for each level.

**Parameters:**
- `occ_thre`: Default $0.01$ [S1, unofficial].
- `ema_decay`: Default $0.95$ [S1, unofficial].
- `warmup_steps`: Default $256$ [S1, unofficial].
- `n`: Update frequency, default $16$ [S1, unofficial].

**Steps:**

1. **Check Training State and Frequency:**
   If not in training mode, raise an error. If `step % n != 0`, skip update [S1, unofficial].

2. **Cell Sampling:**
   Determine which cells to query based on the current step:
   - If `step < warmup_steps`: Sample all cells uniformly using `self._get_all_cells()` [S1, unofficial].
   - If `step >= warmup_steps`: Sample $N = \text{self.cells\_per\_lvl} // 4$ cells, mixing uniform and occupied cells using `self._sample_uniform_and_occupied_cells(N)` [S1, unofficial].

3. **Coordinate Transformation:**
   For each level `lvl` and its sampled indices:
   - Retrieve grid coordinates: `grid_coords = self.grid_coords[indices]` [S1, unofficial].
   - Add uniform random noise to jitter sampling within voxels:
     $$ x_{local} = \frac{\text{grid\_coords} + \text{rand}(\text{grid\_coords})}{\text{self.resolution}} $$
     where $\text{rand}$ generates values in $[0, 1)$ [S1, unofficial].
   - Transform local coordinates to world space using the level's AABB:
     $$ x_{world} = \text{aabbs[lvl, :3]} + x_{local} \times (\text{aabbs[lvl, 3:]} - \text{aabbs[lvl, :3]}) $$
     [S1, unofficial].

4. **Occupancy Evaluation:**
   Evaluate occupancy at world coordinates $x_{world}$ using `occ_eval_fn`:
   $$ o = \text{occ\_eval\_fn}(x_{world}).\text{squeeze}(-1) $$
   [S1, unofficial].

5. **Occupancy Grid Update (EMA):**
   Compute global cell IDs:
   $$ \text{cell\_ids} = \text{lvl} \times \text{self.cells\_per\_lvl} + \text{indices} $$
   [S1, unofficial].
   Update occupancy values using EMA maximum:
   $$ \text{self.occs}[\text{cell\_ids}] = \max(\text{self.occs}[\text{cell\_ids}] \times \text{ema\_decay}, o) $$
   [S1, unofficial].
   *Note: The implementation uses `torch.maximum` instead of `scatter_max` for efficiency, with empirical results showing negligible difference [S1, unofficial].*

6. **Binary Occupancy Update:**
   Compute the threshold for binary occupancy:
   $$ \text{thre} = \text{clamp}(\text{mean}(\text{self.occs}[\text{self.occs} \ge 0]), \text{max}=\text{occ\_thre}) $$
   [S1, unofficial].
   Update binary grid:
   $$ \text{self.binaries} = (\text{self.occs} > \text{thre}).\text{view}(\text{self.binaries.shape}) $$
   [S1, unofficial].

7. **Density Grid Update:**
   - Initialize a temporary grid: `tmp_grid = torch.zeros_like(self.density_grid)` [S2, unofficial].
   - Generate coordinate lines for X, Y, Z axes using `torch.linspace` from `-self.bound + half\_grid\_size` to `self.bound - half\_grid\_size`, split into chunks of 128 [S2, unofficial].
   - Construct meshgrid points:
     $$ xx, yy, zz = \text{meshgrid}(xs, ys, zs, \text{indexing}="ij") $$
     [S2, unofficial].
   - Concatenate and reshape points to shape `(N, 3)`:
     $$ \text{pts} = \text{cat}([xx.\text{reshape}(-1, 1), yy.\text{reshape}(-1, 1), zz.\text{reshape}(-1, 1)], \text{dim}=-1) $$
     [S2, unofficial].
   - Add uniform noise in range `[-hgs, hgs]` to points:
     $$ \text{pts} += (\text{rand}(\text{pts}) \times 2 - 1) \times \text{half\_grid\_size} $$
     where $\text{half\_grid\_size} = \text{self.bound} / \text{resolution}$ [S2, unofficial].
   - Pad points to a multiple of 128 for manual padding:
     $$ \text{pad\_n} = 128 - (\text{n} \% 128) $$
     [S2, unofficial].
   - Query density from the network:
     $$ \text{density} = \text{self.density}(\text{pts}.\text{to}(\text{tmp\_grid.device}))[:n].\text{reshape}(lx, ly, lz).\text{detach}() $$
     [S2, unofficial].
   - Assign density to the temporary grid at the corresponding slice:
     $$ \text{tmp\_grid}[xi \times 128:\dots, yi \times 128:\dots, zi \times 128:\dots] = \text{density} $$
     [S2, unofficial].
   - Update the density grid using EMA:
     $$ \text{self.density\_grid} = \max(\text{self.density\_grid} \times \text{decay}, \text{tmp\_grid}) $$
     [S2, unofficial].
   - Update mean density:
     $$ \text{self.mean\_density} = \text{mean}(\text{self.density\_grid}).\text{item}() $$
     [S2, unofficial].

**Pseudocode:**

```python
def update_density_grid_with_ema(step, occ_eval_fn, occ_thre=0.01, ema_decay=0.95, warmup_steps=256, n=16):
    """
    Updates the density grid using EMA of newly queried densities.
    Assumes self is an object with attributes:
    - training: bool
    - density_grid: torch.Tensor
    - occs: torch.Tensor
    - binaries: torch.Tensor
    - resolution: int
    - levels: int
    - aabbs: torch.Tensor (levels, 6)
    - cells_per_lvl: int
    - grid_coords: torch.Tensor
    - bound: float
    - density: callable (neural network)
    - mean_density: float
    """
    if not self.training:
        raise RuntimeError("Update only allowed during training")
    
    if step % n != 0:
        return

    # 1. Cell Sampling
    if step < warmup_steps:
        indices_list = self._get_all_cells()
    else:
        N = self.cells_per_lvl // 4
        indices_list = self._sample_uniform_and_occupied_cells(N)

    # 2. Coordinate Transformation and Occupancy Evaluation
    for lvl, indices in indices_list:
        grid_coords = self.grid_coords[indices]
        
        # Jitter within voxels
        x_local = (grid_coords + torch.rand_like(grid_coords, dtype=torch.float32)) / self.resolution
        
        # Transform to world space
        x_world = self.aabbs[lvl, :3] + x_local * (self.aabbs[lvl, 3:] - self.aabbs[lvl, :3])
        
        # Evaluate occupancy
        occ = occ_eval_fn(x_world).squeeze(-1)
        
        # Compute global cell IDs
        cell_ids = lvl * self.cells_per_lvl + indices
        
        # Update occupancy with EMA max
        self.occs[cell_ids] = torch.maximum(self.occs[cell_ids] * ema_decay, occ)

    # 3. Binary Occupancy Update
    # Compute threshold
    valid_occs = self.occs[self.occs >= 0]
    if valid_occs.numel() > 0:
        thre = torch.clamp(valid_occs.mean(), max=occ_thre)
    else:
        thre = occ_thre
    
    self.binaries = (self.occs > thre).view(self.binaries.shape)

    # 4. Density Grid Update
    resolution = self.density_grid.shape[0]
    half_grid_size = self.bound / resolution
    
    tmp_grid = torch.zeros_like(self.density_grid)
    
    # Generate coordinate lines
    xs = torch.linspace(-self.bound + half_grid_size, self.bound - half_grid_size, resolution)
    ys = torch.linspace(-self.bound + half_grid_size, self.bound - half_grid_size, resolution)
    zs = torch.linspace(-self.bound + half_grid_size, self.bound - half_grid_size, resolution)
    
    # Split into chunks of 128
    x_chunks = [xs[i:i+128] for i in range(0, len(xs), 128)]
    y_chunks = [ys[i:i+128] for i in range(0, len(ys), 128)]
    z_chunks = [zs[i:i+128] for i in range(0, len(zs), 128)]
    
    for xi, xs_chunk in enumerate(x_chunks):
        for yi, ys_chunk in enumerate(y_chunks):
            for zi, zs_chunk in enumerate(z_chunks):
                xx, yy, zz = torch.meshgrid(xs_chunk, ys_chunk, zs_chunk, indexing="ij")
                pts = torch.cat([xx.reshape(-1, 1), yy.reshape(-1, 1), zz.reshape(-1, 1)], dim=-1)
                
                # Add noise
                pts = pts + (torch.rand_like(pts) * 2 - 1) * half_grid_size
                
                # Pad to multiple of 128
                n = pts.shape[0]
                pad_n = 128 - (n % 128)
                if pad_n < 128:
                    pts = torch.cat([pts, torch.zeros(pad_n, 3, device=pts.device)], dim=0)
                
                # Query density
                density = self.density(pts.to(tmp_grid.device))[:n].reshape(len(xs_chunk), len(ys_chunk), len(zs_chunk)).detach()
                
                # Assign to tmp_grid
                tmp_grid[xi*128:xi*128+len(xs_chunk), yi*128:yi*128+len(ys_chunk), zi*128:zi*128+len(zs_chunk)] = density
    
    # Update density grid with EMA
    self.density_grid = torch.maximum(self.density_grid * ema_decay, tmp_grid)
    self.mean_density = torch.mean(self.density_grid).item()
```

## Subtopics

### [Voxel Prior Loss](10726-voxel-prior-loss.md)
Voxel Prior Loss is a regularization term for 3D Gaussian Splatting that aligns the learned Gaussian primitives with a precomputed occupancy grid. It solves the problem of "ghosting" or floating artifacts in empty space and ensures Gaussians in occupied regions have appropriate scale and opacity. It sets itself apart from standard photometric losses by explicitly enforcing geometric priors derived from voxel occupancy, suppressing Gaussians in empty voxels and encouraging dense, correctly scaled Gaussians in occupied ones.

## Operating characteristics
- **Time Complexity:** Depends on the number of cells sampled and the cost of the occupancy evaluation function. During warmup, it samples all cells, which is $O(R^3)$ where $R$ is resolution. After warmup, it samples a fraction ($1/4$ uniform, $1/4$ occupied), reducing cost. The density grid update involves querying the network at grid points, which is $O(R^3)$ per update step.
- **Memory Complexity:** Requires storing the density grid, occupancy grid, and binary grid, all of size proportional to $R^3$. The hierarchical structure may reduce effective memory usage if sparse.
- **Measured Performance:** Not given in the sources.
- **Scaling:** Scales with grid resolution and number of levels. The use of chunks (128) suggests optimization for memory bandwidth and cache efficiency.
- **Strengths:** Stabilizes training by smoothing density updates; reduces noise in empty space; allows for efficient ray marching via occupancy grids.
- **Limitations:** Requires careful tuning of `ema_decay` and `occ_thre`; warmup phase can be expensive; relies on the quality of `occ_eval_fn`.
- **When to use:** When training neural radiance fields or 3D Gaussian Splatting with occupancy grids to accelerate rendering and improve geometry.
- **When not to use:** When offline baking is preferred (use [MERF Baking](10179-merf-baking.md)) or when binary occupancy is sufficient without density smoothing.

## Background
The method originates from the implementation of faster occupancy grid updates for neural radiance fields, specifically in the context of training 3D Gaussian Splatting and NeRFs with hierarchical grids. It was popularized by the `faster-occgrid` repository [S1, unofficial] and referenced in educational materials like `cv-master-ex` [S2, unofficial]. It addresses the need for stable and efficient online updates of occupancy and density grids during training, which are critical for real-time or near-real-time novel view synthesis.
