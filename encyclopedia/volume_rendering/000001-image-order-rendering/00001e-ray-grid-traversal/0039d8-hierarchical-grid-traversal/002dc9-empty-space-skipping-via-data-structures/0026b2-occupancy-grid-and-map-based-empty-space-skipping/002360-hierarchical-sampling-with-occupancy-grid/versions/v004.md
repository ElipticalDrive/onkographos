# Hierarchical Sampling with Occupancy Grid

Also called: FLASH Renderer, NeRF Hierarchical Sampling

## Overview
Hierarchical Sampling with Occupancy Grid is a two-stage volume rendering method that combines empty-space skipping via an occupancy grid with importance-based hierarchical sampling to accelerate Neural Radiance Field (NeRF) training and inference [S1, unofficial]. It differs from its siblings by explicitly decoupling the coarse sampling phase (guided by spatial occupancy) from the fine sampling phase (guided by rendered weights), allowing for efficient refinement of high-density regions without re-evaluating empty space [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Ray origins $\mathbf{o}$, ray directions $\mathbf{d}$, near/far clipping planes ($t_{\text{near}}, t_{\text{far}}$), an occupancy grid structure, a coarse NeRF model, and a fine NeRF model.
*   **Outputs:** Rendered RGB color, depth, accumulated opacity, and weights for each ray.

**Data Structures:**
*   **OccupancyGrid:** A 3D boolean grid representing the spatial distribution of active volume data [S1, unofficial].
    *   `resolution`: Integer, the side length of the cubic grid.
    *   `aabb_min`: Tensor of shape `[3]`, minimum bounds of the axis-aligned bounding box (AABB) in world space.
    *   `aabb_max`: Tensor of shape `[3]`, maximum bounds of the AABB in world space.
    *   `density_threshold`: Float, the density threshold used to determine if a voxel is occupied.
    *   `grid`: Boolean tensor of shape `[resolution, resolution, resolution]`, where `True` indicates an occupied voxel.
    *   `voxel_size`: Tensor of shape `[3]`, the physical size of each voxel.

**Algorithm Steps:**

1.  **Normalize Ray Directions:**
    Normalize the input ray directions to unit length:
    $$ \mathbf{d}_{\text{norm}} = \frac{\mathbf{d}}{\|\mathbf{d}\|} $$

2.  **Coarse Sampling with Empty-Space Skipping:**
    Determine coarse sample positions $t_{\text{coarse}}$ along the ray.
    *   If an `OccupancyGrid` is available, query it to find occupied regions within $[t_{\text{near}}, t_{\text{far}}]$. Sample points stratified or randomly within these occupied segments [S1, unofficial].
    *   If no occupancy grid is present, perform standard stratified sampling across the entire interval $[t_{\text{near}}, t_{\text{far}}]$ [S1, unofficial].
    *   Let $N_c$ be the number of coarse samples (default 32).

3.  **Coarse Rendering:**
    Evaluate the coarse model at positions $\mathbf{p}_i = \mathbf{o} + t_{\text{coarse}, i} \mathbf{d}_{\text{norm}}$.
    *   Query the coarse model for density $\sigma_i$ and color $\mathbf{c}_i$.
    *   Compute distances between adjacent samples: $d_i = t_{\text{coarse}, i+1} - t_{\text{coarse}, i}$. Handle the last segment by setting $d_{N_c-1}$ to a large value (e.g., $10^{10}$) or assuming infinite background [S1, unofficial].
    *   Compute alpha opacity:
        $$ \alpha_i = 1 - \exp(-\sigma_i \cdot d_i) $$
    *   Compute transmittance (accumulated opacity from previous samples):
        $$ T_i = \prod_{j=0}^{i-1} (1 - \alpha_j) $$
        *Note: Add a small epsilon ($\epsilon = 10^{-10}$) to $(1-\alpha_j)$ for numerical stability* [S1, unofficial].
    *   Compute weights:
        $$ w_i = T_i \cdot \alpha_i $$
    *   Compute coarse color and depth:
        $$ \mathbf{C}_{\text{coarse}} = \sum_{i=0}^{N_c-1} w_i \mathbf{c}_i $$
        $$ D_{\text{coarse}} = \sum_{i=0}^{N_c-1} w_i t_{\text{coarse}, i} $$
        $$ A_{\text{coarse}} = \sum_{i=0}^{N_c-1} w_i $$

4.  **Hierarchical Fine Sampling:**
    Use the coarse weights $w_i$ to guide the placement of fine samples.
    *   Compute midpoints between coarse samples:
        $$ t_{\text{mid}, i} = \frac{t_{\text{coarse}, i} + t_{\text{coarse}, i+1}}{2} $$
    *   Construct bins for sampling:
        $$ \text{bins} = [t_{\text{coarse}, 0}, t_{\text{mid}, 0}, \dots, t_{\text{mid}, N_c-2}, t_{\text{coarse}, N_c-1}] $$
    *   Sample $N_f$ fine positions $t_{\text{fine}}$ from these bins, where the probability of sampling in a bin is proportional to the sum of weights of the coarse samples defining that bin [S1, unofficial]. This is typically done via inverse transform sampling using the cumulative weights.

5.  **Combine and Sort:**
    Concatenate coarse and fine samples:
    $$ t_{\text{combined}} = \text{sort}(t_{\text{coarse}} \cup t_{\text{fine}}) $$
    Let $N_{\text{total}} = N_c + N_f$.

6.  **Fine Rendering:**
    Evaluate the fine model at all positions in $t_{\text{combined}}$.
    *   Query the fine model for density $\sigma'_i$ and color $\mathbf{c}'_i$.
    *   Recompute $d_i, \alpha_i, T_i, w_i$ using the fine model's densities and the sorted $t_{\text{combined}}$ intervals [S1, unofficial].
    *   Compute final color:
        $$ \mathbf{C}_{\text{final}} = \sum_{i=0}^{N_{\text{total}}-1} w_i \mathbf{c}'_i $$
    *   Compute final depth:
        $$ D_{\text{final}} = \sum_{i=0}^{N_{\text{total}}-1} w_i t_{\text{combined}, i} $$
    *   Compute final accumulated opacity:
        $$ A_{\text{final}} = \sum_{i=0}^{N_{\text{total}}-1} w_i $$

7.  **Background Compositing:**
    If a white background is assumed, add the background contribution:
    $$ \mathbf{C}_{\text{out}} = \mathbf{C}_{\text{final}} + (1 - A_{\text{final}}) \cdot \mathbf{1} $$
    Otherwise, $\mathbf{C}_{\text{out}} = \mathbf{C}_{\text{final}}$ [S1, unofficial].

**Pseudocode:**

```python
import torch
import math

def hierarchical_sampling_with_occupancy_grid(
    rays_o,       # [num_rays, 3]
    rays_d,       # [num_rays, 3]
    near,         # float
    far,          # float
    num_coarse,   # int
    num_fine,     # int
    occupancy_grid, # Optional OccupancyGrid object
    model_coarse, # Coarse NeRF model
    model_fine,   # Fine NeRF model
    white_background=True
):
    # 1. Normalize rays
    rays_d = torch.nn.functional.normalize(rays_d, dim=-1)
    
    # 2. Coarse Sampling
    if occupancy_grid is not None:
        # Query occupancy grid for occupied intervals
        # Returns list of (start_t, end_t) for each ray
        occupied_intervals = occupancy_grid.sample_occupied_regions(rays_o, rays_d, near, far)
        t_coarse = sample_from_intervals(occupied_intervals, num_coarse)
    else:
        # Fallback to stratified sampling
        t_coarse = sample_stratified(near, far, num_coarse)
        
    # 3. Coarse Rendering
    positions_coarse = rays_o.unsqueeze(1) + t_coarse.unsqueeze(2) * rays_d.unsqueeze(1)
    # Flatten for model input: [num_rays * num_coarse, 3]
    pos_flat = positions_coarse.reshape(-1, 3)
    dir_flat = rays_d.unsqueeze(1).expand(-1, num_coarse, -1).reshape(-1, 3)
    
    rgb_coarse, density_coarse = model_coarse(pos_flat, dir_flat)
    rgb_coarse = rgb_coarse.reshape(-1, num_coarse, 3)
    density_coarse = density_coarse.reshape(-1, num_coarse)
    
    # Compute distances
    dists = t_coarse[:, 1:] - t_coarse[:, :-1]
    # Append a large distance for the last segment to handle background
    dists = torch.cat([dists, torch.full((dists.shape[0], 1), 1e10, device=dists.device)], dim=-1)
    
    # Compute Alpha
    alpha = 1.0 - torch.exp(-density_coarse * dists)
    
    # Compute Transmittance
    # T[i] = product(1 - alpha[j] for j < i)
    # Use cumprod on (1 - alpha + eps)
    one_minus_alpha = 1.0 - alpha + 1e-10
    T = torch.cumprod(one_minus_alpha, dim=-1)
    # Shift T: T[i] should be product up to i-1. 
    # cumprod gives P[i] = prod(0..i). We want prod(0..i-1).
    # So T_shifted[i] = T[i-1] for i>0, and 1.0 for i=0.
    T_shifted = torch.cat([torch.ones_like(T[:, :1]), T[:, :-1]], dim=-1)
    
    weights_coarse = T_shifted * alpha
    
    # 4. Hierarchical Fine Sampling
    # Compute midpoints
    t_mid = 0.5 * (t_coarse[:, :-1] + t_coarse[:, 1:])
    # Construct bins: [t0, mid0, mid1, ..., tN]
    bins = torch.cat([t_coarse[:, :1], t_mid, t_coarse[:, -1:]], dim=-1)
    
    # Sample fine t-values based on weights_coarse
    t_fine = sample_hierarchical(bins, weights_coarse.detach(), num_fine)
    
    # 5. Combine and Sort
    t_combined = torch.cat([t_coarse, t_fine], dim=-1)
    t_combined, indices = torch.sort(t_combined, dim=-1)
    
    # 6. Fine Rendering
    positions_fine = rays_o.unsqueeze(1) + t_combined.unsqueeze(2) * rays_d.unsqueeze(1)
    pos_flat_fine = positions_fine.reshape(-1, 3)
    dir_flat_fine = rays_d.unsqueeze(1).expand(-1, t_combined.shape[1], -1).reshape(-1, 3)
    
    rgb_fine, density_fine = model_fine(pos_flat_fine, dir_flat_fine)
    rgb_fine = rgb_fine.reshape(-1, t_combined.shape[1], 3)
    density_fine = density_fine.reshape(-1, t_combined.shape[1])
    
    # Recompute distances for combined samples
    dists_combined = t_combined[:, 1:] - t_combined[:, :-1]
    dists_combined = torch.cat([dists_combined, torch.full((dists_combined.shape[0], 1), 1e10, device=dists_combined.device)], dim=-1)
    
    alpha_fine = 1.0 - torch.exp(-density_fine * dists_combined)
    one_minus_alpha_fine = 1.0 - alpha_fine + 1e-10
    T_fine = torch.cumprod(one_minus_alpha_fine, dim=-1)
    T_shifted_fine = torch.cat([torch.ones_like(T_fine[:, :1]), T_fine[:, :-1]], dim=-1)
    
    weights_fine = T_shifted_fine * alpha_fine
    
    # 7. Composite
    rgb_integrated = torch.sum(weights_fine.unsqueeze(-1) * rgb_fine, dim=1)
    acc = torch.sum(weights_fine, dim=-1)
    depth = torch.sum(weights_fine * t_combined, dim=-1)
    
    if white_background:
        rgb_final = rgb_integrated + (1.0 - acc.unsqueeze(-1))
    else:
        rgb_final = rgb_integrated
        
    return rgb_final, depth, acc, weights_fine

def sample_hierarchical(bins, weights, num_samples):
    """
    Samples points from bins according to weights.
    bins: [num_rays, num_bins]
    weights: [num_rays, num_bins - 1] (weights associated with intervals)
    """
    # Normalize weights to probabilities
    prob = weights / (weights.sum(dim=-1, keepdim=True) + 1e-10)
    # Cumulative distribution
    cdf = prob.cumsum(dim=-1)
    cdf = torch.cat([torch.zeros_like(cdf[:, :1]), cdf], dim=-1)
    
    # Generate uniform random numbers
    u = torch.rand_like(cdf)
    
    # Inverse transform sampling
    # Find bin index for each u
    # This is a simplified version; in practice, use torch.searchsorted or similar
    bin_indices = torch.searchsorted(cdf, u, right=True) - 1
    bin_indices = torch.clamp(bin_indices, 0, bins.shape[1] - 2)
    
    # Interpolate within the bin
    bin_start = bins[torch.arange(bins.shape[0]), bin_indices]
    bin_end = bins[torch.arange(bins.shape[0]), bin_indices + 1]
    
    # Map u to the specific bin's local probability
    # This part requires careful handling of the CDF within the bin
    # For simplicity, assuming uniform distribution within the weighted bin is not correct.
    # Correct approach: Sample from the discrete distribution defined by weights,
    # then sample uniformly within the selected bin? 
    # No, hierarchical sampling usually implies sampling proportional to weight,
    # then uniformly within the segment? Or sampling from the continuous distribution?
    # FLASH implementation typically uses:
    # 1. Select bin i with prob w_i.
    # 2. Sample uniformly in [t_i, t_{i+1}].
    # However, the source notes say "sample_hierarchical(bins, weights...)".
    # Let's stick to the standard NeRF hierarchical sampling logic:
    # Sample bin index i with probability proportional to w_i.
    # Sample t uniformly in [bins[i], bins[i+1]].
    
    # Re-implementing simple version based on standard NeRF paper logic adapted for FLASH notes:
    # 1. Sample bin index
    bin_probs = weights / (weights.sum(dim=-1, keepdim=True) + 1e-10)
    bin_indices = torch.multinomial(bin_probs, num_samples, replacement=True)
    
    # 2. Sample uniformly in the bin
    bin_starts = bins[torch.arange(bins.shape[0]), bin_indices]
    bin_ends = bins[torch.arange(bins.shape[0]), bin_indices + 1]
    t_fine = bin_starts + (bin_ends - bin_starts) * torch.rand_like(bin_starts)
    
    return t_fine
```

**Parameters:**
*   `near`: Float, default 2.0. Near clipping plane distance.
*   `far`: Float, default 6.0. Far clipping plane distance.
*   `num_coarse_samples`: Integer, default 32. Number of samples in the coarse stage.
*   `num_fine_samples`: Integer, default 64. Number of samples in the fine stage.
*   `occupancy_grid`: Optional OccupancyGrid instance. If present, used for empty-space skipping during coarse sampling.

**Edge Cases and Pitfalls:**
*   **Division by Zero in Ray-AABB Intersection:** When computing ray-box intersections for the occupancy grid, add a small epsilon ($10^{-8}$) to ray directions to prevent division by zero if a ray is parallel to a box face [S1, unofficial].
*   **Numerical Stability in Transmittance:** Add $10^{-10}$ to $(1 - \alpha)$ before computing the cumulative product to prevent `NaN` values due to floating-point underflow [S1, unofficial].
*   **Model Input Compatibility:** If the model does not support `forward_with_density_only`, dummy zero directions may need to be passed to satisfy input shape requirements during density-only queries [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The coarse stage is $O(N_c)$, and the fine stage is $O(N_c + N_f)$. The occupancy grid query is $O(1)$ per ray for finding occupied intervals, but constructing the grid is $O(V)$ where $V$ is the number of voxels.
*   **Memory Complexity:** The occupancy grid requires $O(R^3)$ memory where $R$ is the resolution. The NeRF models require memory proportional to their parameter count.
*   **Performance:** FLASH achieves training speeds of 10-15 minutes on a single GPU for synthetic scenes, significantly faster than vanilla NeRF [S1, unofficial].
*   **Strengths:** Efficiently skips empty space, reducing the number of model evaluations. Hierarchical sampling focuses computational effort on high-density regions, improving image quality per sample.
*   **Limitations:** Requires construction and maintenance of the occupancy grid. Performance depends on the sparsity of the scene; if the scene is dense, the occupancy grid provides less benefit.

## Background
Hierarchical Sampling with Occupancy Grid is implemented in the FLASH (Fast Learning for Accurate Scene Hashing) project, an experimental implementation of Instant-NGP for Neural Radiance Fields [S1, unofficial]. It was developed to enable rapid training of 3D scenes from 2D images, leveraging multi-resolution hash encoding and occupancy grids for acceleration [S1, unofficial].
