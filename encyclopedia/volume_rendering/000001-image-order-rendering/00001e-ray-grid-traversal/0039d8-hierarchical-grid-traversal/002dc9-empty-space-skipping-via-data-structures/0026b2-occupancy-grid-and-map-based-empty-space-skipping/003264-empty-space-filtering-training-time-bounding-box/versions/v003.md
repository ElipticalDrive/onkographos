# Empty Space Filtering (Training-Time Bounding Box)

Also called: Alpha-based Bounding Box Filtering, Training-time Empty Space Filtering

## Overview
Empty Space Filtering is a preprocessing and runtime optimization technique used in dynamic neural volume rendering to accelerate training and inference by restricting computation to the spatial extent of the scene. It solves the problem of wasted computation in empty regions by constructing a coarse geometry prior (a bounding box) derived from alpha values of a coarse deformation feature grid, and then filtering out sampled points that fall outside this active region or have negligible alpha values [S1]. Unlike static volume rendering methods that use fixed bounds, this method adapts to the dynamic nature of the scene by aggregating object presence across all training time steps [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A coarse deformation feature grid defined over a canonical space and its deformations; a predefined alpha threshold $\tau$; a set of training time steps $T$.
*   **Output:** A coarse geometry prior (axis-aligned bounding box) enclosing the scene; a filtering mask for sampled points during ray marching.

**Data Structures:**
*   **Coarse Deformation Feature Grid:** A 3D grid storing deformation features. Each vertex $v$ in this grid has an associated alpha value $\alpha(v, t)$ at time step $t$.
*   **Coarse Geometry Prior:** An axis-aligned bounding box (AABB) defined by minimum and maximum coordinates $(x_{min}, y_{min}, z_{min})$ and $(x_{max}, y_{max}, z_{max})$.

**Steps:**

1.  **Query Alpha Values:** For every vertex $v$ in the coarse deformation feature grid, and for every training time step $t \in T$, retrieve the alpha value $\alpha(v, t)$. This represents the opacity or presence of the object at that vertex and time [S1].
2.  **Classify Vertices:** A vertex $v$ is classified as an "object point" if its alpha value exceeds the threshold $\tau$ at any time step. Formally, a vertex is considered part of the scene if:
    $$ \exists t \in T : \alpha(v, t) > \tau $$
    Otherwise, it is classified as empty space [S1].
3.  **Compute Bounding Box:** Determine the smallest axis-aligned bounding box that fully encloses all vertices classified as object points across all time steps. This box serves as the "coarse geometry prior" [S1].
4.  **Filter Sampled Points (Deformation Module):** During training, for points sampled in the deformation module, filter out points that are recognized as empty. Since empty points are assumed to be static, a point is filtered if its alpha value is below the threshold for *all* training times:
    $$ \forall t \in T : \alpha(v, t) \le \tau \implies \text{filter point} $$
    This reduces the number of queries to the light-weight MLP [S1].
5.  **Filter Sampled Points (Canonical Module):** For points sampled in the canonical module, filter out empty points only at the canonical time (typically $t=0$ or the reference frame). Points with $\alpha(v, t_{canonical}) \le \tau$ are filtered [S1].
6.  **Apply Bounding Box Constraint:** Use the coarse geometry prior to restrict the volume of the grid in the fine stage. Points sampled outside this bounding box are discarded or not processed, avoiding empty space computation [S1].

**Pseudocode:**

```python
def compute_coarse_geometry_prior(coarse_grid, time_steps, alpha_threshold):
    """
    Computes the bounding box of the scene by aggregating object points
    across all time steps.
    
    Args:
        coarse_grid: 3D grid of vertices. Each vertex has a method get_alpha(t).
        time_steps: List of time indices T.
        alpha_threshold: Scalar threshold tau.
        
    Returns:
        bbox: Tuple (min_coords, max_coords) defining the AABB.
    """
    min_coords = [infinity, infinity, infinity]
    max_coords = [-infinity, -infinity, -infinity]
    
    # Iterate over all vertices in the coarse grid
    for vertex in coarse_grid.vertices:
        is_object = False
        # Check alpha values across all time steps
        for t in time_steps:
            alpha = vertex.get_alpha(t)
            if alpha > alpha_threshold:
                is_object = True
                break
        
        # If vertex is part of the object, update bounding box
        if is_object:
            coords = vertex.position
            for i in range(3):
                if coords[i] < min_coords[i]:
                    min_coords[i] = coords[i]
                if coords[i] > max_coords[i]:
                    max_coords[i] = coords[i]
                    
    return (min_coords, max_coords)

def filter_sampled_points(sampled_points, coarse_grid, time_steps, alpha_threshold, canonical_time):
    """
    Filters out sampled points that are recognized as empty space.
    
    Args:
        sampled_points: List of points to be processed.
        coarse_grid: The coarse deformation feature grid for alpha lookup.
        time_steps: List of time indices T.
        alpha_threshold: Scalar threshold tau.
        canonical_time: The reference time step for canonical module filtering.
        
    Returns:
        filtered_points: List of points that are not empty.
    """
    valid_points = []
    
    for point in sampled_points:
        # Determine which module the point belongs to based on context
        # Note: In practice, this logic is applied separately for deformation vs canonical modules
        # as per the source description. Here we implement the general logic.
        
        # Check if point is in the coarse geometry prior bounding box
        if not is_inside_bbox(point.position, coarse_geometry_prior):
            continue
            
        # For deformation module points: filter if alpha <= threshold for ALL times
        # For canonical module points: filter if alpha <= threshold at canonical time only
        # The source distinguishes these. We assume a flag or context indicates the module.
        
        is_empty = False
        if point.module_type == 'deformation':
            # Filter if always below threshold
            always_below = True
            for t in time_steps:
                alpha = coarse_grid.get_alpha_at_point(point.position, t)
                if alpha > alpha_threshold:
                    always_below = False
                    break
            if always_below:
                is_empty = True
                
        elif point.module_type == 'canonical':
            # Filter only at canonical time
            alpha = coarse_grid.get_alpha_at_point(point.position, canonical_time)
            if alpha <= alpha_threshold:
                is_empty = True
                
        if not is_empty:
            valid_points.append(point)
            
    return valid_points
```

**Parameters:**
*   **Alpha Threshold ($\tau$):** A predefined scalar value used to distinguish object points from empty space. Typical values are not explicitly given in the sources, but it must be tuned to avoid filtering low-density regions [S1].

**Edge Cases and Pitfalls:**
*   **Low-Density Regions:** Regions with low density (e.g., a white plate on a white background) may have alpha values close to zero even if they are part of the scene. If the image reconstruction error is low, these regions might be incorrectly filtered out as empty space [S1]. This can be alleviated by using a background with a different color or disabling the filtering strategy for such scenes [S1].
*   **Dynamic Extent:** The bounding box must be computed over *all* training time steps to ensure the entire dynamic range of the object is captured. Failing to do so may result in parts of the object being filtered out during certain time steps [S1].

## Operating characteristics
*   **Time Complexity:** The preprocessing step (computing the bounding box) requires querying the coarse grid for all vertices and all time steps, which is $O(V \cdot T)$ where $V$ is the number of vertices in the coarse grid and $T$ is the number of time steps. Filtering during training reduces the number of MLP queries, improving training and rendering speed [S1].
*   **Memory Complexity:** Requires storing the coarse deformation feature grid and the computed bounding box. The bounding box is a constant size structure [S1].
*   **Performance:** The method significantly reduces training and rendering time compared to not using filtering. In experiments, the full model with filtering (NDGV full) outperformed the model without filtering (NDGV w/o filter) in training speed, render speed, and PSNR [S1].
*   **Strengths:** Effective for dynamic scenes with significant empty space; reduces computational load on the MLP; adapts to the scene's geometry over time.
*   **Limitations:** May filter out valid low-density objects if the threshold is not carefully chosen; requires a coarse grid to be trained first to generate the alpha values for filtering [S1].

## Background
The method was proposed in the context of Neural Deformable Voxel Grid (NDGV) for fast optimization of dynamic view synthesis. It was introduced by X. Guo et al. in 2022 [S1]. The technique builds upon the use of coarse deformation feature grids to accelerate the training of fine models by providing a geometry prior [S1].
