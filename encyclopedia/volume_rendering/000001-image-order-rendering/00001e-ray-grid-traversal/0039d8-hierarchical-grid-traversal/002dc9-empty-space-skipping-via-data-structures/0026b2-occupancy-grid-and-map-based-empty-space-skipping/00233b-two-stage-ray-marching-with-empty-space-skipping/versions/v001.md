# Two-stage Ray Marching with Empty-Space Skipping

Also called: Occupancy Map Empty Space Skipping, Occupancy-based early exit, Simple occupancy map traversal, Two-phase volumetric rendering

## Overview
Two-stage Ray Marching with Empty-Space Skipping is a volume rendering optimization that accelerates ray traversal by decoupling the search for volume entry from the density sampling process [S1][S2, unofficial]. It solves the problem of wasted computation when rays traverse large empty regions of a volume by using a lower-resolution occupancy map to skip over empty blocks in Stage 1, then switching to high-resolution density sampling in Stage 2 only after an occupied region is detected [S1][S2, unofficial]. This method sets itself apart from [Distance Map Acceleration](972-distance-map-acceleration.md) by using binary occupancy flags rather than distance-to-nearest-occupied-voxel values, and from [Hierarchical Sampling with Occupancy Grid](3035-hierarchical-sampling-with-occupancy-grid.md) by using a fixed two-phase structure rather than adaptive hierarchical refinement [S1][S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Volume data (voxel grid), camera parameters (position, projection matrix, inverse projection matrix), volume bounds, occupancy map (precomputed), ray origin, ray direction.
*   **Outputs:** Final pixel color (composited density/opacity).

**Data Structures:**
*   **Occupancy Map:** A 3D grid of integer flags (0 for empty, 1 for occupied). The resolution is lower than the volume grid. The ratio of volume resolution to occupancy map resolution is denoted by $B$ [S1].
*   **Volume Voxel Buffer:** A 1D buffer storing volume data. Voxel indexing uses row-major order: `index = z * (X * Y) + y * X + x`, where $X, Y, Z$ are the dimensions of the voxel grid [S2, unofficial].
*   **Ray State:** `length` (current distance along ray), `stepSize` (distance per sample), `smokeValue` (current occupancy/density sample).

**Parameters:**
*   $B$: Block size factor, ratio of volume resolution to occupancy map resolution. Larger $B$ skips more empty voxels per sample but reduces precision near occupied regions [S1].
*   `_RayMaxLength`: Maximum distance a ray can travel before being considered a miss [S2, unofficial].
*   `stage2StepMax`: Fixed number of steps for Stage 2 sampling (e.g., 40) [S2, unofficial].
*   `_Smoothing`, `_DensityMult`, `_SmokeOrigin`, `_SmokeRadius`: Parameters for density calculation [S2, unofficial].

**Numbered Steps:**

1.  **Occupancy Map Generation (Preprocessing):**
    Generate an occupancy map using a compute shader. Each shader invocation evaluates a unique volume block for occupancy and writes the result (0 or 1) to the associated occupancy map voxel [S1].

2.  **Ray Initialization:**
    Initialize ray parameters:
    *   `origin` = Camera position [S2, unofficial].
    *   `rayVector` = Direction derived from UV coordinates through inverse projection and camera-to-world matrices:
        $$ \text{rayVector} = \text{normalize}(\text{mul}(_{\text{CamToWorldMatrix}}, \text{float4}(\text{mul}(_{\text{invProjectionMatrix}}, \text{float4}(uv.x \times 2 - 1, uv.y \times 2 - 1, 0, 1)).xyz, 0)).xyz) $$ [S2, unofficial].
    *   `length` = 0 [S2, unofficial].
    *   `stepSize` = 0.2 (or similar small value) [S2, unofficial].
    *   `smokeValue` = -1 [S2, unofficial].

3.  **Stage 1: Empty Space Skipping Loop:**
    While `smokeValue <= 0` AND `length < _RayMaxLength`:
    a. Increment `length` by `stepSize` [S2, unofficial].
    b. Calculate `positionWS` = `origin` + `length` * `rayVector` [S2, unofficial].
    c. Query `smokeValue` = `getSmokeVoxel(positionWS)` [S2, unofficial].
       *   `getSmokeVoxel` converts world position to voxel space, checks bounds, and returns the occupancy flag from the 1D buffer [S2, unofficial].
       *   Bounds check: If `position` is outside `_BoundsExtent`, return -1 (miss) [S2, unofficial]. Note: The Y-axis bounds check in the reference implementation is asymmetric and prone to misinterpretation, anchoring the volume at ground level [S2, unofficial].

4.  **Stage 1 Exit Condition:**
    *   If `smokeValue` remains `<= 0` after `length` exceeds `_RayMaxLength`, the ray misses the volume. Output black color [S2, unofficial].
    *   If `smokeValue == 1` (entry detected), proceed to Stage 2 [S2, unofficial].

5.  **Backward Step Adjustment (Pitfall Mitigation):**
    After finding an occupied region, decrement the ray step number by $\Delta i_{\text{backward}} = -\lfloor f \rfloor$ to ensure the ray goes back at least one voxel length, accounting for interpolation or boundary isosurfaces [S1]. This prevents missing thin structures or boundaries due to interpolation artifacts [S1].

6.  **Stage 2: Density Sampling Loop:**
    If entry detected:
    a. Initialize `stage2StepNum` = 0, `accumulatedDensity` = 0 [S2, unofficial].
    b. While `stage2StepNum < stage2StepMax`:
       i. Calculate `samplePoint` = `origin` + `length` * `rayVector` [S2, unofficial].
       ii. Compute density using `sampleDensity(samplePoint, uv)` [S2, unofficial].
           *   Density formula: `1 - smoothstep(_Smoothing, 1.0, normalizedDistance + noiseValue)` [S2, unofficial].
           *   `normalizedDistance` = `length(pos - _SmokeOrigin) / _SmokeRadius` [S2, unofficial].
           *   Note: The reference implementation samples noise using screen UVs (`uv`), pinning the noise pattern to the screen. Correct implementation requires sampling noise using world position (`samplePoint`) to attach detail to the volume [S2, unofficial].
       iii. Add to `accumulatedDensity` scaled by `_DensityMult` [S2, unofficial].
       iv. Increment `length` by `stepSize` [S2, unofficial].
       v. Increment `stage2StepNum` [S2, unofficial].
    c. Composite the accumulated density into the final color [S2, unofficial].

7.  **Resuming Empty Space Skipping:**
    Empty space skipping resumes only when the occupancy map coordinate $u_{occ}$ changes and the previously sampled voxel had zero opacity [S1]. This ensures the occupancy map is not sampled more than necessary [S1].

**Formulas:**

*   **Step Calculation in Occupancy Map Space:**
    The number of steps to the first sampling point outside the current region on dimension $j \in \{x, y, z\}$ is:
    $$ \Delta i_j = \begin{cases} \lceil (1 + \lfloor \mathbf{u}_j \rfloor - \mathbf{u}_j) / \Delta \mathbf{u}_j \rceil, & \text{if } \Delta \mathbf{u}_j > 0 \\ \lceil (\lfloor \mathbf{u}_j \rfloor - \mathbf{u}_j) / \Delta \mathbf{u}_j \rceil, & \text{otherwise} \end{cases} $$ [S1].
    This can be vectorized using the Heaviside step function:
    $$ \Delta \mathbf{i} = \lceil (\text{step}(\Delta \mathbf{u}) + \lfloor \mathbf{u} \rfloor - \mathbf{u}) / \Delta \mathbf{u} \rceil $$ [S1].
    The final step count is the minimum of the dimensional steps, clamped to a minimum of 1:
    $$ \Delta i = \max(\min(\Delta \mathbf{i}), 1) $$ [S1].
    This clamping handles axis-aligned rays where $\Delta u$ is infinite on one dimension [S1].

*   **Occupancy Map Step Distance:**
    The distance step in occupancy map space is computed as:
    $$ \Delta \mathbf{u}_{\text{occ}} = \frac{d_{\text{vol}}}{B} \Delta \mathbf{t}_{\text{vol}} $$ [S1].
    where $d_{\text{vol}}$ is the volume step size and $\Delta \mathbf{t}_{\text{vol}}$ is the ray direction in volume space [S1].

**Pseudocode:**

```python
def two_stage_ray_marching(ray_origin, ray_direction, occupancy_map, volume_data, bounds_extent, voxel_resolution, block_size_factor, ray_max_length, stage2_step_max, smoke_origin, smoke_radius, smoothing, density_mult, noise_texture):
    """
    Implements Two-stage Ray Marching with Empty-Space Skipping.
    
    Args:
        ray_origin: float3, camera position
        ray_direction: float3, normalized ray direction
        occupancy_map: 3D array, occupancy flags (0 or 1)
        volume_data: 1D array, volume density values
        bounds_extent: float3, half-extent of the volume bounds
        voxel_resolution: float, size of one volume voxel
        block_size_factor: float, ratio of volume resolution to occupancy map resolution (B)
        ray_max_length: float, maximum ray length
        stage2_step_max: int, max steps in stage 2
        smoke_origin: float3, origin of smoke volume
        smoke_radius: float, radius of smoke volume
        smoothing: float, smoothing parameter for density
        density_mult: float, density multiplier
        noise_texture: 2D array, noise values
        
    Returns:
        float4, final pixel color
    """
    
    # Stage 1: Empty Space Skipping
    length = 0.0
    step_size = 0.2  # Fixed step size for simplicity
    smoke_value = -1
    
    while smoke_value <= 0 and length < ray_max_length:
        length += step_size
        position_ws = ray_origin + length * ray_direction
        
        # Get occupancy value
        smoke_value = get_occupancy(position_ws, occupancy_map, bounds_extent, voxel_resolution, block_size_factor)
        
        # If we hit an occupied region, we need to step back slightly to account for interpolation/boundaries
        if smoke_value == 1:
            # Backward step adjustment
            # f is a sampling factor, assumed to be 1.0 for this implementation
            f = 1.0
            length -= floor(f) * step_size
            
    # If ray missed the volume entirely
    if smoke_value <= 0:
        return float4(0.0, 0.0, 0.0, 0.0)
    
    # Stage 2: Density Sampling
    stage2_step_num = 0
    accumulated_density = 0.0
    
    while stage2_step_num < stage2_step_max:
        sample_point = ray_origin + length * ray_direction
        
        # Calculate density
        density = sample_density(sample_point, smoke_origin, smoke_radius, smoothing, density_mult, noise_texture)
        accumulated_density += density
        
        length += step_size
        stage2_step_num += 1
        
    # Composite color based on accumulated density
    # Assuming simple alpha blending for demonstration
    alpha = min(accumulated_density, 1.0)
    color = float4(alpha, alpha, alpha, alpha)
    return color

def get_occupancy(position_ws, occupancy_map, bounds_extent, voxel_resolution, block_size_factor):
    """
    Converts world position to voxel space and returns occupancy flag.
    """
    # Check bounds
    if (position_ws.x < -bounds_extent.x or position_ws.x > bounds_extent.x or
        position_ws.y < -bounds_extent.y + bounds_extent.y or position_ws.y > bounds_extent.y + bounds_extent.y or
        position_ws.z < -bounds_extent.z or position_ws.z > bounds_extent.z):
        return -1  # Out of bounds
        
    # Convert to voxel space
    adjusted_position = position_ws + float3(bounds_extent.x, 0, bounds_extent.z)
    adjusted_position /= voxel_resolution
    adjusted_position = floor(adjusted_position)
    
    # Flatten index
    x, y, z = adjusted_position
    index = z * (occupancy_map.shape[0] * occupancy_map.shape[1]) + y * occupancy_map.shape[0] + x
    
    return occupancy_map[index]

def sample_density(sample_point, smoke_origin, smoke_radius, smoothing, density_mult, noise_texture):
    """
    Calculates density at a given point.
    """
    distance_from_origin = length(sample_point - smoke_origin)
    normalized_distance = distance_from_origin / smoke_radius
    
    # Sample noise using world position (corrected from screen UVs)
    # Assuming noise_texture is sampled based on normalized world coordinates
    noise_uv = sample_point / smoke_radius
    noise_value = noise_texture[noise_uv]
    
    density = 1.0 - smoothstep(smoothing, 1.0, normalized_distance + noise_value)
    return density * density_mult
```

## Subtopics

### [PDF Light Weight Space Leaping](5848-pdf-light-weight-space-leaping.md)
A two-phase ray casting algorithm that uses detector rays to determine empty space distances and spreads this information to neighboring pixels to accelerate subsequent ray casting via space leaping [5848-pdf-light-weight-space-leaping.md]. It differs from standard occupancy map skipping by using spatial coherence across pixels to predict empty space, rather than per-ray occupancy lookups [5848-pdf-light-weight-space-leaping.md]. Choose this when rendering scenes with large, coherent empty regions and when pixel-level coherence can be exploited [5848-pdf-light-weight-space-leaping.md].

## Operating characteristics
*   **Time Complexity:** Stage 1 is $O(1)$ per empty block skipped, proportional to the number of empty blocks traversed. Stage 2 is $O(N)$ where $N$ is the number of steps within occupied regions. Overall complexity is reduced compared to naive ray marching by the factor of empty space skipped [S1][S3, unofficial].
*   **Memory Complexity:** Requires storage for the occupancy map, which is $O(V/B^3)$ where $V$ is the volume resolution and $B$ is the block size factor [S1].
*   **Measured Performance:** In a medical imaging project, using a Volume Occupancy Map to skip empty voxels increased rendering frame rate by 3.2x [S3, unofficial].
*   **Scaling:** Performance improves with larger $B$ (fewer occupancy map samples) but accuracy decreases near occupied regions [S1].
*   **Strengths:** Significant speedup for sparse volumes; simple to implement; low memory overhead for the occupancy map [S1][S3, unofficial].
*   **Limitations:** Requires preprocessing to generate the occupancy map; less effective for dense volumes; fixed step size in Stage 2 may cause bleeding past volume boundaries if not bounded correctly [S2, unofficial].
*   **When to Use:** Sparse volumes, real-time rendering where preprocessing is acceptable, scenes with large empty regions [S1][S3, unofficial].
*   **When Not to Use:** Dense volumes, dynamic volumes where occupancy map generation is too costly, scenes with thin structures that might be missed by coarse occupancy maps [S1][S2, unofficial].

## Background
The technique originated from research on efficient ray casting of volumetric images using distance maps for empty space skipping [S1]. It was developed to address the computational cost of sampling empty space in volumetric rendering [S1]. The method has been applied in various contexts, including medical imaging and real-time rendering [S1][S3, unofficial]. The reference implementation [S2, unofficial] demonstrates its application in real-time volumetric smoke rendering using compute shaders.
