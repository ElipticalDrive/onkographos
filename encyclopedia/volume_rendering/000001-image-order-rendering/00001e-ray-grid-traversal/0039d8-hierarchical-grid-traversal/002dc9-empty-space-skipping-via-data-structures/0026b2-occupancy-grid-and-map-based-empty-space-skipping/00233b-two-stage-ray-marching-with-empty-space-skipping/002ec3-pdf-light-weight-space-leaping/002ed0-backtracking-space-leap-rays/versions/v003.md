# Backtracking Space Leap Rays

Also called: Backtracking Correction for Space Leap Rays

## Overview
Backtracking Space Leap Rays is a correction mechanism applied to space leap rays in volume rendering to ensure that no non-transparent sample points are missed during the leap phase [S1, S2]. It solves the problem where a space leap ray, accelerated by a detector ray, might jump past the boundary of a non-empty cell group, thereby skipping valid data [S1, S2]. It is distinguished from standard space leaping by the explicit verification of the first sample's location relative to empty space and the subsequent backward movement of the ray origin if it lands inside a non-empty cell [S1, S2].

## How it works
**Inputs and Outputs**
*   **Input:** A space leap ray defined by its origin and direction, a leap buffer containing the number of samples taken by the corresponding detector ray to reach the first non-empty cell, and the volume data structure with cell group boundaries [S1].
*   **Output:** A corrected ray origin that is guaranteed to be in an empty cell, along with a temporary buffer of sample values collected during backtracking [S1, S2].

**Data Structures**
*   **Leap Buffer:** An array storing integer values representing the number of samples a detector ray traversed through empty space before hitting a non-empty cell [S1].
*   **Temporary Buffer:** A small array or stack used to store sample values (color and opacity) collected during the backtracking phase to avoid re-sampling [S2].

**Parameters**
*   $\delta$: The sampling distance (step size) along the ray [S1, S2].
*   $\mu_x, \mu_y, \mu_z$: The dimensions (edge lengths) of the current cell group [S1, S2].
*   $M_{max}$: The maximum number of samples to backtrack [S1, S2].

**Steps**
1.  **Leap Check:** Determine the tentative new origin of the space leap ray based on the leap buffer value [S1].
2.  **Boundary Condition Check:** If the leap buffer value is zero, do not leap the ray at all; proceed with standard ray marching from the previous position [S1, S2].
3.  **Leap Adjustment:** When leaping, leap one sample less than the value stored in the leap buffer [S1]. This ensures that the sample immediately preceding the leap target is the last sample in an empty cell [S1].
4.  **Empty Cell Verification:** Evaluate the volume data at the first sample point of the (adjusted) space leap ray [S1, S2].
5.  **Backtracking Decision:**
    *   If the first sample point is inside an empty cell, the ray is correctly positioned before the cell group [S1]. Proceed to standard ray marching from this point [S1, S2].
    *   If the first sample point is inside a non-empty cell, the ray has jumped too far and missed the object boundary [S1]. Initiate backtracking [S1, S2].
6.  **Backtracking Execution:**
    *   Move the ray origin backwards by one sample distance ($\delta$) at a time [S1, S2].
    *   Sample the volume at each backtracked position [S1, S2].
    *   Store the resulting sample values in the temporary buffer [S1, S2].
    *   Continue backtracking until the sample point is located inside an empty cell [S1, S2].
    *   **Limit:** Do not backtrack beyond the limit defined by the leap buffer value, as this would move the ray behind the image plane [S1, S2].
    *   **Upper Bound:** The maximum number of backtracking steps is bounded by $M_{max}$ [S1, S2].
7.  **Compositing:** After backtracking completes, composite the sample values stored in the temporary buffer into the final image buffer before continuing with the forward ray march [S1, S2].

**Formulas**
The upper limit for the number of samples a ray needs to backtrack is calculated as:

$$ M_{max} = 2 \times \frac{\max(\mu_x, \mu_y, \mu_z)}{\delta} $$

Where:
*   $\mu_x, \mu_y, \mu_z$ are the longest edges of the cell group [S1, S2].
*   $\delta$ is the sampling distance [S1, S2].

**Pseudocode**

```python
def backtracking_space_leap_ray(ray_origin, ray_direction, leap_buffer_value, 
                                cell_group_dims, sampling_distance, volume_data):
    """
    Corrects a space leap ray to ensure it starts in an empty cell.
    
    Args:
        ray_origin: Initial origin of the space leap ray.
        ray_direction: Unit direction vector of the ray.
        leap_buffer_value: Number of empty samples from the detector ray.
        cell_group_dims: Tuple (mu_x, mu_y, mu_z) of the cell group dimensions.
        sampling_distance: Step size delta.
        volume_data: Object providing volume access methods.
        
    Returns:
        corrected_origin: The new ray origin guaranteed to be in empty space.
        temp_samples: List of sample values collected during backtracking.
    """
    # Step 2: Boundary Condition Check
    if leap_buffer_value == 0:
        # Do not leap; use original origin or previous position [S1, S2]
        return ray_origin, []

    # Step 3: Leap Adjustment
    # Leap one sample less than the buffer value to land on the last empty sample [S1]
    leap_samples = leap_buffer_value - 1
    tentative_origin = ray_origin + ray_direction * (leap_samples * sampling_distance)

    # Step 4: Empty Cell Verification
    # Check if the first sample point is inside a non-empty cell [S1, S2]
    is_non_empty = volume_data.is_non_empty(tentative_origin)

    if not is_non_empty:
        # Step 5a: First sample is in empty cell [S1, S2]
        return tentative_origin, []

    # Step 5b: First sample is in non-empty cell, initiate backtracking [S1, S2]
    corrected_origin = tentative_origin
    temp_samples = []
    
    # Calculate upper limit for backtracking [S1, S2]
    max_edge = max(cell_group_dims)
    m_max = int(2 * (max_edge / sampling_distance))
    
    # Step 6: Backtracking Execution
    # We backtrack until we find an empty cell.
    # We must not backtrack beyond the leap buffer value to avoid going behind image plane [S1, S2].
    backtrack_limit = min(m_max, leap_buffer_value)
    
    for i in range(1, backtrack_limit + 1):
        # Move back one sample [S1, S2]
        corrected_origin = tentative_origin - ray_direction * (i * sampling_distance)
        
        # Sample the volume [S1, S2]
        sample_value = volume_data.sample(corrected_origin)
        temp_samples.append(sample_value)
        
        # Check if we are now in an empty cell [S1, S2]
        if not volume_data.is_non_empty(corrected_origin):
            break
            
    # Step 7: Compositing is handled by the caller using temp_samples [S1, S2]
    return corrected_origin, temp_samples
```

**Edge Cases and Pitfalls**
*   **Zero Leap Buffer:** If the leap buffer value is zero, the ray must not be leaped at all [S1, S2].
*   **Image Plane Boundary:** Backtracking must not exceed the leap buffer value, otherwise the ray origin moves behind the image plane [S1, S2].
*   **Off-by-One Leap:** Leaping exactly the buffer value would land on the first non-empty sample [S1]. Leaping one less ensures the first sample checked is the last empty one, but if that is still non-empty (due to interpolation or data structure granularity), backtracking is required [S1].

## Operating characteristics
*   **Time Complexity:** Backtracking causes no additional overhead because the ray would have been sampled at those missed points anyway [S1, S2].
*   **Memory Complexity:** Requires a temporary buffer to store sample values during backtracking [S1, S2].
*   **Performance:** In practice, $M_{max}$ is found to be between 1 and 3 samples [S1, S2].
*   **Strengths:** Guarantees visual correctness by preventing missed objects [S1, S2].
*   **Limitations:** Requires checking the volume data at the tentative leap position and storing temporary samples [G].

## Background
Backtracking Space Leap Rays was introduced in the paper "PDF Light Weight Space Leaping using Ray Coherence" by Lakare et al. (2004) [S1, S2]. It was implemented in the Vikon system for perspective direct volume rendering, particularly for endoscopy applications such as Virtual Colonoscopy [S1, S2]. The method addresses the coherence-based space leaping technique's vulnerability to missing small or distant objects when leap rays jump over cell group boundaries [S1, S2].
