# Hierarchical Ray Marching

Also called: March

## Overview
Hierarchical Ray Marching is a sparse voxel traversal technique that dynamically switches between octree levels and voxel levels to optimize ray-marching performance [S1, unofficial]. It differs from sibling methods by adjusting the traversal granularity up or down based on hit/miss status, allowing rapid skipping of empty regions at coarse levels and precise sampling at fine levels [S1, unofficial].

## How it works
**Inputs:** Ray origin ($P_0$) and direction ($D$) [S1, unofficial]. Scene data containing `octantSize` (size of level-0 octants) and `octreeHighestLevel` (maximum octree depth index) [S1, unofficial]. A 3D voxel texture where each texel is a `u32` storing four 8-bit voxel values packed in a specific layout [S1, unofficial].

**Outputs:** A result structure containing hit position, normal, accumulated iterations, status (0=miss, 1=hit octree, 2=hit voxel, 3=out of bounds), voxel data, and UV coordinates [S1, unofficial].

**Data Structures:** The voxel texture packs four 8-bit values per 32-bit texel [S1, unofficial]. For a texel at grid coordinates $(x, y, z)$ where $x$ and $z$ are even, the layout is: bits 0–7 store the voxel at $(x, y, z)$, bits 8–15 store $(x+1, y, z)$, bits 16–23 store $(x, y, z+1)$, and bits 24–31 store $(x+1, y, z+1)$ [S1, unofficial]. Extraction uses a shift count derived from the least significant bits of $x$ and $z$ to mask and shift the correct 8-bit segment [S1, unofficial].

**Algorithm Steps:**
1. Initialize `level = -1` (voxel level), `totalIterations = 0`, and `rayPos = P_0` [S1, unofficial].
2. Loop for a maximum number of iterations [S1, unofficial].
3. Calculate `unitSize`: if `level == -1`, `unitSize = 1`; otherwise `unitSize = octantSize << level` [S1, unofficial].
4. Calculate `maxIterations` for the current step: if `level == octreeHighestLevel`, `maxIterations = 1024`; otherwise `maxIterations = 4` [S1, unofficial].
5. Perform traversal: if `level == -1`, call `MarchThroughVoxels(rayPos, D, maxIterations)`; if `level >= 0`, call `MarchThroughOctree(rayPos / unitSize, D, level, maxIterations)` [S1, unofficial].
6. Scale the hit position: `rayHit.position *= unitSize` [S1, unofficial].
7. Update state: `totalIterations += rayHit.iterations` and `rayPos = rayHit.position` [S1, unofficial].
8. Adjust level based on `rayHit.status`: if `status == 0` (miss) and `level < octreeHighestLevel`, increment `level` (coarser) and continue; if `status == 1` (hit octree) and `level > -1`, decrement `level` (finer) and continue [S1, unofficial].
9. If `status == 2` (hit voxel), copy position, normal, iterations, status, voxelData, and uv to the result and return [S1, unofficial]. If `status == 3` (out of bounds), copy position, status, and iterations to the result and return [S1, unofficial].

**Pseudocode:**
```python
def hierarchical_ray_marching(ray_origin, ray_dir, octant_size, highest_level, voxel_texture):
    level = -1
    total_iterations = 0
    ray_pos = ray_origin

    while True:
        unit_size = 1 if level == -1 else octant_size << level
        max_iter = 1024 if level == highest_level else 4

        if level == -1:
            hit = march_through_voxels(ray_pos, ray_dir, max_iter, voxel_texture)
        else:
            # Source does not provide octree traversal implementation. [G]
            hit = march_through_octree(ray_pos / unit_size, ray_dir, level, max_iter)

        hit.position *= unit_size
        total_iterations += hit.iterations
        ray_pos = hit.position

        if hit.status == 2:
            return {'position': hit.position, 'normal': hit.normal, 'iterations': total_iterations, 'status': 2, 'voxel_data': hit.voxel_data, 'uv': hit.uv}
        elif hit.status == 3:
            return {'position': hit.position, 'status': 3, 'iterations': total_iterations}
        elif hit.status == 0 and level < highest_level:
            level += 1
            continue
        elif hit.status == 1 and level > -1:
            level -= 1
            continue

def march_through_voxels(ray_pos, ray_dir, max_iter, voxel_texture):
    # Standard ray-box intersection for a uniform voxel grid [G].
    t_min = 0.0
    t_max = float('inf')
    for i in range(3):
        if ray_dir[i] == 0.0:
            if ray_pos[i] < 0.0 or ray_pos[i] >= 1.0:
                return {'position': ray_pos, 'status': 0, 'iterations': 0}
        else:
            t1 = (0.0 - ray_pos[i]) / ray_dir[i]
            t2 = (1.0 - ray_pos[i]) / ray_dir[i]
            t_min = max(t_min, min(t1, t2))
            t_max = min(t_max, max(t1, t2))
    if t_min > t_max or t_max < 0.0:
        return {'position': ray_pos, 'status': 0, 'iterations': 0}
    for step in range(max_iter):
        t = t_min + step * (t_max - t_min) / max_iter
        sample_pos = ray_pos + t * ray_dir
        voxel_grid_pos = [int(p) for p in sample_pos]
        x, y, z = voxel_grid_pos
        shift = (x & 1) | ((z & 1) << 1)
        mask = 255 << (shift << 3)
        texel = voxel_texture[x >> 1, y, z >> 1]
        voxel_val = (texel & mask) >> (shift << 3)
        if voxel_val != 0:
            return {'position': sample_pos, 'normal': ray_dir, 'iterations': step, 'status': 2, 'voxel_data': voxel_val, 'uv': sample_pos}
    return {'position': ray_pos + t_max * ray_dir, 'status': 0, 'iterations': max_iter}

def march_through_octree(ray_pos, ray_dir, level, max_iter):
    # Source does not provide octree traversal implementation. [G]
    return {'position': ray_pos, 'status': 0, 'iterations': 0}
```

**Parameters:** `sceneData.octantSize`: The size of octants at level 0 [S1, unofficial]. `sceneData.octreeHighestLevel`: The maximum octree level index [S1, unofficial].

**Edge Cases and Pitfalls:** Boundary checks use `any(octantPos >= vec3<u32>(dimAtLevel))` to exit early if the ray leaves the volume [S1, unofficial]. Incorrect bit-shifting when extracting packed voxel values will yield wrong sampling results [S1, unofficial]. Not given in the sources.
