# Octree Point Search for Closest Point

Also called: PinholeRayTracer::evaluate (Octree)

## Overview
This method uses an octree to efficiently find the closest point to a ray origin among all points intersected by the ray, filtering by a maximum range [S1, unofficial].

## How it works
**Inputs:**
- `viewpoint_`: An `Eigen::Affine3f` defining the camera position and orientation. The ray origin `rayo` is extracted via `viewpoint_.translation()` [S1, unofficial].
- `octree_search`: An instance of `pcl::octree::OctreePointCloudSearch<PointT>` providing spatial indexing for the input point cloud [S1, unofficial].
- `rangeMax_`: A float representing the maximum sensor range. Default is `100000.0f` [S1, unofficial].
- `hfov_`, `vfov_`: Horizontal and vertical field of view in radians [S1, unofficial].
- `hsize_`, `vsize_`: Half-width and half-height of the image grid in pixels [S1, unofficial].

**Outputs:**
- `indices`: A `pcl::PointIndices` object containing the indices of the closest valid points for each ray [S1, unofficial].

**Data Structures:**
- `rayds`: `std::vector<Eigen::Vector3f>` storing ray directions.
- `viewed`: `std::set<int>` tracking processed point indices to avoid duplicates.
- `points_idx`: `std::vector<int>` accumulating point indices from intersected voxels.
- `voxels`: Temporary storage for voxel centers intersected by the ray.

**Steps:**
1. Initialize ray origin `rayo` from `viewpoint_.translation()` [S1, unofficial].
2. Generate a vector of ray directions `rayds` by calling `castRays(rayds)` [S1, unofficial].
3. Initialize a set `viewed` to keep track of processed point indices to avoid duplicates [S1, unofficial].
4. Loop over each ray direction `rayds[i]` for `i` from `0` to `rayds.size() - 1` [S1, unofficial].
5. For the current ray, get the centers of all voxels intersected by the ray using `octree_search.getIntersectedVoxelCenters(rayo, rayds[i], voxels)` [S1, unofficial].
6. For each intersected voxel in `voxels`, retrieve the indices of points within that voxel using `octree_search.voxelSearch(voxels[h], points_idx_temp)` and append them to `points_idx` [S1, unofficial].
7. Initialize `idxmin` to `-1` and `distMin` to `1e+6` [S1, unofficial].
8. Loop over each point index `idx` in `points_idx` [S1, unofficial].
9. Get the point `pt` from the cloud using `points_idx[idx]` and convert to `Eigen::Vector3f ept` [S1, unofficial].
10. Calculate distance `dist` from `rayo` to `ept` [S1, unofficial].
11. If `dist` is less than `rangeMax_` AND less than `distMin`, update `idxmin` to `points_idx[idx]` and `distMin` to `dist` [S1, unofficial].
12. After checking all points for the ray, if `idxmin` is valid (`>=0`) and not already in `viewed`, add `idxmin` to `indices.indices` and insert it into `viewed` [S1, unofficial].

**Pseudocode:**
```python
import math

def evaluate_octree_point_search(viewpoint, octree_search, cloud, range_max, hfov, vfov, hsize, vsize):
    # Extract ray origin from viewpoint transformation [S1, unofficial]
    rayo = viewpoint.translation()
    # Generate ray directions from camera parameters [G]
    rayds = generate_ray_directions(hfov, vfov, hsize, vsize)
    viewed = set()
    indices = []

    for ray_dir in rayds:
        # Get voxel centers intersected by the ray [S1, unofficial]
        voxels = octree_search.get_intersected_voxel_centers(rayo, ray_dir)
        points_idx = []

        for voxel_center in voxels:
            # Retrieve point indices within the voxel [S1, unofficial]
            points_idx_temp = octree_search.voxel_search(voxel_center)
            points_idx.extend(points_idx_temp)

        idxmin = -1
        dist_min = 1e6

        for idx in points_idx:
            pt = cloud[idx]
            # Convert point to 3D vector [S1, unofficial]
            ept = (pt.x, pt.y, pt.z)
            # Calculate Euclidean distance from ray origin [S1, unofficial]
            dist = math.sqrt((ept[0]-rayo[0])**2 + (ept[1]-rayo[1])**2 + (ept[2]-rayo[2])**2)

            if dist < range_max and dist < dist_min:
                idxmin = idx
                dist_min = dist

        if idxmin >= 0 and idxmin not in viewed:
            indices.append(idxmin)
            viewed.add(idxmin)

    return indices

def generate_ray_directions(hfov, vfov, hsize, vsize):
    # Standard camera ray grid generation [G]
    directions = []
    for j in range(-vsize, vsize + 1):
        for i in range(-hsize, hsize + 1):
            x = math.tan(hfov * i / hsize)
            y = math.tan(vfov * j / vsize)
            z = 1.0
            norm = math.sqrt(x*x + y*y + z*z)
            directions.append((x/norm, y/norm, z/norm))
    return directions
```

**Parameters:**
- `rangeMax_`: Default `100000.0f` [S1, unofficial].
- `RES`: Default `0.02f` (box resolution) [S1, unofficial].
- `HFOV`, `VFOV`: Default `M_PI * 160.0f / 180.0f` (approx 2.79 rad) [S1, unofficial].
- `HSIZE`, `VSIZE`: Default `6` and `4` in the example code, with commented alternatives `320` and `240` [S1, unofficial].

**Edge Cases:**
- If no points are within `rangeMax_` or intersected by the ray, `idxmin` remains `-1` and no index is added [S1, unofficial].
- Duplicate points across voxels are handled by the `viewed` set, ensuring each point is only recorded once per traversal [S1, unofficial].

## Background
This method originates from the `basic_next_best_view` project by R. Monica, implemented in C++ using the Point Cloud Library (PCL) [S1, unofficial]. It is part of a pipeline for autonomous exploration where the robot simulates views to determine the next best viewpoint [S1, unofficial]. The `PinholeRayTracer` class encapsulates this logic, treating the point cloud as an occupancy map [S1, unofficial].
