# FA-based Pruning
Also called: Pruning strategy
## Overview
FA-based pruning reduces model size and rendering cost by omitting voxels with low importance scores, leveraging the observation that a small percentage of voxels contribute the majority of rendering importance [G]. It sets itself apart from intensity-only or scale-only heuristics by incorporating Feature Anisotropy (FA) cues, which yields superior reconstruction quality when combined with intensity and scale [S1, unofficial].
## How it works
**Inputs and Outputs:**
*   Input: Sparse voxel grid with associated scalar fields (intensity $I$, scale $S$) and feature tensors $\mathbf{f}$ [G].
*   Output: Pruned voxel grid with low-importance voxels removed [G].

**Data Structures:**
*   Voxel: Stores intensity $I$, scale $S$, and feature vector $\mathbf{f}$ [G].
*   Importance Score $w$: Computed per voxel [G].

**Method:**
1.  **Compute Feature Anisotropy:** For each voxel, analyze the local feature tensor to determine directional variance. The FA metric $A$ is computed from the feature covariance matrix [G].
2.  **Compute Intensity Score:** Normalize intensity $I$ to $[0, 1]$ [G].
3.  **Compute Scale Score:** Normalize scale $S$ to $[0, 1]$ [G].
4.  **Combine Scores:** Calculate the final importance weight $w$ for each voxel. Combining FA with intensity and scale yields the best reconstruction quality [S1, unofficial]. A typical combination is a weighted sum:
    $$ w = \alpha \cdot A + \beta \cdot I + \gamma \cdot S $$
    where $\alpha, \beta, \gamma$ are hyperparameters [G].
5.  **Thresholding:** Remove voxels where $w < \tau$ [G]. The threshold $\tau$ is chosen to achieve a target compression ratio or memory budget [G].
6.  **Reconstruction:** Render using the pruned set [G].

**Parameters:**
*   $\tau$: Pruning threshold. Not given in the sources.
*   $\alpha, \beta, \gamma$: Combination weights. Not given in the sources.

**Edge Cases:**
*   **Degenerate Input:** Voxels with zero variance in features (e.g., uniform background) should have low FA scores, potentially leading to aggressive pruning [G].
*   **Precision:** FA computation involves eigenvalue decomposition or similar operations; numerical stability should be considered for near-singular covariance matrices [G].

**Pseudocode:**
```python
def compute_fa_importance(voxel_grid, alpha=1.0, beta=1.0, gamma=1.0, threshold=0.1):
    """
    Computes importance scores for voxels using FA, intensity, and scale.
    Returns a mask of voxels to keep.
    """
    # [G] Compute global min/max for normalization
    all_I = [v.intensity for v in voxel_grid]
    all_S = [v.scale for v in voxel_grid]
    min_I, max_I = min(all_I), max(all_I)
    min_S, max_S = min(all_S), max(all_S)
    min_A, max_A = 0.0, 1.0

    keep_mask = []
    for voxel in voxel_grid:
        I = voxel.intensity
        S = voxel.scale
        features = voxel.features  # e.g., shape (N, D) for N samples in voxel

        # [G] Compute covariance matrix of features
        if len(features) < 2:
            A = 0.0
        else:
            D = len(features[0])
            mean_f = [sum(f[i] for f in features) / len(features) for i in range(D)]
            centered = [[f[i] - mean_f[i] for i in range(D)] for f in features]
            cov = [[sum(centered[k][i] * centered[k][j] for k in range(len(features))) / (len(features) - 1) for j in range(D)] for i in range(D)]
            # [G] Compute eigenvalues of the symmetric covariance matrix
            eigenvalues = sorted(eigenvalues_of_symmetric(cov))
            if eigenvalues[-1] == 0:
                A = 0.0
            else:
                A = (eigenvalues[-1] - eigenvalues[0]) / (eigenvalues[-1] + eigenvalues[0])

        norm_I = (I - min_I) / (max_I - min_I) if max_I != min_I else 0.0
        norm_S = (S - min_S) / (max_S - min_S) if max_S != min_S else 0.0
        norm_A = (A - min_A) / (max_A - min_A)

        w = alpha * norm_A + beta * norm_I + gamma * norm_S
        keep_mask.append(w >= threshold)
    return keep_mask
```

## Subtopics

### Object-centric Pruning
A classical tree-based pruning approach that computes a bounding volume (typically a box or sphere) around each node to prune tree branches in specific spatial regions [S2]. For SDFs with smooth CSG operators, the bounding box must be extended by the blending radius $k$. This causes boxes to grow excessively large, making them ineffective for pruning [S2].

## Operating characteristics
**Time and Memory Complexity:**
*   Memory: Significantly reduced compared to full voxel grid [S1, unofficial]. Reports size reductions from 4.54 MB to 1.35 MB for 3D DiffuseScalar and from 1.42 MB to 0.48 MB for 3D SynthWiggle using FA-based pruning [S1, unofficial].
*   Time: Rendering time is reduced due to fewer primitive hits [S1, unofficial]. Reports FPS increases from 226.76 to 329.07 for 3D SynthWiggle and from 31.79 to 88.39 for 3D DiffuseScalar [S1, unofficial].

**Measured Performance:**
*   Hardware: RTX 3090 [S1, unofficial].
*   Resolution: 2048×2048 [S1, unofficial].
*   Scene: Synthetic scenes with varying complexity [S1, unofficial].

**Strengths and Limitations:**
*   Strengths: High compression ratio with minimal quality loss when FA is included [S1, unofficial].
*   Limitations: Requires computation of FA, which adds preprocessing cost [G]. For smooth SDFs, bounding volume pruning can be ineffective due to box growth [S2].

**When to Use:**
*   Use when memory bandwidth or storage is a bottleneck, and feature anisotropy is a good indicator of visual importance [G].
*   Do not use for smooth SDFs if relying solely on bounding volume pruning [S2].

## Background
FA-based pruning is part of the broader field of sparse volume rendering and importance-driven rendering [G]. It builds on the observation that sparse representations can achieve high compression if importance is accurately estimated [Voxel Pruning](1693-voxel-pruning.md). The specific use of Feature Anisotropy for pruning is highlighted in recent work on 3D Ellipsoid-based Sparse Volume Rendering [S1, unofficial].
