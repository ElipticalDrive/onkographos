# FA-based Pruning
Also called: Pruning strategy
## Overview
FA-based pruning reduces model size and rendering cost by omitting voxels with low importance scores, leveraging the observation that a small percentage of voxels contribute the majority of rendering importance [Parent]. It sets itself apart from intensity-only or scale-only heuristics by incorporating Feature Anisotropy (FA) cues, which yields superior reconstruction quality when combined with intensity and scale [S1, unofficial].
## How it works
**Inputs and Outputs:**
*   Input: Sparse voxel grid with associated scalar fields (intensity, scale) and feature tensors (for FA computation).
*   Output: Pruned voxel grid with low-importance voxels removed.

**Data Structures:**
*   Voxel: Stores intensity $I$, scale $S$, and feature vector $\mathbf{f}$.
*   Importance Score $w$: Computed per voxel.

**Method:**
1.  **Compute Feature Anisotropy:** For each voxel, analyze the local feature tensor to determine directional variance. Let $\mathbf{f}$ be the feature vector. The FA metric $A$ is derived from the eigenvalues of the covariance matrix of $\mathbf{f}$ in the local neighborhood [S1, unofficial].
2.  **Compute Intensity Score:** Normalize intensity $I$ to $[0, 1]$.
3.  **Compute Scale Score:** Normalize scale $S$ to $[0, 1]$.
4.  **Combine Scores:** Calculate the final importance weight $w$ for each voxel. The sources indicate that combining FA with intensity and scale yields the best results [S1, unofficial]. A typical combination is a weighted sum or product:
    $$ w = \alpha \cdot A + \beta \cdot I + \gamma \cdot S $$
    where $\alpha, \beta, \gamma$ are hyperparameters. [G] Typical values for $\alpha, \beta, \gamma$ are not explicitly given in the sources; implementers should tune these based on the specific feature space normalization.
5.  **Thresholding:** Remove voxels where $w < \tau$. The threshold $\tau$ is chosen to achieve a target compression ratio or memory budget.
6.  **Reconstruction:** Render using the pruned set.

**Parameters:**
*   $\tau$: Pruning threshold. Not given in the sources.
*   $\alpha, \beta, \gamma$: Combination weights. Not given in the sources.

**Edge Cases:**
*   **Degenerate Input:** Voxels with zero variance in features (e.g., uniform background) should have low FA scores, potentially leading to aggressive pruning.
*   **Precision:** FA computation involves eigenvalue decomposition or similar operations; numerical stability should be considered for near-singular covariance matrices.

**Pseudocode:**
```python
def compute_fa_importance(voxel_grid, alpha=1.0, beta=1.0, gamma=1.0, threshold=0.1):
    """
    Computes importance scores for voxels using FA, intensity, and scale.
    Returns a mask of voxels to keep.
    """
    keep_mask = []
    for voxel in voxel_grid:
        # Extract features
        intensity = voxel.intensity
        scale = voxel.scale
        features = voxel.features  # e.g., shape (N, D) for N samples in voxel
        
        # Compute Feature Anisotropy (FA)
        # [G] Assuming features are centered. Compute covariance matrix.
        if len(features) < 2:
            fa_score = 0.0
        else:
            cov_matrix = np.cov(features, rowvar=False)
            # Eigenvalues of covariance matrix
            eigenvalues = np.linalg.eigvalsh(cov_matrix)
            # FA can be defined as the ratio of largest to smallest eigenvalue,
            # or the variance of eigenvalues. Here we use a simple anisotropy measure.
            # [G] Specific FA formula not given in sources; using standard anisotropy.
            if eigenvalues[-1] == 0:
                fa_score = 0.0
            else:
                fa_score = (eigenvalues[-1] - eigenvalues[0]) / (eigenvalues[-1] + eigenvalues[0])
        
        # Normalize scores to [0, 1]
        # [G] Global min/max for normalization not provided; assume per-voxel or global stats are precomputed.
        norm_intensity = normalize(intensity)
        norm_scale = normalize(scale)
        norm_fa = normalize(fa_score)
        
        # Combine scores
        importance = alpha * norm_fa + beta * norm_intensity + gamma * norm_scale
        
        # Threshold
        if importance >= threshold:
            keep_mask.append(True)
        else:
            keep_mask.append(False)
            
    return keep_mask
```
## Subtopics

### Object-centric Pruning
A classical tree-based pruning approach that computes a bounding volume (typically a box or sphere) around each node to prune tree branches in specific spatial regions [S2]. For SDFs with smooth CSG operators, the bounding box must be extended by the blending radius $k$. This causes boxes to grow excessively large, making them ineffective for pruning [S2].

## Operating characteristics
**Time and Memory Complexity:**
*   Memory: Significantly reduced compared to full voxel grid. [S1, unofficial] reports size reductions from ~4.54 MB to ~1.35 MB for 3D DiffuseScalar and from ~1.42 MB to ~0.48 MB for 3D SynthWiggle using FA-based pruning.
*   Time: Rendering time is reduced due to fewer primitive hits. [S1, unofficial] reports FPS increases from 226.76 to 329.07 for 3D SynthWiggle and from 31.79 to 88.39 for 3D DiffuseScalar.

**Measured Performance:**
*   Hardware: RTX 3090 [S1, unofficial].
*   Resolution: 1920x1080 [S2], 2048x2048 [S2].
*   Scene: Synthetic scenes with varying complexity.

**Strengths and Limitations:**
*   Strengths: High compression ratio with minimal quality loss when FA is included [S1, unofficial].
*   Limitations: Requires computation of FA, which adds preprocessing cost. [S2] notes that for smooth SDFs, bounding volume pruning can be ineffective due to box growth.

**When to Use:**
*   Use when memory bandwidth or storage is a bottleneck, and feature anisotropy is a good indicator of visual importance.
*   Do not use for smooth SDFs if relying solely on bounding volume pruning [S2].

## Background
FA-based pruning is part of the broader field of sparse volume rendering and importance-driven rendering. It builds on the observation that sparse representations can achieve high compression if importance is accurately estimated [Parent]. The specific use of Feature Anisotropy for pruning is highlighted in recent work on 3D Ellipsoid-based Sparse Volume Rendering [S1, unofficial].
