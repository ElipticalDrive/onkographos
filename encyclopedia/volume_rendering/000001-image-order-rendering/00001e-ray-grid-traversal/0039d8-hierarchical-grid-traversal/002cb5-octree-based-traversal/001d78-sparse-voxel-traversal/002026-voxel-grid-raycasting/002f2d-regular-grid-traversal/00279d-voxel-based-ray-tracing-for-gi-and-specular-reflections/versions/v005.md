# Voxel-based Ray Tracing for GI and Specular Reflections

Also called: ApplyVoxelRT, Voxel RT, VoxelDDA, VoxelReflectionFallback

## Overview
A voxel-based ray tracing system that uses 3-D Digital Differential Analyzer (3D-DDA) traversal through a 128³ block-occupancy grid to provide global illumination (GI) and specular reflection fallbacks [S1, unofficial]. It serves as a drop-in replacement for Screen-Space Ray Tracing (SSRT) for GI and a fallback for Screen-Space Reflections (SSR) when coverage is incomplete [S1, unofficial]. Unlike [Regular Grid Traversal](5939-regular-grid-traversal.md) which typically renders volumetric density, this method samples a pre-computed Light Propagation Volume (LPV) buffer at ray hit positions to compute indirect lighting and reflection color [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Ray origin ($O$), ray direction ($D$), current surface position, LPV texture (indirect lighting data), voxel mask grid (`imgVoxelMask`) [S1, unofficial].
*   **Output:** Indirect lighting color (for GI) or reflected color (for specular fallback) [S1, unofficial].

**Data Structures:**
*   **Voxel Grid:** A 128³ block-occupancy grid stored in `imgVoxelMask`, populated each frame in the shadow pass [S1, unofficial].
*   **LPV Buffer:** Light Propagation Volumes data, accessed via `GL_ARB_shader_image_load_store` [S1, unofficial].

**Parameters:**
*   `VOXEL_GI_SAMPLES`: Number of cosine-weighted hemisphere rays for GI sampling. Default: 4 [S1, unofficial].
*   `VOXEL_GI_STEPS`: Configurable number of steps in voxel GI ray traversal [S1, unofficial].
*   `VOXEL_REFL_STEPS`: Configurable number of steps in voxel reflection ray traversal [S1, unofficial].
*   `VOXEL_RT_REFLECTIONS`: Feature flag to enable specular reflection fallback. Commented out by default [S1, unofficial].
*   `VOXEL_GI`: Indirect effect mode identifier, value 6 [S1, unofficial].
*   World coordinates use feet-relative scaling consistent with the camera system [S1, unofficial].

**Algorithm Steps:**
1.  **VoxelDDA Traversal:** Perform 3-D DDA traversal over the voxel grid. Handle grid bounds and sign-safe boundary distances. Include ray bias to avoid self-intersection and handle near-parallel rays gracefully. Return the face-centre position and the axis-aligned normal of the hit voxel [S1, unofficial].
2.  **SampleVoxelLighting:** Read the LPV data half a block in front of the hit face. This obtains the indirect color at the surface from propagated light [S1, unofficial].
3.  **ApplyVoxelRT (GI Mode):** Trace `VOXEL_GI_SAMPLES` cosine-weighted hemisphere rays from the surface. For each ray, use `VoxelDDA` to find a hit. If a hit occurs, use `SampleVoxelLighting` to get the LPV color. Blend the sky contribution with the LPV color bounce at the hit surfaces [S1, unofficial].
4.  **VoxelReflectionFallback (Specular Mode):** Perform a single specular DDA ray trace. Activated only when screen-space reflection misses (indicated by `environmentReflection.a < 1`). Scale the voxel lighting to match typical sky-reflection brightness ranges to avoid visual mismatch. Fill in the LPV-sampled voxel color [S1, unofficial].

**Formulas:**
*   Voxel size: $s = 1 / \text{VOXEL\_GRID\_SIZE}$ [G]
*   Initial cell: $i_x = \lfloor O_x / s \rfloor$, $i_y = \lfloor O_y / s \rfloor$, $i_z = \lfloor O_z / s \rfloor$ [G]
*   Step direction: $step_x = \text{sign}(D_x)$, $step_y = \text{sign}(D_y)$, $step_z = \text{sign}(D_z)$ [G]
*   Distance to next boundary: $tMax_x = ((i_x + \max(step_x, 0)) \cdot s - O_x) / D_x$ (similarly for $y, z$) [G]
*   Step increment: $tDelta_x = s / |D_x|$ (similarly for $y, z$) [G]
*   Hit position: $P = O + D \cdot \min(tMax_x, tMax_y, tMax_z)$ [G]
*   Hit normal: $N = (-step_x, -step_y, -step_z)$ along the axis that produced the minimum $tMax$ [G]

**Pseudocode:**
```python
import math
import random

class Vec3:
    def __init__(self, x, y, z):
        self.x, self.y, self.z = x, y, z
    def __add__(self, o): return Vec3(self.x+o.x, self.y+o.y, self.z+o.z)
    def __sub__(self, o): return Vec3(self.x-o.x, self.y-o.y, self.z-o.z)
    def __mul__(self, s): return Vec3(self.x*s, self.y*s, self.z*s)
    def __truediv__(self, s): return Vec3(self.x/s, self.y/s, self.z/s)
    def __neg__(self): return Vec3(-self.x, -self.y, -self.z)
    def dot(self, o): return self.x*o.x + self.y*o.y + self.z*o.z
    def length(self): return math.sqrt(self.dot(self))
    def normalize(self):
        l = self.length()
        return self/l if l > 1e-8 else Vec3(0,0,0)

def is_voxel_occupied(ix, iy, iz, grid):
    """Checks occupancy in the 128³ imgVoxelMask grid [G]."""
    return grid[ix][iy][iz] > 0

def cosine_weighted_hemisphere_sample(normal):
    """Generates a random direction on the hemisphere oriented by normal [G]."""
    u = random.random()
    v = random.random()
    phi = 2.0 * math.pi * u
    cos_theta = math.sqrt(v)
    sin_theta = math.sqrt(1.0 - v)
    # Construct local basis aligned with normal [G]
    up = Vec3(0, 1, 0) if abs(normal.dot(Vec3(0,1,0))) < 0.999 else Vec3(1,0,0)
    tangent = Vec3(0,0,0).normalize() # Placeholder for cross-product basis setup [G]
    return Vec3(sin_theta * math.cos(phi), sin_theta * math.sin(phi), cos_theta).normalize()

def texture_3d(tex, uv):
    """Standard 3D texture fetch [G]."""
    return tex.sample(uv)

def VoxelDDA(origin, direction, max_steps, grid, grid_size=128, voxel_size=1.0/128.0):
    ix = int(math.floor(origin.x / voxel_size))
    iy = int(math.floor(origin.y / voxel_size))
    iz = int(math.floor(origin.z / voxel_size))

    if not (0 <= ix < grid_size and 0 <= iy < grid_size and 0 <= iz < grid_size):
        return None, None

    dx, dy, dz = direction.x, direction.y, direction.z
    tDeltaX = voxel_size / abs(dx) if dx != 0 else float('inf')
    tDeltaY = voxel_size / abs(dy) if dy != 0 else float('inf')
    tDeltaZ = voxel_size / abs(dz) if dz != 0 else float('inf')

    stepX = 1 if dx > 0 else (-1 if dx < 0 else 0)
    stepY = 1 if dy > 0 else (-1 if dy < 0 else 0)
    stepZ = 1 if dz > 0 else (-1 if dz < 0 else 0)

    tMaxX = ((ix + max(stepX, 0)) * voxel_size - origin.x) / dx if dx != 0 else float('inf')
    tMaxY = ((iy + max(stepY, 0)) * voxel_size - origin.y) / dy if dy != 0 else float('inf')
    tMaxZ = ((iz + max(stepZ, 0)) * voxel_size - origin.z) / dz if dz != 0 else float('inf')

    # Ray bias to avoid self-intersection [S1, unofficial]
    tMaxX += 1e-4
    tMaxY += 1e-4
    tMaxZ += 1e-4

    for _ in range(max_steps):
        if is_voxel_occupied(ix, iy, iz, grid):
            tHit = min(tMaxX, tMaxY, tMaxZ)
            hit_pos = origin + direction * tHit
            if tHit == tMaxX:
                hit_normal = Vec3(-stepX, 0, 0)
            elif tHit == tMaxY:
                hit_normal = Vec3(0, -stepY, 0)
            else:
                hit_normal = Vec3(0, 0, -stepZ)
            return hit_pos, hit_normal

        if tMaxX < tMaxY and tMaxX < tMaxZ:
            ix += stepX
            tMaxX += tDeltaX
        elif tMaxY < tMaxZ:
            iy += stepY
            tMaxY += tDeltaY
        else:
            iz += stepZ
            tMaxZ += tDeltaZ

        if not (0 <= ix < grid_size and 0 <= iy < grid_size and 0 <= iz < grid_size):
            break

    return None, None

def SampleVoxelLighting(hit_position, hit_normal, LPV_texture, grid_size=128, voxel_size=1.0/128.0):
    sample_pos = hit_position + hit_normal * (voxel_size * 0.5)
    return texture_3d(LPV_texture, sample_pos).rgb

def ApplyVoxelRT(surface_position, surface_normal, sky_color, grid, LPV_texture):
    total_indirect = Vec3(0.0, 0.0, 0.0)
    for _ in range(4): # VOXEL_GI_SAMPLES default [S1, unofficial]
        sample_dir = cosine_weighted_hemisphere_sample(surface_normal)
        ray_origin = surface_position + surface_normal * 1e-4
        hit_pos, hit_normal = VoxelDDA(ray_origin, sample_dir, 32, grid) # VOXEL_GI_STEPS [S1, unofficial]
        if hit_pos is not None:
            total_indirect += SampleVoxelLighting(hit_pos, hit_normal, LPV_texture)
        else:
            total_indirect += sky_color
    return total_indirect / 4.0

def VoxelReflectionFallback(reflection_direction, surface_position, brightness_scale_factor, grid, LPV_texture):
    ray_origin = surface_position + reflection_direction * 1e-4
    hit_pos, hit_normal = VoxelDDA(ray_origin, reflection_direction, 32, grid) # VOXEL_REFL_STEPS [S1, unofficial]
    if hit_pos is not None:
        lpv_color = SampleVoxelLighting(hit_pos, hit_normal, LPV_texture)
        return lpv_color * brightness_scale_factor
    return Vec3(0.0, 0.0, 0.0)
```

**Edge Cases and Pitfalls:**
*   **Hardware Support:** Requires LPV and `GL_ARB_shader_image_load_store` support. Gracefully degrades to SSRT if these are not met [S1, unofficial].
*   **Precision:** Division-by-zero/NaN sources in TAA resolve pass can produce black pixel artifacts, especially on hardware with aggressive FP16 FTZ behavior (e.g., NVIDIA RTX 5000 series). Epsilon guards are required in `invTonemap()` and other functions [S1, unofficial].
*   **Self-Intersection:** Ray bias is necessary to avoid self-intersection artifacts [S1, unofficial].
*   **Near-Parallel Rays:** DDA traversal must handle near-parallel rays gracefully to avoid infinite loops or incorrect hits [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Proportional to `VOXEL_GI_SAMPLES` * `VOXEL_GI_STEPS` for GI, and `VOXEL_REFL_STEPS` for reflections [S1, unofficial].
*   **Memory Complexity:** Depends on the LPV buffer size and the voxel mask grid (128³). No additional large buffers are needed as it reuses existing shadow pass data [S1, unofficial].
*   **Strengths:** Provides global illumination and specular reflections in scenes where screen-space methods fail (e.g., occluded areas, off-screen objects). Drop-in replacement for SSRT [S1, unofficial].
*   **Limitations:** Relies on the accuracy of the LPV propagation. Requires specific hardware features (`GL_ARB_shader_image_load_store`) [S1, unofficial].
*   **When to Use:** When screen-space GI/Reflections are insufficient or unavailable. Useful for Minecraft-style voxel worlds where LPV is already computed [S1, unofficial].
*   **When Not to Use:** On hardware lacking required OpenGL extensions. If LPV is not enabled or populated [S1, unofficial].
