# DirectVoxGO Volume Rendering

Also called: DirectVoxGO, Voxel Grid Neural Rendering

## Overview
DirectVoxGO is a volume rendering method that accelerates neural radiance field (NeRF) training and inference by sampling points directly on a structured voxel grid rather than uniformly along rays [S1, unofficial]. It solves the problem of inefficient ray marching in sparse scenes by using a mask cache to skip free space and a direct lookup of density and color features from the voxel grid [S1, unofficial]. It sets itself apart from standard NeRF by replacing uniform sampling with grid-based point selection and from other sparse voxel methods by using a dense voxel grid with a binary mask cache for acceleration [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Ray origins `rays_o` ([N, 3]), ray directions `rays_d` ([N, 3]), view directions `viewdirs` ([N, 3]), near/far distances, and rendering parameters.
*   **Outputs:** Rendered RGB images `rgb_marched` ([N, 3]), accumulated transmittance `alphainv_last` ([N]), and intermediate weights `weights` ([M]).

**Data Structures:**
*   **Voxel Grid:** A 3D tensor storing density and color features. The grid is defined by `xyz_min` and `xyz_max` bounding boxes and a resolution `num_voxels`.
*   **Mask Cache:** A binary tensor indicating which voxels contain geometry (true) or are free space (false).
*   **Ray Points:** `ray_pts` ([M, 3]) stores the 3D coordinates of sampled points. `ray_id` ([M]) maps each point to its originating ray. `step_id` ([M]) maps each point to its step index along the ray.

**Parameters:**
*   `stepsize`: Number of voxels per sample step. Typical value: 1.0 [S1, unofficial].
*   `fast_color_thres`: Threshold for filtering points based on alpha or weight values. If > 0, enables optimization. Typical value: 0.005 [S1, unofficial].
*   `voxel_size_ratio`: Ratio used to compute the interval for density-to-alpha conversion. Typical value: 1.0 [S1, unofficial].
*   `rgbnet_direct`: Boolean flag determining if the RGB network outputs direct RGB or residual features.

**Steps:**

1.  **Ray Setup:** Compute ray origins and directions from camera parameters. If NDC (Normalized Device Coordinates) is enabled, transform rays to NDC space [S1, unofficial].
    *   Ray direction computation (for `inverse_y=False`, `flip_y=False`, `mode='center'`):
        $$ \text{dirs} = \left[ \frac{i - K_{0,2}}{K_{0,0}}, \frac{j - K_{1,2}}{K_{1,1}}, 1 \right] $$
    *   NDC ray transformation:
        $$ o_0 = -\frac{1}{W/(2 \cdot \text{focal})} \frac{o_x}{o_z}, \quad d_0 = -\frac{1}{W/(2 \cdot \text{focal})} \left(\frac{d_x}{d_z} - \frac{o_x}{o_z}\right) $$

2.  **Sample Points:** Calculate step distance `stepdist = stepsize * voxel_size`. Sample points along rays within the bounding box `[xyz_min, xyz_max]`. Filter points outside the bounding box [S1, unofficial].
    *   Input: `rays_o`, `rays_d`, `near`, `far`, `stepdist`.
    *   Output: `ray_pts`, `ray_id`, `step_id`, `mask_outbbox`.

3.  **Free Space Culling:** Query the mask cache for the sampled points. Filter out points where the mask is false (free space) [S1, unofficial].

4.  **Density Query:** Query the voxel grid for density values at the remaining points [S1, unofficial].

5.  **Alpha Conversion:** Convert density to alpha using the `Raw2Alpha` function:
    $$ \alpha = 1 - (1 + \exp(\text{density} + \text{shift}))^{-\text{interval}} $$
    where `interval = stepsize * voxel_size_ratio` [S1, unofficial].

6.  **First Color Threshold:** If `fast_color_thres > 0`, filter points where `alpha > fast_color_thres` [S1, unofficial].

7.  **Weight Computation:** Compute accumulated transmittance and weights using `Alphas2Weights.apply(alpha, ray_id, N)`. This function performs a segmented sum over rays to compute weights and the final transmittance `alphainv_last` [S1, unofficial].

8.  **Second Color Threshold:** If `fast_color_thres > 0`, filter points where `weights > fast_color_thres` [S1, unofficial].

9.  **Color Query:** Query the voxel grid for color features `k0` at the remaining points [S1, unofficial].

10. **RGB Computation:**
    *   If `rgbnet is None`: `rgb = sigmoid(k0)` [S1, unofficial].
    *   If `rgbnet is not None`:
        *   If `rgbnet_direct`: `rgb_feat = k0`.
        *   Else: `k0_view = k0[:, 3:]`, `k0_diffuse = k0[:, :3]`.
        *   Compute view direction embeddings: `viewdirs_emb = (viewdirs.unsqueeze(-1) * viewfreq).flatten(-2)`, then concatenate with sin/cos of viewdirs.
        *   `rgb_feat = cat([k0_view, viewdirs_emb], -1)`.
        *   `rgb_logit = rgbnet(rgb_feat)`.
        *   If `rgbnet_direct`: `rgb = sigmoid(rgb_logit)`.
        *   Else: `rgb = sigmoid(rgb_logit + k0_diffuse)` [S1, unofficial].

11. **Accumulation:** Accumulate RGB using segmented sum:
    $$ \text{rgb\_marched} = \sum_{i \in \text{ray}} \text{weights}_i \cdot \text{rgb}_i $$
    Add background color: `rgb_marched += alphainv_last * bg` [S1, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn.functional as F

def render_directvoxgo(rays_o, rays_d, viewdirs, model, render_kwargs):
    """
    Render using DirectVoxGO method.
    
    Args:
        rays_o: [N, 3] tensor of ray origins.
        rays_d: [N, 3] tensor of ray directions.
        viewdirs: [N, 3] tensor of view directions.
        model: DirectVoxGO model instance.
        render_kwargs: Dictionary containing 'stepsize', 'bg', 'near', 'far', etc.
        
    Returns:
        rgb_marched: [N, 3] tensor of rendered RGB.
        alphainv_last: [N] tensor of accumulated transmittance.
    """
    # 1. Sample points on rays
    stepdist = render_kwargs['stepsize'] * model.voxel_size
    # Assuming render_utils_cuda.sample_pts_on_rays is implemented as per source
    ray_pts, mask_outbbox, ray_id, step_id, N_steps, t_min, t_max = render_utils_cuda.sample_pts_on_rays(
        rays_o, rays_d, model.xyz_min, model.xyz_max, 
        render_kwargs['near'], render_kwargs['far'], stepdist
    )
    
    # Filter points outside bounding box
    mask_inbbox = ~mask_outbbox
    ray_pts = ray_pts[mask_inbbox]
    ray_id = ray_id[mask_inbbox]
    step_id = step_id[mask_inbbox]
    
    # 2. Free space culling
    if model.mask_cache is not None:
        mask = model.mask_cache(ray_pts)
        ray_pts = ray_pts[mask]
        ray_id = ray_id[mask]
        step_id = step_id[mask]
        
    # 3. Density query
    density = model.density(ray_pts)
    
    # 4. Alpha conversion
    interval = render_kwargs['stepsize'] * model.voxel_size_ratio
    alpha = 1 - (1 + torch.exp(density + model.shift))**(-interval)
    
    # 5. First color threshold
    if model.fast_color_thres > 0:
        mask = (alpha > model.fast_color_thres)
        ray_pts = ray_pts[mask]
        ray_id = ray_id[mask]
        step_id = step_id[mask]
        density = density[mask]
        alpha = alpha[mask]
        
    # 6. Weight computation
    # Assuming Alphas2Weights.apply is implemented as per source
    weights, alphainv_last = Alphas2Weights.apply(alpha, ray_id, len(rays_o))
    
    # 7. Second color threshold
    if model.fast_color_thres > 0:
        mask = (weights > model.fast_color_thres)
        weights = weights[mask]
        alpha = alpha[mask]
        ray_pts = ray_pts[mask]
        ray_id = ray_id[mask]
        step_id = step_id[mask]
        
    # 8. Color query
    k0 = model.k0(ray_pts)
    
    # 9. RGB computation
    if model.rgbnet is None:
        rgb = torch.sigmoid(k0)
    else:
        if model.rgbnet_direct:
            k0_view = k0
        else:
            k0_view = k0[:, 3:]
            k0_diffuse = k0[:, :3]
            
        viewdirs_emb = (viewdirs.unsqueeze(-1) * model.viewfreq).flatten(-2)
        viewdirs_emb = torch.cat([viewdirs, viewdirs_emb.sin(), viewdirs_emb.cos()], -1)
        viewdirs_emb = viewdirs_emb.flatten(0, -2)[ray_id]
        
        rgb_feat = torch.cat([k0_view, viewdirs_emb], -1)
        rgb_logit = model.rgbnet(rgb_feat)
        
        if model.rgbnet_direct:
            rgb = torch.sigmoid(rgb_logit)
        else:
            rgb = torch.sigmoid(rgb_logit + k0_diffuse)
            
    # 10. Accumulation
    # Assuming segment_coo is implemented as per source
    rgb_marched = segment_coo(
        src=(weights.unsqueeze(-1) * rgb), 
        index=ray_id, 
        out=torch.zeros([len(rays_o), 3]), 
        reduce='sum'
    )
    
    # Add background
    rgb_marched += (alphainv_last.unsqueeze(-1) * render_kwargs['bg'])
    
    return rgb_marched, alphainv_last

class Alphas2Weights(torch.autograd.Function):
    @staticmethod
    def forward(ctx, alpha, ray_id, N):
        # Assuming render_utils_cuda.alpha2weight is implemented as per source
        weights, T, alphainv_last, i_start, i_end = render_utils_cuda.alpha2weight(alpha, ray_id, N)
        if alpha.requires_grad:
            ctx.save_for_backward(alpha, weights, T, alphainv_last, i_start, i_end)
            ctx.n_rays = N
        return weights, alphainv_last

    @staticmethod
    @torch.autograd.function.once_differentiable
    def backward(ctx, grad_weights, grad_last):
        alpha, weights, T, alphainv_last, i_start, i_end = ctx.saved_tensors
        # Assuming render_utils_cuda.alpha2weight_backward is implemented as per source
        grad = render_utils_cuda.alpha2weight_backward(
            alpha, weights, T, alphainv_last, i_start, i_end, 
            ctx.n_rays, grad_weights, grad_last
        )
        return grad, None, None
```

**Edge Cases and Pitfalls:**
*   **Far Distance:** The `far` distance can be too small, causing rays to stop prematurely when hitting the scene bounding box. The code sets `far = 1e9` to prevent this [S1, unofficial].
*   **View Directions:** Ray directions must be normalized for view-dependent color computation. The code computes `viewdirs = rays_d / rays_d.norm(dim=-1, keepdim=True)` [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the number of sampled points and the efficiency of the mask cache. The mask cache significantly reduces the number of points processed in free space.
*   **Memory Complexity:** Proportional to the voxel grid size and the number of rays. The mask cache adds a small memory overhead.
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Scales with the resolution of the voxel grid and the number of rays.
*   **Strengths:** Efficient sampling in sparse scenes due to free space culling. Direct lookup of features from the voxel grid.
*   **Limitations:** Requires a predefined bounding box. Performance may degrade in very dense scenes if the mask cache is less effective.
*   **When to Use:** Suitable for scenes with significant free space and where efficient sampling is critical.
*   **When Not to Use:** Not suitable for scenes without a clear bounding box or where high-frequency details require very fine voxel grids.

## Background
DirectVoxGO was introduced by the authors of the DirectVoxGO repository [S1, unofficial]. It builds on the idea of using voxel grids for neural rendering, aiming to improve efficiency over standard NeRF by leveraging spatial acceleration structures.
