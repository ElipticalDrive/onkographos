# Sparse Shadow Volume Raycast

Also called: raycastShadowVolumeSparse

## Overview
A hierarchical raycasting algorithm that traverses a sparse shadow volume texture to find the first intersection with a shadow-casting volume [S1, unofficial]. It dynamically adjusts its traversal step size and level of detail (LOD) based on occupancy bits, allowing it to skip empty space efficiently compared to fixed-step hierarchical variants [S1, unofficial]. It differs from siblings such as [Voxel-Cell Duality Mapping](2240-voxel-cell-duality-mapping.md), [Spherical Volume Ray Walking](3865-spherical-volume-ray-walking.md), [Plane Marching](3959-plane-marching.md), [RLE4 Ray Tracing](5228-rle4-ray-tracing.md), [Regular Grid Traversal](5939-regular-grid-traversal.md), [Voxel Raytracer](6403-voxel-raytracer.md), and [DirectVoxGO Volume Rendering](6412-directvoxgo-volume-rendering.md) by using a multi-level occupancy-bit search that refines or coarsens traversal granularity on the fly [S1, unofficial].

## How it works
**Inputs:**
*   `origin`: Ray origin in world space.
*   `dir`: Ray direction (normalized).
*   `dist`: Maximum ray distance.
*   `uVolOffset`: Offset vector for the shadow volume texture coordinates.
*   `uVolTexelSize`: Physical size of a texel in the shadow volume.
*   `uVolResolution`: Resolution of the shadow volume texture (vec3).
*   `uShadowVolume`: The sparse shadow volume texture.

**Outputs:**
*   `d`: Distance to the first occupied voxel. Returns `dist` if no intersection is found within the limit [S1, unofficial].

**Data Structures:**
*   `uShadowVolume`: A texture where each texel contains occupancy information. The algorithm samples this texture at different LODs. The exact internal structure is abstracted by the texture fetch, but the algorithm relies on the `x` component of the sampled value being non-zero to indicate occupancy [S1, unofficial].

**Steps:**
1.  **Initialization:** Translate `origin` by `uVolOffset` [S1, unofficial]. Compute `step` as `uVolTexelSize` [S1, unofficial]. Compute `stepDir` as `dir * invShadowVolumeResolution` [S1, unofficial]. Compute `pos` as `origin * invVolumeTexelSize * invShadowVolumeResolution` [S1, unofficial]. Halve `stepDir` and `step` by multiplying by 0.5 [S1, unofficial]. Initialize `lod` to -1 and `d` to 0.0 [S1, unofficial].
2.  **Traversal Loop:** While `d < dist`: Sample `c = textureLod(uShadowVolume, pos, lod).x` [S1, unofficial].
    *   **If `lod == -1` (Coarse Search):** If `c != 0`, calculate bit index from fractional parts of `pos`: `bit = (fract(pos.x * uVolResolution.x) > 0.5 ? 1 : 0) + (fract(pos.y * uVolResolution.y) > 0.5 ? 2 : 0) + (fract(pos.z * uVolResolution.z) > 0.5 ? 4 : 0)` [S1, unofficial]. Create mask `mask = 1 << bit`. If `(mask & c) != 0`, return `d` [S1, unofficial]. Else, advance `pos += stepDir` and `d += step` [S1, unofficial]. If `c == 0`, increment `lod`, double `stepDir` and `step`, and advance `pos += stepDir` and `d += step` [S1, unofficial].
    *   **If `lod != -1` (Refinement):** If `c != 0`, halve `stepDir` and `step`, decrement `lod`, and backtrack `pos -= stepDir` and `d -= step` [S1, unofficial]. Else (`c == 0`), if `lod < 2`, sample `c = textureLod(uShadowVolume, pos, lod + 1).x` [S1, unofficial]. If that sample is `0`, increment `lod`, double `stepDir` and `step`, and advance `pos += stepDir` and `d += step` [S1, unofficial].

**Formulas:**
*   `invShadowVolumeResolution = 1.0 / uVolResolution`
*   `invVolumeTexelSize = 1.0 / uVolTexelSize`
*   `stepDir = dir * invShadowVolumeResolution`
*   `pos = origin * invVolumeTexelSize * invShadowVolumeResolution`
*   `bit = (fract(pos.x * uVolResolution.x) > 0.5 ? 1 : 0) + (fract(pos.y * uVolResolution.y) > 0.5 ? 2 : 0) + (fract(pos.z * uVolResolution.z) > 0.5 ? 4 : 0)`

**Parameters:**
*   `uVolResolution`: vec3, resolution of the shadow volume texture [S1, unofficial].
*   `uVolTexelSize`: float, physical size of a texel [S1, unofficial].

**Edge Cases and Pitfalls:**
*   The algorithm assumes a maximum LOD of 2 [S1, unofficial]. If `lod` is already 2 and the sample is empty, it does not attempt to go deeper, relying on the coarse search or returning the distance limit [S1, unofficial].
*   Precision issues may arise when calculating bit indices from fractional parts of `pos` if `pos` values are very large or small [G].
*   The algorithm assumes the shadow volume texture supports `textureLod` with varying LOD levels [S1, unofficial].

```python
import math

def fract(x):
    return x - math.floor(x)

def textureLod(tex, pos, lod):
    # Standard GPU texture fetch with explicit LOD bias
    return tex.sample(pos, lod)

def raycast_shadow_volume_sparse(origin, dir, dist, uVolOffset, uVolTexelSize, uVolResolution, uShadowVolume):
    invShadowVolumeResolution = 1.0 / uVolResolution
    invVolumeTexelSize = 1.0 / uVolTexelSize
    
    origin = origin + uVolOffset
    step = uVolTexelSize
    stepDir = dir * invShadowVolumeResolution
    pos = origin * invVolumeTexelSize * invShadowVolumeResolution
    stepDir = stepDir * 0.5
    step = step * 0.5
    lod = -1
    d = 0.0

    while d < dist:
        c = textureLod(uShadowVolume, pos, lod).x
        if lod == -1:
            if c != 0:
                bit = (1 if fract(pos.x * uVolResolution.x) > 0.5 else 0) + \
                      (2 if fract(pos.y * uVolResolution.y) > 0.5 else 0) + \
                      (4 if fract(pos.z * uVolResolution.z) > 0.5 else 0)
                mask = 1 << bit
                if (mask & c) != 0:
                    return d
                else:
                    pos = pos + stepDir
                    d = d + step
            else:
                lod = lod + 1
                stepDir = stepDir * 2.0
                step = step * 2.0
                pos = pos + stepDir
                d = d + step
        else:
            if c != 0:
                stepDir = stepDir * 0.5
                step = step * 0.5
                lod = lod - 1
                pos = pos - stepDir
                d = d - step
            else:
                if lod < 2:
                    c = textureLod(uShadowVolume, pos, lod + 1).x
                    if c == 0:
                        lod = lod + 1
                        stepDir = stepDir * 2.0
                        step = step * 2.0
                        pos = pos + stepDir
                        d = d + step
                else:
                    # If lod is already 2 and the sample is empty, it does not attempt to go deeper, relying on the coarse search or returning the distance limit [S1, unofficial]
                    pos = pos + stepDir
                    d = d + step
    return dist
```

## Subtopics

### Hierarchical Shadow Volume Raycast (Non-Sparse)
A hierarchical raycasting algorithm for shadow volumes that uses fixed step sizes and LODs, traversing from base distance to further distances using specific LOD levels (0, 1, 2) [S1, unofficial]. It differs from the sparse variant by not dynamically adjusting step sizes based on occupancy bits, instead using predefined distance thresholds (`baseDistance`) to switch between LOD levels [S1, unofficial]. It is chosen when the shadow volume is not sparse or when a simpler, fixed-step traversal is preferred [S1, unofficial].

### Directional Shadow Raycast
Performs a directional shadow raycast against the sparse shadow volume, including screen-space blocking check and position jittering [S1, unofficial]. It first checks if the ray is blocked in screen space; if so, it returns 0.0 [S1, unofficial]. Otherwise, it jitters the position and calls `raycastShadowVolumeSparse` with the jittered position and direction [S1, unofficial]. It is used to reduce aliasing and improve shadow quality [S1, unofficial].
