# Hierarchical DDA with Super-brick Skipping

Also called: Exact shadow trace with super-brick skipping and occupied-box early-out

## Overview
This method accelerates ray tracing through sparse volumetric data by introducing a two-level occupancy hierarchy (super-bricks and bricks) to skip large empty regions, while maintaining pixel-identical output to the fine per-voxel DDA [S1, unofficial]. It solves the performance bottleneck of traversing empty space by verifying emptiness at a coarser granularity and using an axis-aligned bounding box (AABB) for early termination, ensuring exactness by only skipping verified empty blocks and terminating only when the ray definitively passes the occupied volume [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Ray origin $\mathbf{o}$, ray direction $\mathbf{d}$, volume header, brick masks, super-brick masks, and voxel data [S1, unofficial].
- Output: Boolean indicating if the ray hits any occupied voxel [S1, unofficial].

**Data Structures:**
The buffer layout consists of a header, bricks, brick mask, and super mask [S1, unofficial].
- **Header:** 20 words (`HEADER_WORDS 20`) [S1, unofficial].
- Words 12-14: Occupied box minimum coordinates ($a_{min}$) [S1, unofficial].
- Words 16-18: Occupied box maximum coordinates ($a_{max}$) [S1, unofficial].
- Word 7: Super-mask offset [S1, unofficial].
- **Super-bricks:** A grid of $4^3$ bricks, containing $32^3$ cells total [S1, unofficial]. Each super-brick has a nonempty bitset appended after the brick mask [S1, unofficial].
- **Bricks:** The intermediate level between super-bricks and voxels [S1, unofficial].

**Algorithm Steps:**
1. Initialize DDA state for the ray $\mathbf{o}, \mathbf{d}$ within the volume bounds [G].
2. Loop while the ray is within the volume bounds and iteration count $< 768$ [S1, unofficial].
3. Check super-brick occupancy via its nonempty bitset [S1, unofficial]. If empty, call `skip_box(32)` to advance the ray state by 32 units and continue to the next iteration [S1, unofficial].
4. If the super-brick is occupied, check the current brick's occupancy mask [S1, unofficial]. If the brick is empty, call `skip_box(8)` to advance the ray state by 8 units and continue [S1, unofficial].
5. If the brick is occupied, perform the fine per-voxel DDA traversal [S1, unofficial].
6. Early-out: if the ray is monotonic per axis and the current cell index has passed the occupied box boundary on an axis it is moving toward ($step \ge 0 \land cell > a_{max}$ or $step \le 0 \land cell < a_{min}$), return false immediately [S1, unofficial].
7. The iteration cap remains 768; skipping reduces iterations per ray but does not change the cap [S1, unofficial].

**Pseudocode:**
```python
def trace_shadow(o, d, header, brick_masks, super_masks, voxel_data):
    # Extract occupied box bounds from header [S1, unofficial]
    a_min = header[12:15]
    a_max = header[16:19]
    
    # Initialize standard 3D DDA state [G]
    t, cell, step, t_delta, t_max = init_dda(o, d)
    
    # Iteration cap unchanged by skipping [S1, unofficial]
    max_iterations = 768
    
    for _ in range(max_iterations):
        # Early-out check against occupied box [S1, unofficial]
        for axis in range(3):
            if step[axis] >= 0 and cell[axis] > a_max[axis]:
                return False
            if step[axis] <= 0 and cell[axis] < a_min[axis]:
                return False
        
        # Determine current super-brick index (32^3 cells per super-brick) [G]
        super_idx = tuple(c // 32 for c in cell)
        
        # Check super-brick occupancy via nonempty bitset [S1, unofficial]
        if not is_super_brick_occupied(super_idx, super_masks):
            # Skip entire 32x32x32 super-brick [S1, unofficial]
            t, cell, step = skip_box(t, d, o, cell, step, 32)
            continue
        
        # Determine current brick index within super-brick (8^3 cells per brick) [G]
        brick_idx = tuple((c // 8) % 4 for c in cell)
        
        # Check brick occupancy mask [S1, unofficial]
        if not is_brick_occupied(brick_idx, brick_masks):
            # Skip 8x8x8 brick [S1, unofficial]
            t, cell, step = skip_box(t, d, o, cell, step, 8)
            continue
        
        # Fine per-voxel DDA traversal within occupied brick [S1, unofficial]
        while is_within_brick(cell):
            if is_voxel_occupied(cell, voxel_data):
                return True
            t, cell, step = advance_dda(t, d, cell, step, t_delta, t_max)
        
        # Advance to next cell after brick traversal [G]
        t, cell, step = advance_dda(t, d, cell, step, t_delta, t_max)
        
    return False

def init_dda(o, d):
    # Standard DDA initialization for unit voxel size and origin 0 [G]
    step = [1 if d[i] > 0 else -1 for i in range(3)]
    cell = [int(o[i]) for i in range(3)]
    t_delta = [abs(1.0 / d[i]) if d[i] != 0 else float('inf') for i in range(3)]
    t_max = [t_delta[i] * (cell[i] - o[i] + (0.5 if step[i] > 0 else -0.5)) for i in range(3)]
    return 0.0, cell, step, t_delta, t_max

def advance_dda(t, d, cell, step, t_delta, t_max):
    # Advance to the next voxel boundary along the closest axis [G]
    axis = 0
    if t_max[1] < t_max[axis]: axis = 1
    if t_max[2] < t_max[axis]: axis = 2
    t = t_max[axis]
    cell[axis] += step[axis]
    t_max[axis] += t_delta[axis]
    return t, cell, step, t_delta, t_max

def skip_box(t, d, o, cell, step, size):
    # Advances ray by 'size' units using the same crossing/tie logic as fine DDA [S1, unofficial]
    t_new = t + size
    # Recompute cell index at new t using DDA crossing logic to maintain exactness [S1, unofficial]
    new_cell = [int(o[i] + t_new * d[i]) for i in range(3)]
    return t_new, new_cell, step

def is_super_brick_occupied(idx, masks):
    return masks[idx]

def is_brick_occupied(idx, masks):
    return masks[idx]

def is_voxel_occupied(cell, data):
    return data[cell]

def is_within_brick(cell):
    # Check if cell is within the current 8x8x8 brick [G]
    return all(0 <= (c % 8) < 8 for c in cell)
```

**Parameters:**
- Iteration cap: 768 iterations per ray [S1, unofficial].
- Super-brick size: $32^3$ cells [S1, unofficial].
- Brick size: $8^3$ cells (implied by $32/4=8$) [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Dense Scenes:** In dense scenes with no empty space (e.g., sponge1m), the extra super-mask read and early-out math can cause regression compared to the fine DDA [S1, unofficial].
- **Precision:** The `skip_box` function must use the same crossing/tie logic as the fine DDA to ensure visited-cell decisions are identical between skipping and fine traversal [S1, unofficial].
- **Early-Out Correctness:** The early-out condition must be checked carefully to ensure it only triggers when the ray has definitively passed the occupied volume, not just the current brick/super-brick [S1, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
Time complexity is reduced for sparse volumes due to skipping empty regions, while the iteration cap remains 768 [S1, unofficial]. Memory complexity increases slightly due to the super-brick and brick masks [S1, unofficial].

**Measured Performance:**
On M2 Metal, for the `terrain1m/orbit_close` scene, GPU p50 decreased from 73.11 ms to 44.55 ms (-39.1%) [S1, unofficial]. On M2 Metal, for the `sponge1m/fit` scene, GPU p50 increased from 15.16 ms to 15.24 ms (+0.5%), showing neutral performance for dense scenes [S1, unofficial]. Visual regression tests on M2 Metal show 0% differing pixels and max delta 0 for all 9 stills, confirming exactness [S1, unofficial].

**Strengths and Limitations:**
Strengths include significant speedups in sparse scenes (e.g., autumn, terrain) by skipping empty regions [S1, unofficial]. Limitations include regression in dense scenes due to overhead of hierarchy checks [S1, unofficial].

**When to Use:**
Use for sparse volumetric data where large empty regions are common [G]. Do not use for dense volumetric data where empty regions are rare, as the overhead may outweigh the benefits [G].

## Background
This method was introduced in a pull request for the `voxelite` voxel editor project by 0x63616c [S1, unofficial]. It is part of a performance plan to create a faster exact shadow trace [S1, unofficial]. The method builds on the principles of DDA traversal but adds a hierarchical occupancy check to optimize for sparsity [S1, unofficial].
