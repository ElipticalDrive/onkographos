# Hierarchical Digital Differential Analyzer (HDDA)
Also called: Hierarchical DDA

## Overview
The Hierarchical Digital Differential Analyzer (HDDA) is a specialized ray-traversal algorithm for sparse voxel grids (specifically OpenVDB) that performs multi-resolution leapfrogging to efficiently determine voxels or tiles intersected by a ray [S1, unofficial][S3]. It leverages the compile-time fixed tree configuration of VDB to inline and collapse the hierarchical traversal, reducing the overhead of vertical tree navigation [S1, unofficial][S3]. Unlike generic BVH or KD-tree traversals, HDDA is tightly coupled to the B+tree structure of VDB, using DDA at each node level (InternalNode2, InternalNode1, Leaf) to skip non-intersected nodes and return leaf intersections in front-to-back order [S4, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
- A ray $R(t) = O + tD$, where $O$ is the origin, $D$ is the direction, and $t \in [t_{min}, t_{max}]$.
- An OpenVDB tree with a fixed hierarchy: Root $\to$ InternalNode2 ($32^3$) $\to$ InternalNode1 ($16^3$) $\to$ Leaf ($8^3$) [S4, unofficial].
- An accessor object `acc` providing `probeConstNode<NodeT>(voxel)` and `isValueOn(voxel)` [S2, unofficial].
- Template parameter `ChildNodeLevel`: Specifies the upper node level to start traversal (e.g., InternalNode2) [S2, unofficial].

**Outputs:**
- A list of `TimeSpan` intervals $[t_0, t_1]$ representing active segments along the ray, or a boolean indicating if an active segment exists [S2, unofficial].

### Data Structures
**VolumeHDDA Class:**
- `mDDA`: A `math::DDA<RayT, NodeT::TOTAL>` instance managing the DDA state for the current node level [S2, unofficial].
- `mHDDA`: A recursive instance `VolumeHDDA<TreeT, RayT, ChildNodeLevel-1>` for the child level [S2, unofficial].

**NodeDDA Struct (for Julia implementation [S4, unofficial]):**
- `state`: Underlying DDA with `voxel_size = child_size`.
- `origin`: `Coord` representing the node origin in index space.
- `dim`: `Int32`, children per axis (8, 16, or 32).
- `child_size`: `Int32`, child coverage in voxels (1, 8, or 128).
- `log2cs`: `Int`, $\log_2(\text{child\_size})$ for bit-shift index computation.

**VRIState Struct (Julia implementation [S4, unofficial]):**
- `roots`: Vector of pre-sorted root entries `(tmin, InternalNode2)`.
- `root_idx`: Current root index.
- `i2_ndda`, `i2_node`: DDA and node for InternalNode2 level.
- `i1_ndda`, `i1_node`: DDA and node for InternalNode1 level.

### Algorithm Steps
The algorithm uses template meta-programming to unroll the recursion for C++ implementations [S1, unofficial][S3]. The general case for a node level $N$ (where $N > 0$) is recursive:

1.  **Initialize DDA:** Create `mDDA` for the current node type with the ray. Initialize `TimeSpan t = (-1, -1)` [S2, unofficial].
2.  **Loop:** While `mDDA.step()` returns true:
    a.  **Check Child Node:** If `acc.probeConstNode<NodeT>(mDDA.voxel())` is not null:
        i.  Set ray times: `ray.setTimes(mDDA.time(), mDDA.next())`.
        ii. Recursively call `mHDDA.march(ray, acc, t)` (or `hits`).
        iii. If recursive call returns true (for `march`) or adds to list (for `hits`), continue or return.
    b.  **Check Active Tile:** Else if `acc.isValueOn(mDDA.voxel())`:
        i.  If `t.t0 < 0`: Set `t.t0 = mDDA.time()`.
        ii. Else if `t.t0 >= 0` (inactive tile after active segment):
            - Set `t.t1 = mDDA.time()`.
            - If `t.valid()`, return true (for `march`) or push to list (for `hits`).
            - Reset `t = (-1, -1)`.
3.  **Finalize:** If `t.t0 >= 0` after loop, set `t.t1 = mDDA.maxTime()`. Return false (for `march`) or finish (for `hits`) [S2, unofficial].

**Base Case (Leaf Level, `ChildNodeLevel = 0`):**
1.  Initialize `mDDA` with `LeafT::TOTAL`.
2.  Loop: While `mDDA.step()`:
    a.  If `acc.probeConstNode<LeafT>(mDDA.voxel())` is not null OR `acc.isValueOn(mDDA.voxel())`:
        i.  If `t.t0 < 0`: Set `t.t0 = mDDA.time()`.
        ii. Else if `t.t0 >= 0`:
            - Set `t.t1 = mDDA.time()`.
            - If `t.valid()`, return true or push to list.
            - Reset `t = (-1, -1)`.
3.  If `t.t0 >= 0`, set `t.t1 = mDDA.maxTime()` [S2, unofficial].

**Julia Implementation Details (VRIState [S4, unofficial]):**
1.  **Root Hit:** Find all root InternalNode2 hits, sort by $t_{min}$.
2.  **Phase 1 (Drain I1):** Drain current I1 DDA for leaf hits.
3.  **Phase 2 (Step I2):** Step I2 DDA to find next I1 child with AABB hit.
4.  **Phase 3 (Next Root):** Advance to next pre-sorted root entry.

**NodeDDA Query (Julia [S4, unofficial]):**
1.  Compute local coordinates: $l_x = (ijk[1] - origin[1]) / child\_size$, etc.
2.  Check $0 \le l_x, l_y, l_z < dim$.
3.  Compute child index: $idx = l_x \cdot dim^2 + l_y \cdot dim + l_z$.
4.  Return `(inside, idx)` [S4, unofficial].

### Pseudocode
```python
# General recursive HDDA step for Node Level N
def hdda_step(NodeT, Ray, Accessor, TimeSpan t):
    # Initialize DDA for current node level
    mDDA = DDA(Ray, NodeT.TOTAL)
    
    # Recursive child HDDA instance
    mHDDA = VolumeHDDA(Tree, Ray, NodeT.Level - 1)
    
    while mDDA.step():
        voxel = mDDA.voxel()
        
        # Check if child node exists
        child_node = Accessor.probeConstNode(NodeT, voxel)
        if child_node is not None:
            # Ray is inside child node bounds
            Ray.setTimes(mDDA.time(), mDDA.next())
            # Recurse
            if mHDDA.march(Ray, Accessor, t):
                return True
        
        # Check if current tile is active
        elif Accessor.isValueOn(voxel):
            if t.t0 < 0:
                t.t0 = mDDA.time()
            else:
                # Hit inactive tile after active segment
                t.t1 = mDDA.time()
                if t.valid():
                    return True # Or push to list
                t.set(-1, -1)
    
    # Close open segment at end of ray
    if t.t0 >= 0:
        t.t1 = mDDA.maxTime()
        
    return False

# Base case for Leaf Level
def hdda_leaf_step(LeafT, Ray, Accessor, TimeSpan t):
    mDDA = DDA(Ray, LeafT.TOTAL)
    
    while mDDA.step():
        voxel = mDDA.voxel()
        
        # Check if leaf node exists or tile is active
        leaf_node = Accessor.probeConstNode(LeafT, voxel)
        if leaf_node is not None or Accessor.isValueOn(voxel):
            if t.t0 < 0:
                t.t0 = mDDA.time()
            else:
                t.t1 = mDDA.time()
                if t.valid():
                    return True # Or push to list
                t.set(-1, -1)
                
    if t.t0 >= 0:
        t.t1 = mDDA.maxTime()
        
    return False
```

### Parameters and Edge Cases
- **ChildNodeLevel:** Template argument specifying the entry upper node level. The final level is always the leaf node (level 0) [S2, unofficial].
- **Non-linear Transforms:** HDDA assumes rays are linear in index space. For non-linear transforms (e.g., camera frustum warping), shadow rays do not march in straight lines in index space, preventing direct HDDA use [S1, unofficial][S3].
- **Solution for Non-linear Transforms:** Construct an auxiliary VDB with a linear transform. This auxiliary grid acts as a mask for active values in the frustum volume. It is generated via concurrent resampling of the density grid with a frustum transform onto a binary grid with a linear transform. The auxiliary grid uses lower resolution and single-bit encoding for compactness. Bit-wise topological dilation is performed to account for interpolation kernel size [S1, unofficial][S3].
- **Time Span Management:** `TimeSpan t` is initialized to `(-1, -1)`. `t.t0` marks start, `t.t1` marks end. If inactive tile hit after active, segment closes. If ray ends in active segment, `t.t1` set to `maxTime` [S2, unofficial].

## Subtopics

### [NanoVolumeHDDA](3125-nanovolumehdda.md)
A span-merging hierarchical DDA iterator over a NanoGrid that yields TimeSpan structs representing merged active regions along a ray in front-to-back order. It merges adjacent active leaves and tiles to eliminate seam artifacts at 8-voxel tile edges.

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of active voxels/tiles intersected by the ray, but with a significantly smaller constant factor due to multi-resolution leapfrogging [S1, unofficial][S3].
- **Memory Complexity:** $O(1)$ auxiliary memory per traversal step, as the tree structure is fixed and inlined [S1, unofficial][S3].
- **Performance:** Highly efficient for sparse volumes with linear transformations. The use of template meta-programming reduces vertical navigation overhead [S1, unofficial][S3].
- **Strengths:** Optimized for VDB's B+tree structure; minimizes voxel interpolation for level-set surfaces; compact auxiliary grids for non-linear transforms [S1, unofficial][S3].
- **Limitations:** Requires fixed tree configuration at compile-time; not directly applicable to non-linear transforms without auxiliary grid construction [S1, unofficial][S3].
- **When to Use:** Volume rendering of densities (e.g., clouds) and ray-tracing of narrow-band level set surfaces with linear transformations [S1, unofficial][S3].

## Background
The HDDA was developed by Ken Museth for the VDB (Volume Database) system, initially presented in 2013 [S1, unofficial][S3]. It was designed to take full advantage of the hierarchical structure of VDB, which uses a B+tree with fixed node sizes. The algorithm was implemented in OpenVDB v2 and has since been used for various graphics applications, including volume rendering and level-set intersection [S1, unofficial][S3]. The approach has been adapted in various implementations, including C++ (OpenVDB) and Julia (Lyr.jl) [S2, S4, unofficial].
