# Hierarchical Grid Traversal

Also called: HDDA, Multi-resolution DDA, Sparse Voxel Octree DDA

## Overview
Hierarchical Grid Traversal accelerates ray-grid traversal by skipping empty regions using a multi-level occupancy hierarchy, avoiding the per-voxel cost of flat DDA algorithms [S1, unofficial]. It sets itself apart from flat siblings like [Amanatides–Woo grid traversal](5003-amanatides-woo-grid-traversal.md) by trading memory for speed via coarse-grained empty-space culling, while maintaining pixel-identical output to the fine per-voxel traversal [S1, unofficial].

## Shared principles
All hierarchical DDA variants share the core mechanism of combining a standard Digital Differential Analyzer (DDA) traversal with an occupancy hierarchy to skip empty space [S1, unofficial]. The traversal maintains a DDA state (current time $t$, next boundary times $t_x, t_y, t_z$, and step directions) to determine the next voxel boundary intersection [S1, unofficial]. When the ray enters a region marked as empty by the hierarchy (e.g., a super-brick or internal node), the algorithm advances the DDA state by the size of that empty block rather than stepping through individual voxels [S1, unofficial]. This "skip" operation uses the same crossing/tie logic as the fine DDA to ensure visited-cell decisions remain identical between skipping and fine traversal [S1, unofficial]. The traversal terminates when the ray exits the volume bounds or definitively passes the occupied volume's axis-aligned bounding box (AABB) [S1, unofficial].

## Subtopics

### [OpenVDB DDA](2149-openvdb-dda.md)
Specialized for OpenVDB grids, it uses a fixed step-size defined by `Log2Dim` to traverse nodes or voxels, marching through every boundary without skipping empty space.

### [Hierarchical DDA with Super-brick Skipping](5197-hierarchical-dda-with-super-brick-skipping.md)
Uses a two-level hierarchy (super-bricks and bricks) to skip large empty regions, verifying emptiness at coarser granularity and using an AABB for early termination.

### [DDA Tree Traversal with Mini-Stack](5244-dda-tree-traversal-with-mini-stack.md)
Extends DDA to N-ary trees using a fixed-size mini-stack to manage descent, horizontal processing, and ascent, optimizing for GPU shaders with fixed-depth hierarchies.

## Background
Hierarchical DDA methods were developed to address the performance bottleneck of traversing sparse volumetric data, where flat DDA algorithms waste cycles on empty space [S1, unofficial]. The concept evolved from sparse voxel octree rendering techniques, adapting the efficiency of ray tracing acceleration structures to volume rendering [S1, unofficial]. It is widely used in real-time rendering engines and scientific visualization where data sparsity is high [S1, unofficial].
