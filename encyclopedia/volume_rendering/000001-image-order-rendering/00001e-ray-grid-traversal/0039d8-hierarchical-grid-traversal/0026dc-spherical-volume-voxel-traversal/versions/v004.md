# Spherical Volume Voxel Traversal
Also called: walkSphericalVolume

## Overview
A spherical coordinate voxel traversal algorithm that traces a ray with unit direction over a spherical voxel grid, returning a vector of the spherical coordinate voxels traversed [S1, unofficial]. It computes intersections with spherical shells, polar cones, and azimuthal wedges directly, handling the singularity at the origin by starting traversal at the first non-zero radial shell [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A `Ray` (origin, direction, inverse direction), a `SphericalVoxelGrid` (center, dimensions, precomputed bounds), and `max_t` (unitized time limit) [S1, unofficial].
- **Output:** A `std::vector<SphericalVoxel>` containing the ordered list of voxels traversed, where each voxel stores its radial, polar, and azimuthal indices and its entry/exit times along the ray [S1, unofficial].

**Data Structures:**
The grid and ray are represented by the following structures [S1, unofficial]:
- `SphereBound`: `double radial`, `double polar`, `double azimuthal`.
- `Ray`: `const BoundVec3 origin_`, `const UnitVec3 direction_`, `const FreeVec3 inverse_direction_`, `const enum DirectionIndex NZD_index_`.
- `RaySegment`: `const BoundVec3 P2_`, `const DirectionIndex NZDI_`, `BoundVec3 P1_`, `FreeVec3 ray_segment_`.
- `TrigonometricValues`: `double cosine`, `double sine`.

**Algorithm Steps:**
1. **Early Exit:** If `max_t <= 0.0`, return an empty vector [S1, unofficial].
2. **Ray-Sphere Intersection:**
   - Compute vector from ray origin to sphere center: $rsv = \text{grid.center} - \text{ray.origin}$ [S1, unofficial].
   - Compute squared length $rsvd = \|rsv\|^2$ and dot product $v = rsv \cdot \text{ray.direction}$ [S1, unofficial].
   - Find `radial_entrance_voxel` such that $rsvd < \text{grid.deltaRadiiSquared}(\text{radial\_entrance\_voxel})$ [S1, unofficial].
   - Determine `ray_origin_is_outside_grid = (radial_entrance_voxel == 0)` [S1, unofficial].
   - Compute `vector_index = radial_entrance_voxel - !ray_origin_is_outside_grid` and `entry_radius_squared = grid.deltaRadiiSquared(vector_index)` [S1, unofficial].
   - Check miss: If $entry\_radius\_squared \le rsvd - v^2$, return empty [S1, unofficial].
   - Compute $d = \sqrt{entry\_radius\_squared - (rsvd - v^2)}$ [S1, unofficial].
   - Compute $t_{ray\_exit} = \text{ray.timeOfIntersection}(v + d)$; if $< 0$, return empty [S1, unofficial].
   - Compute $t_{ray\_entrance} = \text{ray.timeOfIntersection}(v - d)$ [S1, unofficial].
3. **Initialization:**
   - Set `current_radial_voxel = radial_entrance_voxel + ray_origin_is_outside_grid` [S1, unofficial].
   - Initialize boundary segments `P_polar` and `P_azimuthal` via `initializeVoxelBoundarySegments` using `entry_radius` [S1, unofficial].
   - Reserve output vector capacity: `grid.numRadialSections() + grid.numPolarSections() + grid.numAzimuthalSections()` [S1, unofficial].
   - Push initial voxel `{radial: current_radial_voxel, polar: 0, azimuthal: 0}` [S1, unofficial].
   - Set $t = t_{ray\_entrance} \times \text{ray\_origin\_is\_out\_side\_grid}$ [S1, unofficial].
   - Compute `unitized_ray_time = max_t * grid.sphereMaxDiameter() + t_ray_entrance * ray_origin_is_outside_grid` [S1, unofficial].
   - Update `max_t = min(t_ray_exit, unitized_ray_time)` if outside, else `unitized_ray_time` [S1, unofficial].
   - Initialize `collinear_times = {0.0, ray.timeOfIntersectionAt(t)}` [S1, unofficial].
4. **Traversal Loop:**
   - While $t < max\_t$:
     - Compute next intersection parameters for radial, polar, and azimuthal boundaries using `radialHit`, `polarHit`, and `azimuthalHit` [S1, unofficial].
     - Check termination: If `current_radial_voxel + radial.tStep == 0` or all `tMax` values are infinite, set `voxels.back().exit_t = t_ray_exit` and return [S1, unofficial].
     - Determine `voxel_intersection = minimumIntersection(radial, polar, azimuthal)` [S1, unofficial].
     - Update $t$ and voxel indices based on intersection type, applying modulo arithmetic for angular coordinates and checking bounds via `inBoundsPolar`/`inBoundsAzimuthal` [S1, unofficial].
     - If out of bounds, set `voxels.back().exit_t = t_ray_exit` and return [S1, unofficial].
     - **Duplicate Check:** If new coordinates match the last voxel, `continue` [S1, unofficial].
     - **Add Voxel:** Set `voxels.back().exit_t = t` and push `{radial, polar, azimuthal, enter_t: t}` [S1, unofficial].
5. **Finalization:** Loop terminates when $t \ge max\_t$; the final voxel's exit time is implicitly handled by the loop condition or explicit boundary checks [S1, unofficial].

**Pseudocode:**
```python
from math import sqrt
from enum import Enum

class HitParams:
    def __init__(self, t_max, t_step):
        self.t_max = t_max
        self.t_step = t_step

class IntersectionType(Enum):
    RADIAL = 0
    POLAR = 1
    AZIMUTHAL = 2
    RADIAL_POLAR = 3
    RADIAL_AZIMUTHAL = 4
    POLAR_AZIMUTHAL = 5
    RADIAL_POLAR_AZIMUTHAL = 6

class SphericalVoxel:
    def __init__(self, radial, polar, azimuthal, enter_t=0.0, exit_t=0.0):
        self.radial = radial
        self.polar = polar
        self.azimuthal = azimuthal
        self.enter_t = enter_t
        self.exit_t = exit_t

def in_bounds_polar(grid, step, current_voxel):
    # [G]: Standard angular bounds check; exact implementation depends on grid topology.
    return 0 <= current_voxel + step < grid.num_polar_sections

def in_bounds_azimuthal(grid, step, current_voxel):
    # [G]: Standard angular bounds check.
    return 0 <= current_voxel + step < grid.num_azimuthal_sections

def minimum_intersection(radial, polar, azimuthal):
    def isEqual(a, b, eps=1e-9): return abs(a - b) < eps
    RP_eq = isEqual(radial.t_max, polar.t_max)
    RA_eq = isEqual(radial.t_max, azimuthal.t_max)
    RP_lt = radial.t_max < polar.t_max
    RA_lt = radial.t_max < azimuthal.t_max
    if RP_lt and not RP_eq and RA_lt and not RA_eq: return IntersectionType.RADIAL
    PA_eq = isEqual(polar.t_max, azimuthal.t_max)
    PA_lt = polar.t_max < azimuthal.t_max
    if not RP_lt and not RP_eq and PA_lt and not PA_eq: return IntersectionType.POLAR
    if not RA_eq: return IntersectionType.AZIMUTHAL
    if RP_eq and RA_eq: return IntersectionType.RADIAL_POLAR_AZIMUTHAL
    if PA_eq: return IntersectionType.POLAR_AZIMUTHAL
    if RP_eq: return IntersectionType.RADIAL_POLAR
    return IntersectionType.RADIAL_AZIMUTHAL

def radial_hit_calculation(ray, grid, P_polar, current_voxel, t, max_t, collinear_times):
    # [G]: Computes time to next radial shell intersection. Returns HitParams.
    return HitParams(t + grid.delta_radius(), 1)

def polar_hit_calculation(ray, grid, P_polar, current_voxel, t, max_t, collinear_times):
    # [G]: Computes time to next polar cone intersection. Returns HitParams.
    return HitParams(t + grid.polar_step(), 1)

def azimuthal_hit_calculation(ray, grid, P_azimuthal, current_voxel, t, max_t, collinear_times):
    # [G]: Computes time to next azimuthal wedge intersection. Returns HitParams.
    return HitParams(t + grid.azimuthal_step(), 1)

def walk_spherical_volume(ray, grid, max_t):
    if max_t <= 0.0:
        return []

    rsv = grid.sphere_center - ray.origin
    rsvd = rsv.squared_length()
    v = rsv.dot(ray.direction)

    radial_entrance_voxel = 0
    while rsvd < grid.delta_radii_squared(radial_entrance_voxel):
        radial_entrance_voxel += 1

    ray_origin_is_outside_grid = (radial_entrance_voxel == 0)
    vector_index = radial_entrance_voxel - (0 if ray_origin_is_outside_grid else 1)
    entry_radius_squared = grid.delta_radii_squared(vector_index)

    rsvd_minus_v_squared = rsvd - v * v
    if entry_radius_squared <= rsvd_minus_v_squared:
        return []

    d = sqrt(entry_radius_squared - rsvd_minus_v_squared)
    t_ray_exit = ray.time_of_intersection(v + d)
    if t_ray_exit < 0.0:
        return []

    t_ray_entrance = ray.time_of_intersection(v - d)
    current_radial_voxel = radial_entrance_voxel + (1 if ray_origin_is_outside_grid else 0)

    P_polar = grid.p_max_polar if ray_origin_is_outside_grid else [
        HitParams(0.0, 0) for _ in range(grid.num_polar_sections + 1)
    ]
    P_azimuthal = grid.p_max_azimuthal if ray_origin_is_outside_grid else [
        HitParams(0.0, 0) for _ in range(grid.num_azimuthal_sections + 1)
    ]

    voxels = []
    voxels.reserve = lambda n: None
    voxels.append(SphericalVoxel(current_radial_voxel, 0, 0))

    t = t_ray_entrance if ray_origin_is_outside_grid else 0.0
    unitized_ray_time = max_t * grid.sphere_max_diameter() + t_ray_entrance * (1 if ray_origin_is_outside_grid else 0)
    max_t = min(t_ray_exit, unitized_ray_time) if ray_origin_is_outside_grid else unitized_ray_time

    collinear_times = [0.0, ray.time_of_intersection_at(t)]

    while t < max_t:
        radial = radial_hit_calculation(ray, grid, P_polar, current_radial_voxel, t, max_t, collinear_times)
        polar = polar_hit_calculation(ray, grid, P_polar, current_polar_voxel, t, max_t, collinear_times)
        azimuthal = azimuthal_hit_calculation(ray, grid, P_azimuthal, current_azimuthal_voxel, t, max_t, collinear_times)

        if current_radial_voxel + radial.t_step == 0 or (radial.t_max == float('inf') and polar.t_max == float('inf') and azimuthal.t_max == float('inf')):
            voxels[-1].exit_t = t_ray_exit
            return voxels

        intersection_type = minimum_intersection(radial, polar, azimuthal)

        if intersection_type == IntersectionType.RADIAL:
            t = radial.t_max
            current_radial_voxel += radial.t_step
        elif intersection_type == IntersectionType.POLAR:
            t = polar.t_max
            if not in_bounds_polar(grid, polar.t_step, current_polar_voxel):
                voxels[-1].exit_t = t_ray_exit
                return voxels
            current_polar_voxel = (current_polar_voxel + polar.t_step) % grid.num_polar_sections
        elif intersection_type == IntersectionType.AZIMUTHAL:
            t = azimuthal.t_max
            if not in_bounds_azimuthal(grid, azimuthal.t_step, current_azimuthal_voxel):
                voxels[-1].exit_t = t_ray_exit
                return voxels
            current_azimuthal_voxel = (current_azimuthal_voxel + azimuthal.t_step) % grid.num_azimuthal_sections
        elif intersection_type == IntersectionType.RADIAL_POLAR:
            t = radial.t_max
            if not in_bounds_polar(grid, polar.t_step, current_polar_voxel):
                voxels[-1].exit_t = t_ray_exit
                return voxels
            current_radial_voxel += radial.t_step
            current_polar_voxel = (current_polar_voxel + polar.t_step) % grid.num_polar_sections
        elif intersection_type == IntersectionType.RADIAL_AZIMUTHAL:
            t = radial.t_max
            if not in_bounds_azimuthal(grid, azimuthal.t_step, current_azimuthal_voxel):
                voxels[-1].exit_t = t_ray_exit
                return voxels
            current_radial_voxel += radial.t_step
            current_azimuthal_voxel = (current_azimuthal_voxel + azimuthal.t_step) % grid.num_azimuthal_sections
        elif intersection_type == IntersectionType.POLAR_AZIMUTHAL:
            t = polar.t_max
            if not in_bounds_polar(grid, polar.t_step, current_polar_voxel) or not in_bounds_azimuthal(grid, azimuthal.t_step, current_azimuthal_voxel):
                voxels[-1].exit_t = t_ray_exit
                return voxels
            current_polar_voxel = (current_polar_voxel + polar.t_step) % grid.num_polar_sections
            current_azimuthal_voxel = (current_azimuthal_voxel + azimuthal.t_step) % grid.num_azimuthal_sections
        elif intersection_type == IntersectionType.RADIAL_POLAR_AZIMUTHAL:
            t = radial.t_max
            if not in_bounds_polar(grid, polar.t_step, current_polar_voxel) or not in_bounds_azimuthal(grid, azimuthal.t_step, current_azimuthal_voxel):
                voxels[-1].exit_t = t_ray_exit
                return voxels
            current_radial_voxel += radial.t_step
            current_polar_voxel = (current_polar_voxel + polar.t_step) % grid.num_polar_sections
            current_azimuthal_voxel = (current_azimuthal_voxel + azimuthal.t_step) % grid.num_azimuthal_sections

        if (voxels[-1].radial == current_radial_voxel and
            voxels[-1].polar == current_polar_voxel and
            voxels[-1].azimuthal == current_azimuthal_voxel):
            continue

        voxels[-1].exit_t = t
        voxels.append(SphericalVoxel(current_radial_voxel, current_polar_voxel, current_azimuthal_voxel, enter_t=t))

    return voxels
```

**Parameters:**
- `max_t`: Unitized time for ray travel. Expected range $[0.0, 1.0]$. If `max_t <= 0.0`, no voxels are traversed. If `max_t >= 1.0`, the entire sphere is traversed [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Duplicate Voxels:** If the computed next voxel coordinates are identical to the current voxel, the loop continues without adding a new entry to prevent duplicates [S1, unofficial].
- **Boundary Conditions:** Angular bounds checks (`inBoundsPolar`, `inBoundsAzimuthal`) are critical. If a traversal step would move outside the valid angular range, the traversal terminates, and the last voxel's exit time is set to `t_ray_exit` [S1, unofficial].
- **Singularity at Origin:** The algorithm handles the origin singularity by starting traversal at the first non-zero radial shell (`radial_entrance_voxel`) and checking if the ray origin is outside the grid [S1, unofficial].
