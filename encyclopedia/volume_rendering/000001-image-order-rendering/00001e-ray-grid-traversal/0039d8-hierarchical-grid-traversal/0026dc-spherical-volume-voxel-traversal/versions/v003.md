# Spherical Volume Voxel Traversal
Also called: walkSphericalVolume

## Overview
Spherical Volume Voxel Traversal is a ray-marching algorithm that traverses a ray through a voxel grid structured in spherical coordinates (radial, polar, azimuthal), returning the sequence of voxels intersected by the ray [S1, unofficial]. It solves the problem of efficiently sampling volumetric data defined on a spherical domain, such as planetary atmospheres or star models, where Cartesian grids introduce significant distortion or wasted space near the center [S1, unofficial]. Unlike Cartesian hierarchical traversal which relies on axis-aligned bounding boxes, this method computes intersections with spherical shells, polar cones, and azimuthal wedges directly, handling the singularity at the origin by starting traversal at the first non-zero radial shell [S1, unofficial]. It builds on [Hierarchical Grid Traversal](8384-hierarchical-grid-traversal.md) by specializing the traversal logic for spherical topology rather than octree or uniform grid structures.

## How it works
**Inputs and Outputs:**
- **Input:** A `Ray` (origin, direction, inverse direction), a `SphericalVoxelGrid` (center, dimensions, precomputed bounds), and `max_t` (unitized time limit).
- **Output:** A `std::vector<SphericalVoxel>` containing the ordered list of voxels traversed, where each voxel stores its radial, polar, and azimuthal indices and its entry/exit times along the ray.

**Data Structures:**
The grid and ray are represented by the following structures [S1, unofficial]:

- `SphereBound`: `double radial`, `double polar`, `double azimuthal`. Represents the bounds of a voxel in spherical space.
- `Ray`:
  - `const BoundVec3 origin_`: Ray origin.
  - `const UnitVec3 direction_`: Normalized ray direction.
  - `const FreeVec3 inverse_direction_`: Element-wise reciprocal of direction for fast step calculation.
  - `const enum DirectionIndex NZD_index_`: Index of the non-zero direction component (used for optimization).
- `RaySegment`:
  - `const BoundVec3 P2_`: End point of the segment.
  - `const DirectionIndex NZDI_`: Non-zero direction index.
  - `BoundVec3 P1_`: Start point of the segment.
  - `FreeVec3 ray_segment_`: Vector from P1 to P2.
- `TrigonometricValues`: `double cosine`, `double sine`. Precomputed trigonometric values for angular boundaries.

**Algorithm Steps:**

1.  **Early Exit:** If `max_t <= 0.0`, return an empty vector [S1, unofficial].
2.  **Ray-Sphere Intersection:**
    - Compute the vector from the ray origin to the sphere center: $rsv = \text{grid.center} - \text{ray.origin}$ [S1, unofficial].
    - Compute squared length $rsvd = \|rsv\|^2$ and dot product $v = rsv \cdot \text{ray.direction}$ [S1, unofficial].
    - Determine the radial entrance voxel by finding the smallest `radial_entrance_voxel` such that $rsvd \ge \text{grid.deltaRadiiSquared}(\text{radial\_entrance\_voxel})$ [S1, unofficial].
    - Check if the ray origin is outside the grid: `ray_origin_is_outside_grid = (radial_entrance_voxel == 0)` [S1, unofficial].
    - Calculate the entry radius squared: $entry\_radius\_squared = \text{grid.deltaRadiiSquared}(\text{vector\_index})$, where `vector_index` is `radial_entrance_voxel - !ray_origin_is_outside_grid` [S1, unofficial].
    - Check for miss: If $entry\_radius\_squared \le rsvd - v^2$, the ray does not intersect the sphere; return empty [S1, unofficial].
    - Compute distance to intersection: $d = \sqrt{entry\_radius\_squared - (rsvd - v^2)}$ [S1, unofficial].
    - Compute ray exit time: $t_{ray\_exit} = \text{ray.timeOfIntersection}(v + d)$ [S1, unofficial]. If $t_{ray\_exit} < 0$, return empty.
    - Compute ray entrance time: $t_{ray\_entrance} = \text{ray.timeOfIntersection}(v - d)$ [S1, unofficial].
3.  **Initialization:**
    - Set `current_radial_voxel = radial_entrance_voxel + ray_origin_is_outside_grid` [S1, unofficial].
    - Initialize `current_polar_voxel` and `current_azimuthal_voxel` based on the ray's initial position within the first radial shell (details omitted in source, assumed to be determined by angular projection of the entrance point) [S1, unofficial].
    - Initialize boundary line segments `P_polar` and `P_azimuthal` using `initializeVoxelBoundarySegments`, which computes the intersection lines of the current radial shell with polar and azimuthal planes [S1, unofficial].
    - Reserve memory for the output vector: `grid.numRadialSections() + grid.numPolarSections() + grid.numAzimuthalSections()` [S1, unofficial].
    - Push the first voxel: `{radial: current_radial_voxel, polar: current_polar_voxel, azimuthal: current_azimuthal_voxel}` [S1, unofficial].
    - Set initial time $t = t_{ray\_entrance} \times \text{ray\_origin\_is\_out\_side\_grid}$ [S1, unofficial].
    - Compute `unitized_ray_time = max_t * grid.sphereMaxDiameter() + t_ray_entrance * ray_origin_is_outside_grid` [S1, unofficial].
    - Update `max_t` to `min(t_ray_exit, unitized_ray_time)` if outside, else `unitized_ray_time` [S1, unofficial].
4.  **Traversal Loop:**
    - While $t < max\_t$:
        - Compute time to next radial boundary: `radial = radialHit(...)`.
        - Compute time to next polar boundary: `polar = polarHit(...)`.
        - Compute time to next azimuthal boundary: `azimuthal = azimuthalHit(...)` [S1, unofficial].
        - Determine the minimum intersection time and type using `minimumIntersection(radial, polar, azimuthal)` [S1, unofficial]. This function compares $t_{max}$ values for radial, polar, and azimuthal hits, handling equality cases (e.g., simultaneous radial-polar hit) [S1, unofficial].
        - Update $t$ and voxel indices based on the intersection type:
            - **Radial:** $t = radial.tMax$, `current_radial_voxel += radial.tStep`.
            - **Polar:** $t = polar.tMax$. Check bounds using `inBoundsPolar`. If out of bounds, set `voxels.back().exit_t = t_ray_exit` and return. Else, `current_polar_voxel = (current_polar_voxel + polar.tStep) % grid.numPolarSections()` [S1, unofficial].
            - **Azimuthal:** $t = azimuthal.tMax$. Check bounds using `inBoundsAzimuthal`. If out of bounds, set `voxels.back().exit_t = t_ray_exit` and return. Else, `current_azimuthal_voxel = (current_azimuthal_voxel + azimuthal.tStep) % grid.numAzimuthalSections()` [S1, unofficial].
            - **RadialPolar:** Update both radial and polar indices. Check polar bounds. If out, return [S1, unofficial].
            - **RadialAzimuthal:** Update both radial and azimuthal indices. Check azimuthal bounds. If out, return [S1, unofficial].
            - **PolarAzimuthal:** Update both polar and azimuthal indices. Check both bounds. If either out, return [S1, unofficial].
            - **RadialPolarAzimuthal:** Update all three indices. Check both angular bounds. If either out, return [S1, unofficial].
        - **Duplicate Check:** If the new voxel coordinates are identical to the last voxel in the vector, `continue` (skip adding) [S1, unofficial].
        - **Add Voxel:** Set `voxels.back().exit_t = t`. Push new voxel `{radial: current_radial_voxel, polar: current_polar_voxel, azimuthal: current_azimuthal_voxel, enter_t: t}` [S1, unofficial].
5.  **Finalization:** If the loop completes without hitting a boundary exit condition, the last voxel's `exit_t` is implicitly handled by the loop termination or explicit check at the start of the next iteration [S1, unofficial].

**Pseudocode:**

```python
def walk_spherical_volume(ray, grid, max_t):
    if max_t <= 0.0:
        return []

    # Ray-Sphere Intersection
    rsv = grid.sphere_center - ray.origin
    rsvd = rsv.squared_length()
    v = rsv.dot(ray.direction)
    
    # Find radial entrance voxel
    radial_entrance_voxel = 0
    while rsvd < grid.delta_radii_squared(radial_entrance_voxel):
        radial_entrance_voxel += 1
        
    ray_origin_is_outside_grid = (radial_entrance_voxel == 0)
    vector_index = radial_entrance_voxel - (0 if ray_origin_is_outside_grid else 1)
    entry_radius_squared = grid.delta_radii_squared(vector_index)
    
    # Check if ray misses the sphere
    rsvd_minus_v_squared = rsvd - v * v
    if entry_radius_squared <= rsvd_minus_v_squared:
        return []
        
    d = sqrt(entry_radius_squared - rsvd_minus_v_squared)
    t_ray_exit = ray.time_of_intersection(v + d)
    if t_ray_exit < 0.0:
        return []
        
    t_ray_entrance = ray.time_of_intersection(v - d)
    current_radial_voxel = radial_entrance_voxel + (1 if ray_origin_is_outside_grid else 0)
    
    # Initialize angular voxels based on entrance point projection
    # [G]: Exact initialization logic for polar/azimuthal from entrance point is not fully detailed in source.
    # Assuming standard projection: theta = acos(z/r), phi = atan2(y, x)
    current_polar_voxel = grid.get_polar_voxel_from_point(ray.point_at(t_ray_entrance))
    current_azimuthal_voxel = grid.get_azimuthal_voxel_from_point(ray.point_at(t_ray_entrance))

    # Initialize boundary segments
    P_polar = initialize_voxel_boundary_segments(grid, current_radial_voxel, "polar")
    P_azimuthal = initialize_voxel_boundary_segments(grid, current_radial_voxel, "azimuthal")

    voxels = []
    voxels.reserve(grid.num_radial_sections + grid.num_polar_sections + grid.num_azimuthal_sections)
    voxels.append(SphericalVoxel(current_radial_voxel, current_polar_voxel, current_azimuthal_voxel))

    t = t_ray_entrance * (1 if ray_origin_is_outside_grid else 0)
    unitized_ray_time = max_t * grid.sphere_max_diameter() + t_ray_entrance * (1 if ray_origin_is_outside_grid else 0)
    max_t = min(t_ray_exit, unitized_ray_time) if ray_origin_is_outside_grid else unitized_ray_time

    collinear_times = [0.0, ray.time_of_intersection_at(t)] # Placeholder for collinear handling

    while t < max_t:
        radial_hit = radial_hit_calculation(ray, grid, P_polar, current_radial_voxel, t, max_t)
        polar_hit = polar_hit_calculation(ray, grid, P_polar, current_polar_voxel, t, max_t)
        azimuthal_hit = azimuthal_hit_calculation(ray, grid, P_azimuthal, current_azimuthal_voxel, t, max_t)

        intersection_type = minimum_intersection(radial_hit, polar_hit, azimuthal_hit)
        
        t_new = t
        radial_step = 0
        polar_step = 0
        azimuthal_step = 0
        
        if intersection_type == IntersectionType.RADIAL:
            t_new = radial_hit.t_max
            radial_step = radial_hit.t_step
        elif intersection_type == IntersectionType.POLAR:
            t_new = polar_hit.t_max
            if not in_bounds_polar(grid, polar_hit.t_step, current_polar_voxel):
                voxels[-1].exit_t = t_ray_exit
                return voxels
            polar_step = polar_hit.t_step
        elif intersection_type == IntersectionType.AZIMUTHAL:
            t_new = azimuthal_hit.t_max
            if not in_bounds_azimuthal(grid, azimuthal_hit.t_step, current_azimuthal_voxel):
                voxels[-1].exit_t = t_ray_exit
                return voxels
            azimuthal_step = azimuthal_hit.t_step
        elif intersection_type == IntersectionType.RADIAL_POLAR:
            t_new = radial_hit.t_max
            if not in_bounds_polar(grid, polar_hit.t_step, current_polar_voxel):
                voxels[-1].exit_t = t_ray_exit
                return voxels
            radial_step = radial_hit.t_step
            polar_step = polar_hit.t_step
        elif intersection_type == IntersectionType.RADIAL_AZIMUTHAL:
            t_new = radial_hit.t_max
            if not in_bounds_azimuthal(grid, azimuthal_hit.t_step, current_azimuthal_voxel):
                voxels[-1].exit_t = t_ray_exit
                return voxels
            radial_step = radial_hit.t_step
            azimuthal_step = azimuthal_hit.t_step
        elif intersection_type == IntersectionType.POLAR_AZIMUTHAL:
            t_new = polar_hit.t_max
            if not in_bounds_polar(grid, polar_hit.t_step, current_polar_voxel) or \
               not in_bounds_azimuthal(grid, azimuthal_hit.t_step, current_azimuthal_voxel):
                voxels[-1].exit_t = t_ray_exit
                return voxels
            polar_step = polar_hit.t_step
            azimuthal_step = azimuthal_hit.t_step
        elif intersection_type == IntersectionType.RADIAL_POLAR_AZIMUTHAL:
            t_new = radial_hit.t_max
            if not in_bounds_polar(grid, polar_hit.t_step, current_polar_voxel) or \
               not in_bounds_azimuthal(grid, azimuthal_hit.t_step, current_azimuthal_voxel):
                voxels[-1].exit_t = t_ray_exit
                return voxels
            radial_step = radial_hit.t_step
            polar_step = polar_hit.t_step
            azimuthal_step = azimuthal_hit.t_step

        # Update indices
        new_radial = current_radial_voxel + radial_step
        new_polar = (current_polar_voxel + polar_step) % grid.num_polar_sections
        new_azimuthal = (current_azimuthal_voxel + azimuthal_step) % grid.num_azimuthal_sections

        # Duplicate check
        if (voxels[-1].radial == new_radial and 
            voxels[-1].polar == new_polar and 
            voxels[-1].azimuthal == new_azimuthal):
            continue

        # Add voxel
        voxels[-1].exit_t = t_new
        voxels.append(SphericalVoxel(new_radial, new_polar, new_azimuthal, t_new))
        
        # Update current state
        current_radial_voxel = new_radial
        current_polar_voxel = new_polar
        current_azimuthal_voxel = new_azimuthal
        t = t_new

    return voxels
```

**Parameters:**
- `max_t`: Unitized time for ray travel. Expected range $[0.0, 1.0]$. If `max_t <= 0.0`, no voxels are traversed. If `max_t >= 1.0`, the entire sphere is traversed [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Duplicate Voxels:** If the computed next voxel coordinates are identical to the current voxel, the loop continues without adding a new entry to prevent duplicates [S1, unofficial].
- **Boundary Conditions:** Angular bounds checks (`inBoundsPolar`, `inBoundsAzimuthal`) are critical. If a traversal step would move outside the valid angular range, the traversal terminates, and the last voxel's exit time is set to `t_ray_exit` [S1, unofficial].
- **Singularity at Origin:** The algorithm handles the origin singularity by starting traversal at the first non-zero radial shell (`radial_entrance_voxel`) and checking if the ray origin is outside the grid [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of voxels traversed along the ray path. In the worst case, this is proportional to the sum of the number of radial, polar, and azimuthal sections intersected by the ray [S1, unofficial].
- **Memory Complexity:** Proportional to the number of voxels traversed, stored in a vector. Pre-allocation is recommended based on grid dimensions [S1, unofficial].
- **Strengths:** Efficiently handles spherical domains without the distortion of Cartesian grids. Precomputed trigonometric values and boundary segments reduce per-step computation [S1, unofficial].
- **Limitations:** Complexity increases with higher resolution in angular dimensions. Handling of the ray origin inside the sphere requires careful initialization of angular voxels [S1, unofficial].

## Background
Spherical Volume Voxel Traversal is part of the Spherical Volume Rendering (SVR) algorithm suite, designed for rendering volumetric data on spherical grids [S1, unofficial]. It addresses the limitations of Cartesian ray marching when applied to spherical objects, such as planets or stars, where voxel size varies significantly with radius in a Cartesian grid [S1, unofficial]. The method was developed to provide a robust and efficient way to traverse spherical voxel grids, handling the unique topology and singularities of spherical coordinates [S1, unofficial].
