# Ray Grid Traversal with Adaptive Step Sizing

Also called: CNC Traversal, Ray Traversal through Multiple Voxel Grids

## Overview
A CUDA kernel that marches rays through one or more axis-aligned voxel grids using precomputed, sorted entry/exit intersections to generate sample points and interval boundaries [S1, unofficial]. It handles empty cells by skipping them and fills continuous segments, supporting both fixed step sizes and cone-angle-aware adaptive stepping [S1, unofficial]. It sets itself apart from standard DDA by decoupling the grid boundary traversal from the sample generation, allowing for variable step sizes that scale with distance from the camera origin [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   `rays_o`: Ray origins, shape `[n_rays, 3]` [S1, unofficial].
    *   `rays_d`: Ray directions, shape `[n_rays, 3]` [S1, unofficial].
    *   `rays_mask`: Optional boolean mask, shape `[n_rays]`, to skip specific rays [S1, unofficial].
    *   `binaries`: Occupancy grids, shape `[n_grids, resx, resy, resz]`, boolean values indicating occupied cells [S1, unofficial].
    *   `aabbs`: Axis-aligned bounding boxes for each grid, shape `[n_grids, 6]` (min/max x, y, z) [S1, unofficial].
    *   `hits`: Boolean array, shape `[n_rays, n_grids]`, indicating if a ray intersects a grid [S1, unofficial].
    *   `t_sorted`: Sorted intersection distances, shape `[n_rays, n_grids * 2]` [S1, unofficial].
    *   `t_indices`: Grid IDs corresponding to each intersection in `t_sorted`, shape `[n_rays, n_grids * 2]` [S1, unofficial].
    *   `near_planes`: Near plane distances, shape `[n_rays]` [S1, unofficial].
    *   `far_planes`: Far plane distances, shape `[n_rays]` [S1, unofficial].
    *   `step_size`: Base step length. Default `1e-3` [S1, unofficial]. If `<= 0.0`, the kernel records steps through each voxel cell instead of marching [S1, unofficial].
    *   `cone_angle`: Controls linear increase of step size with distance. Must be `>= 0.0`. A value of `0.0` means uniform marching with `step_size` [S1, unofficial].
    *   `traverse_steps_limit`: Maximum number of traversal steps per ray. Enables early termination. Default `None` (unlimited). If `<= 0`, no limit is applied [S1, unofficial].
    *   `over_allocate`: Boolean flag. If `true`, memory is pre-allocated based on limits for single-pass traversal. If `false`, a two-pass approach is used [S1, unofficial].
    *   `first_pass`: Boolean flag indicating if this is the counting pass (for two-pass allocation) [S1, unofficial].
*   **Outputs:**
    *   `intervals`: PackedRaySegmentsSpec containing `vals` (start/end distances), `ray_indices`, `is_left`, `is_right`, and `chunk_cnts` [S1, unofficial].
    *   `samples`: PackedRaySegmentsSpec containing `vals` (sample positions), `ray_indices`, `is_valid`, and `chunk_cnts` [S1, unofficial].
    *   `terminate_planes`: Optional array, shape `[n_rays]`, storing the final `t_last` for each ray [S1, unofficial].

**Data Structures:**
The algorithm relies on pre-sorted intersection arrays `t_sorted` and `t_indices`. `t_sorted` contains the $2 \times n\_grids$ intersection points for each ray, sorted by distance. `t_indices` maps these distances to the specific grid ID. The occupancy is stored in `binaries`, a multi-dimensional boolean array.

**Parameters:**
*   `step_size`: `1e-3` [S1, unofficial].
*   `cone_angle`: `0.0` (uniform) to positive values [S1, unofficial].
*   `traverse_steps_limit`: `None` [S1, unofficial].

**Algorithm Steps:**

1.  **Initialization:**
    *   Compute thread ID: `tid = blockIdx.x * blockDim.x + threadIdx.x` [S1, unofficial].
    *   If `rays_mask` is provided and `rays_mask[tid]` is false, terminate [S1, unofficial].
    *   If not `first_pass` and `intervals.chunk_cnts[tid] == 0`, terminate (optimization for rays with no intersections) [S1, unofficial].
    *   Initialize `t_last = near_planes[tid]`, `continuous = false`, `n_intervals = 0`, `n_samples = 0` [S1, unofficial].
    *   Determine the start index in `t_sorted` for this ray: `base_t_sorted` (derived from `t_indices` or precomputed offsets, assumed to be known or computed via prefix sum in preprocessing) [S1, unofficial]. The loop iterates `i` from `base_t_sorted` to `base_t_sorted + n_grids * 2 - 1` [S1, unofficial].

2.  **Interval Processing Loop:**
    *   For each intersection pair `(t_sorted[i], t_sorted[i+1])`:
        *   Compute valid interval bounds:
            $$this\_tmin = \max(t\_sorted[i], near\_planes[tid])$$
            $$this\_tmax = \min(t\_sorted[i+1], far\_planes[tid])$$
        *   If `this_tmin >= this_tmax`, skip this interval (invalid or zero-length) [S1, unofficial].
        *   **Step Size Calculation:**
            *   If `step_size <= 0.0f`:
                *   Set `t_last = this_tmin` [S1, unofficial].
            *   Else:
                *   Calculate adaptive step size:
                    $$dt = \text{clamp}(t\_last \cdot cone\_angle, step\_size, 1e10f)$$
                    where $t$ is the current distance along the ray [S1, unofficial].
                *   March `t_last` forward in a `while` loop until `t_last + dt * 0.5f >= this_tmin` [S1, unofficial].
                *   Set `continuous = true` after the first valid interval is processed [S1, unofficial].

3.  **Voxel Traversal within Interval:**
    *   Setup AABB traversal for the current grid (identified by `t_indices[i]`):
        *   Create `AABBSpec` from `aabbs + level * 6` [S1, unofficial].
        *   Call `setup_traversal` to compute `delta` (voxel step vector), `tdist` (distance to next grid boundary), and initial indices (`step_index`, `current_index`, `final_index`) [S1, unofficial].
    *   **Inner Loop (Voxel Stepping):**
        *   While `t_traverse < this_tmax` and `traverse_steps_limit` not exceeded:
            *   Get cell ID from current indices [S1, unofficial].
            *   **Check Occupancy:**
                *   If `!binaries[cell_id]` (Empty):
                    *   Set `continuous = false` [S1, unofficial].
                    *   If `step_size <= 0.0f`, set `t_last = t_traverse` [S1, unofficial].
                    *   Else, march `t_last` forward using `_calc_dt` until `t_last + dt * 0.5f >= t_traverse` [S1, unofficial].
                    *   Advance traversal to next cell using `single_traversal` [S1, unofficial].
                *   If `binaries[cell_id]` (Occupied):
                    *   Calculate `t_next` (position of next voxel boundary or end of interval) [S1, unofficial].
                    *   If `step_size <= 0.0f`, `t_next = t_traverse` [S1, unofficial].
                    *   Else:
                        *   Calculate `dt` using `_calc_dt(t_last, cone_angle, step_size, 1e10f)` [S1, unofficial].
                        *   If `t_last + dt * 0.5f >= t_traverse`, break inner loop (next sample would be beyond current voxel boundary) [S1, unofficial].
                        *   Else, `t_next = t_last + dt` [S1, unofficial].
                    *   **Write Samples:**
                        *   Calculate sample position:
                            $$sample\_pos = (t\_next + t\_last) \cdot 0.5f$$
                            [S1, unofficial].
                        *   Write sample to `samples.vals` [S1, unofficial].
                        *   Increment `n_samples` [S1, unofficial].
                    *   **Write Intervals:**
                        *   If `intervals.chunk_cnts != nullptr` and `!first_pass`:
                            *   If `!continuous`:
                                *   Write left interval (`t_last`) with `is_left=true`, `is_right=false` [S1, unofficial].
                                *   Increment `n_intervals` [S1, unofficial].
                            *   Write right interval (`t_next`) with `is_left=false`, `is_right=true` [S1, unofficial].
                            *   Increment `n_intervals` [S1, unofficial].
                            *   If `!continuous` previously, set `is_left=true` on the previous index (logic implies merging or marking continuity) [S1, unofficial].
                            *   Set `continuous = true` [S1, unofficial].
                        *   If `step_size <= 0.0f`, the logic simplifies to recording voxel boundaries directly [S1, unofficial].
                    *   Advance traversal: Call `single_traversal(tdist, current_index, overflow_index, step_index, delta)`. If it returns false, break loop [S1, unofficial].

4.  **Finalization:**
    *   If `terminate_planes` is not null, set `terminate_planes[tid] = t_last` [S1, unofficial].
    *   If `intervals.chunk_cnts` is not null, set `intervals.chunk_cnts[tid] = n_intervals` [S1, unofficial].
    *   If `samples.chunk_cnts` is not null, set `samples.chunk_cnts[tid] = n_samples` [S1, unofficial] [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Overlapping Grids:** The order of grids matters. The grid with the lower index (front) has higher priority. If grids overlap, the first grid's occupancy status overwrites the second's [S1, unofficial].
*   **Invalid Intervals:** If `near_plane > far_plane` or grid boundaries result in `this_tmin >= this_tmax`, the interval is skipped [S1, unofficial].
*   **Precision:** Floating-point precision issues may arise when comparing `t_last + dt * 0.5f` with boundaries. The use of `0.5f` suggests a margin for error or centering logic [S1, unofficial].
*   **Two-Pass Allocation:** If `over_allocate` is false, a two-pass approach is required. The first pass counts intervals/samples, and the second pass fills them. This requires persistent storage of `chunk_cnts` between passes [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of rays and the number of voxels traversed per ray. The adaptive step size can reduce the number of samples for distant rays, improving performance [S1, unofficial].
*   **Memory Complexity:** Depends on the output buffers. If `over_allocate` is true, memory is allocated based on `traverse_steps_limit * 2` for intervals and `traverse_steps_limit` for samples. If false, a two-pass approach is used, requiring less initial memory but two kernel launches [S1, unofficial].
*   **Performance:** Optimized for GPU execution using CUDA. Efficiently handles sparse voxel grids by skipping empty cells [S1, unofficial].
*   **Strengths:** Adaptive step sizing reduces sample count for distant objects. Handles multiple grids and occupancy masks. Efficient empty space skipping.
*   **Limitations:** Requires precomputed sorted intersections. Overlapping grid handling is simplistic (first grid wins). Two-pass allocation adds overhead if `over_allocate` is false.
*   **When to Use:** NeRF and 3D Gaussian Splatting rendering pipelines where adaptive sampling is beneficial [S1, unofficial].
*   **When Not to Use:** When uniform sampling is required and `cone_angle` is 0. When overlapping grids with complex occlusion rules are needed.
