# KD-Tree Partitioned Volume Rendering

## Overview
A method to avoid computing all scalar values regardless of visibility by partitioning the volume into smaller sub-volumes with similar properties based on the transfer function [S1, unofficial]. It sets itself apart from standard ray casting by using a kd-tree to manage visibility order and culling sub-volumes against an opacity map, rather than traversing a uniform grid or octree [S1, unofficial].

## How it works
**Inputs and Outputs:** Not given in the sources [S1, unofficial].
**Data Structures:** The volume is partitioned into sub-volumes where scalar values fall within specific ranges defined by the transfer function [S1, unofficial]. A kd-tree organizes these sub-volumes, with each tree node associated with one sub-volume [S1, unofficial]. An opacity map corresponds to a region of the frame buffer and stores the minimum opacity of the frame buffer pixels found within that region [S1, unofficial]. Exact layouts, field sizes, and bit packing are Not given in the sources [S1, unofficial].
**Steps:**
1. Group scalar values within a certain range together based on the transfer function to define sub-volume properties [S1, unofficial].
2. Use a kd-tree to render the partitioned volume with correct visibility order, where each node is associated with a sub-volume [S1, unofficial].
3. Cull and clip each sub-volume against an opacity map [S1, unofficial].

## Subtopics

### Exploded Views
A technique introduced into the raycasting algorithm by Bruckner and Gröller to display inner occluded objects of interest by employing a force-based model to partition the volume into several segments [S2]. The partition manner is controlled by a number of forces and constraints [S2].

## Operating characteristics
Reported 10 fps for the Engine data set using a 2.5 GHz Pentium-IV and a nVidia GeForce4 graphics adapter [S1, unofficial]. Not given in the sources [S1, unofficial].

## Background
Proposed by Li et al. [Li03] to address the inefficiency of computing all scalar values regardless of visibility [S1, unofficial]. The approach combines volume partitioning with kd-tree traversal and opacity map-based culling [S1, unofficial].
