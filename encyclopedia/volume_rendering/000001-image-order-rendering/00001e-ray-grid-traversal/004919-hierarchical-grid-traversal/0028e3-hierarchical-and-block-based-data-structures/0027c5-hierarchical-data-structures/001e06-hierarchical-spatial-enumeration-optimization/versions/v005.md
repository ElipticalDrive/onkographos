# Hierarchical Spatial Enumeration Optimization

Also called: Complete octree representation, Heirarchical Spatial Enumeration, Hierarchical Spatial Enumeration (Octree Pyramid), Pyramid Enumeration, Pyramid of binary volumes

## Overview
Hierarchical Spatial Enumeration Optimization is a ray-tracing acceleration technique that represents a volumetric dataset as a pyramid of binary volumes to encode spatial coherence, specifically empty regions where opacity is zero [S1][S3, unofficial]. It solves the problem of inefficiently traversing large, sparse volume datasets by allowing rays to skip large contiguous blocks of empty space [S2, unofficial]. Unlike geometric ray tracing which uses bounding volumes or lists of primitives, this method uses a hierarchical binary volume structure (a complete octree) which is more efficient for volume data because volume datasets have tens of millions of spatially ordered cells with single samples, whereas geometric scenes have hundreds of cells with many primitives [S1]. It differs from condensed octree representations by storing the hierarchy explicitly as a pyramid of binary volumes, enabling fast image-order rendering [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A volumetric dataset of size $N \times N \times N$ voxels, where $N = 2^M + 1$ for some integer $M \ge 0$. The dataset consists of scalar values (opacity $\alpha$) at voxel locations.
*   **Output:** A pyramid of $M+1$ binary volumes $V_m$ for $m=0, \dots, M$, where each cell $V_m(i)$ is 1 if the region contains non-zero opacity, and 0 otherwise.

**Data Structures:**
The hierarchy is stored as a sequence of 3D arrays (binary volumes).
*   **Level $m$ Volume ($V_m$):** A 3D array of size $L_m \times L_m \times L_m$, where $L_m = (N-1)/2^m$.
*   **Cell Indexing:** Cells are indexed by a level number $m$ and a vector $\mathbf{i} = (i, j, k)$ where $i, j, k \in \{1, \dots, L_m\}$.
*   **Cell Value:** $V_m(\mathbf{i}) \in \{0, 1\}$.
    *   $V_m(\mathbf{i}) = 0$: The region is empty (all constituent voxels have zero opacity).
    *   $V_m(\mathbf{i}) = 1$: The region contains at least one voxel with non-zero opacity.
*   **Geometry:** Voxels are treated as point samples. Cells fill the space between voxels. The size of a cell on level $m$ is $2^m$ times the spacing between voxels. Each volume $V_m$ is one cell larger in each direction than the underlying dataset at that resolution level [S1][S3, unofficial].
*   **Coordinate Alignment:** Voxel $(1,1,1)$ is placed at the front-lower-right corner of cell $(1,1,1)$ on level 0. Cell $(1,1,1)$ on level 0 encloses the space between voxels $(1,1,1)$ and $(2,2,2)$ [S1][S3, unofficial].

**Construction Algorithm:**
The pyramid is constructed bottom-up from the base volume $V_0$ to the top volume $V_M$.

1.  **Base Volume ($V_0$):**
    For each cell $\mathbf{i} \in \{1, \dots, N-1\}^3$:
    $$ V_0(\mathbf{i}) = \begin{cases} 1 & \text{if } \alpha(\mathbf{i} + \Delta\mathbf{i}) > 0 \text{ for any } \Delta\mathbf{i} \in \{0, 1\}^3 \\ 0 & \text{otherwise} \end{cases} $$
    Cell $\mathbf{i}$ in $V_0$ is 1 if any of the 8 voxels at its vertices has non-zero opacity [S1][S3, unofficial].

2.  **Recursive Levels ($m > 0$):**
    For each cell $\mathbf{i} \in \{1, \dots, L_m\}^3$:
    $$ V_m(\mathbf{i}) = \begin{cases} 1 & \text{if } V_{m-1}(\mathbf{j}) = 1 \text{ for any child } \mathbf{j} \text{ of } \mathbf{i} \\ 0 & \text{otherwise} \end{cases} $$
    Cell $\mathbf{i}$ in $V_m$ is 0 if all 8 cells on level $m-1$ that form its octants contain zeros. Otherwise, it is 1 [S1][S3, unofficial].

**Ray Traversal Algorithm:**
For each pixel, a viewing ray is cast. The traversal uses the pyramid to skip empty regions.

1.  **Initialization:** Compute the entry point of the ray into the single cell at the top level ($V_M$). Let current level $m = M$. Let current cell index be $\mathbf{i}_M$ (the top cell). Let ray parameter $t$ be at the entry point.
2.  **Traversal Loop:** While $m \ge 0$:
    a.  **Check Occupancy:** If $V_m(\mathbf{i}_m) == 0$:
        *   The current cell is empty. Advance the ray along the current direction to the exit boundary of the current cell.
        *   Determine the next cell index $\mathbf{i}'_m$ on the same level $m$ that the ray enters.
        *   Check if the parent of $\mathbf{i}'_m$ differs from the parent of $\mathbf{i}_m$.
            *   If yes (crossed a parent boundary), move up to the parent level: $m \leftarrow m - 1$. Compute the new cell index $\mathbf{i}_{m}$ in the parent volume that contains the ray.
            *   If no, remain at level $m$ and set $\mathbf{i}_m \leftarrow \mathbf{i}'_m$.
        *   Continue loop.
    b.  **If $V_m(\mathbf{i}_m) == 1$:**
        *   The current cell contains non-zero opacity.
        *   If $m == 0$ (leaf level):
            *   Draw samples at evenly spaced locations along the ray segment within the current cell.
            *   Resample the data at these sample locations (e.g., trilinear interpolation).
            *   Composite color and opacity into the ray state (front-to-back compositing).
            *   Check for adaptive termination (if accumulated opacity exceeds threshold, stop ray).
            *   Advance ray to the exit boundary of the current cell.
            *   Determine next cell $\mathbf{i}'_0$.
            *   If parent of $\mathbf{i}'_0$ differs from parent of $\mathbf{i}_0$, move up: $m \leftarrow m - 1$. Compute new $\mathbf{i}_m$.
            *   Else, set $\mathbf{i}_0 \leftarrow \mathbf{i}'_0$.
        *   If $m > 0$:
            *   Move down one level: $m \leftarrow m + 1$.
            *   Determine the child cell $\mathbf{i}_{m}$ in $V_m$ that encloses the current ray position.
            *   Continue loop.
3.  **Termination:** If the ray exits the volume or is terminated by opacity threshold, stop.

def hierarchical_spatial_enumeration_traversal(ray_origin, ray_direction, pyramid, N, M):
    """
    ray_origin: (x, y, z)
    ray_direction: (dx, dy, dz)
    pyramid: list of 3D arrays [V_0, V_1, ..., V_M]
    N: dataset side length (N = 2^M + 1)
    M: max level
    """
    # Initialize ray parameters
    t_min = 0.0
    t_max = infinity # or volume boundary
    
    # Compute entry into top level (V_M)
    # V_M is a single cell (1x1x1)
    # Entry point is ray_origin (assuming ray starts inside or we compute intersection)
    # For simplicity, assume ray starts inside the volume or we clip to volume bounds
    
    current_level = M
    # Top level cell index is always (1,1,1)
    current_cell = (1, 1, 1)
    
    # Compute initial t intersection with top level cell
    # Top level cell size is 2^M * voxel_spacing
    # Assuming voxel spacing = 1, cell size = 2^M
    # Cell bounds are [0, 2^M] in each dimension (relative to volume)
    # We need to map ray_origin to this space. 
    # Let's assume ray_origin is already in the coordinate space of the pyramid.
    
    t_enter = compute_ray_cell_intersection(ray_origin, ray_direction, current_level, current_cell)
    t_current = t_enter
    
    accumulated_opacity = 0.0
    accumulated_color = (0.0, 0.0, 0.0)
    
    while current_level >= 0:
        # Check if current cell is empty
        if pyramid[current_level][current_cell] == 0:
            # Advance ray to next cell on same level
            t_exit = compute_ray_cell_exit(ray_origin, ray_direction, t_current, current_level, current_cell)
            t_current = t_exit
            
            # Determine next cell index on same level
            next_cell = get_next_cell_index(current_cell, ray_direction, current_level)
            
            # Check if parent changed
            parent_old = get_parent_index(current_cell, current_level)
            parent_new = get_parent_index(next_cell, current_level)
            
            if parent_new != parent_old:
                # Move up
                current_level -= 1
                current_cell = parent_new
                # Recompute t for the new cell's entry
                t_enter = compute_ray_cell_intersection(ray_origin, ray_direction, current_level, current_cell)
                if t_enter < t_current:
                    t_current = t_enter
            else:
                current_cell = next_cell
        else:
            # Cell is occupied
            if current_level == 0:
                # Leaf level: sample and composite
                t_exit = compute_ray_cell_exit(ray_origin, ray_direction, t_current, current_level, current_cell)
                
                # Draw samples within this cell
                num_samples = compute_num_samples(t_current, t_exit)
                for k in range(num_samples):
                    t_sample = t_current + (t_exit - t_current) * (k + 0.5) / num_samples
                    sample_pos = ray_origin + ray_direction * t_sample
                    alpha, color = resample_volume(sample_pos)
                    
                    # Front-to-back compositing
                    # C_out = C_in + (1 - A_in) * alpha * color
                    # A_out = A_in + (1 - A_in) * alpha
                    weight = (1.0 - accumulated_opacity) * alpha
                    accumulated_color += weight * color
                    accumulated_opacity += weight
                    
                    # Adaptive termination
                    if accumulated_opacity > 0.95: # Example threshold
                        return accumulated_color, accumulated_opacity
                
                t_current = t_exit
                
                # Move to next cell
                next_cell = get_next_cell_index(current_cell, ray_direction, current_level)
                parent_old = get_parent_index(current_cell, current_level)
                parent_new = get_parent_index(next_cell, current_level)
                
                if parent_new != parent_old:
                    current_level -= 1
                    current_cell = parent_new
                    t_enter = compute_ray_cell_intersection(ray_origin, ray_direction, current_level, current_cell)
                    if t_enter < t_current:
                        t_current = t_enter
                else:
                    current_cell = next_cell
            else:
                # Move down
                current_level += 1
                current_cell = get_child_index(current_cell, ray_direction, current_level)
                # t_current remains the same, we are now inside the child cell
                # The child cell is fully contained within the parent, so we don't recompute t_enter
                # We just continue the loop to check occupancy of the child

    return accumulated_color, accumulated_opacity

def compute_ray_cell_intersection(origin, direction, level, cell):
    # Returns t where ray enters the cell
    # Cell bounds depend on level and cell index
    cell_size = 2**level
    # Cell bounds in world space (assuming voxel spacing 1 and origin alignment)
    # Cell (i,j,k) at level m covers [ (i-1)*cell_size, i*cell_size ]
    min_x = (cell[0]-1) * cell_size
    max_x = cell[0] * cell_size
    min_y = (cell[1]-1) * cell_size
    max_y = cell[1] * cell_size
    min_z = (cell[2]-1) * cell_size
    max_z = cell[2] * cell_size
    
    t_min_x = (min_x - origin[0]) / direction[0] if direction[0] != 0 else -infinity
    t_max_x = (max_x - origin[0]) / direction[0] if direction[0] != 0 else infinity
    t_min_y = (min_y - origin[1]) / direction[1] if direction[1] != 0 else -infinity
    t_max_y = (max_y - origin[1]) / direction[1] if direction[1] != 0 else infinity
    t_min_z = (min_z - origin[2]) / direction[2] if direction[2] != 0 else -infinity
    t_max_z = (max_z - origin[2]) / direction[2] if direction[2] != 0 else infinity
    
    t_enter = max(t_min_x, t_min_y, t_min_z)
    return max(t_enter, 0.0) # Assuming ray starts inside or we clip

def compute_ray_cell_exit(origin, direction, t_current, level, cell):
    # Returns t where ray exits the cell
    cell_size = 2**level
    min_x = (cell[0]-1) * cell_size
    max_x = cell[0] * cell_size
    min_y = (cell[1]-1) * cell_size
    max_y = cell[1] * cell_size
    min_z = (cell[2]-1) * cell_size
    max_z = cell[2] * cell_size
    
    t_max_x = (max_x - origin[0]) / direction[0] if direction[0] != 0 else infinity
    t_max_y = (max_y - origin[1]) / direction[1] if direction[1] != 0 else infinity
    t_max_z = (max_z - origin[2]) / direction[2] if direction[2] != 0 else infinity
    
    t_exit = min(t_max_x, t_max_y, t_max_z)
    return t_exit

def get_next_cell_index(cell, direction, level):
    # Determine which adjacent cell the ray enters
    # Based on direction signs
    i, j, k = cell
    dx, dy, dz = direction
    
    ni, nj, nk = i, j, k
    if dx > 0: ni += 1
    elif dx < 0: ni -= 1
    if dy > 0: nj += 1
    elif dy < 0: nj -= 1
    if dz > 0: nk += 1
    elif dz < 0: nk -= 1
    return (ni, nj, nk)

    # Parent index is cell // 2
    i, j, k = cell
    return (i // 2, j // 2, k // 2)

**Parameters:**
*   $M$: Integer such that dataset side length $N = 2^M + 1$. The pyramid has levels $m = 0, \dots, M$ [S1].
*   Cell Size: The size of cells on level $m$ is $2^m$ times the spacing between voxels [S1].

**Edge Cases and Pitfalls:**
*   **Coordinate Alignment:** Voxel $(1,1,1)$ is placed at the front-lower-right corner of cell $(1,1,1)$ on level 0. Cell $(1,1,1)$ on level 0 encloses the space between voxels $(1,1,1)$ and $(2,2,2)$ [S1][S3, unofficial]. Incorrect alignment leads to sampling errors.
*   **Precision:** Floating-point precision in ray-cell intersection calculations can cause rays to miss cells or enter incorrect cells, especially at higher levels where cell sizes are large.
*   **Boundary Conditions:** Rays entering or exiting the volume must be handled correctly to avoid accessing invalid cell indices.

## Subtopics

### [Hierarchical Volume Traversal with Adaptive Termination](1682-hierarchical-volume-traversal-with-adaptive-termination.md)
Hierarchical Volume Traversal with Adaptive Termination is a ray tracing algorithm that uses a pyramidal data structure of binary volumes to skip empty regions and an adaptive termination criterion to stop tracing when opacity changes become negligible. Unlike geometric ray tracing, which uses bounding volumes or spatial subdivision with lists of primitives, this method uses a hierarchical binary volume structure, which is more efficient for volume data because volume datasets have tens of millions of spatially ordered cells with single samples, whereas geometric scenes have hundreds of cells with many primitives. It is a child of Hierarchical Spatial Enumeration Optimization, adding the adaptive termination feature. [Hierarchical Volume Traversal with Adaptive Termination](1682-hierarchical-volume-traversal-with-adaptive-termination.md)

### Hierarchical Opacity Enumeration
An optimization that uses a binary octree to avoid unnecessary resampling of voxels in transparent regions of the volume [S4]. It is a variant of hierarchical spatial enumeration that focuses on opacity-based pruning.

### Flat Pyramid
A hierarchical spatial data structure (quadtree recursively subdivided down to pixel size) where empty space uniformity information is stored in the empty voxels of the 3D volume grid [S5, unofficial]. The structure is a quadtree recursively subdivided down until pixel size. Gray squares denote voxels with volume data; white squares denote empty voxels storing the octree level [S5, unofficial]. When a ray encounters a voxel with uniformity information it jumps to the first voxel outside this uniform region. Voxels with data are treated as usual.

## Operating characteristics
*   **Time Complexity:** The cost of ray tracing volumetric data using a hierarchical enumeration grows linearly with the size of the image, logarithmically with the length of each ray, and linearly with the depth complexity of the data [S2, unofficial].
*   **Memory Complexity:** The pyramid stores $M+1$ binary volumes. The total number of cells is $\sum_{m=0}^{M} ((N-1)/2^m)^3$. Since $N=2^M+1$, the size decreases geometrically. The total memory is dominated by the base volume $V_0$, which is $(N-1)^3$ bits. This is significantly less than storing the full volume if $N$ is large, but still linear in the number of voxels.
*   **Performance:** Speedups of an order of magnitude have been observed for datasets of useful size and complexity [S1]. It saves time by quickly advancing across empty regions of space using the binary pyramid structure [S3, unofficial].
*   **Strengths:** Efficiently skips large empty regions; simple data structure (binary volumes); suitable for image-order rendering.
*   **Limitations:** Requires dataset size to be of the form $2^M+1$; construction time is non-trivial; not as flexible as pointer-based octrees for arbitrary data distributions.
*   **When to use:** When rendering large, sparse volume datasets with significant empty regions.
*   **When not to use:** When the dataset is dense or does not have significant empty regions, the overhead of traversal may not be justified.

## Background
Hierarchical Spatial Enumeration Optimization was introduced by Michael Levoy in 1990 in the paper "Efficient ray tracing of volume data" [S1]. It is based on the observation that many datasets contain coherent regions of uninteresting voxels (opacity zero) [S2, unofficial]. The method was developed to improve the performance of image-order volume rendering algorithms [S1]. It has been used in medical imaging and molecular graphics applications [S1]. The technique is also discussed in Levoy's 1988/1989 reports [S2, S3, unofficial].
