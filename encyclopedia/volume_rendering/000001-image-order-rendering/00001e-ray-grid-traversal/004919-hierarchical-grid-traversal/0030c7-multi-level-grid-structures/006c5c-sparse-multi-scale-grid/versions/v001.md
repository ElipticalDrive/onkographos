# Sparse Multi-Scale Grid

Also called: nested backend, nested multi-resolution backend

## Overview
The Sparse Multi-Scale Grid is a volume rendering and projection algorithm for Smoothed Particle Hydrodynamics (SPH) data that assigns particles to a hierarchy of grid levels based on their kernel smoothing length, deposits contributions onto coarser grids, and collapses the hierarchy coarse-to-fine via upsampling to bound per-particle cost [S1, unofficial]. It sets itself apart from single-resolution backends by providing large speedups for simulations with a wide range of smoothing lengths, such as zoom-ins or cosmological boxes including the intergalactic medium (IGM) [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** SPH particle data (positions, masses, smoothing lengths $h$), target output resolution $R$, target cells per kernel diameter $n_{target}$, and hierarchy depth $n_{levels}$.
*   **Outputs:** A rendered volume (3D) or projected image (2D) with density values.

**Data Structures:**
The method uses a hierarchical grid structure.
*   **Level 0:** A coarse grid covering the domain.
*   **Levels 1 to $n_{levels}$:** Finer sub-grids.
*   **Occupancy:** Cells in coarser grids point to finer sub-grids if occupied. Empty cells are skipped.
*   **Bounding Boxes:** Bounding boxes of occupied regions are tracked to skip empty areas during the hierarchy collapse [S1, unofficial].

**Parameters:**
*   $n_{target}$: Target number of cells per kernel diameter. Default: 6 [S1, unofficial].
*   $n_{levels}$: Depth of the grid hierarchy. Default: 4 [S1, unofficial].
*   $R$: Output resolution. Must be divisible by $2^{n_{levels}}$; otherwise, a `ValueError` is raised [S1, unofficial].

**Algorithm Steps:**
1.  **Level Assignment:** For each particle, determine the grid level it belongs to based on its smoothing length $h$. The level is chosen such that the kernel spans approximately $n_{target}$ cells at that level [S1, unofficial].
2.  **Deposit:** Deposit particle contributions (e.g., density) onto the assigned coarser grid level using the appropriate kernel (Wendland-C2) [S1, unofficial].
3.  **Collapse (Upsampling):** Collapse the hierarchy from coarse to fine.
    *   For 3D volume rendering, use trilinear interpolation during upsampling [S1, unofficial].
    *   For 2D projection, use bilinear interpolation during upsampling [S1, unofficial].
    *   Only visit cells within the tracked bounding boxes of occupied regions [S1, unofficial].
4.  **Periodic Wrapping:** Handle periodic boundary conditions per image, but only for images where the kernel overlaps the region [S1, unofficial].

**Pseudocode:**
```python
def sparse_multi_scale_grid(particles, resolution, n_target=6, n_levels=4):
    """
    Render SPH data using the Sparse Multi-Scale Grid method.
    
    Args:
        particles: List of particle data (pos, mass, h).
        resolution: Output resolution R.
        n_target: Target cells per kernel diameter.
        n_levels: Hierarchy depth.
        
    Returns:
        Rendered grid (3D) or image (2D).
    """
    # Validate resolution
    if resolution % (2 ** n_levels) != 0:
        raise ValueError("Resolution must be divisible by 2**n_levels")
    
    # Initialize hierarchy
    # Level 0 grid covers the domain
    grid_levels = [create_grid(resolution / (2 ** (n_levels - i))) for i in range(n_levels)]
    
    # Track occupied bounding boxes for each level
    occupied_bboxes = [None] * n_levels
    
    # Step 1 & 2: Assign and Deposit
    for particle in particles:
        h = particle.smoothing_length
        # Determine level based on h and n_target
        # Level L has cell size C_L. We want h / C_L approx n_target
        # C_L = R / 2^(n_levels - 1 - L) ? Or similar scaling.
        # The source implies assignment based on kernel spanning cells.
        level = assign_level(h, resolution, n_target, n_levels)
        
        # Deposit onto grid_levels[level]
        deposit_particle(particle, grid_levels[level])
        
        # Update bounding box for this level
        update_bbox(occupied_bboxes[level], particle.position)
    
    # Step 3: Collapse coarse-to-fine
    # Start from level 0 (coarsest) up to n_levels-1 (finest)
    for level in range(n_levels - 1):
        coarse_grid = grid_levels[level]
        fine_grid = grid_levels[level + 1]
        
        # Get bounding box for current level
        bbox = occupied_bboxes[level]
        if bbox is None:
            continue
            
        # Upsample coarse grid to fine grid within bbox
        # 3D uses trilinear, 2D uses bilinear
        upsampling_func = trilinear if is_3d else bilinear
        upsampling_func(coarse_grid, fine_grid, bbox)
        
        # Update bounding box for fine level based on upsampled data
        update_bbox(occupied_bboxes[level + 1], fine_grid)
        
    # Final grid is the finest level
    return grid_levels[n_levels - 1]

def assign_level(h, resolution, n_target, n_levels):
    """
    Assign particle to grid level based on smoothing length.
    """
    # Cell size at level L: C_L = resolution / 2^(n_levels - 1 - L)
    # We want h / C_L approx n_target => C_L approx h / n_target
    # resolution / 2^(n_levels - 1 - L) approx h / n_target
    # 2^(n_levels - 1 - L) approx resolution * n_target / h
    # n_levels - 1 - L approx log2(resolution * n_target / h)
    # L approx n_levels - 1 - log2(resolution * n_target / h)
    
    # Clamp L to [0, n_levels - 1]
    # This is a simplified derivation; actual implementation may vary slightly
    # but must ensure h spans ~n_target cells at level L.
    import math
    log_val = math.log2(resolution * n_target / h)
    L = n_levels - 1 - log_val
    L = max(0, min(n_levels - 1, int(round(L))))
    return L
```

**Edge Cases and Pitfalls:**
*   If $n_{target}$ or $n_{levels}$ are set while using a backend other than 'nested', a `UserWarning` is raised [S1, unofficial].
*   Periodic wrapping is handled per image, but only for images where the kernel overlaps the region [S1, unofficial].
*   Resolution must be divisible by $2^{n_{levels}}$; otherwise, a `ValueError` is raised [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The per-particle cost is bounded at $O(n_{target}^3)$ for 3D volume rendering and $O(n_{target}^2)$ for 2D projection, regardless of the smoothing length [S1, unofficial].
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Projecting 200k particles with smoothing lengths spread over ~3 decades at $1024^2$ resolution on 32 threads takes 0.12 s with the nested backend versus 1.2 s with the fast backend [S1, unofficial].
*   **Strengths:** Large speedups for simulations with a wide range of smoothing lengths (e.g., zoom-ins, cosmological boxes including the IGM) compared to single-resolution backends [S1, unofficial].
*   **Limitations:** Requires resolution to be divisible by $2^{n_{levels}}$. Periodic wrapping is limited to images where the kernel overlaps the region.
*   **When to use:** Use for SPH data with a wide dynamic range in smoothing lengths.
*   **When not to use:** Use single-resolution backends if smoothing lengths are uniform or if resolution constraints cannot be met.

## Background
The Sparse Multi-Scale Grid algorithm was implemented by Benítez-Llambay in 2025 as a new "nested" backend for the `swiftsimio` library for both 3D volume rendering and 2D projection of SPH data [S1, unofficial]. It builds on the principles of hierarchical uniform subdivision and ray-grid traversal shared by its parent family [G].
