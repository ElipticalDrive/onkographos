# Two-Level Grids for Ray Tracing on GPUs

Also called: Nested Grids, Two-Level Grid, Two-Level Grids for Ray Tracing, Two-Level Nested Grid

## Overview
Two-Level Grids for Ray Tracing on GPUs is a fixed-depth hierarchical acceleration structure designed to handle non-uniform primitive distributions in dynamic scenes [S1, S2, unofficial]. It consists of a sparse top-level grid where each occupied cell points to a sub-grid (leaf grid) of arbitrary resolution, solving the "teapot in a stadium problem" where uniform grids fail to eliminate intersection candidates in sparse regions [S1, unofficial]. Unlike [Multi-Level Array Grid](3329-multi-level-array-grid.md) which may use variable depth, this structure is fixed-depth, and unlike [Macrocell Grid Traversal](5207-macrocell-grid-traversal.md) which uses macro-cells, it explicitly constructs leaf grids via a parallel sort-based algorithm [S1, unofficial].

## How it works
### Construction
**Inputs:** Triangle mesh primitives $t$, scene bounding box $b$, top-level resolution $r$ [S1, S2, unofficial].
**Outputs:** Reference Array, Leaf Array, Top-Level Cells Array [S1, S2, unofficial].

**Data Structures:**
1. **Top-Level Cells Array:** One entry per top-level cell. Each entry is a 64-bit value composed of: Bits 0–31: Location (index) of the first leaf cell in the Leaf Array; Bits 32–55: Cell resolution (limiting resolution to $256^3$); Bits 56–63: Flags (e.g., 'is empty', 'has children') [S1, S2, unofficial].
2. **Leaf Array:** Stores start/end indices into the Reference Array for each leaf cell. A leaf cell entry typically stores two integral values indicating the interval in the Reference Array [S1, unofficial].
3. **Reference Array:** A single contiguous array storing pairs of `(leaf_cell_index, primitive_reference)`. Each primitive is referenced once per overlapping leaf cell. References for the same cell are contiguous [S1, S2, unofficial].

**Algorithm Steps:**
1. **Compute Bounds and Resolution:** Compute scene bounds $b$ and top-level resolution $r$ [S1, S2, unofficial].
2. **Upload Primitives:** Upload triangle data $t$ to GPU memory [S2, unofficial].
3. **Build Top-Level Uniform Grid:** Build a temporary uniform grid using the sort-based approach by Kalojanov and Slusallek [KS09] to determine triangle-cell overlaps [S1, S2, unofficial].
4. **Get Top-Level Pairs:** Extract sorted pairs of `(Cell Index, Primitive ID)` from the temporary grid into $Atl_p$. Get the number of top-level references $n$ and top-level cell ranges $tlc$ [S1, S2, unofficial].
5. **Compute Leaf Cell Locations:** Initialize accumulator array $Acc$ of size $r_x \cdot r_y \cdot r_z + 1$ with zeros. Count leaf cells per top-level cell using bounds $b$, resolution $r$, and ranges $tlc$: $Acc \leftarrow \text{COUNT LEAF CELLS}(b, r, tlc)$. Perform exclusive scan on $Acc$: $Acc \leftarrow \text{EXCLUSIVE SCAN}(Acc, r_x \cdot r_y \cdot r_z + 1)$. Initialize top-level cell ranges with scan results: $tlc \leftarrow \text{INITIALIZE}(Acc, tlc)$ [S1, S2, unofficial].
6. **Compute Reference Array Size:** Initialize accumulator array $Arc$ of size $G+1$ (where $G=128$) with zeros. Count leaf references per top-level cell using a fast conservative triangle-cell intersection test (bounding box only): $Arc \leftarrow \text{COUNT LEAF REFS}(t, b, r, n, Atl_p, tlc)$. Perform exclusive scan on $Arc$: $Arc \leftarrow \text{EXCLUSIVE SCAN}(Arc, G+1)$. Get total size $m \leftarrow Arc[G]$ and allocate leaf pairs array $A_p$ of size $m$ [S1, S2, unofficial].
7. **Fill Reference Array:** Write pairs `(Leaf Location, Primitive ID)` to $A_p$. The leaf location is computed from the leaf index and the location of the first leaf for the corresponding top-level cell. Use a more precise test (including plane intersection) when generating these pairs. Invalid intersections are written with a dummy cell index that is discarded during sorting [S1, S2, unofficial].
8. **Sort:** Sort $A_p$ using an improved radix sort by Billeter et al. [BOA09] with two- and four-way splits, sorting only on the required bits (up to two bits at a time) based on the known maximum key size [S1, S2, unofficial].
9. **Extract Leaf Cells:** Extract cell ranges from the sorted $A_p$ to finalize leaf cell intervals: $leaves \leftarrow \text{EXTRACT CELL RANGES}(A_p, m)$ [S1, S2, unofficial].

**Pseudocode:**
```python
def build_two_level_grid(triangles, scene_bounds, top_level_res):
    b = compute_bounds(triangles)
    r = top_level_res
    t = upload_to_gpu(triangles)
    data = build_uniform_grid(t, b, r)
    atl_p = get_sorted_top_level_pairs(data)
    n = get_number_of_top_level_references(data)
    tlc = get_top_level_cell_ranges(data)

    acc = [0] * (r.x * r.y * r.z + 1)
    acc = count_leaf_cells(b, r, tlc, acc)
    acc = exclusive_scan(acc)
    tlc = initialize(tlc, acc)

    G = 128
    arc = [0] * (G + 1)
    arc = count_leaf_refs(t, b, r, n, atl_p, tlc, arc)
    arc = exclusive_scan(arc)
    m = arc[G]
    ap = [None] * m
    ap = write_pairs(t, b, r, n, atl_p, tlc, arc, ap)
    ap = radix_sort(ap)
    leaves = extract_cell_ranges(ap, m)
    return ap, leaves, tlc

# Helper definitions
def compute_bounds(triangles): return min(triangles.vertices), max(triangles.vertices)
def upload_to_gpu(data): return data
def build_uniform_grid(prims, bounds, res): return sort_based_uniform_grid(prims, bounds, res)
def get_sorted_top_level_pairs(data): return data.sorted_pairs
def get_number_of_top_level_references(data): return len(data.sorted_pairs)
def get_top_level_cell_ranges(data): return compute_ranges(data.sorted_pairs)
def count_leaf_cells(bounds, res, tlc, acc):
    for i, (s, e) in enumerate(tlc): acc[i] = e - s
    return acc
def exclusive_scan(arr):
    res = [0] * len(arr); total = 0
    for i in range(len(arr)-1): res[i+1] = total; total += arr[i]
    return res
def initialize(tlc, acc):
    for i in range(len(tlc)): tlc[i].start = acc[i]
    return tlc
def count_leaf_refs(prims, bounds, res, n, atl_p, tlc, arc):
    for i in range(n): arc[atl_p[i].cell_index] += 1
    return arc
def write_pairs(prims, bounds, res, n, atl_p, tlc, arc, ap):
    for i in range(n):
        loc = tlc[atl_p[i].cell_index].start + atl_p[i].leaf_index
        ap[arc[atl_p[i].cell_index]] = (loc, prims[atl_p[i].prim_id])
        arc[atl_p[i].cell_index] += 1
    return ap
def radix_sort(arr): return sort_radix(arr, bits=2)
def extract_cell_ranges(sorted_arr, size):
    ranges = []; start = 0
    for i in range(1, size):
        if sorted_arr[i].key != sorted_arr[i-1].key: ranges.append((start, i)); start = i
    ranges.append((start, size)); return ranges
```

### Traversal
The traversal modifies the standard Digital Differential Analyzer (DDA) algorithm [S1, S2, unofficial].
1. **Top-Level Step:** The ray steps through the top-level grid. If a top-level cell is empty, the ray skips it. If occupied, the ray descends to the child grid [S1, S2, unofficial].
2. **Leaf-Level Step:** Each top-level cell is treated as a uniform grid. The ray traverses the leaf grid using standard DDA [S1, S2, unofficial].
3. **Optimization:** The algorithm reuses decision variables between levels to minimize computational overhead [S1, S2, unofficial].

**Pseudocode:**
```python
def trace_ray(ray, top_level_cells, reference_array, leaf_array):
    t_min, t_max = ray.bounds
    t = t_min
    while t < t_max:
        cell_idx = map_to_top_cell(ray, t)
        if cell_idx is valid:
            cell_data = top_level_cells[cell_idx]
            if not cell_data.is_empty:
                leaf_start = cell_data.leaf_location
                leaf_end = leaf_start + cell_data.num_leaves
                t_leaf_hit = traverse_leaf_grid(ray, t, reference_array, leaf_array, leaf_start, leaf_end)
                if t_leaf_hit < t_max:
                    return t_leaf_hit
```

## Subtopics

### [Two-Level Grid Construction](5226-two-level-grid-construction.md)
A massively parallel, sort-based algorithm for building the structure, solving the problem of constructing high-quality acceleration structures for non-uniform primitive distributions with linear work complexity.

### [Two-Level Grid Ray Traversal](6252-two-level-grid-ray-traversal.md)
A ray-grid traversal algorithm modifying the standard DDA to step through top-level cells and then treat each top cell as a uniform grid for leaf traversal, maintaining SIMD-friendly coherence.

## Operating characteristics
- **Time Complexity:** Construction is $O(N)$ work complexity, where $N$ is the number of primitives, due to the sort-based approach [S1, unofficial]. Traversal performance is generally inferior to state-of-the-art static scene methods (e.g., Aila and Laine [AL09]) [S2, unofficial].
- **Memory Complexity:** Linear in the number of primitives and cells. Pre-allocation of the reference array is required, computed conservatively using bounding box tests [S1, unofficial].
- **Measured Performance:** On an NVIDIA GTX 470, the implementation traced 24 million primary rays/sec for the Conference scene and 22 million for the Fairy scene, compared to 142 million and 75 million respectively for Aila and Laine [S2, unofficial].
- **Strengths:** Handles non-uniform primitive distributions robustly, avoiding the "teapot in a stadium problem" [S1, unofficial].
- **Limitations:** Lower traversal performance compared to optimized static structures [S2, unofficial]. GPU memory constraints require careful pre-allocation [S1, unofficial].
- **When to Use:** Dynamic scenes with non-uniform primitive distributions where fast construction is prioritized over maximum traversal speed [S1, unofficial].

## Background
The two-level grid is a fixed-depth hierarchy introduced by Jevans and Wyvill [JW89] and applied to ray tracing on GPUs by Kalojanov, Billeter, and Slusallek [S1, unofficial]. The construction algorithm generalizes the sort-based uniform grid construction by Kalojanov and Slusallek [KS09] and uses an improved radix sort by Billeter et al. [BOA09] [S1, unofficial]. The implementation was performed in CUDA [NBGS08] [S1, unofficial].
