# Two-Level Grid Ray Traversal

Also called: Modified DDA Traversal

## Overview
Two-Level Grid Ray Traversal is a ray-grid traversal algorithm designed for two-level hierarchical grid structures, modifying the standard Digital Differential Analyzer (DDA) algorithm to step through top-level cells and then treat each top cell as a uniform grid for leaf traversal [S1, S2, unofficial]. It sets itself apart from uniform grid traversal by handling hierarchical data structures while maintaining SIMD-friendly coherence, and from other hierarchical methods by reusing decision variables between levels to minimize computational overhead [S1, S2, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** A set of rays $R_o$, where all rays originate within a given top-level grid cell $o$ [S1, S2, unofficial]. A two-level grid structure consisting of a top-level grid and leaf grids associated with each top-level cell [S1, S2, unofficial].
*   **Output:** A sequence of intersected cells (top-level and leaf-level) for each ray in the set [S1, S2, unofficial].

**Data Structures**
The algorithm operates on a two-level grid structure [S1, S2, unofficial]. The top level is treated as a uniform grid [S1, S2, unofficial]. Each top-level cell contains a reference to a leaf grid, which is also treated as a uniform grid [S1, S2, unofficial]. The specific layout of the leaf grids (e.g., dense array, sparse structure) is defined by the construction method [S2, unofficial], but the traversal logic assumes they behave as uniform grids during the leaf phase [S1, S2, unofficial].

**Numbered Steps**
1.  **Top-Level Traversal:** Step through the top level of the two-level grid structure using the standard DDA algorithm, identical to traversing a uniform grid [S1, S2, unofficial].
2.  **Leaf Initialization:** Upon entering a top-level cell, treat that cell as the origin for a new uniform grid traversal [S1, S2, unofficial]. Reuse decision variables from the top-level traversal to spare computations when initializing the decision variables for the leaf level [S1, S2, unofficial].
3.  **Leaf Traversal:** Advance through the leaf cells within the current top-level cell using the same DDA algorithm used for the top level [S1, S2, unofficial].
4.  **Iteration:** Repeat steps 2 and 3 for each subsequent top-level cell entered by the rays [S1, S2, unofficial].

**Formulas**
The algorithm relies on the coherence property of DDA traversal [S1, S2, unofficial]. Let $R_o$ be a set of rays, all of which have origin (not necessarily the same) in a given grid cell $o$ [S1, S2, unofficial].
*   **Statement:** If a cell $c$ is intersected by any ray $r \in R_o$ and is the $n$-th cell along $r$ counted from the origin, then $c$ will be the $n$-th cell along any ray $r^* \in R_o$ that intersects $c$ [S1, S2, unofficial].
*   **Proof Basis:** Let $o$ be the 0-th cell along the rays in the set [S1, S2, unofficial]. For each cell $c$, it holds that it is at distance $(x, y, z)$ from $o$, where $x, y$ and $z$ are integers denoting the distance (in number of cells) along the coordinate axis with the same name [S1, S2, unofficial]. During traversal, rays advance with exactly one neighbor cell at a time, and the two cells share a side [S1, S2, unofficial]. This means that $c$ will be traversed at $x+y+z = n$-th step of the traversal algorithm for any ray with origin in $o$ if at all [S1, S2, unofficial].

**Parameters**
*   **Grid Density:** A single grid density is determined using the Surface Area Cost Model to work well with the traversal implementation for all test scenes [S1, S2, unofficial].
*   **Typical Values:** Not given in the sources [S1, S2, unofficial].

**Edge Cases and Pitfalls**
*   **Code Divergence:** Code divergence occurs only when rays disagree on which level of structure they need to traverse (i.e., whether to stay in the current leaf grid or move to a new top-level cell) [S1, S2, unofficial]. Otherwise, the algorithm is SIMD-friendly [S1, S2, unofficial].
*   **Memory Access:** A cell along the traversal path, if loaded, will be loaded exactly once from memory [S1, S2, unofficial]. This property transfers to the two-level grid structure when traversing the top level and when rays agree on the first leaf cell when they traverse the leaves [S1, S2, unofficial].
*   **Triangle Intersection:** Coherence in computations is lost during the ray-triangle intersection stage as soon as some rays traverse a full cell while others pass through an empty one, due to parallelization by assigning different rays to each thread [S1, unofficial].

**Pseudocode**
```python
def traverse_two_level_grid(rays, top_grid, leaf_grids):
    # Initialize top-level DDA state for all rays [G]
    top_state = []
    for ray in rays:
        cell = get_cell_containing(ray.origin, top_grid)
        t_max = [ray.t_max, ray.t_max, ray.t_max]
        t_delta = [abs(1.0 / ray.dir[i]) for i in range(3)]
        step = [1 if ray.dir[i] > 0 else -1 for i in range(3)]
        t_next = [t_max[i] if step[i] == -1 else 0.0 for i in range(3)]
        top_state.append({'cell': cell, 't_max': t_max, 't_delta': t_delta, 'step': step, 't_next': t_next})

    while True:
        if all(ray.terminated for ray in rays):
            break

        # Check for top-level boundary crossing
        transitioning = [any(s['t_next'][d] <= s['t_max'][d] for d in range(3)) for s in top_state]

        if any(transitioning):
            for i, s in enumerate(top_state):
                if transitioning[i]:
                    # Advance top-level cell
                    axis = min(range(3), key=lambda d: s['t_next'][d])
                    s['cell'][axis] += s['step'][axis]
                    s['t_next'][axis] += s['t_delta'][axis]
                    # Initialize leaf DDA state, reusing t_delta and step from top level [S1, unofficial]
                    leaf_cell = s['cell']
                    leaf_grid = leaf_grids[leaf_cell]
                    leaf_state = {
                        'cell': leaf_cell,
                        't_max': [ray.t_max, ray.t_max, ray.t_max],
                        't_delta': s['t_delta'],
                        'step': s['step'],
                        't_next': [0.0, 0.0, 0.0]
                    }
                    # Advance leaf DDA to first leaf boundary
                    while True:
                        axis = min(range(3), key=lambda d: leaf_state['t_next'][d])
                        if leaf_state['t_next'][axis] > ray.t_max:
                            break
                        leaf_state['cell'][axis] += leaf_state['step'][axis]
                        leaf_state['t_next'][axis] += leaf_state['t_delta'][axis]
                    top_state[i]['leaf_state'] = leaf_state

        # Traverse leaf cells
        for i, s in enumerate(top_state):
            if not rays[i].terminated:
                leaf = s['leaf_state']
                axis = min(range(3), key=lambda d: leaf['t_next'][d])
                leaf['cell'][axis] += leaf['step'][axis]
                leaf['t_next'][axis] += leaf['t_delta'][axis]
                # Process leaf cell [G]
                process_leaf(leaf['cell'], leaf_grid)

def get_cell_containing(point, grid):
    return [int(point[i] / grid.cell_size[i]) for i in range(3)]
```

## Operating characteristics
*   **Time Complexity:** The traversal is described as "very inexpensive" [S1, S2, unofficial]. The complexity is similar to uniform grid traversal, with the added cost of handling the two-level structure, which is mitigated by reusing decision variables [S1, S2, unofficial].
*   **Memory Complexity:** Not given in the sources [S1, S2, unofficial].
*   **Measured Performance:** Not given in the sources [S1, S2, unofficial].
*   **Scaling:** The algorithm favors coherent rays [S1, S2, unofficial]. Performance degrades if rays are incoherent, leading to code divergence when rays disagree on which level of structure they need to traverse [S1, S2, unofficial].
*   **Strengths:** SIMD (or SIMT) friendly due to lack of code divergence except when rays disagree on level transitions [S1, S2, unofficial]. Efficient memory access as cells are loaded exactly once [S1, S2, unofficial]. Reuse of decision variables reduces computational overhead [S1, S2, unofficial].
*   **Limitations:** Code divergence when rays disagree on level transitions [S1, S2, unofficial]. Loss of coherence during ray-triangle intersection if rays traverse different cell types (full vs. empty) [S1, unofficial].
*   **When to use:** When rendering with two-level hierarchical grids on GPUs, especially with coherent rays [S1, S2, unofficial].
*   **When not to use:** When rays are highly incoherent, leading to frequent level transitions and code divergence [S1, S2, unofficial].

## Background
*   **Origin:** The algorithm is a modification of the DDA traversal algorithm by Amanatides and Woo [AW87] [S1, S2, unofficial].
*   **History:** It was developed for use with two-level grids for ray tracing on GPUs [S1, S2, unofficial]. The authors note that they used the Surface Area Cost Model to determine grid density [S1, S2, unofficial].
*   **Usage:** Used in GPU-based ray tracing systems employing two-level hierarchical grids [S1, S2, unofficial].
