# Macrocell Grid Traversal

Also called: Coarse-fine grid, Downscaled Grid Traversal, Macrocell or multigrids, Two-Level Grid (Coarse Macro-Cells), multigrids

## Overview
Macrocell Grid Traversal is a hierarchical acceleration technique for ray-grid traversal that superimposes a coarse grid over a base uniform fine grid to skip empty regions [S1, S2, S3]. It solves the problem of excessive traversal overhead in large, sparse uniform grids by allowing rays to bypass blocks of empty fine cells in single steps [S2, S3]. Unlike [Multi-Level Array Grid](3329-multi-level-array-grid.md) which may use complex indexing or variable subdivision, or [Multi-Grid Ray Traversal](4142-multi-grid-ray-traversal.md) which might involve multiple independent grids, Macrocell Grid Traversal uses a fixed, regular downsampling factor $M$ to create a simple boolean occupancy map [S1, S2]. This simplicity allows for trivial build times and efficient reuse of frustum setup calculations, yielding approximately 30% performance improvement over single ray grids for medium-sized animated scenes [S2, S3].

## How it works
### Inputs and Outputs
**Inputs:**
- A base uniform fine grid of resolution $N \times N \times N$ (or $W \times H \times D$) [G].
- The ray parameters: origin $\mathbf{o}$, direction $\mathbf{d}$, and inverse direction $\mathbf{d}^{-1}$ [G].
- The downsampling factor $M$ (typically 6) [S2, S3].

**Outputs:**
- A traversal sequence of occupied fine grid cells [S3].
- A boolean occupancy flag for each macrocell indicating if any underlying fine cell is occupied [S1, S2, S3].

### Data Structures
The structure consists of two grids:
1.  **Fine Grid:** The original voxel data. Cells are indexed by $(i, j, k)$ [G].
2.  **Macrocell Grid:** A coarse grid of resolution $\lceil N/M \rceil \times \lceil N/M \rceil \times \lceil N/M \rceil$ [G].
    -   **Layout:** Flat array or organized in bricks for locality [S1].
    -   **Fields:** Each macrocell stores a single boolean flag `occupied`.
    -   **Definition:** A macrocell at coarse index $(I, J, K)$ corresponds to the fine grid block defined by fine indices:
        $$ i \in [I \cdot M, \min((I+1) \cdot M, N) - 1] $$
        $$ j \in [J \cdot M, \min((J+1) \cdot M, N) - 1] $$
        $$ k \in [K \cdot M, \min((K+1) \cdot M, N) - 1] $$
    -   **Occupancy:** `macrocell[I][J][K].occupied` is `true` if any fine cell in the corresponding block is occupied, `false` otherwise [S1, S2, S3].

### Parameters
-   **$M$ (Downsampling Factor):** The side length of the cubic block of fine cells represented by one macrocell.
    -   **Typical Value:** $M = 6$ [S2, S3].
    -   **Constraints:** Smaller $M$ yields insufficient savings to justify overhead; larger $M$ reduces the probability of finding empty regions, reducing skip benefits [S2, S3].

### Algorithm Steps

#### Build Phase
1.  Initialize the macrocell grid with all flags set to `false` [G].
2.  Iterate through all fine grid cells $(i, j, k)$ [G].
3.  If fine cell $(i, j, k)$ is occupied:
    -   Compute macrocell coordinates:
        $$ I = \lfloor i / M \rfloor $$
        $$ J = \lfloor j / M \rfloor $$
        $$ K = \lfloor k / M \rfloor $$
    -   Set `macrocell[I][J][K].occupied = true` [S2].
4.  [G] Handle boundary conditions where $N$ is not a multiple of $M$ by ensuring array bounds checks during indexing.

#### Traversal Phase
The traversal reuses the standard ray-grid traversal logic (DDA) but operates on macrocells first to determine skip distances [S3].

1.  **Frustum Setup (Coarse):**
    -   Compute the initial intersection interval $[t_{min}, t_{max}]$ of the ray with the entire scene bounding box [G].
    -   Compute the coarse grid step variables. Since the macrocell grid is a downscaled version, the step sizes in macrocell space are $M$ times larger than in fine cell space [G].
    -   Let $\Delta t_{x}, \Delta t_{y}, \Delta t_{z}$ be the time to cross one fine cell.
    -   The time to cross one macrocell is $M \cdot \Delta t_{x}$, etc. [G].
    -   Alternatively, compute the coarse grid traversal parameters by dividing the fine grid setup values by $M$ [S2, S3].

2.  **Coarse Traversal Loop:**
    -   Initialize coarse DDA variables $(I, J, K)$ to the macrocell containing the ray origin [G].
    -   While $t < t_{max}$:
        -   Check if `macrocell[I][J][K].occupied` is `false` [G].
        -   **If Empty:**
            -   Skip the entire macrocell.
            -   Advance the coarse DDA to the next macrocell along the ray direction [G].
            -   Update $t$ by adding the time to cross the current macrocell ($M \cdot \Delta t$) [G].
            -   Continue loop.
        -   **If Occupied:**
            -   Perform fine grid traversal within this macrocell block [S3].
            -   Determine the fine cell indices $(i_{start}, j_{start}, k_{start})$ corresponding to $(I, J, K)$ [G].
            -   Execute standard fine grid DDA steps for cells within the block $[I \cdot M, (I+1) \cdot M) \times [J \cdot M, (J+1) \cdot M) \times [K \cdot M, (K+1) \cdot M)$ [G].
            -   For each occupied fine cell, perform ray-volume intersection.
            -   Update $t$ and fine DDA variables.
            -   If the ray exits the current macrocell block, advance the coarse DDA to the next macrocell $(I', J', K')$ and continue the coarse loop.

3.  **Edge Cases:**
    -   **Partial Macrocells:** At the boundaries of the grid, macrocells may be smaller than $M \times M \times M$. The traversal must handle these boundary blocks correctly by checking array bounds [G].
    -   **Ray Origin Outside:** If the ray origin is outside the grid, standard frustum clipping applies before coarse traversal begins [G].

### Pseudocode

```python
def traverse_macrocell_grid(ray_origin, ray_dir, fine_grid, macrocell_grid, M, N, scene_t_max):
    """
    ray_origin: (ox, oy, oz)
    ray_dir: (dx, dy, dz)
    fine_grid: 3D array of booleans, size N x N x N
    macrocell_grid: 3D array of booleans, size ceil(N/M) x ceil(N/M) x ceil(N/M)
    M: downsampling factor
    N: fine grid resolution
    scene_t_max: maximum traversal distance along the ray [G]
    """
    # 1. Fine grid DDA setup [G]
    delta_t_x = 1.0 / ray_dir[0] if ray_dir[0] != 0 else float('inf')
    delta_t_y = 1.0 / ray_dir[1] if ray_dir[1] != 0 else float('inf')
    delta_t_z = 1.0 / ray_dir[2] if ray_dir[2] != 0 else float('inf')
    
    i = int(ray_origin[0])
    j = int(ray_origin[1])
    k = int(ray_origin[2])
    
    t_max_x = (i + 1 - ray_origin[0]) * delta_t_x if ray_dir[0] > 0 else (i - ray_origin[0]) * delta_t_x
    t_max_y = (j + 1 - ray_origin[1]) * delta_t_y if ray_dir[1] > 0 else (j - ray_origin[1]) * delta_t_y
    t_max_z = (k + 1 - ray_origin[2]) * delta_t_z if ray_dir[2] > 0 else (k - ray_origin[2]) * delta_t_z
    
    step_x = 1 if ray_dir[0] > 0 else -1
    step_y = 1 if ray_dir[1] > 0 else -1
    step_z = 1 if ray_dir[2] > 0 else -1
    
    t = 0.0
    
    # 2. Coarse grid DDA setup [G]
    N_coarse = (N + M - 1) // M
    coarse_i = i // M
    coarse_j = j // M
    coarse_k = k // M
    
    coarse_delta_t_x = M * delta_t_x
    coarse_delta_t_y = M * delta_t_y
    coarse_delta_t_z = M * delta_t_z
    
    # Distance to next coarse boundary [G]
    coarse_t_max_x = ((coarse_i + 1) * M - ray_origin[0]) * delta_t_x if ray_dir[0] > 0 else (coarse_i * M - ray_origin[0]) * delta_t_x
    coarse_t_max_y = ((coarse_j + 1) * M - ray_origin[1]) * delta_t_y if ray_dir[1] > 0 else (coarse_j * M - ray_origin[1]) * delta_t_y
    coarse_t_max_z = ((coarse_k + 1) * M - ray_origin[2]) * delta_t_z if ray_dir[2] > 0 else (coarse_k * M - ray_origin[2]) * delta_t_z
    
    # 3. Traversal loop
    while t < scene_t_max:
        # Check bounds for coarse indices
        if not (0 <= coarse_i < N_coarse and 0 <= coarse_j < N_coarse and 0 <= coarse_k < N_coarse):
            break
            
        # Check macrocell occupancy
        if not macrocell_grid[coarse_i][coarse_j][coarse_k]:
            # Skip empty macrocell [G]
            if coarse_t_max_x < coarse_t_max_y:
                if coarse_t_max_x < coarse_t_max_z:
                    coarse_i += step_x
                    t = coarse_t_max_x
                    coarse_t_max_x += coarse_delta_t_x
                else:
                    coarse_k += step_z
                    t = coarse_t_max_z
                    coarse_t_max_z += coarse_delta_t_z
            else:
                if coarse_t_max_y < coarse_t_max_z:
                    coarse_j += step_y
                    t = coarse_t_max_y
                    coarse_t_max_y += coarse_delta_t_y
                else:
                    coarse_k += step_z
                    t = coarse_t_max_z
                    coarse_t_max_z += coarse_delta_t_z
        else:
            # Macrocell occupied, traverse fine cells [G]
            i_start = coarse_i * M
            j_start = coarse_j * M
            k_start = coarse_k * M
            i_end = min(i_start + M, N)
            j_end = min(j_start + M, N)
            k_end = min(k_start + M, N)
            
            while t < scene_t_max and i < i_end and j < j_end and k < k_end:
                if fine_grid[i][j][k]:
                    # Perform ray-volume intersection [G]
                    pass 
                
                # Advance fine DDA [G]
                if t_max_x < t_max_y:
                    if t_max_x < t_max_z:
                        i += step_x
                        t_max_x += delta_t_x
                    else:
                        k += step_z
                        t_max_z += delta_t_z
                else:
                    if t_max_y < t_max_z:
                        j += step_y
                        t_max_y += delta_t_y
                    else:
                        k += step_z
                        t_max_z += delta_t_z
                
                t = min(t_max_x, t_max_y, t_max_z)
            
            # After fine traversal, update coarse DDA to next macrocell [G]
            coarse_i = i // M
            coarse_j = j // M
            coarse_k = k // M
            # Re-sync coarse t_max values to current fine position [G]
            coarse_t_max_x = ((coarse_i + 1) * M - ray_origin[0]) * delta_t_x if ray_dir[0] > 0 else (coarse_i * M - ray_origin[0]) * delta_t_x
            coarse_t_max_y = ((coarse_j + 1) * M - ray_origin[1]) * delta_t_y if ray_dir[1] > 0 else (coarse_j * M - ray_origin[1]) * delta_t_y
            coarse_t_max_z = ((coarse_k + 1) * M - ray_origin[2]) * delta_t_z if ray_dir[2] > 0 else (coarse_k * M - ray_origin[2]) * delta_t_z
```

## Subtopics

### Multi-Grid
An approach based on adopting a coarse grid at the first stage of reconstruction to obtain a rapid, reliable initial volume estimate [S5, unofficial]. It reduces the problem dimension by compressing images while maintaining a 1:1 resolution ratio between voxels and pixels, using a subsampling factor (e.g., $f_c = 2$) to limit noise amplification [S5, unofficial].

### Speculative Macrocell Grid Traversal
An extension of macrocell grid traversal that advances each ray through up to $N_{Spec}$ visible blocks instead of just one, recording multiple block IDs to increase GPU utilization and terminate rays in fewer passes [S6]. The kernel is run over all $w \times h$ pixels; terminated rays exit early [S6]. Calculate offset $o = O_{Act}[ray] \times N_{Spec}$ [S6]. Write up to $N_{Spec}$ visible block IDs into $R_{BID}$ starting at $o$ [S6]. If the ray exits the volume early, fill remaining $R_{BID}$ entries with $UINT\_MAX$ [S6]. Write $N_{Spec}$ entries of the ray ID into $R_{ID}$ starting at $o$ [S6]. Save coarse and fine grid iterator states after $N_{Spec}$ visible blocks are found to resume traversal later [S6].

## Operating characteristics
-   **Time Complexity:** Build time is $O(N^3)$ for the fine grid, but the macrocell build is $O((N/M)^3)$ which is trivial [S2, S3]. Traversal time is reduced by skipping empty macrocells [S4, unofficial]. The overhead of checking macrocells is minimal [S2, S3].
-   **Memory Complexity:** Adds $O((N/M)^3)$ bits (or bytes) for the macrocell grid [G]. For $M=6$, this is roughly $1/216$ of the fine grid size, which is negligible [G].
-   **Measured Performance:** Approximately 30% improvement over single ray grids for medium-sized animated scenes [S2, S3].
-   **Strengths:**
    -   Trivial and cheap build process [S2, S3].
    -   Simple traversal logic [S2, S3].
    -   Low memory overhead [S2, S3].
    -   Effective for scenes with large empty regions [S2, S3].
-   **Limitations:**
    -   Fixed block size $M$ may not adapt to varying density [S2, S3].
    -   For smaller resolutions, savings are insufficient [S2, S3].
    -   For larger resolutions, probability of finding empty regions decreases [S2, S3].
    -   Not suitable for scenes with highly varying geometric density without additional robustness [S2, S3].
-   **When to Use:** Medium-sized animated scenes with significant empty space and uniform fine grid resolution [S2, S3].
-   **When Not to Use:** Scenes with highly varying density where fixed blocks are inefficient, or very small grids where overhead dominates [S2, S3].

## Background
Macrocell Grid Traversal was proposed by Parker et al. in 1999 [S1, S2, S3]. It is a simple hierarchical optimization to a base uniform grid, often used to apply grids to scalar volume fields [S2, S3]. The method was designed to formulate a viable grid traversal for medium-size animated scenes, balancing performance and build time [S2, S3]. Additional levels of macrocells could further improve performance for more complex models, but were not investigated in the original work [S2, S3].
