# Multi-resolution grids

Also called: Hierarchical voxel grids, JW89, Jevans and Wyvill method

## Overview
Multi-resolution grids (JW89) is a recursive hierarchical subdivision algorithm for ray tracing that integrates regular and adaptive spatial subdivision methods [S1]. It solves the problem of efficiently rendering scenes containing both large, regularly distributed objects and small, dense clusters by allowing variable resolution across the spatial domain [S1]. Unlike fixed-resolution grids or purely octree-based approaches, it uses a top-down build strategy where internal voxels maintain their own local sub-grids, enabling efficient traversal through deep recursion when paired with a hash-table indexing strategy [S1].

## How it works
**Inputs and Outputs**
*   **Input:** A set of geometric primitives (polygons) and a scene bounding box.
*   **Output:** A hierarchical grid data structure (root voxel) and a traversal state for ray intersection.

**Data Structures**
The structure is a loosely nested recursive grid [S1].
*   **Voxel:** The fundamental unit.
    *   **Type:** Enum { LEAF, INTERNAL }.
    *   **Leaf Voxel:** Contains a list of primitives (polygons) intersecting the voxel volume [S1].
    *   **Internal Voxel:** Contains a local voxel grid subdivision (child voxels) and a hash table mapping child coordinates to child voxel pointers [S1].
*   **Hash Table:** Used to maintain each non-empty internal voxel, allowing $O(1)$ access to child grids and enabling deep recursion without linear search overhead [S1].

**Build Process (Top-Down)**
All primitives are initially inserted into a single root voxel [S1]. The build process is top-down [S1]. The algorithm recursively subdivides internal voxels based on one of the following criteria [S1][S2, unofficial]:
1.  **Octree-like:** Subdivide into a $2 \times 2 \times 2$ grid (8 children).
2.  **Maximum Depth:** Stop subdivision when a predefined tree depth is reached.
3.  **Constant Resolution:** Fix the resolution of voxel subgrids to a specific value regardless of content density.
4.  **Variable (Adaptive) Resolution:** Subdivide based on occupancy or primitive count thresholds.

**Parameters**
*   Coarseness of the initial voxel grid.
*   Depth of adaptive subdivision trees.
*   Maximum number of polygons per voxel (termination criterion for leaf nodes) [S1].

**Traversal**
1.  Intersect ray with the root voxel AABB.
2.  If intersection fails, terminate.
3.  If the current voxel is a **Leaf**, test the ray against all primitives in the leaf's list.
4.  If the current voxel is **Internal**, use the hash table to locate the specific child voxel corresponding to the ray's current position.
5.  Recursively traverse the child voxel.
6.  Continue until a primitive intersection is found or the ray exits the structure.

**Pitfalls**
*   Without a good indexing strategy (such as the hash table used in JW89), it is not possible to use deep levels of recursion efficiently due to the cost of locating child nodes [S1].
*   Build cost is generally higher than general bottom-up strategies [S1].

## Operating characteristics
*   **Time Complexity:** Traversal is $O(\log N)$ in balanced cases, but depends heavily on the hash table lookup cost and recursion depth. Build time is higher than bottom-up strategies [S1].
*   **Memory Complexity:** Depends on the hash table overhead and the number of internal nodes. The hash table allows sparse storage of empty sub-grids but adds pointer overhead [S1].
*   **Strengths:** Efficiently handles mixed-scale scenes (large regular objects + small dense objects) [S1]. Reduces memory accesses by skipping empty regions via the hash table [S1].
*   **Limitations:** High build cost. Not well-suited for GPU computation due to branching and pointer chasing inherent in hash-table-based recursive traversal [S2, unofficial].
*   **When to use:** CPU-based ray tracing where scene geometry has significant scale variation and build time is not the primary bottleneck.
*   **When not to use:** GPU ray tracing (due to branching and memory access patterns) [S2, unofficial] or scenes requiring very fast build times.

## Background
The method was proposed by Jevans and Wyvill in 1989 [JW89]. It is described in detail in "A Survey on Exploiting Grids for Ray Tracing" [S1] and "Grids in Ray Tracing: A Comprehensive Survey" [S2, unofficial]. The approach integrates regular grid traversal with adaptive subdivision, offering a middle ground between uniform grids and octrees.
