# VolumeHDDA

Also called: VolumeHDDA< TreeT, RayT, 0 >
## Overview
VolumeHDDA is a specialized Hierarchical Digital Differential Analyzer (HDDA) for ray traversal against volume trees, specifically optimized for leaf node processing [S1, unofficial][S2, unofficial]. It builds on [Hierarchical Traversal](896-hierarchical-traversal.md) by providing a templated interface that decouples traversal logic from specific tree and ray implementations [S1, unofficial][S2, unofficial].
