# Ray-guided streaming with atomic bitfield marking

Also called: Atomic bitfield marking for streaming, rayVisited atomic buffer technique [S1, unofficial]

## Overview
This method tracks which finest-level brick cells have been visited by rays to enable selective streaming and refinement, preventing redundant data transfers when multiple rays share a cell [S1, unofficial]. It complements the static hierarchical skipping of its parent [XBrickMap](3116-xbrickmap.md) with dynamic visitation history stored in an atomic bitfield buffer [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Brick index `c` (converted to a 3D vector), grid dimensions `grid` (from the indirection texture), and the `rayVisited` atomic buffer [S1, unofficial].
*   **Output:** Updates the `rayVisited` buffer to mark the corresponding cell as visited [S1, unofficial].

**Data Structures:**
The `rayVisited` buffer is a storage buffer of type `array<atomic<u32>>` [S1, unofficial].
*   **Layout:** Word 0 is unused [S1, unofficial]. Cell index `i` corresponds to bit `i & 31` of word `1 + (i >> 5)` [S1, unofficial].
*   **Size:** The buffer must accommodate all finest-level bricks [S1, unofficial]. A single-word buffer disables the feature [S1, unofficial].

**Steps:**
1.  **Calculate Global Cell Index:** Convert the brick index `c` to a linear cell index: `cell = (c.z * grid.y + c.y) * grid.x + c.x` [S1, unofficial].
2.  **Map to Buffer:** Determine the word and bit within the `rayVisited` buffer: `word = 1u + (cell >> 5u)` and `bit = 1u << (cell & 31u)` [S1, unofficial].
3.  **Atomic Check and Set:** Perform an atomic read-modify-write [S1, unofficial]. If `word < words` (total words in buffer) and the bit is not set `(atomicLoad(&rayVisited[word]) & bit) == 0u`, set the bit using `atomicOr(&rayVisited[word], bit)` [S1, unofficial].

**Pseudocode:**
```python
def mark_brick_visited(c, grid, ray_visited, words):
    # c and grid are tuples/lists of 3 integers (x, y, z)
    cell = (c[2] * grid[1] + c[1]) * grid[0] + c[0]
    word_idx = 1 + (cell >> 5)
    bit_mask = 1 << (cell & 31)
    if word_idx < words:
        # Simulate atomic load and compare-and-swap for GPU context
        current_val = ray_visited[word_idx]
        if (current_val & bit_mask) == 0:
            ray_visited[word_idx] = current_val | bit_mask

def mark_iso_gradient_visited(c, grid, ray_visited, words):
    # Marks the center brick and its 6 axis-aligned neighbors
    mark_brick_visited(c, grid, ray_visited, words)
    neighbors = [
        (c[0]+1, c[1], c[2]), (c[0]-1, c[1], c[2]),
        (c[0], c[1]+1, c[2]), (c[0], c[1]-1, c[2]),
        (c[0], c[1], c[2]+1), (c[0], c[1], c[2]-1)
    ]
    for n in neighbors:
        mark_brick_visited(n, grid, ray_visited, words)
```

**Parameters:**
*   **Buffer Size:** Must accommodate all finest-level bricks [S1, unofficial].
*   **Word 0:** Always unused [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **ISO Gradient Sampling:** Gradient calculations may sample cells outside the volume (e.g., beyond clip planes) [S1, unofficial]. These cells must be marked as visited to remain eligible for refinement [S1, unofficial]. This is handled by `markIsoGradientVisited`, which marks the center brick and its 6 axis-aligned neighbors [S1, unofficial].
*   **Single-Word Buffer:** If the buffer has only one word, the feature is effectively off [S1, unofficial].
