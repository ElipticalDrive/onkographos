# Voxel Refraction & Total Internal Reflection Handling

Also called: Ray Refraction in Voxels, TIR Fallback

## Overview
This method modifies the ray direction upon entering a refractive voxel using Snell's law, with a fallback to the original direction if total internal reflection occurs to prevent infinite ray bouncing and performance degradation [S1, unofficial]. It builds on [Hierarchical DDA with Chunk Stepping](8591-hierarchical-dda-with-chunk-stepping.md) by handling the transition between chunks with varying refractive indices [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input**: Current ray state (`rayPos`, `rayDir`, `invRayDir`), voxel entry data (`voxel.normal`, `hitNormal`), previous voxel's refractive index (`lastVoxRefract`), and a boolean flag `enableRefraction` [S1, unofficial].
*   **Output**: Updated `rayDir`, `invRayDir`, and `rayPos` for continued traversal [S1, unofficial].

**Data Structures**
The method relies on the ray state maintained by the parent traversal algorithm [S1, unofficial]. Key fields include:
*   `rayPos`: `vec3` representing the current ray origin [S1, unofficial].
*   `rayDir`: `vec3` representing the current ray direction (normalized) [S1, unofficial].
*   `invRayDir`: `vec3` representing the inverse of the ray direction ($1/rayDir$), used for DDA stepping [S1, unofficial].
*   `lastSideDist`: `vec3` storing distances to the next voxel boundary along each axis, reset to zero upon refraction [S1, unofficial].
*   `lastVoxRefract`: `float` storing the refractive index of the previously traversed voxel. Default/reset value is $1.0$ [S1, unofficial].

**Steps**
1.  **Check Refraction Flag**: If `enableRefraction` is false, skip refraction logic [S1, unofficial].
2.  **Mark Refraction**: Set a flag `refracted = true` to indicate the ray has undergone refraction [S1, unofficial].
3.  **Advance Position**: Move the ray position to the exact entry point of the new voxel to avoid self-intersection artifacts. This is calculated by advancing along the current direction by the minimum distance to the nearest voxel boundary plus a small epsilon:
    $$ rayPos = rayPos + rayDir \times (\min(\min(lastSideDist.x, lastSideDist.y), lastSideDist.z) + \epsilon) $$
    where $\epsilon$ is a small constant to prevent precision errors [S1, unofficial].
4.  **Store Original Direction**: Save the current direction as `oldRayDir` for potential fallback [S1, unofficial].
5.  **Compute Surface Normal**: Determine the surface normal at the entry point. If the ray is entering from inside a voxel (indicated by the dot product of the negative voxel normal and ray direction being negative), flip the normal:
    $$ normal = \begin{cases} \text{normalize}(-voxel.normal) & \text{if } \text{dot}(-voxel.normal, rayDir) < 0.0 \\ hitNormal & \text{otherwise} \end{cases} $$
    [S1, unofficial].
6.  **Refract Direction**: Apply Snell's law using the `refract()` function, which takes the incident direction, the surface normal, and the refractive index ratio:
    $$ rayDir = \text{refract}(rayDir, normal, lastVoxRefract) $$
    [S1, unofficial].
7.  **Handle Total Internal Reflection (TIR)**: The `refract()` function returns a zero vector (`vec3(0.0)`) if TIR occurs. Check for this condition and revert to the original direction to prevent infinite recursion:
    $$ \text{if } rayDir == \text{vec3}(0.0) \text{ then } rayDir = oldRayDir $$
    [S1, unofficial].
8.  **Update Inverse Ray Direction**: Recalculate the inverse ray direction for the DDA algorithm:
    $$ invRayDir = 1 / rayDir $$
    [S1, unofficial].
9.  **Reinitialize DDA**: Reset `lastSideDist` to zero and reinitialize the DDA step parameters based on the new `rayDir` and `invRayDir` [S1, unofficial].

**Pseudocode**
```python
def handle_voxel_refraction(ray_pos, ray_dir, inv_ray_dir, last_side_dist, last_vox_refract, voxel_normal, hit_normal, enable_refraction):
    if not enable_refraction:
        return ray_pos, ray_dir, inv_ray_dir, last_side_dist

    # Mark as refracted
    refracted = True

    # Advance ray position to exact entry point
    min_dist = min(last_side_dist.x, last_side_dist.y, last_side_dist.z)
    epsilon = 1e-6  # Small constant to prevent precision errors
    ray_pos = ray_pos + ray_dir * (min_dist + epsilon)

    # Store original direction for TIR fallback
    old_ray_dir = ray_dir

    # Compute surface normal, flipping if entering from inside
    if dot(-voxel_normal, ray_dir) < 0.0:
        normal = normalize(-voxel_normal)
    else:
        normal = hit_normal

    # Refract ray direction using Snell's law
    ray_dir = refract(ray_dir, normal, last_vox_refract)

    # Handle Total Internal Reflection
    if ray_dir == vec3(0.0):
        ray_dir = old_ray_dir

    # Update inverse ray direction for DDA
    inv_ray_dir = 1.0 / ray_dir

    # Reinitialize DDA with new ray parameters
    # Reset lastSideDist to zero
    last_side_dist = vec3(0.0)
    
    # [G] Reinitialize DDA step sizes based on inv_ray_dir and voxel size.
    # Standard implementation: step = voxel_size * abs(inv_ray_dir)
    
    return ray_pos, ray_dir, inv_ray_dir, last_side_dist

def refract(I, N, eta):
    # I: incident direction, N: surface normal, eta: ratio of refractive indices (n1/n2)
    # Returns refracted direction or vec3(0.0) on TIR
    cos_theta = dot(N, I)
    sin_theta2 = 1.0 - cos_theta * cos_theta
    if sin_theta2 * eta * eta >= 1.0:
        return vec3(0.0)
    return I * eta + N * (cos_theta * eta - sqrt(1.0 - sin_theta2 * eta * eta))
```

**Parameters**
*   `lastVoxRefract`: Refractive index of the current/previous voxel, used in `refract()`. Default/reset value: $1.0$ [S1, unofficial].
*   `enableRefraction`: Boolean flag controlling whether refraction calculations are performed [S1, unofficial].

**Edge Cases and Pitfalls**
*   **Total Internal Reflection**: If the angle of incidence exceeds the critical angle, `refract()` returns a zero vector. Failing to check for this leads to infinite ray bouncing and performance degradation [S1, unofficial]. The method explicitly checks for `vec3(0.0)` and reverts to the old direction [S1, unofficial].
*   **Precision Errors**: Advancing the ray position requires a small epsilon ($\epsilon$) to prevent the ray from intersecting the same voxel again due to floating-point inaccuracies [S1, unofficial].
*   **Normal Orientation**: The normal must be correctly oriented based on whether the ray is entering from outside or inside the voxel to ensure correct refraction direction [S1, unofficial].
