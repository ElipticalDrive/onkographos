# DeepBrick

Also called: Deep Volume Raytracing

## Overview
DeepBrick is a ray-marching kernel for deep volume raytracing that samples volumetric data, handling empty space skipping and alpha accumulation [S1, unofficial]. It builds on [Sparse Voxel Traversal](1525-sparse-voxel-traversal.md) [G].

## How it works
**Inputs and Outputs:**
*   **Input:** Ray origin, direction, and t-range; VDB leaf node reference; voxel delta (`gvdb->vdel[0]`); world position increment (`wpt`) [S1, unofficial].
*   **Output:** `outBuf` with a layout of 10 floats per pixel: indices 0-2 for color, 3 for mask, 4-6 for normal, 7 for depth, 8-9 for flow [S1, unofficial].

**Data Structures:**
*   **Voxel Value (`val`):** A vector containing color components (`val.x`, etc.) and density/alpha (`val.w`) [S1, unofficial].
*   **Accumulated Color (`clr`):** A vector containing accumulated color components (`clr.x`, etc.) and current transmittance (`clr.w`) [S1, unofficial].
*   **Hit Point (`hit`):** A vector where `hit.x` stores the front hit point (initialized to 0 if not set) and `hit.y` stores the weighted mean depth [S1, unofficial].
*   **Fetched Color (`hclr`):** Temporary color value fetched from the voxel data [S1, unofficial].

**Parameters:**
*   `SCN_MINVAL`: Threshold for skipping empty voxels during initial traversal [S1, unofficial].
*   `SCN_ALPHACUT`: Threshold for stopping color accumulation based on current transmittance [S1, unofficial].
*   `MAX_ITER`: Maximum number of iterations allowed per ray [S1, unofficial].
*   `SCN_EXTINCT`: Extinction coefficient [S1, unofficial].
*   `SCN_ALBEDO`: Albedo multiplier [S1, unofficial].
*   `SCN_PSTEP`: Step size [S1, unofficial].

**Steps:**
1.  **Initialization:** Get the VDB leaf node using `getNode`. Compute the sample point in index coordinates `p` from world position `wp` and voxel delta `gvdb->vdel[0]`. Compute world increment `wpt`. Initialize `val` and `hclr` to zero. Initialize `clr` to zero with transmittance `clr.w = 1.0`. Record the front hit point `hit.x` if it is zero [S1, unofficial].
2.  **Empty Space Skipping:** Loop while `val.w < SCN_MINVAL`, `iter < MAX_ITER`, and `p` is within bounds: transfer the voxel value to `val`, advance `p`, `wp`, and `t.x`, and increment `iter` [S1, unofficial].
3.  **Color Accumulation:** Loop while `clr.w > SCN_ALPHACUT`, `iter < MAX_ITER`, and `p` is within bounds: perform an optional depth buffer test, transfer the voxel value to `val`, compute transmittance, update weighted mean depth `hit.y`, fetch color `hclr`, accumulate color, update transmittance, advance `p`, `wp`, and `t.x`, and increment `iter` [S1, unofficial].
4.  **Finalization:** Clamp final color and alpha [S1, unofficial].

**Formulas:**
*   Transmittance: $val.w = \exp(SCN\_EXTINCT \cdot val.w \cdot SCN\_PSTEP)$ [S1, unofficial].
*   Color accumulation: $clr.x += val.x \cdot clr.w \cdot (1 - val.w) \cdot SCN\_ALBEDO \cdot hclr.x$ [S1, unofficial].

**Pseudocode:**
```python
def deep_brick_raycast(ray_origin, ray_direction, ray_t_min, ray_t_max, vdb_leaf, voxel_delta, scn_minval, scn_alphacut, max_iter, scn_extinct, scn_albedo, scn_pstep):
    # Initialization [S1, unofficial]
    wp = ray_origin
    p = floor(wp / voxel_delta)  # [G]
    wpt = ray_direction * voxel_delta  # [G]
    t = ray_t_min
    val = vec4(0.0)
    hclr = vec4(0.0)
    clr = vec4(0.0, 0.0, 0.0, 1.0)  # Transmittance starts at 1.0 [S1, unofficial]
    hit = vec2(0.0)
    iter = 0

    # Empty Space Skipping [S1, unofficial]
    while iter < max_iter and is_within_bounds(p) and val.w < scn_minval:
        val = vdb_leaf.get_value(p)  # [G]
        p += wpt
        wp += wpt
        t += scn_pstep  # [G]
        iter += 1

    # Color Accumulation [S1, unofficial]
    while iter < max_iter and is_within_bounds(p) and clr.w > scn_alphacut:
        if wp.z > hit.x:  # [G] standard depth buffer test
            break

        val = vdb_leaf.get_value(p)  # [G]

        # Compute Transmittance [S1, unofficial]
        val.w = exp(scn_extinct * val.w * scn_pstep)

        # Update Weighted Mean Depth [G]
        hit.y = hit.y + (1.0 - val.w) * scn_pstep

        # Fetch Color [S1, unofficial]
        hclr = vdb_leaf.get_color(p)  # [G]

        # Accumulate Color [S1, unofficial]
        clr.x += val.x * clr.w * (1.0 - val.w) * scn_albedo * hclr.x
        clr.y += val.y * clr.w * (1.0 - val.w) * scn_albedo * hclr.y
        clr.z += val.z * clr.w * (1.0 - val.w) * scn_albedo * hclr.z

        # Update Transmittance [S1, unofficial]
        clr.w *= val.w

        # Advance [S1, unofficial]
        p += wpt
        wp += wpt
        t += scn_pstep  # [G]
        iter += 1

    # Finalization [S1, unofficial]
    clr = clamp(clr, 0.0, 1.0)

    # Write to output buffer (10 floats per pixel) [S1, unofficial]
    out_buf = [0.0] * 10
    out_buf[0:3] = clr[0:3]
    out_buf[3] = 1.0  # Mask [G]
    out_buf[4:7] = vec3(0.0, 0.0, 1.0)  # Normal [G]
    out_buf[7] = hit.y  # Depth [S1, unofficial]
    out_buf[8:10] = vec2(0.0, 0.0)  # Flow [G]

    return out_buf

def is_within_bounds(p):
    return 0 <= p.x < leaf_width and 0 <= p.y < leaf_height and 0 <= p.z < leaf_depth  # [G]
```

## Subtopics

### [Brick Traversal](4170-brick-traversal.md)
Brick Traversal is a ray-marching kernel that samples a volumetric brick texture, adjusts alpha and RGB values for variable step sizes, and composites the result into a destination color using front-to-back alpha blending. It accounts for a "sample ratio" ($r$) between the ray step and the brick's internal resolution to adjust sampling density across hierarchical levels. It is chosen when hierarchical brick structures are used to store volumetric data, allowing for efficient traversal and sampling at different resolutions.

### Node Processing Rules
Node Processing Rules define how different types of nodes in the hierarchical structure are handled during traversal [S2, unofficial]:
*   **Loaded Brick:** If the node is a brick with available data, perform regular ray-marching inside its data [S2, unofficial].
*   **Unloaded Brick:** If the brick is not loaded (e.g., dynamic loading failure), use the average color stored in the node and accumulate it based on the distance the ray travels through the brick (using pre-integration) [S2, unofficial].
*   **Empty Node:** If the node is empty, ignore it (skip processing) [S2, unofficial].
