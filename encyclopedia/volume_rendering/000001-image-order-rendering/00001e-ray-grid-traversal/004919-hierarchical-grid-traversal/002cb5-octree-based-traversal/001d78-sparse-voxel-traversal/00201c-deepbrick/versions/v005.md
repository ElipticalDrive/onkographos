# DeepBrick

Also called: Deep Volume Raytracing

## Overview
DeepBrick is a ray-marching kernel for deep volume raytracing that combines empty space skipping with front-to-back alpha blending to accumulate color and transmittance [S1, unofficial]. It is distinguished from standard sparse voxel traversal by its explicit support for deep rendering outputs (depth, flow) and its specific handling of hierarchical brick data loading and evaluation [S1, unofficial][S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Ray origin, ray direction, world position increment (`wpt`), voxel delta (`gvdb->vdel[0]`), and a pointer to the VDB leaf node [S1, unofficial].
*   **Output:** A buffer (`outBuf`) containing 10 floats per pixel: indices 0-2 for color, 3 for mask, 4-6 for normal, 7 for depth, 8-9 for flow [S1, unofficial].

**Data Structures:**
*   **VDB Leaf Node:** Accessed via `getNode` and contains the voxel data [S1, unofficial].
*   **Sample Point (`p`):** Index coordinates derived from the world position [S1, unofficial].
*   **Accumulators:**
    *   `val`: Vector holding voxel properties (density, color components) [S1, unofficial].
    *   `clr`: Accumulated color and transmittance [S1, unofficial].
    *   `hit`: Structure storing front hit point (`hit.x`) and weighted mean depth (`hit.y`) [S1, unofficial].

**Parameters:**
*   `SCN_MINVAL`: Threshold for skipping empty voxels during initial traversal [S1, unofficial].
*   `SCN_ALPHACUT`: Threshold for stopping color accumulation based on current transmittance [S1, unofficial].
*   `MAX_ITER`: Maximum iterations per ray [S1, unofficial].
*   `SCN_EXTINCT`: Extinction coefficient [S1, unofficial].
*   `SCN_ALBEDO`: Albedo multiplier [S1, unofficial].
*   `SCN_PSTEP`: Step size [S1, unofficial].

**Algorithm Steps:**

1.  **Initialization:** Get the VDB leaf node using `getNode` [S1, unofficial]. Compute the sample point in index coordinates `p` from the world position `wp` and voxel delta `gvdb->vdel[0]` [S1, unofficial]. Compute the world position increment `wpt` [S1, unofficial]. Initialize `val` and `hclr` (hit color) to zero [S1, unofficial]. Initialize `clr` (accumulated color/transmittance) to zero [S1, unofficial]. Record the front hit point `hit.x` if it is zero [S1, unofficial].
2.  **Empty Space Skipping:** Loop while `val.w < SCN_MINVAL`, `iter < MAX_ITER`, and `p` is within bounds [S1, unofficial]. Fetch the voxel value and update `val.w` (density) [S1, unofficial]. If `val.w < SCN_MINVAL`, advance `p`, `wp`, and `t.x` (ray parameter) [S1, unofficial]. Increment `iter` [S1, unofficial]. This loop skips voxels with negligible density [S1, unofficial].
3.  **Color Accumulation (Ray Marching):** Loop while `clr.w > SCN_ALPHACUT`, `iter < MAX_ITER`, and `p` is within bounds [S1, unofficial]. Perform an optional depth buffer test to cull rays that have already been occluded [S1, unofficial]. Transfer the current voxel's properties into `val` [S1, unofficial]. Compute the transmittance through the current voxel step [S1, unofficial]. Update `hit.y` using the transmittance and step size [S1, unofficial]. Fetch the voxel color into `hclr` [S1, unofficial]. Accumulate the color `clr` [S1, unofficial]. Update `clr.w` by multiplying with the new voxel transmittance [S1, unofficial]. Advance `p`, `wp`, and `t.x` [S1, unofficial]. Increment `iter` [S1, unofficial].
4.  **Finalization:** Clamp the final color and alpha values [S1, unofficial]. Write results to `outBuf` [S1, unofficial].

**Formulas:**
*   Transmittance is computed as $\tau = \exp(SCN\_EXTINCT \cdot val.w \cdot SCN\_PSTEP)$, where $val.w$ is the voxel density, $SCN\_EXTINCT$ is the extinction coefficient, and $SCN\_PSTEP$ is the step size [S1, unofficial]. (Note: The source reuses `val.w` for transmittance; this implementation renames it to $\tau$ to prevent variable reuse bugs.)
*   Color accumulation follows $clr.x += val.x \cdot clr.w \cdot (1 - \tau) \cdot SCN\_ALBEDO \cdot hclr.x$, where $val.x$ is the voxel color component, $clr.w$ is current transmittance, and $SCN\_ALBEDO$ is the albedo multiplier [S1, unofficial].

**Pseudocode:**
```python
import math

def deep_brick_raycast(ray_origin, ray_direction, vdb_leaf, out_buf, pixel_idx):
    # Constants
    SCN_MINVAL = 1e-6
    SCN_ALPHACUT = 0.01
    MAX_ITER = 1000
    SCN_EXTINCT = 1.0
    SCN_ALBEDO = 1.0
    SCN_PSTEP = 1.0  # Step size parameter
    
    # Initialization
    voxel_delta = vdb_leaf.vdel[0]
    wp = [ray_origin[i] for i in range(3)]
    wpt = [ray_direction[i] * voxel_delta for i in range(3)]
    p = [(wp[i] - vdb_leaf.origin[i]) / voxel_delta for i in range(3)]
    
    val = [0.0, 0.0, 0.0, 0.0]  # x,y,z,w
    clr = [0.0, 0.0, 0.0, 0.0]  # clr[3] is transmittance
    hclr = [0.0, 0.0, 0.0, 0.0]
    hit = [0.0, 0.0]            # hit[0] = front hit, hit[1] = weighted mean depth
    iter_count = 0
    
    # Fetch initial voxel
    val = get_voxel(vdb_leaf, p)
    
    # Step 1: Empty Space Skipping
    while val[3] < SCN_MINVAL and iter_count < MAX_ITER and is_in_bounds(p, vdb_leaf):
        p = [p[i] + 1.0 for i in range(3)]
        wp = [wp[i] + wpt[i] for i in range(3)]
        iter_count += 1
        val = get_voxel(vdb_leaf, p)
        
    # Step 2: Color Accumulation
    while clr[3] > SCN_ALPHACUT and iter_count < MAX_ITER and is_in_bounds(p, vdb_leaf):
        if depth_buffer_test(hit[1]):
            break
            
        val = get_voxel(vdb_leaf, p)
        
        # Compute transmittance (renamed from val.w to tau to fix variable reuse)
        tau = math.exp(SCN_EXTINCT * val[3] * SCN_PSTEP)
        
        # Update weighted mean depth
        hit[1] = hit[1] * clr[3] + (1.0 - tau) * wp[2]
        
        hclr = get_color(vdb_leaf, p)
        
        # Accumulate color (applied to x, y, z channels)
        for c in range(3):
            clr[c] += val[c] * clr[3] * (1.0 - tau) * SCN_ALBEDO * hclr[c]
            
        clr[3] *= tau
        
        p = [p[i] + 1.0 for i in range(3)]
        wp = [wp[i] + wpt[i] for i in range(3)]
        iter_count += 1
        
    # Finalization
    clr[0] = max(0.0, min(1.0, clr[0]))
    clr[1] = max(0.0, min(1.0, clr[1]))
    clr[2] = max(0.0, min(1.0, clr[2]))
    
    # Write to output buffer
    out_buf[pixel_idx * 10 + 0] = clr[0]
    out_buf[pixel_idx * 10 + 1] = clr[1]
    out_buf[pixel_idx * 10 + 2] = clr[2]
    out_buf[pixel_idx * 10 + 3] = 1.0 - clr[3]
    out_buf[pixel_idx * 10 + 7] = hit[1]

def get_voxel(leaf, p):
    # Standard voxel fetch operation
    return leaf.get_sample(p)

def is_in_bounds(p, leaf):
    # Standard bounds check
    return all(0 <= p[i] < leaf.dimensions[i] for i in range(3))

def depth_buffer_test(depth):
    # Standard depth test operation
    return depth < current_depth_buffer

def get_color(leaf, p):
    # Standard color fetch operation
    return leaf.get_color(p)
```

## Subtopics

### [Brick Traversal](4170-brick-traversal.md)
A ray-marching kernel that samples a volumetric brick texture, adjusts alpha and RGB values for variable step sizes, and composites the result into a destination color using front-to-back alpha blending. It accounts for a "sample ratio" ($r$) between the ray step and the brick's internal resolution to adjust sampling density across hierarchical levels.

### Node Processing Rules
Defines behavior based on node type [S2, unofficial]:
*   **Loaded Brick**: If the node is a brick with available data, perform regular ray-marching inside its data [S2, unofficial].
*   **Unloaded Brick**: If the brick is not loaded (e.g., dynamic loading failure), use the average color stored in the node and accumulate it based on the distance the ray travels through the brick (using pre-integration) [S2, unofficial].
*   **Empty Node**: If the node is empty, ignore it (skip processing) [S2, unofficial].

### Brick Evaluation
A GPU-based process for constructing distance fields within bricks [S3, unofficial]:
*   **Process**: Each brick is processed by one thread group (size $8^3 = 512$ threads) [S3, unofficial]. Each thread evaluates the edit list once to obtain a single sample [S3, unofficial].
*   **Evaluation**: Iterates through the index buffer of the brick, evaluating each edit at the thread's corresponding location in space [S3, unofficial]. Results are combined according to the CSG operation of each edit [S3, unofficial].
*   **Memory Optimization**: Edits are loaded into group-shared memory in chunks of 256 to speed up evaluation, as 1024 edits do not fit in shared memory [S3, unofficial]. Larger chunks limit occupancy; smaller chunks limit parallelism [S3, unofficial].
*   **Precision**: Brick pool format is 8-bit signed normalized values (256 possible values per voxel) [S3, unofficial]. Distance range is [-4, 4] voxels, where magnitude 1 corresponds to 4 voxels [S3, unofficial]. Surface representation precision is 1/32 of the brick size [S3, unofficial].

## Operating characteristics
*   **Time Complexity**: Linear with respect to the number of voxels traversed along the ray, optimized by empty space skipping and hierarchical brick structures [S1, unofficial][S3, unofficial].
*   **Memory Complexity**: Depends on the brick pool size and shared memory usage [S3, unofficial]. Shared memory usage is constrained to chunks of 256 edits to maintain occupancy [S3, unofficial].
*   **Strengths**: Efficient handling of sparse data via empty space skipping; support for deep rendering (depth/flow output); flexible handling of unloaded bricks via pre-integration [S1, unofficial][S2, unofficial].
*   **Limitations**: Requires careful tuning of thresholds (`SCN_MINVAL`, `SCN_ALPHACUT`); brick evaluation stalls if hierarchical construction is not complete [S3, unofficial]; shared memory constraints in brick evaluation limit parallelism [S3, unofficial].
*   **When to Use**: Suitable for real-time volume rendering of sparse, hierarchical voxel data where depth information is required [S1, unofficial][S3, unofficial].

## Background
DeepBrick is associated with deep volume raytracing techniques, often implemented in conjunction with VDB (Volume Database) structures [S1, unofficial]. The concept of "brick" traversal and hierarchical processing is detailed in research on interactive exploration of procedural volumes [S2, unofficial]. The specific brick evaluation method for signed distance fields (SDFs) was developed for real-time rendering applications, as described in dissertation work on modifiable SDFs [S3, unofficial].
