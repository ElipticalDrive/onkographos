# Sparse Point Cloud Tracer

Also called: Packed SPC Tracer

## Overview
The Sparse Point Cloud (SPC) Tracer is a ray-tracing method that intersects camera rays against SPC points located at grid cell centers without neural operations, returning the color of the nearest intersected cell [S1, unofficial]. It differs from siblings like [Voxel Grid Raycasting](2218-voxel-grid-raycasting.md) and [Cap Node Traversal](3003-cap-node-traversal.md) by treating the structure as discrete colored points rather than volumetric density or hierarchical brick structures [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs:** Camera rays, a Neural Field (`nef`) containing the SPC grid structure and color lookup, a background color (`bg_color`), and a Level of Detail index (`lod_idx`) [S1, unofficial].
*   **Outputs:** A `RenderBuffer` dataclass containing tensors for depth, hit status, RGB color, and alpha for each pixel [S1, unofficial].

**Data Structures**
*   **RaytraceResults:** A structure returned by the grid backend containing `ridx` (ray indices), `pidx` (point indices corresponding to SPC grid cells), and `depth` (intersection depths) [S1, unofficial].
*   **RenderBuffer:** A dataclass holding `depth` (shape `(N, 1)`), `hit` (shape `(N, bool)`), `rgb` (shape `(N, 3)`), and `alpha` (shape `(N, 1)`) [S1, unofficial].

**Parameters**
*   `bg_color`: Background color tuple, default `(0.0, 0.0, 0.0)` [S1, unofficial].
*   `lod_idx`: Level of Detail index for ray sampling. If `None`, defaults to `nef.grid.blas.max_level` [S1, unofficial].

**Steps**
1.  **Initialize LOD:** If `lod_idx` is `None`, set `lod_idx = nef.grid.blas.max_level` [S1, unofficial].
2.  **Ray-Grid Intersection:** Call `nef.grid.blas.raytrace(rays, lod_idx, with_exit=False)` to compute intersections between the input rays and the SPC grid points, returning `ridx`, `pidx`, and `depth` [S1, unofficial].
3.  **Identify First Hits:** Use `spc_render.mark_pack_boundaries(ridx)` to create a boolean mask for the first hit per ray, then extract `first_hits_point`, `first_hits_ray`, and `first_hits_depth` using this mask [S1, unofficial].
4.  **Retrieve Color:** Query the neural field `nef` with `first_hits_point.long()` and `channels='rgb'` to obtain the color of the intersected cell [S1, unofficial].
5.  **Initialize Output Buffers:** Create `depth` (zeros), `alpha` (ones for hit rays), `hit` (bool zeros), `rgb` (zeros), and `out_alpha` (zeros) tensors of appropriate sizes [S1, unofficial].
6.  **Assign Hit Data:** Set `depth[first_hits_ray.long()] = ray_depth`, `hit[first_hits_ray.long()] = alpha[..., 0] > 0.0`, `rgb[first_hits_ray.long(), :3] = color`, and `out_alpha[first_hits_ray.long()] = alpha` [S1, unofficial].
7.  **Return:** Return the populated `RenderBuffer` containing `depth`, `hit`, `rgb`, and `alpha` [S1, unofficial].

**Pseudocode**
```python
class Tensor:
    def __init__(self, shape, fill_value=0.0):
        self.shape = shape
        self.data = [fill_value] * shape[0] if len(shape) == 1 else [[fill_value] * shape[1] for _ in range(shape[0])]
    def __setitem__(self, key, value):
        self.data[key] = value
    def __getitem__(self, key):
        return self.data[key]
    def long(self):
        return Tensor(self.shape, [int(x) for x in self.data])

class RenderBuffer:
    def __init__(self, depth, hit, rgb, alpha):
        self.depth = depth
        self.hit = hit
        self.rgb = rgb
        self.alpha = alpha

def trace_sparse_point_cloud(rays, nef, spc_render, bg_color=(0.0, 0.0, 0.0), lod_idx=None):
    if lod_idx is None:
        lod_idx = nef.grid.blas.max_level

    results = nef.grid.blas.raytrace(rays, lod_idx, with_exit=False)
    ridx = results.ridx
    pidx = results.pidx
    depth = results.depth

    mask = spc_render.mark_pack_boundaries(ridx)
    first_hits_point = pidx[mask]
    first_hits_ray = ridx[mask]
    first_hits_depth = depth[mask]

    color = nef(first_hits_point.long(), channels='rgb')

    N = len(rays)
    out_depth = Tensor((N, 1), 0.0)
    out_hit = Tensor((N, 1), False)
    out_rgb = Tensor((N, 3), 0.0)
    out_alpha = Tensor((N, 1), 1.0)

    ray_indices_long = first_hits_ray.long()
    out_depth[ray_indices_long] = first_hits_depth
    out_hit[ray_indices_long] = out_alpha[ray_indices_long, 0] > 0.0
    out_rgb[ray_indices_long, :3] = color
    out_alpha[ray_indices_long] = out_alpha[ray_indices_long]

    return RenderBuffer(out_depth, out_hit, out_rgb, out_alpha)
```

**Edge Cases and Pitfalls**
*   **No Hit:** If a ray does not intersect any SPC point, the corresponding pixel retains the initialized default values (depth 0, hit false, rgb 0) [S1, unofficial].

## Subtopics

### [Hashed-point searching](16743-hashed-point-searching.md)
Hashed-point searching is an acceleration technique for ray-tracing-based point cloud rendering that projects the 3D search space onto a 2D image plane for hash table lookup. It preserves all points per pixel rather than retaining only the nearest via a z-buffer, and uses an adaptive searching range based on point-to-viewpoint distance instead of a fixed radius or K-nearest neighbors. Choose it when swift location of point clouds near a camera ray is required without fixed-radius constraints.

## Background
The method originates from the NVIDIA Kaolin-Wisp framework, presented in a SIGGRAPH 2022 demo context [S1, unofficial]. It is designed to work with Structured Point Clouds (SPC) stored in a hierarchical grid format for efficient ray-tracing-based visualization [S1, unofficial].
