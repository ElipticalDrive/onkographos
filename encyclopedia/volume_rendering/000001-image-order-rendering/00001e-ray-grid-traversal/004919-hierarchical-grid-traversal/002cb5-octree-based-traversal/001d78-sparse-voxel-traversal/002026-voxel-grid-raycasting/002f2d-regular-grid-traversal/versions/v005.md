# Regular Grid Traversal

Also called: Grid Traversal Algorithm

## Overview
Regular Grid Traversal is a ray-grid traversal method that accelerates ray-primitive intersection tests by mapping primitives to a uniform 3D voxel grid and stepping through occupied cells using 3D-DDA [S1]. It solves the problem of testing every object for every ray by storing primitives in the cells they overlap, allowing rays to skip empty cells and only test primitives within intersected cells [S1]. Unlike [Voxel Grid Raycasting](2218-voxel-grid-raycasting.md) which typically renders volumetric density, this method accelerates geometric ray tracing by storing primitive pointers in voxels [S1]. It differs from [Hierarchical Grid Traversal](52-name.md) by using a flat, uniform structure without hierarchical levels, and from [Sparse Voxel Traversal](5228-sparse-voxel-tracing.md) by not using sparse data structures like octrees [S1].

## Shared principles
The family shares the mechanism of 3D Digital Differential Analyzer (3D-DDA) traversal to step through a uniform 3D grid [G]. The grid partitions the scene's Axis-Aligned Bounding Box (AABB) into $N_x \times N_y \times N_z$ uniform cells [S1]. Rays are advanced by calculating the distance to the next cell boundary along each axis, advancing the coordinate with the smallest distance [S1]. The traversal stops when the ray exits the grid bounds or finds a primitive intersection [S1].

### Algorithm
Given a parametric ray $r(t) = o + t \cdot d$ and a grid spanning $[p_1, p_2]$ with resolution $(N_x, N_y, N_z)$, the cell dimensions are $dx = (p_2.x - p_1.x)/N_x$, $dy = (p_2.y - p_1.y)/N_y$, $dz = (p_2.z - p_1.z)/N_z$. The algorithm computes the starting cell $(X, Y, Z)$, step directions, and initial distances to cell boundaries ($tMax$), then iteratively advances through cells until a hit is found or bounds are exceeded [S1].

```python
def regular_grid_traversal(ray_origin, ray_direction, grid_min, grid_max, grid_res):
    Nx, Ny, Nz = grid_res
    dx = (grid_max.x - grid_min.x) / Nx
    dy = (grid_max.y - grid_min.y) / Ny
    dz = (grid_max.z - grid_min.z) / Nz

    # Intersect ray with grid AABB to handle origins outside bounds [G]
    t_min, t_max = ray_aabb_intersect(ray_origin, ray_direction, grid_min, grid_max)
    if t_max < 0 or t_min > t_max:
        return None
    start_point = ray_origin + ray_direction * max(t_min, 0.0)

    X = int((start_point.x - grid_min.x) / dx)
    Y = int((start_point.y - grid_min.y) / dy)
    Z = int((start_point.z - grid_min.z) / dz)

    stepX = 1 if ray_direction.x > 0 else -1
    stepY = 1 if ray_direction.y > 0 else -1
    stepZ = 1 if ray_direction.z > 0 else -1

    if ray_direction.x > 0:
        tMaxX = ((X + 1) * dx + grid_min.x - start_point.x) / ray_direction.x
    elif ray_direction.x < 0:
        tMaxX = (X * dx + grid_min.x - start_point.x) / ray_direction.x
    else:
        tMaxX = float('inf')

    if ray_direction.y > 0:
        tMaxY = ((Y + 1) * dy + grid_min.y - start_point.y) / ray_direction.y
    elif ray_direction.y < 0:
        tMaxY = (Y * dy + grid_min.y - start_point.y) / ray_direction.y
    else:
        tMaxY = float('inf')

    if ray_direction.z > 0:
        tMaxZ = ((Z + 1) * dz + grid_min.z - start_point.z) / ray_direction.z
    elif ray_direction.z < 0:
        tMaxZ = (Z * dz + grid_min.z - start_point.z) / ray_direction.z
    else:
        tMaxZ = float('inf')

    tDeltaX = dx / abs(ray_direction.x) if ray_direction.x != 0 else float('inf')
    tDeltaY = dy / abs(ray_direction.y) if ray_direction.y != 0 else float('inf')
    tDeltaZ = dz / abs(ray_direction.z) if ray_direction.z != 0 else float('inf')

    while 0 <= X < Nx and 0 <= Y < Ny and 0 <= Z < Nz:
        # Process cell: test primitives stored in this cell [S1]
        if test_primitives_in_cell(X, Y, Z):
            return (X, Y, Z)

        if tMaxX < tMaxY:
            if tMaxX < tMaxZ:
                X += stepX
                tMaxX += tDeltaX
            else:
                Z += stepZ
                tMaxZ += tDeltaZ
        else:
            if tMaxY < tMaxZ:
                Y += stepY
                tMaxY += tDeltaY
            else:
                Z += stepZ
                tMaxZ += tDeltaZ

    return None
```

## Subtopics

### [Regular Grid](3950-regular-grid.md)
A standard implementation using a flat 1D array of primitive lists. It is optimal for uniform data distribution on GPUs due to cache efficiency [3950-regular-grid]. Choose it for general-purpose ray tracing where scene density is uniform.

### [Voxel-based Ray Tracing for GI and Specular Reflections](4091-voxel-based-ray-tracing-for-gi-and-specular-reflections.md)
Uses a 128³ occupancy grid to sample Light Propagation Volumes (LPV) for indirect lighting and reflection fallbacks [4091-voxel-based-ray-tracing-for-gi-and-specular-reflections]. Choose it for global illumination and screen-space reflection fallbacks.

### [Optimised Voxel Ray Marching](4240-optimised-voxel-ray-marching.md)
Optimizes traversal by caching chunk references and using bit-shifts for indexing, avoiding repeated calculations [4240-optimised-voxel-ray-marching]. Choose it for sparse voxel worlds with fixed chunk sizes to reduce computational overhead.

## Background
The method originates from early ray tracing research, where grid traversal algorithms were developed to determine cells traversed by a ray [S1]. The algorithm is similar to rasterization but must find all traversed cells, unlike Bresenham's line algorithm which produces visually acceptable lines without finding all pixels [S1]. The performance is modeled by two constants: $T_{setup}$ (setup time) and $T_{step}$ (time to advance between cells) [S1]. Low $T_{setup}$ benefits low-resolution grids, while high $T_{step}$ hurts performance in larger grids [S1].
