# Regular Grid Traversal

Also called: Grid Traversal Algorithm, 3D-DDA, Digital Differential Analyzer (for grids)

## Overview
Regular Grid Traversal is a ray-scene intersection acceleration technique that partitions a scene bounding box into a fixed-size 3D grid of cells, returning the sequence of cells intersected by a ray to minimize primitive intersection tests [S1]. It solves the problem of testing every object for every ray by only testing primitives stored in intersected cells [S1]. Unlike hierarchical structures (e.g., BVH, Octree) that partition primitives into disjoint sets, the Regular Grid partitions space into disjoint sub-blocks, allowing primitives to belong to multiple sub-blocks [3950-regular-grid.md]. It is distinguished by its constant-time access to cells and simple traversal logic, making it optimal for scenes with uniform data distribution or dynamic scenes requiring frequent rebuilds [3950-regular-grid.md].

## Shared principles
The method consists of two phases: Grid Construction (building the structure) and Ray Traversal (using the structure) [3950-regular-grid.md].

### Grid Construction
1. **Initialize:** Allocate a 1D array of size $N_x \times N_y \times N_z$ and set all entries to `NULL` [3950-regular-grid.md].
2. **Calculate Dimensions:** Compute voxel dimensions and their reciprocals for fast division:
    $$dx = \frac{p_2.x - p_1.x}{N_x}, \quad dx_{reci} = \frac{1}{dx}$$
    (Similarly for $dy, dz$ and $dy_{reci}, dz_{reci}$) [3950-regular-grid.md].
3. **Assign Primitives:** For each primitive $P$:
    *   Get its Axis-Aligned Bounding Box (AABB) $[b_{min}, b_{max}]$ [3950-regular-grid.md].
    *   Calculate the range of grid cells overlapping this AABB. Clamp coordinates to grid bounds $[0, N-1]$ to handle primitives outside or on the boundary [3950-regular-grid.md]:
        $$x_1 = \max(0, \lfloor (b_{min}.x - p_1.x) \cdot dx_{reci} \rfloor)$$
        $$x_2 = \min(N_x - 1, \lfloor (b_{max}.x - p_1.x) \cdot dx_{reci} \rfloor + 1)$$
        (Similarly for $y_1, y_2$ and $z_1, z_2$) [3950-regular-grid.md].
    *   Loop over all cells $(x, y, z)$ in the range $[x_1, x_2) \times [y_1, y_2) \times [z_1, z_2)$:
        *   Construct the AABB for the current cell [3950-regular-grid.md].
        *   If the primitive intersects the cell AABB, add the primitive to the cell's `ObjectList` [3950-regular-grid.md].
    *   *Note:* This mapping must be conservative; it may include more primitives than strictly necessary but never fewer [3950-regular-grid.md].

### Ray Traversal (3D-DDA)
The traversal identifies the sequence of cells intersected by a ray $r(t) = o + t \cdot d$ [S1].

1. **Ray-Grid Intersection:** Intersect the ray with the grid's bounding box $[p_1, p_2]$ to find entry $t_{enter}$ and exit $t_{exit}$ parameters [3950-regular-grid.md].
    *   If $t_{exit} < 0$ or $t_{enter} > t_{exit}$, the ray misses the grid [3950-regular-grid.md].
    *   If $t_{enter} < 0$, set $t_{enter} = 0$ (ray starts inside) [G].
2. **Initialization:**
    *   Determine the starting point on the ray: $start\_point = o + d \cdot t_{enter}$ [3950-regular-grid.md].
    *   Calculate the starting cell $(X, Y, Z)$:
        $$X = \lfloor \frac{start\_point.x - p_1.x}{dx} \rfloor$$
        (Similarly for $Y, Z$) [3950-regular-grid.md].
    *   Calculate step directions:
        $$stepX = \text{sign}(d.x) \quad (\text{1 if } d.x \ge 0, -1 \text{ otherwise})$$
        (Similarly for $stepY, stepZ$) [3950-regular-grid.md].
    *   Calculate delta distances (distance to cross one cell):
        $$tDeltaX = \frac{dx}{|d.x|} \text{ if } d.x \neq 0 \text{ else } \infty$$
        (Similarly for $tDeltaY, tDeltaZ$) [3950-regular-grid.md].
    *   Calculate initial boundary distances ($tMax$):
        *   If $d.x > 0$:
            $$tMaxX = \frac{(X + 1) \cdot dx + p_1.x - start\_point.x}{d.x}$$
        *   If $d.x < 0$:
            $$tMaxX = \frac{X \cdot dx + p_1.x - start\_point.x}{d.x}$$
        *   If $d.x = 0$: $tMaxX = \infty$ [3950-regular-grid.md].
        (Similarly for $tMaxY, tMaxZ$) [3950-regular-grid.md].
3. **Loop:**
    *   While $t_{enter} < t_{exit}$:
        *   Process the current cell $(X, Y, Z)$:
            *   If the cell is not empty, iterate through the `ObjectList` [3950-regular-grid.md].
            *   For each primitive, perform intersection test [3950-regular-grid.md].
            *   *Deduplication:* To avoid testing the same primitive multiple times (if it spans multiple cells), use a "Mailbox" system: assign each ray a unique ID, and store the ray ID in the primitive's intersection cache. Skip tests if the cache already contains the current ray ID [3950-regular-grid.md].
            *   *Correctness Check:* If an intersection is found but the point is outside the current cell, continue advancing [3950-regular-grid.md].
        *   Advance to the nearest boundary:
            *   Find axis $A \in \{X, Y, Z\}$ with minimum $tMaxA$ [3950-regular-grid.md].
            *   Update $tMaxA \leftarrow tMaxA + tDeltaA$ [3950-regular-grid.md].
            *   Update coordinate $A \leftarrow A + stepA$ [3950-regular-grid.md].
            *   If the new coordinate is out of bounds, terminate [3950-regular-grid.md].

import math

class ObjectList:
    def __init__(self, primitive, next_node):
        self.primitive = primitive
        self.next = next_node

def intersect_aabb(origin, direction, min_pt, max_pt):
    # Standard slab method for ray-AABB intersection [G]
    t_min = (min_pt.x - origin.x) / direction.x if direction.x != 0 else float('-inf')
    t_max = (max_pt.x - origin.x) / direction.x if direction.x != 0 else float('inf')
    if t_min > t_max: t_min, t_max = t_max, t_min
    ty_min = (min_pt.y - origin.y) / direction.y if direction.y != 0 else float('-inf')
    ty_max = (max_pt.y - origin.y) / direction.y if direction.y != 0 else float('inf')
    if ty_min > ty_max: ty_min, ty_max = ty_max, ty_min
    if t_min > ty_max or ty_min > t_max: return float('inf'), float('-inf')
    t_min = max(t_min, ty_min)
    t_max = min(t_max, ty_max)
    tz_min = (min_pt.z - origin.z) / direction.z if direction.z != 0 else float('-inf')
    tz_max = (max_pt.z - origin.z) / direction.z if direction.z != 0 else float('inf')
    if tz_min > tz_max: tz_min, tz_max = tz_max, tz_min
    if t_min > tz_max or tz_min > t_max: return float('inf'), float('-inf')
    return max(t_min, 0.0), t_max

def build_regular_grid(primitives, p1, p2, Nx, Ny, Nz):
    # 1. Initialize grid
    grid_size = Nx * Ny * Nz
    grid = [None] * grid_size
    
    # 2. Calculate dimensions
    dx = (p2.x - p1.x) / Nx
    dy = (p2.y - p1.y) / Ny
    dz = (p2.z - p1.z) / Nz
    dx_rec = 1.0 / dx
    dy_rec = 1.0 / dy
    dz_rec = 1.0 / dz
    
    # 3. Assign primitives
    for prim in primitives:
        b_min, b_max = prim.get_aabb()
        
        # Calculate cell range
        x1 = max(0, math.floor((b_min.x - p1.x) * dx_rec))
        x2 = min(Nx - 1, math.floor((b_max.x - p1.x) * dx_rec) + 1)
        y1 = max(0, math.floor((b_min.y - p1.y) * dy_rec))
        y2 = min(Ny - 1, math.floor((b_max.y - p1.y) * dy_rec) + 1)
        z1 = max(0, math.floor((b_min.z - p1.z) * dz_rec))
        z2 = min(Nz - 1, math.floor((b_max.z - p1.z) * dz_rec) + 1)
        
        # Loop over candidate cells
        for x in range(x1, x2):
            for y in range(y1, y2):
                for z in range(z1, z2):
                    idx = x + y * Nx + z * Nx * Ny
                    
                    # Check intersection with cell AABB
                    cell_min = (p1.x + x * dx, p1.y + y * dy, p1.z + z * dz)
                    cell_max = (p1.x + (x + 1) * dx, p1.y + (y + 1) * dy, p1.z + (z + 1) * dz)
                    
                    if prim.intersects_aabb(cell_min, cell_max):
                        # Add to list (prepend)
                        new_node = ObjectList(prim, grid[idx])
                        grid[idx] = new_node
                        
    return grid

def traverse_regular_grid(ray_origin, ray_dir, grid, p1, p2, Nx, Ny, Nz, ray_id):
    # 1. Ray-Grid Intersection
    t_enter, t_exit = intersect_aabb(ray_origin, ray_dir, p1, p2)
    if t_exit < 0 or t_enter > t_exit:
        return None
    
    # Clamp t_enter to 0 if ray starts inside
    t_enter = max(t_enter, 0.0)
    
    # 2. Initialization
    start_point = ray_origin + ray_dir * t_enter
    
    X = math.floor((start_point.x - p1.x) / ((p2.x - p1.x) / Nx))
    Y = math.floor((start_point.y - p1.y) / ((p2.y - p1.y) / Ny))
    Z = math.floor((start_point.z - p1.z) / ((p2.z - p1.z) / Nz))
    
    # Step directions
    step_x = 1 if ray_dir.x >= 0 else -1
    step_y = 1 if ray_dir.y >= 0 else -1
    step_z = 1 if ray_dir.z >= 0 else -1
    
    # Delta distances
    dx = (p2.x - p1.x) / Nx
    dy = (p2.y - p1.y) / Ny
    dz = (p2.z - p1.z) / Nz
    
    t_delta_x = dx / abs(ray_dir.x) if ray_dir.x != 0 else float('inf')
    t_delta_y = dy / abs(ray_dir.y) if ray_dir.y != 0 else float('inf')
    t_delta_z = dz / abs(ray_dir.z) if ray_dir.z != 0 else float('inf')
    
    # Initial tMax
    if ray_dir.x > 0:
        t_max_x = ((X + 1) * dx + p1.x - start_point.x) / ray_dir.x
    elif ray_dir.x < 0:
        t_max_x = (X * dx + p1.x - start_point.x) / ray_dir.x
    else:
        t_max_x = float('inf')
        
    if ray_dir.y > 0:
        t_max_y = ((Y + 1) * dy + p1.y - start_point.y) / ray_dir.y
    elif ray_dir.y < 0:
        t_max_y = (Y * dy + p1.y - start_point.y) / ray_dir.y
    else:
        t_max_y = float('inf')
        
    if ray_dir.z > 0:
        t_max_z = ((Z + 1) * dz + p1.z - start_point.z) / ray_dir.z
    elif ray_dir.z < 0:
        t_max_z = (Z * dz + p1.z - start_point.z) / ray_dir.z
    else:
        t_max_z = float('inf')
        
    # 3. Loop
    while t_enter < t_exit:
        # Check bounds
        if not (0 <= X < Nx and 0 <= Y < Ny and 0 <= Z < Nz):
            break
            
        idx = X + Y * Nx + Z * Nx * Ny
        node = grid[idx]
        
        # Process cell
        while node is not None:
            prim = node.primitive
            # Mailbox check: skip if already tested for this ray
            if not prim.is_tested_for(ray_id):
                hit = test_primitive(prim, ray_origin, ray_dir, ray_id)
                if hit is not None:
                    return hit
            node = node.next
            
        # Advance to nearest boundary
        if t_max_x < t_max_y:
            if t_max_x < t_max_z:
                t_max_x += t_delta_x
                X += step_x
            else:
                t_max_z += t_delta_z
                Z += step_z
        else:
            if t_max_y < t_max_z:
                t_max_y += t_delta_y
                Y += step_y
            else:
                t_max_z += t_delta_z
                Z += step_z
                
    return None

## Subtopics

### [Regular Grid](3950-regular-grid.md)
A Regular Grid is a spatial acceleration structure that divides a scene bounding box into a fixed-size 3D grid of cells (voxels) to reduce the number of ray-primitive intersection tests. It solves the problem of testing every object for every ray by only testing primitives stored in cells intersected by the ray. Unlike hierarchical structures (e.g., BVH, Octree) that partition primitives into disjoint sets, the Regular Grid partitions space into disjoint sub-blocks, allowing primitives to belong to multiple sub-blocks. It is distinguished by its constant-time access to cells and simple traversal logic, making it optimal for scenes with uniform data distribution or dynamic scenes requiring frequent rebuilds.

### [Voxel-based Ray Tracing for GI and Specular Reflections](4091-voxel-based-ray-tracing-for-gi-and-specular-reflections.md)
Voxel-based Ray Tracing is a global illumination (GI) and specular reflection fallback method that performs Digital Differential Analyzer (DDA) traversal through a sparse, block-occupancy voxel grid to sample indirect lighting and environment reflections. It serves as a drop-in replacement for Screen-Space Ray Tracing (SSRT) for GI and a fallback for Screen-Space Reflections (SSR) when screen-space coverage is incomplete, combining sky occlusion with Light Propagation Volumes (LPV) colour bleeding. Unlike standard voxel raycasting which often relies on volume density, this method operates on a binary block-occupancy grid to determine surface hits for lighting queries.

### [Optimised Voxel Ray Marching](4240-optimised-voxel-ray-marching.md)
Optimised Voxel Ray Marching is a ray traversal algorithm for voxel-based scenes that uses fixed-length steps along the ray to traverse a 3D grid of voxels, checking for occupancy at each step. It solves the problem of inefficiently stepping through empty space in large voxel worlds by optimizing memory access patterns, specifically by keeping block lookups within the current working chunk to minimize bitshifts, masks, and multiplication operations. It sets itself apart from [Regular Grid Traversal](5939-regular-grid-traversal.md) by using a chunked memory layout that reduces boundary calculation overhead, and from [Chunked Voxel Traversal](8311-chunked-voxel-traversal.md) by relying on fixed-size inner grids which simplifies implementation and memory layout.

## Background
The Regular Grid Traversal algorithm is a foundational technique in ray tracing, historically developed to determine the cells traversed by a ray [S1]. Algorithms for grid traversal are quite similar to rasterization algorithms (such as Bresenham line draw algorithm [Bre65]), but unlike Bresenham which produces visually acceptable lines in the shortest time without finding all pixels traversed, grid traversal must find all cells traversed by the ray segment [S1]. A naive 3D extension of Bresenham is not suitable as a grid traversal algorithm [S1].

Traversal time is a critical metric, often modeled by two constants: $T_{setup}$ (time to setup traversal algorithm) and $T_{step}$ (time spent to advance from a cell to its neighbor without checking intersection) [S1]. An algorithm with low $T_{setup}$ usually performs better for low resolution grids, whereas high $T_{step}$ provides bad performance for larger grids [S1].
