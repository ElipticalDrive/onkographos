# Regular Grid Traversal

Also called: Grid Traversal Algorithm, Uniform Grid Traversal, 3D-DDA

## Overview
Regular Grid Traversal is a ray-scene intersection acceleration technique that partitions the scene's Axis-Aligned Bounding Box (AABB) into a fixed-size 3D grid of uniform cells (voxels) [S1]. It solves the problem of $O(N)$ ray-primitive intersection tests by allowing rays to skip empty cells, testing only primitives stored in intersected voxels . Unlike hierarchical structures (e.g., BVH, Octree) that partition primitives into disjoint sets, the Regular Grid partitions space into disjoint sub-blocks, meaning a single primitive can belong to multiple cells . It is distinguished by its constant-time cell access, simple traversal logic, and suitability for dynamic scenes due to its linear build time, though it suffers from high memory overhead in sparse scenes .

## Shared principles
The method relies on a uniform 3D grid where each cell corresponds to a fixed volume in world space. The grid is defined by its resolution $(N_x, N_y, N_z)$ and the scene bounding box $[p_1, p_2]$.

**Grid Construction:**
1.  **Cell Dimensions:** The size of each voxel is calculated as:
    $$dx = \frac{p_2.x - p_1.x}{N_x}, \quad dy = \frac{p_2.y - p_1.y}{N_y}, \quad dz = \frac{p_2.z - p_1.z}{N_z}$$
    [S1]
2.  **Primitive Assignment:** For each primitive $P$, its AABB $[b_{min}, b_{max}]$ is computed. The range of grid cells overlapping this AABB is determined by clamping the floor of the normalized coordinates to the grid bounds:
    $$x_1 = \max(0, \lfloor \frac{b_{min}.x - p_1.x}{dx} \rfloor), \quad x_2 = \min(N_x - 1, \lfloor \frac{b_{max}.x - p_1.x}{dx} \rfloor + 1)$$
    (Similarly for $y$ and $z$) [S1].
3.  **Storage:** Each cell stores a list of primitives that overlap it. This mapping must be conservative; it may include more primitives than strictly necessary but never fewer .

**Ray Traversal (3D-DDA):**
The traversal identifies the sequence of cells intersected by a ray $r(t) = o + t \cdot d$.
1.  **Ray-Grid Intersection:** The ray is first intersected with the grid's bounding box to find entry $t_{enter}$ and exit $t_{exit}$ parameters [S1]. If $t_{exit} < 0$ or $t_{enter} > t_{exit}$, the ray misses the grid [S1].
2.  **Initialization:** The starting cell $(X, Y, Z)$ is determined by the ray origin (clamped to $t_{enter}$):
    $$X = \lfloor \frac{(o + d \cdot \max(t_{enter}, 0.0)).x - p_1.x}{dx} \rfloor$$
    (Similarly for $Y, Z$) [S1].
3.  **Step Parameters:**
    *   **Step Direction:** $stepX = \text{sign}(d.x)$ (1, -1, or 0) [S1].
    *   **Delta Distance:** The distance along the ray to cross one full cell:
        $$tDeltaX = \frac{dx}{|d.x|} \text{ if } d.x \neq 0 \text{ else } \infty$$
        (Similarly for $Y, Z$) [S1].
    *   **Initial Boundary Distance ($tMax$):** The distance to the next cell boundary in the current direction. For $d.x > 0$:
        $$tMaxX = \frac{(X + 1) \cdot dx + p_1.x - start\_point.x}{d.x}$$
        For $d.x < 0$:
        $$tMaxX = \frac{X \cdot dx + p_1.x - start\_point.x}{d.x}$$
        (Similarly for $Y, Z$) [S1].
4.  **Loop:** The algorithm advances to the nearest boundary by comparing $tMaxX, tMaxY, tMaxZ$. The axis with the minimum $tMax$ is incremented by its step direction, and its $tMax$ is increased by $tDelta$ [S1]. This continues until the ray exits the grid or a hit is found.

**Performance Metrics:**
Traversal cost is modeled by two constants [S1]:
*   $T_{setup}$: Time to initialize traversal variables. Lower is better for low-resolution grids.
*   $T_{step}$: Time to advance from one cell to a neighbor. High $T_{step}$ degrades performance in large grids.

## Subtopics

### [Regular Grid](3950-regular-grid.md)
The standard implementation using a 1D array of linked lists for primitive storage. It handles primitives spanning multiple cells via a "Mailbox" system (ray ID caching) to avoid redundant intersection tests. It is suitable for general-purpose ray tracing where dynamic updates are frequent.

### [Voxel-based Ray Tracing for GI and Specular Reflections](4091-voxel-based-ray-tracing-for-gi-and-specular-reflections.md)
Adapts the traversal for real-time global illumination (GI) and specular reflections. It uses a binary occupancy grid combined with Light Propagation Volumes (LPV) data, serving as a fallback for Screen-Space Ray Tracing (SSRT) and Screen-Space Reflections (SSR). It samples LPV data at hit positions to retrieve indirect lighting.

### [Optimised Voxel Ray Marching](4240-optimised-voxel-ray-marching.md)
A CPU-oriented variant for large voxel worlds (e.g., Minecraft-like). It organizes voxels into fixed-size "chunks" (e.g., $32^3$) to skip empty space efficiently. It maintains a reference to the current chunk and updates it only upon crossing chunk boundaries, minimizing arithmetic operations compared to pure grid traversal.

## Background
The Regular Grid is one of the earliest acceleration structures for ray tracing. The traversal algorithm is closely related to 3D line rasterization algorithms, specifically noting that a naive 3D extension of Bresenham's algorithm is unsuitable because it does not find all traversed pixels/cells [S1]. The survey by [S1] categorizes these algorithms and highlights the trade-off between setup time and step time. The method is widely used in voxel-based rendering, real-time GI, and as a baseline for more complex hierarchical structures.
