# Voxel Path Tracing with Chunked Storage

Also called: Chunked Voxel Path Tracing, Per-voxel lighting path tracing

## Overview
Voxel Path Tracing with Chunked Storage is a per-voxel lighting method that decouples illumination calculation from the rendering pipeline to enable dynamic streaming and instant map edits [S1, unofficial]. Unlike standard ray-traced voxel rendering which computes lighting per-pixel per-frame, this method accumulates diffuse lighting over multiple frames while calculating direct and specular components via fixed uniform sampling, allowing the scene to remain interactive during edits [S1, unofficial]. It builds on [Chunked Voxel Traversal](8311-chunked-voxel-traversal.md) by organizing voxels into 8x8x8 chunks to facilitate efficient skipping of empty space and targeted updates [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
*   **Voxel Map:** A sparse grid of chunks. Each chunk contains a 3D array of voxels.
*   **Lighting Request Buffer:** A `std430` buffer (`binding 3`) containing `uint chunkIndices[]`. Each entry packs a chunk index (28 bits) and a voxel offset within that chunk (4 bits) [S1, unofficial].
*   **Scene Data:**
    *   `mapSize`: Uniform `uvec3` defining the global map dimensions [S1, unofficial].
    *   `sunDir`: Normalized vector pointing to the sun [S1, unofficial].
    *   `camPos`: Camera position [S1, unofficial].
    *   `skyCubemap`: Uniform `samplerCube` for sky color sampling when `useCubemap` is true [S1, unofficial].
*   **Parameters:**
    *   `numDiffuseSamples`: Number of diffuse samples per frame [S1, unofficial].
    *   `maxDiffuseSamples`: Maximum stored diffuse samples [S1, unofficial].
    *   `diffuseBounceLimit`: Max diffuse bounces [S1, unofficial].
    *   `specularBounceLimit`: Max specular bounces [S1, unofficial].
    *   `shadowSoftness`: Shadow softness factor [S1, unofficial].
    *   `useCubemap`: Boolean flag for sky sampling [S1, unofficial].
    *   `CHUNK_SIZE`: `ivec3(8, 8, 8)` [S1, unofficial].
    *   `INV_CHUNK_SIZE`: `vec3(0.125, 0.125, 0.125)` [S1, unofficial].
    *   `HALF_INV_CHUNK_SIZE`: `vec3(0.0625, 0.0625, 0.0625)` [S1, unofficial].
    *   `EPSILON`: `0.0001` [S1, unofficial].

**Outputs:**
*   **Voxel Storage:** Each voxel stores `normal` (vec3), `material` (uint), `albedo` (vec3), `specLight` (vec3), and `diffuseLight` (vec3) [S1, unofficial].

### Data Structures
**Voxel Struct:**
```glsl
struct Voxel {
    vec3 normal;
    uint material;
    vec3 albedo;

    vec3 diffuseLight;
};
```

**Chunk Indices Buffer Layout:**
Each `uint` in `lightingRequestBuffer` contains:
*   Bits 0-3: Voxel offset within the chunk (4 bits).
*   Bits 4-31: Chunk index (28 bits).
[S1, unofficial]

**Sphere Points:**
A constant array `spherePoints[15]` containing 15 pre-defined `vec3` points on the unit sphere, used for soft shadows and rough reflections [S1, unofficial].

### Algorithm Steps

1.  **Initialization:**
    *   Set `enableRefraction = false` [S1, unofficial].
    *   Determine the chunk index from the work group ID: `mapIndex = chunkIndices[gl_WorkGroupID.x] >> 4` [S1, unofficial].
    *   Retrieve the chunk's world position: `mapPos = ivec3(chunks[mapIndex].pos.xyz)` [S1, unofficial].
    *   Calculate the local voxel number: `voxNum = gl_LocalInvocationID.x + (chunkIndices[gl_WorkGroupID.x] & 15) * gl_WorkGroupSize.x` [S1, unofficial].
    *   Get the chunk-local voxel position: `chunkPos = get_voxel_position(mapIndex, voxNum)` [S1, unofficial].
    *   **Edge Case:** If `!in_chunk_bounds(chunkPos)`, terminate the shader invocation [S1, unofficial].

2.  **Voxel Decompression:**
    *   Calculate global voxel index: `voxelIndex = map[mapIndex].voxelIndex + voxNum` [S1, unofficial].
    *   Decompress the voxel data from the map to retrieve `thisVoxel` and `thisMaterial` [S1, unofficial].
    *   Determine indirect samples: `indirectSamples = float(min(chunks[mapIndex].numIndirectSamples, maxDiffuseSamples))` [S1, unofficial].

3.  **Ray Position Calculation:**
    *   If `indirectSamples == 0`, set `firstSample = true` [S1, unofficial].
    *   Calculate ray origin in world space: `rayPos = INV_CHUNK_SIZE * chunkPos + mapPos + HALF_INV_CHUNK_SIZE` [S1, unofficial].
    *   Adjust `rayPos` based on surface normal to avoid self-intersection: `rayPos += (HALF_INV_CHUNK_SIZE - vec3(EPSILON)) * thisVoxel.normal` [S1, unofficial].

4.  **Specular Lighting Calculation:**
    *   Condition: If `thisMaterial.specular > 0.0` AND `dot(viewDir, thisVoxel.normal) < 0.0` AND `thisMaterial.reflectType <= 1`:
        *   Calculate reflection vector: `reflected = reflect(normalize(viewDir), thisVoxel.normal)` [S1, unofficial].
        *   Initialize `specLight = vec3(0.0)` [S1, unofficial].
        *   Loop `i` from 0 to 14:
            *   Sample direction: `specDir = normalize(reflected * thisMaterial.shininess + spherePoints[i]) + EPSILON` [S1, unofficial].
            *   Call `specular_ray(..., specLight)` (see below) [S1, unofficial].
        *   Average result: `specLight /= 15.0` [S1, unofficial].

5.  **Diffuse Lighting Calculation:**
    *   Condition: If `thisMaterial.specular < 1.0`:
        *   Initialize `diffuseLight = vec3(0.0)` [G].
        *   Add ambient contribution: `diffuseLight += ambientStrength` [S1, unofficial].
        *   Loop `i` from 0 to `numDiffuseSamples - 1`:
            *   Call `diffuse_ray(..., diffuseLight)` (see below) [S1, unofficial].
            *   Call `shadow_ray(..., diffuseLight)` (see below) [S1, unofficial].
        *   Accumulate with history: `diffuseLight = (thisVoxel.diffuseLight * indirectSamples + diffuseLight) / (indirectSamples + numDiffuseSamples)` [S1, unofficial].

6.  **Output Storage:**
    *   Clamp `specLight` and `diffuseLight` to `[0, 1]` [S1, unofficial].
    *   Convert `diffuseLight` to 16-bit per channel: `writeDiffuseLight = uvec3(round(diffuseLight * 65535))` [S1, unofficial].
    *   Split into upper/lower bytes and store `albedo`, `specLight`, `diffuseLight` into `voxels[voxelIndex]` using `encode_uint_RGBA` [S1, unofficial].

### Helper Functions

#### `shadow_ray`
Calculates direct sunlight contribution.
1.  Determine shadow direction:
    *   If `firstSample` is true: `updatedSunDir = sunDir + EPSILON` [S1, unofficial].
    *   Else: `updatedSunDir = normalize(sunDir * shadowSoftness + rand_unit_sphere(seed)) + EPSILON` [S1, unofficial].
2.  Trace shadow: Call `step_map(updatedSunDir, 1 / updatedSunDir, rayPos, true, -1.0, tempNormal, hitVoxel, colorAdd, colorMult)` [S1, unofficial].
3.  If `step_map` returns `false` (no hit):
    *   Add sunlight: `color += sunStrength * colorMult + colorAdd` [S1, unofficial].

#### `specular_ray`
Calculates specular bounces.
1.  Loop `i` from 0 to `specularBounceLimit`:
    *   Trace ray: Call `step_map(rayDir, 1 / rayDir, rayPos, true, -1.0, tempNormal, hitVoxel, colorAdd, colorMult)` [S1, unofficial].
    *   **Hit Case:**
        *   Get `hitMapIndex` [S1, unofficial].
        *   If `map[hitMapIndex].flags & 4` is true, set `map[hitMapIndex].flags |= 4` [S1, unofficial].
        *   Check adjacency: `dist = abs(floor(rayPos * CHUNK_SIZE) - floor(lastPos * CHUNK_SIZE))` [S1, unofficial].
        *   If `dot(dist, dist) <= 1`, return (stop tracing) [S1, unofficial].
        *   Update diffuse component: `hitVoxel.diffuseLight *= 1.0 - hitMaterial.specular` [S1, unofficial].
        *   If `hitMaterial.emissive`:
            *   Add to color: `color += (hitVoxel.albedo * colorMult + colorAdd) * multiplier * albedo` [S1, unofficial].
            *   Return [S1, unofficial].
        *   Update specular multiplier: `multiplier *= hitVoxel.albedo * colorMult * hitMaterial.specular` [S1, unofficial].
        *   Update state: `reflectType`, `lastPos` [S1, unofficial].
        *   Reflect ray: `rayDir = reflect(rayDir, hitVoxel.normal)` [S1, unofficial].

#### `diffuse_ray`
Calculates indirect diffuse bounces.
1.  Loop `i` from 0 to `diffuseBounceLimit`:
    *   Determine direction `dir`:
        *   If `i > 0` and `(rand(seed + diffuseBounceLimit + i) + 1) * 0.5 < hitMaterial.specular`:
            *   `dir = normalize(reflect(lastDir, hitNormal) * hitMaterial.shininess + rand_unit_sphere(time + i))` [S1, unofficial].
        *   Else if `firstSample`:
            *   `dir = normalize(hitNormal) + EPSILON` [S1, unofficial].
        *   Else:
            *   `dir = normalize(hitNormal + rand_unit_sphere(seed + i)) + EPSILON` [S1, unofficial].
    *   Trace ray: Call `step_map(dir, 1 / dir, rayPos, true, -1.0, tempNormal, hitVoxel, colorAdd, colorMult)` [S1, unofficial].
    *   Update `hitNormal` and `hitMaterial` [S1, unofficial].
    *   **Hit Case:**
        *   Check adjacency: `dist = abs(floor(lastPos * CHUNK_SIZE) - floor(rayPos * CHUNK_SIZE))` [S1, unofficial].
        *   If `dot(dist, dist) < 1`, return [S1, unofficial].
        *   If `hitMaterial.emissive`:
            *   Add to color: `color += newColor * (hitVoxel.albedo * colorMult + colorAdd)` [S1, unofficial].
            *   Return [S1, unofficial].
        *   Else:
            *   Update color: `newColor *= (hitVoxel.albedo * colorMult + colorAdd)` [S1, unofficial].
    *   **Miss Case:**
        *   Add sky contribution: `color += (newColor * max(dot(dir, sunDir), 0.0) * sunStrength * colorMult + colorAdd)` [S1, unofficial].
        *   Return [S1, unofficial].

import math

# Constants from evidence
CHUNK_SIZE = 8
INV_CHUNK_SIZE = 0.125
HALF_INV_CHUNK_SIZE = 0.0625
EPSILON = 0.0001

# Standard math helpers
def vec3(x, y, z): return (x, y, z)
def ivec3(x, y, z): return (int(x), int(y), int(z))
def dot(a, b): return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]
def normalize(v):
    l = math.sqrt(dot(v, v))
    return (v[0]/l, v[1]/l, v[2]/l)
def reflect(I, N):
    return (I[0] - 2*dot(I, N)*N[0], I[1] - 2*dot(I, N)*N[1], I[2] - 2*dot(I, N)*N[2])
def abs_vec(v): return (abs(v[0]), abs(v[1]), abs(v[2]))
def floor_vec(v): return (math.floor(v[0]), math.floor(v[1]), math.floor(v[2]))
def clamp_vec(v, mn, mx): return (max(mn, min(mx, v[0])), max(mn, min(mx, v[1])), max(mn, min(mx, v[2])))

# Random number generation from evidence
def rand(seed):
    return (math.sin(seed) * 43758.5453) % 1.0 * 2.0 - 1.0

def rand_unit_sphere(seed):
    while True:

        if dot(point, point) < 1.0:

def specular_ray(ray_dir, ray_pos, hit_voxel, hit_material, bounce_limit, sphere_points, map_data, chunks_data, last_pos):
    color = vec3(0.0, 0.0, 0.0)
    multiplier = 1.0
    current_last_pos = last_pos

    for _ in range(bounce_limit):
        temp_normal = vec3(0.0, 0.0, 0.0)
        hit_voxel_out = decompress_voxel(map_data, 0)

            if map_data[hit_map_index].flags & 4:
                map_data[hit_map_index].flags |= 4

                return color

            hit_voxel_out.diffuse_light = (hit_voxel_out.diffuse_light[0] * (1.0 - hit_material.specular), hit_voxel_out.diffuse_light[1] * (1.0 - hit_material.specular), hit_voxel_out.diffuse_light[2] * (1.0 - hit_material.specular))

                         color[2] + new_color[2] * (hit_voxel_out.albedo[2] * color_mult + color_add[2]))
                return color
            else:
                new_color = (new_color[0] * (hit_voxel_out.albedo[0] * color_mult + color_add[0]),
                             new_color[1] * (hit_voxel_out.albedo[1] * color_mult + color_add[1]),
                             new_color[2] * (hit_voxel_out.albedo[2] * color_mult + color_add[2]))
        else:
            color = (color[0] + (new_color[0] * max(dot(dir, sun_dir), 0.0) * sun_strength * color_mult + color_add[0]),
                     color[1] + (new_color[1] * max(dot(dir, sun_dir), 0.0) * sun_strength * color_mult + color_add[1]),
                     color[2] + (new_color[2] * max(dot(dir, sun_dir), 0.0) * sun_strength * color_mult + color_add[2]))
            return color

    return color

def shadow_ray(ray_pos, hit_voxel, hit_material, sun_dir, shadow_softness, first_sample, seed, map_data):
    if first_sample:
        updated_sun_dir = (sun_dir[0] + EPSILON, sun_dir[1] + EPSILON, sun_dir[2] + EPSILON)
    else:
        sphere_sample = rand_unit_sphere(seed)
        updated_sun_dir = normalize((sun_dir[0]*shadow_softness + sphere_sample[0], sun_dir[1]*shadow_softness + sphere_sample[1], sun_dir[2]*shadow_softness + sphere_sample[2]))
        updated_sun_dir = (updated_sun_dir[0] + EPSILON, updated_sun_dir[1] + EPSILON, updated_sun_dir[2] + EPSILON)

    temp_normal = vec3(0.0, 0.0, 0.0)
    hit_voxel_out = decompress_voxel(map_data, 0)
    color_add = vec3(0.0, 0.0, 0.0)
    color_mult = 1.0

    inv_sun_dir = (1.0/updated_sun_dir[0], 1.0/updated_sun_dir[1], 1.0/updated_sun_dir[2])
    hit = step_map(updated_sun_dir, inv_sun_dir, ray_pos, True, -1.0, temp_normal, hit_voxel_out, color_add, color_mult)

    if not hit:
        return (sun_strength * color_mult + color_add[0], sun_strength * color_mult + color_add[1], sun_strength * color_mult + color_add[2])
    return vec3(0.0, 0.0, 0.0)

## Operating characteristics
*   **Time Complexity:** Lighting is computed per-voxel for visible chunks. Diffuse lighting accumulates over frames, reducing per-frame cost after convergence. Specular and direct lighting are calculated instantly per frame using fixed sample counts [S1, unofficial].
*   **Memory Complexity:** Requires storage for `normal`, `material`, `albedo`, `specLight`, and `diffuseLight` per voxel. Diffuse light is stored in 16-bit per channel format [S1, unofficial].
*   **Strengths:** Enables dynamic streaming and fast map edits because only edited chunks need re-uploading. Empty chunks are skipped during ray casting [S1, unofficial].
*   **Limitations:** Diffuse lighting requires multiple frames to converge. The method is a work-in-progress and may lack polish [S1, unofficial].
*   **When to use:** Interactive voxel environments requiring dynamic editing and real-time lighting updates for direct/specular components, with acceptable latency for diffuse convergence [S1, unofficial].
