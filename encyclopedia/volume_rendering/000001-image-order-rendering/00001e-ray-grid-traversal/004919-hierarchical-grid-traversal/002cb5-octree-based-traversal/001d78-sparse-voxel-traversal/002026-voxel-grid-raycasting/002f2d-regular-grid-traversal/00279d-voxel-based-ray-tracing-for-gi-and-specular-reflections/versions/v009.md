# Voxel-based Ray Tracing for GI and Specular Reflections

Also called: ApplyVoxelRT, Voxel RT, VoxelDDA, VoxelReflectionFallback

## Overview
This method implements a voxel-based ray tracing system using 3D Digital Differential Analyzer (3D-DDA) traversal through a block-occupancy grid to provide global illumination (GI) and specular reflection fallbacks [S1, unofficial]. It serves as a drop-in replacement for Screen-Space Ray Tracing (SSRT) for indirect lighting and a fallback for Screen-Space Reflections (SSR) when coverage is incomplete [S1, unofficial]. Unlike standard voxel raycasting which often relies on volume density, this method operates on a binary occupancy grid combined with Light Propagation Volumes (LPV) data, distinguishing it from [Optimised Voxel Ray Marching](4240-optimised-voxel-ray-marching.md) which typically handles continuous density fields [S1, unofficial].

## How it works
The method extends the parent [Regular Grid Traversal](5939-regular-grid-traversal.md) by integrating specific lighting lookups and hemisphere sampling for GI, and a single-pass specular trace for reflections.

### Inputs and Outputs
*   **Inputs:**
    *   Ray origin $o$ and direction $d$ (normalized).
    *   Voxel grid resolution: $128^3$ blocks [S1, unofficial].
    *   Grid bounds: $[p_1, p_2]$ (feet-relative world-space coordinates) [S1, unofficial].
    *   LPV (Light Propagation Volumes) texture/buffer containing indirect color data [S1, unofficial].
    *   Sky color contribution.
*   **Outputs:**
    *   Indirect lighting color (for GI).
    *   Reflected color (for specular fallback).
    *   Hit position (face-center) and surface normal (axis-aligned) [S1, unofficial].

### Data Structures
*   **Voxel Grid (`imgVoxelMask`):** A $128 \times 128 \times 128$ block-occupancy grid stored in a shader image buffer [S1, unofficial]. Populated each frame in the shadow pass [S1, unofficial].
*   **LPV Data:** Stored in a texture or image buffer, accessible via `GL_ARB_shader_image_load_store` [S1, unofficial].

### Parameters
*   `VOXEL_GI_SAMPLES`: Number of cosine-weighted hemisphere rays for GI sampling. Default: 4 [S1, unofficial].
*   `VOXEL_GI_STEPS`: Maximum number of steps in voxel GI ray traversal [S1, unofficial].
*   `VOXEL_REFL_STEPS`: Maximum number of steps in voxel reflection ray traversal [S1, unofficial].
*   `VOXEL_RT_REFLECTIONS`: Feature flag to enable specular reflection fallback. Commented out by default [S1, unofficial].
*   `VOXEL_GI`: Indirect effect mode identifier, value 6 [S1, unofficial].

### Algorithm Steps

1.  **VoxelDDA (Traversal):** Perform 3D DDA traversal over the $128^3$ grid.
    *   Handle grid bounds and sign-safe boundary distances [S1, unofficial].
    *   Apply **Ray Bias**: Add a small epsilon to the ray origin along the direction vector to avoid self-intersection and handle near-parallel rays gracefully [S1, unofficial].
    *   Return the hit face-center position and the axis-aligned normal of the face entered [S1, unofficial].

2.  **SampleVoxelLighting (GI Lookup):**
    *   At the hit position from `VoxelDDA`, sample the LPV data.
    *   Offset the sample location by half a block in front of the hit face (along the normal) to obtain the indirect color from propagated light [S1, unofficial].

3.  **ApplyVoxelRT (GI Integration):**
    *   Trace `VOXEL_GI_SAMPLES` cosine-weighted hemisphere rays around the surface normal [S1, unofficial].
    *   For each ray, use `VoxelDDA` to find intersections.
    *   If a hit occurs, retrieve color via `SampleVoxelLighting`.
    *   Blend the sky contribution with the LPV color bounce at hit surfaces [S1, unofficial].

4.  **VoxelReflectionFallback (Specular):**
    *   Activated only when screen-space reflection misses (indicated by `environmentReflection.a < 1`) [S1, unofficial].
    *   Perform a single specular DDA ray trace using `VoxelDDA`.
    *   Scale the resulting voxel lighting to match typical sky-reflection brightness ranges to avoid visual mismatch [S1, unofficial].
    *   Fill in the LPV-sampled voxel color if the trace succeeds [S1, unofficial].

### Pseudocode

```python
def voxel_dda(ray_origin, ray_direction, grid_min, grid_max, grid_res, ray_bias_epsilon):
    """
    Perform 3-D DDA traversal over the voxel grid.
    Returns: (hit_position, hit_normal) or None if no hit.
    """
    # Apply ray bias to avoid self-intersection [S1, unofficial]
    biased_origin = ray_origin + ray_direction * ray_bias_epsilon
    
    # Initialize traversal using parent Regular Grid Traversal logic
    # (See 5939-regular-grid-traversal.md for tMax, tDelta, step initialization)
    X, Y, Z, tMaxX, tMaxY, tMaxZ, tDeltaX, tDeltaY, tDeltaZ, stepX, stepY, stepZ = \
        init_regular_grid_traversal(biased_origin, ray_direction, grid_min, grid_max, grid_res)
    
    max_steps = 128 * 3  # Approximate max steps for 128^3 grid diagonal [G]
    steps = 0
    
    while 0 <= X < grid_res.x and 0 <= Y < grid_res.y and 0 <= Z < grid_res.z:
        steps += 1
        if steps > max_steps:
            return None
            
        # Check occupancy in imgVoxelMask [S1, unofficial]
        if is_voxel_occupied(X, Y, Z):
            # Calculate face-center position and normal based on which boundary was crossed
            # This requires tracking which tMax triggered the step
            hit_pos, hit_normal = calculate_face_hit(biased_origin, ray_direction, X, Y, Z, 
                                                     tMaxX, tMaxY, tMaxZ, stepX, stepY, stepZ)
            return hit_pos, hit_normal
            
        # Advance to next cell
        if tMaxX < tMaxY:
            if tMaxX < tMaxZ:
                X += stepX
                tMaxX += tDeltaX
            else:
                Z += stepZ
                tMaxZ += tDeltaZ
        else:
            if tMaxY < tMaxZ:
                Y += stepY
                tMaxY += tDeltaY
            else:
                Z += stepZ
                tMaxZ += tDeltaZ
                
    return None

def sample_voxel_lighting(hit_position, hit_normal, lpv_buffer):
    """
    Read LPV data half a block in front of the hit face.
    """
    # Offset by half block size in the direction of the normal
    block_size = (grid_max - grid_min) / grid_res
    sample_pos = hit_position + hit_normal * (block_size / 2.0)
    
    # Sample LPV buffer at sample_pos [S1, unofficial]
    indirect_color = texture_lpv(lpv_buffer, sample_pos)
    return indirect_color

def apply_voxel_rt(surface_normal, sky_color, lpv_buffer):
    """
    Drop-in replacement for ApplySSRT().
    Traces VOXEL_GI_SAMPLES cosine-weighted hemisphere rays.
    """
    num_samples = VOXEL_GI_SAMPLES # Default 4 [S1, unofficial]
    total_indirect = vec3(0.0)
    
    for i in range(num_samples):
        # Generate cosine-weighted hemisphere ray
        ray_dir = cosine_weighted_hemisphere_sample(surface_normal)
        
        # Trace ray
        hit_pos, hit_normal = voxel_dda(surface_position, ray_dir, grid_min, grid_max, 
                                        grid_res, ray_bias_epsilon)
        
        if hit_pos is not None:
            # Get LPV color at hit
            lpv_color = sample_voxel_lighting(hit_pos, hit_normal, lpv_buffer)
            total_indirect += lpv_color
        else:
            # No hit: contribute sky color (sky occlusion) [S1, unofficial]
            total_indirect += sky_color
            
    # Average samples
    return total_indirect / num_samples

def voxel_reflection_fallback(view_dir, normal, environment_reflection, lpv_buffer):
    """
    Single specular DDA ray trace.
    Activated only when environment_reflection.a < 1 [S1, unofficial].
    """
    # Reflect view direction
    reflect_dir = reflect(-view_dir, normal)
    
    # Trace single ray
    hit_pos, hit_normal = voxel_dda(surface_position, reflect_dir, grid_min, grid_max, 
                                    grid_res, ray_bias_epsilon)
    
    if hit_pos is not None:
        lpv_color = sample_voxel_lighting(hit_pos, hit_normal, lpv_buffer)
        # Scale voxel lighting to match typical sky-reflection brightness [S1, unofficial]
        scaled_color = scale_to_sky_brightness(lpv_color)
        return scaled_color
    else:
        return environment_reflection # Fallback to existing env reflection if miss
```

### Edge Cases and Pitfalls
*   **Hardware Support:** Requires LPV and `GL_ARB_shader_image_load_store` support. Gracefully degrades to SSRT if these are not met [S1, unofficial].
*   **Precision Artifacts:** Division-by-zero or NaN sources in related passes (e.g., TAA resolve) can produce black pixel artifacts, especially on hardware with aggressive FP16 FTZ behavior (e.g., NVIDIA RTX 5000 series) [S1, unofficial]. Epsilon guards are required in tonemapping and blending calculations [S1, unofficial].
*   **Self-Intersection:** Near-parallel rays or origins inside voxels require ray bias to prevent immediate re-intersection [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of steps in the DDA traversal. For GI, complexity is $O(S \cdot N)$ where $S$ is `VOXEL_GI_SAMPLES` (default 4) [S1, unofficial].
*   **Memory Complexity:** $O(V)$ for the voxel grid, where $V = 128^3$ blocks [S1, unofficial]. No additional buffers are needed beyond the existing LPV and mask textures [S1, unofficial].
*   **Strengths:** Provides global illumination and reflections in scenes where screen-space methods fail (e.g., off-screen objects, low coverage) [S1, unofficial]. Drop-in replacement for SSRT [S1, unofficial].
*   **Limitations:** Relies on the quality of the LPV propagation. Blocky artifacts may appear at low resolutions. Requires specific hardware features (`GL_ARB_shader_image_load_store`) [S1, unofficial].
*   **When to Use:** When screen-space GI/Reflections are insufficient or unavailable, and LPV is already in use.
*   **When Not to Use:** On hardware lacking required GL extensions, or when high-fidelity, smooth reflections are required without the blocky nature of voxel data.

## Background
This method was implemented by nyzxor as a pull request to the Eclipse-Shader (an edit of Chocapic13 V9 / Bliss) for Minecraft, integrated via the Iris shader mod [S1, unofficial]. It was added to provide an alternative global illumination method and a fallback for specular reflections [S1, unofficial]. The implementation utilizes the existing 128³ block-occupancy voxel grid (`imgVoxelMask`) populated in the shadow pass, requiring no new buffers or passes [S1, unofficial].
