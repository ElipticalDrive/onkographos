# Sparse Voxel Octree Path Tracing

Also called: CPU Sparse Voxel Ray Tracing, CPU-based SVO rendering, Octree path tracing

## Overview
Sparse Voxel Octree (SVO) Path Tracing is a CPU-based rendering technique that traverses a sparse voxel octree (or DAG) structure to compute physically based lighting via recursive path tracing [S1, S2, unofficial]. It solves the problem of rendering complex, high-resolution voxel-based scenes efficiently by skipping empty space and only processing occupied nodes, writing the accumulated radiance to a texture for display [S1, unofficial]. Unlike its siblings which focus on specific traversal optimizations (e.g., parametric or iterative steps), this method integrates the traversal directly into a Monte Carlo path tracer with Russian roulette termination, diffuse/specular bounces, and material properties (metalness, roughness, emission) stored in the leaf nodes [S2, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
*   **SVO Data Structure:** A flat array `_tree` of `uint32_t` nodes, a root index, and scene metadata (camera position, rotation) [S1, S2, unofficial].
*   **Camera:** Position (`Vector3<f64>`), Rotation (`Quaternion<f64>`), and field of view bounds (`fxmin`, `fxmax`, `fymin`, `fymax`) [S2, unofficial].
*   **Parameters:** `NumSamples` (samples per pixel, 0-250), `MaxBounces` (0-100), `EMISSIVE_SCALE` (15.0), `EPSILON` (0.000002) [S1, S2, unofficial].

**Outputs:**
*   **Image Buffer:** An array of `Pixel` structs (RGBA, scaled to `u16::MAX`) representing the final rendered image [S1, S2, unofficial].

### Data Structures
**Node Layout (`uint32_t`):**
*   **Bits 0-16 (17 bits):** Child pointer offset. Used to jump to children in the flat array [S1, unofficial].
*   **Bits 17-31 (15 bits):** Mask/Type indicator.
    *   **Internal Node:** Initialized to `0x0000FFFF` (binary `...1111 1111 1111 1111`) [S1, unofficial].
    *   **Leaf Node:** Marker value `0x00004200` (binary `...0100 0010 0000 0000`) [S1, unofficial].
    *   *Note:* Source [S2, unofficial] uses a separate `flags` field where `flags & 1 != 0` indicates a leaf, suggesting a variation in implementation details, but the flat array structure remains consistent [S1, S2, unofficial].

**Scene State (`VoxelScene`):**
*   `tree`: Reference to the voxel tree data.
*   `root`: Index of the root node.
*   `camera_position`: `Vector3<f64>`.
*   `camera_rotation`: `Quaternion<f64>` [S2, unofficial].

**Traversal State:**
*   `RayTarget`: Struct containing `distance` (f64), `node` (reference), `nodelocation` (Vector3<f64>), `hitpos` (Vector3<f64>) [S2, unofficial].
*   `RayResult`: Struct containing `colour` (Vector3<f64>), `emission` (f64), `metalness` (f64), `roughness` (f64), `hitlocation` (Vector3<f64>), `hitnormal` (Vector3<f64>), `dead` (boolean/usize) [S2, unofficial].

### Algorithm Steps

#### 1. Tree Generation (Initialization)
The octree is built as a full binary tree up to `maxDepth` (typically 3), stored in a flat array [S1, unofficial].

1.  Initialize `stack` with `{index: 0, depth: 0}`.
2.  Push root node to `_tree` with value `0x0000FFFF`.
3.  Loop while `stack` is not empty:
    a.  Pop `current` from `stack`.
    b.  Calculate `offset = _tree.size() - current.index`.
    c.  Update `_tree[current.index]` by OR-ing the offset shifted left by 17 bits: `_tree[current.index] |= offset << 17`.
    d.  Update `current.index += offset`.
    e.  If `current.depth < maxDepth`:
        i.  Increment `depth`.
        ii. Push 8 children to `_tree` with value `0x0000FFFF`.
        iii. Push 8 stack entries with indices `index + (8 - i)` for `i` in 0..7 and `depth`.
    f.  Else (Leaf):
        i.  Push 8 children to `_tree` with value `0x00004200`.

#### 2. Ray Tracing Loop
For each pixel, cast multiple rays (samples) to reduce noise [S2, unofficial].

1.  Initialize `colour_accumulator = (0, 0, 0)`.
2.  Loop `rpp` times (rays per pixel):
    a.  Generate random offset within pixel bounds: `dx = random_mix(fxmin, fxmax)*2-1`, `dy = random_mix(fymin, fymax)*2-1`.
    b.  Compute ray direction: `raydir = camrot * new_vec(dx, dy, 1.0)`.
    c.  Compute path color: `path_color = do_ray(raydir, camera_position, MaxBounces, tree, root)`.
    d.  Accumulate: `colour_accumulator += path_color`.
3.  Average: `final_colour = colour_accumulator / rpp`.
4.  Tone Mapping/Output:
    a.  `alpha = max(final_colour.r, final_colour.g, final_colour.b)`.
    b.  If `alpha > 0`, `final_colour /= alpha`.
    c.  Scale to `u16::MAX` and store in pixel buffer [S2, unofficial].

#### 3. Recursive Path Tracing (`do_ray`)
This function computes the color contribution of a ray, handling bounces and Russian roulette [S2, unofficial].

**Inputs:** `start` (origin), `dir` (direction), `bouncesleft` (int), `tree`, `root`.
**Output:** `Vector3<f64>` color.

1.  **Base Case:** If `bouncesleft <= 0`, return `(0, 0, 0)` [S2, unofficial].
2.  **Intersection:**
    a.  Cast ray against SVO: `result = cast_ray_voxel(start, dir, root, tree)`.
    b.  If `result.dead == 0` (miss), return `(0, 0, 0)` [S2, unofficial].
3.  **Material Properties:** Extract `colour`, `emission`, `metalness`, `roughness` from the hit leaf node [S2, unofficial].
4.  **Emissive Contribution:**
    `emissive_colour = colour * emission * EMISSION_SCALE` [S2, unofficial].
5.  **Bounce Calculation:**
    a.  Generate new direction: `newdir = rand_dir_from_surf(hitnormal)` [S2, unofficial].
    b.  **Russian Roulette / Specular vs Diffuse:**
        i.  If `random() > 0.5 * (1.0 - metalness)`:
            *   **Specular Bounce:**
                *   Compute Fresnel: `fresnel = fresnel(-dir, hitnormal) * (1.0 - roughness)`.
                *   Compute Specular Weight: `specular = fresnel * ((0.5 * (1.0 - metalness)) + (0.98 * metalness))`.
                *   Compute Specular Highlight: `specular_highlight = ((new_vec(0.5, 0.5, 0.5) * (1.0 - metalness)) + (colour * metalness)) * specular`.
                *   Reflect direction: `reflected = reflect(dir, hitnormal)`.
                *   Mix with roughness: `bounce_dir = (newdir * roughness) + (reflected * (1.0 - roughness))`.
                *   Recurse: `specular_colour = (1.0 - emission) * point_wise_mul(specular_highlight, do_ray(bounce_dir, hitlocation, bouncesleft - 1, tree, root))`.
                *   Return `emissive_colour + specular_colour`.
        ii. Else:
            *   **Diffuse Bounce:**
                *   Compute Diffuse Weight: `diffuse = 0.5 * (1.0 - metalness)`.
                *   Recurse: `diffuse_colour = (1.0 - emission) * diffuse * point_wise_mul(colour, do_ray(newdir, hitlocation, bouncesleft - 1, tree, root))`.
                *   Return `emissive_colour + diffuse_colour`.

#### 4. Voxel Traversal (`cast_ray_voxel` / `cast_ray_v_box`)
This is the core traversal logic, often implemented iteratively or recursively to find the closest leaf [S1, S2, unofficial].

**Iterative Approach (Source [S2, unofficial] logic adapted):**
1.  Initialize `size = 1.0`, `activenodes = [root]`, `nodelocations = [(0,0,0)]`, `x = 0`.
2.  **Loop:**
    a.  While `x < activenodes.len()`:
        i.  For each active node `i`, compute AABB intersection distance: `distance = cast_ray_v_box(start - nodelocations[i], dir, size)`.
        ii. Store in `targets`. Increment `x`.
    b.  Sort `targets` by distance ascending.
    c.  For each target `h`:
        i.  If `distance < MAX` and valid:
            *   If Leaf (`flags & 1 != 0`):
                *   If `distance < closestleaf.distance`:
                    *   Update `closestleaf` with node data (color, emission, etc.).
                    *   `hitlocation = nodelocation + hitpos`.
                    *   `hitnormal = normalize(get_biggest_axis(hitpos))`.
                    *   Mark as hit.
            *   If Internal Node:
                *   For each child `c` in 0..8:
                    *   If `childmask & (1 << c) != 0`:
                        *   Push child location: `nodelocation + (oct_byte_to_vec(child) * size / 2.0)`.
                        *   Push child node index.
    d.  Drain processed nodes: `activenodes.drain(0..x)`, `nodelocations.drain(0..x)`, `x = 0`.
    e.  Halve size: `size /= 2.0`.
3.  Return `closestleaf` if found, else `dead_ray()` [S2, unofficial].

**Stack-based Approach (Source [S1, unofficial] logic):**
Uses a stack to manage traversal state, handling valid internal nodes, leaf nodes, and empty space by casting rays to the next occupied voxel [Parent].

### Pseudocode
```python
def sparse_voxel_octree_path_tracing(scene, width, height, rpp, max_bounces):
    # Initialize output buffer
    image = [[(0.0, 0.0, 0.0, 0.0) for _ in range(width)] for _ in range(height)]
    
    # Camera setup
    cam_pos = scene.camera_position
    cam_rot = scene.camera_rotation
    fxmin, fxmax, fymin, fymax = -1.0, 1.0, -1.0, 1.0 # Typical FOV bounds
    
    for y in range(height):
        for x in range(width):
            color_accum = (0.0, 0.0, 0.0)
            for _ in range(rpp):
                # Generate pixel sample
                dx = random.uniform(fxmin, fxmax) * 2.0 - 1.0
                dy = random.uniform(fymin, fymax) * 2.0 - 1.0
                
                # Transform to world space
                ray_dir = apply_rotation(cam_rot, (dx, dy, 1.0))
                ray_dir = normalize(ray_dir)
                
                # Trace path
                path_color = do_ray(ray_dir, cam_pos, max_bounces, scene.tree, scene.root)
                color_accum = add_vectors(color_accum, path_color)
            
            # Average samples
            avg_color = divide_scalar(color_accum, rpp)
            
            # Tone mapping / Alpha handling
            alpha = max(avg_color.r, avg_color.g, avg_color.b)
            if alpha > 0.0:
                avg_color = divide_scalar(avg_color, alpha)
            
            # Store result (scaled to u16)
            image[y][x] = (
                clamp(avg_color.r * 65535, 0, 65535),
                clamp(avg_color.g * 65535, 0, 65535),
                clamp(avg_color.b * 65535, 0, 65535),
                65535
            )
    return image

def do_ray(origin, direction, bounces_left, tree, root):
    if bounces_left <= 0:
        return (0.0, 0.0, 0.0)
    
    # Cast ray to find closest intersection
    hit = cast_ray_voxel(origin, direction, tree, root)
    
    if hit.dead:
        return (0.0, 0.0, 0.0)
    
    # Extract material properties from leaf node
    color = hit.node.colour
    emission = hit.node.emission
    metalness = hit.node.metalness
    roughness = hit.node.roughness
    
    # Emissive contribution
    emissive = multiply_scalar(color, emission * 15.0) # EMISSION_SCALE = 15.0
    
    # Russian Roulette / Bounce Type
    rand_val = random.uniform(0.0, 1.0)
    
    if rand_val > 0.5 * (1.0 - metalness):
        # Specular Bounce
        fresnel = fresnel_func(-direction, hit.hitnormal) * (1.0 - roughness)
        specular_weight = fresnel * ((0.5 * (1.0 - metalness)) + (0.98 * metalness))
        specular_highlight = multiply_scalar(
            add_vectors(
                multiply_scalar((0.5, 0.5, 0.5), (1.0 - metalness)),
                multiply_scalar(color, metalness)
            ),
            specular_weight
        )
        
        reflected = reflect(direction, hit.hitnormal)
        new_dir = add_vectors(
            multiply_scalar(rand_dir_from_surf(hit.hitnormal), roughness),
            multiply_scalar(reflected, (1.0 - roughness))
        )
        
        recursive_color = do_ray(hit.hitlocation, new_dir, bounces_left - 1, tree, root)
        specular_color = multiply_scalar(
            multiply_scalar((1.0 - emission), specular_highlight),
            recursive_color
        )
        return add_vectors(emissive, specular_color)
    else:
        # Diffuse Bounce
        diffuse_weight = 0.5 * (1.0 - metalness)
        new_dir = rand_dir_from_surf(hit.hitnormal)
        
        recursive_color = do_ray(hit.hitlocation, new_dir, bounces_left - 1, tree, root)
        diffuse_color = multiply_scalar(
            multiply_scalar((1.0 - emission), diffuse_weight),
            multiply_scalar(color, recursive_color)
        )
        return add_vectors(emissive, diffuse_color)

def cast_ray_voxel(origin, direction, tree, root):
    # Simplified iterative traversal based on [S2, unofficial]
    size = 1.0
    activenodes = [root]
    nodelocations = [(0.0, 0.0, 0.0)]
    x = 0
    closest_leaf = (float('inf'), None)
    
    while x < len(activenodes):
        targets = []
        for i in range(x, len(activenodes)):
            node_loc = nodelocations[i]
            # AABB intersection test
            dist = cast_ray_v_box(origin - node_loc, direction, size)
            if dist is not None and dist < float('inf'):
                targets.append((dist, activenodes[i], node_loc))
        
        targets.sort(key=lambda t: t[0])
        
        for dist, node_idx, node_loc in targets:
            if dist < closest_leaf[0]:
                node = get_node(tree, node_idx)
                if is_leaf(node):
                    closest_leaf = (dist, node)
                    # Calculate hit position and normal
                    hit_pos = intersect_v_box(origin - node_loc, direction, size)
                    hit_location = add_vectors(node_loc, hit_pos)
                    hit_normal = normalize(get_biggest_axis(hit_pos))
                    return RayResult(
                        dead=False,
                        node=node,
                        hitlocation=hit_location,
                        hitnormal=hit_normal,
                        colour=node.colour,
                        emission=node.emission,
                        metalness=node.metalness,
                        roughness=node.roughness
                    )
                else:
                    # Push children
                    child_mask = get_child_mask(node)
                    for c in range(8):
                        if child_mask & (1 << c):
                            child_idx = get_child_index(node, c)
                            child_loc = add_vectors(
                                node_loc,
                                multiply_scalar(oct_byte_to_vec(c), size / 2.0)
                            )
                            activenodes.append(child_idx)
                            nodelocations.append(child_loc)
        
        # Drain processed
        activenodes = activenodes[x:]
        nodelocations = nodelocations[x:]
        x = 0
        size /= 2.0
        
    return RayResult(dead=True)
```

### Parameters
*   `maxDepth`: Maximum depth of the octree. Set to 3 in generation [S1, unofficial].
*   `EPSILON`: `0.000002` (f64). Tolerance margin in AABB boundary checks to avoid precision artifacts [S2, unofficial].
*   `NumSamples`: Samples per pixel. UI range 0-250 [S1, unofficial].
*   `EMISSIVE_SCALE`: `15.0` (f64). Multiplier for emissive materials [S2, unofficial].
*   `MaxBounces`: Maximum light bounces. UI range 0-100 [S1, unofficial].
*   `Reflectivity`: Material parameter. UI range 0.0-1.0 [S1, unofficial].

### Edge Cases and Pitfalls
*   **Division by Zero:** Avoided by checking `t > 0.0` in ray-box intersection and using `EPSILON` tolerance [S2, unofficial].
*   **Precision Artifacts:** Floating point comparisons in AABB intersection use `EPSILON` to clamp boundary checks, preventing false negatives on exact edges [S2, unofficial].
*   **Empty Space:** The traversal logic explicitly skips empty nodes by checking child masks and leaf flags, ensuring efficiency [S1, S2, unofficial].
*   **Degenerate Input:** If `NumSamples` is 0, the image will be black. If `MaxBounces` is 0, only emissive surfaces are visible [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Traversal visits only active nodes in the sparse DAG, scaling with visible surface area and depth rather than total voxel count [S2, unofficial]. Path tracing complexity is $O(N \cdot B \cdot V)$, where $N$ is pixels, $B$ is bounces, and $V$ is average nodes visited per ray.
*   **Memory Complexity:** Linear with the number of nodes in the SVO. The flat array `_tree` stores all nodes. For a full octree of depth 3, this is small, but for deeper trees, it grows as $8^d$ in the worst case (though sparsity reduces this) [S1, unofficial].
*   **Measured Performance:** Demonstrated with 12 samples + 12 bounces and 50 samples + 50 bounces [S1, unofficial]. Parallelized across pixel chunks using `rayon` in Rust implementations [S2, unofficial].
*   **Strengths:** Efficiently handles large, sparse voxel datasets. CPU-based implementation allows for flexible path tracing logic without GPU shader constraints.
*   **Limitations:** CPU-based path tracing is generally slower than GPU-based rasterization or GPU path tracing for high-resolution images. The primitive path tracing implementation may exhibit noise at low sample counts [S1, unofficial].
*   **When to Use:** Ideal for offline rendering of voxel-based scenes, architectural visualization, or when hardware constraints prevent GPU path tracing.
*   **When Not to Use:** Real-time applications requiring high frame rates, or scenes with extremely dense voxel data where traversal overhead dominates.

## Background
Sparse Voxel Octree Path Tracing is a technique that combines the spatial efficiency of Sparse Voxel Octrees (SVOs) with the physical accuracy of path tracing. The SVO data structure, originally popularized for efficient storage and rendering of volumetric data, allows for fast traversal of large 3D spaces by skipping empty regions [S1, unofficial]. The path tracing component, based on principles from "Ray Tracing in One Weekend" [S1, unofficial], computes global illumination by simulating the path of light rays. This specific implementation is a CPU-based approach, leveraging the flexibility of general-purpose programming languages (C++, Rust) to implement complex traversal and shading logic [S1, S2, unofficial]. It is often used in educational contexts and prototype rendering systems for voxel art and procedural geometry [S1, S2, unofficial].
