# Sparse Voxel Octree Ray Tracing

Also called: Octree Raymarching, SVO Ray Marching, SVO traversal, SVO::getHit, Sparse Voxel Octree (SVO) Ray Traversal, Sparse Voxel Octree Ray Marching

## Overview
Sparse Voxel Octree (SVO) Ray Tracing is a ray marching algorithm that traverses a 3D Sparse Voxel Octree to find the first occupied voxel (leaf node) intersected by a ray, enabling real-time voxel rendering without polygonal geometry [S1, unofficial][S2, unofficial][S6, unofficial]. It differs from standard ray-triangle rasterization by using a single draw call for a fullscreen triangle to fire one ray per pixel, descending the hierarchical octree structure to skip empty space efficiently via axis-aligned slab intersection logic, and shading the hit voxel using the face normal derived from the ray-AABB intersection [S1, unofficial][S6, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Ray origin $O$ and direction $D$ (per pixel), SVO data structure (nodes/leaves), camera parameters (FOV, view-projection matrix), world bounds [S6, unofficial].
*   **Output:** Hit position, hit normal, color, and status (hit, miss, out-of-bounds) [S1, unofficial].

**Data Structures:**
*   **SVO Node:** Stored in a flat array [S6, unofficial]. A 32-bit integer where MSB (bit 31) indicates a solid leaf [S6, unofficial]. Lower 24 bits store RGB color (8 bits/channel) [S6, unofficial]. If MSB is 0, lower bits are an index to a children array [S6, unofficial].
*   **RayHit Struct:** `status` (u32: 0=no hit, 1=hit octree, 2=hit voxel, 3=out of bounds), `iterations` (u32), `position` (vec3<f32>), `normal` (vec3<f32>), `voxelData` (u32), `uv` (vec2<f32>) [S1, unofficial].
*   **Stack (Optional):** For backtracking in non-leaf traversal, a stack of `ParentElement` structs containing `pos` (float3), `scale` (float), `exit` (float), `index` (uint), `childIndex` (uint) [S2, unofficial]. Fixed size, e.g., 16 or 64 elements [S2, unofficial].

**Parameters:**
*   `MAX_STEPS`: Maximum march steps per ray (e.g., 200) [S6, unofficial].
*   `EPS`: Epsilon for ray origin nudging (e.g., 0.0004) [S6, unofficial].
*   `mRootRadius`: Root radius of SVO (e.g., 256.0f) [S2, unofficial].
*   `MAXIMUM_TREE_DEPTH`: Max octree depth (e.g., 30) [S3, unofficial].

**Steps:**

1.  **Ray Generation:** For each pixel, transform normalized device coordinates (NDC) using the inverse view-projection matrix to get world-space ray origin and direction [S6, unofficial].
2.  **World Bounds Check:** Perform a ray-AABB slab test against the world bounds ($world_{min}, world_{max}$) [S6, unofficial]. If $t_{near} > t_{far}$ or $t_{far} < 0$, return sky color [S6, unofficial].
    $$ t_{near} = \max(\min(t_{0,x}, t_{1,x}), \min(t_{0,y}, t_{1,y}), \min(t_{0,z}, t_{1,z})) $$
    $$ t_{far} = \min(\max(t_{0,x}, t_{1,x}), \max(t_{0,y}, t_{1,y}), \max(t_{0,z}, t_{1,z})) $$
    where $t_0 = (box_{min} - O) / D$ and $t_1 = (box_{max} - O) / D$ [S6, unofficial].
3.  **Root Intersection:** Check intersection with the root octree box [S2, unofficial]. If no intersection, return miss.
4.  **Traversal Loop:** Iterate up to `MAX_STEPS` [S6, unofficial].
    *   **Node Check:** Determine if the current voxel/octant at the ray's current position is occupied using `GetOctant` or by checking the SVO node's valid mask [S1, unofficial][S2, unofficial].
    *   **Hit Detection:** If the node is a solid leaf (MSB set) or active, calculate the exact intersection depth with the voxel's AABB using `RayBoxIntersect` [S1, unofficial][S6, unofficial].
    *   **Backtracking (if using stack):** If the current node is empty or not a leaf, push the current state to the stack, move to the next child along the ray direction, and continue. If no children exist, pop from the stack to backtrack [S2, unofficial].
    *   **Step Forward:** If the current octant is empty, determine the next axis to step along by finding the minimum component of the translation vector to the next slab boundary. Update ray position and translation parameters [S1, unofficial].
    *   **Bounds Check:** If the new position is out of world bounds, set status to 3 (out of bounds) and return [S1, unofficial].
5.  **Termination:** If a hit is found, compute the hit position $P = O + D \cdot t_{min}$ and the normal [S7, unofficial]. If the loop completes without a hit, calculate the intersection with the final voxel box or return a miss status [S1, unofficial].
6.  **Shading:** Shade the hit voxel using the computed normal. Common shading includes ambient and diffuse lighting [S6, unofficial][S5, unofficial].
    $$ Color = (Ambient + Diffuse) \cdot ObjectColor $$
    $$ Diffuse = \max(0, \hat{N} \cdot \hat{L}) \cdot LightColor $$
    [S5, unofficial]

**Pseudocode:**

def ray_aabb(ro, inv_rd, box_min, box_max):
    t0 = (box_min - ro) * inv_rd
    t1 = (box_max - ro) * inv_rd
    t_near = max(max(min(t0.x, t1.x), min(t0.y, t1.y)), min(t0.z, t1.z))
    t_far = min(min(max(t0.x, t1.x), max(t0.y, t1.y)), max(t0.z, t1.z))
    return t_near, t_far

def get_octant_normal(hit_pos, node_center, half_size):
    center_to_hit = hit_pos - node_center
    max_comp = max(abs(center_to_hit.x / half_size.x), abs(center_to_hit.y / half_size.y), abs(center_to_hit.z / half_size.z))
    normal = vec3(0.0)
    if abs(center_to_hit.x / half_size.x) == max_comp:
        normal.x = 1.0 if center_to_hit.x > 0 else -1.0
    elif abs(center_to_hit.y / half_size.y) == max_comp:
        normal.y = 1.0 if center_to_hit.y > 0 else -1.0
    else:
        normal.z = 1.0 if center_to_hit.z > 0 else -1.0
    return normal

def shade_hit(hit_pos, normal, light_pos, light_color, object_color):
    ambient = 0.1 * light_color
    diffuse = max(dot(normal, normalize(light_pos - hit_pos)), 0.0) * light_color
    return (ambient + diffuse) * object_color

def trace_svo_ray(ray_origin, ray_dir, svo_info):
    inv_rd = 1.0 / ray_dir
    inv_rd = vec3(1e-4) if abs(inv_rd) < 1e-4 else inv_rd

    t_near, t_far = ray_aabb(ray_origin, inv_rd, svo_info.world_min, svo_info.world_max)
    if t_near > t_far or t_far < 0:
        return vec3(0.53, 0.81, 0.98)

    t = max(t_near, 0.0) + 0.0004
    t_max = t_far

    root_min = svo_info.origin
    root_max = svo_info.origin + svo_info.size
    root_t_near, root_t_far = ray_aabb(ray_origin, inv_rd, root_min, root_max)
    if root_t_near > root_t_far or root_t_far < 0:
        return vec3(0.53, 0.81, 0.98)

    t = max(root_t_near, 0.0) + 0.0004
    ray_pos = ray_origin + ray_dir * t

    for iteration in range(200):
        if get_octant_occupancy(vec3(ray_pos)):
            voxel_min = ray_pos
            voxel_max = ray_pos + vec3(1.0)
            hit_t, _ = ray_aabb(ray_origin, inv_rd, voxel_min, voxel_max)
            if hit_t >= 0 and hit_t <= t_max:
                hit_pos = ray_origin + ray_dir * hit_t
                normal = get_octant_normal(hit_pos, ray_pos + vec3(0.5), vec3(0.5))
                return shade_hit(hit_pos, normal, vec3(0.0, -1.5, 0.0), vec3(1.0, 1.0, 1.0), vec3(1.0, 1.0, 1.0))

        max_translation = (((0.5 + ray_pos) + 0.5 * sign(ray_dir)) - ray_origin) / ray_dir
        delta_translation = sign(ray_dir) / ray_dir
        ray_advance_mask = max_translation.xyz <= min(max_translation.yzx, max_translation.zxy)
        max_translation = max_translation + ray_advance_mask * delta_translation
        ray_pos = ray_pos + ray_advance_mask * sign(ray_dir)

        if ray_pos.x >= svo_info.world_size or ray_pos.x < 0 or \
           ray_pos.y >= svo_info.world_size or ray_pos.y < 0 or \
           ray_pos.z >= svo_info.world_size or ray_pos.z < 0:
            return vec3(0.0)

    return vec3(0.53, 0.81, 0.98)

## Operating characteristics
*   **Time Complexity:** Bounded by `MAX_STEPS` (e.g., 200) and stack depth (e.g., 16 or 64 elements) rather than strictly tree depth [S2, unofficial].
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** Real-time capable on modern GPUs. Renders the entire scene with a single draw call (fullscreen triangle) [S6, unofficial]. Performance scales with the number of steps and tree depth [S6, unofficial].
*   **Strengths:** No mesh generation required, efficient culling of empty space, supports dynamic updates [S6, unofficial].
*   **Limitations:** Precision issues with ray origin nudging and slab boundaries [S6, unofficial][S3, unofficial]. Limited by the maximum tree depth and stack size for backtracking [S2, unofficial].

## Background
Sparse Voxel Octree Ray Tracing originated as a method to render large voxel datasets efficiently without the overhead of polygonal conversion [S6, unofficial]. It leverages the hierarchical nature of octrees to skip empty space, making it suitable for real-time applications like voxel-based games and planetary visualization [S1, unofficial][S6, unofficial]. The method is often implemented in GLSL or WGSL fragment/compute shaders [S1, unofficial][S6, unofficial].
