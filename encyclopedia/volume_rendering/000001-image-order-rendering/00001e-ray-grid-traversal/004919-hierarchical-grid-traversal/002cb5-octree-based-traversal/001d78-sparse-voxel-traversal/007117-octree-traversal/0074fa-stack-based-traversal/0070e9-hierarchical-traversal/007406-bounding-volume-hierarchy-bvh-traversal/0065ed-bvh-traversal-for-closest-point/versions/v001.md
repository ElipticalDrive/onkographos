# BVH Traversal for Closest Point
Also called: Closest Point BVH Traversal
## Overview
This method performs a recursive traversal of a Bounding Volume Hierarchy (BVH) to find the triangle closest to a specific query point [S1]. It differs from ray-based traversal methods like [Ray Tracing with BVH and Möller–Trumbore](19369-ray-tracing-with-bvh-and-m-ller-trumbore.md) by computing Euclidean distance rather than ray intersection, and from [Mesh BVH](1062-mesh-bvh.md) by focusing on point-to-primitive distance rather than mesh-level collision detection. It builds on [Bounding Volume Hierarchy (BVH) Traversal](18487-bounding-volume-hierarchy-bvh-traversal.md) by utilizing the hierarchical structure to prune branches that cannot contain a closer primitive than the current best.
## How it works
**Inputs and Outputs:**
- Input: A query point $p$, a BVH root node, and a current best distance $d_{min}$ (initialized to infinity).
- Output: The minimum distance $d_{min}$ and the corresponding triangle (or primitive) index.

**Data Structures:**
The BVH is a binary tree where each node contains an Axis-Aligned Bounding Box (AABB) defined by `low` and `high` vectors [S1].
- `Interior`: Contains `low`, `high`, `left` child, and `right` child.
- `Leaf`: Contains `low`, `high`, number of primitives `nprims`, and an array of `Triangle` objects `data` [S1].
- `Triangle`: Defined by three vertices $p_0, p_1, p_2$ [S1].

**Formulas:**
The squared Euclidean distance from point $p$ to AABB $a$ is computed using `distmin` and `distmax` [S1]:
$$ \text{distmin}(p, a) = \sum_{i \in \{x,y,z\}} \max(0, \max(a.\text{low}_i - p_i, p_i - a.\text{high}_i))^2 $$
$$ \text{distmax}(p, a) = \sum_{i \in \{x,y,z\}} \min(a.\text{low}_i - p_i, p_i - a.\text{high}_i)^2 $$
Note: The source implementation of `distmax` uses `min(u, v)` where $u = a.\text{low} - p$ and $v = p - a.\text{high}$, which effectively computes the squared distance to the farthest corner of the AABB relative to $p$ in a specific projection context, though standard farthest point distance usually involves `max` of absolute differences. The source code explicitly defines `distmax` as:
```python
def distmax(pt, a):
    u = a.low - pt.v
    v = pt.v - a.high
    d = min(u, v) # Element-wise min
    return dot(d, d)
```
This specific `distmax` implementation is used for pruning upper bounds [S1].

**Steps:**
1. **Interior Node:**
   - Compute $d_{min\_node} = \text{distmin}(p, \text{AABB})$.
   - If $d_{min\_node} < d_{min}$:
     - Compute $u = \text{distmax}(p, \text{AABB})$.
     - If $u < d_{min}$, update $d_{min} = u$ [S1].
     - Extract AABBs for left ($L_a$) and right ($R_a$) children.
     - Compute $L = \text{distmin}(p, L_a)$ and $R = \text{distmin}(p, R_a)$.
     - If $L < R$, recurse left then right. Else, recurse right then left [S1].
2. **Leaf Node:**
   - Compute $d_{min\_leaf} = \text{distmin}(p, \text{AABB})$.
   - If $d_{min\_leaf} < d_{min}$:
     - Iterate through each triangle $t$ in `data`.
     - Compute $d_t = \text{distmin}(p, t)$.
     - If $d_t < d_{min}$, update $d_{min} = d_t$ and store $t$ [S1].

**Pseudocode:**
```python
def closest_point(p, bvh, best):
    # best is a mutable tuple (current_min_dist, best_triangle)
    if bvh is Interior:
        # Check if the node's AABB is closer than current best
        if distmin(p, bvh.AABB()) < best[0]:
            # Potential pruning using upper bound
            upper_bound = distmax(p, bvh.AABB())
            if upper_bound < best[0]:
                best[0] = upper_bound
            
            # Get children AABBs
            La = bvh.left.AABB()
            Ra = bvh.right.AABB()
            
            # Sort children by distance to point
            L = distmin(p, La)
            R = distmin(p, Ra)
            
            if L < R:
                closest_point(p, bvh.left, best)
                closest_point(p, bvh.right, best)
            else:
                closest_point(p, bvh.right, best)
                closest_point(p, bvh.left, best)
                
    elif bvh is Leaf:
        # Check if leaf AABB is closer
        if distmin(p, bvh.AABB()) < best[0]:
            for t in bvh.data:
                d = distmin(p, t)
                if d < best[0]:
                    best[0] = d
                    best[1] = t
```
**Parameters:**
- Initial $d_{min}$: Infinity [S1].
- `distmax` usage: Used to update the upper bound of the best distance if the farthest point of the AABB is closer than the current best, allowing potential early updates [S1].

**Edge Cases and Pitfalls:**
- The `distmax` function implementation in the source is non-standard for "farthest point" distance and is specific to the cited paper's optimization [S1].
- Precision issues may arise if $d_{min}$ is very small; however, no specific guard is mentioned in the source [S1].
- If the query point is inside an AABB, `distmin` returns 0 [S1].

## Operating characteristics
- Time Complexity: $O(N)$ in the worst case, but typically $O(\log N)$ for balanced trees with spatial coherence [S1].
- Memory Complexity: $O(H)$ for recursion stack, where $H$ is tree height [S1].
- Strengths: Efficient pruning using AABB distances; simple recursive structure [S1].
- Limitations: Recursion depth can be an issue for deep trees; `distmax` optimization is specific to the cited layout [S1].
- When to use: When finding the nearest primitive to a point is required, such as in collision detection or point cloud processing [S1].
