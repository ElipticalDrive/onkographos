# SVO Node Location
## Overview
SVO Node Location maps a continuous 3D ray position to a discrete Sparse Voxel Octree (SVO) node index by traversing from the root to the intersected node [S1, unofficial]. It differs from [Octree Node Lookup by Voxel](5120-octree-node-lookup-by-voxel.md) by using ray-box intersection tests to select the correct child branch, whereas the latter maps discrete voxel coordinates directly to node indices without ray geometry [S1, S2, unofficial]. It builds on [Sparse Voxel Octree Ray Traversal](2451-sparse-voxel-octree-ray-traversal.md) by identifying the active node during traversal [S1, unofficial].
## How it works
### Inputs and outputs
- `raypos`: 3D vector, ray origin or query point [S1, unofficial].
- `raydir`: 3D vector, ray direction [S1, unofficial].
- `address_space`: Memory buffer containing SVO node data [S1, unofficial].
- `root_lower`: 3D vector, lower bound of the root node [S1, unofficial].
- `root_scale`: Scalar, side length of the root node [S1, unofficial].
- `max_depth`: Integer, maximum traversal depth; 0 traverses to leaf [S1, unofficial].
- `stack`: Stack to record the traversal path for backtracking [S1, unofficial].
- **Output**: Located node info and its lower bound, or a null indicator if the ray is outside bounds or the node has no children [S1, unofficial].

### Data structures
- `first_node_t`: Structure returned by child selection. Contains `node_info` (with `root_cd_goffset` and `best_corner`) and `lower` (3D vector of the selected child's lower bound) [S1, unofficial].
- `stack`: Parallel array or dynamic list storing node indices for backtracking [S1, unofficial].

### Steps
1. **Initialization**: Set `pos = raypos`, `lower = (0,0,0)`, `upper = (1,1,1)`, `center = (0.5,0.5,0.5)`, `scale = root_scale / 2`, `depth = 0`, and clear `stack` [S1, unofficial].
2. **Select First Child**: Call `svo_select_first_node_f3` with `pos`, `raydir`, `lower`, `scale`, and root offset [S1, unofficial]. Update `current_node`, `lower`, `upper`, and `center` based on the returned `first_node_t` [S1, unofficial].
3. **Traversal Loop**: While `max_depth == 0 || depth < max_depth`:
   - If `current_node` has no children, break [S1, unofficial].
   - Compute corner indices: `xcorneridx = 0 if pos.x < center.x else 1`, `ycorneridx = 0 if pos.y < center.y else 1`, `zcorneridx = 0 if pos.z < center.z else 1` [S1, unofficial].
   - Combine into `corner` index [S1, unofficial].
   - Retrieve child node info from `address_space` [S1, unofficial].
   - If child does not exist, break [S1, unofficial].
   - Push `current_node` onto `stack` [S1, unofficial].
   - Increment `depth`, update `current_node` to child, halve `scale`, and update `lower`, `upper`, `center` for the new child [S1, unofficial].
4. **Return**: Return `current_node` and its `lower` bound [S1, unofficial].

### Pseudocode
```python
def svo_locate_node(raypos, raydir, address_space, root_lower, root_scale, max_depth, stack):
    # 1. Initialization [S1, unofficial]
    pos = raypos
    lower = vec3(0.0, 0.0, 0.0)
    upper = vec3(1.0, 1.0, 1.0)
    center = vec3(0.5, 0.5, 0.5)
    scale = root_scale / 2.0
    depth = 0
    stack.clear()

    # 2. Select first child [S1, unofficial]
    first_node = svo_select_first_node_f3(pos, raydir, lower, scale, root_cd_goffset=0)
    if first_node is None:
        return None

    current_node = first_node.node_info
    lower = first_node.lower
    upper = lower + vec3(scale)
    center = lower + vec3(scale * 0.5)

    # 3. Traversal loop [S1, unofficial]
    while max_depth == 0 or depth < max_depth:
        if not has_children(current_node, address_space):
            break

        xcorneridx = 0 if pos.x < center.x else 1
        ycorneridx = 0 if pos.y < center.y else 1
        zcorneridx = 0 if pos.z < center.z else 1
        corner = (xcorneridx << 2) | (ycorneridx << 1) | zcorneridx

        child_node = get_child_node(current_node, corner, address_space)
        if child_node is None:
            break

        stack.push(current_node)
        depth += 1
        current_node = child_node
        scale /= 2.0
        lower += vec3((corner & 1), ((corner >> 1) & 1), ((corner >> 2) & 1)) * scale
        upper = lower + vec3(scale)
        center = lower + vec3(scale * 0.5)

    return current_node, lower

def svo_select_first_node_f3(raypos, raydir, lower, scale, root_cd_goffset):
    best_corner = None
    best_distance = float('inf')
    best_child_lower = lower
    child_scale = scale / 2.0

    for corneri in range(8):
        corner_offset = vec3((corneri & 1), ((corneri >> 1) & 1), ((corneri >> 2) & 1))
        child_lower = lower + corner_offset * child_scale
        child_upper = child_lower + vec3(child_scale)

        if not svo_fast_forward_intersects_f3(raypos, raydir, child_lower, child_upper):
            continue

        dir_bounds_upper = child_upper - raypos
        t1, outface = calculate_t1_f3(raypos, raydir, dir_bounds_upper)

        if outface is None:
            continue

        distance = t1
        if distance < best_distance:
            best_distance = distance
            best_corner = corneri
            best_child_lower = child_lower

    if best_corner is None:
        return None

    node_info = create_node_info(root_cd_goffset, best_corner)
    return first_node_t(node_info=node_info, lower=best_child_lower)

def has_children(node_idx, address_space):
    return address_space[node_idx].is_leaf == False

def get_child_node(parent_idx, corner, address_space):
    child_ptr = address_space[parent_idx].children[corner]
    return child_ptr if child_ptr != -1 else None

def svo_fast_forward_intersects_f3(raypos, raydir, child_lower, child_upper):
    tmin = (child_lower - raypos) / raydir
    tmax = (child_upper - raypos) / raydir
    t1 = min(tmin); t2 = max(tmin)
    t3 = min(tmax); t4 = max(tmax)
    t_enter = max(t1, t3)
    t_exit = min(t2, t4)
    return t_enter <= t_exit and t_exit > 0.0

def calculate_t1_f3(raypos, raydir, upper_rel):
    t = upper_rel / raydir
    t_exit = min(t.x, t.y, t.z)
    outface = vec3(0.0)
    if t_exit == t.x: outface = vec3(1.0, 0.0, 0.0)
    elif t_exit == t.y: outface = vec3(0.0, 1.0, 0.0)
    else: outface = vec3(0.0, 0.0, 1.0)
    return t_exit, outface

def create_node_info(goffset, corner):
    return {'root_cd_goffset': goffset, 'best_corner': corner}

def first_node_t(node_info, lower):
    return {'node_info': node_info, 'lower': lower}
```

### Parameters
- `max_depth`: 0 implies full traversal to leaf [S1, unofficial].
- `root_scale`: Depends on scene bounding box [S1, unofficial].

### Edge cases and pitfalls
- **Ray outside root bounds**: If `raypos` is not contained within the root bounds, return a null located node [S1, unofficial].
- **Empty children**: If the current node has no children, break the loop [S1, unofficial].
- **Null exit face**: If intersection calculation yields a null exit face, skip that child [S1, unofficial].

## Subtopics

### SVO First Node Selection
Calculates the initial child node intersected by the ray from the current octree node [S1, unofficial]. It iterates through all 8 corners, computes child bounds, checks ray-box intersection using `svo_fast_forward_intersects_f3`, calculates the exit distance `t1` via `calculate_t1_f3`, and selects the child with the minimum positive distance [S1, unofficial]. It differs from point-based lookup by using ray direction to determine entry, and is chosen when the ray origin is not guaranteed to be inside a specific voxel [S1, unofficial].

### SVO Point Location
Traverses the SVO from root to find the leaf node containing a given 3D position without using ray direction [S2, unofficial]. It computes the child index using binary mapping (front=1, back=0 for X/Y/Z) relative to the node center, updates the node index, and exits when a leaf is reached [S2, unofficial]. It differs from SVO Node Location by relying on discrete coordinate mapping rather than ray intersection tests, and is chosen for point queries or neighbor lookups [S2, unofficial]. Returns `INDEX_NONE` if the position is outside bounds or a child does not exist [S2, unofficial].

### Face Position Calculation
Computes the exact 3D position of the shared face between two adjacent SVO nodes to generate smooth continuous path coordinates from discrete voxel graph traversal [S3, unofficial]. It uses `tree.face_position_between(start, end)` to convert discrete node paths into continuous 3D waypoints [S3, unofficial].

## Operating characteristics
- **Time Complexity**: $O(D)$, where $D$ is the SVO depth, as each level requires constant-time arithmetic and array lookups [S1, S2, unofficial].
- **Memory Complexity**: $O(D)$ for the stack if backtracking is required, otherwise $O(1)$ [S1, unofficial].
- **Strengths**: Precise node identification for ray-based rendering; handles arbitrary ray origins [S1, unofficial].
- **Limitations**: Requires ray-box intersection calculations per step; sensitive to floating-point precision at boundaries [S1, unofficial].

## Background
SVO Node Location is a fundamental component of ray marching and ray tracing through Sparse Voxel Octrees [S1, unofficial]. It was implemented in the `landscapes` project by realazthat for real-time SVO rendering [S1, unofficial]. The concept of locating nodes by position is also used in pathfinding contexts, such as in UE5 tutorials for SVO-based pathfinding, where it is referred to as `FindLeaf` [S2, unofficial].
