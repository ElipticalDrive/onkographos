# Octree Node Lookup by Voxel
## Overview
This method traverses a Sparse Voxel Octree (SVO) from the root to locate the leaf node corresponding to a specific 3D integer voxel coordinate, returning the index of the payload associated with that leaf [S1, unofficial]. It solves the problem of mapping dense voxel grid coordinates to sparse tree payloads, which is a prerequisite for operations like trilinear sampling or attribute retrieval [S1, unofficial]. It differs from its sibling, [Octree Voxel Color Retrieval](5015-octree-voxel-color-retrieval.md), by returning only the payload index rather than the interpolated color value itself [S1, unofficial].
## How it works
**Inputs:**
- `nodes`: Array of `NodeDescriptor` structures representing the octree nodes.
- `num_nodes`: Number of nodes in the `nodes` array.
- `leaf_payload_indices`: Array of indices mapping leaf IDs to payload data.
- `num_leaves`: Number of leaves in the octree.
- `max_depth`: The maximum depth of the octree.
- `voxel`: A 3D integer coordinate $(x, y, z)$ to look up.

**Outputs:**
- An integer representing the payload index for the voxel [S1, unofficial]. Returns $-1$ if the voxel is out of bounds, the path does not exist, or the leaf is invalid [S1, unofficial].

**Data Structures:**
The `NodeDescriptor` contains the following fields [S1, unofficial]:
- `child_mask`: A bitmask indicating which of the 8 children exist (bit $i$ set if child $i$ exists).
- `leaf_mask`: A bitmask indicating which existing children are leaf nodes (subset of `child_mask`).
- `payload_base`: An offset into `leaf_payload_indices` for the first leaf child.
- `internal_child_mask`: A bitmask indicating which existing children are internal nodes (subset of `child_mask`).
- `child_base`: An offset into the `nodes` array for the first internal child.

**Algorithm:**
1. **Empty Check:** If `num_nodes` is 0, return $-1$ [S1, unofficial].
2. **Depth 0 Check:** If `max_depth` is 0, return the first leaf payload index if it exists and is valid, else $-1$ [S1, unofficial].
3. **Bounds Check:** Calculate `grid_size` as $2^{\text{max\_depth}}$. If the voxel coordinate $(x, y, z)$ is not within the range $[0, \text{grid\_size})$, return $-1$ [S1, unofficial].
4. **Initialization:** Set `node_index` = 0 (root node index) and `depth_remaining` = `max_depth` [S1, unofficial].
5. **Traversal Loop:**
   a. If `node_index` >= `num_nodes`, return $-1$ (invalid node reference) [S1, unofficial].
   b. Retrieve the `NodeDescriptor` at `nodes[node_index]` [S1, unofficial].
   c. Calculate the `child_index` for the current depth using bit extraction from the voxel coordinate:
      $$ \text{child\_index} = ((x \gg \text{depth\_remaining}) \& 1) \mid (((y \gg \text{depth\_remaining}) \& 1) \ll 1) \mid (((z \gg \text{depth\_remaining}) \& 1) \ll 2) $$
   d. Calculate `child_bit` as $1 \ll \text{child\_index}$ [S1, unofficial].
   e. **Existence Check:** If `(descriptor.child_mask & child_bit) == 0`, the child does not exist. Return $-1$ [S1, unofficial].
   f. **Leaf Check:** If `(descriptor.leaf_mask & child_bit) != 0`, the child is a leaf [S1, unofficial].
      i. Calculate the leaf ID relative to the node's leaves: `leaf_id` = `prefix_rank(descriptor.leaf_mask, child_index)` [S1, unofficial].
      ii. Calculate the global leaf index: `global_leaf_index` = `descriptor.payload_base` + `leaf_id` [S1, unofficial].
      iii. Retrieve `payload_index` from `leaf_payload_indices[global_leaf_index]` [S1, unofficial].
      iv. Validate `payload_index`. If valid, return it. If invalid, return $-1$ [S1, unofficial].
   g. **Internal Node Check:** Otherwise, the child is an internal node [S1, unofficial].
      i. Calculate the new node index: `new_node_index` = `descriptor.child_base` + `prefix_rank(descriptor.internal_child_mask, child_index)` [S1, unofficial].
      ii. Decrement `depth_remaining` by 1.
      iii. If `depth_remaining` <= 0, return $-1$ (reached max depth without finding a leaf) [S1, unofficial].
      iv. Update `node_index` = `new_node_index` and continue the loop.

**Helper Function: `prefix_rank`**
Calculates the number of set bits in `mask` that are strictly less significant than `child_index` [S1, unofficial].
$$ \text{prefix\_rank}(\text{mask}, \text{child\_index}) = \text{popcount}(\text{mask} \& ((1 \ll \text{child\_index}) - 1)) $$

**Pseudocode:**
```python
def lookup_payload_index_by_voxel(nodes, num_nodes, leaf_payload_indices, num_leaves, max_depth, voxel):
    x, y, z = voxel
    
    # 1. Empty Check
    if num_nodes == 0:
        return -1
    
    # 2. Depth 0 Check
    if max_depth == 0:
        if num_leaves > 0:
            return leaf_payload_indices[0]
        else:
            return -1
            
    # 3. Bounds Check
    grid_size = 1 << max_depth
    if not (0 <= x < grid_size and 0 <= y < grid_size and 0 <= z < grid_size):
        return -1
        
    node_index = 0
    depth_remaining = max_depth
    
    while True:
        # 5a. Invalid Node Check
        if node_index >= num_nodes:
            return -1
            
        descriptor = nodes[node_index]
        
        # 5c. Calculate Child Index
        child_depth = depth_remaining - 1
        x_bit = (x >> child_depth) & 1
        y_bit = (y >> child_depth) & 1
        z_bit = (z >> child_depth) & 1
        child_index = x_bit | (y_bit << 1) | (z_bit << 2)
        
        child_bit = 1 << child_index
        
        # 5e. Existence Check
        if (descriptor.child_mask & child_bit) == 0:
            return -1
            
        # 5f. Leaf Check
        if (descriptor.leaf_mask & child_bit) != 0:
            # Calculate rank among leaves
            lower_mask = (1 << child_index) - 1
            leaf_rank = bin(descriptor.leaf_mask & lower_mask).count('1')
            
            global_leaf_index = descriptor.payload_base + leaf_rank
            
            if global_leaf_index < num_leaves:
                payload_index = leaf_payload_indices[global_leaf_index]
                # [G] Assuming valid payload indices are non-negative integers.
                if payload_index >= 0:
                    return payload_index
            return -1
            
        # 5g. Internal Node Check
        # Calculate rank among internal children
        lower_mask = (1 << child_index) - 1
        internal_rank = bin(descriptor.internal_child_mask & lower_mask).count('1')
        
        new_node_index = descriptor.child_base + internal_rank
        depth_remaining -= 1
        
        if depth_remaining <= 0:
            return -1
            
        node_index = new_node_index
```
## Subtopics

### [WriteLeafOctree](16593-writeleafoctree.md)
WriteLeafOctree is a compute shader that traverses a Sparse Voxel Octree (SVO) to locate the leaf node for each input voxel, then maps the voxel's attributes into a 3D brick pool texture. It differs from its parent, [Octree Node Lookup by Voxel](5120-octree-node-lookup-by-voxel.md), by actively populating a structured brick-based texture memory with the voxel data rather than merely returning the leaf index.

### Sparse Voxel Query
Algorithm to find the voxel level, octpath, and occupancy flag for a query point $q$ given sorted occupied octpaths and levels [S2, unofficial]. It uses Morton encoding and binary search on predecessor/successor intervals to determine exact leaf hits or covering leaves [S2, unofficial].
