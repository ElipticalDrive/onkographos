# Ray Packet BVH Traversal

Also called: Ray Packet Traversal (Closest Hit), closest (packet), occluded, primary ray packet traversal, shadow ray packet traversal

## Overview
Ray Packet BVH Traversal traverses a Wald-ordered Bounding Volume Hierarchy (BVH) for a packet of rays to find the closest intersection for each active ray in the packet [S1, unofficial]. It differs from single-ray traversal by processing multiple rays simultaneously, allowing for batched culling and intersection tests, which improves throughput on SIMD architectures [S1, unofficial]. It supports specialized modes for closest hit (primary rays) and occlusion (shadow rays) via flag-based dispatch [S1, unofficial].

## How it works
**Inputs:**
- A BVH tree (Wald-ordered, binary tree).
- A packet of rays, defined by origin $O_i$, direction $D_i$, and inverse direction $1/D_i$ for each ray $i$ in the packet.
- Flags determining traversal mode: `INTERVALARITH`, `SHAREDORG`, and others controlling the specific intersection kernel [S1, unofficial].

**Outputs:**
- For closest hit: The closest intersection distance and hit point for each ray in the packet.
- For occlusion: A boolean indicating if each ray is occluded (hits any primitive) [S1, unofficial].

**Data Structures:**
- **Stack:** An array of pairs `pair<node*, u32>` with a fixed size of 64. Each element stores a pointer to a BVH node and the index of the first active ray in the packet that needs to be tested against that node [S1, unofficial].
- **Active Array:** An array of booleans (or integers) `active[MAXRAYNUM]` indicating which rays in the packet are still active (have not yet found a closest hit or have not been culled) [S1, unofficial].
- **Signs:** An array `s32 signs[3]` computed once per packet, where `signs[axis] = (ray_dir[axis] >= 0.0f) ? 1 : 0` [S1, unofficial].

**Parameters:**
- `flags`: Bitwise combination of `raypacket::INTERVALARITH`, `raypacket::SHAREDORG`, etc. [S1, unofficial].
- `MAXRAYNUM`: Maximum number of rays in a packet (implementation-dependent, e.g., 16, 32) [S1, unofficial].

**Steps:**

1. **Initialization:**
   - Compute `signs[3]` for the packet's rays. If rays have different directions, this optimization is not applicable or requires per-ray handling [S1, unofficial].
   - Initialize the stack: `stack[0] = {bvhtree.root, 0}`, `stacksz = 1` [S1, unofficial].
   - Initialize `occnum = 0` for occlusion queries [S1, unofficial].

2. **Traversal Loop:**
   - While `stacksz > 0`:
     - Pop from stack: `elem = stack[--stacksz]`, `node = elem.first`, `first = elem.second` [S1, unofficial].
     - **Culling/Intersection Check:**
       - If `flags & INTERVALARITH`:
         - If `flags & SHAREDORG`:
           - Call `slaboneco(node, p, signs)` to check if any ray intersects the node's AABB. If `res` is true, jump to `processnode`.
           - Call `culliaco(node, p, signs)`. If it returns true, break the loop (no rays intersect) [S1, unofficial].
         - Else:
           - Call `slabone(node, p, signs)`. If `res` is true, jump to `processnode`.
           - Call `cullia(node, p, signs)`. If it returns true, break the loop [S1, unofficial].
       - Find the first active ray in the packet that intersects the node's box:
         - If `flags & SHAREDORG`: `res = slabfirstco(node, p, signs, first)` [S1, unofficial].
         - Else: `res = slabfirst(node, p, signs, first)` [S1, unofficial].
         - If `!res`, break the loop (no active rays intersect this node) [S1, unofficial].
     - **Process Node (`processnode` label):**
       - Get `flag = node->getflag()` [S1, unofficial].
       - **If NONLEAF:**
         - Get `offset = node->getoffset()` and `axis = node->getaxis()` [S1, unofficial].
         - Determine `farindex = signs[axis]` and `nearindex = farindex ^ 1` [S1, unofficial].
         - Push far child to stack: `stack[stacksz++] = {node + offset + farindex, first}` [S1, unofficial].
         - Move to near child: `node = node + offset + nearindex` [S1, unofficial].
         - Continue loop (process near child) [S1, unofficial].
       - **If TRILEAF:**
         - Get triangles: `tris = node->getptr<waldtriangle>()`, `n = tris->num` [S1, unofficial].
         - Initialize `active` array: `active[first] = 1`, others 0 [S1, unofficial].
         - Filter active rays within the node's box:
           - If `SHAREDORG`: `slabfilterco(tris, p, active, first, signs)` [S1, unofficial].
           - Else: `slabfilter(tris, p, active, first, signs)` [S1, unofficial].
         - Loop over triangles `i` from 0 to `n-1`:
           - Call `closest<flags>(tris[i], p, active, first, hit)` for closest hit, or `occluded<flags>(tris[i], p, active, first, s)` for occlusion [S1, unofficial].
           - If occlusion: `occnum += result`. If `occnum == p.raynum`, return immediately (all rays occluded) [S1, unofficial].
         - Break loop (leaf processed) [S1, unofficial].
       - **If Sub-BVH Leaf:**
         - Get child intersector: `node = node->getptr<intersector>()->root` [S1, unofficial].
         - Jump to `processnode` [S1, unofficial].

3. **Dispatch:**
   - Initialize extra data: `CACHE_LINE_ALIGNED raypacketextra extra` [S1, unofficial].
   - Get flags via `initextra(extra, p, hit)` [S1, unofficial].
   - Switch on flags, calling `closest<X>(bvhtree, p, extra, hit)` for `X` in `0, 4, 8, 12` [S1, unofficial].

**Pseudocode:**

```python
def ray_packet_bvh_traversal(bvhtree, rays, flags):
    # Initialization
    # Compute signs for the packet (assuming shared direction or handling per-ray)
    # For simplicity, assume shared direction for this example
    signs = [1 if rays[0].dir[axis] >= 0 else 0 for axis in range(3)]
    
    stack = [(bvhtree.root, 0)]
    stacksz = 1
    occnum = 0
    
    while stacksz > 0:
        # Pop from stack
        stacksz -= 1
        node, first = stack[stacksz]
        
        # Culling/Intersection Check
        if flags & INTERVALARITH:
            if flags & SHAREDORG:
                res = slaboneco(node, rays, signs)
                if res:
                    goto processnode
                if culliaco(node, rays, signs):
                    break
            else:
                res = slabone(node, rays, signs)
                if res:
                    goto processnode
                if cullia(node, rays, signs):
                    break
        
        # Find first active ray intersecting node
        if flags & SHAREDORG:
            res = slabfirstco(node, rays, signs, first)
        else:
            res = slabfirst(node, rays, signs, first)
            
        if not res:
            break
            
        # Process Node
        processnode:
        flag = node.get_flag()
        
        if flag == NONLEAF:
            offset = node.get_offset()
            axis = node.get_axis()
            farindex = signs[axis]
            nearindex = farindex ^ 1
            
            # Push far child
            stack[stacksz] = (node + offset + farindex, first)
            stacksz += 1
            
            # Move to near child
            node = node + offset + nearindex
            continue # Continue loop to process near child
            
        elif flag == TRILEAF:
            tris = node.get_ptr_wald_triangle()
            n = tris.num
            active = [0] * MAXRAYNUM
            active[first] = 1
            
            if flags & SHAREDORG:
                slabfilterco(tris, rays, active, first, signs)
            else:
                slabfilter(tris, rays, active, first, signs)
                
            for i in range(n):
                if flags & OCCLUSION:
                    result = occluded(tris[i], rays, active, first, flags)
                    occnum += result
                    if occnum == rays.raynum:
                        return True # All rays occluded
                else:
                    closest(tris[i], rays, active, first, flags)
            break # Leaf processed
            
        elif flag == SUBBVH_LEAF:
            node = node.get_ptr_intersector().root
            goto processnode
            
    return occnum == rays.raynum if flags & OCCLUSION else None
```

**Edge Cases and Pitfalls:**
- **Unreachable Code:** If flags do not match 0, 4, 8, or 12, an assert is triggered [S1, unofficial].
- **Shared Origin:** `SHAREDORG` flag assumes all rays in the packet share the same origin. If not, this optimization is invalid [S1, unofficial].
- **Stack Overflow:** The stack size is fixed at 64. Deep BVHs may overflow, requiring a dynamic stack or larger fixed size [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N \cdot \log M)$ on average, where $N$ is the number of rays in the packet and $M$ is the number of nodes in the BVH. The packet size $N$ allows for SIMD parallelism, reducing constant factors.
- **Memory Complexity:** $O(D)$ for stack depth $D$, plus $O(N)$ for active ray tracking.
- **Performance:** Improves throughput on SIMD hardware by processing multiple rays simultaneously. Culling is batched, reducing branch divergence.
- **Strengths:** High throughput for large numbers of rays, efficient culling, SIMD-friendly.
- **Limitations:** Fixed stack size may overflow for very deep BVHs. Shared origin/direction assumptions limit applicability.
- **When to Use:** Primary ray tracing, shadow ray tracing where many rays are processed together.
- **When Not to Use:** Single-ray tracing, highly divergent ray directions/origins without packetization.

## Background
Ray Packet BVH Traversal is an optimization technique for ray tracing, leveraging SIMD capabilities to process multiple rays simultaneously. It builds on the BVH traversal algorithm, extending it to handle packets of rays. The technique is commonly used in real-time and offline renderers to improve performance.
