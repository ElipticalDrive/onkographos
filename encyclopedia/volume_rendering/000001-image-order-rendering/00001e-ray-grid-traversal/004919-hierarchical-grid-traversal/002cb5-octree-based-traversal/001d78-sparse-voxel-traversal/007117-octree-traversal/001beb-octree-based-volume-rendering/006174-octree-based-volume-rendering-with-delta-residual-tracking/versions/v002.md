# Octree-based Volume Rendering with Delta/Residual Tracking

Also called: Delta/residual tracking with octree, Octree-based Volume Traversal, Ratio tracking for volume rendering

## Overview
This method replaces traditional volume meshes and volume stacks with an octree encoding volume topology and extra data, enabling direct traversal and shading during ray marching [S1, unofficial]. It differs from stack-based volume shading by evaluating all volume shaders in the current leaf node simultaneously at each step, eliminating the need to maintain and update a volume stack during traversal [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A list of objects with volume geometry and their volume bounding boxes [S1, unofficial].
*   **Output:** Rendered image with volume shading, emission, and direct light [S1, unofficial].

**Data Structures:**
*   **Octree Leaf Node:**
    *   `volumes`: A list of active volume objects [S1, unofficial]. The source specifies a fixed size of 1024 objects, but notes this consumes excessive memory and suggests a dynamic pointer to a packed list as an alternative [S1, unofficial].
    *   `min_density`: Minimum density value for the volumes in this leaf [S1, unofficial].
    *   `max_density`: Maximum density value for the volumes in this leaf [S1, unofficial].
    *   The `min_density` and `max_density` values are used to bound the null scattering probability [S1, unofficial].

**Numbered Steps:**
1.  **Build Octree:** Construct an octree from the list of objects possessing volume geometry, using their volume bounding boxes [S1, unofficial].
2.  **Scene Traversal:** During scene traversal, execute octree traversal after `scene_intersect` in `integrator_intersect_closest` [S1, unofficial].
3.  **Volume Shading:** In `shade_volume`, traverse the octree and evaluate all volume shaders in the current leaf node at once, without maintaining a volume stack [S1, unofficial].
4.  **Null Scattering:** Compute min/max density values per leaf node to bound null scattering probability [S1, unofficial].

**Formulas:**
*   Null scattering probability is bounded by the actual volume density using the leaf node's `min_density` and `max_density` values [S1, unofficial]. Specific formulas are not provided in the sources [S1, unofficial].

**Parameters:**
*   Fixed list size for volumes per leaf node: 1024 [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Memory Usage:** A fixed list size of 1024 volume objects per leaf node consumes excessive memory [S1, unofficial].
*   **Null Scattering Efficiency:** Computing min/max density over the entire domain yields a minimum of always 0, reducing null scattering efficiency [S1, unofficial]. Computation should be done at the OpenVDB tile or leaf level instead [S1, unofficial].

## Background
The method was implemented as a work-in-progress patch (D14656) for Blender's Cycles renderer to improve volume motion blur and delta/residual tracking [S1, unofficial]. It was discussed by Kévin Dietrich and Sam Morse-Brown in April 2022 [S1, unofficial].
