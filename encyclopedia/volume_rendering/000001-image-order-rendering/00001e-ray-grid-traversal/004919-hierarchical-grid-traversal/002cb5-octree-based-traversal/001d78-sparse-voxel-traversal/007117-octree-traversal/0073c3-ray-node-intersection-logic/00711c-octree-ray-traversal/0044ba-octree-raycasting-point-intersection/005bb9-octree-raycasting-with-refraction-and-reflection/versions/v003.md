# Octree Raycasting with Refraction and Reflection

Also called: CUDA Octree Raycasting with Refraction and Reflection

## Overview
A GPU-based volume rendering technique that traverses an octree using CUDA kernels to compute ray-surface intersections, handling refraction and reflection recursively to simulate transparent and reflective materials [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** An octree data structure representing the volume, camera position, Model-View-Projection (MVP) matrix, viewport dimensions ($width \times height$), and rendering flags (`enable_reflection`, `enable_refraction`, depth buffer enabled) [S1, unofficial].
- **Output:** A color buffer (image) and optionally a depth buffer [S1, unofficial].

**Data Structures:**
The method relies on specific structures to track traversal state and hit information [S1, unofficial]:
1. **StackEntry**: Used for parent voxel tracking during traversal [S1, unofficial].
    - `parent`: `const int32_t*` pointer to the parent node.
    - `t_max`: `float` maximum t-value for the current voxel.
2. **RaycastHit**: Stores the result of a raycast intersection [S1, unofficial].
    - `hit_t`: `float` distance to the hit.
    - `hit_pos`: `glm::vec3` world position of the hit.
    - `hit_parent`: `const int32_t*` pointer to the parent node.
    - `hit_idx`: `int32_t` child index.
    - `hit_pos_internal`: `glm::vec3` internal position within the voxel.
    - `hit_scale`: `int32_t` scale/depth of the hit node.

**Parameters:**
- `MAX_SCALE`: The maximum depth of the octree, defined as 23, corresponding to the number of bits in a single precision float [S1, unofficial].
- `THREADS_PER_BLOCK_SQUARE`: The number of threads per block in each dimension, set to 32, which is a multiple of the warp size [S1, unofficial].
- `HALF_SQRT_2`: A constant used for origin offsetting, equal to $\frac{\sqrt{2}}{2}$ [S1, unofficial].

**Algorithm Steps:**
1. **Initialize CUDA Kernel Grid:** Calculate block size as `dim3(32, 32)` and grid size as `dim3((width + 31) / 32, (height + 31) / 32)` to cover the viewport dimensions [S1, unofficial].
2. **Compute Eye Ray:** For each pixel $(x, y)$, normalize coordinates to $[0,1]$, convert to NDC $[-1,1]$, multiply by the MVP matrix, and normalize the resulting vector to get the ray direction. The origin is the camera position [S1, unofficial].
3. **Initial Raycast:** Call `raycast(tree, &eye_ray, stack, &raycastHit)` to find the first surface intersection in the octree [S1, unofficial].
4. **Handle Hit:** If `raycastHit.hit_scale < MAX_SCALE`, calculate NDC depth from `hit_pos` using the MVP matrix, clamp to $[-1,1]$, and write to the depth buffer if enabled. Decompress raw attachment to get shading attributes [S1, unofficial].
5. **Shade Fragment:** Call `shade<0>(rendering_attributes, eye_ray, raycastHit, stack, tree)` to compute the initial color, which may recursively handle refraction and reflection [S1, unofficial].
6. **Refraction Handling:** If `enable_reflection` is false but refraction is active, calculate the surface normal, adjust for the dot product sign, compute the refracted direction using indices of refraction, and offset the origin to avoid self-intersection [S1, unofficial].
7. **Refraction Origin Offset:** Set `refraction_ray.origin` to `hit_pos + direction * HALF_SQRT_2 * exp2f(hit.hit_scale - MAX_SCALE)` to prevent self-intersection after refraction [S1, unofficial].
8. **Recursive Refraction:** If `refraction_hit.hit_scale < MAX_SCALE`, recursively call `shade<recursions+1>` and add to output weighted by `one_minus_alpha`. Otherwise, add ambient color weighted by `one_minus_alpha` [S1, unofficial].
9. **Recursive Reflection:** If `reflection_hit.hit_scale < MAX_SCALE`, recursively call `shade<recursions+1>` and add to output weighted by `reflectivity`. Otherwise, add clear color weighted by `reflectivity` [S1, unofficial].
10. **Unmap Resources and Render:** Unmap CUDA resources, bind PBOs to OpenGL textures, draw a fullscreen quad to display the result, and optionally blit the depth buffer to the main framebuffer [S1, unofficial].

```python
import math

MAX_SCALE = 23
THREADS_PER_BLOCK_SQUARE = 32
HALF_SQRT_2 = math.sqrt(2.0) / 2.0

class StackEntry:
    parent: int  # const int32_t* pointer to parent node
    t_max: float

class RaycastHit:
    hit_t: float
    hit_pos: list  # [x, y, z]
    hit_parent: int
    hit_idx: int
    hit_pos_internal: list
    hit_scale: int

def normalize(v):
    length = math.sqrt(v[0]**2 + v[1]**2 + v[2]**2)
    return [v[0]/length, v[1]/length, v[2]/length] if length > 0 else [0.0, 0.0, 0.0]

def dot(a, b):
    return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

def refract(direction, normal, eta):
    ndotd = dot(normal, direction)
    discriminant = 1.0 - eta * eta * (1.0 - ndotd * ndotd)
    if discriminant < 0.0:
        return None
    return [
        eta * direction[0] + (eta * ndotd - math.sqrt(discriminant)) * normal[0],
        eta * direction[1] + (eta * ndotd - math.sqrt(discriminant)) * normal[1],
        eta * direction[2] + (eta * ndotd - math.sqrt(discriminant)) * normal[2]
    ]

def reflect(direction, normal):
    d = dot(direction, normal)
    return [
        direction[0] - 2.0 * d * normal[0],
        direction[1] - 2.0 * d * normal[1],
        direction[2] - 2.0 * d * normal[2]
    ]

def pixel_shader(x, y, width, height, camera_pos, mvp_matrix, tree, enable_reflection, enable_refraction, depth_buffer_enabled):
    if x >= width or y >= height:
        return [0.0, 0.0, 0.0, 0.0]

    ndc_x = (2.0 * x / width) - 1.0
    ndc_y = (2.0 * y / height) - 1.0
    ray_dir = normalize([ndc_x, ndc_y, -1.0])
    ray_origin = camera_pos

    stack = []
    ray_hit = RaycastHit()
    hit_found = raycast(tree, ray_origin, ray_dir, stack, ray_hit)

    if ray_hit.hit_scale < MAX_SCALE:

def shade(recursion_level, attributes, ray_origin, ray_direction, hit, stack, tree, enable_reflection, enable_refraction):
    base_color = compute_base_color(attributes)
    final_color = base_color[:]

    if not enable_reflection and enable_refraction:
        normal = compute_normal(hit)
        if dot(ray_direction, normal) > 0:
            normal = [-n for n in normal]
        
        ior_inside = attributes.get('ior_inside', 1.0)
        ior_outside = attributes.get('ior_outside', 1.0)
        eta = ior_inside / ior_outside
        
        refracted_dir = refract(ray_direction, normal, eta)
        if refracted_dir is None:
            return final_color
            
        offset = HALF_SQRT_2 * (2.0 ** (hit.hit_scale - MAX_SCALE))
        refracted_origin = [
            hit.hit_pos[0] + refracted_dir[0] * offset,
            hit.hit_pos[1] + refracted_dir[1] * offset,
            hit.hit_pos[2] + refracted_dir[2] * offset
        ]
        
        refracted_hit = RaycastHit()
        refracted_found = raycast(tree, refracted_origin, refracted_dir, stack, refracted_hit)
        
        if refracted_found and refracted_hit.hit_scale < MAX_SCALE:
            refracted_color = shade(recursion_level + 1, attributes, refracted_origin, refracted_dir, refracted_hit, stack, tree, enable_reflection, enable_refraction)
            final_color = [final_color[i] + refracted_color[i] * (1.0 - attributes.get('alpha', 1.0)) for i in range(4)]
        else:
            ambient = attributes.get('ambient_color', [0.0, 0.0, 0.0, 0.0])
            final_color = [final_color[i] + ambient[i] * (1.0 - attributes.get('alpha', 1.0)) for i in range(4)]

    if enable_reflection:
        normal = compute_normal(hit)
        if dot(ray_direction, normal) > 0:
            normal = [-n for n in normal]
            
        reflected_dir = reflect(ray_direction, normal)
        offset = HALF_SQRT_2 * (2.0 ** (hit.hit_scale - MAX_SCALE))
        reflected_origin = [
            hit.hit_pos[0] + reflected_dir[0] * offset,
            hit.hit_pos[1] + reflected_dir[1] * offset,
            hit.hit_pos[2] + reflected_dir[2] * offset
        ]
        
        reflected_hit = RaycastHit()
        reflected_found = raycast(tree, reflected_origin, reflected_dir, stack, reflected_hit)
        
        if reflected_found and reflected_hit.hit_scale < MAX_SCALE:
            reflected_color = shade(recursion_level + 1, attributes, reflected_origin, reflected_dir, reflected_hit, stack, tree, enable_reflection, enable_refraction)
            reflectivity = attributes.get('reflectivity', 0.0)
            final_color = [final_color[i] + reflected_color[i] * reflectivity for i in range(4)]
        else:
            clear = attributes.get('clear_color', [0.0, 0.0, 0.0, 0.0])
            reflectivity = attributes.get('reflectivity', 0.0)
            final_color = [final_color[i] + clear[i] * reflectivity for i in range(4)]

    return final_color
```

**Edge Cases and Pitfalls:**
- **Self-intersection:** After refraction or reflection, the ray origin is offset along the ray direction by `HALF_SQRT_2 * exp2f(hit.hit_scale - MAX_SCALE)` to prevent the new ray from immediately hitting the same surface [S1, unofficial].
- **Out-of-bounds pixels:** The kernel checks if $x \ge width$ or $y \ge height$ and returns early to prevent writing to invalid memory, as grid dimensions may exceed viewport size [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources [S1, unofficial].
- **Memory Complexity:** Not given in the sources [S1, unofficial].
- **Performance:** Implemented on GPU using CUDA, leveraging parallelism across pixels with a $32 \times 32$ thread block size aligned to warp size [S1, unofficial].
- **Strengths:** Efficient handling of complex transparent and reflective volumes on GPU. Recursive shading simulates light transport [S1, unofficial].
- **Limitations:** Recursive calls increase computational cost. Self-intersection artifacts require careful origin offset management [S1, unofficial].
- **When to use:** Suitable for GPU-accelerated rendering of transparent/reflective volumes [S1, unofficial].
- **When not to use:** Not suitable for CPU-only implementations or strict performance constraints prohibiting recursion [S1, unofficial].
