# Initial Upper Bound Estimation


## Overview
Initial Upper Bound Estimation is a heuristic sampling process that computes a tight initial upper bound to prune BVH-tree traversal during distance field computation [S1]. It reduces the number of nodes visited by providing a conservative estimate of the distance to the isosurface before the full traversal begins [S1]. Unlike methods that rely on fixed grid resolutions or complex hierarchical structures for early exit, this method uses a small, fixed set of sample points to establish a global constraint that guides the search [S1].

## How it works
**Inputs:**
- A scalar field volume (implicit surface).
- A target isovalue for the isosurface.
- A BVH structure representing the volume data.
- $N_s$: Number of sample points (parameter).

**Outputs:**
- An initial upper bound value $d_{max}$ (the maximum distance from the ray origin to the nearest surface intersection found among samples).
- The BVH traversal state initialized with $d_{max}$.

**Data Structures:**
- **Sample Points:** A list of $N_s$ 3D points $(x_i, y_i, z_i)$ sampled from the approximated surface or volume domain. The source does not specify the exact sampling distribution (e.g., uniform, stratified), only that they are "sampled from the approximated surface" [S1].
- **Upper Bound:** A single scalar value $d_{max}$, initialized to infinity if no samples are provided.

**Steps:**
1. **Sampling:** Select $N_s$ points from the approximated surface of the scalar field [S1].
2. **Distance Calculation:** For each sample point $p_i$, compute its distance $d_i$ to the ray origin (or the relevant reference point for the traversal context). In the context of BVH traversal for distance fields, this typically involves evaluating the distance from the ray origin to the sample point's location or the distance field value at that point [S1].
3. **Bound Computation:** Compute the initial upper bound $d_{max}$ as the minimum of the distances of all sample points:
   $$ d_{max} = \min_{i=1}^{N_s} (d_i) $$
   If $N_s = 0$, $d_{max} = \infty$ [S1].
4. **Traversal Pruning:** Use $d_{max}$ to prune the BVH traversal. During traversal, if a node's bounding box is entirely outside the sphere of radius $d_{max}$ centered at the ray origin, the node is skipped [S1]. If $d_{max} = \infty$, the traversal examines nodes until the first leaf is reached [S1].

**Parameters:**
- **Number of sample points ($N_s$):** 1000 to 1500 is recommended for reasonable-sized datasets [S1]. A value of 1500 was selected in the evaluation to yield swift traversal across all datasets [S1].

**Edge Cases and Pitfalls:**
- **Zero Samples:** If no samples are provided ($N_s=0$), the traversal takes the longest time as the tree must be examined until the first leaf is reached [S1].
- **High Point Count Variables:** For variables with high point counts and even spatial distribution (e.g., CHI, vorticity), increasing samples beyond 1500 causes rapid runtime increases due to convergence toward brute-force, outweighing traversal gains [S1].
- **Precision:** The source does not specify floating-point precision issues, but the bound must be computed accurately to avoid incorrect pruning [S1].

    """
    Computes the initial upper bound for BVH traversal pruning.
    
    Args:
        samples: List of 3D points (x, y, z) sampled from the approximated surface.
        ray_origin: 3D point representing the origin of the ray.
        
    Returns:
        float: The initial upper bound distance.
    """
    if not samples:
        return float('inf')
    
    min_dist = float('inf')
    for point in samples:
        # Compute Euclidean distance from ray origin to sample point
        dx = point[0] - ray_origin[0]
        dy = point[1] - ray_origin[1]
        dz = point[2] - ray_origin[2]
        dist = (dx*dx + dy*dy + dz*dz) ** 0.5
        if dist < min_dist:
            min_dist = dist
            
    return min_dist

## Operating characteristics
- **Time Complexity:** Estimation time increases linearly with sample count $N_s$ [S1]. Traversal time decreases rapidly as $N_s$ increases, then slowly approaches a minimum [S1].
- **Memory Complexity:** Not given in the sources.
- **Measured Performance:** On the evaluated datasets, most datasets reach minimum traversal time between 2000 and 2300 points, fluctuating by 1 ms [S1]. For variables CHI and vorticity, minimums are reached at 1200 and 1500 points respectively [S1]. Beyond these points, running times increase rapidly (CHI: 94.58 to 380.36 ms; vorticity: 69.25 to 248.82 ms) [S1].
- **Scaling:** Performance gained by tighter bounds usually outweighs costs for $N_s < 1500$ [S1].
- **Strengths:** Reduces traversal time significantly with a small number of samples [S1].
- **Limitations:** For high-point-count variables, excessive sampling leads to brute-force convergence and increased runtime [S1].
- **When to use:** When BVH traversal for distance field computation is expensive and a quick estimate of the surface proximity is beneficial [S1].
- **When not to use:** When the dataset has very high point counts and even spatial distribution, as increasing samples beyond 1500 may degrade performance [S1].

## Background
Initial Upper Bound Estimation was introduced in the context of efficient GPU-accelerated computation of isosurfaces [S1]. It is part of a pipeline that includes BVH tree construction and traversal for distance field computation [S1]. The method was evaluated on combustion, hurricane, and ionization datasets [S1].
