# BVH-Based Distance Field Computation with Heuristic Initialization

Also called: BVH Distance Field Computation, Heuristic BVH Traversal for Distance Fields

## Overview
This method computes a distance field for an isosurface approximation by finding the closest point of the isosurface for every voxel in the volume using a Bounding Volume Hierarchy (BVH) tree [S1]. It differs from existing approaches by initializing the upper bound before traversal using evenly sampled points, rather than waiting for the first leaf encounter, which allows for more aggressive pruning at the beginning of the traversal [S1].

## How it works
**Inputs:**
- An array of points approximating the isosurface [S1].
- The voxel grid for which the distance field is computed [S1].

**Outputs:**
- A distance field volume where each voxel contains the distance from its center to the isosurface [S1].

**Data Structures:**
- **BVH Tree:** A binary tree where each internal node consists of a bounding box including all descendants [S1]. A leaf consists of a single primitive (a single point) [S1].
- **Stack:** Used for depth-first traversal [S1].

**Parameters:**
- **Downscaling:** The resulting distance field is downscaled to decimate the search space [S1].
- **Construction Algorithm:** Karras’s algorithm is used to build BVH-trees in parallel [S1].
- **Bounding Volume:** Bounding boxes are used for lower construction time [S1].

**Formulas:**
- Distance to internal node $n$: $d(v, n)$ is the minimum distance from voxel $v$ to the bounding box of $n$ [S1].
- Distance to leaf node $n$: $d(v, n)$ is the distance between voxel $v$ and the corresponding point of $n$ [S1].
- Initial upper bound: $d_u = \min_{p \in P} d(v, p)$ [S1].

**Steps:**
1. **Heuristic Initialization:** Estimate the upper bound before traversal [S1]. Compute the distance from the voxel $v$ to a set of sample points $P$ evenly sampled from the approximating points array (which is in scanline order) [S1]. Calculate the initial upper bound $d_u = \min_{p \in P} d(v, p)$ [S1].
2. **Stack Initialization:** Add the root of the BVH tree to a stack [S1].
3. **Traversal Loop:**
   - Pop the first node $n$ from the stack [S1].
   - If $n$ is an internal node:
     - For each child node $n_c$, compute $d(v, n_c)$ [S1].
     - If $d(v, n_c) < d_u$, push $n_c$ onto the stack [S1].
   - If $n$ is a leaf:
     - Compute $d(v, n)$ between $v$ and $n$ [S1].
     - Update $d_u$ with $\min(d_u, d(v, n))$ [S1].
4. **Termination:** Repeat Step 3 until the stack becomes empty [S1].

**Pseudocode:**
```python
def compute_distance_field(voxel_centers, isosurface_points):
    # [S1] Parallel BVH construction is implementation-specific; assume bvh_root is built.
    bvh_root = None
    
    # [S1] Downscale voxel grid to decimate search space
    # [G] Standard grid downsampling; assume voxel_centers is updated.
    
    # [S1] Pre-compute evenly sampled points for heuristic initialization
    # [G] Stride for even sampling is not specified in the sources.
    stride = max(1, len(isosurface_points) // 100)
    sample_points = isosurface_points[::stride]
    
    distance_field = {}
    
    for v in voxel_centers:
        # Step 1: Heuristic Initialization
        d_u = float('inf')
        for p in sample_points:
            dist = distance(v, p)
            if dist < d_u:
                d_u = dist
        
        # Step 2: Stack Initialization
        stack = [bvh_root]
        
        # Step 3 & 4: Traversal Loop
        while stack:
            n = stack.pop()
            
            if n.is_internal:
                for child in n.children:
                    dist = distance_to_bbox(v, child.bbox)
                    if dist < d_u:
                        stack.append(child)
            else:  # n is leaf
                dist = distance(v, n.point)
                if dist < d_u:
                    d_u = dist
        
        distance_field[v] = d_u
        
    return distance_field

def distance(v, p):
    return ((v[0] - p[0])**2 + (v[1] - p[1])**2 + (v[2] - p[2])**2)**0.5

def distance_to_bbox(v, bbox):
    # Minimum distance from point v to axis-aligned bounding box [G]
    dist_sq = 0.0
    for i in range(3):
        if v[i] < bbox.min[i]:
            dist_sq += (bbox.min[i] - v[i])**2
        elif v[i] > bbox.max[i]:
            dist_sq += (v[i] - bbox.max[i])**2
    return dist_sq**0.5
```

**Edge Cases and Pitfalls:**
- **Precision:** Floating-point precision may affect distance calculations, especially for voxels very close to the surface [G].
- **Boundaries:** Voxels far from the isosurface may have large initial upper bounds, reducing pruning efficiency [G].
- **Degenerate Input:** If the isosurface approximation is empty, the BVH will be empty, and the distance field will remain at infinity or a default value [G].

## Subtopics

### Initial Upper Bound Estimation
A heuristic sampling process that computes a tight initial upper bound to prune BVH-tree traversal during distance field computation. It sets itself apart by estimating the bound before traversal rather than upon the first leaf encounter, allowing earlier pruning. Choose it when maximizing early traversal pruning is critical. ## Operating characteristics
- **Time Complexity:** Depends on the BVH traversal depth and the number of pruned nodes. Heuristic initialization improves pruning efficiency, especially at the beginning of traversal [S1].
- **Memory Complexity:** Proportional to the size of the BVH tree and the distance field volume [G].
- **Measured Performance:** Not given in the sources [S1].
- **Scaling:** Parallelized using CUDA threads, one per voxel [S1].
- **Strengths:** Efficient pruning due to heuristic initialization; parallel construction and traversal [S1].
- **Limitations:** Requires building a BVH for every isosurface approximation; bounding boxes may not be optimal for all shapes [S1].
- **When to Use:** When computing distance fields for isosurface approximations on GPU [S1].
- **When Not to Use:** When the isosurface approximation is very small or when memory is constrained [G].

## Background
- **Origin:** The method is described in "Efficient GPU-Accelerated Computation of Isosurface ..." [S1].
