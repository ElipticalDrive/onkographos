# GPU BVH Construction via Cluster Merging

Also called: Cluster Merging BVH, GPU-based BVH Construction via Cluster Merging, VoxelFragmentML BVH Build

## Overview
This method constructs a Binary Volume Hierarchy (BVH) on the GPU by iteratively merging clusters of triangles [S1, unofficial]. It solves the problem of building hierarchical acceleration structures for ray tracing without CPU-GPU synchronization bottlenecks by using a fully parallel, double-buffered approach involving neighbor finding, prefix scans, and reallocation [S1, unofficial]. It differs from CPU-based top-down or bottom-up builders by keeping all data on the GPU and using a "merge-compact" loop that reduces the number of active clusters by half (approximately) each iteration until a single root remains [S1, unofficial].

## How it works

### Inputs and Outputs
*   **Input:** A set of static triangles. The number of input triangles is $N$ (referred to as `arraySize` or `staticData._numTriangles` in the source) [S1, unofficial].
*   **Output:** A BVH stored in a GPU buffer (`_clusterSSBO`) containing $2N - 1$ nodes (clusters) [S1, unofficial]. The final readback size is explicitly `staticData._numTriangles * 2 - 1` [S1, unofficial].

### Data Structures
*   **BVHCluster**: The data structure representing a cluster. On the CPU, it is defined as `Model3D::BVHCluster` [S1, unofficial]. On the GPU, it resides in a Shader Storage Buffer Object (SSBO) [S1, unofficial]. The exact internal fields are not specified in the source, but it represents a cluster of triangles with a bounding volume [S1, unofficial].
*   **Current Position Buffers**: Two CPU-side arrays of type `GLuint*`, `currentPosBuffer` and `currentPosBufferOut`, each of size `arraySize` (initially $N$) [S1, unofficial]. `currentPosBufferOut` is initialized with sequential integers: `currentPosBufferOut[i] = i` for $0 \le i < \text{arraySize}$ [S1, unofficial]. These buffers track the compacted position of valid clusters during the merge process [S1, unofficial].
*   **GPU Buffers (SSBOs)**:
    *   `cinBuffer`: Read cluster data for the current iteration.
    *   `coutBuffer`: Write cluster data for the next iteration (double-buffered with `cinBuffer`).
    *   `inCurrentPosition`: Read position data for the current iteration.
    *   `outCurrentPosition`: Write position data for the next iteration (double-buffered with `inCurrentPosition`).
    *   `neighborIndex`: Stores the index of the nearest neighbor for each cluster.
    *   `prefixScan`: Temporary buffer for the parallel prefix scan.
    *   `validCluster`: Flag indicating if a cluster remains valid.
    *   `mergedCluster`: Buffer storing details of merged clusters.
    *   `numNodesCount`: Buffer to store the count of remaining nodes.
    *   `arraySizeCount`: Buffer to store the updated `arraySize`.
    *   `_clusterSSBO`: Final BVH storage, sized for $N \times 2 - 1$ clusters [S1, unofficial].
    *   `_tempClusterSSBO`: Temporary cluster storage, sized for `arraySize` [S1, unofficial].
    *   `sortedFaces`: Sorted triangle indices (output of Morton sort).
    *   `gpuData->_tempClusterSSBO`: Temporary cluster data [S1, unofficial].

### Algorithm Steps
The construction consists of three main phases: Morton Code Sorting, Cluster Building, and Iterative Merging [S1, unofficial].

#### Phase 1: Morton Code Sort (Radix Sort)
Triangles are sorted by Morton code to improve spatial locality before clustering [S1, unofficial].
1. **Parameters:** `numBits = 30` (10 bits per coordinate for 3D Morton codes) [S1, unofficial].
2. **Loop:** Iterate `currentBits` from 0 to `numBits - 1` [S1, unofficial].
3. **Bit Mask:** Execute `bitMaskShader` on `mortonCodes` and `indicesBufferID_1` to split into `pBitsBufferID` (bit=1) and `nBitsBufferID` (bit=0) [S1, unofficial].
4. **Reduce:** Perform a prefix scan on `nBitsBufferID` to count zeros [S1, unofficial].
5. **Reset:** Execute `resetPositionShader` on `nBitsBufferID` with 1 group to set the last position to zero [S1, unofficial].
6. **Down Sweep:** Execute `downSweepShader` to compute final positions for the zeros [S1, unofficial].
7. **Reallocate:** Execute `reallocatePositionShader` to reorder `indicesBufferID_1` into `indicesBufferID_2` based on positions [S1, unofficial].

#### Phase 2: Build Initial Clusters
1. **Execution:** Execute `buildClusterShader` with buffers `{ staticData._groupTopologySSBO, sortedFaces, staticData->_clusterSSBO, gpuData->_tempClusterSSBO }` [S1, unofficial].
2. **Uniforms:** Set `arraySize` to the number of triangles [S1, unofficial].
3. **Groups:** Execute with `numGroups` groups [S1, unofficial].
4. **Result:** Initial leaf clusters are created in `_tempClusterSSBO` [S1, unofficial]. The source notes that `buildClusterBuffer` creates `clusterData` of size $N \times 2 - 1$ and sets up `_clusterSSBO` (write) and `_tempClusterSSBO` (write) [S1, unofficial].

#### Phase 3: Iterative Cluster Merging
The core loop reduces the number of clusters until one root remains [S1, unofficial].

**Initialization:**
1. Calculate `arraySize` = number of triangles $N$ [S1, unofficial].
2. Create input buffer `outCluster` (CPU side) [S1, unofficial].
3. Initialize `currentPosBufferOut` with `std::iota(..., 0)` [S1, unofficial].
4. Set up SSBOs: `cinBuffer`, `coutBuffer`, `inCurrentPosition`, `outCurrentPosition`, `neighborIndex`, `prefixScan`, `validCluster`, `mergedCluster`, `numNodesCount`, `arraySizeCount` [S1, unofficial].

**Main Loop:**
While `arraySize > 1`:
1. **Buffer Swapping:** Swap `coutBuffer` and `cinBuffer`, and swap `outCurrentPosition` and `inCurrentPosition` to double-buffer the cluster and position data [S1, unofficial].
2. **Group Size Calculation:** `numGroups = ComputeShader::getNumGroups(arraySize)`, `startThreads = std::ceil(arraySize / 2.0f)`, `numExec = std::ceil(std::log2(arraySize))`, `numGroups2Log = ComputeShader::getNumGroups(startThreads)` [S1, unofficial].
3. **Neighbor Finding:** Execute `findNeighborShader` with buffers `{ cinBuffer, neighborIndex }`. Set uniforms `arraySize` and `radius`. Execute with `numGroups` groups [S1, unofficial].
4. **Cluster Merging:** Execute `clusterMergingShader` with buffers `{ cinBuffer, staticData._clusterSSBO, neighborIndex, validCluster, mergedCluster, prefixScan, inCurrentPosition, numNodesCount }`. Set uniform `arraySize`. Execute with `numGroups` groups. This step merges clusters based on neighbors and writes valid/merged status and prefix scan data [S1, unofficial].
5. **Prefix Scan - Reduce Phase (First Step):** Build a binary tree summatory on `prefixScan`. Initialize `iteration = 0`. Loop `while (iteration < numExec)`: get `numThreads = threadCount[threadCount.size() - 1]`, set uniforms `iteration` and `numThreads`, execute `reduceShader` with `numGroups2Log` groups, then push `std::ceil(numThreads / 2.0f)` to `threadCount` [S1, unofficial].
6. **Prefix Scan - Reset Last Position (Second Step):** Execute `resetPositionShader` on `prefixScan` with 1 group to set the last position to zero. This is noted as faster than CPU modification [S1, unofficial].
7. **Prefix Scan - Down Sweep Phase (Third Step):** Build tree back to first level and compute final summatory on `prefixScan`. Initialize `iteration = threadCount.size() - 2`. Loop `while (iteration >= 0 && iteration < numExec)`: set uniforms `iteration` and `numThreads = threadCount[iteration]`, execute `downSweepShader` with `numGroups2Log` groups, decrement `iteration` [S1, unofficial].
8. **Reallocation:** Execute `reallocClustersShader` with buffers `{ cinBuffer, coutBuffer, validCluster, prefixScan, inCurrentPosition, outCurrentPosition }`. Set uniform `arraySize`. Execute with `numGroups` groups. This compacts the valid clusters into the output buffer [S1, unofficial].
9. **Update Cluster Size:** Execute `endLoopCompShader` with buffers `{ arraySizeCount, prefixScan, validCluster }`. Set uniform `arraySize`. Execute with 1 group. Read back the new `arraySize` from `arraySizeCount` [S1, unofficial].

**Final Readback:**
1. After the loop, read the final BVH cluster data from `staticData._clusterSSBO` into a CPU vector [S1, unofficial].
2. The size is `staticData._numTriangles * 2 - 1` [S1, unofficial].

**Cleanup:**
1. Delete GPU buffers (`coutBuffer`, `cinBuffer`, `inCurrentPosition`, `outCurrentPosition`, `neighborIndex`, `prefixScan`, `validCluster`, `mergedCluster`, `numNodesCount`, `arraySizeCount`) and CPU memory (`outCluster`, `currentPosBuffer`, `currentPosBufferOut`, `volatileGPUData`) [S1, unofficial].

### Pseudocode
```python
def gpu_bvh_cluster_merging(triangles):
    """
    Constructs a BVH on the GPU using cluster merging.
    triangles: List of triangle objects with geometry.
    Returns: BVH clusters as a list of BVHCluster objects.
    """
    N = len(triangles)
    array_size = N
    
    # Phase 1: Morton Code Sort (Radix Sort)
    # Sorts triangle indices by Morton code using a 30-bit radix sort (10 bits per coordinate) [S1, unofficial].
    morton_codes = compute_morton_codes(triangles) # [G] Generates 3D Morton codes for triangle centroids
    indices = list(range(N))
    num_bits = 30
    
    for current_bits in range(num_bits):
        # 1. Bit Mask: Split indices into pBits (bit=1) and nBits (bit=0) [S1, unofficial].
        p_bits_indices = [i for i in indices if (morton_codes[i] >> current_bits) & 1]
        n_bits_indices = [i for i in indices if not ((morton_codes[i] >> current_bits) & 1)]
        
        # 2. Reduce: Prefix scan on nBits to count zeros [S1, unofficial].
        n_count = len(n_bits_indices)
        
        # 3. Reset: Set last position to zero [S1, unofficial].
        # 4. Down Sweep: Compute positions for zeros [S1, unofficial].
        # 5. Reallocate: Reorder indices based on positions [S1, unofficial].
        new_indices = [None] * N
        n_idx = 0
        p_idx = 0
        for idx in indices:
            if (morton_codes[idx] >> current_bits) & 1:
                new_indices[n_count + p_idx] = idx
                p_idx += 1
            else:
                new_indices[n_idx] = idx
                n_idx += 1
        indices = new_indices

    # Phase 2: Build Initial Clusters
    # Execute buildClusterShader with buffers { staticData._groupTopologySSBO, sortedFaces, staticData->_clusterSSBO, gpuData->_tempClusterSSBO } [S1, unofficial].
    # Sets uniform arraySize. Executes with numGroups groups.
    clusters = build_initial_clusters(triangles, indices) # [G] Groups sorted triangles into leaf clusters
    
    # Phase 3: Iterative Merging
    # Buffers setup
    cin_buffer = clusters
    cout_buffer = [None] * (2 * N)
    in_pos = list(range(N))
    out_pos = [None] * (2 * N)
    for i in range(array_size):
        out_pos[i] = i
        
    neighbor_index = [0] * array_size
    prefix_scan = [0] * (2 * N)
    valid_cluster = [True] * array_size
    merged_cluster = [None] * (2 * N)
    thread_count = []
    
    while array_size > 1:
        # Buffer Swapping
        cin_buffer, cout_buffer = cout_buffer, cin_buffer
        in_pos, out_pos = out_pos, in_pos
        
        # Group Size Calculation
        num_groups = get_num_groups(array_size) # [G] ceil(array_size / 256)
        start_threads = ceil(array_size / 2.0)
        num_exec = ceil(log2(array_size))
        num_groups2_log = get_num_groups(start_threads)
        
        # Neighbor Finding
        radius = 1.0 # [G] Search radius for nearest neighbor clusters
        find_neighbor(cin_buffer, neighbor_index, array_size, radius) # [G] Finds nearest neighbor for each cluster
        
        # Cluster Merging
        cluster_merging(cin_buffer, neighbor_index, valid_cluster, merged_cluster, 
                        prefix_scan, in_pos, num_groups) # [G] Merges clusters based on neighbors
        
        # Prefix Scan - Reduce Phase
        iteration = 0
        while iteration < num_exec:
            num_threads = thread_count[-1] if thread_count else array_size
            reduce_shader(prefix_scan, iteration, num_threads, num_groups2_log) # [G] Parallel reduction
            thread_count.append(ceil(num_threads / 2.0))
            iteration += 1
            
        # Prefix Scan - Reset Last Position
        reset_position_shader(prefix_scan, 1) # [G] Sets last element to 0
        
        # Prefix Scan - Down Sweep Phase
        iteration = len(thread_count) - 2
        while iteration >= 0 and iteration < num_exec:
            num_threads = thread_count[iteration]
            down_sweep_shader(prefix_scan, iteration, num_threads, num_groups2_log) # [G] Parallel prefix scan
            iteration -= 1
            
        # Reallocation
        realloc_clusters(cin_buffer, cout_buffer, valid_cluster, prefix_scan, 
                         in_pos, out_pos, array_size) # [G] Compacts valid clusters
        
        # Update Cluster Size
        new_array_size = end_loop_comp(prefix_scan, valid_cluster, array_size) # [G] Counts valid clusters
        array_size = new_array_size
        
    # Final Readback
    final_bvh = read_back(cin_buffer, N) # [G] Copies result to CPU
    return final_bvh
```

### Parameters
*   `radius`: The search radius for finding nearest neighbor clusters during the merging phase. Passed as a uniform to `findNeighborShader` [S1, unofficial].
*   `numBits`: The number of bits for the radix sort, set to 30 (10 bits per coordinate for 3D Morton codes) [S1, unofficial].

### Edge Cases and Pitfalls
*   **Precision:** The use of `double` for AABB calculations (`dAABBCC`, `dvec3`) suggests high precision is required for bounding volume operations [S1, unofficial].
*   **Boundary Conditions:** The loop condition `arraySize > 1` ensures the process stops at a single root. The prefix scan reset step is critical for correctness in the down-sweep phase [S1, unofficial].
*   **Degenerate Input:** If `arraySize` is 0 or 1, the loop does not execute, and the final readback handles the base case. The source does not specify behavior for empty inputs beyond the loop condition [S1, unofficial].
