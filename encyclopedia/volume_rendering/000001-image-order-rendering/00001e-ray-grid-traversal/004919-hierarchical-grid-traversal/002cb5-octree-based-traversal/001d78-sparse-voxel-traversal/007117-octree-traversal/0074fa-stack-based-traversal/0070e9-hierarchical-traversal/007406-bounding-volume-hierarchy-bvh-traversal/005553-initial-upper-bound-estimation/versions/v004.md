# Initial Upper Bound Estimation

Also called: Heuristic Sampling for BVH Pruning

## Overview
Initial Upper Bound Estimation is a preprocessing step for Bounding Volume Hierarchy (BVH) traversal used in distance field computation for isosurfaces. It solves the problem of inefficient traversal caused by loose or non-existent initial bounds by computing a tight upper bound before the main traversal begins. It differs from standard BVH traversal [Bounding Volume Hierarchy (BVH) Traversal](18487-bounding-volume-hierarchy-bvh-traversal.md) by injecting a heuristic sampling phase that prunes the search space early, and from [BVH-Based Distance Field Computation with Heuristic Initialization](15459-bvh-based-distance-field-computation-with-heuristic-initiali.md) by specifically focusing on the trade-off between sampling cost and traversal gain.

## How it works
**Inputs:**
- A set of $N$ sample points $\{p_1, p_2, \dots, p_N\}$ sampled from the approximated isosurface.
- A Bounding Volume Hierarchy (BVH) tree representing the voxel grid or geometry.
- The target voxel or query point $q$ for which the distance field is being computed.

**Outputs:**
- An initial upper bound $d_{max}$, representing the maximum possible distance to the surface within the BVH structure, used to prune branches during traversal.

**Data Structures:**
- **Sample Points:** A list of 3D coordinates $(x, y, z)$.
- **BVH Node:** Contains bounding volume (AABB) and child pointers.

**Steps:**
1. **Sampling:** Sample $N$ points evenly from the approximated isosurface. The points should be distributed to represent the surface geometry [S1].
2. **Bound Computation:** Compute the initial upper bound $d_{max}$ based on the distances from the query point $q$ to the sampled points. Specifically, $d_{max}$ is typically set to the maximum distance from $q$ to any sampled point, or a conservative estimate derived from the spatial extent of the samples relative to the BVH root [S1].
3. **Traversal with Pruning:** Perform BVH traversal starting from the root. For each node, calculate the minimum distance from $q$ to the node's bounding volume. If this minimum distance is greater than $d_{max}$, prune the node (do not traverse its children) [S1].
4. **Fallback:** If $N=0$ (no samples), the initial upper bound is undefined or infinite. The traversal must examine nodes until the first leaf is reached to establish a baseline bound [S1].

**Parameters:**
- **Number of sample points ($N$):**
  - Recommended range: 1000 to 1500 for reasonable-sized datasets [S1].
  - Specific evaluation value: 1500 was selected to yield swift traversal across all tested datasets [S1].
  - Step size for evaluation: 50 points [S1].

**Pitfalls:**
- **High Point Count Variables:** For variables with high point counts and even spatial distribution (e.g., CHI, vorticity), increasing $N$ beyond 1500 causes rapid runtime increases. The estimation time rises linearly, and the traversal time plateaus or increases as the process converges toward brute-force [S1].
- **Convergence to Brute-Force:** Excessive sampling leads to diminishing returns in pruning efficiency while incurring high preprocessing costs [S1].

**Pseudocode:**
```python
def compute_initial_upper_bound(sample_points, query_point):
    """
    Computes the initial upper bound from sampled points.
    Returns the maximum distance from query_point to any sample point.
    """
    if not sample_points:
        return float('inf')
    
    max_dist_sq = 0
    for p in sample_points:
        dist_sq = (p.x - query_point.x)**2 + \
                  (p.y - query_point.y)**2 + \
                  (p.z - query_point.z)**2
        if dist_sq > max_dist_sq:
            max_dist_sq = dist_sq
    return math.sqrt(max_dist_sq)

def bvh_traversal_with_initial_bound(root, query_point, initial_bound):
    """
    Traverses the BVH using the initial upper bound for pruning.
    """
    stack = [root]
    min_dist = float('inf')
    
    while stack:
        node = stack.pop()
        
        # Calculate minimum distance from query_point to node's AABB
        dist_min = distance_point_aabb(query_point, node.aabb)
        
        # Pruning condition: if the closest point in the node is further
        # than the current best known distance (initial_bound), skip this node.
        if dist_min > initial_bound:
            continue
            
        # If leaf node, update min_dist and potentially tighten bound
        if node.is_leaf:
            # Compute exact distance to geometry in leaf
            d = distance_point_geometry(query_point, node.geometry)
            if d < min_dist:
                min_dist = d
                # Note: The initial bound is fixed for the traversal start,
                # but subsequent traversals might use tighter bounds.
                # Here we assume the initial bound is used for the first pass.
        else:
            # Push children to stack
            stack.append(node.left)
            stack.append(node.right)
            
    return min_dist
```

## Operating characteristics
- **Time Complexity:**
  - Estimation time: Increases linearly with the number of sample points $N$ [S1].
  - Traversal time: Decreases rapidly as $N$ increases from 0, then slowly approaches a minimum [S1].
- **Measured Performance:**
  - Without samples ($N=0$), traversal takes the longest time as the tree is examined until the first leaf [S1].
  - Most datasets reach minimum traversal time between 2000 and 2300 points, fluctuating by 1 ms [S1].
  - For variables with high point counts (CHI, vorticity), minimums are reached earlier (1200 and 1500 points respectively). Beyond these points, running times increase rapidly (e.g., CHI: 94.58 ms to 380.36 ms; vorticity: 69.25 ms to 248.82 ms) [S1].
- **Scaling:** Performance gained by tighter bounds usually outweighs costs for $N < 1500$ [S1].
- **Strengths:** Significantly reduces traversal time for most datasets by providing a tight initial bound.
- **Limitations:** Inefficient for variables with very high point counts if $N$ is set too high, leading to brute-force-like behavior.

## Background
This method was evaluated in the context of efficient GPU-accelerated computation of isosurface similarity maps. It addresses the performance bottleneck in BVH traversal for distance field computation by optimizing the initial pruning condition. The approach was tested on various scientific datasets including combustion (CHI, vorticity), hurricane (water vapor ratio), and ionization (GT) data [S1].
