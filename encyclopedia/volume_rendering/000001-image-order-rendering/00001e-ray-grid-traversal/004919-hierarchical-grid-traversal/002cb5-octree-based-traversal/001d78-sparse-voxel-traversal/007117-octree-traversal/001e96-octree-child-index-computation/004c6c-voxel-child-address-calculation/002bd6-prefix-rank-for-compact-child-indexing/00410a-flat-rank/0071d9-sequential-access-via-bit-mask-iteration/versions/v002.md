# Sequential Access via Bit Mask Iteration
Also called: Bit Mask Iterator, Compact Mask Traversal

## Overview
Sequential Access via Bit Mask Iteration is a method for traversing active voxels or nodes in a sparse voxel octree by scanning compact bitmasks, providing an access pattern that outperforms random access for algorithms invariant to voxel sequence [S1, unofficial]. It sets itself apart from its parent, [Flat Rank](10397-flat-rank.md), by operating directly on the node-level `mChildMask` and `mValueMask` to locate the next set bit, rather than computing global ranks; it also differs from [Voxel-Sequential Access via VoxelBlockManager](23467-voxel-sequential-access-via-voxelblockmanager.md) by not maintaining a global contiguous index space across leaf boundaries, instead focusing on local node traversal [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   Input: A sparse voxel octree node containing `mChildMask` and `mValueMask` bitmasks, and a current bit position `offset`.
*   Output: The linear bit offset of the next active child or value relative to the node's start.

**Data Structures:**
*   `mChildMask`: A bitmask where each bit represents the existence of a child node.
*   `mValueMask`: A bitmask where each bit represents the existence of an active voxel value.
*   `DeBruijn`: A static lookup table with 32 entries mapping unique upper five bits of a power-of-two result to its bit position.

**Algorithm:**
To locate the next active value or child node, iterate over the `mChildMask` and `mValueMask` bitmasks in each node [S1, unofficial]. The core operation is computing the linear offset to the next set bit in a mask `mMask` starting from `offset` [S1, unofficial].

1.  Determine the 32-bit word index `n` and the bit offset `m` within that word from the global `offset`:
    $$ n = \text{offset} \gg 5 $$
    $$ m = \text{offset} \& 31 $$
2.  Load the current 32-bit word `b` from the mask:
    $$ b = \text{mMask}[n] $$
3.  Check if the current bit is set (trivial case):
    If $ b \& (1 \ll m) $, return `offset` [S1, unofficial].
4.  Mask out bits lower than `m` to find the next set bit in the current word:
    $$ b = b \& (0\text{xFFFFFFFF} \ll m) $$
5.  If `b` is zero, advance to the next 32-bit word until a non-zero word is found:
    While $ b == 0 $, increment $ n $ and load $ b = \text{mMask}[n] $ [S1, unofficial].
6.  Compute the position of the lowest set bit in `b` using a De Bruijn multiplication and return the global offset:
    $$ \text{bit\_pos} = \text{DeBruijn}[(b \& -b) \times 0\text{x077CB531U} \gg 27] $$
    $$ \text{return } (n \ll 5) + \text{bit\_pos} $$

**Parameters:**
*   `0x077CB531U`: The 32-bit de Bruijn constant [S1, unofficial].
*   `DeBruijn`: A static table with 32 entries [S1, unofficial].

**Pitfalls:**
*   The De Bruijn lookup computes the lowest bit position without branching (conditionals), which is critical for performance [S1, unofficial].
*   Ensure `mMask` is accessed within bounds; the sources do not specify explicit boundary checks for the end of the mask array, implying the iterator is used within valid node extents [S1, unofficial].

**Pseudocode:**
```python
# DeBruijn table definition (32 entries)
# This table maps the upper 5 bits of (x * 0x077CB531U) to the bit index
# for the lowest set bit in x.
DEBRUIJN_TABLE = [
    0, 1, 28, 2, 29, 14, 24, 3, 30, 22, 20, 15, 25, 17, 4, 8, 
    31, 27, 13, 23, 21, 19, 16, 7, 26, 12, 18, 6, 11, 5, 10, 9
]

def next_set_bit(mMask, offset):
    """
    Computes the linear offset to the next set bit in mMask starting from offset.
    mMask: List of uint32_t values representing the bitmask.
    offset: Current bit position (uint32_t).
    Returns: The global bit offset of the next set bit.
    """
    n = offset >> 5
    m = offset & 31
    
    # Load the 32-bit word containing the current bit
    b = mMask[n]
    
    # Trivial case: current bit is set
    if b & (1 << m):
        return offset
    
    # Mask out lower bits to find the next set bit in this word
    b = b & (0xFFFFFFFF << m)
    
    # Find the next non-zero 32-bit word
    while b == 0:
        n += 1
        b = mMask[n]
        
    # Isolate lowest set bit, multiply by de Bruijn constant, shift to index table
    # b & -b isolates the lowest set bit
    # Multiplication by 0x077CB531U makes the upper 5 bits unique for each power of two
    # >> 27 isolates these upper 5 bits to index the table
    bit_pos = DEBRUIJN_TABLE[((b & -b) * 0x077CB531U) >> 27]
    
    return (n << 5) + bit_pos
```

## Subtopics

### [Voxel-Sequential Access via VoxelBlockManager](23467-voxel-sequential-access-via-voxelblockmanager.md)
Voxel-Sequential Access via VoxelBlockManager (VBM) is a linear iteration paradigm that traverses only active voxels in the order defined by the Index-Grid, using the VoxelBlockManager to encode the inverse map from a sequential active-voxel index to the voxel's tree position (leaf ID and in-leaf offset). It sets itself apart from its parent, [Sequential Access via Bit Mask Iteration](22343-sequential-access-via-bit-mask-iteration.md), by providing a global, contiguous index space for active voxels across leaf boundaries, enabling algorithms that require strict sequential access or stencil operations over the active set without random tree traversal overhead.

### Direct Access Bit Masks
Direct Access Bit Masks are bit masks embedded in nodes providing fast, compact direct access to binary topology. They are used for: (1) hierarchical topology encoding, (2) fast sequential iterators, (3) lossless compression, (4) boolean operations, and (5) topology dilation [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** VDB achieves O(1) constant-time complexity for both random and sequential access [S1, unofficial]. In contrast, DT-Grid/H-RLE achieve O(1) for sequential but O(log[topology]) for random lookup [S1, unofficial].
*   **Memory:** The bitmasks (`mChildMask`, `mValueMask`) are compact and cache-friendly, avoiding the need to load larger direct access tables (`mInternalDAT`, `mLeafDAT`) during iteration [S1, unofficial].
*   **Strengths:** Outperforms random access for algorithms invariant to voxel sequence (e.g., time-dependent simulations like level set propagation or fluid advection) [S1, unofficial]. The De Bruijn lookup allows branchless computation of bit positions [S1, unofficial].
*   **Limitations:** Requires the data structure to embed bitmasks in every node. Not suitable for algorithms requiring global contiguous indexing across leaf boundaries without additional management (see [Voxel-Sequential Access via VoxelBlockManager](23467-voxel-sequential-access-via-voxelblockmanager.md)) [S1, unofficial].

## Background
The method was introduced in the VDB (Voxel Database) paper by Ken Museth et al., which won an Academy Award [S1, unofficial]. It was developed to address the need for efficient traversal of dynamic sparse volumes, such as those used in fluids, narrow-band level sets, and volumetric modeling at DreamWorks Animation [S1, unofficial]. The use of De Bruijn sequences for bit manipulation is attributed to Leiserson et al. [S1, unofficial].
