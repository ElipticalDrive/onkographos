# BVH Ray Traversal with Stack

Also called: BVH Ray Traversal for Occlusion, IntersectBVHStackOcclusion, Iterative BVH traversal, Stack-based iterative BVH traversal

## Overview
This method performs an iterative, stack-based traversal of a Bounding Volume Hierarchy (BVH) to find the closest ray-triangle intersection for a single entity [S1, unofficial]. It is optimized for binary occlusion queries (shadow rays), returning the distance to the first intersection or -1.0 if no intersection occurs within the maximum ray length $T_{Max}$ [S1, unofficial]. It differs from recursive traversal by using an explicit fixed-size stack to manage traversal state, preventing stack overflow on deep trees, and from closest-point queries by focusing on the first hit rather than the global minimum across all entities [S1, unofficial]. It builds on [BVH Traversal for Closest Point](19482-bvh-traversal-for-closest-point.md) by replacing recursion with an iterative stack mechanism and handling entity-local coordinate transformations [S1, unofficial].

## How it works

### Inputs and Outputs
**Inputs:**
*   `RayOrigin`: `vec3`, ray origin in world space.
*   `RayDirection`: `vec3`, ray direction in world space.
*   `NodeStartIndex`: `int`, starting index in the global `BVHNodes` array for the current entity.
*   `NodeCount`: `int`, number of nodes in the current entity's BVH.
*   `InverseMatrix`: `mat4`, inverse model matrix of the entity.
*   `TMax`: `float`, maximum traversal distance.
*   `BVHNodes`: Array of `Node` structures.
*   `BVHTris`: Array of `Triangle` structures.
*   `BVHVertices`: Array of `Vertex` structures.
*   `u_TotalNodes`: `int`, total number of nodes in the global BVH.

**Outputs:**
*   `ClosestTraversal`: `float`, distance to the closest intersection, or -1.0 if none.
*   `oMesh`: `int`, index of the intersected mesh (entity).
*   `oTriangleIndex`: `int`, index of the intersected triangle.
*   `iters`: `int`, number of iterations performed.

### Data Structures

**Bounds**
```cpp
struct Bounds {
    vec4 Min; // x, y, z: AABB min; w: packed leaf data (StartIdx, Length)
    vec4 Max; // x, y, z: AABB max; w: child node index offset
};
```
*   For internal nodes, `Max.w` contains the offset to the child node index.
*   For leaf nodes, `Min.w` is packed: `StartIdx = Min.w >> 4`, `Length = Min.w & 0xF` [S1, unofficial].

**Node**
```cpp
struct Node {
    Bounds LeftChildData;
    Bounds RightChildData;
};
```

**Triangle**
```cpp
struct Triangle {
    int PackedData[4];
};
```

**Vertex**
```cpp
struct Vertex {
    vec4 Position;
    uvec4 PackedData;
};
```

**BVHEntity**
```cpp
struct BVHEntity {
    mat4 ModelMatrix;       // 64 bytes
    mat4 InverseMatrix;     // 64 bytes
    int NodeOffset;
    int NodeCount;
    int Data[14];
};
```

### Algorithm Steps

1.  **Transform Ray:** Transform `RayOrigin` and `RayDirection` from world space to the entity's local space using `InverseMatrix`. `RayOrigin` is treated as a point ($w=1.0$), `RayDirection` as a vector ($w=0.0$) [S1, unofficial].
2.  **Compute Inverse Direction:** Calculate `InverseDirection = 1.0f / RayDirection` for slab intersection [S1, unofficial].
3.  **Initialize State:**
    *   `Stack[64]`: Fixed-size integer array.
    *   `StackPointer = 0`.
    *   `ClosestTraversal = -1.0f`.
    *   `Iterations = 0`.
    *   `CurrentNodeIndex = NodeStartIndex` [S1, unofficial].
4.  **Traversal Loop:** Iterate while `Iterations < 1024` [S1, unofficial].
    *   **Bounds Check:** If `StackPointer >= 64` or `StackPointer < 0` or `CurrentNodeIndex < NodeStartIndex` or `CurrentNodeIndex > NodeStartIndex + NodeCount` or `CurrentNodeIndex < 0` or `CurrentNodeIndex > u_TotalNodes`, break [S1, unofficial].
    *   **Fetch Node:** `CurrentNode = BVHNodes[CurrentNodeIndex]` [S1, unofficial].
    *   **Identify Children:** Determine if left and right children are leaves using `IsLeaf(CurrentNode.LeftChildData)` and `IsLeaf(CurrentNode.RightChildData)` [S1, unofficial].
    *   **Compute Traversal Distances:**
        *   If a child is a leaf, its traversal distance is `-1.0f`.
        *   Otherwise, compute `RayBounds(RayOrigin, InverseDirection, ChildBounds, TMax)` [S1, unofficial]. Let these be `LeftTraversal` and `RightTraversal`.
    *   **Intersect Leaves:**
        *   If `LeftLeaf` is true and `IntersectTriangles` is true:
            *   Extract `Packed = CurrentNode.LeftChildData.Min.w`.
            *   `StartIdx = Packed >> 4`, `Length = Packed & 0xF`.
            *   For `Idx` from 0 to `Length - 1`:
                *   Fetch `Triangle tri = BVHTris[Idx + StartIdx]`.
                *   Get vertices `A, B, C` from `BVHVertices` using `tri.PackedData`.
                *   Compute `Intersect = RayTriangle(RayOrigin, RayDirection, A, B, C)`.
                *   If `Intersect.x > 0.0f` and `Intersect.x < TMax`:
                    *   `TMax = Intersect.x`.
                    *   `ClosestTraversal = Intersect.x`.
                    *   Return `Intersect.x` (for occlusion) or update `oMesh`, `oTriangleIndex` (for closest point) [S1, unofficial].
        *   Perform the same for `RightLeaf` [S1, unofficial].
    *   **Push to Stack:**
        *   If `LeftTraversal > 0.0f` and `RightTraversal > 0.0f`:
            *   Determine closer node. If `RightTraversal < LeftTraversal`, swap `CurrentNodeIndex` and `Postponed`.
            *   `Postponed` is the farther node's index (`Max.w + NodeStartIndex`).
            *   If `StackPointer >= 63`, break [S1, unofficial].
            *   `Stack[StackPointer++] = Postponed`.
            *   `CurrentNodeIndex` becomes the closer node's index.
        *   Else if `LeftTraversal > 0.0f`: `CurrentNodeIndex` = left child index.
        *   Else if `RightTraversal > 0.0f`: `CurrentNodeIndex` = right child index.
        *   Else (neither child traversed):
            *   If `StackPointer <= 0`, break.
            *   `CurrentNodeIndex = Stack[--StackPointer]` [S1, unofficial].
5.  **Return:** Return `ClosestTraversal` and update output parameters `iters`, `oMesh`, `oTriangleIndex` [S1, unofficial].

### Pseudocode

```python
def IntersectBVHStack(RayOrigin, RayDirection, NodeStartIndex, NodeCount, InverseMatrix, TMax, BVHNodes, BVHTris, BVHVertices, u_TotalNodes):
    # 1. Transform Ray
    RayOriginLocal = vec3(InverseMatrix * vec4(RayOrigin, 1.0))
    RayDirectionLocal = vec3(InverseMatrix * vec4(RayDirection, 0.0))
    
    # 2. Inverse Direction
    InverseDirection = vec3(1.0) / RayDirectionLocal
    
    # 3. Initialize State
    Stack = [0] * 64
    StackPointer = 0
    ClosestTraversal = -1.0
    IntersectMesh = -1
    IntersectTriangleIdx = -1
    Iterations = 0
    CurrentNodeIndex = NodeStartIndex
    
    # 4. Traversal Loop
    while Iterations < 1024:
        Iterations += 1
        
        # Bounds Check
        if StackPointer >= 64 or StackPointer < 0:
            break
        if CurrentNodeIndex < NodeStartIndex or CurrentNodeIndex > NodeStartIndex + NodeCount:
            break
        if CurrentNodeIndex < 0 or CurrentNodeIndex > u_TotalNodes:
            break
            
        CurrentNode = BVHNodes[CurrentNodeIndex]
        
        # Identify Children
        LeftLeaf = IsLeaf(CurrentNode.LeftChildData)
        RightLeaf = IsLeaf(CurrentNode.RightChildData)
        
        # Compute Traversal Distances
        if LeftLeaf:
            LeftTraversal = -1.0
        else:
            LeftTraversal = RayBounds(RayOriginLocal, InverseDirection, CurrentNode.LeftChildData, TMax)
            
        if RightLeaf:
            RightTraversal = -1.0
        else:
            RightTraversal = RayBounds(RayOriginLocal, InverseDirection, CurrentNode.RightChildData, TMax)
            
        # Intersect Leaves
        if LeftLeaf:
            Packed = CurrentNode.LeftChildData.Min.w
            StartIdx = Packed >> 4
            Length = Packed & 0xF
            for Idx in range(Length):
                Tri = BVHTris[Idx + StartIdx]
                Vertices = GetVerticesFromPackedData(Tri.PackedData, BVHVertices)
                Intersect = RayTriangle(RayOriginLocal, RayDirectionLocal, Vertices[0], Vertices[1], Vertices[2])
                if Intersect.x > 0.0 and Intersect.x < TMax:
                    TMax = Intersect.x
                    ClosestTraversal = Intersect.x
                    IntersectMesh = 0 # Placeholder for entity index
                    IntersectTriangleIdx = Idx + StartIdx
                    # For occlusion, return immediately
                    # return Intersect.x
                    # For closest point, continue to find closer
                    
        if RightLeaf:
            Packed = CurrentNode.RightChildData.Min.w
            StartIdx = Packed >> 4
            Length = Packed & 0xF
            for Idx in range(Length):
                Tri = BVHTris[Idx + StartIdx]
                Vertices = GetVerticesFromPackedData(Tri.PackedData, BVHVertices)
                Intersect = RayTriangle(RayOriginLocal, RayDirectionLocal, Vertices[0], Vertices[1], Vertices[2])
                if Intersect.x > 0.0 and Intersect.x < TMax:
                    TMax = Intersect.x
                    ClosestTraversal = Intersect.x
                    IntersectMesh = 0
                    IntersectTriangleIdx = Idx + StartIdx
                    
        # Push to Stack
        if LeftTraversal > 0.0 and RightTraversal > 0.0:
            # Determine closer node
            LeftIndex = CurrentNode.LeftChildData.Max.w + NodeStartIndex
            RightIndex = CurrentNode.RightChildData.Max.w + NodeStartIndex
            
            if RightTraversal < LeftTraversal:
                CurrentNodeIndex = RightIndex
                Postponed = LeftIndex
            else:
                CurrentNodeIndex = LeftIndex
                Postponed = RightIndex
                
            if StackPointer >= 63:
                break
            Stack[StackPointer] = Postponed
            StackPointer += 1
        elif LeftTraversal > 0.0:
            CurrentNodeIndex = CurrentNode.LeftChildData.Max.w + NodeStartIndex
        elif RightTraversal > 0.0:
            CurrentNodeIndex = CurrentNode.RightChildData.Max.w + NodeStartIndex
        else:
            if StackPointer <= 0:
                break
            StackPointer -= 1
            CurrentNodeIndex = Stack[StackPointer]
            
    return ClosestTraversal, IntersectMesh, IntersectTriangleIdx, Iterations
```

### Edge Cases and Pitfalls
*   **Stack Overflow:** The stack is fixed at 64 elements. If `StackPointer` reaches 63 during a push, the traversal breaks to prevent overflow [S1, unofficial].
*   **Iteration Limit:** The loop is limited to 1024 iterations to prevent infinite loops or excessive computation on degenerate cases [S1, unofficial].
*   **Invalid Node Index:** The traversal checks if `CurrentNodeIndex` is within valid bounds (`NodeStartIndex` to `NodeStartIndex + NodeCount`, and `0` to `u_TotalNodes`). If not, it breaks [S1, unofficial].
*   **Leaf Node Handling:** Leaf nodes have a traversal distance of -1.0f and are intersected directly [S1, unofficial].
*   **Packed Data Extraction:** `StartIdx` and `Length` for leaf nodes are extracted from `Min.w` using bit shifting and masking [S1, unofficial].

## Operating characteristics

### Time and Memory Complexity
*   **Time Complexity:** $O(N)$ in the worst case for a degenerate tree, but typically $O(\log N)$ for balanced BVHs, where $N$ is the number of triangles. The iteration limit of 1024 caps the worst-case time [S1, unofficial].
*   **Memory Complexity:** $O(1)$ auxiliary space for the traversal stack, which is fixed at 64 integers [S1, unofficial].

### Strengths and Limitations
*   **Strengths:** Iterative approach prevents stack overflow on deep trees. Fixed-size stack ensures predictable memory usage. Optimized for occlusion queries by returning early on the first hit [S1, unofficial].
*   **Limitations:** Fixed stack size (64) may be insufficient for very deep BVHs, leading to early termination. Iteration limit (1024) may prevent finding intersections in extremely complex scenes [S1, unofficial].

### When to Use
Use for shadow ray occlusion queries where the first intersection is sufficient. Use when stack overflow is a concern with recursive traversal [S1, unofficial].

### When Not to Use
Use recursive traversal if the BVH depth is known to be small and stack space is not a constraint. Use closest-point traversal if the global minimum intersection is required [S1, unofficial].
