# Two-Pass Hierarchy Traversal

Also called: Two-Step Hierarchy Traversal, Two-pass traversal

## Overview
Two-Pass Hierarchy Traversal is a spatial optimization for ray tracing through hierarchical structures (typically octrees) that reduces computational cost by splitting the traversal into two distinct phases: a coarse extraction of relevant subtrees followed by a fine-grained traversal of those subtrees [S1]. It sets itself apart from sibling methods like [Iterative Up-Down Tree Traversal](21243-iterative-up-down-tree-traversal.md) by explicitly decoupling the identification of the active region from the detailed intersection testing, allowing for significant reuse of traversal state across pixel blocks [S1].

## How it works
The method optimizes the dominant cost of hierarchy traversal by avoiding redundant checks for empty or irrelevant nodes. It operates on a rooted tree $\mathcal{H}$ where nodes have bounding volumes.

**Inputs and Outputs:**
- **Input:** The spatial hierarchy $\mathcal{H}$, ray origin $\mathbf{o}$, ray direction $\mathbf{d}$, and a stopping depth parameter $D_{stop}$ relative to the leaves.
- **Output:** A set of leaf nodes (or nodes satisfying an accuracy criterion) intersected by the ray, ready for shading or scattering computation.

**Data Structures:**
- **Tree Node:** Contains bounding volume (AABB), pointer to children (if internal), and pointer to parent.
- **Subtree Buffer:** A list or stack of nodes identified in Step 1 to be processed in Step 2.

**Parameters:**
- **Stopping Depth ($D_{stop}$):** The depth relative to the leaves where the first traversal stops. A value of 3 means the first pass stops 3 levels above the leaves, producing a set of subtrees of depth 3 [S1].

**Algorithm Steps:**

1.  **Coarse Extraction (First Pass):**
    -   Start traversal from the root of $\mathcal{H}$.
    -   Perform standard ray-node intersection tests.
    -   Descend into children only if the ray intersects the node's bounding volume.
    -   **Termination Condition:** Stop descending when the current node's depth relative to the leaves is less than or equal to $D_{stop}$.
    -   Collect all such nodes into a **Subtree Buffer**. These nodes represent the coarse entry points into the relevant parts of the hierarchy [S1].

2.  **Fine Traversal (Second Pass):**
    -   For each node in the **Subtree Buffer**:
        -   Restart traversal from this node.
        -   Continue descending through the hierarchy until leaf nodes (or nodes satisfying the specific accuracy criterion for the application) are reached [S1].
        -   Perform detailed intersection tests and shading/scattering computations at these leaves.

**Pseudocode:**

```python
def two_pass_hierarchy_traversal(root, ray, stopping_depth):
    """
    Performs two-pass hierarchy traversal.
    
    Args:
        root: The root node of the spatial hierarchy.
        ray: Ray object with origin o and direction d.
        stopping_depth: Integer, depth relative to leaves where first pass stops.
        
    Returns:
        List of leaf nodes intersected by the ray.
    """
    subtree_buffer = []
    
    # Step 1: Coarse Extraction
    # Traverse from root, stopping at nodes with depth <= stopping_depth relative to leaves
    current_node = root
    stack = [current_node]
    
    while stack:
        node = stack.pop()
        
        # Check if ray intersects node bounding box
        if not ray_intersects_aabb(ray, node.bbox):
            continue
            
        # Calculate depth relative to leaves. 
        # Note: Implementation requires knowing max_depth or leaf_depth.
        # Let depth(node) be the distance to the nearest leaf in this subtree.
        depth_to_leaf = get_depth_to_leaf(node)
        
        if depth_to_leaf <= stopping_depth:
            # Reached stopping condition, add to buffer
            subtree_buffer.append(node)
        else:
            # Continue descending to children
            if node.is_internal():
                for child in node.children:
                    stack.append(child)
                    
    # Step 2: Fine Traversal
    intersected_leaves = []
    
    for start_node in subtree_buffer:
        # Restart traversal from the buffered node
        current = start_node
        stack = [current]
        
        while stack:
            node = stack.pop()
            
            if not ray_intersects_aabb(ray, node.bbox):
                continue
                
            if node.is_leaf():
                intersected_leaves.append(node)
            else:
                for child in node.children:
                    stack.append(child)
                    
    return intersected_leaves

def get_depth_to_leaf(node):
    """
    Returns the maximum depth of the subtree rooted at node, 
    measured as the number of edges to the deepest leaf.
    [G] This assumes the tree structure allows efficient depth queries.
    """
    if node.is_leaf():
        return 0
    max_child_depth = 0
    for child in node.children:
        d = get_depth_to_leaf(child)
        if d > max_child_depth:
            max_child_depth = d
    return 1 + max_child_depth
```

**Edge Cases and Pitfalls:**
-   **Stopping Depth 0:** If $D_{stop} = 0$, the first pass descends through the entire hierarchy. The second pass cost is null, and performance equals the direct implementation [S1].
-   **Secondary Rays:** The optimization (specifically tile sharing) should not be applied to secondary rays (rays that have bounced at least once) because their paths are less coherent across pixels [S1].
-   **Material Edges:** Do not apply the 2x2 pixel tile sharing savings when the block covers an edge of the material, as coherence is lost [S1].

## Subtopics

### Rendering Pipeline
This variant applies the two-pass concept to the rendering pipeline for participating media rather than just hierarchy traversal.
-   **Step 1:** Trace rays from the camera. When a ray encounters translucent material, store the ray (with start and end points) in an auxiliary buffer [S1].
-   **Step 2:** Treat all rays from the buffer, computing single, double, and multiple scattering contributions, and add them to the pixel value [S1].
-   **Details:** The auxiliary buffer contains all paths through the material, including primary and secondary rays [S1]. For single scattering, contributions are gathered only over a material layer of thickness $\ell$ (one mean-free-path), as it becomes negligible thereafter [S1]. For multiple scattering, neighboring rays are grouped using 4x4 downsampling and interpolation due to low-frequency effects [S1].

## Operating characteristics
-   **Performance:** The method reduces traversal time by up to 30% compared to naive direct implementation [S1].
-   **Optimal Parameter:** Best performance is achieved when the first step produces a set of trees of depth 3 ($D_{stop}=3$), reducing computation time by 15% for the traversal alone [S1].
-   **Tile Sharing:** When combined with sharing the first pass results over 2x2 pixel tiles for single scattering, the total computation time is reduced by 30% [S1].
-   **Complexity:** The method reduces the number of intersection tests by skipping empty internal nodes in the first pass and limiting the scope of the second pass [S1].
-   **Limitations:** The optimization is most effective for primary rays in single scattering. It provides less benefit or no benefit for secondary rays or when pixel coherence is low (e.g., at material edges) [S1].

## Background
-   **Origin:** The method was introduced in the context of point-based rendering for homogeneous participating media with refractive boundaries [S1].
-   **History:** It was developed to address the high computational cost of hierarchy traversal in both single and multiple scattering computations [S1].
-   **Usage:** It is used in GPU implementations of point-based rendering algorithms for participating media [S1].
