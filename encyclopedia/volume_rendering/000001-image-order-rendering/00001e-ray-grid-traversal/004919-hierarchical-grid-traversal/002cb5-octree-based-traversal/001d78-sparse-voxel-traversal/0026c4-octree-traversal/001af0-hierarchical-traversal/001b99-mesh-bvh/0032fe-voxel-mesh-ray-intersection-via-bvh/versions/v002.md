# Voxel Mesh Ray Intersection via BVH

Also called: Voxel Mesh Raycasting (BVH Triangle Intersection), VoxelGeometryIntersect, VoxelMeshIntersect

## Overview

Voxel Mesh Ray Intersection via BVH is a raycasting method for voxel meshes that traverses a grid of oriented sub-cubes to find intersections with voxel geometry using Binary Volume Hierarchy (BVH) triangle intersection tests [S1, unofficial]. It handles multiple meshes by first checking bounding boxes and then delegating to the specific mesh's BVH [S1, unofficial]. This method builds on [Mesh BVH](1062-mesh-bvh.md) by providing the specific traversal logic and data structures required to query triangle meshes stored within a voxelized world structure [S1, unofficial].

## How it works

### Inputs and Outputs

**Inputs:**
*   `rayOrigin`: `vec3f` position of the ray start [S1, unofficial].
*   `rayDirection`: `vec3f` normalized direction vector [S1, unofficial].
*   `worldBoundsMin`: `vec3f` minimum bounds of the entire voxel world [S1, unofficial].
*   `meshData`: Buffer containing `VoxelMeshStruct` instances [S1, unofficial].
*   `voxel_bvh`: Buffer containing BVH nodes (`AABB` structures) [S1, unofficial].
*   `voxel_indice`: Buffer containing triangle indices for all voxel nodes [S1, unofficial].
*   `indices`: Buffer containing global triangle indices [S1, unofficial].
*   `vertices`: Buffer containing vertex positions [S1, unofficial].
*   `normals`: Buffer containing vertex normals [S1, unofficial].
*   `uvs`: Buffer containing vertex UVs [S1, unofficial].
*   `MAX_DISTANCE`: `f32` maximum traversal distance [S1, unofficial].

**Outputs:**
*   `intersectResult`: Struct containing `found` (bool), `t` (f32), `hit` (bool), `error` (bool), and geometry data (normal, UV, triangle ID) [S1, unofficial].

### Data Structures

**VoxelMeshStruct** (80 bytes, 4-byte aligned):
*   Offset 0-3: `state` (`vec4f`, `x` -> active flag) [S1, unofficial].
*   Offset 4-7: `position` (`vec3f`) [S1, unofficial].
*   Offset 8-11: `indexOffsets` (`vec4f`, `x` -> vertex offset, `y` -> indice offset, `z` -> BVH tree offset, `w` -> voxel indice offset) [S1, unofficial].
*   Offset 12-15: `minBounds` (`vec3f`) [S1, unofficial].
*   Offset 16-19: `maxBounds` (`vec3f`) [S1, unofficial].

**AABB** (BVH Node):
*   `min`: `vec4f` (`xyz` -> position, `w` -> active flag) [S1, unofficial].
*   `max`: `vec4f` (`xyz` -> position, `w` -> node type: `1` for inner, `2` for voxel geometry) [S1, unofficial].

**StackNode**:
*   `nodeId`: `u32` [S1, unofficial].
*   `t`: `f32` [S1, unofficial].
*   Stack is a fixed-size array of 13 `StackNode` instances [S1, unofficial].

**Constants:**
*   `cubeSize`: 16.0 [S1, unofficial].
*   `subCubeSize`: 8.0 [S1, unofficial].
*   `halfSize`: `cubeSize / 2.0` (8.0) [S1, unofficial].
*   `rayLength`: 16.0 [S1, unofficial].
*   `STACK_SIZE`: 13 [S1, unofficial].
*   `VOXEL_NODE_INDEX`: 4095u [S1, unofficial].

### Algorithm Steps

1.  **Inverse Ray Direction:** Calculate `invDir` components to handle near-zero values:
    $$ invDir.x = \frac{1.0}{\text{sign}(rayDirection.x) \cdot \max(|rayDirection.x|, 10^{-8})} $$
    Repeat for $y$ and $z$ [S1, unofficial].

2.  **Initialization:** Set `t = INFINITY`, `totalDistance = 0.0`, `rayPosition = rayOrigin` [S1, unofficial].

3.  **Grid Traversal Loop:**
    *   Define oriented bounding cube corners relative to `rayPosition` using `rayDirection`, `rayRight`, and `rayUp` vectors with `halfSize` offset [S1, unofficial].
    *   Iterate through a $3 \times 3 \times 3$ grid of sub-cubes (indices $i, j, k$ from 0 to 2) [S1, unofficial].
    *   Calculate sub-cube center:
        $$ subCubeCenter = cubeMinCorner + rayDirection \cdot (i \cdot subCubeSize) + rayRight \cdot (j \cdot subCubeSize) + rayUp \cdot (k \cdot subCubeSize) $$
    *   Calculate sub-cube min/max corners:
        $$ subCubeMinCorner = subCubeCenter - rayDirection \cdot \frac{subCubeSize}{2.0} - rayRight \cdot \frac{subCubeSize}{2.0} - rayUp \cdot \frac{subCubeSize}{2.0} $$
    *   Lookup world mesh at `subCubeMinCorner` using `getWorldMesh` [S1, unofficial].
    *   This checks bounds and returns an index if a mesh exists [S1, unofficial].
    *   Perform bounding box intersection test between ray and voxel mesh bounds using `BoundingBoxIntersect`, storing result in `chunkT` [S1, unofficial].
    *   If mesh found, `chunkT < t`, and `chunkT < MAX_DISTANCE`, call `VoxelMeshIntersect` with `rayOrigin`, `rayDirection`, `meshLookUp.index`, and `MAX_DISTANCE` [S1, unofficial].
    *   If `VoxelMeshIntersect` returns found and `result.t <= t`, update `finalResult` and `t` [S1, unofficial].

4.  **BVH Traversal (`VoxelMeshIntersect`):**
    *   Initialize `stackIndex = 0`, `currentNodeIndex = 0`, `currentNodeT = 0.0` [S1, unofficial].
    *   Calculate `inverseDir = 1.0 / rayDirection` [S1, unofficial].
    *   Get mesh position and offset from `mesh.indexOffsets.z` [S1, unofficial].
    *   Loop:
        *   Fetch current node from `voxel_bvh[currentNodeIndex + offset]` [S1, unofficial].
        *   Check if leaf: if `currentNode.max.w == 2.0`, it is a leaf [S1, unofficial].
        *   **Leaf Processing:** Call `VoxelGeometryIntersect(rayOrigin, rayDirection, currentNodeIndex - VOXEL_NODE_INDEX, voxelMeshIndex)` [S1, unofficial].
        *   If hit, set `intersectResult.found = true`, `intersectResult.t = currentNodeT`, store geometry result, and break loop [S1, unofficial].
        *   **Internal Node Processing:**
            *   Calculate child IDs: `leftChildId = 2u * currentNodeIndex + 1u`, `rightChildId = 2u * currentNodeIndex + 2u` [S1, unofficial].
            *   Fetch children from `voxel_bvh` [S1, unofficial].
            *   Test left child: If `leftChild.min.w >= 0`, compute `leftChildT = BoundingBoxIntersect(...)` [S1, unofficial].
            *   If `leftChildT > MAX_DISTANCE`, set `leftChildT = INFINITY` [S1, unofficial].
            *   Test right child: If `rightChild.min.w >= 0`, compute `rightChildT = BoundingBoxIntersect(...)` [S1, unofficial].
            *   If `rightChildT > MAX_DISTANCE`, set `rightChildT = INFINITY` [S1, unofficial].
            *   Only left hit: If `leftChildT < INFINITY && rightChildT == INFINITY`, set `currentNodeIndex = leftChildId`, `currentNodeT = leftChildT` [S1, unofficial].
            *   Only right hit: If `rightChildT < INFINITY && leftChildT == INFINITY`, set `currentNodeIndex = rightChildId`, `currentNodeT = rightChildT` [S1, unofficial].
            *   Both children hit: If `leftChildT < INFINITY && rightChildT < INFINITY`, push the farther child onto the stack and traverse the closer child [S1, unofficial].
            *   Check stack overflow (`stackIndex >= STACK_SIZE`); if overflow, set `intersectResult.error = true` and break [S1, unofficial].

5.  **Triangle Intersection (`VoxelGeometryIntersect`):**
    *   Loop `indiceIndex` from 0 to `length` with step 3 [S1, unofficial].
    *   Get vertex indices `v1, v2, v3` from `indices` array offset by `vertexOffset` [S1, unofficial].
    *   Call `BVH_TriangleIntersect_1` with transformed vertex positions (`vertices[...] + position`) [S1, unofficial].
    *   Update closest hit: If `triResult.t < t && triResult.t != INFINITY`, update `intersectResult.hit = true`, `t = triResult.t`, `finalTriResult = triResult`, `triId = indiceIndex/3u`, `finalIndex = indiceOffset + indiceIndex` [S1, unofficial].

6.  **Normal Interpolation:**
    *   If hit, retrieve vertex normals `n1, n2, n3` and UVs `uv1, uv2, uv3` for the hit triangle [S1, unofficial].
    *   Interpolate normal:
        $$ interpolatedNormal = \text{normalize}(n1 \cdot (1.0 - u - v) + n2 \cdot u + n3 \cdot v) $$
        where `u, v` are from `finalTriResult` [S1, unofficial].

### Pseudocode

```python
import math

# Constants
CUBE_SIZE = 16.0
SUB_CUBE_SIZE = 8.0
HALF_SIZE = CUBE_SIZE / 2.0
MAX_DISTANCE = 1000.0
STACK_SIZE = 13
VOXEL_NODE_INDEX = 4095
EPSILON = 1e-8
INFINITY = float('inf')

class StackNode:
    def __init__(self, node_id, t):
        self.node_id = node_id
        self.t = t

class IntersectResult:
    def __init__(self):
        self.found = False
        self.t = INFINITY
        self.hit = False
        self.error = False
        self.normal = None
        self.uv = None
        self.tri_id = 0

def sign(x):
    if x > 0: return 1.0
    elif x < 0: return -1.0
    else: return 1.0

def vec3(x, y, z):
    return (x, y, z)

def normalize(v):
    l = math.sqrt(v[0]**2 + v[1]**2 + v[2]**2)
    if l == 0: return vec3(0,0,0)
    return vec3(v[0]/l, v[1]/l, v[2]/l)

def cross(a, b):
    return vec3(a[1]*b[2] - a[2]*b[1], a[2]*b[0] - a[0]*b[2], a[0]*b[1] - a[1]*b[0])

def dot(a, b):
    return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

def compute_basis(ray_direction):
    # [G] Standard orthogonal basis computation for raycasting
    if abs(ray_direction[1]) < 0.999:
        ray_right = normalize(cross(ray_direction, vec3(0.0, 1.0, 0.0)))
    else:
        ray_right = normalize(cross(ray_direction, vec3(1.0, 0.0, 0.0)))
    ray_up = normalize(cross(ray_direction, ray_right))
    return ray_right, ray_up

def get_world_mesh_index(position, world_bounds_min):
    # Implementation detail from notes: floor and abs on position relative to worldBoundsMin, scaled by 16
    grid_pos = ((position[0] - world_bounds_min[0]) / 16.0, 
                (position[1] - world_bounds_min[1]) / 16.0, 
                (position[2] - world_bounds_min[2]) / 16.0)
    return int(abs(math.floor(grid_pos[0])) * 1000000 + abs(math.floor(grid_pos[1])) * 1000 + abs(math.floor(grid_pos[2])))

def bounding_box_intersect(ray_origin, ray_direction, aabb_min, aabb_max):
    # Robust slab method handling zero direction components [G]
    t_min = -INFINITY
    t_max = INFINITY
    for i in range(3):
        if abs(ray_direction[i]) > EPSILON:
            t1 = (aabb_min[i] - ray_origin[i]) / ray_direction[i]
            t2 = (aabb_max[i] - ray_origin[i]) / ray_direction[i]
            t_min = max(t_min, min(t1, t2))
            t_max = min(t_max, max(t1, t2))
        else:
            if ray_origin[i] < aabb_min[i] or ray_origin[i] > aabb_max[i]:
                return INFINITY
    return t_min if t_min < t_max else INFINITY

def bvh_triangle_intersect_1(ray_origin, ray_direction, v0, v1, v2):
    # Moller-Trumbore algorithm
    edge1 = vec3(v1[0]-v0[0], v1[1]-v0[1], v1[2]-v0[2])
    edge2 = vec3(v2[0]-v0[0], v2[1]-v0[1], v2[2]-v0[2])
    h = cross(ray_direction, edge2)
    a = dot(edge1, h)
    
    if a < EPSILON:
        return None # Parallel or pointing away
    
    f = 1.0 / a
    s = vec3(ray_origin[0]-v0[0], ray_origin[1]-v0[1], ray_origin[2]-v0[2])
    u = f * dot(s, h)
    
    if u < 0.0 or u > 1.0:
        return None
        
    q = cross(s, edge1)
    v = f * dot(ray_direction, q)
    
    if v < 0.0 or u + v > 1.0:
        return None
        
    t = f * dot(edge2, q)
    
    if t > EPSILON:
        return {'t': t, 'u': u, 'v': v}
    return None

def voxel_geometry_intersect(ray_origin, ray_direction, node_index, voxel_mesh_index, mesh_data, voxel_bvh, voxel_indice, indices, vertices, normals, uvs):
    mesh = mesh_data[voxel_mesh_index]
    vertex_offset = mesh.index_offsets[0]
    indice_offset = mesh.index_offsets[1]
    
    # length <= 0 (calculated as indiceOffsets.y - indiceOffsets.x)
    length = mesh.index_offsets[1] - mesh.index_offsets[0]
    
    if length <= 0:
        return None
        
    tri_result = None
    t = INFINITY
    final_tri_id = 0
    final_index = 0
    
    for i in range(0, length, 3):
        v1_idx = indices[indice_offset + i]
        v2_idx = indices[indice_offset + i + 1]
        v3_idx = indices[indice_offset + i + 2]
        
        v1 = vec3(vertices[v1_idx][0]+mesh.position[0], vertices[v1_idx][1]+mesh.position[1], vertices[v1_idx][2]+mesh.position[2])
        v2 = vec3(vertices[v2_idx][0]+mesh.position[0], vertices[v2_idx][1]+mesh.position[1], vertices[v2_idx][2]+mesh.position[2])
        v3 = vec3(vertices[v3_idx][0]+mesh.position[0], vertices[v3_idx][1]+mesh.position[1], vertices[v3_idx][2]+mesh.position[2])
        
        res = bvh_triangle_intersect_1(ray_origin, ray_direction, v1, v2, v3)
        
        if res and res['t'] < t:
            t = res['t']
            tri_result = res
            final_tri_id = i // 3
            final_index = indice_offset + i
            
    if tri_result:
        v1_idx = indices[indice_offset + final_index]
        v2_idx = indices[indice_offset + final_index + 1]
        v3_idx = indices[indice_offset + final_index + 2]
        
        n1 = normals[v1_idx]
        n2 = normals[v2_idx]
        n3 = normals[v3_idx]
        
        u = tri_result['u']
        v = tri_result['v']
        
        interpolated_normal = normalize(vec3(n1[0]*(1.0-u-v) + n2[0]*u + n3[0]*v, 
                                           n1[1]*(1.0-u-v) + n2[1]*u + n3[1]*v, 
                                           n1[2]*(1.0-u-v) + n2[2]*u + n3[2]*v))
        
        return {
            'found': True,
            't': t,
            'hit': True,
            'normal': interpolated_normal,
            'uv': None,
            'tri_id': final_tri_id
        }
    return None

def voxel_mesh_intersect(ray_origin, ray_direction, mesh_index, max_distance, mesh_data, voxel_bvh, voxel_indice, indices, vertices, normals, uvs):
    stack = [StackNode(0, 0.0) for _ in range(STACK_SIZE)]
    stack_index = 0
    current_node_index = 0
    current_node_t = 0.0
    
    inv_dir = [
        1.0 / (sign(ray_direction[0]) * max(abs(ray_direction[0]), EPSILON)),
        1.0 / (sign(ray_direction[1]) * max(abs(ray_direction[1]), EPSILON)),
        1.0 / (sign(ray_direction[2]) * max(abs(ray_direction[2]), EPSILON))
    ]
    
    mesh = mesh_data[mesh_index]
    offset = mesh.index_offsets[2]
    
    while True:
        node = voxel_bvh[current_node_index + offset]
        
        if node.max[3] == 2.0: # Leaf
            result = voxel_geometry_intersect(
                ray_origin, ray_direction, 
                current_node_index - VOXEL_NODE_INDEX, 
                mesh_index, mesh_data, voxel_bvh, voxel_indice, 
                indices, vertices, normals, uvs
            )
            if result:
                result['t'] = current_node_t
                result['found'] = True
                return result
            else:
                # No hit in this leaf, backtrack or continue?
                # Source implies break if hit, else continue traversal
                # If no hit, we need to continue to next node
                pass
        else:
            left_child_id = 2 * current_node_index + 1
            right_child_id = 2 * current_node_index + 2
            
            left_child = voxel_bvh[left_child_id + offset]
            right_child = voxel_bvh[right_child_id + offset]
            
            left_child_t = INFINITY
            right_child_t = INFINITY
            
            if left_child.min[3] >= 0:
                left_child_t = bounding_box_intersect(
                    ray_origin, ray_direction, 
                    (left_child.min[0], left_child.min[1], left_child.min[2]), 
                    (left_child.max[0], left_child.max[1], left_child.max[2])
                )
                if left_child_t > max_distance:
                    left_child_t = INFINITY
                    
            if right_child.min[3] >= 0:
                right_child_t = bounding_box_intersect(
                    ray_origin, ray_direction, 
                    (right_child.min[0], right_child.min[1], right_child.min[2]), 
                    (right_child.max[0], right_child.max[1], right_child.max[2])
                )
                if right_child_t > max_distance:
                    right_child_t = INFINITY
                    
            if left_child_t < INFINITY and right_child_t == INFINITY:
                current_node_index = left_child_id
                current_node_t = left_child_t
            elif right_child_t < INFINITY and left_child_t == INFINITY:
                current_node_index = right_child_id
                current_node_t = right_child_t
            elif left_child_t < INFINITY and right_child_t < INFINITY:
                # Push farther child
                if stack_index >= STACK_SIZE:
                    return {'error': True}
                
                if left_child_t < right_child_t:
                    stack[stack_index] = StackNode(right_child_id, right_child_t)
                    stack_index += 1
                    current_node_index = left_child_id
                    current_node_t = left_child_t
                else:
                    stack[stack_index] = StackNode(left_child_id, left_child_t)
                    stack_index += 1
                    current_node_index = right_child_id
                    current_node_t = right_child_t
            else:
                # No hit in either child, backtrack
                if stack_index > 0:
                    stack_index -= 1
                    current_node_index = stack[stack_index].node_id
                    current_node_t = stack[stack_index].t
                else:
                    break
                    
    return None

def voxel_mesh_ray_intersection(ray_origin, ray_direction, world_bounds_min, mesh_data, voxel_bvh, voxel_indice, indices, vertices, normals, uvs):
    inv_dir = [
        1.0 / (sign(ray_direction[0]) * max(abs(ray_direction[0]), EPSILON)),
        1.0 / (sign(ray_direction[1]) * max(abs(ray_direction[1]), EPSILON)),
        1.0 / (sign(ray_direction[2]) * max(abs(ray_direction[2]), EPSILON))
    ]
    
    t = INFINITY
    ray_position = ray_origin
    final_result = None
    
    ray_right, ray_up = compute_basis(ray_direction)
    
    # Infinite loop for grid traversal
    while True:
        # Define oriented bounding cube corners
        cube_min_corner = vec3(ray_position[0] - ray_direction[0]*HALF_SIZE - ray_right[0]*HALF_SIZE - ray_up[0]*HALF_SIZE,
                               ray_position[1] - ray_direction[1]*HALF_SIZE - ray_right[1]*HALF_SIZE - ray_up[1]*HALF_SIZE,
                               ray_position[2] - ray_direction[2]*HALF_SIZE - ray_right[2]*HALF_SIZE - ray_up[2]*HALF_SIZE)
        
        for i in range(3):
            for j in range(3):
                for k in range(3):
                    sub_cube_center = vec3(cube_min_corner[0] + ray_direction[0]*(i*SUB_CUBE_SIZE) + ray_right[0]*(j*SUB_CUBE_SIZE) + ray_up[0]*(k*SUB_CUBE_SIZE),
                                           cube_min_corner[1] + ray_direction[1]*(i*SUB_CUBE_SIZE) + ray_right[1]*(j*SUB_CUBE_SIZE) + ray_up[1]*(k*SUB_CUBE_SIZE),
                                           cube_min_corner[2] + ray_direction[2]*(i*SUB_CUBE_SIZE) + ray_right[2]*(j*SUB_CUBE_SIZE) + ray_up[2]*(k*SUB_CUBE_SIZE))
                    sub_cube_min_corner = vec3(sub_cube_center[0] - ray_direction[0]*(SUB_CUBE_SIZE/2.0) - ray_right[0]*(SUB_CUBE_SIZE/2.0) - ray_up[0]*(SUB_CUBE_SIZE/2.0),
                                               sub_cube_center[1] - ray_direction[1]*(SUB_CUBE_SIZE/2.0) - ray_right[1]*(SUB_CUBE_SIZE/2.0) - ray_up[1]*(SUB_CUBE_SIZE/2.0),
                                               sub_cube_center[2] - ray_direction[2]*(SUB_CUBE_SIZE/2.0) - ray_right[2]*(SUB_CUBE_SIZE/2.0) - ray_up[2]*(SUB_CUBE_SIZE/2.0))
                    
                    mesh_index = get_world_mesh_index(sub_cube_min_corner, world_bounds_min)
                    
                    if mesh_index != -1:
                        mesh = mesh_data[mesh_index]
                        chunk_t = bounding_box_intersect(
                            ray_origin, ray_direction,
                            (mesh.min_bounds[0], mesh.min_bounds[1], mesh.min_bounds[2]),
                            (mesh.max_bounds[0], mesh.max_bounds[1], mesh.max_bounds[2])
                        )
                        
                        if chunk_t < t and chunk_t < MAX_DISTANCE:
                            result = voxel_mesh_intersect(
                                ray_origin, ray_direction, mesh_index, MAX_DISTANCE,
                                mesh_data, voxel_bvh, voxel_indice, indices, vertices, normals, uvs
                            )
                            
                            if result and result.get('found') and result['t'] <= t:
                                t = result['t']
                                final_result = result
                                
    return final_result
```

## Subtopics

## Operating characteristics

*   **Time Complexity:** $O(N)$ for grid traversal where $N$ is the number of sub-cubes visited, plus $O(H)$ for BVH traversal where $H$ is the height of the BVH tree [S1, unofficial]. Triangle intersection is $O(T)$ where $T$ is the number of triangles in the leaf node [S1, unofficial].
*   **Memory Complexity:** $O(M)$ for storing mesh data, BVH nodes, and indices [S1, unofficial]. Stack size is fixed at 13 nodes [S1, unofficial].
*   **Performance:** Depends on the density of the voxel mesh and the efficiency of the BVH [S1, unofficial]. Fixed stack size prevents recursion depth issues but may limit traversal depth [S1, unofficial].
*   **Strengths:** Handles multiple meshes efficiently, avoids recursion overhead, fixed memory usage for stack [S1, unofficial].
*   **Limitations:** Fixed stack size may lead to missed intersections if the BVH is very deep [S1, unofficial]. Requires careful handling of oriented cubes [S1, unofficial].

## Background

This method is part of the Divine Voxel Engine (DVE) and Divine Craft project, developed by Divine Star Software [S1, unofficial]. It is designed for real-time voxel rendering and raycasting in large voxel worlds [S1, unofficial].
