# HashDAG Ray Traversal

## Overview
HashDAG Ray Traversal is a GPU kernel that traverses a HashDAG structure to find the path of a ray through a sparse voxel volume, storing the sequence of child indices taken at each level [S1, unofficial]. It serves as the foundational traversal mechanism for [Shadow Tracing with HashDAG](7429-shadow-tracing-with-hashdag.md) [S1, unofficial].

## How it works
The method computes the intersection of a ray with the HashDAG by maintaining a traversal state that includes the current path, a stack for backtracking, and a cache for node metadata [S1, unofficial]. It processes one ray per thread, launching from a ray-grid [S1, unofficial].

**Inputs and Outputs:**
*   **Inputs:** `cameraPosition`, `rayMin` (near plane), `rayDDx`, `rayDDy` (derivatives for anti-aliasing or mipmapping), `imageWidth`, `imageHeight`, `dag` (the HashDAG structure) [S1, unofficial].
*   **Outputs:** A boolean indicating intersection, or the `path` (sequence of child indices) to the first intersecting leaf node, stored in `pathsSurface` [S1, unofficial].

**Data Structures:**
*   `StackEntry`: A struct containing:
    *   `index`: `uint32`, the node index in the HashDAG.
    *   `childMask`: `uint8`, bitmask of children present in the node.
    *   `visitMask`: `uint8`, bitmask of unvisited children.
*   `CachedLeaf`: Used for the last two levels (packed densely into a single 64-bit word). Contains methods `get_first_child_mask()` and `get_second_child_mask(nextChild)` [S1, unofficial].

**Algorithm Steps:**
1.  Calculate pixel coordinates from `blockIdx` and `threadIdx`; return if outside image bounds [S1, unofficial].
2.  Compute `rayOrigin` from `cameraPosition` and `rayDirection` by normalizing the vector from camera to pixel position [S1, unofficial].
3.  Compute `rayDirectionInverse` using double precision for reciprocal components [S1, unofficial].
4.  Determine `rayChildOrder` bitmask: bit 4 if $x < 0$, bit 2 if $y < 0$, bit 1 if $z < 0$ [S1, unofficial].
5.  Initialize traversal state: `level=0`, `path=(0,0,0)`, `stack`, and `cache` with root node index, `childMask`, and initial `visitMask` [S1, unofficial].
6.  Ascend the stack if no children left to visit: decrement `level` and restore `cache` from `stack` until `visitMask` is non-zero or `level` is 0 [S1, unofficial].
7.  If `level` is 0 and no children left, reset `path` and break loop [S1, unofficial].
8.  Ascend `path` by difference between old and new level, update `level` [S1, unofficial].
9.  Find next child to visit using `next_child` function based on `rayChildOrder` and current `visitMask` [S1, unofficial].
10. Mark child as visited by clearing its bit in `visitMask` [S1, unofficial].
11. Descend `path` with `nextChild`, save current `cache` to `stack` at current level, and increment `level` [S1, unofficial].
12. If `level` equals total DAG levels, break loop (leaf voxel reached) [S1, unofficial].
13. If at internal node (`level < leaf_level`), compute child index, update `childMask`, and compute new `visitMask` [S1, unofficial].
14. If at second-to-last or last level, handle packed leaf data: get `childMask` from `cachedLeaf`, update `visitMask` [S1, unofficial].
15. Store the final `path` to the output surface [S1, unofficial].

**Pseudocode:**
```python
def hashdag_ray_traversal(camera_position, ray_min, ray_ddx, ray_ddy, image_width, image_height, dag, paths_surface):
    # Standard CUDA runtime variables provided by the execution environment
    # blockIdx, blockDim, threadIdx are assumed defined
    
    # 1. Pixel and Ray Setup
    pixel_x = (blockIdx.x * blockDim.x) + threadIdx.x
    pixel_y = (blockIdx.y * blockDim.y) + threadIdx.y
    
    if pixel_x >= image_width or pixel_y >= image_height:
        return False

    # Compute ray direction by normalizing vector from camera to pixel position
    pixel_pos = (float(pixel_x), float(pixel_y), 0.0)
    ray_direction = normalize(pixel_pos - camera_position)
    ray_origin = camera_position

    # Compute rayDirectionInverse using double precision
    ray_direction_inverse = (1.0 / ray_direction.x, 1.0 / ray_direction.y, 1.0 / ray_direction.z)

    # Determine rayChildOrder bitmask: bit 4 if x<0, bit 2 if y<0, bit 1 if z<0
    ray_child_order = 0
    if ray_direction.x < 0: ray_child_order |= 1 << 4
    if ray_direction.y < 0: ray_child_order |= 1 << 2
    if ray_direction.z < 0: ray_child_order |= 1 << 1

    # 2. Initialization
    level = 0
    path = []  # Stores child indices
    stack = [None] * MAX_LEVELS
    cache = {'index': 0, 'child_mask': 0, 'visit_mask': 0}

    cache['index'] = dag.get_first_node_index()
    cache['child_mask'] = utils.child_mask(dag.get_node(0, cache['index']))
    cache['visit_mask'] = cache['child_mask'] & compute_intersection_mask(
        level=0, path=path, dag=dag, 
        ray_origin=ray_origin, ray_direction=ray_direction, 
        ray_direction_inverse=ray_direction_inverse, is_root=True
    )

    # 3. Traversal Loop
    while True:
        # Ascend if no children left to visit
        new_level = level
        while new_level > 0 and cache['visit_mask'] == 0:
            new_level -= 1
            cache = stack[new_level]
        
        if new_level == 0 and cache['visit_mask'] == 0:
            path = []
            return False  # No intersection

        # Update path and level after ascent
        path = path[:len(path) - (level - new_level)]  # ascend
        level = new_level

        # Find next child to visit based on rayChildOrder and visitMask
        next_child = find_next_child(cache['visit_mask'], ray_child_order)
        
        # Mark child as visited
        cache['visit_mask'] &= ~(1 << next_child)

        # Descend into child
        path.append(next_child)
        stack[level] = cache
        level += 1

        # Check for leaf hit
        if level == dag.levels:
            paths_surface.write(path)
            return True  # Intersection found

        # Process internal or packed leaf nodes
        if level < dag.leaf_level():
            # Internal node
            cache['index'] = dag.get_child_index(level - 1, cache['index'], cache['child_mask'], next_child)
            cache['child_mask'] = utils.child_mask(dag.get_node(level, cache['index']))
            cache['visit_mask'] = cache['child_mask'] & compute_intersection_mask(
                level=level, path=path, dag=dag, 
                ray_origin=ray_origin, ray_direction=ray_direction, 
                ray_direction_inverse=ray_direction_inverse, is_root=False
            )
        else:
            # Packed leaf data (last two levels)
            if level == dag.leaf_level():
                child_mask = cached_leaf.get_first_child_mask()
            else:
                child_mask = cached_leaf.get_second_child_mask(next_child)
            
            cache['child_mask'] = child_mask
            cache['visit_mask'] = cache['child_mask'] & compute_intersection_mask(
                level=level, path=path, dag=dag, 
                ray_origin=ray_origin, ray_direction=ray_direction, 
                ray_direction_inverse=ray_direction_inverse, is_root=False
            )

    return False

# Helper: Find next child respecting rayChildOrder priority
def find_next_child(visit_mask, ray_child_order):
    # Apply priority mask first, fallback to full visit_mask
    priority = ray_child_order & visit_mask
    if priority == 0:
        priority = visit_mask
    # Return index of highest set bit (31 - __clz equivalent)
    return 31 - priority.bit_length()

# Helper: Standard ray-octree child intersection mask computation [G]
def compute_intersection_mask(level, path, dag, ray_origin, ray_direction, ray_direction_inverse, is_root):
    mask = 0
    # Determine bounding box of current node based on level and path
    node_min, node_max = dag.get_node_bounds(level, path)
    # Test each child bit in childMask
    for child_idx in range(8):
        if not (dag.get_node(level, path[-1] if path else 0).child_mask & (1 << child_idx)):
            continue
        # Compute child AABB (2x2x2 subdivision)
        child_min, child_max = compute_child_aabb(node_min, node_max, child_idx)
        # Ray-AABB intersection test
        if ray_aabb_intersect(ray_origin, ray_direction, ray_direction_inverse, child_min, child_max):
            mask |= (1 << child_idx)
    return mask

# Helper: Ray-AABB intersection [G]
def ray_aabb_intersect(origin, direction, inv_dir, min_b, max_b):
    t_min = (min_b[0] - origin[0]) * inv_dir[0]
    t_max = (max_b[0] - origin[0]) * inv_dir[0]
    if t_min > t_max: t_min, t_max = t_max, t_min
    ty_min = (min_b[1] - origin[1]) * inv_dir[1]
    ty_max = (max_b[1] - origin[1]) * inv_dir[1]
    if ty_min > ty_max: ty_min, ty_max = ty_max, ty_min
    if t_min > ty_max or ty_min > t_max: return False
    if ty_min > t_min: t_min = ty_min
    if ty_max < t_max: t_max = ty_max
    tz_min = (min_b[2] - origin[2]) * inv_dir[2]
    tz_max = (max_b[2] - origin[2]) * inv_dir[2]
    if tz_min > tz_max: tz_min, tz_max = tz_max, tz_min
    if t_min > tz_max or tz_min > t_max: return False
    return True

# Helper: Compute child AABB from parent bounds and child index [G]
def compute_child_aabb(parent_min, parent_max, child_idx):
    mid = [(parent_min[i] + parent_max[i]) / 2.0 for i in range(3)]
    child_min = [parent_min[i] if (child_idx >> i) & 1 == 0 else mid[i] for i in range(3)]
    child_max = [mid[i] if (child_idx >> i) & 1 == 0 else parent_max[i] for i in range(3)]
    return child_min, child_max
```

**Parameters:**
*   `traceParams`: Contains `cameraPosition`, `rayMin`, `rayDDx`, `rayDDy`, `imageWidth`, `imageHeight`, and `pathsSurface` [S1, unofficial].
*   `MAX_LEVELS`: Not given in the sources.
*   `dag.leaf_level()`: Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Packed Levels:** The last two levels are packed densely into a single 64-bit word. The code must distinguish between the second-to-last level (`level == dag.leaf_level()`) and the last level (`level > dag.leaf_level()`) to retrieve the correct child mask from `cachedLeaf` [S1, unofficial].
*   **Precision:** `rayDirectionInverse` must be computed using double precision to avoid artifacts [S1, unofficial].

### [Shadow Tracing with HashDAG](7429-shadow-tracing-with-hashdag.md)
Computes final pixel color by determining if the ray's path is occluded by scene geometry (shadowed) and applying lighting/fog. It treats the HashDAG as implicit geometry for shadow testing. Choose this when shadowing is required.
