# Importance-Driven Volume Rendering with Frustum Cutout

Also called: Frustum IDVR, IDVR design

## Overview
A view-dependent cutout technique that creates a frustum-shaped void around a Volume of Interest (VOI) to allow detailed examination of internal structures while maintaining correct depth perception and visibility of the VOI from any viewing angle [S1]. It differs from the original Viola et al. (2004) conical cutout by using a frustum shape, which solves the drawback where nearby structures at the same depth of the VOI could be covered by surrounding tissue [S1].

## How it works
The method uses a two-pass raycast rendering approach to define a cutout geometry based on the depth of the VOI [S1].

### Inputs and Outputs
**Inputs:** Volumetric data containing the VOI, ray entry points texture $T_R$, ray exit points texture $T_E$ [S1].
**Outputs:** Cutout depth texture $T_C$ (defining the frustum surface), intermediate depth texture $T_V$ (from Pass 1) [S1].

### Data Structures
**Texture $T_V$ (Pass 1 Output):** 4-component floating-point texture [S1]. Fields: $x, y, z$ coordinates of the deepest VOI voxel hit by the ray, and accumulated length $l_a$ along the ray until that voxel [S1]. If a ray does not hit the VOI, all four values are set to zero [S1].

### Steps

#### Pass 1: Depth Texture Generation
1. For each pixel, define a view ray using entry points from $T_R$ and exit points from $T_E$ [S1].
2. Trace the ray through the volume to find the deepest voxel belonging to the VOI [S1].
3. Calculate the accumulated length $l_a$ from the ray origin to this deepest voxel [S1].
4. Store the coordinates $(x, y, z)$ of this voxel and $l_a$ into the corresponding texel in $T_V$ [S1].
5. If the ray misses the VOI entirely, store $(0, 0, 0, 0)$ in $T_V$ [S1].

#### Pass 2: Frustum Cutout Definition
1. For each pixel, retrieve the ray entry point $P_R$ from $T_R$ [S1].
2. Determine a reference texel $P_V$ in $T_V$ relative to $P_R$ [S1]. Three implementations are defined:
   - **Implementation 1 ($P_{V1}$):** Search for a texel in $T_V$ with $l_a > 0$ within a maximum distance $d$ in X and Y directions from the texel coordinates of $P_R$ [S1]. Iterate from the texel with the same coordinates as $P_R$ outwards to distance $d$ [S1]. Select $P_{V1}$ that minimizes the Euclidean distance $|P_R P_{V1}|$ [S1].
   - **Implementation 2 ($P_{V2}$):** Search for a texel in $T_V$ with $l_a > 0$ within distance $d$ in X and Y directions from $P_R$ [S1]. Iterate starting from 0, checking in $\pm d$ in X and Y [S1]. Select $P_{V2}$ that creates a vector $P_R P_{V2}$ with the minimum angle between $P_R P_{V2}$ and the X or Y axis [S1]. Terminate iteration if a sufficient $P_{V2}$ is found [S1].
   - **Implementation 3 ($P_{Vd}$):** Search for a texel in $T_V$ with $l_a > 0$ within distance $\pm d$ in X and Y directions from $P_R$ [S1]. Select $P_{Vd}$ that has the highest $l_a$ value among candidates [S1]. This approach neglects small outliers to create a smoother surface [S1].
3. Let $V$ be the voxel corresponding to the selected $P_V$ (or $P_{Vd}$) [S1].
4. Calculate the maximum search radius $r_1$: $r_1 = \sqrt{d^2 + d^2}$, with constraint $d^2 + d^2 \ge |P_R P_V|$ [S1].
5. Construct vector $R_V$: $V$ is the voxel of the VOI corresponding to $P_V$ [S1]. $R$ is defined using the congruence theorem of triangles, constructing an edge with a 90-degree angle from the view ray to $V$ [S1]. $R_V$ is the vector representing this geometric construction [S1]. For Implementation 3, use $P_{Vd}$ to calculate $P_R P_{Vd}$ and derive $R_{Vd}$ [S1].
6. Determine if the ray hits the top surface of the frustum: If $|R_V| \le r_2$ (where $r_2 \le r_1$), the ray hits the top surface [S1].
7. Calculate the depth value $c$ of the top surface of the frustum for the current view ray:
   - **For Implementations 1 and 2:** $c = |R_V| - |R_V| \frac{|P_R P_V| - r_2}{r_1 - r_2}$ [S1].
   - **For Implementation 3:** $c = |R_{Vd}| - |R_{Vd}| \frac{|P_R P_V| - r_2}{r_1 - r_2}$ [S1].
8. If the ray does not hit the top surface ($|R_V| > r_2$), the cutout depth is determined by the frustum face geometry [S1].

### Parameters
*   $d$: Maximum distance in X and Y directions for searching texels in $T_V$ relative to $P_R$. Typical value: Not given in the sources [S1].
*   $r_2$: Radius limiting the top surface size. Constraint: $r_2 \le r_1$. Typical value: Not given in the sources [S1].

### Edge Cases and Pitfalls
*   **Circular Artifacts:** Implementation 1 ($P_{V1}$) produces circular artifacts around small parts of the VOI that stick out or where depth changes occur [S1].
*   **Hard Edges:** Implementation 2 ($P_{V2}$) produces hard edges in diagonal orientation [S1].
*   **Smoothness:** Implementation 3 ($P_{Vd}$) provides the smoothest result with homogeneous depth values [S1].
*   **No Hit:** If the ray does not hit the VOI, $T_V$ contains zeros, and no cutout is generated for that ray [S1].

### Pseudocode

```python
import math

def compute_frustum_cutout(T_R, T_E, d, r2):
    # Pass 1: Generate Depth Texture T_V
    width, height = T_R.width, T_R.height
    T_V = [[None] * width for _ in range(height)]
    
    for y in range(height):
        for x in range(width):
            P_R = T_R[y][x]  # (x, y, z)
            P_E = T_E[y][x]  # (x, y, z)
            ray_dir = normalize(subtract(P_E, P_R))
            
            # Trace ray through volume to find deepest VOI voxel [G]
            # Sources do not specify the exact traversal algorithm; standard ray marching is used.
            hit = trace_ray_to_deepest_voi(P_R, ray_dir)
            
            if hit is not None:
                T_V[y][x] = [hit.x, hit.y, hit.z, hit.la]
            else:
                T_V[y][x] = [0.0, 0.0, 0.0, 0.0]

    # Pass 2: Define Cutout
    T_C = [[0.0] * width for _ in range(height)]
    r1 = math.sqrt(d**2 + d**2)
    
    for y in range(height):
        for x in range(width):
            P_R = T_R[y][x]
            P_V_texel = T_V[y][x]
            
            if P_V_texel[3] == 0:
                continue  # No VOI hit, no cutout
                
            # Implementation 3 (Recommended for smoothness)
            best_PVd = None
            best_la = -1.0
            
            x_min = max(0, x - d)
            x_max = min(width - 1, x + d)
            y_min = max(0, y - d)
            y_max = min(height - 1, y + d)
            
            for sy in range(y_min, y_max + 1):
                for sx in range(x_min, x_max + 1):
                    candidate = T_V[sy][sx]
                    if candidate[3] > 0:
                        dist_sq = (sx - x)**2 + (sy - y)**2
                        if dist_sq <= d**2:
                            if candidate[3] > best_la:
                                best_la = candidate[3]
                                best_PVd = candidate
            
            if best_PVd is None:
                continue
                
            P_Vd_pos = (best_PVd[0], best_PVd[1], best_PVd[2])
            vec_PR_PVd = subtract(P_Vd_pos, P_R)
            len_PR_PVd = length(vec_PR_PVd)
            
            P_E = T_E[y][x]
            ray_dir = normalize(subtract(P_E, P_R))
            vec_OV = subtract(P_Vd_pos, P_R)
            proj_len = dot(vec_OV, ray_dir)
            proj_vec = scale(ray_dir, proj_len)
            perp_vec = subtract(vec_OV, proj_vec)
            len_R_Vd = length(perp_vec)
            
            if len_R_Vd <= r2:
                c = proj_len
            else:
                numerator = len_PR_PVd - r2
                denominator = r1 - r2
                if denominator == 0:
                    c = len_R_Vd
                else:
                    c = len_R_Vd - len_R_Vd * (numerator / denominator)
            
            T_C[y][x] = c

    return T_C

# Standard vector math helpers [G]
def subtract(a, b): return (a[0]-b[0], a[1]-b[1], a[2]-b[2])
def dot(a, b): return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]
def length(v): return math.sqrt(v[0]**2 + v[1]**2 + v[2]**2)
def normalize(v): l = length(v); return (v[0]/l, v[1]/l, v[2]/l)
def scale(v, s): return (v[0]*s, v[1]*s, v[2]*s)
```

## Operating characteristics
*   **Time Complexity:** Two passes over the image resolution [S1]. Pass 1 is standard volume raycasting. Pass 2 involves a local search of radius $d$ for each pixel, making it $O(W \cdot H \cdot d^2)$ [S1].
*   **Memory Complexity:** Requires storage for $T_R$, $T_E$, $T_V$, and $T_C$. $T_V$ stores 4 floats per pixel [S1].
*   **Strengths:** Maintains correct depth perception; view-dependent; handles complex VOI structures better than conical cutouts by using a section-like plane [S1]. Implementation 3 provides smooth depth values [S1].
*   **Limitations:** Circular artifacts (Impl 1) or hard edges (Impl 2) if not using Impl 3. Performance depends on $d$ [S1].
*   **When to use:** When detailed examination of internal structures of a VOI is required while maintaining spatial context and depth cues [S1].

## Background
The method was developed by Hänel et al. (2014) as a modification of the Importance-Driven Volume Rendering (IDVR) algorithm by Viola et al. (2004) [S1]. The original IDVR used a conical cutout, which had the drawback that nearby structures at the same depth of the VOI could be covered by surrounding tissue (e.g., brain tissue) [S1]. The frustum cutout expands the cutout using a section-like plane aligned with the back side of the VOI to solve this issue [S1]. It was used in the interactive 3D visualization of structural changes in the brain of a person with corticobasal syndrome [S1].
