# Nonuniform Compression on Grid Models

Also called: Importance-based Nonuniform Compression

## Overview
Nonuniform Compression on Grid Models is a storage optimization technique for explicit volume rendering grids that reduces model size by applying different down-sampling scales to volume density and color features [S1]. The method operates on the insight that volume density contributes more critically to rendering quality than color features [S1]. It sets itself apart from uniform compression by asymmetrically compressing attributes and combining low-resolution grids with a sparse set of high-fidelity "important" voxels to preserve high-frequency details [S1]. This method builds on [Voxel Pruning](1693-voxel-pruning.md) by using importance scores to identify which voxels require full resolution storage [S1].

## How it works
**Inputs:** Original explicit grid model $V = \{V_\sigma, V_c\}$, where $V_\sigma$ is the volume density grid and $V_c$ is the color feature grid [S1].
**Outputs:** Compressed representation consisting of down-sampled grids $\{\hat{V}_\sigma, \hat{V}_c\}$ and a list of important voxels with their original high-resolution values [S1].

**Data Structures:**
1. **Down-sampled Grids:** $\hat{V}_\sigma$ and $\hat{V}_c$ stored at reduced resolutions [S1].
2. **Important Voxels List:** A list of tuples containing the 3D coordinates $(x, y, z)$ and the original high-resolution values $(\sigma, c)$ for voxels identified as important [S1].

**Parameters:**
* $S_c$: Down-sampling ratio for color features. Typical value: 4 [S1].
* $S_\sigma$: Down-sampling ratio for volume density. Typical value: 2 [S1].
* Ray set: A large set of rays cast across wide views for importance estimation [S1].

**Steps:**
1. **Calculate Importance Scores:** For each voxel $v_l$ in the original grid, calculate its importance score $I_l$ by casting a large set of rays across wide views and sampling points $x_i$ [S1]. The score is the sum of contributions from all sampling points influenced by the voxel:
   $$ I_l = \sum_i \mathbb{1}_{\{x_i \in \iota(v_l)\}} \cdot w_{i,l} \cdot T_i \cdot \alpha_i $$
   Where $x_i$ is a sampling point on a ray [S1]. The indicator function $\mathbb{1}_{\{x_i \in \iota(v_l)\}}$ equals 1 if $x_i$ is within the neighborhood of voxel $v_l$, and 0 otherwise [S1]. The neighborhood is defined as $\iota(v_l) = \{v_l + \delta : \delta \in [-1, 1]^3\}$ [S1]. The term $w_{i,l}$ is the linear interpolation weight of voxel $v_l$ for point $x_i$, determined by the distance between $x_i$ and the 8 adjacent voxels [S1]. The terms $T_i$ and $\alpha_i$ are the transmittance and opacity at point $x_i$, computed via standard volume rendering accumulation [G].
2. **Identify Important Voxels:** Sort all voxels by their importance scores $I_l$ in decreasing order [S1]. Select a subset of voxels with the largest scores to store at full resolution [S1]. Empirical analysis shows that approximately 17% of voxels contribute to 83% of the overall importance, and 10% contribute to 66% [S1].
3. **Compress Grids:** Apply down-sampling operations to the original grids using the specified ratios:
   $$ \hat{V}_c = \downarrow_{S_c}(V_c) $$
   $$ \hat{V}_\sigma = \downarrow_{S_\sigma}(V_\sigma) $$
   Where $\downarrow_S$ denotes the down-sampling operation by factor $S$ [S1].
4. **Store Compressed Model:** Save the down-sampled grids $\{\hat{V}_\sigma, \hat{V}_c\}$ and the list of important voxels with their original values [S1].
5. **Decompression (One-time Deployment):** To recover the grid for rendering, up-sample the compressed grids $\{\hat{V}_\sigma, \hat{V}_c\}$ to the original grid size using tri-linear interpolation [S1]. Then, replace the values at the coordinates of the stored important voxels with their original high-resolution values to obtain the recovered grid $\{\tilde{V}_\sigma, \tilde{V}_c\}$ [S1].

**Pseudocode:**
```python
import math

def downsample_grid(grid, factor):
    """Downsamples a 3D grid by taking every `factor`-th element along each axis."""
    return grid[::factor, ::factor, ::factor]

def tri_linear_interpolate(grid, x, y, z):
    """Performs tri-linear interpolation at continuous coordinates (x, y, z) on a 3D grid [G]."""
    x0, y0, z0 = math.floor(x), math.floor(y), math.floor(z)
    x1, y1, z1 = x0 + 1, y0 + 1, z0 + 1
    dx, dy, dz = x - x0, y - y0, z - z0
    # Clamp to grid bounds
    x0, x1 = max(0, min(x0, grid.shape[0]-1)), max(0, min(x1, grid.shape[0]-1))
    y0, y1 = max(0, min(y0, grid.shape[1]-1)), max(0, min(y1, grid.shape[1]-1))
    z0, z1 = max(0, min(z0, grid.shape[2]-1)), max(0, min(z1, grid.shape[2]-1))
    c00 = (1-dx)*grid[x0, y0, z0] + dx*grid[x1, y0, z0]
    c01 = (1-dx)*grid[x0, y0, z1] + dx*grid[x1, y0, z1]
    c10 = (1-dx)*grid[x0, y1, z0] + dx*grid[x1, y1, z0]
    c11 = (1-dx)*grid[x0, y1, z1] + dx*grid[x1, y1, z1]
    c0 = (1-dy)*c00 + dy*c10
    c1 = (1-dy)*c01 + dy*c11
    return (1-dz)*c0 + dz*c1

def upsample_grid(compressed, original_shape):
    """Upsamples a compressed grid to the original resolution using tri-linear interpolation [G]."""
    recovered = [0.0] * (original_shape[0] * original_shape[1] * original_shape[2])
    for x in range(original_shape[0]):
        for y in range(original_shape[1]):
            for z in range(original_shape[2]):
                cx, cy, cz = x / compressed.shape[0], y / compressed.shape[1], z / compressed.shape[2]
                recovered[x * original_shape[1] * original_shape[2] + y * original_shape[2] + z] = tri_linear_interpolate(compressed, cx, cy, cz)
    return recovered

def calculate_importance_scores(grid_sigma, grid_color, rays):
    """Calculates importance score for each voxel based on ray sampling [S1]."""
    voxel_count = grid_sigma.shape[0] * grid_sigma.shape[1] * grid_sigma.shape[2]
    importance_scores = [0.0] * voxel_count
    
    for ray in rays:
        # Sample points along the ray
        points = [ray.origin + t * ray.direction for t in ray.sample_distances]
        
        for point in points:
            # Standard volume rendering accumulation for T_i and alpha_i [G]
            sigma_i, alpha_i, transmittance_i = 0.0, 0.0, 1.0
            # Simplified accumulation for demonstration; in practice, integrate along ray segment
            sigma_i = tri_linear_interpolate(grid_sigma, point.x, point.y, point.z)
            alpha_i = 1.0 - math.exp(-sigma_i * ray.step_size)
            transmittance_i = math.exp(-sigma_i * ray.step_size)
            
            # Find influencing voxels (neighbors within [-1, 1]^3)
            influencing_voxels = []
            for dx in [-1, 0, 1]:
                for dy in [-1, 0, 1]:
                    for dz in [-1, 0, 1]:
                        nx, ny, nz = math.floor(point.x) + dx, math.floor(point.y) + dy, math.floor(point.z) + dz
                        if 0 <= nx < grid_sigma.shape[0] and 0 <= ny < grid_sigma.shape[1] and 0 <= nz < grid_sigma.shape[2]:
                            influencing_voxels.append((nx, ny, nz))
            
            for voxel_idx in influencing_voxels:
                # Calculate interpolation weight w_{i,l}
                weight = tri_linear_interpolate(grid_sigma, point.x, point.y, point.z) # Weight proportional to contribution
                # Map 3D index to 1D
                idx = voxel_idx[0] * grid_sigma.shape[1] * grid_sigma.shape[2] + voxel_idx[1] * grid_sigma.shape[2] + voxel_idx[2]
                # Add contribution to importance score
                importance_scores[idx] += weight * transmittance_i * alpha_i
                
    return importance_scores

def compress_grid(original_grid_sigma, original_grid_color, importance_scores, S_sigma=2, S_color=4, top_k_percent=0.17):
    """Compresses the grid using nonuniform downsampling and stores important voxels [S1]."""
    # Step 1: Downsample grids
    compressed_color = downsample_grid(original_grid_color, S_color)
    compressed_sigma = downsample_grid(original_grid_sigma, S_sigma)
    
    # Step 2: Identify important voxels
    voxel_indices = list(range(len(importance_scores)))
    sorted_indices = sorted(voxel_indices, key=lambda i: importance_scores[i], reverse=True)
    
    # Select top k percent
    num_important = int(len(sorted_indices) * top_k_percent)
    important_voxel_indices = sorted_indices[:num_important]
    
    # Store original values for important voxels
    important_voxels_data = []
    for idx in important_voxel_indices:
        coords = (idx // (original_grid_sigma.shape[1] * original_grid_sigma.shape[2]), 
                  (idx // original_grid_sigma.shape[2]) % original_grid_sigma.shape[1], 
                  idx % original_grid_sigma.shape[2])
        sigma_val = original_grid_sigma[coords]
        color_val = original_grid_color[coords]
        important_voxels_data.append({'coords': coords, 'sigma': sigma_val, 'color': color_val})
        
    return compressed_sigma, compressed_color, important_voxels_data

def decompress_grid(compressed_sigma, compressed_color, important_voxels_data, original_shape):
    """Recovers the grid by upsampling and replacing important voxels [S1]."""
    # Upsample compressed grids to original shape using tri-linear interpolation
    recovered_sigma = upsample_grid(compressed_sigma, original_shape)
    recovered_color = upsample_grid(compressed_color, original_shape)
    
    # Replace values at important voxel coordinates with original high-res values
    for voxel_data in important_voxels_data:
        coords = voxel_data['coords']
        recovered_sigma[coords] = voxel_data['sigma']
        recovered_color[coords] = voxel_data['color']
        
    return recovered_sigma, recovered_color
```

## Operating characteristics
* Storage Reduction: Achieves over 40x reduction in grid model storage compared to original grid models [S1].
* Quality Trade-off: Maintains competitive rendering quality with less than 0.3dB drop in PSNR compared to uncompressed models [S1].
* Performance: Enables real-time rendering speeds (e.g., 180 fps) due to reduced memory footprint and bandwidth [S1].
* Strengths: Significant storage savings with minimal quality loss; simple one-time decompression without runtime overhead [G].
* Limitations: Requires an initial pass to calculate importance scores; relies on the assumption that density is more important than color, which may vary by scene [G].
* When to Use: When storage or bandwidth is a constraint and real-time rendering is required [G].
* When Not to Use: When maximum possible visual fidelity is required without any compression artifacts, or if the scene has high-frequency details in color that are not captured by the importance metric [G].

## Background
This method was introduced in the paper "Compact Real-Time Radiance Fields with Neural Codebook" [S1]. It addresses the high storage costs of explicit grid-based neural radiance field representations [S1]. The approach leverages the observation that a small percentage of voxels contribute to the majority of rendering importance, allowing for selective high-resolution storage [S1].
