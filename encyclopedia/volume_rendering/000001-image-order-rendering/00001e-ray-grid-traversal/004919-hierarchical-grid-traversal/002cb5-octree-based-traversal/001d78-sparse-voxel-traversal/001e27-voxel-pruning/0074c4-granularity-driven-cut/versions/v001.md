# Granularity-Driven Cut

Also called: Cut selection, Granularity-Driven Cut Selection, Level-of-Detail Cut, Projected-size voxel selection, Sparse radiance voxel map selection

## Overview
Granularity-Driven Cut is a voxel selection strategy that ensures geometric consistency and scalability by choosing the coarsest node on each root-to-leaf path of an octree that satisfies a granularity constraint relative to a camera box [S1, unofficial]. It solves the problem of fitting large scenes into fixed GPU memory budgets by keeping the full octree in host memory and placing only a selected subset of voxels on the GPU, ensuring fine voxels near the camera and coarser voxels farther away [S1, unofficial]. It sets itself apart from sibling methods like [LightGaussian Pruning Scoring](3213-lightgaussian-pruning-scoring.md) or [FA-based Pruning](3236-fa-based-pruning.md) by relying on geometric projected size constraints rather than importance scores or algebraic approximations, and from [Importance-Driven Volume Rendering](7632-importance-driven-volume-rendering.md) by explicitly managing the trade-off between resolution and memory via a pixel-span target [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** An octree $O$, a box of interest $B$ (bounding the region of interest, e.g., the camera frustum or a submap), and a granularity target $\tau$ (maximum allowed projected size in pixels).
*   **Output:** A cut set $C(\tau, B, O)$, which is a set of non-overlapping voxels that form a sparse radiance voxel map [S1, unofficial].

**Data Structures:**
*   **Octree $O$:** Hierarchical grid structure. Nodes have a parent pointer $\pi(n)$ and a voxel size $v_s(n)$. The root has no parent, defined as $\pi(\text{root}) = \emptyset$ or effectively infinite distance for the formula [S1, unofficial].
*   **Box $B$:** Axis-aligned bounding box defining the region where fine detail is required.
*   **Cut Set $C$:** List of selected node indices or pointers.

**Formulas:**
The projected size proxy $r(n, B)$ bounds the projected size of voxel $n$ in every camera inside box $B$ [S1, unofficial]:

$$r(n, B) = f \frac{v_s(n)}{d(n, B)}$$

Where:
*   $f = \max(f_x, f_y)$ is the focal length of the pinhole camera [S1, unofficial].
*   $v_s(n)$ is the physical size of the voxel node $n$ [S1, unofficial].
*   $d(n, B)$ is the minimum Euclidean distance between voxel $n$ and box $B$ [S1, unofficial].

The cut set is defined as:

$$C(\tau, B, O) = \{n \in O : [r(\pi(n), B) > \tau] \wedge [r(n, B) \leq \tau \vee n \text{ is a leaf}]\}$$

Where:
*   $\tau$ is the granularity target in pixels [S1, unofficial].
*   $\pi(n)$ is the parent of node $n$. For the root, the condition $r(\pi(n), B) > \tau$ is trivially satisfied as the root has no parent [S1, unofficial].

**Parameters:**
*   $\tau$: Granularity target. Increasing $\tau$ reduces the number of selected voxels at the cost of coarser detail [S1, unofficial].
*   $n_{\text{max}}$: Maximum number of voxels resident on the GPU. During training, voxel subdivision stops when this budget is reached [S1, unofficial].

**Steps:**
1.  Define the box of interest $B$ and granularity target $\tau$.
2.  For each root-to-leaf path in the octree $O$:
    a. Traverse from the root downwards.
    b. Find the first node $n$ such that its projected size proxy $r(n, B) \leq \tau$.
    c. If no such node exists on the path (i.e., even the leaf is too large relative to $\tau$ or the path ends before satisfying the condition), select the leaf node $n_{\text{leaf}}$ to ensure coverage without holes [S1, unofficial].
    d. Otherwise, select node $n$. This node is the coarsest node on the path that is fine enough (projected size $\leq \tau$) while its parent was too coarse (projected size $> \tau$) [S1, unofficial].
3.  The union of all selected nodes forms the cut $C(\tau, B, O)$ [S1, unofficial].
4.  During deployment, place box $B$ around the moving camera or submap of interest [S1, unofficial].

**Pseudocode:**

```python
def compute_granularity_driven_cut(octree, box_B, granularity_target_tau, focal_length_f):
    """
    Computes the granularity-driven cut for an octree.
    
    Args:
        octree: The root node of the octree.
        box_B: The box of interest (bounding box).
        granularity_target_tau: Maximum allowed projected size in pixels.
        focal_length_f: Max of fx and fy.
        
    Returns:
        cut_set: A list of selected nodes.
    """
    cut_set = []
    
    # Helper to compute projected size proxy
    def projected_size_proxy(node, box):
        # v_s(node) is the physical size of the voxel
        voxel_size = node.voxel_size
        # d(node, box) is the minimum Euclidean distance between voxel and box
        distance = min_euclidean_distance(node.bounding_box, box)
        
        # Avoid division by zero if voxel intersects box (distance is 0)
        # In this case, the voxel is inside the box of interest.
        # The formula implies infinite projected size, which is > tau.
        # So we must descend to children.
        if distance == 0:
            return float('inf')
            
        return focal_length_f * (voxel_size / distance)

    # Helper to check if a node is a leaf
    def is_leaf(node):
        return node.children is None or len(node.children) == 0

    # Traverse each root-to-leaf path
    # Note: In a real implementation, this is often done via a single DFS/BFS
    # that collects the cut nodes directly.
    
    def traverse_and_select(node, parent_node):
        # Calculate projected size of current node
        r_n = projected_size_proxy(node, box_B)
        
        # Calculate projected size of parent to check the condition r(pi(n), B) > tau
        # For the root, parent is considered to have infinite projected size
        if parent_node is None:
            r_parent = float('inf')
        else:
            r_parent = projected_size_proxy(parent_node, box_B)
            
        # Condition 1: Parent was too coarse (projected size > tau)
        # Condition 2: Current node is fine enough (projected size <= tau) OR is a leaf
        is_parent_too_coarse = r_parent > granularity_target_tau
        is_current_fine_enough = r_n <= granularity_target_tau
        is_current_leaf = is_leaf(node)
        
        if is_parent_too_coarse and (is_current_fine_enough or is_current_leaf):
            # This node satisfies the cut condition
            cut_set.append(node)
            # Do not traverse children, as this node covers the space for the cut
            return
        else:
            # Continue to children
            if not is_leaf(node):
                for child in node.children:
                    traverse_and_select(child, node)
            else:
                # Leaf node reached but didn't satisfy condition?
                # This happens if r_leaf > tau.
                # According to the definition, if no node satisfies r(n,B) <= tau,
                # select the leaf.
                # However, the logic above: if is_parent_too_coarse is true,
                # and is_current_fine_enough is false, and is_current_leaf is true,
                # it enters the if block.
                # If is_parent_too_coarse is false (parent was fine enough),
                # we should have selected the parent.
                # So we only reach here if parent was fine enough but we are still traversing?
                # No, the logic selects the *first* node.
                # If parent was fine enough, parent would have been selected.
                # So we only traverse if parent was NOT fine enough (r_parent > tau).
                # If we are at a leaf and r_leaf > tau, and r_parent > tau,
                # the condition (r_parent > tau) AND (r_leaf <= tau OR is_leaf)
                # becomes True AND (False OR True) = True.
                # So the leaf is selected.
                pass

    traverse_and_select(octree, None)
    return cut_set
```

**Edge Cases and Pitfalls:**
*   **Voxel inside Box $B$:** If a voxel intersects or is inside $B$, $d(n, B) = 0$, making $r(n, B) = \infty$. This ensures the cut descends to the finest available voxels inside the box of interest [S1, unofficial].
*   **No Node Satisfies Constraint:** If no node on a root-to-leaf path satisfies $r(n, B) \leq \tau$ (e.g., even the leaf is too large), the leaf node is selected to ensure coverage without holes [S1, unofficial].
*   **Memory Budget:** During training, subdivision stops when the number of resident voxels reaches $n_{\text{max}}$ [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of nodes in the octree, as each root-to-leaf path is traversed once [S1, unofficial].
*   **Memory Complexity:** The cut size is bounded by $n_{\text{max}}$ on the GPU. The full octree remains in host memory [S1, unofficial].
*   **Strengths:** Ensures geometric consistency (no overlaps or holes) and scalability. GPU memory usage stays bounded as the scene grows [S1, unofficial].
*   **Limitations:** Requires calculating distances and projected sizes for all nodes. Performance depends on the choice of $\tau$ and $B$ [S1, unofficial].
*   **When to use:** Large-scale scenes where GPU memory is limited and geometric consistency is required [S1, unofficial].
*   **When not to use:** Small scenes that fit entirely in GPU memory, or when importance-based pruning is preferred for artistic control [S1, unofficial].

## Background
Granularity-Driven Cut was introduced in the SpaRV (Sparse Radiance Voxels) framework for scalable geometrically consistent LiDAR-Visual Mapping and Rendering [S1, unofficial]. It addresses the limitation that voxel maps grow with scene extent and requested detail, making it impossible to fit large scenes into fixed GPU memory budgets at high detail [S1, unofficial]. The method was developed to allow view-dependent level-of-detail selection based on projected size [S1, unofficial].
