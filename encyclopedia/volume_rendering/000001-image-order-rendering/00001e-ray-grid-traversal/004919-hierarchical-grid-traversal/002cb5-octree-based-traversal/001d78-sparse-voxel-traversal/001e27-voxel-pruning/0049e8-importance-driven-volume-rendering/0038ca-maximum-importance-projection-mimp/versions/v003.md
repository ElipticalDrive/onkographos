# Maximum Importance Projection (MImP)
## Overview
Maximum Importance Projection (MImP) is an importance-driven volume rendering compositing method that displays the object with the highest importance value along a ray densely, while rendering all other intersected objects as fully transparent [S1, S2, unofficial]. It solves visual clutter by acting as a cut-away view where space in front of the most important structure is clipped [S1, unofficial]. Unlike sibling methods that allow variable sparseness levels for multiple objects, MImP offers a binary choice: objects are either rendered with maximum density or not at all, making it simpler to implement but offering less control over partial visibility [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Volumetric dataset, importance values $I_o$ for each object/region, camera parameters, and a depth buffer containing the "last-hit" depth for each pixel [S2, unofficial].
*   **Output:** A 2D image where the highest-importance object is visible, and occluding lower-importance objects are removed [S1, S2, unofficial].

**Data Structures:**
*   **Depth Footprint:** A 2D image (same resolution as the output) where each pixel $i$ stores the depth $z_i$ of the last sample of the highest-importance object along the corresponding ray [S1, S2, unofficial].
*   **Distance Field:** A 2D image derived from the depth footprint, storing the distance $d_i$ of each pixel from the footprint boundary, computed via a 2D chamfer distance transform [S1, S2, unofficial].
*   **Gradient Field:** A 3D vector field (or modified gradient values) used to simulate the lighting of the cut-away surface [S2, unofficial].

**Parameters:**
*   $s_c$: The slope of the countersink (frustum slope) [S1, S2, unofficial].
*   $e_{max}$: The maximum depth value found in the depth footprint of the focus object [S1, S2, unofficial].

**Steps:**

1.  **Identify Focus Object:** For each ray, determine the object with the maximum importance value $I_{max}$ [S1, S2, unofficial].
2.  **Generate Depth Footprint:** Render the volume to determine the depth of the last-hit sample for the focus object at each pixel [S1, S2, unofficial].
3.  **Compute Distance Field:** Apply a 2D chamfer distance transform to the depth footprint to determine distances $d_i$ [S1, S2, unofficial].
4.  **Calculate New Entry Points (Conical MImP):** Find $e_{max}$, the maximum depth value in the footprint [S1, S2, unofficial]. For each pixel $i$, calculate the new starting depth $e_i$ using the formula:
    $$ e_i = e_{max} - d_i \times s_c $$
    where $d_i$ is the distance value from the chamfer transform and $s_c$ is the countersink slope [S1, S2, unofficial]. For cylindrical MImP, $e_i$ is simply $e_{max}$, resulting in a vertical clipping plane [S1, S2, unofficial].
5.  **Modify Ray Traversal:** During raycasting, for any ray where the calculated new entry point $e_i$ is closer to the eye than the original footprint depth, change the ray's starting point to $e_i$ [S1, S2, unofficial]. For cylindrical MImP, simply skip all ray samples that are ahead of (closer to the eye than) the focus object's depth [S2, unofficial].
6.  **Simulate Cut-Out Geometry (Conical MImP):** To render the newly exposed surface correctly, modify the gradient vector at the first ray sample on any modified ray [S2, unofficial]. Calculate the gradient components: the two components parallel to the image plane are estimated from the gradient of the 2D distance field, and the z-component (view direction) is set to the slope factor $s_c$ [S1, S2, unofficial]. Scale up the gradient magnitude, as gradients inside objects are typically small [S2, unofficial].
7.  **Composite:** Render the focus object using its standard dense representation (full opacity) [S1, S2, unofficial]. Render all other objects along the ray with the highest level of sparseness (fully transparent/ignored) [S1, S2, unofficial].

**Pseudocode:**

```python
import math

def compute_mimp_depth_footprint(volume, importance_map, camera):
    """
    Renders the volume to find the last-hit depth of the highest importance object.
    Returns a 2D array 'depth_footprint' of size (height, width).
    """
    width, height = camera.resolution
    depth_footprint = [[0.0] * width for _ in range(height)]
    for y in range(height):
        for x in range(width):
            ray = camera.get_ray(x, y)
            max_imp = -math.inf
            last_hit_depth = 0.0
            for sample in ray.traverse(volume):
                imp = importance_map.get(sample.object_id)
                if imp > max_imp:
                    max_imp = imp
                    last_hit_depth = sample.depth
            depth_footprint[y][x] = last_hit_depth
    return depth_footprint

def chamfer_distance_2d(depth_footprint):
    """
    Applies a 2D chamfer distance transform to the depth footprint.
    Returns a 2D array 'distance_field' where each pixel holds the distance
    to the nearest non-zero (or boundary) pixel in the footprint.
    """
    height, width = len(depth_footprint), len(depth_footprint[0])
    dist = [[0.0] * width for _ in range(height)]
    for y in range(height):
        for x in range(width):
            if depth_footprint[y][x] > 0:
                dist[y][x] = 0.0
            else:
                dist[y][x] = math.inf
    # 2-pass chamfer distance transform (3-4 algorithm)
    for y in range(height):
        for x in range(width):
            if dist[y][x] == math.inf:
                if x > 0: dist[y][x] = min(dist[y][x], dist[y][x-1] + 3)
                if y > 0: dist[y][x] = min(dist[y][x], dist[y-1][x] + 4)
    for y in range(height-1, -1, -1):
        for x in range(width-1, -1, -1):
            if dist[y][x] == math.inf:
                if x < width-1: dist[y][x] = min(dist[y][x], dist[y][x+1] + 3)
                if y < height-1: dist[y][x] = min(dist[y][x], dist[y+1][x] + 4)
    return dist

def calculate_new_entry_points(depth_footprint, distance_field, slope_sc):
    """
    Calculates the new starting depth for each ray to create a conical frustum.
    """
    height, width = len(depth_footprint), len(depth_footprint[0])
    e_max = max(max(row) for row in depth_footprint)
    new_entry_points = [[0.0] * width for _ in range(height)]
    for y in range(height):
        for x in range(width):
            d_i = distance_field[y][x]
            new_entry_points[y][x] = e_max - d_i * slope_sc
    return new_entry_points

def compute_gradient_2d(distance_field, x, y):
    """
    Computes the 2D spatial gradient of the distance field at pixel (x, y).
    """
    height, width = len(distance_field), len(distance_field[0])
    dx = 0.0
    dy = 0.0
    if x > 0: dx = distance_field[y][x] - distance_field[y][x-1]
    elif x < width-1: dx = distance_field[y][x+1] - distance_field[y][x]
    if y > 0: dy = distance_field[y][x] - distance_field[y-1][x]
    elif y < height-1: dy = distance_field[y+1][x] - distance_field[y][x]
    return dx, dy

def render_mimp(volume, camera, new_entry_points, distance_field, slope_sc):
    """
    Renders the final image using MImP logic.
    """
    width, height = camera.resolution
    image = [[0.0, 0.0, 0.0] for _ in range(height)]
    for y in range(height):
        for x in range(width):
            ray = camera.get_ray(x, y)
            start_depth = new_entry_points[y][x]
            color = [0.0, 0.0, 0.0]
            alpha = 0.0
            for sample in ray.traverse(volume, start=start_depth):
                if sample.is_focus_object:
                    grad_x, grad_y = compute_gradient_2d(distance_field, x, y)
                    # Modify gradient at first sample for conical cut-out [S2, unofficial]
                    if sample.depth == start_depth:
                        grad_z = slope_sc
                    else:
                        grad_z = sample.normal.z
                    # Scale up gradient as internal gradients are small [G]
                    scale = 10.0
                    normal = normalize([grad_x * scale, grad_y * scale, grad_z * scale])
                    shading = sample.color * max(0.0, normal.dot([0.0, 0.0, 1.0]))
                    alpha_sample = sample.opacity
                    color[0] += shading[0] * alpha_sample * (1.0 - alpha)
                    color[1] += shading[1] * alpha_sample * (1.0 - alpha)
                    color[2] += shading[2] * alpha_sample * (1.0 - alpha)
                    alpha += alpha_sample * (1.0 - alpha)
                    if alpha >= 1.0:
                        break
            image[y][x] = color
    return image
```

## Operating characteristics
*   **Time Complexity:** The method requires an initial pass to compute the depth footprint and distance field ($O(N)$ for $N$ pixels), followed by the main raycasting pass [S2, unofficial]. The distance transform is fast, typically linear in the number of pixels [S2, unofficial].
*   **Memory Complexity:** Requires storage for the depth footprint and the distance field, both of size $O(W \times H)$ where $W, H$ are image dimensions [S1, S2, unofficial].
*   **Strengths:** Simple to implement compared to other importance-based methods; fast execution due to binary sparseness (dense or transparent) [S2, unofficial].
*   **Limitations:** Suffers from spatial arrangement ambiguity similar to Maximum Intensity Projection (MIP) if cylindrical clipping is used [S1, unofficial]. Cylindrical MImP causes loss of spatial impression in parallel projection [S2, unofficial]. Less control over sparseness selection compared to methods like Average Importance Compositing [S2, unofficial].
*   **When to use:** When the goal is to quickly isolate the most important structure in a volume without occlusion from less important structures [S2, unofficial].
*   **When not to use:** When detailed spatial context of occluded structures is required, or when variable levels of transparency for multiple objects are needed [S2, unofficial].

## Background
Maximum Importance Projection (MImP) was introduced as part of Importance-Driven Volume Rendering by Viola et al. in 2004 [S1, unofficial]. The method is an adaptation of Maximum Intensity Projection (MIP) to importance values, where the "intensity" is replaced by an "importance" metric assigned to volumetric objects [S1, S2, unofficial].
