# Octree-based Hierarchical Sampling

Also called: Octree-based hierarchical sampling optimization, octree-based importance sampling

## Overview
Octree-based Hierarchical Sampling is a technique that uses an octree to determine sampling densities for volumetric data, achieving importance sampling through different sampling densities within the intersection spaces of leaf nodes and training data blocks [S1]. It sets itself apart from uniform sampling by allocating sample points proportionally to the geometric overlap between the data block and the octree leaves, and from static hierarchical sampling by dynamically adapting to the data structure's local granularity [S1].

## How it works
**Inputs:**
1.  A training data block (volumetric data).
2.  An octree structure where leaf nodes correspond to indivisible cuboid subblocks [S1].

**Outputs:**
1.  A set of sample points distributed across the training data block, with density varying by location [S1].

**Data Structures:**
*   **Octree:** A hierarchical tree structure. Each node has a position and size. Leaf nodes are "indivisible cuboid subblocks" [S1].
*   **Training Data Block:** Defined by its position and size [S1].

**Steps:**
1.  **Generate Octree:** Construct an octree where leaf nodes represent the finest granularity of the sampling space. The size of each leaf node ($S_{leaf}$) is determined by the size of the corresponding indivisible cuboid subblock [S1].
2.  **Compute Leaf Volume ($S_{leaf}$):** For each leaf node, calculate its volume based on its spatial dimensions [S1].
3.  **Compute Intersection Volume ($S_{int}$):** For each leaf node, calculate the volume of the intersection space between the leaf node and the training data block. This requires the position and size of the leaf node and the position and size of the training data block [S1].
4.  **Calculate Sample Count ($N$):** For each intersection space, compute the number of sample points to allocate using the following formula [S1]:
    $$ N = \left\lceil \frac{m \cdot S_{int}}{S_{leaf}} \right\rceil $$
    Where:
    *   $N$ is the number of sample points for that intersection space.
    *   $S_{int}$ is the volume of the intersection space.
    *   $S_{leaf}$ is the volume of the corresponding leaf node.
    *   $m$ is a scaling factor representing the total number of samples allocated to that region (implied by context as the numerator multiplier for proportional sampling) [S1].
    *   $\lceil \cdot \rceil$ denotes the ceiling function [S1].
5.  **Perform Random Sampling:** Execute random sampling within each intersection space. The number of points sampled in each space is determined by the calculated $N$ [S1].
6.  **Hierarchical Execution:** Since leaf nodes corresponding to different intersection spaces may have different depths in the octree, the sampling process is hierarchical. Points are sampled at the appropriate depth corresponding to the leaf node's granularity [S1].

**Pseudocode:**
```python
def octree_hierarchical_sampling(octree, training_block):
    """
    Performs octree-based hierarchical sampling on a training data block.
    
    Args:
        octree: An octree structure with leaf nodes. Each leaf has 'position', 'size', and 'volume'.
        training_block: A data structure with 'position' and 'size'.
        
    Returns:
        samples: A list of sample points distributed across the training block.
    """
    samples = []
    
    # m is the scaling factor for total samples per region. 
    # Not explicitly defined in sources beyond Equation 7 context [S1].
    # [G] Assume m is provided as a parameter or derived from global sample budget.
    # For this implementation, we assume m is passed or computed externally.
    # If m is not given, the method cannot be implemented fully.
    # However, Equation 7 implies m is a scalar multiplier.
    # We will treat m as an input parameter for completeness.
    
    for leaf in octree.leaves():
        # Step 2: Compute S_leaf (already available as leaf.volume in many implementations, 
        # but sources say it is obtained based on size of indivisible cuboid subblock [S1])
        s_leaf = leaf.volume
        
        # Step 3: Compute S_int (volume of intersection space)
        # Intersection of two cuboids defined by position and size
        s_int = compute_intersection_volume(leaf, training_block)
        
        # If no intersection, skip
        if s_int == 0:
            continue
            
        # Step 4: Calculate number of sample points N
        # Equation 7: N = ceil(m * S_int / S_leaf) [S1]
        # Note: The source uses 'm' in the numerator. 
        # Context implies m is related to total samples allocated to the region.
        # [G] m must be defined. We assume it is a global or local sample density factor.
        n_samples = math.ceil(m * s_int / s_leaf)
        
        # Step 5: Perform random sampling in the intersection space
        # The intersection space is a cuboid. We sample uniformly within it.
        intersection_cuboid = get_intersection_cuboid(leaf, training_block)
        
        for _ in range(n_samples):
            point = random_point_in_cuboid(intersection_cuboid)
            samples.append(point)
            
    return samples

def compute_intersection_volume(leaf, training_block):
    """Computes the volume of the intersection between two cuboids."""
    inter_min, inter_max = compute_cuboid_intersection(leaf, training_block)
    if inter_min is None:
        return 0.0
    return volume_of_cuboid(inter_min, inter_max)

def compute_cuboid_intersection(cuboid1, cuboid2):
    """Returns (min, max) of intersection, or (None, None) if disjoint."""
    min1, max1 = cuboid1.bounds()
    min2, max2 = cuboid2.bounds()
    
    inter_min = [max(min1[i], min2[i]) for i in range(3)]
    inter_max = [min(max1[i], max2[i]) for i in range(3)]
    
    if any(inter_min[i] >= inter_max[i] for i in range(3)):
        return None, None
    return inter_min, inter_max

def volume_of_cuboid(min_pt, max_pt):
    return (max_pt[0] - min_pt[0]) * (max_pt[1] - min_pt[1]) * (max_pt[2] - min_pt[2])

def get_intersection_cuboid(leaf, training_block):
    """Returns a cuboid object representing the intersection."""
    inter_min, inter_max = compute_cuboid_intersection(leaf, training_block)
    return Cuboid(min_pt=inter_min, max_pt=inter_max)

def random_point_in_cuboid(cuboid):
    """Generates a random point uniformly within the cuboid."""
    min_pt = cuboid.min_pt
    max_pt = cuboid.max_pt
    return [
        random.uniform(min_pt[0], max_pt[0]),
        random.uniform(min_pt[1], max_pt[1]),
        random.uniform(min_pt[2], max_pt[2])
    ]
```

**Parameters:**
*   $m$: A scaling factor for the number of samples. The exact definition of $m$ (e.g., total samples per leaf, total samples per block, or a density constant) is not explicitly detailed in the sources beyond its role in Equation 7 [S1].
*   Octree Granularity: Determines the size of leaf nodes ($S_{leaf}$) [S1].

**Edge Cases and Pitfalls:**
*   **Zero Intersection:** If a leaf node does not intersect the training data block, $S_{int} = 0$, and no samples are generated for that leaf [S1].
*   **Precision:** The use of the ceiling function $\lceil \cdot \rceil$ ensures at least one sample is allocated if $m \cdot S_{int} > 0$, preventing zero samples for small intersections [S1].
*   **Dynamic Failure:** The importance sampling effectiveness degrades as training weights update, requiring octree reconstruction [S1].

## Subtopics

### [Multi-stage Training Strategy](20860-multi-stage-training-strategy.md)
A training procedure that reconstructs the octree at the end of each stage to address the failure of importance sampling as model weights update. It sets itself apart by dynamically adapting the sampling distribution to the current model's error landscape, ensuring subsequent stages continue to benefit from importance sampling rather than converging prematurely on an outdated distribution.

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Not given in the sources.
*   **Strengths:** Achieves importance sampling by varying sampling densities within intersection spaces, potentially improving efficiency in regions of interest [S1].
*   **Limitations:** The importance sampling distribution becomes outdated as training proceeds and weights update, necessitating a multi-stage strategy with octree reconstruction [S1].
*   **When to Use:** When volumetric data has irregular structures or varying importance, and a hierarchical representation (octree) is available or can be constructed [S1].
*   **When Not to Use:** When the sampling distribution needs to remain static throughout training without reconstruction overhead [S1].

## Background
The method was introduced in the context of volumetric super-resolution of scientific data [S1]. It addresses the challenge of efficiently sampling irregular volumetric data by leveraging the hierarchical structure of an octree to allocate sample points based on geometric overlap [S1]. The technique is part of a broader approach that includes a multi-stage training strategy to handle the dynamic nature of deep learning optimization [S1].
