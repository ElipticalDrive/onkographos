# Detail-adaptive Octree Sampling

Also called: Detail-Adaptive Octree Resampling

## Overview
Detail-adaptive Octree Sampling is a method for rendering irregular or curvilinear grids by overcoming the fixed resolution limits of regular grids. It solves the problem of excessive storage and rendering time required to resample irregular data onto a uniform grid with the smallest cell granularity. It sets itself apart from standard regular grid volume rendering by dynamically adjusting local height based on local grid granularity, allowing for time-critical rendering of complex topologies [S1, unofficial][S2, book].

## How it works
**Inputs and Outputs:**
*   **Input:** Irregular or curvilinear grid data (e.g., tetrahedral meshes).
*   **Output:** A rendered image, typically using feedforward projection methods.

**Data Structures:**
*   **Detail-Adaptive Octree:** A hierarchical spatial partitioning structure. Unlike a uniform octree, the local height (depth/size) of nodes is determined by the local granularity of the input grid.
    *   *Layout:* Not given in the sources. The structure supports classification of nodes as `Empty`, `Leaf`, or `Branch` as per the parent method's shared principles.

**Steps:**
1.  **Decomposition:** Sample the irregular data into a detail-adaptive octree. The resolution of the octree is not fixed globally; instead, the local height of the octree nodes is determined by the local granularity of the irregular grid [S1, unofficial][S2, book].
2.  **Rendering:** Render the grid within a time-critical framework using the octree decomposition. This typically involves feedforward (projection) methods where cells are projected onto the screen one by one [S1, unofficial][S2, book].
    *   *Note:* The sources mention Projected Tetrahedra (PT) as a popular projection algorithm for this context, which decomposes tetrahedra into triangles based on their projected profile [S1, unofficial][S2, book].

## Subtopics

### Projected Tetrahedra (PT)
A feedforward projection method often used with this sampling approach. It projects cells onto the screen and decomposes them into triangles, handling four classes of projections. It is chosen when rendering irregular tetrahedral grids with high accuracy is required. See [Projected Tetrahedra](1540-projected-tetrahedra.md).

## Operating characteristics
*   **Time Complexity:** Allows rendering within a time-critical framework, implying efficiency compared to naive resampling. Exact complexity not given in the sources.
*   **Memory Complexity:** Overcomes the need to fix resolution to the smallest cell, reducing storage requirements compared to a uniform high-resolution grid. Exact memory usage not given in the sources.
*   **Strengths:** Handles irregular/curvilinear grids without excessive resampling overhead; supports time-critical rendering.
*   **Limitations:** Requires implementation of octree decomposition and potentially complex projection logic (e.g., PT classes).
*   **When to use:** When rendering irregular grids where fixed-resolution regular grids are too large for storage or rendering.
*   **When not to use:** For regular, uniform grids where standard volume rendering is sufficient.

## Background
The method was introduced to address the limitations of fixed-resolution regular grids when dealing with irregular data. It is discussed in the context of volume visualization and volume graphics, specifically regarding the rendering of curvilinear grids and tetrahedral meshes. The approach leverages octree decomposition to manage the complexity of irregular topologies [S1, unofficial][S2, book].
