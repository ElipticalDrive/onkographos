# Space-Leaping

Also called: Fast Traversal, Skip Traversal

## Overview
Space-leaping is a ray traversal optimization technique for voxel grid raycasting that accelerates rendering by skipping over empty or homogeneous regions of the volume without sampling every individual voxel [S1, unofficial]. It distinguishes itself from standard linear traversal by using spatial data structures or pre-computed metadata to determine jump distances, thereby reducing the number of memory accesses and shading computations in non-contributing areas.

## How it works
Space-leaping relies on the premise that large portions of a volume contain no data or uniform data that does not require high-frequency sampling. The method varies based on the acceleration structure employed.

### Inputs and Outputs
*   **Input**: A 3D volume grid (voxel array), ray origin $\mathbf{o}$, ray direction $\mathbf{d}$, and a traversal acceleration structure (e.g., flat pyramid, proximity cloud, or octree).
*   **Output**: Updated ray position, step size, and compositing state (color/opacity) after skipping empty regions.

### Data Structures

#### Flat Pyramid
A flat pyramid is a spatial acceleration structure where uniformity information is stored in the empty space of the 3D volume grid [S1, unofficial].
*   **Layout**: A 3D array of voxels.
*   **Fields**:
    *   If the voxel contains volume data: Stores the density/opacity value.
    *   If the voxel is empty: Stores an integer representing the level of the octree (or quadtree in 2D projection) to which this empty region belongs. This value indicates the size of the uniform block [S1, unofficial].
*   **Bit Packing**: Not specified in sources. Typically, a small integer (e.g., 2-4 bits) suffices for tree depth.

#### Proximity Cloud
A pre-computed auxiliary grid storing distance information.
*   **Layout**: A 3D array of integers, same dimensions as the volume.
*   **Fields**: For each empty voxel, stores the Manhattan or Euclidean distance (in voxel units) to the nearest non-empty (data) voxel [S1, unofficial].

#### Homogeneity-Acceleration Structure
*   **Layout**: Octree nodes.
*   **Fields**: Mean value and variance of the data within the node's bounding box [S1, unofficial].

### Algorithm Steps

The core logic depends on the specific variant. Below is the unified traversal logic for the **Flat Pyramid** and **Proximity Cloud** variants, which are the most common implementations described.

1.  **Initialize**: Start ray at entry point. Determine initial voxel coordinates $(x, y, z)$.
2.  **Check Voxel Type**:
    *   If the current voxel contains **data**: Proceed with standard raycasting (sample, composite, advance by small step $\Delta s$).
    *   If the current voxel is **empty**:
        *   **Flat Pyramid Variant**: Read the uniformity level $L$ stored in the voxel. Calculate the jump distance $J$ based on $L$. For a quadtree/octree, if level $L$ represents a block of size $2^L$, the jump distance is proportional to $2^L$ along the ray direction. Jump to the first voxel outside this uniform region.
        *   **Proximity Cloud Variant**: Read the proximity value $n$ (distance to nearest data voxel). Skip the next $n$ voxels along the ray. Update ray position by $\Delta s \times n$.
3.  **Repeat**: Continue until the ray exits the volume or the accumulated opacity exceeds a termination threshold.

### Pseudocode

```python
def space_leap_traverse(ray_origin, ray_direction, volume_grid, accel_structure):
    """
    ray_origin: (x, y, z) float
    ray_direction: (dx, dy, dz) float, normalized
    volume_grid: 3D array of voxel data
    accel_structure: 3D array of integers (flat pyramid levels or proximity distances)
    """
    # Initialize ray parameters
    t = 0.0
    x, y, z = ray_origin
    dx, dy, dz = ray_direction
    
    # Determine initial voxel coordinates
    voxel_x, voxel_y, voxel_z = floor(x), floor(y), floor(z)
    
    # Pre-calculate inverse direction for traversal steps
    inv_dx, inv_dy, inv_dz = 1.0/dx, 1.0/dy, 1.0/dz
    
    while inside_volume(voxel_x, voxel_y, voxel_z):
        # Check if current voxel has data
        if volume_grid[voxel_x, voxel_y, voxel_z].has_data:
            # Standard sampling step
            sample = volume_grid[voxel_x, voxel_y, voxel_z].value
            composite(sample)
            # Advance by a small fixed step for accurate sampling
            t += SMALL_STEP
            x, y, z = ray_origin + t * ray_direction
            voxel_x, voxel_y, voxel_z = floor(x), floor(y), floor(z)
        else:
            # Space-leaping logic
            if accel_structure_type == "FLAT_PYRAMID":
                level = accel_structure[voxel_x, voxel_y, voxel_z]
                # Calculate jump size based on tree level
                # Assuming level 0 is 1 voxel, level 1 is 2 voxels, etc.
                jump_voxels = 2 ** level
                # Advance ray by jump_voxels along the dominant axis or proportional steps
                # Simplified: jump along the axis with largest step
                step_x = abs(inv_dx) * jump_voxels
                step_y = abs(inv_dy) * jump_voxels
                step_z = abs(inv_dz) * jump_voxels
                max_step = max(step_x, step_y, step_z)
                t += max_step
                x, y, z = ray_origin + t * ray_direction
                voxel_x, voxel_y, voxel_z = floor(x), floor(y), floor(z)
                
            elif accel_structure_type == "PROXIMITY_CLOUD":
                n = accel_structure[voxel_x, voxel_y, voxel_z]
                # Skip n voxels
                # Approximate distance in ray parameter t
                # n is in voxel units, convert to t units
                # Assuming unit voxel size
                t += n * min(abs(inv_dx), abs(inv_dy), abs(inv_dz)) # Conservative estimate
                x, y, z = ray_origin + t * ray_direction
                voxel_x, voxel_y, voxel_z = floor(x), floor(y), floor(z)
                
            else:
                # Fallback: single voxel step
                t += 1.0
                x, y, z = ray_origin + t * ray_direction
                voxel_x, voxel_y, voxel_z = floor(x), floor(y), floor(z)

    return accumulated_color, accumulated_opacity
```

### Parameters and Edge Cases
*   **Termination Threshold**: A user-defined opacity level (e.g., 0.95) at which ray traversal stops [S1, unofficial].
*   **Precision**: In adaptive ray traversal, empty space is traversed with low precision, switching to high precision near "vicinity flags" (empty voxels neighboring data) [S1, unofficial].
*   **Bounding Boxes**: For sparse volumes with few objects, bounding boxes or convex polyhedra (PARC method) can be used to skip large empty regions [S1, unofficial].
*   **Temporal Coherence**: In animations, a C-buffer (Coordinates-buffer) can store the hit coordinates from the previous frame to optimize the starting point of the ray traversal [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: $O(N_{data} + N_{skip})$, where $N_{data}$ is the number of sampled data voxels and $N_{skip}$ is the number of acceleration structure lookups. Significantly faster than $O(N_{total})$ for sparse volumes.
*   **Memory Complexity**: $O(N_{total})$ for the volume grid plus $O(N_{total})$ for the acceleration structure (flat pyramid or proximity cloud).
*   **Strengths**: Drastically reduces memory bandwidth usage in sparse volumes; simple to implement with flat pyramids.
*   **Limitations**: Requires pre-processing to build the acceleration structure (e.g., computing proximity clouds); less effective for dense, noisy volumes where empty space is rare.

## Background
Space-leaping was introduced as a method to efficiently traverse regions with homogeneous structure in direct volume rendering [S1, unofficial]. The concept of storing uniformity information in the empty space of the volume grid (flat pyramid) allows for fast skipping without maintaining a separate complex tree structure in memory. The technique is particularly relevant for volumes with large empty regions or distinct objects.
