# ISSUE Algorithm
Also called: Modified ISSUE Algorithm
## Overview
The ISSUE (Isosurface Extraction using Span Space Subdivision) algorithm improves upon the NOISE algorithm by subdividing span space into an axis-aligned lattice [S2]. It solves the problem of efficient traversal and classification of volumetric cells relative to an isovalue, enabling parallel processing [S2]. It sets itself apart from siblings like Space Leaping by operating in span space (value domain) rather than spatial domain, allowing for coarser skipping based on data value ranges rather than just spatial occupancy [S1, S2].

## How it works
**Inputs and Outputs:**
*   Input: 3D volumetric dataset (list of cells with min/max values), isovalue $v$, lattice resolution $L$.
*   Output: List of active cells intersecting the isovalue.

**Data Structures:**
1.  **Lattice:** An $L \times L$ grid representing the span space (value range) [S1]. Each cell $(i, j)$ stores a list of volume cells whose min/max values map to that bin [S1].
2.  **Classification Map:** For each lattice element, a category (1-5) indicating its relationship to the isovalue $v$ [S1].
3.  **Search Structures:** For Region 5 elements: A kd-tree built on the lattice element's cells [S1]. For other regions: Sorted linear arrays (coalesced from lattice elements) [S1].

**Steps:**
1.  **Lattice Construction:** Divide the span space (range of data values) into an $L \times L$ axis-aligned lattice. Each tile contains approximately the same number of cells [S1].
2.  **Classification:** For each lattice element, determine its category based on its aggregated min/max bounds relative to the isovalue $v$ [S1]:
    *   **Region 1:** Max value $< v$. Trivially exclude cells [S1].
    *   **Region 2:** Min value $> v$. Trivially include cells [S1].
    *   **Region 3:** Min value $< v$ and Max value $> v$, located above the diagonal in span space. Requires test against Max value [S1].
    *   **Region 4:** Min value $< v$ and Max value $> v$, located below the diagonal. Requires test against Min value [S1].
    *   **Region 5:** Requires full min-max search of its cells [S1].
3.  **Structure Building (Modified ISSUE):** Identify lattice elements falling into Region 5. These lie along the diagonal $y=x$ in the lattice [S1]. Build a kd-tree for each Region 5 lattice element [S1]. Coalesce lattice elements from Regions 1-4 into sorted linear arrays [S1].
4.  **Traversal/Extraction:** Query the structures to find active cells. For Region 5, use the kd-tree to find cells intersecting the isovalue. For other regions, use the sorted arrays or trivial inclusion/exclusion rules [S1].

**Pseudocode:**
```python
def issue_extract(volume_cells, isovalue, L):
    # volume_cells: list of (min_val, max_val) tuples
    if not volume_cells:
        return []

    global_min = min(c[0] for c in volume_cells)
    global_max = max(c[1] for c in volume_cells)
    span = global_max - global_min
    if span == 0:
        span = 1.0

    # 1. Lattice Construction
    lattice = [[[] for _ in range(L)] for _ in range(L)]
    for min_v, max_v in volume_cells:
        i = int((min_v - global_min) / span * L)
        j = int((max_v - global_min) / span * L)
        i = max(0, min(i, L - 1))
        j = max(0, min(j, L - 1))
        lattice[i][j].append((min_v, max_v))

    # 2. Classification
    regions = {1: [], 2: [], 3: [], 4: [], 5: []}
    for i in range(L):
        for j in range(L):
            elem_cells = lattice[i][j]
            if not elem_cells:
                continue
            elem_min = min(c[0] for c in elem_cells)
            elem_max = max(c[1] for c in elem_cells)

            if elem_max < isovalue:
                regions[1].append(elem_cells)
            elif elem_min > isovalue:
                regions[2].append(elem_cells)
            elif i == j:
                regions[5].append(elem_cells)
            else:
                # Regions 3 and 4 split by diagonal position in span space
                if j > i:
                    regions[3].append(elem_cells)
                else:
                    regions[4].append(elem_cells)

    # 3. Structure Building (Modified ISSUE)
    # Minimal kd-tree implementation for self-containment
    class KDNode:
        def __init__(self, data, axis, left=None, right=None):
            self.data = data
            self.axis = axis
            self.left = left
            self.right = right

    def build_kd_tree(cells, depth=0):
        if not cells:
            return None
        axis = depth % 2
        sorted_cells = sorted(cells, key=lambda c: c[axis])
        mid = len(sorted_cells) // 2
        return KDNode(sorted_cells[mid], axis,
                      build_kd_tree(sorted_cells[:mid], depth + 1),
                      build_kd_tree(sorted_cells[mid + 1:], depth + 1))

    def query_kd_tree(node, isovalue, results):
        if node is None:
            return
        min_v, max_v = node.data
        if min_v <= isovalue <= max_v:
            results.append(node.data)
        axis = node.axis
        if axis == 0:
            if isovalue >= min_v:
                query_kd_tree(node.left, isovalue, results)
            if isovalue <= max_v:
                query_kd_tree(node.right, isovalue, results)
        else:
            if isovalue <= max_v:
                query_kd_tree(node.left, isovalue, results)
            if isovalue >= min_v:
                query_kd_tree(node.right, isovalue, results)

    search_structures = {}
    for elem_cells in regions[5]:
        search_structures[elem_cells] = build_kd_tree(elem_cells)

    # 4. Extraction
    active_cells = []
    # Region 2: Trivially include
    for elem_cells in regions[2]:
        active_cells.extend(elem_cells)
    # Region 3: Test against max
    for elem_cells in regions[3]:
        for min_v, max_v in elem_cells:
            if max_v >= isovalue:
                active_cells.append((min_v, max_v))
    # Region 4: Test against min
    for elem_cells in regions[4]:
        for min_v, max_v in elem_cells:
            if min_v <= isovalue:
                active_cells.append((min_v, max_v))
    # Region 5: Use kd-tree
    for elem_cells in regions[5]:
        results = []
        query_kd_tree(search_structures[elem_cells], isovalue, results)
        active_cells.extend(results)

    return active_cells
```

**Parameters:**
*   $L$: Lattice resolution. User-defined. Higher $L$ increases precision but also memory overhead [S1].

**Edge Cases:**
*   **Empty Lattice Elements:** Skip processing [S1].
*   **Precision:** Floating point comparisons for isovalue tests must handle epsilon [G].
*   **Memory:** The modified version increases memory usage due to kd-trees and sorted arrays [S1].

## Operating characteristics
*   **Time Complexity:** $O(n + k)$ for NOISE; ISSUE improves performance but adds overhead for lattice construction and structure building [S2]. The modified version accelerates the search phase but increases memory requirements [S1].
*   **Memory Complexity:** Higher than NOISE due to lattice, kd-trees, and sorted arrays [S1].
*   **Parallelism:** Easily parallelizable by dividing lattice elements among processors [S1].
*   **Strengths:** Parallelizable, improves performance over NOISE [S2].
*   **Limitations:** Higher memory requirement, build overhead [S1].

## Background
The ISSUE algorithm was proposed by Shen et al. [S1] as an improvement over the NOISE algorithm [S1]. It utilizes span space subdivision to accelerate isosurface extraction. The modified version further optimizes by focusing search structures on the diagonal region [S1].
