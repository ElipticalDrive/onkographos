# ISSUE Algorithm
Also called: Modified ISSUE Algorithm
## Overview
The ISSUE (Isosurface Extraction using Span Space Subdivision) algorithm is an image-order method for isosurface extraction that improves upon the NOISE algorithm by subdividing span space into an axis-aligned lattice [S2]. It solves the problem of efficient traversal and classification of volumetric cells relative to an isovalue, enabling parallel processing [S2]. It sets itself apart from siblings like Space Leaping by operating in span space (value domain) rather than spatial domain, allowing for coarser skipping based on data value ranges rather than just spatial occupancy [S1, S2].

## How it works
**Inputs and Outputs:**
*   Input: 3D volumetric dataset, isovalue $v$, lattice resolution $L$.
*   Output: Isosurface geometry (triangles/points).

**Data Structures:**
1.  **Lattice:** An $L \times L$ grid representing the span space (value range). Each cell $(i, j)$ corresponds to a range of min-max values.
2.  **Classification Map:** For each lattice element, a category (1-5) indicating its relationship to the isovalue $v$.
3.  **Search Structures:**
    *   For Region 5 elements: A kd-tree built on the lattice element's cells.
    *   For other regions: Sorted linear arrays (coalesced from lattice elements).

**Steps:**
1.  **Lattice Construction:** Divide the span space (range of data values) into an $L \times L$ axis-aligned lattice. Each tile contains approximately the same number of cells [S1, S2].
2.  **Classification:** For each lattice element, determine its category based on its min/max bounds relative to the isovalue $v$ [S1]:
    *   **Region 1:** Max value $< v$. Trivially exclude cells.
    *   **Region 2:** Min value $> v$. Trivially include cells.
    *   **Region 3:** Min value $< v$ and Max value $> v$, but specific geometric condition (see [S1] Fig 3) requires test against Max value.
    *   **Region 4:** Min value $< v$ and Max value $> v$, but specific geometric condition requires test against Min value.
    *   **Region 5:** Requires full min-max search of its cells.
3.  **Structure Building (Modified ISSUE):**
    *   Identify lattice elements falling into Region 5. These lie along the diagonal $y=x$ in the lattice [S1].
    *   Build a kd-tree for each Region 5 lattice element [S1].
    *   Coalesce lattice elements from Regions 1-4 into sorted linear arrays [S1].
4.  **Traversal/Extraction:**
    *   Query the structures to find active cells.
    *   For Region 5, use the kd-tree to find cells intersecting the isovalue.
    *   For other regions, use the sorted arrays or trivial inclusion/exclusion rules.

**Parameters:**
*   $L$: Lattice resolution. User-defined. Higher $L$ increases precision but also memory overhead [S1].

**Edge Cases:**
*   **Empty Lattice Elements:** Skip processing.
*   **Precision:** Floating point comparisons for isovalue tests must handle epsilon [G].
*   **Memory:** The modified version increases memory usage due to kd-trees and sorted arrays [S1].

## Operating characteristics
*   **Time Complexity:** $O(n + k)$ for NOISE; ISSUE improves performance but adds overhead for lattice construction and structure building [S2]. The modified version simplifies search but adds build time [S1].
*   **Memory Complexity:** Higher than NOISE due to lattice, kd-trees, and sorted arrays [S1].
*   **Parallelism:** Easily parallelizable by dividing lattice elements among processors [S1].
*   **Strengths:** Parallelizable, efficient for large datasets with coherent value ranges [S2].
*   **Limitations:** Higher memory requirement, build time overhead [S1].

## Background
The ISSUE algorithm was proposed by Shen et al. [S1, S2] as an improvement over the NOISE algorithm [S1]. It utilizes span space subdivision to accelerate isosurface extraction. The modified version further optimizes by focusing search structures on the diagonal region [S1].
