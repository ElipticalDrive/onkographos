# Hierarchical Box Space Leaping

Also called: Box enclosure, Simplest form of space leaping, Traversing empty space

## Overview
Hierarchical Box Space Leaping is a ray casting acceleration technique that skips empty space to speed up rendering without affecting image quality [S1, unofficial]. It facilitates fast traversal of regions with homogeneous structure by enclosing the object into a set of boxes, possibly hierarchical, allowing the ray to leap over empty regions before engaging in volumetric traversal [S2, book]. Unlike methods that sample every voxel, this method skips empty space, providing significant speedup [S1, unofficial].

## How it works
The method operates in two distinct phases: an empty space search phase and a volumetric integration phase [S1, unofficial].

**Inputs and Outputs**
*   **Input:** A ray defined by origin $\mathbf{o}$ and direction $\mathbf{d}$; a hierarchical data structure of boxes enclosing the volume data [S2, book].
*   **Output:** The final color and opacity for the pixel associated with the ray [S1, unofficial].

**Data Structures**
The core data structure is a hierarchy of boxes enclosing the volume [S2, book].
*   **Box Layout:** Each box is defined by its minimum corner $\mathbf{min} = (x_{min}, y_{min}, z_{min})$ and maximum corner $\mathbf{max} = (x_{max}, y_{max}, z_{max})$ [G].
*   **Hierarchy:** Boxes are organized in a tree structure where parent boxes enclose child boxes [S2, book]. The root box typically encloses the entire volume [G].

**Algorithm Steps**
1.  **Ray-Box Intersection Test:** For the current ray, traverse the hierarchy from the root [S2, book]. At each node, test if the ray intersects the bounding box [S2, book].
    *   If the ray does not intersect the box, skip the entire subtree rooted at that box [S2, book].
    *   If the ray intersects, proceed to the children [S2, book].
    *   This continues until a leaf box is reached or the ray exits the volume [S2, book].
2.  **Determine Entry and Exit Points:** If the ray intersects the bounding box, calculate the entry point $t_{enter}$ and exit point $t_{exit}$ along the ray parameter $t$ [G].
    *   The ray segment within the box is $[\mathbf{o} + t_{enter}\mathbf{d}, \mathbf{o} + t_{exit}\mathbf{d}]$ [G].
    *   If $t_{enter} > t_{exit}$ or the interval is invalid, the ray misses the box [G].
3.  **Volumetric Traversal (Phase 2):** Only if the ray intersects the box, perform the time-consuming volumetric traversal of the material within the box boundaries [S2, book].
    *   Sample the volume data along the ray segment between $t_{enter}$ and $t_{exit}$ [S1, unofficial].
    *   Integrate colors and opacities using standard volume rendering integration [S1, unofficial].
4.  **Empty Space Skipping (Phase 1):** The ray advances through empty space searching for an object [S1, unofficial]. This phase corresponds to the traversal of the hierarchy where no volumetric sampling occurs [S1, unofficial].

**Formulas**
Ray-box intersection for a box defined by $\mathbf{min}$ and $\mathbf{max}$:
$$ t_{min} = \max \left( \frac{x_{min} - o_x}{d_x}, \frac{y_{min} - o_y}{d_y}, \frac{z_{min} - o_z}{d_z} \right) $$
$$ t_{max} = \min \left( \frac{x_{max} - o_x}{d_x}, \frac{y_{max} - o_y}{d_y}, \frac{z_{max} - o_z}{d_z} \right) $$
The ray intersects the box if $t_{max} \ge t_{min}$ and $t_{max} \ge 0$ [G].

**Pseudocode**
```python
def render_ray(ray_origin, ray_direction, box_hierarchy):
    """Renders a single ray using Hierarchical Box Space Leaping."""
    # Phase 1: Skip empty space by traversing the hierarchy
    t_enter, t_exit = traverse_hierarchy(ray_origin, ray_direction, box_hierarchy)
    
    # If no intersection with any box, the ray passes through empty space
    if t_enter is None or t_exit is None:
        return 0.0  # Background color [G]

    # Phase 2: Integrate colors and opacities within the intersected box
    color = 0.0
    opacity = 0.0
    num_samples = 32  # Not given in the sources.
    dt = (t_exit - t_enter) / num_samples
    
    # Front-to-back compositing loop [G]
    for i in range(num_samples):
        t = t_enter + i * dt
        point = ray_origin + t * ray_direction
        density = sample_volume(point)  # Not given in the sources.
        alpha = 1.0 - density
        c = color_at(point)  # Not given in the sources.
        color = color + c * alpha * (1.0 - opacity)
        opacity = opacity + alpha * (1.0 - opacity)
        
    return color

def traverse_hierarchy(ray_origin, ray_direction, node):
    """Recursively traverse the box hierarchy to find the first intersection."""
    t_min, t_max = ray_box_intersection(ray_origin, ray_direction, node.bbox_min, node.bbox_max)
    
    if t_max < t_min:
        return None, None
    
    # If leaf node, return the intersection interval
    if node.is_leaf:
        return t_min, t_max
    
    # If internal node, check children
    for child in node.children:
        t_enter, t_exit = traverse_hierarchy(ray_origin, ray_direction, child)
        if t_enter is not None:
            return t_enter, t_exit
            
    return None, None

def ray_box_intersection(origin, direction, bbox_min, bbox_max):
    """Computes the intersection interval [t_min, t_max] for a ray and a box."""
    t_min = 0.0
    t_max = float('inf')
    
    for i in range(3):
        if direction[i] == 0:
            if origin[i] < bbox_min[i] or origin[i] > bbox_max[i]:
                return None, None
        else:
            t1 = (bbox_min[i] - origin[i]) / direction[i]
            t2 = (bbox_max[i] - origin[i]) / direction[i]
            t_min = max(t_min, min(t1, t2))
            t_max = min(t_max, max(t1, t2))
            
    if t_max < t_min:
        return None, None
        
    return t_min, t_max
```

**Edge Cases and Pitfalls**
*   **Degenerate Boxes:** Boxes with zero volume should be handled or avoided in the hierarchy construction [G].
*   **Ray Parallel to Box Face:** Division by zero in ray-box intersection if the ray direction component is zero [G].
*   **Precision:** Floating-point precision errors in intersection tests may cause gaps or overlaps in the hierarchy traversal [G].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Significant speedup for sparse volumes by skipping empty space [S1, unofficial]. Simple to implement [S2, book].
*   **Limitations:** The bounding boxes may not tightly fit the object, leading to false positives (rays intersecting the box but not the volume data) [G].
*   **When to Use:** Suitable for sparse volumes where empty space constitutes a large portion of the volume [G].
*   **When Not to Use:** For dense volumes where the overhead of hierarchy traversal outweighs the benefit of skipping empty space [G].

## Background
The concept of space leaping was introduced as a prolific and effective branch of volume rendering acceleration techniques [S1, unofficial]. The simplest form, using bounding boxes, was described as facilitating fast leaping across empty space [S2, book]. The technique is based on the principle that the passage of a ray through empty space does not contribute to the final image, so skipping it provides a significant speedup without affecting image quality [S1, unofficial].
