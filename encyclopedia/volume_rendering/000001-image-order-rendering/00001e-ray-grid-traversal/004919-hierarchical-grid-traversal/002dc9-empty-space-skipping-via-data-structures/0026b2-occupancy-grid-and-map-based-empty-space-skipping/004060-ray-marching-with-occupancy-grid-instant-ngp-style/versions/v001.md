# Ray Marching with Occupancy Grid (Instant-NGP style)

Also called: Occupancy Grid Acceleration, Occupancy Grid Pruning, Ray Marching Strategy

## Overview
This method accelerates volume rendering by maintaining a binary occupancy grid that marks voxels as empty or non-empty, preventing ray sampling in empty spaces [S1][S3, unofficial]. It differs from sibling methods by periodically updating the occupancy grid based on Signed Distance Field (SDF) values using a specific logistic density distribution, rather than relying solely on static bounds or distance maps [S1][S3, unofficial]. This approach builds on [Occupancy Grid and Map-Based Empty Space Skipping](3852-occupancy-grid-and-map-based-empty-space-skipping.md) by introducing a differentiable update mechanism tied to the neural network's SDF output.

## How it works
**Inputs:**
- Ray origin $o$ and direction $d$.
- Neural network model predicting SDF $f(p)$ and radiance $c(p)$.
- Occupancy grid `self.occupancy_grid` (boolean or integer bitmask).
- Configuration flags: `grid_prune` (enable/disable pruning), `randomized` (enable stratified sampling), `render_step_size` (fixed step size).
- Hyperparameters: foreground ray ratio (90%), background ray ratio (10%) [S1].

**Outputs:**
- Rendered color and accumulated alpha for the ray.

**Data Structures:**
- `occupancy_grid`: A 3D grid where each cell corresponds to a voxel in the scene space. Cells are marked `1` (occupied) or `0` (empty). The grid resolution is typically coarser than the neural network's input resolution to save memory.
- `render_step_size`: A scalar float defining the fixed step size for ray marching when adaptive stepping is not used or as a baseline [S2, unofficial].

**Steps:**

1. **Ray Sampling Strategy:**
   - Determine if the current ray is foreground or background.
   - Sample 90% of rays on foreground pixels and 10% on background pixels to accelerate convergence [S1].

2. **Occupancy Grid Query (Pruning):**
   - If `grid_prune` is true, query the occupancy grid along the ray [S2, unofficial].
   - Map ray position $p$ to grid coordinates $u_{\text{occ}} = \lfloor p / B \rfloor$, where $B$ is the block size (voxel size in world units) [G, derived from parent].
   - If the grid cell is marked empty, skip sampling in that region. Continue marching until an occupied cell is found or the ray exits the scene bounds.

3. **Ray Marching:**
   - For each step along the ray:
     - Evaluate SDF $d = f(p)$ and radiance $c(p)$ at current position $p$.
     - Compute density $\phi_s(d)$ using the logistic density distribution:
       $$ \phi_s(d) = \frac{s e^{-sd}}{(1 + e^{-sd})^2} $$
       where $s$ is a learnable parameter [S1].
     - Accumulate color and alpha using standard volume rendering integration:
       $$ C = \sum_{i=0}^{N-1} T_i \alpha_i c_i, \quad T_i = \prod_{j=0}^{i-1} (1 - \alpha_j), \quad \alpha_i = 1 - e^{-\phi_s(d_i) \Delta t} $$
       where $\Delta t$ is the step size (e.g., `render_step_size`) [S2, unofficial].
     - Advance $p$ by $\Delta t$ (or adaptive step if implemented, though Instant-NGP style often uses fixed or cone-angle adjusted steps; cone angle is 0.0 in default config) [S2, unofficial].

4. **Occupancy Grid Update (Periodic):**
   - Periodically update the occupancy grid based on the current SDF predictions [S1][S3, unofficial].
   - For each voxel in the grid:
     - Compute occupancy alpha $\alpha_{\text{occ}}$ from SDF using `occ_eval_fn` [S3, unofficial]:
       - Let $inv\_s = 1/s$. Clip $inv\_s$ to $[10^{-6}, 10^6]$ [S3, unofficial].
       - $estimated\_next\_sdf = d - \text{render\_step\_size} \times 0.5$
       - $estimated\_prev\_sdf = d + \text{render\_step\_size} \times 0.5$
       - $p = \sigma(prev\_sdf \times inv\_s) - \sigma(next\_sdf \times inv\_s)$
       - $c = \sigma(prev\_sdf \times inv\_s)$
       - $\alpha_{\text{occ}} = \frac{p + 10^{-5}}{c + 10^{-5}}$
     - If $\alpha_{\text{occ}} > \text{threshold}$ (e.g., 0.5), mark voxel as occupied; otherwise, mark as empty [S3, unofficial].
   - This update is typically performed every $K$ training iterations [S1].

**Pseudocode:**

```python
import numpy as np

def sigmoid(x):
    return 1.0 / (1.0 + np.exp(-x))

def occ_eval_fn(sdf, render_step_size, inv_s):
    """Compute occupancy alpha from SDF as per Instant-NGP style."""
    # Clip inv_s to [1e-6, 1e6]
    inv_s = np.clip(inv_s, 1e-6, 1e6)
    
    estimated_next_sdf = sdf - render_step_size * 0.5
    estimated_prev_sdf = sdf + render_step_size * 0.5
    
    p = sigmoid(estimated_prev_sdf * inv_s) - sigmoid(estimated_next_sdf * inv_s)
    c = sigmoid(estimated_prev_sdf * inv_s)
    
    alpha = (p + 1e-5) / (c + 1e-5)
    return alpha

def logistic_density(sdf, s):
    """Compute density from SDF using logistic distribution."""
    # phi_s(d) = s * exp(-s*d) / (1 + exp(-s*d))^2
    exp_term = np.exp(-s * sdf)
    density = (s * exp_term) / ((1 + exp_term) ** 2)
    return density

def ray_march_with_occupancy_grid(ray_o, ray_d, model, occupancy_grid, config):
    """
    Ray marching with occupancy grid pruning.
    
    Args:
        ray_o: Ray origin (3,)
        ray_d: Ray direction (3,)
        model: Neural network with f(p) -> (sdf, radiance)
        occupancy_grid: 3D boolean array marking occupied voxels
        config: Configuration dict with grid_prune, render_step_size, etc.
        
    Returns:
        color: Rendered color (3,)
        alpha: Accumulated alpha (1,)
    """
    # 1. Ray Sampling Strategy
    # Determine if foreground or background based on pixel label
    is_foreground = get_pixel_label(ray_o) # Implementation detail
    if is_foreground:
        # 90% of rays are foreground
        pass
    else:
        # 10% of rays are background
        pass

    # 2. Occupancy Grid Query (Pruning)
    if config.grid_prune:
        # Find first occupied voxel along ray
        t_start, t_end = find_occupied_interval(ray_o, ray_d, occupancy_grid, config.render_step_size)
        if t_start is None:

    else:

    # 3. Ray Marching
    color = np.zeros(3)
    alpha = 0.0
    T = 1.0  # Transmittance
    t = t_start
    
    while t < t_end:
        p = ray_o + t * ray_d
        
        # Evaluate model
        sdf, radiance = model(p)
        
        # Compute density
        s = model.get_s() # Learnable parameter
        density = logistic_density(sdf, s)
        
        # Compute alpha for this step
        step_size = config.render_step_size
        alpha_step = 1.0 - np.exp(-density * step_size)
        
        # Accumulate
        weight = T * alpha_step
        color += weight * radiance
        alpha += weight
        T *= (1.0 - alpha_step)
        
        # Early termination if alpha is high enough (optional, alpha_threshold=0.0 in config)
        if config.alpha_threshold > 0 and alpha > config.alpha_threshold:
            break
            
        t += step_size

    return color, alpha

def update_occupancy_grid(model, occupancy_grid, config):
    """Periodically update occupancy grid based on SDF."""
    inv_s = 1.0 / model.get_s()
    render_step_size = config.render_step_size
    
    for voxel in occupancy_grid.voxels:
        p = voxel.center
        sdf = model.sdf(p)
        
        alpha_occ = occ_eval_fn(sdf, render_step_size, inv_s)
        
        if alpha_occ > 0.5: # Threshold
            voxel.mark_occupied()
        else:
            voxel.mark_empty()
```

**Parameters:**
- `grid_prune`: Boolean, enables occupancy grid pruning [S2, unofficial].
- `render_step_size`: Float, fixed step size for sampling [S2, unofficial].
- `randomized`: Boolean, enables stratified sampling [S2, unofficial].
- `cone_angle`: Float, 0.0 disables cone-angle-based step size adjustment [S2, unofficial].
- `alpha_threshold`: Float, 0.0 disables early termination based on alpha [S2, unofficial].
- Foreground ray ratio: 90% [S1].
- Background ray ratio: 10% [S1].

**Edge Cases and Pitfalls:**
- Precision: The `occ_eval_fn` uses sigmoid differences which can suffer from cancellation if $s$ is very large or small. Clipping `inv_s` to $[10^{-6}, 10^6]$ mitigates this [S3, unofficial].
- Boundary: Rays exiting the scene bounds must be handled to avoid infinite loops.
- Degenerate Input: If the SDF is not smooth, the occupancy grid updates may be noisy, leading to flickering. Periodic updates help stabilize this [S1].

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of samples per ray. Pruning reduces the effective $N$ by skipping empty regions.
- **Memory Complexity:** $O(V)$ where $V$ is the number of voxels in the occupancy grid. Typically much smaller than the full volume resolution.
- **Measured Performance:** In Instant-NGP, this method enables real-time rendering of high-resolution scenes on consumer GPUs [S1][S3, unofficial].
- **Strengths:** Significant speedup in sparse scenes; simple to implement; differentiable update allows joint optimization with the neural network.
- **Limitations:** Requires periodic updates which add overhead; less effective in dense scenes where most voxels are occupied.
- **When to use:** Sparse or semi-sparse scenes where empty space dominates.
- **When not to use:** Dense scenes with no empty space; real-time applications where update overhead is prohibitive.

## Background
Originated in Instant-NGP by Müller et al. (2022) [S1][S3, unofficial]. It was introduced to accelerate neural radiance field training and rendering by pruning empty space. The method has been adopted in various neural implicit surface reconstruction frameworks, such as NeuS2 [S1] and RISE-SDF [S3, unofficial].
