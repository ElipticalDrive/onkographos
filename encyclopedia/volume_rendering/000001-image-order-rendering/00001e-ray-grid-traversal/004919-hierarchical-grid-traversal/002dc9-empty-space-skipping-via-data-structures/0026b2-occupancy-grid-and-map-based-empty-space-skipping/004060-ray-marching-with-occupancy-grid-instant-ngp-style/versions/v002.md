# Ray Marching with Occupancy Grid (Instant-NGP style)

Also called: Occupancy Grid Acceleration, Occupancy Grid Pruning, Ray Marching Strategy

## Overview
This method accelerates volume rendering by maintaining a binary occupancy grid that marks voxels as empty or non-empty, preventing ray sampling in empty spaces [S1][S3, unofficial]. It differs from sibling methods by periodically updating the occupancy grid based on Signed Distance Field (SDF) values using a specific logistic density distribution, rather than relying solely on static bounds or distance maps [S1][S3, unofficial]. This approach builds on [Occupancy Grid and Map-Based Empty Space Skipping](3852-occupancy-grid-and-map-based-empty-space-skipping.md) by introducing a differentiable update mechanism tied to the neural network's SDF output [S1].

## How it works
**Inputs:**
- Ray origin $o$ and direction $d$.
- Neural network model predicting SDF $f(p)$ and radiance $c(p)$ [S1].
- Occupancy grid `self.occupancy_grid` (boolean or integer bitmask) [S2, unofficial].
- Configuration flags: `grid_prune` (enable/disable pruning), `randomized` (enable stratified sampling), `render_step_size` (fixed step size) [S2, unofficial].
- Hyperparameters: foreground ray ratio (90%), background ray ratio (10%) [S1].

**Outputs:**
- Rendered color and accumulated alpha for the ray [G].

**Data Structures:**
- `occupancy_grid`: A 3D grid where each cell corresponds to a voxel in the scene space [G]. Cells are marked `1` (occupied) or `0` (empty) [G]. The grid resolution is typically coarser than the neural network's input resolution to save memory [G].
- `render_step_size`: A scalar float defining the fixed step size for ray marching when adaptive stepping is not used or as a baseline [S2, unofficial].

**Steps:**

1. **Ray Sampling Strategy:** Determine if the current ray is foreground or background [S1]. Sample 90% of rays on foreground pixels and 10% on background pixels to accelerate convergence [S1].
2. **Occupancy Grid Query (Pruning):** If `grid_prune` is true, the algorithm queries the occupancy grid to skip empty regions [S2, unofficial]. Map ray position $p$ to grid coordinates $u_{\text{occ}} = \lfloor p / B \rfloor$, where $B$ is the block size (voxel size in world units) [G, derived from parent]. If the grid cell is marked empty, skip sampling in that region [G]. Continue marching until an occupied cell is found or the ray exits the scene bounds [G].
3. **Ray Marching:** For each step along the ray: Evaluate SDF $d = f(p)$ and radiance $c(p)$ at current position $p$ [S1]. Compute density $\phi_s(d)$ using the logistic density distribution:
   $$ \phi_s(d) = \frac{s e^{-sd}}{(1 + e^{-sd})^2} $$
   where $s$ is a learnable parameter [S1]. Accumulate color and alpha using standard volume rendering integration:
   $$ C = \sum_{i=0}^{N-1} T_i \alpha_i c_i, \quad T_i = \prod_{j=0}^{i-1} (1 - \alpha_j), \quad \alpha_i = 1 - e^{-\phi_s(d_i) \Delta t} $$
   where $\Delta t$ is the step size [G]. Advance $p$ by $\Delta t$ (or adaptive step if implemented, though Instant-NGP style often uses fixed or cone-angle adjusted steps; cone angle is 0.0 in default config) [S2, unofficial].
4. **Occupancy Grid Update (Periodic):** Periodically update the occupancy grid based on the current SDF predictions [S1][S3, unofficial]. For each voxel in the grid: Compute occupancy alpha $\alpha_{\text{occ}}$ from SDF using `occ_eval_fn` [S3, unofficial]: Let $inv\_s = 1/s$. Clip $inv\_s$ to $[10^{-6}, 10^6]$ [S3, unofficial]. $estimated\_next\_sdf = d - \text{render\_step\_size} \times 0.5$. $estimated\_prev\_sdf = d + \text{render\_step\_size} \times 0.5$. $p_{\text{diff}} = \sigma(prev\_sdf \times inv\_s) - \sigma(next\_sdf \times inv\_s)$. $c = \sigma(prev\_sdf \times inv\_s)$. $\alpha_{\text{occ}} = \frac{p_{\text{diff}} + 10^{-5}}{c + 10^{-5}}$. Mark voxel as occupied if $\alpha_{\text{occ}}$ exceeds a threshold, otherwise mark as empty [S3, unofficial].

**Pseudocode:**

```python
import numpy as np

def sigmoid(x):
    return 1.0 / (1.0 + np.exp(-x))

def occ_eval_fn(sdf, render_step_size, inv_s):
    """Compute occupancy alpha from SDF as per Instant-NGP style."""
    inv_s = np.clip(inv_s, 1e-6, 1e6)
    next_sdf = sdf - render_step_size * 0.5
    prev_sdf = sdf + render_step_size * 0.5
    p_diff = sigmoid(prev_sdf * inv_s) - sigmoid(next_sdf * inv_s)
    c = sigmoid(prev_sdf * inv_s)
    return (p_diff + 1e-5) / (c + 1e-5)

def logistic_density(sdf, s):
    """Compute density from SDF using logistic distribution."""
    exp_term = np.exp(-s * sdf)
    return (s * exp_term) / ((1 + exp_term) ** 2)

def ray_march_with_occupancy_grid(ray_o, ray_d, model, occupancy_grid, config):
    """
    Ray marching with occupancy grid pruning.
    
    Args:
        ray_o: Ray origin (3,)
        ray_d: Ray direction (3,)
        model: Neural network with f(p) -> (sdf, radiance)
        occupancy_grid: 3D boolean array marking occupied voxels
        config: Configuration dict with grid_prune, render_step_size, etc.
        
    Returns:
        color: Rendered color (3,)
        alpha: Accumulated alpha (1,)
    """
    # 1. Ray Sampling Strategy
    is_foreground = True # Determined by pixel sampling strategy
    if config.grid_prune:
        # Simple grid traversal to find first occupied cell
        grid_o = np.floor(ray_o / config.block_size).astype(int)
        step = np.sign(ray_d).astype(int)
        t_max = np.zeros(3)
        for i in range(3):
            if ray_d[i] > 0:
                t_max[i] = (grid_o[i] + 1) * config.block_size - ray_o[i]
            else:
                t_max[i] = grid_o[i] * config.block_size - ray_o[i]
            t_max[i] /= ray_d[i]
        t_delta = np.zeros(3)
        for i in range(3):
            t_delta[i] = config.block_size / abs(ray_d[i]) if ray_d[i] != 0 else np.inf
        
        t_start = 0.0
        found = False
        while not found:
            if occupancy_grid[tuple(grid_o)]:
                found = True
            else:
                t_max[0] += t_delta[0]
                t_max[1] += t_delta[1]
                t_max[2] += t_delta[2]
                axis = np.argmin(t_max)
                grid_o[axis] += step[axis]
                t_start = t_max[axis]
                if not np.all(np.isfinite(t_max)) or t_start > config.scene_max_dist:
                    return np.zeros(3), 0.0
    else:
        t_start = 0.0
        t_end = config.scene_max_dist

    color = np.zeros(3)
    alpha = 0.0
    T = 1.0
    t = t_start
    t_end = config.scene_max_dist if not config.grid_prune else t_start + config.max_ray_dist

    while t < t_end:
        p = ray_o + t * ray_d
        sdf, radiance = model(p)
        s = model.s
        density = logistic_density(sdf, s)
        step_size = config.render_step_size
        alpha_step = 1.0 - np.exp(-density * step_size)
        weight = T * alpha_step
        color += weight * radiance
        alpha += weight
        T *= (1.0 - alpha_step)
        if config.alpha_threshold > 0 and alpha > config.alpha_threshold:
            break
        t += step_size

    return color, alpha

def update_occupancy_grid(model, occupancy_grid, config):
    """Periodically update occupancy grid based on SDF."""
    inv_s = 1.0 / model.s
    render_step_size = config.render_step_size
    for voxel_coords in occupancy_grid.iter_voxels():
        p = voxel_coords * config.block_size + config.block_size * 0.5
        sdf = model.sdf(p)
        alpha_occ = occ_eval_fn(sdf, render_step_size, inv_s)
        if alpha_occ > config.occ_threshold:
            occupancy_grid.set(voxel_coords, 1)
        else:
            occupancy_grid.set(voxel_coords, 0)
```

**Parameters:**
- `grid_prune`: Boolean, enables occupancy grid pruning [S2, unofficial].
- `render_step_size`: Float, fixed step size for sampling [S2, unofficial].
- `randomized`: Boolean, enables stratified sampling [S2, unofficial].
- `cone_angle`: Float, 0.0 disables cone-angle-based step size adjustment [S2, unofficial].
- `alpha_threshold`: Float, 0.0 disables early termination based on alpha [S2, unofficial].
- Foreground ray ratio: 90% [S1].
- Background ray ratio: 10% [S1].

**Edge Cases and Pitfalls:**
- Precision: The `occ_eval_fn` uses sigmoid differences which can suffer from cancellation if $s$ is very large or small. Clipping `inv_s` to $[10^{-6}, 10^6]$ mitigates this [S3, unofficial].
- Boundary: Rays exiting the scene bounds must be handled to avoid infinite loops [G].
- Degenerate Input: If the SDF is not smooth, the occupancy grid updates may be noisy, leading to flickering [S1].

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of samples per ray. Pruning reduces the effective $N$ by skipping empty regions [G].
- **Memory Complexity:** $O(V)$ where $V$ is the number of voxels in the occupancy grid [G].
- **Strengths:** Significant speedup in sparse scenes; simple to implement; differentiable update allows joint optimization with the neural network [S1].
- **Limitations:** Requires periodic updates which add overhead; less effective in dense scenes where most voxels are occupied [G].
- **When to use:** Sparse or semi-sparse scenes where empty space dominates [G].
- **When not to use:** Dense scenes with no empty space; real-time applications where update overhead is prohibitive [G].

## Background
Originated in Instant-NGP by Müller et al. (2022) [S1][S3, unofficial]. It was introduced to accelerate neural radiance field training and rendering by pruning empty space. The method has been adopted in various neural implicit surface reconstruction frameworks, such as NeuS2 [S1] and RISE-SDF [S3, unofficial].
