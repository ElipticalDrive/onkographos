# Volume Occupancy Map Skip

Also called: Empty Voxel Skip, 空体素跳过技术

## Overview
Volume Occupancy Map Skip is a rendering optimization that accelerates ray traversal in sparse volumetric data by bypassing empty regions [S1, unofficial]. It builds on [Two-stage Ray Marching with Empty-Space Skipping](2985-two-stage-ray-marching-with-empty-space-skipping.md) by using a preprocessed occupancy map to jump directly from one non-empty voxel to the next, avoiding density evaluations in empty space [S1, unofficial]. Unlike [PDF Light Weight Space Leaping](5848-pdf-light-weight-space-leaping.md), which typically uses hierarchical structures like octrees for space leaping, this method relies on a flat or sparse occupancy grid to identify empty voxels, offering a trade-off between memory overhead and traversal simplicity for specific sparse datasets [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   Input: A 3D volumetric dataset (density field) and a set of rays [S1, unofficial].
*   Output: Rendered image or accumulated density/transmittance [S1, unofficial].
*   Auxiliary: A preprocessed Volume Occupancy Map (binary mask) [S1, unofficial][S2].

**Data Structures:**
*   **Volume Occupancy Map:** A binary volume of the same dimensions as the density field, recording whether each voxel is empty or occupied [S2].
*   **Density Field:** The primary volumetric data containing density values [S1, unofficial].

**Algorithm Steps:**
1.  **Preprocessing (Offline/Initial Stage):** Analyze the volumetric dataset to determine which voxels contain non-zero density or significant content [S1, unofficial]. Construct the Volume Occupancy Map by setting each voxel to `1` if occupied or `0` if empty [S1, unofficial][S2]. For dynamic scenes, update the mask volume based on empty voxels determined from multiple static scenes [S2].
2.  **Ray Traversal (Runtime):** For each ray, perform standard ray-box intersection to find the entry point into the volume bounding box [G]. Initialize ray parameters (position, direction, step size) [G]. Loop through the ray: check the current voxel's occupancy status in the Volume Occupancy Map [S1, unofficial]. If empty ($Map[v] == 0$), skip sampling the density function and jump to the next non-empty voxel [S1, unofficial]. If occupied ($Map[v] == 1$), sample the density function at the current ray position [S1, unofficial]. Accumulate color and opacity using standard volume rendering integration [S1, unofficial]. Advance the ray by a step size (e.g., 0.5 voxel spacing) [S1, unofficial]. Update ray position [G]. Terminate if the ray exits the volume bounding box [G] or if transmittance drops below a threshold (early ray termination) [G].

**Formulas:**
*   Occupancy Check: $Occupancy(v) = 1$ if $\rho(v) > \epsilon$, else $0$, where $\rho(v)$ is the density at voxel $v$ and $\epsilon$ is a small threshold [G].

**Parameters:**
*   **Step Size:** Typically set to 0.5 voxel spacing to balance detail and performance in medical imaging [S1, unofficial].
*   **Threshold ($\epsilon$):** Not given in the sources [G].

**Edge Cases and Pitfalls:**
*   **Precision:** Floating-point comparisons for occupancy should use a small epsilon to avoid missing thin structures due to numerical noise [G].
*   **Boundaries:** Ensure the occupancy map covers the entire volume bounding box and handle rays exiting the box correctly [S1, unofficial].
*   **Dynamic Scenes:** For dynamic scenes, the occupancy map must be updated efficiently based on multiple static scenes [S2].
*   **Sparse Data:** If the data is extremely sparse, a flat occupancy map may consume significant memory, though the method is designed for sparse clouds and large volumes [S1, unofficial].

**Pseudocode:**
```python
def volume_occupancy_map_skip(rays, density_field, occupancy_map, voxel_size=1.0, step_ratio=0.5):
    # rays: list of (origin: vec3, direction: vec3)
    # density_field: 3D array of densities
    # occupancy_map: 3D binary array (1=occupied, 0=empty)
    rendered_image = []
    for origin, direction in rays:
        # [G] Standard ray-box intersection to find entry t_min
        t_min, t_max = intersect_ray_box(origin, direction, bounds)
        if t_max < 0:
            rendered_image.append(0.0)
            continue
        t = t_min
        accumulated_color = 0.0
        transmittance = 1.0
        # [G] Early termination threshold typical in volume rendering
        while t < t_max and transmittance > 0.01:
            voxel_coords = floor((origin + t * direction) / voxel_size)
            if occupancy_map[voxel_coords] == 0:
                # Skip empty voxel: advance to next voxel boundary
                # [G] Standard DDA step along dominant axis
                t += voxel_size
            else:
                density = density_field[voxel_coords]
                # [G] Standard density sampling and compositing
                color_sample, alpha = sample_density(density, direction, t)
                accumulated_color += color_sample * transmittance
                transmittance *= (1.0 - alpha)
                t += step_ratio * voxel_size
        rendered_image.append(accumulated_color)
    return rendered_image
```

## Subtopics

### Voxel skipping
An efficiency optimization used in training neural radiance fields (e.g., ViSNeRF) to skip sampling at empty voxels along valid rays [S2]. It creates a binary mask volume after an initial training stage to record empty voxels, improving subsequent training efficiency [S2]. For dynamic scenes, the mask is updated based on empty voxels from multiple static scenes [S2].

## Operating characteristics
*   **Time Complexity:** The underlying 3D-DDA traversal has a time complexity of $O(n)$, where $n$ is the number of voxels traversed, compared to $O(N^3)$ for brute force traversal [S1, unofficial]. Skipping empty voxels reduces the effective $n$ for sparse data.
*   **Memory Complexity:** $O(V)$ where $V$ is the total number of voxels in the grid, required to store the occupancy map [S1, unofficial].
*   **Performance:** In a medical imaging project, this technique increased rendering frame rate by 3.2x [S1, unofficial].
*   **Strengths:** Simple to implement; effective for sparse data; reduces expensive density evaluations [S1, unofficial].
*   **Limitations:** Requires preprocessing; memory overhead for the occupancy map; less effective for dense data [S1, unofficial].
*   **When to use:** Sparse volumetric data (e.g., atmospheric clouds, medical CT with large empty regions) [S1, unofficial].
*   **When not to use:** Dense volumetric data where most voxels are occupied; memory-constrained environments [S1, unofficial].

## Background
The technique is described in the context of volume rendering optimizations, specifically for sparse data like atmospheric clouds or medical imaging [S1, unofficial]. It cites a medical imaging project where it improved frame rates [S1, unofficial]. A similar concept ("Voxel skipping") is applied in ViSNeRF for dynamic volumetric scenes, using a mask volume to skip empty voxels during training [S2]. The concept builds on earlier ray traversal algorithms like 3D-DDA [S1, unofficial].
