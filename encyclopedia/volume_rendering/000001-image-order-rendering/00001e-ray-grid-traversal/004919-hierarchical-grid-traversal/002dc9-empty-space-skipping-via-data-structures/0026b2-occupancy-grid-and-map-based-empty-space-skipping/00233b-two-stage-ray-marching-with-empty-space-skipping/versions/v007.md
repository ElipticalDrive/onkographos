# Two-stage Ray Marching with Empty-Space Skipping

Also called: Occupancy Map Empty Space Skipping, Occupancy-based early exit, Simple occupancy map traversal, Two-phase volumetric rendering

## Overview
Two-stage Ray Marching with Empty-Space Skipping is a rendering optimization that accelerates ray traversal in sparse volumetric data by bypassing empty regions using a precomputed occupancy map [S2, unofficial]. It splits ray traversal into two distinct phases: Stage 1 performs cheap lookups in a lower-resolution occupancy grid to locate the entry point into active volume blocks, and Stage 2 performs expensive density sampling only within those active segments [S2, unofficial]. This method avoids evaluating complex density functions or performing integration in empty space, significantly reducing computational cost for sparse scenes [S1][S2, unofficial]. It differs from its siblings by relying on a flat, lower-resolution occupancy grid rather than hierarchical structures like octrees or distance maps, offering a trade-off between memory overhead and traversal simplicity [S2, unofficial].

## How it works
The method operates in two main phases: occupancy map construction and two-stage ray traversal.

### Inputs and Outputs
*   **Inputs:**
    *   Primary volume data (voxels).
    *   Camera parameters (position, projection matrix, world-to-camera matrix).
    *   Volume bounds (extent) and voxel resolution.
    *   Occupancy map (precomputed).
    *   Parameters: `stepSize` (distance between samples), `_RayMaxLength` (maximum ray distance), `B` (block size factor, ratio of volume resolution to occupancy map resolution) [S1][S2, unofficial].
*   **Outputs:**
    *   Rendered image (color buffer).

### Data Structures
1.  **Occupancy Map:** A 3D grid (or 1D buffer) where each voxel corresponds to a block of volume voxels.
    *   **Layout:** Flattened 1D buffer using row-major order. For a voxel at `(x, y, z)` in a grid of size `(_VoxelsX, _VoxelsY, _VoxelsZ)`, the index is:
        $$ \text{index} = z \cdot (\text{_VoxelsX} \cdot \text{_VoxelsY}) + y \cdot \text{_VoxelsX} + x $$
    *   **Values:** Typically binary or sparse integers indicating occupancy (e.g., `0` for empty, `1` for occupied) [S2, unofficial].
2.  **Volume Voxel Buffer:** Structured buffer containing the primary volume data [S2, unofficial].

### Algorithm Steps

#### 1. Occupancy Map Construction (Preprocessing)
A compute shader generates the occupancy map. Each shader invocation evaluates a unique volume block for occupancy.
*   For each block in the volume, determine if it is "active."
*   **Activity Definition:** A block is active if its maximum scalar value exceeds a threshold $\tau$ or if it contains any non-zero density/opacity [G].
*   Write the result (`0` or `1`) to the corresponding voxel in the occupancy map [S1].

#### 2. Ray Initialization
For each pixel in the image:
1.  Calculate ray origin `origin` from camera position.
2.  Calculate ray direction `rayVector` from UV coordinates:
    $$ \text{rayVector} = \text{normalize}(\text{mul}(\text{_CamToWorldMatrix}, \text{float4}(\text{mul}(\text{_invProjectionMatrix}, \text{float4}(uv.x \cdot 2 - 1, uv.y \cdot 2 - 1, 0, 1)).xyz, 0)).xyz) $$
3.  Initialize `length = 0`, `stepSize` (e.g., `0.2`), and `smokeValue = -1` (indicating uninitialized/empty) [S2, unofficial].

#### 3. Stage 1: Empty Space Skipping
Iterate through the ray, querying the occupancy map to skip empty blocks.
1.  **Loop Condition:** While `smokeValue <= 0` AND `length < _RayMaxLength`:
    a.  Increment `length` by `stepSize`.
    b.  Calculate world position: `positionWS = origin + length * rayVector`.
    c.  Query occupancy: `smokeValue = getSmokeVoxel(positionWS)`.
        *   `getSmokeVoxel` converts `positionWS` to voxel coordinates, checks bounds, and returns the occupancy map value.
        *   **Bounds Check:** If `position` is outside `_BoundsExtent`, return `-1` (miss) [S2, unofficial].
        *   **Coordinate Mapping:** $u_{\text{occ}} = \lfloor u_{\text{vol}} / B \rfloor$ [G].
    d.  If `smokeValue` remains `<= 0` after exceeding `_RayMaxLength`, the ray misses the volume. Output black color and terminate [S2, unofficial].

2.  **Step Calculation for Skipping:**
    To skip efficiently, calculate the number of steps $\Delta i$ to the next sampling point outside the current empty region.
    *   Let $\mathbf{u}$ be the current position in occupancy map space.
    *   Let $\Delta \mathbf{u}$ be the step size in occupancy map space.
    *   Compute steps per dimension $j \in \{x, y, z\}$:
        $$ \Delta i_j = \begin{cases} \lceil (1 + \lfloor \mathbf{u}_j \rfloor - \mathbf{u}_j) / \Delta \mathbf{u}_j \rceil, & \text{if } \Delta \mathbf{u}_j > 0 \\ \lceil (\lfloor \mathbf{u}_j \rfloor - \mathbf{u}_j) / \Delta \mathbf{u}_j \rceil, & \text{otherwise} \end{cases} $$
    *   Vectorized form using Heaviside step function `step()`:
        $$ \Delta \mathbf{i} = \lceil (\text{step}(\Delta \mathbf{u}) + \lfloor \mathbf{u} \rfloor - \mathbf{u}) / \Delta \mathbf{u} \rceil $$
    *   The step count is the minimum of dimensional steps, clamped to 1:
        $$ \Delta i = \max(\min(\Delta \mathbf{i}), 1) $$
    *   The distance step in occupancy map space is:
        $$ \Delta \mathbf{u}_{\text{occ}} = \frac{d_{\text{vol}}}{B} \Delta \mathbf{t}_{\text{vol}} $$
        where $d_{\text{vol}}$ is volume resolution and $\Delta \mathbf{t}_{\text{vol}}$ is the step in volume space [S1].

3.  **Resuming Skipping:**
    *   Resume empty space skipping only when the occupancy map coordinate $u_{\text{occ}}$ changes AND the previously sampled voxel had zero opacity [S1].

#### 4. Stage 2: Density Sampling
Once an occupied region is found (`smokeValue == 1`):
1.  **Backward Step Adjustment:** Decrement the ray step number by $\Delta i_{\text{backward}} = -\lfloor f \rfloor$ to ensure the ray goes back at least one voxel length, accounting for interpolation or boundary isosurfaces [S1].
2.  **Initialization:**
    *   `stage2StepNum = 0`
    *   `accumulatedDensity = 0`
    *   `stage2StepMax = 40` (or similar fixed limit) [S2, unofficial].
3.  **Loop:** While `stage2StepNum < stage2StepMax`:
    a.  Calculate `samplePoint = origin + length * rayVector`.
    b.  Compute density:
        $$ \text{density} = 1 - \text{smoothstep}(\text{_Smoothing}, 1.0, \text{normalizedDistance} + \text{noiseValue}) $$
        where $\text{normalizedDistance} = \text{length}(\text{pos} - \text{_SmokeOrigin}) / \text{_SmokeRadius}$ [S2, unofficial].
    c.  Add to `accumulatedDensity` scaled by `_DensityMult`.
    d.  Increment `length` by `stepSize`.
    e.  Increment `stage2StepNum`.
4.  **Note:** Stage 2 may ignore volume bounds if not explicitly checked, causing smoke to bleed past boundaries [S2, unofficial].

```python
    """
    origin: float3, camera position
    ray_vector: float3, normalized ray direction
    occupancy_map: 3D array or 1D buffer, occupancy values (0 or 1)
    volume_data: 3D array, primary volume density
    params: dict containing stepSize, rayMaxLength, boundsExtent, voxelResolution, B, etc.

def get_occupancy(position_ws, occupancy_map, params):
    """
    Converts world position to occupancy map index and returns value.
    Returns -1 if out of bounds, 0 if empty, 1 if occupied.
    """
    bounds = params['boundsExtent']
    voxel_res = params['voxelResolution']
    
    # Bounds check
    if (position_ws.x < -bounds.x or position_ws.x > bounds.x or
        position_ws.y < -bounds.y or position_ws.y > bounds.y or # Note: asymmetric check in source [S2, unofficial]
        position_ws.z < -bounds.z or position_ws.z > bounds.z):
        return -1
        
    # Convert to voxel coordinates
    adjusted_pos = position_ws + bounds # Offset adjustment [S2, unofficial]
    voxel_coords = floor(adjusted_pos / voxel_res)
    
    # Flatten index
    voxels_x = params['voxelsX']
    voxels_y = params['voxelsY']
    voxels_z = params['voxelsZ']
    index = voxel_coords.z * (voxels_x * voxels_y) + voxel_coords.y * voxels_x + voxel_coords.x
    
    return occupancy_map[index]

def compute_density(position_ws, params):
    """
    Computes density based on distance from smoke origin and noise.
    """
    smoke_origin = params['smokeOrigin']
    smoke_radius = params['smokeRadius']
    smoothing = params['smoothing']
    
    distance_from_origin = length(position_ws - smoke_origin)
    normalized_distance = distance_from_origin / smoke_radius
    
    # Noise sampling would occur here, typically using world position [S2, unofficial]
    # noise_value = sample_noise(position_ws)
    noise_value = 0.0 
    
    density = 1.0 - smoothstep(smoothing, 1.0, normalized_distance + noise_value)
    return density
```

### Parameters and Typical Values
*   **`stepSize`**: Distance between samples. Typical value: `0.2` [S2, unofficial].
*   **`_RayMaxLength`**: Maximum distance the ray travels.
*   **`B`**: Block size factor (ratio of volume resolution to occupancy map resolution). Larger `B` skips more empty voxels per sample but reduces precision near occupied regions [S1].
*   **`_Smoothing`**: Parameter for `smoothstep` function.
*   **`_DensityMult`**: Multiplier for density accumulation.
*   **`stage2StepMax`**: Fixed number of steps for Stage 2. Typical value: `40` [S2, unofficial].

### Edge Cases and Pitfalls
1.  **Volume Bounds Ignorance:** Stage 2 may run for a fixed number of steps regardless of whether the ray has exited the voxel grid, causing smoke to bleed past the volume boundary [S2, unofficial]. Explicit bounds checks are required [G].
2.  **Asymmetric Bounds Check:** Incorrect bounds checking logic (e.g., `position.y < -_BoundsExtent.y + _BoundsExtent.y`) can anchor the volume incorrectly or cause misinterpretation of boundaries [S2, unofficial].
3.  **Variable Shadowing:** Using `length` as a variable name can shadow intrinsic functions like `length()` in HLSL/GLSL [S2, unofficial].
4.  **Screen-Space vs World-Space Noise:** Sampling noise using screen UVs pins the noise pattern to the screen, causing it to "swim" as the camera moves. Correct implementation requires sampling noise using world position to attach detail to the volume [S2, unofficial].
5.  **Interpolation Artifacts:** A sampling point near the edge of an empty block may map to non-zero opacity due to trilinear interpolation of the volume. A backward step adjustment is necessary to ensure the ray goes back at least one voxel length [S1].

### [Volume Occupancy Map Skip](5991-volume-occupancy-map-skip.md)
Builds on this method by using a preprocessed occupancy map to jump directly from one non-empty voxel to the next, avoiding density evaluations in empty space. It relies on a flat or sparse occupancy grid, offering a trade-off between memory overhead and traversal simplicity.

## Operating characteristics
*   **Time Complexity:** Proportional to the number of active voxels sampled plus the cost of occupancy map lookups. The occupancy map lookups are $O(1)$ per step. The skipping efficiency depends on the sparsity of the volume and the block size $B$ [S1].
*   **Memory Complexity:** Requires storage for the primary volume data and the occupancy map. The occupancy map size is reduced by a factor of $B^3$ compared to the volume [S1].
*   **Measured Performance:** Performance gains are significant for sparse volumes where large portions of the ray path are empty. The method is faster than standard ray marching as it avoids density evaluations in empty space [S1][S2, unofficial].
*   **Strengths:** Simple to implement, low memory overhead for the acceleration structure, effective for sparse data [S1][S2, unofficial].
*   **Limitations:** Precision near occupied regions decreases with larger $B$. Requires preprocessing to build the occupancy map. May suffer from artifacts if bounds are not handled correctly [S1][S2, unofficial].
*   **When to Use:** Sparse volumetric data where large empty regions dominate the scene.
*   **When Not to Use:** Dense volumes where most of the ray path is occupied, as the overhead of occupancy map lookups may not be justified.

## Background
The method originates from techniques for efficient ray casting of volumetric images using distance maps and occupancy grids for empty space skipping [S1]. It is a specific instance of occupancy-based early exit strategies, where a secondary data structure (occupancy map) is used to accelerate traversal [S2, unofficial]. The approach is commonly used in real-time volume rendering applications, such as medical imaging and scientific visualization, where performance is critical [S1][S2, unofficial].
