# Fast Marching Method

Also called: Fast Marching SDF

## Overview
The Fast Marching Method (FMM) is a computationally efficient numerical scheme for computing the propagation of an active contour, implicitly handling topological changes [S1]. It solves the Eikonal equation to determine the arrival time of a front expanding in the normal direction from a given boundary condition [S2]. Unlike standard region growing, FMM respects causality by always expanding outwards where the speed function $F > 0$, ensuring that the solution at any grid point depends only on points with earlier arrival times [S1].

## How it works
**Inputs:** A 3D grid of voxels, a strictly positive speed function $F(\mathbf{x}) > 0$ [S1], and a set of boundary voxels defining the initial front [S2].
**Outputs:** An arrival time function $T(\mathbf{x})$ for all voxels in the grid [S1].
**Data Structures:**
1. **Grid $T$**: Stores the arrival time for each voxel, initialized to $\infty$ for non-boundary voxels and to specified boundary values for seeds [G].
2. **Heap $H$**: A min-heap storing voxels in the "Narrow" band (candidates for update), ordered by their current $T$ value [G].
3. **Status Map**: Tracks voxel states: Far ($T=\infty$), Narrow ($T<\infty$, in heap), and Accepted ($T$ is final, removed from heap) [G].
**Algorithm Steps:**
1. **Initialization**: Set $T(\mathbf{x}) = \infty$ for all $\mathbf{x}$. Set $T(\mathbf{x}) = T_{init}(\mathbf{x})$ for boundary voxels. Insert all boundary voxels into $H$ and mark them as Narrow [G].
2. **Main Loop**: While $H$ is not empty:
   a. Extract $\mathbf{x}_{min}$ with the smallest $T$ value from $H$.
   b. Mark $\mathbf{x}_{min}$ as Accepted.
   c. For each neighbor $\mathbf{x}_n$ of $\mathbf{x}_{min}$:
      i. If $\mathbf{x}_n$ is Accepted, skip.
      ii. Compute $T_{new}(\mathbf{x}_n)$ by solving the discretized Eikonal equation using upwind differences from already Accepted neighbors [G].
      iii. If $T_{new}(\mathbf{x}_n) < T(\mathbf{x}_n)$, update $T(\mathbf{x}_n) = T_{new}(\mathbf{x}_n)$. If $\mathbf{x}_n$ is Far, mark it Narrow and insert into $H$; if Narrow, update its priority in $H$ [G].
**Formula:**
The core equation is the Eikonal equation:
$$ \|\nabla T\| F = 1 $$
where $T(\mathbf{x})$ is the arrival function and $F > 0$ is the speed function [S1].
In discrete form, the gradient $\nabla T$ uses upwind differences. For a voxel $\mathbf{x}$ with grid spacing $h$, the new arrival time is computed by taking the minimum over all combinations of upwind neighbors. For a single neighbor $\mathbf{x}_n$ along axis $i$:
$$ T(\mathbf{x}) = T(\mathbf{x}_n) + \frac{h}{F(\mathbf{x})} $$
When multiple neighbors contribute, the quadratic solution is used:
$$ T(\mathbf{x}) = \frac{A - \sqrt{A^2 - B}}{C} $$
where $A, B, C$ are derived from the neighbor values and grid spacing [G].
**Parameters:**
- $F(\mathbf{x})$: Speed function. Must be strictly positive to ensure outward expansion [S1].
- Boundary conditions: Seeds defining the start of the front [S2].
**Edge Cases:**
- $F=0$: Causes division by zero. The speed function must be strictly positive [S1].
- Disconnected components: FMM propagates from seeds. If the domain is not fully connected to seeds, some voxels remain $\infty$ [S1].
**Pseudocode:**
```python
def fast_marching_method(grid_shape, speed_function, boundary_voxels, h=1.0):
    import heapq
    T = [[float('inf')] * grid_shape[1] for _ in range(grid_shape[0])]
    status = [[0] * grid_shape[1] for _ in range(grid_shape[0])] # 0:Far, 1:Narrow, 2:Accepted
    heap = []
    
    def get_neighbors(v, shape):
        x, y = v
        for dx_i, dy_i in [(-1,0),(1,0),(0,-1),(0,1)]:
            nx, ny = x+dx_i, y+dy_i
            if 0 <= nx < shape[0] and 0 <= ny < shape[1]:
                yield (nx, ny)
                
    def compute_new_T(v, T, F, h):
        x, y = v
        accepted_T = []
        for nx, ny in get_neighbors(v, (len(T), len(T[0]))):
            if status[nx][ny] == 2:
                accepted_T.append(T[nx][ny])
        if not accepted_T:
            return float('inf')
        accepted_T.sort()
        if len(accepted_T) == 1:
            return accepted_T[0] + h / F(x, y)
        else:
            A = (accepted_T[0] + accepted_T[1]) / (2 * h)
            B = (accepted_T[0] * accepted_T[1]) / (h**2)
            C = 2.0 / (F(x, y)**2)
            return (A - (A**2 - B)**0.5) / C

    for v in boundary_voxels:
        T[v[0]][v[1]] = 0.0
        status[v[0]][v[1]] = 1
        heapq.heappush(heap, (0.0, v))
        
    while heap:
        t_min, v = heapq.heappop(heap)
        if status[v[0]][v[1]] == 2: continue
        status[v[0]][v[1]] = 2
        for n in get_neighbors(v, grid_shape):
            if status[n[0]][n[1]] == 2: continue
            new_t = compute_new_T(n, T, speed_function, h)
            if new_t < T[n[0]][n[1]]:
                T[n[0]][n[1]] = new_t
                if status[n[0]][n[1]] == 0:
                    status[n[0]][n[1]] = 1
                    heapq.heappush(heap, (new_t, n))
                else:
                    heapq.heappush(heap, (new_t, n))
    return T
```

## Operating characteristics
- **Time Complexity**: Not given in the sources.
- **Memory Complexity**: Not given in the sources.
- **Strengths**: Handles topological changes implicitly; computationally efficient when implemented using heap sort algorithms [S1].
- **Limitations**: Requires a well-defined speed function $F > 0$; sensitive to boundary conditions [S1].
- **When to use**: When computing distance fields or propagation times in a grid where the front expands monotonically [S2].
- **When not to use**: When the speed function can be zero or negative; when non-causal propagation is required [G].

## Background
The Fast Marching Method was proposed first by Tsitsiklis and then by Sethian [S2]. It is based on solving the Eikonal equation to compute the arrival time of a front expanding in the normal direction [S2]. It is advantageous because it implicitly handles topological changes and is computationally efficient when implemented using heap sort algorithms [S1]. It has been used for heart segmentation, where the pericardial cavity acts as a boundary restricting propagation [S1].
