# Occupancy Mipmap Generation


## Overview
Occupancy Mipmap Generation computes a hierarchical occupancy mipmap for a 3D grid using JAX convolutions [S1, unofficial]. It builds on [Occupancy Map Generation](1197-occupancy-map-generation.md) by extending a single-resolution occupancy mask into a multi-resolution pyramid [S1, unofficial].

## How it works
**Inputs:**
- `mat`: A 3D array representing the input grid, where non-zero values indicate occupied space. Dimensions are $X \times Y \times Z$ [S1, unofficial].
- `xdim`: The width of the grid ($X$) [S1, unofficial].

**Outputs:**
- `mipmap`: A list of JAX arrays representing the occupancy hierarchy [S1, unofficial].

**Data Structures:**
- `occupancy_mat`: A 3D binary mask of the same shape as `mat`, where `occupancy_mat[i,j,k] = 1` if `mat[i,j,k] > 0`, else `0` [S1, unofficial].
- `data`: A 4D JAX tensor with shape $(1, X, Y, Z, 1)$ (batch size 1, channel size 1) [S1, unofficial].
- `kernel`: A 5D tensor for convolution, shape $(2^i, 2^i, 2^i, 1, 1)$ [S1, unofficial].
- `mipmap`: A Python list of JAX arrays [S1, unofficial].

**Steps:**
1. Calculate the number of hierarchical levels: $L = \lfloor \log_2(xdim) \rfloor$ [S1, unofficial].
2. Create the binary occupancy mask: `occupancy_mat = (mat > 0).astype(float32)` [S1, unofficial].
3. Compute the total number of occupied points: `nb_of_pts = sum(occupancy_mat)` [S1, unofficial].
4. Convert `occupancy_mat` to a JAX array and add batch and channel dimensions: `data = occupancy_mat[None, :, :, :, None]`, resulting in shape $(1, X, Y, Z, 1)$ [S1, unofficial].
5. Initialize an empty list `mipmap` [S1, unofficial].
6. For each level $i$ from $0$ to $L-1$:
   a. Create a convolution kernel of ones with shape $(2^i, 2^i, 2^i, 1, 1)$ [S1, unofficial].
   b. Define the dimension numbers for `lax.conv_general_dilated`: input and output dimensions are `'NHWDC'` (Batch, Height, Width, Depth, Channel), and kernel dimensions are `'HWDIO'` (Kernel Height, Kernel Width, Kernel Depth, Input Channel, Output Channel) [S1, unofficial].
   c. Apply `lax.conv_general_dilated` with strides $(2^i, 2^i, 2^i)$ and `'SAME'` padding [S1, unofficial].
   d. Remove the batch and channel dimensions from the convolution output [S1, unofficial].
   e. Append the resulting 3D array to `mipmap` [S1, unofficial].
   f. Update `data` to the stripped convolution output for the next iteration [G].
7. Append a final level to `mipmap` containing `nb_of_pts` as a single scalar tensor [S1, unofficial].

**Pseudocode:**
```python
import jax.numpy as jnp
from jax.lax import conv_general_dilated, conv_dimension_numbers

def generate_occupancy_mipmap(mat):
    """
    Generates a hierarchical occupancy mipmap from a 3D grid.
    
    Args:
        mat: numpy array, shape (X, Y, Z). Non-zero values indicate occupancy.
        
    Returns:
        mipmap: list of jax arrays. 
                mipmap[i] is the occupancy map at level i.
                mipmap[-1] is a scalar tensor with the total count of occupied voxels.
    """
    xdim = mat.shape[0]
    levels = jnp.log2(xdim).astype(int)
    
    occupancy_mat = (mat > 0).astype(jnp.float32)
    nb_of_pts = jnp.sum(occupancy_mat)
    
    data = jnp.array(occupancy_mat)
    data = data[None, :, :, :, None]  # Shape: (1, X, Y, Z, 1)
    
    mipmap = []
    
    for i in range(levels):
        kernel_size = 2**i
        kernel = jnp.ones((kernel_size, kernel_size, kernel_size, 1, 1))
        dn = conv_dimension_numbers(data.shape, kernel.shape, ('NHWDC', 'HWDIO', 'NHWDC'))
        
        # Note: The provided source code snippet only constructs kernels and dimension numbers; 
        # the convolution call and data update are omitted [S1, unofficial].
        conv_out = conv_general_dilated(
            data, kernel, window_strides=(kernel_size, kernel_size, kernel_size),
            padding='SAME', dimension_numbers=dn
        )
        conv_out = conv_out[0, :, :, :, 0]  # Remove batch and channel dims
        mipmap.append(conv_out)
        data = conv_out[None, :, :, :, None]  # Update for next level [G]
        
    mipmap.append(jnp.array(nb_of_pts))
    return mipmap
```

**Parameters:**
- `mat`: Input 3D grid array [S1, unofficial].
- `xdim`: Grid width [S1, unofficial].

**Edge Cases and Pitfalls:**
- `xdim` is truncated to an integer via `.astype(int)` if not a power of 2, which may truncate the expected level count [S1, unofficial].
- The convolution sums occupancy counts, so coarser levels contain values $>1$ indicating multiple occupied voxels map to a single coarse voxel [S1, unofficial].

## Subtopics

### [Occupancy Grid Update](2916-occupancy-grid-update.md)
Periodically refreshes a 3D occupancy grid by querying a NeRF model for density at voxel centers. It solves stale spatial caching in on-the-fly NeRF training. It differs from this method by using direct density queries rather than convolutional mipmap generation.

### [Occupancy Map Generation via Ray Casting](8136-occupancy-map-generation-via-ray-casting.md)
Generates an occupancy map by counting rays passing through voxels. It differs from this method by using explicit ray traversal statistics rather than JAX convolutions.
