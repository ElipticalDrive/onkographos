# Occupancy Grid Transition and Update

Also called: Dynamic Occupancy Grid, HMM-based Occupancy Update, Occ. Grid Transition, Probabilistic Occupancy Grid, Transition and Update of Occupancy Grid

## Overview
This method adapts the occupancy grid for efficient point sampling in dynamic Neural Radiance Fields (NeRFs) by treating voxel occupancy as a time-varying probability rather than a static binary state [S1]. It solves the problem of maintaining sampling efficiency in on-the-fly training where scene geometry changes, by applying a transition function to predict motion and a Bayesian update to incorporate new density observations [S1]. Unlike static NeRFs that cache grids or 4D space-time grids that fail to accelerate per-frame training, this method transitions the 3D grid between frames to preserve occupancy information relevant to the current time step [S1].

## How it works
**Inputs and Outputs**
*   **Input:** The final occupancy grid from the previous frame optimization $G^J_{k-1}$, where $k$ is the current frame index and $J$ is the total number of optimization iterations per frame [S1].
*   **Input:** The volume density output $\sigma(x)$ from the NeRF model during current frame optimization [S1].
*   **Input:** A 3D convolution kernel $S$ representing motion probability [S1].
*   **Output:** The updated occupancy grid $G^j_k$ for the current frame at iteration $j$, used to guide point sampling [S1].

**Data Structures**
*   **Occupancy Grid ($G$):** A 3D tensor where each element $G(x)$ represents the probability that voxel $x$ contains positive volume density [S1]. The values are continuous probabilities in the range $[0, 1]$ [G].
*   **Kernel ($S$):** A 3D kernel used for convolution, defined as a simple 3D Gaussian function [S1].

**Steps**
1.  **Transition (Prediction):** At the start of optimizing frame $k$, apply a transition function to the previous frame's final grid $G^J_{k-1}$ to model potential motion [S1]. This is computed by convolving the previous grid with the kernel $S$:
    $$ G^0_k = S * G^J_{k-1} $$
    Here, $G^0_k$ is the initial occupancy probability for frame $k$ before any new observations are processed [S1]. The convolution assumes a Markov property where motion is limited and local [S1].
2.  **Bayesian Update (Correction):** During the $J$ optimization iterations for frame $k$, update the occupancy grid probability $G^j_k$ after each iteration $j$ (where $j \in [1, J]$) using the NeRF's volume density output $\sigma(x)$ at the sampled point $x$ [S1]. The update rule is:
    $$ G^j_k = \begin{cases} 1 & \text{if } \sigma(x) < G^{j-1}_k \\ \sigma(x) & \text{otherwise} \end{cases} $$
    This is a simplified Bayesian update $P(\sigma(x) | G^{j-1}_k)$ [S1]. The condition $\sigma(x) < G^{j-1}_k$ triggers a certainty of occupancy (probability 1), while otherwise the probability is set to the observed density value [S1].
3.  **Sampling:** Use the updated grid $G^j_k$ to sample points only in occupied areas (where probability is significant) during the on-the-fly training process [S1].

**Parameters**
*   **Kernel $S$:** A 3D Gaussian function [S1]. Its specific width/standard deviation is not given in the sources, but it is chosen to represent the probability of motion based on the Markov assumption of limited historical motion information [S1].

**Edge Cases and Pitfalls**
*   **Global Sampling Failure:** Using global random sampling (as in Instant-NGP) to update the grid ignores previous occupancy values and transitions [S1]. In on-the-fly training with few iterations, this can miss occupied regions that have moved, resulting in "blank cubes" in rendered images [S1]. This method avoids that by updating probabilities at occupied points based on transition [S1].
*   **Dynamic Scene Assumption:** The method is designed for dynamic scenes captured by multi-view forward-facing cameras [S1]. It may not be directly applicable to monocular or 360-degree inward-facing setups without modification, as these involve different motion characteristics and hardware constraints [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Performance:** On the synthetic D-NeRF dataset, the method achieves 6 frames per second (FPS) for training and rendering combined [S1]. It significantly accelerates on-the-fly training compared to state-of-the-art algorithms while maintaining comparable rendering quality [S1].
*   **Strengths:** Maintains occupancy information across frames, avoiding the "blank cube" artifacts caused by global random sampling in dynamic scenes [S1]. Efficient for on-the-fly training with limited iterations per frame [S1].
*   **Limitations:** Relies on the Markov assumption of limited motion, which may not capture complex, long-range movements accurately without tuning the kernel $S$ [S1]. Performance may degrade in scenes with rapid, non-local motion [S1].

## Background
*   **Origin:** Proposed in OD-NeRF: Efficient Training of On-the-Fly Dynamic Neural Radiance Fields [S1].
*   **History:** The method addresses the limitation of static NeRF occupancy grids [13, 1] and 4D space-time grids [16] which do not improve on-the-fly efficiency [S1]. It formulates the problem using a Hidden Markov Model approach to transition and update the grid [S1].
*   **Usage:** Evaluated on synthetic D-NeRF [18], real-world MeetRoom [6], and DyNeRF [8] datasets [S1]. It is particularly relevant for streaming scenarios with multi-view forward-facing cameras [S1].
