# Binary Occupancy Grid Pruning

Also called: Grid-based Pruning, History Pruning

## Overview
Binary Occupancy Grid Pruning is a method for accelerating volume rendering by explicitly skipping free space, thereby minimizing the number of sample points for which hash grid features need to be queried and MLPs evaluated [S1]. It sets itself apart from its siblings by combining a coarse binary occupancy grid with two specific pruning strategies—Cylinder Pruning and Joint History- and Grid-based Pruning—to achieve high rendering speeds without model baking [S1]. Unlike [Distance Map Acceleration](972-distance-map-acceleration.md) which uses signed distances, or [MERF Real-Time Rendering](10175-merf-real-time-rendering.md) which uses different acceleration structures, this method relies on a binary mask derived from training history and dense sampling estimates [S1].

## How it works
The method builds on the shared principles of [Occupancy Grid and Map-Based Empty Space Skipping](3852-occupancy-grid-and-map-based-empty-space-skipping.md). It constructs a secondary binary occupancy grid to represent the volume, defines active regions based on density thresholds, and skips free space during ray traversal [S1].

### Inputs and Outputs
*   **Inputs:**
    *   Capture rig geometry (approximated as cylinders).
    *   Training history (maximum density observed per voxel).
    *   Scene geometry (estimated via dense sampling).
    *   Pruning parameters: initial resolution $R_{init}=128^3$, start iteration $I_{start}=100,000$, frequency $F_{prune}=1,000$, max threshold $\alpha=0.2$.
*   **Outputs:**
    *   A binary occupancy grid where voxels are marked as `occupied` or `free`.
    *   During rendering, a list of active intervals along each ray.

### Data Structures
*   **Binary Occupancy Grid:** A 3D array of boolean values.
    *   Layout: $G \in \{0, 1\}^{R \times R \times R}$, where $R$ is the current grid resolution.
    *   Value `1` indicates the voxel is occupied (may contain geometry).
    *   Value `0` indicates the voxel is free (can be skipped).
*   **History Buffer:** A 3D array storing the maximum density observed for each voxel during training.
    *   Layout: $H \in \mathbb{R}^{R \times R \times R}$.
    *   Initialized to $0.0$.
*   **Grid-Based Density Buffer:** A 3D array storing the maximum density estimated via dense sampling inside each voxel.
    *   Layout: $D \in \mathbb{R}^{R \times R \times R}$.
    *   Initialized to $0.0$.

### Steps

1.  **Initialization:**
    *   Initialize the binary occupancy grid $G$ with resolution $R_{init} = 128^3$.
    *   Initialize $H$ and $D$ to zeros.
    *   Apply **Cylinder Pruning** (see Subtopics) to mark voxels inside the capture rig cylinders as `free` ($0$).

2.  **Training Phase (History Tracking):**
    *   During training, for each ray sample falling within a voxel $v$:
        *   Update the history buffer: $H[v] \leftarrow \max(H[v], \rho)$, where $\rho$ is the density contribution of the sample.

3.  **Pruning Phase (Joint History- and Grid-based Pruning):**
    *   This phase begins after iteration $I_{start} = 100,000$.
    *   Every $F_{prune} = 1,000$ iterations:
        *   **Grid-based Estimation:** For each voxel $v$ in $G$:
            *   Evaluate a dense cubic grid inside voxel $v$ to estimate the maximum density.
            *   Use the minimum step size possible inside the voxel based on the ray from the closest camera as a worst-case estimate for density calculation [S1].
            *   Update $D[v]$ with this estimated maximum density.
        *   **Threshold Calculation:**
            *   Calculate the current pruning threshold $\tau$.
            *   $\tau$ is annealed linearly from $0$ to $\alpha = 0.2$ over the course of the pruning phase.
            *   Let $I_{current}$ be the current iteration. Let $I_{end}$ be the final iteration (or a predefined milestone).
            *   $\tau = \alpha \times \frac{I_{current} - I_{start}}{I_{end} - I_{start}}$ (clamped to $[0, \alpha]$).
        *   **Voxel Pruning:**
            *   For each voxel $v$:
                *   If $H[v] < \tau$ AND $D[v] < \tau$:
                    *   Mark $G[v] = 0$ (free).
                *   Else:
                    *   Mark $G[v] = 1$ (occupied).

4.  **Upsampling:**
    *   At predefined iteration milestones, upsample the occupancy grid $G$ to a higher resolution to prune scenes more accurately [S1].
    *   The history and density buffers are also upsampled accordingly.

5.  **Rendering (Ray Traversal):**
    *   For each ray, query the binary occupancy grid $G$ to find the entry and exit points of active regions.
    *   Skip intervals where $G$ is `0`.
    *   Evaluate the MLP and hash grid features only for samples within `1` voxels.

### Pseudocode

```python
def initialize_occupancy_grid(resolution=128):
    """Initialize a 3D binary occupancy grid."""
    return np.zeros((resolution, resolution, resolution), dtype=bool)

def cylinder_pruning(grid, cylinder_centers, cylinder_radii, voxel_size):
    """Mark voxels completely inside cylinders as free."""
    for i in range(grid.shape[0]):
        for j in range(grid.shape[1]):
            for k in range(grid.shape[2]):
                # Get voxel center
                center = np.array([i, j, k]) * voxel_size
                # Check if center is inside any cylinder
                inside = False
                for center_c, radius in zip(cylinder_centers, cylinder_radii):
                    # Distance from axis (simplified for vertical cylinders)
                    dist = np.linalg.norm(center[:2] - center_c[:2])
                    if dist < radius:
                        inside = True
                        break
                if inside:
                    grid[i, j, k] = False  # Free
    return grid

def update_history(history_buffer, voxel_idx, density):
    """Update the maximum density observed for a voxel."""
    history_buffer[voxel_idx] = max(history_buffer[voxel_idx], density)

def estimate_grid_density(grid_buffer, voxel_idx, voxel_bounds, closest_camera_ray):
    """Estimate max density by sampling a dense cubic grid inside the voxel."""
    # Determine minimum step size based on closest camera ray
    # This is a worst-case estimate
    step_size = calculate_min_step_size(voxel_bounds, closest_camera_ray)
    
    max_density = 0.0
    # Sample dense grid inside voxel
    for x in np.arange(voxel_bounds.min_x, voxel_bounds.max_x, step_size):
        for y in np.arange(voxel_bounds.min_y, voxel_bounds.max_y, step_size):
            for z in np.arange(voxel_bounds.min_z, voxel_bounds.max_z, step_size):
                # Evaluate density at (x, y, z)
                # This requires querying the trained model
                density = evaluate_model(x, y, z)
                max_density = max(max_density, density)
    
    grid_buffer[voxel_idx] = max_density
    return max_density

def prune_occupancy_grid(grid, history_buffer, density_buffer, iteration, start_iter, end_iter, alpha):
    """Prune voxels based on history and grid-based density."""
    if iteration < start_iter:
        return grid
    
    # Calculate annealed threshold
    progress = (iteration - start_iter) / (end_iter - start_iter)
    progress = min(progress, 1.0)
    threshold = alpha * progress
    
    for i in range(grid.shape[0]):
        for j in range(grid.shape[1]):
            for k in range(grid.shape[2]):
                voxel_idx = (i, j, k)
                h_val = history_buffer[voxel_idx]
                d_val = density_buffer[voxel_idx]
                
                if h_val < threshold and d_val < threshold:
                    grid[i, j, k] = False  # Prune
                else:
                    grid[i, j, k] = True   # Keep
    return grid

def render_ray(ray, occupancy_grid, voxel_size):
    """Render a ray using the occupancy grid for skipping."""
    # Map ray to grid coordinates
    # u_occ = floor(u_vol / B)
    
    # Find entry and exit points in occupied voxels
    active_intervals = find_active_intervals(ray, occupancy_grid, voxel_size)
    
    color = np.zeros(3)
    transmittance = 1.0
    
    for start, end in active_intervals:
        # Sample within active interval
        num_samples = calculate_num_samples(start, end)
        for t in np.linspace(start, end, num_samples):
            pos = ray.origin + t * ray.direction
            # Query hash grid and evaluate MLP
            density, color_contribution = evaluate_model(pos)
            
            alpha = 1.0 - np.exp(-density * (end - start) / num_samples)
            color += alpha * transmittance * color_contribution
            transmittance *= (1.0 - alpha)
            
            if transmittance < 1e-4:
                break
                
    return color
```

### Parameters
*   $\alpha$: Maximum pruning threshold value. Typical value: $0.2$ [S1].
*   Initial pruning start iteration: $100,000$ [S1].
*   Pruning frequency: Every $1,000$ iterations [S1].
*   Initial grid resolution: $128^3$ [S1].

### Edge Cases and Pitfalls
*   **Precision:** The density estimation in grid-based pruning depends on the step size. Using a step size that is too large may underestimate density, leading to over-pruning [S1].
*   **Boundaries:** Cylinder pruning must ensure that voxels are *completely* inside the cylinder to be marked as free, to avoid cutting into valid geometry [S1].
*   **Degenerate Input:** If the scene has no geometry (e.g., pure black background), all voxels may be pruned, leading to empty renders. The threshold annealing helps mitigate this by being conservative early on [S1].

## Subtopics

### Joint History- and Grid-based Pruning
A conservative pruning strategy combining history-based pruning (tracking max density per voxel during training) with grid-based pruning (evaluating a dense cubic grid inside each voxel to estimate max density) to prune occupancy grid voxels [S1]. It is chosen when higher accuracy in pruning is needed compared to using only one method. It prunes grid voxels where both maximum densities (history and grid-based) fall below the current pruning threshold [S1]. The pruning threshold is annealed linearly from $0$ to $0.2$ [S1].

### Cylinder Pruning
A pruning strategy that approximates the capture rig geometry as a cylinder and marks all occupancy grid voxels completely inside any such cylinder as free space [S1]. It is used to initialize the occupancy grid based on known rig capture positions [S1]. It prevents the model from cheating using floaters in front of cameras, leading to more view-consistent models, and speeds up early stages of training [S1].

## Operating characteristics
*   **Time Complexity:** Pruning is performed periodically (every 1,000 iterations) and involves dense sampling inside each voxel, which is expensive. However, it is done offline or during training, not at render time. Rendering time is reduced by skipping free space.
*   **Memory Complexity:** Requires storing the binary occupancy grid, history buffer, and density buffer. For a $128^3$ grid, this is $128^3 \times 3$ voxels. Upsampling increases memory usage.
*   **Measured Performance:** The method enables native rendering on a Meta Quest Pro VR headset at dual 2K×2K eyebuffers at 72 FPS [S1].
*   **Strengths:** Maximizes rendering speed without model baking; prevents cheating with floaters; improves convergence speed in early training [S1].
*   **Limitations:** Requires training history; dense sampling for grid-based pruning is computationally expensive; initial coarse resolution may lead to inaccurate pruning [S1].
*   **When to use:** When high-performance rendering is required, especially on mobile/VR hardware, and training time is available for pruning [S1].
*   **When not to use:** When real-time adaptation to dynamic scenes is required, as pruning is based on static training history [S1].

## Background
Binary Occupancy Grid Pruning was introduced by Müller et al. in 2022 in the context of VR-NeRF [S1]. It was developed to address the high run-time cost of NeRF rendering in virtual reality, specifically for native rendering on headsets like the Meta Quest Pro [S1]. The method extends widely-adopted occupancy grid acceleration structures by adding novel pruning strategies [S1].
