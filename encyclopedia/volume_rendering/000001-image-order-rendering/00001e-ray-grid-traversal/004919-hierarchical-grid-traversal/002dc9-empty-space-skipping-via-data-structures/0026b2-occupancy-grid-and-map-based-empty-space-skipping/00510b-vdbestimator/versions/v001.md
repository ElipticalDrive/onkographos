# VDBEstimator

Also called: Occupancy Estimator Using A VDB

## Overview
VDBEstimator is an occupancy estimation method that uses a volumetric data base (VDB) grid, specifically the fVDB format, to perform spatial skipping of invisible space during ray marching [S1, unofficial]. It maintains a mutable grid and a buffer of float occupancy values to guide sampling, allowing rays to bypass inactive regions without evaluating the volume density function [S1, unofficial]. It builds on [Occupancy Grid and Map-Based Empty Space Skipping](3852-occupancy-grid-and-map-based-empty-space-skipping.md) by leveraging hierarchical sparse structures for efficient traversal.

## How it works
**Inputs and Outputs:**
*   **Inputs:** Ray origins ($O$) and directions ($D$), near/far planes ($t_{min}, t_{max}$), rendering step size, and the VDB grid state.
*   **Outputs:** Ray intervals ($t_{starts}, t_{ends}$), ray indices, and updated occupancy grid state.

**Data Structures:**
The estimator maintains two primary state attributes [S1, unofficial]:
1.  `self.grid`: An fVDB `GridBatch` object created via `sparse_grid_from_ijk` with `mutable=True`. This structure stores the hierarchical sparse representation of the volume [S1, unofficial].
2.  `self.occs`: A `torch.nn.Parameter` tensor of shape `[self.grid.total_voxels]` initialized to zeros, with `requires_grad=False`. This buffer stores the float occupancy values for each voxel in the grid [S1, unofficial].

**Parameters:**
*   `render_step_size`: Default $10^{-3}$. The step size for marching through the grid [S1, unofficial].
*   `early_stop_eps`: Default $10^{-4}$. Early stop threshold for skipping invisible space [S1, unofficial].
*   `alpha_thre`: Default $0.0$. Alpha threshold for skipping empty space [S1, unofficial].
*   `occ_thre`: Default $10^{-2}$. Threshold used to binarize the occupancy grid during updates [S1, unofficial].
*   `ema_decay`: Default $0.95$. The decay rate for Exponential Moving Average (EMA) updates of the occupancy field [S1, unofficial].
*   `warmup_steps`: Default $256$. During this initial stage, all cells are sampled [S1, unofficial].
*   `n`: Default $16$. The estimator updates the grid every `n` training steps [S1, unofficial].

**Algorithm Steps:**

1.  **Plane Clamping:** If `t_min` is provided, clamp `near_planes` to be at least `t_min`. If `t_max` is provided, clamp `far_planes` to be at most `t_max` [S1, unofficial].
2.  **Stratified Sampling (Optional):** If `stratified` is True, add jitter to `near_planes`:
    $$ t_{near}^{jittered} = t_{near} + \text{rand}() \times \text{render\_step\_size} $$
    where $\text{rand}()$ is a uniform random value [S1, unofficial].
3.  **VDB Traversal:** Call `traverse_vdbs` with rays, grid, near/far planes, step size, and cone angle. This function computes ray-AABB intersections. For each ray-grid pair, it calculates $t_{min}$ and $t_{max}$ as:
    $$ t_{min} = \max(\min(t_1, t_2), \text{near\_plane}) $$
    $$ t_{max} = \min(\max(t_1, t_2), \text{far\_plane}) $$
    where $t_1, t_2$ are the intersection distances with the AABB faces. If no intersection exists ($t_{max} \le t_{min}$ or $t_{max} \le 0$), the interval is marked as invalid [S1, unofficial].
4.  **Alpha Threshold Capping:** If skipping invisible space is enabled (`alpha_thre > 0.0` or `early_stop_eps > 0.0`) and a density/alpha function is provided, cap the alpha threshold:
    $$ \alpha_{thre} = \min(\alpha_{thre}, \text{mean}(self.occs)) $$
    This prevents skipping based on an overly aggressive threshold relative to the current estimated occupancy [S1, unofficial].
5.  **Masking and Filtering:** Generate a mask for valid intervals (where $t_{max} > t_{min}$ and intersection exists). Filter `ray_indices`, `t_starts`, and `t_ends` using this mask [S1, unofficial].
6.  **Grid Update (Training):**
    *   If current training `step < warmup_steps`: Sample all cells using `_get_all_cells()` [S1, unofficial].
    *   If `step >= warmup_steps`: Call `_sample_uniform_and_occupied_cells()`. Sample $n = \text{total\_voxels} // 4$ uniform cells and $n$ occupied cells (or all occupied if fewer than $n$), concatenating them for gradient updates [S1, unofficial].
    *   Update `self.occs` using EMA with `ema_decay` [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Single Grid Limitation:** The `traverse_vdbs` function currently asserts that only one grid is supported (`assert len(grids) == 1`) [S1, unofficial].
*   **Boundary Constraints:** There is a TODO comment indicating that endpoints of sample intervals should be restrained to be within grid boundaries, but this is not yet implemented [S1, unofficial].
*   **Precision:** The use of `torch.frexp` for mip level computation in `_query` assumes specific normalization and may have edge cases near zero [S1, unofficial].

## Subtopics

### Distance Map Acceleration
Uses distance transforms to skip empty space. Sets itself apart by using distance values rather than binary occupancy. Choose when smooth transitions between empty and active regions are needed. [Distance Map Acceleration](972-distance-map-acceleration.md)

### Two-stage Ray Marching with Empty-Space Skipping
Uses a coarse pass to identify active regions before fine sampling. Sets itself apart by decoupling traversal from sampling. Choose for scenes with large empty volumes. [Two-stage Ray Marching with Empty-Space Skipping](2985-two-stage-ray-marching-with-empty-space-skipping.md)

### Hierarchical Sampling with Occupancy Grid
Uses a hierarchical occupancy grid (e.g., octree) for skipping. Sets itself apart by supporting multi-resolution occupancy. Choose for highly sparse volumes. [Hierarchical Sampling with Occupancy Grid](3035-hierarchical-sampling-with-occupancy-grid.md)

### Empty Space Filtering (Training-Time Bounding Box)
Filters empty space during training using a bounding box. Sets itself apart by being a training-time optimization rather than a runtime traversal structure. Choose for static scenes with known bounds. [Empty Space Filtering (Training-Time Bounding Box)](6752-empty-space-filtering-training-time-bounding-box.md)

### MERF Real-Time Rendering
Uses a hash grid for real-time rendering. Sets itself apart by focusing on real-time performance with hash-based lookups. Choose for interactive applications. [MERF Real-Time Rendering](10175-merf-real-time-rendering.md)

## Operating characteristics
*   **Time Complexity:** Depends on the sparsity of the VDB grid. Traversal is proportional to the number of active voxels intersected by rays.
*   **Memory Complexity:** Proportional to the number of active voxels in the VDB grid plus the occupancy buffer.
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Scales well with sparsity. The hierarchical nature of fVDB allows efficient traversal of large volumes with sparse active regions.
*   **Strengths:** Efficient empty space skipping, mutable grid allows for dynamic updates during training.
*   **Limitations:** Currently supports only a single grid. Boundary constraints are not fully implemented.
*   **When to use:** Suitable for training NeRF-like models where the volume is sparse and dynamic updates to occupancy are beneficial.
*   **When not to use:** Not suitable for scenes requiring multiple VDB grids or where boundary constraints are critical.

## Background
VDBEstimator is part of the Taylor-NeRF project, which aims to improve NeRF training efficiency and quality. It leverages the fVDB library for efficient sparse volume representation and traversal. The method was introduced in the context of Taylor series expansion for NeRF, where efficient sampling is crucial for convergence.
