# Occupancy Grid and Map-Based Empty Space Skipping

Also called: Occupancy Grid Acceleration, Map-Based Skipping

## Overview
This family of methods accelerates volumetric ray casting by maintaining a secondary, lower-resolution data structure (typically a grid or map) that indicates the occupancy status of volume blocks. It solves the problem of wasting computational resources sampling empty space by allowing rays to skip inactive regions without evaluating the transfer function or volume texture [S1]. Unlike hierarchical tree-based methods, these approaches often use flat grids or simple distance maps for coarse-to-fine skipping, making them highly parallelizable on GPUs [S1].

## Shared principles
The core mechanism shared by all methods in this family involves three stages: construction of a secondary acceleration structure, definition of activity, and ray-based skipping.

1.  **Acceleration Structure Construction:** A secondary data structure is built to represent the volume. This structure is typically lower resolution than the primary volume texture or has a different topology (e.g., tree vs. grid) to allow for faster traversal [G]. Each element in this structure corresponds to a block, region, or node of volume voxels and stores metadata indicating occupancy or activity [G].
2.  **Active Region Definition:** A block or region is defined as "active" if it contributes to the final image. This is typically determined by density, opacity, or scalar value thresholds. For example, a block is active if its maximum scalar value exceeds an isovalue threshold $\tau$ ($\max(\text{block}) > \tau$) or if its accumulated opacity exceeds a small epsilon [G]. This status may be static (pre-computed) or dynamic (updated per frame or per transfer function change) [G].
3.  **Ray Query and Skip:** During rendering, the algorithm queries the acceleration structure to find the entry and exit points of active regions along a ray. Rays advance past inactive blocks without sampling the primary volume texture, performing standard integration only within active segments [G].
4.  **Coordinate Mapping:** Efficient mapping between ray positions and grid indices is required, typically via integer division by block size: $u_{\text{occ}} = \lfloor u_{\text{vol}} / B \rfloor$ [G].

## Subtopics

### [Distance Map Acceleration](972-distance-map-acceleration.md)
Distance Map Acceleration is a ray traversal technique that uses a precomputed Chebyshev distance map, derived from an occupancy map, to skip sampling points in empty regions of a volumetric image. It reduces the number of texture samples and improves frame rates for volume and isosurface rendering by allowing rays to leap past inactive blocks without evaluating the transfer function or volume texture. Unlike sibling methods that may use hierarchical structures or simple occupancy grids for binary skipping, this method encodes the *distance* to the nearest occupied region, enabling larger, more informed skip steps. It builds on [Occupancy Grid and Map-Based Empty Space Skipping](3852-occupancy-grid-and-map-based-empty-space-skipping.md) by adding a distance field to the occupancy data. See [Distance Map Acceleration](972-distance-map-acceleration.md).

### [Two-stage Ray Marching with Empty-Space Skipping](2985-two-stage-ray-marching-with-empty-space-skipping.md)
Two-stage Ray Marching with Empty-Space Skipping is a rendering optimization that accelerates volumetric ray casting by decoupling the search for active volume data from the expensive density sampling process. It solves the problem of wasting computational resources sampling empty space by using a lower-resolution occupancy map to quickly identify entry points into active regions. Unlike its siblings, it employs a strict two-phase loop: Stage 1 performs cheap, coarse-grained occupancy lookups to skip inactive blocks, while Stage 2 performs fine-grained, expensive density sampling only within confirmed active regions. This approach is distinct from hierarchical methods like [Hierarchical Sampling with Occupancy Grid](3035-hierarchical-sampling-with-occupancy-grid.md) by using a flat occupancy map and fixed-step skipping rather than recursive tree traversal, and from [Distance Map Acceleration](972-distance-map-acceleration.md) by relying on binary occupancy flags rather than distance-to-nearest-occupied-voxel metrics. See [Two-stage Ray Marching with Empty-Space Skipping](2985-two-stage-ray-marching-with-empty-space-skipping.md).

### [Hierarchical Sampling with Occupancy Grid](3035-hierarchical-sampling-with-occupancy-grid.md)
Hierarchical Sampling with Occupancy Grid is a two-stage volume rendering method that combines empty-space skipping via an occupancy grid with importance-based hierarchical sampling to accelerate Neural Radiance Field (NeRF) training and inference. It differs from its siblings by explicitly decoupling the coarse sampling phase (guided by spatial occupancy) from the fine sampling phase (guided by rendered weights), allowing for efficient refinement of high-density regions without re-evaluating empty space. See [Hierarchical Sampling with Occupancy Grid](3035-hierarchical-sampling-with-occupancy-grid.md).

### [Empty Space Filtering (Training-Time Bounding Box)](6752-empty-space-filtering-training-time-bounding-box.md)
Empty Space Filtering is a training-time acceleration strategy for dynamic neural volume rendering that restricts the optimization domain to the scene's active geometry. It solves the problem of inefficient computation in empty space by identifying inactive regions using alpha values from a coarse deformation feature grid and filtering out sampled points that fall within these regions. Unlike rendering-time acceleration methods that skip ray segments during inference, this method reduces the number of queries to the light-weight MLP during the training phase, thereby accelerating both training and subsequent rendering speeds. It sets itself apart from siblings like [Distance Map Acceleration](972-distance-map-acceleration.md) by operating on the training data sampling pipeline rather than the ray traversal logic, and from [Two-stage Ray Marching with Empty-Space Skipping](2985-two-stage-ray-marching-with-empty-space-skipping.md) by using a coarse grid prior to define a bounding box rather than skipping steps in a marching loop [G]. See [Empty Space Filtering (Training-Time Bounding Box)](6752-empty-space-filtering-training-time-bounding-box.md).

### [MERF Real-Time Rendering](10175-merf-real-time-rendering.md)
MERF Real-Time Rendering is a WebGL-based implementation for synthesizing views from Memory-Efficient Radiance Fields (MERF) using a multi-resolution occupancy grid hierarchy for empty space skipping. It differs from CUDA-based accelerators like Instant-NGP by prioritizing browser portability and memory efficiency, achieving real-time frame rates on consumer hardware by combining coarse-to-fine grid queries with deferred appearance sampling. See [MERF Real-Time Rendering](10175-merf-real-time-rendering.md).

### [VDBEstimator](14369-vdbestimator.md)
VDBEstimator is an occupancy estimation method that uses a volumetric data base (VDB) grid, specifically the fVDB format, to perform spatial skipping of invisible space during ray marching. It maintains a mutable grid and a buffer of float occupancy values to guide sampling, allowing rays to bypass inactive regions without evaluating the volume density function. It builds on [Occupancy Grid and Map-Based Empty Space Skipping](3852-occupancy-grid-and-map-based-empty-space-skipping.md) by leveraging hierarchical sparse structures for efficient traversal. See [VDBEstimator](14369-vdbestimator.md).

### Ray Marching with Occupancy Grid (Instant-NGP style)
An acceleration strategy that maintains an occupancy grid marking voxels as empty or non-empty to prevent sampling in empty spaces, updated periodically based on SDF values [S1]. It maintains an occupancy grid that marks each voxel grid as empty or non-empty to guide the marching process [S1]. The occupancy grid is periodically updated based on the SDF value predicted by the model [S1]. The update uses the SDF value $d$ to calculate a density value $\phi_s(d)$ for each grid, where $\phi_s(x) = \frac{se^{-sx}}{(1 + e^{-sx})^2}$ is the logistic density distribution and $s$ is a learnable parameter [S1]. The occupancy grid is then updated in the same manner as Instant-NGP [S1]. To achieve faster convergence, 90% of rays are sampled on foreground pixels and 10% on background pixels [S1].

## Background
The concept of using occupancy grids for empty space skipping in volume rendering has been widely adopted in both traditional ray casting and modern neural rendering pipelines. The specific integration of occupancy grids with neural implicit surfaces, such as in NeuS2, leverages the strategy from Instant-NGP to accelerate training and rendering by preventing sampling in empty spaces [S1]. This approach is particularly effective in dynamic scene reconstruction, where the occupancy grid is updated periodically based on predicted SDF values [S1].
