# MERF Real-Time Rendering

Also called: MERF viewer, Real-Time Viewer Rendering Pipeline, Three.js MERF renderer

## Overview
MERF Real-Time Rendering is a WebGL-based implementation for synthesizing views from Memory-Efficient Radiance Fields (MERF) using a multi-resolution occupancy grid hierarchy for empty space skipping [S2]. It differs from CUDA-based accelerators like Instant-NGP by prioritizing browser portability and memory efficiency, achieving real-time frame rates on consumer hardware by combining coarse-to-fine grid queries with deferred appearance sampling [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** MERF scene representation (split into density texture and appearance texture containing diffuse RGB and feature vectors), camera parameters, and a multi-resolution occupancy grid hierarchy [S2].
*   **Output:** Final image color per pixel [S2].

**Data Structures:**
1.  **Occupancy Grid Hierarchy:** A set of binary textures representing spatial occupancy [S2].
    *   **Construction:** Generated by max-pooling a full-resolution binary mask $A$ with filter sizes $F \in \{16, 32, 128\}$ [S2].
    *   **Resolution:** If the base resolution is $R$, the hierarchy levels have resolutions $R/16$, $R/32$, and $R/128$ [S2].
    *   **Storage:** Textures are encoded as PNGs to reduce video memory usage [S2].
2.  **Scene Textures:**
    *   **Density Texture:** Stores volume density $\sigma$ [S2].
    *   **Appearance Texture:** Stores diffuse RGB colors and feature vectors [S2].
    *   **Layout:** Split into separate components to allow deferred access [S2].

**Algorithm Steps:**
1.  **Ray Initialization:** For each pixel, generate ray origin $\mathbf{o}$ and direction $\mathbf{d}$ [S2].
2.  **Termination Check:** Initialize transmittance $T = 1.0$ [G]. If $T < 2 \times 10^{-4}$, terminate the ray [S2].
3.  **Coarse-to-Fine Query:** Iterate through the occupancy grid hierarchy from coarsest to finest level [S2]. For the current sample position $\mathbf{x}$, compute grid indices for the current level [S2]. Query the occupancy grid at these indices [S2]. If any level indicates the voxel is empty (0), calculate the exit point of the empty block using ray-AABB intersection [S2]. Advance the ray sample position $\mathbf{x}$ to this exit point and restart the hierarchy query from the coarsest level [S2].
4.  **Scene Access:** If all levels in the hierarchy indicate the voxel is occupied (1), access the MERF scene representation [S2].
    *   **Deferred Sampling:** Query the Density Texture at $\mathbf{x}$ to obtain $\sigma$ [S2]. Compute voxel opacity contribution. If $\sigma$ results in non-zero opacity, query the Appearance Texture at $\mathbf{x}$ to obtain color $\mathbf{c}$ and features [S2]. If $\sigma$ is zero, skip reading the Appearance Texture [S2].
5.  **Volume Rendering:** Compute color contribution $C_{\text{sample}}$ and update transmittance $T$ using standard volume rendering integration [S2]. Update sample position $\mathbf{x} \leftarrow \mathbf{x} + \Delta t \cdot \mathbf{d}$ [G].
6.  **Loop:** Repeat steps 2–5 until $T < 2 \times 10^{-4}$ or the ray exits the scene bounds [S2].

**Formulas:**
*   Opacity per step: $\alpha = 1 - e^{-\sigma \Delta t}$ [G]
*   Transmittance update: $T_{\text{new}} = T_{\text{old}} \cdot (1 - \alpha)$ [G]
*   Color accumulation: $C_{\text{out}} = C_{\text{in}} + \alpha \cdot \mathbf{c} \cdot T_{\text{old}}$ [G]

**Pseudocode:**

```python
def render_ray(ray_origin, ray_direction, occupancy_grids, density_tex, appearance_tex):
    T_THRESHOLD = 2e-4
    FILTER_SIZES = [128, 32, 16]  # Coarsest to finest
    STEP_SIZE = 0.01              # Fixed step size [G]

    t = 0.0
    T = 1.0
    accumulated_color = [0.0, 0.0, 0.0]

    while T > T_THRESHOLD:
        current_pos = [ray_origin[i] + t * ray_direction[i] for i in range(3)]
        skip = False

        for level_idx in range(len(FILTER_SIZES)):
            res = FILTER_SIZES[level_idx]
            # Map world position to integer grid indices (coordinates assumed normalized to [0,1])
            grid_idx = (int(current_pos[0] * res), int(current_pos[1] * res), int(current_pos[2] * res))

            # Query binary occupancy (0=empty, 1=occupied)
            is_occupied = occupancy_grids[level_idx][grid_idx[0]][grid_idx[1]][grid_idx[2]]

            if is_occupied == 0:
                # Empty space detected: skip to the end of this block
                min_corner = [grid_idx[i] / res for i in range(3)]
                max_corner = [(grid_idx[i] + 1) / res for i in range(3)]

                t_min = 0.0
                t_max = float('inf')
                ray_misses = False
                for i in range(3):
                    if ray_direction[i] == 0.0:
                        if current_pos[i] < min_corner[i] or current_pos[i] > max_corner[i]:
                            ray_misses = True
                            break
                    else:
                        t1 = (min_corner[i] - current_pos[i]) / ray_direction[i]
                        t2 = (max_corner[i] - current_pos[i]) / ray_direction[i]
                        t_min = max(t_min, min(t1, t2))
                        t_max = min(t_max, max(t1, t2))

                if not ray_misses and t_max > t:
                    t = t_max
                    skip = True
                    break  # Restart hierarchy check from coarsest level at new position

        if skip:
            continue

        # All levels occupied: access scene representation
        sigma = texture_lookup(density_tex, current_pos)
        if sigma > 0.0:
            color, features = texture_lookup(appearance_tex, current_pos)
            alpha = 1.0 - exp(-sigma * STEP_SIZE)
            accumulated_color = [accumulated_color[i] + T * alpha * color[i] for i in range(3)]
            T *= (1.0 - alpha)

        t += STEP_SIZE

    return accumulated_color
```

**Parameters:**
*   **Transmittance Termination Threshold:** $2 \times 10^{-4}$ [S2].
*   **Occupancy Grid Filter Sizes:** 16, 32, and 128 [S2].
*   **Base Resolution:** Example given as 4096, resulting in grid sizes 256, 128, and 32 [S2].

**Edge Cases and Pitfalls:**
*   **Precision:** Ray-AABB intersection must correctly compute block exits to prevent sampling gaps or overlaps [G].
*   **Memory Layout:** The MLP optimization relies on linear memory access patterns; improper texture layout can negate speed gains [S2].
*   **Empty Space:** Skipping logic must correctly handle the transition between grid levels to avoid missing thin occupied structures [G].

## Operating characteristics
*   **Performance:** On an RTX 3090 GPU at 1920x1080 resolution, MERF renders at frame rates well above 100 FPS [S2]. In contrast, Instant-NGP achieves 4 FPS on the same hardware at the same resolution [S2].
*   **Memory:** MERF consumes approximately one-fifth of the video memory of SNeRG++ [S2].
*   **Hardware:** Implemented as a WebGL application (Three.js), making it portable across devices including mobile browsers, though performance varies by GPU [S2].
*   **Optimizations:**
    *   Loop unrolling of the deferred rendering MLP [S2].
    *   Memory layout modifications for linear access [S2].
    *   Exploitation of fast `mat4` multiplication [S2].
    *   These optimizations provide an additional 4× speed-up [S2].
*   **Limitations:** Quality reduction compared to non-real-time methods is evident in background regions (e.g., 1.24 dB PSNR reduction compared to MobileNeRF on Macbook, though MobileNeRF uses 2x memory) [S2].

## Background
*   **Origin:** MERF (Memory-Efficient Radiance Fields) was introduced by [S2] to enable real-time view synthesis in unbounded scenes with limited memory.
*   **Implementation:** The real-time viewer is implemented as a Javascript 3D (Three.js) web application, orchestrated by a single GLSL fragment shader [S2].
*   **Context:** It builds upon SNeRG's implementation and uses the view-dependence model introduced by Hedman et al. [S2]. It is designed to be more portable than CUDA-based solutions like Instant-NGP [S2].
