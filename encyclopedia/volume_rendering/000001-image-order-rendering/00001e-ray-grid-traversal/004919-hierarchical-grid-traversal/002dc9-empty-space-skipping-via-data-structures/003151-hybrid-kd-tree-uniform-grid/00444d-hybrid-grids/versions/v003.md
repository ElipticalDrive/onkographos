# Hybrid Grids


## Overview
Hybrid Grids is a rendering strategy combining a shallow k-d tree with a global grid of macro cells to perform empty-space skipping [S1, unofficial]. It addresses the trade-off between the high construction cost of deep trees and the coarse skipping granularity of shallow trees by using the k-d tree for coarse traversal and the global grid for fine-grained empty space detection within leaf nodes [S1, unofficial]. It sets itself apart from pure hierarchical structures by decoupling tree depth from skipping granularity, enabling faster construction while maintaining rendering efficiency in large datasets [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Sparse volumetric dataset, k-d tree construction parameters (macro cell size $32^3$), global grid resolution (macro cell size $16^3$) [S1, unofficial].
- Output: Rendered image with empty-space skipping applied [S1, unofficial].

**Data Structures:**
1. **Shallow k-d tree:** Built using Spatial Volume Traversal (SVT) macro cells of size $32^3$ [S1, unofficial]. Each SVT stores occupancy information for its volumetric region [S1, unofficial].
2. **Global Grid:** A uniform grid of macro cells derived from the SVTs [S1, unofficial]. Each cell represents a $16^3$ voxel region and stores occupancy status (empty or occupied) [S1, unofficial].

**Steps:**
1. **Construct Shallow k-d Tree:** Build a shallow k-d tree using SVT macro cells of size $32^3$ [S1, unofficial].
2. **Derive Global Grid:** Extract occupancy information from the SVTs of the k-d tree [S1, unofficial].
3. **Resample Global Grid:** Resample the derived grid to a macro cell size of $16^3$ using constant-time operations on the SVTs [S1, unofficial]. The original construction size of $32^3$ is replaced by $16^3$ for finer granularity [S1, unofficial].
4. **Ray Traversal:** Adapt the ray marching algorithm to perform full traversal per ray until a k-d tree leaf node is found [S1, unofficial].
5. **Fine-Grained Skipping:** Inside the k-d tree leaf node, use the global grid to skip over empty space with $16^3$ granularity [S1, unofficial].

**Pseudocode:**
```python
def render_hybrid_grid(volume, kdtree, global_grid, grid_origin, grid_spacing):
    # kdtree: shallow k-d tree with leaf nodes containing SVT occupancy
    # global_grid: uniform grid of 16^3 macro cells with occupancy flags
    # grid_origin: (x, y, z) of global grid origin
    # grid_spacing: 16.0 (voxel size per macro cell)
    
    for pixel in pixels:
        ray_origin = pixel_to_ray_origin(pixel)
        ray_direction = pixel_to_ray_direction(pixel)
        
        # Step 1: Traverse k-d tree to find leaf
        # Standard k-d tree traversal logic [G]
        leaf_node = traverse_kdtree(ray_origin, ray_direction, kdtree)
        
        if leaf_node is None or leaf_node.is_empty:
            continue
            
        # Step 2: Use global grid for fine-grained skipping within leaf
        leaf_min, leaf_max = leaf_node.bounds
        
        # Map leaf bounds to global grid coordinates
        min_cell = [int((leaf_min[i] - grid_origin[i]) / grid_spacing) for i in range(3)]
        max_cell = [int((leaf_max[i] - grid_origin[i]) / grid_spacing) for i in range(3)]
        
        # Ray-grid traversal (DDA) within leaf bounds
        cell = min_cell[:]
        step = [1 if ray_direction[i] > 0 else -1 for i in range(3)]
        t_delta = [abs(1.0 / ray_direction[i]) for i in range(3)]
        t_max = [t_delta[i] * (grid_spacing - (ray_origin[i] - grid_origin[i]) % grid_spacing) for i in range(3)]
        
        while all(cell[i] <= max_cell[i] for i in range(3)):
            if not global_grid[cell[0], cell[1], cell[2]].is_empty:
                # Standard volume shading step [G]
                render_volume_segment(ray_origin, ray_direction, cell)
            
            if t_max[0] < t_max[1] and t_max[0] < t_max[2]:
                cell[0] += step[0]
                t_max[0] += t_delta[0]
            elif t_max[1] < t_max[2]:
                cell[1] += step[1]
                t_max[1] += t_delta[1]
            else:
                cell[2] += step[2]
                t_max[2] += t_delta[2]
```

**Parameters:**
- Macro cell size for k-d tree construction: $32^3$ [S1, unofficial].
- Macro cell size for global grid: $16^3$ [S1, unofficial].

**Edge Cases and Pitfalls:**
- Precision: Not given in the sources.
- Boundaries: The global grid must be aligned with the k-d tree's SVT structure to ensure correct mapping [S1, unofficial].
- Degenerate Input: Not given in the sources.

## Operating characteristics
- **Time Complexity:** Construction time is identical to shallow k-d trees [S1, unofficial]. Rendering time depends on the depth of the k-d tree and the granularity of the global grid [S1, unofficial].
- **Memory Complexity:** Storage overhead is negligible as the global grid is derived from the SVTs of the k-d tree [S1, unofficial].
- **Measured Performance:** Outperforms the outer loop approach (calling a volume rendering shader per block) when using relatively deep trees [S1, unofficial]. Construction performance is the same as that for shallow k-d trees [S1, unofficial].
- **Scaling:** Not given in the sources.
- **Strengths:** Faster construction than deep trees, finer-grained empty space skipping than shallow trees alone, effective for large datasets near available texture memory [S1, unofficial].
- **Limitations:** Construction times are significantly higher than shallow trees when compared to deep trees, but identical to shallow trees [S1, unofficial]. May not be optimal for all scene types [S1, unofficial].
- **When to use:** When data sets are large (near available texture memory) or when empty space manifests as wholes inside the volume [S1, unofficial].
- **When not to use:** Not given in the sources.

## Background
Hybrid Grids was proposed in [ZML19] as an alternative rendering strategy to balance the trade-offs between deep and shallow k-d trees [S1, unofficial]. It was evaluated in the context of the Virvo volume rendering library [SWWL01] and the Visionaray library [ZWL17] [S1, unofficial]. The approach leverages the occupancy information stored in Spatial Volume Traversal (SVT) macro cells to derive a global grid, allowing for efficient empty-space skipping without significant additional storage overhead [S1, unofficial].
