# Hybrid kd-tree/Uniform Grid
Also called: Hybrid kd-tree/uniform grid structure (Zellmann et al.), Zellmann et al. Hybrid Structure

## Overview
This method accelerates volume rendering by combining a kd-tree at the root level with a uniform grid at the leaf-node level to perform efficient empty-space skipping [S1, unofficial]. It addresses the trade-off between the high construction cost of deep trees and the coarse skipping granularity of shallow trees by decoupling tree depth from skipping granularity [S1, unofficial]. Unlike pure hierarchical structures, it allows for faster construction while maintaining rendering efficiency in large datasets by using the kd-tree for coarse traversal and the uniform grid for fine-grained empty-space detection within leaf nodes [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D volume dataset; a transfer function defining opacity/density thresholds for "active" regions.
*   **Output:** A rendered image; a sorted list of non-empty leaf nodes for GPU iteration.

**Data Structures:**
1.  **Hybrid Structure:**
    *   **Root:** A kd-tree. Each node stores splitting planes and bounding boxes.
    *   **Leaves:** Uniform grids. Each leaf node contains a regular 3D grid of cells. Cells store metadata indicating occupancy (empty vs. active) or data values.
    *   **Layout:** The kd-tree nodes are stored in a flat array or pointer-based structure. Leaf nodes point to their respective uniform grid arrays. The uniform grid cells may store either a data value or "uniformity information" indicating the size of an empty octant [S2, unofficial].

**Steps:**
1.  **Construction:**
    *   Build a kd-tree over the volume data. The splitting criteria typically use summed-volume tables or density thresholds to balance the tree [S1, unofficial].
    *   At each leaf node of the kd-tree, subdivide the corresponding volume region into a uniform grid.
    *   Populate the uniform grid cells with occupancy metadata. A cell is marked "active" if its maximum scalar value exceeds a threshold $\tau$ or if it contains non-zero density [G].
    *   For the Uniform Buffer variant, store "uniformity information" in empty voxels of the regular 3D raster, indicating the size of the empty octant to skip [S2, unofficial].

2.  **CPU Traversal (Pre-processing):**
    *   Traverse the kd-tree on the CPU.
    *   Identify all non-empty leaf nodes.
    *   Sort these leaf nodes based on their spatial position relative to the camera or ray origin to optimize GPU processing order [S1, unofficial].

3.  **GPU Rendering (Ray Casting):**
    *   For each ray, use the sorted list of non-empty leaf nodes to determine which regions to sample.
    *   Skip rays that do not intersect any active leaf nodes.
    *   For intersecting rays, iterate through the active leaf nodes.
    *   Within each leaf node, traverse the uniform grid.
    *   If a cell contains "uniformity information" (in the Uniform Buffer variant), leap forward to the first voxel beyond the uniform region [S2, unofficial].
    *   Sample the primary volume texture only within active cells.

**Formulas:**
*   **Occupancy Check:** A block/cell is active if $\max(\text{block}) > \tau$ [G].
*   **Coordinate Mapping:** Map ray position $u_{\text{vol}}$ to grid index $u_{\text{occ}}$ via $u_{\text{occ}} = \lfloor u_{\text{vol}} / B \rfloor$, where $B$ is the block size [G].
*   **Leap Forward:** If a voxel contains uniformity information for an octant of size $S$, advance the ray by $S$ units in the ray direction [S2, unofficial].

**Parameters:**
*   **Threshold $\tau$:** Density/opacity threshold for activity. Typical value: Not given in the sources.
*   **Leaf Grid Resolution:** Resolution of the uniform grid within each kd-tree leaf. Typical value: Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Precision:** Floating-point precision errors in ray-triangle or ray-plane intersections during kd-tree traversal may cause missed nodes or double-sampling [G].
*   **Boundary Conditions:** Rays entering/exiting the volume must be correctly handled to avoid out-of-bounds memory access in the uniform grid [G].
*   **Transfer Function Changes:** If the transfer function changes, the occupancy metadata may need to be recomputed, which can be costly if done per frame [S1, unofficial].

## Subtopics

### [Hybrid Grids](11219-hybrid-grids.md)
Hybrid Grids is a volume rendering strategy that combines a shallow k-d tree with a global grid of macro cells to perform empty-space skipping. It solves the trade-off between the high construction cost of deep trees and the coarse skipping granularity of shallow trees by using the k-d tree for coarse traversal and the global grid for fine-grained empty space detection within leaf nodes. It sets itself apart from pure hierarchical structures by decoupling the tree depth from the granularity of empty-space skipping, allowing for faster construction while maintaining rendering efficiency in large datasets.

### Uniform Buffer
A combination of hierarchical and regular grid advantages where uniformity information decoded by an octree is stored in the empty space of a regular 3D raster to skip empty space without tree search overhead [S2, unofficial]. When a ray encounters a voxel containing 'uniformity information', instruct the ray to perform a leap forward to the first voxel beyond the uniform region [S2, unofficial]. Voxels in the uniform buffer contain either a data value or information indicating to which size empty octant they belong [S2, unofficial]. Traversing a hierarchical data structure is inefficient compared to regular grids; the uniform buffer avoids the time-consuming tree search for appropriate neighbors [S2, unofficial]. The approach saves the need to perform a tree search for the appropriate neighbor, which is the most time-consuming operation and major disadvantage of hierarchical structures [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Construction is $O(N \log N)$ for the kd-tree and $O(N)$ for the uniform grid population, where $N$ is the number of voxels. Rendering is $O(R \cdot L \cdot G)$, where $R$ is the number of rays, $L$ is the number of active leaf nodes, and $G$ is the average number of active cells per leaf node.
*   **Memory Complexity:** $O(N)$ for the volume data plus overhead for the kd-tree nodes and uniform grid metadata. The uniform buffer variant may have additional overhead for storing uniformity information [S2, unofficial].
*   **Measured Performance:** Not given in the sources.
*   **Strengths:** Faster construction than deep trees; efficient empty-space skipping; decoupled granularity [S1, unofficial]. Avoids time-consuming tree searches for neighbors [S2, unofficial].
*   **Limitations:** Requires CPU-GPU synchronization for sorted leaf node lists; transfer-function dependent updates may be costly [S1, unofficial].
*   **When to Use:** Large datasets with significant empty space; scenarios where construction time is a bottleneck.
*   **When Not to Use:** Small datasets where overhead dominates; dynamic scenes requiring frequent structure updates.

## Background
The hybrid kd-tree/uniform grid structure was presented by Zellmann et al. [ZML19] as a method for empty-space skipping in volume rendering [S1, unofficial]. It builds on earlier work by Zellmann et al. [ZSL21] on kd-tree construction based on summed-volume tables, adapting it for GPU-based construction [S1, unofficial]. The uniform buffer variant is described in tutorials on volume visualization techniques, highlighting the inefficiency of hierarchical structure traversal compared to regular grids [S2, unofficial].
