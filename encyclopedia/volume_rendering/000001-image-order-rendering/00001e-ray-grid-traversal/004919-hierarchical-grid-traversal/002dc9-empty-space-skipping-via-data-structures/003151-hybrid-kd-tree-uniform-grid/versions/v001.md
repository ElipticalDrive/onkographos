# Hybrid kd-tree/Uniform Grid
Also called: Hybrid kd-tree/uniform grid structure (Zellmann et al.), Zellmann et al. Hybrid Structure

## Overview
This method accelerates volume rendering by combining a kd-tree at the root level with a uniform grid at the leaf-node level to perform empty-space skipping [S1, unofficial]. It distinguishes itself from pure uniform grids by using the kd-tree to handle irregular data distributions coarsely, while the leaf-level uniform grids provide efficient, fine-grained traversal within active regions [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D volume dataset and a transfer function.
*   **Output:** A rendered image.
*   **Data Structure:** A hybrid tree where internal nodes are kd-tree splits and leaf nodes contain uniform occupancy grids.

**Data Structures:**
1.  **kd-tree:** Root structure. Each node stores a splitting plane (axis and position) and pointers to left/right children.
2.  **Leaf Node:** Represents a spatial region. Contains a uniform grid (occupancy map) indicating active voxels within that region.
3.  **Occupancy Grid:** A 3D array of bits/flags within each leaf, corresponding to the subdivision of the leaf's bounding box.

**Algorithm Steps:**
1.  **Construction:**
    *   Build a kd-tree over the volume data. Zellmann et al. adapt a summed-volume table approach for GPU-based construction [S1, unofficial].
    *   At each leaf node of the kd-tree, construct a uniform grid representing the occupancy of the sub-volume. A cell is marked active if it contains data exceeding a threshold (e.g., density or opacity) [S1, unofficial].
2.  **Rendering (CPU-GPU Hybrid):**
    *   **CPU Traversal:** Traverse the kd-tree on the CPU to identify all non-empty leaf nodes.
    *   **Sorting:** Sort the list of non-empty leaf nodes (e.g., by depth or ray intersection order) [S1, unofficial].
    *   **GPU Iteration:** Pass the sorted list to the GPU. For each ray, iterate through the relevant leaf nodes in the list.
    *   **Leaf Traversal:** Within each active leaf node, use the uniform grid to skip inactive regions and sample only active voxels [S1, unofficial].

**Pseudocode:**
```python
# Construction Phase (Conceptual)
def build_hybrid_structure(volume, threshold):
    # Build kd-tree recursively
    kd_tree = build_kd_tree(volume)
    
    for leaf in kd_tree.leaves:
        # Create uniform grid for this leaf's region
        leaf.grid = create_uniform_grid(leaf.region, volume, threshold)
    return kd_tree

# Rendering Phase
def render_hybrid(kd_tree, sorted_leaves, rays):
    # rays is a list of ray origins and directions
    for ray in rays:
        # Iterate through pre-sorted non-empty leaves
        for leaf in sorted_leaves:
            # Check if ray intersects leaf bounding box
            if ray_intersects_box(ray, leaf.bbox):
                # Traverse uniform grid within leaf
                sample_volume_with_grid_skip(ray, leaf.grid)
```

**Parameters:**
*   **Threshold ($\tau$):** Value below which voxels are considered empty. Not given in the sources.
*   **Leaf Size:** Resolution of the uniform grid at leaf nodes. Not given in the sources.

**Edge Cases:**
*   **Empty Leaves:** The CPU traversal filters these out, so they are not passed to the GPU [S1, unofficial].
*   **Transfer Function Changes:** If the threshold depends on the transfer function, the structure may need rebuilding or updating [S1, unofficial].

## Operating characteristics
*   **Complexity:** Construction is dominated by kd-tree building and leaf grid creation. Rendering complexity depends on the number of non-empty leaves and the sparsity within them.
*   **Performance:** Achieves speed-ups over baseline ray marching by skipping empty regions. Specific numerical performance metrics are not provided in the sources.
*   **Strengths:** Handles irregular data distributions better than pure uniform grids; efficient GPU rendering via sorted leaf lists.
*   **Limitations:** Requires CPU-GPU synchronization for leaf list generation; construction cost on GPU may be high.

## Background
Zellmann et al. [ZML19] presented this hybrid data structure for empty-space skipping in volume rendering [S1, unofficial]. It builds on earlier work by Zellmann et al. [ZSL21] regarding kd-tree reconstruction based on summed-volume tables, adapting it for GPU-based construction [S1, unofficial].
