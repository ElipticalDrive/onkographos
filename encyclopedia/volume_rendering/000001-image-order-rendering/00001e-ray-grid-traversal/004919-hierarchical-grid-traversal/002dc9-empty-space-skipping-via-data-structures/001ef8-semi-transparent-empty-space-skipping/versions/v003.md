# Semi-transparent Empty-Space Skipping

Also called: Analytic Integration with Empty-Space Skipping, Empty-Space Skipping for Semi-transparent Volumes, Semi-transparent Volumetric Rendering with Empty-Space Skipping

## Overview
Semi-transparent Empty-Space Skipping is a ray-tracing optimization for rendering transparent or semi-transparent volumes with constant density. It solves the problem of expensive ray traversal inside large, empty, or low-density regions by combining hierarchical empty-space skipping with analytic integration of the optical depth. Unlike opaque empty-space skipping which culls entire segments, this method identifies the entry and exit points of semi-transparent objects to compute the final color analytically from the segment length, while still using acceleration structures to skip empty space outside the object [S1].

## How it works
The method adapts the hierarchical traversal techniques described in [Empty Space Skipping via Data Structures](5619-empty-space-skipping-via-data-structures.md) to handle transparency. The implementation depends on whether the volume density $\rho$ is constant or varying.

### Inputs and Outputs
*   **Input**: Ray origin $\mathbf{o}$, ray direction $\mathbf{d}$ (normalized), volume density function $\rho(\mathbf{p})$, acceleration structure (BVH) representing the volume bounds, and transfer function parameters (opacity $\alpha$, emission $E$).
*   **Output**: Pixel color $C$ and transmittance $T$.

### Data Structures
The acceleration structure is a Bounding Volume Hierarchy (BVH) where each node stores axis-aligned bounding boxes (AABBs). For semi-transparent empty-space skipping, the BVH nodes must store **lower bounds** on the distance to the ray, rather than just upper bounds used for opaque culling. This allows the ray to "sphere trace" through the interior of the volume to find the exit point [S1].

### Algorithm Steps

#### Case 1: Constant Density
For constant density materials, the optical contribution of a ray segment inside the volume can be computed analytically.

1.  **Find Entry Point**: Perform standard empty-space skipping to find the first intersection $t_{entry}$ with the volume boundary. If no intersection is found, return background color.
2.  **Find Exit Point**: Inside the volume, perform sphere tracing using the BVH with **lower bounds**. The ray continues until it finds a node where the lower bound exceeds the remaining distance to the exit, or it exits the volume. Let the exit point be $t_{exit}$ [S1].
3.  **Analytic Integration**: Compute the optical depth $\tau$ over the segment $[t_{entry}, t_{exit}]$:
    $$
    \tau = \rho \cdot (t_{exit} - t_{entry})
    $$
    The transmittance $T$ and color $C$ are computed as:
    $$
    T = e^{-\tau}
    $$
    $$
    C = E \cdot (1 - T) + C_{background} \cdot T
    $$
    where $E$ is the emission coefficient and $C_{background}$ is the background color [S1].

#### Case 2: Varying Density
For varying density materials, analytic integration is not possible. The method switches to numerical integration inside the volume.

1.  **Find Entry Point**: Use empty-space skipping to find $t_{entry}$ [S1].
2.  **Empty-Space Skipping Outside**: Use sphere tracing with the BVH to skip empty space outside the volume. This step is optimized using the same BVH techniques as the constant density case [S1].
3.  **Numerical Integration Inside**: Once inside the volume, switch to constant-size ray marching. Sample the density $\rho(\mathbf{p})$ at regular intervals and numerically integrate the volume rendering integral:
    $$
    C = \int_{t_{entry}}^{t_{exit}} \rho(\mathbf{p}(t)) \cdot T(t) \, dt
    $$
    This part is **not** optimized by the empty-space skipping acceleration structure, as the density varies and requires sampling [S1].

        distance = t_exit - t_entry
        optical_depth = density_func(ray_origin) * distance
        transmittance = exp(-optical_depth)
        
        color = emission * (1.0 - transmittance) + background_color * transmittance
        return color
    else:
        # Varying density: numerical integration
        # Note: Empty-space skipping is only used to find t_entry and skip outside regions
        # Inside the volume, we must sample
        
        color = 0.0
        transmittance = 1.0
        t = t_entry
        step_size = 0.01 # Constant size ray marching
        
        while t < MAX_DISTANCE and transmittance > EPSILON:
            pos = ray_origin + ray_direction * t
            density = density_func(pos)
            
            # Numerical integration step
            alpha = 1.0 - exp(-density * step_size)
            color += emission * alpha * transmittance
            transmittance *= (1.0 - alpha)
            
            t += step_size
            
        color += background_color * transmittance
        return color

### Parameters and Edge Cases
*   **Density Function**: Must be accessible for evaluation. For constant density, it returns a scalar. For varying density, it returns a scalar field value [S1].
*   **Quadratic Bounds**: Using quadratic bounds instead of linear bounds allows the ray to move away from the entry surface more quickly, improving performance [S1].
*   **Varying Density Pitfall**: Performance gains depend heavily on the amount of empty space in the scene. If the volume is dense everywhere, the overhead of the BVH traversal may not be offset by the skipping benefits [S1].

## Operating characteristics
*   **Time Complexity**: Depends on the BVH traversal depth and the number of samples. For constant density, the number of samples is reduced to 2 (entry/exit) plus BVH nodes visited. For varying density, it is proportional to the volume thickness and sampling rate [S1].
*   **Measured Performance**: On a Clouds scene with constant density, the method achieves a 5.7x speedup over naive sphere tracing (5.6ms vs 31.9ms), reducing average octaves from 1892.0 to 196.3 [S1]. For varying density, it achieves a 1.8x speedup (37.9ms vs 66.5ms), reducing average octaves from 4087.4 to 1675.9 [S1].
*   **Strengths**: Significant speedup for constant density semi-transparent volumes. Effective empty-space skipping for varying density volumes outside the object.
*   **Limitations**: For varying density, the interior requires full numerical integration, limiting the potential speedup. Performance is sensitive to the amount of empty space [S1].

## Background
This method is described in the context of fast sphere tracing of procedural volumetric noise for large scenes [S1]. It extends opaque empty-space skipping techniques to handle transparency by leveraging analytic integration for constant density and hybrid traversal for varying density.
