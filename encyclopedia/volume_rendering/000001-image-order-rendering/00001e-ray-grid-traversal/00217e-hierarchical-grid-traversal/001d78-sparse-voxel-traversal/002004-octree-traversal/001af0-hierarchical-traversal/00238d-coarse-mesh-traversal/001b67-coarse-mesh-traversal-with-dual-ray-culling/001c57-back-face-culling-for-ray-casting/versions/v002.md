# Back-Face Culling for Ray Casting

Also called: Back-face culling for entry/exit determination, Back-face depth culling raycasting, Backface Raycasting, Raycasting with depth pre-pass, Two-Pass Raycasting with Back-Face Depth Buffering, Two-Pass Raycasting with Backface Entry/Exit Points

## Overview
Back-face culling for ray casting is an optimization technique that determines the entry and exit points of a ray into a volume by rendering the back faces of the bounding cube to a texture, avoiding the need to compute ray-cube intersections analytically [S1, unofficial]. It is a two-pass rendering technique: the first pass renders the backface of the bounding box to a framebuffer to record entry depths, and the second pass performs raycasting using those points to drive ray marching, ensuring sampling begins inside the volume and terminates at the exit point [S2, unofficial, S3, unofficial]. This method sets itself apart from analytical intersection methods by leveraging the graphics pipeline's rasterization and depth testing to implicitly solve for ray bounds, and from 3D texture-based entry/exit lookups by using a 2D texture derived from the backface projection [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A volume bounding box (typically a cube defined by 8 vertices and 36 triangle indices), a 3D texture containing volume data (`uVolData`), a 2D texture for back-face coordinates (`uBackCoord` or `ExitPoints`), and camera matrices (Model-View `uMVMatrix`, Projection `uPMatrix`) [S1, unofficial, S3, unofficial].
*   **Outputs:** A final color buffer with the composited volume rendering.

**Data Structures:**
1.  **Frame Buffer (`frameBuffer`):**
    *   **Depth Buffer:** A renderbuffer of type `DEPTH_COMPONENT16` with dimensions `width x height` [S3, unofficial].
    *   **Color Texture (`texture`):** A 2D texture of type `RGBA`, `UNSIGNED_BYTE`, dimensions `width x height`, initialized with zeros (`Uint8Array(4 * width * height)`) [S3, unofficial]. Filters: `LINEAR` for `MIN`/`MAG`, `CLAMP_TO_EDGE` for `S`/`T` [S3, unofficial].
2.  **Volume Data Texture (`uVolData`):** 3D texture containing scalar field data [S3, unofficial]. Requires floating-point support (e.g., `OES_texture_float` in WebGL) [S3, unofficial].
3.  **Back-Face Texture (`uBackCoord`):** 2D texture storing the 3D entry points derived from the back-face render [S2, unofficial, S3, unofficial].

**Parameters:**
*   `StepSize`: Controls the step length in ray marching. Used in direction scaling and alpha modulation [S2, unofficial].
*   `ScreenSize`: Resolution of the screen (`width`, `height`), used to normalize fragment coordinates for texture lookup [S2, unofficial].
*   `uBackCoord`: Sampler uniform for the back-face depth/coordinate texture [S3, unofficial].
*   `uVolData`: Sampler uniform for the volume data texture [S3, unofficial].

**Numbered Steps:**

1.  **Initialization:**
    *   Create the frame buffer, depth renderbuffer, and color texture as described above [S3, unofficial].
    *   Load volume data into `uVolData` [S3, unofficial].
    *   Ensure the vertex winding order is Counterclockwise (CCW) so that front faces have outward normals and back faces have inward normals, allowing standard back-face culling logic to identify back faces when front faces are culled [S1, unofficial].

2.  **Pass 1: Back-Face Depth/Coordinate Capture:**
    *   Bind the custom frame buffer [S3, unofficial].
    *   Set the depth function to `GEQUAL` [S3, unofficial]. This ensures that for a given pixel, the depth value written corresponds to the farthest (back-most) surface hit along the view ray, which represents the entry point into the volume from the camera's perspective (assuming the camera is outside) [S3, unofficial].
    *   Enable front-face culling (or disable back-face culling and explicitly cull front faces) to render only the back-facing polygons of the bounding box [S1, unofficial, S2, unofficial].
    *   Execute the **Back-Face Vertex Shader**:
        *   Input: `VerPos` (vec3, object space), `VerClr` (vec3, object space coordinates).
        *   Output: `EntryPoint` (vec3, passed as `VerClr`), `ExitPointCoord` (vec4, `gl_Position`) [S2, unofficial].
        *   Transformation: `gl_Position = uPMatrix * uMVMatrix * vec4(VerPos, 1.0)` [S3, unofficial].
    *   Execute the **Back-Face Fragment Shader**:
        *   Input: `EntryPoint` (interpolated from `VerClr`) [S2, unofficial].
        *   Output: `FragColor` = `vec4(EntryPoint, 1.0)` [S2, unofficial].
    *   The result is a 2D texture where each pixel contains the 3D object-space coordinates of the back-face intersection (entry point) [S2, unofficial].

3.  **Pass 2: Raycasting:**
    *   Bind the default framebuffer (screen) [S3, unofficial].
    *   Set the depth function to `LEQUAL` [S3, unofficial].
    *   Bind `uBackCoord` (the texture from Pass 1) to texture unit 0 [S3, unofficial].
    *   Bind `uVolData` to texture unit 1 [S3, unofficial].
    *   Execute the **Raycast Vertex Shader**:
        *   Input: `VerPos` (vec3), `VerClr` (vec3, object space coordinates).
        *   Output: `EntryPoint` (vec3, interpolated from `VerClr`), `ExitPointCoord` (vec4, `gl_Position`) [S2, unofficial].
        *   Transformation: `gl_Position = uPMatrix * uMVMatrix * vec4(VerPos, 1.0)` [S3, unofficial].
    *   Execute the **Raycast Fragment Shader**:
        *   Input: `EntryPoint` (interpolated front-face vertex color/position), `ExitPointCoord` (interpolated clip-space position) [S2, unofficial].
        *   **Retrieve Exit Point:** Sample the back-face texture using screen coordinates normalized by `ScreenSize`:
            $$ \text{exitPoint} = \text{texture}(uBackCoord, \frac{\text{gl\_FragCoord.st}}{\text{ScreenSize}}).xyz $$
            *   *Pitfall:* `ExitPointCoord` is in clip-space. Do not perform perspective division manually. Use `gl_FragCoord` directly as it corresponds to the rasterized position [S2, unofficial].
        *   **Check Validity:** If `EntryPoint == exitPoint` (or if the back-face texture lookup returns invalid/no-hit data), discard the fragment and render the background color (e.g., white with alpha 0) [S2, unofficial].
        *   **Compute Ray Direction:**
            $$ \text{dir} = \text{exitPoint} - \text{EntryPoint} $$
            $$ \text{len} = \|\text{dir}\| $$
            $$ \text{deltaDir} = \text{normalize}(\text{dir}) \times \text{StepSize} $$
        *   **Ray Marching Loop:**
            Initialize `voxelCoord = EntryPoint`, `colorAcum = vec4(0.0)`, `alphaAcum = 0.0`, `lengthAcum = 0.0` [S2, unofficial].
            For `i` from 0 to `MaxIterations` (e.g., 1600):
            1.  Sample volume: `intensity = texture(uVolData, voxelCoord).x` [S2, unofficial].
            2.  Apply transfer function to get `colorSample` and `alphaSample` [S2, unofficial].
            3.  Composite:
                $$ \text{colorAcum} += \text{colorSample} \times (1.0 - \text{alphaAcum}) $$
                $$ \text{alphaAcum} += \text{alphaSample} \times (1.0 - \text{alphaAcum}) $$
            4.  Update position: `voxelCoord += deltaDir` [S2, unofficial].
            5.  Update length: `lengthAcum += length(deltaDir)` [S2, unofficial].
            6.  **Termination Conditions:**
                *   If `lengthAcum >= len`, break [S2, unofficial].
                *   If `alphaAcum >= 1.0`, clamp `alphaAcum` to 1.0 and break [S2, unofficial].
        *   Output `FragColor = colorAcum` [S2, unofficial].

**Pseudocode:**

```python
def pass1_backface_capture(cube, mv_matrix, p_matrix, frame_buffer):
    # Bind frame buffer and clear
    bind_framebuffer(frame_buffer)
    clear_color(0.0, 0.0, 0.0, 0.0)
    clear(COLOR_BUFFER_BIT | DEPTH_BUFFER_BIT)
    
    enable(DEPTH_TEST)
    set_depth_function(GEQUAL)  # Capture farthest (back) face
    
    use_program(back_face_shader)
    set_uniform("uMVMatrix", mv_matrix)
    set_uniform("uPMatrix", p_matrix)
    
    # Cull front faces to render only back faces
    set_cull_face(FRONT)
    enable(CULL_FACE)
    
    render_triangle_strip(cube.indices, cube.vertices)
    
    disable(CULL_FACE)
    bind_framebuffer(None)

def pass2_ray_casting(cube, mv_matrix, p_matrix, back_face_texture, volume_texture, step_size, screen_size):
    # Bind screen buffer and clear
    bind_framebuffer(screen_buffer)
    clear_color(1.0, 1.0, 1.0, 0.0)  # White background
    clear(COLOR_BUFFER_BIT | DEPTH_BUFFER_BIT)
    
    enable(DEPTH_TEST)
    set_depth_function(LEQUAL)
    
    use_program(raycast_shader)
    set_uniform("uMVMatrix", mv_matrix)
    set_uniform("uPMatrix", p_matrix)
    set_uniform("StepSize", step_size)
    set_uniform("ScreenSize", screen_size)
    
    # Bind textures
    bind_texture_unit(0, back_face_texture)
    bind_texture_unit(1, volume_texture)
    
    # Render front faces (default cull back faces)
    set_cull_face(BACK)
    enable(CULL_FACE)
    
    render_triangle_strip(cube.indices, cube.vertices)
    
    disable(CULL_FACE)
```

**Vertex Shader (Back-Face Pass):**
```glsl
#version 400
layout(location = 0) in vec3 VerPos;
layout(location = 1) in vec3 VerClr; // Object space coordinates

uniform mat4 uMVMatrix;
uniform mat4 uPMatrix;

out vec3 EntryPoint;
out vec4 ExitPointCoord;

void main() {
    EntryPoint = VerClr; // Pass object space position as color
    ExitPointCoord = uPMatrix * uMVMatrix * vec4(VerPos, 1.0);
    gl_Position = ExitPointCoord;
}
```

**Fragment Shader (Raycast Pass):**
```glsl
#version 400
in vec3 EntryPoint;
in vec4 ExitPointCoord;

uniform sampler2D uBackCoord;
uniform sampler3D uVolData;
uniform vec2 ScreenSize;
uniform float StepSize;

out vec4 FragColor;

void main() {
    // Retrieve exit point from back-face texture
    // Note: gl_FragCoord is in window coordinates, normalize by ScreenSize
    vec3 exitPoint = texture(uBackCoord, gl_FragCoord.xy / ScreenSize).xyz;
    
    // If entry and exit are the same, the ray missed the volume or hit an edge
    if (EntryPoint == exitPoint) {
        discard;
    }
    
    vec3 dir = exitPoint - EntryPoint;
    float len = length(dir);
    vec3 deltaDir = normalize(dir) * StepSize;
    
    vec3 voxelCoord = EntryPoint;
    vec4 colorAcum = vec4(0.0);
    float alphaAcum = 0.0;
    float lengthAcum = 0.0;
    
    // Max iterations to prevent infinite loops
    const int MaxIterations = 1600;
    
    for (int i = 0; i < MaxIterations; i++) {
        float intensity = texture(uVolData, voxelCoord).x;
        
        // Apply transfer function (simplified)
        vec4 colorSample = vec4(intensity, intensity, intensity, intensity);
        float alphaSample = intensity;
        
        // Alpha blending
        colorAcum += colorSample * (1.0 - alphaAcum);
        alphaAcum += alphaSample * (1.0 - alphaAcum);
        
        voxelCoord += deltaDir;
        lengthAcum += length(deltaDir);
        
        // Termination conditions
        if (lengthAcum >= len) break;
        if (alphaAcum >= 1.0) {
            alphaAcum = 1.0;
            break;
        }
    }
    
    FragColor = colorAcum;
}
```

## Subtopics

### [Volume Raycasting with MRT Endpoints](1584-volume-raycasting-with-mrt-endpoints.md)
A technique to obtain ray start and stop positions for volume raycasting by rendering a cube into two floating-point RGB surfaces using a fragment shader that writes object-space coordinates. Front faces go into one attachment, back faces into the other [1584-volume-raycasting-with-mrt-endpoints.md]. This variant uses Multiple Render Targets (MRT) to capture both entry and exit points simultaneously in a single pass, whereas the standard back-face culling method uses two passes (or a depth buffer trick) to derive one point from the back-face and the other from the front-face interpolation. Choose this when single-pass initialization is required and MRT support is available.

## Background
The method originated as an optimization in GPU-based volume rendering to replace CPU-side or complex shader-side ray-cube intersection calculations with hardware-accelerated rasterization and depth testing [S1, unofficial]. It leverages the fact that rendering the back faces of a bounding box to a depth buffer (with `GEQUAL` depth function) effectively records the entry depth of rays into the volume [S1, unofficial]. The technique is documented in various unofficial repositories and tutorials focusing on WebGL and GLSL volume rendering [S1, unofficial, S2, unofficial, S3, unofficial]. It is a variant of hierarchical traversal methods that use coarse meshes, specifically simplifying the entry/exit determination for a cubic bounding box [987-coarse-mesh-traversal-with-dual-ray-culling.md].
