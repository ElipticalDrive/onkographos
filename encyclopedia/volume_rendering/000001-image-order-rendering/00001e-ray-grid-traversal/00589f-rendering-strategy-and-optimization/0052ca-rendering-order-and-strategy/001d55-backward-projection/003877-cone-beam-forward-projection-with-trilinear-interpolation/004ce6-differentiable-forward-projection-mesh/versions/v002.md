# Differentiable Forward Projection (Mesh)

Also called: Differentiable Mesh Projection, FP module, Forward Projection via OpenGL Rasterization, OpenGL forward projection

## Overview
This method computes the differentiable forward projection of 3D triangle meshes onto 2D detector arrays for both parallel and cone-beam geometries [S1, unofficial]. It differs from volume-based approaches (like its parent [Cone Beam Forward Projection with Trilinear Interpolation](8247-cone-beam-forward-projection-with-trilinear-interpolation.md)) by operating directly on mesh topology (vertices and faces) and utilizing a custom CUDA rasterizer to integrate attenuation coefficients along rays, enabling gradient backpropagation through the projection process [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
*   `verts`: Tensor of shape `[batch, num_verts, 3]` containing 3D vertex coordinates [S1, unofficial].
*   `faces`: Tensor of shape `[num_faces, 3]` containing integer indices of vertices for each triangle [S1, unofficial].
*   `idx_angles`: Tensor of shape `[batch]` or scalar indices selecting projection angles from `proj_geom['ProjectionAngles']` [S1, unofficial].
*   `mus`: Tensor of shape `[num_materials]` or `[num_faces]` containing attenuation coefficients ($\mu$) for the materials or faces [S1, unofficial].
*   `proj_geom`: Dictionary containing projection geometry parameters (see Parameters) [S1, unofficial].
*   `labels`: CUDA tensor of shape `[num_faces, 2]` containing outward and inward labels for each face, used to determine surface orientation and material boundaries [S1, unofficial].

**Outputs:**
*   `phat`: Tensor of shape `[batch, height, width]` containing the predicted sinogram/projection values [S1, unofficial].
*   `valid_mask`: Boolean tensor indicating valid pixels (non-zero contribution) [S1, unofficial].

### Data Structures
The `FP` module maintains the following attributes initialized during construction:
*   `proj_geom`: Dictionary with keys:
    *   `type`: String, e.g., `'parallel3d'` or `'conebeam'` [S1, unofficial].
    *   `DetectorColCount`: Integer, width of the detector ($W$) [S1, unofficial].
    *   `DetectorRowCount`: Integer, height of the detector ($H$) [S1, unofficial].
    *   `DetectorSpacingX`: Float, pixel spacing in x [S1, unofficial].
    *   `DistanceOriginSource`: Float, distance from origin to source (for cone beam) [S1, unofficial].
    *   `ProjectionAngles`: Array of angles in radians [S1, unofficial].
*   `labels_fx2`: CUDA tensor of shape `[num_faces, 2]` storing `[label_out, label_in]` for each face [S1, unofficial].
*   `P`: CUDA tensor of shape `[3, 4]` representing the projection matrix [S1, unofficial].
*   `M_left`: CUDA tensor of shape `[3, 3]`, a fixed rotation matrix:
    $$
    M_{left} = \begin{bmatrix} 1.0 & 0 & 0 \\ 0 & 0 & -1 \\ 0 & 1 & 0 \end{bmatrix}
    $$
    This converts from standard coordinate systems to OpenGL conventions [S1, unofficial].

### Numbered Steps
1.  **Initialization**: Compute the projection matrix $P$ from `proj_geom` using a helper function `compute_P(proj_geom)` [S1, unofficial]. Store $P$ and $M_{left}$ as CUDA tensors [S1, unofficial]. Set the view vector $V_t = [0, 0, -max\_sino\_val]$ to position the camera far from the origin [S1, unofficial]. Store detector dimensions $H$ and $W$ from `proj_geom` [S1, unofficial].
2.  **Input Preparation**: Repeat vertices for batch size if necessary [S1, unofficial]. Transpose `verts` to `[batch, 3, num_verts]` for matrix multiplication, then transpose back to `[batch, num_verts, 3]` for subsequent steps [S1, unofficial]. Select projection angles based on `idx_angles` [S1, unofficial]. Compute cosine ($ct$) and sine ($st$) of these angles, unsqueezed for broadcasting [S1, unofficial].
3.  **View Transformation**: Apply 2D rotation in the xy-plane to vertices $(x, y, z)$: $x' = x \cdot ct + y \cdot st$, $y' = -x \cdot st + y \cdot ct$, $z' = z$ [S1, unofficial]. Apply the left rotation matrix $M_{left}$ to the rotated vertices [S1, unofficial]. Translate vertices by the view vector $V_t$ to obtain $VMv$ [S1, unofficial].
4.  **Homogeneous Projection**: Compute vertex lengths (norms) for attenuation calculation: $r = \sqrt{x^2 + y^2 + z^2}$ [S1, unofficial]. Pad vertices with $1.0$ to convert to homogeneous coordinates $[x, y, z, 1]^T$ [S1, unofficial]. Multiply by the projection matrix $P$: $v_h = P \cdot [x, y, z, 1]^T$ [S1, unofficial]. Perform perspective division: $v_{proj} = [x_h/w, y_h/w, z_h/w]$ where $w = v_h[3] + \epsilon$ [S1, unofficial]. Transpose projected points to `[batch, num_verts, 3]` [S1, unofficial].
5.  **Face Processing**: Index vertices by `faces` to get vertex triplets for each face in the batch: $bvf0, bvf1, bvf2$ of shape `[batch, num_faces, 3]` [S1, unofficial]. Index vertex lengths by `faces` to get `len_bxfx3` [S1, unofficial]. Extract the first 2 coordinates of projected points to get `proj_bxfx6` (flattened face vertices in 2D) [S1, unofficial]. Compute edge vectors: $e_1 = bvf1 - bvf0$, $e_2 = bvf2 - bvf0$ [S1, unofficial]. Compute face normals via cross product: $n = e_1 \times e_2$ [S1, unofficial]. Determine front-facing flag: for `parallel3d`, $front\_facing = -n_z$ (negative z-component) [S1, unofficial]; for `conebeam`, $front\_facing = \text{dot}(bvf0, n)$ (dot product of vertex position and normal) [S1, unofficial].
6.  **Coordinate Conversion**: Convert normalized coordinates $[-1, 1]$ to pixel coordinates $[0, W]$ for x-axis and $[0, H]$ for y-axis (flipping vertically) [S1, unofficial].
7.  **Rasterization**: Call the custom CUDA rasterizer with inputs: `proj_bxfx6`, `len_bxfx3`, `front_facing`, `labels`, `mus`, detector dimensions, `max_sino_val`, and a backpropagation flag [S1, unofficial]. The rasterizer iterates over detector pixels and visible faces [S1, unofficial]. For each pixel, it computes barycentric weights $(w_0, w_1, w_2)$ for the covering face [S1, unofficial]. It calculates the integrated attenuation using the barycentric weights and the vertex lengths (distances from origin): $bary = w_0 r_0 + w_1 r_1 + w_2 r_2$ [S1, unofficial]. It updates the sinogram value `im_bxhxwxd` based on the face labels and attenuation coefficients $\mu$: $\text{im} += \text{sign} \cdot \mu_{in} \cdot bary - \text{sign} \cdot \mu_{out} \cdot bary$, where `sign` is $1.0$ if front-facing, $-1.0$ if back-facing, and adjusted if labels are equal or background [S1, unofficial].
8.  **Output**: Squeeze the output tensor `phat` and compute a valid mask using `get_valid_mask` [S1, unofficial]. Return `phat` and `valid_mask` [S1, unofficial].

### Formulas
*   **2D Rotation**: $x' = x \cdot ct + y \cdot st$, $y' = -x \cdot st + y \cdot ct$, $z' = z$ [S1, unofficial].
*   **Homogeneous Projection**: $v_h = P \cdot [x, y, z, 1]^T$ [S1, unofficial].
*   **Perspective Division**: $v_{proj} = [x_h/w, y_h/w, z_h/w]$ where $w = v_h[3] + \epsilon$ [S1, unofficial].
*   **Face Normal**: $n = (bvf1 - bvf0) \times (bvf2 - bvf0)$ [S1, unofficial].
*   **Front-Facing Flag**: $front\_facing = -n_z$ for `parallel3d`; $front\_facing = \text{dot}(bvf0, n)$ for `conebeam` [S1, unofficial].
*   **Barycentric Integration**: $bary = w_0 r_0 + w_1 r_1 + w_2 r_2$ [S1, unofficial].
*   **Sinogram Update**: $\text{im} += \text{sign} \cdot \mu_{in} \cdot bary - \text{sign} \cdot \mu_{out} \cdot bary$ [S1, unofficial].

### Parameters
*   `dtype`: Data type for tensors, default `torch.float32` [S1, unofficial].
*   `max_sino_val`: Float, calculated as `DetectorColCount * DetectorSpacingX * 2`. Used to determine camera distance and clip values [S1, unofficial].
*   `epsilon`: Float, $10^{-8}$, added to the w-component during perspective division to prevent division by zero [S1, unofficial].

### Edge Cases and Pitfalls
*   **Perspective Division**: Uses epsilon $10^{-8}$ to avoid division by zero when $w \approx 0$ [S1, unofficial].
*   **Coordinate Conversion**: Handles both x and y axes with specific slicing patterns to map from normalized to pixel space, including vertical flip for y [S1, unofficial].
*   **Label Handling**: If `label_in < label_out`, the face is skipped; if `label_in == label_out`, the sign is flipped to compensate for the intermediate region; if `label_out == 0` (background), $\mu_{out}$ is negated [S1, unofficial].

### Pseudocode
```python
import torch
import torch.nn as nn

class FP(nn.Module):
    def __init__(self, proj_geom, labels, dtype=torch.float32):
        super(FP, self).__init__()
        self.proj_geom = proj_geom
        self.labels_fx2 = labels.cuda()
        
        # Compute projection matrix P from geometry
        P = compute_P(proj_geom) # Helper function not detailed in source
        self.P = torch.tensor(P, dtype=dtype).cuda()
        
        # Fixed rotation matrix for OpenGL convention
        self.M_left = torch.tensor([[1.0, 0, 0],
                                    [0, 0, -1],
                                    [0, 1, 0]], dtype=dtype).cuda()
        
        # Initialize max_sino_val
        self.max_sino_val = proj_geom['DetectorColCount'] * proj_geom['DetectorSpacingX'] * 2
        
        # Store dimensions
        self.height = proj_geom['DetectorRowCount']
        self.width = proj_geom['DetectorColCount']
        
        # Store projection angles
        self.angles = torch.tensor(proj_geom['ProjectionAngles'], dtype=dtype).cuda()

    def forward(self, verts, faces, idx_angles, mus, backprop=False):
        """
        verts: [batch, num_verts, 3]
        faces: [num_faces, 3]
        idx_angles: [batch] or scalar
        mus: [num_materials] or [num_faces]
        """
        batch_size = verts.size(0)
        num_verts = verts.size(1)
        num_faces = faces.size(0)
        
        # 1. Prepare vertices
        # Transpose to [batch, 3, num_verts] for matrix mult
        verts_T = verts.transpose(1, 2) # [batch, 3, num_verts]
        
        # 2. Get angles
        if idx_angles.dim() == 0:
            idx_angles = idx_angles.unsqueeze(0).repeat(batch_size)
        
        selected_angles = self.angles[idx_angles] # [batch]
        ct = torch.cos(selected_angles).unsqueeze(1).unsqueeze(2) # [batch, 1, 1]
        st = torch.sin(selected_angles).unsqueeze(1).unsqueeze(2) # [batch, 1, 1]
        
        # 3. 2D Rotation in xy-plane
        x = verts_T[:, 0, :] # [batch, num_verts]
        y = verts_T[:, 1, :] # [batch, num_verts]
        z = verts_T[:, 2, :] # [batch, num_verts]
        
        x_new = x * ct + y * st
        y_new = -x * st + y * ct
        z_new = z
        
        rotated_verts = torch.stack([x_new, y_new, z_new], dim=1) # [batch, 3, num_verts]
        
        # 4. Apply M_left
        rotated_verts = torch.matmul(self.M_left, rotated_verts) # [batch, 3, num_verts]
        
        # 5. Translate by V_t = [0, 0, -max_sino_val]
        V_t = torch.tensor([0.0, 0.0, -self.max_sino_val], dtype=rotated_verts.dtype).cuda()
        V_t = V_t.unsqueeze(0).unsqueeze(2) # [1, 3, 1]
        VMv = rotated_verts + V_t # [batch, 3, num_verts]
        
        # 6. Compute vertex lengths (norms)
        lengths = torch.norm(VMv, dim=1) # [batch, num_verts]
        
        # 7. Homogeneous Projection
        # Pad with 1.0
        ones = torch.ones_like(VMv[:, :1, :]) # [batch, 1, num_verts]
        verts_homo = torch.cat([VMv, ones], dim=1) # [batch, 4, num_verts]
        
        # P is [3, 4]
        proj_homo = torch.matmul(self.P, verts_homo) # [batch, 3, num_verts]
        
        # Perspective division
        w = proj_homo[:, 2, :] + 1e-8 # Using z as w for division
        proj_2d = proj_homo[:, :2, :] / w # [batch, 2, num_verts]
        
        # Transpose projected points to [batch, num_verts, 3]
        proj_3d = torch.cat([proj_2d, proj_homo[:, 2:, :]], dim=1) # [batch, 3, num_verts]
        proj_3d = proj_3d.transpose(1, 2) # [batch, num_verts, 3]
        
        # 8. Face Processing
        # Index vertices by faces
        bvf0 = proj_3d[:, faces[:, 0], :] # [batch, num_faces, 3]
        bvf1 = proj_3d[:, faces[:, 1], :]
        bvf2 = proj_3d[:, faces[:, 2], :]
        
        # Index lengths by faces
        len_bxfx3 = lengths[:, faces] # [batch, num_faces, 3]
        
        # Extract projected 2D points
        proj_bxfx6 = torch.cat([bvf0[:, :, :2], bvf1[:, :, :2], bvf2[:, :, :2]], dim=2) # [batch, num_faces, 6]
        
        # Compute edge vectors and normals
        e1 = bvf1 - bvf0
        e2 = bvf2 - bvf0
        n = torch.cross(e1, e2, dim=2) # [batch, num_faces, 3]
        
        # Determine front-facing flag
        if self.proj_geom['type'] == 'parallel3d':
            front_facing = -n[:, :, 2] # Negative z-component
        else: # conebeam
            front_facing = torch.sum(bvf0 * n, dim=2) # Dot product
            
        # Coordinate conversion [-1, 1] to [0, W], [0, H]
        x_pix = (proj_bxfx6[:, :, 0::2] + 1.0) * self.width / 2.0
        y_pix = (1.0 - proj_bxfx6[:, :, 1::2]) * self.height / 2.0
        
        # 9. Rasterization
        # Call custom CUDA rasterizer
        phat = cuda_rasterizer(
            proj_bxfx6, front_facing, len_bxfx3, self.labels_fx2, mus,
            self.height, self.width, self.max_sino_val, backprop
        ) # [batch, height, width]
        
        # 10. Output
        valid_mask = get_valid_mask(phat) # Helper function not detailed in source
        return phat, valid_mask
```
