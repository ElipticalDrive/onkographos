# Voxel Ray Marching with Traversal Order Optimization

Also called: 33 float points ray marching, 3D Texture Path Tracer

## Overview
Voxel Ray Marching with Traversal Order Optimization renders a 3D voxel texture by advancing a ray from the camera to the back plane, compositing samples via front-to-back alpha blending to visualize the volume [S1, unofficial]. It differs from its parent [Ray Marching Optimization](10233-ray-marching-optimization.md) by specifically minimizing floating-point operations during traversal through precomputed step deltas and explicit axis-based boundary comparison [S2, unofficial]. It is distinct from [Tiled Ray Marching with Grid Sampling](2586-tiled-ray-marching-with-grid-sampling.md) by operating on a per-ray basis without tile-based batching, and from [Volume Ray Marching Optimization](14309-volume-ray-marching-optimization.md) by relying on fixed-step or grid-aligned traversal logic rather than adaptive step sizing based on density gradients [S2, unofficial].

## How it works
This method builds on [Ray-grid traversal](17-ray-grid-traversal.md), which advances analytically from one cell boundary to the next. The core mechanism determines the next cell by comparing distances to upcoming boundaries on the x, y, and z axes, selecting the minimum distance to advance.

### Inputs and Outputs
**Inputs:**
*   `ray`: A ray structure containing `origin` (vec3) and `direction` (vec3, normalized).
*   `volumeAABB`: The bounding box of the voxel volume.
*   `_volumeSize`: The physical size of the entire voxel volume (scalar or vec3, typically uniform).
*   `_volumeGrid`: A vec3 representing the dimensions (width, height, depth) of the voxel grid in number of voxels.
*   `texture3D`: The 3D texture containing voxel data (color and alpha).
*   `_alphaClip`: The alpha threshold used to determine if a sampled voxel is opaque/solid.
*   `rec.t`: The distance along the ray to the entry point of the volume (if the ray originates outside or after an initial intersection).

**Outputs:**
*   `rec`: A record structure containing:
    *   `hit` (bool): True if a solid voxel was encountered.
    *   `color` (vec3): The color of the hit voxel.
    *   `position` (vec3): The world-space position of the hit.
    *   `normal` (vec3): The normal of the hit surface (approximated by the entry face normal).

### Data Structures
*   **`recordVolume`**:
    *   `hit`: `bool`
    *   `color`: `vec3`
    *   `position`: `vec3`
    *   `normal`: `vec3`
    *   `t`: `float` (distance along ray)

### Parameters
*   `STEP_LENGTH`: Fixed step size in world units (e.g., 0.005f) used in fixed-step variants [S1, unofficial].
*   `INV_STEP_LENGTH`: Precomputed inverse of `STEP_LENGTH` (1.0f / STEP_LENGTH) [S1, unofficial].
*   `mipmapLevel`: Integer state selecting the mipmap level of `texture3D` [S1, unofficial].
*   `_alphaClip`: Alpha threshold for early termination/hit detection [S2, unofficial].

### Algorithm Steps
The algorithm minimizes floating-point operations by precomputing step deltas (`tDelta`) and determining traversal order via comparison of maximum times to next boundaries (`tMax`) for each axis [S2, unofficial].

1.  **Initialize Traversal State**:
    *   Set `rec.hit = false`.
    *   Determine step direction for each axis:
        *   `stepX = 1` if `ray.direction.x > 0`, else `-1`.
        *   `stepY = 1` if `ray.direction.y > 0`, else `-1`.
        *   `stepZ = 1` if `ray.direction.z > 0`, else `-1`.

2.  **Precompute Step Deltas (`tDelta`)**:
    *   Calculate the time to travel one voxel unit along each axis.
    *   Formula:
        $$ tDeltaX = \left| \frac{\text{voxel\_size}_x}{\text{ray.direction.x}} \right| $$
        $$ tDeltaY = \left| \frac{\text{voxel\_size}_y}{\text{ray.direction.y}} \right| $$
        $$ tDeltaZ = \left| \frac{\text{voxel\_size}_z}{\text{ray.direction.z}} \right| $$
    *   Where $\text{voxel\_size}_x = \frac{\text{_volumeSize}}{\text{_volumeGrid.x}}$ (assuming uniform volume size and grid dimensions).

3.  **Calculate Initial Position and Indices**:
    *   Compute the current position in world space:
        $$ \text{pos} = \text{ray.origin} + \text{ray.direction} \times \text{rec.t} $$
    *   Convert world position to voxel indices:
        $$ X = \lfloor \text{pos.x} / \text{_volumeSize} \times \text{_volumeGrid.x} \rfloor $$
        $$ Y = \lfloor \text{pos.y} / \text{_volumeSize} \times \text{_volumeGrid.y} \rfloor $$
        $$ Z = \lfloor \text{pos.z} / \text{_volumeSize} \times \text{_volumeGrid.z} \rfloor $$
    *   **Boundary Correction**: If an index equals the grid dimension, decrement by 1 to stay within valid bounds $[0, \text{grid\_dim}-1]$.
        *   If $X == \text{_volumeGrid.x}$, $X \leftarrow X - 1$.
        *   If $Y == \text{_volumeGrid.y}$, $Y \leftarrow Y - 1$.
        *   If $Z == \text{_volumeGrid.z}$, $Z \leftarrow Z - 1$.

4.  **Calculate Initial `tMax`**:
    *   Determine the next voxel index along each axis:
        *   `nextX = 1` if `ray.direction.x > 0`, else `0`.
        *   `nextY = 1` if `ray.direction.y > 0`, else `0`.
        *   `nextZ = 1` if `ray.direction.z > 0`, else `0`.
    *   Calculate the world position of the next boundary:
        *   `nextPos = getPosbyIndex(X + nextX, Y + nextY, Z + nextZ)`
    *   Calculate the time to reach the next boundary along each axis:
        $$ tMaxX = \frac{\text{nextPos.x} - \text{pos.x}}{\text{ray.direction.x}} $$
        $$ tMaxY = \frac{\text{nextPos.y} - \text{pos.y}}{\text{ray.direction.y}} $$
        $$ tMaxZ = \frac{\text{nextPos.z} - \text{pos.z}}{\text{ray.direction.z}} $$

5.  **Check for Immediate Hit**:
    *   Sample the current voxel: `sample = sample3D(X, Y, Z)`.
    *   If `sample.a > _alphaClip`:
        *   Set `rec.hit = true`.
        *   Set `rec.color = sample.rgb`.
        *   Set `rec.position = ray.origin + ray.direction * rec.t`.
        *   Set `rec.normal` (initially from `rec.normal` or potential normal).
        *   Return `rec`.

6.  **Main Marching Loop**:
    *   While `!rec.hit`:
        *   Compare `tMaxX`, `tMaxY`, and `tMaxZ` to determine the traversal order. The logic follows a nested comparison structure (0->1->2->3->4 implied) to find the smallest `tMax` [S2, unofficial].
        *   **Case 1: `tMaxX` is smallest** (`tMaxX < tMaxY` and `tMaxX < tMaxZ`):
            *   Increment X: `X += stepX`.
            *   Record potential hit time: `potentialTime = tMaxX`.
            *   Check boundary: If `X >= _volumeGrid.x` or `X < 0`, break loop.
            *   Update `tMaxX`: `tMaxX += tDeltaX`.
            *   Set potential normal: `potentialNormal = vec3(-stepX, 0, 0)`.
        *   **Case 2: `tMaxZ` is smallest** (`tMaxX > tMaxZ` and `tMaxZ < tMaxY`):
            *   Increment Z: `Z += stepZ`.
            *   Record potential hit time: `potentialTime = tMaxZ`.
            *   Check boundary: If `Z < 0` or `Z >= _volumeGrid.z`, break loop.
            *   Update `tMaxZ`: `tMaxZ += tDeltaZ`.
            *   Set potential normal: `potentialNormal = vec3(0, 0, -stepZ)`.
        *   **Case 3: `tMaxY` is smallest** (`tMaxX > tMaxY` and `tMaxY < tMaxZ`):
            *   Increment Y: `Y += stepY`.
            *   Record potential hit time: `potentialTime = tMaxY`.
            *   Check boundary: If `Y >= _volumeGrid.y` or `Y < 0`, break loop.
            *   Update `tMaxY`: `tMaxY += tDeltaY`.
            *   Set potential normal: `potentialNormal = vec3(0, -stepY, 0)`.
        *   **Case 4: `tMaxZ` is smallest** (`tMaxY > tMaxZ`):
            *   Increment Z: `Z += stepZ`.
            *   Record potential hit time: `potentialTime = tMaxZ`.
            *   Check boundary: If `Z < 0` or `Z >= _volumeGrid.z`, break loop.
            *   Update `tMaxZ`: `tMaxZ += tDeltaZ`.
            *   Set potential normal: `potentialNormal = vec3(0, 0, -stepZ)`.
        *   **Sample New Voxel**:
            *   `sample = sample3D(X, Y, Z)`.
            *   If `sample.a > _alphaClip`:
                *   Set `rec.hit = true`.
                *   Set `rec.color = sample.rgb`.
                *   Set `rec.position = ray.origin + ray.direction * (rec.t + potentialTime)`.
                *   Set `rec.normal = potentialNormal`.
                *   Break loop.

7.  **Fixed-Step Variant (Alternative)**:
    *   Some implementations use a fixed step size instead of analytical boundary crossing [S1, unofficial].
    *   Loop `step` from 0 to `numberOfSteps`:
        *   `currentPoint = origin + STEP_LENGTH * step * direction`.
        *   `coordinate = scaleAndBias(currentPoint)`.
        *   `currentSample = textureLod(texture3D, coordinate, mipmapLevel)`.
        *   Composite: `color += (1.0f - color.a) * currentSample`.
        *   Stop if `step` limit reached or `color.a >= 0.99f`.
    *   Apply gamma correction: `color.rgb = pow(color.rgb, 1.0/2.2)`.

### Pseudocode
```python
def raymarch_volume(ray, rec, volume_aabb, volume_size, volume_grid, texture_3d, alpha_clip):
    """
    Ray march through a voxel volume using traversal order optimization.
    
    Args:
        ray: dict with 'origin' (vec3) and 'direction' (vec3)
        rec: dict with 'hit' (bool), 'color' (vec3), 'position' (vec3), 'normal' (vec3), 't' (float)
        volume_aabb: box defining the volume bounds
        volume_size: float, physical size of the volume (assumed uniform)
        volume_grid: vec3, dimensions of the voxel grid (x, y, z)
        texture_3d: 3D texture sampler
        alpha_clip: float, alpha threshold for hit detection
        
    Returns:
        rec: updated record with hit information
    """
    rec['hit'] = False
    
    # Step 1: Determine step directions
    step_x = 1 if ray['direction']['x'] > 0.0 else -1
    step_y = 1 if ray['direction']['y'] > 0.0 else -1
    step_z = 1 if ray['direction']['z'] > 0.0 else -1
    
    # Step 2: Precompute tDelta (time to travel one voxel unit)
    voxel_size_x = volume_size / volume_grid['x']
    voxel_size_y = volume_size / volume_grid['y']
    voxel_size_z = volume_size / volume_grid['z']
    
    # Handle division by zero for ray direction components [G]
    dir_x = ray['direction']['x'] if ray['direction']['x'] != 0.0 else 1e-6
    dir_y = ray['direction']['y'] if ray['direction']['y'] != 0.0 else 1e-6
    dir_z = ray['direction']['z'] if ray['direction']['z'] != 0.0 else 1e-6
    
    t_delta_x = abs(voxel_size_x / dir_x)
    t_delta_y = abs(voxel_size_y / dir_y)
    t_delta_z = abs(voxel_size_z / dir_z)
    
    # Step 3: Calculate initial position and indices
    pos_x = ray['origin']['x'] + ray['direction']['x'] * rec['t']
    pos_y = ray['origin']['y'] + ray['direction']['y'] * rec['t']
    pos_z = ray['origin']['z'] + ray['direction']['z'] * rec['t']
    
    X = int(floor(pos_x / volume_size * volume_grid['x']))
    Y = int(floor(pos_y / volume_size * volume_grid['y']))
    Z = int(floor(pos_z / volume_size * volume_grid['z']))
    
    # Boundary correction for indices equal to grid dimension
    if X == volume_grid['x']: X -= 1
    if Y == volume_grid['y']: Y -= 1
    if Z == volume_grid['z']: Z -= 1
    
    # Step 4: Calculate initial tMax
    # Determine next voxel index
    next_x_offset = 1 if ray['direction']['x'] > 0.0 else 0
    next_y_offset = 1 if ray['direction']['y'] > 0.0 else 0
    next_z_offset = 1 if ray['direction']['z'] > 0.0 else 0
    
    # Helper to get world position from voxel index
    def get_pos_by_index(ix, iy, iz):
        return vec3(
            (ix + 0.5) * (volume_size / volume_grid['x']),
            (iy + 0.5) * (volume_size / volume_grid['y']),
            (iz + 0.5) * (volume_size / volume_grid['z'])
        )
    
    next_pos = get_pos_by_index(X + next_x_offset, Y + next_y_offset, Z + next_z_offset)
    
    t_max_x = (next_pos['x'] - pos_x) / dir_x
    t_max_y = (next_pos['y'] - pos_y) / dir_y
    t_max_z = (next_pos['z'] - pos_z) / dir_z
    
    potential_time = 0.0
    potential_normal = rec['normal']
    
    # Step 5: Check for immediate hit
    sample = texture_3d.sample(X, Y, Z)
    if sample['a'] > alpha_clip:
        rec['hit'] = True
        rec['color'] = sample['rgb']
        rec['position'] = ray['origin'] + ray['direction'] * rec['t']
        rec['normal'] = potential_normal
        return rec
    
    # Step 6: Main marching loop
    while not rec['hit']:
        # Compare tMax values to determine traversal order
        if t_max_x < t_max_y:
            if t_max_x < t_max_z:
                # X axis is smallest
                X += step_x
                potential_time = t_max_x
                if X >= volume_grid['x'] or X < 0:
                    break
                t_max_x += t_delta_x
                potential_normal = vec3(-float(step_x), 0, 0)
            else:
                # Z axis is smallest (since t_max_x > t_max_z and t_max_z < t_max_y)
                Z += step_z
                potential_time = t_max_z
                if Z < 0 or Z >= volume_grid['z']:
                    break
                t_max_z += t_delta_z
                potential_normal = vec3(0, 0, -float(step_z))
        else:
            if t_max_y < t_max_z:
                # Y axis is smallest
                Y += step_y
                potential_time = t_max_y
                if Y >= volume_grid['y'] or Y < 0:
                    break
                t_max_y += t_delta_y
                potential_normal = vec3(0, -float(step_y), 0)
            else:
                # Z axis is smallest (since t_max_y > t_max_z)
                Z += step_z
                potential_time = t_max_z
                if Z < 0 or Z >= volume_grid['z']:
                    break
                t_max_z += t_delta_z
                potential_normal = vec3(0, 0, -float(step_z))
        
        # Sample new voxel
        sample = texture_3d.sample(X, Y, Z)
        if sample['a'] > alpha_clip:
            rec['hit'] = True
            rec['color'] = sample['rgb']
            rec['position'] = ray['origin'] + ray['direction'] * (rec['t'] + potential_time)
            rec['normal'] = potential_normal
            break
            
    return rec
```

### Edge Cases and Pitfalls
*   **Division by Zero**: If a ray direction component is zero, computing `tDelta` and `tMax` involves division by zero, resulting in infinity or NaN [S2, unofficial]. Implementers must handle this, e.g., by clamping direction components to a small epsilon or treating the axis as having infinite `tDelta` [G].
*   **Boundary Conditions**: If the calculated integer coordinate equals the grid dimension, it must be decremented by 1 to stay within valid array bounds $[0, \text{grid\_dim}-1]$ [S2, unofficial].
*   **Out-of-Bounds Coordinates**: Handling of out-of-bounds coordinates varies by platform. macOS may use `sampler border_color::transparent_black`, while iOS/Metal may require explicit `isInsideCube` checks returning transparent black [S1, unofficial].
*   **Precision**: Floating-point precision issues may arise when computing `tMax` and `tDelta` for very large or very small volumes. Using double precision for intermediate calculations may be necessary for high-accuracy applications [G].

## Operating characteristics
*   **Time Complexity**: $O(N)$ where $N$ is the number of voxels traversed along the ray. The number of steps is proportional to the length of the ray within the volume divided by the voxel size.
*   **Memory Complexity**: $O(1)$ per ray, excluding the storage for the 3D texture.
*   **Performance**: The method is highly efficient due to the minimization of floating-point operations (33 float points calculation claim) [S2, unofficial]. It avoids branching overhead associated with adaptive step sizes.
*   **Strengths**: Simple implementation, low memory footprint, predictable performance.
*   **Limitations**: Fixed resolution may lead to aliasing or blockiness. Not suitable for highly anisotropic or non-aligned voxel grids without modification.
*   **When to Use**: Real-time rendering of voxel-based data where performance is critical and visual fidelity is acceptable with fixed resolution.
*   **When Not to Use**: When high-frequency details require adaptive sampling or when the voxel grid is not axis-aligned.

## Background
The method was described by Jiayu He in "A Voxel PathTracing Engine" [S2, unofficial], highlighting its efficiency in minimizing floating-point operations. It is also referenced in the context of Metal-based voxel cone tracing by kakashidinho [S1, unofficial]. The technique is a variant of ray marching optimized for voxel grids, leveraging the regular structure of the data to simplify traversal logic.
