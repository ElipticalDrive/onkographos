# GPU CSG Ray Tracing with Uniform Grid Index

Also called: GPU CSG Renderer Features, GPU CSG tracer, GpuPlot

## Overview
A GPU-based ray tracer for Constructive Solid Geometry (CSG) that accelerates traversal by replacing unindexed full-scans of the root universe with a uniform grid index over the root universe's cells [S1, unofficial]. It renders Solid, Wireframe, and Slice views using a WGSL shader that is an $f32$ transcription of the CPU plotter's logic [S1, unofficial]. It sets itself apart from the unindexed GPU approach by eliminating the cost of rays outside the model stepping through infinite surface extensions, and from the CPU path by leveraging GPU parallelism while correcting specific parity bugs in complement handling [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A CSG scene defined by surfaces, regions (RPN), universes, lattices, and translations [S1, unofficial].
*   **Output:** Rendered images (Solid, Wireframe, Slice) or ray-tracing data [S1, unofficial].

**Data Structures:**
1.  **Flat Geometry Buffer (`outram_blender::csg::gpu::flat`):** A single `u32` buffer containing surfaces, RPN regions, universes, rect/hex lattices (with maps and outer definitions), translations, static crossing hints (OpenMC-style neighbor lists), and the universe graph (used to skip subtrees with no drawn material) [S1, unofficial].
2.  **Uniform Grid Index:** A voxel grid over the root universe's bounding box where each voxel contains a list of cells that intersect it, and each cell's region expression is constant-folded to the specific surfaces passing through that voxel [S1, unofficial].
3.  **GpuPlot Struct:** Contains variants `Solid`, `Wireframe`, `Slice`, matching the CPU plotter's structs [S1, unofficial].

**Parameters:**
*   **Grid Resolution:** Varies by scene; example HTR-10 root universe uses a $30 \times 30 \times 47$ voxel grid [S1, unofficial].
*   **Indexing Budget:** Index universes with token counts above 512, within a 16 MB memory budget [S1, unofficial].
*   **Buffer Limit:** The geometry buffer must not exceed the device's 128 MiB binding limit [S1, unofficial].

**Algorithm Steps:**

1.  **Build the Uniform Grid:** Create a voxel grid over the root universe's bounding box. For each voxel, identify the cells that intersect it. Constant-fold each cell's region expression to determine the specific surfaces that pass through that voxel [S1, unofficial].
2.  **Close the Grid:** Ensure no root cell lies outside the grid bounds. For unbounded OpenMC boxes (e.g., absorber-sphere channels, core cell conus), perform vertex enumeration over plane half-spaces and apply a bound on the cone radius to create tight bounding boxes [S1, unofficial].
3.  **Ray Traversal:** If a ray is outside the model, it jumps directly to the grid index. Inside the grid, the ray steps through voxels. Voxel faces act as silent steps (no surface intersection test required). Upon entering a voxel, test the ray against the pre-computed surfaces for the candidate cells. Sign complex regions from the surface normal to correct a CPU parity bug where complements were not handled via De Morgan's laws. After a silent voxel step, reset the token to ensure the ray can exit a bore/cell correctly [S1, unofficial].
4.  **Rendering:** Phong Solid View renders solid geometry with lighting. Slice View renders section planes with cut faces, supporting per-material visibility and x-ray attenuation with outlines [S1, unofficial].

**Pseudocode:**

```python
import math

# Constants and helpers defined for self-containment
INFINITY = float('inf')
INITIAL_TOKEN = 0
BACKGROUND_COLOR = (0.0, 0.0, 0.0)

def is_inside_root_bbox(origin, direction, bbox_min, bbox_max):
    """Standard ray-AABB intersection check."""
    tmin = (bbox_min[0] - origin[0]) / direction[0] if direction[0] != 0 else -INFINITY
    tmax = (bbox_max[0] - origin[0]) / direction[0] if direction[0] != 0 else INFINITY
    if tmin > tmax: tmin, tmax = tmax, tmin
    tmin = max(tmin, (bbox_min[1] - origin[1]) / direction[1] if direction[1] != 0 else -INFINITY)
    tmax = min(tmax, (bbox_max[1] - origin[1]) / direction[1] if direction[1] != 0 else INFINITY)
    if tmin > tmax: return False
    tmin = max(tmin, (bbox_min[2] - origin[2]) / direction[2] if direction[2] != 0 else -INFINITY)
    tmax = min(tmax, (bbox_max[2] - origin[2]) / direction[2] if direction[2] != 0 else INFINITY)
    return tmin <= tmax

def trace_ray(origin, direction, grid, geometry_buffer):
    # 1. Check if ray is outside the root universe bounding box
    if not is_inside_root_bbox(origin, direction, grid.bbox_min, grid.bbox_max):
        voxel = grid.find_voxel(origin, direction)
        if voxel is None:
            return BACKGROUND_COLOR

        current_voxel = voxel
        token = INITIAL_TOKEN

        while current_voxel is not None:
            # Silent step: moving between voxel faces requires no intersection test
            candidates = current_voxel.candidate_cells
            surfaces = current_voxel.precomputed_surfaces

            # 2. Intersection Test
            hit_surface, hit_dist, hit_normal = find_nearest_intersection(
                origin, direction, surfaces
            )

            if hit_surface is not None:
                # 3. Complex Region Handling
                region_token = hit_surface.get_region_token(hit_normal)

                # Update ray origin to hit point
                origin = origin + direction * hit_dist
                token = region_token

                # Move to next voxel
                current_voxel = grid.get_next_voxel(origin, direction)
            else:
                # Post-Step Correction: Reset token after silent voxel step
                token = INITIAL_TOKEN
                current_voxel = grid.get_next_voxel(origin, direction)

        return BACKGROUND_COLOR
    else:
        # Ray starts inside or intersects root bbox
        voxel = grid.find_voxel(origin, direction)
        if voxel is None:
            return BACKGROUND_COLOR
        current_voxel = voxel
        token = INITIAL_TOKEN
        while current_voxel is not None:
            candidates = current_voxel.candidate_cells
            surfaces = current_voxel.precomputed_surfaces
            hit_surface, hit_dist, hit_normal = find_nearest_intersection(
                origin, direction, surfaces
            )
            if hit_surface is not None:
                region_token = hit_surface.get_region_token(hit_normal)
                origin = origin + direction * hit_dist
                token = region_token
                current_voxel = grid.get_next_voxel(origin, direction)
            else:
                token = INITIAL_TOKEN
                current_voxel = grid.get_next_voxel(origin, direction)
        return BACKGROUND_COLOR

def find_nearest_intersection(origin, direction, surfaces):
    min_dist = INFINITY
    best_surface = None
    best_normal = None

    for surface in surfaces:
        dist, normal = surface.intersect(origin, direction)
        if dist > 0 and dist < min_dist:
            min_dist = dist
            best_surface = surface
            best_normal = normal

    return best_surface, min_dist, best_normal
```

**Edge Cases and Pitfalls:**
*   **Complement Handling:** The CPU port did not remove complements by De Morgan's laws or sign complex regions from the surface normal. This caused rays entering a reflector core (written as `box & ~core`) to be re-located incorrectly. The fix signs complex regions from the normal [S1, unofficial].
*   **Silent Step Token Retention:** After stepping through a voxel face (silent step), the tracer retained the token of the last-crossed surface. This prevented rays inside a bore from exiting. The fix resets the token [S1, unofficial].
*   **ClipPlane Shadow Bug:** In the CPU SolidRayTracePlot with a ClipPlane, the shadow ray was blocked by the cut-away half. The fix ensures the ray is lit once it passes into that half. This changes the shade of 2.5% of pixels but no pixel changes material [S1, unofficial].
*   **Buffer Limit:** If the geometry buffer exceeds the device's 128 MiB binding limit, `set_geometry` returns an error (CPU fallback) instead of panicking [S1, unofficial].
*   **Tori:** The system refuses tori [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The cost per crossing is approximately 90 ns [S1, unofficial]. The evidence explicitly refutes that reflector cells holding up to 124 region tokens cause this cost; instead, unindexed rays performed ~10 full scans of the 128-cell root universe because rays outside the model stepped through infinite extensions (planes, cones) crossing all 1,675 tokens [S1, unofficial].
*   **Memory Complexity:** Indexing is limited by a 16 MB budget for universes with token counts above 512 [S1, unofficial]. The total geometry buffer is limited to 128 MiB [S1, unofficial].
*   **Measured Performance:**
    *   Şeker bed, half-section (900x560): GPU indexed time 24-60 ms (best 17 ms). GPU unindexed time 0.36-0.39 s [S1, unofficial].
    *   Şeker reflector, half-section: GPU indexed time 19-21 ms. GPU unindexed time 0.36 s [S1, unofficial].
    *   X-y slice, mid-bed: GPU indexed time 2 ms. GPU unindexed time 17 ms [S1, unofficial].
    *   DEM bed, half-section: GPU indexed time 33 ms. GPU unindexed time 0.39 s [S1, unofficial].
    *   DEM reflector, half-section: GPU indexed time 20 ms. GPU unindexed time 0.35 s [S1, unofficial].
*   **Scaling:** Indexing reduces frame time significantly compared to unindexed GPU rendering (e.g., from ~0.36s to 24-60ms for the Şeker bed half-section) [S1, unofficial]. Unindexed rays performed ~10 full scans of the 128-cell root universe because rays outside the model stepped through infinite extensions (planes, cones) crossing all 1,675 tokens [S1, unofficial].
*   **Strengths:** Significant speedup over unindexed GPU and CPU methods for large scenes. Handles complex CSG operations.
*   **Limitations:** Grid indexing adds complexity and memory overhead. Unbounded cells require special handling (vertex enumeration). Buffer size limits may force CPU fallback. Tori are refused.
*   **When to use:** When rendering large CSG scenes on a GPU with sufficient memory and compute resources, and when the performance gain from indexing outweighs the setup cost.
*   **When not to use:** When the scene is small enough that unindexed traversal is fast enough, or when memory constraints prevent building the index.

## Background
The method was developed as part of the `outram-blender` project, specifically in the `outram_blender::csg::gpu` module, to provide GPU-accelerated rendering for 3D and 2D views in a workbench application [S1, unofficial]. It was implemented as a WGSL shader, transcribed from the CPU plotter's logic, to support Solid, Wireframe, and Slice views [S1, unofficial]. The development addressed specific performance bottlenecks in the unindexed GPU approach, where rays outside the model caused excessive surface crossings [S1, unofficial]. The implementation includes corrections for parity bugs in complement handling and token retention issues [S1, unofficial]. It was verified against the CPU plotter using Vulkan on an NVIDIA RTX A5000 [S1, unofficial].
