# Digital Differential Analyzer (DDA) Traversal

Also called: 3D DDA Ray Traversal, Amanatides & Woo, DDA Algorithm, Digital Differential Analyzer

## Overview
Digital Differential Analyzer (DDA) Traversal is a grid traversal algorithm that determines the sequence of axis-aligned grid cells (voxels or tiles) intersected by a ray [S1][S4, unofficial][S7, unofficial]. It solves the problem of efficiently locating geometry in a dense grid without performing expensive per-voxel intersection tests or suffering from the gaps and redundancies of naive fixed-step ray marching [S31, S41, unofficial]. Unlike [Siddon's Algorithm](2590-siddon-s-algorithm.md), which computes exact parametric intersection lengths for integration, DDA steps discretely through grid cells using incremental comparisons, making it ideal for real-time ray casting and shadow calculation [S1, S25, unofficial]. It sets itself apart from [3D Bresenham Voxel Traversal](3951-3d-bresenham-voxel-tracing.md) by using floating-point $t$-values for boundary distances rather than integer error accumulation, allowing it to handle arbitrary ray directions and non-unit grid spacing more naturally [S3, S31, unofficial].

## How it works
The algorithm advances analytically from one cell boundary to the next, avoiding fixed-distance sampling steps [S5, unofficial][S7, unofficial]. The core mechanism determines the next cell by comparing the distances to the upcoming boundaries on the x, y, and z axes, selecting the minimum distance to advance [S2, unofficial][S3, unofficial][S5, unofficial].

### Inputs and Outputs
**Inputs:**
*   Ray origin $\mathbf{o} = (o_x, o_y, o_z)$ in world or local space [S2, unofficial].
*   Ray direction $\mathbf{d} = (d_x, d_y, d_z)$ [S1].
*   Grid parameters: voxel size $v$ (or dimensions $N_x, N_y, N_z$ and bounds) [S2, unofficial][S5, unofficial].
*   Optional: Maximum traversal distance or step limit [S2, unofficial].

**Outputs:**
*   A sequence of voxel indices $(i, j, k)$ visited by the ray [S1].
*   Optional: Entry/exit distances $t_{entry}, t_{exit}$ for each voxel [S1][S5, unofficial].
*   Optional: Surface normal of the entered face [S5, unofficial].

### Data Structures
The state is maintained using three vectors of size 3 (one per axis) and a current index vector:
1.  **`step`**: Integer vector $\{-1, 0, 1\}$ indicating the direction of index increment per axis [S1].
2.  **`t_delta`**: Float vector representing the distance along the ray to traverse one voxel width [S1].
3.  **`t_max`**: Float vector representing the distance from the ray origin to the next boundary crossed in each axis [S1].
4.  **`current_voxel`**: Integer vector $(i, j, k)$ representing the current cell index [S1].

### Initialization
1.  **Validate Direction**: If $\mathbf{d}$ is zero or non-finite, return error [S2, unofficial].
2.  **Determine Start Voxel**: Compute the initial voxel index containing the ray origin. For a uniform grid with voxel size $v$, $i = \lfloor o_x / v \rfloor$. If the origin lies exactly on a boundary $k \cdot v$, it belongs to cell $k$ (using floor) [S2, unofficial]. Clamp indices to grid bounds [G].
3.  **Compute Step Direction**:
    $$
    \text{step}_i = \begin{cases} 
    +1 & \text{if } d_i > 0 \\
    -1 & \text{if } d_i < 0 \\
    0 & \text{if } d_i = 0 
    \end{cases}
    $$
    If $d_i = 0$, the ray never crosses a boundary in that dimension [S5, unofficial].
4.  **Compute Delta ($t_{\Delta}$)**: The distance to traverse one voxel.
    $$
    t_{\Delta, i} = \frac{v_i}{|d_i|} \quad \text{if } d_i \neq 0
    $$
    If $d_i = 0$, set $t_{\Delta, i} = 0$ [S1].
5.  **Compute Initial Max ($t_{max}$)**: The distance to the first boundary in each axis.
    $$
    t_{max, i} = \frac{(\text{current\_voxel}_i + \text{step}_i) \cdot v_i - o_i}{d_i}
    $$
    If $d_i = 0$, set $t_{max, i} = \infty$ [S1].
    *Note*: If the ray starts inside the grid, the initial boundary is the next one in the direction of travel [S2, unofficial][S3, unofficial][S5, unofficial].

### Traversal Loop
Iterate while the ray remains within grid bounds and has not exceeded max distance/steps [S5, unofficial]:

1.  **Identify Axis**: Find the axis $k$ with the minimum boundary distance: $t_{min} = \min(t_{max, x}, t_{max, y}, t_{max, z})$ [S2, unofficial][S3, unofficial][S5, unofficial].
2.  **Record Cell**: Yield or process `current_voxel` with interval $[t_{entry}, t_{min}]$ [S1][S5, unofficial].
3.  **Advance Index**: Increment the index in the selected axis: $\text{current\_voxel}_k \leftarrow \text{current\_voxel}_k + \text{step}_k$ [S2, unofficial][S3, unofficial][S5, unofficial].
4.  **Update Boundary**: Update the boundary distance for axis $k$: $t_{max, k} \leftarrow t_{max, k} + t_{\Delta, k}$ [S2, unofficial][S3, unofficial][S5, unofficial].
5.  **Update Entry**: Set $t_{entry} \leftarrow t_{min}$ [S5, unofficial].

### Edge Cases and Pitfalls
*   **Zero Direction Components**: If $d_i = 0$, the axis never steps. $t_{max, i}$ is set to infinity, and $t_{\Delta, i}$ is 0 [S2, unofficial][S5, unofficial].
*   **Coincident Crossings**: If the ray hits an edge or corner (multiple $t_{max}$ values are equal), a fixed priority order (e.g., X, then Y, then Z) must be used to determine which axis steps first to ensure deterministic traversal [S2, unofficial].
*   **Precision Errors**: Successive summation of $t_{max}$ can lead to floating-point error accumulation over long traversals [S5, unofficial]. Some implementations recalculate $t_{max}$ analytically or use correction terms if $t_{max}$ falls behind the current ray parameter [S3, unofficial].
*   **Over-traversal**: Traversal should stop at a distance of 1 voxel or a specified threshold to prevent over-traversal beyond a target point (e.g., LiDAR hit) [S1].
*   **Empty Space**: Cells outside a bounded volume are treated as traversable empty space, allowing the ray to cross into the volume [S2, unofficial].

### Pseudocode
```python
def dda_traversal(ray_origin, ray_direction, voxel_size, grid_bounds):
    """
    Traverses a uniform grid along a ray using the DDA algorithm.
    
    Args:
        ray_origin: tuple (ox, oy, oz)
        ray_direction: tuple (dx, dy, dz)
        voxel_size: float or tuple (vx, vy, vz)
        grid_bounds: object with min and max voxel indices
        
    Yields:
        (voxel_index, t_entry, t_exit)
    """
    # 1. Initialize current voxel index
    # Floor division for index calculation
    current_voxel = [
        int(ray_origin[0] // voxel_size[0]),
        int(ray_origin[1] // voxel_size[1]),
        int(ray_origin[2] // voxel_size[2])
    ]
    
    # Clamp to grid bounds [G]
    current_voxel = [
        max(grid_bounds.min[0], min(grid_bounds.max[0], current_voxel[0])),
        max(grid_bounds.min[1], min(grid_bounds.max[1], current_voxel[1])),
        max(grid_bounds.min[2], min(grid_bounds.max[2], current_voxel[2]))
    ]
    
    # 2. Step direction per axis
    step = [0, 0, 0]
    for i in range(3):
        if ray_direction[i] > 0:
            step[i] = 1
        elif ray_direction[i] < 0:
            step[i] = -1
        else:
            step[i] = 0
            
    # 3. Distance to next boundary (t_max)
    t_max = [0.0, 0.0, 0.0]
    t_delta = [0.0, 0.0, 0.0]
    
    for i in range(3):
        if ray_direction[i] == 0:
            t_max[i] = float('inf')
            t_delta[i] = 0.0
        else:
            # Distance to the next boundary in the direction of travel
            # Boundary is at (current_voxel + step) * voxel_size
            next_boundary = (current_voxel[i] + step[i]) * voxel_size[i]
            t_max[i] = (next_boundary - ray_origin[i]) / ray_direction[i]
            # Distance to traverse one voxel
            t_delta[i] = voxel_size[i] / abs(ray_direction[i])
            
    t_entry = 0.0
    
    # 4. Traversal Loop
    while (current_voxel[0] >= grid_bounds.min[0] and current_voxel[0] <= grid_bounds.max[0] and
           current_voxel[1] >= grid_bounds.min[1] and current_voxel[1] <= grid_bounds.max[1] and
           current_voxel[2] >= grid_bounds.min[2] and current_voxel[2] <= grid_bounds.max[2]):
        
        # Find minimum boundary distance
        # In case of ties, priority is X, then Y, then Z [S2, unofficial]
        min_idx = 0
        min_val = t_max[0]
        if t_max[1] < min_val:
            min_val = t_max[1]
            min_idx = 1
        if t_max[2] < min_val:
            min_idx = 2
            
        t_exit = t_max[min_idx]
        
        # Record cell and interval
        yield current_voxel, t_entry, t_exit
        
        # Advance index and update boundary
        current_voxel[min_idx] += step[min_idx]
        t_max[min_idx] += t_delta[min_idx]
        t_entry = t_exit
```

## Subtopics

### [DDA](2323-dda.md)
The standard Digital Differential Analyzer traversal for uniform grids, using floating-point $t$-values for boundary distances.

### [Wide DDA Cell Traversal](5122-wide-dda-cell-traversal.md)
Traverses a fixed 4x4x4 grid of "wide cells" within an AABB, generating bounding boxes and t-intervals to optimize octree traversal.

### [Two-Step Discrete Ray Tracing](5204-two-step-discrete-ray-tracing.md)
Replaces deep octree traversal with a two-level hierarchy (coarse then fine) to skip empty space in huge voxel spaces.

### [Voxel Occupancy Mask](5242-voxel-occupancy-mask.md)
Uses a 64-bit bitmask per brick to skip empty voxels inside an occupied brick without additional texture lookups.

### [Zero-Crossing DDA Traversal](5474-zero-crossing-dda-traversal.md)
Combines hierarchical traversal with narrow-band detection, halting at the first sign change in a scalar field.

### [Nearest Neighbor Ray Traversal](8321-nearest-neighbor-ray-traversal.md)
Samples data at voxel centers upon entry, prioritizing speed over sampling uniformity.

### [Hardware/Implementation Optimization](10943-hardware-implementation-optimization.md)
Adapts DDA for GPUs using SIMD parallelism, shared memory caching, and register management.

### Exact Grid Traversal
An algorithm that captures all discrete grid points the line passes through, implemented as a naive reference for comparison [S4, unofficial].

### Surface Normal Calculation via Branchless Comparison
Determines the surface normal of a voxel hit by comparing accumulated distances to x and y planes using branchless programming: `compare = total_t.x <= total_t.y ? vec2(1.0,0.0) : vec2(0.0,1.0)` [S5, unofficial].

### SplineSplat
Extends DDA to handle overlapping, compactly supported B-spline basis functions by using a neural network to compute basis contributions, avoiding closed-form analytical expressions [S6].

### Direct Volume Rendering on Deformed Grids
Identifies the first cell hit via an item buffer (Z-buffer encoding of indices) and traverses subsequent cells by finding the nearest intersection among the five remaining walls of the current cell, explicitly checking for re-entry after exiting [S7, unofficial].

## Operating characteristics
*   **Time Complexity**: $O(N)$ where $N$ is the number of voxels traversed. The cost per voxel is constant (a few comparisons and additions) [S2, unofficial][S3, unofficial][S5, unofficial].
*   **Memory Complexity**: $O(1)$ auxiliary space per ray, as only the current state vectors are stored [S1].
*   **Performance**: Highly efficient for uniform grids and real-time applications. It avoids the overhead of tree traversal structures [S1, S25, unofficial].
*   **Strengths**: Simple implementation, low memory footprint, deterministic, and fast for dense or uniform data [S1, S25, unofficial].
*   **Limitations**: Visits every voxel along the ray path, which is inefficient for sparse data or large empty spaces compared to hierarchical methods [S1]. Precision errors can accumulate over very long traversals [S5, unofficial].
*   **When to use**: Real-time ray casting, shadow mapping, uniform grids, or when hardware simplicity is prioritized [S1, S25, unofficial].
*   **When not to use**: Sparse volumes where empty space skipping is critical (use [Hierarchical Grid Traversal](2560-hierarchical-grid-traversal.md) or [Octree and Tree Traversal](4134-octree-and-tree-traversal.md)) [S1].

## Background
The 3D DDA algorithm was introduced by Amanatides and Woo in their seminal paper "A Fast Voxel Traversal Algorithm for Ray Tracing" (1987/1988) [S2, unofficial][S5, unofficial]. It has become a standard technique in computer graphics for ray-grid traversal, widely used in ray casting, shadow calculation, and volume rendering [S1, S25, unofficial]. Variants and optimizations continue to be developed for specific hardware and data structures, such as GPU implementations [S1] and hierarchical extensions [S1].
