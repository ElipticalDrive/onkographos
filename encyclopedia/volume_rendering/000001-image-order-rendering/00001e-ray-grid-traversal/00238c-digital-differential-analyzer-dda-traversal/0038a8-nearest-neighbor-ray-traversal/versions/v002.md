# Nearest Neighbor Ray Traversal

Also called: Scan Conversion, Nearest Neighbor Interpolation

## Overview
Nearest Neighbor Ray Traversal is a volume rendering method that samples data values at the center of each voxel immediately upon entry, requiring zero interpolation [S2, unofficial]. It prioritizes maximum speed over sampling uniformity, making it the fastest but least accurate traversal approach [S2, unofficial].

## How it works
**Inputs:** A ray defined by origin $P$ and direction $g$, a step size $d$, and a voxel grid where data values are stored at cell centers [S2, unofficial].
**Outputs:** A sequence of sampled intensity values along the ray path [G].

**Data Structures:**
The voxel grid is pre-shifted by $0.5$ units in all dimensions so that data values reside at the geometric centers of the grid cells rather than the corners [S2, unofficial]. This allows direct indexing of the center value for any visited voxel.

**Steps:**
1. Calculate the sample point $Q = P + k \times V$, where $V = d \times g$ [S1, unofficial].
2. Round $Q$ to the nearest integer voxel coordinates [S1, unofficial].
3. Retrieve the data value stored at the center of the current voxel [S2, unofficial].
4. Check if the voxel is on the boundary by comparing its value against a threshold [S1, unofficial].
5. If the voxel is on the boundary, perform shading/compositing [S1, unofficial].
6. Increment $k$ and repeat from Step 1 until the ray exits the volume [G].

**Parameters:**
*   **Interpolation Count:** 0 interpolations are required in both 2D and 3D [S2, unofficial].
*   **Grid Shift:** The grid must be shifted by half a unit ($0.5$) to align data with voxel centers [S2, unofficial].

**Pitfalls:**
*   **Jagged Artifacts:** The method produces jagged sampling artifacts because the distance between effective data samples is not uniform [S2, unofficial].
*   **Non-Uniform Density:** Large gaps in sampling density occur as the ray traverses cells, leading to lower accuracy compared to regular sampling [S2, unofficial].

```python
def nearest_neighbor_traversal(ray_origin, ray_direction, step_size, grid, threshold=0.0):
    """
    Performs Nearest Neighbor Ray Traversal on a pre-shifted grid.
    
    Args:
        ray_origin: (x, y, z) tuple representing P.
        ray_direction: (dx, dy, dz) tuple representing g (normalized).
        step_size: float d, the distance between consecutive samples.
        grid: 3D array where data is stored at voxel centers.
        threshold: float, value used to determine boundary voxels.
    
    Returns:
        List of sampled values along the ray.
    """
    samples = []
    k = 0
    # Step vector V = d * g
    V = (step_size * ray_direction[0], 
         step_size * ray_direction[1], 
         step_size * ray_direction[2])
    
    while True:
        # Step 1: Calculate sample point Q
        q_x = ray_origin[0] + k * V[0]
        q_y = ray_origin[1] + k * V[1]
        q_z = ray_origin[2] + k * V[2]
        
        # Step 2: Round Q to nearest integer voxel coordinates
        ix = int(round(q_x))
        iy = int(round(q_y))
        iz = int(round(q_z))
        
        # Boundary check for grid bounds
        if not (0 <= ix < grid.shape[0] and 
                0 <= iy < grid.shape[1] and 
                0 <= iz < grid.shape[2]):
            break
            
        # Step 3: Retrieve value at center of current voxel
        value = grid[ix, iy, iz]
        
        # Step 4 & 5: Check boundary and perform shading
        if value > threshold:
            value = apply_shading(value)
            
        samples.append(value)
        
        # Step 6: Increment k and repeat
        k += 1
        
    return samples

def apply_shading(value):
    """Applies a basic shading/compositing operation to boundary voxels."""

    return value
```

## Subtopics

### Regular Sampling
Samples at uniform intervals along the ray, requiring interpolation. It is more accurate but slower than Nearest Neighbor. Choose it when visual fidelity and uniform sampling density are prioritized over speed. [Regular Sampling](5204-two-step-discrete-ray-tracing.md)

### Blocked Intersection Approach
Samples at voxel boundaries or edges. It is a compromise between speed and accuracy, requiring fewer interpolations than regular sampling. Choose it when a balance between traversal speed and sampling consistency is needed. [Blocked Intersection Approach](5204-two-step-discrete-ray-tracing.md)

## Operating characteristics
*   **Speed:** Fastest among ray traversal methods due to zero interpolation cost [S2, unofficial].
*   **Accuracy:** Least accurate due to jagged sampling and non-uniform distances between effective data samples [S2, unofficial].
*   **Memory:** Requires a pre-shifted grid structure to store data at centers [S2, unofficial].
*   **Use Case:** Suitable for real-time applications where speed is critical and visual fidelity regarding sampling uniformity is secondary [S2, unofficial].

## Background
The method is described in the context of Direct Volume Rendering (DVR) ray-casting pipelines, where data is typically defined at voxel corners and interpolated [S1, unofficial]. The specific "Nearest Neighbor" traversal approach, also referred to as "Scan Conversion," is highlighted in educational materials comparing traversal strategies [S2, unofficial]. It is often contrasted with Tuy's ray-casting pipeline which uses interpolation [S1, unofficial].
