# Ray Casting via Grid Line Intersection

Also called: DDA Raycasting, DDA Raycasting with Fish-eye Correction, Horizontal/Vertical Hit Comparison Raycaster, Vertical/Horizontal Collision Casting, Wolfy Style DDA Raycasting

## Overview
This method is a 2D grid-based raycasting algorithm that traces a ray from a player position through a grid of blocks to find the first wall intersection [S1, unofficial]. It distinguishes itself by explicitly calculating vertical and horizontal grid crossings separately, selecting the closest hit between the two traces, and applying a fish-eye correction to the distance for rendering [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** 2D grid map (`level`), player position (`player.x`, `player.y`), ray angle (`angle`), grid cell size (`BLOCK_SIZE`), grid dimensions (`MAP_SIZE_X`, `MAP_SIZE_Y`), small epsilon (`EPSILON`), and scan mode (`scanmode`) [S1, unofficial].
- **Output:** Hit object containing intersection coordinates (`ray_x`, `ray_y`), direct distance (`distance_direct`), perpendicular distance (`distance_perpendicular`), step count, and texture coordinate (`texture_x`) [S1, unofficial].

**Data Structures:**
- `level`: A 2D array where `level[grid_y][grid_x]` stores wall type or color; a value greater than 0 indicates a wall [S1, unofficial].
- `shared.wall_colors_textures_list`: A dictionary mapping texture IDs to pixel arrays for rendering [S1, unofficial].

**Parameters:**
- `BLOCK_SIZE`: The size of each grid cell in world units, used to convert coordinates to grid indices and calculate deltas [S1, unofficial].
- `MAP_SIZE_X`, `MAP_SIZE_Y`: The dimensions of the grid in cells, used for boundary checks and loop termination [S1, unofficial].
- `EPSILON`: A small value added to `delta_yi` when `y_sign` is -1 to correctly select the grid index backwards [S1, unofficial].
- `distance_h`: Initial high value (1000000) for horizontal distance to prevent premature selection if no hit occurs [S1, unofficial].

**Steps:**
1. Initialize horizontal ray parameters: Calculate `delta_yi` as `BLOCK_SIZE - offset_py` if `y_sign` is 1, else `-offset_py`. If `delta_yi` is 0, set `distance_h` to 1000000. Calculate `delta_xi = delta_yi * (1 / tan(angle))` [S1, unofficial].
2. Adjust `delta_yi` for backward ray direction: If `y_sign` is -1, add `-EPSILON` to `delta_yi` to ensure correct grid index selection backwards [S1, unofficial].
3. Compute vertical ray direction: `right = abs(floor((angle - π / 2) / π) % 2)` [S1, unofficial].
4. Compute first vertical grid line intersection X: `firstX = right ? floor(player.x / 1) * 1 + 1 : floor(player.x / 1) * 1` [S1, unofficial].
5. Compute corresponding Y: `firstY = player.y + (firstX - player.x) * tan(angle)` [S1, unofficial].
6. Initialize ray position: `ray_x = player.x + delta_xi`, `ray_y = player.y + delta_yi` [S1, unofficial].
7. Calculate external deltas: `delta_ye = BLOCK_SIZE * y_sign`, `delta_xe = abs(1 / tan(angle) * BLOCK_SIZE) * x_sign` [S1, unofficial].
8. Set step vectors: `xA = right ? 1 : -1`, `yA = xA * tan(angle)` [S1, unofficial].
9. Loop for horizontal hit detection: Increment `steps_h`. If `steps_h > MAP_SIZE_X * 2`, print error and quit. Clamp `ray_x` to `[0, MAP_SIZE_X * BLOCK_SIZE - 1]` and `ray_y` to `[0, MAP_SIZE_Y * BLOCK_SIZE - 1]` [S1, unofficial].
10. Compute grid indices: `grid_x = int(ray_x / BLOCK_SIZE)`, `grid_y = int(ray_y / BLOCK_SIZE)`. Check if `grid_x` or `grid_y` is out of bounds `[0, MAP_SIZE_X)` or `[0, MAP_SIZE_Y)`; if so, print error and quit [S1, unofficial].
11. Advance ray: `ray_x += delta_xe`, `ray_y += delta_ye` [S1, unofficial].
12. Compute horizontal ray direction: `up = abs(floor(angle / π) % 2)` [S1, unofficial].
13. Compute first horizontal grid line intersection Y: `firstY = up ? floor(player.y / 1) * 1 : floor(player.y / 1) * 1 + 1` [S1, unofficial].
14. Compute corresponding X: `firstX = player.x + (firstY - player.y) / tan(angle)` [S1, unofficial].
15. Set step vectors: `yA = up ? -1 : 1`, `xA = yA / tan(angle)` [S1, unofficial].
16. Loop stepping: `cellX = right ? floor(nextX / 1) : floor(nextX / 1) - 1`, `cellY = floor(nextY / 1)`. Check bounds. If not a wall, `nextX += xA`, `nextY += yA` [S2, unofficial].
17. Select final hit: Compare `distance_h` and `distance_v`. If `scanmode` is `'vertical'`, use vertical hit. If `'horizontal'`, use horizontal hit. If `'shortest'` (default), use the hit with the smaller distance [S1, unofficial]. Store selected `ray_x`, `ray_y`, `distance_direct`, `steps`, and `texture_x` [S1, unofficial].
18. Return hit object with Euclidean distance: `distance = sqrt((player.x - nextX)^2 + (player.y - nextY)^2)` [S1, unofficial].

**Formulas:**
- Fish-eye correction: `distance_perpendicular = distance_direct * cos(player.view_angle - ray_angle)` [S1, unofficial].
- Texture coordinate: `texture_x_h = (next_rayhit_x_h % BLOCK_SIZE) / BLOCK_SIZE` [S1, unofficial].

**Pseudocode:**
```python
import math

def ray_casting_via_grid_line_intersection(level, player, angle, block_size, map_size_x, map_size_y, epsilon, scan_mode):
    # 1. Initialize horizontal ray parameters
    offset_py = player.y % block_size
    y_sign = 1 if player.y_sign > 0 else -1
    delta_yi = (block_size - offset_py) if y_sign == 1 else -offset_py
    if delta_yi == 0:
        distance_h = 1000000
    delta_xi = delta_yi * (1.0 / math.tan(angle))

    # 2. Adjust delta_yi for backward ray direction
    if y_sign == -1:
        delta_yi -= epsilon

    # 3. Compute vertical ray direction
    right = abs(math.floor((angle - math.pi / 2) / math.pi) % 2)

    # 4. Compute first vertical grid line intersection X
    # Note: Sources use division by 1, adapted here to block_size for consistency [S1, unofficial]
    first_x = (math.floor(player.x / block_size) * block_size + block_size) if right else (math.floor(player.x / block_size) * block_size)

    # 5. Compute corresponding Y
    first_y = player.y + (first_x - player.x) * math.tan(angle)

    # 6. Initialize ray position
    ray_x = player.x + delta_xi
    ray_y = player.y + delta_yi

    # 7. Calculate external deltas
    delta_ye = block_size * y_sign
    delta_xe = abs(1.0 / math.tan(angle) * block_size) * (1 if right else -1)

    # 8. Set step vectors
    x_step_v = 1 if right else -1
    y_step_v = x_step_v * math.tan(angle)

    # 9-11. Loop for horizontal hit detection
    steps_h = 0
    while steps_h <= map_size_x * 2:
        steps_h += 1
        # Advance ray
        ray_x += delta_xe
        ray_y += delta_ye
        # Clamp
        ray_x = max(0.0, min(ray_x, map_size_x * block_size - 1))
        ray_y = max(0.0, min(ray_y, map_size_y * block_size - 1))
        # Calculate grid indices
        grid_x = int(ray_x / block_size)
        grid_y = int(ray_y / block_size)
        # Check bounds
        if not (0 <= grid_x < map_size_x and 0 <= grid_y < map_size_y):
            raise ValueError("Out of bounds grid access")
        if level[grid_y][grid_x] > 0:
            break
    vertical_hit_dist = math.sqrt((player.x - ray_x)**2 + (player.y - ray_y)**2)
    vertical_hit = (0, grid_x, grid_y, vertical_hit_dist)

    # 12. Compute horizontal ray direction
    up = abs(math.floor(angle / math.pi) % 2)

    # 13. Compute first horizontal grid line intersection Y
    first_y = (math.floor(player.y / block_size) * block_size) if up else (math.floor(player.y / block_size) * block_size + block_size)

    # 14. Compute corresponding X
    first_x = player.x + (first_y - player.y) / math.tan(angle)

    # 15. Set step vectors
    y_step_h = -1 if up else 1
    x_step_h = y_step_h / math.tan(angle)

    # 16. Loop stepping
    next_x = first_x
    next_y = first_y
    while True:
        cell_x = math.floor(next_x / block_size)
        cell_y = (math.floor(next_y / block_size) - 1) if up else math.floor(next_y / block_size)
        if not (0 <= cell_y < map_size_y and 0 <= cell_x < map_size_x):
            break
        if level[cell_y][cell_x] == 0:
            next_x += x_step_h
            next_y += y_step_h
        else:
            break
    horizontal_hit_dist = math.sqrt((player.x - next_x)**2 + (player.y - next_y)**2)
    horizontal_hit = (1, cell_x, cell_y, horizontal_hit_dist)

    # 17. Select final hit
    if scan_mode == 'vertical':
        selected = vertical_hit
    elif scan_mode == 'horizontal':
        selected = horizontal_hit
    else:
        selected = vertical_hit if vertical_hit_dist < horizontal_hit_dist else horizontal_hit

    # 18. Return hit object
    distance_direct = selected[3]
    distance_perpendicular = distance_direct * math.cos(player.view_angle - angle)
    # texture_x_h = (next_rayhit_x_h % BLOCK_SIZE) / BLOCK_SIZE [S1, unofficial]
    hit_x = selected[1] * block_size + (selected[0] * block_size)
    texture_x = (hit_x % block_size) / block_size
    return {
        'side': selected[0],
        'grid_x': selected[1],
        'grid_y': selected[2],
        'distance_direct': distance_direct,
        'distance_perpendicular': distance_perpendicular,
        'texture_x': texture_x
    }
```

**Edge Cases and Pitfalls:**
- Ray direction backward along the Y-axis requires adding `-EPSILON` to `delta_yi` to ensure correct grid index selection [S1, unofficial].
- Out-of-bounds grid access requires clamping coordinates before access and explicit bounds checks, quitting the program if indices fall outside `[0, MAP_SIZE_X)` or `[0, MAP_SIZE_Y)` [S1, unofficial].
- Infinite loop prevention is enforced by a maximum step count of `MAP_SIZE_X * 2` in the horizontal hit detection loop [S1, unofficial].
