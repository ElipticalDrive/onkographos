# Ray Casting via Grid Line Intersection

Also called: DDA Raycasting, Vertical/Horizontal Collision Casting

## Overview
This method is a 2D raycasting technique that computes intersections with vertical and horizontal grid lines to step cell-by-cell along a ray until a non-zero map cell is found [S1, unofficial]. It distinguishes itself by explicitly calculating vertical and horizontal traces separately, selecting the closest hit between the two, and using Euclidean distance for the final result [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** 2D grid map (`content`), player position (`player.position.x`, `player.position.y`), ray angle (`angle`), grid cell size (assumed 1 unit in source [S1, unofficial]).
- **Output:** Hit object containing side (0 or 1), map coordinates (`mapX`, `mapY`), perpendicular wall distance (`perpWallDist`), and final intersection coordinates (`finalX`, `finalY`).

**Data Structures:**
- `content`: A 2D array representing the grid. `content[x][y]` holds the cell value. Non-zero values indicate walls [S1, unofficial].
- `player`: Object with `position` (x, y) and other properties not directly used in the core DDA logic shown [S1, unofficial].

**Parameters:**
- `angle`: Ray direction in radians.
- `mapX`, `mapY`: Current grid coordinates.
- `sideDistX`, `sideDistY`: Distance to the next vertical/horizontal grid line.
- `stepX`, `stepY`: Step direction (+1 or -1) for x and y.
- `deltaDistX`, `deltaDistY`: Distance to travel in x/y to reach the next grid line.

**Steps:**

1.  **Initialize Vertical Trace:**
    - Compute vertical ray direction: `right = Math.abs(Math.floor((angle - Math.PI / 2) / Math.PI) % 2)` [S1, unofficial].
    - Compute first vertical grid line intersection X: `firstX = right ? Math.floor(player.position.x / 1) * 1 + 1 : Math.floor(player.position.x / 1) * 1` [S1, unofficial].
    - Compute corresponding Y: `firstY = player.position.y + (firstX - player.position.x) * Math.tan(angle)` [S1, unofficial].
    - Set step vectors: `xA = right ? 1 : -1`, `yA = xA * Math.tan(angle)` [S1, unofficial].
    - Initialize loop variables: `nextX = firstX`, `nextY = firstY` [S1, unofficial].

2.  **Step Vertical Trace:**
    - Loop:
        - `cellX = right ? Math.floor(nextX / 1) : Math.floor(nextX / 1) - 1` [S1, unofficial].
        - `cellY = Math.floor(nextY / 1)` [S1, unofficial].
        - Check bounds: If `cellY < 0` or `cellY >= map height` or `cellX < 0` or `cellX >= map width`, break [S1, unofficial].
        - Check cell: If `content[cellX][cellY] == 0`, `nextX += xA`, `nextY += yA` [S1, unofficial].
        - Else, hit found. Calculate distance: `distance = sqrt((player.position.x - nextX)^2 + (player.position.y - nextY)^2)` [S1, unofficial].
        - Return hit with side 0 (vertical hit) [S1, unofficial].

3.  **Initialize Horizontal Trace:**
    - Compute horizontal ray direction: `up = Math.abs(Math.floor(angle / Math.PI) % 2)` [S1, unofficial].
    - Compute first horizontal grid line intersection Y: `firstY = up ? Math.floor(player.position.y / 1) * 1 : Math.floor(player.position.y / 1) * 1 + 1` [S1, unofficial].
    - Compute corresponding X: `firstX = player.position.x + (firstY - player.position.y) / Math.tan(angle)` [S1, unofficial].
    - Set step vectors: `yA = up ? -1 : 1`, `xA = yA / Math.tan(angle)` [S1, unofficial].
    - Initialize loop variables: `nextX = firstX`, `nextY = firstY` [S1, unofficial].

4.  **Step Horizontal Trace:**
    - Loop:
        - `cellX = Math.floor(nextX / 1)` [S1, unofficial].
        - `cellY = up ? Math.floor(nextY / 1) - 1 : Math.floor(nextY / 1)` [S1, unofficial].
        - Check bounds: If `cellY < 0` or `cellY >= map height` or `cellX < 0` or `cellX >= map width`, break [S1, unofficial].
        - Check cell: If `content[cellX][cellY] == 0`, `nextX += xA`, `nextY += yA` [S1, unofficial].
        - Else, hit found. Calculate distance: `distance = sqrt((player.position.x - nextX)^2 + (player.position.y - nextY)^2)` [S1, unofficial].
        - Return hit with side 1 (horizontal hit) [S1, unofficial].

5.  **Select Closest Hit:**
    - Compare distances from vertical and horizontal traces.
    - Return the hit with the smaller distance [S1, unofficial].

**Pseudocode:**

```python
def ray_casting_via_grid_line_intersection(map_content, player_pos, angle):
    # Initialize vertical trace
    right = abs(math.floor((angle - math.pi / 2) / math.pi) % 2)
    first_x = (math.floor(player_pos.x / 1) * 1 + 1) if right else (math.floor(player_pos.x / 1) * 1)
    first_y = player_pos.y + (first_x - player_pos.x) * math.tan(angle)
    x_step = 1 if right else -1
    y_step = x_step * math.tan(angle)
    next_x, next_y = first_x, first_y
    
    # Step vertical trace
    while True:
        cell_x = math.floor(next_x / 1) if right else (math.floor(next_x / 1) - 1)
        cell_y = math.floor(next_y / 1)
        if not (0 <= cell_y < len(map_content) and 0 <= cell_x < len(map_content[0])):
            break
        if map_content[cell_x][cell_y] == 0:
            next_x += x_step
            next_y += y_step
        else:
            vertical_hit_dist = math.sqrt((player_pos.x - next_x)**2 + (player_pos.y - next_y)**2)
            vertical_hit = (0, cell_x, cell_y, vertical_hit_dist)
            break
    
    # Initialize horizontal trace
    up = abs(math.floor(angle / math.pi) % 2)
    first_y = (math.floor(player_pos.y / 1) * 1) if up else (math.floor(player_pos.y / 1) * 1 + 1)
    first_x = player_pos.x + (first_y - player_pos.y) / math.tan(angle)
    y_step = -1 if up else 1
    x_step = y_step / math.tan(angle)
    next_x, next_y = first_x, first_y
    
    # Step horizontal trace
    while True:
        cell_x = math.floor(next_x / 1)
        cell_y = (math.floor(next_y / 1) - 1) if up else math.floor(next_y / 1)
        if not (0 <= cell_y < len(map_content) and 0 <= cell_x < len(map_content[0])):
            break
        if map_content[cell_x][cell_y] == 0:
            next_x += x_step
            next_y += y_step
        else:
            horizontal_hit_dist = math.sqrt((player_pos.x - next_x)**2 + (player_pos.y - next_y)**2)
            horizontal_hit = (1, cell_x, cell_y, horizontal_hit_dist)
            break
    
    # Select closest hit
    if vertical_hit_dist < horizontal_hit_dist:
        return vertical_hit
    else:
        return horizontal_hit
```

**Edge Cases and Pitfalls:**
- Division by zero when `tan(angle)` is undefined (angle = 0, pi, etc.). Handle separately or use alternative calculations [S1, unofficial].
- Boundary checks are crucial to avoid out-of-bounds array access [S1, unofficial].
- Precision issues with floating-point arithmetic may affect hit detection [S1, unofficial].

## Operating characteristics
- **Time Complexity:** O(N) where N is the number of cells traversed by the ray.
- **Memory Complexity:** O(1) auxiliary space.
- **Strengths:** Simple to implement, efficient for uniform grids.
- **Limitations:** Explicitly calculates two traces, which may be less efficient than a single DDA traversal. Not given in the sources for measured performance.
