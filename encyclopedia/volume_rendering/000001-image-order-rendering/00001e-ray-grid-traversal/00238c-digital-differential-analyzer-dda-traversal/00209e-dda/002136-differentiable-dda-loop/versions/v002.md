# Differentiable DDA Loop

Also called: Differentiable DDA

## Overview
A differentiable Digital Differential Analyzer (DDA) loop that traverses a grid along a ray, invoking a callback function for each visited cell [S1, unofficial]. It extends standard DDA traversal by maintaining differentiable state variables, allowing gradients to flow back through the ray marching steps [G].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Ray direction `ray_d2`, grid resolution `grid_res`, initial ray origin (implicit in `p0`), and a callback function `func` [S1, unofficial].
*   **Outputs:** The state returned by the final callback invocation [S1, unofficial].

**Data Structures:**
*   `active`: Boolean flag indicating whether the ray is still valid [S1, unofficial].
*   `state`: User-defined state object passed to the callback [S1, unofficial].
*   `dt_v`: Array of step sizes to the next grid line for each active ray [S1, unofficial].
*   `p0`: Current position of the ray [S1, unofficial].
*   `pi`: Current grid index (integer coordinates) [S1, unofficial].
*   `t_rem`: Remaining ray length to traverse [S1, unofficial].
*   `abs_rcp_d2`: Precomputed absolute reciprocal of the ray direction components [S1, unofficial].

**Numbered Steps:**

1.  **Loop Initialization:** Initialize `active` to true. Initialize `dt_v` based on ray direction and grid spacing. Initialize `p0` to the ray origin. Initialize `pi` to the starting grid cell. Initialize `t_rem` to the total ray length. Initialize `state` to the user's initial state [S1, unofficial].
2.  **Step Selection:** Compute the step size for this iteration: `dt = dr.minimum(dr.min(dt_v), t_rem)`. Identify which grid lines are hit at this step: `mask = dt_v == dt` [S1, unofficial].
3.  **Position Update:** Compute the new position using the Fused Multiply-Add (FMA) operation: `p1 = dr.fma(ray_d2, dt, p0)` [S1, unofficial].
4.  **Callback Invocation:** Invoke the user callback function: `state, cont = func(state, ArrayNu(pi), p0, p1, active & (dt > 0))` [S1, unofficial].
5.  **Grid Index Update:** Update `dt_v` for active rays: `dt_v[active] = dr.select(mask, abs_rcp_d2, dt_v - dt)`. Update `p0` for active rays: `p0[active] = dr.fma(ray_d2, dt, p0)`. Reset `p0` components for rays that crossed a grid line boundary: `p0[mask & active] = dr.select(ray_d2 >= 0, Float(0), Float(1))`. Increment `pi` for rays that crossed a grid line boundary: `pi[mask & active] += step`. Update `t_rem` for active rays: `t_rem[active] = t_rem - dt` [S1, unofficial].
6.  **Activity Update:** Update the `active` mask for the next iteration: `active[active] &= dr.all((pi >= 0) & (pi < ArrayNi(grid_res))) & (t_rem > 0) & cont` [S1, unofficial].

**Pitfalls:**
*   **Starting on a grid line:** If the ray starts exactly on a grid line, `dt` can be 0. The code handles this by selecting the minimum of `dt_v` and `t_rem`, and checking `dt > 0` before invoking the callback [S1, unofficial].

**Pseudocode:**
```python
def differentiable_dda_loop(ray_d2, grid_res, func, initial_state, ray_origin, ray_length):
    # Standard operations defined explicitly to avoid library dependencies
    def fma(a, b, c): return a * b + c
    def select(cond, t, f): return t if cond else f

    # Initialization [S1, unofficial]
    active = True
    state = initial_state
    abs_rcp_d2 = [abs(1.0 / d) for d in ray_d2]
    # dt_v initialization depends on ray origin and grid spacing [G]
    dt_v = [abs((grid_i - ray_origin[i]) / ray_d2[i]) for i in range(len(ray_d2))]
    p0 = list(ray_origin)
    pi = [int(ray_origin[i]) for i in range(len(ray_origin))]
    t_rem = ray_length

    while active:
        # Step Selection [S1, unofficial]
        dt = min(min(dt_v), t_rem)
        mask = [dt_v[i] == dt for i in range(len(dt_v))]

        # Position Update [S1, unofficial]
        p1 = [fma(ray_d2[i], dt, p0[i]) for i in range(len(ray_d2))]

        # Callback Invocation [S1, unofficial]
        if dt > 0:
            state, cont = func(state, pi, p0, p1, active and (dt > 0))
        else:
            cont = True

        # Grid Index Update [S1, unofficial]
        dt_v = [select(mask[i] and active, abs_rcp_d2[i], dt_v[i] - dt) for i in range(len(dt_v))]
        p0 = [fma(ray_d2[i], dt, p0[i]) for i in range(len(ray_d2))]
        p0 = [select(mask[i] and active and (ray_d2[i] >= 0), 0.0, 1.0) for i in range(len(ray_d2))]
        step = [1 if ray_d2[i] >= 0 else -1 for i in range(len(ray_d2))]
        pi = [pi[i] + (step[i] if mask[i] and active else 0) for i in range(len(pi))]
        t_rem = t_rem - dt

        # Activity Update [S1, unofficial]
        out_of_bounds = any(pi[i] < 0 or pi[i] >= grid_res[i] for i in range(len(pi)))
        active = active and not out_of_bounds and (t_rem > 0) and cont

    return state
```
