# Bresenham Voxel Traversal

Also called: Bresenham-like Voxel Traversal, MarchRayVoxelBresenham, Ray-Voxel Grid Intersection (Bresenham)

## Overview
Bresenham Voxel Traversal is a discrete voxel traversal algorithm that uses an integral error-accumulation method to step through voxels along the dominant axis of a ray [S1, unofficial]. It generates a full sequence of visited voxel coordinates rather than just the first hit, and differs from floating-point DDA variants by relying on integer-like error accumulation for axis increments [S1, unofficial].

## How it works
**Inputs:** Ray origin $O$, ray direction $D$, voxel grid dimensions, and a ray-cube intersection function `RayCubeSlabsIntersection` that returns the entry parameter $t$ [S1, unofficial].
**Outputs:** A list of 3D integer coordinates $(i, j, k)$ representing the sequence of visited voxels [S1, unofficial].

**Data Structures:**
- `vec3`: A 3D vector type with components $x, y, z$.
- `vector<vec3>`: A dynamic array of 3D vectors for the output.
- Integers: `ii, jj, kk` for voxel indices; `dx, dy, dz` for ray deltas; `x_length, y_length, z_length` for step counts; `x_inc, y_inc, z_inc` for direction signs; `err_1, err_2` for error terms [S1, unofficial].

**Parameters:**
- `EPSILON`: A small positive constant to handle precision issues and boundary conditions [S1, unofficial].

**Steps:**

1.  **Ray-Grid Intersection:**
    Compute the intersection parameter $t$ using `RayCubeSlabsIntersection` [S1, unofficial].
    If $t < \text{EPSILON}$, push $(-1, -1, -1)$ to the output list and return [S1, unofficial].

2.  **Determine Start and End Points:**
    Calculate the start and end points of the ray segment within the grid [S1, unofficial].
    - If the ray origin $O$ is outside the grid, start $= O + (t + \text{EPSILON}) \cdot D$ [S1, unofficial].
    - If the ray origin $O$ is inside the grid, start $= O$ [S1, unofficial].
    - The end point is computed similarly using the exit intersection parameter [S1, unofficial].

3.  **Calculate Deltas and Increments:**
    Calculate deltas $dx, dy, dz$ as the difference in world coordinates between the end and start points [S1, unofficial].
    - $dx = \text{end}.x - \text{start}.x$
    - $dy = \text{end}.y - \text{start}.y$
    - $dz = \text{end}.z - \text{start}.z$
    
    Calculate lengths $x\_length, y\_length, z\_length$ and determine increments $x\_inc, y\_inc, z\_inc$ based on the sign of $dx, dy, dz$ [S1, unofficial].
    Multiply deltas by 2:
    - $dx2 = dx \cdot 2$
    - $dy2 = dy \cdot 2$
    - $dz2 = dz \cdot 2$

4.  **Determine Dominant Axis:**
    Identify the axis with the maximum absolute delta [S1, unofficial].
    - If $|dx| \ge |dy|$ and $|dx| \ge |dz|$, X is dominant.
    - If $|dy| \ge |dx|$ and $|dy| \ge |dz|$, Y is dominant.
    - If $|dz| \ge |dx|$ and $|dz| \ge |dy|$, Z is dominant.

5.  **Traverse Voxels:**
    Initialize the current voxel position $(i, j, k)$ to the voxel containing the start point [G].
    
    **Case 1: X is dominant**
    - Initialize error terms:
      - $err\_1 = dy2 - x\_length$
      - $err\_2 = dz2 - x\_length$
    - Loop from 0 to $x\_length$:
      - Push current point $(i, j, k)$ to output.
      - If $err\_1 > 0$:
        - $j += y\_inc$
        - $err\_1 -= dx2$
      - If $err\_2 > 0$:
        - $k += z\_inc$
        - $err\_2 -= dx2$
      - $err\_1 += dy2$
      - $err\_2 += dz2$
      - $i += x\_inc$
    - Push final point $(i, j, k)$ after the loop [S1, unofficial].

    **Case 2: Y is dominant**
    - Initialize error terms:
      - $err\_1 = dx2 - y\_length$
      - $err\_2 = dz2 - y\_length$
    - Loop from 0 to $y\_length$:
      - Push current point $(i, j, k)$ to output.
      - If $err\_1 > 0$:
        - $i += x\_inc$
        - $err\_1 -= dy2$
      - If $err\_2 > 0$:
        - $k += z\_inc$
        - $err\_2 -= dy2$
      - $err\_1 += dx2$
      - $err\_2 += dz2$
      - $j += y\_inc$
    - Push final point $(i, j, k)$ after the loop [S1, unofficial].

    **Case 3: Z is dominant**
    - Initialize error terms:
      - $err\_1 = dy2 - z\_length$
      - $err\_2 = dx2 - z\_length$
    - Loop from 0 to $z\_length$:
      - Push current point $(i, j, k)$ to output.
      - If $err\_1 > 0$:
        - $j += y\_inc$
        - $err\_1 -= dz2$
      - If $err\_2 > 0$:
        - $i += x\_inc$
        - $err\_2 -= dz2$
      - $err\_1 += dy2$
      - $err\_2 += dx2$
      - $k += z\_inc$
    - Push final point $(i, j, k)$ after the loop [S1, unofficial].

**Pseudocode:**

```python
def bresenham_voxel_traversal(origin, direction, grid_width, grid_height, grid_depth, ray_cube_intersection):
    """
    Traverses a voxel grid using Bresenham-like integer arithmetic.
    
    Args:
        origin: vec3, ray origin
        direction: vec3, normalized ray direction
        grid_width: int, number of voxels in X
        grid_height: int, number of voxels in Y
        grid_depth: int, number of voxels in Z
        ray_cube_intersection: function, returns (t_entry, t_exit) for ray and grid bounding box
        
    Returns:
        list of vec3, voxel coordinates visited
    """
    # 1. Ray-Grid Intersection
    t_entry, t_exit = ray_cube_intersection(origin, direction, grid_width, grid_height, grid_depth)
    
    EPSILON = 1e-6
    if t_entry < EPSILON:
        return [vec3(-1, -1, -1)]
    
    # 2. Determine Start and End Points
    ox, oy, oz = origin
    inside_x = 0 <= ox < grid_width
    inside_y = 0 <= oy < grid_height
    inside_z = 0 <= oz < grid_depth
    
    if not (inside_x and inside_y and inside_z):
        start_point = origin + (t_entry + EPSILON) * direction
    else:
        start_point = origin
        
    end_point = origin + t_exit * direction
    
    # 3. Calculate Deltas and Increments
    dx = end_point.x - start_point.x
    dy = end_point.y - start_point.y
    dz = end_point.z - start_point.z
    
    # Lengths and increments
    x_length = int(abs(dx))
    y_length = int(abs(dy))
    z_length = int(abs(dz))
    
    x_inc = 1 if dx > 0 else (-1 if dx < 0 else 0)
    y_inc = 1 if dy > 0 else (-1 if dy < 0 else 0)
    z_inc = 1 if dz > 0 else (-1 if dz < 0 else 0)
    
    dx2 = 2 * dx
    dy2 = 2 * dy
    dz2 = 2 * dz
    
    # 4. Determine Dominant Axis
    abs_dx = abs(dx)
    abs_dy = abs(dy)
    abs_dz = abs(dz)
    
    # 5. Traverse Voxels
    # Initialize current voxel position to the voxel containing start_point [G]
    i = int(start_point.x)
    j = int(start_point.y)
    k = int(start_point.z)
    
    points = []
    
    if abs_dx >= abs_dy and abs_dx >= abs_dz:
        # X is dominant
        err_1 = dy2 - x_length
        err_2 = dz2 - x_length
        
        for _ in range(x_length):
            points.append(vec3(i, j, k))
            
            if err_1 > 0:
                j += y_inc
                err_1 -= dx2
            if err_2 > 0:
                k += z_inc
                err_2 -= dx2
                
            err_1 += dy2
            err_2 += dz2
            i += x_inc
            
        points.append(vec3(i, j, k))
        
    elif abs_dy >= abs_dx and abs_dy >= abs_dz:
        # Y is dominant
        err_1 = dx2 - y_length
        err_2 = dz2 - y_length
        
        for _ in range(y_length):
            points.append(vec3(i, j, k))
            
            if err_1 > 0:
                i += x_inc
                err_1 -= dy2
            if err_2 > 0:
                k += z_inc
                err_2 -= dy2
                
            err_1 += dx2
            err_2 += dz2
            j += y_inc
            
        points.append(vec3(i, j, k))
        
    else:
        # Z is dominant
        err_1 = dy2 - z_length
        err_2 = dx2 - z_length
        
        for _ in range(z_length):
            points.append(vec3(i, j, k))
            
            if err_1 > 0:
                j += y_inc
                err_1 -= dz2
            if err_2 > 0:
                i += x_inc
                err_2 -= dz2
                
            err_1 += dy2
            err_2 += dx2
            k += z_inc
            
        points.append(vec3(i, j, k))
        
    return points
```

**Edge Cases and Pitfalls:**
- **Precision:** The algorithm uses `EPSILON` to handle boundary conditions and precision issues during intersection calculation [S1, unofficial].
- **Degenerate Input:** If the ray does not intersect the grid or starts inside with an immediate exit, the algorithm returns $(-1, -1, -1)$ [S1, unofficial].

## Background
The Bresenham Voxel Traversal algorithm is used in the `MarchRayVoxel` function to generate a sequence of voxel coordinates for light transmittance calculations [S1, unofficial]. The method is applied within volumetric rendering pipelines to step through voxel grids along ray paths [S1, unofficial].
