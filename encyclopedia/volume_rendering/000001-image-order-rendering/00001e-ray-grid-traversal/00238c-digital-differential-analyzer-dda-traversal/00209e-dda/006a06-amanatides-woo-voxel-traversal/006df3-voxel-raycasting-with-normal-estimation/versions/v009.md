# Voxel Raycasting with Normal Estimation

Also called: Voxel DDA, DDA Voxel Traversal, Voxel Raycasting via DDA, Digital Differential Analyzer voxel traversal

## Overview
Voxel Raycasting with Normal Estimation traces a ray through a voxel grid to find the first solid voxel, simultaneously estimating the surface normal based on the traversal direction relative to the grid axes [S2][S3, unofficial]. It solves the problem of efficiently querying sparse or dense voxel structures for collision, occlusion, or surface detection by walking the grid directly, visiting only intersected cells [S2][S5, unofficial]. It differs from fixed-step raymarching by calculating intersection distances with voxel boundaries along each axis to determine which boundary is crossed next, ensuring exactly one voxel is processed per step [S3, S4, unofficial]. It builds on [Amanatides-Woo Voxel Traversal](3132-amanatides-woo-voxel-traversal.md) by providing the core traversal mechanism that identifies the hit voxel and entry face, which are then used for normal estimation [S3, S6, unofficial].

## How it works
**Inputs:** Ray origin $O$, ray direction $D$ (normalized), maximum ray distance $maxDist$, voxel grid occupancy data, and an epsilon constant $\epsilon$ for degenerate ray detection [S2][S3, S4, unofficial].
**Outputs:** Boolean hit status, hit position $P$, and surface normal $N$ [S3, S4, unofficial].

**Data Structures:**
*   `Ray`: Contains `origin` (Vec3), `direction` (Vec3), `maxDistance` (float).
*   `VoxelGrid`: Provides a function `isSolid(x, y, z)` returning boolean [S3, unofficial].
*   `HitResult`: Contains `hit` (bool), `point` (Vec3), `normal` (Vec3) [S3, S4, unofficial].

**Parameters:**
*   $\epsilon = 0.0001$ [S2].
*   $maxDist = 6.0$ (typical, scene-dependent) [S3, unofficial].

**Algorithm Steps:**

1.  **Degenerate Ray Check:** Calculate squared magnitude $|D|^2$. If $|D|^2 < \epsilon$, return no hit [S2].
2.  **Initialization:**
    *   Compute step direction vector $S$:
        $$ S_x = \text{sign}(D_x), \quad S_y = \text{sign}(D_y), \quad S_z = \text{sign}(D_z) $$
        Where $\text{sign}(v) = 1$ if $v > 0$, $-1$ if $v < 0$, and $0$ if $v = 0$ [S2].
    *   Compute step size (reciprocal of direction magnitude):
        $$ \Delta T_x = \begin{cases} 1/|D_x| & \text{if } |D_x| > \epsilon \\ \infty & \text{otherwise} \end{cases} $$
        $$ \Delta T_y = \begin{cases} 1/|D_y| & \text{if } |D_y| > \epsilon \\ \infty & \text{otherwise} \end{cases} $$
        $$ \Delta T_z = \begin{cases} 1/|D_z| & \text{if } |D_z| > \epsilon \\ \infty & \text{otherwise} \end{cases} $$
        [S2].
    *   Determine starting voxel coordinates:
        $$ V_x = \lfloor O_x \rfloor, \quad V_y = \lfloor O_y \rfloor, \quad V_z = \lfloor O_z \rfloor $$
        [S2][S3, unofficial].
    *   Initialize distance to next boundary ($T_{max}$) for each axis:
        $$ T_{max_x} = \begin{cases} (V_x + 1 - O_x) \Delta T_x & \text{if } S_x = 1 \\ (O_x - V_x) \Delta T_x & \text{if } S_x = -1 \\ \infty & \text{if } S_x = 0 \end{cases} $$
        $$ T_{max_y} = \begin{cases} (V_y + 1 - O_y) \Delta T_y & \text{if } S_y = 1 \\ (O_y - V_y) \Delta T_y & \text{if } S_y = -1 \\ \infty & \text{if } S_y = 0 \end{cases} $$
        $$ T_{max_z} = \begin{cases} (V_z + 1 - O_z) \Delta T_z & \text{if } S_z = 1 \\ (O_z - V_z) \Delta T_z & \text{if } S_z = -1 \\ \infty & \text{if } S_z = 0 \end{cases} $$
        [S2].
    *   Initialize previous position $P_{prev} = O$ [S6, unofficial].
3.  **Immediate Hit Check:** Check if the starting voxel $(V_x, V_y, V_z)$ is solid. If yes, calculate the entry normal based on the closest face (determined by ray direction and local position within the voxel) and return the hit [S3, unofficial].
4.  **DDA Loop:** While $T_{max_x} < maxDist$ or $T_{max_y} < maxDist$ or $T_{max_z} < maxDist$:
    *   Find the minimum $T_{max}$ among $T_{max_x}, T_{max_y}, T_{max_z}$. Tie-breaking priority: X > Y > Z [S3, unofficial].
    *   Record the ray distance $t$ at the boundary being crossed ($t = T_{max_{axis}}$).
    *   Update previous position: $P_{prev} = P_{curr}$ [S6, unofficial].
    *   Advance the voxel index along the axis with the minimum $T_{max}$:
        *   If $T_{max_x}$ is smallest: $V_x \leftarrow V_x + S_x$, $T_{max_x} \leftarrow T_{max_x} + \Delta T_x$ [S3, unofficial].
        *   Else if $T_{max_y}$ is smallest: $V_y \leftarrow V_y + S_y$, $T_{max_y} \leftarrow T_{max_y} + \Delta T_y$ [S3, unofficial].
        *   Else: $V_z \leftarrow V_z + S_z$, $T_{max_z} \leftarrow T_{max_z} + \Delta T_z$ [S3, unofficial].
    *   Compute current position at the crossed boundary: $P_{curr} = O + D \times t$ [S6, unofficial].
    *   Check if the new voxel $(V_x, V_y, V_z)$ is solid [S2][S3, unofficial].
    *   If solid:
        *   Calculate displacement vector $Diff = P_{curr} - P_{prev}$ [S3, unofficial].
        *   Estimate normal $N$ by comparing absolute components of $Diff$:
            *   If $|Diff_x| > |Diff_y|$ and $|Diff_x| > |Diff_z|$: $N = (-1, 0, 0)$ if $Diff_x > 0$, else $(1, 0, 0)$ [S3, unofficial].
            *   Else if $|Diff_y| > |Diff_z|$: $N = (0, -1, 0)$ if $Diff_y > 0$, else $(0, 1, 0)$ [S3, unofficial].
            *   Else: $N = (0, 0, -1)$ if $Diff_z > 0$, else $(0, 0, 1)$ [S3, unofficial].
        *   Return hit with position $P_{curr}$ and normal $N$ [S3, unofficial].
    *   If not solid, continue loop.
5.  **Termination:** If the loop completes without hitting a solid voxel, return no hit [S3, unofficial].

**Pseudocode:**

```python
import math

def voxel_raycast_with_normal_estimation(origin, direction, max_dist, is_solid, epsilon=0.0001):
    """
    Traces a ray through a voxel grid to find the first solid voxel and estimate its normal.
    
    Args:
        origin (Vec3): Ray origin.
        direction (Vec3): Ray direction (assumed normalized).
        max_dist (float): Maximum ray length.
        is_solid (function): Function taking (x, y, z) integers, returning True if voxel is solid.
        epsilon (float): Threshold for degenerate rays.
        
    Returns:
        dict: {'hit': bool, 'point': Vec3, 'normal': Vec3}
    """
    # 1. Degenerate Ray Check
    dir_sq = direction.x**2 + direction.y**2 + direction.z**2
    if dir_sq < epsilon:
        return {'hit': False, 'point': None, 'normal': None}

    # 2. Initialization
    step_x = 1 if direction.x > 0 else (-1 if direction.x < 0 else 0)
    step_y = 1 if direction.y > 0 else (-1 if direction.y < 0 else 0)
    step_z = 1 if direction.z > 0 else (-1 if direction.z < 0 else 0)

    abs_dx = abs(direction.x)
    abs_dy = abs(direction.y)
    abs_dz = abs(direction.z)

    delta_t_x = (1.0 / abs_dx) if abs_dx > epsilon else float('inf')
    delta_t_y = (1.0 / abs_dy) if abs_dy > epsilon else float('inf')
    delta_t_z = (1.0 / abs_dz) if abs_dz > epsilon else float('inf')

    voxel_x = math.floor(origin.x)
    voxel_y = math.floor(origin.y)
    voxel_z = math.floor(origin.z)

    if step_x == 1:
        t_max_x = (voxel_x + 1.0 - origin.x) * delta_t_x
    elif step_x == -1:
        t_max_x = (origin.x - voxel_x) * delta_t_x
    else:
        t_max_x = float('inf')

    if step_y == 1:
        t_max_y = (voxel_y + 1.0 - origin.y) * delta_t_y
    elif step_y == -1:
        t_max_y = (origin.y - voxel_y) * delta_t_y
    else:
        t_max_y = float('inf')

    if step_z == 1:
        t_max_z = (voxel_z + 1.0 - origin.z) * delta_t_z
    elif step_z == -1:
        t_max_z = (origin.z - voxel_z) * delta_t_z
    else:
        t_max_z = float('inf')

    prev_pos = origin
    t = 0.0

    # 3. Immediate Hit Check
    if is_solid(voxel_x, voxel_y, voxel_z):
        if abs(direction.x) > abs(direction.y) and abs(direction.x) > abs(direction.z):
            normal = Vec3(-step_x, 0, 0)
        elif abs(direction.y) > abs(direction.z):
            normal = Vec3(0, -step_y, 0)
        else:
            normal = Vec3(0, 0, -step_z)
        return {'hit': True, 'point': origin, 'normal': normal}

    # 4. DDA Loop
    while t_max_x < max_dist or t_max_y < max_dist or t_max_z < max_dist:
        if t_max_x <= t_max_y and t_max_x <= t_max_z:
            axis = 'x'
        elif t_max_y <= t_max_z:
            axis = 'y'
        else:
            axis = 'z'

        t = t_max_x if axis == 'x' else (t_max_y if axis == 'y' else t_max_z)

        if axis == 'x':
            voxel_x += step_x
            t_max_x += delta_t_x
        elif axis == 'y':
            voxel_y += step_y
            t_max_y += delta_t_y
        else:
            voxel_z += step_z
            t_max_z += delta_t_z

        curr_pos = Vec3(
            origin.x + direction.x * t,
            origin.y + direction.y * t,
            origin.z + direction.z * t
        )

        if is_solid(voxel_x, voxel_y, voxel_z):
            diff = curr_pos - prev_pos
            abs_diff_x = abs(diff.x)
            abs_diff_y = abs(diff.y)
            abs_diff_z = abs(diff.z)

            if abs_diff_x > abs_diff_y and abs_diff_x > abs_diff_z:
                normal = Vec3(-1, 0, 0) if diff.x > 0 else Vec3(1, 0, 0)
            elif abs_diff_y > abs_diff_z:
                normal = Vec3(0, -1, 0) if diff.y > 0 else Vec3(0, 1, 0)
            else:
                normal = Vec3(0, 0, -1) if diff.z > 0 else Vec3(0, 0, 1)

            return {'hit': True, 'point': curr_pos, 'normal': normal}

        prev_pos = curr_pos

    return {'hit': False, 'point': None, 'normal': None}

class Vec3:
    def __init__(self, x, y, z):
        self.x = x
        self.y = y
        self.z = z
    def __sub__(self, other):
        return Vec3(self.x - other.x, self.y - other.y, self.z - other.z)
```

**Edge Cases and Pitfalls:**
*   **Degenerate Rays:** Rays with zero or near-zero direction components must be handled to avoid division by zero or infinite loops [S2][S4, unofficial].
*   **Axis-Aligned Rays:** If a direction component is exactly 0, the corresponding `step` and `delta_t` are handled as 0 and infinity respectively, skipping traversal on that axis [S4, unofficial].
*   **Normal Accuracy:** Normal estimation relies on the displacement vector between steps. If the step size is large relative to voxel size, or if the ray passes through a corner, the normal may be inaccurate or incorrectly axis-aligned [S3, unofficial]. The method assumes the ray enters the voxel face corresponding to the largest component of the displacement vector [S6, unofficial].
*   **Precision:** Floating-point precision errors in `t_max` accumulation can cause jitter or missed voxels in long rays. Using double precision or periodic re-normalization of `t_max` may be required [G].

## Subtopics

### [DN_step_map](8596-dn-step-map.md)
A traversal algorithm that determines the sequence of voxels intersected by a ray without explicit intersection tests, using precomputed distance-to-boundary parameters. It differs by providing the core traversal mechanism for hit voxel and entry face identification, used for normal estimation. Choose when efficient, exact voxel stepping is required for collision or surface detection.

### [Voxel Raycast with AABB Hitbox Refinement](16579-voxel-raycast-with-aabb-hitbox-refinement.md)
Extends basic voxel raycasting by combining grid traversal with precise geometric intersection against sub-voxel AABB hitboxes. It differs by refining the hit position and normal for non-cuboid shapes, falling back to grid face normals for solid voxels. Choose when non-cuboid collision shapes (hitboxes) are present in the voxel environment.

## Operating characteristics
*   **Time Complexity:** $O(N)$, where $N$ is the number of voxels intersected along the ray path (proportional to $maxDist$) [S5, S7, unofficial].
*   **Memory Complexity:** $O(1)$ auxiliary space, excluding the voxel grid storage [S2].
*   **Performance:** On a 256x256x256 colorfield (16 million voxels), software-mode raycasting achieves decent speed at 2000x2000 resolution and real-time rates at 800x600 for dense objects [S1, unofficial]. It is more efficient than PhysX raycasts for voxel grids [S5, unofficial].
*   **Strengths:** Parallelizable (each ray is independent), efficient for sparse grids (visits only intersected cells), simple implementation [S1, unofficial][S2].
*   **Limitations:** Normal estimation is approximate and axis-aligned, not suitable for smooth surfaces. Performance degrades with very long rays or dense grids without spatial acceleration structures [S1, S3, unofficial].
*   **When to Use:** Collision detection, occlusion culling, and simple surface normal estimation in voxel-based games or simulations where performance is critical and high-precision normals are not required [S2][S3, unofficial].

## Background
The method is based on the Amanatides and Woo algorithm, a classic ray traversal algorithm for regular grids [S1, unofficial]. It was popularized in the context of voxel rendering and collision detection in games [S2][S3, unofficial]. The algorithm was originally described in "A Fast Voxel Traversal Algorithm for Ray Tracing" by Amanatides and Woo (1987) [S4, unofficial].
