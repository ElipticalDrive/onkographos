# Voxel Entry/Exit UV Calculation for DDA Raymarching
Also called: Voxel UV Mapping, Entry/Exit UV Computation

## Overview
This method computes the normalized entry and exit UV coordinates of a ray within a voxel during Digital Differential Analyzer (DDA) traversal, enabling smooth terrain rendering by determining if the ray passes through voxel content or exits [S1, unofficial]. It sets itself apart from standard DDA by integrating geometric UV extraction directly into the traversal step to support surface smoothing logic, rather than merely tracking voxel indices.

## How it works
**Inputs and Outputs**
- **Inputs**: Current ray position ($P_{curr}$), previous ray position ($P_{prev}$), ray direction ($D$), voxel index ($I \in [0,7]$), and a traversal mask ($M$) indicating the face entered/exited.
- **Outputs**: Entry UV ($U_{entry}$), Exit UV ($U_{exit}$), Voxel Center UV ($C$), and a boolean flag indicating whether to break the traversal loop.

**Data Structures**
- **Mask ($M$)**: A `bool3` (or equivalent 3-bit vector) where exactly one component is `true`, indicating the axis and direction of the face intersection [S1, unofficial].
- **Ray Position**: A 3D vector $(x, y, z)$ representing the intersection point in world or voxel space.

**Steps**
1. **Compute Exit UV**: Calculate the exit UV by subtracting the previous array position from the current ray position [S1, unofficial]:
   $$U_{exit} = P_{curr} - P_{prev}$$
   Note: $P_{prev}$ is the ray position at the start of the current voxel step.

2. **Compute Entry UV**: To determine the entry point, the method first calculates the ray position at the entry face. This is done by stepping back from $P_{curr}$ using the distance to the previous face ($d_{prev}$) and the ray direction [S1, unofficial]:
   $$P_{entry} = P_{prev} + D \times d_{prev}$$
   Then, the entry UV is computed by subtracting the floor of the current ray position (interpreted as the voxel origin) from the entry position [S1, unofficial]:
   $$U_{entry} = P_{entry} - \lfloor P_{entry} \rfloor$$
   *Note: In some implementations, if $P_{prev}$ is already normalized to the voxel local space, $U_{entry}$ may be derived directly as $P_{prev} - \lfloor P_{prev} \rfloor$ [S1, unofficial].*

3. **Calculate Voxel Center**: Determine the center of the voxel in UV space. The voxel index $I$ is mapped to a value between 1 and 8, then scaled to [0,1] [S1, unofficial]:
   $$C = (I + 1) \times 0.125$$
   This center $C$ is used for comparison against the midpoint of the ray segment within the voxel.

4. **Compute Midpoint**: Calculate the midpoint between the entry and exit UVs to determine the ray's position relative to the voxel center [S1, unofficial]:
   $$U_{mid} = \frac{U_{entry} + U_{exit}}{2}$$

5. **Determine Traversal Continuation**: Compare the midpoint to the center to decide if the ray has exited the relevant content [S1, unofficial]:
   - If $U_{mid} < C$ (or based on entry face direction), the traversal may break.
   - For side faces (e.g., X-axis entry), compute boundary Y coordinates using linear interpolation between adjacent corners to determine if the ray exits the voxel content [S1, unofficial]:
     $$Y_{min\_max} = (Y_{left} + Y_{right}) \times 0.5$$
     $$Y_{height} = U_{entry}.x \times (Y_{min\_max}.y - Y_{min\_max}.x) + Y_{min\_max}.x$$
     If $U_{entry}.y < Y_{height}$, break.

**Parameters**
- **$d$**: Distance to the next voxel face along the ray direction, computed via length check or mask multiplication [S1, unofficial].
- **$M$**: A `bool3` indicating which voxel faces the ray enters/exits; exactly one boolean is true per step [S1, unofficial].

**Pitfalls**
- The mask must contain exactly one true boolean; otherwise, the length trick for extracting distance fails [S1, unofficial].
- Entry/exit checks require separate handling for upward/downward traversal (e.g., `ray_step.y == 1` implies hitting from below, requiring additional voxel flags for inverted surfaces) [S1, unofficial].

**Pseudocode**
```python
def compute_voxel_uv(P_curr, P_prev, D, voxel_index, mask):
    # Step 1: Compute Exit UV
    # P_prev is the position at the start of the current voxel
    U_exit = P_curr - P_prev

    # Step 2: Compute Entry UV
    # Calculate distance to previous face (d_prev)
    # Assuming mask indicates the face entered at P_prev
    d_prev = length(P_curr - P_prev) # Simplified; in practice, d_prev is derived from mask and delta_dist
    P_entry = P_prev - D * d_prev # Step back to entry face
    U_entry = P_entry - floor(P_entry)

    # Step 3: Calculate Voxel Center
    # voxel_index is 0-7, representing the 8 sub-cubes of a voxel
    center = (voxel_index + 1) * 0.125

    # Step 4: Compute Midpoint
    U_mid = (U_entry + U_exit) * 0.5

    # Step 5: Determine Traversal Continuation
    # Compare midpoint to center
    if U_mid < center:
        return U_entry, U_exit, True # Break

    # Handle side faces for smooth terrain
    if mask.x: # Entered on X-axis
        # Compute boundary Y coordinates
        Y_left = get_voxel_y(voxel_index, 'left')
        Y_right = get_voxel_y(voxel_index, 'right')
        Y_min_max = (Y_left + Y_right) * 0.5
        Y_height = U_entry.x * (Y_min_max.y - Y_min_max.x) + Y_min_max.x
        if U_entry.y < Y_height:
            return U_entry, U_exit, True # Break

    return U_entry, U_exit, False # Continue
```

## Operating characteristics
- **Time Complexity**: O(1) per voxel step, with additional constant-time operations for UV calculation and midpoint comparison.
- **Memory Complexity**: O(1) additional memory for UV and midpoint variables.
- **Strengths**: Enables smooth terrain rendering by providing precise UV coordinates for surface interpolation.
- **Limitations**: Requires careful handling of mask conditions and traversal direction (upward/downward). Precision issues may arise near voxel boundaries.
