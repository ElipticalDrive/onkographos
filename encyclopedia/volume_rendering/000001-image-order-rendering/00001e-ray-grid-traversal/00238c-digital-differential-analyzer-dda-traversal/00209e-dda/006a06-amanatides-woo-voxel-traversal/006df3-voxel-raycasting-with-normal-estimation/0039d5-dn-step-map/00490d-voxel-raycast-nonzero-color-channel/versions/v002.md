# Voxel Raycast (Nonzero/Color Channel)

Also called: Hidden Surface Elimination via Ray Casting, Visible Surface Detection, zylann::voxel_raycast with Color Predicate

## Overview
This method performs hidden surface elimination by casting a ray through a voxel volume to locate the first voxel where a specific data channel is non-zero (or a 1-voxel in a binary array) [S1, unofficial][S2]. It differs from standard DDA traversal by optimizing for sparse or binary data: it processes voxels in groups of eight packed into a single byte, advancing the ray by whole bytes when the group is empty, thereby skipping large empty regions efficiently [S2].

## How it works
**Inputs:**
- Ray origin $\mathbf{O}$ and direction $\mathbf{D}$ (normalized) [G].
- Voxel grid data structure containing binary or channel-based voxel values [S2].
- Channel index $c$ to evaluate for non-zero presence [S1, unofficial].
- Maximum ray distance $d_{max}$ [G].

**Outputs:**
- Hit position $\mathbf{P}_{hit}$ [S1, unofficial].
- Previous position $\mathbf{P}_{prev}$ (position before the hit) [S1, unofficial].
- Distance along ray $d_{hit}$ [S1, unofficial].
- Surface normal $\mathbf{N}$ [S1, unofficial].

**Data Structures:**
The voxel data is stored in a binary array where each byte holds eight voxels [S2]. A predicate structure `RaycastPredicateColor` holds a reference to the `VoxelData` and the target channel index $c$ [S1, unofficial].

**Steps:**
1. **Initialize Raycast Predicate:** Create a predicate object that encapsulates the voxel data and the channel index $c$ [S1, unofficial]. The predicate's evaluation function `operator()` takes a ray state (containing the current hit position) and returns true if the voxel value at that position for channel $c$ is non-zero [S1, unofficial].
2. **Execute Voxel Raycast:** Call the core raycasting routine with the ray origin, direction, the predicate, maximum distance, and output variables for hit/previous positions and distances [S1, unofficial].
3. **Byte-Level Traversal (Optimization):** Inside the traversal, the algorithm examines the voxel array along the ray's path [S2]. For rays aligned with main axes (X, Y, or ±Z), it reads one byte at a time [S2]. If the byte value is zero, it advances to the next byte, effectively skipping eight voxels simultaneously [S2].
4. **Hit Detection:** If the byte value is non-zero, the algorithm identifies that a surface voxel exists within that byte [S2].
5. **Voxel Extraction:** The specific surface voxel is retrieved by applying a bitmask to the non-zero byte to isolate the exact voxel corresponding to the ray's current position [S2].
6. **Result Construction:** Upon a successful hit, instantiate a `VoxelRaycastResult` object [S1, unofficial]. Set the position to the hit location, the previous position to the location before the hit, the distance to the hit distance, and compute the normal as the normalized vector from the previous position to the hit position: $\mathbf{N} = \frac{\mathbf{P}_{hit} - \mathbf{P}_{prev}}{\|\mathbf{P}_{hit} - \mathbf{P}_{prev}\|}$ [S1, unofficial].

**Pseudocode:**
```python
def voxel_raycast_nonzero_color(origin, direction, voxel_data, grid_dims, channel_index, max_distance):
    """
    Casts a ray to find the first voxel where the specified channel is non-zero.
    Optimized for byte-packed voxel data (8 voxels per byte) along main axes.
    """
    # Determine traversal axis and stride based on dominant direction component
    if abs(direction[0]) > 0.5:
        axis, stride = 0, 1
    elif abs(direction[1]) > 0.5:
        axis, stride = 1, grid_dims[0] // 8
    else:
        axis, stride = 2, (grid_dims[0] * grid_dims[1]) // 8

    voxels_per_byte = 8
    step_size = max_distance / (grid_dims[axis] // voxels_per_byte + 1)
    
    t = 0.0
    prev_pos = list(origin)
    byte_idx = 0
    
    while t <= max_distance:
        # Read byte from the packed voxel array
        byte_val = voxel_data[byte_idx]
        
        if byte_val != 0:
            # Find first set bit (or non-zero channel bit) within this byte
            for bit in range(8):
                if byte_val & (1 << bit):
                    hit_pos = list(prev_pos)
                    hit_pos[axis] += bit * step_size
                    normal = [0.0, 0.0, 0.0]
                    normal[axis] = 1.0 if direction[axis] > 0 else -1.0
                    return {
                        "position": hit_pos,
                        "previous_position": prev_pos,
                        "distance_along_ray": t + bit * step_size,
                        "normal": normal
                    }
        
        # Advance to next byte
        t += step_size * 8
        prev_pos = list(prev_pos)
        byte_idx += stride
        if byte_idx >= len(voxel_data):
            break
            
    return None
```

**Edge Cases and Pitfalls:**
- **Byte Alignment:** The algorithm assumes the voxel array is stored such that each byte holds eight voxels, allowing 8 voxels to be examined simultaneously along main axes [S2]. If the data is not packed this way, the optimization fails or produces incorrect results.
- **Bit Masking:** The specific surface voxel must be correctly extracted from the byte using masking [S2].
- **Precision:** Floating-point precision in ray position calculation may cause jitter or missed hits in sparse volumes if not handled with epsilon checks [G].

## Operating characteristics
- **Time Complexity:** $O(k)$ where $k$ is the number of empty bytes traversed before a hit [G]. In sparse volumes, this is significantly faster than per-voxel traversal [S2].
- **Memory Complexity:** $O(1)$ auxiliary memory, as it operates on the existing voxel data structure [G].
- **Strengths:** Extremely fast for binary or sparse data where large empty regions are common [S2]. Simple to implement if the data format is known [G].
- **Limitations:** Only works for finding the *first* non-zero voxel [S1, unofficial][S2]. Not suitable for volume rendering requiring integration through the entire ray [G]. Requires specific data packing (8 voxels/byte) [S2].
- **When to use:** Hidden surface elimination, collision detection in binary voxel worlds, visible surface detection [S2].
- **When not to use:** Volume rendering with transparency, continuous field evaluation, or when data is not packed in 8-voxel bytes [G].

## Background
The concept of hidden surface elimination via ray casting in binary voxel models was introduced in "Hardware Support for the Display and Manipulation of Binary Voxel Models" (1988) [S2]. The specific optimization of examining eight voxels per byte was described in that work [S2]. The modern implementation in `zylann::voxel_raycast` is part of the Zylann Voxel plugin for Godot, integrating it with general-purpose voxel data structures [S1, unofficial].
