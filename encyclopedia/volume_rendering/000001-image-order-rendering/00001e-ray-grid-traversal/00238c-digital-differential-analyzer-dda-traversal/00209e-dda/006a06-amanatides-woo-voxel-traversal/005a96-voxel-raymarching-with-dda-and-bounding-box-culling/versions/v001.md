# Voxel Raymarching with DDA and Bounding Box Culling

Also called: Voxel Raymarching, Voxel Raymarching with DDA

## Overview
Voxel Raymarching with DDA and Bounding Box Culling is an image-order rendering technique for sparse, segmented voxel models. It solves the problem of efficiently rendering large voxel volumes by treating the model as a bounding box mesh where the fragment shader ignores the geometry and instead casts a ray from the eye through the pixel. The ray intersects the box analytically to find the entry point, then steps through the voxel grid using Digital Differential Analyzer (DDA) traversal until it finds a non-empty voxel or leaves the box [S1, unofficial]. It sets itself apart from sibling methods by explicitly decoupling the ray origin from the box surface intersection to avoid floating-point boundary errors, and by using a segment directory to manage sparse 3D texture arrays [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
*   **Voxel Data:** A sparse voxel model split into 128×128×128 voxel segments (bricks). Each segment is stored as an R8 3D texture (one byte per voxel, holding a palette index) [S1, unofficial].
*   **Segment Directory:** A 2D texture listing active segments. Each entry contains the segment's 3D grid coordinates (X, Y, Z) and its index in the bound texture array [S1, unofficial].
*   **Palette:** A 256×1 RGBA8 texture mapping palette indices to colors [S1, unofficial].
*   **Camera State:** Eye offset, screen UV, projection matrix, view matrix, and inverse model matrix [S1, unofficial].
*   **Bounding Box:** `box_center` (Vector3) and `box_size` (Vector3) defining the volume in voxel space [S1, unofficial].
*   **Lighting:** `light_position` in voxel space [S1, unofficial].

**Outputs:**
*   **Albedo:** The color of the first hit voxel, lit by the point light [S1, unofficial].
*   **Depth:** The depth of the hit voxel surface in clip space [S1, unofficial].

### Data Structures
*   **Segment Brick Textures:** An array of `Texture3D` objects. Each texture is 128³ voxels, R8 format. The array order matches the directory entries [S1, unofficial].
*   **Segment Directory:** A 2D texture where each texel `i` stores `(segX, segY, segZ, textureSlot)` as floats. The `textureSlot` is the index into the `segment_voxels` array [S1, unofficial].
*   **Palette Texture:** 256×1 RGBA8. Colors are stored as `uint` 0xRRGGBBAA, reversed to 0xAABBGGRR so little-endian memory bytes are R, G, B, A. Read as sRGB in the shader [S1, unofficial].
*   **Bounding Box Uniforms:** `box_center` and `box_size` passed to the shader [S1, unofficial].

### Steps
1.  **Compute Per-Eye Ray Origin and Direction:**
    *   Transform `EYE_OFFSET` (per-eye offset in midpoint view space) to world space:
        $$ \text{camera\_world} = (\text{INV\_VIEW\_MATRIX} \times \text{vec4}(\text{EYE\_OFFSET}, 1.0)).\text{xyz} $$
    *   Unproject `SCREEN_UV` through the inverse projection matrix into view space, normalize the vector from `EYE_OFFSET` to the unprojected point, then transform direction to world space:
        $$ \text{view\_frag} = \text{INV\_PROJECTION\_MATRIX} \times \text{vec4}(\text{SCREEN\_UV} \times 2.0 - 1.0, 0.0, 1.0) $$
        $$ \text{view\_frag} /= \text{view\_frag}.w $$
        $$ \text{ray\_dir\_view} = \text{normalize}(\text{view\_frag}.xyz - \text{EYE\_OFFSET}) $$
        $$ \text{ray\_world\_dir} = \text{normalize}((\text{INV\_VIEW\_MATRIX} \times \text{vec4}(\text{ray\_dir\_view}, 0.0)).xyz) $$
    *   Transform ray origin and direction to voxel space using the inverse model matrix:
        $$ \text{camera\_voxel} = (\text{inv\_model\_matrix} \times \text{vec4}(\text{camera\_world}, 1.0)).xyz + \text{box\_center} $$
        $$ \text{ray\_dir} = \text{normalize}((\text{inv\_model\_matrix} \times \text{vec4}(\text{ray\_world\_dir}, 0.0)).xyz) $$
    *   Compute box bounds in voxel space:
        $$ \text{box\_min} = \text{box\_center} - \text{box\_size} \times 0.5 $$
        $$ \text{box\_max} = \text{box\_center} + \text{box\_size} \times 0.5 $$

2.  **March Through the Box:**
    *   Perform a ray-AABB slab test to find the entry point `t_entry` and exit point `t_exit` of the ray with the bounding box [S1, unofficial].
    *   If the ray misses the box, discard the pixel.
    *   Start DDA traversal from the entry point. The traversal steps through voxels along the ray path.
    *   For each voxel visited, sample the corresponding 3D texture from the `segment_voxels` array using the segment directory to find the correct texture index.
    *   If a non-empty voxel (palette index > 0) is found, record the hit position, normal, and material ID. If the ray exits the box without finding a non-empty voxel, discard the pixel.

3.  **Compute Lighting:**
    *   Calculate point light lighting with 30% ambient and 70% diffuse:
        $$ \text{to\_light} = \text{normalize}(\text{light\_position} - \text{hit\_pos}) $$
        $$ \text{lighting} = \max(\text{dot}(\text{normal}, \text{to\_light}), 0.0) \times 0.7 + 0.3 $$
    *   Clamp back-facing normals to 0 [S1, unofficial].

4.  **Output Albedo:**
    *   Retrieve the palette color by material index:
        $$ \text{ALBEDO} = \text{get\_material\_color}(\text{material}) \times \text{lighting} $$

5.  **Write Depth:**
    *   Transform `hit_pos` from voxel space to mesh-local (subtract `box_center`), then to world (`MODEL_MATRIX`), then to clip space (`PROJECTION_MATRIX * VIEW_MATRIX`), and write normalized depth:
        $$ \text{hit\_clip} = \text{PROJECTION\_MATRIX} \times \text{VIEW\_MATRIX} \times \text{MODEL\_MATRIX} \times \text{vec4}(\text{hit\_pos} - \text{box\_center}, 1.0) $$
        $$ \text{DEPTH} = \text{hit\_clip}.z / \text{hit\_clip}.w $$

### Pseudocode
```python
# Fragment Shader Entry Point
fragment_shader(SCREEN_UV, EYE_OFFSET, INV_PROJECTION_MATRIX, INV_VIEW_MATRIX, 
                MODEL_MATRIX, INV_MODEL_MATRIX, PROJECTION_MATRIX, 
                box_center, box_size, segment_directory, segment_voxels, palette, 
                light_position):
    
    # 1. Compute Per-Eye Ray Origin and Direction
    camera_world = (INV_VIEW_MATRIX * vec4(EYE_OFFSET, 1.0)).xyz
    view_frag = INV_PROJECTION_MATRIX * vec4(SCREEN_UV * 2.0 - 1.0, 0.0, 1.0)
    view_frag = view_frag / view_frag.w
    ray_dir_view = normalize(view_frag.xyz - EYE_OFFSET)
    ray_world_dir = normalize((INV_VIEW_MATRIX * vec4(ray_dir_view, 0.0)).xyz)
    
    camera_voxel = (INV_MODEL_MATRIX * vec4(camera_world, 1.0)).xyz + box_center
    ray_dir = normalize((INV_MODEL_MATRIX * vec4(ray_world_dir, 0.0)).xyz)
    
    box_min = box_center - box_size * 0.5
    box_max = box_center + box_size * 0.5
    
    # 2. March Through the Box
    t_entry, t_exit, normal, hit_pos, material_id = march_box(camera_voxel, ray_dir, box_min, box_max, segment_directory, segment_voxels)
    
    if material_id == 0:
        discard # Miss
    
    # 3. Compute Lighting
    to_light = normalize(light_position - hit_pos)
    lighting = max(dot(normal, to_light), 0.0) * 0.7 + 0.3
    
    # 4. Output Albedo
    albedo = get_material_color(material_id, palette) * lighting
    
    # 5. Write Depth
    hit_clip = PROJECTION_MATRIX * VIEW_MATRIX * MODEL_MATRIX * vec4(hit_pos - box_center, 1.0)
    depth = hit_clip.z / hit_clip.w
    
    return albedo, depth

# Helper: March Box using DDA
march_box(origin, ray_dir, box_min, box_max, segment_directory, segment_voxels):
    # Ray-AABB Slab Test
    inv_ray_dir = 1.0 / ray_dir
    t0 = (box_min - origin) * inv_ray_dir
    t1 = (box_max - origin) * inv_ray_dir
    t_near = max(max(min(t0.x, t1.x), min(t0.y, t1.y)), min(t0.z, t1.z))
    t_far = min(min(max(t0.x, t1.x), max(t0.y, t1.y)), max(t0.z, t1.z))
    
    if t_near > t_far or t_far < 0:
        return 0, 0, vec3(0), vec3(0), 0 # Miss
    
    # Start DDA at t_near
    current_pos = origin + ray_dir * t_near
    current_voxel = floor(current_pos)
    
    # DDA Step Calculation
    step_x = sign(ray_dir.x)
    step_y = sign(ray_dir.y)
    step_z = sign(ray_dir.z)
    
    t_max_x = (box_min.x if step_x < 0 else box_max.x - current_voxel.x) / ray_dir.x
    t_max_y = (box_min.y if step_y < 0 else box_max.y - current_voxel.y) / ray_dir.y
    t_max_z = (box_min.z if step_z < 0 else box_max.z - current_voxel.z) / ray_dir.z
    
    t_delta_x = abs(1.0 / ray_dir.x)
    t_delta_y = abs(1.0 / ray_dir.y)
    t_delta_z = abs(1.0 / ray_dir.z)
    
    while t_near <= t_far:
        # Sample voxel
        segment_id = get_segment_id(current_voxel)
        texture_index = get_texture_index(segment_id, segment_directory)
        
        if texture_index != -1:
            voxel_data = texelFetch(segment_voxels[texture_index], current_voxel % 128).r
            if voxel_data > 0:
                # Hit found
                hit_pos = origin + ray_dir * t_near
                normal = compute_normal(current_voxel, hit_pos, ray_dir)
                return t_near, t_far, normal, hit_pos, voxel_data
        
        # Advance DDA
        if t_max_x < t_max_y:
            if t_max_x < t_max_z:
                current_voxel.x += step_x
                t_near += t_delta_x
                t_max_x += t_delta_x
            else:
                current_voxel.z += step_z
                t_near += t_delta_z
                t_max_z += t_delta_z
        else:
            if t_max_y < t_max_z:
                current_voxel.y += step_y
                t_near += t_delta_y
                t_max_y += t_delta_y
            else:
                current_voxel.z += step_z
                t_near += t_delta_z
                t_max_z += t_delta_z
                
        # Check bounds
        if not inside_box(current_voxel, box_min, box_max):
            break
            
    return 0, 0, vec3(0), vec3(0), 0 # Miss
```

### Parameters
*   **Segment Size:** 128×128×128 voxels per segment [S1, unofficial].
*   **View Distance:** Camera positioned at 2.5 times the model's largest dimension from the model center [S1, unofficial].
*   **Light Position:** Default `vec3(50.0, 50.0, 25.0)` in voxel space [S1, unofficial].
*   **Inv Model Matrix:** Inverse of the MeshInstance's GlobalTransform, precomputed on the CPU every frame [S1, unofficial].

### Edge Cases and Pitfalls
*   **Bounds Update:** When model bounds change, the bounding box mesh size and position must be updated, and shader uniforms `box_center` and `box_size` must be refreshed. Otherwise, rays will start in the wrong place [S1, unofficial].
*   **Ray Origin Precision:** Starting the ray at the interpolated box-surface position causes fuzzy faces, wrong first-hit lighting, and vanishing faces for faces at coordinate 0 due to `floor()` boundary float errors. This is solved by intersecting the ray with the box analytically and clamping the origin just inside it [S1, unofficial].
*   **Depth Buffer:** Without writing depth at the hit voxel surface, the depth buffer holds the depth of the box's back face. This causes other geometry to intersect the model as if it were a solid box, and in VR the OpenXR compositor uses depth for reprojection, warping a flat box as a plane and canceling per-eye parallax [S1, unofficial].
*   **Coordinate Systems:** Voxel data uses Z-up (MagicaVoxel). Godot uses Y-up. C# code converts voxel coordinates `(x, y, z)_zup` to world coordinates `(x, z, y)_yup`. The shader converts back when reading voxels [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of voxels traversed along the ray. The DDA traversal is efficient for sparse volumes as it skips empty space.
*   **Memory Complexity:** Proportional to the number of active segments. Each segment is a 128³ R8 texture (2 MB). The directory texture is small.
*   **Strengths:** Efficient for sparse voxel models. Avoids floating-point boundary errors by using analytical ray-box intersection. Works well in VR due to correct depth writing.
*   **Limitations:** Requires precomputed inverse model matrix. Performance depends on the density of the voxel model.
*   **When to Use:** Sparse voxel models with large empty spaces. VR applications requiring correct depth for reprojection.
*   **When Not to Use:** Dense voxel models where ray traversal becomes expensive. Models with frequent dynamic changes requiring frequent bound updates.

## Background
This method is implemented in the `Voxel2Pixel` graphics library by Ben McLean [S1, unofficial]. It is designed for use in Godot Engine for rendering voxel models in VR and desktop environments. The method builds on the Amanatides-Woo Voxel Traversal algorithm for efficient ray traversal through voxel grids [S1, unofficial].
