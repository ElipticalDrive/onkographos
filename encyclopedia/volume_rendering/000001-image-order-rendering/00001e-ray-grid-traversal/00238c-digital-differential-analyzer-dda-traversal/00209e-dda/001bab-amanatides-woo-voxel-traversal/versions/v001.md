# Amanatides–Woo Voxel Traversal

Also called: 3D DDA, DDA Raycasting for Voxels, Digital Differential Analyzer Raycasting, Fast Voxel Traversal Algorithm, Ray Marching with Grid Crossing

## Overview
The Amanatides–Woo algorithm efficiently enumerates the uniform grid cells intersected by a ray in front-to-back order by jumping exactly from one grid boundary to the next, avoiding the pitfalls of naïve ray marching such as missing thin cells, redundant work, and arbitrary step sizes [S1, S2, unofficial]. It serves as the foundational traversal method for image-order volume rendering and voxel-based ray casting, building on [Ray-grid traversal](17-ray-grid-traversal.md) by providing an output-sensitive $O(K)$ approach where $K$ is the number of visited cells [S1, unofficial].

## How it works
**Inputs:** Ray origin $P = (P_x, P_y, P_z)$, ray direction $D = (D_x, D_y, D_z)$ (normalized or unnormalized, but non-zero magnitude), voxel grid bounds $[x_{min}, x_{max}] \times [y_{min}, y_{max}] \times [z_{min}, z_{max}]$, and voxel size $V$ (assumed uniform, typically $V=1$ for unit grids).
**Outputs:** A sequence of voxel indices $(i, j, k)$ visited in order of increasing ray parameter $t$, optionally with the entry point and normal for the first hit.

**Data Structures:**
*   `voxel`: Integer tuple $(i, j, k)$ representing the current cell index.
*   `step`: Integer tuple $(s_x, s_y, s_z)$ where $s \in \{-1, 0, 1\}$.
*   `t_delta`: Float tuple $(\Delta t_x, \Delta t_y, \Delta t_z)$ representing the $t$-distance between successive grid plane crossings on each axis.
*   `t_max`: Float tuple $(T_x, T_y, T_z)$ representing the ray parameter $t$ at which the ray crosses the *next* grid boundary on each axis.

**Parameters:**
*   Voxel size $V$: Not given in the sources (assumed 1 in standard derivations, scaled in implementation) [S1, S2, unofficial].
*   Ray bounds: $t_{min}$ (entry into grid) and $t_{max}$ (exit or max ray length) [S1, S3, unofficial].

**Step-by-Step Method:**

1.  **Initialize Direction and Step Signs:**
    For each axis $a \in \{x, y, z\}$:
    *   If $D_a > 0$: $s_a = 1$, $t_{max, a}$ targets the upper boundary.
    *   If $D_a < 0$: $s_a = -1$, $t_{max, a}$ targets the lower boundary.
    *   If $D_a = 0$: $s_a = 0$, $t_{max, a} = \infty$, $\Delta t_a = \infty$ [S1, S2, unofficial].

2.  **Calculate $\Delta t$ (Step Size in $t$):**
    For each axis $a$ where $D_a \neq 0$:
    $$ \Delta t_a = \frac{V}{|D_a|} $$
    If $D_a = 0$, $\Delta t_a = \infty$ [S1, S2, unofficial].

3.  **Determine Starting Voxel and Initial $t_{max}$:**
    *   Calculate the starting voxel index: $i = \lfloor \frac{P_x - x_{min}}{V} \rfloor$, $j = \lfloor \frac{P_y - y_{min}}{V} \rfloor$, $k = \lfloor \frac{P_z - z_{min}}{V} \rfloor$ [S1, S2, unofficial].
    *   Calculate the fractional distance into the current voxel: $f_a = \frac{P_a - (i \cdot V + x_{min})}{V}$ for $a \in \{x, y, z\}$ [S2, unofficial].
    *   Calculate the distance to the next boundary in $t$:
        $$ T_a = \begin{cases} (1.0 - f_a) \cdot \Delta t_a & \text{if } D_a > 0 \\ f_a \cdot \Delta t_a & \text{if } D_a < 0 \\ \infty & \text{if } D_a = 0 \end{cases} $$
        *Note: If the origin is exactly on a boundary, floating-point conventions must be handled carefully to avoid ambiguity [S1, unofficial].*

4.  **Traverse:**
    While the current voxel $(i, j, k)$ is within the grid bounds and $t < t_{max, ray}$:
    1.  Visit voxel $(i, j, k)$ [S1, S2, unofficial].
    2.  Identify the axis with the smallest $T_a$.
    3.  Update the voxel index for that axis: $idx_{axis} += s_{axis}$ [S1, S2, unofficial].
    4.  Update the $t_{max}$ for that axis: $T_{axis} += \Delta t_{axis}$ [S1, S2, unofficial].
    5.  (Optional) Track the last moved axis to determine the surface normal of the hit voxel if a collision is detected [S2, unofficial].

**Pseudocode:**

```python
def amanatides_woo_traverse(origin, direction, grid_min, grid_max, voxel_size=1.0, max_t=float('inf')):
    """
    Traverses a uniform voxel grid along a ray.
    
    Args:
        origin: (x, y, z) ray origin
        direction: (dx, dy, dz) ray direction
        grid_min: (xmin, ymin, zmin) minimum bounds of the grid
        grid_max: (xmax, ymax, zmax) maximum bounds of the grid
        voxel_size: size of each voxel (default 1.0)
        max_t: maximum ray parameter to traverse
        
    Yields:
        (i, j, k): voxel indices visited in order
    """
    # 1. Initialize step signs and handle zero direction components
    step = []
    t_delta = []
    t_max = []
    
    for axis_idx, (p, d) in enumerate(zip(origin, direction)):
        if d > 0:
            step.append(1)
        elif d < 0:
            step.append(-1)
        else:
            step.append(0)
            
        # Calculate delta t: distance in t between grid crossings
        if d != 0:
            t_delta.append(voxel_size / abs(d))
        else:
            t_delta.append(float('inf'))
            
        # Calculate initial t_max: distance to the first grid boundary
        # Determine the coordinate of the first boundary
        if d > 0:
            boundary_coord = (floor((p - grid_min[axis_idx]) / voxel_size) + 1) * voxel_size + grid_min[axis_idx]
        elif d < 0:
            boundary_coord = floor((p - grid_min[axis_idx]) / voxel_size) * voxel_size + grid_min[axis_idx]
        else:
            boundary_coord = p # Never crosses
            
        # Calculate t to reach that boundary
        if d != 0:
            t_max.append((boundary_coord - p) / d)
        else:
            t_max.append(float('inf'))

    # 2. Determine starting voxel index
    # Using floor for positive direction logic consistent with boundary calculation above
    # Note: Implementation must ensure consistency with the boundary calculation logic
    current_voxel = []
    for axis_idx, (p, g_min) in enumerate(zip(origin, grid_min)):
        # Calculate index of the voxel containing the origin
        # This must match the logic used to derive t_max
        idx = floor((p - g_min) / voxel_size)
        current_voxel.append(idx)

    # 3. Traverse loop
    while True:
        # Check bounds
        if not (grid_min[0] <= current_voxel[0] * voxel_size + grid_min[0] < grid_max[0] and
                grid_min[1] <= current_voxel[1] * voxel_size + grid_min[1] < grid_max[1] and
                grid_min[2] <= current_voxel[2] * voxel_size + grid_min[2] < grid_max[2]):
            break
            
        # Check max_t
        # We need to know the current t. In this simple traversal, we can track it 
        # or just rely on t_max values. The loop condition usually checks if the 
        # smallest t_max is within max_t.
        min_t_max = min(t_max)
        if min_t_max > max_t:
            break
            
        yield tuple(current_voxel)
        
        # Find which axis has the smallest t_max
        # Tie-breaking: The original paper suggests deterministic handling. 
        # Here we pick the first minimum found.
        min_axis = 0
        if t_max[1] < t_max[min_axis]:
            min_axis = 1
        if t_max[2] < t_max[min_axis]:
            min_axis = 2
            
        # Step in that axis
        current_voxel[min_axis] += step[min_axis]
        t_max[min_axis] += t_delta[min_axis]

```

**Edge Cases and Pitfalls:**
*   **Ties:** If two or three $t_{max}$ values are equal, the ray hits an edge or corner. A strict `if/else` chain may skip cells. Solutions include stepping all tied axes simultaneously, emitting all "supercover" cells, or using a deterministic half-open convention [S1, unofficial].
*   **Zero Direction Components:** If $D_a = 0$, the ray never crosses planes on that axis. Set $\Delta t_a$ and $T_a$ to $\infty$ to avoid branching in the loop. Avoid $0 \times \infty$ NaNs by initializing these axes separately [S1, unofficial].
*   **Boundary Conventions:** Origins exactly on voxel planes can cause `floor` operations to place the origin in a neighboring cell. Define a clear half-open interval convention and test points just below, on, and above boundaries [S1, unofficial].
*   **Numerical Robustness:** Large world coordinates, small direction components, and negative zero can cause precision issues. Avoid adding random epsilons; use explicit conventions and targeted tolerance [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(K)$, where $K$ is the number of visited cells. The algorithm performs constant work per crossed voxel and does not inspect untouched cells [S1, unofficial].
*   **Memory Complexity:** $O(1)$ auxiliary space, storing only a few vectors per ray [S1, unofficial].
*   **Strengths:** Extremely fast per-voxel update (a few comparisons and one addition); output-sensitive; robust for uniform grids [S1, unofficial].
*   **Limitations:** Only suitable for uniform grids; performance degrades if the ray traverses many empty cells (though better than marching); requires careful handling of ties and boundaries [S1, unofficial].
*   **When to use:** Volume rendering, voxel-based collision detection, and any scenario requiring efficient traversal of a uniform spatial grid [S1, S2, unofficial].
*   **When not to use:** Non-uniform grids (use hierarchical methods like [Hierarchical Traversal](896-hierarchical-traversal.md) or [HDDA](1122-hierarchical-digital-differential-analyzer-hdda.md)), or when sparse data structures are preferred [S1, unofficial].

## Background
The algorithm was introduced by John Amanatides and Andrew Woo in the paper "A Fast Voxel Traversal Algorithm for Ray Tracing," published at Eurographics in 1987 [S1, unofficial]. It is a classic example of transforming continuous ray geometry into a discrete event sequence, optimizing the inner loop for ray tracing performance [S1, unofficial]. It is widely used in voxel engines, medical imaging (e.g., CT reconstruction), and real-time graphics [S2, S3, unofficial].
