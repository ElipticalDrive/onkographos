# Amanatides–Woo Voxel Traversal

Also called: 3D DDA, Amanatides-Woo 3D DDA, Fast Voxel Traversal Algorithm

## Overview
The Amanatides–Woo algorithm efficiently enumerates the uniform grid cells intersected by a ray in front-to-back order by jumping exactly from one grid boundary to the next, avoiding the pitfalls of naïve ray marching such as missing thin cells, redundant work, and arbitrary step sizes [S2, unofficial]. It serves as the foundational traversal method for image-order volume rendering and voxel-based ray casting, building on [Ray-grid traversal](17-ray-grid-traversal.md) by providing an output-sensitive $O(K)$ approach where $K$ is the number of visited cells [S1, unofficial, S2, unofficial].

## How it works
**Inputs:** Ray origin $O = (O_x, O_y, O_z)$, ray direction $D = (D_x, D_y, D_z)$ (non-zero magnitude), voxel grid index bounds $[x_{min}, x_{max}) \times [y_{min}, y_{max}) \times [z_{min}, z_{max})$, and voxel size $V$ (typically $V=1$ for unit grids) [S1, unofficial, S2, unofficial].
**Outputs:** A sequence of voxel indices $(i, j, k)$ visited in front-to-back order. Optionally, the hit voxel position and the normalized face normal of the crossed boundary [S2, unofficial, S3, unofficial].

**Data Structures:**
*   `voxel`: Integer tuple $(i, j, k)$ representing the current cell index [S1, unofficial].
*   `step`: Integer tuple $(s_x, s_y, s_z)$ where $s_a \in \{-1, 0, 1\}$ [S1, unofficial, S2, unofficial].
*   `t_delta`: Float tuple $(\Delta t_x, \Delta t_y, \Delta t_z)$ representing the $t$-distance between successive grid plane crossings on each axis [S1, unofficial, S2, unofficial].
*   `t_max`: Float tuple $(T_x, T_y, T_z)$ representing the ray parameter $t$ at which the ray crosses the *next* grid boundary on each axis [S1, unofficial, S2, unofficial].

**Parameters:**
*   Voxel size $V$: Not given in the sources.
*   Ray bounds: $t_{enter}$ (entry into grid) and $t_{exit}$ (exit or max ray length) [S1, unofficial, S3, unofficial].

**Step-by-Step Method:**

1.  **Clip ray to grid AABB:** For each axis, compute entry and exit parameters. If the ray misses the grid, terminate. If the ray origin is inside the grid, $t_{enter}$ may be negative; start traversal at $t = \max(t_{enter}, 0.0)$ [S1, unofficial].
2.  **Initialize Direction and Step Signs:** For each axis $a \in \{x, y, z\}$: if $D_a > 0$, set $s_a = 1$; if $D_a < 0$, set $s_a = -1$; if $D_a = 0$, set $s_a = 0$ [S1, unofficial, S2, unofficial].
3.  **Calculate $\Delta t$ (Step Size in $t$):** For each axis $a$ where $D_a \neq 0$, compute $\Delta t_a = V / |D_a|$. If $D_a = 0$, set $\Delta t_a = \infty$ [S1, unofficial, S2, unofficial].
4.  **Determine Starting Voxel and Initial $t_{max}$:**
    *   Calculate the starting voxel index: $i = \lfloor P_x / V \rfloor$, $j = \lfloor P_y / V \rfloor$, $k = \lfloor P_z / V \rfloor$, where $P = O + t_{enter} D$. Clamp indices to $[x_{min}, x_{max})$, etc. [S1, unofficial, S2, unofficial].
    *   Calculate the fractional distance into the current voxel: $f_a = (P_a \bmod V) / V$ [S2, unofficial, S3, unofficial].
    *   Calculate the distance to the next boundary in $t$:
        $$ T_a = \begin{cases} (1.0 - f_a) \cdot \Delta t_a & \text{if } D_a > 0 \\ f_a \cdot \Delta t_a & \text{if } D_a < 0 \\ \infty & \text{if } D_a = 0 \end{cases} $$
        *Note: If the origin is exactly on a boundary, floating-point conventions must be handled carefully to avoid ambiguity [S1, unofficial].*
5.  **Traverse:** While the current voxel $(i, j, k)$ is within the grid bounds and current $t \le t_{exit}$:
    1.  Visit voxel $(i, j, k)$ [S1, unofficial, S2, unofficial].
    2.  Identify the axis with the smallest $T_a$ [S1, unofficial, S2, unofficial].
    3.  Update the voxel index for that axis: $idx_{axis} += s_{axis}$ [S1, unofficial, S2, unofficial].
    4.  Update the $t_{max}$ for that axis: $T_{axis} += \Delta t_{axis}$ [S1, unofficial, S2, unofficial].
    5.  Update current $t \leftarrow T_{axis}$.
    6.  (Optional) Track the last moved axis to determine the surface normal of the hit voxel if a collision is detected [S2, unofficial, S3, unofficial].

**Pseudocode:**

```python
import math

def amanatides_woo(origin, direction, grid_min, grid_max, voxel_size=1.0, max_t=float('inf')):
    """
    Traverses a uniform voxel grid along a ray in front-to-back order.
    Assumes origin is already clipped to the grid's AABB if outside.
    grid_min and grid_max are exclusive index bounds for each axis.
    """
    # 1. Clip ray to grid AABB
    t_enter = -float('inf')
    t_exit = float('inf')
    for axis in range(3):
        if abs(direction[axis]) < 1e-6:
            if not (grid_min[axis] <= origin[axis] < grid_max[axis]):
                return # Ray misses grid
        else:
            inv = 1.0 / direction[axis]
            t_a = (grid_min[axis] - origin[axis]) * inv
            t_b = (grid_max[axis] - origin[axis]) * inv
            if t_a > t_b:
                t_a, t_b = t_b, t_a
            t_enter = max(t_enter, t_a)
            t_exit = min(t_exit, t_b)
    if t_exit < max(t_enter, 0.0):
        return # Ray misses grid

    # 2. Start at entry point
    t = max(t_enter, 0.0)
    pos = [origin[i] + t * direction[i] for i in range(3)]

    # 3. Initial voxel indices
    voxel = [int(math.floor(pos[i] / voxel_size)) for i in range(3)]
    for i in range(3):
        voxel[i] = max(grid_min[i], min(voxel[i], grid_max[i] - 1))

    # 4. Step signs
    step = [0, 0, 0]
    for i in range(3):
        if direction[i] > 0: step[i] = 1
        elif direction[i] < 0: step[i] = -1

    # 5. t_delta and t_max
    t_delta = [0.0, 0.0, 0.0]
    t_max = [0.0, 0.0, 0.0]
    for i in range(3):
        if abs(direction[i]) > 1e-6:
            t_delta[i] = voxel_size / abs(direction[i])
            fract = (pos[i] / voxel_size) - voxel[i]
            if direction[i] > 0:
                t_max[i] = (1.0 - fract) * t_delta[i]
            else:
                t_max[i] = fract * t_delta[i]
        else:
            t_delta[i] = float('inf')
            t_max[i] = float('inf')

    # 6. Traverse loop
    while True:
        if not (grid_min[0] <= voxel[0] < grid_max[0] and
                grid_min[1] <= voxel[1] < grid_max[1] and
                grid_min[2] <= voxel[2] < grid_max[2]):
            break
        if t > t_exit:
            break

        yield tuple(voxel)

        # Find axis with smallest t_max
        min_axis = 0
        if t_max[1] < t_max[min_axis]: min_axis = 1
        if t_max[2] < t_max[min_axis]: min_axis = 2

        voxel[min_axis] += step[min_axis]
        t_max[min_axis] += t_delta[min_axis]
        t = t_max[min_axis]
```

**Edge Cases and Pitfalls:**
*   **Ties:** If two or three $t_{max}$ values are equal, the ray hits an edge or corner. A strict `if/else` chain may skip cells. Solutions include stepping all tied axes simultaneously, emitting all "supercover" cells, or using a deterministic half-open convention [S1, unofficial, S2, unofficial].
*   **Zero Direction Components:** If $D_a = 0$, the ray never crosses planes on that axis [S1, unofficial]. Set $\Delta t_a$ and $T_a$ to $\infty$ to avoid branching in the loop [S1, unofficial]. Avoid $0 \times \infty$ NaNs by initializing these axes separately [S1, unofficial, S2, unofficial].
*   **Boundary Conventions:** Origins exactly on voxel planes can cause `floor` operations to place the origin in a neighboring cell [S1, unofficial]. Define a clear half-open interval convention and test points just below, on, and above boundaries [S1, unofficial, S2, unofficial].
*   **Numerical Robustness:** Large world coordinates, small direction components, and negative zero can cause precision issues [S1, unofficial]. Avoid adding random epsilons; use explicit conventions and targeted tolerance [S1, unofficial, S2, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(K)$, where $K$ is the number of visited cells [S2, unofficial].
*   **Memory Complexity:** $O(1)$ auxiliary space, storing only a few vectors per ray [S1, unofficial, S2, unofficial].
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Not given in the sources.
*   **Strengths:** Extremely fast per-voxel update (a few comparisons and one addition); output-sensitive; robust for uniform grids [S1, unofficial, S2, unofficial].
*   **Limitations:** Only suitable for uniform grids; performance degrades if the ray traverses many empty cells (though better than marching); requires careful handling of ties and boundaries [S1, unofficial, S2, unofficial].
*   **When to use:** Volume rendering, voxel-based collision detection, and any scenario requiring efficient traversal of a uniform spatial grid [S1, unofficial, S2, unofficial].
*   **When not to use:** Non-uniform grids (the algorithm assumes uniform voxel sizes) [S1, unofficial, S2, unofficial].

## Background
The algorithm was introduced by John Amanatides and Andrew Woo in the paper "A Fast Voxel Traversal Algorithm for Ray Tracing," published at Eurographics in 1987 [S2, unofficial]. It is a classic example of transforming continuous ray geometry into a discrete event sequence, optimizing the inner loop for ray tracing performance [S1, unofficial, S2, unofficial]. It is widely used in voxel engines and real-time graphics [S2, unofficial, S3, unofficial]. CPU-based implementations are simpler for learning but less efficient than GPU compute shaders for large scenes [S1, unofficial].
