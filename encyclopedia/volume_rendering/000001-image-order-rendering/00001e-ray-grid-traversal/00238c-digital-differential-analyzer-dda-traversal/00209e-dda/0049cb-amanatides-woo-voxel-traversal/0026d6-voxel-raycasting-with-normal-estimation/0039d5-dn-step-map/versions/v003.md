# DN_step_map

Also called: Amanatides & Woo, Amanatides & Woo Ray Traversal, Digital Differential Analyzer raycast, Voxel Grid Raycasting (DDA), Voxel Raycasting / 3D DDA Block Traversal

## Overview
DN_step_map is a Digital Differential Analyzer (DDA) algorithm for traversing a regular 3D voxel grid along a ray to find the first occupied voxel [S1, S6, S7, unofficial]. It determines the sequence of voxels intersected by the ray without performing explicit geometric intersection tests with voxel faces, instead using precomputed boundary crossing distances [S1, S6, unofficial]. It sets itself apart from fixed-step marchers by stepping only when the ray crosses a voxel boundary, making it efficient for sparse or large grids, and from time-based marchers by using a reach-based parameter $t$ and precomputing deltas for efficiency [S6, unofficial]. It builds on [Voxel Raycasting with Normal Estimation](3901-voxel-raycasting-with-normal-estimation.md) by providing the core traversal mechanism that identifies the hit voxel and entry face.

## How it works
**Inputs:**
*   Ray origin $P = (p_x, p_y, p_z)$ in world or volume coordinates [S1, S7, unofficial].
*   Ray direction $D = (d_x, d_y, d_z)$, a non-zero vector [S1, S7, unofficial].
*   Grid parameters: cell size (often 1.0 in voxel coordinates) or bounds [S2, S6, unofficial].
*   Maximum traversal distance $t_{max}$ or maximum step count [S1, S6, S7, unofficial].
*   Occupancy query function `isOccupied(i, j, k)` [S6, unofficial].

**Outputs:**
*   Hit voxel index $(i, j, k)$ [S6, S7, unofficial].
*   Entry face normal (e.g., `neg-x`, `pos-y`) [S6, S7, unofficial].
*   Previous empty voxel index (for block placement logic) [S6, unofficial].
*   Boolean success flag [S3, S7, unofficial].

**Data Structures:**
*   Current voxel indices: $X, Y, Z$ (integers) [S1, S6, unofficial].
*   Step directions: $step_x, step_y, step_z \in \{-1, 0, 1\}$ [S1, S6, S7, unofficial].
*   Distance to next boundary: $t_{max\_x}, t_{max\_y}, t_{max\_z}$ (floats) [S1, S6, unofficial].
*   Distance increment per voxel: $t_{adv\_x}, t_{adv\_y}, t_{adv\_z}$ (floats) [S1, S6, unofficial].
*   Current traversal parameter $t$ (float) [S1, S6, unofficial].

**Algorithm Steps:**

1.  **Validate Direction:** If $|D| \le \epsilon$ (e.g., $10^{-5}$ or `f32::EPSILON`), return failure/null [S4, S6, S7, unofficial].
2.  **Initialize Current Voxel:** Compute starting voxel indices $X = \lfloor p_x \rfloor, Y = \lfloor p_y \rfloor, Z = \lfloor p_z \rfloor$ [S1, S4, S7, unofficial].
3.  **Check Start Voxel:** If the grid allows starting inside a solid voxel, check `isOccupied(X, Y, Z)`. If occupied, return $(X, Y, Z)$ with face normal $(0,0,0)$ and previous voxel $(X, Y, Z)$ [S7, G, unofficial]. *Note: Some implementations step first; if the origin is inside an occupied voxel, a pre-loop check is required to return the start voxel as hit, as the stepping loop moves to adjacent voxels [S6, G, unofficial].*
4.  **Compute Step Directions:**
    $$
    step_x = \begin{cases} 1 & \text{if } d_x > 0 \\ -1 & \text{if } d_x < 0 \\ 0 & \text{if } d_x = 0 \end{cases}
    $$
    (Same for $step_y, step_z$) [S6, S7, unofficial].
5.  **Compute Inverse Directions:**
    $$
    inv_x = \begin{cases} 1.0 / |d_x| & \text{if } |d_x| > \epsilon \\ \infty & \text{otherwise} \end{cases}
    $$
    (Same for $inv_y, inv_z$) [S7, unofficial].
6.  **Initialize Boundary Distances:**
    Calculate the distance to the next voxel boundary along each axis.
    For axis $x$:
    $$
    \text{nextBoundary}_x = \begin{cases} (X + 1) & \text{if } step_x = 1 \\ X & \text{if } step_x = -1 \end{cases}
    $$
    $$
    t_{max\_x} = \begin{cases} (\text{nextBoundary}_x - p_x) \cdot inv_x & \text{if } step_x \neq 0 \\ \infty & \text{if } step_x = 0 \end{cases}
    $$
    (Same for $y, z$) [S6, S7, unofficial].
    *Note: If using world coordinates with cell size $C$, replace boundaries with grid bounds or $X \cdot C$ [S2, S6, unofficial].*
7.  **Initialize Increments:**
    $$
    t_{adv\_x} = \begin{cases} inv_x & \text{if } step_x \neq 0 \\ \infty & \text{otherwise} \end{cases}
    $$
    (Same for $y, z$) [S1, S6, unofficial].
8.  **Traversal Loop:**
    While $t < t_{max}$ and steps $< HARD\_STEP\_CAP$ (e.g., 1024) [S1, S6, unofficial]:
    a.  **Find Minimum Axis:** Identify axis $A \in \{x, y, z\}$ with the smallest $t_{max\_A}$.
    b.  **Check Bounds:** If $t_{max\_A} > t_{max}$, break (ray exited volume) [S6, S7, unofficial].
    c.  **Advance Ray:** Set $t = t_{max\_A}$ [S1, S6, unofficial].
    d.  **Step Voxel:** Update current voxel index: $A \leftarrow A + step_A$ [S1, S6, S7, unofficial].
    e.  **Update Boundary:** Update $t_{max\_A} \leftarrow t_{max\_A} + t_{adv\_A}$ [S1, S6, S7, unofficial].
    f.  **Check Occupancy:** Query `isOccupied(X, Y, Z)`.
    g.  **On Hit:** Return hit voxel $(X, Y, Z)$, entry face (determined by $A$ and $step_A$), and previous empty voxel (calculated by reversing the step on the hit face) [S6, S7, unofficial].
9.  **Return Failure:** If loop completes without hit, return null/failure [S2, S6, S7, unofficial].

**Pseudocode:**

```python
def dn_step_map(origin, direction, max_dist, is_occupied):
    # 1. Validate direction
    dir_len = sqrt(direction.x**2 + direction.y**2 + direction.z**2)
    if dir_len < 1e-5:
        return None

    # Normalize direction
    dir = (direction.x / dir_len, direction.y / dir_len, direction.z / dir_len)
    
    # 2. Initialize current voxel
    curr_x = floor(origin.x)
    curr_y = floor(origin.y)
    curr_z = floor(origin.z)
    
    # 3. Check start voxel (if origin is inside a solid block)
    if is_occupied(curr_x, curr_y, curr_z):
        return {
            'hitVoxel': (curr_x, curr_y, curr_z),
            'hitFace': 'inside',
            'prevEmptyVoxel': (curr_x, curr_y, curr_z)
        }

    # 4. Compute step directions
    step_x = 1 if dir.x > 0 else (-1 if dir.x < 0 else 0)
    step_y = 1 if dir.y > 0 else (-1 if dir.y < 0 else 0)
    step_z = 1 if dir.z > 0 else (-1 if dir.z < 0 else 0)

    # 5. Compute inverse directions
    inv_x = 1.0 / abs(dir.x) if abs(dir.x) > 1e-5 else float('inf')
    inv_y = 1.0 / abs(dir.y) if abs(dir.y) > 1e-5 else float('inf')
    inv_z = 1.0 / abs(dir.z) if abs(dir.z) > 1e-5 else float('inf')

    # 6. Initialize boundary distances
    # Next boundary coordinates
    next_x = (curr_x + 1) if step_x == 1 else curr_x
    next_y = (curr_y + 1) if step_y == 1 else curr_y
    next_z = (curr_z + 1) if step_z == 1 else curr_z

    t_max_x = (next_x - origin.x) * inv_x if step_x != 0 else float('inf')
    t_max_y = (next_y - origin.y) * inv_y if step_y != 0 else float('inf')
    t_max_z = (next_z - origin.z) * inv_z if step_z != 0 else float('inf')

    # 7. Initialize increments
    t_adv_x = inv_x if step_x != 0 else float('inf')
    t_adv_y = inv_y if step_y != 0 else float('inf')
    t_adv_z = inv_z if step_z != 0 else float('inf')

    # 8. Traversal loop
    max_steps = 1024
    steps = 0
    t = 0.0
    
    while t < max_dist and steps < max_steps:
        # Find minimum axis
        if t_max_x <= t_max_y and t_max_x <= t_max_z:
            axis = 'x'
            t = t_max_x
        elif t_max_y <= t_max_z:
            axis = 'y'
            t = t_max_y
        else:
            axis = 'z'
            t = t_max_z
            
        if t > max_dist:
            break
            
        # Step voxel
        if axis == 'x':
            curr_x += step_x
            t_max_x += t_adv_x
            face = 'neg-x' if step_x == -1 else 'pos-x'
        elif axis == 'y':
            curr_y += step_y
            t_max_y += t_adv_y
            face = 'neg-y' if step_y == -1 else 'pos-y'
        else:
            curr_z += step_z
            t_max_z += t_adv_z
            face = 'neg-z' if step_z == -1 else 'pos-z'
            
        # Check occupancy
        if is_occupied(curr_x, curr_y, curr_z):
            # Calculate previous empty voxel
            prev_x, prev_y, prev_z = curr_x, curr_y, curr_z
            if axis == 'x': prev_x -= step_x
            elif axis == 'y': prev_y -= step_y
            else: prev_z -= step_z
            
            return {
                'hitVoxel': (curr_x, curr_y, curr_z),
                'hitFace': face,
                'prevEmptyVoxel': (prev_x, prev_y, prev_z)
            }
            
        steps += 1
        
    return None
```

**Parameters:**
*   `HARD_STEP_CAP`: 1024 steps (prevents infinite loops in degenerate cases) [S6, unofficial].
*   `step_size`: Not used in DDA; step size is implicit (1 voxel) [S4, S6, unofficial].
*   `max_dist`: Maximum traversal distance [S4, S7, unofficial].

**Edge Cases and Pitfalls:**
*   **Zero Direction Components:** If $d_x=0$, $step_x=0$ and $t_{max\_x}=\infty$, effectively ignoring that axis in traversal decisions [S1, S2, S7, unofficial].
*   **Ray Parallel to Axis:** Handled by setting $t_{max}$ to infinity and step/adv to 0 [S1, unofficial].
*   **Origin Inside Solid Voxel:** The algorithm must check the starting voxel before stepping, or the first step will move to an adjacent voxel, potentially missing the hit [S6, G, unofficial].
*   **Zero-Length Direction:** Causes division by zero; handled by checking norm < $10^{-5}$ [S4, S6, unofficial].
*   **Bounds Checking:** The algorithm does not perform internal bounds checking against the grid dimensions; the caller must ensure the ray stays within valid voxel indices or handle out-of-bounds access [S3, G, unofficial].

## Subtopics

### Voxel Raycast (Nonzero/Color Channel)
A variant that stops at the first voxel where a specific channel value is non-zero [S8, unofficial]. It uses a predicate struct holding a reference to VoxelData and a channel index, calling `data.get_voxel(rs.hit_position, channel, defval).i` and returning `v != 0` [S8, unofficial]. It is chosen when color or attribute data, not just occupancy, determines the hit [S8, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(k)$ where $k$ is the number of voxels traversed until a hit is found or the max distance is reached. In the worst case (empty space), $k \approx \text{distance} / \text{cell\_size}$.
*   **Memory Complexity:** $O(1)$ auxiliary space, excluding the grid storage [S1, S6, unofficial].
*   **Performance:** Efficient for sparse grids and large distances compared to fixed-step marchers, as it skips empty space [S6, unofficial]. Performance degrades if the ray traverses many empty voxels before hitting a solid one, but remains better than fixed-step for large gaps [S6, unofficial].
*   **Strengths:** No explicit intersection tests; precomputed deltas; handles axis-parallel rays gracefully; low memory overhead [S1, S6, unofficial].
*   **Limitations:** Requires occupancy query; does not handle non-axis-aligned voxel shapes (e.g., spheres) without modification; precision issues may occur with very large coordinates or very small direction components [S1, S7, unofficial].
*   **When to Use:** Voxel grids with axis-aligned cubic voxels; collision detection; occlusion queries; sparse volumes [S1, S6, S7, unofficial].
*   **When Not to Use:** Non-voxel grids; need for precise intersection points within a voxel (requires additional barycentric calculation); very dense grids where fixed-step might be faster due to cache locality (though DDA is generally preferred) [S6, unofficial].

## Background
The algorithm is based on the Amanatides & Woo method for ray tracing in voxel grids, published in 1986 [S1, S2, unofficial]. It is a classic DDA approach widely used in voxel engines, game development, and volume rendering for efficient traversal [S1, S6, S7, unofficial]. It is implemented in various libraries and engines, including Godot Voxel Tools [S5][S8, unofficial], DoonEngine [S3, unofficial], and custom implementations in research projects [S2, S4, S6, S7, unofficial].
