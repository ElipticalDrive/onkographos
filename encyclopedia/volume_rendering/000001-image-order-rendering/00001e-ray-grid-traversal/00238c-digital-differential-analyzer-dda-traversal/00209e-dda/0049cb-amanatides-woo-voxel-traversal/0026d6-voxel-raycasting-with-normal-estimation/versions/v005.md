# Voxel Raycasting with Normal Estimation

Also called: Amanatides and Woo algorithm, DDA Voxel Traversal, DDA-like voxel traversal, Digital Differential Analyzer voxel traversal, Parallel Ray Casting, Step-wise ray-sphere intersection for voxels, Voxel Raycasting via DDA, VoxelTrace

## Overview
Voxel Raycasting with Normal Estimation is a rendering approach where each ray is shot independently to pierce a data grid, allowing for parallel execution across CPU threads [S1, unofficial]. It traces a ray through a voxel grid to find the first solid voxel hit by walking the grid directly, visiting only intersected cells, with $O(\text{max\_distance})$ complexity [S2, unofficial]. It differs from its siblings by combining the Amanatides-Woo traversal logic with a post-hit normal estimation based on the ray's displacement vector relative to the voxel grid axes [S3, unofficial]. This method eliminates the need for "marching" (iterating through all voxels or maintaining a large list of pierced voxels when only the first hit is needed) [S1, unofficial].

## How it works
**Inputs:**
*   Ray origin $O = (O_x, O_y, O_z)$.
*   Ray direction $D = (D_x, D_y, D_z)$, assumed normalized or scaled.
*   Maximum ray distance $T_{max}$ (e.g., $6.0$ [S3, unofficial]).
*   Voxel grid data structure supporting `solidAt(x, y, z)` queries [S3, unofficial].
*   Epsilon $\epsilon$ for degenerate ray detection (e.g., $0.0001$ [S2, unofficial]).

**Outputs:**
*   Hit position $H$ (voxel coordinates or world space).
*   Surface normal $N$ (axis-aligned unit vector).
*   Boolean success flag.

**Data Structures:**
*   **Voxel Grid:** A sparse or dense array mapping integer coordinates $(x, y, z)$ to occupancy status (solid/empty) and optional color/property data.
*   **Ray State:** Current position $P$, previous position $P_{prev}$, and traversal parameters ($t_{max}, t_{delta}$).

**Parameters:**
*   Step increment for fixed-int marchers (if used): $dt = 0.05$ [S3, unofficial].
*   Epsilon: $0.0001$ [S2, unofficial].

**Algorithm Steps:**

1.  **Degeneracy Check:** Calculate the squared magnitude of the ray direction vector $L$. If $|L|^2 < \epsilon$, the ray is degenerate; return failure [S2, unofficial].
2.  **Initialization:**
    *   Set $P_{prev} = O$.
    *   Set $P = O$.
    *   Initialize traversal variables for DDA (see *Subtopics* or *Amanatides-Woo Voxel Traversal* for full DDA setup, or use fixed-step iteration as per [S3, unofficial]).
3.  **Traversal Loop:**
    *   Iterate $t$ from $0$ to $T_{max}$ with step $dt$ (or use DDA boundary stepping) [S3, unofficial].
    *   Update current position: $P = O + D \cdot t$ [S3, unofficial].
    *   Determine voxel coordinates: $x = \lfloor P_x \rfloor, y = \lfloor P_y \rfloor, z = \lfloor P_z \rfloor$ [S3, unofficial].
    *   **Boundary Check:** If $(x, y, z)$ is outside the grid bounds, continue or return failure.
    *   **Hit Test:** Query `solidAt(x, y, z)`.
        *   If solid:
            *   Set $H = (x, y, z)$ (or interpolated position).
            *   Proceed to Normal Estimation.
            *   Return success.
        *   If empty:
            *   Set $P_{prev} = P$.
            *   Continue loop.
4.  **Normal Estimation:**
    *   Calculate displacement vector: $diff = P - P_{prev}$ [S3, unofficial].
    *   Determine the dominant axis of $diff$:
        *   If $|diff_x| > |diff_y|$ and $|diff_x| > |diff_z|$:
            *   $N = (-\text{sign}(diff_x), 0, 0)$ [S3, unofficial].
        *   Else if $|diff_y| > |diff_z|$:
            *   $N = (0, -\text{sign}(diff_y), 0)$ [S3, unofficial].
        *   Else:
            *   $N = (0, 0, -\text{sign}(diff_z))$ [S3, unofficial].
    *   *Note:* The normal is negated relative to the displacement direction to point outward from the voxel face entered [S3, unofficial].
5.  **Return:** If the loop completes without finding a solid voxel, return failure.

**Pseudocode:**

```python
def voxel_raycast_with_normal(origin, direction, max_dist, grid, epsilon=0.0001):
    # 1. Degeneracy Check
    dir_sq_len = dot(direction, direction)
    if dir_sq_len < epsilon:
        return False, None, None

    # 2. Initialization
    prev_pos = origin
    current_pos = origin
    
    # 3. Traversal Loop (Fixed-step approach from [S3, unofficial])
    # Note: DDA approach (from Amanatides-Woo) is more efficient for sparse grids.
    # This implementation follows the specific "step-wise" logic described in [S3, unofficial].
    step_size = 0.05 # Typical value from [S3, unofficial]
    
    for t in range(0, int(max_dist / step_size)):
        current_pos = add(origin, scale(direction, t * step_size))
        
        # Determine voxel coordinates
        x = floor(current_pos.x)
        y = floor(current_pos.y)
        z = floor(current_pos.z)
        
        # Boundary check (implicit in grid access, handled by grid implementation)
        if not grid.in_bounds(x, y, z):
            continue
            
        # Hit Test
        if grid.solid_at(x, y, z):
            hit_pos = current_pos
            
            # 4. Normal Estimation
            diff = subtract(current_pos, prev_pos)
            
            abs_diff_x = abs(diff.x)
            abs_diff_y = abs(diff.y)
            abs_diff_z = abs(diff.z)
            
            if abs_diff_x > abs_diff_y and abs_diff_x > abs_diff_z:
                sign_x = 1.0 if diff.x > 0 else -1.0
                normal = (-sign_x, 0.0, 0.0)
            elif abs_diff_y > abs_diff_z:
                sign_y = 1.0 if diff.y > 0 else -1.0
                normal = (0.0, -sign_y, 0.0)
            else:
                sign_z = 1.0 if diff.z > 0 else -1.0
                normal = (0.0, 0.0, -sign_z)
                
            return True, hit_pos, normal
            
        prev_pos = current_pos

    return False, None, None
```

**Edge Cases and Pitfalls:**
*   **Large Step Size:** If the step size is large relative to voxel size, the normal estimation may be inaccurate or axis-aligned incorrectly if the ray passes through a corner [S3, unofficial]. The method assumes the ray enters the voxel face corresponding to the largest component of the displacement vector.
*   **Degenerate Rays:** Rays with near-zero direction magnitude must be handled to avoid NaN issues or infinite loops [S2, unofficial].
*   **Parallelization:** When using OpenMP or similar parallel frameworks, incorrect management of inner loop variables (distinguishing between loop variables and invariants) can cause errors [S1, unofficial].
*   **Sparse Grids:** The incremental nature avoids marching through empty space, but performance is still impacted by the density of empty voxels if hierarchical structures are not used [S1, unofficial].

## Subtopics

### [DN_step_map](8596-dn-step-map.md)
A variant that computes the closest entry voxel index for a ray in a regular grid using the Amanatides & Woo method. It solves the problem of efficiently querying sparse voxel structures for collision or occlusion without iterating all voxels. It differs from time-based marchers by using reach-based parameter $t$ and precomputing $tDelta/tMax$ for efficiency. It uses a DDA approach similar to Amanatides & Woo, stepping through voxel boundaries based on the smallest $tMax$, rather than sampling at fixed intervals.

## Operating characteristics
*   **Time Complexity:** $O(\text{max\_distance})$ for fixed-step traversal [S2, unofficial]. With DDA (Amanatides-Woo), complexity is proportional to the number of voxels intersected by the ray, which is typically $O(\text{ray\_length} / \text{voxel\_size})$.
*   **Memory Complexity:** $O(1)$ auxiliary space per ray, excluding the grid storage.
*   **Performance:** On a 256x256x256 colorfield (approx. 16 million data points), it achieves "decent speed" in software mode at 2000x2000 resolution [S1, unofficial]. For dense objects at 800x600 resolution, rates are considered "real time" [S1, unofficial].
*   **Strengths:**
    *   Highly parallelizable as each ray is independent [S1, unofficial].
    *   More efficient than PhysX raycasts for voxel grids due to direct grid walking [S2, unofficial].
    *   Eliminates the need for maintaining large lists of pierced voxels when only the first hit is required [S1, unofficial].
*   **Limitations:**
    *   Normal estimation is approximate and axis-aligned, which may be inaccurate for diagonal hits or large step sizes [S3, unofficial].
    *   Performance degrades with sparse data if no hierarchical structure (like a tree) is used, as empty voxels are still visited [S1, unofficial].
    *   Fixed-step approach (if used) requires careful tuning of step size to balance accuracy and performance [S3, unofficial].

## Background
The method is based on the Amanatides and Woo algorithm for fast traversal of voxel grids [S1, unofficial]. It was implemented in a software-mode ray caster to handle large voxel fields (e.g., 256x256x256) efficiently [S1, unofficial]. The approach was later adapted in projects like VektorVoxels for block placement and breaking, and in CPU rasterizers for normal estimation [S2, unofficial][S3, unofficial]. The "first found" rendering basis allows for early exit, optimizing performance for opaque objects [S1, unofficial].
