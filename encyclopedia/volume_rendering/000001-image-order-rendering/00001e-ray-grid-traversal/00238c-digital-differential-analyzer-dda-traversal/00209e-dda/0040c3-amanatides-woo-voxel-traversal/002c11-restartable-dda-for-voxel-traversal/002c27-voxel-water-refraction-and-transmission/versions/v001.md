# Voxel Water Refraction and Transmission

Also called: Phase 1-3 Water March, See-through water marcher

## Overview
A three-phase rendering technique for simulating light interaction with a voxel-based water surface and volume. It solves the problem of rendering transparent, refractive water over a complex terrain by marching a ray from the camera to the surface, calculating surface reflections and refraction, and then transmitting light through the water volume to the background. It is distinct from full volumetric path tracing by using a deterministic ray-marching approach optimized for voxel grids, relying on [Restartable DDA for Voxel Traversal](5187-restartable-dda-for-voxel-traversal.md) to handle the change in ray direction at the surface.

## How it works
**Inputs:**
- Camera position ($org$) and direction ($dir$) for the current pixel.
- Inverse view-projection matrix ($U.inv\_view\_proj$) for ray origin reconstruction.
- Voxel grid description ($vg$) including extent, cell sizes, and bounds.
- Sky cube map ($sky\_cube$) for environment reflection.
- Material data structure ($vg$) for reading voxel contents.
- Parameters: $U.water\_ior$ (Index of Refraction), $U.depth\_fog\_density$, $U.extinction\_rgb$, $U.deep\_water\_color$, $U.max\_steps$.

**Outputs:**
- Final pixel color ($color$) after tonemapping.

**Data Structures:**
- `DdaState W`: State structure for the DDA traversal, containing current voxel index ($W.idx$), current distance along ray ($W.t\_cur$), ray direction ($W.d$), and the axis of the current voxel face ($W.axis$). This structure is re-initialized in Phase 2.

**Steps:**

1.  **Ray Initialization (Camera to Surface):**
    Construct the ray origin and direction. For perspective projection, the origin is the camera position. For orthographic projection, the origin is backed up beyond the grid AABB.
    $$
    p_0 = U.inv\_view\_proj \cdot [ndc_x, ndc_y, 0.0, 1.0]^T
    $$
    $$
    p_1 = U.inv\_view\_proj \cdot [ndc_x, ndc_y, 1.0, 1.0]^T
    $$
    $$
    near\_pt = p_0.xyz / p_0.w
    $$
    $$
    dir = normalize(p_1.xyz / p_1.w - near\_pt)
    $$
    $$
    org = \begin{cases} U.camera\_pos & \text{if } U.ortho\_backup == 0 \\ near\_pt - dir \cdot U.ortho\_backup & \text{otherwise} \end{cases}
    $$

2.  **Phase 1: Surface Entry:**
    March the ray from $org$ along $dir$ using the DDA until the first non-air/water cell is found. Let the entry point be $entry\_p$ and the entry axis be $entry\_axis$.

3.  **Phase 2: Surface Interaction:**
    Calculate the surface normal $n_{entry}$ based on the entry axis. Calculate the view vector $V$ from the entry point to the camera.
    $$
    V = normalize(org - entry\_p)
    $$
    Calculate Fresnel reflectance $F$ using the Schlick approximation:
    $$
    nv = \max(dot(n_{entry}, V), 0.0)
    $$
    $$
    F = 0.02 + 0.98 \cdot (1.0 - nv)^5
    $$
    Calculate the reflection ray $R$:
    $$
    R = reflect(-V, n_{entry})
    $$
    Sample the sky cube for the reflection color, adding sun specular highlights:
    $$
    reflection = sky\_cube.sample(cube\_smp, R).rgb + U.sun\_color \cdot \max(dot(R, sun), 0.0)^{U.sun\_shininess}
    $$
    Calculate the refracted ray direction $rdir$:
    $$
    rdir = refract(dir, n_{entry}, 1.0 / U.water\_ior)
    $$
    Guard against degenerate refraction (total internal reflection or grazing angles):
    $$
    \text{if } dot(rdir, rdir) < 10^{-6} \text{ then } rdir = dir
    $$
    $$
    rdir = normalize(rdir)
    $$
    Re-initialize the DDA state $W$ with the entry point (offset slightly along $rdir$ to avoid self-intersection) and the refracted direction:
    $$
    walking = dda\_init(W, entry\_p + rdir \cdot 10^{-4}, rdir, G)
    $$

4.  **Phase 3: Volume Transmission:**
    Initialize $water\_dist = 0.0$, $end\_mat = MAT\_AIR$, $end\_axis = 1$, and $exited\_up = false$.
    Loop while $walking$ and $steps < U.max\_steps$:
    1.  Increment $steps$.
    2.  Read material $m$ at $W.idx$.
    3.  If $m$ is not $MAT\_AIR$, $MAT\_WATER$, or $MAT\_BUBBLE$:
        - Set $end\_mat = m$, $end\_axis = W.axis$.
        - Break loop.
    4.  Record $t\_enter = W.t\_cur$.
    5.  Step the DDA: $alive = dda\_step(W, G)$.
    6.  If $m == MAT\_WATER$:
        - $water\_dist += W.t\_cur - t\_enter$.
    7.  If not $alive$:
        - Set $exited\_up = (rdir.y > 0.0)$.
        - Break loop.

5.  **Special Material Handling:**
    If $end\_mat$ is $MAT\_FISH$, $MAT\_FIRE$, or $MAT\_LAVA$, render the material opaque and unattenuated by the water path or surface reflection.
    - Fish: Return tonemapped terrain color for fish.
    - Fire: Return tonemapped palette color multiplied by 3.0.
    - Lava: Return tonemapped palette color multiplied by 1.25.

6.  **Background and Attenuation:**
    Determine the background color $bg$ behind the water:
    - If $end\_mat \neq MAT\_AIR$: $bg = terrain\_color(end\_mat, face\_normal(end\_axis, W.d), sun, U)$.
    - Else if $exited\_up$: $bg = sky\_cube.sample(cube\_smp, rdir).rgb$.
    - Else: $bg = U.deep\_water\_color$.

    Apply Beer-Lambert transmission:
    $$
    T = \exp(-U.depth\_fog\_density \cdot water\_dist \cdot U.extinction\_rgb)
    $$
    $$
    refr = bg \cdot T + U.deep\_water\_color \cdot (1.0 - T)
    $$

7.  **Final Composition:**
    Mix the refracted and reflected colors based on Fresnel reflectance:
    $$
    color = mix(refr, reflection, F)
    $$
    Apply ACES tonemapping and return.

**Pseudocode:**

```python
def voxel_water_refraction(ndc, inv_view_proj, camera_pos, ortho_backup, 
                           sky_cube, vg, G, U, sun):
    # 1. Ray Initialization
    p0 = inv_view_proj * [ndc.x, ndc.y, 0.0, 1.0]
    p1 = inv_view_proj * [ndc.x, ndc.y, 1.0, 1.0]
    near_pt = p0.xyz / p0.w
    dir = normalize(p1.xyz / p1.w - near_pt)
    
    if ortho_backup == 0:
        org = camera_pos
    else:
        org = near_pt - dir * ortho_backup

    # Phase 1: March to surface (implementation depends on parent DDA article)
    entry_p, entry_axis = march_to_surface(org, dir, vg, G)
    
    # Phase 2: Surface Interaction
    n_entry = get_surface_normal(entry_axis)
    V = normalize(org - entry_p)
    nv = max(dot(n_entry, V), 0.0)
    F = 0.02 + 0.98 * pow(1.0 - nv, 5.0)
    
    R = reflect(-V, n_entry)
    reflection = sky_cube.sample(cube_smp, R).rgb + \
                 U.sun_color * pow(max(dot(R, sun), 0.0), U.sun_shininess)
    
    rdir = refract(dir, n_entry, 1.0 / U.water_ior)
    if dot(rdir, rdir) < 1e-6:
        rdir = dir
    rdir = normalize(rdir)
    
    # Re-initialize DDA for refraction
    W = dda_init(entry_p + rdir * 1e-4, rdir, G)
    walking = True
    steps = 0
    water_dist = 0.0
    end_mat = MAT_AIR
    end_axis = 1
    exited_up = False
    
    # Phase 3: Volume Transmission
    while walking and steps < U.max_steps:
        steps += 1
        m = read_material(vg, W.idx)
        
        if m != MAT_AIR and m != MAT_WATER and m != MAT_BUBBLE:
            end_mat = m
            end_axis = W.axis
            break
            
        t_enter = W.t_cur
        alive = dda_step(W, G)
        
        if m == MAT_WATER:
            water_dist += W.t_cur - t_enter
            
        if not alive:
            exited_up = rdir.y > 0.0
            break
            
    # Special Materials
    if end_mat == MAT_FISH:
        return aces_tonemap(terrain_color(MAT_FISH, face_normal(end_axis, W.d), sun, U))
    if end_mat == MAT_FIRE:
        return aces_tonemap(U.palette[MAT_FIRE] * 3.0)
    if end_mat == MAT_LAVA:
        return aces_tonemap(U.palette[MAT_LAVA] * 1.25)
        
    # Background
    if end_mat != MAT_AIR:
        bg = terrain_color(end_mat, face_normal(end_axis, W.d), sun, U)
    elif exited_up:
        bg = sky_cube.sample(cube_smp, rdir).rgb
    else:
        bg = U.deep_water_color
        
    # Beer-Lambert
    T = exp(-U.depth_fog_density * water_dist * U.extinction_rgb)
    refr = bg * T + U.deep_water_color * (1.0 - T)
    
    color = mix(refr, reflection, F)
    return aces_tonemap(color)
```

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of voxels traversed in the water volume and the distance to the surface. Bounded by $U.max\_steps$.
- **Memory Complexity:** Constant, $O(1)$, aside from the voxel grid storage.
- **Strengths:** Efficiently handles refraction and reflection in a single pass without recursive ray tracing. Correctly handles complex terrain occlusion behind the water.
- **Limitations:** Does not simulate subsurface scattering or multiple bounces within the water. Accuracy depends on voxel resolution.
- **When to use:** Real-time rendering of voxel-based water bodies where performance is critical and full volumetric path tracing is too expensive.

## Background
Originating from the "Vox-Ocean" project by wlim33, this method implements a specialized water rendering pipeline for voxel dioramas. It combines standard ray-marching techniques with specific optimizations for voxel grids, such as the restartable DDA for handling refraction. The technique is documented in the project's source code and shader implementations.
