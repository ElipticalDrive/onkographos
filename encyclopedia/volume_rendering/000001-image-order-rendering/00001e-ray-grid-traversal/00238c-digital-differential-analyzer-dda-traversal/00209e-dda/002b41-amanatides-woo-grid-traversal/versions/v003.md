# Amanatides–Woo grid traversal
Also called: traverseGridSegmentFloat

## Overview
An algorithm to traverse grid cells intersected by a line segment defined by two points, calling a visitor function for each cell [S1, unofficial]. It sets itself apart from its siblings by using standard floating-point arithmetic for all distance and direction calculations, providing a direct implementation of the classic Amanatides–Woo method without fixed-point optimization or hierarchical acceleration [S1, unofficial].

## How it works
**Inputs and outputs:**
- `start`: The starting point of the line segment (`vec2f`) [S1, unofficial].
- `end`: The ending point of the line segment (`vec2f`) [S1, unofficial].
- `visitor`: A callable object with a `visit(int, int)` method called for each traversed cell [S1, unofficial].

**Data structures:**
No persistent data structures are required. The algorithm uses local scalar variables for coordinates, deltas, and t-max values.

**Steps:**
1. Compute initial cell coordinates: $x_0 = \lfloor \text{start}.x \rfloor$, $y_0 = \lfloor \text{start}.y \rfloor$, $x_1 = \lfloor \text{end}.x \rfloor$, $y_1 = \lfloor \text{end}.y \rfloor$ [S1, unofficial].
2. Compute step directions: $\text{stepX} = 1$ if $x_1 > x_0$, $-1$ if $x_1 < x_0$, else $0$; similarly for $\text{stepY}$ [S1, unofficial].
3. Compute deltas: $\Delta x = \text{end}.x - \text{start}.x$, $\Delta y = \text{end}.y - \text{start}.y$ [S1, unofficial].
4. Compute t-deltas (inverse step size in $t$): $t_{\Delta X} = |1/\Delta x|$ if $\Delta x \neq 0$, else $\infty$; $t_{\Delta Y} = |1/\Delta y|$ if $\Delta y \neq 0$, else $\infty$ [S1, unofficial].
5. Compute next intersection coordinates: $\text{nextX} = \lfloor \text{start}.x \rfloor + 1$ if $\text{stepX} > 0$, else $\lfloor \text{start}.x \rfloor$; $\text{nextY} = \lfloor \text{start}.y \rfloor + 1$ if $\text{stepY} > 0$, else $\lfloor \text{start}.y \rfloor$ [S1, unofficial].
6. Compute initial t-max values: $t_{\text{max}X} = |(\text{nextX} - \text{start}.x) / \Delta x|$ if $\Delta x \neq 0$, else $\infty$; $t_{\text{max}Y} = |(\text{nextY} - \text{start}.y) / \Delta y|$ if $\Delta y \neq 0$, else $\infty$ [S1, unofficial].
7. Initialize $\text{maxT} = 1.0$, $\text{currentX} = x_0$, $\text{currentY} = y_0$ [S1, unofficial].
8. Loop: Call $\text{visitor.visit}(\text{currentX}, \text{currentY})$. Compute $t = \min(t_{\text{max}X}, t_{\text{max}Y})$. If $t > \text{maxT}$, break [S1, unofficial].
9. If $t_{\text{max}X} < t_{\text{max}Y}$, update $t_{\text{max}X} \leftarrow t_{\text{max}X} + t_{\Delta X}$ and $\text{currentX} \leftarrow \text{currentX} + \text{stepX}$; else update $t_{\text{max}Y} \leftarrow t_{\text{max}Y} + t_{\Delta Y}$ and $\text{currentY} \leftarrow \text{currentY} + \text{stepY}$ [S1, unofficial].
10. After the loop, if $\text{currentX} \neq x_1$ or $\text{currentY} \neq y_1$, explicitly call $\text{visitor.visit}(x_1, y_1)$ to ensure the end cell is included [S1, unofficial].

**Pseudocode:**
```python
def traverse_grid_segment_float(start: Vec2f, end: Vec2f, visitor) -> None:
    x0 = floor(start.x)
    y0 = floor(start.y)
    x1 = floor(end.x)
    y1 = floor(end.y)

    stepX = 1 if x1 > x0 else (-1 if x1 < x0 else 0)
    stepY = 1 if y1 > y0 else (-1 if y1 < y0 else 0)

    dx = end.x - start.x
    dy = end.y - start.y

    tDeltaX = abs(1.0 / dx) if dx != 0.0 else float('inf')
    tDeltaY = abs(1.0 / dy) if dy != 0.0 else float('inf')

    nextX = floor(start.x) + 1 if stepX > 0 else floor(start.x)
    nextY = floor(start.y) + 1 if stepY > 0 else floor(start.y)

    tMaxX = abs((nextX - start.x) / dx) if dx != 0.0 else float('inf')
    tMaxY = abs((nextY - start.y) / dy) if dy != 0.0 else float('inf')

    maxT = 1.0
    currentX = x0
    currentY = y0

    while True:
        visitor.visit(currentX, currentY)
        t = min(tMaxX, tMaxY)
        if t > maxT:
            break

        if tMaxX < tMaxY:
            tMaxX += tDeltaX
            currentX += stepX
        else:
            tMaxY += tDeltaY
            currentY += stepY

    if currentX != x1 or currentY != y1:
        visitor.visit(x1, y1)
```

**Parameters:**
- `start`: `vec2f` [S1, unofficial].
- `end`: `vec2f` [S1, unofficial].
- `visitor`: Callable with `visit(int, int)` [S1, unofficial].

**Edge cases and pitfalls:**
- If the loop terminates before reaching the final cell $(x_1, y_1)$, the end cell must be explicitly visited to ensure completeness [S1, unofficial].
- Division by zero is handled by checking if $\Delta x$ or $\Delta y$ is zero; if so, the corresponding t-delta and t-max are set to infinity [S1, unofficial].
