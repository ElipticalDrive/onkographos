# Macro-Cell Optimization

Also called: Macro-Cell Acceleration, Online Macro-Cell Construction

## Overview
Macro-Cell Optimization is an acceleration technique for volume rendering that partitions the spatial domain into disjoint, closely packed macro-cells to minimize null collisions and reduce the number of expensive neural network inferences [S1]. It sets itself apart from standard DDA methods by storing aggregate statistics (value range and maximum opacity $\mu_{\max}$) per macro-cell, allowing for early termination of rays and adaptive step sizing based on local density bounds [S1].

## How it works
**Inputs and Outputs**
The method takes volume dimensions $D_x, D_y, D_z$, macro-cell size parameter $N_g$, a neural network representation of the volume, and a transfer function as inputs [S1]. It outputs the rendered image and updated macro-cell statistics for online training [S1].

**Data Structures**
The acceleration structure is a 3D grid of macro-cells [S1]. The grid dimensions are $\lceil D_x / N_g \rceil \times \lceil D_y / N_g \rceil \times \lceil D_z / N_g \rceil$ [S1]. Each macro-cell stores the maximum opacity $\mu_{\max}$ of all contained voxels and the value range of those voxels [S1]. If volume dimensions are not an integer multiple of $N_g$, the macro-cell grid extends beyond the volume domain, which is acceptable [S1].

**Parameters**
$N_g$ is the macro-cell size per dimension, typically set to 64 to balance performance and memory footprint [S1]. $s_1$ is the minimum sampling step size, set to 1 [S1]. $s_2$ is the maximum sampling step size, set to 64 [S1]. $p$ is the exponent for adaptive step size calculation, set to 2 [S1].

**Algorithm Steps**
1. Initialization: For each primary ray, determine the intersection with the volume; if no intersection is found, invalidate the ray [S1].
2. Target Calculation: Generate a uniform random number $\zeta \sim \mathcal{U}_{[0,1]}$ and compute the target optical thickness $\tau_{\text{target}} = -\log(1 - \zeta)$ [S1].
3. Traversal: Traverse the ray through the macro-cells using a 3D Digital Differential Analyzer (DDA) [S1].
4. Macro-Cell Check: If a macro-cell is transparent ($\mu_{\max} = 0$), bypass it entirely [S1]. Otherwise, calculate the optical thickness contribution of the segment within the cell [S1].
5. Accumulation: Accumulate the optical thickness $\tau_n = \sum_{i=0}^n \mu_{\max}^i \times s_i$, where $s_i$ is the length of the ray segment within the $i$-th macro-cell [S1].
6. Termination: Stop the ray when $\tau_n > \tau_{\text{target}}$ for the first time, then step backward to find the exact hit location [S1].
7. Ray Marching Mode: For regular ray marching within cells, adaptively vary the sampling step size $\bar{s}$ based on density $\mu$ using $\bar{s} = \max(s_1 + (s_2 - s_1) \cdot |\min(\mu, 1) - 1|^p, s_1)$ [S1]. Sample the volume at intervals of $\bar{s}$ [S1]. Correct the sampled opacity $\alpha$ to $\bar{\alpha} = 1 - (1 - \alpha)^{s / \bar{s}}$, where $s$ is the actual step size [S1].
8. Online Update: During online training, update the macro-cell value range fields using training samples generated in each step, as the process is embarrassingly parallelizable [S1].

**Pseudocode**

```python
import math
import random

def macro_cell_optimization(ray_origin, ray_direction, t_min, t_max, volume_dims, ng, mu_max_grid):
    # 1. Initialize ray (intersection check handled externally per [S1])
    t = t_min

    # 2. Target optical thickness
    zeta = random.uniform(0, 1)
    tau_target = -math.log(1 - zeta)

    # 3. DDA state initialization for macro-cell grid
    grid_dims = (
        math.ceil(volume_dims[0] / ng),
        math.ceil(volume_dims[1] / ng),
        math.ceil(volume_dims[2] / ng)
    )
    inv_dir = (1.0 / ray_direction[0], 1.0 / ray_direction[1], 1.0 / ray_direction[2])
    m_next = [
        (math.floor(ray_origin[i] / ng) + 1) * ng - ray_origin[i] if inv_dir[i] > 0 else
        math.floor(ray_origin[i] / ng) * ng - ray_origin[i]
        for i in range(3)
    ]
    m_delta = [ng * inv_dir[i] for i in range(3)]
    m_step = [1 if inv_dir[i] > 0 else -1 for i in range(3)]
    cell_idx = (
        math.floor(ray_origin[0] / ng),
        math.floor(ray_origin[1] / ng),
        math.floor(ray_origin[2] / ng)
    )

    current_tau = 0.0

    # 4. Traverse macro-cells
    while t < t_max:
        # Find exit distance from current macro-cell
        t_exit = t
        for dim in range(3):
            if m_next[dim] > 0:
                t_exit = min(t_exit, t + m_next[dim])

        s_i = t_exit - t
        mu_max = mu_max_grid[cell_idx[0]][cell_idx[1]][cell_idx[2]]

        # 5. Bypass transparent cells
        if mu_max == 0:
            t = t_exit
            for dim in range(3):
                if t_exit == t + m_next[dim]:
                    cell_idx = (
                        cell_idx[0] + m_step[0] if dim == 0 else cell_idx[0],
                        cell_idx[1] + m_step[1] if dim == 1 else cell_idx[1],
                        cell_idx[2] + m_step[2] if dim == 2 else cell_idx[2]
                    )
                    m_next[dim] += m_delta[dim]
            continue

        # 6. Accumulate optical thickness
        current_tau += mu_max * s_i

        # 7. Termination check
        if current_tau > tau_target:
            hit_t = find_exact_hit(t, t_exit, tau_target, current_tau - mu_max * s_i, mu_max)
            return hit_t

        # Advance ray to next macro-cell
        t = t_exit
        for dim in range(3):
            if t_exit == t + m_next[dim]:
                cell_idx = (
                    cell_idx[0] + m_step[0] if dim == 0 else cell_idx[0],
                    cell_idx[1] + m_step[1] if dim == 1 else cell_idx[1],
                    cell_idx[2] + m_step[2] if dim == 2 else cell_idx[2]
                )
                m_next[dim] += m_delta[dim]

    return None

def find_exact_hit(t_enter, t_exit, tau_target, tau_before, mu_max):
    low, high = t_enter, t_exit
    for _ in range(32):
        mid = (low + high) / 2.0
        seg_len = mid - t_enter
        tau_mid = tau_before + mu_max * seg_len
        if tau_mid < tau_target:
            low = mid
        else:
            high = mid
    return low
```

## Operating characteristics
Performance shows significant speed improvements, particularly with neural representations, due to reduced null collisions and neural network inferences [S1]. The choice of $N_g$ balances performance and memory, with $N_g=64$ being favorable [S1]. Adaptive sampling causes the number of volume samples per ray to fluctuate considerably, but stream compaction of terminated rays prevents performance compromise [S1]. The method assumes the neural representation approximates ground truth accurately; small discrepancies in online-constructed value ranges do not significantly impact rendering quality [S1].

## Background
Macro-Cell Optimization was proposed in the context of interactive volume visualization using multi-resolution hash encoding [S1]. It builds upon the work of Hofmann et al. for target optical thickness calculation and Morrical et al. for adaptive step sizing [S1]. The technique is particularly relevant for neural volume rendering where inference costs are high [S1].
