# Macro-Cell Optimization

Also called: Macro-Cell Acceleration, Online Macro-Cell Construction

## Overview
Macro-Cell Optimization is an acceleration technique for volume rendering that partitions the spatial domain into disjoint, closely packed macro-cells to minimize null collisions and reduce the number of expensive neural network inferences [S1]. It sets itself apart from standard DDA methods by storing aggregate statistics (value range and maximum opacity $\mu_{\max}$) per macro-cell, allowing for early termination of rays and adaptive step sizing based on local density bounds [S1].

## How it works
**Inputs and Outputs**
*   **Input:** Volume dimensions $D_x, D_y, D_z$; macro-cell size parameter $N_g$; neural network representation of the volume; transfer function.
*   **Output:** Rendered image; updated macro-cell statistics (for online training).

**Data Structures**
The acceleration structure is a 3D grid of macro-cells.
*   **Grid Dimensions:** The grid has dimensions $\lceil D_x / N_g \rceil \times \lceil D_y / N_g \rceil \times \lceil D_z / N_g \rceil$ [S1].
*   **Macro-Cell Content:** Each macro-cell stores:
    *   $\mu_{\max}$: The maximum opacity (or density, depending on the specific transfer function implementation, but referred to as $\mu_{\max}$ in the source) of all voxels contained within the cell [S1].
    *   Value Range: The minimum and maximum values of the contained voxels [S1].
*   **Boundary Handling:** If volume dimensions are not an integer multiple of $N_g$, the macro-cell grid extends beyond the volume domain. These out-of-bounds cells are acceptable and handled by the traversal logic [S1].

**Parameters**
*   $N_g$: Macro-cell size per dimension. Typical value: 64 [S1].
*   $s_1$: Minimum sampling step size. Typical value: 1 [S1].
*   $s_2$: Maximum sampling step size. Typical value: 64 [S1].
*   $p$: Exponent for adaptive step size calculation. Typical value: 2 [S1].

**Algorithm Steps**

1.  **Initialization:** For each primary ray, determine the intersection with the volume. If no intersection is found, invalidate the ray [S1].
2.  **Target Calculation:** Generate a uniform random number $\zeta \sim \mathcal{U}_{[0,1]}$ and compute the target optical thickness:
    $$ \tau_{\text{target}} = -\log(1 - \zeta) $$
    [S1]
3.  **Traversal:** Traverse the ray through the macro-cells using a 3D Digital Differential Analyzer (DDA) [S1].
4.  **Macro-Cell Check:** For each visited macro-cell:
    *   If the macro-cell is transparent (i.e., $\mu_{\max} = 0$ or below a threshold), bypass it entirely [S1].
    *   Otherwise, calculate the optical thickness contribution of the segment within the cell.
5.  **Accumulation:** Accumulate the optical thickness $\tau_n$ as the ray progresses:
    $$ \tau_n = \sum_{i=0}^n \mu_{\max}^i \times s_i $$
    where $s_i$ is the length of the ray segment within the $i$-th macro-cell [S1].
6.  **Termination:** Stop the ray when $\tau_n > \tau_{\text{target}}$ for the first time. Step backward to find the exact hit location [S1].
7.  **Ray Marching (Optional/Alternative Mode):** If performing regular ray marching within cells rather than Woodcock tracking with null collisions:
    *   Calculate an adaptive sampling step size $\bar{s}$ based on the current density $\mu$:
        $$ \bar{s} = \max(s_1 + (s_2 - s_1) \cdot |\min(\mu, 1) - 1|^p, s_1) $$
        [S1]
    *   Sample the volume at intervals of $\bar{s}$.
    *   Correct the sampled opacity $\alpha$ to account for the variable step size:
        $$ \bar{\alpha} = 1 - (1 - \alpha)^{s / \bar{s}} $$
        where $s$ is the actual step size used [S1].
8.  **Online Update (For Online Training):** During online training, update the macro-cell value range fields using the training samples generated in each step. This process is embarrassingly parallelizable and incurs negligible overhead [S1].

```python
import math
import random

def macro_cell_optimization(ray, volume_dims, ng, mu_max_grid, neural_net):
    """
    ray: Object with t_min, t_max, direction, origin.
    volume_dims: Tuple (Dx, Dy, Dz).
    ng: Macro-cell size (e.g., 64).
    mu_max_grid: 3D array of max opacities for each macro-cell.
    neural_net: Function to query density/opacity at a point.
    """
    # 1. Initialize ray
    t = ray.t_min
    if not ray.intersects_volume():
        return None

    # 2. Target optical thickness
    zeta = random.uniform(0, 1)
    tau_target = -math.log(1 - zeta)

    # 3. DDA state initialization (simplified, assumes standard DDA setup)
    # Note: Actual DDA state (mNext, mDelta, mStep) depends on the parent Hierarchical DDA implementation.
    # Here we assume a generic traversal loop over macro-cells.
    
    current_tau = 0.0
    
    # Traverse macro-cells
    while t < ray.t_max:
        # Determine current macro-cell index
        # This requires mapping ray position to grid coordinates
        cell_idx = get_macro_cell_index(ray.position_at(t), volume_dims, ng)
        
        # Check if cell is valid (handle boundary extension)
        if not is_valid_cell(cell_idx, volume_dims, ng):

            continue
            
        mu_max = mu_max_grid[cell_idx]
        
        # 4. Bypass transparent cells
        if mu_max == 0:
            # Advance ray to next macro-cell boundary
            t = advance_to_next_cell_boundary(ray, cell_idx, ng)
            continue
            
        # 5. Calculate segment length within this macro-cell
        # This requires computing the intersection of the ray with the current macro-cell box
        t_enter, t_exit = get_cell_intersection(ray, cell_idx, ng)
        segment_length = t_exit - t_enter
        
        # 6. Accumulate optical thickness
        # Using the formula from the source: tau_n = sum(mu_max * s_i)
        current_tau += mu_max * segment_length
        
        # 7. Termination check
        if current_tau > tau_target:
            # Step backward to find exact hit

            hit_t = find_exact_hit(ray, t_enter, t_exit, tau_target, current_tau - mu_max * segment_length, mu_max, neural_net)
            return hit_t
            
        t = t_exit

    return None

def adaptive_step_size(mu, s1=1, s2=64, p=2):
    """
    Calculates adaptive step size based on density mu.
    """
    # Formula: s_bar = max(s1 + (s2 - s1) * |min(mu, 1) - 1|^p, s1)
    min_mu = min(mu, 1)
    term = abs(min_mu - 1) ** p
    s_bar = max(s1 + (s2 - s1) * term, s1)
    return s_bar

def correct_opacity(alpha, s, s_bar):
    """
    Corrects sampled opacity for variable step size.
    """
    # Formula: alpha_bar = 1 - (1 - alpha)^(s / s_bar)
    return 1 - (1 - alpha) ** (s / s_bar)
```

## Operating characteristics
*   **Performance:** Significant speed improvements are observed, particularly when using neural representations, due to the reduction in null collisions and neural network inferences [S1].
*   **Memory Footprint:** The choice of $N_g$ balances performance and memory. $N_g=64$ is found to be favorable [S1].
*   **Variability:** Adaptive sampling causes the number of volume samples per ray to fluctuate considerably, but this does not compromise performance due to stream compaction of terminated rays [S1].
*   **Limitations:** The method assumes the neural representation approximates ground truth accurately; small discrepancies in online-constructed value ranges do not significantly impact rendering quality [S1].

## Background
Macro-Cell Optimization was proposed in the context of interactive volume visualization using multi-resolution hash encoding [S1]. It builds upon the work of Hofmann et al. [46] for target optical thickness calculation and Morrical et al. [47] for adaptive step sizing [S1]. The technique is particularly relevant for neural volume rendering where inference costs are high [S1].
