# Voxel Raycasting with Vertical Slicing

Also called: 12-layer vertical raycasting, voxel4.cpp raycaster

## Overview
Voxel Raycasting with Vertical Slicing is a 3D rendering technique that visualizes voxel thickness by treating each voxel column as 12 distinct vertical layers indexed 0–11 [S1, unofficial]. Unlike standard 2D raycasting which draws a single vertical line per hit, this method draws 12 vertical stripes per hit, spaced by `lineHeight` intervals and centered around the intersection point with a `pitch` offset, allowing visualization of internal structure [S1, unofficial].

## How it works
### Inputs and Outputs
- **Inputs**: 
  - `worldMap`: A 3D integer array `int worldMap[mapWidth][mapHeight][12]` representing the voxel grid, with dimensions `mapWidth = 96` and `mapHeight = 96` [S1, unofficial].
  - `cameraPos`: `(posX, posY)` representing the camera position [S1, unofficial].
  - `cameraDir`: `(dirX, dirY)` representing the camera direction vector [S1, unofficial].
  - `cameraPlane`: `(planeX = 0, planeY = 0.66)` determining the Field of View (FOV) [S1, unofficial].
  - `screenWidth` and `screenHeight`: Output resolution in pixels [S1, unofficial].
  - `pitch`: A constant representing the vertical tilt offset for the voxel stack, defaulting to 200 [S1, unofficial].
- **Outputs**: 
  - A 2D screen buffer where each column `x` contains 12 vertical stripes corresponding to the 12 layers of the hit voxel [S1, unofficial].

### Data Structures
- **World Map**: `int worldMap[96][96][12]`. Each element stores an integer representing the layer's color or state; values 0–5 have specific color mappings, while 6–11 default to Yellow [S1, unofficial].
- **Depth Buffer**: `int depth[384]`. Initialized to 100000; handles occlusion between the 12 vertical slices of the same voxel or across rays, and is reset per ray [S1, unofficial].

### Steps
1. **Initialize Ray Position and Direction**: Set `rayPosX = posX` and `rayPosY = posY`. For each screen column `x` from 0 to `screenWidth - 1`, calculate `cameraX = 2 * x / screenWidth - 1`, `rayDirX = dirX + planeX * cameraX`, and `rayDirY = dirY + planeY * cameraX` [S1, unofficial].
2. **Initialize DDA State**: Determine `stepX` and `stepY` (+1 or -1) based on the signs of `rayDirX` and `rayDirY`. Calculate initial `sideDistX` and `sideDistY` to the first grid boundary: if `rayDirX < 0`, `stepX = -1` and `sideDistX = (rayPosX - mapX) * deltaDistX`; else `stepX = 1` and `sideDistX = (mapX + 1.0 - rayPosX) * deltaDistX`. Apply identical logic for Y. Calculate `deltaDistX = sqrt(1 + (rayDirY^2) / (rayDirX^2))` and `deltaDistY = sqrt(1 + (rayDirX^2) / (rayDirY^2))` [S1, unofficial].
3. **Perform DDA Loop**: Initialize `mapX = int(rayPosX)` and `mapY = int(rayPosY)`. While `mapX` and `mapY` are within bounds `[0, mapWidth-1]` and `[0, mapHeight-1]` respectively, or `hit < 100`: if `sideDistX < sideDistY`, add `deltaDistX` to `sideDistX`, increment `mapX` by `stepX`, set `side = 0`; else add `deltaDistY` to `sideDistY`, increment `mapY` by `stepY`, set `side = 1`. Increment `hit` [S1, unofficial].
4. **Render Voxel Layers**: Calculate perpendicular wall distance: if `side == 0`, `perpWallDist = (mapX - rayPosX + (1 - stepX) / 2) / rayDirX`; if `side == 1`, `perpWallDist = (mapY - rayPosY + (1 - stepY) / 2) / rayDirY` [S1, unofficial]. Calculate `lineHeight = int(screenHeight / perpWallDist)`. Initialize `depth` array of size 384 with 100000. Loop `b` from 0 to 11: calculate `drawStart = lineHeight * (b - 6) + pitch` and `drawEnd = lineHeight + lineHeight * (b - 6) + pitch`. Clamp both to `[0, screenHeight - 1]`. Retrieve color from `worldMap[mapX][mapY][b]`. If `side == 1`, divide color brightness by 2. If color is not Black, draw a vertical line from `drawStart` to `drawEnd` with depth testing against the `depth` array [S1, unofficial].

### Pseudocode
```python
import math

def voxel_raycasting_vertical_slicing(world_map, map_width, map_height, camera_pos, camera_dir, camera_plane, screen_width, screen_height, pitch=200):
    screen_buffer = [[0] * screen_height for _ in range(screen_width)]
    
    for x in range(screen_width):
        camera_x = 2.0 * x / screen_width - 1.0
        ray_dir_x = camera_dir[0] + camera_plane[0] * camera_x
        ray_dir_y = camera_dir[1] + camera_plane[1] * camera_x
        
        ray_pos_x = camera_pos[0]
        ray_pos_y = camera_pos[1]
        
        map_x = int(ray_pos_x)
        map_y = int(ray_pos_y)
        
        delta_dist_x = math.sqrt(1.0 + (ray_dir_y * ray_dir_y) / (ray_dir_x * ray_dir_x))
        delta_dist_y = math.sqrt(1.0 + (ray_dir_x * ray_dir_x) / (ray_dir_y * ray_dir_y))
        
        if ray_dir_x < 0:
            step_x = -1
            side_dist_x = (ray_pos_x - map_x) * delta_dist_x
        else:
            step_x = 1
            side_dist_x = (map_x + 1.0 - ray_pos_x) * delta_dist_x
            
        if ray_dir_y < 0:
            step_y = -1
            side_dist_y = (ray_pos_y - map_y) * delta_dist_y
        else:
            step_y = 1
            side_dist_y = (map_y + 1.0 - ray_pos_y) * delta_dist_y
            
        hit = 0
        side = 0
        
        while (0 <= map_x < map_width and 0 <= map_y < map_height) and hit < 100:
            if side_dist_x < side_dist_y:
                side_dist_x += delta_dist_x
                map_x += step_x
                side = 0
            else:
                side_dist_y += delta_dist_y
                map_y += step_y
                side = 1
            hit += 1
            
        if ray_dir_x == 0:
            perp_wall_dist = float('inf')
        elif side == 0:
            perp_wall_dist = (map_x - ray_pos_x + (1 - step_x) / 2.0) / ray_dir_x
        else:
            perp_wall_dist = (map_y - ray_pos_y + (1 - step_y) / 2.0) / ray_dir_y
            
        if perp_wall_dist == 0 or perp_wall_dist == float('inf'):
            continue
            
        line_height = int(screen_height / perp_wall_dist)
        
        depth_buffer = [100000] * 384
        
        for b in range(12):
            draw_start = line_height * (b - 6) + pitch
            draw_end = line_height + line_height * (b - 6) + pitch
            
            draw_start = max(0, min(screen_height - 1, draw_start))
            draw_end = max(0, min(screen_height - 1, draw_end))
            
            color = world_map[map_x][map_y][b]
            
            if side == 1:
                color = color // 2
                
            if color != 0:
                for y in range(draw_start, draw_end + 1):
                    if depth_buffer[y] > hit:
                        screen_buffer[x][y] = color
                        depth_buffer[y] = hit
                        
    return screen_buffer
```

### Parameters
- `pitch`: Default value is 200. It shifts the vertical position of the voxel layers on the screen [S1, unofficial].
- `cameraPlaneY`: Value is 0.66. The horizontal component `planeX` is 0 [S1, unofficial].

### Edge Cases and Pitfalls
- **Voxel Aspect Ratio**: The source code contains a comment noting that `lineHeight` should be divided by 2 for square voxels, but the implementation omits this division [S1, unofficial].
- **Boundary Conditions**: The DDA loop terminates when `mapX` or `mapY` exceed `[0, mapWidth-1]` and `[0, mapHeight-1]` respectively [S1, unofficial].
- **Depth Buffer Reset**: The `depth` array is re-initialized per ray, indicating per-ray depth management rather than global occlusion [S1, unofficial].

## Operating characteristics
- **Time Complexity**: O(N) per screen column, where N is the average DDA step count plus 12 layer draws [S1, unofficial].
- **Memory Complexity**: O(W * H) for the screen buffer and O(W) for the per-ray depth buffer [S1, unofficial].
- **Measured Performance**: Not given in the sources.
- **Scaling**: Scales linearly with screen width; the fixed 12 layers do not scale with resolution [S1, unofficial].
- **Strengths**: Visualizes voxel thickness and internal structure efficiently using DDA traversal [S1, unofficial].
- **Limitations**: Fixed layer count (12), potential aspect ratio distortion, and per-ray depth management limits cross-ray occlusion [S1, unofficial].
- **When to Use**: When visualizing voxel depth is prioritized over performance [S1, unofficial].
- **When Not to Use**: When high performance is required or dynamic layer counts are needed [S1, unofficial].

## Background
- **Origin**: The method is described in the `voxnine` repository by JCLemme [S1, unofficial].
- **History and Development**: The method extends 2D raycasting by adding a vertical dimension of 12 layers to represent 3D voxels [S1, unofficial].
- **Where it is Used**: Implemented in the `voxnine` project for rendering 3D voxel grids [S1, unofficial].
