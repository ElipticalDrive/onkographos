# Hierarchical DDA with Chunk Stepping

Also called: 3D Voxel Traversal, Chunked DDA Ray Marching, Voxel Ray Marching with DDA & Chunk Stepping

## Overview
This method traces a ray through a hierarchical voxel map by stepping through large chunks using a 3D Digital Differential Analyzer (DDA) algorithm, detecting solid chunks, converting to local coordinates, and continuing the ray until a hit is found or bounds are exceeded [S1, unofficial]. It builds on [Hierarchical DDA](12757-hierarchical-dda.md) by explicitly managing the transition between chunks with varying refractive indices and handling asynchronous chunk loading via flags [S1, unofficial]. It sets itself apart from standard DDA by skipping empty space at the chunk level and from pure voxel marching by maintaining a hierarchical structure that allows for large-step traversal [S1, unofficial].

## How it works
**Inputs:** Ray origin ($rayPos$), ray direction ($rayDir$), inverse ray direction ($invRayDir$), map bounds, chunk size ($CHUNK\_SIZE$), and a hierarchical map data structure containing chunk metadata and voxel data [S1, unofficial].
**Outputs:** A hit result containing the world position, local coordinate, and normal of the first intersected voxel, or a failure state if the ray exits the map or exceeds the range [S1, unofficial].

**Data Structures:**
*   `DNchunk`: Contains `DNivec3 pos` (chunk position), `bool updated`, `uint32_t numVoxels`, `uint32_t numVoxelsGpu`, and `DNcompressedVoxel voxels[8][8][8]` [S1, unofficial].
*   `DNcompressedVoxel`: A 64-bit structure packed as:
    *   `normal` (32 bits): material (8 bits) | nx (8 bits) | ny (8 bits) | nz (8 bits).
    *   `albedo` (32 bits): r (8 bits) | g (8 bits) | b (8 bits) | unused (8 bits) [S1, unofficial].
*   `RaycastHit`: Contains `local` (IVec3), `position` (Vec3), and `normal` (IVec3) [S2, unofficial].

**Parameters:**
*   $CHUNK\_SIZE = 8$ (linear dimension in voxels) [S1, unofficial].
*   $INV\_CHUNK\_SIZE = 1 / CHUNK\_SIZE$ [S1, unofficial].
*   $EPSILON$: Small floating-point offset to prevent self-intersection and clamp boundaries [S1, unofficial].
*   $ignoreFirst$: Boolean flag to skip the first voxel hit during DDA iteration [S1, unofficial].

**Algorithm Steps:**

1.  **Initialization:**
    Compute the initial DDA state for the ray [S1, unofficial]. Calculate `rayStep` as the sign of `rayDir` [S2, unofficial]. Calculate `deltaDist` as the absolute value of `invRayDir` [S2, unofficial]. Initialize `sideDist` to the distance to the first grid plane for each axis using $distance = \frac{world(next\_local) - current\_pos}{dir}$ [S2, unofficial]. Set `ignoreFirst = true` [S1, unofficial].

2.  **Main Loop:**
    While the current voxel position `pos` is within map bounds:
    
    a.  **Chunk Identification:**
        Retrieve the chunk index for the current position: `mapIndex = get_map_index(pos)` [S1, unofficial].
        
    b.  **Chunk Status Check:**
        Fetch the chunk handle and check its flags [S1, unofficial]. If `(mapTile.flags & 3) == 2`, the chunk is solid [S1, unofficial].
        
    c.  **Solid Chunk Handling:**
        If the chunk is solid:
        i.  Compute the exact entry point into the chunk by stepping back along the ray:
            $$updatedRayPos = rayPos + rayDir \times (\min(lastSideDist.x, lastSideDist.y, lastSideDist.z) - EPSILON)$$
        ii. Convert the world-space entry point to chunk-local coordinates:
            $$chunkRayPos = (updatedRayPos - pos) \times CHUNK\_SIZE$$
        iii. Clamp the local ray position to avoid boundary artifacts:
            $$chunkRayPos = \text{clamp}(chunkRayPos, vec3(EPSILON), CHUNK\_SIZE - EPSILON)$$ [S1, unofficial].
        iv. Step through the chunk using a voxel-level DDA:
            Call `step_chunk(pos, mapIndex, rayDir, invRayDir, chunkRayPos, ignoreFirst, maxDepth, hitNormal, voxel, colorAdd, colorMult, refracted)` [S1, unofficial].
        v.  If `step_chunk` returns true:
            Convert back to world coordinates:
            $$rayPos = pos + chunkRayPos \times INV\_CHUNK\_SIZE$$
            Return true (hit found) [S1, unofficial].
        vi. If `step_chunk` reports refraction:
            Update position, reinitialize DDA, and reset `lastSideDist` to zero [S1, unofficial].
            
    d.  **Pending Load Handling:**
        If the chunk is not solid but has a pending load flag, mark it as requested:
        $$map[mapIndex].flags = 3$$
        Set `requested = true` [S1, unofficial].
        
    e.  **DDA Advancement:**
        Update `lastSideDist = sideDist` [S1, unofficial].
        Iterate the DDA:
        $$iterate\_DDA(deltaDist, rayStep, sideDist, pos, hitNormal)$$
        Set `ignoreFirst = false` [S1, unofficial].
        
    f.  **Boundary Check:**
        If the ray exceeds the map bounds or maximum range, terminate [S1, unofficial].

**Pseudocode:**

```python
def trace_ray(ray_origin, ray_direction, map_bounds, chunk_size=8):
    inv_chunk_size = 1.0 / chunk_size
    epsilon = 1e-6
    inv_ray_dir = 1.0 / ray_direction
    ray_step = [1.0 if d > 0 else -1.0 for d in ray_direction]
    delta_dist = [abs(v) for v in inv_ray_dir]

    # Initialize side distances to the first grid plane
    side_dist = []
    for i in range(3):
        if ray_direction[i] > 0:
            side_dist.append((int(ray_origin[i]) + 1 - ray_origin[i]) * inv_ray_dir[i])
        else:
            side_dist.append((int(ray_origin[i]) - ray_origin[i]) * inv_ray_dir[i])

    pos = [int(ray_origin[i] // chunk_size) for i in range(3)]
    ignore_first = True
    last_side_dist = side_dist[:]

    while in_map_bounds(pos, map_bounds):
        map_index = get_map_index(pos, map_bounds)
        chunk_tile = map.get_tile(map_index)

        # Check if chunk is solid (flags & 3 == 2)
        if (chunk_tile.flags & 3) == 2:
            min_dist = min(last_side_dist)
            updated_ray_pos = [ray_origin[i] + ray_direction[i] * (min_dist - epsilon) for i in range(3)]
            chunk_ray_pos = [(updated_ray_pos[i] - pos[i] * chunk_size) * chunk_size for i in range(3)]
            chunk_ray_pos = [max(epsilon, min(chunk_size - epsilon, chunk_ray_pos[i])) for i in range(3)]

            hit_found, refracted, hit_normal = step_chunk(chunk_ray_pos, ray_direction, inv_ray_dir, ignore_first, chunk_size)

            if hit_found:
                ray_origin = [pos[i] * chunk_size + chunk_ray_pos[i] * inv_chunk_size for i in range(3)]
                return True, ray_origin, hit_normal

            if refracted:
                ray_origin = updated_ray_pos
                side_dist = []
                for i in range(3):
                    if ray_direction[i] > 0:
                        side_dist.append((int(ray_origin[i]) + 1 - ray_origin[i]) * inv_ray_dir[i])
                    else:
                        side_dist.append((int(ray_origin[i]) - ray_origin[i]) * inv_ray_dir[i])
                last_side_dist = side_dist[:]
                ignore_first = True
                continue

        # Check for pending load
        if chunk_tile.flags == 3:
            map[map_index].flags = 3
            requested = True

        # Advance DDA
        last_side_dist = side_dist[:]
        min_idx = side_dist.index(min(side_dist))
        pos[min_idx] += ray_step[min_idx]
        # Apply 1.01 multiplier to prevent getting stuck at boundaries [S1, unofficial]
        side_dist[min_idx] += delta_dist[min_idx] * 1.01
        ignore_first = False

    return False, None, None

def in_map_bounds(pos, map_bounds):
    return 0 <= pos[0] < map_bounds[0] and 0 <= pos[1] < map_bounds[1] and 0 <= pos[2] < map_bounds[2]

def get_map_index(pos, map_bounds):
    return pos[0] + pos[1] * map_bounds[0] + pos[2] * map_bounds[0] * map_bounds[1]

def step_chunk(chunk_ray_pos, ray_direction, inv_ray_dir, ignore_first, chunk_size):
    chunk_pos = [0, 0, 0]
    chunk_side_dist = []
    for i in range(3):
        if ray_direction[i] > 0:
            chunk_side_dist.append((1.0 - chunk_ray_pos[i]) * inv_ray_dir[i])
        else:
            chunk_side_dist.append((-chunk_ray_pos[i]) * inv_ray_dir[i])
    chunk_delta = [abs(v) for v in inv_ray_dir]
    chunk_step = [1.0 if d > 0 else -1.0 for d in ray_direction]

    for depth in range(chunk_size * chunk_size * chunk_size):
        if ignore_first:
            ignore_first = False
            continue

        # Check voxel at chunk_pos
        voxel = map.get_voxel(chunk_pos)
        if voxel is not None and not is_empty(voxel):
            return True, False, compute_normal(chunk_pos)

        if is_refractive(voxel):
            return True, True, compute_normal(chunk_pos)

        min_idx = chunk_side_dist.index(min(chunk_side_dist))
        chunk_pos[min_idx] += chunk_step[min_idx]
        chunk_side_dist[min_idx] += chunk_delta[min_idx]

        if not in_map_bounds(chunk_pos, [chunk_size, chunk_size, chunk_size]):
            return False, False, None

    return False, False, None

def compute_normal(local_pos):
    return [local_pos[0], local_pos[1], local_pos[2]]

def is_empty(voxel):
    return voxel is None

def is_refractive(voxel):
    return voxel.material == REFRACTIVE_MATERIAL
```

## Subtopics

### [Voxel Refraction & Total Internal Reflection Handling](8624-voxel-refraction-total-internal-reflection-handling.md)
This method modifies the ray direction upon entering a refractive voxel using Snell's law, with a fallback to the original direction if total internal reflection occurs to prevent infinite ray bouncing and performance degradation. It builds on [Hierarchical DDA with Chunk Stepping](8591-hierarchical-dda-with-chunk-stepping.md) by handling the transition between chunks with varying refractive indices.

## Operating characteristics
**Time Complexity:** The time complexity per DDA iteration is $O(1)$ [S1, unofficial]. Chunk boundary checks and potential asynchronous chunk loading are handled via flags, which may introduce variable latency depending on the loading system [S1, unofficial].
**Memory Complexity:** Memory per chunk is fixed at 512 compressed voxels ($8 \times 8 \times 8$) [S1, unofficial].
**Performance:** The method is optimized for sparse voxel worlds where large empty spaces can be skipped at the chunk level [S1, unofficial]. It is used in the DoonEngine voxel rendering pipeline [S1, unofficial].
**Strengths:** Efficient traversal of large empty volumes; hierarchical structure allows for scalable memory usage; handles refraction and dynamic chunk loading [S1, unofficial].
**Limitations:** Clamping `chunkRayPos` is a temporary workaround to reduce noise and may introduce artifacts; precision issues at chunk boundaries require careful epsilon handling [S1, unofficial].

## Background
This method is used in the DoonEngine voxel rendering pipeline for map and chunk traversal [S1, unofficial]. It represents a practical implementation of hierarchical DDA tailored for real-time voxel rendering with dynamic chunk loading and refraction support [S1, unofficial].
