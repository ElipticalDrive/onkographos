# Optimized Octree DDA Traversal for SSVDAGs

Also called: Symmetry-aware Sparse Voxel DAG Traversal, SSVDAG Traversal

## Overview
This method extends the DDA Tree Traversal with Mini-Stack to support Symmetry-aware Sparse Voxel DAGs (SSVDAGs), a compression format that exploits geometric symmetries to reduce memory footprint [S1, unofficial]. It solves the problem of correctly traversing a DAG where child nodes and leaf voxels may be mirrored relative to their parent's coordinate system. The key distinction from standard octree DDA is the maintenance of a 3-bit `mirror_mask` that tracks reflection transformations, allowing the algorithm to map logical voxel indices to physical storage locations without decompressing the geometry [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A ray $r$ (origin, direction), `ray.t_min`, `ray.t_max`, and a projection factor `proj_factor` for resolution checks.
*   **Output:** The intersection distance $t$ or `NO_INTERSECTION`.

**Data Structures:**
*   **Stack:** Stores tuples `(node_idx, inner_hdr, mirror_mask, level)` to restore state when moving up the tree. Implemented as a dynamically indexed local array (Shader Model 4.0) [S1, unofficial].
*   **Inner Header (`inner_hdr`):** Contains voxel occupancy bits and child pointers.
*   **Leaf Data (`leaf_data`):** Contains voxel occupancy bits for leaf nodes.
*   **Mirror Mask (`mirror_mask`):** A 3-bit integer indicating which reflections (X, Y, Z axes) must be applied to indices [S1, unofficial].

**Helper Functions:**
*   `DDA_init()`: Initializes DDA state for the root node. Returns `(voxidx, ...)`.
*   `DDA_next()`: Advances DDA to the next voxel at the current level. Returns `(voxidx, ...)`.
*   `DDA_down()`: Adjusts DDA state to descend into a child node. Returns `(voxidx, ...)`.
*   `is_in_bounds(voxidx, level)`: Checks if `voxidx` is within the valid range for the current tree level.
*   `inner_voxel_bit(mirrored_voxidx, inner_hdr)`: Checks if the voxel at `mirrored_voxidx` is full in the inner header.
*   `leaf_voxel_bit(mirrored_voxidx, leaf_data)`: Checks if the voxel at `mirrored_voxidx` is full in the leaf data.
*   `fetch_inner_hdr(node_idx)`: Loads the inner header for the given node index.
*   `fetch_leaf_data(node_idx)`: Loads the leaf data for the given node index.
*   `fetch_tagged_ptr(inner_hdr, node_idx, mirrored_voxidx)`: Retrieves the child node index and symmetry mask `m` from the header. Uses a manually unrolled loop to compute offsets for tagged pointers (0, 2, or 4 bytes) [S1, unofficial].
*   `mirror(mask, voxidx, level)`: Applies reflections from `mask` to `voxidx` based on `level`.
*   `resolution_ok(t, cell_size, proj_factor)`: Determines if the current voxel size is sufficient for the desired resolution.

**Algorithm Steps:**

1.  **Initialization:**
    *   Set $t = \text{ray.t\_min}$.
    *   Set `mirror_mask` = 0.
    *   Set `level` = 0.
    *   Set `cell_size` = 0.5.
    *   Initialize DDA: `(voxidx, ...) = DDA_init()`.
    *   Set `node_idx` = 0.
    *   Set `leaf_data` = 0.
    *   Load root header: `inner_hdr = fetch_inner_hdr(node_idx)`.
    *   Compute initial mirrored index: `mirrored_voxidx = mirror(mirror_mask, voxidx, level)`.

2.  **Traversal Loop:**
    *   While $t < \text{ray.t\_max}$:
        1.  **Check Occupancy:**
            *   If `level < MAX_LEVEL`: `is_full_voxel = inner_voxel_bit(mirrored_voxidx, inner_hdr)`.
            *   Else: `is_full_voxel = leaf_voxel_bit(mirrored_voxidx, leaf_data)`.
        2.  **If Empty (`!is_full_voxel`):**
            *   Advance DDA: `(voxidx, ...) = DDA_next()`.
            *   Check Bounds: If `!is_in_bounds(voxidx, level)`:
                *   If Stack is Empty: Return `NO_INTERSECTION`.
                *   Else:
                    *   Pop Stack: `(node_idx, inner_hdr, mirror_mask, level) = stack_pop()`.
                    *   Update Cell Size: `cell_size *= (1 << (old_level - level))` where `old_level` was the level before pop.
                    *   Advance DDA: `(voxidx, ...) = DDA_next()`.
        3.  **If Full (`is_full_voxel`):**
            *   Check Termination: If `level == MAX_LEVEL` or `resolution_ok(t, cell_size, proj_factor)`:
                *   Return $t$ (Intersection Found).
            *   Else (Refine):
                *   If `is_in_bounds(DDA_next())`: Push current state `(node_idx, inner_hdr, mirror_mask, level)` to stack.
                *   Fetch Child: `(m, node_idx) = fetch_tagged_ptr(inner_hdr, node_idx, mirrored_voxidx)`.
                *   Update Mask: `mirror_mask ^= m`.
                *   Increment Level: `level++`.
                *   Halve Cell Size: `cell_size *= 0.5`.
                *   Descend DDA: `(voxidx, ...) = DDA_down()`.
                *   Load Child Data:
                    *   If `level < MAX_LEVEL - 1`: `inner_hdr = fetch_inner_hdr(node_idx)`.
                    *   Else (Leaf):
                        *   Increment Level: `level++`.
                        *   Halve Cell Size: `cell_size *= 0.5`.
                        *   Descend DDA: `(voxidx, ...) = DDA_down()`.
                        *   Load Leaf Data: `leaf_data = fetch_leaf_data(node_idx)`.
        4.  **Update Mirrored Index:**
            *   `mirrored_voxidx = mirror(mirror_mask, voxidx, level)`.

3.  **Termination:**
    *   If loop exits without returning, return `NO_INTERSECTION`.

**Parameters:**
*   `MAX_LEVEL`: The maximum depth of the octree. Not given in the sources.
*   `proj_factor`: Scaling factor for resolution check. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Leaf Refinement:** Leaves are treated as 4x4 blocks, requiring an extra level increment and DDA descent step compared to inner nodes [S1, unofficial].
*   **Pointer Size:** Child pointers are tagged and can be 0, 2, or 4 bytes, requiring specific offset calculation logic in `fetch_tagged_ptr` [S1, unofficial].
*   **Mirror Mask Restoration:** The `mirror_mask` must be pushed to the stack and restored upon popping to ensure correct index mapping when backtracking [S1, unofficial].

```python
def trace_ray(r, proj_factor, MAX_LEVEL):
    t = r.t_min
    mirror_mask = 0
    level = 0
    cell_size = 0.5
    
    # DDA initialization
    voxidx, dda_state = DDA_init()
    node_idx = 0
    leaf_data = 0
    inner_hdr = fetch_inner_hdr(node_idx)
    
    mirrored_voxidx = mirror(mirror_mask, voxidx, level)
    
    while t < r.t_max:
        # Check occupancy
        if level < MAX_LEVEL:
            is_full_voxel = inner_voxel_bit(mirrored_voxidx, inner_hdr)
        else:
            is_full_voxel = leaf_voxel_bit(mirrored_voxidx, leaf_data)
            
        if not is_full_voxel:
            # Empty - move forward
            voxidx, dda_state = DDA_next(dda_state)
            if not is_in_bounds(voxidx, level):
                if stack_is_empty():
                    return NO_INTERSECTION
                else:
                    old_level = level
                    node_idx, inner_hdr, mirror_mask, level = stack_pop()
                    cell_size *= (1 << (old_level - level))
                    voxidx, dda_state = DDA_next(dda_state)
        else:
            # Full - check termination or refine
            if level == MAX_LEVEL or resolution_ok(t, cell_size, proj_factor):
                return t
            
            # Refine
            if is_in_bounds(DDA_next(dda_state)):
                stack_push(node_idx, inner_hdr, mirror_mask, level)
                
            m, node_idx = fetch_tagged_ptr(inner_hdr, node_idx, mirrored_voxidx)
            mirror_mask ^= m
            level += 1
            cell_size *= 0.5
            voxidx, dda_state = DDA_down(dda_state)
            
            if level < MAX_LEVEL - 1:
                inner_hdr = fetch_inner_hdr(node_idx)
            else:
                # Leaf handling
                level += 1
                cell_size *= 0.5
                voxidx, dda_state = DDA_down(dda_state)
                leaf_data = fetch_leaf_data(node_idx)
                
        mirrored_voxidx = mirror(mirror_mask, voxidx, level)
        
    return NO_INTERSECTION
```

## Operating characteristics
*   **Time Complexity:** Proportional to the number of voxels visited along the ray path, including backtracking steps. The overhead of `mirror_mask` updates and tagged pointer fetching is constant per node visit.
*   **Memory Complexity:** Dominated by the mini-stack depth, which is bounded by the tree height. The stack stores `(node_idx, inner_hdr, mirror_mask, level)` per level.
*   **Strengths:** Significantly reduces memory bandwidth and storage by leveraging symmetries (SSVDAG compression). Avoids explicit decompression of mirrored nodes.
*   **Limitations:** Requires careful handling of mirrored indices and tagged pointers. Performance may degrade if the symmetry compression ratio is low.
*   **When to Use:** High-resolution scenes with significant geometric symmetries where memory bandwidth is a bottleneck.
*   **When Not to Use:** Scenes with little symmetry, or when hardware lacks efficient support for the required bitwise operations and stack management.

## Background
SSVDAGs were introduced by Kämpe et al. in 2013 as a compression technique for sparse voxel grids [S1, unofficial]. The optimized DDA traversal for SSVDAGs was presented in a 2017 paper by Albertojaspe, extending the original SVDAG traversal to support more efficient GPU-based ray tracing by integrating symmetry-aware index mapping directly into the DDA loop [S1, unofficial].
