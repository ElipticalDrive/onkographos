# DDA Tree Traversal with Mini-Stack

Also called: Mini-stack traversal, Stack-based hierarchical traversal

## Overview
This method extends the Digital Differential Analyzer (DDA) algorithm for regular grids to N-ary trees, enabling efficient ray traversal of hierarchical sparse voxel structures on GPU shaders [S1, unofficial]. It solves the problem of navigating deep tree hierarchies by maintaining a small stack of DDA states, allowing the ray to descend to the entry leaf, process nodes horizontally, and ascend back up the tree without expensive recursive function calls or large memory allocations [S1, unofficial]. It is distinguished from its siblings by its specific implementation using dynamically indexed local arrays in Shader Model 4.0, optimizing for fixed-depth hierarchies where stack size is known at compile time [S1, unofficial].

## How it works
**Inputs:** Ray origin $\mathbf{o}$, ray direction $\mathbf{d}$, root node address, maximum tree depth $D_{max}$.
**Outputs:** Sequence of leaf voxels intersected by the ray.

**Data Structures:**
1.  **Mini-Stack:** A fixed-size array `stack` of length $D_{max}$.
    *   Each entry `stack[level]` stores:
        *   `dda_params`: The current DDA state (t-values, deltas, current voxel coordinates) for the grid at this level.
        *   `node_addr`: The address of the current node in the indirection pool.
    *   `stack_ptr`: An integer tracking the current depth (top of the stack).
2.  **DDA State:** For a grid of sub-nodes, parameters include:
    *   $t_x, t_y, t_z$: Distance to the next voxel boundary in each axis.
    *   $\Delta t_x, \Delta t_y, \Delta t_z$: Distance between voxel boundaries.
    *   $step_x, step_y, step_z$: Direction of traversal (+1 or -1).
    *   $x, y, z$: Current voxel coordinates within the grid.

**Algorithm Steps:**

1.  **Initialization:**
    *   Set `stack_ptr` = 0.
    *   Initialize DDA parameters for the root grid based on ray $\mathbf{o}$ and $\mathbf{d}$.
    *   Store root node address in `stack[0].node_addr`.

2.  **Descent Phase:**
    *   While `stack_ptr` < $D_{max}$ and the current node is not a leaf:
        *   Retrieve current node address from `stack[stack_ptr].node_addr`.
        *   Determine which child sub-node (grid) the ray enters next using the current DDA state.
        *   Advance DDA state to the entry point of the child sub-node.
        *   Increment `stack_ptr`.
        *   Initialize new DDA parameters for the child grid based on the entry point.
        *   Store child node address in `stack[stack_ptr].node_addr`.

3.  **Leaf Processing:**
    *   Once a leaf node is reached (at `stack_ptr`):
        *   Process the leaf voxels contained within this leaf node along the ray path.
        *   This involves iterating through the leaf's internal structure using the DDA state until the leaf's local boundary is crossed or the ray exits the leaf.

4.  **Horizontal Advance:**
    *   While the ray remains within the current grid level (defined by `stack[stack_ptr]`):
        *   Advance the DDA state to the next voxel in the grid.
        *   If the next voxel is an internal node (not a leaf):
            *   Perform **Descent** into that node (steps 2-3).
        *   If the next voxel is a leaf:
            *   Perform **Leaf Processing** (step 3).
        *   If the ray exits the current grid boundary:
            *   Proceed to **Vertical Ascent**.

5.  **Vertical Ascent:**
    *   While `stack_ptr` > 0 and the ray has exited the current level's boundary:
        *   Decrement `stack_ptr`.
        *   Resume the DDA state stored in `stack[stack_ptr]`.
        *   Continue **Horizontal Advance** from the resumed DDA state.
    *   If `stack_ptr` == 0 and the ray exits the root boundary, terminate traversal.

**Pseudocode:**

```python
def traverse_tree(ray_origin, ray_direction, root_addr, max_depth):
    # Stack stores DDA state and node address for each level
    # stack[level] = { 'dda': DDAState, 'addr': int }
    stack = [None] * max_depth
    stack_ptr = 0
    
    # Initialize root DDA
    current_dda = init_dda(ray_origin, ray_direction)
    stack[0] = { 'dda': current_dda, 'addr': root_addr }
    
    while True:
        level = stack_ptr
        
        # Check if we are at a leaf or need to descend
        node_addr = stack[level]['addr']
        node_type = get_node_type(node_addr)
        
        if node_type == LEAF:
            # Process leaf voxels
            process_leaf(stack[level]['dda'], node_addr)
            
            # Try to advance horizontally or ascend
            if not advance_dda(stack[level]['dda']):
                # Boundary reached, ascend
                if level == 0:
                    break # Done
                stack_ptr -= 1
                continue
            else:
                # Check next voxel type
                next_node_addr = get_child_addr(stack[level]['dda'], node_addr)
                next_type = get_node_type(next_node_addr)
                if next_type != LEAF:
                    # Descend
                    stack_ptr += 1
                    if stack_ptr >= max_depth:
                        break # Error: depth exceeded
                    stack[stack_ptr] = { 
                        'dda': init_child_dda(stack[level]['dda']), 
                        'addr': next_node_addr 
                    }
                    continue
                else:
                    # Next is leaf, process it in next iteration
                    continue
        else:
            # Internal node: descend to the child the ray enters
            stack_ptr += 1
            if stack_ptr >= max_depth:
                break # Error: depth exceeded
            
            # Determine which child to enter
            child_idx = get_next_child_index(stack[level]['dda'])
            child_addr = get_child_addr(stack[level]['dda'], node_addr, child_idx)
            
            # Initialize DDA for the child grid
            child_dda = init_child_dda(stack[level]['dda'])
            
            stack[stack_ptr] = { 'dda': child_dda, 'addr': child_addr }
```

**Parameters:**
*   `max_depth`: Fixed at compile time, corresponding to the maximum depth of the hierarchical structure [S1, unofficial].

**Edge Cases:**
*   **Depth Exceeded:** If `stack_ptr` reaches `max_depth` while still descending, the traversal fails or must handle the error [S1, unofficial].
*   **Ray Exit:** Properly handling the transition from the last level's boundary to termination is critical [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Proportional to the number of nodes and leaves visited by the ray. The DDA step is $O(1)$ per voxel/grid cell.
*   **Memory Complexity:** $O(D_{max})$ for the mini-stack, where $D_{max}$ is the maximum tree depth. This is significantly smaller than a full recursive stack or large explicit stack structures [S1, unofficial].
*   **Hardware:** Designed for GPU shaders (Shader Model 4.0+), leveraging dynamically indexed local arrays for low-latency stack operations [S1, unofficial].
*   **Strengths:** Minimal branching, no need for neighbor tables, efficient memory usage on GPU, suitable for deep hierarchies [S1, unofficial].
*   **Limitations:** Requires fixed maximum depth at compile time; less flexible for dynamic tree structures with unknown depth [S1, unofficial].

## Background
This method was developed as an extension of the Amanatides and Woo DDA algorithm [AW87] to N-ary trees, specifically for interactive exploration of procedural volumes [S1, unofficial]. It addresses the limitations of earlier octree localization methods which were slow and inflexible [S1, unofficial]. The approach leverages Shader Model 4.0 features to implement the stack efficiently within the shader, avoiding the overhead of traditional stack data structures [S1, unofficial].
