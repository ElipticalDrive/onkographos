# Hierarchical Digital Differential Analyzer (HDDA)

Also called: HDDA Tree Marcher, Hierarchical DDA, NanoVDB Ray Marching with HDDA Acceleration, Unity NanoVDB Volume Renderer

## Overview
The Hierarchical Digital Differential Analyzer (HDDA) is a specialized ray traversal algorithm for sparse voxel grids (specifically VDB structures) that performs multi-resolution leapfrogging to efficiently determine intersected voxels or tiles [S1, unofficial][S2]. It solves the problem of slow ray traversal in deep, sparse hierarchies by leveraging the fixed compile-time tree configuration to inline and collapse vertical navigation overhead [S1, unofficial][S2]. Unlike standard DDA which steps voxel-by-voxel, HDDA leaps across empty space at multiple resolution levels, making it distinct from [Leaf Collection](899-leaf-collection.md) (which collects leaves first) and [Point Plane Test Traversal](982-point-plane-test-traversal.md) (which uses geometric tests per node) [S1, unofficial].

## How it works
**Inputs:** A sparse voxel grid (e.g., VDB or NanoVDB) with a hierarchical B+tree structure, a ray defined by origin $\mathbf{o}$, direction $\mathbf{d}$, and interval $[t_{min}, t_{max}]$. For non-linear transforms, an auxiliary binary mask grid is required [S1, unofficial][S2][S4, unofficial].
**Outputs:** A sequence of active voxel/tile intervals $(t_0, t_1)$ along the ray, or hit distances and values for rendering [S1, S3, unofficial].

**Data Structures:**
*   **Grid:** Hierarchical structure with fixed depth/branching factor at compile time [S1, unofficial].
*   **Ray:** Struct containing `origin` (float3), `direction` (float3), `tmin` (float), `tmax` (float) [S4, unofficial].
*   **NodeDDA:** Struct with `state` (DDAState, underlying DDA with voxel_size=child_size), `origin` (Coord, node origin in index space), `dim` (Int32, children per axis: 8, 16, or 32), `child_size` (Int32, child coverage in voxels: 1, 8, or 128), `log2cs` (Int, log2(child_size) for bit-shift index computation) [S3, unofficial].
*   **VRIState:** Struct with `roots` (Vector of tuples, pre-sorted root entries with tmin), `root_idx` (Int), `i2_ndda` (Union{NodeDDA, Nothing}), `i2_node` (Union{InternalNode2, Nothing}), `i1_ndda` (Union{NodeDDA, Nothing}), `i1_node` (Union{InternalNode1, Nothing}) [S3, unofficial].
*   **Auxiliary Mask:** Binary grid (1 bit per voxel) with linear transform, lower resolution, generated by concurrent resampling of the density grid with frustum transform [S1, unofficial][S2].

**Algorithm Steps:**

1.  **Initialization:**
    *   Read grid type and tree handle from buffer. Initialize read accessor with root [S3, unofficial].
    *   If the grid has a non-linear transform (e.g., warped to camera frustum), construct an auxiliary binary VDB with a linear transform [S1, unofficial][S2]. This is done by concurrent resampling of the density grid with the frustum transform onto a binary grid with a linear transform [S1, unofficial][S2].
    *   Perform fast bit-wise topological dilation on the auxiliary binary grid to account for interpolation kernel size [S1, unofficial][S2].

2.  **Root Intersection:**
    *   Find all root InternalNode2 hits, sort by tmin [S3, unofficial].

3.  **State Machine Traversal:**
    *   Phase 1: Drain current I1 DDA for leaf hits.
    *   Phase 2: Step I2 DDA to find next I1 child with AABB hit.
    *   Phase 3: Advance to next pre-sorted root entry [S3, unofficial].

4.  **NodeDDA Query:**
    *   Compute local coordinates $l_x = (ijk[1] - origin[1]) / child\_size$, $l_y = (ijk[2] - origin[2]) / child\_size$, $l_z = (ijk[3] - origin[3]) / child\_size$.
    *   Check $0 \le l_x, l_y, l_z < dim$.
    *   Compute child index $idx = l_x \cdot dim^2 + l_y \cdot dim + l_z$.
    *   Return (inside, idx) [S3, unofficial].

5.  **NodeDDA Step:**
    *   Advance DDA state to next voxel/tile boundary [S3, unofficial].

6.  **Leaf Hit:**
    *   Check AABB hit. Compute $t_{enter}, t_{exit}$ from ray-bbox intersection. Push LeafIntersection to results [S3, unofficial].

7.  **Rendering Loop (Context):**
    *   Initialize `transmittance` = 1.0, `acc_density` = 0.0, `direct_light` = 0.0, `ambient_light` = 0.005 [S4, unofficial].
    *   Loop while `step` < `_RayMarchSamples` and `tmin` < `tmax` [S4, unofficial]:
        *   **Space Skipping (Dimension Check):** Calculate sample position `pos` from `tmin`. Get dimension `dim` using `get_dim_coord(pos)`. If `dim` > 1, increment `step`, add 15 to `tmin`, set `skip` = 15, and continue [S4, unofficial].
        *   **Space Skipping (Density Check):** Evaluate scattering coefficient $\sigma_S$ at `pos`. If $\sigma_S < \text{MIN\_DENSITY}$ (0.01), increment `step`, add 5 to `tmin`, set `skip` = 5, and continue [S4, unofficial].
        *   **Backtracking:** If `skip` > 0, subtract `skip * 0.8` from `tmin` to re-enter the active region, recalculate `pos`, and reset `skip` = 0 [S4, unofficial].
        *   **Accumulation:**
            *   Add $\sigma_S$ to `acc_density`.
            *   Calculate scattered light $S = \sigma_S \times \text{phase\_function}() \times \text{volumetric\_shadow\_2}(pos, acc, \mathbf{d})$ [S4, unofficial].
            *   Calculate integrated scattering $S_{int} = \frac{S - S \cdot e^{-\sigma_E \cdot \text{step\_size}}}{\sigma_E}$ [S4, unofficial].
            *   Guard against division by zero: ensure $\sigma_E \ge 0.000001$ via $\sigma_E = \max(0.000001, \sigma_S)$ [S4, unofficial].
            *   Add `transmittance` $\times S_{int}$ to `direct_light` [S4, unofficial].
            *   Update `transmittance` $\leftarrow \text{transmittance} \times e^{-\sigma_E \cdot \text{step\_size}}$ [S4, unofficial].
        *   **Step Increment:** Increment `step`. Add `step_size` (0.57) to `tmin` [S4, unofficial].

8.  **Final Color Calculation:**
    *   If visualizing steps, return gradient based on step count ratio [S4, unofficial].
    *   Otherwise, `final_color` = (`direct_light` + `ambient_light`) $\times$ `acc_density` [S4, unofficial].
    *   Apply gamma correction: `final_color` = $\text{pow}(\text{final\_color}, 1.0/2.2)$ [S4, unofficial].
    *   Return `float4(final_color, acc_density)` [S4, unofficial].

9.  **Shadow Ray Calculation (`volumetric_shadow_2`):**
    *   Initialize `shadow` = 1.0, `step_size` = 1.0, `jitter` = 0 [S4, unofficial].
    *   Loop 10 times:
        *   Calculate `sample_pos` = `pos` + (`jitter` + `step_size`) $\times$ `light_dir` [S4, unofficial].
        *   Get extinction coefficient $\sigma_E$ at `sample_pos` [S4, unofficial].
        *   Multiply $\sigma_E$ by 0.3 [S4, unofficial].
        *   Update `shadow` $\leftarrow \text{shadow} \times e^{-\sigma_E \cdot \text{step\_size}}$ [S4, unofficial].
        *   Increment `step`.
        *   Update `step_size` $\leftarrow \text{step\_size} \times (2 + \text{random\_float}(sample\_pos))$ [S4, unofficial].
    *   Return `shadow` [S4, unofficial].

**Pseudocode:**
```python
def hdda_traverse(grid, ray):
    """
    Traverses a hierarchical VDB grid using HDDA state machine.
    Returns list of (t_enter, t_exit, leaf_node) tuples.
    """
    # Phase 3: Find and sort root InternalNode2 hits
    roots = find_root_intersections(grid, ray)
    roots.sort(key=lambda x: x[0])
    root_idx = 0
    i2_ndda = None
    i2_node = None
    i1_ndda = None
    i1_node = None
    hits = []

    while root_idx < len(roots):
        # Phase 3: Advance to next pre-sorted root entry
        if i2_node is None or i2_ndda is None:
            if root_idx >= len(roots):
                break
            t_min, i2_node = roots[root_idx]
            i2_ndda = init_node_dda(i2_node, ray, child_size=128, dim=32)
            root_idx += 1

        # Phase 2: Step I2 DDA to find next I1 child with AABB hit
        if i1_node is None or i1_ndda is None:
            inside, child_idx = query_node_dda(i2_ndda, i2_node)
            if inside and get_child_mask(i2_node, child_idx):
                i1_node = get_child(i2_node, child_idx)
                i1_ndda = init_node_dda(i1_node, ray, child_size=8, dim=16)
            else:
                step_node_dda(i2_ndda)
                continue

        # Phase 1: Drain current I1 DDA for leaf hits
        inside, child_idx = query_node_dda(i1_ndda, i1_node)
        if inside and get_child_mask(i1_node, child_idx):
            leaf = get_child(i1_node, child_idx)
            if aabb_hit(ray, leaf):
                t_enter, t_exit = ray_bbox_intersection(ray, leaf)
                hits.append((t_enter, t_exit, leaf))
            step_node_dda(i1_ndda)
        else:
            step_node_dda(i1_ndda)

    return hits

def init_node_dda(node, ray, child_size, dim):
    """Initialize NodeDDA struct with DDA state and node metadata."""
    # dda_init creates state with voxel_size=child_size
    state = dda_init(ray, child_size)
    # log2cs = trailing_zeros(child_size)
    log2cs = bin(child_size - 1).count('0') if child_size > 0 else 0
    return {
        "state": state,
        "origin": node.origin,
        "dim": dim,
        "child_size": child_size,
        "log2cs": log2cs
    }

def query_node_dda(ndda, node):
    """Query NodeDDA: compute local coords, check bounds, return child index."""
    ijk = ndda["state"].current_ijk
    lx = (ijk[1] - ndda["origin"][1]) / ndda["child_size"]
    ly = (ijk[2] - ndda["origin"][2]) / ndda["child_size"]
    lz = (ijk[3] - ndda["origin"][3]) / ndda["child_size"]
    if 0 <= lx < ndda["dim"] and 0 <= ly < ndda["dim"] and 0 <= lz < ndda["dim"]:
        idx = int(lx * ndda["dim"]**2 + ly * ndda["dim"] + lz)
        return True, idx
    return False, -1

def step_node_dda(ndda):
    """Advance DDA state to next voxel/tile boundary."""
    ndda["state"].step()

def find_root_intersections(grid, ray):
    """Find all root InternalNode2 hits. Not given in sources."""
    return []

def get_child_mask(node, idx):
    """Check if child at idx is active in node mask. Not given in sources."""
    return True

def get_child(node, idx):
    """Retrieve child node at index. Not given in sources."""
    return None

def aabb_hit(ray, node):
    """Check if ray intersects node AABB. Standard ray-AABB test."""
    t_min, t_max = ray_aabb_intersect(ray, node.bbox)
    return t_max >= ray.tmin and t_min <= ray.tmax

def ray_bbox_intersection(ray, bbox):
    """Compute t_enter and t_exit for ray vs bounding box. Standard DDA ray-box."""
    t_min = -float('inf')
    t_max = float('inf')
    for i in range(3):
        if abs(ray.direction[i]) < 1e-8:
            if ray.origin[i] < bbox.min[i] or ray.origin[i] > bbox.max[i]:
                return -float('inf'), -float('inf')
        else:
            t1 = (bbox.min[i] - ray.origin[i]) / ray.direction[i]
            t2 = (bbox.max[i] - ray.origin[i]) / ray.direction[i]
            t_min = max(t_min, min(t1, t2))
            t_max = min(t_max, max(t1, t2))
    return t_min, t_max

def dda_init(ray, voxel_size):
    """Initialize standard DDA state for given ray and voxel size."""
    # Standard Amanatides-Woo initialization
    return {"current_ijk": [0, 0, 0], "voxel_size": voxel_size}
```

## Subtopics

### [NanoVolumeHDDA](3125-nanovolumehdda.md)
An iterator for `NanoGrid` that yields merged active spans without heap allocations, merging adjacent leaves/tiles to eliminate seam artifacts at 8-voxel tile edges. Choose when zero-allocation iteration and tile-level merging are required.

## Operating characteristics
**Time Complexity:** Multi-resolution leapfrogging reduces traversal time from $O(N)$ (where $N$ is total voxels) to $O(K)$, where $K$ is the number of active tiles/voxels intersected [S1, unofficial][S2]. Template inlining reduces vertical navigation overhead [S1, unofficial][S2].
**Memory Complexity:** Low, as it traverses the tree without storing large intermediate lists (unlike Leaf Collection) [S1, unofficial]. Auxiliary mask adds $O(M)$ memory where $M$ is the number of voxels in the lower-resolution mask [S1, unofficial][S2].
**Performance:** Tested on RTX 3080 rendering WDAS cloud dataset at 1920x1080 in 6 ms [S4, unofficial].
**Strengths:** Efficient for sparse volumes; minimizes interpolation cost for level sets; handles non-linear transforms via auxiliary mask [S1, unofficial][S2].
**Limitations:** Requires compile-time fixed tree configuration for optimal inlining [S1, unofficial][S2]. Non-linear transforms require auxiliary grid generation [S1, unofficial][S2].

## Background
Originated by Ken Museth in OpenVDB v2, HDDA leverages the B+tree structure of VDB to perform multi-resolution leapfrogging [S1, unofficial][S2]. It was developed to accelerate ray-tracing of narrow-band level set surfaces and volume rendering (e.g., clouds) [S1, unofficial][S2]. The use of template meta-programming to collapse the hierarchical algorithm was a key innovation to reduce vertical navigation overhead [S1, unofficial][S2]. It is used in Unity HDRP for real-time volume rendering [S4, unofficial].
