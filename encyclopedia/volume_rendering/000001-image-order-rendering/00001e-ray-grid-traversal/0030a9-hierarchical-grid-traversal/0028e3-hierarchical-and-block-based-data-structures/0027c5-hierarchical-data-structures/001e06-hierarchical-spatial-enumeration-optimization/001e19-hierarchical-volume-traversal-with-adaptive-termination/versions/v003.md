# Hierarchical Volume Traversal with Adaptive Termination

Also called: Pyramidal Volume Traversal, TraceRay2

## Overview
Hierarchical Volume Traversal with Adaptive Termination is a ray tracing algorithm that uses a pyramidal data structure of binary volumes to skip empty regions and an adaptive termination criterion to stop tracing when opacity changes become negligible [S1]. Unlike geometric ray tracing, which uses bounding volumes or spatial subdivision with lists of primitives, this method uses a hierarchical binary volume structure, which is more efficient for volume data because volume datasets have tens of millions of spatially ordered cells with single samples, whereas geometric scenes have hundreds of cells with many primitives [S1].

## How it works
The method traverses a ray through a hierarchy of binary volumes (a pyramid) to determine which regions contain data [S1]. It adapts the traversal depth based on the content and terminates early if the accumulated opacity is sufficiently high [S1].

### Inputs and Outputs
*   **Input:** Ray parameter $\mathbf{u}$ (defining the ray direction and origin), the pyramidal binary volume structure $\{V_m\}$, the volume data (color and opacity fields), and parameters $\epsilon$, $m_{max}$, $m_{min}$, and $M$ (total levels) [S1].
*   **Output:** Final ray color $\hat{C}(\mathbf{u})$ and accumulated opacity $\alpha(\mathbf{u})$ [S1].

### Data Structures
The core data structure is a pyramid of binary volumes [S1].
*   **Binary Volumes $V_m$:** For each level $m \in \{0, \dots, M\}$, $V_m$ is a 3D grid of bits [S1]. $V_0$ is the base level, and $V_m$ for $m > 0$ is derived from $V_{m-1}$ [S1]. Memory layout: $(2^{M+1} - 1)/7$ bits total for the pyramid [S1].
*   **Volume Data:** Monochrome color and opacity fields [S1]. Memory layout: $2N^3$ bytes for color and opacity per voxel [S1].
*   **Output Image:** Memory layout: $P^2$ bytes [S1].

### Definitions and Formulas
The binary volumes are defined recursively to indicate the presence of non-zero opacity in their spatial extent [S1].

**Base Level ($V_0$):**
$$V_0(\mathbf{i}) = \begin{cases} 1 & \text{if } \alpha(\mathbf{i} + \Delta\mathbf{i}) = 1 \\ 0 & \text{for } \mathbf{i} \in \{1, 2, \dots, N-1\}^3 \text{ and any } \Delta\mathbf{i} \in \{0, 1\}^3 \\ 0 & \text{otherwise} \end{cases}$$
where $\alpha$ is the opacity field, $\mathbf{i}$ is the index, and the condition checks if any of the eight voxels at the vertices of the cell have opacity equal to 1 [S1].

**Higher Levels ($V_m, m > 0$):**
$$V_m(\mathbf{i}) = \begin{cases} 1 & \text{if } V_{m-1}(2\mathbf{i} - \Delta\mathbf{i}) = 1 \\ 0 & \text{otherwise} \end{cases}$$
for $\mathbf{i} \in \{1, 2, \dots, \frac{N-1}{m+1}\}^3$ and any $\Delta\mathbf{i} \in \{0, 1\}^3$ [S1]. This means a cell at level $m$ is 1 if any of the eight cells at level $m-1$ that form its octants are 1 [S1].

### Parameters
*   $\epsilon$: Threshold for significant color change. Default value 0.05. Higher values reduce rendering time, lower values reduce artifacts [S1].
*   $m_{max}$: Starting level for traversal. Set to $M - 2$ for all values of $M$ to minimize traversal costs [S1].
*   $m_{min}$: Lowest level to descend to before rendering. Set to 2 for the current implementation to avoid the high cost of ray-cell intersections at level zero [S1].
*   $M$: Total number of levels in the pyramid [S1].

### Algorithm Steps
The algorithm processes each ray $\mathbf{u}$ as follows [S1]:

1.  Initialize ray color $\hat{C}(\mathbf{u})$ and opacity $\alpha(\mathbf{u})$ to 0 [S1].
2.  Set ray position $\mathbf{x}$ to the entry point of the ray into the volume using `First(u)` [S1].
3.  Set current level $m$ to $m_{max}$ [S1].
4.  Loop while the ray position $\mathbf{x}$ is in bounds (`InBounds(x)`) and accumulated opacity $\alpha(\mathbf{u})$ is less than or equal to $1 - \epsilon$ [S1]:
    a.  Calculate the cell index $\mathbf{i}$ at current level $m$ containing point $\mathbf{x}$ using the `Index(m, x)` procedure [S1].
    b.  If the cell value $V_m(\mathbf{i})$ is 1 and $m > m_{min}$:
        i.  Decrement level $m$ by 1 to descend into the hierarchy ($m := m - 1$) [S1].
        ii. Continue to the next iteration of the loop to re-evaluate the cell at the new level [S1].
    c.  Else (if cell is 1 and at min level, or cell is 0):
        i.  If the cell value $V_m(\mathbf{i})$ is 1:
            1.  Determine the exit point of the current cell along the ray using `Next(m, x, u)` [S1].
            2.  Call `RenderCell(u, x, Next(m, x, u))` to render the interval from current $\mathbf{x}$ to the next cell entry point [S1].
        ii. Advance to the next cell on the same level [S1].
        iii. While the parent of the new cell differs from the parent of the old cell and $m < M$:
            1.  Move up to the parent cell ($\mathbf{i} := \text{Parent}(m, \mathbf{i})$) [S1].
            2.  Increment level $m$ ($m := m + 1$) [S1].
        iv. Update ray position $\mathbf{x}$ to the entry point of the next cell at the current level $m$ ($\mathbf{x} := \text{Next}(m, \mathbf{x}, \mathbf{u})$) [S1].

### RenderCell Procedure
The `RenderCell` procedure handles the resampling and compositing for a specific interval along the ray defined by entry $\mathbf{x}_1$ and exit $\mathbf{x}_2$ [S1].

1.  Define image bounds $\mathbf{U}_1$ and $\mathbf{U}_2$ for the cell interval using `Image(x1)` and `Image(x2)` [S1].
2.  Loop through evenly spaced sample locations $\mathbf{U}$ within this interval from $\mathbf{U}_1$ to $\mathbf{U}_2$ [S1]. Evenly spaced locations are superimposed to avoid noise artifacts caused by resampling at non-uniformly spaced points determined by ray-cell intersections [S1].
3.  For each sample $\mathbf{U}$:
    a.  Get object space coordinates $\mathbf{x}$ using `Object(U)` [S1].
    b.  Check if the base level binary volume $V_0$ at the index of $\mathbf{x}$ is 1 (`V_0(Index(0, x))`) [S1].
    c.  If 1:
        i.  Resample color $\hat{C}(\mathbf{U})$ and opacity $\alpha(\mathbf{U})$ from the volume data using `Sample` [S1].
        ii. Composite the sample into the ray:
            $$\hat{C}(\mathbf{u}) := \hat{C}(\mathbf{u}) + \hat{C}(\mathbf{U})(1 - \alpha(\mathbf{u}))$$
            $$\alpha(\mathbf{u}) := \alpha(\mathbf{u}) + \alpha(\mathbf{U})(1 - \alpha(\mathbf{u}))$$ [S1].

### Pseudocode
```python
def TraceRay2(u, epsilon, m_max, m_min, M, V, InBounds, First, Index, Next, Parent, RenderCell):
    C_ray = 0.0
    alpha_ray = 0.0
    x = First(u)
    m = m_max
    while InBounds(x) and alpha_ray <= 1.0 - epsilon:
        i = Index(m, x)
        if V[m][i] == 1 and m > m_min:
            m -= 1
            continue
        else:
            if V[m][i] == 1:
                x_exit = Next(m, x, u)
                C_ray, alpha_ray = RenderCell(u, x, x_exit, C_ray, alpha_ray, V)
            x_next = Next(m, x, u)
            while m < M and Parent(m, Index(m, x_next)) != Parent(m, i):
                i = Parent(m, i)
                m += 1
            x = x_next
    return C_ray, alpha_ray

def RenderCell(u, x1, x2, C_ray, alpha_ray, V):
    U1 = Image(x1)
    U2 = Image(x2)
    for y in range(U1[1], U2[1] + 1):
        for x in range(U1[0], U2[0] + 1):
            U = (x, y)
            obj_x = Object(U)
            if V[0][Index(0, obj_x)] == 1:
                C_sample = Sample(V.color, obj_x)
                alpha_sample = Sample(V.opacity, obj_x)
                C_ray = C_ray + C_sample * (1.0 - alpha_ray)
                alpha_ray = alpha_ray + alpha_sample * (1.0 - alpha_ray)
    return C_ray, alpha_ray

# [G] Standard projection/resampling helpers:
# First(u): computes ray entry point into volume bounds.
# InBounds(x): returns True if x is inside volume bounds.
# Index(m, x): maps object-space coordinates x to cell index at level m.
# Next(m, x, u): computes exit point of cell at level m along ray u from x.
# Parent(m, i): returns parent cell index of i at level m.
# Image(x): maps object-space coordinates x to 2D image pixel coordinates.
# Object(U): maps 2D image pixel U to object-space coordinates.
# Sample(field, x): trilinearly interpolates field value at object-space x.
```

### Edge Cases and Pitfalls
*   **Resampling Artifacts:** Resampling at non-uniformly spaced points (determined by ray-cell intersections) adds noise artifacts to the image. The solution is to superimpose evenly spaced sample locations and only resample at those specific points [S1].
*   **Level Zero Descent:** Descending to level zero is inefficient for orthographic projections because ray-cell intersection costs exceed simple differencing. The solution is to stop descent at $m_{min}=2$ and render level-zero cells within that higher-level cell [S1].

## Operating characteristics
*   **Time Complexity:** The traversal skips empty regions, reducing the number of samples taken [S1]. The adaptive termination stops tracing when opacity is high, further reducing work [S1]. The cost of traversal is minimized by starting at $m_{max} = M - 2$ [S1].
*   **Memory Complexity:** The memory required is $2N^3$ bytes for the volume data, $(2^{M+1} - 1)/7$ bits for the pyramid, and $P^2$ bytes for the output image [S1].
*   **Strengths:** Efficient for volume data with large empty regions. The hierarchical structure allows skipping large empty areas. The adaptive termination reduces work for opaque regions [S1].
*   **Limitations:** Inefficient if the volume is mostly opaque or has no empty regions, as the hierarchy may not provide significant skipping. Descending to level zero is inefficient for orthographic projections due to high intersection costs [S1].
*   **When to Use:** Suitable for volume datasets with significant empty space and where ray-cell intersection costs are high (e.g., orthographic projections) [S1].
*   **When Not to Use:** Not suitable for geometric scenes with many primitives per cell, as the method is optimized for volume data with single samples per cell [S1].

## Background
The method was introduced in the paper "Efficient ray tracing of volume data" [S1]. It is based on the observation that volume datasets contain coherent regions of uninteresting voxels (opacity zero) and can be encoded as a hierarchical spatial enumeration represented by a pyramid of binary volumes [S1]. The method is also known as Pyramidal Volume Traversal or TraceRay2 [S1].
