# Density Grid Update with EMA

Also called: EMA Occupancy Grid Update

## Overview
This method updates a 3D density grid using an Exponential Moving Average (EMA) of newly queried densities to stabilize training and refine the representation of occupied space [S1, S2, unofficial]. It builds on [Occupancy Grid Update](2916-occupancy-grid-update.md) by maintaining a continuous density value per voxel rather than just binary occupancy, allowing for smoother transitions and better gradient flow during neural radiance field training [S2, unofficial].

## How it works
The method periodically refreshes the density grid by sampling points in world space, querying a neural network for density, and updating the grid using an EMA maximum operation.

**Inputs:**
- `self.density_grid`: 3D tensor of shape `[resolution, resolution, resolution]` (or multi-resolution hierarchy) storing current density values.
- `self.binaries`: 3D tensor of shape `[resolution, resolution, resolution]` storing binary occupancy flags.
- `self.occs`: 1D tensor of shape `[total_cells]` storing continuous occupancy estimates used for thresholding.
- `self.aabbs`: 2D tensor of shape `[levels, 6]` storing axis-aligned bounding boxes `[min_x, min_y, min_z, max_x, max_y, max_z]` for each level.
- `self.resolution`: Integer, the base resolution of the grid.
- `self.levels`: Integer, number of mipmap levels.
- `self.cells_per_lvl`: Integer, total number of cells per level.
- `self.bound`: Float, the side length of the world-space bounding box (assumed cubic).
- `occ_eval_fn`: Callable taking `(N, 3)` coordinates and returning `(N, 1)` occupancy values.
- `density`: Callable (neural network) taking `(N, 3)` coordinates and returning `(N, 1)` density values.
- `step`: Current training step integer.
- `occ_thre`: Float threshold for binarization.
- `ema_decay`: Float decay factor for EMA.
- `warmup_steps`: Integer number of initial steps to sample all cells.
- `n`: Integer, update frequency (every `n` steps).

**Outputs:**
- Updated `self.density_grid`.
- Updated `self.binaries`.
- Updated `self.occs`.
- Updated `self.mean_density`.

**Data Structures:**
- `density_grid`: `torch.float32` tensor, shape `[res, res, res]` for single level or `[levels, res, res, res]` for hierarchy.
- `binaries`: `torch.bool` tensor, same shape as `density_grid`.
- `occs`: `torch.float32` tensor, shape `[cells_per_lvl * levels]`.
- `grid_coords`: `torch.int64` tensor, shape `[N, 3]`, indices of sampled cells.

**Parameters:**
- `occ_thre`: Default `0.01` [S1, unofficial].
- `ema_decay`: Default `0.95` [S1, S2, unofficial].
- `warmup_steps`: Default `256` [S1, S2, unofficial].
- `n`: Update every `n` steps. Default `16` [S2, unofficial].

**Steps:**

1. **Check Update Condition**: If `step % n != 0` or not in training mode, return [S2, unofficial]. If `step < warmup_steps`, set `sample_all = True`, else `sample_all = False` [S1, S2, unofficial].

2. **Sample Cells**:
   - If `sample_all`: Retrieve all cell indices using `self._get_all_cells()`. Let `indices` be the list of all cell indices across all levels.
   - If not `sample_all`: Set `N = self.cells_per_lvl // 4`. Sample `N` uniform and `N` occupied cells using `self._sample_uniform_and_occupied_cells(N)`. Let `indices` be the combined list of sampled indices [S1, unofficial].

3. **Retrieve Grid Coordinates**: For each level `lvl` and its corresponding `indices`, retrieve the 3D grid coordinates: `grid_coords = self.grid_coords[indices]` [S1, unofficial].

4. **Calculate Half Grid Size**: `half_grid_size = self.bound / self.resolution` [S2, unofficial].

5. **Jitter Sampling**: Add uniform random noise to grid coordinates to jitter sampling within voxels:
   $$ x_{local} = \frac{grid\_coords + \text{rand}(\text{shape}(grid\_coords), \text{dtype}=\text{float32})}{self.resolution} $$
   where `rand` generates values in $[0, 1)$ [S1, unofficial].

6. **Transform to World Space**: Transform voxel coordinates from $[0, 1]^3$ to world space using the AABB for the level:
   $$ x_{world} = self.aabbs[lvl, :3] + x_{local} \times (self.aabbs[lvl, 3:] - self.aabbs[lvl, :3]) $$
   This results in `x` of shape `[N, 3]` [S1, unofficial].

7. **Evaluate Occupancy**: Query the occupancy evaluation function at world coordinates:
   $$ occ = occ\_eval\_fn(x).squeeze(-1) $$
   Result `occ` has shape `[N]` [S1, unofficial].

8. **Update Occupancy Estimates (EMA Max)**:
   - Compute global cell IDs: `cell_ids = lvl * self.cells_per_lvl + indices` [S1, unofficial].
   - Update occupancy values using EMA maximum:
     $$ self.occs[cell\_ids] = \max(self.occs[cell\_ids] \times ema\_decay, occ) $$
     Note: The implementation uses `torch.maximum` instead of `scatter_max` [S1, unofficial].

9. **Compute Binarization Threshold**:
   $$ thre = \text{clamp}(\text{mean}(self.occs[self.occs \ge 0]), \text{max}=occ\_thre) $$
   This clamps the mean of non-negative occupancy values to `occ_thre` [S1, unofficial].

10. **Update Binary Occupancy Grid**:
    $$ self.binaries = (self.occs > thre).view(self.binaries.shape) $$
    This reshapes the 1D occupancy comparison to the 3D grid shape [S1, unofficial].

11. **Generate Coordinate Lines (Density Update Path)**:
    - Calculate resolution: `resolution = self.density_grid.shape[0]` [S2, unofficial].
    - Generate coordinate lines for X, Y, Z axes using `torch.linspace` from `-self.bound + half_grid_size` to `self.bound - half_grid_size`. Split these lines into chunks of 128 [S2, unofficial].
    - Construct meshgrid points from these chunks:
      $$ xx, yy, zz = \text{meshgrid}(xs, ys, zs, \text{indexing}="ij") $$
    - Concatenate and reshape points to `[N, 3]`:
      $$ pts = \text{cat}([xx.reshape(-1, 1), yy.reshape(-1, 1), zz.reshape(-1, 1)], \text{dim}=-1) $$
    - Add uniform noise in range `[-half_grid_size, half_grid_size]` to points:
      $$ pts += (\text{rand}(\text{shape}(pts)) \times 2 - 1) \times half\_grid\_size $$
    - Pad points to a multiple of 128 for manual padding:
      $$ pad\_n = 128 - (N \% 128) $$
      (If `pad_n > 0`, pad `pts` with dummy points) [S2, unofficial].

12. **Query Density**:
    - Initialize a temporary grid: `tmp_grid = torch.zeros_like(self.density_grid)` [S2, unofficial].
    - Query density from the network:
      $$ density\_vals = self.density(pts.to(tmp\_grid.device))[:n].reshape(lx, ly, lz).detach() $$
      where `n` is the number of valid points (before padding) and `lx, ly, lz` are the chunk dimensions [S2, unofficial].
    - Assign density to the temporary grid at the corresponding slice:
      $$ tmp\_grid[xi \times 128 : ..., yi \times 128 : ..., zi \times 128 : ...] = density\_vals $$
      Iterate over chunks `xi, xs` in X, `yi, ys` in Y, `zi, zs` in Z [S2, unofficial].

13. **Update Density Grid (EMA Max)**:
    $$ self.density\_grid = \max(self.density\_grid \times decay, tmp\_grid) $$
    This applies the EMA maximum update to the density grid [S2, unofficial].

14. **Update Mean Density**:
    $$ self.mean\_density = \text{mean}(self.density\_grid).item() $$
    [S2, unofficial].

15. **Reinitialize Density Grid Tree (Optional/Implementation Specific)**:
    - Reinitialize the density grid tree with current resolution and levels:
      $$ self.tree = vdbgrid\_cuda.DensityGrid(*self.resolution, self.levels) $$
    - Set the values of the density grid tree from the binary occupancy grid:
      $$ self.tree.setValues(self.binaries.cpu()) $$
    [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Precision**: The use of `torch.maximum` for EMA updates is noted as empirically similar to `scatter_max` but may have different memory access patterns [S1, unofficial].
- **Boundaries**: The jittering ensures points are sampled within voxels, avoiding boundary issues [S1, S2, unofficial].
- **Degenerate Input**: If `n_alive == 0` in the ray marching phase (not part of this update method but related), the process breaks [S1, unofficial]. For this update, if no cells are sampled, the grid remains unchanged.
- **Padding**: Points must be padded to a multiple of 128 for the chunked processing [S2, unofficial].

## Subtopics

### Occupancy Grid Update with EMA
A variant that integrates the density grid update logic into the broader occupancy grid estimator class. It adds a step check (`step % n == 0`) and calls the internal `_update` method which handles the sampling and EMA logic described above. It distinguishes itself by being a method within a class rather than a standalone algorithm, managing the update frequency `n` and training state explicitly [S1, unofficial].

## Operating characteristics
- **Time Complexity**: Depends on the number of sampled cells `N` and the cost of the neural network evaluation. Sampling is $O(N)$, network evaluation is $O(N)$, and grid update is $O(N)$ or $O(res^3)$ if full grid is processed (though chunked processing reduces this).
- **Memory Complexity**: $O(res^3)$ for the density grid and occupancy arrays. Temporary grids and points are proportional to the number of sampled points or chunks.
- **Measured Performance**: Not given in the sources.
- **Scaling**: Scales with the number of levels and resolution. The chunked processing (128 points) helps with memory bandwidth [S2, unofficial].
- **Strengths**: Stabilizes training by smoothing density updates [S2, unofficial]. Efficiently updates only relevant cells [S1, unofficial].
- **Limitations**: Requires careful tuning of `ema_decay` and `occ_thre` [S1, unofficial]. The use of `torch.maximum` may not be as efficient as `scatter_max` for large `N` [S1, unofficial].
- **When to use**: During training of neural radiance fields to maintain a stable occupancy representation [S1, S2, unofficial].
- **When not to use**: During inference if the grid is static, or if memory is extremely constrained and full grid updates are prohibitive.

## Background
The method originates from the implementation of faster occupancy grid updates for neural radiance fields, specifically in the `faster-occgrid` repository [S1, unofficial]. It is also referenced in the `cv-master-ex` repository [S2, unofficial]. The use of EMA for density updates is a technique to stabilize the training process by preventing large fluctuations in density values [S1, S2, unofficial].
