# Rasterizing Bounding Geometry for Empty Space Skipping
Also called: Bounding Geometry Rasterization, Raster-based Bounding Box Culling, Rasterizing Bounding Geometry
## Overview
This method exploits hardware-accelerated rasterization to skip over empty space in volume rendering, avoiding the overhead of explicit tree traversal on the GPU [S1, unofficial]. It sets itself apart from sibling methods like [Early Shader Termination](969-early-shader-termination.md) by using the fragment positions of rasterized bounding geometry faces as the start and end points for ray casting, which can lead to fewer look-ups into the empty-space skipping data structure compared to traditional octree structures [S1, unofficial].
## How it works
**Inputs and Outputs:**
- Input: Bounding geometries (e.g., bounding boxes of leaf nodes of a tree structure) [S1, unofficial].
- Output: Ray casting start and end points derived from fragment positions [S1, unofficial].

**Data Structures:**
- Bounding Geometry: Typically bounding boxes of leaf nodes [S1, unofficial].
- Fragment Buffer: Stores fragment positions of front and back faces [S1, unofficial].

**Steps:**
1. Rasterize the bounding geometries (e.g., bounding boxes of leaf nodes) using hardware-accelerated rasterization [S1, unofficial].
2. Retrieve the fragment positions of the front and back faces of the rasterized bounding geometry [S1, unofficial].
3. Use the fragment position of the front face as the start point for ray casting [S1, unofficial].
4. Use the fragment position of the back face as the end point for ray casting [S1, unofficial].
5. Cast rays between the start and end points to sample the volume [S1, unofficial].

### SparseLeap Rasterization
SparseLeap Rasterization is a variant where the occupancy geometry is generated from a lazily constructed occupancy-histogram tree. Each node in this tree has one of three occupancy classes: empty (if completely empty), non-empty (if non-empty), or unknown (if such information is not yet known) [S1, unofficial]. It utilizes rasterization hardware to avoid hierarchy traversal on the GPU by only traversing per-pixel lists of non-empty ray segments produced through rasterizing occupancy geometry [S1, unofficial]. This approach optimizes both the number of look-ups into the data structure used for empty-space skipping and the number of samples along each viewing ray [S1, unofficial]. An advantage of SparseLeap over other empty-space skipping techniques is that it is agnostic of the data structure used for managing volume data (e.g., page-table hierarchies or octrees) and can be used in conjunction with them [S1, unofficial].

## Background
