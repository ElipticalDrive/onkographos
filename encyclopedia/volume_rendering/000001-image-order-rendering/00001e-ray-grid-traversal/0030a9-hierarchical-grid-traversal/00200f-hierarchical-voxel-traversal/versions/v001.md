# Hierarchical Voxel Traversal

Also called: Recursive Voxel Traversal

## Overview
Hierarchical Voxel Traversal is a recursive raycasting algorithm designed to traverse nested voxel structures, such as chunks containing subvoxels, to find intersections [S1, unofficial]. It distinguishes itself from flat traversal methods by transforming rays into local subvoxel space when entering a detail voxel, allowing for efficient handling of nested voxel data [S1, unofficial]. Unlike [First Active Voxel Detection](4196-first-active-voxel-detection.md) which focuses on finding the first non-empty voxel, this method fully traverses the hierarchy to compute precise intersections within detail voxels.

## How it works
**Inputs and Outputs:**
- **Input:** A ray defined by origin, direction, transform, and optional length; a hierarchical voxel structure (e.g., `VoxelWorldAccess` or generic `Voxel<T>`); maximum iteration limits.
- **Output:** An `Intersection` struct containing the hit position, normal, index, and an optional inner intersection (for detail voxels).

**Data Structures:**
- **Ray:** Contains `origin` (Vec3), `direction` (Vec3), `transform` (Mat4), and `length` (Option<f32>) [S1, unofficial].
- **Voxel:** Generic type `T` with properties `WIDTH`, `DY`, `DZ`, `SCALE`, and `COUNT`. Coordinates are mapped to linear indices using $i = x + y \cdot DY + z \cdot DZ$ [S1, unofficial].

**Steps:**

1.  **World Access Entry:**
    - Calculate the world origin in float3.
    - Compute the current ray position in chunk-local space:
      $$current = ray.origin \cdot (1.0 / self.world.scale) - origin$$
    - Call the core `cast` function with the world access, ray, current position, direction, and max iterations (30) [S1, unofficial].

2.  **Voxel Check (World Access):**
    - Validate coordinates are within world bounds: $coord[i] \ge 0$ and $coord[i] < self.world.dims[i]$ [S1, unofficial].
    - Compute linear index: $i = coord[0] + coord[1] \cdot dims[0] + coord[2] \cdot dims[0] \cdot dims[1]$ [S1, unofficial].
    - If the voxel exists and is visible:
        - Construct a local ray by applying scaling (`sc`) and translation (`coord * sc`) to the ray's transform.
        - Recursively cast on the voxel [S1, unofficial].
    - If the voxel is a detail voxel (has subvoxels):
        - Return an `Intersection` with `inner` set to the sub-intersection, `index` set to the chunk index, and current position/normal [S1, unofficial].
    - If the voxel does not exist (empty chunk slot):
        - Return an `Intersection` with `inner: None`, `index: 0`, and current position/normal [S1, unofficial].

3.  **Generic Voxel Entry:**
    - Inverse the ray transform.
    - Scale by `SUBDIV` ($2^{SUBDIV}$).
    - Transform ray origin and direction into subvoxel space [S1, unofficial].
    - Move ray origin to the start of the bounding box (0 to scale) if not already inside. For each axis $i$:
        - If $direction[i] > 0$, $t = (0.0 - current[i]) / direction[i]$.
        - Else if $direction[i] < 0$, $t = (scale - current[i]) / direction[i]$.
        - If $t > 0$, advance $current$ [S1, unofficial].
    - Call core `cast` with the voxel, ray, current position, direction, and max iterations $6 \cdot T::WIDTH$ [S1, unofficial].

4.  **Generic Voxel Check:**
    - Validate coordinates within $T::WIDTH$.
    - Compute linear index: $i = coord[0] + coord[1] \cdot T::DY + coord[2] \cdot T::DZ$ [S1, unofficial].
    - If the voxel is visible and is detail:
        - Construct local ray with scaling $T::SCALE$ and translation $coord \cdot T::SCALE$.
        - Recursively cast. Return intersection with inner sub-hit [S1, unofficial].
    - If the voxel is visible and NOT detail:
        - Return intersection with `inner: None`, `index: i`, current position/normal [S1, unofficial].

5.  **Core Cast Function:**
    - Initialize integer coordinates `current_i` from `current` floor.
    - Adjust `current_i` down by 1 if `current` is very close to an integer boundary and direction is negative [S1, unofficial].
    - Check starting position first using `raycast.check`. If hit, return immediately [S1, unofficial].
    - Loop up to `iterations`:
        - Calculate distance to next grid plane intersection for each axis using `intersect(current_i[i], current[i], direction[i])`.
        - Find minimum distance $i[d]$.
        - Advance `current` by $direction \cdot i[d]$ where $d$ is the axis with minimum intersection distance.
        - Decrement `current_i[d]` if $direction[d] < 0$ [S1, unofficial].

**Pseudocode:**

```python
def cast(world_access, ray, current, direction, max_iterations):
    # Step 1: World Access Entry
    # current is already in chunk-local space
    return _cast_voxel(world_access, ray, current, direction, max_iterations)

def _cast_voxel(world_access, ray, current, direction, max_iterations):
    # Step 2: Voxel Check (World Access)
    # Assuming world_access provides dims and scale
    # Compute linear index from current coordinates
    # Check bounds and existence
    if not world_access.check(current):
        return Intersection(inner=None, index=0, position=current, normal=vec3(0))
    
    voxel = world_access.get(current)
    if not voxel.visible():
        return Intersection(inner=None, index=0, position=current, normal=vec3(0))
        
    if voxel.is_detail():
        # Construct local ray
        sc = world_access.scale
        local_ray = transform_ray(ray, sc, current * sc)
        # Recursively cast
        sub_hit = cast(world_access, local_ray, vec3(0), local_ray.direction, 30)
        return Intersection(inner=sub_hit, index=world_access.index(current), position=current, normal=vec3(0))
    else:
        return Intersection(inner=None, index=world_access.index(current), position=current, normal=vec3(0))

def cast_generic(voxel, ray, current, direction, max_iterations):
    # Step 3: Generic Voxel Entry
    # Inverse transform and scale
    inv_transform = inverse(ray.transform)
    subdiv = 2 ** voxel.SUBDIV
    ray.origin = inv_transform * (ray.origin * subdiv)
    ray.direction = inv_transform * (ray.direction * subdiv)
    
    # Move ray origin to start of bounding box
    scale = voxel.SCALE
    for i in range(3):
        if direction[i] > 0:
            t = (0.0 - current[i]) / direction[i]
        elif direction[i] < 0:
            t = (scale - current[i]) / direction[i]
        else:
            t = float('inf')
        if t > 0:
            current += direction * t
            
    return _cast_generic_voxel(voxel, ray, current, direction, 6 * voxel.WIDTH)

def _cast_generic_voxel(voxel, ray, current, direction, max_iterations):
    # Step 4: Generic Voxel Check
    # Check bounds
    if not voxel.check(current):
        return Intersection(inner=None, index=0, position=current, normal=vec3(0))
        
    index = voxel.coord_to_index(current)
    voxel_data = voxel.get(index)
    
    if not voxel_data.visible():
        return Intersection(inner=None, index=0, position=current, normal=vec3(0))
        
    if voxel_data.is_detail():
        sc = voxel.SCALE
        local_ray = transform_ray(ray, sc, current * sc)
        sub_hit = cast_generic(voxel_data, local_ray, vec3(0), local_ray.direction, 6 * voxel_data.WIDTH)
        return Intersection(inner=sub_hit, index=index, position=current, normal=vec3(0))
    else:
        return Intersection(inner=None, index=index, position=current, normal=vec3(0))

def core_cast(voxel, ray, current, direction, max_iterations):
    # Step 5: Core Cast Function
    # Initialize integer coordinates
    current_i = floor(current)
    
    # Precision fix for negative direction at integer boundaries
    for i in range(3):
        if abs(current[i] - current_i[i]) < epsilon and direction[i] < 0:
            current_i[i] -= 1
            
    # Check starting position
    if voxel.check(current):
        return _cast_generic_voxel(voxel, ray, current, direction, max_iterations)
        
    # Traverse grid
    for _ in range(max_iterations):
        # Calculate distance to next grid plane
        distances = []
        for i in range(3):
            if direction[i] == 0:
                distances.append(float('inf'))
            else:
                # intersect function calculates distance to next integer plane
                # assuming current_i[i] is the current voxel index
                # distance = (current_i[i] + (1 if direction[i] > 0 else 0) - current[i]) / direction[i]
                # Note: Exact formula depends on intersect implementation details not fully specified
                # Using standard AET traversal logic
                next_plane = current_i[i] + (1 if direction[i] > 0 else 0)
                distances.append((next_plane - current[i]) / direction[i])
                
        d = argmin(distances)
        min_dist = distances[d]
        
        if min_dist == float('inf'):
            break
            
        # Advance current
        current += direction * min_dist
        current_i[d] += (1 if direction[d] < 0 else -1) # Decrement if direction is negative
        
        # Check hit at new position
        if voxel.check(current):
            return _cast_generic_voxel(voxel, ray, current, direction, max_iterations)
            
    return Intersection(inner=None, index=0, position=current, normal=vec3(0))
```

**Parameters:**
- Max iterations for `VoxelWorldAccess` raycasting: 30 [S1, unofficial].
- Max iterations for `Voxel<T>` raycasting: $6 \cdot T::WIDTH$ [S1, unofficial].

**Pitfalls:**
- Precision issues at integer boundaries: If the ray is exactly on an integer coordinate and moving in a negative direction, the integer coordinate index must be decremented to avoid missing the voxel or double-checking [S1, unofficial].
