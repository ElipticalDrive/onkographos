# Fixed-Level Octree Traversal
Also called: Level Rendering
## Overview
Fixed-Level Octree Traversal is a CPU-based ray casting technique that renders sparse voxel octrees by limiting the traversal depth to a fixed maximum level (`maxlevel`) [S1, unofficial]. It solves the problem of rendering large sparse volumes by avoiding deep recursive traversal, instead processing only the top-level nodes of the octree [S1, unofficial]. It differs from recursive octree traversal by stopping the traversal early at a specific depth, applying lighting directly on the leaf nodes reached, and writing the final color without volumetric integration or alpha blending [S1, unofficial].
## How it works
### Inputs and Outputs
**Inputs:**
*   `tree`: The sparse voxel octree structure [S1, unofficial].
*   `rc`: A rendering context containing `rc.n_y` (image height), `rc.lights` (array of light sources), `rc.camera` (camera object with `e_` eye position), and `rc.getRayForPixel(x, y)` (ray generation function) [S1, unofficial].
*   `maxlevel`: The fixed maximum depth of the octree to traverse [S1, unofficial].
*   `texture_array`: Output buffer of size $W \times H \times 4$ (RGBA), where $W$ is image width [S1, unofficial].

**Outputs:**
*   `texture_array` filled with final RGBA color values [S1, unofficial].

### Data Structures
*   `VoxelData`: Stored in leaf nodes. Layout: `morton` (`uint64_t`), `color` (`vec3`), `normal` (`vec3`) [S1, unofficial]. Total size: `sizeof(uint64_t) + 2 * (3 * sizeof(float))` bytes [S1, unofficial].
*   `TreeTraverser`: Stateful object managing the octree walk. Fields: `tree` (reference), `ray` (current ray), `stack` (list of nodes), `isTerminated()` (boolean), `step()` (advance), `getCurrentPosition()` (3D position), `getCurrentNode()` (pointer to `VoxelData`) [S1, unofficial].

### Algorithm Steps
1.  **Initialize Parallelism**: Set the number of OpenMP threads to match the number of available CPU cores [S1, unofficial].
2.  **Pixel Loop**: Iterate over all pixels $(x, y)$ in parallel [S1, unofficial].
3.  **Ray Generation**: For each pixel, generate the ray using `rc.getRayForPixel(x, y)` [S1, unofficial].
4.  **Traversal Initialization**: Create a `TreeTraverser` instance with the tree and the ray [S1, unofficial].
5.  **Traversal Loop**: While the traverser is not terminated:
    *   Check if `stack.size() >= maxlevel` [S1, unofficial].
    *   If true, break the loop [S1, unofficial].
    *   Otherwise, call `t.step()` to advance to the next node [S1, unofficial].
6.  **Lighting Calculation**: If the loop broke due to `maxlevel`, compute lighting for the current node [S1, unofficial].
    *   Initialize color accumulators $r, g, b = 0$ [S1, unofficial].
    *   For each active light $i$:
        *   Compute light vector: $\vec{l} = \text{light}_i.\text{position} - \text{current\_position}$ [S1, unofficial].
        *   Compute distance attenuation:
            $$ \text{distancecut} = \frac{1.0}{C + L \cdot \|\vec{l}\| + Q \cdot \|\vec{l}\|^2} $$
            Where $C, L, Q$ are `rc.lights[i].CONSTANT_ATTENUATION`, `LINEAR_ATTENUATION`, and `QUADRATIC_ATTENUATION` respectively [S1, unofficial].
        *   Normalize light vector: $\vec{l} = \frac{\vec{l}}{\|\vec{l}\|}$ [S1, unofficial].
        *   Compute diffuse factor:
            $$ \text{diffuse\_factor} = \text{normal} \cdot \vec{l} $$
            Where `normal` is `data[t.getCurrentNode()->data].normal` [S1, unofficial].
        *   Accumulate diffuse color:
            $$ r += \max(0.0, \text{diffuse\_factor}) \cdot \text{distancecut} \cdot \text{light}_i.\text{diffuse}[0] $$
            (Repeat for $g, b$ using respective light diffuse components) [S1, unofficial].
        *   Compute specular vector:
            $$ \vec{h} = \vec{l} + (\text{camera\_eye} - \text{current\_position}) $$
            $$ \vec{h} = \frac{\vec{h}}{\|\vec{h}\|} $$
            [S1, unofficial].
        *   Compute Phong specular factor:
            $$ \text{phong\_factor} = (\vec{h} \cdot \text{normal})^{\text{shininess}} $$
            Where `shininess` is `rc.lights[i].SHININESS` [S1, unofficial].
        *   Accumulate specular color:
            $$ r += \max(0.0, \text{phong\_factor}) \cdot \text{distancecut} \cdot \text{light}_i.\text{specular}[0] $$
            (Repeat for $g, b$ using respective light specular components) [S1, unofficial].
7.  **Output**:
    *   Write final color: `texture_array[index] = clamp(255 * r, 0, 255)` cast to `unsigned char` [S1, unofficial].
    *   Set alpha: `texture_array[index+3] = 1` [S1, unofficial].

### Pseudocode
```python
import math
import os

def clamp(val, min_val, max_val):
    return max(min_val, min(max_val, val))

def length(v):
    return math.sqrt(v[0]**2 + v[1]**2 + v[2]**2)

def normalize(v):
    l = length(v)
    return (v[0]/l, v[1]/l, v[2]/l)

def dot(a, b):
    return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

def fixed_level_octree_render(tree, rc, maxlevel, texture_array, W):
    # 1. Initialize parallelism (reference implementation uses OpenMP) [S1, unofficial]
    num_threads = os.cpu_count()
    set_num_threads(num_threads)  # Configures thread pool size [G]

    # 2. Parallelize pixel loop
    for y in range(rc.n_y):
        for x in range(W):
            # 3. Initialize ray traverser
            ray = rc.get_ray_for_pixel(x, y)
            t = TreeTraverser(tree, ray)
            
            r_acc = 0.0
            g_acc = 0.0
            b_acc = 0.0
            
            # 4. Traverse tree
            while not t.is_terminated():
                if len(t.stack) >= maxlevel:
                    break
                t.step()
            
            # 5. Lighting calculation
            current_pos = t.get_current_position()
            node_data = t.get_current_node().data
            normal = node_data.normal
            
            for light in rc.lights:
                to_light = (light.position[0] - current_pos[0],
                            light.position[1] - current_pos[1],
                            light.position[2] - current_pos[2])
                
                len_to_light = length(to_light)
                len2_to_light = len_to_light * len_to_light
                
                distancecut = 1.0 / (
                    light.CONSTANT_ATTENUATION + 
                    light.LINEAR_ATTENUATION * len_to_light + 
                    light.QUADRATIC_ATTENUATION * len2_to_light
                )
                
                to_light = normalize(to_light)
                
                diffuse_factor = dot(normal, to_light)
                
                diff_r = max(0.0, diffuse_factor) * distancecut * light.diffuse[0]
                diff_g = max(0.0, diffuse_factor) * distancecut * light.diffuse[1]
                diff_b = max(0.0, diffuse_factor) * distancecut * light.diffuse[2]
                
                r_acc += diff_r
                g_acc += diff_g
                b_acc += diff_b
                
                eye = rc.camera.e_
                s = (to_light[0] + (eye[0] - current_pos[0]),
                     to_light[1] + (eye[1] - current_pos[1]),
                     to_light[2] + (eye[2] - current_pos[2]))
                s = normalize(s)
                
                spec_factor = pow(max(0.0, dot(s, normal)), light.SHININESS)
                
                spec_r = spec_factor * distancecut * light.specular[0]
                spec_g = spec_factor * distancecut * light.specular[1]
                spec_b = spec_factor * distancecut * light.specular[2]
                
                r_acc += spec_r
                g_acc += spec_g
                b_acc += spec_b

            # 6. Write final color
            index = (y * W + x) * 4
            texture_array[index] = clamp(int(255 * r_acc), 0, 255)
            texture_array[index + 1] = clamp(int(255 * g_acc), 0, 255)
            texture_array[index + 2] = clamp(int(255 * b_acc), 0, 255)
            texture_array[index + 3] = 1

class TreeTraverser:
    def __init__(self, tree, ray):
        self.tree = tree
        self.ray = ray
        self.stack = []
        # Initialize stack with root node if it intersects ray [G]
        if self.tree.intersects(ray):
            self.stack.append(self.tree.root)
        
    def is_terminated(self):
        return len(self.stack) == 0
        
    def step(self):
        if not self.stack:
            return
        current = self.stack.pop()
        # Push children or next sibling based on traversal order [G]
        children = self.tree.get_children(current)
        for child in reversed(children):
            if child.intersects(self.ray):
                self.stack.append(child)
        if not self.stack:
            self.stack.append(self.tree.get_next_sibling(current))
        
    def get_current_position(self):
        return self.stack[-1].center if self.stack else (0.0, 0.0, 0.0)
        
    def get_current_node(self):
        return self.stack[-1] if self.stack else None
```

### Parameters
*   `maxlevel`: The fixed depth limit. Not given in the sources.
*   `rc.lights[i].CONSTANT_ATTENUATION`, `LINEAR_ATTENUATION`, `QUADRATIC_ATTENUATION`: Light attenuation constants. Not given in the sources.
*   `rc.lights[i].SHININESS`: Phong shininess exponent. Not given in the sources.

### Edge Cases and Pitfalls
*   **Precision**: The source uses `float` for lighting calculations and `unsigned char` for output, which may cause quantization artifacts [S1, unofficial].
*   **Boundaries**: The traversal terminates if `stack.size() >= maxlevel`; deeper octree details are ignored [S1, unofficial].
*   **Alpha**: Alpha is hardcoded to 1, ignoring the actual voxel opacity [S1, unofficial].

## Subtopics

### Recursive Octree Traversal
Traverses the entire octree depth recursively. Chosen when full detail is required. [Recursive Octree Traversal](4989-recursive-octree-traversal.md)

### Top Level Octree Rendering
Stops traversal at a depth determined by the pixel's y-coordinate. Chosen for view-dependent level of detail. [Top Level Octree Rendering](4990-top-level-octree-rendering.md)

## Operating characteristics
*   **Measured Performance**: Not given in the sources.
*   **Scaling**: Scales linearly with the number of CPU cores due to OpenMP parallelization [S1, unofficial].
*   **Strengths**: Simple implementation, no recursion overhead, predictable memory usage [S1, unofficial].
*   **Limitations**: No volumetric integration, fixed detail level regardless of distance, alpha is always 1 [S1, unofficial].
