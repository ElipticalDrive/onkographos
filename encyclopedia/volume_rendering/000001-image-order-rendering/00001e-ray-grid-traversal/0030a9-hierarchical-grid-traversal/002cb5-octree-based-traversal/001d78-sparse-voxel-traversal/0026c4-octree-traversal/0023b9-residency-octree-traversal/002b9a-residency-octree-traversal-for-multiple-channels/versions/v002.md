# Residency-octree traversal for multiple channels

Also called: Multi-Channel Residency Octree Traversal, Multi-channel octree traversal

## Overview
This method extends residency-based octree traversal to handle multiple volume channels simultaneously within a single ray [S1, unofficial]. It solves the problem of efficient empty-space and homogeneous-node skipping in multi-volume rendering by requiring that a node be empty or homogeneous for all active channels before it can be skipped [S1, unofficial]. Unlike single-channel traversal, which skips a node as soon as it is empty for that specific channel, this algorithm continues traversing deeper levels for non-empty channels until they also reach an empty or homogeneous state, ensuring no visible data is skipped [S1, unofficial].

## How it works
**Inputs:**
- `rootNode`: The root of the residency octree.
- `ray`: The current ray being evaluated.
- `numChannels`: The total number of volume channels to render.
- `node.culling_metadata_available[channelIndex]`: Boolean flag indicating if culling metadata (empty/homogeneous flags) is available for the current node and channel [S1, unofficial].
- `node.is_empty_flag[channelIndex]`: Boolean flag indicating if the node is empty for the given channel [S1, unofficial].
- `node.is_homogeneous_flag[channelIndex]`: Boolean flag indicating if the node is homogeneous for the given channel [S1, unofficial].
- `node.is_partially_mapped_flag[channelIndex]`: Boolean flag indicating if the node contains data that requires further subdivision or detailed rendering [S1, unofficial].
- `node.depth`: Integer, current depth of the node in the octree.
- `node.spatial_extent`: Object containing the node's bounding box boundaries.
- `node.get_child_along_ray(ray)`: Returns the child node intersected by the ray, or `None` if missing [S1, unofficial].

**Outputs:**
- Node requests for missing culling information or missing child nodes [S1, unofficial].
- Brick requests for rendering, including the chosen resolution level for each channel [S1, unofficial].

**Data Structures:**
- `traversalDepth`: Integer, the maximum depth to traverse [S1, unofficial].
- `node`: Reference to the current octree node [S1, unofficial].
- `channelIndex`: Integer, index of the current channel being processed (0 to `numChannels - 1`) [S1, unofficial].
- `emptyChannels`: Integer, counter of channels found to be empty for the current node [S1, unofficial].
- `homogeneousChannels`: Integer, counter of channels found to be homogeneous for the current node [S1, unofficial].

**Parameters:**
- `traversalDepth`: The maximum depth for traversal, determined by the ray step size. Not given in the sources.

**Algorithm Steps:**
1. Initialize `traversalDepth` based on the ray step size [S1, unofficial].
2. Set `node` to `rootNode`, `channelIndex` to 0, `emptyChannels` to 0, and `homogeneousChannels` to 0 [S1, unofficial].
3. Loop while `node.depth` is less than or equal to `traversalDepth` AND `channelIndex` is less than `numChannels` [S1, unofficial].
4. If no culling information is available for the current `node` and `channelIndex`, report a node request for that node and channel, increment `channelIndex`, and continue to the next iteration [S1, unofficial].
5. If the current `node` is empty for the current `channelIndex`:
   - Check if `emptyChannels` equals `numChannels - 1` [S1, unofficial].
   - If so, skip the node by updating the ray origin to the far boundary of the node's spatial extent, break the loop, and stop traversal for this ray [S1, unofficial].
   - If not all channels are empty, increment `emptyChannels`, increment `channelIndex`, and continue to the next channel [S1, unofficial].
6. If the node is homogeneous for the current channel (logic mirrors empty nodes):
   - Check if `homogeneousChannels` equals `numChannels - 1` [S1, unofficial].
   - If so, skip the node using the spatial extent of the last homogeneous node encountered, break the loop, and stop traversal [S1, unofficial].
   - If not all channels are homogeneous, increment `homogeneousChannels`, increment `channelIndex`, and continue [S1, unofficial].
7. If the node is not partially mapped for the current channel (i.e., it is fully mapped or requires rendering):
   - Choose the resolution level for the current depth and channel [S1, unofficial].
   - Report a brick request with the chosen resolution level [S1, unofficial].
   - Increment `channelIndex` and break the loop to proceed to rendering [S1, unofficial].
8. If `node.depth` is less than `traversalDepth`:
   - Determine the next node along the ray [S1, unofficial].
   - If the next node is missing, report a node request for it [S1, unofficial].
   - Otherwise, update the current `node` to the next node and continue the loop [S1, unofficial].
9. If the loop continues past the depth check (implying end of traversal or specific condition), choose the resolution level for the current channel, and increment `channelIndex` [S1, unofficial].

**Pseudocode:**
```python
def residency_octree_traversal_multi_channel(rootNode, ray, numChannels):
    # 1. Initialize traversal depth based on ray step size [S1, unofficial]
    # Not given in the sources.
    traversalDepth = chooseTraversalDepth(ray.step_size)

    # 2. Initialize state [S1, unofficial]
    node = rootNode
    channelIndex = 0
    emptyChannels = 0
    homogeneousChannels = 0

    # 3. Main traversal loop [S1, unofficial]
    while node.depth <= traversalDepth and channelIndex < numChannels:

        # 4. Check for culling information availability [S1, unofficial]
        if not node.culling_metadata_available[channelIndex]:
            reportNodeRequest(node, channelIndex)
            channelIndex += 1
            continue

        # 5. Handle empty nodes [S1, unofficial]
        if node.is_empty_flag[channelIndex]:
            if emptyChannels == numChannels - 1:
                # All channels are empty; skip this node
                # Skipped distance determined by spatial extent of last empty node encountered [S1, unofficial]
                ray.origin = node.spatial_extent.far_boundary
                break
            else:
                # Only some channels are empty; continue to next channel
                emptyChannels += 1
                channelIndex += 1
                continue

        # 6. Handle homogeneous nodes (mirrors empty node logic) [S1, unofficial]
        if node.is_homogeneous_flag[channelIndex]:
            if homogeneousChannels == numChannels - 1:
                # All channels are homogeneous; skip this node
                # Skipped distance determined by spatial extent of last homogeneous node encountered [S1, unofficial]
                ray.origin = node.spatial_extent.far_boundary
                break
            else:
                # Only some channels are homogeneous; continue to next channel
                homogeneousChannels += 1
                channelIndex += 1
                continue

        # 7. Handle partially mapped / renderable nodes [S1, unofficial]
        if not node.is_partially_mapped_flag[channelIndex]:
            # Node is fully mapped or requires rendering
            # Not given in the sources.
            resolutionLevel = chooseResolutionLevel(node.depth, channelIndex)
            reportBrickRequest(node, ray, resolutionLevel, channelIndex)
            channelIndex += 1
            break

        # 8. Move to next level if depth allows [S1, unofficial]
        if node.depth < traversalDepth:
            nextNode = node.get_child_along_ray(ray)
            if nextNode is None:
                reportNodeRequest(nextNode)
            else:
                node = nextNode
                continue
        else:
            # End of traversal depth reached
            # Not given in the sources.
            resolutionLevel = chooseResolutionLevel(node.depth, channelIndex)
            reportBrickRequest(node, ray, resolutionLevel, channelIndex)
            channelIndex += 1
```

**Edge Cases and Pitfalls:**
- **Empty Node Skipping:** Empty nodes can only be skipped if **ALL** channels are empty for that node. If a node is empty for one channel but not others, traversal must continue for the non-empty channels to find the subdivision level where they are empty [S1, unofficial].
- **Skipped Distance:** The skipped distance is determined by the spatial extent of the **last** empty (or homogeneous) node encountered during traversal. Since spatial extents of nodes strictly decrease between tree traversal steps, this strategy ensures that non-empty space is not skipped [S1, unofficial].
- **Homogeneous Nodes:** Homogeneous nodes are handled similarly to empty nodes. They are only skipped if all channels are homogeneous for that node. The values of the last homogeneous node encountered are used for rendering the node for each channel [S1, unofficial].

## Operating characteristics
- **Time Complexity:** In multi-volume settings, empty-space skipping may require more traversal steps than single-channel settings because multiple channels must be checked for each node [S1, unofficial].
- **Memory Complexity:** Not given in the sources.
- **Scaling:** Not given in the sources.
- **Strengths:** Efficiently skips empty and homogeneous regions across multiple volumes without rendering unnecessary data.
- **Limitations:** Increased traversal overhead compared to single-channel rendering due to the need to check all channels before skipping.
- **When to use:** Multi-volume rendering where channels share spatial structure and empty/homogeneous regions are common.
- **When not to use:** Single-channel rendering where simpler traversal suffices.

## Background
This method is described in the context of scalable web-based volume rendering of large biomedical datasets [S1, unofficial]. It is part of a mixed-resolution multi-volume rendering framework that uses residency-based octrees to manage memory and traversal efficiently [S1, unofficial].
