# LiNode Light Gathering with Octree Traversal

Also called: LiNode::gather

## Overview
LiNode Light Gathering is a ray-surfel intersection method that traverses an octree of surfels to determine the closest hit color and distance for a given ray [S1, unofficial]. It solves the problem of efficiently gathering lighting information from a sparse, hierarchical surfel representation [S1, unofficial]. It differs from its siblings by operating on surfel primitives within octree leaves rather than triangles (Octree Voxel-Triangle Intersection Test), using deterministic traversal rather than stochastic estimation (Woodcock Collision Estimation with Octree Acceleration), or performing point queries (Octree Point Search for Closest Point) [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: A ray defined by origin and direction, and a root `LiNode` (octree node) containing surfels [S1, unofficial].
- Output: The closest hit color and the distance to the hit point (`t`) [S1, unofficial].

**Data Structures:**
- `LiNode`: Inherits from `OctreeNode`. Contains `min` and `max` bounding box corners, `_surfelCount` (integer), and `_surfelData` (array of `shared_ptr<Surfel>`) [S1, unofficial].
- `Surfel`: Contains position, normal, and color data, accessible via methods like `normal()` and `position()` [S1, unofficial].
- `MAX_SURFEL_COUNT`: The maximum number of surfels a leaf node can hold before subdivision [S1, unofficial].

**Steps:**
1. Initialize `tmin` to infinity and `closest` to the background color configuration [S1, unofficial].
2. Test the ray intersection with the current octree node's bounding box using `OctreeNode::test_intersect` [S1, unofficial].
3. If no intersection is found, set `*t` to infinity and return the background color [S1, unofficial].
4. If the node has children:
   - Iterate through all 8 children [S1, unofficial].
   - Recursively call `gather` on each child [S1, unofficial].
   - Update `tmin` and `closest` if a child returns a hit with a smaller distance [S1, unofficial].
5. If the node is a leaf:
   - Check if the ray origin is inside the leaf's bounding box. If so, return the background color with `*t` set to infinity [S1, unofficial].
   - Iterate through all surfels in `_surfelData` (up to `_surfelCount`) [S1, unofficial].
   - For each surfel:
     - Transform the ray into the surfel's local space [S1, unofficial].
     - Normalize the ray direction [S1, unofficial].
     - Perform backface culling: if `s->normal() * (ray.direction * -1) > 0`, skip the surfel [S1, unofficial].
     - Test for intersection between the ray and the surfel [S1, unofficial].
     - If an intersection is found and the distance is less than `tmin`, update `tmin` and `closest` with the surfel's color [S1, unofficial].
6. Set `*t` to `tmin` and return `closest` [S1, unofficial].

**Pseudocode:**
```python
import math

INFINITY = float('inf')

class Color:
    def __init__(self, r, g, b, a=1.0):
        self.r, self.g, self.b, self.a = r, g, b, a

config = type('Config', (), {'background': Color(0.0, 0.0, 0.0, 0.0)})()

def transform_point(mat, p):
    return (mat[0]*p.x + mat[1]*p.y + mat[2]*p.z + mat[3],
            mat[4]*p.x + mat[5]*p.y + mat[6]*p.z + mat[7],
            mat[8]*p.x + mat[9]*p.y + mat[10]*p.z + mat[11])

def transform_vector(mat, v):
    return (mat[0]*v.x + mat[1]*v.y + mat[2]*v.z,
            mat[4]*v.x + mat[5]*v.y + mat[6]*v.z,
            mat[8]*v.x + mat[9]*v.y + mat[10]*v.z)

def normalize(v):
    length = math.sqrt(v.x**2 + v.y**2 + v.z**2)
    if length == 0: return (0.0, 0.0, 0.0)
    return (v.x/length, v.y/length, v.z/length)

def dot(a, b):
    return a.x*b.x + a.y*b.y + a.z*b.z

def intersect_ray_sphere(origin, direction, center, radius):
    oc = (origin.x - center.x, origin.y - center.y, origin.z - center.z)
    a = dot(direction, direction)
    b = 2.0 * dot(oc, direction)
    c = dot(oc, oc) - radius**2
    discriminant = b**2 - 4*a*c
    if discriminant < 0: return None
    t = (-b - math.sqrt(discriminant)) / (2*a)
    if t < 0: return None
    return t

def gather(ray, node):
    # Step 1: Initialize
    tmin = INFINITY
    closest = config.background
    
    # Step 2: Node intersection test
    if not node.test_intersect(ray):
        ray.t = INFINITY
        return config.background
    
    # Step 4: Internal node
    if node.has_children():
        for i in range(8):
            child_t, child_color = gather(ray, node.child(i)) # [S1, unofficial]
            if child_t < tmin:
                tmin = child_t
                closest = child_color
        ray.t = tmin
        return closest
    
    # Step 5: Leaf node
    # Check if ray start is inside bounding box
    if node.is_inside(ray.origin):
        ray.t = INFINITY
        return config.background
    
    # Iterate surfels
    for i in range(node._surfelCount):
        surfel = node._surfelData[i]
        
        # Transform ray to surfel local space
        local_origin = transform_point(surfel.transform_inverse(), ray.origin)
        local_direction = transform_vector(surfel.transform_inverse(), ray.direction)
        local_direction = normalize(local_direction)
        
        # Backface culling
        if dot(surfel.normal(), (-local_direction.x, -local_direction.y, -local_direction.z)) > 0:
            continue
            
        # Test intersection
        hit_t = intersect_ray_sphere(local_origin, local_direction, surfel.position(), surfel.radius()) # [S1, unofficial]
        
        if hit_t is not None and hit_t < tmin:
            tmin = hit_t
            closest = surfel.color()
    
    ray.t = tmin
    return closest
```

**Parameters and Edge Cases:**
- `MAX_SURFEL_COUNT`: When a leaf node exceeds this count, it subdivides into 8 children and re-adds the surfels. Not given in the sources.
- Precision: Ray transformation to local space requires careful handling of floating-point precision to avoid false negatives in intersection tests [G].
- Degenerate Input: Rays originating inside a leaf node are handled by returning the background color, preventing self-intersection artifacts [S1, unofficial].

## Subtopics

### Surfel-based Spherical Harmonic Lighting
This variant processes lighting information from surfels in a leaf node by projecting them onto Spherical Harmonics [S1, unofficial]. It is chosen when compact lighting representation is needed for global illumination or ambient occlusion [S1, unofficial]. It differs from standard LiNode gathering by aggregating lighting data rather than finding a single closest hit [S1, unofficial].
- **Steps**:
  1. For each leaf node in the LiNode hierarchy, if `_surfelCount` is zero, return immediately [S1, unofficial].
  2. Collect all surfels from `_surfelData` into a vector of shared pointers named `surf_list` [S1, unofficial].
  3. Project the lighting onto Spherical Harmonics by calling `SHProject(surf_list, 2, sh_c)` [S1, unofficial].
- **Parameters**: `SHProject` order is hardcoded to 2, resulting in 9 coefficients [S1, unofficial].
- **Layout**: `sh_c` is an array of 9 Spherical Harmonic coefficients (indices 0-8) [S1, unofficial].

## Operating characteristics
- **Time Complexity**: Not given in the sources.
- **Memory Complexity**: Not given in the sources.
- **Strengths**: Efficient culling of non-intersecting nodes and surfels. Simple implementation [S1, unofficial].
- **Limitations**: Performance degrades if the octree is unbalanced or if rays intersect many surfels. Backface culling is simple and may not handle complex geometry well [S1, unofficial].
- **When to use**: Real-time rendering with surfel-based representations [S1, unofficial].
- **When not to use**: Scenes with high-frequency lighting variations requiring higher-order SH or precise ray-triangle intersection [S1, unofficial].

## Background
LiNode Light Gathering is part of the Mr-Voxel project, an open-source voxel-based renderer [S1, unofficial]. It was developed by cgibson as part of the broader effort to create a flexible volume and surfel rendering engine [S1, unofficial]. The method leverages the hierarchical structure of the octree to accelerate ray-surfel intersection tests [S1, unofficial].
