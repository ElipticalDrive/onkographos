# Sparse Ray-Octree Intersection (DECIDE)

Also called: Octree Ray Tracing, Ray-Casting Octree Traversal, Recursive Ray-Octree Intersection, castRay

## Overview
Sparse Ray-Octree Intersection (DECIDE) is a GPU-based algorithm for finding the first intersection of a ray with a sparse voxel octree structure, returning the hit position, normal, and node index [S2, unofficial]. It solves the problem of efficiently traversing hierarchical occupancy grids by handling traversal, descent, and backtracking (popping) using a stack [S2, unofficial]. It sets itself apart from its siblings by using a deterministic, iterative traversal with explicit stack management for backtracking, rather than recursion or stochastic estimation [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Ray origin ($O$), ray direction ($D$), octree root node, maximum traversal depth ($L$), Level of Detail multiplier ($lod$), and scale parameters.
*   **Output:** Hit position ($P$), hit normal ($N$), hit distance ($t_{min}$), node index, and child index. Returns false if no intersection is found within the octree bounds.

**Data Structures:**
*   **Octree Node:** Contains position, size (scale), active flag, and child descriptor.
*   **Child Descriptor:** A bit-packed integer where bits indicate the presence of children (0x8000u for active leaf/voxel, 0x0080u for non-leaf children) and potentially a far pointer flag (0x10000u) [S2, unofficial].
*   **Stack:** Stores parent node indices and $t_{max}$ values for backtracking [S2, unofficial].

**Parameters:**
*   $lod$: Level of Detail multiplier used for termination criteria [S2, unofficial].
*   $scale\_exp2$: Current node size (power of 2).
*   $half\_scale\_exp2$: Half of the current node size.
*   $t\_coef$: Transformation coefficient for coordinate mapping [S2, unofficial].
*   $t\_bias$: Transformation bias for coordinate mapping [S2, unofficial].
*   $octant\_mask$: Permutation mask for child slot indices based on mirroring [S2, unofficial].
*   $s\_max$: Maximum scale (depth) of the octree [S2, unofficial].

**Algorithm Steps:**
1.  **Initialization:**
    *   Calculate corner position in t-space: $t_{corner} = pos \times t_{coef} - t_{bias}$ [S2, unofficial].
    *   Find maximum t-value at the corner: $t_{c\_max} = \min(\min(t_{corner}.x, t_{corner}.y), t_{corner}.z)$ [S2, unofficial].
    *   Initialize $t_{min} = -\infty$, $t_{max} = \infty$ [S3, unofficial].
    *   Initialize stack and scale variables [S2, unofficial].

2.  **Traversal Loop:**
    *   **Permute Child Indices:** Permute child slot indices based on mirroring: $child\_shift = idx \oplus octant\_mask$ [S2, unofficial]. Shift child descriptor: $child\_masks = child\_descriptor \ll child\_shift$ [S2, unofficial].
    *   **Ray-Box Intersection:** Calculate node bounding box ($boxMin, boxMax$) and check ray-box intersection. If no intersection, return false [S3, unofficial].
    *   **Validity Check:** Check if the voxel is valid and the t-span is non-empty: `if ((child_masks & 0x8000u) != 0u && t_min <= t_max)` [S2, unofficial].
    *   **Hit Detection:** If (depth >= currentDepth || node->isLeaf) && node->isActive, a hit is found [S3, unofficial].
    *   **Termination:** Terminate if the voxel is small enough: `if (ubo.lod * tc_max >= scale_exp2) { break; }` [S2, unofficial].
    *   **Descend:** Descend to the first child if the resulting t-span is non-empty (`t_min <= tv_max`) and the non-leaf mask bit is set (`(child_masks & 0x0080u) != 0u`) [S2, unofficial].
    *   **Stack Push:** Push current parent to stack if `tc_max < h`: `stack[scale] = uvec2(parent, floatBitsToUint(t_max));` Update `h = tc_max;` [S2, unofficial].
    *   **Child Selection:** Select child voxel entered first by checking $t_{center}$ against $t_{min}$ for each axis, updating $idx$ and $pos$ [S2, unofficial].
    *   **Update Span:** Update active t-span and invalidate cached child descriptor: $t_{max} = tv_{max}$; $child\_descriptor = 0u$; Decrement scale: $scale--$; Update $scale\_exp2$: $scale\_exp2 = half\_scale\_exp2$; Continue loop [S2, unofficial].
    *   **ADVANCE:** Step along the ray by checking $t_{corner}$ against $t_{c\_max}$. Update $pos$ and $step\_mask$: `if (t_corner.x <= tc_max) step_mask ^= 1, pos.x -= scale_exp2;` etc. [S2, unofficial].
    *   **Update Span (ADVANCE):** Update active t-span and flip bits of child slot index: $t_{min} = t_{c\_max}$; $idx \oplus= step\_mask$ [S2, unofficial].
    *   **POP:** If bit flips disagree with ray direction (`(idx & step_mask) != 0`), find highest differing bit between positions to determine new $scale$: $scale = (floatBitsToUint(float(differing\_bits)) >> 23) - 127u$ [S2, unofficial].
    *   **Restore Parent:** Restore parent voxel from stack: `uvec2 stackEntry = stack[scale]; parent = stackEntry.x; t_max = uintBitsToFloat(stackEntry.y);` [S2, unofficial].
    *   **Prevent Re-storage:** Prevent same parent from being stored again and invalidate cached child descriptor: $h = 0.0$; $child\_descriptor = 0u$ [S2, unofficial].
    *   **Miss Check:** Indicate miss if outside octree: `if (scale >= s_max) { return false; }` [S2, unofficial].
    *   **Undo Mirroring:** Undo mirroring of coordinate system: `if ((octant_mask & 1) == 0) pos.x = 3.0 - scale_exp2 - pos.x;` etc. [S2, unofficial].

3.  **Hit Calculation:**
    *   Calculate hit point: $hitPoint = origin + ray.direction \times t_{min}$ [S2, unofficial].
    *   Calculate vector from center to hit: $centerToHit = hitPoint - (pos + scale\_exp2 \times 0.5)$ [S2, unofficial].
    *   Determine voxel normal by prevailing axis direction: $maxDir = \max(|centerToHit.x|, \max(|centerToHit.y|, |centerToHit.z|))$; $axisDir = vec3(int(centerToHit.x / maxDir), int(centerToHit.y / maxDir), int(centerToHit.z / maxDir))$ [S2, unofficial].
    *   Return result: $castRes.normal = vec4(axisDir, 0.0)$; $castRes.node = parent$; $castRes.childIdx = idx \oplus octant\_mask \oplus 7$; $castRes.scale = scale$; $castRes.pos = pos$; $castRes.t = t_{min}$ [S2, unofficial].

**Pseudocode:**
```python
def castRay(origin, direction, octree_root, lod, scale_exp2, half_scale_exp2, t_coef, t_bias, octant_mask, s_max):
    # Initialization
    pos = origin # Assuming pos is initialized to origin or transformed position
    idx = 0 # Initial child index
    scale = initial_scale # Initial scale based on octree depth
    t_min = -infinity
    t_max = infinity
    stack = [] # Stack for backtracking
    h = 0.0 # Helper variable for stack management
    
    # Calculate corner position in t-space
    t_corner = pos * t_coef - t_bias
    tc_max = min(min(t_corner.x, t_corner.y), t_corner.z)
    
    while True:
        # Permute child slot indices based on mirroring
        child_shift = idx ^ octant_mask
        child_masks = child_descriptor << child_shift
        
        # Check ray-box intersection
        if not ray_box_intersect(origin, direction, node_box):
            return False
        
        # Check if voxel is valid and t-span is non-empty
        if (child_masks & 0x8000u) != 0u and t_min <= t_max:
            # Hit found
            hit_position = origin + direction * t_min
            center_to_hit = hit_position - (pos + scale_exp2 * 0.5)
            max_dir = max(abs(center_to_hit.x), max(abs(center_to_hit.y), abs(center_to_hit.z)))
            axis_dir = vec3(int(center_to_hit.x / max_dir), int(center_to_hit.y / max_dir), int(center_to_hit.z / max_dir))
            
            return {
                'normal': vec4(axis_dir, 0.0),
                'node': parent,
                'childIdx': idx ^ octant_mask ^ 7,
                'scale': scale,
                'pos': pos,
                't': t_min
            }
        
        # Termination criteria
        if lod * tc_max >= scale_exp2:
            break
        
        # Descend to first child
        tv_max = min(t_max, tc_max)
        if t_min <= tv_max and (child_masks & 0x0080u) != 0u:
            # Push to stack if needed
            if tc_max < h:
                stack.append((parent, floatBitsToUint(t_max)))
                h = tc_max
            
            # Select child voxel entered first
            t_center = half_scale_exp2 * t_coef + t_corner
            if t_center.x > t_min:
                idx ^= 1
                pos.x += scale_exp2
            # ... similar for y and z
            
            # Update active t-span
            t_max = tv_max
            child_descriptor = 0u
            scale -= 1
            scale_exp2 = half_scale_exp2
            half_scale_exp2 /= 2
            continue
        
        # ADVANCE step
        if t_corner.x <= tc_max:
            step_mask ^= 1
            pos.x -= scale_exp2
        # ... similar for y and z
        
        t_min = tc_max
        idx ^= step_mask
        
        # POP step
        if (idx & step_mask) != 0:
            # Find highest differing bit
            differing_bits = pos ^ new_pos # Placeholder for actual bit calculation
            scale = (floatBitsToUint(float(differing_bits)) >> 23) - 127u
            
            # Restore parent
            parent, t_max = stack.pop()
            t_max = uintBitsToFloat(t_max)
            
            h = 0.0
            child_descriptor = 0u
        
        # Miss check
        if scale >= s_max:
            return False
            
        # Undo mirroring
        if (octant_mask & 1) == 0:
            pos.x = 3.0 - scale_exp2 - pos.x
        # ... similar for y and z

    return False # No hit found
```

## Subtopics

### [Octree Voxel-Triangle Intersection Test](3316-octree-voxel-triangle-intersection-test.md)
A method to determine if a triangle intersects a voxel within a virtual uniform grid defined by an octree, used for culling or traversal in volume rendering. It implements the Separating Axis Theorem (SAT) to test intersection between a triangle and an axis-aligned bounding box (cube). It serves as the geometric predicate in [Sparse Ray-Octree Intersection (DECIDE)](3006-sparse-ray-octree-intersection-decide.md), replacing generic ray-box tests with a direct voxel-triangle check to handle high-frequency geometry or thin primitives that might be missed by coarse ray stepping.

### [Woodcock Collision Estimation with Octree Acceleration](3419-woodcock-collision-estimation-with-octree-acceleration.md)
An optimized ray marching method that combines Woodcock collision estimation with an octree traversal to skip empty regions and nodes that do not intersect the ray's current segment, reducing the number of volume samples. It sets itself apart from standard ray marching by using the octree structure to cull non-intersecting nodes and from the parent [Sparse Ray-Octree Intersection (DECIDE)](3006-sparse-ray-octree-intersection-decide.md) by specifically employing stochastic collision estimation within leaf nodes rather than deterministic traversal or triangle intersection.

### [LiNode Light Gathering with Octree Traversal](3957-linode-light-gathering-with-octree-traversal.md)
LiNode Light Gathering is a ray-surfel intersection method that traverses an octree of surfels to determine the closest hit color and distance for a given ray. It solves the problem of efficiently gathering lighting information from a sparse, hierarchical surfel representation. It differs from its siblings by operating on surfel primitives within octree leaves rather than triangles (Octree Voxel-Triangle Intersection Test), using deterministic traversal rather than stochastic estimation (Woodcock Collision Estimation with Octree Acceleration), or performing point queries (Octree Point Search for Closest Point).

### [Octree Point Search for Closest Point](4999-octree-point-search-for-closest-point.md)
This method efficiently identifies the closest point to a ray origin among all points intersected by a set of rays, filtering by a maximum range. It differs from sibling methods like [Sparse Ray-Octree Intersection (DECIDE)](3006-sparse-ray-octree-intersection-decide.md) by operating on discrete point clouds indexed by an octree rather than continuous occupancy grids, and from [Octree Voxel-Triangle Intersection Test](3316-octree-voxel-triangle-intersection-test.md) by returning point indices rather than geometric intersection primitives. It is primarily used in Next-Best-View (NBV) planning to simulate sensor observations of a point cloud environment.

## Operating characteristics
*   **Time Complexity:** $O(\log N)$ for traversal to the first hit, where $N$ is the number of voxels, assuming a balanced octree. The stack operations are $O(1)$ per node visited.
*   **Memory Complexity:** $O(D)$ for the stack, where $D$ is the depth of the octree.
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Scales well with sparse data as empty regions are skipped. Performance degrades with highly dense or complex geometry within leaf nodes.
*   **Strengths:** Efficient for sparse data, handles backtracking explicitly, GPU-friendly.
*   **Limitations:** Requires explicit stack management, may be less efficient for very dense data compared to uniform grid traversal.
*   **When to use:** Sparse voxel octrees, real-time rendering with implicit 3D shapes.
*   **When not to use:** Dense uniform grids, scenes with no empty space.

## Background
The DECIDE algorithm is a GPU-based algorithm for ray-octree intersection [S2, unofficial]. It is used in the context of Neural Geometric Level of Detail (NGLOD) for real-time rendering with implicit 3D shapes [S1]. The algorithm handles traversal, descent, and backtracking using a stack [S2, unofficial]. It is implemented in the `krre/origin` repository [S2, unofficial].
