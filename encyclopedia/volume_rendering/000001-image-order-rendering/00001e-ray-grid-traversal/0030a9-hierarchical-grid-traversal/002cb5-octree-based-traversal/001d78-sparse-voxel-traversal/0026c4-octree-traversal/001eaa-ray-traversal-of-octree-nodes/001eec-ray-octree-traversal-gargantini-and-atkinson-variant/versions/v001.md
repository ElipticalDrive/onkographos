# Ray-Octree Traversal (Gargantini and Atkinson variant)

Also called: Atkinson traversal, Gargantini and Atkinson Octree Ray Traversal, Gargantini and Atkinson Octree Traversal, Gargantini and Atkinson Ray-Octree Traversal, Gargantini and Atkinson variant, Gargantini traversal

## Overview
A single-ray octree traversal algorithm that determines the exact order of child octant intersection by sorting the ray's crossings with the X, Y, and Z mid-planes of the current node [S1, S3][S5, unofficial]. It builds on [Ray Traversal of Octree Nodes](1841-ray-traversal-of-octree-nodes.md) by fully sorting these mid-plane intersections to march through children sequentially, exploiting binary arithmetic on integer coordinates for efficient child index updates [S1, S3][S5, unofficial]. Unlike coherent techniques (SIMD, packets, frustum-based traversal), it avoids unnecessary work in highly variant scenes where a pixel covers multiple voxels [S2, S3].

## How it works
**Inputs:**
- `ray`: Ray structure with origin `orig` (Vec3f) and direction `dir` (Vec3f).
- `depth`: Current octree depth (integer).
- `node_index`: Index of the current node in the `nodes` array (uint).
- `parent_trace`: Array storing the traversal path (int[]).
- `cell`: Current node's base coordinate in octree space (Vec3i).
- `tenter`: Ray entry parameter for the current node (float).
- `texit`: Ray exit parameter for the current node (float).
- `isovalue`: Target isovalue for scalar comparison (float).

**Outputs:**
- Returns `true` if an isosurface intersection is found within the current node's volume; `false` otherwise.

**Data Structures:**
- `nodes[depth][node_index]`: Accesses the current `OctNode`.
- `child_bit_depth[depth]`: Precomputed bitmask for the current depth (e.g., $2^{d_{max}-depth}$).
- `axis_table`: Constant array `{4, 2, 1}` mapping sorted axis indices to bit positions [S4, unofficial].

**Steps:**
1.  **Ray-Bounding Box Test:** Generate rays in canonical octree space $[0, 2^{d_{max}}]$ [S1, S3][S5, unofficial]. Perform a standard ray-bounding box test on the root to discard non-intersecting rays, yielding `tenter` and `texit` [S1, S3][S5, unofficial].
2.  **Retrieve Node:** Access `node = nodes[depth][node_index]` and store `node_index` in `parent_trace[depth]` [S1][S4, unofficial].
3.  **Compute Mid-Planes:**
    -   Calculate `child_bit = child_bit_depth[depth]` [S4, unofficial].
    -   Compute the center of the current cell: `center = Vec3f(cell | Vec3i(child_bit))` [S4, unofficial].
    -   Compute intersection distances to the mid-planes: `tcenter = (center - ray.orig) / ray.dir` [S4, unofficial].
    -   Compute the entry point: `penter = ray.orig + ray.dir * tenter` [S4, unofficial].
4.  **Determine First Child:**
    -   Compare `penter` coordinates to `center` to determine the entry octant bits:
        $$tc.x = (penter.x \ge center.x)$$
        $$tc.y = (penter.y \ge center.y)$$
        $$tc.z = (penter.z \ge center.z)$$
    -   Compute the first child index: `child = (tc.x << 2) | (tc.y << 1) | tc.z` [S4, unofficial].
    -   Update `child_cell`: `child_cell = cell | Vec3i((tc.x ? child_bit : 0), (tc.y ? child_bit : 0), (tc.z ? child_bit : 0))` [S4, unofficial].
5.  **Sort Mid-Plane Intersections:**
    -   Create `axis_isects` array containing the sorted indices of `tcenter` such that `tcenter[axis_isects[0]] < tcenter[axis_isects[1]] < tcenter[axis_isects[2]]` [S1][S4, unofficial]. This represents the order of crossing the X, Y, and Z mid-planes [S3][S5, unofficial].
6.  **Traverse Children:**
    -   Initialize `child_tenter = tenter` [S4, unofficial].
    -   Iterate through the sorted `axis_isects` array while `tcenter < texit` [S4, unofficial]:
        a.  **Calculate Exit:** `child_texit = min(tcenter[axis_isects[i]], texit)` [S4, unofficial].
        b.  **Scalar Check:** If `isovalue >= node.child_mins[child]` OR `isovalue <= node.child_maxs[child]`:
            i.  If `node.child_offset == -1`: Traverse scalar leaf (see Subtopics) [S4, unofficial].
            ii. Else if `depth == max_depth - 2`: Traverse cap node (see Subtopics) [S4, unofficial].
            iii. Else: Recursively call `traverse(ray, depth+1, parent_trace, child_cell, child_tenter, child_texit)` [S4, unofficial].
        c.  **Exit Check:** If `child_texit == texit`, return `false` (ray has exited the volume) [S4, unofficial].
        d.  **Update Entry:** `child_tenter = child_texit` [S4, unofficial].
        e.  **Move to Next Child:**
            i.  Get `axisbit = axis_table[axis_isects[i]]` [S4, unofficial].
            ii. If `child & axisbit` is true:
                -   `child &= ~axisbit`
                -   `child_cell[axis_isects[i]] &= ~child_bit`
            iii. Else:
                -   `child |= axisbit`
                -   `child_cell[axis_isects[i]] |= child_bit`
    -   Return `false` if the loop completes without finding an intersection [S4, unofficial].

**Pseudocode:**
```python
def traverse(ray, depth, node_index, parent_trace, cell, tenter, texit, isovalue):
    node = nodes[depth][node_index]
    parent_trace[depth] = node_index
    child_bit = child_bit_depth[depth]
    
    # Compute center and mid-plane intersections
    center = cell | Vec3i(child_bit)
    tcenter = (center - ray.orig) / ray.dir
    penter = ray.orig + ray.dir * tenter
    
    # Determine first child octant
    tc = Vec3i(
        1 if penter.x >= center.x else 0,
        1 if penter.y >= center.y else 0,
        1 if penter.z >= center.z else 0
    )
    child = (tc.x << 2) | (tc.y << 1) | tc.z
    child_cell = cell | Vec3i(
        child_bit if tc.x else 0,
        child_bit if tc.y else 0,
        child_bit if tc.z else 0
    )
    
    # Sort mid-plane intersections
    # axis_isects contains indices 0, 1, 2 sorted by tcenter value
    axis_isects = sort_indices_by_value(tcenter) 
    
    axis_table = [4, 2, 1]
    child_tenter = tenter
    
    for i in range(3):
        axis_idx = axis_isects[i]
        if tcenter[axis_idx] >= texit:
            break
            
        child_texit = min(tcenter[axis_idx], texit)
        
        # Check if isovalue is within child's range
        if isovalue >= node.child_mins[child] or isovalue <= node.child_maxs[child]:
            if node.child_offset == -1:
                if traverse_scalar_leaf(ray, child_cell, child_tenter, child_texit, isovalue):
                    return True
            elif depth == max_depth - 2:
                if traverse_cap(ray, child_cell, child_tenter, child_texit, isovalue):
                    return True
            else:
                if traverse(ray, depth + 1, node.child_start + node.child_offset[child], parent_trace, child_cell, child_tenter, child_texit, isovalue):
                    return True
                    
        if child_texit == texit:
            return False
            
        child_tenter = child_texit
        
        # Move to next child by flipping the bit corresponding to the traversed axis
        axisbit = axis_table[axis_idx]
        if child & axisbit:
            child &= ~axisbit
            child_cell[axis_idx] &= ~child_bit
        else:
            child |= axisbit
            child_cell[axis_idx] |= child_bit
            
    return False
```

## Subtopics

### Cap Node Traversal
A specialized traversal routine for cap nodes, which are leaf-like structures containing scalar values, differing from interior nodes in how child values are retrieved [S3]. Cap intersection is identical to interior nodes, except the isovalue check and recursive call are replaced by determining the values of the eight voxels composing the cell [S3]. To optimize neighbor retrieval, given a child octant `child` (0-7) and a neighbor direction `dir` (0-7), check if `(child & dir)` is false; if so, the neighbor value is `cap.scalars[dir]` [S3]. If true, proceed with standard neighbor-finding [S3].

### Scalar Leaf Traversal
A scalar leaf is traversed recursively to the same depth as caps, despite having no children and a homogeneous value [S5, unofficial]. When traversal reaches cap depth, if the neighborhood of identical voxels within the scalar leaf is encountered, no isosurface is present [S5, unofficial]. At the borders of the scalar leaf node, neighbor-finding is performed as for cap nodes to obtain eight voxel values [S5, unofficial]. If the isovalue lies within the minimum and maximum of these eight values, an isosurface intersection is computed using trilinear interpolation [S5, unofficial].

## Operating characteristics
- **Time Complexity:** Moderate initial cost for computing and sorting mid-plane intersections; subsequent child traversal is trivial via bitmask inversion [S1, S3][S5, unofficial].
- **Memory Complexity:** Requires storage for `nodes`, `child_bit_depth`, and `parent_trace` [S4, unofficial].
- **Performance:** Avoids SIMD/packet/frustum techniques because highly variant scenes and pixels covering multiple voxels cause unnecessary work and performance decreases compared to single-ray techniques [S2, S3]. Wald et al. reported little performance gain from coherent techniques on large data [S2, S3].
- **Strengths:** Efficient single-ray traversal using binary arithmetic; no additional transform required for canonical space [S1, S3][S5, unofficial].
- **Limitations:** Scalar leaves and cap nodes require special handling routines [S1].

## Background
Originated from the technique of Gargantini and Atkinson [5, 6], adapted for octree structures and hashing schemes by Wald et al. in "Interactive Isosurface Ray Tracing of Large Octree Volumes" (2006) [S1, S2, S3][S5, unofficial]. It was chosen over Sung [19, 22, 23] and Samet [17, 19, 20] methods as the fastest traversal for their implementation [S1, S2, S3][S5, unofficial]. Used for interactive isosurface ray tracing of large octree volumes, such as LLNL Richtmyer-Meshkov instability and Utah CSAFE heptane fire simulations [S3].
