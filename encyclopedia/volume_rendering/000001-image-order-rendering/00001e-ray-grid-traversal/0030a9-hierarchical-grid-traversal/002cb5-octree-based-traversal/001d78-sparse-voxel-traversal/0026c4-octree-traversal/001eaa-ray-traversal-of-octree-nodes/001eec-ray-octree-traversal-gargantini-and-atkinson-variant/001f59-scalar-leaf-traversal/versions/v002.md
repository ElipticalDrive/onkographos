# Scalar Leaf Traversal


## Overview
Scalar Leaf Traversal is a node-handling strategy for ray traversal in sparse voxel octrees where leaf nodes store a single homogeneous scalar value rather than a full voxel grid [S1, S2, unofficial]. It differs from standard leaf traversal by recursively traversing to the cap depth, performing boundary neighbor-finding to gather eight corner voxel values, and only computing a trilinear isosurface intersection when the isovalue lies within their minimum and maximum range [S1, S2, unofficial].

## How it works
**Inputs:**
- Ray origin $O$ and direction $D$ (3D tuples/lists).
- Scalar leaf node $L$ with homogeneous value $v_L$, spatial bounding box, and depth.
- Isosurface threshold $v$.
- Cap depth $d_{cap}$.
- Current traversal depth $d_{curr}$.
- Neighbor context containing `child` bit-mask, `cap_scalars` array (8 values), and a recursive neighbor-finding routine [S1, S2, unofficial].

**Outputs:**
- Intersection distance $t_{hit}$ if the isosurface intersects the cell defined by the eight corner voxels.
- `None` if no intersection is found.

**Data Structures:**
- Scalar leaf node: stores a single scalar `value`, spatial `bbox`, and `depth`.
- Neighbor context: provides access to `cap_scalars` (array of 8 neighbor values) and a `child` bit-mask indicating which octree child the ray currently occupies [S1, S2, unofficial].

**Steps:**
1. **Traverse to Cap Depth:** Recursively traverse the octree until $d_{curr} = d_{cap}$ [S1, S2, unofficial]. A scalar leaf is traversed to this depth even though it has no children and a homogeneous value [S1, S2, unofficial].
2. **Uniformity Check:** If the traversal encounters a neighborhood of identical voxels within the scalar leaf, no isosurface is encountered [S1, S2, unofficial]. Since the leaf is homogeneous, the interior contains no surface; an intersection can only occur at the boundary if adjacent nodes differ in value [S1, S2, unofficial].
3. **Neighbor Finding:** At the borders of the scalar leaf node, perform neighbor-finding to retrieve the values of the eight corner voxels of the cell [S1, S2, unofficial]. For a desired neighbor direction `dir` (0–7), check if `(child & dir)` is false. If false, the neighbor value is directly retrieved from `cap_scalars[dir]` [S1, S2, unofficial]. If true, proceed with standard recursive neighbor-finding to retrieve the value [S1, S2, unofficial].
4. **Containment Test:** Once eight voxel values $v_{ijk}$ are obtained, check that the isovalue $v$ lies within their minimum and maximum [S1, S2, unofficial]. If $v < \min(v_{ijk})$ or $v > \max(v_{ijk})$, return `None` [S1, S2, unofficial].
5. **Isosurface Intersection:** If the containment test passes, perform the isosurface intersection with the eight voxels as corners of the cell [S1, S2, unofficial]. Solve the trilinear interpolant equation for the ray parameter $t$ [S1, S2, unofficial]. The hit position is given by evaluating the ray at the first positive root of the resulting cubic polynomial [S1, unofficial].

**Formulas:**
The implicit surface is defined by the trilinear Lagrangian interpolant [S2, unofficial]:
$$f(x, y, z) = \left( \sum_{i, j, k \in \{0,1\}} x_i y_j z_k v_{ijk} \right) - v = 0$$
where $(i, j, k)$ is the minimum coordinate of the cell, $v$ is the isovalue, $v_{ijk}$ is the value at the cell vertex, and $x_0 = 1-x, x_1 = x$ (similarly for $y, z$) [S2, unofficial]. Substituting the ray equation $r(t) = O + tD$ yields a cubic polynomial $a t^3 + b t^2 + c t + d = 0$. The intersection distance is the smallest positive real root $t > 0$ [S1, unofficial].

    Traverses a scalar leaf node to find isosurface intersection.
    ray_O, ray_D: 3-tuples/lists for origin and direction.
    node: ScalarLeafNode with .value, .bbox, .depth.
    isovalue: float threshold.

    current_depth: int current octree depth.

    """

                # Determine corner coordinate in local cell space [0,1]
                # Map to world space using node.bbox
                cx = node.bbox.min_x + i * node.bbox.width
                cy = node.bbox.min_y + j * node.bbox.height
                cz = node.bbox.min_z + k * node.bbox.depth

                # For a homogeneous leaf, interior corners use the leaf value
                if node.bbox.min_x < cx < node.bbox.max_x and \
                   node.bbox.min_y < cy < node.bbox.max_y and \
                   node.bbox.min_z < cz < node.bbox.max_z:
                    val = node.value
                else:
                    # Boundary corner: perform neighbor-finding
                    # Determine direction index (0-7) based on corner position relative to center
                    dir_idx = (i << 2) | (j << 1) | k
                    val = _get_neighbor_value(dir_idx, neighbor_ctx)
                corner_values.append(val)
    
    # Step 4: Isosurface Containment Test
    v_min = min(corner_values)
    v_max = max(corner_values)
    
    if isovalue < v_min or isovalue > v_max:
        return None  # No intersection [S1, S2, unofficial]
    
    # Step 5: Isosurface Intersection
    # Compute cubic coefficients for trilinear interpolation along ray
    coeffs = _compute_trilinear_cubic_coeffs(ray_O, ray_D, corner_values)
    roots = _solve_cubic(coeffs)
    
    # Find first positive root [S1, unofficial]
    t_hit = None
    for t in roots:
        if t > 0:
            t_hit = t
            break
            
    return t_hit

def _solve_cubic(coeffs):
    """Solves a t^3 + b t^2 + c t + d = 0 using Cardano's method [G]."""
    a, b, c, d = coeffs
    if a == 0:
        # Degenerate to quadratic
        if b == 0:
            if c == 0:
                return [] if d == 0 else []
            return [-d / c]
        disc = c*c - 4*b*d
        if disc < 0: return []
        sq = disc**0.5
        return [(-c + sq)/(2*b), (-c - sq)/(2*b)]

    b /= a; c /= a; d /= a

        u = (-q/2 + disc**0.5)**(1/3)
        v = (-q/2 - disc**0.5)**(1/3)
        roots.append(u + v - b/3)
    elif disc == 0:
        u = (-q/2)**(1/3)
        roots.append(2*u - b/3)
        roots.append(-u - b/3)
    else:

        theta = (q/(2*r*r*r))
        if theta > 1: theta = 1
        if theta < -1: theta = -1
        theta = math.acos(theta)
        roots.append(2*r*math.cos(theta/3) - b/3)
        roots.append(2*r*math.cos((theta + 2*math.pi)/3) - b/3)
        roots.append(2*r*math.cos((theta + 4*math.pi)/3) - b/3)
    return roots

## Operating characteristics
- **Time Complexity:** $O(1)$ per scalar leaf node for neighbor lookups and cubic solve [S1, S2, unofficial].
- **Memory Complexity:** $O(1)$ additional memory per node, as no voxel grid is stored [S1, S2, unofficial].
- **Strengths:** Significantly reduces memory usage for large uniform regions by storing a single value instead of a full voxel grid [S1, S2, unofficial]. Efficiently skips large volumes of uniform data [S1, S2, unofficial].
- **Limitations:** Requires careful neighbor-finding at boundaries to ensure correct surface reconstruction [S1, S2, unofficial]. The cubic polynomial solution can be numerically unstable if not implemented carefully [S1, S2, unofficial].
- **When to Use:** Ideal for volumes with large homogeneous regions, such as medical imaging with large uniform background or synthetic volumes with large empty spaces [S1, S2, unofficial].

## Background
Scalar leaf traversal is part of the broader field of interactive isosurface ray tracing of large octree volumes [S1, S2, unofficial]. It was introduced in the context of optimizing ray traversal for sparse voxel octrees where leaf nodes can be either cap nodes (storing a grid of voxels) or scalar leaves (storing a single homogeneous value) [S1, S2, unofficial]. The method is described in the thesis "Ray Tracing Implicit Surfaces for Interactive Visualization" by Knoll [S2, unofficial] and the paper "Interactive Isosurface Ray Tracing of Large Octree Volumes" [S1, unofficial]. The approach builds on the Gargantini and Atkinson variant of ray-octree traversal, adapting it to handle the unique properties of scalar leaves [S1, S2, unofficial].
