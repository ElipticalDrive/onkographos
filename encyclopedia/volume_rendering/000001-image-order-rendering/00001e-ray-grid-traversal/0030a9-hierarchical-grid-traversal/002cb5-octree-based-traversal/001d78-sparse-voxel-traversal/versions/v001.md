# Sparse Voxel Traversal

Also called: OpenVDB Ray Intersector, Sparse Voxel Traversal and Sampling, Structure sampling, VolumeRayIntersector, Voxel Tree Raycasting, getVoxel

## Overview
Sparse Voxel Traversal is a hierarchical ray-intersection algorithm that accelerates volume rendering by navigating a spatial hierarchy (such as a Sparse Voxel Octree) to skip empty space and reduce the number of ray-casting steps [S1][S3, S5, unofficial]. It solves the performance bottleneck of non-hierarchical voxel traversal, where every voxel along a ray must be visited, by allowing the ray to "leap" over large empty regions [S1]. Unlike its siblings, it operates on a recursive tree structure where higher-level cells cover a $2 \times 2$ area of the level below, enabling larger steps through empty space [S1]. It distinguishes itself from standard grid traversal by using interval arithmetic with correct rounding modes to guarantee that no octant is missed during traversal, solving precision errors that occur when subdivision levels approach floating-point limits [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A hierarchical voxel tree (e.g., VoxelTree, OpenVDB Grid) containing nodes of types `Empty`, `Leaf`, or `Branch` [S3, unofficial]. A ray defined by origin $\mathbf{o}$ and direction $\mathbf{d}$ [S3, unofficial].
*   **Output:** Intersection times (TOI) or a callback result from leaf nodes [S3, unofficial].

**Data Structures:**
*   **VoxelBounds:** Struct with fields `x: i32`, `y: i32`, `z: i32` (coordinates as multiples of $2^{\text{lg\_size}}$) and `lg_size: i16` (log_2 of voxel size) [S3, unofficial]. The size in world units is $2^{\text{lg\_size}}$ if $\text{lg\_size} \ge 0$, else $1.0 / 2^{-\text{lg\_size}}$ [S3, unofficial].
*   **TOI:** A wrapper around `f32` implementing `Ord` for sorting intersection times [S3, unofficial].
*   **Entry/Exit:** Structures tracking the side index (0-5) and TOI of ray entry/exit [S3, unofficial].

**Algorithm Steps:**

1.  **Initialization:** Construct the intersector with the grid and optional dilation count [S2]. Set the ray using `setIndexRay` (index space) or `setWorldRay` (world space) [S2]. If the ray misses the grid's bounding box, return false [S2].
2.  **Traversal Loop:** Recursively traverse the tree starting from the root [S3, unofficial].
    *   **Empty Node:** If the current node is `Empty`, do nothing and fall through to calculate the exit [S3, unofficial].
    *   **Leaf Node:** If the current node is `Leaf`, call the action callback `act(bounds, leaf)` [S3, unofficial]. If it returns `Some(r)`, return `Ok(r)` [S3, unofficial]. Otherwise, fall through to calculate the exit [S3, unofficial].
    *   **Branch Node:** If the current node is `Branch`:
        1.  Compute the midpoint of the current bounds: $\mathbf{mid} = [(\text{bounds}.x + 0.5) \cdot \text{size}, (\text{bounds}.y + 0.5) \cdot \text{size}, (\text{bounds}.z + 0.5) \cdot \text{size}]$ [S3, unofficial].
        2.  Calculate the intersection point $\mathbf{intersect}$ at the current entry time: $\mathbf{intersect} = \mathbf{o} + \text{entry\_toi} \cdot \mathbf{d}$, where $\text{entry\_toi}$ is the TOI of the entry (0.0 if none) [S3, unofficial].
        3.  Determine child coordinates: $\text{coords}[i] = 1$ if $\text{intersect}[i] \ge \text{mid}[i]$, else $0$ [S3, unofficial].
        4.  Update bounds for the child: shift coordinates, decrement `lg_size`, and add child coordinates [S3, unofficial].
        5.  Recursively call `cast_ray_branches` with the child branch, origin, direction, entry, new coords, and updated bounds [S3, unofficial].
3.  **Exit Calculation:** If no return value is found in the node (Empty or Leaf without hit):
    1.  Define sides array: $[\text{bounds}.x, \text{bounds}.y, \text{bounds}.z, \text{bounds}.x + 1, \text{bounds}.y + 1, \text{bounds}.z + 1]$ [S3, unofficial].
    2.  For each side, compute the time of intersection (TOI):
        *   Get dimension $\text{dim} = \text{side} \% 3$ and bound value $b = \text{bound} \cdot \text{bounds.size()}$ [S3, unofficial].
        *   If $\mathbf{d}[\text{dim}] == 0.0$, return `None` [S3, unofficial].
        *   Compute $\text{toi} = (b - \mathbf{o}[\text{dim}]) / \mathbf{d}[\text{dim}]$ [S3, unofficial].
        *   Accept if: if entry is `None`, $\text{toi} \ge 0.0$; if entry is `Some`, $\text{entry.toi} \le \text{toi}$ [S3, unofficial].
    3.  Find the minimum valid TOI among the sides. If entry exists, exclude the entry side [S3, unofficial].
    4.  Return `Err(exit)` with the minimum TOI [S3, unofficial].
4.  **Coordinate Update (for Branches):** If `cast_ray` returns `Err(exit)`:
    1.  Calculate dimension $\text{dim} = \text{exit.side} \% 3$ [S3, unofficial].
    2.  If $\mathbf{d}[\text{dim}] < 0.0$:
        *   If $\text{coords}[\text{dim}] == 0$, return the exit error (ray exited tree boundary) [S3, unofficial].
        *   Otherwise, set $\text{coords}[\text{dim}] = 0$ [S3, unofficial].
    3.  If $\mathbf{d}[\text{dim}] \ge 0.0$:
        *   If $\text{coords}[\text{dim}] == 1$, return the exit error [S3, unofficial].
        *   Otherwise, set $\text{coords}[\text{dim}] = 1$ [S3, unofficial].
    4.  Update entry: $\text{entry} = \text{Entry::from\_exit}(\text{exit})$, which maps the exit side to the opposite face [S3, unofficial].
    5.  Loop to the next child [S3, unofficial].

**Pseudocode:**

```python
def cast_ray(node, origin, direction, bounds, entry):
    """
    Recursively traverse a voxel tree node.
    node: TreeBody (Empty, Leaf, or Branch)
    origin: [f32, f32, f32]
    direction: [f32, f32, f32]
    bounds: VoxelBounds
    entry: Optional[Entry]
    Returns: Result[R, Exit]
    """
    if node is Empty:
        pass # Fall through to exit calculation
    elif node is Leaf:
        result = act(bounds, node)
        if result is not None:
            return Ok(result)
        # Fall through to exit calculation
    elif node is Branch:
        mid = [
            (bounds.x + 0.5) * bounds.size(),
            (bounds.y + 0.5) * bounds.size(),
            (bounds.z + 0.5) * bounds.size()
        ]
        entry_toi = entry.toi if entry else 0.0
        intersect = [
            origin[0] + entry_toi * direction[0],
            origin[1] + entry_toi * direction[1],
            origin[2] + entry_toi * direction[2]
        ]
        coords = [
            1 if intersect[0] >= mid[0] else 0,
            1 if intersect[1] >= mid[1] else 0,
            1 if intersect[2] >= mid[2] else 0
        ]
        
        # Update bounds for child
        child_bounds = VoxelBounds(
            x=(bounds.x << 1) + coords[0],
            y=(bounds.y << 1) + coords[1],
            z=(bounds.z << 1) + coords[2],
            lg_size=bounds.lg_size - 1
        )
        
        # Recursive call
        res = cast_ray(node.child, origin, direction, child_bounds, entry)
        if res.is_ok():
            return res
        
        exit = res.error()
        dim = exit.side % 3
        
        # Update coordinates for next iteration
        if direction[dim] < 0.0:
            if coords[dim] == 0:
                return Err(exit)
            coords[dim] = 0
        else:
            if coords[dim] == 1:
                return Err(exit)
            coords[dim] = 1
            
        entry = Entry.from_exit(exit)
        
        # Loop to next child (simplified as recursive call with updated coords)
        # In practice, this is a loop in cast_ray_branches
        return cast_ray(node.child, origin, direction, child_bounds, entry)

    # Exit calculation
    sides = [bounds.x, bounds.y, bounds.z, bounds.x + 1, bounds.y + 1, bounds.z + 1]
    valid_exits = []
    
    for side, bound in enumerate(sides):
        dim = side % 3
        bound_val = bound * bounds.size()
        
        if direction[dim] == 0.0:
            continue
            
        toi = (bound_val - origin[dim]) / direction[dim]
        
        if entry is None:
            if toi >= 0.0:
                valid_exits.append(Exit(side, toi))
        else:
            if entry.toi <= toi:
                valid_exits.append(Exit(side, toi))
                
    if not valid_exits:
        return None # Should not happen if ray is inside
        
    # Find min toi, excluding entry side if entry exists
    min_exit = None
    for exit in valid_exits:
        if entry is not None and exit.side == entry.side:
            continue
        if min_exit is None or exit.toi < min_exit.toi:
            min_exit = exit
            
    return Err(min_exit)
```

**Parameters:**
*   **Precision:** 30 bits (NL=30) [S1].
*   **Resolution:** Octree level 9 ($512^3$ resolution) [S1].
*   **Dilation Count:** Number of voxel dilations on a boolean copy of the input grid to account for interpolation kernel sizes (default 0) [S2].
*   **NodeLevel:** The tree node level at which traversal stops and hit times are resolved (default: Leaf) [S2].

**Edge Cases and Pitfalls:**
*   **Precision Errors:** When subdivision levels approach floating-point limits, standard traversals may mismatch [S1]. This is handled by using interval arithmetic with correct rounding modes (SSE2) to guarantee correctness [S1].
*   **Division by Zero:** If $\mathbf{d}[\text{dim}] == 0.0$, the TOI calculation is skipped for that side [S3, unofficial].
*   **Thread Safety:** The `ValueAccessor` is not thread-safe. A copy constructor must be used to create a separate instance per computational thread [S2].
*   **Index vs World Space:** Hit times $t_0$ and $t_1$ are computed in index space. Client code must use `getIndexPos` or `getWorldPos` to convert [S2].

A ray marching algorithm that traverses a sparse voxel hierarchy (chunks, bricks, voxels) by computing the exit plane of the current cell using precomputed axis-aligned distance fields (AADF) stored in textures, avoiding per-voxel traversal when empty.

### [Voxel Ray Traversal (AABB-optimized)](3255-voxel-ray-traversal-aabb-optimized.md)
An iterator that traverses a 3D voxel volume along a ray, returning hits for voxels contained within the volume. It uses an Axis-Aligned Bounding Box (AABB) test to quickly reject rays that do not intersect the volume before performing the voxel traversal.

### [Hierarchical Brick-Map DDA](4105-hierarchical-brick-map-dda.md)
A ray marching technique that replaces a dense voxel buffer with a sparse hierarchical structure (brick-map) to skip empty regions. It uses a top-level grid of cells (stride 8 voxels) to quickly identify occupied bricks, then descends into those bricks for fine-grained DDA. This reduces memory footprint and traversal time in sparse volumes like drone airspace (>99% empty).

### [Sparse Voxel Grid Raycasting with Occupancy Grid](4152-sparse-voxel-grid-raycasting-with-occupancy-grid.md)
A rendering method that uses a sparse occupancy grid (OccGrid) to accelerate volume rendering by traversing only occupied voxels, using a custom CUDA kernel `traverse_grids` to generate sample intervals.

### Sparse Ray Marching for RTAO
A variant of sparse ray marching used for Ray Traced Ambient Occlusion. It marches from a surface point in a hemisphere direction, counting occlusions up to a radius limit [S5, unofficial]. It starts at the floor of the ray origin, initializes local position and distance to 0, and loops up to $3 \times \text{uniforms.grid\_ext}$ times [S5, unofficial]. It checks voxel occupancy using `voxel_masks`; if occupied, it returns true [S5, unofficial]. It loads the voxel AADF and calculates the exit plane, then advances the ray position [S5, unofficial]. It accumulates distance and stops at `t_max` [S5, unofficial]. Unlike the main sparse ray march, this version does not use the hierarchical chunk/brick structure, only checking `voxel_masks` and `voxel_aadf` [S5, unofficial].

## Operating characteristics
*   **Time Complexity:** Logarithmic with respect to the depth of the octree, $O(\log N)$, where $N$ is the number of voxels, due to skipping empty branches [S1][S3, unofficial].
*   **Memory Complexity:** Proportional to the number of non-empty nodes in the sparse voxel tree [S2].
*   **Performance:** On a PC with a Pentium-4 2.4GHz processor and 512Mbytes of main memory, generating $512 \times 512$ images for various surfaces (e.g., asterisk(9,18)) took approximately 410-445 seconds using the algorithm with SSE2 rounding modes, comparable to Gargantini's algorithm [S1]. The version without rounding modes was several seconds faster [S1].
*   **Strengths:** Guarantees correctness for all cases with minimal performance impact by using interval arithmetic with correct rounding modes [S1]. Efficiently skips empty space in sparse volumes [S3, unofficial].
*   **Limitations:** Requires careful handling of floating-point precision at high subdivision levels [S1]. The `ValueAccessor` is not thread-safe, requiring per-thread instances [S2].
*   **When to Use:** High-resolution sparse volumes where empty space skipping is critical and precision errors are a concern [S1, S2].
*   **When Not to Use:** Dense volumes where the overhead of tree traversal outweighs the benefit of skipping empty space, or when hardware does not support SSE2 instructions for interval arithmetic [S1].

## Background
Sparse Voxel Traversal originated from the need to efficiently render high-resolution implicit surfaces and volumetric data. The method using interval arithmetic with correct rounding modes was introduced to solve precision errors in Gargantini's algorithm, which only partially eliminated errors under restricted conditions [S1]. The implementation in OpenVDB (VolumeRayIntersector) is used in OpenVDB v13.1.0 for ray marching through density or generic volumes [S2]. The 5-4-3 node structure (Node5, Node4, Node3) is commonly used in game industry rendering for VDB data, as seen in benchmarks like Evolve [S4, unofficial]. The variant for Ray Traced Ambient Occlusion (RTAO) is used in real-time path tracing pipelines [S5, unofficial].
