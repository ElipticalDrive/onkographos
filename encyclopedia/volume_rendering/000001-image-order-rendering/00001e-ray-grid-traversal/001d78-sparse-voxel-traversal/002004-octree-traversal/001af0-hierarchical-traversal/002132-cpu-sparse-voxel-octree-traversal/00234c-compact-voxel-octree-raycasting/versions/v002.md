# Compact Voxel Octree Raycasting

Also called: Compact Octree Traversal, SVO Workbench Raycasting, Sparse Ray-Octree Intersection

## Overview
Compact Voxel Octree Raycasting is a CPU-based ray traversal algorithm for Sparse Voxel Octrees (SVO) that optimizes memory layout and traversal logic by compacting active ray-voxel interactions and decoding node masks on-the-fly [S2, unofficial]. It solves the problem of inefficient traversal in sparse structures by using an explicit stack to manage non-sequential memory layouts and a parallel "COMPACTIFY" step to filter out non-intersecting rays, ensuring that only valid ray-voxel pairs are processed in subsequent levels [S1, S2, unofficial]. Unlike recursive or parametric approaches, it relies on a linear block structure with explicit state management, making it suitable for high-performance CPU implementations where memory bandwidth and cache locality are critical [S2, unofficial]. It builds on [CPU Sparse Voxel Octree Traversal](2455-cpu-sparse-voxel-octree-traversal.md) and differs from [Parametric Octree Traversal](2361-parametric-octree-traversal.md), [Iterative Octree Traversal](2618-iterative-octree-traversal.md), [Recursive Octree Traversal](2632-recursive-voxel-octree-traversal.md), and [Sparse Voxel Octree Path Tracing](2988-sparse-voxel-octree-path-tracing.md) by explicitly managing traversal state and compacting active ray lists between levels.

## How it works
### Inputs and Outputs
*   **Input:** A ray $r = (o, d)$, where $o$ is the origin and $d$ is the direction; a Sparse Voxel Octree $ot$; a framebuffer $fb$ for output; screen coordinates $(cur\_x, cur\_y)$; and a parameter $terminLevel$ defining the maximum traversal depth [S2, unofficial].
*   **Output:** A boolean indicating if a leaf was hit, and a rendered pixel value drawn to $fb$ at $(cur\_x, cur\_y)$ [S2, unofficial].

### Data Structures
**CNode (8 bytes, packed)**
The node structure stores metadata for children and is a union of two layouts [S2, unofficial]:
1.  **Standard Layout:**
    *   `valid_mask` (UInt8): Bit $i=1$ means child $i$ exists.
    *   `leaf_mask` (UInt8): Bit $i=1$ means child $i$ is a leaf.
    *   `child_ptr` (UInt16): Relative offset to the first child or a far-pointer indicator.
2.  **Far Pointer Layout:**
    *   `far_ptr` (UInt32): Used if `child_ptr` indicates a far pointer. Contains the actual offset to the child data [S2, unofficial].

**Stack Item (`stack_item_t`)**
Stores the traversal state for backtracking [S2, unofficial]:
*   `tx0, ty0, tz0` (float): Entry t-values for the current node bounds.
*   `tx1, ty1, tz1` (float): Exit t-values for the current node bounds.
*   `node_adr` (pointer/integer): Absolute address of the current node.
*   `idx` (integer): Current child index.

**Traversal State Variables**
*   `si`: Stack index (current top).
*   `sl`: Stack level (current depth).
*   `level`: Current octree depth.
*   `is_first_node`: Boolean flag indicating if the current node is the first visited at this level.
*   `t_start`: Initial entry t-value for the ray.
*   `dir_mask`: Bitmask tracking ray direction flips (bit 4 for x, 2 for y, 1 for z) [S2, unofficial].

### Parameters
*   `terminLevel`: Integer. Maximum depth of the octree. Traversal stops here even if the node is not a leaf in the mask sense. Default: 10 [S2, unofficial].
*   `STACK_SIZE`: Integer. Maximum size of the traversal stack. Asserted against `si` before push [S2, unofficial].
*   `stack_level_max`: Integer. Maximum depth of the stack. `si` is only incremented if `sl < stack_level_max` [S2, unofficial].
*   `tnum_scale`: Fixed-point scaling factor. T-values are stored in fixed-point format with scale $2^{16}$ [S2, unofficial].

### Algorithm Steps
1.  **Ray Normalization:** Handle zero direction components by adding a small epsilon ($10^{-10}$) to avoid division by zero. Handle negative ray directions by flipping the origin and direction, setting `dir_mask` bits to track flips for index correction later [S2, unofficial].
2.  **Initialization:** Set `t_start = min(tx1, min(ty1, tz1))` on initial entry or stack underflow. Initialize `level=0`, `si=0`, `sl=0`, `is_first_node=True`, `node_adr=ot.root_adr`, `idx=0`, `exit_node=False`, `stack_underflow=False` [S2, unofficial].
3.  **Traversal Loop:** Loop while the stack is not empty or the initial node is being processed [S2, unofficial].
    *   **First Node Determination:** If `is_first_node` is true, get the current `BlockEntry`, decode node masks, calculate $t\_enter = \max(tx0, \max(ty0, tz0))$, determine first child index $i$ using $t$-deltas $(txm, tym, tzm)$, and set `is_first_node = false` [S2, unofficial].
    *   **Next Node Determination:** Otherwise, determine next child index using exit bounds $(tx1, ty1, tz1)$ and current `idx` [S2, unofficial].
    *   **Index Correction:** Apply `dir_mask` to the calculated child index `idx` to correct for ray direction flips: `idx_flip = i ^ dir_mask` [S2, unofficial].
    *   **Exit Handling:** If `exit_node` is true, check if `level == 0` (ray exited octree, return false). If `stack_underflow`, reset `t_start` to `t_exit` and restart initialization. Otherwise, pop the stack: decrement `level`, `si`, `sl`; restore `tx0..tz1`, `idx`, `node_adr` from `stack[si]`; get `BlockEntry`; decode child masks [S2, unofficial].
    *   **Leaf Hit Check:** If `c_leaf[idx_flip]` is true OR `level == terminLevel`, call `procLeaf(r, t_start, size)` to render the pixel and return true [S2, unofficial].
    *   **Valid Child Check:** If `c_valid[idx_flip]` is true, push current state to stack (assert `si < STACK_SIZE`), increment `si`, increment `sl` if `sl < stack_level_max`, increment `level`, set `is_first_node = true`, update bounds to child, get child `BlockEntry` using `ot->getRelativeEntry(node_adr, n->child_ptr)`, update `node_adr = child_bep.adr + c_offset[idx_flip]`, and decode new node masks [S2, unofficial].
4.  **COMPACTIFY Step:** After processing a level, run a parallel reduction to remove non-intersecting rays and compact the active ray list $N(l)$ into $N(l+1)$ using an exclusive sum of hit flags [S1].

### Pseudocode
```python
# Data structures
class Pixel:
    def __init__(self, r, g, b): self.r, self.g, self.b = r, g, b
class Framebuffer:
    def __init__(self, w, h): self.w, self.h, self.pixels = w, h, []
    def drawPixel(self, x, y, p): self.pixels.append((x, y, p))
class StackItem:
    def __init__(self, tx0, ty0, tz0, tx1, ty1, tz1, node_adr, idx):
        self.tx0, self.ty0, self.tz0 = tx0, ty0, tz0
        self.tx1, self.ty1, self.tz1 = tx1, ty1, tz1
        self.node_adr, self.idx = node_adr, idx
class CNode:
    def __init__(self): self.valid_mask, self.leaf_mask, self.child_ptr = 0, 0, 0
    def is_far(self): return (self.child_ptr >> 15) & 1

STACK_SIZE = 1024
stack_level_max = 32
terminLevel = 10
tnum_scale = 1 << 16

def child_decode(n, c_leaf, c_valid, c_offset):
    c = 0
    for i in range(8):
        valid = (n.valid_mask >> i) & 1
        leaf = (n.leaf_mask >> i) & 1
        c_valid[i] = valid
        c_leaf[i] = leaf
        if valid and not leaf:
            c_offset[i] = c
            c += 1

def first_node(tx0, ty0, tz0, txm, tym, tzm):
    t_enter = max(tx0, max(ty0, tz0))
    i = 0
    if tzm < t_enter: i ^= 1
    if tym < t_enter: i ^= 2
    if txm < t_enter: i ^= 4
    return i

def new_node(tx1, ty1, tz1, node_index):
    if tx1 < ty1 and tx1 < tz1:
        return 8 if (node_index & 0b100) else (node_index ^ 0b100)
    elif ty1 < tz1:
        return 8 if (node_index & 0b010) else (node_index ^ 0b010)
    else:
        return 8 if (node_index & 0b001) else (node_index ^ 0b001)

def procLeaf(r_o, r_d, tmin, size, fb, cur_x, cur_y):
    red = (int(tmin) >> 8) % 256
    blu = 0
    fb.drawPixel(cur_x, cur_y, Pixel(red / 256, 0, blu / 256))

def ray_cast(r_o, r_d, ot, fb, cur_x, cur_y, termin_level):
    dir_mask = 0
    if r_d.x == 0: r_d.x = 1e-10
    if r_d.x < 0: r_o.x = -r_o.x; r_d.x = -r_d.x; dir_mask |= 4
    if r_d.y == 0: r_d.y = 1e-10
    if r_d.y < 0: r_o.y = -r_o.y; r_d.y = -r_d.y; dir_mask |= 2
    if r_d.z == 0: r_d.z = 1e-10
    if r_d.z < 0: r_o.z = -r_o.z; r_d.z = -r_d.z; dir_mask |= 1

    tx0, ty0, tz0 = 0, 0, 0
    tx1, ty1, tz1 = 1.0, 1.0, 1.0
    txm, tym, tzm = 1.0, 1.0, 1.0
    t_start = min(tx1, min(ty1, tz1))
    level, si, sl = 0, 0, 0
    is_first_node = True
    node_adr = ot.root_adr
    idx = 0
    exit_node = False
    stack_underflow = False
    stack = [None] * STACK_SIZE
    c_leaf, c_valid, c_offset = [False]*8, [False]*8, [0]*8

    while True:
        if is_first_node:
            be = ot.get_entry(node_adr)
            child_decode(be.node, c_leaf, c_valid, c_offset)
            i = first_node(tx0, ty0, tz0, txm, tym, tzm)
            is_first_node = False
        else:
            i = new_node(tx1, ty1, tz1, idx)

        idx_flip = i ^ dir_mask

        if exit_node:
            if level == 0: return False
            if stack_underflow:
                t_start = tx1
                continue
            level -= 1; si -= 1; sl -= 1
            s = stack[si]
            tx0, ty0, tz0, tx1, ty1, tz1, node_adr, idx = s.tx0, s.ty0, s.tz0, s.tx1, s.ty1, s.tz1, s.node_adr, s.idx
            be = ot.get_entry(node_adr)
            child_decode(be.node, c_leaf, c_valid, c_offset)
            continue

        if c_leaf[idx_flip] or level == termin_level:
            procLeaf(r_o, r_d, t_start, 1.0, fb, cur_x, cur_y)
            return True

        if c_valid[idx_flip]:
            assert si < STACK_SIZE
            stack[si] = StackItem(tx0, ty0, tz0, tx1, ty1, tz1, node_adr, idx)
            si += 1
            if sl < stack_level_max: sl += 1
            level += 1
            is_first_node = True
            # [G] Standard octree subdivision updates tx0..tz1 to child bounds based on idx_flip
            child_ptr = ot.get_entry(node_adr).node.child_ptr
            child_bep = ot.get_relative_entry(node_adr, child_ptr)
            node_adr = child_bep.adr + c_offset[idx_flip]
            be = ot.get_entry(node_adr)
            child_decode(be.node, c_leaf, c_valid, c_offset)
    return False

def COMPACTIFY(N_l, D, S):
    # Parallel reduction step
    for all t in {0, ..., |N_l| - 1} in parallel:
        if D[t] == 1:
            k = S[t]
            N_l_plus_1[k] = N_l[t]
    return N_l_plus_1
```

### Edge Cases and Pitfalls
*   **Far Pointers:** If `child_ptr` has bit 15 set (`child_ptr & (1<<15)`), the actual child pointer is stored in a separate 'far' entry at relative offset `child_ptr` from the current address. The far entry's `far_ptr` field contains the actual offset [S2, unofficial].
*   **Stack Underflow:** If the stack is empty and an exit is requested, the algorithm resets `t_start` to `t_exit` and restarts from initialization, effectively treating the ray as if it just entered the octree bounds [S2, unofficial].
*   **Ray Direction Zeroes:** Zero components in the ray direction must be handled by adding a small epsilon to avoid division by zero during t-value calculations [S2, unofficial].
*   **Precision:** T-values are stored in fixed-point format (`tnum`). Clipping is applied to prevent overflow (`tnum_max` and `tnum_min`) [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of rays, but optimized by the COMPACTIFY step which reduces the number of active rays as they traverse deeper into the octree. The traversal itself is proportional to the number of visited nodes [S1, S2, unofficial].
*   **Memory Complexity:** $O(D)$ for the stack, where $D$ is the maximum depth of the octree. The COMPACTIFY step requires temporary storage for the active ray list [S1, S2, unofficial].
*   **Performance:** The method is designed for CPU implementation, leveraging explicit stack management and parallel reduction for COMPACTIFY. It is efficient for sparse scenes where many rays do not intersect the octree [S2, unofficial].
*   **Strengths:** Explicit stack allows for non-recursive traversal, avoiding stack overflow issues. COMPACTIFY reduces memory bandwidth and processing load. On-the-fly mask decoding minimizes memory accesses [S2, unofficial].
*   **Limitations:** The heuristic for `new_node` may not be optimal for all ray directions. The fixed-point arithmetic may introduce precision errors for very large or very small scenes [S2, unofficial].
*   **When to use:** Suitable for CPU-based ray tracing of sparse voxel octrees where memory efficiency and explicit control over traversal are required [S2, unofficial].
*   **When not to use:** Not suitable for GPU implementations where recursive or parametric methods might be more natural. Not ideal for dense scenes where the overhead of stack management and COMPACTIFY may outweigh the benefits [S2, unofficial].

## Background
Compact Voxel Octree Raycasting is associated with the SVO Workbench project [S2, unofficial]. The COMPACTIFY technique, which is integral to this method, is described in the context of Neural Geometric Level of Detail (NGLOD) for real-time rendering with implicit 3D shapes [S1]. The SVO Workbench provides an implementation of this traversal algorithm for CPU-based ray tracing [S2, unofficial].
