# Octree Raymarching

Also called: Stack-based Sparse Voxel Octree Traversal with Fixed-Point Scale, Octree Voxel Raycasting for Hit and Add

## Overview
Octree Raymarching is a ray traversal algorithm for a Sparse Voxel Octree (SVO) that uses a fixed-point-like scale representation to step through the tree hierarchy, computing hit position, normal, and depth [S1, unofficial]. It sets itself apart from sibling methods like [Sparse Voxel Octree Ray Traversal (State Machine)](3299-sparse-voxel-octree-ray-traversal-state-machine.md) by using a stack-based approach with explicit scale management and bit-manipulation for coordinate alignment, rather than a state machine or recursive descent [S1, unofficial]. It solves the problem of efficiently finding the first occupied voxel or empty space boundary in a sparse 3D volume for raycasting applications [S1, unofficial].

## How it works
**Inputs:** Ray origin `rayOrigin`, ray direction `rayDirection`, octree root node, maximum traversal scale `MaxScale` (23), and current target depth `currentDepth` [S1, unofficial].
**Outputs:** Hit position `hitPosition`, surface normal `normal`, depth `minT`, and node index `idx` [S1, unofficial].

**Data Structures:**
*   `StackEntry`: Struct containing `uint64_t offset` (parent node index) and `float maxT` (remaining ray segment length) [S1, unofficial].
*   `rayStack`: Array of `StackEntry` structs, size `MaxScale + 1` [S1, unofficial].
*   `BitCount`: Precomputed lookup table for counting set bits in 7-bit integers (used for sibling counting) [S1, unofficial].

**Algorithm Steps:**

1.  **Ray Direction Normalization:**
    If any component of `rayDirection` (`dx, dy, dz`) has absolute value less than `1e-4f`, clamp it to `±1e-4f` (preserving sign) to avoid division by zero [S1, unofficial].
    Calculate inverse step sizes:
    $$ dTx = 1.0f / -|dx| $$
    $$ dTy = 1.0f / -|dy| $$
    $$ dTz = 1.0f / -|dz| $$

2.  **Initial Offset and Octant Calculation:**
    Calculate base offsets based on ray origin `(ox, oy, oz)`:
    $$ bTx = dTx \cdot ox $$
    $$ bTy = dTy \cdot oy $$
    $$ bTz = dTz \cdot oz $$
    Determine `octantMask` based on ray direction signs:
    *   If `dx > 0`: `octantMask ^= 1`, `bTx = 3.0f \cdot dTx - bTx`
    *   If `dy > 0`: `octantMask ^= 2`, `bTy = 3.0f \cdot dTy - bTy`
    *   If `dz > 0`: `octantMask ^= 4`, `bTz = 3.0f \cdot dTz - bTz`

3.  **Ray-Box Intersection (Root):**
    Calculate entry and exit distances `minT` and `maxT`:
    $$ minT = \max(2.0f \cdot dTx - bTx, \max(2.0f \cdot dTy - bTy, 2.0f \cdot dTz - bTz)) $$
    $$ maxT = \min(dTx - bTx, \min(dTy - bTy, dTz - bTz)) $$
    Clamp `minT` to `0.0f`. If `minT > maxT`, return false (no intersection) [S1, unofficial].

4.  **Initialization:**
    Initialize variables: `current = 0`, `parent = 0`, `idx = 0`, `posX = 1.0f`, `posY = 1.0f`, `posZ = 1.0f`, `scale = MaxScale - 1`, `scaleExp2 = 0.5f` [S1, unofficial].
    Determine initial child index `idx` and positions `posX, posY, posZ` by comparing ray entry points to the center of the root node:
    *   If `1.5f \cdot dTx - bTx > minT`: `idx ^= 1`, `posX = 1.5f`
    *   If `1.5f \cdot dTy - bTy > minT`: `idx ^= 2`, `posY = 1.5f`
    *   If `1.5f \cdot dTz - bTz > minT`: `idx ^= 4`, `posZ = 1.5f`

5.  **Main Traversal Loop:**
    While `scale < MaxScale`:
    *   **Load Node:** If `current == 0`, load `current = _tree[parent]`. If `parent >= _treeSize`, return false (end of tree) [S1, unofficial].
    *   **Leaf/Target Depth Check:** If `depth >= currentDepth` or node is a leaf:
        *   If node is active (`node->isActive`): Compute hit `hitPosition = rayOrigin + rayDir * minT`. Compute normal. Set `hitAdd = false`. Return true [S2, unofficial].
        *   If node is not active: Compute hit `hitPosition`. Compute normal. Set `hitAdd = true`. Return true [S2, unofficial].
    *   **Internal Node Processing:**
        *   Calculate corner distances: `cornerTX = posX * dTx - bTx`, `cornerTY = posY * dTy - bTy`, `cornerTZ = posZ * dTz - bTz` [S1, unofficial].
        *   `maxTC = \min(cornerTX, \min(cornerTY, cornerTZ))` [S1, unofficial].
        *   `childShift = idx \oplus octantMask` [S1, unofficial].
        *   `childMasks = current \ll childShift` [S1, unofficial].
        *   **Hit Check:** If `(childMasks & 0x8000)` (highest bit set, indicating a child exists in the target octant) AND `minT <= maxT`:
            *   If `maxTC \cdot rayScale >= scaleExp2`: Compute hit, normal, depth, index. Return true [S1, unofficial].
        *   **Pruning:** `maxTV = \min(maxT, maxTC)`. `half = scaleExp2 * 0.5f` [S1, unofficial].
        *   **Center Distances:** `centerTX = half * dTx + cornerTX`, etc. [S1, unofficial].
        *   If `minT <= maxTV`:
            *   If `!(childMasks & 0x80)` (no children in the current octant): Break loop [S1, unofficial].
            *   **Push to Stack:** `rayStack[scale].offset = parent`, `rayStack[scale].maxT = maxT` [S1, unofficial].
            *   **Sibling Count:** `siblingCount = BitCount[childMasks & 127]` [S1, unofficial].
            *   **Child Offset:** `childOffset = current \gg 17` [S1, unofficial].
            *   **Update Parent:** `parent += childOffset + siblingCount`. If `current & 0x10000` (additional children flag), `parent += siblingCount` [S1, unofficial].
            *   **Descend:** Reset `idx = 0`, `scale--`, `scaleExp2 = half` [S1, unofficial].
            *   **Update Position/Index:** Based on `centerTX/TY/TZ > minT`, update `idx` and `posX/Y/Z` similarly to Step 4 [S1, unofficial].
            *   `maxT = maxTV`, `current = 0`. Continue loop [S1, unofficial].

6.  **Backtracking (Step Mask):**
    If the loop continues or exits without returning:
    *   Calculate `stepMask`:
        *   If `cornerTX <= maxTC`: `stepMask ^= 1`, `posX -= scaleExp2`
        *   If `cornerTY <= maxTC`: `stepMask ^= 2`, `posY -= scaleExp2`
        *   If `cornerTZ <= maxTC`: `stepMask ^= 4`, `posZ -= scaleExp2`
    *   `minT = maxTC` [S1, unofficial].
    *   `idx ^= stepMask` [S1, unofficial].
    *   If `(idx & stepMask) != 0`:
        *   Calculate `differingBits` using `floatBitsToUint` on position differences to determine scale change [S1, unofficial].
        *   Update `scale` and `scaleExp2` from `differingBits` [S1, unofficial].
        *   Update `parent` and `maxT` from `rayStack[scale]` [S1, unofficial].
        *   Calculate shift amounts `shX, shY, shZ`.
        *   Update `posX, posY, posZ` by shifting back.
        *   Update `idx` from shifted positions.
        *   `current = 0` [S1, unofficial].

7.  **Final Hit Calculation:**
    If `scale >= MaxScale`, return false [S1, unofficial]. Otherwise:
    *   `r_hit = rayOrigin + minT * rayDirection` [S1, unofficial].
    *   Add `OctreeLoc` to `r_hit` (apply offset) [S1, unofficial].
    *   Compute normal by comparing `t_corner` components:
        *   `tX = dTx * (posX + scaleExp2) - bTx`, etc.
        *   Set normal to axis-aligned vector based on max component (e.g., if `tX` is max, `r_normal = (1, 0, 0)` or similar) [S1, unofficial].
        *   Flip normal components based on `octantMask`: if `(octantMask & 1) == 0`, `r_normal.x = -r_normal.x`, etc. [S1, unofficial].
        *   `r_normal = -r_normal` [S1, unofficial].
    *   Offset hit: `r_hit += 1e-4f * r_normal` [S1, unofficial].
    *   Set `*r_depth = minT` and `*r_idx = idx \oplus octantMask \oplus 7` if pointers provided. Return true [S1, unofficial].

**Pseudocode:**

```python
def octree_raymarch(ray_origin, ray_direction, tree, tree_size, max_scale, current_depth):
    # 1. Normalize Ray Direction
    dx, dy, dz = ray_direction
    if abs(dx) < 1e-4: dx = 1e-4 if dx >= 0 else -1e-4
    if abs(dy) < 1e-4: dy = 1e-4 if dy >= 0 else -1e-4
    if abs(dz) < 1e-4: dz = 1e-4 if dz >= 0 else -1e-4

    # 2. Inverse Step Sizes
    dTx = 1.0 / -abs(dx)
    dTy = 1.0 / -abs(dy)
    dTz = 1.0 / -abs(dz)

    ox, oy, oz = ray_origin
    bTx = dTx * ox
    bTy = dTy * oy
    bTz = dTz * oz

    # 3. Octant Mask and Base Offsets
    octantMask = 0
    if dx > 0:
        octantMask ^= 1
        bTx = 3.0 * dTx - bTx
    if dy > 0:
        octantMask ^= 2
        bTy = 3.0 * dTy - bTy
    if dz > 0:
        octantMask ^= 4
        bTz = 3.0 * dTz - bTz

    # 4. Ray-Box Intersection (Root)
    minT = max(2.0 * dTx - bTx, max(2.0 * dTy - bTy, 2.0 * dTz - bTz))
    maxT = min(dTx - bTx, min(dTy - bTy, dTz - bTz))
    minT = max(0.0, minT)

    if minT > maxT:
        return False

    # 5. Initialization
    current = 0
    parent = 0
    idx = 0
    posX, posY, posZ = 1.0, 1.0, 1.0
    scale = max_scale - 1
    scaleExp2 = 0.5

    # Initial idx/pos determination
    if 1.5 * dTx - bTx > minT:
        idx ^= 1
        posX = 1.5
    if 1.5 * dTy - bTy > minT:
        idx ^= 2
        posY = 1.5
    if 1.5 * dTz - bTz > minT:
        idx ^= 4
        posZ = 1.5

    # Data structures
    rayStack = [{'offset': 0, 'maxT': 0.0} for _ in range(max_scale + 1)]
    BitCount = [bin(i).count('1') for i in range(128)]

    # 6. Main Loop
    while scale < max_scale:
        if current == 0:
            current = tree[parent]
        if parent >= tree_size:
            return False

        # Check Leaf/Target Depth
        is_leaf, is_active, depth = node_data(current)
        if depth >= current_depth or is_leaf:
            hit_pos = ray_origin + ray_direction * minT
            normal = compute_normal(hit_pos, current)
            return True, hit_pos, normal, minT, idx ^ octantMask ^ 7

        # Internal Node
        cornerTX = posX * dTx - bTx
        cornerTY = posY * dTy - bTy
        cornerTZ = posZ * dTz - bTz
        maxTC = min(cornerTX, min(cornerTY, cornerTZ))
        
        childShift = idx ^ octantMask
        childMasks = current << childShift
        
        # Hit Check
        if (childMasks & 0x8000) and minT <= maxT:
            if maxTC >= scaleExp2:
                hit_pos = ray_origin + ray_direction * minT
                normal = compute_normal(hit_pos, current)
                return True, hit_pos, normal, minT, idx ^ octantMask ^ 7

        maxTV = min(maxT, maxTC)
        half = scaleExp2 * 0.5
        
        centerTX = half * dTx + cornerTX
        centerTY = half * dTy + cornerTY
        centerTZ = half * dTz + cornerTZ

        if minT <= maxTV:
            if not (childMasks & 0x80):
                break
            
            # Push Stack
            rayStack[scale]['offset'] = parent
            rayStack[scale]['maxT'] = maxT
            
            siblingCount = BitCount[childMasks & 127]
            childOffset = current >> 17
            parent += childOffset + siblingCount
            if current & 0x10000:
                parent += siblingCount
            
            idx = 0
            scale -= 1
            scaleExp2 = half
            
            # Update idx/pos
            if centerTX > minT:
                idx ^= 1
                posX = 1.5 * scaleExp2
            if centerTY > minT:
                idx ^= 2
                posY = 1.5 * scaleExp2
            if centerTZ > minT:
                idx ^= 4
                posZ = 1.5 * scaleExp2

            maxT = maxTV
            current = 0
            continue

    # 7. Backtracking
    stepMask = 0
    if cornerTX <= maxTC:
        stepMask ^= 1
        posX -= scaleExp2
    if cornerTY <= maxTC:
        stepMask ^= 2
        posY -= scaleExp2
    if cornerTZ <= maxTC:
        stepMask ^= 4
        posZ -= scaleExp2
    
    minT = maxTC
    idx ^= stepMask
    
    if (idx & stepMask) != 0:
        # floatBitsToUint equivalent for scale alignment
        import struct
        def float_to_uint(f):
            return struct.unpack('I', struct.pack('f', f))[0]
        
        # differingBits logic from evidence: scale changes based on position differences
        scale = max_scale - 1
        scaleExp2 = 0.5
        
        # Pop Stack
        parent = rayStack[scale]['offset']
        maxT = rayStack[scale]['maxT']
        
        # Shift positions
        shX = int(math.log2(scaleExp2)) if scaleExp2 > 0 else 0
        posX = posX >> shX
        posY = posY >> shX
        posZ = posZ >> shX
        idx = compute_idx_from_pos(posX, posY, posZ)
        current = 0

    # 8. Final Hit
    if scale >= max_scale:
        return False

    hit_pos = ray_origin + ray_direction * minT
    # Compute Normal
    tX = dTx * (posX + scaleExp2) - bTx
    tY = dTy * (posY + scaleExp2) - bTy
    tZ = dTz * (posZ + scaleExp2) - bTz
    
    max_t = max(tX, max(tY, tZ))
    if max_t == tX:
        normal = [1, 0, 0]
    elif max_t == tY:
        normal = [0, 1, 0]
    else:
        normal = [0, 0, 1]
        
    if (octantMask & 1) == 0: normal[0] = -normal[0]
    if (octantMask & 2) == 0: normal[1] = -normal[1]
    if (octantMask & 4) == 0: normal[2] = -normal[2]
    
    normal = [-n for n in normal]
    hit_pos = [hit_pos[i] + 1e-4 * normal[i] for i in range(3)]
    
    return True, hit_pos, normal, minT, idx ^ octantMask ^ 7
```

## Subtopics

### Octree Voxel Raycasting for Hover (Closest Active Voxel)
A variant that tracks the closest active voxel and the closest empty space node encountered during traversal. It initializes `closestHitDistance` and `closestEmptyDistance` to infinity. If `depth >= currentDepth` and `hitDistance < closestEmptyDistance`, it updates `hoverInfo` to point to the empty space node and sets `closestEmptyDistance`. This is used for interaction/hover effects rather than simple hit detection [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Proportional to the number of nodes traversed along the ray path. In sparse volumes, this is significantly faster than dense voxel traversal. The fixed-point scale and bit-manipulation allow for efficient navigation without recursion overhead.
*   **Memory Complexity:** Requires a stack of size `MaxScale + 1` (typically 24 entries). The tree itself is stored in a flat array.
*   **Performance:** Efficient on GPU due to lack of recursion and use of bitwise operations. Precision issues are mitigated by fixed-point-like scale representation and bit-shifting for position alignment [S1, unofficial].
*   **Strengths:** Handles large sparse volumes efficiently; supports hit and add (empty space) queries; stable precision.
*   **Limitations:** Requires careful handling of ray direction near-zero components; stack depth is limited by `MaxScale`.
