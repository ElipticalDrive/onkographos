# Animated Sparse Voxel Octrees (ASVO)


## Overview
Animated Sparse Voxel Octrees (ASVO) is a GPU-based rendering technique that applies rigid transformations or skeletal skinning to voxel-based 3D models in real-time [S1, unofficial]. It differs from standard Sparse Voxel Octree ray traversal by decoupling traversal into a parallel job queue system that processes animated leaf nodes, allowing efficient skeletal animation without reconstructing the octree structure per frame [S1, unofficial].

## How it works
ASVO operates in two main phases: a traversal phase that identifies visible, animated voxels and a drawing phase that resolves pixel coverage and lighting [S1, unofficial]. The method relies on a breadth-first search (BFS) job queue to manage traversal state across the octree hierarchy [S1, unofficial].

### Inputs and Outputs
**Inputs:**
*   **Octree Data:**
    *   `innerNodes`: Array of `BFSInnerNode` structures. Each contains a `mask` (bitmask of children) and `childPtr` (index offset to children) [S1, unofficial].
    *   `leaves`: Array of `VisualData` structures. Each contains visual properties (`normal`, `tangent`, `pos`, `texCoord`, `eyeVec`, `originalCenter`) and animation data (`boneWeights`, `boneIndex0-3`) [S1, unofficial].
    *   `animation`: Array of `float4x4` matrices representing bone transformations for the current frame. Size is `frameCount * boneCount` [S1, unofficial].
    *   `jobs`: Initial queue of `BFSJob` structures. Each job contains `index` (node index), `x`, `y`, `z` (subdivision coordinates) [S1, unofficial].
    *   `dim`: The total dimension of the octree space [S1, unofficial].
    *   `level`: The maximum depth of the octree [S1, unofficial].
    *   `boneCount`: Number of bones in the skeleton [S1, unofficial].
*   **Camera/View:**
    *   `world`, `view`, `projection`: Transformation matrices [S1, unofficial].
    *   `camPos`: Camera position in world space [S1, unofficial].
*   **Lighting:**
    *   `shadowMap`: Depth texture for shadow testing [S1, unofficial].
    *   `diffuse`, `illum`, `spec`, `normal`: Texture maps for material properties [S1, unofficial].

**Outputs:**
*   `depthBuffer`: Buffer storing the minimum depth for each screen pixel [S1, unofficial].
*   `voxelBuffer`: Buffer storing visual data for visible voxels [S1, unofficial].
*   `colorBuffer`: Final rendered image [S1, unofficial].

### Data Structures
*   **BFSJob**: `index` (`uint32_t`), `x`, `y`, `z` (`uint32_t`) [S1, unofficial].
*   **BFSInnerNode**: `mask` (`uint64_t`), `childPtr` (`uint32_t`) [S1, unofficial].
*   **VisualData** (Leaf Node): `vd.boneWeights` (`float4`), `vd.boneIndex0-3` (`uint32_t`), `vd.normal`, `vd.tangent`, `vd.pos`, `vd.texCoord`, `vd.eyeVec`, `vd.originalCenter` (`float3`/`float4`), `mask` (`uint64_t`) [S1, unofficial].

### Algorithm Steps
1.  **Initialization**: Load octree data, animation matrices, and initial BFS jobs from the root [S1, unofficial]. Initialize `depthBuffer` with maximum depth values [S1, unofficial]. Initialize `sharedTravQueuePtr` to 0 [S1, unofficial].
2.  **Traversal Kernel (Per Job)**: Each thread processes one job from the queue [S1, unofficial].
    a. **Grid Cell Calculation**: Calculate the dimensions of the current voxel in world space based on the octree level [S1, unofficial].
       $$ gridCellDim = \frac{dim}{2^{level}} $$
       $$ gridCellHalfDim = gridCellDim \times 0.5 $$
    b. **Voxel Center Computation**: Determine the center of the voxel in world space [S1, unofficial].
       *   If the node is a leaf with skinning (`node.vd.boneWeights.x > 0.0`):
           *   Retrieve bone transformations $M_0, M_1, M_2, M_3$ from the `animation` buffer using `boneIndex0-3` [S1, unofficial].
           *   Interpolate the center position $P_{orig}$ using bone weights $w_0, w_1, w_2, w_3$:
               $$ P_{world} = \sum_{i=0}^{3} w_i \cdot (M_i \cdot P_{orig}) $$
           *   Adjust the half-dimension to counteract stretching during skinning:
               $$ involvedBones = \sum_{i=0}^{3} w_i $$
               $$ gridCellHalfDim = gridCellHalfDim \times \min(2.0, involvedBones) $$
       *   Otherwise, use the original center position from the leaf data [S1, unofficial].
    c. **Clip Space Transformation**: Transform the center and dimensions into clip space [S1, unofficial].
       $$ P_{clip} = projection \times view \times world \times P_{world} $$
       Compute the eye vector:
       $$ eyeVec = \frac{camPos - P_{world}}{\|camPos - P_{world}\|} $$
    d. **Culling**:
       *   **Frustum Culling**: Check if the voxel's clip-space bounds are within $[-1, 1]$ [S1, unofficial].
       *   **Back-face Culling**: If `level > 8`, check the dot product of the normal and eye vector:
           $$ dot(node.vd.normal, eyeVec) \ge -0.4 $$
       If either culling test fails, discard the voxel [S1, unofficial].
    e. **Screen Projection and Depth**: Project the voxel center to screen coordinates $(x, y)$ [S1, unofficial]. Compute depth:
       $$ depth = P_{clip}.z \times 2147483647 $$
    f. **Queue Management or Buffer Update**:
       *   If the voxel has children (`popcount(node.mask) != 0`) AND spans more than 1 pixel (`dimVec.x > 1.0`):
           *   Generate child jobs for the 8 sub-voxels.
           *   Add child jobs to the queue using `atomicAdd` on `sharedTravQueuePtr` [S1, unofficial].
       *   Otherwise (leaf node or too small):
           *   Update the depth buffer:
               $$ atomicMin(depthBuffer + index, depth) $$
    g. **Visual Data Storage**: If the voxel was drawn (`P_{clip}.w == 1.0`) and its depth matches the updated depth buffer value:
       *   Write visual data (`normal`, `tangent`, `position`, `texCoord`, `eyeVec`, `originalCenter`) to `voxelBuffer` at the screen index [S1, unofficial].
3.  **Drawing Kernel (Per Pixel)**: For each pixel $(x, y)$:
    a. **Neighborhood Scan**: Scan a $3 \times 3$ neighborhood in the `depthBuffer` to find the voxel with the minimum depth that covers the pixel [S1, unofficial]. A voxel covers the pixel if:
       $$ |vd.pos.x - 0.5 - x| \le vd.pos.z $$
       $$ |vd.pos.y - 0.5 - y| \le vd.pos.w $$
    b. **Lighting**: Transform the voxel center to light space [S1, unofficial]. Check shadow mapping against `shadowMap` [S1, unofficial]. Compute diffuse and specular lighting using `diffuse`, `illum`, `normal`, and `spec` textures [S1, unofficial]. Update the `colorBuffer` [S1, unofficial].

### Pseudocode
```python
import math

class BFSJob:
    def __init__(self, index, x, y, z):
        self.index = index
        self.x = x
        self.y = y
        self.z = z

class float3:
    def __init__(self, x, y, z):
        self.x, self.y, self.z = x, y, z
    def __mul__(self, s): return float3(self.x*s, self.y*s, self.z*s)
    def __add__(self, o): return float3(self.x+o.x, self.y+o.y, self.z+o.z)
    def __sub__(self, o): return float3(self.x-o.x, self.y-o.y, self.z-o.z)
    def __matmul__(self, m):
        return float3(
            m[0][0]*self.x + m[0][1]*self.y + m[0][2]*self.z + m[0][3],
            m[1][0]*self.x + m[1][1]*self.y + m[1][2]*self.z + m[1][3],
            m[2][0]*self.x + m[2][1]*self.y + m[2][2]*self.z + m[2][3]
        )
    def __rmul__(self, s): return self * s

class float4:
    def __init__(self, x, y, z, w):
        self.x, self.y, self.z, self.w = x, y, z, w

def dot(a, b):
    return a.x*b.x + a.y*b.y + a.z*b.z

def length(v):
    return math.sqrt(v.x**2 + v.y**2 + v.z**2)

def normalize(v):
    l = length(v)
    return float3(v.x/l, v.y/l, v.z/l) if l > 0 else float3(0,0,0)

def atomicAdd(ptr, val):
    old = ptr[0]
    ptr[0] = old + val
    return old

def atomicMin(ptr, val):
    old = ptr[0]
    if val < old: ptr[0] = val
    return old

def popcount(n):
    return bin(n).count('1')

def traverse_job(job, innerNodes, leaves, animation, dim, level, camPos, world, view, projection,
                 depthBuffer, voxelBuffer, queue, queuePtr, width, height):
    gridCellDim = dim / (1 << level)
    gridCellHalfDim = gridCellDim * 0.5

    is_leaf = job.index >= len(innerNodes)
    node = leaves[job.index - len(innerNodes)] if is_leaf else innerNodes[job.index]

    if is_leaf and node.vd.boneWeights.x > 0.0:
        P_orig = node.vd.originalCenter
        w = node.vd.boneWeights
        M0, M1, M2, M3 = animation[node.vd.boneIndex0], animation[node.vd.boneIndex1], animation[node.vd.boneIndex2], animation[node.vd.boneIndex3]
        P_world = w.x * (M0 @ P_orig) + w.y * (M1 @ P_orig) + w.z * (M2 @ P_orig) + w.w * (M3 @ P_orig)
        involvedBones = w.x + w.y + w.z + w.w
        gridCellHalfDim = gridCellHalfDim * min(2.0, involvedBones)
    else:
        P_world = node.vd.originalCenter

    P_clip = projection @ view @ world @ P_world
    eyeVec = normalize(camPos - P_world)

    if not (-1.0 <= P_clip.x <= 1.0 and -1.0 <= P_clip.y <= 1.0 and -1.0 <= P_clip.z <= 1.0):
        return
    if level > 8:
        if dot(node.vd.normal, eyeVec) < -0.4:
            return

    x_screen = P_clip.x / P_clip.w
    y_screen = P_clip.y / P_clip.w
    depth = P_clip.z * 2147483647

    childCount = popcount(node.mask)
    # Estimate screen-space dimension of the voxel
    dimClip = projection @ view @ world @ (P_world + float3(gridCellHalfDim, 0, 0))
    dimVec = float3(dimClip.x / dimClip.w, dimClip.y / dimClip.w, dimClip.z / dimClip.w)
    dimScreen = abs(dimVec.x - x_screen) + abs(dimVec.y - y_screen)

    if childCount != 0 and dimScreen > 1.0:
        for j in range(8):
            if (node.mask >> j) & 1:
                child_index = 0
                for k in range(j):
                    if (node.mask >> k) & 1:
                        child_index += 1
                new_job = BFSJob(
                    index=node.childPtr + child_index,
                    x=2*job.x + (j & 1),
                    y=2*job.y + ((j & 2) >> 1),
                    z=2*job.z + ((j & 4) >> 2)
                )
                idx = atomicAdd(queuePtr, 1)
                queue[idx] = new_job
    else:
        index = int(x_screen) + int(y_screen) * width
        old_depth = atomicMin(depthBuffer + index, depth)
        if P_clip.w == 1.0 and depth == old_depth:
            voxelBuffer[index] = node.vd

def draw_pixel(x, y, depthBuffer, voxelBuffer, shadowMap, diffuse, illum, spec, normal, width, height):
    min_depth = float('inf')
    best_voxel = None
    for dx in range(-1, 2):
        for dy in range(-1, 2):
            px, py = x + dx, y + dy
            if 0 <= px < width and 0 <= py < height:
                idx = px + py * width
                d = depthBuffer[idx]
                if d < min_depth:
                    min_depth = d
                    best_voxel = voxelBuffer[idx]

    if best_voxel is None:
        return

    if abs(best_voxel.pos.x - 0.5 - x) <= best_voxel.pos.z and \
       abs(best_voxel.pos.y - 0.5 - y) <= best_voxel.pos.w:
        # Transform to light space and sample shadow map [G]
        # P_light = light_view_projection @ world @ best_voxel.originalCenter
        # shadow = shadowMap.sample(P_light.xy / P_light.w, P_light.z / P_light.w)
        # Compute diffuse and specular lighting from textures [G]
        # color = compute_diffuse(best_voxel, diffuse, illum) + compute_specular(best_voxel, spec)
        # color *= shadow
        colorBuffer[x + y * width] = best_voxel.color # Placeholder for final color [G]
```

### Parameters and Edge Cases
*   **Level Threshold**: Back-face culling is only applied if `level > 8` [S1, unofficial].
*   **Bone Weights**: Skinning is applied only if `boneWeights.x > 0.0` [S1, unofficial].
*   **Precision**: Depth is computed as `center.z * INT_MAX`, which may introduce precision issues for very large scenes or deep octrees [S1, unofficial].
*   **Queue Size**: The traversal uses a dynamic queue with `atomicAdd`, requiring careful management of shared memory or global memory contention [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: Not given in the sources.
*   **Memory Complexity**: Requires storage for `innerNodes`, `leaves`, `animation` matrices, and buffers (`depthBuffer`, `voxelBuffer`, `colorBuffer`). The queue size depends on the branching factor and visibility [S1, unofficial].
*   **Performance**: High performance on CUDA-capable GPUs (Compute Capability 3.0+) due to parallel job processing [S1, unofficial].
*   **Strengths**: Efficient handling of animated voxel models; no need to rebuild the octree for animation frames [S1, unofficial].
*   **Limitations**: Limited to rigid transformations and skinning; complex deformations may require more sophisticated approaches. Precision issues with depth buffering in large scenes [S1, unofficial].

## Background
ASVO was developed as a CUDA/C++ implementation for rendering animated voxel models [S1, unofficial]. It builds on the concept of Sparse Voxel Octrees, extending them to support skeletal animation by applying bone transformations to leaf nodes during traversal [S1, unofficial]. The project includes a high-performance CUDA implementation and an XNA/C# prototype for algorithm design [S1, unofficial].
