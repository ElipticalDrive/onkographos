# Octree Node Lookup by Voxel


## Overview
This method locates the payload index for a specific 3D voxel coordinate within a Sparse Voxel Octree (SVO) by traversing from the root to the corresponding leaf node [S1, unofficial]. It solves the problem of mapping a continuous or discrete voxel coordinate to the sparse data structure's payload array, returning -1 if the voxel lies outside the tree's bounds or in an empty region [S1, unofficial]. It differs from [Octree Voxel Color Retrieval](5015-octree-voxel-color-retrieval.md) by returning only the index rather than interpolating or fetching the actual color/value data [S1, unofficial].

## How it works
**Inputs:**
- `nodes`: Array of `NodeDescriptor` structures representing the octree nodes.
- `num_nodes`: Total number of nodes in the `nodes` array.
- `leaf_payload_indices`: Array of indices mapping leaf IDs to payload rows.
- `num_leaves`: Total number of leaves.
- `max_depth`: The maximum depth of the octree (root is depth 0).
- `root_bounds`: The spatial bounds of the root node (used to validate voxel coordinates relative to the grid size).
- `voxel`: A 3D integer coordinate `(x, y, z)` to look up.

**Outputs:**
- `payload_index`: The index into the payload array corresponding to the voxel. Returns -1 if the voxel is invalid or empty.

**Data Structures:**
- `NodeDescriptor`: Contains the following fields:
  - `child_mask`: 8-bit bitmask indicating which of the 8 children exist.
  - `leaf_mask`: 8-bit bitmask indicating which children are leaf nodes.
  - `payload_base`: Offset into `leaf_payload_indices` for the first leaf child.
  - `internal_child_mask`: 8-bit bitmask indicating which children are internal nodes.
  - `child_base`: Offset into the `nodes` array for the first internal child.

**Formulas:**
1.  **Grid Size:** $grid\_size = 2^{max\_depth}$
2.  **Child Index:** For a given depth $d$ (where $d$ ranges from $max\_depth-1$ down to 0), the child index $c$ is:
    $$c = \left(\frac{x}{2^d} \pmod 2\right) \mid \left(\left(\frac{y}{2^d} \pmod 2\right) \ll 1\right) \mid \left(\left(\frac{z}{2^d} \pmod 2\right) \ll 2\right)$$
    In bitwise operations:
    $$c = ((x \gg d) \& 1) \mid (((y \gg d) \& 1) \ll 1) \mid (((z \gg d) \& 1) \ll 2)$$
3.  **Prefix Rank:** The number of set bits in a mask strictly below a given index $i$:
    $$prefix\_rank(mask, i) = \text{popcount}(mask \& ((1 \ll i) - 1))$$

**Algorithm Steps:**
1.  If `num_nodes` is 0, return -1.
2.  If `max_depth` is 0, the root is a leaf. If `leaf_payload_indices` is valid and contains data, return `leaf_payload_indices[0]`. Otherwise, return -1.
3.  Calculate $grid\_size = 2^{max\_depth}$.
4.  If `voxel.x`, `voxel.y`, or `voxel.z` is not in the range $[0, grid\_size)$, return -1.
5.  Initialize `node_index = 0` and `depth_remaining = max_depth`.
6.  Loop indefinitely:
    a.  If `node_index >= num_nodes`, return -1 (traversal exceeded node array bounds).
    b.  Retrieve `descriptor = nodes[node_index]`.
    c.  Calculate `child_index` using the formula above with `child_depth = depth_remaining - 1`.
    d.  Compute `child_bit = 1 << child_index`.
    e.  If `(descriptor.child_mask() & child_bit) == 0`, the child does not exist. Return -1.
    f.  If `(descriptor.leaf_mask() & child_bit) != 0`, the child is a leaf:
        i.  Compute `leaf_id = descriptor.payload_base() + prefix_rank(descriptor.leaf_mask(), child_index)`.
        ii. Retrieve `payload_index = leaf_payload_indices[leaf_id]`.
        iii. Validate `payload_index` (e.g., check if it is within bounds of the payload array). If valid, return `payload_index`. Else, return -1.
    g.  Otherwise, the child is an internal node:
        i.  Compute `new_node_index = descriptor.child_base() + prefix_rank(descriptor.internal_child_mask(), child_index)`.
        ii. Decrement `depth_remaining`.
        iii. If `depth_remaining <= 0`, return -1 (should have hit a leaf or invalid path).
        iv. Set `node_index = new_node_index` and continue loop.

**Pseudocode:**
```python
def lookup_payload_index_by_voxel(nodes, num_nodes, leaf_payload_indices, num_leaves, max_depth, voxel):
    # Step 1: Empty tree check
    if num_nodes == 0:
        return -1

    # Step 2: Max depth 0 check (Root is leaf)
    if max_depth == 0:
        if num_leaves > 0 and len(leaf_payload_indices) > 0:
            return leaf_payload_indices[0]
        else:
            return -1

    # Step 3 & 4: Bounds check
    grid_size = 1 << max_depth
    if not (0 <= voxel.x < grid_size and 0 <= voxel.y < grid_size and 0 <= voxel.z < grid_size):
        return -1

    # Step 5: Initialization
    node_index = 0
    depth_remaining = max_depth

    # Step 6: Traversal Loop
    while True:
        # Step 6a: Bounds check for node array
        if node_index >= num_nodes:
            return -1

        descriptor = nodes[node_index]

        # Step 6b: Calculate child index
        child_depth = depth_remaining - 1
        x_bit = (voxel.x >> child_depth) & 1
        y_bit = (voxel.y >> child_depth) & 1
        z_bit = (voxel.z >> child_depth) & 1
        child_index = x_bit | (y_bit << 1) | (z_bit << 2)

        # Step 6d: Check if child exists
        child_bit = 1 << child_index
        if (descriptor.child_mask & child_bit) == 0:
            return -1

        # Step 6f: Check if child is leaf
        if (descriptor.leaf_mask & child_bit) != 0:
            # Compute leaf_id
            # prefix_rank(mask, i) = popcount(mask & ((1 << i) - 1))
            lower_mask = (1 << child_index) - 1
            rank = popcount(descriptor.leaf_mask & lower_mask)
            leaf_id = descriptor.payload_base + rank
            
            # Retrieve payload index
            if leaf_id < num_leaves and leaf_id < len(leaf_payload_indices):
                payload_index = leaf_payload_indices[leaf_id]
                # Validate payload_index (e.g., non-negative, within payload bounds)
                # [G] Assuming payload indices are valid if >= 0 and < payload_rows
                # The source does not specify payload_rows limit check here, 
                # but typically payload_index must be valid.
                return payload_index
            else:
                return -1

        # Step 6g: Internal node
        # Compute new node index
        lower_mask = (1 << child_index) - 1
        rank = popcount(descriptor.internal_child_mask & lower_mask)
        new_node_index = descriptor.child_base + rank
        
        depth_remaining -= 1
        if depth_remaining <= 0:
            return -1
        
        node_index = new_node_index
```

**Parameters:**
- `payload_rows`: Total number of payload rows. Used to validate the returned `payload_index` [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Precision:** Bitwise operations assume integer coordinates. Floating-point voxel coordinates must be converted to integers (e.g., via floor or truncation) before lookup [S1, unofficial].
- **Boundaries:** Voxels exactly at `grid_size` are out of bounds. The check is strictly `< grid_size` [S1, unofficial].
- **Degenerate Input:** An empty tree (`num_nodes == 0`) or a tree with `max_depth == 0` but no leaves must be handled explicitly [S1, unofficial].
- **Invalid Indices:** If `leaf_id` or `payload_index` is out of bounds, return -1 [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(depth)$, where depth is `max_depth`. Each step involves constant-time bitwise operations and array accesses.
- **Memory Complexity:** $O(1)$ auxiliary space. The traversal uses a fixed number of variables.
- **Performance:** Fast for sparse trees as it skips empty branches. Performance degrades if the tree is deep and the voxel is in a sparse region requiring many hops [S1, unofficial].
- **Strengths:** Exact lookup, no interpolation overhead, efficient for sparse data.
- **Limitations:** Does not handle partial voxel coverage (requires discrete voxel coordinates). Not suitable for continuous ray marching without additional interpolation logic [S1, unofficial].

## Background
The method is part of the Sparse Voxel Octree (SVO) rendering pipeline, specifically designed for efficient voxel-based data access. It is implemented in the `sparse-voxels` library by Hector Piteau [S1, unofficial]. The approach leverages bitmasks and prefix ranks to navigate the compacted octree structure without explicit child pointers, optimizing memory usage and cache locality [S1, unofficial].
