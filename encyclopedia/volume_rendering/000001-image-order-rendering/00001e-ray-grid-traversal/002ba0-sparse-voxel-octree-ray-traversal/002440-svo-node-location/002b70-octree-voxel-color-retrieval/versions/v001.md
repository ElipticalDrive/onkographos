# Octree Voxel Color Retrieval

Also called: Color Lookup with Shading, lookupColor

## Overview
Retrieves the color of a voxel from the sparse voxel octree (SVO) data structure, applying lighting if the scene is not shadeless [S1, unofficial]. It navigates the tree from a given node to find the leaf node containing the color data [S1, unofficial]. It builds on [SVO Node Location](3249-svo-node-location.md) by taking the ray-hit node and extending the traversal to the leaf level to extract material properties and compute illumination.

## How it works
**Inputs:**
- `castRes`: Result from ray traversal containing:
  - `pos`: Ray position at hit (float3).
  - `node`: Current octree node index (uint).
  - `childIdx`: Child index within the current node (uint).
  - `scale`: Current tree level (uint).
  - `normal`: Hit normal in local space (float3).
- `octree`: Data structure containing:
  - `data`: Array of uints representing the octree memory layout.
- `renderList`: Contains:
  - `offsets`: Array of offsets for instances.
- `ubo`: Uniform buffer object containing:
  - `shadeless`: Boolean flag (int).
  - `ambientStrength`: Scalar.
  - `lightColor`: vec3.
  - `lightPos`: vec3.
  - `blockInfoEnd`: Offset for block info.
  - `pageBytes`: Bytes per page.
  - `transformCount`: Number of transforms.

**Outputs:**
- `vec4`: Final color with alpha (1.0 if shadeless, otherwise computed alpha).

**Data Structures:**
The octree is stored in a flat array `octree.data`. Nodes are organized into pages. Each page has a header. The layout relies on bit-packing for node pointers and color data.

**Steps:**

1. **Extract Position and Tree State:**
   Convert ray position to integer coordinates for indexing.
   $$ px = \text{floatBitsToInt}(castRes.pos.x) $$
   $$ node = castRes.node $$
   $$ cidx = castRes.childIdx $$
   $$ level = castRes.scale $$

2. **Calculate Page Header and Block Info:**
   Extract the page header from the node index.
   $$ pageHeader = node \ \& \ 0xFFFFF800 $$
   Retrieve block information from the data array.
   $$ blockInfo = pageHeader + octree.data[pageHeader] $$
   Get attach data by adding the block info end offset.
   $$ attachData = \text{int}(blockInfo) + ubo.blockInfoEnd $$

3. **Get Palette Node:**
   Calculate the palette node index.
   $$ paletteNode = octree.data[attachData + \text{int}(node) - \text{renderList.offsets}[index] / 4 - 1] $$

4. **Traverse to Leaf:**
   Loop while the current node does not have color data (indicated by the bit at `cidx` not being set).
   $$ \text{while } ((\text{int}(paletteNode \gg cidx) \ \& \ 1) \neq 1) $$
   Inside the loop:
   - Increment level.
   - Check bounds.
   - Update `node`, `cidx`, `pageHeader`, `blockInfo`, `attachData`, and `paletteNode` according to the octree traversal logic [S1, unofficial].

5. **Calculate Attach Offset and Extract Color Component:**
   $$ attachOffset = attachData + \text{int}(paletteNode \gg 8) + \text{bitCount}(paletteNode \ \& \ (1 \ll cidx) - 1) $$
   $$ c = \text{int}(octree.data[attachOffset]) $$

6. **Extract RGB and Normalize:**
   $$ r = (c \gg 16) \ \& \ 0xFF $$
   $$ g = (c \gg 8) \ \& \ 0xFF $$
   $$ b = c \ \& \ 0xFF $$
   $$ octreeColor = \text{vec3}(r / d, g / d, b / d) $$
   Where $d$ is a normalization divisor [S1, unofficial].

7. **Handle Shadeless Mode:**
   If `ubo.shadeless == 1`, return the color with alpha 1.0.
   $$ \text{return vec4}(octreeColor, 1.0) $$

8. **Load Transformation Matrix:**
   Calculate offset for transform data.
   $$ offset = \text{int}(\text{renderList.offsets}[index] + ubo.pageBytes) / 4 - ubo.transformCount * 4 $$
   Read 16 floats into `v[]` and construct `mat4 octreeToWorld`.

9. **Normalize Hit Normal in World Space:**
   $$ hitNormalWorld = \text{normalize}(octreeToWorld * castRes.normal) $$

10. **Calculate Lighting:**
    $$ ambient = ubo.ambientStrength * \text{vec3}(ubo.lightColor) $$
    $$ lightDir = \text{vec3}(\text{normalize}(ubo.lightPos)) $$
    $$ diffuse = \max(\text{dot}(hitNormalWorld, lightDir), 0.0) * \text{vec3}(ubo.lightColor) $$
    $$ color = (ambient + diffuse) * octreeColor $$

**Pseudocode:**

```python
def octree_voxel_color_retrieval(castRes, octree, renderList, ubo, index):

    c = int(octree.data[attach_offset])
    
    # 6. Extract RGB and Normalize
    r = (c >> 16) & 0xFF
    g = (c >> 8) & 0xFF
    b = c & 0xFF
    octree_color = vec3(r / ubo.divisor, g / ubo.divisor, b / ubo.divisor) # [G] divisor 'd' assumed from ubo or constant
    
    # 7. Handle Shadeless Mode
    if ubo.shadeless == 1:
        return vec4(octree_color, 1.0)
        
    # 8. Load Transformation Matrix
    offset = int(renderList.offsets[index] + ubo.page_bytes) // 4 - ubo.transform_count * 4
    v = [octree.data[offset + i] for i in range(16)] # [G] Assuming data is uints, need conversion to float
    octree_to_world = mat4(v)
    
    # 9. Normalize Hit Normal in World Space
    hit_normal_world = normalize(octree_to_world * castRes.normal)
    
    # 10. Calculate Lighting
    ambient = ubo.ambient_strength * vec3(ubo.light_color)
    light_dir = vec3(normalize(ubo.light_pos))
    diffuse = max(dot(hit_normal_world, light_dir), 0.0) * vec3(ubo.light_color)
    color = (ambient + diffuse) * octree_color
    
    return vec4(color, 1.0) # [G] Alpha assumed 1.0 if not shadeless, or derived from voxel
```

## Operating characteristics
- **Time Complexity:** Linear with respect to the depth of the octree from the hit node to the leaf.
- **Memory Complexity:** Constant additional memory for local variables.
- **Strengths:** Efficient retrieval of color data from sparse structures. Supports dynamic lighting.
- **Limitations:** Requires careful handling of tree traversal and data layout. Precision issues may arise in coordinate conversion.
- **When to use:** When rendering sparse voxel octrees with lighting.
- **When not to use:** When shadeless rendering is sufficient and lighting calculations are too expensive.

## Background
Originated in the context of sparse voxel octree rendering, specifically in implementations like the `origin` renderer [S1, unofficial]. It is used in real-time ray tracing applications to provide shaded voxel colors.
