# Empty Space Skipping via Data Structures

Also called: Hierarchical Empty Space Skipping, Accelerated Ray Traversal via Occupancy Structures

## Overview
Empty Space Skipping via Data Structures is a family of volume rendering optimization techniques that accelerate ray casting by identifying and bypassing empty or inactive regions within a 3D volume using pre-computed or dynamically generated spatial data structures [S1][S2, unofficial]. It solves the problem of redundant sampling in large, sparse volumes by restricting ray marching to active regions, thereby reducing computational cost and memory bandwidth usage. It sets itself apart from image-order methods like [Space Leaping](5863-space-leaping.md) by relying on explicit spatial occupancy maps or hierarchical structures rather than per-pixel coherence, and from [Object-Order Empty Space Skipping](865-object-order-empty-space-skipping.md) by performing skipping via data structure lookups during ray traversal rather than hardware rasterization of bounding geometry.

## Shared principles
All methods in this family share the core mechanism of using a secondary data structure to represent the spatial distribution of active volume data, allowing rays to skip over inactive regions without sampling the primary volume texture.

1.  **Acceleration Structure:** A data structure (e.g., occupancy grid, octree, BVH, hash map) is constructed to represent the volume. Each element in this structure corresponds to a region of the volume and stores metadata indicating whether that region contains "active" data (e.g., density above a threshold, non-zero opacity) [S1][S2, unofficial].
2.  **Active Region Definition:** A region is defined as active if it contributes to the final image. Common criteria include:
    *   Maximum voxel value exceeding an isovalue threshold $\tau$ [S1].
    *   Presence of non-zero opacity after transfer function application [S1][S2, unofficial].
    *   Density values above a specific threshold $\tau_1$ [S1].
3.  **Ray Query and Skip:** During rendering, for each ray, the algorithm queries the acceleration structure to find the entry and exit points of active regions.
    *   If a ray segment lies entirely within an inactive region indicated by the structure, the ray is advanced to the next active region boundary without sampling the volume [S1][S2, unofficial].
    *   If a ray segment intersects an active region, standard ray marching or integration is performed within that segment [S1][S2, unofficial].
4.  **Coordinate Mapping:** Efficient mapping between ray positions in world/voxel space and indices in the acceleration structure is required. For regular grids, this is often a simple division by block size: $u_{\text{occ}} = u_{\text{vol}} / B$ [S1].

## Subtopics

### [Object-Order Empty Space Skipping](865-object-order-empty-space-skipping.md)
Computes ray skip bounds by rasterizing a bounding mesh of active volume blocks. It differs from data-structure lookups by using hardware rasterization to find entry/exit depths, making it resolution-dependent and efficient for large empty regions but requiring geometry regeneration on isovalue changes.

### [Ray Casting with Depth/Alpha Test for Empty Space Skipping](1537-ray-casting-with-depth-alpha-test-for-empty-space-skipping.md)
Uses GPU depth buffer and alpha test to dynamically generate "Slab Silhouette Maps" for skipping. It differs from pre-computed structures by generating the acceleration data on-the-fly during rendering passes, avoiding CPU-side preprocessing but requiring multiple render passes.

### [Semi-transparent Empty-Space Skipping](1911-semi-transparent-empty-space-skipping.md)
Extends hierarchical skipping to semi-transparent volumes by combining BVH traversal with analytic integration for constant density. It differs from opaque skipping by using lower bounds for sphere tracing to find exit points and computing optical depth analytically, rather than just culling segments.

### [Dynamic MLP Maps with Empty Space Skipping](3036-dynamic-mlp-maps-with-empty-space-skipping.md)
Uses a pre-computed 3D occupancy volume to skip empty space in neural volume rendering (volumetric video). It differs from traditional grids by combining occupancy skipping with multi-level hash tables and 2D CNN-generated MLP maps for efficient neural network evaluation.

### [Occupancy Grid and Map-Based Empty Space Skipping](3852-occupancy-grid-and-map-based-empty-space-skipping.md)
Uses a lower-resolution binary grid to skip high-resolution volume blocks. It differs from distance maps by using simple binary flags rather than distance fields, and from hierarchical structures by using a regular grid layout for simple coordinate mapping.

### [Space Leaping](5863-space-leaping.md)
Uses image-order coherence to skip empty space via a lightweight buffer storing first-hit distances. It differs from spatial data structures by relying on neighbor ray similarity rather than explicit 3D occupancy maps, making it lightweight but limited to skipping before the first hit.

### Empty Space Skipping with HistoPyramid
A technique achieving extremely fine-grained empty space skipping by marching rays only through active volume cells, located efficiently with a HistoPyramid texture and rendered as point primitives [S1].
1.  Locate active volume cells using a HistoPyramid texture [S1].
2.  Render active cells as point primitives to create rays close to the isosurface [S1].
3.  Accelerate by exploiting early-depth testing: compare fragment's interpolated z-coordinate with depth buffer value; discard if occluded [S1].
4.  Rasterize primitives in front-to-back order to increase discarded fragments, achieved via CPU-based sorting of volume slices [S1].
Considered a hybrid object-order and image-order approach, meaning it is dependent on rendering resolution [S1].

### Hybrid kd-tree/Uniform Grid
A hybrid data structure combining a kd-tree structure at the root level and a uniform grid at the leaf-node level used for empty-space skipping [S2, unofficial].
During rendering, the kd-tree is traversed on the CPU to generate a sorted list of non-empty leaf nodes that are then iterated over on the GPU [S2, unofficial].

## Background
The concept of empty space skipping is fundamental to efficient volume rendering, particularly for large-scale datasets where significant portions of the volume are empty or inactive. Early work focused on simple occupancy grids and distance maps. The use of hierarchical structures like octrees and BVHs allowed for more efficient skipping in complex scenes. The introduction of GPU-driven techniques, such as using depth buffers for silhouette maps (Slab Silhouette Maps) and HistoPyramids for active cell location, shifted the paradigm towards hybrid object-order/image-order approaches that leverage hardware rasterization for acceleration [S1][S2, unofficial]. Recent developments in neural volume rendering have adapted these skipping techniques to work with implicit representations like hash grids and MLP maps, using occupancy volumes to skip empty space in high-dimensional feature spaces [S1].
