# Empty Space Filtering (Training-Time Bounding Box)

Also called: Alpha-based Bounding Box Filtering, Training-time Empty Space Filtering

## Overview
Empty Space Filtering is a preprocessing and runtime optimization technique used in dynamic neural volume rendering to accelerate training and inference by avoiding computations in regions identified as empty space [S1]. It differs from static occupancy grid methods by deriving its spatial bounds from the temporal consistency of alpha values across all training time steps, creating a "coarse geometry prior" that restricts the active volume [S1]. Unlike [Distance Map Acceleration](972-distance-map-acceleration.md) which uses geometric distance, or [Two-stage Ray Marching with Empty-Space Skipping](2985-two-stage-ray-marching-with-empty-space-skipping.md) which may use separate coarse/fine networks for skipping, this method explicitly filters sampled points based on a global bounding box derived from alpha thresholds [S1].

## How it works
The method operates in two phases: a preprocessing phase to determine the active bounding box, and a runtime phase to filter ray samples. It relies on a coarse deformation feature grid and an alpha threshold to distinguish object points from empty space [S1].

**Inputs:**
- Coarse deformation feature grid vertices.
- Training time steps $t \in \{0, \dots, T\}$.
- Alpha threshold $\tau$ (scalar).

**Outputs:**
- Axis-aligned bounding box (AABB) $[min_x, max_x, min_y, max_y, min_z, max_z]$ enclosing all object points.
- Filtered ray samples for the fine model.

**Data Structures:**
- **Coarse Deformation Feature Grid:** A 3D grid storing deformation features. Vertices are queried to retrieve alpha values.
- **Alpha Value:** A scalar output from the coarse model representing the density/transparency at a grid vertex.

**Steps:**

1.  **Query Alpha Values:** For every vertex $v$ in the coarse deformation feature grid, and for every training time step $t$, query the alpha value $\alpha(v, t)$ [S1].
2.  **Classify Vertices:** A vertex $v$ is classified as an "object point" if its alpha value exceeds the threshold $\tau$ at any time step. Formally, vertex $v$ is an object point if:
    $$
    \exists t \in \{0, \dots, T\} : \alpha(v, t) > \tau
    $$
    Otherwise, it is classified as empty space [S1].
3.  **Compute Bounding Box:** Determine the smallest axis-aligned bounding box that fully encloses all vertices classified as object points across all time steps. Let $V_{obj}$ be the set of object point coordinates. The bounding box limits are:
    $$
    \begin{aligned}
    min_x &= \min_{v \in V_{obj}} v_x, & max_x &= \max_{v \in V_{obj}} v_x \\
    min_y &= \min_{v \in V_{obj}} v_y, & max_y &= \max_{v \in V_{obj}} v_y \\
    min_z &= \min_{v \in V_{obj}} v_z, & max_z &= \max_{v \in V_{obj}} v_z
    \end{aligned}
    $$
    This bounding box serves as the "coarse geometry prior" [S1].
4.  **Filter Ray Samples (Runtime):** During ray marching for the fine model:
    -   **Deformation Module:** For sampled points, if the alpha value is below the threshold $\tau$ for *all* training time steps, the point is considered static empty space and filtered out (not queried to the MLP) [S1].
    -   **Canonical Module:** For sampled points in the canonical module, filter out empty points only at the canonical time $t=0$ (or the specific canonical time used) [S1].
5.  **Initialize Fine Model:** Use the coarse geometry prior to reduce the volume of the grid in the fine stage. The deformation feature grid for the fine model is initialized by interpolating the optimized feature grid from the coarse model, restricted to the bounding box [S1].

**Parameters:**
-   **Alpha Threshold ($\tau$):** A predefined scalar value used to distinguish object points from empty space. Typical values are not explicitly given in the sources, but it must be chosen to avoid filtering low-density regions that are visually significant [S1].

**Edge Cases and Pitfalls:**
-   **Low-Density Regions:** Regions with low density (e.g., a white plate on a white background) may have alpha values close to zero, resulting in low image reconstruction error. These regions may be incorrectly filtered out as empty space, leading to missing geometry in the reconstructed scene [S1]. This can be alleviated by using a background with a different color or disabling the filtering strategy for such scenes [S1].
-   **Static Assumption:** The method assumes empty points are static. If empty space varies significantly over time in a way that affects the bounding box, the static assumption might lead to incorrect filtering [S1].

**Pseudocode:**

```python
def compute_coarse_geometry_prior(coarse_grid, time_steps, alpha_threshold):
    """
    Computes the bounding box of object points from the coarse grid.
    
    Args:
        coarse_grid: 3D grid of vertices.
        time_steps: List of time steps t.
        alpha_threshold: Scalar threshold tau.
        
    Returns:
        bbox: Tuple (min_x, max_x, min_y, max_y, min_z, max_z).
    """
    object_points = []
    
    # Step 1 & 2: Query alpha and classify vertices
    for vertex in coarse_grid.vertices:
        is_object = False
        for t in time_steps:
            # Query alpha value for this vertex at time t
            alpha = query_alpha(coarse_grid, vertex, t)
            if alpha > alpha_threshold:
                is_object = True
                break # No need to check other times for this vertex
        
        if is_object:
            object_points.append(vertex.position)
            
    # Step 3: Compute bounding box
    if not object_points:
        return None # Or handle empty scene case
        
    min_x = min(p.x for p in object_points)
    max_x = max(p.x for p in object_points)
    min_y = min(p.y for p in object_points)
    max_y = max(p.y for p in object_points)
    min_z = min(p.z for p in object_points)
    max_z = max(p.z for p in object_points)
    
    return (min_x, max_x, min_y, max_y, min_z, max_z)

def filter_ray_samples(ray_samples, coarse_grid, time_steps, alpha_threshold, bbox):
    """
    Filters out empty space samples from a ray.
    
    Args:
        ray_samples: List of sampled points along the ray.
        coarse_grid: Coarse deformation feature grid.
        time_steps: List of time steps t.
        alpha_threshold: Scalar threshold tau.
        bbox: Bounding box from compute_coarse_geometry_prior.
        
    Returns:
        filtered_samples: List of samples that are not empty.
    """
    filtered = []
    
    for sample in ray_samples:
        # Check if sample is outside the coarse geometry prior
        if not is_inside_bbox(sample.position, bbox):
            # If outside, it is definitely empty space (based on prior)
            continue
            
        # Step 4: Filter based on alpha values
        # For deformation module: filter if alpha < threshold for ALL times
        # For canonical module: filter if alpha < threshold at canonical time
        # Assuming we are in the deformation module context for this check:
        is_empty = True
        for t in time_steps:
            alpha = query_alpha(coarse_grid, sample.position, t)
            if alpha > alpha_threshold:
                is_empty = False
                break
                
        if not is_empty:
            filtered.append(sample)
            
    return filtered
```

## Operating characteristics
-   **Time Complexity:** Preprocessing is $O(V \cdot T)$ where $V$ is the number of grid vertices and $T$ is the number of time steps. Runtime filtering reduces the number of MLP queries, improving training and rendering speed [S1].
-   **Memory Complexity:** Requires storing the coarse deformation feature grid and the bounding box. The fine model grid volume is reduced, saving memory [S1].
-   **Performance:** Without filtering, training speed, render speed, and PSNR are clearly worse than the full model with filtering [S1]. The method significantly reduces time consumption of training and rendering [S1].
-   **Strengths:** Accelerates training and rendering by reducing MLP queries; simplifies the fine model initialization [S1].
-   **Limitations:** May filter out low-density regions with low reconstruction error (e.g., white on white); relies on the assumption that empty points are static [S1].

## Background
The method was proposed in the context of Neural Deformable Voxel Grid (NDGV) for fast optimization of dynamic view synthesis [S1]. It was introduced to address the computational cost of training dynamic neural radiance fields by leveraging the sparsity of empty space in dynamic scenes [S1]. The approach builds on the idea of using a coarse model to identify relevant regions for the fine model [S1].
