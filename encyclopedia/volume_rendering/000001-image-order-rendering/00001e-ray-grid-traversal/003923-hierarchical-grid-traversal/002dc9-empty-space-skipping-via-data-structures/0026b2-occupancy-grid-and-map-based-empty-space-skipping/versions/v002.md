# Occupancy Grid and Map-Based Empty Space Skipping

Also called: Occupancy Grid Acceleration, Binary Occupancy Skipping

## Overview
This family accelerates volume rendering by using precomputed binary occupancy grids to skip ray marching through empty space, reducing texture memory bandwidth and computational cost [S1]. It differs from [Distance Map Acceleration](972-distance-map-acceleration.md) by using simple binary flags rather than distance fields for skipping, and from [Two-stage Ray Marching with Empty-Space Skipping](2985-two-stage-ray-marching-with-empty-space-skipping.md) by often integrating skipping directly into the traversal loop or hierarchical sampling rather than strictly decoupling entry finding from density sampling in all variants [S1, S2, unofficial].

## Shared principles
The core mechanism relies on a lower-resolution grid (Occupancy Map) where each cell indicates whether its corresponding high-resolution volume block contains non-empty data [S1].
1.  **Occupancy Map Generation**: A block is marked occupied if it contains voxels contributing to the transfer function (e.g., non-zero alpha) or if the isosurface threshold lies within the block's value range (including a halo for boundary safety) [S1].
2.  **Ray Query**: During traversal, the ray's position is mapped to the occupancy grid coordinates. A lookup returns a binary flag [S1].
3.  **Skipping**: If the flag is 0, the ray advances by the block size (or calculated steps to the next block boundary) without sampling the high-resolution volume [S1]. If 1, standard sampling proceeds [S1].
4.  **Coordinate Mapping**: The mapping from volume coordinates $u_{\text{vol}}$ to occupancy coordinates $u_{\text{occ}}$ accounts for block size $B$: $u_{\text{occ}} = u_{\text{vol}} / B$ [S1].

## Subtopics

### [Distance Map Acceleration](972-distance-map-acceleration.md)
Uses a Chebyshev distance map to calculate exact skip distances to the nearest occupied block, offering finer granularity than binary flags.

### [Two-stage Ray Marching with Empty-Space Skipping](2985-two-stage-ray-marching-with-empty-space-skipping.md)
Explicitly separates the "find entry" phase (Stage 1) using the occupancy map from the "sample density" phase (Stage 2), allowing aggressive skipping and precise sampling.

### [Hierarchical Sampling with Occupancy Grid](3035-hierarchical-sampling-with-occupancy-grid.md)
Combines occupancy-based skipping with importance sampling for NeRFs, refining coarse samples with fine samples sorted into a single list.

### [Empty Space Filtering (Training-Time Bounding Box)](6752-empty-space-filtering-training-time-bounding-box.md)
Derives a static bounding box from alpha thresholds across training time steps to filter empty space in dynamic neural rendering.

## Background
Occupancy grids are a standard acceleration structure in volume rendering, originating from the need to optimize ray casting performance [S1]. They are widely used in real-time rendering and neural volume rendering (NeRF) to reduce the number of expensive density/MLP evaluations [S1, S2, unofficial].
