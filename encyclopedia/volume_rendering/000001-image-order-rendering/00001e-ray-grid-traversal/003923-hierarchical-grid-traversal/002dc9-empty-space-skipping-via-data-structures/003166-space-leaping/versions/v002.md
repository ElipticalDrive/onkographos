# Space Leaping

Also called: Fast Traversal, Skip Traversal, Space Leaping using Ray Coherence, Vikon Space Leaping System

## Overview
Space leaping is an acceleration technique for volume rendering that reduces computational cost by skipping empty regions along the ray path [S1, unofficial]. It solves the problem of redundant sampling in large volumes with significant empty space [S2]. Unlike hierarchical methods that traverse complex data structures like octrees, this specific variant exploits ray coherence across neighboring pixels to skip samples using a lightweight buffer [S2]. It is distinct from [Object-Order Empty Space Skipping](865-object-order-empty-space-skipping.md) and [Occupancy Grid and Map-Based Empty Space Skipping](3852-occupancy-grid-and-map-based-empty-space-skipping.md) by relying on image-order coherence rather than pre-computed spatial occupancy maps [S2].

## How it works
This method, specifically the "Light Weight Space Leaping using Ray Coherence" variant implemented in the Vikon system, uses a single buffer to store traversal distances for detector rays and applies those distances to skip samples for neighboring "space leap" rays [S2].

**Inputs and Outputs:**
*   **Input:** Volume dataset, camera parameters (position, direction, sampling distance), image plane size $N \times N$.
*   **Output:** Rendered image with accelerated ray traversal.
*   **Data Structures:**
    *   **Leap Buffer:** A 2D array of size $N \times N$ (image plane size). Each element stores an integer representing the number of samples a detector ray took to reach the first non-empty cell [S2].
    *   **Volume Grid:** Standard 3D voxel grid [S2].

**Algorithm Steps:**

1.  **Initialize Leap Buffer:**
    Create a leap buffer $L$ of size $N \times N$, initialized to zero [S2].

2.  **Cast Detector Rays:**
    For every pixel $(i, j)$ in the image, cast a "detector ray" $R_{det}$ from the camera origin through the pixel center [S2].
    *   March along $R_{det}$ with the standard sampling distance $d$.
    *   Check each sample point against the volume data.
    *   Identify the first sample point $S_{first}$ that lies inside a non-empty (data) cell [S2].
    *   Let $k$ be the number of samples taken to reach $S_{first}$ (i.e., $S_{first}$ is the $k$-th sample along the ray) [S2].
    *   Store $k$ in $L[i][j]$ [S2].
    *   If the ray hits no data within the view frustum, $L[i][j]$ remains 0 or is handled as a background case [S2].

3.  **Cast Space Leap Rays:**
    For every pixel $(i, j)$, cast a "space leap ray" $R_{leap}$ [S2].
    *   Retrieve the leap value $v = L[i][j]$ [S2].
    *   **Boundary Condition Check:** If $v == 0$, do not leap. Proceed with standard ray marching for this pixel [S2].
    *   **Leap Calculation:** Calculate the starting sample index for $R_{leap}$ as $k_{start} = v - 1$ [S2].
        *   Rationale: The leap buffer stores the number of samples to reach the *first* non-empty cell. The sample *before* that (index $v-1$) is the last sample in the empty region [S2].
    *   **Backtracking (Safety):**
        *   Start marching $R_{leap}$ from sample index $k_{start}$ [S2].
        *   Check if the sample at $k_{start}$ is inside an empty cell [S2].
        *   If the sample at $k_{start}$ is inside a *non-empty* cell, backtrack $R_{leap}$ to earlier samples until an empty cell is found [S2].
        *   **Constraint:** Do not backtrack beyond the sample index corresponding to the image plane (i.e., do not go behind the camera). The maximum backtracking depth is limited by the leap buffer value $v$ to prevent invalid geometry [S2].
    *   **Rendering:**
        *   Once the correct starting point in empty space is found (or if $v=0$), proceed with standard front-to-back compositing for the remainder of the ray [S2].

**Formulas:**
*   Leap Buffer Value: $L[i][j] = \min \{ k \mid \text{Sample}_k(R_{det}) \in \text{NonEmpty} \}$ [S2].
*   Leap Start Index: $k_{leap} = L[i][j] - 1$ [S2].

**Parameters:**
*   **Sampling Distance ($d$):** Determines the granularity of the leap. Smaller $d$ increases accuracy but reduces leap efficiency [S2].
*   **Image Plane Size ($N \times N$):** Determines memory usage [S2].

**Edge Cases and Pitfalls:**
*   **Zero Leap Value:** If $L[i][j] = 0$, the ray should not be leaped at all [S2].
*   **Backtracking Limit:** Backtracking must not exceed the leap buffer value $v$ to avoid sampling behind the image plane [S2].
*   **First Hit Only:** Space leaping is only possible between the image plane and the first object hit. Empty space beyond the first hit cannot be leaped using this method [S2].
*   **Accuracy:** The method assumes that neighboring rays have similar first-hit distances. This holds well when the camera is close to the object surface [S2].

## Subtopics

### [Boundary Pixel Detector Ray Casting](5870-boundary-pixel-detector-ray-casting.md)
Boundary Pixel Detector Ray Casting is a safety mechanism within Space Leaping [5870-boundary-pixel-detector-ray-casting.md] that ensures volumetric objects projecting exclusively onto the edges of the image buffer are not erroneously skipped. It distinguishes itself from standard space leaping by treating all image boundary pixels as mandatory "detector pixels," preventing the algorithm from leaping over objects located at the periphery of the view frustum.

### Leap Buffer Boundary Condition Handling
The leap buffer stores the number of samples the detector ray took to reach a non-empty cell. The sample before that is the last sample in an empty cell. If the leap buffer value is zero, the space leap ray should not be leaped at all [S2].

### Original Space-Leaping (Hierarchical)
Original space-leaping efficiently traverses or skips empty space using a hierarchical spatial data structure (e.g., octree) or a flat pyramid [S1, unofficial]. In a flat pyramid, uniform information of the octree is stored in the empty space of the 3D volume grid. When a ray encounters a voxel with uniformity information, it jumps to the first voxel outside this uniform region [S1, unofficial].

### Bounding Box Space-Leaping
For volumes with few objects, bounding boxes or convex polyhedra can be used for space-leaping. The PARC (Polygon assisted ray casting) method allows building a convex polyhedron around the object to skip empty space outside it [S1, unofficial].

### Adaptive Ray Traversal
This approach assigns empty voxels neighboring a data voxel a "vicinity flag." The empty space is traversed rapidly using a low-precision algorithm. When a vicinity voxel is encountered, the algorithm switches to a more accurate traversal method [S1, unofficial].

### Proximity Clouds
In a pre-processing step, the distance to the nearest data voxel is computed for each empty voxel. When a ray encounters a proximity voxel with value $n$, it skips the next $n$ voxels, as there are no data voxels in between [S1, unofficial].

### Homogeneity-Acceleration
Homogeneous regions are approximated with fewer sample points. Mean values and variance are stored in the octree to allow for coarser sampling in uniform areas [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N^2)$ for filling the leap buffer, where $N \times N$ is the image plane size. The buffer is scanned once [S2].
*   **Memory Complexity:** $O(N^2)$, requiring one buffer of size $N \times N$ (e.g., 256x256 bytes for a 256x256 image) [S2].
*   **Performance:** Achieved speedups of up to 165% over non-space leap ray casting on a Pentium-IV, 2.6GHz PC with 1GB RAM and Linux OS [S2].
*   **Strengths:** Low memory overhead; suitable for systems with limited resources (e.g., virtual endoscopy) [S2].
*   **Limitations:** Cannot achieve as much empty space skipping as techniques using data structures for empty/non-empty voxel info because it only leaps one out of every 4 rays, getting 75% of possible acceleration [S2]. Space leaping is only possible between the image plane and the first object hit [S2].
*   **When to Use:** Ideal for virtual endoscopy and applications requiring camera placement close to the object surface, as well as high-resolution volume rendering with orthographic and perspective projections [S2].
*   **When Not to Use:** When the camera is far from the object or when maximum empty space skipping is required regardless of memory cost [S2].

## Background
Space leaping was introduced as a method for fast traversal of regions with homogeneous structure [S1, unofficial]. The "Light Weight Space Leaping using Ray Coherence" variant was incorporated into the Vikon system for perspective direct volume rendering, specifically for endoscopy applications like Virtual Colonoscopy [S2]. The system allows users to navigate inside 3D datasets, where interactive rendering is essential [S2].
