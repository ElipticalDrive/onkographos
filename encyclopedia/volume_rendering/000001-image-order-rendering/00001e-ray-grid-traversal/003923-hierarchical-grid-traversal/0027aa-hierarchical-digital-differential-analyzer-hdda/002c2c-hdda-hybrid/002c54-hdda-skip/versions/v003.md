# HDDA Skip

Also called: Hierarchical DDA (HDDA) Skip

## Overview
HDDA Skip is a ray traversal algorithm for sparse voxel grids (such as VDB) that uses Hierarchical DDA to skip empty regions in bulk steps, advancing ray time $t$ rather than sampling every voxel [S1, unofficial]. It builds on [HDDA Hybrid](5201-hdda-hybrid.md), which combines HDDA for empty tiles and DDA for occupied tiles; HDDA Skip extends this by allowing density-based skipping of invisible space within occupied regions using optional $\sigma$ or $\alpha$ functions [S1, unofficial].

## How it works
**Inputs:** Ray origins $\mathbf{o}$, normalized directions $\mathbf{d}$, grid bounds $[t_0, t_1]$, optional density/opacity functions $\sigma(\cdot)$ or $\alpha(\cdot)$, step size $s$, cone angle $\theta$, and grid accessors for voxel activity and dimension [S1, unofficial].
**Outputs:** Sampled points $(t_{left}, t_{right})$, ray indices, and traversal counts [S1, unofficial].

**Data Structures:**
- `HDDAState`: Stores current voxel index $\mathbf{ijk}$, dimension $dim$, current time $t$, and validity flag [S1, unofficial].
- `Ray`: Origin $\mathbf{o}$, direction $\mathbf{d}$, bounds $t_{min}, t_{max}$ [S1, unofficial].

**Pseudocode:**
```python
def hdda_skip_traverse(ray, acc, first_pass=True):
    # 1. Initialize bounds
    t0 = ray.t0() + 1e-6
    t1 = ray.t1() - 1e-6
    if not ray.clip(acc.root().bbox()) or t0 > t1:
        return  # Skip to next grid

    # 2. Initialize HDDA state
    ijk = floor(ray(t0))  # nanovdb::RoundDown
    dim = acc.getDim(ijk, ray)
    hdda.init(ray, t0, t1, dim)
    ddaIsValid = True
    tlast = t0
    n_trav = 0

    # 3. Outer loop
    while ddaIsValid:
        # Inner skip loop
        while ddaIsValid and not acc.isActive(ijk):
            ddaIsValid = hdda.step()
            if not ddaIsValid:
                break
            ijk = hdda.voxel()
            dim = acc.getDim(ijk, ray)
            hdda.update(ray, dim)

        # 4. Advance to occupied region
        if not ddaIsValid:
            break
        # advance_time advances tlast to the start of the occupied region
        tlast = hdda.time()  # advance_time logic not given in sources [G]

        # 5. Traverse occupied region
        # _calc_dt calculates step size based on cone angle and step size
        dt = min(ray.step_size, 1e10)  # _calc_dt logic not given in sources [G]
        while tlast + dt / 2 < hdda.next():
            if not first_pass:
                record_sample(ray_indices, tlast, tlast + dt)
            n_trav += 1
            tlast += dt
            dt = min(ray.step_size, 1e10)

        # 6. Step HDDA for next iteration
        ddaIsValid = hdda.step()
        ijk = hdda.voxel()
        dim = acc.getDim(ijk, ray)
        hdda.update(ray, dim)
```

**Formulas:**
- $t_0 = \text{ray.t0()} + 10^{-6}$ [S1, unofficial]
- $t_1 = \text{ray.t1()} - 10^{-6}$ [S1, unofficial]
- $\mathbf{ijk} = \lfloor \mathbf{o} + t_0 \mathbf{d} \rfloor$ [S1, unofficial]
- $dt = \text{_calc\_dt}(t_{last}, \theta, s, 10^{10})$ [S1, unofficial]

**Parameters:**
- `render_step_size`: Default $10^{-3}$ [S1, unofficial].
- `cone_angle`: Default $0.0$ [S1, unofficial].
- `early_stop_eps`: Default $10^{-4}$ [S1, unofficial].
- `alpha_thre`: Default $0.0$ [S1, unofficial].

**Edge Cases:**
- Ray bounds invalid ($t_0 > t_1$): Skip grid [S1, unofficial].
- Empty grid: HDDA becomes invalid immediately [S1, unofficial].
- Precision: Use $\epsilon = 10^{-6}$ to avoid boundary issues [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Strengths:** Efficiently skips large empty regions using HDDA; supports density-based early termination via $\sigma$ or $\alpha$ functions [S1, unofficial].
- **Limitations:** Requires active voxel checks and may incur overhead from density evaluation [S1, unofficial].
- **When to Use:** Sparse grids with large empty regions where density-based skipping is beneficial [S1, unofficial].
- **When Not to Use:** Dense grids where HDDA overhead outweighs benefits, or when no density function is available and simple DDA is sufficient [G].

## Background
Originated in the `faster-occgrid` project by Yosshi999, HDDA Skip is an unofficial implementation leveraging Hierarchical DDA for efficient traversal of sparse voxel grids [S1, unofficial]. It extends the HDDA Hybrid approach by integrating density-based skipping capabilities [S1, unofficial].
