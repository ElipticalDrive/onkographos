# Macrocell Grid Traversal

Also called: Downscaled Grid Traversal

## Overview
Macrocell Grid Traversal is a hierarchical acceleration technique for ray-grid traversal that superimposes a coarse grid over a fine uniform grid to skip empty regions efficiently [S1, S2]. It differs from [Two-Level Grids for Ray Tracing on GPUs](4245-two-level-grids-for-ray-tracing-on-gpus.md) by using a simple boolean occupancy flag per macrocell rather than storing detailed boundary or density information, making it a lightweight optimization best suited for scalar volume fields with uniform density [S1, S2].

## How it works
**Inputs:**
- Fine grid dimensions: $N_x \times N_y \times N_z$ cells.
- Fine grid occupancy data: Boolean or density values for each cell.
- Ray parameters: Origin $\mathbf{o}$, direction $\mathbf{d}$, and entry/exit distances $t_{min}, t_{max}$.
- Downsampling factor: $M$ (integer, typically 6) [S1, S2].

**Outputs:**
- Traversal state indicating which fine grid cells are occupied along the ray.
- Skipped regions to optimize computation.

**Data Structures:**
1. **Fine Grid:** Standard uniform grid structure.
2. **Macrocell Grid:** A 3D array of size $\lceil N_x/M \rceil \times \lceil N_y/M \rceil \times \lceil N_z/M \rceil$.
   - Each element is a single boolean flag (1 bit or byte).
   - Value is `true` if any cell in the corresponding $M \times M \times M$ block of the fine grid is occupied; `false` otherwise.

**Algorithm Steps:**

1. **Build Macrocell Grid:**
   Iterate over all macrocells $(i, j, k)$. For each macrocell, check all $M^3$ underlying fine grid cells. If any fine cell is occupied, set `macrocell[i][j][k] = true`; else `false` [S1, S2].

2. **Frustum Setup (Coarse):**
   Compute the traversal parameters for the macrocell grid. Since the macrocell grid is an $M \times M \times M$ downscaled version of the fine grid, the step sizes and entry/exit distances can be derived from the fine grid setup by dividing by $M$ [S1, S2].
   - Let $t_{min}^{macro}, t_{max}^{macro}$ be the entry and exit distances in macrocell space.
   - Let $\Delta x^{macro}, \Delta y^{macro}, \Delta z^{macro}$ be the step sizes in macrocell space.
   - These can be computed as:
     $$ \Delta x^{macro} = \frac{\Delta x^{fine}}{M}, \quad t_{min}^{macro} = \frac{t_{min}^{fine}}{M}, \quad \text{etc.} $$
   - Alternatively, re-use the fine grid frustum setup values and divide by $M$ [S1, S2].

3. **Macrocell Traversal:**
   Traverse the macrocell grid along the ray using standard grid traversal logic. Determine the sequence of macrocells overlapped by the ray. In practice, usually only one macrocell per slice is overlapped [S1, S2].

4. **Skip or Traverse Fine Grid:**
   For each macrocell $(i, j, k)$ visited:
   - If `macrocell[i][j][k]` is `false` (empty):
     - Skip $M$ traversal steps on the original fine grid. This means advancing the fine grid traversal state by $M$ units in the corresponding direction without processing the intermediate cells [S1, S2].
   - If `macrocell[i][j][k]` is `true` (occupied):
     - Perform standard fine grid traversal steps for the cells within this macrocell block [S1, S2].

**Pseudocode:**

```python
def build_macrocell_grid(fine_grid, M):
    """
    Builds the macrocell grid from the fine grid.
    fine_grid: 3D array of booleans, shape (Nx, Ny, Nz)
    M: downsampling factor
    Returns: 3D array of booleans, shape (ceil(Nx/M), ceil(Ny/M), ceil(Nz/M))
    """
    Nx, Ny, Nz = fine_grid.shape
    Mx = (Nx + M - 1) // M
    My = (Ny + M - 1) // M
    Mz = (Nz + M - 1) // M
    macrocell_grid = [[False] * Mz for _ in range(My)]
    for _ in range(Mx):
        macrocell_grid.append([[False] * Mz for _ in range(My)])

    for i in range(Mx):
        for j in range(My):
            for k in range(Mz):
                occupied = False
                # Check all MxMxM cells in the block
                for di in range(M):
                    for dj in range(M):
                        for dk in range(M):
                            fi = i * M + di
                            fj = j * M + dj
                            fk = k * M + dk
                            if fi < Nx and fj < Ny and fk < Nz:
                                if fine_grid[fi][fj][fk]:
                                    occupied = True
                                    break
                        if occupied: break
                    if occupied: break
                macrocell_grid[i][j][k] = occupied
    return macrocell_grid

def traverse_macrocell_grid(ray_origin, ray_direction, fine_grid, M, t_min, t_max):
    """
    Traverses the fine grid using macrocell acceleration.
    ray_origin: (ox, oy, oz)
    ray_direction: (dx, dy, dz)
    fine_grid: 3D array of booleans
    M: downsampling factor
    t_min, t_max: entry and exit distances
    Returns: List of occupied fine grid cells visited
    """
    Nx, Ny, Nz = fine_grid.shape
    macrocell_grid = build_macrocell_grid(fine_grid, M)
    Mx = (Nx + M - 1) // M
    My = (Ny + M - 1) // M
    Mz = (Nz + M - 1) // M

    # Compute fine grid traversal parameters
    # Assuming axis-aligned grid with unit spacing for simplicity
    # In practice, these depend on grid spacing and ray direction
    if dx == 0:
        t_max_x = float('inf')
        step_x = 0
        t_min_x = float('inf')
    else:
        step_x = 1.0 / abs(dx)
        t_min_x = (0 if dx > 0 else -1 - ox) * step_x # Simplified entry calculation
        t_max_x = (Nx if dx > 0 else -1 - ox) * step_x # Simplified exit calculation

    if dy == 0:
        t_max_y = float('inf')
        step_y = 0
        t_min_y = float('inf')
    else:
        step_y = 1.0 / abs(dy)
        t_min_y = (0 if dy > 0 else -1 - oy) * step_y
        t_max_y = (Ny if dy > 0 else -1 - oy) * step_y

    if dz == 0:
        t_max_z = float('inf')
        step_z = 0
        t_min_z = float('inf')
    else:
        step_z = 1.0 / abs(dz)
        t_min_z = (0 if dz > 0 else -1 - oz) * step_z
        t_max_z = (Nz if dz > 0 else -1 - oz) * step_z

    # Initialize fine grid traversal state
    # Current cell indices
    cx = int(ox) if dx > 0 else int(ox) - 1
    cy = int(oy) if dy > 0 else int(oy) - 1
    cz = int(oz) if dz > 0 else int(oz) - 1

    # Clamp to grid bounds
    cx = max(0, min(cx, Nx - 1))
    cy = max(0, min(cy, Ny - 1))
    cz = max(0, min(cz, Nz - 1))

    # Compute initial t values for crossing grid boundaries
    # This is a simplified version; actual implementation requires precise boundary calculations
    t_x = t_min_x if dx > 0 else t_max_x
    t_y = t_min_y if dy > 0 else t_max_y
    t_z = t_min_z if dz > 0 else t_max_z

    # Determine direction of traversal
    step_dir_x = 1 if dx > 0 else -1
    step_dir_y = 1 if dy > 0 else -1
    step_dir_z = 1 if dz > 0 else -1

    visited_cells = []

    # Macrocell traversal parameters
    # Macrocell grid is M times coarser
    step_x_macro = step_x / M
    step_y_macro = step_y / M
    step_z_macro = step_z / M

    # Initial macrocell indices
    cmx = cx // M
    cmy = cy // M
    cmz = cz // M

    # Initial t values for macrocell traversal
    # These should be aligned with macrocell boundaries
    # Simplified: use fine grid t values divided by M
    t_x_macro = t_x / M
    t_y_macro = t_y / M
    t_z_macro = t_z / M

    # Clamp macrocell t values to [t_min, t_max]
    t_x_macro = max(t_x_macro, t_min)
    t_y_macro = max(t_y_macro, t_min)
    t_z_macro = max(t_z_macro, t_min)

    t_max_macro = min(t_max_x / M, t_max_y / M, t_max_z / M) if dx != 0 and dy != 0 and dz != 0 else float('inf')

    # Traverse macrocells
    while t_x_macro <= t_max_macro and t_y_macro <= t_max_macro and t_z_macro <= t_max_macro:
        # Check if current macrocell is occupied
        if cmx < Mx and cmy < My and cmz < Mz:
            if macrocell_grid[cmx][cmy][cmz]:
                # Macrocell is occupied, traverse fine grid cells within this macrocell
                # Determine the range of fine cells in this macrocell
                start_x = cmx * M
                start_y = cmy * M
                start_z = cmz * M
                end_x = min(start_x + M, Nx)
                end_y = min(start_y + M, Ny)
                end_z = min(start_z + M, Nz)

                # Traverse fine grid cells in this block
                # This is a simplified traversal; in practice, use the standard ray-grid traversal
                # for the specific block
                for fx in range(start_x, end_x):
                    for fy in range(start_y, end_y):
                        for fz in range(start_z, end_z):
                            if fine_grid[fx][fy][fz]:
                                visited_cells.append((fx, fy, fz))
            else:
                # Macrocell is empty, skip M steps
                # Advance fine grid traversal state by M steps
                # This is a simplification; in practice, advance the t values by M * step
                t_x_macro += M * step_x_macro
                t_y_macro += M * step_y_macro
                t_z_macro += M * step_z_macro

                # Update macrocell indices
                cmx += step_dir_x
                cmy += step_dir_y
                cmz += step_dir_z
        else:
            # Out of bounds, advance
            t_x_macro += M * step_x_macro
            t_y_macro += M * step_y_macro
            t_z_macro += M * step_z_macro
            cmx += step_dir_x
            cmy += step_dir_y
            cmz += step_dir_z

    return visited_cells
```

**Parameters:**
- $M$: The downsampling factor (block size). Typical value is 6 [S1, S2].
  - Smaller $M$ yields insufficient savings [S1, S2].
  - Larger $M$ reduces the probability of finding empty regions [S1, S2].

**Edge Cases and Pitfalls:**
- For smaller resolutions, the savings for each macrocell step become too small to justify the additional computations [S1, S2].
- For larger resolutions, the probability of finding empty regions decreases, reducing the benefit of skipping [S1, S2].
- The build time for the macrocell grid is trivial and cheap [S1, S2].

## Operating characteristics
- **Time Complexity:** Build time is $O(N_x N_y N_z)$, but trivial and cheap [S1, S2]. Traversal time is reduced by skipping empty regions.
- **Memory Complexity:** Additional memory for the macrocell grid is $O(\frac{N_x N_y N_z}{M^3})$, which is negligible compared to the fine grid [S1, S2].
- **Performance:** Yields a performance improvement of around 30% compared to single ray grids, consistent with improvements seen for single ray grids [S1, S2].
- **Strengths:** Simple to implement, cheap to build, effective for scalar volume fields with uniform density [S1, S2].
- **Limitations:** Less effective for scenes with varying geometric density or very small/large resolutions [S1, S2]. Additional levels of macrocells could further improve performance for more complex models with larger grids, but were not investigated in the source [S1, S2].

## Background
Macrocells were introduced as a simple hierarchical optimization to a base uniform grid, often used to apply grids to scalar volume fields [S1, S2]. The technique was described by Parker et al. in 1999 [S1, S2]. It is particularly useful for medium-size animated scenes where the acceleration structure is rebuilt every frame [S1, S2].
