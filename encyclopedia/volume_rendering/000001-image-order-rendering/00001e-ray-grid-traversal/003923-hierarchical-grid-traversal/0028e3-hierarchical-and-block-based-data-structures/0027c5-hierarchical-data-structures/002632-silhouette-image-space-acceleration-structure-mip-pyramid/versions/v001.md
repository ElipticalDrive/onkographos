# Silhouette Image Space Acceleration Structure (Mip Pyramid)

Also called: Hierarchical Voxelization Acceleration Structure

## Overview
This method accelerates voxelization and culling queries by constructing a mip pyramid over silhouette images, inspired by the hierarchical z-buffer [S1]. It solves the problem of efficiently determining conservative bounds on silhouette coverage for arbitrary voxels in screen space. It differs from its siblings by operating directly on the image-space silhouette data rather than spatial voxel grids, allowing for fast, conservative culling decisions based on projected voxel extents [S1].

## How it works
**Inputs:**
- A set of $n$ silhouette images, one per camera view, containing signed-distance-like values or binary occupancy indicators.
- A voxel $v$ defined by its 8 corners in Normalized Device Coordinates (NDC).

**Outputs:**
- A conservative lower and upper bound on the silhouette value $\mathcal{S}(\mathbf{p})$ for all points $\mathbf{p}$ within voxel $v$.

**Data Structures:**
- **Mip Pyramid:** For each of the $n$ silhouette images, a hierarchy of texture levels is constructed.
  - Level 0: The original smoothed silhouette image.
  - Level $k$: A texture where each texel stores two values: the minimum and maximum of the four corresponding texels from Level $k-1$.
  - The pyramid depth is determined by the image resolution.

**Steps:**
1. **Pyramid Construction:** Immediately after silhouette image smoothing, generate $n$ image pyramids using a GPU compute kernel [S1]. Each level $k > 0$ is computed from level $k-1$ by grouping texels into $2 \times 2$ blocks and storing the min and max values of those blocks.
2. **Voxel Projection:** For a given voxel $v$, project its 8 NDC corners into the silhouette image space of camera $i$.
3. **Bounding Rectangle:** Compute the axis-aligned bounding rectangle (AABB) of the projected corners in screen space: $(\text{minX}, \text{minY}, \text{maxX}, \text{maxY})$.
4. **Level Selection:** Determine the sampling level $L$ in the mip pyramid using the formula:
   $$ L = \lfloor \log_2(\max(\text{maxX} - \text{minX}, \text{maxY} - \text{minY})) \rfloor $$
   At this level $L$, the bounding rectangle covers at most a $2 \times 2$ block of texels [S1].
5. **Sampling:** Sample the texels at the corners of the bounding rectangle from the pyramid level $L$.
6. **Bound Calculation:** Return the minimum and maximum of these sampled values as the conservative bound on the silhouette value $\mathcal{I}_i(\mathcal{C}_i(\mathbf{p}))$ for all $\mathbf{p}$ within the voxel [S1].
7. **Aggregation:** To get the bound on the final silhouette function $\mathcal{S}(\mathbf{p})$, take the product of the minimums (and similarly maximums) over all $n$ images [S1].

**Pseudocode:**
```python
def sample_silhouette_bound(voxel_corners, pyramid_levels, camera_index):
    """
    voxel_corners: list of 8 (x, y) tuples in screen space
    pyramid_levels: list of 2D arrays, where each array is a level of the mip pyramid
                   storing (min_val, max_val) per texel
    camera_index: index of the silhouette image
    """
    # 1. Project corners to screen space (assumed done before call)
    # 2. Find AABB
    min_x = min(c[0] for c in voxel_corners)
    min_y = min(c[1] for c in voxel_corners)
    max_x = max(c[0] for c in voxel_corners)
    max_y = max(c[1] for c in voxel_corners)
    
    # 3. Determine level
    width = max_x - min_x
    height = max_y - min_y
    level = floor(log2(max(width, height)))
    
    # 4. Sample corners at the determined level
    # Note: Coordinates must be clamped to valid texel range for the level
    texels = [
        pyramid_levels[level][clamp(min_y), clamp(min_x)],
        pyramid_levels[level][clamp(min_y), clamp(max_x)],
        pyramid_levels[level][clamp(max_y), clamp(min_x)],
        pyramid_levels[level][clamp(max_y), clamp(max_x)]
    ]
    
    # 5. Return conservative bounds
    min_val = min(t[0] for t in texels)
    max_val = max(t[1] for t in texels)
    
    return min_val, max_val
```

**Parameters:**
- **Pyramid Depth:** Determined by image resolution. Not given in the sources.
- **Smoothing:** The silhouette images must be smoothed prior to pyramid construction. The specific smoothing kernel is defined in [Silhouette Image Acquisition and Filtering](3754-silhouette-image-acquisition-and-filtering.md).

**Edge Cases and Pitfalls:**
- **Conservative Bounds:** The min/max aggregation ensures that no small features are missed and no holes are created in voxelization, as the bounds are conservatively correct [S1].
- **Precision:** Floating-point precision in projection and log2 calculation may affect level selection. Not given in the sources.
- **Boundary Conditions:** Texel sampling must handle cases where the bounding rectangle extends beyond the image boundaries. Not given in the sources.

## Operating characteristics
- **Time Complexity:** Pyramid construction is $O(N)$ where $N$ is the number of texels in the base image. Query time is $O(1)$ per camera view, involving projection, AABB calculation, log2, and 4 texture samples.
- **Memory Complexity:** $O(N \log R)$ where $R$ is the resolution, due to storing min/max pairs at each pyramid level.
- **Performance:** Greatly reduces computation and data accesses needed by the oracle kernel for culling decisions [S1].
- **Strengths:** Conservative bounds prevent missing small features or creating holes. Fast culling in image space.
- **Limitations:** Requires pre-computed silhouette images. Performance depends on the number of camera views $n$.
- **When to Use:** When voxelizing from multi-view silhouette data and fast conservative culling is needed.
- **When Not to Use:** When silhouette data is not available or when spatial locality in voxel space is more critical than image-space coverage.

## Background
The method was introduced in "Real-time high-resolution sparse voxelization with application to image-based modeling" [S1]. It is inspired by the hierarchical z-buffer [Greene et al. 1993]. The structure is used to accelerate the voxelization process in image-based modeling by providing fast, conservative bounds on silhouette coverage.
