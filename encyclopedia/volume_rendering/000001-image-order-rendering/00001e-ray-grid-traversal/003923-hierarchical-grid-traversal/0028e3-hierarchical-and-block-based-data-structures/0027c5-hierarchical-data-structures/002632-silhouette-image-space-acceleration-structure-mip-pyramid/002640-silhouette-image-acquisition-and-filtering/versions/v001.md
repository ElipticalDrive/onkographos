# Silhouette Image Acquisition and Filtering
Also called: Chroma-key silhouette generation, Gaussian-filtered silhouette maps

## Overview
This method generates calibrated, smooth silhouette images from raw camera data to define a visual hull surface $S(\mathbf{p}) = 0.5$ for volume rendering acceleration. It solves the problem of converting uncalibrated, raw sensor data into a consistent signed-distance-like field suitable for conservative voxel culling. It differs from standard binary silhouette extraction by integrating lens distortion correction, demosaicing, and Gaussian smoothing into a single GPU compute pass, ensuring the resulting gradient $\nabla S(\mathbf{p})$ provides a smooth normal field [S1].

## How it works
**Inputs:** Raw Bayer pattern image data from $n$ cameras; camera intrinsic parameters (for distortion correction); Gaussian kernel width $\sigma$.
**Outputs:** $n$ filtered silhouette images (2D textures) where foreground pixels have value $0$ and background pixels have value $1$.

**Data Structures:**
*   **Input Texture Array:** 2D texture array storing raw 8-bit Bayer data.
*   **Output Texture Array:** 2D texture array storing filtered silhouette values (float).
*   **Shared Memory:** Used to store entire image rows or columns during separable filtering.

**Steps:**
1.  **Upload:** Transfer raw Bayer pattern data to GPU memory as a 2D texture array [S1].
2.  **Compute Kernel Launch:** Launch a single compute kernel where each thread processes a pixel or tile. The kernel performs three simultaneous operations:
    a.  **Distortion Correction:** Apply inverse radial lens distortion to map pixel coordinates to undistorted space [S1].
    b.  **Demosaicing:** Interpolate the Bayer pattern to produce full-color or luminance values [S1].
    c.  **Chroma Keying:** Classify pixels as foreground or background. Assign value $0$ to foreground and $1$ to background [S1].
3.  **Filtering:** Apply a separable Gaussian filter to the binary silhouette images.
    a.  **Horizontal Pass:** Process rows. Load an image row into shared memory. Convolve with the horizontal Gaussian kernel.
    b.  **Vertical Pass:** Process columns. Load an image column into shared memory. Convolve with the vertical Gaussian kernel.
    The Gaussian kernel has a unit integral. The width of the kernel controls the smoothness of the resulting surface $S(\mathbf{p})$ [S1].

**Formulas:**
The silhouette function $S(\mathbf{p})$ is defined such that the surface is located where:
$$ S(\mathbf{p}) = \frac{1}{2} $$
The gradient $\nabla S(\mathbf{p})$ is normal to the surface $S(\mathbf{p}) = 0.5$. If the silhouette images are smooth, $\nabla S(\mathbf{p})$ provides a smooth normal field [S1].

**Pseudocode:**
```python
# Pseudocode for the single compute kernel processing a pixel (x, y)
# Note: Separable filtering is implemented via two passes or a combined shared-memory strategy.
# This pseudocode outlines the logical steps per pixel.

def process_pixel(x, y, camera_id, raw_bayer_data, camera_intrinsics, kernel_width):
    # 1. Get raw Bayer value
    raw_val = raw_bayer_data[camera_id][x][y]
    
    # 2. Undistort coordinates
    # Map (x, y) from image plane to normalized plane, apply inverse radial distortion, map back
    u, v = undistort(x, y, camera_intrinsics)
    
    # 3. Demosaic
    # Interpolate neighboring Bayer values to get full intensity I(u, v)
    intensity = demosaic(raw_bayer_data, u, v, camera_intrinsics)
    
    # 4. Chroma Key / Threshold
    # Simple thresholding for silhouette generation
    if is_foreground(intensity):
        silhouette_val = 0.0
    else:
        silhouette_val = 1.0
        
    return silhouette_val

def apply_gaussian_filter(silhouette_images, kernel_width):
    # Horizontal pass
    for row in silhouette_images:
        # Load row into shared memory
        shared_mem = load_row_into_shared_memory(row)
        # Convolve with horizontal Gaussian kernel
        filtered_row = convolve_1d(shared_mem, get_gaussian_kernel(kernel_width, horizontal=True))
        
    # Vertical pass
    for col in silhouette_images:
        # Load column into shared memory
        shared_mem = load_column_into_shared_memory(col)
        # Convolve with vertical Gaussian kernel
        filtered_col = convolve_1d(shared_mem, get_gaussian_kernel(kernel_width, vertical=True))
        
    return filtered_col
```

**Parameters:**
*   **Kernel Width ($\sigma$):** Controls blur. Larger values increase surface smoothness [S1]. Typical values are not specified in the sources.

**Edge Cases:**
*   **Precision:** Raw Bayer data is 8-bit, reducing bandwidth but potentially limiting dynamic range before demosaicing [S1].
*   **Boundaries:** Shared memory strategy requires handling image boundaries carefully during row/column loading [S1].

## Subtopics

### Slab Silhouette Maps with Early Depth Test
A technique that exploits slab silhouette maps and an early depth test to skip empty spaces along the direction normal to the texture slice [S2]. It is used to accelerate volume rendering by avoiding computation in transparent regions. It is chosen when efficient empty space skipping is required along specific axes [S2].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of pixels and cameras, as each pixel is processed in a single pass per camera [S1].
*   **Memory Complexity:** Proportional to the number of cameras and image resolution, storing raw Bayer data and filtered silhouette textures [S1].
*   **Performance:** The use of a single compute kernel and shared memory for separable filtering maximizes GPU performance [S1].
*   **Strengths:** Reduces CPU/GPU bandwidth by uploading raw Bayer data; produces smooth normals for better culling [S1].
*   **Limitations:** Requires accurate camera calibration for distortion correction; smoothing may reduce precision of the visual hull boundary [S1].

## Background
This method is part of real-time high-resolution sparse voxelization for image-based modeling [S1]. It builds on the concept of visual hulls, where the surface is defined as the intersection of silhouettes from multiple views [S1]. The approach was developed to enable efficient voxel culling using a Visual Hull Oracle Kernel, which relies on the smoothness of the silhouette gradient [S1].
