# Compact Voxel Octree Raycasting

Also called: Compact Octree Traversal, SVO Workbench Raycasting, Sparse Ray-Octree Intersection

## Overview
Compact Voxel Octree Raycasting is a CPU-based ray traversal algorithm for Sparse Voxel Octrees that optimizes memory layout and traversal logic by compacting active ray-voxel interactions and decoding node masks on-the-fly [S2, unofficial]. It solves the problem of inefficient traversal in sparse structures by using an explicit stack to manage non-sequential memory layouts and a parallel "COMPACTIFY" step to filter out non-intersecting rays, ensuring that only valid ray-voxel pairs are processed in subsequent levels [S1][S2, unofficial]. Unlike recursive or parametric approaches, it relies on a linear block structure with explicit state management, making it suitable for high-performance CPU implementations where memory bandwidth and cache locality are critical [S2, unofficial]. It builds on [CPU Sparse Voxel Octree Traversal](2455-cpu-sparse-voxel-octree-traversal.md) and differs from [Parametric Octree Traversal](2361-parametric-octree-traversal.md), [Iterative Octree Traversal](2618-iterative-octree-traversal.md), [Recursive Octree Traversal](2632-recursive-voxel-octree-traversal.md), and [Sparse Voxel Octree Path Tracing](2988-sparse-voxel-octree-path-tracing.md) by explicitly managing traversal state and compacting active ray lists between levels.

## How it works
**Inputs and Outputs:** The method takes a ray $r=(o,d)$, a Sparse Voxel Octree $ot$, a framebuffer $fb$, screen coordinates $(cur\_x, cur\_y)$, and a parameter $terminLevel$ as input [S2, unofficial]. It outputs a boolean indicating if a leaf was hit and draws a rendered pixel value to $fb$ at $(cur\_x, cur\_y)$ [S2, unofficial].

**Data Structures:** The core node structure is `CNode`, packed to exactly 8 bytes as a union of two layouts [S2, unofficial]. The standard layout contains `valid_mask` (UInt8, bit $i=1$ means child $i$ exists), `leaf_mask` (UInt8, bit $i=1$ means child $i$ is a leaf), and `child_ptr` (UInt16, relative offset or far-pointer indicator) [S2, unofficial]. The far pointer layout replaces the standard fields with `far_ptr` (UInt32) when `child_ptr` indicates a far pointer [S2, unofficial]. The traversal stack stores `stack_item_t` entries containing entry t-values (`tx0, ty0, tz0`), exit t-values (`tx1, ty1, tz1`), the absolute node address (`node_adr`), and the current child index (`idx`) [S2, unofficial].

**Numbered Steps and Formulas:** 
1. Normalize the ray: add epsilon $10^{-10}$ to zero direction components to prevent division by zero, and flip negative directions by negating origin and direction while setting `dir_mask` bits (x=4, y=2, z=1) [S2, unofficial].
2. Initialize traversal: set $t\_start = \min(tx1, ty1, tz1)$, $level=0$, $si=0$, $sl=0$, $is\_first\_node=True$, $node\_adr=ot.root\_adr$, $idx=0$, $exit\_node=False$, and $stack\_underflow=False$ [S2, unofficial].
3. Loop while the stack is not empty or $is\_first\_node$ is true [S2, unofficial].
4. If $is\_first\_node$, decode node masks, compute $t\_enter = \max(tx0, \max(ty0, tz0))$, determine the first child index $i$ using $t$-deltas $(txm, tym, tzm)$, and set $is\_first\_node=False$ [S2, unofficial].
5. Otherwise, determine the next child index $i$ using exit bounds $(tx1, ty1, tz1)$ [S2, unofficial].
6. Correct the child index for ray direction flips: $idx\_flip = i \oplus dir\_mask$ [S2, unofficial].
7. Handle exit: if $exit\_node$ is true, check if $level==0$ (ray exited octree, return false); if $stack\_underflow$, reset $t\_start$ to $t\_exit$ and restart initialization; otherwise pop the stack, decrement $level$, $si$, $sl$, restore bounds and state, and decode masks [S2, unofficial].
8. Check for leaf hit: if $c\_leaf[idx\_flip]$ is true OR $level == terminLevel$, call $procLeaf(r, t\_start, size)$ and return true [S2, unofficial].
9. Check for valid child: if $c\_valid[idx\_flip]$ is true, push current state to stack (assert $si < STACK\_SIZE$), increment $si$ and $sl$ if $sl < stack\_level\_max$, increment $level$, set $is\_first\_node=True$, update bounds to child, get child `BlockEntry` using $ot.getRelativeEntry(node\_adr, n.child\_ptr)$, update $node\_adr = child\_bep.adr + c\_offset[idx\_flip]$, and decode new masks [S2, unofficial].
10. COMPACTIFY: after processing a level, run a parallel reduction to remove non-intersecting rays from list $N(l)$ to $N(l+1)$ using an exclusive sum of hit flags $D_t$ and indices $S_t$ [S1].

**Parameters:** $terminLevel$ (integer, default 10) defines the maximum octree depth where traversal stops regardless of mask status [S2, unofficial]. $STACK\_SIZE$ (integer) limits the traversal stack and is asserted against $si$ before push [S2, unofficial]. $stack\_level\_max$ (integer) limits stack depth growth, only allowing $sl$ to increment when $sl < stack\_level\_max$ [S2, unofficial]. $tnum\_scale = 2^{16}$ defines the fixed-point scaling for t-values [S2, unofficial].

**Pseudocode:**
```python
def child_decode(valid_mask, leaf_mask):
    c_leaf = [False]*8
    c_valid = [False]*8
    c_offset = [0]*8
    c = 0
    for i in range(8):
        valid = (valid_mask >> i) & 1
        leaf = (leaf_mask >> i) & 1
        c_valid[i] = bool(valid)
        c_leaf[i] = bool(leaf)
        if valid and not leaf:
            c_offset[i] = c
            c += 1
    return c_leaf, c_valid, c_offset

def first_node(tx0, ty0, tz0, txm, tym, tzm):
    t_enter = max(tx0, max(ty0, tz0))
    i = 0
    if tzm < t_enter: i ^= 1
    if tym < t_enter: i ^= 2
    if txm < t_enter: i ^= 4
    return i

def new_node(tx1, ty1, tz1, node_index):
    if tx1 < ty1 and tx1 < tz1:
        return 8 if (node_index & 0b100) else (node_index ^ 0b100)
    elif ty1 < tz1:
        return 8 if (node_index & 0b010) else (node_index ^ 0b010)
    else:
        return 8 if (node_index & 0b001) else (node_index ^ 0b001)

def procLeaf(tmin, fb, cur_x, cur_y):
    red = (int(tmin) >> 8) % 256
    blu = 0
    fb.drawPixel(cur_x, cur_y, (red / 256, 0, blu / 256))

def ray_cast(r_o, r_d, ot, fb, cur_x, cur_y, termin_level):
    dir_mask = 0
    if r_d.x == 0: r_d.x = 1e-10
    if r_d.x < 0: r_o.x = -r_o.x; r_d.x = -r_d.x; dir_mask |= 4
    if r_d.y == 0: r_d.y = 1e-10
    if r_d.y < 0: r_o.y = -r_o.y; r_d.y = -r_d.y; dir_mask |= 2
    if r_d.z == 0: r_d.z = 1e-10
    if r_d.z < 0: r_o.z = -r_o.z; r_d.z = -r_d.z; dir_mask |= 1

    tx0, ty0, tz0 = 0.0, 0.0, 0.0
    tx1, ty1, tz1 = 1.0, 1.0, 1.0
    txm, tym, tzm = 1.0, 1.0, 1.0
    t_start = min(tx1, min(ty1, tz1))
    level, si, sl = 0, 0, 0
    is_first_node = True
    node_adr = ot.root_adr
    idx = 0
    exit_node = False
    stack_underflow = False
    stack = [None] * 1024
    c_leaf, c_valid, c_offset = [False]*8, [False]*8, [0]*8

    while True:
        if is_first_node:
            be = ot.get_entry(node_adr)
            c_leaf, c_valid, c_offset = child_decode(be.node.valid_mask, be.node.leaf_mask)
            i = first_node(tx0, ty0, tz0, txm, tym, tzm)
            is_first_node = False
        else:
            i = new_node(tx1, ty1, tz1, idx)

        idx_flip = i ^ dir_mask

        if exit_node:
            if level == 0: return False
            if stack_underflow:
                t_start = tx1
                continue
            level -= 1; si -= 1; sl -= 1
            s = stack[si]
            tx0, ty0, tz0, tx1, ty1, tz1, node_adr, idx = s.tx0, s.ty0, s.tz0, s.tx1, s.ty1, s.tz1, s.node_adr, s.idx
            be = ot.get_entry(node_adr)
            c_leaf, c_valid, c_offset = child_decode(be.node.valid_mask, be.node.leaf_mask)
            continue

        if c_leaf[idx_flip] or level == termin_level:
            procLeaf(t_start, fb, cur_x, cur_y)
            return True

        if c_valid[idx_flip]:
            assert si < 1024
            stack[si] = (tx0, ty0, tz0, tx1, ty1, tz1, node_adr, idx)
            si += 1
            if sl < 32: sl += 1
            level += 1
            is_first_node = True
            # [G] Standard octree subdivision updates tx0..tz1 to child bounds based on idx_flip
            child_ptr = ot.get_entry(node_adr).node.child_ptr
            child_bep = ot.get_relative_entry(node_adr, child_ptr)
            node_adr = child_bep.adr + c_offset[idx_flip]
            be = ot.get_entry(node_adr)
            c_leaf, c_valid, c_offset = child_decode(be.node.valid_mask, be.node.leaf_mask)
    return False

def COMPACTIFY(N_l, D, S):
    # Parallel reduction step per [S1]
    N_l_plus_1 = []
    for t in range(len(N_l)):
        if D[t] == 1:
            k = S[t]
            N_l_plus_1[k] = N_l[t]
    return N_l_plus_1
```

**Edge Cases and Pitfalls:** Far pointers trigger when `child_ptr` has bit 15 set (`child_ptr & (1<<15)`), requiring a lookup to a separate far entry at relative offset `child_ptr` where `far_ptr` holds the actual address [S2, unofficial]. Stack underflow occurs when the stack is empty and an exit is requested, resetting $t\_start$ to $t\_exit$ and restarting initialization to treat the ray as newly entering the octree bounds [S2, unofficial]. Zero direction components must be guarded with epsilon addition to prevent division by zero during t-value calculations [S2, unofficial]. Fixed-point arithmetic uses `tnum` (SInt32) with clipping at $2^{31}-1000$ and $-2^{31}+1000$ to prevent overflow [S2, unofficial].

## Operating characteristics
The time complexity is $O(N)$ where $N$ is the number of rays, but the COMPACTIFY step reduces active rays as they traverse deeper into the octree [S1][S2, unofficial]. Memory complexity is $O(D)$ for the explicit stack, where $D$ is the maximum octree depth, plus temporary storage for the COMPACTIFY active ray list [S1][S2, unofficial]. The method is optimized for CPU execution, leveraging explicit stack management and parallel reduction to minimize memory bandwidth and cache misses [S2, unofficial]. Strengths include non-recursive traversal avoiding stack overflow, reduced processing load via compaction, and on-the-fly mask decoding minimizing memory accesses [S2, unofficial]. Limitations include a heuristic `new_node` function that may not be optimal for all ray directions, and fixed-point precision constraints for extreme scene scales [S2, unofficial]. It is best suited for CPU-based ray tracing of sparse voxel octrees where memory efficiency and explicit traversal control are required [S2, unofficial]. It should be avoided for GPU implementations where recursive or parametric methods align better with hardware architecture, and for dense scenes where stack management and compaction overhead outweigh benefits [S2, unofficial].

## Background
Compact Voxel Octree Raycasting originates from the SVO Workbench project [S2, unofficial]. The COMPACTIFY technique, which forms the parallel reduction core of this method, was introduced in the context of Neural Geometric Level of Detail (NGLOD) for real-time rendering with implicit 3D shapes [S1]. The SVO Workbench provides a concrete CPU implementation of this traversal algorithm for sparse voxel structures [S2, unofficial].
