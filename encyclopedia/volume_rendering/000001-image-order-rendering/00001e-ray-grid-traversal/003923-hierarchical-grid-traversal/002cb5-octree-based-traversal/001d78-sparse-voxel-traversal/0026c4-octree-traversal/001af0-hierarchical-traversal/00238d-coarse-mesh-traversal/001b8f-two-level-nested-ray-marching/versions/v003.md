# Two-level Nested Ray Marching

Also called: Front-to-back ray marching on AMR, Ray Marching with Coarse Mesh and Refinement Tree

## Overview
Two-level nested ray marching is a volume rendering technique that performs front-to-back compositing by traversing a coarse mesh of bounding volumes and, for each active coarse element, marching through its fine-level descendants (such as a tetrahedral refinement tree) [S1, unofficial]. It distinguishes itself from uniform grid ray marching by avoiding the memory blow-up of high-resolution grids, and from pure hierarchical traversal by explicitly separating the coarse mesh culling step from the fine-level sampling loop [S1, S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A ray defined by origin $\mathbf{org}$, direction $\mathbf{dir}$, and current distance $t$. A coarse mesh data structure containing macrocell summaries (`macrocellValues`) and a traversal function `TraverseCoarseMesh`. A refinement tree (e.g., tetrahedral mesh) associated with coarse elements, with a traversal function `traverse` and an intersection function `intersectFaces`. A transfer function `tf` mapping scalar values to color and opacity. A constant step size `stepSize`.
*   **Output:** Final accumulated color and alpha.

**Data Structures:**
*   `macrocellValues`: An array where `macrocellValues[i]` stores a summary statistic (e.g., maximum density) for coarse element `i`.
*   `tf`: A function or lookup table providing `tf.getColor(scalar)` which returns a color and opacity, and `tf.inRange(scalar)` which checks if the scalar is within the transfer function's active range.

**Algorithm Steps:**

1.  **Initialization:** Set accumulated color $C = \{0, 0, 0\}$ and accumulated alpha $\alpha = 0$.
2.  **Coarse Loop:** While $\alpha < 0.99$:
    a.  Call `TraverseCoarseMesh(ray)` to obtain the current coarse element ID `coarseID`, the back face distance `tBack`, and the distance to the next face `tNextFace`.
    b.  If `coarseID` is $-1$, break the loop (ray has exited the volume).
    c.  Check for emptiness: If `macrocellValues[coarseID] <= 0`, skip processing for this element.
    d.  If not skipped, call `MarchElement(ray, C, \alpha, tBack, coarseID, stepSize, tf)` to update $C$ and $\alpha$.
    e.  Advance the ray: `ray.t = max(tNextFace, ray.t)`.
3.  **Final Compositing:** Return the final color: $C_{final} = (1 - \alpha) \times C_{bg} + C$, where $C_{bg}$ is the background color.

**Nested Element Marching (`MarchElement`):**
1.  Initialize local exit distance `tExit = 0`, sample tetrahedron ID `sampleTetID = 0`, and vertices `tetVertices = {}`.
2.  While `ray.t < tBack` (the back of the coarse element):
    a.  Calculate sample point: $\mathbf{p} = \mathbf{org} + \mathbf{t} \times \mathbf{dir}$.
    b.  **Refinement Traversal:** If `ray.t > tExit`:
        i.  Call `traverse(p, coarseTetID)` to find the containing fine element (e.g., tetrahedron) `sampleTetID` and its vertices `tetVertices`.
        ii. Calculate `tExit` by intersecting the ray with the faces of the current fine element using `intersectFaces(ray.t, p, ray.direction, tetVertices)`.
    c.  **Sampling:** Sample the scalar value $s$ at $\mathbf{p}$ using `sampleData(p, sampleTetID, tetVertices)`.
    d.  **Range Check:** If `!tf.inRange(s)`, continue to the next iteration (skip compositing).
    e.  **Transfer Function:** Get `tfColor = tf.getColor(s)`. Adjust opacity: `tfColor.opacity = tfColor.opacity * tf.opacity`.
    f.  **Advance:** `ray.t = ray.t + stepSize`.
    g.  **Compositing:** Perform front-to-back accumulation:
        $$ C = C + (1 - \alpha) \times \text{tfColor.opacity} \times \text{tfColor.color} $$
        $$ \alpha = \alpha + \text{tfColor.opacity} \times (1 - \alpha) $$
3.  Return updated $C$ and $\alpha$.

**Pseudocode:**

```python
def ray_march_coarse(ray, macrocell_values, step_size, tf, bg_color):
    """
    Main ray marching loop over the coarse mesh.
    """
    color = [0.0, 0.0, 0.0]
    alpha = 0.0
    
    while alpha < 0.99:
        # Traverse coarse mesh to find current element and bounds
        coarse_id, t_back, t_next_face = traverse_coarse_mesh(ray)
        
        if coarse_id == -1:
            break
            
        # Macrocell culling
        skip = macrocell_values[coarse_id] <= 0
        
        if not skip:
            color, alpha = march_element(ray, color, alpha, t_back, coarse_id, step_size, tf)
            
        # Advance ray to next coarse element
        ray.t = max(t_next_face, ray.t)
        
    # Final background compositing
    final_color = (1.0 - alpha) * bg_color + color
    return final_color

def march_element(ray, color, alpha, t_max, coarse_tet_id, step_size, tf):
    """
    Nested march through fine elements within a coarse element.
    """
    t_exit = 0.0
    sample_tet_id = 0
    tet_vertices = []
    
    while ray.t < t_max:
        sample_point = ray.org + ray.t * ray.dir
        
        # Check if we need to traverse to a new fine element
        if ray.t > t_exit:
            sample_tet_id, tet_vertices = traverse(sample_point, coarse_tet_id)
            t_exit = intersect_faces(ray.t, sample_point, ray.direction, tet_vertices)
            
        # Sample data
        scalar = sample_data(sample_point, sample_tet_id, tet_vertices)
        
        # Advance ray step
        ray.t = ray.t + step_size
        
        # Check transfer function range
        if not tf.in_range(scalar):
            continue
            
        # Get transfer function color and adjust opacity
        tf_color = tf.get_color(scalar)
        tf_color.opacity = tf_color.opacity * tf.opacity
        
        # Front-to-back compositing
        color = color + (1.0 - alpha) * tf_color.opacity * tf_color.color
        alpha = alpha + tf_color.opacity * (1.0 - alpha)
        
    return color, alpha
```

**Parameters:**
*   **Step Size:** A constant adjustable step size. No adaptive step size adjustments are implemented [S1, unofficial]. Smaller step sizes increase accuracy but reduce performance [S1, unofficial].
*   **Opacity Threshold:** The ray marching loop continues while $\alpha < 0.99$ [S1, unofficial].

## Subtopics

### AMR Volume Ray-Casting
A variant that ray-marches Adaptive Mesh Refinement (AMR) octrees directly without resampling to a uniform grid, avoiding the $(2^{l_{max}})^3$ memory blow-up [S2, unofficial]. Each ray steps by the local cell size of the current leaf node, so computational cost scales with the simulation data rather than the bounding box [S2, unofficial]. It stores each leaf once in a per-level hash [S2, unofficial]. Unlike the coarse-mesh approach which uses a separate BVH for culling, this method traverses the octree structure directly, stepping by local cell size [S2, unofficial]. It supports cross-level trilinear reconstruction to reduce blockiness from nearest-leaf sampling [S2, unofficial].

## Operating characteristics
*   **Complexity:** Time complexity depends on the number of coarse elements intersected and the density of fine elements within them. Memory complexity is proportional to the number of coarse elements and fine elements, avoiding the exponential growth of uniform grids [S2, unofficial].
*   **Performance:** The use of macrocell culling (`macrocellValues <= 0`) allows skipping empty regions efficiently [S1, unofficial]. However, the constant step size means performance degrades linearly with smaller step sizes, and there is no adaptive optimization for varying density regions [S1, unofficial].
*   **Strengths:** Avoids memory blow-up of high-resolution uniform grids [S2, unofficial]. Efficient culling of empty space via macrocells [S1, unofficial].
*   **Limitations:** Constant step size may lead to aliasing or excessive sampling in low-density areas [S1, unofficial]. Blockiness may occur with nearest-leaf sampling without smoothing [S2, unofficial].

## Background
The method was described in the context of direct volume rendering of tree-based tetrahedral adaptive mesh refinement data [S1, unofficial]. It utilizes a coarse mesh for traversal and a refinement tree for fine-level sampling [S1, unofficial]. A related implementation in the Mera.jl library demonstrates direct AMR octree ray-casting for immersive 3-D visualization, highlighting the memory efficiency of not resampling [S2, unofficial].
