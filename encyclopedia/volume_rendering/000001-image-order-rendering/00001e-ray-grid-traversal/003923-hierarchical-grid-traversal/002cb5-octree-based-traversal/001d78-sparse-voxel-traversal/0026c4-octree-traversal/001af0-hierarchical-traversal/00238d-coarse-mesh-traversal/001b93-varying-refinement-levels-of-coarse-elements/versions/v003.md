# Varying Refinement Levels of Coarse Elements

Also called: Coarse mesh refinement level variation, Inserting refinement levels into coarse mesh

## Overview
This method optimizes hierarchical volume rendering by selecting which elements from a refinement tree are inserted into the coarse mesh (BVH). It addresses the trade-off between BVH traversal efficiency and the depth of the nested fine-structure traversal [S1, unofficial]. By varying the refinement level $k$ of the inserted elements, the algorithm controls the size of the macrocells and the granularity of the culling, allowing the renderer to balance between coarse culling overhead and fine-grained sampling cost [S1, unofficial].

## How it works
The method modifies the coarse mesh construction phase of the parent [Coarse Mesh Traversal](3062-coarse-mesh-traversal.md). Instead of using a fixed set of elements (e.g., only leaf nodes or only root nodes), it traverses the refinement tree to select elements at a specific depth.

### Inputs and Outputs
*   **Input:** The tetrahedral adaptive mesh refinement (TET-AMR) data structure, defined as a hierarchy of refinement trees.
*   **Input:** The target refinement level $k$ (integer $\ge 0$).
*   **Output:** A coarse mesh (BVH) containing a subset of the tetrahedra.
*   **Output:** A mapping from each coarse mesh element (macrocell) to its corresponding position in the refinement tree, enabling nested traversal.

### Data Structures
The coarse mesh consists of bounding volume hierarchy (BVH) nodes. Each leaf node in the BVH represents a "macrocell" which is a tetrahedron from the refinement tree.
*   **Macrocell:** A tetrahedron $T$ from the refinement tree.
*   **BVH Node:** Contains bounding box and children pointers.
*   **Refinement Tree Node:** Contains children pointers and density/value statistics.

### Algorithm Steps
1.  **Initialize:** Start with an empty list of coarse elements $C$.
2.  **Traverse Refinement Tree:** For each root node $R$ in the refinement tree:
    a.  Perform a depth-first or breadth-first traversal of the children of $R$.
    b.  For each node $N$ encountered:
        i.  If the depth of $N$ is less than $k$, continue to its children.
        ii. If the depth of $N$ is equal to $k$, or if $N$ is a leaf node (whichever comes first), add $N$ to the list $C$.
        iii. If $N$ is a leaf node and depth $< k$, add $N$ to $C$ and stop traversing this branch.
3.  **Build BVH:** Construct a BVH using the elements in $C$. The sources specify using 4 faces per element for BVH construction [S1, unofficial].
4.  **Assign Macrocell Values:** For each element $T \in C$, compute a summary statistic (e.g., maximum density) to store in the macrocell for culling purposes.
5.  **Render:** Proceed with standard hierarchical traversal:
    a.  Traverse the BVH to find active macrocells.
    b.  For each active macrocell, enter the nested traversal loop.
    c.  Sample the fine structure (tetrahedra) within the bounds of the macrocell. This involves traversing the original refinement tree to find the specific tetrahedra contained within the macrocell's bounds and performing ray-tetrahedron intersection tests.

### Parameters
*   **Refinement Level $k$:** The depth in the refinement tree at which elements are selected.
    *   $k=0$: Only root nodes (coarsest).
    *   $k=\text{max}$: Only leaf nodes (finest).
    *   Typical values tested: $0, 1, 2, 3, 4, 5$ [S1, unofficial].

### Edge Cases and Pitfalls
*   **Leaf Nodes:** If a refinement tree branch is shorter than level $k$, the leaf node is used instead. This ensures all data is covered.
*   **BVH Efficiency:** Increasing the number of elements in the coarse mesh (higher $k$) decreases BVH efficiency and maximum traversal depth in the BVH itself [S1, unofficial].
*   **Nested Traversal Cost:** Lower $k$ (fewer coarse elements) means larger macrocells, which may contain many more fine-level tetrahedra, increasing the cost of the nested traversal step.

### Pseudocode

```python
def build_coarse_mesh(refinement_tree_roots, target_level):
    """
    Builds a coarse mesh by inserting elements from the refinement tree
    at the specified target_level or at leaf nodes.
    
    Args:
        refinement_tree_roots: List of root nodes of the refinement trees.
        target_level: Integer, the desired refinement level.
        
    Returns:
        coarse_elements: List of tetrahedra to be inserted into the BVH.
    """
    coarse_elements = []
    
    for root in refinement_tree_roots:
        # Stack for DFS: (node, current_depth)
        stack = [(root, 0)]
        
        while stack:
            node, depth = stack.pop()
            
            # Check if we should stop at this node
            is_leaf = node.is_leaf()
            
            if is_leaf or depth == target_level:
                # Add this node's tetrahedron to the coarse mesh
                coarse_elements.append(node.tetrahedron)
            else:
                # Continue traversing children
                for child in node.children:
                    stack.append((child, depth + 1))
                    
    return coarse_elements

def render_with_varying_levels(scene, target_level):
    """
    Renders the scene using the coarse mesh built at target_level.
    """
    # 1. Build Coarse Mesh
    coarse_elements = build_coarse_mesh(scene.refinement_tree_roots, target_level)
    
    # 2. Build BVH from coarse elements
    # Using 4 faces per element for BVH construction [G]
    bvh = build_bvh(coarse_elements)
    
    # 3. Traverse Rays
    for ray in scene.rays:
        color = trace_ray(ray, bvh, scene.refinement_tree_roots)
        scene.image.set_pixel(ray, color)

def trace_ray(ray, bvh, refinement_tree_roots):
    """
    Standard hierarchical traversal with nested fine-structure traversal.
    """
    # Traverse BVH to find active macrocells
    active_macrocells = []
    traverse_bvh(ray, bvh.root, active_macrocells)
    
    accumulated_color = 0.0
    
    for macrocell in active_macrocells:
        # Nested traversal: find fine tetrahedra within this macrocell
        # This requires traversing the refinement tree to find tetrahedra
        # contained in the macrocell's bounds [G]
        fine_tetrahedra = find_tetrahedra_in_bounds(macrocell.bounds, refinement_tree_roots)
        
        for tet in fine_tetrahedra:
            # Perform ray-tetrahedron intersection
            t_hit = intersect_ray_tet(ray, tet)
            if t_hit is not None:
                # Sample density and accumulate color
                density = sample_density(tet, ray.origin + ray.direction * t_hit)
                accumulated_color += accumulate_color(density)
                
    return accumulated_color
```

## Operating characteristics
*   **Time Complexity:** Depends on the number of elements in the coarse mesh ($N_{coarse}$) and the average number of fine tetrahedra per macrocell ($N_{fine}$). BVH traversal is $O(\log N_{coarse})$. Nested traversal cost is proportional to $N_{fine}$. Total cost is roughly $O(R \cdot (\log N_{coarse} + N_{fine}))$ where $R$ is the number of rays.
*   **Memory Complexity:** $O(N_{coarse})$ for the BVH. The refinement tree is stored separately.
*   **Performance:**
    *   **Engine Dataset:** Increasing the refinement level (more coarse elements) generally degrades performance for the Ray Marcher with macrocell optimizations (41.47 ms at Level 0 vs 87.77 ms at Level 5) [S1, unofficial]. The Woodcock tracker also shows significant degradation (7.14 ms at Level 0 vs 94.97 ms at Level 5) [S1, unofficial].
    *   **Uniform Engine Dataset:** Performance is more variable. At Level 1, the Ray Marcher with macrocell optimizations is slightly faster (75.8 ms) than Level 0 (78.58 ms) [S1, unofficial]. The Woodcock tracker shows significant improvement at Levels 1 and 2 (9.57 ms and 9.56 ms) compared to Level 0 (10.72 ms) [S1, unofficial].
    *   **Trade-off:** Increasing coarse mesh elements decreases BVH efficiency but may decrease the refinement tree traversal depth. If the reduction in tree traversal depth outweighs the BVH overhead, performance improves (e.g., Uniform Engine Level 1) [S1, unofficial].
    *   **Macrocell Size:** Smaller macrocells (higher levels) yield tighter majorants for the Woodcock tracker, improving its performance at certain levels [S1, unofficial].

## Background
This method was explored in the context of direct volume rendering of tree-based tetrahedral adaptive mesh refinement (TET-AMR) data [S1, unofficial]. The research investigates how the granularity of the coarse mesh affects the performance of different ray marching strategies (Ray Marcher, Woodcock) on hierarchical data structures. The experiments were conducted on two datasets: "Engine" and "Uniform Engine" [S1, unofficial].
