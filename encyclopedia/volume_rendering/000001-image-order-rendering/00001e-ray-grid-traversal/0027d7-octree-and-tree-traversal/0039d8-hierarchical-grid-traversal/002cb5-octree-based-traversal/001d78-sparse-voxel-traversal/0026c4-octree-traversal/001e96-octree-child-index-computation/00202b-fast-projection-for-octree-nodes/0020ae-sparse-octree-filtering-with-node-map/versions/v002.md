# Sparse Octree Filtering with Node Map

Also called: Light-view Map Node Map, Node Map MIP-map Filtering

## Overview
This method reduces the number of threads launched during sparse voxel octree filtering by using a hierarchical 2D node map to detect and terminate redundant thread execution [S1]. It sets itself apart from naive per-pixel thread launching by terminating threads that target the same common ancestor node, achieving a speedup of > 2x [S1].

## How it works
The method constructs a 2D node map derived from the light-view map to guide thread execution during octree filtering [S1]. It uses a MIP-map pyramid structure to manage thread coordination and termination [S1].

### Data Structures
**Node Map**: A 2D array with multiple levels (MIP-map pyramid) [S1].
- **Lowest Level (Highest Resolution)**: Each pixel stores the index of the 3D leaf node in the sparse octree that contains the corresponding photon from the light-view map [S1].
- **Higher Levels (Lower Resolution)**: Each pixel stores the index of the lowest common ancestor (LCA) node for the nodes referenced by the corresponding pixels in the previous (higher resolution) level [S1].

### Algorithm Steps
1. **Initialization**: Construct the node map from the light-view map [S1]. For the lowest level, map each photon to its containing leaf node index [S1]. For higher levels, compute the LCA for groups of nodes from the level below [S1].
2. **Thread Launch**: Launch one thread per pixel of the lowest node map level for each MIP-mapping pass [S1].
3. **Node Lookup and Redundancy Check**: Each thread traverses the octree to find the specific node it must compute the filtered value for [S1]. Before performing computation, the thread checks the current level of the node map to see if another thread is targeting the same node (a common ancestor) [S1]. If a common ancestor is detected, all threads identifying this node are terminated except the "upper left" one (based on pixel coordinates) [S1]. The surviving thread computes the remaining filtered values for that node [S1].

### Pseudocode
```python
class Octree:
    def find_leaf_node(self, position): return 0  # [G] Standard octree lookup
    def find_lca(self, idx1, idx2): return 0      # [G] Standard octree LCA
    def compute_filtered_value(self, node_idx): pass  # [G] Standard filtering step

def sparse_octree_filtering_with_node_map(light_view_map, octree):
    # 1. Construct Node Map
    # Lowest level: map photons to leaf node indices
    lowest_level = [octree.find_leaf_node(photon.position) for photon in light_view_map]
    node_map = [lowest_level]
    current_level = lowest_level
    # Higher levels: compute LCAs for groups of nodes from the level below
    while len(current_level) > 1:
        next_level = []
        for i in range(0, len(current_level), 2):
            if i + 1 < len(current_level):
                lca_index = octree.find_lca(current_level[i], current_level[i+1])
            else:
                lca_index = current_level[i]  # [G] Fallback for odd length
            next_level.append(lca_index)
        node_map.append(next_level)
        current_level = next_level

    # 2. Launch threads for each MIP-mapping pass
    for level_idx in range(len(node_map)):
        level = node_map[level_idx]
        # Track which node indices are being computed to detect common ancestors
        active_threads = {}
        for pixel_idx, node_idx in enumerate(level):
            # Determine 2D coordinates from pixel_idx for upper-left rule
            # [G] Assuming standard row-major 2D layout
            width = len(node_map[0])
            x = pixel_idx % width
            y = pixel_idx // width
            # Check if another thread already targets this node
            if node_idx in active_threads:
                prev_x, prev_y = active_threads[node_idx]
                # Terminate current thread if it is not upper-left
                if y > prev_y or (y == prev_y and x > prev_x):
                    continue  # Thread terminated
            # Surviving thread computes the filtered value
            active_threads[node_idx] = (x, y)
            octree.compute_filtered_value(node_idx)
```

### Parameters and Edge Cases
- **Thread Termination Heuristic**: The "upper left" rule ensures deterministic termination when multiple threads target the same common ancestor node [S1].
- **Performance**: The heuristic reduces redundant work, yielding a speedup of > 2x compared to not using it [S1].
- **Edge Cases**: Highly irregular photon distributions may cause uneven thread termination, but the upper-left rule guarantees exactly one thread per unique node index per pass [S1].

This method generates anisotropic mipmaps from the leaf nodes of a sparse octree to support efficient cone tracing. It solves the problem of directional lighting blur by filtering voxel data anisotropically along the positive and negative XYZ axes, storing six directional values per voxel. It sets itself apart from isotropic filtering by preserving directional information required for accurate cone tracing, building on the node map structure of [Sparse Octree Filtering with Node Map](2337-sparse-octree-filtering-with-node-map.md) to reduce thread launch overhead.

## Operating characteristics
- **Speedup**: Achieves a speedup of > 2x compared to not using the heuristic to terminate redundant threads [S1].
- **Complexity**: Reduces the number of active threads by terminating redundant threads that target the same common ancestor node in the node map [S1].
- **Strengths**: Efficiently coordinates thread execution during MIP-map generation by leveraging the hierarchical 2D node map structure [S1].
- **Limitations**: Requires construction of the 2D node map from the light-view map; relies on the "upper left" heuristic for deterministic thread termination [S1].

## Background
This method originates from the "Interactive Indirect Illumination Using Voxel Cone Tracing" technique developed by NVIDIA researchers [S1]. It addresses the computational cost of filtering sparse voxel octrees for real-time global illumination by optimizing thread launch overhead through the node map structure [S1].
