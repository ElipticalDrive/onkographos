# Leaf Processing
Also called: IndexGridBuilder::foreach

## Overview
Leaf Processing copies precomputed voxel data from a contiguous source buffer into the leaf node buffers of an OpenVDB tree in parallel [S1, unofficial]. It executes the actual memory copy operations using offsets generated by [Leaf Offset Computation](5185-leaf-offset-computation.md) [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A contiguous source buffer containing voxel values (`data`), an array of precomputed linear offsets for each leaf (`m_leafOffsets`), and a `LeafManager` instance iterating over the tree's leaf nodes [S1, unofficial].
- **Output:** The leaf node buffers (`leaf.buffer().data()`) are populated with the corresponding voxel data from the source buffer [S1, unofficial].

**Data Structures:**
- `m_leafOffsets`: An array of `size_t` where the index corresponds to the leaf node index (`leafIdx`) and the value is the starting byte offset in the source `data` buffer [S1, unofficial].
- `LeafT::SIZE`: The number of voxels in a leaf node [S1, unofficial].
- `ValueT`: The data type of the voxel values [S1, unofficial].

**Steps:**
1. Initialize a parallel iterator over the leaf nodes using `LeafManager::foreach` [S1, unofficial].
2. Configure the parallel execution with a chunk size of 12 [S1, unofficial].
3. For each leaf node processed in parallel:
   a. Retrieve the leaf's global index (`leafIdx`) [S1, unofficial].
   b. Look up the base offset for this leaf from `m_leafOffsets`: `leafBaseOffset = m_leafOffsets[leafIdx]` [S1, unofficial].
   c. Get the pointer to the leaf's internal buffer: `leafData = leaf.buffer().data()` [S1, unofficial].
   d. Calculate the source pointer: `sourcePtr = data + leafBaseOffset` [S1, unofficial].
   e. Copy the leaf's data from the source to the leaf buffer using `std::memcpy` [S1, unofficial]. The number of bytes to copy is `LeafT::SIZE * sizeof(ValueT)` [S1, unofficial].

**Pseudocode:**
```python
def leaf_processing(data: bytearray, m_leafOffsets: list[int], leaf_manager: LeafManager, value_size: int, leaf_size: int):
    """
    Copies voxel data from a flat source buffer into OpenVDB leaf nodes in parallel.
    
    Args:
        data: Contiguous source buffer of voxel values (bytes).
        m_leafOffsets: Array mapping leaf index to byte offset in data.
        leaf_manager: Iterator over leaf nodes.
        value_size: Size of a single voxel value in bytes.
        leaf_size: Number of voxels in a leaf node.
    """
    chunk_size = 12
    
    # Parallel iteration over leaves
    leaf_manager.foreach(
        lambda leaf: process_leaf(leaf, data, m_leafOffsets, value_size, leaf_size),
        parallel=True,
        chunk_size=chunk_size
    )

def process_leaf(leaf, data, m_leafOffsets, value_size, leaf_size):
    """
    Copies data for a single leaf node.
    """
    # Get the index of the current leaf node
    leaf_idx = leaf.index()
    
    # Retrieve the precomputed base offset for this leaf
    leaf_base_offset = m_leafOffsets[leaf_idx]
    
    # Get pointer to the leaf's internal buffer
    leaf_data = leaf.buffer().data()
    
    # Calculate source pointer in the flat data array
    source_offset_in_values = leaf_base_offset // value_size
    
    # Copy data
    for i in range(leaf_size):
        leaf_data[i] = data[source_offset_in_values + i]
```

**Parameters:**
- `chunk_size`: 12 [S1, unofficial].
