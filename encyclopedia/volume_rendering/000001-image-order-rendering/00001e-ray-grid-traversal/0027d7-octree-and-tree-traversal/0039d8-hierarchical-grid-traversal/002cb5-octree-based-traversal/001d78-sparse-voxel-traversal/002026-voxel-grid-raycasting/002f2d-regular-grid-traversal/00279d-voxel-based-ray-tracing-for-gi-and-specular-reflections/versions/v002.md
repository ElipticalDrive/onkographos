# Voxel-based Ray Tracing for GI and Specular Reflections

Also called: ApplyVoxelRT, Voxel RT, VoxelDDA, VoxelReflectionFallback

## Overview
A voxel-based ray tracing system using Digital Differential Analyzer (DDA) traversal through a 128³ block-occupancy grid to provide global illumination (GI) and specular reflection fallbacks [S1, unofficial]. It serves as a drop-in replacement for Screen-Space Ray Tracing (SSRT) for GI and a fallback for Screen-Space Reflections (SSR) when coverage is incomplete, combining sky occlusion with Light Propagation Volume (LPV) colour bleeding [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 128³ block-occupancy voxel grid stored in `imgVoxelMask` (populated each frame in the shadow pass) and LPV data for indirect lighting [S1, unofficial].
*   **Output:** Indirect lighting contribution for GI and reflected colour for specular fallbacks [S1, unofficial].

**Data Structures:**
*   **Voxel Grid:** A 128³ block-occupancy grid stored in `imgVoxelMask` [S1, unofficial].
*   **LPV Data:** Propagated light buffer accessed via image load/store operations [S1, unofficial].

**Parameters:**
*   `VOXEL_GI_SAMPLES`: Number of cosine-weighted hemisphere rays for GI sampling; default value is 4 [S1, unofficial].
*   `VOXEL_GI_STEPS`: Configurable parameter for the number of steps in voxel GI ray traversal [S1, unofficial].
*   `VOXEL_REFL_STEPS`: Configurable parameter for the number of steps in voxel reflection ray traversal [S1, unofficial].
*   `VOXEL_RT_REFLECTIONS`: Feature flag to enable specular reflection fallback; commented out by default [S1, unofficial].
*   `VOXEL_GI`: Indirect effect mode identifier, value 6, added to the `indirect_effect` enum [S1, unofficial].

**Algorithm Steps:**
1.  **VoxelDDA():** Perform 3-D DDA traversal over the voxel grid, handling grid bounds and sign-safe boundary distances, returning face-centre position and axis-aligned normal [S1, unofficial]. Include ray bias in DDA traversal to avoid self-intersection and handle near-parallel rays gracefully [S1, unofficial].
2.  **SampleVoxelLighting():** Read the LPV data half a block in front of the hit face to obtain indirect colour at the surface from propagated light [S1, unofficial].
3.  **ApplyVoxelRT():** Trace `VOXEL_GI_SAMPLES` cosine-weighted hemisphere rays, blending sky contribution with LPV colour bounce at hit surfaces [S1, unofficial]. Acts as a drop-in replacement for `ApplySSRT()` [S1, unofficial].
4.  **VoxelReflectionFallback():** Perform a single specular DDA ray trace; activated only when screen-space reflection misses (`environmentReflection.a < 1`) [S1, unofficial]. Scale voxel lighting to match typical sky-reflection brightness ranges to avoid visual mismatch [S1, unofficial].

```python
def VoxelDDA(origin, direction, grid_size=128.0, max_steps=1000):
    """
    Perform 3-D DDA traversal over the voxel grid.
    Returns: (hit_position, hit_normal, hit_distance) or None if no hit.
    """
    ray_bias = 1e-4
    # Handle zero direction components gracefully
    inv_dir = [1.0 / d if abs(d) > 1e-6 else 0.0 for d in direction]
    step = [1 if d > 0 else -1 for d in direction]

    # Initial voxel coordinates
    current_voxel = [math.floor(o * grid_size) for o in origin]

    # Calculate initial t values for crossing voxel boundaries
    t_max = []
    for i in range(3):
        boundary = current_voxel[i] + (0.5 if step[i] > 0 else -0.5)
        if abs(direction[i]) > 1e-6:
            t_max.append((boundary - origin[i]) * inv_dir[i])
        else:
            t_max.append(float('inf'))

    # t_delta represents distance between boundaries
    t_delta = [abs(inv_dir[i]) for i in range(3)]

    # Apply ray bias to initial t_max to start traversal slightly forward
    t_max = [t + ray_bias for t in t_max]

    for _ in range(max_steps):
        # Find axis with smallest t_max
        min_idx = 0
        if t_max[1] < t_max[min_idx]: min_idx = 1
        if t_max[2] < t_max[min_idx]: min_idx = 2

        # Advance along that axis
        current_voxel[min_idx] += step[min_idx]
        t_max[min_idx] += t_delta[min_idx]

        # Check bounds
        if not all(0 <= v < grid_size for v in current_voxel):
            return None

        # Check occupancy
        if read_voxel_mask(current_voxel[0], current_voxel[1], current_voxel[2]):
            # Return face-centre position and axis-aligned normal
            hit_pos = [current_voxel[i] + 0.5 for i in range(3)]
            normal = [0.0, 0.0, 0.0]
            normal[min_idx] = -step[min_idx]
            dist = math.sqrt(sum((hit_pos[i] - origin[i])**2 for i in range(3)))
            return hit_pos, normal, dist
    return None

def ApplyVoxelRT(origin, normal, sky_colour, num_samples=4, max_steps=100):
    """
    Drop-in replacement for ApplySSRT().
    Traces VOXEL_GI_SAMPLES cosine-weighted hemisphere rays.
    """
    total_indirect = [0.0, 0.0, 0.0]
    for _ in range(num_samples):
        # Cosine-weighted hemisphere sampling [G]
        u1, u2 = random.random(), random.random()
        theta = 2.0 * math.pi * u1
        phi = math.acos(math.sqrt(u2))
        local_dir = [math.sin(phi)*math.cos(theta), math.sin(phi)*math.sin(theta), math.cos(phi)]
        # Transform local_dir to world space aligned with surface normal [G]
        ray_dir = local_dir
        hit = VoxelDDA(origin, ray_dir, max_steps=max_steps)
        if hit is not None:
            hit_pos, hit_norm, _ = hit
            lpv_col = sample_lpv(hit_pos)
            total_indirect = [total_indirect[i] + lpv_col[i] for i in range(3)]
        else:
            total_indirect = [total_indirect[i] + sky_colour[i] for i in range(3)]
    return [c / num_samples for c in total_indirect]

def VoxelReflectionFallback(origin, view_vector, normal_at_origin, environment_reflection, max_steps=100):
    """
    Single specular DDA ray trace.
    Activated only when environment_reflection.a < 1.
    """
    if environment_reflection[3] >= 1.0:
        return environment_reflection[:3]
    # Reflect view vector
    dot = sum(view_vector[i]*normal_at_origin[i] for i in range(3))
    reflect_dir = [view_vector[i] - 2.0*dot*normal_at_origin[i] for i in range(3)]
    hit = VoxelDDA(origin, reflect_dir, max_steps=max_steps)
    if hit is not None:
        hit_pos, hit_norm, _ = hit
        lpv_col = sample_lpv(hit_pos)
        # Scale voxel lighting to match typical sky-reflection brightness [G]
        return [c * 0.5 for c in lpv_col]
    return environment_reflection[:3]
```

**Edge Cases and Pitfalls:**
*   **Hardware Support:** Requires LPV (Light Propagation Volumes) and `GL_ARB_shader_image_load_store` support; gracefully degrades to SSRT if these are not met [S1, unofficial].
*   **Division by Zero:** Epsilon guards are required to prevent division by zero in `invTonemap()`, `FastCatmulRom()`, and TAA blending calculations, especially on hardware with aggressive FP16 FTZ behaviour (e.g., NVIDIA RTX 5000 series) [S1, unofficial].
*   **Self-Intersection:** Ray bias must be included in DDA traversal to avoid self-intersection [S1, unofficial].
*   **Near-Parallel Rays:** DDA traversal must handle near-parallel rays gracefully [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Depends on the size of the voxel grid (128³) and LPV data; no new buffers are needed beyond the existing `imgVoxelMask` [S1, unofficial].
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Scales with the number of GI samples and steps [S1, unofficial].
*   **Strengths:** Provides GI and specular reflections in areas where screen-space methods fail; drop-in replacement for SSRT [S1, unofficial].
*   **Limitations:** Requires LPV and specific GPU features; quality depends on the resolution of the voxel grid (128³) and LPV accuracy [S1, unofficial].
*   **When to use:** When screen-space GI/Reflections are insufficient or unavailable [S1, unofficial].
*   **When not to use:** When hardware lacks LPV or image load/store support; when performance is critical and SSRT is sufficient [S1, unofficial].
