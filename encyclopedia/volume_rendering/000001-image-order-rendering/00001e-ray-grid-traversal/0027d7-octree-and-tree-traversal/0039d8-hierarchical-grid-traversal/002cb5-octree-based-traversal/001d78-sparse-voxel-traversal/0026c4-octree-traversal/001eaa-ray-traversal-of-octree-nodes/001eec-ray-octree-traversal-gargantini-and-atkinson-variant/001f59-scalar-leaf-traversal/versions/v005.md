# Scalar Leaf Traversal

Also called: Scalar leaf node traversal

## Overview
Scalar leaf traversal is the leaf-level processing step in ray traversal of sparse voxel octrees, handling nodes that contain homogeneous scalar values and no children [S3]. It determines whether an isosurface intersects the homogeneous region by checking the neighborhood of voxel values at the cap depth [S2]. It differs from cap node traversal by assuming internal homogeneity, allowing for early rejection when the neighborhood contains identical voxels [S1, S2][S4, S5, unofficial].

## How it works
**Inputs:** Ray parameters (origin $\mathbf{o}$, direction $\mathbf{d}$, current hit distance $t_{hit}$), scalar leaf node data (homogeneous scalar value $v_{leaf}$, bounding box), cap depth $D_{cap}$, and octree structure for neighbor access [S1, S2, S3][S4, S5, unofficial].
**Outputs:** Boolean indicating if an isosurface intersection occurs within the scalar leaf, and if yes, the intersection point and normal [S1, S2, S3][S4, S5, unofficial].
**Data Structures:** The scalar leaf node stores a single scalar value $v_{leaf}$ and its spatial bounds [S3]. The neighborhood consists of the 8 corner voxels of the cell defined by the leaf's bounding box at the cap depth [S1, S2, S3][S4, S5, unofficial].

**Steps:**
1. **Recursive Traversal:** Traverse the octree recursively until the current node depth equals the cap depth $D_{cap}$ [S1, S2, S3][S4, S5, unofficial].
2. **Identify Node Type:** Determine if the current node at $D_{cap}$ is a scalar leaf, which has no children and a homogeneous value [S2, S3][S4, S5, unofficial].
3. **Boundary Value Retrieval:** At the borders of the scalar leaf node, retrieve the scalar values of the 8 corner voxels of the cell defined by the leaf's bounding box [S1, S2, S3][S4, S5, unofficial]. To find a neighbor in direction $dir \in \{0, \dots, 7\}$, check if the child bit corresponding to $dir$ is set; if false, the neighbor value is retrieved from the parent cap's scalar array at index $dir$; if true, proceed with standard neighbor-finding to retrieve the value [S1, S2, S3][S4, S5, unofficial].
4. **Homogeneity Check:** Check if the neighborhood of 8 voxels contains identical values [S1, S2][S4, S5, unofficial]. If all 8 corner values are identical, conclude that no isosurface is encountered within the scalar leaf [S1, S2][S4, S5, unofficial].
5. **Isovalue Range Check:** If the neighborhood is not uniform, check if the target isovalue $v$ lies within the minimum and maximum of the 8 corner voxel values: $\min(v_{corners}) \le v \le \max(v_{corners})$ [S1, S2, S3][S4, S5, unofficial]. If it does, proceed to intersection [S4, S5, unofficial].
6. **Isosurface Intersection:** Perform isosurface intersection using the 8 corner voxels as the corners of the cell [S1, S2, S3][S4, S5, unofficial].

**Isosurface Intersection Details:**
The implicit surface is defined by the trilinear Lagrangian interpolant:
$$ f(x, y, z) = \left( \sum_{i, j, k=\{0,1\}} x_i y_j z_k v_{ijk} \right) - v = 0 $$
where $(i, j, k)$ is the minimum coordinate of the cell, $v$ is the isovalue, $v_{ijk}$ is the value of the cell vertex, and $x_0 = i-x$, $x_1 = x-i$ (similarly for $y, z$ with respect to $j, k$) [S3][S5, unofficial]. The hit position is found by evaluating the ray at the first positive root of the resulting cubic polynomial [S2, S3][S4, S5, unofficial].

## Background
Scalar leaf traversal is part of the interactive isosurface ray tracing of large octree volumes method, introduced by Knoll et al. in 2006 [S1, S2, S3]. It is designed to handle the leaf nodes of sparse voxel octrees efficiently, allowing for real-time rendering of large volumes [S1, S2, S3]. The method builds on the ray-octree traversal technique by Gargantini and Atkinson, adapting it to handle scalar leaves specifically [S1, S2, S3].
