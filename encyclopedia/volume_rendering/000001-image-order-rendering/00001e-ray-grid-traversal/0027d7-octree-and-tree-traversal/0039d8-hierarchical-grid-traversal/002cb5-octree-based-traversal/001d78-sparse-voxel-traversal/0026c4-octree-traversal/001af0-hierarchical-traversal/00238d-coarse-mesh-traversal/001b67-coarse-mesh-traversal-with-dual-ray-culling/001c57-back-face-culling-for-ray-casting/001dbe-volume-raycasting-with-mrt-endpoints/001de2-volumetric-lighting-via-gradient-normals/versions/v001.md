# Volumetric Lighting via Gradient Normals

Also called: Gradient Normal Lighting, Gradient-based Lighting in MRT Raycasting

## Overview
A technique to compute lighting normals in volume data by approximating the gradient vector, which points in the direction of greatest change and whose magnitude indicates surface intersection [S1, unofficial]. It solves the problem of shading volumetric data without explicit surface extraction by using the gradient direction as the surface normal [S1, unofficial]. It sets itself apart from sibling methods by deriving normals directly from scalar field differences rather than geometric primitives or pre-computed meshes [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Volume texture (`VolumeSampler`), ray start/stop positions from MRT endpoints, step length (`StepLength`), threshold (`Threshold`), light position, diffuse material color, and transformation matrices.
- Output: Fragment color with alpha.

**Data Structures:**
- `VolumeSampler`: 3D texture sampling scalar values.
- `RayStart`, `RayStop`: 2D textures storing object-space coordinates for ray origins and destinations.

**Steps:**
1. Retrieve ray start (`rayStart`) and stop (`rayStop`) positions from MRT endpoint textures using screen coordinates.
2. If `rayStart` equals `rayStop`, discard the fragment.
3. Calculate ray vector: `ray = rayStop - rayStart`.
4. Calculate ray length: `rayLength = length(ray)`.
5. Calculate step vector: `stepVector = StepLength * ray / rayLength`.
6. Initialize position `pos = rayStart` and destination color `dst = vec4(0)`.
7. Loop while `dst.a < 1` and `rayLength > 0`:
   a. Sample voxel value `V = lookup(pos)`.
   b. If `V > Threshold`:
      i. Compute gradient components using central differences with step size `L = StepLength`:
         - `E = lookup(pos + vec3(L, 0, 0))`
         - `N = lookup(pos + vec3(0, L, 0))`
         - `U = lookup(pos + vec3(0, 0, L))`
      ii. Compute gradient vector: `grad = vec3(E - V, N - V, U - V)`.
      iii. Transform normal: `normal = normalize(NormalMatrix * grad)`.
      iv. Compute diffuse factor: `df = abs(dot(normal, light))`.
      v. Compute source color: `src = vec4(df * DiffuseMaterial, 1.0)`.
      vi. Update destination: `dst = (1.0 - dst.a) * src + dst`.
      vii. Break loop.
   c. Advance position: `pos += stepVector`.
   d. Decrease ray length: `rayLength -= StepLength`.
8. Output `dst` as fragment color.

**Formulas:**
- Gradient approximation:
  $$ \nabla V \approx \begin{bmatrix} V(x+L, y, z) - V(x, y, z) \\ V(x, y+L, z) - V(x, y, z) \\ V(x, y, z+L) - V(x, y, z) \end{bmatrix} $$
- Diffuse lighting:
  $$ C_{diff} = |\mathbf{n} \cdot \mathbf{l}| \cdot \mathbf{m}_{diff} $$
- Front-to-back blending:
  $$ C_{out} = (1 - \alpha_{in}) C_{src} + \alpha_{in} C_{dst} $$

**Parameters:**
- `Threshold`: Minimum voxel value to trigger gradient computation. Typical value: 0.45 [S1, unofficial].
- `StepLength`: Distance between samples. Typical value: 0.01 [S1, unofficial].

**Edge Cases:**
- If `rayStart == rayStop`, the ray has no length; discard to avoid division by zero.
- If `V <= Threshold`, skip gradient computation to save texture lookups.
- Precision issues may arise if `StepLength` is too large relative to volume resolution, causing aliasing.

## Subtopics

## Operating characteristics
- Time complexity: Linear with respect to ray length in voxels, but only computes gradient for voxels above threshold.
- Memory complexity: Low, requires only volume texture and MRT endpoint textures.
- Strengths: Simple implementation, no pre-computation required, efficient culling via threshold.
- Limitations: Gradient approximation is first-order, may be noisy; thresholding can miss subtle surfaces.
- When to use: Real-time volume rendering where explicit surface extraction is too expensive.
- When not to use: High-fidelity offline rendering requiring smooth normals.

## Background
Originated in early volume rendering techniques for real-time graphics, popularized by Prideout's "Volumetric Splatting" blog post [S1, unofficial]. It leverages basic vector calculus concepts to approximate surface normals in scalar fields.
