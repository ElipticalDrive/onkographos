# Silhouette Image Space Acceleration Structure (Mip Pyramid)

Also called: Hierarchical Voxelization Acceleration Structure

## Overview
This method accelerates voxelization queries by providing conservative bounds on silhouette coverage using a mip pyramid over silhouette images [S1]. It solves the problem of efficiently determining if a voxel intersects with the visual hull surface without sampling every point within the voxel volume [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of $n$ smoothed silhouette images $I_i$ (one per camera view) [S1].
*   **Output:** A mip pyramid for each of the $n$ silhouette images, storing min/max aggregates [S1].

**Data Structures:**
*   **Mip Pyramid:** For each silhouette image $i$, a hierarchy of textures (pyramid levels) [S1].
*   **Texel Layout:** Each texel at level $L > 0$ stores two values: the minimum and maximum of the four corresponding texels at level $L-1$ [S1]. Level 0 contains the smoothed silhouette values [S1].
*   **Value Domain:** The values represent silhouette coverage [S1].

**Construction:**
1.  Generate $n$ image pyramids using a compute kernel launched immediately after silhouette image smoothing [S1].
2.  Build each level bottom-up by computing the minimum and maximum possible values of the four texels at the next lower level [S1].

**Query Algorithm (`sampleSilhouette`):**
To determine a conservative bound on the silhouette value $\mathcal{S}(\mathbf{p})$ for all $\mathbf{p}$ within a voxel $\mathbf{v}$:

1.  **Projection:** Project the 8 NVC space corners of voxel $\mathbf{v}$ into the 2D image space of silhouette image $i$ [S1].
2.  **Bounding Rectangle:** Compute the axis-aligned bounding rectangle (AABB) of these projected corners. Let the bounds be $minX, minY, maxX, maxY$ [S1].
3.  **Level Selection:** Determine the sampling level $L$ in the mip pyramid using the formula:
    $$ L = \lfloor \log_2(\max(maxX - minX, maxY - minY)) \rfloor $$
    At this level $L$, the bounding rectangle covers at most a $2 \times 2$ block of texels [S1].
4.  **Sampling:** Sample the texels at the corners of the AABB in the pyramid at level $L$ [S1].
5.  **Aggregation:** Return the minimum and maximum of these sampled values as the conservative bound for image $i$ [S1].
6.  **Final Bound:** To get the bound for the visual hull $\mathcal{S}(\mathbf{p})$, take the product of the minimums (and similarly maximums) over all $n$ images [S1].

**Pseudocode:**
```python
import math

def sample_silhouette(voxel_corners_ndc, projection_matrices, pyramid_levels, num_images):
    """
    voxel_corners_ndc: List of 8 3D points in NDC space.
    projection_matrices: List of 4x4 projection matrices for each image.
    pyramid_levels: List of lists. pyramid_levels[i][lvl] is a 2D array of (min, max) tuples for image i at level lvl.
    num_images: Total number of silhouette images.
    Returns: (global_min, global_max)
    """
    global_min = 1.0
    global_max = 0.0

    for i in range(num_images):
        projected_2d = []
        for p in voxel_corners_ndc:
            # Standard homogeneous projection
            h = [sum(projection_matrices[i][r][c] * v for c, v in enumerate([p[0], p[1], p[2], 1.0])) for r in range(4)]
            x = h[0] / h[3]
            y = h[1] / h[3]
            projected_2d.append((x, y))

        min_x = min(p[0] for p in projected_2d)
        min_y = min(p[1] for p in projected_2d)
        max_x = max(p[0] for p in projected_2d)
        max_y = max(p[1] for p in projected_2d)

        level = math.floor(math.log2(max(max_x - min_x, max_y - min_y)))

        lvl_data = pyramid_levels[i][level]
        lvl_h = len(lvl_data)
        lvl_w = len(lvl_data[0]) if lvl_h > 0 else 0

        def clamp(val, mn, mx):
            return max(mn, min(val, mx))

        def get_texel(x, y):
            tx = clamp(math.floor(x), 0, lvl_w - 1)
            ty = clamp(math.floor(y), 0, lvl_h - 1)
            return lvl_data[ty][tx]

        t1 = get_texel(min_x, min_y)
        t2 = get_texel(max_x, min_y)
        t3 = get_texel(min_x, max_y)
        t4 = get_texel(max_x, max_y)

        local_min = min(t1[0], t2[0], t3[0], t4[0])
        local_max = max(t1[1], t2[1], t3[1], t4[1])

        global_min *= local_min
        global_max *= local_max

    return global_min, global_max
```

**Parameters:**
*   **Pyramid Depth:** Determined by the resolution of the silhouette images [S1].
*   **Smoothing:** The silhouette images are smoothed before pyramid construction [S1].

**Edge Cases and Pitfalls:**
*   **Conservative Bounds:** The min/max aggregation ensures that no small features are missed and no holes are created in the voxelization, as the bounds are conservatively correct [S1].

## Operating characteristics
*   **Performance:** The structure greatly reduces the amount of computation and data accesses needed by the oracle kernel to make a culling decision for a given voxel [S1].
*   **Strengths:** Conservative bounds prevent missing small features or creating holes in voxelization [S1].
*   **Limitations:** Requires pre-computation of silhouette images and pyramids [S1].
*   **When to Use:** When voxelizing from multiple calibrated camera views and efficient culling of voxels outside the visual hull is required [S1].

## Background
The method was introduced in the context of real-time high-resolution sparse voxelization for image-based modeling [S1]. It is inspired by the hierarchical z-buffer technique [Greene et al. 1993] [S1]. The specific implementation is described in the paper "Real-time high-resolution sparse voxelization with application to image-based modeling" [S1].
