# Multi-Level Array Grid

Also called: Classic multi-level array grid

## Overview
The Multi-Level Array Grid is a hierarchical acceleration structure for ray tracing that recursively subdivides a scene's bounding box into a nested grid of nodes based on item density [S1, S2, unofficial]. It solves the problem of efficient spatial traversal by skipping empty regions via null pointers and refining only occupied areas [S1, S2, unofficial]. Unlike [Two-Level Grids for Ray Tracing on GPUs](4245-two-level-grids-for-ray-tracing-on-gpus.md) which uses a fixed two-level hierarchy, or [Macrocell Grid Traversal](5207-macrocell-grid-traversal.md) which uses macro-cells for coarse traversal, this method allows arbitrary depth (up to a limit) and dynamic grid dimensions per node [S1, S2, unofficial].

## How it works
### Inputs and Outputs
*   **Input**: A set of scene primitives (items) and their bounding boxes.
*   **Output**: A root `GridNode` representing the hierarchical grid structure.

### Data Structures
The structure consists of two main types of nodes: `InnerNode` and `GridNode`.

**InnerNode**: Represents a non-leaf grid level.
*   `min[3]`: Float array, minimum extents of the node's bounding box.
*   `max[3]`: Float array, maximum extents of the node's bounding box.
*   `dim[3]`: Integer array, grid dimensions $(M_x, M_y, M_z)$.
*   `delta[3]`: Float array, cell size in each dimension.
*   `cells`: Pointer to an array of `GridNode*` pointers. The array size is $M_x \times M_y \times M_z$.

**GridNode**: A union type representing either a leaf or an inner node.
*   `index`: Integer.
    *   Low bit: `1` indicates an inner node, `0` indicates a leaf.
    *   High bits: Store the number of items if the node is a leaf.
*   `union`:
    *   `leaf`: Contains `int* items`, a pointer to an array of primitive indices.
    *   `inner`: Contains `InnerNode* interior`, a pointer to the `InnerNode` data.

### Construction Algorithm
1.  **Compute Scene Bounding Box**: Determine the global minimum and maximum extents of all scene primitives. Let $S_i$ be the size of the bounding box in dimension $i \in \{x, y, z\}$.
2.  **Initialize Root**: Create the first node as a leaf node containing all scene items.
3.  **Recursive Processing**: Process each node recursively:
    *   **Termination Conditions**: If the number of items in the current node is less than 8, or the current grid depth is greater than 2, the node remains a leaf and recursion stops [S1, S2, unofficial].
    *   **Expansion**: Otherwise, expand the node to an inner node.
        1.  **Compute Grid Dimensions**: Calculate the dimensions $M_i$ for each axis using the heuristic attributed to Woo (1992) [S1, S2, unofficial]:
            $$M_i = \frac{S_i}{\max\{S_i\}} \sqrt[3]{\rho N} \quad (i \in \{x, y, z\})$$
            Where:
            *   $S_i$ is the bounding box size in dimension $i$.
            *   $\max\{S_i\}$ is the maximum bounding box size across all dimensions.
            *   $\rho$ is the density factor, typically 4 [S1, S2, unofficial].
            *   $N$ is the number of primitives in the current node.
        2.  **Compute Delta**: Calculate the cell size $\delta_i = \frac{S_i}{M_i}$ for each dimension.
        3.  **Allocate Cells**: Allocate the `cells` array for the `InnerNode` with size $M_x \times M_y \times M_z$.
        4.  **Populate Cells**: For each cell in the grid:
            *   Compute the list of items falling within the cell's bounds.
            *   If the list is empty, set the corresponding `cells` pointer to `null`.
            *   If the list is not empty, initialize a new `GridNode` as a leaf containing these items.
        5.  **Recurse**: For each non-null child `GridNode` (leaf), recursively apply the processing steps.

### Pseudocode
```python
def build_multi_level_array_grid(primitives, depth=0):
    """
    Recursively builds the multi-level array grid.
    primitives: list of primitive objects with bounding boxes
    depth: current recursion depth
    """
    if not primitives:
        return None

    # Compute bounding box of current primitives
    min_bounds = [min(p.min[i] for p in primitives) for i in range(3)]
    max_bounds = [max(p.max[i] for p in primitives) for i in range(3)]
    sizes = [max_bounds[i] - min_bounds[i] for i in range(3)]
    max_size = max(sizes)
    N = len(primitives)

    # Termination conditions
    # Leaf threshold: < 8 items
    # Depth limit: > 2
    if N < 8 or depth > 2:
        # Create leaf node
        leaf_items = [p.id for p in primitives]
        index = (N << 1) | 0  # High bits: item count, low bit: 0 (leaf)
        return GridNode(index=index, leaf_items=leaf_items)

    # Expansion to inner node
    # Calculate grid dimensions using Woo's heuristic
    rho = 4
    dim = []
    for i in range(3):
        # M_i = (S_i / max(S)) * cube_root(rho * N)
        # Use integer rounding for dimensions
        m_i = (sizes[i] / max_size) * (rho * N) ** (1/3)
        dim.append(max(1, int(round(m_i))))

    # Compute delta (cell size)
    delta = [sizes[i] / dim[i] for i in range(3)]

    # Initialize inner node structure
    inner_node = InnerNode(
        min=min_bounds,
        max=max_bounds,
        dim=dim,
        delta=delta,
        cells=[None] * (dim[0] * dim[1] * dim[2])
    )

    # Distribute primitives into cells
    for p in primitives:
        # Determine cell coordinates
        cell_coords = []
        for i in range(3):
            # Clamp coordinate to avoid out-of-bounds due to float precision
            coord = (p.min[i] - min_bounds[i]) / delta[i]
            # Handle edge case where coord equals dim[i]
            if coord >= dim[i]:
                coord = dim[i] - 1
            cell_coords.append(int(coord))
        
        # Flatten 3D index to 1D array index
        idx = cell_coords[0] * dim[1] * dim[2] + \
              cell_coords[1] * dim[2] + \
              cell_coords[2]
        
        if inner_node.cells[idx] is None:
            inner_node.cells[idx] = []
        inner_node.cells[idx].append(p)

    # Recursively build children
    for i in range(len(inner_node.cells)):
        if inner_node.cells[i] is not None:
            inner_node.cells[i] = build_multi_level_array_grid(inner_node.cells[i], depth + 1)

    # Create root GridNode for this inner node
    index = 1  # Low bit: 1 (inner), high bits: 0
    return GridNode(index=index, interior=inner_node)
```

### Parameters
*   **Leaf Threshold**: 8 items. Nodes with fewer items remain leaves [S1, S2, unofficial].
*   **Depth Limit**: 2. Recursion stops if depth exceeds 2 [S1, S2, unofficial].
*   **Density Factor ($\rho$)**: 4. Used in the dimension calculation heuristic [S1, S2, unofficial].

### Edge Cases and Pitfalls
*   **Empty Cells**: Represented as `null` pointers in the `cells` array to save memory [S1, S2, unofficial].
*   **Redundant Data**: `delta` is redundant as it can be computed from `min`, `max`, and `dim`, but is cached for performance [S1, S2, unofficial].
*   **One-Level Grid**: Can be simulated by setting the grid depth limit to 1 [S1, S2, unofficial].

## Operating characteristics
*   **Time Complexity**: Construction is $O(N \log N)$ or similar depending on distribution, but the source does not provide a precise complexity formula. Traversal time is dominated by grid traversal, which is faster than one-level grids [S2, unofficial].
*   **Memory Complexity**: Memory usage is reduced by null pointers for empty cells. Inner nodes are larger than leaf nodes but are fewer in number [S1, S2, unofficial].
*   **Performance**: Grid traversal dominates render time. Multi-level grids spend less time on ray-triangle intersections compared to one-level grids [S2, unofficial].
*   **Strengths**: Reduces ray-primitive intersection tests by skipping empty space. Adapts to scene density.
*   **Limitations**: Construction overhead. Fixed depth limit may not be optimal for all scenes.

## Background
The Multi-Level Array Grid is described in the paper "Multi-level Grid Strategies for Ray Tracing" [S1, S2, unofficial]. It is presented as a classic implementation used for performance comparison against other multi-level grid strategies, such as the Multi-Level Hashed Grid. The dimension calculation heuristic is attributed to Woo (1992) [S1, S2, unofficial].
