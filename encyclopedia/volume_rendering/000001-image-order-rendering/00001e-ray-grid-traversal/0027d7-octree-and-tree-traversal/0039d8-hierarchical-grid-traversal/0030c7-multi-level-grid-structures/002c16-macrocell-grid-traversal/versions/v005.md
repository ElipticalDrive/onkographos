# Macrocell Grid Traversal

Also called: Downscaled Grid Traversal

## Overview
Macrocell Grid Traversal is a hierarchical acceleration technique for ray-grid traversal that superimposes a coarse grid over a base uniform fine grid to skip empty regions efficiently [S1, S2]. It reduces traversal overhead by allowing the renderer to skip $M$ steps in the fine grid if an entire block of cells is empty, achieving approximately 30% performance improvement over single ray grids [S1, S2]. It differs from [Multi-Level Array Grid](3329-multi-level-array-grid.md) by using a fixed, uniform downsampling factor rather than variable subdivision, and from [Two-Level Grids for Ray Tracing on GPUs](4245-two-level-grids-for-ray-tracing-on-gpus.md) by relying on a simple boolean occupancy flag per macrocell rather than more complex bounding volumes or secondary structures.

## How it works
**Inputs:**
- A base uniform fine grid representing the volume or scene geometry.
- A downsampling factor $M$ (integer, typically 6) [S1, S2].

**Outputs:**
- A macrocell grid structure containing occupancy flags for coarse blocks.
- Traversal state allowing skipping of empty fine-grid slices.

**Data Structures:**
The macrocell grid is a 3D array of size $N_x/M \times N_y/M \times N_z/M$, where $N_x, N_y, N_z$ are the dimensions of the fine grid. Each element is a boolean flag (or bit) indicating whether any cell in the corresponding $M \times M \times M$ block of the fine grid is occupied [S1, S2].

**Algorithm Steps:**

1.  **Build Macrocell Grid:**
    Iterate through the fine grid. For each block of $M \times M \times M$ cells, set the corresponding macrocell flag to `true` if at least one cell in the block is occupied; otherwise, set it to `false` [S1, S2]. This build step is described as "trivial and cheap" [S1, S2].

2.  **Frustum Setup (Coarse):**
    Compute the traversal parameters for the macrocell grid. Since the macrocell grid is an $M \times M \times M$ downscaled version of the fine grid, the step sizes and entry/exit distances can be derived from the fine grid parameters by dividing by $M$ [S1, S2]. Specifically, if $\Delta x_{fine}$ is the step size in the fine grid, the macrocell step size is $\Delta x_{macro} = \Delta x_{fine} / M$ [S1, S2].

3.  **Traverse Macrocell Grid:**
    Perform standard ray-grid traversal on the macrocell grid. Determine the slice of macrocells overlapped by the ray frustum. In practice, this usually involves only one macrocell slice along the primary axis of traversal [S1, S2].

4.  **Check Occupancy:**
    For the current macrocell slice, check if all macrocells are empty (flag is `false`) [S1, S2].

5.  **Skip or Traverse:**
    -   **If all macrocells in the slice are empty:** Skip $M$ traversal steps on the original fine grid. This effectively jumps over the empty volume represented by the macrocell block [S1, S2].
    -   **If any macrocell is occupied:** Perform standard fine grid traversal steps for that slice. The ray continues through the fine grid cells corresponding to the occupied macrocells [S1, S2].

    """
    Builds the macrocell grid from the fine grid.
    """
    Nx, Ny, Nz = fine_grid.dimensions

    macro_grid = [[False] * macro_Nz for _ in range(macro_Ny)]

**Parameters:**
- $M$: The downsampling factor (block size). Typical value is 6 [S1, S2]. Smaller $M$ yields insufficient savings; larger $M$ reduces the probability of finding empty regions [S1, S2].

**Edge Cases and Pitfalls:**
- For smaller resolutions, the savings for each macrocell step become too small to justify the additional computations [S1, S2].
- For larger resolutions, the probability of finding empty regions decreases, reducing the benefit of skipping [S1, S2].
- Additional levels of macrocells could further improve performance for more complex models with larger grids, but were not investigated in the source material [S1, S2].

## Operating characteristics
- **Time Complexity:** Build time is $O(N)$ where $N$ is the number of fine grid cells, as it requires a single pass to aggregate occupancy [S1, S2]. Traversal time is reduced by a factor related to the empty space ratio, with reported improvements of around 30% compared to single ray grids [S1, S2].
- **Memory Complexity:** The macrocell grid adds $O(N/M^3)$ memory overhead for the boolean flags [S1, S2].
- **Scaling:** Performance improvement is consistent with improvements seen for single ray grids [S1, S2].
- **Strengths:** Simple to implement, cheap to build, effective for medium-size animated scenes with varying density [S1, S2].
- **Limitations:** Less effective for very small or very large resolutions due to overhead or reduced empty region probability [S1, S2]. Not suitable for scenes with highly varying geometric density without more robust hierarchical varieties [S1, S2].

## Background
Macrocells were introduced as a simple hierarchical optimization to a base uniform grid, often used to apply grids to scalar volume fields [S1, S2]. The method was described by Parker et al. in 1999 [S1, S2]. It is particularly useful for ray tracing animated scenes where the acceleration structure is rebuilt every frame, as the build process is trivial and cheap [S1, S2].
