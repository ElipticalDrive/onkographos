# Occupancy Grid and Map-Based Empty Space Skipping

Also called: Grid-based Empty Space Skipping, Occupancy Map Ray Casting

## Overview
Occupancy Grid and Map-Based Empty Space Skipping accelerates volume rendering by using a lower-resolution binary grid to identify empty regions, allowing rays to skip sampling in those areas [S1]. It sets itself apart from [Distance Map Acceleration](972-distance-map-acceleration.md) by using simple binary flags rather than distance fields, and from [Two-stage Ray Marching with Empty-Space Skipping](2985-two-stage-ray-marching-with-empty-space-skipping.md) by integrating the skip logic directly into the ray traversal loop rather than decoupling it into distinct stages.

## Shared principles
The method relies on a precomputed **Occupancy Map**, a 3D texture or grid with resolution $d_{\text{occ}} = (d_x/B, d_y/B, d_z/B)$, where $B$ is the block size (typically $4^3$) [S1]. Each voxel in this map represents a block of the high-resolution volume data and stores a binary flag: 1 if the block contains non-empty data, 0 otherwise [S1].

During ray traversal, for each sample position $t$, the algorithm maps the normalized coordinate to the occupancy map coordinate $u_{\text{occ}}$:
$$
u_{\text{occ}} = \frac{d_{\text{vol}}}{B} \cdot t
$$
If the sampled occupancy flag is 0, the ray is in an empty block. The algorithm calculates the step count $\Delta i$ required to reach the next occupied block boundary. For dimension $j \in \{x, y, z\}$, the step count is:
$$
\Delta i_j = \begin{cases} \lceil (1 + \lfloor u_{\text{occ},j} \rfloor - u_{\text{occ},j}) / \Delta u_j \rceil & \text{if } \Delta u_j > 0 \\ \lceil (\lfloor u_{\text{occ},j} \rfloor - u_{\text{occ},j}) / \Delta u_j \rceil & \text{otherwise} \end{cases}
$$
where $\Delta u_j$ is the change in occupancy map coordinate per sample step [S1]. The actual skip distance $\Delta t_{\text{skip}}$ is derived from the minimum of these dimensional steps, ensuring the ray advances to the nearest occupied region [S1]. If the flag is 1, standard volume sampling and compositing occur [S1].

## Subtopics

### [Distance Map Acceleration](972-distance-map-acceleration.md)
Uses Chebyshev distance maps to leapfrog to occupied boundaries. Choose when precise boundary detection is needed to avoid aliasing.

### [Two-stage Ray Marching with Empty-Space Skipping](2985-two-stage-ray-marching-with-empty-space-skipping.md)
Decouples search and sampling into two phases. Choose for simpler implementations where stage separation aids debugging or specific shading requirements.

### [Hierarchical Sampling with Occupancy Grid](3035-hierarchical-sampling-with-occupancy-grid.md)
Combines occupancy skipping with importance-based refinement for NeRFs. Choose for neural volume rendering where sample efficiency is critical.

## Background
The technique was introduced by Levoy and Whitted in 1985 [S1]. It is widely used in real-time volume rendering and isosurface rendering to reduce texture memory bandwidth [S1].
