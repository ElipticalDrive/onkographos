# Occupancy Map Generation via Ray Casting

Also called: DVGO Voxel Count Views

## Overview
This method generates an occupancy map by counting the number of rays passing through each voxel in a 3D grid, identifying regions viewed by training cameras to initialize or refine the geometry mask [S1, unofficial].

## How it works
**Inputs:**
- `rays`: Tensor of ray origins and directions [S1, unofficial].
- `world_size`: Dimensions of the 3D grid [S1, unofficial].
- `stepsize`: Distance between sample points along a ray [S1, unofficial].
- `near`, `far`: Clamping distances for ray segment intersection [S1, unofficial].
- `downrate`: Downsampling factor for rays if `irregular_shape` is false [S1, unofficial].
- `irregular_shape`: Boolean flag determining ray batching strategy [S1, unofficial].

**Outputs:**
- `count`: A zero-initialized tensor with the same shape as the density grid, accumulating ray hits [S1, unofficial].

**Data Structures:**
- `count`: 3D tensor, shape `(D, H, W)`, dtype float32 [S1, unofficial].
- `ones`: A `DenseGrid` object representing a 3D grid of ones, used for gradient accumulation [S1, unofficial].

**Pseudocode:**
```python
def generate_occupancy_map(rays, world_size, stepsize, near, far, downrate, irregular_shape, world_bounds):
    count = torch.zeros(world_size, dtype=torch.float32)
    if irregular_shape:
        ray_batches = [rays[i:i+10000] for i in range(0, len(rays), 10000)]
    else:
        rays_downsampled = rays[::downrate, ::downrate].reshape(-1, rays.shape[-1])
        ray_batches = [rays_downsampled[i:i+10000] for i in range(0, len(rays_downsampled), 10000)]

    for batch in ray_batches:
        ones = DenseGrid(size=1, world_size=world_size, bounds=world_bounds)
        vec = batch.direction.clone()
        vec[vec == 0] = 1e-6
        rate_a = (world_bounds.min - batch.origin) / vec
        rate_b = (world_bounds.max - batch.origin) / vec
        t_min = max(min(rate_a), min(rate_b))
        t_max = min(max(rate_a), max(rate_b))
        t_min = clamp(t_min, near, far)
        t_max = clamp(t_max, near, far)
        N_samples = int(np.linalg.norm(np.array(world_size) + 1) / stepsize) + 1
        interpx = torch.linspace(t_min, t_max, N_samples)
        rays_pts = batch.origin + interpx.unsqueeze(1) * batch.direction
        ones.query(rays_pts).backward()
        count += (ones.grad > 1).float()
    return count
```

**Formulas:**
- Sample count per ray: $N_{\text{samples}} = \left\lfloor \frac{\| \text{world\_size} + 1 \|}{\text{stepsize}} \right\rfloor + 1$ [S1, unofficial].
- Intersection bounds: $t_{\min} = \max(\min(\text{rate\_a}), \min(\text{rate\_b}))$ and $t_{\max} = \min(\max(\text{rate\_a}), \max(\text{rate\_b}))$, clamped to $[\text{near}, \text{far}]$ [S1, unofficial].

**Parameters:**
- `far`: Set to $10^9$ to prevent rays from stopping early due to small bounding box limits [S1, unofficial].
- `N_samples`: Calculated as above [S1, unofficial].

**Edge Cases:**
- Division by zero in ray direction normalization is handled by replacing zeros with $10^{-6}$ [S1, unofficial].
- Small bounding box limits causing premature ray termination are mitigated by setting `far` to $10^9$ [S1, unofficial].
