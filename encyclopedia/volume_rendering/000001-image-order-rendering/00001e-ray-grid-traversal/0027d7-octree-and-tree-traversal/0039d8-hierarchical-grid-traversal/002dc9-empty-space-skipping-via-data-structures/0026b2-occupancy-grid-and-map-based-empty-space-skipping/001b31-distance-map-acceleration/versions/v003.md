# Distance Map Acceleration

Also called: Accelerated Volume Rendering with Chebyshev Distance Maps, Chebyshev Distance Maps, Chebyshev distance map ray traversal, Distance Field Ray Marching Acceleration, Empty space skipping using distance maps, Ray Traversal with Distance Map Skipping

## Overview
Distance Map Acceleration is a ray traversal technique that uses a precomputed Chebyshev distance map to skip sampling points in empty regions of a volumetric image, reducing texture memory bandwidth and improving frame rates for volume and isosurface rendering [S1][S2, unofficial]. It builds on [Occupancy Grid and Map-Based Empty Space Skipping](3852-occupancy-grid-and-map-based-empty-space-skipping.md) by replacing simple binary occupancy checks with distance-based leapfrogging, allowing rays to jump directly to the nearest occupied region boundary [S1]. Unlike [Two-stage Ray Marching with Empty-Space Skipping](2985-two-stage-ray-marching-with-empty-space-skipping.md) which may use hierarchical structures or multiple passes, this method performs a single-pass ray cast accelerated by a 3D distance field [S2, unofficial].

## How it works
**Inputs:**
- Volume data texture (scalar values) with dimensions $d_{\text{vol}} = (d_x, d_y, d_z)$ [S1].
- Transfer function parameters: `imin` (intensity_min, default 0.1f), `imax` (intensity_max, default 1.0f), `gmin` (gradient_min, default 0.0f), `gmax` (gradient_max, default 0.2f) [S2, unofficial].
- Camera ray origin and direction $\mathbf{d}$ [S1].
- Block size $B \in \mathbb{N}^3$ (typically $B=4^3$) [S1][S2, unofficial].
- Optional precomputed gradient map [S2, unofficial].

**Outputs:**
- Rendered image with empty space skipped [S1][S2, unofficial].

**Data Structures:**
1. **Volume Texture:** 3D texture containing voxel intensities [S1].
2. **Gradient Map:** 3D texture storing precomputed gradient magnitudes, generated via compute shader if `use_precomputed_gradient` is true [S2, unofficial].
3. **Occupancy Map:** 3D texture of binary flags (occupied/unoccupied) with dimensions $d_{\text{occ}} = (d_x/B, d_y/B, d_z/B)$ [S1].
4. **Distance Map:** 3D texture storing Chebyshev distance to the nearest occupied block, same dimensions as the occupancy map [S1][S2, unofficial].
5. **Transfer Function Uniform:** Buffer containing `imin`, `imax`, `gmin`, `gmax` passed to compute shaders via `a_tf_uniform` allocation [S2, unofficial].

**Preprocessing Steps:**
1. **Gradient Map Generation:** If enabled, dispatch a compute shader to calculate gradient magnitudes for all voxels using the tetrahedron method [S1]. The tetrahedron method computes the gradient magnitude at position $\mathbf{pos}$ using four neighbor samples: $\mathbf{g} = 0.25 \cdot \text{vec4}(k_{xyy} \cdot \text{image}(\mathbf{pos}+k_{xyy}) + k_{yyx} \cdot \text{image}(\mathbf{pos}+k_{yyx}) + k_{yxy} \cdot \text{image}(\mathbf{pos}+k_{yxy}) + k_{xxx} \cdot \text{image}(\mathbf{pos}+k_{xxx}))$, where $k = \text{ivec2}(1, -1)$, and returns $\|\mathbf{g}\|$ [S1].
2. **Occupancy Map Generation:** Dispatch a compute shader to evaluate each block of size $B \times B \times B$ [S1].
    - For **volume rendering**: A block is occupied if any voxel within it has non-zero alpha according to the transfer function [S1].
    - For **isosurface rendering**: A block is occupied if the isosurface threshold lies between the minimum and maximum voxel values in the block, and a single-voxel halo around the block is also checked [S1].
3. **Distance Map Generation:** Convert the occupancy map to a Chebyshev distance map using a compute shader [S2, unofficial]. The Chebyshev distance between two points $(x_1, y_1, z_1)$ and $(x_2, y_2, z_2)$ is $\max(|x_1-x_2|, |y_1-y_2|, |z_1-z_2|)$ [S1].

**Ray Traversal Algorithm:**
1. **Ray-Volume Intersection:** Compute entry $t_{\text{entry}}$ and exit $t_{\text{exit}}$ of the ray with the volume bounding box [S1].
2. **Sampling Parameters:** Calculate the number of samples $n$ and step size $\Delta t$:
    $$ n = \lceil \max \vec{x}(\mathbf{d}) \cdot \| \mathbf{t}_{\text{exit}} - \mathbf{t}_{\text{entry}} \| \cdot f \rceil $$
    $$ \Delta t = \frac{t_{\text{exit}} - t_{\text{entry}}}{n - 1} $$
    where $\mathbf{d}$ is the ray direction, $f \ge 1$ is a sampling factor, and $\max \vec{x}$ returns the maximum component of the vector [S1].
3. **Ray Casting Loop:**
    - Initialize current position $t = t_{\text{entry}}$ [S1].
    - While $t < t_{\text{exit}}$:
        - Convert normalized texture coordinate $t$ to volume voxel coordinate $u_{\text{vol}}$ and occupancy map coordinate $u_{\text{occ}}$:
            $$ u_{\text{vol}} = d_{\text{vol}} \cdot t $$
            $$ u_{\text{occ}} = \frac{d_{\text{vol}}}{B} \cdot t $$
        - Sample the occupancy map at $u_{\text{occ}}$ [S1].
        - If the block is **empty**:
            - Calculate the step $\Delta i$ in occupancy map indices to reach the next occupied region. For dimension $j \in \{x, y, z\}$:
                $$ \Delta i_j = \begin{cases} \lceil (1 + \lfloor u_{\text{occ},j} \rfloor - u_{\text{occ},j}) / \Delta u_j \rceil & \text{if } \Delta u_j > 0 \\ \lceil (\lfloor u_{\text{occ},j} \rfloor - u_{\text{occ},j}) / \Delta u_j \rceil & \text{otherwise} \end{cases} $$
                where $\Delta u_j = \frac{d_{\text{vol},j}}{B} \Delta t d_j$ is the change in occupancy map coordinate per sample step along the ray [S1].
            - Convert $\Delta i$ to normalized distance $\Delta t_{\text{skip}}$ and advance $t \leftarrow t + \Delta t_{\text{skip}}$ [S1].
        - If the block is **occupied**:
            - Sample the volume and gradient map at $u_{\text{vol}}$ [S1].
            - Apply transfer function using `imin`, `imax`, `gmin`, `gmax` to compute color and opacity [S2, unofficial].
            - Composite the sample into the ray buffer [S1].
            - Check for early ray termination [S2, unofficial].
            - Advance $t \leftarrow t + \Delta t$ [S1].
4. **Clipping:** The volume is clipped at a specified `clip_distance` from the camera [S2, unofficial]. If the viewpoint enters the volume, the intersection vertices are computed in a vertex shader [S2, unofficial]. Volumes are also clipped against the depth buffer [S2, unofficial].

**Pseudocode:**
```python
import math

def distance_map_accelerated_ray_cast(ray_origin, ray_direction, volume_tex, occ_map, gradient_map, block_size, d_vol, tf_params):
    # 1. Ray-Volume Intersection (slab method for box [0, d_vol))
    t_entry = -float('inf')
    t_exit = float('inf')
    for j in range(3):
        inv_d = 1.0 / ray_direction[j] if ray_direction[j] != 0 else float('inf')
        t1 = (0.0 - ray_origin[j]) * inv_d
        t2 = (d_vol[j] - ray_origin[j]) * inv_d
        t_entry = max(t_entry, min(t1, t2))
        t_exit = min(t_exit, max(t1, t2))
    if t_entry > t_exit:
        return (0.0, 0.0, 0.0)  # background_color

    # 2. Sampling Parameters
    f = 1.0  # sampling_factor
    ray_segment_len = t_exit - t_entry
    max_d = max(abs(c) for c in ray_direction)
    n = math.ceil(max_d * ray_segment_len * f)
    if n < 1:
        n = 1
    delta_t = ray_segment_len / (n - 1) if n > 1 else 0.0

    # Precompute occupancy map step sizes per sample
    delta_u_occ = [(d_vol[j] / block_size) * delta_t * ray_direction[j] for j in range(3)]

    t = t_entry
    color = [0.0, 0.0, 0.0]
    alpha = 0.0

    while t < t_exit:
        # Map t to occupancy map coordinates
        u_occ = [(d_vol[j] / block_size) * t for j in range(3)]
        u_occ_int = [int(math.floor(u)) for u in u_occ]

        # Check occupancy
        if not occ_map.sample(u_occ_int):
            # Empty block: skip using grid step formula
            steps = [0, 0, 0]
            for j in range(3):
                if delta_u_occ[j] > 0:
                    steps[j] = math.ceil((1.0 + math.floor(u_occ[j]) - u_occ[j]) / delta_u_occ[j])
                else:
                    steps[j] = math.ceil((math.floor(u_occ[j]) - u_occ[j]) / delta_u_occ[j])
            
            # Convert steps to normalized distance delta_t_skip
            delta_t_skip = float('inf')
            for j in range(3):
                if delta_u_occ[j] != 0:
                    dt_skip_j = steps[j] * delta_t / delta_u_occ[j]
                    if dt_skip_j > 0:
                        delta_t_skip = min(delta_t_skip, dt_skip_j)
            if delta_t_skip == float('inf'):
                delta_t_skip = delta_t
            t += delta_t_skip
        else:
            # Occupied block: sample volume
            u_vol = [d_vol[j] * t for j in range(3)]
            val = volume_tex.sample(u_vol)
            grad = gradient_map.sample(u_vol) if gradient_map else 0.0
            
            # Apply Transfer Function [G]
            alpha_val, sample_color = tf_apply(val, grad, tf_params)
            
            # Composite
            color[0] = color[0] + alpha_val * (1.0 - alpha) * sample_color[0]
            color[1] = color[1] + alpha_val * (1.0 - alpha) * sample_color[1]
            color[2] = color[2] + alpha_val * (1.0 - alpha) * sample_color[2]
            alpha = alpha + alpha_val * (1.0 - alpha)
            
            if alpha >= 1.0:
                break
                
            t += delta_t

    return color
```

## Subtopics

### [Partitioned Distance Map Combination](1191-partitioned-distance-map-combination.md)
Partitioned Distance Map Combination is the runtime assembly phase that merges a selected subset of precomputed partitioned distance maps into a single global distance map for empty space skipping. It differs from its sibling, [Occupancy Map Generation](1197-occupancy-map-generation.md), by using a ping-pong buffer strategy with two swap textures to iteratively combine maps, allowing more maps to be processed than can be bound simultaneously as shader inputs. Choose this variant when rendering large volumes that exceed GPU memory limits for a single distance map or when dynamic transfer functions require frequent distance map recomputation.

### [Occupancy Map Generation](1197-occupancy-map-generation.md)
Occupancy Map Generation is a GPU compute shader dispatch routine that produces an occupancy map from input volume, gradient, and ITF textures to enable efficient empty-space skipping in volume rendering. It differs from its sibling, [Partitioned Distance Map Combination](1191-partitioned-distance-map-combination.md), by generating a single-resolution occupancy map rather than a continuous distance field or partitioned data. Choose this variant when memory bandwidth is constrained and binary occupancy checks are sufficient for coarse culling.

## Operating characteristics
- **Time Complexity:** Preprocessing is $O(V)$ where $V$ is the number of voxels for gradient and occupancy map generation [S1]. Ray traversal is $O(N_{\text{samples}})$ in the worst case, but significantly reduced by skipping empty space [S1].
- **Memory Complexity:** Occupancy map requires $1/B^3$ of the volume memory [S1]. For $B=4$, this is $1/64$th [S1]. Gradient map requires additional memory if precomputed [S1].
- **Measured Performance:** Not given in the sources.
- **Scaling:** Performance improves with volume sparsity and larger block sizes $B$, though larger blocks reduce skipping granularity [S1].
- **Strengths:** Efficient empty space skipping; simple implementation; works well with GPU compute shaders [S1][S2, unofficial].
- **Limitations:** Requires preprocessing; distance map generation can be costly for large volumes; Chebyshev distance may overestimate skip distances in some cases compared to Euclidean [S1].
- **When to use:** Volume rendering with significant empty space; isosurface rendering [S1].
- **When not to use:** Dense volumes with little empty space; dynamic volumes where preprocessing cost outweighs benefits [S1].

## Background
Distance Map Acceleration was introduced by Lachlan Deakin and Mark Knackstedt in 2019 in "Accelerated Volume Rendering with Chebyshev Distance Maps" [S2, unofficial]. It is an extension of their earlier work on empty space skipping [S1]. The method is implemented in the open-source Vulkan renderer `VkVolume` [S2, unofficial].
