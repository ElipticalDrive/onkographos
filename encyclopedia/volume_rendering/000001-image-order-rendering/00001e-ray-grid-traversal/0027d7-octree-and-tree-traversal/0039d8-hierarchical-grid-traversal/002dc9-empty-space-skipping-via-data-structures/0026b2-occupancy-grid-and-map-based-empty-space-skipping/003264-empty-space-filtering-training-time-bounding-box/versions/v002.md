# Empty Space Filtering (Training-Time Bounding Box)

Also called: Alpha-based Bounding Box Filtering, Training-time Empty Space Filtering

## Overview
Empty Space Filtering is a preprocessing and runtime optimization strategy for dynamic neural volume rendering that accelerates training and rendering by restricting computation to the scene's active volume. It identifies empty space using alpha values from a coarse deformation feature grid and filters out sampled points that are recognized as empty, thereby reducing the number of queries to the light-weight MLP [S1]. Unlike static occupancy grids that rely on fixed voxel density, this method derives a dynamic bounding box from temporal alpha statistics, allowing it to adapt to moving objects while avoiding computation in regions that never contain significant geometry [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A coarse deformation feature grid sampled across all training time steps $t \in [0, T]$.
*   **Output:** A coarse geometry prior (axis-aligned bounding box) and a filtering mask for sampled points during ray marching.

**Data Structures:**
*   **Coarse Deformation Feature Grid:** A 3D grid storing deformation features. Each vertex $v$ has an associated alpha value $\alpha(v, t)$ at time $t$.
*   **Bounding Box:** Defined by minimum and maximum coordinates $(x_{min}, y_{min}, z_{min})$ and $(x_{max}, y_{max}, z_{max})$ encompassing all object points.

**Steps:**

1.  **Alpha Query:** Query all grid vertices of the coarse deformation feature grid for every training time step $t$. Retrieve the alpha value $\alpha(v, t)$ for each vertex $v$.
2.  **Classification:** Classify each grid vertex $v$ as an "object point" or "empty space" based on the alpha threshold. A point is considered an object point if:
    $$ \alpha(v, t) > \text{threshold} $$
    where $\text{threshold}$ is a predefined scalar value [S1].
3.  **Bounding Box Computation:** Compute the smallest axis-aligned bounding box that fully encloses all vertices classified as object points across all time steps $t \in [0, T]$. This defines the "coarse geometry prior" [S1].
4.  **Runtime Filtering (Deformation Module):** For sampled points in the deformation module, filter out points that are recognized as empty. Since empty points are assumed to be static, a sampled point is filtered if its alpha value is below the threshold during *all* training times:
    $$ \text{Keep } p \iff \exists t \in [0, T] : \alpha(p, t) > \text{threshold} $$
5.  **Runtime Filtering (Canonical Module):** For sampled points in the canonical module, filter out empty points only at the canonical time (typically $t=0$ or a reference time) [S1].
6.  **Grid Volume Reduction:** Use the coarse geometry prior to reduce the volume of the grid in the fine stage, initializing the fine model's deformation feature grid with the optimized feature grid from the coarse model via interpolation [S1].

**Pseudocode:**

```python
def compute_coarse_geometry_prior(coarse_grid, time_steps, alpha_threshold):
    """
    Computes the bounding box of the dynamic scene using alpha values.
    
    Args:
        coarse_grid: 3D grid of deformation features.
        time_steps: List of time indices t.
        alpha_threshold: Scalar threshold for object classification.
        
    Returns:
        bbox_min: Tuple (x_min, y_min, z_min)
        bbox_max: Tuple (x_max, y_max, z_max)
    """
    min_x, min_y, min_z = infinity
    max_x, max_y, max_z = -infinity
    
    # Iterate over all grid vertices and all time steps
    for v in coarse_grid.vertices:
        is_object = False
        for t in time_steps:
            alpha = coarse_grid.get_alpha(v, t)
            if alpha > alpha_threshold:
                is_object = True
                break # No need to check other times for this vertex
        
        if is_object:
            # Update bounding box with vertex coordinates
            x, y, z = v.coordinates
            min_x = min(min_x, x)
            min_y = min(min_y, y)
            min_z = min(min_z, z)
            max_x = max(max_x, x)
            max_y = max(max_y, y)
            max_z = max(max_z, z)
            
    return (min_x, min_y, min_z), (max_x, max_y, max_z)

def filter_sampled_points(sampled_points, coarse_grid, time_steps, alpha_threshold, module_type):
    """
    Filters out empty points from a ray's sampled points.
    
    Args:
        sampled_points: List of 3D points sampled along rays.
        coarse_grid: Coarse deformation feature grid.
        time_steps: List of time indices t.
        alpha_threshold: Scalar threshold.
        module_type: 'deformation' or 'canonical'.
        
    Returns:
        filtered_points: List of points that are not empty.
    """
    filtered = []
    
    for p in sampled_points:
        keep_point = False
        
        if module_type == 'deformation':
            # Filter if alpha is below threshold for ALL times
            # Keep if alpha > threshold for AT LEAST ONE time
            for t in time_steps:
                alpha = coarse_grid.get_alpha_at_point(p, t)
                if alpha > alpha_threshold:
                    keep_point = True
                    break
        elif module_type == 'canonical':
            # Filter only at canonical time (assume t=0 for canonical)
            alpha = coarse_grid.get_alpha_at_point(p, 0)
            if alpha > alpha_threshold:
                keep_point = True
                
        if keep_point:
            filtered.append(p)
            
    return filtered
```

**Parameters:**
*   **Alpha Threshold:** A predefined scalar value used to distinguish object points from empty space [S1]. The exact value is not specified in the sources, but it must be chosen to balance sensitivity to low-density regions [S1].

**Edge Cases and Pitfalls:**
*   **Low-Density Regions:** Low-density regions (e.g., a white plate on a white background) may be incorrectly filtered out because the image reconstruction error is low even if the learned density is close to zero [S1]. This can result in missing geometry in the final render. This issue can be alleviated by using a background with a different color or disabling the filtering strategy for specific regions [S1].
*   **Static Assumption:** The method assumes empty points are static in the deformation module. If empty space varies significantly over time in a way that affects the background, this assumption may lead to artifacts [S1].

## Subtopics

### Distance Map Acceleration
*   **What it is:** Uses a distance map to skip empty space by checking if a ray is far from any surface.
*   **Difference:** Relies on geometric distance rather than alpha values from a feature grid.
*   **When to choose:** When explicit surface geometry is available or easily approximated.
*   **Link:** [Distance Map Acceleration](972-distance-map-acceleration.md)

### Two-stage Ray Marching with Empty-Space Skipping
*   **What it is:** Uses a coarse stage to identify occupied regions and a fine stage for detailed rendering.
*   **Difference:** Explicitly separates the rendering into two distinct passes with different resolutions.
*   **When to choose:** When high-quality rendering is required for complex scenes with large empty spaces.
*   **Link:** [Two-stage Ray Marching with Empty-Space Skipping](2985-two-stage-ray-marching-with-empty-space-skipping.md)

### Hierarchical Sampling with Occupancy Grid
*   **What it is:** Uses a hierarchical grid structure to efficiently skip empty voxels.
*   **Difference:** Uses a multi-resolution grid hierarchy rather than a single coarse grid with alpha-based filtering.
*   **When to choose:** When the scene has varying levels of detail and empty space distribution is complex.
*   **Link:** [Hierarchical Sampling with Occupancy Grid](3035-hierarchical-sampling-with-occupancy-grid.md)

## Operating characteristics
*   **Time Complexity:** Training and rendering speed are significantly improved compared to models without filtering. The sources state that "NDGV(w/o filter)" has clearly worse training speed, render speed, and PSNR than the full model with filtering [S1].
*   **Memory Complexity:** Reduces the effective volume of the grid in the fine stage by using the coarse geometry prior, leading to lower memory usage for the fine model [S1].
*   **Strengths:**
    *   Accelerates training by reducing MLP queries [S1].
    *   Adapts to dynamic scenes by considering all time steps [S1].
    *   Simple to implement using existing coarse grid infrastructure [S1].
*   **Limitations:**
    *   May filter out low-density objects if the alpha threshold is not carefully tuned [S1].
    *   Requires a coarse grid to be trained first, adding a preprocessing step [S1].
*   **When to use:** When training dynamic neural volumes and computational efficiency is a priority, and the scene has significant empty space.
*   **When not to use:** When the scene contains low-density objects that are visually important but have low alpha values (e.g., transparent or low-contrast objects) [S1].

## Background
*   **Origin:** Proposed by X. Guo et al. in "Neural Deformable Voxel Grid for Fast Optimization of Dynamic View Synthesis" [S1].
*   **History:** The method is part of the Neural Deformable Voxel Grid (NDGV) framework, which aims to optimize dynamic view synthesis efficiently. It builds upon the concept of using coarse grids to guide fine-stage optimization [S1].
*   **Usage:** Used in dynamic view synthesis tasks, particularly for scenes with moving objects and large empty backgrounds [S1].
