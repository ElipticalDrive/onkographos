# Empty Space Map Generation

Also called: Empty Space Skipping Map, Ray Marching with Empty Space Map, Visibility Map Generation

## Overview
Empty Space Map Generation is a preprocessing optimization for volume ray marching that creates a boolean map indicating which voxels contain no visible geometry based on a transfer function threshold [S1, unofficial]. It allows the renderer to skip entire empty regions during ray traversal, significantly reducing the number of density samples and transfer function evaluations [S1, unofficial]. Unlike standard occupancy grids that only mark binary presence, this method integrates the transfer function's opacity/density criteria directly into the skipping logic, ensuring that only voxels contributing to the final image are processed [S1, unofficial].

## How it works
**Inputs:**
- Scalar field data (density values) for a volume of dimensions $W \times H \times D$.
- Transfer function definition (control points and evaluation method).
- Threshold density value ($T$).

**Outputs:**
- `empty_space_map`: A boolean array of size $(W-1) \times (H-1) \times (D-1)$. Each element corresponds to a voxel in the scalar field.

**Data Structures:**
- `empty_space_map`: 3D boolean array. Index $(i, j, k)$ corresponds to the voxel with minimum corner at grid coordinates $(i, j, k)$.
- `tf_vertices`: Temporary array of 8 floats, storing the transfer function output for the 8 vertices of the current voxel.

**Steps:**

1. **Initialize Map:** Allocate `empty_space_map` with dimensions $(W-1) \times (H-1) \times (D-1)$.
2. **Iterate Voxels:** Loop over all voxel indices $i$ from $0$ to $W-2$, $j$ from $0$ to $H-2$, and $k$ from $0$ to $D-2$.
3. **Sample Vertices:** For the current voxel $(i, j, k)$, identify its 8 vertices. The vertex indices are encoded as $v = v_i + v_j \cdot 2 + v_k \cdot 4$, where $v_i, v_j, v_k \in \{0, 1\}$ represent the corner offsets.
4. **Evaluate Transfer Function:** For each vertex $v$, retrieve the scalar field value at the corresponding grid position $(i + v_i, j + v_j, k + v_k)$ and evaluate the transfer function.
   $$ \text{tf\_vertices}[v] = \text{transfer\_function}(\text{field}(i + v_i, j + v_j, k + v_k)) $$
   [S1, unofficial]
5. **Determine Emptiness:** Check if any vertex has a transfer function density value greater than the threshold $T$.
   $$ \text{is\_empty} = \max(\text{tf\_vertices}) \le T $$
   [S1, unofficial]
6. **Store Result:** Set the map value for the current voxel.
   $$ \text{empty\_space\_map}[\text{Offset}(i, j, k)] = \text{is\_empty} $$
   [S1, unofficial]

**Ray Marching Integration:**
When rendering, the ray marcher uses this map to skip empty voxels:
1. Compute current 3D voxel indices $(v_i[0], v_i[1], v_i[2])$ from the ray position $p$.
2. Check `empty_space_map` at these indices.
3. If empty:
   - Compute the voxel minimum ($v_{min}$) and maximum ($v_{max}$) points in world space.
   - Compute the intersection interval $(t_{min}, t_{max})$ of the ray with the voxel bounding box.
   - Advance the ray parameter $t$ by the maximum of $(t_{max} - t)$ and a minimum marching delta to ensure progress and avoid precision stalls.
   $$ t \leftarrow t + \max(t_{max} - t, \delta_{march}) $$
   [S1, unofficial]
4. If not empty, proceed with standard volume integration.

**Parameters:**
- `tolerance` ($T$): Threshold density value. If any vertex of a voxel has a transfer function density $> T$, the voxel is considered non-empty. [S1, unofficial]

**Pitfalls:**
- **Precision Problems:** Computing voxel intersections can suffer from floating-point precision issues, potentially causing the ray to stall or skip incorrectly. The travel value must be clamped using `FMax` to ensure strict progress along the ray. [S1, unofficial]
- **Boundary Conditions:** The map size is $(W-1) \times (H-1) \times (D-1)$, meaning it covers voxels defined by grid points $0$ to $W-1$, etc. Accessing indices outside this range requires careful boundary checks.

**Pseudocode:**

```python
def generate_empty_space_map(field, transfer_function, width, height, depth, threshold):
    """
    Generates a boolean map indicating empty voxels.
    
    Args:
        field: 3D array of scalar values (density).
        transfer_function: Function that takes a scalar value and returns density/opacity.
        width, height, depth: Dimensions of the scalar field grid.
        threshold: Density threshold. Voxels with all vertices <= threshold are empty.
        
    Returns:
        empty_space_map: 3D boolean array of shape (width-1, height-1, depth-1).
    """
    # Initialize map with dimensions (W-1) x (H-1) x (D-1)
    empty_space_map = [[[False for _ in range(depth - 1)] 
                        for _ in range(height - 1)] 
                       for _ in range(width - 1)]
    
    # Iterate over all voxels
    for i in range(width - 1):
        for j in range(height - 1):
            for k in range(depth - 1):
                # Evaluate transfer function at 8 vertices
                tf_values = []
                for vi in [0, 1]:
                    for vj in [0, 1]:
                        for vk in [0, 1]:
                            # Get scalar value at vertex
                            scalar_val = field[i + vi][j + vj][k + vk]
                            # Evaluate transfer function
                            tf_val = transfer_function(scalar_val)
                            tf_values.append(tf_val)
                
                # Determine if voxel is empty
                # If max tf value <= threshold, the voxel is empty
                is_empty = max(tf_values) <= threshold
                
                # Store result
                empty_space_map[i][j][k] = is_empty
                
    return empty_space_map

def ray_march_with_empty_space(ray_origin, ray_direction, empty_space_map, voxel_size, max_t):
    """
    Ray marching step using empty space map for skipping.
    This is a single step illustration, not the full loop.
    """
    t = 0.0
    marching_delta = 0.1 # Example delta
    
    while t < max_t:
        # Compute current voxel indices
        # Assuming ray_origin is at (0,0,0) and voxel_size is uniform
        x = ray_origin.x + ray_direction.x * t
        y = ray_origin.y + ray_direction.y * t
        z = ray_origin.z + ray_direction.z * t
        
        vi = int(x / voxel_size)
        vj = int(y / voxel_size)
        vk = int(z / voxel_size)
        
        # Check bounds
        if not (0 <= vi < len(empty_space_map) and 
                0 <= vj < len(empty_space_map[0]) and 
                0 <= vk < len(empty_space_map[0][0])):
            break
            
        # Check if empty
        if empty_space_map[vi][vj][vk]:
            # Compute voxel bounds in world space
            v_min_x = vi * voxel_size
            v_max_x = (vi + 1) * voxel_size
            v_min_y = vj * voxel_size
            v_max_y = (vj + 1) * voxel_size
            v_min_z = vk * voxel_size
            v_max_z = (vk + 1) * voxel_size
            
            # Compute intersection interval with voxel bounding box
            # Simplified 1D intersection logic for t
            # t_min_voxel = max(t, (v_min - origin) / direction)
            # t_max_voxel = min(max_t, (v_max - origin) / direction)
            
            # Calculate t_enter and t_exit for this voxel
            t_enter = t
            t_exit = max_t
            
            if ray_direction.x != 0:
                t1 = (v_min_x - ray_origin.x) / ray_direction.x
                t2 = (v_max_x - ray_origin.x) / ray_direction.x
                t_enter = max(t_enter, min(t1, t2))
                t_exit = min(t_exit, max(t1, t2))
            
            if ray_direction.y != 0:
                t1 = (v_min_y - ray_origin.y) / ray_direction.y
                t2 = (v_max_y - ray_origin.y) / ray_direction.y
                t_enter = max(t_enter, min(t1, t2))
                t_exit = min(t_exit, max(t1, t2))
                
            if ray_direction.z != 0:
                t1 = (v_min_z - ray_origin.z) / ray_direction.z
                t2 = (v_max_z - ray_origin.z) / ray_direction.z
                t_enter = max(t_enter, min(t1, t2))
                t_exit = min(t_exit, max(t1, t2))
                
            # Advance t by the maximum of (t_exit - t) and marching_delta
            # This ensures progress and avoids precision stalls
            delta = max(t_exit - t, marching_delta)
            t = t + delta
        else:
            # Not empty, perform standard volume integration step
            # (Implementation details of integration are outside scope of this article)
            t += marching_delta
            
    return t
```

## Subtopics

### [Chebyshev Distance Map Empty Space Skipping](3833-chebyshev-distance-map-empty-space-skipping.md)
This method accelerates volume ray casting by pre-computing a Chebyshev distance map from an occupancy map, allowing rays to skip multiple empty blocks in any dimension. It improves upon standard occupancy map skipping by enabling larger, dimension-independent skips, though it requires more complex generation and higher memory overhead.

## Operating characteristics
- **Time Complexity:** Preprocessing is $O(W \cdot H \cdot D)$, requiring one transfer function evaluation per voxel vertex (8 evaluations per voxel). Ray traversal is $O(N_{occupied})$ where $N_{occupied}$ is the number of non-empty voxels intersected by rays.
- **Memory Complexity:** $O(W \cdot H \cdot D)$ bits for the boolean map.
- **Performance:** Significant speedup in sparse volumes where large empty regions exist. The reduction in transfer function evaluations and density samples is proportional to the volume of empty space.
- **Strengths:** Simple to implement, low memory overhead compared to distance maps, effective for sparse data.
- **Limitations:** Only skips entire voxels; does not skip partial empty regions within a voxel. Precision issues can arise if not handled carefully (e.g., clamping).
- **When to use:** Sparse volumes with large empty regions, real-time rendering where preprocessing cost is acceptable.
- **When not to use:** Dense volumes with little empty space, or when partial voxel skipping is required (use Distance Map Acceleration instead).

## Background
Originating from early volume rendering optimizations, this method is a direct application of occupancy grids to ray marching. It is commonly found in GPU-based volume renderers where transfer function evaluation is expensive. The specific implementation details described here are derived from open-source CUDA volume rendering projects.
