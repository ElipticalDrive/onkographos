# Two-stage Ray Marching with Empty-Space Skipping

Also called: Occupancy Map Empty Space Skipping, Occupancy-based early exit, Simple occupancy map traversal, Two-phase volumetric rendering

## Overview
Two-stage Ray Marching with Empty-Space Skipping is a volume rendering optimization that accelerates ray traversal by decoupling the search for volume entry from the density sampling process [S2, unofficial]. It solves the problem of wasting computational resources evaluating complex density functions in empty space by using a precomputed, lower-resolution **Occupancy Map** to skip over empty blocks [S1]. Unlike its sibling [Distance Map Acceleration](972-distance-map-acceleration.md), which uses distance fields to estimate skip distances, or [Hierarchical Sampling with Occupancy Grid](3035-hierarchical-sampling-with-occupancy-grid.md), which may involve more complex hierarchical structures, this method relies on a simple binary occupancy grid and a two-phase loop structure [S1][S2, unofficial]. It sets itself apart by explicitly separating the "find entry" phase (Stage 1) from the "sample density" phase (Stage 2), allowing for aggressive skipping in empty regions and precise sampling only where necessary [S2, unofficial].

## How it works
The method operates in two distinct stages. Stage 1 uses the Occupancy Map to rapidly advance the ray until it hits an occupied block. Stage 2 performs standard volumetric ray marching within that occupied region.

### Inputs and Outputs
*   **Inputs:**
    *   Ray origin $\mathbf{o}$ and direction $\mathbf{d}$ in world space.
    *   Volume data (density field) at high resolution $d_{\text{vol}}$.
    *   Occupancy Map: A 3D texture/grid of resolution $d_{\text{occ}} = (d_x/B, d_y/B, d_z/B)$, where $B$ is the block size (typically $4^3$) [S1]. Each voxel stores a binary flag: $1$ if the corresponding block contains non-empty data, $0$ otherwise [S1].
    *   Camera matrices: Inverse projection matrix $M_{\text{invProj}}$ and camera-to-world matrix $M_{\text{camToWorld}}$ [S2, unofficial].
    *   Parameters: `stepSize` (distance per sample), `_RayMaxLength` (max traversal distance), `stage2StepMax` (max samples in Stage 2) [S2, unofficial].
*   **Outputs:**
    *   Final accumulated color and opacity for the pixel.

### Data Structures
*   **Occupancy Map:** 3D array or texture. Indexing is typically row-major. For a voxel at $(x, y, z)$, the 1D index is $z \cdot (W \cdot H) + y \cdot W + x$, where $W, H$ are the width and height of the occupancy map [S2, unofficial].
*   **Ray State:**
    *   `length`: Current distance along the ray from origin.
    *   `positionWS`: Current world-space position ($\mathbf{o} + \text{length} \cdot \mathbf{d}$).
    *   `smokeValue`: Result of occupancy query (0, 1, or -1 for out-of-bounds) [S2, unofficial].

### Numbered Steps

1.  **Ray Initialization:**
    *   Compute ray direction $\mathbf{d}$ from screen UV coordinates $(u, v)$:
        $$ \mathbf{d} = \text{normalize}\left( M_{\text{camToWorld}} \cdot M_{\text{invProj}} \cdot [2u-1, 2v-1, 0, 1]^T \right) $$
        [S2, unofficial]
    *   Initialize `length = 0`, `smokeValue = -1` [S2, unofficial].

2.  **Stage 1: Empty Space Skipping (Occupancy Lookup):**
    *   Loop while `smokeValue <= 0` AND `length < _RayMaxLength`:
        a.  Calculate world position: $\mathbf{p} = \mathbf{o} + \text{length} \cdot \mathbf{d}$.
        b.  Query the Occupancy Map at $\mathbf{p}$.
            *   Convert $\mathbf{p}$ to occupancy map coordinates $u_{\text{occ}}$.
            *   Sample the binary flag. If the flag is $0$, the block is empty.
            *   If the flag is $1$, the block is occupied. Set `smokeValue = 1` and break loop.
            *   If out of bounds, return $-1$ [S2, unofficial].
        c.  **Skip Calculation:** If empty, calculate the number of steps $\Delta i$ to the next occupied block boundary using the occupancy map coordinate change $\Delta u_{\text{occ}}$ [S1]:
            $$ \Delta \mathbf{i} = \left\lceil \frac{\text{step}(\Delta \mathbf{u}_{\text{occ}}) + \lfloor \mathbf{u}_{\text{occ}} \rfloor - \mathbf{u}_{\text{occ}}}{\Delta \mathbf{u}_{\text{occ}}} \right\rceil $$
            where $\text{step}(x)$ is the Heaviside step function ($1$ if $x>0$, else $0$) [S1].
            $$ \Delta i = \max(\min(\Delta \mathbf{i}), 1) $$
            [S1]
        d.  Advance `length` by $\Delta i \cdot \text{stepSize}$ [S1].

3.  **Stage 1 Exit Check:**
    *   If `smokeValue <= 0` after exceeding `_RayMaxLength`, the ray missed the volume. Output black/transparent color [S2, unofficial].

4.  **Stage 2: Density Sampling:**
    *   If `smokeValue == 1` (entry detected):
        a.  **Backward Adjustment:** To account for interpolation halos or boundary isosurfaces, decrement the step count or adjust position slightly to ensure the ray samples at least one voxel into the occupied region. Specifically, decrement the step index by $\Delta i_{\text{backward}} = -\lfloor f \rfloor$ where $f$ is the sampling factor, ensuring the ray goes back at least one voxel length [S1].
        b.  Initialize `stage2StepNum = 0`, `accumulatedDensity = 0` [S2, unofficial].
        c.  Loop while `stage2StepNum < stage2StepMax`:
            i.  Calculate `samplePoint = o + length * d`.
            ii. Compute density: $\rho = \text{sampleDensity}(\text{samplePoint})$.
                *   Note: A common implementation flaw is sampling noise using screen UVs instead of world position, causing noise to "swim" with the camera [S2, unofficial]. Correct implementation uses world position [S2, unofficial].
                *   Formula example: $\rho = 1 - \text{smoothstep}(\text{Smoothing}, 1.0, \frac{\|\text{samplePoint} - \text{SmokeOrigin}\|}{\text{SmokeRadius}})$ [S2, unofficial].
            iii. Add to `accumulatedDensity` scaled by `_DensityMult`.
            iv. Increment `length` by `stepSize`.
            v. Increment `stage2StepNum`.
        d.  **Resuming Skipping:** After Stage 2, if the ray is still within the volume bounds and the previously sampled voxel had zero opacity, resume empty space skipping by checking the Occupancy Map again at the new position [S1].

5.  **Compositing:**
    *   Accumulate color and opacity using standard front-to-back or back-to-front compositing based on the density values collected in Stage 2 [S2, unofficial].

### Pseudocode

```python
def two_stage_ray_marching(ray_origin, ray_direction, occupancy_map, volume_params):
    """
    ray_origin: float3
    ray_direction: float3 (normalized)
    occupancy_map: 3D array of integers (0 or 1)
    volume_params: dict containing stepSize, rayMaxLength, stage2StepMax, etc.
    """
    length = 0.0
    step_size = volume_params['stepSize']
    ray_max_length = volume_params['rayMaxLength']
    stage2_step_max = volume_params['stage2StepMax']
    
    # Precompute occupancy map step size in world space
    # d_vol is volume resolution, B is block size
    # d_occ = d_vol / B
    # delta_u_occ = (d_vol / B) * delta_t_vol
    # Assuming step_size corresponds to delta_t_vol in volume space
    delta_u_occ = (volume_params['d_vol'] / volume_params['B']) * step_size
    
    # Stage 1: Find Entry
    while length < ray_max_length:
        # Calculate current world position
        pos_ws = ray_origin + length * ray_direction
        
        # Convert to occupancy map coordinates
        # u_occ = (d_vol / B) * t (relative to volume origin)
        # Assuming pos_ws is already in volume space or offset is handled
        u_occ = (volume_params['d_vol'] / volume_params['B']) * (pos_ws - volume_params['volume_origin'])
        
        # Sample occupancy map
        occ_val = sample_occupancy_map(u_occ, occupancy_map)
        
        if occ_val == 1:
            # Found occupied block
            break
        elif occ_val == 0:
            # Empty block, calculate skip
            # Vectorized step calculation
            # step_func is Heaviside step function
            delta_i_vec = ceil((step_func(delta_u_occ) + floor(u_occ) - u_occ) / delta_u_occ)
            delta_i = max(min(delta_i_vec), 1)
            
            # Advance length
            length += delta_i * step_size
        else:
            # Out of bounds or error
            return (0.0, 0.0, 0.0, 0.0) # Black/Transparent
            
    if length >= ray_max_length:
        return (0.0, 0.0, 0.0, 0.0) # Missed volume

    # Stage 2: Sample Density
    accumulated_color = (0.0, 0.0, 0.0)
    accumulated_opacity = 0.0
    stage2_step_num = 0
    
    # Backward adjustment to ensure we sample inside the block
    # f is sampling factor, typically 1.0 for voxel centers
    # delta_i_backward = -floor(f)
    # This effectively means we might need to step back slightly or ensure first sample is valid
    # In practice, this often means ensuring the first sample in Stage 2 is within the block
    
    while stage2_step_num < stage2_step_max:
        sample_point = ray_origin + length * ray_direction
        
        # Sample density from volume
        density = sample_volume_density(sample_point, volume_params)
        
        # Compositing
        alpha = 1.0 - exp(-density * volume_params['densityMult'])
        color = sample_color(sample_point, volume_params)
        
        # Front-to-back compositing
        weight = alpha * (1.0 - accumulated_opacity)
        accumulated_color += color * weight
        accumulated_opacity += weight
        
        if accumulated_opacity >= 1.0:
            break
            
        length += step_size
        stage2_step_num += 1
        
        # Check if we should resume skipping (if density was 0 and we are still in volume)
        if density == 0:
            # Re-evaluate occupancy at new position
            u_occ_new = (volume_params['d_vol'] / volume_params['B']) * (sample_point - volume_params['volume_origin'])
            if sample_occupancy_map(u_occ_new, occupancy_map) == 0:
                # Resume skipping logic here if desired, or just continue Stage 2 loop
                # The prompt implies resuming skipping only when u_occ changes and prev was zero
                pass 

    return (accumulated_color, accumulated_opacity)

def sample_occupancy_map(u_occ, occ_map):
    # Convert u_occ to integer indices
    idx = floor(u_occ)
    # Check bounds
    if not in_bounds(idx, occ_map.shape):
        return -1
    return occ_map[idx.x, idx.y, idx.z]

def step_func(x):
    return 1.0 if x > 0 else 0.0
```

### Parameters and Typical Values
*   **Block Size ($B$):** Typically $4^3$ or $8^3$. Larger $B$ skips more empty voxels but reduces precision near occupied regions [S1].
*   **Step Size:** Often $0.2$ or $0.5$ world units, depending on resolution [S2, unofficial].
*   **Stage 2 Max Steps:** Often fixed at $40$ in simple implementations, though this can cause bleeding if volume bounds are not checked [S2, unofficial].

### Edge Cases and Pitfalls
*   **Interpolation Halos:** Trilinear interpolation of volume data can cause opacity to appear in empty blocks near occupied boundaries. The backward adjustment step ($\Delta i_{\text{backward}}$) is necessary to ensure the ray samples into the occupied region correctly [S1].
*   **Axis-Aligned Rays:** For rays aligned with axes, $\Delta u_j$ can be infinite or zero, requiring clamping $\Delta i$ to a minimum of $1$ [S1].
*   **Stage 2 Bounds Ignorance:** If Stage 2 runs for a fixed number of steps without checking volume bounds, smoke/density may "bleed" past the volume boundary [S2, unofficial].
*   **Y-Axis Bounds Check Asymmetry:** Some implementations use asymmetric bounds checks (e.g., $y < -E + E$ and $y > E + E$), which anchors the volume at ground level but is prone to misinterpretation [S2, unofficial].
*   **Variable Shadowing:** In GPU shaders, using `length` as a variable name can shadow the intrinsic `length()` function, causing compilation errors or logical bugs [S2, unofficial].
*   **Noise Sampling:** Sampling noise using screen UVs instead of world position causes the noise pattern to move with the camera ("swimming") rather than being attached to the volume [S2, unofficial].

## Subtopics

### [PDF Light Weight Space Leaping](5848-pdf-light-weight-space-leaping.md)
PDF Light Weight Space Leaping (LWSL) is a space-leaping acceleration technique for volume rendering that exploits ray coherence to skip empty space without requiring pre-processing or 3D data structures. It divides image-plane rays into two groups: **detector rays**, which perform full ray casting to determine the distance to the first non-empty cell, and **space leap rays**, which are accelerated by skipping empty space based on information propagated from detector rays. Unlike data-structure-based methods (e.g., DFB) or temporal coherence techniques, LWSL is an image-space method with memory and run-time complexity proportional only to the image size, making it independent of dataset complexity and transfer function changes.

### Volume Occupancy Map Skip
Volume Occupancy Map Skip is a technique to skip empty voxels (e.g., sparse clouds) by using a preprocessed Volume Occupancy Map. If the current voxel is detected as empty, traversal jumps directly to the next non-empty voxel [S3, unofficial]. In a medical imaging project, this technique increased rendering frame rate by 3.2x [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** Stage 1 is $O(1)$ per block skip, proportional to the number of empty blocks traversed. Stage 2 is $O(N)$ where $N$ is the number of samples in occupied regions. Overall, it is significantly faster than brute-force marching in sparse volumes.
*   **Memory Complexity:** Requires storage for the Occupancy Map, which is $1/B^3$ the size of the full volume data [S1].
*   **Measured Performance:** In a medical imaging project, using a Volume Occupancy Map for skipping increased rendering frame rate by 3.2x [S3, unofficial].
*   **Strengths:** Simple to implement; effective for sparse volumes; low memory overhead compared to hierarchical structures like Octrees [S1][S3, unofficial].
*   **Limitations:** Precision loss near occupied regions if $B$ is too large; requires precomputation of the occupancy map; Stage 2 may bleed if bounds are not checked [S1][S2, unofficial].
*   **When to Use:** Sparse volumetric data (e.g., clouds, smoke, medical CT with large empty regions) where precomputation cost is acceptable [S1][S3, unofficial].
*   **When Not to Use:** Dense volumes where most rays hit occupied blocks immediately, as the overhead of occupancy lookup may not be justified [S1].

## Background
The method originates from the need to accelerate ray casting of volumetric images, particularly in the context of isosurface rendering and volume visualization [S1]. The concept of using an occupancy map for empty space skipping was detailed in "Efficient ray casting of volumetric images using distance maps for empty space skipping" [S1]. The two-stage approach, explicitly separating entry detection from density sampling, is exemplified in practical implementations such as the "volumetric-smoke-raymarching" project [S2, unofficial]. The technique is widely used in medical imaging and real-time rendering of atmospheric effects [S3, unofficial].
