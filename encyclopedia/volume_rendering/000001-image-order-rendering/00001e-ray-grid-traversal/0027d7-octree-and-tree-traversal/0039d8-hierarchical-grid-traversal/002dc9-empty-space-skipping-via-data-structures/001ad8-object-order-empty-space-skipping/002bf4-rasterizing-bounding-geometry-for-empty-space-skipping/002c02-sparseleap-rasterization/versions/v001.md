# SparseLeap Rasterization

Also called: SparseLeap, SparseLeap rasterization details

## Overview
SparseLeap is a method for efficient empty space skipping in very large, sparse volume data, such as terabyte-sized microscopy volumes, by exploiting hardware-accelerated rasterization to avoid hierarchy traversal on the GPU [S2, unofficial]. It solves the problem of fragmented space subdivisions making empty regions hard to skip and the infeasibility of pre-computing well-adapted space subdivisions due to frequent changes in active objects [S2, unofficial]. Unlike standard octree empty space skipping, SparseLeap scales better to large, sparse data by moving the major cost of empty space skipping into a rasterization stage that produces per-pixel lists of non-empty ray segments [S2, unofficial]. It is agnostic of the underlying data structure used for managing volume data, such as page-table hierarchies or octrees [S1, unofficial].

## How it works
SparseLeap operates in two main stages: a preprocessing/rasterization stage and a ray-casting stage [S2, unofficial].

**Inputs and Outputs:**
*   **Input:** A lazily constructed occupancy-histogram tree where each node is classified as empty, non-empty, or unknown [S1, unofficial]. A set of fine-grained, view-independent bounding boxes representing the non-empty regions [S2, unofficial].
*   **Output:** A per-pixel ordered list of non-empty ray segments (stabbing boundary faces) for the ray-casting stage [S2, unofficial].

**Data Structures:**
*   **Occupancy-Histogram Tree:** Each node holds an occupancy class:
    *   `empty`: The node is completely empty.
    *   `non-empty`: The node contains non-empty data.
    *   `unknown`: Information is not yet known [S1, unofficial].
*   **Bounding Boxes:** View-independent bounding boxes generated from the non-empty nodes of the tree [S2, unofficial].
*   **Ray Segment List:** For each pixel, an ordered list of bounding box faces that the viewing ray stabs, representing non-empty regions along the ray [S2, unofficial].

**Steps:**

1.  **Generate Occupancy Geometry:** Construct the occupancy-histogram tree lazily during rendering. Identify nodes classified as `non-empty` [S1, unofficial].
2.  **Create Bounding Boxes:** Generate fine-grained, view-independent bounding boxes for the `non-empty` nodes [S2, unofficial].
3.  **Rasterization Stage:**
    *   Transform the bounding boxes into screen space [S2, unofficial].
    *   Rasterize the bounding boxes using hardware-accelerated rasterization [S2, unofficial].
    *   For each pixel, compute an ordered list of the stabbing boundary faces [S2, unofficial]. This list identifies non-empty regions along the ray [S2, unofficial].
    *   Exploit frame coherence by re-using the same bounding boxes unless the set of active objects changes [S2, unofficial].
4.  **Ray-Casting Stage:**
    *   Perform ray casting independently for each pixel [S2, unofficial].
    *   Use the pre-computed ray segment list to leap over empty space without hierarchy traversal [S2, unofficial].
    *   Sample the non-empty volume data only within the regions identified by the ray segment list [S2, unofficial].
5.  **Color Calculation:** Apply a simple analytical lighting model to each intersection of the ray and cell [S2, unofficial].

## Background
SparseLeap was proposed by Markus Hadwiger, Ali K Al-Awami, Johanna Beyer, and Hanspeter Pfister in 2017 [S2, unofficial]. It addresses the challenges of rendering terabyte-sized microscopy volumes, which often contain many fine and intricate structures, making efficient empty space skipping crucial [S2, unofficial]. The method was developed to handle fragmented space subdivisions and frequent changes in active objects, which make pre-computing well-adapted space subdivisions unfeasible [S2, unofficial].
