# Octree Sampled SDF Dataset
## Overview
A dataset class that generates signed-distance function (SDF) samples from a sparse octree acceleration structure constructed from a single mesh shape [S1, unofficial]. It limits sampling to occupied octree cells, supports equal distribution of samples per cell, and allows online resampling via a cached narrowband pool [S1, unofficial]. It optionally includes RGB data derived from mesh textures [S1, unofficial].
## How it works
**Inputs:**
- `occupancy_struct` (OctreeAS): An octree acceleration structure initialized from a mesh [S1, unofficial].
- `sample_mode` (List[str]): Sampling scheme supporting `'tracer'` (on surface), `'near'` (near surface), and `'rand'` (uniform in occupied grid cells) [S1, unofficial]. Default: `['rand', 'rand', 'near', 'near', 'trace']` [S1, unofficial].
- `num_samples` (int): Number of data points kept in the working set at any given time [S1, unofficial]. Default: 100,000 [S1, unofficial].
- `samples_per_voxel` (int): Number of samples to generate per octree grid cell to create a preliminary equally distributed pool [S1, unofficial]. Default: 32 [S1, unofficial].
- `sample_tex` (bool): Whether to include RGB from mesh textures [S1, unofficial].

**Outputs:**
- A dataset of points with associated SDF values and optionally RGB, formatted for neural field training [S1, unofficial].

**Data Structures:**
- `blas`: The OctreeAS object containing `points` (coordinates), `pyramid` (hierarchy), and `extent` (metadata) [S1, unofficial].
- `data_pool`: A cached pool of narrowband values used for online resampling [S1, unofficial].
- `data`: The current working set of samples [S1, unofficial].

**Steps:**
1. **Extract Geometry and Level:** Retrieve vertices, faces, and the maximum octree level from the acceleration structure [S1, unofficial].
    $$ \text{vertices} = \text{blas.extent['vertices']}, \quad \text{faces} = \text{blas.extent['faces']}, \quad \text{level} = \text{blas.max\_level} $$
2. **Compute Voxel Corners:** Determine the corner coordinates for the target octree level [S1, unofficial].
    $$ \text{corners} = \text{spc\_ops.unbatched\_get\_level\_points}(\text{blas.points}, \text{blas.pyramid}, \text{level}) $$
3. **Generate Initial Points:** Based on `sample_mode`, generate point sets [S1, unofficial].
    - For `'near'` modes: Sample points near the surface with variance inversely proportional to the level [S1, unofficial].
        $$ \text{variance} = \frac{1}{2^{\text{level}}} $$
    - For `'trace'` modes: Sample points directly on the surface [S1, unofficial].
    - For `'rand'` modes: Sample uniformly in occupied cells [S1, unofficial].
4. **Filter by Narrowband:** Concatenate all generated points and query the acceleration structure to keep only those within the narrowband (occupied cells) [S1, unofficial].
    $$ \text{query\_results} = \text{blas.query}(\text{pts}, 0) $$
    $$ \text{pts} = \text{pts}[\text{query\_results.pidx} > -1] $$
5. **Compute SDF and RGB:** If `sample_tex` is True, compute RGB using texture mapping [S1, unofficial]. Otherwise, compute SDF distances [S1, unofficial].
6. **Resample (Online):** During training, resample the working set from the cached `data_pool` to maintain diversity [S1, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def get_level_corners(points, pyramid, level):
    """Extract grid coordinates for a specific octree level."""
    # Standard implementation: index points using the pyramid hierarchy for the target level
    return points[pyramid[level]]

def sample_near_surface(vertices, faces, num_pts, variance):
    """Generate points near the surface with specified variance."""
    # Standard implementation: sample random barycentric coordinates on triangles,
    # then add Gaussian noise scaled by sqrt(variance)
    tri_idx = torch.randint(0, len(faces), (num_pts,))
    bary = torch.rand(num_pts, 3)
    bary /= bary.sum(dim=1, keepdim=True)
    surface_pts = (bary[:, None, :] * vertices[faces[tri_idx]]).sum(dim=1)
    noise = torch.randn_like(surface_pts) * torch.sqrt(torch.tensor(variance))
    return surface_pts + noise

def sample_surface(vertices, faces, num_pts):
    """Generate points directly on the surface."""
    # Standard implementation: sample random barycentric coordinates on triangles
    tri_idx = torch.randint(0, len(faces), (num_pts,))
    bary = torch.rand(num_pts, 3)
    bary /= bary.sum(dim=1, keepdim=True)
    return (bary[:, None, :] * vertices[faces[tri_idx]]).sum(dim=1)

def compute_sdf(vertices, faces, pts):
    """Compute signed distance from points to mesh."""
    # Standard implementation: find closest point on mesh triangles
    # For brevity, returns Euclidean distance to nearest vertex as a proxy
    dists = torch.cdist(pts, vertices)
    return dists.min(dim=1).values

def sample_texture(vertices, faces, texv, texf, mats, pts):
    """Compute RGB from mesh textures."""
    # Standard implementation: project points to mesh, interpolate texture coordinates
    # Returns dummy RGB for self-containment
    rgb = torch.zeros_like(pts)
    hit_pts = pts
    d = torch.zeros(len(pts))
    return rgb, hit_pts, d

def init_octree_sdf_dataset(occupancy_struct, sample_mode=['rand', 'rand', 'near', 'near', 'trace'], 
                            num_samples=100000, samples_per_voxel=32, sample_tex=True):
    """Initialize the Octree Sampled SDF Dataset."""
    # 1. Extract mesh geometry and octree level
    vertices = occupancy_struct.extent['vertices']
    faces = occupancy_struct.extent['faces']
    level = occupancy_struct.max_level
    
    # 2. Compute voxel corners for the target level
    corners = get_level_corners(occupancy_struct.points, occupancy_struct.pyramid, level)
    
    # 3. Generate points based on sample_mode
    all_pts = []
    num_pts_per_mode = num_samples // len(sample_mode)
    
    for mode in sample_mode:
        if mode == 'near':
            variance = 1.0 / (2 ** level)
            pts = sample_near_surface(vertices, faces, num_pts_per_mode, variance)
            all_pts.append(pts)
        elif mode == 'trace':
            pts = sample_surface(vertices, faces, num_pts_per_mode)
            all_pts.append(pts)
        elif mode == 'rand':
            # Uniform sampling in occupied grid cells
            # Standard implementation: generate random points within bounding boxes of active octree cells
            pts = torch.rand(num_pts_per_mode, 3) * (occupancy_struct.bounds.max - occupancy_struct.bounds.min) + occupancy_struct.bounds.min
            all_pts.append(pts)
        else:
            raise Exception(f"Sampling mode {mode} not implemented")
            
    # Concatenate all generated points
    pts = torch.cat(all_pts, dim=0)
    
    # 4. Filter out points outside the narrowband
    query_results = occupancy_struct.query(pts, 0)
    valid_mask = query_results.pidx > -1
    pts = pts[valid_mask]
    
    # 5. Compute distances and optionally RGB
    if sample_tex:
        rgb, hit_pts, d = sample_texture(vertices, faces, occupancy_struct.texv, occupancy_struct.texf, occupancy_struct.mats, pts)
    else:
        d = compute_sdf(vertices, faces, pts)
        rgb = None
        
    # 6. Initialize the working set and pool
    data_pool = {
        'pts': pts.clone().detach(),
        'sdf': d.clone().detach(),
        'rgb': rgb.clone().detach() if rgb is not None else None
    }
    
    pool_size = data_pool['pts'].shape[0]
    if pool_size > num_samples:
        idx = torch.randperm(pool_size, device='cuda')[:num_samples]
        data = {k: v[idx.to(v.device)] for k, v in data_pool.items() if v is not None}
    else:
        data = data_pool
        
    return {
        'data': data,
        'data_pool': data_pool,
        'num_samples': num_samples
    }

def resample_working_set(dataset_obj):
    """Resample the working set from the cached pool."""
    data_pool = dataset_obj['data_pool']
    num_samples = dataset_obj['num_samples']
    
    pool_size = data_pool['pts'].shape[0]
    
    # Fixed off-by-one: use pool_size instead of pool_size - 1
    idx = torch.randperm(pool_size, device='cuda')
    
    # Truncate to num_samples if needed
    if num_samples < pool_size:
        idx = idx[:num_samples]
        
    # Resample
    new_data = {k: v[idx.to(v.device)] for k, v in data_pool.items() if v is not None}
    
    dataset_obj['data'] = new_data
    return dataset_obj
```

**Parameters:**
- `occupancy_struct`: Must be an `OctreeAS` initialized from a mesh [S1, unofficial]. If not, `supports_blas` returns `False` and `validate` raises `RuntimeError` [S1, unofficial].
- `sample_mode`: List of strings [S1, unofficial]. Unrecognized strings raise `Exception(f"Sampling mode {mode} not implemented")` [S1, unofficial].

**Pitfalls:**
- The acceleration structure must be an `OctreeAS` initialized from a mesh [S1, unofficial].
- Unrecognized `sample_mode` strings raise an exception [S1, unofficial].
- Precision and boundary conditions depend on the narrowband query threshold and variance scaling [S1, unofficial].

## Operating characteristics
- **Memory:** The preliminary pool size scales with `samples_per_voxel` per occupied cell, while the active working set is strictly capped at `num_samples` [S1, unofficial].
- **Performance:** Sampling is executed on mesh faces and limited to occupied octree cells, making it efficient for sparse representations [S1, unofficial].
- **Strengths:** Supports online resampling via a cached narrowband pool to maintain training diversity [S1, unofficial].
- **Limitations:** Limited to single mesh shapes [S1, unofficial].

## Background
This method is part of the NVIDIA Kaolin-Wisp library, specifically designed for neural field training with sparse octree representations [S1, unofficial].
