# Bounding-Sphere Tree Traversal with Frame-Rate Control

Also called: Adaptive Tree Traversal with Frame-Rate Control, Visibility Culling Tests

## Overview
This method traverses hierarchical bounding-sphere trees (specifically Shell and Solid structures) to render volumetric data as splats, using adaptive frame-rate control to dynamically adjust rendering fidelity [S1, unofficial]. It distinguishes itself from sibling methods by decoupling geometric culling from performance management, using global pixel-size thresholds ($\delta_r, \delta_b$) rather than fixed geometric tolerances to determine traversal depth [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Root node of the bounding-sphere tree; current frame-rate measurement; global parameters $\delta_r$ (minimum regular splat size) and $\delta_b$ (minimum boundary splat size) [S1, unofficial].
*   **Output:** Rendered splats for visible nodes; updated $\delta_r, \delta_b$ values for the next frame [S1, unofficial].

**Data Structures:**
*   **Bounding-Sphere Tree:** Nodes store bounding sphere attributes (radius, center) and type (Shell, Solid, Leaf, Regular, Boundary) [S1, unofficial].
*   **Attributes:** Stored in a breath-first layout to enable progressive loading and fast on-the-fly decompression via table lookups during traversal [S1, unofficial].

**Steps:**
1.  **Frame-Rate Feedback:** Measure the current frame-rate. If it is too low, smoothly increase $\delta_r$ and $\delta_b$. If the frame-rate is too high *after* a fully completed traversal, allow $\delta_r$ and $\delta_b$ to decrease [S1, unofficial].
2.  **Traversal Initiation:** Call `TraverseTree` on the root node [S1, unofficial].
3.  **Culling Tests:** For each child of the current node, perform visibility culling:
    *   **View-Frustum Culling:** If the bounding sphere is completely outside the frustum, ignore the node and all children. If it intersects any frustum plane, traverse to children. If completely inside, disable frustum culling for its children [S1, unofficial].
    *   **Back-Face Culling (Shell):** Use hierarchically encoded normal vectors and bounding normal cones to eliminate branches where all nodes point away from the camera [S1, unofficial].
    *   **Back-Face Culling (Solid):** Cannot be performed hierarchically during traversal due to lack of normal information (depends on CSG probe). Perform back-face culling on individual Solid splats using normals derived from the CSG probe before rendering [S1, unofficial].
    *   **Occlusion Culling:** Hierarchical occlusion is not performed during traversal. Instead, enable the hardware z-buffer algorithm for occlusion culling [S1, unofficial].
4.  **Splat Size Calculation:** Calculate the screen size $S$ of the child's bounding sphere in pixels [S1, unofficial].
5.  **Node Handling:**
    *   If the child is a **Leaf Node**: Render it as a splat of size $S$ pixels [S1, unofficial].
    *   If the child is a **Regular Node** and $S < \delta_r$: Render it as a splat of size $\delta_r$ pixels [S1, unofficial].
    *   If the child is a **Boundary Node** and $S < \delta_b$: Render it as a splat of size $\delta_b$ pixels [S1, unofficial].
    *   Otherwise: Recursively call `TraverseTree(child)` [S1, unofficial].

**Pseudocode:**
```python
# Global parameters
delta_r = 1.0  # Minimum regular splat size in pixels
delta_b = 1.0  # Minimum boundary splat size in pixels

def update_frame_rate_control(current_frame_rate, traversal_completed):
    """
    Adjusts delta_r and delta_b based on frame rate feedback.
    Note: Decrease only allowed after a fully completed traversal.
    """
    if current_frame_rate < threshold_low:
        delta_r = smooth_increase(delta_r)
        delta_b = smooth_increase(delta_b)
    elif current_frame_rate > threshold_high and traversal_completed:
        delta_r = smooth_decrease(delta_r)
        delta_b = smooth_decrease(delta_b)

def traverse_tree(node):
    """
    Recursively traverses the bounding-sphere tree.
    Returns True if the entire subtree was traversed (for frame-rate control).
    """
    traversal_completed = True
    
    for child in node.children:
        # 1. Culling Tests
        if not passes_view_frustum_culling(child):
            continue
        if node.type == "Shell" and passes_back_face_culling_shell(child):
            continue
        # Solid back-face culling is deferred to splat rendering
        
        # 2. Attribute Decompression
        # Fast on-the-fly table lookup to decompress bounding sphere attributes
        sphere = decompress_attributes(child)
        
        # 3. Screen Size Calculation
        S = calculate_screen_size_pixels(sphere)
        
        # 4. Node Handling
        if child.is_leaf:
            render_splat(child, size=S)
        elif child.is_regular and S < delta_r:
            render_splat(child, size=delta_r)
        elif child.is_boundary and S < delta_b:
            render_splat(child, size=delta_b)
        else:
            # Recurse
            if not traverse_tree(child):
                traversal_completed = False
                
    return traversal_completed

def render_volumetric_data():
    """
    Main entry point for a frame.
    """
    current_frame_rate = measure_frame_rate()
    traversal_completed = traverse_tree(root_node)
    update_frame_rate_control(current_frame_rate, traversal_completed)
```

**Parameters:**
*   $\delta_r$: Global minimum regular splat size in pixels [S1, unofficial].
*   $\delta_b$: Global minimum boundary splat size in pixels [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Parameter Adjustment Constraint:** $\delta_r$ and $\delta_b$ are only allowed to decrease after a fully completed tree traversal has led to too high frame-rates. This prevents oscillation during partial traversals [S1, unofficial].
*   **Solid Back-Face Culling:** Cannot be performed hierarchically during traversal because Solid nodes lack normal information during traversal (it depends on the CSG probe). Back-face culling must be performed per-splat using normals from the CSG probe [S1, unofficial].
*   **Occlusion Culling:** Hierarchical occlusion culling is hard for point-based primitives. The method relies on hardware z-buffering rather than tree-based occlusion [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the tree depth and the number of visible nodes. Frame-rate control adapts the number of rendered splats by adjusting $\delta_r$ and $\delta_b$, effectively limiting the number of leaf nodes processed [S1, unofficial].
*   **Memory Complexity:** Uses breath-first storage for progressive loading, allowing only parts of the data structure to be loaded into physical memory during traversal [S1, unofficial].
*   **Strengths:** Real-time performance is guaranteed through adaptive refinement. Fast on-the-fly decompression and hierarchical culling tests (frustum, back-face) effectively skip invisible branches [S1, unofficial].
*   **Limitations:** Occlusion culling is not hierarchical, relying on hardware z-buffering. Back-face culling for Solid nodes is not hierarchical [S1, unofficial].

## Background
The method was introduced by Museth and Lombeyna in "TetSplat: Real-time Rendering and Volume Clipping of Large Volumetric Data Sets" (2004) [S1, unofficial]. It was designed to enable real-time rendering and dynamic volumetric clipping of large datasets using Shell and Solid bounding-sphere tree structures [S1, unofficial].
