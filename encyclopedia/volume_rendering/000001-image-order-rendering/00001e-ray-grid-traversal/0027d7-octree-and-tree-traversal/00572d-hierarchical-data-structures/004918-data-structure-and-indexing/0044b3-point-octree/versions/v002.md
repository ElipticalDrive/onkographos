# Point Octree

## Overview
A Point Octree is a recursive hierarchical data structure designed to manage a dynamic set of 3D points, supporting insertion, removal, retrieval, movement, and spatial queries such as nearest neighbor and radius search [S1, unofficial]. It stores points in parallel arrays within leaf octants and dynamically subdivides nodes when capacity limits are reached [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of 3D points $\mathbf{p}_i$ with associated user data $D_i$.
*   **Output:** A tree structure enabling spatial queries and dynamic updates.

**Data Structures:**
The tree consists of nodes (octants). Each node contains:
*   `children`: An array of up to 8 child octants (or `null` if leaf).
*   `data`: A `PointData<T>` object (or `null` if internal node).
*   `PointData<T>` layout: Two parallel arrays:
    *   `points: Vector3[]`: Stores the coordinates of points in this leaf.
    *   `data: T[]`: Stores the associated user data for each point.

**Parameters:**
*   `maxPoints`: Maximum number of points allowed in a leaf before triggering a split [S1, unofficial].
*   `maxDepth`: Hard limit on recursion depth to prevent infinite subdivision [S1, unofficial].
*   `bias`: A padding value added to octant boundaries during containment checks to handle points near boundaries or sphere intersections [S1, unofficial].

**Algorithm Steps:**

1.  **Insertion (`set`):** Recursively traverse from the root to find the leaf octant containing the point $\mathbf{p}$ [S1, unofficial]. Check if $\mathbf{p}$ already exists in the leaf's `points` array; if yes, update the corresponding entry in `data` [S1, unofficial]. If the leaf is full (number of points $\ge$ `maxPoints`) and current depth < `maxDepth`, call `split()` and `redistribute()` [S1, unofficial]. Otherwise, append $\mathbf{p}$ to `points` and $D$ to `data` in the leaf [S1, unofficial].

2.  **Splitting and Redistribution:** `split()` creates 8 empty child octants [S1, unofficial]. `redistribute(bias)` iterates through all points in the current node's `data` and determines which child octant contains each point using `contains(point, bias)` [S1, unofficial]. The point and its data are moved to the child's `PointData`, and the current node's `data` is set to `null` [S1, unofficial].

3.  **Radius Search (`findPoints`):** Recursively traverse child octants that intersect the query sphere (defined by center $\mathbf{c}$ and radius $r$) [S1, unofficial]. Intersection is approximated by checking if the sphere center lies within the octant boundaries expanded by the radius using `contains(center, radius)` [S1, unofficial]. In leaf nodes, compute squared distance $d^2 = \|\mathbf{p}_i - \mathbf{c}\|^2$ for each point [S1, unofficial]. Filter points where $d^2 \le r^2$ [S1, unofficial].

4.  **Movement (`move`):** If the point and new position are in the same octant, update the position in place or recurse into children [S1, unofficial]. If they diverge, remove the point from the old location and insert it at the new location via `set()` [S1, unofficial].

**Pseudocode:**

```python
class Vector3:
    def __init__(self, x, y, z):
        self.x, self.y, self.z = x, y, z
    def __add__(self, other):
        return Vector3(self.x + other.x, self.y + other.y, self.z + other.z)
    def __truediv__(self, scalar):
        return Vector3(self.x / scalar, self.y / scalar, self.z / scalar)
    def equals(self, other):
        return self.x == other.x and self.y == other.y and self.z == other.z
    def distance_squared(self, other):
        dx = self.x - other.x
        dy = self.y - other.y
        dz = self.z - other.z
        return dx*dx + dy*dy + dz*dz

class PointData:
    def __init__(self):
        self.points = []
        self.data = []

class PointOctant:
    def __init__(self, min_bound, max_bound):
        self.min = min_bound
        self.max = max_bound
        self.children = None
        self.data = None

    def contains(self, point, bias=0):
        return (point.x >= self.min.x - bias and point.x <= self.max.x + bias and
                point.y >= self.min.y - bias and point.y <= self.max.y + bias and
                point.z >= self.min.z - bias and point.z <= self.max.z + bias)

    def split(self):
        mid = (self.min + self.max) / 2.0
        self.children = []
        for i in range(8):
            x_bit = (i >> 2) & 1
            y_bit = (i >> 1) & 1
            z_bit = i & 1
            new_min = Vector3(
                self.min.x if x_bit == 0 else mid.x,
                self.min.y if y_bit == 0 else mid.y,
                self.min.z if z_bit == 0 else mid.z
            )
            new_max = Vector3(
                self.max.x if x_bit == 0 else mid.x,
                self.max.y if y_bit == 0 else mid.y,
                self.max.z if z_bit == 0 else mid.z
            )
            self.children.append(PointOctant(new_min, new_max))
        self.data = None

    def redistribute(self, bias):
        if self.data is None or self.children is None:
            return
        for i in range(len(self.data.points)):
            p = self.data.points[i]
            d = self.data.data[i]
            for child in self.children:
                if child.contains(p, bias):
                    if child.data is None:
                        child.data = PointData()
                    child.data.points.append(p)
                    child.data.data.append(d)
                    break
        self.data = None

    def set(self, point, data_entry, max_points, max_depth, current_depth, bias):
        if current_depth >= max_depth:
            if self.data is None:
                self.data = PointData()
            self.data.points.append(point)
            self.data.data.append(data_entry)
            return

        if self.children is None:
            if self.data is None:
                self.data = PointData()
            for i in range(len(self.data.points)):
                if self.data.points[i].equals(point):
                    self.data.data[i] = data_entry
                    return
            if len(self.data.points) >= max_points:
                self.split()
                self.redistribute(bias)
                for child in self.children:
                    if child.contains(point, bias):
                        child.set(point, data_entry, max_points, max_depth, current_depth + 1, bias)
                        return
            else:
                self.data.points.append(point)
                self.data.data.append(data_entry)
        else:
            for child in self.children:
                if child.contains(point, bias):
                    child.set(point, data_entry, max_points, max_depth, current_depth + 1, bias)
                    return

    def find_points(self, center, radius, results):
        if self.data is None:
            return
        if not self.contains(center, radius):
            return
        if self.children is None:
            for i in range(len(self.data.points)):
                d_sq = self.data.points[i].distance_squared(center)
                if d_sq <= radius * radius:
                    results.append((self.data.points[i], self.data.data[i]))
        else:
            for child in self.children:
                child.find_points(center, radius, results)

    def remove(self, point, bias):
        if self.data is None:
            return
        for i in range(len(self.data.points)):
            if self.data.points[i].equals(point):
                self.data.points.pop(i)
                self.data.data.pop(i)
                break

def move(old_point, new_point, octant, max_points, max_depth, current_depth, bias):
    if octant.contains(old_point, bias) and octant.contains(new_point, bias):
        if octant.children is not None:
            for child in octant.children:
                move(old_point, new_point, child, max_points, max_depth, current_depth + 1, bias)
        elif octant.data is not None:
            for i in range(len(octant.data.points)):
                if octant.data.points[i].equals(old_point):
                    octant.data.points[i] = new_point
                    return octant.data.data[i]
    else:
        octant.remove(old_point, bias)
        for child in octant.children:
            if child.contains(new_point, bias):
                child.set(new_point, None, max_points, max_depth, current_depth + 1, bias)
                break
    return None
```

## Subtopics

### Octree-Based Spatial Query Acceleration
Uses an octree (or kDTree) to accelerate spatial queries like nearest neighbor and radius search, avoiding $O(N^2)$ brute-force comparisons [S2, unofficial]. On a 1.42 million point indoor scan, building a cKDTree index took 417 ms [S2, unofficial]. For 300k points, 16-Nearest Neighbor queries took 4.1 ms with the tree vs 5,071 ms brute force (1,224x speedup) [S2, unofficial]. Radius search (r=0.15m) took 26 ms vs 3,246 ms (126x speedup) [S2, unofficial]. Brute force is faster for single lookups, but the tree amortizes build cost over many queries [S2, unofficial]. Used for normal estimation, segmentation, and ground filtering [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Average-case query and update performance scales logarithmically with point count [G].
*   **Memory Complexity:** Memory usage scales with the number of stored points and tree depth [G].
*   **Performance:** On a 1.42M point scan, index build took 417 ms [S2, unofficial]. 16-NN query on 300k points: 4.1 ms (tree) vs 5,071 ms (brute force) [S2, unofficial].
*   **Strengths:** Supports dynamic updates including insertion, removal, and point movement [S1, unofficial].
*   **Limitations:** `maxDepth` is a hard limit that may prevent perfect balancing for very dense clusters [S1, unofficial]. Build cost is non-trivial for large static datasets if queries are few [S2, unofficial].

## Background
The Point Octree is a standard recursive octree implementation for managing 3D points [S1, unofficial]. It is widely used in point cloud processing for tasks requiring spatial indexing, such as normal estimation and segmentation [S2, unofficial]. The specific implementation details (parallel arrays, bias-based containment) are derived from the `sparse-octree` library [S1, unofficial].
