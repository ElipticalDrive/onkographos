# Spatial Hierarchies
Also called: Spatial Tree Structures
## Overview
Spatial hierarchies accelerate volume rendering by organizing data into a tree structure to perform efficient point location and empty space skipping [S1, unofficial]. They differ from flat grids by enabling recursive descent to skip large empty regions, reducing the number of samples required per ray [S1, unofficial].
## Shared principles
All methods in this family share the core mechanism of hierarchical descent and ascent [G]. The traversal begins at the root of the octree and determines which of the eight children (octants) the ray intersects. This is typically done by comparing the ray's position relative to the center of the current node's bounding box [S1, unofficial][G].

1.  **Child Selection:** For a node with center $\mathbf{c}$ and half-extent $s$, the ray position $\mathbf{p}$ determines the child index $k \in \{0, \dots, 7\}$:
    $$
    k = 4 \cdot \mathbb{I}(p_x \ge c_x) + 2 \cdot \mathbb{I}(p_y \ge c_y) + 1 \cdot \mathbb{I}(p_z \ge c_z)
    $$
    where $\mathbb{I}(\cdot)$ is the indicator function [S1, unofficial][G].

2.  **Empty Space Skipping:** If the selected child is marked as empty (or uniform), the traversal skips the subtree [G]. This is achieved by advancing the ray parameter $t$ to the exit of the current node or using neighbor pointers to jump to the next potentially occupied node [S1, unofficial][G].

3.  **Leaf Handling:** Upon reaching a leaf node, the method typically switches to a fixed-step traversal (like DDA) within the leaf's voxel grid to sample the volume data [S1, unofficial][G].

4.  **Backtracking:** Because octrees are sparse and irregular, traversal often requires backtracking to the parent node when a ray exits a subtree or encounters an empty branch [G]. This is implemented using an explicit stack (on GPU) or recursion (on CPU) [G].
## Subtopics

### Octree
An octree subdivides space into eight octants recursively. It is the most common spatial hierarchy for volumetric data due to its regular structure and efficient empty space skipping. Choose it when the volume has significant empty regions or when uniform sampling within leaves is desired. See [Octree and Tree Traversal](52-octree-and-tree-traversal.md).

### BSP Tree
Binary Space Partitioning trees split space using arbitrary planes. They offer flexibility in handling non-axis-aligned data but can be more complex to traverse. Choose them for scenes with complex geometric boundaries or when axis-aligned splits are insufficient. See [BSP Tree](53-bsp-tree.md).

### KD Tree
KD trees split space along alternating axes. They provide a balance between the regularity of octrees and the flexibility of BSP trees. Choose them for general-purpose acceleration where axis-aligned splits are sufficient but a binary structure is preferred. See [KD Tree](54-kd-tree.md).

### Insertion into Spatial Hierarchies
The insertion algorithm determines the tree structure. It recursively checks if a primitive overlaps the node's bounding box. If the node is a leaf and exceeds `MAXPRIMS` (typically 2-8) and `depth < MAXDEPTH` (typically 16), it subdivides and inserts the primitive into all children. Otherwise, it adds the primitive to the leaf's list [S1, unofficial].

```python
def insert(node, prim):
    if overlap(node.bound, prim):
        if is_leaf(node):
            if node.nprims > MAXPRIMS and node.depth < MAXDEPTH:
                subdivide(node)
                for child in node.children:
                    insert(child, prim)
            else:
                node.prims.append(prim)
        else:
            for child in node.children:
                insert(child, prim)
```

## Background
Spatial hierarchies originated in ray tracing to accelerate object intersection tests [S1, unofficial]. Variations include octrees, BSP trees, and KD trees [S1, unofficial]. They are widely used in volume rendering to skip empty space and reduce sampling costs.
