# Spatial Hierarchies
Also called: Spatial Tree Structures
## Overview
Spatial hierarchies accelerate volume rendering by organizing data into a tree structure to perform efficient point location and empty space skipping, avoiding unnecessary sampling in empty regions [S1, unofficial]. They differ from grid-based methods by adapting resolution to data density, and from image-order methods by being object-order (or data-order) traversal techniques that determine which spatial regions a ray intersects before sampling [S1, unofficial].
## Shared principles
All methods in this family share the core mechanism of hierarchical descent and ascent [G]. The traversal begins at the root of the octree and determines which of the eight children (octants) the ray intersects. This is typically done by comparing the ray's position relative to the center of the current node's bounding box [S1, unofficial][G].

1.  **Child Selection:** For a node with center $\mathbf{c}$ and half-extent $s$, the ray position $\mathbf{p}$ determines the child index $k \in \{0, \dots, 7\}$:
    $$
    k = 4 \cdot \mathbb{I}(p_x \ge c_x) + 2 \cdot \mathbb{I}(p_y \ge c_y) + 1 \cdot \mathbb{I}(p_z \ge c_z)
    $$
    where $\mathbb{I}(\cdot)$ is the indicator function [S1, unofficial][G].

2.  **Empty Space Skipping:** If the selected child is marked as empty (or uniform), the traversal skips the subtree [G]. This is achieved by advancing the ray parameter $t$ to the exit of the current node or using neighbor pointers to jump to the next potentially occupied node [S1, unofficial][G].

3.  **Leaf Handling:** Upon reaching a leaf node, the method typically switches to a fixed-step traversal (like DDA) within the leaf's voxel grid to sample the volume data [S1, unofficial][G].

4.  **Backtracking:** Because octrees are sparse and irregular, traversal often requires backtracking to the parent node when a ray exits a subtree or encounters an empty branch [G]. This is implemented using an explicit stack (on GPU) or recursion (on CPU) [G].
## Subtopics

### Octree
An octree recursively subdivides space into eight octants. It is chosen when the volume data has significant empty space or varying density, allowing for adaptive resolution. It is the most common spatial hierarchy for general-purpose volume rendering.

### BSP Tree
A Binary Space Partitioning tree recursively splits space using a single plane. It is chosen when the data has strong planar symmetries or when exact geometric intersection is required. It differs from octrees by using arbitrary splitting planes rather than axis-aligned cuts.

### KD Tree
A k-d tree splits space using axis-aligned planes at median positions of the data. It is chosen for its simplicity and efficiency in organizing point clouds or sparse voxel grids. It differs from BSP trees by restricting splits to axis-aligned directions.

### Insertion into Spatial Hierarchies
The insertion algorithm determines how primitives or voxels are added to the hierarchy. It uses two parameters: `MAXDEPTH` (typically 16) and `MAXPRIMS` (typically between 2 and 8) [S1, unofficial]. The logic is as follows:

```python
def insert(node, prim):
    if overlap(node.bound, prim):
        if is_leaf(node):
            if node.nprims > MAXPRIMS and node.depth < MAXDEPTH:
                subdivide(node)
                for child in node.children:
                    insert(child, prim)
            else:
                list_insert(node.prims, prim)
        else:
            for child in node.children:
                insert(child, prim)
```
This ensures leaves do not become too large or the tree too deep [S1, unofficial].

## Background
Spatial hierarchies originated in computer graphics for accelerating ray tracing and visibility calculations. Variations include octrees, BSP trees, and KD trees [S1, unofficial]. They are widely used in volume rendering to handle sparse data and large datasets efficiently.
