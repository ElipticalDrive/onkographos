# Hierarchical Spatial Enumeration Optimization

Also called: Complete octree representation, Heirarchical Spatial Enumeration, Hierarchical Spatial Enumeration (Octree Pyramid), Pyramid Enumeration, Pyramid of binary volumes

## Overview
Hierarchical Spatial Enumeration Optimization is a method for accelerating image-order volume rendering by encoding spatial coherence (empty regions) into a pyramid of binary volumes [S1][S2, unofficial]. It solves the problem of inefficiently traversing large voxel datasets by allowing rays to skip large empty regions in logarithmic time relative to ray length [S2, S3, unofficial]. Unlike geometric ray tracing which uses bounding volumes or condensed octree representations [S1], this method uses a complete octree structure (pyramid of binary volumes) specifically optimized for the spatially ordered, single-sample nature of volume data [S1].

## How it works
**Inputs and Outputs**
- **Input:** A 3D volume dataset of size $N \times N \times N$ voxels, where $N = 2^M + 1$ for some integer $M \ge 0$. Each voxel has an opacity value $\alpha$.
- **Output:** A pyramid of $M+1$ binary volumes $V_m$ for $m=0, \dots, M$, where each cell indicates if the enclosed region contains any non-zero opacity.

**Data Structures**
The structure is a pyramid of $M+1$ binary volumes $V_m$.
- **Level $m$ Volume ($V_m$):** A 3D array of binary values.
- **Dimensions:** Volume $V_m$ has side length $(N-1)/2^m$ cells.
    - $V_0$ has side length $N-1$.
    - $V_M$ has side length 1 (single cell).
- **Cell Indexing:** Cells are indexed by level $m$ and vector $\mathbf{i} = (i, j, k)$ where $i, j, k \in \{1, \dots, (N-1)/2^m\}$.
- **Cell Value:** $V_m(\mathbf{i}) \in \{0, 1\}$.
    - $0$: The region is empty (all constituent voxels/cells have zero opacity).
    - $1$: The region contains at least one voxel with non-zero opacity.
- **Geometry:** Voxels are treated as point samples. Cells fill the space between voxels. Each volume is one cell larger in each direction than the underlying dataset it represents at that level. Voxel $(1,1,1)$ is placed at the front-lower-right corner of cell $(1,1,1)$ on level 0. Cell $(1,1,1)$ on level 0 encloses the space between voxels $(1,1,1)$ and $(2,2,2)$ [S1][S3, unofficial].

**Construction Algorithm**
The pyramid is constructed recursively from the base level up.

1.  **Base Level ($V_0$):**
    For each cell $\mathbf{i} \in \{1, \dots, N-1\}^3$:
    $$ V_0(\mathbf{i}) = \begin{cases} 1 & \text{if } \alpha(\mathbf{i} + \Delta\mathbf{i}) > 0 \text{ for any } \Delta\mathbf{i} \in \{0, 1\}^3 \\ 0 & \text{otherwise} \end{cases} $$
    Cell $\mathbf{i}$ in $V_0$ is 1 if any of the 8 voxels at its vertices has non-zero opacity [S1][S3, unofficial].

2.  **Recursive Levels ($m > 0$):**
    For each cell $\mathbf{i}$ in volume $V_m$:
    $$ V_m(\mathbf{i}) = \begin{cases} 1 & \text{if } V_{m-1}(\mathbf{j}) = 1 \text{ for any } \mathbf{j} \text{ forming the octants of } \mathbf{i} \\ 0 & \text{otherwise} \end{cases} $$
    Cell $\mathbf{i}$ in $V_m$ is 0 if all 8 cells on level $m-1$ that form its octants contain zeros [S1][S3, unofficial].

**Ray Traversal Algorithm**
To render a pixel, a viewing ray is traced through the pyramid.

1.  **Initialization:** Compute the entry point of the ray into the single top-level cell $V_M(1,1,1)$. Set current level $m = M$. Set current cell index $\mathbf{i} = (1,1,1)$.
2.  **Traversal Loop:**
    While $m \ge 0$:
    a.  **Check Cell Value:** Let $val = V_m(\mathbf{i})$.
    b.  **If $val == 0$ (Empty):**
        i.  Advance the ray to the next cell on the same level $m$ in the direction of the ray. Let the new cell index be $\mathbf{i}_{new}$.
        ii. Check if the parent of $\mathbf{i}_{new}$ differs from the parent of $\mathbf{i}$.
        iii. If parents differ, move up to the parent level: $m \leftarrow m - 1$, and update $\mathbf{i}$ to the parent cell index of $\mathbf{i}_{new}$ in level $m-1$.
        iv. If parents are the same, stay at level $m$ and set $\mathbf{i} \leftarrow \mathbf{i}_{new}$.
    c.  **If $val == 1$ (Occupied):**
        i.  If $m > 0$, move down one level: $m \leftarrow m + 1$.
        ii. Determine which child cell at level $m$ encloses the current ray position. Set $\mathbf{i}$ to that child's index.
        iii. Continue loop to check the new child cell.
        iv. If $m == 0$ (Leaf Level):
            - The cell contains non-zero opacity.
            - Draw samples at evenly spaced locations along the segment of the ray falling within this cell.
            - Resample the volume data at these locations.
            - Composite color and opacity into the ray state (front-to-back compositing).
            - Advance the ray to the next cell on level 0 (or terminate if ray exits volume).
3.  **Termination:** Stop when the ray exits the volume or accumulated opacity exceeds a threshold (if adaptive termination is used).

**Parameters**
- $M$: Integer such that dataset side length $N = 2^M + 1$. The pyramid has levels $m = 0, \dots, M$ [S1].
- Cell Size: The size of cells on level $m$ is $2^m$ times the spacing between voxels [S1][S3, unofficial].

**Edge Cases and Pitfalls**
- **Coordinate Alignment:** Voxel $(1,1,1)$ is at the front-lower-right corner of cell $(1,1,1)$ on level 0. Cell $(1,1,1)$ on level 0 encloses the space between voxels $(1,1,1)$ and $(2,2,2)$ [S1][S3, unofficial]. Incorrect alignment leads to sampling errors.
- **Dataset Size:** The method requires $N = 2^M + 1$. If the dataset does not meet this, padding or resizing is required [S1].
- **Precision:** Floating-point precision in ray-cell intersection calculations can affect traversal accuracy, especially at higher levels where cells are large [G].

## Subtopics

### [Hierarchical Volume Traversal with Adaptive Termination](1682-hierarchical-volume-traversal-with-adaptive-termination.md)
Hierarchical Volume Traversal with Adaptive Termination is a ray tracing algorithm that uses a pyramidal data structure of binary volumes to skip empty regions and an adaptive termination criterion to stop tracing when accumulated opacity exceeds a threshold. Unlike geometric ray tracing, which uses bounding volumes or spatial subdivision with lists of primitives, this method uses a hierarchical binary volume structure, which is more efficient for volume data because volume datasets have tens of millions of spatially ordered cells with single samples, whereas geometric scenes have hundreds of cells with many primitives.

### Hierarchical Opacity Enumeration
An optimization that uses a binary octree to avoid unnecessary resampling of voxels in transparent regions of the volume [S4].

### Flat Pyramid
A hierarchical spatial data structure (quadtree recursively subdivided down to pixel size) where empty space uniformity information is stored in the empty voxels of the 3D volume grid [S5, unofficial]. The structure is a quadtree recursively subdivided down until pixel size. Gray squares denote voxels with volume data; white squares denote empty voxels storing the octree level [S5, unofficial].

## Operating characteristics
- **Time Complexity:** Grows linearly with image size, logarithmically with ray length, and linearly with depth complexity of the data [S2, unofficial].
- **Memory Complexity:** Requires storage for $M+1$ binary volumes. Total cells $\approx \sum_{m=0}^M ((N-1)/2^m)^3 \approx (N-1)^3 \sum_{m=0}^M (1/8)^m \approx (N-1)^3 \frac{1}{1-1/8} = \frac{8}{7}(N-1)^3$. Thus, memory overhead is roughly $1.14 \times$ the size of the base volume $V_0$ (which is $(N-1)^3$ bits) [G].
- **Performance:** Speedups of an order of magnitude have been observed for datasets of useful size and complexity [S1].
- **Strengths:** Efficiently skips large empty regions; suitable for image-order rendering of large volumetric datasets [S1][S3, unofficial].
- **Limitations:** Requires dataset size $N=2^M+1$; less efficient for datasets with high depth complexity and low empty space [S2, unofficial].

## Background
Originated in the late 1980s by Marc Levoy [S1][S2, unofficial]. It was introduced as an optimization for image-order volume rendering to handle the computational cost of ray casting through large voxel datasets [S1]. The method leverages the spatial coherence of volume data, where large regions often have zero opacity [S2, unofficial]. It is used in medical imaging and molecular graphics applications [S1].
