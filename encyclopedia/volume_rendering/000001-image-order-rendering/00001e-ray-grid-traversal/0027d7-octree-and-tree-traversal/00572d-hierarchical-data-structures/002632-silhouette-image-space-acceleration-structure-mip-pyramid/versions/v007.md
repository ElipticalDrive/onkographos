# Silhouette Image Space Acceleration Structure (Mip Pyramid)

Also called: Hierarchical Voxelization Acceleration Structure

## Overview
This method accelerates voxel coverage queries in image-based modeling by using a hierarchical mip pyramid over silhouette images to provide conservative bounds on voxel visibility [S1]. It solves the problem of efficiently determining whether a voxel intersects the visual hull without sampling every pixel, thereby reducing computation and data access for culling decisions [S1]. It is distinguished from sibling methods by its direct inspiration from the hierarchical z-buffer [S1], storing min/max bounds of texel blocks to ensure no small features are missed or holes created in the voxelization [S1].

## How it works
**Inputs:**
- A set of $n$ silhouette images, one per camera view [S1].
- A voxel $v$ defined by its 8 corners in Normalized Device Coordinate (NDC) space [S1].
- The $n$ pre-generated silhouette image pyramids [S1].

**Outputs:**
- A conservative lower bound (min) and upper bound (max) on the silhouette value $\mathcal{S}(\mathbf{p})$ for all points $\mathbf{p}$ within voxel $v$ [S1]. If the lower bound is 0, the voxel is outside the visual hull [S1].

**Data Structures:**
- For each of the $n$ views, a pyramid of texture levels is stored [S1].
- Level 0: Original smoothed silhouette image [S1].
- Level $l+1$: Each texel stores the minimum and maximum values of the $2 \times 2$ block of texels from level $l$ that it covers [S1].
- Format: Two-channel texture (min, max) per texel [S1].

**Algorithm Steps:**
1. Project the 8 NVC space corners of voxel $v$ into the 2D image space of camera $i$ [S1].
2. Find the axis-aligned bounding rectangle $(minX, minY, maxX, maxY)$ that encloses all projected corners [S1].
3. Determine the sampling level $L$ in the silhouette image mip pyramid:
   $$
   L = \lfloor \log_2(\max(maxX - minX, maxY - minY)) \rfloor
   $$
   At this level $L$, the bounding rectangle covers at most a $2 \times 2$ block of texels [S1].
4. Sample the texels at the corners of the bounding rectangle $(minX, minY)$, $(maxX, minY)$, $(minX, maxY)$, and $(maxX, maxY)$ from level $L$ of the pyramid for view $i$ [S1].
5. Return the minimum and maximum of these sampled values as a conservative bound on $\mathcal{I}_i(\mathbf{C}_i(\mathbf{p}))$ for all $\mathbf{p}$ within $v$ [S1].

**Pseudocode:**
```python
def sampleSilhouette(voxel_v, camera_i, pyramid):
    # 1. Project 8 NVC space corners of voxel v into silhouette image space
    projected = [project_to_image(c, camera_i) for c in voxel_v.corners]
    
    # 2. Find axis-aligned bounding rectangle
    minX = min(p.x for p in projected)
    minY = min(p.y for p in projected)
    maxX = max(p.x for p in projected)
    maxY = max(p.y for p in projected)
    
    # 3. Determine sampling level
    L = floor(log2(max(maxX - minX, maxY - minY)))
    
    # 4. Sample texels at corners of the bounding rectangle
    corners = [(minX, minY), (maxX, minY), (minX, maxY), (maxX, maxY)]
    samples = [pyramid[camera_i][L].sample_at(c) for c in corners]
    
    # 5. Return min and max of these values
    min_val = min(s.min for s in samples)
    max_val = max(s.max for s in samples)
    return min_val, max_val
```

**Global Voxel Bound:**
To determine if the voxel is inside the visual hull, combine bounds across all $n$ views:
$$
min\_bound_{total} = \prod_{i=1}^{n} min\_bound_i
$$
$$
max\_bound_{total} = \prod_{i=1}^{n} max\_bound_i
$$
If $min\_bound_{total} > 0$, the voxel is fully inside [S1]. If $max\_bound_{total} = 0$, it is fully outside [S1]. Otherwise, further sampling is required [S1].

**Generation:**
The $n$ image pyramids are generated by a compute kernel launched immediately after silhouette image smoothing [S1].

**Pitfalls:**
- Conservative bounds ensure no small features are missed and no holes are created in voxelization, as bounds are conservatively correct [S1].
- Precision issues in projection or log calculation may affect level selection; ensure robust handling of edge cases where the bounding box size is very small or zero [G].

This method acquires and preprocesses silhouette images from raw camera data to create smooth, calibrated binary masks used for visual hull approximation. It is distinguished from sibling methods by its unified compute kernel approach that simultaneously handles lens distortion, demosaicing, and chroma-keying, followed by separable Gaussian filtering to control surface smoothness.

## Operating characteristics
- **Performance:** Greatly reduces the amount of computation and data accesses needed by the oracle kernel to make a culling decision for a given voxel [S1].
- **Memory Complexity:** Requires storing $n$ image pyramids [S1].
- **Strengths:** Conservative bounds prevent holes in voxelization; efficient culling of empty space [S1].
- **Limitations:** Requires pre-computation of silhouette images and pyramids; performance depends on the number of views $n$ [S1].
- **Time Complexity:** Not given in the sources.

## Background
The method is presented in the context of real-time high-resolution sparse voxelization with application to image-based modeling [S1]. It is inspired by the well-known hierarchical z-buffer [S1], adapting the concept of hierarchical depth testing to silhouette coverage queries [S1]. The acceleration structure is part of a pipeline that includes silhouette image acquisition, filtering, and voxel rendering as screen-space bounding rectangle splats [S1].
