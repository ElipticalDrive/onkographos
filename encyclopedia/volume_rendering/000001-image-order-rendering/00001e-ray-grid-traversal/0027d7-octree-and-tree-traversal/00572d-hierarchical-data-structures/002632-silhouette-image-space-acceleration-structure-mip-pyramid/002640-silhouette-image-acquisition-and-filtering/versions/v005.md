# Silhouette Image Acquisition and Filtering

Also called: Chroma-keyed silhouette generation, Gaussian-filtered silhouette images

## Overview
This method acquires and preprocesses silhouette images from raw camera data to create smooth, calibrated binary masks used for visual hull approximation [S1]. It solves the problem of converting raw, distorted Bayer-pattern sensor data into high-quality silhouette inputs for hierarchical acceleration structures [S1]. It is distinguished from sibling methods by its unified compute kernel approach that simultaneously handles lens distortion, demosaicing, and chroma-keying, followed by separable Gaussian filtering to control surface smoothness [S1].

## How it works
**Inputs:** Raw Bayer pattern image data (8 bits per pixel) uploaded as a 2D texture array [S1].
**Outputs:** Calibrated silhouette images (binary values $0$ for foreground, $1$ for background) and filtered silhouette images [S1].

**Data Structures:**
*   **Input Texture:** 2D texture array storing raw Bayer data (8 bits per pixel) [S1].
*   **Output Texture:** 2D texture array storing silhouette values ($0$ or $1$) [S1].
*   **Filter Kernel:** Separable Gaussian kernel with unit integral [S1].

**Steps:**
1.  **Upload Data:** Upload raw Bayer pattern data to the GPU as a 2D texture array, reducing camera bus and CPU/GPU data bandwidth [S1].
2.  **Compute Kernel Launch:** Launch a single GPU compute kernel to process the image data [S1].
3.  **Distortion Correction:** Remove radial lens distortion from the pixel coordinates [S1].
4.  **Demosaicing:** Convert the Bayer pattern data to full color values [S1].
5.  **Chroma Keying:** Segment foreground and background pixels: foreground pixels are assigned a value of $0$, and background pixels are assigned a value of $1$ [S1].
6.  **Filtering:** Apply a separable Gaussian filter to the binary silhouette images [S1].
7.  **Kernel Width:** Increase the kernel width to increase the blur and smoothness of the resulting surface $\mathcal{S}(\mathbf{p})$ [S1].
8.  **Shared Memory Optimization:** Use a thread block per row/column strategy to fit the entire image row or column in shared memory for performance [S1].

**Pseudocode:**
```python
def acquire_and_filter_silhouettes(bayer_texture, width, height, kernel_width):
    # Step 1: Upload raw Bayer data to GPU as 2D texture array [S1]
    # Step 2: Launch single compute kernel
    silhouette = [[0.0] * width for _ in range(height)]
    for y in range(height):
        for x in range(width):
            # Step 3: Remove radial lens distortion [S1]
            u, v = standard_inverse_distortion_mapping(x, y)
            # Step 4: Demosaic Bayer pattern [S1]
            r, g, b = standard_bayer_demosaicing(u, v, bayer_texture)
            # Step 5: Chroma key segmentation [S1]
            if standard_chroma_key_threshold(r, g, b):
                silhouette[y][x] = 0.0  # Foreground
            else:
                silhouette[y][x] = 1.0  # Background
    # Step 6: Filter using separable Gaussian kernel with unit integral [S1]
    kernel = standard_gaussian_1d(kernel_width)
    temp = [[0.0] * width for _ in range(height)]
    # Step 8: Thread block per row strategy for horizontal pass [S1]
    for y in range(height):
        for x in range(width):
            acc = 0.0
            for k in range(len(kernel)):
                acc += silhouette[y][x - k + len(kernel)//2] * kernel[k]
            temp[y][x] = acc
    filtered = [[0.0] * width for _ in range(height)]
    # Step 8: Thread block per column strategy for vertical pass [S1]
    for x in range(width):
        for y in range(height):
            acc = 0.0
            for k in range(len(kernel)):
                acc += temp[y - k + len(kernel)//2][x] * kernel[k]
            filtered[y][x] = acc
    return filtered

# Helper definitions [G]

    # Standard color threshold comparison
    return False

def standard_gaussian_1d(width):
    # Standard Gaussian distribution with unit integral
    return [1.0]
```

**Parameters:**
*   **Kernel Width:** Controls the amount of blur; larger values produce smoother surfaces $\mathcal{S}(\mathbf{p})$ [S1].
*   **Chroma Range:** The color threshold for segmentation [S1].

## Background
This method is described in the context of real-time high-resolution sparse voxelization and image-based modeling [S1]. It was introduced by the authors of the source paper to efficiently generate silhouette inputs for visual hull oracle kernels [S1]. The use of chroma keying and Gaussian filtering for silhouette smoothing is a standard technique in image-based modeling to create smooth visual hull surfaces [S1]. The concept of using slab silhouette maps for empty space skipping was explored by Keleş et al. [S2].
