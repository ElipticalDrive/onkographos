# Octree Node Lookup by Voxel
## Overview
This method locates the payload index for a specific 3D voxel coordinate within a Sparse Voxel Octree (SVO) by traversing from the root to the corresponding leaf node [S1, unofficial]. It solves the problem of mapping a discrete voxel coordinate to the sparse data structure's payload array, returning -1 if the voxel lies outside the tree's bounds or in an empty region [S1, unofficial].

## How it works
**Inputs:**
- `nodes`: Array of `NodeDescriptor` structures representing the octree nodes.
- `num_nodes`: Total number of nodes in the `nodes` array.
- `leaf_payload_indices`: Array of indices mapping leaf IDs to payload rows.
- `num_leaves`: Total number of leaves.
- `max_depth`: The maximum depth of the octree (root is depth 0).
- `voxel`: A 3D integer coordinate `(x, y, z)` to look up.

**Outputs:**
- `payload_index`: The index into the payload array corresponding to the voxel. Returns -1 if the voxel is invalid or empty [S1, unofficial].

**Data Structures:**
- `NodeDescriptor`: Contains the following fields:
  - `child_mask`: 8-bit bitmask indicating which of the 8 children exist.
  - `leaf_mask`: 8-bit bitmask indicating which children are leaf nodes.
  - `payload_base`: Offset into `leaf_payload_indices` for the first leaf child.
  - `internal_child_mask`: 8-bit bitmask indicating which children are internal nodes.
  - `child_base`: Offset into the `nodes` array for the first internal child.

**Formulas:**
1.  **Grid Size:** $grid\_size = 2^{max\_depth}$ [S1, unofficial]
2.  **Child Index:** For a given depth $d$ (where $d$ ranges from $max\_depth-1$ down to 0), the child index $c$ is:
    $$c = ((x \gg d) \& 1) \mid (((y \gg d) \& 1) \ll 1) \mid (((z \gg d) \& 1) \ll 2)$$ [S1, unofficial]
3.  **Prefix Rank:** The number of set bits in a mask strictly below a given index $i$:
    $$prefix\_rank(mask, i) = \text{popcount}(mask \& ((1 \ll i) - 1))$$ [S1, unofficial]

**Algorithm Steps:**
1.  If `num_nodes` is 0, return -1 [S1, unofficial].
2.  If `max_depth` is 0, the root is a leaf. If `leaf_payload_indices` is valid and contains data, return `leaf_payload_indices[0]`. Otherwise, return -1 [S1, unofficial].
3.  Calculate $grid\_size = 2^{max\_depth}$ [S1, unofficial].
4.  If `voxel.x`, `voxel.y`, or `voxel.z` is not in the range $[0, grid\_size)$, return -1 [S1, unofficial].
5.  Initialize `node_index = 0` and `depth_remaining = max_depth` [S1, unofficial].
6.  Loop indefinitely:
    a.  If `node_index >= num_nodes`, return -1 (traversal exceeded node array bounds) [S1, unofficial].
    b.  Retrieve `descriptor = nodes[node_index]` [S1, unofficial].
    c.  Calculate `child_index` using the formula above with `child_depth = depth_remaining - 1` [S1, unofficial].
    d.  Compute `child_bit = 1 << child_index` [S1, unofficial].
    e.  If `(descriptor.child_mask & child_bit) == 0`, the child does not exist. Return -1 [S1, unofficial].
    f.  If `(descriptor.leaf_mask & child_bit) != 0`, the child is a leaf:
        i.  Compute `leaf_id = descriptor.payload_base + prefix_rank(descriptor.leaf_mask, child_index)` [S1, unofficial].
        ii. Retrieve `payload_index = leaf_payload_indices[leaf_id]` [S1, unofficial].
        iii. Validate `payload_index` (e.g., check if it is within bounds of the payload array). If valid, return `payload_index`. Else, return -1 [S1, unofficial].
    g.  Otherwise, the child is an internal node:
        i.  Compute `new_node_index = descriptor.child_base + prefix_rank(descriptor.internal_child_mask, child_index)` [S1, unofficial].
        ii. Decrement `depth_remaining` [S1, unofficial].
        iii. If `depth_remaining <= 0`, return -1 (should have hit a leaf or invalid path) [S1, unofficial].
        iv. Set `node_index = new_node_index` and continue loop [S1, unofficial].

**Pseudocode:**
```python
def lookup_payload_index_by_voxel(nodes, num_nodes, leaf_payload_indices, num_leaves, max_depth, voxel):
    # Step 1: Empty tree check
    if num_nodes == 0:
        return -1

    # Step 2: Max depth 0 check (Root is leaf)
    if max_depth == 0:
        if num_leaves > 0 and len(leaf_payload_indices) > 0:
            return leaf_payload_indices[0]
        else:
            return -1

    # Step 3 & 4: Bounds check
    grid_size = 1 << max_depth
    if not (0 <= voxel.x < grid_size and 0 <= voxel.y < grid_size and 0 <= voxel.z < grid_size):
        return -1

    # Step 5: Initialization
    node_index = 0
    depth_remaining = max_depth

    # Step 6: Traversal Loop
    while True:
        # Step 6a: Bounds check for node array
        if node_index >= num_nodes:
            return -1

        descriptor = nodes[node_index]

        # Step 6b: Calculate child index
        child_depth = depth_remaining - 1
        x_bit = (voxel.x >> child_depth) & 1
        y_bit = (voxel.y >> child_depth) & 1
        z_bit = (voxel.z >> child_depth) & 1
        child_index = x_bit | (y_bit << 1) | (z_bit << 2)

        # Step 6d: Check if child exists
        child_bit = 1 << child_index
        if (descriptor.child_mask & child_bit) == 0:
            return -1

        # Step 6f: Check if child is leaf
        if (descriptor.leaf_mask & child_bit) != 0:
            # Compute leaf_id
            lower_mask = (1 << child_index) - 1
            rank = (descriptor.leaf_mask & lower_mask).bit_count()
            leaf_id = descriptor.payload_base + rank
            
            # Retrieve payload index
            if leaf_id < num_leaves and leaf_id < len(leaf_payload_indices):
                payload_index = leaf_payload_indices[leaf_id]
                # Validate payload_index (e.g., non-negative, within payload bounds)
                if payload_index >= 0:
                    return payload_index
                else:
                    return -1
            else:
                return -1

        # Step 6g: Internal node
        # Compute new node index
        lower_mask = (1 << child_index) - 1
        rank = (descriptor.internal_child_mask & lower_mask).bit_count()
        new_node_index = descriptor.child_base + rank
        
        depth_remaining -= 1
        if depth_remaining <= 0:
            return -1
        
        node_index = new_node_index
```

**Parameters:**
- `payload_rows`: Total number of payload rows. Used to validate the returned `payload_index` [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Empty Tree:** An empty tree (`num_nodes == 0`) must return -1 immediately [S1, unofficial].
- **Zero Depth:** A tree with `max_depth == 0` has only a root leaf; validation of `leaf_payload_indices` is required [S1, unofficial].
- **Out-of-Bounds Voxels:** Voxels at or beyond `grid_size` are invalid and return -1 [S1, unofficial].
- **Missing Children:** If the target child bit is not set in `child_mask`, the path is empty and returns -1 [S1, unofficial].
- **Invalid Indices:** If `leaf_id` or `payload_index` is out of bounds or negative, return -1 [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(max\_depth)$, as the traversal visits exactly one node per depth level [S1, unofficial].
- **Memory Complexity:** $O(1)$ auxiliary space, using a fixed set of integer variables for traversal state [S1, unofficial].
- **Strengths:** Exact discrete lookup with minimal branching overhead; efficiently skips empty branches via bitmask checks [S1, unofficial].
- **Limitations:** Requires integer voxel coordinates; does not support continuous sampling or interpolation natively [S1, unofficial].

## Background
The method is part of the Sparse Voxel Octree (SVO) rendering pipeline, specifically designed for efficient voxel-based data access [S1, unofficial]. It leverages compacted bitmasks and prefix ranks to navigate the octree structure without explicit child pointers, optimizing memory usage and cache locality [S1, unofficial].
