# SVO Node Location
## Overview
SVO Node Location is the core traversal kernel for Sparse Voxel Octree (SVO) ray tracing, responsible for determining the specific node in the octree hierarchy that a ray intersects at a given depth or leaf level. It solves the problem of efficiently mapping a continuous ray position to a discrete hierarchical node address while maintaining the traversal path for subsequent operations like color retrieval or density evaluation. It differs from sibling methods primarily by its explicit separation of the "first node selection" heuristic (optimizing for ray entry) from the iterative descent logic, and by its reliance on a software-simulated stack to preserve context for backtracking, unlike state-machine variants that may encode state differently [S1, unofficial].

## How it works
### Inputs and outputs
**Inputs:**
- `raypos`: 3D vector, the origin of the ray in world space.
- `raydir`: 3D vector, the direction of the ray (normalized).
- `root_lower`: 3D vector, the lower bound of the root node in world space.
- `root_scale`: float, the side length of the root node.
- `max_depth`: integer, the target depth to traverse to. If 0, traverse to the leaf level.
- `address_space`: memory buffer, containing the SVO data (node headers/pointers).
- `stack`: array/structure, used to record the traversal path for later reconstruction.

**Outputs:**
- `located_node`: A structure containing the node info (e.g., global offset, corner index) and the lower bound of the located node.
- `stack`: Updated with the path taken from root to the located node.

### Data structures
The implementation relies on a flat memory layout for the SVO.
- **Node Info**: Typically contains a pointer or offset to children/data. In the source, this is accessed via `root_cd_goffset` (global offset) and corner indices.
- **Stack**: A dynamic array or fixed-size buffer storing the sequence of nodes visited. Each entry likely stores the node identifier and its spatial bounds to allow backtracking.
- **Bounds**: Represented as `lower` (3D vector) and `upper` (3D vector) or derived from `lower` and `scale`.

### Steps
1. **Initialization**:
   - Set `pos = raypos`.
   - Set `lower = root_lower`.
   - Set `upper = root_lower + root_scale`.
   - Set `center = lower + 0.5 * root_scale`.
   - Calculate initial child scale: `scale = root_scale / 2`.
   - Select the first child node using `svo_select_first_node_f3` (see Subtopics).
   - Initialize `current_node`, `lower`, `upper`, and `center` based on the selected first node's bounds and info.
   - Set `depth = 0`.

2. **Traversal Loop**:
   - While `(max_depth == 0 || depth < max_depth)`:
     - **Boundary Check**: If `pos` is not within `[lower, upper]`, return a null located node [S1, unofficial].
     - **Leaf Check**: If `current_node` has no children, break the loop [S1, unofficial].
     - **Corner Determination**:
       - Calculate corner indices based on `pos` relative to `center`:
         $$ xcorneridx = (pos.x < center.x) ? 0 : 1 $$
         $$ ycorneridx = (pos.y < center.y) ? 0 : 1 $$
         $$ zcorneridx = (pos.z < center.z) ? 0 : 1 $$
       - Combine indices to get a single child corner index (0-7).
     - **Node Retrieval**:
       - Get the child node info from `address_space` using the current node's offset and the child corner index.
     - **Stack Push**:
       - Push `current_node` onto `stack`.
     - **Descent**:
       - Increment `depth`.
       - Update `current_node` to the child node.
       - Update `lower`, `upper`, and `center` for the new child node (scale halves each level).

3. **Return**:
   - Return the `current_node` info and its bounds.

### Pseudocode
```python
def svo_locate_node(raypos, raydir, root_lower, root_scale, max_depth, address_space, stack):
    # Initialization
    pos = raypos
    lower = root_lower
    upper = root_lower + root_scale
    center = lower + 0.5 * root_scale
    scale = root_scale / 2.0
    
    # Select first node to start traversal
    first_node = svo_select_first_node_f3(0, lower, scale, raypos, raydir, address_space)
    
    if first_node is None:
        return None, stack
        
    current_node = first_node.node_info
    lower = first_node.lower_bound
    upper = lower + scale
    center = lower + 0.5 * scale
    depth = 0
    
    while max_depth == 0 or depth < max_depth:
        # Check if ray position is within current node bounds
        if not is_inside(pos, lower, upper):
            return None, stack
            
        # Check if current node is a leaf (no children)
        if not has_children(current_node, address_space):
            break
            
        # Determine which octant the ray position falls into
        x_corner = 0 if pos.x < center.x else 1
        y_corner = 0 if pos.y < center.y else 1
        z_corner = 0 if pos.z < center.z else 1
        child_corner = (x_corner << 2) | (y_corner << 1) | z_corner
        
        # Get child node info
        child_node = get_child_node(current_node, child_corner, address_space)
        
        # Push current node to stack for backtracking
        stack.push(current_node)
        
        # Update for next iteration
        depth += 1
        current_node = child_node
        scale /= 2.0
        lower = lower + child_corner_to_offset(child_corner, scale)
        upper = lower + scale
        center = lower + 0.5 * scale
        
    return current_node, stack

def is_inside(pos, lower, upper):
    return (lower.x <= pos.x <= upper.x) and \
           (lower.y <= pos.y <= upper.y) and \
           (lower.z <= pos.z <= upper.z)

def has_children(node, address_space):
    # Implementation detail: check if node pointer is valid/non-null
    return node is not None and node.is_valid()

def get_child_node(parent, corner, address_space):
    # Implementation detail: calculate address and read node
    return address_space.read(parent.offset + corner * node_size)

def child_corner_to_offset(corner, scale):
    x = (corner & 1) * scale
    y = ((corner >> 1) & 1) * scale
    z = ((corner >> 2) & 1) * scale
    return vec3(x, y, z)
```

### Parameters
- `max_depth`: Typical value is 0 for full leaf traversal, or a specific integer (e.g., 10-14) for fixed-depth rendering [S1, unofficial].
- `root_scale`: Depends on the scene bounding box, typically 1.0 for normalized coordinates [S1, unofficial].

### Edge cases and pitfalls
- **Ray outside root**: If `raypos` is not within `[root_lower, root_upper]`, the function must return a null node immediately [S1, unofficial].
- **Null children**: If a node has no children (leaf), the loop breaks, and the leaf node is returned [S1, unofficial].
- **Precision**: Floating-point comparisons for `pos < center` must be consistent to avoid jitter or missed nodes in deep trees [G].

## Subtopics

### SVO First Node Selection
A helper function that determines the optimal starting child node for traversal. Unlike simple corner-based selection, it uses ray-cube intersection tests to find the first child the ray actually enters, optimizing for rays that might enter through a face or edge rather than just a corner. It iterates through all 8 corners, calculates bounds, checks intersection via `svo_fast_forward_intersects_f3`, and selects the child with the minimum exit distance [S1, unofficial].

## Operating characteristics
- **Time Complexity**: $O(D)$ where $D$ is the depth of the tree, as it performs a constant amount of work per level.
- **Memory Complexity**: $O(D)$ for the stack, storing the path from root to leaf.
- **Performance**: Highly efficient for sparse data as it skips empty space by following pointers directly. Performance degrades if the ray traverses many empty nodes before hitting occupied ones, though the first-node selection mitigates this [S1, unofficial].
- **Strengths**: Simple logic, low overhead per step, easy to implement in shaders.
- **Limitations**: Requires a stack for backtracking, which can be expensive in memory-constrained environments if not optimized.

## Background
The method is derived from implementations in real-time SVO rendering systems, specifically noted in the `landscapes` repository by realazthat [S1, unofficial]. It represents a standard approach to hierarchical ray traversal where the tree structure is flattened into arrays and accessed via global offsets.
