# Sparse Voxel Octree Ray Traversal

Also called: Sparse Voxel Octree Traversal, SVO Traversal, Sparse Voxel Octree Raycasting, Sparse Voxel Octree Tracing

## Overview
Sparse Voxel Octree (SVO) Ray Traversal is a hierarchical raycasting technique that renders 3D voxel data by traversing an octree structure along ray paths to find occupied cells and their bounding boxes [S2, S3, S6, S8, unofficial]. It solves the problem of efficiently rendering complex voxel-based geometry by skipping empty space, avoiding the need to sample every voxel [S1, S6, unofficial]. Unlike fixed-grid methods like [DDA Traversal](3061-digital-differential-analyzer-dda-traversal.md) which iterate through every cell, SVO traversal descends only into occupied subtrees, providing an implicit Level-of-Detail (LOD) mechanism based on viewer distance [S3, unofficial][S7]. It sets itself apart from [Hierarchical Trilinear Ray Casting](851-hierarchical-trilinear-ray-casting.md) by operating directly on the discrete octree node hierarchy rather than pre-filtered texture grids, and from [Stackless Traversal](5202-stackless-traversal.md) by typically requiring explicit backtracking logic (stack or recursion) to handle the tree's branching structure [S1, S4, S6, S8, unofficial].

## How it works
The method traverses a Sparse Voxel Octree to find the first intersection with a solid voxel. The octree is a hierarchical structure where nodes representing empty space are not stored, making the structure sparse [S3, unofficial].

### Inputs and Outputs
*   **Inputs:**
    *   Ray: Origin $\mathbf{o}$ and direction $\mathbf{d}$ (normalized or unnormalized).
    *   Octree Data: A linear array of nodes. The root node is at index 0.
    *   Root Bounding Box: Defined by center $\mathbf{c}_{root}$ and radius $r_{root}$ (or min/max extents) [S1, S6, S8, unofficial].
*   **Outputs:**
    *   Intersection point $\mathbf{p}$, distance $t$, and surface normal $\mathbf{n}$ (or color/texture data if a leaf is reached) [S1, S6, unofficial].

### Data Structures
The specific layout varies by implementation, but common patterns include:

1.  **Node Structure (Array-based):**
    *   Each node is an integer or struct in a linear buffer [S3, S6, S8, unofficial].
    *   **Flags:** Bits indicating if the node is a leaf, if it is empty, or if children exist [S6, S8, unofficial].
        *   Example [S6, unofficial]: `node[0]` bit 31 is empty flag, bit 30 is leaf flag, bits 0-29 are child index.
        *   Example [S8, unofficial]: MSB (bit 31) set indicates internal node; value > 0 with MSB clear indicates leaf.
    *   **Pointers:** Index of the first child in the array [S3, S6, unofficial].
    *   **Data:** Color/Albedo stored in leaf nodes [S6, S8, unofficial].

2.  **Stack (for iterative traversal):**
    *   Stores state for backtracking: `node_address`, `frontal_mask` (or `idx`), `t_min`, `t_corner` [S8, unofficial].
    *   Max depth is typically limited (e.g., 16-32) [S1, S8, unofficial].

3.  **Ray Coefficients (Precomputed):**
    *   To avoid division in the loop, coefficients are precomputed [S6, S8, unofficial]:
        $$
        t_{coef, i} = \frac{1.0}{|d_i|}, \quad t_{bias, i} = t_{coef, i} \cdot o_i
        $$
        where $i \in \{x, y, z\}$. Note: Signs of $d_i$ determine the traversal direction and bias adjustments [S6, unofficial].

### Numbered Steps

1.  **Ray Initialization:**
    *   Compute ray direction from camera parameters (FOV, resolution, view matrix) [S4, S5, S8, unofficial].
    *   Clamp zero direction components to a small epsilon (e.g., $10^{-4}$) to prevent division by zero [S6, S8, S4, unofficial].
    *   Precompute $t_{coef}$ and $t_{bias}$ [S6, S8, unofficial].

2.  **Root Intersection:**
    *   Perform a slab-based ray-box intersection with the root bounding box [S1, S8, unofficial].
    *   Calculate $t_{min}$ (entry) and $t_{max}$ (exit). If $t_{min} > t_{max}$ or $t_{max} < 0$, the ray misses the scene [S1, S8, unofficial].
    *   Initialize traversal state: `current_node` = root, `scale` = root size, `t_min` = max(0.0, $t_{min}$) [S6, S8, unofficial].

3.  **Traversal Loop:**
    *   While `scale` > minimum voxel size (or max depth not reached):
        a.  **Node Fetch:** Load the current node value from the buffer [S8, unofficial].
        b.  **Empty Check:** If the node is marked empty, backtrack (pop from stack) [S8, S6, unofficial].
        c.  **Leaf Check:** If the node is a leaf, compute color/normal and terminate [S6, S8, unofficial].
        d.  **Internal Node Descent:**
            i.  Determine the child octant index $k$ that the ray enters. This is done by comparing the ray's position relative to the current node's center against the direction signs [S1, S6, S8, unofficial].
                *   Common heuristic: Use `t_corner` comparisons. If $t_{corner, i} > t_{min}$, the ray is on the "far" side of the center plane for axis $i$, setting bit $i$ in the index [S6, S8, unofficial].
            ii. Update `t_min` to the exit distance of the current child box ($t_{corner}$) [S8, unofficial].
            iii. Push current state (parent index, `t_max`, `scale`) to the stack [S6, S8, unofficial].
            iv. Update `current_node` to the child's address.
            v.  Halve `scale` (update `_step` = `scale` * 0.5) [S8, unofficial].
            vi. Update `t_corner` for the new child box based on the new center and `t_min` [S8, unofficial].

4.  **Empty Space Skipping (Advancing):**
    *   If the current node is empty or we need to skip to the next occupied node:
        a.  Calculate the exit distance of the current box ($t_{corner\_max}$) [S8, unofficial].
        b.  Determine `step_mask` for axes where the ray exits the current box boundary ($t_{corner, i} \le t_{corner\_max}$) [S8, unofficial].
        c.  Advance `t_corner` components by adding $\text{sign}(d_i) \cdot \text{step} / d_i$ for stepped axes [S8, unofficial].
        d.  Update `frontal_mask` (or index) by XORing with `step_mask` [S8, unofficial].
        e.  If no axes can be stepped (backtrack condition), pop from stack [S8, unofficial].

5.  **Backtracking:**
    *   If the stack is empty or depth < 0, the ray has exited the octree without a hit [S8, S4, unofficial].

### Formulas

**Ray-Box Intersection (Slab Method):**
For a box with min $\mathbf{b}_{min}$ and max $\mathbf{b}_{max}$:
$$
t_{min, i} = \frac{b_{min, i} - o_i}{d_i}, \quad t_{max, i} = \frac{b_{max, i} - o_i}{d_i}
$$
Swap if $t_{min, i} > t_{max, i}$.
$$
t_{entry} = \max(t_{min, x}, t_{min, y}, t_{min, z})
$$
$$
t_{exit} = \min(t_{max, x}, t_{max, y}, t_{max, z})
$$
Hit if $t_{entry} \le t_{exit}$ and $t_{exit} \ge 0$ [S1, S2, unofficial].

**Child Index Determination (Heuristic):**
Given current center $\mathbf{c}$ and ray direction $\mathbf{d}$:
$$
\text{idx} = 0
$$
If $d_x > 0$: if $t_{corner, x} > t_{min}$, $\text{idx} \ |= \ 1$ [S6, S8, unofficial].
If $d_y > 0$: if $t_{corner, y} > t_{min}$, $\text{idx} \ |= \ 2$ [S6, S8, unofficial].
If $d_z > 0$: if $t_{corner, z} > t_{min}$, $\text{idx} \ |= \ 4$ [S6, S8, unofficial].
*(Note: Exact bit mapping depends on octant ordering convention)* [S1, S6, unofficial].

**Child Box Center:**
$$
\mathbf{c}_{child} = \mathbf{c}_{parent} + \mathbf{P}[\text{idx}] \cdot \text{scale}
$$
where $\mathbf{P}$ is an array of octant vectors (e.g., $\mathbf{P}[0]=(0,0,0)$, $\mathbf{P}[1]=(1,0,0)$ in local space) [S3, S6, unofficial].

### Pseudocode

```python
# Constants
EPS = 1e-4
MAX_DEPTH = 32

# Data Structures
class StackEntry:
    node_address: int
    frontal_mask: int
    t_min: float
    t_corner: vec3

def traverse_svo(ray_origin, ray_direction, svo_buffer, root_min, root_max):
    # 1. Precompute Ray Coefficients
    # Clamp zero components to avoid division by zero
    d = vec3(
        max(EPS, abs(ray_direction.x)) * sign(ray_direction.x),
        max(EPS, abs(ray_direction.y)) * sign(ray_direction.y),
        max(EPS, abs(ray_direction.z)) * sign(ray_direction.z)
    )
    
    t_coef = vec3(1.0 / d.x, 1.0 / d.y, 1.0 / d.z)
    t_bias = t_coef * ray_origin
    
    # 2. Root Intersection
    t_min_root = max(
        (root_min.x - ray_origin.x) / d.x,
        (root_min.y - ray_origin.y) / d.y,
        (root_min.z - ray_origin.z) / d.z
    )
    t_max_root = min(
        (root_max.x - ray_origin.x) / d.x,
        (root_max.y - ray_origin.y) / d.y,
        (root_max.z - ray_origin.z) / d.z
    )
    
    if t_min_root > t_max_root or t_max_root < 0:
        return None # Miss
    
    t_min = max(0.0, t_min_root)
    
    # 3. Initialization
    node_address = 0 # Root index
    scale = (root_max.x - root_min.x) / 2.0 # Assuming cubic root
    _step = scale * 0.5
    center = (root_min + root_max) / 2.0
    
    # Determine initial child based on t_min
    # t_center is distance to center plane
    t_center = (center - ray_origin) / d
    
    # Frontal mask: bits set if ray is on the "far" side of center plane
    frontal_mask = 0
    if t_center.x > t_min: frontal_mask |= 1
    if t_center.y > t_min: frontal_mask |= 2
    if t_center.z > t_min: frontal_mask |= 4
    
    # Corner is the exit point of the current box
    corner = center + vec3(
        -_step if not (frontal_mask & 1) else _step,
        -_step if not (frontal_mask & 2) else _step,
        -_step if not (frontal_mask & 4) else _step
    )
    t_corner = (corner - ray_origin) / d
    t_corner_max = min(t_corner.x, t_corner.y, t_corner.z)
    
    stack = [StackEntry() for _ in range(MAX_DEPTH)]
    depth = 0
    
    # 4. Traversal Loop
    while True:
        # Fetch Node
        value = svo_buffer[node_address]
        
        # Check Empty (MSB set in some implementations, or specific flag)
        # Assuming MSB (bit 31) is empty flag for internal nodes in this example
        # Adjust based on specific SVO layout [S6, S8, unofficial]
        is_empty = (value & 0x80000000) != 0
        is_leaf = (value & 0x80000000) == 0 and value > 0
        
        if is_empty:
            # Backtrack
            if depth == 0:
                return None # No hit
            depth -= 1
            node_address = stack[depth].node_address
            frontal_mask = stack[depth].frontal_mask
            t_min = stack[depth].t_min
            t_corner = stack[depth].t_corner
            scale *= 2.0
            _step = scale * 0.5
            continue
            
        if is_leaf:
            # Hit! Compute color/normal
            return compute_leaf_data(value, ray_origin, ray_direction, t_min)
        
        # Internal Node: Descend
        # Push state
        if depth >= MAX_DEPTH:
            return None # Stack overflow
            
        stack[depth].node_address = node_address
        stack[depth].frontal_mask = frontal_mask
        stack[depth].t_min = t_min
        stack[depth].t_corner = t_corner
        depth += 1
        
        # Determine next child
        # Update t_min to current box exit
        t_min = t_corner_max
        
        # Calculate child center and corner
        # New scale is half
        scale *= 0.5
        _step = scale * 0.5
        
        # New center relative to old corner? 
        # Actually, we need the center of the CHILD box.
        # The child box center is parent_center + offset.
        # But we are tracking 'corner' as the exit point.
        # Let's recalculate center of the new child box.
        # The 'frontal_mask' tells us which octant we are in.
        # Child center = Parent Center + (frontal_mask bits mapped to +/- _step)
        # However, 'center' variable in loop usually tracks the CURRENT node's center.
        
        # Recalculate center for the new child node
        # The 'frontal_mask' was computed based on the PARENT's center.
        # The new node's center is:
        new_center = center + vec3(
            _step if (frontal_mask & 1) else -_step,
            _step if (frontal_mask & 2) else -_step,
            _step if (frontal_mask & 4) else -_step
        )
        center = new_center
        
        # Update t_center for the new child
        t_center = (center - ray_origin) / d
        
        # Reset frontal_mask for the new child based on its center
        frontal_mask = 0
        if t_center.x > t_min: frontal_mask |= 1
        if t_center.y > t_min: frontal_mask |= 2
        if t_center.z > t_min: frontal_mask |= 4
        
        # Update corner (exit of new child box)
        corner = center + vec3(
            -_step if not (frontal_mask & 1) else _step,
            -_step if not (frontal_mask & 2) else _step,
            -_step if not (frontal_mask & 4) else _step
        )
        t_corner = (corner - ray_origin) / d
        t_corner_max = min(t_corner.x, t_corner.y, t_corner.z)
        
        # Update node_address
        # The child address is stored in the current node's value
        # Assuming value & 0x7FFFFFFF is the child index
        child_index = value & 0x7FFFFFFF
        node_address = child_index # Simplified: assumes direct mapping or requires offset
        
        # If the implementation uses a pointer array, node_address = buffer[child_index]
        # For this pseudocode, we assume the value itself contains the pointer or index
        # In many SVOs, the node value IS the pointer to the child block.
        # If it's a DAG or indirect, we might need: node_address = svo_buffer[child_index]
        
        # Continue loop with new node

    return None
```

### Parameters
*   **Root Radius/Size:** Defines the initial bounding box [S1, S3, unofficial].
*   **Max Depth:** Limits traversal to prevent infinite loops or stack overflow (e.g., 16-32) [S2, S8, unofficial].
*   **Epsilon:** Small value to handle degenerate rays (e.g., $10^{-4}$) [S6, S8, unofficial].
*   **Stack Size:** Maximum backtracking depth [S6, S8, unofficial].

### Edge Cases and Pitfalls
*   **Zero Direction Components:** Clamping $d_i$ to EPSILON is required to avoid division by zero [S6, S8, S4, unofficial].
*   **Boundary Precision:** If the ray lies exactly on a boundary, tie-breaking logic (e.g., adding epsilon to position) is needed to ensure consistent child selection [S1, S2, unofficial].
*   **Stack Overflow:** Fixed-size stacks require checking depth limits [S8, unofficial].
*   **Texture Repeat Artifacts:** In texture-based SVOs, ensure lookup points are within valid bounds or use clamping [S2, unofficial].
*   **Recursion Limits:** HLSL does not support recursion; iterative stack-based traversal is mandatory [S3, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(\log N)$ for traversal to a leaf in a balanced octree, where $N$ is the number of voxels. In practice, it is proportional to the number of occupied nodes visited [S3, unofficial][S7].
*   **Memory Complexity:** $O(N_{occupied})$ nodes, significantly less than $O(N_{total})$ for dense grids [S3, unofficial][S7].
*   **Performance:** Can render >1 billion voxels at 20 FPS at 720p on modern GPUs (e.g., AMD 5700) [S6, unofficial].
*   **Strengths:** Efficient empty space skipping, implicit LOD, single draw call for ray generation [S1, S6, unofficial].
*   **Limitations:** Memory overhead for node pointers, difficult dynamic updates (often requires full rebuild) [S3, unofficial][S7].
*   **When to Use:** Static or semi-static voxel scenes, large datasets, real-time rendering.
*   **When Not to Use:** Highly dynamic voxel data requiring frequent updates, or scenes with very low occupancy where a simple grid might be faster due to lower overhead.

## Background
Sparse Voxel Octrees were introduced as a hierarchical data structure for raycasting, allowing efficient rendering of complex voxel models [S3, unofficial]. The technique builds on the DDA traversal principles but applies them hierarchically [S5, unofficial]. It is widely used in real-time rendering engines and research for rendering high-resolution voxel data, such as the Stanford Dragon and large-scale procedural scenes [S6, unofficial]. The method has evolved to include DAG variants for compression and GPU-optimized traversal techniques [S1, unofficial][S7].
