# Sparse Voxel Octree Ray Traversal

Also called: Sparse Voxel Octree Traversal, SVO Traversal, Sparse Voxel Octree Raycasting, Sparse Voxel Octree Tracing

## Overview
Sparse Voxel Octree (SVO) Ray Traversal is a raycasting technique that renders sparse voxel data stored in a 3D sparse octree structure by traversing the hierarchy along ray paths to find occupied cells and their bounding boxes [S2, S6, S8, unofficial]. It solves the problem of efficiently rendering large, complex voxel scenes by skipping empty space using axis-aligned slab intersection logic, avoiding the need to sample every voxel in the volume [S1, S6, unofficial]. Unlike standard rasterization which requires mesh generation and draw calls per chunk, SVO ray tracing renders the entire scene with a single draw call (e.g., a fullscreen triangle) and no vertex buffers [S6, unofficial]. It differs from its siblings, such as [SVO Ray Tracing](3451-svo-ray-tracing.md), by explicitly handling backtracking via a stack or recursive logic to manage hierarchical node descent, rather than relying solely on parallel array-based stack simulation or direct texture sampling [S2, S3, S6, unofficial].

## How it works
The method traverses a Sparse Voxel Octree to find the first intersection with a solid voxel. The octree is stored as a linear array of nodes, where empty nodes are omitted, making the structure sparse [S3, unofficial].

### Inputs and Outputs
**Inputs:**
*   **Ray:** Origin $O$ and direction $D$ (normalized).
*   **SVO Data:** A linear array of nodes. The root node is at index 0.
*   **Root Bounds:** The bounding box of the root node, defined by center $C_{root}$ and radius $R_{root}$ (or min/max corners) [S1, S6, unofficial].
*   **Camera Parameters:** Viewport dimensions, FOV, and projection matrices (for ray generation) [S4, S5, unofficial].

**Outputs:**
*   **Hit Distance:** The $t$ value along the ray where the first occupied leaf node is intersected.
*   **Hit Position:** The 3D world position of the intersection.
*   **Color/Normal:** Data fetched from the leaf node (e.g., color, density) [S6, unofficial].

### Data Structures
The SVO is typically stored in a flat array. Two common layouts are observed:

1.  **Bitfield Mask Layout [S1, S4, unofficial]:**
    *   Each node is a struct or pair of integers.
    *   `masks` (uint): A 32-bit integer where bits track the status of 8 children.
        *   Bits 24-31: Valid mask (is the child node present in memory?).
        *   Bits 16-23: Leaf mask (is the child a leaf node?).
    *   `childPointer` (uint): An offset added to the current node's index to find the first child in the array.
    *   *Alternative [S4, unofficial]:* `data[block_i]` stores the child pointer. `data[block_i + 1]` stores leaf/valid bits: `leaf = data[block_i + 1] >> 8`, `valid = data[block_i + 1] & 0xff`.

2.  **Flag/Index Layout [S6, unofficial]:**
    *   `SVONode` struct containing two `u32` values.
    *   `node[0]`: Bit 31 is the empty flag. Bit 30 is the leaf flag. Bits 0-29 are the child index offset.
    *   `node[1]`: Color data (RGBA).

3.  **Stack Structure [S8, unofficial]:**
    *   Used for backtracking. Stores `node_address`, `frontal_mask`, `t_min`, and `t_corner`. Max depth is typically 32 [S8, unofficial].

### Algorithm Steps

1.  **Ray Generation:**
    For each pixel, generate a ray in world space.
    *   Compute normalized device coordinates (NDC) from fragment coordinates [S4, S8, unofficial].
    *   Transform to view space and then world space using inverse projection and view matrices [S8, unofficial].
    *   Normalize direction $D$.
    *   **Pitfall:** Clamp zero components of $D$ to $\pm \epsilon$ (e.g., $10^{-4}$) to prevent division by zero during slab calculations [S6, S8, unofficial].

2.  **Root Intersection:**
    *   Compute the intersection of the ray with the root bounding box $[B_{min}, B_{max}]$ using the slab method [S1, S8, unofficial].
    *   Calculate $t_{min} = \max(\frac{B_{min} - O}{D})$ and $t_{max} = \min(\frac{B_{max} - O}{D})$ per axis, swapping if $t_{min} > t_{max}$.
    *   If $t_{min} > t_{max}$ or $t_{max} < 0$, the ray misses the root. Return background color [S1, S8, unofficial].
    *   Set initial traversal state: current node index $idx = 0$, current scale $S = R_{root}$ (or half-extent), and $t_{min}$ clamped to $\max(0, t_{min})$ [S6, S8, unofficial].

3.  **Traversal Loop:**
    Iterate while the stack is not empty and depth is within limits [S6, S8, unofficial]:
    
    a.  **Fetch Node:** Load the current node from the SVO array at $idx$ [S8, unofficial].
    
    b.  **Check Node Type:**
        *   **Empty:** If the node is marked empty, backtrack (pop stack) [S8, unofficial].
        *   **Leaf:** If the node is marked a leaf, compute the intersection with the leaf's voxel (cube). If hit within $t_{min}$ and $t_{max}$, record hit and terminate. Otherwise, backtrack [S6, S8, unofficial].
        *   **Internal:** Proceed to descend.
    
    c.  **Determine Child Octant:**
        *   Calculate the center of the current node's bounding box $C_{curr}$ [S8, unofficial].
        *   Compute $t_{center} = (C_{curr} - O) / D$ [S8, unofficial].
        *   Determine the `frontal_mask` based on whether $t_{center}$ components are greater than $t_{min}$ [S8, unofficial].
        *   The child octant is determined by comparing the ray position relative to $C_{curr}$. Specifically, the octant index $i$ is derived from the signs of $(O + D \cdot t_{min}) - C_{curr}$ [S1, S6, unofficial].
        *   *Heuristic [S1, unofficial]:* Use the exit normal of the previous box to determine the next child index via a lookup table.
    
    d.  **Descend:**
        *   Update $idx$ to point to the selected child: $idx = idx + childPointer + octant\_index$ (or using bitfield logic) [S1, S4, unofficial].
        *   Halve the scale: $S = S / 2$ [S8, unofficial].
        *   Update $t_{min}$ to the intersection distance with the child's near plane (or the current $t_{corner}$) [S6, S8, unofficial].
        *   Push the current state (parent index, $t_{max}$, etc.) to the stack for potential backtracking [S6, S8, unofficial].
    
    e.  **Advance (Empty Space Skipping):**
        *   If the current node is empty or we need to skip to the next sibling, calculate the exit distance $t_{exit}$ from the current box [S8, unofficial].
        *   Update $t_{min} = t_{exit}$.
        *   Step the ray position to the next voxel boundary along the axes where the ray exits [S6, S8, unofficial].
        *   If no valid child is found or backtracking is required, pop the stack and restore the previous state [S8, unofficial].

### Pseudocode
```python
# Constants
EPSILON = 1e-4
MAX_DEPTH = 32

# Data Structures
class StackEntry:
    node_address: int
    frontal_mask: int
    t_min: float
    t_corner: vec3

def ray_box_intersect(origin, direction, box_min, box_max):
    """Returns (t_min, t_max) or None if no intersection."""
    t_min = (box_min - origin) / direction
    t_max = (box_max - origin) / direction
    
    # Swap if necessary
    t1 = min(t_min, t_max)
    t2 = max(t_min, t_max)
    
    t_near = max(t1.x, t1.y, t1.z)
    t_far = min(t2.x, t2.y, t2.z)
    
    if t_near > t_far:
        return None
    
    return (t_near, t_far)

def traverse_svo(ray_origin, ray_direction, svo_data, root_min, root_max):
    # 1. Intersect with root
    root_hit = ray_box_intersect(ray_origin, ray_direction, root_min, root_max)
    if root_hit is None:
        return None # Missed scene
    
    t_min, t_max = root_hit
    t_min = max(t_min, 0.0) # Ignore behind camera
    
    # 2. Initialize state
    stack = []
    current_node_idx = 0
    current_scale = (root_max.x - root_min.x) / 2.0 # Half-extent
    current_center = (root_min + root_max) / 2.0
    
    # Precompute ray coefficients for speed
    inv_dir = 1.0 / ray_direction
    # Clamp zero components
    inv_dir = vec3(
        EPSILON if abs(ray_direction.x) < EPSILON else inv_dir.x,
        EPSILON if abs(ray_direction.y) < EPSILON else inv_dir.y,
        EPSILON if abs(ray_direction.z) < EPSILON else inv_dir.z
    )
    
    # Bias terms for slab intersection
    tx_coef = -inv_dir.x
    ty_coef = -inv_dir.y
    tz_coef = -inv_dir.z
    tx_bias = tx_coef * ray_origin.x
    ty_bias = ty_coef * ray_origin.y
    tz_bias = tz_coef * ray_origin.z
    
    # Determine initial octant based on t_min
    # Calculate corner of the child box at t_min
    # This logic varies by implementation; here we use the frontal_mask approach
    
    depth = 0
    
    while True:
        # Fetch node
        node = svo_data[current_node_idx]
        
        # Check if empty (bit 31 set in node[0] for S6 layout)
        if (node.flags & 0x80000000) != 0:
            # Backtrack
            if depth == 0:
                return None # No hit
            depth -= 1
            entry = stack[depth]
            current_node_idx = entry.node_address
            t_min = entry.t_min
            current_scale /= 2.0 # Restore scale logic if needed, or manage via stack
            continue
            
        # Check if leaf
        if (node.flags & 0x40000000) != 0:
            # Leaf node: intersect with voxel
            # Voxel bounds are derived from current_center and current_scale
            voxel_min = current_center - vec3(current_scale)
            voxel_max = current_center + vec3(current_scale)
            
            leaf_hit = ray_box_intersect(ray_origin, ray_direction, voxel_min, voxel_max)
            if leaf_hit and leaf_hit[0] < t_max:
                return leaf_hit # Hit found
            else:
                # Backtrack
                if depth == 0:
                    return None
                depth -= 1
                entry = stack[depth]
                current_node_idx = entry.node_address
                t_min = entry.t_min
                continue
        
        # Internal node: Descend
        # Calculate t_center
        t_center = (current_center - ray_origin) * inv_dir
        
        # Determine frontal_mask: bits set if t_center component > t_min
        frontal_mask = 0
        if t_center.x > t_min: frontal_mask |= 1
        if t_center.y > t_min: frontal_mask |= 2
        if t_center.z > t_min: frontal_mask |= 4
        
        # Calculate t_corner for the child defined by frontal_mask
        # The child corner is the center adjusted by scale in directions where mask bit is 0
        step = current_scale
        corner = current_center
        if not (frontal_mask & 1): corner.x += step
        if not (frontal_mask & 2): corner.y += step
        if not (frontal_mask & 4): corner.z += step
        
        t_corner = (corner - ray_origin) * inv_dir
        t_corner_max = min(t_corner.x, t_corner.y, t_corner.z)
        
        # Update t_min to the exit of the current box (or entry of child)
        t_min = t_corner_max
        
        # Check if we need to backtrack because we exited the valid range
        if t_min > t_max:
             if depth == 0: return None
             depth -= 1
             entry = stack[depth]
             current_node_idx = entry.node_address
             t_min = entry.t_min
             continue

        # Push state for backtracking
        if depth < MAX_DEPTH:
            stack.append(StackEntry(
                node_address=current_node_idx,
                frontal_mask=frontal_mask,
                t_min=t_min, # Save the t_min before it gets overwritten by child logic? 
                             # Actually, we save the state to return to.
                             # The source [S8, unofficial] saves t_min and t_corner.
                t_corner=t_corner
            ))
            depth += 1
        
        # Descend to child
        # Child index is determined by the octant corresponding to the ray's position relative to center
        # Or simply by the frontal_mask logic inverted? 
        # Standard SVO: child index is based on which octant the ray enters.
        # Using the mask to find the child pointer offset.
        
        # Calculate child index from the octant the ray is currently in
        # Ray position at t_min is roughly the corner. 
        # Determine octant index i (0-7)
        ray_pos_at_min = ray_origin + ray_direction * t_min
        octant = 0
        if ray_pos_at_min.x > current_center.x: octant |= 1
        if ray_pos_at_min.y > current_center.y: octant |= 2
        if ray_pos_at_min.z > current_center.z: octant |= 4
        
        # Update node index
        current_node_idx = current_node_idx + node.child_offset + octant
        
        # Update scale and center for next iteration
        current_scale /= 2.0
        current_center = corner # The corner we stepped to is the new center? 
                                # No, the new center is the center of the child box.
                                # Child center = current_center + offset * current_scale (old)
                                # Offset is determined by octant.
        
        # Recalculate center for the child
        # P[octant] is the vector from parent center to child center in units of half-size
        # P[0]=(0,0,0), P[1]=(1,0,0)... wait, standard octant vectors:
        # 0: (-,-,-), 1: (1,-,-), etc. depending on coord system.
        # Let's use the standard:
        offsets = [
            vec3(-1, -1, -1), vec3(1, -1, -1), vec3(-1, 1, -1), vec3(1, 1, -1),
            vec3(-1, -1, 1), vec3(1, -1, 1), vec3(-1, 1, 1), vec3(1, 1, 1)
        ]
        current_center = current_center + offsets[octant] * current_scale # current_scale is already halved
        
        # Continue loop
```

### Parameters
*   **Root Radius/Size:** The initial bounding box size of the octree [S1, S3, unofficial].
*   **Max Depth:** Limits recursion/stack depth (e.g., 16, 23, or 32) [S2, S6, S8, unofficial].
*   **EPSILON:** Small value to prevent division by zero (e.g., $10^{-4}$ or $3.55 \times 10^{-15}$) [S6, S8, unofficial].
*   **FOV:** Field of view for ray generation (e.g., 45-50 degrees) [S5, S6, unofficial].

### Edge Cases and Pitfalls
*   **Zero Direction Components:** Clamping $D$ components to $\pm \epsilon$ is required to avoid NaNs in $1/D$ [S6, S8, unofficial].
*   **Boundary Precision:** If the ray position lies exactly on a node boundary, tie-breaking logic (e.g., adding $0.1 \times D$) is needed to consistently select an octant [S1, unofficial].
*   **Stack Overflow:** Fixed-size stacks (e.g., 32 entries) assume the octree depth does not exceed this limit. Overflow leads to incorrect backtracking [S8, unofficial].
*   **Texture Repeat Artifacts:** In direct texture lookup variants, rays outside the unit cube must be clamped or advanced to avoid wrapping [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(\log N)$ on average for sparse scenes, where $N$ is the number of voxels, as empty space is skipped. In the worst case (dense scene), it approaches $O(N)$ [S3, unofficial][S7].
*   **Memory Complexity:** $O(M)$ where $M$ is the number of non-empty nodes. Significantly less than dense voxel grids [S7].
*   **Performance:** Capable of rendering large scenes (e.g., >1 billion voxels) at real-time frame rates (e.g., 20 FPS at 720p) on modern GPUs [S6, unofficial].
*   **Strengths:** Efficient empty space skipping, implicit LOD, single draw call rendering [S6, unofficial].
*   **Limitations:** Dynamic updates are expensive (often requiring full reconstruction); memory overhead for node structures can be high at very high resolutions [S3, unofficial][S7].

## Background
Sparse Voxel Octrees were introduced as an efficient data structure for raycasting, building on the concept of octrees but omitting empty nodes to save memory [S3, unofficial]. The technique gained prominence with papers such as "Octree Textures on the GPU" (GPU Gems) and later optimizations by Laine and Karras [S2, S6, unofficial]. It is widely used in real-time voxel rendering engines and research projects like the Stanford Dragon renderer [S6, unofficial].
