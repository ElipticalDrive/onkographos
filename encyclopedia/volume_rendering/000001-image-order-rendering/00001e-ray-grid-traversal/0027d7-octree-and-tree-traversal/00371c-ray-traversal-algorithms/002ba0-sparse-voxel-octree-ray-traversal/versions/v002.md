# Sparse Voxel Octree Ray Traversal

Also called: Sparse Voxel Octree Traversal, SVO Traversal, Sparse Voxel Octree Raycasting, Sparse Voxel Octree Tracing

## Overview
Sparse Voxel Octree (SVO) Ray Traversal is a hierarchical ray-casting algorithm that traverses a 3D sparse voxel octree to find the first occupied leaf node (voxel) intersected by a ray [S1, S4, S6, unofficial]. It solves the problem of efficiently rendering large, sparse 3D volumes by skipping empty space and adapting resolution based on viewer distance (implicit Level-of-Detail) [S2, unofficial][S5, unofficial]. It sets itself apart from sibling methods by using a fixed-size traversal stack or iterative descent to manage backtracking through the octree hierarchy, rather than recursion or explicit ray-box intersection at every level [S4, S6, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Ray origin $O$, ray direction $D$ (normalized), SVO data buffer, camera parameters (position, rotation, FOV, viewport size) [S4, S6, unofficial].
*   **Output:** Hit distance $t$, hit position $P$, surface normal $N$, and color $C$. If no hit, return failure/transparent [S4, S6, unofficial].

**Data Structures:**
The SVO is stored as a linear array of nodes [S3, S4, S6, unofficial].
1.  **Compact Node (S4/S6):** Each node is a 32-bit integer.
    *   Bit 31 (MSB): Internal node flag. S4 and S6 use MSB=1 for internal nodes [S4, S6, unofficial]. S1 and S2 use different layouts [S1, S2, unofficial].
    *   Bit 30: Leaf flag [S6, unofficial].
    *   Bits 0-29: Child index (pointer to next node in array) or Color data (if leaf) [S4, S6, unofficial].
2.  **Alternative Layout (S2):** `struct OctreeEntry { int childrenStartIndex; int data; }`. `childrenStartIndex` points to the first of 8 sequential children. `data` contains a bitfield for voxel presence [S2, unofficial].
3.  **Stack:** A fixed-size array to store traversal state for backtracking [S4, S6, unofficial].
    *   S4 Stack: `struct { uint node; float t_max; } stack[16]` [S4, unofficial].
    *   S6 Stack: `struct { uint node_address; uint frontal_mask; float t_min; vec3 t_corner; } stack[32]` [S6, unofficial].

**Parameters:**
*   $S_{MAX}$: Maximum scale/depth. Typically 23 (matching float mantissa bits) [S4, unofficial].
*   $\epsilon$: Epsilon for ray direction clamping. $10^{-4}$ [S4, unofficial] or $3.55 \times 10^{-15}$ [S6, unofficial].
*   $RootRadius$: Radius of the root bounding box [S1, unofficial].

**Algorithm Steps:**

1.  **Ray Initialization:**
    *   Compute ray direction from screen coordinates (fragment shader) or camera parameters [S4, S6, unofficial].
    *   Clamp direction components to $\epsilon$ if $|d_i| < \epsilon$ to avoid division by zero [S4, S6, unofficial].
    *   Precompute ray coefficients for slab intersection: $t_{coef} = 1.0 / |D|$ and $t_{bias} = t_{coef} \cdot O$ [S4, unofficial].
    *   Determine `oct_mask` based on ray direction signs to optimize traversal order and bias calculations:
        *   If $D_x > 0$: `oct_mask ^= 1`, $t_{bias,x} = 3.0 \cdot t_{coef,x} - t_{bias,x}$ [S4, unofficial].
        *   If $D_y > 0$: `oct_mask ^= 2`, $t_{bias,y} = 3.0 \cdot t_{coef,y} - t_{bias,y}$ [S4, unofficial].
        *   If $D_z > 0$: `oct_mask ^= 4`, $t_{bias,z} = 3.0 \cdot t_{coef,z} - t_{bias,z}$ [S4, unofficial].

2.  **Root Intersection:**
    *   Compute ray-box intersection with the root bounding box $[-R, R]$ (or defined min/max) [S1, S6, unofficial].
    *   If no intersection, return failure.
    *   Initialize traversal state:
        *   `node_address` = Root Index (usually 0) [S6, unofficial].
        *   `scale` = $S_{MAX} - 1$ [S4, unofficial] or `depth` = 0 [S6, unofficial].
        *   `size` = Root Size (e.g., $2R$) [S6, unofficial].
        *   `step` = $size / 2$ [S6, unofficial].
        *   `pos` = Initial position in local coordinates (often $(1,1,1)$ or derived from entry point) [S4, S6, unofficial].
        *   `idx` = Initial child index (0-7) determined by which octant the ray enters [S1, S6, unofficial].
        *   `t_min` = Entry distance to root [S1, S6, unofficial].
        *   `t_max` = Exit distance to root [S1, S6, unofficial].

3.  **Traversal Loop:**
    While `scale` < $S_{MAX}$ (or `depth` < MaxDepth):

    a.  **Fetch Node:**
        *   Load node value from `SVO[node_address]` [S4, S6, unofficial].

    b.  **Check Node Type:**
        *   **Internal Node:** (MSB indicates internal, e.g., `val & 0x80000000` in S4/S6) [S4, S6, unofficial].
            *   Calculate child index: `child_idx = ((node & 0x7FFFFFFF) * 2) + ((idx ^ oct_mask) * 2)` (S4) or similar mapping [S4, S6, unofficial].
            *   Fetch child node.
            *   **Push State:** Save current `node_address`, `t_max` (and other context like `frontal_mask` in S6) to stack [S4, S6, unofficial].
            *   **Descend:**
                *   Update `node_address` = `child_idx`.
                *   Decrease `scale` by 1, update `scale_exp2` (half the previous step size) [S4, unofficial].
                *   Update `pos` and `idx` based on the center of the child box relative to `t_min` [S4, S6, unofficial].
                *   Update `t_max` to the intersection distance with the child box boundary (`tv_max`) [S4, unofficial].
                *   Continue loop.
        *   **Leaf Node:** (MSB indicates leaf, or specific flag) [S4, S6, unofficial].
            *   Unpack color from node data (RGB in lower bits, Alpha in upper) [S4, S6, unofficial].
            *   Return hit with color, position, and normal [S4, S6, unofficial].

    c.  **Advance (Empty Space Skipping):**
        *   If the current node is empty or we need to step to the next sibling:
            *   Calculate `t_corner` (exit time from current voxel) using `pos * t_coef - t_bias` [S4, unofficial].
            *   Find `tc_max` = min(`t_corner.x`, `t_corner.y`, `t_corner.z`) [S4, unofficial].
            *   Update `t_min` = `tc_max` [S4, unofficial].
            *   Determine `step_mask`: bits set for axes where `t_corner` component $\le t_{min}$ (actually, where the ray exits the current voxel along that axis) [S4, unofficial].
            *   Update `pos` by subtracting `scale_exp2` for stepped axes [S4, unofficial].
            *   Update `idx` by XORing with `step_mask` [S4, unofficial].
            *   If `t_min` exceeds ray exit distance or BVH culling threshold, break/return failure [S4, unofficial].

    d.  **Backtrack (Pop):**
        *   If `idx` and `step_mask` indicate a backtrack is needed (e.g., `(idx & step_mask) != 0` in S4, or `frontal_mask & step_mask` check in S6):
            *   Pop state from stack [S4, S6, unofficial].
            *   Restore `scale`, `t_max`, `node_address`, etc. [S4, S6, unofficial].
            *   Adjust `pos` by rounding to the restored scale (bit manipulation) [S4, unofficial].
            *   Continue loop.

4.  **Normal Calculation:**
    *   Normals are often calculated on-the-fly based on the exit face of the leaf voxel [S4, unofficial].
    *   Determine face from `oct_mask` and `step_mask` [S4, unofficial].
    *   Map face to normal vector (e.g., Face 1 -> $(1,0,0)$, Face 3 -> $(-1,0,0)$) [S4, unofficial].

**Pseudocode (Based on S4/S6 Hybrid):**

```python
def ray_box_intersect(origin, direction, box_min, box_max):
    t_min = (box_min - origin) / direction
    t_max = (box_max - origin) / direction
    t1 = min(t_min, t_max)
    t2 = max(t_min, t_max)
    t_near = max(t1.x, t1.y, t1.z)
    t_far = min(t2.x, t2.y, t2.z)
    return t_near, t_far

def traverse_svo(ray_origin, ray_dir, svo_data, root_radius):
    eps = 1e-4
    d = vec3(
        eps if abs(ray_dir.x) < eps else ray_dir.x,
        eps if abs(ray_dir.y) < eps else ray_dir.y,
        eps if abs(ray_dir.z) < eps else ray_dir.z
    )
    t_coef = 1.0 / abs(d)
    t_bias = t_coef * ray_origin
    
    oct_mask = 0
    if d.x > 0: oct_mask |= 1; t_bias.x = 3.0 * t_coef.x - t_bias.x
    if d.y > 0: oct_mask |= 2; t_bias.y = 3.0 * t_coef.y - t_bias.y
    if d.z > 0: oct_mask |= 4; t_bias.z = 3.0 * t_coef.z - t_bias.z

    box_min = vec3(-root_radius)
    box_max = vec3(root_radius)
    t_min, t_max = ray_box_intersect(ray_origin, d, box_min, box_max)
    if t_min > t_max: return None

    S_MAX = 23
    scale = S_MAX - 1
    scale_exp2 = 0.5
    node_addr = 0
    idx = 0
    pos = vec3(1.0)
    
    stack_node = [0] * S_MAX
    stack_t_max = [0.0] * S_MAX

    while scale < S_MAX:
        node_val = svo_data[node_addr]
        
        # S4/S6: MSB=1 means internal node
        is_internal = (node_val & 0x80000000) != 0
        
        if is_internal:
            child_idx = ((node_val & 0x7FFFFFFF) * 2) + ((idx ^ oct_mask) * 2)
            child_val = svo_data[child_idx]
            
            stack_node[scale] = node_addr
            stack_t_max[scale] = t_max
            
            node_addr = child_idx
            scale -= 1
            scale_exp2 *= 0.5
            
            t_center = scale_exp2 * t_coef + (pos * t_coef - t_bias)
            if t_center.x > t_min: idx |= 1; pos.x += scale_exp2
            if t_center.y > t_min: idx |= 2; pos.y += scale_exp2
            if t_center.z > t_min: idx |= 4; pos.z += scale_exp2
            
            t_max = min(t_max, min(pos.x, pos.y, pos.z) * t_coef - t_bias)
            continue

        # Leaf or empty
        if (node_val & 0x40000000) != 0: # Leaf flag
            color = svo_data[node_addr + 1]
            return {"t": t_min, "pos": pos, "color": color}
        
        # Advance / Backtrack
        t_corner = pos * t_coef - t_bias
        tc_max = min(t_corner.x, t_corner.y, t_corner.z)
        
        step_mask = 0
        if t_corner.x <= tc_max: step_mask |= 1; pos.x -= scale_exp2
        if t_corner.y <= tc_max: step_mask |= 2; pos.y -= scale_exp2
        if t_corner.z <= tc_max: step_mask |= 4; pos.z -= scale_exp2
        
        t_min = tc_max
        idx ^= step_mask
        
        if t_min >= t_max: break
             
        if (idx & step_mask) != 0:
            # Backtrack
            diff = 0
            if step_mask & 1: diff |= int(abs(pos.x) * 2**20) ^ int((pos.x + scale_exp2) * 2**20)
            if step_mask & 2: diff |= int(abs(pos.y) * 2**20) ^ int((pos.y + scale_exp2) * 2**20)
            if step_mask & 4: diff |= int(abs(pos.z) * 2**20) ^ int((pos.z + scale_exp2) * 2**20)
            
            scale = diff.bit_length() - 1
            scale_exp2 = 2.0 ** (scale - S_MAX)
            
            node_addr = stack_node[scale]
            t_max = stack_t_max[scale]
            
            shx = int(pos.x * 2**scale)
            shy = int(pos.y * 2**scale)
            shz = int(pos.z * 2**scale)
            pos = vec3(shx / 2**scale, shy / 2**scale, shz / 2**scale)
            idx = (shx & 1) | ((shy & 1) << 1) | ((shz & 1) << 2)

    return None
```

## Operating characteristics
*   **Time Complexity:** $O(\log N)$ for traversal depth, where $N$ is the number of voxels, but effectively $O(1)$ per pixel for sparse data as empty space is skipped [S2, unofficial].
*   **Memory Complexity:** Proportional to the number of non-empty nodes in the octree [S2, unofficial].
*   **Performance:** Can render >1 billion voxels at 20 FPS at 720p on mid-range GPUs (e.g., AMD 5700) [S4, unofficial].
*   **Strengths:** Implicit LOD, efficient empty space skipping [S2, unofficial].
*   **Limitations:** Dynamic updates can be expensive (potentially requiring full tree regeneration) [S2, unofficial]. Stack overflow if depth exceeds fixed limit (e.g., 32) [S6, unofficial].
*   **When to use:** Large sparse volumes, real-time rendering [S2, S4, unofficial].
*   **When not to use:** Highly dynamic voxel data requiring frequent full rebuilds [S2, unofficial].

## Background
Sparse Voxel Octrees were introduced by Laine and Karras (2011) as an efficient data structure for ray tracing [S4, S1, unofficial]. The method adapts the octree hierarchy to skip empty space, allowing for Level-of-Detail rendering. It has been implemented in various forms for GPU ray tracing, including in the `mxbrt/svo` renderer and `zazen` engine [S3, S4, unofficial]. The technique is often compared to Sparse Voxel DAGs, which offer further compression [S5, unofficial].
