# Animated Sparse Voxel Octrees (ASVO)

Also called: Animated Sparse Voxel Octree Renderer with X-Toon Shading, SVO renderer, XToonVolume

## Overview
ASVO is a GPU-based raycasting method for rendering animated sparse voxel octrees (SVOs) using X-Toon shading [S1, S2, unofficial]. It solves the problem of efficiently rendering voxel-based characters and models that undergo rigid transformations or skinning by animating rigid octree parts via a keyframed skeleton and placing them in a per-frame top-level bounding volume hierarchy (BVH) [S1, unofficial]. Unlike static SVO renderers, ASVO dynamically updates the spatial acceleration structure every frame to account for bone-driven deformation, allowing for real-time animation of complex voxel models [S2, unofficial].

## How it works
The method consists of an octree builder, an animation system, a traversal kernel, and a shading/draw kernel. It is implemented using OpenGL 4.5 compute shaders [S1, unofficial].

### Inputs and Outputs
**Inputs:**
*   Sparse Voxel Octree data: Inner nodes, leaf nodes (visual data), and animation bone matrices.
*   Scene data: Camera position, view/projection matrices, light position, and texture maps (diffuse, illumination, normal, specular) [S2, unofficial].
*   Animation frame index [S2, unofficial].

**Outputs:**
*   Color buffer (final rendered image) [S2, unofficial].
*   Depth buffer (for visibility culling) [S2, unofficial].

### Data Structures
The implementation uses parallel arrays to store the octree and job queue.

**Inner Nodes (`BFSInnerNode`):**
*   `mask`: Bitmask indicating which of the 8 children are occupied.
*   `childPtr`: Index offset to the first child in the inner node array.

**Leaf Nodes (`VisualData`):**
*   `boneWeights`: Array of 4 floats representing skinning weights. If `boneWeights.x > 0`, the leaf is skinned [S2, unofficial].
*   `boneIndex0-3`: Indices of the 4 bones influencing this leaf [S2, unofficial].
*   `normal`: Surface normal vector [S2, unofficial].
*   `pos`: Packed position/size data (used for screen-space checks) [S2, unofficial].
*   `tangent`, `texCoord`, `eyeVec`, `originalCenter`: Additional visual data [S2, unofficial].

**Jobs (`BFSJob`):**
*   `index`: Index of the node in the inner node array.
*   `x`, `y`, `z`: Subscript within the parent node (0-7) [S2, unofficial].

**Animation Buffer:**
*   `animation`: Array of `float4x4` matrices. Size is `m_frameCount * m_boneCount` [S2, unofficial].

### Numbered Steps

1.  **Octree Building (Pre-processing):**
    *   Build the octree from Signed Distance Fields (SDFs) or raw volumes using a Morton-sorted, bottom-up approach [S1, unofficial].
    *   Prefilter color and normal data during construction [S1, unofficial].
    *   Perform size checks on nodes [S1, unofficial].

2.  **Animation Update:**
    *   Update the current animation frame based on elapsed time [S2, unofficial].
    *   Rigid octree parts are animated by a keyframed skeleton [S1, unofficial].
    *   Construct a per-frame top-level BVH containing the animated parts [S1, unofficial].

3.  **Traversal Kernel (Job Queue Processing):**
    *   Each thread processes one job from a shared queue.
    *   **Grid Cell Calculation:** Calculate the dimensions of the voxel at the current octree level:
        $$gridCellDim = \frac{dimension}{2^{octreeLevel}}$$
        $$gridCellHalfDim = gridCellDim \times 0.5$$
        [S2, unofficial]
    *   **Skinning Application:**
        *   Compute the voxel center in world space.
        *   If the leaf node has bone weights (`node.vd.boneWeights.x > 0`), interpolate the center position using up to 4 bone transformations from the `animation` buffer based on `boneIndex0-3` and `boneWeights.x-w` [S2, unofficial].
        *   Otherwise, use the original center [S2, unofficial].
    *   **Dimension Adjustment:** Resize the voxel half-dimension to counteract stretching during skinning:
        $$gridCellHalfDim \times= \min(2.0, \text{involvedBones})$$
        [S2, unofficial]
    *   **Transformation to Clip Space:**
        *   Transform the center and dimensions into clip space by multiplying by `world`, `view`, and `projection` matrices [S2, unofficial].
        *   Compute the eye vector:
            $$eyeVec = \text{normalize}(camPos - center)$$
            [S2, unofficial]
    *   **Culling:**
        *   Perform frustum culling: The voxel is visible if its clip-space bounds are within $[-1, 1]$ [S2, unofficial].
        *   Perform back-face culling: If the octree level is greater than 8, the voxel is visible only if:
            $$\text{dot}(node.vd.normal, eyeVec) \ge -0.4$$
            [S2, unofficial]
    *   **Screen Projection and Queueing:**
        *   Project the voxel center to screen coordinates $(x, y)$ and compute depth:
            $$depth = center.z \times \text{INT\_MAX}$$
            [S2, unofficial]
        *   If the voxel has children (`d_getChildCountFromMask(node.mask) != 0`) and spans more than 1 pixel (`dimVec.x > 1.0`), add child jobs to the queue using `atomicAdd` on `sharedTravQueuePtr` [S2, unofficial].
        *   Otherwise, update the depth buffer:
            $$atomicMin(depthBuffer + index, depth)$$
            [S2, unofficial]
    *   **Visual Data Writing:**
        *   If the voxel was drawn (`w==1`) and its depth matches the updated depth buffer value, write its visual data (normal, tangent, position, texCoord, eyeVec, originalCenter) to the `voxelBuffer` at the screen index [S2, unofficial].

4.  **Draw Kernel (Shading):**
    *   For each pixel, scan a 3x3 neighborhood in the depth buffer to find the voxel with the minimum depth that covers the pixel [S2, unofficial].
    *   A voxel covers the pixel if:
        $$|vd.pos.x - 0.5 - x| \le vd.pos.z \quad \text{and} \quad |vd.pos.y - 0.5 - y| \le vd.pos.w$$
        [S2, unofficial]
    *   **Lighting:**
        *   Transform the voxel center to light space [S2, unofficial].
        *   Check shadow mapping against `shadowMap` [S2, unofficial].
        *   Compute diffuse and specular lighting using textures for diffuse, illumination, normal, and specular maps [S2, unofficial].
        *   Update the color buffer [S2, unofficial].

### Pseudocode

```python
# Traversal Kernel
def traversal_kernel(job_queue, inner_nodes, leaves, animation, world_matrix, view_matrix, projection_matrix, cam_pos, depth_buffer, voxel_buffer, shared_trav_queue_ptr):
    job = job_queue.pop()
    node = inner_nodes[job.index]
    
    # Determine octree level from job context or global state
    octree_level = get_octree_level(job)
    dimension = get_world_dimension()
    
    # Grid cell dimensions
    grid_cell_dim = dimension / (2.0 ** octree_level)
    grid_cell_half_dim = grid_cell_dim * 0.5
    
    # Get leaf visual data if this is a leaf traversal, or process children
    # Assuming job points to a node to be expanded or a leaf to be rendered
    # For simplicity, assuming we are processing a leaf node's contribution here
    # In the actual BFS, jobs point to inner nodes to expand. 
    # The logic below reflects the leaf processing described in notes.
    
    # If this job represents a leaf node (or we are processing leaf data):
    vd = leaves[job.index] # Simplified indexing for leaf
    
    # Skinning
    center = get_original_center(job)
    if vd.bone_weights[0] > 0.0:
        involved_bones = count_non_zero(vd.bone_weights)
        # Interpolate center using up to 4 bone transformations
        center = interpolate_skinning(center, vd.bone_index_0, vd.bone_index_1, vd.bone_index_2, vd.bone_index_3, vd.bone_weights, animation)
        # Counteract stretching
        grid_cell_half_dim *= min(2.0, involved_bones)
    
    # Transform to clip space
    center_world = center
    center_clip = projection_matrix * view_matrix * world_matrix * center_world
    
    # Eye vector
    eye_vec = normalize(cam_pos - center_world)
    
    # Culling
    if not is_in_frustum(center_clip):
        return
    
    if octree_level > 8:
        if dot(vd.normal, eye_vec) < -0.4:
            return
            
    # Project to screen
    x_screen, y_screen = project_to_screen(center_clip)
    depth = center_clip.z * INT_MAX
    
    # Check if leaf or has children
    child_count = get_child_count_from_mask(node.mask)
    dim_vec = get_dimension_vector(node)
    
    if child_count != 0 and dim_vec.x > 1.0:
        # Add children to queue
        for i in range(8):
            if (node.mask & (1 << i)) != 0:
                new_job = BFSJob(node.child_ptr + i, (job.x * 2) + (i & 1), (job.y * 2) + ((i & 2) >> 1), (job.z * 2) + ((i & 4) >> 2))
                atomic_add(shared_trav_queue_ptr, 1)
                job_queue[atomic_add(shared_trav_queue_ptr, -1)] = new_job # Push to queue
    else:
        # Update depth buffer
        index = get_screen_index(x_screen, y_screen)
        old_depth = atomic_min(depth_buffer + index, depth)
        
        # If we won the depth test (or it was the first write)
        if depth == depth_buffer[index]:
            # Write visual data
            voxel_buffer[index] = VisualData(vd.normal, vd.tangent, center_world, vd.tex_coord, eye_vec, vd.original_center)

# Draw Kernel
def draw_kernel(depth_buffer, voxel_buffer, shadow_map, diffuse_map, illum_map, spec_map, normal_map, color_buffer):
    x, y = get_pixel_coordinates()
    
    # Scan 3x3 neighborhood for min depth
    min_depth = INT_MAX
    best_voxel = None
    
    for dy in range(-1, 2):
        for dx in range(-1, 2):
            idx = get_screen_index(x + dx, y + dy)
            d = depth_buffer[idx]
            if d < min_depth:
                min_depth = d
                best_voxel = voxel_buffer[idx]
                
    if best_voxel is None:
        return
        
    # Check coverage
    if abs(best_voxel.pos.x - 0.5 - x) <= best_voxel.pos.z and abs(best_voxel.pos.y - 0.5 - y) <= best_voxel.pos.w:
        # Lighting
        light_space_pos = transform_to_light_space(best_voxel.original_center)
        shadow = check_shadow_mapping(light_space_pos, shadow_map)
        
        diffuse = sample_texture(diffuse_map, best_voxel.tex_coord)
        illum = sample_texture(illum_map, best_voxel.tex_coord)
        spec = sample_texture(spec_map, best_voxel.tex_coord)
        normal = sample_texture(normal_map, best_voxel.tex_coord)
        
        color = compute_diffuse_specular_lighting(normal, best_voxel.eye_vec, light_space_pos, shadow, diffuse, illum, spec)
        color_buffer[x, y] = color
```

### Parameters
*   **Graphics API:** OpenGL 4.5 compute shaders [S1, unofficial].
*   **Back-face Culling Threshold:** `dot(normal, eyeVec) >= -0.4` for levels > 8 [S2, unofficial].
*   **Skinning Stretch Compensation:** `min(2.0, involvedBones)` [S2, unofficial].

### Edge Cases and Pitfalls
*   **Divide by Zero:** In the original 2016 shader, a divide by zero error occurred when `r = 1` in the X-Toon log formula [S1, unofficial]. This must be guarded against.
*   **Light Direction:** The original shader incorrectly used the light position as a direction vector. It must be converted to a direction (light position - surface position) [S1, unofficial].
*   **Negative Dot Product:** Using `pow` on a negative `n.v` (normal dot view) caused issues. Ensure the base is non-negative or handle negative results appropriately [S1, unofficial].
*   **Unsigned Gradients:** Ensure gradients are handled as signed values if required by the shading model, as unsigned gradients caused artifacts in the original version [S1, unofficial].
*   **GL_REPEAT:** Issues with `GL_REPEAT` texture wrapping were present in the original shader and must be fixed [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** The traversal is hierarchical DDA with pixel-footprint LOD [S1, unofficial]. The complexity depends on the depth of the octree and the number of visible voxels. The use of a job queue allows for parallel processing on the GPU [S2, unofficial].
*   **Memory Complexity:** Requires storage for inner nodes, leaf nodes, animation matrices, and the BVH [S1, S2, unofficial]. The BVH is rebuilt per frame, which adds overhead but allows for efficient culling of animated parts [S1, unofficial].
*   **Performance:** The implementation includes unit tests for traversal and BVH against brute force, and a `--compare` mode that checks GPU output against the CPU renderer, ensuring correctness [S1, unofficial].
*   **Strengths:** Efficiently handles animated voxel models using skinning and hierarchical culling. The per-frame BVH allows for efficient culling of non-visible animated parts.
*   **Limitations:** The per-frame BVH construction adds overhead. The method is specific to OpenGL 4.5 compute shaders in the provided implementation [S1, unofficial].

## Background
ASVO was introduced as part of a thesis project on animated sparse voxel octrees [S2, unofficial]. The original implementation was in CUDA/C++ with an XNA/C# prototype for design [S2, unofficial]. A later rebuild by Andre Rogers added an OpenGL 4.5 compute shader implementation with X-Toon shading, fixing several shader bugs from the original 2016 version [S1, unofficial]. The method is demonstrated with scenes such as a crowd of walkers sharing limb octrees and a bonsai tree [S1, unofficial].
