# Octree Ray Marching with Brick Interpolation and Early Termination

Also called: Two-stage space-skipping volume rendering, GigaVoxels brick traversal

## Overview
This method balances GPU bottlenecks by dividing space-skipping into two stages: coarse division using bricking to address bus and texture cache bottlenecks, and fine division using octrees within bricks to address the rasterization bottleneck [S1, unofficial]. It differs from single-stage bricking (e.g., Tong et al.) by storing unmodified scalar values in brick textures and computing RGB$\alpha$ values post-interpolatively in the fragment shader, avoiding time-consuming texture regeneration when the transfer function changes [S1, unofficial]. It builds on [Sparse Voxel Octree Ray Tracing](2989-sparse-voxel-octree-ray-tracing.md) by embedding octrees within fixed-size bricks rather than a global hierarchy.

## How it works
**Inputs:**
- Volume data set (scalar voxel values).
- Transfer function (mapping scalar to RGB$\alpha$).
- Camera parameters (ray origin, direction, projection matrix).
- Brick dimensions ($b$) and overlap ($n$).
- Traversal limits (`MaxNodesToPushThisFrame`, `maxNodesPerPixelBlock`).

**Outputs:**
- Rendered image with color and opacity.

**Data Structures:**
1.  **Brick Pool:** Manages 3D textures in GPU memory. Each brick is a $b \times b \times b$ volume of scalar values.
    -   Layout: 3D texture array or 3D texture with mipmaps (if supported).
    -   Overlap: Adjacent bricks overlap by $n$ voxels in every direction to support interpolation kernels [S1, unofficial].
    -   Memory Overhead: $\approx (3 \cdot n / b) \cdot 100\%$ [S1, unofficial].
2.  **Octree Nodes:** Stored within each brick. Each node contains:
    -   Pointer to child nodes (or leaf data).
    -   Extents (min/max bounds relative to brick).
    -   Size (scalar multiplier for current node level).
3.  **Traversal State (per ray/pixel):**
    -   `rayWorldPosition`: Current position in world space.
    -   `rayBrickPosition`: Current position within the current brick.
    -   `octTreeNode`: Pointer to current octree node.
    -   `nodeSize`: Current node size in world units.
    -   `voxelHalfSize`: Half-size of a leaf voxel.
    -   `traversalCount`: Total nodes traversed.
    -   `nodeListTraversalCount`: Nodes traversed in current block.
    -   `pushedNodeCount`: Nodes pushed to usage list this frame.
    -   `curDepth`: Current octree depth.
    -   `projVoxelSize`: Projected voxel size in world coordinates.
    -   `parentVoxelSize`: Voxel size at parent level.
    -   `accumulatedOpacity`: Accumulated opacity for early termination.

**Parameters:**
-   $b$: Brick dimension in voxels. Must be $\le$ available texture memory size [S1, unofficial].
-   $n$: Overlap in voxels. $n=0$ for nearest neighbor, $n=1$ for trilinear, $n=2$ for pre-integration/gradient [S1, unofficial].
-   `MaxNodesToPushThisFrame`: Max nodes pushed to usage list per frame [S2, unofficial].
-   `maxNodesPerPixelBlock`: Threshold for `nodeListTraversalCount` reset [S2, unofficial].
-   `startPushingNodes`, `stopPushingNodes`: Range for pushing nodes to usage list [S2, unofficial].
-   `k_ChildNodeSizeScalar`: Scalar multiplier for node size on descent [S2, unofficial].

**Steps:**

1.  **Brick Loading:** Load bricks sequentially from main memory into texture memory if volume exceeds texture memory [S1, unofficial]. Bricks contain unmodified scalar values [S1, unofficial].
2.  **Ray Initialization:** For each pixel, compute ray origin and direction. Initialize `rayWorldPosition`, `accumulatedOpacity = 0.0`, `traversalCount = 0`, `nodeListTraversalCount = 0`, `pushedNodeCount = 0`.
3.  **Brick Traversal Loop:** While ray is within volume bounds:
    a.  **Interpolation Check:** Check if `projVoxelSize > 0`, `curDepth != 0`, and `interpolation factor > 0.001f`. If true, compute `prevBrickRayPos` and call `TraverseBrickInterp`; otherwise call `TraverseBrick` [S2, unofficial].
    b.  **Node Pushing:** If `nodeListTraversalCount` is within `[startPushingNodes, stopPushingNodes)` and `pushedNodeCount < MaxNodesToPushThisFrame`, increment `pushedNodeCount` and call `AddToNodeUsageList` [S2, unofficial].
    c.  **Early Termination:** If `accumulatedOpacity > 0.995` AND current step traversed a brick or constant value, terminate ray [S2, unofficial].
    d.  **Reset State:** Set `octTreeNode` to root, `extents` to `VolExtentMin/Max`, `nodeSize` to 1.0, `voxelHalfSize` to `RootVoxelHalfSize` [S2, unofficial].
    e.  **Ray Containment Test:** Compute `test1 = sign(rayWorldPosition - VolExtentMin)`, `test2 = sign(VolExtentMax - rayWorldPosition)`, `inside = dot(test1, test2)`. If `inside < 0`, ray is outside [S2, unofficial].
    f.  **Increment Counters:** `++traversalCount`, `++nodeListTraversalCount`. If `nodeListTraversalCount >= maxNodesPerPixelBlock`, reset to 0 [S2, unofficial].
    g.  **Descent:** Compute `brickOffset = rayBrickPosition * k_TreeN`, clamp to `childOffset = clamp(uvec3(brickOffset), 0u, 1u)`, update `rayBrickPosition = brickOffset - vec3(childOffset)` [S2, unofficial].
    h.  **Update Extents:** `nodeExtentMin += (vec3(childOffset) * nodeSize)`, `nodeExtentMax -= ((vec3(1.0f) - vec3(childOffset)) * nodeSize)` [S2, unofficial].
    i.  **Fetch Node:** `octTreeNode = texelFetch(OctTreeSampler, octTreeNodePtr, 0)` [S2, unofficial].
    j.  **Interpolation:** If enabled, compute interpolation factor clamped to `[0.0f, 1.0f]`. If `curDepth == 0`, disable interpolation to prevent invalid ratios when `parentVoxelSize == projVoxelSize` [S2, unofficial].
    k.  **Transfer Function:** Lookup RGB$\alpha$ from scalar value using fragment shader [S1, unofficial].
    l.  **Composite:** Update `accumulatedOpacity` and color.
    m.  **Step:** Advance ray position.

**Pseudocode:**

```python
def render_volume(volume_data, transfer_function, camera, brick_pool, octree_root):
    # Initialize brick pool and load bricks into GPU texture memory
    # Bricks are b x b x b scalar volumes with overlap n
    # Octree is embedded within each brick
    
    for pixel in pixels:
        ray_origin, ray_direction = camera.get_ray(pixel)
        accumulated_opacity = 0.0
        accumulated_color = vec3(0.0)
        ray_world_pos = ray_origin
        cur_depth = 0
        traversal_count = 0
        node_list_traversal_count = 0
        pushed_node_count = 0
        
        while ray_world_pos is within volume bounds:
            # Check interpolation conditions
            proj_voxel_size = compute_projected_voxel_size(camera, ray_world_pos)
            parent_voxel_size = compute_parent_voxel_size(cur_depth)
            interpolation_factor = compute_interpolation_factor(ray_world_pos, proj_voxel_size, parent_voxel_size)
            
            if proj_voxel_size > 0 and cur_depth != 0 and interpolation_factor > 0.001f:
                prev_brick_ray_pos = ray_world_pos
                traverse_brick_interp(ray_world_pos, prev_brick_ray_pos, octree_root, brick_pool, transfer_function, 
                                      accumulated_opacity, accumulated_color, cur_depth, proj_voxel_size, parent_voxel_size)
            else:
                traverse_brick(ray_world_pos, octree_root, brick_pool, transfer_function, 
                               accumulated_opacity, accumulated_color, cur_depth, proj_voxel_size)
            
            # Early termination
            if accumulated_opacity > 0.995 and step_traversed_brick_or_constant:
                break
            
            # Node pushing logic
            if start_pushing_nodes <= node_list_traversal_count < stop_pushing_nodes and pushed_node_count < MaxNodesToPushThisFrame:
                pushed_node_count += 1
                add_to_node_usage_list(octree_root)
            
            # Increment counters
            traversal_count += 1
            node_list_traversal_count += 1
            if node_list_traversal_count >= maxNodesPerPixelBlock:
                node_list_traversal_count = 0
            
            # Advance ray
            ray_world_pos += ray_direction * step_size
            
            # Update depth and sizes
            cur_depth = get_current_depth(ray_world_pos, octree_root)
            parent_voxel_size = compute_parent_voxel_size(cur_depth)
            proj_voxel_size = compute_projected_voxel_size(camera, ray_world_pos)

def traverse_brick(ray_pos, octree_root, brick_pool, transfer_function, acc_opacity, acc_color, depth, proj_voxel_size):
    # Reset traversal state
    oct_tree_node = octree_root
    extents_min = VolExtentMin
    extents_max = VolExtentMax
    node_size = 1.0f
    voxel_half_size = RootVoxelHalfSize
    
    # Ray containment test
    test1 = sign(ray_pos - extents_min)
    test2 = sign(extents_max - ray_pos)
    inside = dot(test1, test2)
    
    if inside < 0:
        return # Ray outside
    
    # Descent and stepping
    while oct_tree_node is not leaf:
        brick_offset = ray_pos * k_TreeN
        child_offset = clamp(uvec3(brick_offset), 0u, 1u)
        ray_brick_pos = brick_offset - vec3(child_offset)
        
        node_extent_min = extents_min + (vec3(child_offset) * node_size)
        node_extent_max = extents_max - ((vec3(1.0f) - vec3(child_offset)) * node_size)
        
        oct_tree_node = texel_fetch(OctTreeSampler, oct_tree_node_ptr, 0)
        node_size *= k_ChildNodeSizeScalar
        voxel_half_size *= k_ChildNodeSizeScalar
        
        # Update extents for next iteration
        extents_min = node_extent_min
        extents_max = node_extent_max
    
    # Fetch scalar value
    scalar_value = fetch_scalar_value(oct_tree_node, ray_pos)
    
    # Transfer function lookup
    color, opacity = transfer_function.lookup(scalar_value)
    
    # Composite
    acc_opacity += opacity * (1.0 - acc_opacity)
    acc_color += color * opacity * (1.0 - acc_opacity)

def traverse_brick_interp(ray_pos, prev_brick_ray_pos, octree_root, brick_pool, transfer_function, 
                          acc_opacity, acc_color, depth, proj_voxel_size, parent_voxel_size):
    # Similar to traverse_brick but with interpolation
    # Interpolation factor clamped to [0.0f, 1.0f]
    # If depth == 0, disable interpolation
    scalar_value = interpolate_scalar_values(prev_brick_ray_pos, ray_pos, octree_root, brick_pool)
    color, opacity = transfer_function.lookup(scalar_value)
    acc_opacity += opacity * (1.0 - acc_opacity)
    acc_color += color * opacity * (1.0 - acc_opacity)
```

**Edge Cases and Pitfalls:**
-   **Triangle Throughput Bottleneck:** Space-skipping increases triangle count. If too high, it becomes the limiting factor, overloading the rasterization bottleneck [S1, unofficial].
-   **Interpolation at Root:** Disabled when `curDepth == 0` to prevent invalid ratios when `parentVoxelSize == projVoxelSize` [S2, unofficial].
-   **Early Termination:** Only triggers if `accumulatedOpacity > 0.995` AND step traversed a brick or constant value, preventing premature cutoff [S2, unofficial].
-   **Interpolation Factor:** Clamped to `[0.0f, 1.0f]` and thresholded at `0.001f` to avoid division by zero [S2, unofficial].
-   **Brick Size:** Must be $\le$ available texture memory [S1, unofficial].
-   **Overlap:** Depends on interpolation kernel. $n=0$ for nearest neighbor, $n=1$ for trilinear, $n=2$ for pre-integration/gradient [S1, unofficial].

## Operating characteristics
-   **Time Complexity:** Depends on brick size, octree depth, and ray length. Coarse skipping via bricks reduces texture cache misses and bus traffic. Fine skipping via octrees reduces rasterization load.
-   **Memory Complexity:** Brick memory overhead $\approx (3 \cdot n / b) \cdot 100\%$ [S1, unofficial]. Octree nodes stored within bricks.
-   **Performance:** Balances bus/texture cache bottlenecks (bricks) and rasterization bottleneck (octrees) [S1, unofficial]. Early ray termination reduces fragment shader load for highly-filled datasets [S1, unofficial].
-   **Strengths:** Handles large volumes exceeding texture memory. Runtime transfer function changes without texture regeneration. Efficient space-skipping.
-   **Limitations:** Triangle throughput bottleneck if space-skipping increases triangle count too much [S1, unofficial]. Overlap increases memory usage [S1, unofficial].
-   **When to Use:** Large volume datasets, dynamic transfer functions, GPU with limited texture memory but high rasterization throughput.
-   **When Not to Use:** Small volumes fitting in texture memory without bricking. Scenes where triangle throughput is already the bottleneck.

## Background
Originated in 2006 by Danny Ruijters et al. [S1, unofficial]. The method addresses bottlenecks in GPU volume rendering by combining bricking and octree traversal. Bricking was previously used by Tong et al. [TWTT99], but required texture regeneration for transfer function changes. This method stores scalar values and uses fragment shader lookup [S1, unofficial]. Implemented in systems like GigaVoxels [S2, unofficial].
