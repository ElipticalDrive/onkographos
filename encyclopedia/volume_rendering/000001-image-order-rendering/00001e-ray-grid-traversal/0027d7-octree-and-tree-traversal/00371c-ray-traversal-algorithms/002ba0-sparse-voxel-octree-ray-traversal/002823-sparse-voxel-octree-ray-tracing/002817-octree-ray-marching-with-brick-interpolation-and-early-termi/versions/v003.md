# Octree Ray Marching with Brick Interpolation and Early Termination


## Overview
This method traverses a sparse voxel octree using fixed-size bricks to render volume data, balancing GPU bus/cache and rasterization bottlenecks. It differs from single-stage bricking by storing unmodified scalar values in brick textures and computing RGB$\alpha$ values post-interpolatively in the fragment shader, avoiding time-consuming texture regeneration when the transfer function changes [S1, unofficial]. It builds on [Sparse Voxel Octree Ray Tracing](2989-sparse-voxel-octree-ray-tracing.md) and differs from [SVO Ray Marching with Stack-Based Navigation](2454-svo-ray-marching-with-stack-based-navigation.md) by using brick interpolation and early termination thresholds.

## How it works
**Inputs:** Ray origin, ray direction, volume scalar data, octree structure, brick textures, transfer function [G].
**Outputs:** Accumulated color and opacity per pixel.
**Data Structures:**
1. **Traversal State (per ray/pixel):** `rayWorldPosition` (world space), `rayBrickPosition` (brick-local), `octTreeNode` (pointer), `nodeSize` (world units), `voxelHalfSize` (world units), `traversalCount`, `nodeListTraversalCount`, `pushedNodeCount`, `curDepth`, `projVoxelSize`, `parentVoxelSize`, `accumulatedOpacity`, `extents` (`VolExtentMin`/`VolExtentMax`) [S1, unofficial].
**Parameters:**
- `projVoxelSize`: Projected voxel size in world coordinates. Used for interpolation ratio [S1, unofficial].
- `parentVoxelSize`: Voxel size at the parent octree level. Used in interpolation denominator [S1, unofficial].
- `k_ChildNodeSizeScalar`: Scalar multiplier applied to `nodeSize` and `voxelHalfSize` on each descent step [S1, unofficial].
- `MaxNodesToPushThisFrame`: Maximum number of nodes allowed to be pushed to the usage list per frame [S1, unofficial].
- `maxNodesPerPixelBlock`: Threshold for `nodeListTraversalCount` before it resets to 0 [S1, unofficial].
- `startPushingNodes`, `stopPushingNodes`: Range boundaries for pushing nodes to the usage list [S1, unofficial].
**Steps:**
1. Reset traversal state: set `octTreeNode` to `rootOctTreeNode`, `extents` to `VolExtentMin`/`VolExtentMax`, `nodeSize` to `1.0f`, `voxelHalfSize` to `RootVoxelHalfSize` [S1, unofficial].
2. Compute ray containment test: `test1 = sign(rayWorldPosition - VolExtentMin)`, `test2 = sign(VolExtentMax - rayWorldPosition)`, `inside = dot(test1, test2)` [S1, unofficial].
3. Increment traversal counters: `++traversalCount`, `++nodeListTraversalCount`. If `nodeListTraversalCount >= maxNodesPerPixelBlock`, reset to 0 [S1, unofficial].
4. Descent: compute `brickOffset = rayBrickPosition * k_TreeN`, clamp to `childOffset = clamp(uvec3(brickOffset), 0u, 1u)`, update `rayBrickPosition = brickOffset - vec3(childOffset)` [S1, unofficial].
5. Update extents: `nodeExtentMin += (vec3(childOffset) * nodeSize)`, `nodeExtentMax -= ((vec3(1.0f) - vec3(childOffset)) * nodeSize)` [S1, unofficial].
6. Fetch next octree node: `octTreeNode = texelFetch(OctTreeSampler, octTreeNodePtr, 0)` [S1, unofficial].
7. Check interpolation condition: If `PixelSize > projVoxelSize`, `curDepth != 0`, and `interpolation factor > 0.001`, compute `prevBrickRayPos` and call `TraverseBrickInterp`; otherwise call `TraverseBrick` [S1, unofficial].
8. Node pushing: If `nodeListTraversalCount` is within `[startPushingNodes, stopPushingNodes)` and `pushedNodeCount < MaxNodesToPushThisFrame`, increment `pushedNodeCount` and call `AddToNodeUsageList` [S1, unofficial].
**Pseudocode:**
```python
def render_volume(ray_origin, ray_direction, octree_root, brick_pool, transfer_function):
    ray_world_pos = ray_origin
    accumulated_opacity = 0.0
    accumulated_color = vec3(0.0)
    cur_depth = 0
    traversal_count = 0
    node_list_traversal_count = 0
    pushed_node_count = 0
    ray_brick_pos = vec3(0.0)
    node_size = 1.0
    voxel_half_size = root_voxel_half_size
    extents_min = vol_extent_min
    extents_max = vol_extent_max
    oct_tree_node = octree_root

    while ray_world_pos is within volume bounds:
        # 1. Reset traversal state
        oct_tree_node = octree_root
        extents_min = vol_extent_min
        extents_max = vol_extent_max
        node_size = 1.0
        voxel_half_size = root_voxel_half_size

        # 2. Compute ray containment test
        test1 = sign(ray_world_pos - extents_min)
        test2 = sign(extents_max - ray_world_pos)
        inside = dot(test1, test2)
        if inside < 0:
            break

        # 3. Increment traversal counters
        traversal_count += 1
        node_list_traversal_count += 1
        if node_list_traversal_count >= max_nodes_per_pixel_block:
            node_list_traversal_count = 0

        # 4. Descent
        brick_offset = ray_brick_pos * k_tree_n
        child_offset = clamp(brick_offset, 0.0, 1.0)
        ray_brick_pos = brick_offset - child_offset

        # 5. Update extents
        node_extent_min = extents_min + (child_offset * node_size)
        node_extent_max = extents_max - ((1.0 - child_offset) * node_size)
        extents_min = node_extent_min
        extents_max = node_extent_max

        # 6. Fetch next octree node
        oct_tree_node = texel_fetch(OctTreeSampler, oct_tree_node_ptr, 0)
        node_size *= k_child_node_size_scalar
        voxel_half_size *= k_child_node_size_scalar

        # 7. Check interpolation condition
        # Compute proj_voxel_size, parent_voxel_size, interpolation_factor [G]
        if pixel_size > proj_voxel_size and cur_depth != 0 and interpolation_factor > 0.001:
            prev_brick_ray_pos = ray_world_pos
            # TraverseBrickInterp logic not given in sources [S1, unofficial]
            accumulated_opacity, accumulated_color = traverse_brick_interp(...)
        else:
            # TraverseBrick logic not given in sources [S1, unofficial]
            accumulated_opacity, accumulated_color = traverse_brick(...)

        # 8. Node pushing
        if start_pushing_nodes <= node_list_traversal_count < stop_pushing_nodes and pushed_node_count < max_nodes_to_push_this_frame:
            pushed_node_count += 1
            add_to_node_usage_list(oct_tree_node)

        # Early termination
        if accumulated_opacity > 0.995 and step_traversed_brick_or_constant:
            break

        # Advance ray
        ray_world_pos += ray_direction * step_size
        cur_depth = get_current_depth(ray_world_pos, octree_root)
```
**Edge Cases and Pitfalls:**
- **Interpolation at Root:** Disabled when `curDepth == 0` to prevent invalid ratios when `parentVoxelSize == projVoxelSize` [S1, unofficial].
- **Early Termination:** Only triggers if `accumulatedOpacity > 0.995` AND the current step actually traversed a brick or constant value, preventing premature cutoff during initialization or empty space [S1, unofficial].
- **Interpolation Factor:** Clamped to `[0.0f, 1.0f]` and thresholded at `0.001f` to avoid division by zero or negligible interpolation steps [S1, unofficial].

## Subtopics

### [Two-staged Space-Skipping with Bricking and Octrees](5210-two-staged-space-skipping-with-bricking-and-octrees.md)
A strategy to balance load on GPU bottlenecks by dividing space-skipping into two stages: coarse division using bricking to address bus and texture cache bottlenecks, and fine division using octrees within bricks to address the rasterization bottleneck.

### [Stackless GPU Raycasting with Octree Traversal](5222-stackless-gpu-raycasting-with-octree-traversal.md)
A raycasting algorithm that computes the volume rendering integral by enumerating non-empty bricks in front-to-back order, adapting sampling density to brick resolution, and stopping when accumulated opacity exceeds a threshold. It uses the octree with neighbor structure to accelerate traversal without a stack.

## Background
Originated in 2006 by Danny Ruijters et al. [S1, unofficial]. The method addresses bottlenecks in GPU volume rendering by combining bricking and octree traversal [S1, unofficial]. This method stores scalar values and uses fragment shader lookup [S1, unofficial]. Implemented in systems like GigaVoxels [S1, unofficial].
