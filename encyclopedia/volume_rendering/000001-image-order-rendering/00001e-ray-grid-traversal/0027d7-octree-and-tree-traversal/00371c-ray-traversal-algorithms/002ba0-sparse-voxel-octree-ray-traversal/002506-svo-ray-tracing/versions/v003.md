# SVO Ray Tracing
Also called: SVO Walk (Traversal)

## Overview
SVO Ray Tracing is a depth-first ray traversal algorithm for Sparse Voxel Octrees (SVO) that visits nodes in a specific order relative to the eye position [S1, unofficial]. It differs from pure SVO traversal by explicitly managing a stack to control visitation order based on eye position, and from BVH-based approaches by operating directly on the octree structure without an intermediate bounding volume hierarchy [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A Sparse Voxel Octree (SVO) structure, a camera (origin, rotation, field of view), and a render target (width, height).
*   **Output:** A rendered image.

**Data Structures:**
The implementation uses a specific buffer layout for GPU execution [S1, unofficial]:
1.  **Uniform Buffer (`RaytracerShaderUniforms`):**
    *   `camera_rotation`: `[[f32; 4]; 4]` (4x4 matrix).
    *   `camera_origin`: `[f32; 4]`.
    *   `width`: `u32`.
    *   `height`: `u32`.
    *   `aspect_ratio`: `f32`.
    *   `fov`: `f32` (stored as $\tan(\text{fov}_{rad}/2)$).
    *   `bvh_root`: `u32` (index of the root node).
2.  **SVO Buffer:** Stores the SVO node pool.
3.  **BVH Node Buffer:** Stores internal nodes.
4.  **BVH Leaf Buffer:** Stores leaf nodes.

**Node Layout:**
*   **BVHNode:**
    *   `center`: `[f32; 4]` (x, y, z, w).
    *   `radius`: `f32`.
    *   `left_child`: `u32`.
    *   `right_child`: `u32`.
    *   *Note:* Child indices are stored with the most significant bit set (`| 0x80000000`) to distinguish them from leaf indices [S1, unofficial].
*   **BVHLeaf:**
    *   `model_address`: `u32`.
    *   `inv_model`: `[f32; 4]` (inverse transformation matrix).

**Algorithm Steps:**
1.  **Initialization:** Create a uniform buffer, SVO buffer, BVH node buffer, and BVH leaf buffer with maximum sizes (e.g., 16384 leaves, 32767 nodes) [S1, unofficial]. Bind these to a render pipeline with a quad vertex shader and raytrace fragment shader [S1, unofficial].
2.  **Scene Construction:**
    *   Load voxel grid data (e.g., from CSV) [S1, unofficial].
    *   Convert the voxel grid to an SVO [S1, unofficial].
    *   For each object, compute its position, scale, and rotation.
    *   Encode the position into a Morton code [S1, unofficial].
    *   Create a `BVHLeaf` for each object containing its model address and inverse transformation matrix [S1, unofficial].
    *   Sort leaves by Morton code [S1, unofficial].
3.  **BVH Construction (from Leaves):**
    *   Initialize an empty node at index 0 (`empty_node_idx`) [S1, unofficial].
    *   Process sorted leaves in pairs:
        *   For each pair (or single remaining leaf), compute the bounding sphere center and radius [S1, unofficial].
        *   Create a `BVHNode` with the computed center, radius, and child indices.
        *   Set `left_child` and `right_child` indices to the leaf indices (ORed with `0x80000000`) or recursively built node indices [S1, unofficial].
        *   Push the new node index to a queue [S1, unofficial].
    *   While the queue has more than one node:
        *   Pop two nodes from the front (`left_child`, `right_child`) [S1, unofficial].
        *   Compute the bounding sphere for the two children [S1, unofficial].
        *   Create a new parent `BVHNode` with the combined center, radius, and child indices [S1, unofficial].
        *   Push the parent index to the queue [S1, unofficial].
    *   The last node in the queue is the root [S1, unofficial].
4.  **Rendering Loop:**
    *   Update the uniform buffer with camera parameters (rotation, origin, width, height, aspect ratio, fov, bvh_root) [S1, unofficial].
    *   Begin a render pass with a clear color (e.g., white) [S1, unofficial].
    *   Set the pipeline and bind group [S1, unofficial].
    *   Draw a quad (4 vertices) to trigger the raytrace fragment shader [S1, unofficial].

**Pseudocode:**
```python
# BVH Construction Logic
def build_bvh(leaves):
    # leaves is a list of (morton_code, leaf_data, transform, scale) sorted by morton_code
    node_queue = []
    nodes = []
    empty_node_idx = 0
    
    # Initialize empty node
    nodes.append(BVHNode(center=[0,0,0,0], radius=0.0, left_child=0, right_child=0))
    
    # Process leaves in pairs
    i = 0
    while i < len(leaves):
        leaf1 = leaves[i]
        center1, radius1 = compute_bounding_sphere(leaf1.transform)
        
        if i + 1 < len(leaves):
            leaf2 = leaves[i+1]
            center2, radius2 = compute_bounding_sphere(leaf2.transform)
            combined_center, combined_radius = compute_bounding_sphere([center1, center2])
            
            # Create leaf nodes for the pair
            leaf_idx1 = len(nodes) # Assuming leaves are stored in nodes or separate buffer
            leaf_idx2 = len(nodes) + 1
            
            # Create internal node
            node_idx = len(nodes)
            nodes.append(BVHNode(
                center=combined_center,
                radius=combined_radius,
                left_child=leaf_idx1 | 0x80000000,
                right_child=leaf_idx2 | 0x80000000
            ))
            node_queue.append(node_idx)
            i += 2
        else:
            # Single leaf at the end
            node_idx = len(nodes)
            nodes.append(BVHNode(
                center=center1,
                radius=radius1,
                left_child=leaf_idx1 | 0x80000000,
                right_child=empty_node_idx
            ))
            node_queue.append(node_idx)
            i += 1
            
    # Build internal nodes from queue
    while len(node_queue) > 1:
        left_idx = node_queue.pop(0)
        right_idx = node_queue.pop(0)
        
        left_node = nodes[left_idx]
        right_node = nodes[right_idx]
        
        combined_center, combined_radius = compute_bounding_sphere([left_node.center, right_node.center])
        
        parent_idx = len(nodes)
        nodes.append(BVHNode(
            center=combined_center,
            radius=combined_radius,
            left_child=left_idx,
            right_child=right_idx
        ))
        node_queue.append(parent_idx)
        
    return nodes[0] # Root node
```

## Subtopics

### [SVO Walk (Traversal)](5188-svo-walk-traversal.md)
SVO Walk is a depth-first ray traversal algorithm for Sparse Voxel Octrees (SVO) that visits nodes in a specific order relative to the eye position, invoking a callback for each visited node. It differs from pure SVO traversal by explicitly managing a stack to control visitation order based on eye position, and from BVH-based approaches by operating directly on the octree structure without an intermediate bounding volume hierarchy.
