# SVO Walk (Traversal)

## Overview
SVO Walk is a depth-first traversal algorithm for Sparse Voxel Octrees (SVO) that visits nodes in an order determined by the eye position, invoking a callback for each visited node [S1, unofficial]. It differs from pure SVO traversal by explicitly managing a stack to control visitation order based on eye position, and from BVH-based approaches by operating directly on the octree structure without an intermediate bounding volume hierarchy [S1, unofficial].

## How it works
**Inputs:** SVO root node, eye position, and a callback function `on_node` [S1, unofficial].
**Outputs:** Execution of `on_node` for each visited node in traversal order [S1, unofficial].

**Data Structures:**
*   **Stack:** Stores tuples `(node_ref, stem, depth)` [S1, unofficial].
    *   `node_ref`: Pointer or index to the current octree node [S1, unofficial].
    *   `stem`: A 3D integer vector representing the node's origin coordinates at the current depth [S1, unofficial].
    *   `depth`: The current octree depth level (integer) [S1, unofficial].

**Formulas:**
*   **Offset:** The physical size of a voxel at a given depth [S1, unofficial].
    $$ \text{offset} = 2^{-\text{depth}} $$
    Implemented via bit manipulation for efficiency [S1, unofficial]:
    ```python
    exp = 126 - depth
    f = exp << 23
    offset = struct.unpack('f', struct.pack('I', f))[0]  # bit-cast to float [G]
    ```
*   **Voxel Position:** The world-space position of the voxel corner [S1, unofficial].
    $$ \text{voxel} = \text{stem} \times \text{offset} $$
*   **Child Origin:** For a child at index $i$ (0-7) in the octree [S1, unofficial]:
    $$ \text{new\_origin} = \text{stem} + \text{index\_offset}(i, \text{offset}) $$

**Algorithm Steps:**
1.  Initialize the stack with `(ROOT_NODE, (0,0,0), 0)` [S1, unofficial].
2.  While the stack is not empty:
    a.  Pop `(node_ref, stem, depth)` from the stack [S1, unofficial].
    b.  Retrieve the node from `node_ref` [S1, unofficial].
    c.  Calculate `offset` using the bit-manipulation method above [S1, unofficial].
    d.  Calculate `voxel = stem * offset` [S1, unofficial].
    e.  Call `on_node(is_leaf, data, voxel)` [S1, unofficial].
    f.  If `on_node` returns `true` AND the node is not a leaf:
        i.  Calculate the sorting order of the 8 children based on the eye position and `stem` [S1, unofficial].
        ii. For each child in the sorted order:
            1.  Determine the child's index $i$.
            2.  Calculate `new_origin = stem + index_offset(i, offset)` [S1, unofficial].
            3.  Push `(child_ref, new_origin, depth + 1)` to the stack [S1, unofficial].

**Pseudocode:**
```python
import struct
import math

def svo_walk(root_node, eye_position, on_node):
    stack = [(root_node, (0, 0, 0), 0)]
    while stack:
        node_ref, stem, depth = stack.pop()
        # offset = 2^(-depth) via bit manipulation [S1, unofficial]
        exp = 126 - depth
        f = exp << 23
        offset = struct.unpack('f', struct.pack('I', f))[0]  # bit-cast to float [G]
        
        # voxel = stem.extend(offset) [S1, unofficial]
        voxel = (stem[0] * offset, stem[1] * offset, stem[2] * offset)
        
        is_leaf = node_ref.is_leaf()
        data = node_ref.data
        if on_node(is_leaf, data, voxel):
            if not is_leaf:
                children = node_ref.children
                # Sort children indices 0-7 based on distance to eye_position [S1, unofficial]
                def child_origin(i):
                    return (stem[0] + ((i & 1) * offset),
                            stem[1] + (((i >> 1) & 1) * offset),
                            stem[2] + (((i >> 2) & 1) * offset))
                sorted_children = sorted(range(8), key=lambda i: math.dist(eye_position, child_origin(i)))
                for i in sorted_children:
                    new_origin = child_origin(i)
                    stack.append((children[i], new_origin, depth + 1))
```

**Fast Walk Variant:**
*   Uses a fixed-size stack array of 256 elements [S1, unofficial].
*   Uses raw pointers for node access to minimize overhead [S1, unofficial].
*   Calculates voxel using `offset * 1.73` (approx $\sqrt{3}$) in some implementations, though the standard formula is $2^{-\text{depth}}$ [S1, unofficial].

**Edge Cases:**
*   **Stack Overflow:** The fixed-size stack (256 elements) may overflow in deep or complex scenes [S1, unofficial].
*   **Precision:** The bit-manipulation method for offset calculation is efficient but limited to specific depth ranges where $126 - \text{depth}$ yields a valid IEEE 754 exponent [S1, unofficial].

## Subtopics

### [SVO Walk (Traversal) — fast_walk](5217-svo-walk-traversal-fast-walk.md)
A hybrid variant combining BVH coarse culling with SVO fine-grained evaluation. It reduces visited nodes compared to pure SVO traversal and maintains SVO memory efficiency at the leaves compared to pure BVH traversal.

### SVO Walk (Traversal) — ComputeGlobalState
Iterates through all nodes using a PreOrderTraversal to compute global active states [S2]. If a node's local state is INACTIVE, it sets `activeGlobal` to FALSE and marks `inactiveAncestors` as TRUE; otherwise it inherits `inactiveAncestors` from the parent [S2]. If the node is globally active, it increments the `numActiveGlobal` counter [S2].

## Operating characteristics
*   **Time Complexity:** Proportional to the number of visited nodes [S1, unofficial].
*   **Memory Complexity:** $O(D)$ for the stack, where $D$ is the maximum depth of the tree [S1, unofficial]. The fixed-size stack variant uses constant memory (256 elements) [S1, unofficial].
