# Sparse Voxel Octree Ray Traversal (State Machine)
Also called: Fixed-Point SVO Traversal, SVO Raycasting

## Overview
A deterministic software ray traversal algorithm for Sparse Voxel Octrees (SVO) implemented as a finite state machine using fixed-point arithmetic, originally designed to emulate an FPGA hardware raycaster [S1, unofficial]. It differs from recursive or stack-based traversals by using explicit goto-based control flow and a circular buffer stack to manage backtracking, ensuring predictable execution paths suitable for hardware synthesis or deterministic software rendering [S1, unofficial].

## How it works
**Inputs:** Ray origin $r.o$, ray direction $r.d$, SVO data structure (compact nodes), traversal parameters [S1, unofficial].
**Outputs:** Hit point, depth, or traversal status [G].

**Data Structures:**
*   **CNode (Compact Node):** 32-bit packed structure.
    *   Bits 0-7: `valid_mask` (8 bits, child validity) [S1, unofficial].
    *   Bits 8-15: `leaf_mask` (8 bits, child leaf status) [S1, unofficial].
    *   Bits 16-30: `child_ptr` (15 bits, offset to children) [S1, unofficial].
    *   Bit 31: `far_ptr` flag (1 bit, indicates if children are at a far address) [S1, unofficial].
*   **OctreeCursor:** Contains pointer to `CNode` data, current `CNode* node`, current address `adr`, current `level`, and a `Cache` pointer [S1, unofficial].
*   **StackItem:**
    *   `cur`: OctreeCursor [S1, unofficial].
    *   `tx0, ty0, tz0, tx1, ty1, tz1`: Fixed-point intersection times (tnum) [S1, unofficial].
    *   `idx`: Current child index being processed [S1, unofficial].
*   **Stack:** Circular buffer of `StackItem` with `top` index, `length`, and size `ss`. Push wraps `top` modulo `ss` and increments `length` (capped at `ss`) [S1, unofficial]. Pop decrements `top` (wrapping if negative) and decrements `length` [S1, unofficial].

**Parameters:**
*   `terminLevel`: Maximum depth before forcing leaf termination. Default: 10 [S1, unofficial].
*   `tnum_scale`: Fixed-point scaling factor. Value: 65536 ($2^{16}$) [S1, unofficial].
*   `tnum_max`, `tnum_min`: Bounds for fixed-point clipping. Clamping offset: 1000 [S1, unofficial].

**Algorithm Steps:**

1.  **Ray Direction Normalization:**
    *   If any component of $r.d$ is zero, add 0.001 to that component to prevent division by zero [S1, unofficial].
    *   If any component of $r.d$ is negative, flip the ray origin component ($r.o.x \leftarrow -r.o.x$) and negate the direction component ($r.d.x \leftarrow -r.d.x$). Record these flips in `dir_mask` (bit 4 for X, bit 2 for Y, bit 1 for Z) [S1, unofficial].

2.  **Initial Bounding Box Intersection:**
    *   Compute intersection times with the unit cube $[-1, 1]^3$:
        $$tx0 = \frac{-1 - r.o.x}{r.d.x}, \quad tx1 = \frac{1 - r.o.x}{r.d.x}$$
        $$ty0 = \frac{-1 - r.o.y}{r.d.y}, \quad ty1 = \frac{1 - r.o.y}{r.d.y}$$
        $$tz0 = \frac{-1 - r.o.z}{r.d.z}, \quad tz1 = \frac{1 - r.o.z}{r.d.z}$$
    *   Calculate entry and exit times:
        $$t_{enter} = \max(tx0, \max(ty0, tz0))$$
        $$t_{exit} = \min(tx1, \min(ty1, tz1))$$
    *   If $t_{enter} \ge t_{exit}$, the ray misses the bounding box; terminate [S1, unofficial].

3.  **Fixed-Point Conversion:**
    *   Scale times by `tnum_scale`: $tnum = t \times 65536$ [S1, unofficial].
    *   Clip values to $[tnum\_min + 1000, tnum\_max - 1000]$ to prevent overflow [S1, unofficial].

4.  **State Machine Loop:**
    The traversal uses goto-based control flow [S1, unofficial].

    *   **Initialization:** Initialize `cur` to root. `level = 0` [S1, unofficial].
    *   **Compute Midpoints:** $txm = (tx0+tx1)/2$, $tym = (ty0+ty1)/2$, $tzm = (tz0+tz1)/2$ [S1, unofficial].
    *   **Set Entry Time:** Set $t_{enter} = \max(tx0, \max(ty0, tz0))$ [S1, unofficial].
    *   **Select Initial Child Index:** $idx = (txm < t_{enter}) \ll 2 \mid (tym < t_{enter}) \ll 1 \mid (tzm < t_{enter})$ [S1, unofficial].
    *   **Compute Child Bounds:** $tx0_{child} = (idx \& 4) ? txm : tx0$, $tx1_{child} = (idx \& 4) ? tx1 : txm$ (similarly for Y and Z) [S1, unofficial].
    *   **Calculate Child Exit Time:** $t_{exit\_child} = \min(tx1_{child}, \min(ty1_{child}, tz1_{child}))$ [S1, unofficial].
    *   **Flip Index for Direction:** $idx_{flip} = idx \oplus dir\_mask$ [S1, unofficial].
    *   **Check Exit:** If $t_{exit\_child} \le t_{start}$ (current traversal start time), skip this node. Jump to next index [S1, unofficial].
    *   **Check Leaf/Termination:** If `cur.childIsFilled(idx_flip)` OR `level == terminLevel`: mark as leaf hit and finish [S1, unofficial].
    *   **Check Validity:** If `cur.childIsValid(idx_flip)`: push current state (`cur`, bounds, `idx`) to Stack [S1, unofficial]. Update `cur` to child: `cur = cur.getChild(idx_flip)` [S1, unofficial]. Update bounds to child bounds. Increment `level`. Continue traversal [S1, unofficial].
    *   **Handle Node Exit/Backtrack:** If exiting node and `level==0`, finish. If stack is empty, restart traversal from $t_{exit\_child}$. Otherwise, pop stack, decrement `level`, and continue traversal [S1, unofficial].

**Pseudocode:**

```python
def traverse_svo_state_machine(ray_origin, ray_direction, root_node, node_data, cache, termin_level=10, tnum_scale=65536):
    # 1. Handle Ray Direction
    dir_mask = 0
    r_o = list(ray_origin) # [x, y, z]
    r_d = list(ray_direction)
    for i in range(3):
        if r_d[i] == 0:
            r_d[i] = 0.001
        if r_d[i] < 0:
            r_o[i] = -r_o[i]
            r_d[i] = -r_d[i]
            if i == 0: dir_mask |= 4
            elif i == 1: dir_mask |= 2
            elif i == 2: dir_mask |= 1

    # 2. Initial Bounding Box Intersection
    tx0 = (-1.0 - r_o[0]) / r_d[0]
    tx1 = (1.0 - r_o[0]) / r_d[0]
    ty0 = (-1.0 - r_o[1]) / r_d[1]
    ty1 = (1.0 - r_o[1]) / r_d[1]
    tz0 = (-1.0 - r_o[2]) / r_d[2]
    tz1 = (1.0 - r_o[2]) / r_d[2]

    t_enter = max(tx0, max(ty0, tz0))
    t_exit = min(tx1, min(ty1, tz1))
    if t_enter >= t_exit:
        return None # Miss

    # 3. Fixed-Point Conversion
    # tnum_max and tnum_min are standard 32-bit signed integer bounds [G]
    tnum_max = 2**31 - 1
    tnum_min = -2**31
    def to_tnum(t):
        val = int(t * tnum_scale)
        return max(tnum_min + 1000, min(tnum_max - 1000, val))

    tx0, tx1 = to_tnum(tx0), to_tnum(tx1)
    ty0, ty1 = to_tnum(ty0), to_tnum(ty1)
    tz0, tz1 = to_tnum(tz0), to_tnum(tz1)

    # Data Structures
    class StackItem:
        def __init__(self, cur, tx0, ty0, tz0, tx1, ty1, tz1, idx):
            self.cur = cur
            self.tx0, self.ty0, self.tz0 = tx0, ty0, tz0
            self.tx1, self.ty1, self.tz1 = tx1, ty1, tz1
            self.idx = idx

    stack_store = [None] * 256 # ss
    stack_top = 0
    stack_len = 0

    def push_stack(item):
        nonlocal stack_top, stack_len
        stack_store[stack_top] = item
        stack_top = (stack_top + 1) % len(stack_store)
        if stack_len < len(stack_store):
            stack_len += 1

    def pop_stack():
        nonlocal stack_top, stack_len
        if stack_len == 0:
            return None
        stack_len -= 1
        stack_top = (stack_top - 1) % len(stack_store)
        if stack_top < 0:
            stack_top += len(stack_store)
        return stack_store[stack_top]

    class OctreeCursor:
        def __init__(self, data, node, adr, level, cache):
            self.data = data
            self.node = node
            self.adr = adr
            self.level = level
            self.cache = cache

        def childIsFilled(self, idx):
            return (self.node.leaf_mask >> idx) & 1

        def childIsValid(self, idx):
            return (self.node.valid_mask >> idx) & 1

        def getChild(self, child_idx):
            valid_count = 0
            for i in range(child_idx):
                if (self.node.valid_mask >> i) & 1:
                    valid_count += 1
            child_ptr = self.node.child_ptr & ~(1 << 15)
            if self.node.child_ptr & (1 << 15):
                far_adr = self.adr + child_ptr
                child_node = self.data[far_adr]
            else:
                child_node = self.data[self.adr + child_ptr]
            return OctreeCursor(self.data, child_node, self.adr + child_ptr, self.level + 1, self.cache)

    # Initialize
    cur = OctreeCursor(node_data, root_node, 0, 0, cache)
    level = 0
    t_start = 0
    idx = 0

    while True:
        # Compute midpoints & entry time
        txm = (tx0 + tx1) // 2
        tym = (ty0 + ty1) // 2
        tzm = (tz0 + tz1) // 2
        t_enter_curr = max(tx0, max(ty0, tz0))

        # Select initial child index on first node
        if level == 0 and idx == 0:
            idx = ((txm < t_enter_curr) << 2) | ((tym < t_enter_curr) << 1) | (tzm < t_enter_curr)

        while idx < 8:
            # Compute child bounds
            c_tx0 = txm if (idx & 4) else tx0
            c_tx1 = tx1 if (idx & 4) else txm
            c_ty0 = tym if (idx & 2) else ty0
            c_ty1 = ty1 if (idx & 2) else tym
            c_tz0 = tzm if (idx & 1) else tz0
            c_tz1 = tz1 if (idx & 1) else tzm

            t_exit_child = min(c_tx1, min(c_ty1, c_tz1))
            idx_flip = idx ^ dir_mask

            # Check Exit
            if t_exit_child <= t_start:
                idx += 1
                continue

            # Check Leaf/Termination
            if cur.childIsFilled(idx_flip) or level == termin_level:
                return {"hit": True, "depth": t_exit_child, "node": cur.node}

            # Check Validity
            if cur.childIsValid(idx_flip):
                push_stack(StackItem(cur, tx0, ty0, tz0, tx1, ty1, tz1, idx))
                cur = cur.getChild(idx_flip)
                tx0, ty0, tz0 = c_tx0, c_ty0, c_tz0
                tx1, ty1, tz1 = c_tx1, c_ty1, c_tz1
                level += 1
                idx = 0
                break # Restart loop for new node
            else:
                idx += 1

        # Handle Node Exit/Backtrack
        if level == 0:
            return None # Finish

        if stack_len == 0:
            # Restart from t_exit_child
            t_start = t_exit_child
            cur = OctreeCursor(node_data, root_node, 0, 0, cache)
            level = 0
            tx0, tx1 = to_tnum((-1.0 - r_o[0]) / r_d[0]), to_tnum((1.0 - r_o[0]) / r_d[0])
            ty0, ty1 = to_tnum((-1.0 - r_o[1]) / r_d[1]), to_tnum((1.0 - r_o[1]) / r_d[1])
            tz0, tz1 = to_tnum((-1.0 - r_o[2]) / r_d[2]), to_tnum((1.0 - r_o[2]) / r_d[2])
            idx = 0
            continue

        popped = pop_stack()
        cur = popped.cur
        tx0, ty0, tz0 = popped.tx0, popped.ty0, popped.tz0
        tx1, ty1, tz1 = popped.tx1, popped.ty1, popped.tz1
        idx = popped.idx + 1
        level -= 1
```

## Operating characteristics
*   **Time Complexity:** Proportional to the number of nodes visited. The state machine overhead is minimal, making it efficient for hardware implementation.
*   **Memory Complexity:** Uses a fixed-size circular buffer stack. Memory usage is $O(S)$ where $S$ is the stack size, independent of tree depth.
*   **Strengths:** Deterministic execution, low memory footprint, suitable for FPGA and embedded systems. Fixed-point arithmetic avoids floating-point unit dependencies.
*   **Limitations:** Fixed-point precision limits accuracy for very deep trees or large scenes. Requires careful handling of edge cases (zero direction, overflow).
*   **When to use:** Real-time rendering on constrained hardware, FPGA-based ray tracing, or when deterministic software behavior is required.
*   **When not to use:** High-precision offline rendering where floating-point accuracy is critical, or scenes with extremely deep octrees exceeding stack limits.

## Background
The method originates from the `svo-workbench` project by skyfex, which implements a software ray tracer for Sparse Voxel Octrees [S1, unofficial]. It was specifically designed to model a Verilog-based hardware raycaster, allowing the same traversal logic to be used in both software and FPGA implementations [S1, unofficial]. The project demonstrates caching strategies and rendering into a shared framebuffer [S1, unofficial].
