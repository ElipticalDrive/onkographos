# Robust Iso-surface Rendering via Bisection and Newton Refinement

Also called: Isosurface Raycasting with Binary Search, Similarity Map Rendering, bisection trace with Newton refinement, isoray rendering pipeline

## Overview
This method renders volumetric similarity maps by tracing rays to find the first intersection with an isosurface defined by class similarity values, followed by Phong shading [S1]. It distinguishes itself from standard voxel stepping by employing a rigorous bisection search for intersection detection, optionally refined by Newton's method to achieve sub-pixel accuracy [S1][S2, unofficial]. Unlike [Volumetric Isosurface Rendering with Intersection Refinement](958-volumetric-isosurface-rendering-with-intersection-refinement.md) which may use linear interpolation, this approach guarantees robustness through interval arithmetic or Lipschitz-based inclusion functions [S2, unofficial].

## How it works
**Inputs:**
*   Scalar field function $f(\mathbf{p})$ returning value and optionally gradient.
*   Camera parameters: origin $\mathbf{o}$, direction $\mathbf{d}$, field of view, projection type.
*   Iso-value threshold $\tau$ for the specific class $C$.
*   Bounding box bounds $(\mathbf{lo}, \mathbf{hi})$.
*   Parameters: `newton_iter` (default 3), `margin` (default 0.01), `lipschitz` (constant or 'auto').

**Outputs:**
*   Color buffer with forward-composited surface colors.
*   Depth buffer.
*   Hit masks and surface normals.

**Data Structures:**
*   `TraceResult`: Contains `position` (N, 3), `normal` (N, 3), `t` (N,), `hit` (N, bool).
*   `AffineForm` (for inclusion functions): `x0` (N,), `xi` (N, K), `delta` (N,). Used for robust interval evaluation.
*   `GradientInclusion`: Wraps $f$ and a Lipschitz constant $L$.

**Steps:**

1.  **Camera Setup:** Compute ray origins and directions for each pixel. For perspective projection, use FOV; for parallel, use extent [S2, unofficial].
2.  **Bounding Box Intersection:** Compute ray-AABB intersection to get $t_{min}$ and $t_{max}$. The AABB is expanded by a margin:
    $$ \text{margin} = (\mathbf{hi} - \mathbf{lo}) \times 0.01 $$
    $$ \mathbf{aabb\_lo} = \mathbf{lo} - \text{margin} $$
    $$ \mathbf{aabb\_hi} = \mathbf{hi} + \text{margin} $$
    [S2, unofficial]
3.  **Lipschitz Estimation (if `lipschitz='auto'`):** Estimate $L$ by sampling $N$ points in the bounds, computing gradient norms, and taking the maximum multiplied by a safety factor (default 1.5) [S2, unofficial].
    $$ L = \max_{i} \|\nabla f(\mathbf{p}_i)\| \times 1.5 $$
    [S2, unofficial]
4.  **Coarse Traversal:** Step along the ray from $t_{min}$ until $f(\mathbf{p}(t)) \ge \tau$. If the ray exits the volume without crossing, mark as miss [S1].
5.  **Bisection Search:** Perform binary search within the interval $[t_{start}, t_{end}]$ where the sign change (or threshold crossing) was detected.
    $$ t_{mid} = \frac{t_{start} + t_{end}}{2} $$
    Evaluate $f(\mathbf{p}(t_{mid}))$. If $f \ge \tau$, set $t_{end} = t_{mid}$; else $t_{start} = t_{mid}$. Repeat until interval width is below a convergence threshold [S1].
6.  **Newton Refinement (Optional):** Apply Newton's method to refine $t$ for sub-pixel accuracy.
    $$ t_{new} = t_{old} - \frac{f(\mathbf{p}(t_{old})) - \tau}{\nabla f(\mathbf{p}(t_{old})) \cdot \mathbf{d}} $$
    Repeat for `newton_iter` iterations [S1][S2, unofficial].
7.  **Normal Computation:** Compute surface normal $\mathbf{n}$ at the hit position $\mathbf{p}_{hit}$.
    *   If $f$ provides analytic gradient: $\mathbf{n} = \nabla f(\mathbf{p}_{hit})$.
    *   Else, use centered finite differences with step $h=10^{-5}$:
        $$ \mathbf{n} = \frac{1}{2h} \begin{bmatrix} f(\mathbf{p}+h\mathbf{x}) - f(\mathbf{p}-h\mathbf{x}) \\ f(\mathbf{p}+h\mathbf{y}) - f(\mathbf{p}-h\mathbf{y}) \\ f(\mathbf{p}+h\mathbf{z}) - f(\mathbf{p}-h\mathbf{z}) \end{bmatrix} $$
        Normalize $\mathbf{n}$, clamping norm to $\ge 10^{-12}$ to prevent division by zero [S2, unofficial].
8.  **Shading:** Compute color using Phong model with ambient, diffuse, and specular components. Cast shadow ray to light source [S1].
9.  **Compositing:** Blend surface color onto output buffer using forward compositing. Continue raycasting until early ray termination threshold is reached [S1].

def newton_refine(f, origins, directions, t, tau, iterations):
    """Refine intersection parameter t using Newton's method."""
    for _ in range(iterations):
        positions = origins + t[:, None, None] * directions
        vals, grads = f(positions)
        
        # Reshape for batch dot product
        # grad is (N, 3), direction is (N, 3)
        # d_val_dt = grad . d
        d_val_dt = np.sum(grads * directions, axis=1)
        
        # Avoid division by zero
        d_val_dt = np.maximum(np.abs(d_val_dt), 1e-12) * np.sign(d_val_dt)
        
        t = t - (vals - tau) / d_val_dt
    return t

def estimate_lipschitz(f, bounds, n_samples=10000, safety=1.5):
    lo, hi = bounds
    rng = np.random.default_rng()
    pts = rng.uniform(lo, hi, (n_samples, 3))
    vals, grads = f(pts)
    
    if grads is not None:
        grad_norms = np.linalg.norm(grads, axis=1)
    else:
        # Fallback to finite differences if no analytic gradient
        h = 1e-5
        offsets = np.array([[h,0,0],[-h,0,0],[0,h,0],[0,-h,0],[0,0,h],[0,0,-h]])
        all_pts = (pts[None,:,:] + offsets[:,None,:]).reshape(6*n_samples, 3)
        all_vals, _ = f(all_pts)
        v = all_vals.reshape(6, n_samples)
        gx = (v[0] - v[1]) / (2*h)
        gy = (v[2] - v[3]) / (2*h)
        gz = (v[4] - v[5]) / (2*h)
        grad_norms = np.sqrt(gx**2 + gy**2 + gz**2)
        
    return float(np.max(grad_norms) * safety)

## Subtopics

### [Newton Refinement](1346-newton-refinement.md)
An optional post-processing step applied after the bisection phase to achieve sub-pixel hit-point accuracy by iteratively correcting the position using directional derivatives.

## Operating characteristics
*   **Time Complexity:** Bisection is $O(\log(1/\epsilon))$ per ray for precision $\epsilon$. Newton refinement adds $O(k)$ where $k$ is the number of iterations. Lipschitz estimation is $O(N)$ where $N$ is sample count.
*   **Memory Complexity:** $O(N)$ for storing ray data and results. Affine arithmetic variants may require $O(K)$ per point for noise symbols.
*   **Performance:** Post-processing (bilateral solver) takes ~0.4s for $256^3$ and ~5.3s for $512^3$ on Intel i7-8700K [S1]. Rendering speed depends on ray count and refinement steps.
*   **Strengths:** Robust intersection detection; sub-pixel accuracy; handles complex implicit surfaces well.
*   **Limitations:** Requires differentiable or gradient-accessible functions for Newton refinement; Lipschitz estimation can be costly if done per-frame.
*   **When to use:** High-quality offline rendering or interactive annotation where precision is critical [S1].

## Background
Originating from work on segmentation-based transfer function design, this method leverages self-supervised vision transformers to generate similarity maps, which are then rendered using robust isosurface raycasting [S1]. The implementation details, including the bisection and Newton refinement pipeline, are documented in the `iso-surface-rendering` repository [S2, unofficial].
