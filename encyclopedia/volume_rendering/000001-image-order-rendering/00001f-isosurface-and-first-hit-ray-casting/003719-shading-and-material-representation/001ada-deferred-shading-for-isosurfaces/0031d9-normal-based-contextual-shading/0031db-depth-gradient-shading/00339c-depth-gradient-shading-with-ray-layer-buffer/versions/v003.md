# Depth-Gradient Shading with Ray-Layer Buffer
Also called: Gradient estimation with ray-layer buffer

## Overview
A technique to estimate surface gradients for shading by analyzing depth coherency in a ray-layer buffer, solving the problem of noisy shading in regions with low volume gradient magnitudes [S1]. It differs from its parent, [Depth-Gradient Shading](6618-depth-gradient-shading.md), by operating on the discrete layers of a multi-layer ray-casting buffer rather than a continuous z-buffer, allowing it to distinguish between different material surfaces encoded in the same pixel column [S1].

## How it works
**Inputs and Outputs:**
- Input: Ray-layer buffer containing depth values and material IDs for each layer; volume gradient field; pixel spacing in world space [S1].
- Output: Blended gradient vector per pixel per layer [S1].

**Data Structures:**
The ray-layer buffer is a 3D texture or array where each entry corresponds to a pixel $(x, y)$ and a layer index $l$ [S1]. Each entry stores:
- `depth`: The depth value of the surface intersection for this layer [S1].
- `materialID`: The identifier of the material at this intersection [S1].

**Steps:**
1. For the current layer $l$ being ray-casted at pixel $(x, y)$, retrieve the entry from the ray-layer buffer [S1].
2. Retrieve the entries from the four immediate neighboring pixels $(x-1, y)$, $(x+1, y)$, $(x, y-1)$, and $(x, y+1)$ for the same layer $l$ [S1].
3. For each neighbor $i \in \{1, 2, 3, 4\}$, calculate the absolute depth difference: $\Delta d_i = |d_{curr} - d_{ni}|$ [S1].
4. Select the neighbor $k$ with the minimal absolute depth difference: $\Delta d_k = \min(\Delta d_1, \Delta d_2, \Delta d_3, \Delta d_4)$ [S1]. The source assumes that depth values produced by the same surface have strong coherency, and that entries are encoded with material ID, so differences between different material IDs are typically large [S1].
5. Calculate the surface gradient magnitude approximation using the selected depth difference and `pixelSpacing` ($p$): $g_{surf} = \frac{\Delta d_k}{p}$ [S1].
6. Retrieve the volume gradient magnitude $g_{vol}$ for the current voxel/sample [G].
7. Calculate the blend factor: $blend = \min(1, \frac{g_{vol}}{threshold})$ [S1].
8. Compute the final blended gradient: $gradient = blend \cdot volumeGradient + (1 - blend) \cdot surfaceGradient$ [S1]. The source uses the term "gradient" for both vectors and magnitudes in the formula, and the blend factor explicitly uses `gradientMagnitude` [S1].

**Formulas:**
- Depth difference: $\Delta d_i = |d_{curr} - d_{ni}|$
- Surface gradient magnitude: $g_{surf} = \frac{\Delta d_k}{p}$
- Blend factor: $blend = \min(1, \frac{g_{vol}}{threshold})$
- Final gradient: $gradient = blend \cdot volumeGradient + (1 - blend) \cdot surfaceGradient$ [S1]

**Parameters:**
- `pixelSpacing`: Distance between neighboring pixels in world space [S1].
- `threshold`: Threshold for blending [S1].

**Edge Cases and Pitfalls:**
- Empty pixels: Ray segments labeled with `mtIdEmpty` are skipped during ray-layer buffer generation, so empty entries should not exist for valid layers [S1].
- Boundary/Isolated surfaces: The method assumes that "an entry in the ray-layer buffer has at least one direct neighbor that is produced by the same surface" [S1]. At sharp boundaries or isolated surfaces, this coherency assumption may fail, leading to inaccurate gradient estimation [S1].

**Pseudocode:**
```python
def depth_gradient_shading(ray_layer_buffer, volume_gradient_field, pixel_spacing, threshold):
    # ray_layer_buffer: 3D array [width, height, layers] storing depth and materialID
    # volume_gradient_field: 3D array [width, height, layers] storing gradient vectors
    for layer in range(num_layers):
        for x in range(width):
            for y in range(height):
                # 1. Retrieve current entry
                curr_entry = ray_layer_buffer[x, y, layer]
                d_curr = curr_entry.depth
                
                # 2. Retrieve neighbors for the same layer
                neighbor_entries = [
                    ray_layer_buffer[x-1, y, layer],
                    ray_layer_buffer[x+1, y, layer],
                    ray_layer_buffer[x, y-1, layer],
                    ray_layer_buffer[x, y+1, layer]
                ]
                
                # 3. Calculate absolute depth differences
                depth_diffs = [abs(d_curr - n.depth) for n in neighbor_entries]
                
                # 4. Select neighbor with minimal absolute depth difference
                min_diff = min(depth_diffs)
                
                # 5. Calculate surface gradient magnitude
                g_surf = min_diff / pixel_spacing
                
                # 6. Retrieve volume gradient magnitude
                g_vol = abs(volume_gradient_field[x, y, layer].magnitude)
                
                # 7. Calculate blend factor
                blend = min(1.0, g_vol / threshold)
                
                # 8. Compute final blended gradient
                vol_grad = volume_gradient_field[x, y, layer]
                final_gradient = blend * vol_grad + (1.0 - blend) * g_surf
                
                yield final_gradient
```

## Subtopics

### [Deferred Shading with Approximate Normals](11342-deferred-shading-with-approximate-normals.md)
Calculates view-dependent lighting in layered volume rendering by storing a single representative normal vector per ray segment and performing shading in a deferred step before compositing, rather than multiplying shading coefficients with fragment color before warping. It solves the problem of noisy shading in regions with low volume gradient magnitudes by using a weighted accumulation strategy that prioritizes samples with high visual impact. It differs from this method by explicitly storing and shading with normal vectors derived from volume gradients rather than depth gradients, allowing for more accurate specular highlights and surface perception.

## Operating characteristics
- **Time Complexity:** Constant time per pixel per layer, as it involves a fixed number of texture lookups and arithmetic operations [G].
- **Memory Complexity:** Requires storage of the ray-layer buffer (depth and material ID per layer per pixel) [G].
- **Strengths:** Reduces noise in shading for regions with low volume gradient magnitudes, such as mask surfaces cutting through volume regions [S1].
- **Limitations:** Relies on the assumption of depth coherency among neighbors [S1].
- **When to use:** When shading noisy regions due to low volume gradients, particularly for mask surfaces in multi-layer volume rendering [S1].
- **When not to use:** When high-fidelity surface normals are required and volume gradients are unreliable, or when the depth coherency assumption is violated [G].

## Background
Originated in the context of multi-layer volume ray casting on GPU, specifically to address shading artifacts in regions where volume gradients are weak [S1]. The method was implemented using OpenGL 2.1 and GLSL on an Nvidia Quadro FX 5600 [S1].
