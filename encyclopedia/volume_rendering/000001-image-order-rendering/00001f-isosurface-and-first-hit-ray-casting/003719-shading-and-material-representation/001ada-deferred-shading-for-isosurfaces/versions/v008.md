# Deferred Shading for Isosurfaces

Also called: Curvature Estimation, Deferred Shading with Differential Properties, Differential Surface Properties Computation, Gradient and Hessian Estimation, Image-Space Shading

## Overview
Deferred Shading for Isosurfaces is a multi-pass image-space technique that computes surface properties (position, gradient, Hessian, curvature) in separate rendering passes and uses them in a final shading pass [S1]. It solves the problem of high-quality isosurface visualization by decoupling shading from volume sampling, calculating lighting only for visible pixels using pre-computed differential property images [S1]. It distinguishes itself from direct volume rendering by applying shading only after the opaque volume is determined, and from immediate shading methods by storing full surface attributes (gradient, Hessian, curvature) in intermediate floating-point buffers rather than computing them on-the-fly during a single ray-march [S1].

## How it works
The method operates on the intersection point $\mathbf{p}$ found by the parent method [G]. It extends the parent's principles by computing first-order (gradient) and second-order (Hessian) differential properties in image space to derive surface normals and principal curvatures for isosurfaces [S1].

### Inputs and Outputs
*   **Input:** Scalar volume data $f(\mathbf{x})$, typically stored in a 3D texture [S1].
*   **Output:** Final shaded image [S1].
*   **Intermediate Buffers:**
    *   Position image ($\mathbf{pos}$): 3D coordinates of the isosurface intersection [S1].
    *   Gradient image ($\mathbf{g}$): RGB floating-point image storing $\nabla f$ [S1].
    *   Hessian image ($\mathbf{H}$): Stored in two RGB floating-point images, storing the six unique components of $\nabla^2 f$ [S1].
    *   Curvature images: Two floating-point targets storing principal curvatures $\kappa_1, \kappa_2$ and directions $\mathbf{e}_1, \mathbf{e}_2$ [S1].

### Data Structures and Layout
1.  **Gradient ($\mathbf{g}$):** Stored in a single RGB floating-point image. Each pixel $(u,v)$ contains $(\frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}, \frac{\partial f}{\partial z})$ evaluated at the hit point [S1].
2.  **Hessian ($\mathbf{H}$):** Due to symmetry ($H_{ij} = H_{ji}$), only six unique components are calculated. These are stored in two RGB floating-point images [S1].
3.  **Curvature:** Magnitudes and directions are rendered to two floating-point targets [S1].

### Numbered Steps

1.  **Pass 1: Ray-Casting (Position)**
    *   **Input:** Volume texture [S1].
    *   **Output:** Position image ($\mathbf{pos}$) [S1].
    *   **Action:** Perform ray-casting to find the isosurface intersection $\mathbf{p}$ for each pixel. Store $\mathbf{p}$ in the position buffer [S1].

2.  **Pass 2: Gradient Computation**
    *   **Input:** Position image ($\mathbf{pos}$), Volume texture [S1].
    *   **Output:** Gradient image ($\mathbf{g}$) [S1].
    *   **Action:** Compute the gradient $\mathbf{g} = \nabla f$ in three rendering passes (one per component). In each pass, evaluate a tri-cubic B-spline convolution sum to compute one first-order partial derivative. This requires eight texture fetches from the 3D volume texture and three fetches from 1D filter weight textures [S1].
    *   **Formula:** $\mathbf{n} = \frac{\mathbf{g}}{|\mathbf{g}|}$ (used for normal in shading) [S1].

3.  **Pass 3: Hessian Computation**
    *   **Input:** Position image ($\mathbf{pos}$), Volume texture [S1].
    *   **Output:** Hessian image ($\mathbf{H}$) [S1].
    *   **Action:** Compute the Hessian $\mathbf{H} = \nabla \mathbf{g}$ in six rendering passes (one per unique second partial derivative). Each pass uses either eleven or fourteen texture fetches [S1].

4.  **Pass 4: Curvature Computation**
    *   **Input:** Gradient image ($\mathbf{g}$), Hessian image ($\mathbf{H}$) [S1].
    *   **Output:** Principal curvatures $\kappa_1, \kappa_2$ and directions $\mathbf{e}_1, \mathbf{e}_2$ [S1].
    *   **Action:** Compute principal curvature magnitudes and directions in a single rendering pass using the gradient and Hessian images [S1].
    *   **Formula:** The shape operator $\mathbf{S}$ is defined as the tangent space projection of the normalized Hessian:
        $$ \mathbf{S} = \mathbf{P}^T \frac{\mathbf{H}}{|\mathbf{g}|} \mathbf{P}, \quad \mathbf{P} = \mathbf{I} - \frac{\mathbf{g}\mathbf{g}^T}{|\mathbf{g}|^2} $$
        The principal curvatures $\kappa_{1,2}$ are the eigenvalues of $\mathbf{S}$, computed as:
        $$ \kappa_{1,2} = \frac{1}{2} \left( \text{trace}(\mathbf{A}) \pm \sqrt{\text{trace}(\mathbf{A})^2 - 4 \det(\mathbf{A})} \right) $$
        where $\mathbf{A}$ is the $2 \times 2$ matrix representation of $\mathbf{S}$ in the tangent basis [S1].
        The principal directions $\mathbf{e}_i$ are computed as:
        $$ \mathbf{e}_i = \kappa_i \mathbf{u} + (\kappa_i + a_{22} - a_{11}) \mathbf{v} $$
        where $\mathbf{u}, \mathbf{v}$ are basis vectors of the tangent plane and $a_{11}, a_{22}$ are elements of $\mathbf{A}$ [S1].

5.  **Pass 5: Shading**
    *   **Input:** Position ($\mathbf{pos}$), Gradient ($\mathbf{g}$), Curvatures ($\kappa_{1,2}, \mathbf{e}_{1,2}$) [S1].
    *   **Output:** Final Image [S1].
    *   **Action:** Render the shaded isosurface using the property images. Apply shading models such as Blinn-Phong or tone shading using the normal vector derived from $\mathbf{g}$ [S1]. Apply curvature-based effects (color mapping, flow advection, NPR) [S1].

### Pseudocode

```python
import math
import numpy as np

def pass1_ray_casting(volume_texture, width, height):
    # Intersection points are found by the parent ray-casting method [G].
    pos_buffer = np.zeros((height, width, 3), dtype=np.float32)
    for v in range(height):
        for u in range(width):
            # hit_point = parent_ray_cast(u, v, volume_texture)
            pos_buffer[v, u] = [0.0, 0.0, 0.0]
    return pos_buffer

def pass2_gradient(pos_buffer, volume_texture, width, height):
    grad_buffer = np.zeros((height, width, 3), dtype=np.float32)
    for axis in range(3):
        for v in range(height):
            for u in range(width):
                p = pos_buffer[v, u]
                # Evaluate tri-cubic B-spline convolution sum for one partial derivative
                # Requires 8 texture fetches from 3D volume and 3 from 1D filter weights [S1]
                grad_buffer[v, u, axis] = 0.0 # tricubic_convolution_gradient(p, volume_texture, axis)
    return grad_buffer

def pass3_hessian(pos_buffer, volume_texture, width, height):
    hess1 = np.zeros((height, width, 3), dtype=np.float32)
    hess2 = np.zeros((height, width, 3), dtype=np.float32)
    axes1 = [0, 0, 0, 1, 1, 2]
    axes2 = [0, 1, 2, 1, 2, 2]
    for i in range(6):
        for v in range(height):
            for u in range(width):
                p = pos_buffer[v, u]
                # Evaluate second partial derivative
                # Requires 11 or 14 texture fetches per pass [S1]
                val = 0.0 # tricubic_convolution_hessian(p, volume_texture, axes1[i], axes2[i])
                if i < 3:
                    hess1[v, u, i] = val
                else:
                    hess2[v, u, i - 3] = val
    return hess1, hess2

def pass4_curvature(grad_buffer, hess1, hess2, width, height):
    kappa1_buffer = np.zeros((height, width), dtype=np.float32)
    kappa2_buffer = np.zeros((height, width), dtype=np.float32)
    e1_buffer = np.zeros((height, width, 3), dtype=np.float32)
    e2_buffer = np.zeros((height, width, 3), dtype=np.float32)
    
    for v in range(height):
        for u in range(width):
            g = grad_buffer[v, u]
            g_norm = np.linalg.norm(g)
            if g_norm < 1e-6:
                kappa1_buffer[v, u] = 0.0
                kappa2_buffer[v, u] = 0.0
                continue
                
            H = np.zeros((3, 3))
            H[0, 0] = hess1[v, u, 0]; H[0, 1] = hess1[v, u, 1]; H[0, 2] = hess1[v, u, 2]
            H[1, 0] = hess1[v, u, 1]; H[1, 1] = hess2[v, u, 0]; H[1, 2] = hess2[v, u, 1]
            H[2, 0] = hess1[v, u, 2]; H[2, 1] = hess2[v, u, 1]; H[2, 2] = hess2[v, u, 2]
            
            P = np.eye(3) - np.outer(g, g) / (g_norm ** 2)
            S = P.T @ (H / g_norm) @ P
            
            u_vec, v_vec = compute_tangent_basis(g)
            A = np.array([
                [u_vec @ S @ u_vec, u_vec @ S @ v_vec],
                [v_vec @ S @ u_vec, v_vec @ S @ v_vec]
            ])
            
            tr = np.trace(A)
            det = np.linalg.det(A)
            disc = tr ** 2 - 4 * det
            if disc < 0:
                disc = 0.0
            sqrt_disc = math.sqrt(disc)
            
            k1 = 0.5 * (tr + sqrt_disc)
            k2 = 0.5 * (tr - sqrt_disc)
            
            kappa1_buffer[v, u] = k1
            kappa2_buffer[v, u] = k2
            
            a11 = A[0, 0]
            a22 = A[1, 1]
            
            e1 = k1 * u_vec + (k1 + a22 - a11) * v_vec
            e2 = k2 * u_vec + (k2 + a22 - a11) * v_vec
            
            e1_buffer[v, u] = e1 / np.linalg.norm(e1)
            e2_buffer[v, u] = e2 / np.linalg.norm(e2)
            
    return kappa1_buffer, kappa2_buffer, e1_buffer, e2_buffer

def pass5_shading(pos_buffer, grad_buffer, kappa1_buffer, kappa2_buffer, e1_buffer, e2_buffer, width, height):
    final_image = np.zeros((height, width, 3), dtype=np.float32)
    for v in range(height):
        for u in range(width):
            p = pos_buffer[v, u]
            if np.all(p == 0.0):
                final_image[v, u] = [0.0, 0.0, 0.0]
                continue
                
            g = grad_buffer[v, u]
            n = g / np.linalg.norm(g)
            
            # Lighting model evaluation [G]
            L = np.array([0.0, 0.0, 1.0])
            V = np.array([0.0, 0.0, -1.0])
            H_vec = L + V
            H_norm = np.linalg.norm(H_vec)
            if H_norm > 0:
                H_vec /= H_norm
                
            diffuse = max(0.0, np.dot(n, L))
            specular = max(0.0, np.dot(n, H_vec)) ** 20.0
            
            color = np.array([0.2, 0.2, 0.2]) + diffuse * np.array([0.8, 0.8, 0.8]) + specular * np.array([0.8, 0.8, 0.8])
            
            k1 = kappa1_buffer[v, u]
            k2 = kappa2_buffer[v, u]
            # Curvature color mapping via lookup texture [S1]
            curvature_color = np.array([0.0, 0.0, 0.0])
            
            final_image[v, u] = color + curvature_color
    return final_image

def compute_tangent_basis(g):
    if abs(g[0]) > abs(g[1]):
        v_vec = np.array([-g[1], g[0], 0.0])
    else:
        v_vec = np.array([0.0, -g[2], g[1]])
    v_vec = v_vec / np.linalg.norm(v_vec)
    u_vec = np.cross(g, v_vec)
    u_vec = u_vec / np.linalg.norm(u_vec)
    return u_vec, v_vec
```

### Parameters and Typical Values
*   **Filter:** Tri-cubic B-spline convolution [S1].
*   **Texture Fetches:** 8 volume + 3 weight for gradient; 11 or 14 for Hessian [S1].
*   **Floating Point Precision:** Used for intermediate buffers (gradient, Hessian, curvature) [S1].

### Edge Cases and Pitfalls
*   **Flow Advection Seams:** Advecting flow along curvature directions may produce visible seams because the orientation of curvature direction vectors is not uniquely defined [S1].
*   **Zero Gradient:** If $|\mathbf{g}| \approx 0$, the normal and shape operator are undefined. Guard against division by zero [G].
*   **Negative Discriminant:** In curvature calculation, if $\text{trace}(\mathbf{A})^2 - 4 \det(\mathbf{A}) < 0$, the eigenvalues are complex. Clamp to 0 or handle as flat surface [G].

## Subtopics

### [Surface shading for thresholded volumes](1159-surface-shading-for-thresholded-volumes.md)
Surface shading for thresholded volumes is a post-processing technique that applies illumination models to isosurfaces extracted from scalar volume data by thresholding. It solves the problem of visualizing the 3D shape and orientation of opaque boundaries within a volume without the computational cost of full ray-marching integration. It distinguishes itself from direct volume rendering by applying shading only after the opaque volume is determined.

### [Normal-based Contextual Shading](6617-normal-based-contextual-shading.md)
Normal-based Contextual Shading is an object-space shading technique applied after finding closest intersection points to achieve better results than image-space depth-gradient shading. It solves the problem of inaccurate normal estimation by fitting a linear or biquadratic function to the set of points that belong to the same iso-surface. It differs from its parent, Deferred Shading for Isosurfaces, by operating directly on the discrete intersection points rather than computing gradients in volume space.

## Operating characteristics
*   **Time Complexity:** Image-space complexity, independent of grid size [S1]. Total passes: 1 (Ray-Cast) + 3 (Gradient) + 6 (Hessian) + 1 (Curvature) + 1 (Shading) = 12 passes [S1].
*   **Memory Complexity:** Requires multiple floating-point images (Position, Gradient, Hessian x2, Curvature x2) [S1].
*   **Performance:** On a NVIDIA GeForce 6800, each property calculation pass renders a single screen-aligned quad [S1].
*   **Strengths:** High-quality differential properties (curvature) computed accurately via tri-cubic filtering; decoupled shading allows for complex effects (flow advection, NPR) [S1].
*   **Limitations:** High number of rendering passes; seams in flow advection due to non-unique curvature direction orientation [S1].
*   **When to use:** When high-fidelity curvature-based shading and visualization of isosurface geometry is required, and performance allows for multiple passes [G].
*   **When not to use:** When real-time performance with limited GPU memory is critical, or when simple normal-based shading suffices [G].

## Background
The method was introduced in "Real-Time Ray-Casting and Advanced Shading of Discrete Isosurfaces" [S1]. It builds on the principles of deferred shading and differential geometry applied to volume data [S1]. The technique exploits GPU capabilities for image-space processing to compute complex surface properties efficiently [G].
