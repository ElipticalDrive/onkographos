# Shaded Surface Display (SSD)

Also called: SS-VRT, Surface Shaded Display (SSD)

## Overview
Shaded Surface Display (SSD) is a surface rendering technique that creates a 3D visual illustration of CT volumetric data from any desired perspective, providing a sensation of three-dimensionality superior to other volume rendering techniques [S2]. It differs from direct volume rendering by discarding internal data and rendering only the surface, relying on gray-scale shading rather than color assignment based on tissue classification [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** 3D CT volume $V$ where each voxel $v \in V$ has a Hounsfield Unit (HU) value. Parameters: `min_hu`, `max_hu` (Hounsfield range), observer position $O$, light position $L$, viewport dimensions, field of view.
*   **Output:** 2D image $I$ with gray-scale surface shading.

**Data Structures:**
*   **Voxel Grid:** 3D array of float values representing Hounsfield Units [S2].
*   **Binary Mask:** Implicit or explicit representation of voxels satisfying $\text{min\_hu} \le V(x,y,z) \le \text{max\_hu}$ [S1].
*   **Surface Representation:** Set of boundary voxels or mesh vertices where the mask transitions between included and excluded tissue types [S2].

**Steps:**
1.  **Segmentation:** Select voxels to be included in the surface rendering based on a selected range of Hounsfield values [S1]. The volume is segmented into tissue types (e.g., parenchyma, bone, airways, vessels) by analyzing combinations of Hounsfield ranges [S2].
2.  **Surface Extraction:** Calculate the location of surfaces separating the segmented tissue types [S2]. Discard all non-surface data, resulting in a hollow dataset [S1].
3.  **Normal Calculation:** Compute surface normals at the extracted boundary points using the gradient of the Hounsfield values [G].
4.  **Ray Tracing & Shading:** Calculate a perspective visualization based on a selectable observer position and light source positioning using ray-tracing techniques [S2]. Apply gray-scale shading derived by calculations to simulate a 'virtual spotlight' [S1]. The opacity is set to high for the selected surface, with low opacity only at steep gradients to create a hard, transparent boundary representation [S3, unofficial].
5.  **Composite:** Assign pixel colors based on the computed shading intensity and background.

**Formulas:**
*   **Thresholding:** $M(x,y,z) = \begin{cases} 1 & \text{if } \text{min\_hu} \le V(x,y,z) \le \text{max\_hu} \\ 0 & \text{otherwise} \end{cases}$
*   **Normal Estimation:** $\mathbf{n} = \frac{\nabla V}{\|\nabla V\|}$, where $\nabla V$ is the central difference gradient of the volume at the surface point [G].
*   **Shading Intensity:** $I = \max(0, \mathbf{n} \cdot \mathbf{l}) \times \text{base\_intensity}$, simulating a virtual spotlight at $L$ [S1].

**Parameters:**
*   **Hounsfield Range:** A selected range of Hounsfield values used to determine which voxels are included in the surface rendering [S2]. Typical ranges depend on anatomy: bone (~+400 to +3000 HU), soft tissue (~+20 to +100 HU), air (< -900 HU) [G].

**Pitfalls:**
*   **Hollow Dataset:** Internal features are discarded, requiring subsequent editing or volume rendering with cut planes if internal context is needed [S1].
*   **Stair-Step Artifact:** Discontinuities in the scanner dataset due to nonvolumetric data acquisition can cause stair-step artifacts [S2]. This artifact is not frequently encountered with Multi-Detector CT (MDCT) [S2].
*   **Occlusion:** Structures behind adjacent surfaces are hidden unless the region of interest is progressively trimmed or excluded/included interactively [S2].

**Pseudocode:**
```python
import math

def dot(a, b):
    return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]

def normalize(v):
    length = math.sqrt(v[0]**2 + v[1]**2 + v[2]**2)
    if length == 0: return (0.0, 0.0, 0.0)
    return (v[0]/length, v[1]/length, v[2]/length)

def clamp(val, min_val, max_val):
    return max(min_val, min(val, max_val))

def shaded_surface_display(ct_volume, min_hu, max_hu, observer_pos, light_pos, image_width, image_height, fov_deg, max_steps):
    """
    ct_volume: 3D list/array of Hounsfield values
    min_hu, max_hu: float, Hounsfield range threshold
    observer_pos: 3-tuple (x, y, z)
    light_pos: 3-tuple (x, y, z)
    image_width, image_height: int
    fov_deg: float, field of view in degrees
    max_steps: int, maximum ray march steps
    Returns: 2D list of float intensities
    """
    vol_shape = (len(ct_volume), len(ct_volume[0]), len(ct_volume[0][0]))
    image = [[0.0] * image_width for _ in range(image_height)]
    aspect = image_width / image_height
    focal_length = 1.0 / math.tan(math.radians(fov_deg / 2.0))
    step_size = 0.5
    
    for y in range(image_height):
        for x in range(image_width):
            u = (2.0 * (x + 0.5) / image_width - 1.0) * aspect
            v = (1.0 - 2.0 * (y + 0.5) / image_height)
            ray_dir = normalize((u / focal_length, v / focal_length, 1.0))
            
            t = 0.0
            hit = False
            while t < 100.0 and not hit:
                pos = (observer_pos[0] + t * ray_dir[0],
                       observer_pos[1] + t * ray_dir[1],
                       observer_pos[2] + t * ray_dir[2])
                
                ix, iy, iz = int(pos[0]), int(pos[1]), int(pos[2])
                if 0 <= ix < vol_shape[0] and 0 <= iy < vol_shape[1] and 0 <= iz < vol_shape[2]:
                    val = ct_volume[ix][iy][iz]
                    if min_hu <= val <= max_hu:
                        # Compute normal via central differences
                        nx = ct_volume[clamp(ix+1, 0, vol_shape[0]-1)][iy][iz] - ct_volume[clamp(ix-1, 0, vol_shape[0]-1)][iy][iz]
                        ny = ct_volume[ix][clamp(iy+1, 0, vol_shape[1]-1)][iz] - ct_volume[ix][clamp(iy-1, 0, vol_shape[1]-1)][iz]
                        nz = ct_volume[ix][iy][clamp(iz+1, 0, vol_shape[2]-1)] - ct_volume[ix][iy][clamp(iz-1, 0, vol_shape[2]-1)]
                        normal = normalize((nx, ny, nz))
                        
                        # Gray-scale shading (virtual spotlight)
                        light_dir = normalize((light_pos[0] - pos[0], light_pos[1] - pos[1], light_pos[2] - pos[2]))
                        intensity = max(0.0, dot(normal, light_dir))
                        image[y][x] = intensity
                        hit = True
                t += step_size
    return image
```

## Operating characteristics
*   **Time Complexity:** Processor intensive due to the complexity of surface extraction and ray-tracing calculations [S2].
*   **Memory Complexity:** Requires storage for the volume data and the extracted surface representation [G].
*   **Strengths:** Provides superior 3D sensation; excellent for visualizing fine details of specific density structures (e.g., bone fractures, ducts) [S2]. Allows real-time user manipulation of view perspective and virtual light sources [S2].
*   **Limitations:** Prone to stair-step artifacts from nonvolumetric acquisition (though less common with MDCT) [S2]; cannot see through opaque surfaces without interactive trimming/exclusion [S2]; does not allow color assignment based on tissue classification to differentiate adjacent structures [S1].
*   **When to Use:** Studying fine anatomical details like articular bone surfaces, virtual endoscopy, and assessing structures with specific density ranges (e.g., biliary tree with contrast) [S2].
*   **When Not to Use:** When transparent visualization of internal structures is required without surface occlusion, or when color differentiation of adjacent structures is necessary [S1].

## Background
Shaded Surface Display Volume Rendering (SS-VRT) was developed as a technique to create 3D visual illustrations of CT volumetric data for display from any desired perspective [S2]. It became commonplace as processing power increased, allowing for real-time user manipulation [S2]. The technique's principle diagnostic utility lies in its ability to represent structures of a specific density with great detail [S2]. It is particularly useful for analyzing hypodense structures like the bile tree and pancreatic duct, especially during contrast agent administration phases [S2]. It is widely used for studying osseous structures, evaluating pelvic fractures, and performing virtual endoscopy [S1][S2].
