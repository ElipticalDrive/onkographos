# Gaussian Grounded Inter-Reflection

Also called: Inter-reflection Computation

## Overview
Gaussian Grounded Inter-Reflection models indirect illumination in reflective scenes by separating direct light $L_{\text{dir}}$ and indirect light $L_{\text{ind}}$ [S1, unofficial][S2]. It approximates visibility $V$ via ray tracing on an extracted mesh or SDF-based ray marching to determine occlusion, allowing the indirect component to account for light bouncing off other surfaces [S1, unofficial][S2]. It differs from standard Phong or simple environment map shading by explicitly computing self-occlusion and secondary bounces using either mesh-based ray tracing [S1, unofficial] or SDF-based ray marching [S2]. It builds on [Surface shading for thresholded volumes](1159-surface-shading-for-thresholded-volumes.md) and contrasts with [Shading for Isosurfaces (Single-Pass Multi-Stage)](2094-shading-for-isosurfaces-single-pass-multi-stage.md), [Fast Shaded Isosurfaces](2105-fast-shaded-isosurfaces.md), [Volume Raycasting with Surface Extraction and Phong Shading](3662-volume-raycasting-with-surface-extraction-and-phong-shading.md), [Interval Shading](6414-interval-shading.md), [IsosurfaceClassifier Lighting Model](6676-isosurfaceclassifier-lighting-model.md), and [Boundary Shader](14912-boundary-shader.md) by grounding visibility checks in either explicit mesh BVH traversal or differentiable SDF sampling rather than baked lighting or single-pass approximations.

## How it works
**Inputs:**
*   Surface normal $N$ at the shading point [S1, unofficial][S2].
*   View direction $\omega_o$ (denoted as $w_i$ in [S2] notation) [S1, unofficial][S2].
*   Incoming light direction $\omega_i$ for direct light calculation [S1, unofficial].
*   Material properties including specular reflectance $f_s$ [S1, unofficial].
*   Geometry representation: either a periodically extracted triangular mesh with BVH [S1, unofficial] or a differentiable SDF field [S2].
*   For [S1, unofficial]: view-dependent spherical harmonic coefficients for indirect color $l_{\text{ind}}$ and per-Gaussian alpha values $\alpha_i$ [S1, unofficial].
*   For [S2]: light source position and incoming radiance [S2].

**Outputs:**
*   Modified specular radiance $L'_s(\omega_o)$ including inter-reflection effects [S1, unofficial].

**Data Structures:**
*   **Mesh (S1):** Triangular mesh extracted via Truncated Signed Distance Function (TSDF) fusion, stored with a Bounding Volume Hierarchy (BVH) for acceleration [S1, unofficial].
*   **Gaussian Attributes (S1):** Each Gaussian primitive stores view-dependent color coefficients modeled by spherical harmonics and an alpha value $\alpha_i$ [S1, unofficial].
*   **SDF Field (S2):** A differentiable SDF representation of the scene geometry [S2].

**Steps:**

1.  **Calculate Reflected Direction:**
    Compute the reflection vector $R$ (or $w_r$) based on the surface normal $N$ and the view direction.
    $$ R = 2(\omega_o \cdot N)N - \omega_o $$
    [S1, unofficial] uses $\omega_o$ as the incident direction in this formula. [S2] uses $w_r = 2(n \cdot w_i)n - w_i$ (the source text contains a typo "2 × n − wi", but the context implies the standard reflection formula) [S2].

2.  **Determine Visibility ($V$):**
    Check if the reflected ray is occluded by the scene geometry.
    *   **Method A (Mesh-based, [S1, unofficial]):** Perform ray tracing against the extracted mesh using the BVH. If the ray hits the mesh, $V=1$ (visible); otherwise, $V=0$ (occluded) [S1, unofficial].
    *   **Method B (SDF-based, [S2]):** Identify a secondary intersection point $x'$ by ray marching in direction $w_r$. Check occlusion of $x'$ from the light source by uniformly sampling 20 points along the path between the light source and $x'$. If any sampled point has a negative SDF value, the light is considered occluded ($V=0$); otherwise, $V=1$ [S2].

3.  **Compute Indirect Lighting ($L_{\text{ind}}$):**
    *   **Method A (Gaussian Grounded, [S1, unofficial]):** Evaluate the view-dependent color $l_{\text{ind}}$ (modeled by spherical harmonics) in the reflected direction $R$ at the Gaussian level. Aggregate the indirect lighting map via alpha blending across $N$ Gaussians:
        $$ l_{\text{ind}} = \sum_{i=1}^N l_{\text{ind}}^{(i)} \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j) $$
        [S1, unofficial]
    *   **Method B (SDF/Ray Marching, [S2]):** If $x'$ is unobstructed, compute the outgoing radiance at $x'$ using the light source's incoming radiance. Combine this with a blending coefficient (conditioned on roughness) to represent indirect illumination [S2].

4.  **Combine Direct and Indirect Light:**
    Calculate the final specular term $L'_s(\omega_o)$ by weighting the direct and indirect components with visibility $V$:
    $$ L'_s(\omega_o) \approx \left( \int_{\Omega} f_s(\omega_i, \omega_o) (\omega_i \cdot \mathbf{N}) d\omega_i \right) \cdot [L_{\text{dir}} \cdot V + L_{\text{ind}} \cdot (1 - V)] $$
    [S1, unofficial]
    Here, $L_{\text{dir}}$ is the direct light component (the second term in Eq. 8 of [S1, unofficial]), and $L_{\text{ind}}$ is the computed indirect light. The integral term represents the environment lighting estimation [S1, unofficial].

**Pseudocode:**

```python
def dot(a, b): return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]
def normalize(v): s = dot(v, v)**0.5; return (v[0]/s, v[1]/s, v[2]/s)
def lerp(a, b, t): return (a[0]+t*(b[0]-a[0]), a[1]+t*(b[1]-a[1]), a[2]+t*(b[2]-a[2]))
def reflect(incident, normal): return 2*dot(incident, normal)*normal - incident

def gaussian_ground_inter_reflection(origin, N, omega_o, omega_i, material, geometry_type, mesh=None, bvh=None, sh_coeffs=None, alphas=None, sdf_func=None, light_pos=None):
    # Step 1: Calculate Reflected Direction
    # [S1, unofficial] uses omega_o as the incident direction in its reflection formula.
    # [S2] uses omega_i (denoted w_i) for the same purpose.
    incident_dir = omega_o if geometry_type == 'mesh' else omega_i
    R = reflect(incident_dir, N)

    V = 1.0
    L_ind = 0.0

    if geometry_type == 'mesh':
        # Step 2a: Mesh-based visibility check [S1, unofficial]
        # [G] Standard BVH ray tracing implementation
        hit_point = None
        stack = [bvh.root]
        while stack:
            node = stack.pop()
            if not node.aabb.intersects(origin, R): continue
            if node.is_leaf:
                for tri in node.triangles:
                    t = ray_triangle_intersect(origin, R, tri)
                    if t > 1e-4:
                        hit_point = origin + R * t
                        break
            else:
                stack.extend(node.children)
            if hit_point: break
        V = 0.0 if hit_point is None else 1.0

        # Step 3a: Gaussian indirect lighting aggregation [S1, unofficial]
        l_ind_agg = 0.0
        prod_alpha = 1.0
        for i in range(len(sh_coeffs)):
            l_ind_i = evaluate_sh(sh_coeffs[i], R)
            alpha_i = alphas[i]
            l_ind_agg += l_ind_i * alpha_i * prod_alpha
            prod_alpha *= (1.0 - alpha_i)
        L_ind = l_ind_agg

    elif geometry_type == 'sdf':
        # Step 2b: SDF-based visibility check [S2]
        # [G] Standard SDF ray marching to find x'
        x_prime = origin
        for step in range(100):
            dist = sdf_func(x_prime)
            if dist < 1e-3: break
            if dist > 10.0: break
            x_prime = x_prime + R * dist
        else:
            x_prime = None

        if x_prime is not None:
            occluded = False
            # [S2] Uniformly sample 20 points between light and x'
            for k in range(20):
                t = k / 19.0
                sample_pt = lerp(light_pos, x_prime, t)
                if sdf_func(sample_pt) < 0:
                    occluded = True
                    break
            V = 0.0 if occluded else 1.0

            if not occluded:
                # [S2] Compute outgoing radiance at x' using light's incoming radiance
                # [G] Simplified direct lighting at x'
                L_ind = compute_radiance_at(x_prime, light_pos, material)
        else:
            V = 1.0
            L_ind = 0.0

    # Step 4: Combine direct and indirect light [S1, unofficial]
    # [G] Approximate environment integral term
    env_integral = integrate_specular(N, omega_i, omega_o, material.f_s)
    L_dir = material.direct_light # [S1, unofficial] Eq. 8 term
    L_prime_s = env_integral * (L_dir * V + L_ind * (1.0 - V))
    return L_prime_s

def ray_triangle_intersect(origin, dir, tri):
    # [G] Möller–Trumbore algorithm
    v1, v2, v3 = tri.v0, tri.v1, tri.v2
    e1, e2 = (v1[0]-v2[0], v1[1]-v2[1], v1[2]-v2[2]), (v3[0]-v2[0], v3[1]-v2[1], v3[2]-v2[2])
    p, q, r = (dir[1]*e2[2]-dir[2]*e2[1], dir[2]*e2[0]-dir[0]*e2[2], dir[0]*e2[1]-dir[1]*e2[0]), \
              (origin[0]-v2[0], origin[1]-v2[1], origin[2]-v2[2]), \
              dot(dir, e1)
    if abs(r) < 1e-8: return -1.0
    inv_r = 1.0 / r
    u, v, t = dot(p, q)*inv_r, dot(q, e2)*inv_r, dot(p, e2)*inv_r
    if u < 0 or u > 1 or v < 0 or u + v > 1: return -1.0
    return t

def evaluate_sh(coeffs, direction):
    # [G] Standard spherical harmonic evaluation
    x, y, z = direction
    return coeffs[0] + coeffs[1]*x + coeffs[2]*y + coeffs[3]*z

def integrate_specular(N, omega_i, omega_o, f_s):
    # [G] Approximate hemisphere integral for environment lighting
    return f_s * max(0.0, dot(omega_i, N))

def compute_radiance_at(point, light_pos, material):
    # [G] Standard direct lighting computation
    to_light = normalize((light_pos[0]-point[0], light_pos[1]-point[1], light_pos[2]-point[2]))
    return material.albedo * max(0.0, dot(to_light, material.normal_at(point)))
```

**Parameters:**
*   **Sampling points for SDF occlusion (S2):** 20 points uniformly sampled along the path [S2].
*   **Roughness:** Influences the blending coefficient in [S2] [S2].
*   **TSDF Fusion:** Used periodically during optimization to extract the mesh in [S1, unofficial] [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** Ray tracing on meshes requires correct BVH construction to avoid missed intersections [S1, unofficial]. SDF ray marching requires careful step size control to avoid missing thin geometry [S2].
*   **Boundaries:** The visibility check $V$ is binary (0 or 1) in both [S1, unofficial] and [S2], which may cause aliasing at grazing angles [S1, unofficial][S2].
*   **Degenerate Input:** If the mesh extraction fails or the SDF is invalid, the inter-reflection calculation may fail [S1, unofficial]. Efficient computation is non-trivial and relies on on-the-fly mesh extraction [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the visibility check method. Mesh-based ray tracing requires BVH traversal per ray [S1, unofficial]. SDF ray marching requires $O(K)$ steps for marching plus $O(M)$ for occlusion sampling (20 points) [S2].
*   **Memory Complexity:** Mesh-based approach requires storing the mesh and BVH [S1, unofficial]. SDF-based approach requires storing the SDF field [S2]. Gaussian-based approach requires storing SH coefficients per Gaussian [S1, unofficial].
*   **Performance:** [S1, unofficial] reports that on-the-fly mesh extraction adds overhead but enables accurate self-occlusion [S1, unofficial]. [S2] notes that importance sampling and differentiable layers allow for efficient optimization [S2].
*   **Strengths:** Accurately models self-occlusion and indirect lighting for reflective surfaces [S1, unofficial][S2].
*   **Limitations:** Computationally expensive due to ray tracing/marching [S1, unofficial][S2]. Requires additional geometry representation (mesh or SDF) [S1, unofficial][S2].

## Background
*   **Origin:** The method is described in "Reflective Gaussian Splatting" [S1, unofficial] and "PIR: Photometric Inverse Rendering with Shading Cues Modeling and Surface Reflectance Regularization" [S2].
*   **History:** Developed to address the lack of inter-reflection modeling in standard Gaussian Splatting and other real-time rendering techniques [S1, unofficial][S2].
*   **Usage:** Used in inverse rendering and realistic rendering of reflective objects [S1, unofficial][S2].
