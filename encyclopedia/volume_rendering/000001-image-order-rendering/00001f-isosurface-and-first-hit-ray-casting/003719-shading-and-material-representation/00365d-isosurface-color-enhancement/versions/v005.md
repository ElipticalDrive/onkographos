# Isosurface Color Enhancement

Also called: Color Enhancement via Scalar Changing Rate, Enhanced Isosurface Rendering, Speed-color Map

## Overview
Isosurface Color Enhancement is a shading technique applied to intersection points on an isosurface to illustrate neighborhood density and reveal internal structures behind the isosurface [S1, unofficial]. Unlike standard isosurface rendering which assigns a constant or gradient-based color, this method approximates the accumulated alpha in a semi-transparent neighborhood behind the surface using the scalar changing rate as a proxy for neighborhood thickness [S1, unofficial]. It sets itself apart by maintaining the simplicity and computational complexity of standard isosurface rendering without increasing the voxel-traversal or ray-voxel intersection cost [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** Scalar field $v$, isovalue $l_{iso}$, viewing ray direction $\vec{r}$, local transfer function defined by pairs $\{\alpha_{T,i}, \tilde{c}_i\}_{i=1}^n$ where $\alpha_{T,i}$ is opacity and $\tilde{c}_i=(r_i, g_i, b_i)$ is color, global parameters `densityFactor` and $\Delta v$, sample distance `stdSampleDistance`, and voxel size $h$ [S1, unofficial][G].
*   **Output:** Final color $\tilde{C}$ for the intersection point $\mathbf{p}$ [S1, unofficial].

**Data Structures**
*   **Speed-color Map:** A logarithmically sampled array of size $m$ [S1, unofficial]. The $j$-th entry stores the pre-calculated color $\tilde{C}_j$ for speed value $\text{speed}_j = -\ln(1 - j/m)$, where $j = 1, 2, ..., m$ [S1, unofficial].

**Steps**
1.  **Compute Scalar Changing Rate:** Estimate the scalar changing rate $v'_l(l_{iso})$ at the intersection point $\mathbf{p}$ [S1, unofficial].
    *   *Shallow Estimation:* Use the directional derivative along the viewing ray: $v'_l(l_{iso}) \approx \nabla v \cdot \vec{r}$ [S1, unofficial]. The gradient $\nabla v$ is computed on the fly using 6 neighboring scalar samples via finite differences [S1, unofficial].
    *   *Deep Estimation (Internal Structures):* Perform an iterative search along the viewing ray to find a distance $\Delta l$ where the scalar value reaches $l_{iso} + \Delta v$ [S1, unofficial]. Estimate the rate as $\Delta l / \Delta v$ [S1, unofficial].
2.  **Calculate Speed:** Compute the speed value using the formula:
    $$ \text{speed} = \frac{v'_l(l_{iso})}{\text{densityFactor}} $$
    where $\text{speed} \in (0, +\infty)$ [S1, unofficial].
3.  **Lookup Color:** Use the calculated `speed` to index into the Speed-color Map [S1, unofficial]. Since `speed` has an infinite range, linear mapping is not feasible; the logarithmic sampling handles this [S1, unofficial].
4.  **Return Color:** Return the color $\tilde{C}$ from the map [S1, unofficial].

**Formulas**
The alpha value for accumulation in the neighborhood is approximated as:
$$ \alpha \approx \frac{\alpha_{T,i}}{n \cdot \text{speed}} $$
where $\alpha_{T,i}$ is the alpha value defined in the transfer function assuming a sample distance `stdSampleDistance`, and $n$ is the number of samples in the neighborhood [S1, unofficial].

The accumulated color $\tilde{C}(\text{speed})$ is calculated via alpha blending:
$$ \tilde{C}(\text{speed}) = \sum_{i=1}^{n} \alpha_{\text{speed},i} \tilde{c}_i \prod_{j=1}^{i-1} (1 - \alpha_{\text{speed},j}) $$
where $\alpha_{\text{speed},i} = \frac{\alpha_{T,i}}{n \cdot \text{speed}}$ and $\tilde{c}_i = (r_i, g_i, b_i)$ are the colors from the local transfer function [S1, unofficial].

**Parameters**
*   `densityFactor`: A global tunable parameter used to normalize the scalar changing rate into the 'speed' value [S1, unofficial]. Typical value derived from `stdSampleDistance` and $\Delta v$ [S1, unofficial].
*   $\Delta v$: A global tunable parameter defining the range for deep neighborhood estimation (isovalue to isovalue + $\Delta v$) [S1, unofficial].
*   `stdSampleDistance`: The sample distance assumed in the transfer function definition [S1, unofficial].

**Pseudocode**
```python
import math

def compute_isosurface_color_enhancement(intersection_point, ray_direction, scalar_field, isovalue, transfer_function, density_factor, delta_v, speed_color_map, voxel_size):
    # Step 1: Estimate scalar changing rate v'_l(l_iso)
    grad_v = compute_gradient(scalar_field, intersection_point, voxel_size)
    scalar_rate_shallow = sum(g * d for g, d in zip(grad_v, ray_direction))
    
    # Deep estimation for internal structures: iterative search along ray
    scalar_rate_deep = estimate_deep_rate(scalar_field, intersection_point, ray_direction, isovalue, delta_v, voxel_size)
    
    # Use deep estimation to reveal internal structures, or shallow for immediate vicinity [S1, unofficial]
    scalar_rate = scalar_rate_deep 
    
    # Step 2: Calculate Speed
    speed = scalar_rate / density_factor
    
    # Step 3: Lookup Color from Speed-color Map
    # Map definition: speed_j = -ln(1 - j/m) for j=1..m [S1, unofficial]
    # Inverting for index: j = m * (1 - exp(-speed))
    map_size = len(speed_color_map)
    index_float = map_size * (1.0 - math.exp(-speed))
    
    # Clamp index to valid range [0, map_size-1] for 0-based array access [G]
    index = int(min(max(index_float, 0.0), map_size - 1.0))
    
    # Return precomputed color [S1, unofficial]
    return speed_color_map[index]

def estimate_deep_rate(scalar_field, start_point, direction, isovalue, delta_v, voxel_size):
    current_pos = list(start_point)
    target_scalar = isovalue + delta_v
    step = voxel_size
    max_steps = 1000
    
    for _ in range(max_steps):
        current_scalar = scalar_field(current_pos)
        if current_scalar >= target_scalar:
            distance = math.sqrt(sum((p - s)**2 for p, s in zip(current_pos, start_point)))
            return distance / delta_v
        current_pos = [p + d * step for p, d in zip(current_pos, direction)]
        
    return float('inf')

def compute_gradient(scalar_field, point, voxel_size):
    h = voxel_size
    dx = (scalar_field([point[0] + h, point[1], point[2]]) - scalar_field([point[0] - h, point[1], point[2]])) / (2.0 * h)
    dy = (scalar_field([point[0], point[1] + h, point[2]]) - scalar_field([point[0], point[1] - h, point[2]])) / (2.0 * h)
    dz = (scalar_field([point[0], point[1], point[2] + h]) - scalar_field([point[0], point[1], point[2] - h])) / (2.0 * h)
    return [dx, dy, dz]
```

**Edge Cases and Pitfalls**
*   **Infinite Speed Range:** Speed has an infinite value range, so a linear map is not feasible [S1, unofficial]. A logarithmic sampling is used to handle the infinite range [S1, unofficial].
*   **Shallow vs. Deep:** Shallow neighborhood estimation using $\nabla v \cdot \vec{r}$ reflects only the immediate vicinity [S1, unofficial]. Deep neighborhood estimation reveals internal structures but requires iterative search [S1, unofficial].

## Subtopics

### Shallow Neighborhood Estimation
Estimates the scalar changing rate using the directional derivative $\nabla v \cdot \vec{r}$ to reflect the immediate vicinity of the isosurface [S1, unofficial]. Sets itself apart from deep estimation by avoiding iterative searches, making it faster but less effective at revealing internal structures [S1, unofficial]. Link: [Shallow Neighborhood Estimation](shallow-neighborhood-estimation.md).

### Deep Neighborhood Estimation
Estimates the scalar changing rate by performing an iterative search along the viewing ray to find $\Delta l$ where the scalar reaches $l_{iso} + \Delta v$, then computing $\Delta l / \Delta v$ [S1, unofficial]. Sets itself apart from shallow estimation by revealing internal structures behind the isosurface at the cost of additional computation [S1, unofficial]. Link: [Deep Neighborhood Estimation](deep-neighborhood-estimation.md).

## Operating characteristics
*   **Time Complexity:** Does not increase computational complexity compared to standard isosurface rendering [S1, unofficial]. The color lookup is $O(1)$ after precomputation [S1, unofficial].
*   **Memory Complexity:** Requires storage for the Speed-color map of size $m$ [S1, unofficial].
*   **Strengths:** Improves visual fidelity and reveals internal structures without significant increase in computational cost [S1, unofficial]. Maintains the simplicity of standard isosurface rendering [S1, unofficial].
*   **Limitations:** Shallow estimation only reflects immediate vicinity [S1, unofficial]. Deep estimation requires iterative search which may be slower than shallow, though still cheaper than full volume rendering [S1, unofficial].

## Background
Originated in the work on "Efficient and Effective Volume Visualization with Enhanced Isosurface Rendering" [S1, unofficial]. The method was developed to improve the effectiveness of isosurface rendering while maintaining performance efficiency [S1, unofficial]. It extends the structure extraction capability by enabling explicit scene exploration [S1, unofficial].
