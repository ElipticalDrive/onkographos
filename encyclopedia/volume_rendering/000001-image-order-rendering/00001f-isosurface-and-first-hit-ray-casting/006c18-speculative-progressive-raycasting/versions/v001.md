# Speculative Progressive Raycasting

Also called: Progressive Wavefront Isosurface Raycasting, implicit isosurface rendering algorithm, progressive algorithm for implicit isosurface raycasting, progressive wavefront traversal with ray-block speculation

## Overview
Speculative Progressive Raycasting is a GPU-based algorithm for interactive, memory-constrained visualization of massive implicit isosurfaces. It solves the problem of rendering large volumes on lightweight devices (e.g., web browsers) by progressively traversing a wavefront of rays through a block-compressed volume, decompressing data on-demand to minimize memory footprint. It differs from static block-caching methods like BCMC by eliminating explicit triangle mesh storage and processing blocks in a view-dependent wavefront, tying compute costs primarily to image size rather than dataset size [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Volume data compressed using ZFP's fixed-rate compression mode [S1]. Camera position and isovalue $\tau$ [S1].
*   **Output:** Progressive image of the isosurface. Rendering completes when all rays have terminated [S1].

**Data Structures:**
The algorithm maintains several image-sized buffers (width $W$, height $H$) and a GPU-driven LRU cache for decompressed blocks.

1.  **Ray Data Buffer:** Size 16 bytes per-ray.
    *   Fields: Ray direction $\mathbf{d}$ (3 floats), entry $t$ value $t_{entry}$ (1 float) [S1].
2.  **Iterator State Buffer:** Size 32 bytes per-ray.
    *   Fields: $t_{max}$ (1 float), current coarse cell ID (1 uint), current fine cell ID (1 uint), padding (1 float) [S1].
3.  **RBID Buffer:** Image-sized buffer.
    *   Type: UINT.
    *   Value: Block ID each ray intersects, or `UINT_MAX` if none [S1].
4.  **Macrocell Grid:** Two-level grid constructed on the GPU [S1].
    *   **Fine Grid:** Uses ZFP's $4^3$ block decomposition [S1].
    *   **Coarse Grid:** Groups $4^3$ regions of ZFP blocks to form coarse cells containing $16^3$ voxels [S1].
    *   **Value Range:** Each cell stores the value range $[v_{min}, v_{max}]$. This range is computed by combining the range of the cell's voxels/blocks with those of its neighbors in the $+x, +y, +z$ directions to prevent cracks from missing values in the dual grid [S1].

**Algorithm Steps:**

1.  **Initialization:**
    *   Upload ZFP-compressed volume data to the GPU [S1].
    *   Construct the two-level macrocell grid on the GPU. Compute value ranges for all fine and coarse cells, incorporating neighbor ranges in $+x, +y, +z$ to ensure no isovalue is missed due to dual grid boundaries [S1].
    *   Initialize the LRU cache for decompressed blocks [S1].

2.  **Ray Setup (per camera/isovalue change):**
    *   Rasterize the backfaces of the volume's bounding box.
    *   In the fragment shader, compute ray directions $\mathbf{d}$ and entry $t$ values $t_{entry}$ for each pixel.
    *   Write $\mathbf{d}$ and $t_{entry}$ to the Ray Data Buffer (16 bytes/ray).
    *   Mark rays that miss the volume as terminated [S1].

3.  **Progressive Wavefront Loop:**
    Repeat the following steps until all rays are terminated:

    3.1. **Macrocell Grid Traversal:**
    *   For each active ray, traverse the coarse grid using the Amanatides and Woo algorithm [S1].
    *   Skip coarse cells where $\tau \notin [v_{min}, v_{max}]$.
    *   Upon entering a coarse cell containing $\tau$, traverse the $4^3$ fine grid blocks within it.
    *   Skip fine blocks where $\tau \notin [v_{min}, v_{max}]$.
    *   If a block containing $\tau$ is found:
        *   Save the current coarse and fine grid iterator states ($t_{max}$ and cell IDs) to the Iterator State Buffer. This prevents precision issues from skipping cells between passes [S1].
        *   Write the block ID to the RBID buffer for this ray.
        *   Mark the ray as having found a block (or terminated if it exits the volume) [S1].

    3.2. **Mark Visible and Active Blocks:**
    *   Identify all blocks referenced in the RBID buffer as **visible**.
    *   Identify all $+x, +y, +z$ neighbors of visible blocks as **active**. Active blocks are required to provide data for the visible block's dual grid to avoid cracks [S1].
    *   Mark all visible and active blocks for decompression [S1].

    3.3. **On-Demand Decompression and Caching:**
    *   For each marked block:
        *   If the block is not in the LRU cache, decompress it using a WebGPU port of ZFP's CUDA decompressor [S1].
        *   Insert the decompressed block into the LRU cache.
        *   If the cache exceeds capacity, evict the least recently used block [S1].

    3.4. **Block Raycasting Kernel Setup:**
    *   Perform stream compaction and parallel sorts to construct arrays of:
        *   Visible block IDs.
        *   Number of rays intersecting each block.
        *   Ray IDs sorted by their block ID [S1].

    3.5. **Block Raycasting and Speculation:**
    *   Launch the block raycasting kernel. Each block processes its assigned rays to find ray-isosurface intersections.
    *   **Speculation:** To fill open compute slots left by terminated rays, traverse additional blocks speculatively along active rays. A global speculation count determines how many extra blocks to test per active ray. This increases GPU utilization and accelerates rendering completion [S1].
    *   If a ray intersects the isosurface within the block, mark it as terminated. Refine the intersection position if necessary (standard isosurface refinement) [S1, G].

    3.6. **Completion Check:**
    *   Compute the remaining number of active rays.
    *   If zero, rendering is complete.
    *   Display the current image to the user [S1].

lru_cache: LRUCache # Stores decompressed 4^3 blocks
ray_data_buffer: Buffer # 16 bytes/ray: direction, t_entry
iterator_state_buffer: Buffer # 32 bytes/ray: t_max, coarse_id, fine_id
rbid_buffer: Buffer # UINT, block ID or UINT_MAX
is_terminated: Buffer # Boolean, per ray

def init(volume_data, camera, isovalue):
    zfp_compressed_data = upload(volume_data)
    macrocell_grid = build_macrocell_grid(zfp_compressed_data)
    lru_cache = LRUCache()
    ray_data_buffer = compute_initial_rays(camera)
    is_terminated = [False] * (W * H)
    # Initialize iterator states
    for i in range(W * H):
        iterator_state_buffer[i].t_max = ray_data_buffer[i].t_entry
        iterator_state_buffer[i].coarse_id = 0
        iterator_state_buffer[i].fine_id = 0

def compute_initial_rays(camera):
    # Rasterize backfaces of bounding box
    rays = []
    for pixel in pixels:
        ray = ray_from_pixel(camera, pixel)
        if ray.intersects_volume():
            rays.append({
                'direction': ray.direction,
                't_entry': ray.t_min,
                'id': pixel.id
            })
        else:
            is_terminated[pixel.id] = True
            rays.append(None)
    return rays

def progressive_render(isovalue, speculation_count=1):
    while not all(is_terminated):
        # 1. Traverse Macrocell Grid
        traverse_grid(isovalue)
        
        # 2. Mark Blocks
        visible_blocks = set()
        active_blocks = set()
        for i in range(W * H):
            if not is_terminated[i]:
                bid = rbid_buffer[i]
                if bid != UINT_MAX:
                    visible_blocks.add(bid)
                    # Add +x, +y, +z neighbors
                    active_blocks.add(get_neighbor(bid, +1, 0, 0))
                    active_blocks.add(get_neighbor(bid, 0, +1, 0))
                    active_blocks.add(get_neighbor(bid, 0, 0, +1))
        
        all_blocks = visible_blocks.union(active_blocks)
        
        # 3. Decompress and Cache

            if not lru_cache.contains(bid):
                decompressed = decompress_zfp(zfp_compressed_data, bid)
                lru_cache.insert(bid, decompressed)
        
        # 4. Setup Block Raycasting
        block_rays = compact_and_sort_rays(rbids, is_terminated)
        
        # 5. Execute Block Raycasting with Speculation
        # Speculation adds extra blocks to test for active rays
        execute_block_raycasting_kernel(block_rays, speculation_count, isovalue)
        
        # 6. Check Completion
        update_termination_status()
        display_image()

def traverse_grid(isovalue):
    for i in range(W * H):
        if is_terminated[i]:
            continue
        
        state = iterator_state_buffer[i]
        ray_dir = ray_data_buffer[i].direction
        t_current = state.t_max
        
        # Traverse Coarse Grid
        coarse_id = state.coarse_id
        while coarse_id is valid:
            coarse_cell = macrocell_grid.coarse[coarse_id]
            if isovalue not in coarse_cell.value_range:
                coarse_id = next_coarse_cell(coarse_id, ray_dir, t_current)
                continue
            
            # Traverse Fine Grid within Coarse Cell
            fine_id = state.fine_id
            while fine_id is valid:
                fine_block = macrocell_grid.fine[fine_id]
                if isovalue not in fine_block.value_range:
                    fine_id = next_fine_cell(fine_id, ray_dir, t_current)
                    continue
                
                # Found candidate block
                rbid_buffer[i] = fine_block.id
                state.t_max = t_current # Save state
                state.coarse_id = coarse_id
                state.fine_id = fine_id
                break # Exit fine traversal
            
            if rbid_buffer[i] != UINT_MAX:
                break # Found block in this coarse cell
            
            coarse_id = next_coarse_cell(coarse_id, ray_dir, t_current)
        
        if rbid_buffer[i] == UINT_MAX:
            is_terminated[i] = True

def execute_block_raycasting_kernel(block_rays, speculation_count, isovalue):
    for block_id, rays in block_rays:
        decompressed_block = lru_cache.get(block_id)
        for ray_idx in rays:

## Operating characteristics
*   **Time Complexity:** Tied to image size ($W \times H$) and number of passes, not dataset size. Each pass processes active rays and visible blocks [S1].
*   **Memory Complexity:** Proportional to the number of active blocks in the LRU cache, which is significantly smaller than the total dataset. Achieves up to 5.7× reduction in overall memory use and 8.4× reduction in data decompressed compared to BCMC [S1].
*   **Performance:** On an RTX 3080 at 1280×720, the Richtmyer-Meshkov dataset averages 264ms per-pass and 1.2s total render time [S1].
*   **Strengths:**
    *   Enables interactive visualization of massive volumes (up to 8.05B voxels) on lightweight devices (XPS 13, M1 Mac Mini) [S1].
    *   Runs entirely on the GPU (WebGPU), eliminating CPU communication bottlenecks [S1].
    *   Progressive rendering improves interactivity by displaying the surface after each pass [S1].
*   **Limitations:**
    *   Does not scale down well to small datasets; overhead may make it slower than BCMC on small volumes like Plasma or Chameleon [S1].
    *   Uses a global speculation count, which is restrictive; per-ray speculation could increase utilization but adds complexity [S1].
    *   Precision issues in tracking $t$ values can cause cells to be skipped if iterator states are not saved/restored [S1].

## Background
The algorithm was proposed by Will Usher and Valerio Pascucci in 2023 [S1]. It addresses the memory constraints of lightweight end-user devices when visualizing massive datasets produced by modern simulations. It builds on prior work in ray-guided large volume rendering and implicit isosurface extraction, specifically improving upon the Brick Cache Memory Constrained (BCMC) algorithm by eliminating explicit triangle mesh storage and using a view-dependent wavefront traversal [S1]. The implementation targets WebGPU/WebAssembly environments for browser-based visualization [S1].
