# Cell-Based First-Hit Ray Casting


## Overview
Cell-based first-hit ray casting is a volume rendering technique that accelerates iso-surface extraction by dividing the volume into cubic sub-volumes called macro-cells [S1, unofficial][S2]. It solves the performance bottleneck of conventional ray casting by avoiding empty space traversal and reducing the average ray path length to only a few steps per pixel [S1, unofficial]. It sets itself apart from its siblings by using a min-max octree to cull macro-cells and projecting only those containing iso-surface portions to the screen, where local rays are cast [S1, unofficial][S2]. Unlike [Hybrid Strategy for Interactive High Resolution Isosurface Ray Tracing](3697-hybrid-strategy-for-interactive-high-resolution-isosurface-r.md) or [Interactive High Resolution Isosurface Ray Tracing](4093-interactive-high-resolution-isosurface-ray-tracing.md), it does not rely on dedicated acceleration hardware or surface fitting techniques that lack interactive threshold adjustment [S1, unofficial].

## How it works
**Inputs:**
*   Volume data $V$ with dimensions $D_x \times D_y \times D_z$ [G].
*   One or more iso-value thresholds $\tau$ [S1, unofficial].
*   Camera parameters (eye position, view direction, projection matrix) [G].
*   Macro-cell dimension parameter $n$ (typically 4–10) [S1, unofficial][S2].

**Outputs:**
*   Color image buffer $C$ of resolution $W \times H$ [G].
*   A per-pixel hit flag to prevent re-rendering pixels that have already found an intersection [S2].

**Data Structures:**
1.  **Min-Max Octree:**
    *   Each node stores `min_val` and `max_val` representing the minimum and maximum data values in the sub-volume it covers [S1, unofficial][S2].
    *   Leaf nodes represent **macro-cells** [S1, unofficial][S2].
    *   A macro-cell consists of $n^3$ data cells (defined by $(n+1)^3$ voxel grid points) [S2].
2.  **Ray History Buffer:**
    *   Stores cells encountered along the last ray and a flag indicating if an iso-surface portion is contained there [S1, unofficial]. This exploits inter-ray coherency to skip intersection tests for rays visiting the same cells [S1, unofficial].
3.  **Pixel Hit Flags:**
    *   Boolean array of size $W \times H$. If the flag for a pixel is true, no more local rays are cast at this pixel [S2].

**Algorithm Steps:**

1.  **Build Min-Max Octree:** Recursively subdivide the volume. For each node, compute `min_val` and `max_val` of the contained data [S1, unofficial][S2]. Leaf nodes correspond to macro-cells of size $n \times n \times n$ cells [S1, unofficial][S2].
2.  **Traverse Octree in Viewing Order:** Start at the root. For a current node, check if any threshold $\tau$ satisfies: $\text{min\_val} \le \tau \le \text{max\_val}$ [S1, unofficial][S2]. If the condition fails, cull the entire subtree [S1, unofficial][S2]. If the condition passes, sort the 8 child nodes based on the viewing vector to ensure correct front-to-back processing order [S1, unofficial][S2]. This is done using a representative ray direction that intersects all sub-volumes [S1, unofficial]. Recursively process children.
3.  **Process Leaf Nodes (Macro-Cells):** When a leaf node (macro-cell) is reached, it contains potential iso-surface portions [S2]. **Trimming:** Trim the macro-cell to the smallest cuboid containing the portions of the iso-surfaces [S2]. **Projection:** Project the trimmed macro-cell onto the screen plane [S2]. **Rasterization:** Rasterize the projection to identify all pixels $(x, y)$ covered by the macro-cell [S2].
4.  **Cast Local Rays:** For each covered pixel $(x, y)$: If the pixel hit flag is true, skip this pixel [S2]. Construct a local ray originating from the camera eye, passing through $(x, y)$, and clipped to the entry and exit points of the macro-cell [S1, unofficial][S2]. **Early Scanline Termination (Optional Optimization):** If the pixel is likely to not find an intersection, skip the ray cast to save time [S1, unofficial]. **Voxel Traversal:** Use a fast voxel traversal algorithm (e.g., Amanatides and Woo) to iterate through cells pierced by the local ray within the macro-cell [S1, unofficial][S2]. **Boundary Check:** For each cell, determine if it is a "boundary cell" (contains data values both above and below $\tau$) [S1, unofficial]. **Intersection Test:** If a boundary cell is found, perform a ray-surface intersection test [S1, unofficial][S2]. *Fast Intersection Method:* Divide the ray segment through the cell into two equal parts. Evaluate density at endpoints. If signs differ, linearly interpolate the intersection point [S1, unofficial]. *Exact Intersection Method (Alternative):* Invert trilinear interpolation to find exact intersection points [S1, unofficial]. **Shading:** If an intersection is found: Calculate the gradient $\nabla f$ at the intersection point using trilinear interpolation of the gradient components [S1, unofficial][S2]. Compute color using shading model (e.g., Phong) [G]. Assign color to $C[y][x]$ [G]. Set the pixel hit flag to true [S2]. **Coherency Check:** Use the Ray History Buffer to skip intersection tests if the current ray visits the same cells as the previous ray and the buffer indicates no surface was found [S1, unofficial].

def _traverse_node(node, camera, thresholds, color_buffer, hit_flags,
                   ray_history_buffer, n, width, height):
    # Culling: Check if any threshold is within node's min/max range [S1, unofficial][S2]
    cull = True
    for tau in thresholds:
        if node.min_val <= tau <= node.max_val:
            cull = False
            break

    if cull:
        return

    # If leaf node (macro-cell)
    if node.is_leaf:
        _process_macro_cell(node, camera, thresholds, color_buffer, hit_flags,
                            ray_history_buffer, n, width, height)
        return

    # Internal node: Sort children by viewing order [S1, unofficial][S2]
    # Use representative ray direction to determine order
    children = sorted(node.children, key=lambda child:
                      _dot_product(_vector_sub(child.center, camera.eye), camera.direction))

    for child in children:
        _traverse_node(child, camera, thresholds, color_buffer, hit_flags,
                       ray_history_buffer, n, width, height)

def _process_macro_cell(node, camera, thresholds, color_buffer, hit_flags,
                        ray_history_buffer, n, width, height):
    # 1. Trim macro-cell to smallest cuboid containing iso-surfaces [S2]
    trimmed_cuboid = _compute_trimmed_cuboid(node.bounds, thresholds)

    # 2. Project trimmed cuboid to screen [S2]
    screen_rect = _project_cuboid_to_screen(trimmed_cuboid, camera)

    # 3. Rasterize and cast local rays
    for y in range(screen_rect.y_min, screen_rect.y_max):
        for x in range(screen_rect.x_min, screen_rect.x_max):
            # Skip if pixel already hit [S2]
            if hit_flags[y][x]:
                continue

            # Construct local ray clipped to macro-cell [S1, unofficial][S2]
            ray = _create_local_ray(camera, x, y, node.bounds)

            # 4. Voxel Traversal within macro-cell (Amanatides & Woo [S1, unofficial][S2])
            cells = _amanatides_woo_traversal(ray, node.bounds, n)

            intersection_found = False
            for cell in cells:
                # Check coherency [S1, unofficial]
                cell_id = _get_cell_id(cell, node.bounds)
                if cell_id in ray_history_buffer and not ray_history_buffer[cell_id]:
                    continue  # Skip intersection test based on history

                # Check if boundary cell [S1, unofficial]
                if _is_boundary_cell(cell, thresholds):
                    # Perform intersection test [S1, unofficial][S2]
                    hit_point, hit_normal = _fast_ray_surface_intersection(ray, cell, thresholds)

                    if hit_point is not None:
                        # Shading [G]
                        gradient = _trilinear_gradient(cell, hit_point)
                        color = _phong_shading(hit_point, hit_normal, gradient, camera)

                        # Update output
                        color_buffer[y][x] = color
                        hit_flags[y][x] = True
                        intersection_found = True

                        # Update history buffer for this cell
                        ray_history_buffer[cell_id] = True
                        break  # First hit wins

            if not intersection_found:
                # Mark cells visited in this ray as 'no surface' for coherency
                for cell in cells:
                    cell_id = _get_cell_id(cell, node.bounds)
                    if cell_id not in ray_history_buffer:
                        ray_history_buffer[cell_id] = False

def _fast_ray_surface_intersection(ray, cell, thresholds):
    # Fast intersection method: divide segment into two, check signs, interpolate [S1, unofficial]
    p1 = ray.origin + ray.direction * cell.entry_t
    p2 = ray.origin + ray.direction * cell.exit_t

    d1 = _trilinear_sample(p1)
    d2 = _trilinear_sample(p2)

    for tau in thresholds:
        if (d1 - tau) * (d2 - tau) < 0:
            # Linear interpolation
            t = cell.entry_t + (tau - d1) / (d2 - d1) * (cell.exit_t - cell.entry_t)
            hit_point = ray.origin + ray.direction * t
            hit_normal = _trilinear_gradient(cell, hit_point)
            return hit_point, hit_normal

    return None, None

def _create_local_ray(camera, x, y, bounds): return {'origin': camera.eye, 'direction': camera.direction, 'entry_t': 0.0, 'exit_t': 1.0}  # Ray clipping [G]
def _amanatides_woo_traversal(ray, bounds, n): return [{'entry_t': 0.0, 'exit_t': 1.0, 'coords': (0,0,0)}]  # Standard traversal [G]
def _get_cell_id(cell, bounds): return str(cell.coords)
def _is_boundary_cell(cell, thresholds): return True  # Standard boundary check [G]
def _trilinear_sample(point): return 0.5  # Standard interpolation [G]
def _trilinear_gradient(cell, point): return (0.0, 0.0, 0.0)  # Standard gradient [G]
def _phong_shading(point, normal, gradient, camera): return (1.0, 1.0, 1.0)  # Standard shading [G]

**Parameters:**
*   $n$: Macro-cell dimension. Typical values: 3–10 [S1, unofficial][S2].
*   Thresholds: Iso-values. Example: 0 HU (soft tissue) to 1100 HU (stent) [S1, unofficial].
*   Image Resolution: 512x512 in reported experiments [S1, unofficial].

**Pitfalls:**
*   **Macro-cell Size:** Small $n$ increases octree traversal and projection overhead, splits rays into more segments, and increases expensive ray initialization steps for rays traveling along iso-surfaces without intersecting [S1, unofficial]. Large $n$ reduces early termination effectiveness because small critical regions are less likely to be detected [S1, unofficial].
*   **Viewing Order:** Ray segments must be processed in correct viewing order to ensure the first intersection determines the final pixel color. Failure to sort child nodes by viewing vector causes visibility artifacts [S1, unofficial][S2].
*   **Distance Coding:** Not used because it would require recomputation for each new iso-value [S1, unofficial].
*   **Soft Tissue Occlusion:** When low thresholds hide the surface of interest (e.g., soft tissue hiding a stent), conventional ray casting may be faster because ray-surface distances are short. Cell-based method suffers as almost all macro-cells must be processed and "peep holes" delay termination [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on the number of macro-cells intersecting the iso-surface and the local ray path length [G]. Significantly faster than conventional ray casting when higher thresholds hide soft tissue and reduce macro-cell processing [S1, unofficial].
*   **Measured Performance:**
    *   Virtual angioscopy (stented aorta): Average frame time 1.291s vs 2.119s for conventional [S1, unofficial].
    *   450 HU threshold (bones/stent): 1.953s vs 8.563s (4.38x speedup) [S1, unofficial].
    *   1100 HU threshold (stent only): 0.609s vs 12.781s (20.98x speedup) [S1, unofficial].
*   **Ray Path Reduction:** Reduces average steps per pixel from ~35.5 (conventional) to ~15.6 (cell-based), and further to ~3.9 with optimizations (trimming, early termination) [S1, unofficial].
*   **Strengths:** Short average ray path lengths; cache-coherent access (each macro-cell processed once); supports interactive threshold adjustment; no dedicated hardware required [S1, unofficial].
*   **Limitations:** Performance degrades when low thresholds cause extensive macro-cell processing due to fine-structured tissue ("peep holes"); small macro-cells increase overhead; large macro-cells reduce culling efficiency [S1, unofficial].
*   **When to Use:** Fast perspective iso-surfacing, virtual endoscopy, interactive threshold adjustment [S1, unofficial][S2].
*   **When Not to Use:** Low-resolution previews (use conventional ray casting or progressive rendering); scenarios with very low thresholds where soft tissue occludes the surface of interest [S1, unofficial].

## Background
*   **Origin:** Proposed by André Neubauer, Lukas Mroz, H. Hauser, and R. Wegenkittl in 2002 [S1, unofficial].
*   **Development:** Developed as part of the AlVis project for visualization of high-resolution industrial CT data (aluminum foam) and tested for virtual angioscopy (stent placement assessment) [S1, unofficial].
*   **Comparison:** Contrasted with Surface Fitting techniques (e.g., Hietala et al.) which require dedicated hardware and lack interactive threshold adjustment [S1, unofficial]. Contrasted with exact ray-surface intersection methods (Lin et al., Parker et al.) which are more accurate but computationally expensive; this method uses a faster, slightly less accurate approximation [S1, unofficial].
