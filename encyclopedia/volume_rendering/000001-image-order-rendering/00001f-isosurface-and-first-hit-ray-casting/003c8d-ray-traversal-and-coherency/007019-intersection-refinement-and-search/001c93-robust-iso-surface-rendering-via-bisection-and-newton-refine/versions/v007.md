# Robust Iso-surface Rendering via Bisection and Newton Refinement

Also called: Isosurface Raycasting with Binary Search, Similarity Map Rendering, bisection trace with Newton refinement, isoray rendering pipeline

## Overview
This method renders volumetric similarity maps by tracing rays to find the first intersection with an isosurface defined by class similarity values, followed by Phong shading [S1]. It employs a bisection search for intersection detection after a coarse traversal, optionally refined by Newton's method to achieve sub-pixel accuracy [S1][S2, unofficial]. Unlike methods relying solely on linear interpolation, this approach guarantees robustness through interval arithmetic or Lipschitz-based inclusion functions [S2, unofficial].

## How it works
**Inputs:**
*   Scalar field function $f(\mathbf{p})$ returning value and optionally gradient [S2, unofficial].
*   Camera parameters: origin $\mathbf{o}$, direction $\mathbf{d}$, field of view, projection type [S2, unofficial].
*   Iso-value threshold $\tau$ for the specific class $C$ [S1].
*   Bounding box bounds $(\mathbf{lo}, \mathbf{hi})$ [S2, unofficial].
*   Parameters: `newton_iter` (default 3), `margin` (default 0.01), `lipschitz` (constant or 'auto'), `safety` (default 1.5), `n_samples` (default 10000) [S2, unofficial].

**Outputs:**
*   Color buffer with forward-composited surface colors [S1].
*   Depth buffer [S2, unofficial].
*   Hit masks and surface normals [S2, unofficial].

**Data Structures:**
*   `TraceResult`: Contains `position` (N, 3), `normal` (N, 3), `t` (N,), `hit` (N, bool) [S2, unofficial].
*   `AffineForm` (for inclusion functions): `x0` (N,), `xi` (N, K), `delta` (N,) [S2, unofficial].
*   `GradientInclusion`: Wraps $f$ and a Lipschitz constant $L$ [S2, unofficial].

**Steps:**

1.  **Camera Setup:** Compute ray origins and directions for each pixel. For perspective projection, use FOV; for parallel, use extent [S2, unofficial].
2.  **Bounding Box Intersection:** Compute ray-AABB intersection to get $t_{min}$ and $t_{max}$. The AABB is expanded by a margin:
    $$ \text{margin} = (\mathbf{hi} - \mathbf{lo}) \times 0.01 $$
    $$ \mathbf{aabb\_lo} = \mathbf{lo} - \text{margin} $$
    $$ \mathbf{aabb\_hi} = \mathbf{hi} + \text{margin} $$
    [S2, unofficial]
3.  **Lipschitz Estimation (if `lipschitz='auto'`):** Estimate $L$ by sampling $N$ points in the bounds, computing gradient norms, and taking the maximum multiplied by a safety factor (default 1.5) [S2, unofficial].
    $$ L = \max_{i} \|\nabla f(\mathbf{p}_i)\| \times 1.5 $$
    [S2, unofficial]
4.  **Coarse Traversal:** Step along the ray from $t_{min}$ until $f(\mathbf{p}(t)) \ge \tau$ [S1].
5.  **Bisection Search:** Perform binary search within the interval $[t_{start}, t_{end}]$ where the threshold crossing was detected [S1].
    $$ t_{mid} = \frac{t_{start} + t_{end}}{2} $$
    Evaluate $f(\mathbf{p}(t_{mid}))$. If $f \ge \tau$, set $t_{end} = t_{mid}$; else $t_{start} = t_{mid}$ [G].
6.  **Newton Refinement (Optional):** Apply Newton's method to refine $t$ for sub-pixel accuracy [S1][S2, unofficial].
    $$ t_{new} = t_{old} - \frac{f(\mathbf{p}(t_{old})) - \tau}{\nabla f(\mathbf{p}(t_{old})) \cdot \mathbf{d}} $$
    Repeat for `newton_iter` iterations [S2, unofficial].
7.  **Normal Computation:** Compute surface normal $\mathbf{n}$ at the hit position $\mathbf{p}_{hit}$ [S2, unofficial].
    *   If $f$ provides analytic gradient: $\mathbf{n} = \nabla f(\mathbf{p}_{hit})$ [S2, unofficial].
    *   Else, use centered finite differences with step $h=10^{-5}$:
        $$ \mathbf{n} = \frac{1}{2h} \begin{bmatrix} f(\mathbf{p}+h\mathbf{x}) - f(\mathbf{p}-h\mathbf{x}) \\ f(\mathbf{p}+h\mathbf{y}) - f(\mathbf{p}-h\mathbf{y}) \\ f(\mathbf{p}+h\mathbf{z}) - f(\mathbf{p}-h\mathbf{z}) \end{bmatrix} $$
        Normalize $\mathbf{n}$, clamping norm to $\ge 10^{-12}$ to prevent division by zero [S2, unofficial].
8.  **Shading:** Compute color using Phong model with ambient, diffuse, and specular components. Cast shadow ray to light source [S1].
9.  **Compositing:** Blend surface color onto output buffer using forward compositing. Continue raycasting until early ray termination threshold is reached [S1].

**Pseudocode:**

```python
import numpy as np

def ray_aabb_intersect(origins, directions, aabb_lo, aabb_hi):
    """Standard slab method for ray-AABB intersection."""
    directions = np.where(directions == 0, 1e-12, directions)
    t1 = (aabb_lo - origins) / directions
    t2 = (aabb_hi - origins) / directions
    t_enter = np.maximum(t1, t2).min(axis=1)
    t_exit = np.minimum(t1, t2).max(axis=1)
    t_min = np.maximum(t_enter, 0.0)
    t_max = np.minimum(t_exit, np.inf)
    hit_mask = t_min <= t_max
    return t_min, t_max, hit_mask

def centered_difference_normals(f, pos, h=1e-5):
    """Compute surface normals via centered difference."""
    N = pos.shape[0]
    offsets = np.array([[h, 0, 0], [-h, 0, 0], [0, h, 0], [0, -h, 0], [0, 0, h], [0, 0, -h]], dtype=pos.dtype)
    all_points = (pos[None, :, :] + offsets[:, None, :]).reshape(6 * N, 3)
    all_vals, _ = f(all_points)
    v = all_vals.reshape(6, N)
    grad_x = (v[0] - v[1]) / (2.0 * h)
    grad_y = (v[2] - v[3]) / (2.0 * h)
    grad_z = (v[4] - v[5]) / (2.0 * h)
    normals = np.stack([grad_x, grad_y, grad_z], axis=1)
    norms = np.linalg.norm(normals, axis=1, keepdims=True)
    norms = np.maximum(norms, 1e-12)
    return normals / norms

def estimate_lipschitz(f, bounds, n_samples=10000, safety=1.5, h=1e-5):
    """Estimate Lipschitz constant over bounding box."""
    lo, hi = bounds
    rng = np.random.default_rng()
    pts = rng.uniform(lo, hi, (n_samples, 3))
    vals, grads = f(pts)
    if grads is not None:
        grad_norms = np.linalg.norm(grads, axis=1)
    else:
        offsets = np.array([[h, 0, 0], [-h, 0, 0], [0, h, 0], [0, -h, 0], [0, 0, h], [0, 0, -h]], dtype=np.float64)
        all_points = (pts[None, :, :] + offsets[:, None, :]).reshape(6 * n_samples, 3)
        all_vals, _ = f(all_points)
        v = all_vals.reshape(6, n_samples)
        gx = (v[0] - v[1]) / (2.0 * h)
        gy = (v[2] - v[3]) / (2.0 * h)
        gz = (v[4] - v[5]) / (2.0 * h)
        grad_norms = np.sqrt(gx**2 + gy**2 + gz**2)
    return float(grad_norms.max() * safety)

def bisect_trace(f, origins, directions, t_min, t_max, tau, coarse_step=0.01, max_iter=30):
    """Coarse traversal followed by bisection search for isosurface intersection."""
    # Coarse traversal
    t = t_min.copy()
    positions = origins + t[:, None] * directions
    vals, _ = f(positions)
    while np.any(vals < tau) & np.any(t < t_max):
        t = np.minimum(t + coarse_step, t_max)
        positions = origins + t[:, None] * directions
        vals, _ = f(positions)
    
    # Bisection search on the interval where crossing occurred
    t_start = t_min.copy()
    t_end = t.copy()
    for _ in range(max_iter):
        t_mid = (t_start + t_end) / 2.0
        positions = origins + t_mid[:, None] * directions
        vals, _ = f(positions)
        inside = vals >= tau
        t_start[inside] = t_mid[inside]
        t_end[~inside] = t_mid[~inside]
    return t_mid

def newton_refine(f, origins, directions, t, tau, iterations):
    """Refine intersection parameter t using Newton's method."""
    for _ in range(iterations):
        positions = origins + t[:, None] * directions
        vals, grads = f(positions)
        d_val_dt = np.sum(grads * directions, axis=1)
        d_val_dt = np.maximum(np.abs(d_val_dt), 1e-12) * np.sign(d_val_dt)
        t = t - (vals - tau) / d_val_dt
    return t

def shade_phong(normals, hit, light_dir, view_dir, ambient, diffuse_color, specular_color, shininess):
    """Simple Phong shading."""
    color = np.zeros_like(ambient)
    if not hit.any():
        return color
    n = normals[hit]
    l = light_dir[hit]
    v = view_dir[hit]
    r = 2.0 * np.sum(n * l, axis=1, keepdims=True) * n - l
    diff = np.maximum(np.sum(n * l, axis=1), 0.0)
    spec = np.maximum(np.sum(r * v, axis=1), 0.0) ** shininess
    color[hit] = ambient + diff * diffuse_color + spec * specular_color
    return np.clip(color, 0.0, 1.0)

def robust_isosurface_render(
    f, bounds, origins, directions, tau,
    newton_iter=3, margin=0.01, lipschitz='auto',
    safety=1.5, n_samples=10000, ambient=0.2, diffuse_color=np.array([1.0, 1.0, 1.0]),
    specular_color=np.array([0.5, 0.5, 0.5]), shininess=32.0
):
    lo, hi = bounds
    margin_vec = (hi - lo) * margin
    aabb_lo = lo - margin_vec
    aabb_hi = hi + margin_vec
    
    t_min, t_max, hit_mask = ray_aabb_intersect(origins, directions, aabb_lo, aabb_hi)
    
    if lipschitz == 'auto':
        L = estimate_lipschitz(f, bounds, n_samples, safety)
    else:
        L = lipschitz
        
    t_hit = bisect_trace(f, origins, directions, t_min, t_max, tau)
    
    if newton_iter > 0:
        t_hit = newton_refine(f, origins, directions, t_hit, tau, newton_iter)
        
    normals = np.zeros_like(origins)
    valid_hits = np.isfinite(t_hit) & hit_mask
    
    if valid_hits.any():
        hit_positions = origins[valid_hits] + t_hit[valid_hits, None] * directions[valid_hits]
        vals, grads = f(hit_positions)
        if grads is None:
            grads = centered_difference_normals(f, hit_positions)
        norms = np.linalg.norm(grads, axis=1, keepdims=True)
        norms = np.maximum(norms, 1e-12)
        normals[valid_hits] = grads / norms
        
    light_dir = np.array([0.0, 0.0, -1.0])
    view_dir = np.array([0.0, 0.0, 1.0])
    color = shade_phong(normals, valid_hits, light_dir, view_dir, ambient, diffuse_color, specular_color, shininess)
    
    return t_hit, normals, valid_hits, color
```

## Subtopics

### [Newton Refinement](1346-newton-refinement.md)
An optional post-processing step applied after the bisection phase to achieve sub-pixel hit-point accuracy by iteratively correcting the position using directional derivatives.

## Operating characteristics
*   **Time Complexity:** Bisection is $O(\log(1/\epsilon))$ per ray for precision $\epsilon$ [G]. Newton refinement adds $O(k)$ where $k$ is the number of iterations [G]. Lipschitz estimation is $O(N)$ where $N$ is sample count [G].
*   **Memory Complexity:** $O(N)$ for storing ray data and results [G]. Affine arithmetic variants may require $O(K)$ per point for noise symbols [G].
*   **Performance:** Post-processing (bilateral solver) takes ~0.4s for $256^3$ and ~5.3s for $512^3$ on Intel i7-8700K [S1]. Rendering speed depends on ray count and refinement steps [G].
*   **Strengths:** Robust intersection detection; sub-pixel accuracy; handles complex implicit surfaces well [G].
*   **Limitations:** Requires differentiable or gradient-accessible functions for Newton refinement; Lipschitz estimation can be costly if done per-frame [G].
*   **When to use:** High-quality offline rendering or interactive annotation where precision is critical [S1].

## Background
This method originates from work on segmentation-based transfer function design, leveraging self-supervised vision transformers to generate similarity maps that are subsequently rendered using robust isosurface raycasting [S1]. The implementation details, including the bisection and Newton refinement pipeline, are documented in the `isoray` package [S2, unofficial].
