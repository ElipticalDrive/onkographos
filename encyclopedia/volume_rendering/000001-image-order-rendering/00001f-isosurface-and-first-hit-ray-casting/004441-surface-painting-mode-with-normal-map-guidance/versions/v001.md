# Surface Painting Mode with Normal Map Guidance

Also called: Auto-follow surface, MIDA-based Surface Painting, Surface Painting Mode

## Overview
Surface Painting Mode with Normal Map Guidance is an interactive volume rendering technique that allows users to paint volumetric envelopes (metaballs) directly on the visible surface of a volumetric object [S1, unofficial]. It solves the problem of manually positioning brush tips to follow complex 3D curvature by automatically overriding the brush's depth and orientation based on the underlying isosurface [S1, unofficial]. Unlike standard ray casting which renders the final image, this method generates auxiliary 2D buffers (position and normal maps) to guide the placement of new metaballs, ensuring they align with the object's geometry [S1, unofficial]. It distinguishes itself from sibling methods by integrating surface detection directly into the painting interaction loop rather than as a post-processing step [S1, unofficial].

## How it works
The method operates in two phases: an offline or background generation of surface guidance data, and an interactive painting phase where this data drives the brush behavior.

### Inputs and Outputs
**Inputs:**
*   Volumetric scalar field $V$.
*   Mouse cursor screen coordinates $(u, v)$.
*   Brush parameters: type (spherical/cylindrical), size, penetration depth, and orientation mode.

**Outputs:**
*   Updated metaball series defining the painted envelope.
*   2D Position Buffer $B_p$ and Normal Buffer $B_n$ (generated during surface detection).

### Data Structures
Two 2D buffers are allocated, corresponding to the screen resolution (width $W$, height $H$).
1.  **Position Buffer ($B_p$):** Stores the 3D world coordinates of the first surface hit for each pixel.
    *   Layout: Array of size $W \times H$.
    *   Element type: `vec3` (float32 x3).
    *   Value: $\mathbf{p}_{hit}$, the intersection point on the isosurface.
2.  **Normal Buffer ($B_n$):** Stores the surface normal at the hit point.
    *   Layout: Array of size $W \times H$.
    *   Element type: `vec3` (float32 x3).
    *   Value: $\mathbf{n}_{hit}$, the normalized gradient of the scalar field at $\mathbf{p}_{hit}$.

### Algorithm Steps

1.  **Surface Detection (Generation Shader):**
    For each pixel $(u, v)$ in the viewport:
    a.  Construct a ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ originating from the camera through $(u, v)$.
    b.  Perform MIDA ray casting [S1, unofficial] (see Parent: [Isosurface and first-hit ray casting](20-isosurface-and-first-hit-ray-casting.md)).
    c.  Sample the volume $V$ along the ray. Stop evaluation immediately upon encountering the first non-transparent voxel (isovalue crossing) [S1, unofficial].
    d.  **Refinement:** Apply a 5-step refinement routine to the detected intersection position [S1, unofficial].
        i.  Subdivide the current ray stepping size $\Delta t$ into smaller increments.
        ii. Probe the volume in both directions from the coarse hit position to find a more precise isosurface crossing.
    e.  Compute the surface normal $\mathbf{n}$ at the refined position using the gradient $\nabla V$ [S1, unofficial].
    f.  Store $\mathbf{p}_{hit}$ in $B_p[u][v]$ and $\mathbf{n}$ in $B_n[u][v]$.

2.  **Normal Map Filtering:**
    Apply a Gaussian blur convolution to $B_n$ to reduce noise caused by discrete voxel sampling [S1, unofficial].
    *   Kernel: Standard Gaussian kernel $K$.
    *   Operation: $B_n^{filtered}[u][v] = \sum_{i,j} K[i][j] \cdot B_n[u+i][v+j]$.
    *   This step mitigates abrupt orientation changes in superquadratic metaballs [S1, unofficial].

3.  **Interactive Painting:**
    When the user paints at screen position $(u, v)$:
    a.  Retrieve $\mathbf{p}_{target} = B_p[u][v]$ and $\mathbf{n}_{target} = B_n^{filtered}[u][v]$.
    b.  **Depth Override:** Set the brush tip's depth (Z-coordinate in view space or distance along ray) to match $\mathbf{p}_{target}$. This ensures the brush follows the object's surface [S1, unofficial].
    c.  **Orientation Override (Superquadratic Metaballs only):** Calculate a rotation matrix $R$ that aligns the metaball's principal axis with $\mathbf{n}_{target}$ [S1, unofficial].
    d.  **Brush Shape:**
        *   If **Cylindrical**: Orient the cylinder's axis perpendicular to $\mathbf{n}_{target}$ (tangent to the surface) [S1, unofficial].
        *   If **Spherical**: Use standard spherical placement.
    e.  **Penetration Depth:** Allow user-adjustable offset along the normal $\mathbf{n}_{target}$ to control how deeply the brush penetrates the surface [S1, unofficial].
    f.  Add the metaball to the envelope series. The metaball merges with existing ones based on proximity and field functions [S1, unofficial].

### Pseudocode

```python
def generate_surface_guidance_buffers(volume, camera, width, height):
    """
    Generates position and normal buffers by ray casting the volume.
    """
    pos_buffer = zeros((height, width, 3))
    norm_buffer = zeros((height, width, 3))
    
    for y in range(height):
        for x in range(width):
            # 1. Ray construction
            ray_origin, ray_dir = camera.get_ray(x, y)
            
            # 2. MIDA Ray Casting with early exit
            hit_pos = None
            hit_normal = None
            
            # Coarse traversal
            t = 0.0
            while t < max_distance:
                p = ray_origin + t * ray_dir
                val = volume.sample(p)
                
                if is_non_transparent(val):
                    hit_pos = p
                    break
                t += step_size
            
            if hit_pos is not None:
                # 3. 5-Step Refinement
                hit_pos = refine_isosurface(volume, hit_pos, ray_dir)
                
                # 4. Normal Computation
                hit_normal = compute_gradient_normal(volume, hit_pos)
                
                # 5. Store in buffers
                pos_buffer[y, x] = hit_pos
                norm_buffer[y, x] = hit_normal

    # 6. Gaussian Filtering on Normal Buffer
    filtered_norm_buffer = gaussian_blur(norm_buffer, kernel_size=5)
    
    return pos_buffer, filtered_norm_buffer

def refine_isosurface(volume, coarse_pos, ray_dir):
    """
    5-step refinement routine.
    Subdivides stepping size and probes in both directions.
    """
    current_pos = coarse_pos
    step = initial_step_size
    
    for step_num in range(5):
        step /= 2.0
        # Probe in both directions to find finer crossing
        # Note: Specific bisection logic depends on parent MIDA implementation
        # Here we assume a local search around current_pos
        new_pos = local_search(volume, current_pos, step, ray_dir)
        if new_pos is not None:
            current_pos = new_pos
        else:
            break
            
    return current_pos

def paint_metaball(mouse_x, mouse_y, pos_buffer, norm_buffer, brush_params):
    """
    Places a metaball guided by the surface buffers.
    """
    # Retrieve guidance data
    target_pos = pos_buffer[mouse_y, mouse_x]
    target_normal = norm_buffer[mouse_y, mouse_x]
    
    # Override depth
    brush_depth = target_pos
    
    # Determine orientation
    if brush_params.type == "superquadratic":
        # Calculate rotation matrix aligning metaball axis with normal
        rotation_matrix = align_to_vector(target_normal)
        brush_orientation = rotation_matrix
    elif brush_params.type == "cylindrical":
        # Cylinder axis perpendicular to surface normal
        brush_orientation = perpendicular_to(target_normal)
    else:
        brush_orientation = identity_matrix()
        
    # Apply penetration depth offset
    final_pos = target_pos + (target_normal * brush_params.penetration_depth)
    
    # Add metaball to scene
    add_metaball(final_pos, brush_params.size, brush_orientation)
```

### Parameters
*   **Refinement Steps:** Fixed at 5 steps [S1, unofficial].
*   **Gaussian Kernel:** Applied to normal map; size not specified, but standard convolution is used [S1, unofficial].
*   **Brush Shape:** Spherical or Cylindrical [S1, unofficial].
*   **Penetration Depth:** User-adjustable scalar offset along the normal [S1, unofficial].

### Edge Cases and Pitfalls
*   **Normal Noise:** Volumetric datasets produce noisy normal maps, causing abrupt orientation changes in superquadratic metaballs [S1, unofficial]. Mitigated by 5-step refinement and Gaussian blurring [S1, unofficial].
*   **Transparent Voxels:** The algorithm stops at the *first* non-transparent voxel. If the volume has internal structures, only the outermost surface is captured [S1, unofficial].
*   **Missing Surface Data:** If the ray does not hit the volume (e.g., background pixels), the buffers may contain undefined values. Implementation should handle these as "no paint" or use default values [G].

## Subtopics

### MIDA Ray Casting
The underlying traversal algorithm used for surface detection. It is optimized for early exit upon first hit. See [MIDA Ray Casting](link-if-available).

### Metaball Envelopes
The geometric primitive used for painting. Metaballs merge based on field functions, allowing smooth envelope creation. See [Metaball Volume Representation](link-if-available).

## Operating characteristics
*   **Time Complexity:** $O(W \cdot H \cdot S)$ for buffer generation, where $W, H$ are screen dimensions and $S$ is the average number of samples per ray. Painting is $O(1)$ per brush stroke after buffer generation.
*   **Memory Complexity:** $O(W \cdot H)$ for storing position and normal buffers. For 1920x1080 resolution, this is approximately $1920 \times 1080 \times 24$ bytes $\approx 40$ MB for both buffers combined.
*   **Performance:** The method requires a full pass over the screen to generate buffers, which can be expensive if done every frame. It is typically used in interactive modes where buffers are updated only when the view or volume changes [S1, unofficial].
*   **Strengths:** Provides intuitive surface-following painting; eliminates manual depth adjustment; supports complex orientations via normals.
*   **Limitations:** Noisy normals require filtering; only captures the first surface; performance cost of buffer generation.

## Background
The method was introduced by [S1, unofficial] in the context of context-preserving volume image exploration using a 3D painting metaphor. It was designed to allow users to create envelopes around specific features of volumetric objects (e.g., bone vs. brain matter) by painting directly on the surface. The implementation relies on Transform Feedback to reuse vertex arrays for rendering the envelope without recalculating geometry [S1, unofficial].
