# Active Cell Filtering

Also called: Optimization 2, Value Range Filtering

## Overview
Active Cell Filtering is a pre-processing optimization for hybrid implicit isosurface ray tracing that reduces the number of geometric primitives generated for rendering. It solves the problem of unnecessary computation by discarding input cells whose value ranges (and those of their neighbors) do not overlap with the user-specified isovalue [S1]. Unlike sibling methods such as Dual Cell Optimization, which changes the geometry type used for extraction, Active Cell Filtering operates by pruning the set of candidate cells before any primitive construction occurs [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A tree-based adaptive mesh refinement (TB-AMR) dataset (e.g., cell-centered data), an octree structure storing value ranges at inner nodes, and a scalar isovalue $v_{iso}$.
*   **Output:** A subset of "active" input cells eligible for primitive extraction (octants or dual cells) [S1].

**Data Structures:**
*   **Octree:** Each node $N_i$ stores a value range $[min_i, max_i]$ representing the minimum and maximum scalar values found in the subtree rooted at $N_i$ [S1].
*   **Input Cells:** Each cell $C$ has an associated value range $[min_C, max_C]$ [S1].

**Algorithm:**
The method determines if an input cell $C$ is "active" by traversing the octree from the root. A cell is active if the union of its own value range and the value ranges of its neighboring cells contains the isovalue [S1].

1.  **Traverse Octree:** Start at the root of the octree.
2.  **Prune Inner Nodes:** For any inner node $N_i$, check if the isovalue $v_{iso}$ lies within its stored range $[min_i, max_i]$.
    *   If $v_{iso} \notin [min_i, max_i]$, terminate traversal for this branch. None of the descendants (including neighbors of $C$) can contain the isovalue [S1].
    *   If $v_{iso} \in [min_i, max_i]$, continue traversal to children [S1].
3.  **Check Neighbors:** For the target cell $C$, identify its neighbors. In the context of the octree traversal, this involves checking if any neighbor's value range (stored in the leaf or derived from the tree structure) overlaps with $v_{iso}$ when unioned with $C$'s range [S1].
4.  **Determine Activity:** Return `true` (active) if any neighbor of $C$ is found whose value range, unioned with $C$'s value range, contains $v_{iso}$. Otherwise, return `false` [S1].

**Pseudocode:**
The following Python-like pseudocode implements the filtering logic. It assumes an `Octree` class with `min_val` and `max_val` attributes for nodes, and a method to retrieve neighbor ranges.

```python
def is_cell_active(cell_C, isovalue, octree_root):
    """
    Determines if cell C is active by checking if its value range
    unioned with any neighbor's range contains the isovalue.
    Uses octree pruning for efficiency.
    """
    # Get value range of the cell itself
    min_c, max_c = get_cell_value_range(cell_C)
    
    # If the cell's own range doesn't contain isovalue, 
    # we must check neighbors. If it does, it is active.
    if min_c <= isovalue <= max_c:
        return True

    # Traverse octree to find neighbors and check their ranges
    # We need to find all neighbors of cell_C in the tree structure.
    # For efficiency, we prune branches that cannot contain the isovalue.
    
    neighbors = get_neighbors_in_octree(cell_C, octree_root, isovalue)
    
    for neighbor in neighbors:
        min_n, max_n = get_neighbor_value_range(neighbor)
        # Check if the union of cell_C and neighbor contains isovalue
        # Union range is [min(min_c, min_n), max(max_c, max_n)]
        union_min = min(min_c, min_n)
        union_max = max(max_c, max_n)
        
        if union_min <= isovalue <= union_max:
            return True
            
    return False

def get_neighbors_in_octree(cell_C, node, isovalue):
    """
    Recursively finds neighbors of cell_C, pruning branches where
    the node's value range does not contain isovalue.
    """
    # Pruning step: if node's range doesn't contain isovalue, stop
    if not (node.min_val <= isovalue <= node.max_val):
        return []
    
    # If leaf node, check if it is a neighbor of cell_C
    if node.is_leaf():
        if is_neighbor(node.cell, cell_C):
            return [node.cell]
        else:
            return []
    
    # Recurse into children
    neighbors = []
    for child in node.children:
        neighbors.extend(get_neighbors_in_octree(cell_C, child, isovalue))
        
    return neighbors
```

**Parameters and Edge Cases:**
*   **Isovalue:** The scalar threshold defining the isosurface.
*   **Precision:** Floating-point comparisons for range inclusion must handle edge cases where $v_{iso}$ equals exactly $min$ or $max$. The sources use inclusive bounds ($\leq$) [S1].
*   **Boundary Cells:** Cells on the domain boundary have fewer neighbors. The logic remains valid as it only checks existing neighbors [S1].

## Operating characteristics
*   **Performance:** The optimization significantly reduces extraction time for sparse isosurfaces. On the Meteor-20060 dataset (158M cells, 1.44% active), extraction time drops from 114.08s (Naive) to 6.68s [S1]. On the ExaJet dataset (656M cells, 0.83% active), it drops from 505.96s to 19.13s [S1].
*   **Complexity:** The complexity depends on the sparsity of the isosurface and the depth of the octree. In the worst case (dense isosurface), it may traverse most of the tree, but the pruning step provides significant speedup for sparse cases [S1].
*   **Strengths:** Reduces the number of primitives generated, directly lowering the workload for the subsequent ray-tracing step.
*   **Limitations:** Requires an octree structure with pre-computed value ranges at inner nodes. Not applicable to uniform grids without such a structure [S1].

## Background
Active Cell Filtering was introduced as "Optimization 2" in the context of hybrid implicit isosurface ray tracing for TB-AMR data [S1]. It was developed to address the inefficiency of naively tiling the entire domain with octants or dual cells, where many primitives would not intersect the isosurface [S1]. The method leverages the hierarchical nature of AMR data to skip irrelevant regions early [S1].
