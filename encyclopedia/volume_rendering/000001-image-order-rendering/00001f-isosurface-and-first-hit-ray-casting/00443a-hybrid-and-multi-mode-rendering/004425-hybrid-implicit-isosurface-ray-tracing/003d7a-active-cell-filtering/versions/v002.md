# Active Cell Filtering

Also called: Optimization 2, Value Range Filtering

## Overview
Active Cell Filtering is a pre-processing optimization for hybrid implicit isosurface ray tracing that reduces the number of geometric primitives generated for rendering [S1]. It solves the problem of unnecessary computation by discarding input cells whose value ranges (and those of their neighbors) do not overlap with the user-specified isovalue [S1]. Unlike sibling methods such as Dual Cell Optimization, which changes the geometry type used for extraction, Active Cell Filtering operates by pruning the set of candidate cells before any primitive construction occurs [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A tree-based adaptive mesh refinement (TB-AMR) dataset, an octree structure storing value ranges at inner nodes, and a scalar isovalue $v_{\text{iso}}$ [S1].
*   **Output:** A subset of active input cells eligible for primitive extraction (octants or dual cells) [S1].

**Data Structures:**
*   **Octree:** Each node $N_i$ stores a value range $[min_i, max_i]$ used to check if the input cell $C$ and its neighboring cells contain the isovalue [S1].
*   **Input Cells:** Each cell $C$ has an associated value range $[min_C, max_C]$ [S1].

**Algorithm:**
The method determines if an input cell $C$ is "active" by traversing the octree from the root [S1]. A cell is active if the union of its own value range and the value ranges of its neighboring cells contains the isovalue [S1].

1.  **Traverse Octree:** Start at the root of the octree [S1].
2.  **Prune Inner Nodes:** For any inner node $N_i$, check if the isovalue $v_{\text{iso}}$ lies within its stored range $[min_i, max_i]$ [S1]. If $v_{\text{iso}} \notin [min_i, max_i]$, terminate traversal for this branch because the children cannot contain the isovalue [S1]. If $v_{\text{iso}} \in [min_i, max_i]$, continue traversal to children [S1].
3.  **Check Neighbors:** For the target cell $C$, identify its neighbors [S1]. In the context of the octree traversal, this involves checking if any neighbor's value range overlaps with $v_{\text{iso}}$ when unioned with $C$'s range [S1].
4.  **Determine Activity:** Return `true` (active) if any neighbor of $C$ is found whose value range, unioned with $C$'s value range, contains $v_{\text{iso}}$ [S1]. Otherwise, return `false` [S1].

**Pseudocode:**
The following Python-like pseudocode implements the filtering logic [S1].

```python
def is_cell_active(cell_C, isovalue, octree_root):
    """Determines if cell C is active by checking if its value range
    unioned with any neighbor's range contains the isovalue."""
    min_c, max_c = get_cell_value_range(cell_C)
    if min_c <= isovalue <= max_c:
        return True
    return traverse_octree(cell_C, min_c, max_c, isovalue, octree_root)

def traverse_octree(cell_C, min_c, max_c, isovalue, node):
    """Recursively traverses the octree, pruning branches that cannot contain the isovalue."""
    if not (node.min_val <= isovalue <= node.max_val):
        return False
    if node.is_leaf():
        return check_neighbor_union(cell_C, min_c, max_c, isovalue, node)
    for child in node.children:
        if traverse_octree(cell_C, min_c, max_c, isovalue, child):
            return True
    return False

def get_cell_value_range(cell):
    """Returns the minimum and maximum scalar values of a cell."""
    return cell.min_val, cell.max_val

def check_neighbor_union(cell_C, min_c, max_c, isovalue, node):
    """Checks if the union of cell_C's range and a neighbor's range contains the isovalue."""
    min_n, max_n = get_cell_value_range(node.cell)
    union_min = min(min_c, min_n)
    union_max = max(max_c, max_n)
    return union_min <= isovalue <= union_max
```

**Parameters and Edge Cases:**
*   **Isovalue:** The scalar threshold defining the isosurface [S1].
*   **Precision:** Floating-point comparisons for range inclusion must handle edge cases where $v_{\text{iso}}$ equals exactly $min$ or $max$ [G].
*   **Boundary Cells:** Cells on the domain boundary have fewer neighbors, but the logic remains valid as it only checks existing neighbors [S1].

## Operating characteristics
*   **Performance:** The optimization significantly reduces extraction time for sparse isosurfaces [S1]. On the Meteor-20060 dataset (158M cells, 1.44% active), extraction time drops from 114.08s (Naive) to 6.68s [S1]. On the ExaJet dataset (656M cells, 0.83% active), it drops from 505.96s to 19.13s [S1].
*   **Complexity:** The complexity depends on the sparsity of the isosurface and the depth of the octree [G].
*   **Strengths:** Reduces the number of primitives generated, directly lowering the workload for the subsequent ray-tracing step [S1].
*   **Limitations:** Requires an octree structure with pre-computed value ranges at inner nodes [S1].

## Background
Active Cell Filtering was introduced as "Optimization 2" in the context of hybrid implicit isosurface ray tracing for TB-AMR data [S1]. It was developed to address the inefficiency of naively tiling the entire domain with octants or dual cells, where many primitives would not intersect the isosurface [S1]. The method leverages the hierarchical nature of AMR data to skip irrelevant regions early [S1].
