# Hybrid Implicit Isosurface Ray Tracing

Also called: Hybrid Isosurface Method

## Overview
Hybrid Implicit Isosurface Ray Tracing is a method for rendering high-quality, crack-free isosurfaces from rectilinear volumes (including AMR) by combining explicit voxel selection with implicit ray-marching. It extracts a list of active voxels, builds a BVH over them, and performs implicit ray-isosurface intersections within each voxel without extracting polygons [S1, unofficial]. It sets itself apart from pure sample-based methods by avoiding fixed step-sizes that miss features in refined regions, and from pure explicit extraction by deferring polygon generation until the final shading stage, allowing for exact implicit intersection [S1, unofficial].

## How it works
**Inputs:**
*   A rectilinear volume (structured grid, rectilinear grid, or BS-AMR) [S1, unofficial].
*   An isovalue $I$ [S1, unofficial].
*   A ray packet $\mathbf{r}_i(t) = \mathbf{O}_i + t\mathbf{D}_i$ [S1, unofficial].

**Outputs:**
*   Intersection points $t$ for each ray in the packet.
*   Surface normals (computed via gradient of the scalar field at the intersection point) [G].

**Data Structures:**
1.  **Voxel Abstraction:** A logical voxel is defined as a cube with trilinearly interpolated scalar values at its vertices [S1, unofficial].
    *   For regular grids: Described by 12 values:
        *   3 floats: 3D coordinates of the voxel origin.
        *   1 float: Width (assuming uniform height/depth or derived from grid structure).
        *   8 floats: Scalar values at the 8 vertices.
    *   For general rectilinear volumes: 2 additional floats for height and depth [S1, unofficial].
2.  **Active Voxel Reference:** Active voxels are encoded into a single 64-bit integer. The source uses a 21:21:21 bit split for coordinates, though this is specific to the implementation's coordinate range [S1, unofficial].
3.  **VoxelSource:** An entity that generates a list of active voxels and provides bounding boxes and full voxel data given a 64-bit reference [S1, unofficial].
4.  **BVH:** Built using Embree, containing one primitive per active voxel [S1, unofficial].

**Steps:**
1.  **Active Voxel Extraction:** Use the `VoxelSource` to identify all active voxels (those whose value range contains the isovalue $I$). Store a 64-bit reference for each [S1, unofficial].
2.  **BVH Construction:** Create an Embree "user geometry" with one primitive per active voxel. Implement a `getBounds` callback that queries the `VoxelSource` for the voxel's bounding box using the 64-bit reference. Use Embree to build the BVH [S1, unofficial].
3.  **Ray Traversal:** Traverse rays through the BVH. For each ray packet (4-, 8-, or 16-wide), identify candidate voxels [S1, unofficial].
4.  **Implicit Intersection:** For each candidate voxel, query the full voxel data from the `VoxelSource` using the 64-bit reference. Perform an implicit ray-isosurface intersection within the voxel using the Marmitt et al. algorithm [S1, unofficial].
    *   The Marmitt et al. algorithm solves for the intersection of a ray with the trilinearly interpolated isosurface within a voxel [S1, unofficial].
    *   This involves solving a cubic equation derived from the trilinear interpolation model [G].
5.  **Hit Selection:** Select the smallest positive $t$ within the voxel bounds as the intersection point [S1, unofficial].

**Pseudocode:**
```python
def hybrid_isosurface_trace(ray_packet, voxel_source, isovalue):
    # Step 1: Get active voxels
    active_voxel_refs = voxel_source.get_active_voxels(isovalue)
    
    # Step 2: Build BVH (conceptual, using Embree API)
    # In practice, this is done once per frame or when volume changes
    bvh = build_embree_bvh(active_voxel_refs, voxel_source)
    
    # Step 3: Traverse and Intersect
    intersections = []
    for ray in ray_packet:
        t_hit = infinity
        hit_voxel = None
        
        # Traverse BVH
        candidates = bvh.traverse(ray)
        
        for voxel_ref in candidates:
            # Query voxel data
            voxel = voxel_source.get_voxel(voxel_ref)
            
            # Perform implicit intersection (Marmitt et al.)
            t = intersect_ray_iso_voxel(ray, voxel, isovalue)
            
            if t is not None and 0 < t < t_hit:
                t_hit = t
                hit_voxel = voxel
                
        if t_hit != infinity:
            intersections.append((ray, t_hit, hit_voxel))
            
    return intersections

def intersect_ray_iso_voxel(ray, voxel, isovalue):
    # Marmitt et al. algorithm for trilinear interpolation
    # This is a simplified representation; the actual implementation
    # solves a cubic equation for the root.
    # Inputs: ray (O, D), voxel (8 vertex values, 8 vertex positions), isovalue
    # Output: t or None
    
    # 1. Check if isovalue is within the range of voxel vertex values
    min_val = min(voxel.vertex_values)
    max_val = max(voxel.vertex_values)
    if not (min_val <= isovalue <= max_val):
        return None
        
    # 2. Solve for t using the trilinear interpolation model
    # f(O + t*D) = isovalue
    # This results in a cubic equation: a*t^3 + b*t^2 + c*t + d = 0
    # Coefficients a, b, c, d are derived from the 8 vertex values and positions
    # [G] Implementation detail: The cubic equation is solved using Cardano's method
    # or a numerical solver, and only real roots within [0, voxel_depth] are considered.
    
    roots = solve_cubic_trilinear(ray, voxel, isovalue)
    
    # 3. Return the smallest positive root within the voxel
    valid_roots = [t for t in roots if 0 < t < voxel.depth]
    if valid_roots:
        return min(valid_roots)
    return None
```

**Parameters:**
*   Ray packet size: 4, 8, or 16 rays [S1, unofficial].
*   Isosurface value: User-defined [S1, unofficial].

**Edge Cases:**
*   **Refined Regions:** Sample-based methods fail here due to fixed step sizes; this method handles them by using the voxel's internal structure [S1, unofficial].
*   **Empty Space:** The BVH and active voxel filtering skip empty space efficiently [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Depends on BVH traversal and the cost of implicit intersection per voxel. BVH traversal is $O(\log N)$ where $N$ is the number of active voxels. Implicit intersection is constant time per voxel (solving a cubic) [S1, unofficial].
*   **Memory Complexity:** Proportional to the number of active voxels, as each active voxel is a primitive in the BVH [S1, unofficial].
*   **Performance:** Yields better framerates than sample-based methods for refined regions and higher quality than sample-based methods [S1, unofficial].
*   **Strengths:** High-quality, crack-free isosurfaces; handles AMR data well; avoids polygon extraction overhead [S1, unofficial].
*   **Limitations:** Requires building a BVH per frame or when volume changes; ISPC implementation may be wasteful if ray packets are small relative to voxel count [S1, unofficial].
*   **When to use:** When high-quality isosurfaces from AMR or rectilinear volumes are needed, and polygon extraction is undesirable or too costly [S1, unofficial].
*   **When not to use:** For simple regular grids where explicit extraction (e.g., Marching Cubes) is sufficient and faster [S1, unofficial].

## Background
The method was introduced by Feng et al. in 2018 as part of the OSPRay project [S1, unofficial]. It integrates with OSPRay's existing AMR volume structures and uses Embree for BVH construction and traversal [S1, unofficial]. It addresses the limitations of OSPRay's built-in sample-based isosurface method, which misses surfaces and loses detail in refined regions [S1, unofficial].
