# Opacity Peeling
## Overview
Opacity peeling is an interaction technique used to reveal interior hidden spatial structures within a volume by selectively discarding or modifying the opacity of surface layers along the viewing ray [S1]. It serves as a specific implementation of surface peeling, differing from general surface peeling by focusing on the attenuation of ray-marched contributions rather than explicit geometric intersection skipping [S1]. While surface peeling explicitly skips the first $N$ intersection points, opacity peeling typically achieves the "peeling" effect by adjusting the transfer function or compositing weights to ignore the outermost layers, thereby exposing deeper structures without requiring explicit geometric primitives [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D volume dataset $V$, a camera view (position, orientation, field of view), and a peeling parameter $k$ (number of layers to remove) or a threshold $\tau$ for opacity/depth [S1].
*   **Output:** A 2D image where the outermost $k$ layers of visible geometry are suppressed, revealing internal structures [S1].

**Data Structures:**
*   **Volume Data:** A 3D grid of scalar values (e.g., density, intensity).
*   **Ray Buffer:** For each pixel, a list of intersection points or sampled intervals along the ray. In image-order rendering, this is often implicit within the ray-marching loop.
*   **Peeling State:** A counter or mask indicating which ray samples correspond to the "peeled" layers [S1].

**Method Steps:**
1.  **Ray Casting:** For each pixel in the image plane, cast a ray into the volume.
2.  **Sampling:** Sample the volume along the ray at regular intervals or adaptive steps.
3.  **Layer Identification:** Determine the order of visible surfaces or density peaks along the ray. The first $k$ significant contributions are identified as the "outer" layers [S1].
4.  **Opacity Modification:**
    *   *Approach A (Weight Suppression):* During front-to-back compositing, if the current sample index $i$ is less than $k$ (where $k$ is the peeling depth), set the transmittance or opacity contribution of that sample to zero.
    *   *Approach B (Transfer Function Shift):* Modify the transfer function $T(v)$ such that values corresponding to the outer surface are mapped to zero opacity. This may require pre-computing the surface location or using a depth-based threshold [S1].
5.  **Compositing:** Perform standard front-to-back alpha compositing for the remaining samples ($i \ge k$).
    $$ C = \sum_{i=k}^{N} T_i \alpha_i \prod_{j=0}^{i-1} (1 - \alpha_j) $$
    Where $T_i$ is the color, $\alpha_i$ is the opacity (modified to 0 for $i < k$), and $N$ is the total number of samples.
6.  **Display:** Render the resulting color $C$ to the pixel buffer.

**Parameters:**
*   $k$: Number of layers to peel. Typical values depend on volume resolution and desired visibility depth.
*   $\tau$: Threshold for surface detection, if used to define layers [S1].

**Edge Cases and Pitfalls:**
*   **Thin Structures:** If the volume contains thin internal structures, peeling too many layers may remove them entirely.
*   **Ambiguity in Layer Definition:** In non-isosurface volumes (e.g., diffuse clouds), defining "layers" is ambiguous. Opacity peeling often relies on density thresholds or pre-computed distance fields to define layers reliably [S1].
*   **Precision:** Floating-point precision in ray marching may cause jitter in the peeled boundary if not stabilized [G].

**Pseudocode:**
```python
def opacity_peeling(volume, camera, k):
    """
    Renders the volume with the outer k layers peeled away.
    volume: 3D array of scalar values
    camera: object with get_ray(x, y) method
    k: integer, number of layers to skip
    """
    image_width, image_height = volume.dimensions
    output_image = zeros((image_height, image_width, 3))

    for y in range(image_height):
        for x in range(image_width):
            ray = camera.get_ray(x, y)
            color = (0.0, 0.0, 0.0)
            transmittance = 1.0
            layer_count = 0

            # Ray march through volume
            for t in range(0, volume.max_depth, step_size):
                pos = ray.origin + t * ray.direction
                if not volume.contains(pos):
                    break
                
                value = volume.sample(pos)
                opacity = transfer_function(value)
                
                # Skip the first k layers
                if layer_count < k:
                    layer_count += 1
                    continue
                
                # Standard compositing for remaining layers
                contribution = opacity * transmittance
                color += contribution * color_from_value(value)
                transmittance *= (1.0 - opacity)
                
                if transmittance < epsilon:
                    break

            output_image[y, x] = color

    return output_image
```

## Subtopics

### [Brain Peeling](13890-brain-peeling.md)
A view-independent variant that uses a precomputed distance field to remove brain tissue layers, offering more reliable exploration of surface-adjacent features than view-dependent opacity peeling.

## Operating characteristics
*   **Time Complexity:** $O(W \cdot H \cdot N)$, where $W, H$ are image dimensions and $N$ is the number of samples per ray. Peeling adds negligible overhead to standard ray marching [S1].
*   **Memory Complexity:** $O(V)$ for volume storage, plus $O(1)$ per pixel for compositing state [S1].
*   **Strengths:** Efficient single-pass implementation; flexible; does not require explicit geometric mesh extraction [S1].
*   **Limitations:** Definition of "layers" can be ambiguous in non-isosurface data; view-dependent (in standard form) [S1].
*   **When to Use:** When exploring internal structures of a volume without explicit geometry is required, and performance is critical [S1].

## Background
Opacity peeling was introduced by Rezk-Salama and Kolb as a technique to partition volumes into segments for displaying hidden structural details [S1]. It is part of the broader family of surface peeling techniques used in volume visualization to enhance visibility of internal features [S1].
