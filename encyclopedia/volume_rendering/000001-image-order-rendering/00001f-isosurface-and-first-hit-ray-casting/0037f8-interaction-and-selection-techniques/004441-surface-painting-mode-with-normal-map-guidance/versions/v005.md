# Surface Painting Mode with Normal Map Guidance

Also called: Auto-follow surface, MIDA-based Surface Painting, Surface Painting Mode

## Overview
Surface Painting Mode with Normal Map Guidance is an interactive volume rendering technique that allows users to paint volumetric envelopes (metaballs) directly on the visible surface of a volumetric object [S1, unofficial]. It solves the problem of manually positioning brush tips to follow complex 3D curvature by automatically overriding the brush's depth and orientation based on the underlying isosurface [S1, unofficial]. Unlike standard ray casting which renders the final image, this method generates auxiliary 2D buffers (position and normal maps) to guide the placement of new metaballs, ensuring they align with the object's geometry [S1, unofficial]. It builds on [Isosurface and first-hit ray casting](20-isosurface-and-first-hit-ray-casting.md).

## How it works
### Inputs and Outputs
**Inputs:** Volumetric scalar field, camera parameters, mouse cursor screen coordinates $(u, v)$, and brush parameters (type, size, penetration depth) [S1, unofficial].
**Outputs:** Updated metaball series defining the painted envelope [S1, unofficial].

### Data Structures
Two 2D buffers are allocated, corresponding to the screen plane [S1, unofficial]. The Position Buffer stores the 3D world coordinates of the first surface hit for each pixel [S1, unofficial]. The Normal Buffer stores the surface normal at the hit point [S1, unofficial].

### Algorithm Steps
1. **Surface Detection:** For each pixel $(u, v)$, construct a ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ originating from the camera through $(u, v)$ [G]. Perform MIDA ray casting [S1, unofficial]. Sample the volume along the ray and stop evaluation immediately upon encountering the first non-transparent voxel [S1, unofficial]. Apply a 5-step refinement routine to the detected intersection position [S1, unofficial]. Subdivide the current ray stepping size into increasingly smaller values and probe the volume space in both directions from the current position to find a finer matching isosurface [S1, unofficial]. Compute the surface normal at the refined position [S1, unofficial]. Store the ray's position and the object's normal value in two separate 2D buffers corresponding to screen plane points [S1, unofficial].
2. **Normal Map Filtering:** Apply a convolution operation with a Gaussian blurring kernel to the normal map [S1, unofficial]. This step mitigates abrupt orientation changes in superquadratic metaballs [S1, unofficial].
3. **Interactive Painting:** When the user paints at screen position $(u, v)$, map the mouse cursor position to the corresponding pair of values in the 2D buffers to override the current brush tip's depth [S1, unofficial]. For superquadratic metaballs, use the direction of the normal at the current position to calculate the rotation matrix of the metaball [S1, unofficial]. A cylindrical brush tip orients itself perpendicular to the surface of the volumetric object [S1, unofficial]. The depth of the object’s surface penetration by the brush tip can be adjusted [S1, unofficial]. Add the metaball to the envelope series, where metaballs merge based on size, proximity, and field function [S1, unofficial].

import math

class Camera:
    def get_ray(self, x, y, width, height, fov=1.0):
        # [G] Standard perspective ray generation from screen coordinates
        ndc_x = (2.0 * x / width) - 1.0
        ndc_y = (2.0 * y / height) - 1.0
        origin = [0.0, 0.0, 5.0]
        direction = [ndc_x * fov, ndc_y * fov, -5.0]
        length = math.sqrt(sum(c*c for c in direction))
        return origin, [d/length for d in direction]

class Volume:
    def sample(self, p):
        # [G] Scalar field evaluation
        return 1.0 if 0.0 <= p[0] <= 1.0 and 0.0 <= p[1] <= 1.0 and 0.0 <= p[2] <= 1.0 else 0.0

class BrushParams:
    def __init__(self, type="spherical", size=1.0, penetration_depth=0.0):
        self.type = type
        self.size = size
        self.penetration_depth = penetration_depth

def generate_surface_guidance_buffers(volume, camera, width, height):
    """Generates position and normal buffers by ray casting the volume."""
    pos_buffer = [[None] * width for _ in range(height)]
    norm_buffer = [[None] * width for _ in range(height)]

    for y in range(height):
        for x in range(width):
            ray_origin, ray_dir = camera.get_ray(x, y, width, height)
            hit_pos = None
            hit_normal = None

            # Coarse traversal
            t = 0.0
            step_size = 0.1  # [G] Initial step size not given in sources
            max_distance = 100.0  # [G] Max distance not given in sources

            while t < max_distance:
                p = [ray_origin[i] + t * ray_dir[i] for i in range(3)]
                val = volume.sample(p)
                if val > 0.0:  # [G] Threshold for non-transparent voxel
                    hit_pos = p
                    break
                t += step_size

            if hit_pos is not None:
                # 5-Step Refinement
                hit_pos = refine_isosurface(volume, hit_pos, ray_dir, step_size)
                # Normal Computation
                hit_normal = compute_gradient_normal(volume, hit_pos)
                # Store in buffers
                pos_buffer[y][x] = hit_pos
                norm_buffer[y][x] = hit_normal

    # Gaussian Filtering on Normal Buffer
    filtered_norm_buffer = gaussian_blur(norm_buffer)
    return pos_buffer, filtered_norm_buffer

def refine_isosurface(volume, coarse_pos, ray_dir, initial_step_size):
    """5-step refinement routine. Subdivides stepping size and probes in both directions."""
    current_pos = list(coarse_pos)
    step = initial_step_size

    for _ in range(5):
        step /= 2.0
        # Probe in both directions from current position
        for direction in [1.0, -1.0]:
            probe_pos = [current_pos[i] + direction * step * ray_dir[i] for i in range(3)]
            if volume.sample(probe_pos) > 0.0:
                current_pos = probe_pos
                break
    return current_pos

def compute_gradient_normal(volume, pos):
    """Computes surface normal via central finite differences."""
    eps = 1e-4
    grad = [0.0, 0.0, 0.0]
    for i in range(3):
        p_plus = list(pos)
        p_minus = list(pos)
        p_plus[i] += eps
        p_minus[i] -= eps
        grad[i] = (volume.sample(p_plus) - volume.sample(p_minus)) / (2.0 * eps)
    norm = math.sqrt(sum(g*g for g in grad))
    if norm > 0:
        return [g / norm for g in grad]
    return [0.0, 0.0, 1.0]

def gaussian_blur(buffer, kernel_size=3):
    """Applies a 2D Gaussian convolution to the normal buffer."""
    # [G] Standard 3x3 Gaussian kernel approximation
    kernel = [[1.0/16.0, 2.0/16.0, 1.0/16.0],
              [2.0/16.0, 4.0/16.0, 2.0/16.0],
              [1.0/16.0, 2.0/16.0, 1.0/16.0]]
    filtered = [[None] * len(buffer[0]) for _ in range(len(buffer))]
    for y in range(len(buffer)):
        for x in range(len(buffer[0])):
            if buffer[y][x] is None:
                continue
            acc = [0.0, 0.0, 0.0]
            for ky in range(kernel_size):
                for kx in range(kernel_size):
                    ny = y + ky - 1
                    nx = x + kx - 1
                    if 0 <= ny < len(buffer) and 0 <= nx < len(buffer[0]) and buffer[ny][nx] is not None:
                        for c in range(3):
                            acc[c] += buffer[ny][nx][c] * kernel[ky][kx]
            filtered[y][x] = acc
    return filtered

def paint_metaball(mouse_x, mouse_y, pos_buffer, norm_buffer, brush_params):
    """Places a metaball guided by the surface buffers."""
    target_pos = pos_buffer[mouse_y][mouse_x]
    target_normal = norm_buffer[mouse_y][mouse_x]

    if target_pos is None or target_normal is None:
        return  # [G] Handle missing surface data

    # Override depth
    brush_depth = target_pos

    # Determine orientation
    if brush_params.type == "superquadratic":
        rotation_matrix = align_to_vector(target_normal)
        brush_orientation = rotation_matrix
    elif brush_params.type == "cylindrical":
        brush_orientation = perpendicular_to(target_normal)
    else:
        brush_orientation = [[1,0,0],[0,1,0],[0,0,1]]

    # Apply penetration depth offset
    final_pos = [target_pos[i] + target_normal[i] * brush_params.penetration_depth for i in range(3)]

    # Add metaball to scene
    add_metaball(final_pos, brush_params.size, brush_orientation)

def align_to_vector(normal):
    """Creates a rotation matrix aligning the Z-axis with the normal."""
    # [G] Standard basis alignment using Gram-Schmidt
    z = normal
    x = [1.0, 0.0, 0.0]
    if abs(z[0]) > 0.9:
        x = [0.0, 1.0, 0.0]
    x = [x[i] - sum(x[j]*z[j] for j in range(3))*z[i] for i in range(3)]
    x_len = math.sqrt(sum(c*c for c in x))
    x = [c/x_len for c in x]
    y = [x[1]*z[2]-x[2]*z[1], x[2]*z[0]-x[0]*z[2], x[0]*z[1]-x[1]*z[0]]
    return [x, y, z]

def perpendicular_to(normal):
    """Returns a vector perpendicular to the normal."""
    # [G] Cross product with arbitrary vector
    arbitrary = [1.0, 0.0, 0.0]
    if abs(normal[0]) > 0.9:
        arbitrary = [0.0, 1.0, 0.0]
    return [normal[1]*arbitrary[2]-normal[2]*arbitrary[1],
            normal[2]*arbitrary[0]-normal[0]*arbitrary[2],
            normal[0]*arbitrary[1]-normal[1]*arbitrary[0]]

### Parameters
*   **Refinement Steps:** Fixed at 5 steps [S1, unofficial].
*   **Gaussian Kernel:** Applied to normal map; size not specified, but standard convolution is used [S1, unofficial].
*   **Brush Shape:** Spherical or Cylindrical [S1, unofficial].
*   **Penetration Depth:** User-adjustable scalar offset along the normal [S1, unofficial].

### Edge Cases and Pitfalls
*   **Normal Noise:** Volumetric datasets produce noisy normal maps, causing abrupt orientation changes in superquadratic metaballs [S1, unofficial]. Mitigated by 5-step refinement and Gaussian blurring [S1, unofficial].
*   **Transparent Voxels:** The algorithm stops at the *first* non-transparent voxel [S1, unofficial]. If the volume has internal structures, only the outermost surface is captured [S1, unofficial].
*   **Missing Surface Data:** If the ray does not hit the volume (e.g., background pixels), the buffers may contain undefined values [S1, unofficial]. Implementation should handle these as "no paint" or use default values [G].

## Background
The method was introduced by [S1, unofficial] in the context of context-preserving volume image exploration using a 3D painting metaphor. It was designed to allow users to create envelopes around specific features of volumetric objects (e.g., bone vs. brain matter) by painting directly on the surface [S1, unofficial]. The implementation relies on Transform Feedback to reuse vertex arrays for rendering the envelope without recalculating geometry [S1, unofficial].
