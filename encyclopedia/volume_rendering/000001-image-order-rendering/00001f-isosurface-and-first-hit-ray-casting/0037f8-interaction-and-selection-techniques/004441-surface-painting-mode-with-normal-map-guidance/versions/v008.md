# Surface Painting Mode with Normal Map Guidance

Also called: Auto-follow surface, MIDA-based Surface Painting, Surface Painting Mode

## Overview
Surface Painting Mode is an interaction technique that allows users to paint volumetric envelopes by automatically overriding the brush tip's depth and orientation to match the underlying isosurface of a volumetric dataset [S1, unofficial]. It solves the problem of manually aligning brush geometry with complex, curved internal structures by using a pre-computed normal map derived from ray casting [S1, unofficial]. It differs from standard painting by decoupling the brush position from the surface geometry, and from clipping techniques by modifying the painted object's attributes rather than the view volume [S1, unofficial].

## How it works
The method relies on the principles of [Isosurface and first-hit ray casting](20-isosurface-and-first-hit-ray-casting.md) to generate surface metadata, which is then used to guide the brush transformation [G].

### Inputs and Outputs
*   **Inputs:**
    *   Volumetric dataset $V$ with scalar values [S1, unofficial].
    *   Mouse cursor screen coordinates $(u, v)$ [S1, unofficial].
    *   Brush parameters: type (spherical, cylindrical, superquadratic), size, height, and sign (positive/negative) [S1, unofficial].
    *   Isosurface threshold $\tau$ [S1, unofficial].
*   **Outputs:**
    *   Updated volumetric envelope (series of metaballs) aligned to the surface [S1, unofficial].
    *   Two 2D buffers: Position Buffer $B_P$ and Normal Buffer $B_N$ [S1, unofficial].

### Data Structures
*   **Position Buffer $B_P$:** A 2D array of size $W \times H$ (screen resolution) [S1, unofficial]. Each element stores the 3D world position $\mathbf{p} = (x, y, z)$ of the first-hit isosurface point corresponding to the screen pixel [S1, unofficial].
*   **Normal Buffer $B_N$:** A 2D array of size $W \times H$ [S1, unofficial]. Each element stores the 3D surface normal $\mathbf{n} = (n_x, n_y, n_z)$ at the corresponding hit point [S1, unofficial].
*   **Brush Tip:** Defined as a metaball [S1, unofficial]. For cylindrical brushes, the orientation is determined by the normal vector [S1, unofficial]. For superquadratic metaballs, the orientation matrix is derived from the normal [S1, unofficial].

### Algorithm Steps

1.  **Isosurface Generation (Buffer Population):**
    For each pixel $(u, v)$ in the screen resolution $W \times H$:
    a.  Construct a ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ from the camera through $(u, v)$ into the volume space [S1, unofficial].
    b.  Perform MIDA ray casting: Evaluate scalar values $V(\mathbf{r}(t))$ along the ray [S1, unofficial].
    c.  Stop evaluation immediately upon encountering the first non-transparent voxel (where $V(\mathbf{r}(t)) \geq \tau$) [S1, unofficial].
    d.  **Refinement:** Apply a 5-step isosurface refinement routine to the hit position $t_{hit}$ [S1, unofficial].
        i.  Subdivide the current ray stepping size into increasingly smaller values [S1, unofficial].
        ii. Probe the volume space in both directions from the current position along the ray to find a finer matching isosurface intersection $t_{final}$ [S1, unofficial].
    e.  Calculate the position $\mathbf{p} = \mathbf{r}(t_{final})$ [S1, unofficial].
    f.  Calculate the normal $\mathbf{n}$ at $\mathbf{p}$ using finite differences of the scalar field $V$ [G].
    g.  Store $\mathbf{p}$ in $B_P[u][v]$ and $\mathbf{n}$ in $B_N[u][v]$ [S1, unofficial].

2.  **Normal Map Filtering:**
    Apply a convolution operation with a Gaussian blurring kernel to the normal map to reduce noise caused by the discrete nature of the volumetric dataset [S1, unofficial]. This prevents abrupt orientation changes in superquadratic metaballs [S1, unofficial].

3.  **Brush Interaction:**
    When the user moves the mouse to $(u, v)$ and initiates a paint stroke:
    a.  Retrieve $\mathbf{p}_{surf} = B_P[u][v]$ and $\mathbf{n}_{surf} = B_N[u][v]$ [S1, unofficial].
    b.  **Depth Override:** Set the brush tip's depth (distance along the ray or z-coordinate in local space) to match $\mathbf{p}_{surf}$ [S1, unofficial]. This ensures the brush follows the object's surface [S1, unofficial].
    c.  **Orientation Override:**
        *   If the brush is **cylindrical**: Orient the cylinder's axis perpendicular to $\mathbf{n}_{surf}$ [S1, unofficial].
        *   If the brush is **superquadratic**: Calculate a rotation matrix $R$ using $\mathbf{n}_{surf}$ as the primary orientation axis, and apply it to the metaball [S1, unofficial].
    d.  **Penetration Depth:** Allow the user to adjust the depth of the object’s surface penetration by the brush tip, effectively controlling how deeply the brush intersects the surface [S1, unofficial].
    e.  Add the transformed metaball to the envelope series [S1, unofficial]. The brush tip is always the first metaball, defining the attributes (size, field function) for subsequent merged metaballs [S1, unofficial].

### Pseudocode

```python
def generate_surface_buffers(volume, camera, width, height, threshold):
    """
    Generates Position Buffer B_P and Normal Buffer B_N.
    """
    B_P = [[None] * height for _ in range(width)]
    B_N = [[None] * height for _ in range(width)]
    max_steps = 1000
    step_size = 1.0 / max_steps

    for v in range(height):
        for u in range(width):
            ray_origin, ray_direction = camera.screen_to_ray(u, v)
            t = 0.0
            hit_t = None

            # MIDA ray casting: stop at first non-transparent voxel
            for _ in range(max_steps):
                pos = ray_origin + t * ray_direction
                if volume.scalar(pos) < threshold:
                    t += step_size
                else:
                    hit_t = t
                    break

            if hit_t is None:
                continue

            # Refinement: 5 steps, subdivide step size, probe both directions
            current_t = hit_t
            refine_step = step_size
            for _ in range(5):
                refine_step /= 2.0
                for delta in [-refine_step, refine_step]:
                    probe_t = current_t + delta
                    if 0 <= probe_t <= 1.0:
                        probe_pos = ray_origin + probe_t * ray_direction
                        if volume.scalar(probe_pos) >= threshold:
                            current_t = probe_t
                            break

            # Position and normal
            p = ray_origin + current_t * ray_direction
            n = volume.normal(p)

            B_P[u][v] = p
            B_N[u][v] = n

    # Filtering: Gaussian blur on normal map
    B_N = gaussian_blur_normals(B_N)
    return B_P, B_N

def gaussian_blur_normals(normal_buffer, kernel_size=3):
    """Applies a 3x3 Gaussian kernel to reduce normal map noise [G]."""
    h = len(normal_buffer[0])
    w = len(normal_buffer)
    blurred = [[None] * h for _ in range(w)]
    # Standard 3x3 Gaussian weights normalized by 16
    weights = [[1, 2, 1], [2, 4, 2], [1, 2, 1]]
    half = kernel_size // 2
    for y in range(h):
        for x in range(w):
            sum_n = [0.0, 0.0, 0.0]
            weight_sum = 0
            for dy in range(-half, half + 1):
                for dx in range(-half, half + 1):
                    ny, nx = y + dy, x + dx
                    if 0 <= ny < h and 0 <= nx < w and normal_buffer[nx][ny] is not None:
                        w_val = weights[dy + half][dx + half]
                        sum_n[0] += normal_buffer[nx][ny][0] * w_val
                        sum_n[1] += normal_buffer[nx][ny][1] * w_val
                        sum_n[2] += normal_buffer[nx][ny][2] * w_val
                        weight_sum += w_val
            if weight_sum > 0:
                blurred[x][y] = normalize([sum_n[0]/weight_sum, sum_n[1]/weight_sum, sum_n[2]/weight_sum])
            else:
                blurred[x][y] = normal_buffer[x][y]
    return blurred

def paint_on_surface(mouse_u, mouse_v, brush, B_P, B_N):
    """
    Updates brush transformation based on surface buffers.
    """
    p_surf = B_P[mouse_u][mouse_v]
    n_surf = B_N[mouse_u][mouse_v]
    if p_surf is None or n_surf is None:
        return brush

    # Override depth to match surface position
    brush.depth = p_surf

    # Override orientation
    if brush.type == "cylindrical":
        brush.orientation = align_perpendicular(brush.axis, n_surf)
    elif brush.type == "superquadratic":
        brush.orientation = rotation_matrix_from_normal(n_surf)

    # Apply penetration depth adjustment
    brush.position = p_surf + (n_surf * brush.penetration_depth)
    return brush

# Helper definitions
def normalize(v):
    length = (v[0]**2 + v[1]**2 + v[2]**2)**0.5
    return [v[0]/length, v[1]/length, v[2]/length] if length > 0 else [0, 0, 0]

def align_perpendicular(axis, normal):
    up = [0, 1, 0]
    if abs(dot(axis, up)) > 0.99:
        up = [1, 0, 0]
    return normalize(cross(normal, up))

def rotation_matrix_from_normal(normal):
    z = normalize(normal)
    x = normalize(cross(z, [0, 1, 0]))
    y = cross(x, z)
    return [x, y, z]

def dot(a, b): return a[0]*b[0] + a[1]*b[1] + a[2]*b[2]
def cross(a, b): return [a[1]*b[2]-a[2]*b[1], a[2]*b[0]-a[0]*b[2], a[0]*b[1]-a[1]*b[0]]
```

### Parameters
*   **Refinement Steps:** 5 steps are used in the refinement routine [S1, unofficial].
*   **Gaussian Kernel:** Applied to the normal map to reduce noise [S1, unofficial].
*   **Brush Shape:** Cylindrical or Spherical (Superquadratic metaballs are used for the envelope definition, but the brush tip shape influences the merge) [S1, unofficial].
*   **Penetration Depth:** Adjustable parameter controlling how deeply the brush intersects the surface [S1, unofficial].

### Edge Cases and Pitfalls
*   **Normal Noise:** Volumetric datasets produce noisy normal maps, leading to abrupt orientation changes in superquadratic metaballs [S1, unofficial]. Mitigated by 5-step refinement and Gaussian blurring [S1, unofficial].
*   **Transparent Voxels:** The algorithm stops at the first *non-transparent* voxel; if no non-transparent voxel is found along the ray, the pixel is skipped [S1, unofficial].
*   **Degenerate Normals:** At flat surfaces or singularities, normals may be unstable [G]. The Gaussian blur helps smooth these transitions [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(W \cdot H \cdot S)$ for buffer generation, where $W, H$ are screen dimensions and $S$ is the number of samples per ray (including refinement steps) [G]. Painting interaction is $O(1)$ per brush stroke after buffer generation [G].
*   **Memory Complexity:** $O(W \cdot H)$ for storing the two 2D buffers ($B_P$ and $B_N$) [G].
*   **Performance:** The method requires a full screen-resolution ray cast to generate the buffers, which can be computationally expensive for high resolutions [G].
*   **Strengths:** Allows precise alignment of brush geometry with complex curved surfaces; supports negative brushes for erasing; flexible envelope definition via metaball merging [S1, unofficial].
*   **Limitations:** Noisy normals can cause visual artifacts without filtering; requires pre-computation of surface buffers; limited to isosurface-aligned painting [S1, unofficial].
*   **When to Use:** When the user needs to paint envelopes that closely follow the curvature of a volumetric object (e.g., painting an envelope around a finger's digit) [S1, unofficial].
