# Average Intensity Projection with IsoSurface Detection

Also called: Exact Projection Mean Density

## Overview
Average Intensity Projection with IsoSurface Detection is a volume rendering technique that computes the mean density of all voxels along a ray that fall within a valid density range, while simultaneously detecting the first isosurface crossing to enable surface-based shading [S2, unofficial]. Unlike standard Maximum Intensity Projection (MIP) which highlights only the brightest voxel, or standard Volume Ray Casting which accumulates opacity, this method averages the internal structure's density while using the detected surface position for lighting calculations [S2, unofficial]. It distinguishes itself from siblings like [Exact Projection First Contact](1897-exact-projection-first-contact.md) by incorporating a global average of the ray's valid samples rather than stopping at the first hit, and from [Isosurface Display via Opacity Mapping](6053-isosurface-display-via-opacity-mapping.md) by explicitly calculating a mean position for normal estimation [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D volume texture `texVol` containing scalar density values; a 1D transfer function texture `tf` (or `colorMap`) mapping density to RGBA color; an isosurface threshold `iso`; a sensitivity factor `sens` (typically 10); the number of steps `num_steps` (fixed at 256); and ray parameters `startPos`, `rayDir`, `tNear`, `tFar` [S1, unofficial][S2, unofficial].
*   **Output:** A fragment color `FragColor` representing the shaded average intensity projection [S2, unofficial].

**Data Structures:**
*   `texVol`: 3D texture, sampled via `texture(texVol, texPos).x` or `.r` [S1, unofficial][S2, unofficial].
*   `tf`: 1D texture, sampled via `texture(tf, meanValue)` [S1, unofficial].
*   `meanSum`: Float accumulator for density values [S1, unofficial].
*   `validSamples`: Integer counter for samples within the valid range [S1, unofficial].
*   `meanPos`: 3D vector accumulator for sample positions [S1, unofficial].
*   `color`: 4D vector accumulator for color values [S1, unofficial].

**Algorithm Steps:**

1.  **Initialization:**
    *   Set `meanSum = 0.0`, `validSamples = 0`, `meanPos = vec3(0.0)`, and `color = vec4(0.0)` [S1, unofficial].
    *   Define the effective isovalue: `iso_eff = iso / sens` [S1, unofficial].
    *   Define the step size: `dt = (tFar - tNear) / num_steps` [G].

2.  **Ray Marching Loop:**
    *   Iterate `i` from 0 to `num_steps - 1` [S1, unofficial]:
        *   Calculate current position: `curPos = startPos + rayDir * (tNear + i * dt)` [G].
        *   Transform `curPos` to texture coordinates:
            *   `tmp = vec3(curPos.xy, curPos.z * 2.3486238532110093)` [S1, unofficial].
            *   `texPos = (1.0 + tmp) / 2.0` [S1, unofficial].
            *   `texPos.y = 1.0 - texPos.y` [S1, unofficial].
        *   Sample density: `iso1 = texture(texVol, texPos).x` [S1, unofficial].
        *   Calculate next position: `nextPos = startPos + rayDir * (tNear + (i + 1) * dt)` [G].
        *   Transform `nextPos` to texture coordinates `texPosNext` using the same transformation as `texPos` [S1, unofficial].
        *   Sample next density: `iso2 = texture(texVol, texPosNext).x` [S1, unofficial].

3.  **Isosurface Detection and Accumulation:**
    *   Check for isosurface crossing: If `iso1 < iso_eff` and `iso2 > iso_eff` [S1, unofficial]:
        *   Perform binary search to find the exact intersection point `texIso` between `texPos` and `texPosNext` using the threshold `iso_eff` [S1, unofficial].
        *   Sample the color at the intersection: `value = vec4(texture(texVol, texIso).x)` [S1, unofficial].
        *   Add to color accumulator: `color = color + value` [S1, unofficial].
        *   Note: The source notes do not explicitly state whether to add to `meanSum` or `validSamples` upon crossing, but implies the crossing point is treated as a valid sample for the projection [S1, unofficial].
    *   If no crossing is detected:
        *   Check if `iso1` is within the valid range (implied by the context of "valid range" in [S2, unofficial], though specific min/max thresholds are not provided in the code snippets, the logic `if (val < minDensityThreshold || val > maxDensityThreshold) continue;` from [S2, unofficial] suggests a range check). For the purpose of this implementation based on [S1, unofficial], we assume the sample is valid if it contributes to the average.
        *   If the sample is considered valid (e.g., within implicit bounds or always valid in the simplified [S1, unofficial] version):
            *   `meanSum = meanSum + iso1` [G, inferred from "average density"].
            *   `validSamples = validSamples + 1` [G, inferred].
            *   `meanPos = meanPos + curPos` [G, inferred].
        *   *Correction based on [S1, unofficial] specific logic:* The source [S1, unofficial] uses a counter `cnt` initialized to 1, decrementing if no crossing. This logic is contradictory to the `validSamples` approach in [S2, unofficial]. We follow the explicit accumulation logic from [S2, unofficial] which is more robust: accumulate all valid samples. If following [S1, unofficial] strictly: `cnt--` if no crossing [S1, unofficial]. However, [S1, unofficial] also says "calculate the average density of all voxels along the ray within the valid range". We will use the `validSamples` approach as it is standard for "Average Intensity Projection" [S2, unofficial].

4.  **Final Calculation:**
    *   If `validSamples > 0`:
        *   Calculate mean density: `meanValue = meanSum / float(validSamples)` [S1, unofficial].
        *   Calculate mean position: `meanPos = meanPos / float(validSamples)` [S1, unofficial].
        *   Map mean value to color: `baseColor = texture(tf, meanValue)` [S1, unofficial].
        *   Apply compensation factor: `compensate = 1.0 / (iso_eff + 0.5)` [S1, unofficial].
        *   `finalColor = baseColor * compensate` [S1, unofficial].
    *   Else:
        *   `finalColor = vec4(0.0)` [S1, unofficial].

5.  **Lighting (Optional):**
    *   If lighting is enabled:
        *   Calculate normal at `meanPos`: `normal = calculateNormal(meanPos)` [S1, unofficial]. This typically involves finite differences or tri-cubic filtering of the gradient $\nabla f$ at `meanPos` [Parent].
        *   Calculate lit color: `litColor = calculateLighting(normal, -rayDir, meanPos, finalColor.rgb)` [S1, unofficial].
        *   Output `FragColor = vec4(litColor, 1.0)` [S1, unofficial].
    *   Else:
        *   Output `FragColor = finalColor` [S1, unofficial].

**Pseudocode:**

```python
def average_intensity_projection_with_isosurface(startPos, rayDir, tNear, tFar, num_steps, iso, sens, texVol, tf, enableLighting):
    iso_eff = iso / sens
    meanSum = 0.0
    validSamples = 0
    meanPos = vec3(0.0)
    colorAccum = vec4(0.0)
    
    dt = (tFar - tNear) / num_steps
    
    for i in range(num_steps):
        # Current position
        curPos = startPos + rayDir * (tNear + i * dt)
        texPos = transform_to_texture(curPos)
        
        # Next position
        nextPos = startPos + rayDir * (tNear + (i + 1) * dt)
        texPosNext = transform_to_texture(nextPos)
        
        # Sample densities
        iso1 = texture(texVol, texPos).x
        iso2 = texture(texVol, texPosNext).x
        
        # Isosurface detection
        if iso1 < iso_eff and iso2 > iso_eff:
            # Binary search for exact intersection
            texIso = binary_search_intersection(texPos, texPosNext, iso_eff, texVol)
            # Accumulate color at intersection
            value = vec4(texture(texVol, texIso).x)
            colorAccum = colorAccum + value
            
            # Also count as a valid sample for the average?
            # Source [S1, unofficial] is ambiguous, but [S2, unofficial] implies averaging valid samples.
            # We assume the intersection point is a valid sample.
            meanSum = meanSum + iso_eff # Use iso_eff as the value at surface
            validSamples = validSamples + 1
            meanPos = meanPos + get_world_position(texIso) # Approximate
        else:
            # Check if within valid range (assuming no explicit min/max thresholds in [S1, unofficial])
            # If [S2, unofficial] min/max thresholds were used, they would be checked here.
            # For [S1, unofficial] implementation, we assume all non-crossing samples are valid for average.
            meanSum = meanSum + iso1
            validSamples = validSamples + 1
            meanPos = meanPos + curPos
            
    if validSamples > 0:
        meanValue = meanSum / float(validSamples)
        meanPos = meanPos / float(validSamples)
        
        baseColor = texture(tf, meanValue)
        compensate = 1.0 / (iso_eff + 0.5)
        finalColor = baseColor * compensate
        
        if enableLighting:
            normal = calculate_normal(meanPos, texVol)
            litColor = calculate_lighting(normal, -rayDir, meanPos, finalColor.rgb)
            return vec4(litColor, 1.0)
        else:
            return finalColor
    else:
        return vec4(0.0)

def transform_to_texture(pos):
    tmp = vec3(pos.xy, pos.z * 2.3486238532110093)
    texPos = (1.0 + tmp) / 2.0
    texPos.y = 1.0 - texPos.y
    return texPos
```

**Parameters:**
*   `num_steps`: Fixed at 256 [S1, unofficial].
*   `iso`: Isosurface threshold [S1, unofficial].
*   `sens`: Sensitivity factor, typically 10 [S1, unofficial].
*   `iso_eff`: Effective isovalue, `iso / sens` [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Division by Zero:** If `validSamples` is 0, the mean cannot be calculated. The algorithm outputs black `vec4(0.0)` [S1, unofficial].
*   **Texture Coordinate Transformation:** The Z-axis uses a hardcoded multiplier `2.3486238532110093`, implying a specific non-uniform aspect ratio or data layout assumption [S1, unofficial]. Using this method with differently scaled data will distort the volume [S1, unofficial].
*   **Y-Axis Inversion:** The Y-axis texture coordinate is inverted (`1.0 - texPos.y`) to correct for image orientation [S1, unofficial].
*   **Compensation Factor:** The factor `1/(iso_eff + 0.5)` scales the final color based on the isovalue, which may lead to darkening if `iso_eff` is high [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ per pixel, where $N$ is the number of steps (`num_steps`). The binary search adds a logarithmic factor for each isosurface crossing, but crossings are typically sparse [S1, unofficial].
*   **Memory Complexity:** $O(1)$ auxiliary memory per pixel, plus the storage for the volume and transfer function textures [S1, unofficial].
*   **Strengths:** Provides a smooth representation of internal density structures while retaining surface shading cues from the isosurface [S2, unofficial]. It avoids the "blooming" effect of MIP by averaging [S2, unofficial].
*   **Limitations:** The hardcoded texture coordinate transformation limits its applicability to specific data layouts [S1, unofficial]. The compensation factor is arbitrary and may require tuning [S1, unofficial]. It does not handle multiple isosurfaces or complex lighting effects like shadows or ambient occlusion as described in the source [S1, unofficial].
*   **When to use:** When the goal is to visualize the average density of a structure while still benefiting from surface-like shading, and the data layout matches the hardcoded transformation [S2, unofficial].
*   **When not to use:** For data with varying aspect ratios, or when accurate surface normals from the first hit are required without averaging [S1, unofficial].
