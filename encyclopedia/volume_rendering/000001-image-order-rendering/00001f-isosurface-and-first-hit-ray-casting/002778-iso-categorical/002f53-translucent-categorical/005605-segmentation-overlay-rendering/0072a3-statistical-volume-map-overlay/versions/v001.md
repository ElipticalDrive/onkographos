# Statistical Volume Map Overlay

Also called: Statistical Volume Map Rendering, VMP Integration, Volume Map Overlay

## Overview
Statistical Volume Map Overlay is a volume rendering technique that integrates statistical volume maps (VMP) into the ray-casting pipeline to visualize activated regions (e.g., in brain imaging) alongside underlying anatomical data [S1]. It differs from standard segmentation overlays by allowing map values to be rendered both outside and inside the anatomical volume with adjustable blending, rather than restricting the overlay to a binary or discrete label boundary [S1]. It builds on [Segmentation Overlay Rendering](15607-segmentation-overlay-rendering.md) by treating the statistical map as a continuous scalar field integrated during depth compositing.

## How it works
**Inputs and Outputs:**
*   **Anatomical Volume:** A 3D scalar field (e.g., MRI intensity) used for primary rendering and opacity masking.
*   **Statistical Volume Map (VMP):** A 3D scalar field containing statistical values (e.g., t-values, z-scores) aligned with the anatomical volume.
*   **Output:** A composite RGBA image where the VMP is blended with the anatomical rendering.

**Data Structures:**
The VMP is stored as a 3D grid of floating-point values, aligned voxel-for-voxel with the anatomical volume. No specific bit-packing is mandated by the method; standard floating-point representation is implied by the use of statistical thresholds and interpolation [S1].

**Parameters:**
1.  **Threshold:** A scalar value. Map values below this threshold are excluded from rendering. This value is also assigned to the lowest entry of the Color Look-Up Table (LUT) [S1].
2.  **LUT Max:** A scalar value. Sets the highest value of the Color LUT. Values above this are not thresholded out but are clamped to the top color of the LUT [S1].
3.  **Inside Anat:** A scalar in $[0.0, 1.0]$ (typical values: $0.0, 0.02, 0.15$). Controls the attenuation of map values inside the anatomical volume. $0.0$ suppresses all internal map values; higher values progressively reveal them [S1].
4.  **Restrict to Anatomy:** A boolean flag. When enabled, map values are only rendered where the anatomical ray opacity reaches an opaque threshold during depth integration [S1].
5.  **Absorption:** A scalar (default $3.0$). The anatomical absorption coefficient used when *Restrict to Anatomy* is enabled to determine ray opacity decay [S1].
6.  **Interpolation:** Enum selecting the sampling method for the VMP: `Trilinear` (default), `Cubic`, or `Nearest` [S1].
7.  **Apply Slice Cut:** A boolean flag. If enabled, map values are only visualized if they intersect the anatomical slice cut plane; if disabled, map values are shown in the space exposed by the cut [S1].
8.  **Show Values:** Enum selecting which sign of values to display: `Positive`, `Negative`, or `Both` [S1].

**Algorithm Steps:**

1.  **Initialization:** Load the VMP file linked to the anatomical dataset. Initialize the rendering pipeline with the selected VMP, its Color LUT, and the statistical threshold [S1].
2.  **Ray Casting Setup:** For each pixel, cast a ray through the volume. Define the ray origin and direction based on the camera parameters.
3.  **Sampling Configuration:** Select the interpolation method (`Trilinear`, `Cubic`, or `Nearest`) for sampling the VMP at the ray's current position [S1].
4.  **Depth Integration Loop:** Iterate along the ray from near to far clipping plane. At each sample step $i$:
    a.  **Anatomical Sample:** Sample the anatomical volume at position $P_i$. Compute anatomical opacity $\alpha_{anat}$ using the absorption coefficient (default $3.0$) [S1].
    b.  **Map Sample:** Sample the VMP at position $P_i$ using the selected interpolation method. Let the value be $v_{map}$ [S1].
    c.  **Thresholding:** If $v_{map} < \text{Threshold}$, set $v_{map} = 0$ (or ignore contribution) [S1].
    d.  **Sign Filtering:** If `Show Values` is `Positive` and $v_{map} < 0$, or if `Show Values` is `Negative` and $v_{map} > 0$, set $v_{map} = 0$ [S1].
    e.  **Inside Anatomy Attenuation:** Determine if $P_i$ is inside the anatomical volume. This is typically determined by the anatomical opacity or a separate mask.
        *   If $P_i$ is inside the anatomical volume, multiply $v_{map}$ by the `Inside Anat` factor. If `Inside Anat` is $0.0$, $v_{map}$ becomes $0$ [S1].
        *   If $P_i$ is outside, $v_{map}$ is used as-is (or with full weight) [S1].
    f.  **Restrict to Anatomy Check:** If `Restrict to Anatomy` is enabled:
        *   Accumulate anatomical opacity along the ray up to $P_i$.
        *   If the accumulated anatomical opacity has not reached an opaque threshold (i.e., the ray has not "hit" the anatomy surface yet), set $v_{map} = 0$ [S1].
        *   This restricts map visualization to locations where the ray reaches the anatomical surface [S1].
    g.  **Slice Cut Check:** If `Apply Slice Cut` is enabled:
        *   Check if $P_i$ intersects the active anatomical slice cut plane.
        *   If not intersecting, set $v_{map} = 0$ [S1].
        *   If disabled, map values are visible in the space exposed by the cut (no additional masking) [S1].
    h.  **Color Mapping:** Map the final $v_{map}$ to an RGBA color using the LUT. The LUT maps the range $[\text{Threshold}, \text{LUT Max}]$ to the color spectrum. Values above `LUT Max` are clamped to the top color [S1].
    i.  **Compositing:** Composite the map color $C_{map}$ and opacity $\alpha_{map}$ (derived from $v_{map}$ or a fixed map opacity) with the current accumulated color and opacity using front-to-back alpha blending:
        $$ C_{out} = C_{in} \cdot (1 - \alpha_{map}) + C_{map} \cdot \alpha_{map} $$
        $$ \alpha_{out} = \alpha_{in} \cdot (1 - \alpha_{map}) + \alpha_{map} $$
5.  **Multi-Selection:** If multiple maps are enabled, repeat steps 2-4 for each map and composite the results sequentially or simultaneously, ensuring each map retains its independent LUT and threshold settings [S1].

**Pseudocode:**

```python
def render_statistical_volume_map(ray_origin, ray_direction, anatomical_volume, vmp_volume, params):
    """
    Renders a single ray for Statistical Volume Map Overlay.
    
    params: dict containing:
        threshold: float
        lut_max: float
        inside_anat: float (0.0 to 1.0)
        restrict_to_anatomy: bool
        absorption: float (default 3.0)
        interpolation: str ('trilinear', 'cubic', 'nearest')
        apply_slice_cut: bool
        show_values: str ('positive', 'negative', 'both')
        slice_plane: plane equation or None
        lut: function mapping value to RGBA
    """
    accumulated_color = [0.0, 0.0, 0.0, 0.0]
    accumulated_opacity = 0.0
    accumulated_anat_opacity = 0.0
    
    # Step size for ray marching
    step_size = 1.0 # Assuming voxel-aligned steps for simplicity
    
    for t in range(0, ray_length, step_size):
        pos = ray_origin + ray_direction * t
        
        # 1. Sample Anatomical Volume
        anat_val = sample_volume(anatomical_volume, pos, params.interpolation)
        # Simple absorption model: opacity increases with value
        anat_opacity_step = 1.0 - math.exp(-params.absorption * anat_val)
        
        # Update accumulated anatomical opacity for "Restrict to Anatomy" logic
        accumulated_anat_opacity += anat_opacity_step * (1.0 - accumulated_opacity)
        
        # 2. Sample VMP
        vmp_val = sample_volume(vmp_volume, pos, params.interpolation)
        
        # 3. Thresholding
        if vmp_val < params.threshold:
            vmp_val = 0.0
            
        # 4. Sign Filtering
        if params.show_values == 'positive' and vmp_val < 0:
            vmp_val = 0.0
        elif params.show_values == 'negative' and vmp_val > 0:
            vmp_val = 0.0
            
        # 5. Inside Anatomy Attenuation
        # Determine if inside anatomy: if anat_val > 0 (simplified)
        is_inside = anat_val > 0
        if is_inside:
            vmp_val *= params.inside_anat
            
        # 6. Restrict to Anatomy
        if params.restrict_to_anatomy:
            # Only render if ray has reached opaque anatomical threshold
            # Assuming opaque threshold is 1.0 for accumulated opacity
            if accumulated_anat_opacity < 1.0:
                vmp_val = 0.0
                
        # 7. Slice Cut Check
        if params.apply_slice_cut:
            if not intersects_slice_plane(pos, params.slice_plane):
                vmp_val = 0.0
                
        # 8. Color Mapping
        # Clamp vmp_val for LUT lookup if above lut_max, but do not threshold out
        display_val = min(vmp_val, params.lut_max)
        map_color = params.lut(display_val)
        
        # Map opacity: assume linear relationship with value for visualization
        # Or use a fixed opacity for the map overlay
        map_opacity = map_color[3] # Assuming LUT returns RGBA
        if map_opacity == 0:
            continue
            
        # 9. Front-to-Back Compositing
        # Blend map color over the current accumulated color
        # Note: The map is an overlay, so it might be blended differently than standard volume rendering
        # Standard alpha blending:
        new_alpha = accumulated_opacity + map_opacity * (1.0 - accumulated_opacity)
        new_color = (accumulated_color * (1.0 - map_opacity) + map_color * (1.0 - accumulated_opacity)) / new_alpha if new_alpha > 0 else [0,0,0,0]
        
        accumulated_color = new_color
        accumulated_opacity = new_alpha
        
        # Early ray termination if fully opaque
        if accumulated_opacity >= 1.0:
            break
            
    return accumulated_color
```

**Edge Cases and Pitfalls:**
*   **Interpolation Artifacts:** Trilinear interpolation can cause unintended color values at boundaries of discrete or ideal maps (e.g., eccentricity maps). Use `Nearest` neighbor interpolation for such cases [S1].
*   **Threshold/LUT Alignment:** The threshold value is assigned to the lowest entry of the LUT (red). If `LUT Max` is set equal to the threshold, all positive values render as red [S1].
*   **Inside Anat Precision:** Very low `Inside Anat` values (e.g., 0.02) may result in very faint internal visualization, potentially lost in noise [S1].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of samples per ray and the number of active maps. Each additional map adds a constant factor to the per-pixel computation [S1].
*   **Memory Complexity:** Requires storing the VMP in memory, aligned with the anatomical volume. No additional large data structures are required beyond standard ray-casting buffers [S1].
*   **Performance:** Performance is comparable to standard volume rendering, with a slight overhead for sampling the additional VMP and applying the attenuation/restriction logic [S1].
*   **Strengths:** Allows flexible visualization of statistical data both inside and outside anatomical structures; supports multiple simultaneous maps with independent LUTs; provides intuitive controls for revealing internal activity [S1].
*   **Limitations:** Dependent on the quality of the anatomical volume rendering for "Restrict to Anatomy" functionality; interpolation artifacts can degrade discrete map visualization [S1].
*   **When to Use:** When visualizing statistical activations (e.g., fMRI) in conjunction with anatomical context, especially when internal activations need to be visible or when multiple statistical maps need to be overlaid [S1].
*   **When Not to Use:** When discrete, non-interpolated map boundaries are critical (use Nearest neighbor or standard segmentation overlay); when performance is severely constrained and multiple maps are not needed [S1].

## Background
Statistical Volume Map Overlay was developed as part of the BrainVoyager software suite for brain imaging applications [S1]. It enables the integration of volume maps into the volume rendering process, allowing researchers to visualize activated brain regions alongside underlying anatomical data [S1]. The method was introduced in BrainVoyager v23.0, providing features such as adjustable blending, slice cut logic, and multi-selection mode for overlaying multiple maps [S1].
