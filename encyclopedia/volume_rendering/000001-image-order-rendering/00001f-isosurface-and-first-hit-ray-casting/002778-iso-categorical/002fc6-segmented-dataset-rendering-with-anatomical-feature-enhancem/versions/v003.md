# Segmented Dataset Rendering with Anatomical Feature Enhancement

Also called: Sliced Volume Rendering with Segmentation Labels

## Overview
This method renders segmented volumetric datasets by "painting" colors derived from segmentation labels directly onto the rendered volume, rather than relying on distinct transfer functions for object separation [S1]. It delivers higher image quality with smoother subvolume boundaries compared to previous categorical rendering approaches [S1]. It sets itself apart from its parent [iso_categorical](4049-iso-categorical.md) by replacing discrete voxel-at-a-time testing with a continuous painting approach that enhances anatomical features [S1].

## How it works
Inputs: Segmented volumetric data, segmentation labels, rendering parameters.
Outputs: Rendered image with enhanced anatomical features and smooth subvolume boundaries.

Steps:
1. Acquire segmentation labels for the volume [S1].
2. Map each unique label to a specific color value [G].
3. During ray casting, sample the segmentation labels along the ray [S1].
4. "Paint" the acquired colors onto the rendered volume based on the sampled labels [S1].
5. Composite the painted colors to produce the final image [G].

```python
def render_segmented_volume(volume, labels, camera_params, screen_width, screen_height):
    # Initialize output image as a list of lists of lists [height][width][3]
    image = [[[0.0, 0.0, 0.0] for _ in range(screen_width)] for _ in range(screen_height)]

    # Step not specified in sources [S1]
    unique_labels = set()
    for z in range(len(labels)):
        for y in range(len(labels[z])):
            for x in range(len(labels[z][y])):
                unique_labels.add(labels[z][y][x])
    color_map = {label: [float(label % 256), float((label // 256) % 256), float(label // 65536)] for label in unique_labels}

    for y in range(screen_height):
        for x in range(screen_width):
            # Step not specified in sources [S1]
            ray_origin = camera_params['origin']
            ray_direction = camera_params['directions'][y][x]
            ray_direction = normalize(ray_direction)

            accumulated_color = [0.0, 0.0, 0.0]
            t = 0.0
            step_size = camera_params.get('step_size', 1.0)
            max_distance = camera_params.get('max_distance', 100.0)

            while t < max_distance:
                # Get position along ray
                pos = [ray_origin[i] + t * ray_direction[i] for i in range(3)]

                # Get segmentation label at position, handling boundaries [G]
                label = get_label_at_position(labels, pos)

                # Get color for this label
                color = color_map.get(label, [0.0, 0.0, 0.0])

                # Step not specified in sources [S1]
                accumulated_color = [accumulated_color[i] + color[i] for i in range(3)]

                # Advance along ray
                t += step_size

            # Clamp and store result
            image[y][x] = [min(c, 1.0) for c in accumulated_color]

    return image

def normalize(v):
    length = (v[0]**2 + v[1]**2 + v[2]**2)**0.5
    return [v[0]/length, v[1]/length, v[2]/length] if length > 0 else [0.0, 0.0, 0.0]

def get_label_at_position(labels, pos):
    # Convert continuous position to integer grid indices
    ix, iy, iz = int(pos[0]), int(pos[1]), int(pos[2])
    # Clamp to valid bounds
    ix = max(0, min(ix, len(labels[0][0]) - 1))
    iy = max(0, min(iy, len(labels[0]) - 1))
    iz = max(0, min(iz, len(labels) - 1))
    return labels[iz][iy][ix]
```

## Subtopics

### [Two-level volume rendering](7677-two-level-volume-rendering.md)
An extension that subdivides a volume into distinct objects and assigns individual rendering modes to each. It sets itself apart by allowing different transfer functions, shading models, or compositing strategies per object, unlike standard direct volume rendering which applies a uniform model. Choose it when rendering segmented datasets requires high image quality and smooth subvolume boundaries with object-specific visual properties.

## Background
The algorithm was presented in the context of rendering 4D cardiac datasets synchronized with electrocardiogram signals [S1]. It was developed to improve upon previous techniques for dynamic volume rendering and manipulation [S1]. The method facilitates image manipulation and image-guided intervention by providing higher image quality and smoother subvolume boundaries compared to using different transfer functions for segmented object separation [S1].
