# Volumetric Smoke Rendering with Worley Noise and Light Maps

Also called: Unity Volumetric Smoke, Volumetric Smoke Rendering

## Overview
A real-time volumetric rendering technique for smoke using Unity Compute Shaders for texture generation and a vertex/fragment shader for raymarching. It combines Worley noise for density, a light map for scattering, and optional density masks. It differs from standard direct volume rendering by using procedural Worley noise for density detail and a separate light map to simulate light scattering and god rays, rather than relying solely on volume density for shading.

## How it works
### Inputs and Outputs
**Inputs:**
- Camera position and view direction.
- Volume bounds (AABB).
- Worley noise textures (2D or 3D) for density and detail.
- Light map texture (optional).
- Density mask texture (optional).
- Simulation state (optional, for animated smoke).
- Parameters: `density_threshold`, `god_rays_strength`, `light_decay`, `light_color`, `light_direction`, `octave_count`, `persistence`, `lacunarity`, `amplitude`, `size`, `use_united_texture`, `use_light_map`, `density_sample_count`, `light_sample_count`, `light_sample_per_density_sample`, `step_size`, `texture_offset`, `noise_texture_size`, `light_texture_size`, `mask_texture_size`, `object_scale`, `iterate_z_every`, `update_light_map_every`, `time_ms`.

**Outputs:**
- Final rendered image with smoke color and opacity.

### Data Structures
- `StructuredBuffer<float2> feature_points_buffer_2D`: Buffer of 2D feature points for 2D Worley noise.
- `RWTexture2D<float> noise_texture_2D`: Read-write 2D texture for storing 2D Worley noise.
- `StructuredBuffer<float3> feature_points_buffer_3D`: Buffer of 3D feature points for 3D Worley noise.
- `RWTexture3D<float> noise_texture_3D`: Read-write 3D texture for storing 3D Worley noise.
- `RWTexture2D<float> slice_texture`: Read-write 2D texture for storing a slice of the 3D noise texture.
- `RWTexture3D<float> light_density_texture`: Read-write 3D texture for storing light density.
- `union_texture`: RenderTexture with format R8G8B8A8_UNorm, dimension Tex3D, size `max_size` x `max_size` x `max_size` (where `max_size` is the max of `worley_noise_size`, `light_map_resolution`, and `solver.density_rt` dimensions). `enableRandomWrite` is true.
- `MergedSample` struct: Contains four floats: `noise`, `detail`, `light`, `mask`.

### Steps
1. **Worley Noise Generation:**
   - Generate Worley noise octaves: Loop from octave 0 to `octave_count`-1. Set `worley_noise_division_size` to (`size`, `size`, `size`). Call `_compute_worley_noise_3D_detail(amplitude)`. Update `amplitude *= persistence`. Update `size = Mathf.CeilToInt(size / lacunarity)`.
   - Compute shader `add_worley_noise_2D` generates 2D Worley noise by iterating over a 3x3 grid of neighboring cells, finding the minimum distance to feature points, and adding the result scaled by `noise_strength`.
   - Compute shader `add_worley_noise_3D` generates 3D Worley noise similarly, iterating over a 3x3x3 grid of neighboring cells in 3D space.
   - Compute shader `get_slice_of_3D_texture` copies a 2D slice from a 3D texture to a 2D texture at a specified slice index.

2. **Texture Merging:**
   - Merge textures: Find kernel `unite_textures`. Set uniforms: `united_texture_size`, `noise_texture_size`, `detail_texture_size`, `light_texture_size`, `mask_texture_size`. Bind textures: `united_texture`, `noise_texture_merge`, `detail_texture_merge`, `light_texture_merge`, `mask_texture_merge`. Dispatch kernel with thread groups `ceil(max_size/8)`.

3. **Ray Casting:**
   - Vertex shader computes world position, screen position, and camera view direction for each vertex of the rendering quad/plane.
   - Fragment shader calculates local camera position and normalized view direction relative to the volume object.
   - Ray-AABB intersection is computed to find the entry point (`hit.x`) and distance inside the box (`hit.y`) for the ray originating at the camera.
   - The ray start point is calculated as camera position plus view direction scaled by the entry distance.

4. **Ray Marching:**
   - At each step, the merged texture is sampled to get noise, detail, and mask values, which are processed to calculate density.
   - If the calculated density is below the threshold, it is replaced by a constant `god_rays_strength` value to allow light to pass through empty areas for god ray effects.
   - If density is near the god rays strength threshold and light intensity is high, light intensity is boosted by 1.5x.
   - The color is blended using front-to-back blending: new color contribution is added based on its alpha and the remaining transparency of the accumulated color.
   - The loop breaks early if the accumulated alpha reaches 0.96, optimizing performance for opaque regions.
   - The final surface color is returned with alpha clamped to 1.0, and the RGB channels are divided by alpha (premultiplied to straight alpha conversion or similar handling).

### Pseudocode
```python
import math

def vec3(x, y, z):
    return [x, y, z]

def vec4(x, y, z, w):
    return [x, y, z, w]

def ray_intersect_aabb(bounds_min, bounds_max, ray_origin, ray_dir):
    inv_ray_dir = [1.0 / ray_dir[i] if ray_dir[i] != 0 else float('inf') for i in range(3)]
    t0 = [(bounds_min[i] - ray_origin[i]) * inv_ray_dir[i] for i in range(3)]
    t1 = [(bounds_max[i] - ray_origin[i]) * inv_ray_dir[i] for i in range(3)]
    t_min = [min(t0[i], t1[i]) for i in range(3)]
    t_max = [max(t0[i], t1[i]) for i in range(3)]
    dst_a = max(t_min[0], max(t_min[1], t_min[2]))
    dst_b = min(t_max[0], min(t_max[1], t_max[2]))
    dst_to_box = max(0.0, dst_a)
    dst_inside_box = max(0.0, dst_b - dst_to_box)
    return [dst_to_box, dst_inside_box]

def blend_ftb(color, new_color):
    color[0] += (1.0 - color[3]) * new_color[3] * new_color[0]
    color[1] += (1.0 - color[3]) * new_color[3] * new_color[1]
    color[2] += (1.0 - color[3]) * new_color[3] * new_color[2]
    color[3] += (1.0 - color[3]) * new_color[3]
    return color

def worley_noise_2d(id_x, id_y, noise_texture_size_x, noise_texture_size_y, cell_size_x, cell_size_y, feature_points_buffer_2D, noise_strength):
    texture_coordinates = [id_x, id_y]
    cell_count_x = noise_texture_size_x // cell_size_x
    cell_count_y = noise_texture_size_y // cell_size_y
    cell_coordinates = [int(texture_coordinates[0] // cell_size_x), int(texture_coordinates[1] // cell_size_y)]
    local_coordinates = [texture_coordinates[0] / cell_size_x - cell_coordinates[0], texture_coordinates[1] / cell_size_y - cell_coordinates[1]]
    min_distance = 1.0
    for offset_y in range(-1, 2):
        for offset_x in range(-1, 2):
            offset = [offset_x, offset_y]
            neighbour_cell_coordinates = [cell_coordinates[0] + offset[0], cell_coordinates[1] + offset[1]]
            wrapped_cell_coordinates = [neighbour_cell_coordinates[0] % cell_count_x, neighbour_cell_coordinates[1] % cell_count_y]
            cell_index = wrapped_cell_coordinates[0] + wrapped_cell_coordinates[1] * cell_count_x
            feature_point_offset = [neighbour_cell_coordinates[0] + feature_points_buffer_2D[cell_index][0], neighbour_cell_coordinates[1] + feature_points_buffer_2D[cell_index][1]]
            distance = math.sqrt((cell_coordinates[0] + local_coordinates[0] - feature_point_offset[0])**2 + (cell_coordinates[1] + local_coordinates[1] - feature_point_offset[1])**2)
            min_distance = min(min_distance, distance)
    return (1.0 - min_distance) * noise_strength

def worley_noise_3d(id_x, id_y, id_z, noise_texture_size_x, noise_texture_size_y, noise_texture_size_z, cell_size_x, cell_size_y, cell_size_z, feature_points_buffer_3D, noise_strength):
    texture_coordinates = [id_x, id_y, id_z]
    cell_count_x = noise_texture_size_x // cell_size_x
    cell_count_y = noise_texture_size_y // cell_size_y
    cell_count_z = noise_texture_size_z // cell_size_z
    cell_coordinates = [int(texture_coordinates[0] // cell_size_x), int(texture_coordinates[1] // cell_size_y), int(texture_coordinates[2] // cell_size_z)]
    local_coordinates = [texture_coordinates[0] / cell_size_x - cell_coordinates[0], texture_coordinates[1] / cell_size_y - cell_coordinates[1], texture_coordinates[2] / cell_size_z - cell_coordinates[2]]
    min_distance = 1.0
    for offset_z in range(-1, 2):
        for offset_y in range(-1, 2):
            for offset_x in range(-1, 2):
                offset = [offset_x, offset_y, offset_z]
                neighbour_cell_coordinates = [cell_coordinates[0] + offset[0], cell_coordinates[1] + offset[1], cell_coordinates[2] + offset[2]]
                wrapped_cell_coordinates = [neighbour_cell_coordinates[0] % cell_count_x, neighbour_cell_coordinates[1] % cell_count_y, neighbour_cell_coordinates[2] % cell_count_z]
                cell_index = wrapped_cell_coordinates[0] + cell_count_x * (wrapped_cell_coordinates[1] + cell_count_y * wrapped_cell_coordinates[2])
                feature_point_offset = [neighbour_cell_coordinates[0] + feature_points_buffer_3D[cell_index][0], neighbour_cell_coordinates[1] + feature_points_buffer_3D[cell_index][1], neighbour_cell_coordinates[2] + feature_points_buffer_3D[cell_index][2]]
                distance = math.sqrt((cell_coordinates[0] + local_coordinates[0] - feature_point_offset[0])**2 + (cell_coordinates[1] + local_coordinates[1] - feature_point_offset[1])**2 + (cell_coordinates[2] + local_coordinates[2] - feature_point_offset[2])**2)
                min_distance = min(min_distance, distance)
    return (1.0 - min_distance) * noise_strength

def sample_merged_texture(tex_coord, use_united_texture, united_texture, noise_texture, detail_texture, light_texture, mask_texture, noise_texture_size, light_texture_size, mask_texture_size, object_scale, texture_offset):
    if use_united_texture:
        final_tex_coord = [(tex_coord[i] + 0.5 + texture_offset[i] / noise_texture_size[i] + 1.0) % 1.0 for i in range(3)]
        data = united_texture[final_tex_coord]
        noise = data[0]
        detail = data[1]
        light = data[2]
        mask = data[3] * 32.0
        return [noise, detail, light, mask]
    else:
        minimalized_object_scale = [object_scale[i] / max(object_scale[0], max(object_scale[1], object_scale[2])) for i in range(3)]
        scaled_tex_coord = [tex_coord[i] * minimalized_object_scale[i] + 0.5 for i in range(3)]
        noise = noise_texture[scaled_tex_coord]
        detail = detail_texture[scaled_tex_coord]
        light = light_texture[scaled_tex_coord] if use_light_map else 0.65
        unscaled_tex_coord = [tex_coord[i] / minimalized_object_scale[i] for i in range(3)]
        mask = mask_texture[unscaled_tex_coord]
        return [noise, detail, light, mask]

def volumetric_smoke_rendering(camera, volume_bounds, united_texture, noise_texture, detail_texture, light_texture, mask_texture, noise_texture_size, light_texture_size, mask_texture_size, object_scale, texture_offset, use_united_texture, use_light_map, density_threshold, god_rays_strength, light_decay, light_color, light_direction, density_sample_count, light_sample_count, light_sample_per_density_sample, step_size):
    h, w = camera.screen_height, camera.screen_width
    image = [[vec3(0.0, 0.0, 0.0) for _ in range(w)] for _ in range(h)]
    
    for y in range(h):
        for x in range(w):
            ray_origin, ray_direction = camera.cast_ray(x, y)
            accumulated_color = vec4(0.0, 0.0, 0.0, 0.0)
            
            hit = ray_intersect_aabb(volume_bounds[0], volume_bounds[1], ray_origin, ray_direction)
            ray_start = [ray_origin[i] + ray_direction[i] * hit[0] for i in range(3)]
            t = hit[0]
            
            for step in range(density_sample_count):
                if accumulated_color[3] >= 0.96:
                    break
                
                pos = [ray_start[i] + ray_direction[i] * (t - hit[0]) for i in range(3)]
                sample = sample_merged_texture(pos, use_united_texture, united_texture, noise_texture, detail_texture, light_texture, mask_texture, noise_texture_size, light_texture_size, mask_texture_size, object_scale, texture_offset)
                noise, detail, light, mask = sample[0], sample[1], sample[2], sample[3]
                
                density = noise + detail * mask
                if density < density_threshold:
                    density = god_rays_strength
                
                light_intensity = light * (1.0 / (1.0 + light_decay * (t - hit[0])))
                if density > god_rays_strength * 0.5 and light_intensity > 0.5:
                    light_intensity *= 1.5
                
                color = [light_color[i] * light_intensity for i in range(3)]
                alpha = density * step_size
                
                accumulated_color = blend_ftb(accumulated_color, vec4(color[0], color[1], color[2], alpha))
                t += step_size
                
            image[y][x] = [accumulated_color[i] / accumulated_color[3] if accumulated_color[3] > 0 else 0.0 for i in range(3)]
            
    return image
```

### Parameters
- `density_threshold`: Threshold for density values; if density is below this, it is treated as empty/god ray area.
- `god_rays_strength`: Constant density value assigned to empty areas to allow god rays to shine through.
- `light_decay`: Exponential decay factor for light intensity over distance.
- `density_sample_count`: Number of steps for density sampling in the ray march.
- `light_sample_count`: Number of steps for light sampling.
- `light_sample_per_density_sample`: Ratio of light samples to density samples.
- `light_color`: RGB color of the light source.
- `light_direction`: Direction vector of the light source.
- `noise_strength`: Multiplier for the Worley noise output.
- `octave_count`: Number of octaves for Worley noise generation. Default value: 5.
- `persistence`: Amplitude multiplier per octave in Worley noise generation. Default value: 0.5f.
- `lacunarity`: Frequency multiplier per octave in Worley noise generation. Default value: 2.0f.
- `amplitude`: Initial amplitude for Worley noise. Default value: 0.075f.
- `size`: Initial resolution for Worley noise texture. Default value: 16.
- `use_united_texture`: Boolean flag (int) to switch between merged texture sampling and individual texture sampling. Default: 0.
- `use_light_map`: Boolean flag (int) to enable light map sampling. Default: 0.
- `texture_offset`: Vector3 parameter for noise animation offset. Calculated as `(0, (-time_ms * 0.003f * worley_noise_size.y % worley_noise_size.y), 0)`.
- `noise_texture_size`: Vector3 parameter for Worley noise texture dimensions.
- `light_texture_size`: Vector3 parameter for light map texture dimensions.
- `mask_texture_size`: Vector3 parameter for density mask texture dimensions.
- `object_scale`: Vector4 parameter for object scaling, used to normalize texture coordinates.
- `iterate_z_every`: Integer parameter controlling how often to iterate through Z slices for 3D slice display. Default: 1.
- `update_light_map_every`: Integer parameter controlling how often to update the light map. Default: 1.
- `time_ms`: Float parameter for time in milliseconds, used for animation. Range: 0 to 128.

### Edge Cases and Pitfalls
- **Texture coordinate wrapping:** The united texture sampling uses `fmod` with `+1` to handle negative coordinates and ensure wrapping within `[0,1)`.
- **Mask scaling:** The mask value from the united texture is scaled by `32.0f`.
- **Light map fallback:** If `use_light_map` is false, the light value is hardcoded to `0.65f`.

## Operating characteristics
- **Time Complexity:** O(N * M) where N is the number of pixels and M is the number of samples per ray.
- **Memory Complexity:** O(V) where V is the volume of the noise textures.
- **Measured Performance:** Real-time performance on modern GPUs using Unity Compute Shaders.
- **Scaling:** Scales with resolution and number of samples.
- **Strengths:** Real-time performance, procedural density generation, god ray effects.
- **Limitations:** Limited to smoke-like effects, requires careful tuning of parameters.
- **When to use:** Real-time smoke effects in games and simulations.
- **When not to use:** High-fidelity offline rendering, non-smoke volumes.
