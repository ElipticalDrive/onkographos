# Piecewise Density Approximation for Reparameterized Sampling

Also called: PWC approximation, PWL approximation, Piecewise Constant Approximation

## Overview
This method approximates the optical density field $\sigma_r(t)$ along a ray as either piecewise constant or piecewise linear on a fixed grid, enabling the analytical computation of the cumulative opacity integral $I(t) = \int \sigma_r(s) ds$ [S1, S2, unofficial]. By inverting the resulting monotonic cumulative opacity function $F_r(t) = 1 - \exp(-I(t))$, it generates volume samples that are uniformly distributed in opacity space rather than Euclidean space [S1, S2, unofficial]. This approach differs from [Piecewise Linear Mapping and Integration](9000-piecewise-linear-mapping-and-integration.md) by explicitly constructing a piecewise approximation of the *density* (the derivative of the integral) to facilitate closed-form inversion, whereas siblings like [Linear Opacity Interpolation](7016-linear-opacity-interpolation.md) may interpolate opacity directly [S1, S2, unofficial].

## How it works
**Inputs:**
*   Ray segment bounds $t_n$ (near) and $t_f$ (far) [S1, S2, unofficial].
*   A grid of $m+1$ points $t_0, t_1, \dots, t_m$ such that $t_n = t_0 < t_1 < \dots < t_m = t_f$ [S1, S2, unofficial].
*   A density query function $\sigma_r(t)$ that returns the scalar density at position $t$ [S1, S2, unofficial].
*   A target opacity value $y_f$ (typically $1 - \exp(-\int_{t_n}^{t_f} \sigma_r(s) ds)$ or a user-defined max opacity) [S1, S2, unofficial].
*   A uniform random sample $u \sim U[0, 1]$ [S1, S2, unofficial].

**Outputs:**
*   A sample position $t \in [t_n, t_f]$ such that the cumulative opacity up to $t$ matches $y_f u$ [S1, S2, unofficial].

**Data Structures:**
*   Grid array $T = [t_0, t_1, \dots, t_m]$ of size $m+1$.
*   Precomputed bin widths $\delta_i = t_{i+1} - t_i$ for $i=0 \dots m-1$ [S2, unofficial].

**Steps:**

1.  **Grid Construction:** Define the grid points $t_0, \dots, t_m$ spanning the ray segment $[t_n, t_f]$ [S1, S2, unofficial].
2.  **Density Sampling:**
    *   For **Piecewise Constant (PWC)**: For each bin $j \in \{0, \dots, m-1\}$, select a representative point $\hat{t}_j \in [t_j, t_{j+1}]$. The sources specify picking a *random* point within the bin [S2, unofficial], though other implementations may use the bin center [S1, unofficial]. Query the density $\sigma_j = \sigma_r(\hat{t}_j)$ [S1, S2, unofficial].
    *   For **Piecewise Linear (PWL)**: Query the density at all grid points: $\sigma_i = \sigma_r(t_i)$ for $i=0, \dots, m$ [S1, S2, unofficial].
3.  **Integral Approximation:** Compute the cumulative integral approximation $I(t)$ for a target $t \in [t_i, t_{i+1})$:
    *   **PWC ($I_0$):**
        $$ I_0(t) = \sum_{j=1}^{i} \sigma_j (t_j - t_{j-1}) + \sigma_i (t - t_i) $$
        where $\sigma_j = \sigma_r(\hat{t}_j)$ [S1, S2, unofficial]. Note: The summation index in the sources starts at 1, implying $t_0$ is the start. The term for the current bin uses the density sampled at $\hat{t}_i$ [S1, S2, unofficial].
    *   **PWL ($I_1$):**
        $$ I_1(t) = \sum_{j=1}^{i} \frac{\sigma_j + \sigma_{j-1}}{2} (t_j - t_{j-1}) + \frac{\sigma_i + \bar{\sigma}_r(t)}{2} (t - t_i) $$
        where $\bar{\sigma}_r(t)$ is the linearly interpolated density at $t$:
        $$ \bar{\sigma}_r(t) = \sigma_i \frac{t_{i+1}-t}{t_{i+1}-t_i} + \sigma_{i+1} \frac{t-t_i}{t_{i+1}-t_i} $$
        [S2, unofficial].
4.  **Inverse Opacity Calculation:**
    The goal is to find $t$ such that:
    $$ y_f u = 1 - \exp(-I(t)) $$
    Rearranging for the integral:
    $$ I(t) = -\log(1 - y_f u) $$
    Let $Y = -\log(1 - y_f u)$ [S1, S2, unofficial].
5.  **Bin Search:** Find the index $i$ such that $I(t_i) \le Y < I(t_{i+1})$.
    *   For PWC, $I_0(t)$ is piecewise linear. Compute cumulative sums of rectangular areas to find the bin.
    *   For PWL, $I_1(t)$ is piecewise quadratic. Compute cumulative sums of trapezoidal areas to find the bin.
6.  **Solve for $t$:**
    *   **PWC:** Solve the linear equation within bin $i$:
        $$ \sigma_i (t - t_i) + I_0(t_i) = Y \implies t = t_i + \frac{Y - I_0(t_i)}{\sigma_i} $$
        [S1, S2, unofficial].
    *   **PWL:** Solve the quadratic equation within bin $i$. Let $\Delta t = t - t_i$. The equation is:
        $$ \frac{\sigma_i + \bar{\sigma}_r(t_i + \Delta t)}{2} \Delta t + I_1(t_i) = Y $$
        Substituting $\bar{\sigma}_r(t_i + \Delta t) = \sigma_i + \frac{\sigma_{i+1}-\sigma_i}{\delta_i} \Delta t$:
        $$ \frac{2\sigma_i + \frac{\sigma_{i+1}-\sigma_i}{\delta_i} \Delta t}{2} \Delta t + I_1(t_i) = Y $$
        $$ \frac{\sigma_{i+1}-\sigma_i}{2\delta_i} (\Delta t)^2 + \sigma_i \Delta t + (I_1(t_i) - Y) = 0 $$
        Solve for $\Delta t$ using the quadratic formula, selecting the root that lies in $[0, \delta_i]$ [S1, S2, unofficial].
7.  **Return:** $t = t_i + \Delta t$ [S1, S2, unofficial].

**Pseudocode:**

```python
import math

def piecewise_density_approximation(t_near, t_far, grid, sigma_func, y_f, u, mode='pwc'):
    """
    Generate a sample t using piecewise density approximation.
    
    Args:
        t_near: Start of ray segment.
        t_far: End of ray segment.
        grid: List of grid points [t_0, ..., t_m].
        sigma_func: Function returning density sigma_r(t).
        y_f: Target opacity factor (e.g., 1 - exp(-total_density)).
        u: Uniform random sample in [0, 1].
        mode: 'pwc' for piecewise constant, 'pwl' for piecewise linear.
        
    Returns:
        t: Sample position on the ray.
    """
    # 1. Precompute grid properties
    m = len(grid) - 1
    deltas = [grid[i+1] - grid[i] for i in range(m)]
    
    # 2. Compute target integral value Y
    # Avoid log(0) if y_f*u is 0
    if y_f * u == 0:
        return t_near
    
    Y = -math.log(1.0 - y_f * u)
    
    # 3. Sample densities
    if mode == 'pwc':
        # PWC: Sample one density per bin
        # Sources say pick a random point in bin [S2, unofficial], or arbitrary point [S1, unofficial]
        # We use the midpoint for determinism, or random if specified.
        # Here we use midpoint as a standard implementation choice when random is not strictly enforced for reproducibility.
        # If strict adherence to [S2, unofficial] is required, replace with random.uniform(grid[i], grid[i+1])
        sigmas = []
        for i in range(m):
            t_sample = (grid[i] + grid[i+1]) / 2.0 # [G] Midpoint used for deterministic implementation
            sigmas.append(sigma_func(t_sample))
            
        # 4. Find bin and solve linear equation
        current_integral = 0.0
        for i in range(m):
            bin_integral = sigmas[i] * deltas[i]
            if current_integral + bin_integral >= Y:
                # Found bin i
                # Solve: sigmas[i] * (t - grid[i]) + current_integral = Y
                if sigmas[i] == 0:
                    return grid[i] # Degenerate case
                t = grid[i] + (Y - current_integral) / sigmas[i]
                return t
            current_integral += bin_integral
            
    elif mode == 'pwl':
        # PWL: Sample density at grid points
        sigmas = [sigma_func(t) for t in grid]
        
        # 4. Find bin and solve quadratic equation
        current_integral = 0.0
        for i in range(m):
            # Integral of trapezoid over full bin i
            # Area = (sigma_i + sigma_{i+1}) / 2 * delta_i
            bin_integral = (sigmas[i] + sigmas[i+1]) / 2.0 * deltas[i]
            
            if current_integral + bin_integral >= Y:
                # Found bin i
                # Solve quadratic: A * dt^2 + B * dt + C = 0
                # A = (sigma_{i+1} - sigma_i) / (2 * delta_i)
                # B = sigma_i
                # C = current_integral - Y
                
                A = (sigmas[i+1] - sigmas[i]) / (2.0 * deltas[i])
                B = sigmas[i]
                C = current_integral - Y
                
                if A == 0:
                    # Linear case (constant density in bin)
                    if B == 0:
                        return grid[i]
                    dt = -C / B
                else:
                    # Quadratic formula
                    discriminant = B*B - 4*A*C
                    if discriminant < 0:
                        # Numerical error or invalid Y, clamp to bin end
                        dt = deltas[i]
                    else:
                        sqrt_d = math.sqrt(discriminant)
                        # Two roots. We want the one in [0, delta_i].
                        # Since I(t) is monotonic increasing, and we are inside the bin,
                        # the smaller positive root is typically the solution if A > 0.
                        # If A < 0, the parabola opens downward, but I(t) must still be monotonic.
                        # Standard quadratic formula:
                        root1 = (-B + sqrt_d) / (2 * A)
                        root2 = (-B - sqrt_d) / (2 * A)
                        
                        # Select valid root
                        if 0 <= root1 <= deltas[i]:
                            dt = root1
                        elif 0 <= root2 <= deltas[i]:
                            dt = root2
                        else:
                            # Fallback
                            dt = deltas[i]
                            
                t = grid[i] + dt
                return t
                
            current_integral += bin_integral
            
    # Fallback if Y is beyond total integral
    return t_far
```

**Edge Cases and Pitfalls:**
*   **Zero Density:** If $\sigma_i = 0$ in PWC, division by zero occurs in step 6. Handle by returning the start of the bin or skipping [S1, S2, unofficial].
*   **Monotonicity:** The approximations $I_0(t)$ and $I_1(t)$ are monotonic only if $\sigma_r(t) \ge 0$. The sources note that for non-negative fields, the approximations are non-negative [S1, S2, unofficial]. If density can be negative, the inversion may fail or yield non-unique solutions.
*   **Precision:** Solving the quadratic equation for PWL requires care with floating-point precision, especially when $A$ is very small (near-constant density) [S1, S2, unofficial].

## Subtopics

### Piecewise Constant Approximation (PWC)
Approximates density as constant within each grid bin. Simpler to implement and faster to evaluate, but less accurate for smooth density fields. Predominant in NeRF literature [S2, unofficial].

### Piecewise Linear Approximation (PWL)
Approximates density as linearly interpolated between grid points. Provides higher accuracy for smooth fields and results in a piecewise quadratic cumulative integral. More complex to invert (requires solving quadratic equations) [S1, S2, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(m)$ to find the correct bin, where $m$ is the number of grid bins. The inversion within the bin is $O(1)$ for PWC and $O(1)$ for PWL (quadratic solve).
*   **Memory Complexity:** $O(m)$ to store the grid and precomputed densities.
*   **Strengths:** Enables analytical inversion of the opacity function, allowing for differentiable rendering with respect to the density field $\sigma_r$ [S1, S2, unofficial]. The resulting sample locations are differentiable functions of the density [S1, unofficial].
*   **Limitations:** Accuracy depends on the grid resolution $m$. Coarse grids may alias high-frequency density variations. The random sampling of $\hat{t}_j$ in PWC (as per [S2, unofficial]) introduces variance if not averaged, though deterministic choices (midpoint) are common [S1, S2, unofficial].
*   **When to use:** When differentiable volume sampling is required, or when analytical inversion is preferred over numerical root-finding. Suitable for NeRF training and differentiable rendering pipelines [S1, S2, unofficial].

## Background
The method originates from the work on differentiable rendering with reparameterized volume sampling. It was introduced to address the difficulty of sampling from the opacity distribution $F_r(t)$ analytically. By approximating the density field, the integral becomes a simple polynomial (linear or quadratic) within each bin, allowing for closed-form inversion [S1, S2, unofficial]. The approach is widely used in neural radiance fields (NeRF) and related differentiable rendering techniques [S2, unofficial].
