# Linear Opacity Interpolation

Also called: Grey-value based opacity mapping, Linear Opacity Transfer Function, OTF, Scalar Opacity Transfer Function, Scalar-Based Opacity Transfer Function, pokrytie

## Overview
Linear Opacity Interpolation maps scalar volume data values to opacity using linear interpolation between two threshold values [S3, unofficial]. It solves the problem of isolating objects of interest by assigning high opacity to grey values inside the object and low or zero opacity to surrounding values [S2, unofficial]. It sets itself apart from its siblings by using simple linear interpolation between two thresholds, whereas [Piecewise Function Scalar Opacity Transfer](12435-piecewise-function-scalar-opacity-transfer.md) supports arbitrary piecewise definitions and [Piecewise Linear Opacity Mapping with Gradient Scaling](1335-piecewise-linear-opacity-mapping-with-gradient-scaling.md) incorporates gradient information [S2, unofficial].

## How it works
**Inputs and Outputs**
*   **Input**: Scalar volume value $i$ (or $F$) at a sample position.
*   **Parameters**:
    *   $oa, ob$: Lower and upper thresholds (integer/UINT16) [S3, unofficial].
    *   $foa, fob$: Opacity values at thresholds $oa$ and $ob$ respectively (float, typically $0.0$ to $1.0$) [S3, unofficial].
    *   $f_{min}, f_{max}$: Global minimum and maximum data values defining the full range [S1, S4].
    *   $N$: Number of intervals in the opacity array [S1, S4].
    *   $\alpha_{min}, \alpha_{max}$: Minimum and maximum opacity values [S1, S4].
*   **Output**: Opacity $\alpha \in [0, 1]$ [S3, unofficial].

**Data Structures**
The method can be implemented via direct calculation or a pre-established look-up table (LUT) array $O$ [S1][S2, unofficial].
*   **Array $O$**: Size $N+1$.
*   **Layout**: $O[i]$ stores the opacity value corresponding to the $i$-th interval index.
*   **Formula for Array Construction**:
    $$ O[i] = \alpha_{min} + \frac{\alpha_{max} - \alpha_{min}}{N} \times i, \quad 0 \leq i \leq N $$
    [S1, S4]

**Steps**
1.  **Direct Calculation Method**:
    1.  If input $i$ is outside the range $[oa, ob]$, return $0.0$ [S3, unofficial].
    2.  Otherwise, compute $\alpha$ using linear interpolation between $(oa, foa)$ and $(ob, fob)$:
        $$ \alpha = foa + (fob - foa) \frac{i - oa}{ob - oa} $$
        [S3, unofficial]

2.  **Array-Based (LUT) Method**:
    1.  Pre-establish array $O$ of size $N+1$ using the formula above [S1, S4].
    2.  Calculate step size $\Delta f$:
        $$ \Delta f = \frac{f_{max} - f_{min}}{N} $$
        [S1, S4]
    3.  Map input data value $F$ to array index $n$:
        $$ n = \begin{cases} 0 & F < f_{min} \\ \frac{F - f_{min}}{\Delta f} & f_{min} \leq F \leq f_{max} \\ N & F > f_{max} \end{cases} $$
        [S1, S4]
    4.  Retrieve opacity from array: $\alpha = O[n]$ [S1].

**Pseudocode**
```python
def linear_opacity_interpolation_direct(i: int, oa: int, ob: int, foa: float, fob: float) -> float:
    """
    Direct calculation of opacity using linear interpolation between two thresholds.
    """
    if i < oa or i > ob:
        return 0.0
    # Linear interpolation
    return foa + (fob - foa) * (i - oa) / (ob - oa)

def linear_opacity_interpolation_lut(F: float, f_min: float, f_max: float, 
                                     alpha_min: float, alpha_max: float, 
                                     N: int) -> float:
    """
    Opacity lookup using a pre-established linear array.
    """
    # Calculate step size
    delta_f = (f_max - f_min) / N
    
    # Map data value F to index n
    if F < f_min:
        n = 0
    elif F > f_max:
        n = N
    else:
        n = (F - f_min) / delta_f
        
    # Note: In a real implementation, n would be clamped to integer bounds [0, N]
    # and the array O would be pre-computed.
    # O[i] = alpha_min + (alpha_max - alpha_min) / N * i
    
    # Return opacity from array O at index n
    # Since O is not passed, we compute it directly here for self-containment
    # Clamping n to valid range [0, N]
    n_clamped = max(0, min(N, int(n)))
    opacity = alpha_min + (alpha_max - alpha_min) / N * n_clamped
    return opacity
```

**Edge Cases and Pitfalls**
*   **Division by Zero**: If $oa = ob$ in the direct method, the denominator $(ob - oa)$ becomes zero. The sources do not specify a guard for this degenerate case [S3, unofficial]. [G] In practice, if $oa = ob$, the opacity should likely be constant or undefined; a safe implementation would check for this and return $foa$ or $0.0$.
*   **Precision**: The array-based method relies on floating-point division for index calculation. Precision errors may cause $n$ to slightly exceed $N$ or be negative before clamping [S1, S4]. [G] Explicit clamping of $n$ to $[0, N]$ is required before array access.
*   **Data Range**: If the input data $F$ falls outside $[f_{min}, f_{max}]$, the index $n$ is clamped to $0$ or $N$ [S1, S4].

## Operating characteristics
*   **Time Complexity**: $O(1)$ for both direct calculation and LUT lookup, assuming constant-time arithmetic or array access [S1][S3, unofficial].
*   **Memory Complexity**: $O(N)$ for the LUT-based approach, where $N$ is the number of intervals [S1, S4]. The direct method uses $O(1)$ memory.
*   **Strengths**: Simple to implement; efficient; effective for isolating objects with distinct grey values [S2, unofficial].
*   **Limitations**: Cannot model complex opacity transitions or non-linear relationships; sensitive to the choice of thresholds $oa, ob$ [S3, unofficial].
*   **When to Use**: When the object of interest has a grey value significantly different from its surroundings [S2, unofficial].
*   **When Not to Use**: When complex opacity variations or gradient-based transparency are required [S2, unofficial].

## Background
The method was described in works focusing on volume rendering visualization, particularly for explosion field features and medical applications [S1, S4][S2, unofficial]. It is based on the principle that opacity transfer functions can be linearly approximated, allowing for pre-established arrays or simple interpolation to map data values to opacity [S1, S4]. The approach avoids trial-and-error coefficient modification by using a structured linear mapping [S1, S4].
