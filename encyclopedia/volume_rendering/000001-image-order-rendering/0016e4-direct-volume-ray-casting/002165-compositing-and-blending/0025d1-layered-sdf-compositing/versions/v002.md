# Layered SDF Compositing


## Overview
Layered SDF Compositing is a method for rendering Signed Distance Field (SDF) glyphs by compositing multiple layers (typically a face and one or more outline layers) using alpha blending and pre-multiplied alpha handling [S1, unofficial]. It differs from standard volume ray casting by operating on discrete, pre-sampled layers of a 2D texture atlas rather than continuous 3D volume data, allowing for efficient, sharp text rendering with variable-width outlines [S1, unofficial].

## How it works
The method composites up to four layers (Layer0 to Layer3) corresponding to the SDF face and up to three outline rings. Each layer provides a color and an alpha value. The compositing is performed in a specific order, typically from the outermost layer (Layer3) to the innermost (Layer0), or vice versa depending on the implementation's accumulation strategy. The provided notes describe a specific accumulation order where `outColor` is updated iteratively.

**Inputs:**
- `color0` to `color3`: RGB colors for each layer.
- `alpha0` to `alpha3`: Alpha values for each layer.
- `alpha`: A scalar multiplier for the final alpha (often 1.0 or a global opacity setting).

**Outputs:**
- `outColor`: The final pre-multiplied RGB color.
- `outAlpha`: The final accumulated alpha.

**Data Structures:**
The inputs are typically stored as vectors or structs. For Layer4, four sets of color/alpha pairs are required.

**Edge Cases and Pitfalls:**
-   **Division by Zero:** If `outColor.a` is 0, division by zero occurs. A guard is required to return black or transparent.
-   **Precision:** Premultiplying and then dividing can lead to precision loss, especially with low alpha values.
-   **Order of Operations:** The order of layers (inner to outer or outer to inner) is critical. The source implies a specific order (Layer0 to Layer3 in the lerp chain, but the lerp is `lerp(outer, inner, weight)`).

## Subtopics

### [SDF Underlay & Inner Underlay](5612-sdf-underlay-inner-underlay.md)
SDF Underlay & Inner Underlay renders a blurred, colored border either behind (underlay) or inside (inner underlay) the primary glyph face by sampling the Signed Distance Field (SDF) atlas at an offset UV coordinate, scaling the distance, and blending it with the face color using pre-multiplied alpha. It differs from standard outline methods by allowing the border to be offset in UV space independently of the glyph geometry and by supporting "inner" rendering where the border appears within the filled region of the character.

## Operating characteristics
-   **Time Complexity:** O(1) per pixel, as it involves a fixed number of texture lookups and arithmetic operations (up to 4 layers).
-   **Memory Complexity:** O(1) per pixel, storing only the current accumulated color and alpha.
-   **Strengths:** Efficient, sharp text rendering, supports variable-width outlines, easy to implement in shaders.
-   **Limitations:** Limited to 4 layers, requires pre-sampled SDF atlas, may suffer from aliasing if not filtered properly.

## Background
Layered SDF Compositing is used in modern text rendering engines, particularly those using Signed Distance Fields for scalable text. It is implemented in libraries like Unity NanoVDB Renderer [S1, unofficial].
