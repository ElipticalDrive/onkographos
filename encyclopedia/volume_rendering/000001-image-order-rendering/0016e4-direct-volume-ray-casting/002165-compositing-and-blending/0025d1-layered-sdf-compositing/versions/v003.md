# Layered SDF Compositing
## Overview
Layered SDF Compositing is a method for rendering Signed Distance Field (SDF) glyphs by compositing multiple layers (typically a face and one or more outline layers) using alpha blending and pre-multiplied alpha handling [S1, unofficial]. It differs from standard volume ray casting by operating on discrete, pre-sampled layers of a 2D texture atlas rather than continuous 3D volume data, allowing for efficient, sharp text rendering with variable-width outlines [S1, unofficial].
## How it works
**Inputs:**
- `color0` to `color3`: RGB color vectors for each layer.
- `alpha0` to `alpha3`: Scalar alpha values for each layer.
- `alpha`: A scalar global opacity multiplier for Layer1, or a vector `[alpha0, alpha1, alpha2, alpha3]` for Layer2 and Layer4.

**Outputs:**
- `outColor`: The final un-premultiplied RGB color.
- `outAlpha`: The final accumulated scalar alpha.

**Data Structures:**
Inputs are passed as vectors or structs. The accumulator state is a 4D vector `(outColor.rgb, outColor.a)` where `.rgb` holds the blended color and `.a` holds the accumulated alpha [S1, unofficial].

**Steps:**
1. **Layer 1 (Face only):** Multiply `color0.a` by the scalar `alpha`. Set `outColor` to `color0` [S1, unofficial].
2. **Layer 2 (Face + 1 Outline):** Multiply `color1.a` by `alpha.y`. Premultiply `color0.rgb` by `color0.a` and `color1.rgb` by `color1.a`. Compute `outColor = lerp(color1, color0, alpha.x)`. Divide `outColor.rgb` by `outColor.a` [S1, unofficial].
3. **Layer 4 (Face + 3 Outlines):** Multiply `color3.a` by `alpha.w`. Premultiply all color RGBs by their respective alphas. Compute `outColor = lerp(lerp(lerp(color3, color2, alpha.z), color1, alpha.y), color0, alpha.x)`. Divide `outColor.rgb` by `outColor.a` [S1, unofficial].

**Pseudocode:**
```python
def lerp(a, b, t):
    return a * (1.0 - t) + b * t

def composite_layer1(color0, alpha_global):
    out_alpha = color0.a * alpha_global
    out_color = color0.rgb
    return out_color, out_alpha

def composite_layer2(color0, color1, alpha_vec):
    a0, a1 = alpha_vec.x, alpha_vec.y
    # Scale alpha1
    a1_scaled = color1.a * a1
    # Premultiply RGBs
    c0_premult = color0.rgb * color0.a
    c1_premult = color1.rgb * color1.a
    # Lerp (standard linear interpolation on RGB)
    out_color = lerp(c1_premult, c0_premult, a0)
    # Accumulate alpha (standard front-to-back) [G]
    out_alpha = a0 + a1_scaled * (1.0 - a0)
    # Un-premultiply
    if out_alpha > 1e-6:
        out_color = out_color / out_alpha
    else:
        out_color = (0.0, 0.0, 0.0)
    return out_color, out_alpha

def composite_layer4(color0, color1, color2, color3, alpha_vec):
    a0, a1, a2, a3 = alpha_vec.x, alpha_vec.y, alpha_vec.z, alpha_vec.w
    # Scale alpha3
    a3_scaled = color3.a * a3
    # Premultiply all RGBs
    c0_p = color0.rgb * color0.a
    c1_p = color1.rgb * color1.a
    c2_p = color2.rgb * color2.a
    c3_p = color3.rgb * color3.a
    # Nested lerp
    temp1 = lerp(c3_p, c2_p, a2)
    temp2 = lerp(temp1, c1_p, a1)
    out_color = lerp(temp2, c0_p, a0)
    # Accumulate alpha (standard front-to-back) [G]
    a_temp = a3_scaled + a2 * (1.0 - a3_scaled)
    a_temp = a_temp + a1 * (1.0 - a_temp)
    out_alpha = a_temp + a0 * (1.0 - a_temp)
    # Un-premultiply
    if out_alpha > 1e-6:
        out_color = out_color / out_alpha
    else:
        out_color = (0.0, 0.0, 0.0)
    return out_color, out_alpha
```

**Edge Cases and Pitfalls:**
- **Division by Zero:** If `outColor.a` is 0, division by zero occurs. A guard is required to return black or transparent [G].
- **Precision:** Premultiplying and then dividing can lead to precision loss, especially with low alpha values [G].
- **Order of Operations:** The order of layers (inner to outer or outer to inner) is critical. The source implies a specific order (Layer0 to Layer3 in the lerp chain, but the lerp is `lerp(outer, inner, weight)`).
## Subtopics

### [SDF Underlay & Inner Underlay](5612-sdf-underlay-inner-underlay.md)
SDF Underlay & Inner Underlay renders a blurred, colored border either behind (underlay) or inside (inner underlay) the primary glyph face by sampling the Signed Distance Field (SDF) atlas at an offset UV coordinate, scaling the distance, and blending it with the face color using pre-multiplied alpha. It differs from standard outline methods by allowing the border to be offset in UV space independently of the glyph geometry and by supporting "inner" rendering where the border appears within the filled region of the character.

## Operating characteristics
- **Time Complexity:** O(1) per pixel, as it involves a fixed number of texture lookups and arithmetic operations (up to 4 layers) [S1, unofficial].
- **Memory Complexity:** O(1) per pixel, storing only the current accumulated color and alpha [S1, unofficial].
- **Strengths:** Efficient, sharp text rendering, supports variable-width outlines, easy to implement in shaders [S1, unofficial].
- **Limitations:** Limited to 4 layers, requires pre-sampled SDF atlas, may suffer from aliasing if not filtered properly [S1, unofficial].
## Background
Layered SDF Compositing is used in modern text rendering engines, particularly those using Signed Distance Fields for scalable text. It is implemented in libraries like Unity NanoVDB Renderer [S1, unofficial].
