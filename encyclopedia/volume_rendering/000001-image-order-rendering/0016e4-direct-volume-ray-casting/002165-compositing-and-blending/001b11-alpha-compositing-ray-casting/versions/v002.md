# Alpha Compositing Ray Casting

Also called: Front-to-back compositing, Front-to-back ray casting, Volume Compositing, Volumetric Compositing

## Overview
Alpha Compositing Ray Casting projects a semi-transparent 3D scalar field onto a 2D image plane by integrating optical properties along viewing rays, eliminating the need for binary classification of the data [S2]. It differs from Maximum Intensity Projection (MIP) by preserving internal texture and visibility through opacity-weighted accumulation rather than selecting only the highest intensity value [S1].

## How it works
The method discretizes the volume rendering integral into a summation over sample points along a ray, performing front-to-back compositing [S2, S3, S5].

### Inputs and Outputs
*   **Inputs**:
    *   `volume_texture`: 3D array or texture storing scalar voxel values.
    *   `camera`: Defines ray origins and directions for each pixel.
    *   `transfer_function`: Maps scalar values to RGBA color and opacity. Implemented as a 2D texture in WebGL contexts [S3] or a function in software [S2].
    *   `step_size`: Fixed distance between samples, or derived from volume dimensions [S3].
    *   `threshold`: Opacity threshold for early ray termination (typically 0.95–0.99) [S2, S3].
*   **Outputs**:
    *   `image`: 2D array of RGB values representing the final rendered frame.

### Data Structures
*   **Volume Texture**: 3D array of scalar values. In WebGL implementations, sampled using `texture(volume, p)` [S3].
*   **Transfer Function**: 2D texture where the x-coordinate is the scalar value and y-coordinate is fixed (e.g., 0.5) [S3]. Output is RGBA.
*   **Accumulators**:
    *   `accumulated_color` ($C'$): `vec3`, initialized to $(0, 0, 0)$.
    *   `accumulated_opacity` ($\alpha'$): `float`, initialized to $0.0$.

### Steps
1.  **Ray Initialization**: For each pixel, compute ray origin $\bar{o}$ and direction $\bar{d}$ [G].
2.  **Bounding Box Intersection**: Intersect the ray with the volume bounds $[0,1]^3$ to find entry $t_0$ and exit $t_1$ [S3]. If $t_0 > t_1$, discard the pixel. If the eye is inside the volume, clamp $t_0$ to $0.0$ [S3].
3.  **Step Size Calculation**: Compute step size $dt$ based on volume dimensions $V_{dim}$ and ray direction $\bar{d}$:
    $$ dt = \min \left( \frac{1}{V_{dim,x} |d_x|}, \frac{1}{V_{dim,y} |d_y|}, \frac{1}{V_{dim,z} |d_z|} \right) $$
    [S3].
4.  **Ray Marching Loop**: Iterate from $t = t_0$ to $t < t_1$ with increment $dt$:
    a.  **Sample**: Evaluate scalar value $s$ at position $\bar{p} = \bar{o} + t\bar{d}$ using trilinear interpolation [S1, S5].
    b.  **Transfer Function**: Map $s$ to color $\bar{c}_i$ and opacity $\alpha_i$. In some WebGL implementations, the opacity $\alpha_i$ is taken directly from the scalar value $s$, ignoring the transfer function's alpha channel [S3]. In standard implementations, $\alpha_i$ comes from the transfer function [S2, S5].
    c.  **Compositing**: Update accumulators:
        $$ C'_i = C'_{i-1} + (1 - \alpha'_{i-1}) \alpha_i \bar{c}_i $$
        $$ \alpha'_i = \alpha'_{i-1} + (1 - \alpha'_{i-1}) \alpha_i $$
        [S2, S5].
    d.  **Early Termination**: If $\alpha' \ge \text{threshold}$ (e.g., 0.95 or 0.99), break the loop [S2, S3].
5.  **Gamma Correction**: Apply gamma correction (typically 2.2) to the final accumulated color:
    $$ \bar{C}_{final} = \bar{C}'_{last}^{1/2.2} $$
    [S2].

### Pseudocode
```python
def alpha_compositing_raycast(volume_texture, camera, transfer_function, volume_dims, step_size=None, threshold=0.99):
    """
    Renders a volume using front-to-back alpha compositing.
    
    Args:
        volume_texture: 3D array or texture object supporting trilinear sampling.
        camera: Object with method cast_ray(x, y) returning (origin, direction).
        transfer_function: Function or 2D texture mapping scalar value -> (color, opacity).
        volume_dims: Tuple (dim_x, dim_y, dim_z) of the volume grid.
        step_size: Fixed marching distance. If None, derived from volume_dims.
        threshold: Opacity threshold for early ray termination.
        
    Returns:
        image: 2D list of RGB values.
    """
    H, W = camera.height, camera.width
    image = [[0.0, 0.0, 0.0] for _ in range(H)]
    
    for y in range(H):
        for x in range(W):
            ray_origin, ray_direction = camera.cast_ray(x, y)
            ray_direction = normalize(ray_direction)
            
            accumulated_color = [0.0, 0.0, 0.0]
            accumulated_opacity = 0.0
            
            if step_size is None:
                dir_abs = [max(abs(d), 1e-6) for d in ray_direction]
                dt_vec = [1.0 / (volume_dims[i] * dir_abs[i]) for i in range(3)]
                step_size = min(dt_vec)
                
            inv_dir = [1.0 / d if abs(d) > 1e-6 else 1e6 for d in ray_direction]
            box_min = [0.0, 0.0, 0.0]
            box_max = [1.0, 1.0, 1.0]
            tmin_tmp = [(box_min[i] - ray_origin[i]) * inv_dir[i] for i in range(3)]
            tmax_tmp = [(box_max[i] - ray_origin[i]) * inv_dir[i] for i in range(3)]
            tmin = [min(tmin_tmp[i], tmax_tmp[i]) for i in range(3)]
            tmax = [max(tmin_tmp[i], tmax_tmp[i]) for i in range(3)]
            t0 = max(tmin)
            t1 = min(tmax)
            
            if t0 > t1:
                continue
            t0 = max(t0, 0.0)
            
            t = t0
            while t < t1 and accumulated_opacity < threshold:
                pos = [ray_origin[i] + t * ray_direction[i] for i in range(3)]
                scalar_value = volume_texture.sample_trilinear(pos)
                color, opacity = transfer_function(scalar_value)
                
                accumulated_color[0] += (1.0 - accumulated_opacity) * opacity * color[0]
                accumulated_color[1] += (1.0 - accumulated_opacity) * opacity * color[1]
                accumulated_color[2] += (1.0 - accumulated_opacity) * opacity * color[2]
                accumulated_opacity += (1.0 - accumulated_opacity) * opacity
                
                t += step_size
                
            image[y][x] = [c ** (1.0/2.2) for c in accumulated_color]
            
    return image
```

### Parameters and Edge Cases
*   **Threshold**: Typically 0.95 [S3] or 0.99 [S2]. Higher thresholds improve accuracy but increase computation.
*   **Normal Discontinuities**: Gradients for shading (if used) should use a two-voxel offset to avoid rings on smooth surfaces [S1, S3].
*   **Numerical Stability**: In some variants, a small epsilon ($\epsilon = 10^{-10}$) is added to the product term to prevent instability [S5].
*   **Zero Direction Components**: If a ray direction component is zero, the step size calculation must clamp it to a small positive value to avoid division by zero [G].

## Operating characteristics
*   **Time Complexity**: $O(N \cdot M)$, where $N$ is the number of pixels and $M$ is the number of samples per ray. $M$ depends on volume depth and step size [G].
*   **Memory Complexity**: $O(V)$ for the volume texture, where $V$ is the number of voxels [G].
*   **Performance**: Real-time rendering is achievable with hardware acceleration (e.g., WebGL fragment shaders) [S3]. Software implementations may be slow without optimization [S1].
*   **Strengths**: Preserves internal structure and texture better than MIP [S2]. No binary classification required, reducing false positives/negatives [S1].
*   **Limitations**: Computationally expensive for large volumes or high resolutions. Sensitive to transfer function design.

## Background
The technique was popularized by Drebin et al. [S2], who introduced volumetric compositing to eliminate binary classification artifacts. It became a standard in volume rendering pipelines, enabling real-time rendering through hardware frameworks [S2]. It is widely used in medical imaging and scientific visualization [G].
