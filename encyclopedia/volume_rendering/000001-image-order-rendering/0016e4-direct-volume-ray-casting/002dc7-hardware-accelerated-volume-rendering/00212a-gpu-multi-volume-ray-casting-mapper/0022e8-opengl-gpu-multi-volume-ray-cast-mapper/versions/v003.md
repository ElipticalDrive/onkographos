# OpenGL GPU Multi Volume Ray Cast Mapper

Also called: OpenGL GPU Multi-Volume Ray Casting Mapper, OpenGL Volume Ray Caster, vtkOpenGLGPUMultiVolumeRayCastMapper

## Overview
The OpenGL GPU Multi Volume Ray Cast Mapper is an OpenGL-specific subclass of the GPU Multi-Volume Ray Casting Mapper that handles hardware extension checks, OpenGL object lifecycle management, and clipping/cropping plane setup for GPU-accelerated volume rendering [S1, unofficial]. It serves as the concrete implementation responsible for drawing the volume ray cast image to the screen by managing fragment shader programs, framebuffer objects, and texture uploads required for rendering multiple volumes simultaneously [S2, unofficial]. It builds on [GPU Multi-Volume Ray Casting Mapper](2461-gpu-multi-volume-ray-casting-mapper.md) by providing the specific OpenGL API bindings and state management necessary for hardware-accelerated ray casting [S1, unofficial].

## How it works
The method initializes OpenGL resources, validates hardware support, uploads volume data and transfer functions to GPU textures, applies clipping/cropping constraints, and executes a fragment shader-based ray casting pass into an offscreen framebuffer before presenting the result [S1, unofficial][S2, unofficial].

### Inputs and Outputs
- **Inputs**: 
  - Primary volume data (`vtkImageData`), optional secondary volume data (`vtkImageData`), and up to `MAX_NUMBER_OF_ADDITIONAL_VOLUMES` additional volumes [S1, unofficial].
  - Volume properties including color transfer functions, opacity transfer functions, and blend types (MIP, Composite, Shaded, etc.) [S2, unofficial].
  - Clipping planes (`vtkPlane*`) and cropping region bounds for each volume [S1, unofficial].
  - Render window and renderer context [S2, unofficial].
- **Outputs**: 
  - A rendered image displayed on the screen, generated via an offscreen framebuffer object (FBO) [S2, unofficial].

### Data Structures
- **Clipping Planes**: `ClippingPlane[MAX_NUMBER_OF_ADDITIONAL_VOLUMES+1]` stores pointers to `vtkPlane` objects for the primary and additional volumes [S1, unofficial].
- **State Flags**: 
  - `Clipped[MAX_NUMBER_OF_ADDITIONAL_VOLUMES+1]`, `Cropped[MAX_NUMBER_OF_ADDITIONAL_VOLUMES+1]`, `ClippedModified[MAX_NUMBER_OF_ADDITIONAL_VOLUMES+1]`: Integer flags tracking the clipping/cropping state and modification status per volume [S1, unofficial].
- **Cropping Bounds**: `CroppingLowBounds[MAX_NUMBER_OF_ADDITIONAL_VOLUMES+1][3]` and `CroppingHighBounds[MAX_NUMBER_OF_ADDITIONAL_VOLUMES+1][3]` store 3D bounding box coordinates for cropping regions per volume [S1, unofficial].
- **Transformed Inputs**: `TransformedInput`, `TransformedInput2`, and `AdditionalTransformedInput` array store shallow copies of input data with adjusted extents to handle non-zero starting extents [S1, unofficial].
- **Last Input Tracking**: `LastInput`, `LastInput2`, and `AdditionalLastInput` arrays track previous inputs to detect data changes [S2, unofficial].
- **Reduction Factor**: `ReductionFactor` (double, 0.0 to 1.0) used to scale the render viewport based on performance [S2, unofficial].

### Numbered Steps
1. **Check Hardware Support**: Call `IsRenderSupported(window, property)` to verify that the hardware supports 3D texture mapping and required OpenGL extensions for the given render window and volume property. Returns 1 if supported, 0 otherwise [S1, unofficial].
2. **Load Extensions**: Call `LoadExtensions(window)` to load required and optional OpenGL extensions. Sets `Supports_GL_ARB_texture_float` if the extension is loaded [S2, unofficial].
3. **Test Required Extensions**: For each required extension, call `TestRequiredExtension(extension_name)`. If an extension is not supported, add its name to the unsupported extensions string. Returns 1 if supported, 0 otherwise [S1, unofficial].
4. **Create OpenGL Objects**: Call `CreateOpenGLObjects(ren)` to create OpenGL objects such as textures, buffers, and fragment program IDs [S2, unofficial].
5. **Allocate Framebuffers**: Call `AllocateFrameBuffers(ren)` to allocate GPU memory for framebuffers based on the window size [S2, unofficial].
6. **Prepare Input Data**: 
   - Validate that at least one input is not NULL [S1, unofficial].
   - Update all input data (`input`, `input2`, and additional inputs) [S1, unofficial].
   - If the input has changed (timestamp or data), create shallow copies in `TransformedInput`, `TransformedInput2`, and `AdditionalTransformedInput` arrays [S1, unofficial].
   - Adjust extents to handle non-zero starting values: 
     - Get origin and spacing [S1, unofficial].
     - Adjust origin: `origin[cc] = origin[cc] + extents[2*cc]*spacing[cc]` for `cc` in 0..2 [S1, unofficial].
     - Adjust extents: `extents[2*cc+1] -= extents[2*cc]` and `extents[2*cc] -= extents[2*cc]` for `cc` in 0..2 [S1, unofficial].
     - Set adjusted origin and extents in the cloned data [S1, unofficial].
7. **Load Scalar Field Data**: Call `LoadScalarField(input, input2, textureExtent, volume)` to load scalar field data into a 3D texture on the GPU. Handles point or cell-based extents [S2, unofficial].
8. **Update Transfer Functions**: 
   - Call `UpdateColorTransferFunction(vol, numberOfScalarComponents)` to update the color transfer function on the GPU [S2, unofficial].
   - Call `UpdateOpacityTransferFunction(vol, numberOfScalarComponents, level)` to update the opacity transfer function on the GPU [S2, unofficial].
9. **Clip Bounding Box**: Call `ClipBoundingBox(ren, worldBounds, vol)` to clip the bounding box with clipping planes and near/far planes [S2, unofficial].
10. **Check Cropping Planes**: If cropping is enabled, validate that cropping planes are valid (i.e., `CroppingRegionPlanes[0] < CroppingRegionPlanes[1]`, etc.). If invalid, silently fail by setting `goodSoFar = 0` [S1, unofficial].
11. **Render Volume**: 
    - Compute the reduction factor using `ComputeReductionFactor(allocatedTime)` based on previous frame time and allocated time [S2, unofficial].
    - Render the volume using one of: `RenderWholeVolume(ren, vol)`, `RenderRegions(ren, vol)`, or `RenderSubVolume(ren, bounds, vol)` [S2, unofficial].
    - Load projection parameters using `LoadProjectionParameters(ren, vol)` [S2, unofficial].
    - Compute the number of cropping regions using `ComputeNumberOfCroppingRegions()` [S2, unofficial].
12. **Copy FBO to Texture**: Call `CopyFBOToTexture()` to copy the color buffer state from the framebuffer object to a texture [S2, unofficial].
13. **Render to Screen**: Call `RenderTextureToScreen(ren)` to render the offscreen buffer to the screen [S2, unofficial].
14. **Release Resources**: Call `ReleaseGraphicsResources()` to delete OpenGL objects. Post-condition: `OpenGLObjectsCreated == 0` [S1, unofficial].

### Formulas
- **Origin Adjustment**: 
  $$ origin[cc] = origin[cc] + extents[2 \times cc] \times spacing[cc] $$
  for $cc \in \{0, 1, 2\}$ [S1, unofficial].
- **Extent Adjustment**: 
  $$ extents[2 \times cc + 1] = extents[2 \times cc + 1] - extents[2 \times cc] $$
  $$ extents[2 \times cc] = 0 $$
  for $cc \in \{0, 1, 2\}$ [S1, unofficial].
- **Reduction Factor**: Computed by `ComputeReductionFactor(allocatedTime)` based on previous frame time and allocated time. Value is between 0.0 and 1.0 [S2, unofficial].
- **Power of Two**: `PowerOfTwoGreaterOrEqual(x)` computes the smallest power of two greater than or equal to $x$ [S2, unofficial].

### Parameters
- **ClippingPlane[MAX_NUMBER_OF_ADDITIONAL_VOLUMES+1]**: Array of `vtkPlane*` pointers for clipping planes [S1, unofficial].
- **CroppingLowBounds[MAX_NUMBER_OF_ADDITIONAL_VOLUMES+1][3]** and **CroppingHighBounds[MAX_NUMBER_OF_ADDITIONAL_VOLUMES+1][3]**: 3D bounding box coordinates for cropping regions [S1, unofficial].
- **ReductionFactor**: Double value between 0.0 and 1.0 for viewport reduction [S2, unofficial].
- **FrameRate**: Desired frame rate in frames per second (default 10.0, range 0.01 to 60.0) [S2, unofficial].
- **BlendType**: Enum for blend function (MIP=0, Composite=1, CompositeShadeRamp=2, CT_Skin=3, CT_Bone=4, CT_Muscle=5, RGB_Composite=6) [S2, unofficial].
- **OpacityWindow** and **OpacityLevel**: Double values for opacity transfer function window and level (default 4096 and 2048) [S2, unofficial].

### Edge Cases and Pitfalls
- **Invalid Cropping Planes**: If cropping planes define a zero or negative volume (e.g., due to interactive widget dragging), the renderer silently fails by setting `goodSoFar = 0` without error messages [S1, unofficial].
- **NULL Inputs**: Checks if `input`, `input2`, or any `Additionalinput` is NULL; if so, outputs an error message and fails [S1, unofficial].
- **Color Channels**: If color channels are not 3, the renderer may fail or produce incorrect results (commented out in some versions) [S1, unofficial].
- **Non-Zero Extents**: The mapper requires workarounds for GPU volume ray casting mappers that cannot handle extents starting from non-zero values, necessitating extent adjustment [S1, unofficial].
- **Four-Component Data**: The shader handles four-component data (RGBA) by extracting scalar values from the alpha channel and computing colors from RGB, but this may not work correctly if color transfer functions are not properly configured [S2, unofficial].

### Pseudocode
```python
def OpenGLGPUMultiVolumeRayCastMapper_Render(window, property, volumes, clipping_planes, cropping_bounds):
    # Step 1: Check hardware support
    if not IsRenderSupported(window, property):
        return False

    # Step 2: Load extensions
    LoadExtensions(window)
    Supports_GL_ARB_texture_float = TestRequiredExtension("GL_ARB_texture_float")

    # Step 3: Create OpenGL objects
    CreateOpenGLObjects(window.renderer)
    AllocateFrameBuffers(window.renderer)

    # Step 4: Prepare input data
    for vol in volumes:
        if vol.input is None:
            return False
        vol.input.Update()
        
        # Check for data change
        if vol.input != vol.LastInput or vol.input.GetMTime() > vol.TransformedInput.GetMTime():
            vol.TransformedInput.ShallowCopy(vol.input)
            
            # Adjust extents for non-zero starting values
            extents = vol.TransformedInput.GetExtent()
            origin = vol.TransformedInput.GetOrigin()
            spacing = vol.TransformedInput.GetSpacing()
            
            for cc in range(3):
                origin[cc] = origin[cc] + extents[2*cc] * spacing[cc]
                extents[2*cc+1] = extents[2*cc+1] - extents[2*cc]
                extents[2*cc] = 0
            
            vol.TransformedInput.SetOrigin(origin)
            vol.TransformedInput.SetExtent(extents)
            
            vol.LastInput = vol.input

    # Step 5: Load scalar field data
    for vol in volumes:
        LoadScalarField(vol.TransformedInput, vol.TransformedInput2, vol.textureExtent, vol)

    # Step 6: Update transfer functions
    for vol in volumes:
        UpdateColorTransferFunction(vol, vol.numberOfScalarComponents)
        UpdateOpacityTransferFunction(vol, vol.numberOfScalarComponents, vol.level)

    # Step 7: Clip bounding box
    for vol in volumes:
        ClipBoundingBox(window.renderer, vol.worldBounds, vol)

    # Step 8: Check cropping planes
    if vol.Cropping:
        if (vol.CroppingRegionPlanes[0] >= vol.CroppingRegionPlanes[1] or
            vol.CroppingRegionPlanes[2] >= vol.CroppingRegionPlanes[3] or
            vol.CroppingRegionPlanes[4] >= vol.CroppingRegionPlanes[5]):
            return False

    # Step 9: Compute reduction factor
    reduction_factor = ComputeReductionFactor(window.allocated_time)

    # Step 10: Render volume
    LoadProjectionParameters(window.renderer, vol)
    num_cropping_regions = ComputeNumberOfCroppingRegions()
    
    if reduction_factor < 1.0:
        RenderRegions(window.renderer, vol)
    else:
        RenderWholeVolume(window.renderer, vol)

    # Step 11: Copy FBO to texture
    CopyFBOToTexture()

    # Step 12: Render to screen
    RenderTextureToScreen(window.renderer)

    return True

def ReleaseGraphicsResources():
    # Step 13: Release resources
    DeleteOpenGLObjects()
    OpenGLObjectsCreated = 0

# Helper definitions to replace placeholders
def IsRenderSupported(window, property):
    # Standard check: verify 3D texture support and required extensions
    return window.HasExtension("GL_ARB_texture_float") and property.IsValid()

def LoadExtensions(window):
    # Standard: query and cache supported extensions
    window.CacheExtensions()

def TestRequiredExtension(ext_name):
    # Standard: check if extension is in cached list
    return ext_name in window.SupportedExtensions

def CreateOpenGLObjects(renderer):
    # Standard: glGenTextures, glGenFramebuffers, glGenPrograms
    renderer.CreateTextures()
    renderer.CreateFramebuffers()
    renderer.CreateShaders()

def AllocateFrameBuffers(renderer):
    # Standard: glTexImage2D for FBO color attachment based on window size
    w, h = renderer.GetWindowSize()
    renderer.AllocateFBO(w, h)

def LoadScalarField(input_data, input2, texture_extent, volume):
    # Standard: glTexImage3D with input data
    volume.Upload3DTexture(input_data, texture_extent)

def UpdateColorTransferFunction(vol, num_components):
    # Standard: upload LUT to 1D/2D texture
    vol.UploadColorLUT(num_components)

def UpdateOpacityTransferFunction(vol, num_components, level):
    # Standard: upload opacity LUT to 1D texture
    vol.UploadOpacityLUT(num_components, level)

def ClipBoundingBox(renderer, world_bounds, vol):
    # Standard: set glClipPlane or compute view-space clipping planes
    renderer.SetClippingPlanes(world_bounds)

def ComputeReductionFactor(allocated_time):
    # Standard: ratio of previous frame time to allocated time, clamped [0.0, 1.0]
    return min(1.0, max(0.0, allocated_time / max(1.0, renderer.GetLastFrameTime())))

def LoadProjectionParameters(renderer, vol):
    # Standard: upload modelview/projection matrices to shader uniforms
    renderer.UploadMatrices()

def ComputeNumberOfCroppingRegions():
    # Standard: count active cropping planes
    return renderer.ActiveCroppingPlanesCount()

def RenderRegions(renderer, vol):
    # Standard: render viewport scaled by reduction factor
    renderer.RenderScaledViewport(vol)

def RenderWholeVolume(renderer, vol):
    # Standard: full resolution raycast
    renderer.RenderFullViewport(vol)

def CopyFBOToTexture():
    # Standard: glCopyTexImage2D or glBlitFramebuffer
    renderer.CopyFBOToTexture()

def RenderTextureToScreen(renderer):
    # Standard: render fullscreen quad with FBO texture
    renderer.RenderQuad()

def DeleteOpenGLObjects():
    # Standard: glDeleteTextures, glDeleteFramebuffers, glDeletePrograms
    renderer.DeleteAllGLObjects()
```

## Subtopics
#### Four-Component Volume Rendering Fragment Shader
A GLSL fragment shader implementation for volume rendering that handles datasets with four components (e.g., RGBA or RGB+Alpha) by extracting scalar values and computing colors from a single `vec4` input sample [S2, unofficial]. It defines a function `scalarFromValue` that takes a `vec4 value` and returns the `w` component (alpha/4th channel) as a float, and functions `colorFromValue` and `colorFromValue2` that take a `vec4 value` and return a `vec4` where the RGB components are taken from the input's xyz and the alpha is hardcoded to 1.0 [S2, unofficial]. The shader targets GLSL version 110, indicated by the directive `#version 110` [S2, unofficial]. A pitfall is that the comment notes that 'value' should be thought of as an object, implying the shader treats the input vector as a structured data entity rather than just raw color data [S2, unofficial].

## Operating characteristics
- **Time Complexity**: Not given in the sources [S1, unofficial].
- **Memory Complexity**: Not given in the sources [S2, unofficial].
- **Measured Performance**: Not given in the sources [S1, unofficial].
- **Scaling**: The reduction factor allows for adaptive viewport scaling based on rendering time, which can improve interactive performance [S2, unofficial].
- **Strengths**: Supports multiple volumes, adaptive sampling, masking, and AMR mode through its parent class; handles clipping and cropping efficiently on the GPU [S1, unofficial].
- **Limitations**: Requires OpenGL hardware support for 3D texture mapping and specific extensions; may fail silently with invalid cropping planes or NULL inputs [S1, unofficial].
- **When to Use**: When rendering multiple volumes with OpenGL hardware acceleration, especially when clipping, cropping, or masking is required [S1, unofficial].
- **When Not to Use**: When hardware does not support required OpenGL extensions or when rendering single volumes without the need for multiple volume support [S1, unofficial].

## Background
The OpenGL GPU Multi Volume Ray Cast Mapper is part of the Visualization Toolkit (VTK) and is an OpenGL-specific implementation of the GPU Multi-Volume Ray Casting Mapper [S1, unofficial]. It was developed to provide hardware-accelerated volume rendering capabilities for multiple volumes within the VTK framework [S1, unofficial]. The method is used in scientific visualization applications that require interactive rendering of large volumetric datasets with multiple components [S2, unofficial].
