# Maximum Intensity Projection (MIP)
Also called: MIP Shader, Max intensity
## Overview
Maximum Intensity Projection (MIP) is a volume rendering technique that projects the maximum scalar value encountered along each viewing ray onto the 2D image plane [S1, unofficial]. It is primarily used to highlight high-intensity structures, such as blood vessels in angiography or calcifications in CT scans, by suppressing lower-intensity background noise [S1, unofficial]. Unlike standard alpha compositing, MIP is order-independent and inherently loses depth information, making it impossible to distinguish whether the maximum value originates from the front or back of the volume [S1, unofficial].
## How it works
**Inputs and Outputs:**
- Input: A 3D scalar volume $V$ defined on a grid of dimensions $W \times H \times D$.
- Input: Camera parameters defining the ray origin $\mathbf{o}$ and direction $\mathbf{d}$ for each pixel.
- Input: Number of sampling steps $N$ along the ray.
- Output: A 2D image where each pixel value $C$ is the maximum scalar value found along the corresponding ray.

**Data Structures:**
- **Volume Data:** A 3D texture or array storing scalar values. In implementation [S2, unofficial], this is often stored as a `Data3DTexture` with `RedFormat` and `FloatType` to preserve precision for intensity comparison.
- **Ray Parameters:** For each pixel, the ray $r(t) = \mathbf{o} + t\mathbf{d}$ is computed. The ray segment within the volume is discretized into $N$ steps.

**Algorithm:**
1. For each pixel $(u, v)$ in the output image:
2. Construct the ray $r(t) = \mathbf{o} + t\mathbf{d}$ intersecting the volume bounding box.
3. Initialize the maximum intensity accumulator $M = -\infty$ (or the minimum possible value of the data type).
4. Iterate $i$ from $0$ to $N-1$:
    a. Calculate the sample position $t_i$ along the ray segment within the volume.
    b. Sample the scalar value $s_i$ from the volume $V$ at position $r(t_i)$ using trilinear interpolation [S1, unofficial].
    c. Update the maximum: $M = \max(M, s_i)$.
5. Assign the final pixel color $C(u, v) = M$.

**Pseudocode:**
```python
def compute_mip(volume, ray_origin, ray_direction, num_steps, volume_dims):
    """
    Computes the Maximum Intensity Projection for a single ray.
    
    Args:
        volume: 3D array or texture object supporting trilinear sampling.
        ray_origin: 3D vector (x, y, z).
        ray_direction: 3D vector (x, y, z), normalized.
        num_steps: Integer number of samples along the ray.
        volume_dims: 3D vector (width, height, depth) of the volume.
        
    Returns:
        float: The maximum scalar value along the ray.
    """
    # Determine the entry and exit points of the ray with the volume bounding box
    # [G] Implementation detail: Standard AABB intersection algorithm required.
    # Let t_min and t_max be the distances to the entry and exit faces.
    # If the ray does not intersect the volume, return a background value (e.g., 0 or -inf).
    
    t_entry, t_exit = intersect_aabb(ray_origin, ray_direction, volume_dims)
    
    if t_entry > t_exit:
        return -float('inf') # Or background color
        
    # Calculate step size
    ray_length = t_exit - t_entry
    step_size = ray_length / num_steps
    
    max_intensity = -float('inf')
    
    for i in range(num_steps):
        # Calculate sample position along the ray
        t = t_entry + i * step_size
        sample_pos = ray_origin + t * ray_direction
        
        # Sample the volume using trilinear interpolation
        # [G] Implementation detail: sample_pos must be clamped to volume bounds
        # to avoid out-of-bounds access during interpolation.
        scalar_value = volume.trilinear_sample(sample_pos)
        
        # Update maximum
        if scalar_value > max_intensity:
            max_intensity = scalar_value
            
    return max_intensity
```

**Parameters:**
- `num_steps`: Controls the trade-off between computational cost and smoothness. Too few steps may miss small high-intensity structures [S1, unofficial]. Typical values depend on resolution and ray length; the example implementation uses 200 steps [S2, unofficial].
- Interpolation: Trilinear interpolation is standard for sampling scalar values [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Depth Ambiguity:** MIP loses differentiation of front/behind relationships. It is unclear where the maximum lies along the ray [S1, unofficial].
- **Missing Details:** Regular sampling may miss details if the step size is too large relative to the voxel size or the size of high-intensity structures [S1, unofficial].
- **Boundary Conditions:** Rays entering near 90 degrees to the grid axes may require careful handling of cell intersections to avoid sampling errors [S1, unofficial].
- **Data vs. Color:** MIP operates on scalar data. Color mapping is applied *after* the maximum is found, not during sampling [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(P \cdot N)$, where $P$ is the number of pixels and $N$ is the number of steps per ray.
- **Memory Complexity:** $O(W \cdot H \cdot D)$ for the volume storage. No additional per-ray memory is required beyond the accumulator.
- **Strengths:** Simple to implement; highly effective for visualizing high-contrast structures against low-intensity backgrounds; order-independent, allowing for flexible traversal orders and potential early termination if a maximum threshold is reached (though full traversal is standard for correctness).
- **Limitations:** Loses all depth information; can be misleading if multiple structures overlap; sensitive to noise if the noise has high intensity; does not provide a realistic 3D appearance.
- **When to use:** Angiography, bone visualization, or any scenario where the highest intensity values are the features of interest.
- **When not to use:** When depth perception is critical or when structures of varying intensities need to be viewed simultaneously with correct spatial relationships.

## Background
MIP is a variation of direct volume ray casting [S1, unofficial]. It has been widely used in medical imaging, particularly in CT and MRI, for decades. The technique is often implemented as a shader class in graphics libraries, such as the `MipShader` in the `volume_vis` repository [S2, unofficial]. It is distinct from other projection techniques like Minimum Intensity Projection (MinIP) or Summation Projection (Slab) by its use of the maximum aggregator [S1, unofficial].
