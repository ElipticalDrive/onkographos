# Projection and MIP Techniques

Also called: Maximum Intensity Projection, Minimum Intensity Projection, Forward Projection

## Overview
Projection and MIP Techniques are volume rendering methods that project a single scalar value from along each viewing ray onto a 2D image plane, rather than integrating emission and absorption [Direct volume ray casting](19-direct-volume-ray-casting.md). Unlike standard direct volume rendering which computes a weighted average of all samples, these techniques select an extremum (maximum or minimum) or a specific projection value, making them order-independent and computationally simpler [S1, S3, S9, S14, S25, unofficial]. They are primarily used in medical imaging to highlight specific density ranges, such as bones in CT scans or air-filled lungs, by suppressing intermediate tissue [S14, unofficial][S19, book][S20, unofficial].

## Shared principles
The family relies on the volume rendering integral discretized into a summation over sample points along a ray [S3, S5, unofficial]. The ray $r$ is parameterized by $r(t) = O + tD$, entering the volume at $t_{start}$ and exiting at $t_{end}$ [Volume Raycasting Discretization](831-volume-raycasting-discretization.md). The data model is sampled using $s(t)$ [Volume Raycasting Discretization](831-volume-raycasting-discretization.md).

Unlike the parent's front-to-back compositing, these techniques do not accumulate opacity or color. Instead, they maintain a single accumulator variable (e.g., $I_{max}$ or $I_{min}$) initialized to an extreme value (e.g., $-\infty$ or $+\infty$) [S1, S8, S21, S26, unofficial]. For each sample $i$ along the ray:
1.  Sample the volume at the current ray position to get a scalar value $d_i$ [S1, S5, S23, unofficial].
2.  Update the accumulator based on the specific projection type (e.g., $I_{max} \leftarrow \max(I_{max}, d_i)$ for MIP) [S1, S2, S6, S20, unofficial].
3.  If an early termination condition is met (e.g., intensity exceeds a threshold), terminate the ray [S4, unofficial].

Rays are cast from the eyepoint, one for each pixel [S1][S4, unofficial]. The volume is typically represented as a 3D texture [S4, S3, unofficial]. Sampling is performed using trilinear interpolation [S1][S5, unofficial]. A fixed random offset is applied to each ray's start position to prevent sample layers from appearing as bands [S18, unofficial]. The final accumulated color is typically corrected with gamma 2.2 [S9, unofficial].

```python
import random
import math

def vec3(x, y, z):
    return [x, y, z]

def pow_vec3(v, exponent):
    return [v[0]**exponent, v[1]**exponent, v[2]**exponent]

def compute_ray_exit(origin, direction, bounds):
    # Slab intersection for axis-aligned box [G]
    t0 = max((bounds[0][i] - origin[i]) / direction[i] if direction[i] != 0 else float('inf') for i in range(3))
    t1 = min((bounds[1][i] - origin[i]) / direction[i] if direction[i] != 0 else float('inf') for i in range(3))
    return max(t0, t1)

def trilinear_interpolate(volume, pos, dims):
    # Standard trilinear interpolation [G]
    vx = pos[0] * (dims[0] - 1)
    vy = pos[1] * (dims[1] - 1)
    vz = pos[2] * (dims[2] - 1)
    x0, y0, z0 = int(math.floor(vx)), int(math.floor(vy)), int(math.floor(vz))
    x1, y1, z1 = x0 + 1, y0 + 1, z0 + 1
    x0 = max(0, min(x0, dims[0]-1))
    x1 = max(0, min(x1, dims[0]-1))
    y0 = max(0, min(y0, dims[1]-1))
    y1 = max(0, min(y1, dims[1]-1))
    z0 = max(0, min(z0, dims[2]-1))
    z1 = max(0, min(z1, dims[2]-1))
    wx = vx - x0
    wy = vy - y0
    wz = vz - z0
    c00 = volume[x0][y0][z0] * (1-wx) + volume[x1][y0][z0] * wx
    c01 = volume[x0][y0][z1] * (1-wx) + volume[x1][y0][z1] * wx
    c10 = volume[x0][y1][z0] * (1-wx) + volume[x1][y1][z0] * wx
    c11 = volume[x0][y1][z1] * (1-wx) + volume[x1][y1][z1] * wx
    r0 = c00 * (1-wy) + c10 * wy
    r1 = c01 * (1-wy) + c11 * wy
    return r0 * (1-wz) + r1 * wz

def projection_mip(volume_data, camera, transfer_function, volume_bounds, volume_dims, step_size=0.001, threshold=None, mode='max'):
    """
    Renders a volume using Projection/MIP techniques.
    mode: 'max' for MIP, 'min' for MinIP.
    """
    h, w = camera.screen_height, camera.screen_width
    image = [[vec3(0.0, 0.0, 0.0) for _ in range(w)] for _ in range(h)]
    
    # Determine threshold if not provided
    if threshold is None:
        threshold = float('inf')
    
    # Pre-compute volume max/min for thresholding if needed
    vol_values = [v for row in volume_data for slice in row for v in slice]
    vol_max = max(vol_values) if vol_values else 0.0
    vol_min = min(vol_values) if vol_values else 0.0
    
    intensity_threshold = 0.75 * vol_max if threshold == 'auto' else threshold

    for y in range(h):
        for x in range(w):
            ray_origin, ray_direction = camera.cast_ray(x, y)
            
            # Compute ray intersection with volume bounds [G]
            t_start, t_end = compute_ray_exit(ray_origin, ray_direction, volume_bounds)
            
            if t_start >= t_end:
                continue # Ray misses volume

            # Initialize accumulator based on mode
            if mode == 'max':
                accumulator = -float('inf')
                terminator = lambda acc, thresh: acc > thresh
            else: # min
                accumulator = float('inf')
                terminator = lambda acc, thresh: acc < thresh
            
            max_position = None
            
            # Random offset to prevent banding artifacts [S18]
            t = t_start + random.uniform(0.0, step_size)
            
            while t < t_end:
                # Compute current position in texture space [0,1]
                pos = [(ray_origin[i] + t * ray_direction[i]) for i in range(3)]
                
                # Sample volume using trilinear interpolation [S1, unofficial][S5, unofficial]
                scalar_value = trilinear_interpolate(volume_data, pos, volume_dims)
                
                # Update accumulator
                if mode == 'max':
                    if scalar_value > accumulator:
                        accumulator = scalar_value
                        max_position = pos
                else:
                    if scalar_value < accumulator:
                        accumulator = scalar_value
                        max_position = pos
                
                # Early termination if accumulator exceeds threshold [S4, unofficial]
                if terminator(accumulator, intensity_threshold):
                    break
                
                t += step_size
            
            # Apply transfer function to the accumulator value
            color, _ = transfer_function(accumulator)
            
            # Gamma correction [S9, unofficial]
            image[y][x] = pow_vec3(color, 1.0/2.2)

    return image
```

## Subtopics

### [Maximum Intensity Projection](902-maximum-intensity-projection.md)
Projects the maximum scalar value along each ray. Used to highlight high-density structures like bones or contrast-enhanced vessels. Order-independent.

### [Forward Projection (aTx)](1492-forward-projection-atx.md)
Not given in the sources.

### [Minimum Intensity Projection](5299-minimum-intensity-projection.md)
Projects the minimum scalar value along each ray. Used to visualize low-density structures like air-filled lungs by suppressing high-intensity background tissue.

## Background
Maximum Intensity Projection (MIP) was introduced to address the limitations of standard volume rendering in highlighting specific high-contrast features without the computational cost of full integration [S14, unofficial][S19, book]. It became a standard tool in medical imaging for CT angiography and bone visualization [S14, unofficial]. Minimum Intensity Projection (MinIP) extends this concept to low-intensity features [S1].
