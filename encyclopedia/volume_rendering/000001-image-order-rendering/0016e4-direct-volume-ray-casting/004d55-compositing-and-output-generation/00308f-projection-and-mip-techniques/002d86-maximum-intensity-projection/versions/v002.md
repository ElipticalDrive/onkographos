# Maximum Intensity Projection

Also called: MIP, Max Intensity Projection, Ray Traversal -MIP

## Overview
Maximum Intensity Projection (MIP) is a volume rendering technique that projects the maximum scalar value encountered along each ray through the volume onto a 2D image plane [S1, S3, S9, S25, unofficial]. Unlike standard direct volume rendering which integrates emission and absorption along the ray [Direct volume ray casting](19-direct-volume-ray-casting.md), MIP ignores intermediate values and only renders the color and lighting of the voxel with the highest intensity [S2, S4, S26, unofficial]. It is primarily used to highlight high-density structures such as bones in CT scans or contrast-enhanced blood vessels in angiography [S2, S6, S20, unofficial]. The key distinction from its siblings is that MIP is order-independent; the final result does not depend on the order in which samples are processed, allowing for random access and acceleration structures [S1, S30, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A 3D volume dataset (scalar field), a camera configuration (origin and direction for each pixel), and a transfer function mapping scalar values to color [S2, S4, S14, unofficial].
*   **Output:** A 2D image where each pixel's color corresponds to the transfer function applied to the maximum scalar value found along the corresponding ray [S3, S9, S16, unofficial].

**Data Structures:**
*   **Volume:** Typically stored as a 3D texture or a 1D/2D array. In some implementations, 16-bit values are packed into 8-bit channels (e.g., RG8unorm) [S14, S26, unofficial].
*   **Accumulators:** Unlike front-to-back compositing, MIP requires tracking only the maximum value found so far along the ray and its position (if lighting is required) [S1, S16, unofficial]. No opacity accumulation is needed [S1, S19, unofficial].

**Algorithm Steps:**
1.  **Ray Initialization:** For each pixel, compute the ray origin and direction. Determine the entry ($t_{start}$) and exit ($t_{end}$) points of the ray with the volume's axis-aligned bounding box (AABB) [S3, S14, unofficial].
2.  **Initialization:** Initialize the maximum intensity variable $I_{max}$ to the minimum possible value (e.g., $-\infty$ or the minimum data value) and the position of the maximum $P_{max}$ to the ray start or null [S1, S26, unofficial].
3.  **Ray Marching:** Iterate along the ray from $t_{start}$ to $t_{end}$ with a fixed step size $\Delta t$ [S4, S15, S23, unofficial].
    *   Compute the current sample position $P(t) = O + tD$ [S12, unofficial].
    *   Sample the volume at $P(t)$ using trilinear interpolation to get the scalar value $s$ [G].
    *   **Update Maximum:** If $s > I_{max}$, update $I_{max} = s$ and $P_{max} = P(t)$ [S1, S26, unofficial].
    *   **Early Termination (Optional):** If $I_{max}$ exceeds a threshold (e.g., $0.75 \times \text{volume\_maximum}$), the ray can be terminated early [S4, unofficial]. Note that standard MIP does not use opacity-based early termination because opacity is not accumulated [S1, S19, unofficial].
4.  **Color Mapping:** Apply the transfer function to $I_{max}$ to obtain the final color $C_{final}$ [S4, unofficial][S22, book].
5.  **Lighting (Optional):** If lighting is enabled, compute the gradient at $P_{max}$ and calculate diffuse/specular shading to produce a shaded color [S8, unofficial]. If lighting is disabled, use the raw transfer function color [S8, unofficial].
6.  **Output:** Write $C_{final}$ to the pixel buffer [S8, unofficial].

**Formulas:**
The core update rule for the maximum intensity is:
$$ I_{max} \leftarrow \max(I_{max}, s_k) $$
where $s_k$ is the scalar value at sample $k$ along the ray [S1, S2, unofficial].

The final pixel intensity $I(x, r)$ for a ray $r$ passing through point $x$ is:
$$ I(x, r) = \max_{s \in [0, L]} (\mu(s)) $$
where $L$ is the ray length and $\mu(s)$ is the density/intensity at position $s$ [S4, S9, unofficial].

**Parameters:**
*   **Step Size:** Determines the distance between samples. Can be fixed or adaptive. Interactive modes often use larger steps for speed, while production renders use smaller steps [S8, S11, unofficial].
*   **Threshold:** A value used to clamp or terminate the ray. Commonly set to a fraction of the volume's maximum intensity (e.g., 0.75) [S4, unofficial].
*   **Window/Level:** Controls the contrast and brightness of the output color mapping [S14, unofficial].

**Pseudocode:**
```python
import math
import random

def vec3(x, y, z):
    return [x, y, z]

def compute_ray_exit(origin, direction, bounds):
    # Slab intersection for axis-aligned box [G]
    t0 = max((bounds[0][i] - origin[i]) / direction[i] if direction[i] != 0 else float('inf') for i in range(3))
    t1 = min((bounds[1][i] - origin[i]) / direction[i] if direction[i] != 0 else float('inf') for i in range(3))
    return max(t0, t1)

def trilinear_interpolate(volume, pos, dims):
    # Standard trilinear interpolation [G]
    vx = pos[0] * (dims[0] - 1)
    vy = pos[1] * (dims[1] - 1)
    vz = pos[2] * (dims[2] - 1)
    x0, y0, z0 = int(math.floor(vx)), int(math.floor(vy)), int(math.floor(vz))
    x1, y1, z1 = x0 + 1, y0 + 1, z0 + 1
    x0 = max(0, min(x0, dims[0]-1))
    x1 = max(0, min(x1, dims[0]-1))
    y0 = max(0, min(y0, dims[1]-1))
    y1 = max(0, min(y1, dims[1]-1))
    z0 = max(0, min(z0, dims[2]-1))
    z1 = max(0, min(z1, dims[2]-1))
    wx = vx - x0
    wy = vy - y0
    wz = vz - z0
    c00 = volume[x0][y0][z0] * (1-wx) + volume[x1][y0][z0] * wx
    c01 = volume[x0][y0][z1] * (1-wx) + volume[x1][y0][z1] * wx
    c10 = volume[x0][y1][z0] * (1-wx) + volume[x1][y1][z0] * wx
    c11 = volume[x0][y1][z1] * (1-wx) + volume[x1][y1][z1] * wx
    r0 = c00 * (1-wy) + c10 * wy
    r1 = c01 * (1-wy) + c11 * wy
    return r0 * (1-wz) + r1 * wz

def maximum_intensity_projection(volume, camera, transfer_function, volume_bounds, volume_dims, step_size=0.001, threshold=None):
    """
    Renders a volume using Maximum Intensity Projection (MIP).
    """
    h, w = camera.screen_height, camera.screen_width
    image = [[vec3(0.0, 0.0, 0.0) for _ in range(w)] for _ in range(h)]
    
    if threshold is None:
        threshold = float('inf')
    
    vol_max = max(volume.flatten()) if volume else 0.0
    intensity_threshold = 0.75 * vol_max if threshold == 'auto' else threshold

    for y in range(h):
        for x in range(w):
            ray_origin, ray_direction = camera.cast_ray(x, y)
            
            t_start, t_end = compute_ray_exit(ray_origin, ray_direction, volume_bounds)
            
            if t_start >= t_end:
                continue

            max_intensity = -float('inf')
            max_position = None
            
            # Random offset to prevent banding artifacts [S18, unofficial]
            t = t_start + random.uniform(0.0, step_size)
            
            while t < t_end:
                pos = [(ray_origin[i] + t * ray_direction[i]) for i in range(3)]
                scalar_value = trilinear_interpolate(volume, pos, volume_dims)
                
                if scalar_value > max_intensity:
                    max_intensity = scalar_value
                    max_position = pos
                
                # Early termination if max intensity exceeds threshold [S4, unofficial]
                if max_intensity > intensity_threshold:
                    break
                
                t += step_size
            
            color, _ = transfer_function(max_intensity)
            image[y][x] = color

    return image
```

## Subtopics

### Morphological Maximum Intensity Projection (MMIP) with Morphological Closing
A variant designed for non-axial views to prevent hole formation caused by undersampling [S33]. Standard MIP projects voxels directly, which can leave gaps in oblique views [S33]. MMIP applies a morphological closing operation to the 2D projection image after voxel projection to reconstruct continuous structures [S33]. It uses a structuring element (e.g., 2x2x2) for the morphological operations [S33].

### [Local Maximum Intensity Projection](6054-local-maximum-intensity-projection.md)
Instead of finding the global maximum along the entire ray, this method assigns the first local maximum that exceeds a predefined threshold to each pixel. Proposed by Sato to mitigate the depth information loss inherent in standard MIP. It requires setting a dataset-specific threshold, making it more complex to use than standard MIP.

### Closest Vessel Projection
A local projection technique often used in slab imaging for vascular diagnosis [S21]. It identifies the closest vessel to the viewpoint that satisfies a local maximum condition [S21]. Like Local MIP, it requires careful threshold tuning specific to the dataset [S21].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot M)$, where $N$ is the number of pixels and $M$ is the number of samples per ray [G].
*   **Memory Complexity:** $O(1)$ per ray for accumulators (only max value and position needed), plus storage for the volume [G].
*   **Strengths:**
    *   Excellent for visualizing high-intensity structures like bones, calcifications, and contrast-filled vessels [S2, S6, S20, unofficial].
    *   Order-independent, allowing for flexible acceleration structures (e.g., priority queues, multilevel grids) [S1, S30, unofficial].
    *   Simple implementation; no need for transfer functions to define opacity or for complex compositing equations [S2, unofficial][S22, book].
*   **Limitations:**
    *   **Loss of Depth Information:** The output image does not convey the depth (z-position) of the maximum intensity voxel. Structures can overlap ambiguously [S4, S17, unofficial].
    *   **Occlusion:** A higher density blood vessel can 'hide' other blood vessels which are closer to the view-point [S4, unofficial].
    *   **Static Limitations:** Static MIPs lack depth cues, making interactive exploration or animation sequences more useful [S21].
*   **When to Use:** Best for angiography (CTA/MRA) and bone visualization in CT where high-intensity structures are the primary interest [S2, S6, S20, unofficial].
*   **When Not to Use:** When depth perception is critical, or when visualizing low-intensity structures in MR images where high-intensity structures dominate [S23, S25, unofficial].

## Background
MIP was introduced as a simpler alternative to the full volume rendering integral, particularly for medical imaging applications [S1, S2, unofficial]. It is widely used in medical imaging to visualize high-intensity structures like blood vessels in angiography [S1, S2, unofficial]. The technique avoids the computational cost of numerical integration and transfer function tuning required by direct volume rendering [S2, unofficial][S22, book]. Early implementations relied on hardware extensions like `GL_EXT_blend_minmax` to perform the maximum operation in the fragment shader [S2, S5, unofficial]. Modern implementations typically perform the max operation in software or via GPU compute shaders, allowing for more flexible acceleration and lighting calculations at the maximum position [S3, S8, S16, unofficial].
