# Classified Volume Rendering

Also called: Fast Volume Rendering with Run-Length Encoded Classified Data, Volume Rendering (VR), vpRenderClassifiedVolume, vpRenderClassifiedVolume algorithm

## Overview
Classified Volume Rendering is a direct volume ray casting method that achieves maximum rendering speed by precomputing optical properties (color and opacity) for every voxel, thereby decoupling the classification step from the rendering loop [S1, S3]. Unlike standard direct volume rendering which applies the transfer function during ray traversal, this method fixes the classification function permanently during a preprocessing phase, allowing subsequent renders to vary only view transformation and shading parameters without recomputing voxel opacities [S1, S3]. It is distinguished from [Direct Volume Rendering](19-direct-volume-ray-casting.md) by its reliance on a pre-classified data structure and the absence of octree acceleration, making it the fastest available mode when the opacity transfer function remains constant [S3].

## How it works
The method operates in two distinct phases: a one-time preprocessing phase to generate the classified volume, and a rendering phase that performs ray casting using the precomputed data.

### Inputs and Outputs
**Inputs:**
*   Raw volume data: A 3D grid of scalar values (e.g., Hounsfield units for CT) $V_{raw}[x][y][z]$.
*   Classification function: A set of transfer functions mapping scalar ranges to color $C$ and opacity $\alpha$. The sources specify the use of trapezoidal functions for tissue separation [S2, unofficial].
*   View parameters: Camera origin, direction, and projection matrix.
*   Shading parameters: Light positions, material properties, and normal estimation method [S1].

**Outputs:**
*   A 2D image buffer containing the final rendered pixel colors.
*   A preclassified volume data structure containing run-length encoded classified data [S1].

### Data Structures
The core data structure is the **preclassified volume**. While the exact memory layout of the "run-length encoded" structure is not detailed in the provided sources, the rendering routine `vpRenderClassifiedVolume` accesses this structure directly instead of the raw voxel array or an octree [S3]. The structure stores the precomputed optical properties for each voxel.

The image buffer is declared as:
```c
unsigned char image[bytes_per_scan][height][bytes_per_pixel];
```
where `bytes_per_pixel` is determined by the pixel format (e.g., 4 bytes for RGB+opacity) [S1].

### Preprocessing Phase
This phase is performed once when the volume is acquired or when the classification function changes.

1.  **Load Volume Data:** Read the raw scalar volume $V_{raw}$ [S1].
2.  **Choose Classification Function:** Define the transfer functions. For medical imaging, trapezoidal functions are used to separate tissue types (e.g., bone, soft tissue) based on attenuation threshold levels [S2, unofficial].
3.  **Precompute Classified Volume:** Iterate through every voxel in the volume dataset [S1][S2, unofficial].
    *   For each voxel, determine the percentage of each tissue type represented based on the scalar value and the trapezoidal thresholds [S2, unofficial].
    *   Calculate the weighted sum of the colors and opacities for each tissue type to determine the overall color $C_v$ and transparency $\alpha_v$ for that voxel [S2, unofficial].
    *   Store these precomputed values in the classified volume structure [S1].

### Rendering Phase
This phase is repeated for each frame or view change.

1.  **Set View and Shading Parameters:** Configure the camera and lighting [S1].
2.  **Ray Casting:** For each pixel, cast a ray through the 3D volume [S2, unofficial].
3.  **Voxel Traversal:** As the ray passes through voxels, retrieve the precomputed color $C_v$ and opacity $\alpha_v$ from the classified volume structure [S3]. Note that the octree is **not** used in this mode [S3].
4.  **Compositing:** Apply the front-to-back compositing equation to integrate the contributions of the voxels along the ray [S2, unofficial][S3].
    $$
    C'_{i} = C'_{i-1} + (1 - \alpha'_{i-1}) \alpha_v C_v
    $$
    $$
    \alpha'_{i} = \alpha'_{i-1} + (1 - \alpha'_{i-1}) \alpha_v
    $$
    where $C'$ and $\alpha'$ are the accumulated color and opacity, initialized to 0 [S3, S12].
5.  **Shading Application:** Enhance 3D perception by applying shading effects (e.g., reflections, shadows) to the surface of the rendered image based on the accumulated normals or gradients [S1][S2, unofficial].
6.  **Store Result:** Place the final pixel color in the image buffer declared by `vpSetImage()` [S1].

### Pseudocode

```python
def preprocess_volume(raw_volume, classification_functions):
    """
    Precomputes the classified volume data structure.
    raw_volume: 3D array of scalar values.
    classification_functions: List of trapezoidal functions mapping scalar ranges to (color, opacity).
    Returns: classified_volume_data (run-length encoded structure).
    """
    classified_volume_data = initialize_run_length_encoded_structure()
    
    for x, y, z in raw_volume.indices():
        scalar_value = raw_volume[x, y, z]
        
        # Determine tissue contributions using trapezoidal functions
        total_color = (0, 0, 0)
        total_opacity = 0.0
        
        for tissue in classification_functions:
            # Calculate percentage of this tissue type represented in the voxel
            # based on predefined attenuation threshold levels
            percentage = tissue.calculate_percentage(scalar_value)
            
            # Weighted sum of color and opacity
            tissue_color = tissue.get_color()
            tissue_opacity = tissue.get_opacity()
            
            total_color += percentage * tissue_color
            total_opacity += percentage * tissue_opacity
            
        # Store precomputed optical properties
        classified_volume_data.set_voxel_properties(x, y, z, total_color, total_opacity)
        
    return classified_volume_data

def render_classified_volume(classified_volume_data, view_params, shading_params):
    """
    Renders the preclassified volume using current viewing and shading parameters.
    classified_volume_data: The precomputed run-length encoded structure.
    view_params: Camera origin, direction, projection.
    shading_params: Light positions, material properties.
    Returns: 2D image buffer.
    """
    image_buffer = initialize_image_buffer()
    
    for pixel in image_buffer.pixels():
        ray = generate_ray(pixel, view_params)
        
        accumulated_color = (0, 0, 0)
        accumulated_opacity = 0.0
        
        # Traverse ray through volume
        # Note: Octree is NOT used in this mode [S3]
        for voxel_sample in ray.traverse(classified_volume_data):
            # Retrieve precomputed properties
            C_v = voxel_sample.color
            alpha_v = voxel_sample.opacity
            
            # Front-to-back compositing
            transmittance = 1.0 - accumulated_opacity
            accumulated_color += transmittance * alpha_v * C_v
            accumulated_opacity += transmittance * alpha_v
            
            if accumulated_opacity >= 1.0:
                break # Ray fully occluded
        
        # Apply shading effects (reflections, shadows) [S1][S2, unofficial]
        final_color = apply_shading(accumulated_color, accumulated_opacity, shading_params)
        
        image_buffer.set_pixel(pixel, final_color)
        
    return image_buffer
```

### Parameters and Edge Cases
*   **Precomputation Time:** Several minutes, depending on volume size [S1].
*   **Trapezoid Slope:** Manipulating the slope of the trapezoidal transfer functions allows real-time adjustment of which structures are included (e.g., sliding towards lower Hounsfield units includes smaller vessels) [S2, unofficial].
*   **Fixed Classification:** The opacity transfer function **must not change** between renderings because voxel opacities are fixed in the preclassified volume [S3]. Changing the transfer function requires re-running the preprocessing phase.
*   **Masking Pathology:** VR can mask anatomical information and pathology (e.g., intracranial aneurysms) if bone subtraction is not performed [S2, unofficial].

## Subtopics

### [Image-Centric Volume Rendering with SN-SVM Classification](7509-image-centric-volume-rendering-with-sn-svm-classification.md)
This method enables direct volume rendering by allowing users to interact with raw 2D volume slices to define training data for an SN-SVM classifier, which then automatically classifies all voxels and assigns colors via color harmonization. It distinguishes itself from Classified Volume Rendering by avoiding pre-processing steps such as branch decomposition or contour tree computation, thereby preserving raw data granularity and preventing information loss during initial semantic realization.

## Operating characteristics
*   **Speed:** This is the fastest rendering mode available in VolPack [S3]. It eliminates the need for per-ray classification and octree traversal during rendering [S1, S3].
*   **Memory:** Requires additional memory to store the preclassified volume structure, which involves run-length encoding [S1].
*   **Flexibility:** Low flexibility regarding the transfer function. It is only suitable when the classification (opacity transfer function) remains fixed across multiple renderings [S1, S3]. If the transfer function changes, the slower [Direct Volume Rendering](19-direct-volume-ray-casting.md) with min-max octree acceleration should be used [S1, S3].
*   **Accuracy:** May mask anatomical details or pathology if not carefully configured (e.g., lack of bone subtraction) [S2, unofficial].

## Background
Classified Volume Rendering is part of the VolPack library, a standard software package for volume rendering [S1]. It was designed to address the computational cost of applying transfer functions during ray casting by moving this operation to a preprocessing stage [S1]. The method is particularly relevant in medical imaging, where large volumes (CT/MR) are rendered repeatedly from different viewpoints with consistent tissue classification [S2, unofficial].
