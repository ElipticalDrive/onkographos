# Attention Compositing

Also called: Attention Compositing Module

## Overview
Attention Compositing is a method for Direct Volume Ray Casting (DVR) that automates view-dependent visual emphasis by integrating semantic attention maps with traditional transfer functions. It solves the problem of isolating Regions of Interest (ROIs) in complex volumetric data (e.g., medical images) where manual segmentation is difficult or where low-level saliency fails to capture semantic importance. Unlike standard DVR, which relies solely on intensity-based opacity, or importance-driven methods using manual labels which may cause over-segmentation and loss of context, Attention Compositing preserves surrounding contextual information while de-emphasizing occluding structures with low attention values.

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    1.  Volumetric data $V$.
    2.  Transfer Function (TF) parameters defining opacity $O_{TF}$ and color $\mathbf{c}$ for each voxel based on intensity.
    3.  Attention Map $A$: A 3D volume of raw attention values generated by a deep learning model (e.g., F-CAM), where higher values indicate semantic importance.
*   **Outputs:**
    *   Final rendered image with emphasized ROIs and de-emphasized background/occluders.

**Data Structures:**
*   **Attention Volume:** Same dimensions as the input volume $V$, storing scalar attention values $A_i$ for each voxel $i$.
*   **Priority Volume:** A derived scalar volume storing the composite priority $Pr_i$ for each voxel.

**Method Steps:**

1.  **Generate Attention Map:**
    Use a pre-trained convolutional neural network (CNN) to generate a focused attention map $A$ for the input volume. This map encodes semantic information, highlighting ROIs (e.g., tumors in PET scans) while suppressing non-semantic structures [S1].

2.  **Compute TF-Enhanced Attention ($A_e$):**
    For each voxel $i$, combine the raw attention value $A_i$ with the opacity $O_{TF,i}$ assigned by the Transfer Function for the target ROI. This step ensures that only voxels with both high semantic attention and high intensity-based opacity are considered significant.
    $$
    A_{e,i} = O_{TF,i} \cdot A_i
    $$
    Where:
    *   $A_{e,i}$ is the TF-enhanced attention value.
    *   $O_{TF,i}$ is the opacity value assigned by the TF for the ROI tent.
    *   $A_i$ is the raw attention value from the attention map.

3.  **Calculate Priority ($Pr$):**
    Determine the final priority for each voxel by aggregating $A_{e,i}$ and the occlusion relations along the viewing ray. Voxels occluding high-priority ROIs with low attention values are assigned lower priority to become transparent, allowing the ROI to be seen. Voxels with low $A_{e,i}$ (false positives or context) are also de-emphasized.
    *Note: The source describes the aggregation of attention, TF opacity, and occlusion into a single-dimensional attribute called priority, but does not provide a closed-form algebraic formula for the occlusion integration step itself, only the definition of $A_e$ and the conceptual result [S1].*

4.  **Modify Opacity for Compositing:**
    Adjust the opacity $\alpha_i$ used in the standard front-to-back compositing equation. The original opacity $O_{TF,i}$ is modulated by the priority $Pr_i$. High-priority voxels retain or increase their effective opacity, while low-priority voxels (including occluders with low attention) have their opacity reduced.
    *Implementation Note:* In practice, this is often achieved by scaling the opacity contribution in the compositing loop or by pre-multiplying the opacity by a factor derived from $Pr_i$.

5.  **Standard DVR Compositing:**
    Perform standard front-to-back volume rendering using the modified opacities.
    $$
    \mathbf{C}_{out} = \sum_{i=1}^{N} \mathbf{c}_i \alpha'_i \prod_{j=1}^{i-1} (1 - \alpha'_j)
    $$
    $$
    \alpha_{out} = 1 - \prod_{i=1}^{N} (1 - \alpha'_j)
    $$
    Where $\alpha'_i$ is the priority-modified opacity for sample $i$.

**Pseudocode:**

```python
def attention_compositing(volume, attention_map, transfer_function, ray_origin, ray_direction, t_near, t_far, num_samples):
    """
    Renders a volume using Attention Compositing.
    
    Args:
        volume: 3D array of voxel intensities.
        attention_map: 3D array of raw attention values (same dimensions as volume).
        transfer_function: Function mapping intensity -> (color, opacity).
        ray_origin: 3D vector (o).
        ray_direction: 3D vector (d).
        t_near: Entry parameter of ray into volume.
        t_far: Exit parameter of ray into volume.
        num_samples: Number of samples along the ray.
        
    Returns:
        final_color: 3D vector (RGB).
        final_opacity: Scalar (A).
    """
    dt = (t_far - t_near) / num_samples
    acc_color = [0.0, 0.0, 0.0]
    acc_opacity = 0.0
    
    for i in range(num_samples):
        t = t_near + i * dt
        pos = ray_origin + t * ray_direction
        
        # 1. Sample volume and attention map
        intensity = sample_volume(volume, pos)
        raw_attention = sample_volume(attention_map, pos)
        
        # 2. Get TF properties for the target ROI
        # Note: TF is typically designed for specific semantic classes (e.g., tumor)
        color, tf_opacity = transfer_function(intensity)
        
        # 3. Compute TF-Enhanced Attention
        # Ae = O_TF * A
        tf_enhanced_attention = tf_opacity * raw_attention
        
        # 4. Determine Priority and Modified Opacity
        # The source defines Priority as an aggregation of Ae and occlusion.
        # For implementation, we assume a simplified modulation where
        # effective opacity is scaled by the normalized attention strength.
        # In the source, R1 (occluder) has low attention -> low priority -> transparent.
        # ROI has high attention -> high priority -> opaque.
        
        # Heuristic implementation of priority-based opacity modulation:
        # If tf_enhanced_attention is high, keep tf_opacity.
        # If low, reduce opacity to allow ray to pass through to ROI behind it.
        # A simple scaling factor could be:
        priority_factor = tf_enhanced_attention / max(max(attention_map.flatten()), 1e-6)
        
        # Clamp priority factor to [0, 1] or scale as needed
        # The source implies that occluders with low attention are rendered sparsely/transparently.
        modified_opacity = tf_opacity * priority_factor
        
        # Guard against zero opacity to avoid division by zero in alpha blending if needed,
        # though standard front-to-back handles alpha=0 correctly.
        if modified_opacity < 1e-6:
            continue
            
        # 5. Front-to-back compositing
        # C_acc = C_acc + (1 - alpha_acc) * c * alpha
        # alpha_acc = alpha_acc + (1 - alpha_acc) * alpha
        weight = (1.0 - acc_opacity) * modified_opacity
        acc_color[0] += weight * color[0]
        acc_color[1] += weight * color[1]
        acc_color[2] += weight * color[2]
        acc_opacity += weight
        
        # Early ray termination optimization (optional)
        if acc_opacity > 0.99:
            break
            
    return acc_color, acc_opacity
```

**Parameters:**
*   **Attention Map Source:** Typically a CNN (e.g., F-CAM) trained on the specific modality (PET, MRI) [S1].
*   **Transfer Function:** Usually a 1D intensity-based TF specific to the modality (e.g., PET/CT) [S1].

**Edge Cases and Pitfalls:**
*   **False Positives in Attention:** The attention map may highlight non-ROI structures with high attention values. The TF-enhanced attention step ($A_e = O_{TF} \cdot A$) mitigates this by requiring high TF opacity (intensity match) as well [S1].
*   **False Positives in TF:** The TF may assign high opacity to contextual structures (e.g., bones in MRI) that are not ROIs. The attention map filters these out if they have low semantic attention [S1].
*   **Occlusion:** If a high-attention ROI is occluded by a low-attention structure, the low-attention structure must be made transparent. The priority calculation must account for this depth relationship [S1].

## Subtopics

### F-CAM (Focused Class Activation Mapping)
A technique for generating the attention map $A$. It transfers semantic information from classification tasks to localization, focusing on small ROIs in medical images. It differs from standard CAM by focusing on specific classes and refining localization [S1].

### Importance-Driven Visualization
A sibling method using manual segmentation labels. It often causes over-segmentation and unwanted removal of adjacent context (e.g., bones). Attention Compositing is chosen when manual labeling is impractical or when preserving context is critical [S1].

### Saliency-Driven DVR
An early attempt using bottom-up saliency maps based on low-level features. It lacks semantic understanding. Attention Compositing is chosen when semantic relevance (e.g., tumor vs. healthy tissue) is required [S1].

## Operating characteristics
*   **Time Complexity:** Adds the cost of sampling the attention map (same as volume sampling) and a few multiplications per sample. The CNN inference is performed once per volume (or per frame if dynamic), not per ray. Thus, per-frame rendering cost is negligible compared to standard DVR.
*   **Memory Complexity:** Requires storing an additional 3D volume for the attention map, equal in size to the input volume.
*   **Strengths:** Automates visual emphasis; preserves contextual information better than manual segmentation; handles view-dependent occlusion effectively; reduces false positives from both TF and attention map.
*   **Limitations:** Requires a pre-trained attention model; dependent on the quality of the attention map; may fail if the attention model is not trained for the specific pathology or feature [S1].
*   **When to use:** Medical imaging (PET-CT, MRI) where ROIs are small and semantically defined, and manual segmentation is too labor-intensive.
*   **When not to use:** Non-medical data without semantic labels; real-time applications where pre-computing attention maps is prohibitive.

## Background
Attention Compositing was proposed by Li et al. in 2024, building on earlier work in saliency-driven DVR by Jung et al. [S1]. It addresses the limitations of low-level saliency and manual segmentation by leveraging deep learning-based semantic attention maps. It is particularly relevant in medical visualization tools like 3D Slicer and ImageJ, where automated ROI emphasis aids diagnosis [S1].
