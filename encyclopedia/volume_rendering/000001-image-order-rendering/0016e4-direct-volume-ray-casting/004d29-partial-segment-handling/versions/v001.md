# Partial Segment Handling

Also called: Reduced Segment Length Opacity Adjustment, Segmental Replacement, Segmental Replacer Node

## Overview
Partial Segment Handling addresses the "jerky edges" or stair-stepping artifacts that occur at volume boundaries or cutting surfaces when rays are sampled at fixed intervals, leaving an incomplete segment at the end of the ray march [S1, unofficial]. It solves this by introducing a smaller final segment to fill the remaining distance to the boundary and adjusting its opacity to preserve the correct accumulated attenuation [S1, unofficial]. Unlike [2D Visualization from 3D Grid (Slow)](1507-2d-visualization-from-3d-grid-slow.md) which may rely on denser sampling, or [Cutting Plane Integration](8414-cutting-plane-integration.md) which simply discards data, this method maintains the discrete sampling structure while correcting the optical depth of the final step [S1, unofficial]. A variant, Segmental Replacement, uses surface models to partially replace volume models to avoid rendering the entire volume, facilitating real-time simulation [S2, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
*   Original segment length $d_1$ (typically the fixed step size $\Delta t$).
*   Original segment opacity $\alpha_1$ (derived from the transfer function and extinction coefficient for length $d_1$).
*   Remaining distance to the volume boundary or cutting surface $d_2$ (where $0 < d_2 < d_1$).
*   [S2, unofficial] Optional: Surface model data for the replacement region.

**Outputs:**
*   Adjusted opacity $\alpha_2$ for the partial segment.
*   [S2, unofficial] Rendered pixel color using either the adjusted volume segment or the surface counterpart.

### Data Structures
No specific complex data structures are required beyond the standard ray marching state. The method operates on scalar values associated with the current ray step.
*   **Segment State:** Contains current position $t$, accumulated color $\mathbf{C}_{acc}$, and accumulated opacity $\alpha_{acc}$.
*   **Boundary Check:** A boolean or distance value indicating if the next full step $t + d_1$ exceeds the volume exit $t_{far}$ or a cutting plane.

### Steps
1.  **Ray Marching:** Perform standard front-to-back compositing for full segments of length $d_1$ as defined in [Direct volume ray casting](19-direct-volume-ray-casting.md).
2.  **Boundary Detection:** At each step, check if the next sample position $t_{next} = t_{current} + d_1$ exceeds the volume exit parameter $t_{far}$ or intersects a cutting plane.
3.  **Partial Segment Calculation:** If a boundary is crossed:
    *   Calculate the remaining distance $d_2 = t_{far} - t_{current}$ (or distance to cutting plane).
    *   Retrieve the volumetric data value at $t_{current}$ (or interpolate if the boundary is within a voxel, though typically the segment starts at a sample point).
    *   Determine the original opacity $\alpha_1$ that would have been applied if the segment length were $d_1$. This is usually $\alpha_1 = 1 - e^{-\sigma \cdot d_1}$, where $\sigma$ is the extinction coefficient derived from the transfer function [S1, unofficial].
    *   Calculate the adjusted opacity $\alpha_2$ for the shorter length $d_2$ using the formula below.
    *   Composite the partial segment using $\alpha_2$ and the color $\mathbf{c}$ derived from the data at $t_{current}$.
    *   Terminate the ray march.
4.  **Segmental Replacement (Variant):** If using the Segmental Replacer Node strategy:
    *   Clip the volume model along vertical and horizontal planes to generate sub-parts [S2, unofficial].
    *   Identify regions where the volume model is replaced by a surface counterpart.
    *   Render the surface counterpart for the "darker areas" or specified regions to exhibit internal information while avoiding the cost of rendering the entire volume model [S2, unofficial].

### Formulas
The core adjustment for reduced segment length is [S1, unofficial]:

$$
\alpha_2 = 1 - (1 - \alpha_1)^{\frac{d_2}{d_1}}
$$

Where:
*   $\alpha_1$ is the opacity of the original full segment of length $d_1$.
*   $d_1$ is the original segment length (step size).
*   $d_2$ is the new, reduced segment length (remaining distance to boundary).
*   $\alpha_2$ is the adjusted opacity for the partial segment.

This formula ensures that the transmission $(1 - \alpha_2)$ equals the transmission of the original segment raised to the power of the length ratio, preserving the Beer-Lambert law's exponential attenuation property for the partial distance [S1, unofficial].

### Parameters
*   **Segment Length ($d_1$):** Typically the fixed step size $\Delta t$ used in the ray march. Adaptive strategies may vary $d_1$ based on contribution [S1, unofficial].
*   **Transfer Function:** Maps scalar values to extinction coefficient $\sigma$ and color $\mathbf{c}$.

### Edge Cases and Pitfalls
*   **Zero Remaining Distance:** If $d_2 \approx 0$, $\alpha_2$ should be 0 to avoid division by zero or numerical instability in the exponent.
*   **Precision:** Ensure floating-point precision is sufficient for the exponentiation, especially when $d_2 \ll d_1$.
*   **Cutting Surfaces:** When using cutting planes, the "boundary" is not necessarily the volume exit. The method must correctly identify the intersection of the ray with the cutting plane geometry to determine $d_2$ [S1, unofficial].
*   **Surface Replacement Artifacts:** In the Segmental Replacement variant, mismatched lighting or opacity between the surface model and the volume model can cause visible seams [S2, unofficial].

### Pseudocode

```python
def partial_segment_handling(ray_origin, ray_direction, volume_exit_t, cutting_plane_t, step_size, transfer_function):
    """
    Renders a ray with partial segment handling at boundaries.
    
    Args:
        ray_origin: 3D vector, camera origin.
        ray_direction: 3D vector, normalized viewing direction.
        volume_exit_t: float, t parameter where ray exits volume.
        cutting_plane_t: float, t parameter where ray hits cutting plane (or infinity if none).
        step_size: float, fixed segment length d1.
        transfer_function: function, maps scalar value to (color, extinction_coeff).
        
    Returns:
        final_color: 3D vector, composited color.
        final_opacity: float, accumulated opacity.
    """
    # Determine the effective exit point
    effective_exit_t = min(volume_exit_t, cutting_plane_t)
    
    t_current = ray_origin + 0.0 * ray_direction # Start at origin (or t_near)
    # Note: In standard DVR, we start at t_near. For simplicity, assume t_current is the start of the current segment.
    # Let's assume we are at the start of a segment.
    
    acc_color = (0.0, 0.0, 0.0)
    acc_opacity = 0.0
    
    while t_current < effective_exit_t:
        t_next = t_current + step_size
        
        # Check if this segment is partial
        if t_next > effective_exit_t:
            # Partial segment handling
            d1 = step_size
            d2 = effective_exit_t - t_current
            
            # Get data at current position
            # Assuming a function get_volume_value(pos) exists
            val = get_volume_value(t_current)
            color, sigma = transfer_function(val)
            
            # Calculate original opacity alpha1 for length d1
            # alpha1 = 1 - exp(-sigma * d1)
            alpha1 = 1.0 - math.exp(-sigma * d1)
            
            # Calculate adjusted opacity alpha2 for length d2
            # alpha2 = 1 - (1 - alpha1)^(d2/d1)
            if d1 > 0:
                ratio = d2 / d1
                alpha2 = 1.0 - math.pow((1.0 - alpha1), ratio)
            else:
                alpha2 = 0.0
            
            # Composite the partial segment
            # C_out = C_acc + (1 - alpha_acc) * c * alpha
            # alpha_out = alpha_acc + (1 - alpha_acc) * alpha
            weight = (1.0 - acc_opacity) * alpha2
            acc_color = acc_color + weight * color
            acc_opacity = acc_opacity + weight
            
            break # End of ray
            
        else:
            # Full segment
            t_mid = t_current + step_size / 2.0
            val = get_volume_value(t_mid)
            color, sigma = transfer_function(val)
            
            alpha = 1.0 - math.exp(-sigma * step_size)
            
            weight = (1.0 - acc_opacity) * alpha
            acc_color = acc_color + weight * color
            acc_opacity = acc_opacity + weight
            
            t_current = t_next
            
    return acc_color, acc_opacity
```

## Subtopics

### Segmental Replacement
A strategy where a surface model partially replaces a volume model to exhibit internal information while avoiding the rendering of the entire volume model. It is chosen when real-time simulation requires avoiding the cost of full volume rendering, and the trade-off is acceptable [S2, unofficial].

### Adaptive Segment Length
An optimization where smaller segments are used when the contribution to the ray color is large, and longer segments when the contribution is low. This reduces artifacts while optimizing for speed [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of samples. The partial segment handling adds a constant-time check and calculation at the end of the ray march.
*   **Memory Complexity:** $O(1)$ additional memory. No new data structures are required.
*   **Performance:** The method is computationally inexpensive, adding minimal overhead to the ray march. It is suitable for real-time applications [S1, unofficial].
*   **Strengths:** Eliminates jerky edges at boundaries without requiring global resampling or increased sampling density.
*   **Limitations:** Only addresses artifacts at the end of the ray. Does not address aliasing within the volume (e.g., onion rings) which may require [Anti-Aliasing and Filtering](1574-anti-aliasing-and-filtering.md) [S1, unofficial].

## Background
Partial Segment Handling was identified as a solution to common artifacts in volume rendering, specifically jerky edges caused by incomplete segments at volume boundaries [S1, unofficial]. The technique is based on the Beer-Lambert law's exponential attenuation properties. The concept of using surface models to partially replace volume models (Segmental Replacement) was explored in hybrid rendering frameworks for real-time manipulation of volume and surface models [S2, unofficial].
