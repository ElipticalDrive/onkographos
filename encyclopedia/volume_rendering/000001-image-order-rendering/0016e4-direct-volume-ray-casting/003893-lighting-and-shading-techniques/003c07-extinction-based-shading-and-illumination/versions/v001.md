# Extinction-based Shading and Illumination

Also called: Extinction-based shading, SAT-based illumination

## Overview
Extinction-based shading is a GPU-accelerated technique for computing ambient occlusion, color bleeding, and soft shadows in direct volume ray casting by aggregating extinction coefficients using a 3D Summed Area Table (SAT) [S1, unofficial]. Unlike traditional methods that rely on expensive shadow ray sampling or opacity-based approximations, this method uses distance-weighted cuboid shell queries against a precomputed SAT of extinction coefficients to achieve high-quality illumination with minimal runtime overhead [S1, unofficial]. It sets itself apart from siblings like [Pre-integrated Volume Rendering](5327-pre-integrated-volume-rendering.md) by focusing on global illumination effects (shadows/AO) rather than local transfer function integration, and from [Extinction-based Shadow and Scattering Approximation](9149-extinction-based-shadow-and-scattering-approximation.md) by explicitly utilizing a 3D SAT structure for constant-time neighborhood aggregation [S1, unofficial].

## How it works
The method implements the emission-absorption optical model, building on the shading step of [Direct volume ray casting](19-direct-volume-ray-casting.md). It enhances the standard Phong or Blinn-Phong shading by modulating the incident light intensity with attenuation factors derived from the volume's extinction properties [S1, unofficial].

### Inputs and Outputs
**Inputs:**
*   Scalar volume data $V$.
*   Transfer function $T(d)$ mapping scalar values to color $C$ and opacity $\alpha$.
*   Camera parameters (origin $\mathbf{o}$, direction $\mathbf{d}$).
*   Light source positions and types (ambient, directional).
*   SAT resolution and shell parameters.

**Outputs:**
*   Final pixel color $C_{final}$ with illumination effects (AO, shadows, color bleeding).
*   Auxiliary 3D textures: SAT of extinction coefficients and Light Cache.

### Data Structures
Two auxiliary 3D textures are used, stored in GPU memory (e.g., render-to-3D texture) [S1, unofficial]:
1.  **Extinction SAT Texture:** Stores the prefix sums of extinction coefficients. Can be of arbitrary size (within OpenGL limits) and does not need to match input volume resolution [S1, unofficial].
2.  **Light Cache Texture:** A ping-pong texture used during SAT generation, which becomes the storage for accumulated illumination factors (AO, shadows, color bleeding) during rendering [S1, unofficial].

**Extinction Coefficient Layout:**
For a voxel with scalar value $d$, the extinction coefficient $\tau$ is derived from the opacity $\alpha$ provided by the transfer function. While the exact mapping formula is not explicitly detailed in the sources, it is distinct from using opacity directly, as the method emphasizes using extinction coefficients for the SAT [S1, unofficial]. The SAT stores these values. For color bleeding, the SAT stores vectors $\tau_{C_{RGB}}$, allowing four values (RGBA) to be processed per operation in the same 3D texture [S1, unofficial].

### Numbered Steps

1.  **Construct Extinction SAT:**
    *   Compute extinction coefficients $\tau$ for all voxels based on the current Transfer Function (TF).
    *   Build a 3D Summed Area Table (SAT) of these coefficients using a recursive doubling technique. This requires a logarithmic number of passes relative to the SAT dimensions [S1, unofficial].
    *   Store the result in the Extinction SAT Texture.
    *   *Note:* If computing color bleeding, simultaneously construct a SAT for vectors $\tau_{C_{RGB}}$ in the same texture pass [S1, unofficial].

2.  **Compute Ambient Occlusion (AO) and Color Bleeding:**
    *   Approximate the spherical neighborhood $\Omega_A$ around each voxel using a series of concentric cuboid shells $Sh_i$ [S1, unofficial].
    *   Query the Extinction SAT for each shell $Sh_i$ to get the aggregate sum of extinction coefficients in constant time (using up to 8 lookups) [S1, unofficial].
    *   Accumulate AO values iteratively, starting from the innermost shell $Sh_0$:
        $$ \tau_{Sh_0} = SAT(Sh_0) \cdot r_{Sh_0}^{-2} $$
        $$ \tau_{Sh_{i+1}} = \tau_{Sh_i} + (SAT(Sh_{i+1}) - SAT(Sh_i)) \cdot r_{Sh_{i+1}}^{-2} $$
        where $r_{Sh_i}$ is the radius (or characteristic size) of shell $Sh_i$ [S1, unofficial].
    *   Store the accumulated AO result in the Light Cache Texture.
    *   *Note:* Color bleeding is computed similarly using the $\tau_{C_{RGB}}$ SAT, using the same number of shells [S1, unofficial].

3.  **Compute Directional Soft Shadows:**
    *   **Static Lights:** If the light position is fixed relative to the dataset, compute attenuation factors once. Approximate the sampling cone $\Omega_L = \Psi$ for each voxel and light source using a series of cuboids. The primary cone axis is the coordinate axis with the smallest angle to the vector to the light source [S1, unofficial]. Query the Extinction SAT for these cuboids and store the attenuation factors in the Light Cache Texture [S1, unofficial].
    *   **Dynamic Lights:** If the light moves relative to the dataset, repeat the cone approximation and SAT query every frame to update the Light Cache Texture [S1, unofficial].

4.  **Ray Casting and Shading:**
    *   For each pixel, generate a ray and sample the volume [S1, unofficial].
    *   At each sample point, retrieve the pre-computed illumination factors from the Light Cache Texture [S1, unofficial].
    *   Calculate the reflected light $E_i$ for the sample using the extinction-based illumination model:
        $$ E_i = I_{A,L} \cdot e^{-w_{A,L} \sum_{\Omega_{A,L}} \Delta^{\tau_j} \cdot k} \cdot C_{RGB} $$
        where:
        *   $I_{A,L}$ is the ambient or light source intensity [S1, unofficial].
        *   $w_{A,L}$ is the weighting function ($w_A = r^{-2}$ for AO, $w_L = V^{-1}$ for shadows, where $V$ is the aggregate query size) [S1, unofficial].
        *   $\sum_{\Omega_{A,L}} \Delta^{\tau_j}$ is the sum of extinction coefficients over the query region (obtained from the SAT/Light Cache) [S1, unofficial].
        *   $k$ is a local illumination factor (e.g., from gradient-based normal estimation) [S1, unofficial].
        *   $C_{RGB}$ is the color of the sample [S1, unofficial].
    *   Composite the final color using the standard front-to-back over operator, incorporating $E_i$ as the emitted light at the sample [S1, unofficial].

### Parameters
*   **Number of Shells:** As few as 3 shells are sufficient for image quality indistinguishable from large neighborhood sampling. More shells are needed if the radius of $\Omega_A$ exceeds 10% of the dataset radius [S1, unofficial].
*   **Cone Sampling:** User-defined sampling frequency and growth rate (change of frequency over distance) on the primary axis for shadow cones [S1, unofficial].
*   **SAT Resolution:** Arbitrary, but affects quality/performance. Examples: $192^3$ for Head dataset, $64^3$ for Engine/Pelvis [S1, unofficial].

### Edge Cases and Pitfalls
*   **TF Changes:** The SAT must be updated whenever the Transfer Function changes because extinction coefficients are TF-dependent [S1, unofficial].
*   **Performance:** Dynamic illumination requires per-frame SAT queries, increasing cost. Static illumination incurs near-zero extra cost (one additional texture lookup per sample) [S1, unofficial].
*   **Memory:** Storing color bleeding vectors increases memory bandwidth requirements, though sources note this did not harm performance on tested hardware [S1, unofficial].

### Pseudocode

```python
# Step 1: Construct Extinction SAT
def build_extinction_sat(volume, transfer_function, sat_size):
    # Compute extinction coefficients tau for each voxel
    tau_volume = compute_extinction(volume, transfer_function)
    
    # Build 3D SAT using recursive doubling
    # This can be done in log(N) passes on GPU
    sat = compute_3d_sat(tau_volume, sat_size)
    return sat

# Step 2: Compute AO and Color Bleeding
def compute_ao_and_color_bleeding(sat, num_shells, shell_radii):
    light_cache = create_3d_texture(sat.size)
    
    # Initialize AO accumulator
    ao_accumulator = 0.0
    color_accumulator = vec3(0.0)
    
    # Iterate through shells
    for i in range(num_shells):
        # Query SAT for the cuboid shell Sh_i
        # SAT query returns sum of extinction coefficients in the cuboid
        sum_extinction = query_sat(sat, get_cuboid_shell(i, shell_radii[i]))
        
        # Weight by inverse square of radius
        weight = 1.0 / (shell_radii[i] ** 2)
        
        # Accumulate AO
        # Note: The formula in sources implies iterative accumulation
        # tau_Sh_{i+1} = tau_Sh_i + (SAT(Sh_{i+1}) - SAT(Sh_i)) * r_{Sh_{i+1}}^-2
        # Here we assume shell_radii[i] corresponds to the radius of the current shell
        # and we are accumulating the contribution of the shell itself.
        
        # For AO
        shell_contribution = sum_extinction * weight
        ao_accumulator += shell_contribution
        
        # For Color Bleeding (using vector SAT)
        # Assuming a separate SAT for RGB or interleaved data
        sum_color_extinction = query_sat_color(sat, get_cuboid_shell(i, shell_radii[i]))
        color_accumulator += sum_color_extinction * weight
        
    # Store results in Light Cache
    write_to_light_cache(light_cache, ao_accumulator, color_accumulator)
    return light_cache

# Step 3: Compute Directional Soft Shadows (Static Example)
def compute_static_shadows(sat, light_position, num_cone_samples):
    light_cache = create_3d_texture(sat.size)
    
    for each voxel in volume:
        # Determine primary cone axis
        vector_to_light = light_position - voxel_position
        primary_axis = get_coordinate_axis_with_smallest_angle(vector_to_light)
        
        # Approximate cone with cuboids
        cuboids = approximate_cone_with_cuboids(voxel_position, light_position, primary_axis, num_cone_samples)
        
        # Query SAT for each cuboid and aggregate
        total_extinction = 0.0
        for cuboid in cuboids:
            total_extinction += query_sat(sat, cuboid)
            
        # Compute attenuation factor
        # Weighting function w_L = V^-1 where V is aggregate query size
        # Note: The exact aggregation of cuboids into V is not fully detailed,
        # but typically involves the sum of volumes or a representative size.
        # For implementation, we assume total_extinction is weighted appropriately.
        attenuation = exp(-total_extinction) # Simplified, actual formula uses w_L
        
        write_to_light_cache(light_cache, attenuation=attenuation)
        
    return light_cache

# Step 4: Ray Casting
def ray_cast(volume, transfer_function, light_cache, camera, lights):
    sat = build_extinction_sat(volume, transfer_function, SAT_SIZE)
    
    # Pre-compute illumination if static or if TF changed
    if light_is_static:
        ao_cache = compute_ao_and_color_bleeding(sat, NUM_SHELLS, SHELL_RADII)
        shadow_cache = compute_static_shadows(sat, light.position, CONE_SAMPLES)
    else:
        ao_cache = compute_ao_and_color_bleeding(sat, NUM_SHELLS, SHELL_RADII)
        shadow_cache = compute_dynamic_shadows(sat, light.position, CONE_SAMPLES)
        
    for each pixel:
        ray = generate_ray(camera, pixel)
        accumulated_color = vec3(0.0)
        accumulated_opacity = 0.0
        
        t_start, t_end = intersect_volume(ray)
        
        for t from t_start to t_end with step dt:
            p = ray.origin + ray.direction * t
            scalar = sample_volume(volume, p)
            color, opacity = transfer_function(scalar)
            
            # Retrieve illumination factors from Light Cache
            ao_factor = sample_light_cache(ao_cache, p)
            shadow_factor = sample_light_cache(shadow_cache, p)
            
            # Compute local illumination factor k (e.g., Blinn-Phong)
            normal = estimate_normal(volume, p)
            k = compute_blinn_phong(normal, light.direction, camera.direction)
            
            # Compute incident light with extinction-based shading
            # E_i = I_{A,L} * e^{-w * sum_extinction * k} * C_RGB
            # Note: The sources formula combines attenuation and k.
            # A common interpretation is that the extinction term modulates the light intensity.
            # Let's assume the Light Cache stores the pre-computed exponential attenuation term.
            # E_i = I * ao_factor * shadow_factor * k * color
            
            # More precisely based on Eq 8:
            # The term e^{-w * sum} is the attenuation.
            # The Light Cache stores this attenuation (and AO/Color components).
            # So, E_i = I * attenuation * k * color
            
            incident_light = lights.intensity * ao_factor * shadow_factor * k
            
            # Composite
            transmittance = 1.0 - accumulated_opacity
            accumulated_color += transmittance * opacity * incident_light * color
            accumulated_opacity += transmittance * opacity
            
            if accumulated_opacity > 0.99:
                break
                
        return accumulated_color
```

## Operating characteristics
*   **Time Complexity:** SAT construction is $O(N \log N)$ where $N$ is the number of voxels in the SAT, using recursive doubling [S1, unofficial]. AO and shadow computation involves a constant number of SAT queries per voxel (proportional to the number of shells/cone samples). Ray casting is $O(R)$ where $R$ is the number of samples per ray.
*   **Memory Complexity:** Requires two auxiliary 3D textures (SAT and Light Cache) of arbitrary size [S1, unofficial]. Color bleeding increases memory bandwidth usage [S1, unofficial].
*   **Performance:** On a Head dataset (128x256x256, SAT 192^3, 15 shells), performance is 111fps with ambient only and 143fps with dynamic illumination [S1, unofficial]. On an Engine dataset (256x256x128, SAT 64^3, 50 cone samples), it is 57fps ambient only and 130fps with dynamic illumination [S1, unofficial]. Static illumination incurs near-zero extra cost during rendering [S1, unofficial].
*   **Strengths:** Fast computation of global illumination effects (AO, shadows) using constant-time SAT queries. Interactive TF updates are possible due to fast SAT construction.
*   **Limitations:** Requires additional GPU memory for auxiliary textures. Dynamic illumination requires per-frame updates. Approximation of spherical neighborhoods with cuboid shells may introduce artifacts if not enough shells are used [S1, unofficial].

## Background
The method was introduced in a paper by the University of Zurich (UZH) [S1, unofficial]. It improves upon previous approaches like Diaz et al. [4] by using extinction coefficients instead of opacity for the SAT and approximating neighborhoods with cuboid shells instead of eight adjacent octants, allowing for distance-based weighting [S1, unofficial]. The technique leverages GPU capabilities for fast SAT construction and 3D texture lookups to achieve interactive frame rates for volume rendering with complex illumination [S1, unofficial].
