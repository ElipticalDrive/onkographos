# Hybrid Gradient Volume Raycasting with Lasso Masking

Also called: Colored Raycast Volume Render, HU Direction + Opacity Threshold Lighting

## Overview
This method is a direct volume raycasting technique that renders medical CT data by combining pre-computed Hounsfield Unit (HU) gradients for lighting direction with a hybrid shading model that applies Phong lighting only when significant opacity changes are detected along the gradient direction [S1, unofficial]. It incorporates lasso-based voxel masking to selectively hide or reveal regions of the volume and uses cutting cube bounds to define the rendering region [S1, unofficial]. It differs from standard direct volume rendering by decoupling the lighting direction from the sample gradient, using pre-computed gradients for stability, and by introducing conditional shading based on opacity thresholds to prevent artifacts on smooth structures like vessels [S1, unofficial]. It builds on [Lighting and Shading Techniques](8281-lighting-and-shading-techniques.md) and is a sibling to [Next Event Estimation for Emissive Volumes](3557-next-event-estimation-for-emissive-volumes.md).

## How it works
The method is implemented as a fragment shader pipeline that performs ray marching within a defined 3D bounding box [S1, unofficial]. It relies on the parent's principles of front-to-back compositing and ray discretization [S1, unofficial].

### Inputs and Outputs
*   **Inputs:**
    *   `volumeTexture`: `texture_2d_array<f32>` containing the scalar density values (HU) [S1, unofficial].
    *   `gradientTexture`: `texture_2d_array<f32>` containing pre-computed gradient vectors [S1, unofficial].
    *   `ctfTexture`: `texture_1d<f32>` storing the Color Transfer Function (CTF) lookup table [S1, unofficial].
    *   `lassoMask`: `texture_3d<u32>` where voxels inside the lasso contour have a value of 0 and outside have a non-zero value [S1, unofficial].
    *   `Uniforms`: A struct containing transformation matrices, camera position, volume dimensions, step size, and toggle flags [S1, unofficial].
*   **Outputs:**
    *   A `vec4<f32>` containing the accumulated color and opacity for the pixel [S1, unofficial].

### Algorithm Steps
1.  **Vertex Shader**: Transform the input quad position to clip space using `modelMatrix`, `viewMatrix`, and `projectionMatrix` [S1, unofficial]. Pass the world position and a zero ray direction to the fragment shader [S1, unofficial].
2.  **Fragment Shader Initialization**: Compute the camera position in cube space using the `inverseModelMatrix` [S1, unofficial]. Set the ray origin to the camera position [S1, unofficial]. Compute the ray direction by normalizing `(worldPosition - cameraPosition)` and scaling by `voxelSpacing` [S1, unofficial].
3.  **Ray-Box Intersection**: Intersect the ray with the box defined by `boxMin = -1.0/voxelSpacing` and `boxMax = 1.0/voxelSpacing` [S1, unofficial]. Return `tNear` and `tFar` [S1, unofficial]. Discard the pixel if `tNear >= tFar` or `tFar <= 0` [S1, unofficial].
4.  **Jitter**: Compute a jitter offset to prevent banding artifacts:
    $$ jitter = fract(\sin(dot(input.clipPosition.xy, vec2(12.9898, 78.233))) \times 43758.5453) \times uniforms.stepSize $$
    Initialize the ray parameter $t$ with this jitter [S1, unofficial].
5.  **Ray Marching Loop**: While `accumulatedAlpha < 0.95` and $t < t_{Far}$:
    a.  **Position Conversion**: Compute the scaled position: $scaledPos = scaledRayOrigin + rayDir \times t$ [S1, unofficial]. Convert to texture space $[0, 1]$:
        $$ pos = scaledPos \times uniforms.voxelSpacing \times 0.5 + vec3(0.5) $$
        [S1, unofficial]
    b.  **Texture Bounds Check**: If `pos.x`, `pos.y`, or `pos.z` is outside $[0, 1]$, break the loop [S1, unofficial].
    c.  **Lasso Mask Check**: Compute voxel coordinates:
        $$ voxelCoord = (u32(pos.x \times (volumeWidth-1)), u32(pos.y \times (volumeHeight-1)), u32(pos.z \times (volumeDepth-1))) $$
        Load `maskValue` from `lassoMask` [S1, unofficial]. If `maskValue == 0` (inside lasso contour), increment $t$ and `stepCount`, then `continue` (skip this sample) [S1, unofficial].
    d.  **Volume Sampling**: Sample the density using `sampleVolumeFast(pos)` [S1, unofficial].
    e.  **CTF Evaluation**: Evaluate color and alpha using `evaluateCTF(density)` [S1, unofficial].
    f.  **Alpha Threshold**: If `sampleAlpha <= 0.001`, skip lighting and accumulation, increment $t$ and `stepCount`, then `continue` [S1, unofficial].
    g.  **Alpha Normalization**: Compute normalized alpha:
        $$ \alpha = sampleAlpha \times \frac{stepSize}{0.006} $$
        Clamp $\alpha$ to $[0, 1]$ [S1, unofficial].
    h.  **Hybrid Lighting**: If `toggleGradient` is enabled, sample the pre-computed gradient from `gradientTexture` at `pos` [S1, unofficial]. Apply Phong shading using the gradient direction [S1, unofficial]. Only apply the computed lighting if the opacity change exceeds a threshold (typically 0.15) [S1, unofficial]. This prevents shading on smooth vessels [S1, unofficial].
    i.  **Accumulation**: Compute weight: $weight = \alpha \times (1.0 - accumulatedAlpha)$ [S1, unofficial]. Update accumulated color:
        $$ accumulatedColor += ctfColor.rgb \times lighting \times weight $$
        [S1, unofficial]. Update accumulated opacity:
        $$ accumulatedAlpha += weight $$
        [S1, unofficial]. If `accumulatedAlpha >= 0.95`, break the loop [S1, unofficial].
    j.  **Step Increment**: Increment $t$ by `stepSize` [S1, unofficial].
6.  **Post-Processing**: If `accumulatedAlpha < 0.1`, add an ambient gray color to mask numerical errors:
    $$ accumulatedColor += vec3(0.02) \times (0.1 - accumulatedAlpha) $$
    [S1, unofficial]
7.  **Return**: Return `vec4(accumulatedColor, accumulatedAlpha)` [S1, unofficial].

### Helper Functions

**Volume Sampling** [S1, unofficial]:
```python
def sample_volume_fast(uvw, volume_texture, num_slices):
    coords = clamp(uvw, 0.0, 1.0)
    z = coords.z * (num_slices - 1.0)
    z0 = floor(z)
    z1 = min(z0 + 1.0, num_slices - 1.0)
    z_frac = z - z0
    sample0 = texture_sample_level(volume_texture, coords.xy, int(z0), 0.0)
    sample1 = texture_sample_level(volume_texture, coords.xy, int(z1), 0.0)
    return mix(sample0.r, sample1.r, z_frac)

def texture_sample_level(texture, uv, slice_idx, mip_level):
    u, v = uv
    u0 = floor(u * (texture.width - 1))
    v0 = floor(v * (texture.height - 1))
    u1 = min(u0 + 1, texture.width - 1)
    v1 = min(v0 + 1, texture.height - 1)
    u_frac = u * (texture.width - 1) - u0
    v_frac = v * (texture.height - 1) - v0
    p00 = texture[slice_idx][v0][u0]
    p01 = texture[slice_idx][v0][u1]
    p10 = texture[slice_idx][v1][u0]
    p11 = texture[slice_idx][v1][u1]
    top = mix(p00, p01, u_frac)
    bottom = mix(p10, p11, u_frac)
    return mix(top, bottom, v_frac)
```

**CTF Evaluation** [S1, unofficial]:
```python
def evaluate_ctf(density, ctf_texture):
    min_hu = -1024.0
    max_hu = 3071.0
    normalized = clamp((density - min_hu) / (max_hu - min_hu), 0.0, 1.0)
    texel_index = int(normalized * 255.0)
    return texture_load(ctf_texture, texel_index, 0)

def texture_load(texture, index, layer):
    return texture[layer][index]
```

### Edge Cases and Pitfalls
*   **Numerical Errors**: Very transparent regions (`accumulatedAlpha < 0.1`) may show black dots due to `f16` numerical errors [S1, unofficial]. This is mitigated by adding the subtle gray ambient color in the post-processing step [S1, unofficial].
*   **Lasso Masking**: Voxels inside the lasso contour (`maskValue == 0`) are skipped [S1, unofficial]. Ensure the mask texture is correctly aligned with the volume texture coordinates [S1, unofficial].
*   **Gradient Threshold**: Lighting is only applied if the opacity change exceeds 0.15 [S1, unofficial]. This prevents shading artifacts on smooth structures like blood vessels [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: Not given in the sources.
*   **Memory Complexity**: Not given in the sources.
*   **Performance**: The method is implemented in a fragment shader, allowing for parallel execution on the GPU [S1, unofficial]. The use of pre-computed gradients avoids the need for on-the-fly gradient calculation, saving computation time [S1, unofficial]. The lasso mask check adds a small overhead per sample but allows for efficient culling of irrelevant voxels [S1, unofficial].
*   **Strengths**: Stable lighting due to pre-computed gradients [S1, unofficial]. Selective rendering via lasso masking [S1, unofficial]. Reduced artifacts on smooth structures via opacity threshold lighting [S1, unofficial].
*   **Limitations**: Requires pre-computation of gradients [S1, unofficial]. The lasso mask must be provided and aligned with the volume [S1, unofficial]. Numerical errors in low-opacity regions require a specific fix [S1, unofficial].
