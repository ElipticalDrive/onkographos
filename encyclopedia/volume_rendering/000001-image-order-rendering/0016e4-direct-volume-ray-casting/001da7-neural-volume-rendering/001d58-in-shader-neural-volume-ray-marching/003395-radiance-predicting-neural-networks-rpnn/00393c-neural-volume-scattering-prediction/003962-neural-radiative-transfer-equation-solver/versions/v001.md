# Neural Radiative Transfer Equation Solver

Also called: Neural network-based real-time volume rendering method, RPNN variant with hierarchical transmittance and sampling templates

## Overview
A real-time volume rendering method that uses a neural network to simulate the iterative integration process of solving the Radiative Transfer Equation (RTE), replacing traditional path tracing to achieve real-time performance for high albedo anisotropic materials with multiple scattering [S1, unofficial]. It sets itself apart from its sibling [Neural Volume Scattering Prediction](8439-neural-volume-scattering-prediction.md) and the earlier [Radiance-Predicting Neural Networks (RPNN)](8438-radiance-predicting-neural-networks-rpnn.md) by decomposing input features into density, transmission, and phase, and by using specific sampling templates (diffuse and highlight) to simplify the network structure and input parameters, thereby addressing RPNN's inability to handle shadows and its requirement for large sampling [S1, unofficial].

## How it works
**Inputs:**
1.  Original 3D volumetric media density field, represented as a point cloud or voxel grid with resolution $1024 \times 1024 \times 1024$ [S1, unofficial].
2.  Incident light direction (implied by the highlight template geometry) [S1, unofficial].

**Outputs:**
1.  Scattering distribution for the center points of all sampling templates, which contributes to the final radiance calculation [S1, unofficial].

**Data Structures:**
1.  **Hierarchical Density Fields:** A set of 11 density fields $\rho_i$ at resolutions $R_i$. The resolutions are:
    *   $i=0: 1024^3$
    *   $i=1: 512^3$
    *   $i=2: 256^3$
    *   $i=3: 128^3$
    *   $i=4: 64^3$ (Note: Source text contains typo '624 * 64 * 64', corrected to $64^3$ based on sequence) [S1, unofficial].
    *   $i=5: 32^3$
    *   $i=6: 16^3$
    *   $i=7: 8^3$
    *   $i=8: 4^3$ (Note: Source text contains typo '4 * 4 * 4 * 4', corrected to $4^3$ based on sequence) [S1, unofficial].
    *   $i=9: 2^3$
    *   $i=10: 1^3$
2.  **Hierarchical Transmission Fields:** A set of 11 transmission fields $T_i(p, y)$, one for each density level [S1, unofficial].
3.  **Transmission Feature:** A single feature map resulting from the 3D-CNN processing of the 11 transmission fields [S1, unofficial].
4.  **Diffuse Reflection Sampling Template ($S_{diff}$):** A set of 182 points distributed in a sphere around a center point, divided into 8 layers [S1, unofficial].
    *   Layer 0: 6 points (1 center, 5 inside).
    *   Layer 1: 8 points.
    *   Layer 2: 12 points.
    *   Layer 3: 16 points.
    *   Layer 4: 24 points.
    *   Layer 5: 32 points.
    *   Layer 6: 48 points.
    *   Layer 7: 48 points.
    *   Points in layers 1-7 are evenly distributed in the spherical shell between the current layer's surface and the previous layer's surface [S1, unofficial].
5.  **Highlight Sampling Template ($S_{high}$):** A set of 72 points distributed along the direction of incident light, divided into 4 layers [S1, unofficial].
    *   Layer 0: 32 points.
    *   Layer 1: 16 points.
    *   Layer 2: 16 points.
    *   Layer 3: 8 points.
    *   Points are evenly distributed by distance from the center [S1, unofficial].

**Parameters:**
*   $\lambda_{i+1}$: Coefficient for transmittance calculation, range $[0, 1]$, specific value $0.6$ [S1, unofficial].

**Steps:**

1.  **Data Processing (Hierarchical Transmittance):**
    For each density level $i$ from 0 to 10:
    a.  Obtain the density field $\rho_i(x)$ at resolution $R_i$.
    b.  Calculate the transmission field $T_i(p, y)$ using the formula:
        $$ T_i(p, y) = e^{-\int_{p}^{y} \lambda_{i+1} \rho_i(x) dx} $$
        where $p$ is the starting point, $y$ is the ending point along the path, and $\lambda_{i+1} = 0.6$ [S1, unofficial].
    c.  Store the 11 transmission fields $T_0, \dots, T_{10}$ [S1, unofficial].

2.  **Transmission Feature Extraction:**
    a.  Input the 11 hierarchical transmission fields into a 3D Convolutional Neural Network (3D-CNN) [S1, unofficial].
    b.  The 3D-CNN assigns a weight to each level of transmission field and superimposes them to produce a single combined transmission feature [S1, unofficial].

3.  **Feature Sampling:**
    For a given center point in the volume:
    a.  Sample the **density features** using both $S_{diff}$ and $S_{high}$ templates.
    b.  Sample the **transmission features** (from the combined feature map generated in Step 2) using both $S_{diff}$ and $S_{high}$ templates.
    c.  Sample the **phase features** (scattering phase function values) using both $S_{diff}$ and $S_{high}$ templates.
    d.  This results in sampled phase features, sampled density features, and sampled transmission features for each template layer [S1, unofficial].

4.  **Network Input Preparation:**
    a.  Layer the three types of sampled features (density, transmission, phase) according to the layers of the diffuse reflection sampling template and the highlight sampling template [S1, unofficial].
    b.  The sampled features of each layer are sent into the network for internal scattering estimation [S1, unofficial].

5.  **Attention Mechanism:**
    a.  Pass the layered features through an attention module [S1, unofficial].
    b.  The module selects important channel features to pay more attention to light scattering, highlights, and shadows [S1, unofficial].

6.  **Scattering Prediction:**
    a.  Feed the attended features into the backbone neural network [S1, unofficial].
    b.  Predict the scattering distribution for the center points of all sampling templates ($S_{diff}$ and $S_{high}$) [S1, unofficial].

## Subtopics

### Hierarchical Transmittance
A technique to represent optical depth at multiple resolutions to capture both fine details and global lighting effects efficiently. It sets itself apart by using a fixed coefficient $\lambda$ to scale density before integration, simplifying the transmittance calculation compared to full path tracing. Choose it when rendering large volumes with varying density scales. ### Diffuse Reflection Sampling Template
A spherical sampling pattern designed to capture isotropic scattering contributions. It sets itself apart from the highlight template by focusing on general scattering rather than directional highlights. Choose it for rendering the bulk appearance of participating media. [Link to Diffuse Template](8441-diffuse-sampling-template.md) (Hypothetical).

### Highlight Sampling Template
A directional sampling pattern aligned with the light source to capture specular-like highlights and shadowing effects. It sets itself apart from the diffuse template by focusing on the light direction. Choose it when accurate highlights and shadows are critical. ## Operating characteristics
*   **Time Complexity:** Real-time performance is claimed, significantly faster than traditional path tracing [S1, unofficial]. The complexity is dominated by the 3D-CNN inference and the sampling operations, which are constant per pixel/voxel based on the fixed template sizes (182 + 72 = 254 points) [S1, unofficial].
*   **Memory Complexity:** Requires storing 11 hierarchical density fields and 11 transmission fields. For a $1024^3$ input, the memory usage is substantial but reduced by downsampling. The 3D-CNN and backbone network weights also consume memory [S1, unofficial].
*   **Measured Performance:** The source claims "greatly increase the rendering speed while maintaining rendering quality" and "outperforms previous methods" [S1, unofficial]. Specific FPS or hardware details are not given.
*   **Strengths:** Real-time rendering, handles high albedo anisotropic materials with multiple scattering, better handling of shadows and highlights compared to RPNN, simplified network structure [S1, unofficial].
*   **Limitations:** Requires pre-computation of hierarchical fields, relies on neural network approximation which may not generalize to all material types, specific template geometry limits flexibility [S1, unofficial].
*   **When to use:** Real-time applications requiring realistic volumetric rendering of participating media like clouds, smoke, or translucent materials [S1, unofficial].
*   **When not to use:** When exact physical accuracy is required over speed, or for scenes with dynamic lighting that cannot be pre-computed into the transmission features [S1, unofficial].
