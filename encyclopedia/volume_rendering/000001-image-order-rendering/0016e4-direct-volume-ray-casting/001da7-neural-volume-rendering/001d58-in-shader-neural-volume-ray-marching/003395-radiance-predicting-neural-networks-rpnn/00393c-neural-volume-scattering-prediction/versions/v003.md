# Neural Volume Scattering Prediction

Also called: Backbone Neural Network for Volume Rendering, Deep scattering for volumes, Radiance-predicting neural network for volumes

## Overview
Neural Volume Scattering Prediction is a method for rendering participating media that uses a neural network to predict the scattering distribution at the centers of sampling templates, which is then used to solve the radiative transfer equation [S1, unofficial]. It sets itself apart from its sibling [Neural Radiative Transfer Equation Solver](8466-neural-radiative-transfer-equation-solver.md) and the earlier [Radiance-Predicting Neural Networks (RPNN)](7049-radiance-predicting-neural-networks-rpnn.md) by decomposing input features into density, transmission, and phase, and by using specific sampling templates (diffuse and highlight) to simplify the network structure and input parameters [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs:**
    *   Sampling features: Pre-calculated density, transmission, and phase features derived from particle position coordinates and template points [S1, unofficial].
    *   Configuration parameters:
        *   Asymmetry parameters of the Henyey-Greenstein (HG) phase function ($g$): 1, 2, or 3 parameters depending on material type [S1, unofficial].
        *   Albedo ($\eta_c$): A 3D vector for RGB channels, range 0–1, assumed homogeneous within the same material [S1, unofficial].
            *   Gaseous materials: 0 to 0.5 [S1, unofficial].
            *   Solid, liquid, and skin materials: 0.5 to 1 [S1, unofficial].
        *   Angle ($\alpha$): Between viewing direction ($\omega$) and light direction ($l$), calculated as $\alpha = \cos^{-1}(\omega, l)$ [S1, unofficial].
    *   Dataset: Annotated data $Z = \{(F_1, F(u_1, l_1)), ..., (F_N, F(u_N, l_N))\}$, where $N$ is the dataset size, $F_i(p, l)$ is the annotation value, and $T^c(F)$ is the estimated value [S1, unofficial].
*   **Outputs:**
    *   Scattering distribution $F(p, l)$ for the center point of each sampling template [S1, unofficial].
    *   These values are brought into the radiative transfer equation to render the volume medium [S1, unofficial].

**Data Structures**
*   **Sampling Templates:** Total of 4129 templates [S1, unofficial].
    *   Diffuse reflection sampling template: 8 layers [S1, unofficial].
    *   Specular (highlight) reflection sampling template: 4 layers [S1, unofficial].
*   **Feature Vectors:**
    *   For the $i$-th layer input feature $H_i^\tau$, where $\tau \in \{\rho, f, T\}$ represents density, phase function, and transmission field respectively:
        *   Average pooling: $B_i^\tau = \frac{1}{n_i} \sum_{j=1}^{n_i} H_{i,j}^\tau$ [S1, unofficial].
        *   Maximum pooling: $f_i^\tau = \max H_{i,j}^\tau$ [S1, unofficial].
        *   $n_i$: Total number of points in the $i$-th layer template [S1, unofficial].
    *   Attention vector $v_i$: 8-dimensional vector constructed from layer inputs:
        $$v_i = \{B_i^\rho, B_i^f, B_i^T, f_i^\rho, f_i^f, f_i^T, g, \alpha\}$$ [S1, unofficial].

**Algorithm Steps**
The method uses a backbone neural network divided into two separate networks with identical structures: one for diffuse reflection and one for specular reflection [S1, unofficial]. If density, transmittance, and phase are included, there are 6 identical network modules (2 per feature type: diffuse/specular) [S1, unofficial].

1.  **Input Layer:**
    *   Input sampling features (density, transmission, phase) from the pre-calculation table based on particle position and template points [S1, unofficial].
    *   Features are input in batches. There are 4129 sampling templates, so the network processes them 4129 times (or in parallel using multiple models) [S1, unofficial].

2.  **Hidden Layer Processing (Layer-by-Layer):**
    *   For each feature type (density, transmission, phase), process features layer-by-layer through identical network structures [S1, unofficial].
    *   **Diffuse Reflection:** Process 8 layers [S1, unofficial].
    *   **Specular Reflection:** Process 4 layers [S1, unofficial].
    *   **Per Layer Operation:**
        1.  Fuse current layer sampling features (e.g., density) with configuration parameters ($g, \eta_c, \alpha$) [S1, unofficial].
        2.  Input the fused vector into an **Attention Module** (implemented as SENet) to determine channel importance [S1, unofficial].
            *   Construct $v_i$ from the current layer's pooled features and configuration parameters [S1, unofficial].
            *   Calculate weight coefficient $w_i^\tau = S(R(v_i))$, where $R(v_i) = \max(v_i, 0)$ (ReLU) and $S(x) = \frac{1}{1+e^{-x}}$ (Sigmoid) [S1, unofficial].
            *   Apply weights to features: $H_i^\tau = w_i^\tau \cdot \sum H_i^\tau$ [S1, unofficial].
        3.  Fuse the attention module output with the next layer's sampling features using Fully Connected layer **FC-1** to match dimensions [S1, unofficial].
        4.  Pass the fused vector through Fully Connected layer **FC-2** [S1, unofficial].
        5.  Fuse the result with the current layer's sampling feature and output [S1, unofficial].

3.  **Merge Diffuse and Specular:**
    *   Merge the diffuse reflection sampling density features (after 8 iterations) and specular reflection sampling density features (after 4 iterations) via a full connection [S1, unofficial].

4.  **Final Prediction:**
    *   Input sampling transmission features and sampling phase features layer-by-layer (12 times each total across diffuse/specular paths) [S1, unofficial].
    *   Fuse transmission and phase features together [S1, unofficial].
    *   Input the fused features into a Multilayer Perceptron (MLP) [S1, unofficial].
    *   Output the scattering distribution of the center point of the sampling template [S1, unofficial].

5.  **Rendering:**
    *   Sample all 4129 volume medium particle points with the template [S1, unofficial].
    *   Predict output in parallel to obtain scattering distributions for all 4129 centers [S1, unofficial].
    *   Bring predicted scattering distribution values into the radiative transfer equation to render the volume medium [S1, unofficial].

**Loss Function**
The network is trained using a mean square error loss with logarithmic transformation to compress the radiation range and speed up training [S1, unofficial].

$$L_S = \frac{1}{B} \sum_{i \in B} \left( \log \frac{T^c(F)}{\eta_c \gamma} + 1 - \log \frac{F_i(p, l)}{\eta_c \gamma} + 1 \right)^2$$

*   $B$: Batch size [S1, unofficial].
*   $T^c(F)$: Estimated value of the neural network [S1, unofficial].
*   $F_i(p, l)$: Annotation value of the scattering distribution [S1, unofficial].
*   $\eta_c$: Albedo for RGB channel $c$ [S1, unofficial].
*   $\gamma$: Hyperparameter, typically $\gamma = 4$ [S1, unofficial].
*   $c$: RGB color channel [S1, unofficial].

The total loss is minimized over the annotated dataset $Z$:
$$L_{total} = \argmin \frac{1}{N} \sum_{i=1}^{N} L_S$$ [S1, unofficial].

**Pseudocode**

```python
import math

def relu(x):
    return [max(0.0, v) for v in x]

def sigmoid(x):
    return [1.0 / (1.0 + math.exp(-v)) for v in x]

def average_pooling(features, n_points):
    dim = len(features[0])
    avg = [0.0] * dim
    for feat in features:
        for k in range(dim):
            avg[k] += feat[k]
    return [v / n_points for v in avg]

def max_pooling(features):
    dim = len(features[0])
    max_val = [float('-inf')] * dim
    for feat in features:
        for k in range(dim):
            if feat[k] > max_val[k]:
                max_val[k] = feat[k]
    return max_val

def attention_module(v_i):
    r_v_i = relu(v_i)
    return sigmoid(r_v_i)

def fc_layer(vec_in, target_dim):
    # [G] Standard linear projection with learned weights and bias
    # Returns a vector of length target_dim
    return [0.0] * target_dim

def process_layer(features, config, is_diffuse):
    # 1. Fuse current layer features with configuration parameters
    # [G] Exact fusion operation not specified; assumed concatenation or addition
    fused_config = features[0] + config

    # 2. Attention Module (SENet)
    # Construct 8-dimensional vector v_i
    n_points = len(features)
    # Assuming features contain density, phase, and transmission components
    B_rho = average_pooling(features, n_points)
    f_rho = max_pooling(features)
    # B_f, B_T, f_f, f_T would be computed similarly from respective feature streams
    B_f = [0.0] * len(B_rho)
    B_T = [0.0] * len(B_rho)
    f_f = [0.0] * len(f_rho)
    f_T = [0.0] * len(f_rho)

    g = config[0]
    alpha = config[1]
    v_i = B_rho + B_f + B_T + f_rho + f_f + f_T + [g, alpha]

    w_i = attention_module(v_i)

    # 3. FC-1: Fuse attention output with next layer features to match dimensions
    # [G] Next layer features are not available in this single-layer function;
    # in practice, FC-1 projects the attention output to the dimension of the next layer
    next_layer_dim = len(features[0])
    fc1_out = fc_layer(w_i, next_layer_dim)

    # 4. FC-2
    fc2_out = fc_layer(fc1_out, next_layer_dim)

    # 5. Fuse with current layer feature and output
    output = [fc2_out[k] + features[0][k] for k in range(next_layer_dim)]
    return output

def neural_volume_scattering_prediction(density_feats, trans_feats, phase_feats, config):
    # config = [g, alpha, albedo_r, albedo_g, albedo_b]
    n_layers_diffuse = 8
    n_layers_specular = 4

    # Diffuse reflection path (8 layers)
    diffuse_feats = density_feats
    for _ in range(n_layers_diffuse):
        diffuse_feats = process_layer(diffuse_feats, config, is_diffuse=True)

    # Specular reflection path (4 layers)
    specular_feats = density_feats
    for _ in range(n_layers_specular):
        specular_feats = process_layer(specular_feats, config, is_diffuse=False)

    # Merge diffuse and specular density features via FC
    merged_density = fc_layer(diffuse_feats, len(specular_feats))

    # Transmission and phase features layer-by-layer (12 times each)
    trans_feats_12 = trans_feats
    for _ in range(12):
        trans_feats_12 = process_layer(trans_feats_12, config, is_diffuse=True)

    phase_feats_12 = phase_feats
    for _ in range(12):
        phase_feats_12 = process_layer(phase_feats_12, config, is_diffuse=True)

    # Fuse transmission and phase features
    fused_trans_phase = [trans_feats_12[k] + phase_feats_12[k] for k in range(len(trans_feats_12))]

    # Multilayer Perceptron (MLP)
    # [G] Standard MLP with learned weights and ReLU activations
    mlp_out = fc_layer(fused_trans_phase, 3) # Output 3 channels for RGB scattering
    scattering_distribution = [max(0.0, v) for v in mlp_out]

    return scattering_distribution

def compute_loss(estimated, annotation, albedo, gamma=4):
    # L_S = 1/B * sum( (log(T^c(F)/(eta_c*gamma)) + 1 - log(F_i(p,l)/(eta_c*gamma)) + 1)^2 )
    loss = 0.0
    for c in range(3): # RGB channels
        term1 = math.log(estimated[c] / (albedo[c] * gamma)) + 1.0
        term2 = math.log(annotation[c] / (albedo[c] * gamma)) + 1.0
        loss += (term1 - term2) ** 2
    return loss / 3.0
```

## Subtopics

### [Neural Radiative Transfer Equation Solver](8466-neural-radiative-transfer-equation-solver.md)
A real-time volume rendering method that uses a neural network to simulate the iterative integration process of solving the Radiative Transfer Equation (RTE), replacing traditional path tracing to achieve real-time performance for high albedo anisotropic materials with multiple scattering. It sets itself apart from its sibling [Neural Volume Scattering Prediction](8439-neural-volume-scattering-prediction.md) and the earlier [Radiance-Predicting Neural Networks (RPNN)](8438-radiance-predicting-neural-networks-rpnn.md) by decomposing input features into density, transmission, and phase, and by using specific sampling templates (diffuse and highlight) to simplify the network structure and input parameters, thereby addressing RPNN's inability to handle shadows and its requirement for large sampling.

## Operating characteristics
*   **Time Complexity:** The method processes 4129 sampling templates [S1, unofficial]. To improve real-time rendering performance, multiple neural network models can be generated and calculated in parallel [S1, unofficial].
*   **Memory Complexity:** Requires storage for the pre-calculation table of sampling features and the neural network weights [S1, unofficial]. The network structure includes 6 identical modules (2 per feature type: diffuse/specular) with 8 layers for diffuse and 4 for specular [S1, unofficial].
*   **Measured Performance:** Designed for real-time rendering of high albedo anisotropic materials with multiple scattering [S1, unofficial].
*   **Strengths:**
    *   Logarithmic transformation compresses radiation range, speeding up training and reducing bright mutations from high-frequency phase functions [S1, unofficial].
*   **Limitations:**
    *   Requires pre-calculation of sampling features based on particle positions and template points [S1, unofficial].
    *   Assumes the 3D volume medium is homogeneous (albedo is equal everywhere within the same material) [S1, unofficial].
*   **When to use:** Suitable for real-time rendering of participating media with high albedo and anisotropic scattering properties [S1, unofficial].
*   **When not to use:** Not suitable for heterogeneous media where albedo varies significantly within a single material type, or for real-time applications where parallel model generation is not feasible [S1, unofficial].
