# Neural Radiative Transfer Equation Solver

Also called: Neural network-based real-time volume rendering method, RPNN variant with hierarchical transmittance and sampling templates

## Overview
A real-time volume rendering method that uses a neural network to simulate the iterative integration process of solving the Radiative Transfer Equation (RTE), replacing traditional path tracing to achieve real-time performance for high albedo anisotropic materials with multiple scattering [S1, unofficial]. It sets itself apart from its sibling [Neural Volume Scattering Prediction](8439-neural-volume-scattering-prediction.md) and the earlier [Radiance-Predicting Neural Networks (RPNN)](8438-radiance-predicting-neural-networks-rpnn.md) by decomposing input features into density, transmission, and phase, and by using specific sampling templates (diffuse and highlight) to simplify the network structure and input parameters, thereby addressing RPNN's inability to handle shadows and its requirement for large sampling [S1, unofficial].

## How it works
**Inputs:**
1.  Original 3D volumetric media density field, represented as a point cloud or voxel grid with resolution $1024 \times 1024 \times 1024$ [S1, unofficial].
2.  Incident light direction (implied by the highlight template geometry) [S1, unofficial].

**Outputs:**
1.  Scattering distribution for the center points of all sampling templates, which contributes to the final radiance calculation [S1, unofficial].

**Data Structures:**
1.  **Hierarchical Density Fields:** A set of 11 density fields $\rho_i$ at resolutions $R_i$ [S1, unofficial].
    *   $i=0: 1024^3$
    *   $i=1: 512^3$
    *   $i=2: 256^3$
    *   $i=3: 128^3$
    *   $i=4: 64^3$ (Note: Source text contains typo '624 * 64 * 64', corrected to $64^3$ based on sequence) [S1, unofficial].
    *   $i=5: 32^3$
    *   $i=6: 16^3$
    *   $i=7: 8^3$
    *   $i=8: 4^3$ (Note: Source text contains typo '4 * 4 * 4 * 4', corrected to $4^3$ based on sequence) [S1, unofficial].
    *   $i=9: 2^3$
    *   $i=10: 1^3$
2.  **Hierarchical Transmission Fields:** A set of 11 transmission fields $T_i(p, y)$, one for each density level [S1, unofficial].
3.  **Transmission Feature:** A single feature map resulting from the 3D-CNN processing of the 11 transmission fields [S1, unofficial].
4.  **Diffuse Reflection Sampling Template ($S_{diff}$):** A set of 182 points distributed in a sphere around a center point, divided into 8 layers [S1, unofficial].
    *   Layer 0: 6 points (1 center, 5 inside) [S1, unofficial].
    *   Layer 1: 8 points.
    *   Layer 2: 12 points.
    *   Layer 3: 16 points.
    *   Layer 4: 24 points.
    *   Layer 5: 32 points.
    *   Layer 6: 48 points.
    *   Layer 7: 48 points.
    *   Points in layers 1-7 are evenly distributed in the spherical shell between the current layer's surface and the previous layer's surface [S1, unofficial].
5.  **Highlight Sampling Template ($S_{high}$):** A set of 72 points distributed along the direction of incident light, divided into 4 layers [S1, unofficial].
    *   Layer 0: 32 points.
    *   Layer 1: 16 points.
    *   Layer 2: 16 points.
    *   Layer 3: 8 points.
    *   Points are evenly distributed by distance from the center [S1, unofficial].

**Parameters:**
*   $\lambda_{i+1}$: Coefficient for transmittance calculation, range $[0, 1]$, specific value $0.6$ [S1, unofficial].

**Steps:**

1.  **Data Processing (Hierarchical Transmittance):**
    For each density level $i$ from 0 to 10:
    a.  Obtain the density field $\rho_i(x)$ at resolution $R_i$ [S1, unofficial].
    b.  Calculate the transmission field $T_i(p, y)$ using the formula:
        $$ T_i(p, y) = e^{-\int_{p}^{y} \lambda_{i+1} \rho_i(x) dx} $$
        where $p$ is the starting point, $y$ is the ending point along the path, and $\lambda_{i+1} = 0.6$ [S1, unofficial].
    c.  Store the 11 transmission fields $T_0, \dots, T_{10}$ [S1, unofficial].

2.  **Transmission Feature Extraction:**
    a.  Input the 11 hierarchical transmission fields into a 3D Convolutional Neural Network (3D-CNN) [S1, unofficial].
    b.  The 3D-CNN assigns a weight to each level of transmission field and superimposes them to produce a single combined transmission feature [S1, unofficial].

3.  **Sampling Template Generation:**
    a.  Create the diffuse reflection sampling template $S_{diff}$ using a sphere divided into 8 layers [S1, unofficial].
    b.  Create the highlight sampling template $S_{high}$ divided into 4 layers along the incident light direction [S1, unofficial].

4.  **Feature Sampling:**
    For a given center point in the volume:
    a.  Sample the **density features** using both $S_{diff}$ and $S_{high}$ templates [S1, unofficial].
    b.  Sample the **transmission features** (from the combined feature map generated in Step 2) using both $S_{diff}$ and $S_{high}$ templates [S1, unofficial].
    c.  Sample the **phase features** (scattering phase function values) using both $S_{diff}$ and $S_{high}$ templates [S1, unofficial].
    d.  This results in sampled phase features, sampled density features, and sampled transmission features for each template layer [S1, unofficial].

5.  **Network Input Preparation:**
    a.  Layer the three types of sampled features (density, transmission, phase) according to the layers of the diffuse reflection sampling template and the highlight sampling template [S1, unofficial].
    b.  The sampled features of each layer are sent into the network for internal scattering estimation [S1, unofficial].

6.  **Attention Mechanism:**
    a.  Pass the layered features through an attention module [S1, unofficial].
    b.  The module selects important channel features to pay more attention to light scattering, highlights, and shadows [S1, unofficial].

7.  **Scattering Prediction:**
    a.  Feed the attended features into the backbone neural network [S1, unofficial].
    b.  Predict the scattering distribution for the center points of all sampling templates ($S_{diff}$ and $S_{high}$) [S1, unofficial].

**Pseudocode:**

```python
import math

def downsample(volume, target_res):
    """Downsamples a 3D volume to target_res using average pooling."""
    src_res = len(volume)
    stride = src_res // target_res
    downsampled = [[[0.0 for _ in range(target_res)] for _ in range(target_res)] for _ in range(target_res)]
    for z in range(target_res):
        for y in range(target_res):
            for x in range(target_res):
                sum_val = 0.0
                count = 0
                for dz in range(stride):
                    for dy in range(stride):
                        for dx in range(stride):
                            sum_val += volume[z * stride + dz][y * stride + dy][x * stride + dx]
                            count += 1
                downsampled[z][y][x] = sum_val / count
    return downsampled

def compute_transmittance_field(density_field, lambda_coeff):
    """
    Computes transmission field T_i(p, y) = exp(-int_p^y lambda * rho_i(x) dx).
    Assumes a standard ray-marching integration along the viewing direction.
    """
    # Source does not specify the exact integration path discretization.
    # [G] Implementing a simplified per-voxel optical depth accumulation along the z-axis.
    res = len(density_field)
    transmission_field = [[[0.0 for _ in range(res)] for _ in range(res)] for _ in range(res)]
    for z in range(res):
        for y in range(res):
            optical_depth = 0.0
            for x in range(res):
                optical_depth += lambda_coeff * density_field[z][y][x]
                transmission_field[z][y][x] = math.exp(-optical_depth)
    return transmission_field

def generate_diffuse_template():
    """Generates the diffuse reflection sampling template S_diff (182 points, 8 layers)."""
    layers = [6, 8, 12, 16, 24, 32, 48, 48]
    template = []
    base_radius = 1.0
    for i, num_points in enumerate(layers):
        points = []
        if i == 0:
            # Layer 0: 1 center, 5 inside
            points.append([0.0, 0.0, 0.0])
            for k in range(5):
                theta = math.sqrt(k + 1) * math.pi
                phi = 2 * math.pi * k / 1.618
                r = 0.2
                points.append([r * math.sin(theta) * math.cos(phi), r * math.sin(theta) * math.sin(phi), r * math.cos(theta)])
        else:
            # Layers 1-7: Evenly distributed in spherical shell
            prev_r = base_radius * (i - 1) / 7.0
            curr_r = base_radius * i / 7.0
            for k in range(num_points):
                theta = math.sqrt(k + 1) * math.pi
                phi = 2 * math.pi * k / 1.618
                r = (prev_r + curr_r) / 2.0
                points.append([r * math.sin(theta) * math.cos(phi), r * math.sin(theta) * math.sin(phi), r * math.cos(theta)])
        template.append(points)
    return template

def generate_highlight_template():
    """Generates the highlight sampling template S_high (72 points, 4 layers)."""
    layers = [32, 16, 16, 8]
    template = []
    for i, num_points in enumerate(layers):
        points = []
        z = (i + 1) * 0.25
        for k in range(num_points):
            theta = math.sqrt(k + 1) * math.pi
            phi = 2 * math.pi * k / 1.618
            r = 0.5
            x = r * math.sin(theta) * math.cos(phi)
            y = r * math.sin(theta) * math.sin(phi)
            points.append([x, y, z])
        template.append(points)
    return template

def sample_features(density_field, transmission_feature, phase_field, template):
    """Samples density, transmission, and phase features at template points using trilinear interpolation."""
    sampled = []
    res = len(density_field)
    for layer_points in template:
        layer_samples = []
        for point in layer_points:
            # Normalize point to [0, 1]
            px, py, pz = point[0] / 2.0 + 0.5, point[1] / 2.0 + 0.5, point[2] / 2.0 + 0.5
            # Trilinear interpolation (simplified)
            d = density_field[int(pz * res)][int(py * res)][int(px * res)]
            t = transmission_feature[int(pz * res)][int(py * res)][int(px * res)]
            p = phase_field[int(pz * res)][int(py * res)][int(px * res)]
            layer_samples.append([d, t, p])
        sampled.append(layer_samples)
    return sampled

def three_d_cnn_forward(transmission_fields):
    """Superimposes 11 transmission fields with learned weights."""
    # Source does not specify exact weights or architecture.
    # [G] Assuming a simple weighted sum as described: "adds a weight to each level... superimposes".
    combined = [[[0.0 for _ in range(len(transmission_fields[0]))] for _ in range(len(transmission_fields[0][0]))] for _ in range(len(transmission_fields[0][0][0]))]
    weights = [0.1] * 11
    for i, field in enumerate(transmission_fields):
        for z in range(len(field)):
            for y in range(len(field[0])):
                for x in range(len(field[0][0])):
                    combined[z][y][x] += weights[i] * field[z][y][x]
    return combined

def attention_forward(features):
    """Selects important channel features."""
    # Source does not specify attention mechanism details.
    # [G] Applying a simple channel-wise scaling factor.
    return [[f * 1.2 for f in layer] for layer in features]

def backbone_forward(attended_features):
    """Predicts scattering distribution."""
    # Source does not specify backbone architecture.
    # [G] Flattening and applying a linear transformation.
    flat = [val for layer in attended_features for point in layer for val in point]
    return [val * 0.5 for val in flat]

def neural_radiative_transfer_solver(density_field_1024):
    """Main pipeline for the Neural Radiative Transfer Equation Solver."""
    resolutions = [1024, 512, 256, 128, 64, 32, 16, 8, 4, 2, 1]
    density_fields = [downsample(density_field_1024, res) for res in resolutions]

    lambda_coeff = 0.6
    transmission_fields = [compute_transmittance_field(field, lambda_coeff) for field in density_fields]
    transmission_feature = three_d_cnn_forward(transmission_fields)

    s_diff = generate_diffuse_template()
    s_high = generate_highlight_template()

    # Phase field generation is not detailed in the source.
    # [G] Assuming a constant phase field or derived from density.
    phase_field = [[[1.0 for _ in range(len(density_fields[0]))] for _ in range(len(density_fields[0][0]))] for _ in range(len(density_fields[0][0][0]))]

    sampled_diff = sample_features(density_fields[0], transmission_feature, phase_field, s_diff)
    sampled_high = sample_features(density_fields[0], transmission_feature, phase_field, s_high)

    # Layer the features as described
    input_features = sampled_diff + sampled_high

    attended_features = attention_forward(input_features)
    scattering_distribution = backbone_forward(attended_features)

    return scattering_distribution
```

## Subtopics

### Hierarchical Transmittance
A technique to represent optical depth at multiple resolutions to capture both fine details and global lighting effects efficiently [S1, unofficial]. It sets itself apart by using a fixed coefficient $\lambda=0.6$ to scale density before integration, simplifying the transmittance calculation compared to full path tracing [S1, unofficial]. Choose it when rendering large volumes with varying density scales [S1, unofficial]. [Link to Hierarchical Transmittance](8440-hierarchical-transmittance.md)

### Diffuse Reflection Sampling Template
A spherical sampling pattern designed to capture isotropic scattering contributions [S1, unofficial]. It sets itself apart from the highlight template by focusing on general scattering rather than directional highlights [S1, unofficial]. Choose it for rendering the bulk appearance of participating media [S1, unofficial]. [Link to Diffuse Template](8441-diffuse-sampling-template.md)

### Highlight Sampling Template
A directional sampling pattern aligned with the light source to capture specular-like highlights and shadowing effects [S1, unofficial]. It sets itself apart from the diffuse template by focusing on the light direction [S1, unofficial]. Choose it when accurate highlights and shadows are critical [S1, unofficial]. [Link to Highlight Template](8442-highlight-sampling-template.md)

## Operating characteristics
*   **Time Complexity:** Real-time performance is claimed, significantly faster than traditional path tracing [S1, unofficial]. The complexity is dominated by the 3D-CNN inference and the sampling operations, which are constant per pixel/voxel based on the fixed template sizes (182 + 72 = 254 points) [S1, unofficial].
*   **Memory Complexity:** Requires storing 11 hierarchical density fields and 11 transmission fields [S1, unofficial].
*   **Measured Performance:** The source claims "greatly increase the rendering speed while maintaining rendering quality" and "outperforms previous methods" [S1, unofficial]. Specific FPS or hardware details are not given.
*   **Strengths:** Real-time rendering, handles high albedo anisotropic materials with multiple scattering, better handling of shadows and highlights compared to RPNN, simplified network structure [S1, unofficial].
*   **Limitations:** Requires pre-computation of hierarchical fields, relies on neural network approximation which may not generalize to all material types, specific template geometry limits flexibility [S1, unofficial].
*   **When to use:** Real-time applications requiring realistic volumetric rendering of participating media like clouds, smoke, or translucent materials [S1, unofficial].
*   **When not to use:** Not given in the sources.

## Background
The method originates from a paper titled "A real-time rendering method for high albedo anisotropic materials with multiple scattering" [S1, unofficial]. It was developed to address the limitations of previous Neural Radiance Prediction Neural Networks (RPNN), which only accepted density features, required large sampling, and struggled with shadows [S1, unofficial]. The work builds on the concept of using neural networks to solve the Radiative Transfer Equation (RTE) iteratively, as introduced in earlier works on neural volume rendering [S1, unofficial].
