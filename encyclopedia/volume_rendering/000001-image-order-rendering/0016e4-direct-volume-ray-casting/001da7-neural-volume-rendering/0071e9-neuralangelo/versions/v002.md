# Neuralangelo

Also called: Neuralangelo reconstruction

## Overview
Neuralangelo is a framework for high-fidelity 3D surface reconstruction from multi-view RGB images using neural volume rendering, specifically designed to recover dense, detailed 3D surface structures without auxiliary data such as depth or segmentation [S2]. It distinguishes itself from sibling methods like [NeRF Volumetric Rendering (Coarse/Fine Sampling)](979-nerf-volumetric-rendering-coarse-fine-sampling.md) by combining multi-resolution 3D hash grids (Instant NGP-style) with neural surface rendering based on Signed Distance Fields (SDF) [S2]. Unlike concurrent approaches that use displacement networks to correct shape, Neuralangelo controls detail levels through hierarchical hash grids and utilizes numerical gradients to compute higher-order derivatives as a smoothing operation [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A set of posed RGB images $\{I_k\}$ of a static scene [S2].
*   **Outputs:** A reconstructed 3D mesh extracted from the learned neural SDF, and a neural representation (hash grids + MLPs) capable of rendering novel views [S2].

**Data Structures:**
1.  **Multi-resolution Hash Grids:** A set of $L$ hash grids, where each grid $l \in \{1, \dots, L\}$ has a resolution $T_l$ (number of entries) [S2][S4, unofficial]. Each entry stores a feature vector $\mathbf{f} \in \mathbb{R}^D$ [G]. The hash function maps a 3D coordinate $\mathbf{x}$ to a grid index and a local position within the cell [S2][S4, unofficial].
2.  **SDF MLP:** A Multi-Layer Perceptron that takes the aggregated hash features and outputs a scalar Signed Distance Field value $\tilde{s}$ [S2].
3.  **Color MLP:** A separate Multi-Layer Perceptron that outputs the color $\mathbf{c}$ given the hash features and viewing direction $\mathbf{d}$ [S2][G].

**Numbered Steps:**
1.  **Sampling:** For each pixel in the training images, cast a ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ [S2]. Sample $N$ points $\{t_i\}_{i=1}^N$ along the ray within the scene bounds [S2].
2.  **Hash Encoding:** For each sampled point $\mathbf{x}_i$, query all $L$ hash grids to retrieve multi-resolution features [S2].
3.  **Neural Prediction:**
    *   Feed the aggregated features into the SDF MLP to predict the raw signed distance $\tilde{s}_i$ [S2].
    *   Feed the aggregated features and the viewing direction $\mathbf{d}$ into the Color MLP to predict the raw color $\tilde{\mathbf{c}}_i$ [S2][G].
4.  **SDF-based Volume Rendering:** Convert the raw SDF $\tilde{s}_i$ to density $\sigma_i$ and opacity $\alpha_i$ using a softplus activation and a scaling factor $\beta$ (temperature) [S2]:
    $$
    \sigma_i = \text{softplus}(-\beta \tilde{s}_i)
    $$
    $$
    \alpha_i = 1 - \exp(-\sigma_i \Delta t_i)
    $$
    where $\Delta t_i$ is the distance between adjacent samples [G]. The final color is computed using the standard front-to-back volume rendering equation (see [Direct volume ray casting](19-direct-volume-ray-casting.md)) [S2].
5.  **Loss Computation:** Minimize the photometric loss between rendered and ground truth images, and a surface regularization loss based on the mean curvature of the SDF level sets [S3].
6.  **Optimization with Numerical Gradients:**
    *   Instead of using analytical gradients for the hash grid features, Neuralangelo uses **numerical gradients** to update the hash grid parameters [S4, unofficial].
    *   Compute the gradient of the loss with respect to the hash grid features $\mathbf{f}$ using finite differences with a step size $\epsilon$:
        $$
        \nabla_{\mathbf{f}} \mathcal{L} \approx \frac{\mathcal{L}(\mathbf{f} + \epsilon \mathbf{u}) - \mathcal{L}(\mathbf{f} - \epsilon \mathbf{u})}{2\epsilon} \mathbf{u}
        $$
        where $\mathbf{u}$ is a random direction vector [S4, unofficial].
    *   **Coarse-to-Fine Strategy:** Start with a large step size $\epsilon$ (larger than the hash grid cell size) to encourage communication between neighboring grid cells and smooth the geometry [S4, unofficial]. Progressively decrease $\epsilon$ during training to refine fine details [S2][S4, unofficial].

**Pseudocode:**

```python
import numpy as np

def softplus(x):
    return np.log(np.exp(x) + 1)

def trilinear_interpolate(grid, coords):
    """Standard trilinear interpolation on a 3D grid [G]."""
    # coords: (N, 3), grid: (Dx, Dy, Dz, D)
    # Simplified for pseudocode: assumes grid is already flattened or indexed
    # In practice, this hashes coordinates, finds 8 neighbors, and interpolates weights.
    return np.zeros((coords.shape[0], grid.shape[-1]))

def query_hash_grid(points, hash_grids):
    """
    Queries multi-resolution hash grids for points.
    points: (N, 3) coordinates
    hash_grids: list of L grids, each with shape (T_l, D)
    Returns: (N, D_total) aggregated features
    """
    features = []
    for grid in hash_grids:
        # Hash coordinates to indices and interpolate features [G]
        feats = trilinear_interpolate(grid, points)
        features.append(feats)
    return np.concatenate(features, axis=-1)

def neuralangelo_forward(ray_o, ray_d, t_near, t_far, hash_grids, sdf_mlp, color_mlp, num_samples, beta):
    """
    Forward pass for Neuralangelo rendering.
    ray_o: Camera origin (3,)
    ray_d: Camera direction (3,)
    t_near, t_far: Ray segment bounds
    hash_grids: List of L hash grids
    sdf_mlp: Function taking features -> (sdf,)
    color_mlp: Function taking features, view_dir -> color
    num_samples: Number of points along the ray
    beta: Temperature for SDF to density conversion
    """
    # 1. Sample points along the ray
    t_vals = np.linspace(t_near, t_far, num_samples)
    points = ray_o + t_vals[:, None] * ray_d  # Shape: (num_samples, 3)
    delta_t = t_vals[1] - t_vals[0]  # Uniform step size [G]

    # 2. Hash Encoding
    h = query_hash_grid(points, hash_grids)  # Shape: (num_samples, D_total)

    # 3. Neural Prediction
    sdf_raw = sdf_mlp(h)  # Shape: (num_samples,)
    color_raw = color_mlp(h, ray_d)  # Shape: (num_samples, 3)

    # 4. SDF to Density and Opacity
    sigma = softplus(-beta * sdf_raw)  # Shape: (num_samples,)
    alpha = 1.0 - np.exp(-sigma * delta_t)  # Shape: (num_samples,)

    # 5. Volume Rendering (Front-to-Back)
    transmittance = np.ones(num_samples + 1)
    for i in range(num_samples):
        transmittance[i+1] = transmittance[i] * (1.0 - alpha[i])
    
    weights = alpha * transmittance[:-1]
    color_out = np.sum(weights[:, None] * color_raw, axis=0)
    
    return color_out, sdf_raw, alpha

def update_hash_grids_numerical(hash_grids, loss_fn, points, ray_d, sdf_mlp, color_mlp, step_size, learning_rate):
    """
    Update hash grid features using numerical gradients.
    """
    for grid in hash_grids:
        current_feats = grid.copy()
        loss_current = loss_fn(points, ray_d, hash_grids, sdf_mlp, color_mlp)
        
        direction = np.random.randn(*current_feats.shape)
        perturbed_feats = current_feats + step_size * direction
        grid[:] = perturbed_feats
        loss_perturbed = loss_fn(points, ray_d, hash_grids, sdf_mlp, color_mlp)
        
        grad = (loss_perturbed - loss_current) / (2 * step_size) * direction
        grid[:] = current_feats - learning_rate * grad
```

**Parameters:**
*   **Step Size ($\epsilon$):** Controls the magnitude of numerical gradient updates. Large steps ($> \text{grid size}$) enable cross-cell communication; small steps ($< \text{grid size}$) approximate analytical gradients [S4, unofficial].
*   **Beta ($\beta$):** Temperature parameter for SDF-to-density conversion. Not given in the sources.
*   **Hash Grid Resolutions:** Number of levels and specific resolutions. Not given in the sources.

**Edge Cases and Pitfalls:**
*   **Highly Reflective Scenes:** Neuralangelo struggles with highly reflective surfaces, potentially missing structures like buttons or eyes [S4, unofficial].
*   **Step Size Scheduling:** The coarse-to-fine optimization schedule mitigates convergence issues by starting with large steps for smooth geometry and decreasing them for fine details [S2][S4, unofficial].

## Subtopics

### Hash Grid Encoding
A sparse feature representation that maps 3D coordinates to multi-resolution feature vectors using hash functions [S2][G]. It enables efficient training and rendering by reducing memory footprint and computation compared to dense grids [G]. Choose this when memory efficiency and training speed are critical [S2].

### SDF-based Volume Rendering
A rendering technique that uses Signed Distance Fields to define geometry [S2]. It provides more stable surface extraction and better regularization than density-based NeRFs [S3]. Choose this when high-fidelity mesh extraction is required [S2].

## Operating characteristics
*   **Time Complexity:** Training time is significantly reduced compared to standard NeRFs due to the use of hash grids, but numerical gradient computation adds overhead per step [S4, unofficial]. Rendering time is fast due to the efficient hash lookups [G].
*   **Memory Complexity:** Memory usage is proportional to the total number of hash grid entries [G]. It is much more memory-efficient than dense voxel grids [G].
*   **Measured Performance:** Neuralangelo achieves state-of-the-art results in both view synthesis and geometry reconstruction on datasets like DTU and Tanks and Temples [S3].
*   **Strengths:** High-fidelity surface reconstruction, ability to handle large-scale scenes, no need for auxiliary data (depth/segmentation) [S2].
*   **Limitations:** Struggles with highly reflective scenes [S4, unofficial].

## Background
Neuralangelo was introduced by Li et al. at CVPR 2023 by NVIDIA researchers [S4, unofficial]. It builds upon the Instant NGP hash grid encoding and the neural surface rendering framework (like NeuS) to address the limitations of previous methods in recovering detailed structures from real-world scenes [S2]. The method was developed to enable high-fidelity 3D asset generation for augmented/virtual/mixed reality applications [S2].
