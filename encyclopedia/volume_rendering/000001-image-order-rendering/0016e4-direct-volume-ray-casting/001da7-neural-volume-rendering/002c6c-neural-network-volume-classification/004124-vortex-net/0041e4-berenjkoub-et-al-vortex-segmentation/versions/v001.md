# Berenjkoub et al. vortex segmentation
Also called: Vortex segmentation using synthetic cylinder flows

## Overview
A method that trains convolutional neural networks (CNNs) on synthetic cylinder flows with analytically known vortex boundaries to identify vortices in volumetric data, eliminating the need for manual threshold tuning associated with traditional criteria like $\lambda_2$ [S1, unofficial]. It sets itself apart from its parent [Vortex-Net](10429-vortex-net.md) by replacing the replication of a specific criterion's boundary with direct supervised learning on ground-truth synthetic data, thereby removing the bottleneck of threshold selection entirely [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: 2D flow patches of size $64 \times 64$.
- Output: Binary segmentation mask indicating vortex presence.

**Data Structures:**
- Synthetic Cylinder Flows: Parametrically generated 2D velocity fields where the vortex boundary is defined analytically.
- Patches: Extracted $64 \times 64$ sub-regions from the 2D flow fields.
- Ground Truth: Binary labels derived directly from the analytical boundary definition, requiring no thresholding [S1, unofficial].

**Steps:**
1. **Generate Synthetic Data:** Create a dataset of synthetic cylinder flows. The vortex boundaries are known analytically, providing perfect ground truth labels without ambiguity [S1, unofficial].
2. **Patch Extraction:** Extract $64 \times 64$ patches from the 2D flow fields. These patches serve as the input samples for training [S1, unofficial].
3. **Model Training:** Train three architectures: a standard CNN, a ResNet, and a U-Net. The models learn to map the velocity field patches to the binary vortex labels [S1, unofficial].
4. **Evaluation:** Evaluate the segmentation performance using the F-score metric [S1, unofficial].

**Pseudocode:**
```python
# Pseudocode for the training pipeline described in [S1, unofficial]

def generate_synthetic_cylinder_flow(patches_per_flow, patch_size=64):
    """
    Generates synthetic 2D cylinder flows with analytically known boundaries.
    Returns a list of (flow_patch, ground_truth_mask) tuples.
    """
    data = []
    for _ in range(patches_per_flow):
        # Generate parametric flow field
        flow_field = create_cylinder_flow()
        
        # Extract random 64x64 patches
        for _ in range(100): # Example iteration count
            x, y = random_patch_coordinates(flow_field.shape)
            patch = flow_field[x:x+patch_size, y:y+patch_size]
            
            # Derive ground truth from analytical boundary
            # The boundary is known, so we can compute exact binary mask
            mask = compute_analytical_vortex_mask(patch)
            
            data.append((patch, mask))
    return data

def train_segmentation_models(data):
    """
    Trains CNN, ResNet, and U-Net architectures on the synthetic data.
    """
    models = {
        'CNN': build_cnn(),
        'ResNet': build_resnet(),
        'U-Net': build_unet() # U-Net includes skip connections
    }
    
    results = {}
    for name, model in models.items():
        # Standard binary cross-entropy or similar loss
        model.compile(loss='binary_crossentropy', optimizer='adam')
        
        # Train on patches
        patches, masks = zip(*data)
        model.fit(patches, masks, epochs=100, batch_size=32)
        
        # Evaluate F-score
        predictions = model.predict(patches)
        f_score = calculate_f_score(masks, predictions)
        results[name] = f_score
        
    return results

def calculate_f_score(true_masks, pred_masks):
    """
    Computes the F-score (F1-score) for binary segmentation.
    """
    # Convert predictions to binary (threshold at 0.5)
    pred_binary = (pred_masks > 0.5).astype(int)
    true_binary = true_masks.astype(int)
    
    tp = np.sum((pred_binary == 1) & (true_binary == 1))
    fp = np.sum((pred_binary == 1) & (true_binary == 0))
    fn = np.sum((pred_binary == 0) & (true_binary == 1))
    
    precision = tp / (tp + fp + 1e-8)
    recall = tp / (tp + fn + 1e-8)
    
    f_score = 2 * (precision * recall) / (precision + recall + 1e-8)
    return f_score
```

**Parameters:**
- Patch Size: $64 \times 64$ pixels [S1, unofficial].
- Architectures: CNN, ResNet, U-Net [S1, unofficial].
- Metric: F-score [S1, unofficial].

**Edge Cases and Pitfalls:**
- Validation was performed on a single 2D flow configuration. This raises concerns about the method's transferability to 3D turbulent fields [S1, unofficial].

## Subtopics

### Bai et al. 3D Vortex Segmentation
A method that operates directly on 3D grids using an MLP for local velocity vector classification to identify vortices and flow regimes, avoiding the memory overhead of 3D convolutions [S1, unofficial]. It differs from Berenjkoub et al. by handling 3D volumetric data natively rather than relying on 2D patches, and by including a separate classification network for flow regimes based on the relationship between local vorticity magnitude and Reynolds number [S1, unofficial]. On 3D shockwave volumes ($81 \times 81 \times 81$ to $161 \times 81 \times 81$), it achieved 99.76% segmentation accuracy with >50% time reduction and >99% classification accuracy with 90% time reduction compared to traditional criteria [S1, unofficial].

## Operating characteristics
- **Time Complexity:** Not given in the sources.
- **Memory Complexity:** Not given in the sources.
- **Measured Performance:** U-Net achieved the highest F-score of 0.997 on the synthetic 2D cylinder flow data [S1, unofficial].
- **Strengths:** Eliminates the need for manual threshold tuning, which is a bottleneck for criteria like $\lambda_2$ [S1, unofficial]. U-Net's skip connections preserve boundary detail effectively [S1, unofficial].
- **Limitations:** Validated only on a single 2D flow configuration; transfer to 3D turbulent fields is unverified [S1, unofficial].
- **When to use:** When precise vortex boundary identification is required and manual threshold tuning is undesirable, particularly for 2D flow analysis.
- **When not to use:** For 3D turbulent fields where transferability has not been established, or when computational resources for 3D convolutions are not a constraint and 3D context is critical (consider [Bai et al. 3D Vortex Segmentation](10429-vortex-net.md#bai-et-al-3d-vortex-segmentation) instead).

## Background
The method was introduced by Berenjkoub et al. [9] as a response to the bottleneck of threshold selection in vortex identification criteria like $\lambda_2$, which often require manual adjustment to match visual expectations [S1, unofficial]. It builds on the idea of using synthetic data with known ground truth to train neural networks, a concept also explored in [Vortex-Net](10429-vortex-net.md) but applied here to bypass criterion-specific boundaries entirely [S1, unofficial]. The approach was validated against CNN, ResNet, and U-Net architectures [S1, unofficial].
