# Neural Volume Raycasting Debug Visualization

Also called: Debug Visualization Pipeline for Neural Volumes

## Overview
This method provides a diagnostic visualization pipeline for neural volume models by rendering individual sample points as instanced spheres, colored by the network's predicted radiance and filtered by an opacity threshold [S1, unofficial]. It differs from standard volume rendering by bypassing the differentiable compositing integral to directly inspect the raw spatial distribution and magnitude of neural network outputs, helping to identify sampling artifacts or convergence issues [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A trained neural network model (typically an MLP), a dataset of camera rays (positions and optional view directions), and configuration parameters (`empty_threshold`, `num_samples`).
*   **Output:** A visualization scene (e.g., HTML/Scenepic format) containing instanced spheres representing non-empty sample points.

**Data Structures:**
*   **Rays:** Defined by origin $\mathbf{o}$ and direction $\mathbf{d}$. Sample points $\mathbf{p}_i$ are derived from ray parameters.
*   **Model Output:** A tensor of shape `(batch_size, num_samples, 4)`, where the last dimension contains `[R, G, B, opacity]`.
*   **Instanced Mesh:** A collection of spheres (base geometry) with per-instance attributes:
    *   `position`: $(x, y, z)$ coordinates of the sample point.
    *   `color`: $(r, g, b)$ predicted radiance.
    *   `scale`: Uniform scaling factor (default $0.02$).

**Parameters:**
*   `empty_threshold`: Opacity threshold to classify samples as empty. Default: $0.1$ [S1, unofficial].
*   `num_samples`: Number of samples per ray used for reshaping model output. Default: $64$ [S1, unofficial].

**Steps:**
1.  **Ray Subsampling:** Select a subset of rays from the dataset using a precomputed index set to reduce computational load during debugging [S1, unofficial].
2.  **Data Preparation:** For each camera, fetch the associated rays. Move ray sample positions and view directions to the model's compute device. Reshape positions to `(-1, 3)` [S1, unofficial].
3.  **Neural Query:** Pass positions (and view directions if the model is view-dependent) to the neural network. The model returns raw outputs `color_o` [S1, unofficial].
4.  **Reshape and Split:** Reshape `color_o` to `(-1, num_samples, 4)`. Split the last dimension into color (3 channels) and opacity (1 channel) [S1, unofficial].
5.  **Activation:** Apply activation functions to normalize outputs:
    *   Color: Apply sigmoid to clamp values to $[0, 1]$ [S1, unofficial].
    *   Opacity: Apply softplus to ensure non-negative values [S1, unofficial].
6.  **Classification:** Convert tensors to CPU numpy arrays. Classify samples as empty if `opacity < empty_threshold` [S1, unofficial].
7.  **Visualization Construction:** Create instanced sphere meshes:
    *   Non-empty samples: Use white base color with per-instance colors from the predicted radiance.
    *   Empty samples: Use a shared black color (or omit them).
    *   Scale all spheres to $0.02$ [S1, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn.functional as F
import numpy as np

def debug_visualize(model, dataset, args):
    """
    Visualize neural volume samples as instanced spheres.
    
    Args:
        model: Neural network model (MLP)
        dataset: Ray dataset object
        args: Configuration arguments including empty_threshold, num_samples, mode
        
    Returns:
        scene: Visualization scene object (e.g., Scenepic)
    """
    # 1. Subsample rays
    if args.num_cameras and args.num_cameras < dataset.num_cameras:
        dataset = dataset.sample_cameras(args.num_cameras, args.num_samples, args.stratified)
    
    # Set dataset mode if specified
    if args.mode == "sparse":
        dataset.mode = RayDataset.Mode.Sparse
    elif args.mode == "center":
        dataset.mode = RayDataset.Mode.Center
    elif args.mode == "dilate":
        dataset.mode = RayDataset.Mode.Dilate
        
    # Initialize scene
    scene = dataset.to_scenepic()
    
    # 2. Iterate over cameras and fetch rays
    all_positions = []
    all_colors = []
    
    for i in range(dataset.num_cameras):
        # Fetch rays for current camera
        ray_samples = dataset.rays_for_camera(i)
        
        # Move to device and reshape positions
        positions = ray_samples.positions.to(model.device)
        positions = positions.view(-1, 3)
        
        # Handle view directions if model uses them
        if model.uses_view_directions:
            views = ray_samples.views.to(model.device)
            views = views.view(-1, 3)
            color_o = model(positions, views)
        else:
            color_o = model(positions)
            
        # 3. Reshape and split output
        # Ensure output shape matches (batch, num_samples, 4)
        color_o = color_o.view(-1, args.num_samples, 4)
        color, opacity = torch.split(color_o, [3, 1], dim=-1)
        
        # 4. Apply activations
        color = torch.sigmoid(color)
        opacity = F.softplus(opacity)
        
        # 5. Convert to numpy and classify
        positions_np = positions.cpu().numpy()
        color_np = color.cpu().numpy()
        opacity_np = opacity.cpu().numpy()
        
        # Flatten for processing
        positions_np = positions_np.reshape(-1, 3)
        color_np = color_np.reshape(-1, 3)
        opacity_np = opacity_np.reshape(-1)
        
        # Classify empty vs non-empty
        empty_mask = opacity_np < args.empty_threshold
        
        # Store non-empty samples
        non_empty_positions = positions_np[~empty_mask]
        non_empty_colors = color_np[~empty_mask]
        
        all_positions.append(non_empty_positions)
        all_colors.append(non_empty_colors)
        
    # 6. Create instanced spheres
    # Combine all non-empty samples
    if all_positions:
        final_positions = np.vstack(all_positions)
        final_colors = np.vstack(all_colors)
        
        # Create instanced mesh with scale 0.02
        # Note: Implementation details for Scenepic instancing depend on the library API
        # Base geometry: Sphere
        # Instance attributes: position, color, scale=0.02
        scene.add_instanced_spheres(
            positions=final_positions,
            colors=final_colors,
            scale=0.02,
            base_color=(1.0, 1.0, 1.0) # White base, modulated by instance color
        )
        
    # Save visualization
    scene.save_as_html(args.output_path, "Ray Sampling")
    return scene
```

**Edge Cases and Pitfalls:**
*   **Shape Mismatch:** The model output shape must strictly match `(batch, num_samples, 4)`. If the model returns a different shape, the split and reshape operations will fail or misalign color/opacity channels [S1, unofficial].
*   **Precision:** Ensure that the `empty_threshold` is chosen carefully; too low a threshold may visualize noise, while too high may hide valid structure.

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of sampled points across all rays. The dominant cost is the neural network forward pass.
*   **Memory Complexity:** Linear with respect to the number of samples, storing positions, colors, and opacities for visualization.
*   **Strengths:** Provides immediate visual feedback on the spatial distribution of neural network predictions; helps debug issues with sampling density or network convergence.
*   **Limitations:** Not suitable for final image generation; does not account for occlusion or compositing; performance degrades with very high sample counts due to the number of instanced objects.
*   **When to Use:** During model development and debugging to inspect raw neural volume outputs.
*   **When Not to Use:** For final rendering or performance-critical applications.

## Background
This method originates from the implementation of Fourier Feature Networks for Neural Volume Rendering, specifically within the context of debugging and visualizing the intermediate outputs of the neural network [S1, unofficial]. It leverages the ability of neural networks to represent continuous volumetric fields and provides a direct way to inspect these representations without the complexity of differentiable rendering integrals.
