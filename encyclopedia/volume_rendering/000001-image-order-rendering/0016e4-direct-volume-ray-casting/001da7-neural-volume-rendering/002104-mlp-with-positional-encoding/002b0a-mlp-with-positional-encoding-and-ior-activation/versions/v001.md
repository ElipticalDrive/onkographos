# MLP with Positional Encoding and IOR Activation

Also called: MLP with Skip Connections and Refractive Index Activation

## Overview
This method extends the standard neural volume rendering MLP by constraining the output to represent a physically plausible refractive index (IOR) field. While the parent [MLP with Positional Encoding](2416-mlp-with-positional-encoding.md) predicts RGB color and density, this variant predicts a scalar field (refractive index) used in ray tracing simulations for transparent or refractive media. It is distinguished by a specific post-processing activation function (`ior_act`) that maps the MLP's raw output to a positive range $[1, \infty)$, ensuring physical validity for light propagation.

## How it works
**Inputs:**
- `x`: Input feature vector. Typically the positional encoding of 3D coordinates $(x, y, z)$.
- `deg_point`: Integer degree for positional encoding.
- `net_depth`: Integer depth of the hidden layers.
- `net_width`: Integer width of the hidden layers.
- `do_skip`: Boolean flag for skip connections.
- `activation`: Choice of activation function (ReLU or ELU).
- `ior_den`: Denominator for the IOR scaling factor.

**Outputs:**
- `eta`: Scalar field representing the refractive index at the input position.

**Data Structures:**
- The MLP consists of a sequence of dense (fully connected) layers.
- Weights are initialized using He uniform initialization.
- The final layer outputs a single scalar value (`out_channel = 1`).

**Parameters:**
- `net_depth`: Default 4.
- `net_width`: Default 128 (for dark matter simulations) or 256 (for gas/neural field simulations).
- `deg_point`: Default 4 or 6.
- `ior_den`: Default 400.
- `do_skip`: Default `True` for dark matter, `False` for gas/neural fields.
- `activation`: `nn.relu` for dark matter, `nn.elu` for gas/neural fields.

**Algorithm:**
1.  **Positional Encoding:** Apply positional encoding to the input coordinates $x$. Let $x_{enc} = \text{posenc}(x, \text{deg\_point})$.
2.  **Skip Connection Storage:** Store the encoded input for potential skip connections: $inputs = x_{enc}$.
3.  **Hidden Layers:** Iterate $i$ from $0$ to $\text{net\_depth} - 1$:
    a. Apply a dense layer with width $\text{net\_width}$: $x = \text{Dense}_{\text{net\_width}}(x)$.
    b. Apply the chosen activation function: $x = \text{Activation}(x)$.
    c. **Skip Connection Logic:** If `do_skip` is true, and $i > 0$, and $i$ is a multiple of $\lfloor \text{net\_depth} / 2 \rfloor$:
        i. Concatenate the current representation $x$ with the original encoded input $inputs$ along the feature axis: $x = \text{concat}(x, inputs)$.
4.  **Output Layer:** Apply a final dense layer with 1 output channel: $y = \text{Dense}_1(x)$.
5.  **IOR Activation:** Apply the refractive index activation function to constrain the output:
    $$ \eta = \frac{\text{softplus}(y - 2)}{\text{ior\_den}} + 1 $$
    Where $\text{softplus}(z) = \ln(1 + e^z)$.

**Pseudocode:**
```python
import jax.numpy as jnp
from jax import nn

def mlp_with_ior_activation(x, params, deg_point, net_depth, net_width, do_skip, activation_fn, ior_den):
    """
    x: Input coordinates, shape (..., 3)
    params: Dictionary containing weights and biases for the MLP
    deg_point: Degree of positional encoding
    net_depth: Number of hidden layers
    net_width: Width of hidden layers
    do_skip: Boolean, use skip connections
    activation_fn: JAX activation function (e.g., nn.relu or nn.elu)
    ior_den: Denominator for IOR scaling
    """
    
    # 1. Positional Encoding
    # posenc is assumed to be a defined function that expands x
    x_enc = posenc(x, deg_point)
    
    # 2. Store inputs for skip connections
    inputs = x_enc
    
    # 3. Hidden Layers
    current_x = x_enc
    skip_interval = net_depth // 2
    
    for i in range(net_depth):
        # Apply dense layer with He uniform initialization (handled by params)
        current_x = dense_layer(current_x, params[f'layer_{i}'])
        
        # Apply activation
        current_x = activation_fn(current_x)
        
        # Skip connection logic
        if do_skip and i > 0 and i % skip_interval == 0:
            # Concatenate with original encoded input
            current_x = jnp.concatenate([current_x, inputs], axis=-1)
            
    # 4. Final Dense Layer
    y = dense_layer(current_x, params['output_layer'])
    
    # 5. IOR Activation
    # softplus(y - 2) / ior_den + 1
    eta = nn.softplus(jnp.squeeze(y) - 2) / ior_den + 1.0
    
    return eta
```

**Edge Cases and Pitfalls:**
- **Precision:** The `softplus` function is numerically stable, but subtracting 2 before applying it is critical for the specific scaling used in the source implementation.
- **Boundaries:** The output $\eta$ is strictly greater than 1.0 because $\text{softplus}(z) > 0$ for all real $z$, and $\text{ior\_den} > 0$. This ensures the refractive index is physically valid (greater than vacuum).
- **Degenerate Input:** If `net_depth` is 0 or 1, the skip connection logic may not trigger or may behave unexpectedly depending on the modulo arithmetic. The default depth is 4.

## Subtopics

### MLP_act_dm
Uses `net_width=128`, `do_skip=True`, `activation=relu`. Optimized for dark matter simulations.

### MLP_act_gas
Uses `net_width=256`, `do_skip=False`, `activation=elu`. Optimized for gas/neural field simulations.

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of hidden layers and width. The positional encoding adds a constant factor based on `deg_point`.
- **Memory Complexity:** Proportional to the number of parameters in the MLP. Skip connections increase memory usage slightly due to concatenation operations but do not change the parameter count.
- **Performance:** The specific choice of activation and skip connections affects convergence speed. ReLU with skips (`dm`) is used for smoother fields, while ELU without skips (`gas`) is used for more complex, less correlated fields.
- **Strengths:** Physically constrained output ensures valid refractive indices without post-processing clipping.
- **Limitations:** The fixed formula for IOR activation limits the range of refractive indices that can be efficiently learned. The denominator `ior_den` (400) is a hyperparameter that may need tuning for different materials.

## Background
This method originates from the `rtnf` (Refractive Neural Fields) project, an unofficial implementation for neural volume rendering with refractive effects. It adapts the standard MLP architecture used in NeRF-like models to predict refractive index fields instead of color/density. The specific activation function is designed to map unconstrained neural network outputs to the physical domain of refractive indices.
