# MLP with Positional Encoding and IOR Activation

Also called: MLP with Skip Connections and Refractive Index Activation

## Overview
A multi-layer perceptron that maps 3D coordinates to a scalar field (e.g., refractive index) using positional encoding, residual skip connections, and a domain-specific activation function to constrain output ranges [S1, unofficial]. It is distinguished by a post-processing activation function that maps the MLP's raw output to a positive range $[1, \infty)$, ensuring physical validity for light propagation [S1, unofficial].

## How it works
**Inputs:**
- `x`: Input feature vector, typically the positional encoding of 3D coordinates $(x, y, z)$ [S1, unofficial].
- `deg_point`: Integer degree for positional encoding [S1, unofficial].
- `net_depth`: Integer depth of the hidden layers [S1, unofficial].
- `net_width`: Integer width of the hidden layers [S1, unofficial].
- `do_skip`: Boolean flag for skip connections [S1, unofficial].
- `activation`: Choice of activation function (ReLU or ELU) [S1, unofficial].
- `ior_den`: Denominator for the IOR scaling factor [S1, unofficial].

**Outputs:**
- `eta`: Scalar field representing the refractive index at the input position [S1, unofficial].

**Data Structures:**
- The MLP consists of a sequence of dense (fully connected) layers [S1, unofficial].
- Weights are initialized using He uniform initialization [S1, unofficial].
- The final layer outputs a single scalar value (`out_channel = 1`) [S1, unofficial].

**Parameters:**
- `net_depth`: Default 4 [S1, unofficial].
- `net_width`: Default 128 (for dark matter simulations) or 256 (for gas/neural field simulations) [S1, unofficial].
- `deg_point`: Default 4 or 6 [S1, unofficial].
- `ior_den`: Default 400 [S1, unofficial].
- `do_skip`: Default `True` for dark matter, `False` for gas/neural fields [S1, unofficial].
- `activation`: `nn.relu` for dark matter, `nn.elu` for gas/neural fields [S1, unofficial].

**Algorithm:**
1. **Positional Encoding:** Apply positional encoding to the input coordinates $x$. Let $x_{enc} = \text{posenc}(x, \text{deg\_point})$ [S1, unofficial].
2. **Skip Connection Storage:** Store the encoded input for potential skip connections: $inputs = x_{enc}$ [S1, unofficial].
3. **Hidden Layers:** Iterate $i$ from $0$ to $\text{net\_depth} - 1$:
    a. Apply a dense layer with width $\text{net\_width}$: $x = \text{Dense}_{\text{net\_width}}(x)$ [S1, unofficial].
    b. Apply the chosen activation function: $x = \text{Activation}(x)$ [S1, unofficial].
    c. **Skip Connection Logic:** If `do_skip` is true, and $i > 0$, and $i$ is a multiple of $\lfloor \text{net\_depth} / 2 \rfloor$:
        i. Concatenate the current representation $x$ with the original encoded input $inputs$ along the feature axis: $x = \text{concat}(x, inputs)$ [S1, unofficial].
4. **Output Layer:** Apply a final dense layer with 1 output channel: $y = \text{Dense}_1(x)$ [S1, unofficial].
5. **IOR Activation:** Apply the refractive index activation function to constrain the output:
    $$ \eta = \frac{\text{softplus}(y - 2)}{\text{ior\_den}} + 1 $$
    Where $\text{softplus}(z) = \ln(1 + e^z)$ [G].

**Pseudocode:**
```python
import jax.numpy as jnp
from jax import nn

def posenc(x, deg_point):
    """Standard positional encoding [G]."""
    scales = jnp.array([2.0 ** (2 * i / deg_point) for i in range(deg_point // 2)])
    x = jnp.expand_dims(x * scales, axis=-1)
    return jnp.concatenate([jnp.sin(x), jnp.cos(x)], axis=-1)

def dense_layer(x, weight, bias):
    """Standard fully connected layer [G]."""
    return x @ weight + bias

def mlp_with_ior_activation(x, params, deg_point, net_depth, net_width, do_skip, activation_fn, ior_den):
    """
    x: Input coordinates, shape (..., 3)
    params: Dictionary containing weights and biases for the MLP
    deg_point: Degree of positional encoding
    net_depth: Number of hidden layers
    net_width: Width of hidden layers
    do_skip: Boolean, use skip connections
    activation_fn: JAX activation function (e.g., nn.relu or nn.elu)
    ior_den: Denominator for IOR scaling
    """
    # 1. Positional Encoding
    x_enc = posenc(x, deg_point)
    
    # 2. Store inputs for skip connections
    inputs = x_enc
    
    # 3. Hidden Layers
    current_x = x_enc
    skip_interval = net_depth // 2
    
    for i in range(net_depth):
        # Apply dense layer with He uniform initialization (handled by params)
        current_x = dense_layer(current_x, params[f'layer_{i}_weight'], params[f'layer_{i}_bias'])
        
        # Apply activation
        current_x = activation_fn(current_x)
        
        # Skip connection logic
        if do_skip and i > 0 and i % skip_interval == 0:
            # Concatenate with original encoded input
            current_x = jnp.concatenate([current_x, inputs], axis=-1)
            
    # 4. Final Dense Layer
    y = dense_layer(current_x, params['output_weight'], params['output_bias'])
    
    # 5. IOR Activation
    eta = nn.softplus(jnp.squeeze(y) - 2) / ior_den + 1.0
    
    return eta
```

**Edge Cases and Pitfalls:**
- **Precision:** The `softplus` function is numerically stable, but subtracting 2 before applying it is critical for the specific scaling used in the source implementation [S1, unofficial].
- **Boundaries:** The output $\eta$ is strictly greater than 1.0 because $\text{softplus}(z) > 0$ for all real $z$, and $\text{ior\_den} > 0$ [G]. This ensures the refractive index is physically valid (greater than vacuum) [G].
- **Degenerate Input:** If `net_depth` is 0 or 1, the skip connection logic may not trigger or may behave unexpectedly depending on the modulo arithmetic [S1, unofficial]. The default depth is 4 [S1, unofficial].

## Background
This method originates from the `rtnf` (Refractive Neural Fields) project, an unofficial implementation for neural volume rendering with refractive effects [S1, unofficial]. It adapts the standard MLP architecture used in NeRF-like models to predict refractive index fields instead of color/density [S1, unofficial]. The specific activation function is designed to map unconstrained neural network outputs to the physical domain of refractive indices [S1, unofficial].
