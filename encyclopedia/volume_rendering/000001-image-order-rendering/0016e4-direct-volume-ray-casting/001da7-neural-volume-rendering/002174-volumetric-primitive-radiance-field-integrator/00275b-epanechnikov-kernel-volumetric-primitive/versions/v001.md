# Epanechnikov Kernel Volumetric Primitive

Also called: Epanechnikov Kernel, Epanechnikov Volumetric Primitive

## Overview
The Epanechnikov Kernel Volumetric Primitive is a spatially bounded volumetric primitive used in neural volume rendering to model density fields with sharp edges and compact support [S1, unofficial]. Unlike Gaussian primitives which have infinite support, the Epanechnikov kernel generates compact "shells" that enable more efficient acceleration structures and faster rendering, particularly for modeling sharp boundaries [S1, unofficial]. It serves as a physically-based alternative to splatting methods, allowing integration into radiative transfer engines for scattering and emissive media [S1, unofficial].

## How it works
**Inputs:** Ray origin $\mathbf{o}$, ray direction $\mathbf{d}$, primitive center $\mathbf{c}_i$, covariance matrix $\Sigma_i$.
**Outputs:** Optical depth $\tau_i$ along the ray segment, transmittance $T$, and sampled free-flight distance $t$.

**Data Structures:**
*   Primitive $i$: Defined by center $\mathbf{c}_i \in \mathbb{R}^3$ and covariance matrix $\Sigma_i \in \mathbb{R}^{3 \times 3}$ (symmetric positive definite).

**Formula:**
The 3D Epanechnikov kernel density function is defined as [S1, unofficial]:
$$
E_i(\mathbf{x}) = \begin{cases} \frac{15}{8\pi} \left(\frac{7}{3} |\Sigma_i| \right)^{1/2} \left[1 - \frac{1}{7} d(\mathbf{x})\right] & \text{if } d(\mathbf{x}) \le 1 \\ 0 & \text{otherwise} \end{cases}
$$
where $d(\mathbf{x}) = (\mathbf{x} - \mathbf{c}_i)^T \Sigma_i^{-1} (\mathbf{x} - \mathbf{c}_i)$ is the squared Mahalanobis distance from the center. The kernel is non-zero only within the ellipsoid defined by $d(\mathbf{x}) \le 1$.

**Steps:**
1.  **Intersection Test:** Determine if the ray intersects the support ellipsoid of the primitive. If not, $\tau_i = 0$.
2.  **Optical Depth Integration:** Compute the optical depth $\tau_i(\mathbf{x}_a, \mathbf{x}_b)$ along the ray segment $[\mathbf{x}_a, \mathbf{x}_b]$ by integrating the density $E_i(\mathbf{x}(t))$. The source states that a closed-form analytical solution exists for this integration [S1, unofficial].
3.  **Transmittance Calculation:** Calculate transmittance using the Beer-Lambert law: $T = \exp(-\sum \tau_i)$ [S1, unofficial].
4.  **Free-Flight Sampling:** Sample a distance $t$ along the ray for scattering events. The probability density is $p(t) = \mu_t(\mathbf{x}_t)T(\mathbf{x}_0, \mathbf{x}_t)$ [S1, unofficial]. While an analytical solution for the cumulative distribution function exists, it is complex; therefore, numerical root-finding methods (e.g., Newton-Raphson or bisection) are generally used to sample $t$ [S1, unofficial].

import numpy as np

def epanechnikov_kernel_density(x, c, Sigma_inv, det_Sigma):
    """
    Compute the Epanechnikov kernel density at point x.
    x: (3,) array
    c: (3,) array, center
    Sigma_inv: (3,3) array, inverse covariance
    det_Sigma: float, determinant of covariance
    """
    diff = x - c
    d_sq = diff @ Sigma_inv @ diff
    
    if d_sq > 1.0:
        return 0.0
    
    # Constant factor: 15/(8*pi) * sqrt(7/3 * |Sigma|)
    # Note: |Sigma| is det_Sigma. The formula uses |Sigma| inside sqrt.
    # The source formula: (15 / (8 * pi)) * ((7/3) * |Sigma|)**0.5
    constant = (15.0 / (8.0 * np.pi)) * np.sqrt((7.0 / 3.0) * det_Sigma)
    
    density = constant * (1.0 - (1.0 / 7.0) * d_sq)
    return density

## Subtopics

### Gabor Kernel Volumetric Primitive
A 3D anisotropic Gabor kernel used as a primitive for volume rendering, combining a Gaussian envelope with a planar wave modulation to allow for orientation-selective, band-pass filtering [S2]. It is chosen when modeling residual details or orientation-specific features in level-of-detail rendering [S2]. The kernel is defined as $g(\mathbf{x}; \boldsymbol{\mu}, \Sigma, \boldsymbol{\omega}) = \frac{1}{\sqrt{8\pi^3 |\Sigma|}} \exp\left(-\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu})^T \Sigma^{-1}(\mathbf{x}-\boldsymbol{\mu})\right) \cos\left(\boldsymbol{\omega}^T (\mathbf{x}-\boldsymbol{\mu})\right)$ [S2]. The covariance matrix is factorized as $\Sigma = R S S^T R^T$ [S2]. The frequency vector is modeled as $\boldsymbol{\omega} = R S^{-1}(\omega, \omega, \omega)^T$ to reduce parameters [S2]. Its Fourier transform is $\mathcal{F}\{g(\mathbf{x})\}(\mathbf{k}) = \frac{1}{2} e^{-i\mathbf{k}^T \boldsymbol{\mu}} \left[ e^{-\frac{1}{2}(\mathbf{k}-\mathbf{f}_0)^T \Sigma(\mathbf{k}-\mathbf{f}_0)} + e^{-\frac{1}{2}(\mathbf{k}+\mathbf{f}_0)^T \Sigma(\mathbf{k}+\mathbf{f}_0)} \right]$ where $\mathbf{f}_0 = \|\boldsymbol{\omega}\|$ [S2]. Rendering uses the analytical Fourier transform to approximate band-limited filtered volumes [S2].

## Operating characteristics
**Time Complexity:** Rendering is faster than Gaussian-based methods because the finite support of the Epanechnikov kernel allows for more efficient acceleration structures (e.g., fewer primitives need to be checked per ray) [S1, unofficial].
**Memory Complexity:** Depends on the number of primitives. The compact support may allow for sparser representations compared to Gaussians for sharp features.
**Strengths:** Physically-based integration into radiative transfer engines; supports scattering and emissive media; faster rendering than Gaussians; suitable for sharp edges [S1, unofficial].
**Limitations:** Free-flight distance sampling requires numerical root-finding, which is more complex than analytical sampling for Gaussians [S1, unofficial]. The closed-form optical depth integration, while existing, is complex to implement [S1, unofficial].

## Background
The Epanechnikov Kernel Volumetric Primitive is part of a family of volumetric ray-traced primitives designed to model scattering and emissive media, proposed in 2025 [S1, unofficial]. It addresses limitations of 3D Gaussian Splatting, which approximates density as delta functions and lacks physical volume integration [S1, unofficial]. The method builds on radiative transfer theory to enable global illumination and soft shadows [S1, unofficial].
