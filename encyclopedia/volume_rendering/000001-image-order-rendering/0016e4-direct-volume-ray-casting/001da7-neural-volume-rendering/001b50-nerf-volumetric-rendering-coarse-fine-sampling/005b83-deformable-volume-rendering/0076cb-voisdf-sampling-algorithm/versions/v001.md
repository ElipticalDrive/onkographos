# VoISDF Sampling Algorithm
Also called: Error-bound based inverse CDF sampling

## Overview
The VoISDF Sampling Algorithm generates a set of sample points along a ray for volume rendering by iteratively refining an initial uniform grid based on a rigorous upper bound of the opacity approximation error [S1, unofficial]. It solves the problem of sub-optimal sampling in neural implicit surface rendering, where naive approximations of the opacity function lead to missed or over-extended density regions, causing incorrect radiance approximations and artifacts [S1, unofficial]. Unlike sibling methods like [Rigidly Transformed Neural Radiance Field (RT-NeRF)](18944-rigidly-transformed-neural-radiance-field-rt-nerf.md) which may rely on random or fixed uniform sampling, this method guarantees that the discretization error of the opacity CDF remains below a threshold $\epsilon$, enabling accurate inverse transform sampling for the final render [S1, unofficial].

## How it works
**Inputs:**
- Ray origin $\mathbf{c}$ and direction $\mathbf{v}$.
- Error threshold $\epsilon > 0$.
- Density model parameter $\beta$ (typical value: 0.001) [S1, unofficial].
- Maximum ray distance $M$ [S1, unofficial].
- Initial sample count $n$ (typical value: 128) [S1, unofficial].
- Final sample count $m$ (typical value: 64) [S1, unofficial].
- Maximum iterations `max_iter` (value: 5) [S1, unofficial].
- Density network $\sigma(\mathbf{x})$ and Signed Distance Function (SDF) network $d_\Omega(\mathbf{x})$ [S1, unofficial].

**Outputs:**
- A set of $m$ sample positions $\mathcal{S} = \{s_i\}_{i=1}^m$ along the ray, optimized for inverse CDF sampling of the opacity PDF $\tau(t)$ [S1, unofficial].

**Data Structures:**
- $\mathcal{T} = \{t_i\}_{i=1}^k$: A sorted list of sample positions along the ray, where $t_1=0$ and $t_k=M$.
- $\beta_+$: The current effective density parameter used for error bounding, initialized such that the error bound is satisfied.

**Formulas:**
1.  **Transparency and Opacity:**
    $$T(t) = \exp\left(-\int_0^t \sigma(\mathbf{x}(s)) ds\right)$$
    $$O(t) = 1 - T(t)$$
    $$\tau(t) = \frac{dO}{dt}(t) = \sigma(\mathbf{x}(t))T(t)$$ [S1, unofficial]

2.  **Rectangle Rule Approximation:**
    For $t \in [t_k, t_{k+1}]$, let $\delta_i = t_{i+1} - t_i$ and $\sigma_i = \sigma(\mathbf{x}(t_i))$.
    $$\hat{R}(t) = \sum_{i=1}^{k-1} \delta_i \sigma_i + (t - t_k) \sigma_k$$ [S1, unofficial]
    $$\widehat{O}(t) = 1 - \exp\left(-\hat{R}(t)\right)$$ [S1, unofficial]

3.  **Distance to Boundary ($d_i^*$):**
    Let $B_i = \{\mathbf{x} \mid \|\mathbf{x} - \mathbf{x}(t_i)\| < |d_i|\}$, where $d_i = d_\Omega(\mathbf{x}(t_i))$.
    $$d_i^* = \min_{\substack{s \in [t_i, t_{i+1}] \\ \mathbf{y} \notin B_i \cup B_{i+1}}} \|\mathbf{x}(s) - \mathbf{y}\|$$ [S1, unofficial]

4.  **Error Bound Components:**
    $$\widehat{E}(t) = \frac{\alpha}{4\beta} \left( \sum_{i=1}^{k-1} \delta_i^2 e^{-\frac{d_i^*}{\beta}} + (t - t_k)^2 e^{-\frac{d_k^*}{\beta}} \right)$$
    Note: $\alpha$ is a constant related to the Lipschitz bound of the density. The sources do not provide an explicit value for $\alpha$, only its role in the bound [S1, unofficial].

5.  **Interval Error Bound:**
    $$\text{Bound}_k = \exp\left(-\hat{R}(t_k)\right) \left( \exp(\widehat{E}(t_{k+1})) - 1 \right)$$ [S1, unofficial]

6.  **Global Error Bound:**
    $$B_{\mathcal{T}, \beta} = \max_{k \in [n-1]} \left\{ \text{Bound}_k \right\}$$
    By convention $\hat{R}(t_0) = 0$ [S1, unofficial].

7.  **Parameter Adjustment (Lemma 2):**
    To satisfy $B_{\mathcal{T}, \beta} \leq \epsilon$ with fixed $n$:
    $$\beta \geq \frac{\alpha M^2}{4(n-1) \log(1 + \epsilon)}$$ [S1, unofficial]

**Steps:**
1.  **Initialize:** Create uniform sample set $\mathcal{T}_0 = \{t_i\}_{i=1}^n$ where $t_k = (k-1) \frac{M}{n-1}$ for $k \in [n]$ [S1, unofficial].
2.  **Initialize $\beta_+$:** Calculate $\beta_+$ using Lemma 2 such that $B_{\mathcal{T}_0, \beta_+} \leq \epsilon$ [S1, unofficial].
3.  **Iterative Refinement:** While $B_{\mathcal{T}, \beta} > \epsilon$ and iteration count < `max_iter`:
    a.  **Upsample:** Add $n$ new samples to $\mathcal{T}$. The number of points added to interval $[t_i, t_{i+1}]$ is proportional to its current error bound $\text{Bound}_i$ [S1, unofficial].
    b.  **Bisection Search:** Use bisection method (max 10 iterations) to find $\beta_* \in (\beta, \beta_+)$ such that $B_{\mathcal{T}, \beta_*} = \epsilon$. Update $\beta_+ \leftarrow \beta_*$ [S1, unofficial].
4.  **Finalize:** Ensure $B_{\mathcal{T}, \beta_+} \leq \epsilon$. Compute the approximated opacity function $\widehat{O}(t)$ using the final $\mathcal{T}$ and $\beta_+$ [S1, unofficial].
5.  **Inverse Sampling:** Generate $m$ final samples $\mathcal{S}$ by performing inverse transform sampling on $\widehat{O}(t)$ [S1, unofficial].

    for u in u_samples:

            if o_mid < u:

            else:

**Edge Cases and Pitfalls:**
-   **Naive Opacity Approximation:** Using a crude approximation of $O$ leads to sub-optimal sample sets that miss or over-extend non-negligible $\tau$ values, causing incorrect radiance approximations and harming the learned density-radiance field decomposition [S1, unofficial].
-   **Artifacts:** Random samples in NeRF cause salt-and-pepper artifacts; fixed uniformly spaced sampling leads to different types of artifacts. This method mitigates these by adapting samples to the error bound [S1, unofficial].
-   **SDF Non-differentiability:** The bound relies on the Lipschitz constant of $\sigma$ because $d_\Omega$ is not differentiable everywhere [S1, unofficial].
-   **Parameter Sensitivity:** The value of $\alpha$ is not explicitly given in the sources, which may hinder implementation without further derivation from the supplementary material [S1, unofficial].

## Operating characteristics
-   **Time Complexity:** The algorithm involves iterative refinement. Each iteration requires computing error bounds for all intervals, which is $O(n)$ where $n$ is the number of samples. Upsampling increases $n$. The bisection search adds a logarithmic factor. Final inverse sampling is $O(m \log M)$ or $O(m)$ with precomputed CDF.
-   **Memory Complexity:** $O(n)$ to store the sample set $\mathcal{T}$ and intermediate error bounds.
-   **Measured Performance:** The sources do not provide specific benchmark numbers (FPS, resolution) for the sampling algorithm itself, only qualitative comparisons showing fewer artifacts than NeRF [S1, unofficial].
-   **Strengths:** Guarantees opacity approximation error below $\epsilon$. Reduces artifacts compared to random or uniform sampling.
-   **Limitations:** Computationally expensive due to repeated error bound calculations and bisection search. Requires access to SDF and density networks.
-   **When to use:** When rendering neural implicit surfaces with high accuracy requirements and deformable geometry.
-   **When not to use:** When real-time performance is critical and approximate sampling is acceptable.

## Background
The VoISDF Sampling Algorithm was introduced in the paper "Volume Rendering of Neural Implicit Surfaces" (VoISDF) [S1, unofficial]. It addresses the limitations of standard NeRF sampling in the context of implicit surfaces, where the density is derived from a Signed Distance Function (SDF). The method leverages the mathematical properties of SDFs to derive a tight bound on the opacity approximation error, allowing for adaptive sampling that concentrates points where the opacity changes rapidly [S1, unofficial].
