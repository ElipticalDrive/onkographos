# Hierarchical Sampling with Weight Modification

Also called: Fine sampling with blurpool

## Overview
This method refines the sampling distribution along rays in neural volume rendering by generating additional sample points based on the alpha compositing weights of a coarse model. It addresses the limitation of standard importance sampling, which may miss thin structures or empty regions, by smoothing the weight distribution before sampling. It sets itself apart from standard NeRF importance sampling by applying a specific "blurpool" filter to the weights, ensuring a smoother upper envelope that encourages exploration of empty space while maintaining focus on high-weight regions.

## How it works
**Inputs and Outputs:**
- Input: Coarse sample positions $\mathbf{t}^c$ along a ray, and the corresponding alpha compositing weights $w$ computed from the coarse model.
- Output: Refined fine sample positions $\mathbf{t}^f$.

**Data Structures:**
- $w$: A 1D array of size $N_c$ (number of coarse samples), where $w_k$ is the weight of the $k$-th coarse sample.
- $w'$: A 1D array of size $N_c$, storing the modified weights.

**Parameters:**
- $N_c$: Number of coarse samples. Default: 128 [S1].
- $N_f$: Number of fine samples. Default: 128 [S1].
- $\alpha$: Hyperparameter added to the envelope to ensure sampling in empty regions. Default: 0.01 [S1].

**Steps:**
1. **Coarse Sampling:** Produce coarse samples $\mathbf{t}^c$ using stratified sampling along the ray [S1].
2. **Weight Computation:** Compute the alpha compositing weights $w$ for the coarse samples using the coarse model [S1].
3. **Weight Modification:** Modify the weights $w$ to create a smoothed upper envelope:
   a. Apply a 2-tap max filter to $w$. For each index $k$, compute the local maximums:
      $$ m_k = \max(w_{k-1}, w_k) $$
      $$ m_{k+1} = \max(w_k, w_{k+1}) $$
      (Boundary conditions: For $k=0$, assume $w_{-1}=0$; for $k=N_c-1$, assume $w_{N_c}=0$) [G].
   b. Apply a 2-tap blur filter (averaging) to the result of the max filter:
      $$ w'_k = \frac{1}{2}(m_k + m_{k+1}) + \alpha $$
      Substituting the max filter results:
      $$ w'_k = \frac{1}{2}(\max(w_{k-1}, w_k) + \max(w_k, w_{k+1})) + \alpha \quad (18) $$
   c. Re-normalize $w'$ so that $\sum w'_k = 1$ [S1].
4. **Fine Sampling:** Sample fine sample positions $\mathbf{t}^f$ from the modified weights $w'$ using inverse transform sampling [S1].

**Pseudocode:**
```python
def hierarchical_sampling_with_weight_modification(w, alpha=0.01):
    """
    Modifies weights w using a 2-tap max filter followed by a 2-tap blur filter,
    adds alpha, and renormalizes.
    
    Args:
        w: List of floats, alpha compositing weights from coarse samples.
        alpha: Hyperparameter for empty region sampling.
        
    Returns:
        w_prime: List of floats, modified and normalized weights.
    """
    n = len(w)
    w_prime = [0.0] * n
    
    # Step 1: 2-tap max filter
    # m[k] = max(w[k-1], w[k])
    # We need max(w[k-1], w[k]) and max(w[k], w[k+1]) for the blur step
    
    # Handle boundaries: assume w[-1] = 0 and w[n] = 0
    w_padded = [0.0] + w + [0.0]
    
    max_vals = []
    for k in range(n):
        # w[k-1] is w_padded[k], w[k] is w_padded[k+1], w[k+1] is w_padded[k+2]
        left_max = max(w_padded[k], w_padded[k+1])
        right_max = max(w_padded[k+1], w_padded[k+2])
        max_vals.append((left_max + right_max) / 2.0)
        
    # Step 2: Add alpha
    for k in range(n):
        max_vals[k] += alpha
        
    # Step 3: Renormalize
    total = sum(max_vals)
    if total == 0:
        # Fallback to uniform if all weights are zero (empty ray)
        uniform = [1.0 / n] * n
        return uniform
        
    w_prime = [v / total for v in max_vals]
    
    return w_prime
```

**Edge Cases and Pitfalls:**
- **Empty Regions:** If all coarse weights are zero, the modified weights will be $\alpha$. Renormalization ensures a valid probability distribution.
- **Boundary Conditions:** The max filter requires neighbors outside the array. Assuming zero weights outside the ray segment is standard [G].
- **Precision:** Ensure floating-point precision is sufficient for small $\alpha$ values to avoid numerical instability during renormalization.

## Subtopics

### [L0-Sampler](7382-l0-sampler.md)
An enhanced sampling strategy that concentrates sampling points near the surface by shaping the weight function $w(t)$ to approximate the L0 distance form, replacing the piecewise constant interpolation of HVS with piecewise exponential functions.

## Operating characteristics
- **Time Complexity:** The weight modification step is $O(N_c)$, where $N_c$ is the number of coarse samples. The fine sampling step is $O(N_f \log N_c)$ or $O(N_f)$ with cumulative sum lookup. Overall, it adds minimal overhead compared to standard importance sampling.
- **Memory Complexity:** $O(N_c)$ to store the modified weights.
- **Measured Performance:** In mip-NeRF, using 128 coarse and 128 fine samples yields the same number of total MLP evaluations as NeRF (which uses 64 coarse and 128 fine, but with a separate fine MLP), providing a fair comparison [S1].
- **Strengths:** Ensures sampling in empty regions, reduces aliasing artifacts by smoothing the weight distribution.
- **Limitations:** The smoothing may slightly blur the distinction between high and low weight regions, potentially leading to less precise sampling in very complex scenes.
- **When to Use:** When using a single MLP for both coarse and fine sampling, or when anti-aliasing is a priority.
- **When Not to Use:** When computational budget is extremely tight and empty regions are not a concern.

## Background
This method was introduced in mip-NeRF: A Multiscale Representation for Anti-Aliasing Neural Radiance Fields [S1]. It builds on the NeRF importance sampling technique but modifies the weight distribution to better handle multiscale structures and anti-aliasing. The "blurpool" filter was adapted from image processing techniques [S1].
