# NeRF Volumetric Rendering (Coarse/Fine Sampling)

Also called: NeRF Coarse-to-Fine Rendering, NeRF Rendering Equation, NeRF Two-Stage Sampling, Standard NeRF, Vanilla NeRF, Volume Rendering (NeRF), Volumetric Rendering (NeRF)

## Overview
NeRF Volumetric Rendering (Coarse/Fine Sampling) is a differentiable volume rendering technique that synthesizes novel views of 3D scenes by querying a neural radiance field along camera rays and accumulating outputs using classical volume rendering [S3, S14]. It solves the problem of insufficient sampling in high-frequency regions by employing a two-stage sampling strategy: a coarse network estimates the density distribution to guide a fine network that concentrates samples in high-opacity regions [S12, S29, unofficial]. This method sets itself apart from its siblings, such as [Iterative Ray Marching with Neural Volume Inference](1494-iterative-ray-marching-with-neural-volume-inference.md) which uses learned acceleration structures, and [DVGO Volume Rendering Forward Pass](2363-dvgo-volume-rendering-forward-pass.md) which uses hybrid voxel-MLP representations, by relying on a simple, differentiable stratified resampling of coarse alpha weights without auxiliary acceleration structures or complex data structures [S1, S12, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A batch of rays $\mathbf{r} = (\mathbf{o}, \mathbf{d})$ where $\mathbf{o}$ is the origin and $\mathbf{d}$ is the direction; near and far plane bounds $t_n, t_f$; number of coarse samples $N_c$ and fine samples $N_f$; boolean flags for `lindisp` (inverse depth sampling) and `perturb` (stratified jittering); and two neural networks: `coarse_model` and `fine_model` [S8, S12, S18, unofficial].
*   **Outputs:** Rendered RGB color $\mathbf{C}_{out}$, accumulated opacity $\alpha_{out}$, depth $\mathbf{D}_{out}$, and optionally disparity maps [S1, S12, unofficial].

**Data Structures:**
*   **Ray Batch:** Tensor of shape $[R, 8]$ or $[R, 9]$ containing ray origins (3), directions (3), near/far bounds (2), and optionally viewing directions (3) if view-dependent color is used [S8, S12, unofficial].
*   **Sample Positions:** Tensor of shape $[R, N]$ containing depth values $t_i$ along the ray [S9, unofficial].
*   **3D Points:** Tensor of shape $[R, N, 3]$ containing world coordinates $\mathbf{x}_i = \mathbf{o} + t_i \mathbf{d}$ [S9, unofficial].
*   **Network Output:** Tensor of shape $[R, N, 4]$ containing raw density $\tilde{\sigma}$ (1 channel) and raw color $\tilde{\mathbf{c}}$ (3 channels) [S1, unofficial].

**Numbered Steps:**

1.  **Ray Construction:** For each pixel, construct the ray $\mathbf{r}(t) = \mathbf{o} + t\mathbf{d}$ using the camera pose and intrinsic parameters [S2, S5]. Extract ray origins $\mathbf{o}$, directions $\mathbf{d}$, and near/far bounds $t_n, t_f$ from the ray batch [S8, unofficial].

2.  **Coarse Sampling:**
    *   Generate $N_c$ linearly spaced values $t_{vals} \in [0, 1]$ [S11, unofficial].
    *   Map to depth bounds:
        *   If `lindisp` is False: $z_{vals} = t_n (1 - t_{vals}) + t_f t_{vals}$ [S8, unofficial].
        *   If `lindisp` is True: $z_{vals} = \left( \frac{1}{t_n} (1 - t_{vals}) + \frac{1}{t_f} t_{vals} \right)^{-1}$ [S11, unofficial].
    *   If `perturb` is True, apply stratified sampling: compute midpoints $mids = 0.5 (z_{vals}[:, 1:] + z_{vals}[:, :-1])$, define lower bounds $[z_{vals}[:, :1], mids]$ and upper bounds $[mids, z_{vals}[:, -1]]$, and jitter: $z_{vals} = lower + (upper - lower) \cdot \text{rand}()$ [S9, S12, unofficial].
    *   Compute 3D points: $\mathbf{x}_i = \mathbf{o} + z_{vals, i} \mathbf{d}$ [S9, unofficial].

3.  **Coarse Network Query:**
    *   Apply positional encoding $\gamma(\cdot)$ to spatial coordinates $\mathbf{x}$ and viewing directions $\mathbf{d}$ [S4, S22].
    *   Query `coarse_model` to obtain raw density $\tilde{\sigma}_c$ and raw color $\tilde{\mathbf{c}}_c$ [S1, unofficial][S4].
    *   Apply activation functions:
        *   Density: $\sigma_c = \text{softplus}(\tilde{\sigma}_c)$ or $\text{relu}(\tilde{\sigma}_c)$ [S1, S13, S10, unofficial]. Note: [S10, unofficial] uses softplus with a bias, while [S13, unofficial] uses ReLU. Standard NeRF typically uses softplus for density to ensure positivity [S10, unofficial].
        *   Color: $\mathbf{c}_c = \text{sigmoid}(\tilde{\mathbf{c}}_c)$ [S1, unofficial].

4.  **Coarse Rendering:**
    *   Compute segment distances: $\delta_i = z_{vals, i+1} - z_{vals, i}$ for $i < N_c-1$, and $\delta_{N_c-1} = \infty$ (or a large value like $10^{10}$) to handle the last interval [S13, S34, unofficial].
    *   Compute alpha (opacity): $\alpha_i = 1 - \exp(-\sigma_{c,i} \delta_i)$ [S9, S34, unofficial].
    *   Compute transmittance: $T_i = \exp\left(-\sum_{j=1}^{i-1} \sigma_{c,j} \delta_j\right)$ [S5, S14].
    *   Compute weights: $w_i = T_i \alpha_i$ [S9, S29, unofficial].
    *   Compute coarse color: $\mathbf{C}_{coarse} = \sum_{i=1}^{N_c} w_i \mathbf{c}_{c,i}$ [S1, S34, unofficial].
    *   Compute coarse depth: $\mathbf{D}_{coarse} = \sum_{i=1}^{N_c} w_i z_{vals, i}$ [S5, S28].

5.  **Fine Sampling (Importance Resampling):**
    *   Use the coarse weights $w_i$ (excluding the first sample $i=0$ to avoid bias) as a probability distribution [S29, S38, unofficial].
    *   Draw $N_f$ samples from this distribution using stratified sampling to generate finer depth values $z_{vals}^{fine}$ [S1, S29, unofficial].
    *   **Crucial Implementation Detail:** Detach $z_{vals}^{fine}$ from the computation graph to prevent gradients from flowing back to the coarse network during the fine stage [S29, unofficial].

6.  **Fine Network Query:**
    *   Compute 3D points for fine samples: $\mathbf{x}_i^{fine} = \mathbf{o} + z_{vals, i}^{fine} \mathbf{d}$ [S9, unofficial].
    *   Apply positional encoding to $\mathbf{x}^{fine}$ and $\mathbf{d}$ [S4].
    *   Query `fine_model` to obtain raw density $\tilde{\sigma}_f$ and raw color $\tilde{\mathbf{c}}_f$ [S12, S18, unofficial].
    *   Apply activations: $\sigma_f = \text{softplus}(\tilde{\sigma}_f)$, $\mathbf{c}_f = \text{sigmoid}(\tilde{\mathbf{c}}_f)$ [S1, S10, unofficial].

7.  **Fine Rendering:**
    *   Compute distances $\delta_i^{fine}$ between fine samples [S13, unofficial].
    *   Compute alpha: $\alpha_i^{fine} = 1 - \exp(-\sigma_{f,i} \delta_i^{fine})$ [S34, unofficial].
    *   Compute transmittance: $T_i^{fine} = \exp\left(-\sum_{j=1}^{i-1} \sigma_{f,j} \delta_j^{fine}\right)$ [S14].
    *   Compute weights: $w_i^{fine} = T_i^{fine} \alpha_i^{fine}$ [S29, unofficial].
    *   Compute final color: $\mathbf{C}_{out} = \sum_{i=1}^{N_f} w_i^{fine} \mathbf{c}_{f,i}$ [S1, S34, unofficial].
    *   Compute final depth: $\mathbf{D}_{out} = \sum_{i=1}^{N_f} w_i^{fine} z_{vals, i}^{fine}$ [S5].

8.  **Loss Computation:**
    *   Compute photometric loss (MSE) between $\mathbf{C}_{coarse}$ and ground truth $\mathbf{C}_{gt}$, and between $\mathbf{C}_{out}$ and $\mathbf{C}_{gt}$ [S18, unofficial][S24].
    *   Backpropagate through both stages to update `coarse_model` and `fine_model` parameters [S3, S14].

**Pseudocode:**

```python
import torch
import torch.nn.functional as F

def positional_encoding(x, include_input=True, log_sampling=True):
    """Standard NeRF positional encoding."""
    if log_sampling:
        scale = 1.0
        freq_bands = 10
        num_bands = freq_bands * 2
    else:
        scale = 1.0
        num_bands = 10
        freq_bands = 5 # Placeholder for non-log sampling logic if needed, but standard is log
    
    # Simplified standard NeRF encoding based on [S2, S23]
    # x is [N, D]
    out = []
    if include_input:
        out.append(x)
    for i in range(num_bands):
        freq = 2**i * scale
        out.append(torch.sin(x * freq))
        out.append(torch.cos(x * freq))
    return torch.cat(out, dim=-1)

def raw2alpha(raw, dists, act_fn=F.relu):
    """Convert raw density to alpha."""
    # raw: [R, N], dists: [R, N]
    alpha = 1.0 - torch.exp(-act_fn(raw) * dists)
    return alpha

def render(rays_o, rays_d, near, far, n_samples_coarse, n_samples_fine, 
           coarse_model, fine_model, lindisp=False, perturb=1.0, chunk=1024*32):
    """
    Render a batch of rays using coarse and fine sampling.
    rays_o: [R, 3]
    rays_d: [R, 3]
    near: [R]
    far: [R]
    """
    device = rays_o.device
    R = rays_o.shape[0]
    
    # --- Coarse Stage ---
    # 1. Generate coarse z_vals
    t_vals = torch.linspace(0., 1., n_samples_coarse, device=device)
    if not lindisp:
        z_vals = near.unsqueeze(-1) * (1. - t_vals) + far.unsqueeze(-1) * t_vals
    else:
        z_vals = 1. / (1. / near.unsqueeze(-1) * (1. - t_vals) + 1. / far.unsqueeze(-1) * t_vals)
        
    # 2. Stratified sampling for coarse
    if perturb > 0.:
        mids = .5 * (z_vals[..., 1:] + z_vals[..., :-1])
        upper = torch.cat([mids, z_vals[..., -1:]], -1)
        lower = torch.cat([z_vals[..., :1], mids], -1)
        t_rand = torch.rand(z_vals.shape, device=device)
        z_vals = lower + (upper - lower) * t_rand
        
    # 3. Query Coarse Model
    # Expand z_vals to [R, N_coarse] and compute 3D points
    pts = rays_o.unsqueeze(1) + rays_d.unsqueeze(1) * z_vals.unsqueeze(-1) # [R, N, 3]
    
    # View direction is constant for all samples on a ray
    viewdirs = rays_d.unsqueeze(1).expand(pts.shape) # [R, N, 3]
    
    # Positional Encoding
    pts_enc = positional_encoding(pts.reshape(-1, 3))
    viewdirs_enc = positional_encoding(viewdirs.reshape(-1, 3))
    
    # Forward pass (chunked to save memory)
    raw_coarse = batchify(coarse_model, pts_enc, viewdirs_enc, chunk) # [R*N, 4]
    raw_coarse = raw_coarse.reshape(R, n_samples_coarse, 4)
    
    sigma_coarse = raw_coarse[..., 3] # [R, N]
    rgb_coarse = raw_coarse[..., :3]   # [R, N, 3]
    
    # 4. Compute Coarse Weights
    dists = z_vals[..., 1:] - z_vals[..., :-1]
    dists = torch.cat([dists, torch.tensor([1e10], device=device).expand(dists[..., :1].shape)], -1)
    dists = dists * torch.norm(rays_d.unsqueeze(-1), dim=-1) # Scale by ray length
    
    alpha_coarse = raw2alpha(sigma_coarse, dists) # [R, N]
    T_coarse = torch.cumprod(1. - alpha_coarse + 1e-10, dim=-1) # [R, N]
    T_coarse = torch.cat([torch.ones_like(T_coarse[..., :1]), T_coarse[..., :-1]], -1) # [R, N]
    
    weights_coarse = T_coarse * alpha_coarse # [R, N]
    rgb_coarse_final = (weights_coarse.unsqueeze(-1) * rgb_coarse).sum(dim=-2) # [R, 3]
    
    # --- Fine Stage ---
    # 5. Sample Fine Points based on Coarse Weights
    # Detach to stop gradient flow to coarse model
    weights_coarse_detached = weights_coarse.detach()
    
    # Sample from distribution defined by weights_coarse (excluding first sample)
    # This is a simplified importance sampling step. In practice, use a library or custom CUDA kernel.
    # Here we assume a helper `sample_finer_z_values` exists which draws N_f samples
    # from the PDF defined by weights_coarse[:, 1:]
    z_vals_fine = sample_finer_z_values(weights_coarse_detached[:, 1:], n_samples_fine) # [R, N_f]
    
    # Prepend the first coarse sample to ensure continuity? 
    # Standard NeRF often just uses the fine samples drawn from the coarse distribution.
    # However, some implementations concatenate. We follow the standard "fine sampling" 
    # which draws new points.
    
    # 6. Query Fine Model
    pts_fine = rays_o.unsqueeze(1) + rays_d.unsqueeze(1) * z_vals_fine.unsqueeze(-1)
    viewdirs_fine = rays_d.unsqueeze(1).expand(pts_fine.shape)
    
    pts_fine_enc = positional_encoding(pts_fine.reshape(-1, 3))
    viewdirs_fine_enc = positional_encoding(viewdirs_fine.reshape(-1, 3))
    
    raw_fine = batchify(fine_model, pts_fine_enc, viewdirs_fine_enc, chunk)
    raw_fine = raw_fine.reshape(R, n_samples_fine, 4)
    
    sigma_fine = raw_fine[..., 3]
    rgb_fine = raw_fine[..., :3]
    
    # 7. Compute Fine Weights
    dists_fine = z_vals_fine[..., 1:] - z_vals_fine[..., :-1]
    dists_fine = torch.cat([dists_fine, torch.tensor([1e10], device=device).expand(dists_fine[..., :1].shape)], -1)
    dists_fine = dists_fine * torch.norm(rays_d.unsqueeze(-1), dim=-1)
    
    alpha_fine = raw2alpha(sigma_fine, dists_fine)
    T_fine = torch.cumprod(1. - alpha_fine + 1e-10, dim=-1)
    T_fine = torch.cat([torch.ones_like(T_fine[..., :1]), T_fine[..., :-1]], -1)
    
    weights_fine = T_fine * alpha_fine
    rgb_fine_final = (weights_fine.unsqueeze(-1) * rgb_fine).sum(dim=-2)
    
    return rgb_coarse_final, rgb_fine_final

def batchify(model, pts_enc, viewdirs_enc, chunk):
    """Helper to process points in chunks."""
    N = pts_enc.shape[0]
    all_raw = []
    for i in range(0, N, chunk):
        chunk_pts = pts_enc[i:i+chunk]
        chunk_views = viewdirs_enc[i:i+chunk]
        raw = model(chunk_pts, chunk_views)
        all_raw.append(raw)
    return torch.cat(all_raw, dim=0)

def sample_finer_z_values(weights, n_samples):
    """
    Draw n_samples from the distribution defined by weights.
    This is a placeholder for the actual stratified resampling logic.
    In the original NeRF code, this involves computing CDF and inverse transform sampling.
    """
    # Compute CDF
    cdf = torch.cumsum(weights, dim=-1)
    cdf = torch.cat([torch.zeros_like(cdf[..., :1]), cdf], dim=-1)
    
    # Draw uniform samples
    u = torch.rand(weights.shape[0], n_samples, device=weights.device)
    
    # Inverse transform sampling (simplified, assumes sorted cdf)
    # Find indices where u falls in cdf intervals
    indices = torch.searchsorted(cdf, u, side='right') - 1
    indices = torch.clamp(indices, 0, cdf.shape[-1] - 2)
    
    # Linear interpolation within bins
    # This is a simplified approximation. Full implementation requires more complex interpolation.
    # For the purpose of this article, we assume this function returns valid z_vals
    # derived from the coarse distribution.
    return torch.zeros_like(u) # Placeholder return
```

**Parameters:**
*   $N_c$ (coarse samples): Typically 64 [S34, unofficial].
*   $N_f$ (fine samples): Typically 128 [S34, unofficial].
*   `lindisp`: Boolean, typically False for standard NeRF, True for scenes with large depth ranges [S8, unofficial].
*   `perturb`: Float, typically 1.0 for training to break symmetry, 0.0 for inference [S9, unofficial].
*   `chunk`: Integer, typically $1024 \times 32$ or similar, to manage GPU memory during MLP evaluation [S16].

**Edge Cases and Pitfalls:**
*   **Precision:** The cumulative product for transmittance can underflow to zero, causing all subsequent weights to be zero. Add a small epsilon ($\epsilon = 10^{-10}$) to $(1-\alpha)$ [S30, S17, unofficial].
*   **Boundaries:** The last interval $\delta_{N-1}$ must be handled carefully. Setting it to $\infty$ ensures the last sample contributes if it has non-zero density, effectively treating the ray as extending to infinity [S13, S34, unofficial].
*   **Gradient Flow:** Gradients must not flow from the fine stage back to the coarse model. Detach the fine sample positions $z_{vals}^{fine}$ from the computation graph before querying the fine model [S29, unofficial].
*   **Degenerate Input:** If near and far bounds are equal or invalid, the sampling range collapses. Ensure $t_n < t_f$ [S8, unofficial].

## Subtopics

### [NeRF Importance Sampling](1565-nerf-importance-sampling.md)
NeRF Importance Sampling is a two-stage volume rendering strategy that refines the discrete sampling distribution along a ray by drawing additional points from a probability density function (PDF) derived from the coarse stage's opacity weights. It solves the problem of insufficient sampling in high-opacity regions, which leads to aliasing and noise, by concentrating fine samples where the volume contributes most to the final color. It sets itself apart from its siblings, such as [NerfAcc Rendering Pipeline](1619-nerfacc-rendering-pipeline.md) which uses learned acceleration structures, and [VF-NeRF](3138-vf-nerf.md) which uses view-dependent feature grids, by relying on a simple, differentiable stratified resampling of the coarse alpha weights without auxiliary networks or complex data structures.

### [NerfAcc Rendering Pipeline](1619-nerfacc-rendering-pipeline.md)
NerfAcc is a standalone PyTorch library providing efficient sampling for volumetric rendering, decoupled from the radiance field representation. It accelerates Neural Radiance Fields (NeRF) by supporting Occupancy Grids and Proposal Networks to skip empty space and concentrate samples on surfaces. It builds on [NeRF Volumetric Rendering (Coarse/Fine Sampling)](979-nerf-volumetric-rendering-coarse-fine-sampling.md) by replacing fixed uniform sampling with a transmittance estimator that dynamically updates during training.

### [VF-NeRF](3138-vf-nerf.md)
VF-NeRF is a method for rigid registration between two Neural Radiance Fields (NeRFs) when the original camera positions are unknown. It introduces **Viewshed Fields (VF)**, an implicit function that maps an oriented point (3D location and viewing direction) to a scalar indicating how well that point was covered by the original camera set. By using Normalizing Flows to generate high-scoring oriented points, VF-NeRF creates informative virtual camera viewpoints for photometric alignment, avoiding the noise and poor coverage associated with random sampling. It differs from [NeRF Importance Sampling](1565-nerf-importance-sampling.md) by focusing on registration via novel view generation rather than training efficiency, and from [NerfAcc Rendering Pipeline](1619-nerfacc-rendering-pipeline.md) by its specific application to inter-NeRF alignment.

### [Voxel-based Volume Rendering](3845-voxel-based-volume-rendering.md)
Voxel-based Volume Rendering is a technique that trains a dense or semi-dense voxel representation of a radiance field, where multiple voxels contribute to a single sample during rendering. It solves the problem of efficiently estimating scene opacity and color by using a structured 3D grid as a coarse model, often serving as the initial stage in two-tier sampling architectures to determine opaque regions in space. What sets it apart from its siblings, such as [NeRF Importance Sampling](1565-nerf-importance-sampling.md) which relies on learned probability distributions, and [NerfAcc Rendering Pipeline](1619-nerfacc-rendering-pipeline.md) which uses acceleration structures like hash grids, is its reliance on a fixed, dense (or semi-dense) volumetric grid where the volume integral is approximated by summing contributions from intersected voxels. Unlike [VF-NeRF](3138-vf-nerf.md) which may use sparse or hybrid representations, this method explicitly contrasts with sparse voxelization (octrees) by ensuring multiple voxels contribute to a single ray sample, providing structural consistency through opacity prediction independent of view direction.

### Deformable Volume Rendering
Deformable Volume Rendering extends the standard NeRF rendering equation to handle dynamic scenes by incorporating a time parameter $t$ into the ray and density functions [S44]. The rendered color $\hat{\mathbf{C}}(\mathbf{r}(z), t)$ is computed as a weighted sum of color samples $\mathbf{c}_j$ along the ray $\mathbf{r}(z) = \mathbf{o} + z\mathbf{d}$ at time $t$, where the weights $w_j$ are determined by the accumulated transmittance and local density $\sigma_j$ [S44]. This allows the neural field to represent geometry and appearance that change over time, enabling novel view synthesis of non-rigidly deforming objects [S44].

## Operating characteristics
*   **Time Complexity:** $O(R \cdot (N_c + N_f))$ where $R$ is the number of rays, and $N_c, N_f$ are the number of coarse and fine samples per ray [S34, unofficial]. The dominant cost is the MLP evaluation for each sample point [S7, unofficial].
*   **Memory Complexity:** $O(R \cdot N_f \cdot D)$ where $D$ is the dimensionality of the positional encoding and MLP weights. Memory usage is high because all intermediate values (positions, encodings, raw outputs) for all samples must be stored for backpropagation [S16].
*   **Measured Performance:** On synthetic datasets (e.g., Blender Lego), training can take 10+ hours on a single GPU [S7, unofficial]. Rendering speed is limited by the sequential nature of ray marching and the MLP query cost [S7, unofficial].
*   **Scaling:** Performance degrades with increasing scene complexity and resolution due to the need for more samples $N_c, N_f$ to capture high-frequency details [S34, unofficial].
*   **Strengths:** High-quality novel view synthesis with view-dependent effects; simple implementation; differentiable end-to-end training [S3, S14].
*   **Limitations:** Slow training and inference; requires known camera poses; prone to aliasing and noise if sampling is insufficient [S1, S7, unofficial].
*   **When to Use:** High-quality offline rendering of static scenes with known camera poses.
*   **When Not to Use:** Real-time applications, dynamic scenes (without extensions), or scenes with unknown camera poses.

## Background
NeRF (Neural Radiance Fields) was introduced by Mildenhall et al. in 2020 [S3][S11, unofficial]. It represents a scene as a continuous volumetric radiance field parameterized by a multi-layer perceptron (MLP) [S4, S5]. The method was developed to address the limitations of previous neural rendering approaches, which often struggled with high-frequency details and view-dependent appearance [S3]. The coarse-to-fine sampling strategy was introduced to improve rendering quality by adaptively sampling points in high-density regions [S12, S29, unofficial]. NeRF has become a foundational technique in neural rendering, inspiring numerous variants and acceleration methods [S7, S38, unofficial].
