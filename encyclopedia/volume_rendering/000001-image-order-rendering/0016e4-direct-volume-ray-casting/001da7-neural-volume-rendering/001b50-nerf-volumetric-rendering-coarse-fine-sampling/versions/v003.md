# NeRF Volumetric Rendering (Coarse/Fine Sampling)

Also called: Coarse and Fine Sampling, Differentiable Volume Rendering for View Synthesis, Differentiable volume rendering for NeRF, Flat ray-batch volume rendering, Hierarchical Volume Sampling, NeRF Coarse-to-Fine Rendering, NeRF Fine Sampling and Rendering, NeRF Two-Stage Sampling, NeRF Volume Rendering, Standard NeRF Rendering, Two-Stage Sampling, Volume Rendering (NeRF), VolumeRenderer

## Overview
NeRF Volumetric Rendering synthesizes novel views by querying a neural radiance field (a coordinate MLP) along camera rays and accumulating outputs using differentiable volume rendering [S1, S3]. It solves the view synthesis problem by optimizing a continuous 5D function (spatial location and viewing direction) to predict volume density and view-dependent color [S1]. Unlike single-stage uniform sampling, this method employs a two-stage hierarchical sampling strategy: a coarse network estimates density to guide finer sampling in high-density regions, reducing aliasing and improving geometric detail [S7]. It operates on a flat batch of rays rather than a spatial grid, enabling efficient training on randomly sampled rays [S3].

## How it works
**Inputs:**
- `rays_o`: Ray origins, tensor of shape $[R, 3]$ [S3].
- `rays_d`: Unnormalized ray directions (Blender convention: camera looks down -z), tensor of shape $[R, 3]$ [S3].
- `near`, `far`: Near and far clipping plane distances along the ray, scalars or tensors of shape $[R, 1]$ [S2, S4].
- `coarse_model`, `fine_model`: Two neural networks with identical architecture but independent weights [S7].
- `n_samples`: Number of coarse samples per ray (default 64) [S3].
- `fine_sample_size`: Number of fine samples to add (default 128) [S8].
- `perturb`: Boolean flag to enable stratified sampling jittering (default True) [S3].
- `white_background`: Boolean flag to composite over white background (default True for Blender dataset) [S3].

**Outputs:**
- `rgb`: Rendered color, shape $[R, 3]$ [S3].
- `depth`: Weighted average depth, shape $[R]$ [S3].
- `acc`: Total accumulated opacity, shape $[R]$ [S3].

**Data Structures:**
- The neural field maps 3D coordinates and viewing directions to color $\mathbf{c}$ and density $\sigma$, using positional encoding [S5].
- Samples are stored as $z$-values along the ray parameter $t$ [S2, S3].

**Steps:**

1.  **Ray Initialization and Coarse Sampling:**
    Generate linearly spaced depths $t_{vals} \in [0, 1]$ of size $n_{samples}$ [S3]. Map to world space near/far bounds:
    $$ z_{vals} = \text{near} \cdot (1 - t_{vals}) + \text{far} \cdot t_{vals} $$
    Shape: $[R, n_{samples}]$ [S2, S3].
    If `perturb` is True, apply stratified sampling:
    - Compute midpoints: $mids = 0.5 \cdot (z_{vals}[:, 1:] + z_{vals}[:, :-1])$ [S3].
    - Define intervals: $lower = [z_{vals}[:, 0], mids]$, $upper = [mids, z_{vals}[:, -1]]$ [S3].
    - Jitter: $z_{vals} = lower + (upper - lower) \cdot \text{rand}(R, n_{samples})$ [S3].

2.  **Coarse Network Query:**
    Compute 3D points: $\mathbf{pts} = \text{rays\_o} + \text{rays\_d} \cdot z_{vals}$ [S2, S3].
    Flatten points to $[-1, 3]$ and query `coarse_model` to get raw RGB $\mathbf{c}$ and density $\sigma$ [S3, S5].
    Reshape outputs to $[R, n_{samples}, 3]$ and $[R, n_{samples}]$ [S7].

3.  **Coarse Rendering (Alpha Compositing):**
    Compute segment distances $\delta$:
    $$ \delta_i = (z_{vals, i+1} - z_{vals, i}) \cdot \|\text{rays\_d}\| $$
    Append a large value ($10^{10}$) for the last segment to ensure termination [S2, S4].
    Compute alpha using softplus activation on density:
    $$ \alpha_i = 1 - \exp(-\text{softplus}(\sigma_i) \cdot \delta_i) $$
    [S2]. Add epsilon ($10^{-10}$) to $(1-\alpha)$ before cumulative product for stability [S3].
    Compute transmittance $T$ (exclusive cumulative product):
    $$ T_i = \prod_{j=0}^{i-1} (1 - \alpha_j + \epsilon) $$
    [S3]. Compute weights:
    $$ w_i = T_i \cdot \alpha_i $$
    [S3, S5].
    Render coarse maps:
    $$ C_{coarse} = \sum w_i \mathbf{c}_i, \quad D_{coarse} = \sum w_i z_{i}, \quad A_{coarse} = \sum w_i $$
    [S5].

4.  **Fine Sampling (Hierarchical):**
    Use coarse weights to guide finer sampling [S5]. Exclude the first weight (index 0) as it corresponds to the start of the ray [S5].
    - Add epsilon ($10^{-5}$) to weights and normalize to form a probability distribution [S7].
    - Compute CDF from weights, prepend zero [S7].
    - Sample $fine\_sample\_size$ values from a uniform distribution [S7].
    - Use inverse CDF sampling (searchsorted) to find bin indices and interpolate $z$-values within bins to generate $z_{fine}$ [S7].
    - Detach $z_{fine}$ from the computation graph to prevent gradient flow to the coarse network [S7].

5.  **Interleaving and Fine Network Query:**
    Concatenate coarse $z_{vals}$ and fine $z_{fine}$, then sort them to interleave samples [S7].
    Compute new 3D points $\mathbf{pts}_{all}$ from sorted $z$-values [S7].
    Flatten and query `fine_model` to get $\mathbf{c}_{fine}$ and $\sigma_{fine}$ [S7].

6.  **Fine Rendering:**
    Recompute distances $\delta$ and alphas $\alpha$ for the sorted samples using the fine network outputs [S7].
    Compute new weights $w_i$ and transmittance $T_i$ [S7].
    Render final maps:
    $$ C_{final} = \sum w_i \mathbf{c}_i $$
    [S7].
    If `white_background` is True, add background contribution:
    $$ C_{final} = C_{final} + (1 - A_{final}) \cdot \mathbf{1} $$
    [S3, S7].

**Pseudocode:**

```python
import torch
import torch.nn as nn

def softplus(x):
    return nn.functional.softplus(x)

def render_rays(rays_o, rays_d, near, far, coarse_model, fine_model, 
                n_samples=64, fine_sample_size=128, perturb=True, 
                white_background=True, epsilon_alpha=1e-10, epsilon_weight=1e-5):
    """
    Renders rays using NeRF coarse-to-fine sampling.
    
    Args:
        rays_o: [R, 3] Ray origins
        rays_d: [R, 3] Ray directions (unnormalized)
        near: [R, 1] Near plane distances
        far: [R, 1] Far plane distances
        coarse_model: Neural network returning (color, density)
        fine_model: Neural network returning (color, density)
        n_samples: int Number of coarse samples
        fine_sample_size: int Number of fine samples
        perturb: bool Enable stratified sampling
        white_background: bool Composite over white
        epsilon_alpha: float Epsilon for alpha stability
        epsilon_weight: float Epsilon for weight normalization
        
    Returns:
        rgb: [R, 3]
        depth: [R]
        acc: [R]
    """
    R = rays_o.shape[0]
    
    # 1. Coarse Sampling
    t_vals = torch.linspace(0.0, 1.0, n_samples, device=rays_o.device)
    z_vals = near * (1.0 - t_vals) + far * t_vals  # [R, n_samples]
    
    if perturb:
        mids = 0.5 * (z_vals[:, 1:] + z_vals[:, :-1])
        upper = torch.cat([mids, z_vals[:, -1:]], dim=-1)
        lower = torch.cat([z_vals[:, :1], mids], dim=-1)
        random_vals = torch.rand_like(z_vals)
        z_vals = lower + (upper - lower) * random_vals
        
    # 2. Coarse Network Query
    pts_coarse = rays_o[:, None, :] + rays_d[:, None, :] * z_vals[:, :, None]  # [R, n_samples, 3]
    pts_flat = pts_coarse.reshape(-1, 3)
    dirs_flat = rays_d[:, None, :].expand(pts_coarse.shape).reshape(-1, 3)
    
    coarse_out = coarse_model(pts_flat, dirs_flat)
    c_coarse = coarse_out[0].reshape(R, n_samples, 3)
    sigma_coarse = coarse_out[1].reshape(R, n_samples)
    
    # 3. Coarse Rendering
    dists = z_vals[:, 1:] - z_vals[:, :-1]  # [R, n_samples-1]
    dists = torch.cat([dists, torch.full((R, 1), 1e10, device=rays_o.device)], dim=-1) # [R, n_samples]
    dists = dists * torch.norm(rays_d, dim=-1, keepdim=True)  # [R, n_samples]
    
    alpha_coarse = 1.0 - torch.exp(-softplus(sigma_coarse) * dists)
    # Transmittance: exclusive cumprod
    ones = torch.ones_like(alpha_coarse[:, :1])
    T_coarse = torch.cumprod(torch.cat([ones, 1.0 - alpha_coarse + epsilon_alpha], dim=-1), dim=-1)[:, :-1]
    weights_coarse = T_coarse * alpha_coarse
    
    rgb_coarse = torch.sum(weights_coarse[:, :, None] * c_coarse, dim=1)
    acc_coarse = torch.sum(weights_coarse, dim=1)
    depth_coarse = torch.sum(weights_coarse * z_vals, dim=1)
    
    # 4. Fine Sampling
    # Use weights from index 1 to n_samples-1 (excluding first bin start)
    weights_fine = weights_coarse[:, 1:] + epsilon_weight
    weights_fine = weights_fine / (torch.sum(weights_fine, dim=-1, keepdim=True) + epsilon_weight)
    
    # CDF
    cdf = torch.cumsum(weights_fine, dim=-1)
    cdf = torch.cat([torch.zeros_like(cdf[:, :1]), cdf], dim=-1)
    
    # Sample from uniform distribution
    u = torch.rand(R, fine_sample_size, device=rays_o.device)
    
    # Inverse CDF Sampling
    indices = torch.searchsorted(cdf, u, right=True)
    below_indices = torch.clamp(indices - 1, min=0)
    above_indices = torch.clamp(indices, max=cdf.shape[-1] - 1)
    
    cdf_below = torch.gather(cdf, 1, below_indices)
    cdf_above = torch.gather(cdf, 1, above_indices)
    # Use mids for bin interpolation
    mids_fine = 0.5 * (z_vals[:, 1:] + z_vals[:, :-1])
    z_below = torch.gather(mids_fine, 1, below_indices)
    z_above = torch.gather(mids_fine, 1, above_indices)
    
    denom = cdf_above - cdf_below + epsilon_weight
    t = (u - cdf_below) / denom
    z_fine = z_below + t * (z_above - z_below)
    
    # Detach to stop gradient flow to coarse model
    z_fine = z_fine.detach()
    
    # 5. Interleave and Fine Query
    z_all = torch.cat([z_vals, z_fine], dim=-1)
    z_all, _ = torch.sort(z_all, dim=-1)
    
    pts_all = rays_o[:, None, :] + rays_d[:, None, :] * z_all[:, :, None]
    pts_flat_all = pts_all.reshape(-1, 3)
    dirs_flat_all = rays_d[:, None, :].expand(pts_all.shape).reshape(-1, 3)
    
    fine_out = fine_model(pts_flat_all, dirs_flat_all)
    c_fine = fine_out[0].reshape(R, z_all.shape[-1], 3)
    sigma_fine = fine_out[1].reshape(R, z_all.shape[-1])
    
    # 6. Fine Rendering
    dists_all = z_all[:, 1:] - z_all[:, :-1]
    dists_all = torch.cat([dists_all, torch.full((R, 1), 1e10, device=rays_o.device)], dim=-1)
    dists_all = dists_all * torch.norm(rays_d, dim=-1, keepdim=True)
    
    alpha_fine = 1.0 - torch.exp(-softplus(sigma_fine) * dists_all)
    ones_all = torch.ones_like(alpha_fine[:, :1])
    T_fine = torch.cumprod(torch.cat([ones_all, 1.0 - alpha_fine + epsilon_alpha], dim=-1), dim=-1)[:, :-1]
    weights_fine_final = T_fine * alpha_fine
    
    rgb_final = torch.sum(weights_fine_final[:, :, None] * c_fine, dim=1)
    acc_final = torch.sum(weights_fine_final, dim=1)
    depth_final = torch.sum(weights_fine_final * z_all, dim=1)
    
    if white_background:
        rgb_final = rgb_final + (1.0 - acc_final[:, None])
        
    return rgb_final, depth_final, acc_final
```

## Subtopics

### [Hierarchical Sampling (Inverse CDF Sampling)](973-hierarchical-sampling-inverse-cdf-sampling.md)
The specific sampling technique used in the fine stage to draw samples from the probability distribution defined by the coarse weights.

### [Uniform Ray Sampling](1261-uniform-ray-sampling.md)
The baseline sampling method used in the coarse stage before stratification, which NeRF improves upon by adding jitter and hierarchical refinement.

## Operating characteristics
- **Performance:** Hierarchical sampling uses the coarse model's density to guide finer sampling, reducing aliasing and improving detail compared to single-stage uniform sampling [S7].
- **Strengths:** Differentiable end-to-end, allowing optimization from images alone; handles view-dependent appearance via directional encoding; hierarchical sampling efficiently allocates samples to dense regions [S1, S7].
- **Limitations:** The basic implementation is inefficient and does not converge to a sufficiently high-resolution representation for complex scenes without hierarchical refinement [S1].

## Background
NeRF (Neural Radiance Fields) was introduced by Mildenhall et al. in 2020 [S1]. It represents a scene as a continuous 5D function mapping spatial coordinates and viewing directions to volume density and emitted color [S1]. The method is trained by minimizing the difference between rendered images and ground truth images using gradient descent, leveraging the differentiability of the volume rendering integral [S1]. The coarse-to-fine sampling strategy was introduced to address the inefficiency and aliasing artifacts of uniform sampling, allowing the model to focus computational resources on regions with high density [S7].
