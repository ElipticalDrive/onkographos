# NeuSample

Also called: Neural Sample Field

## Overview
NeuSample is a method for efficient novel view synthesis that replaces the coarse-to-fine hierarchical sampling stage of Neural Radiance Fields (NeRF) with a lightweight neural network called the Neural Sample Field [S1, unofficial]. It solves the problem of high computational overhead during inference by mapping a ray directly to a set of sample positions, enabling single-shot inference without a separate coarse pass [S1, unofficial]. Unlike NeRF, which requires two-stage inference to estimate opacity and then refine samples, NeuSample learns the sampling distribution end-to-end, achieving better rendering quality with approximately 25% less inference time on standard benchmarks [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A ray defined by origin $o = (x_o, y_o, z_o)$ and normalized direction $d = (\theta, \phi)$.
*   **Output:** A set of $N$ 3D coordinates $\{x_1, ..., x_N\}$ along the ray, which are fed into the radiance field to compute density $\sigma$ and color $c$.

**Data Structures:**
The Neural Sample Field $S_\Theta$ is a Multi-Layer Perceptron (MLP).
*   **Input Layer:** Concatenation of position-encoded ray origin and direction.
*   **Hidden Layers:** 8 Fully Connected (FC) layers with ReLU activations.
*   **Skip Connection:** The input is concatenated with the output of the 4th hidden layer.
*   **Hidden Dimension:** 256 features per layer.
*   **Output Layer:** 1 FC layer mapping 256 features to $N$ scalars, followed by a Sigmoid activation.

**Parameters:**
*   $N$: The number of samples output by the field. In the source experiments, $N=192$ [S1, unofficial]. This replaces the sum of coarse ($N_c$) and fine ($N_f$) samples used in standard NeRF.
*   Position Encoding: 10-frequency sine/cosine encoding applied to both origin and direction [S1, unofficial].

**Algorithm:**
1.  **Ray Computation:** Compute ray origin $o$ and direction $d$ for the target pixel based on camera pose.
2.  **Encoding:** Apply 10-frequency position encoding $\tilde{\tau}$ to $o$ and $d$. Concatenate the encoded vectors.
3.  **Sample Field Inference:** Pass the concatenated encoded input through $S_\Theta$ to obtain $N$ scalars $\hat{t}_1, ..., \hat{t}_N$.
4.  **Normalization:** The output of $S_\Theta$ is passed through a Sigmoid activation to constrain values to $[0, 1]$. These are the relative sample positions $\hat{t}_i$.
5.  **Coordinate Transformation:** Map relative positions $\hat{t}_i$ to absolute distances $t_i$ using near ($t_n$) and far ($t_f$) bounds:
    $$ t_i = (1 - \hat{t}_i)t_n + \hat{t}_i t_f $$
    Compute 3D coordinates:
    $$ x_i = o + t_i d $$
6.  **Radiance Field Evaluation:** Feed $x_i$ into the radiance field network $R_\Theta$ to obtain density $\sigma_i$ and color $c_i$.
7.  **Volume Rendering:** Accumulate the final pixel color $C(r)$ using standard volume rendering integration over the samples [S1, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn as nn
import math

class PositionalEncoding(nn.Module):
    """10-frequency positional encoding for NeRF-style inputs."""
    def __init__(self, num_frequencies=10):
        super().__init__()
        self.num_frequencies = num_frequencies

    def forward(self, x):
        # x shape: (..., 3)
        # NeRF encoding: sin(2^i * pi * x) for i in 0..num_frequencies-1
        # Output shape: (..., 3 * 2 * num_frequencies)
        freq_bands = 2.0 ** torch.arange(self.num_frequencies, device=x.device).float() * math.pi
        # Expand x to (..., 1, 3) and freq_bands to (1, num_frequencies, 1)
        # Result: (..., num_frequencies, 3)
        scaled_x = x.unsqueeze(-2) * freq_bands.unsqueeze(-1)
        encoded = torch.sin(scaled_x)
        return encoded.view(*x.shape[:-1], -1)

class NeuralSampleField(nn.Module):
    """
    NeuSample Neural Sample Field S_Theta.
    Maps ray (origin, direction) to N relative sample positions in [0, 1].
    """
    def __init__(self, num_samples=192, hidden_dim=256, num_fc_layers=8, pos_freq=10):
        super().__init__()
        self.num_samples = num_samples
        self.pos_encoder = PositionalEncoding(num_frequencies=pos_freq)
        
        # Input dimension: 3 (origin) + 3 (direction) = 6 raw dims
        # Encoded dimension: 6 * 2 * 10 = 120
        input_dim = 6 * 2 * pos_freq
        
        # 8 FC layers with ReLU
        layers = []
        prev_dim = input_dim
        for i in range(num_fc_layers):
            layers.append(nn.Linear(prev_dim, hidden_dim))
            layers.append(nn.ReLU())
            prev_dim = hidden_dim
            
        # Skip connection: Concatenate input with output of 4th layer (index 3 in 0-based list of layers before activation? 
        # Note: Source says "concatenate the original input with the output of the 4th layer". 
        # In a sequential list of Linear+ReLU, the 4th layer's output is after the 4th ReLU.
        # We will implement this via a custom forward pass or explicit structure.
        # To keep it clean, we define the first 4 layers, then the rest.
        
        self.first_half = nn.Sequential(
            nn.Linear(input_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU()
        )
        
        self.second_half = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim), nn.ReLU()
        )
        
        # Final mapping to N samples
        self.output_layer = nn.Linear(hidden_dim, num_samples)
        self.sigmoid = nn.Sigmoid()

    def forward(self, origin, direction):
        """
        origin: (..., 3)
        direction: (..., 3)
        Returns: (..., N) relative positions in [0, 1]
        """
        # Encode
        enc_origin = self.pos_encoder(origin)
        enc_direction = self.pos_encoder(direction)
        x = torch.cat([enc_origin, enc_direction], dim=-1)
        
        # First half
        h = self.first_half(x)
        
        # Skip connection: concatenate original input (encoded) with h
        # Source: "Concatenate the original input with the output of the 4th layer"
        # The input to the network is the encoded vector.
        x_with_skip = torch.cat([x, h], dim=-1)
        
        # Second half
        h = self.second_half(x_with_skip)
        
        # Output
        logits = self.output_layer(h)
        relative_positions = self.sigmoid(logits)
        
        return relative_positions

def render_neusample(ray_origins, ray_directions, near_bound, far_bound, sample_field, radiance_field):
    """
    Single-shot rendering using NeuSample.
    
    ray_origins: (H, W, 3)
    ray_directions: (H, W, 3)
    near_bound: float
    far_bound: float
    sample_field: NeuralSampleField instance
    radiance_field: RadianceField instance (standard NeRF MLP)
    """
    # 1. Get relative positions from Neural Sample Field
    # sample_field outputs (H, W, N)
    relative_t = sample_field(ray_origins, ray_directions)
    
    # 2. Map to absolute distances
    # t_i = (1 - t_hat_i) * t_n + t_hat_i * t_f
    absolute_t = (1 - relative_t) * near_bound + relative_t * far_bound
    
    # 3. Compute 3D coordinates
    # x_i = o + t_i * d
    # absolute_t shape: (H, W, N)
    # ray_origins shape: (H, W, 3)
    # ray_directions shape: (H, W, 3)
    # Expand for broadcasting
    coords = ray_origins.unsqueeze(-2) + absolute_t.unsqueeze(-1) * ray_directions.unsqueeze(-2)
    # coords shape: (H, W, N, 3)
    
    # 4. Evaluate Radiance Field
    # Reshape to (H*W*N, 3) for batched evaluation if the radiance field expects it,
    # or iterate. Assuming radiance_field can handle (..., 3) input.
    # radiance_field returns sigma and color
    # sigma: (H, W, N, 1)
    # color: (H, W, N, 3)
    sigma, color = radiance_field(coords)
    
    # 5. Volume Rendering
    # Standard NeRF integration
    # delta_i = t_{i+1} - t_i
    # Add a small epsilon to avoid division by zero or log(0) issues if needed, 
    # though standard alpha calculation handles it.
    # Sort samples? NeuSample output is not guaranteed sorted. 
    # Source does not explicitly mention sorting. However, volume rendering 
    # formulas typically assume ordered samples. 
    # Note: The source formula for rendering uses delta_i = t_{i+1} - t_i.
    # If samples are not sorted, delta_i can be negative.
    # Standard practice in such learned sampling is to sort the samples 
    # before rendering to ensure correct depth ordering. 
    # The source text says "transformed into point coordinates... fed into radiance field... 
    # perform volume rendering". It does not explicitly state sorting.
    # However, Eq 2 in source implies standard integration. 
    # If the network outputs unsorted t_hat, the rendering will be incorrect.
    # We assume the network learns to output sorted samples or the implementation sorts them.
    # Given "relative sample position between the near and far bound", 
    # and the goal of modeling geometry, sorted output is implied for valid integration.
    # We will add a sort step as a necessary implementation detail for correctness [G].
    
    # Sort samples by absolute_t
    sorted_t, sort_indices = torch.sort(absolute_t, dim=-1)
    
    # Apply sort to coords, sigma, color
    # Using advanced indexing or gather
    # coords: (H, W, N, 3) -> (H, W, N, 3)
    # sigma: (H, W, N, 1) -> (H, W, N, 1)
    # color: (H, W, N, 3) -> (H, W, N, 3)
    
    # Reshape for gathering
    H, W, N, _ = coords.shape
    flat_indices = sort_indices.unsqueeze(-1).expand(-1, -1, -1, 3).long()
    flat_sigma_indices = sort_indices.unsqueeze(-1).expand(-1, -1, -1, 1).long()
    flat_color_indices = sort_indices.unsqueeze(-1).expand(-1, -1, -1, 3).long()
    
    sorted_coords = torch.gather(coords, -2, flat_indices)
    sorted_sigma = torch.gather(sigma, -2, flat_sigma_indices)
    sorted_color = torch.gather(color, -2, flat_color_indices)
    
    # Calculate deltas
    # delta_i = t_{i+1} - t_i
    # Add far_bound at the end to get delta for the last segment
    t_expanded = torch.cat([sorted_t, torch.full_like(sorted_t[..., :1], far_bound)], dim=-1)
    deltas = t_expanded[..., 1:] - t_expanded[..., :-1]
    
    # Alpha calculation
    # alpha_i = 1 - exp(-sigma_i * delta_i)
    alpha = 1.0 - torch.exp(-sorted_sigma * deltas)
    
    # Transmittance
    # T_i = product(1 - alpha_j) for j < i
    # T_1 = 1
    # T_i = T_{i-1} * (1 - alpha_{i-1})
    # Using cumprod
    # (1 - alpha) shape: (H, W, N)
    # Shifted for T
    transmittance_prev = torch.cat([torch.ones_like(alpha[..., :1]), 1.0 - alpha[..., :-1]], dim=-1)
    transmittance = torch.cumprod(transmittance_prev, dim=-1)
    
    # Weight w_i = alpha_i * T_i
    weights = alpha * transmittance
    
    # Final color
    # C = sum(w_i * c_i)
    final_color = torch.sum(weights.unsqueeze(-1) * sorted_color, dim=-2)
    
    return final_color
```

**Edge Cases and Pitfalls:**
*   **Sample Ordering:** The volume rendering formula assumes samples are ordered along the ray. The Neural Sample Field outputs relative positions in $[0,1]$. If the network outputs unsorted positions, the computed deltas $\delta_i$ will be incorrect, leading to rendering artifacts. The implementation must sort the samples by $t_i$ before rendering [G].
*   **Precision:** The use of Sigmoid constrains outputs to $[0,1]$. If the scene geometry extends significantly beyond $[t_n, t_f]$, samples will be clipped, potentially missing geometry.
*   **Initialization:** The source mentions a "sample field extraction method" and "depth boost" for real-world scenes, implying that initialization from a coarse NeRF or depth predictor can help convergence [S1, unofficial].

## Subtopics

### Sample Field Extraction
A compression technique that extracts a smaller, faster sample field from the trained NeuSample model to further reduce inference time (e.g., to 25% of original) while maintaining quality [S1, unofficial].

### Depth Boost Initialization
A training strategy for real-world scenes where the output mean of the extracted sample field is forced to fit depth predicted by a learned regular field, aiding convergence on complex geometry [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Single-shot inference. Avoids the two-stage (coarse + fine) evaluation of NeRF. Saves approximately 25% of inference time compared to standard NeRF [S1, unofficial].
*   **Memory Complexity:** Requires storing the Neural Sample Field network (8 FC layers, 256 hidden dim) in addition to the Radiance Field. The memory overhead is small compared to the savings in compute.
*   **Performance:** On Realistic Synthetic 360° and Real ForwardFacing benchmarks, NeuSample achieves better or comparable PSNR to NeRF while being faster [S1, unofficial].
*   **Strengths:** Eliminates the need for hierarchical sampling logic; end-to-end differentiable training; simpler pipeline.
*   **Limitations:** Requires training a separate network for sampling; performance may depend on the quality of the learned sampling distribution, especially in complex real-world scenes (addressed via extraction/initialization techniques).

## Background
NeuSample was introduced in the paper "NeuSample: Neural Sample Field for Efficient View Synthesis" [S1, unofficial]. It addresses the computational bottleneck of NeRF's coarse-to-fine sampling. The method was developed to enable faster inference for novel view synthesis, particularly for applications like virtual reality and 3D previews where real-time or near-real-time performance is critical. It builds on the principles of neural radiance fields but modifies the sampling strategy to be learned rather than heuristic.
