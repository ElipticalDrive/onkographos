# Neural Voxel Renderer

Also called: NVR Architecture

## Overview
The Neural Voxel Renderer (NVR) is a neural network that takes a discrete voxel representation of a scene and a light position as input to produce a continuous, smooth rendered image [S1]. It solves the problem of mapping discrete geometric representations (voxels) to high-quality, physically-based renderings by implicitly learning the complex lighting and shading effects that traditional rasterization or simple volume rendering might miss [S1]. What sets it apart from its siblings, such as the Coarse Ray Renderer, is its explicit use of a dual-branch architecture (voxel encoding and light encoding) combined with a perceptual loss function to ensure photorealistic output from a structured 3D grid input [S1].

## How it works
**Inputs and Outputs:**
*   **Voxel Input ($V$):** A 3D grid of voxels with dimensions $128 \times 128 \times 128$ and 4 channels (RGB + visibility), denoted as $V \in \mathbb{R}^{128 \times 4}$ [S1]. The notation $\mathbb{R}^{128 \times 4}$ in the source text is a known typo for a 3D grid structure, but the spatial dimensions $128^3$ and 4 channels are the operative parameters [S1].
*   **Light Input ($L$):** A 3D vector representing the light position, $L \in \mathbb{R}^3$ [S1].
*   **Output Image ($I$):** A 2D image with dimensions $256 \times 256$ and 3 channels (RGB), denoted as $I \in \mathbb{R}^{256 \times 3}$ [S1].

**Data Structures:**
The network $\theta$ processes $V$ and $L$ to produce $I$ [S1]. The internal data structures consist of feature maps generated by convolutional layers [S1]. The voxel branch produces 2D feature maps of a specific spatial resolution that matches the tiled light features [S1]. The light branch produces a latent vector that is expanded to match the spatial dimensions of the voxel features [S1].

**Numbered Steps:**
1.  **Voxel Encoding:** Process the 3D input voxels $V$ through a series of 3D convolutions [S1].
2.  **Reshaping:** Transform the 3D features into 2D by reshaping the last two dimensions [S1]. If the feature tensor is $h \times w \times d \times c$, it becomes $h \times w \times (d \times c)$ [S1]. This step acts as an orthographic projection in latent space, keeping all depth information [S1].
3.  **1×1 Convolutions:** Apply 1×1 convolutions to the reshaped features [S1].
4.  **2D Convolution:** Process the features through a series of 2D convolutional blocks (followed by batch normalization and ReLU activations) to produce the final voxel encoding features [S1].
5.  **Light Encoding:** Process the light input $L$ through a separate branch consisting of 2 fully connected layers to deliver latent illumination features [S1].
6.  **Tiling:** Tile the latent illumination features to form an image with the same spatial dimensions as the final features from the voxel encoding branch [S1]. This ensures every spatial location has illumination information [S1].
7.  **Concatenation:** Concatenate the tiled light features with the voxel encoding features along the channel dimension [S1].
8.  **Decoding:** Feed the joint features to a decoder (a series of 2D convolutional layers) that outputs the final image $I$ at resolution $256 \times 256$ [S1].

**Formulas:**
The network is trained by minimizing the loss function $L(I, T)$:

$$
L(I, T) = ||I - T||_1 + \beta \sum_i w_i ||v_i(I) - v_i(T)||_2
$$

Where:
*   $I$ is the predicted image [S1].
*   $T$ is the target image [S1].
*   $v_i$ is the response of the $i$-th layer of a pretrained VGG network [S1].
*   $w_i$ is the weighting factor for layer $i$ [S1].
*   $\beta$ is a hyperparameter [S1].

**Parameters:**
*   **Optimizer:** Adam [S1].
*   **Learning Rate:** $10^{-4}$ [S1].
*   **Batch Size:** 10 [S1].
*   **VGG Layers:** conv1 and conv2 are used for perceptual loss [S1].
*   **Scene Setup:** Camera focal length is fixed to 40, light color is fixed to white, object material is diffuse, floor material is slightly specular, and an area light is used to generate realistic soft shadows [S1].

**Pseudocode:**
```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class NeuralVoxelRenderer(nn.Module):
    def __init__(self):
        super(NeuralVoxelRenderer, self).__init__()
        # Voxel Encoding Branch
        # Series of 3D convolutions (details not specified in source)
        self.voxel_3d_conv = nn.Sequential(
            nn.Conv3d(4, 64, kernel_size=3, padding=1),
            nn.BatchNorm3d(64),
            nn.ReLU(),
            nn.Conv3d(64, 128, kernel_size=3, padding=1),
            nn.BatchNorm3d(128),
            nn.ReLU()
        )
        
        # 1x1 Convolutions on reshaped features
        self.voxel_1x1_conv = nn.Conv3d(128, 128, kernel_size=1)
        
        # 2D Convolutional blocks for voxel features
        self.voxel_2d_conv = nn.Sequential(
            nn.Conv2d(128, 256, kernel_size=3, padding=1),
            nn.BatchNorm2d(256),
            nn.ReLU(),
            nn.Conv2d(256, 256, kernel_size=3, padding=1),
            nn.BatchNorm2d(256),
            nn.ReLU()
        )
        
        # Light Encoding Branch
        # 2 fully connected layers
        self.light_fc1 = nn.Linear(3, 256)
        self.light_fc2 = nn.Linear(256, 256)
        
        # Decoder
        # Series of 2D convolutional layers to output 256x256x3 image
        self.decoder = nn.Sequential(
            nn.Conv2d(512, 256, kernel_size=3, padding=1),
            nn.BatchNorm2d(256),
            nn.ReLU(),
            nn.Conv2d(256, 128, kernel_size=3, padding=1),
            nn.BatchNorm2d(128),
            nn.ReLU(),
            nn.Conv2d(128, 3, kernel_size=3, padding=1)
        )

    def forward(self, V, L):
        """
        V: Tensor of shape (B, 4, 128, 128, 128)
        L: Tensor of shape (B, 3)
        """
        # 1. Voxel Encoding
        x = self.voxel_3d_conv(V)  # Shape: (B, 128, 128, 128, 128)
        
        # 2. Reshaping: h x w x d x c -> h x w x (d * c)
        # Permute to (B, H, W, D, C) to match source description
        x = x.permute(0, 2, 3, 1, 4)  # (B, 128, 128, 128, 128)
        B, H, W, D, C = x.shape
        x = x.view(B, H, W, D * C)    # (B, 128, 128, 16384)
        
        # 3. 1x1 Convolutions (applied in channel dimension)
        x = x.permute(0, 3, 1, 2)    # (B, 16384, 128, 128)
        x = self.voxel_1x1_conv(x)   # (B, 128, 128, 128)
        
        # 4. 2D Convolutional blocks
        x = self.voxel_2d_conv(x)    # (B, 256, 128, 128)
        
        # 5. Light Encoding
        l_feat = F.relu(self.light_fc1(L))
        l_feat = self.light_fc2(l_feat)  # Shape: (B, 256)
        
        # 6. Tiling
        # Expand light features to match spatial dimensions of x
        l_tiled = l_feat.view(B, -1, 1, 1).expand(-1, -1, H, W)  # (B, 256, 128, 128)
        
        # 7. Concatenation
        joint = torch.cat([x, l_tiled], dim=1)  # (B, 512, 128, 128)
        
        # 8. Decoding
        out = self.decoder(joint)  # (B, 3, 256, 256)
        return out
```

**Edge Cases and Pitfalls:**
*   **Precision:** The use of perceptual loss with VGG requires careful normalization of input images to match VGG's expected input distribution [S1].
*   **Boundaries:** The voxel input is fixed at $128^3$ [S1]. Scenes larger or smaller than this resolution may require preprocessing or interpolation [S1].
*   **Symmetry:** The source mentions taking advantage of symmetry for man-made objects by copying color from symmetric voxels if the original is not visible [S1].
*   **Projective Texturing Artifacts:** Appearance capture from a single image introduces artifacts typical of projective texturing, where assigned colors contain view-dependent information (shading, shadows) from the input view [S1]. When rendering from a different viewpoint or lighting condition, the object colors need to change accordingly, but captured colors are static [S1].

## Subtopics

### NVR+
An extension of NVR that adds a rerendering network (using RenderNet as a backbone) to handle high-frequency and irregular textures that cause blurring in the base NVR [S1]. It maintains high-quality textures while producing the correct overall scene appearance [S1].

### Coarse Ray Renderer
A sibling method in the volume rendering hierarchy [S1]. While NVR uses a fixed voxel grid and neural network to map directly to images, Coarse Ray Rendering typically involves sampling rays through a volume representation [S1]. NVR is distinct in its explicit dual-branch architecture and direct image output from voxels [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** The network is trained to produce smooth surfaces in the output image, implicitly learning to map discrete voxels to continuous renderings [S1].
*   **Strengths:** Can render overall structure, colors, reflections, and shadows well [S1]. Implicitly learns to smooth discrete geometric representations [S1].
*   **Limitations:** When the color pattern of the object in the input voxels forms a high-frequency and irregular texture, the output may blur and exhibit artifacts [S1].
*   **When to use:** When a smooth, photorealistic rendering is needed from a voxel representation, and the scene does not contain high-frequency irregular textures [S1].
*   **When not to use:** When the input voxels contain high-frequency, irregular textures, as the base NVR may produce blurry results with artifacts [S1].

## Background
The Neural Voxel Renderer was introduced in the paper "Neural Voxel Renderer: Learning an Accurate and Controllable Rendering Tool" [S1]. The method uses a traditional, physically-based renderer to generate target images from 3D meshes, which are then used to train the neural network [S1]. The architecture is illustrated in Fig. 4 of the source paper [S1].
