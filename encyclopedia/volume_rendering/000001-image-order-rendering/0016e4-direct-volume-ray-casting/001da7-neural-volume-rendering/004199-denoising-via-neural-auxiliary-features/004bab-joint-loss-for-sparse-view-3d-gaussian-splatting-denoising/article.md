# Joint Loss for Sparse-View 3D Gaussian Splatting Denoising

Also called: Composite Perceptual Loss, Denoise-GS Joint Loss

## Overview
The Joint Loss is a composite objective function used in the second round of training to refine denoised images generated by 3D Gaussian Splatting (3DGS) from sparse views [S1]. It balances low-frequency agreement with high-frequency fidelity to enhance detail sharpness and texture fidelity while preserving structural consistency [S1]. It sets itself apart from simple pixel-wise losses by explicitly separating coarse tone preservation from fine detail restoration, using specific terms for gradient, chroma, and total variation to prevent over-sharpening and color shifts [S1].

## How it works
The method operates during the refinement stage of a two-round training process [S1]. The first round produces a coarse denoised image, and the Joint Loss is applied in the second round to fine-tune the output [S1].

### Inputs and Outputs
*   **Input ($x$):** The coarse denoised image from the first training round [S1].
*   **Output ($\hat{x}$):** The refined image predicted by the neural network parameters $\theta$ [S1].
*   The loss compares $\hat{x}$ against $x$ to guide the refinement process [S1].

### Steps
1. Render the coarse denoised image $x$ from the first training round [S1].
2. Apply Gaussian smoothing with standard deviation $\sigma$ to both the input $x$ and the network output $\hat{x}$ [S1].
3. Compute the low-frequency consistency loss $L_{coarse}$ using the Charbonnier loss on the smoothed images [S1].
4. Compute the detail consistency loss $L_{fine}$ using pixel-wise Charbonnier loss, SSIM, gradient consistency, chroma consistency, and Total Variation regularization [S1].
5. Combine the losses into the total objective $L(\theta) = \alpha L_{coarse}(\theta) + (1-\alpha)L_{fine}(\theta)$ and backpropagate to refine the network parameters $\theta$ [S1].

### Formulas
The total loss $L(\theta)$ is a weighted sum of a coarse loss $L_{coarse}$ and a fine loss $L_{fine}$ [S1]:

$$
L(\theta) = \alpha L_{coarse}(\theta) + (1-\alpha) L_{fine}(\theta)
$$

**1. Low-Frequency Consistency Loss ($L_{coarse}$)** [S1]
This term compares the input and output after Gaussian smoothing to preserve tone and large-scale structure [S1]:

$$
L_{coarse} = \frac{1}{|\Omega|} \sum_{p \in \Omega} \rho(G_{\sigma}(\hat{x})(p) - G_{\sigma}(x)(p))
$$

Where:
*   $\Omega$ is the pixel domain.
*   $G_{\sigma}$ is Gaussian smoothing with standard deviation $\sigma$ [S1].
*   $\rho(\delta) = \sqrt{\delta^2 + \epsilon^2}$ is the Charbonnier loss [S1].

**2. Detail Consistency Loss ($L_{fine}$)** [S1]
This term preserves edges, textures, and color consistency while avoiding over-sharpening [S1]:

$$
L_{fine} = \lambda_1 \rho(\hat{x} - x) + \lambda_2 (1 - SSIM(\hat{x}, x)) + \lambda_3 \|\nabla \hat{x} - \nabla x\| + \lambda_4 \|Chr(\hat{x}) - Chr(x)\| + \lambda_5 TV(\hat{x})
$$

Where:
*   $\rho(\hat{x} - x)$ is the pixel-level robust distance (Charbonnier loss) [S1].
*   $SSIM(\hat{x}, x)$ is the Structural Similarity Index Measure between the output and the input image [S1].
*   $\nabla$ denotes the image gradient operator [S1].
*   $Chr(\cdot)$ denotes the chroma component of the image [S1].
*   $TV(\hat{x})$ is the Total Variation of the output image [S1].

### Parameters
*   $\alpha$: Weight for low-frequency consistency loss. Typical value: $0.35$ [S1].
*   $\lambda_1$: Coefficient for overall pixel fidelity (robust distance). Typical value: $0.25$ [S1].
*   $\lambda_2$: Coefficient for structural similarity. Typical value: $0.5$ [S1].
*   $\lambda_3$: Coefficient for gradient consistency. Typical value: $0.15$ [S1].
*   $\lambda_4$: Coefficient for chroma consistency. Typical value: $0.05$ [S1].
*   $\lambda_5$: Coefficient for Total Variation regularization. Typical value: $0.05$ [S1].
*   $\epsilon$: Small constant for Charbonnier loss stability. Not given in the sources [S1].
*   $\sigma$: Standard deviation for Gaussian smoothing. Not given in the sources [S1].

```python
import torch
import torch.nn.functional as F

def gaussian_blur(image, sigma):
    """Apply Gaussian blur to an image tensor (B, C, H, W)."""
    kernel_size = int(6 * sigma + 1)
    if kernel_size % 2 == 0:
        kernel_size += 1
    coords = torch.arange(kernel_size, dtype=torch.float32, device=image.device)
    coords -= (kernel_size - 1) / 2.0
    g = torch.exp(-(coords ** 2) / (2 * sigma ** 2))
    g = g / g.sum()
    g_2d = torch.outer(g, g).unsqueeze(0).unsqueeze(0)
    pad = kernel_size // 2
    padded = F.pad(image, (pad, pad, pad, pad), mode='reflect')
    return F.conv2d(padded, g_2d, padding=0)

def charbonnier_loss(x, y, epsilon):
    """Charbonnier loss: sqrt((x-y)^2 + epsilon^2)."""
    diff = x - y
    return torch.mean(torch.sqrt(diff ** 2 + epsilon ** 2))

def compute_ssim(img1, img2, window_size=11):
    """Compute SSIM between two image tensors (B, C, H, W)."""
    C1 = 0.01 ** 2
    C2 = 0.03 ** 2
    mu1 = F.avg_pool2d(img1, window_size, stride=1, padding=window_size // 2)
    mu2 = F.avg_pool2d(img2, window_size, stride=1, padding=window_size // 2)
    mu1_sq = mu1.pow(2)
    mu2_sq = mu2.pow(2)
    mu1_mu2 = mu1 * mu2
    sigma1_sq = F.avg_pool2d(img1.pow(2), window_size, stride=1, padding=window_size // 2) - mu1_sq
    sigma2_sq = F.avg_pool2d(img2.pow(2), window_size, stride=1, padding=window_size // 2) - mu2_sq
    sigma12 = F.avg_pool2d(img1 * img2, window_size, stride=1, padding=window_size // 2) - mu1_mu2
    ssim_map = ((2 * mu1_mu2 + C1) * (2 * sigma12 + C2)) / \
               ((mu1_sq + mu2_sq + C1) * (sigma1_sq + sigma2_sq + C2))
    return torch.mean(ssim_map)

def compute_gradient(image):
    """Compute gradient magnitude using Sobel operators."""
    sobel_x = torch.tensor([[-1, 0, 1], [-2, 0, 2], [-1, 0, 1]], dtype=image.dtype, device=image.device).unsqueeze(0).unsqueeze(0)
    sobel_y = torch.tensor([[-1, -2, -1], [0, 0, 0], [1, 2, 1]], dtype=image.dtype, device=image.device).unsqueeze(0).unsqueeze(0)
    pad = 1
    padded = F.pad(image, (pad, pad, pad, pad), mode='reflect')
    grad_x = F.conv2d(padded, sobel_x, padding=0)
    grad_y = F.conv2d(padded, sobel_y, padding=0)
    return torch.sqrt(grad_x ** 2 + grad_y ** 2 + 1e-6)

def compute_chroma(image):
    """Extract chroma component from RGB image (B, C, H, W)."""
    r, g, b = image[:, 0:1, :, :], image[:, 1:2, :, :], image[:, 2:3, :, :]
    luminance = 0.299 * r + 0.587 * g + 0.114 * b
    gray = torch.cat([luminance, luminance, luminance], dim=1)
    return image - gray

def compute_tv(image):
    """Total Variation regularization."""
    diff_h = image[:, :, :, 1:] - image[:, :, :, :-1]
    diff_v = image[:, :, 1:, :] - image[:, :, :-1, :]
    return torch.mean(torch.abs(diff_h)) + torch.mean(torch.abs(diff_v))

def joint_loss(output, input, alpha, lambda1, lambda2, lambda3, lambda4, lambda5, sigma, epsilon):
    """Compute the Joint Loss for 3DGS Denoising."""
    output_blur = gaussian_blur(output, sigma)
    input_blur = gaussian_blur(input, sigma)
    L_coarse = charbonnier_loss(output_blur, input_blur, epsilon)

    L_pixel = charbonnier_loss(output, input, epsilon)
    ssim_val = compute_ssim(output, input)
    L_ssim = 1.0 - ssim_val

    grad_out = compute_gradient(output)
    grad_in = compute_gradient(input)
    L_grad = torch.mean(torch.abs(grad_out - grad_in))

    chroma_out = compute_chroma(output)
    chroma_in = compute_chroma(input)
    L_chroma = torch.mean(torch.abs(chroma_out - chroma_in))

    L_tv = compute_tv(output)

    L_fine = (lambda1 * L_pixel + lambda2 * L_ssim + lambda3 * L_grad + lambda4 * L_chroma + lambda5 * L_tv)
    L_total = alpha * L_coarse + (1 - alpha) * L_fine
    return L_total
```

### Edge Cases and Pitfalls
*   **Over-reliance on single terms:** Over-weighting a single loss term may cause loss of detail or color shift [S1]. Coefficients must be numerically balanced to trade off sharpness and stability [S1].
*   **Viewpoint Selection in High-Frequency Scenes:** In scenes with rich high-frequency textures (e.g., fern leaves), selecting viewpoints based on maximum Laplacian variance (sharpness) may cause local textures to become too abrupt [S1]. This negatively affects SSIM and LPIPS scores, as sharpness does not necessarily equate to structural consistency [S1].
*   **Over-sharpening:** The Total Variation (TV) regularizer is crucial to limit high-frequency oscillation without over-weakening true edges, suppressing noise reappearance when combined with the pixel-level robust distance [S1].

## Operating characteristics
*   **Time Complexity:** Not given in the sources [S1].
*   **Memory Complexity:** Not given in the sources [S1].
*   **Strengths:** Preserves global structure and tone while enhancing local details [S1]. Robust to outlier noise via Charbonnier loss [S1]. Prevents color shifts and over-sharpening [S1].
*   **Limitations:** Performance depends on the careful tuning of hyperparameters ($\alpha, \lambda_i$) [S1]. May struggle with scenes where high-frequency details are naturally abrupt if viewpoint selection relies on maximum Laplacian variance [S1].
*   **When to use:** When refining denoised 3DGS renderings from sparse views, particularly when structural consistency and texture fidelity are critical [G].
*   **When not to use:** If computational resources are extremely limited and a simpler L1/L2 loss is sufficient, or if the input images are already very clean [G].

## Background
The Joint Loss was proposed in the "Denoise-GS" method, which includes unsupervised denoising with an N2V-UNet, pose-based grouping, and selection of representative viewpoints [S1]. The method was evaluated on the LLFF dataset with 3DGS, Mip-Splatting, Scaffold-GS, and InstantSplat, simulating real imaging degradation by adding Gaussian noise ($\sigma=0.25$) [S1]. The evaluation metrics included PSNR, SSIM, and LPIPS [S1]. The method aims to provide a more robust input source for subsequent denoising and reconstruction by preserving essential geometric variations while reducing noise interference [S1].
