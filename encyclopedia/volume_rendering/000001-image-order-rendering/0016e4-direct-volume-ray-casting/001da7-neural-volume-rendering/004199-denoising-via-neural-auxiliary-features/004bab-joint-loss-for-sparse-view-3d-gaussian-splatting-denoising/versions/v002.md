# Joint Loss for Sparse-View 3D Gaussian Splatting Denoising

Also called: Composite Perceptual Loss, Denoise-GS Joint Loss

## Overview
The Joint Loss is a composite objective function used in the second round of training to refine denoised images generated by 3D Gaussian Splatting (3DGS) from sparse views. It balances low-frequency agreement with high-frequency fidelity to enhance detail sharpness and texture fidelity while preserving structural consistency [S1]. It sets itself apart from simple pixel-wise losses by explicitly separating coarse tone preservation from fine detail restoration, using specific terms for gradient, chroma, and total variation to prevent over-sharpening and color shifts [S1].

## How it works
The method operates during the refinement stage of a two-round training process. The first round typically produces a coarse denoised image (e.g., via an N2V-UNet [S1]), and the Joint Loss is applied in the second round to fine-tune the output.

### Inputs and Outputs
*   **Input ($x$):** The noisy or coarsely denoised rendered image from the current viewpoint.
*   **Output ($\hat{x}$):** The refined, denoised image predicted by the neural network parameters $\theta$.
*   **Ground Truth ($y$):** Not directly used in the loss formulation described; the loss compares the network's output $\hat{x}$ against the input $x$ (which acts as the supervision signal in this self-supervised or semi-supervised context, or potentially against clean images if supervised, though the text emphasizes refining the "first round denoised images" [S1]). *Note: The formula defines $L_{fine}$ as $\rho(\hat{x}-x)$, implying the target for the "detail" term is the input image itself, assuming the input contains the structural truth but with noise, or that the network is learning to map noise to clean while keeping structure. However, standard denoising usually compares $\hat{x}$ to a clean $y$. The text states: "The objective of the second round is to refine the first round denoised images... compares the input and the output after smoothing." This implies $x$ is the input to the refinement network (noisy/coarse) and $\hat{x}$ is the refined output. The loss minimizes the difference between $\hat{x}$ and $x$ in a structured way.*

### Data Structures
No specific complex data structures are defined for the loss itself. It operates on image tensors of shape $H \times W \times C$ (Height, Width, Channels).

### Parameters
*   $\alpha$: Weight for low-frequency consistency loss. Typical value: $0.35$ [S1].
*   $\lambda_1$: Coefficient for overall pixel fidelity (robust distance). Typical value: $0.25$ [S1].
*   $\lambda_2$: Coefficient for structural similarity. Typical value: $0.5$ [S1].
*   $\lambda_3$: Coefficient for gradient consistency. Typical value: $0.15$ [S1].
*   $\lambda_4$: Coefficient for chroma consistency. Typical value: $0.05$ [S1].
*   $\lambda_5$: Coefficient for Total Variation regularization. Typical value: $0.05$ [S1].
*   $\epsilon$: Small constant for Charbonnier loss stability. Not given in the sources.
*   $\sigma$: Standard deviation for Gaussian smoothing. Not given in the sources.

### Formulas
The total loss $L(\theta)$ is a weighted sum of a coarse loss $L_{coarse}$ and a fine loss $L_{fine}$ [S1]:

$$
L(\theta) = \alpha L_{coarse}(\theta) + (1-\alpha) L_{fine}(\theta)
$$

**1. Low-Frequency Consistency Loss ($L_{coarse}$)**
This term compares the input and output after Gaussian smoothing to preserve tone and large-scale structure [S1]:

$$
L_{coarse} = \frac{1}{|\Omega|} \sum_{p \in \Omega} \rho(G_{\sigma}(\hat{x})(p) - G_{\sigma}(x)(p))
$$

Where:
*   $\Omega$ is the pixel domain.
*   $G_{\sigma}$ is Gaussian smoothing with standard deviation $\sigma$.
*   $\rho(\delta) = \sqrt{\delta^2 + \epsilon^2}$ is the Charbonnier loss [S1].

**2. Detail Consistency Loss ($L_{fine}$)**
This term preserves edges, textures, and color consistency while avoiding over-sharpening [S1]:

$$
L_{fine} = \lambda_1 \rho(\hat{x} - x) + \lambda_2 (1 - SSIM(\hat{x}, f_x)) + \lambda_3 \|\nabla \hat{x} - \nabla x\| + \lambda_4 \|Chr(\hat{x}) - Chr(x)\| + \lambda_5 TV(\hat{x})
$$

Where:
*   $\rho(\hat{x} - x)$ is the pixel-level robust distance (Charbonnier loss) [S1].
*   $SSIM(\hat{x}, f_x)$ is the Structural Similarity Index Measure between the output and the input (or a filtered version $f_x$, though the text implies $x$) [S1, S42]. *Note: The source notation $f_x$ is ambiguous; standard SSIM compares two images. Given the context "structural agreement", it likely compares $\hat{x}$ and $x$.*
*   $\nabla$ denotes the image gradient operator [S1].
*   $Chr(\cdot)$ denotes the chroma component of the image [S1].
*   $TV(\hat{x})$ is the Total Variation of the output image [S1].

```python
import torch.nn.functional as F

def gaussian_blur(image, sigma=1.0):
    """Apply Gaussian blur to an image tensor."""
    # Assuming image is (B, C, H, W)
    kernel_size = int(6 * sigma + 1)
    if kernel_size % 2 == 0:
        kernel_size += 1

    # Create Gaussian kernel

    # For brevity, we assume a helper exists or use F.gaussian_blur if available.
    # Here we use a simplified approximation or standard library call if allowed.
    # Since we cannot call external libs, we define a simple separable blur or use F.conv2d with a generated kernel.
    # Generating Gaussian kernel:
    coords = torch.arange(kernel_size, dtype=torch.float32)
    coords -= (kernel_size - 1) / 2.0
    g = torch.exp(-(coords ** 2) / (2 * sigma ** 2))
    g = g / g.sum()
    g_2d = torch.outer(g, g).unsqueeze(0).unsqueeze(0)
    # Pad image
    pad = kernel_size // 2
    padded_image = F.pad(image, (pad, pad, pad, pad), mode='reflect')
    blurred = F.conv2d(padded_image, g_2d, padding=0)
    return blurred

def charbonnier_loss(x, y, epsilon=1e-3):
    """Charbonnier loss: sqrt((x-y)^2 + epsilon^2)"""
    diff = x - y
    return torch.mean(torch.sqrt(diff ** 2 + epsilon ** 2))

    mu1_sq = mu1.pow(2)
    mu2_sq = mu2.pow(2)
    mu1_mu2 = mu1 * mu2
    
    sigma1_sq = F.avg_pool2d(img1.pow(2), window_size, stride=1, padding=window_size//2) - mu1_sq
    sigma2_sq = F.avg_pool2d(img2.pow(2), window_size, stride=1, padding=window_size//2) - mu2_sq
    sigma12 = F.avg_pool2d(img1 * img2, window_size, stride=1, padding=window_size//2) - mu1_mu2

    if size_average:

def compute_gradient(image):
    """Compute gradient magnitude using Sobel operators."""
    # Sobel kernels
    sobel_x = torch.tensor([[-1, 0, 1], [-2, 0, 2], [-1, 0, 1]], dtype=image.dtype, device=image.device).unsqueeze(0).unsqueeze(0)
    sobel_y = torch.tensor([[-1, -2, -1], [0, 0, 0], [1, 2, 1]], dtype=image.dtype, device=image.device).unsqueeze(0).unsqueeze(0)
    
    # Pad image
    pad = 1
    padded = F.pad(image, (pad, pad, pad, pad), mode='reflect')
    
    grad_x = F.conv2d(padded, sobel_x, padding=0)
    grad_y = F.conv2d(padded, sobel_y, padding=0)
    
    # Magnitude
    return torch.sqrt(grad_x ** 2 + grad_y ** 2 + 1e-6)

def compute_chroma(image):
    """Extract chroma (color) component. Assuming RGB input."""
    # Convert RGB to YCbCr or similar to extract chroma.
    # Simplified: subtract luminance.
    # Luminance approximation: 0.299 R + 0.587 G + 0.114 B
    r, g, b = image[:, 0:1, :, :], image[:, 1:2, :, :], image[:, 2:3, :, :]
    luminance = 0.299 * r + 0.587 * g + 0.114 * b
    # Chroma can be defined as the difference from luminance or Cb/Cr components.
    # The text says "chroma consistency". We'll use the difference from gray.
    gray = torch.cat([luminance, luminance, luminance], dim=1)
    return image - gray

def compute_tv(image):
    """Total Variation regularization."""
    diff_h = image[:, :, :, 1:] - image[:, :, :, :-1]
    diff_v = image[:, :, 1:, :] - image[:, :, :-1, :]
    return torch.mean(torch.abs(diff_h)) + torch.mean(torch.abs(diff_v))

def joint_loss(output, input, alpha=0.35, lambda1=0.25, lambda2=0.5, lambda3=0.15, lambda4=0.05, lambda5=0.05, sigma=1.0, epsilon=1e-3):
    """
    Compute the Joint Loss for 3DGS Denoising.
    
    Args:
        output (Tensor): Refined image $\hat{x}$ (B, C, H, W)
        input (Tensor): Input image $x$ (B, C, H, W)
        alpha: Weight for coarse loss
        lambda1..5: Weights for fine loss components
        sigma: Gaussian blur sigma
        epsilon: Charbonnier epsilon
        
    Returns:
        Tensor: Scalar loss value
    """
    # 1. Coarse Loss
    output_blur = gaussian_blur(output, sigma)
    input_blur = gaussian_blur(input, sigma)
    L_coarse = charbonnier_loss(output_blur, input_blur, epsilon)
    
    # 2. Fine Loss
    # Pixel-level robust distance
    L_pixel = charbonnier_loss(output, input, epsilon)
    
    # Structural Similarity (SSIM)
    # SSIM returns a value between -1 and 1, usually close to 1 for similar images.
    # The loss term is (1 - SSIM).
    ssim_val = compute_ssim(output, input)
    L_ssim = 1.0 - ssim_val
    
    # Gradient Consistency
    grad_out = compute_gradient(output)
    grad_in = compute_gradient(input)
    L_grad = torch.mean(torch.abs(grad_out - grad_in))
    
    # Chroma Consistency
    chroma_out = compute_chroma(output)
    chroma_in = compute_chroma(input)
    L_chroma = torch.mean(torch.abs(chroma_out - chroma_in))
    
    # Total Variation
    L_tv = compute_tv(output)
    
    L_fine = (lambda1 * L_pixel + 
              lambda2 * L_ssim + 
              lambda3 * L_grad + 
              lambda4 * L_chroma + 
              lambda5 * L_tv)
              
    # Total Loss
    L_total = alpha * L_coarse + (1 - alpha) * L_fine
    
    return L_total
```

### Edge Cases and Pitfalls
*   **Over-reliance on single terms:** Over-weighting a single loss term may cause loss of detail or color shift. Coefficients must be numerically balanced to trade off sharpness and stability [S1].
*   **Viewpoint Selection in High-Frequency Scenes:** In scenes with rich high-frequency textures (e.g., fern leaves), selecting viewpoints based on maximum Laplacian variance (sharpness) may cause local textures to become too abrupt. This negatively affects SSIM and LPIPS scores, as sharpness does not necessarily equate to structural consistency [S1].
*   **Over-sharpening:** The Total Variation (TV) regularizer is crucial to limit high-frequency oscillation without over-weakening true edges, suppressing noise reappearance when combined with the pixel-level robust distance [S1].

## Operating characteristics
*   **Time Complexity:** The loss computation involves Gaussian smoothing, SSIM calculation, gradient computation, and TV regularization. These are all $O(H \times W)$ operations per image. The SSIM calculation involves local window operations, making it slightly more expensive but still linear with respect to the number of pixels.
*   **Memory Complexity:** Requires storing the input, output, and intermediate buffers (blurred images, gradients, chroma components). Memory usage is proportional to the image resolution.
*   **Strengths:** Preserves global structure and tone while enhancing local details. Robust to outlier noise via Charbonnier loss. Prevents color shifts and over-sharpening.
*   **Limitations:** Performance depends on the careful tuning of hyperparameters ($\alpha, \lambda_i$). May struggle with scenes where high-frequency details are naturally abrupt (e.g., ferns) if viewpoint selection is not robust.
*   **When to use:** When refining denoised 3DGS renderings from sparse views, particularly when structural consistency and texture fidelity are critical.
*   **When not to use:** If computational resources are extremely limited and a simpler L1/L2 loss is sufficient, or if the input images are already very clean.

## Background
The Joint Loss was proposed in the "Denoise-GS" method, which includes unsupervised denoising with an N2V-UNet, pose-based grouping, and selection of representative viewpoints [S1]. The method was evaluated on the LLFF dataset with 3DGS, Mip-Splatting, Scaffold-GS, and InstantSplat, simulating real imaging degradation by adding Gaussian noise ($\sigma=0.25$) [S1]. The evaluation metrics included PSNR, SSIM, and LPIPS [S1]. The method aims to provide a more robust input source for subsequent denoising and reconstruction by preserving essential geometric variations while reducing noise interference [S1].
