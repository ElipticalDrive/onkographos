# MLP Model (Density Baseline)
Also called: positional encoder + MLP

## Overview
A baseline neural volume representation that maps 3D Cartesian positions to density using a Multi-Layer Perceptron (MLP) with explicit positional encoding [S1, unofficial]. It serves as a reference for density reconstruction capabilities in neural tomography, distinct from hash-grid or latent-feature approaches [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** A 3D Cartesian position vector $\mathbf{x} \in \mathbb{R}^3$, mapped to an Axis-Aligned Bounding Box (AABB) [S1, unofficial].
- **Output:** A single scalar representing the base-10 logarithm of the number density, $\log_{10} n_e$ [S1, unofficial].

**Data Structures and Layout:**
The input to the MLP is a concatenated vector of dimension 48, formed by:
1. **Raw Position:** 3 dimensions [S1, unofficial].
2. **Fourier Positional Encoding:** Axis-wise Fourier features with $L=6$ bands, frequencies $2^0, \dots, 2^5$. For each axis, this generates $\sin(2^k \pi x)$ and $\cos(2^k \pi x)$ for $k \in \{0, \dots, 5\}$, totaling $2 \times 3 \times 6 = 36$ dimensions [S1, unofficial].
3. **Spherical Harmonic Encoding:** Degree 2 real spherical harmonics of the unit direction $\hat{\mathbf{x}}$, totaling $(2+1)^2 = 9$ dimensions [S1, unofficial].

**MLP Architecture:**
- **Hidden Layers:** 4 layers, each with width 256 [S1, unofficial].
- **Activation:** SiLU (Sigmoid Linear Unit) for hidden layers [S1, unofficial].
- **Output Layer:** Linear layer producing a single scalar [S1, unofficial].
- **Initialization:** The final layer bias is initialized to the midpoint of the configured $\log_{10} n_e$ clamp range [S1, unofficial].
- **Total Parameters:** 210,177 [S1, unofficial].

**Step-by-Step Method:**
1. Map the input 3D position $\mathbf{x}$ to the AABB [S1, unofficial].
2. Compute the Fourier positional encoding $\mathbf{f}_{\text{fourier}}(\mathbf{x})$ using the specified frequencies and axes [S1, unofficial].
3. Compute the spherical harmonic encoding $\mathbf{f}_{\text{sh}}(\hat{\mathbf{x}})$ where $\hat{\mathbf{x}}$ is the normalized direction of $\mathbf{x}$ [G].
4. Concatenate the raw position, Fourier encoding, and SH encoding: $\mathbf{v} = [\mathbf{x}, \mathbf{f}_{\text{fourier}}(\mathbf{x}), \mathbf{f}_{\text{sh}}(\hat{\mathbf{x}})]$ [S1, unofficial].
5. Pass $\mathbf{v}$ through the MLP to produce the output scalar:
   $$ \mathbf{h}_1 = \text{SiLU}(\mathbf{W}_1 \mathbf{v} + \mathbf{b}_1) $$
   $$ \mathbf{h}_2 = \text{SiLU}(\mathbf{W}_2 \mathbf{h}_1 + \mathbf{b}_2) $$
   $$ \mathbf{h}_3 = \text{SiLU}(\mathbf{W}_3 \mathbf{h}_2 + \mathbf{b}_3) $$
   $$ \mathbf{h}_4 = \text{SiLU}(\mathbf{W}_4 \mathbf{h}_3 + \mathbf{b}_4) $$
   $$ \log_{10} n_e = \mathbf{w}_5 \cdot \mathbf{h}_4 + b_5 $$
   [S1, unofficial]

**Pseudocode:**
```python
import math
import numpy as np

def fourier_encoding(x, num_bands=6):
    """
    Computes axis-wise Fourier positional encoding.
    x: (3,) array
    Returns: (36,) array
    """
    freqs = np.array([2**k for k in range(num_bands)])
    args = 2.0 * math.pi * np.outer(freqs, x)
    sin_vals = np.sin(args).flatten()
    cos_vals = np.cos(args).flatten()
    return np.concatenate([sin_vals, cos_vals])

def spherical_harmonic_degree_2(x):
    """
    Computes degree 2 real spherical harmonics for the direction of x.
    x: (3,) array
    Returns: (9,) array
    """
    norm = np.linalg.norm(x)
    if norm == 0:
        return np.zeros(9)
    d = x / norm
    x, y, z = d[0], d[1], d[2]
    
    y00 = 0.5 * math.sqrt(1.0 / math.pi)
    y1m1 = math.sqrt(3.0 / (4.0 * math.pi)) * y
    y10 = math.sqrt(3.0 / (4.0 * math.pi)) * z
    y11 = math.sqrt(3.0 / (4.0 * math.pi)) * x
    
    y2m2 = math.sqrt(15.0 / math.pi) * x * y
    y2m1 = math.sqrt(15.0 / math.pi) * y * z
    y20 = math.sqrt(5.0 / (16.0 * math.pi)) * (3 * z**2 - 1)
    y21 = math.sqrt(15.0 / math.pi) * z * x
    y22 = math.sqrt(15.0 / math.pi) * (x**2 - y**2)
    
    return np.array([y00, y1m1, y10, y11, y2m2, y2m1, y20, y21, y22])

def mlp_model_forward(x, weights, biases):
    """
    Forward pass of the MLP baseline.
    x: (3,) raw position
    weights: list of 5 weight matrices [W1, W2, W3, W4, W5]
    biases: list of 5 bias vectors [b1, b2, b3, b4, b5]
    Returns: scalar log10_ne
    """
    raw_pos = x
    fourier_feat = fourier_encoding(x)
    sh_feat = spherical_harmonic_degree_2(x)
    
    input_vec = np.concatenate([raw_pos, fourier_feat, sh_feat])
    
    h = input_vec
    for i in range(4):
        h = np.dot(h, weights[i]) + biases[i]
        h = h * np.exp(h) / (1.0 + np.exp(h))  # SiLU activation [G]
        
    log10_ne = np.dot(h, weights[4]) + biases[4]
    return log10_ne
```

**Parameters:**
- Fourier bands $L=6$ [S1, unofficial].
- MLP hidden width: 256 [S1, unofficial].
- MLP hidden layers: 4 [S1, unofficial].
- Final layer bias initialization: Midpoint of $\log_{10} n_e$ clamp range [S1, unofficial].

**Edge Cases and Pitfalls:**
- Division by zero in spherical harmonic calculation if $\mathbf{x} = \mathbf{0}$ [G].

## Subtopics

### HeadGaS Baseline (Direct Input MLP)
A variant where the expression vector $e_i$ and encoded position $\boldsymbol{\mu}$ are fed directly into an MLP $\boldsymbol{\rho}(\boldsymbol{\mu})$ to predict color and opacity, without a basis of latent features [S2]. It uses 5 linear layers with leaky ReLU activations [S2]. On the INSTA dataset with 295k Gaussians, it achieves 32.08 PSNR with 0.010s rendering time [S2]. It is slower than the proposed HeadGaS method despite lacking MLP computation during rendering, due to the significantly larger number of Gaussians (295k vs 28k) [S2].

## Operating characteristics
- **Complexity:** The model contains 210,177 trainable parameters [S1, unofficial]. Evaluation time scales linearly with query frequency and is independent of scene complexity [G].
- **Performance:** On the INSTA dataset, the HeadGaS Baseline (295k Gaussians) renders in 0.010s, compared to 0.004s for the proposed HeadGaS method (28k Gaussians) [S2].
- **Strengths:** Simple architecture with explicit frequency control via positional encoding [S1, unofficial].
- **Limitations:** High parameter count relative to simple density functions; requires careful bias initialization [S1, unofficial].

## Background
Originated as a baseline in neural tomography research to evaluate density reconstruction capabilities using positional encoders and MLPs [S1, unofficial]. It contrasts with more complex representations like multiresolution hash grids [S1, unofficial].
