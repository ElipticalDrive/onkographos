# CNN Post-Processing Network
Also called: Lightweight CNN
## Overview
A post-processing convolutional neural network applied to MLP-decoded results to reduce boundary artifacts [S1]. It sets itself apart from its siblings by operating as a shallow, feed-forward refinement layer that leverages neighboring pixel information to improve texture detail without introducing multiview inconsistency, unlike [Field Output Prediction](4830-field-output-prediction.md) which predicts field values directly, or [Sigma Network Layer](6256-sigma-network-layer.md) which focuses on density estimation [S2].
## How it works
**Inputs and Outputs:**
- Input: The rendered image (or feature map) produced by the MLP-decoded volumetric representation.
- Output: The refined RGB image with reduced boundary artifacts and enhanced texture detail [S1, S2].

**Data Structures:**
- The network consists of a stack of convolutional layers.
- For the boundary artifact mitigation variant: 5 convolution layers, each with 32 channels [S1].
- For the general refinement variant: 3 convolution layers with 3x3 kernels and ReLU activations [S2].
- Final layer: A feed-forward perceptron (fully connected layer) mapping feature space to RGB space [S2].

**Steps:**
1. **Convolutional Processing:**
   - Apply convolutional layers to the input image.
   - Use "reflectance" padding for the inputs of each convolution [S2].
   - Remove padding values in the outputs to prevent checkerboard artifacts [S2].
   - No skip connections are added in the 5-layer variant [S1].
2. **Feature-to-RGB Conversion:**
   - Pass the final feature map through a feed-forward perceptron layer to produce the RGB output [S2].
3. **Training (if applicable):**
   - Compute the loss as the Mean Squared Error (MSE) between the MLP-decoded results and the ground-truth (GT) volume [S1].
   - Alternatively, for alignment-aware training, use a loss function $L_{PM}(G, R) = \min_i (D(G_i, R)) + \lambda \cdot \text{EuclideanDistance}(G, R)$, where $G$ is the ground truth patch, $R$ is the rendered patch, and $G_i$ are subpatches of $G$ [S2].
4. **Quantization (Boundary Artifact Variant):**
   - Apply quantization with 9 bits at the end of CNN training without subsequent fine-tuning [S1].

**Parameters:**
- Convolution kernel size: 3x3 [S2].
- Number of channels: 32 [S1].
- Number of layers: 5 [S1] or 3 [S2].
- Quantization precision: 9 bits [S1].
- Padding: Reflectance [S2].

**Edge Cases and Pitfalls:**
- **Checkerboard Artifacts:** Prevented by removing padding values in the outputs [S2].
- **Multiview Inconsistency:** Avoided because the CNN is very shallow and performs no upsampling [S2].
- **Artifact Removal Limit:** Limited capacity does not guarantee removal of boundary artifacts when distortion is significant; remaining artifacts may still negatively impact rendering quality [S1].
- **Training Overhead:** Adds approximately 5 minutes to encoding time and 100 KB to model size [S1].
- **Decoding Overhead:** Adds approximately 50 seconds to decoding time due to sequential inference [S1].

## Subtopics

### Boundary Artifact Mitigation
A technique where a lightweight CNN (5 layers, 32 channels each) is applied to the output of the finest scale MLPs to mitigate rendering artifacts caused by inconsistent outputs between adjacent disjoint volumetric blocks along their boundaries. It sets itself apart by specifically targeting block-boundary discontinuities in multiscale volumetric representations, using MSE loss against ground-truth volume and 9-bit quantization without fine-tuning. Choose this when dealing with block-based neural representations that exhibit visible seams. ## Operating characteristics
- **Time Complexity:** Decoding adds approximately 50 seconds of sequential inference time [S1].
- **Memory Complexity:** Adds approximately 100 KB to the model size [S1].
- **Performance:** Despite the added sequential inference time, decoding remains significantly faster than neurcomp [S1].
- **Strengths:** Reduces boundary artifacts, improves texture detail, avoids multiview inconsistency, prevents checkerboard artifacts [S1, S2].
- **Limitations:** Limited capacity does not guarantee removal of all boundary artifacts when distortion is significant [S1]. Training and inference performance lags significantly behind traditional compressors like SZ3 and TTHRESH [S1].
- **When to Use:** When using MLP-based volumetric representations with block-based encoding and boundary artifacts are visible [S1]. When high-fidelity neural radiance fields require consistent texture across viewpoints [S2].
- **When Not to Use:** When real-time performance is critical and the overhead of sequential inference is unacceptable [S1]. When distortion is significant and artifact removal is critical [S1].

## Background
Originated in the context of efficient compressive neural representations for time-varying volumetric datasets (ECNR) [S1] and high-fidelity neural radiance fields (AligNeRF) [S2]. ECNR was presented in 2024, advocating for multiple small MLPs to encode local blocks in a multiscale fashion [S1]. AligNeRF was presented in 2023, focusing on alignment-aware training for high-fidelity rendering [S2].
