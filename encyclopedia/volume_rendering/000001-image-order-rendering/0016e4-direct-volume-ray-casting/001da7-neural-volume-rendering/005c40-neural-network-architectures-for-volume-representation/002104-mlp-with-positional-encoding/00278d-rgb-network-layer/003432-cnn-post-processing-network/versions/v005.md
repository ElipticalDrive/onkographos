# CNN Post-Processing Network

Also called: Lightweight CNN

## Overview
A post-processing convolutional neural network applied to MLP-decoded results to reduce boundary artifacts [S1, S2]. It sets itself apart from its sibling [Field Output Prediction](4830-field-output-prediction.md) by operating on the final rendered image or feature maps rather than predicting field values directly, and from [Sigma Network Layer](6256-sigma-network-layer.md) by focusing on spatial texture refinement and artifact mitigation rather than density estimation [S1, S2].

## How it works
**Inputs and Outputs:**
*   **Input:** The output from the finest-scale MLPs (RGB values or feature maps) [S1, S2].
*   **Output:** Refined RGB image with reduced boundary artifacts [S1, S2].

**Data Structures:**
*   **CNN Architecture:** A shallow convolutional network. Specific implementations vary:
    *   *ECNR variant:* Five convolution layers, each with 32 channels. No skip connections [S1].
    *   *AligNeRF variant:* 3-layer convolutional network with ReLU activations and 3×3 kernels [S2].
    *   *VoxGRAF variant:* 2 hidden layers of dimension 16 and kernel size 3 [S3].

**Steps:**
1.  **Input Padding:** Apply "reflectance" padding to the input features to handle boundary conditions [S2].
2.  **Convolution:** Pass the padded input through the convolutional layers.
    *   For the ECNR variant, apply five convolutions with 32 channels [S1].
    *   For the AligNeRF variant, apply three convolutions with 3×3 kernels [S2].
    *   For the VoxGRAF variant, apply two hidden layers with dimension 16 and kernel size 3 [S3].
3.  **Output Trimming:** Remove the padding values from the outputs to prevent checkerboard artifacts [S2].
4.  **Feature-to-RGB Conversion:** Use a feed-forward perceptron layer to convert the representation from feature space to RGB space [S2].
5.  **Training (Optional):** Train the CNN using a loss function defined as the Mean Squared Error (MSE) between the MLP-decoded results and the ground-truth (GT) volume [S1].
6.  **Quantization (Optional):** Apply quantization with 9 bits without subsequent fine-tuning to reduce model size [S1].

**Formulas:**
*   **Loss Function (ECNR):**
    $$ L = \text{MSE}(R_{MLP}, V_{GT}) $$
    Where $R_{MLP}$ is the MLP-decoded result and $V_{GT}$ is the ground-truth volume [S1].

**Parameters:**
*   **ECNR:** 5 convolution layers, 32 channels per layer, 9-bit quantization [S1].
*   **AligNeRF:** 3 convolution layers, 3×3 kernels, ReLU activation [S2].
*   **VoxGRAF:** 2 hidden layers, dimension 16, kernel size 3, alias-free layers with critical sampling [S3].

**Edge Cases and Pitfalls:**
*   **Boundary Artifacts:** Limited capacity does not guarantee removal of boundary artifacts when distortion is significant; remaining artifacts may still negatively impact rendering quality [S1].
*   **Checkerboard Artifacts:** Prevented by removing padding values in the outputs [S2].
*   **Multiview Inconsistency:** Avoided because the CNN is very shallow and performs no upsampling [S2].

**Pseudocode:**
```python
def cnn_post_processing(input_features, architecture='ecnr'):
    """
    Applies CNN post-processing to MLP-decoded results.
    
    Args:
        input_features: Tensor of shape (H, W, C) or (B, H, W, C) from MLP.
        architecture: String specifying the CNN variant ('ecnr', 'alignerf', 'voxgraf').
        
    Returns:
        Refined RGB tensor.
    """
    if architecture == 'ecnr':
        # ECNR: 5 conv layers, 32 channels, no skip connections
        x = reflectance_pad(input_features)
        for i in range(5):
            x = conv2d(x, filters=32, kernel_size=3, stride=1, padding='valid')
            x = relu(x)
        # No quantization in inference, only during training/storage
        return x
        
    elif architecture == 'alignerf':
        # AligNeRF: 3 conv layers, 3x3 kernels, ReLU, then perceptron
        x = reflectance_pad(input_features)
        for i in range(3):
            x = conv2d(x, filters=32, kernel_size=3, stride=1, padding='valid')
            x = relu(x)
        # Remove padding values to prevent checkerboard artifacts
        x = trim_padding(x)
        # Convert feature space to RGB space
        rgb = perceptron_layer(x)
        return rgb
        
    elif architecture == 'voxgraf':
        # VoxGRAF: 2 hidden layers, dim 16, kernel 3, alias-free
        x = reflectance_pad(input_features)
        for i in range(2):
            x = alias_free_conv2d(x, filters=16, kernel_size=3, stride=1, padding='valid')
            x = relu(x)
        # Final layer to RGB
        rgb = conv2d(x, filters=3, kernel_size=1, stride=1, padding='valid')
        return rgb
        
    else:
        raise ValueError("Unknown architecture")

def reflectance_pad(tensor):
    """Applies reflectance padding to handle boundaries."""
    # Implementation depends on framework, typically replicates boundary values
    return pad(tensor, mode='reflect')

def trim_padding(tensor):
    """Removes padding values from the output."""
    # Assuming padding was 1 pixel on each side
    return tensor[:, 1:-1, 1:-1, :]

def alias_free_conv2d(tensor, filters, kernel_size, stride, padding):
    """Applies alias-free convolution with critical sampling."""
    # Upsample, convolve, downsample to prevent texture sticking
    # Simplified: standard conv for pseudocode clarity, 
    # but note that alias-free layers use specific upsampling/downsampling
    return conv2d(tensor, filters, kernel_size, stride, padding)

def perceptron_layer(tensor):
    """Converts feature space to RGB space."""
    # Flatten, dense layer to 3 channels
    flat = flatten(tensor)
    rgb = dense(flat, units=3)
    return reshape(rgb, tensor.shape[:-1] + (3,))
```

## Subtopics

### [Supplementary Feature Input for Super-Resolution](7251-supplementary-feature-input-for-super-resolution.md)
A technique where the super-resolution network accepts multiple feature maps alongside the low-resolution color image to improve reconstruction quality, specifically adapted for volumetric rendering. It sets itself apart from standard image super-resolution by incorporating volumetric-specific auxiliary data (depth, color-opacity vectors) to resolve ambiguities inherent in volume rendering, such as undefined depth in transparent regions.

### 2D Refinement Layers
An optional shallow 2D CNN applied to refine the rendered image, using alias-free layers to prevent texture sticking under viewpoint changes [S3]. It sets itself apart by using alias-free layers with critical sampling to maintain consistency across viewpoints [S3]. Choose this when rendering dynamic scenes with viewpoint changes where texture aliasing is a concern [S3].

### Boundary Artifact Mitigation
Mitigates rendering artifacts caused by inconsistent outputs between adjacent disjoint volumetric blocks along their boundaries [S1]. It sets itself apart by specifically targeting block-boundary discontinuities in multiscale representations [S1]. Choose this when using block-based MLP encoding (like ECNR) where boundary artifacts are prominent [S1].

## Operating characteristics
**Time and Memory Complexity:**
*   **Encoding Overhead:** Adds approximately 5 minutes to encoding time and 100 KB to model size [S1].
*   **Decoding Overhead:** Adds approximately 50 seconds to decoding time due to sequential inference [S1].
*   **Memory:** The CNN parameter size is small (e.g., 100 KB for the ECNR variant) [S1].

**Measured Performance:**
*   Despite the added sequential inference time, decoding remains significantly faster than neurcomp [S1].
*   The CNN yields the best result with the same model size compared to other methods like MINER+ [S1].

**Strengths and Limitations:**
*   **Strengths:** Reduces boundary artifacts effectively; avoids multiview inconsistency due to shallow depth and lack of upsampling [S1, S2].
*   **Limitations:** Limited capacity does not guarantee removal of boundary artifacts when distortion is significant; training overhead is non-negligible [S1].

**When to Use:**
*   Use when boundary artifacts from block-based MLP encoding are visually distracting and performance constraints allow for sequential CNN inference [S1].
*   Use when multiview consistency is critical and upsampling artifacts must be avoided [S2].

**When Not to Use:**
*   Do not use when real-time performance is critical and the overhead of sequential inference is unacceptable [S1].
*   Do not use when distortion is significant, as the CNN may not fully remove artifacts [S1].

## Background
Originated in the context of efficient compressive neural representations for time-varying volumetric datasets, specifically in the ECNR method [S1]. It was developed to address the issue of inconsistent outputs between adjacent blocks in multiscale spatiotemporal representations [S1]. The technique has been adapted in various forms for different neural rendering tasks, such as AligNeRF for high-fidelity radiance fields [S2] and VoxGRAF for fast 3D-aware image synthesis [S3].
