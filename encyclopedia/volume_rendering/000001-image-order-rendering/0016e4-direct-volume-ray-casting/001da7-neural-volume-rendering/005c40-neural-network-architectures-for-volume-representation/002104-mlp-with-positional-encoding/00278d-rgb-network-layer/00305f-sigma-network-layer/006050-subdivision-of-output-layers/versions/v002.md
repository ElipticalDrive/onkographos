# Subdivision of Output Layers

Also called: Subdiv output layers

## Overview
Subdivision of Output Layers is a reparameterization technique in neural volume rendering that increases the number of depth samples during training without altering the final rendered color of existing rays [S1, unofficial]. It modifies the last layer of each subnetwork by duplicating and rearranging weight and bias tensors, ensuring the network's output remains consistent with the previous resolution [S1, unofficial]. This method is distinct from Subdivision of Input Layers, which preserves input ray colors by modifying the first and last layers to handle increased input dimensionality [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Original weight tensor $W_{org}$ of shape $[n_{subnetworks}, d_{out}, d_{in}]$ and bias tensor $B_{org}$ of shape $[n_{subnetworks}, d_{out}]$ [S1, unofficial].
*   **Output:** Modified weight tensor $W_{new}$ and bias tensor $B_{new}$ with shapes $[n_{subnetworks}, 2d_{out}, d_{in}]$ and $[n_{subnetworks}, 2d_{out}]$ respectively, containing reparameterized values [S1, unofficial].

**Data Structures:**
The method operates on tensor layouts where dimensions are explicitly split and concatenated [S1, unofficial].
*   $n_{subnetworks}$: Number of subnetworks [S1, unofficial].
*   $d_{out}$: Original output dimension (number of depth samples/channels) [S1, unofficial].
*   $d_{in}$: Input dimension [S1, unofficial].

**Steps:**
1.  **Bias Rearrangement:** Split the output dimension $d_{out}$ of the bias tensor into $c=4$ channels [S1, unofficial]. The shape $[n_{subnetworks}, d_{out}]$ becomes $[n_{subnetworks}, d_{out}/4, 4]$ [S1, unofficial].
2.  **Bias Duplication:** Concatenate the rearranged bias with itself along the channel dimension (dim=2) [S1, unofficial]. The shape becomes $[n_{subnetworks}, d_{out}/4, 8]$ [S1, unofficial].
3.  **Bias Reshape:** Rearrange the concatenated bias back to a contiguous tensor structure [S1, unofficial]. The shape becomes $[n_{subnetworks}, 2d_{out}]$ [S1, unofficial].
4.  **Weight Rearrangement:** Split the output dimension $d_{out}$ of the weight tensor into $c=2$ channels [S1, unofficial]. The shape $[n_{subnetworks}, d_{out}, d_{in}]$ becomes $[n_{subnetworks}, d_{out}/2, 2, d_{in}]$ [S1, unofficial].
5.  **Weight Duplication:** Concatenate the rearranged weight with itself along the channel dimension (dim=2) [S1, unofficial]. The shape becomes $[n_{subnetworks}, d_{out}/2, 4, d_{in}]$ [S1, unofficial].
6.  **Weight Reshape:** Rearrange the concatenated weight back to a contiguous tensor structure [S1, unofficial]. The shape becomes $[n_{subnetworks}, 2d_{out}, d_{in}]$ [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def rearrange(tensor, pattern, c=None):
    if pattern == 'n (d c) -> n d c':
        n, d_out = tensor.shape
        d = d_out // c
        return tensor.reshape(n, d, c)
    elif pattern == 'n d c -> n (d c)':
        n, d, c = tensor.shape
        return tensor.reshape(n, d * c)
    elif pattern == 'n (d c) i -> n d c i':
        n, d_out, d_in = tensor.shape
        d = d_out // c
        return tensor.reshape(n, d, c, d_in)
    elif pattern == 'n d c i -> n (d c) i':
        n, d, c, d_in = tensor.shape
        return tensor.reshape(n, d * c, d_in)
    raise ValueError("Unsupported pattern")

def concatenate(tensors, dim):
    return np.concatenate(tensors, axis=dim)

def subdiv_output_layers(org_weight, org_bias):
    bias = rearrange(org_bias, 'n (d c) -> n d c', c=4)
    bias = concatenate([bias, bias], dim=2)
    bias = rearrange(bias, 'n d c -> n (d c)')

    weight = rearrange(org_weight, 'n (d c) i -> n d c i', c=2)
    weight = concatenate([weight, weight], dim=2)
    weight = rearrange(weight, 'n d c i -> n (d c) i')

    return weight, bias
```

**Parameters:**
*   $c=4$ for bias splitting and $c=2$ for weight splitting [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Divisibility:** The original output dimension $d_{out}$ must be divisible by 4 for the bias operation and by 2 for the weight operation [S1, unofficial].
*   **Precision:** The method relies on exact tensor reshaping and concatenation without scaling factors, unlike input subdivision which applies a 0.5 multiplier [S1, unofficial].

## Subtopics

### Subdivision of Input Layers
A reparameterization technique to maintain unchanged input ray colors after depth subdivision by modifying the weight matrices and bias vectors of the first and last layer functions of the networks [S1, unofficial]. It splits the input dimension $d_{in}$ into $c=2$ channels, duplicates the weights along the input dimension, and averages them by multiplying by 0.5 to ensure hidden features remain unaffected [S1, unofficial]. The bias remains unchanged [S1, unofficial]. This construction validates that the color of each input ray is kept unchanged [S1, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
The operation is $O(n_{subnetworks} \cdot d_{out} \cdot d_{in})$ for weights and $O(n_{subnetworks} \cdot d_{out})$ for biases, as it involves tensor rearrangement and concatenation [S1, unofficial]. Memory usage remains constant as the output tensor shapes are identical to the input shapes before subdivision [S1, unofficial].

**Measured Performance:**
Not given in the sources.

**Scaling:**
The method allows for progressive refinement of depth samples ($D_k = D \times 2^k$) during training stages [S1, unofficial]. It scales with the number of subnetworks and the depth resolution [S1, unofficial].

**Strengths and Limitations:**
*   **Strengths:** Ensures consistency of rendered colors when increasing depth resolution, preventing artifacts from sudden changes in sampling density [S1, unofficial].
*   **Limitations:** Requires $d_{out}$ to be divisible by 4 for bias operations [S1, unofficial]. Only applies to the last layer of the subnetworks [S1, unofficial].

**When to use it and when not:**
Use when progressively increasing the number of depth samples in a neural volume rendering pipeline to improve rendering quality without disrupting the learned representation [S1, unofficial]. Do not use if the output dimension is not divisible by 4 or if the goal is to modify input ray properties rather than output depth samples [S1, unofficial].

## Background
Originated in the "Progressively-connected Light Field Network for Efficient View Synthesis" paper (2022) [S1, unofficial]. The technique is part of a broader strategy involving progressive connection and depth subdivision to enhance rendering quality in neural view synthesis [S1, unofficial]. It is used in conjunction with consistency losses for regularization [S1, unofficial].
