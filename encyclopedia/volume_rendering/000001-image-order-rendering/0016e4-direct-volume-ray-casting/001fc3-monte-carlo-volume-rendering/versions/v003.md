# Monte Carlo Volume Rendering

Also called: Monte Carlo Scattering (MCS), Stochastic Volume Rendering

## Overview
Monte Carlo Volume Rendering (MCVR) is a stochastic approach to direct volume ray casting that replaces uniform spatial sampling with probabilistic distance sampling and null-collision scattering events [S1, S2, S3, unofficial]. Unlike standard ray casting which integrates along fixed steps, MCVR traces photon paths through participating media by randomly determining the distance to the next interaction (absorption or scattering) using an exponential distribution, allowing for adaptive sampling density based on local volume properties [S1, S2, unofficial]. It is distinct from deterministic methods by its reliance on random number generation and frame accumulation to converge to the final image, making it particularly suitable for simulating complex light transport phenomena like multiple scattering in heterogeneous media [S2, unofficial].

## How it works
The method operates in two primary phases: a forward ray-casting phase (often implemented in fragment shaders) for single-scattering or view-dependent lighting, and a backward photon-tracing phase (often implemented in compute shaders) for multi-bounce global illumination [S2, unofficial]. Both phases rely on the volume rendering equation but solved via stochastic integration [S2, unofficial].

### Inputs and Outputs
**Inputs:**
*   **Volume Data:** A 3D texture (`sampler3D`) containing scalar density or RGBA values [S2, S3, unofficial].
*   **Transfer Function:** A 2D texture (`sampler2D`) mapping scalar values to color and opacity [S2, unofficial].
*   **Environment Map:** A 2D texture (`sampler2D`) representing the background or skybox light source [S2, S3, unofficial].
*   **Camera Matrices:** The inverse Model-View-Projection (MVP) matrix to unproject screen coordinates to world-space rays [S2, S3, unofficial].
*   **Parameters:**
    *   `uSigmaMax` (float): Maximum extinction coefficient (majorant) for distance sampling [S2, unofficial].
    *   `uMajorant` (float): The majorant density for null-collision sampling, typically $\ge \max(\sigma_a + \sigma_s)$ [S2, unofficial].
    *   `uAbsorptionCoefficient` (float): Base absorption multiplier [S2, unofficial].
    *   `uScatteringCoefficient` (float): Base scattering multiplier [S2, unofficial].
    *   `uScatteringBias` (float): Anisotropy parameter $g$ for the Henyey-Greenstein phase function [S2, unofficial].
    *   `uMaxBounces` (uint): Maximum scattering bounces [S2, unofficial].
    *   `uSteps` (uint): Number of integration steps per photon trace [S2, unofficial].
    *   `uAlphaCorrection` (float): Scaling factor for sampled alpha [S2, unofficial].
    *   `uOffset` (float): Random offset for seed generation [S2, unofficial].

**Outputs:**
*   **Accumulator Texture:** A 2D texture storing the running average of rendered frames [S2, unofficial].
*   **Photon Buffers (Compute Shader):** Buffers storing photon state (`position`, `direction`, `transmittance`, `radiance`, `bounces`, `samples`) for subsequent accumulation or visualization [S2, unofficial].

### Data Structures
**Photon State (inferred from [S2, unofficial]):**
Stored in output buffers as `vec4` components:
*   `position`: `vec3` (x, y, z)
*   `direction`: `vec3` (x, y, z)
*   `transmittance`: `vec3` (RGB)
*   `radiance`: `vec3` (RGB)
*   `bounces`: Stored in `direction.w` as `float(bounces)`
*   `samples`: Stored in `radiance.w` as `float(samples)`

### Pseudocode

The following pseudocode combines the forward ray-casting (single scattering) and backward photon tracing (multi-scattering) approaches described in the sources [S2, S3, unofficial].

```python
# Helper: Random Number Generation
# Uses a hash-based pseudo-random number generator suitable for shaders
def rand(p, seed):
    """
    Generates a pseudo-random vec2 from position p and seed.
    Implementation detail: fract(cos(sin(p * M) * D) + seed)
    """
    M = mat2(12.9898, 78.233, 45.164, 21.413)
    D = vec2(123.456, 789.012)
    val = fract(sin(dot(p, M) * D) + seed)
    return vec2(val.x, val.y)

# Helper: Environment Map Sampling
def sample_environment(direction):
    """
    Samples the environment map given a direction vector.
    Converts direction to spherical coordinates.
    """
    # atan2(d.x, -d.z) for longitude, asin(-d.y) for latitude
    lon = atan(direction.x, -direction.z)
    lat = asin(-direction.y)
    
    # Normalize to [0, 1] texture coordinates
    u = (lon / (2.0 * PI)) * 0.5 + 0.5
    v = (lat / PI) * 0.5 + 0.5
    
    return texture(uEnvironmentMap, vec2(u, v))

# Helper: Volume Color Sampling
def sample_volume_color(pos):
    """
    Retrieves optical properties from the volume texture.
    Returns vec4 (RGB color, Alpha opacity).
    """
    return texture(uVolume, pos)

# Phase 1: Forward Ray Casting (Single Scattering / View-Dependent)
# Implemented in Fragment Shader
def monte_carlo_ray_cast(pixel_pos, inv_mvp, volume, env_map, sigma_max, alpha_correction, scattering_dir):
    """
    Traces a single ray per pixel, stochastically sampling the first scattering event.
    """
    # 1. Unproject Ray
    # vRayFrom and vRayTo are derived from pixel_pos and inv_mvp
    ray_origin = unproject(pixel_pos, inv_mvp)
    ray_dir = normalize(unproject(pixel_pos + vec2(1.0, 1.0), inv_mvp) - ray_origin)
    
    # 2. Intersect with Volume Bounding Box (Unit Cube [0,1]^3)
    t_near, t_far = intersect_box(ray_origin, ray_dir, box_min=vec3(0), box_max=vec3(1))
    
    if t_near >= t_far:
        return sample_environment(ray_dir)
    
    max_dist = t_far - t_near
    inv_max_dist = 1.0 / max_dist
    
    # 3. Initialize Random Seed
    # Seed based on pixel position and frame offset
    seed = rand(pixel_pos, uOffset)
    
    # 4. Stochastic Distance Sampling
    # Sample distance to first scattering event using exponential distribution
    inv_sigma_max = 1.0 / sigma_max
    dist = 0.0
    
    while dist < max_dist:
        r = rand(vec2(dist, seed.x), seed.y) # Generate random numbers
        # dist_new = dist_old - log(1 - r.x) / sigma_max
        step = -log(1.0 - r.x) * inv_sigma_max
        dist += step
        
        if dist >= max_dist:
            break
            
        # 5. Check for Scattering Event (Density Sampling)
        # Sample volume at current position
        pos = ray_origin + ray_dir * (t_near + dist)
        vol_sample = sample_volume_color(pos)
        
        # Effective alpha for this step
        alpha = vol_sample.a * alpha_correction * inv_sigma_max
        
        # Russian Roulette / Rejection Sampling
        # Continue if r.y < alpha
        if r.y < alpha:
            break
            
    # 6. If no scattering event within volume, sample environment
    if dist >= max_dist:
        return sample_environment(ray_dir)
        
    # 7. Compute Scattering Contribution
    # Position of scattering event
    scatter_pos = ray_origin + ray_dir * (t_near + dist)
    
    # Sample diffuse color at scattering point
    diffuse_color = sample_volume_color(scatter_pos).rgb
    
    # Sample light from environment in scattering direction
    light_color = sample_environment(scattering_dir)
    
    # Compute Transmittance from scatter point to exit
    # This involves another stochastic loop or deterministic integration
    transmittance = compute_transmittance(scatter_pos, scattering_dir, sigma_max, alpha_correction)
    
    # Final Color
    return diffuse_color * light_color * transmittance

# Phase 2: Photon Tracing (Multi-Bounce / Global Illumination)
# Implemented in Compute Shader
def trace_photon(photon, volume, env_map, majorant, abs_coeff, scat_coeff, bias, max_bounces, max_steps):
    """
    Traces a photon path through the volume using null-collision Monte Carlo.
    """
    # 1. Initialize Photon
    photon.position = photon.entry_point # From ray-box intersection
    photon.direction = normalize(photon.direction)
    photon.transmittance = vec3(1.0)
    photon.radiance = vec3(0.0)
    photon.bounces = 0
    photon.samples = 0
    
    inv_majorant = 1.0 / majorant
    
    for i in range(max_steps):
        # 2. Generate Random Step Size
        r = rand(vec2(i, photon.position), photon.seed)
        step_size = -log(1.0 - r.x) * inv_majorant
        
        # 3. Advance Position
        photon.position += photon.direction * step_size
        
        # 4. Check Bounds
        if not is_inside_unit_cube(photon.position):
            # Photon escaped: Sample environment for radiance contribution
            env_light = sample_environment(photon.direction)
            photon.radiance += photon.transmittance * env_light
            photon.samples += 1
            # Reset photon for next trace
            return photon
            
        # 5. Sample Volume Properties
        vol_sample = sample_volume_color(photon.position)
        
        # Compute local coefficients
        # mu_absorption = volume.alpha * absorption_coefficient
        mu_abs = vol_sample.a * abs_coeff
        # mu_scattering = volume.alpha * scattering_coefficient
        mu_scat = vol_sample.a * scat_coeff
        
        # Null collision coefficient
        mu_null = majorant - mu_abs - mu_scat
        
        # Probabilities
        p_null = abs(mu_null) / majorant
        p_abs = mu_abs / majorant
        p_scat = mu_scat / majorant
        
        # 6. Determine Collision Type
        r2 = rand(vec2(i+1, photon.position), photon.seed)
        
        if r2.y < p_abs + p_scat:
            # Absorption or Scattering Event
            if r2.y < p_abs:
                # Absorption: Photon dies, no further contribution
                break
            else:
                # Scattering Event
                # Update transmittance with weight
                weight_s = mu_scat / (majorant * p_scat)
                photon.transmittance *= vol_sample.rgb * weight_s
                
                # Sample new direction using Henyey-Greenstein
                photon.direction = sample_henyey_greenstein(photon.direction, bias)
                photon.bounces += 1
                
                if photon.bounces >= max_bounces:
                    break
        else:
            # Null Collision
            # Photon continues, transmittance is reduced by weight
            weight_n = abs(mu_null) / (majorant * p_null)
            photon.transmittance *= weight_n
            
    return photon

# Helper: Transmittance Computation (Forward Phase)
def compute_transmittance(start_pos, direction, sigma_max, alpha_correction):
    """
    Computes transmittance from start_pos along direction to volume exit.
    Uses stochastic sampling similar to distance sampling.
    """
    ray_origin = start_pos
    t_near, t_far = intersect_box(ray_origin, direction, vec3(0), vec3(1))
    if t_near >= t_far:
        return 1.0
        
    max_dist = t_far - t_near
    inv_max_dist = 1.0 / max_dist
    inv_sigma_max = 1.0 / sigma_max
    
    dist = 0.0
    transmittance = 1.0
    
    # Seed for this segment
    seed = rand(start_pos, 0.0) 
    
    while dist < max_dist:
        r = rand(vec2(dist, seed.x), seed.y)
        step = -log(1.0 - r.x) * inv_sigma_max
        dist += step
        
        if dist >= max_dist:
            break
            
        pos = ray_origin + direction * (t_near + dist)
        vol_sample = sample_volume_color(pos)
        alpha = vol_sample.a * alpha_correction * inv_sigma_max
        
        # Update transmittance
        transmittance *= (1.0 - alpha)
        
        # Russian Roulette to terminate early
        if rand(vec2(dist+1, seed.x), seed.y).y > alpha:
            break
            
    return transmittance
```

### Parameters and Typical Values
*   `uSigmaMax`: Must be $\ge$ maximum extinction coefficient in the volume. Typical values depend on data normalization, often $1.0$ to $10.0$ [S2, unofficial].
*   `uMajorant`: Must be $\ge \max(\sigma_a + \sigma_s)$. Default value $2.0$ [S2, unofficial].
*   `uAbsorptionCoefficient`: Default $1.0$ [S2, unofficial].
*   `uScatteringCoefficient`: Default $1.0$ [S2, unofficial].
*   `uScatteringBias` ($g$): Default $0.0$ (isotropic) [S2, unofficial].
*   `uMaxBounces`: Default $8$ [S2, unofficial].
*   `uSteps`: Default varies, but sufficient to cover volume depth [S2, unofficial].
*   `uAlphaCorrection`: Adjusts effective opacity; used to compensate for stochastic sampling bias [S2, unofficial].

### Edge Cases and Pitfalls
*   **Majorant Selection:** If `uMajorant` is too low, the null-collision method fails (probabilities $> 1$). It must be an upper bound on the sum of absorption and scattering coefficients [S2, unofficial].
*   **Precision:** Logarithms of random numbers near $0$ can cause instability. Use `1.0 - rand()` instead of `rand()` inside `log` to avoid `log(0)` [S2, unofficial].
*   **Boundary Conditions:** Rays missing the volume must sample the environment map correctly. The intersection test must handle rays parallel to faces [S2, S3, unofficial].
*   **Convergence:** MCVR produces noisy images initially. Frame accumulation is required for convergence. The number of frames needed depends on variance in the volume [S2, unofficial].
*   **Gradient Calculation:** Some implementations use Sobel operators to pre-compute gradients for shading and opacity modulation to hide homogeneous regions [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot B)$ per pixel, where $N$ is the number of steps/bounces and $B$ is the number of samples per pixel (for accumulation). The stochastic nature means the number of steps per ray is variable, but bounded by `uSteps` or escape [S2, unofficial].
*   **Memory Complexity:** $O(V)$ for volume storage, plus $O(P)$ for photon buffers if using compute shaders, where $P$ is the number of pixels [S2, unofficial].
*   **Performance:** Slower than deterministic ray casting per frame due to random number generation and lack of spatial coherence in sampling. However, it handles complex lighting (multiple scattering) more accurately than single-scattering approximations [S2, unofficial].
*   **Strengths:** Handles heterogeneous media well; naturally supports multiple scattering; adaptive sampling density based on local extinction [S1, S2, unofficial].
*   **Limitations:** Noisy output requiring accumulation; sensitive to majorant selection; random number generation overhead [S2, unofficial].
*   **When to Use:** When accurate simulation of light transport in participating media (fog, smoke, biological tissue) is required, and real-time performance is not critical or can be achieved via accumulation [S2, unofficial].
*   **When Not to Use:** For homogeneous volumes where deterministic integration is sufficient and faster; when real-time, single-frame feedback is strictly required without accumulation [S1, unofficial].

## Background
Monte Carlo methods for volume rendering originated from the need to simulate light transport in participating media more accurately than deterministic integration allowed [S1, unofficial]. The specific implementation described in the sources is a GPU-based technique using compute shaders for photon tracing and fragment shaders for ray casting, exposing parameters like extinction, albedo, and bias via a UI [S2, unofficial]. It builds on the principles of path tracing and null-collision Monte Carlo methods adapted for volumetric data [S2, unofficial]. The method is often compared to pre-integrated volume rendering, which trades flexibility for speed by pre-computing integrals [S1, unofficial].
