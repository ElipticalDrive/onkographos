# Perspective Sampling

Also called: Warp-space Uniform Sampling

## Overview
Perspective sampling is a point-sampling strategy for camera rays in volume rendering that ensures approximately uniform sampling density in the image plane, rather than in Euclidean space [S1][S2, unofficial]. It addresses the misalignment between axis-aligned grids in Euclidean space and camera rays [S2, unofficial]. It differs from standard uniform sampling by using the Jacobian of the perspective warping function to adjust step sizes [S1][S2, unofficial].

## How it works
**Inputs:**
- Camera origin $o \in \mathbb{R}^3$ [G].
- Camera ray direction $d \in \mathbb{R}^3$ (normalized) [G].
- Perspective warping function $F: \mathbb{R}^3 \to \mathbb{R}^3$ and its Jacobian $J(x) = \frac{\partial F}{\partial x}$ [S1][S2, unofficial].
- Preset sampling interval parameter $l$ [S1][S2, unofficial].

**Outputs:**
- A sequence of 3D sample points $\{x_i\}$ along the ray [G].

**Data Structures:**
- Current sample point $x_i$ (vector, 3 floats) [G].
- Next sample point $x_{i+1}$ (vector, 3 floats) [G].
- Jacobian matrix $J_i$ (matrix, $3 \times 3$ floats) [S1][S2, unofficial].

**Steps:**
1. Initialize the first sample point $x_0$ at a starting distance $t_{start}$ along the ray: $x_0 = o + t_{start} \cdot d$ [G].
2. For each sample index $i = 0, 1, \dots, N-1$:
   a. Compute the Jacobian matrix $J_i$ of the perspective warping function $F$ at the current point $x_i$ [S1][S2, unofficial].
   b. Compute the vector $v = J_i \cdot d$.
   c. Compute the Euclidean norm $\|v\|_2$.
   d. Calculate the next sample point using the linear approximation: $x_{i+1} = x_i + l \cdot \|J_i \cdot d\|_2 \cdot d$ [S1][S2, unofficial].
   e. Store $x_i$ as a sample point.
3. Stop when the ray exits the scene or reaches the far clipping plane [G].

**Parameters:**
- $l$: Preset parameter controlling the sampling interval in the warp space approximation [S1][S2, unofficial]. Typical values are not explicitly given in the sources [G].

**Edge Cases and Pitfalls:**
- **Linear Approximation:** The method uses a linear approximation for the sampling step, as discussed in the supplementary material [S2, unofficial].
- **Jacobian Computation:** The Jacobian $J_i$ must be computed accurately [G]. If $F$ is a neural network or complex analytical function, automatic differentiation or analytical derivatives are required [G].
- **Boundary Conditions:** The sampling must be bounded by the scene's near and far planes to avoid infinite loops or sampling outside the region of interest [G].

**Pseudocode:**
```python
def perspective_sample(o, d, F_jacobian, l, t_start, t_end):
    """
    Generate sample points along a ray using perspective sampling.
    
    Args:
        o: Camera origin (3,)
        d: Ray direction (3,), normalized
        F_jacobian: Function to compute Jacobian J(x) -> (3, 3)
        l: Preset sampling interval parameter
        t_start: Starting distance along the ray
        t_end: Ending distance along the ray
        
    Returns:
        List of sample points x_i
    """
    samples = []
    x = [o[r] + t_start * d[r] for r in range(3)]
    
    while True:
        # Compute Jacobian at current point
        J = F_jacobian(x)
        
        # Compute J * d
        Jd = [sum(J[r][c] * d[c] for c in range(3)) for r in range(3)]
        
        # Compute norm ||Jd||_2
        norm_Jd = sum(v * v for v in Jd) ** 0.5
        
        # Calculate next point: x_{i+1} = x_i + l * ||J_i * d||_2 * d
        x_next = [x[r] + l * norm_Jd * d[r] for r in range(3)]
        
        # Add current sample
        samples.append(x)
        
        # Update for next iteration
        x = x_next
        
        # Check boundary condition
        # Distance along ray from origin: dot(x - o, d)
        dist = sum((x[r] - o[r]) * d[r] for r in range(3))
        if dist >= t_end:
            break
            
    return samples
```

## Subtopics

### Volume Rendering with Perspective Warping
This variant applies perspective sampling to sample points $x_i$ on the camera ray, warps them to the warp space using the perspective warping function, and computes density $\sigma_i$ and color $c_i$ from a neural representation built on the warp space [S2, unofficial]. The final pixel color is computed via volume rendering compositing: $\hat{c} = \sum_i T_i \alpha_i c_i$, where $T_i = \prod_{j=0}^{i-1}(1 - \alpha_j)$ is the accumulated transmittance and $\alpha_i = 1 - \exp(-\delta_i \sigma_i)$ is the opacity [S2, unofficial].

## Operating characteristics
- **Time Complexity:** The cost per sample is dominated by the evaluation of the warping function $F$ and its Jacobian $J$ [G].
- **Memory Complexity:** Minimal, as it only stores the current point and Jacobian [G].
- **Performance:** Improves sampling efficiency and brings more stable convergence compared to uniform Euclidean sampling [S1][S2, unofficial].
- **Strengths:** Ensures approximately uniform sampling in the image plane, reducing artifacts and improving reconstruction quality [S1][S2, unofficial].
- **Limitations:** Relies on a linear approximation which may be inaccurate for highly non-linear warping functions [S2, unofficial]. Requires computation of the Jacobian, which can be computationally expensive [G].

## Background
Perspective sampling is introduced in the context of F2-NeRF (Fast Neural Radiance Field Training with Free Camera Trajectories) to address sampling inefficiencies in volume rendering [S1][S2, unofficial]. It builds on space warping concepts, such as NDC warping and inverse sphere warping, which map unbounded space to a bounded space [S2, unofficial].
