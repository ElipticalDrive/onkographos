# NDC Warping
Also called: Normalized Device Coordinate Warping
## Overview
NDC Warping is a space-warping technique for forward-facing scenes that maps an infinitely far view frustum to a bounded box by squashing the z-axis [S1]. It is specifically designed for forward-facing trajectories, whereas its parent [Space Warping (Log+Warp)](5815-space-warping-log-warp.md) handles broader radial distortion and its child [Perspective Warping](7499-perspective-warping.md) generalizes to arbitrary camera trajectories [G]. It is unsuitable for 360-degree environments [S1].
## How it works
Inputs and outputs:
- Input: 3D point $\mathbf{x} = (x, y, z)$ in camera space, where the camera looks down the positive z-axis [G].
- Output: Warped 3D point $\mathbf{x}' = (x', y', z')$ in NDC space [G].

Data structures:
- Not given in the sources.

Numbered steps:
1. Divide the lateral coordinates by depth to project the point onto the normalized plane [G].
2. Transform the depth coordinate to squash the unbounded frustum into a bounded interval [G].

Formulas:
- $x' = x / z$
- $y' = y / z$
- $z' = 1 / z$ (or linearly remapped to $[0, 1]$ or $[-1, 1]$ based on near/far planes) [G]

Parameters:
- Near and far clipping distances ($z_{near}, z_{far}$) define the bounded depth range, though exact values are not given in the sources.

Edge cases and pitfalls:
- Unsuitable for 360-degree environments [S1].
- Division by zero when $z = 0$ requires clamping or near-plane culling [G].

Pseudocode:
```python
def ndc_warp(x, y, z, z_near=0.01, z_far=100.0):
    # Clamp depth to avoid division by zero
    z = max(z, z_near)
    # Project lateral coordinates
    x_prime = x / z
    y_prime = y / z
    # Squash depth to [0, 1] range
    z_prime = (z_far - z) / (z_far - z_near)
    return x_prime, y_prime, z_prime
```
## Subtopics

### [Perspective Warping](7499-perspective-warping.md)
Generalizes NDC warping to arbitrary camera trajectories by aligning axis-aligned grids with camera rays, mapping unbounded space to a bounded space. Choose it for unbounded scenes with non-forward-facing cameras; it automatically degenerates to NDC warping for forward-facing trajectories.
