# Proper Space Warping

Also called: 3D Perspective Warping Construction, F(x), F(x) = MG(x), PCA-based Proper Warping, PCA-based Warping

## Overview
Proper Space Warping constructs a local 3D-to-3D mapping $F: \mathbb{R}^3 \to \mathbb{R}^3$ that approximates a "proper" warping function, where the squared Euclidean distance in warp space equals the sum of squared distances across all visible cameras [S1][S2, unofficial]. It solves the problem of aligning grid-based scene representations with multi-view geometry by ensuring that axis-aligned grids in the warp space align with camera rays, thereby reducing interpolation artifacts and improving training stability for Neural Radiance Fields [S2, unofficial]. It differs from [NDC Warping](7267-ndc-warping.md) by using a data-driven PCA projection of multi-view coordinates rather than a fixed normalized device coordinate transformation, and from its parent [Space Warping (Log+Warp)](5815-space-warping-log-warp.md) by explicitly optimizing for multi-view distance preservation via Principal Component Analysis rather than radial distortion [S1][S2, unofficial].

## How it works
**Inputs:**
- A local 3D region $S$ (typically a leaf node in a spatial hierarchy).
- A set of $n_c$ visible cameras $\{C_i\}_{i=1}^{n_c}$ for region $S$.
- Number of sampled points $n_p$ (Not given in the sources).

**Outputs:**
- A warping function $F(x) = M G(x)$, where $M$ is a projection matrix and $G(x)$ maps 3D points to concatenated 2D projected coordinates.
- The projection matrix $M \in \mathbb{R}^{3 \times 2n_c}$.

**Data Structures:**
- **Camera Projection $C_i(x)$**: Returns the 2D homogeneous or normalized coordinates of 3D point $x$ in camera $i$'s image plane. [S1][S2, unofficial]
- **Mapping Function $G(x)$**: Concatenates projections from all $n_c$ cameras.
  $$ G(x) = [C_1(x), C_2(x), \dots, C_{n_c}(x)] \in \mathbb{R}^{2n_c} $$
  [S2, unofficial]
- **Projection Matrix $M$**: A $3 \times 2n_c$ matrix constructed from the first three eigenvectors of the covariance matrix of sampled projected points. [S1][S2, unofficial]
- **Warp Space Points $z_j$**: The result $z_j = F(x_j) \in \mathbb{R}^3$. [S1][S2, unofficial]

**Parameters:**
- $n_c$: Number of visible cameras. Typically set to 4 for leaf nodes visible by more than 4 cameras. If fewer than 4 cameras are visible, all are used. [S2, unofficial]
- Camera Selection: If $n_c > 4$, cameras are selected to maximize the minimal pairwise distance between them. [S2, unofficial]

**Steps:**
1. **Sampling**: Sample $n_p$ evenly-spaced points $\{x_j\}_{j=1}^{n_p}$ within the local region $S$. [S2, unofficial]
2. **Projection**: Compute the projected coordinates for all sampled points across all $n_c$ visible cameras:
   $$ y_j = G(x_j) = [C_1(x_j), \dots, C_{n_c}(x_j)] \in \mathbb{R}^{2n_c} $$
   [S2, unofficial]
3. **PCA**: Perform Principal Component Analysis on the set of points $\{y_j\}_{j=1}^{n_p}$.
   - Compute the covariance matrix of $\{y_j\}$.
   - Extract the first three eigenvectors corresponding to the largest eigenvalues.
   - Construct $M$ by stacking these three eigenvectors as rows (or columns, depending on convention; the source states $M$ is constructed from the first three eigenvectors, and $z_j = M y_j$, implying $M$ is $3 \times 2n_c$). [S1][S2, unofficial]
4. **Warping Function Definition**: Define the warping function as:
   $$ F(x) = M G(x) $$
   [S1][S2, unofficial]
5. **Post-Normalization**: Apply post-normalization to $F(x)$ to ensure the resulting points $\{z_j\}$ in the warp space are located around the origin. [S1][S2, unofficial]

**Edge Cases and Pitfalls:**
- **Fewer than 3 visible cameras**: PCA requires at least 3 dimensions to produce a $3 \times 2n_c$ matrix if $2n_c < 3$, or rank deficiency if $n_c$ is small. The source specifies $n_c=4$ typically, implying robustness. If $n_c$ is very small, the approximation may be poor. [S2, unofficial]
- **Degenerate Camera Configurations**: If cameras are collinear or coplanar in a way that reduces the rank of the projected point cloud, PCA may fail to produce a full-rank $M$. The camera selection strategy (maximizing pairwise distance) mitigates this. [S2, unofficial]
- **Precision**: The source notes that $F(x)$ is an *approximately* proper warping function, relaxing the strict definition to sampled points. This approximation error should be considered. [S1][S2, unofficial]

## Subtopics

### NDC Warping
Uses a fixed normalized device coordinate transformation for warping. Choose when a simple, non-data-driven approach is sufficient. [Link](7267-ndc-warping.md)

### Space Warping (Log+Warp)
Uses radial distortion to warp space towards the view cell center. Choose when background dampening is prioritized over multi-view distance preservation. [Link](5815-space-warping-log-warp.md)

## Operating characteristics
- **Time Complexity**: The construction phase involves sampling $n_p$ points, projecting them through $n_c$ cameras, and performing PCA on $n_p$ points in $2n_c$ dimensions. PCA is $O(n_p (2n_c)^2)$ or $O(n_p^2)$ depending on implementation. This is done per leaf node. [S1][S2, unofficial]
- **Memory Complexity**: Stores the projection matrix $M$ of size $3 \times 2n_c$ per leaf node. [S2, unofficial]
- **Strengths**: Aligns grid-based representations with camera rays, reducing interpolation artifacts. Improves training stability for NeRFs with free camera trajectories. [S2, unofficial]
- **Limitations**: Requires visible cameras for each region. Computationally more expensive than fixed warping methods due to PCA. Approximate, not exact, proper warping. [S1][S2, unofficial]
- **When to Use**: When training NeRFs with diverse camera trajectories and using grid-based scene representations. [S2, unofficial]
- **When Not to Use**: When computational resources for per-node PCA are limited, or when camera visibility is sparse.

## Background
Proper Space Warping was introduced in the F2-NeRF paper (Wang et al., CVPR 2023) to enable fast neural radiance field training with free camera trajectories. It addresses the misalignment between axis-aligned grids and camera rays in multi-view settings by constructing a warping function that preserves multi-view distances. The method relaxes the strict definition of proper warping to an approximate version solvable via PCA. [S1][S2, unofficial]
