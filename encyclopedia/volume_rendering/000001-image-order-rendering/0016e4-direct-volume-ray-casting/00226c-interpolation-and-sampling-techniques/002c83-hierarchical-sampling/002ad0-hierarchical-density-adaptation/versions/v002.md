# Hierarchical Density Adaptation

Also called: On-the-fly coarse sampling

## Overview
Hierarchical Density Adaptation is a sampling strategy for direct volume ray casting that generates a coarse density estimate from a dense feature grid on the fly to guide importance sampling for fine samples [S1]. It solves the problem of missing thin or high-frequency surface details when sampling directly from a dense grid, which can occur if coarse sample points fall between grid cells containing significant geometry [S1]. Unlike sibling methods that maintain a dedicated, pre-computed coarse grid or train a separate coarse network, this method derives the coarse density by convolving the existing dense density grid with a non-learnable kernel, thereby avoiding additional memory allocation for coarse structures while ensuring robust surface detection [S1].

## How it works
The method operates in two stages: coarse sampling to estimate density distribution, and fine sampling to render color [S1]. It relies on a dense density feature grid $G_\sigma$ and a dense appearance feature grid $G_a$ [S1].

**Inputs and Outputs:**
*   **Input:** Dense density grid $G_\sigma$, dense appearance grid $G_a$, camera ray origin $o$, ray direction $\mathbf{d}$, number of coarse samples $N_c$, number of fine samples $N_f$ [S1].
*   **Output:** Pixel color $\hat{C}$ [S1].

**Data Structures:**
*   $G_\sigma$: A 3D grid storing volume density values $\sigma$ [S1]. In the primary implementation (EgoNeRF), this is a balanced spherical grid where resolution increases exponentially along the radial direction [S1].
*   $K$: A non-learnable convolution kernel, specifically an average pooling kernel [S1].

**Steps:**

1.  **On-the-fly Coarse Density Estimation:**
    To prevent skipping important surface regions, the density at coarse sample locations is not read directly from $G_\sigma$ [S1]. Instead, it is computed by convolving $G_\sigma$ with kernel $K$ [S1].
    $$ \sigma(\mathbf{x}_{\text{coarse}}) = \mathcal{T}(K * G_\sigma, \mathbf{x}_{\text{coarse}}) $$
    where $\mathcal{T}$ denotes trilinear (or appropriate spherical) interpolation [S1]. The kernel $K$ acts as an average pooling operation, smoothing the density field to capture broader geometric extents [S1].

2.  **Coarse Sampling:**
    Sample $N_c$ points $\mathbf{x}_i$ along the ray [S1]. In the standard spherical grid implementation, these samples are distributed exponentially along the ray rather than uniformly, to match the exponential increase in grid resolution along the radial direction [S1]. Let $\delta_i$ be the distance between consecutive coarse samples [S1].

3.  **Weight Calculation:**
    Calculate importance sampling weights $w_i$ for each coarse sample based on the estimated density $\sigma_i = \sigma(\mathbf{x}_i)$ and accumulated transmittance $\tau_i$ [S1]:
    $$ w_i = \tau_i (1 - e^{-\sigma_i \delta_i}) $$
    where the accumulated transmittance is:
    $$ \tau_i = e^{-\sum_{j=1}^{i-1} \sigma_j \delta_j} $$
    with $\tau_1 = 1$ [S1].

4.  **Fine Sampling:**
    Sample $N_f$ fine points from the probability distribution defined by the normalized weights $w_i$ [S1]. These points are used to query the dense grids for precise density and color [S1].

5.  **Rendering:**
    Render the pixel using the combined set of $N = N_c + N_f$ samples [S1]. The color is computed via volume rendering integration [S1]:
    $$ \hat{C} = \sum_{i=1}^{N} \tau_i (1 - e^{-\sigma(\mathbf{x}_i)\delta_i}) c(\mathbf{x}_i, \mathbf{d}) + \tau_{N+1} c_{\text{env}}(\mathbf{d}) $$
    where $c(\mathbf{x}_i, \mathbf{d})$ is the color obtained from the appearance grid $G_a$ and an optional decoding MLP, and $c_{\text{env}}(\mathbf{d})$ is the environment map color [S1].

**Pseudocode:**

```python
import math

def exponential_ray_samples(origin, direction, n_samples):
    """Generates n_samples distances exponentially spaced along a ray [G]."""
    # Geometric progression from a near bound to a far bound
    t_near, t_far = 0.1, 100.0
    return [t_near * (t_far / t_near) ** (i / (n_samples - 1)) for i in range(n_samples)]

def sample_from_distribution(probs, bounds, n_samples):
    """Samples n_samples points from a discrete distribution over segment bounds [G]."""
    import random
    indices = random.choices(range(len(probs)), weights=probs, k=n_samples)
    points = []
    for idx in indices:
        t_min = bounds[idx]
        t_max = bounds[idx + 1] if idx + 1 < len(bounds) else bounds[-1] * 2.0
        t_sample = t_min + random.random() * (t_max - t_min)
        points.append(t_sample)
    return points

def hierarchical_density_adaptation(ray_origin, ray_direction, G_sigma, G_appearance, 
                                    N_c, N_f, kernel_K, env_map=None):
    """
    Renders a single ray using Hierarchical Density Adaptation.
    
    Args:
        ray_origin: 3D vector (o)
        ray_direction: 3D vector (d)
        G_sigma: Dense density grid object with method query_and_smooth(x, kernel)
        G_appearance: Dense appearance grid object with method query(x, d)
        N_c: Number of coarse samples
        N_f: Number of fine samples
        kernel_K: Convolution kernel (average pooling)
        env_map: Optional environment map function c_env(d)
        
    Returns:
        pixel_color: Scalar or RGB vector
    """
    # Step 1 & 2: Coarse Sampling and Density Estimation
    distances = exponential_ray_samples(ray_origin, ray_direction, N_c)
    coarse_points = []
    coarse_densities = []
    coarse_transmittances = []
    
    current_transmittance = 1.0
    for i, dist in enumerate(distances):
        x_coarse = ray_origin + dist * ray_direction
        sigma_coarse = G_sigma.query_and_smooth(x_coarse, kernel_K)
        
        coarse_points.append(x_coarse)
        coarse_densities.append(sigma_coarse)
        coarse_transmittances.append(current_transmittance)
        
        # Delta is distance to next sample; use large value for tail segment
        if i < len(distances) - 1:
            delta_i = distances[i+1] - dist
        else:
            delta_i = float('inf')
            
        current_transmittance *= math.exp(-sigma_coarse * delta_i)

    # Step 3: Calculate Importance Sampling Weights
    weights = []
    for i in range(N_c):
        sigma_i = coarse_densities[i]
        tau_i = coarse_transmittances[i]
        if i < N_c - 1:
            delta_i = distances[i+1] - distances[i]
        else:
            delta_i = float('inf')
        w_i = tau_i * (1.0 - math.exp(-sigma_i * delta_i))
        weights.append(w_i)
        
    # Normalize weights for probability distribution
    total_weight = sum(weights)
    if total_weight > 0:
        probs = [w / total_weight for w in weights]
    else:
        probs = [1.0 / N_c] * N_c
        
    # Step 4: Fine Sampling
    fine_distances = sample_from_distribution(probs, distances, N_f)
    fine_points = [ray_origin + t * ray_direction for t in fine_distances]
    
    # Combine coarse and fine points
    all_distances = distances + fine_distances
    all_points = [ray_origin + t * ray_direction for t in all_distances]
    
    # Step 5: Rendering
    # Sort all points by distance from origin
    all_points.sort(key=lambda p: math.dist(p, ray_origin))
    
    pixel_color = 0.0
    accumulated_transmittance = 1.0
    
    for i, x in enumerate(all_points):
        sigma = G_sigma.query(x)
        color = G_appearance.query(x, ray_direction)
        
        if i < len(all_points) - 1:
            delta = math.dist(all_points[i], all_points[i+1])
        else:
            delta = 0.0
            
        weight = accumulated_transmittance * (1.0 - math.exp(-sigma * delta))
        pixel_color += weight * color
        accumulated_transmittance *= math.exp(-sigma * delta)
        
    # Add environment map contribution if available
    if env_map is not None:
        pixel_color += accumulated_transmittance * env_map(ray_direction)
        
    return pixel_color
```

**Parameters:**
*   $N_c$: Number of coarse samples along the ray [S1].
*   $N_f$: Number of fine samples along the ray [S1].
*   $K$: Convolution kernel [S1]. Typically an average pooling kernel [S1].

**Edge Cases and Pitfalls:**
*   **Skipping Surface Regions:** Evaluating density directly from the dense grid $G_\sigma$ at coarse points may skip important surface regions if the coarse sampling interval is larger than the feature thickness [S1]. This is mitigated by the on-the-fly convolution with $K$ [S1].
*   **Grid Resolution Mismatch:** In spherical grids, resolution increases exponentially with radius [S1]. Uniform sampling may under-sample distant regions [S1]. Coarse samples should be distributed exponentially to match the grid structure [S1].

## Subtopics

### Environment Map Integration
This variant integrates an equirectangular environment map $E \in \mathbb{R}^{H \times W \times 3}$ to handle outdoor or large indoor environments where the bounded feature grid (limited by $R_{max}$) cannot represent distant geometry [S1]. The environment map represents visibility at almost infinite distance [S1]. The rendering equation is extended to include a tail term: $\hat{C} = \sum_{i=1}^{N} \tau_i (1 - e^{-\sigma(\mathbf{x}_i)\delta_i}) c(\mathbf{x}_i, \mathbf{d}) + \tau_{N+1} c_{\text{env}}(\mathbf{d})$, where $c_{\text{env}}(\mathbf{d}) = \mathcal{E}(u, v; \mathbf{d})$ and $(u, v)$ are sampling positions dependent only on the viewing direction $\mathbf{d}$ [S1].

## Operating characteristics
*   **Memory:** Requires no additional memory for a dedicated coarse grid, as the coarse density is derived from the existing dense grid $G_\sigma$ [S1].
*   **Time Complexity:** Adds the cost of a convolution operation (average pooling) over the grid or per-sample during the coarse stage, plus the overhead of $N_c$ coarse samples [S1]. The total sample count is $N_c + N_f$ [S1].
*   **Strengths:** Prevents aliasing and missing thin structures that occur with direct dense grid sampling [S1]. Efficient as it reuses the primary density representation [S1].
*   **Limitations:** The quality of the coarse estimate depends on the kernel $K$ and the density grid resolution [S1]. If the grid is too sparse, even the smoothed estimate may be inaccurate [S1].
*   **When to use:** When using explicit feature grids (like balanced spherical grids) where maintaining a separate coarse grid is memory-prohibitive or unnecessary, and surface details are thin relative to the coarse sampling interval [S1].

## Background
This method was introduced in the context of EgoNeRF, a radiance field representation using balanced spherical feature grids for egocentric view synthesis [S1]. It was proposed to address the limitations of standard hierarchical sampling when applied to explicit grids, where direct sampling might miss geometry [S1]. The approach leverages the physical meaning of volume density in the grid to allow simple convolution-based smoothing for coarse estimation [S1].
