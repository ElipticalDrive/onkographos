# Cubic Interpolation (Mitchell-Netravali)

Also called: Mitchell-Netravali, Mitchell-Netravali Cubic Filter

## Overview
Mitchell-Netravali cubic interpolation is a family of C0 and C1 continuous cubic filters defined by parameters B and C, used to reconstruct volume data while preventing high-frequency leakage artifacts [S1, unofficial]. It distinguishes itself from simpler schemes by offering a tunable trade-off between blurring and ringing, and from fixed B-splines by allowing the generation of Catmull-Rom splines [S1, unofficial]. It builds on [Fast tri-cubic interpolation](848-fast-tri-cubic-interpolation.md) by providing the specific kernel weights for the convolution sum.

## How it works
**Inputs and Outputs:**
- Input: A 3D volume texture $V$, a ray origin $O$, a ray direction $D$, and a step size $s$.
- Output: A single accumulated color/opacity value along the ray.
- Parameters: Tuning parameters $B$ and $C$.

**Data Structures:**
- The kernel $k(x)$ is a scalar function.
- The volume $V$ is accessed via integer voxel coordinates.

**Method:**
1.  For each sample point $P$ along the ray, compute the fractional offset $x$ from the nearest voxel center.
2.  Compute the kernel weight $k(x)$ using the Mitchell-Netravali formula.
3.  Fetch the 64 nearest voxel values in 3D (4 samples per dimension).
4.  Compute the weighted sum of these 64 samples.
5.  Clamp the result to the valid input range to prevent out-of-bounds values [S1, unofficial].

**Kernel Formula:**
The kernel $k(x)$ is defined piecewise based on $|x|$:

$$
k(x) = \frac{1}{6} \begin{cases} 
(12 - 9B - 6C)|x|^3 + (-18 + 12B + 6C)|x|^2 + (6 - 2B), & \text{if } |x| < 1; \\
(-B - 6C)|x|^3 + (6B + 30C)|x|^2 + (-12B - 48C)|x| + (8B + 24C), & \text{if } 1 \le |x| < 2; \\
0, & \text{otherwise.}
\end{cases}
$$

**Symbol Definitions:**
- $x$: The distance from the sample point to the voxel center, normalized such that voxel centers are at integers.
- $B, C$: Tuning parameters.
- $|x|$: Absolute value of $x$.

**Parameters:**
- $B=1.0, C=0.0$: Generates Cubic B-splines [S1, unofficial].
- $B=0.0, C=0.5$: Generates Catmull-Rom splines [S1, unofficial].
- Typical values trade off aliasing effects (blurring, ringing, anisotropy) [S1, unofficial].

**Pitfalls:**
- General cubic interpolation can produce values outside the range of the inputs; these must be clamped [S1, unofficial].
- The filter satisfies $\sum_{n=-\infty}^{\infty} h(x-n) = 1$ to prevent sample frequency ripple [S1, unofficial].

**Pseudocode:**
```python
def mitchell_netravali_kernel(x, B, C):
    abs_x = abs(x)
    if abs_x < 1.0:
        term1 = (12.0 - 9.0 * B - 6.0 * C) * (abs_x ** 3)
        term2 = (-18.0 + 12.0 * B + 6.0 * C) * (abs_x ** 2)
        term3 = (6.0 - 2.0 * B)
        return (term1 + term2 + term3) / 6.0
    elif abs_x < 2.0:
        term1 = (-B - 6.0 * C) * (abs_x ** 3)
        term2 = (6.0 * B + 30.0 * C) * (abs_x ** 2)
        term3 = (-12.0 * B - 48.0 * C) * abs_x
        term4 = (8.0 * B + 24.0 * C)
        return (term1 + term2 + term3 + term4) / 6.0
    else:
        return 0.0

def sample_volume_mitchell(volume, x_frac, y_frac, z_frac, B, C):
    # x_frac, y_frac, z_frac are fractional coordinates in [0, 1)
    # Determine the 4x4x4 grid of voxel indices
    # Note: In a real implementation, boundary checks are required.
    # This pseudocode assumes valid interior access.
    
    total_weight = 0.0
    weighted_sum = 0.0
    
    for dx in range(-1, 3): # 4 samples in X
        for dy in range(-1, 3): # 4 samples in Y
            for dz in range(-1, 3): # 4 samples in Z
                # Calculate distance from voxel center
                # Voxel center is at integer coordinate.
                # If current pos is i + x_frac, and we want voxel i+dx,
                # the distance is (i + x_frac) - (i + dx) = x_frac - dx
                dist_x = x_frac - dx
                dist_y = y_frac - dy
                dist_z = z_frac - dz
                
                # Compute kernel weights
                w_x = mitchell_netravali_kernel(dist_x, B, C)
                w_y = mitchell_netravali_kernel(dist_y, B, C)
                w_z = mitchell_netravali_kernel(dist_z, B, C)
                
                weight = w_x * w_y * w_z
                voxel_val = volume.get_value(dx, dy, dz) # Placeholder for actual fetch
                
                weighted_sum += weight * voxel_val
                total_weight += weight
                
    # Clamp result to prevent out-of-bounds values [S1, unofficial]
    result = weighted_sum / total_weight if total_weight > 0 else 0.0
    return clamp(result, min_val, max_val)
```

## Subtopics

### Cubic Interpolation
A higher-order polynomial interpolation scheme for smoother results than linear interpolation, requiring more samples [S2, unofficial]. In 3D, it requires sampling 64 voxels ($2^4$) [S2, unofficial]. It produces smoother results than linear interpolation but increases render time [S2, unofficial].

## Operating characteristics
**Time and Memory Complexity:**
- In 3D, cubic interpolation requires sampling 64 nearest samples [S1, unofficial].
- Spatial extent is $4N$ samples, where $N$ is the dimension of the input (i.e., 4, 16, or 64 for 1D, 2D, or 3D cases) [S1, unofficial].
- As complexity increases, quality increases, but so does computation [S1, unofficial].

**Strengths and Limitations:**
- Strengths: C0 and C1 continuity prevents high-frequency leakage artifacts [S1, unofficial]. Tunable parameters allow trade-offs between blurring, ringing, and anisotropy [S1, unofficial]. Limited spatial extent [S1, unofficial].
- Limitations: Higher computational cost than linear or nearest-neighbor [S1, unofficial]. Can produce values outside the input range, requiring clamping [S1, unofficial].

**When to Use:**
- Use when smoother results than linear interpolation are needed and computational resources allow for 64 samples per point [S2, unofficial].
- Use when specific artifact characteristics (ringing vs. blurring) need to be tuned via B and C parameters [S1, unofficial].

## Background
Originated from Mitchell and Netravali's work on reconstruction filters [Mitchell 88], as cited in [S1, unofficial]. The method is designed to provide C0 and C1 continuity to prevent high-frequency leakage artifacts [S1, unofficial]. It is used in volume rendering for publication-quality imagery [S1, unofficial].
