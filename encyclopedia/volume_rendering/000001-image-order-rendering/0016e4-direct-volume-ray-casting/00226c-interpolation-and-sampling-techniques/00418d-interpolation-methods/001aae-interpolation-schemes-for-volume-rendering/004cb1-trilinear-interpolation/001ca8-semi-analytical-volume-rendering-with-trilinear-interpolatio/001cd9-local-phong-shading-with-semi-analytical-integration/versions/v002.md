# Local Phong Shading with Semi-Analytical Integration

Also called: Quadratic Shading Integration, Semi-Analytical Volume Rendering with Shading

## Overview
This method extends semi-analytical volume rendering by incorporating local Phong diffuse shading into the integration process [S1]. It solves the problem of accurate lighting in volume rendering by reconstructing the shading function as a quadratic polynomial along the ray, allowing for analytical integration of the light contribution [S1]. It sets itself apart from scalar-only semi-analytical methods by requiring at most one additional sampling point per cell to capture the shading extremum, while maintaining the topological accuracy of the underlying trilinear interpolation [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Trilinear interpolation coefficients for the scalar field $s(x,y,z)$ within a hexahedral cell; light direction vector $\vec{L} = (l_x, l_y, l_z)$; preintegration tables $C_{front}$, $C_{back}$, and $\alpha$; ray segment parameters $t_{start}, t_{end}$ within the cell [S1].
*   **Outputs:** Integrated color contribution $I$ for the ray segment, accounting for shading [S1].

**Data Structures:**
The method relies on the trilinear coefficients $s_{ijk}$ (where $i,j,k \in \{0,1\}$) defining the scalar field $s(x,y,z)$ in the unit cube [S1]. The shading function is represented by quadratic coefficients $e, f, g$ for $d(t) = e t^2 + f t + g$ [S1].

**Steps:**
1.  Compute the analytical gradient $\nabla s(x,y,z)$ from the trilinear coefficients [S1]. Compute the diffuse shading function $d(x,y,z) = \nabla s(x,y,z) \cdot \vec{L}$ [S1].
2.  Parametrize the ray as $x(t), y(t), z(t)$ for $t \in [0, L]$ (local cell coordinates) [S1]. Substitute into $d(x,y,z)$ to obtain the quadratic form $d(t) = e \cdot t^2 + f \cdot t + g$, where $e, f, g$ are computed from the gradient coefficients and ray parameters [S1]. For a parametrized ray inside a cell, the gradient variation over this ray is thus a quadratic form in $t$ [S1].
3.  Find the local extremum $r$ of $d(t)$ by setting the derivative to zero: $r = -f / (2e)$ [S1]. Since $d(t)$ is a quadratic polynomial, there is at most a single local extremum $r$ [S1].
4.  Sample the shading function at the cell entry ($t=0$), cell exit ($t=L$), and the local extremum $r$ (if $0 < r < L$) [S1]. This requires at most one additional sampling point per cell compared to the scalar-only method [S1].
5.  Split the ray segment $[0, L]$ at the extremum $r$ into $[0, r]$ and $[r, L]$ (if $r$ is within the interval) [S1]. The integral becomes:
    $$I = \int_0^r c(s(t))d(t)e^{-\int_0^t \tau(s(u))du} dt + \int_r^L c(s(t))d(t)e^{-\int_0^t \tau(s(u))du} dt$$ [S1].
6.  Approximate the scalar field $s(t)$ as linear between sample points [S1]. For the full cell with extremum $r$, the total integral is approximated using preintegration functions:
    $$I \approx d(s(0)) C_{front}(s(0), s(r), r) + d(s(r)) C_{back}(s(0), s(r), r) + (1 - \alpha(s(0), s(r), r)) [ d(s(r)) C_{front}(s(r), s(L), L-r) + d(s(L)) C_{back}(s(r), s(L), L-r) ]$$ [S1].
7.  Preintegration functions are defined as:
    $$C_{back}(a, b, l) = \int_0^1 c((1-t') a + t' b) t' e^{-\int_0^{t'} \tau((1-t') a + t' b) l du} dt'$$
    $$C_{front}(a, b, l) = \int_0^1 c((1-t') a + t' b) (1-t') e^{-\int_0^{t'} \tau((1-t') a + t' b) l du} dt'$$
    $$\alpha(a, b, l) = 1 - e^{-\int_0^1 \tau((1-t') b + t' a) l dt'}$$
    where $a, b$ are scalar values at interval endpoints, $l$ is the interval length, and $c(\cdot), \tau(\cdot)$ are the color and absorption transfer functions [S1].

**Pseudocode:**
```python
def integrate_local_phong_shading(s_coeffs, L_vec, t_start, t_end, C_front, C_back, alpha, c_func, tau_func):
    # 1. Compute quadratic coefficients e, f, g for d(t) from gradient and ray [S1]
    e, f, g = compute_shading_quadratic(s_coeffs, L_vec)
    
    # 2. Find local extremum r of d(t) = e*t^2 + f*t + g [S1]
    if abs(e) > 1e-9:
        r = -f / (2.0 * e)
    else:
        r = None  # Linear case, no internal extremum
        
    # 3. Determine integration intervals based on extremum [S1]
    if r is not None and t_start < r < t_end:
        t1, t2, t3 = t_start, r, t_end
    else:
        t1, t2, t3 = t_start, t_end, t_end
        
    # 4. Sample shading function d(t) at interval boundaries [S1]
    d1 = e*t1*t1 + f*t1 + g
    d2 = e*t2*t2 + f*t2 + g
    d3 = e*t3*t3 + f*t3 + g
    
    # 5. Compute scalar values s(t) at boundaries (linear interpolation assumed) [S1]
    s1 = sample_scalar(s_coeffs, t1)
    s2 = sample_scalar(s_coeffs, t2)
    s3 = sample_scalar(s_coeffs, t3)
    
    # 6. Compute interval lengths
    l1 = t2 - t1
    l2 = t3 - t2
    
    # 7. Evaluate preintegration functions [S1]
    cf1 = C_front(s1, s2, l1)
    cb1 = C_back(s1, s2, l1)
    a1 = alpha(s1, s2, l1)
    
    cf2 = C_front(s2, s3, l2)
    cb2 = C_back(s2, s3, l2)
    
    # 8. Apply split-interval approximation formula [S1]
    I = d1 * cf1 + d2 * cb1
    if l2 > 0:
        I += (1.0 - a1) * (d2 * cf2 + d3 * cb2)
        
    return I
```

**Pitfalls:**
*   **Discontinuity:** The reconstructed scalar field is only $C^0$ continuous across cell faces. Consequently, the gradient $\nabla s$ is discontinuous, causing shading discontinuities across cell boundaries [S1].
*   **Extremum Handling:** If the extremum $r$ lies outside the cell interval $[0, L]$, the shading function is monotonic within the cell, and no split is needed.

## Operating characteristics
*   **Complexity:** Adds at most one additional sample per cell compared to scalar-only semi-analytical rendering [S1].
*   **Performance:** Not given in the sources for specific hardware performance metrics.
*   **Strengths:** Captures local lighting variations within cells [S1].
*   **Limitations:** Shading discontinuities at cell faces may be visible due to $C^0$ continuity of the scalar field [S1].

## Background
This method is an extension of the semi-analytical volume rendering approach for AMR (Adaptive Mesh Refinement) data, presented by Marchesin et al. in 2009 [S1]. It builds on the trilinear interpolation-based semi-analytical integration described in the parent article.
