# First Order Integration (Trapezoid Rule)

Also called: Linear Interpolation Approximation, Linear approximation, Linear interpolation integration, Standard pre-integrated volume rendering

## Overview
First Order Integration approximates the volume rendering integral by assuming a linear interpolation of the scalar field between two discrete sample points, corresponding to the trapezoid rule [S1, unofficial][S2]. Unlike the piecewise-constant Riemann sum used in zero-order integration, this method captures higher frequencies of the transfer function, reducing visual artifacts caused by discontinuities between consecutive samples [S1, unofficial][S2]. It sets itself apart by requiring pre-computation of integrals into a lookup table indexed by segment endpoints and length, rather than evaluating the transfer function per sample [S2].

## How it works
**Inputs:**
*   Scalar field values at the front endpoint ($s_f$) and back endpoint ($s_b$) of a ray segment.
*   Length of the ray segment ($l$).
*   Transfer function mapping scalar values to color ($q$) and extinction coefficient ($\kappa$).

**Outputs:**
*   Pre-computed transparency ($T$) and color contribution ($c$) for the segment, stored in a 3D lookup table.

**Data Structures:**
*   **3D Lookup Table (LUT):** A 3D array indexed by $(s_f, s_b, l)$.
    *   Dimensions: Determined by the quantization of $s_f$, $s_b$, and $l$.
    *   Content: Each entry stores the pre-integrated transparency and color contribution for the segment defined by those parameters.

**Steps:**
1.  **Define Linear Interpolation:** Approximate the scalar field $s(x)$ within a ray segment of length $l$ as a linear interpolation between the front sample $s_f$ and back sample $s_b$. Let $x$ be the distance from the front endpoint ($0 \le x \le l$). The scalar value at position $x$ is:
    $$ s(x) = s_f + \frac{s_b - s_f}{l} x $$
2.  **Compose with Transfer Function:** The extinction coefficient $\kappa(x)$ and chromaticity (color contribution density) $q(x)$ are obtained by applying the transfer function to the interpolated scalar field:
    $$ \kappa(x) = \kappa(s(x)) $$
    $$ q(x) = q(s(x)) $$
3.  **Integrate over Segment:** Compute the transparency $T$ and color contribution $c$ for the segment by integrating the composed functions over the segment length $l$.
    *   Transparency:
        $$ T = \exp\left( -\int_0^l \kappa(s(x)) \, dx \right) $$
    *   Color Contribution:
        $$ c = \int_0^l q(s(x)) \exp\left( -\int_0^x \kappa(s(u)) \, du \right) \, dx $$
    *   Note: These integrals generally do not have closed-form solutions for arbitrary transfer functions and must be computed numerically during pre-processing.
4.  **Store in LUT:** Store the computed $T$ and $c$ in the 3D lookup table at the index corresponding to $(s_f, s_b, l)$.

**Parameters:**
*   $s_f$: Scalar value at the front endpoint of the ray segment [S2].
*   $s_b$: Scalar value at the back endpoint of the ray segment [S2].
*   $l$: Length of the ray segment [S2].

**Edge Cases and Pitfalls:**
*   **Continuity:** The reconstructed signal is $C^0$ continuous globally but not $C^1$ continuous inside a dual voxel (between two sample points) [S2]. This lack of $C^1$ continuity is sufficient to capture high frequencies of the transfer function but may still exhibit some artifacts if sampling is too coarse [S2].
*   **Pre-computation Requirement:** Unlike zero-order integration, first-order integration requires pre-integration because the scalar field is not constant [S2]. This increases memory usage due to the 3D LUT [S2].
*   **Sampling Distance:** The sampling distance $l$ affects the computation of color and opacity values, making it a necessary index for the LUT [S2].

## Operating characteristics
*   **Time Complexity:** Pre-computation is offline. Runtime rendering involves 3D texture lookups, which are fast, but the LUT size can be large.
*   **Memory Complexity:** Requires a 3D lookup table indexed by $(s_f, s_b, l)$. The size depends on the resolution of each dimension. Not given in the sources.
*   **Performance:** Better convergence than zero-order approximation, capturing higher frequencies of the transfer function [S2]. However, it is more computationally expensive than zero-order methods due to the need for pre-integration and larger memory footprint [S2].
*   **Strengths:** Reduces visual artifacts from discontinuities between samples; captures high frequencies of the transfer function [S2].
*   **Limitations:** Requires pre-computation; memory intensive due to 3D LUT; not $C^1$ continuous [S2].
*   **When to use:** When higher visual quality is needed than zero-order integration provides, and pre-computation time/memory is acceptable [S2].
*   **When not to use:** When memory is constrained or real-time pre-computation is not feasible [S2].

## Background
First Order Integration, also known as the trapezoid rule approximation in volume rendering, was proposed to improve rendering quality by capturing high frequencies of the transfer function [S2]. It addresses the significant approximation error and visual artifacts associated with zero-order (piecewise-constant) integration, which is not even $C^0$ continuous [S2]. The method builds on the concept of pre-integrated volume rendering, where integrals are pre-computed and stored in lookup tables [S2].
