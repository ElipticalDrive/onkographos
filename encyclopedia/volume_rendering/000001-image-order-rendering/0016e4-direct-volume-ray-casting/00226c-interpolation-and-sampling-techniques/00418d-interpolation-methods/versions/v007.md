# Interpolation Methods

Also called: Interpolation Schemes

## Overview
Interpolation methods approximate a continuous volumetric field $V(\mathbf{p})$ from discrete samples $V_i$ located at grid positions $\mathbf{p}_i$ to determine values at arbitrary query points $\mathbf{p}$ along a viewing ray [S1, unofficial][S2, unofficial]. This family is distinguished from sibling methods like [Depth to Distance Conversion](2428-depth-to-distance-conversion.md) and [Sampling and Jittering](2516-sampling-and-sampling.md) by its specific focus on the spatial weighting kernel used to blend neighbor values, rather than the geometric placement of samples or the conversion of depth parameters. It sets itself apart from [Adaptive Undersampling](5397-adaptive-undersampling.md) by providing a deterministic or stochastic estimate of the continuous function at every sample step, rather than skipping steps based on error metrics.

## Shared principles
All methods in this family operate on the principle that a continuous function $V(\mathbf{p})$ must be approximated from a discrete set of samples $V_i$ located at grid positions $\mathbf{p}_i$. The core mechanism involves:

1.  **Query Positioning**: Determining the 3D coordinate $\mathbf{p}$ along the ray $r(t) = \mathbf{o} + t\mathbf{d}$ where a value is needed. This may involve converting depth parameters to physical distances or warping coordinates for neural encodings.
2.  **Kernel/Weight Application**: Computing weights $w_i(\mathbf{p})$ based on the distance between $\mathbf{p}$ and the sample centers $\mathbf{p}_i$. The interpolated value is:
    $$
    V(\mathbf{p}) = \sum_{i} w_i(\mathbf{p}) V_i
    $$
    The choice of kernel (e.g., linear, cubic, inverse distance) determines the spatial extent (number of neighbors) and frequency response (aliasing vs. blurring) [S1, unofficial][S2, unofficial].
3.  **Coordinate Transformation**: Mapping world-space or camera-space coordinates to the local coordinate system of the volume data (e.g., normalized $[-1, 1]$ or $[0, 1]$ ranges) before interpolation .

## Subtopics

### [Alpha Grid Mask](2430-alpha-grid-mask.md)
A module that samples alpha (opacity) values from a precomputed 3D alpha volume using grid sampling with normalized coordinates. It enables efficient ray filtering based on opacity by providing a differentiable interface to query alpha values at arbitrary 3D coordinates. It sets itself apart from sibling interpolation methods by specifically targeting alpha/mask volumes for culling or weighting, often leveraging hardware-accelerated grid sampling routines (e.g., PyTorch's `grid_sample`) rather than manual kernel implementations.

### [Gradient-Based Interpolation by Sample Splatting](9072-gradient-based-interpolation-by-sample-splatting.md)
A real-time technique for reconstructing source radiance $L_x$ in inhomogeneous, single-scattering media from a sparse set of sample points. It solves the problem of severe rendering artifacts (such as broken light shafts and incorrect volumetric shadows) that occur when standard interpolation methods (like RBF) fail to capture high-frequency shading variations near light sources. Unlike sibling methods that rely solely on radiance values, this method uses both the radiance value and its spatial gradient at each sample point to construct a first-order Taylor approximation, significantly reducing relative error (4.3% vs 14.7% for RBF) while maintaining real-time performance.

### [Shape-Based Interpolation](10499-shape-based-interpolation.md)
A technique primarily used for surface rendering that preserves the geometric integrity of objects during the interpolation process. Unlike standard volume interpolation methods that blend scalar values directly, SBI converts the object or surface into an intermediate "scene" representation, interpolates this scene, and then extracts the final interpolated surface. This approach solves the problem of shape distortion and blurring inherent in traditional filtering, ensuring that sharp boundaries and topological features are maintained.

### [Interblock Interpolation](11155-interblock-interpolation.md)
A data reduction technique used in GPU-based volume ray casting to handle missing samples between spatial blocks by interpolating from neighboring block samples. It enables significantly higher data reduction ratios (up to 80:1) compared to standard replication methods, allowing for efficient rendering of large volumes with limited memory bandwidth. It differs from sibling methods like [Volumetric Ray Casting with Trilinear Interpolation](13406-volumetric-ray-casting-with-trilinear-interpolation.md) by operating on block-level neighborhoods rather than individual voxel grids, trading local continuity for massive compression.

### [Nearest Neighbor Sampling](11694-nearest-neighbor-sampling.md)
A volume rendering interpolation technique that assigns the value of the single grid sample closest to the ray's current position. It solves the problem of estimating continuous volume data from discrete samples by selecting the nearest neighbor rather than blending multiple values. Unlike trilinear interpolation, which blends eight neighboring points to provide $C^0$ smoothness, nearest neighbor produces piecewise constant, discontinuous results. It is chosen when execution speed is prioritized over visual quality, as it yields the poorest visual results due to jagged edges and staircasing artifacts.

### [Inverse Distance Weighting Interpolation](13925-inverse-distance-weighting-interpolation.md)
A spatial interpolation method that estimates a value at a query point by computing a weighted average of known sample values, where weights are inversely proportional to the distance between the query point and the samples. In the context of volume rendering and point cloud processing, it is typically implemented using the $k$-nearest neighbors (k-NN) to limit computational cost and ensure local smoothness. It differs from Nearest Neighbor Sampling by providing continuous, differentiable results, and from Linear Interpolation by allowing arbitrary numbers of neighbors ($k \ge 1$) and non-grid-aligned sampling positions, though it generally produces smoother results than nearest-neighbor but less sharp detail than higher-order kernels like Lanczos.

### [Color and Normal Weighted Interpolation](14922-color-and-normal-weighted-interpolation.md)
A volume rendering technique designed to reduce per-resampling-point computational cost by minimizing expensive lighting calculations and relying on interpolated attributes. It solves the problem of high computational load in direct volume ray casting, specifically for visualizing complex explosion fields and shock waves, by reducing the number of lighting operations from eight to one per sample point. Unlike standard trilinear interpolation which may suffer from interface color confusion, this method improves display accuracy of microstructures and corrects interface artifacts without affecting the rendering of translucent media.

### [Kernel-based Resampling](16228-kernel-based-resampling.md)
Approximates a continuous volumetric field $V(\mathbf{p})$ from discrete samples $V_i$ by convolving the data with a spatially localized weight function (kernel) centered at the query position $\mathbf{p}$ along the viewing ray. It solves the discretization artifacts inherent in nearest-neighbor sampling by providing a continuous, differentiable estimate of the volume value. It sets itself apart from sibling methods like [Nearest Neighbor Sampling](11694-nearest-neighbor-sampling.md) by utilizing multiple neighbors to reduce aliasing, and from [Gradient-Based Interpolation by Sample Splatting](9072-gradient-based-interpolation-by-sample-splatting.md) by relying on scalar weight functions rather than geometric splatting primitives.

## Background
The distinction between nearest neighbor and trilinear interpolation is a fundamental concept in volume visualization, with trilinear interpolation noted for improving image quality at the cost of substantially increased computational effort [S1, unofficial]. The choice of interpolation method is directly connected to the quality of the resulting images [S1, unofficial]. Higher-order interpolation methods have been explored in template-based ray casting, where connected cells allow for multiple samples along continuous rays, enabling the precomputation of interpolation functions in tables for faster rendering [S3, unofficial].
