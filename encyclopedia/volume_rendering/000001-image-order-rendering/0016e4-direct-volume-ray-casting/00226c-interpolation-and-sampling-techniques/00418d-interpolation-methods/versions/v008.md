# Interpolation Methods

Also called: Interpolation Schemes

## Overview
Interpolation Methods approximate a continuous volumetric function $V(\mathbf{p})$ from discrete grid samples $V_i$ to determine values at arbitrary query positions $\mathbf{p}$ along a viewing ray. This family solves the discretization artifacts inherent in raw voxel data, such as aliasing and geometric inaccuracies, by providing continuous estimates of scalar fields, colors, opacities, and gradients [S1, unofficial][S2, unofficial]. It sets itself apart from sibling methods like [Depth to Distance Conversion](2428-depth-to-distance-conversion.md) and [Sampling and Jittering](2516-sampling-and-sampling.md) by focusing specifically on the spatial weighting and kernel application required to reconstruct the signal between sample centers, rather than on ray parameterization or noise reduction.

## Shared principles
All methods in this family operate on the principle that a continuous function $V(\mathbf{p})$ must be approximated from a discrete set of samples $V_i$ located at grid positions $\mathbf{p}_i$. The core mechanism involves:

1.  **Query Positioning**: Determining the 3D coordinate $\mathbf{p}$ along the ray $r(t) = \mathbf{o} + t\mathbf{d}$ where a value is needed. This may involve converting depth parameters to physical distances or warping coordinates for neural encodings.
2.  **Kernel/Weight Application**: Computing weights $w_i(\mathbf{p})$ based on the distance between $\mathbf{p}$ and the sample centers $\mathbf{p}_i$. The interpolated value is:
    $$
    V(\mathbf{p}) = \sum_{i} w_i(\mathbf{p}) V_i
    $$
    The choice of kernel (e.g., linear, cubic, inverse distance) determines the spatial extent (number of neighbors) and frequency response (aliasing vs. blurring) [S1, unofficial][S2, unofficial].
3.  **Coordinate Transformation**: Mapping world-space or camera-space coordinates to the local coordinate system of the volume data (e.g., normalized $[-1, 1]$ or $[0, 1]$ ranges) before interpolation .

## Subtopics

### [Alpha Grid Mask](2430-alpha-grid-mask.md)
A module that samples alpha values from a precomputed 3D volume using hardware-accelerated grid sampling with normalized coordinates. It sets itself apart by targeting alpha/mask volumes for efficient culling or weighting, leveraging routines like PyTorch's `grid_sample` rather than manual kernel implementations.

### [Gradient-Based Interpolation by Sample Splatting](9072-gradient-based-interpolation-by-sample-splatting.md)
A real-time technique for reconstructing source radiance in inhomogeneous media from sparse samples. It uses both radiance values and spatial gradients to construct first-order Taylor approximations, significantly reducing shading errors near light sources compared to standard RBF or nearest-neighbor methods.

### [Shape-Based Interpolation](10499-shape-based-interpolation.md)
A surface rendering technique that preserves geometric integrity by converting the object into an intermediate scene representation, interpolating the scene, and then extracting the surface. This prevents the shape distortion and blurring inherent in traditional scalar value blending.

### [Interblock Interpolation](11155-interblock-interpolation.md)
A data reduction technique for GPU-based ray casting that interpolates missing samples between spatial blocks using neighboring block samples. It enables high data reduction ratios (up to 80:1) by operating on block-level neighborhoods rather than individual voxels, trading local continuity for compression.

### [Nearest Neighbor Sampling](11694-nearest-neighbor-sampling.md)
Assigns the value of the single closest grid sample. It produces piecewise constant, discontinuous results with jagged edges, chosen only when execution speed is prioritized over visual quality.

### [Pre-filtered Cubic B-spline Interpolation](13450-pre-filtered-cubic-b-spline-interpolation.md)
Replaces trilinear interpolation with cubic B-spline basis functions to improve sampling accuracy. It solves aliasing and geometric inaccuracies without increasing memory footprint, using a lightweight pre-processing step and local lookups during ray evaluation.

### [Inverse Distance Weighting Interpolation](13925-inverse-distance-weighting-interpolation.md)
Estimates values using a weighted average of $k$-nearest neighbors where weights are inversely proportional to distance. It provides continuous, differentiable results for arbitrary sampling positions, smoother than nearest-neighbor but less sharp than higher-order kernels like Lanczos.

### [Opacity-Weighted Trilinear Interpolation Volume Rendering](14920-opacity-weighted-trilinear-interpolation-volume-rendering.md)
Improves visual accuracy by interpolating the product of opacity and material color, rather than interpolating them separately. This prevents interface color confusion and Mach band artifacts common in methods that interpolate shaded voxel colors.

### [Color and Normal Weighted Interpolation](14922-color-and-normal-weighted-interpolation.md)
Reduces computational cost by minimizing expensive lighting calculations, performing exactly one lighting operation per resampling point while interpolating color, opacity, and normal vectors. It improves display accuracy of microstructures and corrects interface artifacts.

### [Kernel-based Resampling](16228-kernel-based-resampling.md)
Approximates the continuous field by convolving data with a spatially localized weight function. It sets itself apart by utilizing multiple neighbors to reduce aliasing, relying on scalar weight functions rather than geometric splatting primitives.

## Background
The choice of interpolation method is directly connected to the quality of the resulting images in volume rendering [S1, unofficial]. Standard Trilinear Interpolation is an important feature in classification routines, although the computational effort substantially increases [S1, unofficial]. Nearest neighbor and trilinear interpolation are two primary methods described for interpolating ray sample values, with nearest neighbor being the simplest and trilinear providing improved image quality at higher cost [S1, unofficial].
