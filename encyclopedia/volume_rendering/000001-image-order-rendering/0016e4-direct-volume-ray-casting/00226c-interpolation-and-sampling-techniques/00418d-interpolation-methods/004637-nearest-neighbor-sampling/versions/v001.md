# Nearest Neighbor Sampling

Also called: Nearest Neighbour Sampling, Vizinho mais próximo

## Overview
Nearest Neighbor Sampling is a voxel interpolation technique that retrieves the value of the single voxel whose integer coordinates are closest to the ray's current position [S1, unofficial][S2, unofficial]. It serves as a fallback or low-cost alternative when higher-order interpolation is not required or when computational resources are constrained [S2, unofficial]. Unlike trilinear interpolation, which combines neighboring samples to produce smoother results, Nearest Neighbor Sampling selects only the closest sample, resulting in lower image quality but significantly reduced execution time [S1, unofficial].

## How it works
**Inputs and outputs:**
- Input: Ray position $\mathbf{p} = (x, y, z)$ in voxel space.
- Output: Scalar value $V(\mathbf{p})$ from the volume dataset.

**Data structures:**
- The volume is stored as a 3D grid of voxels.
- The position $\mathbf{p}$ is a floating-point coordinate.

**Steps:**
1. Compute the integer coordinates of the closest voxel by rounding the ray position $\mathbf{p}$ to the nearest integer.
   $$
   i = \text{round}(x), \quad j = \text{round}(y), \quad k = \text{round}(z)
   $$
2. Retrieve the value at the computed integer coordinates $(i, j, k)$ from the volume dataset.
   $$
   V(\mathbf{p}) = V(i, j, k)
   $$

**Pseudocode:**
```python
def nearest_neighbor_sample(p, volume):
    """
    Sample the volume at position p using nearest neighbor interpolation.
    
    Args:
        p: Tuple (x, y, z) of floating-point coordinates in voxel space.
        volume: 3D array representing the volume dataset.
        
    Returns:
        Scalar value at the nearest voxel.
    """
    # Round coordinates to nearest integer
    i = round(p[0])
    j = round(p[1])
    k = round(p[2])
    
    # Retrieve value at integer coordinates
    # Note: Boundary checks should be applied if p is outside the volume bounds [G]
    return volume[i, j, k]
```

**Edge cases and pitfalls:**
- **Boundary conditions:** If the ray position $\mathbf{p}$ is outside the volume bounds, the rounded coordinates may be out of range. Implementers must clamp indices or handle out-of-bounds access appropriately [G].
- **Precision:** Rounding behavior at exactly half-integer values (e.g., 0.5) depends on the rounding mode (round half up, round half to even, etc.). Consistency with the volume grid definition is required [G].

## Subtopics

### Trilinear Interpolation
Combines 8 neighboring voxels using linear weights. Chosen when smoothness is prioritized over speed. [Trilinear Interpolation](10527-trilinear-interpolation.md)

### Bilinear Interpolation
2D version of trilinear. Used for texture sampling in volume rendering contexts where one dimension is uniform. [Bilinear Interpolation](10528-bilinear-interpolation.md)

### Box Filtering
Averages values within a voxel's extent. Produces smoother results than nearest neighbor but is more expensive. [Box Filtering](10529-box-filtering.md)

## Operating characteristics
- **Time complexity:** $O(1)$ per sample. Only rounding and a single memory lookup are required.
- **Memory complexity:** $O(1)$ auxiliary memory.
- **Performance:** Significantly faster than trilinear or higher-order interpolation methods [S1, unofficial].
- **Quality:** Produces blocky, aliased images due to the lack of smoothing between voxels [S1, unofficial].
- **When to use:** Real-time applications with strict performance constraints, or when the volume resolution is sufficiently high that aliasing is less perceptible.
- **When not to use:** High-quality offline rendering where visual smoothness is critical.

## Background
Nearest Neighbor Sampling is a fundamental interpolation technique in computer graphics, widely used in texture mapping and volume rendering. Its simplicity makes it a common baseline for comparison with more sophisticated methods. The technique is discussed in various educational resources and practical implementations of volume ray casting [S1, unofficial][S2, unofficial].
