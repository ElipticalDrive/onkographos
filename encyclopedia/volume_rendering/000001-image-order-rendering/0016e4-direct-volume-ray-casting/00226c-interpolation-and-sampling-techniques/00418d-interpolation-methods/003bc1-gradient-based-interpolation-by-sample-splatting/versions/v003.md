# Gradient-Based Interpolation by Sample Splatting

Also called: Gradient-Based Interpolation, Gradient-based Interpolation for Source Radiance

## Overview
Gradient-Based Interpolation by Sample Splatting is a real-time technique for reconstructing source radiance $L_x$ in inhomogeneous, single-scattering media from a sparse set of sample points [S1]. It solves the problem of severe rendering artifacts (such as broken light shafts and incorrect volumetric shadows) that occur when standard interpolation methods (like RBF) fail to capture high-frequency shading variations near light sources [S1]. Unlike sibling methods that rely solely on radiance values, this method uses both the radiance value and its spatial gradient at each sample point to construct a first-order Taylor approximation, significantly reducing relative error (4.3% vs 14.7% for RBF) while maintaining real-time performance [S1].

## How it works
The method operates in three phases: (1) computing source radiance and gradients at sparse sample points, (2) splatting these samples into a 3D volume texture to interpolate radiance at all voxels, and (3) ray marching through the resulting volume texture to compute final image radiance [S1].

### Inputs and Outputs
*   **Inputs**:
    *   Scene geometry and density field $D(\mathbf{x})$.
    *   Light source parameters (e.g., point source intensity $I_0$, position $\mathbf{s}$).
    *   View parameters (camera position $\mathbf{o}$, direction $\mathbf{d}$).
    *   User-defined intervals $\Delta_1$ (for source radiance tracing) and $\Delta_2$ (for gradient estimation) [S1].
*   **Outputs**:
    *   A 3D volume texture containing the interpolated source radiance $L_x$ at every voxel [S1].
    *   The final rendered image after ray marching [S1].

### Data Structures
*   **Sample**: Defined by a tuple $(\mathbf{x}_j, L_{\mathbf{x}_j}, \nabla L_{\mathbf{x}_j}, R_j)$ [S1].
    *   $\mathbf{x}_j$: 3D position in the media volume.
    *   $L_{\mathbf{x}_j}$: Scalar source radiance at $\mathbf{x}_j$.
    *   $\nabla L_{\mathbf{x}_j}$: 3D vector gradient of source radiance at $\mathbf{x}_j$.
    *   $R_j$: Valid radius of the sample. In the reference implementation, $R_j = 3r_j$, where $r_j$ is the culling radius of the corresponding Gaussian center $c_j$ (where $\mathbf{x}_j = c_j$) [S1].
*   **Valid Sphere**: The sphere centered at $\mathbf{x}_j$ with radius $R_j$. A sample $j$ contributes to the interpolation of a point $\mathbf{x}$ if $\|\mathbf{x} - \mathbf{x}_j\| < R_j$ [S1].
*   **3D Volume Texture**: Stores the interpolated source radiance $L_x$ for all voxels in the volume [S1].

### Step-by-Step Method

#### 1. Sample Point Selection
Sample points $\{\mathbf{x}_j\}$ are dynamically distributed in the medium to minimize shading error [S1]. The reference implementation uses a recursive sample splitting procedure [S1]. For comparison with RBF, samples may be taken from Gaussian centers $c_j$ of a density representation [S1].

#### 2. Evaluate Source Radiance and Gradient at Samples
For each sample point $\mathbf{x}_j$:

**A. Compute Source Radiance $L_{\mathbf{x}_j}$**
Evaluate the integral along the ray from $\mathbf{x}_j$ to the light source $\mathbf{s}$ [S1]. The source radiance for a point source is given by:
$$
L_{\mathbf{x}_j} = \frac{I_0}{4\pi d_{s\mathbf{x}_j}^2} \tau_{s\mathbf{x}_j}
$$
where $d_{s\mathbf{x}_j}$ is the distance from source to $\mathbf{x}_j$, and $\tau_{s\mathbf{x}_j}$ is the transmittance [S1]. Transmittance is computed via discrete volume tracing at intervals of $\Delta_1$ [S1]:
$$
\tau_{s\mathbf{x}_j} = \exp\left(-\sigma_t \Delta_1 \sum_{u \in \mathbb{U}} D(u)\right)
$$
where $\mathbb{U} = \{u_k : u_k = \mathbf{x}_j + \mathbf{v} k \Delta_1, k = 0, 1, \dots \lfloor \|\mathbf{s} - \mathbf{x}_j\|/\Delta_1 \rfloor \}$, $\mathbf{v} = (\mathbf{s} - \mathbf{x}_j)/\|\mathbf{s} - \mathbf{x}_j\|$, and $u_k \in \mathbb{V}$ (inside the volume) [S1].

**B. Compute Gradient $\nabla L_{\mathbf{x}_j}$**
Numerically evaluate the gradient using central differences at six points surrounding $\mathbf{x}_j$ along the X, Y, and Z axes with interval $\Delta_2$ [S1]:
$$
\nabla L_{\mathbf{x}_j} = \left( \frac{L_{\mathbf{x}_j + \Delta_2 \mathbf{x}} - L_{\mathbf{x}_j - \Delta_2 \mathbf{x}}}{2\Delta_2}, \frac{L_{\mathbf{x}_j + \Delta_2 \mathbf{y}} - L_{\mathbf{x}_j - \Delta_2 \mathbf{y}}}{2\Delta_2}, \frac{L_{\mathbf{x}_j + \Delta_2 \mathbf{z}} - L_{\mathbf{x}_j - \Delta_2 \mathbf{z}}}{2\Delta_2} \right)
$$
where $L_{\mathbf{x}_j \pm \Delta_2 \mathbf{x}}$ etc. are computed using the same volume tracing procedure as in step A [S1].

#### 3. Gradient-Based Interpolation by Sample Splatting
Reconstruct $L_{\mathbf{x}}$ for all points $\mathbf{x}$ in the volume using the samples [S1]. The interpolation is a weighted average of first-order Taylor approximations [S1]:
$$
L_{\mathbf{x}} = \frac{\sum_{j \in S} W_j(\mathbf{x}) \left( L_{\mathbf{x}_j} + (\mathbf{x} - \mathbf{x}_j) \cdot \nabla L_{\mathbf{x}_j} \right)}{\sum_{j \in S} W_j(\mathbf{x})}
$$
where $S = \{j : \|\mathbf{x} - \mathbf{x}_j\| < R_j\}$ and the weight function is $W_j(\mathbf{x}) = R_j / \|\mathbf{x} - \mathbf{x}_j\|$ [S1].

**Implementation via Splatting (GPU):**
1.  **Intersection**: For each sample $j$, intersect its valid sphere with each X-Y slice of the volume (assuming +Z aligned to viewing axis) [S1].
2.  **Bounding Quads**: Find the bounding quads of the intersection circles for each slice [S1].
3.  **Grouping**: Group bounding quads by slice [S1].
4.  **Rendering**: For each slice, render the bounding quads with alpha blending enabled [S1].
    *   For each pixel (representing a point $\mathbf{x}$ in the slice), evaluate and accumulate two values:
        *   Numerator term: $N_j(\mathbf{x}) = W_j(\mathbf{x}) \left( L_{\mathbf{x}_j} + (\mathbf{x} - \mathbf{x}_j) \cdot \nabla L_{\mathbf{x}_j} \right)$
        *   Denominator term: $D_j(\mathbf{x}) = W_j(\mathbf{x})$
    *   Accumulate these into two separate buffers (or textures) for the slice [S1].
5.  **Division**: After all samples are splatted, compute $L_{\mathbf{x}} = N(\mathbf{x}) / D(\mathbf{x})$ for each pixel [S1].
6.  **Volume Texture**: Render the result into a 3D volume texture [S1].

#### 4. Final Radiance Computation
Perform a ray march to discretely compute the integral in Eq. (2) for final radiance [S1]:
$$
L = \frac{I_0}{d_{sv}^2} \tau_{sv} + \frac{\Omega}{4\pi} \int_{x_{out}}^{x_{in}} D(x) L_x \tau_{xv} dx
$$
where the first term is direct transmission and the second is single scattered radiance [S1]. The integral is computed using the interpolated $L_x$ values from the volume texture [S1].

### Pseudocode

```python
def gradient_based_interpolation_by_sample_splatting(scene, view_params, delta1, delta2):
    """
    Reconstructs source radiance in a volume using gradient-based interpolation.
    
    Args:
        scene: Contains density field D(x), light sources, geometry.
        view_params: Camera position, direction, volume bounds.
        delta1: Step size for source radiance tracing.
        delta2: Step size for gradient estimation.
        
    Returns:
        final_image: Rendered image.
    """
    
    # 1. Dynamic Sampling (Simplified: using Gaussian centers for reference)
    samples = get_dynamic_samples(scene.density_field)
    
    # 2. Evaluate Source Radiance and Gradient at Samples
    for sample in samples:
        x_j = sample.position
        R_j = 3 * sample.culling_radius  # Reference implementation
        
        # Compute Source Radiance L_xj
        # Trace ray from x_j to light source s
        direction = normalize(scene.light_source.position - x_j)
        distance = length(scene.light_source.position - x_j)
        
        # Discrete integration for transmittance
        sum_density = 0.0
        num_steps = int(distance / delta1)
        for k in range(num_steps + 1):
            u_k = x_j + direction * k * delta1
            if is_inside_volume(u_k, scene.volume_bounds):
                sum_density += scene.density_field(u_k)
        
        transmittance = exp(-scene.extinction_coefficient * delta1 * sum_density)
        L_xj = (scene.light_source.intensity / (4 * PI * distance**2)) * transmittance
        sample.L = L_xj
        
        # Compute Gradient Nabla L_xj
        # Central differences along X, Y, Z axes
        grad_x = (trace_source_radiance(x_j + delta2 * vec(1,0,0), scene) - 
                  trace_source_radiance(x_j - delta2 * vec(1,0,0), scene)) / (2 * delta2)
        grad_y = (trace_source_radiance(x_j + delta2 * vec(0,1,0), scene) - 
                  trace_source_radiance(x_j - delta2 * vec(0,1,0), scene)) / (2 * delta2)
        grad_z = (trace_source_radiance(x_j + delta2 * vec(0,0,1), scene) - 
                  trace_source_radiance(x_j - delta2 * vec(0,0,1), scene)) / (2 * delta2)
        sample.gradient = vec(grad_x, grad_y, grad_z)
        
        sample.valid_radius = R_j

    # 3. Gradient-Based Interpolation by Sample Splatting
    # Initialize accumulation buffers for numerator and denominator
    volume_texture_num = create_3d_texture(scene.volume_resolution)
    volume_texture_den = create_3d_texture(scene.volume_resolution)
    
    # Iterate over each sample and splat into volume
    for sample in samples:
        x_j = sample.position
        L_xj = sample.L
        grad_L_xj = sample.gradient
        R_j = sample.valid_radius
        
        # Determine bounding box of valid sphere in volume coordinates
        min_x = max(0, floor(x_j.x - R_j))
        max_x = min(width, ceil(x_j.x + R_j))
        min_y = max(0, floor(x_j.y - R_j))
        max_y = min(height, ceil(x_j.y + R_j))
        min_z = max(0, floor(x_j.z - R_j))
        max_z = min(depth, ceil(x_j.z + R_j))
        
        # Render bounding quads for each Z slice (assuming Z is viewing axis)
        for z in range(min_z, max_z + 1):
            # Calculate intersection circle radius at this Z slice
            dist_z_sq = (z - x_j.z)**2
            if dist_z_sq >= R_j**2:
                continue
            circle_radius = sqrt(R_j**2 - dist_z_sq)
            
            # Bounding quad for this slice
            quad_min_x = max(0, floor(x_j.x - circle_radius))
            quad_max_x = min(width, ceil(x_j.x + circle_radius))
            quad_min_y = max(0, floor(x_j.y - circle_radius))
            quad_max_y = min(height, ceil(x_j.y + circle_radius))
            
            # For each pixel in the quad
            for y in range(quad_min_y, quad_max_y + 1):
                for x in range(quad_min_x, quad_max_x + 1):
                    # Point x in world space (assuming voxel centers)
                    point_x = vec(x + 0.5, y + 0.5, z + 0.5)
                    
                    # Check if point is inside valid sphere
                    dist_sq = length_sq(point_x - x_j)
                    if dist_sq >= R_j**2:
                        continue
                    
                    dist = sqrt(dist_sq)
                    
                    # Weight function W_j(x) = R_j / ||x - x_j||
                    W_j = R_j / dist
                    
                    # Taylor approximation: L_xj + (x - x_j) . grad_L_xj
                    displacement = point_x - x_j
                    approx_L = L_xj + dot(displacement, grad_L_xj)
                    
                    # Accumulate numerator and denominator
                    volume_texture_num[x, y, z] += W_j * approx_L
                    volume_texture_den[x, y, z] += W_j

    # Compute final interpolated source radiance
    for z in range(scene.volume_resolution.z):
        for y in range(scene.volume_resolution.y):
            for x in range(scene.volume_resolution.x):
                if volume_texture_den[x, y, z] > 0:
                    volume_texture[x, y, z] = volume_texture_num[x, y, z] / volume_texture_den[x, y, z]
                else:
                    volume_texture[x, y, z] = 0.0

    # 4. Final Radiance Computation (Ray Marching)
    final_image = render_with_ray_marching(scene, view_params, volume_texture)
    
    return final_image

def trace_source_radiance(point_x, scene):
    """Helper to compute source radiance at a given point."""
    # Same logic as in step 2A
    direction = normalize(scene.light_source.position - point_x)
    distance = length(scene.light_source.position - point_x)
    sum_density = 0.0
    num_steps = int(distance / delta1) # delta1 from outer scope
    for k in range(num_steps + 1):
        u_k = point_x + direction * k * delta1
        if is_inside_volume(u_k, scene.volume_bounds):
            sum_density += scene.density_field(u_k)
    transmittance = exp(-scene.extinction_coefficient * delta1 * sum_density)
    return (scene.light_source.intensity / (4 * PI * distance**2)) * transmittance
```

### Parameters
*   $\Delta_1$: User-defined step size for volume tracing to compute source radiance. Controls precision of $L_{\mathbf{x}_j}$ [S1].
*   $\Delta_2$: User-defined step size for numerical gradient estimation. Controls precision of $\nabla L_{\mathbf{x}_j}$ [S1].
*   $R_j$: Valid radius. In the reference implementation, $R_j = 3r_j$ where $r_j$ is the culling radius of the corresponding Gaussian center [S1].

### Edge Cases and Pitfalls
*   **Sharp Shading Variations**: RBF-based methods fail with sharp shading variations (e.g., light shafts, volumetric shadows) caused by local/directional/high-frequency illumination, producing severe artifacts [S1]. This method handles them well [S1].
*   **Precision**: The precision of numerical evaluation is controlled by $\Delta_1$ and $\Delta_2$. Smaller values increase accuracy but also computation time [S1].
*   **Boundary Conditions**: When tracing rays for source radiance or gradients, points may exit the volume $\mathbb{V}$. The summation should only include points $u_k \in \mathbb{V}$ [S1].
*   **Division by Zero**: If no samples contribute to a voxel (denominator is zero), the interpolated radiance should be set to 0 or a default value [G].

## Operating characteristics
*   **Time Complexity**: The method is designed for real-time performance. The source radiance and gradient computations are parallelized on the GPU [S1]. The splatting process involves rendering bounding quads, which is efficient on modern GPUs [S1].
*   **Memory Complexity**: Requires storage for the sample set and a 3D volume texture for interpolated source radiance [S1].
*   **Measured Performance**: In the reference implementation, the method achieves real-time performance (e.g., 23.4 fps) for dynamic lighting and scenes [S1].
*   **Accuracy**: Relative error of 4.3% compared to 14.7% for RBF-based interpolation at comparable performance levels [S1].
*   **Strengths**: Captures all-frequency shading effects (glows, light shafts, volumetric shadows) in real-time [S1]. No precomputation of light transport is needed [S1]. Supports dynamic changes in lighting, media, and scene configurations [S1].
*   **Limitations**: Assumes single scattering [S1]. Accuracy depends on the dynamic sampling strategy; poor sampling can lead to artifacts [S1].
