# Alpha Grid Mask

Also called: Alpha Grid Mask Sampling, Alpha Volume Sampling

## Overview
Alpha Grid Mask is a module that samples alpha (opacity) values from a precomputed 3D alpha volume using grid sampling with normalized coordinates [S1, unofficial][S2, unofficial][S3, unofficial]. It enables ray filtering based on opacity by providing an interface to query alpha values at arbitrary 3D coordinates [S2, unofficial]. It sets itself apart from sibling interpolation methods by specifically targeting alpha/mask volumes for culling or weighting, leveraging PyTorch's `grid_sample` primitive rather than manual kernel implementations [S1, unofficial][S2, unofficial].

## How it works
The method maps world-space or camera-space query points to the local coordinate system of a discrete 3D alpha volume, then retrieves interpolated values using trilinear interpolation via a grid sampling primitive [S3, unofficial].

**Inputs and Outputs:**
*   **Input:** A set of 3D query points $\mathbf{p} \in \mathbb{R}^3$ (shape $[N, 3]$) and an internal 3D alpha volume tensor [S1, unofficial][S2, unofficial].
*   **Output:** A tensor of sampled alpha values $\alpha \in \mathbb{R}$ (shape $[N]$) [S1, unofficial][S2, unofficial].

**Data Structures:**
The module maintains the following state:
*   `device`: Torch device for tensor operations [S2, unofficial].
*   `aabb`: Axis-aligned bounding box defined by min and max coordinates, shape $[2, 3]$ [S1, unofficial][S2, unofficial].
*   `aabbSize`: Computed as `self.aabb[1] - self.aabb[0]`, shape $[3]$ [S2, unofficial].
*   `invgridSize`: Scaling factor for normalization. Defined as `2.0 / (self.aabb[1] - self.aabb[0])` or equivalently `1.0 / self.aabbSize * 2`. If `aabbSize` is a vector $[3]$, `invgridSize` is also a vector $[3]$ [S2, unofficial].
*   `alpha_volume`: The 3D alpha tensor. Sources describe it as shape $[1, 1, H, W, D]$ or $[1, 1, D, H, W]$ depending on the specific implementation variant [S2, unofficial][S3, unofficial].
*   `gridSize`: LongTensor of shape $[3]$ containing the dimensions of the alpha volume [S2, unofficial][S3, unofficial].

**Steps:**
1.  **Normalization**: Convert query points $\mathbf{p}$ from world space to the normalized range $[-1, 1]$ used by the grid sampler [S1, unofficial][S2, unofficial][S3, unofficial].
    $$
    \mathbf{p}_{norm} = (\mathbf{p} - \mathbf{aabb}_{min}) \cdot \mathbf{invgridSize} - 1
    $$
    Where $\mathbf{aabb}_{min}$ is `self.aabb[0]` and $\mathbf{invgridSize}$ is `self.invgridSize` [S1, unofficial][S2, unofficial][S3, unofficial].
2.  **Reshaping**: Reshape $\mathbf{p}_{norm}$ to match the expected input format for the grid sampling function. Typically, this involves adding batch and depth dimensions to become shape $[1, N, 1, 1, 3]$ [S1, unofficial][S2, unofficial][S3, unofficial].
3.  **Sampling**: Call the grid sampling function (e.g., `F.grid_sample`) with `align_corners=True` [S1, unofficial].
    $$
    \alpha_{raw} = \text{grid\_sample}(\text{alpha\_volume}, \mathbf{p}_{norm}, \text{align\_corners}=\text{True})
    $$
    This performs trilinear interpolation of the alpha values [S1, unofficial][S2, unofficial][S3, unofficial].
4.  **Reshaping Output**: Reshape the result from $[1, N, 1, 1, 1]$ to $[N]$ [S1, unofficial][S2, unofficial][S3, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

class AlphaGridMask:
    def __init__(self, alpha_volume, aabb, device='cuda'):
        """
        Initialize Alpha Grid Mask.
        
        Args:
            alpha_volume: Tensor of shape [1, 1, D, H, W] or [1, 1, H, W, D] containing alpha values.
            aabb: Tensor of shape [2, 3] defining the bounding box [min_coords, max_coords].
            device: Device for tensor operations.
        """
        self.device = device
        self.alpha_volume = alpha_volume.to(device)
        self.aabb = aabb.to(device)
        
        # Compute bounding box size
        self.aabbSize = self.aabb[1] - self.aabb[0]  # Shape [3]
        
        # Compute inverse grid size for normalization
        # Note: Sources indicate invgridSize is computed as 1.0/aabbSize * 2.
        # If aabbSize is [3], invgridSize is [3].
        self.invgridSize = 1.0 / self.aabbSize * 2.0  # Shape [3]
        
        # Store grid size for reference
        self.gridSize = torch.tensor(alpha_volume.shape[-3:], dtype=torch.long, device=device)

    def normalize_coord(self, xyz_sampled):
        """
        Normalize coordinates to [-1, 1] range.
        
        Args:
            xyz_sampled: Tensor of shape [N, 3] or [..., 3].
            
        Returns:
            Normalized coordinates in [-1, 1].
        """
        # Formula: (xyz - aabb_min) * invgridSize - 1
        return (xyz_sampled - self.aabb[0]) * self.invgridSize - 1

    def sample_alpha(self, xyz_sampled):
        """
        Sample alpha values from the precomputed alpha volume.
        
        Args:
            xyz_sampled: Tensor of shape [N, 3] containing query points.
            
        Returns:
            Tensor of shape [N] containing sampled alpha values.
        """
        # 1. Normalize coordinates
        xyz_norm = self.normalize_coord(xyz_sampled)
        
        # 2. Reshape for grid_sample: [N, 3] -> [1, N, 1, 1, 3]
        # grid_sample expects input of shape [B, H_out, W_out, D_out, 3] or similar depending on dim order.
        # Standard PyTorch grid_sample for 3D expects [B, D_out, H_out, W_out, 3] if input is [B, C, D, H, W].
        # However, source snippets show view(1, -1, 1, 1, 3). We follow the source structure.
        xyz_reshaped = xyz_norm.view(1, -1, 1, 1, 3)
        
        # 3. Sample using grid_sample with align_corners=True
        # Source [S2, unofficial] uses F.grid_sample(self.alpha_volume, xyz_reshaped, align_corners=True)
        # Source [S3, unofficial] uses similar logic.
        alpha_vals = F.grid_sample(
            self.alpha_volume, 
            xyz_reshaped, 
            align_corners=True
        )
        
        # 4. Reshape output to [N]
        return alpha_vals.view(-1)
```

**Parameters:**
*   `align_corners`: Boolean, typically `True` [S1, unofficial][S2, unofficial][S3, unofficial].
*   `aabb`: Axis-aligned bounding box [S1, unofficial].
*   `alpha_volume`: 3D tensor of alpha values [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Coordinate Bounds**: Points outside the `aabb` will be sampled with boundary values (clamped or padded depending on `grid_sample` mode, default is usually 'border' or 'zeros' in some contexts, but `align_corners` affects the mapping of grid edges) [G].
*   **Dimensionality**: The `invgridSize` calculation involves division by `aabbSize`. If `aabbSize` is a vector $[3]$, `invgridSize` becomes a vector $[3]$. The broadcasting in the normalization formula `(xyz_sampled - self.aabb[0]) * self.invgridSize - 1` works correctly if `xyz_sampled` has shape $[..., 3]$ [S2, unofficial].
*   **Tensor Shape**: The `alpha_volume` shape must match the expectations of the grid sampling function. Sources vary between $[1, 1, H, W, D]$ and $[1, 1, D, H, W]$ [S2, unofficial][S3, unofficial].

## Background
Alpha Grid Mask is a component found in implementations of Tensorial Radiance Fields and related neural rendering frameworks [S1, unofficial][S2, unofficial]. It leverages PyTorch's `grid_sample` function to provide a convenient interface for sampling from 3D grids [S2, unofficial]. The method is used in contexts where opacity information needs to be efficiently queried during volume rendering or novel view synthesis [S1, unofficial][S3, unofficial].
