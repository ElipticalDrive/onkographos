# Inverse Distance Weighting Interpolation


## Overview
Inverse Distance Weighting Interpolation estimates a value at a query point by computing a weighted average of known sample values, where weights are inversely proportional to the distance between the query point and the samples [S1, unofficial]. In point cloud processing, it is typically implemented using the $k$-nearest neighbors ($k$-NN) to limit computational cost and ensure local smoothness [G]. It differs from Nearest Neighbor Sampling by using multiple neighbors to produce smoother results [G].

## How it works
**Inputs and Outputs:**
*   **Source Points:** Coordinates $\mathbf{xyz} \in \mathbb{R}^{m \times 3}$ and feature vectors $\mathbf{feat} \in \mathbb{R}^{m \times c}$ [S1, unofficial].
*   **Query Points:** Coordinates $\mathbf{new\_xyz} \in \mathbb{R}^{n \times 3}$ [S1, unofficial].
*   **Parameters:** Integer $k$ (number of neighbors), scalar $\epsilon = 10^{-8}$ (regularization constant) [S1, unofficial].
*   **Batch Offsets:** Arrays $\mathbf{offset}$ and $\mathbf{new\_offset}$ of size $b$ for batched processing [S1, unofficial].
*   **Output:** Interpolated features $\mathbf{new\_feat} \in \mathbb{R}^{n \times c}$ [S1, unofficial].

**Data Structures:**
*   Indices array $\mathbf{idx} \in \mathbb{Z}^{n \times k}$ storing the indices of the $k$ nearest neighbors in $\mathbf{xyz}$ for each query point [S1, unofficial].
*   Distances array $\mathbf{dist} \in \mathbb{R}^{n \times k}$ storing the Euclidean distances to these neighbors [S1, unofficial].

**Steps:**
1.  **Neighbor Search:** Perform $k$-nearest neighbor query to find indices $\mathbf{idx}$ and distances $\mathbf{dist}$ for each point in $\mathbf{new\_xyz}$ relative to $\mathbf{xyz}$ [S1, unofficial].
2.  **Initialization:** Initialize output tensor $\mathbf{new\_feat}$ of shape $(n, c)$ to zeros [S1, unofficial].
3.  **Reciprocal Distance:** Compute reciprocal distances with epsilon regularization: $r_{j,i} = \frac{1}{\mathbf{dist}_{j,i} + \epsilon}$ for $i = 1 \dots k$ [S1, unofficial].
4.  **Weight Normalization:** Normalize weights by summing reciprocals along the neighbor dimension: $w_{j,i} = \frac{r_{j,i}}{\sum_{l=1}^{k} r_{j,l}}$ [S1, unofficial].
5.  **Feature Aggregation:** Loop over $k$ neighbors and accumulate weighted features: $\mathbf{new\_feat}_j \mathrel{+}= \mathbf{feat}_{\mathbf{idx}_{j,i}} \cdot w_{j,i}$ for $i = 1 \dots k$ [S1, unofficial].

**Pseudocode:**
```python
import numpy as np

def inverse_distance_weighting_interpolation(xyz, new_xyz, feat, k, epsilon=1e-8):
    """
    Interpolate features from source points to query points using k-NN IDW.
    
    Args:
        xyz: (m, 3) array of source coordinates.
        new_xyz: (n, 3) array of query coordinates.
        feat: (m, c) array of source features.
        k: int, number of neighbors.
        epsilon: float, regularization term to prevent division by zero.
        
    Returns:
        new_feat: (n, c) array of interpolated features.
    """
    n = new_xyz.shape[0]
    c = feat.shape[1]
    new_feat = np.zeros((n, c))
    
    # Step 1: k-NN query (brute-force for clarity)
    diff = new_xyz[:, np.newaxis, :] - xyz[np.newaxis, :, :]
    dist_sq = np.sum(diff ** 2, axis=2)
    idx = np.argsort(dist_sq, axis=1)[:, :k]
    dist = np.sqrt(np.take_along_axis(dist_sq, idx, axis=1))
    
    # Step 2: Reciprocal distances with epsilon regularization
    dist_recip = 1.0 / (dist + epsilon)
    
    # Step 3: Normalize weights along the neighbor dimension
    norm = np.sum(dist_recip, axis=1, keepdims=True)
    weights = dist_recip / norm
    
    # Step 4: Accumulate weighted features over k neighbors
    for i in range(k):
        new_feat += feat[idx[:, i]] * weights[:, i:i+1]
        
    return new_feat
```

**Edge Cases and Pitfalls:**
*   **Division by Zero:** If a query point coincides exactly with a source point, the distance is 0. Adding $\epsilon = 10^{-8}$ to the distance before inversion prevents numerical instability [S1, unofficial].

### 3-Nearest Neighbors Interpolation
A baseline method similar to Closest Point, but linearly interpolates the displacements of the three nearest triangular mesh vertices, with coefficients inversely related to distances [S2]. It is used in mesh deformation and displacement mapping tasks [S2].
