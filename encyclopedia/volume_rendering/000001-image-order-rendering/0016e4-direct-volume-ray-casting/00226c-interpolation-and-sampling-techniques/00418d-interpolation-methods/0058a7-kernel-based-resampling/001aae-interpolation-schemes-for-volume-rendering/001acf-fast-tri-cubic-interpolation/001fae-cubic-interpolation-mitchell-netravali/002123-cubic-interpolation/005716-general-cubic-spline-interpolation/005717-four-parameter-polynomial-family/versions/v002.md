# Four-parameter polynomial family
Also called: Four-parameter polynomial, Generalized Catmull-Rom family

## Overview
The four-parameter polynomial family is a set of fourth-order piecewise polynomials defined by a single parameter $a$, which generalizes the Catmull-Rom spline. It solves the need for smooth interpolation with tunable continuity properties, specifically allowing for continuous second derivatives when $a = -1/2$. It differs from its parent, General Cubic Spline Interpolation, by using fourth-order polynomials instead of third-order ones, thereby gaining the ability to enforce $C^2$ continuity (continuous second derivative) which is impossible with cubic splines.

## Shared principles
The family defines a symmetric, piecewise fourth-order reconstruction filter $h(x)$ with support $[-2, 2]$. The function is defined such that $h(x) = h(-x)$ for $x < 0$. For the positive half of the domain, the filter is composed of two fourth-order polynomials controlled by the parameter $a$:

$$
h(x) = 
\begin{cases} 
ax^4 + \left(a - \frac{5}{2}\right)x^3 + \left(a - \frac{3}{2}\right)x^2 + 1 & 0 \le x < 1 \\
ax^4 + \left(6a - \frac{1}{2}\right)x^3 + \left(-13a + \frac{5}{2}\right)x^2 + (12a - 4)x + (2 - 4a) & 1 \le x < 2 \\
0 & \text{otherwise}
\end{cases}
$$

The parameter $a$ is the free variable that shapes the filter [S1, unofficial]. The function is continuous and has a continuous first derivative for all values of $a$ [S1, unofficial].

Specific values of $a$ yield distinct properties:
1.  **Catmull-Rom Spline:** When $a = 0$, the function reduces to the standard Catmull-Rom cubic-spline interpolation function [S1, unofficial].
2.  **Continuous Second Derivative:** When $a = -1/2$, the function possesses a continuous second derivative ($C^2$ continuity) [S1, unofficial]. This is the only polynomial in this specific family form that achieves $C^2$ continuity while maintaining the support and symmetry constraints described.

## Subtopics

### Catmull-Rom Spline
*   **What it is:** The specific instance of the four-parameter polynomial family where $a = 0$.
*   **Distinction:** It is a cubic interpolating spline (despite being a subset of a fourth-order family definition, the $a=0$ terms reduce the highest order terms to zero in the relevant intervals or simplify to cubic forms consistent with Catmull-Rom). It guarantees interpolation of the input data points.
*   **When to choose:** When standard Catmull-Rom behavior is desired, which is common in computer graphics for smooth curve fitting through control points.
*   **Link:** [Catmull-Rom Spline](52-catmull-rom-spline.md)

### B-Spline (Cubic)
*   **What it is:** While not directly a member of the $a$-parameterized fourth-order family in the same way Catmull-Rom is, the cubic B-spline is noted as the only cubic-spline function with a continuous second derivative.
*   **Distinction:** Unlike the Catmull-Rom subset ($a=0$), the B-spline does not interpolate the data points (it is a smoothing spline). However, it achieves $C^2$ continuity within the cubic constraint space.
*   **When to choose:** When $C^2$ continuity is required but interpolation of the original sample points is not necessary, or when a smoother, less oscillatory result is preferred over the interpolating Catmull-Rom.
*   **Link:** [Cubic B-Spline](53-cubic-b-spline.md)

## Background
The four-parameter polynomial family was introduced in the context of speed and accuracy analysis for medical volume rendering [S1, unofficial]. The formulation allows for the derivation of reconstruction filters using more than four sample points, although this significantly increases the complexity of the 3D algorithm [S1, unofficial]. The family highlights the trade-off between interpolation accuracy and derivative continuity, noting that while the Catmull-Rom spline ($a=0$) is a real interpolation function, it lacks continuous second derivatives. The parameter $a=-1/2$ is identified as the unique solution within this polynomial structure that provides continuous second derivatives.
