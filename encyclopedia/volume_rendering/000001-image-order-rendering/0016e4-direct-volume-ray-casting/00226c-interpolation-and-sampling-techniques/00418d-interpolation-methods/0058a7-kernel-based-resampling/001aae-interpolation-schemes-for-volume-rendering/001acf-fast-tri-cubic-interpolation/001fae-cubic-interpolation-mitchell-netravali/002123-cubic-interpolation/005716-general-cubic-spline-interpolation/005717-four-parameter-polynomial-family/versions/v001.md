# Four-parameter polynomial family
Also called: Four-parameter polynomial, Generalized Catmull-Rom family

## Overview
The four-parameter polynomial family is a set of fourth-order polynomials parameterized by $a$ that generalizes the Catmull-Rom spline for volume rendering interpolation [S1, unofficial]. It extends the cubic interpolation capabilities of its parent by allowing control over higher-order continuity, specifically enabling a continuous second derivative when $a = -1/2$ [S1, unofficial].

## Shared principles
This family defines a reconstruction filter $h(x)$ using a single parameter $a$. The function is symmetric and defined piecewise over the support $[-2, 2]$. For $x < 0$, $h(x) = h(-x)$. The positive half is defined as:

$$
h(x) = 
\begin{cases} 
ax^4 + \left(a - \frac{5}{2}\right)x^3 + \left(a - \frac{3}{2}\right)x^2 + 1 & 0 \le x < 1 \\
ax^4 + \left(6a - \frac{1}{2}\right)x^3 + \left(-13a + \frac{5}{2}\right)x^2 + (12a - 4)x + 2 - 4a & 1 \le x < 2 \\
0 & \text{otherwise}
\end{cases}
$$

The parameter $a$ controls the shape of the filter. When $a=0$, the function reduces to the standard Catmull-Rom cubic-spline interpolation function [S1, unofficial]. When $a=-1/2$, the function possesses a continuous second derivative, in addition to the continuous first derivative guaranteed for all $a$ [S1, unofficial].

## Subtopics

### Catmull-Rom Spline
The specific instance where $a=0$. It is the most common choice in this family for general-purpose volume rendering due to its balance of sharpness and smoothness [S1, unofficial].

### B-Spline Variant
The specific instance where $a=-1/2$. This variant is chosen when higher-order smoothness (continuous second derivative) is required, although it may introduce more blurring compared to the Catmull-Rom case [S1, unofficial].

## Background
The family was introduced in the context of optimizing speed and accuracy for medical volume rendering applications [S1, unofficial]. It was derived to provide a unified framework for cubic-spline functions, allowing researchers to explore the trade-offs between interpolation accuracy and derivative continuity by varying a single parameter [S1, unofficial]. The derivation notes that while polynomials using more than four sample points can be derived, they significantly increase the complexity of 3D algorithms, justifying the focus on this four-parameter subset [S1, unofficial].
