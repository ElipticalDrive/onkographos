# General Cubic Spline Interpolation
Also called: B-C Spline Family, General cubic-spline family, Mitchell-Netravali Spline Family

## Overview
The General Cubic Spline Interpolation family defines a set of symmetric, piecewise cubic reconstruction filters parameterized by $B$ and $C$ [S1, unofficial]. It solves the problem of balancing interpolation accuracy with smoothness in volume rendering by allowing continuous adjustment of the filter's shape [S1, unofficial]. It is distinct from its sibling [Catmull-Rom Interpolation](13562-catmull-rom-interpolation.md) by offering a broader parameter space, and from its child [Four-parameter polynomial family](15871-four-parameter-polynomial-family.md) by using third-order rather than fourth-order polynomials [S1, unofficial].

## Shared principles
The family defines a symmetric, piecewise cubic reconstruction filter $h(x)$ with support $[-2, 2]$. The function is defined such that $h(x) = h(-x)$ for $x < 0$. For the positive half of the domain, the filter is composed of two cubic polynomials:

$$
h(x) = 
\begin{cases} 
\left(\frac{2}{3} - \frac{B}{2} - C\right)x^3 + (-3 + 2B + C)x^2 + 1 - \frac{B}{2} & 0 \le x < 1 \\
\left(\frac{B}{2} - C\right)x^3 + (B + 5C)x^2 + \left(-\frac{B}{6} - C\right)x + \left(-2B - 8C\right)x + \frac{4B}{3} + 4C & 1 \le x < 2 \\
0 & \text{otherwise}
\end{cases}
$$

The parameters $B$ and $C$ are free variables that shape the filter [S1, unofficial]. The function is continuous, symmetrical, and has a continuous first derivative for all values of $B$ and $C$ [S1, unofficial]. Furthermore, a constant value is always reconstructed to the same value regardless of the value of $B$ and $C$ [S1, unofficial].

Specific constraints on $B$ and $C$ yield notable properties:
1.  **Interpolation:** The function acts as an interpolating filter only when $B = 0$ [S1, unofficial].
2.  **Linear Reconstruction:** To accurately reconstruct a straight line (satisfying condition 6), $B$ must equal $-2C + 1$ [S1, unofficial]. When this condition is met, the derivative at $x=1$ is automatically fixed to $-1/2$ [S1, unofficial].

The family does not guarantee interpolation (condition 4) or linear reconstruction (condition 6) unless these specific constraints are met [S1, unofficial].

## Subtopics

### [Four-parameter polynomial family](15871-four-parameter-polynomial-family.md)
A fourth-order polynomial family that generalizes Catmull-Rom interpolation. It is chosen when second-derivative continuity is required, which is not achievable with the cubic splines of this parent family.

## Background
The family was described by Mitchell and Netravali in 1988 [S1, unofficial]. It is commonly used in image processing and volume rendering to provide a tunable balance between sharpness and smoothness [S1, unofficial]. The cubic B-spline is a specific instance within this family where $B=1$ and $C=0$, resulting in an approximating rather than interpolating filter [S1, unofficial].
