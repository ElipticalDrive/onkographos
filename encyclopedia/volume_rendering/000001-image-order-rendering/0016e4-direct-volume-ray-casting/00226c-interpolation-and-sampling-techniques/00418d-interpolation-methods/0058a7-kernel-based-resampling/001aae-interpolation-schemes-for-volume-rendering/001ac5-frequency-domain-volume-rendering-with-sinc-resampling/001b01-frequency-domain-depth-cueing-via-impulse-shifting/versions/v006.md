# Frequency Domain Depth Cueing via Impulse Shifting

Also called: Shifted spectrum depth cueing, Shifted H depth cueing, Shifted spectrum depth, Frequency domain depth cueing method

## Overview
Frequency domain depth cueing via impulse shifting implements distance-based weighting entirely within the frequency domain by modifying the interpolation filter $H(s)$ to $H'(s)$ via complex shifts, avoiding explicit spatial convolution or expensive per-view 3D FFTs [S2, S5, unofficial]. It replaces the infinite spatial-domain transform of the depth cueing function with a finite cosine or sine wave, using delta functions for efficient filter construction [S1, unofficial]. This method sets itself apart from hybrid spatial-frequency approaches by requiring only a single 3D forward transform of the volume data, performing all subsequent depth cueing operations as a negligible-cost 2D filter modification evaluated strictly on the slice plane [S3, S5, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** The 3D Fourier spectrum of the volume $F(s)$ (computed once), the standard interpolation filter $H(s)$, the view vector $V$, and depth cueing parameters ($C_{cue}, C_{avg}$ or sine wave parameters) [S2, S3, S4, S5, unofficial].
*   **Output:** The depth-cued projection image for the current view [S3, S4, unofficial].

**Data Structures:**
*   **Filter $H(s)$:** A small support filter, typically $3^3$ to $5^3$ in size [S2, S3, S5, unofficial].
*   **Modified Filter $H'(s)$:** The result of convolving $H(s)$ with the Fourier transform of the depth cueing function $D(s)$ [S2, S3, S4, unofficial]. Due to the use of delta functions, $H'(s)$ consists of shifted copies of $H(s)$ with complex weights [S3, S4, S5, unofficial].

**Mathematical Foundation:**
Spatial domain depth cueing is expressed as the product $f(x) \cdot d(x) \cdot p_m(x)$, where $d(x)$ is the depth cueing function and $p_m(x)$ is vignetting compensation [S3, S4, unofficial]. In the frequency domain, this corresponds to $(F(s) * D(s) * P_m(s)) * H(s)$ [S3, S4, unofficial]. By the convolution theorem, this is equivalent to:
$$ (F(s) * P_m(s)) * (H(s) * D(s)) $$
Let $H'(s) = H(s) * D(s)$. The rendering equation becomes:
$$ F_f(x) p_m(x)g * H'(s) $$
where $F_f(x)$ is the forward transform of the volume [S4, unofficial]. Thus, depth cueing is achieved by replacing $H(s)$ with $H'(s)$ [S2, S3, unofficial].

**Implementation Steps:**

1.  **Precompute Volume Spectrum:** Compute the 3D forward FFT of the volume data $f(x)$ once. This term is independent of eye position [S3, S4, S5, unofficial].
2.  **Define Depth Cueing Function $d(x)$:**
    *   *Linear Approximation:* Use a linear ramp $d_l(x) = C_{cue}(V \cdot x) + C_{avg}$, where $V$ is the view vector, $x$ is position, $C_{cue}$ is strength, and $C_{avg}$ is a constant [S3, S4, S5, unofficial].
    *   *Sine Wave Approximation:* Use a half-period of a sine wave to highlight the middle of the volume or approximate linear cueing. Adjust origin, amplitude, and period such that the value is 0 at the farthest voxel and 1 at the closest voxel to eliminate the need for a DC term [S4, S5, unofficial]. The period is typically made long enough so the cueing appears almost linear [S4, S5, unofficial].
3.  **Compute Fourier Transform $D(s)$:**
    *   *For Linear Cueing:* The transform involves differentiation. $D_l(s) = i 2\pi C_{cue} (V \cdot s) + C_{avg} \delta(s)$, where $s = [x, y, z]$ is the differential operator [S3, S4, unofficial]. Specifically, $H'(s) = C_{cue} (V \cdot \nabla H(s)) + C_{avg} H(s)$ [S3, S4, unofficial].
    *   *For Sine Wave Cueing:* The transform of a sine wave is two delta functions (impulses). $D(s) = C_1 \delta(s - s_w) + C_2 \delta(s + s_w)$, where $C_1, C_2$ are complex constants determined by amplitude/shift, and $s_w$ is determined by the period [S3, S4, S5, unofficial].
4.  **Compute Modified Filter $H'(s)$:**
    *   Convolve $H(s)$ with $D(s)$.
    *   *For Linear Cueing:* $H'(s)$ is a linear combination of $H(s)$ and its derivatives. Since $H$ is small, this is negligible [S3, S4, unofficial].
    *   *For Sine Wave Cueing:* Convolution with delta functions shifts $H(s)$. $H'(s) = C_1 H(s - s_w) + C_2 H(s + s_w)$ [S3, S4, S5, unofficial]. This amounts to summing three shifted copies of the filter with complex weights (two for the sine wave impulses and one for the constant term, or two if the DC term is eliminated by adjusting the wave's origin and amplitude) [S4, S5, unofficial].
    *   *Optimization:* One impulse can be removed by doubling the weight of the remaining impulse to reduce kernel size [S4, S5, unofficial].
5.  **Render:** Use $H'(s)$ instead of $H(s)$ for the interpolation step during slice extraction from the stored spectrum [S3, S4, S5, unofficial].

**Pseudocode:**

```python
def compute_modified_filter(H, cue_type, view_vector, params):
    """
    Computes the modified interpolation filter H'(s) for frequency domain depth cueing.
    H: 3D array representing the interpolation filter support (e.g., 5x5x5).
    cue_type: 'linear' or 'sine'.
    view_vector: 3D vector V.
    params: dict containing Ccue, Cavg, period, amplitude, origin_shift.
    Returns: 3D array H_prime.
    """
    import numpy as np
    
    # Helper: Create frequency coordinate grid matching H's shape
    def create_freq_grid(shape):
        # Returns arrays sx, sy, sz representing spatial frequency coordinates
        # Normalized to [-0.5, 0.5] per dimension
        sx, sy, sz = np.meshgrid(
            np.arange(shape[0]) - shape[0]//2,
            np.arange(shape[1]) - shape[1]//2,
            np.arange(shape[2]) - shape[2]//2,
            indexing='ij'
        )
        return sx, sy, sz

    # Helper: Shift a 3D array by a fractional offset in frequency domain
    def shift_array(arr, offset):
        # Implements circular shift for delta convolution in frequency domain
        # offset is a 3D vector [dx, dy, dz]
        # For exact delta convolution, we perform integer shifts or interpolation
        # Here we assume H is defined on a grid and we shift indices
        ox, oy, oz = np.round(offset).astype(int)
        shifted = np.roll(np.roll(np.roll(arr, ox, axis=0), oy, axis=1), oz, axis=2)
        return shifted

    sx, sy, sz = create_freq_grid(H.shape)
    s_mag = np.sqrt(sx**2 + sy**2 + sz**2)
    
    if cue_type == 'linear':
        # H'(s) = Ccue * (V . grad H(s)) + Cavg * H(s)
        # grad H(s) in frequency domain corresponds to multiplication by i*2*pi*s
        # We approximate the gradient of H in frequency space
        # Note: Sources define D_l(s) = i 2\pi C_{cue} (V \cdot s) + C_{avg} \delta(s)
        # Convolution with D_l(s) yields the linear combination below
        Ccue = params.get('Ccue', 1.0)
        Cavg = params.get('Cavg', 0.5)
        
        # Compute directional derivative of H along V in frequency domain
        # grad_H_freq = i * 2 * pi * (V_x * sx + V_y * sy + V_z * sz) * H
        grad_H_freq = 1j * 2 * np.pi * (view_vector[0]*sx + view_vector[1]*sy + view_vector[2]*sz) * H
        H_prime = Ccue * grad_H_freq + Cavg * H
        
    elif cue_type == 'sine':
        # H'(s) = C1 * H(s - s_w) + C2 * H(s + s_w)
        period = params.get('period', 10.0)
        amplitude = params.get('amplitude', 1.0)
        origin_shift = params.get('origin_shift', 0.0)
        
        # s_w is the frequency vector corresponding to the period and view direction
        # Frequency = 1 / period. Direction = normalized view_vector.
        v_norm = view_vector / np.linalg.norm(view_vector)
        s_w = v_norm / period
        
        # Complex weights for sine wave impulses
        # C1 and C2 are determined by amplitude and phase shift
        C1 = -0.5j * amplitude * np.exp(-1j * 2 * np.pi * origin_shift / period)
        C2 =  0.5j * amplitude * np.exp( 1j * 2 * np.pi * origin_shift / period)
        
        # Shift H by +s_w and -s_w, scale by complex weights, and sum
        H_shifted_pos = shift_array(H, s_w)
        H_shifted_neg = shift_array(H, -s_w)
        
        H_prime = C1 * H_shifted_pos + C2 * H_shifted_neg
        
        # Optimization: Remove one impulse by doubling the weight of the remaining impulse
        # This makes the image complex, but the real part contains the correct projection
        # H_prime = 2 * C1 * H_shifted_pos  (if removing negative impulse)
        
    return H_prime

def render_slice(F_s, H_prime, slice_params):
    """
    Extracts a 2D slice from the 3D spectrum and applies the modified filter.
    F_s: 3D frequency domain volume.
    H_prime: Modified filter computed by compute_modified_filter.
    slice_params: dict with view_origin, view_direction, resolution.
    Returns: 2D complex array representing the depth-cued projection.
    """
    # Step 1: Extract 2D slice from 3D spectrum at the current view position
    # This is a 2D operation evaluated only on the plane of the slice being extracted [S3, S4, unofficial]
    slice_spectrum = extract_2d_slice_from_3d_spectrum(F_s, slice_params)
    
    # Step 2: Interpolate using the modified filter H'(s)
    # Convolve slice_spectrum with H_prime in the 2D frequency domain
    # Since H_prime is small, this is a direct spatial-domain convolution or frequency multiplication
    filtered_slice = convolve_2d(slice_spectrum, H_prime)
    
    # Step 3: Inverse FFT to obtain spatial domain projection
    projection = np.fft.ifft2(filtered_slice)

```

**Edge Cases and Pitfalls:**
*   **Complex Output:** Using a sine wave depth cueing with two impulses (or removing one) makes the projection image complex (non-real) [S2, S3, S4, S5, unofficial]. The imaginary part is a cosine wave (analytic signal) [S3, S4, unofficial]. The implementer must take the **real part** of the result, which contains the correct projection image [S2, S3, S4, S5, unofficial].
*   **DC Term:** If the sine wave is not adjusted to be zero at the farthest voxel, a DC term is needed, increasing kernel size [S4, S5, unofficial].
*   **Filter Size:** Removing one impulse reduces kernel size but introduces complexity [S4, S5, unofficial].

## Operating characteristics
*   **Time Complexity:** The 3D forward FFT is performed only once $O(N^3 \log N)$ [S3, S5, unofficial]. Per-view, the cost is dominated by the 2D slice extraction and interpolation. The recomputation of $H'(s)$ is negligible because the support of $H$ is small ($3^3$ to $5^3$) and $D(s)$ is a simple expression (delta functions or linear ramps) [S2, S3, S4, S5, unofficial].
*   **Memory Complexity:** Requires storing the 3D spectrum $F(s)$ and the small filter $H(s)$ [S1, S3, unofficial].
*   **Performance:** Practically free compared to spatial domain convolution or hybrid approaches requiring multiple 3D FFTs [S2, S3, S4, S5, unofficial].
*   **Strengths:** High quality (uses ideal sinc resampling via the parent method), efficient (single 3D FFT), flexible (any depth cueing function with simple Fourier transform) [S2, S3, S4, S5, unofficial].
*   **Limitations:** Produces complex intermediate results for sine-wave cueing (requires taking real part); assumes the volume is static (since 3D FFT is done once) [S2, S3, S4, S5, unofficial].

## Background
*   **Origin:** Developed as part of frequency domain volume rendering research at Stanford University [S2, S3, S5, unofficial].
*   **History:** Presented in the SIGGRAPH '93 paper "Frequency Domain Volume Rendering" [S2, S5, unofficial]. It builds on the Fourier Projection-Slice Theorem [S1, unofficial].
*   **Usage:** Used in frequency domain volume rendering to add shape cues (depth cueing and directional shading) to the basic projection-slice rendering, which lacks occlusion and shading [S3, unofficial].
