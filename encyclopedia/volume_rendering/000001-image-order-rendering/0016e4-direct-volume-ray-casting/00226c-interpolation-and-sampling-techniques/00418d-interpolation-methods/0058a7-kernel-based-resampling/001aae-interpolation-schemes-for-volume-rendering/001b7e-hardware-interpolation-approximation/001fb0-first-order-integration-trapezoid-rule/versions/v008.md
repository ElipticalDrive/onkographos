# First Order Integration (Trapezoid Rule)
Also called: Linear Interpolation Approximation, Linear approximation, Linear interpolation integration, Standard pre-integrated volume rendering

## Overview
First Order Integration approximates the volume rendering integral along a ray segment by assuming the scalar field varies linearly between two discrete samples, corresponding to the trapezoid rule [S1, unofficial][S3]. It solves the visual artifacts caused by piecewise-constant (zero-order) approximations by capturing higher frequencies of the transfer function, enabling the pre-computation of the integral into a lookup table [S3]. It sets itself apart from its parent, [Hardware Interpolation Approximation](1027-hardware-interpolation-approximation.md), by explicitly modeling the linear variation of the scalar field to allow for pre-integration, and from [Second Order Pre-Integrated Volume Rendering](3388-second-order-pre-integrated-volume-rendering.md) by using a linear rather than quadratic polynomial, resulting in higher approximation error for high-frequency fields but lower computational complexity [S1, unofficial].

## How it works
**Inputs:**
*   Scalar field samples at the front ($s_f$) and back ($s_b$) endpoints of a ray segment [S3].
*   Sampling distance $l = x_{i+1} - x_i$ [S3]. If the sampling distance is constant, $l$ can be fixed [S2, unofficial].
*   Transfer functions for opacity $\kappa(s)$ and color/emission $q(s)$ [S1, unofficial][S2, unofficial].

**Outputs:**
*   Pre-integrated opacity $T_i$ and color contribution $C_i$ for the segment [S2, unofficial][S3].

**Data Structures:**
*   A 3D lookup table (LUT) indexed by $(s_f, s_b, l)$ storing the precomputed integrals [S3]. If $l$ is constant, this reduces to a 2D table indexed by $(s_f, s_b)$ [S2, unofficial].

**Steps:**
1.  **Linear Interpolation Assumption:** Assume the scalar field $s(x)$ varies linearly between the front sample $s_f$ and back sample $s_b$ over the interval $[x_i, x_{i+1}]$ [S2, unofficial][S3].
2.  **Composition:** Compose the linearly interpolated scalar field with the transfer functions to obtain the extinction coefficient $\kappa(s(x))$ and chromaticity $q(s(x))$ [S3].
3.  **Integration:** Compute the integrals for opacity and color over the segment length $l$ [S2, unofficial].
    *   Opacity: $T_i = \exp\left(-\int_{x_i}^{x_{i+1}} \kappa(s(x)) dx\right)$ [S2, unofficial].
    *   Color: $C_i = \int_{x_i}^{x_{i+1}} q(s(x)) \exp\left(-\int_{x_i}^{x} \kappa(s(x')) dx'\right) dx$ [S2, unofficial].
4.  **Tabulation:** Pre-compute these integrals for all relevant combinations of $(s_f, s_b, l)$ and store them in the LUT [S3].
5.  **Rendering:** During ray casting, look up the pre-integrated values using the sampled $s_f$ and $s_b$ (and $l$ if variable) to composite the segment [S2, unofficial][S3].

**Formulas:**
The continuous version for a sample interval $[x_i, x_{i+1}]$ with linear $s(x)$ simplifies the integrals by changing the integration variable from $x$ to $s$ [S2, unofficial]:

$$ T_i = \exp\left(-\int_{s_i}^{s_{i+1}} \kappa(s) \frac{l}{s_{i+1}-s_i} ds \right) $$

$$ C_i = \int_{s_i}^{s_{i+1}} q(s) \exp\left(-\int_{s_i}^{s} \kappa(s') \frac{l}{s_{i+1}-s_i} ds' \right) \frac{l}{s_{i+1}-s_i} ds $$

**Parameters:**
*   $s_f, s_b$: Scalar values at front and back endpoints [S3].
*   $l$: Length of the ray segment [S3].
*   $d$: Sampling distance $x_{i+1} - x_i$ [S2, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** The approximation error is significant if the scalar field has high curvature, as the linear assumption fails to capture $C^1$ continuity within a dual voxel [S3].
*   **Boundaries:** The method assumes the transfer functions do not depend on derivatives [S2, unofficial].
*   **Degenerate Input:** If $s_f = s_b$, the linear interpolation is constant, reducing to zero-order integration [S3].

**Pseudocode:**
```python
import math

def precompute_lut(s_min, s_max, num_levels, lengths, kappa_func, q_func):
    """
    Precompute the lookup table for first order integration.
    s_min, s_max: Range of scalar values.
    num_levels: Number of discrete levels for s_f and s_b.
    lengths: List of possible segment lengths.
    kappa_func, q_func: User-defined transfer functions for extinction and color.
    """
    table = [[[None for _ in lengths] for _ in range(num_levels)] for _ in range(num_levels)]
    s_vals = [s_min + i * (s_max - s_min) / (num_levels - 1) for i in range(num_levels)]

    for i, sf in enumerate(s_vals):
        for j, sb in enumerate(s_vals):
            for k, l in enumerate(lengths):
                if abs(sb - sf) < 1e-9:
                    # Constant field case (degenerate linear interpolation)
                    k_val = kappa_func(sf)
                    q_val = q_func(sf)
                    T = math.exp(-k_val * l)
                    C = q_val * (1 - T) / k_val if k_val > 0 else q_val * l
                else:
                    T = 1.0
                    C = 0.0
                    opacity = 1.0
                    steps = 100
                    ds = (sb - sf) / steps
                    for step in range(steps):
                        s_curr = sf + step * ds
                        k_curr = kappa_func(s_curr)
                        q_curr = q_func(s_curr)
                        opacity *= math.exp(-k_curr * ds)
                        C += q_curr * opacity * ds
                    T = opacity
                table[i][j][k] = (T, C)
    return table, s_vals, lengths

def render_segment(s_f, s_b, l, table, s_vals, lengths):
    """
    Retrieve pre-integrated values for a ray segment via clamped lookup.
    """
    def clamp(val, min_val, max_val):
        return max(min_val, min(max_val, val))

    i = int(clamp(round((s_f - s_vals[0]) / (s_vals[-1] - s_vals[0]) * (len(s_vals) - 1)), 0, len(s_vals) - 1))
    j = int(clamp(round((s_b - s_vals[0]) / (s_vals[-1] - s_vals[0]) * (len(s_vals) - 1)), 0, len(s_vals) - 1))
    k = int(clamp(round((l - lengths[0]) / (lengths[-1] - lengths[0]) * (len(lengths) - 1)), 0, len(lengths) - 1))
    return table[i][j][k]
```

## Subtopics

### [Second Order Pre-Integrated Volume Rendering](3388-second-order-pre-integrated-volume-rendering.md)
Second Order Pre-Integrated Volume Rendering is a direct volume rendering technique that approximates the scalar field along a ray segment using a second-order Lagrange polynomial (quadratic) defined by three equispaced samples, allowing the volume rendering integral to be pre-computed into a lookup table. This method captures high-frequency transfer function details more accurately than linear approaches by reducing the discrepancy between the trilinearly interpolated volume and its piecewise polynomial approximation. It sets itself apart from its parent, First Order Integration (Trapezoid Rule), by using quadratic polynomials to model the non-zero curvature inherent in trilinear interpolation, thereby providing significantly reduced approximation error and faster convergence for scalar fields with high frequencies.

### [Analytic Integration for Linear Variation](5146-analytic-integration-for-linear-variation.md)
Analytic Integration for Linear Variation computes the exact volume rendering integral for optical properties that vary linearly along a ray segment. It solves the approximation errors of numerical quadrature (such as the Trapezoid Rule) when the scalar field is interpolated linearly (e.g., from tetrahedron vertices) and transfer functions are linear. Unlike First Order Integration (Trapezoid Rule), which assumes constant or linearly averaged values, this method derives a closed-form solution for the exponential integral of a linear function, providing higher accuracy for linearly interpolated data.

### [Deterministic Volume Integration](17834-deterministic-volume-integration.md)
Deterministic Volume Integration is a ray-marching technique that improves upon standard point-sampling by integrating the trilinearly interpolated feature fields over the entire length of a ray segment within a voxel, rather than evaluating them at a single point. This method addresses the error introduced by assuming density and color fields are constant between samples, providing a more accurate estimation of the volume integral compared to Monte Carlo approaches. It is distinct from Second Order Pre-Integrated Volume Rendering which handles quadratic variations, and Analytic Integration for Linear Variation which may use different basis functions or constraints.

## Operating characteristics
*   **Time Complexity:** Precomputation is $O(N^2 \cdot M)$ where $N$ is the number of scalar levels and $M$ is the number of segment lengths. Rendering is $O(1)$ per segment via LUT lookup [S3].
*   **Memory Complexity:** $O(N^2 \cdot M)$ for the LUT [S3].
*   **Measured Performance:** Hardware raycasting implementations using this method achieved 10-30 Hz for $256^3$ volumes on specialized hardware (U VIZARD, volumePRO) [S2, unofficial].
*   **Strengths:** Captures high frequencies of the transfer function better than zero-order integration; enables pre-integration for fast rendering [S3].
*   **Limitations:** Approximation error is significant for high-curvature fields; requires 3D LUT if segment length varies [S3].

*   **When not to use:** Not given in the sources.

## Background
First Order Integration, also known as the trapezoid rule in this context, was proposed as an alternative to piecewise-constant Riemann sums to reduce visual artifacts in volume rendering [S1, unofficial]. The concept of pre-integration was introduced by Engel et al. in 2001 [S2, unofficial]. It is used in direct volume ray casting to improve rendering quality by simulating infinitely many interpolated samples between discrete points [S2, unofficial].
