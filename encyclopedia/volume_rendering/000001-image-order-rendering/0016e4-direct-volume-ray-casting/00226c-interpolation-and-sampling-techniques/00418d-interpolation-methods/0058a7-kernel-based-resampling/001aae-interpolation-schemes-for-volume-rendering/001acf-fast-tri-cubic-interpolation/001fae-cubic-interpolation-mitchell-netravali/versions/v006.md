# Cubic Interpolation (Mitchell-Netravali)

Also called: Mitchell-Netravali, Mitchell-Netravali Cubic Filter

## Overview
Mitchell-Netravali cubic interpolation is a parametric family of reconstruction filters used in volume rendering to approximate scalar field values with C0 and C1 continuity, preventing high-frequency leakage artifacts common in lower-order methods [S1, unofficial]. It distinguishes itself from its parent [Fast tri-cubic interpolation](848-fast-tri-cubic-interpolation.md) by providing a general parameterized kernel rather than a fixed B-spline implementation, and from siblings like [Adaptive Filter Size for Rendering Time Reduction](861-adaptive-filter-size-for-rendering-time-reduction.md) by using a fixed support size determined by the cubic extent [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Scalar field values $v_i$ at integer grid positions, and a query position $x$ (typically a ray sample point).
- Parameters: Tuning coefficients $B$ and $C$.
- Output: Reconstructed scalar value $V(x)$.

**Data Structures:**
- The kernel $k(x)$ is a piecewise cubic polynomial.
- In 3D, the reconstruction requires a $4 \times 4 \times 4$ grid of neighboring texels (64 samples total) [S1, unofficial].

**Formula:**
The 1D kernel $k(x)$ is defined by the absolute distance $|x|$ and parameters $B, C$:

$$
k(x) = \frac{1}{6} \begin{cases} 
(12 - 9B - 6C)|x|^3 + (-18 + 12B + 6C)|x|^2 + (6 - 2B), & \text{if } |x| < 1; \\
(-B - 6C)|x|^3 + (6B + 30C)|x|^2 + (-12B - 48C)|x| + (8B + 24C), & \text{if } 1 \le |x| < 2; \\
0, & \text{otherwise.}
\end{cases}
$$

The reconstructed value is the convolution of the input samples with this kernel. In 3D, for a query point, the value is the sum of the 64 nearest neighbor values weighted by the product of their respective 1D kernel evaluations along each axis.

**Parameters:**
- $B, C$: Trade off aliasing effects (blurring, ringing, anisotropy) [S1, unofficial].
- Typical values:
  - $B=1.0, C=0.0$: Cubic B-splines [S1, unofficial].
  - $B=0.0, C=0.5$: Catmull-Rom splines [S1, unofficial].

**Steps:**
1. Determine the integer grid coordinates surrounding the query point $x$.
2. Compute the fractional offset $dx = x - \lfloor x \rfloor$.
3. For each axis, identify the 4 nearest integer indices (2 on each side of the query point).
4. For each of the 64 combinations of these indices in 3D, compute the weight $w = k(x_i - x) \cdot k(y_i - y) \cdot k(z_i - z)$.
5. Sum the products of the weights and the corresponding voxel values.
6. Clamp the result to the valid input range to prevent values outside the input range [S1, unofficial].

**Pitfalls:**
- General cubic interpolation can produce values outside the range of the inputs; clamping is required [S1, unofficial].
- The filter support is fixed at 4N samples in N dimensions (64 in 3D), which is computationally expensive compared to linear interpolation [S1, unofficial].

## Operating characteristics
- **Time Complexity:** In 3D, requires 64 nearest samples per query point [S1, unofficial].
- **Memory Complexity:** Spatial extent is $4^N$ samples, where $N$ is the dimension (4, 16, or 64 for 1D, 2D, 3D respectively) [S1, unofficial].
- **Strengths:** C0 and C1 continuity prevents high-frequency leakage artifacts; tunable parameters allow balancing between blurring and ringing [S1, unofficial].
- **Limitations:** High computational cost due to 64 texture fetches in 3D; potential for overshoot (ringing) if parameters are not tuned correctly [S1, unofficial].
- **When to use:** When visual smoothness is prioritized over performance and artifacts from linear interpolation (star patterns) are unacceptable [S1, unofficial].

## Background
The Mitchell-Netravali filter was defined by Mitchell and Netravali in 1988 [S1, unofficial]. It is widely used in volume rendering and image processing to provide high-quality reconstruction with tunable properties.
