# Analytic Integration for Linear Variation
Also called: Williams and Max method
## Overview
This method computes the exact volume rendering integral when optical properties (opacity and color) vary linearly along a ray segment, typically within a tetrahedral cell with linear scalar interpolation and linear transfer functions. It replaces the numerical trapezoid rule with a closed-form analytic solution, eliminating discretization error for this specific basis. It is distinguished from its parent [First Order Integration (Trapezoid Rule)](2077-first-order-integration-trapezoid-rule.md) by providing exact results for linear variations rather than approximations, and from [Second Order Pre-Integrated Volume Rendering](3388-second-order-pre-integrated-volume-rendering.md) by handling general tetrahedral geometry rather than restricting to voxel grids with precomputed lookup tables.
## How it works
**Inputs and Outputs:**
- Input: Ray segment defined by entry point $\mathbf{r}_0$ and exit point $\mathbf{r}_1$ within a tetrahedron. Scalar values $s_i$ at the four tetrahedron vertices $\mathbf{v}_i$ ($i=0..3$). Linear transfer functions mapping scalar $s$ to opacity $\tau(s) = a s + b$ and color $\mathbf{c}(s) = \mathbf{d} s + \mathbf{e}$.
- Output: Transmittance $T$ and accumulated color $\mathbf{C}$ over the segment.

**Data Structures:**
- Barycentric coordinates or tetrahedron geometry data to evaluate scalar $s(\mathbf{r})$ at any point $\mathbf{r}$ on the ray.
- Coefficients $a, b, \mathbf{d}, \mathbf{e}$ defining the linear transfer functions.

**Steps:**
1. **Parameterize the Ray:** Define the ray as $\mathbf{r}(t) = \mathbf{r}_0 + t(\mathbf{r}_1 - \mathbf{r}_0)$ for $t \in [0, 1]$.
2. **Evaluate Scalar Field:** The scalar value $s(t)$ along the ray is linear because the scalar field is linearly interpolated from tetrahedron vertices and the ray is a line segment. Let $s(t) = s_0 + t(s_1 - s_0)$, where $s_0 = s(\mathbf{r}_0)$ and $s_1 = s(\mathbf{r}_1)$.
3. **Define Optical Properties:** Since transfer functions are linear, opacity $\tau(t) = a s(t) + b$ and color $\mathbf{c}(t) = \mathbf{d} s(t) + \mathbf{e}$ are also linear functions of $t$.
4. **Compute Transmittance:** The transmittance $T$ is given by $T = \exp\left(-\int_0^1 \tau(t) \, dt\right)$. Since $\tau(t)$ is linear, the integral is the area of a trapezoid: $\int_0^1 \tau(t) \, dt = \frac{\tau(0) + \tau(1)}{2}$. Thus, $T = \exp\left(-\frac{\tau_0 + \tau_1}{2}\right)$, where $\tau_0 = \tau(0)$ and $\tau_1 = \tau(1)$. [G] Note: This step yields the same result as the trapezoid rule for opacity, but the color accumulation differs.
5. **Compute Accumulated Color:** The accumulated color $\mathbf{C}$ is $\mathbf{C} = \int_0^1 \mathbf{c}(t) \exp\left(-\int_0^t \tau(u) \, du\right) dt$. Let $\tau(t) = \alpha t + \beta$ and $\mathbf{c}(t) = \mathbf{\gamma} t + \mathbf{\delta}$. The inner integral is $\int_0^t (\alpha u + \beta) du = \frac{1}{2}\alpha t^2 + \beta t$. Let $E(t) = \exp\left(-\frac{1}{2}\alpha t^2 - \beta t\right)$. The integral becomes $\int_0^1 (\mathbf{\gamma} t + \mathbf{\delta}) E(t) dt$. This integral has a closed-form solution involving the error function $\text{erf}$ or can be computed numerically with high precision if the analytic form is too complex. Williams and Max [58] provided the full analytic expression. [S1, book]
6. **Handle Piecewise Linear Transfer Functions:** If the transfer function is piecewise linear, divide the tetrahedron into sub-polyhedra where the transfer function is linear, and apply the above steps to each sub-segment. [S1, book]

**Parameters:**
- Linear transfer function coefficients $a, b, \mathbf{d}, \mathbf{e}$.

**Edge Cases and Pitfalls:**
- **Numerical Stability:** The analytic expression can be numerically unstable for large opacities. Improved stability techniques were introduced in [59]. [S1, book]
- **Cycles in Visibility Sorting:** If used in a tetrahedral rendering pipeline, visibility sorting may encounter cycles, which is a separate bottleneck. [S1, book]

## Subtopics
## Operating characteristics
- **Time Complexity:** $O(1)$ per tetrahedron segment, assuming the analytic formula is evaluated directly. However, the formula is complex, so constant factors are higher than the trapezoid rule.
- **Memory Complexity:** $O(1)$ additional memory.
- **Performance:** Evaluated on GPU by Moreland and Angel [43] using precomputed texture tables to accelerate the evaluation. [S1, book]
- **Strengths:** Exact results for linear variations; no discretization error.
- **Limitations:** Complex analytic formula; numerical stability issues; requires linear scalar interpolation and linear transfer functions; visibility sorting in tetrahedral meshes can be problematic.
- **When to Use:** When exact integration is required for tetrahedral meshes with linear properties and performance allows for the complexity.
- **When Not to Use:** When using voxel grids (use [Second Order Pre-Integrated Volume Rendering](3388-second-order-pre-integrated-volume-rendering.md) instead) or when performance is critical and approximate results are acceptable (use [First Order Integration (Trapezoid Rule)](2077-first-order-integration-trapezoid-rule.md)).

## Background
First presented by Williams and Max [58]. Improved for numerical stability in [59]. Evaluated on GPU by Moreland and Angel [43] using precomputed texture tables. [S1, book]
