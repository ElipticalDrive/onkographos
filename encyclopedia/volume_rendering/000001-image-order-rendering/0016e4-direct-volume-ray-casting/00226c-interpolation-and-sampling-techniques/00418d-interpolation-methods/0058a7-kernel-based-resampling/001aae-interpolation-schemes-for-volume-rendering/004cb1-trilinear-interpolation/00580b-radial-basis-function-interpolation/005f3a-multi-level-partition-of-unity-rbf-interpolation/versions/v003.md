# Multi-level Partition-of-Unity RBF Interpolation

Also called: Local RBF Interpolation, MPU Implicit with RBF

## Overview
Multi-level Partition-of-Unity RBF Interpolation (MPU-RBF) constructs a global scalar field approximation from scattered 3D data points by blending local Radial Basis Function (RBF) interpolants [S1, unofficial]. It adapts the algorithmic structure of the Multi-level Partition-of-Unity (MPU) implicits method [S1, unofficial]. The method replaces the original piecewise quadric approximations with local RBF interpolants to achieve high interpolation quality at low computational cost [S1, unofficial]. Unlike global RBF methods that solve a dense linear system over all data points, this approach partitions data into manageable clusters using an octree to ensure scalability [S1, unofficial].

## How it works
**Inputs:** A set of scattered sample points $P = \{p_i\}$ with associated scalar values $\{f_i\}$, and an octree structure built for regularization [S1, unofficial].
**Outputs:** A continuous scalar field value $F(x)$ for any query point $x \in \mathbb{R}^3$ [S1, unofficial].

**Data Structures:**
*   **Octree Node:** Stores the cell centroid, the number of sample points contained within the cell, and the sphere of influence radius $r$ [S1, unofficial].
*   **Interpolation Node:** A selected octree node whose centroid serves as the center for a local RBF interpolant [S1, unofficial].
*   **Local Point Set $S$:** The subset of original sample points $p_i$ located within the sphere of influence of an interpolation node [S1, unofficial].

**Parameters:**
*   $\alpha = 0.75$: Scaling factor for the sphere of influence radius [S1, unofficial].
*   $c = 0.025$: Hardy’s constant for the RBF kernel [S1, unofficial].
*   $N = 100$: Maximum number of points allowed in a local matrix solver [S1, unofficial].

**Algorithm Steps:**
1. **Octree Construction and Radius Calculation:** Construct an octree for the data [S1, unofficial]. For each node, compute the number of points in the cell and the radius $r$ of the sphere of influence centered at the node's centroid [S1, unofficial].
2. **Local Point Set Collection:** For a given interpolation node, identify the set $S$ of original sample points $p_i$ that lie within the sphere of influence (distance $\le r$ from the centroid) [S1, unofficial].
3. **Threshold Enforcement:** If $|S| > N$, traverse the octree deeper to refine the partition [S1, unofficial]. If a leaf node still contains too many points, augment the tree with further subdivisions until the problem size for the local matrix solver is $\le N$ [S1, unofficial].
4. **Local Interpolant Construction:** For each interpolation node, solve for the coefficients $\lambda_i$ using the points in $S$ [S1, unofficial]. The coefficients are determined by solving the linear system $A\lambda = f$, where $A_{ij} = \phi_j(p_i)$ and $f$ contains the scalar values at points in $S$ [G].
5. **Global Approximation Evaluation:** To evaluate $F(x)$ at a query point, identify all interpolation nodes whose spheres of influence contain $x$ [S1, unofficial]. Calculate the contribution $H_k(x)$ of each local interpolant $k$, accumulate the sum of weights $W(x) = \sum_k w_k(x)$ and the sum of weighted contributions $C(x) = \sum_k w_k(x) H_k(x)$, and normalize the result by dividing the sum of contributions by the sum of weights [S1, unofficial].
6. **Efficient Evaluation:** The global approximation is evaluated using a recursive routine that traverses the octree, achieving $O(\log m)$ time complexity, where $m$ is the number of interpolation nodes [S1, unofficial].

**Formulas:**
*   Sphere of influence radius: $r = \alpha d$, where $d$ is the length of the octree node’s diagonal [S1, unofficial].
*   Hardy’s multiquadric RBF interpolant: $H(x) = \sum_{i=1}^{|S|} \lambda_i \phi_i(x)$, where $\phi_i(x) = \sqrt{|x - p_i|^2 + c^2}$ [S1, unofficial].
*   Global normalized field: $F(x) = \frac{\sum_k w_k(x) H_k(x)}{\sum_k w_k(x)}$, where $w_k(x)$ are partition-of-unity weight functions [S1, unofficial].

**Pitfalls:**
*   **Data Usage:** Only original sample points are used for interpolation; no resampling is performed, which avoids bias introduction but requires the original data to be accessible during evaluation [S1, unofficial].
*   **Precision:** The square root in Hardy’s kernel requires careful handling of floating-point precision, especially for points very close to sample locations [G].
*   **Boundary Conditions:** The method relies on partition-of-unity weight functions to blend local interpolants, ensuring smooth transitions across the domain [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Evaluation is $O(\log m)$, where $m$ is the number of interpolation nodes [S1, unofficial]. Construction involves solving local linear systems of size at most $N \times N$, which the source notes can be solved relatively quickly [S1, unofficial].
*   **Memory Complexity:** Proportional to the number of interpolation nodes and the storage of the octree and original points [S1, unofficial].
*   **Strengths:** High interpolation quality with relatively low computational cost compared to global RBF methods; handles non-uniform, scattered data without requiring a structured grid; scalable to large datasets due to local solving [S1, unofficial].
*   **Limitations:** Requires an octree structure; performance depends on the choice of parameters $\alpha$, $c$, and $N$ [S1, unofficial].
*   **When to Use:** Suitable for isosurface generation and scalar field visualization from large-scale scattered data where global methods are too expensive [S1, unofficial].

## Background
The method is based on the Multi-level Partition-of-Unity (MPU) implicits method by Ohtake et al. [S1, unofficial]. It adapts this framework by substituting local quadric approximations with Hardy’s multiquadric RBF interpolants [S1, unofficial]. The approach was developed to address the domain cover problem in isosurface generation for large-scale scattered data visualization [S1, unofficial].
