# Alpha Grid Mask

Also called: Alpha Volume Sampling

## Overview
Alpha Grid Mask is a module for sampling alpha (opacity) values from a precomputed 3D alpha volume using trilinear interpolation [S1, unofficial]. It solves the problem of incorporating spatially varying opacity constraints into volume rendering pipelines, allowing external supervision or geometry masks to influence the final image. It differs from direct intensity sampling by applying a linear remapping to sampled values to ensure they fall within a valid $[min\_opacity, max\_opacity]$ interval, preventing complete occlusion or invisibility artifacts [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of 3D query positions $\mathbf{p}$ (batched as $B \times 3$), and an internal state containing the alpha volume and bounding box metadata.
*   **Output:** A tensor of sampled alpha values $\alpha$ with shape $B$.

**Data Structures:**
The module maintains the following internal state:
*   `aabb`: A tensor of shape $[2, 3]$ representing the minimum and maximum coordinates of the axis-aligned bounding box enclosing the volume.
*   `gridSize`: A tensor of shape $[3]$ representing the resolution (dimensions) of the alpha volume along each axis.
*   `invgridSize`: A tensor of shape $[3]$ containing the element-wise reciprocal of `gridSize`.
*   `alpha_volume`: A tensor of shape $[1, 1, D, H, W]$ (or equivalent layout depending on the backend) storing the raw alpha values.

**Steps:**
1.  **Coordinate Normalization:** Transform the input query positions $\mathbf{p}$ from world space to the normalized $[-1, 1]$ range required by the grid sampling function. For each point $\mathbf{p}_i = (x, y, z)$:
    $$ \mathbf{p}'_i = (\mathbf{p}_i - \mathbf{aabb}_{min}) \odot \mathbf{invgridSize} \times 2 - 1 $$
    Where $\mathbf{aabb}_{min}$ is the first row of `aabb`, $\odot$ denotes element-wise multiplication, and the result is clamped or handled according to the grid sampler's boundary conditions. Note: The source code snippet shows `xyz_sampled = (xyz_sampled - self.aabb[0]) * self.invgridSize - 1`. This implies a specific normalization where `invgridSize` might already incorporate the scaling factor or the bounding box is defined differently. Based on the explicit code `xyz_sampled = (xyz_sampled - self.aabb[0]) * self.invgridSize - 1`, we follow this exact formula.
2.  **Grid Sampling:** Perform trilinear interpolation on `alpha_volume` using the normalized coordinates $\mathbf{p}'$. The sampling is performed with `align_corners=True`.
    $$ \alpha = \text{grid\_sample}(\text{alpha\_volume}, \mathbf{p}', \text{align\_corners}=\text{True}) $$
    The output is reshaped to a 1D tensor of size $B$.
3.  **Opacity Remapping (Implicit):** While the core sampling returns raw values, the method's purpose involves mapping these to a specified opacity range. If the raw sampled value is $\alpha_{raw}$, and the target range is $[min\_opacity, max\_opacity]$, the final opacity $\alpha_{final}$ is typically computed as:
    $$ \alpha_{final} = min\_opacity + (\alpha_{raw} - \alpha_{min}) \frac{max\_opacity - min\_opacity}{\alpha_{max} - \alpha_{min}} $$
    Where $\alpha_{min}$ and $\alpha_{max}$ are the minimum and maximum values in the `alpha_volume`. If the source does not explicitly define this remapping step in the code snippet, it is noted as a logical requirement of the "Alpha Grid Mask" description to prevent occlusion artifacts [S1, unofficial].

**Pseudocode:**
```python
def sample_alpha_grid_mask(query_points, aabb_min, invgrid_size, alpha_volume):
    """
    query_points: Tensor of shape (B, 3)
    aabb_min: Tensor of shape (3,)
    invgrid_size: Tensor of shape (3,)
    alpha_volume: Tensor of shape (1, 1, D, H, W)
    """
    # Step 1: Normalize coordinates to [-1, 1] range
    # Formula from source: xyz_sampled = (xyz_sampled - self.aabb[0]) * self.invgridSize - 1
    normalized_points = (query_points - aabb_min) * invgrid_size - 1.0
    
    # Reshape for grid_sample: (B, 1, 1, 3) -> (1, B, 1, 1, 3) if using PyTorch grid_sample
    # Note: PyTorch grid_sample expects input (N, C, H, W, D) or (N, C, H, W) and grid (N, H_out, W_out, D_out, 2/3)
    # The source uses: xyz_sampled.view(1, -1, 1, 1, 3)
    grid = normalized_points.view(1, -1, 1, 1, 3)
    
    # Step 2: Sample alpha values using grid sample with align_corners=True
    # F.grid_sample in PyTorch expects input (N, C, H, W, D) for 3D
    # Assuming alpha_volume is (1, 1, D, H, W)
    sampled = torch.nn.functional.grid_sample(
        alpha_volume, 
        grid, 
        mode='trilinear', 
        align_corners=True
    )
    
    # Reshape output to (B,)
    alpha_vals = sampled.view(-1)
    
    return alpha_vals
```

**Parameters:**
*   `align_corners`: Boolean, set to `True` in the source implementation [S1, unofficial].
*   `min_opacity`, `max_opacity`: Not explicitly defined in the code snippet but implied by the description as the target range for remapping [S1, unofficial].

**Edge Cases:**
*   **Out-of-Bounds:** Points outside the `aabb` will be sampled based on the grid sampler's padding mode (default is usually zero or border). The source does not specify a padding mode, so it defaults to the library behavior [S1, unofficial].
*   **Precision:** Trilinear interpolation is used, which may introduce smoothing artifacts compared to nearest-neighbor sampling [S1, unofficial].

## Subtopics

### [Sample Opacities from Mask](2510-sample-opacities-from-mask.md)
This method samples opacity values from a precomputed 3D alpha mask volume for a set of 3D point positions, mapping the raw mask values to a specified opacity range. It serves as the core sampling primitive for the Alpha Grid Mask module, enabling volume rendering to incorporate spatially varying opacity constraints derived from external supervision or geometry masks. It differs from direct intensity sampling by applying a linear remapping to the sampled values to ensure they fall within a valid $[min\_opacity, max\_opacity]$ interval, preventing complete occlusion or invisibility artifacts.

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of query points, as each point requires a constant number of arithmetic operations and one trilinear interpolation.
*   **Memory Complexity:** $O(D \times H \times W)$ for storing the `alpha_volume`.
*   **Strengths:** Efficiently samples precomputed opacity fields; integrates easily with differentiable rendering pipelines (e.g., PyTorch).
*   **Limitations:** Requires precomputation of the alpha volume; memory usage scales with volume resolution.
*   **When to use:** When spatially varying opacity constraints are needed and can be precomputed into a 3D grid.
*   **When not to use:** When dynamic, per-frame opacity changes are required without recomputing the grid.

## Background
The Alpha Grid Mask method originates from the implementation of Collaborative Neural Radiance Fields for Novel View Synthesis [S1, unofficial]. It is used in neural rendering pipelines to inject external opacity constraints into the volume rendering process.
