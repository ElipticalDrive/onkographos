# LOS-integration for visualization

Also called: LUT-based Line-of-Sight Integration, column_ne integration, emission integration, ewt_temp integration

## Overview
LOS-integration for visualization computes physical scalar quantities (electron column density, integrated emissivity, or emission-weighted temperature) along camera rays by sampling neural network fields or ground truth data and integrating the resulting physical values over ray segments [S1, unofficial]. It differs from standard direct volume ray casting by outputting specific physical diagnostics rather than just RGB color, utilizing a lookup table (LUT) or field query for emissivity coefficients and handling unit conversions for astrophysical contexts (e.g., solar corona) [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Ray origins `rays_o` $(N, 3)$, ray directions `rays_d` $(N, 3)$, sample start times `t_s` $(M,)$, sample end times `t_e` $(M,)$, ray indices `ray_idx` $(M,)$, validity mask `valid` $(N,)$, and configuration parameters (`quantity`, `uniform_samples`, `r_min_rsun`, `r_max_rsun`, `channels`) [S1, unofficial].
*   **Outputs:** A tensor `full` of shape $(N, C)$, where $N$ is the number of rays and $C$ is the number of output channels (spectral lines or scalar values). Invalid rays contain `NaN` [S1, unofficial].

**Data Structures:**
*   `rays_o`, `rays_d`: Float tensors representing ray geometry.
*   `t_s`, `t_e`: Float tensors representing parametric distances along rays.
*   `ray_idx`: Integer tensor mapping each sample to its parent ray.
*   `valid`: Boolean mask for rays that are within the viewing frustum/valid range.
*   `log_ne`, `log_temp`: Logarithmic electron density and temperature values sampled at 3D coordinates.
*   `ccoef`: Emissivity coefficients retrieved from a field/LUT based on $(\log n_e, \log T, \log r)$ [S1, unofficial].

**Steps:**
1.  **Ray Preparation:** Convert `rays_o` and `rays_d` to the renderer's dtype and device [S1, unofficial].
2.  **Sampling:**
    *   If `uniform_samples > 0`, generate uniform samples along the ray shell to obtain `t_s`, `t_e`, `ray_idx`, and `valid` [S1, unofficial].
    *   Otherwise, use pre-computed points along rays [S1, unofficial].
3.  **Coordinate Conversion:**
    *   Compute midpoints: $t_{mid} = 0.5 \times (t_s + t_e)$ [S1, unofficial].
    *   Compute Cartesian coordinates in AABB space: $x_{AABB} = \text{rays\_o}[valid][ray\_idx] + t_{mid} \times \text{rays\_d}[valid][ray\_idx]$ [S1, unofficial].
    *   Scale to physical units: $x_{xyz} = x_{AABB} \times \text{aabb\_scale}$ [S1, unofficial].
4.  **Radial Masking:**
    *   Compute sample radius: $r_{samp} = \|x_{xyz}\|$ [S1, unofficial].
    *   Initialize keep mask: $keep\_w = \mathbf{1}$ [S1, unofficial].
    *   Apply radial constraints: If `r_min_rsun` is set, $keep\_w \leftarrow keep\_w \times (r_{samp} \ge r_{min\_rsun})$. If `r_max_rsun` is set, $keep\_w \leftarrow keep\_w \times (r_{samp} \le r_{max\_rsun})$ [S1, unofficial]. This prevents artifacts from the saturated chromospheric base below $1 R_{\odot}$ [S1, unofficial].
5.  **Field Query:**
    *   Retrieve log electron density (`log_ne`) and log temperature (`log_temp`).
    *   If using Ground Truth (`use_gt`), query the GT fields at $x_{xyz}$ [S1, unofficial].
    *   If using Learned Fields, call `_predict_learned_fields(x_AABB)` to get `log_ne` and `log_temp` [S1, unofficial].
    *   Clamp `log_ne` and `log_temp` if `self.clamp` is True [S1, unofficial].
6.  **Segment Length Calculation:**
    *   Compute physical segment length: $seg\_len = (t_e - t_s) \times \text{aabb\_scale} \times \text{rsun\_to\_cm}$ [S1, unofficial].
    *   Define integration helper `integ(vals)` which accumulates `vals * seg_len * keep_w` into a per-ray output tensor indexed by `ray_idx` [S1, unofficial].
7.  **Quantity Integration:**
    *   **Case 'column_ne':**
        *   Compute electron density: $n_e = 10^{\text{log\_ne}}$ [S1, unofficial].
        *   Integrate: $per\_ray = \text{integ}(n_e)$ [S1, unofficial].
    *   **Case 'emission' or 'ewt_temp':**
        *   Compute radius: $r = \|x_{xyz}\|$, $\log r = \log_{10}(r)$ [S1, unofficial].
        *   Clamp $\log r$ if `self.clamp` is True [S1, unofficial].
        *   Stack inputs for emissivity coefficient field: $ntr = [\log n_e, \log T, \log r]$ (transposed to shape $(M, 3)$) [S1, unofficial].
        *   Query emissivity coefficients: $ccoef\_all = \text{ccoef\_field}(ntr)$ [S1, unofficial].
        *   Select specified `channels` if provided [S1, unofficial].
        *   Sum over channels to get emissivity $\epsilon$ [S1, unofficial].
        *   **For 'emission':** $per\_ray = \text{integ}(\epsilon)$ [S1, unofficial].
        *   **For 'ewt_temp':**
            *   Numerator: $num = \text{integ}(T \times \epsilon)$ where $T = 10^{\text{log\_temp}}$ [S1, unofficial].
            *   Denominator: $den = \text{integ}(\epsilon)$ [S1, unofficial].
            *   Result: $per\_ray = num / \max(den, 10^{-30})$ [S1, unofficial].
8.  **Final Assembly:**
    *   Initialize `full` tensor of shape $(N, C)$ with `NaN` [S1, unofficial].
    *   Assign results: `full[valid] = per_ray` [S1, unofficial].

**Pseudocode:**
```python
def los_integration(rays_o, rays_d, t_s, t_e, ray_idx, valid, cfg):
    """
    Performs Line-of-Sight integration for visualization quantities.
    
    Args:
        rays_o: (N, 3) ray origins
        rays_d: (N, 3) ray directions
        t_s: (M,) start times
        t_e: (M,) end times
        ray_idx: (M,) ray indices for each sample
        valid: (N,) boolean mask for valid rays
        cfg: Configuration object containing aabb_scale, rsun_to_cm, 
             r_min_rsun, r_max_rsun, quantity, channels, clamp, etc.
             
    Returns:
        full: (N, C) integrated quantities, NaN for invalid rays
    """
    N = rays_o.shape[0]
    device = rays_o.device
    dtype = rays_o.dtype
    
    # 1. Coordinate Conversion
    t_mid = 0.5 * (t_s + t_e)
    
    # Gather ray origins and directions for valid rays
    valid_rays_o = rays_o[valid]
    valid_rays_d = rays_d[valid]
    
    # Map samples to valid rays
    # Note: ray_idx maps sample index to ray index. 
    # We need to handle the case where ray_idx might refer to indices outside valid mask
    # or we assume ray_idx is already relative to valid rays or global.
    # Based on source: rays_o[valid][ray_idx] implies ray_idx is index into valid_rays_o
    x_AABB = valid_rays_o[ray_idx] + t_mid[:, None] * valid_rays_d[ray_idx]
    
    # Scale to physical units
    x_xyz = x_AABB * cfg.aabb_scale
    
    # 2. Radial Masking
    r_samp = torch.linalg.vector_norm(x_xyz, dim=-1)
    keep_w = torch.ones_like(r_samp)
    
    if cfg.r_min_rsun is not None:
        keep_w = keep_w * (r_samp >= cfg.r_min_rsun)
    if cfg.r_max_rsun is not None:
        keep_w = keep_w * (r_samp <= cfg.r_max_rsun)
        
    # 3. Field Query
    # Assume get_log_ne and get_log_temp are available functions/methods
    # If use_gt: query GT fields
    # Else: query learned fields
    log_ne = get_log_ne(x_xyz, cfg) 
    log_temp = get_log_temp(x_xyz, cfg)
    
    if cfg.clamp:
        log_ne = torch.clamp(log_ne, min=cfg.min_log_ne, max=cfg.max_log_ne)
        if log_temp is not None:
            log_temp = torch.clamp(log_temp, min=cfg.min_log_temp, max=cfg.max_log_temp)
            
    # 4. Segment Length
    seg_len = (t_e - t_s) * cfg.aabb_scale * cfg.rsun_to_cm
    
    # 5. Integration Helper
    # Initialize output for valid rays
    num_valid = valid.sum()
    # Determine output channels C
    # If quantity is column_ne, C=1. If emission/ewt_temp, C=len(channels) or all channels
    if cfg.quantity in ['emission', 'ewt_temp']:
        # Determine number of channels from ccoef_field or cfg
        # Assuming ccoef_field returns shape (M, C_all)
        ccoef_all = query_ccoef_field(log_ne, log_temp, x_xyz, cfg)
        if cfg.channels is not None:
            ccoef = ccoef_all[:, cfg.channels]
        else:
            ccoef = ccoef_all
        C = ccoef.shape[1]
    else:
        C = 1
        ccoef = None # Not used for column_ne
        
    out = torch.zeros((num_valid, C), device=device, dtype=dtype)
    
    # 6. Compute Integrand and Accumulate
    if cfg.quantity == 'column_ne':
        ne = torch.pow(10.0, log_ne)
        integrand = ne * seg_len * keep_w
        # Expand to (M, 1) for broadcasting with out
        integrand = integrand.unsqueeze(-1)
        out.index_add_(0, ray_idx, integrand)
        
    elif cfg.quantity == 'emission':
        # ccoef is emissivity epsilon
        epsilon = ccoef.sum(dim=-1, keepdim=True) if ccoef.ndim > 1 else ccoef
        # If ccoef was already summed over channels in query, use it directly
        # Assuming ccoef here is the final emissivity per sample
        integrand = ccoef * seg_len[:, None] * keep_w[:, None]
        out.index_add_(0, ray_idx, integrand)
        
    elif cfg.quantity == 'ewt_temp':
        # Numerator: T * epsilon
        # Denominator: epsilon
        # ccoef is emissivity epsilon
        epsilon = ccoef.sum(dim=-1, keepdim=True) if ccoef.ndim > 1 else ccoef
        T = torch.pow(10.0, log_temp)
        
        num_integrand = T * epsilon * seg_len[:, None] * keep_w[:, None]
        den_integrand = epsilon * seg_len[:, None] * keep_w[:, None]
        
        out_num = torch.zeros((num_valid, 1), device=device, dtype=dtype)
        out_den = torch.zeros((num_valid, 1), device=device, dtype=dtype)
        
        out_num.index_add_(0, ray_idx, num_integrand)
        out_den.index_add_(0, ray_idx, den_integrand)
        
        # Compute weighted average
        # Clamp denominator to avoid division by zero
        per_ray = out_num / torch.clamp(out_den, min=1e-30)
        
        # Assign to out (assuming C=1 for ewt_temp scalar output, or expand if multi-channel)
        # Source implies scalar output for ewt_temp
        if C == 1:
            out = per_ray
        else:
            # If multi-channel, ewt_temp might be computed per channel?
            # Source says "per_ray = num / den.clamp_min(1e-30)"
            # Assuming single scalar output for ewt_temp
            pass 
            
    # 7. Final Assembly
    full = torch.full((N, C), float('nan'), device=device, dtype=dtype)
    full[valid] = out
    
    return full
```

**Parameters:**
*   `uniform_samples`: Number of uniform samples if requested. Default 0 [S1, unofficial].
*   `r_min_rsun`: Minimum radius in solar radii to keep samples. Default None [S1, unofficial].
*   `r_max_rsun`: Maximum radius in solar radii to keep samples. Default None [S1, unofficial].
*   `channels`: Spectral line indices to select for emission/ewt_temp. Default None (all channels) [S1, unofficial].
*   `quantity`: String, one of 'column_ne', 'emission', 'ewt_temp'. Defines the integrand [S1, unofficial].
*   `rsun_to_cm`: Constant from config, default $6.957 \times 10^{10}$, converting solar radii to centimeters [S1, unofficial].
*   `wavelengths`: List of wavelengths in Angstroms used for photon-to-ergs conversion in emissivity calculations [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Saturated Disk Artifacts:** Integrating below $r=1 R_{\odot}$ manufactures a saturated filled disk because the spherical interpolant border-pads the dense chromospheric base. This is handled by zeroing out-of-shell samples' contribution via the `keep_w` mask based on `r_min_rsun`/`r_max_rsun` [S1, unofficial].
*   **Division by Zero:** In `ewt_temp`, the denominator (integrated emissivity) can be zero. This is handled by clamping the denominator to a minimum value of $10^{-30}$ [S1, unofficial].
*   **Invalid Rays:** Rays that do not intersect the volume or are outside the viewing frustum return `NaN` in the output tensor [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of samples $M$ and rays $N$. The dominant cost is the neural network field query or GT field interpolation for each sample [S1, unofficial].
*   **Memory Complexity:** Linear with respect to $M$ for storing intermediate tensors (`log_ne`, `log_temp`, `ccoef`) and $N$ for the output tensor [S1, unofficial].
*   **Strengths:** Provides physically meaningful diagnostics (density, temperature, emissivity) rather than just visual appearance. Efficiently reuses the sampling infrastructure of the forward pass [S1, unofficial].
*   **Limitations:** Requires accurate field data (GT or learned). Performance depends on the complexity of the field query (e.g., neural network inference) [S1, unofficial].

## Background
LOS-integration for visualization is part of the CoroNeRF framework, which uses neural radiance fields for solar corona visualization [S1, unofficial]. It was developed to enable the extraction of physical quantities from neural field representations of the solar corona, allowing for comparison with ground truth data and other observational diagnostics [S1, unofficial].
