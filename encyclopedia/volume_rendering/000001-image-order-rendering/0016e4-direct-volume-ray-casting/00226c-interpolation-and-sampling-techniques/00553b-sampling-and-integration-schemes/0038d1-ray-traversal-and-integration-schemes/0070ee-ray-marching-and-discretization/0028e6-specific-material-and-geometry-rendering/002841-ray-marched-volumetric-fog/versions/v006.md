# Ray-marched Volumetric Fog

Also called: Forward ray-marching fog, Full-screen volumetric fog

## Overview
Ray-marched volumetric fog simulates light absorption, scattering, soft shadows, and light shafts (god rays) by treating fog as a 3D volume of participating media traced via ray-marching from the camera to the scene [S1, unofficial]. It differs from backward ray-marching (scene to camera) by enabling early-out optimizations when transmittance becomes sufficiently low [S1, unofficial].

## How it works
**Inputs:**
*   Camera position and view/projection matrices.
*   Depth buffer (z-buffer) for scene geometry intersection.
*   Light properties: position, intensity ($\Phi$), and optionally shadow maps.
*   Fog parameters: density ($\tau$), scattering coefficient ($a$), phase function ($P$), and step size ($\Delta l$).

**Outputs:**
*   Final radiance ($L$) per pixel, composited over the background color.

**Data Structures:**
*   **Ray:** Defined by origin (camera position) and direction (derived from UV coordinates and projection matrices).
*   **Step State:** Current distance along ray ($l$), accumulated transmittance ($T$), accumulated radiance ($L$).

**Numbered Steps:**
1.  **Ray Generation:** For each pixel, construct a ray originating at the camera.
2.  **Scene Intersection:** Sample the depth buffer using the pixel's UV coordinate to reconstruct the 3D position of the scene intersection point. This defines the ray's maximum extent.
3.  **Clamping:** Clamp the ray distance to a `zfar` value to prevent infinite marching if the ray misses the scene geometry [S1, unofficial].
4.  **Jittering (Optional but Recommended):** Add a pseudo-random delta step to the ray's starting position to fix slice artifacts caused by aligned sampling grids [S1, unofficial].
5.  **Marching Loop:** Iterate from the camera (start) to the scene intersection (finish) at regular intervals ($\Delta l$).
6.  **Transmittance Update:** Calculate the transmittance from the camera to the current step position using the density $\tau$ and distance $l_n$ [S1, unofficial].
7.  **In-scattering Calculation:** Compute the light scattered into the view direction at the current step position [S1, unofficial].
8.  **Accumulation:** Add the product of in-scattering, transmittance, and step size to the accumulated radiance.
9.  **Early-out:** If transmittance drops below a threshold, terminate the loop early [S1, unofficial].

**Formulas:**

The final radiance $L$ is approximated using a Riemann sum [S1, unofficial]:

$$ L = \sum_{n=0}^{N} L_i(x(l_n), \omega) e^{-\tau l_n} \Delta l $$

Where:
*   $L$: Calculated radiance.
*   $N$: Total number of steps.
*   $L_i(x(l_n), \omega)$: In-scattering term at step $n$.
*   $e^{-\tau l_n}$: Transmittance from camera to step $n$, where $\tau$ is density and $l_n$ is distance traveled.
*   $\Delta l$: Ray-march step size.

The in-scattering term $L_i$ for a point light source is defined as [S1, unofficial]:

$$ L_i(x, \omega) = \frac{a \Phi}{4\pi d^2} v(x) e^{-\tau d} P(\omega, \omega_i) $$

Where:
*   $a$: Scattering coefficient (probability of photon scattering).
*   $\Phi$: Point light intensity.
*   $d$: Distance between the sample point and the light source.
*   $v(x)$: Visibility of the sample point from the light source (1 if no shadow mapping is used).
*   $e^{-\tau d}$: Transmittance from the light to the sample point.
*   $P(\omega, \omega_i)$: Phase function describing the angular distribution of scattered light.

**Parameters:**
*   **Density ($\tau$):** Constant for uniform fog [S1, unofficial]. Can be procedurally generated, sampled from a texture, or from OpenVDB for non-uniform fog [S1, unofficial].
*   **Visibility ($v(x)$):** Set to 1 in basic implementations; can be sampled from a light's cube shadow map if available [S1, unofficial].
*   **Phase Function ($P$):** Uses the Schlick approximation of the Henyey-Greenstein (HG) function for real-time performance, as the original HG function is expensive [S1, unofficial].
*   **Step Size ($\Delta l$):** Determines resolution. Smaller steps reduce artifacts but increase cost.

**Pitfalls:**
*   **Slice Artifacts:** Occur when rays march with the same step size starting at the same point, causing samples to align on the same "slices" [S1, unofficial].
*   **Noise:** Jittering fixes slice artifacts but can introduce noise, especially with larger step sizes [S1, unofficial].
*   **Banding:** Visible in the distance even with jittering; requires further sampling strategies or temporal accumulation to resolve [S1, unofficial].

**Pseudocode:**

```python
def ray_marched_volumetric_fog(camera_pos, view_proj, depth_buffer, light_pos, light_intensity, fog_density, step_size, zfar):
    """
    Renders volumetric fog using forward ray-marching.
    """
    # Initialize output image
    image = zeros_like(depth_buffer)
    
    # Pre-calculate light direction normalization factor
    # Note: In a real shader, this is done per-light or per-pixel depending on light count
    light_inv_dist_sq = 1.0 / (4.0 * 3.14159265359) 
    
    for y in range(height):
        for x in range(width):
            # 1. Ray Generation
            uv = vec2(x, y) / vec2(width, height)
            ray_origin = camera_pos
            ray_direction = unproject(uv, view_proj)
            ray_direction = normalize(ray_direction)
            
            # 2. Scene Intersection
            depth = sample_depth(depth_buffer, uv)
            scene_point = unproject_depth(uv, depth, view_proj)
            ray_to_scene = scene_point - ray_origin
            ray_length = length(ray_to_scene)
            
            # 3. Clamping
            if ray_length > zfar:
                ray_length = zfar
                # Adjust direction if clamping changes the endpoint significantly, 
                # though typically we just limit the march distance.
            
            # 4. Jittering
            jitter = random_float() * step_size
            current_dist = jitter
            
            # State variables
            accumulated_radiance = vec3(0.0)
            current_transmittance = 1.0
            
            # 5. Marching Loop
            while current_dist < ray_length:
                # Calculate current 3D position
                current_pos = ray_origin + ray_direction * current_dist
                
                # 6. Transmittance from Camera
                # T_cam = exp(-tau * current_dist)
                # Optimization: Update incrementally or use expf
                cam_transmittance = exp(-fog_density * current_dist)
                
                # If transmittance is too low, we can stop (Early-out)
                if cam_transmittance < 0.01:
                    break
                
                # 7. In-scattering Calculation
                # Distance from sample point to light
                dist_to_light = length(current_pos - light_pos)
                
                # Light attenuation (inverse square law)
                light_attenuation = light_intensity * light_inv_dist_sq / (dist_to_light * dist_to_light)
                
                # Transmittance from Light to Sample
                light_transmittance = exp(-fog_density * dist_to_light)
                
                # Visibility (1.0 for no shadows, or sample shadow map)
                visibility = 1.0 
                
                # Phase Function (Schlick-Henyey Greenstein approximation)
                # P(w, wi) depends on scattering angle. 
                # For simplicity, assuming isotropic or pre-computed P here.
                # In practice: P = schlick_hg_phase_function(ray_direction, light_direction, g)
                phase = 1.0 # Placeholder for actual phase function evaluation
                
                # In-scattering term Li
                # Li = (a * Phi / (4 * pi * d^2)) * v(x) * e^(-tau * d) * P
                in_scattering = fog_density * light_attenuation * visibility * light_transmittance * phase
                
                # 8. Accumulation
                # Contribution = Li * T_cam * Delta_l
                contribution = in_scattering * cam_transmittance * step_size
                accumulated_radiance += contribution
                
                # Advance step
                current_dist += step_size
            
            # 9. Composition
            # Final color = accumulated_radiance + background_color * final_transmittance
            final_transmittance = exp(-fog_density * ray_length)
            background_color = sample_background(uv) # Or from depth buffer color
            image[y, x] = accumulated_radiance + background_color * final_transmittance
            
    return image
```

## Operating characteristics
*   **Time Complexity:** $O(N \cdot P)$, where $N$ is the number of pixels and $P$ is the number of steps per ray.
*   **Memory Complexity:** $O(P)$ for per-ray state if computed sequentially, or $O(N \cdot P)$ if storing intermediate buffers. Typically implemented as a full-screen pass with minimal state.
*   **Performance:** Real-time capable on modern GPUs due to the simplicity of the shader and early-out optimizations. Performance degrades with higher step counts or non-uniform density sampling.
*   **Strengths:** Simple to implement, works well with existing scene geometry (via depth buffer), allows dynamic interaction with lights and shadows.
*   **Limitations:** Slice artifacts require jittering or temporal accumulation; noise at large step sizes; uniform fog assumption simplifies density lookup but limits complexity without texture/OpenVDB integration.
*   **When to use:** Real-time games requiring atmospheric depth and light shafts (e.g., Horizon Zero Dawn, Death Stranding) [S1, unofficial].
*   **When not to use:** Offline rendering requiring high-fidelity multiple scattering or complex volumetric geometry without pre-computation.

## Background
The technique is based on the principles of participating media rendering, specifically forward ray-marching for real-time applications. It draws from the work of Toth and Umenhofer on real-time volumetric lighting in participating media [S1, unofficial]. Implementations are found in games such as Horizon Zero Dawn, Death Stranding, and Returnal, where fog interacts dynamically with world lighting and geometry [S1, unofficial].
