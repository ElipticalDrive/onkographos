# DVGO Density and Color Rendering

Also called: DVGO volume rendering

## Overview
DVGO (Direct Volume Gaussian Optimization) is a method for synthesizing novel views of 3D scenes by combining a sparse 3D voxel grid with a shallow neural network. It solves the problem of efficient neural volume rendering by decoupling density and color representation: density is derived directly from the voxel grid using a non-linear activation, while color is computed via a view-dependent neural network. It distinguishes itself from standard NeRF by using a voxel grid for density to enable faster training and inference, and by employing a "post-activation" strategy that allows for sharper surface reconstruction with fewer grid cells [S1].

## How it works

### Inputs and Outputs
*   **Inputs:**
    *   $V^{(\sigma)}$: A 3D voxel grid storing raw density values $\ddot{\sigma}$. Dimensions $N_x \times N_y \times N_z$.
    *   $V^{(f)}$: A 3D voxel grid storing color features. Dimensions $N_x \times N_y \times N_z$ with channel count $C$.
    *   $b$: A scalar hyperparameter for the softplus shift.
    *   $\Theta$: Parameters for the shallow MLP.
    *   $r$: A camera ray defined by origin and direction.
    *   $t_n, t_f$: Near and far plane distances along the ray.
    *   $n$: Number of sample points along the ray.
*   **Outputs:**
    *   $\hat{C}(r)$: The synthesized RGB color for the pixel.

### Data Structures
The method relies on two primary 3D grids:
1.  **Density Grid ($V^{(\sigma)}$):** Stores scalar values $\ddot{\sigma}_i \in \mathbb{R}$. These are raw, unbounded values that are mapped to non-negative densities via activation.
2.  **Feature Grid ($V^{(f)}$):** Stores vector features $\mathbf{f}_i \in \mathbb{R}^C$. These are interpolated and passed to the MLP.

Both grids are sampled using **trilinear interpolation**. For a query point $x_i \in \mathbb{R}^3$, the interpolation function is defined as:
$$ \text{interp}(x_i, V) : (\mathbb{R}^3, \mathbb{R}^{C \times N_x \times N_y \times N_z}) \rightarrow \mathbb{R}^C $$
[G] In implementation, this involves finding the 8 neighboring voxel indices, computing weights based on fractional coordinates, and performing a weighted sum of the corner values.

### Numbered Steps

1.  **Ray Sampling:** Sample $n$ points $x_i$ uniformly (or adaptively) along the ray segment $[t_n, t_f]$. Calculate the step size $\delta_i$ as the distance between adjacent sample points.
2.  **Feature Interpolation:** For each sample point $x_i$, retrieve the raw density value $\ddot{\sigma}_i$ and the color feature vector $\mathbf{f}_i$ from the grids:
    $$ \ddot{\sigma}_i = \text{interp}(x_i, V^{(\sigma)}) $$
    $$ \mathbf{f}_i = \text{interp}(x_i, V^{(f)}) $$
3.  **Density Activation:** Map the raw density to a non-negative extinction coefficient $\sigma_i$ using the shifted softplus function:
    $$ \sigma_i = \text{softplus}(\ddot{\sigma}_i) = \log(1 + \exp(\ddot{\sigma}_i + b)) $$
    [S1] The shift parameter $b$ is a hyperparameter.
4.  **Color Emission:** Compute the view-dependent color $c_i^{(rgb)}$ using a shallow MLP. The MLP takes the interpolated color features $\mathbf{f}_i$, the positional encoding of the position $x_i$, and the positional encoding of the ray direction $d$:
    $$ c_i^{(rgb)} = \text{MLP}_\Theta(\text{PE}(x_i), \text{PE}(d), \mathbf{f}_i) $$
    [S1] Positional encoding is applied to both $x_i$ and $d$.
5.  **Alpha Calculation:** Compute the termination probability (alpha) for each sample:
    $$ \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
6.  **Transmittance Accumulation:** Compute the accumulated transmittance $T_i$ from the near plane to $x_i$:
    $$ T_i = \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    With $T_1 = 1$.
7.  **Volume Rendering Quadrature:** Accumulate the final color $\hat{C}(r)$:
    $$ \hat{C}(r) = \sum_{i=1}^{n} T_i \alpha_i c_i + T_{n+1} c_{bg} $$
    where $c_{bg}$ is a pre-defined background color (e.g., white or black).

### Pseudocode

```python
def dvgo_render(ray_origin, ray_direction, near_plane, far_plane, 
                num_samples, density_grid, feature_grid, 
                mlp_params, softplus_shift, bg_color):
    """
    Renders a single ray using DVGO.
    
    Args:
        ray_origin: (3,) array, origin of the ray.
        ray_direction: (3,) array, normalized direction of the ray.
        near_plane: float, start distance.
        far_plane: float, end distance.
        num_samples: int, number of sample points.
        density_grid: 3D array (Nx, Ny, Nz), raw density values.
        feature_grid: 3D array (Nx, Ny, Nz, C), color features.
        mlp_params: object or function, parameters for the shallow MLP.
        softplus_shift: float, hyperparameter b.
        bg_color: (3,) array, background color.
        
    Returns:
        color: (3,) array, final pixel color.
    """
    # 1. Sample points along the ray
    t_vals = np.linspace(near_plane, far_plane, num_samples)
    points = ray_origin + ray_direction * t_vals[:, np.newaxis]
    
    # Calculate delta (distance between adjacent samples)
    # For uniform sampling, delta is constant. For non-uniform, compute differences.
    deltas = np.diff(t_vals, prepend=near_plane) # Shape (num_samples,)
    # Note: deltas[i] is the distance from point i to point i+1? 
    # Standard volume rendering uses delta_i as the step size at sample i.
    # If t is sorted, delta_i = t_{i+1} - t_i for i < n, and last delta is far_plane - t_{n-1}?
    # The formula uses delta_i for alpha_i. 
    # Let's assume uniform step for simplicity or compute exact intervals.
    step_size = (far_plane - near_plane) / (num_samples - 1)
    deltas = np.full(num_samples, step_size)
    deltas[-1] = far_plane - t_vals[-1] # Adjust last step if needed, or keep uniform.
    # Standard implementation often uses uniform step size for all.
    
    # 2. Interpolate features and densities
    # interp function performs trilinear interpolation
    raw_densities = np.array([trilinear_interpolate(density_grid, p) for p in points])
    features = np.array([trilinear_interpolate(feature_grid, p) for p in points])
    
    # 3. Density Activation (Softplus)
    densities = np.log(1 + np.exp(raw_densities + softplus_shift))
    
    # 4. Color Emission via MLP
    # Apply positional encoding to points and directions
    # PE is a standard sinusoidal positional encoding
    pe_points = positional_encoding(points)
    pe_directions = positional_encoding(np.tile(ray_direction, (num_samples, 1)))
    
    colors = np.zeros((num_samples, 3))
    for i in range(num_samples):
        # MLP input: features[i], pe_points[i], pe_directions[i]
        colors[i] = mlp_forward(mlp_params, features[i], pe_points[i], pe_directions[i])
        
    # 5. Alpha and Transmittance Calculation
    alphas = 1 - np.exp(-densities * deltas)
    
    # Transmittance T_i = product_{j=1}^{i-1} (1 - alpha_j)
    # T_1 = 1
    transmittances = np.ones(num_samples)
    for i in range(1, num_samples):
        transmittances[i] = transmittances[i-1] * (1 - alphas[i-1])
        
    # 6. Volume Rendering Quadrature
    # C(r) = sum_{i=1}^n T_i * alpha_i * c_i + T_{n+1} * c_bg
    # T_{n+1} = product_{j=1}^n (1 - alpha_j)
    transmittance_final = transmittances[-1] * (1 - alphas[-1])
    
    contribution = transmittances * alphas * colors
    final_color = np.sum(contribution, axis=0) + transmittance_final * bg_color
    
    return final_color
```

### Parameters and Edge Cases
*   **Softplus Shift ($b$):** A hyperparameter. Typical values are not specified in the sources, but it controls the transition from zero to positive density.
*   **Post-Activation:** DVGO explicitly applies the non-linear activation (softplus) *after* trilinear interpolation. This is critical for producing sharp surfaces. Applying activation before interpolation (pre-activation) results in blurred surfaces [S1].
*   **Positional Encoding:** The MLP requires positional encoding for both position and direction. The specific encoding scheme (e.g., frequency bands) is not detailed in the provided notes but is standard in NeRF-like architectures [S1].
*   **Background Color:** $c_{bg}$ is a pre-defined constant.

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of samples $n$ and the depth of the MLP. The dominant cost is the trilinear interpolation and the MLP forward pass for each sample.
*   **Memory Complexity:** Proportional to the size of the voxel grids ($N_x N_y N_z$). DVGO is generally more memory-efficient than dense NeRF representations for high-resolution scenes because it uses a sparse grid structure for density.
*   **Strengths:**
    *   **Sharp Surfaces:** The post-activation strategy allows for sharp surface reconstruction with fewer grid cells compared to pre-activation methods [S1].
    *   **Efficiency:** Faster training and inference compared to pure neural representations like NeRF due to the grid-based density lookup.
*   **Limitations:**
    *   **Resolution Dependence:** Quality is limited by the voxel grid resolution. Fine details may be lost if the grid is too coarse.
    *   **View-Dependent Color:** Requires an MLP for color, which can be slower than direct texture lookup for simple materials.
*   **When to Use:** Suitable for novel view synthesis of complex 3D scenes where sharp geometry is important and computational efficiency is a priority over pure neural flexibility.

## Background
DVGO was introduced in the paper "NeRF Synthesis with Shading Guidance" [S1]. It builds upon the principles of Neural Radiance Fields (NeRF) but introduces a voxel grid for density representation to improve efficiency and sharpness. The method leverages the shifted softplus activation from Mip-NeRF [S1] for density mapping.
