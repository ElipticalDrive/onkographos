# Light-space transmittance volumes

Also called: Light-space transmittance, Transmittance volumes

## Overview
Light-space transmittance volumes are a technique for computing light attenuation in participating media by pre-calculating optical depth from light sources into a 3D grid, allowing receivers to look up transmittance via interpolation [S1, unofficial]. It is the volume rendering equivalent of deep shadow maps for participating media, shifting the computational burden from per-receiver ray marching to a single per-cluster grid construction [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input:** An absorbance field (voxel grid defining extinction coefficients), a set of emitter clusters (groups of light facets or the entire light source for distant receivers), and a receiver position [S1, unofficial].
*   **Output:** The optical depth $\tau$ from the emitter cluster to the receiver position, derived from the transmittance volume [S1, unofficial].

**Data Structures**
The transmittance volume is a 3D grid indexed by spatial position [S1, unofficial]. For each emitter cluster, a separate grid of optical depth values is stored [S1, unofficial]. The grid resolution is typically coarse relative to the scene scale (e.g., $12 \times 12 \times 16$) to manage memory [S1, unofficial]. The volume is implemented as a differentiable function (e.g., in JAX) of the absorbance field to ensure exact gradient computation $dG/d(\text{absorbance})$ [S1, unofficial].

**Steps**
1.  **Cluster Emission:** Group light source facets into clusters. A distant receiver may treat the entire lamp as one cluster, while closer receivers may require finer clustering [S1, unofficial].
2.  **March and Store:** For each emitter cluster, march outward through the absorbance grid from the cluster's representative origin point. Calculate the accumulated optical depth to every sample point in the grid and store these values in the cluster's transmittance volume [S1, unofficial].
3.  **Lookup:** For a receiver at position $\mathbf{p}$, identify the relevant emitter cluster. Retrieve the optical depth $\tau$ by performing trilinear interpolation on the corresponding transmittance volume at $\mathbf{p}$ [S1, unofficial].
4.  **Attenuation:** Compute transmittance $T = e^{-\tau}$ for shading calculations [S1, unofficial].

**Formulas**
*   Optical Depth: $\tau(\mathbf{p}) = \int_{\mathbf{o}}^{\mathbf{p}} \sigma_t(\mathbf{r}) \, d\mathbf{r}$, where $\mathbf{o}$ is the cluster origin and $\sigma_t$ is the extinction coefficient [S1, unofficial].
*   Transmittance: $T = e^{-\tau}$ [S1, unofficial].

**Parameters**
*   **Grid Resolution:** Coarse grids are used to limit memory (e.g., $12 \times 12 \times 16$) [S1, unofficial].
*   **Cluster Count:** The method depends on clustering; tens of clusters are feasible, but one volume per facet is not [S1, unofficial].

**Edge Cases and Pitfalls**
*   **Near-Field Inaccuracy:** The method is an approximation twice over: it uses a single representative point for the cluster origin and interpolates $\tau$ between samples. $\tau$ is smooth with respect to receiver position for a fixed origin but not near the origin itself. Therefore, the near field should retain the exact ray walk [S1, unofficial].
*   **Memory Cost:** Storage requires one grid of optical depths per cluster. This is efficient for tens of clusters on a coarse grid but prohibitive for one volume per facet [S1, unofficial].
*   **Clustering Dependency:** Without emitter clusters, creating one volume per facet costs more than the ray walk it replaces [S1, unofficial].

**Pseudocode**
```python
import math

def compute_transmittance_volume(absorbance_grid, cluster_origin, grid_resolution, voxel_size):
    """
    March from cluster_origin through absorbance_grid to fill a transmittance volume.
    Returns a 3D array of optical depths.
    """
    volume = [[[0.0 for _ in range(grid_resolution[2])] for _ in range(grid_resolution[1])] for _ in range(grid_resolution[0])]
    for i in range(grid_resolution[0]):
        for j in range(grid_resolution[1]):
            for k in range(grid_resolution[2]):
                voxel_pos = [
                    cluster_origin[0] + i * voxel_size[0],
                    cluster_origin[1] + j * voxel_size[1],
                    cluster_origin[2] + k * voxel_size[2]
                ]
                # [G] Integrate absorbance along the ray from cluster_origin to voxel_pos
                optical_depth = 0.0
                steps = 10
                for s in range(steps):
                    t = s / steps
                    point_on_ray = [
                        cluster_origin[d] + t * (voxel_pos[d] - cluster_origin[d]) for d in range(3)
                    ]
                    # [G] Sample absorbance at point_on_ray (e.g., trilinear interpolation into absorbance_grid)
                    sigma_t = 1.0
                    optical_depth += sigma_t * math.sqrt(sum((voxel_pos[d] - cluster_origin[d])**2 for d in range(3))) / steps
                volume[i][j][k] = optical_depth
    return volume

def get_transmittance(receiver_pos, cluster_volume, voxel_size):
    """
    Look up optical depth from the pre-computed volume using trilinear interpolation.
    """
    voxel_pos = [
        (receiver_pos[d] - cluster_volume.origin[d]) / voxel_size[d] for d in range(3)
    ]
    # [G] Near-field check: if distance to origin is below a threshold, use exact ray march instead of interpolation
    dist = math.sqrt(sum((receiver_pos[d] - cluster_volume.origin[d])**2 for d in range(3)))
    if dist < cluster_volume.near_field_threshold:
        # [G] Exact ray march implementation omitted per sources
        return 0.0

    # [G] Trilinear interpolation of optical depth from volume data
    i, j, k = int(voxel_pos[0]), int(voxel_pos[1]), int(voxel_pos[2])
    fx, fy, fz = voxel_pos[0] - i, voxel_pos[1] - j, voxel_pos[2] - k
    v000 = cluster_volume.data[i][j][k]
    v100 = cluster_volume.data[i+1][j][k]
    v010 = cluster_volume.data[i][j+1][k]
    v110 = cluster_volume.data[i+1][j+1][k]
    v001 = cluster_volume.data[i][j][k+1]
    v101 = cluster_volume.data[i+1][j][k+1]
    v011 = cluster_volume.data[i][j+1][k+1]
    v111 = cluster_volume.data[i+1][j+1][k+1]
    tau = (1-fx)*(1-fy)*(1-fz)*v000 + fx*(1-fy)*(1-fz)*v100 + (1-fx)*fy*(1-fz)*v010 + fx*fy*(1-fz)*v110 + \
          (1-fx)*(1-fy)*fz*v001 + fx*(1-fy)*fz*v101 + (1-fx)*fy*fz*v011 + fx*fy*fz*v111
    return math.exp(-tau)
```

## Operating characteristics
*   **Time Complexity:** Construction is $O(N_{clusters} \times N_{voxels})$. Lookup is $O(1)$ per receiver via interpolation, compared to $O(N_{steps})$ for the exact walk [S1, unofficial].
*   **Memory Complexity:** $O(N_{clusters} \times N_{voxels})$ for storing optical depth grids [S1, unofficial].
*   **Performance:** On a 4,096-facet lamp, 3,954 receivers, and a $12 \times 12 \times 16$ grid, the graded per-call field took ~19-21 s, while uniform absorption took ~0.4 s. The exact walk cost was significantly higher, scaling with $N_{receivers} \times N_{facets} \times (n_x + n_y + n_z)$ [S1, unofficial].
*   **Strengths:** Eliminates per-receiver ray marching for transmittance; supports exact gradients via differentiable programming [S1, unofficial].
*   **Limitations:** High memory usage for many clusters; inaccurate in the near field; requires clustering [S1, unofficial].
*   **When to Use:** When the number of receivers is large and the light source can be effectively clustered; when gradients are needed [S1, unofficial].
*   **When Not to Use:** When the light source has many facets requiring individual volumes; in the near field of the light [S1, unofficial].

## Background
The technique is based on the concept of shadow maps (Williams 1978) and deep shadow maps (Lokovic & Veach, SIGGRAPH 2000), which compute transmittance from the light's side once into a structure indexed by position [S1, unofficial]. It adapts this idea to 3D volumes for participating media [S1, unofficial].
