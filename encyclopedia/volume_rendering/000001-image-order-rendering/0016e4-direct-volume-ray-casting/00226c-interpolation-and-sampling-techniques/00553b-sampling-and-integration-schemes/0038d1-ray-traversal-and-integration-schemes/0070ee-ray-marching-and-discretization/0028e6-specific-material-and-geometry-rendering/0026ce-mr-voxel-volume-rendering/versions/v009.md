# Mr-Voxel Volume Rendering

Also called: VolumeIntegrator::Li

## Overview
Mr-Voxel Volume Rendering is a direct volume ray casting technique implemented within the Mr-Voxel library that performs ray marching through a single volume region to accumulate emitted light and compute scattering contributions from a single light source [S1, unofficial]. It distinguishes itself from general-purpose volume renderers by its specific integration of an accelerated voxel data structure with a custom lighting model derived from standard physically based rendering principles, focusing on a single-volume, single-light scenario [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A camera ray defined by origin and direction, scene data containing a single volume object (`volumes[0]`) and a single light source (`lights[0]`), and a step size parameter `mStepSize`.
*   **Output:** A `Spectrum` representing the accumulated radiance $L_v$ and a transmittance value $T$ updated for the ray.

**Data Structures:**
The implementation assumes access to a `Volume` object via `mScene->getVolumes()[0]` and a `Light` object via `mScene->getLightSources()[0]`. The `Volume` object provides methods for computing optical depth (`tau`), emitted light (`Lve`), and scattering coefficient (`sigma_s`). The `Scene` object provides intersection testing for shadow rays.

**Parameters:**
*   `mStepSize`: The nominal step size for ray marching.
*   Russian Roulette threshold: $10^{-3}$ for transmittance.
*   Russian Roulette probability: $0.5$.

**Algorithm Steps:**
1.  **Determine Sample Count:** Calculate the number of samples based on the ray segment length $(t_1 - t_0)$ and `mStepSize`. If the calculated count is 0, set it to 1.
    $$ \text{numSamples} = \max\left(1, \left\lfloor \frac{t_1 - t_0}{\text{mStepSize}} \right\rfloor \right) $$
2.  **Calculate Step Length:** Compute the actual step length to ensure the ray covers the exact interval.
    $$ \text{step} = \frac{t_1 - t_0}{\text{numSamples}} $$
3.  **Jitter Start:** Apply a random offset to the starting position $t_0$ along the ray to reduce aliasing.
    $$ t_0 \leftarrow t_0 + \left( \frac{\text{rand()}}{\text{RAND\_MAX}} \right) \times \text{step} $$
4.  **Initialize Accumulators:** Set accumulated radiance $L_v = 0$ and transmittance $T_r = 1$.
5.  **Ray Marching Loop:** Iterate $i$ from $0$ to $\text{numSamples} - 1$:
    a.  **Update Position:** Let $p_{prev}$ be the current position and $p$ be the new position $ray(t_0)$.
    b.  **Define Step Ray:** Create a short ray segment from $p_{prev}$ to $p$ with length `step`.
    c.  **Compute Optical Depth:** Calculate the optical depth $\tau$ for this step. The source uses a midpoint evaluation or specific integration logic:
        $$ \tau_{step} = \text{volumes}[0] \to \text{tau}(\text{stepRay}, 0.5 \times \text{step}, 0) $$
    d.  **Update Transmittance:**
        $$ T_r \leftarrow T_r \times e^{-\tau_{step}} $$
    e.  **Accumulate Emitted Light:**
        $$ L_v \leftarrow L_v + \text{volumes}[0] \to \text{Lve}(p) $$
    f.  **Check Scattering:** Get the scattering coefficient $\sigma_s = \text{volumes}[0] \to \sigma_s(p)$. If $\sigma_s$ is non-zero (not black):
        i.  **Light Direction:** Compute the normalized direction $w_L$ from $p$ to the light source.
        ii. **Shadow Ray:** Cast a shadow ray from $p$ in direction $w_L$. Check if it intersects a surface closer than the light distance. If no intersection occurs or the intersection distance is greater than the distance to the light, the point is unshadowed.
        iii. **Light Transmittance:** If unshadowed, compute the transmittance through the volume to the light. The source uses a step size of $2 \times \text{mStepSize}$ for this query:
            $$ l_T = e^{-\text{volumes}[0] \to \text{tau}(\text{shadRay}, 2 \times \text{mStepSize}, 0)} $$
        iv. **Direct Lighting:** Compute the direct lighting contribution $L_d$ using the light's color and the computed transmittance. Add to accumulated radiance:
            $$ L_v \leftarrow L_v + (l_T \times \text{lights}[0] \to \text{color}) \times \sigma_s \times T_r $$
    g.  **Russian Roulette:** If $T_r < 10^{-3}$, perform Russian Roulette. With probability $0.5$, break the loop. Otherwise, continue and scale $T_r$ by $1/0.5$ (i.e., $T_r \leftarrow T_r / 0.5$).

        # Compute optical depth for the step
        # Source: volumes[0]->tau(tRay, 0.5 * step, 0)
        tau_step = volume.tau(step_ray, 0.5 * step, 0)
        
        # Update transmittance
        Tr = Tr * exp(-tau_step)
        
        # Accumulate emitted light
        Lv = Lv + volume.Lve(p)
        
        # Get scattering coefficient
        ss = volume.sigma_s(p)
        
        if ss != Spectrum(0, 0, 0):
            # Compute light direction
            w_L = normalize(light.position - p)
            
            # Shadow ray
            shad_ray = Ray(p, w_L)
            surface_hit = scene.intersect(shad_ray)
            
            # Check if unshadowed
            dist_to_light = (light.position - p).length()
            is_unshadowed = (surface_hit is None) or (surface_hit.t > dist_to_light)
            
            if is_unshadowed:
                # Compute light transmittance
                # Source: volumes[0]->tau(shadRay, mStepSize * 2, 0.0)
                tau_light = volume.tau(shad_ray, mStepSize * 2, 0.0)
                l_tr = exp(-tau_light)
                
                # Direct lighting contribution
                L_d = l_tr * light.color
                Lv = Lv + L_d * ss * Tr
        
        # Russian Roulette
        if Tr < 1e-3:
            if random() < 0.5:
                break
            else:
                Tr = Tr / 0.5
                
        p_prev = p
        
    return Lv, Tr

## Operating characteristics
*   **Complexity:** Time complexity is linear with respect to the number of samples per ray ($O(N)$). Memory complexity is minimal, requiring only storage for the current sample and accumulators, assuming the voxel data is accessed via the accelerated structure.
*   **Performance:** Performance is dependent on the efficiency of the `tau` and `sigma_s` queries within the voxel structure. The use of a fixed step size and Russian Roulette helps manage computational cost in transparent regions.
*   **Limitations:** The implementation is restricted to a single volume and a single light source. It does not support multiple scattering or complex lighting interactions beyond direct illumination from one source [S1, unofficial]. The assumption of a single volume means it cannot handle scenes with multiple overlapping volumetric objects without modification [S1, unofficial].
*   **When to use:** Suitable for simple volumetric effects where a single light source and volume are sufficient, or as a baseline for testing voxel acceleration structures.

## Background
Mr-Voxel is a combination of an accelerated voxel data structure and a volume rendering library, developed as part of a graphics graduate thesis [S1, unofficial]. The lighting equations specific to this volume rendering process are derived or loosely based on the volume rendering sections of "Physically Based Rendering, 2nd edition" by Matt Pharr [S1, unofficial]. The long-term goals included including importance-sampled light caches for all polygonal, implicit and volume objects in a scene [S1, unofficial].
