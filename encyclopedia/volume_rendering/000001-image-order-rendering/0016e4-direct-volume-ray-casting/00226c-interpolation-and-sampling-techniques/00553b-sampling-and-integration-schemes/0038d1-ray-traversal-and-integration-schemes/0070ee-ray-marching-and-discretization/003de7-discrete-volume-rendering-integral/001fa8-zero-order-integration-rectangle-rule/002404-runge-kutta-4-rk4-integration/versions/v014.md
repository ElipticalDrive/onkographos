# Runge-Kutta 4 (RK4) Integration

Also called: Runge-Kutta 4 (RK4), RK4 method, RK4 integration, RK4 Integrator, Runge-Kutta 4 Integrator, 4th order Runge-Kutta, Runge-Kutta 4th order, Fourth Order Runge-Kutta, Order Four Runge-Kutta

## Overview
Runge-Kutta 4 (RK4) is a fourth-order explicit numerical integration method used to compute curved photon and ray trajectories in media with continuously varying properties, such as refractive index or flow velocity [S1, S2, S3]. It solves the initial value problem by taking four slope estimates within a single time step to reduce integration error over time, providing significantly higher accuracy than the first-order Euler method [S3][S4, S5, unofficial]. It sets itself apart from its parent [Zero Order Integration (Rectangle Rule)](2082-zero-order-integration-rectangle-rule.md) by accounting for the variation of the field within the step rather than assuming constancy, and from its sibling [Gaussian Integration for Volume Rendering](5546-gaussian-integration-for-volume-rendering.md) by using a deterministic weighted average of field samples rather than probabilistic sampling [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** Current position $p(t)$ (or $x_i$), time step $\Delta t$ (or $\delta$), and a vector field function $f(p, t)$ (or $\nu(x, t)$) representing the derivative (e.g., velocity, gradient of refractive index) [S3][S5, unofficial].
*   **Output:** New position $p(t + \Delta t)$ (or $x_{i+1}$) [S3][S5, unofficial].

**Data Structures:**
*   **Position:** A 3D vector $(x, y, z)$ [S4, unofficial].
*   **Slopes ($k_1, k_2, k_3, k_4$ or $x_1, x_2, x_3, x_4$):** 3D vectors representing the field values at specific points [S3][S4, unofficial].
*   **Time Step:** A scalar value $\Delta t$ [S3].

**Formulas:**
The update rule for the position is:
$$ p(t + \Delta t) = p(t) + \frac{\Delta t}{6} (k_1 + 2k_2 + 2k_3 + k_4) $$
where the intermediate slopes are calculated as follows [S2][S4, unofficial]:

For a **steady** flow field $f(p)$ [S3]:
$$ k_1 = f(p(t)) $$
$$ k_2 = f\left(p(t) + \frac{\Delta t}{2} k_1\right) $$
$$ k_3 = f\left(p(t) + \frac{\Delta t}{2} k_2\right) $$
$$ k_4 = f(p(t) + \Delta t \cdot k_3) $$

For an **unsteady** flow field $f(p, t)$ [S3][S5, unofficial]:
$$ k_1 = f(p(t), t) $$
$$ k_2 = f\left(p(t) + \frac{\Delta t}{2} k_1, t + \frac{\Delta t}{2}\right) $$
$$ k_3 = f\left(p(t) + \frac{\Delta t}{2} k_2, t + \frac{\Delta t}{2}\right) $$
$$ k_4 = f(p(t) + \Delta t \cdot k_3, t + \Delta t) $$

Note: In some formulations, the slopes $k_i$ include the multiplication by $\Delta t$ (i.e., $k_1 = \Delta t \cdot f(p)$), in which case the final update is $p(t+\Delta t) = p(t) + \frac{1}{6}(k_1 + 2k_2 + 2k_3 + k_4)$ [S4, S5, unofficial]. The implementation below uses the form where $k_i$ are pure field derivatives, consistent with [S3].

**Parameters:**
*   $\Delta t$: The time step size. Described as "small" [S3]. In real-time applications, it is dynamic to maintain performance [S5, unofficial].
*   $t$: Current time. For steady fields, this is ignored or fixed [S5, unofficial].

**Pseudocode:**
```python
def rk4_integrate(pos, dt, vector_field_func, is_unsteady=False, current_time=0.0):
    """
    Performs one step of Runge-Kutta 4 integration.
    
    Args:
        pos: Current position (vec3).
        dt: Time step size (float).
        vector_field_func: Function f(p, t) returning vec3.
        is_unsteady: Boolean flag for time-dependent fields.
        current_time: Current time t (float).
        
    Returns:
        New position (vec3).
    """
    # Step 1: Sample at current position
    k1 = vector_field_func(pos, current_time if is_unsteady else 0.0)
    
    # Step 2: Sample at midpoint using k1
    # Position: pos + (dt/2) * k1
    mid_pos_1 = pos + (dt * 0.5) * k1
    time_1 = current_time + (dt * 0.5) if is_unsteady else current_time
    k2 = vector_field_func(mid_pos_1, time_1)
    
    # Step 3: Sample at midpoint using k2
    # Position: pos + (dt/2) * k2
    mid_pos_2 = pos + (dt * 0.5) * k2
    time_2 = current_time + (dt * 0.5) if is_unsteady else current_time
    k3 = vector_field_func(mid_pos_2, time_2)
    
    # Step 4: Sample at end using k3
    # Position: pos + dt * k3
    end_pos = pos + dt * k3
    time_3 = current_time + dt if is_unsteady else current_time
    k4 = vector_field_func(end_pos, time_3)
    
    # Step 5: Weighted average
    # p(t + dt) = p(t) + (dt / 6) * (k1 + 2*k2 + 2*k3 + k4)
    weighted_sum = k1 + (2.0 * k2) + (2.0 * k3) + k4
    new_pos = pos + (dt / 6.0) * weighted_sum
    
    return new_pos
```

**Edge Cases and Pitfalls:**
*   **Unsteady Flow:** Requires six texture reads (or function evaluations) instead of four because the flow field changes over time, requiring samples at intermediate time steps $t + \Delta t/2$ and $t + \Delta t$ [S3].
*   **Steady Flow:** The time argument must be ignored or set to a fixed value [S5, unofficial].
*   **Precision:** RK4 has an error of $O(dt^5)$ per step, compared to $O(dt^2)$ for Euler [S4, unofficial]. However, it is approximately 4x slower than Euler [S4, unofficial].
*   **Vortices:** RK4 stays within vortices better than Euler, but may sometimes converge to the center of vortices instead of escaping them [S4, unofficial].

## Subtopics

### [Euler Integration](3836-euler-integration.md)
Euler Integration is the most basic numerical method for solving initial value problems (IVPs) in vector fields, estimating the next state based on the derivative at the current single point. In volume rendering, it is numerically equivalent to traditional ray marching, where the radiance variation is evaluated using a single sample per segment. It serves as the baseline explicit integrator for streamline visualization and differential ray marching, distinguished from higher-order siblings like [Runge-Kutta 4 (RK4) Integration](3158-runge-kutta-4-rk4-integration.md) by its first-order accuracy and single-sample-per-step efficiency.

### [Runge-Kutta 2/3 ODE Solver](3839-runge-kutta-2-3-ode-solver.md)
A 2nd/3rd order Runge-Kutta method for solving ODEs with adaptive step size control. It sets itself apart from its parent [Runge-Kutta 4 (RK4) Integration](3158-runge-kutta-4-rk4-integration.md) by using a lower-order formulation that requires fewer function evaluations per step, and from its sibling [Dormand-Prince 5(4) Step](13933-dormand-prince-5-4-step.md) by offering a balance of accuracy and performance with a minimum of four evaluations per step.

### [Tensorline Integration](9613-tensorline-integration.md)
Tensorline Integration visualizes directional information in volumetric tensor fields by integrating streamlines through masked focus regions. It combines fourth-order Runge-Kutta geometric integration with a discrete Riemann sum approximation of the volume rendering integral to composite color and opacity along the ray. It differs from sibling methods like [Euler Integration](3836-euler-integration.md) by using RK4 for higher accuracy in complex flow structures, while relying on discrete compositing for image synthesis.

### [Dormand-Prince 5(4) Step](13933-dormand-prince-5-4-step.md)
The Dormand-Prince 5(4) step is an explicit Runge-Kutta method providing 5th-order accuracy with embedded 4th-order error estimation, used for integrating ordinary differential equations (ODEs) in volume rendering. It sets itself apart from its sibling [Runge-Kutta 4 (RK4) Integration](3158-runge-kutta-4-rk4-integration.md) by computing an embedded error estimate to control step acceptance, whereas RK4 uses a fixed step size [G].

### [Modified 4th Order Runge-Kutta Integration](23697-modified-4th-order-runge-kutta-integration.md)
A numerical integration method used for volume deformation processes, specifically within tensor field visualization. It adapts the standard 4th order Runge-Kutta (RK4) scheme by redefining the force function $F$ to equate position adjustment directly to the force field at the current time step. This modification prioritizes the convergence to the correct resting state of spring models over the accuracy of intermediate integration stages, thereby accelerating processing speed. It differs from standard RK4 by relaxing the requirement for precise trajectory tracking in favor of computational efficiency for static equilibrium solutions.

### Separatrix Integration and Termination
Integrates relevant radial directions (separatrices) triangle-wise using the 4th order Runge-Kutta method [S6, book]. Termination conditions include: (a) the separatrix leaves the domain, (b) it gets close to a degenerate point/line/triangle, or (c) it describes a circle/spiral and passes itself closely in parallel integration direction [S6, book]. Separatrices are stored as polylines [S6, book].

## Operating characteristics
*   **Time Complexity:** Rendering time is proportional to the number of samples. RK4 requires four samples per step, making it quadruple the cost of Euler for the same step size [S2]. It is approximately 4x slower than Euler [S4, unofficial].
*   **Memory Complexity:** Requires storage for the current position, the vector field texture, and potentially intermediate time steps for unsteady fields [S3].
*   **Accuracy:** RK4 error is smaller by an order of magnitude compared to Euler [S4, unofficial]. It closely approaches the analytical solution for linear profiles and avoids significant discrepancies in caustic shape and position compared to piecewise Snell's law approximations [S1].
*   **Strengths:** Higher accuracy allows for larger time steps while maintaining precision [S4, unofficial]. It handles curved trajectories in continuously varying media (e.g., refractive index gradients) much better than lower-order methods [S1].
*   **Limitations:** Higher computational cost per step [S2]. In vortex flows, it may converge to the center rather than escaping, which can be a physical inaccuracy depending on the context [S4, unofficial].
*   **When to use:** When high accuracy is required for curved trajectories in varying media, and computational resources allow for 4x the cost of Euler [S2][S4, unofficial].
*   **When not to use:** When real-time performance is critical and lower accuracy is acceptable, or when the field is constant (Euler is sufficient) [S2][S4, unofficial].

## Background
RK4 was introduced as a standard numerical method for solving ordinary differential equations. In the context of volume rendering and visualization, it has been used to compute curved photon and ray trajectories in media with continuously varying index of refraction [S1], and for particle advection in flow fields [S3][S5, unofficial]. It is cited as a higher-order integrator that reduces integration error significantly compared to Euler [S4, unofficial]. The method is widely used in differential ray marching [S2] and dense geometric flow visualization [S3].
