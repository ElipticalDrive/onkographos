# Mr-Voxel Volume Rendering

Also called: VolumeIntegrator::Li, Mr-Voxel Volume Integrator

## Overview
Mr-Voxel Volume Rendering is a direct volume ray casting technique implemented within the Mr-Voxel library, specifically encapsulated in the `VolumeIntegrator::Li` function [S1, unofficial]. It solves the problem of computing the radiance contribution of a single volumetric region along a ray by marching through the volume, accumulating emitted light and single-scattering contributions from a single light source [S1, unofficial]. It is distinguished from its siblings by its explicit handling of a single volume and single light source within a unified ray-marching loop, relying on a specific step-size discretization and Russian Roulette termination for transmittance culling [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A ray $r(t) = o + td$ defined by origin $o$ and direction $d$, with near/far bounds $t_0$ and $t_1$ defining the intersection segment with the volume.
*   **Input:** A single volume object `volumes[0]` providing methods for optical depth (`tau`), emitted light (`Lve`), and scattering coefficient (`sigma_s`).
*   **Input:** A single light source `lights[0]` providing color.
*   **Input:** A scene object `mScene` providing intersection tests for shadow rays.
*   **Input:** A base step size parameter `mStepSize`.
*   **Output:** A `Spectrum` representing the accumulated radiance $L_v$.
*   **Output:** A transmittance value $T$ updated by the integrator.

**Data Structures:**
The implementation assumes a `VolumeIntegrator` class context. Key fields accessed include:
*   `mStepSize`: The nominal step size for ray marching.
*   `mScene`: Pointer to the scene graph, providing `getVolumeCount()`, `getVolumes()`, `getLightSources()`, and `intersect()`.
*   `volumes[0]`: The active volume object.
*   `lights[0]`: The active light source.

**Numbered Steps:**

1.  **Sample Count Calculation:** Calculate the number of samples $N$ required to cover the ray segment length $(t_1 - t_0)$ using the base step size `mStepSize`.
    $$ N = \left\lceil \frac{t_1 - t_0}{\text{mStepSize}} \right\rceil $$
    If $N < 1$, set $N = 1$ [S1, unofficial].

2.  **Step Length Adjustment:** Compute the actual step length $\Delta l$ to ensure the ray exactly reaches $t_1$ after $N$ steps:
    $$ \Delta l = \frac{t_1 - t_0}{N} $$
    [S1, unofficial].

3.  **Jittered Start:** Apply a random offset to the starting parameter $t_0$ to reduce banding artifacts. Generate a random float $u \in [0, 1)$ and update:
    $$ t_0 \leftarrow t_0 + u \cdot \Delta l $$
    [S1, unofficial].

4.  **Initialization:** Initialize accumulated radiance $L_v = 0$ and current transmittance $T_r = 1$. Initialize previous position $p_{prev}$ to the ray origin at $t_0$.

5.  **Marching Loop:** Iterate $i$ from $0$ to $N-1$:
    a.  **Position Update:** Compute current position $p = r(t_0 + i \cdot \Delta l)$. Define a short ray segment `tRay` from $p_{prev}$ to $p$ with length $\Delta l$.
    b.  **Optical Depth:** Compute the optical depth $\tau$ for the segment `tRay`. The source code samples the optical depth at the midpoint ($0.5 \cdot \Delta l$) of the segment:
        $$ \tau = \text{volumes}[0].\text{tau}(\text{tRay}, 0.5 \cdot \Delta l, 0) $$
        [S1, unofficial].
    c.  **Transmittance Update:** Update the accumulated transmittance:
        $$ T_r \leftarrow T_r \cdot e^{-\tau} $$
        [S1, unofficial].
    d.  **Emission Accumulation:** Retrieve the emitted light $L_e$ at position $p$ and add to the accumulator:
        $$ L_v \leftarrow L_v + \text{volumes}[0].L_e(p) $$
        [S1, unofficial].
    e.  **Scattering Check:** Retrieve the scattering coefficient $\sigma_s = \text{volumes}[0].\sigma_s(p)$. If $\sigma_s$ is effectively zero (black), skip lighting calculations for this step and continue to the next iteration [S1, unofficial].
    f.  **Lighting Direction:** Compute the normalized direction vector $\omega_L$ from $p$ to the light source position.
    g.  **Shadow Ray:** Create a shadow ray `shadRay` starting at $p$ in direction $\omega_L$. Check for occlusion by geometry:
        $$ \text{isUnshadowed} = \neg (\text{mScene}.\text{intersect}(\text{shadRay}, \text{surface}) \land \text{surface}.t < \|p - \text{lightPos}\|) $$
        [S1, unofficial].
    h.  **Light Transmittance:** If `isUnshadowed` is true, compute the light transmittance $T_l$ through the volume along the path to the light. The source code uses a step size of `mStepSize * 2` for this calculation:
        $$ T_l = e^{-\text{volumes}[0].\text{tau}(\text{shadRay}, \text{mStepSize} \cdot 2, 0.0)} $$
        [S1, unofficial].
    i.  **Direct Lighting Contribution:** Compute the direct lighting contribution $L_d$ and add to $L_v$:
        $$ L_d = T_l \cdot \text{lights}[0].\text{color} $$
        $$ L_v \leftarrow L_v + L_d \cdot \sigma_s \cdot T_r $$
        [S1, unofficial].
    j.  **Termination (Russian Roulette):** If $T_r < 10^{-3}$, perform Russian Roulette. With probability $p_{kill} = 0.5$, break the loop. Otherwise, continue and scale the transmittance to maintain unbiasedness:
        $$ T_r \leftarrow \frac{T_r}{0.5} $$
        [S1, unofficial].
    k.  Update $p_{prev} \leftarrow p$.

6.  **Return:** Return $L_v$ as the accumulated radiance.

**Pseudocode:**

```python
def mr_voxel_volume_render(ray_origin, ray_direction, t_near, t_far, m_step_size, scene, volumes, lights):
    # 1. Calculate number of samples
    num_samples = ceil((t_far - t_near) / m_step_size)
    if num_samples < 1:
        num_samples = 1

    # 2. Calculate actual step length
    step = (t_far - t_near) / num_samples

    # 3. Apply random offset to starting position
    u = random_float(0.0, 1.0)
    t_current = t_near + u * step

    # 4. Initialize accumulators
    Lv = Spectrum(0.0, 0.0, 0.0)
    Tr = 1.0
    p_prev = ray_origin + t_current * ray_direction

    # 5. Marching loop
    for i in range(num_samples):
        # a. Position Update
        t_next = t_current + step
        p = ray_origin + t_next * ray_direction
        
        # Create short ray segment from p_prev to p
        # Note: The source calculates tau using a helper function on a ray segment
        # We approximate the segment ray for the tau function
        segment_ray_origin = p_prev
        segment_ray_direction = p - p_prev
        segment_ray_length = length(segment_ray_direction)
        
        # b. Optical Depth
        # Source samples at midpoint (0.5 * step)
        tau = volumes[0].tau(segment_ray_origin, segment_ray_direction, 0.5 * step, 0)
        
        # c. Transmittance Update
        Tr = Tr * exp(-tau)
        
        # d. Emission Accumulation
        Lv = Lv + volumes[0].Lve(p)
        
        # e. Scattering Check
        sigma_s = volumes[0].sigma_s(p)
        
        # Check if sigma_s is black/zero
        if not is_black(sigma_s):
            # f. Lighting Direction
            light_pos = lights[0].position
            w_L = normalize(light_pos - p)
            
            # g. Shadow Ray
            # Check if ray intersects surface closer than light distance
            surface_hit = scene.intersect(p, w_L)
            light_dist = length(light_pos - p)
            
            is_unshadowed = True
            if surface_hit is not None:
                if surface_hit.t < light_dist:
                    is_unshadowed = False
            
            # h. Light Transmittance
            if is_unshadowed:
                # Source uses mStepSize * 2 for light transmittance calculation
                # We assume tau function takes a ray and a length parameter
                light_tau = volumes[0].tau(p, w_L, m_step_size * 2, 0.0)
                l_Tr = exp(-light_tau)
                
                # i. Direct Lighting Contribution
                Ld = l_Tr * lights[0].color
                Lv = Lv + Ld * sigma_s * Tr
        
        # j. Termination (Russian Roulette)
        if Tr < 1e-3:
            if random_float(0.0, 1.0) < 0.5:
                break
            else:
                Tr = Tr / 0.5
        
        # k. Update previous position
        p_prev = p
        t_current = t_next

    return Lv
```

**Parameters:**
*   `mStepSize`: The nominal step size for ray marching. Typical values are not specified in the sources, but it serves as the base for calculating `numSamples` and the light transmittance integration length [S1, unofficial].
*   `1e-3`: The transmittance threshold for triggering Russian Roulette [S1, unofficial].
*   `0.5`: The survival probability for Russian Roulette [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Zero Samples:** If the ray segment is shorter than `mStepSize`, `numSamples` is forced to 1 to prevent division by zero or empty loops [S1, unofficial].
*   **Single Volume/Light Assumption:** The implementation explicitly accesses `volumes[0]` and `lights[0]`. It does not support multiple volumes or lights in the current form; a TODO comment indicates that aggregators are needed for multi-volume scenes [S1, unofficial].
*   **Precision:** The use of `rand() / RAND_MAX` for jittering is a standard C-style random number generation method [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of samples $N$, where $N \approx \frac{\text{Ray Length}}{\text{mStepSize}}$. Each sample involves a constant number of volume queries and potentially one shadow ray intersection.
*   **Memory Complexity:** $O(1)$ auxiliary memory, as it accumulates radiance in a single pass without storing sample history.
*   **Strengths:** Simple implementation; handles single-scattering and emission correctly; uses Russian Roulette for efficient termination in optically thick regions.
*   **Limitations:** Limited to single volume and single light source per integrator call; no multiple scattering; performance depends heavily on `mStepSize` and scene density.
*   **When to Use:** Suitable for simple volumetric effects or as a building block for more complex integrators where single-scattering is sufficient. Not suitable for dense, participating media with significant multiple scattering.

## Background
Mr-Voxel is a volume rendering library and accelerated voxel data structure developed by C. Gibson as part of his graphics graduate thesis [S1, unofficial]. The volume rendering technique described herein is implemented in the `VolumeIntegrator::Li` function. The lighting equations are derived or loosely based on the volume rendering sections of "Physically Based Rendering, 2nd edition" by Matt Pharr [S1, unofficial]. The project aims to include importance-sampled light caches for polygonal, implicit, and volume objects in the long term [S1, unofficial].
