# DVGO Density and Color Rendering

Also called: DVGO volume rendering

## Overview
DVGO (Density Volume Grid Optimization) is a direct volume rendering method that accelerates neural volume rendering by decoupling density and color representation into separate data structures: a 3D voxel grid for density and a shallow Multi-Layer Perceptron (MLP) for view-dependent color [S1]. It solves the computational bottleneck of standard NeRF-style methods by replacing the density MLP with trilinear interpolation on a sparse or dense grid, allowing for faster training and inference while maintaining high-fidelity view-dependent effects through the color network [S1]. Unlike [Mr-Voxel Volume Rendering](3874-mr-voxel-volume-rendering.md) which may use explicit voxel traversal, DVGO relies on fixed-step ray marching with trilinear sampling [S1].

## How it works

### Inputs and Outputs
*   **Inputs**: Camera ray $r(t) = o + td$ defined by origin $o$ and direction $d$; near plane $t_n$ and far plane $t_f$; grid resolution $N_x \times N_y \times N_z$; number of samples $n$ per ray.
*   **Outputs**: Pixel color $\hat{C}(r)$.

### Data Structures
1.  **Density Grid ($V^{(\sigma)}$)**: A 3D tensor of shape $R \times N_x \times N_y \times N_z$. Stores raw density values $\ddot{\sigma}_i \in \mathbb{R}$. The dimension $R$ represents the number of channels (typically 1 for scalar density, but the source notation $V$ implies a feature-like storage; however, Eq. 2 uses $\ddot{\sigma}_i$ directly, implying scalar storage or a single channel extraction) [S1].
2.  **Feature Grid ($V^{(f)}$)**: A 3D tensor of shape $C \times N_x \times N_y \times N_z$. Stores feature vectors $f_i \in \mathbb{R}^C$ used for color prediction [S1].
3.  **Color MLP ($MLP_\Theta$)**: A shallow neural network with parameters $\Theta$. It takes the interpolated feature vector, positional encoding of position, and positional encoding of direction as input [S1].
4.  **Hyperparameters**:
    *   $b$: Shift parameter for softplus activation [S1].
    *   $c_{bg}$: Pre-defined background color [S1].

### Numbered Steps

1.  **Ray Sampling**: For a given ray $r$, sample $n$ points $x_i$ uniformly between $t_n$ and $t_f$. Let $\delta_i$ be the distance between adjacent sample points (constant step size $\Delta t = (t_f - t_n)/n$) [S1].
2.  **Trilinear Interpolation**: For each sample point $x_i$, retrieve the raw density value $\ddot{\sigma}_i$ from $V^{(\sigma)}$ and the feature vector $f_i$ from $V^{(f)}$ using trilinear interpolation:
    $$ \ddot{\sigma}_i = \text{interp}(x_i, V^{(\sigma)}) $$
    $$ f_i = \text{interp}(x_i, V^{(f)}) $$
    [S1]
3.  **Density Activation**: Apply the shifted softplus function to map the raw grid value to a non-negative density $\sigma_i$:
    $$ \sigma_i = \text{softplus}(\ddot{\sigma}_i) = \log(1 + \exp(\ddot{\sigma}_i + b)) $$
    [S1]
4.  **Color Prediction**: Compute the view-dependent color emission $c_i^{(rgb)}$ by passing the feature vector $f_i$, the position $x_i$, and the ray direction $d$ through the color MLP. Positional encoding (PE) is applied to $x_i$ and $d$:
    $$ c_i^{(rgb)} = MLP_\Theta(\text{PE}(f_i), \text{PE}(x_i), \text{PE}(d)) $$
    [S1]
5.  **Alpha Calculation**: Calculate the termination probability (alpha) for each sample:
    $$ \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
    [S1]
6.  **Transmittance Accumulation**: Calculate the accumulated transmittance $T_i$ from the near plane to point $x_i$:
    $$ T_i = \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    [S1]
7.  **Composite Color**: Accumulate the color contributions using volume rendering quadrature:
    $$ \hat{C}(r) = \sum_{i=1}^{n} T_i \alpha_i c_i^{(rgb)} + T_{n+1} c_{bg} $$
    [S1]

    densities = []
    colors = []
    
    for i in range(n_samples):
        x_i = ray_origin + ray_direction * t_samples[i]
        
        # Interpolate
        raw_sigma = trilinear_interp(density_grid, x_i)
        f_i = trilinear_interp(feature_grid, x_i)
        
        # Density Activation: softplus(raw_sigma + b)
        sigma_i = math.log(1 + math.exp(raw_sigma + b_shift))
        densities.append(sigma_i)
        
        # Color Prediction
        pos_pe = positional_encoding(x_i)
        c_i = color_mlp(f_i, pos_pe, dir_pe)
        colors.append(c_i)
        
    densities = np.array(densities)
    colors = np.array(colors)
    
    # Step 5 & 6: Alpha and Transmittance
    # alpha_i = 1 - exp(-sigma_i * dt)
    alphas = 1.0 - np.exp(-densities * dt)
    
    # T_i = product(1 - alpha_j) for j < i
    # T_1 = 1.0
    # T_2 = 1 - alpha_1
    # ...
    # We can compute this efficiently with cumulative product
    one_minus_alpha = 1.0 - alphas
    # T[i] is the transmittance BEFORE sample i
    # T[0] = 1.0
    # T[1] = 1 - alpha[0]
    # T[2] = (1 - alpha[0]) * (1 - alpha[1])
    
    # Cumulative product of (1-alpha)
    # np.cumprod returns [p0, p0*p1, ...]
    # We need T[i] = prod_{j=0}^{i-1} (1-alpha[j])
    # So T[0] = 1
    # T[1] = 1-alpha[0]
    
    cum_prod = np.concatenate(([1.0], np.cumprod(one_minus_alpha[:-1])))
    transmittances = cum_prod
    
    # Step 7: Composite
    # C = sum(T_i * alpha_i * c_i) + T_{n+1} * bg
    # T_{n+1} is the transmittance after the last sample
    T_last = np.prod(one_minus_alpha)
    
    contribution = transmittances * alphas * colors
    final_color = np.sum(contribution, axis=0) + T_last * bg_color
    
    return final_color

### Parameters and Edge Cases
*   **Shift $b$**: A hyperparameter in the softplus activation. It controls the sharpness of the density transition. A larger $b$ makes the transition sharper [S1].
*   **Post-Activation**: DVGO explicitly applies non-linear activation (softplus) *after* trilinear interpolation. This "post-activation" strategy is noted to produce sharper surfaces compared to pre-activation, allowing for fewer cells to represent surface details [S1].
*   **Background**: The term $T_{n+1} c_{bg}$ handles the case where the ray passes through the entire volume without terminating. $c_{bg}$ is a learnable or pre-defined constant [S1].

## Operating characteristics

*   **Time Complexity**: $O(n \cdot (N_{interp} + N_{MLP}))$ per ray, where $n$ is the number of samples, $N_{interp}$ is the cost of trilinear interpolation (constant time, 8 texture lookups), and $N_{MLP}$ is the cost of the shallow color network. This is significantly faster than full NeRF which requires an MLP for both density and color.
*   **Memory Complexity**: $O(N_x N_y N_z (1 + C))$, where $C$ is the feature dimension. This is generally lower than the memory required for the large MLPs in standard NeRFs if the grid resolution is moderate, but can be high for very high-resolution grids.
*   **Strengths**: Fast training and inference due to grid-based density lookup; sharp surface rendering via post-activation; view-dependent color via MLP [S1].
*   **Limitations**: Fixed grid resolution limits detail; memory usage scales with grid size; trilinear interpolation can cause blurring if the grid is too coarse [S1].
*   **When to use**: When real-time or fast training of neural volumes is required, and the scene has sharp surfaces that benefit from post-activation [S1].

## Background

DVGO was introduced in the paper "NeRF Synthesis with Shading Guidance" [S1]. It builds upon the principles of NeRF but optimizes the density representation by moving it from a neural network to a 3D voxel grid, while retaining a neural network for view-dependent color. This hybrid approach aims to balance the representational power of neural networks with the computational efficiency of grid-based methods.
