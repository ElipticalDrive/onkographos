# DVGO Density and Color Rendering

Also called: DVGO volume rendering

## Overview
DVGO renders 3D scenes by decoupling geometry and appearance into a voxel grid and a neural network [S1]. It maps stored grid values to non-negative densities using a shifted softplus activation, and computes view-dependent color emission via a shallow MLP taking interpolated features and positional encodings [S1]. The method accumulates radiance along rays using standard volume rendering quadrature [S1]. Post-activation interpolation (applying non-linearities after trilinear interpolation) produces sharp surfaces, reducing the required grid resolution for surface detail [S1].

## How it works
**Inputs and Outputs:** The method takes a voxel grid resolution $N_x \times N_y \times N_z$, a feature grid $V^{(f)}$, a density grid $V^{(d)}$, a shallow MLP $MLP_\Theta$, a shift hyperparameter $b$, a sample count $n$, and a background color $c_{bg}$ [S1]. It outputs the rendered color $\hat{C}(r)$ for a camera ray $r$ [S1].

**Data Structures:**
1. **Density Grid ($V^{(d)}$):** 3D tensor of shape $(N_x, N_y, N_z)$ storing raw scalar values $\ddot{\sigma}$, which serve as inputs to the activation function [S1].
2. **Feature Grid ($V^{(f)}$):** 3D tensor of shape $(C, N_x, N_y, N_z)$ storing $C$-dimensional feature vectors at each voxel [S1].
3. **MLP ($MLP_\Theta$):** Small neural network mapping concatenated interpolated features and positional encodings to RGB color [S1].

**Numbered Steps:**
1. **Ray Casting & Sampling:** For each pixel, cast ray $r$ from camera origin [S1]. Sample $n$ points $x_i$ uniformly between near and far planes [S1]. Let $\delta_i$ be the distance to the adjacent sampled point [S1].
2. **Density Retrieval:** Interpolate raw density $\ddot{\sigma}_i$ from $V^{(d)}$ at $x_i$ using trilinear interpolation [S1].
3. **Density Activation:** Compute $\sigma_i = \text{softplus}(\ddot{\sigma}_i)$ [S1].
4. **Color Feature Retrieval:** Interpolate feature vector $f_i$ from $V^{(f)}$ at $x_i$ using trilinear interpolation [S1].
5. **Color Emission:** Apply positional encoding $\gamma(\cdot)$ to $x_i$ and ray direction $d$ [S1]. Compute $c_i^{(rgb)} = MLP_\Theta([f_i; \gamma(x_i); \gamma(d)])$ [S1].
6. **Termination Probability:** Compute $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$ [S1].
7. **Accumulated Transmittance:** Compute $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$, with $T_1 = 1$ [S1].
8. **Volume Rendering Quadrature:** Accumulate color $\hat{C}(r) = \sum_{i=1}^{n} T_i \alpha_i c_i^{(rgb)} + T_{n+1} c_{bg}$ [S1].

**Formulas:**
- Density activation: $\sigma_i = \text{softplus}(\ddot{\sigma}_i) = \log(1 + \exp(\ddot{\sigma}_i + b))$, where $\ddot{\sigma}_i$ is the value stored in $V^{(d)}$ and $b$ is a hyperparameter shift [S1].
- Color emission: $c_i^{(rgb)} = MLP_\Theta(\text{interp}(x_i, V^{(f)}), x_i, d)$, where $x_i$ is the position, $V^{(f)}$ is the feature grid, and $d$ is the ray direction [S1].
- Termination probability: $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$, where $\delta_i$ is the distance to the adjacent sampled point [S1].
- Accumulated transmittance: $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$, denoting transmittance from the near plane to point $x_i$ [S1].
- Volume rendering quadrature: $\hat{C}(r) = \sum_{i=1}^{n} T_i \alpha_i c_i^{(rgb)} + T_{n+1} c_{bg}$, where $c_{bg}$ is a pre-defined background color [S1].

**Parameters:**
- $b$: Shift hyperparameter for the softplus activation [S1].
- $n$: Number of sample points along the ray [S1].
- $c_{bg}$: Pre-defined background color [S1].
- Typical values: Not given in the sources.

**Pseudocode:**
```python
import math
import numpy as np

def softplus(x, b=0.0):
    """Shifted softplus activation: log(1 + exp(x + b))."""
    return np.log(1.0 + np.exp(x + b))

def trilinear_interpolate(grid, x, y, z):
    """Trilinear interpolation for 3D or 4D grids. Coordinates in [0, 1]."""
    x = np.clip(x, 0.0, 1.0)
    y = np.clip(y, 0.0, 1.0)
    z = np.clip(z, 0.0, 1.0)
    
    if grid.ndim == 3:
        C = 1
        Nx, Ny, Nz = grid.shape
    else:
        C, Nx, Ny, Nz = grid.shape
        
    ix = np.floor(x * (Nx - 1)).astype(int)
    iy = np.floor(y * (Ny - 1)).astype(int)
    iz = np.floor(z * (Nz - 1)).astype(int)
    
    fx = x * (Nx - 1) - ix
    fy = y * (Ny - 1) - iy
    fz = z * (Nz - 1) - iz
    
    ix1 = np.minimum(ix + 1, Nx - 1)
    iy1 = np.minimum(iy + 1, Ny - 1)
    iz1 = np.minimum(iz + 1, Nz - 1)
    
    if C == 1:
        v000 = grid[ix, iy, iz]
        v100 = grid[ix1, iy, iz]
        v010 = grid[ix, iy1, iz]
        v110 = grid[ix1, iy1, iz]
        v001 = grid[ix, iy, iz1]
        v101 = grid[ix1, iy, iz1]
        v011 = grid[ix, iy1, iz1]
        v111 = grid[ix1, iy1, iz1]
    else:
        v000 = grid[:, ix, iy, iz]
        v100 = grid[:, ix1, iy, iz]
        v010 = grid[:, ix, iy1, iz]
        v110 = grid[:, ix1, iy1, iz]
        v001 = grid[:, ix, iy, iz1]
        v101 = grid[:, ix1, iy, iz1]
        v011 = grid[:, ix, iy1, iz1]
        v111 = grid[:, ix1, iy1, iz1]
        
    w000 = (1 - fx) * (1 - fy) * (1 - fz)
    w100 = fx * (1 - fy) * (1 - fz)
    w010 = (1 - fx) * fy * (1 - fz)
    w110 = fx * fy * (1 - fz)
    w001 = (1 - fx) * (1 - fy) * fz
    w101 = fx * (1 - fy) * fz
    w011 = (1 - fx) * fy * fz
    w111 = fx * fy * fz
    
    return (w000 * v000 + w100 * v100 + w010 * v010 + w110 * v110 +
            w001 * v001 + w101 * v101 + w011 * v011 + w111 * v111)

def positional_encoding(x, min_deg=0, max_deg=10):
    """[G] Standard NeRF positional encoding: [sin(2^k pi x), cos(2^k pi x)]."""
    scales = [2 ** i for i in range(min_deg, max_deg)]
    scaled_x = np.outer(x, np.array(scales) * np.pi)
    return np.concatenate([np.sin(scaled_x), np.cos(scaled_x)], axis=-1)

def render_ray(ray_origin, ray_direction, near, far, 
               density_grid, feature_grid, mlp, b, n_samples, c_bg):
    """Renders a single ray using DVGO."""
    t_vals = np.linspace(near, far, n_samples)
    points = ray_origin + t_vals[:, np.newaxis] * ray_direction
    
    delta = (far - near) / (n_samples - 1) if n_samples > 1 else (far - near)
    
    accumulated_color = np.zeros(3)
    accumulated_transmittance = 1.0
    
    for i in range(n_samples):
        x, y, z = points[i]
        
        raw_density = trilinear_interpolate(density_grid, x, y, z)
        sigma = softplus(raw_density, b)
        
        alpha = 1.0 - np.exp(-sigma * delta)
        
        color_features = trilinear_interpolate(feature_grid, x, y, z)
        
        pos_enc = positional_encoding(points[i], min_deg=0, max_deg=10)
        dir_enc = positional_encoding(ray_direction, min_deg=0, max_deg=4)
        mlp_input = np.concatenate([color_features, pos_enc, dir_enc])
        color_emission = mlp(mlp_input)
        
        weight = accumulated_transmittance * alpha
        accumulated_color += weight * color_emission
        accumulated_transmittance *= (1.0 - alpha)
        
    accumulated_color += accumulated_transmittance * c_bg
    
    return accumulated_color
```

**Edge Cases and Pitfalls:**
- **Post-Activation Sharpness:** Applying non-linear activation functions (like softplus) *after* trilinear interpolation produces sharper surfaces than pre-activation, allowing fewer grid cells for surface detail [S1].
- **Boundary Conditions:** Coordinates must be clamped to the grid bounds before interpolation to prevent out-of-bounds indexing [G].
- **Precision:** The exponential function in $\alpha_i$ and $T_i$ can underflow or overflow if $\sigma_i \delta_i$ is extreme [G].

## Background
