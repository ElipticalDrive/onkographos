# Procedural Volumetric Cloud Rendering

Also called: Nubis³, Nubis Cubed, Nubis Evolved, Volumetric Cloud Renderer, Volumetric Cloud Rendering, Real-time Volumetric Cloud Rendering

## Overview
Procedural Volumetric Cloud Rendering is a real-time technique that ray-marches a spherical cloud layer built from tileable 3D noise fields, lighting it with a multiple-scattering approximation and temporal reprojection to allow rendering at reduced resolutions [S3, unofficial]. It combines Schneider’s Nubis density model (from Horizon Zero Dawn) with Hillaire 2016 light transport (from Frostbite) [S1, unofficial]. It is distinguished from sibling methods by its camera-centred direction grid for sky integration and its explicit lifting of the cloud layer above terrain relief to avoid depth-compositing artifacts [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Camera position ($u_{CamPos}$), inverse view-projection matrix ($u_{InvViewProj}$), sun direction ($u_{SunDir}$), sun color, time ($u_{Time}$), wind vector ($u_{Wind}$), cloud coverage ($u_{Coverage}$), density multiplier ($u_{Density}$), cloud type ($u_{CloudType}$), base height ($u_{BaseHeight}$), thickness ($u_{Thickness}$), anisotropy ($u_{Anisotropy}$), extinction ($u_{Extinction}$), ambient intensity ($u_{Ambient}$), and erosion amount ($u_{Erosion}$).
*   **Textures:**
    *   $u_{Shape}$: 128³ sampler3D (Perlin fbm dilated by Worley, plus three Worley octaves) [S3, unofficial].
    *   $u_{Detail}$: 32³ sampler3D (Worley detail) [S3, unofficial].
    *   $u_{Weather}$: 512² sampler2D (coverage and cloud type per region) [S3, unofficial].
*   **Outputs:**
    *   `outColor` (vec4): RGB is in-scattered radiance, A is transmittance [S3, unofficial].
    *   `outDepth` (float): Metres along the ray, 0 if no cloud [S3, unofficial].

**Data Structures:**
*   **Cloud Layer:** Defined by a spherical shell with inner radius $R_{Inner}$ and outer radius $R_{Outer}$. $R_{Outer} = EARTH\_RADIUS + u_{BaseHeight} + u_{Thickness}$. $R_{Inner} = EARTH\_RADIUS + u_{BaseHeight}$. $EARTH\_RADIUS = 6371000.0$ metres [S3, unofficial].
*   **Noise Tiles:** Shape noise tile size is $1/SHAPE\_SCALE = 9000$ metres. Detail noise tile size is $1/DETAIL\_SCALE = 900$ metres. Weather map scale is $1/WEATHER\_SCALE = 48000$ metres [S3, unofficial].

**Numbered Steps:**

1.  **Ray Setup:**
    *   Convert vertex UV to ray direction based on quadrant:
        *   If $uv.x < 0.5$ and $uv.y < 0.5$: `rayDirWorld` = `_FrustumCornerBL`
        *   If $uv.x < 0.5$ and $uv.y \ge 0.5$: `rayDirWorld` = `_FrustumCornerTL`
        *   If $uv.x \ge 0.5$ and $uv.y < 0.5$: `rayDirWorld` = `_FrustumCornerBR`
        *   Else: `rayDirWorld` = `_FrustumCornerTR` [S4, unofficial].
    *   Normalize `rayDirWorld` to get `rayDir`.
    *   Calculate `oc = ro - vec3(0.0, -EARTH_RADIUS, 0.0)`, where `ro` is camera position [S3, unofficial].
    *   Calculate `rCam = length(oc)`, `b = dot(oc, rd)`, `c = dot(oc, oc)` [S3, unofficial].
    *   Compute `hOuter = b * b - (c - rOuter * rOuter)`. If `hOuter < 0.0`, return [S3, unofficial].
    *   Compute `sOuter = sqrt(hOuter)`, `tOuterNear = -b - sOuter`, `tOuterFar = -b + sOuter` [S3, unofficial].
    *   Compute `hInner = b * b - (c - rInner * rInner)`. If `hInner > 0.0`, `sInner = sqrt(hInner)`, else `sInner = 0.0` [S3, unofficial].
    *   Determine intersection interval $[t_{start}, t_{end}]$ based on whether the camera is inside or outside the shell. If camera is outside ($rCam > rOuter$), $t_{start} = tOuterNear$, $t_{end} = tOuterFar$. If inside, $t_{start} = 0$, $t_{end} = tOuterFar$ (assuming ray exits outward) or handle inner intersection if ray points inward [S3, unofficial]. *Note: Source [S3, unofficial] implies intersection with spherical shell, allowing camera to be below, inside or above.*

2.  **Marching Loop:**
    *   Initialize `transmittance = 1.0`, `radiance = vec3(0.0)`, `depthAccum = 0.0`, `transmittanceWeightedDepth = 0.0`.
    *   Calculate step size `dt` derived from ray span through layer divided by `uMaxSteps` [S3, unofficial].
    *   Jitter step start position using interleaved gradient noise (Halton sequence) per pixel [S3, unofficial].
    *   Loop `i` from 0 to `uMaxSteps`:
        *   If `transmittance < 0.005` (0.5%), break [S3, unofficial].
        *   Current position `p = ro + t * rd`.
        *   **Density Sampling:**
            *   Get weather coverage `cov` from $u_{Weather}$ at `p`'s horizontal position [S3, unofficial].
            *   Select vertical profile based on `uCloudType` (stratus, cumulus, cumulonimbus) [S3, unofficial].
            *   Sample $u_{Shape}$ at `p` with wind offset `uWind * uTime` and height shear [S3, unofficial].
            *   Sample $u_{Detail}$ at `p` [S3, unofficial].
            *   Compute base density from shape noise.
            *   Apply erosion: `erosionWeight = pow(1.0 - baseDensity, 6)` (quintic) [S2, unofficial]. `finalDensity = baseDensity - erosionWeight * uErosion * detailSample` [S2, unofficial].
            *   Scale by coverage and `uDensity` [S3, unofficial].
            *   Apply vertical profile falloff based on height relative to `uBaseHeight` [S1, unofficial].
        *   **Lighting (In-scattering):**
            *   Calculate optical depth to sun: Sample density 6 times along ray towards `uSunDir` [S3, unofficial]. `tau = sum(density * stepSize)` [S2, unofficial].
            *   Calculate light transmittance: `lightTransmittance = exp(-tau * uExtinction)` [S2, unofficial].
            *   Calculate phase function: `phaseVal = HenyeyGreenstein(dot(rd, sunDir), uAnisotropy)` [S2, unofficial].
            *   Calculate multiple scattering approximation: Evaluate 4-octave approximation (attenuated extinction, contribution, phase eccentricity) [S3, unofficial].
            *   Calculate powder term: Darkens back-lit edges [S3, unofficial].
            *   Calculate ambient term: Interpolate between `AMBIENT_TOP` (vec3(0.62, 0.74, 0.95)) and `AMBIENT_BOTTOM` (vec3(0.36, 0.42, 0.52)) based on height [S3, unofficial].
            *   Integrate in-scattering analytically over step `dt`: `dRadiance = lightTransmittance * phaseVal * multipleScattering * powder * ambient * density * dt` [S3, unofficial].
            *   Update `radiance += dRadiance * transmittance`.
            *   Update `transmittance *= exp(-density * uExtinction * dt)` [S2, unofficial].
            *   Update `depthAccum += dt`.
            *   Update `transmittanceWeightedDepth += dt * transmittance`.
            *   `t += dt` [S3, unofficial].

3.  **Output:**
    *   `outColor.rgb = radiance`.
    *   `outColor.a = transmittance`.
    *   `outDepth = transmittanceWeightedDepth / max(transmittanceWeightedDepth, 1e-6)` (mean depth) [S3, unofficial].

**Pseudocode:**

```python
# Constants
EARTH_RADIUS = 6371000.0
AMBIENT_TOP = vec3(0.62, 0.74, 0.95)
AMBIENT_BOTTOM = vec3(0.36, 0.42, 0.52)

def ray_sphere_intersection(ro, rd, r_inner, r_outer):
    oc = ro - vec3(0.0, -EARTH_RADIUS, 0.0)
    b = dot(oc, rd)
    c = dot(oc, oc)
    
    # Outer sphere
    h_outer = b*b - (c - r_outer*r_outer)
    if h_outer < 0.0:
        return None, None
    
    s_outer = sqrt(h_outer)
    t_outer_near = -b - s_outer
    t_outer_far = -b + s_outer
    
    # Inner sphere
    h_inner = b*b - (c - r_inner*r_inner)
    s_inner = sqrt(h_inner) if h_inner > 0.0 else 0.0
    
    # Determine interval
    # Assuming camera is outside or on surface for simplicity, 
    # or handling inside case as per source [S3, unofficial]
    t_start = max(0.0, t_outer_near)
    t_end = t_outer_far
    
    if t_start > t_end:
        return None, None
        
    return t_start, t_end

def henyey_greenstein(cos_theta, g):
    g2 = g * g
    numerator = 1.0 - g2
    denominator = pow(1.0 + g2 - 2.0 * g * cos_theta, 1.5)
    return numerator / (4.0 * 3.14159 * denominator)

def main(ro, rd, u_shape, u_detail, u_weather, u_inv_view_proj, u_sun_dir, u_time, u_wind, u_coverage, u_density, u_cloud_type, u_base_height, u_thickness, u_anisotropy, u_extinction, u_ambient, u_erosion, u_max_steps):
    r_outer = EARTH_RADIUS + u_base_height + u_thickness
    r_inner = EARTH_RADIUS + u_base_height
    
    t_start, t_end = ray_sphere_intersection(ro, rd, r_inner, r_outer)
    if t_start is None:
        return vec4(0.0), 0.0
    
    dt = (t_end - t_start) / u_max_steps
    t = t_start
    
    radiance = vec3(0.0)
    transmittance = 1.0
    depth_accum = 0.0
    trans_weighted_depth = 0.0
    
    for i in range(u_max_steps):
        if transmittance < 0.005:
            break
            
        p = ro + t * rd
        
        # Density
        # 1. Weather map lookup for coverage and type
        # 2. Shape noise sample with wind
        # 3. Detail noise sample
        # 4. Combine and erode
        density = compute_density(p, u_shape, u_detail, u_weather, u_wind, u_time, u_coverage, u_density, u_cloud_type, u_base_height, u_erosion)
        
        if density <= 0.0:
            t += dt
            continue
            
        # Lighting
        # 1. Optical depth to sun
        tau = 0.0
        for j in range(6):
            sun_p = p + j * dt * 0.5 * u_sun_dir # Approximate path
            tau += sample_density(sun_p, u_shape, u_detail, u_weather, u_wind, u_time) * dt * 0.5
            
        light_trans = exp(-tau * u_extinction)
        
        # 2. Phase
        phase = henyey_greenstein(dot(normalize(rd), normalize(u_sun_dir)), u_anisotropy)
        
        # 3. Multiple scattering approx (simplified)
        ms = compute_multiple_scattering(density, tau)
        
        # 4. Ambient
        height = length(p - vec3(0.0, -EARTH_RADIUS, 0.0)) - EARTH_RADIUS
        ambient_factor = mix(AMBIENT_TOP, AMBIENT_BOTTOM, clamp(height / u_thickness, 0.0, 1.0))
        
        # 5. Powder term (simplified)
        powder = 1.0 - clamp(dot(normalize(rd), normalize(u_sun_dir)), 0.0, 1.0) * 0.5
        
        d_radiance = light_trans * phase * ms * powder * ambient_factor * density * dt
        
        radiance += d_radiance * transmittance
        transmittance *= exp(-density * u_extinction * dt)
        depth_accum += dt
        trans_weighted_depth += dt * transmittance
        
        t += dt
        
    mean_depth = trans_weighted_depth / max(depth_accum, 1e-6)
    return vec4(radiance, transmittance), mean_depth
```

## Subtopics

### [Volumetric Clouds from Base Shape (Nubis/Frostbite Hybrid)](9609-volumetric-clouds-from-base-shape-nubis-frostbite-hybrid.md)
Renders clouds as a spherical shell above a base shape, ensuring conformity to terrain without 2D tearing. Uses Schneider’s density model and Hillaire 2016 light transport. Chosen when clouds must wrap around a planet or irregular base geometry.

## Operating characteristics
*   **Time Complexity:** $O(N \cdot M)$ where $N$ is the number of pixels and $M$ is the number of marching steps. With temporal reprojection, the effective cost is reduced by the resolution scale factor squared.
*   **Memory Complexity:** $O(T_{shape} + T_{detail} + T_{weather})$ for noise textures, plus $O(W \cdot H)$ for framebuffers (color, depth, history).
*   **Performance:** On Mesa llvmpipe (CPU rasterizer) at 640×360, full-resolution 128 steps takes 927 ms. Half-resolution with temporal reprojection takes 266 ms (29% of full-res) [S3, unofficial].
*   **Strengths:** Real-time performance via temporal reprojection; physically plausible lighting with multiple scattering; handles camera movement inside/outside the layer.
*   **Limitations:** Approximation in multiple scattering (lit side of thick clouds is flatter than path-traced); sky is an analytic gradient, not a full atmosphere model; single cloud layer only [S3, unofficial].
*   **When to use:** Real-time games requiring volumetric clouds with good visual quality and performance.
*   **When not to use:** Offline rendering requiring exact physical accuracy; scenes with multiple distinct cloud layers (e.g., cirrus + cumulus) without extension.

## Background
Originating from techniques presented by Andrew Schneider (Horizon Zero Dawn, SIGGRAPH 2015) and Sébastien Hillaire (Frostbite, SIGGRAPH 2016; Unreal Engine, SIGGRAPH 2020), this method combines Nubis Evolved/Cubed density shaping with Frostbite's energy-conserving integration and temporal reprojection [S1, unofficial]. It is implemented in various open-source projects for engines like Bevy, Unity, and standalone OpenGL applications [S1, S2, S3, S4, unofficial].
