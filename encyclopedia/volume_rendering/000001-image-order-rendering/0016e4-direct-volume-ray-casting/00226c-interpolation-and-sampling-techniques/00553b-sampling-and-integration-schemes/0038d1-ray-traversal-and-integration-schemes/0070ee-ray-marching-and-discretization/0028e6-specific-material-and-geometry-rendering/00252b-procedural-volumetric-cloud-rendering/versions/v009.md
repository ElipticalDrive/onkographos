# Procedural Volumetric Cloud Rendering

Also called: Nubis³, Nubis Cubed, Nubis Evolved, Volumetric Cloud Renderer, Volumetric Cloud Rendering, Real-time Volumetric Cloud Rendering

## Overview
Procedural Volumetric Cloud Rendering is a real-time technique that renders planetary-scale cloud layers by ray-marching through a spherical shell volume defined by procedural noise fields [S1, S2, S3, S4, unofficial]. It solves the problem of generating physically plausible, dynamically moving cloudscapes with accurate atmospheric lighting and shadowing without relying on pre-baked textures or finite element meshes [S2, S3, unofficial]. What sets it apart from local volumetrics (like [Ray-marched Volumetric Fog](4248-ray-marched-volumetric-fog.md)) is its treatment of clouds as a global spherical shell, allowing the camera to be inside, below, or above the layer, and its integration of specific atmospheric scattering models (Hillaire 2016/2020) and noise-based shaping (Nubis) to achieve photorealistic scale [S1, S2, S3, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Camera position ($o$), ray direction ($d$), sun direction ($L_{sun}$), cloud layer parameters (base height, thickness, coverage), noise textures (shape, detail, weather), and atmospheric constants (extinction, ambient color).
*   **Outputs:** Fragment color (in-scattered radiance + transmittance), depth (transmittance-weighted mean depth) [S3, unofficial].

**Data Structures:**
*   **Shape Texture:** 3D texture (e.g., $128^3$) storing Perlin-Worley noise for base cloud shape [S3, unofficial].
*   **Detail Texture:** 3D texture (e.g., $32^3$) storing Worley noise for edge erosion and fine detail [S3, unofficial].
*   **Weather Map:** 2D texture (e.g., $512^2$) storing coverage and cloud type (stratus, cumulus, etc.) per region [S3, unofficial].
*   **Framebuffers:**
    *   Cloud FBO: Two attachments. `GL_COLOR_ATTACHMENT0` (RGBA16F) for radiance/transmittance; `GL_COLOR_ATTACHMENT1` (R32F) for depth [S3, unofficial].
    *   Resolve FBO: Single attachment (RGBA16F) for temporal history [S3, unofficial].

**Numbered Steps:**

1.  **Ray Setup:**
    *   Normalize ray direction: $d = \text{normalize}(d_{raw})$ [S2, unofficial].
    *   Intersect ray with the spherical cloud shell defined by inner radius $R_{in}$ and outer radius $R_{out}$ [S3, unofficial].
        *   Let $oc = o - C$ (where $C$ is planet center).
        *   $b = \text{dot}(oc, d)$.
        *   $c = \text{dot}(oc, oc) - R_{out}^2$.
        *   $h_{outer} = b^2 - c$. If $h_{outer} < 0$, no intersection [S3, unofficial].
        *   $s_{outer} = \sqrt{h_{outer}}$.
        *   $t_{outer\_near} = -b - s_{outer}$, $t_{outer\_far} = -b + s_{outer}$ [S3, unofficial].
        *   Calculate inner intersection similarly. If $h_{inner} > 0$, $s_{inner} = \sqrt{h_{inner}}$, else $s_{inner} = 0$ [S3, unofficial].
        *   Determine entry $t_{start}$ and exit $t_{end}$ points within the shell [S3, unofficial].
    *   *Alternative Box Intersection:* If using a box volume, compute $t_{min} = \max(\frac{boxMin - o}{d})$ and $t_{max} = \min(\frac{boxMax - o}{d})$, clamping $t_{start} = \max(0, t_{min})$ and $t_{end} = \min(t_{max}, t_{solid})$ [S2, unofficial].

2.  **Step Size Calculation:**
    *   Calculate total span: $L = t_{end} - t_{start}$ [S3, unofficial].
    *   Determine step size $\Delta l$ based on resolution and layer thickness. For temporal reprojection, render at reduced resolution (e.g., half) [S3, unofficial].
    *   Apply jittering: Offset sample position by interleaved gradient noise or Halton sequence jitter to reduce banding [S3, unofficial].

3.  **Density Sampling (Shaping):**
    *   Transform world position $P$ to noise space using wind offset and scaling [S2, S3, unofficial].
    *   Sample Shape Texture: $N_{shape} = \text{texture}(uShape, P_{shape})$ [S3, unofficial].
    *   Sample Detail Texture: $N_{detail} = \text{texture}(uDetail, P_{detail})$ [S3, unofficial].
    *   Sample Weather Map: Get coverage $C_{cov}$ and cloud type $T_{type}$ from $uWeather$ [S3, unofficial].
    *   Compute Base Density: Combine shape noise with vertical profile based on $T_{type}$ and height above cloud base [S1, S3, unofficial].
    *   Apply Erosion: Use detail noise to erode edges. $D_{final} = \max(D_{base} - \text{erosion}(N_{detail}) \cdot (1 - C_{cov}), 0)$ [S3, unofficial].
    *   Apply Falloff: Multiply by Y-falloff and XZ-falloff functions to blend clouds into the atmosphere at layer boundaries [S2, unofficial].

4.  **Lighting Integration (Ray Marching):**
    *   Initialize accumulated transmittance $T = 1.0$, in-scattered radiance $L_{in} = 0$, and optical depth $\tau = 0$ [S3, unofficial].
    *   Loop from $t = t_{start}$ to $t_{end}$ with step $\Delta l$:
        *   Current position $P = o + t \cdot d$ [S3, unofficial].
        *   **Optical Depth Calculation:** Sample density along the ray toward the sun for $N_{light}$ steps (e.g., 6) to compute light transmittance $T_{light} = e^{-\tau_{light}}$ [S3, unofficial].
        *   **Phase Function:** Compute scattering angle $\theta$ between $d$ and $L_{sun}$. Evaluate phase function $p(\theta)$, typically a two-lobe Henyey-Greenstein or Mie phase function [S1, S3, unofficial].
        *   **Multiple Scattering:** Evaluate a multi-octave approximation of multiple scattering (e.g., 4 octaves) using attenuated extinction and contribution factors [S3, unofficial].
        *   **In-Scattering:** Compute contribution: $L_{step} = \sigma_s(P) \cdot T_{light} \cdot p(\theta) \cdot L_{sun} \cdot \Delta l \cdot T$ [S3, unofficial].
        *   **Ambient/Powder:** Add ambient term (fading from blue top to grey bottom) and powder term (darkening back-lit edges) [S3, unofficial].
        *   **Accumulation:** $L_{in} += L_{step}$, $\tau += \sigma_t(P) \cdot \Delta l$, $T = e^{-\tau}$ [S3, unofficial].
        *   **Termination:** If $T < 0.005$ (0.5%), break loop [S3, unofficial].

5.  **Output Writing:**
    *   Write $L_{in}$ and $T$ to color buffer [S3, unofficial].
    *   Write transmittance-weighted mean depth to depth buffer [S3, unofficial].

**Pseudocode:**

```python
def render_clouds(camera_pos, camera_dir, sun_dir, cloud_params, textures):
    # 1. Ray-Sphere Intersection
    oc = camera_pos - cloud_params.center
    b = dot(oc, camera_dir)
    c = dot(oc, oc) - cloud_params.radius_outer**2
    h_outer = b**2 - c
    if h_outer < 0:
        return 0.0, 1.0 # No intersection
    
    s_outer = sqrt(h_outer)
    t_outer_near = -b - s_outer
    t_outer_far = -b + s_outer
    
    # Inner sphere intersection
    c_inner = dot(oc, oc) - cloud_params.radius_inner**2
    h_inner = b**2 - c_inner
    if h_inner > 0:
        s_inner = sqrt(h_inner)
        t_inner_near = -b - s_inner
        t_inner_far = -b + s_inner
    else:
        t_inner_near = 0
        t_inner_far = 0
        
    # Determine entry and exit
    t_start = max(t_outer_near, t_inner_near)
    t_end = min(t_outer_far, t_inner_far)
    
    if t_start >= t_end:
        return 0.0, 1.0

    # 2. Setup Marching
    total_span = t_end - t_start
    step_size = total_span / cloud_params.max_steps
    jitter = get_jitter(camera_dir) # Halton or gradient noise
    accumulated_transmittance = 1.0
    accumulated_radiance = vec3(0.0)
    accumulated_depth_weight = 0.0
    
    # 3. March
    for i in range(cloud_params.max_steps):
        t = t_start + i * step_size + jitter
        if t >= t_end:
            break
            
        pos = camera_pos + t * camera_dir
        
        # Density Sampling
        density = sample_cloud_density(pos, textures, cloud_params)
        if density <= 0.0:
            continue
            
        # Optical Depth for Light
        tau_light = 0.0
        light_step = step_size / 6.0
        light_pos = pos
        for j in range(6):
            light_pos += sun_dir * light_step
            tau_light += sample_cloud_density(light_pos, textures, cloud_params) * light_step
        light_transmittance = exp(-tau_light)
        
        # Phase Function
        cos_theta = dot(normalize(camera_dir), normalize(sun_dir))
        phase = heney_greenstein_phase(cos_theta, cloud_params.anisotropy)
        
        # Multiple Scattering Approximation
        ms_factor = compute_multiple_scattering(pos, density, tau_light)
        
        # In-Scattering Contribution
        sigma_s = density # Simplified, usually density * scattering_coeff
        step_radiance = sigma_s * light_transmittance * phase * cloud_params.sun_intensity * step_size * accumulated_transmittance
        accumulated_radiance += step_radiance
        
        # Accumulate Transmittance
        sigma_t = density # Simplified, usually density * extinction_coeff
        accumulated_transmittance *= exp(-sigma_t * step_size)
        
        # Depth Weighting
        accumulated_depth_weight += t * step_size * accumulated_transmittance
        
        # Termination
        if accumulated_transmittance < 0.005:
            break
            
    # 4. Output
    mean_depth = accumulated_depth_weight / (1.0 - accumulated_transmittance + 1e-6)
    return accumulated_radiance, accumulated_transmittance, mean_depth

def sample_cloud_density(pos, textures, params):
    # Sample shape and detail noise
    shape_val = texture(params.u_shape, pos * params.shape_scale + params.wind_offset)
    detail_val = texture(params.u_detail, pos * params.detail_scale)
    weather_val = texture(params.u_weather, pos.xz * params.weather_scale)
    
    # Combine noise
    base_density = shape_val * weather_val.coverage
    erosion = detail_val * params.erosion
    density = max(base_density - erosion, 0.0)
    
    # Apply falloff
    height = length(pos - params.center) - params.planet_radius
    y_falloff = exp(-height / params.falloff_scale)
    return density * y_falloff
```

## Subtopics

### [Volumetric Clouds from Base Shape (Nubis/Frostbite Hybrid)](9609-volumetric-clouds-from-base-shape-nubis-frostbite-hybrid.md)
Renders clouds as a spherical shell using 3D noise density, combining Nubis shaping with Frostbite light transport. Choose when planetary scale and camera freedom (inside/outside) are required.

## Operating characteristics
*   **Time Complexity:** $O(N \cdot M)$, where $N$ is the number of pixels and $M$ is the number of ray steps. With temporal reprojection, effective cost is reduced by rendering at lower resolution (e.g., half-res) and blending history [S3, unofficial].
*   **Memory Complexity:** $O(T)$, where $T$ is the size of noise textures (shape, detail, weather) and framebuffers for temporal history [S3, unofficial].
*   **Performance:** On CPU rasterizer (Mesa llvmpipe) at 640x360, full-res 128 steps takes ~927 ms; half-res with temporal reprojection takes ~266 ms (29% of full-res) [S3, unofficial]. On GPU, performance scales with step count and resolution.
*   **Strengths:** Physically plausible lighting, dynamic movement, supports arbitrary camera positions relative to the cloud layer, efficient via temporal reprojection [S3, unofficial].
*   **Limitations:** Approximate multiple scattering (flat lit side), requires careful tuning of noise parameters, temporal reprojection can ghost on fast-moving clouds or disocclusions [S3, unofficial].
*   **When to Use:** Planetary skies, open-world games, VR environments requiring large-scale clouds.
*   **When Not to Use:** Localized fog, indoor scenes, or when strict physical accuracy of multiple scattering is critical without approximation [S3, unofficial].

## Background
Originating from techniques presented in SIGGRAPH talks by Andrew Schneider (Horizon: Zero Dawn, 2015) and Stefan Hillaire (Frostbite, 2016; Unreal Engine, 2020), this method evolved into "Nubis" and "Nubis³" [S1, S2, S3, unofficial]. It integrates atmospheric scattering models (Hillaire 2020) and noise-based shaping (Schneider 2022) to create real-time volumetric clouds [S1, unofficial]. Recent implementations include open-source projects for Bevy, OpenGL, and Unity, demonstrating its adaptability across engines [S1, S2, S3, S4, unofficial].
