# Verlet Integration

Also called: Position-Based Dynamics Integration, Störmer-Verlet, Velocity Verlet

## Overview
Verlet Integration is a numerical integration method for particle dynamics that updates positions based on current and previous positions without explicitly storing velocity [S1, unofficial]. It is time-reversible and unconditionally stable, distinguishing it from Euler Integration by implicitly handling velocity through position differences [S1, unofficial].

## How it works
**Inputs:**
- Current position $pos$
- Previous position $oldPos$
- Acceleration $acc$ (accumulated from forces) [S1, unofficial]
- Mass $mass$
- Damping factor $damping$ (scalar, default 0.99) [S1, unofficial]
- Pinned status $pinned$ (boolean) [S1, unofficial]
- Time step $dt$ (squared as $dt^2$) [G]

**Outputs:**
- New position $newPos$
- Updated $oldPos$
- Reset $acc$ to zero

**Data Structures:**
Each particle stores:
- `pos`: Vec3 (current position)
- `oldPos`: Vec3 (previous position)
- `acc`: Vec3 (accumulated acceleration)
- `mass`: float
- `pinned`: bool

**Steps:**
1. If $pinned$ is true, return immediately without updating [S1, unofficial].
2. Apply forces to calculate acceleration: $acc = acc + force / mass$ [S1, unofficial].
3. Store current position in temporary variable: $tempPos = pos$ [S1, unofficial].
4. Update position using the Verlet scheme:
   $$newPos = pos + (pos - oldPos) \times damping + acc \times dt^2$$
   Note: The velocity term $(pos - oldPos)$ is scaled by $damping$ to simulate energy loss [S1, unofficial].
5. Update previous position: $oldPos = tempPos$ [S1, unofficial].
6. Reset acceleration: $acc = 0$ [S1, unofficial].

**Pseudocode:**
```python
def verlet_step(particle, force, damping, dt_sq):
    if particle.pinned:
        return

    # Apply forces to acceleration
    particle.acc = particle.acc.addScaled(force, 1.0 / particle.mass)

    # Store current position
    tempPos = particle.pos.clone()

    # Calculate velocity term (pos - oldPos)
    velocity = particle.pos.sub(particle.oldPos)

    # Scale velocity by damping
    dampedVelocity = velocity.scale(damping)

    # Scale acceleration by squared timestep
    accelTerm = particle.acc.scale(dt_sq)

    # Update position
    particle.pos = particle.pos.add(dampedVelocity).add(accelTerm)

    # Update old position
    particle.oldPos = tempPos

    # Reset acceleration
    particle.acc.set(0, 0, 0)
```

**Parameters:**
- `damping`: Scalar multiplier for velocity term, default 0.99 [S1, unofficial].
- `dt_sq`: Squared time step value ($dt^2$) [G].

**Edge Cases:**
- Pinned particles do not update position or apply forces [S1, unofficial].
