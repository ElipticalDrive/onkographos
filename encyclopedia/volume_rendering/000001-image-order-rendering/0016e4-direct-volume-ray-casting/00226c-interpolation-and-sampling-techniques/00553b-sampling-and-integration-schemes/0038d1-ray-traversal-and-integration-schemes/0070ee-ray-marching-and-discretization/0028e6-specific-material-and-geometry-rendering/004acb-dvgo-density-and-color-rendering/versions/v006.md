# DVGO Density and Color Rendering

Also called: DVGO volume rendering

## Overview
DVGO (Density Volume Grid Optimization) is a method for synthesizing novel views of 3D scenes by combining a 3D voxel grid with a shallow neural network [S1]. It solves the problem of efficient volume rendering by storing density and color features in a regular grid, allowing for fast trilinear interpolation during ray marching [S1]. Unlike pure neural radiance fields (NeRFs) that query a dense MLP for every sample, DVGO uses the grid to store intermediate representations, significantly reducing memory and compute requirements while maintaining high visual fidelity [S1]. It is distinguished from sibling methods like [Mr-Voxel Volume Rendering](3874-mr-voxel-volume-rendering.md) by its specific use of a shifted softplus activation for density and a shallow MLP for view-dependent color, optimized for fast training and inference [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   Ray $r$ defined by origin $o$ and direction $d$.
*   Near plane distance $t_n$ and far plane distance $t_f$.
*   Number of sample points $n$.
*   Feature grid $V^{(f)}$ of dimensions $R \times N_x \times N_y \times N_z$, where $R$ is the feature dimension [S1].
*   Density grid $V^{(d)}$ of dimensions $1 \times N_x \times N_y \times N_z$ (implied by context of density activation) [S1].
*   Neural network parameters $\Theta$ for the shallow MLP [S1].
*   Hyperparameter $b$ for the shifted softplus function [S1].
*   Background color $c_{bg}$ [S1].

**Outputs:**
*   Rendered pixel color $\hat{C}(r)$ [S1].

### Data Structures
*   **Feature Grid ($V^{(f)}$):** A 4D tensor storing $R$-dimensional feature vectors at each voxel. Layout: `[R, Nx, Ny, Nz]`.
*   **Density Grid ($V^{(d)}$):** A 4D tensor storing scalar density values. Layout: `[1, Nx, Ny, Nz]`.
*   **Shallow MLP:** A multi-layer perceptron with parameters $\Theta$. It takes concatenated inputs of interpolated features, positional encodings of position, and positional encodings of direction.

### Steps
1.  **Ray Sampling:** Sample $n$ points $x_i$ along the ray $r(t) = o + td$ uniformly between $t_n$ and $t_f$. Let $\delta_i$ be the distance between adjacent sample points $x_i$ and $x_{i+1}$ [S1].
2.  **Feature Interpolation:** For each sample point $x_i$, retrieve the feature vector $f_i$ from the feature grid $V^{(f)}$ using trilinear interpolation:
    $$ f_i = \text{interp}(x_i, V^{(f)}) $$
    where $\text{interp}: \mathbb{R}^3 \times \mathbb{R}^{R \times N_x \times N_y \times N_z} \rightarrow \mathbb{R}^R$ [S1].
3.  **Density Activation:** Retrieve the raw density value $\ddot{\sigma}_i$ from the density grid $V^{(d)}$ at $x_i$ (via trilinear interpolation if necessary, though the text implies direct access or interpolation of the scalar field). Apply the shifted softplus activation to ensure non-negative density:
    $$ \sigma_i = \text{softplus}(\ddot{\sigma}_i) = \log(1 + \exp(\ddot{\sigma}_i + b)) $$
    where $\ddot{\sigma}_i$ is the stored value and $b$ is a hyperparameter shift [S1].
4.  **Color Emission:** Compute the view-dependent color emission $c_i^{(rgb)}$ by passing the interpolated features $f_i$, the position $x_i$, and the ray direction $d$ through the shallow MLP $\Theta$. Positional encoding is applied to $x_i$ and $d$ before feeding them into the MLP:
    $$ c_i^{(rgb)} = \text{MLP}_\Theta(\text{concat}(\text{PE}(x_i), \text{PE}(d), f_i)) $$
    Note: The source formula $c_i^{(rgb)} = \text{MLP}_\Theta(\text{interp}(x_i, V^{(f)}), x_i, d)$ implies the MLP takes these as inputs, with positional encoding applied to spatial and directional components [S1].
5.  **Termination Probability:** Calculate the probability of termination (opacity) at sample $i$:
    $$ \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
    where $\delta_i$ is the step size [S1].
6.  **Accumulated Transmittance:** Calculate the accumulated transmittance $T_i$ from the near plane to point $x_i$:
    $$ T_i = \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    with $T_1 = 1$ [S1].
7.  **Volume Rendering Quadrature:** Accumulate the color contributions from all $n$ samples and add the background contribution:
    $$ \hat{C}(r) = \sum_{i=1}^{n} T_i \alpha_i c_i^{(rgb)} + T_{n+1} c_{bg} $$
    where $T_{n+1} = \prod_{j=1}^{n} (1 - \alpha_j)$ is the transmittance after the last sample [S1].

    Renders a single ray using the DVGO method.

        ray_origin: (3,) array, origin of the ray.
        ray_direction: (3,) array, direction of the ray.
        near_plane: float, start distance t_n.
        far_plane: float, end distance t_f.
        n_samples: int, number of sample points n.
        feature_grid: (R, Nx, Ny, Nz) array, feature grid V^(f).
        density_grid: (1, Nx, Ny, Nz) array, density grid V^(d).
        mlp_params: dict or object, parameters Theta for the shallow MLP.
        b: float, hyperparameter shift for softplus.
        background_color: (3,) array, pre-defined background color c_bg.
        
    Returns:
        rendered_color: (3,) array, final pixel color C(r).
    """
    
    # 1. Sample points along the ray
    t_vals = np.linspace(near_plane, far_plane, n_samples)
    sample_points = ray_origin + t_vals[:, np.newaxis] * ray_direction # Shape: (n_samples, 3)
    
    # Calculate step sizes delta_i
    # delta_i is distance to adjacent sampled point. 
    # For uniform sampling, delta is constant, but we compute for each i as per formula context.
    # The formula alpha(sigma, delta) uses delta_i. 
    # Typically delta_i = t_{i+1} - t_i for i < n, and for the last point, 
    # the transmittance T_{n+1} uses the full remaining distance or assumes uniform step.
    # We assume uniform step size for simplicity unless specified otherwise.
    delta = (far_plane - near_plane) / (n_samples - 1)
    
    accumulated_transmittance = 1.0
    rendered_color = np.zeros(3)
    
    for i in range(n_samples):
        x_i = sample_points[i]
        
        # 2. Feature Interpolation
        # interp(x_i, V^(f)) -> f_i (R,)
        f_i = trilinear_interpolate(feature_grid, x_i)
        
        # 3. Density Activation
        # Get raw density value from density grid
        # Assuming density_grid is accessed similarly to feature_grid
        raw_density = trilinear_interpolate(density_grid, x_i)
        # Apply shifted softplus
        sigma_i = math.log(1 + math.exp(raw_density + b))
        
        # 4. Color Emission
        # Apply positional encoding to x_i and ray_direction
        pe_pos = positional_encoding(x_i)
        pe_dir = positional_encoding(ray_direction)
        
        # Concatenate features, PE(pos), PE(dir) and pass through MLP
        # Note: The exact concatenation order depends on MLP implementation, 
        # but source implies inputs are interp features, x_i, d.
        mlp_input = np.concatenate([f_i, pe_pos, pe_dir])
        c_i = mlp_forward(mlp_params, mlp_input) # Returns (3,) color
        
        # 5. Termination Probability
        alpha_i = 1.0 - math.exp(-sigma_i * delta)
        
        # 6. Accumulate Color
        # T_i is accumulated transmittance from near plane to x_i
        # Contribution is T_i * alpha_i * c_i
        rendered_color += accumulated_transmittance * alpha_i * c_i
        
        # Update transmittance for next step
        accumulated_transmittance *= (1.0 - alpha_i)
        
    # 7. Add Background
    # T_{n+1} is the transmittance after the last sample
    rendered_color += accumulated_transmittance * background_color
    
    return rendered_color

### Parameters and Edge Cases
*   **Hyperparameter $b$:** A shift value for the softplus function. Its typical value is not given in the sources [S1].
*   **Post-Activation:** DVGO applies non-linear activation functions (softplus) *after* trilinear interpolation. This produces sharper surfaces and requires fewer cells for surface detail compared to pre-activation schemes [S1].
*   **Precision:** The exponential function in $\alpha_i$ and $T_i$ can suffer from underflow or overflow if $\sigma_i \delta_i$ is very large or very small. Standard floating-point handling applies.
*   **Boundaries:** Trilinear interpolation requires handling points outside the grid bounds. Typically, clamping or zero-padding is used, though not explicitly specified in the sources [S1].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of samples $n$ and the number of rays (pixels). Each sample requires one trilinear interpolation and one MLP forward pass.
*   **Memory Complexity:** Dominated by the storage of the feature grid $V^{(f)}$ and density grid $V^{(d)}$. The MLP parameters are negligible compared to the grid size for high-resolution scenes.
*   **Strengths:** Fast training and inference compared to dense MLP-based NeRFs due to the use of a grid for density and features. The post-activation scheme allows for sharp details with fewer grid cells [S1].
*   **Limitations:** Resolution is limited by the grid size $N_x \times N_y \times N_z$. High-resolution grids require significant memory. View-dependent effects are limited by the shallow MLP capacity [S1].
*   **When to use:** When fast training and inference are required, and the scene can be represented well with a voxel grid. Suitable for static scenes with complex geometry and appearance.
*   **When not to use:** For scenes requiring extremely high resolution beyond feasible grid sizes, or highly dynamic scenes where grid updates are costly.

## Background
DVGO was introduced in the paper "NeRF Synthesis with Shading Guidance" [S1]. It builds upon the principles of Neural Radiance Fields (NeRF) but optimizes the representation by using a 3D voxel grid for density and features, combined with a shallow MLP for color. The method leverages the shifted softplus activation from Mip-NeRF for density and demonstrates that post-activation interpolation yields sharper surfaces [S1].
