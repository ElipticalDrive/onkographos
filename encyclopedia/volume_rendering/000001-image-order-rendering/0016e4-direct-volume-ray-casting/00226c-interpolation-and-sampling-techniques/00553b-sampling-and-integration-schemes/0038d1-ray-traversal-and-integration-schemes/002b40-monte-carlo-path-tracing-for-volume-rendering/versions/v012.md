# Monte Carlo Path Tracing for Volume Rendering

Also called: MC VPT, Monte Carlo Path Tracing, Monte Carlo Volumetric Path Tracing, P=KU Implementation, Path Tracing Volume Rendering, VPT

## Overview
Monte Carlo Path Tracing for Volume Rendering is a unified, brute-force, progressive stochastic rendering framework that produces photo-realistic images of volumetric data without relying on pre-computed quantities or auxiliary volumes [S2]. It distinguishes itself from traditional ray marching by using Woodcock tracking to efficiently handle light attenuation and shadows, and by integrating depth-of-field and hybrid surface/volumetric scattering through stochastic sampling rather than slice-based approximations [S2].

## How it works
**Inputs and Outputs:**
*   **Input:** Volumetric data (typically 16-bit unsigned short), camera parameters (MVP matrix, lens aperture), lighting configuration (environment, point, area lights), transfer function (opacity $\alpha$, color), and maximum extinction coefficient $\sigma_{max}$ [S2].
*   **Output:** A Low Dynamic Range (LDR) image, accumulated progressively over frames [S2].

**Data Structures:**
*   **Accumulator Buffer:** Stores the running Monte Carlo estimate of the High Dynamic Range (HDR) color [S2].
*   **Frame Buffer:** Stores the current frame's HDR estimate [S2].
*   **Camera Parameters:** Stored in constant memory for fast access [S2].
*   **Lights:** Stored in constant memory [S2].

**Numbered Steps:**

1.  **Ray Generation:**
    *   Unproject screen position to get ray origin `vRayFrom` and ray end `vRayTo` using the inverse MVP matrix [S2].
    *   Construct a camera ray using a thin lens model: sample a point on the lens and a perturbed point within the pixel area on the film plane using stratified sampling [S2].
    *   Intersect the ray with the volume’s bounding box to obtain parametric range $[t_{bounds}.x, t_{bounds}.y]$ [S2].
    *   If $t_{bounds}.x \ge t_{bounds}.y$, the ray misses the volume; sample the environment map and output as color [S2].

2.  **Initialization:**
    *   Calculate ray segment `from` and `to` within the cube and `maxDistance` [S2].
    *   Initialize seed: `seed = vPosition + rand(vec2(uOffset, uOffset))` [S2].
    *   Initialize `from` to the ray origin at the bounding box entry point [S2].

3.  **Scattering Point Selection (Woodcock Tracking):**
    *   To find the first scattering point, use Woodcock tracking [S2]:
        1.  Generate a path length $s$ using the maximum extinction coefficient $\sigma_{max}$ [S2].
        2.  Accept the tentative collision point with probability $\sigma_t(p(s)) / \sigma_{max}$, where $\sigma_t$ is the extinction coefficient at point $p(s)$ [S2].
        3.  Repeat until a collision is accepted [S2].
    *   Alternatively, implemented via `sampleDistance(from, to, seed)` [S2]:
        1.  Initialize `dist = 0.0`, `invSigmaMax = 1.0 / uSigmaMax`, `invMaxDistance = 1.0 / maxDistance` [S2].
        2.  Loop: generate random `seed`, update `dist -= log(1.0 - seed.x) * invSigmaMax` [S2].
        3.  If `dist > maxDistance`, break loop [S2].
        4.  Calculate `samplingPosition = mix(from, to, dist * invMaxDistance)` [S2].
        5.  Get `alphaSample = transferSample.a * uAlphaCorrection` [S2].
        6.  If `seed.y < alphaSample * invSigmaMax`, break loop [S2].
    *   If the loop breaks due to `dist > maxDistance`, sample the environment map and output [S2].

4.  **Lighting and Transmittance Calculation:**
    *   Update `from` to the scattering point: `from = mix(from, to, dist / maxDistance)` [S2].
    *   Calculate transmittance from `from` to `to` using `sampleTransmittance(from, to, seed)` [S2]:
        1.  Initialize `transmittance = 1.0` [S2].
        2.  Loop similarly to `sampleDistance`, updating `transmittance *= 1.0 - alphaSample * invSigmaMax` [S2].
    *   Compute direct lighting contribution [S2]:
        1.  Form light ray $R_{light}$ connecting scattering point $p_s$ to a stochastically sampled point on a stochastically chosen light source [S2].
        2.  Apply Woodcock tracking to $R_{light}$ to determine if blocked. If the resulting scattering point $p'_s$ is beyond $p_s$, the ray is unblocked; add light's exitant radiance $L_e$ [S2].
        3.  Sample scattering function yielding scattering ray $R_{scattering}$; intersect with light to compute contribution [S2].
        4.  Combine contributions using Multiple Importance Sampling (MIS) with the power heuristic [S2].
    *   Hybrid Scattering Decision [S2]:
        1.  Draw random number $j$ from uniform distribution [S2].
        2.  Compare $j$ to $P_{brdf}$. If $j < P_{brdf}$, treat as surface scattering (BRDF); otherwise, treat as volumetric scattering (Phase function) [S2].
        3.  $P_{brdf} = \alpha_x \cdot (1 - \exp(-25 \cdot g \cdot \|\nabla_{tn}(x)\|))$, where $\alpha_x$ is opacity, $\|\nabla_{tn}(x)\|$ is normalized gradient magnitude, and $g \in [0,1]$ is gradient factor [S2].
        4.  For surface scattering, use Fresnel blend shading model [S2]. For volumetric, use isotropic phase function (or Schlick's) [S2].

5.  **Color Accumulation:**
    *   Sample diffuse color at `from`: `diffuseColor = sampleVolumeColor(from)` [S2].
    *   Sample light color: `lightColor = sampleEnvironmentMap(uScatteringDirection)` [S2].
    *   Calculate final color: $oColor = diffuseColor \times lightColor \times transmittance$ [S2].
    *   Accumulate frame: `acc = texture(uAccumulator, vPosition)`, `frame = texture(uFrame, vPosition)` [S2].
    *   Update accumulator: `oColor = acc + (frame - acc) * uInvFrameNumber` [S2].

6.  **Post-Processing:**
    *   Filter HDR MC estimate with separable Gaussian kernel (standard deviation 1.5, window 5x5 pixels) to reduce anti-aliasing [S2].
    *   Compute cumulative moving average for Monte Carlo integration [S2].
    *   Tone map HDR estimate to compress dynamic range [S2].
    *   Gamma correct [S2].
    *   An-isotropically filter LDR image to reduce noise [S2].

**Pseudocode:**

```python
import math
import random

def mix(a, b, t):
    return a + (b - a) * t

def sample_phase_function(direction):
    phi = random.uniform(0, 2 * math.pi)
    cos_theta = random.uniform(-1, 1)
    sin_theta = math.sqrt(1 - cos_theta**2)
    return (sin_theta * math.cos(phi), sin_theta * math.sin(phi), cos_theta)

def woodcock_tracking_ray(origin, direction, max_dist, sigma_max, volume_sampler):
    dist = 0.0
    inv_sigma_max = 1.0 / sigma_max
    while dist < max_dist:
        r = random.uniform(0, 1)
        dist -= math.log(1.0 - r) * inv_sigma_max
        if dist >= max_dist:
            return False, None
        pos = mix(origin, origin + direction * max_dist, dist / max_dist)
        sigma_t = volume_sampler.get_extinction(pos)
        r_accept = random.uniform(0, 1)
        if r_accept < sigma_t / sigma_max:
            return True, pos
    return False, None

def monte_carlo_volume_rendering(pixel_pos, camera_params, volume_data, transfer_func, lights, sigma_max, alpha_correction, gradient_factor, frame_number):
    # 1. Ray Generation
    ray_origin = camera_params.unproject(pixel_pos)
    ray_direction = camera_params.sample_lens_and_pixel(pixel_pos)
    t_min, t_max = intersect_bounding_box(ray_origin, ray_direction, volume_data.bbox)
    
    if t_min >= t_max:
        return sample_environment_map(ray_direction)

    max_distance = t_max - t_min
    from_point = ray_origin + t_min * ray_direction
    to_point = ray_origin + t_max * ray_direction
    
    seed = pixel_pos + random.uniform(0, 1) * camera_params.uOffset
    
    # 2. Scattering Point Selection (Woodcock Tracking / sampleDistance)
    dist = 0.0
    inv_sigma_max = 1.0 / sigma_max
    inv_max_distance = 1.0 / max_distance
    
    while dist < max_distance:
        r1 = random.uniform(0, 1)
        dist -= math.log(1.0 - r1) * inv_sigma_max
        
        if dist >= max_distance:
            break
            
        sampling_pos = mix(from_point, to_point, dist * inv_max_distance)
        alpha_sample = transfer_func.sample_alpha(sampling_pos) * alpha_correction
        
        r2 = random.uniform(0, 1)
        if r2 < alpha_sample * inv_sigma_max:
            break
            
    if dist >= max_distance:
        return sample_environment_map(ray_direction)
        
    scattering_point = mix(from_point, to_point, dist * inv_max_distance)
    
    # 3. Transmittance Calculation
    transmittance = 1.0
    dist_t = 0.0
    while dist_t < max_distance:
        r1 = random.uniform(0, 1)
        dist_t -= math.log(1.0 - r1) * inv_sigma_max
        if dist_t >= max_distance:
            break
        sampling_pos_t = mix(from_point, to_point, dist_t * inv_max_distance)
        alpha_sample_t = transfer_func.sample_alpha(sampling_pos_t) * alpha_correction
        transmittance *= 1.0 - alpha_sample_t * inv_sigma_max
        
    # 4. Lighting and Hybrid Scattering
    grad_mag = compute_normalized_gradient(scattering_point, volume_data)
    p_brdf = transfer_func.sample_alpha(scattering_point) * (1.0 - math.exp(-25.0 * gradient_factor * grad_mag))
    
    r_hybrid = random.uniform(0, 1)
    if r_hybrid < p_brdf:
        color = sample_fresnel_blend_brdf(scattering_point, ray_direction, lights)
    else:
        scattering_dir = sample_phase_function(ray_direction)
        light_color = sample_environment_map(scattering_dir)
        diffuse_color = sample_volume_color(scattering_point, transfer_func)
        
        # Light attenuation via Woodcock tracking on light ray
        is_unblocked, _ = woodcock_tracking_ray(scattering_point, scattering_dir, max_distance, sigma_max, volume_data)
        if is_unblocked:
            color = diffuse_color * light_color * transmittance
        else:
            color = vec4(0.0)
            
    # 5. Accumulation
    current_acc = get_accumulator_buffer(pixel_pos)
    current_frame = color
    inv_frame_number = 1.0 / frame_number
    new_acc = current_acc + (current_frame - current_acc) * inv_frame_number
    set_accumulator_buffer(pixel_pos, new_acc)
    
    # 6. Post-Processing
    filtered_acc = gaussian_filter(new_acc, std=1.5, window=5)
    tone_mapped = tone_map(filtered_acc)
    gamma_corrected = tone_mapped ** (1.0 / 2.2)
    final_color = anisotropic_filter(gamma_corrected)
    
    return final_color
```

**Parameters:**
*   `sigma_max` (uSigmaMax): Maximum scattering coefficient used for distance sampling [S2].
*   `alpha_correction` (uAlphaCorrection): Correction factor for alpha values from transfer function [S2].
*   `gradient_factor` (g): Controls surface/volumetric scattering amount, range [0-1] [S2].
*   `uOffset`: Offset for random seed generation [S2].
*   `uInvFrameNumber`: Inverse of current frame number for exponential moving average accumulation [S2].
*   Gaussian kernel: Standard deviation 1.5, window 5x5 pixels [S2].

**Edge Cases and Pitfalls:**
*   **Noise at Startup:** Objectionable noise occurs at the start of the MC algorithm. A noise reduction filter is applied during initial iterations, increasing blurring initially, with influence reducing based on the error in the running estimate [S2].
*   **Ray Marching Performance:** Standard Ray Marching becomes prohibitively slow for shadow calculations at every sample. Woodcock tracking is used to yield far fewer shadow computations and remains unbiased [S2].
*   **Reset Condition:** If transfer function, lighting, or camera position changes, the Monte Carlo integrated estimate buffer must be cleared and the algorithm restarted [S2].

## Subtopics

### Real-time Spatio-Temporal Denoising for DVR
A real-time denoising algorithm for DVR in MR systems that exploits temporal coherence between adjacent frames and spatial coherence between HMD screens to reduce noise from MC estimation [S5]. It identifies three corresponding reprojected pixels for a target pixel: one on the other HMD screen in the current frame, and two on the left and right HMD screens in the previous frame [S5]. It calculates their contribution using a weight function and performs spatio-temporal denoising to reduce visual discomfort caused by MC estimation noise [S5].

## Operating characteristics
*   **Time Complexity:** Progressive convergence. Performance is measured in frame estimates per second [S2].
*   **Memory Complexity:** Insensitive to lighting, material, camera, and transfer function configurations. Does not require pre-computed quantities or additional volumes [S2].
*   **Measured Performance (800x600 resolution, 16-bit unsigned short data):**
    *   Mecanix (512x743x512): 35.2 (Front), 34.1 (Left), 36.3 (Top) fps [S2].
    *   Manix (512x460x512): 32.7 (Front), 39.7 (Left), 42.4 (Top) fps [S2].
    *   Engine (256x256x128): 65.5 (Front), 53.7 (Left), 65.7 (Top) fps [S2].
    *   Bonsai (256x256x257): 57.7 (Front), 66.6 (Left), 68.1 (Top) fps [S2].
    *   Artifix (512x347x512): 47.3 (Front), 40.3 (Left), 50.8 (Top) fps [S2].
*   **Strengths:** Photo-realism, unified handling of isosurfaces and volumes, support for complex lighting (directional, point, environment), depth-of-field via stochastic sampling, unbiased [S2].
*   **Limitations:** Noise at low frame counts requires filtering; progressive nature means no single-frame instant result without accumulation [S2].

## Background
*   **Origin:** Developed by Csébfalvi et al. as part of the Exposure Render framework [S2].
*   **History:** Csébfalvi et al. were the first to apply Monte Carlo integration to volume rendering to solve depth-of-field effects and achieve photo-realism [S2]. The method was demonstrated on datasets including Mecanix, Manix, Engine, Bonsai, Artifix, and a bat CT scan [S2].
*   **Usage:** Implemented in the Exposure Render framework [S2].
