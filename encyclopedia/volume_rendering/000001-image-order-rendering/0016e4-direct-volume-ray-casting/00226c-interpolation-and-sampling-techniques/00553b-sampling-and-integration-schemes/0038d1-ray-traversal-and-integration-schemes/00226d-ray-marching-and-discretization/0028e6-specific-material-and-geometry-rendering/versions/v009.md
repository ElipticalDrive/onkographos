# Specific Material and Geometry Rendering

Also called: Material Parameter Setting, DVGO Density and Color Rendering, Procedural Volumetric Cloud Rendering, Mr-Voxel Volume Rendering, Ray-marched Volumetric Fog, Surface and DRR Rendering Modes, Material Percentage Volume Rendering, Volumetric Heat Haze, Volumetric Geometry Rendering

## Overview
Specific Material and Geometry Rendering encompasses techniques for defining optical properties, handling complex geometric boundaries (such as planetary shells or binary objects), and implementing specific material compositing strategies within direct volume ray casting. It solves the problem of mapping raw spatial data (grids, textures, or procedural functions) to physically or artistically plausible light interaction, while providing specialized traversal logic for non-uniform domains like cloud layers or fog volumes. It differs from generic ray marching by explicitly handling material blending, post-activation density grids, and geometric constraints (shells, cutters) that dictate the integration domain and optical behavior.

## Shared principles
The family shares the fundamental volume rendering equation, where radiance $L$ is accumulated along a ray $r(t) = o + td$:

$$ L = \int_{t_n}^{t_f} T(t) \sigma_s(t) L_e(t, \omega) dt $$

where $T(t) = e^{-\int_{t_n}^t \sigma_t(\tau) d\tau}$ is the transmittance, $\sigma_s$ is the scattering coefficient, $\sigma_t = \sigma_s + \sigma_a$ is the extinction coefficient, and $L_e$ is the emitted/in-scattered radiance.

All methods discretize this integral via ray marching, stepping through the volume with step size $\Delta l$. Key shared mechanisms include:
1.  **Material Binding:** Mapping spatial coordinates to optical properties ($\sigma_a, \sigma_s, \sigma_t$) via textures, grids, or procedural functions.
2.  **Transmittance Culling:** Terminating the march when accumulated transmittance $T$ drops below a threshold (e.g., $10^{-3}$) to save computation.
3.  **Phase Functions:** Using scattering phase functions (e.g., Henyey-Greenstein, Mie) to determine angular distribution of scattered light.
4.  **Jittering:** Applying random offsets to sample positions to reduce banding and aliasing artifacts caused by regular sampling grids.

## Subtopics

### [Procedural Volumetric Cloud Rendering](3480-procedural-volumetric-cloud-rendering.md)
A real-time technique for rendering planetary-scale cloud layers using adaptive ray marching through noise-based density fields. It differs from local volumetrics by treating clouds as a spherical shell, allowing the camera to be inside, below, or above the layer. It combines density shaping (Nubis Evolved/Cubed) with light transport approximations (Frostbite). Choose this for large-scale atmospheric effects requiring multi-scattering approximations and shadowing via depth maps.

### [Mr-Voxel Volume Rendering](3874-mr-voxel-volume-rendering.md)
A direct volume ray casting technique implemented in the Mr-Voxel library, encapsulated in `VolumeIntegrator::Li`. It solves the problem of computing radiance for a single volumetric region along a ray by marching through the volume, accumulating emitted light and single-scattering contributions. It is distinguished by its explicit handling of a single volume and single light source within a unified ray-marching loop, relying on specific step-size discretization and Russian Roulette termination for transmittance culling. Choose this for unbiased single-volume, single-light integration with Russian Roulette.

### [Ray-marched Volumetric Fog](4248-ray-marched-volumetric-fog.md)
Simulates light absorption, scattering, soft shadows, and light shafts (god rays) by treating fog as a 3D volume of participating media traced via forward ray-marching from the camera to the scene. It solves the problem of rendering aerial perspective and dynamic volumetric lighting in real-time applications. Unlike backward ray-marching, it marches from the camera to the scene intersection, allowing for early-out optimizations when transmittance drops below a threshold. Choose this for real-time fog, god rays, and aerial perspective.

### [Material Parameter Setting](5335-material-parameter-setting.md)
Defines the binding between spatial data (grids, textures, or procedural functions) and optical properties (absorption, scattering, emission). It solves the problem of how to map raw voxel data to physically or artistically plausible light interaction. It is distinguished by two primary paradigms: a **Structured Object-Based** approach (material objects with typed fields and texture descriptors) and a **Procedural API-Based** approach (context handles and integer constants for material slots). Choose this to configure the optical properties queried during ray marching.

### [DVGO Density and Color Rendering](12839-dvgo-density-and-color-rendering.md)
DVGO (Direct Volume Gaussian Optimization) renders volumetric scenes by storing density and color features in a 3D grid, using trilinear interpolation to retrieve features at sample points and a shallow MLP to predict view-dependent color. It distinguishes itself from standard grid-based methods by applying non-linear density activation *after* interpolation (post-activation), which enables the representation of sharp surfaces with fewer grid cells. Choose this for neural implicit volume representation with view-dependent color.

### Surface and DRR Rendering Modes
- **Definition:** Surface rendering mode computes color $C(s)$ according to the Phong equation using the volume gradient. Digitally Reconstructed Radiographs (DRRs) mode sets $C(s) = (0,0,0)$, attenuating only the backlight by accumulated transmittance $t$. Maximum Intensity Projections (MIPs) mode outputs the opacity $\alpha$ of the maximum-opacity interval along the ray [S1, unofficial].
- **Parameter:** A uniform variable tells the fragment shader which rendering mode to use [S1, unofficial].

### Material Percentage Volume Rendering
- **Definition:** A technique for rendering volumes with mixtures of materials (e.g., bone, muscle) by creating material percentage volumes and compositing them [S2, unofficial].
- **Steps:** Assume the scalar field was sampled above Nyquist frequency or low-pass filtered. Differentiate materials by scalar value or additional composition info. Create material percentage volumes (scalar fields for each material). Associate color and opacity with each material. Obtain composite color and opacity by linearly combining the color and opacity for each material percentage volume. Use a matte volume (scalar field 0-1) to slice the volume or perform spatial set operations. Transform the volume so one axis is perpendicular to the image plane. Project plane by plane in a back-to-front manner and composite to form the final image [S2, unofficial].

### Volumetric Heat Haze
- **Definition:** Produces the same result as Volumetric Geometry but adds a heat haze refraction effect. Requires V-Ray. Uses Surface channel gradient to change ray direction [S3].
- **Parameter:** Heat Haze (`hhfactor`): Multiplier for refraction based on Surface channel gradient. 1 approximates normal air heat haze from temperature. 0 produces no effect. Larger values needed if using smoke/other channels as source. Only available in Volumetric Heat Haze mode [S3].
- **Pitfall:** Heat Haze only affects camera view, not shadows cast through volume. If Heat Haze shader intersects with VRayMtl refraction, Max depth of VRayMtl may need increase [S3].

### Volumetric Geometry Rendering
- **Definition:** Produces the same visual result as Volumetric mode but uses procedural geometry made of multiple transparent layers. Requires V-Ray. Used for exporting deep images and render elements (normals, velocity, multi matte) not available in standard Volumetric mode [S3].
- **Pitfall:** Approximate and Approximate+Shadows options for Scattering in Smoke color window are not supported in this mode. Cutter Geom does not work when Mode is set to Volumetric Geometry [S3].

## Background
The concept of rendering specific materials within volumes dates back to early volume visualization work. Drebin, Carpenter, and Hanrahan developed techniques for rendering volumes with mixtures of materials, such as CT data containing bone, muscle, and flesh, by creating material percentage volumes [S2, unofficial]. Image-order techniques, fundamentally different from object-order techniques, determine for each pixel which data samples contribute to it [S2, unofficial]. Modern implementations include procedural cloud rendering for planetary scales [S1, S2, unofficial][S3] and neural implicit methods like DVGO [S1, unofficial]. Specific rendering modes like DRRs and MIPs are supported in GPU volume renderers [S1, unofficial]. V-Ray provides specialized modes for volumetric geometry and heat haze effects [S3].
