# DVGO Density and Color Rendering

Also called: DVGO volume rendering

## Overview
DVGO (Direct Volume Grid Optimization) is a method for synthesizing novel views of 3D scenes by combining a 3D voxel grid with a shallow neural network [S1]. It solves the problem of efficient volumetric rendering by storing density and color features in a structured grid, allowing for fast trilinear interpolation during ray marching, while using a neural network to handle view-dependent appearance [S1]. It is distinguished from pure NeRF approaches by its explicit spatial discretization of density, which allows for sharper surface reconstruction with fewer parameters, and from pure voxel methods by its ability to model complex, view-dependent lighting and color variations via the MLP [S1].

## How it works

### Inputs and Outputs
*   **Inputs:**
    *   $V^{(\sigma)}$: A 3D grid storing raw density values $\ddot{\sigma}$. Dimensions: $N_x \times N_y \times N_z$.
    *   $V^{(f)}$: A 3D grid storing color features. Dimensions: $N_x \times N_y \times N_z \times C$, where $C$ is the feature channel count.
    *   Ray $r$: Defined by origin and direction $d$.
    *   Hyperparameters: Shift $b$ for softplus, number of samples $n$, step size $\delta_i$.
*   **Outputs:**
    *   $\hat{C}(r)$: The final pixel color for ray $r$.

### Data Structures
The method relies on two primary 3D grids:
1.  **Density Grid ($V^{(\sigma)}$):** Stores scalar values $\ddot{\sigma}_i \in \mathbb{R}$. These are raw, unbounded values that are mapped to non-negative densities via activation.
2.  **Feature Grid ($V^{(f)}$):** Stores vectors of size $C$. These features are interpolated and passed to the MLP.

### Numbered Steps

1.  **Sampling:** For a given ray $r$, sample $n$ points $x_i$ along the ray between the near and far planes. The distance between adjacent points is $\delta_i$.
2.  **Interpolation:** For each sample point $x_i$, retrieve the raw density $\ddot{\sigma}_i$ and color feature vector $f_i$ from the grids using trilinear interpolation:
    $$ \ddot{\sigma}_i = \text{interp}(x_i, V^{(\sigma)}) $$
    $$ f_i = \text{interp}(x_i, V^{(f)}) $$
    Where $\text{interp}: (\mathbb{R}^3, \mathbb{R}^{C \times N_x \times N_y \times N_z}) \rightarrow \mathbb{R}^C$ [S1].
3.  **Density Activation:** Convert the raw density $\ddot{\sigma}_i$ to a non-negative density $\sigma_i$ using the shifted softplus function:
    $$ \sigma_i = \text{softplus}(\ddot{\sigma}_i) = \log(1 + \exp(\ddot{\sigma}_i + b)) $$
    where $b$ is a hyperparameter shift [S1].
4.  **Color Emission:** Compute the view-dependent color $c_i^{(rgb)}$ by passing the interpolated feature $f_i$, the position $x_i$, and the ray direction $d$ through a shallow multilayer perceptron (MLP) parameterized by $\Theta$. Positional encoding is applied to $x_i$ and $d$ before feeding them into the MLP:
    $$ c_i^{(rgb)} = \text{MLP}_\Theta(f_i, x_i, d) $$
    [S1].
5.  **Alpha Calculation:** Calculate the termination probability (opacity) $\alpha_i$ at point $x_i$ based on the density $\sigma_i$ and the step size $\delta_i$:
    $$ \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
    [S1].
6.  **Transmittance Calculation:** Calculate the accumulated transmittance $T_i$ from the near plane to point $x_i$:
    $$ T_i = \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    with $T_1 = 1$ [S1].
7.  **Accumulation:** Compute the final pixel color $\hat{C}(r)$ by summing the weighted color contributions and the background term:
    $$ \hat{C}(r) = \sum_{i=1}^{n} T_i \alpha_i c_i^{(rgb)} + T_{n+1} c_{bg} $$
    where $c_{bg}$ is a pre-defined background color [S1].

### Parameters and Typical Values
*   **Shift $b$:** A hyperparameter for the softplus activation. Specific typical values are not given in the sources [S1].
*   **Number of samples $n$:** Not specified in the sources [S1].
*   **Step size $\delta_i$:** Determined by the distance between sampled points. If uniform sampling is used, $\delta_i = (far\_plane - near\_plane) / n$ [S1].

### Edge Cases and Pitfalls
*   **Post-Activation Sharpness:** Applying non-linear activation functions (like softplus) *after* trilinear interpolation (post-activation) produces sharper surfaces compared to pre-activation. This allows the method to represent surface details with fewer grid cells [S1].
*   **Non-Negative Density:** The softplus activation ensures that the resulting density $\sigma_i$ is always non-negative, which is physically required for absorption [S1].

## Operating characteristics

*   **Time Complexity:** The rendering time is dominated by the trilinear interpolation and the MLP forward pass for each sample point along the ray. With $n$ samples per ray, the complexity is $O(n \cdot (C + \text{MLP\_cost}))$ per ray.
*   **Memory Complexity:** The memory usage is proportional to the size of the density grid and feature grid: $O(N_x N_y N_z + N_x N_y N_z C)$.
*   **Strengths:**
    *   **Sharp Surfaces:** Post-activation density mapping allows for sharp surface reconstruction with fewer cells [S1].
    *   **Efficiency:** Using a grid for density and features enables fast interpolation, avoiding the need for dense neural network queries at every point for spatial locality (unlike pure NeRF) [S1].
    *   **View-Dependence:** The MLP allows for complex view-dependent color effects [S1].
*   **Limitations:**
    *   **Grid Resolution:** The quality is limited by the grid resolution. Fine details require large grids, increasing memory usage [S1].
    *   **Aliasing:** Trilinear interpolation can introduce blurring if the grid is too coarse, though post-activation mitigates this for density [S1].
*   **When to Use:** Suitable for applications requiring view-dependent effects and sharp surfaces where pure voxel rendering is too blurry and pure NeRF is too slow or memory-intensive for the desired resolution [S1].

## Background

DVGO was introduced in the paper "NeRF Synthesis with Shading Guidance" [S1]. It builds upon the principles of Neural Radiance Fields (NeRF) but introduces a voxel grid to store density and features, aiming to improve rendering efficiency and surface sharpness. The method utilizes the shifted softplus activation from Mip-NeRF [S1].
