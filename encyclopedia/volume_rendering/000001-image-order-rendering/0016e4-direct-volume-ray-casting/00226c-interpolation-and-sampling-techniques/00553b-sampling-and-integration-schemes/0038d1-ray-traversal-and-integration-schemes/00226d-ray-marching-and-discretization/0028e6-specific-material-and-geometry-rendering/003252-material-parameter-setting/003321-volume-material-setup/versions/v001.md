# Volume Material Setup

Also called: ApplyToMaterial, Material Initialization, Shader Parameter Binding, Volume Material Setup (Affine, Weights, Label Map), initMaterial

## Overview
Volume Material Setup initializes the rendering state for direct volume ray casting by creating and caching a `RawShaderMaterial` (or equivalent shader program) configured for transparent volumetric rendering. It binds necessary textures (noise, fire profiles, transfer functions, labels, weights) and uniform parameters (affine transforms, intensity ranges) to the GPU, enabling the shader to correctly sample and composite volume data. It differs from sibling methods by focusing on the **binding and configuration** of material resources rather than the traversal logic or the transfer function definition itself.

## How it works
The method constructs a material object that encapsulates all shader inputs required for volume rendering. It handles the selection of textures based on availability, computes inverse affine matrices for coordinate transformation, and sets flags to inform the shader about the data type (e.g., label map vs. continuous).

### Inputs and Outputs
*   **Inputs**:
    *   `d`: Data object containing metadata (`d.meta`), transfer function (`d.tf`), and optional texture references (`d.labelTexture`, `d.weightTexture`).
    *   `volumeTexLabels`: Optional pre-loaded 3D texture for label data.
    *   `volumeTexWeights`: Optional pre-loaded 3D texture for weight data.
    *   `tfTexCurrent`: The current transfer function texture.
    *   `vs`, `fs`: Vertex and fragment shader source code strings.
*   **Outputs**:
    *   `material`: An initialized material object (e.g., `THREE.RawShaderMaterial`) ready for assignment to a mesh renderer.

### Data Structures and Layouts

**Uniforms Object Layout**
The uniforms passed to the shader are structured as follows:

| Uniform Name | Type | Value/Source | Description |
| :--- | :--- | :--- | :--- |
| `nzw` | `t` (Texture) | `nzw.png` | Noise texture for turbulence. |
| `fireProfile` | `t` (Texture) | `firetex.png` | Fire profile texture. |
| `time` | `f` (Float) | `1.0` | Time parameter for animation. |
| `_TFTex` | `t` (Texture) | `tfTexCurrent` | Transfer function texture. |
| `_VolumeTexLabels` | `t` (Texture) | Selected label texture | Label map texture. |
| `_VolumeTexWeights` | `t` (Texture) | Selected weight texture | Weight texture (or black if null). |
| `_Affine` | `m4` (Matrix4) | `affine` | 4x4 affine transformation matrix. |
| `_InvAffine` | `m4` (Matrix4) | `affine.inverse` | Inverse affine transformation matrix. |
| `_Dim` | `v4` (Vector4) | `(dimX, dimY, dimZ, 1.0)` | Volume dimensions. |
| `_P1` | `f` (Float) | `p1` | Lower bound of intensity range. |
| `_P99` | `f` (Float) | `p99` | Upper bound of intensity range. |
| `_IsLabelMap` | `i` (Int) | `0` or `1` | Flag indicating label map usage. |
| `_HasWeights` | `i` (Int) | `0` or `1` | Flag indicating weight texture presence. |

**Texture Configuration**
*   `nzw`: `RepeatWrapping` on S and T axes; `LinearFilter` for mag/min.
*   `fireProfile`: `ClampToEdgeWrapping` on S and T axes; `LinearFilter` for mag/min.

### Numbered Steps

1.  **Extract Dimensions**: Read `dimX`, `dimY`, `dimZ` from `d.meta.dim`.
2.  **Initialize Intensity Range**:
    *   Set `p1 = 0.0`, `p99 = 1.0`.
    *   If `d.tf.type == "continuous"` and `d.meta.intensity_range` exists with length 2:
        *   Set `p1 = d.meta.intensity_range[0]`.
        *   Set `p99 = d.meta.intensity_range[1]`.
3.  **Load Noise Texture**: Load `nzw.png`. Set wrapping to `RepeatWrapping` and filtering to `LinearFilter`.
4.  **Load Fire Profile Texture**: Load `firetex.png`. Set wrapping to `ClampToEdgeWrapping` and filtering to `LinearFilter`.
5.  **Compute Affine Matrices**:
    *   Construct `affine` matrix from `d.meta.affine` (4x4).
    *   Compute `invAffine = affine.inverse()`.
6.  **Select Label Texture**:
    *   If `volumeTexLabels` is provided, use it.
    *   Else if `d.labelTexture` is provided, use it.
    *   Else, use a default black 3D texture (`BlackTex3D`).
    *   Bind this to `_VolumeTexLabels`.
7.  **Select Weight Texture**:
    *   If `volumeTexWeights` is provided, use it.
    *   Else if `d.weightTexture` is provided, use it.
    *   Else, set `texW = null`.
    *   If `texW` is not null, bind it to `_VolumeTexWeights` and set `_HasWeights = 1`.
    *   If `texW` is null, bind `BlackTex3D` to `_VolumeTexWeights` and set `_HasWeights = 0`.
8.  **Bind Transfer Function**:
    *   Bind `tfTexCurrent` to `_TFTex`.
    *   If `d.tf.type == "labelmap"`, set `_IsLabelMap = 1`.
    *   Else, set `_IsLabelMap = 0`.
9.  **Create Material**:
    *   Instantiate the material (e.g., `THREE.RawShaderMaterial`) with:
        *   Vertex shader `vs`.
        *   Fragment shader `fs`.
        *   Uniforms object containing all textures, matrices, vectors, and flags defined above.
        *   `side: THREE.DoubleSide`.
        *   `blending: THREE.AdditiveBlending`.
        *   `transparent: true`.
10. **Assign Material**: Assign the created `material` to `MeshRenderer.sharedMaterial`.

### Pseudocode

```python
def init_material(d, volumeTexLabels=None, volumeTexWeights=None, tfTexCurrent=None, vs=None, fs=None):
    """
    Initializes and returns a RawShaderMaterial for volume rendering.
    """
    # Step 1: Extract dimensions
    dimX, dimY, dimZ = d.meta.dim[0], d.meta.dim[1], d.meta.dim[2]
    
    # Step 2: Initialize intensity range
    p1 = 0.0
    p99 = 1.0
    if d.tf.type == "continuous" and hasattr(d.meta, 'intensity_range') and len(d.meta.intensity_range) == 2:
        p1 = d.meta.intensity_range[0]
        p99 = d.meta.intensity_range[1]
        
    # Step 3: Load noise texture
    nzw = load_texture('nzw.png')
    nzw.wrapS = WRAP_REPEAT
    nzw.wrapT = WRAP_REPEAT
    nzw.magFilter = FILTER_LINEAR
    nzw.minFilter = FILTER_LINEAR
    
    # Step 4: Load fire profile texture
    fireProfile = load_texture('firetex.png')
    fireProfile.wrapS = WRAP_CLAMP_TO_EDGE
    fireProfile.wrapT = WRAP_CLAMP_TO_EDGE
    fireProfile.magFilter = FILTER_LINEAR
    fireProfile.minFilter = FILTER_LINEAR
    
    # Step 5: Compute affine matrices
    affine = Matrix4(d.meta.affine) # Assuming 4x4 matrix from d.meta.affine
    invAffine = affine.inverse()
    
    # Step 6: Select label texture
    if volumeTexLabels is not None:
        texLbl = volumeTexLabels
    elif hasattr(d, 'labelTexture') and d.labelTexture is not None:
        texLbl = d.labelTexture
    else:
        texLbl = BlackTex3D # Default black 3D texture
    # Note: Binding happens in uniform setup
        
    # Step 7: Select weight texture
    if volumeTexWeights is not None:
        texW = volumeTexWeights
    elif hasattr(d, 'weightTexture') and d.weightTexture is not None:
        texW = d.weightTexture
    else:
        texW = None
        
    if texW is not None:
        hasWeights = 1
        # Bind texW to _VolumeTexWeights
    else:
        hasWeights = 0
        # Bind BlackTex3D to _VolumeTexWeights
        
    # Step 8: Bind Transfer Function and Flags
    # Bind tfTexCurrent to _TFTex
    if d.tf.type == "labelmap":
        isLabelMap = 1
    else:
        isLabelMap = 0
        
    # Step 9: Create Uniforms Object
    uniforms = {
        'nzw': {'type': 't', 'value': nzw},
        'fireProfile': {'type': 't', 'value': fireProfile},
        'time': {'type': 'f', 'value': 1.0},
        '_TFTex': {'type': 't', 'value': tfTexCurrent},
        '_VolumeTexLabels': {'type': 't', 'value': texLbl},
        '_VolumeTexWeights': {'type': 't', 'value': texW if texW is not None else BlackTex3D},
        '_Affine': {'type': 'm4', 'value': affine},
        '_InvAffine': {'type': 'm4', 'value': invAffine},
        '_Dim': {'type': 'v4', 'value': Vector4(dimX, dimY, dimZ, 1.0)},
        '_P1': {'type': 'f', 'value': p1},
        '_P99': {'type': 'f', 'value': p99},
        '_IsLabelMap': {'type': 'i', 'value': isLabelMap},
        '_HasWeights': {'type': 'i', 'value': hasWeights}
    }
    
    # Step 10: Instantiate Material
    material = RawShaderMaterial({
        'vertexShader': vs,
        'fragmentShader': fs,
        'uniforms': uniforms,
        'side': SIDE_DOUBLE,
        'blending': BLEND_ADDITIVE,
        'transparent': True
    })
    
    # Step 11: Assign Material
    # MeshRenderer.sharedMaterial = material
    return material
```

### Parameters and Typical Values
*   `_P1`, `_P99`: Floats representing the intensity range for continuous transfer functions. Default: `0.0`, `1.0`.
*   `_IsLabelMap`: Integer flag (`0` or `1`). `1` if `d.tf.type == "labelmap"`.
*   `_HasWeights`: Integer flag (`0` or `1`). `1` if a weight texture is provided.
*   `time`: Float, default `1.0`.

### Edge Cases and Pitfalls
*   **Missing Intensity Range**: If `d.meta.intensity_range` is missing for a continuous TF, the range defaults to `[0.0, 1.0]`, which may cause incorrect color mapping if the data is not normalized.
*   **Null Textures**: If no label or weight texture is provided, a black 3D texture is used. The shader must handle this gracefully (e.g., treating black as zero intensity/weight).
*   **Affine Inverse**: Computing the inverse affine matrix is critical for correct coordinate transformation. Singular matrices will cause errors.
*   **Texture Wrapping**: Incorrect wrapping modes (e.g., `RepeatWrapping` for fire profile) may cause artifacts at texture boundaries.

## Operating characteristics
*   **Time Complexity**: O(1) for material setup, assuming texture loading is asynchronous or cached. The actual rendering cost is determined by the ray marching scheme.
*   **Memory Complexity**: O(1) additional memory for the material object itself, plus the memory for the textures (which are typically loaded once and reused).
*   **Strengths**: Centralizes material configuration, making it easy to switch between different rendering modes (e.g., label map vs. continuous) by changing flags.
*   **Limitations**: Depends on the availability of specific textures (`nzw.png`, `firetex.png`) which may not be relevant for all volume rendering scenarios (e.g., non-fire volumes).

## Background
The method is derived from implementations in WebGL-based volume rendering libraries, specifically `VolumetricFire` [S2, unofficial] and `vrdf-sdk` [S1, unofficial]. It reflects the pattern of initializing a `RawShaderMaterial` with explicit uniform bindings for textures and matrices, common in low-level graphics programming where fine-grained control over shader inputs is required.
