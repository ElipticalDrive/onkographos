# Raycasting with Transfer Function and Shading

Also called: Front-to-back volume raycasting with gradient-based diffuse shading

## Overview
This method performs direct volume ray casting in a fragment shader, rendering a volume defined by 3D textures using a 1D transfer function and gradient-based diffuse shading [S1, unofficial]. It distinguishes itself from sibling methods by explicitly computing surface normals from pre-stored gradient data to apply Lambertian lighting, rather than relying solely on density accumulation or geometry occlusion [S1, unofficial]. Unlike [Ray Marching Volume Rendering](4877-ray-marching-volume-rendering.md), which focuses on cloud rendering with phase functions, this approach targets solid volumetric data with explicit shading models.

## How it works
**Inputs and Outputs:**
The method takes a fragment position in clip space and renders to `oColor` (vec4) and `oNormal` (vec3). It requires several uniform textures and parameters:
- `cubeFront` (sampler2D, binding 0): Stores the entry point of the ray into the volume.
- `cubeBack` (sampler2D, binding 1): Stores the exit point of the ray from the volume.
- `volume` (sampler3D, binding 2): The 3D density/scalar field texture.
- `gradients` (sampler3D, binding 3): Pre-computed gradient data, encoded as vec2.
- `transferFunction` (sampler1D, binding 4): Maps scalar values to RGBA color and opacity.
- `bakedNoise` (sampler2D, binding 5): 2D noise texture for jittering.
- `ciModelMatrixInverseTranspose` (mat3): Model-view matrix inverse transpose for normal transformation.
- `light` (struct): Contains `direction` (vec3), `ambient` (vec3), and `diffuse` (vec3).
- `threshold` (ivec2): Range of iso values (0-255) to render. Default is `(0, 255)` [S1, unofficial].
- `stepSize` (vec3): Step size in each dimension.
- `iterations` (int): Maximum number of ray marching steps.
- `diffuseShading` (bool): Flag to enable/disable shading.
- `stepScale` (float): Parameter for opacity correction [S1, unofficial].

**Data Structures:**
The gradient data in `gradients` is encoded as a 2D vector per voxel. The decoding formula assumes a spheremap transform [S1, unofficial].

**Steps:**
1.  **Ray Setup:**
    -   Convert fragment position to texture coordinates: $texC = \frac{position.xy}{position.w}$.
    -   Adjust coordinates: $texC.x = 0.5 \cdot texC.x + 0.5$, $texC.y = 0.5 \cdot texC.y - 0.5$.
    -   Sample entry and exit points: $front = texture(cubeFront, texC).xyz$, $back = texture(cubeBack, texC).xyz$.
    -   Compute ray direction: $dir = normalize(back - front)$.
    -   Initialize ray position: $pos = vec4(front, 0)$.
    -   Initialize accumulators: $dst = vec4(0)$, $src = vec4(0)$, $value = vec4(0)$.
    -   Compute step vector: $step = dir \cdot stepSize$.
    -   Jitter start position: $pos.xyz += step \cdot texture(bakedNoise, \frac{gl\_FragCoord.xy}{256}).x$ [S1, unofficial].

2.  **Ray Marching Loop:**
    -   Iterate $i$ from $0$ to $iterations - 1$:
        -   Set $pos.w = 0$.
        -   Sample volume density: $value.a = texture(volume, pos.xyz).x$.
        -   Compute integer iso value: $isoValue = \lfloor 255.0 \cdot value.a \rfloor$.
        -   Check threshold: If $isoValue \ge threshold.x$ and $isoValue \le threshold.y$:
            -   Sample transfer function: $src = texture(transferFunction, value.a)$.
            -   Apply opacity correction: $src.a = 1 - (1 - src.a)^{\frac{stepScale}{0.5}}$ [S1, unofficial].
            -   If `diffuseShading` is true:
                -   Sample encoded gradient: $enc = texture(gradients, pos.xyz).xy$.
                -   Decode normal:
                    -   $n.z = dot(enc, enc) \cdot 2.0 - 1.0$.
                    -   $n.xy = normalize(enc.xy) \cdot \sqrt{1.0 - n.z \cdot n.z}$.
                    -   $n = vec3(n.xy, n.z)$.
                -   Transform normal: $normal = normalize(ciModelMatrixInverseTranspose \cdot n)$.
                -   Compute light direction: $lightDir = normalize(-light.direction)$.
                -   Compute Lambert factor: $lambert = max(dot(normal, lightDir), 0.0)$.
                -   Apply shading: $src.rgb = light.diffuse \cdot lambert \cdot src.rgb + light.ambient \cdot src.rgb$.
            -   Front-to-back blending:
                -   $src.rgb *= src.a$.
                -   $dst = (1.0 - dst.a) \cdot src + dst$.
            -   Early termination: If $dst.a \ge 0.95$, break loop [S1, unofficial].
        -   Advance position: $pos.xyz += step$.
        -   Boundary check: If $pos.x > 1.0$ or $pos.y > 1.0$ or $pos.z > 1.0$, break loop [S1, unofficial].

3.  **Output:**
    -   Set $oColor = vec4(dst.rgb, 1.0)$.
    -   Set $oNormal = value.xyz$ (the last sampled gradient/normal, or zero if no sample was taken) [S1, unofficial].
    -   Set $gl\_FragDepth = pos.z$ [S1, unofficial].

**Pseudocode:**
```python
def raycast_with_shading(position, uniforms):
    # Ray Setup
    tex_c = position.xy / position.w
    tex_c.x = 0.5 * tex_c.x + 0.5
    tex_c.y = 0.5 * tex_c.y - 0.5
    
    front = uniforms['cubeFront'].sample(tex_c)
    back = uniforms['cubeBack'].sample(tex_c)
    
    dir_vec = normalize(back.xyz - front.xyz)
    pos = vec4(front.xyz, 0.0)
    dst = vec4(0.0)
    value = vec4(0.0)
    
    step_vec = dir_vec * uniforms['stepSize']
    
    # Jitter start position
    noise_val = uniforms['bakedNoise'].sample(gl_FragCoord.xy / 256.0).x
    pos.xyz += step_vec * noise_val
    
    # Ray Marching Loop
    for i in range(uniforms['iterations']):
        pos.w = 0.0
        
        # Sample volume
        value.a = uniforms['volume'].sample(pos.xyz).x
        iso_value = int(255.0 * value.a)
        
        # Threshold check
        if uniforms['threshold'].x <= iso_value <= uniforms['threshold'].y:
            # Sample transfer function
            src = uniforms['transferFunction'].sample(value.a)
            
            # Opacity correction
            step_scale = uniforms['stepScale']
            src.a = 1.0 - pow(1.0 - src.a, step_scale / 0.5)
            
            # Shading
            if uniforms['diffuseShading']:
                enc = uniforms['gradients'].sample(pos.xyz).xy
                n_z = dot(enc, enc) * 2.0 - 1.0
                n_xy = normalize(enc.xy) * sqrt(1.0 - n_z * n_z)
                n = vec3(n_xy, n_z)
                
                normal = normalize(uniforms['ciModelMatrixInverseTranspose'] * n)
                light_dir = normalize(-uniforms['light'].direction)
                lambert = max(dot(normal, light_dir), 0.0)
                
                src.rgb = uniforms['light'].diffuse * lambert * src.rgb + uniforms['light'].ambient * src.rgb
            
            # Front-to-back blending
            src.rgb *= src.a
            dst = (1.0 - dst.a) * src + dst
            
            # Early termination
            if dst.a >= 0.95:
                break
        
        # Advance position
        pos.xyz += step_vec
        
        # Boundary check
        if pos.x > 1.0 or pos.y > 1.0 or pos.z > 1.0:
            break
            
    # Output
    o_color = vec4(dst.rgb, 1.0)
    o_normal = value.xyz
    gl_FragDepth = pos.z
    
    return o_color, o_normal
```

## Subtopics

### [Gradient-Based Volume Rendering with Isovalue Lookup](10998-gradient-based-volume-rendering-with-isovalue-lookup.md)
This method performs direct volume ray casting by storing pre-computed integer isovalue and gradient magnitude data in a 3D texture, allowing the fragment shader to sample surface properties directly without numerical differentiation. It distinguishes itself from standard raycasting by weighting the transfer function opacity with the gradient magnitude, which enhances edges and surfaces, and by using a lookup-based approach for lighting and visibility selection. It builds on [Raycasting with Transfer Function and Shading](3773-raycasting-with-transfer-function-and-shading.md) by replacing on-the-fly gradient computation with pre-sampled gradient magnitudes and adding isovalue-based selection logic.

### [Gradient-Density Raycasting with Transfer Function Blending](13551-gradient-density-raycasting-with-transfer-function-blending.md)
A fragment-based volume rendering technique that performs raycasting in the fragment shader, sampling density and gradient simultaneously, blending between two transfer functions based on an index, and applying silhouette and gradient magnitude modulation for shading. It differs from standard raycasting by explicitly computing the gradient vector per sample to drive both shading (via `Illuminate`) and opacity modulation (via `SilhouetteModulation` and `GradientMagnitudeModulation`), while using a fixed step count derived from ray length rather than adaptive traversal.

## Operating characteristics
- **Time Complexity:** $O(N)$ where $N$ is the number of iterations (ray steps) per fragment.
- **Memory Complexity:** $O(1)$ per fragment, plus storage for the 3D volume, gradient, and transfer function textures.
- **Performance:** Performance is limited by memory bandwidth due to frequent 3D texture lookups and the need to decode normals. The early termination condition ($dst.a \ge 0.95$) can significantly reduce average iteration count for opaque regions.
- **Strengths:** Simple implementation in fragment shaders; provides basic shading effects; jittering reduces aliasing artifacts.
- **Limitations:** Fixed step size may lead to aliasing or slow convergence in sparse regions; gradient decoding assumes specific encoding; boundary checks are simple and may not handle complex volume shapes perfectly.
- **When to use:** Real-time rendering of solid volumetric data where basic shading is sufficient.
- **When not to use:** When high-quality anti-aliasing or adaptive step sizes are required; when complex lighting effects (e.g., subsurface scattering) are needed.

## Background
This method is based on a fragment shader implementation for front-to-back volume raycasting with gradient-based diffuse shading [S1, unofficial]. It uses a spheremap transform for normal decoding, attributed to Cry Engine 3 and Martin Mittring [S1, unofficial]. The approach is part of a broader family of direct volume rendering techniques that integrate transfer functions and lighting models during ray marching.
