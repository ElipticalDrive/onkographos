# Specific Material and Geometry Rendering


## Overview
Specific Material and Geometry Rendering is a family of techniques within direct volume ray casting that addresses the problem of rendering complex, non-uniform, or physically distinct volumetric phenomena—such as planetary clouds, procedural fog, and multi-material datasets—by tailoring the sampling, shading, and integration strategies to the specific material properties or geometric constraints of the volume. It distinguishes itself from generic ray marching by decoupling the traversal logic from the material definition, allowing for specialized handling of large-scale atmospheric shells, neural density representations, and multi-material compositing that standard homogeneous volume renderers cannot efficiently support.

## Shared principles
The family shares the fundamental volume rendering integral, where the final color $C(r)$ along a ray $r$ is computed by integrating the emitted and scattered light attenuated by transmittance:
$$
C(r) = \int_{t_n}^{t_f} T(t) \sigma_t(t) c(t) dt
$$
where $T(t) = \exp\left(-\int_{t_n}^{t} \sigma_t(t') dt'\right)$ is the transmittance, $\sigma_t$ is the extinction coefficient (density), and $c(t)$ is the color/emission at position $t$.

All methods in this family rely on:
1.  **Ray Traversal:** Casting rays from the camera through the volume bounds, often using sphere or box intersection tests to determine the entry and exit points ($t_n, t_f$).
2.  **Discretization:** Approximating the integral via a Riemann sum or similar quadrature over discrete steps $\Delta t$.
3.  **Material Definition:** Mapping raw data (grids, textures, or procedural functions) to optical properties ($\sigma_t$, scattering color, emission) via specific parameter settings or neural networks.
4.  **Shading Models:** Computing in-scattering using phase functions (e.g., Henyey-Greenstein) and lighting models appropriate for the material (e.g., cloud microphysics, PBR for procedural surfaces).

## Subtopics

### [Procedural Volumetric Cloud Rendering](3480-procedural-volumetric-cloud-rendering.md)
Renders planetary-scale cloud layers as spherical shells using procedural noise and atmospheric lighting models, distinct from local volumetrics by its use of multi-resolution noise fields and adaptive stepping for large-scale physics.

### [Mr-Voxel Volume Rendering](3874-mr-voxel-volume-rendering.md)
A direct volume ray casting technique using an accelerated voxel data structure for a single volume region and single light source, focusing on efficient integration of emitted light and scattering within a custom PBR-derived lighting model.

### [Ray-marched Volumetric Fog](4248-ray-marched-volumetric-fog.md)
Simulates light absorption, scattering, and soft shadows by treating fog as a participating media traced via ray marching, distinguished by its forward approach allowing early-out optimizations when transmittance is low.

### [Material Parameter Setting](5335-material-parameter-setting.md)
Defines the optical and geometric properties of volumetric media by mapping raw data grids to physical attributes (density, color, emission) via explicit channel bindings or low-level API calls, focusing on the *definition* of properties rather than traversal.

### [DVGO Density and Color Rendering](12839-dvgo-density-and-color-rendering.md)
Synthesizes novel views by combining a sparse 3D voxel grid with a shallow neural network, decoupling density (from the grid via softplus activation) and color (from the view-dependent MLP) to enable faster training and sharper surfaces than standard NeRF.

### Surface and DRR Rendering Modes
*   **Definition:** Surface rendering mode computes color $C(s)$ using the Phong equation based on the volume gradient. Digitally Reconstructed Radiographs (DRRs) mode sets $C(s) = (0,0,0)$, attenuating only the backlight by accumulated transmittance $t$. Maximum Intensity Projections (MIPs) output the opacity $\alpha$ of the maximum-opacity interval along the ray [S1, unofficial].
*   **Parameter:** A uniform variable tells the fragment shader which rendering mode to use [S1, unofficial].

### Material Percentage Volume Rendering
*   **Definition:** A technique for rendering volumes with mixtures of materials (e.g., bone, muscle) by creating material percentage volumes and compositing them [S2, unofficial].
*   **Steps:** Assume the scalar field was sampled above the Nyquist frequency or low-pass filtered. Differentiate materials by scalar value or additional composition info. Create material percentage volumes, where each is a scalar field representing one material. Associate color and opacity with each material. Obtain composite color and opacity by linearly combining the color and opacity for each material percentage volume. Use a matte volume (scalar field 0-1) to slice the volume or perform spatial set operations. Transform the volume so one axis is perpendicular to the image plane. Project plane by plane in a back-to-front manner and composite to form the final image [S2, unofficial].

### Volumetric Heat Haze
*   **Definition:** Produces the same result as Volumetric Geometry but adds a heat haze refraction effect. Requires V-Ray. Uses the Surface channel gradient to change ray direction [S3].
*   **Parameter:** Heat Haze (`hhfactor`): Multiplier for refraction based on Surface channel gradient. 1 approximates normal air heat haze from temperature. 0 produces no effect. Larger values needed if using smoke/other channels as source. Only available in Volumetric Heat Haze mode [S3].
*   **Pitfall:** Heat Haze only affects camera view, not shadows cast through volume. If Heat Haze shader intersects with VRayMtl refraction, Max depth of VRayMtl may need increase [S3].

### Volumetric Geometry Rendering
*   **Definition:** Produces the same visual result as Volumetric mode but uses procedural geometry made of multiple transparent layers. Requires V-Ray. Used for exporting deep images and render elements (normals, velocity, multi matte) not available in standard Volumetric mode [S3].
*   **Pitfall:** Approximate and Approximate+Shadows options for Scattering in Smoke color window are not supported in this mode. Cutter Geom does not work when Mode is set to Volumetric Geometry [S3].

## Background
The concept of specific material handling in volume rendering evolved from early image-order techniques that treated volumes as homogeneous participating media. Drebin, Carpenter, and Hanrahan introduced material percentage volumes to handle mixtures like bone and muscle, assuming scalar fields were sampled above the Nyquist frequency [S2, unofficial]. Later, GPU-based volume rendering introduced flexible material parameter settings, allowing users to bind VDB grids to physical properties like density and emission, supporting modes such as surface rendering, DRRs, and MIPs [S1, unofficial]. In the context of atmospheric rendering, techniques like procedural volumetric cloud rendering emerged to handle planetary-scale clouds using spherical shells and procedural noise, distinct from local fog simulations [S2, unofficial][S3]. More recently, neural volume rendering methods like DVGO have introduced hybrid approaches, using voxel grids for density and neural networks for color, optimizing for training speed and surface sharpness [S1, unofficial].
