# DVGO Density and Color Rendering

Also called: DVGO volume rendering

## Overview
DVGO (Direct Volume Gaussian Optimization) renders volumetric scenes by storing density and color features in a 3D grid, using trilinear interpolation to retrieve features at sample points and a shallow MLP to predict view-dependent color [S1]. It distinguishes itself from standard grid-based methods by applying non-linear density activation *after* interpolation (post-activation), which enables the representation of sharp surfaces with fewer grid cells [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A ray $r$ defined by origin $o$ and direction $d$; a density grid $V^{(\sigma)}$ of size $N_x \times N_y \times N_z$; a feature grid $V^{(f)}$ of size $N_x \times N_y \times N_z$ with channel dimension $C$; a shift hyperparameter $b$; an MLP parameterized by $\Theta$; near and far plane distances $t_n, t_f$; and step count $n$.
*   **Output:** The accumulated color $\hat{C}(r)$ for the pixel.

**Data Structures:**
*   **Density Grid ($V^{(\sigma)}$):** Stores raw scalar values $\ddot{\sigma}_i \in \mathbb{R}$. Layout is a 3D array of floats.
*   **Feature Grid ($V^{(f)}$):** Stores feature vectors $f \in \mathbb{R}^C$. Layout is a 3D array of floats.
*   **MLP ($MLP_\Theta$):** A shallow neural network taking concatenated inputs of interpolated features, positional encodings of position, and positional encodings of direction.

**Numbered Steps:**
1.  **Ray Sampling:** Sample $n$ points $x_i$ along the ray $r(t) = o + td$ between $t_n$ and $t_f$. The distance to the adjacent sampled point is $\delta_i$.
2.  **Feature Retrieval:** For each sample point $x_i$, retrieve the raw density value $\ddot{\sigma}_i$ and feature vector $f_i$ from the grids using trilinear interpolation:
    $$ \ddot{\sigma}_i = \text{interp}(x_i, V^{(\sigma)}) $$
    $$ f_i = \text{interp}(x_i, V^{(f)}) $$
3.  **Density Activation:** Apply the shifted softplus function to map the interpolated raw density to a non-negative extinction coefficient $\sigma_i$:
    $$ \sigma_i = \text{softplus}(\ddot{\sigma}_i) = \log(1 + \exp(\ddot{\sigma}_i + b)) $$
    where $b$ is a hyperparameter shift [S1].
4.  **Color Prediction:** Compute the view-dependent color emission $c_i^{(rgb)}$ by passing the interpolated features $f_i$, the position $x_i$, and the ray direction $d$ through the MLP. Positional encoding is applied to $x_i$ and $d$ before inputting them to the MLP [S1]:
    $$ c_i^{(rgb)} = MLP_\Theta(f_i, \text{PE}(x_i), \text{PE}(d)) $$
5.  **Alpha Calculation:** Calculate the termination probability (alpha) at each sample point:
    $$ \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
6.  **Transmittance Accumulation:** Compute the accumulated transmittance $T_i$ from the near plane to point $x_i$:
    $$ T_i = \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    By definition, $T_1 = 1$.
7.  **Color Accumulation:** Accumulate the final color $\hat{C}(r)$ using the volume rendering quadrature formula, including a pre-defined background color $c_{bg}$:
    $$ \hat{C}(r) = \sum_{i=1}^{n} T_i \alpha_i c_i + T_{n+1} c_{bg} $$

**Pseudocode:**
```python
def dvgo_render_ray(ray_origin, ray_direction, V_sigma, V_feature, b, mlp, n_samples, t_near, t_far, c_bg):
    """
    Renders a single ray using DVGO.
    
    Args:
        ray_origin: (3,) array, origin of the ray.
        ray_direction: (3,) array, normalized direction of the ray.
        V_sigma: 3D array, raw density grid.
        V_feature: 4D array (Nx, Ny, Nz, C), feature grid.
        b: float, shift parameter for softplus.
        mlp: function, MLP taking (features, pos_enc, dir_enc) -> color.
        n_samples: int, number of sample points.
        t_near: float, near plane distance.
        t_far: float, far plane distance.
        c_bg: (3,) array, background color.
        
    Returns:
        color: (3,) array, accumulated color.
    """
    # 1. Sample points along the ray
    t_values = np.linspace(t_near, t_far, n_samples)
    points = ray_origin + t_values[:, np.newaxis] * ray_direction
    
    # Calculate delta (distance between adjacent samples)
    # Assuming uniform sampling for simplicity, delta is constant
    delta = (t_far - t_near) / (n_samples - 1)
    
    accumulated_transmittance = 1.0
    accumulated_color = np.zeros(3)
    
    for i in range(n_samples):
        x_i = points[i]
        
        # 2. Trilinear interpolation
        # Note: interp function handles boundary checks and normalization
        raw_sigma = interp_trilinear(x_i, V_sigma)
        features = interp_trilinear(x_i, V_feature)
        
        # 3. Density Activation (Post-activation)
        # softplus(x) = log(1 + exp(x))
        # Using shifted softplus: log(1 + exp(x + b))
        sigma_i = np.log(1.0 + np.exp(raw_sigma + b))
        
        # 4. Color Prediction
        # Positional encoding is applied to position and direction
        pos_enc = positional_encoding(x_i)
        dir_enc = positional_encoding(ray_direction)
        
        # MLP input: features concatenated with positional encodings
        # Implementation detail: MLP expects a flat vector or specific tensor shape
        color_i = mlp(features, pos_enc, dir_enc)
        
        # 5. Alpha Calculation
        alpha_i = 1.0 - np.exp(-sigma_i * delta)
        
        # 6. Accumulate Color
        # T_i is accumulated_transmittance from previous steps
        accumulated_color += accumulated_transmittance * alpha_i * color_i
        
        # 7. Update Transmittance
        accumulated_transmittance *= (1.0 - alpha_i)
        
        # Early termination optimization (optional, not in core formula)
        if accumulated_transmittance < 1e-3:
            break
            
    # Add background contribution
    accumulated_color += accumulated_transmittance * c_bg
    
    return accumulated_color
```

**Parameters:**
*   $b$: Shift hyperparameter for softplus. Typical values are not specified in the sources [S1].
*   $n$: Number of sample points. Not given in the sources [S1].
*   $C$: Feature dimension. Not given in the sources [S1].

**Edge Cases and Pitfalls:**
*   **Post-Activation:** Applying non-linear activation functions after trilinear interpolation (post-activation) is critical for producing sharp surfaces. Pre-activation (applying softplus before interpolation) results in smoother, less detailed surfaces [S1].
*   **Precision:** The softplus function involves exponentials. Care must be taken with numerical stability for large values of $\ddot{\sigma}_i + b$ [S1].
*   **Boundaries:** Trilinear interpolation requires handling points outside the grid bounds. Standard clamping or zero-padding is implied but not explicitly defined [S1].

## Operating characteristics
*   **Time Complexity:** $O(n \cdot C_{mlp})$ per ray, where $n$ is the number of samples and $C_{mlp}$ is the cost of the MLP evaluation. Trilinear interpolation is $O(1)$.
*   **Memory Complexity:** $O(N_x N_y N_z (1 + C))$ for storing the density and feature grids.
*   **Strengths:** Capable of producing sharp surfaces with fewer grid cells compared to methods that apply activation before interpolation [S1].
*   **Limitations:** Requires storing both density and feature grids, increasing memory usage compared to density-only grids. Performance depends on the MLP size and the number of samples.
*   **When to use:** When high-frequency details are required and memory allows for feature grids.
*   **When not to use:** When memory is extremely constrained and only coarse geometry is needed.

## Background
DVGO was introduced in the paper "NeRF Synthesis with Shading Guidance" [S1]. It builds upon the principles of NeRF but adapts them for direct volume rendering using a grid-based representation with specific activation strategies.
