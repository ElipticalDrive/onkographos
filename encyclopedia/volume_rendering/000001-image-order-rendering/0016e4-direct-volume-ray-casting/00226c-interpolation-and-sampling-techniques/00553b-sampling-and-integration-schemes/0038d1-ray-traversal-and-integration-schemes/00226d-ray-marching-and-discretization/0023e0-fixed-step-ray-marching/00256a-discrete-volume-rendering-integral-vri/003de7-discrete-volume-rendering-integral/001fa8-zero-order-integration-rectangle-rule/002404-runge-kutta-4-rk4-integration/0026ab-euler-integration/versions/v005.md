# Euler Integration

Also called: Euler Method, Forward Euler, Euler's Method, Explicit Euler, Euler Integrator, Order 1 Runge-Kutta, First-order Euler Integrator

## Overview
Euler Integration is the most basic numerical method for solving initial value problems (IVPs) in vector fields, estimating the next state based on the derivative at the current single point [S1]. In volume rendering, it is numerically equivalent to traditional ray marching, where the radiance variation is evaluated using a single sample per segment [S1]. It serves as the baseline explicit integrator for streamline visualization and differential ray marching, distinguished from higher-order siblings like [Runge-Kutta 4 (RK4) Integration](3158-runge-kutta-4-rk4-integration.md) by its first-order accuracy and single-sample-per-step efficiency [S1][S3, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** Current position $x_n$ (or $y_i$), vector field function $v(x)$ (or derivative function $f(y,t)$), step size $dt$ (or $s$) [S1][S3, unofficial].
*   **Output:** Next position $x_{n+1}$ (or $y_{i+1}$) [S1][S3, unofficial].

**Data Structures:**
*   **Position:** A 3D vector (e.g., `double3` or `float3`) representing the current location in the volume [G].
*   **Vector Field:** A 3D texture or grid storing the vector value at each voxel [G].
*   **Step Size:** A scalar float representing the distance to march [S1].

**Explicit Euler (Standard Ray Marching):**
The explicit method linearizes the Taylor series expansion, approximating the next position by moving along the vector field direction at the current position [S2, unofficial].

1.  Sample the vector field at the current position $x_n$ [S3, unofficial].
2.  Compute the displacement by multiplying the vector field value by the step size $dt$ [S3, unofficial].
3.  Add the displacement to the current position to get $x_{n+1}$ [S3, unofficial].

**Formula:**
$$x_{n+1} = x_n + dt \cdot v(x_n) + O(dt^2)$$
Where:
*   $x_n$ is the current position.
*   $x_{n+1}$ is the next position.
*   $dt$ is the time/step size.
*   $v(x_n)$ is the vector field value at $x_n$ [S3, unofficial].
*   $O(dt^2)$ is the local truncation error per step [S3, unofficial].

**Implicit Euler (Backwards Euler):**
The implicit method replaces the explicit derivative evaluation with an implicit one at the next step to stabilize calculations in stiff regions [S1]. It solves a per-step system of equations [S1].

**Formula:**
$$y_{i+1} = y_i + s \cdot f(y_{i+1}, t_i)$$
Where:
*   $y_{i+1}$ is the unknown value at the next step [S1].
*   $y_i$ is the current value.
*   $s$ is the step size.
*   $f$ is the derivative function evaluated at the next step's state $y_{i+1}$ [S1].

**Algorithm (Explicit):**
```python
def euler_explicit(pos, dt, vector_field_sampler):
    """
    Performs one step of explicit Euler integration.
    
    Args:
        pos: Current position (Vec3).
        dt: Step size (float).
        vector_field_sampler: Function that returns vector (Vec3) at a given position.
        
    Returns:
        Next position (Vec3).
    """
    # 1. Sample vector field at current position
    v = vector_field_sampler(pos)
    
    # 2. Compute displacement: dt * v
    displacement = v * dt
    
    # 3. Return new position
    return pos + displacement
```

**Algorithm (Implicit):**
The implicit equation requires solving for $y_{i+1}$ using fixed-point iteration until the error is below a tolerance threshold [S1].

```python
def euler_implicit(pos, dt, vector_field_sampler, tolerance=1e-6, max_iterations=10):
    """
    Performs one step of implicit Euler integration using fixed-point iteration.
    
    Args:
        pos: Current position (Vec3).
        dt: Step size (float).
        vector_field_sampler: Function that returns vector (Vec3) at a given position.
        tolerance: Error threshold for convergence (float).
        max_iterations: Maximum number of fixed-point iterations (int).
        
    Returns:
        Next position (Vec3).
    """
    # Initial guess: use explicit Euler result
    v_current = vector_field_sampler(pos)
    next_pos = pos + v_current * dt
    
    for i in range(max_iterations):
        # Evaluate derivative at the current estimate of the next position
        v_next = vector_field_sampler(next_pos)
        
        # Calculate the new estimate based on the implicit formula:
        # y_{i+1} = y_i + s * f(y_{i+1}, t_i)
        new_next_pos = pos + v_next * dt
        
        # Check for convergence
        error = (new_next_pos - next_pos).length()
        if error < tolerance:
            return new_next_pos
            
        next_pos = new_next_pos
        
    # Return the last estimate if tolerance not reached
    return next_pos
```

**Parameters:**
*   **Step size ($s$ or $dt$):** The distance between samples. Larger $s$ results in faster calculation but lower accuracy [S1].
*   **Fixed-point tolerance:** The threshold for error in the fixed-point iteration for the implicit method. Configures the precision of the implicit solve [S1].

**Edge Cases and Pitfalls:**
*   **Precision:** For inappropriately large step sizes, the error remains undesirably large even for higher-order schemes [S2, unofficial].
*   **Vortices:** The Euler integrator tends to escape vortices even for very low time step values, whereas higher-order methods may converge to the center [S3, unofficial].
*   **Convergence:** The implicit method may fail to converge to an adequate solution for bigger step sizes if the per-step error is too high [S1].
*   **Stiffness:** Explicit Euler is prone to instabilities in stiff regions; implicit Euler is used to overcome mathematical singularities (e.g., point lights) with little performance hit [S1].

## Subtopics

### Bidirectional Diffusion Tensor Tracking
A variant used for tracking white matter tracts in diffusion tensor imaging. It modifies the tracking process by taking both forward and backward steps from the seed point (reversing the time step sign $\Delta t \to -\Delta t$) to overcome the arbitrary choice between eigenvectors and their negatives when decomposing the tensor field [S5, unofficial].

### [Verlet Integration](13495-verlet-integration.md)
A numerical integration method for particle dynamics that is time-reversible and unconditionally stable, distinguishing it from Euler Integration by implicitly handling velocity through position differences. It updates particle positions based on current and previous positions without explicitly storing velocity.

## Operating characteristics
**Time and Memory Complexity:**
*   **Time:** $O(1)$ per step. It requires only one vector field evaluation per step, making it the most efficient method for low accuracy requirements [S1].
*   **Memory:** $O(1)$ auxiliary memory (storing current position and vector).

**Measured Performance:**
*   Euler is the most efficient method for low accuracies [S1].
*   Global error is proportional to the step size $O(h)$, while local error is proportional to the square of the step size $O(h^2)$ [S2, S3, unofficial].

**Strengths and Limitations:**
*   **Strengths:** Simplest implementation (literally two lines of code) [S3, unofficial], fastest execution per step, and numerically equivalent to traditional ray marching [S1].
*   **Limitations:** First-order accuracy leads to significant error accumulation over long paths; escapes vortices; unstable in stiff regions without implicit formulation [S3, unofficial].

**When to use/not use:**
*   Use as a baseline for comparison or when performance is critical and high accuracy is not required [S1].
*   Do not use when tracking complex flow features like vortices, as the Euler integrator tends to escape them even for very low time step values [S3, unofficial].

## Background
Euler's method is the most basic numerical method for initial value problems, widely documented in existing literature [S1]. It was introduced as a standard technique for solving ordinary differential equations and has been applied in volume rendering as "traditional ray marching" [S1]. It is used in streamline visualization [S3, unofficial] and as a comparative baseline for more advanced integrators like Runge-Kutta methods [S1].
