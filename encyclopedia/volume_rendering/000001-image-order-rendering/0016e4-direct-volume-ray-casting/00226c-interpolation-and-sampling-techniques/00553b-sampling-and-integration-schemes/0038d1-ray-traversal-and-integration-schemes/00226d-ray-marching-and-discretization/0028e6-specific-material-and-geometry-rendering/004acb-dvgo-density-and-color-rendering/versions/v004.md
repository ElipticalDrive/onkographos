# DVGO Density and Color Rendering

Also called: DVGO volume rendering

## Overview
DVGO (Direct Volume Grid Optimization) is a method for synthesizing novel views of complex 3D scenes by combining the efficiency of voxel-based storage with the representational power of neural networks [S1]. It solves the problem of high memory consumption and slow rendering associated with pure neural radiance fields (NeRF) by storing density and color features in a 3D grid, while using a shallow MLP to handle view-dependent effects [S1]. Unlike pure voxel methods, DVGO supports continuous, view-dependent shading, and unlike pure NeRF, it avoids the $O(N)$ query cost per pixel by leveraging spatial locality and trilinear interpolation [S1].

## How it works
**Inputs and Outputs**
*   **Input**: A 3D grid of density values $V^{(\sigma)} \in \mathbb{R}^{N_x \times N_y \times N_z}$, a 3D grid of color features $V^{(f)} \in \mathbb{R}^{C \times N_x \times N_y \times N_z}$, a shallow MLP parameterized by $\Theta$, positional encoding function $\text{PE}(\cdot)$, ray direction $d$, near/far planes $t_n, t_f$, and step size $\delta$.
*   **Output**: A single color value $\hat{C}(r)$ for a camera ray $r$.

**Data Structures**
1.  **Density Grid ($V^{(\sigma)}$)**: A 3D tensor storing raw density values $\ddot{\sigma}_i$. Size: $N_x \times N_y \times N_z$. Values are real numbers.
2.  **Feature Grid ($V^{(f)}$)**: A 3D tensor storing color feature vectors. Size: $C \times N_x \times N_y \times N_z$, where $C$ is the feature dimension.
3.  **MLP ($MLP_\Theta$)**: A shallow multi-layer perceptron mapping concatenated feature vectors and positional encodings to RGB color.

**Numbered Steps**
1.  **Ray Sampling**: For a camera ray $r(t) = o + td$, sample $n$ points $x_i$ uniformly between the near plane $t_n$ and far plane $t_f$. The distance between adjacent points is $\delta_i = t_{i+1} - t_i$ (or constant step $\delta$).
2.  **Trilinear Interpolation**: For each sample point $x_i$, retrieve the raw density value $\ddot{\sigma}_i$ and color feature vector $f_i$ from the grids using trilinear interpolation:
    $$ \ddot{\sigma}_i = \text{interp}(x_i, V^{(\sigma)}) $$
    $$ f_i = \text{interp}(x_i, V^{(f)}) $$
    where $\text{interp}: \mathbb{R}^3 \times \mathbb{R}^{D \times N_x \times N_y \times N_z} \rightarrow \mathbb{R}^D$ [S1].
3.  **Density Activation**: Apply the shifted softplus activation to map the interpolated raw density to a non-negative extinction coefficient $\sigma_i$:
    $$ \sigma_i = \text{softplus}(\ddot{\sigma}_i) = \log(1 + \exp(\ddot{\sigma}_i + b)) $$
    where $b$ is a hyperparameter shift [S1].
4.  **Termination Probability**: Calculate the probability $\alpha_i$ that the ray terminates at $x_i$:
    $$ \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
    where $\delta_i$ is the distance to the adjacent sampled point [S1].
5.  **Color Emission**: Compute the view-dependent color $c_i^{(rgb)}$ by passing the interpolated feature $f_i$, the positional encoding of the position $\text{PE}(x_i)$, and the positional encoding of the direction $\text{PE}(d)$ through the MLP:
    $$ c_i^{(rgb)} = MLP_\Theta(f_i, \text{PE}(x_i), \text{PE}(d)) $$
    Positional encoding is applied to both $x_i$ and $d$ [S1].
6.  **Volume Rendering Quadrature**: Accumulate the colors along the ray using the standard volume rendering equation:
    $$ \hat{C}(r) = \sum_{i=1}^{n} T_i \alpha_i c_i + T_{n+1} c_{bg} $$
    where $c_{bg}$ is a pre-defined background color, and $T_i$ is the accumulated transmittance:
    $$ T_i = \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    $T_i$ denotes the transmittance from the near plane to point $x_i$ [S1].

**Parameters**
*   $b$: Shift hyperparameter in softplus. Not given in the sources.
*   $n$: Number of samples per ray. Not given in the sources.
*   $\delta$: Step size. Not given in the sources.
*   $C$: Feature dimension. Not given in the sources.

**Edge Cases and Pitfalls**
*   **Post-Activation Sharpness**: Applying non-linear activation functions (like softplus) *after* trilinear interpolation (post-activation) produces sharper surfaces than pre-activation, allowing for fewer cells to represent surface detail [S1].
*   **Precision**: The softplus function involves exponentials; ensure numerical stability for large negative values of $\ddot{\sigma}_i + b$ [G].

```python
import numpy as np

def positional_encoding(x, num_freq_bands=10):
    """Standard positional encoding for NeRF-style inputs."""
    freq_bands = 2.0 ** np.linspace(0, num_freq_bands - 1, num_freq_bands)
    x_expanded = np.expand_dims(x, axis=-1) * freq_bands

def dvgo_render_ray(ray_origin, ray_direction, near_plane, far_plane, 
                    density_grid, feature_grid, mlp_weights, 
                    num_samples, step_size, shift_b, bg_color):
    """
    Renders a single ray using the DVGO method.
    
    Args:
        ray_origin: (3,) array
        ray_direction: (3,) array
        near_plane: float
        far_plane: float
        density_grid: (Nx, Ny, Nz) array
        feature_grid: (C, Nx, Ny, Nz) array
        mlp_weights: parameters for the shallow MLP
        num_samples: int
        step_size: float (delta)
        shift_b: float (b)
        bg_color: (3,) array
        
    Returns:
        color: (3,) array
    """
    # 1. Sample points along the ray
    # [G] Assuming uniform sampling for simplicity as per standard DVGO description
    # Points are sampled between near_plane and far_plane
    t_vals = np.linspace(near_plane, far_plane, num_samples + 1)
    # Use midpoints for sampling
    t_samples = (t_vals[:-1] + t_vals[1:]) / 2.0
    
    # Ray points
    points = ray_origin + ray_direction * np.expand_dims(t_samples, axis=1)
    
    # 2. Interpolate density and features
    # [G] Assuming trilinear_interpolate is defined as above
    raw_densities = np.array([trilinear_interpolate(density_grid, p) for p in points])
    features = np.array([trilinear_interpolate(feature_grid, p) for p in points])
    
    # 3. Density Activation (Shifted Softplus)
    # sigma_i = log(1 + exp(sigma_ddot_i + b))
    densities = np.log(1 + np.exp(raw_densities + shift_b))
    
    # 4. Termination Probability
    # alpha_i = 1 - exp(-sigma_i * delta_i)
    # [G] Assuming constant step size delta
    deltas = np.full(num_samples, step_size)
    alphas = 1.0 - np.exp(-densities * deltas)
    
    # 5. Color Emission via MLP
    # c_i = MLP(interped_feature, PE(position), PE(direction))
    # [G] Placeholder for MLP forward pass
    # The MLP takes concatenated inputs: feature, PE(x), PE(d)
    colors = np.zeros((num_samples, 3))
    for i in range(num_samples):
        # Positional encoding
        pe_x = positional_encoding(points[i])
        pe_d = positional_encoding(ray_direction)
        
        # Concatenate feature, PE(x), PE(d)
        input_vec = np.concatenate([features[i], pe_x, pe_d])
        
        # [G] Placeholder for MLP computation
        # colors[i] = mlp_forward(input_vec, mlp_weights)
        # Since MLP details are not in source, we assume a standard forward pass
        # exists. For the purpose of this article, we note the dependency.
        colors[i] = np.tanh(input_vec[:3]) # Dummy output for structure
        
    # 6. Volume Rendering Quadrature
    # T_i = product(1 - alpha_j) for j < i
    # C = sum(T_i * alpha_i * c_i) + T_{n+1} * bg_color
    
    transmittances = np.ones(num_samples + 1)
    for i in range(1, num_samples + 1):
        transmittances[i] = transmittances[i-1] * (1 - alphas[i-1])
        
    # Accumulate color
    accumulated_color = np.zeros(3)
    for i in range(num_samples):
        accumulated_color += transmittances[i] * alphas[i] * colors[i]
        
    # Add background
    accumulated_color += transmittances[num_samples] * bg_color
    
    return accumulated_color
```

## Subtopics

### Mip-NeRF Density Activation
Uses the shifted softplus function for density mapping. Sets it apart by providing a smooth, non-negative mapping from raw grid values to density. Choose when smooth density transitions are needed. Link: [Mip-NeRF](link-to-mipnerf-if-available).

### Trilinear Interpolation
The standard method for retrieving values from the 3D grid. Sets it apart by being computationally efficient compared to higher-order interpolation. Choose for real-time or near-real-time rendering. Link: [Trilinear Interpolation](link-to-trilinear-if-available).

## Operating characteristics
*   **Time Complexity**: $O(N \cdot K)$ per pixel, where $N$ is the number of samples per ray and $K$ is the cost of the MLP forward pass and positional encoding. This is significantly faster than pure NeRF ($O(N \cdot M)$ where $M$ is the cost of querying a large MLP for every point without spatial caching) because the grid lookup is $O(1)$ and the MLP is shallow [S1].
*   **Memory Complexity**: $O(C \cdot N_x \cdot N_y \cdot N_z)$ for the feature grid and $O(N_x \cdot N_y \cdot N_z)$ for the density grid. This is much lower than storing a large MLP for every point in space, but higher than pure voxel rendering which stores only scalar values [S1].
*   **Measured Performance**: DVGO enables real-time rendering on modern GPUs by leveraging the efficiency of voxel grids while maintaining the quality of neural rendering [S1].
*   **Strengths**: Supports view-dependent effects; sharp surfaces with fewer cells due to post-activation; efficient rendering compared to pure NeRF.
*   **Limitations**: Resolution is limited by the grid size; aliasing artifacts may occur if the grid is too coarse; requires careful tuning of the shift parameter $b$ and grid resolution [S1].
*   **When to Use**: When view-dependent shading is required but pure NeRF is too slow or memory-intensive.
*   **When Not to Use**: When the scene has extremely fine details that require a very high-resolution grid, or when view-independent shading is sufficient (use pure voxel rendering).

## Background
DVGO was introduced in the paper "NeRF Synthesis with Shading Guidance" [S1]. It builds upon the principles of NeRF but addresses the computational bottlenecks by introducing a voxel-based representation for density and color features. The method leverages the shifted softplus activation from Mip-NeRF [S1] and demonstrates that post-activation interpolation leads to sharper surfaces.
