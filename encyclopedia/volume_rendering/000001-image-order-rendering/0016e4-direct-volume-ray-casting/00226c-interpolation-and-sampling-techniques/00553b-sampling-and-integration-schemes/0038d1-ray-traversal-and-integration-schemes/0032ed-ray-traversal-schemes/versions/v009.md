# Ray Traversal Schemes

Also called: Accumulate Projection, Depth Projection, Max Intensity Projection, Ray Traversal -Accumulate

## Overview
Ray traversal schemes define the reduction logic that maps a sequence of discretized ray samples $(C_i, \alpha_i)$ to a final pixel output [S1, S2, S3, unofficial]. They solve the problem of aggregating volumetric data along a viewing ray into a 2D image, determining whether the result represents a translucent composite, a maximum intensity projection, or an averaged density map [S1, S2, S3, unofficial]. This family is distinguished from sibling methods like [Ray Marching and Discretization](2788-ray-marching-and-discretization.md) by focusing on the compositing/reduction phase rather than the spatial sampling phase, and from [Monte Carlo Path Tracing for Volume Rendering](4980-monte-carlo-path-tracing-for-volume-rendering.md) by typically employing deterministic, order-dependent integration [S1, S2, S3, unofficial].

## Shared principles
The family operates on the discretized ray samples $(C_i, \alpha_i)$ generated by the parent's sampling stage [G]. The core mechanism is a reduction function $R$ that maps the sample sequence to a pixel output. The reduction types are:
1.  **Accumulation**: Front-to-back compositing using the standard alpha blending equation [S1, S2, S3, unofficial].
2.  **Extremum**: Selecting the maximum or minimum scalar value along the ray [S2, S3, unofficial].
3.  **Averaging**: Computing the arithmetic mean of scalar values [S1, S2, S3, unofficial].
4.  **First Hit**: Identifying the first sample that meets a classification threshold [S1, unofficial].
5.  **Depth**: Recording the ray parameter $t$ where the primary event occurs [S1, unofficial].

All schemes operate on the discretized ray samples generated by the parent's sampling stage [G]. The reduction logic can be implemented as follows:

```python
def reduce_samples(samples, scheme):
    accumulated_color = (0.0, 0.0, 0.0)
    accumulated_alpha = 0.0
    first_intensity = None
    first_depth = None
    max_intensity = None
    sum_intensity = 0.0
    count = 0
    for i, (c, a, t) in enumerate(samples):
        if scheme == "accumulate":
            accumulated_color = c * a * (1.0 - accumulated_alpha) + accumulated_color * (1.0 - a)
            accumulated_alpha = a + accumulated_alpha * (1.0 - a)
        elif scheme == "max":
            if max_intensity is None or c > max_intensity:
                max_intensity = c
        elif scheme == "average":
            sum_intensity += c
            count += 1
        elif scheme == "first":
            if first_intensity is None:
                first_intensity = c
                first_depth = t
        if scheme == "accumulate" and accumulated_alpha >= 1.0:
            break
    if scheme == "max": return max_intensity
    if scheme == "average": return sum_intensity / count if count > 0 else 0.0
    if scheme == "first": return first_intensity, first_depth
    return accumulated_color, accumulated_alpha
```

## Subtopics

### [Pixel Intensity Evaluation with Scene Aggregates](10890-pixel-intensity-evaluation-with-scene-aggregates.md)
Pixel Intensity Evaluation with Scene Aggregates is a rendering method that integrates radiance over a pixel footprint using aggregated visibility functions to handle inter-voxel correlation and background blending without order-dependent ray marching. It solves the problem of correctly blending scene aggregate contributions with external background objects, which standard volumetric models fail to distinguish when voxels have identical local properties but different spatial correlations. It sets itself apart from sibling methods like [X-Ray Volume Rendering](11336-x-ray-volume-rendering.md) by explicitly modeling the semi-transparency of geometry primitives via boundary visibility, rather than relying solely on scalar accumulation or extremum selection.

### [X-Ray Volume Rendering](11336-x-ray-volume-rendering.md)
X-Ray Volume Rendering is a volume rendering technique that computes the final color by linearly accumulating or averaging sampled voxel intensities along a ray, simulating a transmission view (like a CT scan) where opacity and alpha compositing are ignored. Unlike standard ray casting which uses front-to-back alpha blending to simulate opaque/translucent surfaces, X-Ray rendering sums the raw color values, resulting in a transparent/transmissive appearance where internal structures are visible as a superposition of densities. It differs from its sibling [Pixel Intensity Evaluation with Scene Aggregates](10890-pixel-intensity-evaluation-with-scene-aggregates.md) by specifically targeting the linear integration of voxel values rather than general scene aggregates.

### Voxel Aggregation Methods
Differentiable rendering approaches modify the standard traversal to allow gradient backpropagation through the ray. Yan et al. [7] associate an occupancy probability to each pixel by casting a ray, sampling all associated voxels, and choosing the one with the highest occupancy probability [S4, unofficial]. Tulsiani et al. [29] compute the probability that a ray stops at a certain distance, enabling the rendering of depth maps, color images, and foreground masks [S4, unofficial]. Henzler et al. [30] introduce a bidirectional emission-absorption (EA) light radiation model for emitting materials, in addition to visual hull (VH) and absorption-only (AO) models [S4, unofficial]. Lombardi et al. [31] iteratively accumulate color and opacity probabilities, discarding remaining voxels when cumulative opacity reaches a maximum value [S4, unofficial]. Jiang et al. [32] locate the surface voxel closest to the camera and compute the final pixel color as a weighted sum of the surface voxel and its neighbors, computing normals for shading [S4, unofficial]. A key pitfall is that while locating the surface point is not a differentiable operation, the pixel color remains differentiable with respect to the voxels around the surface point [S4, unofficial].

## Background
The Accumulate scheme, specifically front-to-back compositing, was formalized by Levoy in 1988 to make transparent layers visible by accumulating opacity while compositing colors [S1, S2, S3, unofficial]. Maximum Intensity Projection (MIP) is widely used in Magnetic Resonance Angiography to highlight high-intensity structures like blood vessels [S2, S3, unofficial]. Average projection produces an X-ray-like picture by averaging values along the ray [S1, S2, S3, unofficial]. First-hit and Depth schemes are used to extract iso-surfaces and depth information, respectively [S1, unofficial].
