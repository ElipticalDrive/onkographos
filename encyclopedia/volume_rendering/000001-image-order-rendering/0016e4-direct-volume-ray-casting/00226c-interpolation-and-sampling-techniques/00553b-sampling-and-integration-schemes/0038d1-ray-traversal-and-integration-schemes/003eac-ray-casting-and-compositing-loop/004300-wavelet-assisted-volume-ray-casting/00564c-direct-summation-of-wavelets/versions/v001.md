# Direct Summation of Wavelets

Also called: Direct Wavelet Summation, Direct summation approach, Direct wavelet summation on adaptive mesh, Wavelet space ray casting

## Overview
Direct Summation of Wavelets is a volume rendering technique that evaluates the radiative transfer equation by directly summing wavelet coefficients during ray casting, rather than resampling data onto a uniform grid or converting the wavelet-based grid into an unstructured mesh [S1]. It builds on [Wavelet-Assisted Volume Ray Casting](10893-wavelet-assisted-volume-ray-casting.md) by using the wavelet coefficients themselves as the primary data structure for evaluation, avoiding the memory overhead of traditional unstructured grid renderers like VTK's projected tetrahedra [S1]. Unlike VTK-based approaches, this method does not require significant memory and works successfully for large data sets, providing better image quality than VTK's projected tetrahedra renderer, though at slower speeds than VTK's ZSweep renderer [S1].

## How it works
The method evaluates the function $f(x)$ in physical space by summing scaling and wavelet coefficients, then uses these values to determine color $C$ and opacity $\alpha$ for the radiative transfer equation.

**Inputs and Outputs:**
*   **Input:** Wavelet coefficients from a 4th order interpolating wavelet transform of a regular grid (e.g., $256^3$); user-prescribed coarse grid resolution (typically $64^3$); threshold value $\epsilon$ for coefficient filtering.
*   **Output:** Rendered image pixels $I$.

**Data Structures:**
The implementation uses a linear array of `CoarseMeshNode` structures of size $N \times N \times N$ (where $N=64$ in the cited implementation) [S1].

```python
struct CoarseMeshNode {
    float scaling_coefficients[8];      // 8 nearest scaling coefficients
    WaveletNode* wavelet_node_array;    // Pointer to dynamically allocated array
    int number_of_wlt_nodes_of_level[J-1]; // Count of wavelet nodes per level
};

struct WaveletNode {
    float wavelet_coefficient;          // Coefficient value
    float wavelet_coordinates[3];       // Spatial coordinates (x, y, z)
    int wavelet_type;                   // Type identifier (redundant but speeds up summation)
};
```
The `wavelet_node_array` is sorted by wavelet levels and types to increase cache coherence [S1]. Storing 8 nearest scaling coefficients per node is redundant but provides ~30% acceleration due to better cache coherence [S1]. Storing `wavelet_type` is also redundant but saves computation time during summation, leading to an additional ~10% speedup [S1].

**Parameters:**
*   **Coarse grid resolution:** $N=64$ along one axis ($64^3$ total nodes) [S1].
*   **Threshold value $\epsilon$:** Recommended optimal value is 0.01 for preprocessing. Rendering results do not change for threshold values below 0.01 [S1].
*   **Cutoff limits:** Scaling function support cutoff is 1; Wavelet function support cutoff is 2. Functions are zero for argument $> \xi_{cutoff}$ [S1].

**Steps:**

1.  **Preprocessing:** Perform a partial inverse wavelet transform to obtain scaling functions on a coarse grid at the user-prescribed resolution (e.g., $64^3$) [S1]. This step is performed in a fraction of a second [S1].
2.  **Thresholding:** Filter wavelet coefficients. Only include wavelet coefficients with magnitude greater than the threshold value $\epsilon$ [S1]. The error in determining the function value $f(x)$ through this truncated version is $O(\epsilon)$ [S1].
3.  **Ray Casting Loop:** For each ray in the image:
    a.  **Coarse Image Generation:** Obtain a coarse image by linearly interpolating from the nearest eight coarse mesh scaling coefficients into the correspondent points on the ray [S1].
    b.  **Detail Addition:** Compute additional details by summing fine level wavelet coefficients. This step is currently non-interactive [S1].
    c.  **Function Evaluation:** For each point $x$ along the ray, calculate the function value $f(x)$ by summing scaling coefficients and wavelet coefficients based on support overlap with the interpolation point and wavelet amplitude [S1].
    d.  **Radiative Transfer:** Solve the radiative transfer equation using the computed $f(x)$ to determine color $C$ and opacity $\alpha$ [S1].

**Formulas:**

The radiative transfer equation solved is [S1]:
$$I = \int_0^\infty C \alpha e^{-\int_0^s \alpha ds'} ds$$
where color $C$ and opacity $\alpha$ are determined by the function $f(x)$ in physical space, $C = C(f(x))$ and $\alpha = \alpha(f(x))$ [S1].

The rendering integral is approximated as [S1]:
$$I \approx \sum_{i=0}^{n(\alpha)} C_i \alpha_i d_i \prod_{j=0}^{i-1} (1 - \alpha_j d_j)$$
where $i$ is the ray point index, $d_i$ is the constant step along the ray, and $n(\alpha)$ is the total number of points along the ray [S1].

**Pseudocode:**

```python
def render_image(wavelet_data, coarse_resolution=64, threshold=0.01):
    # Step 1: Preprocessing
    # Perform partial inverse wavelet transform to get scaling coefficients on coarse grid
    coarse_grid = partial_inverse_wavelet_transform(wavelet_data, coarse_resolution)
    
    # Step 2: Thresholding and Data Structure Construction
    # Filter coefficients and build CoarseMeshNode array
    coarse_mesh_nodes = []
    for i in range(coarse_resolution):
        for j in range(coarse_resolution):
            for k in range(coarse_resolution):
                node = CoarseMeshNode()
                # Store 8 nearest scaling coefficients for cache coherence
                node.scaling_coefficients = get_8_nearest_scaling_coeffs(coarse_grid, i, j, k)
                
                # Filter wavelet coefficients by threshold
                relevant_wavelets = []
                for wlt in wavelet_data:
                    if abs(wlt.coefficient) > threshold:
                        # Check support overlap with cutoff limits
                        # Scaling cutoff = 1, Wavelet cutoff = 2
                        if is_within_support(wlt, i, j, k, cutoff=2):
                            relevant_wavelets.append(wlt)
                
                # Sort by level and type for cache coherence
                relevant_wavelets.sort(key=lambda x: (x.level, x.type))
                
                node.wavelet_node_array = relevant_wavelets
                node.number_of_wlt_nodes_of_level = count_by_level(relevant_wavelets)
                
                coarse_mesh_nodes.append(node)
    
    # Step 3: Ray Casting
    image = empty_image(width, height)
    
    for ray in rays:
        # Linear interpolation from coarse mesh scaling coefficients
        # This provides the interactive coarse image
        coarse_values = linear_interpolate_from_coarse_mesh(ray, coarse_mesh_nodes)
        
        # Detail addition: Summation of fine level wavelet coefficients
        # This step is non-interactive in the cited implementation
        fine_details = []
        for point in ray.points:
            # Find relevant coarse mesh node
            node = get_coarse_mesh_node_for_point(point, coarse_mesh_nodes)
            
            # Sum wavelet coefficients based on support overlap
            f_x = 0.0
            for wlt_node in node.wavelet_node_array:
                # Use table lookup for scaling/wavelet functions phi and psi
                # with artificial cutoff limits (1 for scaling, 2 for wavelet)
                basis_value = evaluate_basis_function(wlt_node, point)
                f_x += wlt_node.coefficient * basis_value
            
            fine_details.append(f_x)
        
        # Solve Radiative Transfer Equation
        # I approx sum(C_i * alpha_i * d_i * product(1 - alpha_j * d_j))
        ray_color = 0.0
        transmittance = 1.0
        d = ray.step_size # Constant step
        
        for i, f_val in enumerate(fine_details):
            C = map_color(f_val)
            alpha = map_opacity(f_val)
            
            ray_color += C * alpha * d * transmittance
            transmittance *= (1 - alpha * d)
            
        image.set_pixel(ray.pixel_coords, ray_color)
        
    return image
```

**Edge Cases and Pitfalls:**
*   **Cache Misses:** One cache miss occurs during access to scaling coefficients, and at least one cache miss occurs during summation of wavelet coefficients inside each coarse mesh block [S1].
*   **Precision:** The error in determining the function value $f(x)$ through the truncated version of the equation with all wavelet coefficients greater than the threshold is $O(\epsilon)$ [S1].
*   **Hardware Acceleration:** The current implementation does not use hardware acceleration [S1].

## Operating characteristics
*   **Time Complexity:** Rendering time is linear relative to the number of rays, the average number of points on a ray, and the number of wavelet coefficients in the sum [S1].
*   **Memory Complexity:** Requires less memory than VTK-based approaches, making it suitable for large data sets [S1]. The redundancy in storing 8 nearest scaling coefficients increases memory usage slightly but improves performance [S1].
*   **Measured Performance:** On a Pentium 4 3.2 GHz, 2G RAM, Nvidia GeForce Fx5200-TD128, rendering a $500 \times 500$ image for Convection data set with threshold 0.5 took 39 seconds [S1].
*   **Strengths:** Better image quality than VTK's projected tetrahedra renderer; does not require much memory; works successfully for all data sets including large ones [S1].
*   **Limitations:** Rendering time is slower than VTK's projected tetrahedra renderer; the detail addition step is non-interactive in the cited implementation; no hardware acceleration is used [S1].
*   **When to use:** When memory is constrained or when rendering large wavelet-based data sets where VTK-based unstructured grid renderers fail due to memory limits [S1].
*   **When not to use:** When interactive detail addition is required or when maximum possible image quality is needed (VTK's ZSweep provides better quality, albeit much slower) [S1].

## Background
*   **Origin:** The method was presented in the paper "Volumetric Rendering on Wavelet-Based Adaptive Grid" [S1].
*   **History:** It was developed as an alternative to complementing the adaptive wavelet grid with a traditional AMR grid for subsequent VTK-based rendering [S1].
*   **Usage:** Used for rendering convection and hydrogen 3D orbital data sets generated on regular $256^3$ grids compressed via 4th order interpolating wavelet transform [S1].
