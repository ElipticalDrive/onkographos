# Depth Compositing Speculated Intersections

Also called: Closest Hit Selection, Speculation Depth Compositing

## Overview
This method performs depth compositing on a set of potential intersections found for each ray during speculative ray traversal [S1]. It iterates through $N_{Spec}$ candidates to select the closest valid hit and writes the result to the framebuffer, marking rays that exit the volume without a hit as terminated [S1]. It differs from non-speculative compositing by handling multiple block IDs per ray ID, requiring an offset buffer to resolve unique ray-block pairs [S1].

## How it works
**Inputs:**
- $N_{Spec}$: Speculation count per ray [S1].
- $RID$: Buffer of ray IDs, where each active ray ID appears $N_{Spec}$ times [S1].
- $O_{Spec}$: Offset buffer providing the index into the intersection data for each ray-block pair [S1].
- Intersection data: Depth values and other attributes for the $N_{Spec}$ blocks traversed by each ray [S1].
- $w, h$: Image width and height [S1].
- $N_{Act}$: Number of currently active rays [S1].

**Outputs:**
- Framebuffer: Final color/depth for each pixel [S1].
- Termination status: Marks rays that did not hit a surface [S1].

**Data Structures:**
- $RID$: Array of size $N_{Act} \times N_{Spec}$. Contains ray identifiers. Not unique per entry; duplicates indicate multiple speculation slots for the same ray [S1].
- $O_{Spec}$: Array of size $N_{Act} \times N_{Spec}$. Stores offsets into the intersection results buffer, allowing the kernel to access the correct depth/value for each specific ray-block intersection [S1].

**Parameters:**
- $N_{Spec} = \lfloor \frac{w \times h}{N_{Act}} \rfloor$ [S1].
- Maximum $N_{Spec} = 64$ [S1].

**Steps:**
1. For each active ray $r$ in the active set:
2.   Initialize $closest\_hit = \infty$ and $hit\_found = false$ [G].
3.   For $i$ from 0 to $N_{Spec} - 1$:
4.     Retrieve the ray ID $rid = RID[r \times N_{Spec} + i]$ [S1].
5.     Retrieve the offset $offset = O_{Spec}[r \times N_{Spec} + i]$ [S1].
6.     Retrieve the depth $d$ and attributes from the intersection data at $offset$ [S1].
7.     If $d < closest\_hit$:
8.       $closest\_hit = d$
9.       $best\_result = attributes$
10.      $hit\_found = true$
11.   If $hit\_found$:
12.     Write the attributes from $best\_result$ to the framebuffer at the pixel corresponding to ray $r$ [S1].
13.   Else:
14.     Mark ray $r$ as terminated [S1].

**Pseudocode:**
```python
def depth_compositing_speculated_intersections(RID, O_Spec, intersection_data, N_Spec, N_Act):
    """
    Selects the closest intersection for each active ray from N_Spec candidates.
    """
    framebuffer = [None] * N_Act
    terminated = [False] * N_Act

    for r in range(N_Act):
        closest_depth = float('inf')
        best_result = None
        hit_found = False

        for i in range(N_Spec):
            offset = O_Spec[r * N_Spec + i]
            depth, attributes = intersection_data[offset]

            if depth < closest_depth:
                closest_depth = depth
                best_result = attributes
                hit_found = True

        if hit_found:
            framebuffer[r] = best_result
        else:
            terminated[r] = True

    return framebuffer, terminated
```

**Edge Cases and Pitfalls:**
- Without 64-bit atomics, depth sorting must be performed in this compositing step rather than during traversal [S1].
- The speculation count is capped at 64 to balance between terminating rays in fewer passes and performing unnecessary computation [S1].

## Operating characteristics
- **Time Complexity:** $O(N_{Act} \times N_{Spec})$ per pass. Since $N_{Spec} \approx \frac{w \times h}{N_{Act}}$, total work is $O(w \times h)$ per pass, independent of $N_{Act}$ [S1].
- **Memory Complexity:** Requires buffers for $RID$ and $O_{Spec}$ of size $N_{Act} \times N_{Spec} \approx w \times h$ [S1].
- **Performance:** Evaluated on datasets from $256^3$ to $2048 \times 2048 \times 1920$ voxels [S1].
- **Strengths:** Allows efficient use of GPU resources by reusing terminated ray slots for speculation [S1].
- **Limitations:** Requires multiple passes if $N_{Spec}$ is small; limited to 64 speculation slots [S1].

## Background
Described as the final compositing step in speculative progressive raycasting for memory-constrained isosurface visualization of massive volumes [S1]. The method addresses the non-uniqueness of ray IDs in speculative traversal by introducing offset buffers [S1].
