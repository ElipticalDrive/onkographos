# Epipolar Sampling


## Overview
Epipolar sampling is a technique to sample features from other views along epipolar lines for a given ray, enabling cross-view feature aggregation without full 3D volume rendering during the encoding phase [S1, unofficial]. It solves the problem of efficiently correlating information between a reference view and target views without performing full 3D volume rendering or explicit 3D reconstruction during the encoding phase [S1, unofficial].

## How it works
**Inputs:**
- `features`: Tensor of image features for all views.
- `intrinsics`: Camera intrinsic matrices.
- `extrinsics`: Camera-to-world transformation matrices (OpenCV-style, +Z forward) [S1, unofficial].
- `near`, `far`: Near and far plane distances for ray projection.
- `num_samples` ($s$): Number of samples per epipolar line segment. Typical value: 64 [S1, unofficial].

**Outputs:**
- `features_sampled`: Tensor of aggregated features.
- `valid`: Boolean mask indicating valid samples.
- `xy_sample`: Sample coordinates in target view space.

**Data Structures:**
The core data structure for the sampling result is defined by the `EpipolarSampling` dataclass fields [S1, unofficial]:
- `features`: `Float[Tensor, 'batch view other_view ray sample channel']`
- `valid`: `Bool[Tensor, 'batch view other_view ray']`
- `xy_ray`: `Float[Tensor, 'batch view ray 2']`
- `xy_sample`: `Float[Tensor, 'batch view other_view ray sample 2']`
- `xy_sample_near`: `Float[Tensor, 'batch view other_view ray sample 2']`
- `xy_sample_far`: `Float[Tensor, 'batch view other_view ray sample 2']`
- `origins`: `Float[Tensor, 'batch view ray 3']`
- `directions`: `Float[Tensor, 'batch view ray 3']`

**Steps:**
1. **Generate Image Rays:** Generate image rays (xy, origins, directions) for each pixel in the source view using `sample_image_grid` and `get_world_rays` [S1, unofficial].
2. **Project Rays to Target Views:** Project these rays onto all other views using `project_rays` with extrinsics, intrinsics, near, and far planes to obtain `xy_min`, `xy_max`, and `overlaps_image` [S1, unofficial].
3. **Clamp and Mask:** Clamp `xy_min` and `xy_max` to zero for infinite values and mask with `overlaps_image` [S1, unofficial].
4. **Compute Sample Depths:** Compute sample depths linearly spaced between 0 and 1: `sample_depth = (torch.arange(s) + 0.5) / s` [S1, unofficial].
5. **Interpolate Sample Coordinates:** Interpolate sample coordinates in the target view: `xy_sample = xy_min + sample_depth * (xy_max - xy_min)` [S1, unofficial].
6. **Handle View Exclusion:** Transpose the sample coordinates so the 'view' dimension refers to the view from which samples are drawn (target view), handling the exclusion of the diagonal (self-view) via precomputed indices [S1, unofficial].
7. **Sample Features:** Sample image features at `xy_sample` coordinates using bilinear `grid_sample` with zero padding [S1, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def epipolar_sampling(features, intrinsics, extrinsics, near, far, num_samples=64):
    """
    Args:
        features: [B, V, H, W, C]
        intrinsics: [V, 3, 3]
        extrinsics: [V, 4, 4] (OpenCV camera-to-world)
        near, far: float
        num_samples: int
    Returns:
        sampled_features: [B, V, V-1, R, S, C]
        valid: [B, V, V-1, R]
        xy_sample: [B, V, V-1, R, S, 2]
    """
    B, V, H, W, C = features.shape
    R = H * W
    s = num_samples
    device = features.device

    # 1. Generate image rays for source view [S1, unofficial]
    y, x = torch.meshgrid(torch.arange(H), torch.arange(W), indexing='ij')
    xy_source = torch.stack([x, y], dim=-1).float() # [H, W, 2]
    xy_source_flat = xy_source.reshape(-1, 2) # [R, 2]
    origins = torch.zeros(B, V, R, 3, device=device) # [B, V, R, 3]
    directions = torch.zeros(B, V, R, 3, device=device) # [B, V, R, 3]
    # (get_world_rays implementation omitted; assumes origins/directions computed per pixel) [G]

    # 2. Project rays to target views [S1, unofficial]
    xy_min = torch.zeros(B, V, V, R, 2, device=device)
    xy_max = torch.zeros(B, V, V, R, 2, device=device)
    overlaps_image = torch.zeros(B, V, V, R, dtype=torch.bool, device=device)
    # (project_rays implementation omitted; assumes xy_min, xy_max, overlaps_image computed) [G]

    # 3. Clamp and mask [S1, unofficial]
    xy_min = torch.where(torch.isinf(xy_min), torch.zeros_like(xy_min), xy_min)
    xy_max = torch.where(torch.isinf(xy_max), torch.zeros_like(xy_max), xy_max)
    xy_min = xy_min * overlaps_image.unsqueeze(-1)
    xy_max = xy_max * overlaps_image.unsqueeze(-1)

    # 4. Compute sample depths [S1, unofficial]
    sample_depth = (torch.arange(s, device=device) + 0.5) / s # [S]

    # 5. Interpolate sample coordinates [S1, unofficial]
    # Broadcast sample_depth to [1, 1, 1, 1, S, 1]
    xy_sample = xy_min.unsqueeze(4) + sample_depth.unsqueeze(0).unsqueeze(0).unsqueeze(0).unsqueeze(0) * (xy_max.unsqueeze(4) - xy_min.unsqueeze(4)) # [B, V, V, R, S, 2]

    # 6. Transpose and handle diagonal exclusion [S1, unofficial]
    xy_sample = xy_sample.transpose(1, 2) # [B, V, V, R, S, 2]
    diag_mask = torch.eye(V, dtype=torch.bool, device=device)
    xy_sample = xy_sample[:, ~diag_mask] # [B, V, V-1, R, S, 2]

    # 7. Sample features [S1, unofficial]
    # Normalize to [-1, 1] for grid_sample [G]
    x_norm = 2.0 * (xy_sample[..., 0] / W) - 1.0
    y_norm = 2.0 * (xy_sample[..., 1] / H) - 1.0
    grid = torch.stack([x_norm, y_norm], dim=-1) # [B, V', R, S, 2]

    # Reshape features for grid_sample: [B*V, C, H, W]
    features_flat = features.permute(0, 1, 4, 2, 3).reshape(B * V, C, H, W)
    grid_flat = grid.reshape(B * V, R, S, 2)
    sampled = F.grid_sample(features_flat, grid_flat, mode='bilinear', padding_mode='zeros', align_corners=False) # [B*V, C, R, S]
    sampled_features = sampled.permute(0, 2, 3, 1).reshape(B, V, V-1, R, S, C) # [B, V, V-1, R, S, C]

    valid = overlaps_image.any(dim=-1) # [B, V, V, R]
    valid = valid[:, ~diag_mask] # [B, V, V-1, R]

    return sampled_features, valid, xy_sample
```

## Subtopics

### [Epipolar Encoder](6426-epipolar-encoder.md)
The Epipolar Encoder is a two-view (or multi-view) neural module that resolves scale ambiguity in 3D reconstruction by aggregating cross-view features along epipolar lines. It solves the problem where camera poses are scaled by an arbitrary factor $s_i$, preventing the inference of metric depth from a single view. Unlike standard volume rendering which samples along a ray, this method samples features from a reference pixel and correlates them with features sampled along the corresponding epipolar line in a second view, augmented with positionally encoded depths. This allows the encoder to memorize the correct depth consistent with the scene's arbitrary scale, which is then used for subsequent Gaussian parameter prediction.

### Spot Light Rectification
An extension of the rectification mapping for perspective cameras and local spot lights, where the $\gamma$ coordinate is set to the angle the light ray makes with the direction from the light to the camera [S2]. This results in nonuniform sampling density along the camera ray, causing the $ds/d\gamma$ term in the integral $I(\gamma, \beta)$ to vary with both $\gamma$ and $\beta$, unlike directional lights where it varies only with $\beta$ [S2].
