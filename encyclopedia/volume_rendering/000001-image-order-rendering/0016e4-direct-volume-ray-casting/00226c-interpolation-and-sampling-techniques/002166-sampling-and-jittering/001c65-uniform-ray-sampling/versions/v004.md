# Uniform Ray Sampling

Also called: Uniform Sampling, Uniform Point Sampling, Uniform Point Sampling along Rays

## Overview
Uniform Ray Sampling generates a fixed number of 3D points along camera rays by distributing sample depths evenly or randomly within the interval defined by the near and far clipping planes. It serves as the baseline discretization strategy for volume rendering and neural radiance fields (NeRF) when no transmittance estimator or density prior is available, assuming every point along the ray contributes equally to the final rendering [S2]. Unlike [Stratified Ray Sampling](3014-stratified-ray-sampling.md) which introduces controlled randomness within structured bins to break aliasing, or [Spatial Skipping](2516-sampling-and-jittering.md) which skips empty regions, uniform sampling distributes points across the entire depth range without structural adaptation, making it the simplest to implement but often the least efficient for scenes with large empty spaces [S2].

## How it works
**Inputs:**
*   `origins`: Tensor of ray origins, shape $(N, 3)$, where $N$ is the number of rays.
*   `directions`: Tensor of unit-norm ray directions, shape $(N, 3)$.
*   `near`: Scalar or tensor of near clipping plane distances.
*   `far`: Scalar or tensor of far clipping plane distances.
*   `num_samples` (or `n_pts_per_ray`): Integer specifying the number of samples per ray.

**Outputs:**
*   `sample_points`: Tensor of 3D coordinates, shape $(N, \text{num\_samples}, 3)$.
*   `sample_lengths`: Tensor of segment lengths, shape $(N, \text{num\_samples}, 1)$, used for integration weights.

**Data Structures:**
The method typically operates on a `RayBundle` object or similar structure containing `origins`, `directions`, `sample_points`, and `sample_lengths` [S6][S7, unofficial].

**Steps:**
1.  **Generate Depth Values:** Create a 1D tensor of `num_samples` values linearly spaced between `near` and `far`. Let these be $z_i$ for $i = 0, \dots, \text{num\_samples}-1$.
    $$ z_i = \text{near} + \frac{i}{\text{num\_samples} - 1} (\text{far} - \text{near}) $$
    *Note: Some implementations use $N+1$ points or specific indexing $i \in [0, N]$ for the interval endpoints [S10]. The standard discrete sampling for integration usually uses $N$ points representing the centers or start of intervals.*
2.  **Broadcast Ray Parameters:** Reshape `origins` to $(N, 1, 3)$ and `directions` to $(N, 1, 3)$ to allow broadcasting with the depth tensor. Reshape $z$ to $(1, \text{num\_samples}, 1)$ or $(N, \text{num\_samples}, 1)$ depending on batch handling.
3.  **Compute 3D Positions:** Calculate the 3D sample points $\mathbf{x}_i$ using the ray equation:
    $$ \mathbf{x}_i = \mathbf{o} + z_i \cdot \mathbf{d} $$
    where $\mathbf{o}$ is the ray origin and $\mathbf{d}$ is the ray direction [S10][S13, unofficial].
4.  **Compute Segment Lengths:** Calculate the distance between consecutive samples to determine the integration step size (delta). For uniform sampling, the delta $\Delta z$ is constant:
    $$ \Delta z = \frac{\text{far} - \text{near}}{\text{num\_samples}} $$
    The `sample_lengths` tensor is filled with $\Delta z$ (or the specific distance between adjacent $z_i$ values) [S7, S12, unofficial].

**Pseudocode:**
```python
import torch

def uniform_ray_sampling(origins, directions, near, far, num_samples):
    """
    Generates uniform sample points along camera rays.
    
    Args:
        origins: Tensor of shape (N, 3)
        directions: Tensor of shape (N, 3), unit norm
        near: Float or Tensor of shape (N,)
        far: Float or Tensor of shape (N,)
        num_samples: Int, number of samples per ray
        
    Returns:
        sample_points: Tensor of shape (N, num_samples, 3)
        sample_lengths: Tensor of shape (N, num_samples, 1)
    """
    # 1. Generate linearly spaced depth values between near and far
    # Using linspace to get num_samples points. 
    # Note: Some implementations use num_samples + 1 for boundaries, 
    # but for point sampling, num_samples points are standard.
    # If near/far are scalars:
    if near.dim() == 0:
        z_vals = torch.linspace(near, far, num_samples, device=origins.device)
    else:
        # Handle per-ray near/far if they are tensors
        # Reshape for broadcasting: (N, 1)
        near = near.unsqueeze(1)
        far = far.unsqueeze(1)
        # Create steps
        steps = torch.linspace(0, 1, num_samples, device=origins.device)
        z_vals = near * (1 - steps) + far * steps
        
    # 2. Reshape for broadcasting
    # origins: (N, 1, 3)
    origins = origins.unsqueeze(1)
    # directions: (N, 1, 3)
    directions = directions.unsqueeze(1)
    # z_vals: (N, num_samples, 1) if per-ray, else (num_samples, 1) -> broadcast to N
    if near.dim() == 0:
        z_vals = z_vals.unsqueeze(0).expand(origins.shape[0], -1, 1)
    else:
        z_vals = z_vals.unsqueeze(2) # (N, num_samples, 1)

    # 3. Compute 3D sample points: P = O + D * z
    sample_points = origins + directions * z_vals
    
    # 4. Compute sample lengths (deltas)
    # For uniform sampling, delta is constant
    if near.dim() == 0:
        delta = (far - near) / num_samples
        sample_lengths = torch.full_like(sample_points[..., :1], delta)
    else:
        # Calculate delta from z_vals differences if needed, 
        # but for uniform linspace, it's constant per ray
        delta = (far - near) / num_samples
        sample_lengths = torch.full_like(sample_points[..., :1], delta)
        
    return sample_points, sample_lengths
```

**Edge Cases and Pitfalls:**
*   **Near/Far Equality:** If `near == far`, the interval is zero, leading to division by zero or identical sample points. Guard against this by clamping or skipping rays.
*   **Precision:** In very large scenes, linear depth sampling can lead to poor resolution near the camera if `far` is large. This is addressed by variants like [Uniform NDC Point Sampling](2395-uniform-ndc-point-sampling.md) or logarithmic sampling [S10].
*   **Aliasing:** Regular uniform sampling can cause aliasing artifacts (Moiré patterns) in volume rendering. This is often mitigated by adding small random noise (jitter) to the sample positions, effectively turning it into stratified sampling [S11, S14, unofficial].

## Subtopics

### [Stratified Monte Carlo Radiance Estimate](1373-stratified-monte-carlo-radiance-estimate.md)
The Stratified Monte Carlo Radiance Estimate is an unbiased radiance estimation method that reduces variance compared to uniform sampling by dividing the ray interval into strata and sampling within each. It is particularly effective for degenerate distributions where uniform sampling requires significantly more samples to achieve comparable accuracy. Unlike [Uniform Ray Sampling](1261-uniform-ray-sampling.md), which distributes points evenly or randomly across the entire depth range without structure, this method ensures coverage of the entire interval by enforcing one sample per bin.

### [Evenly Spaced Sampling with Preprocessed Rays and Depth Indicators](2335-evenly-spaced-sampling-with-preprocessed-rays-and-depth-indi.md)
This method ensures even spacing along rays within a voxel cell by using preprocessed ray data and a 4-bit depth-sampling indicator stored in the pixel opacity. It solves the problem of efficiently computing sampling coordinates for trilinear interpolation and evaluating the Riemann sum in front-to-back order. It differs from [Uniform Ray Sampling](1261-uniform-ray-sampling.md) by relying on a shared set of preprocessed rays and a stateful depth indicator to maintain sampling continuity across cells.

### [Uniform NDC Point Sampling](2395-uniform-ndc-point-sampling.md)
Uniform NDC Point Sampling transforms camera rays into an average camera frame and uniformly samples points within the projected Normalized Device Coordinates (NDC) space. It solves the problem of inefficient sample distribution in large scenes by providing a linear sampling in disparity from the near plane to infinity in original space, which combines the benefits of uniform and logarithmic sampling approaches. It is distinct from other strategies because it is only applicable if all samples lie strictly in the front hemisphere of the average camera frame, a limitation not shared by siblings like Stratified Ray Sampling.

### [Batch Stratified Sampling](2730-batch-stratified-sampling.md)
Batch Stratified Sampling generates $N_c$ evenly-spaced depth bins in the interval $[near, far]$ and perturbs sample positions within each bin to reduce aliasing artifacts during volume rendering. It extends Uniform Ray Sampling by stratifying the depth interval, ensuring samples are distributed more evenly across the ray's depth range.

### [Stratified Ray Sampling](3014-stratified-ray-sampling.md)
Stratified Ray Sampling divides the ray interval $[near, far]$ into $N$ evenly-spaced bins and draws one sample uniformly at random from each bin. Unlike [Evenly Spaced Sampling with Preprocessed Rays and Depth Indicators](2335-evenly-spaced-sampling-with-preprocessed-rays-and-depth-indi.md) which uses fixed positions, this method introduces controlled randomness within structured intervals. It is used to improve the feel and quality of training data for volume rendering by breaking up regular sampling patterns.

### [Local Sampling](5532-local-sampling.md)
Local Sampling is a ray sampling strategy that reduces computational cost by concentrating samples around a known surface representation, such as a depth texture, rather than distributing them uniformly along the entire ray. It solves the problem of wasted evaluations in empty space, allowing for a drastic reduction in sample count (down to two per ray) while maintaining high rendering quality. Unlike [Uniform Ray Sampling](1261-uniform-ray-sampling.md), which samples the full depth range, Local Sampling relies on an oracle (ground truth or learned) to localize the surface, making it distinct from sibling methods like [Stratified Ray Sampling](3014-stratified-ray-sampling.md) that do not require explicit surface priors.

### Forward Sampling Inside Surface
Samples points forward along the ray from the surface to get SDF values inside the object, used when latent space is not pretrained [S3, unofficial]. It asserts `num_forward_sampling > 0`, computes grid offsets, and generates points at `valid_zdepth + grid` to decode SDF values [S3, unofficial].

### Camera Ray Sampling for Translucent Materials
For translucent materials, this method computes the exit point $d_{\max}$ and samples the ray randomly with a small number of samples (as low as one) [S15]. The sample depths $d_k$ are computed using the formula:
$$ d_k = -\frac{1}{\sigma_t} \log \left( 1 - \frac{|k(1 - e^{-\sigma_t d_{\max}})|}{k_{\max}} \right) $$
where $\sigma_t$ is the extinction coefficient, $k$ is the sample index, and $k_{\max}$ is the total number of samples [S15]. This ensures exactly $k_{\max}$ samples are placed, handling small object widths by preventing undersampling [S15].

### Non-linear (Logarithmic) Sampling
A sample placement strategy using logarithmic non-linearity to focus samples on objects closer to the camera, reducing network evaluations without losing quality in large depth ranges [S10]. The logarithmic depth $\tilde{d}_i$ is calculated from uniform depth $d_i$ as:
$$ \tilde{d}_i = d_{min} + \frac{\log(d_i - d_{min} + 1)}{\log(d_{max} - d_{min} + 1)} \cdot (d_{max} - d_{min}) $$
In ablation studies, logarithmic sampling increases PSNR by 1.3 dB per doubling of $N$, compared to 1.8 dB for uniform sampling [S10].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot S)$, where $N$ is the number of rays and $S$ is the number of samples per ray. The generation of points is linear in the total number of samples.
*   **Memory Complexity:** $O(N \cdot S \cdot 3)$ for storing the sample points, plus $O(N \cdot S)$ for lengths.
*   **Performance:** On an RTX PRO 6000 Blackwell, processing 1M rays for the dragon dataset with fp32 and cone=0 takes approximately 2.790ms (optimized) vs 2.953ms (baseline), a 1.06x speedup [S1, unofficial]. For the wdas_cloud dataset (2.6 GB fog), it takes 16.391ms vs 17.216ms, a 1.05x speedup [S1, unofficial].
*   **Strengths:** Simple to implement; deterministic (if no jitter); serves as a robust baseline for comparison [S2].
*   **Limitations:** Lowest efficiency in most cases compared to spatial skipping or PDF-based methods because it samples empty space uniformly [S2]. Prone to aliasing artifacts without jitter [S11, unofficial].
*   **When to Use:** When no density information is available; as a baseline for training NeRFs; in scenes where objects are distributed uniformly throughout the depth range.
*   **When Not to Use:** In scenes with large empty spaces (use Spatial Skipping); when high accuracy is needed with few samples (use Importance Sampling); when aliasing is a concern without jitter.

## Background
Uniform sampling is the default raymarching strategy in NeRF-style rendering, placing samples uniformly between the near and far planes [S10]. It assumes a constant PDF and linearly decaying transmittance $T(t) = 1 - (t - t_n)/(t_f - t_n)$, which is mathematically equivalent to uniform sampling along the ray [S2]. This method is widely used as the baseline in NeRF [16] and its variants [S2, S10].
