# Non-linear (Logarithmic) Sampling

Also called: Logarithmic Sampling, Logarithmic Sampling for Volumetric Clouds, Logarithmic depth sampling

## Overview
Non-linear (Logarithmic) Sampling is a sample placement strategy that distributes points along a view ray using a logarithmic function to concentrate density near the camera while maintaining coverage over large depth ranges [S1][S2, unofficial]. It addresses the limitation of uniform sampling in large scenes, where linear spacing causes excessive evaluations in the distance or insufficient resolution near the viewer [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Minimum depth $d_{min}$, maximum depth $d_{max}$, and the number of samples $N$ [G].
*   **Outputs:** A sequence of $N$ depth values $\tilde{d}_i$ for $i \in [0, N-1]$ [G].

**Data Structures:**
*   A contiguous array of floating-point numbers storing the computed depth values [G].

**Parameters:**
*   $d_{min}$: The start of the ray segment (typically camera near plane) [G].
*   $d_{max}$: The end of the ray segment (typically camera far plane) [G].
*   $N$: The total number of samples per ray [G].

**Formulas:**
The method first generates uniform depth indices $d_i$ and then warps them logarithmically [S1].
1. **Uniform Depth Generation:**
   $$d_i = d_{min} + \frac{i}{N-1} (d_{max} - d_{min})$$
   where $i$ is the sample index from $0$ to $N-1$ [G].
2. **Logarithmic Warping:**
   $$\tilde{d}_i = d_{min} + \frac{\log(d_i - d_{min} + 1)}{\log(d_{max} - d_{min} + 1)} \cdot (d_{max} - d_{min})$$ [S1].

**Pseudocode:**
```python
import math

def generate_logarithmic_samples(d_min, d_max, n_samples):
    """
    Generates n_samples depth values along a ray from d_min to d_max
    using logarithmic non-linearity.
    
    Args:
        d_min (float): Minimum depth (near plane).
        d_max (float): Maximum depth (far plane).
        n_samples (int): Number of samples to generate.
        
    Returns:
        list[float]: List of warped depth values.
    """
    if n_samples <= 0:
        return []
    if d_max <= d_min:
        return [d_min] * n_samples
    if n_samples == 1:
        return [d_min]

    samples = []
    depth_range = d_max - d_min
    
    # Logarithmic base is arbitrary as long as numerator and denominator match [G]
    log_denom = math.log(depth_range + 1)
    
    for i in range(n_samples):
        # Step 1: Calculate uniform depth d_i
        d_i = d_min + (i / (n_samples - 1)) * depth_range
        
        # Step 2: Apply logarithmic warping
        numerator = math.log(d_i - d_min + 1)
        warped_depth = d_min + (numerator / log_denom) * depth_range
        
        samples.append(warped_depth)
        
    return samples
```

**Edge Cases and Pitfalls:**
*   **Precision:** The addition of $1$ inside the logarithm ensures the argument remains positive when $d_i = d_{min}$ [S1].
*   **Balance:** If the sampling density along the z-axis is not balanced with the x-y plane coverage, lighting will appear incorrect when the camera rotates, even if the static render looks acceptable [S2, unofficial]. The goal is to keep the frustum covered by a single sample roughly cubic [S2, unofficial].
*   **Under-sampling:** To maintain performance, the number of samples along the z-axis is typically set to approximately 10 times fewer than the number of samples covering the x-y plane area [S2, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources [G].
*   **Memory Complexity:** Not given in the sources [G].
*   **Performance:** In ablation studies, logarithmic sampling increases PSNR by 1.3 dB per doubling of $N$, compared to 1.8 dB for uniform sampling [S1].
*   **Strengths:** Reduces network evaluations in large depth ranges without losing quality near the camera [S1].
*   **Limitations:** Lower PSNR efficiency per sample compared to uniform sampling; requires careful balancing with x-y sampling density to avoid lighting artifacts [S2, unofficial].
*   **When to use:** Large scenes with significant depth ranges; volumetric clouds; neural radiance fields where near-field detail is critical [S1][S2, unofficial].
*   **When not to use:** Small scenes with limited depth range; scenarios where uniform distribution is strictly required for theoretical guarantees [G].

## Background
Non-linear logarithmic sampling was introduced in the context of compact neural radiance fields, specifically in the DONeRF paper [S1]. It was proposed as an intuitive first step to reduce network evaluations by focusing samples on objects closer to the camera [S1]. The technique was further popularized and adapted for real-time volumetric cloud rendering in game engines, where it is described as the "most important optimization for large scenes" to balance sample frustums [S2, unofficial].
