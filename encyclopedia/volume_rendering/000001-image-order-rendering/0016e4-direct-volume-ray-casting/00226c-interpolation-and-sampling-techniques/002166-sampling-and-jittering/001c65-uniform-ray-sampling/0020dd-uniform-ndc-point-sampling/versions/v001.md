# Uniform NDC Point Sampling

Also called: NDC Sampling

## Overview
Uniform NDC Point Sampling transforms camera rays into an average camera frame and uniformly samples points within the projected Normalized Device Coordinates (NDC) space [S1]. It solves the problem of inefficient sample distribution in large scenes by providing a linear sampling in disparity from the near plane to infinity in original space, which combines the benefits of uniform and logarithmic sampling approaches [S1]. It is distinct from other strategies because it is only applicable if all samples lie strictly in the front hemisphere of the average camera frame, a limitation not shared by siblings like Stratified Ray Sampling [S1].

## How it works
**Inputs:**
*   Ray origin $o = (o_x, o_y, o_z)$ and direction $d = (d_x, d_y, d_z)$ in world or camera coordinates.
*   Number of samples per ray $N_{samples}$ [S2, unofficial].
*   NDC depth bounds: $d_{min} = 1$ and $d_{max} = \infty$ [S1].
*   Bounding box limits: $xyz_{min}$ and $xyz_{max}$ [S2, unofficial].

**Outputs:**
*   A list of $N_{samples}$ 3D points sampled along the ray.

**Data Structures:**
*   Points are stored as a list or array of 3D coordinates $(p_x, p_y, p_z)$.

**Steps:**
1.  **Transform to Average Frame:** Transform the ray origin $o$ and direction $d$ into the average camera frame [S1]. This step is critical to ensure the validity of the NDC assumption.
2.  **Compute Normalized Distance:** For each step index $i_{step} \in \{0, 1, \dots, N_{samples}-1\}$, compute the normalized distance $dist$ [S2, unofficial]:
    $$ dist = \frac{i_{step}}{N_{samples} - 1} $$
3.  **Interpolate 3D Point:** Compute the 3D point coordinates by linear interpolation using the transformed ray parameters [S2, unofficial]:
    $$ p_x = o_x + d_x \times dist $$
    $$ p_y = o_y + d_y \times dist $$
    $$ p_z = o_z + d_z \times dist $$
    *Note: The sources describe this linear interpolation in the context of NDC space [S1][S2, unofficial]. In standard NDC, $dist$ typically maps to depth $z$, but the provided pseudocode logic in [S2, unofficial] implies a direct linear interpolation along the ray vector components.*
4.  **Bounding Box Check:** Determine if the point is outside the bounding box defined by $xyz_{min}$ and $xyz_{max}$ by checking if any coordinate is less than the min or greater than the max [S2, unofficial].

**Pseudocode:**
```python
def uniform_ndc_point_sampling(ray_origin, ray_direction, n_samples, bbox_min, bbox_max):
    """
    Samples points uniformly in NDC space along a ray.
    
    Args:
        ray_origin: Tuple (ox, oy, oz)
        ray_direction: Tuple (dx, dy, dz)
        n_samples: Integer, number of samples per ray
        bbox_min: Tuple (xmin, ymin, zmin)
        bbox_max: Tuple (xmax, ymax, zmax)
        
    Returns:
        List of tuples (px, py, pz)
    """
    # Step 1: Transform to average camera frame
    # [G] The exact transformation matrix is not provided in the sources.
    # The user must apply the transformation defined in the original NeRF paper appendix
    # or the specific implementation's average camera frame logic.
    # For the purpose of this implementation, we assume ray_origin and ray_direction
    # are already in the correct frame or the transformation is a placeholder.
    o_x, o_y, o_z = ray_origin
    d_x, d_y, d_z = ray_direction
    
    points = []
    
    # Step 2 & 3: Compute normalized distance and interpolate
    for i_step in range(n_samples):
        # Compute normalized distance
        dist = i_step / (n_samples - 1)
        
        # Linear interpolation in NDC space
        # Note: Standard NDC sampling usually maps dist to depth z.
        # However, [S2, unofficial] explicitly defines px, py, pz as linear interpolation
        # along the ray vector components. This implies the "NDC" space here
        # might be treated as a linear parameterization or the transformation
        # in Step 1 aligns the ray such that this linear interpolation holds.
        p_x = o_x + d_x * dist
        p_y = o_y + d_y * dist
        p_z = o_z + d_z * dist
        
        # Step 4: Bounding box check
        # [G] The sources mention checking bounds but do not specify if points
        # outside are discarded, clamped, or kept. We keep them as per the
        # sampling definition, but a robust implementation might filter them.
        if (p_x < bbox_min[0] or p_x > bbox_max[0] or
            p_y < bbox_min[1] or p_y > bbox_max[1] or
            p_z < bbox_min[2] or p_z > bbox_max[2]):
            # Option 1: Discard (not specified in sources)
            # Option 2: Keep (default behavior of sampling)
            pass 
            
        points.append((p_x, p_y, p_z))
        
    return points
```

**Parameters:**
*   $N_{samples}$: The fixed number of samples per ray [S2, unofficial].
*   $d_{min} = 1$, $d_{max} = \infty$ [S1].

**Edge Cases and Pitfalls:**
*   **Front Hemisphere Constraint:** The method is only applicable if all samples lie strictly in the front hemisphere of the average camera frame [S1].
*   **Perspective Distortions:** Large deviations from the average camera frame lead to high non-linear perspective distortions, which may negatively impact the learning process [S1].
*   **Sample Count Threshold:** In ablation studies, NDC sampling only surpasses uniform sampling in quality at 128 samples [S1].

## Operating characteristics
*   **Time Complexity:** $O(N_{samples})$ per ray, as it performs a fixed number of linear interpolations [S2, unofficial].
*   **Memory Complexity:** $O(N_{samples})$ to store the sampled points [S2, unofficial].
*   **Performance:** In ablation studies on diverse scenes (Bulldozer, Forest, Classroom, San Miguel), NDC sampling only manages to surpass uniform sampling at 128 samples [S1]. It performs worse than all other local sampling approaches until $N=32$ [S1].
*   **Strengths:** Combines uniform and logarithmic sampling approaches from the perspective of network input [S1]. Linear in NDC space [S1].
*   **Limitations:** Limited to scenes where rays can be transformed to an average frame with all samples in the front hemisphere [S1]. Sensitive to large deviations from the average camera frame [S1].
*   **When to Use:** When using a fixed number of samples per ray and the scene geometry allows for a stable average camera frame transformation [S1][S2, unofficial].
*   **When Not to Use:** When rays extend into the back hemisphere of the average camera frame or when high accuracy is required with low sample counts (<128) [S1].

## Background
Uniform NDC Point Sampling was introduced in the context of NeRF (Neural Radiance Fields) [S1]. It is based on the NDC sampling strategy proposed in the original NeRF paper [MST*20] [S1]. The method transforms rays into an average camera frame and uniformly samples within the projected normalized device coordinates (NDC), directly feeding NDC samples into positional encoding [S1]. The detailed derivations for the transformation are provided in the appendix of the original NeRF paper [S1]. It is used in neural rendering pipelines to handle large scenes and improve training efficiency by focusing samples on the foreground while dampening background high frequencies [S1].
