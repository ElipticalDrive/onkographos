# Mesh-based Sampling

Also called: Wan et al. Mesh-based Sampling

## Overview
Mesh-based Sampling localizes surface evaluation by estimating the volume density or Signed Distance Field (SDF) to define an inner and outer mesh boundary, using learned features attached to mesh vertices to estimate radiance [S1]. It builds on [Local Sampling](5532-local-sampling.md) by placing samples around a known ground truth surface representation to reduce empty space evaluations [S1]. It sets itself apart from sibling methods by requiring only two samples per ray, significantly improving runtime efficiency while remaining applicable as a post-processing step to any existing NeRF models [S1].

## How it works
**Inputs:**
*   An implicit representation (volume density or SDF) defining the object geometry [S1].
*   Two meshes (inner and outer) derived from the implicit representation [S1].
*   Learned features attached to the vertices of these meshes [S1].
*   A viewing direction vector $\mathbf{d}$ for the ray [S1].

**Outputs:**
*   Estimated radiance for the ray [S1].

**Data Structures:**
*   **Inner Mesh:** A triangular mesh representing the inner boundary of the surface region, with vertices storing learned feature vectors [S1].
*   **Outer Mesh:** A triangular mesh representing the outer boundary of the surface region, with vertices storing learned feature vectors [S1].
*   **Ray:** Defined by origin $\mathbf{o}$ and direction $\mathbf{d}$ [G].

**Steps:**
1.  **Ray-Mesh Intersection:** Compute the intersection points of the viewing ray with both the inner mesh and the outer mesh [S1]. Let these intersection points be $\mathbf{p}_{\text{in}}$ and $\mathbf{p}_{\text{out}}$ respectively [S1].
2.  **Feature Interpolation:** At each intersection point ($\mathbf{p}_{\text{in}}$ and $\mathbf{p}_{\text{out}}$), interpolate the learned features from the surrounding mesh vertices [S1]. This yields feature vectors $\mathbf{f}_{\text{in}}$ and $\mathbf{f}_{\text{out}}$ [S1].
3.  **Radiance Estimation:** Feed the interpolated features ($\mathbf{f}_{\text{in}}, \mathbf{f}_{\text{out}}$) and the viewing direction $\mathbf{d}$ into a shallow convolutional network [S1].
4.  **Output:** The network outputs the estimated radiance [S1].

**Formulas:**
*   Feature interpolation: $\mathbf{f}(\mathbf{p}) = \text{Interpolate}(\mathcal{M}, \mathbf{p})$, where $\mathcal{M}$ is the mesh and $\mathbf{p}$ is the intersection point [S1].
*   Radiance estimation: $L = \mathcal{N}(\mathbf{f}(\mathbf{p}_{\text{in}}), \mathbf{f}(\mathbf{p}_{\text{out}}), \mathbf{d})$, where $\mathcal{N}$ is the shallow convolutional network [S1].

**Parameters:**
*   Number of samples per ray: 2 [S1].

**Edge Cases and Pitfalls:**
*   Ray-mesh intersection precision must be handled carefully to avoid missing thin surface regions or producing incorrect $\mathbf{p}_{\text{in}}$/$\mathbf{p}_{\text{out}}$ ordering [G].
*   The shallow convolutional network architecture must be explicitly designed to accept two spatial feature vectors and a direction vector as joint inputs [S1].

**Pseudocode:**
```python
def mesh_based_sampling(ray_origin, ray_direction, inner_mesh, outer_mesh, network):
    # 1. Ray-mesh intersection
    p_in = intersect_ray_mesh(ray_origin, ray_direction, inner_mesh)
    p_out = intersect_ray_mesh(ray_origin, ray_direction, outer_mesh)
    # 2. Feature interpolation
    f_in = interpolate_features(inner_mesh, p_in)
    f_out = interpolate_features(outer_mesh, p_out)
    # 3. Radiance estimation
    radiance = network(f_in, f_out, ray_direction)
    return radiance
```

## Subtopics

### Trajectory Sample Strategy
A query point sampling strategy where points are distributed along a displacement trajectory from a voxel grid to the surface closest point, designed to be more efficient than uniform or Gaussian sampling for mesh deformation tasks [S2, unofficial]. It maintains performance with fewer query points (75k vs 200k) and is more efficient for mesh deformation [S2, unofficial]. In unconstrained chair point cloud generation, Trajectory 75k achieved CD=56.12 and EMD=53.30, outperforming Uniform 75k (CD=56.88, EMD=54.93) and Gaussian 75k (CD=56.46, EMD=53.97) [S2, unofficial]. Compared to uniform sampling (query points uniformly from voxel shape space) and Gaussian sampling (points sampled with Gaussian distribution, mean=ground truth surface, variance=0.1 and 0.01), trajectory sampling maintains performance with fewer query points (75k vs 200k) and is more efficient for mesh deformation [S2, unofficial].

## Operating characteristics
*   **Efficiency:** Requires only two samples per ray, significantly improving runtime efficiency compared to methods that require dense sampling or multiple evaluations [S1].
*   **Generality:** Can be applied as a post-processing step to any existing NeRF models, making it a versatile addition to existing pipelines [S1].
*   **Performance:** Specific quantitative performance metrics (e.g., FPS, memory usage) for the Wan et al. method are not given in the sources [S1].

## Background
The method was proposed by Wan et al. [WRB* 23] as a way to localize the surface between an inner and outer mesh using volume density or SDF estimates from an implicit representation [S1]. It is cited in recent surveys on learning-based 3D representations as a technique that improves runtime efficiency by minimizing the number of samples per ray [S1].
