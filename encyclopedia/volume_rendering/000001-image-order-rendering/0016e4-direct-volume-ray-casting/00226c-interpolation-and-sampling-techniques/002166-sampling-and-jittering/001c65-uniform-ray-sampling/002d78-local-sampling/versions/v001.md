# Local Sampling

Also called: Depth-guided Sampling, Surface-aware Sampling

## Overview
Local Sampling is a ray sampling strategy that reduces computational cost by concentrating samples around a known surface representation, such as a depth texture, rather than distributing them uniformly along the entire ray [S1]. It solves the problem of wasted evaluations in empty space, allowing for a drastic reduction in sample count (down to two per ray) while maintaining high rendering quality [S1]. Unlike [Uniform Ray Sampling](1261-uniform-ray-sampling.md), which samples the full depth range, Local Sampling relies on an oracle (ground truth or learned) to localize the surface, making it distinct from sibling methods like [Stratified Ray Sampling](3014-stratified-ray-sampling.md) that do not require explicit surface priors.

## How it works
**Inputs:**
*   Ray origin $\mathbf{o}$ and direction $\mathbf{d}$.
*   Minimum depth $t_{min}$ and maximum depth $t_{max}$ defining the ray segment.
*   A depth oracle providing the ground truth surface depth $t_{surf}$ at the ray's intersection with the surface [S1].

**Outputs:**
*   A set of sample depths $\{t_i\}$ concentrated around $t_{surf}$.

**Data Structures:**
*   The depth oracle is typically implemented as a neural network (Depth Oracle Network) that predicts $t_{surf}$ given camera parameters, or accessed as a precomputed depth texture [S1].

**Steps:**
1.  **Query Surface Depth:** Determine the depth $t_{surf}$ of the nearest surface along the ray $\mathbf{d}$ using the depth oracle [S1].
2.  **Define Local Region:** Define a narrow interval $[t_{surf} - \delta, t_{surf} + \delta]$ around the surface, where $\delta$ is a small offset [S1].
3.  **Sample Locally:** Place the required number of samples (e.g., $N=2$) uniformly or with jittering within this local interval [S1].
4.  **Render:** Evaluate the volume rendering integral using only these local samples [S1].

**Formulas:**
*   Sample placement: $t_i = t_{surf} + \epsilon_i$, where $\epsilon_i$ is a small perturbation [S1].
*   Quality metric: Log+warp sampling adds approximately 1.3 dB in PSNR over uniform sampling when used with Local Sampling [S1].

**Parameters:**
*   Number of samples per ray: Can be reduced to $N=2$ with nearly no decrease in quality [S1].
*   Offset $\delta$: Not explicitly defined in sources, but implied to be small enough to avoid mixing foreground and background [S1].

**Edge Cases and Pitfalls:**
*   **Depth Discontinuities:** If the depth oracle is smooth (e.g., a single-output network), it may smooth over depth discontinuities, causing samples to mix foreground and background features and distort the image [S1].
*   **Inference Availability:** Ground truth depth is often unavailable during inference due to memory constraints and the need for reprojection for novel views [S1]. This limits Local Sampling to niche scenarios or requires training a learned sampling oracle [S1].

**Pseudocode:**
```python
def local_sampling(ray_origin, ray_direction, depth_oracle, t_min, t_max, num_samples=2):
    """
    Generates samples concentrated around the surface depth predicted by the oracle.
    
    Args:
        ray_origin: 3D vector, origin of the ray.
        ray_direction: 3D vector, direction of the ray.
        depth_oracle: Function or data structure providing surface depth t_surf.
        t_min: Float, minimum depth of the ray segment.
        t_max: Float, maximum depth of the ray segment.
        num_samples: Int, number of samples to generate (default 2).
        
    Returns:
        depths: List of floats, sample depths along the ray.
    """
    # Step 1: Query the surface depth from the oracle
    # The oracle takes ray parameters and returns the depth to the nearest surface
    t_surf = depth_oracle(ray_origin, ray_direction)
    
    # Define a small local window around the surface
    # The exact width of the window is not specified in sources, 
    # but it must be narrow enough to avoid background mixing [S1]
    delta = 0.01  # [G] Placeholder value; implementation-specific
    
    t_start = max(t_min, t_surf - delta)
    t_end = min(t_max, t_surf + delta)
    
    # Step 2: Generate samples uniformly within the local window
    if num_samples == 1:
        depths = [t_surf]
    else:
        # Uniform sampling within the local interval
        step = (t_end - t_start) / (num_samples - 1) if num_samples > 1 else 0
        depths = [t_start + i * step for i in range(num_samples)]
        
    return depths
```

## Subtopics

### Mesh-based Sampling
A variant that uses volume density or Signed Distance Field (SDF) estimates to localize the surface between an inner and an outer mesh, with learned features attached to mesh vertices [S2]. It computes ray intersections with both meshes, interpolates features at these points, and feeds them along with the viewing direction into a shallow convolutional network to estimate radiance [S2]. This approach requires only two samples per ray, significantly improving runtime efficiency, and can be applied as a post-processing step to any existing NeRF models [S2].

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of samples per ray. Since $N$ can be reduced to 2, the per-ray cost is minimal [S1, S2].
*   **Memory Complexity:** Requires storage for the depth oracle (neural network weights or depth textures) [S1]. Large-scale scenes may require significant storage for individual depth maps [S1].
*   **Performance:** With local sampling, the number of samples can be reduced to two with nearly no decrease in quality [S1]. Log+warp adds about 1.3 dB in quality over uniform for local sampling [S1].
*   **Strengths:** Drastic reduction in sample count; high quality-speed tradeoff when surface geometry is known [S1].
*   **Limitations:** Ground truth depth is often unavailable during inference; depth smoothing can cause artifacts at discontinuities [S1].
*   **When to use:** When a reliable surface representation (depth map, SDF, or mesh) is available and computational resources are limited [S1, S2].
*   **When not to use:** In novel view synthesis where reprojection of depth maps is not feasible or when depth discontinuities are prominent and the oracle is not sharp enough [S1].

## Background
Local Sampling was introduced in the context of NeRF (Neural Radiance Fields) to address the inefficiency of uniform sampling in empty space [S1]. The concept was explored in "DONeRF: Towards Real‐Time Rendering of Compact Neural Radiance Fields using Depth Oracle Networks" [S1], which proposed using a depth oracle network to predict surface locations during training, enabling efficient sampling at inference. Mesh-based variants were later discussed in "Recent Advances and Trends in Learning‐Based 3D Representations" [S2], highlighting methods that use SDFs or meshes for surface localization.
