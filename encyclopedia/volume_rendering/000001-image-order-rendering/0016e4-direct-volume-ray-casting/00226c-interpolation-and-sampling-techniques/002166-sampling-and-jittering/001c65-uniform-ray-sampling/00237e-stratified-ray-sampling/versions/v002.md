# Stratified Ray Sampling

Also called: Jittered Uniform Sampling, Stratified Sampling

## Overview
Stratified Ray Sampling divides the ray interval $[near, far]$ into $N$ evenly-spaced bins and draws one sample uniformly at random from each bin [S3, unofficial]. Unlike [Evenly Spaced Sampling with Preprocessed Rays and Depth Indicators](2335-evenly-spaced-sampling-with-preprocessed-rays-and-depth-indi.md) which uses fixed positions, this method introduces controlled randomness within structured intervals [S3, unofficial]. It is used to improve the feel and quality of training data for volume rendering by breaking up regular sampling patterns [S1, unofficial].

## How it works
**Inputs:**
- `near` (float): Minimum depth ($z_{min}$) [S2, unofficial].
- `far` (float): Maximum depth ($z_{max}$) [S2, unofficial].
- `n_pts_per_ray` (int): Number of samples $N$ per ray [S2, unofficial].
- `lindisp` (bool): If True, sample linearly in disparity ($1/z$) instead of depth [S3, unofficial].
- `perturb` (bool): If True, add uniform noise within each bin [S3, unofficial].
- `origins` (Tensor): Ray origins, shape $[N_{rays}, 3]$.
- `directions` (Tensor): Ray directions, shape $[N_{rays}, 3]$.

**Outputs:**
- `z_vals` (Tensor): Depth values, shape $[N_{rays}, N]$.
- `sample_points` (Tensor): 3D coordinates, shape $[N_{rays}, N, 3]$.

**Data Structures:**
- `z_vals`: 2D tensor where each row corresponds to a ray and each column to a sample index.
- `sample_points`: 3D tensor where the last dimension is the spatial coordinate $(x, y, z)$.

**Steps:**

1.  **Generate Base Intervals:**
    Compute $N$ evenly spaced values $t_i$ in the range $[0, 1]$ [S3, unofficial]:
    $$ t_i = \frac{i}{N-1}, \quad i = 0, \dots, N-1 $$
    If `lindisp` is True, compute depths in disparity space [S3, unofficial]:
    $$ z_i = \frac{1}{\frac{1}{near}(1 - t_i) + \frac{1}{far}t_i} $$
    Otherwise, compute depths linearly [S3, unofficial]:
    $$ z_i = near(1 - t_i) + far \cdot t_i $$

2.  **Apply Perturbation (if enabled):**
    If `perturb` is True, divide the interval into bins and sample uniformly within each bin [S3, unofficial]:
    - Compute midpoints between sorted samples:
      $$ m_i = \frac{1}{2}(z_{i+1} + z_i), \quad i = 0, \dots, N-2 $$
    - Define bin boundaries [S3, unofficial]:
      $$ lower_i = \begin{cases} z_0 & i=0 \\ m_{i-1} & i > 0 \end{cases} $$
      $$ upper_i = \begin{cases} m_i & i < N-1 \\ z_{N-1} & i = N-1 \end{cases} $$
    - Generate uniform random noise $r_i \sim U(0, 1)$ for each sample [S3, unofficial].
    - Compute final stratified depths:
      $$ z_i = lower_i + (upper_i - lower_i) \cdot r_i $$
    If `perturb` is False, $z_i$ remains unchanged [S3, unofficial].

3.  **Compute 3D Points:**
    For each ray $r$ with origin $o_r$ and direction $d_r$, compute the 3D sample positions [S3, unofficial]:
    $$ P_{r,i} = o_r + z_{r,i} \cdot d_r $$
    This is vectorized as:
    $$ \text{sample\_points} = \text{origins} + \text{z\_vals} \cdot \text{directions} $$
    where broadcasting handles the dimensions $[N_{rays}, 1, 3]$ for origins/directions and $[N_{rays}, N, 1]$ for z_vals [S3, unofficial].

**Pseudocode:**

```python
import torch

def stratified_ray_sampling(origins, directions, near, far, n_pts_per_ray, lindisp=False, perturb=True):
    """
    Generate stratified samples along rays.
    
    Args:
        origins: Tensor of shape [N_rays, 3]
        directions: Tensor of shape [N_rays, 3]
        near: float, minimum depth
        far: float, maximum depth
        n_pts_per_ray: int, number of samples N
        lindisp: bool, sample in disparity space
        perturb: bool, add uniform noise within bins
        
    Returns:
        z_vals: Tensor of shape [N_rays, N]
        sample_points: Tensor of shape [N_rays, N, 3]
    """
    N = n_pts_per_ray
    device = origins.device
    
    # Step 1: Generate base intervals
    t_vals = torch.linspace(0.0, 1.0, N, device=device)
    
    if lindisp:
        # Sample linearly in disparity (1/depth)
        inv_near = 1.0 / near
        inv_far = 1.0 / far
        z_vals = 1.0 / (inv_near * (1.0 - t_vals) + inv_far * t_vals)
    else:
        # Sample linearly in depth
        z_vals = near * (1.0 - t_vals) + far * t_vals
        
    # Expand z_vals to [N_rays, N] for batched rays
    z_vals = z_vals.unsqueeze(0).expand(origins.shape[0], -1)
    
    # Step 2: Apply Perturbation
    if perturb:
        # Compute midpoints: mids[i] = 0.5 * (z_vals[i+1] + z_vals[i])
        mids = 0.5 * (z_vals[:, 1:] + z_vals[:, :-1])
        
        # Define bin boundaries
        lower = torch.cat([z_vals[:, :1], mids], dim=1)
        upper = torch.cat([mids, z_vals[:, -1:]], dim=1)
        
        # Generate random noise
        t_rand = torch.rand_like(z_vals)
        
        # Sample uniformly within bins
        z_vals = lower + (upper - lower) * t_rand
        
    # Step 3: Compute 3D Points
    # origins: [N_rays, 3], directions: [N_rays, 3], z_vals: [N_rays, N]
    # Reshape for broadcasting: origins [N_rays, 1, 3], directions [N_rays, 1, 3], z_vals [N_rays, N, 1]
    sample_points = origins[:, None, :] + z_vals[:, :, None] * directions[:, None, :]
    
    return z_vals, sample_points
```

**Parameters:**
- `n_pts_per_ray`: Number of sample points per ray. Typical values are $N_c = 64$ for coarse passes and $N_f = 128$ for fine passes in hierarchical sampling [S3, unofficial].
- `min_depth` (`near`): Starting depth for sampling [S2, unofficial].
- `max_depth` (`far`): Ending depth for sampling [S2, unofficial].
- `lindisp`: Boolean flag. If True, sampling is performed in disparity space [S3, unofficial].
- `perturb`: Boolean flag. If True, uniform noise is added to break up regular sampling patterns [S3, unofficial].

## Background
Stratified Ray Sampling is used in the "coarse" pass of hierarchical sampling strategies to provide a uniform initial estimate before refining samples in high-density regions [S3, unofficial]. It is also used in general volume rendering to improve the feel and quality of training data by breaking up regular sampling patterns [S1, unofficial].
