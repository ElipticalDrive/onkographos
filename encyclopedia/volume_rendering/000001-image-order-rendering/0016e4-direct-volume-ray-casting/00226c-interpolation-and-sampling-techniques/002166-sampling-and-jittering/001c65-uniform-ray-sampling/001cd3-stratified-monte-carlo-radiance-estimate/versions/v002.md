# Stratified Monte Carlo Radiance Estimate

Also called: RVS Stratified Estimate, Stratified Sampling

## Overview
The Stratified Monte Carlo Radiance Estimate is an unbiased radiance estimation method that reduces variance compared to uniform sampling by dividing the ray interval into strata and sampling within each [S1, unofficial]. It is particularly effective for degenerate distributions where uniform sampling requires significantly more samples to achieve comparable accuracy [S1, unofficial]. Unlike [Uniform Ray Sampling](1261-uniform-ray-sampling.md), which distributes points evenly or randomly across the entire depth range without structure, this method ensures coverage of the entire interval by enforcing one sample per bin [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** Ray $\mathbf{r}$, near clipping plane $t_n$, far clipping plane $t_f$, number of samples $k$.
- **Outputs:** Radiance estimate $\hat{C}_{\text{IW}}(\mathbf{r})$, sample points $\tau_i$, sample lengths $(t_i - t_{i-1})$ [S1, S2, unofficial].

**Data Structures:**
- `RayBundle.sample_lengths`: A tensor/array of size $k$ storing the length of each bin $(t_i - t_{i-1})$ [S2, unofficial].
- `RayBundle.sample_points`: A tensor/array of size $k$ storing the sampled positions $\tau_i$ along the ray direction [S2, unofficial].

**Steps:**
1. Define the bin boundaries by dividing the interval $[t_n, t_f]$ into $k$ equal parts:
   $$ t_i = t_n + i \cdot \frac{t_f - t_n}{k}, \quad i = 0, \dots, k $$
   where $t_0 = t_n$ and $t_k = t_f$ [S1, S3, unofficial].
2. Extract lower and upper bounds for each bin $i$:
   $$ \text{lower}_i = t_{i-1}, \quad \text{upper}_i = t_i $$
   [S3, unofficial].
3. Sample a point $\tau_i$ within each bin. Two modes are supported:
   - **Randomized:** Sample uniformly within the bin:
     $$ \tau_i = \text{lower}_i + u_i \cdot (\text{upper}_i - \text{lower}_i), \quad u_i \sim U[0, 1] $$
     [S3, unofficial].
   - **Deterministic (Midpoint):** Use the center of the bin:
     $$ \tau_i = 0.5 \cdot (\text{lower}_i + \text{upper}_i) $$
     [S3, unofficial].
4. Compute the radiance estimate using the stratified formula [S1, unofficial]:
   $$ \hat{C}_{\text{IW}}(\mathbf{r}) = \sum_{i=1}^k (t_i - t_{i-1}) c_{\mathbf{r}}(\tau_i) \frac{dF_{\mathbf{r}}}{dt} \bigg|_{t=\tau_i} $$
   where $c_{\mathbf{r}}(\tau_i)$ is the color contribution at $\tau_i$ and $\frac{dF_{\mathbf{r}}}{dt}$ is the differential transmittance/opacity derivative at $\tau_i$ [S1, unofficial].
5. Store the bin lengths $(t_i - t_{i-1})$ in `RayBundle.sample_lengths` and the sample points $\tau_i$ in `RayBundle.sample_points` [S2, unofficial].

**Pseudocode:**
```python
import random

def stratified_monte_carlo_radiance_estimate(ray_origin, ray_direction, near, far, k, randomize=True):
    """
    Computes the stratified Monte Carlo radiance estimate.
    
    Args:
        ray_origin: (3,) tuple/list, origin of the ray.
        ray_direction: (3,) tuple/list, normalized direction of the ray.
        near: float, near clipping plane distance.
        far: float, far clipping plane distance.
        k: int, number of samples (bins).
        randomize: bool, if True, sample uniformly within bins; if False, use midpoints.
        
    Returns:
        radiance_estimate: float, the estimated radiance.
        sample_points: list of (3,) tuples, 3D positions of samples.
        sample_lengths: list of floats, lengths of each bin.
    """
    # Step 1: Create bin boundaries
    bin_boundaries = [near + i * (far - near) / k for i in range(k + 1)]
    
    # Step 2: Extract lower and upper bounds
    lower_bounds = bin_boundaries[:-1]
    upper_bounds = bin_boundaries[1:]
    
    # Step 3: Sample points within each bin
    samples = []
    for l, u in zip(lower_bounds, upper_bounds):
        if randomize:
            u_i = random.uniform(0.0, 1.0)
            samples.append(l + u_i * (u - l))
        else:
            samples.append(0.5 * (l + u))
            
    # Step 4: Compute sample lengths
    sample_lengths = [u - l for l, u in zip(lower_bounds, upper_bounds)]
    
    # Step 5: Compute 3D sample points
    sample_points = [
        (ray_origin[0] + s * ray_direction[0],
         ray_origin[1] + s * ray_direction[1],
         ray_origin[2] + s * ray_direction[2])
        for s in samples
    ]
    
    # Step 6: Compute radiance estimate
    # The sources do not specify how c_r(tau_i) and dF_r/dt are evaluated [G]
    radiance_estimate = 0.0
    for i in range(k):
        # c_r(tau_i) and dF_r/dt|_{t=tau_i} are assumed to be computed by the renderer
        radiance_estimate += sample_lengths[i] * c_r(sample_points[i]) * dF_r(sample_points[i])
        
    return radiance_estimate, sample_points, sample_lengths
```

**Parameters:**
- $k$: Number of samples. Typical values vary by scene complexity. In "Foggy" field experiments, $k=32$ matched the performance of $k=256$ uniform samples [S1, unofficial]. In "Wall" field experiments, $k=4$ was sufficient to match the baseline [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Degenerate Distributions:** The method is specifically noted to be effective for degenerate distributions, where uniform sampling performs poorly [S1, unofficial].
- **Boundary Conditions:** The bins are defined as $[t_{i-1}, t_i]$, ensuring full coverage of $[t_n, t_f]$ without gaps or overlaps [S1, unofficial].

## Operating characteristics
- **Measured Performance:** In "Foggy" field experiments, $k=32$ stratified samples matched the accuracy of $k=256$ uniform samples, representing an 8x reduction in sample count [S1, unofficial]. In "Wall" field experiments, $k=4$ stratified samples matched the baseline, a 64x reduction [S1, unofficial].
- **Strengths:** Significantly reduces variance compared to uniform sampling, especially for degenerate distributions [S1, unofficial]. Unbiased estimate [S1, unofficial].
- **Limitations:** Requires knowledge of the interval $[t_n, t_f]$ to define bins [S1, unofficial].

## Background
The Stratified Monte Carlo Radiance Estimate was introduced in the context of differentiable rendering with reparameterized volume sampling [S1, unofficial]. It builds on the idea that inverse transform sampling requires only a few points for degenerate distributions [S1, unofficial]. The method was compared against a baseline uniform sampling estimate, showing consistent variance reduction [S1, unofficial].
