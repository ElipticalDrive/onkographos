# Hierarchical Sampling

Also called: Coarse and Refined Stage Sampling, Coarse-to-Fine Sampling, Hierarchical Volume Sampling, Importance Sampling for NeRF, Two-Stage Sampling

## Overview
Hierarchical sampling is a two-stage sampling strategy used in neural volume rendering to improve rendering quality and efficiency by concentrating samples in regions of high geometric or radiance complexity [S1, unofficial][S2, unofficial][S4]. It solves the problem of inefficient uniform sampling, where many samples fall in empty space or smooth regions, by using a coarse network to estimate the density distribution and then importance-sampling along the ray based on that estimate [S2, unofficial][S4]. It sets itself apart from standard direct volume ray casting [19-direct-volume-ray-casting.md] by replacing uniform discretization with a learned, non-uniform probability density function (PDF) derived from a separate coarse model, and from [Neural volume rendering](1576-neural-volume-rendering.md) by explicitly decoupling the density estimation (coarse) from the final color prediction (fine) into two distinct passes [S1, unofficial][S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Camera ray $r(t) = \mathbf{o} + t\mathbf{d}$, near/far bounds $[t_n, t_f]$, coarse network $N_c$, fine network $N_f$, number of coarse samples $N_c$, number of fine samples $N_f$ [S2, unofficial].
*   **Outputs:** Final pixel color $C$ and accumulated opacity $\alpha$ [S4].

**Data Structures:**
*   **Coarse Samples:** A set of depths $t_c = \{t_{c,1}, \dots, t_{c,N_c}\}$ along the ray, typically generated via stratified sampling within the interval $[t_n, t_f]$ [S2, unofficial].
*   **Coarse Predictions:** For each $t_{c,i}$, the coarse network outputs density $\sigma_{c,i}$ and color $C_{c,i}$ [S1, unofficial][S2, unofficial].
*   **Weights:** Importance weights $w_{c,i}$ proportional to the expected contribution of each coarse segment, derived from $\sigma_{c,i}$ and the transmittance [S2, unofficial].
*   **Fine Samples:** A set of depths $t_{fine} = \{t_{f,1}, \dots, t_{f,N_f}\}$ sampled from the distribution defined by $w_{c,i}$ [S2, unofficial].

**Steps:**
1.  **Coarse Pass (Density Estimation):** Generate $N_c$ stratified samples $t_{c,i}$ along the ray segment $[t_n, t_f]$ [S2, unofficial]. For each $t_{c,i}$, query the coarse network $N_c$ to obtain density $\sigma_{c,i}$ and color $C_{c,i}$ [S1, unofficial][S2, unofficial]. Compute the weight $w_{c,i}$ for each sample using the volume rendering contribution formula:
    $$
    w_{c,i} = T_{c,i} \left( 1 - \exp\left(- \sigma_{c,i} \Delta t_i\right) \right)
    $$
    where $T_{c,i} = \exp\left(-\sum_{j=1}^{i-1} \sigma_{c,j} \Delta t_j\right)$ is the transmittance up to sample $i$, and $\Delta t_i$ is the distance between adjacent samples [S2, unofficial][S5, unofficial].
2.  **Importance Sampling (Fine Sample Generation):** Construct a cumulative distribution function (CDF) from the normalized coarse weights $w_{c,i}$ [S2, unofficial]. Sample $N_f$ new depths $t_{f,j}$ from this CDF [S2, unofficial]. This concentrates samples in regions where the coarse network predicted high density [S2, unofficial][S4]. **Pitfall:** The sampling step is non-differentiable with respect to the coarse model's output if gradients are intended to flow back to update the coarse model's density predictions; implementations detach the inputs to prevent this gradient flow [S2, unofficial].
3.  **Fine Pass (Color Prediction):** For each fine sample depth $t_{f,j}$, query the fine network $N_f$ to obtain density $\sigma_{f,j}$ and color $C_{f,j}$ [S1, unofficial][S2, unofficial]. Perform volume rendering compositing using the fine samples to compute the final pixel color $C$ and opacity $\alpha$ [S4].
4.  **Loss Calculation (Training):** The total loss sums the mean squared error (MSE) between the color rendered from the coarse samples and the ground truth, plus the MSE between the color rendered from the fine samples and the ground truth [S2, unofficial][S4].

**Parameters:**
*   $N_c$: Number of intervals in the coarse stage. Typical value: 64 [S4].
*   $N_f$: Number of intervals in the refined stage. Typical value: 128 [S4].

**Pseudocode:**
```python
import math
import random

def hierarchical_sample(ray_o, ray_d, t_n, t_f, coarse_net, fine_net, n_coarse=64, n_fine=128):
    """
    Perform hierarchical sampling for a single ray.
    Args:
        ray_o: Ray origin (3,)
        ray_d: Ray direction (3,)
        t_n: Near bound (float)
        t_f: Far bound (float)
        coarse_net: Coarse neural network callable(t, o, d) -> (sigma, color)
        fine_net: Fine neural network callable(t, o, d) -> (sigma, color)
        n_coarse: Number of coarse samples
        n_fine: Number of fine samples
    Returns:
        color: Rendered color (3,)
        alpha: Rendered opacity (float)
    """
    # 1. Coarse Pass: Stratified Sampling
    t_coarse = sorted([t_n + (i + random.uniform(0, 1)) * (t_f - t_n) / n_coarse for i in range(n_coarse)])
    sigma_coarse, color_coarse = coarse_net(t_coarse, ray_o, ray_d)
    
    # 2. Compute Coarse Weights for Importance Sampling
    deltas = [t_coarse[i+1] - t_coarse[i] for i in range(n_coarse - 1)]
    deltas.append(deltas[-1])  # [G] Handle boundary by repeating last interval
    alphas = [1.0 - math.exp(-s * dt) for s, dt in zip(sigma_coarse, deltas)]
    
    transmittances = [1.0]
    for a in alphas[:-1]:
        transmittances.append(transmittances[-1] * (1.0 - a))
        
    weights = [T * a for T, a in zip(transmittances, alphas)]
    total_w = sum(weights)
    pdf = [w / total_w for w in weights]
    
    # 3. Fine Pass: Importance Sampling
    # [G] Detach sampling from coarse network gradients during training
    t_fine = inverse_cdf_sample(pdf, t_coarse, n_fine)
    sigma_fine, color_fine = fine_net(t_fine, ray_o, ray_d)
    
    # 4. Volume Rendering with Fine Samples
    deltas_fine = [t_fine[i+1] - t_fine[i] for i in range(n_fine - 1)]
    deltas_fine.append(deltas_fine[-1])
    alphas_fine = [1.0 - math.exp(-s * dt) for s, dt in zip(sigma_fine, deltas_fine)]
    
    transmittances_fine = [1.0]
    for a in alphas_fine[:-1]:
        transmittances_fine.append(transmittances_fine[-1] * (1.0 - a))
        
    color = sum(T * a * c for T, a, c in zip(transmittances_fine, alphas_fine, color_fine))
    opacity = 1.0 - transmittances_fine[-1]
    
    return color, opacity

def inverse_cdf_sample(pdf, values, n_samples):
    """Sample indices from a 1D PDF using inverse transform sampling."""
    cdf = []
    acc = 0.0
    for p in pdf:
        acc += p
        cdf.append(acc)
    samples = []
    for _ in range(n_samples):
        u = random.uniform(0, 1)
        idx = 0
        while idx < len(cdf) - 1 and cdf[idx] < u:
            idx += 1
        samples.append(values[idx])
    return sorted(samples)
```

## Subtopics

### [Hierarchical Density Adaptation](4868-hierarchical-density-adaptation.md)
Hierarchical Density Adaptation is a sampling strategy for volume rendering that controls rendering density using a hierarchy of sampled data to maintain constant frame rates. It serves as an alternative to opacity-based adaptive sampling, trading image smoothness for rendering speed by controlling the total number of rendered primitives per frame. It distinguishes itself from standard hierarchical sampling by generating the coarse density estimate on-the-fly from the dense grid via convolution, rather than relying on a separate, pre-allocated coarse network or grid.

### DDNeRF
DDNeRF is a neural volume rendering method that improves sampling efficiency in hierarchical sampling by learning a continuous density distribution within each ray interval, rather than relying on a discrete piecewise-constant probability density function (PDF) [S1, unofficial]. It sets itself apart from [Hierarchical Sampling](4865-hierarchical-sampling.md) by replacing the discrete weight normalization with a parametric Gaussian distribution estimation [S1, unofficial].

### Hu et al. Density-based Sampling
Hu et al. Density-based Sampling is a method that evaluates the coarse NeRF MLP only at valid points (positive densities) and the fine network at pivotal points (densities exceeding a predefined threshold) [S7].

## Operating characteristics
*   **Time Complexity:** The method requires two forward passes through neural networks (coarse and fine) per ray, effectively doubling the network evaluation cost compared to a single-pass method [S4].
*   **Memory Complexity:** Requires storing the parameters for two networks and the intermediate predictions (density, color) for all $N_c + N_f$ samples [S4].
*   **Strengths:** Efficiently concentrates samples in complex regions (edges, high-frequency details), improving image quality per sample [S2, unofficial][S4].
*   **Limitations:** The non-differentiable sampling step requires careful gradient handling (detaching inputs) [S2, unofficial]. The two-stage process adds implementation complexity [S2, unofficial].
*   **When to use:** When rendering neural radiance fields or implicit representations where geometry is unknown and uniform sampling is inefficient [S1, unofficial][S2, unofficial][S4].
*   **When not to use:** When the volume data is explicit and uniform sampling is sufficient, or when hardware constraints prevent storing two networks [S1, unofficial][S2, unofficial].

## Background
Hierarchical sampling was introduced in the context of neural radiance fields to address the inefficiency of uniform sampling in large scenes [S1, unofficial][S2, unofficial]. It has since become a standard component in many neural rendering pipelines [S1, unofficial][S2, unofficial][S4].
