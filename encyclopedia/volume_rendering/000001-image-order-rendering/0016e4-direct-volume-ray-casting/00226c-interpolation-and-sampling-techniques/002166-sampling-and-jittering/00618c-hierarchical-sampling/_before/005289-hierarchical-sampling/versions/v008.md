# Hierarchical Sampling

Also called: Coarse and Refined Stage Sampling, Coarse-to-Fine Sampling, Two-Stage Sampling

## Overview
Hierarchical sampling is a two-stage strategy for volume rendering that improves image quality by concentrating samples in regions of high geometric or color complexity, thereby addressing the sensitivity of neural radiance fields to sparse initial sampling [S6, S3, unofficial]. It sets itself apart from uniform sampling by using a coarse network to estimate density and guide importance sampling for a fine network, and from [Hierarchical Sampling (Inverse CDF Sampling)](973-hierarchical-sampling-inverse-cdf-sampling.md) by explicitly defining the coarse-to-fine pipeline as the primary mechanism for efficiency, often implemented via the inverse-CDF of coarse weights [S3, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Ray origin $\mathbf{o}$ and direction $\mathbf{d}$, near/far bounds $[t_n, t_f]$, number of coarse samples $N_{coarse}$, number of fine samples $N_{fine}$, coarse neural network $f_c$, fine neural network $f_f$.
*   **Outputs:** Rendered color $\hat{C}(\mathbf{r})$ and depth/transmittance for the ray $\mathbf{r}$.

**Data Structures:**
*   **Sample Depths:** Arrays of size $N_{coarse}$ and $N_{fine}$ storing scalar distances $t$ along the ray.
*   **Density/Color:** Tensors of shape $(N, 4)$ or $(N, 3)$ storing volume density $\sigma$ and color $\mathbf{c}$ for each sample point.
*   **CDF:** Cumulative distribution array of size $N_{coarse}$, normalized to $[0, 1]$.

**Parameters:**
*   $N_{coarse}$: Number of coarse samples. Typical value: 64 [S1, S5].
*   $N_{fine}$: Number of fine samples. Typical value: 64 [S1] or 128 [S3, unofficial][S5].
*   Learning Rate: Typically $5 \times 10^{-4}$ or $10^{-4}$ [S1, S5].

**Steps:**

1.  **Coarse Sampling:** Uniformly (or stratified) sample $N_{coarse}$ points along the ray interval $[t_n, t_f]$. Let these depths be $t_c = \{t_{c,1}, \dots, t_{c,N_{coarse}}\}$ [S1, S5].
2.  **Coarse Pass:** Evaluate the coarse network $f_c$ at each $t_{c,i}$ to predict volume density $\sigma_c$ and color $\mathbf{c}_c$ [S2, S3, unofficial].
3.  **Weight Computation:** Compute the weight $w_i$ for each coarse sample, representing its expected color contribution [S6, S3, unofficial]:
    $$ w_i = T_c(t_{c,i}) \left( 1 - \exp\left(- \sigma_c(t_{c,i}) \Delta t_{c,i}\right) \right) $$
    where $T_c(t_{c,i}) = \exp\left(-\sum_{j=1}^{i-1} \sigma_c(t_{c,j}) \Delta t_{c,j}\right)$ is the transmittance up to sample $i$, and $\Delta t_{c,i} = t_{c,i+1} - t_{c,i}$ is the interval length [S3, S6, unofficial]. Note: For the last sample, $\Delta t$ is often handled by assuming the ray continues or using the distance to $t_f$.
4.  **CDF Construction:** Construct the cumulative distribution function (CDF) from the weights $w_i$. Normalize weights so $\sum w_i = 1$ if necessary, then compute $CDF_i = \sum_{j=1}^{i} w_j$ [S3, unofficial].
5.  **Fine Sampling (Importance Sampling):** Sample $N_{fine}$ points from the CDF. This is typically done by generating $N_{fine}$ uniform random numbers $u \in [0, 1]$ and finding the corresponding $t$ values via inverse lookup or interpolation on the CDF [S3, unofficial]. Let these depths be $t_f = \{t_{f,1}, \dots, t_{f,N_{fine}}\}$ [S1][S3, unofficial].
6.  **Fine Pass:** Evaluate the fine network $f_f$ at each $t_{f,i}$ to predict density $\sigma_f$ and color $\mathbf{c}_f$ [S2, S6, unofficial].
7.  **Rendering:** Combine coarse and fine samples (often by concatenating and sorting them by depth) and perform volume rendering integration [S3, S7, unofficial].

**Pseudocode:**

```python
import torch
import torch.nn.functional as F

def hierarchical_sample(ray_origins, ray_directions, t_near, t_far, 
                        n_coarse, n_fine, coarse_net, fine_net):
    """
    Performs hierarchical sampling for a batch of rays.
    
    Args:
        ray_origins: (B, 3) Tensor of ray origins.
        ray_directions: (B, 3) Tensor of ray directions (normalized).
        t_near: (B,) Tensor of near bounds.
        t_far: (B,) Tensor of far bounds.
        n_coarse: int, number of coarse samples.
        n_fine: int, number of fine samples.
        coarse_net: Module, coarse neural network.
        fine_net: Module, fine neural network.
        
    Returns:
        t_coarse: (B, n_coarse) Tensor of coarse sample depths.
        sigma_coarse: (B, n_coarse, 1) Tensor of coarse densities.
        c_coarse: (B, n_coarse, 3) Tensor of coarse colors.
        t_fine: (B, n_fine) Tensor of fine sample depths.
        sigma_fine: (B, n_fine, 1) Tensor of fine densities.
        c_fine: (B, n_fine, 3) Tensor of fine colors.
    """
    B = ray_origins.shape[0]
    
    # 1. Coarse Sampling: Uniform stratified sampling
    # Generate uniform samples in [0, 1]
    u_coarse = torch.linspace(0, 1, n_coarse, device=ray_origins.device).unsqueeze(0) # (1, n_coarse)
    # Add stratification noise
    noise = torch.rand(B, n_coarse, device=ray_origins.device)
    u_coarse = u_coarse + noise / n_coarse
    u_coarse = torch.clamp(u_coarse, 0, 1)
    
    # Map to t space
    t_coarse = t_near.unsqueeze(1) + u_coarse * (t_far.unsqueeze(1) - t_near.unsqueeze(1)) # (B, n_coarse)
    
    # Get 3D points
    pts_coarse = ray_origins.unsqueeze(1) + t_coarse.unsqueeze(2) * ray_directions.unsqueeze(1) # (B, n_coarse, 3)
    
    # 2. Coarse Pass
    # coarse_net expects (B*N, 3) or similar, assuming it handles positional encoding internally
    # Flatten for network input if necessary, then reshape
    pts_coarse_flat = pts_coarse.view(-1, 3)
    sigma_coarse_flat, c_coarse_flat = coarse_net(pts_coarse_flat)
    sigma_coarse = sigma_coarse_flat.view(B, n_coarse, 1) # (B, n_coarse, 1)
    c_coarse = c_coarse_flat.view(B, n_coarse, 3) # (B, n_coarse, 3)
    
    # 3. Weight Computation
    # Calculate intervals
    dt_coarse = torch.diff(t_coarse, dim=1, prepend=torch.zeros(B, 1, device=t_coarse.device)) # (B, n_coarse)
    # Transmittance T_i = exp(-sum_{j<i} sigma_j * dt_j)
    # We can use cumulative sum of sigma * dt
    alpha_dt_coarse = sigma_coarse.squeeze(2) * dt_coarse # (B, n_coarse)
    cum_alpha_coarse = torch.cumsum(alpha_dt_coarse, dim=1) # (B, n_coarse)
    T_coarse = torch.exp(-torch.cat([torch.zeros(B, 1, device=t_coarse.device), cum_alpha_coarse[:, :-1]], dim=1)) # (B, n_coarse)
    
    # Weight w_i = T_i * (1 - exp(-sigma_i * dt_i))
    # Note: sigma_coarse is (B, n_coarse, 1), need to squeeze for element-wise ops if dt is (B, n_coarse)
    sigma_squeezed = sigma_coarse.squeeze(2)
    weights_coarse = T_coarse * (1 - torch.exp(-sigma_squeezed * dt_coarse)) # (B, n_coarse)
    
    # 4. CDF Construction
    # Normalize weights to sum to 1 for each ray
    weights_sum = weights_coarse.sum(dim=1, keepdim=True) + 1e-10 # (B, 1)
    weights_norm = weights_coarse / weights_sum # (B, n_coarse)
    cdf_coarse = torch.cumsum(weights_norm, dim=1) # (B, n_coarse)
    
    # 5. Fine Sampling: Inverse CDF sampling
    u_fine = torch.rand(B, n_fine, device=ray_origins.device) # (B, n_fine)
    
    # Find indices in CDF
    # We want to find i such that cdf[i-1] < u <= cdf[i]
    # torch.searchsorted is efficient
    indices = torch.searchsorted(cdf_coarse, u_fine, right=True) # (B, n_fine)
    indices = torch.clamp(indices, 0, n_coarse - 1)
    
    # Interpolate t values
    # Get lower and upper bounds for interpolation
    lower_indices = indices - 1
    lower_indices = torch.clamp(lower_indices, 0, n_coarse - 1)
    
    # CDF values at indices
    cdf_lower = torch.gather(cdf_coarse, 1, lower_indices) # (B, n_fine)
    cdf_upper = torch.gather(cdf_coarse, 1, indices) # (B, n_fine)
    
    # T values for interpolation
    t_lower = torch.gather(t_coarse, 1, lower_indices) # (B, n_fine)
    t_upper = torch.gather(t_coarse, 1, indices) # (B, n_fine)
    
    # Linear interpolation
    # t_fine = t_lower + (t_upper - t_lower) * (u - cdf_lower) / (cdf_upper - cdf_lower)
    # Handle division by zero if cdf_lower == cdf_upper
    denom = cdf_upper - cdf_lower + 1e-10
    t_fine = t_lower + (t_upper - t_lower) * (u_fine - cdf_lower) / denom # (B, n_fine)
    
    # Get 3D points for fine samples
    pts_fine = ray_origins.unsqueeze(1) + t_fine.unsqueeze(2) * ray_directions.unsqueeze(1) # (B, n_fine, 3)
    
    # 6. Fine Pass
    pts_fine_flat = pts_fine.view(-1, 3)
    sigma_fine_flat, c_fine_flat = fine_net(pts_fine_flat)
    sigma_fine = sigma_fine_flat.view(B, n_fine, 1) # (B, n_fine, 1)
    c_fine = c_fine_flat.view(B, n_fine, 3) # (B, n_fine, 3)
    
    return t_coarse, sigma_coarse, c_coarse, t_fine, sigma_fine, c_fine
```

**Edge Cases and Pitfalls:**
*   **Gradient Flow:** The sampling step (inverse CDF lookup) is non-differentiable with respect to the coarse model's output. To prevent gradients from flowing back through the sampling operation to update the coarse network's density predictions based on the fine sampling, the inputs to the sampling function must be detached from the coarse network's computation graph [S3, unofficial].
*   **Degenerate CDF:** If all coarse weights are zero (e.g., empty space), the CDF is flat. The inverse sampling will return uniform samples, which is acceptable but provides no refinement benefit [G].
*   **Boundary Conditions:** The last interval $\Delta t$ for the coarse samples must be handled carefully, as there is no subsequent sample. A common approach is to assume the ray continues to $t_f$ or use the distance to the next logical boundary [G].

## Subtopics

### [Hierarchical Density Adaptation](4868-hierarchical-density-adaptation.md)
Controls rendering density using a hierarchy of sampled data to maintain constant frame rates, generating coarse density estimates on-the-fly via convolution rather than a separate pre-allocated grid.

### [Hu et al. Density-based Sampling](7323-hu-et-al-density-based-sampling.md)
Restricts fine network evaluation to regions of significant geometric presence using a fixed density threshold, skipping empty space entirely.

### [DDNeRF](8860-ddnerf.md)
Improves sampling efficiency by learning a continuous density distribution (mixture of truncated Gaussians) within each ray interval, replacing discrete weight normalization with parametric Gaussian estimation.

## Operating characteristics
*   **Time Complexity:** $O(N_{coarse} + N_{fine})$ network evaluations per ray. The inverse CDF sampling adds $O(N_{coarse} \log N_{coarse})$ or $O(N_{coarse})$ depending on implementation, but is negligible compared to network inference.
*   **Memory Complexity:** $O(N_{coarse} + N_{fine})$ per ray for storing sample positions, densities, and colors.
*   **Measured Performance:** In NeRF-like settings, using $N_{coarse}=64$ and $N_{fine}=64-128$ provides a significant quality improvement over uniform sampling with similar total sample counts, or allows for higher quality with the same computational budget [S1, S5].
*   **Strengths:** Efficiently allocates samples to complex regions, reducing noise and aliasing in detailed areas while maintaining speed in smooth regions [S4][S6, unofficial].
*   **Limitations:** Requires two network passes (coarse and fine), increasing latency per ray. The quality of the fine sampling is dependent on the accuracy of the coarse network's density predictions [S6, unofficial].
*   **When to Use:** When rendering scenes with high-frequency details or varying opacity, and computational resources allow for two network evaluations per ray.
*   **When Not to Use:** In real-time applications with strict latency constraints where a single network pass is required, or in scenes with uniform density where uniform sampling is sufficient.

## Background
Hierarchical sampling was introduced as a core component of Neural Radiance Fields (NeRF) by Mildenhall et al. in 2020 [S3, S6, unofficial]. It was designed to address the issue that uniform sampling along rays is inefficient for scenes with complex geometry, as it wastes samples in empty space and under-samples detailed regions. The method builds on the idea of importance sampling, using a coarse estimate of the scene's density to guide the placement of finer samples. It has since become a standard technique in neural volume rendering and is used in many subsequent works, including [DDNeRF](8860-ddnerf.md) and [Hu et al. Density-based Sampling](7323-hu-et-al-density-based-sampling.md) [S1][S2, unofficial].
