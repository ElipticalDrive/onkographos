# Hierarchical Volume Sampling
Also called: Coarse and fine sampling, Two-Stage Sampling

## Overview
Hierarchical volume sampling is an importance sampling strategy for direct volume ray casting that reduces computational cost by concentrating samples in regions of high density. It differs from standard NeRF [S1, unofficial][S2] by using a single network for both coarse and fine stages [S1, unofficial], or by employing a compact 3D volume representation in the fine stage [S2].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Camera ray parameters (origin, direction), near/far clipping planes, coarse density predictions.
*   **Outputs:** Final pixel color and alpha.

**Data Structures:**
*   **Coarse Samples:** $N$ points uniformly distributed along the ray segment $[t_n, t_f]$.
*   **Fine Samples:** $M$ points distributed according to the probability density function (PDF) derived from coarse predictions.
*   **Fine Volume (MuRF specific):** A 3D tensor $z \in \mathbb{R}^{W/8 \times H/8 \times D \times C_{fine}}$, where $C_{fine}$ is the reduced channel dimension [S2].

**Steps:**
1.  **Coarse Sampling:** Uniformly sample $N$ points along the ray between the near and far planes [S1, unofficial][S2].
2.  **Coarse Prediction:** Query the coarse model (or single network) at these $N$ points to obtain density $\sigma_i$ and color $c_i$ [S1, unofficial][S2].
3.  **PDF Construction:** Compute the unnormalized weight $w_i$ for each sample using the volume rendering equation's opacity term [S2]:
    $$ w_i = \alpha_i \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    where $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$, $\delta_i$ is the distance between adjacent samples, and the product is 1 for $i=1$ [S2].
    Normalize these weights to form the PDF $p_i$:
    $$ p_i = \frac{w_i}{\sum_{k=1}^{N} w_k} $$
4.  **Importance Sampling:** Sample $M$ new points along the ray according to the distribution $p_i$ [S1, unofficial][S2].
5.  **Fine Prediction:**
    *   *Single Network (StyleNeRF):* Query the same network at the $M$ fine points to get density and color [S1, unofficial].
    *   *Compact Volume (MuRF):* Construct a target view frustum volume at full resolution but with reduced channel dimension ($C_{fine} = 16$ vs coarse $128$) [S2]. Use a lightweight 3D U-Net to predict color and density from this compact volume [S2].
6.  **Final Rendering:** Composite the fine samples using the volume rendering equation to produce the final color [S1, unofficial][S2].

**Parameters:**
*   $N$ (coarse samples): 64 [S2].
*   $M$ (fine samples): 16 [S2].
*   Coarse channel dimension: 128 [S2].
*   Fine channel dimension: 16 [S2].

**Edge Cases:**
*   If all coarse densities are zero, the PDF is uniform, and fine sampling degrades to uniform sampling [S2].
*   Precision issues in $\alpha_i$ calculation when $\sigma_i \delta_i$ is very large or very small [G].

**Pseudocode:**
```python
def hierarchical_volume_sampling(ray_origin, ray_direction, near, far, coarse_model, fine_model, N=64, M=16):
    # Step 1: Coarse Uniform Sampling
    t_coarse = linspace(near, far, N)
    points_coarse = ray_origin + t_coarse[:, None] * ray_direction
    
    # Step 2: Coarse Prediction
    # Returns density sigma and color c for each point
    sigma_coarse, c_coarse = coarse_model(points_coarse)
    
    # Step 3: PDF Construction
    # Calculate alpha and weights
    # delta is distance between samples; assume uniform spacing for simplicity
    delta = t_coarse[1] - t_coarse[0]
    alpha = 1.0 - exp(-sigma_coarse * delta)
    
    # Accumulate transmittance T_i = product(1 - alpha_j) for j < i
    T = ones(N)
    for i in range(1, N):
        T[i] = T[i-1] * (1.0 - alpha[i-1])
        
    # Unnormalized weights
    w = T * alpha
    
    # Normalize to PDF
    pdf = w / sum(w)
    
    # Step 4: Importance Sampling
    # Sample M indices based on pdf
    indices = sample_with_replacement(N, pdf, M)
    t_fine = t_coarse[indices]
    # Add small jitter or interpolate if needed, but sources imply discrete selection
    points_fine = ray_origin + t_fine[:, None] * ray_direction
    
    # Step 5: Fine Prediction
    # Option A: Single Network (StyleNeRF)
    sigma_fine, c_fine = coarse_model(points_fine)
    
    # Option B: Compact Volume (MuRF) - Not fully detailed in sources, marked [G]
    # if use_compact_volume:
    #     volume_tensor = construct_frustum_volume(points_fine, coarse_features)
    #     sigma_fine, c_fine = fine_model(volume_tensor)
    
    # Step 6: Final Rendering
    # Recalculate alpha for fine samples
    alpha_fine = 1.0 - exp(-sigma_fine * delta)
    
    # Recalculate T for fine samples (assuming sorted t_fine)
    T_fine = ones(M)
    for i in range(1, M):
        T_fine[i] = T_fine[i-1] * (1.0 - alpha_fine[i-1])
        
    final_color = sum(T_fine * alpha_fine * c_fine)
    return final_color
```

## Operating characteristics
*   **Time Complexity:** $O(N + M)$ per ray, where $N$ is coarse samples and $M$ is fine samples. Typically $N \gg M$ (e.g., 64 vs 16) [S2].
*   **Memory Complexity:** Reduced in the fine stage if a compact volume is used (channel dim 128 $\to$ 16) [S2].
*   **Strengths:** Removes empty space and occluded regions, allowing fewer samples for similar quality [S2]. Single-network approach reduces memory footprint compared to two-network NeRF [S1, unofficial].
*   **Limitations:** Requires two passes (coarse then fine) [S1, unofficial][S2].

## Background
Originated in NeRF (Mildenhall et al., 2020) [S1, unofficial][S2]. Adopted by StyleNeRF using a single network [S1, unofficial] and by MuRF using a compact 3D U-Net [S2].
