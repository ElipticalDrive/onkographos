# Hierarchical Sampling

Also called: Coarse-to-Fine Sampling, Importance Sampling for NeRF, Two-Stage Sampling

## Overview
Hierarchical sampling is a two-stage sampling strategy for neural volume rendering that uses a coarse neural network to estimate geometry and guide the placement of fine samples via importance sampling [S1, S2, S4, unofficial]. It solves the problem of inefficient uniform sampling by concentrating computational effort on regions of high opacity or color change, thereby improving reconstruction quality and rendering efficiency compared to single-stage stratified sampling [S2, unofficial][S3]. Unlike [NeRF Volumetric Rendering (Coarse/Fine Sampling)](979-nerf-volumetric-rendering-coarse-fine-sampling.md) which typically trains two networks jointly with a specific loss weighting, this method focuses on the sampling mechanism itself, where the coarse pass generates a probability distribution for the fine pass [S2, S4, unofficial].

## How it works
**Inputs:**
*   Ray $r(t) = \mathbf{o} + t\mathbf{d}$ defined by origin $\mathbf{o}$ and direction $\mathbf{d}$.
*   Near and far bounds $[t_{start}, t_{end}]$ [S1, S4, unofficial].
*   Coarse neural network $f_c$ (MLP) predicting raw density $\sigma_c$ [S1, S2, unofficial].
*   Fine neural network $f_f$ (MLP) predicting raw density $\sigma_f$ and color $\mathbf{c}_f$ [S1, S2, unofficial].
*   Number of coarse samples $N_c$ and fine samples $N_f$ [S2, unofficial].

**Outputs:**
*   Final pixel color $C$ [S1, unofficial].
*   Gradients for network weights [S1, S2, unofficial].

**Data Structures:**
*   **Sample Depths:** Array of floats $t$ of size $N_c$ or $N_f$.
*   **CDF:** Array of floats of size $N_c$, representing the cumulative distribution function derived from coarse weights.

**Steps:**

1.  **Coarse Pass:**
    1.  Generate $N_c$ sample depths $t_c$ uniformly or via stratified sampling within $[t_{start}, t_{end}]$ [S2, unofficial][S3].
    2.  For each $t_c^{(i)}$, query the coarse network $f_c$ to obtain raw density $\sigma_c^{(i)}$ [S1, S2, unofficial].
    3.  Compute segment lengths $\delta_i = t_c^{(i+1)} - t_c^{(i)}$ (with $\delta_0 = t_c^{(1)} - t_{start}$ and $\delta_{N_c-1} = t_{end} - t_c^{(N_c-1)}$) [S1, S14, unofficial].
    4.  Compute opacity $\alpha_c^{(i)} = 1 - \exp(-\sigma_c^{(i)} \cdot \delta_i)$ [S1, S14, unofficial].
    5.  Compute transmittance $T_c^{(i)} = \exp(-\sum_{j=1}^{i-1} \sigma_c^{(j)} \delta_j)$ [S1, S14, unofficial].
    6.  Compute weights $w_c^{(i)} = T_c^{(i)} \alpha_c^{(i)}$ [S2, unofficial].

2.  **Importance Sampling Construction:**
    1.  Normalize weights to form a probability mass function: $p_c^{(i)} = w_c^{(i)} / \sum_{j=1}^{N_c} w_c^{(j)}$ [S2, unofficial].
    2.  Construct the Cumulative Distribution Function (CDF) $F_c$ where $F_c^{(i)} = \sum_{j=1}^{i} p_c^{(j)}$ [S2, unofficial].
    3.  [G] Handle degenerate case where all weights are zero (empty space) by falling back to uniform sampling or skipping fine pass.

3.  **Fine Pass Sampling:**
    1.  Generate $N_f$ uniform random numbers $u \sim \mathcal{U}(0, 1)$ [S2, unofficial].
    2.  For each $u$, find the interval $[F_c^{(k)}, F_c^{(k+1)}]$ containing $u$ using binary search or linear scan [S2, unofficial].
    3.  Interpolate within the interval to determine the new sample depth $t_f$ proportional to the segment length $\delta_k$ [S2, unofficial].
        *   Formula: $t_f = t_c^{(k)} + (t_c^{(k+1)} - t_c^{(k)}) \cdot \frac{u - F_c^{(k)}}{F_c^{(k+1)} - F_c^{(k)}}$ [S2, G, unofficial].
        *   [G] For the first and last intervals, clamp or extend bounds appropriately to cover $[t_{start}, t_{end}]$.

4.  **Fine Pass Rendering:**
    1.  Query the fine network $f_f$ at each $t_f^{(j)}$ to get $\sigma_f^{(j)}$ and $\mathbf{c}_f^{(j)}$ [S1, S2, unofficial].
    2.  Compute $\alpha_f^{(j)} = 1 - \exp(-\sigma_f^{(j)} \cdot \delta_f^{(j)})$ where $\delta_f$ is the distance between adjacent fine samples (or distance to coarse samples if using hybrid compositing) [S1, S14, unofficial].
    3.  Composite colors using front-to-back compositing:
        $$ C = \sum_{j=1}^{N_f} T_f^{(j)} \alpha_f^{(j)} \mathbf{c}_f^{(j)}, \quad T_f^{(j)} = \exp\left(-\sum_{m=1}^{j-1} \sigma_f^{(m)} \delta_f^{(m)}\right) $$
        [S1, S14, unofficial].

5.  **Loss Computation:**
    *   Total Loss = MSE(coarse prediction) + MSE(fine prediction) [S2, unofficial].
    *   [G] In practice, the coarse loss is often weighted less or used only for gradient flow to the coarse network, while the fine loss drives the final image quality.

**Pseudocode:**

```python
import torch
import math

def hierarchical_sample_and_render(ray_o, ray_d, t_start, t_end, 
                                   n_coarse, n_fine, 
                                   coarse_mlp, fine_mlp):
    """
    Performs hierarchical sampling and rendering for a single ray.
    
    Args:
        ray_o: (3,) Tensor, ray origin.
        ray_d: (3,) Tensor, ray direction.
        t_start: float, near bound.
        t_end: float, far bound.
        n_coarse: int, number of coarse samples.
        n_fine: int, number of fine samples.
        coarse_mlp: Module, coarse network.
        fine_mlp: Module, fine network.
        
    Returns:
        color: (3,) Tensor, final pixel color.
    """
    # 1. Coarse Sampling
    # Stratified sampling for coarse points
    t_coarse = stratified_sample(t_start, t_end, n_coarse)
    
    # Query coarse network
    # Points shape: (n_coarse, 3)
    points_coarse = ray_o.unsqueeze(0) + t_coarse.unsqueeze(1) * ray_d.unsqueeze(0)
    
    # Get raw density from coarse MLP
    # sigma_coarse shape: (n_coarse, 1)
    sigma_coarse = coarse_mlp(points_coarse).squeeze(1)
    
    # 2. Compute Coarse Weights for Importance Sampling
    # Compute segment lengths
    deltas_coarse = torch.zeros_like(t_coarse)
    deltas_coarse[0] = t_coarse[0] - t_start
    deltas_coarse[-1] = t_end - t_coarse[-1]
    deltas_coarse[1:-1] = t_coarse[1:] - t_coarse[:-1]
    
    # Compute opacity and transmittance
    alpha_coarse = 1.0 - torch.exp(-sigma_coarse * deltas_coarse)
    # Cumulative sum of sigma * delta for transmittance
    # T[i] = exp(-sum_{j=0}^{i-1} sigma[j] * delta[j])
    sigma_delta_coarse = sigma_coarse * deltas_coarse
    cum_sigma_delta = torch.cumsum(sigma_delta_coarse, dim=0)
    # Shift cum_sigma_delta to the right by 1, fill with 0 at start
    T_coarse = torch.exp(torch.cat([torch.zeros(1, device=sigma_coarse.device), cum_sigma_delta[:-1]]))
    
    # Weights w[i] = T[i] * alpha[i]
    weights_coarse = T_coarse * alpha_coarse
    
    # 3. Construct CDF for Importance Sampling
    # Normalize weights to probabilities
    prob_coarse = weights_coarse / (weights_coarse.sum() + 1e-8)
    cdf_coarse = torch.cumsum(prob_coarse, dim=0)
    
    # 4. Fine Sampling via Inverse CDF
    # Generate uniform random numbers
    u_fine = torch.rand(n_fine, device=t_coarse.device)
    
    # Find indices in CDF
    # torch.searchsorted returns the index where u_fine would be inserted to maintain order
    # This gives us the bin index k such that cdf[k-1] <= u < cdf[k]
    indices = torch.searchsorted(cdf_coarse, u_fine)
    indices = torch.clamp(indices, 0, n_coarse - 1)
    
    # Get bounds for interpolation
    t_lower = torch.cat([torch.tensor([t_start], device=t_coarse.device), t_coarse[:-1]])
    t_upper = torch.cat([t_coarse[1:], torch.tensor([t_end], device=t_coarse.device)])
    
    # Get CDF bounds for interpolation
    cdf_lower = torch.cat([torch.tensor([0.0], device=cdf_coarse.device), cdf_coarse[:-1]])
    cdf_upper = cdf_coarse
    
    # Interpolate to get fine sample depths
    # t_fine = t_lower + (t_upper - t_lower) * (u - cdf_lower) / (cdf_upper - cdf_lower)
    # Handle division by zero if cdf_upper == cdf_lower (zero weight bin)
    denom = cdf_upper - cdf_lower
    denom = torch.where(denom > 1e-8, denom, torch.ones_like(denom))
    
    t_fine = t_lower + (t_upper - t_lower) * (u_fine - cdf_lower) / denom
    
    # 5. Fine Rendering
    points_fine = ray_o.unsqueeze(0) + t_fine.unsqueeze(1) * ray_d.unsqueeze(0)
    sigma_fine, color_fine = fine_mlp(points_fine) # Assuming MLP returns sigma and color
    
    # Compute fine deltas (distance between fine samples)
    deltas_fine = torch.zeros_like(t_fine)
    deltas_fine[0] = t_fine[0] - t_start
    deltas_fine[-1] = t_end - t_fine[-1]
    deltas_fine[1:-1] = t_fine[1:] - t_fine[:-1]
    
    alpha_fine = 1.0 - torch.exp(-sigma_fine * deltas_fine)
    sigma_delta_fine = sigma_fine * deltas_fine
    cum_sigma_delta_fine = torch.cumsum(sigma_delta_fine, dim=0)
    T_fine = torch.exp(torch.cat([torch.zeros(1, device=sigma_fine.device), cum_sigma_delta_fine[:-1]]))
    
    # Composite
    weights_fine = T_fine * alpha_fine
    color = torch.sum(weights_fine.unsqueeze(1) * color_fine, dim=0)
    
    return color

def stratified_sample(t_start, t_end, n_samples):
    """Generates stratified samples along a ray segment."""
    # Uniform stratified sampling
    ts = torch.linspace(t_start, t_end, n_samples + 1)
    # Add noise within each interval
    noise = torch.rand(n_samples + 1) * (t_end - t_start) / n_samples
    ts = ts[:-1] + noise
    return ts
```

**Parameters:**
*   $N_c$: Number of coarse samples. Typical value: 64 [S2, unofficial].
*   $N_f$: Number of fine samples. Typical value: 128 [S2, unofficial].
*   $t_{start}, t_{end}$: Near and far clipping planes.

**Edge Cases and Pitfalls:**
*   **Non-differentiability:** The sampling step (inverse CDF) is non-differentiable with respect to the coarse model's output. Gradients must not flow back through the sampling operation to the coarse network's density predictions if the coarse network is being trained jointly via the fine loss. The implementation detaches the inputs to the sampling function or uses straight-through estimators if necessary [S2, unofficial].
*   **Zero Density:** If the coarse network predicts zero density everywhere, the weights are zero, and the CDF is flat. Importance sampling fails. Fallback to uniform sampling is required [G].
*   **Precision:** Floating-point precision issues in CDF construction can lead to sampling artifacts in very thin structures [S3].

## Subtopics

### [Hierarchical Density Adaptation](4868-hierarchical-density-adaptation.md)
Hierarchical Density Adaptation is a sampling strategy for direct volume ray casting that generates a coarse density estimate from a dense feature grid on the fly to guide importance sampling for fine samples [4868-hierarchical-density-adaptation.md]. It solves the problem of missing thin or high-frequency surface details when sampling directly from a dense grid, which can occur if coarse sample points fall between grid cells containing significant geometry. Unlike sibling methods that maintain a dedicated, pre-computed coarse grid or train a separate coarse network, this method derives the coarse density by convolving the existing dense density grid with a non-learnable kernel, thereby avoiding additional memory allocation for coarse structures while ensuring robust surface detection [4868-hierarchical-density-adaptation.md].

#### Hu et al. Density-based Sampling
A method that evaluates the coarse NeRF MLP only at valid points (positive densities) and the fine network at pivotal points (densities exceeding a predefined threshold) [S5]. This optimizes computation by skipping zero-density regions for the coarse pass and focusing fine resources on significant geometry [S5].

## Operating characteristics
*   **Time Complexity:** $O(N_c + N_f)$ per ray, where $N_c$ and $N_f$ are the number of coarse and fine samples. The overhead of constructing the CDF is $O(N_c \log N_c)$ or $O(N_c)$ with linear search.
*   **Memory Complexity:** $O(N_c)$ to store coarse samples, weights, and CDF.
*   **Performance:** Achieves 2-3x efficiency gains over uniform sampling without aliasing artifacts in boundary-heavy volumes [S3].
*   **Strengths:** Efficiently concentrates samples in high-opacity regions, improving detail preservation [S3].
*   **Limitations:** Requires two network queries per ray (coarse and fine). The non-differentiable sampling step complicates joint training if gradients are needed for the coarse network from the fine loss [S2, unofficial].
*   **When to use:** When rendering scenes with complex geometry or high-frequency details where uniform sampling is inefficient.
*   **When not to use:** For simple, smooth volumes where uniform sampling is sufficient, or when memory is extremely constrained (due to storing CDF).

## Background
Hierarchical sampling was introduced in the context of Neural Radiance Fields (NeRF) to address the inefficiency of uniform sampling [S1, S2, unofficial]. The original NeRF paper proposed a two-stage process with a coarse and fine network, using importance sampling based on the coarse density distribution [S1, S2, unofficial]. This approach has since become a standard technique in neural volume rendering [S4, unofficial]. Variants like Hu et al.'s density-based sampling further optimize this by focusing evaluations on significant geometry [S5].
