# Hierarchical Sampling (Inverse CDF Sampling)

Also called: Inverse CDF Sampling

## Overview
Hierarchical Sampling (Inverse CDF Sampling) generates importance samples along a ray in volume rendering by inverting the cumulative distribution function (CDF) of a discrete probability distribution derived from per-bin weights [S1, S2, unofficial]. It solves the problem of inefficient uniform sampling by concentrating samples in high-contribution regions while spreading them in empty or occluded areas [S1, S5, unofficial]. Unlike [Uniform Ray Sampling](1261-uniform-ray-sampling.md), which treats all depth intervals equally, this method uses the probability density function (PDF) to guide sample placement, reducing variance in the final image [S3, S5, unofficial]. It serves as the core sampling mechanism in hierarchical rendering pipelines, where coarse samples inform the weights for fine sampling [S1, S3, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   `weights`: A 2D tensor of unnormalized weights per bin, shape `(batch_size, num_bins)` [S1, unofficial].
    *   `bins`: A 1D tensor of bin boundaries along the ray, shape `(num_bins + 1,)` [S1, unofficial]. These define the spatial intervals $[z_i, z_{i+1}]$ [S1, unofficial].
    *   `N_samples`: Integer specifying the number of samples to draw per ray [S1, unofficial].
    *   `det`: Boolean flag. If `True`, uses deterministic linearly spaced samples instead of random uniform samples [S1, unofficial].
    *   `perturb`: Float controlling jittering. $0$ disables jittering (deterministic midpoints), $1$ enables full stratified jittering [S1, unofficial].
*   **Outputs:**
    *   `samples`: A tensor of sampled depth positions along the ray, shape `(batch_size, N_samples)` [S1, unofficial].

**Data Structures:**
*   **Weights:** Unnormalized scalar values per bin. Must be non-negative.
*   **Bins:** Monotonically increasing depth values defining the interval boundaries.
*   **CDF:** Cumulative sum of the normalized PDF, prepended with a zero to define the lower bound of the first bin.

**Steps:**

1.  **Add Epsilon to Weights:** Add a small constant $\epsilon = 10^{-5}$ to all weights to prevent division by zero during normalization and ensure non-zero probabilities [S1, S2, S3, S4, S5, unofficial].
    $$ w' = w + \epsilon $$
2.  **Compute PDF:** Normalize the weights along the last dimension (bins) to obtain the Probability Density Function (PDF) [S1, S2, S3, S4, S5, unofficial].
    $$ \text{pdf}_i = \frac{w'_i}{\sum_{j} w'_j} $$
3.  **Compute CDF:** Compute the cumulative sum of the PDF and prepend a zero tensor to represent the start of the first bin [S1, S2, S3, S4, S5, unofficial].
    $$ \text{cdf}_0 = 0 $$
    $$ \text{cdf}_i = \text{cdf}_{i-1} + \text{pdf}_{i-1} \quad \text{for } i > 0 $$
4.  **Generate Query Values:** Generate $N_{samples}$ query values $u$ in the range $[0, 1]$ [S1, S2, S3, S4, S5, unofficial].
    *   If `det` is `True`, use linearly spaced values: $u_k = \frac{k}{N_{samples}}$ for $k=0 \dots N_{samples}-1$ [S1, S3, unofficial].
    *   If `det` is `False`, use uniform random numbers: $u_k \sim \mathcal{U}(0, 1)$ [S1, S2, S3, S5, unofficial].
5.  **Find Bin Indices:** Use binary search (`searchsorted`) to find the indices in the CDF where each $u$ falls [S1, S2, S3, S4, S5, unofficial].
    $$ \text{inds}_k = \text{searchsorted}(\text{cdf}, u_k, \text{side}=\text{'right'}) $$
6.  **Determine Bin Boundaries:** Identify the lower (`below`) and upper (`above`) bin indices for interpolation, clamping them to valid ranges [S1, S2, S3, S4, S5, unofficial].
    $$ \text{below}_k = \max(0, \text{inds}_k - 1) $$
    $$ \text{above}_k = \min(\text{cdf.shape}[-1] - 1, \text{inds}_k) $$
7.  **Gather CDF and Bin Values:** Gather the CDF values and bin boundaries corresponding to the `below` and `above` indices [S1, S2, S3, S4, S5, unofficial].
    $$ \text{cdf\_below}_k = \text{cdf}[\text{below}_k] $$
    $$ \text{cdf\_above}_k = \text{cdf}[\text{above}_k] $$
    $$ \text{bin\_below}_k = \text{bins}[\text{below}_k] $$
    $$ \text{bin\_above}_k = \text{bins}[\text{above}_k] $$
8.  **Compute Interpolation Factor:** Calculate the relative position $t$ within the bin using inverse CDF interpolation [S1, S2, S3, S4, S5, unofficial]. Handle division by zero by replacing the denominator with $1.0$ if it falls below $\epsilon$ [S1, S3, S5, unofficial].
    $$ \text{denom}_k = \text{cdf\_above}_k - \text{cdf\_below}_k $$
    $$ \text{denom}_k = \begin{cases} \text{denom}_k & \text{if } \text{denom}_k \ge 10^{-5} \\ 1.0 & \text{otherwise} \end{cases} $$
    $$ t_k = \frac{u_k - \text{cdf\_below}_k}{\text{denom}_k} $$
9.  **Interpolate Samples:** Map $t$ back to the actual depth range to get the final sample position [S1, S2, S3, S4, S5, unofficial].
    $$ \text{sample}_k = \text{bin\_below}_k + t_k \cdot (\text{bin\_above}_k - \text{bin\_below}_k) $$

**Pseudocode:**

```python
import torch

def hierarchical_sampling(weights, bins, N_samples, det=False):
    """
    Perform hierarchical sampling using inverse CDF interpolation.
    
    Args:
        weights: Tensor of shape (batch_size, num_bins), unnormalized weights.
        bins: Tensor of shape (num_bins + 1,), bin boundaries.
        N_samples: int, number of samples to draw.
        det: bool, if True use deterministic linspace, else random uniform.
        
    Returns:
        samples: Tensor of shape (batch_size, N_samples), sampled depths.
    """
    # 1. Add epsilon to prevent NaNs
    weights = weights + 1e-5
    
    # 2. Compute PDF
    pdf = weights / torch.sum(weights, dim=-1, keepdim=True)
    
    # 3. Compute CDF and prepend zero
    cdf = torch.cumsum(pdf, dim=-1)
    cdf = torch.cat([torch.zeros_like(cdf[..., :1]), cdf], dim=-1)
    
    # 4. Generate query values u
    if det:
        u = torch.linspace(0., 1., steps=N_samples, device=weights.device)
        u = u.expand(list(cdf.shape[:-1]) + [N_samples])
    else:
        u = torch.rand(list(cdf.shape[:-1]) + [N_samples], device=weights.device)
        
    # 5. Find indices in CDF
    inds = torch.searchsorted(cdf, u, right=True)
    
    # 6. Determine bin boundaries
    below = torch.max(torch.zeros_like(inds - 1), inds - 1)
    above = torch.min((cdf.shape[-1] - 1) * torch.ones_like(inds), inds)
    
    # 7. Stack indices for gathering
    inds_g = torch.stack([below, above], dim=-1)
    
    # 8. Gather CDF and bin values
    matched_shape = list(cdf.shape[:-1]) + [N_samples]
    cdf_g = torch.gather(cdf.unsqueeze(1).expand(matched_shape), 2, inds_g)
    bins_g = torch.gather(bins.unsqueeze(0).unsqueeze(0).expand(matched_shape), 2, inds_g)
    
    # 9. Compute interpolation factor
    denom = cdf_g[..., 1] - cdf_g[..., 0]
    denom = torch.where(denom < 1e-5, torch.ones_like(denom), denom)
    t = (u - cdf_g[..., 0]) / denom
    
    # 10. Interpolate samples
    samples = bins_g[..., 0] + t * (bins_g[..., 1] - bins_g[..., 0])
    
    return samples
```

**Edge Cases and Pitfalls:**
*   **Zero Weights:** If weights are zero, normalization causes division by zero. Adding $\epsilon$ prevents this [S1, S5, unofficial].
*   **Zero-Width Bins:** If bin boundaries are identical, the denominator in interpolation becomes zero. Clamping the denominator to $\epsilon$ prevents NaNs [S1, S5, unofficial].
*   **Out-of-Bounds Indices:** `searchsorted` may return indices equal to `num_bins` if $u=1$. Clamping `above` to `cdf.shape[-1] - 1` ensures valid indexing [S1, S2, S3, S4, S5, unofficial].

## Subtopics

### [Inverse Opacity Calculation](1099-inverse-opacity-calculation.md)
A differentiable method for generating importance samples along a ray by inverting the CDF of rendering contribution. It solves the problem of finding the ray parameter $t$ corresponding to a target cumulative density value $y$, allowing samples to be drawn directly from transmittance estimates rather than computing expensive integrals. Unlike standard NeRF hierarchical sampling, which interpolates exponentiated densities and requires auxiliary losses, this method interpolates the density field directly (piecewise linear or constant), offering better numerical stability for end-to-end optimization. It enables Monte Carlo estimates with fewer ray points and allows gradients to back-propagate through the sampling process to the density field parameters.

### [Proposal Network Sampling](1589-proposal-network-sampling.md)
A method for importance sampling that directly estimates the PDF along a ray using a coarse neural network, known as the proposal network. It solves the problem of inefficient uniform sampling by concentrating samples on high-contribution areas (such as surfaces) while spreading them in empty or occluded regions, providing more accurate transmittance estimation than spatial skipping methods. It builds on [Hierarchical Sampling (Inverse CDF Sampling)](973-hierarchical-sampling-inverse-cdf-sampling.md) by learning the sampling distribution dynamically rather than relying on static weights.

### [RangeFineSampler](3141-rangefinesampler.md)
A fine sampler that generates samples uniformly around the coarse sample with the maximum weight, within a specified range, and adds random samples across the full near-far range.

*   **Strengths:** Efficiently concentrates samples in high-contribution regions; differentiable, enabling gradient flow to density parameters [S1, unofficial]; simple to implement [S1, unofficial].
*   **Limitations:** Requires pre-computed weights (from a coarse pass or proposal network) [S1, unofficial]; performance degrades if weights are inaccurate [S1, unofficial]; numerical instability if not handled with epsilon [S1, S5, unofficial].
*   **When to Use:** When a coarse estimate of density/opacity is available and importance sampling is desired to reduce noise [S1, S5, unofficial].
*   **When Not to Use:** When no prior information about the scene is available (use [Uniform Ray Sampling](1261-uniform-ray-sampling.md) or [Stochastic Jittering](924-stochastic-jittering.md)); when computational budget is extremely tight and the overhead of computing weights is prohibitive [S1, unofficial].

## Background
Hierarchical sampling was introduced in the context of Neural Radiance Fields (NeRF) to improve the efficiency of volume rendering [S1, S2, unofficial]. The original NeRF paper by Mildenhall et al. used stratified sampling within intervals defined by a coarse network [S2, unofficial]. Later works, such as those by Drorke and others, refined this by explicitly using inverse CDF sampling on normalized weights to achieve importance sampling [S1, S3, unofficial].
