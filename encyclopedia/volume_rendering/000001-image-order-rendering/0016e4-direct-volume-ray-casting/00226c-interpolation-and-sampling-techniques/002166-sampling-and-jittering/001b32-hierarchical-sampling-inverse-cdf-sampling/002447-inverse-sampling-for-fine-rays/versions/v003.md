# Inverse Sampling for Fine Rays
Also called: FineSampler
## Overview
Inverse Sampling for Fine Rays is a hierarchical sampling technique that generates fine-grained sample positions along a ray using inverse transform sampling on coarse rendering weights [S2, unofficial]. It differs from [Inverse Opacity Calculation](1099-inverse-opacity-calculation.md) by constructing a discrete probability density function (PDF) from coarse weights rather than inverting accumulated opacity, and from [Proposal Network Sampling](1589-proposal-network-sampling.md) by using deterministic inverse CDF lookup instead of a learned network [S2, unofficial].
## How it works
**Inputs and Outputs:**
- Input: `z_vals` (coarse sample depths, shape `[B, Kc]`), `weights` (coarse rendering weights, shape `[B, Kc]`), `Kf` (total fine samples), `Kfd` (fine samples dedicated to depth/disparity), `n_coarse` (number of coarse samples, typically `Kc`) [S2, unofficial].
- Output: `z_fine` (fine sample depths, shape `[B, Kf - Kfd]`) [S2, unofficial].

**Data Structures:**
- `z_vals`: Tensor of depth values along the ray [S2, unofficial].
- `weights`: Tensor of unnormalized importance weights derived from the coarse pass [S2, unofficial].
- `cdf`: Cumulative distribution function tensor, shape `[B, Kc + 1]` after prepending zero [S2, unofficial].

**Steps:**
1. **Regularize Weights:** Add a small epsilon ($\epsilon = 10^{-5}$) to `weights` to prevent division by zero [S2, unofficial].
   $$ w'_i = w_i + \epsilon $$
2. **Compute PDF:** Normalize the regularized weights along the last dimension to obtain the PDF [S2, unofficial].
   $$ \text{pdf}_i = \frac{w'_i}{\sum_{j=0}^{Kc-1} w'_j} $$
3. **Compute CDF:** Compute the cumulative sum of the PDF [S2, unofficial].
   $$ \text{cdf}_i = \sum_{j=0}^{i} \text{pdf}_j $$
4. **Prepend Zero:** Prepend a zero to the CDF to handle the first interval correctly, resulting in a CDF of length $Kc + 1$ [S2, unofficial].
   $$ \text{cdf}_{\text{prepended}} = [0, \text{cdf}_0, \text{cdf}_1, \dots, \text{cdf}_{Kc-1}] $$
5. **Generate Uniform Samples:** Generate $B \times (K_f - K_{fd})$ uniform random numbers $u \sim \mathcal{U}(0, 1)$ [S2, unofficial].
6. **Inverse Transform (Search):** Use `searchsorted` to find the indices in the CDF corresponding to $u$, identifying which coarse bin each fine sample falls into [S2, unofficial].
   $$ \text{indices} = \text{searchsorted}(\text{cdf}_{\text{prepended}}, u) $$
7. **Clamp Indices:** Clamp indices to a minimum of 0 to handle boundary conditions [S2, unofficial].
8. **Normalize Indices:** Divide the indices by $n_{\text{coarse}}$ to get normalized positions within the coarse grid [S2, unofficial].
   $$ \text{norm\_idx} = \frac{\text{indices}}{n_{\text{coarse}}} $$
9. **Add Noise:** Add uniform noise to the normalized indices to jitter samples within the bin [S2, unofficial].
   $$ \text{noise} \sim \mathcal{U}(0, 1) $$
   $$ \text{z\_steps} = \text{norm\_idx} + \text{noise} $$
10. **Map to Depth/Disparity:** Map `z_steps` back to the actual depth or disparity space using the same transformation logic applied during coarse sampling [S2, unofficial].

**Pseudocode:**
```python
import torch
import torch.nn.functional as F

def inverse_sampling_for_fine_rays(z_vals, weights, Kf, Kfd, n_coarse, eps=1e-5):
    """
    z_vals: [B, Kc] coarse depths
    weights: [B, Kc] coarse weights
    Kf: total fine samples
    Kfd: fine samples for depth/disparity
    n_coarse: number of coarse samples (len(z_vals[-1]))
    """
    # 1. Regularize weights
    weights = weights + eps
    
    # 2. Compute PDF
    pdf = weights / weights.sum(dim=-1, keepdim=True)
    
    # 3. Compute CDF
    cdf = pdf.cumsum(dim=-1)
    
    # 4. Prepend zeros
    cdf = F.pad(cdf, (1, 0), value=0.)
    
    # 5. Generate uniform random numbers
    num_fine_samples = Kf - Kfd
    u = torch.rand(z_vals.shape[0], num_fine_samples, device=z_vals.device)
    
    # 6. Find indices in CDF
    indices = torch.searchsorted(cdf, u)
    
    # 7. Clamp indices
    indices = torch.clamp(indices, min=0)
    
    # 8. Normalize indices
    z_steps = indices.float() / n_coarse
    
    # 9. Add noise
    noise = torch.rand_like(z_steps)
    z_steps = z_steps + noise
    
    # 10. Map to depth space
    # Mapping logic depends on coarse sampling configuration [G]
    z_near = z_vals[..., 0:1]
    z_far = z_vals[..., -1:]
    z_fine = z_near + z_steps * (z_far - z_near)
    
    return z_fine
```

**Parameters:**
- `eps`: $10^{-5}$ [S2, unofficial].
- `Kf`, `Kfd`: Not given in the sources.

**Edge Cases:**
- If all weights are zero, the PDF becomes uniform after adding epsilon, leading to uniform sampling [S2, unofficial].
- Precision issues in `searchsorted` near 0 or 1 are handled by clamping and noise addition [S2, unofficial].

## Subtopics

### Importance Sampling (Fine)
This variant implements the inverse sampling procedure described in the PixelNeRF codebase [S2, unofficial]. It explicitly reserves `Kfd` samples for depth/disparity space, generating only `Kf - Kfd` samples via inverse CDF lookup, and normalizes indices by `n_coarse` before adding jitter [S2, unofficial]. It is used in few-shot novel view synthesis pipelines [S2, unofficial].

## Background
Inverse Sampling for Fine Rays is part of the PixelNeRF architecture, introduced by Alex Yu, Vickie Ye, Matthew Tancik, and Angjoo Kanazawa in 2021 [S2, unofficial]. It builds on the concept of importance sampling in volume rendering, adapting it for the hierarchical sampling scheme used in NeRF-like models [G]. The implementation is based on the PixelNeRF codebase [S2, unofficial].
