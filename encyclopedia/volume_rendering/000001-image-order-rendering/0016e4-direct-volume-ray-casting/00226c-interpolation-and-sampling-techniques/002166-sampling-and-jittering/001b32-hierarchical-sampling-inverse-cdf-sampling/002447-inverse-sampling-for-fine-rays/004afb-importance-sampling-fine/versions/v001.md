# Importance Sampling (Fine)

Also called: Fine Importance Sampling, Fine Ray Importance Sampling

## Overview
This method generates secondary sample positions along a ray by leveraging the probability distribution derived from a prior coarse rendering pass. It solves the problem of inefficient uniform sampling in regions of high radiance or opacity by concentrating samples where they contribute most to the final image. It differs from its parent, [Inverse Sampling for Fine Rays](3235-inverse-sampling-for-fine-rays.md), by explicitly defining the construction of the probability density function (PDF) and cumulative distribution function (CDF) from coarse weights, and the specific noise-injection step required to map discrete indices back to continuous depth space.

## How it works
**Inputs:**
- Coarse weights $w_i$ for $i \in \{0, \dots, N_{coarse}-1\}$, representing the contribution of each coarse sample to the ray's color/depth.
- Number of fine samples to generate, $K_f - K_{fd}$ (denoted as $N_{fine}$ in sources).
- Number of coarse samples, $N_{coarse}$.
- Ray depth bounds (near/far) or disparity bounds.

**Outputs:**
- $N_{fine}$ sample positions (depths or disparities) along the ray.

**Data Structures:**
- `weights`: Array of size $N_{coarse}$.
- `pdf`: Array of size $N_{coarse}$.
- `cdf`: Array of size $N_{coarse} + 1$.
- `u`: Array of size $N_{fine}$ containing uniform random numbers in $[0, 1)$.
- `indices`: Array of size $N_{fine}$ containing integer indices into the CDF.
- `z_steps`: Array of size $N_{fine}$ containing normalized positions in $[0, 1)$.

**Steps:**

1.  **Regularize Weights:** Add a small epsilon $\epsilon = 10^{-5}$ to all coarse weights to prevent division by zero.
    $$ w'_i = w_i + \epsilon $$
2.  **Compute PDF:** Normalize the regularized weights along the ray dimension to form a probability distribution.
    $$ \text{pdf}_i = \frac{w'_i}{\sum_{j=0}^{N_{coarse}-1} w'_j} $$
3.  **Compute CDF:** Compute the cumulative sum of the PDF. Prepend a zero to the CDF array to handle the first interval correctly, resulting in an array of size $N_{coarse} + 1$.
    $$ \text{cdf}_0 = 0 $$
    $$ \text{cdf}_{i+1} = \text{cdf}_i + \text{pdf}_i \quad \text{for } i \in \{0, \dots, N_{coarse}-1\} $$
4.  **Generate Random Numbers:** Generate $N_{fine}$ uniform random numbers $u_k \in [0, 1)$ for $k \in \{0, \dots, N_{fine}-1\}$.
5.  **Find Indices:** Use binary search (`searchsorted`) to find the index $idx_k$ in the CDF such that $\text{cdf}_{idx_k} \le u_k < \text{cdf}_{idx_k+1}$.
6.  **Clamp Indices:** Ensure indices are valid, clamping to a minimum of 0.
    $$ idx_k = \max(0, idx_k) $$
7.  **Compute Normalized Steps:** Add uniform noise to the index to break ties and map to a continuous normalized position $z_k \in [0, 1)$. The source specifies adding uniform noise to the index and dividing by $N_{coarse}$.
    $$ z_k = \frac{idx_k + \text{uniform}(0, 1)}{N_{coarse}} $$
    *Note: This step effectively interpolates within the bin defined by the coarse sample.*
8.  **Map to Depth/Disparity:** Map the normalized step $z_k$ to the actual depth or disparity space using the same transformation logic used in the coarse sampling stage (e.g., linear interpolation between near and far planes, or disparity-to-depth conversion).

**Pseudocode:**

```python
import numpy as np

def importance_sampling_fine(weights, n_coarse, n_fine, near, far):
    """
    Perform fine importance sampling based on coarse weights.
    
    Args:
        weights: np.ndarray of shape (N_coarse,), coarse rendering weights.
        n_coarse: int, number of coarse samples.
        n_fine: int, number of fine samples to generate.
        near: float, near plane distance.
        far: float, far plane distance.
        
    Returns:
        np.ndarray of shape (N_fine,), sample depths.
    """
    # 1. Regularize weights
    epsilon = 1e-5
    weights_reg = weights + epsilon
    
    # 2. Compute PDF
    pdf = weights_reg / np.sum(weights_reg)
    
    # 3. Compute CDF (prepend zero)
    cdf = np.zeros(n_coarse + 1)
    cdf[1:] = np.cumsum(pdf)
    
    # 4. Generate uniform random numbers
    u = np.random.uniform(0, 1, size=n_fine)
    
    # 5. Find indices in CDF
    # searchsorted finds the index where u[i] should be inserted to maintain order
    # This corresponds to the lower bound index in the CDF
    indices = np.searchsorted(cdf, u, side='left')
    
    # 6. Clamp indices to minimum 0
    indices = np.maximum(indices, 0)
    
    # 7. Compute normalized z_steps
    # Add uniform noise to the index and divide by n_coarse
    noise = np.random.uniform(0, 1, size=n_fine)
    z_steps = (indices + noise) / n_coarse
    
    # 8. Map z_steps to depth space
    # Assuming linear depth interpolation for this example
    # If disparity space is used, the mapping logic would differ
    depths = near + z_steps * (far - near)
    
    return depths
```

**Parameters:**
- $N_{coarse}$: Number of coarse samples. Typical value: 64 [S2, unofficial].
- $N_{fine}$: Number of fine samples. Typical value: 64 [S2, unofficial].
- $\epsilon$: Epsilon for weight regularization. Typical value: $10^{-5}$ [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Zero Weights:** If all coarse weights are zero, the PDF becomes undefined. The epsilon addition prevents this [S1, unofficial].
- **Index Out of Bounds:** `searchsorted` may return an index equal to the length of the CDF if $u_k$ is very close to 1. Clamping to the maximum valid index (or handling the last bin explicitly) is required. The source specifies clamping to minimum 0, but does not explicitly mention clamping to maximum. Standard implementation should clamp to $N_{coarse}-1$ or handle the last bin.
- **Precision:** Floating point precision in cumulative sum can lead to slight inaccuracies in CDF normalization.
- **Disparity vs Depth:** The mapping step (8) depends on whether the ray is parameterized by depth or disparity. The source states "using the same logic as coarse sampling," implying consistency with the coarse sampling method's parameterization [S1, unofficial].

## Subtopics

### Inverse Sampling for Fine Rays
The general technique of using inverse transform sampling to generate fine samples based on a probability distribution. Importance Sampling (Fine) is a specific implementation of this technique using coarse weights. [Link](3235-inverse-sampling-for-fine-rays.md)

## Operating characteristics
- **Time Complexity:** $O(N_{coarse} + N_{fine})$ for computing PDF, CDF, and sampling. The `searchsorted` operation is $O(\log N_{coarse})$ per sample, leading to $O(N_{fine} \log N_{coarse})$ for the sampling step. Overall complexity is dominated by $O(N_{coarse} + N_{fine} \log N_{coarse})$.
- **Memory Complexity:** $O(N_{coarse})$ to store the CDF.
- **Strengths:** Reduces variance in regions of high radiance or opacity by concentrating samples where they matter. Improves convergence rate compared to uniform fine sampling.
- **Limitations:** Requires a prior coarse pass to generate weights. Adds computational overhead for computing PDF/CDF and sampling. Performance gain depends on the scene's complexity and the quality of the coarse estimate.
- **When to Use:** When computational budget allows for a two-pass approach (coarse then fine) and the scene has significant variation in radiance/opacity.
- **When Not to Use:** When memory is extremely constrained (due to CDF storage) or when the coarse estimate is poor (leading to poor fine sampling).

## Background
This method is part of the hierarchical sampling strategy used in Neural Radiance Fields (NeRF) and related methods. It was introduced in the context of PixelNeRF [S1, unofficial] and VolRecon [S2, unofficial]. The approach builds on the idea that a coarse sampling pass can provide a rough estimate of the scene's structure, which can then be used to guide a more detailed fine sampling pass. This technique has become standard in many NeRF variants to improve rendering quality and efficiency.
