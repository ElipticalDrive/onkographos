# Inverse Sampling for Fine Rays
Also called: FineSampler
## Overview
Inverse Sampling for Fine Rays is a hierarchical sampling technique used in volume rendering to generate high-frequency samples along a ray based on the probability distribution derived from coarse rendering weights [S2, unofficial]. It differs from [Inverse Opacity Calculation](1099-inverse-opacity-calculation.md) by explicitly constructing a discrete probability density function (PDF) from coarse weights rather than inverting the accumulated opacity function, and from [Proposal Network Sampling](1589-proposal-network-sampling.md) by using a deterministic inverse CDF lookup instead of a learned neural network to predict sample locations [S2, unofficial].
## How it works
**Inputs and Outputs:**
- Input: `z_vals` (coarse sample depths, shape `[B, Kc]`), `weights` (coarse rendering weights, shape `[B, Kc]`), `Kf` (total fine samples), `Kfd` (fine samples dedicated to depth/disparity), `n_coarse` (number of coarse samples, typically `Kc`) [S2, unofficial].
- Output: `z_fine` (fine sample depths, shape `[B, Kf - Kfd]`) [S2, unofficial].

**Data Structures:**
- `z_vals`: Tensor of depth values along the ray [S2, unofficial].
- `weights`: Tensor of unnormalized importance weights derived from the coarse pass [S2, unofficial].
- `cdf`: Cumulative distribution function tensor, shape `[B, Kc + 1]` after prepending zero [S2, unofficial].

**Steps:**
1. **Regularize Weights:** Add a small epsilon ($\epsilon = 10^{-5}$) to `weights` to prevent division by zero [S2, unofficial].
   $$ w'_i = w_i + \epsilon $$
2. **Compute PDF:** Normalize the regularized weights along the ray dimension (last dimension) to obtain the probability density function [S2, unofficial].
   $$ \text{pdf}_i = \frac{w'_i}{\sum_{j=0}^{Kc-1} w'_j} $$
3. **Compute CDF:** Compute the cumulative sum of the PDF [S2, unofficial].
   $$ \text{cdf}_i = \sum_{j=0}^{i} \text{pdf}_j $$
4. **Prepend Zero:** Prepend a zero to the CDF to handle the first interval correctly, resulting in a CDF of length $Kc + 1$ [S2, unofficial].
   $$ \text{cdf}_{\text{prepended}} = [0, \text{cdf}_0, \text{cdf}_1, \dots, \text{cdf}_{Kc-1}] $$
5. **Generate Uniform Samples:** Generate $B \times (K_f - K_{fd})$ uniform random numbers $u \sim \mathcal{U}(0, 1)$ [S2, unofficial].
6. **Inverse Transform (Search):** Use `searchsorted` to find the indices in the CDF corresponding to $u$ [S2, unofficial].
   $$ \text{indices} = \text{searchsorted}(\text{cdf}_{\text{prepended}}, u) $$
7. **Clamp Indices:** Clamp indices to a minimum of 0 [S2, unofficial].
8. **Normalize Indices:** Compute normalized $z\_steps$ by adding uniform noise to indices and dividing by $n_{\text{coarse}}$ [S2, unofficial].
   $$ \text{z\_steps} = \frac{\text{indices} + \mathcal{U}(0, 1)}{n_{\text{coarse}}} $$
9. **Map to Depth/Disparity:** Map `z_steps` to depth or disparity space using the same transformation logic applied during coarse sampling [S2, unofficial].

**Pseudocode:**
```python
import torch

def inverse_sampling_for_fine_rays(z_vals, weights, Kf, Kfd, n_coarse, eps=1e-5):
    """
    z_vals: [B, Kc] coarse depths
    weights: [B, Kc] coarse weights
    Kf: total fine samples
    Kfd: fine samples for depth/disparity
    n_coarse: number of coarse samples
    """
    # 1. Regularize weights
    weights = weights + eps
    
    # 2. Compute PDF
    pdf = weights / weights.sum(dim=-1, keepdim=True)
    
    # 3. Compute CDF
    cdf = pdf.cumsum(dim=-1)
    
    # 4. Prepend zeros
    cdf = torch.cat([torch.zeros_like(cdf[:, :1]), cdf], dim=-1)
    
    # 5. Generate uniform random numbers
    num_fine_samples = Kf - Kfd
    u = torch.rand(z_vals.shape[0], num_fine_samples, device=z_vals.device)
    
    # 6. Find indices in CDF
    indices = torch.searchsorted(cdf, u)
    
    # 7. Clamp indices
    indices = torch.clamp(indices, min=0)
    
    # 8. Normalize indices: add noise then divide by n_coarse
    noise = torch.rand_like(indices.float())
    z_steps = (indices.float() + noise) / n_coarse
    
    # 9. Map to depth space [G]
    z_near = z_vals[..., 0:1]
    z_far = z_vals[..., -1:]
    z_fine = z_near + z_steps * (z_far - z_near)
    
    return z_fine
```

**Parameters:**
- `eps`: $10^{-5}$ [S2, unofficial].
- `Kf`, `Kfd`: Determined by the rendering pipeline configuration [G].

**Edge Cases:**
- If all weights are zero, the PDF becomes uniform after adding epsilon, leading to uniform sampling [S2, unofficial].
- Precision issues in `searchsorted` near 0 or 1 are handled by clamping and noise addition [S2, unofficial].

## Subtopics

### Importance Sampling (Fine)
This is the specific implementation of Inverse Sampling for Fine Rays as described in the PixelNeRF codebase [S2, unofficial]. It is chosen when using the PixelNeRF architecture for few-shot novel view synthesis, particularly when fine-grained depth estimation is required alongside color rendering [S2, unofficial]. It relies on the `searchsorted` operation for efficient inverse CDF lookup [S2, unofficial].

## Background
Inverse Sampling for Fine Rays is part of the PixelNeRF architecture, introduced by Alex Yu, Vickie Ye, Matthew Tancik, and Angjoo Kanazawa in 2021 [S2, unofficial]. It builds on the concept of importance sampling in volume rendering, adapting it for the hierarchical sampling scheme used in NeRF-like models [S2, unofficial]. The implementation is based on the PixelNeRF codebase [S2, unofficial].
