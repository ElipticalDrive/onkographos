# Discrete Distribution Sampler

Also called: Discrete Distribution Sampling, DistributionSampler

## Overview
The Discrete Distribution Sampler selects indices from a finite set of choices based on associated weights, mapping a uniform random number to a specific bin via cumulative probability [S1, unofficial]. It serves as the core selection mechanism in hierarchical sampling pipelines, enabling volume rendering algorithms to concentrate samples in high-density regions defined by per-bin weights [S2, unofficial]. Unlike continuous interpolation methods, it operates on discrete probability mass functions, making it suitable for selecting from pre-computed bin structures or proposal distributions [S1, unofficial].

## How it works
The method supports two primary modes: stochastic sampling for unbiased estimation and deterministic top-k selection for stable training or debugging [S2, unofficial]. The input is a set of choices with associated weights (or a probability density function tensor) and a uniform random variable $u \in [0, 1)$ [S1, unofficial].

### Inputs and Outputs
*   **Inputs**:
    *   `choices`: A list or tensor of items, each with an associated weight $w_i \ge 0$ [S1, unofficial].
    *   `u`: A uniform random number in $[0, 1)$ [S1, unofficial].
    *   `deterministic`: A boolean flag. If `true`, selects top-k indices; if `false`, samples stochastically [S2, unofficial].
    *   `num_samples`: The number of indices to select (used in deterministic mode) [S2, unofficial].
*   **Outputs**:
    *   `index`: The selected index or indices [S1, unofficial].
    *   `densities`: The probability density values at the selected indices [S2, unofficial].

### Data Structures
*   **Weighted Choice**: A structure containing an identifier and a float weight [S1, unofficial].
*   **PDF Tensor**: In tensor-based implementations, the input is a float tensor of shape `Float[*batch, bucket]`, where `bucket` represents the number of discrete bins [S2, unofficial].
*   **Index Tensor**: The output is an int64 tensor of shape `Int64[*batch, sample]` [S2, unofficial].

### Algorithm Steps

#### Stochastic Sampling Mode
1.  **Calculate Total Weight**: Compute the sum of all weights:
    $$ W_{total} = \sum_{i} w_i $$
    [S1, unofficial]
2.  **Scale Random Number**: Map the uniform random variable $u$ to the range $[0, W_{total})$:
    $$ u' = u \times W_{total} $$
    [S1, unofficial]
3.  **Iterative Subtraction**: Iterate through the choices in order. For each choice $i$ with weight $w_i$:
    $$ u' \leftarrow u' - w_i $$
    If $u' \le 0$, return the current choice's index [S1, unofficial].
4.  **Fallback**: If the loop completes without returning (due to floating-point precision issues where $u'$ remains slightly positive), return the last element's index [S1, unofficial].

#### Deterministic (Top-K) Mode
1.  **Sort and Select**: Sort the probability densities (weights) in descending order and select the top $k$ indices [S2, unofficial].
2.  **Gather Values**: Retrieve the corresponding values from the target tensor using the selected indices [S2, unofficial].

### Pseudocode (Stochastic)

```python
def sample_discrete_distribution_stochastic(choices, u):
    """
    Samples a single index from a list of weighted choices using inverse CDF sampling.
    
    Args:
        choices: List of objects with attribute 'weight' (float >= 0).
        u: Uniform random number in [0, 1).
        
    Returns:
        index: The index of the selected choice.
    """
    # Step 1: Calculate total weight
    total_w = sum(choice.weight for choice in choices)
    
    # Guard against zero total weight
    if total_w == 0:
        return 0 # Default to first index or handle error
        
    # Step 2: Scale u
    u_scaled = u * total_w
    
    # Step 3: Iterate and subtract
    for i, choice in enumerate(choices):
        u_scaled -= choice.weight
        if u_scaled <= 0.0:
            return i
            
    # Step 4: Fallback
    return len(choices) - 1
```

### Pseudocode (Tensor-based Gather)

```python
def gather_discrete_values(target, index, bucket_dim):
    """
    Gathers values from a target tensor using an index tensor, handling broadcasting.
    
    Args:
        target: Tensor of shape [..., bucket_size, ...].
        index: Int64 tensor of shape [..., sample_size].
        bucket_dim: The dimension in target corresponding to the buckets.
        
    Returns:
        gathered: Tensor with values selected by index.
    """
    # Determine bucket dimension as second-to-last dimension of index
    # Note: Source specifies bucket_dim = index.ndim - 1, but gather is along target's bucket_dim.
    # We assume index aligns with the bucket dimension of the target.
    
    # Expand index dimensions to match target dimensionality
    while len(index.shape) < len(target.shape):
        index = index[..., None]
        
    # Broadcast index to match target shape, preserving bucket dimension size
    # This step ensures index can be used for gathering along the specific bucket_dim
    broadcasted_index_shape = list(target.shape)
    # The index tensor must be broadcastable. 
    # If target's bucket dim is 1, reset index to zeros to handle broadcasting correctly
    if target.shape[bucket_dim] == 1:
        index = torch.zeros_like(index)
        
    # Perform gather operation
    # Note: In PyTorch, gather requires index to have same number of dims as input
    # and indices to be broadcastable to input shape.
    return target.gather(dim=bucket_dim, index=index)
```

## Subtopics

### Piecewise-Constant PDF Sampling
A variant that samples from a piecewise-constant probability density function defined by bin endpoints $t$ and weight logits $w_{logits}$ [S3, unofficial]. It supports deterministic center sampling (using linspace with padding) or stochastic sampling with uniform jitter [S3, unofficial]. It uses an inverse CDF function (`invert_cdf`) to map uniform samples to bin coordinates [S3, unofficial]. Key parameters include `single_jitter` (same jitter for all samples along a ray) and `use_gpu_resampling` (uses gather instruction for speed) [S3, unofficial].

### Multinomial Sampling Fallback
A utility function that selects $n$ indices from a weight distribution, switching between PyTorch and NumPy implementations to handle large tensor sizes (specifically when `num_elements > 2^{24}`) [S4, unofficial]. It normalizes weights, converts to NumPy for `np.random.choice`, and converts back to a Tensor [S4, unofficial].

### PMF Sampling
Samples indices from a discrete probability mass function (PMF) with replacement [S5, unofficial]. It computes the cumulative distribution function (CDF) along the support dimension, generates uniform random numbers, and uses `searchsorted` to find corresponding indices in the CDF [S5, unofficial]. Indices are clamped to the valid range $[0, \text{support\_size} - 1]$ [S5, unofficial].

## Operating characteristics
*   **Time Complexity**: $O(N)$ for stochastic sampling where $N$ is the number of bins, as it requires a linear scan to subtract weights [S1, unofficial]. Deterministic top-k selection is $O(N \log N)$ due to sorting [S2, unofficial].
*   **Memory Complexity**: $O(N)$ to store the weights and cumulative sums (if precomputed) [S1, unofficial].
*   **Precision**: The iterative subtraction method is susceptible to floating-point precision errors if weights vary significantly in magnitude or if $N$ is very large, potentially causing the loop to complete without $u' \le 0$ [S1, unofficial]. Using cumulative sums and binary search (`searchsorted`) can mitigate this but increases implementation complexity [S5, unofficial].
*   **Strengths**: Simple to implement, unbiased (in stochastic mode), and flexible with arbitrary weight distributions [S1, unofficial].
*   **Limitations**: Linear scan is slow for large $N$; deterministic mode loses stochasticity [S2, unofficial].

## Background
The Discrete Distribution Sampler is a fundamental component in Monte Carlo rendering and hierarchical sampling strategies. It originates from the general technique of inverse transform sampling applied to discrete domains [S1, unofficial]. In the context of volume rendering, it is used to select sample positions along a ray based on pre-computed density or opacity weights, enabling efficient hierarchical sampling [S2, unofficial]. The specific implementations cited are found in modern volume rendering and 3D Gaussian splatting codebases [S1, S2, S3, S4, S5, unofficial].
