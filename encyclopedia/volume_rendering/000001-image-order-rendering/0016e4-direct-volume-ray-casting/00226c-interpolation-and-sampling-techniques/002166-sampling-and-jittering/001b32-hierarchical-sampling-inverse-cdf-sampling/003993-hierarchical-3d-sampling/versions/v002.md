# Hierarchical 3D Sampling

Also called: Hierarchical Poisson-disk Sampling, Ordered 3D Dithering

## Overview
Hierarchical 3D Sampling generates a sequence of points within a unit cube such that any prefix $\{P_0, \dots, P_{n-1}\}$ maintains uniform density and a minimum inter-point distance [S1]. This property enables density control for volume rendering, serving as an alternative to opacity control or managing the level of detail (LOD) by selecting a subset of pre-computed points [S1]. The method provides hierarchical point sets where the priority of a point is defined by its serial number (index) in the generation sequence [S1]. Ordered dithering produces regular patterns, while Poisson-disk variants produce irregular patterns to mitigate aliasing [S1].

## How it works
### Inputs and Outputs
**Inputs:**
*   Target number of points $n$ [S1].
*   Sampling domain: A unit cube $[0,1]^3$ with periodic boundary conditions (each face treated identically to its opposite) [S1].
*   Source data: Voxel grid for scalar value retrieval [S1].

**Outputs:**
*   A sequence of 3D coordinates $\{P_0, P_1, \dots, P_{n-1}\}$ representing the hierarchical point set [S1].
*   Pre-computed histogram $h(s)$: The count of sampled points falling into each scalar value bin $s$, used for estimating the total number of rendered primitives [S1].

### Data Structures
1.  **Point List**: An array of 3D vectors storing coordinates $(x, y, z)$. The index $k$ corresponds to the priority number; smaller $k$ implies higher priority [S1].
2.  **Histogram**: An array indexed by scalar value $s$, storing the integer count $h(s)$ of points whose interpolated scalar value equals $s$ [S1].

### Steps
1.  **Generate Point Set**: Create the sequence of points using either Ordered 3D Dithering or Hierarchical Poisson-disk Sampling [S1].
2.  **Interpolate Scalar Values**: For each point $P_k$, calculate the scalar value $s_k$ by linear interpolation from the original voxel data [S1].
3.  **Update Histogram**: Increment the count $h(s_k)$ in the histogram for the calculated scalar value [S1].
4.  **Estimate Total Points**: Use the histogram to estimate the total number of candidates $N$ for density control [S1].

### Algorithms for Point Generation

#### 1. Ordered 3D Dithering (Regular Pattern)
This is the simplest implementation, extending 2D ordered dithering (digital halftoning) directly to 3D [S1].
*   **Method**: Divide the unit cube into a grid. Assign points to grid centers. Sort the grid cells based on a 3D dithering matrix value. The first $n$ points in this sorted order form the subset $\{P_0, \dots, P_{n-1}\}$ [S1].
*   **Properties**: Points are evenly distributed. The serial number $k$ determines priority [S1].

#### 2. Hierarchical Poisson-disk Sampling (Irregular Pattern)
Proposed by McCool and Fiume, this method creates irregular patterns to avoid aliasing [S1].
*   **Parameters**:
    *   Failure threshold $T_{\text{fail}} = 1000$ [S1].
    *   Radius reduction factor $\alpha = 0.99$ [S1].
    *   Initial minimum distance limit $L_{\text{init}}$: Not given in the sources [G].
*   **Procedure**:
    1.  Initialize an empty list of placed points.
    2.  Set current limit length $L = L_{\text{init}}$.
    3.  Repeat until $n$ points are placed:
        a.  Attempt to place a new point $P_{\text{new}}$ randomly in the unit cube.
        b.  Check distance to all previously placed points.
        c.  If distance to any existing point is less than $L$, discard $P_{\text{new}}$ and increment failure counter $C$.
        d.  If $C < T_{\text{fail}}$, repeat step 3a.
        e.  If $C \ge T_{\text{fail}}$, reduce $L \leftarrow L \times \alpha$ and reset $C = 0$.
        f.  If $L$ becomes too small to place any point, terminate or adjust $L_{\text{init}}$ [S1].

### Formulas
**Scalar Interpolation**:
The scalar value $s$ at point $P$ is calculated by linear interpolation from the original voxel data [S1].
$$ s = \text{LinearInterpolate}(VoxelData, P) $$
*Note: Higher degree interpolation or interpolation from irregular meshed data is also possible [S1].*

**Total Candidate Estimation**:
For a density function $d_m(s)$, the estimated total number of points $N$ is:
$$ N = \sum_{s=s_{\min}}^{s_{\max}} d_m(s) h(s) $$
where $s_{\min}$ and $s_{\max}$ are the minimum and maximum scalar values, and $h(s)$ is the histogram count [S1].

For other density functions requiring gradient magnitude, an approximation is used:
$$ N = \sum_{s=s_{\min}}^{s_{\max}} \bar{g}(s) h(s) $$
where $\bar{g}(s)$ is the average gradient magnitude at scalar value $s$ [S1].

**Density Adjustment**:
If the number of candidates $N$ is too large for interactivity, the actual point density $d(x)$ is reduced:
$$ d(x) = d_m(x) \min(1, S/N) $$
where $S$ represents a target scaling factor [S1].

### Pseudocode
```python
import random

def calculate_initial_limit(n):
    """[G] Standard approximation for uniform spacing in a unit cube."""
    return (1.0 / n) ** (1.0 / 3.0)

def random_point_in_unit_cube():
    """Standard uniform random generation in [0, 1)^3."""
    return (random.random(), random.random(), random.random())

def distance_periodic(p1, p2):
    """Euclidean distance on a 3D torus."""
    diff = [min(abs(p1[i] - p2[i]), 1.0 - abs(p1[i] - p2[i])) for i in range(3)]
    return (diff[0]**2 + diff[1]**2 + diff[2]**2) ** 0.5

def generate_hierarchical_poisson_disk(n):
    """
    Generates n points using Hierarchical Poisson-disk sampling.
    Matches the dart-throwing algorithm with radius reduction from [S1].
    """
    points = []
    L = calculate_initial_limit(n)
    failure_count = 0
    T_fail = 1000
    alpha = 0.99
    
    while len(points) < n:
        candidate = random_point_in_unit_cube()
        
        is_valid = True
        for existing_point in points:
            if distance_periodic(candidate, existing_point) < L:
                is_valid = False
                break
        
        if is_valid:
            points.append(candidate)
            failure_count = 0
        else:
            failure_count += 1
            if failure_count >= T_fail:
                L = L * alpha
                failure_count = 0
                if L < 1e-6:
                    break
                    
    return points

def estimate_total_points(histogram, density_function):
    """
    Estimates total number of rendered primitives N.
    histogram: dict mapping scalar value s to count h(s)
    density_function: function d_m(s)
    """
    N = 0.0
    for s, h_s in histogram.items():
        N += density_function(s) * h_s
    return N
```

### Edge Cases and Pitfalls
*   **Regularity Artifact**: If the total number of points $n$ is too small, the regularity of the pattern becomes obvious, causing aliasing artifacts when correlated with object surfaces or screen coordinates [S1].
*   **Aliasing**: Ordered dithering creates severe aliasing artifacts due to its regularity. Irregular patterns (like Poisson-disk) are necessary for many applications to mitigate this [S1].
*   **Performance**: Hierarchical Poisson-disk sampling requires expensive computation during generation. However, points can be pre-computed and reused for any object [S1].

## Operating characteristics
*   **Time Complexity**: Ordered Dithering generation involves simple grid assignment and sorting [S1]. Poisson-disk generation has high computational cost due to distance checks against all existing points [S1]. Exact asymptotic complexity is Not given in the sources.
*   **Memory Complexity**: $O(n)$ to store the point list and $O(S)$ for the histogram, where $S$ is the number of scalar bins [S1].
*   **Strengths**:
    *   Provides hierarchical LOD control; subsets of points maintain uniform density [S1].
    *   Irregular variants (Poisson-disk) reduce aliasing artifacts [S1].
    *   Pre-computable; reusable across different objects [S1].
*   **Limitations**:
    *   Regular patterns (Dithering) suffer from aliasing [S1].
    *   Poisson-disk generation is computationally expensive [S1].
    *   Requires careful tuning of failure thresholds and radius reduction factors [S1].
*   **When to Use**: When density control is needed for opacity adaptation or LOD management, and pre-computation is feasible [S1].

## Background
Hierarchical 3D Sampling is used for density control and level-of-detail management in volume rendering [S1]. The method builds on 2D ordered dithering techniques used in digital halftoning [S1]. The irregular variant, Hierarchical Poisson-disk sampling, was proposed by McCool and Fiume [S1]. The technique is applied in real-time previewing for volume visualization [S1].
