# Inverse CDF Interpolation

Also called: Inverse CDF Sampling

## Overview
Inverse CDF Interpolation inverts a cumulative distribution function defined by bin endpoints `t` and weights `w` at query points `u` in `[0, 1)` [S1, unofficial][S2, unofficial]. It converts uniform random numbers into spatial positions along a ray by mapping them to the time domain using linear interpolation between cumulative weight boundaries [S1, unofficial][S2, unofficial].

## How it works
**Inputs:**
- `w_logits`: Raw density scores (logits) for each sample interval along the ray. Shape: $(N,)$ or $(B, N)$ where $N$ is the number of intervals [S1, unofficial][S2, unofficial].
- `t`: Array of bin endpoints (time/depth values) corresponding to the intervals. Shape: $(N+1,)$ [S1, unofficial][S2, unofficial].
- `u`: Uniform random numbers in $[0, 1)$. Shape: $(M,)$ or $(B, M)$ [S1, unofficial][S2, unofficial].

**Outputs:**
- `t_new`: Sampled time/depth values corresponding to the random inputs `u` [S1, unofficial][S2, unofficial].

**Data Structures:**
- `w`: Normalized weights, shape $(N,)$ [S1, unofficial][S2, unofficial].
- `cw`: Cumulative weights (CDF), shape $(N+1,)$ [S1, unofficial][S2, unofficial].

**Steps:**
1. Normalize weights: Convert logits to weights using the Softmax function along the last axis. `w = torch.softmax(w_logits, dim=-1)` [S1, unofficial][S2, unofficial].
2. Compute CDF: Integrate the weights to form the cumulative distribution function. `cw = integrate_weights(w)` [S1, unofficial][S2, unofficial].
3. Interpolate: Map the uniform random values `u` to the time domain `t` using the inverse CDF. `t_new = math.sorted_interp(u, cw, t)` [S1, unofficial][S2, unofficial].

**Formulas:**
$$ w_i = \frac{\exp(w\_logits_i)}{\sum_{j} \exp(w\_logits_j)} $$
$$ cw_0 = 0, \quad cw_i = cw_{i-1} + w_{i-1} \quad \text{for } i = 1 \dots N $$
$$ t\_new = t_i + (t_{i+1} - t_i) \frac{u - cw_i}{cw_{i+1} - cw_i} \quad \text{where } cw_i \le u < cw_{i+1} $$

**Pseudocode:**
```python
import torch

def inverse_cdf_interpolation(w_logits, t, u):
    # Step 1: Normalize weights using Softmax along the last axis
    # Source: w = torch.softmax(w_logits, dim=-1)
    w = torch.softmax(w_logits, dim=-1)

    # Step 2: Compute cumulative weights (CDF)
    # Source: cw = integrate_weights(w)
    # cw has shape matching w with an extra element at the start: [0, w0, w0+w1, ..., 1]
    cw = torch.cat([torch.zeros_like(w[..., :1]), torch.cumsum(w, dim=-1)], dim=-1)

    # Step 3: Interpolate u into the inverse CDF using t and cw
    # Source: t_new = math.sorted_interp(u, cw, t)
    # Find interval index i such that cw[..., i] <= u < cw[..., i+1]
    # searchsorted with side='right' returns insertion point i where cw[..., i-1] <= u < cw[..., i]
    indices = torch.searchsorted(cw, u, side='right') - 1
    indices = torch.clamp(indices, min=0, max=w.shape[-1] - 1)

    # Gather bounds
    cw_lower = cw.gather(-1, indices.unsqueeze(-1)).squeeze(-1)
    cw_upper = cw.gather(-1, (indices + 1).unsqueeze(-1)).squeeze(-1)
    t_lower = t[indices]
    t_upper = t[indices + 1]

    # Linear interpolation
    denom = cw_upper - cw_lower
    denom = torch.where(denom == 0, 1.0, denom)
    fraction = (u - cw_lower) / denom
    t_new = t_lower + fraction * (t_upper - t_lower)

    return t_new
```

**Edge Cases and Pitfalls:**
- **Zero Weights:** If a bin has zero weight, `cw_lower` equals `cw_upper`. The interpolation fraction becomes undefined. The code handles this by clamping the denominator to 1.0, effectively returning the lower bound `t_lower` [G].
- **Boundary Conditions:** Uniform samples `u` must be strictly less than 1.0 to avoid index out-of-bounds when searching in `cw` which ends at 1.0. Clamping `u` to `1 - epsilon` is recommended [G].
- **Precision:** Floating-point errors in cumulative sum may cause `cw[-1]` to deviate slightly from 1.0. Normalizing `cw` by `cw[-1]` can improve robustness [G].
