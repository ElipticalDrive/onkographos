# Piecewise Constant Approximation Inverse

Also called: Inverse CDF with Piecewise Constant Density, Piecewise Constant Inverse Sampling

## Overview
This method computes the ray parameter $t$ corresponding to a target cumulative density value $y$ by assuming the density $\rho_{\mathbf{r}}$ is constant within each sample interval $[t_{j-1}, t_j]$ [S1, unofficial]. It serves as the core inversion step in inverse opacity sampling, allowing the generation of sample positions that are uniformly distributed with respect to the accumulated density integral [S1, unofficial]. Unlike [Piecewise Linear Approximation Inverse](2649-piecewise-linear-approximation-inverse.md), which models density as linear within intervals and requires solving a quadratic equation, this approach yields a closed-form linear solution, making it computationally cheaper but less accurate for rapidly varying density fields [S1, unofficial].

## How it works
**Inputs:**
- $y$: The target cumulative density value (scalar) [S1, unofficial].
- $t$: An array of $N+1$ sample positions $[t_0, \dots, t_N]$ along the ray [S1, unofficial].
- $\rho_{\mathbf{r}}$: An array of $N$ density values $[\rho_{\mathbf{r}}(\hat{t}_1), \dots, \rho_{\mathbf{r}}(\hat{t}_N)]$, where $\rho_{\mathbf{r}}(\hat{t}_j)$ is the constant density for interval $j$ [S1, unofficial].

**Outputs:**
- $t$: The ray parameter such that the integral of density from $t_0$ to $t$ equals $y$ [S1, unofficial].

**Steps:**
1. Compute the cumulative density sum for all complete intervals preceding the current interval $i$: $S_i = \sum_{j=1}^i \rho_{\mathbf{r}}(\hat{t}_j)(t_j - t_{j-1})$ [S1, unofficial].
2. Determine the interval index $i$ such that $S_i \le y < S_{i+1}$, which identifies the interval $[t_i, t_{i+1}]$ containing the target cumulative value [S1, unofficial].
3. Calculate $t$ using the linear inversion formula: $t = t_i + \frac{y - S_i}{\rho_{\mathbf{r}}(\hat{t}_i)}$ [S1, unofficial].

**Pitfalls:**
- When density $\rho_{\mathbf{r}}(\hat{t}_i) \approx 0$, the denominator becomes unstable; the implementation adds a small epsilon value to the denominator to improve stability [S1, unofficial].

**Pseudocode:**
```python
def piecewise_constant_inverse(y, t, rho):
    """
    Solve for t given target cumulative density y.
    t: array of length N+1, sample positions [t_0, ..., t_N]
    rho: array of length N, density values [rho_1, ..., rho_N] for intervals [t_0,t_1]...[t_{N-1},t_N]
    y: target cumulative density scalar
    """
    N = len(t) - 1
    cumulative_sum = 0.0
    
    for i in range(1, N + 1):
        # Map 1-based interval index i to 0-based array index i-1
        idx = i - 1
        interval_width = t[i] - t[idx]
        interval_density = rho[idx]
        interval_contribution = interval_density * interval_width
        
        if cumulative_sum + interval_contribution >= y:
            # Found interval i: [t_i, t_{i+1}]
            # Stability guard: add epsilon to denominator if density is near zero [S1, unofficial]
            denom = interval_density + 1e-8
            t_result = t[idx] + (y - cumulative_sum) / denom
            return t_result
        
        cumulative_sum += interval_contribution
        
    # Fallback if y exceeds total accumulated density
    return t[N]
```

### Inverse CDF Interpolation
This variant inverts the CDF defined by bin endpoints `t` and weights `w` at query points `u` in $[0, 1)$ [S2, unofficial]. It converts logits to weights via `w = torch.softmax(w_logits, dim=-1)`, computes the CDF via `cw = integrate_weights(w)`, and interpolates `u` into the inverse CDF using `t_new = sorted_interp(u, cw, t)` [S2, unofficial].

## Background
The piecewise constant approximation inverse is derived in the context of differentiable volume rendering, specifically for reparameterized volume sampling [S1, unofficial]. It provides an explicit formula for the density integral inverse, enabling efficient inverse opacity sampling [S1, unofficial]. The method is part of a broader family of inverse CDF sampling techniques used to generate samples proportional to density along a ray [S1, unofficial].
