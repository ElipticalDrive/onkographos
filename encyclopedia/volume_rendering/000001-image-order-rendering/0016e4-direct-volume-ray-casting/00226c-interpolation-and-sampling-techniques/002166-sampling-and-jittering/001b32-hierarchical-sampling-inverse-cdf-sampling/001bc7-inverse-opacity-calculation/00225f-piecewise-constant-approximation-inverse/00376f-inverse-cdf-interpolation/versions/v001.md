# Inverse CDF Interpolation

Also called: Inverse CDF Sampling

## Overview
Inverse CDF Interpolation is a hierarchical sampling technique used in volume rendering to draw samples from a probability distribution defined by discrete density weights. It solves the problem of converting uniform random numbers into spatial positions along a ray, ensuring that samples are concentrated in regions of high density. It differs from its parent, Piecewise Constant Approximation Inverse, by using linear interpolation between cumulative weight boundaries rather than assuming constant density within bins, which provides smoother sampling distributions [S1, S2, unofficial].

## How it works
**Inputs:**
- `w_logits`: A tensor of raw density scores (logits) for each sample interval along the ray. Shape: $(N,)$ or $(B, N)$ where $N$ is the number of intervals.
- `t`: The array of bin endpoints (time/depth values) corresponding to the intervals. Shape: $(N+1,)$.
- `u`: Uniform random numbers in $[0, 1)$. Shape: $(M,)$ or $(B, M)$.

**Outputs:**
- `t_new`: The sampled time/depth values corresponding to the random inputs `u`.

**Data Structures:**
- `w`: Normalized weights, shape $(N,)$.
- `cw`: Cumulative weights (CDF), shape $(N+1,)$.

**Steps:**
1.  **Normalize Weights:** Convert logits to probabilities using the Softmax function along the last axis.
    $$ w_i = \frac{\exp(w\_logits_i)}{\sum_{j=1}^{N} \exp(w\_logits_j)} $$
    [S1, S2, unofficial]

2.  **Compute Cumulative Weights (CDF):** Integrate the weights to form the cumulative distribution function. The CDF is an array of size $N+1$, where the first element is 0 and subsequent elements are the running sum of weights.
    $$ cw_0 = 0 $$
    $$ cw_i = cw_{i-1} + w_{i-1} \quad \text{for } i = 1 \dots N $$
    $$ cw_{N} = 1.0 $$
    [S1, S2, unofficial]

3.  **Inverse Interpolation:** Map the uniform random values `u` to the time domain `t` using the inverse CDF. This is performed by finding the interval in `cw` that contains `u` and linearly interpolating between the corresponding time endpoints `t`.
    $$ t\_new = \text{interp}(u, cw, t) $$
    [S1, S2, unofficial]

**Pseudocode:**
```python
import torch
import math

def inverse_cdf_interpolation(w_logits, t, u):
    """
    Samples points along a ray based on density weights using Inverse CDF Interpolation.
    
    Args:
        w_logits: Tensor of shape (N,) or (B, N) containing raw density scores.
        t: Tensor of shape (N+1,) containing bin endpoints.
        u: Tensor of shape (M,) or (B, M) containing uniform random numbers in [0, 1).
        
    Returns:
        t_new: Tensor of sampled time values.
    """
    # Step 1: Normalize weights using Softmax
    # Ensure w_logits is at least 2D for consistent softmax behavior if needed, 
    # but standard softmax works on the last dimension.
    w = torch.softmax(w_logits, dim=-1)
    
    # Step 2: Compute Cumulative Weights (CDF)
    # cw has shape (N+1,) if w is (N,), or (B, N+1) if w is (B, N)
    # cw[0] is 0.0, cw[i] is sum(w[:i])
    cw = torch.cat([torch.zeros_like(w[..., :1]), torch.cumsum(w, dim=-1)], dim=-1)
    
    # Step 3: Interpolate u into the inverse CDF
    # Find the index i such that cw[..., i] <= u < cw[..., i+1]
    # Then linearly interpolate between t[i] and t[i+1]
    
    # Handle edge cases: u might be exactly 1.0 due to floating point, clamp to < 1.0
    u = torch.clamp(u, min=0.0, max=1.0 - 1e-6)
    
    # Find indices where u falls into the cumulative weight bins
    # searchsorted returns the index i such that cw[..., i-1] < u <= cw[..., i]
    # We need to adjust for 0-based indexing and the fact that cw has N+1 elements
    indices = torch.searchsorted(cw, u, side='right') - 1
    indices = torch.clamp(indices, min=0, max=w.shape[-1] - 1)
    
    # Get the lower and upper bounds for interpolation
    cw_lower = cw.gather(-1, indices.unsqueeze(-1)).squeeze(-1)
    cw_upper = cw.gather(-1, (indices + 1).unsqueeze(-1)).squeeze(-1)
    
    t_lower = t[indices]
    t_upper = t[indices + 1]
    
    # Linear interpolation
    # Avoid division by zero if cw_lower == cw_upper (zero weight bin)
    denom = cw_upper - cw_lower
    denom = torch.where(denom == 0, 1.0, denom)
    
    fraction = (u - cw_lower) / denom
    t_new = t_lower + fraction * (t_upper - t_lower)
    
    return t_new
```

**Edge Cases and Pitfalls:**
-   **Zero Weights:** If a bin has zero weight, `cw_lower` equals `cw_upper`. The interpolation fraction becomes undefined. The code above handles this by clamping the denominator to 1.0, effectively returning the lower bound `t_lower` [G].
-   **Boundary Conditions:** Uniform samples `u` must be strictly less than 1.0 to avoid index out-of-bounds when searching in `cw` which ends at 1.0. Clamping `u` to `1 - epsilon` is recommended [G].
-   **Precision:** Floating-point errors in cumulative sum may cause `cw[-1]` to deviate slightly from 1.0. Normalizing `cw` by `cw[-1]` can improve robustness [G].

## Operating characteristics
-   **Time Complexity:** $O(N)$ for computing the CDF and $O(M \log N)$ or $O(M)$ for the inverse interpolation depending on the search method (binary search vs. linear scan).
-   **Memory Complexity:** $O(N)$ to store the cumulative weights.
-   **Strengths:** Provides smooth sampling distributions; differentiable with respect to logits (via Softmax and interpolation); efficient on GPUs using vectorized operations.
-   **Limitations:** Requires computing the full CDF for each ray; less accurate than analytical inverse CDF if the density function is known and simple, but more flexible for arbitrary discrete weights.

## Background
Inverse CDF Interpolation is implemented in modern neural rendering frameworks such as InstantSplat and density-bounded ray weight libraries. It builds on the concept of hierarchical sampling where uniform random numbers are transformed according to the estimated density distribution along the ray. The method is widely used in differentiable volume rendering to enable gradient-based optimization of scene representations [S1, S2, unofficial].
