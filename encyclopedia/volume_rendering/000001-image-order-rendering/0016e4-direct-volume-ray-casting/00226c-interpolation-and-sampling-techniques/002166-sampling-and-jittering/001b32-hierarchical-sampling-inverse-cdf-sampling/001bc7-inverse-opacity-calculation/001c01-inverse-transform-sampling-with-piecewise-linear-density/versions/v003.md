# Inverse Transform Sampling with Piecewise Linear Density

Also called: RVS Inverse CDF Sampling, RVS Sampling

## Overview
Inverse Transform Sampling with Piecewise Linear Density is a differentiable method for generating samples along a ray according to a distribution induced by linearly interpolating the volume density $\sigma_{\mathbf{r}}$ [S1]. It solves the problem of finding the ray parameter $t$ corresponding to a target cumulative density value $y$, ensuring that samples strictly follow the Beer-Lambert law within each bin [S1]. Unlike NeRF's hierarchical sampling, which interpolates exponentiated densities (probabilities), this method interpolates the density field directly, offering better numerical stability for end-to-end optimization [S1].

## How it works
**Inputs:**
- $u$: Uniform random variable, $u \in [0, 1)$.
- $\sigma_{\mathbf{r}}$: Array of density values at grid knots, size $N$.
- $t_s, t_e$: Start and end parameters of the ray segment.
- $t$: Array of grid knots, size $N$, where $t_0 = t_s$ and $t_{N-1} = t_e$.

**Outputs:**
- $t_{\text{sample}}$: The sampled ray parameter.

**Data Structures:**
- `prefix_integrals`: Array of size $N$, storing the cumulative integral of density from $t_0$ to $t_i$.
- `bin_integrals`: Array of size $N-1$, storing the integral of density within each interval $[t_i, t_{i+1}]$.

**Steps:**

1. **Compute Bin Integrals and Prefix Sums:**
   Calculate the integral of density over each interval using linear interpolation, as required by the quadratic derivation [S1].
   $$ \text{bin\_integrals}_i = \frac{\sigma_{\mathbf{r}}(t_i) + \sigma_{\mathbf{r}}(t_{i+1})}{2} (t_{i+1} - t_i) $$
   $$ \text{prefix\_integrals}_0 = 0 $$
   $$ \text{prefix\_integrals}_{i+1} = \text{prefix\_integrals}_i + \text{bin\_integrals}_i $$

2. **Compute Inverse Opacity Input $y$:**
   Calculate the target cumulative density value $y$ from the uniform sample $u$ and the total ray optical depth $\tau = \text{prefix\_integrals}_{N-1}$ [S1]. Using the numerically stable logsumexp operator:
   $$ y = -\log \left( \exp(\log(1-u)) + \exp(\log u - \tau) \right) $$
   *Edge Case:* When the integral is approximately zero, the logsumexp implementation becomes computationally unstable, and $y$ is replaced with a first-order approximation $u \cdot \tau$ [S1].

3. **Find the Interval:**
   Find the index $i$ such that $\text{prefix\_integrals}_i \le y < \text{prefix\_integrals}_{i+1}$ [G]. If $y \ge \text{prefix\_integrals}_{N-1}$, set $t_{\text{sample}} = t_e$ [G].

4. **Solve for $\Delta t$:**
   Within the interval $[t_i, t_{i+1}]$, assume linear density interpolation [S1]. We solve for $\Delta t = t - t_i$ in the quadratic equation:
   $$ 0 = a \Delta t^2 + b \Delta t + c $$
   Where:
   $$ a = \frac{\sigma_{\mathbf{r}}(t_{i+1}) - \sigma_{\mathbf{r}}(t_i)}{2} $$
   $$ b = \sigma_{\mathbf{r}}(t_i) \cdot (t_{i+1} - t_i) $$
   $$ c = \left( \text{prefix\_integrals}_i - y \right) \cdot (t_{i+1} - t_i) $$
   Compute the root using the stable formula to avoid cancellation when $a \approx 0$ [S1]:
   $$ \Delta t = \frac{-2c}{b + \sqrt{b^2 - 4ac}} $$
   *Pitfall:* If $b^2 - 4ac < 0$, clamp the discriminant to $0$ [G]. If the denominator is $0$, set $\Delta t = 0$ [G].

5. **Return Result:**
   $$ t_{\text{sample}} = t_i + \Delta t $$

**Pseudocode:**

```python
import numpy as np

def inverse_cdf_piecewise_linear(u, sigmas, ts):
    """
    Inverse Transform Sampling with Piecewise Linear Density.
    
    Args:
        u: Uniform random sample [0, 1).
        sigmas: Density values at knots, shape (N,).
        ts: Knot positions, shape (N,).
        
    Returns:
        t_sample: Sampled position along the ray.
    """
    N = len(ts)
    if N < 2:
        return ts[0]
        
    # 1. Compute Prefix Integrals (linear interpolation per source derivation)
    bin_integrals = (sigmas[:-1] + sigmas[1:]) / 2.0 * np.diff(ts)
    prefix_integrals = np.concatenate([[0.0], np.cumsum(bin_integrals)])
    total_tau = prefix_integrals[-1]
    
    # 2. Compute y (Inverse Opacity Input)
    # Handle numerical stability for small optical depth (transparent rays)
    if total_tau < 1e-5:
        y = u * total_tau
    else:
        term1 = np.log(1.0 - u)
        term2 = np.log(u) - total_tau
        max_val = np.maximum(term1, term2)
        y = - (max_val + np.log(np.exp(term1 - max_val) + np.exp(term2 - max_val)))
        
    # 3. Find interval
    i = np.searchsorted(prefix_integrals, y, side='right') - 1
    i = np.clip(i, 0, N - 2)
    
    t_i = ts[i]
    t_ip1 = ts[i+1]
    sigma_i = sigmas[i]
    sigma_ip1 = sigmas[i+1]
    
    dt_interval = t_ip1 - t_i
    
    # 4. Solve Quadratic
    a = (sigma_ip1 - sigma_i) / 2.0
    b = sigma_i * dt_interval
    c = (prefix_integrals[i] - y) * dt_interval
    
    discriminant = b*b - 4*a*c
    if discriminant < 0:
        discriminant = 0.0
        
    denom = b + np.sqrt(discriminant)
    if denom == 0:
        delta_t = 0.0
    else:
        # Corrected stable formula: original source had sign error for c < 0
        delta_t = (-2.0 * c) / denom
        
    # Clamp delta_t to interval bounds
    delta_t = np.clip(delta_t, 0.0, dt_interval)
    
    return t_i + delta_t
```

## Operating characteristics
- **Time Complexity:** $O(N)$ to compute prefix integrals; $O(\log N)$ or $O(1)$ to find the interval and solve the quadratic [G].
- **Memory Complexity:** $O(N)$ to store prefix integrals [G].
- **Strengths:** Differentiable; samples follow the Beer-Lambert law within bins; numerically stable for end-to-end optimization compared to exponentiated density interpolation [S1].
- **Limitations:** Requires computing prefix integrals; quadratic solution has edge cases for $a \approx 0$ handled by the stable formula [S1].
- **When to use:** When differentiable sampling from a linearly interpolated density field is required, particularly in neural volume rendering contexts like RVS [S1].

## Background
This method was introduced in "Differentiable Rendering with Reparameterized Volume Sampling" (2023) [S1]. It contrasts with the original NeRF hierarchical sampling, which uses piecewise constant density interpolation and exponentiates densities [S1]. The RVS method interpolates the density field directly, leading to samples that adhere to the Beer-Lambert law within each bin, which is argued to be more suitable for end-to-end optimization due to better numerical stability [S1].
