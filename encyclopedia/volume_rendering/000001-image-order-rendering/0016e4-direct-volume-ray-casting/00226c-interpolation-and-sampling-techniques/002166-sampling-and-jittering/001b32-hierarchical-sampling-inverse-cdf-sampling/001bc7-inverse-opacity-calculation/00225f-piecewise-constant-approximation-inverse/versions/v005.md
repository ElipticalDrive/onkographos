# Piecewise Constant Approximation Inverse

Also called: Inverse CDF with Piecewise Constant Density, Piecewise Constant Inverse Sampling

## Overview
Piecewise Constant Approximation Inverse computes the inverse of the density integral along a ray to determine sample positions in inverse opacity sampling [S1, unofficial]. It assumes the density $\sigma_{\mathbf{r}}$ is constant within each discrete sample interval $[t_{j-1}, t_j]$ [S1, unofficial]. This approach differs from its sibling, [Piecewise Linear Approximation Inverse](2649-piecewise-linear-approximation-inverse.md), by treating density as a step function rather than a linearly varying one, resulting in a linear equation for the ray parameter $t$ instead of a quadratic one [S1, unofficial]. It builds on [Inverse Opacity Calculation](1099-inverse-opacity-calculation.md) by providing an explicit closed-form solution for the ray parameter given a target cumulative density value [S1, unofficial].

## How it works
**Inputs:**
- $y$: The target cumulative density value (integral of density) to solve for [S1, unofficial].
- $\{t_j\}_{j=0}^{N}$: The sorted array of sample positions along the ray, where $t_0$ is the entry point and $t_N$ is the exit point [G].
- $\{\hat{\sigma}_j\}_{j=1}^{N}$: The density values sampled at each interval, where $\hat{\sigma}_j$ represents the constant density in the interval $[t_{j-1}, t_j]$ [S1, unofficial].

**Outputs:**
- $t$: The ray parameter such that the integral of density from $t_0$ to $t$ equals $y$ [S1, unofficial].

**Data Structures:**
- Arrays `t` and `sigma` of size $N+1$ and $N$ respectively [G].
- Precomputed prefix sums of the product $\sigma \cdot \Delta t$ can be used to accelerate the summation, though the direct summation is $O(N)$ per query [G].

**Steps:**
1. Iterate through the sample intervals $j=1, \dots, N$ to find the index $i$ such that the cumulative integral up to $t_i$ is less than or equal to $y$, and the cumulative integral up to $t_{i+1}$ is greater than $y$ [G]. Specifically, find $i$ where:
   $$ \sum_{j=1}^{i} \hat{\sigma}_j (t_j - t_{j-1}) \le y < \sum_{j=1}^{i+1} \hat{\sigma}_j (t_j - t_{j-1}) $$
   If $y$ exceeds the total integral, clamp $t$ to $t_N$ [G]. If $y \le 0$, return $t_0$ [G].
2. Calculate the cumulative integral up to the start of the identified interval $t_i$:
   $$ C_i = \sum_{j=1}^{i} \hat{\sigma}_j (t_j - t_{j-1}) $$
3. Solve for $t$ using the linear relationship within the interval $[t_i, t_{i+1}]$ [S1, unofficial]. The density is assumed constant at $\hat{\sigma}_i$ [S1, unofficial]. The formula is derived from:
   $$ y = C_i + \hat{\sigma}_i (t - t_i) $$
   Rearranging for $t$:
   $$ t = t_i + \frac{y - C_i}{\hat{\sigma}_i} $$

**Formula:**
The explicit solution for $t$ is:
$$ t = t_i + \frac{y - \sum_{j=1}^{i} \hat{\sigma}_j (t_j - t_{j-1})}{\hat{\sigma}_i} $$
where $\hat{\sigma}_i$ is the density in the interval containing $t$ [S1, unofficial]. (Note: The source text contains a typographical error in the denominator, listing $\sigma_r(\hat{t}_j)$; the correct term is $\sigma_r(\hat{t}_i)$ to match the linear derivation [S1, unofficial].)

**Parameters:**
- Epsilon ($\epsilon$): A small positive constant added to the denominator $\hat{\sigma}_i$ to prevent division by zero or instability when density is near zero [S1, unofficial]. Typical value: $10^{-6}$ or machine epsilon scaled by density range [G].

**Edge Cases and Pitfalls:**
- **Zero Density:** If $\hat{\sigma}_i \approx 0$, the denominator becomes unstable. The implementation must add a small epsilon value to the denominator to improve stability [S1, unofficial].
- **Boundary Conditions:** If $y$ is outside the range $[0, I_{total}]$, the result should be clamped to $[t_0, t_N]$ [G].
- **Precision:** Floating-point errors in the summation $C_i$ can accumulate. Using Kahan summation or precomputed prefix sums can mitigate this [G].

**Pseudocode:**
```python
def piecewise_constant_inverse(t, sigma, y, epsilon=1e-6):
    """
    Compute the ray parameter t for a given cumulative density y
    using piecewise constant density approximation.
    
    Args:
        t: Array of sample positions [t_0, t_1, ..., t_N]
        sigma: Array of densities [sigma_1, ..., sigma_N] for intervals [t_0, t_1], ..., [t_{N-1}, t_N]
        y: Target cumulative density value
        epsilon: Small value to add to denominator for stability
        
    Returns:
        t_out: The computed ray parameter
    """
    n = len(sigma)
    if n == 0:
        return t[0]
    
    # Compute cumulative integrals C[i] = integral from t_0 to t_i
    C = [0.0] * (n + 1)
    for j in range(1, n + 1):
        delta_t = t[j] - t[j-1]
        C[j] = C[j-1] + sigma[j-1] * delta_t
        
    total_integral = C[n]
    
    # Clamp y to valid range [G]
    if y <= 0.0:
        return t[0]
    if y >= total_integral:
        return t[n]
        
    # Find interval index i such that C[i] <= y < C[i+1]
    i = 0
    for j in range(1, n + 1):
        if C[j] > y:
            i = j - 1
            break
            
    # Solve for t in interval [t_i, t_{i+1}] using the linear relationship [S1, unofficial]
    # y = C[i] + sigma[i] * (t - t[i])
    # Add epsilon to denominator for stability when density is near zero [S1, unofficial]
    t_out = t[i] + (y - C[i]) / (sigma[i] + epsilon)
    
    return t_out
```

## Subtopics

### [Inverse CDF Interpolation](7982-inverse-cdf-interpolation.md)
Uses linear interpolation between cumulative weight boundaries rather than assuming constant density within bins, providing smoother sampling distributions. Choose this when higher accuracy in sample placement is needed and the cost of solving a linear interpolation is acceptable [G].

## Operating characteristics
- **Time Complexity:** Not given in the sources. [G] Linear scan is $O(N)$, binary search $O(\log N)$.
- **Memory Complexity:** Not given in the sources. [G] $O(N)$ for cumulative array, $O(1)$ if computed on the fly.
- **Strengths:** Not given in the sources. [G] Simple to implement, computationally inexpensive per sample, explicit closed-form solution.
- **Limitations:** Not given in the sources. [G] Assumes constant density within intervals, which can lead to sampling artifacts if the density varies significantly within an interval.
- **When to use:** Not given in the sources. [G] When performance is critical and the density field is relatively smooth or the sampling rate is high enough that the piecewise constant assumption is reasonable.
- **When not to use:** Not given in the sources. [G] When high accuracy in sample placement is required for highly varying density fields, or when the density is known to vary linearly within intervals.
