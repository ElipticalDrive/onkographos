# Ray Casting with Jittered Sampling

Also called: Jittered Sampling Volume Rendering

## Overview
Ray Casting with Jittered Sampling is a direct volume rendering technique that casts rays through a 3D voxel grid to accumulate color and opacity along the ray path [S1, unofficial]. It distinguishes itself from uniform ray sampling by perturbing sample positions with a pre-computed jitter texture to break up regular grid patterns and reduce aliasing artifacts [S1, unofficial]. Unlike stochastic methods, it uses deterministic offsets stored in a 2D texture rather than runtime random number generation [G].

## How it works

### Inputs and Outputs
**Inputs:**
*   3D Voxel Data Texture: Stores voxel colors and opacities [S1, unofficial].
*   Camera parameters: Projection matrix, ModelView matrix, and camera position [S1, unofficial].
*   Volume parameters: Bounding box extents, translation, and scale [S1, unofficial].
*   Rendering parameters: Number of samples per ray, ray step size, and a lighting computation flag [S1, unofficial].
*   Jitter Texture: A 2D texture storing pre-computed jitter offsets [S1, unofficial].

**Outputs:**
*   Color buffer: Accumulated RGBA color per pixel [S1, unofficial].

### Data Structures

**Voxel Data Texture (`textureIDs[0]`)**
*   **Target:** `GL_TEXTURE_3D` [S1, unofficial].
*   **Format:** `GL_RGBA32F` for floating-point data, `GL_RGBA8` for unsigned byte data, or `GL_COMPRESSED_RGBA_S3TC_DXT5_EXT` if the uncompressed size exceeds 1GB [S1, unofficial].
*   **Content:** Voxel colors and opacities [S1, unofficial].

**Jitter Texture (`textureIDs[1]`)**
*   **Target:** `GL_TEXTURE_2D` [S1, unofficial].
*   **Size:** 32x32 pixels [S1, unofficial].
*   **Content:** 2D jitter offset vectors for sampling [S1, unofficial].

**Geometry**
*   **Structure:** Bounding box composed of 6 faces (front, back, left, right, top, bottom) [S1, unofficial].
*   **Primitive:** `GL_QUADS` [S1, unofficial].
*   **Vertices:** 4 vertices per face, defined by bounding box corners ($x_{min/max}, y_{min/max}, z_{min/max}$) [S1, unofficial].

### Parameters

*   **$N_{samples}$ (`m_numSamples`):** Number of samples per ray.
    *   If voxel count is 0: $N_{samples} = \sqrt{dim_X^2 + dim_Y^2 + dim_Z^2} + 2$ [S1, unofficial].
    *   Clamped to a minimum of 32 [S1, unofficial].
*   **$JitterTexSize$:** Resolution of the jitter texture. Fixed at 32x32 [S1, unofficial].
*   **$RayStepSize$:** Distance between samples along the ray.
    *   Formula: $RayStepSize = \frac{\sqrt{3.0}}{N_{samples}}$ [S1, unofficial].
    *   Normalizes the step size relative to the diagonal of the unit cube [S1, unofficial].
*   **$VolTranslation$:** Bounding box center [S1, unofficial].
*   **$VolScale$:** Bounding box dimensions [S1, unofficial].
*   **$VolExtentMin/Max$:** Bounding box minimum and maximum coordinates [S1, unofficial].

### Algorithm Steps

1.  **Coordinate Transformation Setup:**
    *   Normalize the volume bounding box to a unit cube for shader calculations [S1, unofficial].
    *   Transform $VolExtentMin$, $VolExtentMax$, $CameraPosition$, and $LightPosition$ into this local space using:
        $$coord_{local} = \frac{coord_{world} - VolTranslation}{VolScale} + 0.5$$
        [S1, unofficial]

2.  **Near Plane Pass:**
    *   Draw a near plane quad using a separate shader program (`s_pCameraNearPlaneProg`) [S1, unofficial].
    *   Pass the same transformation matrices and parameters as the main ray caster [S1, unofficial].

3.  **Stencil Test Setup:**
    *   Enable the stencil test [S1, unofficial].
    *   Set the function to `GL_EQUAL` with a reference value of 0 [S1, unofficial].
    *   Set the operation on pass to `GL_INCR` [S1, unofficial].
    *   This ensures only one pixel modifies the color buffer per fragment [S1, unofficial].

4.  **Blending Setup:**
    *   Enable alpha blending [S1, unofficial].
    *   Set blend factors to `GL_ONE` and `GL_ONE_MINUS_SRC_ALPHA` [S1, unofficial].

5.  **Ray Casting Shader Execution:**
    *   For each pixel, cast a ray through the volume [S1, unofficial].
    *   Sample the 3D voxel texture along the ray path [S1, unofficial].
    *   Apply jitter offsets from the 2D jitter texture to sample positions to reduce aliasing [S1, unofficial].
    *   Accumulate color and opacity along the ray using front-to-back compositing [S1, unofficial].
    *   Optionally compute lighting if the `ComputeLighting` flag is set [S1, unofficial].

### Pseudocode

```python
import math

def transform_to_local(coord, vol_translation, vol_scale):
    """Transforms world coordinates to local unit cube space."""
    return [(c - t) / s + 0.5 for c, t, s in zip(coord, vol_translation, vol_scale)]

def sample_jitter(jitter_texture, u, v, jitter_tex_size):
    """Samples a 2D jitter offset from the pre-computed texture."""
    # Normalize UV coordinates to [0, 1) range
    u_norm = (u % jitter_tex_size) / jitter_tex_size
    v_norm = (v % jitter_tex_size) / jitter_tex_size
    # Return a 2D offset vector (dx, dy)
    return jitter_texture[u_norm, v_norm]

def jittered_volume_ray_casting(camera_pos, proj_matrix, model_view_matrix,
                                voxel_texture, jitter_texture, jitter_tex_size,
                                vol_translation, vol_scale, vol_extent_min, vol_extent_max,
                                light_pos, compute_lighting, num_samples):
    """Main ray casting loop for jittered volume rendering."""
    # 1. Coordinate Transformation
    local_extent_min = transform_to_local(vol_extent_min, vol_translation, vol_scale)
    local_extent_max = transform_to_local(vol_extent_max, vol_translation, vol_scale)
    local_camera_pos = transform_to_local(camera_pos, vol_translation, vol_scale)
    local_light_pos = transform_to_local(light_pos, vol_translation, vol_scale)
    
    # 2. Setup Rendering State
    enable_stencil_test()
    set_stencil_function(GL_EQUAL, ref=0)
    set_stencil_op(GL_INCR, GL_KEEP, GL_KEEP)
    enable_alpha_blending()
    set_blend_factors(GL_ONE, GL_ONE_MINUS_SRC_ALPHA)
    
    # 3. Near Plane Pass
    draw_near_plane_quad(proj_matrix, model_view_matrix, local_camera_pos, local_light_pos)
    
    # 4. Ray Casting Loop
    ray_step_size = math.sqrt(3.0) / num_samples
    
    for v in range(height):
        for u in range(width):
            # Generate ray direction from camera to pixel
            ray_dir = generate_ray_direction(u, v, proj_matrix, model_view_matrix, local_camera_pos)
            ray_dir = normalize(ray_dir)
            
            # Initialize accumulation (RGBA color, scalar opacity)
            acc_color = [0.0, 0.0, 0.0, 0.0]
            acc_opacity = 0.0
            
            # Determine ray start and end points in local space
            ray_start = local_camera_pos
            ray_end = [ray_start[i] + ray_dir[i] * distance_to_far_plane for i in range(3)]
            
            # Get jitter offset for this pixel
            jitter_offset = sample_jitter(jitter_texture, u, v, jitter_tex_size)
            
            # Calculate number of steps
            ray_length = math.sqrt(sum((ray_end[i] - ray_start[i])**2 for i in range(3)))
            num_steps = int(ray_length / ray_step_size)
            
            # Sample along ray
            for i in range(num_steps):
                # Apply jitter as an offset to the step index
                t = (i + jitter_offset[0]) * ray_step_size
                sample_pos = [ray_start[i] + ray_dir[i] * t for i in range(3)]
                
                # Check if sample is within volume bounds
                if all(local_extent_min[i] <= sample_pos[i] <= local_extent_max[i] for i in range(3)):
                    # Sample voxel texture
                    voxel_color = sample_3d_texture(voxel_texture, sample_pos)
                    voxel_opacity = voxel_color[3]
                    
                    # Front-to-back compositing
                    weight = voxel_opacity * (1.0 - acc_opacity)
                    acc_color[0] += voxel_color[0] * weight
                    acc_color[1] += voxel_color[1] * weight
                    acc_color[2] += voxel_color[2] * weight
                    acc_color[3] += voxel_color[3] * weight
                    acc_opacity += weight
                    
                    # Early termination if fully opaque
                    if acc_opacity >= 1.0:
                        break
            
            # Write to color buffer
            write_color_buffer(u, v, acc_color)
```

### Edge Cases and Pitfalls

*   **Memory Limit:** If the uncompressed voxel texture size exceeds 1GB, the format is automatically switched to `GL_COMPRESSED_RGBA_S3TC_DXT5_EXT` to fit within GPU memory limits [S1, unofficial].
*   **Empty Volume:** If the voxel data pointer is NULL and no subvolumes exist, a default color LUT is generated with 4 entries (transparent black, red, green, blue) and applied to the volume [S1, unofficial].
*   **Precision:** The coordinate transformation formula $(coord - translation) / scale + 0.5$ assumes consistent units between world coordinates and volume dimensions [S1, unofficial].

## Subtopics

### Stochastic Jittering
Uses runtime random number generation for jitter offsets instead of a pre-computed texture [G].

### Hierarchical Sampling (Inverse CDF Sampling)
Uses hierarchical data structures to sample based on probability distributions, useful for importance sampling [G].

### Uniform Ray Sampling
Samples at fixed intervals without jitter, leading to aliasing artifacts [G].

### Monte Carlo Volume Rendering
Uses stochastic sampling with many samples to reduce noise, often for complex lighting [G].

### Random Jitter with Reprojection
Uses jittered sampling with reprojection techniques for temporal stability in animations [G].

### Importance Sampling for SPH Rendering
Tailored for Smoothed Particle Hydrodynamics data, sampling based on particle density [G].

### Warp-based Sampling
Uses warping techniques to adjust sampling patterns, possibly for adaptive resolution [G].

## Operating characteristics

*   **Time Complexity:** $O(N_{pixels} \times N_{samples})$ per frame [G].
*   **Memory Complexity:** $O(VoxelVolume + JitterTextureSize)$ [G].
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Scales linearly with resolution and number of samples [G].
*   **Strengths:** Reduces aliasing artifacts compared to uniform sampling; deterministic jitter pattern ensures reproducibility [S1, unofficial].
*   **Limitations:** Requires a pre-computed 32x32 jitter texture [S1, unofficial].
*   **When to use:** When aliasing is a concern and deterministic results are preferred [S1, unofficial].
*   **When not to use:** When memory is extremely constrained or when stochastic methods are preferred for other reasons [G].
