# Ray Start Position Jittering

Also called: Ray start jittering

## Overview
Ray start position jittering is a technique used in direct volume ray casting to reduce aliasing artifacts [S1]. It improves rendering quality when using a low number of ray casting steps by varying the starting distance of the rays [S2, unofficial].

**Steps:**
1. Before casting, vary the starting distance of the rays [S2, unofficial].
2. Proceed with the ray casting iteration using the modified starting position [S1][S2, unofficial].
**Formulas:** Not given in the sources.
**Parameters:** Not given in the sources.
**Edge Cases and Pitfalls:** Not given in the sources.
**Pseudocode:**
```python
def jitter_ray_start(ray_origin, ray_direction, step_size, random_generator):
    """
    Applies jitter to the ray start position to reduce slice artifacts.
    
    Args:
        ray_origin: Vector3, the original ray origin.
        ray_direction: Vector3, the normalized ray direction.
        step_size: Float, the distance between ray casting samples.
        random_generator: Function returning a float in [0, 1).
        
    Returns:
        Vector3, the jittered ray origin.
    """
    # The sources do not specify the exact mathematical formula for the offset [G].
    # A standard implementation applies a random fraction of the step size along the ray direction.
    r = random_generator()
    offset = r * step_size
    jittered_origin = ray_origin + (offset * ray_direction)
    return jittered_origin
```

## Background
The technique was employed alongside nearest-neighbor interpolation to reduce aliasing artifacts in a hardware and software system for volumetric display [S1]. It was also documented in a WebGL-based volume rendering tool as a basic technique to improve quality when working with a very low number of ray casting steps [S2, unofficial].
