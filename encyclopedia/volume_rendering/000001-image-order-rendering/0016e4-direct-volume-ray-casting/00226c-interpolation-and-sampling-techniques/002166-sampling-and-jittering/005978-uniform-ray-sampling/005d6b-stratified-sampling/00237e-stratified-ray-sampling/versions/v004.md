# Stratified Ray Sampling

Also called: Jittered Uniform Sampling, Ray Sampling for Acoustic Volume Rendering, Stratified Sample

## Overview
Stratified Ray Sampling is a technique that generates sample points along a camera ray by dividing the ray's depth interval into equal-sized bins and drawing one random sample uniformly from each bin. It solves the problem of aliasing and high variance inherent in pure uniform sampling by ensuring that the entire depth range is covered without gaps, while the random jitter within bins breaks up regular patterns [S4, unofficial][S5]. Unlike [Uniform Ray Sampling](1261-uniform-ray-sampling.md), which places points at fixed intervals, this method introduces controlled noise to improve the statistical properties of the integral estimate [S2, unofficial].

## How it works
**Inputs:**
*   `origins`: Ray origins, shape $[N_{rays}, 3]$.
*   `directions`: Ray directions, shape $[N_{rays}, 3]$.
*   `min_depth` ($u_n$): Near plane distance.
*   `max_depth` ($u_f$): Far plane distance.
*   `n_pts_per_ray` ($N$): Number of samples per ray.
*   `lindisp` (bool): If True, sample linearly in disparity ($1/u$) instead of depth [S4, unofficial].
*   `perturb` (bool): If True, add uniform noise within each bin [S4, unofficial].

**Outputs:**
*   `z_vals`: Sample depths, shape $[N_{rays}, N]$.
*   `sample_points`: 3D coordinates, shape $[N_{rays}, N, 3]$.

**Data Structures:**
*   `z_vals`: A tensor of floating-point values representing the distance from the camera origin along the ray direction for each sample point.

**Steps:**

1.  **Compute Linear Spacing:**
    Generate $N$ evenly spaced values between 0 and 1.
    $$t_{vals} = \text{linspace}(0.0, 1.0, N)$$
    [S4, unofficial]

2.  **Map to Depth Interval:**
    Calculate the depth values $z_{vals}$ based on the `lindisp` flag.
    
    If `lindisp` is False (linear depth):
    $$z_{vals} = u_n (1 - t_{vals}) + u_f t_{vals}$$
    [S4, unofficial]
    
    If `lindisp` is True (linear disparity):
    $$z_{vals} = \frac{1}{\frac{1}{u_n}(1 - t_{vals}) + \frac{1}{u_f}t_{vals}}$$
    [S4, unofficial]
    
    *Note: In the context of acoustic volume rendering, points are sampled directly in the parameter $u$ along the ray direction $\omega$ starting from $p_l$ [S1]. The position of the $m$-th point is:*
    $$p(u_m) = p_l + \left( (u_f - u_n)\frac{m}{N} + u_n \right)\omega$$
    [S1]

3.  **Apply Stratification (Perturbation):**
    If `perturb` is True, add uniform noise to break the regular grid structure. This is done by defining bins and sampling uniformly within them.
    
    a. Compute midpoints between adjacent samples:
    $$mids = 0.5 \times (z_{vals}[:, 1:] + z_{vals}[:, :-1])$$
    [S4, unofficial]
    
    b. Define bin boundaries. The upper bound of the last bin is `max_depth`, and the lower bound of the first bin is `min_depth`.
    $$upper = \text{concat}(mids, z_{vals}[:, -1:])$$
    $$lower = \text{concat}(z_{vals}[:, :1], mids)$$
    [S4, unofficial]
    
    c. Generate random numbers $t_{rand}$ uniformly distributed in $[0, 1]$ with the same shape as $z_{vals}$.
    $$z_{vals} = lower + (upper - lower) \times t_{rand}$$
    [S4, unofficial]
    
    Alternatively, described as partitioning the interval $[t_n, t_f]$ into $N$ evenly-spaced bins and drawing one sample $t_i$ uniformly at random from within the bin boundaries defined by $t_n + \frac{i-1}{N}(t_f - t_n)$ and $t_n + \frac{i}{N}(t_f - t_n)$ [S5].

4.  **Compute 3D Positions:**
    Expand $z_{vals}$ to shape $[N_{rays}, N, 1]$ and multiply by directions, then add origins.
    $$sample\_points = origins + z_{vals} \times directions$$
    [S4, unofficial]
    Or explicitly for the $m$-th point on ray $i$:
    $$P_{i,m} = O_i + z_{i,m} \cdot D_i$$
    [S3, unofficial]

**Parameters:**
*   `n_pts_per_ray` ($N$): Typically 64 for coarse network training [S5].
*   `min_depth`, `max_depth`: Scene-dependent near and far clipping planes.
*   `lindisp`: Often set to True in NeRF implementations to better sample distant objects [S4, unofficial].
*   `perturb`: Typically True during training to improve generalization and reduce overfitting to the grid [S4, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** When `min_depth` is very small or zero, disparity sampling (`lindisp=True`) avoids division by zero issues inherent in $1/u$ if handled carefully, but standard linear depth is safer if near plane is 0.
*   **Boundary Conditions:** The perturbation step must ensure that the final sample does not exceed `max_depth` or fall below `min_depth`. The concatenation logic in step 3b ensures the outer bins are bounded by the actual min/max depths.
*   **Degenerate Input:** If `min_depth` == `max_depth`, the interval has zero width, resulting in all samples being identical.

**Pseudocode:**

```python
import torch

def stratified_ray_sampling(origins, directions, min_depth, max_depth, n_pts_per_ray, lindisp=False, perturb=True):
    """
    Generates stratified samples along rays.
    
    Args:
        origins: Tensor of shape [N_rays, 3]
        directions: Tensor of shape [N_rays, 3]
        min_depth: Float, near plane
        max_depth: Float, far plane
        n_pts_per_ray: Int, number of samples
        lindisp: Bool, sample in disparity space
        perturb: Bool, add uniform noise within bins
        
    Returns:
        z_vals: Tensor of shape [N_rays, n_pts_per_ray]
        sample_points: Tensor of shape [N_rays, n_pts_per_ray, 3]
    """
    # Step 1: Linear spacing in [0, 1]
    t_vals = torch.linspace(0.0, 1.0, n_pts_per_ray, device=origins.device)
    
    # Expand for broadcasting: [1, N]
    t_vals = t_vals.unsqueeze(0)
    
    # Step 2: Map to depth interval
    if lindisp:
        # Linear in disparity: 1/z = (1-near)*(1-t) + (1-far)*t
        # z = 1 / ((1-t)/near + t/far)
        # Handle potential division by zero if near/far are 0? 
        # Standard NeRF assumes near > 0.
        inv_near = 1.0 / min_depth
        inv_far = 1.0 / max_depth
        inv_z_vals = inv_near * (1.0 - t_vals) + inv_far * t_vals
        z_vals = 1.0 / inv_z_vals
    else:
        # Linear in depth
        z_vals = min_depth * (1.0 - t_vals) + max_depth * t_vals
        
    # Expand z_vals to [N_rays, N]
    z_vals = z_vals.expand(origins.shape[0], -1)
    
    # Step 3: Perturbation (Stratification)
    if perturb:
        # Get midpoints between adjacent samples
        # z_vals shape: [N_rays, N]
        # mids shape: [N_rays, N-1]
        mids = 0.5 * (z_vals[:, 1:] + z_vals[:, :-1])
        
        # Define bin boundaries
        # upper: [N_rays, N] -> last element is max_depth
        # lower: [N_rays, N] -> first element is min_depth
        upper = torch.cat([mids, z_vals[:, -1:]], dim=1)
        lower = torch.cat([z_vals[:, :1], mids], dim=1)
        
        # Random uniform in [0, 1]
        t_rand = torch.rand_like(z_vals)
        
        # Sample uniformly within bins
        z_vals = lower + (upper - lower) * t_rand
        
    # Step 4: Compute 3D points
    # directions: [N_rays, 3], z_vals: [N_rays, N]
    # Expand z_vals to [N_rays, N, 1]
    z_vals_expanded = z_vals.unsqueeze(2)
    directions_expanded = directions.unsqueeze(1) # [N_rays, 1, 3]
    
    sample_points = origins.unsqueeze(1) + z_vals_expanded * directions_expanded
    
    return z_vals, sample_points
```

## Subtopics

### [Hierarchical Stratified Sampling](10554-hierarchical-stratified-sampling.md)
Adds an adaptive refinement layer on top of stratified sampling, using initial samples to guide density in subsequent passes.

### [Batch Stratified Sampling](2730-batch-stratified-sampling.md)
Optimizes the stratified sampling process for batched ray processing on GPUs.

### [Local Sampling](5532-local-sampling.md)
Focuses sampling within a local neighborhood rather than the full ray interval.

### [Non-linear (Logarithmic) Sampling](5814-non-linear-logarithmic-sampling.md)
Uses non-linear spacing (e.g., logarithmic) instead of uniform bins, often combined with stratification.

### [Pixel-guided ray sampling](7551-pixel-guided-ray-sampling.md)
Uses pixel-level information to guide the stratification or sampling distribution.

### [Context-based Probability Ray Sampling](7561-context-based-probability-ray-sampling.md)
Uses context to determine probability densities for sampling, potentially replacing uniform bin stratification.

## Operating characteristics
*   **Time Complexity:** $O(N)$ per ray, where $N$ is the number of samples. Generating random numbers and linear interpolation are constant time operations per sample.
*   **Memory Complexity:** $O(N)$ per ray to store the sample depths and coordinates.
*   **Performance:** Significantly reduces variance compared to pure uniform sampling, leading to faster convergence in Monte Carlo integration [S4, unofficial][S5]. It is computationally cheap and easy to parallelize.
*   **Strengths:** Eliminates aliasing artifacts from regular grids; simple to implement; robust.
*   **Limitations:** Does not adapt to scene complexity (unlike hierarchical methods); still requires a fixed number of samples per ray, which may be wasteful in empty space or insufficient in dense regions if $N$ is low.
*   **When to use:** Standard baseline for volume rendering and NeRF training; when computational budget is fixed and scene geometry is unknown or uniform.
*   **When not to use:** When high-frequency details require adaptive sampling (use Hierarchical Stratified Sampling) or when the scene has large empty regions (use Non-linear Sampling).

## Background
Stratified sampling is a fundamental technique in Monte Carlo integration, widely used in computer graphics to reduce variance. In the context of neural volume rendering, it was popularized by the original NeRF paper and subsequent implementations [S4, unofficial]. It is also used in acoustic volume rendering to approximate integrals over ray directions and depths [S1]. The method is a standard component in many volume rendering pipelines, often serving as the "coarse" pass in hierarchical sampling strategies [S5].
