# Stratified Monte Carlo Radiance Estimate

Also called: RVS Stratified Estimate

## Overview
The Stratified Monte Carlo Radiance Estimate is an unbiased radiance estimation technique that reduces variance compared to uniform sampling, particularly effective for degenerate distributions [S1, unofficial]. It sets itself apart from its sibling [Batch Stratified Sampling](2730-batch-stratified-sampling.md) by focusing on the specific integration of radiance along a single ray's path segment using stratified bins, and from [Stratified Ray Sampling](3014-stratified-ray-sampling.md) by operating on the distance parameter $t$ along the ray rather than stratifying the ray origins or directions themselves [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Ray origin $\mathbf{o}$, ray direction $\mathbf{d}$, near clipping plane $t_n$, far clipping plane $t_f$, and number of samples $k$ [S2, unofficial].
*   **Outputs:** Estimated radiance $\hat{C}(\mathbf{r})$ for the ray $\mathbf{r}$ [S1, unofficial].

**Data Structures:**
The method requires storing the bin boundaries and the sampled distances [S3, unofficial]. In implementation, these are often stored in structures like `RayBundle.sample_points` (3D positions) and `RayBundle.sample_lengths` (distances $t_i$) [S2, unofficial].

**Steps:**
1.  **Define Bin Boundaries:** Divide the integration interval $[t_n, t_f]$ into $k$ equal-sized bins [S3, unofficial]. The boundaries $t_i$ for $i=0, \dots, k$ are defined as $t_i = t_n + i \cdot \frac{t_f - t_n}{k}$, where $t_0 = t_n$ and $t_k = t_f$ [S1, S3, unofficial].
2.  **Generate Samples:** For each bin $i$ (where $i=1, \dots, k$), generate a sample $\tau_i$ within the interval $[t_{i-1}, t_i]$ [S1, unofficial].
    *   **Randomized (Unbiased):** Draw a uniform random number $u_i \sim U[0, 1]$ and compute $\tau_i = t_{i-1} + u_i \cdot (t_i - t_{i-1})$ [S3, unofficial].
    *   **Deterministic (Midpoint):** Use the center of the bin $\tau_i = 0.5 \cdot (t_{i-1} + t_i)$ [S3, unofficial].
3.  **Compute 3D Positions:** Calculate the 3D position $\mathbf{p}_i$ for each sample distance $\tau_i$ as $\mathbf{p}_i = \mathbf{o} + \tau_i \mathbf{d}$ [S2, unofficial].
4.  **Evaluate Density and Color:** Evaluate the volume density $\sigma_i$ and color contribution $c_{\mathbf{r}}(\tau_i)$ at each position $\mathbf{p}_i$ [S1, unofficial].
5.  **Accumulate Radiance:** Compute the final radiance estimate by summing the contributions [S1, unofficial]:
    $$ \hat{C}_{\text{IW}}(\mathbf{r}) = \sum_{i=1}^k (t_i - t_{i-1}) c_{\mathbf{r}}(\tau_i) \frac{dF_{\mathbf{r}}}{dt} \bigg|_{t=\tau_i} $$
    where $\frac{dF_{\mathbf{r}}}{dt}$ is the probability density function (PDF) of the distance distribution along the ray [G].

**Pseudocode:**
```python
import random

def stratified_monte_carlo_radiance_estimate(ray_origin, ray_direction, t_near, t_far, num_samples, pdf_func, color_func):
    """
    Computes the stratified Monte Carlo radiance estimate for a single ray.
    
    Args:
        ray_origin: 3D vector (x, y, z)
        ray_direction: 3D vector (x, y, z), assumed normalized
        t_near: float, near clipping plane distance
        t_far: float, far clipping plane distance
        num_samples: int, number of stratified bins k
        pdf_func: function(t) -> float, returns PDF dF/dt at distance t
        color_func: function(t) -> float, returns color contribution c_r(tau) at distance t
        
    Returns:
        float, estimated radiance C(r)
    """
    # Step 1: Define bin boundaries
    bin_width = (t_far - t_near) / num_samples
    t_bounds = [t_near + i * bin_width for i in range(num_samples + 1)]
    
    total_radiance = 0.0
    
    # Step 2-5: Iterate over each bin
    for i in range(1, num_samples + 1):
        t_prev = t_bounds[i-1]
        t_curr = t_bounds[i]
        
        # Step 2: Generate sample tau_i (randomized uniform sampling)
        u_i = random.uniform(0.0, 1.0)
        tau_i = t_prev + u_i * (t_curr - t_prev)
        
        # Step 3: Compute 3D position
        p_i = (
            ray_origin[0] + tau_i * ray_direction[0],
            ray_origin[1] + tau_i * ray_direction[1],
            ray_origin[2] + tau_i * ray_direction[2]
        )
        
        # Step 4: Evaluate color and PDF
        c_i = color_func(tau_i)
        pdf_i = pdf_func(tau_i)
        
        # Step 5: Accumulate radiance
        delta_i = t_curr - t_prev
        contribution = delta_i * c_i * pdf_i
        total_radiance += contribution
        
    return total_radiance
```

**Parameters:**
*   $k$ (num_samples): The number of stratified bins. Typical values vary by scene complexity. In a 'Foggy' field experiment, $k=32$ matched the performance of $k=256$ uniform samples [S1, unofficial]. In a 'Wall' field experiment, only $k=4$ samples were needed to match the baseline [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Degenerate Distributions:** The method is particularly effective for degenerate distributions where uniform sampling performs poorly [S1, unofficial].
*   **Precision:** When $\sigma_i \delta_i$ is very small, $1 - \exp(-\sigma_i \delta_i)$ can suffer from catastrophic cancellation. Use `expm1` or Taylor expansion if necessary [G].
*   **Boundary Conditions:** Ensure $t_n < t_f$ and $k > 0$ [G]. If $t_n = t_f$, the interval is empty and radiance is 0 [G].

## Subtopics

### [Antithetic Sampling](7196-antithetic-sampling.md)
Antithetic sampling is a variance reduction technique for estimating the derivative of a BSDF with respect to scene parameters when the integrand approximates an odd function. It exploits the symmetry of Normal Distribution Functions (NDFs) to make the derivative term an odd function, allowing paired samples to cancel out noise. It sets itself apart from general stratified sampling by targeting the specific symmetry of microfacet derivatives, whereas its sibling [Decomposed sampling](1374-decomposed-sampling.md) addresses cases where derivatives are even functions.

### Ratio Estimator with Equidistant Sampling (REES)
A stochastic integrator that distributes samples at equal distance, jittered by noise, combined with a ratio estimator using analytic unoccluded radiance [S5]. It uses the basic framework of stratified sampling paired with analytic unoccluded radiance computation [S5]. REES yields better convergence in unoccluded parts of the scene but leads to overall poor distribution of samples in occluded parts compared to MCWVDS [S5].

### Sample Trimmed Mean Estimator
A technique to reduce variance from rare outliers in importance sampling by using a sample trimmed mean over each pixel, discarding extreme samples [S6]. It stores multiple independent, intermediate (low sample count) results [S6]. For each pixel, it discards the top 1-5% and bottom 1-5% of samples, then averages the remaining samples [S6]. This trades a slight bias for a large reduction in variance, reducing overall error [S6]. The estimator remains consistent because the distribution approaches Gaussian for large sample counts, making the bias zero for symmetric distributions [S6].

## Background
Stratified sampling is a well-known technique used in Monte Carlo rendering to reduce variance [S4]. The specific application to radiance estimation in volume rendering, referred to as the RVS Stratified Estimate, was detailed in research on differentiable rendering with reparameterized volume sampling [S1, unofficial]. The method builds on the principle of dividing the integration interval into bins to ensure better coverage of the domain compared to purely random uniform sampling [S1, unofficial].
