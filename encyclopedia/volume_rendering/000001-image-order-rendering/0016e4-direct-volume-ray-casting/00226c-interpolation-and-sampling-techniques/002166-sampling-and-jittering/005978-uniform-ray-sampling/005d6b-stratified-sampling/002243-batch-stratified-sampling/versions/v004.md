# Batch Stratified Sampling

Also called: StratifiedSampler, Uniform Stratified Sampling

## Overview
Batch Stratified Sampling partitions the ray depth interval $[t_n, t_f]$ into $N_c$ evenly-spaced bins and perturbs sample positions within each bin to reduce aliasing artifacts during volume rendering [S1, unofficial]. It builds on [Stratified Sampling](17389-stratified-sampling.md) by vectorizing the bin boundary and sampling operations to process multiple rays simultaneously [S3, unofficial]. Unlike pure uniform sampling, it ensures one sample per stratum, avoiding clustering and gaps [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Ray origins $\mathbf{o}$ (shape $[R, 3]$), ray directions $\mathbf{d}$ (shape $[R, 3]$), near plane $t_n$ (scalar or $[R]$), far plane $t_f$ (scalar or $[R]$), number of bins $N_c$ (integer), and a boolean flag `perturb` (default `True`) [S1, S3, unofficial].
*   **Outputs:** Sample depths $\tau$ (shape $(*, N_c)$) and 3D positions $\mathbf{p}$ (shape $(*, N_c, 3)$) [S1, S3, unofficial].

**Data Structures:**
*   Tensors store all values; depths are stored as floating-point values [S1, S3, unofficial].

**Steps:**
1.  **Normalize and Expand Bounds:** If $t_n$ and $t_f$ are scalars or 1D arrays, they are broadcast or reshaped to match the batch dimension $R$ with shape $[R, 1]$ [S3, unofficial].
2.  **Compute Normalized Boundaries:** Generate $N_c + 1$ evenly spaced values $u_i$ in the interval $[0, 1]$ using linear spacing [S3, unofficial].
3.  **Interpolate to World Space:** Map the normalized boundaries to the ray-specific near and far planes. For each ray $r$, the boundaries $t^{(r)}_i$ are computed as $t^{(r)}_i = t_n^{(r)} \cdot (1 - u_i) + t_f^{(r)} \cdot u_i$, yielding a tensor of shape $(*, N_c + 1)$ [S3, unofficial].
4.  **Compute Bin Midpoints:** Calculate the midpoints between adjacent boundaries. For $i=0, \dots, N_c-1$, $m^{(r)}_i = 0.5 \cdot (t^{(r)}_i + t^{(r)}_{i+1})$, yielding a tensor of shape $(*, N_c)$ [S3, unofficial].
5.  **Define Interval Bounds:** Construct lower bounds $L^{(r)} = [t^{(r)}_0, m^{(r)}_0, \dots, m^{(r)}_{N_c-1}]$ and upper bounds $U^{(r)} = [m^{(r)}_0, \dots, m^{(r)}_{N_c-1}, t^{(r)}_{N_c}]$, both of shape $(*, N_c)$ [S3, unofficial].
6.  **Sample Within Bins:** Generate random uniform numbers $v^{(r)}_i \sim U[0, 1]$ for each ray and bin [S1, unofficial]. If `perturb` is `True`, compute the sample depth $\tau^{(r)}_i = L^{(r)}_i + v^{(r)}_i \cdot (U^{(r)}_i - L^{(r)}_i)$ [S1, S3, unofficial]. If `perturb` is `False`, use the midpoint $\tau^{(r)}_i = 0.5 \cdot (L^{(r)}_i + U^{(r)}_i)$ [S3, unofficial].
7.  **Compute 3D Positions:** For each sample, compute the 3D position $\mathbf{p}^{(r)}_i = \mathbf{o}^{(r)} + \tau^{(r)}_i \cdot \mathbf{d}^{(r)}$ [S1, unofficial].

**Pseudocode:**
```python
import torch

def batch_stratified_sampling(rays_o, rays_d, near, far, num_samples, perturb=True):
    """
    rays_o: [R, 3]
    rays_d: [R, 3]
    near: scalar or [R]
    far: scalar or [R]
    num_samples: int (N_c)
    perturb: bool
    """
    # 1. Normalize and Expand Bounds
    if near.ndim == 0:
        near = near.expand(rays_o.shape[0], 1)
    else:
        near = near.unsqueeze(-1)
        
    if far.ndim == 0:
        far = far.expand(rays_o.shape[0], 1)
    else:
        far = far.unsqueeze(-1)
        
    # 2. Compute Normalized Boundaries in [0, 1]
    u = torch.linspace(0, 1, num_samples + 1, device=rays_o.device)
    
    # 3. Interpolate to World Space
    t_vals = near * (1.0 - u) + far * u  # Shape: [R, N_c + 1]
    
    # 4. Compute Bin Midpoints
    mids = 0.5 * (t_vals[:, :-1] + t_vals[:, 1:])  # Shape: [R, N_c]
    
    # 5. Define Interval Bounds
    lower = torch.cat([t_vals[:, :1], mids], dim=-1)  # Shape: [R, N_c]
    upper = torch.cat([mids, t_vals[:, -1:]], dim=-1)  # Shape: [R, N_c]
    
    # 6. Sample Within Bins
    if perturb:
        rand_vals = torch.rand_like(lower)
        z_vals = lower + (upper - lower) * rand_vals
    else:
        z_vals = 0.5 * (lower + upper)
        
    # 7. Compute 3D Positions
    rays_o_exp = rays_o.unsqueeze(1)  # [R, 1, 3]
    rays_d_exp = rays_d.unsqueeze(1)  # [R, 1, 3]
    z_vals_exp = z_vals.unsqueeze(2)  # [R, N_c, 1]
    
    pts = rays_o_exp + z_vals_exp * rays_d_exp  # [R, N_c, 3]
    
    return z_vals, pts
```

**Parameters:**
*   `num_samples` ($N_c$): The number of stratified bins. Typical values range from 32 to 128 in neural rendering pipelines [S1, S4, unofficial].
*   `perturb`: Boolean flag. `True` for unbiased randomized sampling, `False` for deterministic midpoint sampling [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Precision:** When $t_n \approx t_f$, the bin width becomes very small, potentially leading to numerical instability or duplicate samples [G]. A small epsilon check or clamping of the bin width may be required.
*   **Boundary Conditions:** The method assumes $t_n < t_f$ [G]. If $t_n \ge t_f$, the interval is invalid and the implementation should validate this input.
*   **Batch Dimensions:** The method requires consistent batch dimensions for `rays_o`, `rays_d`, `near`, and `far` [S3, unofficial]. Mismatched shapes will cause broadcasting errors.

## Subtopics

### [Jittered Sampling](2870-jittered-sampling.md)
Generates a regular grid of samples per pixel with independent uniform random offsets within each grid cell to reduce aliasing while maintaining stratification. It enhances supersampling by introducing random offsets to ray origins within the pixel grid, distributing samples more evenly and reducing patterned artifacts compared to uniform grids. Unlike standard uniform ray sampling, it breaks the rigid alignment of sample positions, which prevents coherent aliasing patterns in volume rendering.

### Adaptive Stratified Sampling
A stratified sampling method where the unit interval is partitioned into $c$ strata based on non-zero bins of a predicted distribution, and samples are allocated unevenly to strata based on the predicted probability mass to handle multimodal distributions [S5]. It allocates $\lfloor s/c \rfloor$ samples to each stratum and distributes the remainder to bins with maximal predicted probability [S5]. It clips the distance between adjacent intra-stratum samples to the bin width to prevent outsized contributions from endpoints [S5]. It is biased if the sample budget $s < c$, but implementations ensure $s \ge c$ via regularization [S5]. Typical sample budget $s$ is 17.6 samples per ray at high resolutions [S5].

## Operating characteristics
*   **Time and Memory Complexity:** Not given in the sources.
*   **Performance:** In neural rendering benchmarks, hierarchical sampling with $N_c=64$ coarse and $N_f=128$ fine samples per ray is commonly used, achieving high PSNR with mixed precision on CUDA [S1, unofficial].
*   **Strengths:** Reduces aliasing artifacts compared to uniform sampling; supports efficient batch processing [S1, unofficial].
*   **Limitations:** Does not adapt to scene complexity; may waste samples in empty space if not combined with hierarchical or adaptive strategies [S1, unofficial].
*   **When to Use:** Standard direct volume rendering or neural rendering where uniform coverage is desired and computational efficiency is key [S1, unofficial].
*   **When Not to Use:** Scenes with high variance or complex geometry where adaptive sampling is needed [S5].
