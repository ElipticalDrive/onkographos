# Stratified Ray Sampling

Also called: Jittered Uniform Sampling

## Overview
Stratified Ray Sampling is a technique that generates sample points along a camera ray by dividing the depth interval into bins and drawing one random sample from each bin. It solves the problem of aliasing and high variance inherent in purely uniform or purely random sampling by ensuring every part of the ray's depth range is covered while introducing controlled jitter [S3, unofficial]. Unlike [Uniform Ray Sampling](1261-uniform-ray-sampling.md), which places points at fixed intervals, this method adds noise to break up regular patterns, and unlike [Non-linear (Logarithmic) Sampling](5814-non-linear-logarithmic-sampling.md), it maintains uniform spacing in the specified domain (depth or disparity) rather than adapting to scene geometry [S3, unofficial].

## How it works
**Inputs:**
- `origins`: Ray origins, shape $[N_{rays}, 3]$.
- `directions`: Ray directions, shape $[N_{rays}, 3]$.
- `min_depth` (near): Scalar, start of sampling interval.
- `max_depth` (far): Scalar, end of sampling interval.
- `n_pts_per_ray` ($N$): Integer, number of samples per ray.
- `lindisp`: Boolean, if `True`, sample linearly in disparity ($1/z$); if `False`, sample linearly in depth ($z$) [S3, unofficial].
- `perturb`: Boolean, if `True`, add uniform noise within bins; if `False`, use deterministic midpoints or fixed offsets [S3, unofficial].

**Outputs:**
- `z_vals`: Sample depths, shape $[N_{rays}, N]$.
- `sample_points`: 3D coordinates, shape $[N_{rays}, N, 3]$.

**Data Structures:**
- `z_vals`: Tensor of floats.
- `sample_points`: Tensor of floats.

**Steps:**
1. **Generate Base Depths:**
   Compute $N$ evenly spaced values in the interval $[0, 1]$:
   $$t_{vals} = \text{linspace}(0.0, 1.0, N)$$
   [S3, unofficial]

2. **Map to Depth/Disparity:**
   If `lindisp` is `True`, map $t_{vals}$ to disparity space and invert to get depth:
   $$z_{vals} = \frac{1.0}{\frac{1.0}{\text{min\_depth}}(1.0 - t_{vals}) + \frac{1.0}{\text{max\_depth}}t_{vals}}$$
   Otherwise, map linearly in depth:
   $$z_{vals} = \text{min\_depth}(1.0 - t_{vals}) + \text{max\_depth}t_{vals}$$
   [S3, unofficial]

3. **Stratification (Jittering):**
   If `perturb` is `True`, divide the interval into $N$ bins and sample uniformly within each bin:
   - Compute midpoints between adjacent samples:
     $$mids = 0.5 \times (z_{vals}[:, 1:] + z_{vals}[:, :-1])$$
   - Define bin boundaries:
     $$upper = \text{concat}(mids, z_{vals}[:, -1:])$$
     $$lower = \text{concat}(z_{vals}[:, :1], mids)$$
   - Generate random noise $t_{rand}$ uniformly distributed in $[0, 1]$ with shape $[N_{rays}, N]$:
     $$t_{rand} = \text{rand}([N_{rays}, N])$$
   - Compute final stratified depths:
     $$z_{vals} = lower + (upper - lower) \times t_{rand}$$
   [S3, unofficial]
   
   If `perturb` is `False`, the deterministic $z_{vals}$ from Step 2 are used directly (or potentially shifted to bin centers, though the source implies the unperturbed case uses the linear spacing directly or via the same formula with $t_{rand}=0.5$ implicitly, but standard stratified sampling usually implies the jittered version when "jittered" is in the alias. The source [S3, unofficial] explicitly links `perturb` to the jittering logic).

4. **Compute 3D Positions:**
   Expand dimensions to allow broadcasting:
   $$sample\_points = origins[:, None, :] + directions[:, None, :] \times z_{vals}[:, :, None]$$
   [S3, unofficial]

**Parameters:**
- `n_pts_per_ray`: Typical values range from 64 to 128 in NeRF implementations [S3, unofficial].
- `min_depth`, `max_depth`: Scene-dependent. Often determined by bounding box or near/far plane settings.
- `lindisp`: Often `True` for scenes with large depth variations to better sample distant objects [S3, unofficial].
- `perturb`: Often `True` during training to reduce overfitting to specific sample positions [S1, S3, unofficial].

**Edge Cases:**
- **Zero Depth:** If `min_depth` is 0, disparity sampling ($1/z$) becomes undefined. Ensure `min_depth > 0` when `lindisp` is `True` [S3, unofficial].
- **Precision:** Using `float32` may cause jittering artifacts if the depth range is very large; `float64` may be required for high-precision scenes [G].

## Operating characteristics
- **Time Complexity:** $O(N_{rays} \times N)$ for generating samples and positions. The jittering step adds a constant factor for random number generation.
- **Memory Complexity:** $O(N_{rays} \times N)$ to store `z_vals` and `sample_points`.
- **Performance:** Reduces aliasing compared to uniform sampling without the variance of pure Monte Carlo. It is computationally cheap and deterministic (if `perturb=False`) or pseudo-deterministic.
- **Strengths:** Simple to implement, effective at breaking up regular aliasing patterns, works well as a baseline for more complex sampling strategies.
- **Limitations:** Does not adapt to scene content; samples may be wasted in empty space or insufficient in dense regions.
- **When to use:** As a default sampling strategy for volume rendering and NeRFs when no prior knowledge of scene density is available.
- **When not to use:** When high-frequency details require adaptive sampling or when computational budget is extremely tight and uniform sampling suffices.

## Background
Stratified sampling is a classic variance reduction technique in Monte Carlo integration. In the context of neural volume rendering, it was popularized by NeRF (Neural Radiance Fields) to improve training stability and reconstruction quality [S3, unofficial]. The addition of uniform noise (jittering) helps prevent the network from overfitting to the specific grid of sample points [S1, unofficial]. It builds on [Uniform Ray Sampling](1261-uniform-ray-sampling.md) by introducing randomness within structured bins.
