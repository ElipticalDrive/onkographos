# Depth-guided ray sampling

Also called: Confidence and Depth-Guided Sampling, Depth Prior Sampling, Pd sampling

## Overview
Depth-guided ray sampling is a ray sampling strategy that uses depth information to concentrate sample points near geometric boundaries and object surfaces [S1, S2]. It complements pixel-guided sampling by targeting areas with abrupt depth changes rather than color variation [S2]. The method addresses the inefficiency of uniform sampling, which often misses object surfaces and degrades rendering quality [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Depth probability volume $P_i(u, v)$ or per-view depth estimates $D_j(p)$ [S1, S2]; ray origin $o$ and direction $g$ [S1]; near plane $e_n$ and far plane $e_f$ [S1]; total sample count $M$ [S1]; neighborhood size $n$ [S2]; fusion weight $\beta$ [S2].
*   **Outputs:** A set of $M$ sample distances $e_m$ along the ray [S1].

**Data Structures:**
*   **Depth Probability Volume:** A 3D array $P_i(u, v)$ storing the probability of depth at pixel $(u, v)$ for each discrete depth plane $L_i$ [S2].
*   **Expected Depth Map:** A 2D array $D(u, v)$ storing the expected depth value per pixel [S2].
*   **Sampling Probability Map:** A 2D array $P'_d(u, v)$ storing the normalized standard deviation of depth values in local neighborhoods [S2].
*   **Confidence Range:** A 1D interval $\hat{U}(p) = [\hat{D}(p) - \hat{S}(p), \hat{D}(p) + \hat{S}(p)]$ defining the high-probability depth region for pixel $p$ [S1].

**Steps:**

1.  **Compute Expected Depth:** Calculate the expected depth $D(u, v)$ by summing the products of depth probabilities and their corresponding plane distances [S2]:
    $$D(u, v) = \sum_{i=1}^{N_d} P_i(u, v) \cdot L_i$$
    where $N_d$ is the number of depth planes and $L_i \in [L_{\min}, L_{\max}]$ [S2].

2.  **Compute Depth Standard Deviation:** Calculate the standard deviation of depth values within an $n \times n$ neighborhood centered at $(u, v)$ to form the sampling probability map [S2]:
    $$P_d(u, v) = \sqrt{\frac{1}{K} \sum_{x', y'} [D(x', y') - \bar{D}]^2}$$
    where $\bar{D}$ is the mean depth in the neighborhood, $(x', y')$ iterates over valid neighborhood pixels, and $K$ is the actual number of pixels in the patch (accounting for image boundaries) [S2].

3.  **Normalize Probability:** Apply min-max normalization to $P_d(u, v)$ to produce $P'_d(u, v)$, preventing underfitting for rays in low-variance regions [S2].

4.  **Calculate Confidence Interval (Alternative Formulation):** In multi-view stereo contexts, compute the standard deviation $\hat{S}(p)$ directly from depth estimates and their confidence weights $P_j(p)$ [S1]:
    $$\hat{S}(p) = \sqrt{\sum_{j=1}^{J} P_j(p) (D_j(p) - \hat{D}(p))^2}$$
    where $J$ is the number of views/planes, $P_j(p)$ are confidence weights, and $D_j(p)$ are depth estimates from those views [S1]. The confidence range is $\hat{U}(p) = [\hat{D}(p) - \hat{S}(p), \hat{D}(p) + \hat{S}(p)]$ [S1].

5.  **Fuse Probabilities (Optional):** Combine the depth-guided probability $P'_d(u, v)$ with pixel-guided probability $P'_c(u, v)$ using weight $\beta$ [S2]:
    $$P_{\text{samp}}(u, v) = \beta P'_c(u, v) + (1 - \beta) P'_d(u, v)$$
    [S2].

6.  **Sample Points:** Distribute the $M$ sample distances along the ray $r_p = o + e g$ [S1]:
    *   Place half of the $M$ points uniformly between $e_n$ and $e_f$ [S1].
    *   Place the second half of the points uniformly within the clamped confidence range $[\max(e_n, \hat{D}(p) - \hat{S}(p)), \min(e_f, \hat{D}(p) + \hat{S}(p))]$ [S1].

**Pseudocode:**

```python
import math

def depth_guided_sampling(D, n, M, e_n, e_f, o, g, beta=None, P_c=None):
    """
    D: 2D list of floats, expected depth map [H, W]
    n: int, neighborhood size for standard deviation
    M: int, total number of samples per ray
    e_n: float, near plane distance
    e_f: float, far plane distance
    o: list of 3 floats, ray origin
    g: list of 3 floats, ray direction
    beta: float, fusion weight (optional)
    P_c: 2D list of floats, normalized pixel-guided probability (optional)
    Returns: list of 3D points along the ray
    """
    H = len(D)
    W = len(D[0])
    
    # Step 2: Compute depth standard deviation P_d(u, v)
    P_d = [[0.0] * W for _ in range(H)]
    for u in range(H):
        for v in range(W):
            y_start = max(0, u - n // 2)
            y_end = min(H, u + n // 2 + 1)
            x_start = max(0, v - n // 2)
            x_end = min(W, v + n // 2 + 1)
            
            patch = [D[r][c] for r in range(y_start, y_end) for c in range(x_start, x_end)]
            K = len(patch)
            mean_val = sum(patch) / K
            var_val = sum((x - mean_val) ** 2 for x in patch) / K
            P_d[u][v] = math.sqrt(var_val)
            
    # Step 3: Normalize P_d to P_prime_d
    min_val = min(min(row) for row in P_d)
    max_val = max(max(row) for row in P_d)
    range_val = max_val - min_val
    P_prime_d = [[(P_d[u][v] - min_val) / range_val if range_val > 1e-8 else 0.0 for v in range(W)] for u in range(H)]
    
    # Step 5: Fuse probabilities if beta is provided
    if beta is not None and P_c is not None:
        P_samp = [[beta * P_c[u][v] + (1 - beta) * P_prime_d[u][v] for v in range(W)] for u in range(H)]
    else:
        P_samp = P_prime_d
        
    # Step 6: Sample points for a single ray (using center pixel as example)
    u_center, v_center = H // 2, W // 2
    D_hat = D[u_center][v_center]
    S_hat = P_d[u_center][v_center]
    
    half_M = M // 2
    e_uniform = [e_n + (e_f - e_n) * (m / (half_M - 1)) for m in range(half_M)]
    
    e_near = max(e_n, D_hat - S_hat)
    e_far = min(e_f, D_hat + S_hat)
    if e_near >= e_far:
        e_guided = [e_n + (e_f - e_n) * (m / (M - half_M - 1)) for m in range(M - half_M)]
    else:
        e_guided = [e_near + (e_far - e_near) * (m / (M - half_M - 1)) for m in range(M - half_M)]
        
    e_samples = e_uniform + e_guided
    points = [[o[0] + e * g[0], o[1] + e * g[1], o[2] + e * g[2]] for e in e_samples]
    return points
```

**Parameters:**
*   $n$: Neighborhood size for standard deviation calculation. Typical value not given in the sources.
*   $M$: Number of sample points per ray. Typical value not given in the sources.
*   $\beta$: Fusion weight for pixel-guided sampling. Typical value not given in the sources.

**Edge Cases and Pitfalls:**
*   **Boundary Conditions:** At image borders, the $n \times n$ neighborhood is truncated, so the variance divisor must be the actual patch area $K$ rather than $n^2$ [S2].
*   **Invalid Confidence Range:** If $\hat{U}(p)$ falls outside $[e_n, e_f]$ or becomes empty due to precision limits, the range must be clamped or fallback to uniform sampling [S1].
*   **Precision:** Small $N_d$ or quantized depth probabilities can introduce discretization errors in $D(u, v)$ and $\hat{S}(p)$ [S2].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Concentrates samples near geometric boundaries and object surfaces, improving reconstruction quality in depth-ambiguous regions [S1, S2].
*   **Limitations:** Performance degrades if the underlying depth estimation network produces inaccurate probabilities or confidence weights [S1, S2].
*   **When to Use:** When reliable depth priors are available and geometric accuracy is prioritized over color variation [S1, S2].
*   **When Not to Use:** When depth estimation is unreliable or when color/texture variation better indicates sampling importance [S1, S2].

## Background
Depth-guided ray sampling was introduced to improve neural volume rendering and multi-view stereo reconstruction [S1, S2]. It builds on the ENeRF coarse-to-fine depth prediction pipeline to generate depth probability volumes [S2]. The method was proposed to solve the inefficiency of uniform NeRF sampling, which fails to concentrate points on object surfaces and reduces rendering quality [S1]. It is frequently combined with pixel-guided sampling via weighted fusion during training [S2].
