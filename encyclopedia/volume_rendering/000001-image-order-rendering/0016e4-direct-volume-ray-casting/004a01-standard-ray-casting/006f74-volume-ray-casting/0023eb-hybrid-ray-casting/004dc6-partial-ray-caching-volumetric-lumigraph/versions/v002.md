# Partial Ray Caching (Volumetric Lumigraph)

Also called: Intermediate Image Ray Casting, Lightfield Extension, Volumetric Lumigraph, Warping Ray Casting

## Overview
Partial Ray Caching accelerates volume rendering by decomposing the volume integral into segments, storing composited color and opacity for partial rays, and re-combining them for novel viewpoints near the original one to save integration cost [S1, unofficial][S2, book]. Unlike static lumigraph or lightfield methods, this approach is dynamically computed, though it can also be used statically for volumetric-style lumigraph rendering [S2, book]. It serves as a volumetric extension of the lumigraph [S1, unofficial][S2, book].

## How it works
**Inputs:** Volumetric dataset, initial view direction $V_a$, target novel view direction $V_b$ (within a limited view cone).
**Outputs:** Rendered image for view $V_b$.

**Data Structures:**
1.  **Slab Images:** A stack of depth-layered images. Each image corresponds to a slab of the volume.
2.  **Partial Ray Data:** Stored within the slab images, containing composited color ($C$) and opacity ($\alpha$) for each ray segment.
3.  **Coarse Polygonal Mesh:** Computed on the fly for each layer to approximate the underlying object geometry [S1, unofficial][S2, book].

**Steps:**
1.  **Decomposition:** Decompose the volume into slabs [S2, book].
2.  **Initial Rendering:** Render each slab into an image from the initial view direction $V_a$, storing the partial ray integrals (composited color and opacity) [S1, unofficial][S2, book].
3.  **Mesh Generation:** Compute a coarse polygonal mesh on the fly for each layer to approximate the underlying object [S1, unofficial][S2, book].
4.  **Warping and Composition:** For a novel viewpoint $V_b$:
    *   Map the stored slab images onto the coarse polygonal meshes [S1, unofficial][S2, book].
    *   Use interpolation to obtain partial integrals at non-grid positions when combining partial rays for the new view direction $V_b$ [S2, book].
    *   Composite the billboard images (slab images) for the desired view $V_b$ [S2, book].
    *   Re-combine partial rays into complete rays for the new image [S1, unofficial].

**Parameters:**
*   **View Cone:** The method is effective for viewpoints within a specific view cone. Mueller et al. rendered warped and composited images from novel viewpoints within a 30° view cone [S2, book].

**Edge Cases and Pitfalls:**
*   **Gaps:** Gaps may quickly emerge when the layers are kept planar when rendering from novel viewpoints [S2, book]. This is mitigated by computing a coarse polygonal mesh for each layer [S1, unofficial][S2, book].

**Pseudocode:**
```python
def render_partial_ray_cache(volume, initial_view, target_view, view_cone_angle=30.0):
    """
    Renders a volume using partial ray caching.
    
    Args:
        volume: The volumetric dataset.
        initial_view: The view direction V_a used for caching.
        target_view: The novel view direction V_b.
        view_cone_angle: Maximum angle deviation from initial_view allowed.
        
    Returns:
        Rendered image for target_view.
    """
    # Check if target view is within the valid view cone
    if angle_between(initial_view, target_view) > view_cone_angle:
        raise ValueError("Target view is outside the valid view cone.")

    # Step 1: Decompose volume into slabs
    slabs = decompose_volume_into_slabs(volume)
    
    # Step 2: Render each slab from initial_view, storing partial integrals
    # Each slab image stores composited color and opacity for partial rays
    slab_images = []
    for slab in slabs:
        # Render slab from initial_view
        # Store partial ray integrals (color C, opacity alpha) in the image
        img = render_slab(slab, initial_view)
        slab_images.append(img)
        
    # Step 3: Compute coarse polygonal mesh for each layer
    # This prevents gaps when warping
    meshes = []
    for i, slab in enumerate(slabs):
        # Approximate underlying object geometry for this slab
        mesh = compute_coarse_mesh(slab)
        meshes.append(mesh)
        
    # Step 4: Render for target_view by warping and composing
    # Initialize output image
    output_image = create_empty_image()
    
    # Composite slab images for the new view
    for i, slab_img in enumerate(slab_images):
        mesh = meshes[i]
        
        # Warp the slab image onto the mesh for the target_view
        # Use interpolation to obtain partial integrals at non-grid positions
        warped_img = warp_image_onto_mesh(slab_img, mesh, target_view)
        
        # Composite the warped image into the output
        # Standard alpha compositing
        output_image = composite(output_image, warped_img)
        
    return output_image
```

## Operating characteristics
*   **Performance:** Saves the cost for fully integrating all rays for each new viewpoint, reducing it to the expense of compositing a few partial segments per ray, which is much lower [S1, unofficial][S2, book].
*   **Hardware:** Can be rendered using standard graphics hardware [S1, unofficial][S2, book].
*   **Limitations:** Limited to viewpoints near the original one (e.g., within a 30° view cone) [S2, book]. Gaps may emerge if layers are kept planar [S2, book].
*   **Usage:** Suitable for volume rendering at great perspective distortions, such as in virtual endoscopy applications [S2, book].

## Background
*   **Origin:** The method falls into the domain of image-based rendering (IBR) [S1, unofficial][S2, book]. It is a volumetric extension of the lumigraph [S1, unofficial][S2, book] or lightfield [S1, unofficial][S2, book], albeit dynamically computed.
*   **Development:**
    *   Brady et al. exploited this idea for volume rendering at great perspective distortions, such as in virtual endoscopy applications [S1, unofficial][S2, book].
    *   Mueller et al. stored the rays in the form of a stack of depth-layered images and rendered these images warped and composited from novel viewpoints within a 30° view cone, using standard graphics hardware [S1, unofficial][S2, book].
*   **Alternatives:** An alternative method that uses a precomputed triangle mesh to achieve similar goals for iso-surface volume rendering was proposed by Chen et al. [S1, unofficial][S2, book]. Yagel and Shi warped complete images to nearby viewpoints, aided by a depth buffer [S1, unofficial][S2, book].
