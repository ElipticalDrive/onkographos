# Monte Carlo Path Tracing for Volume Rendering

Also called: MCSRender, Monte Carlo Scattering Rendering

## Overview
Monte Carlo Path Tracing for Volume Rendering (MCSRender) is a stochastic method that simulates light transport within participating media by tracing random paths through the volume, calculating scattering events and transmittance along the way [S1, unofficial]. Unlike fixed-step ray casting, it uses distance sampling to determine scattering locations based on optical thickness, allowing for more accurate handling of heterogeneous media and complex lighting interactions [S1, unofficial]. It distinguishes itself from sibling methods by employing a frame-by-frame exponential moving average accumulation to converge to the final image, rather than a single-pass deterministic integration [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Input:** Camera parameters (MVP matrix), volume data (3D texture), transfer function, environment map (for lighting), and uniform parameters ($\sigma_{max}$, $\alpha_{correction}$, $\vec{u}_{scattering}$, $\Delta offset$).
- **Output:** Accumulated color image $C_{final}$ and a transient frame buffer $C_{frame}$ [S1, unofficial].

**Data Structures:**
- **Volume Texture:** 3D texture storing scalar density values.
- **Environment Map:** 2D texture storing light source colors/intensities.
- **Accumulator Buffer:** Framebuffer storing the running average color $C_{acc}$ [S1, unofficial].
- **Frame Buffer:** Framebuffer storing the current frame's contribution $C_{frame}$ [S1, unofficial].

**Parameters:**
- $\sigma_{max}$: Maximum scattering coefficient used for distance sampling [S1, unofficial].
- $\alpha_{correction}$: Correction factor applied to opacity values from the transfer function [S1, unofficial].
- $\vec{u}_{scattering}$: Uniform direction vector for secondary ray scattering [S1, unofficial].
- $\Delta offset$: Uniform float used in random seed generation to prevent banding [S1, unofficial].
- $N_{inv}$: Inverse of the current frame number ($1/N$) for accumulation [S1, unofficial].

**Algorithm Steps:**

1.  **Ray Generation:**
    For each pixel, unproject the screen position using the inverse MVP matrix to obtain the ray origin $\vec{O}$ and a point on the far plane $\vec{P}_{far}$ [S1, unofficial]. Define the ray direction $\vec{D} = \vec{P}_{far} - \vec{O}$ and normalize it.

2.  **Bounding Box Intersection:**
    Intersect the ray with the volume's axis-aligned bounding box (AABB) to find entry $t_{start}$ and exit $t_{end}$ distances [S1, unofficial]. If $t_{start} \ge t_{end}$, the ray misses the volume; sample the environment map at direction $\vec{D}$ and output as color [S1, unofficial].

3.  **Initialization:**
    Calculate the maximum distance within the volume: $d_{max} = t_{end} - t_{start}$ [S1, unofficial].
    Initialize the current position $\vec{P}_{curr} = \vec{O} + t_{start}\vec{D}$ [S1, unofficial].
    Initialize the accumulated color $C_{frame} = \vec{0}$ [S1, unofficial].
    Generate a random seed: $\vec{S} = \vec{P}_{curr} + \text{rand}(\vec{u}_{offset})$ [S1, unofficial].

4.  **Path Tracing Loop:**
    While $\vec{P}_{curr}$ is within the volume bounds:
    
    a. **Distance Sampling:**
       Call `sampleDistance($\vec{P}_{curr}$, $\vec{P}_{end}$, $\vec{S}$, $\sigma_{max}$, $d_{max}$)` to find the distance $d_{scat}$ to the next scattering event [S1, unofficial].
       - If $d_{scat} > d_{max}$, break the loop (ray exits volume).
       - Update position: $\vec{P}_{scat} = \text{mix}(\vec{P}_{curr}, \vec{P}_{end}, d_{scat} / d_{max})$ [S1, unofficial].
       - Update seed: $\vec{S} = \text{new random value}$ [S1, unofficial].

    b. **Transmittance Calculation:**
       Calculate transmittance $T$ from $\vec{P}_{curr}$ to $\vec{P}_{scat}$ using `sampleTransmittance($\vec{P}_{curr}$, $\vec{P}_{scat}$, $\vec{S}$)` [S1, unofficial].
       - Initialize $T = 1.0$.
       - Sample volume color at intermediate positions along the segment.
       - Update $T \leftarrow T \times (1.0 - \alpha_{sample} \cdot \alpha_{correction} / \sigma_{max})$ [S1, unofficial].
       - Note: The sources describe a loop similar to distance sampling but multiplying transmittance factors [S1, unofficial].

    c. **Lighting and Shading:**
       Sample the volume color (diffuse albedo) at $\vec{P}_{scat}$: $C_{diffuse} = \text{sampleVolumeColor}(\vec{P}_{scat})$ [S1, unofficial].
       Sample the light color from the environment map in the scattering direction $\vec{u}_{scattering}$: $C_{light} = \text{sampleEnvironmentMap}(\vec{u}_{scattering})$ [S1, unofficial].
       Compute the contribution: $C_{contrib} = C_{diffuse} \times C_{light} \times T$ [S1, unofficial].
       Add $C_{contrib}$ to $C_{frame}$ [S1, unofficial].

    d. **Update Position:**
       Set $\vec{P}_{curr} = \vec{P}_{scat}$ [S1, unofficial].
       Recalculate bounding box intersection for the new position and direction to find new $\vec{P}_{end}$ [S1, unofficial].

5.  **Accumulation:**
   混合当前帧结果与历史累积值 [S1, unofficial]:
   $$ C_{acc} = C_{acc} + (C_{frame} - C_{acc}) \times N_{inv} $$
   Reset $C_{frame}$ to $\vec{0}$ for the next frame [S1, unofficial].

            seed = [curr_pos[i] + offset for i in range(3)]
            
            # 4. Path Tracing Loop
            while True:
                # Calculate end of current segment
                segment_end = [curr_pos[i] + max_dist * ray_dir[i] for i in range(3)]
                
                # Distance Sampling
                dist = sample_distance_loop(curr_pos, segment_end, seed, sigma_max, max_dist)
                
                if dist >= max_dist:
                    break # Ray exits volume
                
                # Update position to scattering point
                t_scat = dist / max_dist
                scat_pos = mix_vec3(curr_pos, segment_end, t_scat)
                
                # Transmittance Calculation
                transmittance = sample_transmittance(curr_pos, scat_pos, seed, sigma_max, alpha_correction)
                
                # Lighting
                diffuse_color = volume.sample(scat_pos) # Returns vec3
                light_color = env_map.sample(scattering_dir)
                
                # Contribution
                contrib = [diffuse_color[i] * light_color[i] * transmittance for i in range(3)]
                frame_color = [frame_color[i] + contrib[i] for i in range(3)]
                
                # Update for next iteration
                curr_pos = scat_pos
                max_dist = max_dist - dist # Remaining distance in volume
                if max_dist <= 0:
                    break
                    
                # Regenerate seed
                seed = mix_vec3(curr_pos, curr_pos, 0)
                seed = [curr_pos[i] + offset for i in range(3)]
            
            # 5. Accumulation
            accumulator[y][x] = [accumulator[y][x][i] + (frame_color[i] - accumulator[y][x][i]) * inv_frame_num for i in range(3)]
            
    return accumulator

**Edge Cases and Pitfalls:**
- **Precision:** Floating-point errors in ray-box intersection can cause self-intersection or gaps. Use epsilon offsets [G].
- **Bandling:** A fixed random offset is applied to the seed to prevent sample layers from appearing as bands [S1, unofficial].
- **Termination:** Early termination occurs if the ray exits the volume bounds or if the distance to the next scattering event exceeds the remaining distance in the volume [S1, unofficial].

## Operating characteristics
- **Time Complexity:** $O(N \cdot M)$, where $N$ is the number of pixels and $M$ is the average number of scattering events per ray. Convergence requires multiple frames, so effective time is $O(N \cdot M \cdot F)$ where $F$ is the number of frames for convergence.
- **Memory Complexity:** $O(V)$ for the volume texture and $O(P)$ for the accumulator buffers, where $V$ is the volume size and $P$ is the screen resolution.
- **Performance:** Performance depends heavily on the density of the volume and the scattering coefficient $\sigma_{max}$. High density leads to more scattering events and longer render times per frame.
- **Strengths:** Handles complex lighting and heterogeneous media accurately. Converges to the correct solution given enough samples.
- **Limitations:** Slow convergence requires temporal accumulation. Noise is visible in early frames. Sensitive to parameter tuning ($\sigma_{max}$, $\alpha_{correction}$).
