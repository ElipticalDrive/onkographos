# Partial Pre-Integration

## Overview
Partial Pre-Integration is a cell projection technique that improves ray integration approximation in volume rendering by utilizing a 2D lookup table ($\psi$ table) that is independent of the transfer function [S1]. Unlike Full Pre-Integration, which requires recomputing the lookup table whenever the transfer function changes, Partial Pre-Integration allows for interactive transfer function updates with minimal overhead [S1]. It builds on [Volume Raycasting Discretization](831-volume-raycasting-discretization.md) by computing cell contributions via a fragment shader lookup, trading some computational speed for reduced under-sampling errors [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** Scalar field values at the entry ($s_f$) and exit ($s_b$) points of a voxel cell, the geometric thickness of the cell along the ray ($l$), and a transfer function $T(s)$ that maps scalar values to RGBA colors [S1].
*   **Output:** The final RGBA color contribution of the cell to the image [S1].

**Data Structures:**
*   **2D $\psi$ Table:** A pre-compiled 2D texture or array that stores pre-computed integration results for the cell span [S1]. The dimensions and content are fixed and independent of the visualization attributes or transfer function [S1].

**Steps:**
1.  **Retrieve Colors:** Sample the transfer function $T$ at the entry scalar value $s_f$ and the exit scalar value $s_b$ to obtain their associated RGBA colors, denoted as $C_f$ and $C_b$ [S1].
2.  **Compute Indices:** Use the retrieved colors $C_f$, $C_b$, and the cell thickness $l$ to compute the indices for accessing the 2D $\psi$ table [S1]. The exact mapping formula is not specified in the sources [G].
3.  **Lookup and Compose:** Retrieve the pre-computed values from the $\psi$ table using the computed indices [S1]. Use these values to compute the final fragment color for the cell, effectively performing the integration of the volume rendering integral over the cell span [S1].

**Formulas:**
The volume rendering integral is discretized into a summation over sample points along a ray, assuming a zero background intensity ($I_0 = 0$) [S1]. The ray $r$ is parameterized by $\rho_r(\bar{\rho}) : \bar{R} \rightarrow \bar{R}^2$, entering the volume at $\bar{\rho} = 0$ and exiting at $\bar{\rho} = D$ [S1]. The data model is sampled using $s(\bar{\rho})$ [S1]. The transfer function is defined as $g(s) = s$ and $\tau(s) = s/2$ for the evaluation context [S1].

**Parameters:**
*   **$\psi$ Table Resolution:** Not given in the sources.
*   **Thickness ($l$):** The geometric length of the ray segment within the voxel [S1].

**Edge Cases and Pitfalls:**
*   **Under-sampling:** Partial Pre-Integration is less prone to under-sampling errors compared to simple average scalar methods [S1].
*   **Performance:** It is slower than the simple average scalar method (original PT by Shirley and Tuchman) [S1].
*   **Transfer Function Changes:** Unlike Full Pre-Integration, the $\psi$ table does not need to be recomputed when the transfer function changes [S1].

**Pseudocode:**
```python
def partial_pre_integration(s_f, s_b, l, transfer_function, psi_table):
    """
    Computes the color contribution of a voxel cell using Partial Pre-Integration.
    
    Args:
        s_f (float): Scalar value at the entry point of the cell.
        s_b (float): Scalar value at the exit point of the cell.
        l (float): Thickness of the cell along the ray.
        transfer_function (function): Maps scalar s to RGBA color.
        psi_table (2D array): Pre-compiled lookup table independent of transfer function.
        
    Returns:
        tuple: Final RGBA color for the cell.
    """
    # Step 1: Retrieve RGBA colors associated with sf and sb from the transfer function
    C_f = transfer_function(s_f)
    C_b = transfer_function(s_b)
    
    # Step 2: Compute indices into the 2D psi table
    # The sources do not specify the exact index mapping formula [G].
    # Standard implementations normalize alpha values and thickness to table dimensions.
    alpha_f, alpha_b = C_f[1], C_b[1]
    u = int(alpha_f * (psi_table.shape[0] - 1))
    v = int(alpha_b * (psi_table.shape[1] - 1))
    
    # Step 3: Retrieve values from the psi table and use them to compute the final fragment color
    psi_value = psi_table[u, v]
    # The sources do not specify the exact composition formula [G].
    # Standard partial pre-integration uses the table value to scale the color contribution.
    final_color = (psi_value[0] * C_f[0] + psi_value[1] * C_b[0],
                   psi_value[0] * C_f[1] + psi_value[1] * C_b[1],
                   psi_value[0] * C_f[2] + psi_value[1] * C_b[2],
                   1.0)
    return final_color
```

## Subtopics

### [Hybrid Volume and Isosurface Rendering with Partial Pre-Integration](1311-hybrid-volume-and-isosurface-rendering-with-partial-pre-inte.md)
A GPU-accelerated cell projection method that combines direct volume rendering with multiple isosurfaces. It uses tetrahedral discretization, requires no cell connectivity, and offers lower memory usage than hardware-accelerated ray casting variants. Choose it when interactive frame rates with simultaneous opaque/semi-transparent isosurfaces are required.

### [Semi-Analytical Fragment Shader Preintegration](1379-semi-analytical-fragment-shader-preintegration.md)
Improves accuracy by adaptively subdividing ray segments within a cell based on local extrema of scalar and shading polynomials, allowing lookup-based integration over smaller intervals. Choose it when higher integration accuracy is needed at the cost of adaptive subdivision overhead.

## Operating characteristics
*   **Time Complexity:** Slower than the simple average scalar method (original PT) [S1].
*   **Memory Complexity:** Requires storage for the 2D $\psi$ table [S1].
*   **Strengths:** Less prone to under-sampling errors than simple averaging; allows interactive transfer function updates without full table recomputation [S1].
*   **Limitations:** Slower than basic averaging methods [S1].
*   **When to Use:** When interactive transfer function exploration is required and under-sampling artifacts are a concern, and performance is acceptable [S1].
*   **When Not to Use:** When maximum performance is critical and interactive transfer function changes are not needed (use Full Pre-Integration or simple averaging) [S1].

## Background
Partial Pre-Integration was introduced by Moreland et al. [S1]. It was developed to overcome the disadvantage of Full Pre-Integration, where the pre-integration table must be recomputed every time the transfer function changes, which can be an expensive operation depending on table resolution [S1]. The 2D $\psi$ table used in this method was computed by Moreland et al. and made available for downloading [S1]. An implementation using fragment shaders was described in a prototype programmed in C++ using OpenGL 2.0 with GLSL [S1].
