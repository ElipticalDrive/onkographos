# Zero Order Integration (Rectangle Rule)

Also called: Discrete sampling iteration, Iteration A, Piecewise-constant approximation, Riemann Sum Approximation for Volume Rendering, Riemann sum integration, Riemann sum with rectangle rule, Zero-order hold reconstruction

## Overview

Zero Order Integration approximates the continuous volume rendering integral by a Riemann sum over $n$ equidistant segments, assuming the scalar signal (density/extinction) is constant within each segment [S1, S2, unofficial][S4, unofficial][S6]. It sets itself apart from higher-order methods like [Runge-Kutta 4 (RK4) Integration](3158-runge-kutta-4-rk4-integration.md) or [Partial Pre-Integration](1148-partial-pre-integration.md) by requiring only one sample lookup per step and no pre-computed tables, but at the cost of significant approximation errors and visible discontinuities [S4, unofficial][S6]. Unlike back-to-front accumulation which cannot perform early ray termination, the forward iteration form of this method supports early ray termination [S5, book].

## How it works

**Inputs and Outputs:**
*   **Input:** Ray interval $[0, D]$, number of segments $n$, segment length $\Delta x = D/n$ (or $\Delta s$), extinction coefficient function $\tau(s)$, emission/color function $c(s)$ or $q(s)$.
*   **Output:** Approximated color $C$ (and optionally transmittance $T$).

**Data Structures:**
*   Sample points $x_i = i \Delta x$ for $i = 0 \dots n-1$ [S5, book].
*   Pre-computed or on-the-fly values for $\tau(x_i)$ and $c(x_i)$ [S4, unofficial].

**Formulas:**
The transparency of the $i$-th segment is defined as [S5, book]:
$$ T_i = \exp(-\tau(x_i)\Delta x) $$
The color contribution of the $i$-th segment is [S1, unofficial]:
$$ c_i = q(x_i)\Delta x $$
Alternatively, using opacity $A_i = 1 - T_i$ [S2, unofficial]:
$$ A_i \approx \tau(x_i)\Delta x \quad \text{when } \tau(x_i)\Delta x \ll 1.0 $$
The accumulated transmittance up to sample $i$ is [S5, book]:
$$ T(s_i) = \prod_{j=0}^{i-1} \exp(-\tau(x_j)\Delta x) $$
The final color approximation (assuming background $B$) is [S5, book]:
$$ C \approx \sum_{i=0}^{n-1} T(s_i) \tau(x_i) c(x_i) \Delta x + T(D) B $$

**Parameters:**
*   $n$: Number of segments. Not given in the sources.
*   $\Delta x = D/n$: Segment length [S2, unofficial][S5, book].

**Steps:**
1.  Divide the interval $[0, D]$ into $n$ equal segments of length $\Delta x = D/n$ [S2, unofficial][S5, book].
2.  Choose sample points $x_i = i\Delta x$ for $i=0 \dots n-1$ [S5, book].
3.  Evaluate extinction $\tau(x_i)$ and color/emission $c(x_i)$ at each sample point [S4, unofficial].
4.  Compute segment transparency $T_i = \exp(-\tau(x_i)\Delta x)$ [S5, book].
5.  Compute segment color contribution $c_i = q(x_i)\Delta x$ [S1, unofficial] or $C_i = g(x_i)$ [S2, unofficial].
6.  Composite the results using either Front-to-Back or Back-to-Front iteration.

**Pseudocode (Front-to-Back with Early Ray Termination):**
This corresponds to "Iteration A" [S5, book].

```python
def zero_order_integration_front_to_back(n, step, tau_func, c_func, background_color=0.0, t_threshold=1e-4):
    """
    Zero Order Integration using Front-to-Back iteration with early ray termination.
    
    Args:
        n: Number of segments.
        step: Distance between consecutive samples (DeltaS).
        tau_func: Function returning extinction coefficient tau(s).
        c_func: Function returning color/emission c(s).
        background_color: Background intensity B.
        t_threshold: Threshold for early ray termination. [G] Standard small epsilon.
        
    Returns:
        Final color C.
    """
    accumulated_color = 0.0
    accumulated_transmittance = 1.0
    
    for i in range(n):
        if accumulated_transmittance < t_threshold:
            break
            
        tau_i = tau_func(i * step)
        c_i = c_func(i * step)
        
        accumulated_color += accumulated_transmittance * tau_i * c_i * step
        accumulated_transmittance *= math.exp(-tau_i * step)
        
    accumulated_color += accumulated_transmittance * background_color
    return accumulated_color
```

**Pseudocode (Back-to-Front):**
Corresponds to the recursive form derived in [S2, unofficial][S6].

```python
def zero_order_integration_back_to_front(n, step, tau_func, c_func, background_color=0.0):
    """
    Zero Order Integration using Back-to-Front iteration.
    Does not support early ray termination.
    """
    accumulated_color = background_color
    
    for i in range(n - 1, -1, -1):
        tau_i = tau_func(i * step)
        c_i = c_func(i * step)
        
        T_i = math.exp(-tau_i * step)
        
        accumulated_color = T_i * accumulated_color + tau_i * c_i * step
        
    return accumulated_color
```

**Edge Cases and Pitfalls:**
*   **Discontinuities:** The reconstructed signal is not $C^0$ continuous, leading to visible discontinuities and significant approximation errors [S6].
*   **Uniform Sampling Artifacts:** Uniform sampling assumes homogeneous material within each segment, which may result in artifacts [S1, unofficial].
*   **Taylor Approximation:** Using $\exp(-\tau(s)\Delta s) \approx 1 - \tau(s)\Delta s$ is valid only when $\tau(s)\Delta s$ is small; otherwise, it causes visible artifacts [S4, unofficial].
*   **Early Termination:** Early ray termination stops computation when $T$ becomes zero or small enough that further terms have negligible effect [S5, book].

## Subtopics

### [Runge-Kutta 4 (RK4) Integration](3158-runge-kutta-4-rk4-integration.md)
Runge-Kutta 4 (RK4) is a higher-order numerical integration method for volume rendering that queries the vector field at four distinct positions to compute a single ray step, significantly reducing truncation error compared to the zero-order [Rectangle Rule](2082-zero-order-integration-rectangle-rule.md) and first-order [Euler Integration](3839-runge-kutta-2-3-ode-solver.md) methods. It sets itself apart by achieving an error order of $O(dt^5)$ per step, allowing for larger step sizes while maintaining accuracy, though it requires four texture lookups per step rather than one.

### Gaussian Integration for Volume Rendering
Gaussian integration approximates the volume rendering integral as an unequally weighted sum of the integrand at $n$ unequally spaced sample points to achieve greater accuracy for smoothly varying transfer functions compared to equally spaced sampling [S5, book]. The sample locations and weights are chosen such that the integral is exact for polynomials of maximum degree $2n-1$, utilizing the $2n$ degrees of freedom in the positions and weights [S5, book]. It performs poorly for non-smooth transfer functions selected to emphasize specific contour surfaces, as the integrand is not well-approximated by high-degree polynomials in these cases [S5, book]. Unlike equally spaced sampling, Gaussian integration uses unequally spaced points and weights, providing higher accuracy for smooth integrands but failing for non-smooth ones [S5, book].

## Operating characteristics

*   **Time Complexity:** $O(n)$ per ray, where $n$ is the number of samples [S2, unofficial][S4, unofficial].
*   **Memory Complexity:** $O(1)$ auxiliary memory per ray (excluding the volume data itself) [S4, unofficial].
*   **Performance:** Computationally inexpensive, requiring one sample lookup and one exponential per segment [S4, unofficial][S6].
*   **Strengths:** Simple implementation, supports early ray termination (in forward iteration), no pre-computation required [S4, unofficial][S6].
*   **Limitations:** Low accuracy, visible artifacts due to piecewise-constant assumption, $C^0$ discontinuities [S1, unofficial][S6].

## Background

Zero Order Integration, also known as the Rectangle Rule or Riemann Sum approximation, is one of the simplest numerical integration techniques applied to volume rendering. It originates from the fundamental definition of the Riemann integral, where the area under a curve is approximated by the sum of rectangles [S1, S2, unofficial][S4, unofficial][S5, book]. In the context of volume rendering, it was widely used in early direct volume ray casting implementations due to its computational efficiency [S4, unofficial]. The method assumes that the scalar field (density) is constant within each ray segment, leading to a "zero-order hold" reconstruction [S6]. While historically significant, it is often superseded by higher-order methods or pre-integration techniques for high-quality rendering [S1, unofficial][S6].
