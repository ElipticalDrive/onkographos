# Euler Integration
Also called: Euler Integrator, First-order Euler Integrator, Forward Euler

## Overview
Euler Integration is a first-order numerical integration scheme for univariate functions $x: \mathbb{R} \to \mathbb{R}^n$, used to approximate the solution of initial value problems (IVPs) in vector fields [S1, unofficial]. It linearizes the Taylor series expansion to compute the next position from the current position and the vector field derivative [S1, unofficial]. It is distinguished from its parent [Runge-Kutta 4 (RK4) Integration](3158-runge-kutta-4-rk4-integration.md) by its simplicity and lower accuracy; while RK4 uses four samples to achieve fourth-order accuracy, Euler uses only one sample, resulting in first-order global error [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   Input: Current position $x_n$ (or $x(t)$), time step $dt$ (or $h$), and a vector field function $v(x)$ (or $x'(t)$).
*   Output: Next position $x_{n+1}$ (or $x(t+h)$).

**Data Structures:**
*   Position: A 3D vector (or 4D homogeneous vector if scalar data is attached).
*   Vector Field: Sampled at the current position.

**Steps:**
1.  Sample the vector field at the current position $x_n$ to obtain the derivative $v(x_n)$.
2.  Compute the displacement by multiplying the derivative by the step size $dt$.
3.  Add the displacement to the current position to obtain $x_{n+1}$.

**Formula:**
The update rule is defined as [S1, unofficial][S2, unofficial]:
$$x_{n+1} = x_n + dt \cdot v(x_n) + O(dt^2)$$
Where:
*   $x_n$ is the current position.
*   $x_{n+1}$ is the next position.
*   $dt$ is the time step (or step size $h$).
*   $v(x_n)$ is the vector field value (derivative) at $x_n$.
*   $O(dt^2)$ represents the local truncation error.

**Pseudocode:**
The following Python-like pseudocode implements the integration step. It assumes a function `sample_vector_field` that returns a 3D vector (or 4D if scalar data is required) and a `Vector3` type for arithmetic.

```python
def euler_integrate(pos, dt, sample_vector_field):
    """
    Performs one step of Euler integration.
    
    Args:
        pos: Current position (Vector3 or Vector4).
        dt: Time step size (float).
        sample_vector_field: Function that takes a position and returns the vector field value.
        
    Returns:
        The next position (Vector3 or Vector4).
    """
    # Sample the vector field at the current position
    # If pos is Vector4, sample_vector_field should handle the coordinates appropriately
    # [G] Assuming sample_vector_field returns a Vector3 for velocity/direction
    # and potentially a scalar if needed, but standard Euler for streamlines 
    # typically just updates position.
    v = sample_vector_field(pos.x, pos.y, pos.z)
    
    # Compute next position: x_{n+1} = x_n + dt * v(x_n)
    next_pos_x = pos.x + dt * v.x
    next_pos_y = pos.y + dt * v.y
    next_pos_z = pos.z + dt * v.z
    
    # Return the new position
    return Vector3(next_pos_x, next_pos_y, next_pos_z)
```

**Edge Cases and Pitfalls:**
*   **Step Size Sensitivity:** The local error is proportional to the square of the step size, and the global error is proportional to the step size [S2, unofficial]. An inappropriately large $h$ results in undesirably large errors, even for higher-order schemes, but is particularly detrimental here [S1, unofficial].
*   **Vortex Escaping:** Euler integration tends to escape vortices even for very low time step values, whereas higher-order methods like RK4 may converge to the center or follow the vortex more accurately [S2, unofficial].
*   **Precision:** As a first-order method, it requires very small step sizes to achieve accuracy comparable to higher-order methods, which increases computational cost [S2, unofficial].

## Subtopics

### Runge-Kutta 2/3 ODE Solver
A second- or third-order method that uses more samples than Euler to reduce error. Choose it when Euler's first-order accuracy is insufficient but RK4's cost is too high. See [Runge-Kutta 2/3 ODE Solver](3839-runge-kutta-2-3-ode-solver.md).

## Operating characteristics
**Time and Memory Complexity:**
*   Time Complexity: $O(1)$ per step, requiring only one vector field evaluation [S1, unofficial][S2, unofficial].
*   Memory Complexity: $O(1)$, storing only the current position and step size.

**Measured Performance:**
*   The method is extremely fast to implement and execute, often described as "literally two lines of code" [S2, unofficial].
*   However, to achieve acceptable accuracy, the step size $dt$ must be very small, which increases the number of steps required to traverse a given distance [S2, unofficial].

**Strengths and Limitations:**
*   **Strengths:** Simplicity, low computational overhead per step, easy to implement [S2, unofficial].
*   **Limitations:** First-order global error $O(dt)$, poor accuracy for large step sizes, tendency to escape vortices [S1, unofficial][S2, unofficial].

**When to Use:**
*   Use when computational resources are extremely limited and rough approximations are acceptable.
*   Use as a baseline for comparison with higher-order methods [S2, unofficial].

**When Not to Use:**
*   Do not use when high accuracy is required, especially in regions with complex flow features like vortices [S2, unofficial].
*   Do not use if the step size cannot be made sufficiently small to mitigate the first-order error [S1, unofficial].

## Background
**Origin:**
The Euler Method is a first-order numerical integration scheme for univariate functions [S1, unofficial]. It is based on the linearization of the Taylor series expansion [S1, unofficial].

**History and Development:**
It is the simplest numerical integrator for stream lines, using the current position and vector field value to compute the next step [S2, unofficial]. It is commonly used as a starting point for more advanced integration schemes [S2, unofficial].

**Usage:**
It is used in vector field visualization, particularly in real-time applications where simplicity is prioritized over accuracy [S2, unofficial]. It serves as a baseline for comparing higher-order methods like Runge-Kutta 4 [S2, unofficial].
