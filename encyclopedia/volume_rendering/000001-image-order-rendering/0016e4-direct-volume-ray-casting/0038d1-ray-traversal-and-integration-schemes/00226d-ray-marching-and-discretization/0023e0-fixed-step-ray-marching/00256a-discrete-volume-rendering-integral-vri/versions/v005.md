# Discrete Volume Rendering Integral (VRI)
Also called: Pass 2 Fragment Shader VRI Evaluation

## Overview
The Discrete Volume Rendering Integral (VRI) is the fundamental numerical approximation used in direct volume ray casting to compute the color and opacity of a pixel by integrating the continuous Volume Rendering Equation (VRE) along a camera ray [S1, S15][S24, unofficial]. It solves the problem of rendering 3D scalar or vector fields by discretizing the ray into fixed or variable segments, sampling the volume data at each step, and compositing the results front-to-back [S1, unofficial][S8, S17, unofficial]. It sets itself apart from analytical methods like [Self-Attenuation Integral Evaluation](1085-self-attenuation-integral-evaluation.md) by relying on Riemann sums rather than closed-form solutions, and from higher-order integration schemes like [Runge-Kutta 4 (RK4) Integration](3158-runge-kutta-4-rk4-integration.md) by assuming constant density and color within each segment (Zero Order Integration) [S7, S20, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Entry texture coordinate $s_{in}$, exit texture coordinate $s_{out}$, slice spacing in world coordinates $\Delta x$, spatial dimensions of the bounding box $x_{dim}, y_{dim}, z_{dim}$, attenuation values $\tau(s)$, emitted color $C(s)$, and backlight $L_{backlight}$.
*   **Output:** Final pixel color $L_{out}$.

**Data Structures:**
*   **3D Volume Texture:** Stores attenuation values $\tau(s)$.
*   **1D Transfer Function Texture:** Maps attenuation $\tau'$ to color $k_d$ (if present).
*   **Gradient Texture:** Stores volume gradients for shading (if present).

**Numbered Steps:**
1.  **Compute $\Delta s$:** Calculate the step size in texture coordinates. The slice spacing $\Delta x$ is a world-space measure. Compute the spatial locations of the entry and exit points from their texture coordinates. Divide the spatial segment between these points into pieces of length $\Delta x$. The difference in texture coordinates corresponding to one piece of length $\Delta x$ is $\Delta s$ [S1, unofficial].
2.  **Initialize Accumulators:** Set output color $L_{out} = (0, 0, 0)$ and accumulated transparency $t = 1$.
3.  **Iterate Along Ray:** Loop from $s = s_{in}$ to $s_{out}$ with step $\Delta s$.
    a.  **Sample Attenuation:** Lookup $\tau(s)$ from the 3D volume texture. If a transfer function exists, lookup $\tau'$ and $k_d$ from the 1D texture [S1, unofficial].
    b.  **Compute Opacity:** Calculate $\alpha = \tau(s) \; \Delta x$.
    c.  **Compute Color:** Determine $C(s)$ using volume gradients (e.g., Phong equation) or other shading methods, potentially using gradient textures and $k_d$ [S1, unofficial].
    d.  **Composite:** Update $L_{out} = L_{out} + t \; C(s) \; \alpha$.
    e.  **Update Transparency:** Update $t = t \; (1 - \alpha)$.
4.  **Add Backlight:** Return $L_{out} + t \; L_{backlight}$, where $L_{backlight}$ is the light coming from behind the volume [S1, unofficial].

**Formulas:**
The VRI is defined as:
$$L_\textrm{out} = \displaystyle \sum_{i=0}^n C_i\ \alpha_i\ \left(\ \prod_{j=0}^{i-1}\ (1-\alpha_j)\ \right)$$
where $t_i = \prod_{j=0}^{i-1}\ (1-\alpha_j)$ denotes the total transparency up to step $i$, representing the attenuation of light generated in the $i^\textrm{th}$ interval before leaving the volume through the entry point toward the eye. At the entry point, $t_0 = 1$ [S1, unofficial].

**Parameters:**
*   $\Delta x$: Slice spacing in world coordinates.
*   $\Delta s$: Spacing in texture coordinates along the ray, derived from $\Delta x$ and spatial dimensions.
*   $L_{backlight}$: Light coming from behind the volume.

**Edge Cases and Pitfalls:**
*   **Computing $\Delta s$:** A common pitfall is confusing world-space spacing with texture-coordinate spacing. $\Delta s$ must be computed by mapping the world-space slice spacing $\Delta x$ to the texture coordinate domain based on the specific ray's orientation and the bounding box dimensions [S1, unofficial].
*   **Precision:** Accumulating transparency $t$ can suffer from precision loss if $\alpha$ is very small or large over many steps.

**Pseudocode:**
```python
def compute_vri(s_in, s_out, delta_x, x_dim, y_dim, z_dim, volume_texture, transfer_function, gradient_texture, backlight):
    # Step 1: Compute delta_s
    # Compute spatial locations of entry and exit from texture coordinates
    # spatial_entry = texture_to_world(s_in, x_dim, y_dim, z_dim)
    # spatial_exit = texture_to_world(s_out, x_dim, y_dim, z_dim)
    # spatial_segment_length = distance(spatial_entry, spatial_exit)
    # num_steps = spatial_segment_length / delta_x
    # delta_s = (s_out - s_in) / num_steps
    
    L_out = (0.0, 0.0, 0.0)
    t = 1.0
    s = s_in
    
    while s <= s_out:
        # Step 3a: Sample Attenuation
        tau = volume_texture.sample(s)
        if transfer_function is not None:
            tau_prime, k_d = transfer_function.sample(tau)
        else:
            tau_prime = tau
            k_d = 1.0
            
        # Step 3b: Compute Opacity
        alpha = tau_prime * delta_x
        
        # Step 3c: Compute Color
        # C(s) computation depends on shading method (e.g., Phong)
        # gradient = gradient_texture.sample(s)
        # C_s = compute_color(tau_prime, gradient, k_d)
        C_s = (0.0, 0.0, 0.0) # Placeholder for specific shading logic
        
        # Step 3d: Composite
        L_out = L_out + t * C_s * alpha
        
        # Step 3e: Update Transparency
        t = t * (1.0 - alpha)
        
        s = s + delta_s
        
    # Step 4: Add Backlight
    return L_out + t * backlight
```
