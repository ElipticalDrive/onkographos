# DVGO Density and Color Rendering

Also called: DVGO volume rendering

## Overview
DVGO (Density Volume Grid Optimization) is a method for synthesizing novel views of complex scenes by combining a 3D voxel grid with a shallow neural network [S1]. It solves the problem of high memory consumption and slow training associated with pure neural radiance fields (NeRF) by storing density and color features in a structured 3D grid, allowing for fast trilinear interpolation and GPU-friendly parallelization [S1]. Unlike pure MLP-based NeRFs, DVGO leverages the spatial locality of voxels to achieve sharper surfaces with fewer parameters, while avoiding the heavy ray-marching overhead of traditional voxel-based rendering by using a fixed-step integration scheme [S1].

## How it works

### Inputs and Outputs
*   **Inputs:**
    *   $V^{(\sigma)}$: A 3D grid of shape $N_x \times N_y \times N_z$ storing raw density values $\ddot{\sigma} \in \mathbb{R}$.
    *   $V^{(f)}$: A 3D grid of shape $N_x \times N_y \times N_z$ storing color feature vectors $f \in \mathbb{R}^C$.
    *   $b$: A scalar hyperparameter for the density activation shift.
    *   $\Theta$: Parameters of a shallow MLP for color prediction.
    *   $r$: A camera ray defined by origin $o$ and direction $d$.
    *   $t_{near}, t_{far}$: The integration interval along the ray.
    *   $n$: The number of sample points along the ray.
    *   $c_{bg}$: A pre-defined background color.
*   **Outputs:**
    *   $\hat{C}(r)$: The synthesized color for the ray.

### Data Structures
The method relies on two dense 3D grids:
1.  **Density Grid ($V^{(\sigma)}$):** Stores raw scalar values $\ddot{\sigma}_i$. These are not densities themselves but inputs to the activation function.
2.  **Feature Grid ($V^{(f)}$):** Stores feature vectors of dimension $C$. These are interpolated and passed to the MLP.

### Steps
1.  **Ray Sampling:** Sample $n$ points $x_i$ uniformly along the ray segment $[t_{near}, t_{far}]$. Let $\delta_i$ be the distance between adjacent sample points (typically constant $\delta = (t_{far} - t_{near}) / n$).
2.  **Feature Interpolation:** For each sample point $x_i$, retrieve the raw density $\ddot{\sigma}_i$ and feature vector $f_i$ from the grids using trilinear interpolation:
    $$ \ddot{\sigma}_i = \text{interp}(x_i, V^{(\sigma)}) $$
    $$ f_i = \text{interp}(x_i, V^{(f)}) $$
    [S1]
3.  **Density Activation:** Apply the shifted softplus function to ensure non-negative density $\sigma_i$:
    $$ \sigma_i = \log(1 + \exp(\ddot{\sigma}_i + b)) $$
    [S1]
    *Note: Applying this non-linear activation after interpolation (post-activation) is critical for producing sharp surfaces [S1].*
4.  **Color Prediction:** Compute the view-dependent color emission $c_i^{(rgb)}$ by passing the interpolated feature $f_i$, the position $x_i$, and the ray direction $d$ through the MLP. Positional encoding is applied to $x_i$ and $d$ before feeding them into the MLP:
    $$ c_i^{(rgb)} = MLP_\Theta(f_i, \text{PE}(x_i), \text{PE}(d)) $$
    [S1]
5.  **Termination Probability:** Calculate the probability of termination (opacity contribution) at each sample point:
    $$ \alpha_i = 1 - \exp(-\sigma_i \delta_i) $$
    [S1]
6.  **Transmittance Calculation:** Compute the accumulated transmittance $T_i$ from the near plane to point $x_i$:
    $$ T_i = \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    [S1]
    Define $T_1 = 1$.
7.  **Color Accumulation:** Sum the contributions of all samples and add the background term:
    $$ \hat{C}(r) = \sum_{i=1}^{n} T_i \alpha_i c_i^{(rgb)} + T_{n+1} c_{bg} $$
    [S1]

### Pseudocode

```python
import math

def dvgo_render_ray(ray_origin, ray_direction, t_near, t_far, n_samples, 
                    grid_density, grid_features, shift_b, mlp_params, 
                    background_color, pos_encoder):
    """
    Renders a single ray using DVGO.
    
    Args:
        ray_origin: (3,) array, origin of the ray.
        ray_direction: (3,) array, normalized direction of the ray.
        t_near: float, near plane distance.
        t_far: float, far plane distance.
        n_samples: int, number of sample points.
        grid_density: 3D array (Nx, Ny, Nz), raw density values.
        grid_features: 4D array (Nx, Ny, Nz, C), feature vectors.
        shift_b: float, shift parameter for softplus.
        mlp_params: dict or object, parameters for the shallow MLP.
        background_color: (3,) array, background color.
        pos_encoder: function, applies positional encoding to position and direction.
        
    Returns:
        color: (3,) array, rendered color.
    """
    
    # Step 1: Sample points along the ray
    t_values = t_near + (t_far - t_near) * (torch.arange(1, n_samples + 1) / n_samples)
    points = ray_origin + ray_direction * t_values.unsqueeze(1) # Shape: (n_samples, 3)
    
    delta = (t_far - t_near) / n_samples
    
    # Step 2: Interpolate features from grids
    # interp function performs trilinear interpolation
    raw_densities = trilinear_interpolate(points, grid_density) # Shape: (n_samples,)
    features = trilinear_interpolate(points, grid_features)     # Shape: (n_samples, C)
    
    # Step 3: Density Activation (Shifted Softplus)
    densities = math.log(1 + torch.exp(raw_densities + shift_b))
    
    # Step 4: Color Prediction
    # Apply positional encoding to points and direction
    encoded_points = pos_encoder(points)
    encoded_direction = pos_encoder(ray_direction)
    
    # Pass through shallow MLP
    # MLP takes concatenated [features, encoded_points, encoded_direction]
    colors = mlp_forward(features, encoded_points, encoded_direction, mlp_params) # Shape: (n_samples, 3)
    
    # Step 5 & 6: Calculate Alpha and Transmittance
    alphas = 1 - torch.exp(-densities * delta)
    
    # Compute transmittance T_i = product_{j=1}^{i-1} (1 - alpha_j)
    # T_1 = 1
    one_minus_alpha = 1 - alphas
    # Cumulative product of (1 - alpha)
    # T[i] corresponds to transmittance arriving at sample i
    # We need T_1, T_2, ..., T_n
    # T_1 = 1
    # T_2 = (1 - alpha_1)
    # T_3 = (1 - alpha_1) * (1 - alpha_2)
    
    # Efficient calculation using cumprod
    # cumprod of (1-alpha) gives [ (1-a1), (1-a1)(1-a2), ... ]
    # We need to prepend 1.0
    cumprod = torch.cat([torch.tensor([1.0]), torch.cumprod(one_minus_alpha[:-1], dim=0)])
    transmittances = cumprod
    
    # Step 7: Color Accumulation
    # Contribution = T_i * alpha_i * color_i
    contributions = transmittances * alphas * colors
    
    # Sum contributions
    accumulated_color = torch.sum(contributions, dim=0)
    
    # Add background term: T_{n+1} * c_bg
    # T_{n+1} is the transmittance after the last sample
    t_last = one_minus_alpha[-1] if n_samples > 0 else 1.0
    background_term = t_last * background_color
    
    final_color = accumulated_color + background_term
    
    return final_color
```

### Parameters and Edge Cases
*   **Shift $b$:** A hyperparameter controlling the sharpness of the density activation. Not given in the sources.
*   **Grid Resolution:** $N_x, N_y, N_z$. Higher resolution allows for finer detail but increases memory. DVGO claims to require fewer cells than alternatives due to post-activation sharpness [S1].
*   **MLP Depth:** Described as "shallow". Specific depth/width not given in the sources.
*   **Positional Encoding:** Applied to $x_i$ and $d$. Specific frequency bands not given in the sources.
*   **Pitfall:** Applying non-linear activation *before* interpolation can lead to blurry surfaces. DVGO specifically uses post-activation (interpolate then activate) to maintain sharpness [S1].

## Operating characteristics
*   **Time Complexity:** $O(n \cdot (C_{interp} + C_{mlp}))$ per ray, where $n$ is the number of samples, $C_{interp}$ is the cost of trilinear interpolation, and $C_{mlp$ is the cost of the shallow MLP. Trilinear interpolation is very fast on GPUs.
*   **Memory Complexity:** $O(N_x N_y N_z (1 + C))$ for the two grids. This is significantly lower than the memory required for a large MLP to represent the same scene detail, as the grid structure exploits spatial coherence.
*   **Strengths:** Fast training and inference compared to pure NeRF; sharp surfaces with fewer parameters; compatible with standard GPU texture hardware for interpolation.
*   **Limitations:** Fixed grid resolution limits the detail that can be stored; memory usage scales with the volume of the bounding box; view-dependent effects are limited by the MLP capacity.
*   **When to use:** When memory is constrained but high-quality novel view synthesis is needed, and the scene fits within a reasonable bounding box.
*   **When not to use:** For scenes with infinite extent or extremely high-frequency details that would require prohibitively large grids.

## Background
DVGO was introduced in the paper "NeRF Synthesis with Shading Guidance" [S1]. It builds upon the principles of NeRF but addresses its memory inefficiencies by introducing a 3D voxel grid. The method utilizes the shifted softplus activation from Mip-NeRF [S1] to ensure non-negative densities. The key insight is that post-activation interpolation yields sharper surfaces, allowing for coarser grids.
