# Procedural Volumetric Cloud Rendering

Also called: Nubis³, Nubis Cubed, Nubis Evolved, Volumetric Cloud Renderer, Volumetric Cloud Rendering, Real-time Volumetric Cloud Rendering

## Overview

Procedural Volumetric Cloud Rendering is a real-time GPU technique that ray-marches a spherical cloud layer built from tileable 3D noise fields, lighting it with multiple-scattering approximations and Mie phase functions [S3, S4, unofficial]. It solves the problem of rendering physically plausible, large-scale cloudscapes that interact with solid geometry and atmospheric lighting without pre-baking weather maps [S2, S3, unofficial]. What sets it apart from its siblings is the combination of Nubis-style noise shaping (Perlin-Worley fbm) with Frostbite-style energy-conserving integration and temporal reprojection, allowing half-resolution marching to converge to full-resolution quality [S1, S3, unofficial]. Unlike [Mr-Voxel Volume Rendering](3874-mr-voxel-volume-rendering.md) which relies on voxel grids, this method uses procedural textures, and unlike [Ray-marched Volumetric Fog](4248-ray-marched-volumetric-fog.md) which typically uses simple exponential density, it employs complex multi-octave noise and anisotropic scattering [S2, S3, unofficial].

## How it works

**Inputs and Outputs:**
*   **Inputs:** Camera position, view-projection matrix, sun direction, sun color, cloud layer base height, thickness, wind vector, time, and noise textures (shape, detail, weather).
*   **Outputs:** Radiance (RGB), Transmittance (A), and Transmittance-weighted mean depth (for temporal reprojection) [S3, unofficial].

**Data Structures:**
*   **Shape Texture:** `sampler3D` (128³ resolution). Contains Perlin fbm dilated by Worley noise plus three Worley octaves [S3, unofficial].
*   **Detail Texture:** `sampler3D` (32³ resolution). Contains Worley noise for edge erosion [S3, unofficial].
*   **Weather Map:** `sampler2D` (512² resolution). Stores coverage and cloud type (stratus, cumulus, cumulonimbus) per region [S3, unofficial].
*   **Framebuffers:**
    *   `cloudFbo_`: Two color attachments. `GL_COLOR_ATTACHMENT0` (GL_RGBA16F) for radiance/transmittance; `GL_COLOR_ATTACHMENT1` (GL_R32F) for depth [S3, unofficial].
    *   `resolveFbo_[i]`: Two ping-pong framebuffers (GL_RGBA16F) for temporal history [S3, unofficial].
    *   `outputFbo_`: Single color attachment (GL_RGBA8) for final composite [S3, unofficial].

**Numbered Steps:**

1.  **Noise Texture Generation (Compute Shader):**
    Generate the 128³ shape texture and 32³ detail texture on the GPU at startup. Ensure they are tileable [S3, unofficial].

2.  **Ray Setup:**
    For each pixel, construct the ray origin `ro` and direction `rd` in world space.
    *   If using a spherical planet model: Calculate `oc = ro - vec3(0.0, -EARTH_RADIUS, 0.0)`, `rCam = length(oc)`, `b = dot(oc, rd)`, `c = dot(oc, oc)`.
    *   Compute `hOuter = b * b - (c - rOuter * rOuter)`. If `hOuter < 0.0`, return.
    *   Compute `sOuter = sqrt(hOuter)`, `tOuterNear = -b - sOuter`, `tOuterFar = -b + sOuter`.
    *   Compute `hInner = b * b - (c - rInner * rInner)`. If `hInner > 0.0`, `sInner = sqrt(hInner)`, else `sInner = 0.0`.
    *   Determine intersection interval `[tNear, tFar]` with the cloud shell [S3, unofficial].
    *   *Alternative (Box):* Intersect ray with AABB using `intersectBox`. Clamp near intersection `tHit.x` to `max(0, tHit.x)` and far to `min(tHit.y, tHitSolid)` [S2, unofficial].

3.  **Step Size Calculation:**
    Derive step size from the ray's span through the layer. Jitter steps per pixel using interleaved gradient noise that changes each frame [S3, unofficial].

4.  **Ray Marching Loop:**
    Iterate from `tNear` to `tFar` with step size `dt`.
    *   **Termination:** Stop if transmittance drops below 0.5% (or log threshold -4.6) [S3, S2, unofficial].
    *   **Density Sampling:**
        *   Transform world position to noise space using wind offset and time [S3, S4, unofficial].
        *   Sample `shapeTexture` at current position.
        *   Sample `detailTexture` for erosion.
        *   Sample `weatherMap` to get coverage and cloud type.
        *   Compute final density: `density = max(shapeDensity - erosionWeight * detailDensity, 0.f) * coverage * densityMultiplier` [S3, S2, unofficial].
    *   **Lighting (In-Scattering):**
        *   **Optical Depth:** Take 6 samples toward the sun from the current step to calculate optical depth `tau` [S3, unofficial].
        *   **Transmittance:** `lightTransmittance = exp(tau * cloudLightAbsorptionMult)` [S2, unofficial].
        *   **Phase Function:** Evaluate two-lobe Henyey-Greenstein phase function using the angle between ray and sun [S3, S2, unofficial].
        *   **Multiple Scattering:** Evaluate four-octave approximation (attenuated extinction, contribution, phase eccentricity) [S3, unofficial].
        *   **Ambient:** Fade ambient color from blue (`vec3(0.62, 0.74, 0.95)`) at top to grey (`vec3(0.36, 0.42, 0.52)`) at bottom [S3, unofficial].
        *   **Powder Term:** Darken back-lit edges [S3, unofficial].
        *   **Integration:** Integrate in-scattering analytically over the step [S3, unofficial].
    *   **Accumulation:**
        *   `radiance += scatteredLight * transmittance`
        *   `transmittance *= exp(-density * stepSize)`
        *   `depthAccum += depth * transmittance`

5.  **Temporal Reprojection (Resolve Pass):**
    *   Render cloud pass at reduced resolution (e.g., 0.5 scale) with sub-pixel jitter from Halton sequence [S3, unofficial].
    *   Reconstruct world position from cloud depth.
    *   Project through previous frame's view-projection matrix.
    *   Blend history sample at 92% (blend factor 0.08) [S3, unofficial].
    *   Clamp history to 3×3 neighborhood to prevent ghosting [S3, unofficial].

6.  **Composite Pass:**
    Combine resolved cloud color, depth, and shape texture into final output [S3, unofficial].

**Pseudocode:**

```python
def ray_march_clouds(ro, rd, shape_tex, detail_tex, weather_tex, sun_dir, time, wind, base_height, thickness):
    # Constants
    EARTH_RADIUS = 6371000.0
    SHAPE_SCALE = 1.0 / 9000.0
    DETAIL_SCALE = 1.0 / 900.0
    WEATHER_SCALE = 1.0 / 48000.0
    AMBIENT_TOP = vec3(0.62, 0.74, 0.95)
    AMBIENT_BOTTOM = vec3(0.36, 0.42, 0.52)
    
    # Intersection with spherical shell
    oc = ro - vec3(0.0, -EARTH_RADIUS, 0.0)
    b = dot(oc, rd)
    c = dot(oc, oc)
    r_outer = base_height + thickness
    r_inner = base_height
    
    h_outer = b*b - (c - r_outer*r_outer)
    if h_outer < 0.0:
        return vec4(0.0), 1.0, 0.0
        
    s_outer = sqrt(h_outer)
    t_near = -b - s_outer
    t_far = -b + s_outer
    
    h_inner = b*b - (c - r_inner*r_inner)
    if h_inner > 0.0:
        s_inner = sqrt(h_inner)
        t_near = max(t_near, -b - s_inner)
        t_far = max(t_far, -b + s_inner)
    else:
        t_near = max(t_near, 0.0)
        
    if t_near > t_far:
        return vec4(0.0), 1.0, 0.0
        
    step_size = (t_far - t_near) / 128.0 # Default steps
    transmittance = 1.0
    radiance = vec3(0.0)
    depth_accum = 0.0
    
    for t in range(0, 128):
        if transmittance < 0.005:
            break
            
        current_t = t_near + t * step_size
        pos = ro + rd * current_t
        
        # Noise Sampling
        shape_pos = pos * SHAPE_SCALE + wind * time
        detail_pos = pos * DETAIL_SCALE
        
        shape_val = texture(shape_tex, shape_pos).r
        detail_val = texture(detail_tex, detail_pos).r
        weather = texture(weather_tex, pos.xy * WEATHER_SCALE)
        
        coverage = weather.r
        cloud_type = weather.g
        
        # Density Calculation
        density = shape_val - detail_val * (1.0 - coverage) # Simplified erosion
        density = max(density * coverage, 0.0)
        
        # Lighting
        # Optical depth towards sun
        tau = 0.0
        for i in range(6):
            sun_pos = pos + sun_dir * (i * step_size)
            tau += texture(shape_tex, sun_pos * SHAPE_SCALE).r * step_size
            
        light_trans = exp(-tau * 1.0) # Absorption mult
        
        # Phase
        cos_angle = dot(normalize(rd), normalize(sun_dir))
        phase = henyey_greenstein(cos_angle, 0.8) * 0.5 + henyey_greenstein(cos_angle, -0.5) * 0.5
        
        # Multiple Scattering Approximation
        ms = multiple_scattering_approx(tau, phase)
        
        # Ambient
        height_frac = (pos.y + EARTH_RADIUS - base_height) / thickness
        ambient = mix(AMBIENT_TOP, AMBIENT_BOTTOM, height_frac)
        
        # In-scattering contribution
        scattered = ms * light_trans + ambient * 0.1
        radiance += scattered * transmittance * step_size
        
        # Update Transmittance
        transmittance *= exp(-density * step_size)
        depth_accum += current_t * transmittance * step_size
        
    mean_depth = depth_accum / (1.0 - transmittance + 1e-6)
    return radiance, transmittance, mean_depth

def henyey_greenstein(cos_theta, g):
    g2 = g * g
    return (1.0 - g2) / (4.0 * 3.14159 * pow(1.0 + g2 - 2.0 * g * cos_theta, 1.5))

def multiple_scattering_approx(tau, phase):
    # Simplified 4-octave approximation
    return phase * exp(-tau * 0.5) * 0.8
```

**Parameters:**
*   `shape_noise_scale`: Default 6.4 km. Controls cloud size [S1, unofficial].
*   `uShape`: 128³ sampler3D [S3, unofficial].
*   `uDetail`: 32³ sampler3D [S3, unofficial].
*   `uWeather`: 512² sampler2D [S3, unofficial].
*   `uWind`: vec2 wind vector [S3, unofficial].
*   `uTime`: float time [S3, unofficial].
*   `uBaseHeight`: float base height [S3, unofficial].
*   `uThickness`: float thickness [S3, unofficial].
*   `uCoverage`: float coverage control [S3, unofficial].
*   `uDensity`: float density control [S3, unofficial].
*   `uMaxSteps`: int max steps (default 128) [S3, unofficial].
*   `s.scale`: Resolution scale (default 0.5) [S3, unofficial].

**Edge Cases and Pitfalls:**
*   **Shadow Map Basis Error:** If multiple non-parallel suns exist, the cloud shadow map (traced along the first directional light) will appear displaced for other lights. Other lights must march the cloud layer toward themselves independently [S1, unofficial].
*   **Viewport Depth Mismatch:** If the camera is inset, depth reads must be offset by the viewport origin to avoid tracing the wrong part of the view [S1, unofficial].
*   **History Validity:** Temporal reprojection history is invalid if the view entity changes, textures are reallocated, or the resolution changes [S1, unofficial].
*   **Reprojection Depth:** Mean cloud depth is a compromise if thin near clouds overlap far ones. The 3×3 history clamp handles disocclusions [S3, unofficial].

## Subtopics

### [Volumetric Clouds from Base Shape (Nubis/Frostbite Hybrid)](9609-volumetric-clouds-from-base-shape-nubis-frostbite-hybrid.md)
A variant where the cloud layer is defined by two altitudes above a base shape (e.g., a planet). It uses Schneider's density model and Hillaire 2016 light transport. Choose this when rendering clouds on curved surfaces to avoid 2D weather map tearing.

## Operating characteristics

*   **Time Complexity:** O(N * M) where N is the number of pixels and M is the number of ray steps. With temporal reprojection, the effective cost is reduced by the resolution scale factor squared.
*   **Memory Complexity:** O(T) for texture storage (shape, detail, weather) and O(F) for framebuffers (ping-pong buffers for temporal history).
*   **Measured Performance:** On Mesa llvmpipe (CPU rasterizer) at 640×360: Full-res, 128 steps, no temporal: 927 ms. Half-res, 128 steps, temporal: 266 ms (29% of full-res) [S3, unofficial].
*   **Scaling:** Performance scales linearly with resolution and step count. Temporal reprojection allows rendering at half or quarter resolution with minimal quality loss, converging over ~12 frames [S3, unofficial].
*   **Strengths:** Real-time performance, physically plausible lighting, supports arbitrary base shapes, avoids 2D map artifacts.
*   **Limitations:** Approximate multiple scattering (flatter lit side than path-traced), single cloud layer (no cirrus), hand-tuned sun color at low elevation (analytic sky) [S3, unofficial].
*   **When to Use:** Real-time games, interactive simulations, VR.
*   **When Not to Use:** Offline rendering requiring exact physical accuracy, scenes with multiple distinct cloud layers requiring complex inter-layer scattering.

## Background

Originating from Andrew Schneider's work on *Horizon: Zero Dawn* (Nubis) and Sébastien Hillaire's work on Frostbite and Unreal Engine, this technique combines procedural noise shaping with energy-conserving volumetric integration [S1, S2, S3, unofficial]. It was adapted for real-time engines like Bevy and Unity, leveraging temporal reprojection to achieve high quality at interactive framerates [S1, S3, S4, unofficial].
