# Volume Ray Casting with Barycentric Interpolation and Phong Lighting

Also called: Attenuated Ray Casting, CPU Volume Ray Caster, GPU Volume Ray Caster, Ray Tracing Volume Rendering, VIPER Ray Casting Method

## Overview
Volume Ray Casting with Barycentric Interpolation and Phong Lighting is a direct volume rendering technique that casts parallel rays from a viewing plane through a 3D voxel grid, sampling data values using barycentric interpolation within unit cubes and accumulating lighting contributions [S1, S3, unofficial]. It solves the problem of visualizing 3D scalar fields by projecting voxel values to a 2D view plane while simulating light absorption and reflection [S1, S3, unofficial]. Unlike standard ray tracers that spawn secondary rays at intersections, this method attenuates rays as they travel through the volume, making it computationally faster but lacking advanced features like reflections and refractions [S2, unofficial]. It builds on [Volume Ray Casting](3161-volume-ray-casting.md) by specifying the interpolation scheme (barycentric/linear within cells) and the shading model (Phong).

## How it works
**Inputs:**
- 3D scalar volume data grid (voxels).
- Viewing parameters: canvas width, canvas height, camera position, view matrix, light direction, light intensity [S1, S3, unofficial].
- Transfer function parameters: mapping scalar values to opacity (0 to 1) [S3, unofficial].
- Phong shading parameters: ambient, diffuse, specular coefficients, shininess [S3, unofficial].

**Outputs:**
- 2D image (canvas) with color values for each pixel [S1, S3, unofficial].

**Data Structures:**
- **Volume Grid:** A 3D array of scalar values. Each element is converted into a voxel [S3, unofficial].
- **Viewing Plane:** Defined by vertex arrays for canvas points [S1, unofficial].
- **Ray State:** Origin, direction, current intensity, accumulated color [S2, unofficial].

**Steps:**

1.  **Initialization:**
    - Convert each data element into a voxel [S3, unofficial].
    - Initialize the viewing plane and volume data structures [S1, unofficial].
    - Assign an initial light intensity value to each ray [S2, unofficial].

2.  **Ray Generation:**
    - For each pixel on the canvas, compute the ray origin from the viewing plane and the direction from the view matrix [S1, unofficial].

3.  **Ray Traversal and Sampling:**
    - Iterate along the ray from $t=0$ to $t=\text{distance}$ with a step size $\text{sample\_period}$ [S1, unofficial].
    - Trace the ray through the volume one cell at a time using its direction vector [S2, unofficial].
    - At every cell intersection, compute data values at the ray's entry and exit points by linearly interpolating the data values from each vertex in the cell wall [S2, unofficial]. This is the barycentric interpolation step within the unit cube.
    - Compare the interpolated entry and exit values with the target value; if the target value lies between them, process the intersection to compute the color contribution [S2, unofficial].

4.  **Classification:**
    - Classify each voxel by assigning opacity using lookup tables and transfer functions that map scalar data to opacity. Opacity ranges from 0 (transparent) to 1 (opaque) [S3, unofficial].

5.  **Shading and Lighting:**
    - Perform shading using the standard Phong shading equation [S3, unofficial].
    - Calculate a gradient vector for each voxel to determine the light reflection direction [S3, unofficial].
    - Calculate the color contribution based on ambient, diffuse, and specular components [S3, unofficial].

6.  **Attenuation and Accumulation:**
    - Attenuate the ray's light level at each intersection by multiplying it by a transparency factor $T$ between 0 and 1 [S2, unofficial].
    - Accumulate the color contributions from all processed intersections [S2, unofficial].
    - Terminate ray tracing when the ray's intensity falls below a significance threshold or when the ray exits the volume boundary [S2, unofficial].

7.  **Output:**
    - Clamp the accumulated value scaled by a dimming factor to $[0, 1]$ and output as color [S1, unofficial].

**Pseudocode:**

```python
def volume_ray_casting_with_barycentric_phong(volume, canvas_width, canvas_height, view_matrix, light_dir, light_intensity, transfer_function, phong_params):
    """
    volume: 3D array of scalar values (voxels)
    canvas_width, canvas_height: dimensions of the output image
    view_matrix: matrix to compute ray directions
    light_dir: normalized vector for light direction
    light_intensity: initial intensity of the ray
    transfer_function: function mapping scalar value to opacity (0.0 to 1.0)
    phong_params: dict with ambient, diffuse, specular, shininess
    """
    image = zeros((canvas_height, canvas_width, 3))
    
    # Precompute voxel dimensions and bounds
    voxel_size = 1.0 # Assuming normalized grid
    volume_dims = volume.shape
    
    for y in range(canvas_height):
        for x in range(canvas_width):
            # Step 2: Ray Generation
            ray_origin = compute_ray_origin(x, y, canvas_width, canvas_height, view_matrix)
            ray_direction = compute_ray_direction(x, y, canvas_width, canvas_height, view_matrix)
            
            ray_intensity = light_intensity
            accumulated_color = zeros(3)
            
            # Step 3: Ray Traversal
            t = 0.0
            step_size = voxel_size # Sample at each cell boundary or fixed period
            
            while t < max_distance:
                # Compute current position
                pos = ray_origin + t * ray_direction
                
                # Check if inside volume bounds
                if not is_inside_volume(pos, volume_dims):
                    break
                
                # Find the cell containing pos
                cell = get_cell_index(pos, volume_dims)
                
                # Compute entry and exit points of the ray within this cell
                entry_point, exit_point = get_cell_intersections(ray_origin, ray_direction, cell, volume_dims)
                
                # Compute distance to next intersection
                t_next = distance(ray_origin, exit_point)
                
                # Sample at entry and exit points using barycentric interpolation
                # Linear interpolation from vertices of the cell wall
                val_entry = barycentric_interpolate(volume, entry_point, cell)
                val_exit = barycentric_interpolate(volume, exit_point, cell)
                
                # Check if target value lies between entry and exit (implicit in continuous sampling)
                # Classify voxel
                opacity_entry = transfer_function(val_entry)
                opacity_exit = transfer_function(val_exit)
                
                # Step 5: Shading
                # Calculate gradient for Phong shading
                gradient = compute_gradient(volume, entry_point, cell)
                normal = normalize(gradient)
                
                # Phong shading equation
                ambient = phong_params['ambient']
                diffuse = phong_params['diffuse'] * max(0, dot(normal, light_dir))
                view_dir = normalize(-ray_direction)
                reflect_dir = reflect(-light_dir, normal)
                specular = phong_params['specular'] * pow(max(0, dot(view_dir, reflect_dir)), phong_params['shininess'])
                
                color_contribution = (ambient + diffuse + specular) * light_intensity
                
                # Step 6: Attenuation and Accumulation
                # Attenuate ray intensity
                # Transparency factor T is related to opacity. 
                # If opacity is 1, T=1 (opaque), if 0, T=0 (transparent).
                # The note says "multiply by a transparency factor between 0 and 1".
                # Usually, transmission = 1 - opacity.
                transmission = 1.0 - opacity_entry 
                ray_intensity *= transmission
                
                # Accumulate color
                # The contribution is weighted by the transmission of previous steps
                accumulated_color += color_contribution * transmission
                
                # Termination check
                if ray_intensity < significance_threshold:
                    break
                
                t = t_next
            
            # Step 7: Output
            image[y, x] = clamp(accumulated_color, 0.0, 1.0)
            
    return image

def barycentric_interpolate(volume, point, cell):
    """
    Linearly interpolate data values from each vertex in the cell wall.
    For a unit cube, this is trilinear interpolation.
    """
    # Get the 8 vertices of the cell
    v000 = volume[cell.x, cell.y, cell.z]
    v100 = volume[cell.x+1, cell.y, cell.z]
    v010 = volume[cell.x, cell.y+1, cell.z]
    v110 = volume[cell.x+1, cell.y+1, cell.z]
    v001 = volume[cell.x, cell.y, cell.z+1]
    v101 = volume[cell.x+1, cell.y, cell.z+1]
    v011 = volume[cell.x, cell.y+1, cell.z+1]
    v111 = volume[cell.x+1, cell.y+1, cell.z+1]
    
    # Local coordinates within the cell
    u, v, w = point - cell.origin
    
    # Trilinear interpolation
    c00 = lerp(v000, v100, u)
    c10 = lerp(v010, v110, u)
    c01 = lerp(v001, v101, u)
    c11 = lerp(v011, v111, u)
    
    c0 = lerp(c00, c10, v)
    c1 = lerp(c01, c11, v)
    
    return lerp(c0, c1, w)

def lerp(a, b, t):
    return a + t * (b - a)
```

**Parameters:**
- **Transparency factor:** A scalar value between 0 (completely transparent) and 1 (completely opaque) used to attenuate ray intensity at each intersection [S2, unofficial]. Note: In standard volume rendering, opacity $\alpha$ is used to compute transmission $1-\alpha$. The source describes a "transparency factor" used to multiply intensity, which implies transmission.
- **Significance threshold:** The intensity level below which ray tracing is terminated [S2, unofficial]. Not given in the sources.
- **Sample period:** The step size for iteration along the ray [S1, unofficial]. Not given in the sources.

**Edge Cases and Pitfalls:**
- **Precision:** Linear interpolation within cells may introduce artifacts if the step size is too large relative to voxel size [S2, unofficial].
- **Boundaries:** Ray termination must handle exit from volume boundary correctly [S2, unofficial].
- **Degenerate Input:** If the volume is empty or all values are zero, the image will be black or transparent [S3, unofficial].

## Operating characteristics
- **Time Complexity:** Linear with respect to the number of samples per ray and the number of pixels. The number of samples depends on the volume depth and step size [S1, unofficial].
- **Memory Complexity:** Linear with respect to the volume size and image size [S1, unofficial].
- **Measured Performance:** Computationally faster than standard ray tracers [S2, unofficial]. Performance scales with the number of processors in parallel implementations [S3, unofficial].
- **Strengths:** Allows transparent surfaces to be rendered; computationally faster than standard ray tracers; no communication overheads in parallel implementations [S2, S3, unofficial].
- **Limitations:** Lacks advanced image-enhancing features like reflections and refractions [S2, unofficial].
- **When to use:** When rendering transparent volumes is required and performance is a concern [S2, unofficial].
- **When not to use:** When advanced lighting effects like reflections and refractions are needed [S2, unofficial].

## Background
The technique originated from the VIPER program, which implemented ray casting for volume rendering [S2, unofficial]. It was developed in the context of sampling scattered data onto rectangular grids for volume visualization [S2, unofficial]. The method uses the VolPack library for classification, shading, and other rendering procedures [S3, unofficial]. It is used in parallel, multiresolution, and adaptive-resolution techniques for volume visualization of time-varying data [S3, unofficial].
