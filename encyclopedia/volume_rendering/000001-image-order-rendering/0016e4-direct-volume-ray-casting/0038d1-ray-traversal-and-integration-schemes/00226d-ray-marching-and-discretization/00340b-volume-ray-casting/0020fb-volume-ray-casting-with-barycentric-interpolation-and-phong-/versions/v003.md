# Volume Ray Casting with Barycentric Interpolation and Phong Lighting

Also called: CPU Volume Ray Caster, GPU Volume Ray Caster, Ray Tracing Volume Rendering

## Overview
A volume rendering technique that casts rays from a viewing plane through a 3D voxel grid, sampling voxel values using barycentric interpolation within the unit cube, and accumulating lighting contributions (ambient, diffuse, specular) along the ray path [S1, unofficial]. It projects values to a view plane to produce a 2D image by casting parallel rays from the eye to voxels [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D voxel grid (scalar data), viewing parameters (camera position, view matrix, canvas dimensions), light position, light color, material properties (ambient, diffuse, specular coefficients, shininess, dimming factor), transfer function (mapping scalar data to opacity), sample period (step size) [S1, unofficial].
*   **Outputs:** 2D image (color buffer) [S2, unofficial].

**Data Structures:**
*   **Voxel Grid:** A 3D array of scalar values representing the volume data [S1, unofficial].
*   **Viewing Plane:** Defined by a canvas width and height, and a center point [S1, unofficial].
*   **Transfer Function:** Maps scalar data to opacity [S2, unofficial].

**Steps:**
1.  **Initialization:** Initialize the viewing plane and volume data structures [S1, unofficial]. Convert each data element into a voxel [S2, unofficial].
2.  **Ray Generation:** For each pixel on the canvas, compute the ray origin from the viewing plane and the ray direction from the view matrix [S1, unofficial].
3.  **Classification:** Classify each voxel by assigning opacity using lookup tables and transfer functions that map scalar data to opacity [S2, unofficial].
4.  **Ray Marching and Accumulation:** Iterate along the ray from $t=0$ to $t=\text{distance}$ with a step size of `sample_period` [S1, unofficial].
    *   **Sampling:** At the current position along the ray, sample the voxel value using barycentric interpolation within the unit cube [S1, unofficial].
    *   **Lighting:** Calculate lighting contributions using the standard Phong shading equation [S2, unofficial]. Calculate a gradient vector for the current voxel to determine the surface normal [S2, unofficial]. Compute the reflection direction based on the normal and light direction [S2, unofficial]. Calculate ambient, diffuse, and specular components [S1, unofficial].
    *   **Accumulation:** Accumulate the lighting result along the ray path.
5.  **Output:** Clamp the accumulated value, scaled by a dimming factor, to the range $[0, 1]$ and output as color [S1, unofficial].

**Pseudocode:**
```python
import math

class Vec3:
    def __init__(self, x, y, z): self.x, self.y, self.z = x, y, z
    def __add__(self, o): return Vec3(self.x+o.x, self.y+o.y, self.z+o.z)
    def __sub__(self, o): return Vec3(self.x-o.x, self.y-o.y, self.z-o.z)
    def __mul__(self, s): return Vec3(self.x*s, self.y*s, self.z*s)
    def dot(self, o): return self.x*o.x + self.y*o.y + self.z*o.z
    def length(self): return math.sqrt(self.x**2 + self.y**2 + self.z**2)
    def normalize(self): l = self.length(); return Vec3(self.x/l, self.y/l, self.z/l) if l > 0 else Vec3(0,0,0)
    def reflect(self, n): return self - n * 2 * self.dot(n)
    def clamp(self, mn, mx): return Vec3(max(mn, min(mx, self.x)), max(mn, min(mx, self.y)), max(mn, min(mx, self.z)))

def volume_ray_casting_with_barycentric_phong(voxel_grid, grid_dims, camera_pos, light_pos, light_color, material, transfer_func, sample_period, canvas_width, canvas_height, max_ray_length):
    # Initialize output image
    image = [[[0.0, 0.0, 0.0] for _ in range(canvas_width)] for _ in range(canvas_height)]
    
    for y in range(canvas_height):
        for x in range(canvas_width):
            # 1. Compute ray origin and direction from viewing plane
            ray_origin = camera_pos
            ray_direction = Vec3((x - canvas_width / 2.0) / canvas_width, (y - canvas_height / 2.0) / canvas_height, -1.0).normalize()
            
            acc_color = Vec3(0, 0, 0)
            acc_opacity = 0.0
            
            # 2. Iterate along the ray
            t = 0.0
            while t < max_ray_length:
                # 3. Sample voxel using barycentric interpolation
                voxel_pos = ray_origin + ray_direction * t
                voxel_value = barycentric_interpolate(voxel_grid, grid_dims, voxel_pos)
                
                # 4. Classify: Map scalar value to opacity
                opacity = transfer_func(voxel_value)
                
                # 5. Calculate Lighting (Phong)
                # Calculate gradient for normal estimation
                normal = compute_gradient_normal(voxel_grid, grid_dims, voxel_pos)
                
                light_dir = (light_pos - voxel_pos).normalize()
                view_dir = (camera_pos - voxel_pos).normalize()
                
                ambient = light_color * material.ambient
                diffuse = light_color * material.diffuse * max(normal.dot(light_dir), 0.0)
                reflect_dir = light_dir.reflect(normal)
                specular = light_color * material.specular * max(normal.dot(view_dir), 0.0) ** material.shininess
                
                voxel_color = ambient + diffuse + specular
                
                # 6. Accumulate (Front-to-Back)
                acc_color = acc_color + (1.0 - acc_opacity) * voxel_color * opacity
                acc_opacity = acc_opacity + (1.0 - acc_opacity) * opacity
                
                # 7. Step forward
                t += sample_period
                
            # 8. Output
            # Clamp and scale by dimming factor
            final_color = (acc_color * material.dimming_factor).clamp(0.0, 1.0)
            image[y][x] = [final_color.x, final_color.y, final_color.z]
            
    return image

def barycentric_interpolate(voxel_grid, grid_dims, point):
    # Find the unit cube containing the point
    ix, iy, iz = int(point.x), int(point.y), int(point.z)
    wx, wy, wz = point.x - ix, point.y - iy, point.z - iz
    
    def clamp_idx(v, dim): return max(0, min(v, dim - 1))
    
    v000 = voxel_grid[clamp_idx(ix, grid_dims[0])][clamp_idx(iy, grid_dims[1])][clamp_idx(iz, grid_dims[2])]
    v100 = voxel_grid[clamp_idx(ix+1, grid_dims[0])][clamp_idx(iy, grid_dims[1])][clamp_idx(iz, grid_dims[2])]
    v010 = voxel_grid[clamp_idx(ix, grid_dims[0])][clamp_idx(iy+1, grid_dims[1])][clamp_idx(iz, grid_dims[2])]
    v110 = voxel_grid[clamp_idx(ix+1, grid_dims[0])][clamp_idx(iy+1, grid_dims[1])][clamp_idx(iz, grid_dims[2])]
    v001 = voxel_grid[clamp_idx(ix, grid_dims[0])][clamp_idx(iy, grid_dims[1])][clamp_idx(iz+1, grid_dims[2])]
    v101 = voxel_grid[clamp_idx(ix+1, grid_dims[0])][clamp_idx(iy, grid_dims[1])][clamp_idx(iz+1, grid_dims[2])]
    v011 = voxel_grid[clamp_idx(ix, grid_dims[0])][clamp_idx(iy+1, grid_dims[1])][clamp_idx(iz+1, grid_dims[2])]
    v111 = voxel_grid[clamp_idx(ix+1, grid_dims[0])][clamp_idx(iy+1, grid_dims[1])][clamp_idx(iz+1, grid_dims[2])]
    
    c00 = v000 + wx * (v100 - v000)
    c10 = v010 + wx * (v110 - v010)
    c01 = v001 + wx * (v101 - v001)
    c11 = v011 + wx * (v111 - v011)
    
    b0 = c00 + wy * (c10 - c00)
    b1 = c01 + wy * (c11 - c01)
    
    return b0 + wz * (b1 - b0)

def compute_gradient_normal(voxel_grid, grid_dims, point):
    # Calculate gradient vector for each voxel using central differences
    ix, iy, iz = int(point.x), int(point.y), int(point.z)
    
    def clamp_idx(v, dim): return max(0, min(v, dim - 1))
    
    dx = voxel_grid[clamp_idx(ix+1, grid_dims[0])][iy][iz] - voxel_grid[clamp_idx(ix-1, grid_dims[0])][iy][iz]
    dy = voxel_grid[ix][clamp_idx(iy+1, grid_dims[1])][iz] - voxel_grid[ix][clamp_idx(iy-1, grid_dims[1])][iz]
    dz = voxel_grid[ix][iy][clamp_idx(iz+1, grid_dims[2])] - voxel_grid[ix][iy][clamp_idx(iz-1, grid_dims[2])]
    
    return Vec3(dx, dy, dz).normalize()
```

**Parameters:**
*   `sample_period`: Step size for ray marching. Typical values for the number of sample points are 64, 128, 256, 512 [S1, unofficial].
*   `dimming_factor`: A scaling factor applied to the accumulated value before clamping [S1, unofficial].
*   `material`: Contains ambient, diffuse, specular coefficients, shininess, and dimming factor [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Boundary Conditions:** The gradient calculation requires neighboring voxels [G].
*   **Degenerate Input:** Empty volumes or volumes with constant scalar values may result in no visible structure [G].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot M)$, where $N$ is the number of pixels and $M$ is the number of sample points per ray [G].
*   **Measured Performance:** The source provides speedup data for different numbers of sample points (64, 128, 256, 512) and processors, but specific hardware details and absolute performance metrics are not provided [S1, unofficial].
*   **Strengths:** Parallelizable across processors without communication overhead [S2, unofficial].
*   **Limitations:** Computationally expensive due to per-pixel ray marching and lighting calculations [G].
*   **When to Use:** When high-quality lighting and smooth interpolation are required, and computational resources are sufficient [G].
*   **When Not to Use:** When real-time performance is critical and hardware resources are limited [G].

## Background
The method is based on volume ray casting, a technique for visualizing 3D scalar fields [S1, unofficial]. The specific implementation using barycentric interpolation and Phong lighting is described in the context of a project for learning volume ray casting [S1, unofficial]. The VolPack library functions are called for classification, shading, and rendering procedures [S2, unofficial]. The temporal rendering section describes generating complete frames per processor without communication overhead [S2, unofficial]. The technique is applicable to time-varying data visualization [S2, unofficial]. Volumetric rendering computes images from three-dimensional grids of data instead of surfaces, where every stretch of a ray's journey can absorb, scatter, or add light [S3].
