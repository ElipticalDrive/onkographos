# Ray Traversal Schemes

Also called: Accumulate Projection, Depth Projection, Max Intensity Projection, Ray Traversal -Accumulate

## Overview
Ray traversal schemes define the aggregation logic applied to the optical properties sampled along a ray to produce the final pixel value [S1, S2, S3, unofficial]. They solve the problem of reducing a 1D sequence of volumetric samples to a single pixel color and auxiliary data [S2, unofficial]. They are distinguished from sibling schemes by their focus on the compositing and reduction rules rather than the sampling geometry or image-order loop structure [G].

## Shared principles
The family operates on the discretized ray samples $(C_i, \alpha_i)$ generated by the parent's sampling stage [G]. The core mechanism is a reduction function $R$ that maps the sample sequence to a pixel output [S2, unofficial]. The reduction types are:
1.  **Accumulation**: Front-to-back compositing using the standard alpha blending equation [S2, S3, unofficial].
2.  **Extremum**: Selecting the maximum or minimum scalar value along the ray [S2, S3, unofficial].
3.  **Averaging**: Computing the arithmetic mean of scalar values [S2, S3, unofficial].
4.  **First Hit**: Identifying the first sample that meets a classification threshold [S1, S2, unofficial].
5.  **Depth**: Recording the ray parameter $t$ where the primary event occurs [S1, S2, unofficial].

All schemes operate on the discretized ray samples generated by the parent's sampling stage [G]. The reduction logic can be implemented as follows:

```python
def reduce_samples(samples, scheme):
    accumulated_color = (0.0, 0.0, 0.0)
    accumulated_alpha = 0.0
    first_intensity = None
    first_depth = None
    max_intensity = None
    sum_intensity = 0.0
    count = 0
    for i, (c, a, t) in enumerate(samples):
        if scheme == "accumulate":
            accumulated_color = c * a * (1.0 - accumulated_alpha) + accumulated_color * (1.0 - a)
            accumulated_alpha = a + accumulated_alpha * (1.0 - a)
        elif scheme == "max":
            if max_intensity is None or c > max_intensity:
                max_intensity = c
        elif scheme == "average":
            sum_intensity += c
            count += 1
        elif scheme == "first":
            if first_intensity is None:
                first_intensity = c
                first_depth = t
        if scheme == "accumulate" and accumulated_alpha >= 1.0:
            break
    if scheme == "max": return max_intensity
    if scheme == "average": return sum_intensity / count if count > 0 else 0.0
    if scheme == "first": return first_intensity, first_depth
    return accumulated_color, accumulated_alpha
```

## Subtopics

### [Pixel Intensity Evaluation with Scene Aggregates](10890-pixel-intensity-evaluation-with-scene-aggregates.md)
This method replaces sequential ray marching with a precomputed visibility aggregation model to solve the problem of blending scene aggregates with external backgrounds while handling inter-voxel correlation [10890-pixel-intensity-evaluation-with-scene-aggregates.md]. Unlike standard schemes that process samples sequentially, it evaluates pixel intensity by integrating radiance over the pixel footprint using Aggregated Visibility Functions [10890-pixel-intensity-evaluation-with-scene-aggregates.md]. It is chosen when accurate silhouette reconstruction and background blending are required without per-ray traversal overhead [10890-pixel-intensity-evaluation-with-scene-aggregates.md]. See [Pixel Intensity Evaluation with Scene Aggregates](10890-pixel-intensity-evaluation-with-scene-aggregates.md).

### [X-Ray Volume Rendering](11336-x-ray-volume-rendering.md)
This scheme computes a linear accumulation of voxel intensity values along a ray, producing an image similar to a projectional X-ray or CT scan [11336-x-ray-volume-rendering.md]. Unlike standard direct volume rendering which uses alpha compositing to simulate transparency and occlusion, this method sums the sampled values to highlight dense structures without depth-based occlusion [11336-x-ray-volume-rendering.md]. It differs from its sibling [Average](6890-ray-traversal-schemes.md) rendering by explicitly normalizing the sum by the total number of steps to maintain intensity invariance relative to step size, whereas Average typically divides by the count of valid or non-background samples [11336-x-ray-volume-rendering.md]. See [X-Ray Volume Rendering](11336-x-ray-volume-rendering.md).

### Intensity
Extracts the intensity value of the first sample along the ray [S1, S2, unofficial]. It is used when the goal is to visualize specific internal structures rather than the entire volume [S1, unofficial].

### Max (Maximum Intensity Projection)
Projects the maximum intensity value encountered along the entire ray length [S2, S3, unofficial]. It is particularly useful for visualizing high-contrast structures like blood vessels in Magnetic Resonance Angiography or CT angiography, as it preserves the brightest voxels regardless of depth [S2, S3, unofficial].

### Average
Produces an X-ray-like picture by averaging the scalar values along the ray [S2, S3, unofficial]. This method removes depth cues and occlusion, providing a global view of density distribution [S2, unofficial].

### Accumulate
Accumulates opacity while compositing colors to make transparent layers visible [S2, S3, unofficial]. This is the standard direct volume rendering approach described in the parent article, utilizing the front-to-back compositing equation [S1, S2, unofficial].

### First
Extracts the intensity or depth value of the first sample along the ray [S1, S2, unofficial]. It is used for surface extraction and visualization of specific boundaries [S1, S2, unofficial].

### Depth
Records the distance $t$ along the ray where the primary visual event occurs [S1, S2, unofficial]. It is used for depth mapping and spatial analysis [S1, S2, unofficial].

#### Voxel Aggregation Methods
These variants focus on probabilistic or differentiable aggregation for neural rendering contexts [S4, unofficial].
*   **Yan et al.**: Casts a ray and selects the voxel with the highest occupancy probability [S4, unofficial].
*   **Tulsiani et al.**: Computes the probability that a ray stops at a certain distance, enabling depth map and color image rendering [S4, unofficial].
*   **Henzler et al.**: Introduces bidirectional emission-absorption light radiation models alongside visual hull and absorption-only models [S4, unofficial].
*   **Lombardi et al.**: Iteratively accumulates color and opacity probabilities, discarding remaining voxels when cumulative opacity reaches a maximum [S4, unofficial].
*   **Jiang et al.**: Locates the surface voxel closest to the camera for Signed Distance Functions, computing color as a weighted sum of the surface and neighboring voxels, with shading based on local normals [S4, unofficial]. Note that locating the surface point is not differentiable, though the pixel color is differentiable with respect to surrounding voxels [S4, unofficial].

## Background
The classification of ray traversal schemes was formalized in early direct volume rendering literature [S1, S2, S3, unofficial]. The "Accumulate" scheme is attributed to Levoy (1988) as the standard for volumetric compositing [S1, S2, S3, unofficial]. Maximum Intensity Projection and Average projection were established as standard alternatives for specific medical imaging applications, such as angiography and X-ray simulation [S2, S3, unofficial]. Recent developments in differentiable rendering have expanded these schemes to include probabilistic aggregation and neural voxel representations [S4, unofficial].
