# Terminal Rendering Pipeline

Also called: ASCII Raymarcher Display, ASCII/ANSI Volume Rendering, Character-based Screen Buffer, Terminal ASCII Rendering Pipeline

## Overview
The Terminal Rendering Pipeline renders a 3D scene to a text-based terminal buffer by iterating over pixels, mapping them to Normalized Device Coordinates (NDC), casting rays via a raymarcher, and applying ASCII/ANSI styling based on depth and lighting [S1, unofficial]. It differs from standard terminal rendering by explicitly accounting for character aspect ratio when converting pixel indices to NDC and using ANSI escape codes to modulate brightness based on depth percentage, effectively acting as a low-resolution, text-based raymarcher [S1, unofficial].

## How it works
**Inputs and Outputs:**
- **Inputs:** Camera position and orientation, raymarcher instance (step count, max distance, epsilon), list of lights, screen height, aspect ratio, and ASCII gradient string [S1, unofficial].
- **Outputs:** Terminal screen buffer containing ASCII characters and ANSI escape codes [S1, unofficial].

**Data Structures:**
- **Screen Buffer:** Two vectors of size `width * height` [S1, unofficial].
  - `pixels_vector`: `std::vector<char>`, stores the ASCII character for each pixel [S1, unofficial].
  - `modifiers_vector`: `std::vector<std::string>`, stores per-pixel ANSI escape codes [S1, unofficial].
- **Dimensions:**
  - `height`: Number of rows [S1, unofficial].
  - `width`: Number of columns, calculated as `height * aspect * CHAR_ASPECT` [S1, unofficial].
  - `CHAR_ASPECT`: Constant value `2.0` to account for character aspect ratio [S1, unofficial].
  - `pixels`: Total pixel count `width * height` [S1, unofficial].
- **NDC Constants:**
  - `half_pixel_width`: `1.0 / (2.0 * width)` [S1, unofficial].
  - `half_pixel_height`: `1.0 / (2.0 * height)` [S1, unofficial].
- **Gradient:**
  - `gradient`: String of ASCII characters representing brightness levels [S1, unofficial].
  - `gradient_size`: Length of the gradient string [S1, unofficial].

**Numbered Steps:**
1. **Initialize Screen:** Determine screen height, calculate width using `width = height * aspect * CHAR_ASPECT`, initialize `pixels_vector` with `EMPTY_CHAR` and `modifiers_vector` with empty strings, calculate `half_pixel_width` and `half_pixel_height`, and set `gradient_size` to the length of the gradient string [S1, unofficial].
2. **Render Loop (per frame):** Clear the terminal screen and hide cursor using static methods, clear the screen buffer, and iterate over all pixel indices $i$ from $0$ to `screen.get_pixel_count() - 1` [S1, unofficial]. For each pixel:
   a. **Convert Pixel Index to NDC:** Calculate column and row from index $i$: $col = i \pmod{width}$, $row = \lfloor i / width \rfloor$ [S1, unofficial]. Calculate NDC coordinates: $ndc_x = \frac{col}{width} + \frac{1}{2 \cdot width}$, $ndc_y = \frac{row}{height} - \frac{1}{2 \cdot height}$ [S1, unofficial].
   b. **Map NDC to World Position:** Use camera projection to map $(ndc_x, ndc_y)$ to world position `pixel_wpos` [S1, unofficial].
   c. **Raymarch:** Cast ray from `cam.pos` to `pixel_wpos` [S1, unofficial]. If hit: compute normalized light intensity `light` based on surface normal and lights, compute depth percentage $D_{perc} = \frac{hit\_distance}{MAX\_DIST}$, and set pixel color based on brightness and depth [S1, unofficial]. If $D_{perc} > 0.666$, apply dim modifier `\u001b[2m`; if $D_{perc} > 0.333$, apply no modifier; else apply bright modifier `\u001b[1m` [S1, unofficial]. Map brightness to gradient character index: $idx = \lfloor \max(brightness - 0.0001, 0.0) \times gradient\_size \rfloor$, clamp $idx$ to $[0, gradient\_size - 1]$, set `pixels_vector[i]` to `gradient[idx]`, and set `modifiers_vector[i]` to the selected ANSI modifier [S1, unofficial]. If no hit: set `pixels_vector[i]` to `EMPTY_CHAR` and `modifiers_vector[i]` to empty string [S1, unofficial].
3. **Output:** Print the buffer to the terminal using `print_buffer()`, which outputs each character with its corresponding ANSI modifier [S1, unofficial].

**Pseudocode:**
```python
def render_frame(height, aspect, raymarcher, lights, gradient):
    CHAR_ASPECT = 2.0
    width = height * aspect * CHAR_ASPECT
    num_pixels = width * height
    gradient_size = len(gradient)
    EMPTY_CHAR = ' '
    
    pixels_vector = [EMPTY_CHAR] * num_pixels
    modifiers_vector = [''] * num_pixels
    
    # [G] Clear terminal and hide cursor using ANSI escape codes.
    print('\033[2J\033[H', end='')
    print('\033[?25l', end='')
    
    for i in range(num_pixels):
        col = i % width
        row = i // width
        
        ndc_x = (col / width) + (1.0 / (2.0 * width))
        ndc_y = (row / height) - (1.0 / (2.0 * height))
        
        # [G] Standard camera projection maps NDC to world coordinates.
        pixel_wpos = camera.ndc_to_world_pos(ndc_x, ndc_y)
        
        # [S1, unofficial] Raymarch from camera position to pixel_wpos.
        # [G] Raymarching step loop and hit detection not detailed in sources.
        hit, normal, hit_distance = raymarcher.raymarch(camera.pos, pixel_wpos)
        
        if hit:
            # [G] Diffuse lighting calculation from scene lights.
            light = sum(l.calculate_diffuse(normal) for l in lights)
            
            max_dist = raymarcher.get_max_dist()
            depth_percentage = hit_distance / max_dist
            
            if depth_percentage > 0.666:
                modifier = "\u001b[2m"
            elif depth_percentage > 0.333:
                modifier = ""
            else:
                modifier = "\u001b[1m"
            
            brightness = light
            idx = int(max(brightness - 0.0001, 0.0) * gradient_size)
            idx = max(0, min(idx, gradient_size - 1))
            
            pixels_vector[i] = gradient[idx]
            modifiers_vector[i] = modifier
        else:
            pixels_vector[i] = EMPTY_CHAR
            modifiers_vector[i] = ""
    
    # Output buffer to terminal
    for i in range(num_pixels):
        print(f"{modifiers_vector[i]}{pixels_vector[i]}", end='')
        if (i + 1) % width == 0:
            print()
    print('\033[?25h', end='')
```

**Parameters:**
- **FPS:** Target frame rate is 30. `FRAME_TIME = 1.0 / FPS` [S1, unofficial].
- **CHAR_ASPECT:** 2.0 [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Aspect Ratio:** Failure to account for character aspect ratio (`CHAR_ASPECT`) results in distorted scenes [S1, unofficial]. The width is scaled by `CHAR_ASPECT` to compensate for the taller-than-wide nature of terminal characters [S1, unofficial].
- **Precision:** The brightness mapping uses a small epsilon (`0.0001`) to avoid index out-of-bounds errors due to floating-point inaccuracies [S1, unofficial].

### [ASCII Rendering with Dithering](4103-ascii-rendering-with-dithering.md)
ASCII Rendering with Dithering renders 3D scenes to a text-based terminal buffer by casting rays, computing lighting, and mapping the resulting continuous-tone color to a limited set of ASCII characters (typically `#` and space) using ANSI escape codes. It differs from standard terminal rendering by employing ordered dithering via a Bayer matrix to simulate grayscale intensity and color depth within the constraints of a fixed 80x24 character grid, effectively acting as a low-resolution, text-based raymarcher.
