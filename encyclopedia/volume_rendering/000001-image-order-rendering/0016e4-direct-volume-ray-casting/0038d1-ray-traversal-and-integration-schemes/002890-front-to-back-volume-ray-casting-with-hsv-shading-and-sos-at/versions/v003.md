# Front-to-Back Volume Ray Casting with HSV Shading and SOS/Attenuation/Reflection Filtering

Also called: Front-to-Back Volume Ray Casting

## Overview
This method is a direct volume rendering technique that casts rays from the camera through each pixel into a 3D volume, samples voxel values along the ray, and composites them front-to-back to produce the final pixel color [S1, unofficial]. It distinguishes itself by applying filtering based on Scalar Output Scalar (SOS), Attenuation, and Reflection values, converting volume data to RGB using HSV color space, and using specific thresholding to discard irrelevant samples [S1, unofficial]. It builds on [Ray Traversal and Integration Schemes](8341-ray-traversal-and-integration-schemes.md) by implementing a fixed-step front-to-back integration loop with early termination.

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   `uBackCoord`: A 2D texture storing the exit point coordinates for each pixel (RGB).
    *   `uSliceMaps`: An array of 2D textures storing the volume slices. The layout maps 3D coordinates to 2D slice indices and 2D coordinates within the slice [S1, unofficial].
    *   `frontColor`: Varying vector from the vertex shader representing the entry point (RGB) and potentially other metadata (W) [S1, unofficial].
    *   Uniforms: `uStepsI` (integer, number of steps), `uOpacityVal` (float, opacity scaling), `minSos`, `maxSos`, `minAtten`, `maxAtten`, `minRefl`, `maxRefl` (floats, thresholds) [S1, unofficial].
*   **Outputs:**
    *   `gl_FragColor`: The final composited color and alpha for the pixel [S1, unofficial].

**Data Structures:**
*   **Volume Texture Layout:** The volume is stored as a series of 2D slices (`uSliceMaps`). The 3D coordinate $(x, y, z)$ is mapped to a specific slice index and 2D texture coordinate.
    *   `slicesPerSprite = uSlicesOverX * uSlicesOverY` [S1, unofficial].
    *   `s1Original = floor(z * uNumberOfSlices)` [S1, unofficial].
    *   `tex1Index = int(floor(s1Original / slicesPerSprite))` [S1, unofficial].
    *   `s1 = mod(s1Original, slicesPerSprite)` [S1, unofficial].
    *   `dx1 = fract(s1 / uSlicesOverX)` [S1, unofficial].
    *   `dy1 = floor(s1 / uSlicesOverY) / uSlicesOverY` [S1, unofficial].
    *   `texpos1.x = dx1 + (x / uSlicesOverX)` [S1, unofficial].
    *   `texpos1.y = dy1 + (y / uSlicesOverY)` [S1, unofficial].
    *   The value is retrieved from `uSliceMaps[tex1Index]` at `texpos1` [S1, unofficial]. Note: The source code provided only retrieves a single value (`value1`) and returns it, implying a simplified or single-channel access pattern in the specific implementation cited, despite the structure supporting multi-channel retrieval in the loop logic [S1, unofficial].

**Numbered Steps:**
1.  **Calculate Texture Coordinates:** Compute normalized texture coordinates from the fragment position: $texC = \frac{(pos.xy / pos.w) + 1.0}{2.0}$ [S1, unofficial].
2.  **Retrieve Exit Point:** Sample the back coordinate texture: $backColor = texture2D(uBackCoord, texC)$ [S1, unofficial].
3.  **Compute Ray Direction:** Calculate the direction vector: $dir = backColor.rgb - frontColor.rgb$ [S1, unofficial].
4.  **Initialize Position:** Set current position $vpos = frontColor$ [S1, unofficial].
5.  **Compute Step Size:** Calculate the step vector: $Step = \frac{dir}{uStepsF}$, where $uStepsF = float(uStepsI)$ [S1, unofficial].
6.  **Initialize Accumulators:** Set $accum = vec4(0, 0, 0, 0)$ and $sample = vec4(0, 0, 0, 0)$ [S1, unofficial].
7.  **Loop:** For $i$ from 0 to $uStepsI - 1$:
    8.  **Sample Volume:** Get volume value at $vpos.xyz$. The source code defines `getVolumeValue` returning a single float in one snippet, but the shading logic expects a vec3 (SOS, Attenuation, Reflection). We assume the implementation retrieves a vec3 representing these three components [S1, unofficial]. Let $gray\_val$ be this vec3 [S1, unofficial].
    9.  **Filtering:** If $gray\_val.z < 0.05$ OR $gray\_val.x < minSos$ OR $gray\_val.x > maxSos$ OR $gray\_val.y < minAtten$ OR $gray\_val.y > maxAtten$ OR $gray\_val.z < minRefl$ OR $gray\_val.z > maxRefl$, set $colorValue = vec4(0.0)$ and skip to step 15 [S1, unofficial].
    10. **Compute Color Value:**
        *   $colorValue.x = gray\_val.x$ (SOS)
        *   $colorValue.y = 1.0 - \frac{gray\_val.y}{0.6}$ (Attenuation mapped to G)
        *   $colorValue.z = gray\_val.z$ (Reflection mapped to B)
        *   $colorValue.w = 0.1$ (Base Alpha) [S1, unofficial].
    11. **Compute Sample Alpha:** $sample.a = colorValue.a \times opacityFactor \times \frac{1.0}{uStepsF}$ [S1, unofficial]. Note: The source uses `uOpacityVal` as `opacityFactor` [S1, unofficial].
    12. **Compute Sample RGB:** $sample.rgb = (1.0 - accum.a) \times hsv2rgb(colorValue.rgb) \times sample.a$ [S1, unofficial].
    13. **Accumulate:** $accum += sample$ [S1, unofficial].
    14. **Early Termination (Opacity):** If $accum.a \ge 1.0$, break the loop [S1, unofficial].
    15. **Advance Position:** $vpos.xyz += Step$ [S1, unofficial].
    16. **Boundary Check:** If $vpos.x < 0.0$ OR $vpos.x > 1.0$ OR $vpos.y < 0.0$ OR $vpos.y > 1.0$ OR $vpos.z < 0.0$ OR $vpos.z > 1.0$, break the loop [S1, unofficial].
17. **Output:** Set $gl\_FragColor = accum$ [S1, unofficial].

**HSV to RGB Conversion:**
The method uses an HSV to RGB conversion function `hsv2rgb`. The source code does not provide the explicit implementation of `hsv2rgb`, but standard HSV to RGB conversion logic is required [S1, unofficial].

**Pseudocode:**

```python
def front_to_back_ray_casting(pos, front_color, u_back_coord_sampler, u_slice_maps, 
                              u_slices_over_x, u_slices_over_y, u_number_of_slices,
                              u_steps_i, u_opacity_val, min_sos, max_sos, min_atten, 
                              max_atten, min_refl, max_refl):
    """
    pos: vec4 (fragment position)
    front_color: vec4 (entry point and metadata)
    u_back_coord_sampler: sampler2D
    u_slice_maps: array of sampler2D
    u_slices_over_x: float
    u_slices_over_y: float
    u_number_of_slices: float
    u_steps_i: int
    u_opacity_val: float
    min_sos, max_sos, min_atten, max_atten, min_refl, max_refl: float
    """
    
    # 1. Calculate Texture Coordinates
    tex_c = ((pos.xy / pos.w) + 1.0) / 2.0
    
    # 2. Retrieve Exit Point
    back_color = texture2D(u_back_coord_sampler, tex_c)
    
    # 3. Compute Ray Direction
    dir = back_color.rgb - front_color.rgb
    
    # 4. Initialize Position
    vpos = front_color
    
    # 5. Compute Step Size
    u_steps_f = float(u_steps_i)
    step = dir / u_steps_f
    
    # 6. Initialize Accumulators
    accum = vec4(0.0, 0.0, 0.0, 0.0)
    sample = vec4(0.0, 0.0, 0.0, 0.0)
    
    slices_per_sprite = u_slices_over_x * u_slices_over_y
    
    for i in range(u_steps_i):
        # 8. Sample Volume
        # Note: The source code's getVolumeValue is simplified. 
        # We assume a function that returns vec3(SOS, Attenuation, Reflection)
        gray_val = get_volume_value_3d(vpos.xyz, u_slice_maps, u_slices_over_x, 
                                       u_slices_over_y, u_number_of_slices)
        
        # 9. Filtering
        if (gray_val.z < 0.05 or 
            gray_val.x < min_sos or gray_val.x > max_sos or 
            gray_val.y < min_atten or gray_val.y > max_atten or 
            gray_val.z < min_refl or gray_val.z > max_refl):
            color_value = vec4(0.0, 0.0, 0.0, 0.0)
        else:
            # 10. Compute Color Value
            color_value = vec4(
                gray_val.x, 
                1.0 - gray_val.y / 0.6, 
                gray_val.z, 
                0.1
            )
        
        # 11. Compute Sample Alpha
        # opacityFactor is u_opacity_val
        sample_a = color_value.w * u_opacity_val * (1.0 / u_steps_f)
        
        # 12. Compute Sample RGB
        # hsv2rgb is assumed to be defined
        sample_rgb = (1.0 - accum.a) * hsv2rgb(color_value.rgb) * sample_a
        sample = vec4(sample_rgb, sample_a)
        
        # 13. Accumulate
        accum += sample
        
        # 14. Early Termination (Opacity)
        if accum.a >= 1.0:
            break
            
        # 15. Advance Position
        vpos.xyz += step
        
        # 16. Boundary Check
        if (vpos.x < 0.0 or vpos.x > 1.0 or 
            vpos.y < 0.0 or vpos.y > 1.0 or 
            vpos.z < 0.0 or vpos.z > 1.0):
            break
            
    # 17. Output
    return accum

def get_volume_value_3d(volpos, u_slice_maps, u_slices_over_x, u_slices_over_y, u_number_of_slices):
    """
    Retrieves a vec3 (SOS, Attenuation, Reflection) from the volume texture array.
    Note: The source code snippet only shows retrieval of a single float/value1.
    This implementation assumes the structure supports vec3 retrieval as per the shading logic.
    """
    s1_original = floor(volpos.z * u_number_of_slices)
    tex1_index = int(floor(s1_original / (u_slices_over_x * u_slices_over_y)))
    s1 = mod(s1_original, u_slices_over_x * u_slices_over_y)
    
    dx1 = fract(s1 / u_slices_over_x)
    dy1 = floor(s1 / u_slices_over_y) / u_slices_over_y
    
    texpos1 = vec2(
        dx1 + (volpos.x / u_slices_over_x),
        dy1 + (volpos.y / u_slices_over_y)
    )
    
    # Assuming the texture at tex1_index stores xyz components
    # In the source, it returns value1 (float). 
    # For the shading logic to work, we must assume vec3 retrieval.
    # If the source strictly returns float, this function would need adjustment.
    # Based on "gray_val.x/y/z" usage, we assume vec3.
    return texture2D(u_slice_maps[tex1_index], texpos1).xyz

def hsv2rgb(hsv):
    """
    Standard HSV to RGB conversion.
    hsv: vec3 (H, S, V) in range [0,1]
    """
    h = hsv.x
    s = hsv.y
    v = hsv.z
    
    if s == 0.0:
        return vec3(v, v, v)
    
    i = floor(h * 6.0)
    f = h * 6.0 - i
    p = v * (1.0 - s)
    q = v * (1.0 - f * s)
    t = v * (1.0 - (1.0 - f) * s)
    
    i = int(i) % 6
    
    if i == 0:
        return vec3(v, t, p)
    elif i == 1:
        return vec3(q, v, p)
    elif i == 2:
        return vec3(p, v, t)
    elif i == 3:
        return vec3(p, q, v)
    elif i == 4:
        return vec3(t, p, v)
    else:
        return vec3(v, p, q)
```

**Parameters:**
*   `uStepsI`: Integer constant, typically 144 [S1, unofficial].
*   `uOpacityVal`: Float, controls opacity scaling. Default 40 in source, but used as a factor [S1, unofficial].
*   `minSos`, `maxSos`: Thresholds for SOS component [S1, unofficial].
*   `minAtten`, `maxAtten`: Thresholds for Attenuation component [S1, unofficial].
*   `minRefl`, `maxRefl`: Thresholds for Reflection component [S1, unofficial].
*   `StepSize`: Distance between samples. In the source, step size is derived from `dir/uStepsF`, but another note mentions `StepSize` adjustable 0-1024.0. The primary algorithm uses fixed steps based on `uStepsI` [S1, unofficial].
*   `bgColor`: Default `vec4(1.0, 1.0, 1.0, 0.0)` [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Opaque Rays:** The loop breaks if `accum.a >= 1.0` to prevent unnecessary computation [S1, unofficial].
*   **Out-of-Bounds:** The loop breaks if `vpos` goes outside `[0.0, 1.0]` to prevent memory access errors [S1, unofficial].
*   **Alpha Clamping:** Accumulated alpha can exceed 1.0 due to precision; it is clamped to 1.0 and the loop breaks [S1, unofficial].
*   **Ray Length:** Termination must account for exact ray length to avoid sampling outside the volume [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot S)$, where $N$ is the number of pixels and $S$ is the number of steps per ray (typically 144) [S1, unofficial]. Early termination reduces average cost for opaque regions.
*   **Memory Complexity:** $O(V)$, where $V$ is the volume size, stored in 2D slice textures [S1, unofficial].
*   **Performance:** Uses a fixed number of steps (144), which is simpler than adaptive step methods but may be less efficient for sparse volumes [S1, unofficial].
*   **Strengths:** Simple implementation, early termination for opaque rays, filtering reduces noise from irrelevant data [S1, unofficial].
*   **Limitations:** Fixed step size may lead to aliasing or slow convergence in low-density regions. HSV mapping is arbitrary and may not represent physical properties accurately [S1, unofficial].
