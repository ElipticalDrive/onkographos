# Front-to-Back Volume Ray Casting with HSV Shading and SOS/Attenuation/Reflection Filtering

Also called: Front-to-Back Volume Ray Casting

## Overview
This method renders a 3D volume by casting rays from the camera through each pixel, sampling voxel values along the ray path, and compositing them front-to-back to produce the final pixel color [S1, unofficial]. It distinguishes itself by using a fixed number of steps per ray and applying specific filtering based on Scalar Output Scalar (SOS), Attenuation, and Reflection values to determine sample validity, while converting volume data to RGB using HSV color space for shading [S1, unofficial]. Unlike adaptive step methods, it uses a constant step count (typically 144) and breaks early on opacity saturation or boundary exit [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   `uBackCoord`: A 2D texture storing the exit point coordinates for each ray, sampled via normalized fragment coordinates [S1, unofficial].
    *   `uSliceMaps`: An array of 2D textures representing volume slices, used to simulate 3D texture lookup [S1, unofficial].
    *   `frontColor`: Varying vector from the vertex shader representing the entry point of the ray [S1, unofficial].
    *   `uStepsI`: Integer constant for the number of steps per ray (default 144) [S1, unofficial].
    *   `uOpacityVal`: Uniform float controlling the opacity scaling factor [S1, unofficial].
    *   `minSos`, `maxSos`: Thresholds for the SOS component [S1, unofficial].
    *   `minAtten`, `maxAtten`: Thresholds for the Attenuation component [S1, unofficial].
    *   `minRefl`, `maxRefl`: Thresholds for the Reflection component [S1, unofficial].
    *   `uSlicesOverX`, `uSlicesOverY`: Dimensions of the sprite sheet layout for slice mapping [S1, unofficial].
    *   `uNumberOfSlices`: Total number of slices in the volume [S1, unofficial].
*   **Outputs:**
    *   `gl_FragColor`: The final accumulated color and alpha for the pixel [S1, unofficial].

**Data Structures:**
*   **Volume Representation:** The volume is stored as a set of 2D slice textures (`uSliceMaps`) arranged in a sprite sheet layout. The 3D position is mapped to 2D texture coordinates based on the slice index and position within the slice [S1, unofficial].
*   **Ray Parameters:**
    *   `EntryPoint`: `vec3` from `frontColor` [S1, unofficial].
    *   `ExitPoint`: `vec3` derived from `uBackCoord` texture lookup [S1, unofficial].
    *   `Step`: `vec3` direction vector divided by `uStepsI` [S1, unofficial].
    *   `accum`: `vec4` accumulator for color and alpha, initialized to `(0,0,0,0)` [S1, unofficial].
    *   `sample`: `vec4` temporary buffer for current sample color and alpha, initialized to `(0,0,0,0)` [S1, unofficial].

**Numbered Steps:**
1.  **Ray Initialization:**
    *   Calculate texture coordinates from the current fragment position: $texC = \frac{(pos.xy/pos.w) + 1.0}{2.0}$ [S1, unofficial].
    *   Sample the back color (exit point) from the `uBackCoord` texture: $backColor = texture2D(uBackCoord, texC)$ [S1, unofficial].
    *   Compute the ray direction vector: $dir = backColor.rgb - frontColor.rgb$ [S1, unofficial].
    *   Initialize the current position $vpos$ to $frontColor$ [S1, unofficial].
    *   Calculate the step size vector: $Step = \frac{dir}{uStepsI}$ [S1, unofficial].
    *   Initialize accumulation buffer $accum = vec4(0,0,0,0)$ and sample buffer $sample = vec4(0,0,0,0)$ [S1, unofficial].

2.  **Ray Marching Loop:**
    *   Loop $i$ from $0$ to $uStepsI - 1$:
        *   Sample the volume value at the current position $vpos.xyz$ using `getVolumeValue` [S1, unofficial]. This function maps the 3D position to 2D slice coordinates and performs texture lookup [S1, unofficial].
        *   Let the sampled value be $gray\_val = (gray\_val.x, gray\_val.y, gray\_val.z)$ representing (SOS, Attenuation, Reflection) [S1, unofficial].
        *   **Filtering:** If $gray\_val.z < 0.05$ OR $gray\_val.x < minSos$ OR $gray\_val.x > maxSos$ OR $gray\_val.y < minAtten$ OR $gray\_val.y > maxAtten$ OR $gray\_val.z < minRefl$ OR $gray\_val.z > maxRefl$, set $colorValue = vec4(0.0)$ and skip shading for this step [S1, unofficial].
        *   **Color Mapping:** Otherwise, compute $colorValue$ components:
            *   $colorValue.x = gray\_val.x$
            *   $colorValue.y = 1.0 - \frac{gray\_val.y}{0.6}$
            *   $colorValue.z = gray\_val.z$
            *   $colorValue.w = 0.1$ [S1, unofficial].
        *   **HSV to RGB:** Convert $colorValue.rgb$ from HSV to RGB using `hsv2rgb` [S1, unofficial].
        *   **Sample Alpha:** Compute sample alpha: $sample.a = colorValue.a \times uOpacityVal \times \frac{1.0}{uStepsI}$ [S1, unofficial].
        *   **Sample RGB:** Compute sample RGB: $sample.rgb = (1.0 - accum.a) \times hsv2rgb(colorValue.rgb) \times sample.a$ [S1, unofficial].
        *   **Accumulation:** Add sample to accum: $accum += sample$ [S1, unofficial].
        *   **Termination Check:** If $accum.a \ge 1.0$, break the loop [S1, unofficial].
        *   **Advance Position:** $vpos.xyz += Step$ [S1, unofficial].
        *   **Boundary Check:** If $vpos.x$, $vpos.y$, or $vpos.z$ is outside $[0.0, 1.0]$, break the loop [S1, unofficial].

3.  **Output:**
    *   Output $accum$ as `gl_FragColor` [S1, unofficial].

**Formulas:**
*   **Ray Direction:** $dir = ExitPoint - EntryPoint$ [S1, unofficial].
*   **Step Vector:** $Step = \frac{dir}{uStepsI}$ [S1, unofficial].
*   **Sample Alpha:** $sample.a = colorValue.a \times uOpacityVal \times \frac{1.0}{uStepsI}$ [S1, unofficial].
*   **Sample RGB:** $sample.rgb = (1.0 - accum.a) \times hsv2rgb(colorValue.rgb) \times sample.a$ [S1, unofficial].
*   **Accumulation:**
    $$ accum.rgb += (1.0 - accum.a) \times sample.rgb $$
    $$ accum.a += (1.0 - accum.a) \times sample.a $$
    [S1, unofficial].

**Parameters:**
*   `uStepsI`: 144 [S1, unofficial].
*   `uOpacityVal`: 40 (default) [S1, unofficial].
*   `minSos`, `maxSos`: Thresholds for SOS [S1, unofficial].
*   `minAtten`, `maxAtten`: Thresholds for Attenuation [S1, unofficial].
*   `minRefl`, `maxRefl`: Thresholds for Reflection [S1, unofficial].
*   `StepSize`: Adjustable via UI, range 0 to 1024.0 [S1, unofficial].
*   `bgColor`: `vec4(1.0, 1.0, 1.0, 0.0)` [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Out-of-Bounds Access:** The loop breaks if $vpos$ goes outside $[0,1]$ to prevent out-of-bounds memory access [S1, unofficial].
*   **Alpha Clamping:** Accumulated alpha can exceed 1.0 due to floating-point precision; it is handled by clamping to 1.0 and breaking the loop [S1, unofficial].
*   **Ray Termination:** The loop breaks if accumulated alpha reaches 1.0, preventing unnecessary computation for opaque rays [S1, unofficial].
*   **Ray Length:** Ray termination must account for the exact ray length to avoid sampling outside the volume [S1, unofficial].

**Pseudocode:**
```python
import math

def hsv2rgb(h, s, v):
    # Standard HSV to RGB conversion [G]
    if s == 0.0:
        return (v, v, v)
    i = int(h * 6.0)
    f = h * 6.0 - i
    p = v * (1.0 - s)
    q = v * (1.0 - s * f)
    t = v * (1.0 - s * (1.0 - f))
    i %= 6
    if i == 0:
        return (v, t, p)
    elif i == 1:
        return (q, v, p)
    elif i == 2:
        return (p, v, t)
    elif i == 3:
        return (p, q, v)
    elif i == 4:
        return (t, p, v)
    else:
        return (v, p, q)

def get_volume_value(volpos, uNumberOfSlices, uSlicesOverX, uSlicesOverY, uSliceMaps):
    # Simulates 3D texture lookup using 2D slice maps [S1, unofficial]
    slicesPerSprite = uSlicesOverX * uSlicesOverY
    s1Original = math.floor(volpos[2] * uNumberOfSlices)
    tex1Index = int(math.floor(s1Original / slicesPerSprite))
    s1 = s1Original % slicesPerSprite
    dx1 = s1 / uSlicesOverX - math.floor(s1 / uSlicesOverX)
    dy1 = math.floor(s1 / uSlicesOverY) / uSlicesOverY
    texpos1_x = dx1 + (volpos[0] / uSlicesOverX)
    texpos1_y = dy1 + (volpos[1] / uSlicesOverY)
    # In a real implementation, uSliceMaps would be accessed here.
    # For pseudocode, we assume a function texture2D exists.
    # value = texture2D(uSliceMaps[tex1Index], (texpos1_x, texpos1_y)).xyz
    # Returning a dummy value for completeness
    return (0.5, 0.5, 0.5)

def raycast(frontColor, backColor, uStepsI, uOpacityVal, minSos, maxSos, minAtten, maxAtten, minRefl, maxRefl, uNumberOfSlices, uSlicesOverX, uSlicesOverY, uSliceMaps):
    dir_vec = [backColor[0] - frontColor[0], backColor[1] - frontColor[1], backColor[2] - frontColor[2]]
    vpos = [frontColor[0], frontColor[1], frontColor[2]]
    Step = [dir_vec[0] / uStepsI, dir_vec[1] / uStepsI, dir_vec[2] / uStepsI]
    
    accum = [0.0, 0.0, 0.0, 0.0] # r, g, b, a
    sample = [0.0, 0.0, 0.0, 0.0]
    
    for i in range(uStepsI):
        # Sample volume
        gray_val = get_volume_value(vpos, uNumberOfSlices, uSlicesOverX, uSlicesOverY, uSliceMaps)
        
        # Filtering
        if (gray_val[2] < 0.05 or gray_val[0] < minSos or gray_val[0] > maxSos or
            gray_val[1] < minAtten or gray_val[1] > maxAtten or
            gray_val[2] < minRefl or gray_val[2] > maxRefl):
            colorValue = [0.0, 0.0, 0.0, 0.0]
        else:
            colorValue = [gray_val[0], 1.0 - gray_val[1]/0.6, gray_val[2], 0.1]
        
        # HSV to RGB
        rgb = hsv2rgb(colorValue[0], colorValue[1], colorValue[2])
        
        # Sample Alpha
        sample[3] = colorValue[3] * uOpacityVal * (1.0 / uStepsI)
        
        # Sample RGB
        sample[0] = (1.0 - accum[3]) * rgb[0] * sample[3]
        sample[1] = (1.0 - accum[3]) * rgb[1] * sample[3]
        sample[2] = (1.0 - accum[3]) * rgb[2] * sample[3]
        
        # Accumulation
        accum[0] += sample[0]
        accum[1] += sample[1]
        accum[2] += sample[2]
        accum[3] += (1.0 - accum[3]) * sample[3]
        
        # Termination
        if accum[3] >= 1.0:
            break
        
        # Advance
        vpos[0] += Step[0]
        vpos[1] += Step[1]
        vpos[2] += Step[2]
        
        # Boundary Check
        if vpos[0] < 0.0 or vpos[0] > 1.0 or vpos[1] < 0.0 or vpos[1] > 1.0 or vpos[2] < 0.0 or vpos[2] > 1.0:
            break
            
    return accum
```

## Operating characteristics
*   **Time Complexity:** $O(N \times S)$, where $N$ is the number of pixels and $S$ is the number of steps per ray (fixed at 144) [S1, unofficial].
*   **Memory Complexity:** $O(V)$, where $V$ is the size of the volume data stored in slice textures [S1, unofficial].
*   **Performance:** The method uses a fixed number of steps, which simplifies implementation but may not be as efficient as adaptive methods for sparse volumes [S1, unofficial].
*   **Strengths:** Simple implementation, early termination for opaque regions, specific filtering for SOS/Attenuation/Reflection values allows for targeted visualization [S1, unofficial].
*   **Limitations:** Fixed step size may lead to aliasing or missed details in complex volumes; HSV conversion may not be suitable for all data types [S1, unofficial].
*   **When to Use:** Suitable for real-time rendering where performance is critical and the volume data has distinct SOS/Attenuation/Reflection characteristics [S1, unofficial].
*   **When Not to Use:** Not suitable for volumes requiring high accuracy or adaptive sampling [S1, unofficial].
