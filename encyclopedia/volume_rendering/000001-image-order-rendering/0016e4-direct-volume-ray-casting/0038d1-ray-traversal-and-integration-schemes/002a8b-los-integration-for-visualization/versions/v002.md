# LOS-integration for visualization

Also called: LUT-based Line-of-Sight Integration, column_ne integration, emission integration, ewt_temp integration

## Overview
LOS-integration for visualization computes physical scalar quantities (electron column density, integrated emissivity, or emission-weighted temperature) along camera rays by integrating sampled neural network or ground truth fields [S1, unofficial]. It differs from standard direct volume rendering by outputting physically consistent integrated values rather than final pixel colors, often serving as a diagnostic or intermediate visualization step for solar corona data [S1, unofficial]. It is distinct from [Pre-integrated Volume Rendering](5327-pre-integrated-volume-rendering.md) by using learned or GT fields for the integrand rather than pre-computed lookup tables of transmittance, and from [Next Event Estimation for Emissive Volumes](3557-next-event-estimation-for-emissive-volumes.md) by performing deterministic line-of-sight integration rather than stochastic path tracing [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
*   `rays_o`: Ray origins, shape `(N, 3)` [S1, unofficial].
*   `rays_d`: Ray directions, shape `(N, 3)` [S1, unofficial].
*   `t_s`: Start times for samples, shape `(M,)` [S1, unofficial].
*   `t_e`: End times for samples, shape `(M,)` [S1, unofficial].
*   `ray_idx`: Indices mapping samples to rays, shape `(M,)` [S1, unofficial].
*   `valid`: Boolean mask for valid rays, shape `(N,)` [S1, unofficial].
*   `quantity`: String, one of `'column_ne'`, `'emission'`, or `'ewt_temp'` [S1, unofficial].
*   `uniform_samples`: Integer, number of uniform samples if requested (default 0) [S1, unofficial].
*   `r_min_rsun`: Float or None, minimum radius in solar radii to keep samples (default None) [S1, unofficial].
*   `r_max_rsun`: Float or None, maximum radius in solar radii to keep samples (default None) [S1, unofficial].
*   `channels`: List, tuple, int, or None, spectral line indices to select (default None, all channels) [S1, unofficial].
*   `use_gt`: Boolean, whether to use ground truth fields if available [S1, unofficial].
*   `clamp`: Boolean, whether to clamp log fields to configured bounds [S1, unofficial].

**Outputs:**
*   `full`: Tensor of shape `(N, C)` where $C$ is the number of intensity channels (or 1 for column density), containing integrated values. Invalid rays contain NaN [S1, unofficial].

### Data Structures
*   **Scalar Fields**: Accessed via `self.ne_field` and `self.temp_field` (ground truth) or predicted via `self._predict_learned_fields` [S1, unofficial]. These return logarithmic values $\log_{10} n_e$ and $\log_{10} T$ [S1, unofficial].
*   **Emissivity Coefficient Field**: `self.ccoef_field` takes stacked inputs $(\log n_e, \log T, \log r)$ and outputs coefficients $c_{coef}$ [S1, unofficial].
*   **Configuration**: `self.aabb_scale` scales AABB coordinates to physical units; `self.cfg['rsun_to_cm']` (default $6.957 \times 10^{10}$) converts solar radii to centimeters [S1, unofficial].

### Steps
1.  **Ray Preparation**: Convert `rays_o` and `rays_d` to the renderer's dtype and device [S1, unofficial].
2.  **Sampling**:
    *   If `uniform_samples > 0`, call `_sample_uniform_shell` to obtain `t_s`, `t_e`, `ray_idx`, and `valid` [S1, unofficial].
    *   Otherwise, call `_sample_points_along_rays` [S1, unofficial].
3.  **Coordinate Conversion**:
    *   Compute midpoints: $t_{mid} = 0.5 \times (t_s + t_e)$ [S1, unofficial].
    *   Compute Cartesian coordinates in AABB space: $\mathbf{x}_{AABB} = \mathbf{rays\_o}_{valid}[\mathbf{ray\_idx}] + t_{mid} \times \mathbf{rays\_d}_{valid}[\mathbf{ray\_idx}]$ [S1, unofficial].
    *   Scale to physical units: $\mathbf{x}_{xyz} = \mathbf{x}_{AABB} \times \text{self.aabb\_scale}$ [S1, unofficial].
4.  **Radial Masking**:
    *   Compute sample radius: $r_{samp} = \|\mathbf{x}_{xyz}\|$ [S1, unofficial].
    *   Initialize mask $\mathbf{keep\_w} = \mathbf{1}$ [S1, unofficial].
    *   If `r_min_rsun` is not None, $\mathbf{keep\_w} \leftarrow \mathbf{keep\_w} \times (r_{samp} \ge r_{min\_rsun})$ [S1, unofficial].
    *   If `r_max_rsun` is not None, $\mathbf{keep\_w} \leftarrow \mathbf{keep\_w} \times (r_{samp} \le r_{max\_rsun})$ [S1, unofficial]. This prevents saturated disk artifacts from chromospheric base padding [S1, unofficial].
5.  **Field Retrieval**:
    *   If `use_gt` and `self.ne_field` exists, query $\log n_e = \text{self.ne\_field}(\mathbf{x}_{xyz})$ and optionally $\log T = \text{self.temp\_field}(\mathbf{x}_{xyz})$ [S1, unofficial].
    *   Else, call `self._predict_learned_fields(x_AABB)` to get $\log n_e$ and $\log T$ [S1, unofficial].
    *   If `clamp` is True, clamp $\log n_e$ and $\log T$ to configured min/max bounds [S1, unofficial].
6.  **Segment Length**:
    *   Compute physical segment length: $L_{seg} = (t_e - t_s) \times \text{self.aabb\_scale} \times \text{self.cfg.get('rsun\_to\_cm', 6.957 \times 10^{10})}$ [S1, unofficial].
7.  **Integration Helper**:
    *   Define `integ(vals)` which initializes an output tensor of size $N_{valid}$ and accumulates values per ray: $\text{out}[\mathbf{ray\_idx}] \leftarrow \text{out}[\mathbf{ray\_idx}] + \text{vals} \times L_{seg} \times \mathbf{keep\_w}$ [S1, unofficial].
8.  **Quantity Computation**:
    *   **If `quantity == 'column_ne'`**:
        *   Compute electron density: $n_e = 10^{\log n_e}$ [S1, unofficial].
        *   Integrate: $P_{ray} = \text{integ}(n_e)$ [S1, unofficial].
    *   **If `quantity == 'emission'` or `quantity == 'ewt_temp'`**:
        *   Compute radius: $r = \|\mathbf{x}_{xyz}\|$, $\log r = \log_{10}(r)$ [S1, unofficial].
        *   Clamp $\log r$ if `clamp` is True [S1, unofficial].
        *   Stack inputs: $\mathbf{ntr} = [\log n_e, \log T, \log r]^T$ (transposed to shape $(M, 3)$) [S1, unofficial].
        *   Query emissivity coefficient: $\mathbf{ccoef\_all} = \text{self.ccoef\_field}(\mathbf{ntr})$ [S1, unofficial].
        *   Select specified channels if `channels` is not None [S1, unofficial].
        *   Sum over channels to get emissivity $\epsilon$ [S1, unofficial].
        *   **For 'emission'**:
            *   Integrate: $P_{ray} = \text{integ}(\epsilon)$ [S1, unofficial].
        *   **For 'ewt_temp'**:
            *   Numerator: $Num = \text{integ}(10^{\log T} \times \epsilon)$ [S1, unofficial].
            *   Denominator: $Den = \text{integ}(\epsilon)$ [S1, unofficial].
            *   Result: $P_{ray} = Num / \max(Den, 10^{-30})$ [S1, unofficial].
9.  **Finalization**:
    *   Initialize `full` tensor of shape $(N, C)$ with NaN [S1, unofficial].
    *   Set `full[valid] = P_{ray}` [S1, unofficial].
    *   Return `full` [S1, unofficial].

### Pseudocode
```python
def los_integration(rays_o, rays_d, t_s, t_e, ray_idx, valid, quantity, 
                    uniform_samples=0, r_min_rsun=None, r_max_rsun=None, 
                    channels=None, use_gt=False, clamp=False, 
                    aabb_scale=1.0, rsun_to_cm=6.957e10, 
                    ne_field=None, temp_field=None, ccoef_field=None, 
                    predict_learned_fields=None):
    """
    Performs Line-of-Sight integration for visualization.
    Returns full tensor of shape (N, C) with NaN for invalid rays.
    """
    N = rays_o.shape[0]
    
    # 1. Ray Preparation (dtype/device handling assumed handled by caller or framework)
    
    # 2. Sampling
    if uniform_samples > 0:
        t_s, t_e, ray_idx, valid = _sample_uniform_shell(uniform_samples)
    else:
        t_s, t_e, ray_idx, valid = _sample_points_along_rays()
        
    M = t_s.shape[0]
    N_valid = valid.sum()
    
    # 3. Coordinate Conversion
    t_mid = 0.5 * (t_s + t_e)
    # Select valid rays
    valid_rays_o = rays_o[valid]
    valid_rays_d = rays_d[valid]
    
    # Gather ray origins/directions for samples
    sampled_o = valid_rays_o[ray_idx]
    sampled_d = valid_rays_d[ray_idx]
    
    # Compute AABB coordinates
    x_AABB = sampled_o + t_mid[:, None] * sampled_d
    
    # Scale to physical units
    x_xyz = x_AABB * aabb_scale
    
    # 4. Radial Masking
    r_samp = torch.linalg.vector_norm(x_xyz, dim=-1)
    keep_w = torch.ones_like(r_samp)
    
    if r_min_rsun is not None:
        keep_w = keep_w * (r_samp >= r_min_rsun)
    if r_max_rsun is not None:
        keep_w = keep_w * (r_samp <= r_max_rsun)
        
    # 5. Field Retrieval
    if use_gt and ne_field is not None:
        log_ne = ne_field(x_xyz)
        if temp_field is not None:
            log_temp = temp_field(x_xyz)
        else:
            log_temp = None
    else:
        _, log_ne, log_temp = predict_learned_fields(x_AABB)
        if log_temp is None and temp_field is not None:
            log_temp = temp_field(x_xyz)
            
    if clamp:
        # Assuming configured min/max bounds are available or defaults
        log_ne = torch.clamp(log_ne, min=-10, max=10) # Placeholder bounds [G]
        if log_temp is not None:
            log_temp = torch.clamp(log_temp, min=5, max=8) # Placeholder bounds [G]
            
    # 6. Segment Length
    seg_len = (t_e - t_s) * aabb_scale * rsun_to_cm
    
    # 7. Integration Helper
    def integ(vals):
        out = torch.zeros(N_valid, device=vals.device, dtype=vals.dtype)
        # out.index_add_(0, ray_idx, vals * seg_len * keep_w)
        # Manual implementation for clarity
        weighted_vals = vals * seg_len * keep_w
        for i in range(M):
            out[ray_idx[i]] += weighted_vals[i]
        return out

    # 8. Quantity Computation
    if quantity == 'column_ne':
        ne = torch.pow(10.0, log_ne)
        per_ray = integ(ne)
        full = torch.full((N, 1), float('nan'), dtype=per_ray.dtype)
        full[valid] = per_ray
        return full
        
    elif quantity in ['emission', 'ewt_temp']:
        r = torch.linalg.vector_norm(x_xyz, dim=-1)
        log_r = torch.log10(r)
        if clamp:
            log_r = torch.clamp(log_r, min=-10, max=10) # Placeholder bounds [G]
            
        # Stack inputs: (M, 3)
        ntr = torch.stack([log_ne, log_temp, log_r], dim=-1)
        
        # Query ccoef
        ccoef_all = ccoef_field(ntr) # Returns (M, C_channels)
        
        if channels is not None:
            ccoef = ccoef_all[:, channels]
        else:
            ccoef = ccoef_all
            
        # Sum over channels to get emissivity epsilon
        eps = torch.sum(ccoef, dim=-1)
        
        if quantity == 'emission':
            per_ray = integ(eps)
            full = torch.full((N, 1), float('nan'), dtype=per_ray.dtype)
            full[valid] = per_ray
            return full
            
        elif quantity == 'ewt_temp':
            temp_lin = torch.pow(10.0, log_temp)
            num = integ(temp_lin * eps)
            den = integ(eps)
            # Clamp denominator to avoid division by zero
            den = torch.clamp(den, min=1e-30)
            per_ray = num / den
            full = torch.full((N, 1), float('nan'), dtype=per_ray.dtype)
            full[valid] = per_ray
            return full
            
    else:
        raise ValueError(f"Unknown quantity: {quantity}")
```

### Parameters
*   `uniform_samples`: int, number of uniform samples if requested. Default 0 [S1, unofficial].
*   `r_min_rsun`: Union[float, None], minimum radius in solar radii to keep samples. Default None [S1, unofficial].
*   `r_max_rsun`: Union[float, None], maximum radius in solar radii to keep samples. Default None [S1, unofficial].
*   `channels`: Union[list, tuple, int, None], spectral line indices to select for emission/ewt_temp. Default None (all channels) [S1, unofficial].
*   `quantity`: str, one of 'column_ne', 'emission', 'ewt_temp'. Defines the integrand [S1, unofficial].
*   `rsun_to_cm`: Constant from config, default `6.957e10`, converting solar radii to centimeters [S1, unofficial].
*   `wavelengths`: List of wavelengths in Angstroms (implied by `* 1e-8` conversion to meters in `ph2ergs` calculation) used for photon-to-ergs conversion [S1, unofficial].

### Edge Cases and Pitfalls
*   **Saturated Disk Artifacts**: Integrating below $r=1 R_{sun}$ manufactures a saturated filled disk because the spherical interpolant border-pads the dense chromospheric base. This is handled by zeroing out-of-shell samples' contribution via the `keep_w` mask based on `r_min_rsun`/`r_max_rsun` [S1, unofficial].
*   **Division by Zero**: In `ewt_temp`, the denominator (integrated emissivity) can be zero. This is handled by `den.clamp_min(1e-30)` [S1, unofficial].
*   **Invalid Rays**: Rays that do not intersect the volume or are otherwise invalid return NaN in the output tensor [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: Linear with respect to the number of samples $M$ and rays $N$, dominated by field queries and integration accumulation [S1, unofficial].
*   **Memory Complexity**: Linear with respect to $N$ and $M$ for storing ray data, sample coordinates, and intermediate field values [S1, unofficial].
*   **Strengths**: Provides physically consistent integrated quantities (column density, emissivity, temperature) suitable for diagnostic visualization [S1, unofficial]. Efficiently handles large volumes via uniform sampling and GPU-accelerated indexing [S1, unofficial].
*   **Limitations**: Requires access to scalar fields (GT or learned) and emissivity coefficients [S1, unofficial]. Sensitive to radial boundaries due to chromospheric padding artifacts if not masked [S1, unofficial].
*   **When to Use**: When physical diagnostics of the solar corona (density, temperature, emission) are required rather than final rendered images [S1, unofficial].
*   **When Not to Use**: When real-time interactive rendering of final pixel colors is the primary goal without post-processing [S1, unofficial].

## Background
LOS-integration for visualization is part of the CoroNeRF framework, which uses neural radiance fields for solar corona rendering [S1, unofficial]. It was developed to provide physically meaningful visualizations of solar atmospheric properties by integrating learned or ground truth fields along lines of sight [S1, unofficial]. The method supports multiple physical quantities, including electron column density, integrated emissivity, and emission-weighted temperature, allowing for flexible diagnostic analysis of solar data [S1, unofficial].
