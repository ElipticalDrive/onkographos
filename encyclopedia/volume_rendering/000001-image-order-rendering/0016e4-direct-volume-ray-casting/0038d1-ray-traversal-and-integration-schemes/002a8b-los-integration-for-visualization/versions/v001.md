# LOS-integration for visualization

Also called: LUT-based Line-of-Sight Integration, column_ne integration, emission integration, ewt_temp integration

## Overview
LOS-integration for visualization computes scalar physical quantities along camera rays by integrating emissivity or density fields, typically derived from neural networks or ground truth data, rather than rendering color directly. It differs from standard direct volume ray casting by outputting integrated physical metrics (column density, total emission, or emission-weighted temperature) instead of accumulated RGB color, and by relying on a lookup table (LUT) or field query for emissivity coefficients rather than a direct transfer function. It is specifically designed for solar corona visualization to handle physical unit conversions and radial masking.

## How it works
### Inputs and Outputs
**Inputs:**
*   `rays_o`: Ray origins, shape $(N, 3)$ [S1, unofficial].
*   `rays_d`: Ray directions, shape $(N, 3)$ [S1, unofficial].
*   `t_s`: Start times for sample segments, shape $(M,)$ [S1, unofficial].
*   `t_e`: End times for sample segments, shape $(M,)$ [S1, unofficial].
*   `ray_idx`: Indices mapping samples to rays, shape $(M,)$ [S1, unofficial].
*   `valid`: Boolean mask for valid rays, shape $(N,)$ [S1, unofficial].
*   `quantity`: String specifying the integrand: `'column_ne'`, `'emission'`, or `'ewt_temp'` [S1, unofficial].
*   `aabb_scale`: Scaling factor from AABB space to physical units (e.g., solar radii) [S1, unofficial].
*   `rsun_to_cm`: Conversion constant, default $6.957 \times 10^{10}$ cm/R$_\odot$ [S1, unofficial].
*   `wavelengths`: List of wavelengths in Angstroms for photon-to-erg conversion [S1, unofficial].
*   `r_min_rsun`, `r_max_rsun`: Optional radial bounds to restrict integration to the corona shell [S1, unofficial].
*   `channels`: Optional spectral line indices to select [S1, unofficial].
*   `use_gt`: Boolean flag to use ground truth fields instead of neural network predictions [S1, unofficial].

**Outputs:**
*   `full`: Integrated scalar values, shape $(N, C)$, where $C$ is the number of intensity channels. Invalid rays contain NaN [S1, unofficial].

### Data Structures
*   **Field Queries**: Access to `ne_field` (electron density) and `temp_field` (temperature) which return log-values ($\log_{10} n_e$, $\log_{10} T$) given Cartesian coordinates [S1, unofficial].
*   **Emissivity Coefficient Field (`ccoef_field`)**: A LUT or neural network that takes stacked inputs $(\log_{10} n_e, \log_{10} T, \log_{10} r)$ and outputs emissivity coefficients $c_{coef}$ in units of erg s$^{-1}$ cm$^{-3}$ sr$^{-1}$ [S1, unofficial].

### Steps
1.  **Ray Initialization**: Convert `rays_o` and `rays_d` to the target dtype and device [S1, unofficial]. Determine sample points along rays. If `uniform_samples > 0`, use uniform sampling; otherwise, use point-based sampling to generate `t_s`, `t_e`, `ray_idx`, and `valid` [S1, unofficial].
2.  **Coordinate Conversion**:
    *   Compute segment midpoints: $t_{mid} = 0.5 \times (t_s + t_e)$ [S1, unofficial].
    *   Compute Cartesian coordinates in AABB space: $x_{AABB} = rays\_o[valid][ray\_idx] + t_{mid} \times rays\_d[valid][ray\_idx]$ [S1, unofficial].
    *   Convert to physical units: $x_{xyz} = x_{AABB} \times aabb\_scale$ [S1, unofficial].
3.  **Radial Masking**:
    *   Compute sample radius: $r_{samp} = \|x_{xyz}\|$ [S1, unofficial].
    *   Initialize keep mask: $keep\_w = \mathbf{1}$ [S1, unofficial].
    *   Apply bounds: If $r_{min\_rsun}$ is set, $keep\_w \leftarrow keep\_w \times (r_{samp} \ge r_{min\_rsun})$. If $r_{max\_rsun}$ is set, $keep\_w \leftarrow keep\_w \times (r_{samp} \le r_{max\_rsun})$ [S1, unofficial]. This prevents artifacts from the saturated chromospheric base [S1, unofficial].
4.  **Field Retrieval**:
    *   If `use_gt` and fields are available, query $log\_ne = ne\_field(x_{xyz})$ and optionally $log\_temp = temp\_field(x_{xyz})$ [S1, unofficial].
    *   Otherwise, predict fields using the neural network: $log\_ne, log\_temp = \text{predict}(x_{AABB})$ [S1, unofficial].
    *   Clamp values if configured [S1, unofficial].
5.  **Segment Length Calculation**:
    *   Compute physical segment length: $seg\_len = (t_e - t_s) \times aabb\_scale \times rsun\_to\_cm$ [S1, unofficial].
6.  **Integration Helper**:
    *   Define `integ(vals)` which initializes an output tensor of size $N_{valid}$ and accumulates values indexed by `ray_idx`: $out[ray\_idx] \leftarrow out[ray\_idx] + vals \times seg\_len \times keep\_w$ [S1, unofficial].
7.  **Quantity-Specific Integration**:
    *   **If `quantity == 'column_ne'`**:
        *   Compute electron density: $n_e = 10^{log\_ne}$ [S1, unofficial].
        *   Integrate: $per\_ray = \text{integ}(n_e)$ [S1, unofficial].
    *   **If `quantity == 'emission'` or `'ewt_temp'`**:
        *   Compute radius: $r = \|x_{xyz}\|$, $log\_r = \log_{10}(r)$ [S1, unofficial].
        *   Stack inputs for emissivity: $ntr = \text{stack}([log\_ne, log\_temp, log\_r])$. Transpose so samples are rows [S1, unofficial].
        *   Query emissivity coefficient: $c_{coef\_all} = ccoef\_field(ntr)$ [S1, unofficial].
        *   Select channels if specified [S1, unofficial].
        *   Sum over channels to get emissivity $\epsilon$ [S1, unofficial].
        *   **For 'emission'**:
            *   Integrate: $per\_ray = \text{integ}(\epsilon)$ [S1, unofficial].
        *   **For 'ewt_temp'**:
            *   Numerator: $num = \text{integ}(10^{log\_temp} \times \epsilon)$ [S1, unofficial].
            *   Denominator: $den = \text{integ}(\epsilon)$ [S1, unofficial].
            *   Result: $per\_ray = num / \max(den, 10^{-30})$ [S1, unofficial].
8.  **Output Assembly**:
    *   Initialize `full` tensor of shape $(N, C)$ with NaN [S1, unofficial].
    *   Assign results: $full[valid] = per\_ray$ [S1, unofficial].

### Pseudocode
```python
import torch
import math

def los_integration_for_visualization(
    rays_o, rays_d, t_s, t_e, ray_idx, valid,
    quantity, aabb_scale, rsun_to_cm, wavelengths,
    r_min_rsun=None, r_max_rsun=None, channels=None,
    use_gt=False, ne_field=None, temp_field=None, ccoef_field=None,
    predict_learned_fields=None, clamp=False
):
    """
    Performs Line-of-Sight integration for visualization quantities.
    """
    # 1. Ray Initialization
    # Assume rays_o, rays_d are already on correct device/dtype
    # valid, ray_idx, t_s, t_e are generated by sampling logic [S1, unofficial]
    
    # 2. Coordinate Conversion
    t_mid = 0.5 * (t_s + t_e)
    
    # Gather valid rays
    valid_rays_o = rays_o[valid]
    valid_rays_d = rays_d[valid]
    
    # Compute midpoints in AABB space
    # t_mid is (M,), ray_idx maps to valid rays
    # x_AABB shape: (M, 3)
    x_AABB = valid_rays_o[ray_idx] + t_mid[:, None] * valid_rays_d[ray_idx]
    
    # Convert to physical units
    x_xyz = x_AABB * aabb_scale
    
    # 3. Radial Masking
    r_samp = torch.linalg.vector_norm(x_xyz, dim=-1)
    keep_w = torch.ones_like(r_samp)
    
    if r_min_rsun is not None:
        keep_w = keep_w * (r_samp >= r_min_rsun)
    if r_max_rsun is not None:
        keep_w = keep_w * (r_samp <= r_max_rsun)
        
    # 4. Field Retrieval
    if use_gt and ne_field is not None:
        log_ne = ne_field(x_xyz)
        log_temp = None
        if temp_field is not None:
            log_temp = temp_field(x_xyz)
    else:
        _, log_ne, log_temp = predict_learned_fields(x_AABB)
        if log_temp is None and temp_field is not None:
            log_temp = temp_field(x_xyz)
            
    if clamp:
        # Clamp using configured min/max bounds [G]
        log_ne = torch.clamp(log_ne, min=-10, max=10) # Example bounds
        if log_temp is not None:
            log_temp = torch.clamp(log_temp, min=5, max=8) # Example bounds

    # 5. Segment Length
    # seg_len shape: (M, 1) for broadcasting
    seg_len = (t_e - t_s)[:, None] * aabb_scale * rsun_to_cm
    
    # 6. Integration Helper
    # out accumulates per valid ray index
    N_valid = valid.sum()
    
    def integ(vals):
        # vals shape: (M, ...)
        # We need to multiply by seg_len and keep_w
        weighted = vals * seg_len * keep_w[:, None]
        out = torch.zeros((N_valid, *vals.shape[1:]), device=vals.device, dtype=vals.dtype)
        # index_add_ accumulates into out
        out.index_add_(0, ray_idx, weighted)
        return out

    # 7. Quantity-Specific Integration
    if quantity == 'column_ne':
        ne = torch.pow(10.0, log_ne)
        per_ray = integ(ne)
        
    elif quantity in ['emission', 'ewt_temp']:
        r = torch.linalg.vector_norm(x_xyz, dim=-1)
        log_r = torch.log10(r)
        if clamp:
            log_r = torch.clamp(log_r, min=-5, max=5) # Example bounds
            
        # Stack inputs: (M, 3)
        ntr = torch.stack([log_ne, log_temp, log_r], dim=-1)
        
        # Query ccoef_field
        # ccoef_all shape: (M, C)
        ccoef_all = ccoef_field(ntr)
        
        # Select channels
        if channels is not None:
            ccoef_all = ccoef_all[:, channels]
            
        # Sum over channels to get emissivity epsilon
        eps = torch.sum(ccoef_all, dim=-1, keepdim=True) # Shape (M, 1)
        
        # Unit conversions
        # sr2arcsec = (180/pi)^2 * 3600^2
        # ph2ergs = 6.626e-27 * 3e10 / (wavelengths * 1e-8)
        # Assuming wavelengths is a tensor/list compatible with eps channels
        sr2arcsec = (180.0 / math.pi)**2 * 3600.0**2
        ph2ergs = 6.62607015e-27 * 3e10 / (torch.tensor(wavelengths) * 1e-8)
        
        # Convert emissivity to intensity per arcsec^2 per photon energy
        # epsI shape: (M, C)
        epsI = ccoef_all / ph2ergs[None, :] / sr2arcsec
        
        # Differential intensity dI = epsI * seg_len_phys
        # seg_len_phys shape: (M, 1)
        dI = epsI * seg_len
        
        # Apply radial mask
        dI = dI * keep_w[:, None]
        
        if quantity == 'emission':
            per_ray = integ(dI)
        elif quantity == 'ewt_temp':
            # Numerator: integ(10^log_temp * eps)
            # Note: eps here is raw ccoef sum, not converted to intensity? 
            # Source says: num = integ(torch.pow(10.0, log_temp) * eps)
            # But eps was defined as sum over channels of ccoef. 
            # Let's follow source strictly:
            num = integ(torch.pow(10.0, log_temp) * eps)
            den = integ(eps)
            per_ray = num / torch.clamp_min(den, 1e-30)
            
    else:
        raise ValueError(f"Unknown quantity: {quantity}")

    # 8. Output Assembly
    N_total = rays_o.shape[0]
    C_out = per_ray.shape[1] if per_ray.dim() > 1 else 1
    full = torch.full((N_total, C_out), float('nan'), device=rays_o.device, dtype=rays_o.dtype)
    full[valid] = per_ray
    
    return full
```

### Parameters
*   `uniform_samples`: int, number of uniform samples if requested. Default 0 [S1, unofficial].
*   `r_min_rsun`: float or None, minimum radius in solar radii to keep samples. Default None [S1, unofficial].
*   `r_max_rsun`: float or None, maximum radius in solar radii to keep samples. Default None [S1, unofficial].
*   `channels`: list, tuple, int, or None, spectral line indices to select. Default None (all channels) [S1, unofficial].
*   `quantity`: str, one of `'column_ne'`, `'emission'`, `'ewt_temp'`. Defines the integrand [S1, unofficial].
*   `rsun_to_cm`: float, constant from config, default $6.957 \times 10^{10}$, converting solar radii to centimeters [S1, unofficial].
*   `wavelengths`: list of floats, wavelengths in Angstroms used for photon-to-ergs conversion [S1, unofficial].

### Edge Cases and Pitfalls
*   **Saturated Disk Artifacts**: Integrating below $r=1$ R$_\odot$ manufactures a saturated filled disk because the spherical interpolant border-pads the dense chromospheric base. This is handled by zeroing out-of-shell samples' contribution via the `keep_w` mask based on `r_min_rsun`/`r_max_rsun` [S1, unofficial].
*   **Division by Zero**: In `ewt_temp` calculation, the denominator `den` can be zero. This is handled by `den.clamp_min(1e-30)` [S1, unofficial].
*   **Invalid Rays**: Rays that do not intersect the volume or fall outside valid bounds return NaN in the output tensor [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: Linear with respect to the number of samples $M$ and rays $N$. The dominant cost is the field query (neural network inference or LUT lookup) and the integration accumulation.
*   **Memory Complexity**: Linear with respect to $M$ for intermediate tensors ($x_{xyz}$, $log\_ne$, etc.) and $N$ for the output tensor.
*   **Strengths**: Physically consistent output; handles complex emissivity models via LUTs; efficient radial masking.
*   **Limitations**: Requires pre-computed or predicted scalar fields; not a direct color renderer; sensitive to radial bounds for accurate corona visualization.
*   **When to use**: When the goal is to visualize physical quantities (density, temperature, emission) rather than synthetic color images, particularly in solar physics contexts.
*   **When not to use**: When standard RGB volume rendering is required without physical unit interpretation.

## Background
LOS-integration for visualization is part of the CoroNeRF framework, developed for rendering solar corona data. It leverages neural radiance fields (NeRF) or ground truth fields to predict electron density and temperature, which are then integrated along lines of sight to produce physically meaningful scalar maps. The method addresses the specific challenge of visualizing the solar corona, where the dense chromosphere can cause artifacts if not properly masked.
