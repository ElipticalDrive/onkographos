# NeRV Rendering

Also called: NeRV ray marching, NeRV volume rendering

## Overview
NeRV (Neural Reflectance and Visibility Fields) is a neural volume rendering method that represents a 3D scene using separate neural networks for geometry, reflectance, and visibility to enable high-quality relighting and view synthesis [S1]. It differs from standard neural radiance fields by explicitly modeling surface normals and microfacet BRDF parameters, allowing for physically-based shading with direct and indirect illumination rather than relying solely on view-dependent color [S1].

## How it works

### Inputs and Outputs
**Inputs:**
*   Camera origin $\mathbf{c}$ and direction $\boldsymbol{\omega}_o$ [S1].
*   Pre-trained neural network parameters:
    *   Shape MLP ($\text{MLP}_\theta$): Maps $\mathbf{x}$ to density $\sigma$ and normal $\mathbf{n}$ [S1].
    *   Reflectance MLP ($\text{MLP}_\psi$): Maps $\mathbf{x}$ to BRDF parameters $(a, \gamma)$ [S1].
    *   Visibility MLP ($\text{MLP}_\phi$): Maps $(\mathbf{x}, \boldsymbol{\omega}_i)$ to expected termination depth $\tilde{t}_0$ [S1].
*   Environment lighting map $E(\mathbf{x}, \boldsymbol{\omega})$ [S1].

**Outputs:**
*   Pixel color $V(\mathbf{c}, \boldsymbol{\omega}_o)$ [S1].

### Data Structures
The method relies on three Multi-Layer Perceptrons (MLPs) [S1]. The specific architecture (layer sizes, activation functions) is not detailed in the provided source excerpts, but the input/output signatures are defined as follows [S1]:
1.  **Shape Network**: Input $\mathbf{x} \in \mathbb{R}^3$. Outputs scalar density $\sigma \in \mathbb{R}$ and vector normal $\mathbf{n} \in \mathbb{R}^3$ [S1].
2.  **Reflectance Network**: Input $\mathbf{x} \in \mathbb{R}^3$. Outputs scalar albedo $a \in \mathbb{R}$ and scalar roughness parameter $\gamma \in \mathbb{R}$ [S1].
3.  **Visibility Network**: Input $(\mathbf{x}, \boldsymbol{\omega}_i) \in \mathbb{R}^3 \times \mathbb{R}^3$. Outputs scalar expected depth $\tilde{t}_0 \in \mathbb{R}$ [S1].

### Algorithm Steps

1.  **Ray Sampling and Neural Query**:
    Draw $N=256$ stratified samples along the camera ray $\mathbf{x}(t) = \mathbf{c} - t\boldsymbol{\omega}_o$ [S1]. For each sample point $\mathbf{x}(t)$, query the networks:
    *   Density: $\sigma = \text{MLP}_\theta(\mathbf{x}(t))$ [S1].
    *   Normal: $\mathbf{n} = \nabla_\mathbf{x} \text{MLP}_\theta(\mathbf{x}(t))$ [S1].
    *   BRDF Parameters: $(a, \gamma) = \text{MLP}_\psi(\mathbf{x}(t))$ [S1].

2.  **Direct Illumination Estimation**:
    For each point $\mathbf{x}(t)$ along the ray, estimate the direct illumination integral [S1].
    *   Sample $K=12 \times 24 = 288$ directions $\boldsymbol{\omega}_i$ on the sphere using a fixed grid [S1].
    *   For each $\boldsymbol{\omega}_i$, retrieve environment lighting $E(\mathbf{x}(t), -\boldsymbol{\omega}_i)$ [S1].
    *   Query the visibility network for the predicted visibility $\tilde{V}_\phi = \text{MLP}_\phi(\mathbf{x}(t), \boldsymbol{\omega}_i)$ [S1].
    *   Compute the microfacet BRDF value $R(\mathbf{x}(t), \boldsymbol{\omega}_i, \boldsymbol{\omega}_o)$ using the parameters $(a, \gamma)$ and normal $\mathbf{n}$ [S1].
    *   Integrate the product $E \cdot \tilde{V}_\phi \cdot R$ over the sphere to obtain the direct illumination contribution $L_{dir}$ [S1].

3.  **Indirect Illumination Estimation**:
    Estimate indirect illumination for points along the ray [S1].
    *   Compute the expected camera ray termination depth $t_0 = D(\mathbf{c}, -\boldsymbol{\omega}_o)$ using the density samples from Step 1 [S1].
    *   At the termination point $\mathbf{x}(t_0)$, sample $M=128$ random directions $\boldsymbol{\omega}_i$ on the upper hemisphere [S1].
    *   For each $\boldsymbol{\omega}_i$, query the visibility network to get the expected secondary depth $\tilde{t}''_0 = \text{MLP}_\phi(\mathbf{x}(t_0), \boldsymbol{\omega}_i)$ [S1].
    *   Compute the secondary intersection point $\mathbf{x}_0(\tilde{t}''_0) = \mathbf{x}(t_0) + \tilde{t}''_0 \boldsymbol{\omega}_i$ [S1].
    *   Shade each secondary point $\mathbf{x}_0(\tilde{t}''_0)$ with direct illumination following the procedure in Step 2 [S1].
    *   Multiply the estimated indirect illumination incident at $\mathbf{x}(t_0)$ by the microfacet BRDF values $R(\mathbf{x}(t_0), \boldsymbol{\omega}_i, \boldsymbol{\omega}_o)$ and integrate over the hemisphere to produce the indirect illumination contribution $L_{ind}$ [S1].

4.  **Compositing**:
    Compute the total reflected radiance $L_r(\mathbf{x}(t), \boldsymbol{\omega}_o) = L_{dir} + L_{ind}$ at each sample [S1]. Composite along the ray using the quadrature rule:
    $$
    V(\mathbf{c}, \boldsymbol{\omega}_o) = \sum_t V(\mathbf{x}(t), \mathbf{c}) \alpha(\sigma(\mathbf{x}(t)) \delta) L_r(\mathbf{x}(t), \boldsymbol{\omega}_o)
    $$
    where:
    *   $\delta$ is the distance between samples along the ray [S1].
    *   $\alpha(z) = 1 - \exp(-z)$ [S1].
    *   $V(\mathbf{x}(t), \mathbf{c}) = \exp\left(-\sum_{s < t} \sigma(\mathbf{x}(s)) \delta\right)$ is the transmittance [S1].

import math

def render_nerv_ray(c, w_o, env_light, mlp_theta, mlp_psi, mlp_phi, t_far):
    """
    Renders a single ray using the NeRV method.
    
    Args:
        c: Camera origin (list/tuple of 3 floats)
        w_o: Camera direction (list/tuple of 3 floats)
        env_light: Function E(x, w) returning lighting value
        mlp_theta: Shape MLP returning (sigma, normal)
        mlp_psi: Reflectance MLP returning (albedo, roughness)
        mlp_phi: Visibility MLP returning expected depth
        t_far: Ray exit parameter
        
    Returns:
        Pixel color (float)
    """
    num_samples = 256
    delta = t_far / num_samples
    t_values = [i * delta for i in range(num_samples)]

    # Step 1: Query networks
    densities = []
    normals = []
    brdf_params = []
    for t in t_values:
        x = [c[0] - t * w_o[0], c[1] - t * w_o[1], c[2] - t * w_o[2]]
        sigma, n = mlp_theta(x)
        a, gamma = mlp_psi(x)
        densities.append(sigma)
        normals.append(n)
        brdf_params.append((a, gamma))

    # Step 2 & 3: Compute Radiance at each point
    radiances = []
    for i, t in enumerate(t_values):
        x = [c[0] - t * w_o[0], c[1] - t * w_o[1], c[2] - t * w_o[2]]
        n = normals[i]
        a, gamma = brdf_params[i]

        # Direct Illumination
        dir_grid = generate_sphere_grid(12, 24)
        direct_light = 0.0
        for w_i in dir_grid:
            E = env_light(x, [-w_i[0], -w_i[1], -w_i[2]])
            t_vis = mlp_phi(x, w_i)
            R = microfacet_brdf(n, w_i, w_o, a, gamma)
            direct_light += E * t_vis * R
        L_dir = direct_light * (4.0 * math.pi / len(dir_grid))

        # Indirect Illumination
        t_0 = compute_termination_depth(densities, delta)
        x_term = [c[0] - t_0 * w_o[0], c[1] - t_0 * w_o[1], c[2] - t_0 * w_o[2]]
        hemi_dirs = sample_hemisphere(n, 128)
        indirect_light = 0.0
        for w_i in hemi_dirs:
            t_sec = mlp_phi(x_term, w_i)
            x_sec = [x_term[0] + t_sec * w_i[0], x_term[1] + t_sec * w_i[1], x_term[2] + t_sec * w_i[2]]
            L_sec_dir = compute_direct_radiance(x_sec, w_o, env_light, mlp_theta, mlp_psi, mlp_phi)
            R_ind = microfacet_brdf(n, w_i, w_o, a, gamma)
            indirect_light += L_sec_dir * R_ind
        L_ind = indirect_light * (2.0 * math.pi / len(hemi_dirs))

        L_r = L_dir + L_ind
        radiances.append(L_r)

    # Step 4: Compositing
    color = 0.0
    transmittance = 1.0
    for i, t in enumerate(t_values):
        sigma = densities[i]
        alpha = 1.0 - math.exp(-sigma * delta)
        color += transmittance * alpha * radiances[i]
        transmittance *= (1.0 - alpha)
    return color

def generate_sphere_grid(res_x, res_y):
    dirs = []

        theta = 2 * math.pi * i / res_x

## Operating characteristics

*   **Time Complexity**: High. Each pixel requires 256 forward passes through the shape and reflectance networks [S1]. Additionally, for every sample, direct illumination requires 288 queries to the visibility network and environment lighting lookup, and indirect illumination requires 128 queries to the visibility network plus shading of secondary points [S1]. This makes it significantly slower than standard NeRF which typically does not perform explicit ray tracing for lighting [S1].
*   **Memory Complexity**: Depends on the size of the three MLPs ($\theta, \psi, \phi$) [S1]. No large voxel grids or hash tables are mentioned in the provided excerpts, suggesting a compact representation compared to grid-based methods [S1].
*   **Strengths**: Enables physically-based relighting and view synthesis with explicit surface normals and BRDFs, allowing for realistic indirect illumination [S1].
*   **Limitations**: Computationally expensive due to the nested sampling for lighting and the need for three separate networks [S1].

## Background

NeRV (Neural Reflectance and Visibility Fields) is a neural volume rendering method that extends neural rendering by decoupling geometry, reflectance, and visibility into separate neural fields to facilitate relighting [S1].
