# Illustrative Volume Rendering with Style Transfer

Also called: Style Transfer Function (STF) Volume Rendering

## Overview
Illustrative Volume Rendering with Style Transfer combines standard direct volume ray casting with a Style Transfer Function (STF) to apply artistic, non-photorealistic styles to volumetric data [S1, unofficial]. It allows users to load volumetric datasets, define transfer functions that map density to material indices and styles, and interactively rotate and zoom the rendered result [S1, unofficial]. It distinguishes itself from photorealistic ray casting by decoupling the visual appearance (color/texture) from the physical density, using a 2D array texture to map surface normals and material types to pre-computed artistic styles [S1, unofficial].

## How it works
The method uses a two-pass rendering approach: first, it renders the back face of the volume to determine ray exit points; second, it performs ray casting through the volume, using the exit points to limit ray length and applying style transfer textures to determine the final color [S1, unofficial].

### Inputs and Outputs
*   **Input**: A 3D volume dataset (scalar field), a camera view (projection, view, model matrices), and style transfer textures.
*   **Output**: A 2D image with artistic styling applied to the volumetric data.

### Data Structures and Layouts

**1. RawDataModel State**
The model maintains the following state variables [S1, unofficial]:
*   `isLoaded`: Boolean, initialized to `false`.
*   `sModelName`: String, 1024 characters.
*   `width`, `height`, `numCuts`: Integers representing volume dimensions.
*   `stepSize`: Float, default `0.001f`.
*   `threshold`: Float, default `0.15f`.
*   `texture/buffer IDs`: Integers, initialized to `0`.
*   `transferFunc`: Array of 256 `glm::vec4` entries. Initialized such that `transferFunc[i] = glm::vec4((float)i / 255.f)` [S1, unofficial].

**2. Vertex Buffer Object (VBO) and Index Buffer**
*   **VBO**: Contains 24 floats defining 8 vertices of a unit cube (range 0.0–1.0) [S1, unofficial].
*   **VAO**: Binds attribute 0 (vertex location) and attribute 1 (vertex color) to the VBO data [S1, unofficial].
*   **Index Buffer**: 36 unsigned integers defining 12 triangles (2 per face, counter-clockwise winding) [S1, unofficial].

**3. Textures**
*   **Volume Texture**:
    *   Type: `GL_TEXTURE_3D`.
    *   Dimensions: `width` x `height` x `numCuts`.
    *   Internal Format: `GL_INTENSITY`.
    *   Wrap Modes: `GL_CLAMP` for S, T, R.
    *   Filters: `GL_LINEAR` Min/Mag.
    *   Data: `dataScalars` (normalized floats) [S1, unofficial].
*   **Transfer Function Texture**:
    *   Type: `GL_TEXTURE_1D`.
    *   Size: 256.
    *   Internal Format: `GL_RGBA8`.
    *   Wrap Mode: `GL_REPEAT`.
    *   Filters: `GL_NEAREST` Min/Mag.
    *   Data: `transferFunc` array [S1, unofficial].
*   **Index Function Texture**:
    *   Type: `GL_TEXTURE_1D`.
    *   Maps material index to style index [S1, unofficial]. (Specific dimensions/format not given in sources, assumed consistent with STF requirements).
*   **Style Transfer Texture**:
    *   Type: `GL_TEXTURE_2D_ARRAY`.
    *   Layers: Corresponds to the number of styles.
    *   Dimensions: 2D grid for lit-sphere coordinates [S1, unofficial].
*   **Back Face Texture**:
    *   Type: `GL_TEXTURE_2D`.
    *   Size: Window resolution (`MainData::rootWindow->getSize().x` by `y`).
    *   Internal Format: `GL_RGBA32F`.
    *   Wrap Modes: `GL_REPEAT`.
    *   Filters: `GL_NEAREST` Min/Mag.
    *   Purpose: Stores exit points [S1, unofficial].

**4. Frame Buffer Object (FBO)**
*   Contains a depth renderbuffer (`GL_DEPTH_COMPONENT`) and a color attachment (`backFaceTexture`, `GL_TEXTURE_2D`) [S1, unofficial].
*   Depth test is enabled [S1, unofficial].

### Numbered Steps

1.  **Initialization**:
    *   Set `isLoaded = false`.
    *   Initialize `transferFunc` array with 256 entries where `transferFunc[i] = glm::vec4((float)i / 255.f)` [S1, unofficial].
    *   Call `setupVolumeShaders()`, `createTransferFunctionTexture()`, and `stf.loadStyles()` [S1, unofficial].

2.  **Volume Loading**:
    *   Call `createVertexBuffer()` to set up VBO/VAO for the unit cube [S1, unofficial].
    *   Load volume data via `loadVolumeFromFile8()` or `loadVolumeFromFile16()` into `dataScalars` (normalized floats) [S1, unofficial].
    *   Create `backFaceTexture` for exit point storage [S1, unofficial].
    *   Create Frame Buffer Object (FBO) [S1, unofficial].

3.  **Matrix and Geometry Setup**:
    *   Set volume dimensions (`width`, `height`, `numCuts`) [S1, unofficial].
    *   Compute `cubeSizes = glm::vec3(width/max, height/max, numCuts/max)` [S1, unofficial].
    *   Scale model and position at `(-cubeSizes.x/2, -cubeSizes.y/2, 0)` [S1, unofficial].
    *   Compute matrices:
        *   Projection: 45-degree FOV, aspect ratio, near 0.1, far 500 [S1, unofficial].
        *   View: `lookAt(0,0,-1, 0,0,0, 0,1,0)` [S1, unofficial].
        *   Model, Normal, ViewProjection, ModelViewProjection [S1, unofficial].

4.  **Rendering Loop**:
    *   If `isLoaded` is true, call `renderBackFace()` then `renderVolumeRayCasting()` [S1, unofficial].

5.  **Back Face Rendering (`renderBackFace`)**:
    *   Bind the FBO [S1, unofficial].
    *   Render the back faces of the volume cube to populate the `backFaceTexture` with exit points [S1, unofficial].

6.  **Ray Casting Rendering (`renderVolumeRayCasting`)**:
    *   Bind default framebuffer (`GL_FRAMEBUFFER = 0`) [S1, unofficial].
    *   Set viewport to window size [S1, unofficial].
    *   Use `rayCastShader` [S1, unofficial].
    *   Set uniforms:
        *   `MVP`: ModelViewProjection matrix [S1, unofficial].
        *   `ViewMatrix`: View matrix [S1, unofficial].
        *   `NormalMatrix`: Normal matrix [S1, unofficial].
        *   `StepSize`: `stepSize` (default 0.001f) [S1, unofficial].
        *   `Threshold`: `threshold` (default 0.15f) [S1, unofficial].
        *   `ScreenSize`: Window width and height as floats [S1, unofficial].
    *   Bind textures to units:
        *   Unit 1: `transferFunctionTexture` (1D) [S1, unofficial].
        *   Unit 2: `indexFunctionTexture` (1D) [S1, unofficial].
        *   Unit 3: `styleTransferTexture` (2D Array) [S1, unofficial].
    *   Execute ray casting shader, which likely uses the exit points from the back face texture to determine ray length and applies style transfer based on normals and material indices [S1, unofficial].

### Pseudocode

```python
class RawDataModel:
    def __init__(self):
        self.is_loaded = False
        self.s_model_name = "" # 1024 chars
        self.width = 1
        self.height = 1
        self.num_cuts = 1
        self.step_size = 0.001
        self.threshold = 0.15
        self.texture_ids = [0, 0, 0, 0, 0] # Placeholder for IDs
        self.transfer_func = [glm.vec4(i / 255.0) for i in range(256)]
        self.setup_volume_shaders()
        self.create_transfer_function_texture()
        self.stf.load_styles()

    def load_volume(self, file_path):
        self.create_vertex_buffer()
        # Load raw data into dataScalars (normalized floats)
        self.data_scalars = load_volume_from_file(file_path)
        self.create_back_face_texture()
        self.create_frame_buffer()
        
        # Compute cube sizes and matrices
        max_dim = max(self.width, self.height, self.num_cuts)
        self.cube_sizes = glm.vec3(self.width / max_dim, self.height / max_dim, self.num_cuts / max_dim)
        
        # Position model
        self.model_position = glm.vec3(-self.cube_sizes.x / 2, -self.cube_sizes.y / 2, 0)
        
        # Compute matrices
        self.projection = compute_projection(fov=45.0, aspect=window_width/window_height, near=0.1, far=500.0)
        self.view = compute_look_at(eye=glm.vec3(0, 0, -1), target=glm.vec3(0, 0, 0), up=glm.vec3(0, 1, 0))
        self.model = compute_model_matrix(scale=self.cube_sizes, translation=self.model_position)
        self.normal_matrix = compute_normal_matrix(self.model)
        self.view_projection = self.projection * self.view
        self.model_view_projection = self.view_projection * self.model

    def render(self):
        if self.is_loaded:
            self.render_back_face()
            self.render_volume_ray_casting()

    def render_back_face(self):
        # Bind FBO with backFaceTexture as color attachment
        bind_framebuffer(self.fbo)
        # Render back faces of the volume cube
        draw_cube_back_faces()
        # Unbind FBO
        bind_framebuffer(0)

    def render_volume_ray_casting(self):
        # Bind default framebuffer
        bind_framebuffer(0)
        set_viewport(0, 0, window_width, window_height)
        
        use_shader(self.ray_cast_shader)
        
        # Set uniforms
        self.ray_cast_shader.set_uniform("MVP", self.model_view_projection)
        self.ray_cast_shader.set_uniform("ViewMatrix", self.view)
        self.ray_cast_shader.set_uniform("NormalMatrix", self.normal_matrix)
        self.ray_cast_shader.set_uniform("StepSize", self.step_size)
        self.ray_cast_shader.set_uniform("Threshold", self.threshold)
        self.ray_cast_shader.set_uniform("ScreenSize", float(window_width), float(window_height))
        
        # Bind textures
        active_texture(1)
        bind_texture(GL_TEXTURE_1D, self.stf.transfer_function_texture)
        self.ray_cast_shader.set_uniform("transferFunctionTexture", 1)
        
        active_texture(2)
        bind_texture(GL_TEXTURE_1D, self.stf.index_function_texture)
        self.ray_cast_shader.set_uniform("indexFunctionTexture", 2)
        
        active_texture(3)
        bind_texture(GL_TEXTURE_2D_ARRAY, self.stf.style_function_texture)
        self.ray_cast_shader.set_uniform("styleTransferTexture", 3)
        
        # Draw volume (ray casting)
        draw_volume()
```

### Parameters
*   `stepSize`: Ray casting step size. Default: `0.001f` [S1, unofficial].
*   `threshold`: Ray casting threshold. Default: `0.15f` [S1, unofficial].

### Edge Cases and Pitfalls
*   **Precision**: The back face texture uses `GL_RGBA32F`, ensuring high precision for exit point storage [S1, unofficial].
*   **Boundaries**: Volume texture wrap mode is `GL_CLAMP`, preventing sampling errors at volume boundaries [S1, unofficial].
*   **Degenerate Input**: If `isLoaded` is false, rendering is skipped [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: Not given in the sources.
*   **Memory Complexity**: Not given in the sources.
*   **Measured Performance**: Not given in the sources.
*   **Strengths**: Allows interactive rotation and zoom with artistic styles; supports saving/loading transfer functions with assigned styles [S1, unofficial].
*   **Limitations**: Relies on pre-computed style textures; requires a two-pass rendering approach [S1, unofficial].
*   **When to use**: When non-photorealistic, artistic visualization of volumetric data is desired.
*   **When not to use**: When photorealistic, physically-based rendering is required.

## Background
The method is based on the academic paper "Style Transfer Function" by Bruckner et al. (2007) [S1, unofficial]. It was implemented as a homework project for a college course, providing a practical implementation of the STF concept [S1, unofficial].
