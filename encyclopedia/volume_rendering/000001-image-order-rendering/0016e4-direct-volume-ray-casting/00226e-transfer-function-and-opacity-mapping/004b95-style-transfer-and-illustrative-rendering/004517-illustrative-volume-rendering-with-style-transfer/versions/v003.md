# Illustrative Volume Rendering with Style Transfer

Also called: Style Transfer Function (STF) Volume Rendering

## Overview
Illustrative Volume Rendering with Style Transfer combines standard direct volume ray casting with a Style Transfer Function (STF) to apply artistic styles to volumetric data [S1, unofficial]. It allows users to load volumetric datasets, define transfer functions with assigned artistic styles, and interactively rotate or zoom the resulting volume [S1, unofficial]. This method distinguishes itself from sibling techniques like [Raycasting with Style Transfer and Contour Lines](11409-raycasting-with-style-transfer-and-contour-lines.md) by focusing on the integration of style transfer textures directly into the ray casting shader pipeline, rather than post-processing or contour-based stylization.

## How it works
The method implements a two-pass rendering approach: first rendering the back face of the volume to capture exit points, and then performing ray casting that utilizes these exit points for ray length calculation, combined with style transfer textures [S1, unofficial].

### Inputs and Outputs
**Inputs:**
*   Volumetric scalar data (8-bit or 16-bit raw data).
*   Camera parameters (projection, view, model matrices).
*   Style Transfer Function (STF) data, including transfer function textures and style function textures.
*   Rendering parameters: `stepSize` (default 0.001f), `threshold` (default 0.15f) [S1, unofficial].

**Outputs:**
*   A 2D image with artistic style applied to the volumetric data.

### Data Structures and Layouts

**RawDataModel State:**
*   `isLoaded`: Boolean, initialized to `false`.
*   `sModelName`: String, 1024 characters.
*   `width`, `height`, `numCuts`: Integers, initialized to 1.
*   `stepSize`: Float, default 0.001f.
*   `threshold`: Float, default 0.15f.
*   `texture/buffer IDs`: Integers, initialized to 0.
*   `transferFunc`: Array of 256 `glm::vec4` entries. Initialized such that `transferFunc[i] = glm::vec4((float)i / 255.f)` [S1, unofficial].

**Vertex Buffer Object (VBO) for Volume Cube:**
*   **Vertices:** 24 floats defining 8 vertices of a unit cube (range 0.0-1.0) [S1, unofficial].
*   **Indices:** 36 unsigned integers defining 12 triangles (2 per face, counter-clockwise winding) [S1, unofficial].
*   **VAO Bindings:**
    *   Attribute 0: Vertex location (bound to VBO).
    *   Attribute 1: Vertex color (bound to same VBO) [S1, unofficial].
*   **Index Buffer:** Bound to `GL_ELEMENT_ARRAY_BUFFER` [S1, unofficial].

**Back Face Texture:**
*   **Type:** 2D texture (`GL_TEXTURE_2D`).
*   **Dimensions:** `MainData::rootWindow->getSize().x` by `y` (window resolution) [S1, unofficial].
*   **Internal Format:** `GL_RGBA32F` [S1, unofficial].
*   **Wrap Modes:** `GL_REPEAT` [S1, unofficial].
*   **Filters:** Min/Mag filter `GL_NEAREST` [S1, unofficial].
*   **Purpose:** Stores exit points for ray casting [S1, unofficial].

**Transfer Function Texture:**
*   **Type:** 1D texture (`GL_TEXTURE_1D`).
*   **Dimensions:** 256 [S1, unofficial].
*   **Internal Format:** `GL_RGBA8` [S1, unofficial].
*   **Wrap Mode:** `GL_REPEAT` [S1, unofficial].
*   **Filters:** Min/Mag filter `GL_NEAREST` [S1, unofficial].
*   **Pixel Unpack Alignment:** 1 [S1, unofficial].
*   **Data Source:** `transferFunc` array (`glm::vec4`) [S1, unofficial].

**Style Function Texture:**
*   **Type:** 2D Array texture (`GL_TEXTURE_2D_ARRAY`) [S1, unofficial].
*   **Data Source:** `stf.styleFunctionTexture` [S1, unofficial].

**Index Function Texture:**
*   **Type:** 1D texture (`GL_TEXTURE_1D`) [S1, unofficial].
*   **Data Source:** `stf.indexFunctionTexture` [S1, unofficial].

**Volume Texture:**
*   **Type:** 3D texture (`GL_TEXTURE_3D`).
*   **Dimensions:** `width`, `height`, `numCuts` [S1, unofficial].
*   **Internal Format:** `GL_INTENSITY` [S1, unofficial].
*   **Wrap Modes:** `GL_CLAMP` for S, T, R [S1, unofficial].
*   **Filters:** Min/Mag filter `GL_LINEAR` [S1, unofficial].
*   **Data Source:** `dataScalars` (normalized float array) [S1, unofficial].

**Frame Buffer Object (FBO):**
*   **Attachments:**
    *   Depth renderbuffer (`GL_DEPTH_COMPONENT`) [S1, unofficial].
    *   Color attachment: `backFaceTexture` (`GL_TEXTURE_2D`) [S1, unofficial].
*   **State:** Depth test enabled [S1, unofficial].

### Initialization Steps
1.  Initialize `RawDataModel`: Set `isLoaded=false`, allocate `sModelName` (1024 chars), set `width=1`, `height=1`, `numCuts=1`, `stepSize=0.001f`, `threshold=0.15f`, and texture/buffer IDs to 0 [S1, unofficial].
2.  Initialize `transferFunc` array: For `i` from 0 to 255, set `transferFunc[i] = glm::vec4((float)i / 255.f)` [S1, unofficial].
3.  Call `setupVolumeShaders()` [S1, unofficial].
4.  Call `createTransferFunctionTexture()` [S1, unofficial].
5.  Call `stf.loadStyles()` [S1, unofficial].

### Volume Loading Steps
1.  Call `createVertexBuffer()` to set up VBO/VAO for cube rendering [S1, unofficial].
2.  Call `loadVolumeFromFile8()` or `loadVolumeFromFile16()` to read raw data into `dataScalars` (normalized floats) [S1, unofficial].
3.  Call `createBackFaceTexture()` to create the 2D texture for exit point storage [S1, unofficial].
4.  Call `createFrameBuffer()` to set up the FBO with depth renderbuffer and color attachment [S1, unofficial].
5.  Set volume dimensions (`width`, `height`, `numCuts`) [S1, unofficial].
6.  Compute `cubeSizes = glm::vec3(width/max, height/max, numCuts/max)` [S1, unofficial].
7.  Scale model and position at `(-cubeSizes.x/2, -cubeSizes.y/2, 0)` [S1, unofficial].
8.  Compute matrices:
    *   Projection: 45 deg FOV, aspect ratio, near 0.1, far 500 [S1, unofficial].
    *   View: `lookAt(0,0,-1, 0,0,0, 0,1,0)` [S1, unofficial].
    *   Model, Normal, ViewProjection, ModelViewProjection [S1, unofficial].

### Rendering Steps
1.  If `isLoaded` is true:
    a.  Call `renderBackFace()` [S1, unofficial].
    b.  Call `renderVolumeRayCasting()` [S1, unofficial].

**`renderBackFace()` Implementation:**
*   Bind the FBO [S1, unofficial].
*   Render the back face of the volume cube to populate the `backFaceTexture` with exit points [S1, unofficial].
*   Unbind the FBO [S1, unofficial].

**`renderVolumeRayCasting()` Implementation:**
1.  Bind default framebuffer (`GL_FRAMEBUFFER = 0`) [S1, unofficial].
2.  Set viewport to window size [S1, unofficial].
3.  Use `rayCastShader` [S1, unofficial].
4.  Set uniforms:
    *   `MVP`: `modelViewProjection` [S1, unofficial].
    *   `ViewMatrix`: `view` [S1, unofficial].
    *   `NormalMatrix`: `normalMatrix` [S1, unofficial].
    *   `StepSize`: `stepSize` [S1, unofficial].
    *   `Threshold`: `threshold` [S1, unofficial].
    *   `ScreenSize`: `(float)width, (float)height` [S1, unofficial].
5.  Bind textures to active units:
    *   `GL_TEXTURE1`: `transferFunctionTexture` (`GL_TEXTURE_1D`) [S1, unofficial].
    *   `GL_TEXTURE2`: `indexFunctionTexture` (`GL_TEXTURE_1D`) [S1, unofficial].
    *   `GL_TEXTURE3`: `styleTransferTexture` (`GL_TEXTURE_2D_ARRAY`) [S1, unofficial].
6.  Set corresponding shader uniforms for textures [S1, unofficial].
7.  Render the volume using ray casting, likely using the exit points from `backFaceTexture` to determine ray length [S1, unofficial].

class RawDataModel:
    def __init__(self):
        self.isLoaded = False
        self.sModelName = "" # 1024 chars
        self.width = 1
        self.height = 1
        self.numCuts = 1
        self.stepSize = 0.001f
        self.threshold = 0.15f
        self.textureIds = [0] * 10 # Placeholder for texture/buffer IDs
        self.transferFunc = [glm::vec4((float)i / 255.f) for i in range(256)]
        self.setupVolumeShaders()
        self.createTransferFunctionTexture()
        self.stf.loadStyles()

    def loadVolume(self, filename):
        self.createVertexBuffer()
        if filename.endswith('.8'):
            self.dataScalars = loadVolumeFromFile8(filename)
        else:
            self.dataScalars = loadVolumeFromFile16(filename)
        self.createBackFaceTexture()
        self.createFrameBuffer()
        
        # Compute dimensions and matrices
        max_dim = max(self.width, self.height, self.numCuts)
        self.cubeSizes = glm::vec3(self.width/max_dim, self.height/max_dim, self.numCuts/max_dim)
        
        # Position and scale
        self.modelMatrix = glm::translate(glm::mat4(1.0), glm::vec3(-self.cubeSizes.x/2, -self.cubeSizes.y/2, 0))
        # Scale is applied via model matrix or vertex shader, details not fully specified in source [G]
        
        # Camera matrices
        aspect = self.width / self.height
        self.projectionMatrix = glm::perspective(glm::radians(45.0f), aspect, 0.1f, 500.0f)
        self.viewMatrix = glm::lookAt(glm::vec3(0, 0, -1), glm::vec3(0, 0, 0), glm::vec3(0, 1, 0))
        self.normalMatrix = glm::mat3(glm::transpose(glm::inverse(self.modelMatrix)))
        self.viewProjectionMatrix = self.projectionMatrix * self.viewMatrix
        self.modelViewProjectionMatrix = self.viewProjectionMatrix * self.modelMatrix
        
        self.isLoaded = True

    def render(self):
        if self.isLoaded:
            self.renderBackFace()
            self.renderVolumeRayCasting()

    def renderBackFace(self):
        # Bind FBO
        glBindFramebuffer(GL_FRAMEBUFFER, self.fboId)
        glViewport(0, 0, windowWidth, windowHeight)
        # Render back face to backFaceTexture

        glBindFramebuffer(GL_FRAMEBUFFER, 0)

    def renderVolumeRayCasting(self):
        glBindFramebuffer(GL_FRAMEBUFFER, 0)
        glViewport(0, 0, windowWidth, windowHeight)
        
        self.rayCastShader.use()
        self.rayCastShader.setUniform("MVP", self.modelViewProjectionMatrix)
        self.rayCastShader.setUniform("ViewMatrix", self.viewMatrix)

        glBindTexture(GL_TEXTURE_1D, self.stf.indexFunctionTexture)
        self.rayCastShader.setUniform("indexFunctionTexture", 2)
        
        # Bind Style Transfer Texture

### Edge Cases and Pitfalls
*   **Precision:** The back face texture uses `GL_RGBA32F` for exit points, ensuring high precision for ray length calculation [S1, unofficial].
*   **Boundaries:** Volume texture uses `GL_CLAMP` wrap modes to prevent sampling artifacts at volume boundaries [S1, unofficial].
*   **Degenerate Input:** If volume dimensions are 0 or negative, `cubeSizes` computation may fail. The source initializes dimensions to 1, so this is a potential pitfall if loading fails [S1, unofficial].
*   **Threshold:** The `threshold` parameter (default 0.15f) is used in ray casting. Its exact role (e.g., opacity cutoff) is not detailed in the source [S1, unofficial].

The technique extends standard volume rendering by integrating style transfer functions, allowing for illustrative visualization of volumetric data [S1, unofficial].
