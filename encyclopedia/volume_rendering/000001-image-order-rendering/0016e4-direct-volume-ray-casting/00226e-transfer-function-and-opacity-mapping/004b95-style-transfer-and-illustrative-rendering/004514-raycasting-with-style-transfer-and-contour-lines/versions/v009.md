# Raycasting with Style Transfer and Contour Lines

Also called: FGC_T3 Raycasting, Style-based Volume Raycasting

## Overview
This method performs direct volume ray casting that integrates artistic style transfer and contour line rendering into the standard front-to-back compositing loop [S1, unofficial]. It differs from standard ray casting by mapping surface normals to a 2D array texture of pre-computed artistic styles (such as lit spheres or matcaps) and optionally overlaying contour lines based on curvature and view angle [S1, unofficial]. It builds on [Style Transfer and Illustrative Rendering](13031-style-transfer-and-illustrative-rendering.md) by providing a specific implementation of style-based shading and contour generation within the ray casting framework.

## How it works

### Inputs and Outputs
**Inputs:**
*   **Volume Data**: A 3D texture (`VolumeTex`) containing scalar density values.
*   **Exit Points**: A 2D texture (`ExitPoints`) storing the 3D exit coordinates for each screen pixel, computed in a prior pass.
*   **Entry Point**: A uniform `vec3` (`EntryPoint`) representing the camera position or front entry point for the ray.
*   **Transfer Function**: A 1D texture (`transferFunctionTexture`) mapping density to opacity (green channel) and material index (red channel).
*   **Index Function**: A 1D texture (`indexFunctionTexture`) mapping material index to style index.
*   **Style Texture**: A 2D array texture (`styleTransferTexture`) containing multiple 2D style images (e.g., lit sphere maps), indexed by the style index.
*   **Uniforms**: `NormalMatrix` (4x4), `StepSize` (float), `Threshold` (float), `ScreenSize` (vec2), `lightPos` (vec3).

**Outputs:**
*   **Fragment Color**: A `vec4` (`FragColor`) representing the final composited color with alpha.

### Data Structures
*   **`EntryPoint`**: `vec3`, camera origin.
*   **`ExitPoints`**: `sampler2D`, stores `vec3` exit positions.
*   **`VolumeTex`**: `sampler3D`, stores scalar density.
*   **`transferFunctionTexture`**: `sampler1D`, layout: Red = Material Index, Green = Opacity.
*   **`indexFunctionTexture`**: `sampler1D`, layout: Red = Style Index (normalized 0-1).
*   **`styleTransferTexture`**: `sampler2DArray`, layout: 2D images stacked in the depth dimension, where depth corresponds to style index.

### Parameters
*   **`StepSize`**: Distance between samples along the ray. Default: `0.01f` [S1, unofficial].
*   **`Threshold`**: Minimum density value to process. Default: `0.15f` [S1, unofficial].
*   **`AVAILABLE_STYLE_COUNT`**: Number of styles in the array texture. Value: `34` [S1, unofficial].
*   **`USE_NOISE_JITTER`**: Boolean flag to enable noise jittering for anti-aliasing [S1, unofficial].
*   **`USE_THRESHOLD`**: Boolean flag to enable density thresholding [S1, unofficial].
*   **`USE_CONTOUR`**: Boolean flag to enable contour line rendering [S1, unofficial].

### Algorithm Steps

1.  **Ray Initialization**:
    *   Retrieve the 3D exit point from the `ExitPoints` texture using the fragment's screen coordinates normalized by `ScreenSize`.
    *   If the entry point equals the exit point, discard the fragment (background).
    *   Calculate the ray direction vector (`rayDirection`) as the difference between the exit point and the entry point.
    *   Calculate the total ray length as the magnitude of `rayDirection`.
    *   Calculate the step vector: `stepVector = StepSize * rayDirection / rayLength`.
    *   Initialize the ray start position (`rayStart`) to the entry point. If `USE_NOISE_JITTER` is defined, add a noise jitter offset to `rayStart` based on fragment coordinates.

2.  **Accumulator Initialization**:
    *   Initialize current position `pos` to `rayStart`.
    *   Initialize destination color `dst` to `(0, 0, 0, 0)`.
    *   Initialize previous normal `previousNormal` to `(1, 0, 0)` (or similar identity).
    *   Initialize current normal `normal` to `(1, 0, 0)`.
    *   Initialize base color `baseColor` to `(0, 0, 0, 0)`.

3.  **Ray Casting Loop**:
    *   While accumulated opacity `dst.a` is less than `1.0` AND remaining ray length `rayLength` is greater than `0`:
        a.  **Sample Density**: Sample the volume density at `pos` from `VolumeTex`.
        b.  **Threshold Check**: If `USE_THRESHOLD` is defined and density is not greater than `Threshold`, skip to step 3f.
        c.  **Transfer Function Lookup**: Sample `transferFunctionTexture` at the density value. Extract opacity from the green channel and material index from the red channel.
        d.  **Style Index Lookup**: Sample `indexFunctionTexture` at the material index. Multiply the result by `AVAILABLE_STYLE_COUNT` and cast to integer to get `styleIndex`.
        e.  **Normal Estimation**:
            i.  Compute the gradient at `pos` using central differences with step size `StepSize`. Let $L$ be `StepSize`.
                $$ \nabla V = \left( V(pos + (L, 0, 0)) - V(pos), V(pos + (0, L, 0)) - V(pos), V(pos + (0, 0, L)) - V(pos) \right) $$
            ii. Transform the gradient using the `NormalMatrix` to get the current `normal`.
            iii. Store the current `normal` as `previousNormal` for the next iteration's curvature calculation.
        f.  **Style Transfer**:
            i.  Map the `normal` vector to 2D coordinates using the lit sphere mapping:
                $$ \text{litsphere}(\mathbf{n}) = \left( \frac{n_x + 1}{2}, \frac{-n_y + 1}{2} \right) $$
                *(Note: Source code uses `vec2(normal.x, -normal.y) * 0.5f + 0.5f`)*
            ii. Sample `styleTransferTexture` using the lit sphere coordinates and `styleIndex` to get `baseColor`.
        g.  **Contour Lines (Optional)**:
            i.  If `USE_CONTOUR` is defined:
                1.  Calculate curvature approximation:
                    $$ \kappa = \arccos\left( \frac{\mathbf{n} \cdot \mathbf{n}_{prev}}{\|\mathbf{n}\| \|\mathbf{n}_{prev}\|} \right) \times \text{StepSize} $$
                2.  Calculate contour condition threshold:
                    $$ T_{kv} = \text{thickness} \times \kappa $$
                    $$ \text{cond} = \sqrt{T_{kv} (2 - T_{kv})} $$
                    *(Where `thickness` is `1.0`)*
                3.  Calculate view dot product:
                    $$ nDotV = |\mathbf{n} \cdot \frac{-\mathbf{pos}}{\|\mathbf{pos}\|}| $$
                4.  If $nDotV \le \text{cond}$, apply matcap style:
                    1.  Calculate lighting delta:
                        $$ \text{litDelta} = 1 - \min(1, \frac{\text{cond} - nDotV}{\text{cond}}) $$
                    2.  Adjust length:
                        $$ \text{adjustedLength} = \min(1, \frac{\|\mathbf{n}\|}{\text{litDelta}}) $$
                    3.  Sample `styleTransferTexture` using matcap coordinates (derived from `pos` and `normal`) and `styleIndex` to update `baseColor`.
        h.  **Compositing**:
            i.  Set source color `src` to `baseColor` with opacity from the transfer function.
            ii. Pre-multiply alpha: `src.rgb *= src.a`.
            iii. Composite into destination:
                $$ \text{dst} = (1 - \text{dst}.a) \times \text{src} + \text{dst} $$
        i.  **Advance Ray**:
            i.  Update position: `pos += stepVector`.
            ii. Decrease remaining length: `rayLength -= StepSize`.

4.  **Output**: Write `dst` to `FragColor`.

### Pseudocode

```python
def raycast_with_style_transfer_and_contour_lines(
    entry_point: vec3,
    exit_points_texture: Texture2D,
    volume_texture: Texture3D,
    transfer_function_texture: Texture1D,
    index_function_texture: Texture1D,
    style_transfer_texture: Texture2DArray,
    normal_matrix: mat4,
    screen_size: vec2,
    step_size: float = 0.01,
    threshold: float = 0.15,
    available_style_count: int = 34,
    use_noise_jitter: bool = False,
    use_threshold: bool = True,
    use_contour: bool = False
) -> vec4:
    """
    Performs ray casting with style transfer and optional contour lines.
    Assumes fragment shader context where gl_FragCoord is available.
    """
    
    # 1. Ray Initialization
    exit_point = exit_points_texture.sample(gl_FragCoord.st / screen_size)
    
    if entry_point == exit_point:
        return vec4(0.0)  # Discard background
    
    ray_direction = exit_point - entry_point
    ray_length = length(ray_direction)
    
    if ray_length == 0:
        return vec4(0.0)
        
    step_vector = step_size * ray_direction / ray_length
    
    ray_start = entry_point
    if use_noise_jitter:
        # Assuming a simple noise function snoise exists
        noise_offset = step_vector * snoise(gl_FragCoord.xy / 2.5)
        ray_start += noise_offset
        
    pos = ray_start
    dst = vec4(0.0)
    normal = vec3(1.0)
    previous_normal = vec3(1.0)
    
    # 2. Ray Casting Loop
    while dst.a < 1.0 and ray_length > 0.0:
        # Sample density
        density = volume_texture.sample(pos).x
        
        # Threshold check
        if use_threshold and density <= threshold:
            pos += step_vector
            ray_length -= step_size
            continue
            
        # Transfer function lookup
        tf_sample = transfer_function_texture.sample(density)
        opacity = tf_sample.g
        material_index = tf_sample.r
        
        # Style index lookup
        style_index_float = index_function_texture.sample(material_index).x
        style_index = int(style_index_float * available_style_count)
        
        # Normal estimation
        # Gradient calculation with step size L = step_size
        L = step_size
        look_up = density
        grad_x = volume_texture.sample(pos + vec3(L, 0, 0)).x - look_up
        grad_y = volume_texture.sample(pos + vec3(0, L, 0)).x - look_up
        grad_z = volume_texture.sample(pos + vec3(0, 0, L)).x - look_up
        gradient = vec3(grad_x, grad_y, grad_z)
        
        previous_normal = normal
        normal = (normal_matrix * vec4(gradient, 0.0)).xyz
        
        # Style transfer
        # Lit sphere mapping: vec2(normal.x, -normal.y) * 0.5 + 0.5
        lit_sphere_coords = vec2(normal.x, -normal.y) * 0.5 + 0.5
        base_color = style_transfer_texture.sample(lit_sphere_coords, style_index)
        
        # Contour lines (optional)
        if use_contour:
            magnitudes = length(normal) * length(previous_normal)
            if magnitudes > 0.0:
                curvature = acos(dot(normal, previous_normal) / magnitudes) * step_size
            else:
                curvature = 0.0
                
            thickness = 1.0
            t_kv = thickness * curvature
            cond = sqrt(t_kv * (2.0 - t_kv))
            
            view_dir = normalize(-pos)
            n_dot_v = abs(dot(normal, view_dir))
            
            if n_dot_v <= cond:
                lit_delta = 1.0 - min(1.0, (cond - n_dot_v) / cond)
                adjusted_length = min(1.0, length(normal) / lit_delta)
                
                # Matcap sampling (simplified as per source logic)
                # Source uses matcap(pos.xyz, normal).xy
                # Assuming matcap generates 2D coords from pos and normal
                matcap_coords = vec2(0.0) # Placeholder for matcap logic if not explicitly defined beyond name
                # Note: Source code implies matcap(pos.xyz, normal) returns vec2
                # Since exact matcap formula isn't provided, we assume it maps to style texture
                # For implementation, one would need the specific matcap coordinate generation function
                # Here we assume it returns valid 2D coords for the style texture
                matcap_coords = vec2(0.5) # [G] Placeholder: In actual implementation, this must be computed from pos/normal
                base_color = style_transfer_texture.sample(matcap_coords, style_index)
                
        # Compositing
        src = vec4(base_color.rgb, opacity)
        src.rgb *= src.a
        dst = (1.0 - dst.a) * src + dst
        
        pos += step_vector
        ray_length -= step_size
        
    return dst
```

### Edge Cases and Pitfalls
*   **Zero Ray Length**: If the entry point equals the exit point, the ray length is zero. The algorithm discards the fragment to avoid division by zero in step vector calculation [S1, unofficial].
*   **Zero Gradient Magnitude**: If the gradient is zero (flat region), the normal remains unchanged or undefined. The source initializes normal to `(1,0,0)` [S1, unofficial].
*   **Curvature Calculation**: The curvature formula uses `acos`, which is sensitive to numerical precision when normals are nearly parallel. The source divides by the product of magnitudes, which can be zero if normals are zero vectors [S1, unofficial].
*   **Contour Condition**: The condition `nDotV <= cond` determines when to switch to matcap style. If `cond` is zero (no curvature), contours are not drawn [S1, unofficial].
*   **Style Index Bounds**: The style index is calculated by multiplying the normalized index by `AVAILABLE_STYLE_COUNT`. If the index function texture returns values outside [0, 1], the index may be out of bounds for the style texture array [S1, unofficial].

## Operating characteristics

### Time and Memory Complexity
*   **Time Complexity**: $O(N \cdot S)$, where $N$ is the number of samples per ray (determined by ray length and `StepSize`) and $S$ is the cost of texture sampling and style lookup. The contour calculation adds a constant overhead per sample.
*   **Memory Complexity**: $O(V + T)$, where $V$ is the volume texture size, $T$ is the size of the style transfer texture array, and auxiliary textures (ExitPoints, Transfer Function).

### Measured Performance
*   Not given in the sources.

### Scaling
*   Performance scales linearly with image resolution (number of fragments) and volume density (number of samples per ray).
*   The use of a 2D array texture for styles allows efficient switching between styles without complex shader branching for style selection, but increases texture memory usage.

### Strengths and Limitations
*   **Strengths**: Integrates artistic styles directly into the ray casting loop, allowing for real-time stylized volume rendering. Contour lines provide additional structural information.
*   **Limitations**: Relies on pre-computed style textures, limiting the variety of styles to those available. Contour lines are approximated and may exhibit artifacts if the curvature calculation is unstable.

### When to Use
*   Use when stylized, illustrative volume rendering is required, particularly for scientific visualization where artistic styles aid interpretation.
*   Not suitable for photorealistic rendering or when dynamic style generation is needed.
