# Raycasting with Style Transfer and Contour Lines

Also called: FGC_T3 Raycasting, Style-based Volume Raycasting

## Overview
This method extends direct volume ray casting by replacing standard photorealistic shading with artistic style transfer and illustrative contour lines [S1, unofficial]. It solves the problem of visual ambiguity in scientific visualization by mapping surface normals and material indices to a 2D array texture of artistic styles, while using curvature and view-angle thresholds to render contour lines that emphasize geometric features [S1, unofficial]. It differs from standard ray casting by decoupling the optical appearance from the physical light transport, instead relying on pre-computed style maps [S1, unofficial].

## How it works
The method operates in a fragment shader, processing each pixel by casting a ray through the volume and applying style-based compositing.

### Inputs and Outputs
**Inputs:**
*   `EntryPoint`: `vec3`, the entry point of the ray into the volume for the current fragment.
*   `ExitPoints`: `sampler2D`, a texture storing exit points. Sampled using `gl_FragCoord.st / ScreenSize`.
*   `VolumeTex`: `sampler3D`, the 3D volume data (scalar density).
*   `transferFunctionTexture`: `sampler1D`, maps density to opacity (green channel) and material index (red channel).
*   `indexFunctionTexture`: `sampler1D`, maps material index to a style index.
*   `styleTransferTexture`: `sampler2DArray`, contains $N$ 2D style images, where $N$ is `AVAILABLE_STYLE_COUNT`.
*   `NormalMatrix`: `mat4`, transforms gradients to world/view space for shading.
*   `ScreenSize`: `vec2`, resolution of the output image.
*   `StepSize`: `float`, distance between samples. Default: 0.01 [S1, unofficial].
*   `Threshold`: `float`, minimum density to process. Default: 0.15 [S1, unofficial].
*   `AVAILABLE_STYLE_COUNT`: `int`, number of styles in the array texture. Value: 34 [S1, unofficial].

**Outputs:**
*   `FragColor`: `vec4`, the final composited color with alpha.

### Data Structures
*   **Volume Data**: 3D texture of scalar values.
*   **Transfer Function**: 1D texture. Channel `r` = material index, Channel `g` = opacity.
*   **Index Function**: 1D texture. Channel `r` = normalized style index (0.0 to 1.0).
*   **Style Texture**: 2D Array texture. Dimensions $W \times H \times N$. Each slice $k$ corresponds to a style.

### Algorithm Steps

1.  **Ray Initialization**:
    *   Retrieve the exit point from the `ExitPoints` texture using normalized fragment coordinates: $\mathbf{p}_{exit} = \text{texture}(\text{ExitPoints}, \frac{\mathbf{c}_{frag}}{\mathbf{s}_{size}})$.
    *   If $\mathbf{p}_{entry} == \mathbf{p}_{exit}$, discard the fragment (background) [S1, unofficial].
    *   Compute ray direction $\mathbf{d} = \mathbf{p}_{exit} - \mathbf{p}_{entry}$ and length $L = \|\mathbf{d}\|$ [S1, unofficial].
    *   Compute step vector $\mathbf{s} = \text{StepSize} \cdot \frac{\mathbf{d}}{L}$ [S1, unofficial].
    *   Initialize ray position $\mathbf{p} = \mathbf{p}_{entry}$. If jittering is enabled, add noise: $\mathbf{p} \leftarrow \mathbf{p} + \mathbf{s} \cdot \text{snoise}(\frac{\mathbf{c}_{frag}}{2.5})$ [S1, unofficial].
    *   Initialize accumulators: destination color/alpha $\mathbf{C}_{dst} = (0,0,0,0)$, current normal $\mathbf{n} = (1,0,0)$, previous normal $\mathbf{n}_{prev} = \mathbf{n}$, base style color $\mathbf{C}_{base} = (0,0,0,0)$ [S1, unofficial].

2.  **Ray Marching Loop**:
    While $\mathbf{C}_{dst}.a < 1.0$ and $L > 0$:
    *   Sample density $D = \text{texture}(\text{VolumeTex}, \mathbf{p}).x$ [S1, unofficial].
    *   If `USE_THRESHOLD` is defined and $D \le \text{Threshold}$, skip to next step (continue) [S1, unofficial].
    *   Sample transfer function: $\alpha = \text{texture}(\text{transferFunctionTexture}, D).g$, $idx = \text{texture}(\text{transferFunctionTexture}, D).r$ [S1, unofficial].
    *   Determine style index: $k = \lfloor \text{texture}(\text{indexFunctionTexture}, idx).r \cdot \text{AVAILABLE\_STYLE\_COUNT} \rfloor$ [S1, unofficial].
    *   Compute gradient $\mathbf{g}$ at $\mathbf{p}$ using central differences with step $h = \text{StepSize}$:
        $$
        \mathbf{g} = \begin{bmatrix} \text{texture}(\text{VolumeTex}, \mathbf{p} + (h,0,0)).x - D \\ \text{texture}(\text{VolumeTex}, \mathbf{p} + (0,h,0)).x - D \\ \text{texture}(\text{VolumeTex}, \mathbf{p} + (0,0,h)).x - D \end{bmatrix}
        $$
        [S1, unofficial].
    *   Transform gradient to normal space: $\mathbf{n}_{new} = \text{normalize}(\text{NormalMatrix} \cdot \begin{bmatrix} \mathbf{g} \\ 0 \end{bmatrix})$ [S1, unofficial].
    *   **Style Mapping**:
        *   Map normal to 2D coordinates for the base style: $\mathbf{u}_{lit} = \begin{bmatrix} n_x \\ -n_y \end{bmatrix} \cdot 0.5 + 0.5$ [S1, unofficial].
        *   Sample base style color: $\mathbf{C}_{base} = \text{texture}(\text{styleTransferTexture}, \begin{bmatrix} \mathbf{u}_{lit} \\ k \end{bmatrix})$ [S1, unofficial].
    *   **Contour Lines** (if `USE_CONTOUR` is defined):
        *   Compute curvature approximation: $\kappa = \arccos\left(\frac{\mathbf{n}_{new} \cdot \mathbf{n}}{\|\mathbf{n}_{new}\| \|\mathbf{n}\|}\right) \cdot \text{StepSize}$ [S1, unofficial].
        *   Compute contour condition threshold: $T_{kv} = \text{thickness} \cdot \kappa$ (where `thickness` is 1.0), $C_{cond} = \sqrt{T_{kv}(2 - T_{kv})}$ [S1, unofficial].
        *   Compute view dot product: $n_{dotV} = |\mathbf{n}_{new} \cdot \frac{-\mathbf{p}}{\|\mathbf{p}\|}|$ [S1, unofficial].
        *   If $n_{dotV} \le C_{cond}$:
            *   Calculate lighting delta: $\Delta_{lit} = 1 - \min(1, \frac{C_{cond} - n_{dotV}}{C_{cond}})$ [S1, unofficial].
            *   Adjust length: $L_{adj} = \min(1, \frac{\|\mathbf{n}_{new}\|}{\Delta_{lit}})$ [S1, unofficial].
            *   Sample matcap style: $\mathbf{C}_{base} = \text{texture}(\text{styleTransferTexture}, \begin{bmatrix} \text{matcap}(\mathbf{p}, \mathbf{n}_{new}) \\ k \end{bmatrix})$ [S1, unofficial].
    *   **Compositing**:
        *   Set source: $\mathbf{C}_{src} = \begin{bmatrix} \mathbf{C}_{base}.rgb \cdot \alpha \\ \alpha \end{bmatrix}$ [S1, unofficial].
        *   Front-to-back compositing: $\mathbf{C}_{dst} \leftarrow (1 - \mathbf{C}_{dst}.a) \mathbf{C}_{src} + \mathbf{C}_{dst}$ [S1, unofficial].
    *   Advance: $\mathbf{p} \leftarrow \mathbf{p} + \mathbf{s}$, $L \leftarrow L - \text{StepSize}$, $\mathbf{n} \leftarrow \mathbf{n}_{new}$ [S1, unofficial].

3.  **Output**:
    *   Write $\mathbf{C}_{dst}$ to `FragColor` [S1, unofficial].

### Pseudocode

```python
def raycast_style_transfer(EntryPoint, ExitPointsTex, VolumeTex, TransferFuncTex, IndexFuncTex, StyleTex, NormalMatrix, ScreenSize, StepSize, Threshold, UseThreshold, UseContour, Thickness):
    # 1. Ray Initialization
    # Sample exit point from texture using normalized fragment coordinates
    # Note: gl_FragCoord.st / ScreenSize is assumed to be available in the shader context
    exit_point = ExitPointsTex.sample(gl_FragCoord.st / ScreenSize)
    
    if EntryPoint == exit_point:
        return vec4(0, 0, 0, 0) # Discard background

    ray_direction = exit_point - EntryPoint
    ray_length = length(ray_direction)
    step_vector = StepSize * normalize(ray_direction)
    
    # Initialize position
    pos = EntryPoint
    # Optional noise jitter [G]
    # if USE_NOISE_JITTER:
    #     pos += step_vector * snoise(gl_FragCoord.xy / 2.5)

    # Accumulators
    dst_color = vec4(0.0)
    dst_alpha = 0.0
    normal = vec3(1.0, 0.0, 0.0)
    
    while dst_alpha < 1.0 and ray_length > 0.0:
        # Sample density
        density = VolumeTex.sample(pos).x
        
        # Threshold check
        if UseThreshold and density <= Threshold:
            pos += step_vector
            ray_length -= StepSize
            continue
            
        # Transfer Function
        tf_sample = TransferFuncTex.sample(density)
        opacity = tf_sample.g
        index_val = tf_sample.r
        
        # Style Index
        idx_sample = IndexFuncTex.sample(index_val)
        style_index_float = idx_sample.x
        style_index = int(style_index_float * 34) # AVAILABLE_STYLE_COUNT = 34
        
        # Gradient and Normal
        h = StepSize
        grad_x = VolumeTex.sample(pos + vec3(h, 0, 0)).x - density
        grad_y = VolumeTex.sample(pos + vec3(0, h, 0)).x - density
        grad_z = VolumeTex.sample(pos + vec3(0, 0, h)).x - density
        gradient = vec3(grad_x, grad_y, grad_z)
        
        # Transform normal
        normal_new = normalize((NormalMatrix * vec4(gradient, 0.0)).xyz)
        
        # Base Style (LitSphere)
        lit_coords = vec2(normal_new.x, -normal_new.y) * 0.5 + 0.5
        base_color = StyleTex.sample(vec3(lit_coords, float(style_index)))
        
        # Contour Lines
        if UseContour:
            # Curvature approximation
            magnitudes = length(normal) * length(normal_new)
            if magnitudes > 0:
                curvature = acos(dot(normal, normal_new) / magnitudes) * StepSize
            else:
                curvature = 0.0
                
            Tkv = Thickness * curvature
            cond = sqrt(Tkv * (2.0 - Tkv))
            
            # View dot product
            view_dir = normalize(-pos)
            n_dot_v = abs(dot(normal_new, view_dir))
            
            if n_dot_v <= cond:
                lit_delta = 1.0 - min(1.0, (cond - n_dot_v) / cond)
                adjusted_length = min(1.0, length(normal_new) / lit_delta)
                
                # Matcap style for contours [G]
                # matcap function maps pos/normal to 2D coords for the style texture
                matcap_coords = matcap(pos, normal_new) 
                base_color = StyleTex.sample(vec3(matcap_coords, float(style_index)))
        
        # Compositing
        src_color = base_color.rgb * opacity
        src_alpha = opacity
        
        # Pre-multiply alpha is implicit in the formula: (1 - dst.a) * src + dst
        # where src is treated as (rgb * a, a)
        dst_color = (1.0 - dst_alpha) * vec4(src_color, src_alpha) + dst_color
        dst_alpha = dst_color.a
        
        # Advance
        normal = normal_new
        pos += step_vector
        ray_length -= StepSize
        
    return dst_color
```

### Edge Cases and Pitfalls
*   **Division by Zero**: In curvature calculation, if `magnitudes` is zero (degenerate gradient), the dot product normalization fails. Guard against this [S1, unofficial].
*   **Curvature Domain**: The term $T_{kv}(2 - T_{kv})$ must be non-negative. If $T_{kv} > 2$, the square root becomes invalid. Clamp $T_{kv}$ or handle the domain error [S1, unofficial].
*   **Style Index Bounds**: Ensure `style_index` is clamped to $[0, \text{AVAILABLE\_STYLE\_COUNT}-1]$ to prevent out-of-bounds texture access [S1, unofficial].
*   **Precision**: Floating point precision in gradient calculation can cause jitter in normal estimation. Using central differences with `StepSize` may introduce aliasing if `StepSize` is large relative to voxel size [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: $O(N \cdot P)$, where $N$ is the number of pixels and $P$ is the average number of samples per ray (determined by ray length and `StepSize`). The contour calculation adds constant overhead per sample.
*   **Memory Complexity**: $O(V + S)$, where $V$ is the volume texture size and $S$ is the size of the style transfer array texture ($W \times H \times 34$).
*   **Performance**: The method is computationally intensive due to multiple texture lookups per sample (Volume, Transfer, Index, Style) and gradient computation. It is typically implemented on the GPU using fragment shaders [S1, unofficial].
*   **Strengths**: Produces high-quality illustrative results with customizable artistic styles. Contour lines enhance shape perception.
*   **Limitations**: Style transfer is view-independent (except for the matcap contour mode which uses position). Performance scales linearly with resolution and ray length. Requires pre-computed style textures [S1, unofficial].

## Background
The method originates from the "FGC_T3" project, an illustrative volume rendering implementation using OpenGL shaders [S1, unofficial]. It was developed to provide artistic visualization capabilities for scientific data, combining traditional ray casting with style transfer techniques [S1, unofficial]. The approach uses a 2D array texture to store multiple artistic styles, allowing dynamic switching based on material properties derived from the transfer function [S1, unofficial].
