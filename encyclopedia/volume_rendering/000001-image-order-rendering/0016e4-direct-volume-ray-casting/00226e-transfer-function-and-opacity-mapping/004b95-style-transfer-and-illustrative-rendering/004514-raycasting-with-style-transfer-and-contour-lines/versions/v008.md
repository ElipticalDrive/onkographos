# Raycasting with Style Transfer and Contour Lines

Also called: FGC_T3 Raycasting, Style-based Volume Raycasting

## Overview
Raycasting with Style Transfer and Contour Lines is a direct volume rendering technique that applies artistic styles to volumetric data based on surface normals and material indices, while optionally rendering contour lines to emphasize structural features [S1, unofficial]. It distinguishes itself from standard direct volume raycasting by decoupling material appearance from density via a two-stage indexing system (material index to style index) and enhancing the result with curvature-based contour detection [S1, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
*   **Volume Data:** A 3D texture (`VolumeTex`) storing scalar density values.
*   **Transfer Function:** A 1D texture (`transferFunctionTexture`) mapping density to a material index (stored in the red channel) and opacity (stored in the green channel) [S1, unofficial].
*   **Index Function:** A 1D texture (`indexFunctionTexture`) mapping material indices to style indices [S1, unofficial].
*   **Style Transfer Texture:** A 2D array texture (`styleTransferTexture`) where the first two dimensions represent lit-sphere coordinates and the third dimension (layer) represents the style index [S1, unofficial].
*   **Exit Points:** A 2D texture (`ExitPoints`) storing the 3D exit coordinates for each screen pixel, generated by a preceding back-face rendering pass [S1, unofficial].
*   **Uniforms:**
    *   `NormalMatrix` (mat4): Transformation matrix for normals.
    *   `StepSize` (float): Distance between samples along the ray. Default: 0.01f [S1, unofficial].
    *   `Threshold` (float): Minimum density for valid sampling. Default: 0.15f [S1, unofficial].
    *   `ScreenSize` (vec2): Resolution of the output image.
    *   `AVAILABLE_STYLE_COUNT` (int): Number of styles in the array texture. Value: 34 [S1, unofficial].
*   **Fragment Attributes:**
    *   `EntryPoint` (vec3): The 3D entry point of the ray, passed from the vertex shader or computed.
    *   `gl_FragCoord` (vec4): Screen-space fragment coordinates.

**Outputs:**
*   `FragColor` (vec4): The final composited color and opacity for the fragment.

### Data Structures
*   **VolumeTex:** `sampler3D`. Stores density. Access via `texture(VolumeTex, pos).x`.
*   **transferFunctionTexture:** `sampler1D`. Input: density (0-1). Output: `vec4` where `.r` is material index, `.g` is opacity.
*   **indexFunctionTexture:** `sampler1D`. Input: material index (0-1 normalized). Output: `vec4` where `.x` is normalized style index.
*   **styleTransferTexture:** `sampler2DArray`. Input: `(u, v, layer)`. `u,v` are lit-sphere coordinates (0-1). `layer` is integer style index. Output: `vec4` base color.
*   **ExitPoints:** `sampler2D`. Input: `gl_FragCoord.st / ScreenSize`. Output: `vec3` exit point.

### Algorithm Steps
1.  **Retrieve Exit Point:** Sample the `ExitPoints` texture using normalized fragment coordinates:
    $$ \mathbf{p}_{exit} = \text{texture}(\text{ExitPoints}, \frac{\text{gl\_FragCoord}.st}{\text{ScreenSize}}).xyz $$
2.  **Background Check:** If the entry point $\mathbf{p}_{entry}$ equals $\mathbf{p}_{exit}$, discard the fragment (background) [S1, unofficial].
3.  **Ray Setup:**
    *   Calculate ray direction: $\mathbf{d} = \mathbf{p}_{exit} - \mathbf{p}_{entry}$.
    *   Calculate ray length: $L = \|\mathbf{d}\|$.
    *   Calculate step vector: $\mathbf{s} = \text{StepSize} \cdot \frac{\mathbf{d}}{L}$.
    *   Initialize ray position $\mathbf{pos} = \mathbf{p}_{entry}$. If `USE_NOISE_JITTER` is defined, jitter the start position: $\mathbf{pos} \leftarrow \mathbf{pos} + \mathbf{s} \cdot \text{snoise}(\frac{\text{gl\_FragCoord}.xy}{2.5})$ [S1, unofficial].
4.  **Initialize Accumulators:**
    *   Destination color/opacity: $\mathbf{c}_{dst} = (0, 0, 0, 0)$.
    *   Previous normal: $\mathbf{n}_{prev} = (1, 0, 0)$ (or similar default, source uses `vec3(1.f)` but normalizes later; effectively acts as initial state) [S1, unofficial].
    *   Current normal: $\mathbf{n} = (1, 0, 0)$.
    *   Base color: $\mathbf{c}_{base} = (0, 0, 0, 0)$.
5.  **Ray Marching Loop:** While $\mathbf{c}_{dst}.a < 1.0$ and $L > 0$:
    1.  **Sample Density:** $\rho = \text{texture}(\text{VolumeTex}, \mathbf{pos}).x$.
    2.  **Threshold Check:** If `USE_THRESHOLD` is defined and $\rho \le \text{Threshold}$, skip to step 5.5 (advance ray).
    3.  **Transfer Function Lookup:**
        *   Opacity: $\alpha = \text{texture}(\text{transferFunctionTexture}, \rho).g$.
        *   Material Index: $m = \text{texture}(\text{transferFunctionTexture}, \rho).r$.
    4.  **Style Index Lookup:**
        *   Normalized Style Index: $s_{norm} = \text{texture}(\text{indexFunctionTexture}, m).x$.
        *   Integer Style Index: $s = \lfloor s_{norm} \cdot \text{AVAILABLE\_STYLE\_COUNT} \rfloor$.
    5.  **Normal Estimation:**
        *   Compute gradient $\mathbf{g}$ at $\mathbf{pos}$ using central differences or forward differences with step size `StepSize`. The source defines `computeGradient` using forward differences relative to a "lookUp" value (density):
            $$ \mathbf{g} = \begin{bmatrix} \rho(x+\Delta, y, z) - \rho \\ \rho(x, y+\Delta, z) - \rho \\ \rho(x, y, z+\Delta) - \rho \end{bmatrix} $$
            where $\Delta = \text{StepSize}$ [S1, unofficial].
        *   Transform gradient to view space: $\mathbf{n}_{new} = \text{NormalMatrix} \cdot \begin{bmatrix} \mathbf{g} \\ 0 \end{bmatrix}$.xyz.
        *   Update previous normal: $\mathbf{n}_{prev} = \mathbf{n}$.
        *   Update current normal: $\mathbf{n} = \mathbf{n}_{new}$.
    6.  **Lit-Sphere Mapping:**
        *   Map normal to 2D coordinates:
            $$ \mathbf{u} = \begin{bmatrix} n_x \\ -n_y \end{bmatrix} \cdot 0.5 + 0.5 $$
            [S1, unofficial].
    7.  **Style Lookup:**
        *   $\mathbf{c}_{base} = \text{texture}(\text{styleTransferTexture}, \mathbf{u}, s)$ [S1, unofficial].
    8.  **Contour Line Calculation (Optional):**
        *   If `USE_CONTOUR` is defined:
            *   Calculate curvature approximation:
                $$ \kappa = \arccos\left(\frac{\mathbf{n} \cdot \mathbf{n}_{prev}}{\|\mathbf{n}\| \|\mathbf{n}_{prev}\|}\right) \cdot \text{StepSize} $$
                [S1, unofficial].
            *   Calculate contour condition:
                $$ T_{kv} = \text{thickness} \cdot \kappa $$
                $$ \text{cond} = \sqrt{T_{kv} (2 - T_{kv})} $$
                where `thickness` is 1.0 [S1, unofficial].
            *   Calculate view dot product:
                $$ \text{nDotV} = |\mathbf{n} \cdot \frac{-\mathbf{pos}}{\|\mathbf{pos}\|}| $$
                [S1, unofficial].
            *   If $\text{nDotV} \le \text{cond}$, apply matcap style for contours:
                *   Calculate lighting delta: $\Delta_{lit} = 1.0 - \min(1.0, \frac{\text{cond} - \text{nDotV}}{\text{cond}})$.
                *   Adjust normal length: $L_{adj} = \min(1.0, \frac{\|\mathbf{n}\|}{\Delta_{lit}})$.
                *   Sample matcap style: $\mathbf{c}_{base} = \text{texture}(\text{styleTransferTexture}, \text{matcap}(\mathbf{pos}, \mathbf{n}).xy, s)$. Note: `matcap` function maps position and normal to lit-sphere coordinates specifically for contour highlighting [S1, unofficial].
    9.  **Compositing:**
        *   Source color: $\mathbf{c}_{src} = (\mathbf{c}_{base}.rgb, \alpha)$.
        *   Pre-multiply alpha: $\mathbf{c}_{src}.rgb \leftarrow \mathbf{c}_{src}.rgb \cdot \mathbf{c}_{src}.a$.
        *   Front-to-back compositing:
            $$ \mathbf{c}_{dst} = (1.0 - \mathbf{c}_{dst}.a) \cdot \mathbf{c}_{src} + \mathbf{c}_{dst} $$
    10. **Advance Ray:**
        *   $\mathbf{pos} \leftarrow \mathbf{pos} + \mathbf{s}$.
        *   $L \leftarrow L - \text{StepSize}$.
6.  **Output:** Set `FragColor` to $\mathbf{c}_{dst}$ [S1, unofficial].

### Pseudocode
```python
def raycast_with_style_transfer_and_contour_lines(
    volume_tex, exit_points_tex, transfer_func_tex, index_func_tex,
    style_transfer_tex, normal_matrix, step_size, threshold, screen_size,
    entry_point, frag_coord, use_threshold, use_noise_jitter, use_contour,
    available_style_count=34
):
    # 1. Retrieve Exit Point
    uv = frag_coord.st / screen_size
    exit_point = exit_points_tex.sample(uv)
    
    # 2. Background Check
    if entry_point == exit_point:
        return vec4(0, 0, 0, 0)
    
    # 3. Ray Setup
    ray_direction = exit_point - entry_point
    ray_length = length(ray_direction)
    step_vector = step_size * normalize(ray_direction)
    
    pos = entry_point
    if use_noise_jitter:
        # snoise is a simple noise function, e.g., Perlin or Simplex
        jitter = snoise(frag_coord.xy / 2.5)
        pos += step_vector * jitter
        
    # 4. Initialize Accumulators
    dst_color = vec4(0, 0, 0, 0)
    prev_normal = vec3(1, 0, 0) # Default initial normal
    curr_normal = vec3(1, 0, 0)
    
    # 5. Ray Marching Loop
    while dst_color.a < 1.0 and ray_length > 0:
        # Sample Density
        density = volume_tex.sample(pos).x
        
        # Threshold Check
        if use_threshold and density <= threshold:
            pos += step_vector
            ray_length -= step_size
            continue
            
        # Transfer Function Lookup
        opacity = transfer_func_tex.sample(density).g
        material_index = transfer_func_tex.sample(density).r
        
        # Style Index Lookup
        style_index_norm = index_func_tex.sample(material_index).x
        style_index = int(style_index_norm * available_style_count)
        
        # Normal Estimation
        # Compute gradient using forward differences with step_size
        grad_x = volume_tex.sample(pos + vec3(step_size, 0, 0)).x - density
        grad_y = volume_tex.sample(pos + vec3(0, step_size, 0)).x - density
        grad_z = volume_tex.sample(pos + vec3(0, 0, step_size)).x - density
        gradient = vec3(grad_x, grad_y, grad_z)
        
        # Transform gradient to view space
        new_normal = (normal_matrix * vec4(gradient, 0)).xyz
        
        prev_normal = curr_normal
        curr_normal = new_normal
        
        # Lit-Sphere Mapping
        u = vec2(curr_normal.x, -curr_normal.y) * 0.5 + 0.5
        
        # Style Lookup
        base_color = style_transfer_tex.sample(u, style_index)
        
        # Contour Line Calculation
        if use_contour:
            magnitudes = length(curr_normal) * length(prev_normal)
            if magnitudes > 0:
                curvature = acos(dot(curr_normal, prev_normal) / magnitudes) * step_size
            else:
                curvature = 0.0
                
            thickness = 1.0
            tkv = thickness * curvature
            cond = sqrt(tkv * (2.0 - tkv))
            
            view_dir = normalize(-pos)
            n_dot_v = abs(dot(curr_normal, view_dir))
            
            if n_dot_v <= cond:
                lit_delta = 1.0 - min(1.0, (cond - n_dot_v) / cond)
                adjusted_length = min(1.0, length(curr_normal) / lit_delta)
                # matcap function maps pos and normal to lit-sphere coords for contour style
                matcap_uv = matcap(pos, curr_normal).xy
                base_color = style_transfer_tex.sample(matcap_uv, style_index)
                
        # Compositing
        src_color = vec4(base_color.rgb, opacity)
        src_color.rgb *= src_color.a
        dst_color = (1.0 - dst_color.a) * src_color + dst_color
        
        # Advance Ray
        pos += step_vector
        ray_length -= step_size
        
    return dst_color
```

### Parameters
*   **StepSize:** Default 0.01f [S1, unofficial].
*   **Threshold:** Default 0.15f [S1, unofficial].
*   **AVAILABLE_STYLE_COUNT:** 34 [S1, unofficial].

### Edge Cases and Pitfalls
*   **Zero-Length Normals:** If the gradient is zero (flat region), the normal remains unchanged or becomes undefined. The pseudocode handles this by checking `magnitudes > 0` before computing curvature [S1, unofficial].
*   **Boundary Conditions:** The `ExitPoints` texture must be correctly populated by a preceding pass. If the ray does not intersect the volume, the entry and exit points will be identical, and the fragment is discarded [S1, unofficial].
*   **Precision:** The curvature calculation involves `acos`, which is sensitive to floating-point errors when the dot product is slightly outside [-1, 1]. Clamping is recommended [G].
*   **Contour Artifacts:** The contour condition `cond` can become unstable if `tkv` exceeds 2.0, leading to imaginary numbers in the square root. The source uses `sqrt(tkv * (2 - tkv))`, implying `tkv` should be $\le 2$. If `tkv > 2`, `cond` becomes NaN or invalid. A guard `tkv = min(tkv, 2.0)` is recommended [G].

## Operating characteristics
*   **Time Complexity:** $O(N \cdot M)$, where $N$ is the number of pixels and $M$ is the average number of samples per ray. The complexity is linear with respect to the number of samples.
*   **Memory Complexity:** $O(V + S)$, where $V$ is the volume data size and $S$ is the size of the style transfer texture (2D array). The exit points texture adds $O(P)$ memory, where $P$ is the number of pixels.
*   **Performance:** Performance depends heavily on the number of samples and the complexity of the style transfer texture lookups. The use of a 2D array texture allows for efficient style switching without branching. Contour calculations add a small overhead due to the curvature computation and additional texture lookups [S1, unofficial].
*   **Strengths:** Provides high-quality artistic rendering with minimal user intervention. The decoupling of material and style allows for easy swapping of artistic styles. Contour lines enhance the perception of structure.
*   **Limitations:** Requires a pre-pass to generate exit points. The quality of the style transfer depends on the resolution and coverage of the style transfer texture. Contour lines may appear noisy if the step size is too large or the volume is sparse [S1, unofficial].

## Background
The method originates from the work of Jose Villegas on illustrative volume rendering, specifically the "FGC_T3" implementation [S1, unofficial]. It builds upon the principles of style transfer in volume rendering, extending them with contour line generation to provide a more illustrative and artistic representation of volumetric data [S1, unofficial].
