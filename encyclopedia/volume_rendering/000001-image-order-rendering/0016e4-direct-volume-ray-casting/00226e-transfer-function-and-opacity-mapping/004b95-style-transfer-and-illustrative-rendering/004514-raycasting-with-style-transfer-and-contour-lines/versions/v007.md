# Raycasting with Style Transfer and Contour Lines

Also called: FGC_T3 Raycasting, Style-based Volume Raycasting

## Overview
This method extends direct volume ray casting by replacing standard color/opacity mapping with a **Style Transfer Function (STF)** that maps material indices and surface normals to artistic styles via a 2D array texture [S1, unofficial]. It distinguishes itself from standard transfer function methods by decoupling material identification from visual appearance, allowing multiple artistic styles to be applied to the same underlying data based on geometry and view angle [S1, unofficial]. It builds on [Style Transfer and Illustrative Rendering](13031-style-transfer-and-illustrative-rendering.md).

## How it works
The method operates in two passes: a pre-pass to capture exit points and the main ray casting pass.

### Inputs and Outputs
**Inputs:**
*   **Volume Data:** A 3D texture (`VolumeTex`) containing scalar density values.
*   **Transfer Function Texture:** A 1D texture (`transferFunctionTexture`) mapping density to opacity (green channel) and material index (red channel) [S1, unofficial].
*   **Index Function Texture:** A 1D texture (`indexFunctionTexture`) mapping material index to style index [S1, unofficial].
*   **Style Transfer Texture:** A 2D array texture (`styleTransferTexture`) where layers correspond to style indices, and the 2D coordinates correspond to surface normal mappings (lit sphere) [S1, unofficial].
*   **Exit Points Texture:** A 2D texture (`ExitPoints`) storing the 3D exit coordinates for each screen pixel, generated by a back-face rendering pass [S1, unofficial].
*   **Uniforms:** `NormalMatrix` (mat4), `StepSize` (float, default 0.01), `Threshold` (float, default 0.15), `ScreenSize` (vec2), `AVAILABLE_STYLE_COUNT` (int, value 34) [S1, unofficial].

**Outputs:**
*   **FragColor:** The final composited color and opacity for each fragment [S1, unofficial].

### Data Structures
*   **ExitPoints Texture:** 2D texture storing `vec3` exit coordinates. Indexed by normalized fragment coordinates `gl_FragCoord.st / ScreenSize` [S1, unofficial].
*   **Style Transfer Texture:** 2D array texture. Dimensions: Width $\times$ Height $\times$ `AVAILABLE_STYLE_COUNT`. The first two dimensions store color values mapped from normal vectors; the third dimension selects the style [S1, unofficial].

### Steps

1.  **Exit Point Retrieval:**
    Retrieve the 3D exit point for the current fragment from the `ExitPoints` texture using normalized screen coordinates:
    $$ \mathbf{p}_{exit} = \text{texture}(\text{ExitPoints}, \frac{\mathbf{gl\_FragCoord.st}}{\text{ScreenSize}}).xyz $$
    If the retrieved exit point equals the entry point (background), discard the fragment [S1, unofficial].

2.  **Ray Initialization:**
    Calculate the ray direction $\mathbf{d}$ and length $L$:
    $$ \mathbf{d} = \mathbf{p}_{exit} - \mathbf{p}_{entry} $$
    $$ L = \|\mathbf{d}\| $$
    Calculate the step vector $\mathbf{s}$:
    $$ \mathbf{s} = \text{StepSize} \cdot \frac{\mathbf{d}}{L} $$
    Initialize the ray start position $\mathbf{p}$. If noise jittering is enabled, add jitter based on fragment coordinates:
    $$ \mathbf{p} = \mathbf{p}_{entry} + \mathbf{s} \cdot \text{snoise}\left(\frac{\mathbf{gl\_FragCoord.xy}}{2.5}\right) $$
    Initialize accumulators: destination color/opacity $\mathbf{c}_{dst} = (0,0,0,0)$, current normal $\mathbf{n} = (1,0,0)$, base color $\mathbf{c}_{base} = (0,0,0,0)$, and source color $\mathbf{c}_{src} = (0,0,0,0)$ [S1, unofficial].

3.  **Ray Marching Loop:**
    While accumulated opacity $\mathbf{c}_{dst}.a < 1.0$ and remaining ray length $L > 0$:
    
    a. **Sample Density:**
       $$ \rho = \text{texture}(\text{VolumeTex}, \mathbf{p}).x $$
       If `USE_THRESHOLD` is defined and $\rho \le \text{Threshold}$, skip to step 3g [S1, unofficial].

    b. **Transfer Function Lookup:**
       Sample opacity $\alpha$ and material index $idx$ from `transferFunctionTexture`:
       $$ \alpha = \text{texture}(\text{transferFunctionTexture}, \rho).g $$
       $$ idx = \text{texture}(\text{transferFunctionTexture}, \rho).r $$

    c. **Style Index Determination:**
       Map material index to style index $s$:
       $$ s = \lfloor \text{texture}(\text{indexFunctionTexture}, idx).x \cdot \text{AVAILABLE\_STYLE\_COUNT} \rfloor $$

    d. **Normal Estimation:**
       Compute the gradient $\mathbf{g}$ at $\mathbf{p}$ using central differences with step size `StepSize` $h$:
       $$ \mathbf{g} = \begin{bmatrix} \rho(x+h, y, z) - \rho \\ \rho(x, y+h, z) - \rho \\ \rho(x, y, z+h) - \rho \end{bmatrix} $$
       Transform the gradient to view space using `NormalMatrix` $\mathbf{M}_N$:
       $$ \mathbf{n}_{new} = \text{normalize}(\mathbf{M}_N \cdot \begin{bmatrix} \mathbf{g} \\ 0 \end{bmatrix}.xyz) $$
       Store previous normal $\mathbf{n}_{prev} = \mathbf{n}$ and update $\mathbf{n} = \mathbf{n}_{new}$ [S1, unofficial].

    e. **Style Lookup:**
       Map normal $\mathbf{n}$ to lit sphere coordinates $\mathbf{u}$:
       $$ \mathbf{u} = \begin{bmatrix} n_x \\ -n_y \end{bmatrix} \cdot 0.5 + 0.5 $$
       Sample the base color from the style transfer texture:
       $$ \mathbf{c}_{base} = \text{texture}(\text{styleTransferTexture}, \begin{bmatrix} \mathbf{u} \\ s \end{bmatrix}) $$

    f. **Contour Lines (Optional):**
       If `USE_CONTOUR` is defined:
       Calculate curvature approximation $\kappa$:
       $$ \kappa = \arccos\left(\frac{\mathbf{n} \cdot \mathbf{n}_{prev}}{\|\mathbf{n}\| \|\mathbf{n}_{prev}\|}\right) \cdot \text{StepSize} $$
       Calculate contour condition threshold $C$:
       $$ T_{kv} = \text{thickness} \cdot \kappa $$
       $$ C = \sqrt{T_{kv} (2 - T_{kv})} $$
       Calculate view dot product $N_V$:
       $$ N_V = |\mathbf{n} \cdot \frac{-\mathbf{p}}{\|\mathbf{p}\|}| $$
       If $N_V \le C$, apply a matcap style adjustment:
       $$ \Delta = 1 - \min(1, \frac{C - N_V}{C}) $$
       $$ \mathbf{c}_{base} = \text{texture}(\text{styleTransferTexture}, \begin{bmatrix} \text{matcap}(\mathbf{p}, \mathbf{n}).xy \\ s \end{bmatrix}) $$
       [S1, unofficial]

    g. **Compositing:**
       Set source color:
       $$ \mathbf{c}_{src} = \begin{bmatrix} \mathbf{c}_{base}.rgb \\ \alpha \end{bmatrix} $$
       Pre-multiply alpha:
       $$ \mathbf{c}_{src}.rgb \leftarrow \mathbf{c}_{src}.rgb \cdot \mathbf{c}_{src}.a $$
       Composite into destination:
       $$ \mathbf{c}_{dst} = (1 - \mathbf{c}_{dst}.a) \cdot \mathbf{c}_{src} + \mathbf{c}_{dst} $$

    h. **Advance Ray:**
       $$ \mathbf{p} \leftarrow \mathbf{p} + \mathbf{s} $$
       $$ L \leftarrow L - \text{StepSize} $$

4.  **Output:**
    Write $\mathbf{c}_{dst}$ to `FragColor` [S1, unofficial].

### Pseudocode
```python
def raycast_with_style_transfer_and_contour_lines(
    entry_point: vec3,
    exit_points_texture: Texture2D,
    volume_texture: Texture3D,
    transfer_function_texture: Texture1D,
    index_function_texture: Texture1D,
    style_transfer_texture: Texture2DArray,
    normal_matrix: mat4,
    screen_size: vec2,
    step_size: float = 0.01,
    threshold: float = 0.15,
    available_style_count: int = 34,
    use_threshold: bool = True,
    use_noise_jitter: bool = False,
    use_contour: bool = False,
    thickness: float = 1.0
) -> vec4:
    """
    Performs volume ray casting with style transfer and optional contour lines.
    """
    # 1. Retrieve Exit Point
    normalized_coord = vec2(gl_frag_coord_st) / screen_size
    exit_point = exit_points_texture.sample(normalized_coord).xyz
    
    # Discard background
    if entry_point == exit_point:
        return vec4(0.0)

    # 2. Ray Initialization
    ray_direction = exit_point - entry_point
    ray_length = length(ray_direction)
    step_vector = step_size * normalize(ray_direction)
    
    ray_pos = entry_point
    if use_noise_jitter:
        # snoise is a standard simplex noise function
        jitter = step_size * snoise(vec2(gl_frag_coord_xy) / 2.5)
        ray_pos += jitter

    dst_color = vec4(0.0)
    current_normal = vec3(1.0, 0.0, 0.0)
    prev_normal = current_normal

    # 3. Ray Marching Loop
    while dst_color.a < 1.0 and ray_length > 0.0:
        # Sample Density
        density = volume_texture.sample(ray_pos).x
        
        if use_threshold and density <= threshold:
            ray_pos += step_vector
            ray_length -= step_size
            continue

        # Transfer Function Lookup
        tf_sample = transfer_function_texture.sample(density)
        opacity = tf_sample.g
        material_index = tf_sample.r

        # Style Index Determination
        style_index_float = index_function_texture.sample(material_index).x
        style_index = int(style_index_float * available_style_count)

        # Normal Estimation
        h = step_size
        grad_x = volume_texture.sample(ray_pos + vec3(h, 0, 0)).x - density
        grad_y = volume_texture.sample(ray_pos + vec3(0, h, 0)).x - density
        grad_z = volume_texture.sample(ray_pos + vec3(0, 0, h)).x - density
        gradient = vec3(grad_x, grad_y, grad_z)
        
        prev_normal = current_normal
        # Transform gradient to view space
        normal_vec = normal_matrix * vec4(gradient, 0.0)
        current_normal = normalize(normal_vec.xyz)

        # Style Lookup
        # Lit sphere mapping
        lit_sphere_u = vec2(current_normal.x, -current_normal.y) * 0.5 + 0.5
        
        base_color = style_transfer_texture.sample(vec3(lit_sphere_u, float(style_index)))

        # Contour Lines
        if use_contour:
            magnitudes = length(current_normal) * length(prev_normal)
            if magnitudes > 0.0:
                curvature = acos(dot(current_normal, prev_normal) / magnitudes) * step_size
            else:
                curvature = 0.0
            
            t_kv = thickness * curvature
            cond = sqrt(t_kv * (2.0 - t_kv))
            
            view_dir = normalize(-ray_pos)
            n_dot_v = abs(dot(current_normal, view_dir))
            
            if n_dot_v <= cond:
                lit_delta = 1.0 - min(1.0, (cond - n_dot_v) / cond)
                # matcap function maps position and normal to 2D coords for matcap style
                matcap_coords = matcap(ray_pos, current_normal).xy
                base_color = style_transfer_texture.sample(vec3(matcap_coords, float(style_index)))

        # Compositing
        src_color = vec4(base_color.rgb, opacity)
        src_color.rgb *= src_color.a
        dst_color = (1.0 - dst_color.a) * src_color + dst_color

        # Advance
        ray_pos += step_vector
        ray_length -= step_size

    return dst_color
```

### Parameters
*   **StepSize:** Distance between samples. Default: 0.01 [S1, unofficial].
*   **Threshold:** Minimum density for processing. Default: 0.15 [S1, unofficial].
*   **AVAILABLE_STYLE_COUNT:** Number of styles in the array texture. Value: 34 [S1, unofficial].

### Edge Cases and Pitfalls
*   **Background Detection:** If the exit point equals the entry point, the fragment is discarded. This requires accurate back-face rendering for the exit points texture [S1, unofficial].
*   **Normal Degeneracy:** If the gradient magnitude is zero, the normal is undefined. The pseudocode handles this by checking magnitudes before computing curvature [S1, unofficial].
*   **Precision:** The curvature calculation involves `acos`, which is sensitive to floating-point errors when vectors are nearly parallel. Clamping the dot product to $[-1, 1]$ is recommended [G].
*   **Array Texture Bounds:** The style index must be clamped to $[0, \text{AVAILABLE\_STYLE\_COUNT}-1]$ to avoid out-of-bounds sampling [G].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of samples along the ray. Each sample requires multiple texture lookups (volume, transfer function, index function, style transfer) and gradient computations.
*   **Memory Complexity:** Dominated by the storage of the 3D volume texture, the 2D array style transfer texture, and the exit points texture. The style transfer texture size is $W \times H \times \text{AVAILABLE\_STYLE\_COUNT}$ [S1, unofficial].
*   **Performance:** The method is GPU-intensive due to the high number of texture samples per fragment and the use of array textures. The pre-pass for exit points adds overhead but allows for efficient ray marching without front-face intersection tests [S1, unofficial].
*   **Strengths:** Enables high-quality artistic rendering with minimal changes to the underlying data. The use of lit sphere mapping allows for consistent lighting effects across different styles.
*   **Limitations:** The quality of the result depends heavily on the design of the style transfer texture and the accuracy of the normal estimation. Contour lines may appear noisy if the step size is too large or the data is sparse [S1, unofficial].

## Background
The method originates from the work on illustrative volume rendering, specifically the FGC_T3 implementation which integrates style transfer functions into the ray casting pipeline. It was developed to allow artists to apply various artistic styles (e.g., pencil sketch, watercolor) to volumetric data based on material properties and surface orientation [S1, unofficial].
