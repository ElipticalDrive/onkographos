# Direct Volume Rendering with Interactive Piecewise Transfer Function

Also called: DirectVolRendering1, Front-to-Back Ray Casting with Transfer Functions, InteractiveDirectVolRendering

## Overview
A CPU-based direct volume rendering technique that maps scalar voxel values to RGBA colors using a piecewise linear transfer function defined by 5 control points, then composites the resulting 3D volume along rays using front-to-back alpha blending [S1, unofficial]. It differs from optimized implementations by performing transfer function application and compositing in two separate passes (creating an intermediate 4D RGBA volume, then compositing), rather than combining them into a single ray-casting loop [S1, unofficial].

## How it works
**Inputs:**
*   `vol`: Input 3D volume data, a numpy array of shape $(D, H, W)$ where $D$ is depth/slices, $H$ is height, $W$ is width [S1, unofficial].
*   `l1, l2, l3, l4`: Threshold values defining the boundaries of the 5 intervals in the transfer function. Must satisfy $0 \le l1 < l2 < l3 < l4 \le \max(vol)$ [S1, unofficial].
*   `alpha1, alpha2, alpha3, alpha4, alpha5`: Opacity values for the 5 intervals defined by $l1-l4$. `alpha1` corresponds to values $< l1$, `alpha2` to $l1 \le v < l2$, etc., `alpha5` to values $\ge l4$ [S1, unofficial].
*   `rgbScaler`: Array of size $n = cn/4$. Each row $i$ stores $[scalar, R, G, B]$ [S2, unofficial].
*   `opacityScaler`: Array of size $n = on/2$. Each row $i$ stores $[scalar, opacity]$ [S2, unofficial].

**Outputs:**
*   `res`: Final rendered image array of shape $(W, H, 4)$ (RGBA) [S1, unofficial].

**Data Structures:**
*   `fres`: Intermediate 4D RGBA volume of shape $(D, 4, H, W)$ [S1, unofficial].
*   `ps`: Accumulated RGBA state of shape $(4, H, W)$ [S1, unofficial]. Note: Source code initializes `ps` with shape $(H, W, D)$ but accesses it as $(4, H, W)$, implying a logical shape of $(4, H, W)$ for the compositing loop [S1, unofficial].

**Steps:**

1.  **Preprocessing (Normalization):**
    Normalize the input volume to the 8-bit integer range $[0, 255]$.
    $$ v_{norm} = \text{round}\left( 255 \cdot \frac{v - v_{min}}{v_{max} - v_{min} + 10^{-15}} \right) $$
    where $v_{min} = \min(vol)$ and $v_{max} = \max(vol)$ [S1, unofficial]. The epsilon $10^{-15}$ prevents division by zero if the volume has constant values [S1, unofficial].

2.  **Transfer Function Application:**
    For each slice $i$ in range $(D)$:
    *   Initialize `res1`, `res2`, `res3`, `res4` (R, G, B, A channels) as zero arrays of shape $(H, W)$ [S1, unofficial].
    *   Let $v = vol_{norm}[i, :, :]$.
    *   Apply boolean masking to assign RGBA values based on thresholds:
        *   If $v < l1$: $R=0, G=0, B=0, A=\alpha1$ [S1, unofficial].
        *   If $l1 \le v < l2$: $R=0, G=0, B=255, A=\alpha2$ [S1, unofficial].
        *   If $l2 \le v < l3$: $R=0, G=255, B=0, A=\alpha3$ [S1, unofficial].
        *   If $l3 \le v < l4$: $R=255, G=0, B=0, A=\alpha4$ [S1, unofficial].
        *   If $v \ge l4$: $R=127, G=0, B=127, A=\alpha5$ [S1, unofficial].
    *   Store results in `fres[i, 0, :, :]` (R), `fres[i, 1, :, :]` (G), `fres[i, 2, :, :]` (B), `fres[i, 3, :, :]` (A) [S1, unofficial].

3.  **Compositing (Front-to-Back):**
    *   Initialize `ps` (previous sample) as zero array of shape $(4, H, W)$ representing accumulated RGBA [S1, unofficial].
    *   For each slice $i$ from $0$ to $D-1$:
        *   Get current slice $s = fres[i, :, :, :]$ of shape $(4, H, W)$ [S1, unofficial].
        *   Update temporary result `tmp_res`:
            $$ C_{out} = C_{prev} + (1 - A_{prev}) \cdot A_{curr} \cdot C_{curr} $$
            $$ A_{out} = A_{prev} + (1 - A_{prev}) \cdot A_{curr} $$
            Where $C_{prev}$ and $A_{prev}$ are from `ps`, and $C_{curr}, A_{curr}$ are from $s$ [S1, S2, unofficial].
        *   Set `ps = tmp_res` [S1, unofficial].

4.  **Final Output:**
    *   Initialize `res` of shape $(W, H, 4)$ [S1, unofficial].
    *   Copy `ps` channels to `res`. Note: The source code inverts the alpha channel: $res[:, :, 3] = 1 - res[:, :, 3]$ [S1, unofficial]. This suggests the output represents transparency or background visibility, though standard VR outputs accumulated color and opacity [S1, unofficial].

**Pseudocode:**

```python
import numpy as np

def normalize_volume(vol):
    """Normalize volume to 8-bit integer range [0, 255]."""
    vmin = np.min(vol)
    vmax = np.max(vol)
    # Prevent division by zero
    denom = vmax - vmin + 1e-15
    vol_norm = np.round(255 * (vol - vmin) / denom)
    return vol_norm.astype(np.uint8)

def apply_transfer_function(vol_norm, l1, l2, l3, l4, alpha1, alpha2, alpha3, alpha4, alpha5):
    """
    Apply piecewise transfer function to volume.
    Returns 4D RGBA volume of shape (D, 4, H, W).
    """
    D, H, W = vol_norm.shape
    fres = np.zeros((D, 4, H, W), dtype=np.float32)
    
    for i in range(D):
        v = vol_norm[i, :, :]
        
        # Initialize channels
        R = np.zeros((H, W), dtype=np.float32)
        G = np.zeros((H, W), dtype=np.float32)
        B = np.zeros((H, W), dtype=np.float32)
        A = np.zeros((H, W), dtype=np.float32)
        
        # Masking logic
        # v < l1
        mask1 = v < l1
        R[mask1] = 0
        G[mask1] = 0
        B[mask1] = 0
        A[mask1] = alpha1
        
        # l1 <= v < l2
        mask2 = (v >= l1) & (v < l2)
        R[mask2] = 0
        G[mask2] = 0
        B[mask2] = 255
        A[mask2] = alpha2
        
        # l2 <= v < l3
        mask3 = (v >= l2) & (v < l3)
        R[mask3] = 0
        G[mask3] = 255
        B[mask3] = 0
        A[mask3] = alpha3
        
        # l3 <= v < l4
        mask4 = (v >= l3) & (v < l4)
        R[mask4] = 255
        G[mask4] = 0
        B[mask4] = 0
        A[mask4] = alpha4
        
        # v >= l4
        mask5 = v >= l4
        R[mask5] = 127
        G[mask5] = 0
        B[mask5] = 127
        A[mask5] = alpha5
        
        fres[i, 0, :, :] = R
        fres[i, 1, :, :] = G
        fres[i, 2, :, :] = B
        fres[i, 3, :, :] = A
        
    return fres

def composite_volume(trans_vol):
    """
    Front-to-back compositing.
    trans_vol: 4D array of shape (D, 4, H, W).
    Returns: 3D array of shape (H, W, 4) with inverted alpha.
    """
    D, _, H, W = trans_vol.shape
    
    # Initialize accumulated RGBA (4, H, W)
    ps = np.zeros((4, H, W), dtype=np.float32)
    
    for i in range(D):
        s = trans_vol[i, :, :, :] # Shape (4, H, W)
        
        # Extract current color and opacity
        C_curr = s[0:3, :, :]
        A_curr = s[3, :, :]
        
        # Extract previous accumulated color and opacity
        C_prev = ps[0:3, :, :]
        A_prev = ps[3, :, :]
        
        # Front-to-back blending
        # C_out = C_prev + (1 - A_prev) * A_curr * C_curr
        # A_out = A_prev + (1 - A_prev) * A_curr
        
        one_minus_A_prev = 1.0 - A_prev
        tmp_C = C_prev + one_minus_A_prev * A_curr * C_curr
        tmp_A = A_prev + one_minus_A_prev * A_curr
        
        ps[0:3, :, :] = tmp_C
        ps[3, :, :] = tmp_A
        
    # Reshape to (H, W, 4)
    res = np.transpose(ps, (1, 2, 0))
    
    # Invert alpha channel as per source implementation
    res[:, :, 3] = 1.0 - res[:, :, 3]
    
    return res

def interpolate_value(scalar_a, scalar_b, val_a, val_b, value):
    """Linear interpolation."""
    if scalar_b == scalar_a:
        return val_a
    alpha = (value - scalar_a) / (scalar_b - scalar_a)
    return alpha * val_b + (1 - alpha) * val_a

def interpolate_rgb(value, rgb_scaler):
    """Interpolate RGB color from scalar value using rgb_scaler table."""
    n = len(rgb_scaler)
    for i in range(n - 1):
        scalar_a = rgb_scaler[i][0]
        scalar_b = rgb_scaler[i+1][0]
        if value == scalar_a:
            return np.array([rgb_scaler[i][1], rgb_scaler[i][2], rgb_scaler[i][3]])
        if scalar_a < value < scalar_b:
            r = interpolate_value(scalar_a, scalar_b, rgb_scaler[i][1], rgb_scaler[i+1][1], value)
            g = interpolate_value(scalar_a, scalar_b, rgb_scaler[i][2], rgb_scaler[i+1][2], value)
            b = interpolate_value(scalar_a, scalar_b, rgb_scaler[i][3], rgb_scaler[i+1][3], value)
            return np.array([r, g, b])
    # Handle last point
    if value == rgb_scaler[n-1][0]:
        return np.array([rgb_scaler[n-1][1], rgb_scaler[n-1][2], rgb_scaler[n-1][3]])
    return np.array([0.0, 0.0, 0.0])

def interpolate_opacity(value, opacity_scaler):
    """Interpolate opacity from scalar value using opacity_scaler table."""
    n = len(opacity_scaler)
    for i in range(n - 1):
        scalar_a = opacity_scaler[i][0]
        scalar_b = opacity_scaler[i+1][0]
        if value == scalar_a:
            return opacity_scaler[i][1]
        if scalar_a < value < scalar_b:
            return interpolate_value(scalar_a, scalar_b, opacity_scaler[i][1], opacity_scaler[i+1][1], value)
    if value == opacity_scaler[n-1][0]:
        return opacity_scaler[n-1][1]
    return 0.0
```

## Operating characteristics
*   **Time Complexity:** $O(D \cdot H \cdot W)$ for transfer function application and $O(D \cdot H \cdot W)$ for compositing, where $D, H, W$ are volume dimensions [S1, unofficial].
*   **Memory Complexity:** $O(D \cdot H \cdot W)$ for the intermediate 4D RGBA volume `fres` [S1, unofficial]. This is higher than single-pass ray casting which does not store the full intermediate volume [S1, unofficial].
*   **Strengths:** Simple implementation, interactive control via piecewise linear transfer function [S1, unofficial].
*   **Limitations:** High memory usage due to intermediate volume storage; two-pass approach is less efficient than single-pass ray casting; alpha inversion in final output is non-standard [S1, unofficial].
*   **When to use:** Educational purposes or simple interactive demos where memory is not a constraint [S1, unofficial].
*   **When not to use:** Large volumes or production rendering where memory efficiency and performance are critical [S1, unofficial].

## Background
Originated from a Python-based educational demo by Dakai Zhou, aiming to understand the ray casting algorithm from scratch without image processing packages [S1, unofficial]. It uses DICOM images as input, though CT images are recommended over MR images for better volume rendering results [S1, unofficial]. The method is implemented in `DirectVolRendering.py` and `InteractiveDirectVolRendering.py` [S1, unofficial].
