# Linear Opacity Interpolation

Also called: pokrytie

## Overview
Linear Opacity Interpolation maps scalar volume data values to opacity ($\alpha$) using linear interpolation between two threshold values [S1, unofficial]. It solves the problem of defining visibility for specific intensity ranges by creating a smooth transition between transparent and opaque states. It sets itself apart from its siblings by using simple linear interpolation between two thresholds, whereas [Piecewise Function Scalar Opacity Transfer](12435-piecewise-function-scalar-opacity-transfer.md) supports arbitrary piecewise definitions and [Piecewise Density Approximation for Reparameterized Sampling](1139-piecewise-density-approximation-for-reparameterized-sampling.md) focuses on analytical inversion for reparameterized sampling.

## How it works
**Inputs and Outputs:**
- Input: scalar volume value $i$ (typically UINT16).
- Parameters: lower threshold $oa$ (UINT16), upper threshold $ob$ (UINT16), opacity at lower threshold $foa$ (float), opacity at upper threshold $fob$ (float).
- Output: opacity $\alpha$ (float).

**Data Structures:**
No complex data structures are required. The method relies on four scalar parameters defining the linear segment.

**Steps:**
1. Check if the input value $i$ falls outside the defined range $[oa, ob]$.
2. If $i < oa$ or $i > ob$, return $0.0$.
3. Otherwise, compute the interpolated opacity using linear interpolation between $foa$ and $fob$ over the range $[oa, ob]$.

**Formula:**
$$
\alpha = \begin{cases} 
0.0 & i < oa \lor i > ob \\
foa + (fob - foa) \frac{i - oa}{ob - oa} & \text{otherwise}
\end{cases}
$$

**Parameters:**
- $oa, ob$: Lower and upper thresholds. Type: UINT16.
- $foa, fob$: Opacity values at the thresholds. Type: float. Typical range: $[0.0, 1.0]$ [S1, unofficial].

**Pseudocode:**
```python
def linear_opacity_interpolation(i: int, oa: int, ob: int, foa: float, fob: float) -> float:
    """
    Compute opacity for a scalar volume value i using linear interpolation.
    
    Args:
        i: Scalar volume value (UINT16 equivalent).
        oa: Lower threshold (UINT16).
        ob: Upper threshold (UINT16).
        foa: Opacity at oa (float).
        fob: Opacity at ob (float).
        
    Returns:
        Opacity alpha (float).
    """
    # Guard against invalid ranges where oa >= ob
    if oa >= ob:
        return 0.0
        
    # Step 1: Check if input is outside the defined range
    if i < oa or i > ob:
        return 0.0
    
    # Step 2: Linear interpolation
    # alpha = foa + (fob - foa) * (i - oa) / (ob - oa)
    alpha = foa + (fob - foa) * (i - oa) / (ob - oa)
    
    return alpha
```

**Edge Cases and Pitfalls:**
- If $oa \ge ob$, the denominator becomes zero or negative. The implementation should handle this, typically by returning 0.0 or clamping [G].
- Precision issues may arise if $i$ is very close to $oa$ or $ob$ due to floating-point representation, though standard linear interpolation is generally stable.
- Values outside the range $[oa, ob]$ are clamped to 0.0 opacity, effectively making them transparent.

## Operating characteristics
- **Time Complexity:** $O(1)$ per sample. The calculation involves a few comparisons and basic arithmetic operations.
- **Memory Complexity:** $O(1)$. Only four scalar parameters are stored.
- **Strengths:** Simple to implement, computationally inexpensive, easy to understand and tune.
- **Limitations:** Limited flexibility compared to piecewise or curve-based methods. Cannot model complex opacity distributions with a single segment.
- **When to use:** When a simple, smooth transition between transparent and opaque states is sufficient.
- **When not to use:** When complex opacity distributions or non-linear transitions are required.

## Background
The method is described in the context of parallel volume rendering implementations, specifically in the `besnik/parallel-volume-rendering` repository [S1, unofficial]. It is a fundamental technique in direct volume ray casting, forming the basis for more complex transfer function mappings.
