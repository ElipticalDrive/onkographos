# Linear Opacity Interpolation

Also called: pokrytie

## Overview
Linear Opacity Interpolation maps scalar volume data values to opacity using linear interpolation between two threshold values [S1, unofficial]. It serves as the foundational opacity mapping primitive in piecewise linear transfer functions, providing a simple, computationally efficient way to define opacity ramps [S1, unofficial]. Unlike its sibling [Piecewise Linear Opacity Mapping with Gradient Scaling](1335-piecewise-linear-opacity-mapping-with-gradient-scaling.md), this method operates solely on scalar values without incorporating gradient magnitude scaling, making it suitable for homogeneous regions or when boundary emphasis is handled separately [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: scalar data value $i$ (typically unsigned integer, e.g., `UINT16`).
- Parameters: lower threshold $oa$ (`UINT16`), upper threshold $ob$ (`UINT16`), opacity at lower threshold $foa$ (`float`), opacity at upper threshold $fob$ (`float`). Typical values for $foa, fob$ are in $[0.0, 1.0]$ [S1, unofficial].
- Output: opacity $\alpha$ (`float`) in $[0.0, 1.0]$.

**Data Structures:**
No complex data structures are required. The method uses four scalar parameters: $oa, ob, foa, fob$.

**Steps:**
1. Check if the input value $i$ lies outside the interval $[oa, ob]$.
2. If $i < oa$ or $i > ob$, return $\alpha = 0.0$.
3. Otherwise, compute the linear interpolation between $foa$ and $fob$ over the range $[oa, ob]$ using the formula below.

**Formula:**
$$
\alpha = \begin{cases} 
0.0 & i < oa \lor i > ob \\
foa + (fob - foa) \frac{i - oa}{ob - oa} & \text{otherwise}
\end{cases}
$$

**Pseudocode:**
```python
def linear_opacity_interpolation(i: int, oa: int, ob: int, foa: float, fob: float) -> float:
    """
    Compute opacity alpha for scalar value i using linear interpolation
    between thresholds oa and ob with opacities foa and fob.
    
    Args:
        i: Input scalar data value (UINT16 equivalent)
        oa: Lower threshold (UINT16)
        ob: Upper threshold (UINT16)
        foa: Opacity at lower threshold (float, typically 0.0-1.0)
        fob: Opacity at upper threshold (float, typically 0.0-1.0)
        
    Returns:
        Opacity alpha (float)
    """
    if i < oa or i > ob:
        return 0.0
    
    # Linear interpolation between foa and fob over range [oa, ob]
    # Avoid division by zero if oa == ob (though typically oa < ob)
    if oa == ob:
        return foa
    
    alpha = foa + (fob - foa) * (i - oa) / (ob - oa)
    return alpha
```

**Edge Cases and Pitfalls:**
- If $oa = ob$, the denominator becomes zero. The sources do not specify behavior for this degenerate case [G]. A safe implementation should return $foa$ (or $fob$, which should be equal) to avoid division by zero.
- Input values outside $[oa, ob]$ are clamped to 0.0 opacity, not extrapolated.
- Precision issues may arise if $oa$ and $ob$ are very close, leading to numerical instability in the division.

## Subtopics

### [Bézier Curve Opacity Mapping](8485-b-zier-curve-opacity-mapping.md)
Maps scalar volume data values to opacity using a user-defined Bézier curve, allowing non-linear opacity control across a selected data range. It extends Linear Opacity Interpolation by replacing piecewise linear segments with a smooth parametric curve, enabling complex opacity transitions that linear interpolation cannot achieve.

## Operating characteristics
- **Time Complexity:** $O(1)$ per sample. The method involves a constant number of comparisons and arithmetic operations.
- **Memory Complexity:** $O(1)$. No additional memory is required beyond the four parameters.
- **Strengths:** Extremely fast, simple to implement, and easy to understand. Suitable for real-time applications where computational efficiency is critical.
- **Limitations:** Cannot represent complex, non-linear opacity transitions. Lacks gradient-based boundary enhancement, which may result in less distinct feature boundaries compared to gradient-scaled methods.
- **When to use:** When simple, linear opacity ramps are sufficient, or when gradient scaling is applied separately.
- **When not to use:** When complex opacity transitions or boundary emphasis via gradient scaling is required.

## Background
Linear Opacity Interpolation is a fundamental technique in direct volume rendering, forming the basis of piecewise linear transfer functions. It is implemented in various open-source volume rendering projects, such as the parallel volume rendering codebase by besnik [S1, unofficial]. The method is widely used due to its simplicity and efficiency.
