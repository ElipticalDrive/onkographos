# Linear Opacity Interpolation

Also called: pokrytie

## Overview
Linear Opacity Interpolation maps scalar volume data values to opacity using linear interpolation between two threshold values [S1, unofficial]. It serves as the foundational opacity mapping primitive in piecewise linear transfer functions, providing a simple, computationally efficient way to define opacity transitions over a specific data range [S1, unofficial]. It is distinguished from its sibling [Piecewise Linear Opacity Mapping with Gradient Scaling](1335-piecewise-linear-opacity-mapping-with-gradient-scaling.md) by its exclusive reliance on scalar value thresholds, ignoring gradient information for opacity determination.

## How it works
**Inputs and Outputs:**
- Input: Scalar volume data value $i$ (typically unsigned integer, e.g., `UINT16`).
- Parameters: Lower threshold $o_a$ (`UINT16`), upper threshold $o_b$ (`UINT16`), opacity at lower threshold $f_o_a$ (`float`), opacity at upper threshold $f_o_b$ (`float`).
- Output: Opacity $\alpha$ (`float`, range [0.0, 1.0]).

**Data Structures:**
No complex data structures are required. The method operates on scalar values and four parameter constants.

**Steps:**
1. Check if the input value $i$ is outside the range $[o_a, o_b]$.
2. If $i < o_a$ or $i > o_b$, return opacity $0.0$.
3. If $i$ is within $[o_a, o_b]$, compute the opacity using linear interpolation between $f_o_a$ and $f_o_b$ based on the relative position of $i$ within $[o_a, o_b]$.

**Formula:**
The opacity $\alpha$ is calculated as:
$$
\alpha = \begin{cases} 
0.0 & i < o_a \lor i > o_b \\
f_o_a + (f_o_b - f_o_a) \frac{i - o_a}{o_b - o_a} & \text{otherwise}
\end{cases}
$$

**Parameters:**
- $o_a, o_b$: Lower and upper thresholds. Type: `UINT16`.
- $f_o_a, f_o_b$: Opacity values at thresholds. Type: `float`. Typical range: [0.0, 1.0] [S1, unofficial].

**Edge Cases and Pitfalls:**
- **Division by Zero:** If $o_a = o_b$, the denominator $(o_b - o_a)$ becomes zero. The source code implies a linear interpolation function `linInt` is used, which must handle this case (e.g., by returning $f_o_a$ or handling it as a special case) to avoid NaN or infinity [S1, unofficial].
- **Input Range:** Values outside $[o_a, o_b]$ result in zero opacity. Ensure thresholds are chosen to cover the relevant data range of interest.
- **Precision:** Floating-point precision in the interpolation step should be sufficient for smooth gradients.

**Pseudocode:**
```python
def linear_opacity_interpolation(i: int, oa: int, ob: int, foa: float, fob: float) -> float:
    """
    Maps scalar volume data value i to opacity using linear interpolation.
    
    Args:
        i: Scalar volume data value (UINT16).
        oa: Lower threshold (UINT16).
        ob: Upper threshold (UINT16).
        foa: Opacity at oa (float).
        fob: Opacity at ob (float).
        
    Returns:
        Opacity alpha (float).
    """
    if i < oa or i > ob:
        return 0.0
    
    # Handle potential division by zero if oa == ob
    if oa == ob:
        return foa
    
    # Linear interpolation
    alpha = foa + (fob - foa) * (i - oa) / (ob - oa)
    return alpha
```

### [Bézier Curve Opacity Mapping](8485-b-zier-curve-opacity-mapping.md)
Maps scalar volume data values to opacity using a user-defined Bézier curve, allowing non-linear opacity control across a selected data range. It extends [Linear Opacity Interpolation](7016-linear-opacity-interpolation.md) by replacing piecewise linear segments with a smooth parametric curve, enabling complex opacity transitions that linear interpolation cannot achieve.

## Operating characteristics
- **Time Complexity:** $O(1)$ per voxel/sample. The calculation involves a few comparisons and basic arithmetic operations.
- **Memory Complexity:** $O(1)$ additional memory for parameters.
- **Performance:** Extremely fast due to its simplicity. Suitable for real-time volume rendering where computational efficiency is critical.
- **Strengths:** Simple to implement, fast, easy to understand and tune via two thresholds and two opacity values.
- **Limitations:** Limited expressiveness compared to higher-order curves or gradient-based mappings. Cannot model complex opacity variations within the range $[o_a, o_b]$ other than a linear ramp.
- **When to Use:** When a simple, linear transition in opacity is sufficient for the data range of interest, and performance is a priority.
- **When Not to Use:** When complex, non-linear opacity transitions are required, or when gradient information is needed to enhance features (use [Piecewise Linear Opacity Mapping with Gradient Scaling](1335-piecewise-linear-opacity-mapping-with-gradient-scaling.md) instead).

## Background
Linear Opacity Interpolation is a fundamental technique in direct volume rendering, specifically within the context of transfer function design. It is implemented in various volume rendering systems, including those utilizing parallel processing for performance [S1, unofficial]. The method is often a building block for more complex piecewise linear transfer functions.
