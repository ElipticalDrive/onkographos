# Linear Opacity Interpolation

Also called: pokrytie

## Overview
Linear Opacity Interpolation maps scalar volume data values to opacity using linear interpolation between two threshold values [S1, unofficial]. It sets itself apart from its sibling [Piecewise Linear Mapping and Integration](9000-piecewise-linear-mapping-and-integration.md) by restricting the mapping to a single linear segment defined by a lower and upper threshold, rather than a general piecewise chain [S1, unofficial].

## How it works
**Inputs and Outputs**:
- Input: scalar volume value $i$ (typically `UINT16`).
- Parameters: lower threshold $oa$ (`UINT16`), upper threshold $ob$ (`UINT16`), opacity at lower threshold $foa$ (`float`), opacity at upper threshold $fob$ (`float`).
- Output: opacity $\alpha$ (`float`).

**Data Structures**:
No complex structures; the method operates on scalar values and four parameters.

**Steps**:
1. Check if the input value $i$ is outside the range $[oa, ob]$.
2. If $i < oa$ or $i > ob$, return $0.0$.
3. Otherwise, compute the interpolated opacity using linear interpolation between $(oa, foa)$ and $(ob, fob)$.

**Formula**:
The opacity $\alpha$ is calculated as [S1, unofficial]:
$$
\alpha = \begin{cases} 
0.0 & i < oa \lor i > ob \\
foa + (fob - foa) \frac{i - oa}{ob - oa} & \text{otherwise}
\end{cases}
$$

**Parameters**:
- $oa, ob$: Lower and upper thresholds. Type: `UINT16`.
- $foa, fob$: Opacity values at thresholds. Type: `float`. Typical range: $[0.0, 1.0]$.

**Pseudocode**:
```python
def linear_opacity_interpolation(i: int, oa: int, ob: int, foa: float, fob: float) -> float:
    """
    Computes opacity for a scalar volume value i using linear interpolation
    between thresholds oa and ob.
    
    Args:
        i: Scalar volume value (UINT16 equivalent).
        oa: Lower threshold (UINT16).
        ob: Upper threshold (UINT16).
        foa: Opacity at oa (float).
        fob: Opacity at ob (float).
        
    Returns:
        Opacity alpha (float).
    """
    if i < oa or i > ob:
        return 0.0
    
    # Linear interpolation
    # Note: Division by zero is avoided if oa != ob. 
    # If oa == ob, the range is degenerate; standard behavior is undefined or returns foa/fob.
    # Assuming valid range where oa < ob.
    alpha = foa + (fob - foa) * (i - oa) / (ob - oa)
    return alpha
```

**Edge Cases**:
- If $i$ is outside $[oa, ob]$, opacity is $0.0$ [S1, unofficial].
- If $oa = ob$, the denominator is zero. The source code implies a check `if (i<oa) || (i>ob)` which handles equality if $i=oa=ob$ by entering the else branch, leading to division by zero. In practice, $oa < ob$ is required for this specific formula [S1, unofficial].

## Operating characteristics
- **Time Complexity**: $O(1)$ per voxel/value.
- **Memory Complexity**: $O(1)$ for parameters.
- **Strengths**: Simple, fast, easy to implement.
- **Limitations**: Only supports a single linear transition. Cannot model complex opacity distributions with multiple features or non-linear behaviors.
- **When to use**: When a single feature needs to be highlighted with a linear opacity ramp.
- **When not**: When multiple features or non-linear opacity changes are required.

## Background
Originated in early volume rendering implementations for simple threshold-based visualization. The term "pokrytie" is used in some implementations [S1, unofficial].
