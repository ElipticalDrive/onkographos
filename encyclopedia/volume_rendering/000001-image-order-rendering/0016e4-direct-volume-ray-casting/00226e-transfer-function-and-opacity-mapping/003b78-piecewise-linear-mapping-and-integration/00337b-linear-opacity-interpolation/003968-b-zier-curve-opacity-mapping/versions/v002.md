# Bézier Curve Opacity Mapping

Also called: opacity curve editor, pokrytieKriv

## Overview
Bézier Curve Opacity Mapping maps scalar volume data values to opacity using a user-defined Bézier curve, allowing non-linear opacity control across a selected data range [S1, unofficial]. It extends [Linear Opacity Interpolation](7016-linear-opacity-interpolation.md) by replacing piecewise linear segments with a smooth parametric curve [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A scalar volume data value $i$ (unsigned 16-bit integer, range 0–4095) [S1, unofficial].
*   **Input:** A set of control points defining the Bézier curve, stored in an array `kriv.suradnice[]` with size `kriv.pocet` [S1, unofficial].
*   **Input:** Editor geometry parameters: `edt_left` (x-coordinate of left edge), `edt_top` (y-coordinate of top edge), `edt_sir` (width), `edt_vys` (height) [S1, unofficial].
*   **Output:** Opacity $\alpha \in [0, 1]$ [S1, unofficial].

**Data Structures:**
*   `kriv.pocet`: Integer count of control points [S1, unofficial].
*   `kriv.suradnice[]`: Array of points, where each point has `x` and `y` coordinates representing pixel positions within the editor [S1, unofficial].

**Steps:**
1.  **Validation:** Check if `kriv.pocet > 1`. If not, return $\alpha = 0.0$ [S1, unofficial].
2.  **Normalize Input:** Normalize the input data value $i$ to the range $[0, 1]$ by dividing by 4095.0 [S1, unofficial].
3.  **Normalize Curve Bounds:** Normalize the x-coordinates of the first ($x_0$) and last ($x_{n-1}$) control points to the range $[0, 1]$ relative to the editor width [S1, unofficial].
4.  **Calculate Parameter $t$:** Compute the normalized parameter $t$ along the curve based on the normalized input position [S1, unofficial].
5.  **Boundary Check:** If $\text{norm\_i}$ is outside the range $[\text{norm\_oa}, \text{norm\_ob}]$, return $\alpha = 0.0$ [S1, unofficial].
6.  **Evaluate Curve:** Evaluate the Bézier curve at parameter $t$ using `vratKrivku(t, kriv)`, which returns a point `krivka` with coordinates $(x(t), y(t))$ [S1, unofficial].
7.  **Normalize and Invert Output:** Normalize the y-coordinate of the curve point to the editor height and invert it to map higher visual positions to lower opacity [S1, unofficial].

**Formulas:**
$$ t = \frac{\frac{i}{4095} - \frac{x_0 - L}{W}}{\frac{x_{n-1} - L}{W} - \frac{x_0 - L}{W}} $$
$$ \alpha = 1 - \frac{y(t) - T}{H} $$
where $i$ is the input value, $x_0$ and $x_{n-1}$ are the first and last control point x-coordinates, $L$ and $W$ are the editor left coordinate and width, $T$ and $H$ are the editor top coordinate and height, and $y(t)$ is the curve y-value at parameter $t$ [S1, unofficial].

**Pseudocode:**
```python
def bezier_opacity_mapping(i, kriv, edt_left, edt_top, edt_sir, edt_vys):
    """
    Calculate opacity for input value i using a Bézier curve.
    Args:
        i: Input scalar value (0-4095).
        kriv: Object containing control points.
              kriv.pocet: Number of control points.
              kriv.suradnice: List of points with .x and .y attributes.
        edt_left: Editor left x-coordinate.
        edt_top: Editor top y-coordinate.
        edt_sir: Editor width.
        edt_vys: Editor height.
    Returns:
        float: Opacity alpha in [0.0, 1.0].
    """
    # Step 1: Validation
    if kriv.pocet <= 1:
        return 0.0
    
    # Step 2: Normalize input
    norm_i = i / 4095.0
    
    # Step 3: Normalize curve endpoints
    x0 = kriv.suradnice[0].x
    x_last = kriv.suradnice[kriv.pocet - 1].x
    
    norm_oa = (x0 - edt_left) / edt_sir
    norm_ob = (x_last - edt_left) / edt_sir
    
    # Guard against division by zero if endpoints share the same x-coordinate [G]
    if norm_ob == norm_oa:
        return 0.0
    
    # Step 4: Calculate parameter t
    t = (norm_i - norm_oa) / (norm_ob - norm_oa)
    
    # Step 5: Boundary check
    if norm_i < norm_oa or norm_i > norm_ob:
        return 0.0
    
    # Step 6: Evaluate Bézier curve
    # vratKrivku evaluates the Bézier curve defined by kriv.suradnice at parameter t [S1, unofficial]
    krivka = vratKrivku(t, kriv)
    y_t = krivka.y
    
    # Step 7: Normalize y and invert
    alpha = 1.0 - (y_t - edt_top) / edt_vys
    
    return alpha

def vratKrivku(t, kriv):
    """
    Evaluate a Bézier curve at parameter t using De Casteljau's algorithm [G].
    """
    n = kriv.pocet
    pts = [Point(p.x, p.y) for p in kriv.suradnice]
    
    for r in range(1, n):
        for i in range(n - r):
            pts[i].x = (1 - t) * pts[i].x + t * pts[i + 1].x
            pts[i].y = (1 - t) * pts[i].y + t * pts[i + 1].y
            
    return pts[0]

class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y
```

**Parameters:**
*   `i`: Input data value (UINT16, range 0–4095) [S1, unofficial].
*   `edt_sir`/`edt_vys`: Editor width and height in pixels [S1, unofficial].
*   `edt_left`/`edt_top`: Editor top-left coordinates in pixels [S1, unofficial].
*   `kriv.suradnice[]`: Array of control points defining the curve [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Division by Zero:** If `norm_ob == norm_oa` (i.e., the first and last control points have the same x-coordinate), the denominator in the calculation of $t$ becomes zero [S1, unofficial].
*   **Out-of-Bounds Input:** If the input value $i$ maps to a `norm_i` outside the range `[norm_oa, norm_ob]`, the opacity is clamped to 0.0 [S1, unofficial].
*   **Precision:** The input value $i$ is divided by 4095.0, implying a 12-bit data range [S1, unofficial].
