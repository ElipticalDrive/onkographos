# Alpha Discard

Also called: Alpha-to-Weight Computation with Alpha Mask, Transparency Handling

## Overview
Alpha Discard is a fragment-level optimization in direct volume ray casting and voxel rendering that discards fragments with alpha values below a specified threshold. It solves the problem of rendering transparency efficiently by allowing the renderer to skip expensive blending operations for nearly transparent pixels, thereby enabling the rendering engine to pass through to opaque geometry behind them. It is distinct from Alpha Blend, which computes actual transparency with proper accumulation but suffers from sorting and performance limitations when multiple transparent surfaces are involved [S2].

## How it works
**Inputs and Outputs:**
- **Input:** Fragment color (specifically the alpha channel, $a$), optional alpha map texture, threshold parameter $T$.
- **Output:** Fragment is either discarded (not written to the framebuffer) or passed to the next rendering stage.

**Data Structures:**
- **Alpha Map:** A 2D texture (e.g., `m_AlphaMap`) where the red channel (`.r`) stores the alpha value for each texture coordinate.
- **Threshold:** A scalar value $m\_AlphaDiscardThreshold$ (float).

**Steps:**
1. **Calculate Base Alpha:** Compute the initial alpha value by multiplying the diffuse sum's alpha by the diffuse color's alpha.
   $$ a = \text{DiffuseSum}.a \times \text{diffuseColor}.a $$
2. **Apply Alpha Map (Optional):** If an alpha map is defined, sample it using the new texture coordinates and multiply the result into the current alpha.
   $$ a = a \times \text{texture2D}(m\_AlphaMap, \text{newTexCoord}).r $$
3. **Discard Check:** If the discard flag is enabled and the computed alpha is strictly less than the threshold, discard the fragment.
   $$ \text{if } a < m\_AlphaDiscardThreshold \text{ then discard} $$

**Parameters:**
- **$m\_AlphaDiscardThreshold$:** The threshold value for alpha discard. Fragments with alpha below this value are culled. [S1, unofficial]
- **DISCARD_ALPHA:** A compile-time or runtime flag that enables the discard logic. [S1, unofficial]
- **ALPHAMAP:** A flag indicating the presence of an alpha map texture. [S1, unofficial]

**Edge Cases and Pitfalls:**
- **Precision:** Floating-point precision errors in alpha calculation may cause fragments to be incorrectly discarded or retained near the threshold boundary.
- **Ordering:** Alpha discard is typically used in opaque passes or specific transparency handling modes. It does not handle depth sorting for multiple transparent surfaces, which can lead to visual artifacts if used in place of proper alpha blending for complex overlapping transparent geometry [S2].
- **Texture Atlas Setup:** When using a texture atlas, a typical setup requires three distinct materials: opaque, alpha clip (using discard), and transparent (using blend) [S2].

**Pseudocode:**
```python
def compute_alpha_discard(diffuse_sum_alpha, diffuse_color_alpha, alpha_map, new_tex_coord, alpha_discard_threshold, discard_alpha_enabled, alpha_map_defined):
    # Step 1: Calculate base alpha
    alpha = diffuse_sum_alpha * diffuse_color_alpha
    
    # Step 2: Apply alpha map if defined
    if alpha_map_defined:
        alpha_map_sample = sample_texture_2d(alpha_map, new_tex_coord)
        alpha = alpha * alpha_map_sample.r
    
    # Step 3: Discard if below threshold
    if discard_alpha_enabled:
        if alpha < alpha_discard_threshold:
            return "DISCARD"
    
    return alpha
```

## Subtopics

### Alpha Clip
A rendering technique that discards transparent pixels to allow rendering through the opaque pass. It avoids typical issues with transparent surfaces but does not provide true visual transparency. [S2]

### Alpha Blend
A technique that performs actual transparency with proper blending. It has limitations when multiple transparent surfaces are rendered behind each other due to sorting requirements. [S2]

### Transparency Index
A property in voxel models (e.g., `VoxelBlockyModel`) that tunes occlusion between faces. Faces with the same index may be culled, while different indices may remain visible, allowing visibility through layers like leaves behind glass. [S2]

### Culls Neighbors
A property in voxel models (default true) that prevents rendering of neighboring voxel sides. Disabling it renders inner voxel sides, making foliage look denser but potentially less hollow. [S2]

## Operating characteristics
- **Time Complexity:** $O(1)$ per fragment for the discard check.
- **Memory Complexity:** $O(1)$ additional memory for threshold and flags.
- **Performance:** Significantly faster than alpha blending for scenes with many nearly transparent surfaces, as it avoids blending operations and depth sorting.
- **Strengths:** Efficient culling of transparent fragments; simple implementation; works well with texture atlases.
- **Limitations:** Does not support true visual transparency; requires careful material setup (opaque, alpha clip, transparent); may cause visual artifacts if used incorrectly for complex overlapping transparent geometry.
- **When to Use:** When performance is critical and true visual transparency is not required (e.g., foliage, glass with simple occlusion).
- **When Not to Use:** When accurate visual transparency with multiple overlapping transparent surfaces is needed.

## Background
Alpha Discard is a common technique in computer graphics, particularly in voxel-based rendering and real-time applications where performance is paramount. It is often used in conjunction with alpha clipping to handle transparency in a way that is compatible with opaque rendering passes. The technique is widely supported in modern graphics APIs and game engines.
