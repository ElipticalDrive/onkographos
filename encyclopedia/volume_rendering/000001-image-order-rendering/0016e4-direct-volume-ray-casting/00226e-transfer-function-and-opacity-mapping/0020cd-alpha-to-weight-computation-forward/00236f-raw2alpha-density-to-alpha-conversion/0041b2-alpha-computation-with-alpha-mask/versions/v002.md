# Alpha Computation with Alpha Mask

Also called: Masked Polygons and α_bar, α_bar Occlusion Weighing

## Overview
Alpha Computation with Alpha Mask corrects over-estimation of occlusion when rendering planar surfaces with complex contours, such as foliage or fences, by weighing the occlusion contribution with the average alpha value $\bar{\alpha}$ of the surface texture [S2, unofficial]. It differs from standard per-pixel alpha blending by applying a scalar occlusion weight to the entire surface's ambient occlusion volume contribution rather than performing per-sample alpha testing during integration [S2, unofficial].

## How it works
### Inputs and Outputs
**Inputs:**
- Surface geometry tagged with an alpha mask [S2, unofficial].
- Integration length $L$ [S1, unofficial].
- Density features or sigma features [S1, unofficial].
- Alpha texture for sampling [S2, unofficial].

**Outputs:**
- Corrected alpha value $\alpha$ [S1, unofficial].
- Average alpha $\bar{\alpha}$ for occlusion weighting [S2, unofficial].

### Data Structures
- **Alpha Mask:** Boolean array indicating valid sample locations where sampled alpha $> 0$ [S1, unofficial].
- **Sigma Tensor:** Tensor storing extinction coefficients $\sigma$, initialized to zeros [S1, unofficial].

### Steps
1. **Mask Generation:** If `self.alphaMask` exists, sample alpha values at 3D locations (`xyz_locs`) and create a boolean mask `alpha_mask` where sampled alpha $> 0$ [S1, unofficial].
2. **Initialization:** Initialize the sigma tensor with zeros [S1, unofficial].
3. **Feature Computation:** If `alpha_mask.any()` is true, normalize coordinates and compute density features [S1, unofficial].
4. **Density Conversion:** Convert density features to sigma ($\sigma$): if `component_wise_feature2density` is true, use the feature values directly as $\sigma$; otherwise, apply a density conversion function [S1, unofficial].
5. **Assignment:** Assign the computed valid sigma values to the sigma tensor at indices specified by `alpha_mask` [S1, unofficial].
6. **Alpha Calculation:** Compute alpha from sigma and length using the Beer-Lambert law:
   $$ \alpha = 1 - \exp(-\sigma \cdot L) $$
   [S1, unofficial]
7. **Occlusion Weighting (Geometric Context):** For surfaces tagged with a mask, determine $\bar{\alpha}$ efficiently by fetching from a low MIP level of the alpha texture in the geometry shader [S2, unofficial]. Weigh the surface's occlusion contribution by $\bar{\alpha}$ [S2, unofficial].

### Formulas
- **Alpha from Sigma:**
  $$ \alpha = 1 - e^{-\sigma L} $$
  Where $\sigma$ is the extinction coefficient and $L$ is the integration length [S1, unofficial].
- **Occlusion Weight:**
  The occlusion contribution is scaled by $\bar{\alpha}$, the average alpha value of the texture [S2, unofficial].

### Parameters
- **MIP Level:** A low MIP level of the alpha texture is used to compute $\bar{\alpha}$ efficiently [S2, unofficial].
- **Threshold:** Alpha values are considered valid if $> 0$ [S1, unofficial].

### Edge Cases and Pitfalls
- **Positional Variation:** Using the full alpha-channel for positional variation in occlusion from a single polygon is not efficient without tessellation [S2, unofficial]. The analytic solution assumes constant opacity over the integration domain; making it piecewise constant requires multiple integrals, which is equivalent to tessellating the polygon [S2, unofficial].
- **Over-estimation:** Without masking, the underlying geometry of alpha-masked surfaces causes ambient occlusion volumes to over-estimate occlusion [S2, unofficial].

### Pseudocode
```python
def compute_alpha_with_mask(density_features, length, alpha_mask, is_component_wise=True):
    """
    Compute alpha from density features using an alpha mask.
    Note: The geometric averaging of alpha for occlusion weighting is handled
    separately in the geometry shader as per [S2, unofficial].
    """
    import math

    # Step 1: Initialize sigma tensor
    sigma_tensor = [0.0] * len(density_features)

    # Step 2: Determine valid locations
    if not any(alpha_mask):
        return sigma_tensor

    # Step 3 & 4: Convert features to sigma and assign
    valid_sigma = []
    for i in range(len(density_features)):
        if alpha_mask[i]:
            if is_component_wise:
                valid_sigma.append(density_features[i])
            else:
                # Apply feature2density function
                # Not given in the sources.
                valid_sigma.append(density_features[i])

    for i in range(len(density_features)):
        if alpha_mask[i]:
            sigma_tensor[i] = valid_sigma.pop(0)

    # Step 5: Compute alpha
    alpha = [1.0 - math.exp(-sigma_tensor[i] * length) for i in range(len(sigma_tensor))]

    return alpha

def get_average_alpha_for_occlusion(alpha_texture, mip_level=0):
    """
    Efficiently compute average alpha for occlusion weighting.
    Implemented in geometry shader in practice [S2, unofficial].
    """
    # Fetch from low MIP level
    # This is a conceptual representation; actual implementation uses GPU texture sampling
    # Not given in the sources.
    mip_texture = alpha_texture
    avg_alpha = sum(mip_texture) / len(mip_texture)
    return avg_alpha
```

## Subtopics

### Ambient Occlusion Volumes
A broader technique for computing ambient occlusion using volume primitives, which uses alpha masking to correct for over-occlusion of planar surfaces [S2, unofficial].

### Neural Radiance Fields (NeRF) Density Conversion
The process of converting density features to sigma and then to alpha, often involving alpha masking for valid regions [S1, unofficial].

## Operating characteristics
- **Strengths:** Efficiently corrects over-estimation of occlusion for complex planar surfaces without requiring tessellation [S2, unofficial].
- **Limitations:** Cannot efficiently handle positional variation in occlusion within a single polygon without tessellation [S2, unofficial].

## Background
The method was introduced in the context of Ambient Occlusion Volumes (AOV) by McGuire in 2010 [S2, unofficial]. It addresses the issue where artists model planar surfaces with complex contours (e.g., foliage, fences) as alpha-masked polygons, leading to incorrect occlusion estimates if the underlying geometry is treated as fully opaque [S2, unofficial]. The technique leverages the efficiency of geometry shaders and low MIP level texture fetches to compute average alpha values [S2, unofficial].
