# Layer Separation Heuristic

Also called: Feature Peeling

## Overview
The Layer Separation Heuristic determines optimal split points along a ray in multi-layer volume rendering to separate high-quality raycasting from lower-cost image warping [S1]. It solves the problem of identifying the main visual effect of light attenuation, which frequently occurs in the middle of a ray interval rather than at entry or exit [S1]. Unlike simple depth-based splitting, this heuristic identifies main visual effects along the ray, preserving depth cues and providing better visual approximation for transparent volumes [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A ray sampled at discrete steps through the volume, where each sample provides voxel opacity $\alpha_i$ and accumulated transmittance $T_i$ [S1].
*   **Output:** A set of depth values defining layer separation points along the ray [S1].

**Data Structures:**
The method operates on a 1D array of sample values along the ray, requiring no complex spatial data structures beyond the standard ray marching buffer [G].

**Steps:**
1.  **Evaluate Criteria:** For each sample point $i$ along the ray, calculate a score using either the maximum opacity criterion ($\alpha_i$) or the maximum color impact criterion ($C_i = \alpha_i \times T_i$) [S1].
2.  **Identify Local Maxima:** Find local maxima in the score sequence, where a point $i$ is a local maximum if its score is greater than or equal to its immediate neighbors [S1].
3.  **Resolve Discrete Spans:** If a local maximum spans several consecutive sample points, select the median index of these points as the separation depth [S1].
4.  **Select Layers:** Choose the top $N$ separation points based on their scores, with the Maximum Color Impact method generally preferred for slight visual quality advantages [S1].

**Formulas:**
*   **Color Impact:**
    $$ C_i = \alpha_i \cdot T_i $$
    Where:
    *   $\alpha_i$ is the opacity of the voxel at sample $i$ [S1].
    *   $T_i$ is the transmittance (remaining opacity along the ray segment) from the camera to sample $i$ [S1].

**Parameters:**
*   **Number of Layers ($N$):** A fixed integer determined in advance [S1]. Evaluations tested layer counts from 2 to 9 [S1].
*   **Criterion Selection:** Binary choice between "Max Opacity" and "Max Color Impact" [S1].

**Pitfalls:**
*   **Fixed Layer Count:** Layers must be allocated in advance [S1]. If the heuristic is overly sensitive, it may allocate too many layers to features close to the camera, leaving distant features underrepresented [S1].
*   **Heuristic Failure:** The heuristic is fixed and cannot adapt to dynamic scene complexity; insufficient layers or poor distribution lead to visual artifacts [S1].
*   **Depth Cues:** Simple entry or exit depth choices fail to capture main light attenuation effects occurring in the middle of the ray interval [S1].

**Pseudocode:**
```python
def find_layer_separation(rays, num_layers, criterion="color_impact"):
    """
    Finds layer separation points for a batch of rays.
    rays: List of Ray objects, each containing a list of sample points.
    num_layers: Integer, number of layers to separate.
    criterion: String, "opacity" or "color_impact".
    Returns: List of lists, where each inner list contains depth values for that ray.
    """
    separation_points = []
    
    for ray in rays:
        points = ray.samples
        if not points:
            separation_points.append([])
            continue
            
        scores = []
        for i, point in enumerate(points):
            alpha = point.opacity
            T_i = point.accumulated_transmittance  # Transmittance from camera to this point [S1]
            
            if criterion == "color_impact":
                score = alpha * T_i
            else:  # maximum_opacity
                score = alpha
            scores.append((score, point.depth, i))
            
        # Find local maxima with proper boundary handling [G]
        local_maxima = []
        for i in range(len(scores)):
            is_max = True
            if i > 0 and scores[i][0] < scores[i-1][0]:
                is_max = False
            if i < len(scores) - 1 and scores[i][0] < scores[i+1][0]:
                is_max = False
            if is_max:
                local_maxima.append(scores[i])
                
        # Resolve plateaus: if consecutive points share the max score, pick median index [S1]
        resolved_maxima = []
        if local_maxima:
            current_group = [local_maxima[0]]
            for j in range(1, len(local_maxima)):
                if local_maxima[j][2] == current_group[-1][2] + 1:
                    current_group.append(local_maxima[j])
                else:
                    median_idx = current_group[len(current_group)//2][2]
                    resolved_maxima.append((max(current_group, key=lambda x: x[0])[0], 
                                           next(p.depth for p in points if p.index == median_idx), 
                                           median_idx))
                    current_group = [local_maxima[j]]
            median_idx = current_group[len(current_group)//2][2]
            resolved_maxima.append((max(current_group, key=lambda x: x[0])[0], 
                                   next(p.depth for p in points if p.index == median_idx), 
                                   median_idx))
            
        # Select top N layers based on score [S1]
        resolved_maxima.sort(key=lambda x: x[0], reverse=True)
        selected = resolved_maxima[:num_layers]
        
        depths = [m[1] for m in selected]
        separation_points.append(depths)
        
    return separation_points
```

## Subtopics

### [Layered Image Warping](11344-layered-image-warping.md)
Groups volume elements by distance and opacity to ensure consistent shading, overcoming single-image warping limitations.

### [Distribution by Depth Layer](11346-distribution-by-depth-layer.md)
Assigns high-quality raycasting to close layers and warping to distant ones, exploiting depth proximity for quality allocation.

## Operating characteristics
*   **Performance:** Enables multi-frame rate rendering by allowing high-quality raycasting for a subset of layers while warping the rest [S1]. Layer images can be transferred separately to the fast node as soon as completed, reducing latency [S1].
*   **Strengths:** Preserves depth cues better than single surface approaches; outperforms single layered image warps for transparent transfer functions (e.g., MANIX dataset) [S1].
*   **Limitations:** Visual quality suffers if layers are not distributed well (e.g., too many close to camera); fixed number of layers limits adaptability; quality gain is less significant for opaque transfer functions revealing bones (e.g., VIX dataset) [S1].
*   **When to Use:** Transparent volumes where depth cues are critical and view-dependent lighting is needed [S1].
*   **When Not to Use:** Opaque volumes with simple structures where the quality difference is negligible [S1].
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.

## Background
The method was introduced in the context of Multi-Frame Rate Volume Rendering by S. Hauswiesner, D. Kalkofen, and D. Schmalstieg [S1]. It addresses the limitations of single-layer image warping by separating volume layers based on visual impact rather than uniform depth intervals [S1]. The approach was evaluated on datasets such as MANIX (head CT) and VIX (foot) [S1].
