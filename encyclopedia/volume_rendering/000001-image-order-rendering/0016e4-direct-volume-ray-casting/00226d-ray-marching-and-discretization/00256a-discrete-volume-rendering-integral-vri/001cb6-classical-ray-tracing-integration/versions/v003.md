# Classical Ray Tracing Integration

Also called: Kajiya and Von Herzen

## Overview
Classical Ray Tracing Integration is a volume rendering technique that computes pixel color by combining background transmission (attenuated by absorption) and uniform in-scattering [S2, S5]. It solves the problem of rendering volumetric objects with defined boundaries or integrating geometric visibility directly into volume pipelines [S1, S4]. Unlike standard direct volume ray casting which samples uniformly along the entire ray, this method explicitly calculates entry and exit points to limit sampling to the volume interior and applies Beer's law for transmission [S1, S2]. It is distinguished from [Alpha Compositing Ray Casting](922-alpha-compositing-ray-casting.md) by its handling of homogeneous spheres via analytical integration, and from [Single Scattering Volume Rendering with Ray Marching](1532-single-scattering-volume-rendering-with-ray-marching.md) by its assumption of uniform scattering color [S1, S2].

## How it works
The method operates in two primary modes: analytical integration for homogeneous spheres and ray marching with shading heuristics for general volume data [S1, S2]. Both modes rely on the volume rendering integral discretized into a summation over sample points along a ray [S4].

### Inputs and Outputs
*   **Inputs**: Camera ray (origin $\bar{o}$, direction $\bar{d}$), volume data (3D texture or sphere parameters), transfer function $TF$, shading parameters (absorption coefficient $\sigma_a$, scatter color $C_{scatter}$, shading mode) [S1, S2].
*   **Outputs**: Final pixel color $C_{final}$ and accumulated opacity $\alpha_{final}$ [S1, S2].

### Data Structures
1.  **Sphere Object**:
    *   `center`: `vec3` (e.g., $[0, 0, -4]$) [S1].
    *   `radius`: `float` (e.g., $1.0$) [S1].
    *   `sigma_a`: `float` (absorption coefficient, e.g., $0.1$) [S1].
    *   `scatter`: `vec3` (uniform scatter color, e.g., $[0.8, 0.1, 0.5]$) [S1].
2.  **Volume Context** (for marching mode):
    *   `volume`: 3D texture or grid [S2].
    *   `tfn`: Transfer function mapping scalar value to $(C, \alpha)$ [S2].
    *   `params`: Shading mode (`GRADIENT_SHADING` or `SINGLE_SHADE_HEURISTIC`), `shadingScale`, `gradientStep`, lighting parameters [S2].

### Algorithm Steps

#### Mode 1: Analytical Integration for Homogeneous Spheres
This mode assumes a homogeneous sphere with uniform scattering and absorption [S1].

1.  **Intersection Test**: Compute parametric distances $t_0$ and $t_1$ where the ray enters and leaves the sphere. If no intersection, return `background_color` [S1, S2].
2.  **Distance Calculation**: Compute the distance traveled through the sphere. While geometrically $\|\bar{p}_1 - \bar{p}_2\|$, it is computationally redundant; use $t_1 - t_0$ directly [S1, S2].
3.  **Transmission**: Apply Beer's law to compute the transmission factor $T$:
    $$ T = e^{-\sigma_a \cdot (t_1 - t_0)} $$
    where $\sigma_a$ is the absorption coefficient [S1, S2].
4.  **Color Composition**: Compute the final color as the sum of the attenuated background and the uniform scatter:
    $$ C_{final} = C_{background} \cdot T + C_{scatter} \cdot (1 - T) $$
    [S1, S2].

#### Mode 2: Ray Marching with Shading Heuristics
This mode samples a general volume, supporting two shading strategies [S2].

1.  **Initialization**:
    *   Initialize `alpha = 0`, `color = 0` [S2, S3].
    *   For `SINGLE_SHADE_HEURISTIC`: Initialize `highestOrg = 0`, `highestColor = 0`, `highestAlpha = 0` [S2, S3].
2.  **Intersection Check**: If the ray intersects the volume bounds $[t_{start}, t_{end}]$, proceed. Otherwise, return background [S2, S3].
3.  **Jitter**: Generate a random jitter value $j \in [0, 1)$ to offset the first sample position along the ray direction [S2, S3].
4.  **Ray Marching Loop**: Iterate $t$ from $t_{start}$ to $t_{end}$ with step size `marchingStep`.
    *   **Position**: Calculate position $\bar{p} = \bar{o} + t \cdot \bar{d}$ [S2, S3].
    *   **Sample**: Get scalar value $d$ using trilinear interpolation [S1, S5].
    *   **Transfer Function**: Map $d$ to sample color $C_s$ and opacity $\alpha_s$ [S2, S5].
    *   **Opacity Correction**: Apply opacity correction based on step size to ensure slice-count invariance [S2, S3].
    *   **Gradient Calculation**: Compute gradient $\bar{N}_o = -\nabla d$ using a central difference operator with `gradientStep` [S1, S2, S3]. Transform to world space $\bar{N}_w$ [S2, S3].
    *   **Transmittance**: Calculate current transmittance $tr = 1 - \alpha$ [S2, S3].
    *   **Shading Mode**:
        *   **If `GRADIENT_SHADING`**: Transform ray direction to world space. Compute shaded color $C_{shade}$ using lighting model (ambient + directional) with normal $\bar{N}_w$ [S2, S3]. Blend sample color: $C_s = \text{lerp}(\text{shadingScale}, C_s, C_{shade})$ [S2, S3].
        *   **If `SINGLE_SHADE_HEURISTIC`**: Check if current sample density is highest: if $\alpha_s \cdot (1 - \alpha) > \text{highestAlpha}$, update `highestOrg`, `highestColor`, and `highestAlpha` [S2, S3]. Use unshaded $C_s$ for accumulation [S2, S3].
    *   **Accumulation**:
        *   Update color: $C_{new} = C_{old} + (1 - \alpha_{old}) \cdot C_s \cdot \alpha_s$ [S2, S3].
        *   Update alpha: $\alpha_{new} = \alpha_{old} + (1 - \alpha_{old}) \cdot \alpha_s$ [S2, S3].
    *   **Termination**: If $\alpha \ge 0.99$ (nearly one), break loop [S2, S3].
5.  **Final Shading (Heuristic Only)**:
    *   If `highestAlpha > 0`, compute shadow ray transmittance $T_{shadow}$ from `highestOrg` to light direction [S2, S3].
    *   Compute final color:
        $$ C_{final} = \text{lerp}(C_{accumulated}, C_{highest} \cdot \alpha_{highest} \cdot T_{shadow}, \text{shadingScale}) $$
        [S2, S3].
6.  **Gamma Correction**: Apply gamma 2.2 correction to the final color [S2, S5].

### Pseudocode

```python
import math
import random

def classical_ray_tracing_integration(ray_origin, ray_direction, sphere, background_color, volume=None, params=None):
    """
    Renders a pixel using classical ray tracing integration.
    Supports homogeneous spheres (analytical) and general volumes (marching).
    """
    def lerp(a, b, t):
        return a + t * (b - a)

    def vec3_add(a, b):
        return (a[0] + b[0], a[1] + b[1], a[2] + b[2])

    def vec3_mul(a, b):
        return (a[0] * b[0], a[1] * b[1], a[2] * b[2])

    def vec3_scale(v, s):
        return (v[0] * s, v[1] * s, v[2] * s)

    def vec3_pow(v, p):
        return (v[0] ** p, v[1] ** p, v[2] ** p)

    # --- Mode 1: Homogeneous Sphere (Analytical) ---
    if sphere is not None and volume is None:
        t0, t1 = sphere.intersect(ray_origin, ray_direction)
        if t0 is None:
            return background_color

        distance = t1 - t0
        transmission = math.exp(-sphere.sigma_a * distance)

        final_color = vec3_add(
            vec3_mul(background_color, (transmission, transmission, transmission)),
            vec3_mul(sphere.scatter, (1.0 - transmission, 1.0 - transmission, 1.0 - transmission))
        )
        return vec3_pow(final_color, 1.0 / 2.2)

    # --- Mode 2: General Volume (Ray Marching) ---
    if volume is not None:
        t_start, t_end = volume.intersect_bounds(ray_origin, ray_direction)
        if t_start is None:
            return background_color

        alpha = 0.0
        color = (0.0, 0.0, 0.0)
        highest_org = (0.0, 0.0, 0.0)
        highest_color = (0.0, 0.0, 0.0)
        highest_alpha = 0.0

        jitter = random.random()
        step_size = params.marchingStep if params else 0.01
        t_curr = t_start + jitter * step_size

        while alpha < 0.99 and t_curr < t_end:
            p = vec3_add(ray_origin, vec3_mul(ray_direction, t_curr))
            scalar = volume.sample_trilinear(p)
            sample_color, sample_alpha = volume.tfn(scalar)

            # Opacity correction for slice-count invariance [G]
            sample_alpha = 1.0 - math.exp(-sample_alpha * step_size)

            grad = volume.sample_gradient(p, scalar, params.gradientStep)
            normal_world = volume.transform_normal(grad)
            transmittance = 1.0 - alpha

            if params.mode == "GRADIENT_SHADING":
                dir_world = volume.transform_vector(ray_direction)
                shaded_color = volume.shade_scivis_light(dir_world, normal_world, sample_color,
                                                         params.mat_gradient_shading,
                                                         params.light_ambient,
                                                         params.light_directional_rgb,
                                                         params.light_directional_dir)
                sample_color = vec3_add(vec3_scale(sample_color, 1.0 - params.shadingScale),
                                        vec3_scale(shaded_color, params.shadingScale))

            elif params.mode == "SINGLE_SHADE_HEURISTIC":
                current_density = transmittance * sample_alpha
                if current_density > highest_alpha:
                    highest_org = p
                    highest_color = sample_color
                    highest_alpha = current_density

            contrib = vec3_mul(sample_color, (transmittance * sample_alpha, transmittance * sample_alpha, transmittance * sample_alpha))
            color = vec3_add(color, contrib)
            alpha += transmittance * sample_alpha

            t_curr += step_size

        if params.mode == "SINGLE_SHADE_HEURISTIC" and highest_alpha > 0.0:
            shadow_transmittance = volume.compute_shadow_transmittance(highest_org, params.light_directional_dir)
            final_shaded_color = vec3_mul(highest_color, (highest_alpha * shadow_transmittance, highest_alpha * shadow_transmittance, highest_alpha * shadow_transmittance))
            color = vec3_add(vec3_scale(color, 1.0 - params.shadingScale),
                             vec3_scale(final_shaded_color, params.shadingScale))

        return vec3_pow(color, 1.0 / 2.2)

    return background_color
```

### Parameters
*   `sigma_a`: Absorption coefficient. Typical value: $0.1$ [S1].
*   `scatter`: Uniform scatter color. Typical value: $[0.8, 0.1, 0.5]$ [S1].
*   `background_color`: Color returned if no intersection. Typical value: $[0.572, 0.772, 0.921]$ [S1].
*   `shadingScale`: Scalar blending unshaded and shaded colors [S2].
*   `gradientStep`: Step size for gradient estimation [S2].
*   `marchingStep`: Step size for ray marching [S2].

### Edge Cases and Pitfalls
*   **Redundant Distance Calculation**: Computing the Euclidean distance between entry and exit points ($\|\bar{p}_1 - \bar{p}_2\|$) is correct but computationally redundant if $t_0$ and $t_1$ are known; use $t_1 - t_0$ [S1, S2].
*   **Uniform Scattering Assumption**: The analytical mode assumes uniform scattering color regardless of position or direction; it does not account for directional lighting or varying scattering properties [S1, S2].
*   **Heuristic Gradient**: In `SINGLE_SHADE_HEURISTIC`, gradients are not accumulated; only the highest density point is stored for deferred shading [S2, S3].
*   **Shadow Ray Cost**: Computing shadow transmittance from the highest density point adds significant cost for the heuristic mode [S2, S3].

## Operating characteristics
*   **Time Complexity**: $O(N)$ where $N$ is the number of samples along the ray [G]. For analytical spheres, it is $O(1)$ per pixel [S1, S2]. For marching, it depends on volume density and step size [S2, S3].
*   **Memory Complexity**: $O(1)$ for analytical mode. $O(V)$ for volume data storage in marching mode [G].
*   **Performance**: Analytical integration is extremely fast and exact for homogeneous spheres [S1, S2]. Ray marching handles complex scalar fields and supports deferred shading heuristics [S2, S3].
*   **Strengths**: Exact solution for homogeneous volumes; integrates geometric visibility; supports shading heuristics for complex data [S1, S2, S3, S4].
*   **Limitations**: Analytical mode is limited to simple shapes; uniform scattering assumption is unrealistic for many volumes; heuristic shading may produce artifacts if the highest density point is not representative [S1, S2].
*   **When to use**: Ideal for rendering simple volumetric objects (e.g., clouds, smoke balls) or when integrating geometric surfaces with volume data [S1, S3]. Avoid for highly anisotropic or spatially varying scattering volumes [S1].

## Background
The method originates from early volume rendering techniques that combined ray tracing with volume data [S1]. The integration of classical ray tracing into volume rendering pipelines was proposed to handle visibility and geometric merging, such as superimposing radiation treatment planning isodose surfaces over CT data [S4]. The heuristic shading approach was developed to balance performance and visual quality in scientific visualization [S2]. Recent applications include integrating ray tracing for interreflections in 3D Gaussian Splatting [S5].
