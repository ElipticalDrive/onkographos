# Classical Ray Tracing Integration

Also called: Analytical Volume Integration for Homogeneous Spheres, Ray Marching Traceray, Ray Tracing Integration for 3DGS, Ray casting with geometry, Ray tracing volume rendering, Ray-Sphere Volume Rendering with Absorption and Uniform Scattering, SciVis Shading

## Overview
Classical Ray Tracing Integration is a volume rendering technique that combines analytical geometric intersection with ray marching to compute pixel color by combining background transmission (attenuated by absorption) and uniform in-scattering [S1, unofficial]. It solves the problem of rendering volumetric objects with defined boundaries (such as spheres) or integrating geometric visibility into volume pipelines, offering a closed-form solution for homogeneous volumes or a deferred shading heuristic for complex scalar fields [S1, S2, unofficial]. Unlike standard direct volume ray casting which samples uniformly along the entire ray, this method explicitly calculates entry and exit points to limit sampling to the volume interior and applies Beer's law for transmission [S1, unofficial]. It is distinguished from [Alpha Compositing Ray Casting](922-alpha-compositing-ray-casting.md) by its handling of homogeneous spheres via analytical integration, and from [Single Scattering Volume Rendering with Ray Marching](1532-single-scattering-volume-rendering-with-ray-marching.md) by its assumption of uniform scattering color [S1, unofficial].

## How it works
The method operates in two primary modes: analytical integration for homogeneous spheres and ray marching with shading heuristics for general volume data. Both modes rely on the volume rendering integral discretized into a summation over sample points along a ray [S5].

### Inputs and Outputs
*   **Inputs**: Camera ray (origin $\bar{o}$, direction $\bar{d}$), volume data (3D texture or sphere parameters), transfer function $TF$, shading parameters (absorption coefficient $\sigma_a$, scatter color $C_{scatter}$, shading mode).
*   **Outputs**: Final pixel color $C_{final}$ and accumulated opacity $\alpha_{final}$.

### Data Structures
1.  **Sphere Object**:
    *   `center`: `vec3` (e.g., $[0, 0, -4]$) [S1, unofficial].
    *   `radius`: `float` (e.g., $1.0$) [S1, unofficial].
    *   `sigma_a`: `float` (absorption coefficient, e.g., $0.1$) [S1, unofficial].
    *   `scatter`: `vec3` (uniform scatter color, e.g., $[0.8, 0.1, 0.5]$) [S1, unofficial].
2.  **Volume Context** (for marching mode):
    *   `volume`: 3D texture or grid.
    *   `tfn`: Transfer function mapping scalar value to $(C, \alpha)$.
    *   `params`: Shading mode (`GRADIENT_SHADING` or `SINGLE_SHADE_HEURISTIC`), `shadingScale`, `gradientStep`, lighting parameters [S2, unofficial].

### Algorithm Steps

#### Mode 1: Analytical Integration for Homogeneous Spheres
This mode assumes a homogeneous sphere with uniform scattering and absorption [S1, unofficial].

1.  **Intersection Test**: Compute parametric distances $t_0$ and $t_1$ where the ray enters and leaves the sphere. If no intersection, return `background_color` [S1, unofficial].
2.  **Distance Calculation**: Compute the distance traveled through the sphere. While geometrically $\|\bar{p}_1 - \bar{p}_2\|$, it is computationally redundant; use $t_1 - t_0$ directly [S1, unofficial].
3.  **Transmission**: Apply Beer's law to compute the transmission factor $T$:
    $$ T = e^{-\sigma_a \cdot (t_1 - t_0)} $$
    where $\sigma_a$ is the absorption coefficient [S1, unofficial].
4.  **Color Composition**: Compute the final color as the sum of the attenuated background and the uniform scatter:
    $$ C_{final} = C_{background} \cdot T + C_{scatter} \cdot (1 - T) $$
    [S1, unofficial].

#### Mode 2: Ray Marching with Shading Heuristics
This mode samples a general volume, supporting two shading strategies [S2, unofficial].

1.  **Initialization**:
    *   Initialize `alpha = 0`, `color = 0`.
    *   For `SINGLE_SHADE_HEURISTIC`: Initialize `highestOrg = 0`, `highestColor = 0`, `highestAlpha = 0` [S2, unofficial].
2.  **Intersection Check**: If the ray intersects the volume bounds $[t_{start}, t_{end}]$, proceed. Otherwise, return background [S2, unofficial].
3.  **Jitter**: Generate a random jitter value $j \in [0, 1)$ to prevent banding artifacts [S2, S3, unofficial].
4.  **Ray Marching Loop**: Iterate $t$ from $t_{start}$ to $t_{end}$ with step size `marchingStep`.
    *   **Position**: Calculate position $\bar{p} = \bar{o} + \text{lerp}(j, t_{start}, t_{end}) \cdot \bar{d}$ (or standard linear interpolation along the ray segment) [S2, unofficial].
    *   **Sample**: Get scalar value $d = \text{sampleVolume}(\bar{p})$ using trilinear interpolation [S1, S5].
    *   **Transfer Function**: Map $d$ to sample color $C_s$ and opacity $\alpha_s$ [S2, unofficial].
    *   **Opacity Correction**: Apply opacity correction based on step size to ensure slice-count invariance [S2, S3, unofficial].
    *   **Gradient Calculation**: Compute gradient $\bar{N}_o = -\nabla d$ using a central difference operator with `gradientStep` [S2, S1, unofficial]. Transform to world space $\bar{N}_w$ [S2, unofficial].
    *   **Transmittance**: Calculate current transmittance $tr = 1 - \alpha$ [S2, unofficial].
    *   **Shading Mode**:
        *   **If `GRADIENT_SHADING`**:
            *   Transform ray direction to world space.
            *   Compute shaded color $C_{shade}$ using lighting model (ambient + directional) with normal $\bar{N}_w$ [S2, unofficial].
            *   Blend sample color: $C_s = \text{lerp}(\text{shadingScale}, C_s, C_{shade})$ [S2, unofficial].
        *   **If `SINGLE_SHADE_HEURISTIC`**:
            *   Check if current sample density is highest: if $\alpha_s \cdot (1 - \alpha) > \text{highestAlpha}$, update `highestOrg`, `highestColor`, and `highestAlpha` [S2, unofficial].
            *   Use unshaded $C_s$ for accumulation [S2, unofficial].
    *   **Accumulation**:
        *   Update color: $C_{new} = C_{old} + (1 - \alpha_{old}) \cdot C_s \cdot \alpha_s$ [S2, unofficial].
        *   Update alpha: $\alpha_{new} = \alpha_{old} + (1 - \alpha_{old}) \cdot \alpha_s$ [S2, unofficial].
    *   **Termination**: If $\alpha \ge 0.99$ (nearly one), break loop [S2, unofficial].
5.  **Final Shading (Heuristic Only)**:
    *   If `highestAlpha > 0`, compute shadow ray transmittance $T_{shadow}$ from `highestOrg` to light direction [S2, unofficial].
    *   Compute final color:
        $$ C_{final} = \text{lerp}(C_{accumulated}, C_{highest} \cdot \alpha_{highest} \cdot T_{shadow}, \text{shadingScale}) $$
        [S2, unofficial].
6.  **Gamma Correction**: Apply gamma 2.2 correction to the final color [S2, unofficial].

    if sphere is not None and volume is None:
        t0, t1 = sphere.intersect(ray_origin, ray_direction)
        if t0 is None:
            return background_color
        
        # Distance is simply t1 - t0 [S1, unofficial]
        distance = t1 - t0
        
        # Beer's Law for transmission [S1, unofficial]
        transmission = exp(-sphere.sigma_a * distance)
        
        # Final color: attenuated background + uniform scatter [S1, unofficial]
        final_color = background_color * transmission + sphere.scatter * (1.0 - transmission)

### Parameters
*   `sigma_a`: Absorption coefficient. Typical value: $0.1$ [S1, unofficial].
*   `scatter`: Uniform scatter color. Typical value: $[0.8, 0.1, 0.5]$ [S1, unofficial].
*   `background_color`: Color returned if no intersection. Typical value: $[0.572, 0.772, 0.921]$ [S1, unofficial].
*   `shadingScale`: Scalar blending unshaded and shaded colors [S2, unofficial].
*   `gradientStep`: Step size for gradient estimation [S2, unofficial].
*   `marchingStep`: Step size for ray marching [S2, unofficial].

### Edge Cases and Pitfalls
*   **Redundant Distance Calculation**: Computing the Euclidean distance between entry and exit points ($\|\bar{p}_1 - \bar{p}_2\|$) is correct but computationally redundant if $t_0$ and $t_1$ are known; use $t_1 - t_0$ [S1, unofficial].
*   **Uniform Scattering Assumption**: The analytical mode assumes uniform scattering color regardless of position or direction; it does not account for directional lighting or varying scattering properties [S1, unofficial].
*   **Heuristic Gradient**: In `SINGLE_SHADE_HEURISTIC`, gradients are not accumulated; only the highest density point is stored for deferred shading [S2, unofficial].
*   **Shadow Ray Cost**: Computing shadow transmittance from the highest density point adds significant cost for the heuristic mode [S2, unofficial].

## Operating characteristics
*   **Time Complexity**: $O(N)$ where $N$ is the number of samples along the ray. For analytical spheres, it is $O(1)$ per pixel. For marching, it depends on volume density and step size.
*   **Memory Complexity**: $O(1)$ for analytical mode. $O(V)$ for volume data storage in marching mode.
*   **Performance**: Analytical integration is extremely fast and exact for homogeneous spheres. Ray marching is slower but handles complex geometries. Early ray termination optimizes performance in dense regions [S2, S3, unofficial].
*   **Strengths**: Exact solution for homogeneous volumes; integrates geometric visibility; supports shading heuristics for complex data.
*   **Limitations**: Analytical mode is limited to simple shapes (spheres); uniform scattering assumption is unrealistic for many volumes; heuristic shading may produce artifacts if the highest density point is not representative [S1, S2, unofficial].
*   **When to use**: Ideal for rendering simple volumetric objects (e.g., clouds, smoke balls) or when integrating geometric surfaces with volume data [S1, S3, unofficial]. Avoid for highly anisotropic or spatially varying scattering volumes [S1, unofficial].

## Background
The method originates from early volume rendering techniques that combined ray tracing with volume data [S1, unofficial]. It was formalized in the context of scientific visualization shading, where analytical integration for homogeneous spheres provided a baseline for more complex methods [S1, unofficial]. The integration of classical ray tracing into volume rendering pipelines was proposed to handle visibility and geometric merging, such as superimposing radiation treatment planning isodose surfaces over CT data [S3, unofficial]. The heuristic shading approach was developed to balance performance and visual quality in scientific visualization [S2, unofficial]. Recent applications include integrating ray tracing for interreflections in 3D Gaussian Splatting [S4, unofficial].
