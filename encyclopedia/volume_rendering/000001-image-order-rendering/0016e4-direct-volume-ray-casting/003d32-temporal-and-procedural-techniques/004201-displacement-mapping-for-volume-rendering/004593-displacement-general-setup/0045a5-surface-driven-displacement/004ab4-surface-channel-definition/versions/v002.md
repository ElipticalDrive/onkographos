# Surface Channel Definition

Also called: Surface Channel

## Overview
The Surface Channel Definition specifies which data channel within a volumetric simulation defines the fluid's surface for solid rendering and displacement [S1]. It solves the boundary determination problem by selecting a scalar field and an isosurface threshold [S1]. It is used in Mesh, Ocean Mesh, Cap Mesh, and Isosurface render modes, and also denotes the surface for Gradient and Surface-driven displacement in all modes [S1]. It builds on [Surface Driven Displacement](11547-surface-driven-displacement.md) by providing the reference surface field.

## How it works
**Inputs and Outputs:**
*   **Input:** A volumetric dataset containing named channels (Liquid/Temperature, Smoke, Speed, Fuel, or Texture) [S1].
*   **Input:** An isosurface threshold value (`surflevel`) [S1].
*   **Input:** An inversion flag (`solidbelow`) [S1].
*   **Output:** A scalar field or binary boundary representing the surface, used for mesh generation or displacement calculations [S1].

**Data Structures:**
The specific internal data structure layout is not given in the sources. The method relies on named channels within the simulation cache [S1].

**Steps:**
1.  Identify the selected `Surface Channel` (`sarg`) from the available simulation outputs [S1].
2.  If `sarg` is `Texture`, load the texture specified in the `stex` slot. In Mesh, Ocean Mesh, Cap Mesh, and Isosurface render modes, this map completely replaces loaded cache files [S1].
3.  For `Speed` and `Fuel` channels, ensure their respective outputs are explicitly enabled in the simulation settings [S1].
4.  Evaluate the scalar value at each voxel position from the selected channel.
5.  Compare the evaluated value against the `Isosurface Level` threshold.
6.  Determine surface membership based on the `Invert Volume` flag.
7.  Define the surface for solid rendering and displacement [S1].

**Formulas:**
Let $V$ be the scalar value at voxel position $\mathbf{p}$, and $T$ be the `Isosurface Level` threshold. Surface membership is determined by:
*   If `Invert Volume` is disabled: $V \ge T$ denotes internal/surface; $V < T$ denotes external.
*   If `Invert Volume` is enabled: $V < T$ denotes internal/surface; $V \ge T$ denotes external.

**Parameters:**
*   **Surface Channel (`sarg`):** Identifies the channel defining the surface [S1]. Options include:
    *   `Liquid/Temperature`: Defines the liquid surface. Typical ranges are $0$–$1$ for Liquid simulations and $600$–$2000$ for Fire/Smoke simulations [S1].
    *   `Smoke`: Defines the liquid surface. Typical range is $0$–$1$ for Fire/Smoke simulations [S1].
    *   `Speed`: Defines the liquid surface. Calculated as the length of the velocity vector for each voxel. Requires the Speed channel output to be enabled [S1].
    *   `Fuel`: Defines the liquid surface. Requires the Fuel channel output to be enabled [S1].
    *   `Texture`: Uses a custom texture map to define the mesh surface. Requires the `stex` slot to specify the texture [S1].
*   **Isosurface Level (`surflevel`):** The threshold value $T$ for geometry generation. Grid cells with values below this threshold are ignored [S1].
*   **Invert Volume (`solidbelow`):** Boolean flag. By default, values above the surface level are considered internal. When enabled, it swaps the inside and outside definitions [S1].

**Edge Cases and Pitfalls:**
*   **Missing Outputs:** The `Speed` and `Fuel` channels will not function if their outputs are not explicitly enabled in the simulation settings [S1].
*   **Texture Replacement:** In Mesh, Ocean Mesh, Cap Mesh, or Isosurface modes, selecting a `Texture` map completely replaces any loaded cache files, discarding simulation data [S1].
*   **Range Mismatch:** Using default thresholds with channels that have non-standard ranges (e.g., a $0$–$1$ threshold for a Fire/Smoke Temperature channel ranging $600$–$2000$) will result in incorrect surface generation [S1].

## Background
The concept is based on the isosurface generation technique for generating surfaces from volumetric data [S1]. While primarily used for rendering liquids, it is also applied to smoke and fire to create effects such as underwater bubbles or freezing fire [S1].
