# Exponential Decay Blur Filter
Also called: Exponential Smoothing Blur, IIR Blur
## Overview
A linear blur filter that applies exponential decay smoothing along the outermost two dimensions of an input tensor [S1, unofficial].
## How it works
**Inputs and Outputs:**
- Input: A tensor $X$ [S1, unofficial].
- Output: A smoothed tensor $Y$ of the same shape as $X$ [S1, unofficial].

**Parameters:**
- Smoothing parameter $\alpha$: Controls the decay rate [G].

**Data Structures:**
- The algorithm operates on a single buffer $Y$ initialized as a copy of $X$ [S1, unofficial].

**Steps:**
The filter is separable, processing the last two dimensions independently [S1, unofficial]. Each dimension undergoes a forward pass followed by a backward pass [S1, unofficial].
1. Initialize $Y = X$ [S1, unofficial].
2. Forward pass along the last dimension: for $i$ from $0$ to $W-2$: $Y[..., i+1] \leftarrow Y[..., i+1] + \alpha \cdot Y[..., i]$ [S1, unofficial].
3. Backward pass along the last dimension: for $i$ from $W-2$ down to $0$: $Y[..., i] \leftarrow Y[..., i] + \alpha \cdot Y[..., i+1]$ [S1, unofficial].
4. Forward pass along the second-to-last dimension: for $i$ from $0$ to $H-2$: $Y[..., i+1, :] \leftarrow Y[..., i+1, :] + \alpha \cdot Y[..., i, :]$ [S1, unofficial].
5. Backward pass along the second-to-last dimension: for $i$ from $H-2$ down to $0$: $Y[..., i, :] \leftarrow Y[..., i, :] + \alpha \cdot Y[..., i+1, :]$ [S1, unofficial].

**Pseudocode:**
```python
def exponential_decay_blur(X, alpha):
    Y = X.clone()
    H = Y.shape[-2]
    W = Y.shape[-1]
    
    for i in range(W - 1):
        Y[..., i + 1] = Y[..., i + 1] + alpha * Y[..., i]
    for i in range(W - 2, -1, -1):
        Y[..., i] = Y[..., i] + alpha * Y[..., i + 1]
    for i in range(H - 1):
        Y[..., i + 1, :] = Y[..., i + 1, :] + alpha * Y[..., i, :]
    for i in range(H - 2, -1, -1):
        Y[..., i, :] = Y[..., i, :] + alpha * Y[..., i + 1, :]
    return Y
```

**Edge Cases and Pitfalls:**
- Boundary conditions: The loop bounds `range(shape-1)` ensure indices stay within tensor dimensions; boundary elements are updated by neighbors but do not propagate out of bounds [S1, unofficial].
- Precision: Accumulation of floating-point errors is possible in very long sequences, though typically negligible for image dimensions [G].
- Degenerate input: If $H=1$ or $W=1$, the corresponding `range` is empty and the pass is skipped, which is correct behavior [G].

## Subtopics

### [Exponential Moving Average Smoothing](15247-exponential-moving-average-smoothing.md)
A recursive low-pass filter that estimates the underlying signal by weighting the current observation and the previous smoothed estimate [G]. It is distinguished from fixed-kernel blurs by its infinite impulse response and adaptive memory, where the effective window size is determined by the smoothing parameter $\alpha$ rather than a fixed spatial or temporal radius [G].
