# Two-pass Weighted Gaussian Blur

Also called: Gaussian blur blending

## Overview
A post-processing blending technique used to improve visualization quality for moving objects or during camera navigation in stroke-based splatting [S1]. It differs from its sibling [Exponential Decay Blur Filter](11279-exponential-decay-blur-filter.md) by using a weighted Gaussian kernel rather than exponential decay, and from [Standard Gaussian Blur](21025-standard-gaussian-blur.md) by integrating Z-buffer occlusion checks during the blending process to handle depth-aware transparency [S1]. It serves as an alternative to alpha blending by simulating tint blending through continuous Gaussian falloff [S1].

## How it works
**Inputs:** Rendered patches with color, transparency (alpha), and depth (Z) values; Z-buffer data.
**Outputs:** Blended final image.
**Data Structures:**
- A-Buffer: Stores accumulated fragments, sorted incrementally via bubble sort [S1].
- Z-buffer: Stores depth values for occlusion testing [S1].

**Steps:**
1. **Initialization:** Prepare buffers for rendering patches. [G] Initialize A-Buffer with zeroed color and alpha accumulators.
2. **Incremental Sorting:** Perform bubble-sort operations on the A-Buffer to sort fragments by depth. This ensures a minimum amount of fragments are available for blending [S1].
3. **Concurrent Blending:** While the bubble-sort is processing, perform Gaussian blur blending with Z-buffer occlusion [S1].
4. **Gaussian Weighting:** For each fragment, calculate Gaussian weights based on amplitude and sigma values ($\sigma_x, \sigma_y$) [S1]. The transparency component controls the influence.
5. **Blending:** Apply common alpha blending on rendered patches, giving stronger influence to topmost patches, simulating tint blending [S1].
6. **Iteration:** Repeat sorting and blending iterations. Sorted data is only used after a preset amount of iterations to ensure sufficient neighboring patches for blended color calculation [S1].

**Formulas:**
- Gaussian Weight: $W(x,y) = A \cdot e^{-\frac{x^2}{2\sigma_x^2} - \frac{y^2}{2\sigma_y^2}}$ where $A$ is amplitude, $\sigma_x, \sigma_y$ are standard deviations [S1].
- Alpha Blending: $C_{out} = C_{src} \cdot \alpha_{src} + C_{dst} \cdot (1 - \alpha_{src})$ [S1, implied by "common alpha blending"].

**Parameters:**
- Amplitude ($A$): Controls influence strength [S1].
- Sigma ($\sigma_x, \sigma_y$): Controls falloff width [S1].
- Preset iterations: Minimum iterations before using sorted data [S1].

**Edge Cases:**
- High-frequency noise removal works even with high amplitude and low sigma values due to continuous Gaussian falloff [S1].
- Boundary regions require careful handling of alpha blending to avoid artifacts [S1].

**Pseudocode:**
```python
def two_pass_weighted_gaussian_blur(patches, z_buffer, a_buffer, preset_iterations):
    # Initialize A-Buffer
    a_buffer.clear()
    
    # Render patches and update A-Buffer
    for patch in patches:
        a_buffer.add(patch)
        
    # Incremental bubble sort and concurrent blending
    for iteration in range(max_iterations):
        # Perform one step of bubble sort on A-Buffer
        a_buffer.bubble_sort_step()
        
        # Perform Gaussian blur blending with Z-buffer occlusion
        if iteration >= preset_iterations:
            # Use sorted data for blending
            blended_color = calculate_blended_color(a_buffer, z_buffer)
            apply_blending(blended_color)
        else:
            # Perform blending without sorted data (or with partial data)
            # This step ensures minimum fragments are processed
            perform_partial_blending(a_buffer, z_buffer)
            
    return final_image

def calculate_blended_color(a_buffer, z_buffer):
    total_color = (0, 0, 0)
    total_alpha = 0
    for fragment in a_buffer.sorted_fragments:
        # Check Z-buffer occlusion
        if fragment.z < z_buffer.get(fragment.x, fragment.y):
            continue
            
        # Calculate Gaussian weight
        weight = gaussian_weight(fragment.x, fragment.y, fragment.amplitude, fragment.sigma_x, fragment.sigma_y)
        
        # Alpha blending
        color = fragment.color * weight
        alpha = fragment.alpha * weight
        
        total_color = total_color + color * (1 - total_alpha)
        total_alpha = total_alpha + alpha * (1 - total_alpha)
        
    return total_color / max(total_alpha, epsilon)
```

## Subtopics

### [Standard Gaussian Blur](21025-standard-gaussian-blur.md)
Uses fixed Gaussian weights without Z-buffer occlusion or adaptive sorting. Choose for static scenes where depth-aware blending is unnecessary.

### [Exponential Decay Blur Filter](11279-exponential-decay-blur-filter.md)
Uses exponential decay instead of Gaussian weights. Choose for faster computation with similar visual results in some contexts.

### [3D Box Blur](19548-3d-box-blur.md)
Applies a box filter in 3D space. Choose for volumetric data where isotropic smoothing is required.

### [Separable Weighted Blur (DoF)](21017-separable-weighted-blur-dof.md)
Uses separable filters for depth-of-field effects. Choose for simulating camera focus.

### [HQ Upsample Combine Blur](21020-hq-upsample-combine-blur.md)
Combines upsampled and blurred data. Choose for high-quality upscaling.

### [Post-Processing Filtering](21964-post-processing-filtering.md)
General category of post-processing filters. Use as a reference for other techniques.

## Operating characteristics
- **Time Complexity:** Depends on the number of patches and iterations. Bubble sort adds $O(N^2)$ overhead per iteration, but incremental sorting reduces this [S1].
- **Memory Complexity:** Requires storage for A-Buffer and Z-buffer [S1].
- **Performance:** Effective for moving objects and camera navigation [S1]. High-frequency noise removal is efficient with appropriate sigma values [S1].
- **Strengths:** Improves visualization quality, handles motion, simulates tint blending [S1].
- **Limitations:** Computational cost of bubble sort and Gaussian weighting [S1].
- **When to Use:** Moving objects, camera navigation, dynamic scenes [S1].
- **When Not to Use:** Static scenes where [Standard Gaussian Blur](21025-standard-gaussian-blur.md) is sufficient.

## Background
Originated in stroke-based splatting for point cloud visualization [S1]. Developed to address visualization quality issues during camera navigation and moving object rendering [S1]. The technique integrates with incremental A-Buffer sorting to enhance performance [S1].
