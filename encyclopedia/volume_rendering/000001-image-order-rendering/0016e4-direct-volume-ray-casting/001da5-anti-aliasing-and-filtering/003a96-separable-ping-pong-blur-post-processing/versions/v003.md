# Separable Ping-Pong Blur Post-Processing

Also called: Horizontal-vertical blur, PostProcessBlurShader, Two-pass blur

## Overview
Separable Ping-Pong Blur Post-Processing applies a smoothing filter to a rendered image to reduce high-frequency noise and aliasing artifacts [S1, unofficial]. It solves the problem of jagged edges and visual noise in direct volume ray casting by treating the rendered image as a discrete function requiring spatial smoothing [S1, unofficial]. Unlike sibling methods that operate on volumetric primitives or screen-space geometry buffers, this method operates exclusively on the final color buffer using a two-pass separable convolution [S1, unofficial]. It sets itself apart by using a "ping-pong" framebuffer switching technique to perform horizontal and vertical blurs sequentially, allowing for efficient computation with constant memory per pass regardless of kernel width [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** The base rendered scene image (color buffer).
*   **Output:** The blurred image, written to the target color buffer.

**Data Structures:**
*   **Ping-Pong Textures:** Two textures, `_fbTexture[0]` and `_fbTexture[1]`, allocated with dimensions $512 \times 512$ [S1, unofficial].
    *   Format: `GL_RGB` [S1, unofficial].
    *   Internal Format: `GL_UNSIGNED_SHORT_5_6_5` [S1, unofficial].
    *   Filtering: `GL_LINEAR` (Bilinear) [S1, S2, unofficial].
    *   Wrapping: `GL_CLAMP_TO_EDGE` [S1, S2, unofficial].
*   **Ping-Pong Framebuffers:** Two framebuffers, `_framebuffer[0]` and `_framebuffer[1]` [S1, unofficial].
    *   `_framebuffer[0]`: Attaches `_fbTexture[0]` and a `GL_DEPTH_COMPONENT16` renderbuffer [S1, unofficial].
    *   `_framebuffer[1]`: Attaches only `_fbTexture[1]` [S1, unofficial].
*   **Shader Uniforms:**
    *   `m_fTexelOffset`: The calculated texel offset for sampling [S1, unofficial].
    *   `blurStep`: A `Vec2` uniform controlling the blur step size [S2, unofficial].
    *   `focus`: A `Float` uniform controlling focus [S2, unofficial].
    *   `halfBand`: A `Float` uniform controlling half band [S2, unofficial].
    *   `maxRadius`: A `Float` uniform controlling max radius [S2, unofficial].
    *   `saturation`: A `Float` uniform controlling saturation [S2, unofficial].

**Parameters:**
*   `fullTextureSize`: Fixed resolution for post-processing textures, typically $512$ [S1, unofficial].
*   `w1`: Weight for the faster filter kernel, typically $0.0555555$ [S1, unofficial].
*   `w2`: Weight for the faster filter kernel, typically $0.2777777$ [S1, unofficial].

**Steps:**
1.  **Initialization:** Allocate `_fbTexture[0]` and `_fbTexture[1]` with the specified format, filtering, and wrapping. Create `_framebuffer[0]` and `_framebuffer[1]` and attach the textures and depth buffer as specified [S1, unofficial].
2.  **Base Render:** Render the scene into `_framebuffer[0]` [S1, unofficial].
3.  **Pass 1 (Horizontal Blur):**
    *   Bind `_framebuffer[1]` as the draw target [S1, unofficial].
    *   Set shader uniform `_SHADER_UNIFORM_TEXEL_OFFSET_X` to `m_fTexelOffset` and `_SHADER_UNIFORM_TEXEL_OFFSET_Y` to `0.0f` [S1, unofficial].
    *   Draw a fullscreen quad using the blur shader, sampling from `_fbTexture[0]` [S1, unofficial].
4.  **Pass 2 (Vertical Blur):**
    *   Bind the final target color buffer (or `_framebuffer[0]` if reusing) as the draw target [S1, unofficial].
    *   Set shader uniform `_SHADER_UNIFORM_TEXEL_OFFSET_X` to `0.0f` and `_SHADER_UNIFORM_TEXEL_OFFSET_Y` to `m_fTexelOffset` [S1, unofficial].
    *   Draw a fullscreen quad using the blur shader, sampling from the result of Pass 1 (`_fbTexture[1]`) [S1, unofficial].

**Formulas:**
The base texel offset is calculated as [S1, unofficial]:
$$
m\_fTexelOffset = \frac{1.0f}{fullTextureSize}
$$

An intra-texel offset adjustment is applied using specific kernel weights [S1, unofficial]:
$$
intraTexelOffset = \frac{w2}{w1 + w2} \times m\_fTexelOffset
$$

The final offset used for sampling is [S1, unofficial]:
$$
m\_fTexelOffset_{final} = m\_fTexelOffset + intraTexelOffset
$$

**Pseudocode:**
```python
def initialize_ping_pong_blur():
    # Allocate two 512x512 RGB textures with unsigned short 5-6-5 format
    fb_texture_0 = create_texture(width=512, height=512, format=GL_RGB, internal_format=GL_UNSIGNED_SHORT_5_6_5)
    fb_texture_1 = create_texture(width=512, height=512, format=GL_RGB, internal_format=GL_UNSIGNED_SHORT_5_6_5)
    
    # Set filtering and wrapping
    set_texture_filtering(fb_texture_0, filter=GL_LINEAR, wrap=GL_CLAMP_TO_EDGE)
    set_texture_filtering(fb_texture_1, filter=GL_LINEAR, wrap=GL_CLAMP_TO_EDGE)
    
    # Create framebuffers
    fb_0 = create_framebuffer()
    attach_texture(fb_0, fb_texture_0, attachment=COLOR_ATTACHMENT0)
    attach_renderbuffer(fb_0, format=GL_DEPTH_COMPONENT16)
    
    fb_1 = create_framebuffer()
    attach_texture(fb_1, fb_texture_1, attachment=COLOR_ATTACHMENT0)
    
    return fb_0, fb_1, fb_texture_0, fb_texture_1

def render_scene(fb_0):
    bind_framebuffer(fb_0)
    clear_color_buffer()
    clear_depth_buffer()
    draw_scene() # Render the base volume rendering output

def apply_separable_blur(fb_0, fb_1, fb_texture_0, fb_texture_1, shader, full_texture_size=512):
    # Calculate offsets
    w1 = 0.0555555
    w2 = 0.2777777
    base_offset = 1.0 / full_texture_size
    intra_offset = (w2 / (w1 + w2)) * base_offset
    final_offset = base_offset + intra_offset
    
    # Pass 1: Horizontal Blur
    bind_framebuffer(fb_1)
    clear_color_buffer()
    bind_shader(shader)
    set_uniform(shader, "texel_offset_x", final_offset)
    set_uniform(shader, "texel_offset_y", 0.0)
    set_uniform(shader, "blur_step", vec2(1.0, 0.0)) # Example uniform usage
    set_uniform(shader, "focus", 1.0)
    set_uniform(shader, "half_band", 1.0)
    set_uniform(shader, "max_radius", 1.0)
    set_uniform(shader, "saturation", 1.0)
    bind_texture(shader, "input_texture", fb_texture_0)
    draw_fullscreen_quad()
    
    # Pass 2: Vertical Blur
    bind_framebuffer(fb_0) # Or the final target buffer
    clear_color_buffer()
    bind_shader(shader)
    set_uniform(shader, "texel_offset_x", 0.0)
    set_uniform(shader, "texel_offset_y", final_offset)
    set_uniform(shader, "blur_step", vec2(0.0, 1.0)) # Example uniform usage
    bind_texture(shader, "input_texture", fb_texture_1)
    draw_fullscreen_quad()
```

**Edge Cases and Pitfalls:**
*   **Texture Filtering:** Must be set to Bilinear (`GL_LINEAR`) because the blur taps land between texels [S2, unofficial].
*   **Texture Wrapping:** Must be set to Clamp (`GL_CLAMP_TO_EDGE`) because default wrapping (e.g., Repeat) causes the blur at the top edge to pull in pixels from the bottom of the frame [S2, unofficial].

## Subtopics

### [Exponential Decay Blur Filter](11279-exponential-decay-blur-filter.md)
A linear blur filter that applies exponential decay smoothing along the outermost two dimensions of an input tensor. It serves as a post-processing step in separable ping-pong blur pipelines to reduce high-frequency noise and aliasing artifacts in rendered images. Unlike Gaussian blurs, it uses an infinite impulse response (IIR) structure, allowing for efficient computation with constant memory per pass regardless of kernel width.

### Two-pass Weighted Gaussian Blur
A blending technique used to improve visualization quality for moving objects or during camera navigation [S3]. It applies a two-pass weighted Gaussian blur and performs Gaussian blur blending with Z-buffer occlusion while the incremental bubble-sort A-Buffer is processing [S3].

## Operating characteristics
*   **Time Complexity:** $O(N)$ per pass, where $N$ is the number of pixels, because the blur is separable into two 1D passes. The kernel width affects the constant factor but not the asymptotic complexity if the kernel is fixed or precomputed.
*   **Memory Complexity:** $O(W \times H)$ for the ping-pong textures, where $W$ and $H$ are the texture dimensions. The method requires two full-resolution textures for the ping-pong mechanism [S1, unofficial].
*   **Measured Performance:** Specific performance metrics are not provided in the sources. The use of `GL_UNSIGNED_SHORT_5_6_5` suggests a trade-off between memory bandwidth and color precision [S1, unofficial].
*   **Strengths:** Efficient for large blur radii due to separability; constant memory usage per pass; simple implementation using standard framebuffer objects.
*   **Limitations:** Fixed resolution of $512 \times 512$ in the reference implementation may limit applicability to higher resolutions without modification [S1, unofficial]; blurring is applied uniformly, which may not be desirable for all regions of the image; does not account for depth or geometry information during the blur itself (unlike depth-aware blurs).
*   **When to use:** When post-processing a rendered image to reduce aliasing and noise, and the scene does not require depth-aware blurring.
*   **When not to use:** When high-resolution textures are required and memory is constrained; when the blur needs to be adaptive based on scene content or depth.

## Background
The method originates from the iVoxel project, an iPhone OS Scenegraph Rendering System developed by Torsten Becker, Norman Holz, Lars Schneider, and others at the Hasso-Plattner-Institute (HPI) in Potsdam, Germany, around 2009 [S1, unofficial]. It was used as a post-processing step to improve the visual quality of rendered voxel data. The technique leverages standard OpenGL ES 2.0 features for framebuffer objects and shader-based convolution [S1, unofficial].
