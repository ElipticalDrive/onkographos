# Separable Ping-Pong Blur Post-Processing

Also called: Horizontal-vertical blur, PostProcessBlurShader, Two-pass blur

## Overview
This method applies a separable blur to a rendered image using a ping-pong framebuffer technique to minimize texture allocations. It solves the problem of smoothing high-frequency artifacts in direct volume ray casting by treating the image as a discrete function and applying neighborhood-based convolution [S1, S2, unofficial]. It is distinguished from its siblings by its explicit use of two alternating framebuffers for horizontal and vertical passes, whereas siblings like [Splatting for Anti-aliasing Small Cells](829-splatting-for-anti-aliasing-small-cells.md) operate in object space or [Screen-Space Image Filtering](9037-screen-space-image-filtering.md) may use different accumulation strategies.

## How it works
**Inputs and Outputs:**
*   **Input:** A rendered scene image (color buffer) and a target resolution (typically 512x512 for post-processing) [S1, S2, unofficial].
*   **Output:** A blurred image stored in the final render target [S1, unofficial].

**Data Structures:**
1.  **Textures:** Two textures, `_fbTexture[0]` and `_fbTexture[1]`, allocated with dimensions $512 \times 512$ [S1, unofficial].
    *   Format: `GL_RGB` [S1, unofficial].
    *   Internal Format/Type: `GL_UNSIGNED_SHORT_5_6_5` [S1, unofficial].
    *   Filtering: `GL_LINEAR` (Bilinear) [S1, S2, unofficial].
    *   Wrapping: `GL_CLAMP_TO_EDGE` [S1, S2, unofficial].
2.  **Framebuffers:** Two framebuffers, `_framebuffer[0]` and `_framebuffer[1]` [S1, unofficial].
    *   `_framebuffer[0]`: Attaches `_fbTexture[0]` as color attachment and a `GL_DEPTH_COMPONENT16` renderbuffer as depth attachment [S1, unofficial].
    *   `_framebuffer[1]`: Attaches `_fbTexture[1]` as color attachment only [S1, unofficial].
3.  **Shader Uniforms:**
    *   `_SHADER_UNIFORM_TEXEL_OFFSET_X`: Horizontal texel offset [S1, unofficial].
    *   `_SHADER_UNIFORM_TEXEL_OFFSET_Y`: Vertical texel offset [S1, unofficial].
    *   `blurStep`: Vec2 uniform controlling blur step size [S2, unofficial].
    *   `focus`: Float uniform controlling focus [S2, unofficial].
    *   `halfBand`: Float uniform controlling half band [S2, unofficial].
    *   `maxRadius`: Float uniform controlling max radius [S2, unofficial].
    *   `saturation`: Float uniform controlling saturation [S2, unofficial].

**Parameters:**
*   `fullTextureSize`: Fixed resolution for post-processing textures, typically 512 [S1, unofficial].
*   `w1`: Weight for kernel, value $0.0555555f$ [S1, unofficial].
*   `w2`: Weight for kernel, value $0.2777777f$ [S1, unofficial].

**Steps:**
1.  **Initialization:** Allocate `_fbTexture[0]` and `_fbTexture[1]` with the specified format, filtering, and wrapping. Create `_framebuffer[0]` and `_framebuffer[1]` and attach the textures and depth buffer as described [S1, unofficial].
2.  **Scene Render:** Render the volume scene into `_framebuffer[0]` [S1, unofficial].
3.  **Pass 1 (Horizontal Blur):**
    *   Bind `_framebuffer[1]` as the draw framebuffer.
    *   Set shader uniform `_SHADER_UNIFORM_TEXEL_OFFSET_X` to $m\_fTexelOffset$ and `_SHADER_UNIFORM_TEXEL_OFFSET_Y` to $0.0f$ [S1, unofficial].
    *   Draw a fullscreen quad using the blur shader, sampling from `_fbTexture[0]` [S1, unofficial].
4.  **Pass 2 (Vertical Blur):**
    *   Bind the final target color buffer (or `_framebuffer[0]` if reusing) as the draw framebuffer.
    *   Set shader uniform `_SHADER_UNIFORM_TEXEL_OFFSET_X` to $0.0f$ and `_SHADER_UNIFORM_TEXEL_OFFSET_Y` to $m\_fTexelOffset$ [S1, unofficial].
    *   Draw a fullscreen quad using the blur shader, sampling from `_fbTexture[1]` [S1, unofficial].

**Formulas:**
The texel offset is calculated to determine the sampling distance for the blur kernel [S1, unofficial]:

$$
m\_fTexelOffset = \frac{1.0f}{fullTextureSize}
$$

An intra-texel offset adjustment is applied using specific weights $w1$ and $w2$ [S1, unofficial]:

$$
intraTexelOffset = \frac{w2}{w1 + w2} \times m\_fTexelOffset
$$

The final offset used for sampling is [S1, unofficial]:

$$
m\_fTexelOffset_{final} = m\_fTexelOffset + intraTexelOffset
$$

**Pseudocode:**
```python
# Initialization
fullTextureSize = 512
w1 = 0.0555555f
w2 = 0.2777777f

# Calculate offsets
m_fTexelOffset = 1.0f / fullTextureSize
intraTexelOffset = (w2 / (w1 + w2)) * m_fTexelOffset
m_fTexelOffset_final = m_fTexelOffset + intraTexelOffset

# Allocate textures and framebuffers
fb_texture_0 = create_texture(width=512, height=512, format=GL_RGB, type=GL_UNSIGNED_SHORT_5_6_5, filter=GL_LINEAR, wrap=GL_CLAMP_TO_EDGE)
fb_texture_1 = create_texture(width=512, height=512, format=GL_RGB, type=GL_UNSIGNED_SHORT_5_6_5, filter=GL_LINEAR, wrap=GL_CLAMP_TO_EDGE)
depth_buffer = create_renderbuffer(width=512, height=512, format=GL_DEPTH_COMPONENT16)

framebuffer_0 = create_framebuffer()
framebuffer_0.attach_color(fb_texture_0)
framebuffer_0.attach_depth(depth_buffer)

framebuffer_1 = create_framebuffer()
framebuffer_1.attach_color(fb_texture_1)

# Step 1: Render Scene
bind_framebuffer(framebuffer_0)
render_scene()

# Step 2: Horizontal Pass
bind_framebuffer(framebuffer_1)
set_shader_uniform("texel_offset_x", m_fTexelOffset_final)
set_shader_uniform("texel_offset_y", 0.0f)
bind_texture(fb_texture_0, unit=0) # Assuming shader samples from unit 0
draw_fullscreen_quad()

# Step 3: Vertical Pass
bind_framebuffer(final_target) # Or framebuffer_0 if ping-ponging back
set_shader_uniform("texel_offset_x", 0.0f)
set_shader_uniform("texel_offset_y", m_fTexelOffset_final)
bind_texture(fb_texture_1, unit=0)
draw_fullscreen_quad()
```

**Edge Cases and Pitfalls:**
*   **Texture Filtering:** Must be set to Bilinear (`GL_LINEAR`) because blur taps land between texels [S2, unofficial].
*   **Texture Wrapping:** Must be set to Clamp (`GL_CLAMP_TO_EDGE`) because default wrapping (e.g., Repeat) causes the blur at the top edge to pull in the bottom of the frame [S2, unofficial].

## Subtopics

### Exponential Decay Blur Filter
A simple linear blur filter that applies exponential decay smoothing along the outermost two dimensions of an input tensor $X$ [S3, unofficial]. It is chosen for its simplicity in processing tensor data compared to spatial image blurs [S3, unofficial]. It performs a forward and backward pass along the last dimension, then the second-to-last dimension, using a decay factor $\alpha$ [S3, unofficial].

### Two-pass Weighted Gaussian Blur
A blending technique used to improve visualization quality for moving objects or during camera navigation in stroke-based splatting [S4]. It is chosen when high-frequency noise needs removal while maintaining shape representation [S4]. It performs Gaussian blur blending with Z-buffer occlusion while an incremental bubble-sort A-Buffer is processing [S4].

## Operating characteristics
*   **Time Complexity:** $O(N)$ where $N$ is the number of pixels, as it performs two passes over the image with a constant kernel size [S1, unofficial].
*   **Memory Complexity:** $O(W \times H)$ for the two ping-pong textures [S1, unofficial].
*   **Performance:** The fixed 512x512 resolution for post-processing textures suggests it is optimized for lower-resolution preview or specific mobile constraints (iOS OpenGL ES) [S1, unofficial].
*   **Strengths:** Efficient use of memory by reusing framebuffers; simple implementation [S1, unofficial].
*   **Limitations:** Fixed resolution may not scale to high-res displays without modification; separable blur assumes isotropic blur, which may not be desired for all anisotropic artifacts [S1, S2, unofficial].
*   **When to use:** When real-time performance is critical and isotropic smoothing is acceptable [S1, unofficial].
*   **When not to use:** When anisotropic filtering or non-separable kernels are required [S1, unofficial].

## Background
This method originates from the MiniSG iPhone OS Scenegraph Rendering System, developed by Torsten Becker, Norman Holz, Lars Schneider, and others at the Hasso-Plattner-Institute (HPI) in Potsdam, Germany, around 2009 [S1, unofficial]. It was implemented to provide efficient post-processing on mobile hardware with limited memory and compute resources [S1, unofficial].
