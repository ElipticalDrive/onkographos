# Separable Ping-Pong Blur Post-Processing

Also called: Horizontal-vertical blur, Ping-Pong Blur, Ping-Pong Gaussian Blur, PostProcessBlurShader, Separable Bloom Blur, Two-pass blur

## Overview
Separable Ping-Pong Blur Post-Processing applies a spatial smoothing filter to a rendered image to reduce high-frequency noise and aliasing artifacts [S1, unofficial]. It operates exclusively on the final color buffer using a two-pass separable convolution, alternating between two framebuffers to perform horizontal and vertical blurs sequentially [S1, unofficial]. Unlike sibling methods that process volumetric primitives or screen-space geometry buffers, this technique relies on a ping-pong framebuffer switching mechanism to achieve efficient computation with constant memory per pass regardless of kernel width [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** The base rendered scene image (color buffer) [S2, unofficial].
*   **Output:** The blurred image, written to the target color buffer [S2, unofficial].

**Data Structures:**
*   **Ping-Pong Textures:** Two 2D textures, `_fbTexture[0]` and `_fbTexture[1]`, allocated at $512 \times 512$ resolution [S2, unofficial].
    *   Format: `GL_RGB` [S2, unofficial].
    *   Internal Format: `GL_UNSIGNED_SHORT_5_6_5` [S2, unofficial].
    *   Filtering: `GL_LINEAR` (bilinear) [S2, S3, unofficial].
    *   Wrapping: `GL_CLAMP_TO_EDGE` [S2, S3, unofficial].
*   **Ping-Pong Framebuffers:** Two FBOs, `_framebuffer[0]` and `_framebuffer[1]` [S2, unofficial].
    *   `_framebuffer[0]`: Attaches `_fbTexture[0]` and a `GL_DEPTH_COMPONENT16` renderbuffer [S2, unofficial].
    *   `_framebuffer[1]`: Attaches only `_fbTexture[1]` [S2, unofficial].
*   **Shader Uniforms:**
    *   `m_fTexelOffset`: The calculated texel offset for sampling [S2, unofficial].
    *   `blurStep`: A `Vec2` uniform controlling the blur step size [S3, unofficial].
    *   `focus`: A `Float` uniform controlling focus [S3, unofficial].
    *   `halfBand`: A `Float` uniform controlling half band [S3, unofficial].
    *   `maxRadius`: A `Float` uniform controlling max radius [S3, unofficial].
    *   `saturation`: A `Float` uniform controlling saturation [S3, unofficial].

**Parameters:**
*   `fullTextureSize`: Fixed resolution for post-processing textures, typically $512$ [S2, unofficial].
*   `w1`: Weight for the faster filter kernel, typically $0.0555555$ [S2, unofficial].
*   `w2`: Weight for the faster filter kernel, typically $0.2777777$ [S2, unofficial].
*   `passes`: Integer controlling the number of blur iterations applied after the initial horizontal/vertical pass [S1, unofficial].
*   `bloomOffset`: Float uniform controlling the blur kernel width, passed to the shader as `u_TexOffsetCoeff` [S1, unofficial].

**Steps:**
1.  **Initialization:** Allocate `_fbTexture[0]` and `_fbTexture[1]` with the specified format, filtering, and wrapping. Create `_framebuffer[0]` and `_framebuffer[1]` and attach the textures and depth buffer as specified [S2, unofficial].
2.  **Base Render:** Render the scene into `_framebuffer[0]` [S2, unofficial].
3.  **Pass 1 (Horizontal Blur):** Bind `_framebuffer[1]` as the draw target [S2, unofficial]. Set shader uniform `_SHADER_UNIFORM_TEXEL_OFFSET_X` to `m_fTexelOffset` and `_SHADER_UNIFORM_TEXEL_OFFSET_Y` to `0.0f` [S2, unofficial]. Draw a fullscreen quad sampling from `_fbTexture[0]` [S2, unofficial].
4.  **Pass 2 (Vertical Blur):** Bind the target color buffer (or `_framebuffer[0]` if reusing) as the draw target [S2, unofficial]. Set X offset to `0.0f` and Y offset to `m_fTexelOffset` [S2, unofficial]. Draw a fullscreen quad sampling from the result of Pass 1 (`_fbTexture[1]`) [S2, unofficial].
5.  **Additional Passes (if `passes > 2`):** Loop `i` from `0` to `passes - 2`. Alternate binding `_framebuffer[0]` and `_framebuffer[1]`, toggle `u_Horizontal` between `0` and `1`, bind the opposite ping-pong texture, and draw a fullscreen quad [S1, unofficial].

**Formulas:**
The base texel offset is calculated as [S2, unofficial]:
$$
m\_fTexelOffset = \frac{1.0}{fullTextureSize}
$$

An intra-texel offset adjustment is applied using specific kernel weights [S2, unofficial]:
$$
intraTexelOffset = \frac{w2}{w1 + w2} \times m\_fTexelOffset
$$

The final offset used for sampling is [S2, unofficial]:
$$
m\_fTexelOffset_{final} = m\_fTexelOffset + intraTexelOffset
$$

**Pseudocode:**
```python
def initialize_ping_pong_blur(width=512, height=512):
    # Allocate two RGB textures with unsigned short 5-6-5 format
    fb_texture_0 = allocate_texture(width, height, format="RGB", internal_format="UNSIGNED_SHORT_5_6_5")
    fb_texture_1 = allocate_texture(width, height, format="RGB", internal_format="UNSIGNED_SHORT_5_6_5")
    
    # Set filtering and wrapping
    set_texture_filtering(fb_texture_0, filter="LINEAR", wrap="CLAMP_TO_EDGE")
    set_texture_filtering(fb_texture_1, filter="LINEAR", wrap="CLAMP_TO_EDGE")
    
    # Create framebuffers and attach textures
    fb_0 = create_framebuffer()
    attach_texture(fb_0, fb_texture_0, attachment="COLOR_ATTACHMENT0")
    attach_renderbuffer(fb_0, format="DEPTH_COMPONENT16")
    
    fb_1 = create_framebuffer()
    attach_texture(fb_1, fb_texture_1, attachment="COLOR_ATTACHMENT0")
    
    return fb_0, fb_1, fb_texture_0, fb_texture_1

def render_scene(fb_0):
    bind_framebuffer(fb_0)
    clear_color_buffer()
    clear_depth_buffer()
    draw_scene_geometry()  # Render the base volume rendering output

def apply_separable_blur(fb_0, fb_1, fb_texture_0, fb_texture_1, shader, full_texture_size=512, passes=2, bloom_offset=1.0):
    # Calculate offsets
    w1 = 0.0555555
    w2 = 0.2777777
    base_offset = 1.0 / full_texture_size
    intra_offset = (w2 / (w1 + w2)) * base_offset
    final_offset = base_offset + intra_offset
    
    # Pass 1: Horizontal Blur
    bind_framebuffer(fb_1)
    clear_color_buffer()
    bind_shader(shader)
    set_uniform(shader, "texel_offset_x", final_offset)
    set_uniform(shader, "texel_offset_y", 0.0)
    set_uniform(shader, "blur_step", vec2(1.0, 0.0))
    set_uniform(shader, "focus", 1.0)
    set_uniform(shader, "half_band", 1.0)
    set_uniform(shader, "max_radius", 1.0)
    set_uniform(shader, "saturation", 1.0)
    bind_texture(shader, "input_texture", fb_texture_0)
    draw_fullscreen_quad()
    
    # Pass 2: Vertical Blur
    bind_framebuffer(fb_0)  # Or the final target buffer
    clear_color_buffer()
    bind_shader(shader)
    set_uniform(shader, "texel_offset_x", 0.0)
    set_uniform(shader, "texel_offset_y", final_offset)
    set_uniform(shader, "blur_step", vec2(0.0, 1.0))
    bind_texture(shader, "input_texture", fb_texture_1)
    draw_fullscreen_quad()
    
    # Additional passes (if passes > 2)
    for i in range(passes - 2):
        # Alternate FBOs and textures
        if i % 2 == 0:
            bind_framebuffer(fb_0)
            set_uniform(shader, "u_Horizontal", 0)
            bind_texture(shader, "input_texture", fb_texture_1)
        else:
            bind_framebuffer(fb_1)
            set_uniform(shader, "u_Horizontal", 1)
            bind_texture(shader, "input_texture", fb_texture_0)
            
        set_uniform(shader, "u_TexOffsetCoeff", bloom_offset)
        clear_color_buffer()
        draw_fullscreen_quad()
```

**Edge Cases and Pitfalls:**
*   **Texture Filtering:** Must be set to Bilinear (`GL_LINEAR`) because the blur taps land between texels [S3, unofficial].
*   **Texture Wrapping:** Must be set to Clamp (`GL_CLAMP_TO_EDGE`) because default wrapping (e.g., Repeat) causes the blur at the top edge to pull in pixels from the bottom of the frame [S3, unofficial].

## Subtopics

### [Exponential Decay Blur Filter](11279-exponential-decay-blur-filter.md)
A linear blur filter that applies exponential decay smoothing along the outermost two dimensions of an input tensor. It serves as a post-processing step in separable ping-pong blur pipelines to reduce high-frequency noise and aliasing artifacts in rendered images. Unlike Gaussian blurs, it uses an infinite impulse response (IIR) structure, allowing for efficient computation with constant memory per pass regardless of kernel width.

### [Two-pass Weighted Gaussian Blur](12468-two-pass-weighted-gaussian-blur.md)
A blending technique used to improve visualization quality for moving objects or during camera navigation. It applies a two-pass weighted Gaussian blur and performs Gaussian blur blending with Z-buffer occlusion while the incremental bubble-sort A-Buffer is processing.

### [3D Box Blur](19548-3d-box-blur.md)
A post-processing blur filter that samples a 3D volume at 8 corners of a small box centered on the current coordinate and averages them.

### [Separable Weighted Blur (DoF)](21017-separable-weighted-blur-dof.md)
A 2D post-processing blur that weights neighboring samples by their alpha values to preserve sharp edges in depth-of-field rendering.

### [HQ Upsample Combine Blur](21020-hq-upsample-combine-blur.md)
Combines a high-resolution small-scale blur with a low-resolution large-scale blur using alpha-based blending for depth of field.

### [Post-Processing Filtering](21964-post-processing-filtering.md)
Integration of post-processing filters (e.g., Gaussian blur) applied to accumulated color or depth buffers after ray intersection and shading to smooth residual aliasing without additional ray computations.

### Shadow Map Post-Processing
If shadows are enabled, invert the shadow color map so shadowed areas are black [S4, unofficial]. Blur the inverted shadow map horizontally and then vertically to avoid aliasing [S4, unofficial]. Multiply the blurred shadow map with the volume color texture for final shadowing [S4, unofficial]. Apply tone mapping to the resulting post-process texture [S4, unofficial].

### Multi-Resolution Tap Mixing
Blends medium and low resolution defocus buffers based on alpha to mix bluriness levels before final compositing [S5, unofficial]. Sample medium and low resolution buffers at current UV [S5, unofficial]. Square medium alpha: $tapMedium.a = tapMedium.a^2$ [S5, unofficial]. Lerp medium RGB into low RGB using squared alpha as factor: $tapLow.rgb = lerp(tapMedium.rgb, tapLow.rgb, tapMedium.a^2)$ [S5, unofficial]. Inputs are `_TapMedium` (sampler2D) and `_TapLow` (sampler2D), output is `SV_Target` [S5, unofficial].

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** $O(W \times H)$ for the ping-pong textures, where $W$ and $H$ are the texture dimensions [S2, unofficial].
*   **Measured Performance:** Not given in the sources.
*   **Strengths:** Efficient for large blur radii due to separability; constant memory usage per pass; simple implementation using standard framebuffer objects [S1, unofficial].
*   **Limitations:** Fixed resolution of $512 \times 512$ in the reference implementation may limit applicability to higher resolutions without modification [S2, unofficial]; blurring is applied uniformly, which may not be desirable for all regions of the image; does not account for depth or geometry information during the blur itself [S3, unofficial].
*   **When to use:** When post-processing a rendered image to reduce aliasing and noise, and the scene does not require depth-aware blurring [S3, unofficial].
*   **When not to use:** When high-resolution textures are required and memory is constrained; when the blur needs to be adaptive based on scene content or depth [S3, unofficial].

## Background
The method originates from the iVoxel project, an iPhone OS Scenegraph Rendering System developed by Torsten Becker, Norman Holz, Lars Schneider, and others at the Hasso-Plattner-Institute (HPI) in Potsdam, Germany, around 2009 [S2, unofficial]. It was used as a post-processing step to improve the visual quality of rendered voxel data [S2, unofficial]. The technique leverages standard OpenGL ES 2.0 features for framebuffer objects and shader-based convolution [S2, unofficial].
