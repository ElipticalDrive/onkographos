# Prefiltering
Also called: Adaptive Prefiltering, Anisotropy Prefiltering

## Overview
Prefiltering is a technique used in volume rendering to remove singularity-like artifacts and avoid discretization errors, particularly in participating media with insufficient optical thickness to naturally blur sampled illumination [S1]. It differs from naive prefiltering of source illumination by being adaptive, allowing the perception of background illumination features while smoothing out high-frequency noise [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A set of directional ordinates (or light sources/VPLs) with associated importance weights $w_n$ and a scattering anisotropy parameter $g$.
*   **Output:** A prefiltered initialization of the radiance field or scattering coefficients that mitigates aliasing and singularity artifacts.

**Data Structures:**
*   **Ordinates:** A list of $N$ directions. Each ordinate $n$ has an associated importance $w_n \in (0, 1)$, which is proportional to the solid angle $\Omega_n$ it represents [S1].
*   **Anisotropy Map:** A scalar value $a_{n,i}$ assigned to each ordinate $n$ for each spatial ordinate $i$ (or direction bin), determining the initial spread of the scattering kernel [S1].

**Parameters:**
*   $\beta$: A scalar factor defining the proportionality in the anisotropy mapping heuristic. Value: Tuned empirically once for each environment map [S1].

**Algorithm Steps:**
1.  **Calculate Importance:** Determine the importance $w_n$ for each ordinate $n$. This is typically proportional to the solid angle $\Omega_n$ covered by the ordinate [S1].
2.  **Compute Initial Anisotropy:** For each ordinate $n$, calculate the initial anisotropy $a_{n,i}$ using the heuristic formula:
    $$ a_{n,i} = \left(1 - \frac{w_n}{N}\right)^\beta $$
    where $N$ is the total number of ordinates [S1].
    *   **Logic:** Important ordinates (high $w_n$) result in smaller $a_{n,i}$, making them denser in the directional domain with smaller solid angles. Less important ordinates (low $w_n$) result in larger $a_{n,i}$, becoming sparser with larger solid angles [S1].
3.  **Apply Clamping:** Apply clamping to the resulting values to reduce any remaining singularities [S1].

**Pseudocode:**
```python
def compute_prefiltered_anisotropy(ordinates, beta):
    """
    Computes the initial anisotropy for prefiltering based on ordinate importance.
    
    Args:
        ordinates: List of objects, each having an 'importance' attribute (w_n).
        beta: Scalar factor for proportionality (empirically tuned).
        
    Returns:
        List of anisotropy values a_n for each ordinate.
    """
    N = len(ordinates)
    anisotropy_values = []
    
    for n in range(N):
        w_n = ordinates[n].importance
        # Heuristic mapping from importance to anisotropy
        # Important ordinates (high w_n) -> lower anisotropy (denser)
        # Less important ordinates (low w_n) -> higher anisotropy (sparser)
        a_n = (1.0 - w_n / N) ** beta
        
        # Clamp to reduce singularities [S1]
        # Note: Exact clamp bounds are not specified in sources, 
        # typically [0, 1] or similar physical bounds for anisotropy factors.
        a_n = max(0.0, min(1.0, a_n)) 
        
        anisotropy_values.append(a_n)
        
    return anisotropy_values
```

**Edge Cases and Pitfalls:**
*   **Singularity Artifacts:** Without prefiltering, thin media with strong scattering anisotropy (e.g., $g=0.98$) and low numbers of ordinates exhibit singularity-like artifacts [S1].
*   **Empirical Tuning:** The parameter $\beta$ requires empirical tuning for each specific environment map, though this is described as a simple and quick task [S1].
*   **Discretization:** The method addresses artifacts arising from insufficient optical thickness to blur sampled illumination [S1].

## Subtopics

### Quasi-Interpolation Prefilter
A prefilter applied to reduce aliasing artifacts, specifically preventing 'valleys' of rims from becoming shallower due to oversmoothing [S2]. It is used in the context of GPU isosurface raycasting of FCC (Face-Centered Cubic) datasets to maintain reconstruction quality [S2].

## Operating characteristics
*   **Performance:** The prefiltering step itself is part of a larger pipeline. In the cited implementation, prefiltering contributes to the initialization phase, with subsequent steps like residual propagation (2 ms) and grid merging (4 ms) adding to the total time [S1].
*   **Strengths:** Removes singularity-like artifacts in thin, strongly scattering media; adaptive nature preserves background illumination features [S1].
*   **Limitations:** Requires empirical tuning of $\beta$ per environment map; effectiveness depends on the number of ordinates (low numbers exacerbate artifacts without prefiltering) [S1].
*   **When to use:** Media with strong scattering anisotropy and insufficient optical thickness to blur sampled illumination [S1].

## Background
Prefiltering in this context was proposed as part of the Principal-Ordinates Propagation (POP) method for real-time rendering of participating media [S1]. The method addresses shortcomings in handling highly anisotropic scattering, which is common in natural and artificial media [S1]. The technique was demonstrated to be indispensable for generating high-quality results in scenarios where naive prefiltering would fail to preserve illumination features [S1].
