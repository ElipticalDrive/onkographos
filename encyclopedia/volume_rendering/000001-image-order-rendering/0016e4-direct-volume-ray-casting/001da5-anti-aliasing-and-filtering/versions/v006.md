# Anti-Aliasing and Filtering

Also called: Box filter, Gaussian filter, Volume Filter

## Overview
Anti-Aliasing and Filtering addresses visual artifacts caused by undersampling, such as jagged edges, flickering, and high-frequency noise, by smoothing the transition between discrete samples and continuous geometry [G]. This family encompasses methods that operate at different stages of the rendering pipeline: pre-filtering data to prevent discretization errors, spatial filtering during rasterization, and post-processing screen-space blurs [G]. It is distinct from sibling methods like [Interpolation and Sampling Techniques](2787-interpolation-and-sampling-techniques.md) because it focuses on the suppression of high-frequency components in the final image or intermediate buffers rather than the accuracy of individual sample retrieval [G].

## Shared principles
The children share no single mathematical mechanism beyond operating on discrete signals [G]. Methods are selected based on their pipeline stage: pre-filtering for participating media [2928-prefiltering.md], rasterization coverage for line primitives [3607-line-coverage-anti-aliasing.md], or screen-space post-processing for ambient occlusion and color buffers [8374-pseudoseparable-cross-bilateral-filter.md][8804-separable-ping-pong-blur-post-processing.md][9037-screen-space-image-filtering.md] [G].

```python
def compute_line_coverage_aa(fragment_world_pos, line_start, line_end, viewport_height, fov_y):
    v = line_end - line_start
    w = fragment_world_pos - line_start
    c1 = dot(v, w)
    c2 = dot(v, v)
    
    if c2 == 0:
        distance = length(fragment_world_pos - line_start)
    else:
        b = c1 / c2
        b = max(0.0, min(1.0, b))
        closest_point = line_start + b * v
        distance = length(fragment_world_pos - closest_point)
        
    alpha = distance / (viewport_height * fov_y)
    return alpha

def blend_line_color(alpha, line_color, background_color):
    final_color = alpha * line_color + (1.0 - alpha) * background_color
    return final_color

class BilateralData:
    def __init__(self, ao, normal, trace_distance):
        self.Ao = ao
        self.Normal = normal
        self.TraceDistance = trace_distance

def apply_pseudo_separable_bilateral_filter(uv, direction, filter_size=14, epsilon=0.001, discrete_weights=None):
    # [G] Load texture values at uv
    center_ao = LoadAmbientOcclusionAsFloat4(uv)
    center_normal = LoadNormal(uv)
    center_depth = LoadTraceDistance(uv)
    center_data = BilateralData(center_ao, center_normal, center_depth)
    
    gtid = GetGlobalThreadID()
    pad_offset = CastDir(gtid.xy) + filter_size
    gsBilateralData = [None] * ((2 * filter_size) + 100)
    gsBilateralData[pad_offset + gtid.xy] = center_data
    
    uv_step = GetUVStep(direction)
    for i in range(1, filter_size + 1):
        uv_lower = uv - (i * uv_step)
        lower_ao = LoadAmbientOcclusionAsFloat4(uv_lower, sampler="point_clamp")
        lower_normal = LoadNormal(uv_lower, sampler="point_clamp")
        lower_depth = LoadTraceDistance(uv_lower, sampler="point_clamp")
        gsBilateralData[pad_offset + gtid.xy - i] = BilateralData(lower_ao, lower_normal, lower_depth)
        
        uv_upper = uv + (i * uv_step)
        upper_ao = LoadAmbientOcclusionAsFloat4(uv_upper, sampler="point_clamp")
        upper_normal = LoadNormal(uv_upper, sampler="point_clamp")
        upper_depth = LoadTraceDistance(uv_upper, sampler="point_clamp")
        gsBilateralData[pad_offset + gtid.xy + i] = BilateralData(upper_ao, upper_normal, upper_depth)
        
    SyncThreads()
    
    filtered_ao = center_data.Ao * discrete_weights[0]
    total_weight = discrete_weights[0]
    
    for i in range(1, filter_size + 1):
        for sign in [-1, 1]:
            neighbor_idx = pad_offset + gtid.xy + (sign * i)
            b_data = gsBilateralData[neighbor_idx]
            
            depth_diff = abs(center_data.TraceDistance - b_data.TraceDistance)
            depth_weight = 1.0 / (epsilon + center_data.TraceDistance * 0.01 + depth_diff)
            normal_dot = dot(center_data.Normal, b_data.Normal)
            normal_weight = pow(abs(normal_dot), 32)
            combined_weight = discrete_weights[i] * depth_weight * normal_weight
            
            filtered_ao += b_data.Ao * combined_weight
            total_weight += combined_weight
            
    final_ao = filtered_ao / total_weight if total_weight > 0 else center_data.Ao
    WriteToAmbientOcclusionTarget(uv, final_ao)

def initialize_ping_pong_blur(width=512, height=512):
    fb_texture_0 = [[0.0] * width for _ in range(height)]
    fb_texture_1 = [[0.0] * width for _ in range(height)]
    fb_0 = {"texture": fb_texture_0, "depth": True}
    fb_1 = {"texture": fb_texture_1}
    return fb_0, fb_1, fb_texture_0, fb_texture_1

def apply_separable_blur(fb_0, fb_1, fb_texture_0, fb_texture_1, shader, full_texture_size=512):
    w1 = 0.0555555
    w2 = 0.2777777
    base_offset = 1.0 / full_texture_size
    intra_offset = (w2 / (w1 + w2)) * base_offset
    final_offset = base_offset + intra_offset
    
    bind_framebuffer(fb_1)
    clear_color_buffer()
    bind_shader(shader)
    set_uniform(shader, "texel_offset_x", final_offset)
    set_uniform(shader, "texel_offset_y", 0.0)
    bind_texture(shader, "input_texture", fb_texture_0)
    draw_fullscreen_quad()
    
    bind_framebuffer(fb_0)
    clear_color_buffer()
    bind_shader(shader)
    set_uniform(shader, "texel_offset_x", 0.0)
    set_uniform(shader, "texel_offset_y", final_offset)
    bind_texture(shader, "input_texture", fb_texture_1)
    draw_fullscreen_quad()
```

## Subtopics

### [Prefiltering](2928-prefiltering.md)
Prefiltering initializes radiance or scattering coefficients for discrete ordinates to remove singularity-like artifacts and avoid discretization errors in participating media with insufficient optical thickness. It differs from naive source illumination prefiltering by being adaptive, preserving background illumination features while smoothing the initial scattering distribution. Choose this method when rendering thin, strongly-scattering media where natural blurring is absent.

### [Line Coverage Anti-Aliasing](3607-line-coverage-anti-aliasing.md)
Line Coverage Anti-Aliasing reduces jagged edges in rasterized lines by calculating the ratio of a line's occupancy within a pixel and blending the pixel's original color with the line's color based on that ratio. It differs from the all-or-nothing strategy by producing smoother edges, especially for wireframe models. Choose this method when rendering line-based or wireframe geometry.

### [PseudoSeparable Cross Bilateral Filter](8374-pseudoseparable-cross-bilateral-filter.md)
The PseudoSeparable Cross Bilateral Filter is a screen-space post-processing technique used to smooth Ambient Occlusion data in direct volume ray casting. It reduces computational cost by decomposing a 2D bilateral filter into two sequential 1D passes, leveraging precomputed depth and normal information to preserve edges and prevent bleeding across object boundaries. It sets itself apart from standard Gaussian blurs by weighting neighbors based on geometric consistency rather than spatial proximity. Choose this method when preserving sharp silhouettes in volumetric scenes is required.

### [Separable Ping-Pong Blur Post-Processing](8804-separable-ping-pong-blur-post-processing.md)
Separable Ping-Pong Blur Post-Processing applies a smoothing filter to a rendered image to reduce high-frequency noise and aliasing artifacts. It solves the problem of jagged edges and visual noise by treating the rendered image as a discrete function requiring spatial smoothing. It differs from sibling methods by operating exclusively on the final color buffer using a two-pass separable convolution with a ping-pong framebuffer switching technique. Choose this method when efficient constant-memory per-pass smoothing of the final color buffer is needed.

### [Screen-Space Image Filtering](9037-screen-space-image-filtering.md)
Screen-Space Image Filtering refers to a family of techniques that modify a base image rendered in a vacuum by adding effects caused by participating media, using only information currently visible on the screen. It sets itself apart from its siblings by its exclusive reliance on the 2D image buffer, which cannot access data for objects behind the camera or occluded geometry. Choose this method when high parallelism on GPUs is prioritized over physical accuracy.

### [Affine Arithmetic Filtering](17417-affine-arithmetic-filtering.md)
Affine Arithmetic Filtering obtains an average value of a procedural shader with an error bound over a finite area using affine arithmetic. It differs from standard sampling by providing rigorous error bounds for procedural volume shading. Choose this method when deterministic error bounds for procedural volume evaluation are required.

### Screen Space Ratio (SSR) with Perspective Filter
Calculates the Screen Space Ratio (SSR) for a texture coordinate to determine sampling density or filtering strength, optionally applying a perspective filter to soften the result [S2, unofficial]. It calculates the SSR based on projection matrix, position, object scale, and screen dimensions, used for font scaling [S2, unofficial]. If Filter is true: compute derivatives $a = \text{float2}(\text{ddx}(UV.x), \text{ddy}(UV.x))$ and $b = \text{float2}(\text{ddx}(UV.y), \text{ddy}(UV.y))$; compute $s = \text{lerp}(\text{dot}(a,a), \text{dot}(b,b), 0.5)$; set $\text{SSR} = \text{rsqrt}(s) / \text{TextureSize}$ [S2, unofficial]. If Filter is false: compute $s = \text{rsqrt}(|\text{ddx}(UV.x) \cdot \text{ddy}(UV.y) - \text{ddy}(UV.x) \cdot \text{ddx}(UV.y)|)$; set $\text{SSR} = s / \text{TextureSize}$ [S2, unofficial]. Set $\text{pixelSize} = \text{position}.w$; divide $\text{pixelSize}$ by $(\text{objectScale} \cdot \text{mul}((\text{float2x2})\text{projection}, \text{float2}(\text{screenWidth}, \text{screenHeight})))$; compute $\text{SSR} = \text{rsqrt}(\text{dot}(\text{pixelSize}, \text{pixelSize}) \cdot 2) \cdot \text{fontScale}$ [S2, unofficial].

### Center-Precomputed MIP Filter
An anti-aliasing technique that precomputes MIP-filtered parameters at the surfel center during preprocessing to reduce per-pixel rasterization cost while eliminating aliasing artifacts [S3, unofficial]. Stores the resulting MIP-filtered inverse covariance $\Sigma^{-1}_{\text{mip}}$ and normalization factor $\alpha_{\text{norm}}$ once per primitive [S3, unofficial]. During rasterization, loads these four parameters from shared memory [S3, unofficial]. Applies the parameters directly to the intersection coordinates via the quadratic form of equation 6 [S3, unofficial]. Rendering time is 50 ms per frame for the center-precomputed MIP filter, an overhead of only 8 ms (<20%) over the unfiltered baseline of 42 ms [S3, unofficial]. Compared to per-pixel Jacobian evaluation (AA-2DGS), this method is visually indistinguishable but faster (50 ms vs 65 ms per frame) because it avoids computing the full 2x2 Jacobian, its outer product, and matrix inverse at every covered pixel [S3, unofficial].

### Differential Object Filter
An invisible object that makes overlapping volume parts invisible [S4]. In PovRay rendering, it interacts with other objects [S4]. In preview, it interacts only with volume [S4]. Rendering quality must be set quite high because the volume shape becomes complicated rather than a simple box [S4].

### FXAA (Fast Approximate Antialiasing)
An antialiasing method that operates on the final color buffer [S5]. It performs edge detection and applies perceptually correct edge filtering [S5]. It provides antialiasing for both geometry and volume in the composited image [S5]. FXAA is applied to the final composited image, whereas multisampled G-buffer antialiasing is applied during geometry rendering [S5]. They can be combined for improved quality [S5].

### Inverse Diffuse Filter
Applies inverse diffusion with a negative diffusion coefficient to correct z-direction blur in confocal microscopy data [S4]. Works only in preview. Filtered data must be exported to new .df3 files for PovRay rendering [S4].

## Background
Early methods relied on simple box filters for crisp edges in high-resolution volumes, while Gaussian filters were introduced to prevent banding artifacts [S1].
