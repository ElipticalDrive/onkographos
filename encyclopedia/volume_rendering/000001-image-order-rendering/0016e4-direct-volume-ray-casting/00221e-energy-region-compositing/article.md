# Energy Region Compositing

Also called: Energy Compositing

## Overview
Energy Region Compositing is a volume rendering technique that composites multiple energy-specific volumes within a region of interest defined by a magnitude volume [S1, unofficial]. It applies a threshold to energy intensity before compositing, blending colors based on normalized intensities above that threshold [S1, unofficial]. Unlike standard direct volume ray casting which integrates opacity and color along a single scalar field, this method selectively renders energy contributions only where the magnitude volume indicates presence, effectively masking out background noise or irrelevant regions [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   `view_matrix`: A $3 \times 3$ matrix (indices 0:3, 4:7, 8:11) defining camera orientation [S1, unofficial].
    *   `volume`: The primary scalar volume object containing dimensions `dim_x`, `dim_y`, `dim_z` and a method `get_maximum()` [S1, unofficial].
    *   `magnitudeVolume`: A scalar volume defining the region of interest; samples are processed only if the value is non-zero [S1, unofficial].
    *   `energy_volumes`: A dictionary mapping integer energy IDs to `Volume` objects [S1, unofficial].
    *   `image_size`: Integer width and height of the output image (assumed square) [S1, unofficial].
    *   `interactive_mode`: Boolean flag determining step size [S1, unofficial].
*   **Outputs:**
    *   `image`: A flat array of RGBA values (8-bit integers) of size `image_size * image_size * 4` [S1, unofficial].

**Data Structures:**
*   `colorDictionary`: A mapping from energy ID to an RGB color vector. Colors are generated by permuting the list `[1, 0, 0.5, 1]` taken 3 at a time. The first permutation is assigned to ID 0 (black `[0,0,0]`), and subsequent IDs map to subsequent permutations [S1, unofficial].

**Parameters:**
*   `step`: Loop step size for pixel iteration. Set to 20 in the notes, but code snippets show 2 or 10 [S1, unofficial].
*   `threshold`: Energy intensity ratio threshold. Set to 0.3 (30%) [S1, unofficial].

**Numbered Steps:**

1.  **Initialization:** Clear the `image` array to zeros [S1, unofficial]. Extract view vectors: $\mathbf{u} = \text{view\_matrix}[0:3]$, $\mathbf{v} = \text{view\_matrix}[4:7]$, $\mathbf{view} = \text{view\_matrix}[8:11]$ [S1, unofficial]. Calculate `image_center` = `image_size` / 2 and `volume_center` = [`dim_x`/2, `dim_y`/2, `dim_z`/2] [S1, unofficial]. Calculate `diagonal` = $\lfloor \sqrt{3} \cdot \max(\text{dim\_x}, \text{dim\_y}, \text{dim\_z}) / 2 \rfloor + 1$ [S1, unofficial]. Set `step` based on `interactive_mode` [S1, unofficial].

2.  **Pixel Loop:** Iterate over pixel coordinates $(i, j)$ with stride `step` from 0 to `image_size` [S1, unofficial]. Initialize accumulated color components `initial_r`, `initial_g`, `initial_b` to 0 [S1, unofficial].

3.  **Ray Marching:** Iterate along the ray depth $k$ from `diagonal` down to `-diagonal` [S1, unofficial].
    *   Compute voxel coordinates:
        $$ \mathbf{p} = \mathbf{u}(i - \text{image\_center}) + \mathbf{v}(j - \text{image\_center}) + \mathbf{view} \cdot k + \text{volume\_center} $$
        [S1, unofficial]
    *   Sample the `magnitudeVolume` at $\mathbf{p}$ to get value $g$ [S1, unofficial].
    *   If $g \neq 0$:
        *   Initialize `color_voxel` to $[0, 0, 0]$ [S1, unofficial].
        *   Sample the primary `volume` at $\mathbf{p}$. If the value $> 0$:
            *   Iterate through each `key` in `energy_volumes` [S1, unofficial].
            *   Get `intensity_max` for the energy volume (pre-computed global maximum) [S1, unofficial].
            *   Get `energy_intensity` by sampling the specific energy volume at $\mathbf{p}$ [S1, unofficial].
            *   Calculate ratio $r = \text{energy\_intensity} / \text{intensity\_max}$ [S1, unofficial].
            *   If $r > 0.3$:
                *   Get `energy_color` from `colorDictionary[key]` [S1, unofficial].
                *   Update `color_voxel` using blending:
                    $$ \text{color\_voxel} = \text{color\_voxel} \cdot (1 - r) + \text{energy\_color} \cdot r $$
                    [S1, unofficial]
        *   Calculate `color_a` = $\max(\text{color\_voxel})$ [S1, unofficial].
    *   Else ($g = 0$):
        *   `color_voxel` remains $[0, 0, 0]$ and `color_a` is effectively 0 [S1, unofficial].

4.  **Compositing:**
    *   Update accumulated color:
        $$ \text{current\_r} = \text{color\_a} \cdot \text{color\_voxel}[0] + (1 - \text{color\_a}) \cdot \text{initial\_r} $$
        $$ \text{current\_g} = \text{color\_a} \cdot \text{color\_voxel}[1] + (1 - \text{color\_a}) \cdot \text{initial\_g} $$
        $$ \text{current\_b} = \text{color\_a} \cdot \text{color\_voxel}[2] + (1 - \text{color\_a}) \cdot \text{initial\_b} $$
        [S1, unofficial]
    *   Update `initial_r`, `initial_g`, `initial_b` to `current_r`, `current_g`, `current_b` [S1, unofficial].

5.  **Finalization:**
    *   After the ray loop, clamp and convert to 8-bit integers:
        $$ \text{red} = \lfloor \text{current\_r} \cdot 255 \rfloor \text{ if } < 255 \text{ else } 255 $$
        (Same for green and blue) [S1, unofficial].
    *   Set alpha to 255 (fully opaque) [S1, unofficial].
    *   Assign RGBA values to `image[(j * image_size + i) * 4 : (j * image_size + i) * 4 + 4]` [S1, unofficial].

**Pseudocode:**

> **Unverified code.** The code below did not pass a test run against a reference implementation, or no test fits it, so it may contain errors.

```python
import math
from itertools import permutations

def render_energy_region_compositing(view_matrix, volume, magnitude_volume, energy_volumes, image_size, interactive_mode):
    # 1. Initialization
    image = [0] * (image_size * image_size * 4)
    
    # Extract view vectors
    u_vector = view_matrix[0:3]
    v_vector = view_matrix[4:7]
    view_vector = view_matrix[8:11]
    
    image_center = image_size / 2
    volume_center = [volume.dim_x / 2, volume.dim_y / 2, volume.dim_z / 2]
    
    # Calculate diagonal extent
    max_dim = max(volume.dim_x, volume.dim_y, volume.dim_z)
    diagonal = int(math.floor(math.sqrt(3) * max_dim / 2)) + 1
    
    # Step size (notes say 20, code snippets show 2 or 10)
    step = 20 if interactive_mode else 1
    
    # Color dictionary
    perm = list(permutations([1, 0, 0.5, 1], 3))
    ids = list(energy_volumes.keys())
    color_dictionary = {0: [0, 0, 0]}
    for i in range(len(ids)):
        color_dictionary[ids[i]] = list(perm[i])
        
    # Pre-calculate intensity max for each energy volume
    energy_max_intensities = {}
    for key, vol in energy_volumes.items():
        energy_max_intensities[key] = vol.get_maximum()

    # 2. Pixel Loop
    for i in range(0, image_size, step):
        for j in range(0, image_size, step):
            initial_r, initial_g, initial_b = 0.0, 0.0, 0.0
            
            # 3. Ray Marching
            for k in range(diagonal, -diagonal, -1):
                # Compute voxel coordinates
                voxel_cords = [
                    u_vector[0] * (i - image_center) + v_vector[0] * (j - image_center) + view_vector[0] * k + volume_center[0],
                    u_vector[1] * (i - image_center) + v_vector[1] * (j - image_center) + view_vector[1] * k + volume_center[1],
                    u_vector[2] * (i - image_center) + v_vector[2] * (j - image_center) + view_vector[2] * k + volume_center[2]
                ]
                
                # Sample magnitude volume
                g = get_voxel_interpolated(magnitude_volume, voxel_cords[0], voxel_cords[1], voxel_cords[2])
                
                color_voxel = [0.0, 0.0, 0.0]
                
                if g != 0:
                    # Sample primary volume to check if region is active
                    primary_val = get_voxel_interpolated(volume, voxel_cords[0], voxel_cords[1], voxel_cords[2])
                    
                    if primary_val > 0:
                        # Iterate through energy volumes
                        for key in energy_volumes:
                            vol = energy_volumes[key]
                            intensity_max = energy_max_intensities[key]
                            energy_intensity = get_voxel_interpolated(vol, voxel_cords[0], voxel_cords[1], voxel_cords[2])
                            
                            if intensity_max > 0:
                                ratio = energy_intensity / intensity_max
                            else:
                                ratio = 0.0
                                
                            if ratio > 0.3:
                                energy_color = color_dictionary[key]
                                # Blend
                                color_voxel = [
                                    color_voxel[0] * (1 - ratio) + energy_color[0] * ratio,
                                    color_voxel[1] * (1 - ratio) + energy_color[1] * ratio,
                                    color_voxel[2] * (1 - ratio) + energy_color[2] * ratio
                                ]
                
                # Calculate alpha from max component of color_voxel
                color_a = max(color_voxel)
                
                # 4. Compositing
                current_r = color_a * color_voxel[0] + (1 - color_a) * initial_r
                current_g = color_a * color_voxel[1] + (1 - color_a) * initial_g
                current_b = color_a * color_voxel[2] + (1 - color_a) * initial_b
                
                initial_r, initial_g, initial_b = current_r, current_g, current_b
            
            # 5. Finalization
            red = int(math.floor(current_r * 255)) if current_r < 1.0 else 255
            green = int(math.floor(current_g * 255)) if current_g < 1.0 else 255
            blue = int(math.floor(current_b * 255)) if current_b < 1.0 else 255
            alpha = 255 
            
            idx = (j * image_size + i) * 4
            image[idx] = red
            image[idx + 1] = green
            image[idx + 2] = blue
            image[idx + 3] = alpha

    return image

def get_voxel_interpolated(volume, x, y, z):
    # [G] Standard trilinear interpolation using 8 surrounding voxels
    ix, iy, iz = int(math.floor(x)), int(math.floor(y)), int(math.floor(z))
    fx, fy, fz = x - ix, y - iy, z - iz
    
    # Clamp coordinates to volume bounds
    ix = max(0, min(ix, volume.dim_x - 1))
    iy = max(0, min(iy, volume.dim_y - 1))
    iz = max(0, min(iz, volume.dim_z - 1))
    
    # Fetch 8 neighbors
    v000 = volume.get_voxel(ix, iy, iz)
    v100 = volume.get_voxel(ix + 1, iy, iz)
    v010 = volume.get_voxel(ix, iy + 1, iz)
    v110 = volume.get_voxel(ix + 1, iy + 1, iz)
    v001 = volume.get_voxel(ix, iy, iz + 1)
    v101 = volume.get_voxel(ix + 1, iy, iz + 1)
    v011 = volume.get_voxel(ix, iy + 1, iz + 1)
    v111 = volume.get_voxel(ix + 1, iy + 1, iz + 1)
    
    # Trilinear interpolation
    c1 = v000 * (1 - fx) + v100 * fx
    c2 = v010 * (1 - fx) + v110 * fx
    c3 = v001 * (1 - fx) + v101 * fx
    c4 = v011 * (1 - fx) + v111 * fx
    
    r1 = c1 * (1 - fy) + c2 * fy
    r2 = c3 * (1 - fy) + c4 * fy
    
    return r1 * (1 - fz) + r2 * fz
```

**Edge Cases and Pitfalls:**
*   **Zero Intensity Max:** If an energy volume has a maximum intensity of 0, division by zero occurs in the ratio calculation. The pseudocode guards against this with a check `if intensity_max > 0` [S1, unofficial].
*   **Magnitude Volume Zeros:** If the magnitude volume sample is 0, no energy blending occurs for that voxel, and the color remains black/transparent unless handled by the compositing alpha [S1, unofficial].
*   **Step Size Artifacts:** Using a large step size (20) for interactive mode may cause aliasing or missed thin structures [S1, unofficial].
*   **Coordinate System Assumption:** The source implementation adds world-space view vectors to voxel-space volume center coordinates, assuming the view matrix scales to voxel units or the coordinate system is normalized [S1, unofficial]. Arbitrary camera origins require modifying the coordinate formula.

## Operating characteristics
*   **Time Complexity:** $O(W \cdot H \cdot D \cdot E)$, where $W, H$ are image dimensions, $D$ is the ray depth (diagonal), and $E$ is the number of energy volumes. The inner loop iterates over all energy volumes for each active voxel [S1, unofficial].
*   **Memory Complexity:** $O(V + \sum E_i)$, where $V$ is the primary volume size, and $E_i$ are the energy volume sizes. The `colorDictionary` is small [S1, unofficial].
*   **Strengths:** Allows selective visualization of specific energy types within a structural context defined by the magnitude volume. The thresholding (0.3) reduces noise from low-intensity energy contributions [S1, unofficial].
*   **Limitations:** The method does not use standard alpha compositing opacity integration; instead, it uses a max-based alpha (`color_a`) and linear blending of colors, which may not preserve physical light transport accuracy [S1, unofficial]. The fixed threshold and color assignment are arbitrary [S1, unofficial].
