# Radon Integrator
## Overview
The Radon Integrator computes the Radon transform (projection) of a volume by tracing rays through a purely absorptive medium and accumulating attenuation along the path [S1, unofficial]. It serves as a specialized volumetric additive manufacturing (TVAM) integrator that calculates the absorbed dose or optical density projection, distinct from sibling methods like the Corner Integrator which may handle different scattering or boundary conditions [S1, unofficial]. It builds on the TVAM Integrator base class, inheriting projector ray sampling and time sampling capabilities [S1, unofficial].

## How it works
**Inputs and Outputs:**
- Input: Scene geometry (target mesh, vial, projector, sensor), volume density/absorption coefficients (implicitly via medium interaction), configuration parameters (spp, max_depth, transmission_only).
- Output: A tensor representing the projected attenuation (Radon transform) accumulated per pixel.

**Data Structures:**
- `active`: Boolean flag indicating if the ray is still valid and within bounds.
- `inside_target`: Boolean flag tracking if the ray is currently inside the target geometry.
- `active_medium`: Boolean flag tracking if the ray is currently inside a medium that contributes to absorption.
- `throughput`: Scalar float, initial value 1.0, accumulates the product of BSDF weights.
- `L`: Scalar float, initial value 0.0, accumulates the total contribution.
- `t`: Scalar float, initial value 0.0, accumulates distance traveled within the medium.
- `d`: Integer, current ray depth.

**Numbered Steps:**

1.  **Render Initialization**: In the main render loop, suspend automatic differentiation gradients. Prepare the sampler and generate the initial ray. Call the `sample()` function with `ADMode.Primal` to ensure primal values are computed without gradient tracking during the path traversal [S1, unofficial].
2.  **Weighting and Accumulation**: Multiply the result returned by `sample()` by the ray weight. Scatter-reduce this value into the output image tensor using an additive operation (`Add`) [S1, unofficial].
3.  **Sample Initialization**: Inside `sample()`, initialize `active_medium = False`, `inside_target = False`, `throughput = 1.0`, `L = 0.0`, `t = 0.0`, and `d = 0` [S1, unofficial].
4.  **Medium Retrieval**: Get the scattering coefficient $\sigma_s$ and extinction coefficient $\sigma_t$ from the current medium context [S1, unofficial]. Note: The method assumes a purely absorptive medium, implying $\sigma_s$ may be zero or ignored in the final contribution formula [S1, unofficial].
5.  **Ray Tracing Loop**: Loop while `active` is true:
    a.  Intersect the ray with the scene geometry.
    b.  Update `active &= si.is_valid()`, where `si` is the scene intersection [S1, unofficial].
    c.  **Contribution Calculation**: Compute the contribution for the current segment. If the ray hits the target and is in an active medium, the contribution is:
        $$ \text{contrib} = \text{throughput} \times \exp(-\sigma_t \times t) \times (1 - \exp(-\sigma_t \times \text{si}.t)) $$
        This formula assumes the medium is purely absorptive, where $\text{si}.t$ is the distance to the next intersection [S1, unofficial].
    d.  **Accumulation**: If `hit_target` and `active_medium` are true, add `contrib` to `L`. Update `t += si.t` [S1, unofficial].
    e.  **State Update (Inside Target)**: Update `inside_target` state using the XOR-like logic:
        $$ \text{inside\_target} = (\neg \text{inside\_target} \land \text{hit\_target}) \lor (\text{inside\_target} \land \neg \text{hit\_target}) $$
        Note: This logic may cause some rays to leak out of the target volume if the intersection validity is ambiguous [S1, unofficial].
    f.  **BSDF Sampling**: Sample the BSDF at the intersection.
        - If `transmission_only` is true, set the context type mask to `Transmission`.
        - Else, if `depth == 0` and `active`, force refraction sampling to avoid generating useless rays that do not penetrate the volume [S1, unofficial].
    g.  **Throughput and Depth**: Update `throughput *= bs_w` (BSDF weight). Spawn a new ray. Increment `d` for non-target hits. Update `active &= (d < max_depth)` [S1, unofficial].
    h.  **Medium Transition**: Update `active_medium` state:
        $$ \text{active\_medium} = (\text{active\_medium} \land \neg \text{si.is\_medium\_transition}()) \lor (\text{si.is\_medium\_transition}() \land (\text{si.target\_medium}(\text{ray}.d) \neq \text{None})) $$
        This checks if the ray is transitioning between media and if the new target medium is valid [S1, unofficial].

**Pseudocode:**

```python
def radon_integrator_render(scene, sampler, config):
    # Suspend gradients for primal computation
    with dr.no_grad():
        spp = config.get('spp', 4)
        max_depth = config.get('max_depth', 10)
        transmission_only = config.get('transmission_only', False)
        
        output_tensor = dr.zeros(scene.sensor.shape)
        
        for _ in range(spp):
            ray = sampler.next_ray()
            # Call sample with Primal mode
            L = sample_radon(ray, scene, max_depth, transmission_only)
            # Multiply by weight (assumed 1.0 for direct projection in this context)
            weight = 1.0
            # Scatter reduce into output
            dr.scatter_add(output_tensor, ray.index, L * weight)
            
    return output_tensor

def sample_radon(ray, scene, max_depth, transmission_only):
    active = True
    inside_target = False
    active_medium = False
    throughput = 1.0
    L = 0.0
    t = 0.0
    d = 0
    
    while active:
        si = scene.intersect(ray)
        active = active and si.is_valid()
        
        if not active:
            break
            
        # Get medium coefficients
        sigma_s, sigma_t = get_medium_coefficients(si)
        
        # Compute contribution if hitting target and in active medium
        hit_target = si.is_target_hit() # Assumed helper for target mesh
        if hit_target and active_medium:
            contrib = throughput * dr.exp(-sigma_t * t) * (1.0 - dr.exp(-sigma_t * si.t))
            L += contrib
            
        t += si.t
        
        # Update inside_target state
        # Logic: XOR of previous state and hit status
        inside_target = (not inside_target and hit_target) or (inside_target and not hit_target)
        
        # Sample BSDF
        if transmission_only:
            ctx_type_mask = Transmission
        else:
            if d == 0 and active:
                ctx_type_mask = Refraction # Force refraction
            else:
                ctx_type_mask = All
        
        bs_w = sample_bsdf(si, ctx_type_mask)
        throughput *= bs_w
        
        # Spawn new ray
        ray = spawn_new_ray(ray, si, bs_w)
        d += 1
        
        # Update active based on depth
        active = active and (d < max_depth)
        
        # Update active_medium state
        is_transition = si.is_medium_transition()
        new_medium = si.target_medium(ray.d)
        active_medium = (active_medium and not is_transition) or (is_transition and new_medium is not None)
        
    return L
```

**Parameters:**
- `spp`: Samples per pixel. Typical value: 4 [S1, unofficial].
- `max_depth`: Maximum ray depth. Not given in the sources.
- `transmission_only`: Boolean flag to restrict sampling to transmission. Not given in the sources.

**Edge Cases and Pitfalls:**
- The `inside_target` state update logic may cause rays to leak out of the target volume if intersection validity is ambiguous [S1, unofficial].
- Precision issues may arise in the exponential terms $\exp(-\sigma_t \times t)$ for large optical depths [S1, unofficial].

## Subtopics

### [CornerIntegrator](7445-cornerintegrator.md)
Handles volumetric integration using corner-based sampling or different boundary conditions. Choose when corner-based accuracy is preferred over pure ray projection.

## Operating characteristics
- **Time Complexity**: Linear with respect to the number of samples (spp) and ray depth. Each ray traverses the scene geometry and medium.
- **Memory Complexity**: Constant per ray, storing state variables (`active`, `throughput`, `L`, `t`, `d`).
- **Strengths**: Efficient for computing pure absorption projections (Radon transform) without complex scattering calculations.
- **Limitations**: Assumes purely absorptive medium; may suffer from ray leakage due to `inside_target` logic.
- **When to use**: When the goal is to compute the tomographic projection (absorbed dose) for TVAM optimization.
- **When not to use**: When scattering or emission is significant, or when corner-based boundary handling is required.

## Background
The Radon Integrator is part of the Dr. TVAM project, an inverse rendering framework for Tomographic Volumetric Additive Manufacturing [S1, unofficial]. It was developed by researchers at EPFL's Realistic Graphics Lab to optimize printing patterns for 3D printing via volumetric methods [S1, unofficial].
