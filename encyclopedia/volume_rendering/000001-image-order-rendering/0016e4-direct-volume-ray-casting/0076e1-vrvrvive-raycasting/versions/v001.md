# VRVRVive Raycasting

Also called: VRVRVive, Virtual Reality Volume Rendering with the HTC Vive

## Overview
VRVRVive is a two-pass, image-order direct volume raycasting algorithm implemented in a fragment shader, designed specifically for Virtual Reality (VR) rendering on the HTC Vive platform [S1, unofficial]. It solves the performance constraints of real-time VR by integrating Level of Detail (LoD) management, Early Ray Termination (ERT), and Ambient Occlusion (AO) into a single rendering pipeline [S1, unofficial]. Unlike standard raycasting methods, it decouples the ray traversal logic into a normalization pass and a compositing pass, allowing for dynamic step-size adjustment based on depth and explicit culling planes to optimize fragment shader execution [S1, unofficial].

## How it works
The method operates as a two-pass fragment shader program. It requires a 3D volume texture, a 1D transfer function texture, and 2D UVW map textures for the front and back faces of the volume bounding box.

### Inputs and Outputs
**Inputs:**
*   `volume_texture`: `sampler3D`, the scalar volume data.
*   `transferFunctionTex`: `sampler1D`, maps scalar values to RGBA.
*   `back_uvw_map`: `sampler2D`, stores the UVW coordinates of the ray entry point on the back face of the volume.
*   `front_uvw_map`: `sampler2D`, stores the UVW coordinates of the ray exit point on the front face of the volume.
*   Uniforms: `uWindowingMinVal`, `uWindowingRange`, `uStepSize`, `uLodMaxLevel`, `uLodBegin`, `uLodRange`, `ALPHA_SCALE`, `EMISSION_SCALE`, `ABSORPTION_SCALE`, `AMBIENT_OCCLUSION_SCALE`, `AMBIENT_OCCLUSION_RADIUS`, `ERT_THRESHOLD`.

**Outputs (FBO Attachments):**
*   `fragDepth` (location 0): Depth buffer.
*   `fragColor1` to `fragColor4` (locations 1-4): Layered color/depth buffers for compositing.
*   `fragColorDebug` (location 5): Debug visualization.

### Data Structures
The method uses a layered compositing structure in Pass 2. It maintains a fixed-size array of 4 layers:
*   `layerColor[4]`: Stores the accumulated color for each layer.
*   `layerDepth[4]`: Stores the depth threshold for each layer.

### Parameters
*   `ALPHA_SCALE`: Default 20.0. Multiplies the alpha output from the transfer function.
*   `ERT_THRESHOLD`: Default 0.99. Accumulated opacity threshold to terminate ray marching early.
*   `EMISSION_SCALE`: Default 1.0. Scales the emission component of the transfer function.
*   `ABSORPTION_SCALE`: Default 10.0. Scales the absorption coefficient.
*   `AMBIENT_OCCLUSION_SCALE`: Default 2.0.
*   `AMBIENT_OCCLUSION_RADIUS`: Default 2.0. Radius for AO sampling in texture space units.
*   `uWindowingMinVal`: Lower bound for transfer function windowing.
*   `uWindowingRange`: Range for transfer function windowing.
*   `uStepSize`: Base ray sampling step size.
*   `uLodMaxLevel`: Factor controlling LoD degradation intensity.
*   `uLodBegin`: Depth at which LoD begins.
*   `uLodRange`: Depth range over which LoD degrades.

### Steps

#### Pass 1: Normalization and UVW Map Generation
This pass computes the normalized ray parameters and prepares the UVW coordinates for the volume.

1.  Initialize `t = 0.0`.
2.  If `RANDOM_OFFSET` is defined, add `0.002 * 2.0 * rand(passUV)` to `t`.
3.  Loop while `t < 1.0 + (0.5 * parameterStepSize)`:
    a.  Calculate current UVW: `curUVW = mix(startUVW, endUVW, t)`.
    b.  Calculate current distance: `curDistance = mix(startDistance, endDistance, t)`.
    c.  **Level of Detail (LoD)**: If `LEVEL_OF_DETAIL` is defined:
        i.  Calculate `curLod = max(0.0, min(1.0, ((curDistance - uLodBegin) / uLodRange))) * uLodMaxLevel`.
        ii. Update `parameterStepSize` and `distanceStepSize` based on `curLod`.
        iii. Sample volume: `curSample = textureLod(volume_texture, curUVW, curLod).r`.
    d.  Else:
        i.  Sample volume: `curSample = texture(volume_texture, curUVW).r`.
    e.  Store results for Pass 2.

#### Pass 2: Compositing with LoD, ERT, and AO
This pass performs the actual ray marching, transfer function application, and compositing.

1.  Initialize `segmentColor = (0,0,0,0)`, `curAlpha = 0.0`, `curColor = (0,0,0,0)`.
2.  Declare `layerColor[4]` and `layerDepth[4]`.
3.  Set `layerDepth[0..3]` based on `endDistance` and `parameterStepSize`.
4.  Initialize state variables:
    *   `lastDistance = result.firstHit.a`
    *   `lastAlpha = 0.0`
    *   `lastNonZero = 0.0`
    *   `currentLayer = 1`
    *   `numLayers = 4`
    *   `currentLayerThreshold = float(currentLayer) / float(numLayers)`
5.  Initialize `t = 0.0`.
6.  If `RANDOM_OFFSET` is defined, add offset to `t`.
7.  Loop while `t < 1.0 + (0.5 * parameterStepSize)`:
    a.  Calculate `curUVW = mix(startUVW, endUVW, t)` and `curDistance`.
    b.  **Cull Planes**: If `CULL_PLANES` is defined, skip if `curUVW` is outside `uCullMin`/`uCullMax`.
    c.  **Sampling**:
        i.  If `LEVEL_OF_DETAIL` is defined, calculate `curLod` and sample using `textureLod`. Else, sample using `texture`.
        ii. Let `curSample.value` be the sampled scalar.
    d.  **Transfer Function & Color Calculation**:
        i.  If `EMISSION_ABSORPTION_RAW` is defined:
            1.  `sampleEmissionAbsorption = transferFunctionRaw(curSample.value)`.
            2.  Scale RGB by `EMISSION_SCALE`.
            3.  Scale A by `pow(sampleEmissionAbsorption.a * ABSORPTION_SCALE, 2.0)`.
            4.  Calculate `sampleAlpha = 1.0 - exp(-sampleEmissionAbsorption.a * distanceStepSize)`.
            5.  `sampleColor = vec4(sampleEmissionAbsorption.rgb * sampleAlpha, sampleAlpha)`.
        ii. Else:
            1.  Calculate relative value: $rel = (value - uWindowingMinVal) / uWindowingRange$.
            2.  Clamp: $clamped = \max(0.0, \min(1.0, rel))$.
            3.  Get color from 1D texture: $color = texture(transferFunctionTex, clamped)$.
            4.  Adjust Alpha: $color.a *= ALPHA_SCALE * stepSize$.
            5.  Adjust RGB: $color.rgb *= color.a$.
            6.  `sampleColor = color`.
    e.  **Ambient Occlusion (AO)**: If `AMBIENT_OCCLUSION` is defined:
        i.  Sample 8 neighbors (±1 in x, y, z) using radius `AMBIENT_OCCLUSION_RADIUS/1.414 * curStepSize`. Sum occlusion.
        ii. Sample 6 face neighbors (±1 in x, y, z) using radius `AMBIENT_OCCLUSION_RADIUS * curStepSize`. Sum occlusion.
        iii. Apply occlusion to `sampleColor` (implementation detail implied: modulate alpha or color by occlusion factor).
    f.  Increment `t += parameterStepSize`.
    g.  **Early Ray Termination (ERT)**: If `sampleColor.a < 0.00001`, continue to next iteration.
    h.  **Compositing**:
        i.  Update accumulated color and alpha using front-to-back blending:
            $$ \mathbf{C}_{acc} \leftarrow \mathbf{C}_{acc} + (1 - \alpha_{acc}) \cdot \mathbf{c}_i \cdot \alpha_i $$
            $$ \alpha_{acc} \leftarrow \alpha_{acc} + (1 - \alpha_{acc}) \cdot \alpha_i $$
        ii. If `alpha_acc >= ERT_THRESHOLD`, break loop.
    i.  **Layer Management**: Update `layerColor` and `layerDepth` arrays based on `curDistance` and `currentLayerThreshold`.

### Formulas
*   **Transfer Function Mapping**:
    $$ rel = \frac{value - uWindowingMinVal}{uWindowingRange} $$
    $$ clamped = \max(0.0, \min(1.0, rel)) $$
    $$ color = texture(transferFunctionTex, clamped) $$
    $$ color.a = color.a \cdot ALPHA\_SCALE \cdot stepSize $$
    $$ color.rgb = color.rgb \cdot color.a $$

*   **Beer-Lambert Inversion (for EMISSION_ABSORPTION_RAW mode)**:
    $$ T = \exp(-A \cdot z) $$
    $$ C = E \cdot (1.0 - T) $$
    Where $A$ is the absorption coefficient, $z$ is the distance, $T$ is transmission, $E$ is emission, and $C$ is the resulting color contribution.

*   **Alpha Correction**:
    $$ sampleAlpha = 1.0 - \exp(-sampleEmissionAbsorption.a \cdot distanceStepSize) $$

### Edge Cases and Pitfalls
*   **LoD Approximation**: The Level of Detail calculation is noted as a "bad approximation" in the source comments, potentially leading to visual artifacts or inconsistent sampling rates [S1, unofficial].
*   **Cull Planes Performance**: The cull planes check uses `any(lessThan(...))`, which is described as "lazy" and may have performance implications or logic quirks depending on vectorization [S1, unofficial].
*   **AO Sampling**: The source code for Ambient Occlusion cuts off, leaving the exact application of the occlusion sum to `sampleColor` implied but not explicitly defined [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: Linear with respect to the number of samples per ray, which is determined by the volume depth and the step size. The step size is dynamically adjusted by LoD, potentially reducing complexity for distant samples.
*   **Memory Complexity**: Low. Requires storage for the volume texture, transfer function, and a small fixed-size array for layer compositing (4 layers).
*   **Performance**: Optimized for VR hardware (HTC Vive) using fragment shaders. The two-pass approach allows for efficient UVW map generation and compositing.
*   **Strengths**: Integrates LoD, ERT, and AO directly into the raycasting loop. Supports culling planes.
*   **Limitations**: LoD is a "bad approximation". AO implementation details are incomplete in the source. Relies on specific texture maps (front/back UVW).
