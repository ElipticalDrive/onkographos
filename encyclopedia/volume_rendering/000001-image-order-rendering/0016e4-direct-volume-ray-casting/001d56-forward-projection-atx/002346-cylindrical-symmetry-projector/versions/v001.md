# Cylindrical Symmetry Projector

Also called: Abel Transform

## Overview
The Cylindrical Symmetry Projector is a forward/back-projector pair designed for objects possessing cylindrical symmetry [S1, S2, unofficial]. It serves as a specialized case of the general forward projector, reducing computational complexity by exploiting geometric constraints [S1, S2, unofficial]. The Abel Transform is identified as a specific instance of this method applied to parallel-beam geometries [S1, S2, unofficial].

## How it works
**Inputs:** A 3D volume $V(x, y, z)$ assumed to have cylindrical symmetry around the $z$-axis.
**Outputs:** 2D projection data $P(r, z)$ (forward) or updated volume voxels (backprojection).

**Data Structures:**
The input volume is represented in cylindrical coordinates $(r, \theta, z)$. Due to symmetry, the value is independent of $\theta$. The data structure is a 2D array $V_{cyl}(r, z)$ of size $N_r \times N_z$.
*   $r$: Radial coordinate, $r \in [0, R_{max}]$.
*   $z$: Axial coordinate, $z \in [Z_{min}, Z_{max}]$.

**Forward Projection (Abel Transform):**
For parallel-beam geometry, the projection $P(r, z)$ at radial distance $r$ from the axis is computed by integrating the volume density along the chord at that radius. The formula is:
$$ P(r, z) = 2 \int_{r}^{R_{max}} \frac{V_{cyl}(\rho, z) \cdot \rho}{\sqrt{\rho^2 - r^2}} d\rho $$
Where:
*   $P(r, z)$ is the projection value at radius $r$ and height $z$.
*   $V_{cyl}(\rho, z)$ is the volume density at radius $\rho$ and height $z$.
*   $R_{max}$ is the maximum radius of the object.

**Backprojection:**
The backprojection operation reconstructs the volume from the projections. For the Abel transform, this involves an inverse integral operation. Given $P(r, z)$, the volume density is recovered via:
$$ V_{cyl}(r, z) = -\frac{1}{\pi} \int_{r}^{R_{max}} \frac{dP(\rho, z)}{d\rho} \frac{1}{\sqrt{\rho^2 - r^2}} d\rho $$
In discrete implementations, numerical differentiation and integration are required [G].

**Parameters:**
*   $N_r$: Number of radial samples. Typical values depend on resolution requirements.
*   $N_z$: Number of axial samples.
*   $R_{max}$: Maximum radius of the symmetric object.

**Edge Cases and Pitfalls:**
*   **Singularity at $r = \rho$:** The term $\sqrt{\rho^2 - r^2}$ approaches zero as $\rho \to r$. Numerical integration methods must handle this integrable singularity carefully (e.g., using Gauss-Chebyshev quadrature or specialized singular integral techniques) [G].
*   **Boundary Conditions:** The integration limit $R_{max}$ must be correctly identified. If the object does not extend to $R_{max}$, the upper limit should be the actual object radius $R_{obj}(z)$ [G].
*   **Discretization Error:** Naive Riemann summation can introduce significant errors due to the singularity. High-order quadrature is recommended.

**Pseudocode (Forward Projection):**
```python
def forward_project_abel(V_cyl, r_samples, z_samples):
    """
    Computes the Abel transform (forward projection) for a cylindrically symmetric volume.
    
    Args:
        V_cyl: 2D array of shape (N_r, N_z), representing V(r, z).
        r_samples: Array of radial positions for the projection output.
        z_samples: Array of axial positions for the projection output.
        
    Returns:
        P: 2D array of shape (len(r_samples), len(z_samples)).
    """
    N_r = V_cyl.shape[0]
    N_z = V_cyl.shape[1]
    dr = r_samples[1] - r_samples[0] # Assuming uniform sampling for simplicity
    P = zeros((len(r_samples), len(z_samples)))
    
    for i, r in enumerate(r_samples):
        for j, z in enumerate(z_samples):
            # Integral from r to R_max
            # Using a simple trapezoidal rule with singularity handling [G]
            # In practice, use a specialized quadrature for 1/sqrt(x)
            integral_sum = 0.0
            num_steps = N_r - int(r / dr)
            
            # Iterate rho from r to R_max
            for k in range(num_steps):
                rho = r + k * dr
                if rho >= r_samples[-1]: # R_max
                    break
                
                # Avoid division by zero at rho = r
                if rho == r:
                    weight = 0.0 # Or handle via limit
                else:
                    weight = rho / sqrt(rho**2 - r**2)
                
                # Trapezoidal weight adjustment for singularity [G]
                # Standard trapezoidal rule is inaccurate here. 
                # A robust implementation would use Gauss-Chebyshev.
                # Placeholder for robust quadrature:
                integral_sum += V_cyl[int(rho/dr), j] * weight * dr
                
            P[i, j] = 2 * integral_sum
            
    return P
```

## Subtopics

### Abel Transform
The specific case of the Cylindrical Symmetry Projector for parallel-beam geometries. It is chosen when the object is strictly cylindrically symmetric and the acquisition geometry is parallel. See [Abel Transform](abel-transform.md).

## Operating characteristics
*   **Time Complexity:** $O(N_r \cdot N_z \cdot N_r)$ for naive integration, or $O(N_r \cdot N_z \log N_r)$ with FFT-based methods [G]. Significantly faster than general 3D forward projection ($O(N_r^2 \cdot N_z)$ or higher depending on ray casting).
*   **Memory Complexity:** $O(N_r \cdot N_z)$ for the symmetric volume representation, compared to $O(N_r^2 \cdot N_z)$ for a full 3D volume.
*   **Strengths:** High computational efficiency for symmetric objects; reduced memory footprint.
*   **Limitations:** Only applicable to objects with perfect cylindrical symmetry; sensitive to symmetry violations; singularities in integration require careful numerical handling.
*   **When to use:** Tomographic reconstruction or projection of objects like cylinders, pipes, or biological structures with rotational symmetry.
*   **When not to use:** Asymmetric objects or complex geometries without symmetry.

## Background
The Cylindrical Symmetry Projector and the Abel Transform have roots in classical tomography and spectroscopy. The Abel Transform is historically used in plasma physics and astrophysics to reconstruct spherically or cylindrically symmetric distributions from line-of-sight projections [S1, S2, unofficial]. Recent implementations in differentiable programming frameworks, such as the one by Champley & Maddox (2021), have integrated these projectors into differentiable forward projector pipelines for X-ray CT, enabling gradient-based optimization for symmetric objects [S1, S2, unofficial].
