# Forward Projection (aTx)

Also called: Fan Beam Projection, Parallel Beam Projection, X-ray projection, aTx

## Overview
Forward Projection (aTx) is a volume rendering composition scheme where interpolated samples along a ray are simply summed to produce an image [S1]. It solves the problem of generating 2D projections from 3D volumetric data by mimicking the physical process of X-ray attenuation, where the total signal is the integral of density along the ray path [S1]. Unlike alpha blending, which preserves depth cues through opacity accumulation, Forward Projection loses depth information, making it ideal for visualizing high-density structures like bones or vessels where relative depth is less critical than total integrated intensity [S1].

## How it works
**Inputs:**
- A 3D volume $V$ (scalar field, e.g., density or attenuation coefficient).
- A set of ray parameters defining the projection geometry (origin, direction, sampling interval $\Delta s$).
- For each pixel, a ray defined by origin $\mathbf{o}$ and direction $\mathbf{d}$.

**Outputs:**
- A 2D projection image $P$ where each pixel value $P_{ij}$ is the sum of interpolated volume values along the corresponding ray.

**Data Structures:**
- The volume $V$ is typically stored as a 3D array or grid.
- The accumulator for each ray is a scalar initialized to 0.

**Steps:**
1. For each pixel $(i, j)$ in the output image:
2. Define the ray $\mathbf{r}(s) = \mathbf{o}_{ij} + s \cdot \mathbf{d}_{ij}$, where $s$ ranges from the near clipping plane to the far clipping plane.
3. Initialize the accumulator $A = 0$.
4. Iterate through samples $k$ along the ray at positions $s_k$:
   a. Compute the 3D world position $\mathbf{p}_k = \mathbf{r}(s_k)$.
   b. Sample the volume value $v_k = V(\mathbf{p}_k)$ using interpolation (e.g., trilinear).
   c. Update the accumulator: $A \leftarrow A + v_k \cdot \Delta s$.
5. Assign the final accumulator value to the pixel: $P_{ij} = A$.

**Formula:**
The discrete approximation of the line integral is:
$$
P_{ij} = \sum_{k=1}^{N} v_k \cdot \Delta s
$$
where $v_k$ is the interpolated volume value at sample $k$, and $\Delta s$ is the step size along the ray [S1].

**Parameters:**
- $\Delta s$: Sampling interval. Typical values depend on the volume resolution and desired accuracy; often set to the voxel size or a fraction thereof [G].

**Edge Cases and Pitfalls:**
- **Loss of Depth Information:** Since only the sum is stored, occlusion and depth ordering are not represented [S1].
- **Aliasing:** If $\Delta s$ is too large relative to the frequency content of the volume, artifacts may appear.
- **Boundary Conditions:** Rays that do not intersect the volume should return 0 or a background value.

## Subtopics

### [Cylindrical Symmetry Projector](3005-cylindrical-symmetry-projector.md)
The Cylindrical Symmetry Projector is a forward and back projector pair designed for objects possessing cylindrical symmetry, serving as a specialized case of the Forward Projection (aTx) method. It solves the problem of computing line integrals through axisymmetric volumes by reducing the 3D integration to a 1D radial problem, specifically implementing the Abel Transform for parallel-beam geometries. Unlike general 3D projectors, it exploits rotational invariance to achieve significant computational efficiency, distinguishing it from siblings like Analytic 3D Gaussian Ray Tracing for Tomography which handle arbitrary 3D distributions without symmetry assumptions.

### [Analytic 3D Gaussian Ray Tracing for Tomography](3017-analytic-3d-gaussian-ray-tracing-for-tomography.md)
This method replaces the local affine approximation of splatting with exact ray tracing to compute line integrals through 3D Gaussian primitives analytically. It solves the problem of quantitative accuracy degradation and geometric inflexibility in tomographic reconstruction, specifically addressing nonlinear corrections like arc-correction in PET scanners. Unlike splatting-based pipelines which project into 2D screen space, this approach directly computes ray-primitive intersections, avoiding the assumption of non-overlapping Gaussians.

### CT Initialization via Fan Beam Ray Transform and FBP
This variant initializes CT reconstruction by computing a reference image via Fan beam ray transform and filtered back projection (FBP), then creates a sparse sinogram by subsampling and resizing [S3, unofficial].
**Steps:**
1. Convert input image to CPU numpy array.
2. Initialize sinogram, sparse_sinogram, and ori_img arrays with shape [batch, 720, 720].
3. For each batch element: compute sinogram via Fan_ray_trafo(img[i]).
4. Compute reference image ori_img[i] via Fan_FBP(sinogram[i]).
5. Store sinogram max value.
6. Subsample sinogram along first axis with stride r: t = np.copy(sinogram[i,::r,:]).
7. Resize t to [720, 720] using cv2.resize and store in sparse_sinogram.
**Parameters:**
- r: Subsampling stride for the sinogram along the angular/detector axis.
**Layout:**
- Output arrays: ori_img, sparse_sinogram, sinogram all have shape [batch, 720, 720] and dtype float32. sinogram_max has shape [batch, 1].

## Operating characteristics
- **Time Complexity:** $O(N \cdot M)$, where $N$ is the number of pixels and $M$ is the number of samples per ray.
- **Memory Complexity:** $O(V)$ for the volume storage, $O(N)$ for the output image.
- **Performance:** Generally faster than alpha blending because it avoids branching and complex accumulation logic. It is highly parallelizable.
- **Strengths:** Simple implementation, fast computation, good for visualizing dense structures.
- **Limitations:** No depth information, no transparency effects, sensitive to sampling density.
- **When to use:** When depth cues are not required, and the goal is to visualize the total integrated density (e.g., bone visualization in CT).
- **When not to use:** When transparency, occlusion, or depth perception is important.

## Background
Forward Projection is a fundamental technique in medical imaging and computer graphics, rooted in the physics of X-ray attenuation. It is widely used in Computed Tomography (CT) for generating projection data for reconstruction algorithms like Filtered Back Projection (FBP) [S1]. The method is also known as X-ray projection or aTx (attenuation transform) in the context of volume rendering [S1].
