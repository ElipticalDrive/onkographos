# Forward Raymarching Volume Rendering

Also called: Gradient-based Phong Volume Rendering, MIP/ISO Volume Rendering, Three.js Volume Shader

## Overview
Forward Raymarching Volume Rendering is a direct volume ray casting technique implemented in the Three.js library that samples a 3D texture along view rays to support two distinct rendering modes: Maximum Intensity Projection (MIP) and threshold-based isosurface rendering with gradient-based Phong lighting [S1, unofficial]. It differs from standard front-to-back compositing by either accumulating the single maximum intensity value along the ray (MIP) or terminating early upon crossing a specific density threshold to compute surface lighting (ISO) [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Input Volume**: A 3D texture (`u_data`) of type `Data3DTexture` with format `RGBAFormat` and type `UnsignedByteType` [S1, unofficial].
*   **Uniforms**:
    *   `u_size` (`vec3`): Dimensions of the volume in voxels [S1, unofficial].
    *   `u_renderstyle` (`int`): 0 for MIP, 1 for ISO [S1, unofficial].
    *   `u_renderthreshold` (`float`): The threshold value for ISO mode [S1, unofficial].
    *   `u_clim` (`vec2`): Clipping limits for the colormap in ISO mode [S1, unofficial].
    *   `u_cmdata` (`sampler2D`): Colormap texture used in ISO mode [S1, unofficial].
*   **Varyings**: `v_position` (back face position), `v_nearpos`, `v_farpos` (clipping plane positions) [S1, unofficial].
*   **Output**: `gl_FragColor` (`vec4`) containing the final RGBA color [S1, unofficial].

**Data Structures and Constants**
*   `MAX_STEPS`: Hard-coded integer limit for the raymarching loop to satisfy WebGL 1 constraints. Typical values are 887 for $512^3$ volumes and 1774 for $1024^3$ volumes [S1, unofficial].
*   `REFINEMENT_STEPS`: Integer constant, typically 4, determining sub-steps for refinement [S1, unofficial].
*   `relative_step_size`: Float constant, typically 1.0, controlling the step length in world units before normalization [S1, unofficial].
*   Lighting constants: `ambient_color` (default `vec4(0.2, 0.4, 0.2, 1.0)`), `diffuse_color` (default `vec4(0.8, 0.2, 0.2, 1.0)`), `specular_color` (default `vec4(1.0, 1.0, 1.0, 1.0)`), `shininess` (default 32) [S1, unofficial].

**Sampling Function**
The scalar value is retrieved from the RGB channels of the volume texture using luminance weights, ignoring the alpha channel [S1, unofficial]:
$$
\text{val} = 0.2125 \cdot R + 0.7154 \cdot G + 0.0721 \cdot B
$$
where $R, G, B$ are the sampled texture components [S1, unofficial].

**Algorithm Steps**

1.  **Ray Initialization**:
    *   Compute the view direction: $\mathbf{v} = \text{normalize}(\mathbf{o}_{near} - \mathbf{o}_{far})$ [S1, unofficial].
    *   Calculate the distance to the front surface of the volume box. The starting position $\mathbf{front}$ is calculated by clamping the dot product of the view ray and the back face position against the box boundaries defined by `u_size` [S1, unofficial]:
        $$
        \text{distance} = \max \left( \text{dot}(\mathbf{o}_{near} - \mathbf{p}_{back}, \mathbf{v}), \min \left( \frac{-0.5 - p_{back,x}}{v_x}, \frac{u_{size,x} - 0.5 - p_{back,x}}{v_x} \right) \right)
        $$
        (Repeated for y and z axes) [S1, unofficial].
        $$
        \mathbf{front} = \mathbf{p}_{back} + \mathbf{v} \cdot \text{distance}
        $$
    *   Calculate the number of steps: $N = \lfloor -\text{distance} / \text{relative\_step\_size} + 0.5 \rfloor$. If $N < 1$, discard the fragment [S1, unofficial].
    *   Compute the step vector in texture coordinates: $\mathbf{s} = \frac{\mathbf{p}_{back} - \mathbf{front}}{u_{size} \cdot N}$ [S1, unofficial].
    *   Compute the starting location in texture coordinates: $\mathbf{loc}_{start} = \frac{\mathbf{front}}{u_{size}}$ [S1, unofficial].

2.  **Mode Selection**:
    *   If `u_renderstyle` is 0, execute `cast_mip`.
    *   If `u_renderstyle` is 1, execute `cast_iso` [S1, unofficial].

3.  **MIP Mode (`cast_mip`)**:
    *   Initialize `max_val` to $-10^6$ and `max_i` to 100 [S1, unofficial].
    *   Loop `iter` from 0 to `MAX_STEPS` - 1:
        *   If `iter >= N`, break [S1, unofficial].
        *   Sample `val = sample1(loc)` [S1, unofficial].
        *   If `val > max_val`, update `max_val = val` and `max_i = iter` [S1, unofficial].
        *   Advance `loc += s` [S1, unofficial].
    *   **Refinement**:
        *   Set `iloc = start_loc + s \cdot (max_i - 0.5)` [S1, unofficial].
        *   Set `istep = s / REFINEMENT_STEPS` [S1, unofficial].
        *   Loop `i` from 0 to `REFINEMENT_STEPS` - 1:
            *   `max_val = max(max_val, sample1(iloc))` [S1, unofficial].
            *   `iloc += istep` [S1, unofficial].
    *   **Output**: Set `gl_FragColor` to the RGB value sampled at `iloc` from the volume texture `u_data` [S1, unofficial].

4.  **ISO Mode (`cast_iso`)**:
    *   Initialize `gl_FragColor = vec4(0.0)` [S1, unofficial].
    *   Compute `low_threshold = u_renderthreshold - 0.02 \cdot (u_clim[1] - u_clim[0])` [S1, unofficial].
    *   Loop `iter` from 0 to `MAX_STEPS` - 1:
        *   If `iter >= N`, break [S1, unofficial].
        *   Sample `val = sample1(loc)` [S1, unofficial].
        *   If `val > low_threshold`:
            *   **Refinement**:
                *   Set `iloc = loc - 0.5 \cdot s` [S1, unofficial].
                *   Set `istep = s / REFINEMENT_STEPS` [S1, unofficial].
                *   Loop `i` from 0 to `REFINEMENT_STEPS` - 1:
                    *   `val = sample1(iloc)` [S1, unofficial].
                    *   If `val > u_renderthreshold`:
                        *   Compute lighting using `add_lighting(val, iloc, dstep, view_ray)` where `dstep = 1.5 / u_size` [S1, unofficial].
                        *   Assign result to `gl_FragColor` and return [S1, unofficial].
                    *   `iloc += istep` [S1, unofficial].
        *   Advance `loc += s` [S1, unofficial].

5.  **Lighting (`add_lighting`)**:
    *   **Gradient Calculation**: Approximate the gradient $\mathbf{N}$ using central differences along each axis [S1, unofficial]:
        $$
        N_x = \text{sample1}(\mathbf{loc} + \mathbf{s} \cdot (-0.5, 0, 0)) - \text{sample1}(\mathbf{loc} + \mathbf{s} \cdot (0.5, 0, 0))
        $$
        (Similarly for $N_y$ and $N_z$) [S1, unofficial].
    *   Compute magnitude $g_m = \|\mathbf{N}\|$ and normalize $\mathbf{N} = \mathbf{N} / g_m$ [S1, unofficial].
    *   **Normal Flipping**: Flip the normal to point towards the viewer [S1, unofficial]:
        $$
        N_{select} = \text{float}(\text{dot}(\mathbf{N}, \mathbf{v}) > 0.0)
        $$
        $$
        \mathbf{N} = (2.0 \cdot N_{select} - 1.0) \cdot \mathbf{N}
        $$
    *   **Phong Shading**: Compute lighting with a single light aligned with the view direction $\mathbf{L} = \mathbf{v}$ [S1, unofficial]:
        *   Lambertian term: $L_{amb} = \max(\text{dot}(\mathbf{N}, \mathbf{L}), 0.0)$ [S1, unofficial].
        *   Specular term: $\mathbf{H} = \text{normalize}(\mathbf{L} + \mathbf{v})$, $S_{pec} = \max(\text{dot}(\mathbf{H}, \mathbf{N}), 0.0)^{\text{shininess}}$ [S1, unofficial].
        *   Final color: $\mathbf{C}_{final} = \mathbf{C}_{tex} \cdot (\mathbf{C}_{amb} + \mathbf{C}_{diff} \cdot L_{amb}) + \mathbf{C}_{spec} \cdot S_{pec}$ [S1, unofficial].
        *   Alpha: $\alpha_{final} = \alpha_{tex}$ [S1, unofficial].

**Pseudocode**

```python
# Constants
MAX_STEPS = 887  # Adjust based on volume size
REFINEMENT_STEPS = 4
RELATIVE_STEP_SIZE = 1.0
LUMINANCE_WEIGHTS = vec3(0.2125, 0.7154, 0.0721)

def sample_luminance(texcoords, u_data):
    """Sample RGB and compute luminance."""
    rgb = texture(u_data, texcoords).rgb
    return dot(rgb, LUMINANCE_WEIGHTS)

def cast_mip(start_loc, step, nsteps, view_ray, u_data, u_clim, u_cmdata):
    max_val = -1e6
    max_i = 100
    loc = start_loc
    
    # Main Raymarch Loop
    for iter in range(MAX_STEPS):
        if iter >= nsteps:
            break
        
        val = sample_luminance(loc, u_data)
        if val > max_val:
            max_val = val
            max_i = iter
        
        loc += step

    # Refinement
    iloc = start_loc + step * (max_i - 0.5)
    istep = step / REFINEMENT_STEPS
    for i in range(REFINEMENT_STEPS):
        val = sample_luminance(iloc, u_data)
        if val > max_val:
            max_val = val
        iloc += istep

    # Output RGB from texture
    return texture(u_data, iloc)

def cast_iso(start_loc, step, nsteps, view_ray, u_data, u_renderthreshold, u_clim):
    gl_FragColor = vec4(0.0)
    dstep = 1.5 / u_size
    low_threshold = u_renderthreshold - 0.02 * (u_clim[1] - u_clim[0])
    loc = start_loc
    
    # Main Raymarch Loop
    for iter in range(MAX_STEPS):
        if iter >= nsteps:
            break
        
        val = sample_luminance(loc, u_data)
        
        if val > low_threshold:
            # Refinement for precise threshold crossing
            iloc = loc - 0.5 * step
            istep = step / REFINEMENT_STEPS
            for i in range(REFINEMENT_STEPS):
                val = sample_luminance(iloc, u_data)
                if val > u_renderthreshold:
                    # Compute Lighting
                    color = add_lighting(val, iloc, dstep, view_ray, u_data)
                    gl_FragColor = color
                    return
                iloc += istep
        
        loc += step

def add_lighting(val, loc, step, view_ray, u_data):
    # Gradient Calculation
    N = vec3(0.0)
    N.x = sample_luminance(loc + vec3(-step.x, 0, 0), u_data) - sample_luminance(loc + vec3(step.x, 0, 0), u_data)
    N.y = sample_luminance(loc + vec3(0, -step.y, 0), u_data) - sample_luminance(loc + vec3(0, step.y, 0), u_data)
    N.z = sample_luminance(loc + vec3(0, 0, -step.z), u_data) - sample_luminance(loc + vec3(0, 0, step.z), u_data)
    
    gm = length(N)
    if gm == 0:
        return vec4(0.0)
    
    N = normalize(N)
    
    # Flip normal to point towards viewer
    Nselect = float(dot(N, view_ray) > 0.0)
    N = (2.0 * Nselect - 1.0) * N
    
    # Phong Lighting
    L = view_ray  # Light aligned with view
    V = -view_ray # View direction (for half vector, though L=V simplifies H)
    
    # Note: In the source, H = normalize(L+V). If L=view_ray and V=view_ray (from fragment shader context where V is often view dir),
    # the source code snippet says: H = normalize(L+V). 
    # In the provided snippet: "H = normalize(L+V)" where L is light dir.
    # The snippet implies L is aligned with view direction.
    
    H = normalize(L + view_ray) # Assuming L=view_ray based on "single light aligned with view direction"
    
    lambertTerm = clamp(dot(N, L), 0.0, 1.0)
    specularTerm = pow(max(dot(H, N), 0.0), 32.0) # Default shininess
    
    # Colors from uniforms
    ambient = vec4(0.2, 0.4, 0.2, 1.0)
    diffuse = vec4(0.8, 0.2, 0.2, 1.0)
    specular = vec4(1.0, 1.0, 1.0, 1.0)
    
    # Get base color from texture
    tex_color = texture(u_data, loc)
    
    final_color = tex_color.rgb * (ambient.rgb + diffuse.rgb * lambertTerm) + specular.rgb * specularTerm
    final_alpha = tex_color.a
    
    return vec4(final_color, final_alpha)
```

**Edge Cases and Pitfalls**
*   **WebGL 1 Loop Constraints**: WebGL 1 does not allow comparing loop indices with non-constant expressions. The implementation uses a hard-coded `MAX_STEPS` and an explicit `break` condition (`iter >= nsteps`) inside the loop [S1, unofficial].
*   **Luminance Thresholding**: Using luminance for thresholding in ISO mode can break original threshold behavior when switching to direct RGB sampling, causing the threshold to have no impact and resulting in dark artifacts due to incorrect luminance weighting or alpha handling [S1, unofficial].
*   **Step Size**: If `nsteps < 1`, the fragment is discarded, potentially causing holes in the rendering for very small volumes or distant cameras [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: $O(N \cdot R)$, where $N$ is the number of pixels and $R$ is the number of steps per ray (bounded by `MAX_STEPS`). The refinement step adds a constant overhead.
*   **Memory Complexity**: $O(1)$ per fragment, excluding the storage of the 3D texture and colormap [S1, unofficial].
*   **Performance**: Performance is limited by the hard-coded `MAX_STEPS` and the cost of 3D texture sampling and gradient calculations. Typical values for `MAX_STEPS` are 887 for $512^3$ volumes and 1774 for $1024^3$ volumes [S1, unofficial].
*   **Strengths**: Simple implementation; supports both MIP and ISO modes; gradient-based lighting provides surface-like appearance in ISO mode [S1, unofficial].
*   **Limitations**: WebGL 1 compatibility constraints (hard-coded loop limits); luminance-based sampling may not represent color accurately for all data types; no accumulation of transparency (binary-like behavior in ISO, max in MIP) [S1, unofficial].
