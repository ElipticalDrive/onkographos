# Spherical Harmonics Approximation

Also called: SH Approximation, Spherical Harmonics Basis Approximation

## Overview
Spherical Harmonics (SH) Approximation is a technique to approximate a spherical function $f(\omega)$ using a subset of spherical harmonics basis functions to enable efficient and differentiable computation for inverse problems, avoiding expensive Monte Carlo integration [S1]. It sets itself apart from direct Monte Carlo methods by precomputing transfer matrices and using linear algebra operations (dot products and convolutions) to evaluate integrals of products of functions, such as those found in rendering equations [S1]. Unlike general SH applications that might focus on storage, this method specifically targets the computational efficiency of the *product* of functions (e.g., visibility $\times$ lighting) within an inverse problem context [S1].

## How it works
**Inputs and Outputs:**
*   **Input:** A spherical function $f(\omega)$ (e.g., radiance, visibility, or hemisphere response) defined over the domain $\Omega$ (the unit sphere).
*   **Output:** A coefficient vector $\mathbf{f} \in \mathbb{R}^n$ representing the SH approximation, and optionally the reconstructed function $\tilde{f}(\omega)$ at specific directions.

**Data Structures:**
*   **Coefficient Vector:** A 1D array of size $n = (L+1)^2$, where $L$ is the maximum SH degree. The index $i$ linearizes the degree $\ell$ and order $m$ using the mapping:
    $$i = \ell^2 + \ell + m$$
    where $\ell \in \{0, \dots, L\}$ and $m \in \{-\ell, \dots, \ell\}$ [S1, Parent].
*   **Transfer Matrix:** A 3D tensor $C$ of size $n \times n \times n$, where $C_{ijk} = \int_{\Omega} y_i(\omega)y_j(\omega)y_k(\omega) d\omega$ [S1]. This matrix is precomputed and static for a given basis [S1].

**Parameters:**
*   **Bandwidth $n$:** The number of coefficients. A value of $n=8$ is cited as providing good low-frequency approximations for typical inverse problem scenarios [S1]. Higher bandwidths increase accuracy but also computational cost [S1].

**Steps:**

1.  **Projection (Coefficient Extraction):**
    Compute the SH coefficients $\mathbf{f}$ for a given spherical function $f(\omega)$ by solving the integral:
    $$f_i = \int_{\Omega} f(\omega)y_i(\omega)d\omega$$
    where $y_i(\omega)$ are the real-valued SH basis functions [S1, Parent].
    *   *Note:* In the context of the source method, integrals for environment maps ($L$) are solved using numerical integration at initialization [S1]. Integrals for geometry-dependent terms like the hemisphere response ($H(x)$) are handled via rotation matrices to maintain differentiability [S1].

2.  **Reconstruction:**
    Evaluate the approximated signal $\tilde{f}(\omega)$ at a direction $\omega$ using the dot product of coefficients and basis functions:
    $$\tilde{f}(\omega) = \sum_{i=1}^{n} f_i y_i(\omega)$$
    [S1, Parent].

3.  **Integral of Product:**
    Compute the integral of the product of two approximated functions $\tilde{a}(\omega)$ and $\tilde{b}(\omega)$ as the dot product of their coefficient vectors:
    $$\int_{\Omega} \tilde{a}(\omega)\tilde{b}(\omega)d\omega = \mathbf{a} \cdot \mathbf{b}$$
    [S1, Parent].

4.  **Product Convolution (SH Projection of Multiplication):**
    Compute the SH coefficients of the product of two functions, denoted as $\mathbf{a} * \mathbf{b}$, using the precomputed transfer matrix $C$:
    $$(\mathbf{a} * \mathbf{b})_i = \sum_{j=1}^{n} \sum_{k=1}^{n} C_{ijk} a_j b_k$$
    [S1, Parent].

5.  **Rendering Equation Evaluation (Example Application):**
    To compute outgoing radiance $B(x)$ for a point $x$ with albedo $a(x)$, visibility $\mathbf{V}(x)$, and lighting $\mathbf{L}$, use the hemisphere response $\mathbf{H}(x)$:
    $$B(x) = a(x) \left( \mathbf{L} \cdot (\mathbf{V}(x) * \mathbf{H}(x)) \right)$$
    [S1]. Here, $\mathbf{V}(x) * \mathbf{H}(x)$ computes the SH coefficients of the product of visibility and hemisphere response, which is then dotted with lighting coefficients [S1].

**Pseudocode:**

```python
import numpy as np

def compute_sh_coefficients(function_samples, basis_functions, n):
    """
    Projects a spherical function into SH coefficients.
    function_samples: array of shape (num_samples,) containing f(omega)
    basis_functions: array of shape (num_samples, n) containing y_i(omega)
    n: number of SH coefficients (bandwidth)
    Returns: vector f of shape (n,)
    """
    # f_i = integral(f(omega) * y_i(omega))
    # Approximated via numerical integration (e.g., Monte Carlo or quadrature)
    # weights: array of shape (num_samples,) representing integration weights
    weights = np.ones(len(function_samples)) / len(function_samples) # Placeholder for specific quadrature
    
    # Dot product of weighted basis functions with function values
    f = basis_functions.T @ (function_samples * weights)
    return f

def reconstruct_sh_signal(coefficients, basis_functions):
    """
    Reconstructs the signal from SH coefficients.
    coefficients: vector of shape (n,)
    basis_functions: array of shape (num_samples, n)
    Returns: array of shape (num_samples,) containing f_tilde(omega)
    """
    return basis_functions @ coefficients

def sh_convolution(a, b, transfer_matrix, n):
    """
    Computes the SH coefficients of the product of two functions.
    a, b: vectors of shape (n,)
    transfer_matrix: tensor of shape (n, n, n)
    Returns: vector of shape (n,)
    """
    # (a * b)_i = sum_j sum_k C_ijk * a_j * b_k
    # Using Einstein summation for efficiency
    result = np.einsum('ijk,j,k->i', transfer_matrix, a, b)
    return result

def compute_radiance(albedo, lighting_coeffs, visibility_coeffs, hemisphere_coeffs, transfer_matrix, n):
    """
    Computes outgoing radiance B(x) = a(x) * (L . (V * H))
    """
    # Step 1: Convolve visibility and hemisphere response
    vh_product = sh_convolution(visibility_coeffs, hemisphere_coeffs, transfer_matrix, n)
    
    # Step 2: Dot product with lighting
    integral_value = np.dot(lighting_coeffs, vh_product)
    
    # Step 3: Scale by albedo
    radiance = albedo * integral_value
    return radiance
```

**Edge Cases and Pitfalls:**
*   **Gibbs Phenomenon:** Truncating the series causes ringing artifacts for high-frequency signals [Parent].
*   **Smoothness Assumption:** The method assumes the input function is sufficiently smooth; discontinuities (e.g., hard shadows) cause slow convergence [Parent].
*   **Rotation:** Rotating a SH function requires applying a linear transformation defined by Wigner D-matrices to the coefficient vector [Parent]. The hemisphere response $H(x)$ is handled by rotating the basis functions rather than the coefficients to maintain differentiability with respect to surface normal $n(x)$ [S1].

## Subtopics

### Hemisphere Projection in SH Space
This variant addresses the computation of the hemisphere response $H(x) = \int_{\Omega} \max(n(x) \cdot \omega, 0)y(\omega)d\omega$ [S1]. Instead of numerical integration for every normal, it reformulates the problem using the rotation property of SH functions: $H(x) = \phi_{SH}(n(x)) \int_{\Omega} \max(i_z \cdot \omega, 0)y(\omega)d\omega$, where $\phi_{SH}(x)$ is a linear rotation function and $i_z = (0, 0, 1)^T$ [S1]. This makes the equation differentiable with respect to $n(x)$ and allows the integral term to be precomputed analytically or via numerical integration at initialization, as it does not need to be differentiable during the inverse problem optimization [S1].

## Operating characteristics
*   **Time Complexity:** Projection is $O(n^2)$ per sample or $O(n^2 \cdot N_{samples})$ for full integration [Parent]. Product convolution is $O(n^3)$ [Parent].
*   **Memory Complexity:** Requires storing the transfer matrix $C$ of size $n^3$ [Parent]. For $n=8$, this is $512$ floats, which is negligible.
*   **Measured Performance:** A bandwidth of $n=8$ is cited as providing good low-frequency approximations [S1]. Switching between max degree 3 (SH-16) and 4 (SH-25) yields negligible differences in metrics or visual quality for typical scenes [Parent].
*   **Strengths:** Enables differentiable computation of integrals involving products of functions, which is crucial for inverse problems [S1]. Avoids the high variance and cost of Monte Carlo integration [S1].
*   **Limitations:** Struggles with high-frequency details and discontinuities due to the smoothness assumption and Gibbs phenomenon [Parent].
*   **When to use:** Suitable for inverse problems where differentiable rendering is required and the signal is relatively smooth (e.g., soft shadows, diffuse lighting).
*   **When not to use:** Not suitable for hard-edged shadows or high-frequency specularities without significant bandwidth increase [Parent].

## Background
The method originates from the work on "Efficient and Differentiable Shadow Computation for Inverse Problems" [S1]. It builds on the general theory of Spherical Harmonics [Parent] and applies it specifically to the rendering equation to replace Monte Carlo integration with algebraic operations. The use of SH for global illumination dates back to earlier work (e.g., Green [6] cited in [S1]), but this specific application focuses on the differentiability and efficiency gains for inverse geometry and material optimization [S1].
