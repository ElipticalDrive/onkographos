# Ray Tracing Backward Pass
## Overview
The Ray Tracing Backward Pass computes gradients for spherical harmonic (SH) coefficients, ray origins, and ray directions, and optionally accumulates gradients for background and sparsity/beta losses [S1, unofficial]. It operates at the ray-tracing level to handle the backward pass for volume rendering with SH basis functions, distinguishing it from its sibling [Spherical Harmonic Volume Shading](5946-spherical-harmonic-volume-shading.md) by processing the entire ray path rather than shading individual primitives [S1, unofficial].
## How it works
**Inputs:**
*   `grad_output`: Gradient of the loss with respect to the rendered image (RGB or SH domain) [S1, unofficial].
*   `color_cache`: The forward pass output (rendered colors) for each ray [S1, unofficial].
*   `ray_origins`, `ray_dirs`: Ray parameters [S1, unofficial].
*   `grid`: The 3D grid structure containing SH coefficients and density [S1, unofficial].
*   `opt`: Optimization options containing `beta_loss` and `sparsity_loss` weights [S1, unofficial].
*   `log_transmit`: Log-transmittance values from the forward pass [S1, unofficial].
*   `accum`: Accumulated background color from the forward pass (if applicable) [S1, unofficial].

**Outputs:**
*   `grads`: Gradients for SH coefficients, density, and ray parameters [S1, unofficial].
*   `grad_sphfunc_val`: Intermediate gradients for SH basis values [S1, unofficial].

**Data Structures:**
*   `sphfunc_val`: Shared memory array storing SH basis function values for the current ray step [S1, unofficial].
*   `grad_sphfunc_val`: Shared memory array storing gradients of SH basis values [S1, unofficial].
*   `ray_spec`: Structure containing ray origin and direction [S1, unofficial].
*   `temp_storage`: Warp-level reduction buffer [S1, unofficial].

**Parameters:**
*   `beta_loss`: Float weight for beta distribution sparsity loss, passed to `trace_ray_cuvol_backward` [S1, unofficial].
*   `sparsity_loss`: Float weight for sparsity loss, passed to `trace_ray_cuvol_backward` [S1, unofficial].
*   `Q`: Denominator factor in the gradient normalization formula `norm_factor = 2.0 / (3.0 * Q)` [S1, unofficial].
*   `grid.sh_data_dim`: Threshold for `lane_id` to determine early kernel exit [S1, unofficial].
*   `grid.basis_dim`: Dimension of the SH basis [S1, unofficial].

**Steps:**
1.  **Thread Identification:** Calculate global thread ID and derive `ray_id`, `ray_blk_id`, and `lane_id`. If `lane_id >= grid.sh_data_dim`, return early [S1, unofficial].
2.  **Shared Memory Initialization:** Initialize `sphfunc_val`, `grad_sphfunc_val`, `ray_spec`, and `temp_storage` [S1, unofficial].
3.  **Ray Setup:** Set `ray_spec` from `ray_origins` and `ray_dirs`, and extract direction vector `vdir` [S1, unofficial].
4.  **Gradient Buffer Init:** If `lane_id < grid.basis_dim`, initialize `grad_sphfunc_val` to `0.0` [S1, unofficial].
5.  **SH Evaluation:** Calculate spherical harmonic function values using `calc_sphfunc` [S1, unofficial].
6.  **Ray Bounds:** If `lane_id == 0`, find ray bounds using `ray_find_bounds` [S1, unofficial].
7.  **Gradient Normalization:** Compute `grad_out`: if `grad_out_is_rgb`, calculate `resid = color_cache - grad_output`, then `grad_out[i] = resid * norm_factor` where `norm_factor = 2.0 / (3.0 * Q)`. Otherwise, `grad_out[i] = grad_output[i]` [S1, unofficial].
8.  **Warp Synchronization:** Synchronize warps within the SH data dimension mask [S1, unofficial].
9.  **Volume Backward Trace:** Call `trace_ray_cuvol_backward` with `grad_out`, `color_cache`, `ray_spec`, `opt`, `lane_id`, `sphfunc_val`, `grad_sphfunc_val`, `temp_storage`, `log_transmit_in`, `beta_loss`, `sparsity_loss`, `grads`, and optional `accum`/`log_transmit` outputs [S1, unofficial].
10. **SH Backward Pass:** Call `calc_sphfunc_backward` to compute gradients for spherical harmonic basis coefficients [S1, unofficial].

**Pseudocode:**
```python
# Pseudocode for render_ray_backward_kernel
# Inputs: grad_output, color_cache, ray_origins, ray_dirs, grid, opt, log_transmit, accum
# Outputs: grads

def render_ray_backward_kernel(grad_output, color_cache, ray_origins, ray_dirs, grid, opt, log_transmit, accum):
    # 1. Thread Identification
    global_tid = get_global_thread_id()  # CUDA intrinsic
    ray_id = global_tid // grid.sh_data_dim
    ray_blk_id = global_tid // (grid.sh_data_dim * WARP_SIZE)  # WARP_SIZE = 32 [G]
    lane_id = global_tid % WARP_SIZE
    
    if lane_id >= grid.sh_data_dim:
        return

    # 2. Shared Memory Initialization
    sphfunc_val = [0.0] * grid.basis_dim
    grad_sphfunc_val = [0.0] * grid.basis_dim
    ray_spec = {'origin': None, 'dir': None}
    temp_storage = [0.0] * WARP_SIZE

    # 3. Ray Setup
    ray_spec['origin'] = ray_origins[ray_id]
    ray_spec['dir'] = ray_dirs[ray_id]
    vdir = normalize(ray_spec['dir'])

    # 4. Gradient Buffer Init
    if lane_id < grid.basis_dim:
        grad_sphfunc_val[lane_id] = 0.0

    # 5. SH Evaluation
    sphfunc_val = calc_sphfunc(vdir, grid.basis_dim)

    # 6. Ray Bounds
    if lane_id == 0:
        ray_bounds = ray_find_bounds(ray_spec, grid)

    # 7. Gradient Normalization
    if grad_out_is_rgb:
        resid = color_cache[ray_id] - grad_output[ray_id]
        norm_factor = 2.0 / (3.0 * Q)
        grad_out = resid * norm_factor
    else:
        grad_out = grad_output[ray_id]

    # 8. Warp Synchronization
    sync_warps_in_sh_mask()

    # 9. Volume Backward Trace
    trace_ray_cuvol_backward(
        grad_out=grad_out,
        color_cache=color_cache[ray_id],
        ray_spec=ray_spec,
        opt=opt,
        lane_id=lane_id,
        sphfunc_val=sphfunc_val,
        grad_sphfunc_val=grad_sphfunc_val,
        temp_storage=temp_storage,
        log_transmit_in=log_transmit[ray_id],
        beta_loss=opt.beta_loss,
        sparsity_loss=opt.sparsity_loss,
        grads=grads,
        accum=accum[ray_id] if accum is not None else None,
        log_transmit_out=log_transmit[ray_id]
    )

    # 10. SH Backward Pass
    calc_sphfunc_backward(
        grad_sphfunc_val=grad_sphfunc_val,
        vdir=vdir,
        basis_dim=grid.basis_dim,
        grads_sh=grads.sh_coeffs
    )
```
## Subtopics

### Background Rendering Backward Pass
Computes gradients for background rendering, handling RGB gradient normalization and calling the background backward function [S1, unofficial]. It checks if `log_transmit[ray_id] < -25.0f`; if true, it returns early to avoid unnecessary computation [S1, unofficial]. It creates a `SingleRaySpec`, finds background bounds, computes `grad_out` using `norm_factor = 2.0 / (3.0 * Q)` when `grad_out_is_rgb`, and calls `render_background_backward` with `grid`, `grad_out`, `ray_spec`, `opt`, `log_transmit[ray_id]`, `accum[ray_id]`, `sparsity_loss`, and `grads` [S1, unofficial].

### Fused Volume Rendering with Losses
Launches the forward ray kernel and optionally allocates an `accum` tensor if background rendering is used [S1, unofficial]. It uses `beta_loss` to determine if `log_transmit` is needed and passes it to the backward kernel [S1, unofficial]. It uses `sparsity_loss` as a parameter [S1, unofficial]. The kernel launch configuration uses `CUDA_N_BLOCKS_NEEDED(Q * WARP_SIZE, TRACE_RAY_CUDA_THREADS)` [S1, unofficial].

## Background
The Ray Tracing Backward Pass is part of the svox2 library [S1, unofficial]. It is designed to support differentiable volumetric rendering using spherical harmonics for basis functions [S1, unofficial]. The implementation leverages CUDA for parallel execution on GPUs [S1, unofficial].
