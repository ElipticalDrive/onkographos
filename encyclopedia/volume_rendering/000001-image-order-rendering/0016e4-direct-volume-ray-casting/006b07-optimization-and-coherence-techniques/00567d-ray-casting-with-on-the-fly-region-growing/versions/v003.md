# Ray casting with on-the-fly region growing

Also called: On-the-fly region growing ray casting

## Overview
This method extends direct volume ray casting by integrating a local region growing algorithm during ray traversal to eliminate artifacts caused by contrast inhomogeneities, such as isolated "particle-like" regions in medical imaging [S1]. Unlike standard ray casting which may render these artifacts as part of the surface, or undersampling which loses local features, this approach filters small isolated noise while preserving large structural boundaries like endocardial walls [S1]. It is specifically designed for 3-D navigation in cardiac MSCT data where contrast distribution is non-uniform [S1].

## How it works
The method modifies the standard detection and refinement steps by inserting a region growing stage whenever an object is detected via thresholding [S1].

### Inputs and Outputs
**Inputs:**
*   Volume data $V$ (scalar field, e.g., Hounsfield Units) [S1].
*   Camera parameters (origin $\mathbf{o}$, direction $\mathbf{d}$) [G].
*   Contrast Threshold $CT$ (scalar, typical range 40–120 HU) [S1].
*   Size Threshold $ST$ (scalar, typical range 1000–1500 voxels) [S1].
*   Volume bounding box defined by $\mathbf{b}_{\min}$ and $\mathbf{b}_{\max}$ [G].

**Outputs:**
*   Final pixel color and opacity [G].
*   Surface point coordinates for shading [S1].

### Data Structures
*   **Stack**: A LIFO structure used to store voxel coordinates $(x, y, z)$ during region growing [S1].
*   **Visited Set**: A boolean grid or hash set marking voxels already processed in the current region growing instance to prevent cycles and redundant processing [S1].
*   **Region Counter**: An integer tracking the number of voxels in the current growing region [S1].

### Algorithm Steps
1.  **Ray Casting Initialization**: For each pixel, define ray $r(t) = \mathbf{o} + t\mathbf{d}$ [G]. Intersect with volume bounding box to get $t_{\text{near}}$ and $t_{\text{far}}$ [G].
2.  **Rough Detection Loop**: Iterate along the ray from $t_{\text{near}}$ to $t_{\text{far}}$ with a step size $\Delta t$ small enough to avoid unexpected crossings of surfaces [S1]. At sample position $\mathbf{p}_i$, retrieve voxel value $V(\mathbf{p}_i)$ [G]. Check if $V(\mathbf{p}_i) < CT$ [S1]. If $V(\mathbf{p}_i) \ge CT$, continue to next sample [S1]. If $V(\mathbf{p}_i) < CT$, a potential object is detected [S1]. Proceed to Region Growing.
3.  **Region Growing**: Initialize `Stack` with $\mathbf{p}_i$ [S1]. Initialize `Visited` set with $\mathbf{p}_i$ [S1]. Initialize `RegionSize` = 0 [S1]. While `Stack` is not empty: Pop voxel $\mathbf{v}$ from `Stack` [S1]. Increment `RegionSize` [S1]. If `RegionSize` $\ge ST$, stop growing. The region is considered "relevant" (e.g., a wall) [S1]. Break loop. For each neighbor $\mathbf{n}$ of $\mathbf{v}$ (6-connected or 26-connected) [G]: If $\mathbf{n}$ is within volume bounds and not in `Visited`: Retrieve $V(\mathbf{n})$ [G]. If $V(\mathbf{n}) < CT$: Add $\mathbf{n}$ to `Visited` [S1]. Push $\mathbf{n}$ to `Stack` [S1].
4.  **Decision and Continuation**: If `RegionSize` $< ST$: The detected region is an artifact [S1]. The text states "omit it, and continue the ray-casting process using the rough detection scheme" [S1]. This implies the ray traversal continues past the artifact cluster [G]. If `RegionSize` $\ge ST$: The region is relevant [S1]. The first detected voxel $\mathbf{p}_i$ is assumed to be on the surface [S1]. Stop ray traversal for this pixel. Proceed to Refinement.
5.  **Refinement**: Perform 3-D linear interpolation in the neighborhood of the surface point $\mathbf{p}_i$ using the eight surrounding voxels [S1]. Search for the local gradient maximum to determine precise surface orientation [S1]. Compute shading based on the surface normal [G]. Composite the result using the standard front-to-back equation [G].

### Pseudocode
```python
def ray_cast_with_region_growing(volume, origin, direction, CT, ST, bbox_min, bbox_max):
    """
    Casts a ray and applies on-the-fly region growing to filter artifacts.
    volume: 3D numpy array of voxel values.
    origin, direction: 3D arrays for ray r(t) = origin + t * direction.
    CT: Contrast Threshold. ST: Size Threshold.
    bbox_min, bbox_max: 3D arrays defining volume bounds.
    Returns: (color, alpha, surface_point) or (0, 0, None).
    """
    # 1. Ray-Bounding Box Intersection
    t_near, t_far = ray_aabb_intersect(origin, direction, bbox_min, bbox_max)
    if t_near is None:
        return (0.0, 0.0, 0.0), 0.0, None

    # 2. Rough Detection Loop
    dt = 0.5  # Step size in continuous units [G]
    t = t_near
    surface_point = None

    while t <= t_far:
        p = origin + t * direction
        voxel_val = trilinear_interpolate(volume, p, bbox_min, bbox_max)

        if voxel_val < CT:
            # Convert continuous position to integer voxel index for region growing
            idx = [int(floor(p[i])) for i in range(3)]
            region_size, is_relevant = perform_region_growing(volume, idx, CT, ST, bbox_min, bbox_max)

            if is_relevant:
                surface_point = p
                break
            # else: artifact detected, omit and continue ray casting [S1]

        t += dt

    if surface_point is not None:
        # 3. Refinement
        normal = compute_gradient(volume, surface_point, bbox_min, bbox_max)
        color = compute_shading(normal)
        alpha = 1.0
        return color, alpha, surface_point
    else:
        return (0.0, 0.0, 0.0), 0.0, None

def ray_aabb_intersect(origin, direction, bbox_min, bbox_max):
    t_min = []
    t_max = []
    for i in range(3):
        if direction[i] != 0:
            t_min.append((bbox_min[i] - origin[i]) / direction[i])
            t_max.append((bbox_max[i] - origin[i]) / direction[i])
        else:
            if origin[i] < bbox_min[i] or origin[i] > bbox_max[i]:
                return None, None
            t_min.append(float('-inf'))
            t_max.append(float('inf'))
    t_near = max(min(t_min[i], t_max[i]) for i in range(3))
    t_far = min(max(t_min[i], t_max[i]) for i in range(3))
    if t_near > t_far or t_far < 0:
        return None, None
    return max(0.0, t_near), t_far

def trilinear_interpolate(volume, point, bbox_min, bbox_max):
    p = [max(bbox_min[i], min(bbox_max[i], point[i])) for i in range(3)]
    ix, iy, iz = [int(floor(p[i])) for i in range(3)]
    fx, fy, fz = [p[i] - ix for i in range(3)]
    def v(x, y, z):
        x = max(0, min(x, volume.shape[0]-1))
        y = max(0, min(y, volume.shape[1]-1))
        z = max(0, min(z, volume.shape[2]-1))
        return volume[x, y, z]
    c00 = v(ix, iy, iz) * (1-fx) + v(ix+1, iy, iz) * fx
    c01 = v(ix, iy, iz+1) * (1-fx) + v(ix+1, iy, iz+1) * fx
    c10 = v(ix, iy+1, iz) * (1-fx) + v(ix+1, iy+1, iz) * fx
    c11 = v(ix, iy+1, iz+1) * (1-fx) + v(ix+1, iy+1, iz+1) * fx
    c0 = c00 * (1-fy) + c10 * fy
    c1 = c01 * (1-fy) + c11 * fy
    return c0 * (1-fz) + c1 * fz

def perform_region_growing(volume, seed_idx, CT, ST, bbox_min, bbox_max):
    stack = [seed_idx]
    visited = set()
    visited.add(tuple(seed_idx))
    region_size = 0
    while stack:
        curr = stack.pop()
        region_size += 1
        if region_size >= ST:
            return region_size, True
        for n in get_neighbors(curr, bbox_min, bbox_max):
            if n not in visited:
                visited.add(n)
                if volume[n[0], n[1], n[2]] < CT:
                    stack.append(n)
    return region_size, False

def get_neighbors(point, bbox_min, bbox_max):
    neighbors = []
    for axis in range(3):
        for delta in [-1, 1]:
            n = list(point)
            n[axis] += delta
            if all(bbox_min[i] <= n[i] <= bbox_max[i] for i in range(3)):
                neighbors.append(tuple(n))
    return neighbors

def compute_gradient(volume, point, bbox_min, bbox_max):
    dx = 0.5
    grad = [0.0, 0.0, 0.0]
    for i in range(3):
        p_pos = list(point)
        p_neg = list(point)
        p_pos[i] += dx
        p_neg[i] -= dx
        grad[i] = trilinear_interpolate(volume, p_pos, bbox_min, bbox_max) - \
                  trilinear_interpolate(volume, p_neg, bbox_min, bbox_max)
    norm = (grad[0]**2 + grad[1]**2 + grad[2]**2)**0.5
    if norm == 0: return [0, 0, 1]
    return [g/norm for g in grad]

def compute_shading(normal):
    intensity = max(0.0, -normal[0]*0.5 - normal[1]*0.5 - normal[2]*0.8)
    return (intensity, intensity, intensity)
```

### Parameters
*   **Contrast Threshold (CT)**: The Hounsfield Unit value below which voxels are considered part of the object or artifact. Typical range: 40 to 120 HU [S1].
*   **Size Threshold (ST)**: The maximum number of voxels allowed for a "particle-like" region to be considered an artifact. If the region size is smaller than ST, it is filtered out. Typical range: 1000 to 1500 voxels [S1].
*   **Relative Size Metric**: $\rho(CT, ST) = MS(CT, ST) / MMS(CT)$, where $MS(CT, ST)$ is the mean size of eliminated regions for given CT and ST, and $MMS(CT)$ is the maximum of $MS(CT, ST)$ over the range of ST when CT is fixed [S1].

### Edge Cases and Pitfalls
*   **CT Too High**: If CT is set too high, occluding regions become too large and may connect to the actual walls (e.g., endocardial walls). This causes them to lose their "particle-like" isolated nature, making them indistinguishable from relevant structures and thus harder to filter as artifacts [S1].
*   **Computational Cost**: The region growing stage increases computational requirements. On a 2-GHz CPU with 1-GB memory, the average time for ventricle exploration is 3 seconds with ST=1500, which is twice the time required without region growing [S1]. The computation time increases with ST [S1].
*   **No Pre-segmentation**: The method does not require pre-segmentation, which is an advantage for flexibility but a disadvantage for performance [S1].

## Operating characteristics
*   **Time Complexity**: The base ray casting is $O(N)$ per pixel where $N$ is the number of samples [G]. The region growing adds overhead proportional to the size of the detected regions [G]. In the worst case, if many large regions are detected, the complexity increases significantly [G]. The source notes that computation time is twice that of standard ray casting [S1].
*   **Memory Complexity**: Requires additional memory for the `Stack` and `Visited` set during region growing. The size is proportional to the largest artifact region detected along the ray [G].
*   **Performance**: Tested on cardiac MSCT data (512x512 matrix, ~200 slices, voxel size 0.33-0.4 mm³) [S1]. Average 100-150 eliminated regions per view [S1].
*   **Strengths**: Eliminates artifacts due to contrast inhomogeneities without pre-segmentation; improves visibility of walls (e.g., endocardial walls, coronary sinus); preserves local surface features better than undersampling [S1].
*   **Limitations**: Increased computational cost (2x slower); sensitive to parameter selection (CT and ST trade-off); requires interactive parameter tuning for optimal results [S1].
*   **When to Use**: 3-D navigation in medical volumes with non-uniform contrast (e.g., cardiac MSCT) where small isolated artifacts obscure important structures [S1].
*   **When Not to Use**: Real-time applications requiring high frame rates where the 2x overhead is unacceptable [G].

## Background
The method was proposed by J.L. Coatrieux, K. Rioual, C. Göksu, E. Unanua, and P. Haigron from the Laboratoire Traitement du Signal et de l’Image, INSERM U642, Université de Rennes 1 [S1]. It was motivated by the need for pre-operative planning in Cardiac Resynchronisation Therapy, specifically for 3-D navigation into heart cavities using multislice X-Ray Computed Tomography (MSCT) data [S1]. The algorithm builds on the general framework of ray casting with rough detection and linear interpolation refinement [S1].
