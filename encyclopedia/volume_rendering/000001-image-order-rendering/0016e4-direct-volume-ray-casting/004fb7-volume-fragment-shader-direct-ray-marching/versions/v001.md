# Volume Fragment Shader (Direct Ray Marching)

Also called: Ray-box volume rendering

## Overview
This method implements direct volume ray casting within a single OpenGL fragment shader, computing the final pixel color by marching a ray through a 3D volume texture [S1, unofficial]. It differs from parent methods by performing the entire ray-traversal loop, transfer function lookup, and compositing in the fragment stage, driven by NDC coordinates rather than interpolated vertex attributes to ensure robustness on macOS [S1, unofficial]. It supports multiple rendering modes (Max Projection, Iso-Surface) and includes specific optimizations like dithering to reduce banding artifacts [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:**
    *   `gl_FragCoord`: Window-space fragment coordinates.
    *   `volumeTex`: A `sampler3D` containing the volume data, normalized to $[0, 1]$ [S1, unofficial].
    *   `transferTex`: A `sampler2D` representing a 1D lookup table (LUT) stored as a single-row 2D texture [S1, unofficial].
    *   Uniforms: `renderMode` (int: 0=Max, 1=Iso), `isoValue` (float), `quality` (float $0.1..1.0$), `dithering` (float $0..1$), `roiMin`/`roiMax` (vec3, texture coords $[0,1]$), `boxHalf` (vec3, half-extents of the volume bounding box in world space), `gamma` (float), `rangeMin`/`rangeMax` (float), `brightness` (float) [S1, unofficial].
*   **Outputs:**
    *   Fragment color (RGB) and optionally opacity.

**Data Structures:**
*   **Volume Texture:** 3D texture object. Values are assumed to be in $[0, 1]$.
*   **Transfer Function Texture:** 2D texture with height 1. The x-coordinate maps to the volume value, and the y-coordinate is fixed at 0.5 (center). The RGB output of the texture lookup provides the color $\mathbf{c}$ and alpha $\alpha$ [S1, unofficial].

**Numbered Steps:**

1.  **Ray Construction:**
    Compute Normalized Device Coordinates (NDC) from `gl_FragCoord` to avoid interpolation artifacts [S1, unofficial]. Define the ray origin $\mathbf{o}$ as the camera position and direction $\mathbf{d}$ based on the view matrix and NDC [G].

2.  **Ray-AABB Intersection:**
    Intersect the ray with the volume bounding box using the slab method [S1, unofficial].
    *   Calculate inverse direction: $\mathbf{invDir} = 1.0 / \mathbf{d}$ [S1, unofficial].
    *   Compute intersection intervals for each axis:
        $$ t_0 = (-\mathbf{boxHalf} - \mathbf{o}) \cdot \mathbf{invDir} $$
        $$ t_1 = (\mathbf{boxHalf} - \mathbf{o}) \cdot \mathbf{invDir} $$
    *   Determine entry and exit parameters:
        $$ t_{near} = \max(\max(t_{0,x}, t_{0,y}), t_{0,z}) $$
        $$ t_{far} = \min(\min(t_{1,x}, t_{1,y}), t_{1,z}) $$
    *   The ray intersects the box if $t_{far} > \max(t_{near}, 0.0)$ [S1, unofficial]. If not, discard the fragment.

3.  **ROI Clipping:**
    Apply Region of Interest (ROI) clipping by adjusting $t_{near}$ and $t_{far}$ based on `roiMin` and `roiMax` texture coordinates [S1, unofficial]. The world-to-texture mapping is:
    $$ \mathbf{p}_{tex} = \frac{\mathbf{p}_{world}}{2.0 \cdot \mathbf{boxHalf}} + 0.5 $$
    The ray march range is constrained to the ROI bounds in texture space [S1, unofficial].

4.  **Dithering:**
    To prevent banding artifacts, add a random offset to the ray start position $t_{near}$ [S1, unofficial].
    *   Generate a pseudo-random value using a hash function with a `noiseSeed` [S1, unofficial].
    *   Offset: $\Delta t_{dither} = \text{random}() \cdot \text{dithering} \cdot \Delta t_{step}$ [S1, unofficial].
    *   New start: $t_{start} = t_{near} + \Delta t_{dither}$ [S1, unofficial].

5.  **Step Count Calculation:**
    Determine the number of samples $N$ based on the `quality` parameter [S1, unofficial].
    *   Let $L = t_{far} - t_{near}$ be the ray length inside the volume.
    *   Base step size $\Delta t_{base}$ is derived from the volume resolution or a fixed constant [G].
    *   $N = \lceil L / (\Delta t_{base} \cdot \text{quality}) \rceil$ [S1, unofficial].
    *   Actual step size: $\Delta t = L / N$ [S1, unofficial].

6.  **Ray Marching Loop:**
    Iterate $i$ from $0$ to $N-1$:
    *   Compute sample position: $t_i = t_{start} + i \cdot \Delta t$ [S1, unofficial].
    *   Compute world position: $\mathbf{p}_i = \mathbf{o} + t_i \mathbf{d}$ [G].
    *   Map to texture coordinates: $\mathbf{u}_i = \frac{\mathbf{p}_i}{2.0 \cdot \mathbf{boxHalf}} + 0.5$ [S1, unofficial].
    *   **Intensity Normalization:**
        *   Sample raw value $v_{raw} = \text{texture}(volumeTex, \mathbf{u}_i)$ [S1, unofficial].
        *   Normalize: $v_{norm} = \frac{v_{raw} - \text{rangeMin}}{\text{rangeMax} - \text{rangeMin}}$ [S1, unofficial].
        *   Guard against division by zero: If $\text{rangeMax} - \text{rangeMin} < 10^{-6}$, set $v_{norm} = 0.0$ [S1, unofficial].
        *   Clamp $v_{norm}$ to $[0, 1]$ [S1, unofficial].
        *   Apply Gamma correction: $v_{final} = \text{pow}(v_{norm}, \gamma)$ [S1, unofficial].
        *   Apply Brightness: $v_{final} = v_{final} \cdot \text{brightness}$ [S1, unofficial].

    *   **Classification (Transfer Function):**
        *   Lookup color and opacity from `transferTex`: $(\mathbf{c}_i, \alpha_i) = \text{texture}(transferTex, (v_{final}, 0.5))$ [S1, unofficial].

    *   **Rendering Mode Logic:**
        *   **Max Projection (`renderMode == 0`):**
            *   Update max intensity: $I_{max} = \max(I_{max}, v_{final})$ [S1, unofficial].
            *   Continue to next sample.
        *   **Iso-Surface (`renderMode == 1`):**
            *   Check if $|v_{final} - \text{isoValue}| < \epsilon$ (where $\epsilon$ is a small threshold) [S1, unofficial].
            *   If true, set $\alpha_i = 1.0$ (or high value) and $\mathbf{c}_i$ to the iso-color.
            *   If false, $\alpha_i = 0.0$.
        *   **Standard Volume Rendering (Default):**
            *   Use $\mathbf{c}_i$ and $\alpha_i$ directly from the transfer function [S1, unofficial].

    *   **Compositing (Front-to-Back):**
        *   Update accumulated color and opacity [S1, unofficial]:
            $$ \mathbf{C}_{acc} \leftarrow \mathbf{C}_{acc} + (1 - \alpha_{acc}) \cdot \mathbf{c}_i \cdot \alpha_i $$
            $$ \alpha_{acc} \leftarrow \alpha_{acc} + (1 - \alpha_{acc}) \cdot \alpha_i $$
        *   **Early Ray Termination:** If $\alpha_{acc} \ge 1.0$, break the loop [G].

7.  **Output:**
    *   If `renderMode == 0` (Max Projection), output $I_{max}$ (possibly with gamma correction applied again if not done per-sample) [S1, unofficial].
    *   Otherwise, output $\mathbf{C}_{acc}$ and $\alpha_{acc}$ [S1, unofficial].

**Pseudocode:**

```python
# Inputs: gl_FragCoord, volumeTex, transferTex, uniforms
# Outputs: fragColor

def main(gl_FragCoord, volumeTex, transferTex, uniforms):
    # 1. Ray Construction
    ndc = compute_ndc(gl_FragCoord) # [G] Standard OpenGL NDC conversion
    ray_o, ray_d = compute_ray_from_ndc(ndc, uniforms.camera) # [G]

    # 2. Ray-AABB Intersection
    inv_dir = 1.0 / ray_d
    t0 = (-uniforms.boxHalf - ray_o) * inv_dir
    t1 = (uniforms.boxHalf - ray_o) * inv_dir
    
    t_near = max(max(t0.x, t0.y), t0.z)
    t_far = min(min(t1.x, t1.y), t1.z)
    
    if t_far <= max(t_near, 0.0):
        return vec4(0.0) # No intersection

    # 3. ROI Clipping
    # Map ROI texture bounds to world space t-values
    # [S1, unofficial] describes ROI as texture coordinate bounds
    # Assuming linear mapping from t_near/t_far to ROI min/max
    roi_min_world = uniforms.roiMin * 2.0 * uniforms.boxHalf + uniforms.boxHalf # [G] Inverse of world-to-texture
    roi_max_world = uniforms.roiMax * 2.0 * uniforms.boxHalf + uniforms.boxHalf # [G]
    
    # Adjust t_near and t_far based on ROI
    # [S1, unofficial] implies clipping the visible region
    # Simplified: clamp t_near and t_far to ROI bounds if ROI is active
    # Note: Exact ROI-to-t mapping depends on camera orientation relative to box
    # For axis-aligned box and camera, we can project ROI bounds onto ray
    # [G] Placeholder for exact ROI projection logic if not axis-aligned
    # Assuming simple clamping for axis-aligned case for implementation completeness
    t_near = max(t_near, t_roi_near) # [G] t_roi_near derived from ROI
    t_far = min(t_far, t_roi_far)   # [G] t_roi_far derived from ROI
    
    if t_far <= t_near:
        return vec4(0.0)

    # 4. Dithering
    random_val = pseudo_random_hash(gl_FragCoord.xy + uniforms.noiseSeed)
    dither_offset = random_val * uniforms.dithering
    t_start = t_near + dither_offset

    # 5. Step Count
    ray_length = t_far - t_near
    # quality 0.1 -> coarse, 1.0 -> fine
    # [S1, unofficial] quality controls step count
    # Assume base step size corresponds to quality 1.0
    # N = ray_length / (base_step * quality)
    # [G] base_step is not explicitly defined, assume derived from volume resolution or fixed
    base_step = 0.01 # [G] Placeholder value, typically derived from volume dimensions
    num_samples = int(ray_length / (base_step * uniforms.quality))
    if num_samples < 1:
        num_samples = 1
    dt = ray_length / num_samples

    # 6. Ray Marching
    acc_color = vec3(0.0)
    acc_alpha = 0.0
    max_intensity = 0.0

    for i in range(num_samples):
        t = t_start + i * dt
        p_world = ray_o + t * ray_d
        
        # World-to-Texture
        u = p_world / (2.0 * uniforms.boxHalf) + 0.5
        
        # Intensity Normalization
        v_raw = texture(volumeTex, u).r
        range_diff = uniforms.rangeMax - uniforms.rangeMin
        if range_diff < 1e-6:
            v_norm = 0.0
        else:
            v_norm = (v_raw - uniforms.rangeMin) / range_diff
        v_norm = clamp(v_norm, 0.0, 1.0)
        v_final = pow(v_norm, uniforms.gamma) * uniforms.brightness
        
        # Classification
        c_i, a_i = texture(transferTex, vec2(v_final, 0.5)).rgb, texture(transferTex, vec2(v_final, 0.5)).a
        
        # Mode Logic
        if uniforms.renderMode == 0: # Max Projection
            max_intensity = max(max_intensity, v_final)
            continue
        elif uniforms.renderMode == 1: # Iso-Surface
            if abs(v_final - uniforms.isoValue) < 0.01: # [G] Threshold placeholder
                a_i = 1.0
                c_i = vec3(1.0) # [G] Iso-color placeholder
            else:
                a_i = 0.0
        
        # Compositing
        if a_i > 0.0:
            acc_color += (1.0 - acc_alpha) * c_i * a_i
            acc_alpha += (1.0 - acc_alpha) * a_i
        
        if acc_alpha >= 1.0:
            break

    # 7. Output
    if uniforms.renderMode == 0:
        return vec4(pow(max_intensity, uniforms.gamma) * uniforms.brightness, 1.0) # [G] Gamma/Brightness re-applied for output
    else:
        return vec4(acc_color, acc_alpha)
```

**Parameters:**
*   `renderMode`: int, 0 = MaxProjection, 1 = IsoSurface [S1, unofficial].
*   `isoValue`: float, threshold in $[0, 1]$ for isosurface rendering [S1, unofficial].
*   `quality`: float in $[0.1, 1.0]$, controls step count (higher is finer) [S1, unofficial].
*   `dithering`: float in $[0, 1]$, controls random ray-start offset strength [S1, unofficial].
*   `roiMin`, `roiMax`: vec3, texture coordinate bounds in $[0, 1]$, default $(0,0,0)$ and $(1,1,1)$ [S1, unofficial].
*   `gamma`: float, power-law intensity correction [S1, unofficial].
*   `rangeMin`, `rangeMax`: float, clip the normalized intensity window [S1, unofficial].
*   `brightness`: float, output brightness multiplier [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Division by Zero:** If `rangeMax - rangeMin` is less than $10^{-6}$, the intensity normalization returns 0.0 to avoid division by zero [S1, unofficial].
*   **macOS Robustness:** NDC coordinates must be computed from `gl_FragCoord` rather than interpolated vertex attributes to ensure correctness on macOS [S1, unofficial].
*   **Banding:** Dithering is required to prevent banding artifacts caused by discrete sampling [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** $O(N)$ per pixel, where $N$ is the number of samples along the ray. $N$ is controlled by the `quality` parameter and the ray length [S1, unofficial].
*   **Memory Complexity:** $O(1)$ per fragment, plus the memory for the 3D volume texture and 2D transfer function texture [S1, unofficial].
*   **Performance:** Performance is heavily dependent on the `quality` setting and the density of the volume (opacity). Early ray termination can significantly speed up rendering for opaque volumes [G].
*   **Strengths:** Simple implementation, runs entirely on the GPU fragment shader, supports interactive exploration via real-time parameter updates (ROI, quality, etc.) [S1, unofficial].
*   **Limitations:** Fixed step size (unless adaptive stepping is added) can lead to aliasing or slow rendering. No support for complex lighting models beyond the transfer function color [S1, unofficial].

## Background
This method is derived from the implementation in ClearVolume-plus, an open-source tool for live 3D volume visualization [S1, unofficial]. It adapts standard direct volume ray casting techniques to a fragment shader environment, leveraging OpenGL's texture sampling capabilities for efficient data access [S1, unofficial].
