# Cylindrical Symmetry Projector

Also called: Abel Transform, Abel Transform Discretization

## Overview
The Cylindrical Symmetry Projector is a forward and back projector pair designed for objects with cylindrical symmetry [S2, S3, unofficial]. It solves the problem of computing line integrals through axisymmetric volumes by reducing the 3D integration to a 1D radial problem, specifically implementing the Abel Transform for parallel-beam geometries [S2, S3, unofficial].

## How it works
**Inputs and Outputs:**
*   **Input:** A radial extinction coefficient profile $\alpha(r)$ defined for $r \in [0, r_{max}]$ [S1, unofficial].
*   **Output:** The total optical depth $\delta_{max}(x)$ for a set of projection rays at impact parameter $x$ [S1, unofficial].

**Data Structures:**
*   **Radial Profile:** A vector $A$ of size $N_r$, representing $\alpha(r_j)$ at discrete radii $r_j$ [S1, unofficial].
*   **Projection Vector:** A vector $\Delta$ of size $N_x$, representing $\delta_{max}(x_i)$ at discrete impact parameters $x_i$ [S1, unofficial].
*   **Kernel Matrix:** A matrix $K$ of size $N_x \times N_r$, where element $K_{ij}$ represents the geometric path length of the $i$-th ray passing through the $j$-th concentric ring [S1, unofficial].
*   **Radial Boundaries:** An array of size $N_r + 1$ defining the inner and outer radii of each concentric ring [G].

**Steps:**
1.  **Discretization:** Discretize the cross-section into $N_r$ concentric rings to approximate the continuous integral as a finite sum [S1, unofficial].
2.  **Kernel Construction:** Compute the geometric kernel matrix $K$, where $K_{ij}$ corresponds to the path length of the $i$-th ray through the $j$-th ring [S1, unofficial].
3.  **Forward Projection:** Compute the total optical depth vector $\Delta$ using the linear algebraic form $\Delta = KA$ [S1, unofficial].
4.  **Back Projection:** Reconstruct $\alpha(r)$ from measured $\delta_{max}(x)$ by solving the linear system $KA = \Delta$ for $A$ [S1, unofficial].

**Formulas:**
Under axisymmetry, the total optical depth $\delta_{max}(x)$ is the Abel transform of the local extinction-coefficient profile $\alpha(r)$ [S1, unofficial]:
$$ \delta_{max}(x) = 2 \int_{x}^{r_{max}} \frac{\alpha(r) r}{\sqrt{r^2 - x^2}} dr $$
This integral is approximated by the discrete sum:
$$ \Delta_i = \sum_{j=0}^{N_r-1} K_{ij} A_j $$
where $K_{ij}$ encodes the integral of the geometric factor over the $j$-th ring for the $i$-th ray [S1, unofficial].

**Parameters:**
*   $r_{max}$: Maximum radius of the object.
*   $x$: Impact parameter (distance from the axis of symmetry to the ray).
*   $N_r, N_x$: Number of radial bins and projection samples.

**Edge Cases and Pitfalls:**
*   **Singularity:** The kernel has a singularity at $r=x$, requiring careful numerical evaluation or analytic integration over ring widths [G].
*   **Ill-Conditioning:** The Abel transform is an ill-posed inverse problem, making the back projection sensitive to noise [G].
*   **Out-of-Bounds Rays:** Rays with $x > r_{max}$ yield zero optical depth and must be clamped to avoid negative square roots [G].

**Pseudocode:**
```python
import math

def cylindrical_symmetry_projector(alpha, r_boundaries, x_grid):
    """
    Forward projection using Cylindrical Symmetry (Abel Transform).
    alpha: vector A of size N_r, extinction coefficients per ring.
    r_boundaries: array of size N_r + 1 defining ring inner/outer radii.
    x_grid: array of impact parameters x_i.
    """
    N_r = len(alpha)
    N_x = len(x_grid)
    delta_max = [0.0] * N_x
    K = [[0.0] * N_r for _ in range(N_x)]

    for i in range(N_x):
        x_i = x_grid[i]
        for j in range(N_r):
            r_inner = r_boundaries[j]
            r_outer = r_boundaries[j + 1]
            # Analytic integral of Abel kernel 2*r/sqrt(r^2-x^2) over ring [r_inner, r_outer] [G]
            term_outer = math.sqrt(max(r_outer**2 - x_i**2, 0.0))
            term_inner = math.sqrt(max(r_inner**2 - x_i**2, 0.0))
            K[i][j] = 2.0 * (term_outer - term_inner)

    for i in range(N_x):
        s = 0.0
        for j in range(N_r):
            s += K[i][j] * alpha[j]
        delta_max[i] = s
    return delta_max
```

## Subtopics

### Abel Transform
The specific mathematical operation applied in parallel-beam geometries for cylindrical symmetry [S2, S3, unofficial]. Choose it when the object is strictly axisymmetric and the projection geometry is parallel [G]. Link: [Abel Transform](abel-transform.md).

### Radial Discretization
The method of dividing the radial profile into concentric rings to approximate the continuous integral [S1, unofficial]. Choose finer discretization for higher accuracy but increased computational cost [G]. Link: [Radial Discretization](radial-discretization.md).

## Operating characteristics
*   **Time Complexity:** Not given in the sources.
*   **Memory Complexity:** Not given in the sources.
*   **Strengths:** Reduces a 3D integration problem to a 1D radial problem for axisymmetric objects [S2, S3, unofficial].
*   **Limitations:** Only applicable to objects with cylindrical symmetry; the back projection involves solving an ill-posed linear system [G].
*   **When to use:** When the object is known to be axisymmetric [G].
*   **When not to use:** For arbitrary 3D objects or objects with significant asymmetry [G].

## Background
The method was implemented as a forward/back projector pair for objects with cylindrical symmetry by Champley & Maddox (2021) [S2, S3, unofficial]. It is applied in tomographic reconstruction of axisymmetric sprays and combustion diagnostics [S1, unofficial].
