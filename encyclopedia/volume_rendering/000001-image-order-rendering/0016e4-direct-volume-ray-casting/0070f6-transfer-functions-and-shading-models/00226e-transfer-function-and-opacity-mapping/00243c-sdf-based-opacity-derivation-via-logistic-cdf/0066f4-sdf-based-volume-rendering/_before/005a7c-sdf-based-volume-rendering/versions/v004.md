# SDF-based Volume Rendering

Also called: NeuS Opacity Derivation, NeuS Volume Rendering with SDF, SDF-to-Opacity via Sigmoid, VolSDF-style Rendering, Volume Rendering with SDF

## Overview
SDF-based Volume Rendering is a neural rendering technique that represents a scene as an implicit Signed Distance Field (SDF) parameterized by a neural network, converting SDF values into opacity for volume integration [S1][S2, unofficial]. It solves the problem of reconstructing high-quality surfaces with fine details while rendering photo-realistic images, distinguishing itself from standard NeRF by using a logistic mapping of the SDF to allow optimization with neural volume rendering [S2, unofficial]. This method builds on [SDF-based Opacity Derivation via Logistic CDF](3233-sdf-based-opacity-derivation-via-logistic-cdf.md) to correctly model surface opacity [S2, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** Camera center $\mathbf{o}$, viewing direction $\mathbf{v}$, a neural network $f(\mathbf{x})$ predicting the SDF value at 3D point $\mathbf{x}$, a steepness parameter $s$, and $N$ discrete sample points $\mathbf{p}_i$ along the ray [S1][S2, unofficial].
*   **Outputs:** Rendered color $\hat{C}(\mathbf{r})$ for the pixel [S1].

**Data Structures:**
*   **Ray:** $\mathbf{p}(t) = \mathbf{o} + t\mathbf{v}$ for $t \ge 0$ [S2, unofficial].
*   **Samples:** $N$ points $\mathbf{p}_i = \mathbf{o} + t_i\mathbf{v}$ where $t_1 < t_2 < \dots < t_N$ [S2, unofficial].
*   **SDF Network:** $f: \mathbb{R}^3 \to \mathbb{R}$, typically an MLP [S1].

**Formulas:**
1.  **Sigmoid Function:**
    $$ \Phi_s(x) = \frac{1}{1 + e^{-sx}} $$
    where $s$ is a learned or manually updated steepness parameter [S2, unofficial].

2.  **Opacity:**
    For each sample interval $[t_i, t_{i+1}]$, the opacity $\alpha_i$ is computed as:
    $$ \alpha_i = \max \left( \frac{\Phi_s(f(\mathbf{p}_i)) - \Phi_s(f(\mathbf{p}_{i+1}))}{\Phi_s(f(\mathbf{p}_i))}, 0 \right) $$
    where $f(\mathbf{p}_i)$ is the SDF value at point $\mathbf{p}_i$ [S2, unofficial].

3.  **Transmittance:**
    $$ T_i = \prod_{j=1}^{i-1} (1 - \alpha_j) $$
    with $T_1 = 1$ [S1].

4.  **Rendered Color:**
    $$ \hat{C}(\mathbf{r}) = \sum_{i=1}^N T_i \alpha_i c_i $$
    where $c_i$ is the predicted color at $\mathbf{p}_i$ [S2, unofficial].

**Parameters:**
*   **$s$ (steepness):** Controls the sharpness of the sigmoid. It is described as being learned or manually updated during training [S2, unofficial].
*   **$N$ (samples):** Number of discrete points along the ray. Not given in the sources.

**Pseudocode:**
```python
def sdf_volume_rendering(ray_origin, ray_direction, sdf_network, color_network, s, t_values):
    """
    Renders a pixel using SDF-based volume rendering.
    
    Args:
        ray_origin: 3D vector, camera center o.
        ray_direction: 3D vector, viewing direction v.
        sdf_network: Function f(x) returning SDF value.
        color_network: Function c(x) returning color.
        s: Float, steepness parameter for sigmoid.
        t_values: List of floats, sorted depths t_i along the ray.
        
    Returns:
        rendered_color: 3D vector, C_hat(r).
    """
    # Ensure sample points are sorted by depth to guarantee t_i < t_{i+1}
    t_values = sorted(t_values)
    num_samples = len(t_values)
    
    accumulated_transmittance = 1.0
    rendered_color = [0.0, 0.0, 0.0]
    
    for i in range(num_samples - 1):
        # Compute 3D points for current interval
        p_i = ray_origin + t_values[i] * ray_direction
        p_next = ray_origin + t_values[i+1] * ray_direction
        
        # Evaluate SDF and Sigmoid
        f_i = sdf_network(p_i)
        f_next = sdf_network(p_next)
        
        phi_i = 1.0 / (1.0 + math.exp(-s * f_i))
        phi_next = 1.0 / (1.0 + math.exp(-s * f_next))
        
        # Compute opacity alpha_i
        # Guard against division by zero if phi_i is numerically zero
        if phi_i < 1e-8:
            alpha = 0.0
        else:
            alpha = max((phi_i - phi_next) / phi_i, 0.0)
            
        # Get color at current point p_i
        c_i = color_network(p_i)
        
        # Accumulate color (vector addition)
        rendered_color[0] += accumulated_transmittance * alpha * c_i[0]
        rendered_color[1] += accumulated_transmittance * alpha * c_i[1]
        rendered_color[2] += accumulated_transmittance * alpha * c_i[2]
        
        # Update transmittance
        accumulated_transmittance *= (1.0 - alpha)
        
        # Early termination if transmittance is negligible
        if accumulated_transmittance < 1e-5:
            break
            
    return rendered_color
```

**Edge Cases and Pitfalls:**
*   **Division by Zero:** If $\Phi_s(f(\mathbf{p}_i)) = 0$, the opacity formula involves division by zero. The pseudocode includes a numerical guard for this [G].
*   **Negative Opacity:** The $\max(..., 0)$ ensures opacity is non-negative, handling cases where the sigmoid value increases along the ray due to network approximation [S2, unofficial].
*   **Parameter $s$:** The value of $s$ significantly affects the result. It must be learned or updated during training to adapt to the scene's scale and detail [S2, unofficial].

## Subtopics

### [MPF Volume Rendering](10260-mpf-volume-rendering.md)
MPF Volume Rendering is a neural volume rendering technique that replaces the Signed Distance Field (SDF) backbone with Metric-Phase Fields (MPFs) to handle sign-ambiguous geometry and thin structures. It derives opacity from a signed composite field $\phi$ using a NeuS-style occupancy mapping, while color is predicted by a separate radiance network, isolating the geometry representation change from the rendering pipeline.

### Sigmoidal OTF
A transfer function that maps normalized feature detector values to opacity using a threshold $T$ and steepness parameter $\gamma$, designed to produce smoothly highlighted edges in volume renderings [S4]. It differs from threshold-based OTF by replacing hard cutoffs with smooth transitions, making it more effective for highlighting edges without abrupt opacity jumps [S4]. It is applied to color and gradient feature detectors (gR, cBRAIN, cR, cBR) for cryo-imaging volume rendering of adult and embryonic mouse datasets [S4]. Parameters: $\gamma$ (typical value 50) controls the steepness, approaching a step function for large $\gamma$; $T$ is the threshold value, enabling uniform definition across datasets [S4].

## Operating characteristics
*   **Time Complexity:** Linear in the number of samples $N$ per ray, $O(N)$, due to the sequential accumulation of transmittance and color [S1].
*   **Memory Complexity:** Not given in the sources.
*   **Measured Performance:** Not given in the sources.
*   **Strengths:** Enables high-fidelity surface reconstruction and photo-realistic rendering by leveraging the geometric priors of SDFs [S1][S2, unofficial].
*   **Limitations:** Requires learning or tuning the steepness parameter $s$ [S2, unofficial].
*   **When to Use:** When high-quality surface reconstruction is required alongside novel view synthesis, particularly for scenes with fine details [S1][S2, unofficial].
*   **When Not to Use:** Not given in the sources.

## Background
SDF-based Volume Rendering was introduced by Wang et al. in the NeuS paper (2021) [S1][S2, unofficial]. It was developed to address the limitations of NeRF in surface reconstruction, providing a method to render photo-realistic images while simultaneously reconstructing high-quality surfaces with fine details [S1]. The method uses a logistic function to convert SDF predictions to opacity, allowing optimization with neural volume rendering [S2, unofficial]. It has been adopted in subsequent works such as Neuralangelo for high-fidelity neural surface reconstruction [S2, unofficial].
