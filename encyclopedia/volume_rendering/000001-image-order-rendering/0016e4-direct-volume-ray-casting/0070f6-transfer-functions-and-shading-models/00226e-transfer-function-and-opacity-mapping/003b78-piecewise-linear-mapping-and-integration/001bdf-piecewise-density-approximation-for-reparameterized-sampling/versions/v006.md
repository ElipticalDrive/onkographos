# Piecewise Density Approximation for Reparameterized Sampling

Also called: PWC approximation, PWL approximation, Piecewise Constant Approximation

## Overview
Piecewise Density Approximation for Reparameterized Sampling is a method for generating volume samples along a ray by approximating the density field $\sigma_r(t)$ as either piecewise constant or piecewise linear on a predefined grid [S1, S2, unofficial]. This approximation allows the cumulative opacity integral to be computed analytically, enabling the inversion of the opacity function to determine sample locations corresponding to uniform random numbers [S1, S2, unofficial]. It differs from its siblings by operating on the density field directly to facilitate analytical integration, whereas [Linear Opacity Interpolation](7016-linear-opacity-interpolation.md) interpolates opacity values directly, and [Piecewise Linear Opacity Mapping with Gradient Scaling](1335-piecewise-linear-opacity-mapping-with-gradient-scaling.md) incorporates gradient-based scaling into the opacity mapping process.

## How it works
**Inputs:**
- Ray segment endpoints $t_n$ and $t_f$ (typically $t_n=0, t_f=1$ or physical bounds).
- A grid of points $t_0, t_1, \dots, t_m$ such that $t_n = t_0 < t_1 < \dots < t_m = t_f$ [S1, S2, unofficial].
- A scalar density field $\sigma_r(t)$ defined along the ray [S1, S2, unofficial].
- A target uniform random sample $u \in [0, 1]$ [S1, S2, unofficial].
- The final opacity $y_f = F_r(t_f)$ [S1, S2, unofficial].

**Outputs:**
- A sample location $t$ on the ray such that the cumulative opacity up to $t$ corresponds to $u$ [S1, S2, unofficial].

**Data Structures:**
- Grid array: A sorted list of floats $[t_0, t_1, \dots, t_m]$ [S1, S2, unofficial].
- Density values: For Piecewise Constant (PWC), a value $\sigma_r(\hat{t}_j)$ for each bin $j$ [S2, unofficial]. For Piecewise Linear (PWL), values $\sigma_r(t_j)$ at each grid point [S1, S2, unofficial].

**Steps:**

1. **Construct Approximation:** Choose between Piecewise Constant (PWC) or Piecewise Linear (PWL) approximation [S1, S2, unofficial].
    - **PWC:** For each bin $j \in [0, m-1]$, select a point $\hat{t}_j \in [t_j, t_{j+1}]$ (e.g., randomly or at the midpoint) and evaluate $\sigma_r(\hat{t}_j)$ [S1, S2, unofficial].
    - **PWL:** Evaluate $\sigma_r(t_j)$ at each grid point $t_j$ [S1, S2, unofficial].

2. **Compute Cumulative Integral Approximation:** Calculate the integral approximation $I(t) = \int_{t_n}^t \sigma_r(s) ds$ for a given $t \in [t_i, t_{i+1})$ [S1, S2, unofficial].
    - **PWC Integral $I_0(t)$:**
      $$I_0(t) = \sum_{j=1}^i \sigma_r(\hat{t}_j)(t_j - t_{j-1}) + \sigma_r(\hat{t}_i)(t - t_i)$$
      where $\hat{t}_j$ is the representative point in bin $j$ [S1, S2, unofficial].
    - **PWL Integral $I_1(t)$:**
      $$I_1(t) = \sum_{j=1}^{i-1} \frac{\sigma_r(t_j) + \sigma_r(t_{j-1})}{2} (t_j - t_{j-1}) + \frac{\sigma_r(t_i) + \bar{\sigma}_r(t)}{2} (t - t_i)$$
      where $\bar{\sigma}_r(t)$ is the linearly interpolated density at $t$:
      $$\bar{\sigma}_r(t) = \sigma_r(t_i) \frac{t_{i+1}-t}{t_{i+1}-t_i} + \sigma_r(t_{i+1}) \frac{t-t_i}{t_{i+1}-t_i}$$
      [S2, unofficial].

3. **Formulate Inversion Equation:** The goal is to find $t$ such that the cumulative opacity $F_r(t)$ matches the target value derived from $u$ [S1, S2, unofficial]. The relationship is:
   $$y_f u = 1 - \exp\left(-\int_{t_n}^t \sigma_r(s) ds\right)$$
   Rearranging for the integral:
   $$-\log(1 - y_f u) = \int_{t_n}^t \sigma_r(s) ds \approx I(t)$$
   Let $Y = -\log(1 - y_f u)$ [S1, S2, unofficial].

4. **Solve for $t$:** Find the bin $i$ containing the solution and solve for $t$ within that bin [S1, S2, unofficial].
    - **For PWC:** $I_0(t)$ is piecewise linear. Find $i$ such that $I_0(t_i) \le Y < I_0(t_{i+1})$. Then solve:
      $$Y = I_0(t_i) + \sigma_r(\hat{t}_i)(t - t_i)$$
      $$t = t_i + \frac{Y - I_0(t_i)}{\sigma_r(\hat{t}_i)}$$
      [S1, unofficial]. Note: If $\sigma_r(\hat{t}_i) = 0$, the density is zero in this bin, and the solution lies in a subsequent bin with non-zero density.
    - **For PWL:** $I_1(t)$ is piecewise quadratic. Find $i$ such that $I_1(t_i) \le Y < I_1(t_{i+1})$. Substitute $\bar{\sigma}_r(t)$ into $I_1(t)$ to form a quadratic equation in $t$:
      $$Y = C_i + \frac{\sigma_r(t_i) + \sigma_r(t_{i+1})}{2(t_{i+1}-t_i)} (t - t_i)^2 + \frac{\sigma_r(t_i) - \sigma_r(t_{i+1})}{2} (t - t_i)$$
      where $C_i = \sum_{j=1}^{i-1} \frac{\sigma_r(t_j) + \sigma_r(t_{j-1})}{2} (t_j - t_{j-1})$ is the cumulative integral up to $t_i$ [S2, unofficial]. Solve the quadratic equation for $t \in [t_i, t_{i+1})$ [S1, S2, unofficial].

**Parameters:**
- Grid resolution $m$: Number of bins. Not given in the sources.
- Bin selection strategy for PWC: Random or midpoint. Not given in the sources.

**Edge Cases and Pitfalls:**
- **Zero Density:** If $\sigma_r(\hat{t}_i) = 0$ in PWC, division by zero occurs in the inversion step. The algorithm must skip bins with zero density [S1, unofficial].
- **Monotonicity:** The integral approximations $I_0(t)$ and $I_1(t)$ are monotonic if the density field is non-negative [S1, S2, unofficial].
- **Precision:** Solving the quadratic equation for PWL requires careful handling of numerical stability, especially when coefficients are small [S1, S2, unofficial].

**Pseudocode:**

```python
import math

def piecewise_density_approximation_inverse(t_grid, density_values, u, y_f, mode='pwc'):
    """
    Compute sample location t given uniform random u using piecewise density approximation.
    
    Args:
        t_grid: List of grid points [t_0, ..., t_m].
        density_values: 
            For PWC: List of density values [sigma_r(t_hat_0), ..., sigma_r(t_hat_{m-1})] for each bin.
            For PWL: List of density values [sigma_r(t_0), ..., sigma_r(t_m)] at grid points.
        u: Uniform random sample in [0, 1].
        y_f: Final opacity F_r(t_f).
        mode: 'pwc' or 'pwl'.
        
    Returns:
        t: Sample location on the ray.
    """
    m = len(t_grid) - 1
    target_integral = -math.log(1 - y_f * u)
    
    # Precompute cumulative integrals to find the correct bin
    cum_integral = [0.0] * (m + 1)
    
    if mode == 'pwc':
        for j in range(1, m + 1):
            bin_width = t_grid[j] - t_grid[j-1]
            cum_integral[j] = cum_integral[j-1] + density_values[j-1] * bin_width
            
        # Find bin i
        i = 0
        for j in range(1, m + 1):
            if target_integral < cum_integral[j]:
                i = j - 1
                break
        else:
            i = m - 1 # Should not happen if u <= 1 and y_f correct
            
        # Solve for t in bin i
        sigma_hat = density_values[i]
        if sigma_hat == 0:
            # Density is zero in this bin, move to next non-zero bin
            # [G] In practice, skip bins with zero density until a non-zero one is found
            for k in range(i + 1, m):
                if density_values[k] > 0:
                    i = k
                    break
            else:
                return t_grid[-1] # All remaining density is zero
                
        sigma_hat = density_values[i]
        t = t_grid[i] + (target_integral - cum_integral[i]) / sigma_hat
        
    elif mode == 'pwl':
        # Precompute cumulative integrals and coefficients for quadratic solution
        # I_1(t) in bin i is: C_i + A_i * (t - t_i) + B_i * (t - t_i)^2
        # where A_i = (sigma(t_i) - sigma(t_{i+1})) / 2
        #       B_i = (sigma(t_i) + sigma(t_{i+1})) / (2 * (t_{i+1} - t_i))
        
        coeffs = [] # List of (C_i, A_i, B_i) for each bin
        
        current_cum = 0.0
        for j in range(m):
            t_i = t_grid[j]
            t_next = t_grid[j+1]
            sigma_i = density_values[j]
            sigma_next = density_values[j+1]
            
            width = t_next - t_i
            A = (sigma_i - sigma_next) / 2.0
            B = (sigma_i + sigma_next) / (2.0 * width)
            
            coeffs.append((current_cum, A, B))
            
            # Cumulative integral at t_{j+1}
            current_cum += A * width + B * width * width
            
        # Find bin i
        i = 0
        for j in range(m):
            # Integral at t_{j+1} for bin j
            C, A, B = coeffs[j]
            integral_at_end = C + A * (t_grid[j+1] - t_grid[j]) + B * (t_grid[j+1] - t_grid[j])**2
            if target_integral < integral_at_end:
                i = j
                break
        else:
            i = m - 1
            
        C, A, B = coeffs[i]
        t_i = t_grid[i]
        t_next = t_grid[i+1]
        
        # Solve B * dt^2 + A * dt + (C - target_integral) = 0 for dt = t - t_i
        # dt = (-A +/- sqrt(A^2 - 4*B*(C - target_integral))) / (2*B)
        discriminant = A*A - 4*B*(C - target_integral)
        if discriminant < 0:
            # [G] Numerical error, clamp to 0
            discriminant = 0
        sqrt_disc = math.sqrt(discriminant)
        
        # Choose the root that lies in [0, width]
        dt1 = (-A + sqrt_disc) / (2 * B)
        dt2 = (-A - sqrt_disc) / (2 * B)
        
        width = t_next - t_i
        if 0 <= dt1 <= width:
            dt = dt1
        elif 0 <= dt2 <= width:
            dt = dt2
        else:
            # [G] Fallback, should not happen with correct logic
            dt = 0
            
        t = t_i + dt
        
    else:
        raise ValueError("Mode must be 'pwc' or 'pwl'")
        
    return t
```

## Subtopics

### Piecewise Constant Approximation (PWC)
Approximates density as constant within each bin. Simpler to implement and faster to evaluate, but less accurate than PWL. Chosen when computational efficiency is prioritized over precision. Link: [Piecewise Density Approximation for Reparameterized Sampling](#piecewise-density-approximation-for-reparameterized-sampling).

### Piecewise Linear Approximation (PWL)
Approximates density as linearly interpolated between grid points. More accurate than PWC, but requires solving a quadratic equation for inversion. Chosen when higher fidelity is needed. Link: [Piecewise Density Approximation for Reparameterized Sampling](#piecewise-density-approximation-for-reparameterized-sampling).

## Operating characteristics
- **Time Complexity:** Finding the bin is $O(m)$ or $O(\log m)$ with binary search. Solving for $t$ is $O(1)$ for PWC (linear) and $O(1)$ for PWL (quadratic). Total time per sample is $O(m)$ or $O(\log m)$ depending on bin search.
- **Memory Complexity:** $O(m)$ to store the grid and density values.
- **Measured Performance:** Not given in the sources.
- **Scaling:** Performance scales linearly with the number of bins $m$.
- **Strengths:** Analytical integration allows for differentiable rendering and efficient sample generation. Non-negative density fields ensure monotonic integrals.
- **Limitations:** Accuracy depends on grid resolution. PWC may introduce artifacts if bins are too large. PWL requires solving quadratic equations, which can be numerically unstable.
- **When to use:** When differentiable volume sampling is required and the density field can be approximated by piecewise functions.
- **When not to use:** When high accuracy is required with very few bins, or when the density field has complex structures that are not well-approximated by piecewise functions.

## Background
The method was introduced in "Differentiable Rendering with Reparameterized Volume Sampling" by [S1, unofficial] and [S2, unofficial] in 2023. It builds on the idea of approximating the density field to enable analytical computation of the cumulative opacity integral, which is then inverted to generate samples. This approach is particularly useful in differentiable rendering pipelines where gradients with respect to the density field are needed.
