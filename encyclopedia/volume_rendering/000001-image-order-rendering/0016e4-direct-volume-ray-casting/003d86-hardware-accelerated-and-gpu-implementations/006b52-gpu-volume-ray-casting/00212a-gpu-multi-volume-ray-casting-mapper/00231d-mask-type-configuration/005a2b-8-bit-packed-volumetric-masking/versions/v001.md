# 8-bit Packed Volumetric Masking

Also called: Bit-packed volume mask, VolumetricModel mask extension

## Overview
8-bit Packed Volumetric Masking is a technique for applying voxel-level visibility masks to volumetric data without duplicating the underlying scalar volume data. It solves the memory overhead problem of traditional masking by storing masks as 8-bit packed boolean arrays, where each byte represents the visibility of 8 adjacent voxels along the X-axis. Unlike transfer functions which map scalar values to opacity/color, this method maps XYZ coordinates directly to boolean visibility, allowing for independent rotation or transformation of the mask relative to the data volume.

## How it works
**Inputs and Outputs:**
*   **Input:** A volumetric dataset with dimensions $(volDimX, volDimY, volDimZ)$ and a mask buffer.
*   **Output:** A boolean value indicating whether a given sampling position $p$ falls within a visible voxel.

**Data Structures:**
The mask is stored in a `VolumetricModel` structure with the following fields:
*   `maskBuffer`: A pointer to a 1D array of `uint8` (unsigned char).
*   `maskDims`: A `vec3i` specifying the dimensions of the mask buffer in memory units. For a volume of dimensions $(volDimX, volDimY, volDimZ)$, `maskDims` is set to $(\lfloor volDimX/8 \rfloor, volDimY, volDimZ)$.
*   `hasMask`: A boolean flag indicating if a mask is present.

**Mask Buffer Layout:**
The mask buffer is a 1D array of unsigned chars. The index for a voxel at $(x, y, z)$ is calculated as:
$$ index = z \times sliceSize + y \times maskDims.x + \lfloor x/8 \rfloor $$
where $sliceSize = maskDims.x \times maskDims.y$.

**Algorithm Steps:**
1.  **Commit Phase:** In `VolumetricModel::commit()`, check if the 'mask' parameter exists.
    *   If present: retrieve the data pointer into `maskBuffer`, retrieve `maskDims`, and set `hasMask` to `true`.
    *   If not present: set `hasMask` to `false`.
2.  **Sampling Phase:** For each ray sample at position $p$:
    *   Map continuous position $p$ to discrete voxel indices $(x, y, z)$ using floor rounding:
        $$ x = \lfloor p.x \rfloor, \quad y = \lfloor p.y \rfloor, \quad z = \lfloor p.z \rfloor $$
    *   Calculate the byte index in the packed buffer.
    *   Extract the specific bit corresponding to $x$ within that byte.
    *   Return the result of the bitwise AND operation.

**Pseudocode:**
```python
def inMask(mask_buffer, mask_dims, p):
    """
    Check if voxel at continuous position p is visible.
    
    Args:
        mask_buffer: list of uint8, the packed mask data.
        mask_dims: tuple (mx, my, mz), dimensions of the mask buffer.
        p: tuple (px, py, pz), continuous sampling position.
        
    Returns:
        bool: True if visible, False if occluded/hidden.
    """
    # If no mask is defined, consider everything visible
    if not mask_buffer:
        return True

    # Map continuous position to discrete voxel indices
    x = int(p[0]) # floor(p.x)
    y = int(p[1]) # floor(p.y)
    z = int(p[2]) # floor(p.z)

    # Calculate slice size in the 1D buffer
    slice_size = mask_dims[0] * mask_dims[1]

    # Calculate byte index in the 1D array
    byte_index = z * slice_size + y * mask_dims[0] + (x // 8)

    # Retrieve the byte value
    mask_val = mask_buffer[byte_index]

    # Determine the bit position within the byte (0-7)
    bit_position = x % 8

    # Create bitmask and check visibility
    bit_mask = 1 << bit_position
    
    return (mask_val & bit_mask) != 0
```

**Parameters:**
*   `mask`: `OSPData` object containing the packed mask buffer, created via `ospNewSharedData1D` with type `OSP_UCHAR`.
*   `maskDims`: `vec3i` specifying the dimensions of the mask buffer.
*   `volDimX`: The width of the volumetric dataset in voxels. Must be handled such that padding is applied if not a multiple of 8.

**Edge Cases and Pitfalls:**
*   **Dimension Padding:** If `volDimX` is not a multiple of 8, the mask buffer size calculation $(volDimX \times volDimY \times volDimZ / 8)$ requires explicit padding to ensure valid memory access for the last partial byte. The buffer size must be rounded up to the next multiple of 8 bits per slice.
*   **Coordinate Rounding:** The mask lookup uses `floor(p.x)`, `p.y`, `p.z` to map continuous sampling positions to discrete voxel indices.
*   **Bit Extraction:** The specific bit within the byte is determined by `(x%8)`, shifting a 1 by that amount to create a bitmask for the bitwise AND operation.

## Operating characteristics
*   **Memory Efficiency:** Reduces mask memory footprint by a factor of 8 compared to byte-per-voxel masks.
*   **Performance:** Minimal overhead during ray casting; requires only one additional memory access and bitwise operation per sample.
*   **Limitations:** Only supports binary visibility (visible/hidden). Does not support partial opacity or label-based masking directly.
*   **When to use:** When memory bandwidth is a bottleneck and binary visibility masks are sufficient.
*   **When not to use:** When label-based masking or partial transparency masks are required.

## Background
This method was developed as an unofficial extension to the OSPRay library to optimize memory usage for volumetric masking. It was proposed by Shijou87 in a GitHub issue discussion in 2023, addressing the need to avoid duplicating volumetric data when applying masks. The implementation involves modifications to the `VolumetricModel` class and the `volumes.ispc` shader code.
