# WebGL Path Tracing Volume Rendering

Also called: Interactive Voxel Volume Rendering via WebGL 2.0

## Overview
This method implements an interactive voxel volume renderer using path tracing that runs in modern browsers via WebGL 2.0 [S1, unofficial]. It renders 3D scalar fields by casting rays from the camera through the volume, accumulating color and opacity along the ray, and applying lighting and shadowing effects [S1, unofficial]. It is distinguished from standard hardware-accelerated ray casting by its implementation of soft shadows via light tracing and its use of a linear search for non-uniform opacity/color maps rather than texture sampling [S1, unofficial].

## How it works
**Inputs and Outputs:**
The fragment shader receives uniforms for the volume data (`volume` as `highp sampler3D`), volume dimensions (`volume_dims` as `ivec3`), step scaling (`dt_scale` as `float`), light position (`lightPosition` as `vec3`), windowing parameters (`windowLevel`, `windowWidth` as `float`), rescaling parameters (`rescaleIntercept`, `rescaleSlope` as `float`), and map definitions (`numberOfOpacitySamples`, `opacityMapPositions`, `opacityMapSamples`, `numberOfColorSamples`, `colorMapPositions`, `colorMapSamples` as `highp sampler2D` and `int`) [S1, unofficial]. It receives varying inputs `vray_dir` (ray direction) and `transformed_eye` (camera origin) [S1, unofficial]. The output is a `vec4` color [S1, unofficial].

**Data Structures:**
*   **Volume:** 3D texture (`sampler3D`) storing scalar values.
*   **Opacity/Color Maps:** 2D textures (`sampler2D`) storing control points. The implementation uses a linear search through control points rather than texture sampling to allow arbitrary non-uniform control point positions [S1, unofficial].
*   **Ray Parameters:** Computed per-pixel.

**Steps:**

1.  **Ray-Box Intersection:**
    Compute the inverse ray direction `invDir = 1.0 / ray_dir`.
    Compute temporary bounds: `tmin_tmp = (boxMin - ray_origin) * invDir` and `tmax_tmp = (boxMax - ray_origin) * invDir`.
    Compute `tmin = min(tmin_tmp, tmax_tmp)` and `tmax = max(tmin_tmp, tmax_tmp)`.
    Compute entry `t0 = max(tmin.x, max(tmin.y, tmin.z))` and exit `t1 = min(tmax.x, min(tmax.y, tmax.z))` [S1, unofficial].
    If `t0 > t1`, the ray does not intersect the volume; discard the fragment [S1, unofficial].

2.  **Step Size Calculation:**
    Compute the base step vector `dt_vec = 1.0 / (vec3(volume_dims) * abs(ray_dir))` [S1, unofficial].
    Compute the step size `dt = dt_scale * min(dt_vec.x, min(dt_vec.y, dt_vec.z))` [S1, unofficial].

3.  **Ray Origin Offset:**
    Generate a random offset using a Wang hash based on fragment coordinates: `offset = wang_hash(int(gl_FragCoord.x + 1024.0 * gl_FragCoord.y))` [S1, unofficial].
    Compute the initial position `p = transformed_eye + (t0 + offset * dt) * ray_dir` [S1, unofficial].

4.  **Ray Marching Loop:**
    Initialize accumulated color `voxelColor = vec4(0.0)` [S1, unofficial].
    Loop `t` from `t0` to `t1` with step `dt`:
    a.  **Sample Volume:** Get raw value `val` at `p`.
    b.  **Rescale:** `rescaled = rescaleSlope * val + rescaleIntercept` [S1, unofficial].
    c.  **Windowing:** `windowed = (rescaled - (windowLevel - windowWidth / 2.0)) / windowWidth` [S1, unofficial].
    d.  **Opacity Mapping:** Find the interval in `opacityMapPositions` containing `windowed`. Interpolate between `opacityMapSample(i-1)` and `opacityMapSample(i)` using linear interpolation. Clamp the result to `[0, 1]` to get `opacity` [S1, unofficial].
    e.  **Color Mapping:** Find the interval in `colorMapPositions` containing `windowed`. Interpolate between `colorMapSample(i-1)` and `colorMapSample(i)` to get `color` [S1, unofficial].
    f.  **Beer-Lambert Approximation:** Compute `val_color = vec4(opacity * color, opacity)`. Adjust alpha for step size: `val_color.a = 1.0 - pow(1.0 - val_color.a, dt_scale)` [S1, unofficial].
    g.  **Compositing:**
        `voxelColor.rgb += (1.0 - voxelColor.a) * val_color.a * val_color.rgb`
        `voxelColor.a += (1.0 - voxelColor.a) * val_color.a` [S1, unofficial].
    h.  **Early Termination:** If `voxelColor.a >= 0.95`, break the loop [S1, unofficial].
    i.  **Advance:** `p += ray_dir * dt` [S1, unofficial].

5.  **Lighting Calculation:**
    a.  **Normal Estimation:** Compute voxel size `voxelSize = 1.0 / vec3(volume_dims)`. Compute the gradient using central differences of the opacity value (applying the opacity map to the rescaled value) at `p` [S1, unofficial].
        `gradient.x = (sampleVolumeOpacity(p + vec3(voxelSize.x, 0, 0)) - sampleVolumeOpacity(p - vec3(voxelSize.x, 0, 0))) * (1.0 / (2.0 * voxelSize.x))` (similarly for y, z).
        Normalize the gradient to get `voxelNormal` [S1, unofficial].
    b.  **Light Direction:** `lightDirection = normalize(lightPosition - p)` [S1, unofficial].
    c.  **Diffuse:** `intensity = dot(voxelNormal, lightDirection)` [S1, unofficial].
    d.  **Specular:** If `intensity > 0.0`, compute half vector `h = normalize(lightDirection + transformed_eye)`. Compute `intSpec = max(dot(h, voxelNormal), 0.0)`. Compute `spec = specular * pow(intSpec, shininess)` with `shininess = 8.0` [S1, unofficial].
    e.  **Shadow:** If `voxelColor.a >= 0.20`, compute `shadow = clamp(softShadow(p) * 2.0 + 0.1, 0.0, 1.0)`, else `shadow = 1.0` [S1, unofficial].
    f.  **Final Color:** `lightColor = shadow * max(intensity * diffuse + spec, ambient)` with `diffuse=0.6`, `ambient=0.4`, `specular=0.5` [S1, unofficial].
    g.  **Output:** `voxelColor.rgb = lightColor * voxelColor.rgb` (or similar combination, source implies lighting modulates the accumulated color) [S1, unofficial].

6.  **Soft Shadow Calculation (`softShadow`):**
    Sample 8 points around `p` in a 3x3 grid (excluding center) with spacing `delta = min(voxelSize.x, min(voxelSize.y, voxelSize.z)) * 2.0` [S1, unofficial].
    For each point, compute `pointShadow = 1.0 - traceLight(point, lightPosition)` [S1, unofficial].
    Sum these shadows and divide by 8.0 [S1, unofficial].

7.  **Light Tracing (`traceLight`):**
    Cast a ray from `voxel` towards `light`. Compute `voxelToLight = light - voxel`, `d = normalize(voxelToLight)`, and origin `o = voxel - 1000.0 * d` [S1, unofficial].
    Intersect ray with box to get bounds `box` [S1, unofficial].
    Compute `start = length(voxel - o)` [S1, unofficial].
    Sample opacity along the ray from `start` to `box.y` with step `delta = min(voxelSize.x, min(voxelSize.y, voxelSize.z)) / samplesPerVoxel` (where `samplesPerVoxel = 1.0`) [S1, unofficial].
    Accumulate `integrated += val / samplesPerVoxel / 4.0` [S1, unofficial].
    If `integrated > 0.95`, break [S1, unofficial].
    Return `clamp(integrated, 0.0, 1.0)` [S1, unofficial].

**Pseudocode:**

```python
def wang_hash(seed):
    seed = (seed ^ 61) ^ (seed >> 16)
    seed *= 9
    seed = seed ^ (seed >> 4)
    seed *= 0x27d4eb2d
    seed = seed ^ (seed >> 15)
    return float(seed % 2147483647) / float(2147483647)

def srgb_conversion(x):
    if x <= 0.0031308:
        return 12.92 * x
    else:
        return 1.055 * pow(x, 1.0 / 2.4) - 0.055

def sample_volume_value(p, volume, volume_dims, rescaleSlope, rescaleIntercept, windowLevel, windowWidth, opacityMapPositions, opacityMapSamples, colorMapPositions, colorMapSamples):
    # 1. Sample raw value from 3D texture
    val = texture(volume, p).r
    
    # 2. Rescale
    rescaled = rescaleSlope * val + rescaleIntercept
    
    # 3. Windowing
    windowFloor = windowLevel - windowWidth / 2.0
    windowed = (rescaled - windowFloor) / windowWidth

def trace_light(voxel, light, volume, volume_dims, samplesPerVoxel):
    voxelToLight = light - voxel
    d = normalize(voxelToLight)
    o = voxel - 1000.0 * d
    
    # Ray-box intersection for light ray
    box = ray_box_intersection(o, d)
    start = length(voxel - o)
    
    voxelSize = 1.0 / vec3(volume_dims)
    delta = min(voxelSize.x, min(voxelSize.y, voxelSize.z)) / samplesPerVoxel
    
    integrated = 0.0
    t = start
    while t < box.y:
        p = o + d * t
        val, _, opacity = sample_volume_value(p, ...) # Simplified for shadow
        integrated += opacity / samplesPerVoxel / 4.0
        if integrated > 0.95:
            break
        t += delta
        
    return clamp(integrated, 0.0, 1.0)

def soft_shadow(p, light, volume, volume_dims):
    voxelSize = 1.0 / vec3(volume_dims)
    delta = min(voxelSize.x, min(voxelSize.y, voxelSize.z)) * 2.0
    
    total_shadow = 0.0
    count = 0
    
    # 3x3 grid excluding center
    for x in [-1, 0, 1]:
        for y in [-1, 0, 1]:
            if x == 0 and y == 0:
                continue
            point = p + vec3(x * delta, y * delta, 0) # Assuming 2D grid in plane? Source says 3x3 grid around voxel.
            # Note: Source says "8 points around the voxel position p in a 3x3 grid (excluding center)".
            # It does not specify the plane. Assuming XY plane relative to voxel or local coordinates.
            # Given "spacing delta", it implies a grid.
            # Let's assume a 3x3 grid in the plane perpendicular to view or light? 
            # Source is vague on orientation. We assume a standard 3x3 grid in the local space or XY plane.
            # However, for shadow, it's usually a hemisphere or grid around the point.
            # We will implement a 3x3 grid in the XY plane relative to p.
            
            pointShadow = 1.0 - trace_light(point, light, ...)
            total_shadow += pointShadow
            count += 1
            
    return total_shadow / 8.0

def fragment_shader(vray_dir, transformed_eye):
    # 1. Ray-Box Intersection
    invDir = 1.0 / vray_dir
    tmin_tmp = (boxMin - transformed_eye) * invDir
    tmax_tmp = (boxMax - transformed_eye) * invDir
    tmin = min(tmin_tmp, tmax_tmp)
    tmax = max(tmin_tmp, tmax_tmp)
    t0 = max(tmin.x, max(tmin.y, tmin.z))
    t1 = min(tmax.x, min(tmax.y, tmax.z))
    
    if t0 > t1:
        discard()
        
    # 2. Step Size
    dt_vec = 1.0 / (vec3(volume_dims) * abs(vray_dir))
    dt = dt_scale * min(dt_vec.x, min(dt_vec.y, dt_vec.z))
    
    # 3. Offset
    offset = wang_hash(int(gl_FragCoord.x + 1024.0 * gl_FragCoord.y))
    p = transformed_eye + (t0 + offset * dt) * vray_dir
    
    # 4. Ray Marching
    voxelColor = vec4(0.0)
    t = t0
    while t < t1:
        val, color, opacity = sample_volume_value(p, ...)
        
        val_color = vec4(opacity * color, opacity)
        val_color.a = 1.0 - pow(1.0 - val_color.a, dt_scale)
        
        voxelColor.rgb += (1.0 - voxelColor.a) * val_color.a * val_color.rgb
        voxelColor.a += (1.0 - voxelColor.a) * val_color.a
        
        if voxelColor.a >= 0.95:
            break
            
        p += vray_dir * dt
        t += dt
        
    # 5. Lighting
    voxelSize = 1.0 / vec3(volume_dims)
    # Normal estimation
    grad_x = (sample_volume_value(p + vec3(voxelSize.x, 0, 0), ...).opacity - sample_volume_value(p - vec3(voxelSize.x, 0, 0), ...).opacity) * (1.0 / (2.0 * voxelSize.x))
    grad_y = (sample_volume_value(p + vec3(0, voxelSize.y, 0), ...).opacity - sample_volume_value(p - vec3(0, voxelSize.y, 0), ...).opacity) * (1.0 / (2.0 * voxelSize.y))
    grad_z = (sample_volume_value(p + vec3(0, 0, voxelSize.z), ...).opacity - sample_volume_value(p - vec3(0, 0, voxelSize.z), ...).opacity) * (1.0 / (2.0 * voxelSize.z))
    voxelNormal = normalize(vec3(grad_x, grad_y, grad_z))
    
    lightDirection = normalize(lightPosition - p)
    intensity = dot(voxelNormal, lightDirection)
    
    specular = 0.5
    diffuse = 0.6
    ambient = 0.4
    shininess = 8.0
    
    spec = 0.0
    if intensity > 0.0:
        h = normalize(lightDirection + transformed_eye)
        intSpec = max(dot(h, voxelNormal), 0.0)
        spec = specular * pow(intSpec, shininess)
        
    shadow = 1.0
    if voxelColor.a >= 0.20:
        shadow = clamp(soft_shadow(p, lightPosition, ...) * 2.0 + 0.1, 0.0, 1.0)
        
    lightColor = shadow * max(intensity * diffuse + spec, ambient)
    voxelColor.rgb = lightColor * voxelColor.rgb
    
    # 6. SRGB Conversion
    final_color = vec3(srgb_conversion(voxelColor.r), srgb_conversion(voxelColor.g), srgb_conversion(voxelColor.b))
    
    return vec4(final_color, 1.0)
```

**Parameters:**
*   `dt_scale`: Scaling factor for step size. Affects number of samples and Beer-Lambert approximation accuracy. Typical value not specified [S1, unofficial].
*   `rescaleSlope`, `rescaleIntercept`: Linear transformation for raw volume values [S1, unofficial].
*   `windowLevel`, `windowWidth`: Windowing parameters for opacity/color mapping [S1, unofficial].
*   `shininess`: Set to 8.0 [S1, unofficial].
*   `diffuse`: 0.6 [S1, unofficial].
*   `ambient`: 0.4 [S1, unofficial].
*   `specular`: 0.5 [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Ray-Box Intersection Failure:** If `t0 > t1`, the ray misses the volume. The fragment is discarded [S1, unofficial].
*   **Early Termination:** The ray marching loop breaks if `voxelColor.a >= 0.95` [S1, unofficial].
*   **Shadow Ray Early Termination:** The light tracing loop breaks if `integrated > 0.95` [S1, unofficial].
*   **Precision:** The use of `highp` for samplers and coordinates is required for WebGL 2.0 [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of samples per ray, which depends on volume dimensions and `dt_scale`. Shadow calculation adds a constant factor (8 samples per shadow ray) and another ray march per sample.
*   **Memory Complexity:** Dominated by the 3D volume texture and 2D map textures.
*   **Performance:** Interactive in modern browsers [S1, unofficial]. Performance is affected by `dt_scale` and shadow ray sampling.
*   **Strengths:** Runs in browsers without plugins; supports non-uniform opacity/color maps via linear search; includes soft shadows.
*   **Limitations:** Linear search for maps is slower than texture sampling; soft shadows are expensive; limited to WebGL 2.0 capabilities.

## Background
This method is an implementation of interactive voxel volume rendering using path tracing, specifically designed for WebGL 2.0 [S1, unofficial]. It is part of a repository providing a browser-based volume renderer [S1, unofficial].
