# GPU Direct Volume Rendering with Anisotropic Shading

Also called: CUDA DVR

## Overview
A GPU-based direct volume ray casting algorithm that enhances visual quality by applying anisotropic shading models (Ward or Lafortune BRDFs) to volumetric data [S1]. It distinguishes itself from standard isotropic shading by precomputing and storing covariance matrices alongside gradients, allowing the reconstruction of local surface orientation and anisotropy axes on-the-fly during ray casting [S1].

## How it works
**Inputs and Outputs:**
*   **Inputs:** 3D scalar field data, precomputed 3D textures for normals and covariance matrices, transfer function $TF$, list of light sources $LS$, Henyey-Greenstein phase function $f_{d,hg}$, Ward BRDF function $f_{s,w}$, background radiance $L_b$, glossiness parameter $\kappa_w$, scaling factor $\gamma_w$, and diffuse coefficient $k_d$ [S1].
*   **Outputs:** Final color image with accumulated radiance and opacity [S1].

**Data Structures:**
*   **Scalar Field:** Stored in a 3D texture [S1].
*   **Prefiltered Normals:** Stored in a 3D texture, quantized to 8 bits per channel [S1].
*   **Covariance Matrices:** Stored in a 3D texture as symmetric 2x2 matrices, quantized to 8 bits per channel [S1]. Eigenvectors are **not** stored; they are computed during rendering to avoid interpolation inconsistencies [S1].

**Algorithm Steps:**
1.  **Preprocessing (Optional):** If prefiltering is enabled, iterate over all voxels $x$, read the symmetric 2x2 matrix $C$, apply Gaussian filtering, and store the result back [S1].
2.  **Ray Casting Loop:** For each pixel $P$:
    a. Initialize accumulated radiance $L = 0$ and transmittance $T = 0$ [S1].
    b. Compute the eye ray and set view direction $\omega = -\text{ray.direction}$ [S1].
    c. While the ray has not finished traversing the volume:
        i. Get the current ray position $x$ [S1].
        ii. Sample the symmetric 2x2 covariance matrix $C$ and the gradient $G_{\sigma t}$ from their respective 3D textures at $x$ [S1].
        iii. Compute the surface normal $N_{\sigma t} = G_{\sigma t} / \text{length}(G_{\sigma t})$ [S1].
        iv. Perform eigenanalysis on $C$ to obtain eigenvalues $\lambda_1, \lambda_2$ and eigenvectors $\Lambda_1, \Lambda_2$ [S1].
        v. Transform eigenvectors $\Lambda_1, \Lambda_2$ to world space and normalize them using $N_{\sigma t}$ to obtain tangent vectors $U$ and $V$ [S1].
        vi. Compute Ward anisotropy parameters $u_w, v_w$ from $\lambda_1, \lambda_2, \kappa_w, \gamma_w$ [S1]. (For Lafortune BRDF, compute corresponding parameters analogously) [S1].
        vii. Compute the specular coefficient $k_s = \text{length}(G_{\sigma t})$ [S1].
        viii. Initialize light contribution $L_i = 0$ [S1].
        ix. For each light source $ls \in LS$:
            1. Compute light direction $\omega_0 = \text{lightDirection}(x, ls)$ [S1].
            2. Compute the BRDF value:
               $$f = k_d f_{d,hg}(\omega_0, \omega) + k_s f_{s,w}(U, V, N_{\sigma t}, u_w, v_w, \omega_0, \omega) (\omega_0 \cdot N_{\sigma t})$$
               [S1]
            3. Add to light contribution:
               $$L_i = L_i + f \cdot \text{incomingRadianceFromLightSource}(x, ls)$$
               [S1]
        x. Composite the light contribution into the accumulator using the transfer function:
           $$(L, T) = \text{composite}(x, TF, L, T, L_i)$$
           [S1]
    d. Return the final color: $T \cdot L_b + L$ [S1].

**Pseudocode:**
```python
def gpu_anisotropic_volume_rendering(
    scalar_field_texture,
    normal_texture,
    covariance_texture,
    transfer_function,
    light_sources,
    kappa_w,
    gamma_w,
    k_d,
    background_radiance,
    light_direction_func,
    incoming_radiance_func,
    composite_func
):
    # Preprocessing step (optional, done once)
    # for x in all_voxels:
    #     C = read_symmetric_2x2_matrix(covariance_texture, x)
    #     C = filter_gaussian(C)
    #     write_symmetric_2x2_matrix(covariance_texture, C, x)

    for pixel in screen:
        L = 0.0
        T = 0.0
        ray = compute_eye_ray(pixel)
        omega = -ray.direction  # View direction

        while ray_casting_not_finished(ray):
            x = get_ray_position(ray)

            # Sample precomputed data
            C = sample_symmetric_2x2_matrix(covariance_texture, x)
            G_sigma_t = sample_gradient(normal_texture, x)

            # Compute normal
            N_sigma_t = normalize(G_sigma_t)

            # Eigenanalysis of covariance matrix
            lambda_1, lambda_2, Lambda_1, Lambda_2 = compute_eigenanalysis(C)

            # Transform eigenvectors to world space and normalize
            U, V = transform_to_world_space_and_normalize(Lambda_1, Lambda_2, N_sigma_t)

            # Compute Ward parameters
            u_w, v_w = compute_ward_parameters(lambda_1, lambda_2, kappa_w, gamma_w)

            # Specular coefficient from gradient magnitude
            k_s = length(G_sigma_t)

            L_i = 0.0
            for ls in light_sources:
                omega_0 = light_direction_func(x, ls)

                # Diffuse term using Henyey-Greenstein phase function
                f_diffuse = k_d * henyey_greenstein_phase(omega_0, omega)

                # Specular term using Ward BRDF
                f_specular = k_s * ward_brdf(U, V, N_sigma_t, u_w, v_w, omega_0, omega) * dot(omega_0, N_sigma_t)

                f = f_diffuse + f_specular

                L_i += f * incoming_radiance_func(x, ls)

            # Composite step
            L, T = composite_func(x, transfer_function, L, T, L_i)

    return T * background_radiance + L
```

**Edge Cases and Pitfalls:**
*   **Eigenvector Interpolation:** Eigenvectors must not be stored or interpolated directly. Interpolating eigenvectors leads to inconsistent results due to sign ambiguity and discontinuities [S1]. Instead, the covariance matrix components are interpolated, and eigenanalysis is performed on-the-fly [S1].
*   **Gradient Normalization:** The normal $N_{\sigma t}$ is derived from the gradient $G_{\sigma t}$. If the gradient magnitude is zero, normalization fails [S1].
*   **Quantization:** Values are quantized to 8 bits per channel. This may introduce artifacts in high-precision requirements, though it is generally sufficient for gradient-based shading [S1].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of ray samples and light sources. The eigenanalysis is performed per ray sample per light source, adding computational overhead compared to isotropic shading [S1].
*   **Memory Complexity:** Requires storage for the scalar field, prefiltered normals, and covariance matrices. Storing the symmetric 2x2 matrix (6 values) and gradient (3 values) per voxel increases memory footprint compared to storing only the scalar field [S1].
*   **Performance:** Interactive visualization is achievable on GPU hardware. On-the-fly eigenanalysis is preferred over precomputing eigenvectors to balance memory usage and computational cost [S1].
*   **Strengths:** Provides realistic anisotropic shading effects for volumetric data, enhancing the perception of structure and orientation [S1].
*   **Limitations:** Higher memory usage due to precomputed textures. More complex than standard isotropic DVR [S1].

## Background
The method is described in "Anisotropic Ambient Volume Shading" [S1]. It builds on the concept of using geometry tensors (covariance matrices) to estimate local surface orientation and anisotropy in volumetric data [S1]. The approach avoids the high cost of on-the-fly curvature estimation by prefiltering and storing the necessary tensor data [S1].
