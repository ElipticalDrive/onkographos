# Back-face rasterized volume rendering

Also called: Back-Face Entry Point Method, Backface Rendering for Ray Casting, Backface Culling for Ray Casting Entry Points

## Overview
Back-face rasterized volume rendering is a GPU-accelerated technique that determines ray entry and exit points for volume ray casting by rasterizing the back faces of the volume's bounding box geometry [S1, S2, S3, S4, unofficial]. It solves the problem of efficiently culling pixels outside the volume and correctly handling camera zooming, which can cause front-face clipping issues [S2, unofficial]. It differs from [Bounding Box Raymarching](2071-bounding-box-raymarching.md) by explicitly utilizing a two-pass approach where the first pass captures back-face coordinates into a texture, and the second pass uses these coordinates to define ray endpoints for front-to-back compositing [S1, S2, S3, unofficial]. Unlike [Volume Ray Casting with RayData Texture](3077-volume-ray-casting-with-raydata-texture.md), which stores ray data in a dedicated texture, this method often computes ray directions from geometry attributes or camera matrices directly in the fragment shader [S5, unofficial].

## How it works
The method uses a two-pass rendering pipeline. The first pass renders the back faces of the volume's bounding box to a 2D texture to store the ray entry (or exit, depending on culling direction) points. The second pass renders the front faces, retrieves the stored points, and performs the ray marching integration [S1, S2, S3, S4, unofficial].

### Inputs and Outputs
*   **Inputs:**
    *   Volume data $V(\mathbf{x})$ stored as a 3D texture (`sampler3D`) or 2D texture array [S1, S4, unofficial].
    *   Transfer function mapping scalar values to color/opacity, stored as a 1D or 2D texture (`sampler1D`/`sampler2D`) [S1, S2, S4, unofficial].
    *   Camera parameters: View matrix, Projection matrix, Eye position [S2, S4, unofficial].
    *   Bounding box geometry: A unit cube $[0,1]^3$ or scaled to volume dimensions [S2, S4, unofficial].
*   **Outputs:**
    *   Final image color buffer (default framebuffer) [S1, S4, unofficial].

### Data Structures
1.  **Bounding Box Geometry:**
    *   Vertices: 8 vertices in object coordinates, typically $\{0.0, 0.0, 0.0\}$ to $\{1.0, 1.0, 1.0\}$ [S4, unofficial].
    *   Indices: 36 indices defining 12 triangles (2 per face) [S4, unofficial].
2.  **Back-Face Texture (`g_bfTexObj` / `u_ExitPoints`):**
    *   Type: 2D texture (`sampler2D`) [S1, S4, unofficial].
    *   Format: `GL_RGBA16F` (half-precision float) or `GL_RGBA32F` [S4, unofficial].
    *   Dimensions: Matches viewport resolution ($g\_winWidth \times g\_winHeight$) [S4, unofficial].
    *   Content: Stores the 3D vertex position (entry/exit point) as RGB color values [S1, S4, unofficial].
3.  **Frame Buffer Object (FBO):**
    *   Attachments: Color attachment bound to `g_bfTexObj`, Depth attachment (optional but recommended for correct back-face rasterization) [S3, S4, unofficial].

### Steps

1.  **Initialization:**
    *   Create FBO and attach `g_bfTexObj` [S4, unofficial].
    *   Define bounding box VBO/VAO [S4, unofficial].
    *   Load volume and transfer function textures [S1, S4, unofficial].

2.  **Pass 1: Capture Back-Face Points**
    *   Bind FBO (`g_frameBuffer`) [S1, S4, unofficial].
    *   Set viewport to $(0, 0, g\_winWidth, g\_winHeight)$ [S1, S4, unofficial].
    *   Enable depth test and face culling [S4, unofficial].
    *   Set `glCullFace(GL_FRONT)` to render only back faces [S1, S4, unofficial].
    *   Use back-face vertex/fragment shaders [S1, S4, unofficial].
        *   **Vertex Shader:** Transform vertex position to clip space. Output vertex position in object/local space as `fragPos` [S4, unofficial].
        *   **Fragment Shader:** Write `fragPos` (as `vec4`) to output color `gExisPoints` [S4, unofficial].
    *   Draw bounding box (`glDrawElements`) [S1, S4, unofficial].
    *   Unbind FBO [S1, S4, unofficial].

3.  **Pass 2: Ray Casting and Compositing**
    *   Bind default framebuffer [S1, S4, unofficial].
    *   Set viewport [S1, S4, unofficial].
    *   Enable face culling. Set `glCullFace(GL_BACK)` to render only front faces [S1, S4, unofficial].
    *   Use ray-casting vertex/fragment shaders [S1, S4, unofficial].
    *   **Vertex Shader:**
        *   Transform vertex to clip space.
        *   Output vertex position in object/local space as `EntryPoint` (front face position) [S4, unofficial].
        *   (Alternative: Compute ray direction in eye space using camera matrices [S2, S5, unofficial]).
    *   **Fragment Shader:**
        *   Sample `u_ExitPoints` texture using `gl_FragCoord.st / u_Resolution` to retrieve the back-face position (`exitPoint`) [S4, unofficial].
        *   Compute ray direction: $\mathbf{d} = \text{exitPoint} - \text{EntryPoint}$ [S1, S4, unofficial].
        *   Compute ray length: $L = \|\mathbf{d}\|$ [S4, unofficial].
        *   If $L \approx 0$ (entry equals exit), discard fragment [S4, unofficial].
        *   Compute step vector: $\mathbf{s} = \frac{\mathbf{d}}{N}$ or $\mathbf{s} = \text{normalize}(\mathbf{d}) \cdot \Delta t$ [S1, S4, unofficial].
        *   Initialize accumulated color $C' = (0,0,0,0)$ and opacity $\alpha' = 0$ [S1, S4, unofficial].
        *   Initialize current position $\mathbf{p} = \text{EntryPoint}$ [S1, S4, unofficial].
        *   **Ray Marching Loop:** For $i = 0$ to $N-1$:
            1.  Sample volume value $v = V(\mathbf{p})$ [S1, S4, unofficial].
            2.  Map $v$ to color $C_i$ and opacity $\alpha_i$ using transfer function [S1, S4, unofficial].
            3.  If $\alpha_i > 0$:
                $$ C' = C' + (1 - \alpha') \alpha_i C_i $$
                $$ \alpha' = \alpha' + (1 - \alpha') \alpha_i $$
            4.  Advance position: $\mathbf{p} = \mathbf{p} + \mathbf{s}$ [S1, S4, unofficial].
            5.  **Early Termination:** If $\alpha' \ge 1.0$ (or threshold 0.95), break loop [S1, S2, S3, unofficial].
            6.  **Boundary Check:** If $\mathbf{p}$ is outside $[0,1]^3$, break loop [S1, unofficial].
        *   Output final $C'$ to framebuffer [S1, S4, unofficial].

### Pseudocode

```python
# Pass 1: Back-Face Capture
def pass1_capture_backface():
    bind_framebuffer(g_frameBuffer)
    set_viewport(0, 0, g_winWidth, g_winHeight)
    enable_depth_test()
    enable_cull_face()
    set_cull_face(GL_FRONT) # Render back faces
    
    use_shader(backface_program)
    set_uniform("MVP", projection * view * model)
    
    # Vertex shader outputs fragPos (object space position)
    # Fragment shader outputs fragPos as color
    draw_elements(GL_TRIANGLES, 36, GL_UNSIGNED_INT, indices)
    
    unbind_framebuffer()

# Pass 2: Ray Casting
def pass2_ray_casting():
    bind_framebuffer(0) # Default framebuffer
    set_viewport(0, 0, g_winWidth, g_winHeight)
    enable_cull_face()
    set_cull_face(GL_BACK) # Render front faces
    
    use_shader(raycast_program)
    set_uniform("u_ExitPoints", g_bfTexObj)
    set_uniform("u_VolumeTex", volume_texture)
    set_uniform("u_TransferFunc", transfer_function)
    set_uniform("u_Resolution", (g_winWidth, g_winHeight))
    set_uniform("u_StepSize", step_size) # Or uSteps
    
    # Vertex shader outputs EntryPoint (object space position)
    # Fragment shader computes ray and marches
    
    draw_elements(GL_TRIANGLES, 36, GL_UNSIGNED_INT, indices)

# Fragment Shader Logic (Pass 2)
def fragment_shader_ray_casting(entry_point: vec3):
    # Retrieve exit point from texture sampled at current fragment coordinates
    exit_point = texture(u_ExitPoints, gl_FragCoord.xy / u_Resolution).xyz
    
    # Check for degenerate ray
    if length(exit_point - entry_point) < 1e-6:
        discard()
        
    # Compute ray parameters
    ray_dir = exit_point - entry_point
    ray_len = length(ray_dir)
    step_vec = ray_dir / u_StepSize # Assuming u_StepSize is total steps or normalized step
    
    # Initialize accumulation
    accum_color = vec4(0.0)
    accum_alpha = 0.0
    
    # Current position
    pos = entry_point
    
    # Marching loop
    # Note: Loop count depends on implementation (fixed N or length-based)
    for i in range(1600): # Typical max steps
        # Sample volume
        vol_val = texture(u_VolumeTex, pos).r
        
        # Transfer function
        tf_sample = texture(u_TransferFunc, vec2(vol_val, 0.5)) # 2D TF or 1D mapped
        color_sample = tf_sample.rgb
        alpha_sample = tf_sample.a
        
        # Compositing
        if alpha_sample > 0.0:
            # Adjust alpha based on step size if necessary
            # alpha_sample = 1.0 - pow(1.0 - alpha_sample, step_factor)
            
            accum_color.rgb += (1.0 - accum_alpha) * alpha_sample * color_sample
            accum_alpha += (1.0 - accum_alpha) * alpha_sample
            
        # Advance
        pos += step_vec
        
        # Early termination
        if accum_alpha >= 1.0:
            break
            
        # Boundary check (if pos goes outside [0,1])
        if any(pos < 0.0) or any(pos > 1.0):
            break
            
    # Background composition (if needed)
    # accum_color.rgb = accum_color.rgb + (1.0 - accum_alpha) * background_color
    
    return accum_color
```

### Parameters
*   **uSteps / u_StepSize:** Number of sampling steps or step size. Typical value: 256 steps [S1, unofficial].
*   **uOpacityVal:** Opacity scaling factor. Typical value: 4.0 [S1, unofficial].
*   **uMinGrayVal / uMaxGrayVal:** Volume value thresholds. Typical: 0.001 to 1.0 [S1, unofficial].
*   **uAbsorptionModeIndex:** Rendering mode switch (0: Simple accumulation, 1: Alpha blending, 2: Max projection) [S1, unofficial].
*   **DELTA:** Constant step size. Value: 0.005 [S3, unofficial].

### Edge Cases and Pitfalls
*   **Zooming:** Rendering front faces causes clipping when the camera zooms inside the volume. Rendering back faces avoids this [S2, unofficial].
*   **Degenerate Rays:** If entry point equals exit point (ray misses or is tangent), the shader must discard the fragment to avoid division by zero [S4, unofficial].
*   **Loop Termination:** GLSL loop limits may require a large constant (e.g., 4095) with an explicit break condition based on `uSteps` [S1, unofficial].
*   **Boundary Access:** Ensure position checks prevent out-of-bounds texture sampling [S1, unofficial].
*   **Mida Mode:** Some compositing modes (e.g., 'mida') may not work correctly [S3, unofficial].

## Subtopics

### [Bounding Box Raymarching](2071-bounding-box-raymarching.md)
A variant that explicitly uses a two-pass approach to derive ray bounds from geometry colors, avoiding manual ray-box intersection math in the fragment shader.

### [Volume Ray Casting with RayData Texture](3077-volume-ray-casting-with-raydata-texture.md)
Stores ray data in a dedicated texture, differing from back-face rasterization which derives endpoints from geometry attributes.

## Operating characteristics
*   **Time Complexity:** $O(N \cdot W \cdot H)$, where $N$ is the number of samples per ray, and $W \times H$ is the resolution. The two-pass approach adds a constant overhead.
*   **Memory Complexity:** $O(W \cdot H)$ for the back-face texture storage [S4, unofficial].
*   **Performance:** Efficiently culls pixels outside the volume, reducing fragment shader invocations [S2, unofficial]. Performance scales with resolution and step count.
*   **Strengths:** Handles zooming correctly; avoids complex ray-box intersection calculations in the fragment shader for boundary determination [S2, S4, unofficial].
*   **Limitations:** Requires two render passes; extra memory for the intermediate texture [S4, unofficial].

## Background
The method is a standard technique in GPU-accelerated volume rendering, leveraging the graphics pipeline's rasterization capabilities to determine ray boundaries. It is commonly implemented in WebGL and OpenGL contexts [S1, S2, S4, unofficial].
