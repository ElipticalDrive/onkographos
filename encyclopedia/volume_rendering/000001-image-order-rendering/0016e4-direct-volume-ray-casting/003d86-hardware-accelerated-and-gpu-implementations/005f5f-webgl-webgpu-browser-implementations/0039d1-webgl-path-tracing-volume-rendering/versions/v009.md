# WebGL Path Tracing Volume Rendering

Also called: Interactive Voxel Volume Rendering via WebGL 2.0

## Overview
An interactive voxel volume renderer using path tracing that runs in modern browsers via WebGL 2.0. It renders 3D scalar fields (volumes) by casting rays from the camera through the volume, accumulating color and opacity along the ray, and applying lighting/shadowing [S1, unofficial]. It differs from its siblings by using a single-pass fragment shader approach with explicit ray-box intersection and Beer-Lambert integration, rather than geometry-based intersection or structured data traversal [S1, unofficial].

## How it works
**Inputs and Outputs:**
The method runs in a WebGL 2.0 fragment shader.
*   **Uniforms:** `volume` (highp sampler3D), `volume_dims` (ivec3), `dt_scale` (float), `lightPosition` (vec3), `windowLevel` (float), `windowWidth` (float), `rescaleIntercept` (float), `rescaleSlope` (float), `numberOfOpacitySamples` (int), `opacityMapPositions` (highp sampler2D), `opacityMapSamples` (highp sampler2D), `numberOfColorSamples` (int), `colorMapPositions` (highp sampler2D), `colorMapSamples` (highp sampler2D).
*   **Varyings/Inputs:** `vray_dir` (vec3), `transformed_eye` (vec3).
*   **Output:** `color` (vec4).

**Data Structures:**
*   **Opacity/Color Maps:** Defined by `numberOfOpacitySamples` (or `numberOfColorSamples`) pairs of positions and samples. These are stored in 2D textures (`opacityMapPositions`, `opacityMapSamples`, etc.). The positions are non-uniform, requiring linear search rather than texture sampling [S1, unofficial].
*   **Volume:** Stored in a 3D texture (`volume`).

**Parameters:**
*   `dt_scale`: Scaling factor for step size. Typical value not specified [S1, unofficial].
*   `rescaleSlope`, `rescaleIntercept`: Linear transformation parameters. `rescaled_value = rescaleSlope * raw_value + rescaleIntercept` [S1, unofficial].
*   `shininess`: 8.0 [S1, unofficial].
*   `diffuse`: 0.6 [S1, unofficial].
*   `ambient`: 0.4 [S1, unofficial].
*   `specular`: 0.5 [S1, unofficial].
*   `samplesPerVoxel`: 1.0 [S1, unofficial].

**Steps:**

1.  **Ray-Box Intersection:**
    Compute `invDir = 1.0 / dir`.
    Compute `tmin_tmp = (boxMin - orig) * invDir` and `tmax_tmp = (boxMax - orig) * invDir`.
    Compute `tmin = min(tmin_tmp, tmax_tmp)` and `tmax = max(tmin_tmp, tmax_tmp)`.
    Compute `t0 = max(tmin.x, max(tmin.y, tmin.z))` and `t1 = min(tmax.x, min(tmax.y, tmax.z))`.
    Return `vec2(t0, t1)`.
    If `t_hit.x > t_hit.y`, discard the fragment [S1, unofficial].

2.  **Step Size Calculation:**
    Compute `dt_vec = 1.0 / (vec3(volume_dims) * abs(ray_dir))`.
    Compute `dt = dt_scale * min(dt_vec.x, min(dt_vec.y, dt_vec.z))` [S1, unofficial].

3.  **Ray Origin Offset:**
    Generate a random offset using `wang_hash(int(gl_FragCoord.x + 1024.0 * gl_FragCoord.y))`.
    Compute initial position `p = transformed_eye + (t_hit.x + offset * dt) * ray_dir` [S1, unofficial].

4.  **Ray Marching Loop:**
    Initialize `voxelColor = vec4(0.0)`.
    Loop `t` from `t_hit.x` to `t_hit.y` with step `dt`:
    a.  Sample volume value `val`.
    b.  Get color `color` and opacity `opacity` (see Opacity/Color Mapping below).
    c.  Compute `val_color = vec4(opacity * color, opacity)`.
    d.  Apply Beer-Lambert law approximation: `val_color.a = 1.0 - pow(1.0 - val_color.a, dt_scale)`.
    e.  Update accumulated color: `voxelColor.rgb += (1.0 - voxelColor.a) * val_color.a * val_color.rgb`.
    f.  Update accumulated alpha: `voxelColor.a += (1.0 - voxelColor.a) * val_color.a`.
    g.  If `voxelColor.a >= 0.95`, break [S1, unofficial].
    h.  Advance position `p += ray_dir * dt` [S1, unofficial].

5.  **Lighting Calculation:**
    a.  Compute normal at the final ray position `p` using central differences of opacity (see Normal Estimation below).
    b.  Compute light direction `lightDirection = normalize(p - lightPosition)`.
    c.  Compute diffuse intensity `intensity = dot(voxelNormal, lightDirection)`.
    d.  Compute specular: if `intensity > 0.0`, compute half vector `h = normalize(lightDirection + transformed_eye)`, `intSpec = max(dot(h, voxelNormal), 0.0)`, `spec = specular * pow(intSpec, shininess)` with `shininess = 8.0`.
    e.  Compute shadow: if `voxelColor.a >= 0.20`, `shadow = clamp(softShadow(p) * 2.0 + 0.1, 0.0, 1.0)`, else `shadow = 1.0`.
    f.  Compute final light color: `lightColor = shadow * max(intensity * diffuse + spec, ambient)` with `diffuse=0.6`, `ambient=0.4`, `specular=0.5` [S1, unofficial].

6.  **Opacity Mapping:**
    Apply the opacity map to the rescaled value. The opacity map is defined by `numberOfOpacitySamples` pairs of positions and samples stored in 2D textures.
    Find the interval `[opacityMapPosition(i-1), opacityMapPosition(i)]` containing the value.
    Interpolate between `opacityMapSample(i-1)` and `opacityMapSample(i)` using linear interpolation.
    Clamp the result multiplied by `(value - windowFloor) / windowWidth` to [0, 1], where `windowFloor = windowLevel - windowWidth / 2.0` [S1, unofficial].

7.  **Color Mapping:**
    Apply the color map to the rescaled value. Similar to opacity, find the interval in `colorMapPositions` and interpolate between `colorMapSample(i-1)` and `colorMapSample(i)` [S1, unofficial].

8.  **Normal Estimation:**
    Compute voxel size `voxelSize = 1.0 / vec3(volume_dims)`.
    Compute gradient using central differences of `sampleVolumeOpacity` (which applies opacity map to rescaled volume value).
    `gradient.x = (sampleVolumeOpacity(position + vec3(voxelSize.x, 0, 0)) - sampleVolumeOpacity(position - vec3(voxelSize.x, 0, 0))) * (1.0 / (2.0 * voxelSize.x))`, similarly for y and z.
    Normalize the gradient [S1, unofficial].

9.  **Soft Shadow Calculation:**
    Sample 8 points around the voxel position `p` in a 3x3 grid (excluding center) with spacing `delta = min(voxelSize.x, min(voxelSize.y, voxelSize.z)) * 2.0`.
    For each point, compute `pointShadow = 1.0 - traceLight(position, lightPosition)`.
    Sum these shadows and divide by 8.0 [S1, unofficial].

10. **Light Tracing (Shadow Ray):**
    Cast a ray from `voxel` towards `light`.
    Compute `voxelToLight = light - voxel`, `d = normalize(voxelToLight)`, `o = voxel - 1000.0 * d`.
    Intersect ray with box to get `box`.
    Compute `start = length(voxel - o)`.
    Sample opacity along the ray from `start` to `box.y` with step `delta = min(voxelSize.x, min(voxelSize.y, voxelSize.z)) / samplesPerVoxel` (where `samplesPerVoxel = 1.0`).
    Accumulate `integrated += val / samplesPerVoxel / 4.0`.
    If `integrated > 0.95`, break.
    Return `clamp(integrated, 0.0, 1.0)` [S1, unofficial].

11. **Random Number Generation:**
    Use Wang hash for pseudo-random numbers.
    `seed = (seed ^ 61) ^ (seed >> 16); seed *= 9; seed = seed ^ (seed >> 4); seed *= 0x27d4eb2d; seed = seed ^ (seed >> 15); return float(seed % 2147483647) / float(2147483647);` [S1, unofficial].

12. **SRGB Conversion:**
    Convert linear color to SRGB.
    If `x <= 0.0031308f`, return `12.92f * x`.
    Else return `1.055f * pow(x, 1.f / 2.4f) - 0.055f` [S1, unofficial].

**Pseudocode:**

```python
def wang_hash(seed):
    seed = (seed ^ 61) ^ (seed >> 16)
    seed *= 9
    seed = seed ^ (seed >> 4)
    seed *= 0x27d4eb2d
    seed = seed ^ (seed >> 15)
    return float(seed % 2147483647) / float(2147483647)

def srgb_convert(x):
    if x <= 0.0031308:
        return 12.92 * x
    else:
        return 1.055 * pow(x, 1.0 / 2.4) - 0.055

def sample_volume_opacity(position, volume_dims, opacity_map_positions, opacity_map_samples, num_opacity_samples, window_level, window_width, rescale_slope, rescale_intercept):
    # Sample raw volume value
    raw_val = sample3d(volume, position)
    # Rescale
    rescaled_val = rescale_slope * raw_val + rescale_intercept
    # Windowing
    window_floor = window_level - window_width / 2.0
    normalized_val = (rescaled_val - window_floor) / window_width
    
    # Linear search for opacity map interval
    opacity = 0.0
    for i in range(1, num_opacity_samples):
        pos_prev = opacity_map_positions[i-1]
        pos_curr = opacity_map_positions[i]
        if pos_prev <= normalized_val <= pos_curr:
            samp_prev = opacity_map_samples[i-1]
            samp_curr = opacity_map_samples[i]
            # Linear interpolation
            t = (normalized_val - pos_prev) / (pos_curr - pos_prev) if pos_curr != pos_prev else 0.0
            opacity = samp_prev + t * (samp_curr - samp_prev)
            break
    return clamp(opacity, 0.0, 1.0)

def trace_light(voxel, light_position, volume_dims, samples_per_voxel):
    voxel_to_light = light_position - voxel
    d = normalize(voxel_to_light)
    o = voxel - 1000.0 * d
    
    # Ray-box intersection for shadow ray
    inv_dir = 1.0 / d
    tmin_tmp = (box_min - o) * inv_dir
    tmax_tmp = (box_max - o) * inv_dir
    tmin = min(tmin_tmp, tmax_tmp)
    tmax = max(tmin_tmp, tmax_tmp)
    t0 = max(tmin.x, max(tmin.y, tmin.z))
    t1 = min(tmax.x, min(tmax.y, tmax.z))
    
    if t0 > t1:
        return 1.0 # No intersection, fully lit
    
    start = length(voxel - o)
    voxel_size = 1.0 / vec3(volume_dims)
    delta = min(voxel_size.x, min(voxel_size.y, voxel_size.z)) / samples_per_voxel
    
    integrated = 0.0
    t = start
    while t < t1:
        pos = o + d * t
        val = sample_volume_opacity(pos, ...) # Assumes necessary uniforms are available
        integrated += val / samples_per_voxel / 4.0
        if integrated > 0.95:
            break
        t += delta
        
    return clamp(integrated, 0.0, 1.0)

def fragment_shader(vray_dir, transformed_eye, ...):
    # 1. Ray-Box Intersection
    inv_dir = 1.0 / vray_dir
    tmin_tmp = (box_min - transformed_eye) * inv_dir
    tmax_tmp = (box_max - transformed_eye) * inv_dir
    tmin = min(tmin_tmp, tmax_tmp)
    tmax = max(tmin_tmp, tmax_tmp)
    t0 = max(tmin.x, max(tmin.y, tmin.z))
    t1 = min(tmax.x, min(tmax.y, tmax.z))
    
    if t0 > t1:
        discard()
        
    # 2. Step Size
    dt_vec = 1.0 / (vec3(volume_dims) * abs(vray_dir))
    dt = dt_scale * min(dt_vec.x, min(dt_vec.y, dt_vec.z))
    
    # 3. Ray Origin Offset
    seed = int(gl_FragCoord.x + 1024.0 * gl_FragCoord.y)
    offset = wang_hash(seed)
    p = transformed_eye + (t0 + offset * dt) * vray_dir
    
    # 4. Ray Marching
    voxel_color = vec4(0.0)
    t = t0
    while t < t1:
        # Sample Volume
        raw_val = sample3d(volume, p)
        rescaled_val = rescale_slope * raw_val + rescale_intercept
        window_floor = window_level - window_width / 2.0
        normalized_val = (rescaled_val - window_floor) / window_width
        
        # Opacity Map
        opacity = 0.0
        for i in range(1, numberOfOpacitySamples):
            pos_prev = opacityMapPositions[i-1]
            pos_curr = opacityMapPositions[i]
            if pos_prev <= normalized_val <= pos_curr:
                samp_prev = opacityMapSamples[i-1]
                samp_curr = opacityMapSamples[i]
                t_interp = (normalized_val - pos_prev) / (pos_curr - pos_prev) if pos_curr != pos_prev else 0.0
                opacity = samp_prev + t_interp * (samp_curr - samp_prev)
                break
        opacity = clamp(opacity, 0.0, 1.0)
        
        # Color Map
        color = vec3(0.0)
        for i in range(1, numberOfColorSamples):
            pos_prev = colorMapPositions[i-1]
            pos_curr = colorMapPositions[i]
            if pos_prev <= normalized_val <= pos_curr:
                samp_prev = colorMapSamples[i-1]
                samp_curr = colorMapSamples[i]
                t_interp = (normalized_val - pos_prev) / (pos_curr - pos_prev) if pos_curr != pos_curr else 0.0
                color = samp_prev + t_interp * (samp_curr - samp_prev)
                break
                
        val_color = vec4(opacity * color, opacity)
        val_color.a = 1.0 - pow(1.0 - val_color.a, dt_scale)
        
        voxel_color.rgb += (1.0 - voxel_color.a) * val_color.a * val_color.rgb
        voxel_color.a += (1.0 - voxel_color.a) * val_color.a
        
        if voxel_color.a >= 0.95:
            break
            
        p += vray_dir * dt
        t += dt
        
    # 5. Lighting
    # Normal Estimation
    voxel_size = 1.0 / vec3(volume_dims)
    grad_x = (sample_volume_opacity(p + vec3(voxel_size.x, 0, 0), ...) - sample_volume_opacity(p - vec3(voxel_size.x, 0, 0), ...)) * (1.0 / (2.0 * voxel_size.x))
    grad_y = (sample_volume_opacity(p + vec3(0, voxel_size.y, 0), ...) - sample_volume_opacity(p - vec3(0, voxel_size.y, 0), ...)) * (1.0 / (2.0 * voxel_size.y))
    grad_z = (sample_volume_opacity(p + vec3(0, 0, voxel_size.z), ...) - sample_volume_opacity(p - vec3(0, 0, voxel_size.z), ...)) * (1.0 / (2.0 * voxel_size.z))
    voxel_normal = normalize(vec3(grad_x, grad_y, grad_z))
    
    light_direction = normalize(lightPosition - p)
    intensity = dot(voxel_normal, light_direction)
    
    spec = 0.0
    if intensity > 0.0:
        h = normalize(light_direction + transformed_eye)
        int_spec = max(dot(h, voxel_normal), 0.0)
        spec = 0.5 * pow(int_spec, 8.0)
        
    shadow = 1.0
    if voxel_color.a >= 0.20:
        shadow = clamp(soft_shadow(p, lightPosition, volume_dims) * 2.0 + 0.1, 0.0, 1.0)
        
    light_color = shadow * max(intensity * 0.6 + spec, 0.4)
    
    final_color = voxel_color.rgb * light_color
    final_color = srgb_convert(final_color)
    
    return vec4(final_color, 1.0)
```

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of samples along the ray. The number of samples is determined by `dt_scale` and the volume dimensions. Shadow calculation adds a constant factor (8 shadow rays, each with its own marching loop).
*   **Memory Complexity:** Depends on the volume texture size and the number of opacity/color map samples. The opacity/color maps are stored in 2D textures.
*   **Measured Performance:** Not given in the sources.
*   **Scaling:** Performance scales with resolution and `dt_scale`. Higher `dt_scale` reduces samples but may introduce artifacts. Early termination at `voxelColor.a >= 0.95` can significantly reduce computation for opaque regions.
*   **Strengths:** Interactive performance in browsers, simple implementation, flexible opacity/color mapping.
*   **Limitations:** Linear search for opacity/color maps can be slow for large maps. Shadow calculation is expensive. No global illumination.
*   **When to use:** Interactive visualization of scalar fields in web browsers.
*   **When not:** High-fidelity offline rendering, volumes with very large opacity/color maps, scenes requiring global illumination.
