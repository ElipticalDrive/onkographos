# WebGL Path Tracing Volume Rendering

Also called: Interactive Voxel Volume Rendering via WebGL 2.0

## Overview
An interactive voxel volume renderer using path tracing that runs in modern browsers via WebGL 2.0 [S1, unofficial]. It renders 3D scalar fields by casting rays from the camera through the volume, accumulating color and opacity along the ray, and applying lighting/shadowing [S1, unofficial]. It differs from standard ray casting by computing normals via central differences of opacity and applying Phong-like lighting with soft shadows, rather than relying solely on direct illumination or pre-computed lighting [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs**:
    *   `volume`: `highp sampler3D` containing the scalar field [S1, unofficial].
    *   `volume_dims`: `ivec3` defining the dimensions of the volume texture [S1, unofficial].
    *   `transformed_eye`: `vec3` camera position in world space [S1, unofficial].
    *   `vray_dir`: `vec3` ray direction in world space [S1, unofficial].
    *   `dt_scale`: `float` step size scaling factor [S1, unofficial].
    *   `lightPosition`: `vec3` light source position [S1, unofficial].
    *   `windowLevel`, `windowWidth`: `float` for window/level adjustment [S1, unofficial].
    *   `rescaleSlope`, `rescaleIntercept`: `float` for linear transformation of raw values [S1, unofficial].
    *   `numberOfOpacitySamples`, `opacityMapPositions`, `opacityMapSamples`: `int`, `highp sampler2D`, `highp sampler2D` for opacity transfer function [S1, unofficial].
    *   `numberOfColorSamples`, `colorMapPositions`, `colorMapSamples`: `int`, `highp sampler2D`, `highp sampler2D` for color transfer function [S1, unofficial].
*   **Output**: `vec4` color (RGBA) for the fragment [S1, unofficial].

**Data Structures**
*   **Opacity/Color Maps**: Stored in 2D textures where the x-coordinate represents the position (control point) and the y-coordinate represents the sample value (opacity or color intensity) [S1, unofficial]. The number of control points is given by `numberOfOpacitySamples` or `numberOfColorSamples` [S1, unofficial].
*   **Volume**: Stored in a 3D texture (`sampler3D`) [S1, unofficial].

**Algorithm Steps**

1.  **Ray-Box Intersection**:
    Compute the intersection of the ray with the volume's bounding box [S1, unofficial].
    $$
    \text{invDir} = \frac{1.0}{\text{dir}}
    $$
    $$
    t_{\text{min\_tmp}} = (\text{boxMin} - \text{orig}) \times \text{invDir}
    $$
    $$
    t_{\text{max\_tmp}} = (\text{boxMax} - \text{orig}) \times \text{invDir}
    $$
    $$
    t_{\text{min}} = \min(t_{\text{min\_tmp}}, t_{\text{max\_tmp}})
    $$
    $$
    t_{\text{max}} = \max(t_{\text{min\_tmp}}, t_{\text{max\_tmp}})
    $$
    $$
    t_0 = \max(t_{\text{min}.x, \max(t_{\text{min}.y, t_{\text{min}.z})})
    $$
    $$
    t_1 = \min(t_{\text{max}.x, \min(t_{\text{max}.y, t_{\text{max}.z})})
    $$
    If $t_0 > t_1$, the ray does not intersect the volume; discard the fragment [S1, unofficial].

2.  **Step Size Calculation**:
    Compute the step size $dt$ based on the volume dimensions and ray direction to ensure consistent sampling density relative to voxel size [S1, unofficial].
    $$
    dt_{\text{vec}} = \frac{1.0}{\text{volume\_dims} \times |\text{ray\_dir}|}
    $$
    $$
    dt = dt_{\text{scale}} \times \min(dt_{\text{vec}.x, \min(dt_{\text{vec}.y, dt_{\text{vec}.z})})
    $$
    Typical value for $dt_{\text{scale}}$ is not specified in the sources [S1, unofficial].

3.  **Ray Origin Offset**:
    Generate a random offset to reduce aliasing [S1, unofficial].
    $$
    \text{seed} = \text{wang\_hash}(\text{int}(gl\_FragCoord.x + 1024.0 \times gl\_FragCoord.y))
    $$
    $$
    \text{offset} = \frac{\text{seed}}{2147483647.0}
    $$
    $$
    p = \text{transformed\_eye} + (t_0 + \text{offset} \times dt) \times \text{ray\_dir}
    $$
    The `wang_hash` function is defined as:
    ```python
    def wang_hash(seed):
        seed = (seed ^ 61) ^ (seed >> 16)
        seed *= 9
        seed = seed ^ (seed >> 4)
        seed *= 0x27d4eb2d
        seed = seed ^ (seed >> 15)
        return seed % 2147483647
    ```
    [S1, unofficial].

4.  **Value Rescaling**:
    Apply linear transformation to raw volume values [S1, unofficial].
    $$
    \text{rescaled\_value} = \text{rescaleSlope} \times \text{raw\_value} + \text{rescaleIntercept}
    $$

5.  **Transfer Function Application**:
    *   **Opacity**: Find the interval $[opacityMapPositions(i-1), opacityMapPositions(i)]$ containing the rescaled value. Interpolate between $opacityMapSamples(i-1)$ and $opacityMapSamples(i)$ using linear interpolation. Clamp the result multiplied by $\frac{\text{value} - \text{windowFloor}}{\text{windowWidth}}$ to $[0, 1]$, where $\text{windowFloor} = \text{windowLevel} - \frac{\text{windowWidth}}{2.0}$ [S1, unofficial].
    *   **Color**: Similar to opacity, find the interval in $colorMapPositions$ and interpolate between $colorMapSamples(i-1)$ and $colorMapSamples(i)$ [S1, unofficial].

6.  **Ray Marching Loop**:
    Initialize `voxelColor = vec4(0.0)`. Loop $t$ from $t_0$ to $t_1$ with step $dt$ [S1, unofficial].
    Inside the loop:
    *   Sample volume value `val` at current position $p$.
    *   Get `color` and `opacity` from transfer functions applied to `val`.
    *   Compute `val_color = vec4(opacity * color, opacity)`.
    *   Apply Beer-Lambert law approximation:
        $$
        val\_color.a = 1.0 - (1.0 - val\_color.a)^{dt_{\text{scale}}}
        $$
    *   Update accumulated color:
        $$
        voxelColor.rgb += (1.0 - voxelColor.a) \times val\_color.a \times val\_color.rgb
        $$
    *   Update accumulated alpha:
        $$
        voxelColor.a += (1.0 - voxelColor.a) \times val\_color.a
        $$
    *   If $voxelColor.a \ge 0.95$, break [S1, unofficial].
    *   Advance position: $p += \text{ray\_dir} \times dt$.

7.  **Lighting Calculation**:
    *   **Normal Estimation**: Compute voxel size:
        $$
        \text{voxelSize} = \frac{1.0}{\text{volume\_dims}}
        $$
        Compute gradient using central differences of `sampleVolumeOpacity` (which applies opacity map to rescaled volume value):
        $$
        \text{gradient}.x = \frac{\text{sampleVolumeOpacity}(p + \text{vec3}(\text{voxelSize}.x, 0, 0)) - \text{sampleVolumeOpacity}(p - \text{vec3}(\text{voxelSize}.x, 0, 0))}{2.0 \times \text{voxelSize}.x}
        $$
        Similarly for $y$ and $z$. Normalize the gradient to get `voxelNormal` [S1, unofficial].
    *   **Diffuse**:
        $$
        \text{lightDirection} = \text{normalize}(\text{lightPosition} - p)
        $$
        $$
        \text{intensity} = \text{dot}(\text{voxelNormal}, \text{lightDirection})
        $$
    *   **Specular**:
        If $\text{intensity} > 0.0$:
        $$
        h = \text{normalize}(\text{lightDirection} + \text{transformed\_eye})
        $$
        $$
        \text{intSpec} = \max(\text{dot}(h, \text{voxelNormal}), 0.0)
        $$
        $$
        \text{spec} = \text{specular} \times \text{pow}(\text{intSpec}, \text{shininess})
        $$
        With $\text{shininess} = 8.0$, $\text{specular} = 0.5$, $\text{diffuse} = 0.6$, $\text{ambient} = 0.4$ [S1, unofficial].
    *   **Shadow**:
        If $voxelColor.a \ge 0.20$:
        $$
        \text{shadow} = \text{clamp}(\text{softShadow}(p) \times 2.0 + 0.1, 0.0, 1.0)
        $$
        Else:
        $$
        \text{shadow} = 1.0
        $$
    *   **Final Light Color**:
        $$
        \text{lightColor} = \text{shadow} \times \max(\text{intensity} \times \text{diffuse} + \text{spec}, \text{ambient})
        $$
    *   Apply `lightColor` to the accumulated `voxelColor` [S1, unofficial].

8.  **Soft Shadow Calculation**:
    Sample 8 points around the voxel position $p$ in a 3x3 grid (excluding center) with spacing $\delta = \min(\text{voxelSize}.x, \min(\text{voxelSize}.y, \text{voxelSize}.z)) \times 2.0$ [S1, unofficial]. For each point, compute:
    $$
    \text{pointShadow} = 1.0 - \text{traceLight}(\text{position}, \text{lightPosition})
    $$
    Sum these shadows and divide by 8.0 [S1, unofficial].

9.  **Light Tracing (Shadow Ray)**:
    Cast a ray from `voxel` towards `light` [S1, unofficial].
    $$
    \text{voxelToLight} = \text{light} - \text{voxel}
    $$
    $$
    d = \text{normalize}(\text{voxelToLight})
    $$
    $$
    o = \text{voxel} - 1000.0 \times d
    $$
    Intersect ray with box to get `box`. Compute `start = length(voxel - o)` [S1, unofficial].
    Sample opacity along the ray from `start` to `box.y` with step $\delta = \frac{\min(\text{voxelSize}.x, \min(\text{voxelSize}.y, \text{voxelSize}.z))}{\text{samplesPerVoxel}}$ (where $\text{samplesPerVoxel} = 1.0$) [S1, unofficial].
    Accumulate:
    $$
    \text{integrated} += \frac{\text{val}}{\text{samplesPerVoxel} \times 4.0}
    $$
    If $\text{integrated} > 0.95$, break [S1, unofficial].
    Return $\text{clamp}(\text{integrated}, 0.0, 1.0)$ [S1, unofficial].

10. **SRGB Conversion**:
    Convert linear color to SRGB. If $x \le 0.0031308$, return $12.92 \times x$. Else return $1.055 \times x^{1/2.4} - 0.055$ [S1, unofficial].

**Pseudocode**
```python
def render_fragment(volume, volume_dims, transformed_eye, vray_dir, dt_scale, 
                    lightPosition, windowLevel, windowWidth, rescaleSlope, rescaleIntercept,
                    opacityMapPositions, opacityMapSamples, colorMapPositions, colorMapSamples):
    # 1. Ray-Box Intersection
    invDir = 1.0 / vray_dir
    tmin_tmp = (boxMin - transformed_eye) * invDir
    tmax_tmp = (boxMax - transformed_eye) * invDir
    tmin = min(tmin_tmp, tmax_tmp)
    tmax = max(tmin_tmp, tmax_tmp)
    t0 = max(tmin.x, max(tmin.y, tmin.z))
    t1 = min(tmax.x, min(tmax.y, tmax.z))
    if t0 > t1: return discard_fragment()

    # 2. Step Size
    dt_vec = 1.0 / (volume_dims * abs(vray_dir))
    dt = dt_scale * min(dt_vec.x, min(dt_vec.y, dt_vec.z))

    # 3. Ray Origin Offset
    seed = wang_hash(int(gl_FragCoord.x + 1024.0 * gl_FragCoord.y))
    offset = seed / 2147483647.0
    p = transformed_eye + (t0 + offset * dt) * vray_dir

    # 4-5. Rescale & Transfer Functions
    def sample_transfer(rescaled_val, pos_tex, samp_tex, num_samples):
        for i in range(1, num_samples):
            if pos_tex[i] >= rescaled_val:
                t = (rescaled_val - pos_tex[i-1]) / (pos_tex[i] - pos_tex[i-1])
                return lerp(samp_tex[i-1], samp_tex[i], t)
        return samp_tex[num_samples-1]

    def apply_opacity(rescaled_val):
        base_opacity = sample_transfer(rescaled_val, opacityMapPositions, opacityMapSamples, numberOfOpacitySamples)
        windowFloor = windowLevel - windowWidth / 2.0
        return clamp(base_opacity * (rescaled_val - windowFloor) / windowWidth, 0.0, 1.0)

    def apply_color(rescaled_val):
        return sample_transfer(rescaled_val, colorMapPositions, colorMapSamples, numberOfColorSamples)

    # 6. Ray Marching
    voxelColor = vec4(0.0)
    t = t0
    while t < t1:
        raw_val = sample_volume(volume, p)
        rescaled = rescaleSlope * raw_val + rescaleIntercept
        opacity = apply_opacity(rescaled)
        color = apply_color(rescaled)
        val_color = vec4(opacity * color, opacity)
        val_color.a = 1.0 - pow(1.0 - val_color.a, dt_scale)
        voxelColor.rgb += (1.0 - voxelColor.a) * val_color.a * val_color.rgb
        voxelColor.a += (1.0 - voxelColor.a) * val_color.a
        if voxelColor.a >= 0.95: break
        t += dt
        p += vray_dir * dt

    # 7. Lighting
    voxelSize = 1.0 / volume_dims
    grad = compute_gradient_opacity(p, voxelSize, apply_opacity)
    voxelNormal = normalize(grad)
    lightDir = normalize(lightPosition - p)
    intensity = dot(voxelNormal, lightDir)
    spec = 0.0
    if intensity > 0.0:
        h = normalize(lightDir + transformed_eye)
        intSpec = max(dot(h, voxelNormal), 0.0)
        spec = 0.5 * pow(intSpec, 8.0)
    shadow = 1.0
    if voxelColor.a >= 0.20:
        shadow = clamp(soft_shadow(p, voxelSize) * 2.0 + 0.1, 0.0, 1.0)
    lightColor = shadow * max(intensity * 0.6 + spec, 0.4)
    voxelColor.rgb *= lightColor

    # 10. SRGB
    return srgb_convert(voxelColor)

def wang_hash(seed):
    seed = (seed ^ 61) ^ (seed >> 16)
    seed *= 9
    seed = seed ^ (seed >> 4)
    seed *= 0x27d4eb2d
    seed = seed ^ (seed >> 15)
    return seed % 2147483647

def soft_shadow(p, voxelSize):
    delta = min(voxelSize.x, min(voxelSize.y, voxelSize.z)) * 2.0
    total_shadow = 0.0
    for dx in [-1, 0, 1]:
        for dz in [-1, 0, 1]:
            if dx == 0 and dz == 0: continue
            pos = p + vec3(dx * delta, 0.0, dz * delta)
            total_shadow += 1.0 - trace_light(pos, lightPosition)
    return total_shadow / 8.0

def trace_light(voxel, light):
    voxelToLight = light - voxel
    d = normalize(voxelToLight)
    o = voxel - 1000.0 * d
    box = ray_box_intersection(o, d)
    start = length(voxel - o)
    integrated = 0.0
    step = min(voxelSize.x, min(voxelSize.y, voxelSize.z)) / 1.0
    t = start
    while t < box.y:
        val = sample_opacity_at_pos(t)
        integrated += val / 4.0
        if integrated > 0.95: break
        t += step
    return clamp(integrated, 0.0, 1.0)

def srgb_convert(x):
    return 12.92 * x if x <= 0.0031308 else 1.055 * pow(x, 1.0/2.4) - 0.055
```

**Pitfalls**
*   **Ray-box intersection failure**: If $t_0 > t_1$, the ray does not intersect the volume box. The fragment is discarded [S1, unofficial].
*   **Early termination**: The ray marching loop breaks if accumulated alpha `voxelColor.a >= 0.95` to save computation [S1, unofficial].
*   **Shadow ray early termination**: The light tracing loop breaks if integrated opacity `integrated > 0.95` [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: Linear with respect to the number of samples along the ray. The number of samples is determined by the volume dimensions, ray direction, and `dt_scale`. Shadow calculation adds a constant overhead per lit voxel [S1, unofficial].
*   **Memory Complexity**: Dominated by the storage of the 3D volume texture and the 2D transfer function textures [S1, unofficial].
*   **Performance**: Interactive performance is achieved on modern browsers via WebGL 2.0. Performance scales with resolution and volume size [S1, unofficial].
*   **Strengths**: Interactive frame rates, browser-based accessibility, soft shadows for improved depth perception [S1, unofficial].
*   **Limitations**: Approximate lighting (normal estimation from opacity gradients may be noisy), fixed step size (unless adaptive), limited to scalar volumes [S1, unofficial].
*   **When to use**: Interactive visualization of scalar fields in web browsers [S1, unofficial].
*   **When not to use**: High-fidelity offline rendering requiring accurate normal estimation from the scalar field itself, or complex volume data types (e.g., tensor fields) [S1, unofficial].

## Background
The method demonstrates the use of WebGL 2.0 for interactive volume rendering with path tracing techniques, including lighting and shadowing, within a web browser environment [S1, unofficial]. The repository name is not given in the sources.
