# WebGL Path Tracing Volume Rendering

Also called: Interactive Voxel Volume Rendering via WebGL 2.0

## Overview
An interactive voxel volume renderer that runs in modern web browsers via WebGL 2.0, rendering 3D scalar fields by casting rays from the camera through the volume, accumulating color and opacity, and applying lighting and shadowing [S1, unofficial]. It distinguishes itself from standard direct volume ray casting by implementing a path-tracing-like shading model (diffuse, specular, and soft shadows) within the fragment shader, while using a linear search through control points for transfer functions to support arbitrary non-uniform sampling [S1, unofficial].

## How it works
**Inputs and Outputs**
*   **Inputs**:
    *   `volume`: `highp sampler3D` containing the scalar field.
    *   `volume_dims`: `ivec3` defining the dimensions of the volume texture.
    *   `vray_dir`: `vec3` ray direction in world space.
    *   `transformed_eye`: `vec3` camera origin in world space.
    *   `lightPosition`: `vec3` position of the light source.
    *   `windowLevel`, `windowWidth`: Floats defining the DICOM-like windowing for value rescaling [S1, unofficial].
    *   `rescaleSlope`, `rescaleIntercept`: Floats for linear transformation of raw values (`rescaled_value = rescaleSlope * raw_value + rescaleIntercept`) [S1, unofficial].
    *   `dt_scale`: Float scaling factor for the ray marching step size and Beer-Lambert approximation [S1, unofficial].
    *   `opacityMapPositions`, `opacityMapSamples`: `highp sampler2D` textures storing control points for opacity mapping [S1, unofficial].
    *   `colorMapPositions`, `colorMapSamples`: `highp sampler2D` textures storing control points for color mapping [S1, unofficial].
    *   `numberOfOpacitySamples`, `numberOfColorSamples`: Integers defining the number of control points [S1, unofficial].
    *   `box_min`, `box_max`: `vec3` defining the volume bounding box in world space.
*   **Outputs**:
    *   `color`: `vec4` final accumulated color and opacity for the pixel.

**Data Structures**
The transfer functions are stored in 2D textures where one dimension represents the position (value) and the other represents the sample (opacity or color) [S1, unofficial]. The renderer performs a linear search through these control points rather than using texture interpolation, allowing for non-uniform spacing of control points [S1, unofficial].

**Algorithm Steps**

1.  **Ray-Box Intersection**:
    Compute the inverse ray direction `invDir = 1.0 / ray_dir` [S1, unofficial].
    Calculate temporary bounds:
    $$ t_{min\_tmp} = (boxMin - orig) \cdot invDir $$
    $$ t_{max\_tmp} = (boxMax - orig) \cdot invDir $$
    Determine entry and exit times:
    $$ t_{min} = \min(t_{min\_tmp}, t_{max\_tmp}) $$
    $$ t_{max} = \max(t_{min\_tmp}, t_{max\_tmp}) $$
    $$ t_0 = \max(t_{min}.x, \max(t_{min}.y, t_{min}.z)) $$
    $$ t_1 = \min(t_{max}.x, \min(t_{max}.y, t_{max}.z)) $$
    If $t_0 > t_1$, the ray does not intersect the volume; discard the fragment [S1, unofficial].

2.  **Step Size Calculation**:
    Compute the step size based on the volume dimensions and ray direction to ensure consistent voxel traversal:
    $$ dt_{vec} = \frac{1.0}{vec3(volume\_dims) \cdot |ray\_dir|} $$
    $$ dt = dt\_scale \cdot \min(dt_{vec}.x, \min(dt_{vec}.y, dt_{vec}.z)) $$
    [S1, unofficial]

3.  **Ray Origin Offset**:
    Generate a random offset to reduce aliasing using a Wang hash:
    $$ seed = (seed \oplus 61) \oplus (seed \gg 16) $$
    $$ seed = seed \cdot 9 $$
    $$ seed = seed \oplus (seed \gg 4) $$
    $$ seed = seed \cdot 0x27d4eb2d $$
    $$ seed = seed \oplus (seed \gg 15) $$
    $$ offset = \frac{seed \pmod{2147483647}}{2147483647} $$
    Initial position:
    $$ p = transformed\_eye + (t_0 + offset \cdot dt) \cdot ray\_dir $$
    [S1, unofficial]

4.  **Ray Marching Loop**:
    Initialize accumulated color `voxelColor = vec4(0.0)` [S1, unofficial].
    Loop $t$ from $t_0$ to $t_1$ with step $dt$:
    a.  **Sample Volume**: Retrieve raw value $V$ from `volume` at position $p$ [S1, unofficial].
    b.  **Rescale Value**:
        $$ V_{rescaled} = rescaleSlope \cdot V + rescaleIntercept $$
        $$ V_{windowed} = \frac{V_{rescaled} - (windowLevel - windowWidth/2.0)}{windowWidth} $$
    c.  **Transfer Function**:
        *   **Opacity**: Find interval $[opacityMapPositions(i-1), opacityMapPositions(i)]$ containing $V_{windowed}$. Interpolate between $opacityMapSamples(i-1)$ and $opacityMapSamples(i)$ [S1, unofficial]. Clamp result to $[0, 1]$. Let this be $\alpha_{raw}$.
        *   **Color**: Similarly, interpolate color $\mathbf{c}_{raw}$ from `colorMapSamples`.
    d.  **Beer-Lambert Approximation**:
        $$ \mathbf{val\_color} = vec4(\alpha_{raw} \cdot \mathbf{c}_{raw}, \alpha_{raw}) $$
        $$ \mathbf{val\_color}.a = 1.0 - (1.0 - \mathbf{val\_color}.a)^{dt\_scale} $$
    e.  **Compositing**:
        $$ \mathbf{voxelColor}.rgb \leftarrow \mathbf{voxelColor}.rgb + (1.0 - \mathbf{voxelColor}.a) \cdot \mathbf{val\_color}.a \cdot \mathbf{val\_color}.rgb $$
        $$ \mathbf{voxelColor}.a \leftarrow \mathbf{voxelColor}.a + (1.0 - \mathbf{voxelColor}.a) \cdot \mathbf{val\_color}.a $$
    f.  **Early Termination**: If $\mathbf{voxelColor}.a \ge 0.95$, break loop [S1, unofficial].
    g.  **Advance**: $p \leftarrow p + ray\_dir \cdot dt$ [S1, unofficial].
    [S1, unofficial]

5.  **Lighting and Shading**:
    If $\mathbf{voxelColor}.a < 0.20$, shadow is set to 1.0; otherwise, lighting is computed [S1, unofficial].
    a.  **Normal Estimation**:
        Compute voxel size $voxelSize = 1.0 / vec3(volume\_dims)$ [S1, unofficial].
        Estimate gradient $\nabla V$ using central differences on the opacity-mapped value at $p$:
        $$ \nabla V_x = \frac{Opacity(p + (voxelSize.x, 0, 0)) - Opacity(p - (voxelSize.x, 0, 0))}{2 \cdot voxelSize.x} $$
        (Similarly for y and z).
        $$ voxelNormal = normalize(\nabla V) $$
    b.  **Diffuse Lighting**:
        $$ lightDirection = normalize(p - lightPosition) $$
        $$ intensity = dot(voxelNormal, lightDirection) $$
        $$ diffuseIntensity = intensity \cdot 0.6 $$
    c.  **Specular Lighting**:
        $$ h = normalize(lightDirection + transformed\_eye) $$
        $$ intSpec = \max(dot(h, voxelNormal), 0.0) $$
        $$ spec = 0.5 \cdot intSpec^{8.0} $$
    d.  **Shadow Calculation**:
        Compute `softShadow(p)` by casting a shadow ray (see Step 6) [S1, unofficial].
        $$ shadow = clamp(softShadow(p) \cdot 2.0 + 0.1, 0.0, 1.0) $$
    e.  **Final Color**:
        $$ lightColor = shadow \cdot \max(intensity \cdot 0.6 + spec, 0.4) $$
        $$ \mathbf{voxelColor}.rgb \leftarrow \mathbf{voxelColor}.rgb \cdot lightColor $$
    [S1, unofficial]

6.  **Soft Shadow Calculation**:
    Sample 8 points around the voxel position $p$ in a 3x3 grid (excluding center) with spacing $\delta = \min(voxelSize.x, \min(voxelSize.y, voxelSize.z)) \cdot 2.0$ [S1, unofficial]. For each point, compute `pointShadow = 1.0 - traceLight(position, lightPosition)` [S1, unofficial]. Sum these shadows and divide by 8.0 [S1, unofficial].

7.  **Light Tracing (Shadow Ray)**:
    Cast a ray from $voxel$ towards $light$.
    $$ voxelToLight = light - voxel $$
    $$ d = normalize(voxelToLight) $$
    $$ o = voxel - 1000.0 \cdot d $$
    Intersect ray with box to get $[t_{start}, t_{end}]$ [S1, unofficial].
    Compute $start = length(voxel - o)$.
    Sample opacity along the shadow ray from $start$ to $t_{end}$ with step $\delta = \min(voxelSize.x, \min(voxelSize.y, voxelSize.z)) / samplesPerVoxel$ (where $samplesPerVoxel = 1.0$) [S1, unofficial].
    Accumulate $integrated \leftarrow integrated + val / samplesPerVoxel / 4.0$ [S1, unofficial].
    If $integrated > 0.95$, break [S1, unofficial].
    Return $clamp(integrated, 0.0, 1.0)$ [S1, unofficial].

8.  **SRGB Conversion**:
    Convert final linear color to sRGB for display:
    If $x \le 0.0031308$, return $12.92 \cdot x$ [S1, unofficial].
    Else return $1.055 \cdot x^{1/2.4} - 0.055$ [S1, unofficial].

**Pseudocode**

```python
def render_fragment(vray_dir, transformed_eye, volume, volume_dims, dt_scale, 
                    light_position, window_level, window_width, rescale_slope, 
                    rescale_intercept, opacity_map_positions, opacity_map_samples,
                    color_map_positions, color_map_samples, num_opacity_samples, 
                    num_color_samples, frag_coord, box_min, box_max):
    # 1. Ray-Box Intersection
    inv_dir = 1.0 / vray_dir
    t_min_tmp = (box_min - transformed_eye) * inv_dir
    t_max_tmp = (box_max - transformed_eye) * inv_dir
    t_min = min(t_min_tmp, t_max_tmp)
    t_max = max(t_min_tmp, t_max_tmp)
    t0 = max(t_min.x, max(t_min.y, t_min.z))
    t1 = min(t_max.x, min(t_max.y, t_max.z))
    
    if t0 > t1:
        return vec4(0.0)

    # 2. Step Size
    dt_vec = 1.0 / (vec3(volume_dims) * abs(vray_dir))
    dt = dt_scale * min(dt_vec.x, min(dt_vec.y, dt_vec.z))

    # 3. Ray Origin Offset
    seed = wang_hash(int(frag_coord.x + 1024.0 * frag_coord.y))
    offset = float(seed % 2147483647) / 2147483647.0
    p = transformed_eye + (t0 + offset * dt) * vray_dir

    # 4. Ray Marching
    voxel_color = vec4(0.0)
    t = t0
    while t < t1:
        val = sample_volume(volume, p)
        rescaled_val = rescale_slope * val + rescale_intercept
        windowed_val = (rescaled_val - (window_level - window_width / 2.0)) / window_width
        
        alpha_raw = lookup_transfer(windowed_val, opacity_map_positions, opacity_map_samples, num_opacity_samples)
        color_raw = lookup_transfer(windowed_val, color_map_positions, color_map_samples, num_color_samples)
        
        val_color = vec4(alpha_raw * color_raw, alpha_raw)
        val_color.a = 1.0 - pow(1.0 - val_color.a, dt_scale)
        
        voxel_color.rgb += (1.0 - voxel_color.a) * val_color.a * val_color.rgb
        voxel_color.a += (1.0 - voxel_color.a) * val_color.a
        
        if voxel_color.a >= 0.95:
            break
            
        p += vray_dir * dt
        t += dt

    # 5. Lighting
    if voxel_color.a >= 0.20:
        voxel_size = 1.0 / vec3(volume_dims)
        grad = compute_gradient_opacity(p, voxel_size, volume, volume_dims, window_level, window_width, rescale_slope, rescale_intercept, opacity_map_positions, opacity_map_samples, num_opacity_samples)
        voxel_normal = normalize(grad)
        
        light_dir = normalize(p - light_position)
        intensity = dot(voxel_normal, light_dir)
        diffuse = intensity * 0.6
        
        h = normalize(light_dir + transformed_eye)
        int_spec = max(dot(h, voxel_normal), 0.0)
        spec = 0.5 * pow(int_spec, 8.0)
        
        shadow_val = soft_shadow(p, light_position, volume, volume_dims, voxel_size, window_level, window_width, rescale_slope, rescale_intercept, opacity_map_positions, opacity_map_samples, num_opacity_samples, box_min, box_max)
        shadow = clamp(shadow_val * 2.0 + 0.1, 0.0, 1.0)
        
        light_color = shadow * max(intensity * 0.6 + spec, 0.4)
        voxel_color.rgb *= light_color

    voxel_color.rgb = srgb_convert(voxel_color.rgb)
    return voxel_color

def wang_hash(seed):
    seed = (seed ^ 61) ^ (seed >> 16)
    seed *= 9
    seed = seed ^ (seed >> 4)
    seed *= 0x27d4eb2d
    seed = seed ^ (seed >> 15)
    return seed % 2147483647

def lookup_transfer(value, positions, samples, num_samples):
    for i in range(1, num_samples):
        if positions[i] >= value:
            t = (value - positions[i-1]) / (positions[i] - positions[i-1])
            return samples[i-1] + t * (samples[i] - samples[i-1])
    return samples[num_samples-1]

def sample_volume(volume, p):
    return texture(volume, p).r

def sample_volume_opacity(p, volume, volume_dims, window_level, window_width, rescale_slope, rescale_intercept, opacity_map_positions, opacity_map_samples, num_opacity_samples):
    val = sample_volume(volume, p)
    rescaled_val = rescale_slope * val + rescale_intercept
    windowed_val = (rescaled_val - (window_level - window_width / 2.0)) / window_width
    return lookup_transfer(windowed_val, opacity_map_positions, opacity_map_samples, num_opacity_samples)

def compute_gradient_opacity(p, voxel_size, volume, volume_dims, window_level, window_width, rescale_slope, rescale_intercept, opacity_map_positions, opacity_map_samples, num_opacity_samples):
    def sample_op(pos):
        return sample_volume_opacity(pos, volume, volume_dims, window_level, window_width, rescale_slope, rescale_intercept, opacity_map_positions, opacity_map_samples, num_opacity_samples)
    grad_x = (sample_op(p + vec3(voxel_size.x, 0, 0)) - sample_op(p - vec3(voxel_size.x, 0, 0))) / (2.0 * voxel_size.x)
    grad_y = (sample_op(p + vec3(0, voxel_size.y, 0)) - sample_op(p - vec3(0, voxel_size.y, 0))) / (2.0 * voxel_size.y)
    grad_z = (sample_op(p + vec3(0, 0, voxel_size.z)) - sample_op(p - vec3(0, 0, voxel_size.z))) / (2.0 * voxel_size.z)
    return normalize(vec3(grad_x, grad_y, grad_z))

def ray_box_intersect(o, d, box_min, box_max):
    inv_d = 1.0 / d
    t_min_tmp = (box_min - o) * inv_d
    t_max_tmp = (box_max - o) * inv_d
    t_min = min(t_min_tmp, t_max_tmp)
    t_max = max(t_min_tmp, t_max_tmp)
    t0 = max(t_min.x, max(t_min.y, t_min.z))
    t1 = min(t_max.x, min(t_max.y, t_max.z))
    return vec2(t0, t1)

def trace_light(voxel, light_pos, volume, volume_dims, voxel_size, window_level, window_width, rescale_slope, rescale_intercept, opacity_map_positions, opacity_map_samples, num_opacity_samples, box_min, box_max):
    voxel_to_light = light_pos - voxel
    d = normalize(voxel_to_light)
    o = voxel - 1000.0 * d
    box_hit = ray_box_intersect(o, d, box_min, box_max)
    if box_hit.y < box_hit.x:
        return 1.0
    start = length(voxel - o)
    delta = min(voxel_size.x, min(voxel_size.y, voxel_size.z)) / 1.0
    integrated = 0.0
    t = start
    while t < box_hit.y:
        sample_pos = o + t * d
        val = sample_volume_opacity(sample_pos, volume, volume_dims, window_level, window_width, rescale_slope, rescale_intercept, opacity_map_positions, opacity_map_samples, num_opacity_samples)
        integrated += val / 1.0 / 4.0
        if integrated > 0.95:
            break
        t += delta
    return clamp(integrated, 0.0, 1.0)

def soft_shadow(p, light_pos, volume, volume_dims, voxel_size, window_level, window_width, rescale_slope, rescale_intercept, opacity_map_positions, opacity_map_samples, num_opacity_samples, box_min, box_max):
    delta = min(voxel_size.x, min(voxel_size.y, voxel_size.z)) * 2.0
    sum_shadow = 0.0
    count = 0
    for dx in [-1, 0, 1]:
        for dy in [-1, 0, 1]:
            if dx == 0 and dy == 0:
                continue
            offset = vec3(dx * delta, dy * delta, 0.0)
            pos = p + offset
            point_shadow = 1.0 - trace_light(pos, light_pos, volume, volume_dims, voxel_size, window_level, window_width, rescale_slope, rescale_intercept, opacity_map_positions, opacity_map_samples, num_opacity_samples, box_min, box_max)
            sum_shadow += point_shadow
            count += 1
    return sum_shadow / 8.0

def srgb_convert(x):
    if x <= 0.0031308:
        return 12.92 * x
    else:
        return 1.055 * pow(x, 1.0 / 2.4) - 0.055
```

## Operating characteristics
*   **Time Complexity**: Not given in the sources.
*   **Memory Complexity**: Not given in the sources.
*   **Performance**: Not given in the sources.
*   **Strengths**: Runs on standard web hardware without plugins. Supports arbitrary transfer functions. Provides basic shading (diffuse/specular/shadow) for better depth perception [S1, unofficial].
*   **Limitations**: Linear search for transfer functions is slower than texture-based lookup. Shadow calculation is expensive and simplified (single sample per voxel direction). No global illumination or caustics [S1, unofficial].
*   **When to use**: Interactive visualization of scalar fields in web applications where basic shading improves understanding [S1, unofficial].
*   **When not to use**: Not given in the sources.

## Background
This method is based on an open-source WebGL 2.0 based interactive voxel volume renderer using path tracing that runs in modern browsers [S1, unofficial]. It builds upon the principles of direct volume ray casting [19-direct-volume-ray-casting.md] but adapts them for the fragment shader execution model of WebGL, incorporating shading models typically found in path tracers [S1, unofficial].
