# Layered Volume Rendering with Light Propagation

Also called: Layer-based volumetric ray marching, Plane-sweep volume rendering

## Overview
Layered Volume Rendering with Light Propagation is a compute-shader-based technique that renders volumetric data by processing a stack of parallel planes (layers) rather than individual pixels or rays [S1, unofficial]. It propagates light and view rays across these layers, accumulating color, alpha, and material properties while applying refraction gradients and transfer functions [S1, unofficial]. It sets itself apart from standard direct volume ray casting by decoupling the light transport calculation from the view ray accumulation into distinct propagation passes, allowing for efficient screen-space approximation of scattering and refraction effects across discrete depth slices [S1, unofficial].

## How it works
The method operates on a stack of $P$ parallel planes spaced by a constant distance. It uses two main phases per layer: a **Light Propagation** pass to compute attenuated light intensity and direction, and a **Ray Propagation** pass to accumulate the final image color using the propagated light [S1, unofficial].

### Inputs and Outputs
**Inputs:**
*   `ubo`: Uniform buffer object containing:
    *   `plane_pixel_size`: Pixel size of rendering planes in world units [S1, unofficial].
    *   `distance_between_planes`: Constant Z-distance between consecutive layers [S1, unofficial].
    *   `lightVSPos`: View-space position of the light source [S1, unofficial].
    *   `light_color`: View-space color/intensity of the light source [S1, unofficial].
    *   `plane_count`: Total number of layers $P$ [S1, unofficial].
*   Textures:
    *   `volume_density`: Scalar volume data [S1, unofficial].
    *   `volume_transfer`: Transfer function texture, sampled with `vec2(volume_density, volume_density_prev)` to output alpha [S1, unofficial].
    *   `medium_transfer`: Tint transfer function texture, sampled with `vec2(volume_density, volume_density_prev)` to output tint color [S1, unofficial].
*   Buffers (from previous layer or initialization):
    *   `lb_in`: Light color buffer (input) [S1, unofficial].
    *   `ldb_in`: Light direction buffer (input) [S1, unofficial].
    *   `vpb_in`: View position buffer (input) [S1, unofficial].
    *   `vdb_in`: View direction buffer (input) [S1, unofficial].
    *   `cb_in`: Color buffer (input) [S1, unofficial].
    *   `mb_in`: Material buffer (input) [S1, unofficial].

**Outputs:**
*   `lb_out`: Light color buffer (output) [S1, unofficial].
*   `ldb_out`: Light direction buffer (output) [S1, unofficial].
*   `cb_out`: Final color/alpha buffer (output) [S1, unofficial].
*   `mb_out`: Material buffer (output) [S1, unofficial].
*   `vpb_out`: Next view position buffer (output) [S1, unofficial].
*   `vdb_out`: Next view direction buffer (output) [S1, unofficial].

### Data Structures
All buffers are accessed via `imageLoad`/`imageStore` using `ivec2` pixel coordinates corresponding to the screen resolution [S1, unofficial]. The buffers store `vec4` values for color/alpha/material and `vec3` for directions/positions.

### Algorithm Steps

#### 1. Initialization
For the first layer ($layer\_index = 0$), initialize light direction `ldb_in` to a default value (e.g., $(0,0,1)$) and light color `lb_in` to the source light color. Initialize view buffers `vpb_in` and `vdb_in` based on camera parameters. Initialize `cb_in` and `mb_in` to zero [S1, unofficial].

#### 2. Light Propagation Pass
For each layer $l$ from $0$ to $P-1$:
1.  **Coordinate Calculation**: Compute current layer Z position:
    $$ z_{current} = z_{front} - l \cdot d_{plane} $$
    where $z_{front}$ is the Z-coordinate of the front plane and $d_{plane}$ is `ubo.distance_between_planes` [S1, unofficial].
2.  **Light Ray Intersection**: For each pixel $(u, v)$, define a light ray starting at $(0.5, 0.5, z_{current} + d_{plane})$ with direction $-\mathbf{L}_{current}$ (sampled from `ldb_in` at $(u,v)$). Intersect this ray with the plane at $z_{current}$ to find the hit point $\mathbf{p}_{prev}$ [S1, unofficial].
3.  **Light Sampling & Averaging**:
    *   Sample light color $\mathbf{L}_{prev}$ from `lb_in` at $\mathbf{p}_{prev}.xy$ [S1, unofficial].
    *   Sample light direction $\mathbf{L}_{prev\_dir}$ from `ldb_in` at $\mathbf{p}_{prev}.xy$.
    *   Apply 4-tap averaging to $\mathbf{L}_{prev\_dir}$: center weight 0.5, four neighbors weight 0.125 each. Normalize the result. If length $< 10^{-6}$, set to $(0,0,1)$ [S1, unofficial].
4.  **Irradiance Scaling**:
    *   Compute screen-space area factors: $S_{current} = |\frac{\partial u}{\partial x}| \cdot |\frac{\partial u}{\partial y}|$ and $S_{prev} = |\frac{\partial p_{prev}.x}{\partial x}| \cdot |\frac{\partial p_{prev}.y}{\partial y}|$ using `dFdx`/`dFdy` [S1, unofficial].
    *   Compute irradiance factor $I$:
        $$ I = \begin{cases} S_{prev} / S_{current} & \text{if } S_{current} > 10^{-8} \\ 1.0 & \text{otherwise} \end{cases} $$
        [S1, unofficial].
5.  **Transfer Function & Attenuation**:
    *   Convert UV and $\mathbf{p}_{prev}.xy$ to world positions at $z_{current}$ and $z_{current} + d_{plane}$ [S1, unofficial].
    *   Sample `volume_density` at both positions to get $\rho_{current}$ and $\rho_{prev}$ [S1, unofficial].
    *   Sample `volume_transfer` with `vec2(ρ_current, ρ_prev)` to get opacity $\alpha$ [S1, unofficial].
    *   Sample `medium_transfer` with `vec2(ρ_current, ρ_prev)` to get tint $\mathbf{T}$ via `mix(vec3(1.0), m_data.rgb, m_data.a)` [S1, unofficial].
    *   Compute output light color: $\mathbf{L}_{out} = \mathbf{L}_{prev} \cdot I \cdot (1.0 - \alpha) \cdot \mathbf{T}$. Clamp $\mathbf{L}_{out}$ to minimum value 20.0 [S1, unofficial].
6.  **Light Refraction Update**:
    *   Compute midpoint $\mathbf{m}_{ws} = (\mathbf{p}_{ws} + \mathbf{p}_{prev\_ws}) \cdot 0.5$ [S1, unofficial].
    *   Get refraction gradient $\nabla \mathbf{L}_{grad}$ from volume density at $\mathbf{m}_{ws}$ [S1, unofficial].
    *   Update light direction: $\mathbf{L}_{next} = \mathbf{L}_{prev\_dir} + \nabla \mathbf{L}_{grad} \cdot d_{plane}$. Normalize and store to `ldb_out` [S1, unofficial].

#### 3. Ray Propagation Pass
For each layer $l$ from $0$ to $P-1$:
1.  **View Ray Intersection**:
    *   Sample view position $\mathbf{V}_{pos}$ from `vpb_in` and direction $\mathbf{V}_{dir}$ from `vdb_in` at $(u,v)$ [S1, unofficial].
    *   Convert $\mathbf{V}_{pos}$ to world space [S1, unofficial].
    *   Intersect ray from $\mathbf{V}_{pos}$ with direction $-\mathbf{V}_{dir}$ with plane at $z_{current} + d_{plane}$ to get previous hit point $\mathbf{V}_{prev}$ [S1, unofficial].
2.  **Shading**:
    *   Compute volume gradient $\mathbf{N}$ at $\mathbf{V}_{ws} + 0.5$ [S1, unofficial].
    *   View vector $\mathbf{V} = \text{normalize}(-\mathbf{V}_{dir})$ [S1, unofficial].
    *   Light direction $\mathbf{L}_{dir} = \text{normalize}(\text{ubo.lightVSPos} - \mathbf{V}_{pos})$ [S1, unofficial].
    *   Half vector $\mathbf{H} = \text{normalize}(\mathbf{L}_{dir} + \mathbf{V})$ [S1, unofficial].
    *   Specular: $\text{spec} = \max(\mathbf{N} \cdot \mathbf{H}, 0.0)^{128.0}$ [S1, unofficial].
    *   Specular intensity: $\mathbf{I}_s = \text{ubo.light_color} \cdot \text{spec} \cdot 0.05$ [S1, unofficial].
    *   Material mask: $m_{mask} = \text{smoothstep}(0.0, 0.05, \rho_{current})$ [S1, unofficial].
3.  **Accumulation**:
    *   Sample previous color $\mathbf{C}_{prev}$ and alpha $A_{prev}$ from `cb_in` [S1, unofficial].
    *   Sample previous material $\mathbf{M}_{prev}$ from `mb_in` [S1, unofficial].
    *   Sample light intensity $\mathbf{I}_d$ from `lb_in` at current UV [S1, unofficial].
    *   Compute current color:
        $$ \mathbf{C}_{current} = \mathbf{C}_{prev} + (1.0 - A_{prev}) \cdot \mathbf{M}_{prev} \cdot (\alpha \cdot \mathbf{I}_d + \mathbf{I}_s \cdot m_{mask}) $$
        [S1, unofficial].
    *   Update alpha:
        $$ A_{current} = A_{prev} + (1.0 - A_{prev}) \cdot \alpha $$
        [S1, unofficial].
    *   Update material:
        $$ \mathbf{M}_{current} = \mathbf{M}_{prev} \cdot (1.0 - m.w) + \mathbf{M}_{prev} \cdot m.xyz \cdot m.w $$
        where $m$ is the material sample from `mb_in` [S1, unofficial].
4.  **Refraction & Next Step**:
    *   Compute midpoint $\mathbf{m}_{ws} = (\mathbf{V}_{ws} + \mathbf{V}_{prev\_ws}) \cdot 0.5 + 0.5$ [S1, unofficial].
    *   Get refraction gradient $\nabla \mathbf{V}_{grad}$ [S1, unofficial].
    *   Update view direction: $\mathbf{V}_{next} = \mathbf{V}_{dir} + \nabla \mathbf{V}_{grad} \cdot d_{plane}$. Normalize [S1, unofficial].
    *   Intersect ray from $\mathbf{V}_{pos}$ with $\mathbf{V}_{next}$ to plane at $z_{current} - d_{plane}$ to get $\mathbf{V}_{next\_pos}$ [S1, unofficial].
5.  **Background Replacement (Last Layer)**:
    *   If $l == P-1$:
        *   Generate checkerboard background: scale=16, `check_uv` = $\mathbf{V}_{next}.xy \cdot 16$, $f = \lfloor \text{check\_uv}.x \rfloor + \lfloor \text{check\_uv}.y \rfloor \pmod 2$, $\mathbf{B} = \text{mix}((0.2,0.2,0.2), (0.5,0.5,0.5), f)$ [S1, unofficial].
        *   Blend background: $\mathbf{C}_{current} = \mathbf{B} \cdot (1.0 - A_{current}) + \mathbf{C}_{current} \cdot A_{current}$ [S1, unofficial].
        *   Set $A_{current} = 1.0$ [S1, unofficial].
6.  **Output Storage**:
    *   Store $\mathbf{C}_{current}, A_{current}$ to `cb_out` [S1, unofficial].
    *   Store $\mathbf{M}_{current}$ to `mb_out` [S1, unofficial].
    *   Store $\mathbf{V}_{next\_pos}$ to `vpb_out` [S1, unofficial].
    *   Store $\mathbf{V}_{next}$ to `vdb_out` [S1, unofficial].

### Pseudocode
```python
# Constants
EPSILON = 1e-6
MIN_LIGHT = 20.0
SPECULAR_POWER = 128.0
SPECULAR_SCALE = 0.05
MATERIAL_MASK_THRESHOLD = 0.05

def process_layer(layer_index, ubo, textures, buffers):
    z_current = ubo.middle_of_front_plane_vs.z - float(layer_index) * ubo.distance_between_planes
    
    # Light Propagation
    # 1. Intersect light ray
    # Ray: origin=(0.5, 0.5, z_current + dist), dir=-L_prev
    # Hit point lp_prev on plane z_current
    lp_prev = intersect_ray_plane(vec3(0.5, 0.5, z_current + ubo.distance_between_planes), 
                                  -sample_buffer(buffers.ldb_in, uv), 
                                  z_current)
    
    # 2. Sample and average light direction
    L_prev_dir = sample_buffer(buffers.ldb_in, lp_prev.xy)
    L_prev_dir = average_4tap(L_prev_dir) # center 0.5, neighbors 0.125
    if length(L_prev_dir) < EPSILON:
        L_prev_dir = vec3(0, 0, 1)
    L_prev_dir = normalize(L_prev_dir)
    
    # 3. Irradiance scaling
    S_current = abs(dFdx(uv.x)) * abs(dFdy(uv.y))
    S_prev = abs(dFdx(lp_prev.x)) * abs(dFdy(lp_prev.y))
    if S_current > EPSILON:
        I = S_prev / S_current
    else:
        I = 1.0
        
    # 4. Transfer function
    # Convert to world space
    pos_current_ws = uv_to_world(uv, z_current)
    pos_prev_ws = uv_to_world(lp_prev.xy, z_current + ubo.distance_between_planes)
    
    rho_current = sample_texture(textures.volume_density, pos_current_ws)
    rho_prev = sample_texture(textures.volume_density, pos_prev_ws)
    
    alpha = sample_texture(textures.volume_transfer, vec2(rho_current, rho_prev)).a # Assuming alpha is in A channel or returned directly
    tint = sample_texture(textures.medium_transfer, vec2(rho_current, rho_prev))
    tint = mix(vec3(1.0), tint.rgb, tint.a)
    
    L_prev_color = sample_buffer(buffers.lb_in, lp_prev.xy)
    L_out = L_prev_color * I * (1.0 - alpha) * tint
    L_out = clamp(L_out, vec3(MIN_LIGHT), vec3(1e6))
    
    # 5. Light refraction
    mid_ws = (pos_current_ws + pos_prev_ws) * 0.5
    ref_grad = compute_refraction_gradient(textures.volume_density, mid_ws)
    L_next = L_prev_dir + ref_grad * ubo.distance_between_planes
    L_next = normalize(L_next)
    
    # Ray Propagation
    # 1. Intersect view ray
    V_pos = sample_buffer(buffers.vpb_in, uv)
    V_dir = sample_buffer(buffers.vdb_in, uv)
    V_pos_ws = vsp_to_world(V_pos)
    
    V_prev = intersect_ray_plane(V_pos_ws, -V_dir, z_current + ubo.distance_between_planes)
    
    # 2. Shading
    N = normalize(compute_gradient(textures.volume_density, V_pos_ws + 0.5))
    V_vec = normalize(-V_dir)
    L_dir = normalize(ubo.lightVSPos - V_pos)
    H = normalize(L_dir + V_vec)
    spec = pow(max(dot(N, H), 0.0), SPECULAR_POWER)
    is_val = ubo.light_color * spec * SPECULAR_SCALE
    material_mask = smoothstep(0.0, MATERIAL_MASK_THRESHOLD, rho_current)
    
    # 3. Accumulation
    C_prev = sample_buffer(buffers.cb_in, uv).rgb
    A_prev = sample_buffer(buffers.cb_in, uv).a
    M_prev = sample_buffer(buffers.mb_in, uv)
    id_val = sample_buffer(buffers.lb_in, uv)
    
    C_current = C_prev + (1.0 - A_prev) * M_prev * (alpha * id_val + is_val * material_mask)
    A_current = A_prev + (1.0 - A_prev) * alpha
    M_current = M_prev * (1.0 - M_prev.w) + M_prev * M_prev.xyz * M_prev.w
    
    # 4. Refraction & Next Step
    mid_ws_ray = (V_pos_ws + V_prev) * 0.5 + 0.5
    vd_grad = compute_refraction_gradient(textures.volume_density, mid_ws_ray)
    V_next = V_dir + vd_grad * ubo.distance_between_planes
    V_next = normalize(V_next)
    V_next_pos = intersect_ray_plane(V_pos_ws, V_next, z_current - ubo.distance_between_planes)
    
    # 5. Background (Last Layer)
    if layer_index == ubo.plane_count - 1:
        scale = 16
        check_uv = V_next_pos.xy * scale
        f = mod(floor(check_uv.x) + floor(check_uv.y), 2.0)
        bg = mix(vec3(0.2), vec3(0.5), f)
        C_current = bg * (1.0 - A_current) + C_current * A_current
        A_current = 1.0
        
    # 6. Output
    store_buffer(buffers.cb_out, uv, vec4(C_current, A_current))
    store_buffer(buffers.mb_out, uv, M_current)
    store_buffer(buffers.vpb_out, uv, V_next_pos)
    store_buffer(buffers.vdb_out, uv, V_next)
    store_buffer(buffers.lb_out, uv, L_out)
    store_buffer(buffers.ldb_out, uv, L_next)
```

### Parameters
*   `ubo.plane_pixel_size`: Pixel size of the rendering planes in world units [S1, unofficial].
*   `ubo.distance_between_planes`: Constant Z-distance between consecutive layers [S1, unofficial].
*   `ubo.lightVSPos`: View-space position of the light source [S1, unofficial].
*   `ubo.light_color`: View-space color/intensity of the light source [S1, unofficial].
*   `ubo.plane_count`: Number of layers [S1, unofficial].

### Edge Cases and Pitfalls
*   **Zero-length light direction**: If the normalized light direction after averaging has length $< 10^{-6}$, it is replaced with $(0,0,1)$ to prevent NaN propagation or division by zero [S1, unofficial].
*   **Division by zero in irradiance scaling**: If $S_{current} < 10^{-8}$, the irradiance factor $I$ is clamped to 1.0 to avoid NaN or infinite values [S1, unofficial].
*   **Layer boundary handling**: On the last layer ($layer\_index == P-1$), the accumulated alpha is forced to 1.0 and a checkerboard background is blended in to prevent transparent edges or missing geometry [S1, unofficial].

## Operating characteristics
*   **Time Complexity**: $O(P \cdot W \cdot H)$, where $P$ is the number of planes, and $W \times H$ is the screen resolution. Each pixel is processed once per layer in two passes (light and view) [S1, unofficial].
*   **Memory Complexity**: $O(W \cdot H)$ for the buffers, as only the current and previous layer states need to be stored [S1, unofficial].
*   **Performance**: The method is designed for GPU execution via compute shaders, leveraging parallel processing for each pixel and layer [S1, unofficial].
*   **Strengths**: Efficient handling of large volumes by reducing the 3D integration to a series of 2D plane sweeps; supports screen-space refraction and approximate scattering [S1, unofficial].
*   **Limitations**: Approximate light transport due to screen-space propagation; quality depends on the number of layers and plane spacing [S1, unofficial].

## Background
This method is described in the context of a Vulkan-based volume rendering implementation, specifically associated with the `vis-magnus-2018` project [S1, unofficial]. It represents a modern, hardware-accelerated approach to layered volume rendering, integrating light propagation with view ray casting in a compute shader environment [S1, unofficial].
