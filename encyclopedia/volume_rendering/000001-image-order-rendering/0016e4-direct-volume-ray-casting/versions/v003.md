# Direct volume ray casting

Also called: Direct Volume Rendering (DVR), Ray Casting, Ray Marching

## Overview
Direct volume ray casting is an image-order rendering technique that casts a ray through a 3D volume for every pixel, sampling scalar values, mapping them to RGBA via a transfer function, and compositing samples front-to-back using alpha blending to produce the final image [S2, S3]. It differs from [Isosurface and first-hit ray casting](20-isosurface-and-first-hit-ray-casting.md) by allowing all voxels to contribute to the final image rather than stopping at the first opaque surface [S5], and from [Distance-field ray marching](21-distance-field-ray-marching.md) by using uniform step sizes rather than distance-field-guided steps [G]. It replaces slice-stack methods by providing a solid volume appearance from any angle without edge-on gaps [S15].

## Shared principles
The method relies on the volume rendering integral, discretized into a summation over sample points along a ray [S3, S5]. The ray $r$ is parameterized by $r(t) = O + tD$, entering the volume at $t_{start}$ and exiting at $t_{end}$ [Volume Raycasting Discretization](831-volume-raycasting-discretization.md). The data model is sampled using $s(t)$ [Volume Raycasting Discretization](831-volume-raycasting-discretization.md).

The compositing is performed front-to-back [S2, S3, S5]. Let $C'_i$ be the accumulated color and $\alpha'_i$ be the accumulated opacity after sample $i$, with initial conditions $C'_0 = 0$ and $\alpha'_0 = 0$ [S2, S5]. For each sample $i$ along the ray:
1.  Sample the volume at the current ray position to get a scalar value $d_i$ [S2, S5].
2.  Apply a transfer function to map the scalar value to color $C_i$ and opacity $\alpha_i$ [S2, S5].
3.  Update accumulated color:
    $$ C'_i = C'_{i-1} + (1 - \alpha'_{i-1}) \alpha_i C_i $$
4.  Update accumulated opacity:
    $$ \alpha'_i = \alpha'_{i-1} + (1 - \alpha'_{i-1}) \alpha_i $$
5.  If $\alpha' \ge 1$ (or a specific threshold, typically 99%) [S2, S3], terminate the ray (early ray termination) [S2, S3, S4].

Rays are cast from the eyepoint, one for each pixel [S1, S4]. The volume is typically represented as a 3D texture [S4, S3]. Gradients for shading are calculated using a central difference operator [S1]. To avoid normal discontinuities that cause visible rings on smooth surfaces, the gradient is computed using a two-voxel offset rather than a one-voxel offset [S1]. Sampling is performed using trilinear interpolation [S1, S5]. A fixed random offset is applied to each ray's start position to prevent sample layers from appearing as bands [S3]. The final accumulated color is typically corrected with gamma 2.2 [S2].

```python
import random

def vec3(x, y, z):
    return [x, y, z]

def pow_vec3(v, exponent):
    return [v[0]**exponent, v[1]**exponent, v[2]**exponent]

def compute_ray_exit(origin, direction, bounds):
    # Slab intersection for axis-aligned box [G]
    t0 = max((bounds[0][i] - origin[i]) / direction[i] if direction[i] != 0 else float('inf') for i in range(3))
    t1 = min((bounds[1][i] - origin[i]) / direction[i] if direction[i] != 0 else float('inf') for i in range(3))
    return max(t0, t1)

def direct_volume_raycast(volume_texture, camera, transfer_function, step_size=0.001, threshold=0.99):
    """
    Renders a volume using fixed-step raycasting with front-to-back compositing.
    """
    h, w = camera.screen_height, camera.screen_width
    # Initialize output image as a 2D array of vec3(0.0, 0.0, 0.0)
    image = [[vec3(0.0, 0.0, 0.0) for _ in range(w)] for _ in range(h)]
    
    for y in range(h):
        for x in range(w):
            ray_origin, ray_direction = camera.cast_ray(x, y)
            accumulated_color = vec3(0.0, 0.0, 0.0)
            accumulated_opacity = 0.0
            
            # Ray initialization: fixed random offset to prevent banding [S3]
            t = random.uniform(0.0, step_size)
            
            # Compute ray exit distance from volume bounds [G]
            t_end = compute_ray_exit(ray_origin, ray_direction, volume_bounds)
            
            while accumulated_opacity < threshold and t < t_end:
                # Sample volume at current position using trilinear interpolation [S1, S5]
                scalar_value = volume_texture.sample_trilinear(ray_origin, t, ray_direction)
                
                # Apply transfer function to get color and opacity [S2, S5]
                color, opacity = transfer_function(scalar_value)
                
                # Front-to-back compositing [S2, S5]
                accumulated_color[0] += (1.0 - accumulated_opacity) * opacity * color[0]
                accumulated_color[1] += (1.0 - accumulated_opacity) * opacity * color[1]
                accumulated_color[2] += (1.0 - accumulated_opacity) * opacity * color[2]
                accumulated_opacity += (1.0 - accumulated_opacity) * opacity
                
                t += step_size
                
            # Gamma correction [S2]
            image[y][x] = pow_vec3(accumulated_color, 1.0/2.2)
            
    return image
```

### [Distance Color Blending](791-distance-color-blending.md)
A technique to enhance depth perception by dimming colors and shifting them towards a background color (often blue for aerial perspective) as they recede from the viewer [791-distance-color-blending.md]. It uses an exponential function for non-linear progression [791-distance-color-blending.md].
1. Determine fraction of distance through volume $d_v$ for the sample [791-distance-color-blending.md].
2. Calculate blending factor $B = k_{ds} d_v^{k_{de}}$ [791-distance-color-blending.md].
3. Compute final color $c_d = (1 - B) c_v + B c_b$ [791-distance-color-blending.md].
4. Use $c_d$ as the final color [791-distance-color-blending.md].

Formula:
$$ c_d = (1 - k_{ds} d_v^{k_{de}}) c_v + k_{ds} d_v^{k_{de}} c_b $$
where $c_d$ is the depth-cued color, $c_v$ is the original voxel color, $c_b$ is the background color, $d_v$ is the fraction of distance through the volume, $k_{ds}$ controls the size/magnitude of the blending effect, and $k_{de}$ controls the rate of application (exponent) [791-distance-color-blending.md].
Parameters: $c_b$ is the background color. If grey $(a,a,a)$, only intensity dimming occurs. If blue $(a,b,c)$ with $c>a,b$, a cool shift is introduced [791-distance-color-blending.md].

## Background
The term "direct volume rendering" was coined by Marc Levoy in his 1988 paper "Display of Surfaces from Volume Data" [S1, S4]. Levoy defined the volume rendering pipeline, which remains an influential framework [S1]. The technique was originally designed to display weak or fuzzy surfaces with smooth silhouettes and few aliasing artifacts [S1].

Historically, it evolved from slice-stack methods, which showed gaps when viewed edge-on [S3]. GPU-based implementations, such as ray marching, were developed to perform the traversal efficiently within fragment shaders, outperforming CPU-based Shear-Warp methods in both speed and image quality [S4]. For example, GPU ray marching achieved 48 fps for a Skull model with 400 steps, compared to 10 fps for Shear-Warp [S4]. It is used in medical imaging visualization, such as in the quick_dicom project [S3].
