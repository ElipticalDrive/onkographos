# Hybrid Volume Rendering
Also called: Hybrid and Mixed Geometry
## Overview
Hybrid Volume Rendering is a technique that allows polygon and volume data to be visualized in a single image, useful for displaying scale, grids, or other polygon-defined objects over, behind, and through volume data [S1, unofficial]. It distinguishes itself from pure volume ray casting by integrating explicit geometric primitives (polygons) with implicit volumetric fields, enabling the co-rendering of distinct data types that would otherwise require separate passes or compositing.

## Shared principles
The core mechanism involves rendering both polygonal geometry and volumetric data into a common framebuffer, typically using a depth buffer to resolve visibility between the two data types. The process generally follows these steps:

1.  **Polygon Rendering**: Render the explicit polygonal objects (e.g., grids, scales, labels) into the color and depth buffers. This establishes the foreground or background geometry.
2.  **Volume Rendering**: Perform direct volume ray casting or slice-based rendering for the volumetric data. During this pass, the depth buffer is used to clip rays or determine visibility, ensuring that volume data is correctly occluded by or occludes the polygons based on their depth values.
3.  **Compositing**: The final image is a composite of the polygonal and volumetric contributions, resolved via standard depth testing.

No specific mathematical transfer function or ray marching algorithm is shared across all hybrid methods, as the volume rendering component can vary (e.g., ray casting, texture-based slicing). The shared principle is the integration of explicit and implicit representations in a single rendering pipeline.

## Subtopics

### Hybrid Ray Tracing
Combines ray tracing for polygons with volume rendering techniques (often ray casting) for volumes. It allows for accurate shadows and reflections from polygons affecting the volume visualization. Choose this when high-fidelity lighting interactions between geometry and volume are required. See [Hybrid Ray Tracing](2308-hybrid-ray-tracing.md).

### Mixed Geometry Rendering
Focuses on rendering multiple types of geometry (polygons, volumes, point clouds) in a unified manner, often using specific blending or compositing strategies. Choose this when dealing with heterogeneous data sources that need to be visualized together without strict hierarchy. See [Mixed Geometry Rendering](3442-mixed-geometry-rendering.md).

## Background
The term "Hybrid Volume Rendering Techniques" was introduced in the early 1990s to describe methods that combine polygon and volume data visualization [S1, unofficial]. Key early references include [Lev90], [RK92], and [vWHVP92]. These techniques were developed to address the limitation of pure volume rendering, which often lacks context provided by explicit geometric markers like scales, grids, or anatomical landmarks. The approach is useful for displaying scale, grids, or other polygon-defined objects over, behind, and through volume data [S1, unofficial].
