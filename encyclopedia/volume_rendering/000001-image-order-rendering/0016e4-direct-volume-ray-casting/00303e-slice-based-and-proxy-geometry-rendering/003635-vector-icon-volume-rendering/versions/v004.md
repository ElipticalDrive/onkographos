# Vector Icon Volume Rendering

Also called: Billboard vector icons, Vector Icon Splatting with Billboard Textures, Vector icons embedded in splat footprint, Volume Rendering with Embedded Vector Icons

## Overview
Vector Icon Volume Rendering is a 3D raster resampling technique that integrates vector field visualization into volume rendering by embedding small billboard images containing vector icons within the splat footprint of scalar data [S1, unofficial]. It solves the problem of visualizing flow direction and magnitude within a volumetric scalar field (such as density clouds) by creating an illusion of coherent flow through stochastic placement and orientation of these icons [S1, unofficial]. It sets itself apart from standard direct volume ray casting by explicitly rendering discrete geometric primitives (cylinders or icons) within the splat footprint to represent vector attributes, rather than relying solely on scalar opacity and color transfer functions [S1, unofficial].

## How it works
**Inputs and Outputs:**
*   **Inputs:** A 3D scalar field (e.g., density), a 3D vector field (e.g., wind velocity), a 3D texture containing the scalar data, and a set of billboard textures containing vector icons.
*   **Outputs:** A 2D image where scalar volume is rendered via alpha blending, overlaid with oriented vector icons indicating flow.

**Data Structures:**
*   **3D Texture:** Stores the scalar volumetric data.
*   **Billboard Textures:** A set of 2D textures containing pre-rendered vector icons. These textures are cycled through to simulate motion [S1, unofficial].
*   **Proxy Geometry:** Quads or triangle fans representing slicing planes, textured with the 3D scalar volume [S1, unofficial].

**Method Steps:**
1.  **Sheet Construction:** Build the volume rendering in sheets oriented parallel to the image plane [S1, unofficial].
2.  **Sorting:** Composite these sheets in a back-to-front order relative to the camera [S1, unofficial].
3.  **Grid Sampling:** For each sheet, take a regular grid sampling of the data points [S1, unofficial].
4.  **Splat Placement:** Place an image reconstruction operator (splat) over each grid point [S1, unofficial].
5.  **Stochastic Icon Selection:** Use a stochastic heuristic to determine whether a specific splat should include a vector icon (cylinder) [S1, unofficial].
6.  **Icon Offset:** If an icon is included, randomly offset the cylinder/icon from the center of the splat [S1, unofficial].
7.  **Billboard Orientation:** Orient the billboard image such that it lies perpendicular to the viewing ray and parallel to the projected vector direction at the splat's center point [S1, unofficial].
8.  **Icon Scaling:** Select the icon size based on the flow direction relative to the viewer:
    *   If flow is parallel to the screen, choose the largest icon [S1, unofficial].
    *   If flow is parallel to the viewer’s line of sight, reduce the icon to a small dot [S1, unofficial].
    *   Intermediate directions use intermediate sizes to indicate vector direction into/out of the screen [S1, unofficial].
9.  **Color Mapping:** Assign color to the vector icons based on scalar attributes, such as altitude [S1, unofficial].
10. **Compositing:** Add the volume integral for each pixel under the splat and the cylinder/icon. Composite the billboard images with the scalar volume using hardware alpha blending [S1, unofficial].
11. **Animation (Optional):** To alleviate sparse representation and create motion, cycle through a set of textures where icons move across the texture, fading in and out, at rendering time [S1, unofficial].

**Pseudocode:**
```python
def render_vector_icon_volume(scalar_volume_3d, vector_field_3d, billboard_textures, camera):
    # 1. Generate proxy geometry (sheets) parallel to image plane
    sheets = generate_slicing_planes(scalar_volume_3d.bounding_box)
    
    # 2. Sort sheets back-to-front relative to camera
    sheets.sort(key=lambda s: s.depth_from_camera(camera))
    
    for sheet in sheets:
        # 3. Regular grid sampling on the current sheet
        grid_points = sheet.sample_grid(vector_field_3d)
        
        for point in grid_points:
            scalar_val = scalar_volume_3d.sample(point.position)
            vector_val = vector_field_3d.sample(point.position)
            
            # 4. Place splat footprint
            splat_footprint = create_splat(point.position)
            
            # 5. Stochastic heuristic for icon inclusion
            if stochastic_include_icon():
                # 6. Random offset from center
                offset = random_offset()
                icon_position = point.position + offset
                
                # 7. Determine billboard orientation
                # Perpendicular to viewing ray, parallel to projected vector
                view_ray = camera.position - icon_position
                projected_vector = project_vector(vector_val, view_ray)
                billboard_transform = align_billboard(view_ray, projected_vector)
                
                # 8. Select icon size based on flow direction
                flow_angle = angle_between(vector_val, view_ray)
                if flow_angle is parallel_to_screen:
                    icon_size = LARGEST
                elif flow_angle is parallel_to_viewer:
                    icon_size = DOT_SIZE
                else:
                    icon_size = interpolate_size(flow_angle)
                
                # 9. Color based on altitude (scalar attribute)
                icon_color = map_altitude_to_color(scalar_val)
                
                # 10. Render icon
                render_billboard(
                    texture=billboard_textures[current_texture_index],
                    position=icon_position,
                    transform=billboard_transform,
                    size=icon_size,
                    color=icon_color
                )
            
            # 11. Render scalar volume splat (standard alpha blending)
            render_scalar_splat(
                position=point.position,
                scalar=scalar_val,
                footprint=splat_footprint
            )
            
            # 12. Cycle textures for animation illusion
            current_texture_index = (current_texture_index + 1) % len(billboard_textures)
```

**Parameters:**
*   **Stochastic Heuristic Threshold:** Not given in the sources.
*   **Icon Sizes:** Largest (flow parallel to screen), Small Dot (flow parallel to line of sight). Intermediate sizes for other angles [S1, unofficial].
*   **Color Mapping:** Altitude of the vector icons [S1, unofficial].

**Edge Cases and Pitfalls:**
*   **Sparse Representation:** The discrete and sparse nature of the icons can make the flow difficult to understand [S1, unofficial].
*   **Precision:** Random offsetting requires careful handling to ensure icons remain within the splat footprint or are correctly composited [S1, unofficial].

## Operating characteristics
*   **Time Complexity:** Linear with respect to the number of grid points in the sheets. The stochastic check and texture cycling add constant overhead per point.
*   **Memory Complexity:** Requires storage for the 3D scalar volume, the 3D vector field, and the set of billboard textures.
*   **Strengths:** Provides intuitive visual cues for flow direction and magnitude within a volumetric context; merges scalar and vector field rendering seamlessly [S1, unofficial].
*   **Limitations:** The representation is sparse and discrete, which can obscure flow continuity; relies on stochastic placement which may lead to visual noise or uneven distribution [S1, unofficial].
*   **When to use:** When visualizing time-varying flow fields (e.g., wind, climate simulations) where direction and magnitude are critical alongside scalar density [S1, unofficial].
*   **When not to use:** When dense, continuous flow visualization is required without the artifact of discrete icons.

## Background
**Origin:** Developed by R. Crawfis, H. Shen, and N. Max [S1, unofficial].
**History:** The technique was presented at the 9th International Symposium on Flow Visualization, Heriot-Watt University, Edinburgh, 2000 [S1, unofficial]. It builds on earlier work by Crawfis and Max on 3D raster resampling and anisotropic texture volume rendering [S1, unofficial].
**Application:** Applied to global climate simulations to visualize wind velocity direction overlaid on cloudiness density [S1, unofficial].
